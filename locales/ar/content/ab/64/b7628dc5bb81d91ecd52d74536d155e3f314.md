# مقدمة

يحتوي الصنف `Array` في JavaScript على العديد من الطرق المدمجة القوية لتحويل المصفوفات.
تجعل هذه الطرق تحويل مصفوفة إلى أخرى أسهل بكثير مما سيكون عليه الأمر باستخدام حلقة `for` بسيطة أو تعامل مباشر أكثر.

بعض الطرق [_نقية_][pure-function-definition]، أي أنها لا تعدّل المصفوفة الأصلية، بل تُرجع مصفوفة جديدة بدلًا منها.
في حين تعمل طرق أخرى على تعديل المصفوفة التي تُستدعى عليها و**لا** تُرجع المصفوفة المعدّلة.

فيما يلي بعض الطرق الأكثر استخدامًا لتحويل المصفوفات.
تجد القائمة الكاملة للطرق المتاحة في [توثيق MDN][array-methods].

### map (نقية)

أنشئ مصفوفة جديدة بتحويل كل عنصر وفق دالة تُمرَّر كوسيط.
غالبًا ما تُكتب دوال الاستدعاء الرجعي هذه بصيغة [دوال السهم][concept-arrow-functions].

```javascript
let arr = [1, 2, 3, 4];

const newArr = arr.map((value) => value - 1);
console.log(newArr);
// => [0, 1, 2, 3]
console.log(arr);
// => [1, 2, 3, 4]
```

تجدر الإشارة إلى أن المصفوفة الناتجة ستكون دائمًا بالطول نفسه الذي للمصفوفة الأصلية.

### filter (نقية)

تُنشئ مصفوفة بترشيح المصفوفة الحالية وفق دالة ترشيح (تُرجع صحيحًا إذا كان ينبغي الاحتفاظ بالعنصر وخطأً إذا كان ينبغي حذفه).

```javascript
let arr = [1, 2, 3, 4];

arr.filter((value) => value % 2 === 0);
// => [2, 4]
```

### reduce (نقية)

تختصر المصفوفة إلى قيمة واحدة باستخدام دالة تأخذ _المُراكم_ والعنصر الحالي في المصفوفة كمعاملين.
تُحدِّد هذه الدالة كيفية دمج العنصر الحالي في المُراكم، وتُرجع المُراكم الذي سيُستخدم في التكرار التالي.

```javascript
let arr = [1, 2, 3, 4];

// Get the sum of elements
arr.reduce((accumulator, currentValue) => accumulator + currentValue, 0);
// => 10

// Classify the numbers by whether they are odd or not
arr.reduce(
  (accumulator, currentValue) => {
    if (currentValue % 2 === 0) {
      accumulator.even.push(currentValue);
    } else {
      accumulator.odd.push(currentValue);
    }

    return accumulator;
  },
  { even: [], odd: [] },
);
// => { even: [2, 4], odd: [1, 3] }
```

### reverse

تعكس ترتيب عناصر المصفوفة.

```javascript
const arr = [1, 2, 3, 4];

arr.reverse();
// => [4, 3, 2, 1]
```

تعدّل هذه الطريقة المصفوفة التي تُستدعى عليها.

### slice (نقية)

بالنظر إلى فهرس بداية وفهرس نهاية، تُنشئ مصفوفة فرعية من المصفوفة التي تُستدعى عليها.

لن يُضمَّن العنصر الواقع عند فهرس النهاية.
كذلك جميع المعاملات اختيارية:
ففهرس البداية قيمته الافتراضية `0`، وفهرس النهاية قيمته الافتراضية طول المصفوفة.

```javascript
const arr = [1, 2, 3, 4];

arr.slice(1, 2); // [2]
arr.slice(1); // [2, 3, 4]
// You can also use negative numbers, that represent the indexes
// starting from the end of the array
arr.slice(-2); // [3, 4]
```

### splice

تحذف عناصر من مصفوفة أو تستبدلها و/أو تضيف عناصر جديدة إليها.

تأخذ المعاملات التالية:

- فهرس العنصر الذي يبدأ عنده تعديل المصفوفة
- عدد العناصر المراد حذفها
- العناصر المراد إدراجها في المصفوفة (اختياري)

تُرجع `splice` العناصر التي حُذفت.

```javascript
const arr = ['1', '2', '5', '6'];

// Insert an element at index 2
arr.splice(2, 0, '3');
console.log(arr);
// => ['1', '2', '3', '5', '6']

// Remove 2 elements, starting at index 3 and insert 2 elements
const removed = arr.splice(3, 2, '4', '5');
console.log(removed);
// => ['5', '6']
console.log(arr);
// => ['1', '2', '3', '4', '5']

// Remove 1 element at index 1
arr.splice(1, 1);
console.log(arr);
// => ['1', '3', '4', '5']
```

### sort

افتراضيًا، تُرتِّب `sort` عناصر المصفوفة بتحويلها أولًا إلى سلاسل نصية ثم تطبيق مقارنة السلاسل النصية (انظر [مقارنة المفاهيم][concept-comparison]).
يحدث الترتيب _في موضعها_، مما يعني أن المصفوفة الأصلية تُعدَّل.
كما تُرجع `sort` تلك المصفوفة المعدّلة، وهو أمر مناسب إذا أردت ربط طرق أخرى بها.

```javascript
const arr = ['c', 'a', 'z', 'b'];
const result = arr.sort();
console.log(result);
// => ['a', 'b', 'c', 'z']
console.log(arr);
// => ['a', 'b', 'c', 'z']
```

لتخصيص سلوك الترتيب، يمكنك تمرير دالة مقارنة كوسيط.
تُستدعى دالة المقارنة نفسها بوسيطين هما عنصران من المصفوفة.
وعليها حينئذ أن تُرجع ما يلي:

- عددًا سالبًا إذا كان ينبغي ترتيب الوسيط الأول قبل الثاني
- عددًا موجبًا إذا كان ينبغي ترتيب الوسيط الأول بعد الثاني
- `0` إذا كان ينبغي أن يبقى ترتيب العناصر كما هو

على سبيل المثال، لترتيب الأعداد يمكن استخدام دالة المقارنة التالية.

```javascript
const arr = [3, 1, 2, 10];
arr.sort((a, b) => a - b);
// => [1, 2, 3, 10]
// "a - b" is negative when b is greater than a, positive when
// a is greater than b and 0 when they are equal.
```
