# التعليمات

إنها الوردية الليلية عند رصيف ميناء هال. سفينة الشحن *Olwen* راسية إلى جانب الرصيف، وطاقم من عمال الرصيف يعمل على بيان الشحن على التوازي. يجب وزن كل صندوق قبل أن يُحمَّل على متن السفينة، ويحتفظ رئيس الميناء بسجل حمولة جارٍ واحد يُحدّثه كل رفع. لكن هناك عقبة: لا توجد سوى رافعة واحدة على الرصيف، لذا لا يمكن أن يتمزق السجل عندما يحدّثه عاملان في الوقت نفسه.

كل صندوق عبارة عن مصفوفة من أوزان العناصر. ووزن الصندوق هو مجموع تلك العناصر.

## 1. زِن صندوقًا

عرّف `weigh-crate` بحيث تأخذ صندوقًا وتُرجع وزنه الإجمالي. هذا عمل تسلسلي بسيط: صندوق واحد، ورقم واحد ناتج عنه.

```factor
{ 12 8 15 } weigh-crate .
! => 35
```

## 2. زِن بيان الشحن كاملًا على التوازي

عرّف `weigh-all` بحيث تأخذ مصفوفة من الصناديق وتُرجع مصفوفة بأوزانها بالترتيب نفسه. استخدم `parallel-map` حتى يجري العمل على كل صندوق بالتزامن.

```factor
{ { 5 5 } { 10 } { 3 4 5 } } weigh-all .
! => { 10 10 12 }
```

## 3. ابنِ رافعة جديدة

عرّف `<crane>` لإنشاء رافعة جديدة: توبل يحتوي على `<lock>` جديد وحمولة قدرها `0`. الرافعة هي المورد المشترك الذي ستحميه المهام اللاحقة.

```factor
<crane> tonnage>> .
! => 0
```

## 4. ارفع صندوقًا إلى السجل الجاري

عرّف `hoist-crate` بحيث تأخذ `weight` و`crane` وتضيف الوزن إلى حمولة الرافعة **تحت قفل الرافعة**، حتى تكون عملية القراءة والجمع والكتابة ذرّية في مواجهة عمال الرصيف الآخرين الذين يرفعون في الوقت نفسه.

```factor
<crane>
35 over hoist-crate
17 over hoist-crate
tonnage>> .
! => 52
```

## 5. اقرأ الحمولة الجارية

عرّف `crane-tonnage` بحيث تُرجع الحمولة الحالية للرافعة، وذلك أيضًا تحت القفل، حتى لا ترى القراءة قيمة ممزقة في منتصف عملية رفع.

```factor
<crane>
35 over hoist-crate
crane-tonnage .
! => 35
```

## 6. حمّل الشحنة

عرّف `load-cargo` بحيث تأخذ مصفوفة من الصناديق ورافعة، و**لكل صندوق، أنشئ خيطًا لعامل رصيف** يزن الصندوق ويرفع وزنه إلى الرافعة. ولا تُرجع الكلمة إلا بعد أن ينتهي كل عمال الرصيف. استخدم `<promise>` و`?promise` لتنسيق الانضمام.

```factor
<crane> :> crane
{ { 5 5 } { 10 } { 3 4 5 } } crane load-cargo
crane crane-tonnage .
! => 32
```
