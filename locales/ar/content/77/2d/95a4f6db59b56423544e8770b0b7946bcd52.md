# مقدمة

## الدوال

في Gleam تُعرَّف الدوال باستخدام الصيغة `pub fn`.

```gleam
pub fn add(x: Int, y: Int) -> Int {
  x + y
}
```

تأخذ هذه الدالة وسيطين، كلاهما من النوع `Int`، وتُرجع قيمة من النوع `Int`. لا توجد كلمة مفتاحية `return` في Gleam، فقيمة آخر تعبير في الدالة _تُرجَع ضمنيًا_ دائمًا.

تعليقات النوع الخاصة بالوسائط ونوع الإرجاع اختيارية، وسيتحقق Gleam دائمًا من أنواع كودك بشكل كامل. عادةً ما يضيف مبرمجو Gleam تعليقات النوع إلى دوالهم من أجل الوضوح، لكن يمكنك حذفها إن أردت.

```gleam
pub fn add(x, y) {
  x + y
}
```

يمكن استدعاء دالة باستخدام الصيغة `function_name(argument1, argument2)`.

```gleam
pub fn double(x: Int) -> Int {
  // Call the add function defined above
  add(x, x)
}
```

## المتغيرات

في Gleam تُعرَّف المتغيرات باستخدام الصيغة `let name = expression`.

```gleam
pub fn main() {
  let count = 1
}
```

يمكن الإعلان عن المتغيرات مع تعليقات النوع. وكما هو الحال مع وسائط الدوال، فهي اختيارية، رغم أن معظم مبرمجي Gleam يحذفون تعليقات النوع الخاصة بالمتغيرات اختصارًا.

```gleam
pub fn main() {
  let count: Int = 1
}
```

## السلاسل النصية الحرفية

في Gleam تُكتب السلاسل النصية باستخدام علامات الاقتباس المزدوجة.

```gleam
pub fn greeting() {
  "Hello, world!"
}
```

## تعليقات الكود

يمكن استخدام التعليقات لترك ملاحظات لمبرمجين آخرين يقرؤون الكود المصدري. التعليقات في Gleam عبارة عن أسطر مفردة يسبقها `//`.

```gleam
pub fn main() {
  // This is a comment
  let x = 1
}
```
