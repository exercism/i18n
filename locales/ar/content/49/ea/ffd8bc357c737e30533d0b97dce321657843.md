# مقدمة

ورث صديقك إليود مزرعة عن جدتها تيغيست.
كانت جدتها مخترعة، وكانت تميل إلى بناء الأشياء بطريقة معقدة أكثر من اللازم.
يحتوي قن الدجاج على شاشة رقمية تعرض عددًا مُرمَّزًا يمثّل مواضع كل البيض الذي يمكن جمعه.

تطلب منك إليود كتابة برنامج يُظهر العدد الفعلي للبيض في القن.

تُحسب طريقة ترميز معلومات المواضع كما يلي:

1. افحص المواضع المحتملة لوضع البيض، وسجّل `1` عند وجود بيضة و`0` عند وجود موضع فارغ.
2. حوّل العدد من النظام الثنائي إلى النظام العشري.
3. اعرض النتيجة على الشاشة.

المثال 1:

```text
Chicken Coop:
 _ _ _ _ _ _ _
|E| |E|E| | |E|

Resulting Binary:
 1 0 1 1 0 0 1

Decimal number on the display:
89

Actual eggs in the coop:
4
```

المثال 2:

```text
Chicken Coop:
 _ _ _ _ _ _ _ _
| | | |E| | | | |

Resulting Binary:
 0 0 0 1 0 0 0 0

Decimal number on the display:
16

Actual eggs in the coop:
1
```
