# نبذة

تجمع Factor العشوائية في مفردات [`random`][random] حول كلمة عامة واحدة:

```
random ( obj -- elt )
```

وهي توزّع سلوكها حسب وسيطها:

- **عدد صحيح** `n` يُنتج عددًا صحيحًا عشوائيًا في المجال `[0, n)`؛
- **متتالية** تُنتج عنصرًا عشوائيًا؛
- كما تُدعم أيضًا assocs وhash-sets وصفوف `uniform-distribution`.

وتُبنى عليه دالتان مساعدتان للتعامل مع المتتاليات:

```factor
USING: random ;

{ 1 2 3 4 5 } randomize .   ! shuffle in place (Fisher–Yates)
{ 1 2 3 4 5 } 3 sample .    ! 3 distinct elements; error if too many
```

تُعدّل `randomize` المتتالية في مكانها وتُرجعها، لذا استخدم `clone` أولًا إذا احتجت إلى الحفاظ على الترتيب الأصلي.

## من أين تأتي العشوائية

تقرأ `random` المولّد المحفوظ في المتغير الديناميكي `random-generator`. افتراضيًا، هذا مولّد Mersenne Twister تُستمد بذرته من ساعة النظام، لذا تختلف كل عملية تشغيل عن غيرها. ويمكنك تركيب مولّد مختلف خلال مدة تنفيذ الاقتباس:

```
<mersenne-twister> ( seed -- rnd )
with-random        ( rnd quot -- )
```

```factor
USING: random random.mersenne-twister ;

42 <mersenne-twister> [ { 1 2 3 } randomize ] with-random .
! => the same ordering on every run
```

ولأن `with-random` تربط `random-generator` ببساطة خلال المدى الديناميكي للاقتباس، ينبغي توسيم الكلمة التي تغلّفها بـ`inline` حتى يتمكن الاقتباس من ترك نتيجته على المكدس للمستدعي.

وإلى جانب هذه، توفّر `random` كلًا من `random-bits` و`random-unit` و`uniform-random` و`normal-random` لتوزيعات أخرى، إضافة إلى `system-random-generator` و`secure-random-generator` لتلبية الاحتياجات غير القابلة للتكرار والتشفيرية.
