# التعليمات

يُعِدّ Ozan قائمة تشغيل لرحلة برية قادمة. لا يريد أن يسمع المقطوعة نفسها أكثر من مرة، لكنّ قائمة التشغيل صارت طويلة جدًا لدرجة أنه يجد صعوبة في تذكّر المقطوعات التي أُضيفت بالفعل.

إنّ API مشغّل الموسيقى لدى Ozan لا يعمل إلا مع المصفوفات، فيحاول كتابة كود يستخدم `Array.indexOf()` للتحقق من وجود مقطوعة قبل إضافتها إلى قائمة التشغيل. وللأسف، يستغرق برنامجه وقتًا طويلًا جدًا في التنفيذ. إنه بحاجة إلى مساعدتك!

وعندما تسرع لمساعدة Ozan، تُفاجأ بأن قائمة تشغيله تضم _نصف مليون_ مقطوعة. ربما تعرف بنية بيانات مختلفة تتيح لك التعامل مع قائمة التشغيل بكفاءة أكبر؟

## 1. إزالة المقطوعات المكررة

نفّذ الدالة `removeDuplicates`، التي تتلقى قائمة تشغيل بوصفها _معاملًا_ و_تُرجع_ قائمة تشغيل جديدة تكون جميع مقطوعاتها فريدة.

```javascript
const playlist = [
  'Court and Spark - Joni Mitchell',
  'Big Yellow Taxi - Joni Mitchell',
  'Court and Spark - Joni Mitchell',
];

removeDuplicates(playlist);
//=> ['Court and Spark - Joni Mitchell', 'Big Yellow Taxi - Joni Mitchell']
```

## 2. التحقق مما إذا كانت المقطوعة قد أُضيفت بالفعل

نفّذ الدالة `hasTrack`، التي تتلقى قائمة تشغيل ومقطوعة كـ_معاملات_ و_تُرجع_ قيمة منطقية تشير إلى ما إذا كانت قائمة التشغيل تحتوي على المقطوعة.

```javascript
const playlist = [
  'The Fashion Show - Grace Jones',
  'Dr. Funkenstein - Parliament',
];

hasTrack(playlist, 'Dr. Funkenstein - Parliament');
//=> true

hasTrack(playlist, 'Walking in the Rain - Grace Jones');
//=> false
```

## 3. إضافة مقطوعة

نفّذ الدالة `addTrack`، التي تتلقى قائمة تشغيل ومقطوعة كـ_معاملات_ و_تُرجع_ قائمة تشغيل جديدة تتضمن المقطوعة.

```javascript
const playlist = ['Selma - Bijelo Dugme'];

addTrack(playlist, 'Atomic Dog - George Clinton');
//=> ['Selma - Bijelo Dugme', 'Atomic Dog - George Clinton']

addTrack(playlist, 'Selma - Bijelo Dugme');
//=> ['Selma - Bijelo Dugme', 'Atomic Dog - George Clinton']
```

## 4. حذف مقطوعة

نفّذ الدالة `deleteTrack`، التي تتلقى قائمة تشغيل ومقطوعة كـ_معاملات_ و_تُرجع_ قائمة تشغيل جديدة لا تتضمن المقطوعة.

```javascript
const playlist = [
  'The Treasure - Fra Lippo Lippi',
  'After the Fall - Klaus Nomi',
];

deleteTrack(playlist, 'The Treasure - Fra Lippo Lippi');
//=> ['After the Fall - Klaus Nomi']

deleteTrack(playlist, 'I Feel the Magic - Belinda Carlisle');
//=> ['After the Fall - Klaus Nomi']
```

## 5. سرد الفنانين الفريدين

نفّذ الدالة `listArtists`، التي تتلقى قائمة تشغيل كـ_معامل_ و_تُرجع_ قائمة الفنانين الفريدين في قائمة التشغيل. لاحظ أن أسماء المقطوعات مكتوبة بالصيغة `<SONG> - <ARTIST>`.

```javascript
const playlist = [
  'All Mine - Portishead',
  'Sight to Behold - Devendra Banhart',
  'Sour Times - Portishead',
];

listArtists(playlist);
//=> ['Portishead', 'Devendra Banhart']
```
