# التعليمات

في هذا التمرين ستقوم بنمذجة آلة وزن.

## 1. إنشاء حالة أولية لآلة الوزن

عند تهيئتها، ينبغي أن تعتمد آلة الوزن على إعدادات المصنع، وهي تختلف باختلاف المكان الذي تُباع فيه الآلة.
ولذلك ينبغي أن يكون بالإمكان تهيئة الآلة بدقة معيّنة، وبما يحدد ما إذا كانت تستخدم النظام المتري أم الإمبراطوري.

نفّذ الطريقة `WeighingMachine#initialize` التي تأخذ وسيطين: `precision` وهو `Int32`، و`metric` وهو `Bool`.
الوسيط `metric` عندما يكون `true` يعني أن الآلة ينبغي أن تستخدم النظام المتري، وإلا فينبغي أن تستخدم النظام الإمبراطوري.
كما ينبغي أن تعيّن طريقة التهيئة أيضًا متغير المثيل `@weight` إلى `0.0`.

```crystal
precision = 3
metric = true
vm = WeighingMachine.new(precision, metric)
```

## 2. السماح لآلة الوزن بامتلاك دقة

لتلبية الاحتياجات المختلفة، نسمح بتخصيص كل آلة وزن بدقة معيّنة (عدد الأرقام بعد الفاصلة العشرية).

نفّذ طريقة الجلب `WeighingMachine#precision` لتُرجع دقة آلة الوزن.

```crystal
precision = 3
metric = true
vm = WeighingMachine.new(precision, metric)
vm.precision
# => 3
```

## 3. السماح بتعيين الوزن على آلة الوزن

نفّذ الخاصية `WeighingMachine#weight` للسماح بجلب الوزن _و_تعيينه:

```crystal
precision = 3
metric = true
wm = WeighingMachine.new(precision, metric)
wm.weight = 60.5
wm.weight
# => 60.5

wm.weigh
# => 60.5
```

## 4. السماح بالتبديل بين الوحدات المترية والإمبراطورية

نفّذ الخاصية `WeighingMachine#metric=` للسماح بتعيين الوحدة.
ينبغي أن تقبل قيمة منطقية.

```crystal
precision = 3
metric = true
wm = WeighingMachine.new(precision, metric)
vm.weight = 60.5
wm.metric = false

vm.weigh
# => 133.377
```
