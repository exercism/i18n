# مقدمة

## الاستثناءات

تستخدم لغة البرمجة Java _الاستثناءات_ للتعامل مع الأخطاء والأحداث الاستثنائية الأخرى.

### ما هو الاستثناء

الاستثناء حدث يقع أثناء تنفيذ البرنامج فيعطّل التدفق الطبيعي للتعليمات.
تُثار الاستثناءات صراحةً في Java، وتُسمى عملية إثارتها _رمي الاستثناء_.
وتُسمى عملية التعامل مع الاستثناء _التقاط الاستثناء_.

في Java، جميع الاستثناءات أصناف فرعية من الصنف `Exception`، وهو نفسه صنف فرعي من `Throwable`.

تميّز Java بين نوعين من الاستثناءات:

1. الاستثناءات المُتحقَّق منها
2. الاستثناءات غير المُتحقَّق منها

#### الاستثناءات المُتحقَّق منها

_الاستثناءات المُتحقَّق منها_ هي حالات استثنائية ينبغي للتطبيق أن يتوقعها ويتعافى منها.
ومن أمثلتها `FileNotFoundException` الذي يقع عندما تحاول طريقة قراءة ملف غير موجود.

يُتحقَّق من هذا النوع من الاستثناءات في وقت الترجمة: يجب على الطرق التي ترمي استثناءات مُتحقَّق منها أن تحدد ذلك في توقيع الطريقة، ويُشترط على الكود الذي يستدعي طريقة قد ترمي استثناءً مُتحقَّقًا منه أن يتعامل معه، وإلا فلن يُترجم الكود.

جميع الاستثناءات المُتحقَّق منها هي أصناف فرعية من `Exception` لا ترث من `RuntimeException`.

#### الاستثناءات غير المُتحقَّق منها

_الاستثناءات غير المُتحقَّق منها_ هي حالات استثنائية لا يستطيع التطبيق عادةً أن يتوقعها أو يتعافى منها.
ومن أمثلتها `NullPointerException` الذي يقع عندما تتوقع طريقة قيمة غير `null` لكنها تستقبل `null`.

لا يُتحقَّق من هذا النوع من الاستثناءات في وقت الترجمة: لا يجب على الطرق التي ترمي استثناءات غير مُتحقَّق منها أن تحدد ذلك في توقيع الطريقة، ولا يُشترط على الكود الذي يستدعي طريقة قد ترمي استثناءً غير مُتحقَّق منه أن يتعامل معه.

ترث جميع الاستثناءات غير المُتحقَّق منها من `RuntimeException`، وهو بدوره يرث من `Exception`.

### رمي الاستثناءات

يمكن لطريقة في Java أن ترمي استثناءً باستخدام عبارة `throw`.

#### رمي استثناء مُتحقَّق منه

عند رمي استثناء مُتحقَّق منه من طريقة، يجب تحديد ذلك في توقيع الطريقة باستخدام الكلمة المفتاحية `throws`، كما في المثال أدناه.
وهذا يُلزم الكود المستدعي بأن يتوقع إمكانية رمي استثناء وأن يتعامل معه وفقًا لذلك.

```java
public class InsufficientBalanceException extends Exception {

}

public class BankAccount {
  public void withdraw(double amount) throws InsufficientBalanceException {
    if (balance < amount) {
      throw new InsufficientBalanceException();
    }

    // rest of the method implementation
  }
}
```

#### رمي استثناء غير مُتحقَّق منه

عند رمي استثناء غير مُتحقَّق منه من طريقة، لا يجب تحديد ذلك في توقيع الطريقة، وإن كان ذلك مدعومًا.

```java
public class BankAccount {
  public void withdraw(double amount) {
    if (amount < 0) {
      throw new IllegalArgumentException("Cannot withdraw a negative amount");
    }

    // rest of the method implementation
  }
}
```

### معالجة الاستثناءات

تتم معالجة الاستثناءات في Java باستخدام الكلمات المفتاحية `try` و`catch` و`finally`.

- ينبغي تغليف عبارات الكود التي قد ترمي استثناءً في كتلة `try`.
- تتبع كتلة `try` كتلة `catch` واحدة أو أكثر تلتقط الاستثناءات المرمية في كتلة `try`.
- وقد تتبع كتل `catch` اختياريًا كتلة `finally` التي تُنفَّذ دائمًا بعد كتلة `try`، بغض النظر عما إذا رُمي استثناء أم لا.

يوضح المثال التالي كيف تعمل هذه الكلمات المفتاحية:

```java
public class ATM {
  public void withdraw(BankAccount bankAccount, double amount) {
    try {
      System.out.println("Withdrawing " + amount);
      bankAccount.withdraw(amount);
      System.out.println("Withdrawal succeeded");
    } catch (InsufficientBalanceException) {
      System.out.println("Withdrawal failed: insufficient balance");
    } catch (RuntimeException e) {
      System.out.println("Withdrawal failed: " + e.getMessage());
    } finally {
      System.out.println("Current balance: " + bankAccount.getBalance());
    }
  }
}
```

في هذا المثال، عندما لا يُرمى أي استثناء، تُطبع المخرجات التالية:

```text
Withdrawing 10.0
Withdrawal succeeded
Current balance: 5.0
```

أما إذا رمَت العبارة `bankAccount.withdraw(amount)` استثناء `InsufficientBalanceException`، فتُطبع المخرجات التالية:

```text
Withdrawing 10.0
Withdrawal failed: insufficient balance
Current balance: 5.0
```

أو، في حال رمي استثناء غير مُتحقَّق منه من `bankAccount.withdraw(amount)`، فتُطبع المخرجات التالية:

```text
Withdrawing -10.0
Withdrawal failed: Cannot withdraw a negative amount
Current balance: 5.0
```

### الأخطاء

تحتوي Java أيضًا على تصنيف منفصل يُسمى _الأخطاء_، وهي مشكلات جسيمة تقع خارج التطبيق.
ومن أمثلة الأخطاء `OutOfMemoryError` الذي يقع عندما يحاول التطبيق استخدام ذاكرة أكبر من المتاحة على النظام.

ومثل الاستثناءات غير المُتحقَّق منها، لا يُتحقَّق من الأخطاء في وقت الترجمة.
والفرق أنها تمثل مشكلات على مستوى النظام، وعادةً تُرمى من الآلة الافتراضية لـ Java أو من البيئة بدلًا من التطبيق.
وعمومًا لا ينبغي للتطبيقات أن تحاول التقاطها أو معالجتها.

ترث جميع الأخطاء في Java من الصنف `Error`.
