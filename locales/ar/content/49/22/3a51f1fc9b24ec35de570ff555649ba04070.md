# التعليمات

أنت تطوّر لعبة فيديو لتقمّص الأدوار خاصة بك. في لعبتك، هناك _شخصيات_ و_أغراض_. ومن بين الإجراءات الكثيرة التي يمكنك تنفيذها على غرض ما، أن تجعل شخصية تأكله.

ليست كل الأغراض صالحة للأكل، ولا تُحدث كل الأغراض الصالحة للأكل التأثير نفسه في الشخصية. بعض الأغراض، عند أكلها، تتحول إلى غرض مختلف (مثلًا، إذا أكلت تفاحة، يتبقى لديك لبّ التفاحة).

ولإتاحة كل هذه المرونة، قررت إنشاء بروتوكول `Edible` يمكن لبعض الأغراض تنفيذه.

## 1. عرّف قابلية الأكل

أنشئ بروتوكول `RPG.Edible`. يحتوي البروتوكول على دالة واحدة، وهي `eat`. تقبل دالة `eat` غرضًا وشخصية وتُرجع ناتجًا ثانويًا وشخصية.

## 2. اجعل أرغفة الخبز صالحة للأكل

طبّق بروتوكول `RPG.Edible` على غرض `RPG.LoafOfBread`. عند أكله، يمنح رغيف الخبز الشخصية 5 نقاط صحة وليس له ناتج ثانوي.

```elixir
RPG.Edible.eat(%RPG.LoafOfBread{}, %RPG.Character{health: 31})
# => {nil, %RPG.Character{health: 36, mana: 0}}
```

## 3. اجعل جرعات المانا صالحة للأكل

طبّق بروتوكول `RPG.Edible` على غرض `RPG.ManaPotion`. عند أكلها، تمنح جرعة المانا الشخصية من نقاط المانا بقدر قوة الجرعة، وتنتج زجاجة فارغة.

```elixir
RPG.Edible.eat(%RPG.ManaPotion{strength: 13}, %RPG.Character{mana: 50})
# => {%RPG.EmptyBottle{}, %RPG.Character{health: 100, mana: 63}}
```

## 4. اجعل السموم صالحة للأكل

طبّق بروتوكول `RPG.Edible` على غرض `RPG.Poison`. عند أكله، يسلب السم كل نقاط الصحة من الشخصية، وينتج زجاجة فارغة.

```elixir
RPG.Edible.eat(%RPG.Poison{}, %RPG.Character{health: 3000})
# => {%RPG.EmptyBottle{}, %RPG.Character{health: 0, mana: 0}}
```
