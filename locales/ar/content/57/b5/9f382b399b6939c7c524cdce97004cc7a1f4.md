# التعليمات

بوريس مهووس كبير بقطارات السكك الحديدية المصغّرة، وقد قرر أن يشارك شغفه مع العالم بإطلاق رسالة إخبارية. سيبدأ بإرسال العدد الأول من الرسالة الإخبارية إلى الأصدقاء والمعارف الذين يشاركونه هذه الهواية، وعناوين بريدهم الإلكتروني محفوظة في ملف نصي.

تلميح: استخدم وحدة [simplifile](https://hexdocs.pm/simplifile/simplifile.html) لعمليات الملفات.

## 1. قراءة عناوين البريد الإلكتروني من ملف

نفّذ الدالة `read_emails`. تأخذ سلسلة نصية تمثل مسار ملف نصي يحتوي على عناوين بريد إلكتروني مفصولة بأسطر جديدة، وتُرجع قائمة بعناوين البريد الإلكتروني الموجودة في الملف.

```gleam
read_emails("/home/my_user/documents/model_train_friends_emails.txt")
// -> Ok(["rick@example.com", "choochoo42@example.com", "anna@example.com"])
```

## 2. إنشاء ملف سجل للكتابة

إرسال البريد الإلكتروني مهمة قد تفشل لأسباب كثيرة غير متوقعة، مثل خطأ مطبعي في عنوان البريد الإلكتروني أو مشكلات مؤقتة في الشبكة. ولضمان قدرتك على إعادة محاولة إرسال الرسائل إلى جميع أصدقائك دون إرسال رسائل مكررة، تحتاج إلى تسجيل عناوين البريد الإلكتروني التي استلمت الرسالة بالفعل. ولهذا ستحتاج إلى ملف سجل.

نفّذ الدالة `create_log_file`. تأخذ مسار ملف وتُنشئ ملفًا فارغًا جديدًا في ذلك الموقع.

```gleam
create_log_file("/home/my_user/documents/newsletter_issue1_log.txt")
// -> Ok(Nil)
```

## 3. تسجيل رسالة بريد إلكتروني أُرسلت

نفّذ الدالة `log_sent_email`. تأخذ مسار ملف سجل وسلسلة نصية تحتوي على عنوان البريد الإلكتروني. وتكتب عنوان البريد الإلكتروني في الملف، متبوعًا بسطر جديد.

```gleam
log_sent_email(
  "/home/my_user/documents/newsletter_issue1_log.txt",
  "joe@example.com",
)
// -> Ok(Nil)
```

## 4. إرسال الرسالة الإخبارية

الآن بعد أن أصبحت لديك كل اللبنات الأساسية لعملية إرسال البريد الإلكتروني، عليك دمجها معًا في دالة واحدة.

نفّذ الدالة `send_newsletter`. تأخذ مسار الملف الذي يحتوي على عناوين البريد الإلكتروني، ومسار ملف السجل، ودالة مجهولة ترسل بريدًا إلكترونيًا إلى عنوان بريد إلكتروني مُعطى.

ينبغي أن تقرأ جميع عناوين البريد الإلكتروني من الملف المُعطى وتحاول إرسال بريد إلكتروني إلى كل واحد منها. وإذا أرجعت الدالة المجهولة التي ترسل البريد الإلكتروني قيمة `Ok`، فاكتب عنوان البريد الإلكتروني في ملف السجل. واحرص على فعل ذلك بمجرد إرسال البريد الإلكتروني.

```gleam
send_newsletter(
  "model_train_friends_emails.txt",
  "newsletter_issue1_log.txt",
  send_email,
)
// -> Ok(Nil)
```
