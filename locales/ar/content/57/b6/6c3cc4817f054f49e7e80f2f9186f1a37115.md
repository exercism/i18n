# التعليمات

إيليز، الساحرة الناشئة، تواصل تدريبها.
لديها مجموعة من البطاقات تريد التلاعب بها.

لتبسيط الأمور، تبدأ عادةً بالبطاقات المرقّمة من 2 إلى 10 فقط، على الرغم من أن بعض الحِيَل قد تتضمن بطاقات إضافية (بطاقات الوجه).

<!-- prettier-ignore-start -->
~~~~exercism/note
هناك **أساليب عديدة** لخلط البطاقات، ولكن للحفاظ على وهم السحر، من الضروري ألّا *يُستخدم أسلوب واحد بعينه*، فمثلًا لا تستخدم إيليز `splice` أو `slice` أو `shift` أو `unshift` أو `push` أو `at`.
كما لا يُستخدم أبدًا مُوصِل المصفوفة `array[index]` ولا مُوصِل الكائن (`object[key]` و`object.key`).
~~~~
<!-- prettier-ignore-end -->

هل تريد مساعدة إيليز على الارتقاء بسحرها؟

<!-- prettier-ignore-start -->
~~~~exercism/advanced
يمكن تنفيذ كل دالة باستخدام المعاملات وجسم دالة يحوي `return expression` واحدًا.
~~~~

## 1. احصل على البطاقة الأولى

ستستدعي إيليز البطاقة الأولى في المجموعة دون استخدام `array[index]` أو `.at(index)` أو `.shift()`.
إنه يشبه السحر تمامًا.

```javascript
const deck = [5, 9, 7, 1, 8];

getFirstCard(deck);
// => 5
```

## 2. احصل على البطاقة الثانية

تقوم إيليز بخفة يد فتستدعي البطاقة الثانية في المجموعة دون استخدام `array[index]` أو `.shift()`.

```javascript
const deck = [3, 2, 10, 6, 7];

getSecondCard(deck);
// => 2
```

## 3. بدّل بطاقتين

ستجعل إيليز البطاقتين في المجموعة تتبادلان مكانيهما.
إنها لا تحتاج إلى استدعاء أي دالة.

```javascript
const deck = [10, 7];

swapTwoCards(deck);
// => [7, 10]
```

## 4. أزِح ثلاث بطاقات

لأداء مزيد من خفة اليد، تأخذ إيليز ثلاث بطاقات وتنقل البطاقة العليا بسرعة إلى الخلف، فتصبح البطاقة الوسطى هي الأولى، والبطاقة السفلية القديمة هي الوسطى.
إنها لا تحتاج إلى استدعاء أي دالة.

```javascript
const deck = [2, 6, 10];

shiftThreeCardsAround(deck);
// => [6, 10, 2]
```

## 5. اختر الرزمة المسمّاة

ستفصل إيليز المجموعة إلى رزمتين.
ثم تطلب من المراقب أن يختار إحدى الرزمتين، وسنسمّيها `chosen`.
لم تعد رزمة `disregarded` ذات صلة، فتجعلها تختفي.
إنها لا تحتاج إلى استدعاء أي دالة.

```javascript
const deck = [5, 4, 7, 10];
const chosen = [5, 4];
const disregarded = [7, 10];

pickNamedPile({ chosen, disregarded });
// => [5, 4]
```

## 5. بدّل الرزمة المختارة

للأسف، يظل المراقب يختار الرزمة "الخاطئة"، لكن بسحر سريع بارع، تعيد إيليز تسمية رزمة `chosen` لتصبح `disregarded`، ورزمة `disregarded` لتصبح رزمة `chosen`.
إنها لا تحتاج إلى استدعاء أي دالة.

```javascript
const deck = [5, 4, 7, 10];
const chosen = [5, 4];
const disregarded = [7, 10];

swapNamedPile({ chosen, disregarded });
// => { chosen: [7, 10], disregarded: [5, 4] }
```
