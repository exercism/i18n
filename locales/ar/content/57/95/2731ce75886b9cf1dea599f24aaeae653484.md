# ملحق التعليمات

## السجلات

| السجل | الاستخدام | النوع | الوصف |
| -------- | --------- | ------- | --------------------------- |
| `$a0`    | إدخال     | عنوان | مصفوفة كلمات الكتب           |
| `$a1`    | إدخال     | عدد صحيح | عدد الكتب                    |
| `$v0`    | إخراج     | عدد صحيح | السعر، بالسنتات             |
| `$t0-9`  | مؤقت      | أي | يُستخدم للتخزين المؤقت        |
