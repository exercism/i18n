# التعليمات

لامونت كائن فضائي من عالم Lisp يريد كتابة لعبة فيديو خاصة به. ومن المهام التي طلب مساعدتك فيها تتبّع قائمة النتائج الأعلى.

## 1. إنشاء جدول النتائج الأعلى

عرّف دالة `make-high-score-table` لا تأخذ أي وسائط وتُقيّم إلى جدول تجزئة فارغ جديد:

```lisp
(make-high-score-table) ; => #<HASH-TABLE :TEST EQL :COUNT 0 {1005A90103}>
```

## 2. إضافة لاعب إلى الجدول

لإضافة لاعب إلى الجدول، عرّف دالة `add-player` تأخذ وسيطين:
- جدول النتائج الأعلى
- اسم اللاعب ككلمة مفتاحية

اضبط النتيجة الأولية للاعب على صفر.

```lisp
(add-player hash-table :louis) ; => 0
(add-player hash-table :lilly) ; => 0
```

## 3. ضبط نتيجة لاعب

لضبط نتيجة لاعب، عرّف دالة `set-score` تأخذ ثلاثة وسائط:
- جدول النتائج الأعلى
- اسم اللاعب ككلمة مفتاحية
- نتيجة اللاعب كعدد صحيح

```lisp
(set-score hash-table :louis 1234) ; => 1234
```

## 4. الحصول على نتيجة من الجدول

للحصول على نتيجة لاعب من الجدول، عرّف دالة `get-score` تأخذ وسيطين:
- جدول النتائج الأعلى
- اسم اللاعب ككلمة مفتاحية

ينبغي أن تُقيّم هذه الدالة إلى النتيجة المخزّنة للاعب.
وإذا لم تكن هناك نتيجة مخزّنة لذلك اللاعب، أو لم يكن ذلك اللاعب موجودًا في الجدول بعد، فقيّمها إلى `0`.

```lisp
(get-score hash-table :louis)                         ; => 1234
(get-score hash-table :lilly)                         ; => 0
(get-score hash-table :not-a-character-in-this-story) ; => 0
```

## 5. إزالة لاعب من الجدول

لإزالة لاعب من جدول النتائج الأعلى، عرّف دالة `remove-player` تأخذ وسيطين:
- جدول النتائج الأعلى
- اسم اللاعب ككلمة مفتاحية

ينبغي أن تتعامل هذه الدالة بلطف مع الحالات التي لم يكن فيها اللاعب قد أُضيف إلى الجدول بعد.
ومن الواضح أنه بعد إزالة لاعب، إذا طُلبت نتيجته من الجدول فستكون صفرًا.

```lisp
(set-score hash-table :louis 1234)           ; => 1234
(remove-player hash-table :louis)            ; => T
(get-score hash-table :louis)                ; => 0

(remove-player hash-table :not-in-the-table) ; => NIL
```
