# مقدمة

## التاريخ والوقت

تحتوي حزمة `java.time` التي أُدخلت في Java 8 على عدة أصناف للتعامل مع التواريخ والوقت.

### `LocalDate`

يمثّل الصنف `java.time.LocalDate` تاريخًا بدون منطقة زمنية في [نظام التقويم ISO-8601][iso-8601]، مثل `2007-12-03`:

```java
LocalDate date = LocalDate.of(2007, 12, 3);
```

يمكن مقارنة التواريخ بتواريخ أخرى:

```java
LocalDate date1 = LocalDate.of(2007, 12, 3);
LocalDate date2 = LocalDate.of(2007, 12, 4);

date1.isBefore(date2);
// => true

date1.isAfter(date2);
// => false
```

تمتلك نسخة `LocalDate` دوال وصول لاسترجاع أجزاء الوقت منها:

```java
LocalDate date = LocalDate.of(2007, 12, 3);

date.getDayOfMonth();
// => 3
```

تمتلك نسخة `LocalDate` طُرقًا لإضافة وحدات زمنية إليها:

```exercism/note
تُرجع هذه الطرق نسخة _جديدة_ من `LocalDate` ولا تُحدّث النسخة الموجودة، لأن الصنف `LocalDate` غير قابل للتغيير.
```

```java
LocalDate date = LocalDate.of(2007, 12, 3);

date.plusDays(3);
// => 2007-12-06
```

### `LocalDateTime`

يمثّل الصنف `java.time.LocalDateTime` تاريخًا ووقتًا بدون منطقة زمنية في [نظام التقويم ISO-8601][iso-8601]، مثل `2007-12-03T10:15:30`:

```java
LocalDateTime datetime = LocalDateTime.of(2007, 12, 3, 10, 15, 30);
```

يمكنك تحويل نسخة `LocalDate` إلى `LocalDateTime`:

```java
LocalDate date = LocalDate.of(2007, 12, 3);
LocalDateTime datetime = date.atTime(10, 15, 30);
datetime.toString();
// => "2007-12-03T10:15:30"
```

### تنسيق التواريخ والأوقات

يستخدم كل من `LocalDate` و`LocalDateTime` الترميز القياسي [ISO-8601][iso-8601] عند التحويل من `String` وإليه.

```java
LocalDateTime datetime = LocalDateTime.of(2007, 12, 3, 10, 15, 30);
LocalDateTime parsed = LocalDateTime.parse("2007-12-03T10:15:30");

datetime.isEqual(parsed);
// => true
```

لا يمكن محاولة تحليل `LocalDate` أو `LocalDateTime` من `String` بهذه الطريقة باستخدام تنسيق مختلف.
بدلًا من ذلك، لتنسيق التواريخ باستخدام تنسيق مخصّص، ينبغي عليك استخدام `java.time.format.DateTimeFormatter`:

```java
DateTimeFormatter parser = DateTimeFormatter.ofPattern("dd/MM/yyyy");
LocalDate date = LocalDate.parse("03/12/2007", parser);

DateTimeFormatter printer = DateTimeFormatter.ofPattern("MMMM d, yyyy");
printer.format(date);
// => "December 3, 2007"
```

يمكنك أيضًا تحديد الإعدادات المحلية عند إنشاء التنسيق المخصّص للتنسيق والتحليل لمناطق مختلفة:

```java
DateTimeFormatter.ofPattern("MMMM d, yyyy", Locale.FRENCH).format(date);
// => décembre 3, 2007

DateTimeFormatter.ofPattern("MMMM d, yyyy", Locale.of("pt")).format(date);
// => dezembro 3, 2007
```

[iso-8601]: https://en.wikipedia.org/wiki/ISO_8601
