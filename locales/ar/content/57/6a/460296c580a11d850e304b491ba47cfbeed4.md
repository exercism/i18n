# التعليمات

في هذا التمرين، ستعمل مع حسابات التوفير.
في كل سنة، يُحدَّث رصيد حساب التوفير الخاص بك بناءً على سعر الفائدة.
ويعتمد سعر الفائدة الذي يمنحك إياه البنك على مقدار المال الموجود في حسابك (أي رصيده):

- 3.213% لرصيد أقل من `0` دولار (يصبح الرصيد أكثر سلبية).
- 0.5% لرصيد أكبر من أو يساوي `0` دولار، وأقل من `1000` دولار.
- 1.621% لرصيد أكبر من أو يساوي `1000` دولار، وأقل من `5000` دولار.
- 2.475% لرصيد أكبر من أو يساوي `5000` دولار.

لديك أربع مهام، وكل مهمة تتعامل مع الرصيد وسعر الفائدة الخاص به.

## 1. احسب سعر الفائدة

نفّذ الدالة `interest_rate` لحساب سعر الفائدة بناءً على الرصيد المحدد:

```cpp
interest_rate(200.75);
// => 0.5
```

## 2. احسب الفائدة

نفّذ الدالة `yearly_interest` لحساب الفائدة بناءً على الرصيد المحدد:

```cpp
yearly_interest(200.75):
// => 1.003750
```

## 3. احسب التحديث السنوي للرصيد

نفّذ الدالة `annual_balance_update` لحساب التحديث السنوي للرصيد، مع مراعاة سعر الفائدة:

```cpp
annual_balance_update(200.75);
// => 201.75375
```

## 4. احسب عدد السنوات اللازمة للوصول إلى الرصيد المطلوب

نفّذ الدالة `years_until_desired_balance` لحساب الحد الأدنى لعدد السنوات اللازمة للوصول إلى الرصيد المطلوب، مع مراعاة أن الفائدة تُضاف إلى الرصيد كل سنة.
هذا يعني أن الرصيد بعد سنة واحدة يساوي: رصيد البداية + فائدة رصيد البداية.
والرصيد بعد السنة الثانية يساوي الرصيد بعد سنة واحدة + فائدة الرصيد بعد سنة واحدة.
وهكذا، حتى يصبح رصيد السنة الحالية أكبر من أو يساوي الرصيد المستهدف.

```cpp
double balance {200.75};
double targetBalance {214.88};
years_until_desired_balance(balance, targetBalance)
// => 14
```

لاحظ أن القيمة التي تُرجعها الدالة من النوع `int`.
