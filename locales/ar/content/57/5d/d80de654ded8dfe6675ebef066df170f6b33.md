# مقدمة

في Rust، يمكن التعامل مع أي نوع ينفّذ السمة [`Iterator`](https://doc.rust-lang.org/stable/std/iter/trait.Iterator.html) على أنه مكرِّر.
يمكن تحويل [`collections`](https://doc.rust-lang.org/std/collections/index.html) المدمجة في Rust إلى مكرِّرات عبر الطرق `iter` و`iter_mut` و`into_iter`.
وتتمتع المكرِّرات بمجموعة واسعة من [الطرق القوية](https://doc.rust-lang.org/stable/std/iter/trait.Iterator.html#provided-methods)، مثل `collect` و`map` و`filter` و`fold`، لتنفيذ عمليات على بياناتك.

```rust
use std::collections::HashMap;

let v = vec![0, 1, 2];

let mut iter = v.iter();

// Call next() to return the next value
assert_eq!(Some(&0), iter.next());
assert_eq!(Some(&1), iter.next());
assert_eq!(Some(&2), iter.next());
// Ahen None once it's over
assert_eq!(None, iter.next());

// Loop over iterators with built-in methods, such as `map` and `collect`
let w: HashMap<_, _> = v.into_iter().map(|x| (x, x + 1)).collect();
println!("{w:?}");
// => {1: 2, 0: 1, 2: 3}
```
