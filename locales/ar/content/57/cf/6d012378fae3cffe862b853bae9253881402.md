# تثبيت Java

بالإضافة إلى واجهة سطر الأوامر الخاصة بـ Exercism ومحرّر النصوص المفضّل لديك، يتطلب التدريب على تمارين Java في Exercism وجود **حزمة تطوير Java** ‏(JDK). وتتضمن حزمة JDK كلاً من بيئة تشغيل Java _و_ أدوات التطوير، وأبرزها مترجم Java.

توجد اليوم توزيعات عديدة لحزمة JDK، وبعضها مفتوح المصدر. ونحن في Exercism نوصي باستخدام [Eclipse Temurin by Adoptium][adoptium].

## إصدارات Java المدعومة

يدعم مسار Java في Exercism إصدار Java 25 LTS وما قبله.

## تثبيت Eclipse Temurin

لتثبيت Eclipse Temurin على نظامك، توجّه إلى [تعليمات التثبيت][adoptium-installation-guide] الممتازة التي يقدمونها. ستجد هناك إرشادات حول كيفية تثبيت حزمة JDK باستخدام مدير الحزم المفضّل لديك، كما تحتوي الصفحة على روابط لمثبّتات قابلة للتنزيل لجميع أنظمة التشغيل الرئيسية.

## بيئات تطوير Java المتكاملة

تتوفر العديد من بيئات التطوير المتكاملة المجانية لـ Java. إليك بعض الخيارات الشائعة:

- [IntelliJ IDEA Community Edition][intellij-idea]
- [Eclipse][eclipse]
- [Visual Studio Code مع إضافة Java][vscode-java]
