# حول

مثل اللغات الأخرى، توفّر C++ أيضًا جملة `switch`.
جمل `switch` أسلوب أقصر لكتابة جمل `if ... else if` الطويلة.
لإنشاء جملة `switch`، نبدأ باستخدام الكلمة المفتاحية `switch` متبوعةً بعدد صحيح.
ثم نُعرّف كل شرط من الشروط باستخدام الكلمة المفتاحية `case`.
يمكننا أيضًا تعريف حالة `default`، تُنفَّذ عندما لا يتحقق أيٌّ من شروط `case` السابقة.
يجب أن تنتهي كل حالة بعبارة `break` (أو `return`).

```cpp
int price{0};
int adults{3};
int kids{2};

switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
        break;
    case 2:
        price = 70;
        break;
    default:
        price = group_size * 30;
}
```

## السقوط إلى الحالة التالية

من الأمور المهمة في بنية `switch` أن الكود يستمر في التنفيذ حتى توقفه عبارة `break` (أو `return`).
قد يؤدي هذا إلى سلوك غير متوقع.

```cpp
int adults{1};
int kids{0};
switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
    case 2:
        price = 70;
    default:
        price = group_size * 30;
}
// price will be 30!
```

أهم حالة استخدام لميزة التنفيذ المستمر هذه هي عبارة تحمل عدة تسميات.
يمكن لعدة نتائج من `switch` أن تقابل نفس جزء الكود الذي سيُنفَّذ.
وبهذه الطريقة (في تطبيق حجوزات على سبيل المثال) يمكن أن تكون الدالة المستدعاة لحجمي المجموعة 2 و3 هي نفسها:
```cpp
switch (group_size) {
case 1:
    book_room();
    break;
case 2:
case 3:
    book_apartment(group_size);
    break;
default:
    book_house(group_size);
}
// book_apartment happens wheng roup_size is 2 or 3
```

~~~~exercism/note
كما رأيت، فإن جملة `switch` في C++ محدودة جدًا مقارنةً بلغات أخرى.
تدعم لغات كثيرة جمل `switch` المبنية على تعبير منطقي أو حتى تعبيرات نمطية.
يمكنك أن تعتبر نسخة C++ بنية `goto`/`switch` موسّعة.
جملة `switch` وحدها هي التي يمكنها الانتقال إلى تسمية.
بعد ذلك تُتجاهل جميع التسميات الأخرى، وعليك استخدام عبارة `break` للخروج من كتلة الكود.
