# الاختبارات

لتشغيل الاختبارات، نفّذ الأمر التالي:

```bash
make
```

## الاختبارات المتخطّاة

حلّ التمرين يعني جعل جميع اختباراته تنجح.
افتراضيًا، لا يُنفَّذ سوى اختبار واحد (الأول) عند تشغيل الاختبارات.
هذا مقصود، لأنه يتيح لك التركيز على جعل ذلك الاختبار الواحد ينجح فقط.
وبمجرد أن ينجح، يمكنك تفعيل الاختبار التالي بحذف سطر `TEST_IGNORE()`.
عندما تُفعَّل جميع الاختبارات ويجعلها تطبيقك تنجح كلها، تكون قد حللت التمرين!

## تصحيح الأخطاء

لمساعدتك في تصحيح الأخطاء، هناك وحدات ماكرو متنوعة معرّفة في ملف `debug.mac`.
يمكن استدعاؤها بوسيط واحد أو أكثر بالحجم المناسب.
على سبيل المثال:

```x86asm
debugf32 xmm0, xmm1 ; prints the value of two 32-bit floating-point numbers
debugd16 ax, cx, dx ; prints the value of three signed 16-bit integers
debugx64 [rax]      ; prints the value of a 64-bit integer in hexadecimal format
debugs rsi          ; prints a NUL-terminated string whose address is stored in `rsi`
debugu8_xmm xmm1    ; prints 16 packed 8-bit unsigned integers
```

لاستخدام أيٍّ من وحدات الماكرو هذه، يجب تضمين `debug.mac` في أعلى ملف الحل:

```x86asm
%include "debug.mac"
```
