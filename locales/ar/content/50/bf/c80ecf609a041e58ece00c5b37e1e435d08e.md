# حول

المتغيرات التي تُعرَّف باستخدام الكلمة المفتاحية `final` بدلاً من `var` لا يمكن إسناد قيمة لها إلا مرة واحدة.

```haxe
final a = "hello";
var b = "world";
trace(a, b); // hello, world
b = "haxe";
trace(a, b); // hello, haxe

// The following line would cause a compilation error:
// a = "bye";
```

من المهم ملاحظة أن `final` قد لا يكون له التأثير المقصود مع الأنواع غير القابلة للتغيير، مثل المصفوفات أو الكائنات:

```haxe
final a = [0, 1, 2];
trace(a); // [0,1,2]

// this would cause a compilation error:
// a = [0, 1, 2, 3];

// but the following line works:
a.push(3);
trace(a); // [0,1,2,3]
```
