# نبذة

Java لغة ذات أنواع ثابتة، وهذا يعني أن لكل شيء نوعًا في وقت الترجمة.
ويُسمى إسناد قيمة إلى اسم تعريفَ متغير.

```java
int explicitVar = 10; // Explicitly typed
```

يمكن إسناد قيمة المتغير وتحديثها باستخدام [عامل `=`][assignment].
وبمجرد تعريف المتغير، لا يمكن أن يتغير نوعه أبدًا.

```java
int count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

Java لغة كائنية التوجه، وهي تتطلب تعريف كل الدوال داخل _صنف_، وتُعرَّف الأصناف باستخدام [الكلمة المفتاحية `class`][classes].
وتُسمى الدالة داخل الصنف _طريقة_.
ويمكن لكل [طريقة][methods] أن تمتلك صفرًا أو أكثر من المعاملات.
ويجب تحديد نوع كل المعاملات صراحةً، فلا يوجد استنتاج للأنواع بالنسبة إلى المعاملات.
وبالمثل، يجب تحديد نوع الإرجاع صراحةً أيضًا.
وتُرجِع الدوال قيمها باستخدام [الكلمة المفتاحية `return`][return].
وللسماح لبقية الأصناف باستدعاء الطريقة، يجب إضافة معدِّل الوصول `public`.

```java
class Calculator {
    public int add(int x, int y) {
        return x + y;
    }
}
```

ويتم استدعاء الطريقة بتحديد صنفها واسم الطريقة وتمرير وسائط لكل معامل من معاملاتها.

```java
int sum = new Calculator().add(1, 2);
```

إذا لم تستخدم الطريقة أي _حالة_ للصنف (وهو الحال في هذا التمرين)، فيمكن جعل الطريقة `static` باستخدام المعدِّل `static`.
وبالمثل، إذا كان الصنف يحتوي على دوال `static` فقط، فيمكن جعله `static` هو الآخر باستخدام المعدِّل `static`.

```java
static class Calculator {
    public static int multiply(int x, int y) {
        return x * y;
    }
}
```

يُحدَّد النطاق في Java بين المحرفين `{` و `}`.

تدعم Java نوعين من [التعليقات][comments].
يُسبق التعليق أحادي السطر بـ `//`، أما التعليقات متعددة الأسطر فتُوضع بين `/*` و `*/`.

تُعرَّف قيم الأعداد الصحيحة على أنها رقم واحد أو أكثر (متتالية)، وهي تدعم [العوامل الرياضية الافتراضية][operators].
