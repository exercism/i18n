# حول

المتغيرات المحلية لا تحل محل الكود المعتمد على المكدس، بل تتعايش معه. الجأ إليها عندما:

- تتم الإشارة إلى المدخل نفسه أكثر من مرة.
- لا يتطابق الترتيب الطبيعي للعمليات مع ترتيب المكدس.
- أنت داخل كلمة من رتبة أعلى تمنح اللامبدا عدة قيم دفعة واحدة (`assoc-map`، أي `( key value -- newkey newvalue )`).

```factor
USING: locals ;

! Two references to ratio: stack-shuffled vs. local.
: average  ( a b -- avg ) + 2 / ;
:: average ( a b -- avg ) a b + 2 / ;        ! same effect
```

`[let code :> name code :> name ... body ]` يقدّم ارتباطات محلية داخل اقتباس أو عند المستمع، حيث لا يكون لـ `:>` نطاق معجمي يربط فيه لولا ذلك:

```factor
[let 5 :> x 10 :> y x y + ] .   ! => 15
```

تتيح لك لاحقة التغيير `:>` إعادة ربط متغير محلي، وهي مفيدة في الحلقات ذات الطابع الأمريّ:

```factor
:: collatz ( n -- count )
    n :> current!
    0 :> count!
    [ current 1 = ] [
        current odd?
        [ current 3 * 1 + current! ]
        [ current 2 / current! ] if
        count 1 + count!
    ] until
    count ;
```
