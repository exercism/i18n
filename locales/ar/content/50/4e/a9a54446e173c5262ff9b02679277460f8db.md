# التعليمات

في هذا التمرين تلعب لعبة تقمّص أدوار تُسمّى "Wizard and Warriors" مع أعزّ أصدقائك. أنت سيّد اللعبة، الشخص المكلّف بجعل عالم اللعبة نابضًا بالحياة للاعبين. ومن الجوانب الأساسية في ذلك وصف اللعبة للاعبين: ما حالة الشخصية، وكيف تبدو البلدة التي يزورونها، وما إلى ذلك.

لديك خمس مهام تطلب منك وصف أجزاء من اللعبة للاعبين.

## 1. صِف شخصية

لكل شخصية صنف ومستوى وعدد من نقاط الصحة، وتوصف كما يلي: `"You're a level <LEVEL> <CLASS> with <HIT_POINTS> hit points."`. نفّذ الطريقة (الثابتة) `GameMaster.Describe` التي تأخذ `Character` كمعاملها الوحيد وتُرجع وصفه.

```csharp
var character = new Character();
character.Class = "Wizard";
character.Level = 4;
character.HitPoints = 28;

GameMaster.Describe(character);
// => "You're a level 4 Wizard with 28 hit points."
```

## 2. صِف وجهة

لكل وجهة اسم وعدد من السكان، وتوصف كما يلي: `"You've arrived at <NAME>, which has <INHABITANTS> inhabitants."`. نفّذ الطريقة (الثابتة) `GameMaster.Describe` التي تأخذ `Destination` كمعاملها الوحيد وتُرجع وصفها.

```csharp
var destination = new Destination();
destination.Name = "Muros";
destination.Inhabitants = 732;

GameMaster.Describe(destination);
// => "You've arrived at Muros, which has 732 inhabitants."
```

## 3. صِف أسلوب السفر

يمكن للشخصيات السفر إلى وجهة بأحد الخيارين:

- سيرًا على الأقدام، ويوصف ذلك كما يلي: `"You're traveling to your destination by walking."`
- على ظهر حصان، ويوصف ذلك كما يلي: `"You're traveling to your destination on horseback."`

نفّذ الطريقة (الثابتة) `GameMaster.Describe` التي تأخذ `TravelMethod` كمعاملها الوحيد وتُرجع وصفه.

```csharp
GameMaster.Describe(TravelMethod.Horseback);
// => "You're traveling to your destination on horseback."
```

## 4. صِف شخصية تسافر إلى وجهة

عندما تسافر شخصية إلى وجهة، يوصف ذلك بمزيج من الأوصاف الفردية: `"<CHARACTER> <TRAVEL_METHOD> <DESTINATION>"`. نفّذ الطريقة (الثابتة) `GameMaster.Describe` التي تأخذ `Character` و`Destination` و`TravelMethod` كمعاملاتها وتُرجع وصفها.

```csharp
var character = new Character();
character.Class = "Wizard";
character.Level = 4;
character.HitPoints = 28;

var destination = new Destination();
destination.Name = "Muros";
destination.Inhabitants = 732;

GameMaster.Describe(character, destination, TravelMethod.Horseback);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination on horseback. You've arrived at Muros, which has 732 inhabitants."
```

## 5. صِف شخصية تسافر إلى وجهة دون تحديد أسلوب السفر

في أغلب الحالات، تسافر الشخصيات إلى وجهاتها سيرًا على الأقدام. وللتسهيل على اللاعبين، يُسمح لهم بعدم ذكر أسلوب سفرهم، وفي هذه الحالة يُفترض أن السفر سيرًا على الأقدام. نفّذ الطريقة (الثابتة) `GameMaster.Describe` التي تأخذ `Character` و`Destination` كمعاملاتها وتُرجع وصفها.

```csharp
var character = new Character();
character.Class = "Wizard";
character.Level = 4;
character.HitPoints = 28;

var destination = new Destination();
destination.Name = "Muros";
destination.Inhabitants = 732;

GameMaster.Describe(character, destination);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination by walking. You've arrived at Muros, which has 732 inhabitants."
```
