# نبذة

تُستخدم التعابير الشرطية لتنفيذ الكود بناءً على **ما إذا** كان الشرط **صحيحًا** أو **خطأ**. وتُكتب هذه التعابير بالشكل التالي:

```haxe
if (condition) {
  expressions
};
```

تكون نتيجة الشرط من النوع `Bool`، لذا عندما تكون النتيجة `true` تُنفَّذ التعابير.

أحيانًا، عندما يكون الشرط `false` في الواقع، نريد تنفيذ جزء آخر من الكود. وهنا يأتي دور تعبير `else`. ينفّذ `else` التعابير عندما يكون الشرط الأولي `false`. لكن ماذا لو أردنا فحص الشرط لعدة احتمالات؟ حينها نستخدم `else if (condition)`. إليك مثالًا كاملًا:

```haxe
var a = 10;

if (a == 2) {
  trace("a is 2");
} else if (a == 5) {
  trace("a is 5");
} else {
  trace("a is 10");
}

// a is 10
```
