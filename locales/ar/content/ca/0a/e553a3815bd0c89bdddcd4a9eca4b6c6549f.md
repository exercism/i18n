# مقدمة

يمكن لدوال Go وطرقها أن تُرجع قيمًا متعددة:

```go
func GetCard() (Card, error) { ... }
```

يجب إسناد كل قيمة مُرجعة بالترتيب، مع الفصل بينها بفواصل:

```go
card, err := GetCard()
```

كل موضع في الإسناد يعرّف متغيرًا.
ولن يُصرّف Go الكود إذا لم يُستخدم أي متغير معلن.
ويأخذ المعرّف الفارغ `_` مكان اسم المتغير لتخطّي قيمة الإرجاع تلك:

```go
card, _ := GetCard()
```

`error` واجهة مدمجة.
خطأ قيمته `nil` يعني أنه لم يقع أي خطأ، وأي قيمة غير `nil` تعني أن هناك خطأ ما.
وبحسب العُرف، ينبغي أن تُرجع الدوال القابلة للفشل قيمة `error` باعتبارها قيمتها الأخيرة.
وعلى المستدعي التحقق منها قبل استخدام أي قيم إرجاع أخرى:

```go
card, err := GetCard()
if err != nil {
    return err // do not use card here
}
// safe to use card here
```
