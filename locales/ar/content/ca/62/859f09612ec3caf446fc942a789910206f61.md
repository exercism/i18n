# تشغيل الاختبارات

يمكن تشغيل SWI Prolog إما تفاعليًا أو بتنفيذه مباشرةً من سطر الأوامر.

## سطر الأوامر

يمكن استخدام الأمر التالي لتشغيل الاختبارات من سطر الأوامر:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)'
```

استبدل `<exercise>` باسم التمرين الذي تنفذه.

## التشغيل التفاعلي

لتشغيل Prolog تفاعليًا، شغّل أولًا:

```bash
swipl
```

بعد بدء وحدة تحكم Prolog، حمّل تنفيذك وشغّل الاختبارات باستخدام:

```
?- ["<exercise>.pl"].
?- ["<exercise>_tests.plt"].
?- run_tests.
```

استبدل `<exercise>` باسم التمرين الذي تنفذه.

### إعادة تحميل التغييرات

بعد تحميل الملفات أعلاه، يمكنك تطبيق أي تغييرات أجريتها بتشغيل:

```
?- make.
```

## الاختبارات المتخطّاة

عندما تبدأ تمرينًا لأول مرة، سيعمل الاختبار الأول فقط. وقد تم تخطي الباقي بإضافة `condition(pending)` إلى هدف `test`.
بعد نجاح الاختبار الأول، أزل تخطي الاختبار التالي بتغيير `pending` في `condition(pending)` إلى `true`.
كرّر ذلك مع كل اختبار حتى تعمل جميعها وتنجح.

### سطر الأوامر

أضف الوسيط `-- --all` إلى نهاية الأمر لتشغيل أي اختبارات معلّقة أيضًا:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)' -- --all
```
