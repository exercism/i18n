# مقدمة

## المصفوفات والمتجهات

توفّر C++ حاويات مختلفة لتخزين عناصر من النوع نفسه بترتيب محدّد. هناك `std::array` للحاويات ذات الحجم الثابت، و`std::vector` الذي يأتي بقدرة على تغيير الحجم ديناميكيًا.

### الإنشاء

عندما تُعلن عن مصفوفة أو متجه، عليك تحديد نوع العناصر التي ستحتوي عليها الحاوية. كما تحتاج المصفوفات إلى تحديد حجم. لنلقِ نظرة على هذه الأمثلة لرؤية كيفية تهيئة هذين النوعين من الحاويات:

```cpp
#include <array>
#include <string>

// std::array<element_type, size> variable_name {list of elements}
std::array<std::string, 3> indie_rock {"yeah", "yeah", "yeah"};
// indie_rock contains the elements "yeah" three times
```

تحتاج المتجهات عادةً إلى مساحة أكبر، لأنها تخصّص ذاكرة لنموّها لاحقًا. ولا تحتاج إلى تحديد حجم:

```cpp
#include <vector>

// std::vector<element_type> variable_name {list of elements}
std::vector<int> countdown {3, 2, 1};
// countdown contains the elements 3, 2 and 1
```

> ملاحظة: لا تحتاج إلى معرفة الآلية الدقيقة وراء مفهوم القوالب بعد، فسيكون له مفهومه الخاص في موضع أبعد في شجرة المنهج.

### الوصول إلى العناصر

تشترك المتجهات والمصفوفات في الدوال نفسها للوصول إلى عناصرها. يمكنك استخدام الدالتين العضويتين `front` و`back` للحصول على العنصرين الأول والأخير من الحاوية. وهناك أيضًا `at` والعامل `[]` للوصول إلى عناصر محدّدة.

```cpp
countdown[0];
// => 3
countdown.at(2);
// => 1
countdown[1] = 4;
// countdown now contains 3, 4 and 1
indie_rock.back() = "yeahs";
// indie_rock is now "yeah", "yeah", "yeahs"
```

> ملاحظة: إذا اخترت موضعًا خارج مدى الحاوية، فقد يؤدي العامل `[]` إلى سلوك غير محدّد.
> أما دالة `at` فسترفع استثناءً، وهو ما قد يسهّل حياتك على المدى الطويل.

### معدّلات المتجه

بما أن حجم `vector` ليس ثابتًا، فمن الممكن إضافة عناصر أو حذفها. ومن الدوال الشائعة لهذا الغرض `emplace_back` و`pop_back`.

```cpp
std::vector<std::string> witches {"Holly", "Alyssa", "Shannen"};
witches.pop_back();
// Shannen is no longer with the witches
witches.emplace_back("Rose");
// Rose has joined the team
```

### السعة

يمكنك التحقق من كون الحاوية فارغة عبر الدالة العضو `empty`. وإذا أردت معرفة عدد العناصر، يمكنك استخدام `size`.
