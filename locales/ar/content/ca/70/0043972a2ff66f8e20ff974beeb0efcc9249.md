# ملحق التعليمات

## التعامل مع التواريخ في Prolog

الدعم المدمج للتواريخ في Prolog [بدائي إلى حد كبير][built-in-dates-support]. ويمكنك حل هذا التمرين بما هو مدمج في Prolog وحده، لكن ثمة طريقة أجمل بكثير للتعامل مع التواريخ، وهي استخدام [حزمة date_time][date-time-package].

### تثبيت حزمة date_time

إذا كانت نسخة Swipl المثبَّتة لديك حديثة بما يكفي، يمكنك تثبيت الحزمة بتشغيل:

```bash
swipl pack install date_time
```

وإن لم ينجح ذلك، يمكنك تشغيل:

```shell
swipl -g 'pack_install(date_time)'
```

~~~~exercism/note
إذا كنت تستخدم المحرر على الإنترنت، فلست بحاجة إلى تثبيت أي شيء يدويًا.
~~~~

### استخدام حزمة date_time

أضف الكود التالي إلى أعلى ملف الحل لاستخدام حزمة `date_time`:

```prolog
:- use_module(library(date_time)).
```
