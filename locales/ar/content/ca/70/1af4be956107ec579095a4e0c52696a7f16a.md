# التعليمات

بصفتك تعمل في مدينة ملاهٍ، أُعطيت مواصفات لتصميم نظام لإدارة الحضور والألعاب. طُلب منك تصميم نموذج للـ `Attendee` (الشخص الذي يزور المدينة).

## 1. أنشئ كائنات `Attendee` جديدة

نفّذ الطريقة `Attendee#initialize` في الصنف `Attendee`، ويجب أن تأخذ الطول (بالسنتيمتر) وتخزّنه في متغير نسخة.

```ruby
Attendee.new(106)
# => #<Attendee:0x000055c33e6c7e18 @height=106>
```

## 2. كم يبلغ طول الحاضر؟

نفّذ الدالة الجالبة `Attendee#height` في الصنف `Attendee`، ويجب أن تُرجع طول النسخة.

```ruby
Attendee.new(106).height
# => 106
```

## 3. ما هو معرّف تذكرة الألعاب؟

لم يشترِ جميع الحاضرين تذكرة ألعاب، لكننا نحتاج إلى معرفة ما إذا كانت لديهم تذكرة أم لا. نفّذ الدالة الجالبة `Attendee#pass_id` في الصنف `Attendee`، ويجب أن تُرجع قيمة `pass_id` الخاصة بالنسخة، أو `nil` إذا لم تكن لدى الحاضر تذكرة.

```ruby
Attendee.new(106).pass_id
# => nil
```

## 4. اسمح للأشخاص بشراء تذكرة

نفّذ `Attendee#issue_pass!` لتغيير حالة النسخة، واضبط متغير نسخة معرّف التذكرة على الوسيط. ويجب أن تُرجع معرّف التذكرة.

```ruby
attendee = Attendee.new(106)
attendee.issue_pass!(42)
attendee.pass_id
# => 42
```

## 5. أبطِل التذكرة

يخالف بعض الزوار القواعد بسلوك غير آمن، لذا تريد المدينة أن تكون قادرة على إبطال التذاكر. نفّذ `Attendee#revoke_pass!` لتغيير حالة النسخة، واضبط معرّف التذكرة على `nil`.

```ruby
attendee = Attendee.new(106)
attendee.issue_pass!(42)
attendee.revoke_pass!
attendee.pass_id
# => nil
```
