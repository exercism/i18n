# نبذة

`bit` هو أصغر قيمة يمكن التعامل معها في الحوسبة.
وكلمة `bit` اختصار لعبارة «الرقم الثنائي».
وهو وحدة لتخزين البيانات في بيئة التنفيذ، كبيرة بما يكفي لتحتوي على كائن قد يأخذ إحدى قيمتين.
وبالتالي، فإن قيمته الثنائية إما `1` أو `0`.
وتتكوّن جميع أنواع البيانات الأخرى من عدة `bits`.
فعلى سبيل المثال، يتكوّن `byte` عادةً من ثمانية `bits`.

## كيفية كتابة قيم البتات

تكوّن `Bits` نظام أعداد أساسه `2`.
يوضع كل مضاعف للعدد `2` في ما نعتبره منزلة العشرات/المئات/الآلاف/إلخ، إلا أن «العشرات» هنا تصبح «اثنين»، و«المئات» تصبح «أربعة»، و«الآلاف» تصبح «ثمانية»، وهكذا.
إذن، القيمة العشرية `2` تقابلها القيمة الثنائية `10`، و`4` تقابلها `100`، و`8` تقابلها `1000`.
وكما في الأعداد العشرية، تزداد القيم كلما انتقلنا من اليمين إلى اليسار.
يمكننا تصوّر القيمة العشرية `5` ممثَّلة بـ `101` في النظام الثنائي، بوضع `1` في منزلة «الآحاد» و`1` في منزلة «الأربعة».
غير أن القيم الثنائية الحرفية ليست جزءًا من معيار لغة C.
القيم الثنائية الوحيدة التي يدعمها معيار لغة C هي `1` أو `0` المفردة.
لكن بعض امتدادات المترجمات غير القياسية _تدعم_ القيم الثنائية الحرفية، مثل مترجم gnu، وذلك بوضع السابقة `0b` قبل القيمة.

```c
#include <stdio.h>

int main() {
    int binary_five = 0b101;
    printf("%d", binary_five);
    return 0;
}
```

من المهم أن تتذكر أن هذا الترميز لا تدعمه كل المترجمات، وقد يشكّل عائقًا أمام نقل الكود بين مترجمات مختلفة.

من الأساليب الشائعة لكتابة القيم الثنائية استخدام الترميز الست عشري، وهو نظام أعداد أساسه 16.
في لغة C، يسبق الترميز الست عشري القيمة الحرفية بـ `0x` أو `0X`.
ولأن القيمة العشرية `16` تُمثَّل بـ `1` في منزلة العشرات، فإن القيمة العشرية `10` تُمثَّل بـ `0xA` في النظام الست عشري، و`11` بـ `0xB`، و`12` بـ `0xC`، و`13` بـ `0xD`، و`14` بـ `0xE`، و`15` بـ `0xF`.
وهكذا، على سبيل المثال، تُكتب القيمة العشرية `42` على الصورة `0x2A`: `2` مضروبًا في `16` (= `32`) زائد `10` (= `42`).

وفي النظام الثنائي، يمكننا تصوّر `42` على أنها `00101010`: `32` زائد `8` زائد `2`.
نقول إن البتات التي في الموضع الثاني والرابع والسادس من اليمين «مضبوطة»، أي أنها `1` بدلًا من `0`.
البت في الموضع الثاني قيمته `2`، وفي الرابع `8`، وفي السادس `32`.
وضبط هذه البتات الثلاث يحدّد القيمة `42`.

## أقنعة البتات

يمكن أن يكون قناع البتات أي قيمة تُستخدم لضبط بتات فردية.
فعلى سبيل المثال، تحتوي الأبجدية الإنجليزية على ستة وعشرين حرفًا.
ويمكن استخدام قيمة من ستة وعشرين بتًّا على الأقل، مثل عدد صحيح غير مُوقّع بسعة 32 بت، كقناع بتات لضبط حالة `true` أو `false` لكل حرف إنجليزي.
وأي قيمة تملك بتات كافية للتعامل مع مجموعة مطلوبة من شروط `true` أو `false` يمكن أن تصلح قناع بتات.
ويتم ضبط البتات الفردية وقراءتها باستخدام العوامل البتّية.

## العوامل البتّية

لنفترض أننا نريد تتبّع الحروف التي تظهر في `string`.
في مثالنا، سنستخدم الحروف الستة والعشرين في الأبجدية الإنجليزية فقط.
سيكون قناع البتات لدينا عددًا صحيحًا غير مُوقّع بسعة 32 بت.
يمثّل `0` عدم ظهور الحرف.
ويمثّل `1` ظهور الحرف مرة واحدة أو أكثر.
في البداية، سيكون التمثيل الثنائي لقناع البتات لدينا 32 من `0s` على التوالي: `00000000000000000000000000000000`.
سيكون الموضع الأيمن مخصّصًا للحرف `A`.
ويكون الموضع الثاني من اليسار للحرف `B`، وهكذا.
لنفترض أننا نعالج كل حروف السلسلة النصية داخل حلقة، لذا نريد سطرًا واحدًا من الكود يصلح لضبط أي حرف.

### العامل البتّي للإزاحة إلى اليسار: كيفية تحديد موضع بت

`<<` هو العامل البتّي الخاص بالإزاحة إلى اليسار.

إذا كان الحرف لدينا `A` فلا نريد أي إزاحة إلى اليسار، أما إذا كان الحرف `B` فنريد الإزاحة إلى اليسار موضعًا واحدًا، وإذا كان `C` فنريد الإزاحة إلى اليسار موضعين، وهكذا.
ورغم أننا ندرك `chars` على أنها حروف مثل `A` أو `B`، فإن `char` مُنفَّذ في الذاكرة كنوع صحيح، لذا يمكننا إجراء حسابات بسيطة على `char`.
بافتراض وجود متغير باسم `letter` يمثّل `char` الذي نعالجه، يمكننا الإزاحة إلى اليسار بالعدد المطلوب من المواضع بإزاحة `1` إلى اليسار بمقدار الفرق بين `letter` والحرف `A`، هكذا: `1 << letter - 'A'`.
‏`A` - `A` يساوي `0`، لذا تكون الإزاحة إلى اليسار صفر مواضع إذا كان `letter` هو `A`.
و`B` - `A` يساوي `1`، لذا تكون الإزاحة إلى اليسار موضعًا واحدًا إذا كان `letter` هو `B`، وهكذا.

### العامل البتّي «أو» الشامل: كيفية ضبط بت

بعد أن نعرف _أين_ نريد ضبط بت، يمكننا ضبطه فعليًا باستخدام العامل البتّي «أو» الشامل، وهو `|`.
تكون نتيجة العامل `|` مساوية لـ `1` في كل موضع يكون فيه البت مضبوطًا في الطرف الأيسر أو الأيمن.
إذن، نتيجة `0010 | 0001` هي `0011`.
(من المهم أن تتذكر أن هذه القيمة هي `11` في النظام الثنائي، لكنها `3` في النظام العشري.)
ولإسناد النتيجة إلى قيمة، يمكن دمج العامل `|` مع عامل الإسناد لضبط البتات هكذا: `|=`.
ولتبسيط الأمر، لا يستخدم المثال التالي حلقة، لكنه يوضّح كيف يمكننا معالجة الحروف `ABA` داخل قناع بتات.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    // it's important to initialize the mask to 0 so we don't get garbage values
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    mask |= 1 << letter_A_again - 'A';
    // prints 3
    printf("%d", mask);
}
```

نضبط الجزء الأيمن من القناع على `0001` من أجل `A`، ثم نضبط القناع على `0011` من أجل `B`.
وضبط `A` مرة أخرى لا يُحدث أي تغيير في القناع الحالي.
كان بإمكاننا تجنّب ضبط البت مرة أخرى بالنظر لمعرفة ما إذا كان `A` قد ضُبط بالفعل.

### العامل البتّي «و»: كيفية قراءة بت

`&` هو العامل البتّي «و».
تكون نتيجة العامل `&` مساوية لـ `1` في كل موضع يكون فيه البت مضبوطًا في الطرفين الأيسر والأيمن معًا.
إذن، نتيجة `0011 & 0001` هي `0001`.
ويمكننا رؤية ذلك عمليًا في المثال التالي.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    // prints A already set
    if (mask & 1 << letter_A_again - 'A')
        printf("A already set\n");
    else
        mask |= 1 << letter_A_again - 'A';
    printf("%d", mask);
}
```

### العامل البتّي «أو» الحصري: كيفية قلب بت

`^` هو العامل البتّي «أو» الحصري.
وجود عامل «أو» _الشامل_ يعني ضمنًا وجود عامل «أو» _حصري_ بسلوك مختلف.
تكون نتيجة العامل `^` مساوية لـ `1` في كل موضع يكون فيه _أحد_ الطرفين فقط، الأيسر أو الأيمن، قد ضُبط فيه البت.
إذن، نتيجة `0001 ^ 0011` هي `0010`.
لن يُضبط البت الأيمن لأن _كلا_ الطرفين يحتوي على `1` في الموضع الأيمن.
تُكتب عملية «أو» الحصرية أحيانًا بالرمز XOR.
إذا أُجريت عملية XOR على نتيجة تطبيق XOR على قيمة، فإنها تُرجع القيمة الأصلية.
ويمكن استخدام ذلك في تشفير بسيط جدًا يُستخدم فيه المفتاح نفسه للتشفير وفك التشفير معًا.
على سبيل المثال

```c
#include <stdio.h>

int main() {
    char a = 'a';
    char b = 'b';
    char c = 'c';
    // we will use "a" for the "key"
    char first = a ^ 'a';
    char second = b ^ 'a';
    char third = c ^ 'a';
    // prints three "dots" for unprintable characters
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 0 3 2
    printf("%d %d %d\n", first, second, third);
    first = first ^ 'a';
    second = second ^ 'a';
    third = third ^ 'a';
    // prints a b c
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 97 98 99
    printf("%d %d %d\n", first, second, third);
}
```

### العامل البتّي للإزاحة إلى اليمين: كيفية تنصيف قيمة

`>>` هو العامل البتّي للإزاحة إلى اليمين.
عادةً، لكل موضع تُزاح فيه بتات قيمة إلى اليمين، تكون النتيجة هي القيمة مقسومة على اثنين.
على سبيل المثال

```c
#include <stdio.h>

int main() {
    int number = 16;
    number >>= 2;
    // prints 4, or 16 / 2 = 8 / 2 = 4
    printf("%d\n", number);
}
```

إذا كانت قيمة الطرف الأيمن سالبة أو أكبر من أو مساوية لعرض الطرف الأيسر بعد الترقية، فإن السلوك غير معرّف.
وينطبق ذلك أيضًا على عامل الإزاحة إلى اليسار.
وعند استخدام عدد صحيح مُوقّع بدلًا من عدد صحيح غير مُوقّع، فقد تدخل إشارة العدد في الحساب أيضًا.
يوضّح المثال التالي السلوك على نظام معيّن عند الإزاحة بعيدًا جدًا إلى اليسار أو اليمين في عدد صحيح مُوقّع.

```c
#include <stdio.h>

int main() {
    int number = 16;
    number <<= 250;
    // prints 1073741824
    printf("%d\n", number);
    number <<= 1;
    // prints -2147483648
    printf("%d\n", number);
    number <<= 1;
    // prints 0
    printf("%d\n", number);
    // total shifts are now 256, done incrementally
    number <<= 4;
    // prints 0
    printf("%d\n", number);
    number = 16;
    // prints 16 when 256 total shifts done at once
    printf("%d\n", number << 256);
    // prints 0 when bits shifted right far enough
    printf("%d\n", number >> 5);    
    // still prints 0
    printf("%d\n", number >> 255);
    // prints 16 when shifted right far enough to "wrap around"
    printf("%d\n", number >> 256);
}
```

ولأن السلوك غير معرّف، فقد يعطي نظام مختلف نتائج مختلفة.
ومن المهم عند إزاحة البتات أن تفهم حدود نوع البيانات المستخدم.

## حقول البتات

رأينا كيف يمكن مخاطبة البتات المحزومة في نوع بيانات بسيط من خلال موضعها.
ويمكن مخاطبة البتات المحزومة في `struct` بالاسم.
ويُسمّى نوع البيانات هذا `bit field`.
يمكن أن تكون `bit fields` مفيدة عندما نحتاج إلى مجموعة من الأعلام ذات قيمتي تشغيل/إيقاف ونريد تقليل استخدام الذاكرة.

```c
#include <stdio.h>

int main() {

    struct lights {
        unsigned int number_of_lights;
        unsigned int red   : 1;
        unsigned int green : 1;
        unsigned int blue  : 1;
    };
    struct lights lightboard = {3, 0, 0, 0};
     
    //  prints 000
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    lightboard.green = 1;

    //  prints 010
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    // prints 3
    printf("%d\n", lightboard.number_of_lights);
}
```

ينشئ التركيب `unsigned int variable_name : 1;` حقلًا بسعة `1` بت داخل `unsigned int` موضوع داخل البنية.
وبدلًا من `unsigned int`، يمكن استخدام `signed int`، أو، بدءًا من C99 فصاعدًا، يمكن استخدام النوع `bool`.
ويمكن أن تحتوي البنية التي تضم حقول بتات على حقول من أنواع بيانات أخرى، مثل `number_of_lights` في المثال أعلاه.
