# مقدمة

تتيح لك الأنواع العامة كتابة كود يعمل مع أنواع متعددة دون تكرار.
عرّف الأنواع العامة باستخدام الأقواس الزاوية `<T>`، حيث يمثل `T` عنصرًا بديلًا لأي نوع.

```rust
fn largest_list<T>(l1: Array<T>, l2: Array<T>) -> Array<T> {
    if l1.len() > l2.len() {
        l1
    } else {
        l2
    }
}
```

يشترط Cairo تحديد قيود السمات لتوضيح العمليات التي يجب أن يدعمها النوع العام.
يمكنك إضافة قيود باستخدام صيغة `+`:

```rust
fn process_data<T, +Drop<T>, +Copy<T>>(value: T) -> T {
    // Function body
}
```

يمكن أن تكون البنى أيضًا عامة:

```rust
#[derive(Drop)]
struct Container<T> {
    value: T,
}
```

يمكن أن تكون السمات عامة أيضًا، ما يسمح لها بالعمل مع أنواع مختلفة:

```rust
trait Processor<T> {
    fn process(self: @T) -> ByteArray;
}

impl MyProcessor<T, +Drop<T>> of Processor<T> {
    fn process(self: @T) -> ByteArray {
        "processed"
    }
}
```

يمكن للدوال أن تقبل معاملات عامة مع قيود السمات، ما يجعلها تعمل مع أي نوع ينفّذ السمة المطلوبة:

```rust
fn use_processor<T, +Processor<T>, +Drop<T>>(item: T) -> ByteArray {
    item.process()
}
```
