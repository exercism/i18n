# نبذة

يحدّد [_سلوك الاستثناء_][exception-behaviour] كيفية رفع [`errors`][getting-started-errors] وعرضها.

وهو يتضمّن دالتي رد نداء اختياريتين:

- تُحوّل `message/1` بنية الخطأ إلى رسالة مقروءة.
- تُنشئ `exception/1` الرسالة من الوسيط الثاني في `raise/2`، مما يسمح بتعديل الرسالة.

الأخطاء المعرَّفة:

- تحمل اسم الوحدة التي تُنفَّذ فيها.
- تكون امتدادًا لنوع البنية.
- تمتلك حقل `:message`.
- يمكن استخدامها مع `raise/1` و`raise/2` لرفع الخطأ المقصود

## تعريف استثناء

لتعريف استثناء من وحدة خطأ، استخدم ماكرو [`defexception`][defexception]:

```elixir
# Defines a minimal error, with the name `MyError`
defmodule MyError do
  defexception message: "error"
end

# Defines an error with a customized exception/1 function
defmodule MyCustomizedError do
  defexception message: "custom error"

  @impl true
  def exception(value) do
    case value do
      [] ->
        %MyCustomizedError{}

      _ ->
        %MyCustomizedError{message: "Alert: " <> value}
    end
  end
end
```

## استخدام الاستثناءات

يمكن استخدام الأخطاء المعرَّفة مثل خطأ مدمج باستخدام `raise/1` أو `raise/2`:

```elixir
raise MyError
# => ** (MyError) error

raise MyError, "an error occurred"
# => ** (MyError) an error occurred

raise MyCustomizedError
# => ** (MyCustomizedError) "custom error"

raise MyCustomizedError, "a very bad error occurred"
# => ** (MyCustomizedError) Alert: a very bad error occurred
```
