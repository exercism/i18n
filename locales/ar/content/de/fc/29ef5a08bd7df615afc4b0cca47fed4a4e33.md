# مقدمة

تتيح لك الطباعة في Cairo عرض الرسائل أو معلومات التصحيح أثناء تنفيذ البرنامج.

## الأساسيات

توفر Cairo وحدتَي ماكرو للطباعة:

- `println!`: يُخرج رسالة متبوعة بسطر جديد.
- `print!`: يُخرج رسالة دون سطر جديد.

```rust
println!("Hello, Cairo!"); 
println!("x = {}, y = {}", 10, 20); 
```

تُستبدل العناصر النائبة `{}` بالقيم المقدمة.

## تنسيق السلاسل النصية

استخدم `format!` لإنشاء `ByteArray` دون طباعته فورًا:

```rust
let result = format!("{}-{}-{}", "tic", "tac", "toe");
println!("{}", result); // Output: tic-tac-toe
```

## أنواع البيانات المخصصة

بالنسبة للأنواع المخصصة، نفّذ `Display` أو اشتق `Debug` للطباعة:

```rust
#[derive(Debug)]
struct Point { x: u8, y: u8 }

let p = Point { x: 3, y: 4 };
println!("{:?}", p); // Debug output: Point { x: 3, y: 4 }
```

## الطباعة بالنظام الست عشري

استخدم `{:x}` لطباعة الأعداد الصحيحة بالنظام الست عشري:

```rust
println!("{:x}", 255); // Output: ff
```
