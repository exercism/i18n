# ملحق التعليمات

## الذاكرة المحجوزة

يستخدم المخزن المؤقت الخاص بالسلسلة النصية المُدخلة البايتات من 64 إلى 191 من الذاكرة الخطية.

## صيغة الإدخال

يأتي الإدخال مُنسَّقًا على هيئة سلسلة نصية واحدة من ثلاثة أسطر، مع فاصل سطر في نهاية كل سطر. ويظهر رمزا `X` و`O` دائمًا بحرف كبير.

إذن تُرمَّز لوحة اللعبة

```
X··
OXO
XOX
```
على النحو التالي

```
"X  \nOXO\nXOX\n"
```
