# مقدمة

‏JavaScript لغة ديناميكية، تدعم أساليب البرمجة كائنية التوجه والأمرية والتعريفية (مثل البرمجة الوظيفية).

## الإسناد وإعادة الإسناد

توجد عدة أساليب رئيسية لإسناد القيم إلى الأسماء في JavaScript، إما باستخدام المتغيرات أو الثوابت. في Exercism، تُكتب المتغيرات دائمًا بنمط [camelCase][wiki-camel-case]، وتُكتب الثوابت بنمط [SCREAMING_SNAKE_CASE][wiki-snake-case]. لا يوجد دليل رسمي يجب اتباعه، ولدى شركات ومؤسسات مختلفة أدلة أنماط متنوعة. _لا تتردد في كتابة المتغيرات كما تشاء_. الميزة في كتابتها كما أُعدّت بها التمارين هي أنها ستُبرَز بشكل مختلف في واجهة الويب ومعظم بيئات التطوير المتكاملة.

يمكن تعريف المتغيرات في JavaScript باستخدام الكلمة المفتاحية [`const`][mdn-const] أو [`let`][mdn-let] أو [`var`][mdn-var].

يمكن للمتغير أن يشير إلى قيم مختلفة على مدار عمره عند استخدام `let` أو `var`. على سبيل المثال، يمكن تعريف `myFirstVariable` وإعادة تعريفه مرات عديدة باستخدام عامل الإسناد `=`:

```javascript
let myFirstVariable = 1;
myFirstVariable = 'Some string';
myFirstVariable = new SomeComplexClass();
```

على النقيض من `let` و`var`، لا يمكن إسناد قيمة إلى المتغيرات المعرّفة بـ `const` إلا مرة واحدة. ويُستخدم هذا لتعريف الثوابت في JavaScript.

```javascript
const MY_FIRST_CONSTANT = 10;

// Cannot be re-assigned.
MY_FIRST_CONSTANT = 20;
// => TypeError: Assignment to constant variable.
```

> 💡 في تمرين تعليمي لاحق، يتم استكشاف الفرق بين إسناد/ربط _الثابت_ و_قيمة الثابت_ وشرحه.

## تعريف الدوال

في JavaScript، تُغلَّف وحدات الوظائف داخل _الدوال_، وعادةً ما تُجمَّع الدوال معًا في الملف نفسه إذا كانت تنتمي إلى بعضها البعض. يمكن لهذه الدوال أن تأخذ معاملات (وسائط)، وأن _تُرجع_ قيمة باستخدام الكلمة المفتاحية `return`. تُستدعى الدوال باستخدام صيغة `()`.

```javascript
function add(num1, num2) {
  return num1 + num2;
}

add(1, 3);
// => 4
```

> 💡 في JavaScript توجد _أساليب عديدة_ مختلفة لتعريف دالة. تبدو هذه الأساليب الأخرى مختلفة عن استخدام الكلمة المفتاحية `function`. يحاول المسار تقديمها تدريجيًا، لكن إذا كنت تعرفها بالفعل، فلا تتردد في استخدام أي منها. في معظم الحالات، لا يكون استخدام أحدها أفضل أو أسوأ من الآخر.

## الإتاحة لملفات أخرى

لجعل `function` أو ثابت أو متغير متاحًا في _ملفات أخرى_، يجب [تصديرها][mdn-export] باستخدام الكلمة المفتاحية `export`. يمكن بعد ذلك لملف آخر أن [يستورد][mdn-import] هذه العناصر باستخدام الكلمة المفتاحية `import`. ويُعرف هذا أيضًا بنظام الوحدات. ومن الأمثلة الرائعة على ذلك كيفية عمل جميع الاختبارات. لكل تمرين ملف واحد على الأقل، مثل `lasagna.js`، يتضمن _التنفيذ_. وبالإضافة إلى ذلك، يوجد ملف آخر على الأقل، مثل `lasagna.spec.js`، يتضمن _الاختبارات_. _يستورد_ هذا الملف الكيانات العامة (أي المُصدَّرة) لاختبار التنفيذ:

```javascript
// file.js
export const MY_VALUE = 10;

export function add(num1, num2) {
  return num1 + num2;
}

// file.spec.js
import { MY_VALUE, add } from './file';

add(MY_VALUE, 5);
// => 15
```
