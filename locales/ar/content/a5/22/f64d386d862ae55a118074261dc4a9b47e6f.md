# الاختبارات

## تثبيت مشغّل اختبارات مسار GDScript في Exercism

ستحتاج إلى تثبيت [Godot][installation] بشكل صحيح لاستخدام مشغّل الاختبارات.

لبناء نصوص GDScript واختبارها لصالح Exercism، سيُشغَّل Godot في الوضع "headless" من واجهة سطر الأوامر.
تتطلب هذه التعليمات حاليًا نظام Linux وbash.

### الخطوة 1: تثبيت البنية الأساسية لمشغّل الاختبارات

للتحضير للاختبار، استنسخ [https://github.com/exercism/gdscript-test-runner][gdscript-test-runner] وانقل محتوياته إلى `/opt/test-runner/`:

```sh
git clone https://github.com/exercism/gdscript-test-runner.git
sudo mkdir -p /opt/
sudo mv gdscript-test-runner/ /opt/test-runner/
```

### الخطوة 2: تنزيل سكربت مشغّل اختبار التمرين الواحد

بافتراض أنك أعددت أداة `exercism` ونزّلت تمرينًا واحدًا على الأقل بلغة GDScript، فمن المفترض أن يكون قد أُنشئ مجلد `exercism/gdscript` لاحتواء التمارين.
احفظ [مشغّل الاختبارات][test-local-gdscript-solution] في هذا المجلد واجعل الملف قابلًا للتنفيذ، أو أنشئ رابطًا إليه فقط:

```sh
cd ~/exercism/gdscript # replace with your exercism/gdscript directory
ln /opt/test-runner/bin/test-local-gdscript-solution.sh
```

## تشغيل الاختبارات

بعد إتمام خطوات التثبيت، يمكنك البدء من أي مجلد تمرين (مثل `~/exercism/gdscript/two-fer`) وتشغيل السكربت (الموجود في المستوى الأعلى، في `../`) لاختبار حلك المحلي لذلك التمرين:

```sh
../test-local-gdscript-solution.sh
```
