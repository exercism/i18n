# مقدمة

محارف Factor هي أعداد صحيحة، أي نقاط ترميز Unicode، لذا تمنحك العوامل العددية `<` و`>` و`=` ترتيبًا حساسًا لحالة الأحرف مباشرةً. وتضيف مفردات [`unicode`][unicode] دوال فحص تراعي Unicode وتحويلًا لحالة حرف واحد.

## دوال فحص الأحرف

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
digit>   ( c -- n )    ! the integer value of a digit char
blank?   ( c -- ? )    ! whitespace
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
CHAR: 7 digit>  .    ! => 7
```

## تحويل حالة الأحرف

يقلب `ch>upper` و`ch>lower` حالة حرف واحد. أما `>upper` و`>lower` على مستوى السلسلة النصية فيطبّقانهما على كل حرف من أحرف السلسلة النصية.

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```

تجعل `capitalize` السلسلة النصية كلها بحروف صغيرة ثم تكبّر حرفها الأول، أي حالة العنوان لكلمة واحدة:

```factor
"hELLO" capitalize .   ! => "Hello"
```

## المحارف الحرفية

تتحلّل `CHAR: A` إلى نقطة ترميز `A` بصيغة عدد صحيح. وللمحارف ذات الأسماء، استخدم الأسماء `space` و`tab` و`\n` وغيرها:

```factor
CHAR: A .        ! => 65
CHAR: space .    ! => 32
CHAR: \n .       ! => 10
```

## الرموز

عندما تحتاج كلمة إلى إرجاع وسم بدلًا من قيمة، مثل `yes`/`no`/`maybe` بدلًا من قيمة منطقية، فأعلن كل وسم بوصفه *رمزًا*. الرمز كلمة تدفع نفسها عند استدعائها، ولا يتساوى رمزان إلا إذا كانا الاسم نفسه.

```factor
USING: kernel ;

SYMBOLS: yes no maybe ;

yes .    ! => yes
yes yes = .    ! => t
yes no = .     ! => f
```

تُعلن `SYMBOL: name` رمزًا واحدًا، أما `SYMBOLS: a b c ;` فتعلن عدة رموز.
