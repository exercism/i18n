# مقدمة

معظم كلمات التسلسل التي رأيتها تُرجع تسلسلات *جديدة* وتترك مدخلاتها كما هي: `suffix` و`reverse` و`map`، وما إلى ذلك. لكن المصفوفات والمتجهات تدعم أيضًا **التعديل في المكان**، وكلاهما يظهر عندما تريد تسجيل حالة تتغير بمرور الوقت.

## نوعان من التسلسلات القابلة للتعديل

- **المصفوفات** (`{ … }`) لها طول ثابت. يبني `<array> ( n elt -- array )` (في [`arrays`][arrays]) مصفوفة جديدة طولها `n` مملوءة بنسخ من `elt`.
- **المتجهات** (`V{ … }`) تنمو وتتقلص. استخدم `V{ } clone` للحصول على متجه فارغ جديد؛ ويحجز `<vector> ( n -- vector )` (في [`vectors`][vectors]) سعة مسبقًا لـ `n` عنصرًا.

```factor
USING: arrays kernel prettyprint vectors ;

5 0 <array> .   ! => { 0 0 0 0 0 }
V{ } clone .    ! => V{ }
```

## تغيير خانة

تعمل هاتان الكلمتان على كلا نوعي التسلسل، وكلتاهما تتوقع التسلسل بعد الفهرس:

```
set-nth    ( elt n seq -- )
change-nth ( n seq quot -- )
```

تُسند `set-nth` القيمة؛ وتُطبّق `change-nth` اقتباسًا على العنصر في الموضع `n`.
كلتا هاتين الكلمتين من [`sequences`][sequences] لا تُرجعان شيئًا إلى المكدس؛ فالتعديل هو الأثر.

```factor
USING: arrays kernel math prettyprint sequences ;

5 0 <array>                 ! { 0 0 0 0 0 }
7 2 pick set-nth            ! mutates: position 2 becomes 7
0 over [ 1 + ] change-nth   ! mutates: position 0 += 1
.                           ! => { 1 0 7 0 0 }
```

## النمو والتقلص

هذه الثلاث لا معنى لها إلا على المتجهات، لأن المصفوفات لا يمكن أن يتغير طولها:

```
push  ( elt seq -- )    ! append to the end
pop   ( seq -- elt )    ! remove and return the last
pop*  ( seq -- )        ! remove the last, discard
```

```factor
USING: kernel sequences vectors ;

V{ } clone              ! a fresh empty vector
"alice" over push       ! V{ "alice" }
"bob"   over push       ! V{ "alice" "bob" }
dup pop .               ! prints "bob"
.                       ! prints V{ "alice" }
```

## من المتجه إلى المصفوفة

عندما تبني متجهًا وتريد إعادة مصفوفة ذات طول ثابت، تُرجع `>array ( seq -- array )` (في [`arrays`][arrays]) مصفوفة جديدة بالعناصر نفسها:

```factor
USING: arrays kernel prettyprint sequences vectors ;

V{ "alice" "bob" "carol" } >array .
! => { "alice" "bob" "carol" }
```

## `clone`: احتفظ بلقطة

التعديل يغيّر التسلسل في مكانه. إذا سلّمك مستدعٍ تسلسلًا وكنت على وشك تغييره، فإن `clone` (في [`kernel`][kernel]) يمنحك نسخة مستقلة جديدة حتى لا تتغير نسخة المستدعي دون علمه:

```factor
USING: kernel prettyprint ;

V{ "a" "b" "c" } clone .    ! => V{ "a" "b" "c" }   (a fresh copy)
```

ينطبق الاحتياط نفسه على `V{ }` وغيرها من القيم الحرفية الفارغة. في بعض اللغات، يحجز `[]` أو `vec![]` حاوية جديدة في كل مرة يُقيَّم فيها التعبير. أما في Factor، فالقيمة الحرفية `V{ }` المكتوبة في مصدرك هي *كائن واحد* يتقاسمه كل موضع استدعاء يذكرها. وإذا دفعت بـ `push` إلى `V{ }` مباشرة، فسيرى الاستدعاء التالي البقايا. و`V{ } clone` ينشئ النسخة الجديدة التي تريدها في معظم الأحيان.
