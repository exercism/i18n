# مقدمة

## الشرح

إلى جانب أنواع البيانات الأولية مثل `number` و`string`، هناك نوع بيانات مهم آخر في JavaScript يُسمى `object`.
الكائنات مجموعات من أزواج المفتاح والقيمة.
وبذلك يمكن استخدامها بالطريقة نفسها التي تُستخدم بها ما يُشار إليه غالبًا باسم الخرائط أو القواميس في لغات أخرى.

في لغات أخرى، غالبًا ما تحتاج جميع القيم في الخريطة إلى أن تكون من نوع البيانات نفسه.
أما في JavaScript، فالنوع الوحيد المقيَّد هو نوع المفتاح: إذ يجب أن يكون `string`.
ويمكن أن تكون القيم داخل الكائن الواحد من أنواع مختلفة.
فقد تكون أنواعًا أولية مثل الأعداد، ولكنها قد تكون أيضًا مصفوفات أو كائنات أخرى أو حتى دوال.
وهذا يجعل الكائنات متعددة الاستخدامات إلى حد كبير، حتى إنها تُعد أيضًا كيانات أساسية في [البرمجة كائنية التوجه][oop] (OOP) في JavaScript.

في ما يلي، سنركّز على الكائنات بوصفها مجموعات أو خرائط.
وسنغطي حالات استخدام أخرى للكائنات في مفاهيم أخرى، انظر مثلًا [الأصناف][concept-classes].

## إنشاء كائن

تُنشئ كائنًا باستخدام الأقواس المعقوفة.
يمكنك أيضًا تضمين بعض المُدخلات مباشرة.
ولذلك، اذكر المفتاح أولًا، ثم نقطتين، ثم القيمة.

```javascript
const emptyObject = {};

const obj = {
  favoriteNumber: 42,
  greeting: 'Hello World',
  useGreeting: true,
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
  fruits: ['melon', 'papaya'],
  addNumbers: function (a, b) {
    return a + b;
  },
};
```

الفاصلة الأخيرة بعد آخر مُدخل اختيارية في JavaScript.

قد تتساءل لماذا لا تُوضع المفاتيح بين علامات اقتباس رغم أنه يُفترض أن تكون سلاسل نصية.
هذه صيغة مختصرة.
إذا كان المفتاح يتبع قواعد التسمية الخاصة بـ [المُعرّف][mdn-identifier] في JavaScript، فيمكنك حذف علامات الاقتباس.
أما المفاتيح التي تحتوي أسماؤها على أحرف خاصة، فتحتاج إلى استخدام صيغة السلسلة النصية المعتادة.

```javascript
const obj = {
  '1keyStartsWithNumber': '...',
  'key/with/slashes': '...',
  'key-with-dashes': '...',
  'key with spaces': '...',
  '#&()[]{}èä樹keyWithSpecialChars': '...',
};
```

## استرجاع قيمة

هناك أسلوبان لاسترجاع قيمة مفتاح معيّن: صيغة النقطة وصيغة الأقواس المربعة.

```javascript
const obj = { greeting: 'hello world' };

obj.greeting;
// => hello world

obj['greeting'];
// => hello world

// Bracket notation also works with variables.
const key = 'greeting';
obj[key];
// => hello world
```

استخدام صيغة النقطة كاختصار له القيد نفسه الذي لحذف علامات الاقتباس.
فهو لا يعمل إلا إذا كان المفتاح يتبع قواعد تسمية المُعرّفات.

## إضافة قيمة أو تغييرها

يمكنك إضافة قيمة أو تغييرها باستخدام عامل الإسناد `=`.
ومرة أخرى، تتوفر صيغتا النقطة والأقواس المربعة.

```javascript
const obj = { greeting: 'hello world' };

obj.greeting = 'Hi there!';
obj['greeting'] = 'Welcome.';

obj.newKey1 = 'new value 1';
obj['new key 2'] = 'new value 2';

const key = 'new key 3';
obj[key] = 'new value 3';
```

## حذف مُدخل

يمكنك حذف زوج مفتاح-قيمة من كائن باستخدام الكلمة المفتاحية `delete`.

```javascript
const obj = {
  key1: 'value1',
  key2: 'value2',
};

delete obj.key1;
delete obj['key2'];
```

## التحقق من وجود مفتاح

يمكنك التحقق مما إذا كان مفتاح معيّن موجودًا في كائن باستخدام الطريقة `hasOwnProperty`.

```javascript
const obj = { greeting: 'hello world' };

obj.hasOwnProperty('greeting');
// => true

obj.hasOwnProperty('age');
// => false
```

## المرور على الكائن بحلقة

توجد حلقة خاصة `for...in` للمرور على جميع مفاتيح كائن.

```javascript
const obj = {
  name: 'Ali',
  age: 65,
};

for (let key in obj) {
  console.log(key, obj[key]);
}
// name Ali
// age 65
```

لتجنّب الأخطاء الدقيقة، ينبغي أن تفترض دائمًا أن حلقة `for...in` تزور المفاتيح بترتيب عشوائي.
وانتبه أيضًا إلى أن `for...in` يتضمّن [المفاتيح الموروثة][concept-inheritance] في تكراره.
