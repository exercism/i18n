# التكرار

في البرمجة، يشير [التكرار][iteration] إلى عملية إعادة تنفيذ كتلة من الكود عدة مرات.
ويمكن تحقيق ذلك باستخدام مفاهيم مثل حلقات `while` وحلقات `until`.
كما يمكن تحقيقه باستخدام الاستدعاء الذاتي، وهو دالة تستدعي نفسها.

لكن في أغلب الأحيان تريد التكرار على مجموعة من العناصر، مثل `Array` أو `Range` أو `String`.
الصنفان `Array` و`Range` في Crystal يتضمنان وحدة [`Enumerable`][enumerable]، التي توفر عددًا من الطرق للتكرار على العناصر.
في المقابل، لصنف `String` مجموعته الخاصة من الطرق للتكرار على الأحرف.

كذلك لا يوجد في Crystal أي عبارة `for` كما في اللغات الأخرى.
بل لديها عدة طرق يمكن استخدامها للتكرار.

## التكرار

الطريقة الأكثر شيوعًا للتكرار على مجموعة هي استخدام طريقة [`each`][each]، التي تُمرّر كل عنصر في المجموعة إلى كتلة.
ويمكن فعل ذلك بسهولة باستخدام `Range`.
لنفترض أنك تريد التكرار بين 1 و3، يمكنك استخدام طريقة `each` للتكرار على النطاق.

```crystal
(1..3).each do |n|
  puts n
end

# Output:
# 1
# 2
# 3
```

وبشكل أبسط، إذا أردت فقط التكرار عددًا من المرات يمكنك استخدام طريقة [`times`][times]، الموجودة في صنف `Int`.

```crystal
3.times do |n|
  puts n
end

# Output:
# 0
# 1
# 2
```

## التكرار على `String`

‏`String` سلسلة من الأحرف ولا تنتمي إلى وحدة `Enumerable`، ما يعني أن لها مجموعتها الخاصة من الطرق للتكرار على الأحرف.
الطريقة الأكثر شيوعًا للتكرار على `String` هي استخدام طريقة [`each_char`][each_char]، التي تُمرّر كل حرف في `String` إلى كتلة.

~~~~exercism/note
تُمرّر طريقة `each_char` كائن `Char` وليس كائن `String` إلى الكتلة.
~~~~

```crystal
str = "hello"
str.each_char { |char| puts char }

# Output:
# h
# e
# l
# l
# o
```

وثمة طريقة أخرى للتكرار على `String` هي استخدام طريقة [`each_line`][each_line].
وتُستخدم هذه الطريقة غالبًا عند قراءة ملف سطرًا بسطر.

```crystal
str = "hello\nworld"
str.each_line do |line|
  puts line
end

# Output:
# hello
# world
```

## التكرار على كائن يتضمن وحدة `Enumerable`

توفر وحدة [`Enumerable`][enumerable] عددًا من الطرق للتكرار على عناصر مجموعة.
والمجموعات التي تتضمن وحدة `Enumerable` هي `Array` و`Range` و`Hash` و`Set` وغيرها، وسنتناول غيرها في مفاهيم لاحقة.

الطريقة الأكثر شيوعًا للتكرار على `Array` هي استخدام طريقة [`each`][each]، التي تُمرّر كل عنصر في `Array` إلى كتلة.

```crystal
arr = [5, 2, 3]
arr.each do |element|
  puts element
end

# Output:
# 5
# 2
# 3
```

### Map

طريقة [`map`][map] هي طريقة أخرى للتكرار على `Array`، وهي تُرجع `Array` جديدة تحتوي على نتائج تطبيق الكتلة على كل عنصر.
إنها مشابهة لطريقة `each`، لكنها تُرجع `Array` جديدة بالعناصر المحوّلة.
والتحويل مفيد جدًا عندما تريد تطبيق دالة على كل عنصر من عناصر المجموعة، وهي عملية شائعة.

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  element * 2
end

new_arr
# => [2, 4, 6]
```

وباستخدام تدفق تحكم مثل `if` يمكنك تصفية العناصر التي تريد تحويلها.

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  if element.odd?
    element * 2
  else
    element
  end
end

new_arr
# => [2, 2, 6]
```

### مع الفهرس

أحيانًا تحتاج إلى معرفة فهرس العنصر الذي تتكرر عليه، ويمكنك استخدام طريقة [`each_with_index`][each_with_index] أو [`map_with_index`][map_with_index] لذلك.
إنها تُمرّر كل عنصر وفهرسه إلى كتلة، كما تقبل الطريقة وسيطًا اختياريًا لتحديد فهرس البداية.

```crystal
arr = [1, 2, 3]
arr.each_with_index(4) do |element, index|
  puts "Element: #{element}, Index: #{index}"
end

# Output:
# Element: 1, Index: 4
# Element: 2, Index: 5
# Element: 3, Index: 6
```

لاحظ أن طريقة [`each_char_with_index`][each_char_with_index] متاحة أيضًا لكائنات `String`.

### sum

تُرجع طريقة [`sum`][sum] مجموع كل العناصر في المجموعة، كما تقبل كتلة اختيارية لتحويل العناصر قبل جمعها.
وتقبل أيضًا وسيطًا اختياريًا لتحديد القيمة الأولية للمجموع.

```crystal
arr = [1, 2, 3]
arr.sum
# => 6

arr.sum(2) { |n| n * 2 }
# => 14
```

### reduce

[`reduce`][reduce] أو الطيّ كما يُعرف في لغات أخرى، هي طريقة تقوم، مع طريقة دمج وقيمة أولية، بدمج كل العناصر في المجموعة.
تمتلك طريقة `reduce` مُجمِّعًا يُمرَّر إلى الكتلة، والمُجمِّع هو ناتج التكرار السابق.
وهكذا تصبح عملية استدعاء ذاتي تدمج كل العناصر في المجموعة.

```crystal
arr = [1, 2, 3]
arr.reduce(0) do |acc, n|
  acc + n
end
# => 6
```

قد تبدو `reduce` مشابهة لـ`sum`، لكن `reduce` أكثر مرونة لأنها تتيح لك تحديد القيمة الأولية للمُجمِّع وطريقة الدمج.
ويمكن استخدام `reduce` لتنفيذ `sum` و`count` وطرق أخرى.
