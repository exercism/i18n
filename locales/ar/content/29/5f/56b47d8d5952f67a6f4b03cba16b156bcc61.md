# نبذة

السلاسل النصية في F# كائنات غير قابلة للتغيير، تمثّل نصًا على هيئة تسلسل من محارف يونيكود (حروف، أرقام، علامات ترقيم، وغيرها). تُستخدم علامات الاقتباس المزدوجة لتعريف نسخة من `string`:

```fsharp
let fruit = "Apple"
```

يمكن التعامل مع السلسلة النصية عبر استدعاء إحدى [طرقها][methods] أو [خصائصها][properties]، أو باستخدام إحدى الدوال في [وحدة `String`][string-module]. ولأن قيم السلاسل النصية لا يمكن أن تتغير أبدًا بعد تعريفها، فإن جميع طرق ودوال التعامل مع السلاسل النصية تُرجع سلسلة نصية جديدة.

تُحدَّد السلسلة النصية بعلامات الاقتباس المزدوجة (`"`). تحتاج بعض المحارف الخاصة إلى [الهروب][escaping] باستخدام محرف الشرطة المائلة العكسية (`\`). كما يمكن إضافة الرمز `@` في بداية السلسلة النصية، ما يجعلها [سلسلة نصية حرفية][verbatim] تتجاهل أي محارف تم تهريبها.

```fsharp
let escaped = "c:\\test.txt"
let verbatim = @"c:\test.txt"
escaped = verbatim
// => true
```

بدلًا من ذلك، يمكن تعريف السلاسل النصية باستخدام [علامات الاقتباس الثلاثية][triple-quoted] (`"""`)، ما يتيح استخدام علامة اقتباس مزدوجة داخل السلسلة دون تهريبها.

```fsharp
let tripledQuoted = """<movie title="Se7en" />"""
// => "<movie title="Se7en" />
```

وأخيرًا، يمكن دمج السلاسل النصية عبر [العامل `+`][plus-operator]:

```fsharp
let name = "Jane"
"Hello " + name + "!"
// => "Hello Jane!"
```
