# التعليمات

في هذا التمرين، ستُنظّم سباقات بين أنواع مختلفة من سيارات التحكم عن بُعد. ولكل سيارة سرعتها الخاصة وخصائص استهلاكها للبطارية.

تبدأ السيارات ببطاريات ممتلئة بالكامل (100%). وفي كل مرة تقود فيها السيارة باستخدام جهاز التحكم عن بُعد، تقطع مسافة تساوي سرعة السيارة بالأمتار، وتخفض نسبة البطارية المتبقية بمقدار استهلاكها.

وإذا كانت بطارية السيارة أقل من نسبة استهلاكها، فلن تتمكن من قيادتها بعد ذلك.

لكل حلبة سباق مسافتها الخاصة. ويُختبر كل سيارة بالتحقق مما إذا كانت قادرة على إنهاء الحلبة دون استنفاد بطاريتها.

لديك ست مهام، وستتعامل كل واحدة منها مع نسخ من سيارات التحكم عن بُعد.

## 1. إنشاء سيارة تحكم عن بُعد

اسمح بإنشاء سيارة تحكم عن بُعد من خلال تعريف مُنشئ لصنف `NeedForSpeed` يأخذ سرعة السيارة بالأمتار ونسبة استهلاك البطارية كمعاملَيه الاثنين (وكلاهما من النوع `int`):

```java
int speed = 5;
int batteryDrain = 2;
var car = new NeedForSpeed(speed, batteryDrain);
```

## 2. إنشاء حلبة سباق

اسمح بإنشاء حلبة سباق من خلال تعريف مُنشئ لصنف `RaceTrack` يأخذ مسافة الحلبة بالأمتار كمعامله الوحيد (وهو من النوع `int`):

```java
int distance = 800;
var raceTrack = new RaceTrack(distance);
```

## 3. قُد السيارة

نفّذ طريقة `NeedForSpeed.drive()` التي تحدّث عدد الأمتار المقطوعة بناءً على سرعة السيارة. ونفّذ أيضًا طريقة `NeedForSpeed.distanceDriven()` لتُرجع عدد الأمتار التي قطعتها السيارة:

```java
int speed = 5;
int batteryDrain = 2;
var car = new NeedForSpeed(speed, batteryDrain);
car.drive();

car.distanceDriven();
// => 5
```

## 4. التحقق من استنفاد البطارية

حدّث طريقة `NeedForSpeed.drive()` لتستهلك البطارية بناءً على استهلاك بطارية السيارة. ونفّذ أيضًا طريقة `NeedForSpeed.batteryDrained()` التي تشير إلى ما إذا كانت البطارية مستنفدة إلى حد يمنع القيادة:

```java
int speed = 5;
int batteryDrain = 2;
var car = new NeedForSpeed(speed, batteryDrain);
car.drive();

car.batteryDrained();
// => false
```

## 5. إنشاء سيارة Nitro للتحكم عن بُعد

سيارة التحكم عن بُعد الأكثر مبيعًا هي Nitro، التي تبلغ سرعتها القصوى المذهلة 50 مترًا مع استهلاك بطارية نسبته 4%. نفّذ الطريقة (الثابتة) `NeedForSpeed.nitro()` لتُرجع سيارة من هذا النوع:

```java
var car = NeedForSpeed.nitro();
car.drive();
car.distanceDriven();
// => 50
```

## 6. التحقق من قدرة سيارة تحكم عن بُعد على إنهاء السباق

لإنهاء السباق، يجب أن تكون السيارة قادرة على قطع مسافة السباق. وهذا يعني ألا تستنفد بطاريتها قبل أن تعبر خط النهاية. نفّذ طريقة `RaceTrack.canFinishRace()` التي تأخذ نسخة `NeedForSpeed` كمعامل لها وتُرجع `true` إذا كانت السيارة قادرة على إنهاء السباق، وإلا فتُرجع `false`:

```java
int speed = 5;
int batteryDrain = 2;
var car = new NeedForSpeed(speed, batteryDrain);

int distance1 = 100;
var race1 = new RaceTrack(distance1);

int distance2 = 300;
var race2 = new RaceTrack(distance2);

race1.canFinishRace(car);
// => true

race2.canFinishRace(car);
// => false
```
