# مقدمة

مثل لغات البرمجة الأخرى، توفّر C++ أيضًا جملة `switch`.
جمل `switch` أسلوب أقصر لكتابة جمل `if ... else if` الطويلة.
ولإنشاء جملة `switch`، نبدأ باستخدام الكلمة المفتاحية `switch` متبوعة بعدد صحيح.
ثم نُعرّف كل شرط من الشروط باستخدام الكلمة المفتاحية `case`.
ويمكننا أيضًا تعريف حالة `default`، تُنفَّذ عندما لا يتطابق أي من شروط `case` السابقة.
ويجب أن تنتهي كل حالة بعبارة `break` (أو `return`).

```cpp
int price{0};
int adults{3};
int kids{2};

switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
        break;
    case 2:
        price = 70;
        break;
    default:
        price = group_size * 30;
}
```

## السقوط عبر الحالات

من الأمور المهمة في بنية `switch` أن الكود يستمر في التنفيذ حتى توقفه عبارة `break` (أو `return`).
وقد يؤدي هذا إلى سلوك غير متوقع.

```cpp
int adults{1};
int kids{0};
switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
    case 2:
        price = 70;
    default:
        price = group_size * 30;
}
// price will be 30!
```

الحالة الاستخدامية الرئيسية لميزة التنفيذ المتواصل هذه هي عبارة تحمل عدة تسميات.
يمكن أن تشير عدة نتائج في `switch` إلى نفس الجزء من الكود المراد تنفيذه.
وبهذه الطريقة (في تطبيق حجوزات على سبيل المثال)، يمكن أن تكون الدالة المستدعاة لحجمي المجموعة 2 و3 هي نفسها:
```cpp
switch (group_size) {
case 1:
    book_room();
    break;
case 2:
case 3:
    book_apartment(group_size);
    break;
default:
    book_house(group_size);
}
// book_apartment happens when group_size is 2 or 3
```
