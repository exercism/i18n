# ملحق التعليمات

## تلميحات

عليك تنفيذ الدالة `convert` التي تُرجع العدد محوّلًا إلى صوت قطرات المطر. يمكنك استخدام التوقيع المقدم إذا لم تكن متأكدًا من الأنواع، لكن لا تدعه يقيّد إبداعك:

```haskell
convert :: Int -> String
```

يتعامل هذا التمرين مع البيانات النصية. ولأسباب تاريخية، فإن النوع `String` في Haskell مرادف لـ `[Char]`، وهو مصفوفة من المحارف. ولمعالجة البيانات النصية بكفاءة أكبر، يمكن استخدام النوع `Text`.

كإضافة اختيارية إلى هذا التمرين، يمكنك

- أن تقرأ عن [أنواع السلاسل النصية](https://haskell-lang.org/tutorial/string-types) في Haskell.
- أن تضيف `- text` إلى قائمة الاعتماديات لديك في package.yaml.
- أن تستورد `Data.Text` [بالكيفية التالية](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- أن تكتب الآن مثلًا `convert :: Int -> Text` وتشير إلى تركيبات `Data.Text` مثل `T.pack`.
- أن تبحث عن الوثائق الخاصة بـ [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html)،
- أن تستبدل بعد ذلك كل مواضع `String` بـ `Text` في Raindrops.hs:

```haskell
convert :: Int -> Text
```

هذا الجزء اختياري بالكامل.
