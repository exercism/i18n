# الاختبارات

## تشغيل الاختبارات

لتشغيل الاختبارات، نفّذ الأمر التالي:

```bash
bats test-<exercise-slug>.bats
```

### أداة bats مكتوبة بلغة bash

ملف `bats` هو سكربت مكتوب بلغة bash، ويضم بعض الدوال الخاصة التي يتعرّف عليها الأمر `bats`.
وسترى بعض الاختبارات التي تبدو هكذا:

```bash
sed -E -f <exercise-slug>.sed <<< "$input"
```

صيغة `<<<` هذه هي *Here String* في bash.
وهي تُرسل السلسلة النصية الواقعة على يمينها إلى المدخل القياسي للبرنامج الواقع على يسارها.
وهي مكافئة تقريبًا لما يلي:

```bash
echo "$input" | sed -E -f <exercise-slug>.sed
```

## الاختبارات المتخطّاة

حلّ أي تمرين يعني جعل جميع اختباراته تنجح.
بشكل افتراضي، يُنفَّذ اختبار واحد فقط (الأول) عند تشغيل الاختبارات.
وهذا مقصود، فهو يتيح لك التركيز على جعل ذلك الاختبار الواحد ينجح فقط.
وبمجرد أن ينجح، يمكنك تمكين الاختبار التالي بتعليق أو حذف

    [[ $BATS_RUN_SKIPPED == true ]] || skip

التعليقات التي تسبق الاختبارات الأخرى.

## تجاوز التخطّي

لتشغيل جميع الاختبارات، بما فيها تلك التي تحمل تعليقات `skip`، يمكنك تنفيذ:

```bash
BATS_RUN_SKIPPED=true bats test-<exercise-slug>.bats
```

أو يمكنك تعليق السطر التالي أو حذفه:

```bash
[[ $BATS_RUN_SKIPPED == "true" ]] || skip
```

من ملف الاختبار.
