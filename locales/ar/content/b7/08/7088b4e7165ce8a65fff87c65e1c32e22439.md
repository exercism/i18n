# مقدمة

توفّر Swift تنويعًا في صياغتها عند التعامل مع الإغلاقات، يُعرف باسم الإغلاقات اللاحقة. تنشأ الإغلاقات اللاحقة عندما يكون آخر معامل في قائمة معاملات الدالة من نوع دالة. في هذه الحالة، عند تمرير إغلاق، يمكن كتابة الإغلاق _بعد_ القوس الهلالي المغلق وتُحذف تسمية الوسيط. لاحظ أنه إذا كان للدالة معامل واحد فقط، فيمكن حذف الأقواس الهلالية تمامًا.

```swift
func fetchURL(_ urlString: String,
              uponReceipt handleResult: (String) -> ()
             )  -> () {
  if let url = URL(string: urlString), let htmlString = fetch(url) {
    handleResult(htmlString)
  }
}

fetchURL("https://www.swift.org") { print($0) }
// prints the fetched html string

["apple", "ball", "carrot"].sorted { $0.count < $1.count }
```
