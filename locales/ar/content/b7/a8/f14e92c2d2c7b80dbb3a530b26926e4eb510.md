# الطباعة

تتيح لك الطباعة في Cairo عرض الرسائل والقيم في وحدة التحكم، ما يسهّل تصحيح أخطاء البرامج وإيصال المعلومات أثناء التنفيذ.

نظام الطباعة مرن وبسيط في الوقت نفسه، إذ يوفّر أدوات لتنسيق البيانات بمختلف أنواعها وإخراجها.

## أساسيات الطباعة

يوفّر Cairo ماكروين أساسيين لطباعة النص في وحدة التحكم:

- **`println!`**: يطبع الناتج في سطر جديد.
- **`print!`**: يطبع الناتج في السطر نفسه، دون إضافة سطر جديد.

يأخذ كلا الماكروين `ByteArray` بوصفه الوسيط الأساسي، ويمكن أن يكون سلسلة نصية بسيطة أو سلسلة نصية منسّقة تحوي عناصر نائبة للقيم.

```rust
// Printing a simple message
println!("Hello, Cairo!");

// Printing with values
let x = 10;
let y = 20;
println!("Values: x = {}, y = {}", x, y);
```

في المثال أعلاه:

- تُستبدل العناصر النائبة `{}` بقيمتي `x` و `y`.
- يضمن `println!` أن ينتهي الناتج بسطر جديد.

## تنسيق السلاسل النصية

قد تحتاج أحيانًا إلى إنشاء سلسلة نصية منسّقة دون طباعتها فورًا.

يتيح لك الماكرو `format!` فعل ذلك.

إنه يعمل بطريقة مشابهة لـ `println!`، لكنه يُرجع `ByteArray` بدلًا من إرسال الناتج إلى وحدة التحكم.

```rust
let s1: ByteArray = "tic";
let s2: ByteArray = "tac";
let s3: ByteArray = "toe";

// Create a formatted string
let result = format!("{s1}-{s2}-{s3}");

println!("{}", result); // Output: tic-tac-toe
```

في هذا المثال:

- يجمع `format!` بين `s1` و `s2` و `s3` في سلسلة نصية واحدة، ويفصل بينها بشرطات (`-`).
- ويمكن إعادة استخدام السلسلة النصية الناتجة أو طباعتها لاحقًا.

## طباعة أنواع البيانات المخصصة

افتراضيًا، لا يستطيع Cairo طباعة سوى الأنواع الأساسية مثل الأعداد الصحيحة والسلاسل النصية.

إذا حاولت طباعة نوع مخصص، مثل البنية، فستصادف خطأً ما لم ينفّذ النوع سمتَي `Display` أو `Debug`.

### استخدام `Display` لتنسيق مخصص

تتيح لك السمة `Display` تحديد كيفية طباعة نوع مخصص.

إليك مثال:

```rust
use core::fmt::{Display, Formatter, Error};

struct Point {
    x: u8,
    y: u8,
}

impl PointDisplay of Display<Point> {
    fn fmt(self: @Point, ref f: Formatter) -> Result<(), Error> {
        write!(f, "Point({}, {})", *self.x, *self.y)
    }
}

let p = Point { x: 3, y: 4 };
println!("{}", p); // Output: Point(3, 4)
```

في هذا المثال:

- تحدّد الدالة `fmt` كيفية تحويل بنية `Point` إلى سلسلة نصية قابلة للطباعة.
- ويضيف الماكرو `write!` السلسلة النصية المنسّقة إلى `Formatter`.

### تصحيح الأخطاء باستخدام `Debug`

لأغراض تصحيح الأخطاء، يوفّر Cairo السمة `Debug`.

ويمكنك اشتقاقها تلقائيًا لمعظم الأنواع، ما يجعل طباعة التفاصيل الداخلية لبنياتك سريعة وسهلة.

```rust
#[derive(Debug)]
struct Point {
    x: u8,
    y: u8,
}

let p = Point { x: 3, y: 4 };
println!("{:?}", p); // Output: Point { x: 3, y: 4 }
```

في هذا المثال:

- يولّد `#[derive(Debug)]` تنفيذ السمة `Debug` تلقائيًا.
- ويخبر العنصر النائب `{:?}` الماكرو `println!` باستخدام السمة `Debug` للتنسيق.

## الطباعة بالنظام الست عشري

يتيح Cairo طباعة الأعداد الصحيحة بصيغة ست عشرية باستخدام العنصر النائب `{:x}`.

```rust
let value: u32 = 255;
println!("{:x}", value); // Output: ff
```

وهذا مفيد بشكل خاص عند التعامل مع تمثيلات البيانات منخفضة المستوى.
