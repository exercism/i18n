# أنواع الأعداد

توفّر Crystal مجموعة متنوعة من أنواع الأعداد المختلفة لأغراض متعددة.
فعلى سبيل المثال، بعض الأنواع أسرع لكن نطاق قيمها الممكنة أصغر من غيرها.
وبعضها له نطاق أوسع من القيم الممكنة لكنه أبطأ.

في Crystal، توجد أنواع أعداد صحيحة مُوقّعة وأنواع غير مُوقّعة.
يمكن أن تكون الأعداد الصحيحة المُوقّعة موجبة أو سالبة.
أما الأعداد الصحيحة غير المُوقّعة فلا يمكن أن تكون إلا موجبة.

## أنواع الأعداد الصحيحة المُوقّعة

هذه هي [أنواع الأعداد الصحيحة المُوقّعة][int] في Crystal:

| Type     | Size (bits) | Range                                                                                                       |
| -------- | ----------- | ----------------------------------------------------------------------------------------------------------- |
| `Int8`   | 8           | -128 إلى 127                                                                                                 |
| `Int16`  | 16          | -32_768 إلى 32_767                                                                                           |
| `Int32`  | 32          | -2_147_483_648 إلى 2_147_483_647                                                                             |
| `Int64`  | 64          | -9_223_372_036_854_775_808 إلى 9_223_372_036_854_775_807                                                     |
| `Int128` | 128         | -170_141_183_460_469_231_731_687_303_715_884_105_728 إلى 170_141_183_460_469_231_731_687_303_715_884_105_727 |

تستهلك الأنواع الأصغر ذاكرة أقل وتكون أسرع من الأنواع الأكبر، لكن نطاق قيمها الممكنة أصغر.

حين تعلم أن القيم ستبقى ضمن نطاق معيّن، فمن الأفضل استخدام أصغر نوع ممكن لتوفير الذاكرة وتحسين الأداء.

النوع الافتراضي للأعداد الصحيحة هو `Int32`.
لتعريف عدد صحيح بنوع محدّد، يمكنك استخدام اسم النوع كلاحقة بإضافة `<number>_I <bit>`.

```crystal
1_i8.class
# => Int8
```

يمكنك استخدام الطريقة `to_i<bit>` للتحويل بين أنواع الأعداد الصحيحة المختلفة.
تحوّل الطريقة `to_i` إلى النوع الافتراضي للأعداد الصحيحة، وهو `Int32`.

```crystal
1_i8.to_i16.class
# => Int16

2_i16.to_i.class
# => Int32
```

## أنواع الأعداد الصحيحة غير المُوقّعة

هذه هي أنواع [الأعداد الصحيحة غير المُوقّعة][uint] في Crystal:

`UInt8`، `UInt16`، `UInt32`، `UInt64`، `UInt128`

الفرق الوحيد بين الأعداد الصحيحة المُوقّعة وغير المُوقّعة هو أن غير المُوقّعة لا يمكن أن تكون إلا موجبة.
لتعريف عدد صحيح غير مُوقّع بنوع محدّد، يمكنك استخدام اسم النوع كلاحقة بإضافة `<number>_u<bit>`.
يمكنك استخدام الطريقة `to_u<bit>` للتحويل بين أنواع الأعداد الصحيحة غير المُوقّعة المختلفة.
تحوّل الطريقة `to_u` إلى النوع الافتراضي للأعداد الصحيحة غير المُوقّعة، وهو `UInt32`.

```crystal
1_u8.to_u16.class
# => UInt16
```

## أنواع أعداد الفاصلة العائمة

هذه هي أنواع أعداد الفاصلة العائمة في Crystal:

| Type      | Size (bits) | Range                |
| --------- | ----------- | -------------------- |
| `Float32` | 32          | 1.2E-38 إلى 3.4E+38   |
| `Float64` | 64          | 2.3E-308 إلى 1.7E+308 |

يوجد نوعان مختلفان من [أعداد الفاصلة العائمة][float]، أحدهما أكثر دقة من الآخر.

النوع الافتراضي لأعداد الفاصلة العائمة هو `Float64`.

يمكنك استخدام الطريقة `to_f<bit>` للتحويل بين أنواع أعداد الفاصلة العائمة المختلفة.
تحوّل الطريقة `to_f` إلى النوع الافتراضي لأعداد الفاصلة العائمة، وهو `Float64`.

## النوع الناتج بعد عملية

عند تنفيذ عملية بين عددين، تكون النتيجة من نوع العدد الأعلى دقة.
أعداد الفاصلة العائمة أكثر دقة من الأعداد الصحيحة، والعدد الصحيح أكثر ضبطًا من العدد الصحيح غير المُوقّع.
ثم إن `Float64` أكثر دقة من Float32، وهكذا.

```crystal
(1_u8 + 2_u64).class
# => UInt64

(1_u8 + 2_i64).class
# => Int64

(1_u8 + 2.0_f64).class
# => Float64
```

## تعمّق أكثر: الأعداد الصحيحة غير المُوقّعة مقابل المُوقّعة

~~~~exercism/advanced
من وراء الكواليس، ما يميّز الأعداد الصحيحة غير المُوقّعة عن المُوقّعة هو أن المُوقّعة تستخدم البت الأول لتخزين الإشارة.
وتكون الإشارة إما موجبة وإما سالبة.
أما في الأعداد الصحيحة غير المُوقّعة، فيُستخدم البت الأول لتخزين القيمة.
لذا فإن القيمة العظمى لعدد صحيح مُوقّع بسعة 32 بت هي 2^31 - 1.
وبالنسبة لعدد صحيح غير مُوقّع بسعة 32 بت، فإن القيمة العظمى هي 2^32 - 1.

إذا أردت معرفة المزيد عن مفهوم الإشارة في الأعداد، يمكنك القراءة عنه على [ويكيبيديا](https://en.wikipedia.org/wiki/Signedness).
~~~~
