# مقدمة

## النسخ والمراجع

بما نعرفه حتى الآن، يكون تحديث متغير بمساعدة دالة مُرهقًا بعض الشيء.
فكل وسيط يُمرَّر إلى دالة يُعالَج كنسخة، ولا يغيّر القيمة الأصلية.
واعتمادًا على حجم النوع الذي تستخدمه، قد تكون لهذا عواقب وخيمة على أداء الكود.

```cpp
int adjust_salary(int base, int kids) {
    return base + kids * 500;
}
int now_a_mother_of_twins{2500};
adjust_salary(now_a_mother_of_twins, 2);

// now_a_mother_of_twins is still 2500
now_a_mother_of_twins = adjust_salary(now_a_mother_of_twins, 2);
// now_a_mother_of_twins is now 3500
```

يمكن النظر إلى `References` على أنها أسماء بديلة، فالتغييرات التي تجري عليها تؤثر على المتغير الأصلي.
وتستعين `References` بـ**علامة العطف** (`&`) في تعريف النوع.

```cpp
int balance{1000};
int& budget{balance};
int pro_computer_wheels{699};
budget -= pro_computer_wheels;
// budget is now 301;
// balance is also 301;
```

لا يمكن إعادة الربط (أي تغيير ارتباط `reference`).
ولا يمكن أن يكون لديك `reference` غير مُهيَّأ.
يجب تهيئة `References` بمتغير موجود.

```cpp
int main_acc{1'000'000};
int side_acc{-20};
int& savings{main_acc};
// => main_acc and savings are 1'000'000

// try to reseat savings to use main account
savings = side_acc;
// savings and main_acc are now -20
// as this uses the **value** of side_acc
savings += 20;
// savings and main_acc are now 0, side_acc is stil -20

int& future_budget;
// => compiler error, reference must be bound!
```

## `void`

بفضل قوة `references`، قد لا تحتاج إلى إرجاع قيمة من دالة على الإطلاق.
وفي هذه الحالة يُستخدم `void` كنوع للإرجاع.

```cpp
void increase_power(int& level) {
    level += 500;
}
int goku{8700};
increase_power(goku);
// goku's power level?
// It's over 9000!
```
