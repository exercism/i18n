# مقدمة

في Haxe، تُعدّ الاستثناءات أسلوبًا آمنًا للتعامل مع الأخطاء التي تحدث عند تشغيل الكود. يجب أن تحتوي جميع الاستثناءات على رسالة تصف الخطأ. يمكننا _رمي_ الاستثناءات باستخدام الكلمة المفتاحية `throw`:

```haxe
public function main(num:Int) {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
  // ...
}
```

عند رمي استثناء، يبحث الكود عن جزء مُكلَّف بمعالجة الخطأ. وإذا لم يجد أي جزء، فسيعرض رسالة الخطأ مع إيقاف تنفيذ البرنامج أيضًا.

لمعالجة الاستثناءات في Haxe، نستخدم كتلة `try-catch`. تتكوّن عبارة الكتلة هذه من كتلة `try` واحدة وكتلة `catch` واحدة أو أكثر. تحاول كتلة `try` تنفيذ جزء من الكود، بينما تنتظر كتلة `catch` في حال رُمي استثناء لتلتقطه، حتى لا يتوقف التنفيذ. وعندما تلتقط كتلة `catch` استثناءً، فإنها تنفّذ أيضًا كل ما داخل الكتلة:

```haxe
try {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
} catch (e) {
  // All exceptions will be caught here
  trace(e.message); // Argument num cannot be greater than 10
}
```

يجب حذف نوع وسيط كتلة `catch`.
