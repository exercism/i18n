# مقدمة

## حلقات `for`

عبارة `for` تكرّر تنفيذ كتلة من الكود.
ويتحكم سطرها الأول في عدد مرات تكرار هذه الكتلة:

```go
for init; condition; post {
    // loop body
}
```

- عبارة **التهيئة** تُنفَّذ مرة واحدة قبل التكرار الأول. ومن الشائع أن تُعلن متغير عدّاد وتُهيّئه لتستخدمه الحلقة.
- **الشرط** تعبير منطقي يُقيَّم قبل كل تكرار. وتتوقف الحلقة عندما يُقيَّم هذا التعبير إلى `false`.
- عبارة **الخطوة اللاحقة** تُنفَّذ بعد اكتمال كل تكرار. ويمكن استخدامها لتحديث العدّاد.

لا تُحِط `init; condition; post` بأقواس هلالية.
ومع ذلك، فإن الأقواس المعقوفة `{ }` التي تحيط بجسم الحلقة مطلوبة دائمًا.

تبدأ هذه الحلقة قيمة `i` من `1`، وتطبع القيمة الحالية لـ `i`، وتزيدها استعدادًا للتكرار التالي، وتتوقف عندما يصل `i` إلى `10`:

```go
for i := 1; i < 10; i++ {
    fmt.Println(i)
}
```
