# الدوال الجالبة والضابطة

الدوال الجالبة والضابطة هي طرق تتيح لك قراءة قيمة خاصية كائن وكتابتها.
تمتلك Crystal وحدات ماكرو، وهو ما يسهّل تعريف الدوال الجالبة والضابطة لخاصية.
وحدات الماكرو وسيلة لتوليد الكود في وقت الترجمة، وسنغطي ذلك لاحقًا في مفهوم الماكرو.

في Ruby تُعرَّف هذه الطرق باستخدام الطرق `attr_reader` و`attr_writer` و`attr_accessor`، وهي تشبه إلى حد كبير ما تنفّذه Crystal من حيث المظهر.
وقد عرّفت Crystal هذه كوحدات ماكرو: `getter` و`setter` و`property`.

## الدوال الجالبة

الماكرو `getter` يُعرّف طريقة تُرجع قيمة متغير النسخة.
وهذا يعني أنك لم تعد مضطرًا لكتابة `@` قبل متغير النسخة عندما تريد الوصول إليه (داخل الطرق، باستثناء `initialize`)؛ بدلًا من ذلك يمكنك استدعاء الطريقة التي عرّفها ماكرو `getter`.

يمكن لماكرو `getter` أن يقبل عدة متغيرات نسخة عند فصلها بفواصل.

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name
    @name
  end

  def age
    @age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  getter name, :age
end
```

كما ترى، استخدام `getter` يقلّل مقدار الكود الذي تكتبه ويجعل قراءته أسهل.
كذلك تختلف Ruby عن Crystal في أن Crystal تقبل اسم المتغير والرمز معًا كوسيطين لماكرو `getter`.
وسنغطي الرموز لاحقًا في مفهوم الرمز.

## الدوال الضابطة

الماكرو `setter` يُعرّف طريقة تُسند قيمة إلى متغير النسخة.
هذا الماكرو ليس شائعًا كثيرًا، وغالبًا يُستخدم ماكرو `property` بدلًا منه.
ستبدو الطرق التي ستُنشأ على الشكل `name_of_method=`؛ والعلامة `=` هي ما يسمح بإسناد قيمة إلى الخاصية.

تعريف هذه الطريقة خاص بعض الشيء، لأن الوسيط الذي تستقبله الطريقة يأتي بعد علامة `=`.
وتستخدم طرق خاصة أخرى في Crystal هذا التركيب، مثل الطريقة `+`.

وكما في ماكرو `getter`، عندما تريد تحديث قيمة متغير النسخة بعد تعريف `setter`، يمكنك استدعاء الطريقة التي عرّفها ماكرو `setter`.

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name=(name : String)
    @name = name
  end

  def age=(age : Int32)
    @age = age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  setter name, :age
end
```

## الخاصية

ماكرو `property` يُعرّف كلاً من الدالة الجالبة والدالة الضابطة لمتغير النسخة.

```crystal
class Person
  @name : String
  @age : Int32

  property name, :age
end
```
