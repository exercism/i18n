# حول

**إعلانات أنواع الاتحاد**، المتاحة بدءًا من `PHP 8.0.0`، تقبل قيمًا من أنواع مختلفة متعددة، بدلًا من نوع واحد. تُنشأ تعريفات أنواع الاتحاد باستخدام رمز الأنبوب (`|`) للفصل بين الأنواع.

```php
function add(int|float $a, int|float $b): int|float
{
    return $a + $b;
}
```

## الفروق الدقيقة

- يمكن الإعلان عن الأنواع `null` على أنها _قابلة لأن تكون `null`_ إما باستخدام `?Type` أو `Type1|Type2|null`.
- الأنواع المكررة أو الزائدة المعلنة ستؤدي إلى خطأ في وقت الترجمة.
- لا يمكن استخدام `void` كجزء من إعلان نوع الاتحاد.
