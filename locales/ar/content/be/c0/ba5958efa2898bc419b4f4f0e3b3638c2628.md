# نبذة

*التعبير النمطي* (regex) هو نمط صغير يصف شكل نصٍّ ما. توجد أدوات التعبير النمطي في Factor ضمن مفردات [`regexp`][regexp]، ويُكتب النمط كصيغة حرفية بين `R/ ` و`/`.

معظم المحارف في النمط تطابق نفسها. أما القوة التعبيرية فتأتي من أصناف المحارف والمكمِّمات:

```
\d        ! a digit 0–9            \s   ! whitespace
\D        ! any non-digit          \S   ! non-whitespace
[A-Z]     ! one capital letter     .    ! any one character
[^0-9]    ! any char except a digit

{4}       ! exactly 4              +    ! one or more
{2,5}     ! between 2 and 5        *    ! zero or more
?         ! optional               |    ! either side (alternation)
```

فالنمط `R/ [A-Z]{2}-\d{4}/` يطابق "حرفين كبيرين، ثم شرطة، ثم أربعة أرقام".

## مطابقة السلسلة النصية كاملةً مقابل البحث

لا ينجح `matches?` إلا عندما تطابق *السلسلة النصية بأكملها* النمط. أما الكلمات الأخرى فتبحث *داخل* السلسلة النصية:

```
matches?             ( string regexp -- ? )
re-contains?         ( string regexp -- ? )
count-matches        ( string regexp -- n )
all-matching-subseqs ( string regexp -- seq )
first-match          ( string regexp -- slice/f )
re-split             ( string regexp -- seq )
re-replace           ( string regexp replacement -- result )
```

```factor
USING: regexp ;

"NS-1024" R/ [A-Z]{2}-\d{4}/ matches? .         ! => t
"id NS-1024 ok" R/ [A-Z]{2}-\d{4}/ matches? .   ! => f   (extra text)
"id NS-1024 ok" R/ [A-Z]{2}-\d{4}/ re-contains? .   ! => t

"a1b2c3" R/ \d/ count-matches .   ! => 3
"a1b2c3" R/ \d/ re-replace .      ! NOTE: see re-replace below
```

## المقاطع

`first-match` و`re-split` تُرجعان كائنات `slice`، وهي عروض خفيفة داخل السلسلة النصية الأصلية لا سلاسل نصية جديدة. حوّل كائن `slice` باستخدام `>string` عندما تحتاج إلى سلسلة نصية مستقلة (مثلًا لمقارنتها بسلسلة نصية حرفية). أما `all-matching-subseqs` فتُرجع سلاسل نصية بالفعل.

## الاستبدال

تستبدل `re-replace` كل مطابقة بسلسلة نصية بديلة وتُرجع النتيجة:

```factor
USING: regexp ;

"user=alice pass=hunter2" R/ pass=\S+/ "pass=****" re-replace .
! => "user=alice pass=****"
```

## بناء نمط أثناء التشغيل

يُحلَّل `R/ /` عند تحميل الملف. ولبناء نمط من سلسلة نصية تُحسَب أثناء التشغيل، استخدم `<regexp>`:

```
<regexp> ( string -- regexp )
```
