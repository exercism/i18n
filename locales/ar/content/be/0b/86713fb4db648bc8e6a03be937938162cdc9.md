# مقدمة

في Go، تُكرِّر حلقة `for range` كتلةً من الكود لقيم تأتي من تعبير `range`. ويحدد تعبير `range` ما إذا كان كل تكرار سيُنتج قيمة واحدة أم قيمتين.

## تعبيرات `range`

### `range` على شريحة

يُنتج `range` على شريحة فهرس كل عنصر وقيمته بالترتيب:

```go
vals := []int{10, 20, 30}
for i, v := range vals {
    fmt.Println(i, v)
}
// 0 10
// 1 20
// 2 30
```

### `range` على خريطة

يُنتج `range` على خريطة كل مفتاح وقيمته، لكن ترتيب التكرار غير مضمون.
وتجعل لغة Go ترتيب التكرار على الخرائط عشوائيًا عمدًا، لذا قد يُنتج البرنامج نفسه مخرجات مختلفة في كل تشغيل.

```go
hash := map[int]int{9: 10, 99: 20, 999: 30}
for k, v := range hash {
    fmt.Println(k, v)
}
// 99 20
// 999 30
// 9 10
```

### `range` على سلسلة نصية

يُنتج `range` على سلسلة نصية فهرس البايت وكل `rune` (أي نقطة كود في Unicode).
في المثال التالي، يشغل `子` ثلاثة بايتات، لذا يبدأ `猫` عند فهرس البايت `3` وليس `1`.

```go
for i, r := range "子猫" {
    fmt.Println(i, r, string(r))
}
// 0 23376 子
// 3 29483 猫
```

إذا كنت بحاجة إلى فهارس `rune` بدلًا من ذلك، فحوّل السلسلة النصية إلى شريحة من قيم `rune`:

```go
for i, r := range []rune("子猫") {
    fmt.Println(i, r, string(r))
}
// 0 23376 子
// 1 29483 猫
```

### `range` على عدد صحيح

يمكن استخدام `range` للتكرار على عدد صحيح مباشرةً، فيُنتج قيمًا تبدأ من `0` وتصل إلى العدد نفسه دون أن تشمله.
القيم صفر والسالبة صالحة، لكنها لا تُنتج أي تكرار.

```go
for n := range 3 {
    fmt.Println(n)
}
// 0
// 1
// 2
```

### `range` على مُكرِّر

يقبل `range` مُكرِّرًا من النوع `iter.Seq[V]` أو `iter.Seq2[K, V]`.
والمُكرِّر دالة تُنتج تسلسلًا من القيم، قيمةً تلو الأخرى. ثم يمكن لـ `range` أن يمر عبر تلك القيم.

```go
text := "The quick brown fox"
for word := range strings.FieldsSeq(text) {
    fmt.Println(word)
}
// The
// quick
// brown
// fox

names := []string{"Alice", "Bob", "Vera"}
for i, v := range slices.All(names) {
    fmt.Println(i, ":", v)
}
// 0 : Alice
// 1 : Bob
// 2 : Vera
```

### `range` على قناة

أخيرًا، يمكن لـ `range` استقبال القيم المُرسَلة عبر قناة حتى تُغلق تلك القناة في مكان آخر.
وسيُغطّى موضوع القنوات بمزيد من التفصيل لاحقًا في منهج المسار.

## حذف الفهرس أو القيمة

لن تُصرّف لغة Go الكود إذا عُرِّف متغير ولم يُستخدم قط.

```go
vals := []int{10, 20, 30}
for i, v := range vals {
    fmt.Println(v)
}
// Go build failed: declared and not used: i
```

إذا كنت بحاجة إلى القيمة فقط، فأسند الفهرس أو المفتاح إلى `_` لتتجاهله.

```go
vals := []int{10, 20, 30}
for _, v := range vals {
    fmt.Println(v)
}
// 10
// 20
// 30
```

وإذا كنت بحاجة إلى الفهرس فقط، فاحذفه تمامًا:

```go
vals := []int{10, 20, 30}
for i := range vals {
    fmt.Println(i)
}
// 0
// 1
// 2
```

وإذا لم تكن بحاجة إلى الفهرس ولا إلى القيمة، فيمكن حذف كليهما:

```go
vals := []int{10, 20, 30}
count := 0
for range vals {
    count++
}
// count == 3
```
