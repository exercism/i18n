# مقدمة

في Haxe، النوع المجرد هو نوع يكون مختلفًا في وقت التشغيل. وهو ميزة تعمل في وقت الترجمة، وتُعرّف أنواعًا "فوق" أنواع ملموسة بهدف تعديل سلوكها أو توسيعه:

```haxe
abstract AbstractInt(Int) {
    inline public function new(i:Int) {
        this = i;
    }
}
```

هنا نُعرّف النوع `AbstractInt` باستخدام الكلمة المفتاحية `abstract`. وصياغته شديدة الشبه بصياغة `class`. وكما هي الحال مع الأصناف، يمكن أن تمتلك الأنواع المجردة طرقًا. ويمكن أيضًا إنشاء كائنات منها واستخدامها تمامًا كالأصناف:

```haxe
class Main {
    static public function main() {
        var a = new AbstractInt(12);
        trace(a); // 12
    }
}
```
