# https://www.php.net/manual/en/language.basic-syntax.phptags.php"عامل تحديد النطاق

يتيح لنا عامل تحديد النطاق (`::`) الإشارة إلى صنف ما للوصول إلى ثوابته الاسمية، أو خصائصه الساكنة، أو طرقه الساكنة.

```php
class MyClass
{
  public const MY_VALUE = 1;
}

// MyClass::class => "MyClass"
// MyClass::MY_VALUE => 1
```

## استخدام `self` و `static` مع عامل تحديد النطاق

قد يحتاج الكائن إلى الإشارة إلى نطاقه الخاص. ولتسهيل ذلك، تتيح الكلمة المفتاحية `self` للصنف الإشارة إلى نطاقه الخاص. واستخدام الكلمة المفتاحية `self` يفصل الصنف عن اسمه، ما يسهّل صيانة الكود مع الوقت.

```php
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return self::MY_VALUE;
  }
}

// (new MyClass)->getMyValue() => 1
```

غير أن `self` مرتبط معجميًا بالصنف الذي يظهر فيه.

```php
class MyOtherClass extends MyClass
{
  public const MY_VALUE = 99;
}

// (new MyOtherClass)->getMyValue() => 1
```

لا يزال تقييم `MyOtherClass::getMyValue` يعطي `1` بدلًا من `99`. وللتعامل مع ذلك، استخدم الكلمة المفتاحية `static` مع عامل تحديد النطاق لـ«ربط متأخر» للإشارة بالصنف الحالي المشتق.

```php
// Update MyClass:
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return static::MY_VALUE;
  }
}
```

## استخدام `parent` مع عامل تحديد النطاق

قد نحتاج إلى الإشارة تحديدًا إلى ثابت أو خاصية أو طريقة متاحة من النطاق الأب:

```php
class MyClass
{
  public function getMaximum(): int
  {
    return 5;
  }
}

class AnotherClass extends MyClass
{
  public function getMaximum(): int
  {
    return parent::getMaximum() * 2;
  }
}

// (new AnotherClass())->getMaximum() => 10
```

وفي البرمجة كائنية التوجه، يُستخدم `parent` في الأغلب لاستدعاء البانية الخاصة بالصنف الأب عند إنشاء كائن:

```php
class ChildClass extends ParentClass
{
  public function __construct(): void
  {
    parent::__construct();
  }
}
```

## تنبيهات

### رؤية الثوابت والخصائص والطرق

لا يزال عامل تحديد النطاق يتبع القواعد التي تضعها محددات الرؤية `public` و `private` و `protected`.
