# نبذة

`List` شبيه جدًا بـ [`Array`][array]. لكن هناك فروق جوهرية لا تريد أن تفوّتها:

1. لا يمكن فهرسة `List` باستخدام الأقواس المربعة، أي `[0]`.
2. لا يمكن تهيئة `List`.
3. لا توجد تعبيرات استيعابية لـ `List`.
4. يمكن لـ `List` تعديل عناصرها بحرية أثناء التكرار عليها.

`List` عضو في حزمة `haxe.ds`، لذا كلما أردت استخدام `List`، تحتاج إلى استيراد حزمتها:

```haxe
import haxe.ds.List;

class Main {
  static function main() {
    var myList = List<Int>();

    for (i in 0...5) {
      myList.add(i);
    }

    trace(myList); // {0, 1, 2, 3, 4}
  }
}
```

[array]: https://haxe.org/manual/std-Array.html
