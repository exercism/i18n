# مقدمة

## عوامل المقارنة

عوامل المقارنة مشابهة لتلك الموجودة في كثير من اللغات الأخرى.

للتساوي، العاملان هما `==` (يساوي) و`!=` (لا يساوي).

```Kotlin
val txt = "abc"
txt == "abc" // => true
txt != "abc" // => false
```

عوامل أكبر من وأصغر من مألوفة أيضًا.

```Kotlin
1 < 3 // => true
3 > 3 // => false
3 <= 3 // => true
4 >= 3 // => true
```

## التفريع باستخدام `if`

هذه هي الصيغة الكاملة لتعبير `if`:

```Kotlin
if (conditional1) {
//    something...
} else if (conditional2) {
//    something...
} else {
//    something...
}
```

- الأقواس الهلالية `()` حول كل شرط ضرورية.
- يجب أن يُقيَّم الشرط إلى قيمة منطقية، إما `true` أو `false`.
  لا يوجد في Kotlin مفهوم «القيم الصادقة» و«القيم الكاذبة» الموجود في بعض اللغات.
- الأقواس المعقوفة `{}` اختيارية إذا كان هناك تعبير واحد فقط.
- كلٌّ من `else if` و`else` اختياري، ويمكن أن توجد عدة كتل من `else if`.

يمكن أيضًا استخدام تعبير `if` لـ«اختيار» قيمة:

```Kotlin
val number = 100000
val description = if (number > 100) "number is over 100" else "number is less than 100"
// => description = "number is over 100"
```

## بدائل؟

باختيار متعمد، لا يحتوي Kotlin على العامل الثلاثي `? :` الموجود في Java، بل يُفضَّل الشكل المختصر لـ`if ... else`:

```Kotlin
return if (isOK) goodValue else badValue
```
