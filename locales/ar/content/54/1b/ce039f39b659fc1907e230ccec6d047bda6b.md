# نبذة

الأعداد العشرية هي أعداد لها رقم واحد أو أكثر بعد الفاصلة العشرية.

```gleam
let float = 3.45
// -> 3.45
```

للأعداد العشرية أيضًا مجموعتها الخاصة من العوامل.

```gleam
1.0 +. 1.4 // -> 2.4
5.0 -. 1.5 // -> 3.5
5.0 /. 2.0 // -> 2.5
3.0 *. 3.1 // -> 9.3

2.0 >. 1.0  // -> True
2.0 <. 1.0  // -> False
2.0 >=. 1.0 // -> True
2.0 <=. 1.0 // -> False
```

يمكن أيضًا إضافة الشرطات السفلية إلى الأعداد العشرية لمزيد من الوضوح.

```gleam
1_000_000.0 // One million
```

يمكن أيضًا استخدام الترميز العلمي مع الأعداد العشرية:

```gleam
1.01e3 // -> 1010
15.1e-3 // -> 0.0151
```
