# مقدمة إلى الحساب في صدفة Bash

يمكن لـ Bash إجراء الحساب، لكن _بالأعداد الصحيحة فقط_.
إذا احتجت إلى إجراء حسابات بالفاصلة العائمة، فستحتاج إلى الاستعانة ببرنامج خارجي (مثل [awk][awk] أو [bc][bc]).

عوامل الحساب مُدرجة (بحسب أسبقية التنفيذ) في الدليل: [حساب الصدفة][arithmetic].

بالإضافة إلى ذلك، لا تُجري Bash الحساب إلا في مواضع معينة (تُعرف بـ«سياقات الحساب»).

## التوسيع الحسابي

يبدو التوسيع الحسابي مثل [استبدال الأوامر][cmd-sub]، لكن بأقواس مزدوجة.

```bash
$(( expression ))
```

يتوسّع هذا التركيب إلى نتيجة تقييم التعبير.
ويُستخدم عادةً لالتقاط النتيجة في متغير:

```bash
x=$(( 3 + 4 ))
```

~~~~exercism/note
مقدار المسافات البيضاء داخل الأقواس متروك لك.
إنها مسألة أسلوب وقابلية للقراءة.

```bash
x=$(( 3 + 4 ))
y=$((5+6))
```

يحب كاتبك الودود إضافة مسافات حتى يكون التعبير الحسابي أوضح داخل الأقواس.
~~~~

## الشرط الحسابي

يُنفَّذ الشرط الحسابي داخل أقواس مزدوجة _بدون_ علامة `$` في البداية:

```bash
(( expression ))
```

هذا لا يتوسّع إلى النتيجة.
لكنه يُنتج _حالة خروج_.

* حالة الخروج هي 0 (نجاح) إذا كانت نتيجة التعبير **لا تساوي صفرًا**.
* حالة الخروج هي 1 (فشل) إذا كانت نتيجة التعبير **تساوي صفرًا**.

~~~~exercism/note
داخل `((` تستخدم Bash المعنى نفسه للصحيح/الخطأ كما في لغة C: الصفر خطأ، وما لا يساوي صفرًا صحيح.
**وهذا عكس كيفية تقييم Bash لحالات الخروج!**
~~~~

يُستخدم هذا التركيب عادةً في موضعين:

1. كجزء **الأمر** في [جملة `if`][conditional-if] أو [حلقة `while`][looping-while].

   ```bash
   if (( x == y - 1 )); then ...
   while (( y > 0 )); do ...
   ```

1. كأمر قائم بذاته لتعديل قيمة متغير.

   ```bash
   (( x = x + 1 ))
   echo "new value for x is $x"
   ```

   ~~~~exercism/caution
   احترس عند استخدام الحساب بهذه الطريقة مع `set -e`.
   إذا قيّم التعبير إلى صفر، فستكون حالة الخروج غير صفرية وستتوقف Bash.

   ```bash
   x=0
   (( x++ ))
   echo "you will see this"

   set -e
   x=0
   (( x++ ))
   echo "shell exits on the previous line; you won't see this"
   ```

   لمناقشة أكثر تفصيلًا حول عامل `++`، اطّلع على هذا المقال عن [الزيادة اللاحقة مقابل الزيادة السابقة][incr]

   [incr]: https://thisvsthat.io/postincrement-vs-preincrement
   ~~~~


## مواضع أخرى ذات سياق حسابي

هناك بعض المواضع الأخرى التي تُعدّ سياقات حسابية:

* [حلقة `for` الحسابية][looping-for].

  ```bash
  for (( i = 0; i < 10; i++ )); do
      echo "$i"
  done
  ```

* جزء الفهرس في مصفوفة مفهرسة رقميًا.

  ```bash
  echo "The next element is ${array[x + 1]}"
  # ................................^^^^^
  ```

  لمزيد من المعلومات عن المصفوفات، اقرأ مستند مفهوم [المصفوفات][arrays].

* جزآ الإزاحة والطول في توسيع `${var:offset:length}`.
* [الأمر المُدمج `let`][let].
  * لاحظ أن `(( expression ))` مفضّل على `let "expresson"`.
    فعلى عكس التركيب الشرطي الحسابي، يخضع تعبير `let` لتوسيع أسماء الملفات وتقسيم الكلمات، ويتطلب علامات التنصيص.
* إسناد المتغيرات، عندما يكون للمتغير «سمة العدد الصحيح».

  ```bash
  # variable x does not have the integer attribute
  x="3 + 4"
  declare -p x      # => declare -- x="3 + 4"

  # variable y has the integer attribute
  declare -i y
  y="4 + 5"
  declare -p y      # => declare -i y="9"
  ```

  ~~~~exercism/note
  من رأي الكاتب أن استخدام `declare -i` محدود.
  وفائدته الرئيسية أنه يسمح بحساب «مباشر» (بدون صيغة التعبير الحسابي).
  وقد يُربك هذا قارئي الكود، حيث تُقيَّم التعبيرات الحسابية في مواضع غير متوقعة.
  ~~~~

## استخدام المتغيرات في التعبيرات الحسابية

إليك جانبًا واحدًا من سياقات الحساب يحسّن قابلية القراءة.

```bash
height=10
width=20
area=$(( height * width ))
```

هل لاحظت أن علامات `$` غائبة عن المتغيرات في التعبير الحسابي؟
تتيح لك Bash فعل ذلك.
فهي تجعل التعبيرات أسهل قراءةً بكثير.

يقول الدليل،

> داخل التعبير، يمكن أيضًا الإشارة إلى متغيرات الصدفة بالاسم دون استخدام صيغة توسيع المعاملات.

وهو يعمل حتى مع عناصر المصفوفة:

```bash
point1=(10 15)  # these are (x, y) coordinates
point2=(20 7)
distance_squared=$(( (point1[0] - point2[0])**2 + (point1[1] - point2[1])**2 ))
```

لكن تعبيرات المعاملات الأخرى تحتاج إلى استخدام صيغتها الخاصة.
على سبيل المثال، مضاعفة طول سلسلة نصية:

```bash
s="hello world"
len=$(( ${#s} * 2 ))
```

كما يجب أن تفعل المعاملات الموضعية الشيء نفسه.
إذا كان أول معاملين موضعيين يمثلان العرض والارتفاع:

```bash
area=$(( $1 * $2 ))
```
