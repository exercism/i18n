# مقدمة

تشبه `List` المصفوفة `Array` إلى حد كبير. لكن هناك فروق جوهرية لا تريد أن تفوتك:

1. لا يمكن فهرسة القائمة باستخدام الأقواس المربعة، أي `[0]`.
2. لا يمكن تهيئة القائمة.
3. لا توجد صيَغ استيعابية للقوائم.
4. يمكن للقائمة تعديل عناصرها بحرية أثناء التكرار عليها.

`List` عضو في حزمة `haxe.ds`، لذا في كل مرة تريد فيها استخدام القوائم، عليك استيراد حزمتها:

```haxe
import haxe.ds.List;

class Main {
  static function main() {
    var myList = List<Int>();

    for (i in 0...5) {
      myList.add(i);
    }

    trace(myList); // {0, 1, 2, 3, 4}
  }
}
```
