# التعليمات

ليلة مزدحمة أخرى في ساحة الفرز في أنتويرب. أنت موجّه الحركة المناوب: يجب إعادة تجميع عربات الشحن القادمة في قطارات صادرة، وفحص الوصلات، وتقسيم المسارات عند المفاصل، ودمج الحمولات المتطابقة لأغراض الفوترة.

كل *عربة* هي سلسلة نصية تسمّي ما تحمله: `"coal"`، `"timber"`، `"crates"`، إلخ.

## 1. اقرن العربات في قطارات

عرّف `couple` لتأخذ مصفوفة من العربات وطولًا `n`، وتُرجع قطارات غير متداخلة من `n` عربة لكل قطار. قد يكون القطار الأخير أقصر إذا لم يقبل العدد القسمة بالتساوي.

```factor
{ "coal" "coal" "coke" "ore" "ore" "timber" "timber" } 3 couple .
! => { { "coal" "coal" "coke" } { "ore" "ore" "timber" } { "timber" } }
```

## 2. ألقِ نظرة على الوصلات

عرّف `peek-couplings` لتأخذ مصفوفة من العربات وتُرجع كل زوج متجاور، حتى يتمكن المفتش من فحص كل وصلة.

```factor
{ "coal" "ore" "timber" "crates" } peek-couplings .
! => { { "coal" "ore" } { "ore" "timber" } { "timber" "crates" } }
```

## 3. قسّم صفّ العربات عند المفاصل

عرّف `split-at-junctions` لتأخذ مصفوفة من العربات ومصفوفة `junctions` (عربات تحدّد نقطة قطع)، وتُرجع المقاطع الواقعة بين عربات المفاصل. لا تُحتفظ بعربات المفاصل نفسها.

```factor
{ "coal" "coal" "switch" "ore" "switch" "timber" }
{ "switch" } split-at-junctions .
! => { { "coal" "coal" } { "ore" } { "timber" } }
```

## 4. ادمج الحمولات المتطابقة

عرّف `coalesce-cargo` لتأخذ مصفوفة من العربات وتجمع العربات *المتتالية* الحاملة للحمولة نفسها في متتاليات.

```factor
{ "coal" "coal" "ore" "ore" "ore" "timber" "coal" } coalesce-cargo .
! => { { "coal" "coal" } { "ore" "ore" "ore" } { "timber" } { "coal" } }
```
