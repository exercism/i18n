# مقدمة

في Gleam من الشائع كتابة الدوال عالية الرتبة واستخدامها، أي الدوال التي تأخذ دوال أخرى كوسائط. وأحيانًا عندما تستخدم دوال عالية الرتبة كثيرة في وقت واحد، قد يصبح الكود صعب القراءة، بسبب طبقات الإزاحة الكثيرة.

على سبيل المثال، إليك دالة تستدعي عدة دوال تُرجع `Result(Int, Nil)`، وتجمع القيم إذا نجحت الأربع جميعًا.

```gleam
import gleam/result

pub fn main() -> Result(Int, Nil) {
  result.try(function1(), fn(a) {
    result.try(function2(), fn(b) {
      result.try(function3(), fn(c) {
        result.try(function4(), fn(d) {
          Ok(a + b + c + d)
        })
      })
    })
  })
}
```

تتيح لنا تعبيرات `use` في Gleam كتابة هذا الكود دون الإزاحة، مما يجعله غالبًا أسهل في القراءة.

```gleam
import gleam/result

pub fn main() -> Result(Int, Nil) {
  use a <- result.try(function1())
  use b <- result.try(function2())
  use c <- result.try(function3())
  use d <- result.try(function4())
  Ok(a + b + c + d)
}
```

تعبير `use` يجمع كل العبارات التالية في الكتلة ويمررها كدالة رد نداء كوسيط أخير في استدعاء الدالة. والمتغيرات بين الكلمة المفتاحية `use` والرمز `<-` هي أسماء الوسائط التي ستمرر إلى دالة رد النداء.

```gleam
// This use expression
use a <- function(1, 2)
io.println("Hello!")
a

// Is equivalent to this normal function call
function(1, 2, fn(a) {
  io.println("Hello!")
  a
})
```

يمكن لدالة رد النداء أن تأخذ أي عدد من الوسائط، أو ألا تأخذ أي وسيط.

```gleam
use a, b, c, d <- call_4_function()

use <- call_0_function()
```

لا توجد متطلبات خاصة لإنشاء دالة يمكن استدعاؤها بتعبير `use`، عدا أن تأخذ دالة رد نداء كوسيط أخير.

```gleam
pub fn call_twice(function: fn() -> t) -> #(t, t) {
  let first = function()
  let second = function()
  #(first, second)
}
```

تعبيرات `use` في Gleam ميزة قوية جدًا يمكن تطبيقها على الكثير من المشكلات، لكن عند الإفراط في استخدامها قد تجعل الكود صعب القراءة. ومن الأفضل عمومًا استخدام صيغة استدعاء الدالة العادية، وألا تلجأ إلى تعبيرات `use` إلا عندما تجعل الكود أسهل في القراءة.
