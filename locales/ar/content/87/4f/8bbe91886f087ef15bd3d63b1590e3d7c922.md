# عن السلاسل النصية

في Kotlin، [`string`][ref-string] هي تسلسل من محارف يونيكود غير قابل للتغيير.

تعني [`Immutable`][wiki-immutable] أن أي عملية تُجرى على سلسلة نصية يجب أن تُرجع سلسلة نصية جديدة، فلا يمكن للسلسلة النصية الأصلية أن تتغير أبدًا.

تعني [`Unicode`][wiki-unicode] أنه يمكن تمثيل معظم أنظمة الكتابة في العالم، لكن لا توجد مقابلة واحدة بواحدة بين المحارف والبايتات (على عكس اللغات الأقدم مثل C). وسنناقش هذا بمزيد من التفصيل في مفهوم [`Chars`][concept-chars].

تُحاط السلسلة النصية بعلامتَي تنصيص مزدوجتين `" "`.

تحتاج بعض المحارف إلى الهروب: `\\`، إضافة إلى المحارف غير الطابعة المعتادة مثل `\t` (علامة الجدولة) و`\n` (سطر جديد).

```kotlin
val s = "Escape backslash \\."
// Escape backslash \.
```

تُحاط السلاسل النصية متعددة الأسطر بثلاث علامات تنصيص مزدوجة، ويمكن أن تحتوي على أي نص (دون حاجة إلى الهروب).

```kotlin
val multi = """I'm a
    multi-line
    string with special characters \ \t """
//I'm a
//    multi-line
//    string with special characters  \ \t 
```

استخدم [trimIndent][trimIndent-doc] لإزالة المسافة البادئة المشتركة في بداية الأسطر. يفيد ذلك في تنسيق السلسلة النصية:

```kotlin
val multi = """
    I'm a
      multi-line
    string""".trimIndent()

//I'm a
//  multi-line
//string
```

وبدلًا من ذلك، يتيح لك [trimMargin][trimMargin-doc] تحديد فاصل. عندئذٍ يبدأ كل سطر في `String` بعد هذا الفاصل. القيمة الافتراضية للفاصل هي `|`، لكن يمكنك تحديد فاصل مختلف كمعامل. على سبيل المثال:

```kotlin
val multi = """
    |I'm a
    |  multi-line
    |string""".trimMargin()

//I'm a
//  multi-line
//string

val multi2 = """
    start>I'm a
    start>  multi-line
    start>string""".trimMargin("start>")

//I'm a
//  multi-line
//string
```

يمكن دمج السلاسل النصية باستخدام `+`، لكن من الأفضل أن يقتصر ذلك على الحالات القصيرة والبسيطة، فهناك خيارات أخرى، وغالبًا أفضل.

## قوالب السلاسل النصية

يشير [`Templates`][ref-templates] إلى ما تسميه بعض اللغات الأخرى «الإقحام».

إذا احتوت سلسلة نصية على علامة دولار `$` يتبعها معرّف، أو احتوت على أقواس معقوفة (`{expression}`) تحيط بتعبير، فإنها تُستبدل، على الترتيب، بالقيمة أو بنتيجة هذا التعبير.

```kotlin
val x = 42
val st = "x is $x, x squared is {x * x}"
// x is 42, x squared is 1764
```

## تنسيق السلاسل النصية

على منصة JVM (فقط)، يتيح `String.format()` تنسيقًا أدق من قوالب السلاسل النصية، مع [صياغة][web-formats] مشابهة لدوال [`printf`][wiki-printf] (القديمة جدًا!).

```kotlin
String.format("%s %.3f", "π ≈", 3.14159)
//π ≈ 3.142
```

## دوال السلاسل النصية

توفّر Kotlin _العديد_ من [`functions`][ref-string-functions] للتعامل مع السلاسل النصية.

في معظمها، هذه [`extensions functions`][ref-extensions] وليست أعضاء في صنف `String`، وإن كان لذلك أثر ضئيل على طريقة استخدامنا لها.

~~~~exercism/note
صفحات [التوثيق][ref-string-functions] المعقدة نوعًا ما في Kotlin تخفي دوال الامتداد في العرض الافتراضي.
وفي وقت كتابة هذا النص، يقع المحتوى الأكثر قيمة مخفيًا داخل تبويب اسمه `Members & Extensions`.
انقر عليه لتوسيع هذا القسم ورؤية جميع الأعضاء ودوال الامتداد المتاحة في صنف `String`.

[ref-string-functions]: https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/
~~~~

يعرض المثال التالي مجموعة صغيرة فقط مما هو متاح:

```kotlin
val str = "Hello World!"

str.length              // => 12 (a property, not a function)
str.elementAt(6)        // => W
str.elementAtOrNull(20) // => null (index out of range)
str.substring(6, 11)    // => "World"
str.substringAfter(" ") // => "World!"

str.lowercase()         // => "hello world!"
str.uppercase()         // => "HELLO WORLD!"

str.startsWith("Hel")   // => true
str.endsWith("xyz")     // => false
str.indexOf("0")        // => 4

str.toCharArray()       // => [H, e, l, l, o,  , W, o, r, l, d, !]
"42".toInt() + 1        // => 43  (parsing; see also toFloat)

"Howdy!  ".trim()       // => "Howdy"
```

## بناء سلسلة نصية

أحيانًا نحتاج إلى بناء سلسلة نصية طويلة على مراحل، مثلًا داخل حلقة.

وسرعان ما يصبح دمج السلاسل النصية باستخدام `+` غير أنيق ولا سريع: ذلك أن عدم قابلية السلسلة للتغيير يعني الحاجة إلى _الكثير_ من عمليات النسخ.

توفّر Kotlin طرقًا عدة أكثر كفاءة لدمج السلاسل النصية:

- قوالب السلاسل النصية، كما ورد أعلاه.
- [`joinToString()][ref-jointostring]، وسنغطيه في مفهوم [القوائم][concept-lists].
- [`StringBuilder`][ref-stringbuilder] من Java، وهو لا يُعتبر أسلوبًا مثاليًا في Kotlin بشكل خاص.
- [`buildString()`][ref-buildstring] من Kotlin، وهي تغلّف `StringBuilder` بصياغة أكثر إيجازًا وأقرب إلى أسلوب Kotlin.
وهي تأخذ منطق بناء السلسلة النصية كوسيط من نوع لامبدا، وسنناقش ذلك في مفهوم لاحق.

في جوهره، `StringBuilder` بنية تشبه المصفوفة، وتوفّر العديد من الطرق الملائمة. وهذه مجموعة صغيرة منها:

- [`append()`][ref-sb-append] للإضافة في النهاية.
- [`insert()`][ref-sb-insert] للإضافة في موضع محدد.
- [`deleteAt()`][ref-sb-deleteat] و[`deleteRange()`][ref-sb-deleterange] للحذف من موضع أو مواضع محددة.
- `toString()` للتحويل إلى سلسلة نصية عادية في النهاية: أي دمج كل شيء في عملية واحدة سريعة.

```kotlin
// Available, not recommended
val sb = StringBuilder()
sb.append("Hello ")
sb.append("World!")
sb.toString()
//Hello World!
```

مثال على `buildString()`، باستخدام صياغة من مفاهيم لاحقة:

```kotlin
val countDown = buildString {
    for (i in 5 downTo 1) {
        append(i)
        append("_")
    }
}
// countDown is "5_4_3_2_1_"
```
