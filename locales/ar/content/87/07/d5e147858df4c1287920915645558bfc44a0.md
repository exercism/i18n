## تاريخ موجز جدًا

كان التعامل مع المحارف في الحواسيب أبسط بكثير في العقود الماضية، حين كان المبرمجون يفترضون أن الإنجليزية هي اللغة المهمة الوحيدة.
إذن: 26 حرفًا، بحالتيها العلوية والسفلى، و10 أرقام، وعدة علامات ترقيم، إضافة إلى رمز (0x07) لإصدار رنين الجرس، وقد اتّسع كل ذلك في 7 بتات: مجموعة محارف [ASCII][wiki-ascii].

بطبيعة الحال، بدأ الناس يسألون: ماذا عن à وä وŁ؟ ثم بدأ آخرون يسألون عن ऄ وஹ وญ، وأراد الشباب رموزًا تعبيرية 😱.
فماذا نفعل؟

ولكي لا نطيل، اضطر كثير من الأذكياء الصابرين إلى العمل في لجان لسنوات لوضع تفاصيل مجموعة محارف [Unicode][web-unicode]، والترميزات مثل [UTF-8][wiki-utf-8]، واحتاجت برمجيات كثيرة إلى إعادة كتابة _بالغة_ التعقيد.
كما ظهرت bugs جديدة كثيرة.

ولمنع انهيار _كل شيء_، يضمن تصميم Unicode/UTF-8 أن أول 127 رمزًا مطابقة لـ ASCII _(حتى الجرس)_.

## المحارف في Kotlin

تتمتع اللغات المصممة بعد عام 2005 تقريبًا بميزة ضخمة، وهي أن معيار Unicode المستقر إلى حد معقول كان موجودًا بالفعل.

استطاعت Kotlin (التي صدرت أول مرة عام 2011) أن تفترض أن المستخدمين سيستخدمون مجموعة متنوعة من اللغات (البشرية)، وأنهم سيحتاجون إلى Unicode للتعبير عنها.

المحارف الحرفية تُكتب بين علامتي تنصيص فرديتين، وتختلف عن السلاسل النصية التي تُكتب بين علامتي تنصيص مزدوجتين.
قد يكون هذا بديهيًا لمن أتى من عالم C/C++، لكنه قد يربك مبرمجي Python وJavaScript.

```kotlin
val a = 'a'
a::class.qualifiedName  // => kotlin.Char
a.code  // => 97

val jha = 'झ'  // Devanagari alphabet
jha.code  // => 2333

val heart = '❤'  // heart emoji
heart.code  // => 10084

Char.MAX_VALUE.code  // => 65535 (64k, the largest code point allowed)
```

التحويل بين `Char` و`Int` بسيط:

```kotlin
a.code  // => 97  (a.toInt() is deprecated)
Char(97) // => 'a'
```

يسمح المترجم ب_بعض_ أشكال الحساب الصحيح على قيم `Char`:

```kotlin
'a' + 5       // => 'f'
'c' - 'a'   // => 2
'c' + 'a'   // => error!

'f' + ('A' - 'a')  // => 'F' (same as 'f'.uppercase()

'f'.dec() // => 'e' (decrement)
'f'.inc() // => 'g' (increment)
```

## بعض دوال `Char`

كما هو الحال دائمًا، هناك [دوال كثيرة][ref-char-lib] جدًا بحيث لا يمكن مناقشتها هنا، لذا هذه مجرد مختارات.

- في الحروف الأبجدية المناسبة، غيّر حالة الأحرف باستخدام [`uppercase()`][ref-uppercase] و[`lowercase()`][ref-lowercase].
- اختبر حالة الأحرف باستخدام [`isUpperCase()`][ref-isuppercase] و[`isLowerCase()`][ref-islowercase].
- اختبر نوع المحرف باستخدام:
    - [`isLetter()`][ref-isletter]، ويغطي كثيرًا من الحروف الأبجدية
    - [`isDigit()`][ref-isdigit]، في النطاق 0..9
    - `isLetterOrDigit()`، ويجمع بين الاثنين السابقين
    - [`isWhitespace()`][ref-iswhitespace]، أي محرف مسافة بيضاء

```kotlin
'झ'.isLetter()      // => true
'A'.isLowerCase()   // => false
'4'.isDigit()       // => true
'\t'.isWhitespace() // => true  (tab character)
```

## التحويلات المتبادلة بين قائمة المحارف والسلسلة النصية

للتحويل من السلسلة النصية إلى قائمة محارف، يمكننا استخدام `toList()`.

وللتحويل من قائمة محارف إلى سلسلة نصية، توجد دالة [`joinToString()`][ref-jointostring]، التي تأخذ فاصلًا (غالبًا السلسلة النصية الفارغة) كوسيط.

```kotlin
val kt = "kotlin".toList()  // => [k, o, t, l, i, n]
kt.joinToString("")   // => "kotlin"
kt.joinToString("_")  // => "k_o_t_l_i_n"
```

لاحظ أن `joinToString()` تعمل على قائمة أو مصفوفة.
ل_تحويل_ محرف `Char` واحد إلى سلسلة نصية من محرف واحد، استخدم `toString()`.

```kotlin
'a'.toString() // => "a"
```

للتحقق من وجود محرف في `String`، أو في قائمة محارف أو مصفوفة، لدينا `in`، الذي يقابل دالة [`contains()`][ref-contains].

```kotlin
val clist = "kotlin".toList()  // => [k, o, t, l, i, n]
't' in clist     // => true
't' in "kotlin"  // => true
```
