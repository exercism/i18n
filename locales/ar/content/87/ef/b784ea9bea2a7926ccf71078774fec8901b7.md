# التعليمات

في هذا التمرين ستتعامل مع أسطر السجل.

كل سطر سجل هو سلسلة نصية منسّقة على النحو التالي: `"[<LEVEL>]: <MESSAGE>"`.

هناك ثلاثة مستويات سجل مختلفة:

- `INFO`
- `WARNING`
- `ERROR`

لديك ثلاث مهام، وكل مهمة تأخذ سطر سجل وتطلب منك أن تفعل به شيئًا.

## 1. استخرج الرسالة من سطر سجل

نفّذ الطريقة `LogLine.Message()` (_static_) لتُرجع رسالة سطر السجل:

```csharp
LogLine.Message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

يجب إزالة أي مسافات بيضاء في البداية أو في النهاية:

```csharp
LogLine.Message("[WARNING]:  Disk almost full\r\n")
// => "Disk almost full"
```

## 2. استخرج مستوى السجل من سطر سجل

نفّذ الطريقة `LogLine.LogLevel()` (_static_) لتُرجع مستوى السجل الخاص بسطر السجل، على أن يكون بأحرف صغيرة:

```csharp
LogLine.LogLevel("[ERROR]: Invalid operation")
// => "error"
```

## 3. أعد تنسيق سطر سجل

نفّذ الطريقة `LogLine.Reformat()` (_static_) التي تعيد تنسيق سطر السجل، فتضع الرسالة أولًا ويأتي مستوى السجل بعدها بين الأقواس الهلالية:

```csharp
LogLine.Reformat("[INFO]: Operation completed")
// => "Operation completed (info)"
```
