# مقدمة

## الوراثة

في لغة C#، يمكن تعريف تسلسل هرمي من الأصناف باستخدام _الوراثة_، وهي تسمح للصنف المشتق (`Car`) بأن يرث سلوك الصنف الأصل (`Vehicle`) وبياناته. وإذا لم يُحدَّد صنف أصل، فإن الصنف يرث من الصنف `object`.

يمكن للأصناف الأصل أن توفّر وظائف للأصناف المشتقة بثلاثة أساليب:

- تعريف طريقة عادية.
- تعريف طريقة `virtual`، وهي مثل الطريقة العادية، لكن الأصناف المشتقة _يمكنها_ تغييرها.
- تعريف طريقة `abstract`، وهي طريقة بلا تطبيق و_يجب_ على الأصناف المشتقة تطبيقها. والصنف الذي يحتوي على طرق `abstract` يجب أن يُوسم بـ `abstract` أيضًا. ولا يمكن إنشاء كائنات من الأصناف المجرّدة.

يسمح معدِّل الوصول `protected` بالوصول إلى عضو من أعضاء الصنف الأصل داخل الصنف المشتق، لكنه يمنع الوصول إليه من الأصناف الأخرى.

وتستطيع الأصناف المشتقة الوصول إلى أعضاء الصنف الأصل عبر الكلمة المفتاحية `base`.

```csharp
// Inherits from the 'object' class
abstract class Vehicle
{
    // Can be overridden
    public virtual void Drive()
    {
    }

    // Must be overridden
    protected abstract int Speed();
}

class Car : Vehicle
{
    public override void Drive()
    {
        // Override virtual method

        // Call parent implementation
        base.Drive();
    }

    protected override int Speed()
    {
        // Implement abstract method
    }
}
```

مُنشئ الصنف المشتق يستدعي تلقائيًا مُنشئ الصنف الأصل _قبل_ تنفيذ منطق مُنشئه الخاص. ويمكن تمرير الوسائط إلى مُنشئ الصنف الأصل باستخدام الكلمة المفتاحية `base`:

```csharp
abstract class Vehicle
{
    protected Vehicle(int wheels)
    {
        Console.WriteLine("Called first");
    }
}

class Car : Vehicle
{
    public Car() : base(4)
    {
        Console.WriteLine("Called second");
    }
}
```

وعندما يُشتق أكثر من صنف من صنف أصل، فغالبًا ما تطبّق هذه الأصناف (الاثنان أو أكثر) إصدارات مختلفة من طريقة في الصنف الأصل. وهذا مبدأ مهم جدًا يُسمى تعدد الأشكال. وعلى سبيل المثال، في تنويع على المثال السابق نعرض كيف يمكن للكود الذي يستخدم `Vehicle` أن يغيّر سلوكه حسب نوع المركبة التي أُنشئ منها كائن.

```csharp
abstract class Vehicle
{
   public abstract string GetDescription();
}

class Car : Vehicle
{
   public Car()
   {
   }

   public override string GetDescription()
   {
      return "Runabout";
   }
}

class Rig : Vehicle
{
   public Rig()
   {
   }

   public override string GetDescription()
   {
      return "Big Rig";
   }
}

Vehicle v1 = new Car();
Vehicle v2 = new Rig();

v1.GetDescription();
// => Runabout
v2.GetDescription();
// => Big Rig
```
