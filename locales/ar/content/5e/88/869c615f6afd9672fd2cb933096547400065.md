# التعليمات

أنت مراقب طيور شغوف، تُحصي كل يوم الطيور التي تزور حديقتك. تُخزَّن هذه الأعداد في مصفوفة، بدءًا من الأقدم يومًا.

## 1. عدد اليوم

عرّف `today` لتأخذ مصفوفة الأعداد اليومية من المكدس وتُرجع عدد اليوم.

```factor
{ 2 5 0 7 4 1 } today .
! => 1
```

## 2. زيادة عدد اليوم

عرّف `increment-todays-count` لتُرجع مصفوفة جديدة زاد فيها عدد اليوم بمقدار واحد. يجب ألا تُعدَّل المصفوفة الأصلية.

```factor
{ 2 5 0 7 4 1 } increment-todays-count .
! => { 2 5 0 7 4 2 }
```

## 3. هل كان هناك يوم بلا طيور؟

عرّف `has-day-without-birds?` لتُرجع `t` إذا سجّل يوم واحد على الأقل صفر طيور، وإلا `f`.

```factor
{ 2 5 0 7 4 1 } has-day-without-birds? .
! => t

{ 2 5 1 } has-day-without-birds? .
! => f
```

## 4. جمع الأيام الأولى

عرّف `count-for-first-days` لتأخذ مصفوفة أعداد وعددًا `n`، وتُرجع مجموع أول `n` من الأعداد.

```factor
{ 2 5 0 7 4 1 } 4 count-for-first-days .
! => 14
```

## 5. إحصاء الأيام المزدحمة

اليوم المزدحم هو يوم فيه خمسة طيور أو أكثر. عرّف `busy-days` لتُرجع عدد الأيام المزدحمة في المصفوفة.

```factor
{ 2 5 0 7 4 1 } busy-days .
! => 2
```

## 6. إكمال الأيام الناقصة

إذا لم تُراقب كل يوم من فترة تمتد `n` من الأيام، فاملأ الأيام الناقصة في النهاية بـ `0`. عرّف `pad-missing-days` لتأخذ مصفوفة أعداد وطولًا مستهدفًا `n`، وتُرجع مصفوفة طولها `n` على الأقل وخاناتها الإضافية `0`. يجب الحفاظ على الأعداد الموجودة دون تغيير؛ وإذا كان المُدخل بطول `n` على الأقل بالفعل، فأرجعه دون تغيير.

```factor
{ 2 5 0 } 7 pad-missing-days .
! => { 2 5 0 0 0 0 0 }

{ 4 1 6 8 } 3 pad-missing-days .
! => { 4 1 6 8 }
```
