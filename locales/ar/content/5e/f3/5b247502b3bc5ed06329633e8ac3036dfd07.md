# نبذة

تُقارن [جملة `switch`][switch] قيمةً بعدة أنماط محتملة للمطابقة. وهي توفّر بديلًا أنظف وأسهل قراءةً من ربط عدة عبارات `if-else` بعضها ببعض.

تبدأ جملة `switch` بالكلمة المفتاحية `switch` متبوعة بالقيمة المراد اختبارها. وتُقدَّم كل مطابقة محتملة بالكلمة المفتاحية `case`. وتعرّف الكلمة المفتاحية `default` حالة احتياطية تُنفَّذ إذا لم تطابق أي من الحالات الصريحة. ومثل تسلسل عبارات `if-else`، لا تنفّذ جملة `switch` إلا كتلة الكود المرتبطة بأول حالة مطابقة.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

خذ تسلسل عبارات `if-else` التالي:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

ويمكن كتابته بوضوح أكبر باستخدام جملة `switch`:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## ربط القيم وشروط `where`

يمكن لحالة `switch` أن تربط القيم المطابقة بثوابت أو متغيرات مؤقتة لاستخدامها في جسم تلك الحالة. ويمكن أن تتضمن الحالات أيضًا شرط `where` للتحقق من شروط منطقية إضافية قبل المطابقة:

```swift
let x = 1337
switch sumOfDivisors(of: x) {
case let total where total == x:
    print(total, "is a perfect number")
default:
    print(x, "is not a perfect number")
}
```
