# مقدمة

`when` هي الكلمة المفتاحية في تصفية الاستثناءات. وتوضع بعد عبارة catch ويمكن أن تأخذ تعبيرًا منطقيًا يحتوي على أي قيم في النطاق في ذلك الوقت. إذا قيّم التعبير إلى صحيح، فسيتم تنفيذ الكتلة المرتبطة بعبارة `catch` تلك، وإلا يتم التحقق من عبارة `catch` التالية، إن وجدت.

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```
