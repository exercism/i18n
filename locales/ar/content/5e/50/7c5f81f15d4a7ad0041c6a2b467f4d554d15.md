# نبذة

[`fold`][fold] هو [محوّل مكرّر مستهلِك][consuming iterator adaptor] يطبّق دالة على كل عنصر من عناصر التكرار، ويجمّع النتيجة في قيمة جديدة.

تأخذ كل عملية تكرار من `fold` وسيطين. الأول قيمة ابتدائية للمُجمِّع، والثاني إغلاق يأخذ هو نفسه وسيطين: المُجمِّع وعنصرًا. والقيمة التي يُرجعها الإغلاق هي القيمة التالية للمُجمِّع. وبمجرد أن ينفد المكرّر، تُرجَع القيمة النهائية للمُجمِّع.

يمكن استخدام `fold` عندما يُراد تحويل مجموعة إلى قيمة واحدة. على سبيل المثال، إذا أردنا مجموع كل الأعداد الزوجية

```rust
pub fn main() {
    let even_sum = (1..=10).fold(0, |acc, num| if num % 2 == 0 { acc + num } else { acc });
    println!("{even_sum:?}");
}
```

يطبع `30`.

غالبًا ما يمكن تحقيق ما يمكن فعله بـ `fold` بواسطة دالة أخرى أو عدة دوال. في المثال أعلاه، استخدام [`filter`][filter] على `(1..=10)` ثم [`sum`][sum] سيكون أقل إسهابًا ويعطي النتيجة نفسها، هكذا

```rust
(0..=10).filter(|n| *n % 2 == 0).sum()
```

ومن الدوال الأخرى الأكثر استخدامًا من `fold` نذكر [`product`][product] و[`collect`][collect].

يمكن استخدام المُجمِّع مع غير القيم العددية. على سبيل المثال

```rust
pub fn giant_grunts(initial: char) -> String {
    ["Bee", "Fee", "Gee", "Fi", "Hi", "Fo", "Mo", "Fum", "Tum"].iter().fold(
        String::new(),
        |acc, grunt| if grunt.starts_with(initial) { acc + grunt } else { acc },
    )
}

pub fn main() {
    let song = giant_grunts('F');
    println!("{song:?}");
}
```

يطبع `FeeFiFoFum`
