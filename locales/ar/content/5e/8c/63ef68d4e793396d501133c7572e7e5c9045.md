# مقدمة

يمكن استخدام الأصناف في Kotlin لتغليف البيانات والسلوك.
يُعرَّف الصنف باستخدام الكلمة المفتاحية `class`.
على سبيل المثال:

```kotlin
class Car
```

أنشئ نسخة من الصنف باستدعائه.

```kotlin
val instance = Car()
```

## الخصائص

في الأمثلة أعلاه، عُرّف الصنف `Car` دون أي خصائص.
يمكن تعريف خصائص الصنف في جسمه، بين الأقواس المعقوفة `{}`، باستخدام `var` للخصائص القابلة للتعديل و`val` للخصائص غير القابلة للتعديل.
على سبيل المثال:

```kotlin
class Car {
    // color is mutable
    var color = "red"

    // year is immutable
    val year = 2025
}
```

بدلًا من ذلك، يمكن تعريف الخصائص في مُنشئ يستقبلها.

## المنشئات

يحتوي Kotlin على نوعين من المنشئات: المُنشئ الأساسي والمُنشئ الثانوي.
يُعرَّف المُنشئ الأساسي في السطر نفسه الذي يُعرَّف فيه الصنف.
على سبيل المثال:

```kotlin
class Car constructor(var color : String = "red", val year : Int = 2025) {
    // ...
}
```

يمكن حذف الكلمة المفتاحية `constructor` إذا لم توجد تعليقات توضيحية ولا محددات رؤية:

```kotlin
class Car(var color : String = "red", val year : Int = 2025) {
    // ...
}
```

~~~~exercism/note
يسمح Kotlin بتعريف الصنف دون جسم إذا كان يحتوي على خصائص فقط، دون حاجة إلى الأقواس المعقوفة `{}`:

```kotlin
class Car (var color : String = "red", val year : Int = 2025)
```
~~~~

لا يمكن أن يمتلك الصنف إلا مُنشئًا أساسيًا واحدًا.
أما المنشئات الثانوية فهي منشئات إضافية يمكن إضافتها بتعريفها في جسم الصنف بالكلمة المفتاحية `constructor`.
على سبيل المثال:

```kotlin
class Car constructor(var color : String = "red", val year : Int = 2025) {

    // This constructor allows the year to be provided as a String
    constructor(color : String = "red", yearText : String) : this(color, yearText.toIntOrNull() ?: 0)
}
```

يجب أن يستدعي المُنشئ الثانوي المُنشئ الأساسي بالنداء على `this`.

## كتل التهيئة

يضبط المُنشئ الأساسي خصائص الصنف.
إذا لزم القيام بأمور أخرى أثناء إنشاء الكائن، فيمكن استخدام كتل `init` لتنفيذ إجراءات إضافية.

```kotlin
class Car constructor(var color: String = "red", val year : Int = 2025) {
    init {
        println("Car is ${color}, made in ${year}")
    }
}
```

## الدوال

يمكن تعريف الدوال في جسم الصنف.
على سبيل المثال:

```kotlin
class Car (var color : String = "red", val year : Int = 2025) {
    fun repaint(newColor : String) {
        color = newColor
    }
}
```

## الرؤية

يمكن أن تكون الخصائص والدوال `private` أو `public` أو `internal` أو `protected`.

- لا يمكن الوصول إلى `private` إلا من داخل الصنف
- يمكن الوصول إلى `protected` من داخل الصنف، وكذلك من أي أصناف فرعية
- يمكن الوصول إلى `internal` من داخل الوحدة نفسها
- يمكن للمكوّنات الأخرى التي تستخدم الصنف الوصول إلى `public`

على سبيل المثال:

```kotlin
class Car {
    private val color: String
    public val year: Int
    internal val model: String
    protected val brand: String

    private fun drive() {
        // ...
    }

    internal fun start() {
        // ...
    }

    protected fun stop() {
        // ...
    }

    public fun make() {
        // ...
    }
}
```
