# مرجع Rust

## المفاهيم

تعلّم تمارين مفاهيم Rust المفاهيم بدءًا من الأساسيات وصولًا إلى إتقان اللغة. وهي مصنّفة ومدرجة أدناه.

توجد مفاهيم Exercism لخدمة المتعلمين بطرق عملية، ولذلك تختلف عن الأفكار المجردة. يوضّح هذا المستند ما تعنيه هذه المفاهيم في Rust. أضفنا أدناه تجميعًا بصريًا لمساعدة مشرفي المسارات على إنشاء مستند مرجعي فعّال. هذه التجميعات _لا_ تشكّل تقسيمات تربوية. لذا يُرجى عدم الإشارة إليها أثناء التدريس.

تشير مربعات الاختيار إلى ما إذا كانت المفاهيم قد دُرّست بعد في قائمة خريطة التمارين.

## خريطة تمارين المفاهيم

المثالي أن يكون لدينا تمرين مفاهيم واحد لكل مفهوم من المفاهيم المذكورة أعلاه، يعلّم مفهومًا واحدًا فقط ولا يتطلب سوى متطلباته السابقة. لكن تحقيق ذلك ليس عمليًا تمامًا. على سبيل المثال، سيكون من الصعب تصميم تمرين يعلّم ما هي الدوال دون أن يتطلب أي معرفة بالأنواع الأولية. وبالمثل، سيكون من الصعب تعليم الأنواع الأولية باستخدام مجموعة اختبارات دون أي معرفة بالدوال.

ينبغي أن تشكّل التمارين في هذا الجدول رسمًا بيانيًا موجّهًا غير دوري (DAG) يغطي في النهاية جميع المفاهيم المذكورة أعلاه.

| التمرين                  | المتطلبات السابقة                            | يُعلّم                                                    | الوصف                                                                            |
| ------------------------ | -------------------------------------------- | -------------------------------------------------------- | -------------------------------------------------------------------------------- |
| `hello-world`            | -                                            | الدوال، مجموعات الاختبارات                               | أرجِع القيمة الحرفية `&str` وهي `"hello world"`                                  |
| `compiled-calculator`    | `hello-world`                                | الأعداد الصحيحة، إسناد المتغيرات                         | نفّذ مجموعة من العمليات الحسابية وأرجِع النتيجة ضمنيًا                            |
| `conditionals`           | `hello-world`                                | الجمل الشرطية                                            | ينبغي أن يُبنى على شكل ثلاثة فروع: `if` / `else if` / `else`؛ مع إرجاع ضمني      |
| `slices`                 | `hello-world`، `compiled-calculator`         | الشرائح                                                  | استخرج شريحة من معامل هو شريحة من الأعداد الصحيحة                                |
| `loops`                  | `slices`                                     | تكرار أساسي على شريحة                                    | يُفضّل أن يتضمن إرجاعًا مبكرًا بحيث يكون التعبير عنه بمكرِّر أمرًا مرهقًا         |
| `iterator-use`           | `slices`                                     | استخدام المكرِّرات، `collect`                            |
| `integer-sizes`          | `compiled-calculator`                        | أعداد صحيحة غير `i32`، التحويل                           | لا تزال كلها موقّعة                                                              |
| `unsigned-ints`          | `integer-sizes`                              | أعداد صحيحة غير موقّعة                                    |
| `indexing`               | `integer-sizes`، `slices`                    | الفهرسة، `usize`                                         |
| `floats`                 | `compiled-calculator`                        | الأعداد العشرية                                          | على الأرجح تمرين الآلة الحاسبة المترجمة نفسه، لكن بنتائج ليست أعدادًا صحيحة       |
| `bools`                  | `compiled-calculator`                        | القيم المنطقية، العوامل المنطقية                         |
| `char`                   | `compiled-calculator`                        | نوع البيانات `char`                                      | ينبغي أن يتضمن بعض الأمثلة على المحارف العريضة                                   |
| `str-use`                | `char`، `slices`                             | `&str`                                                   | ملاحظة: غير قابل للتغيير!                                                        |
| `string-use`             | `str-use`                                    | `String`                                                 | ملاحظة: مملوك وقابل للتغيير                                                      |
| `format-macro`           | `string-use`                                 | ماكرو `format!`                                          |
| `str-vs-string`          | `str-use`، `string-use`                      | الدمج والتحويل والتكاليف وغير ذلك                        |
| `generics-basics`        | `integer-sizes`، `floats`                    | استخدام السمات الخارجية كحدود، الأنواع العامة الأساسية   | على الأرجح لا يزال تمرين الآلة الحاسبة المترجمة، لكن بصيغة عامة                  |
| `structs`                | `string-use`، `unsigned-ints`، `floats`      | إنشاء بنية واستخدامها لإدارة البيانات                    | `Person` لها اسم وطول وعدد الأحذية المملوكة                                      |
| `implicit-return`        | `compiled-calculator`                        | النطاقات والتعبيرات والإرجاع الضمني                      |
| `explicit-return`        | `implicit-return`، `conditionals`            | عبارة `return` الصريحة                                   |
| `methods`                | `structs`، `explicit-return`                 | كتل `impl`، الطرق                                        |
| `tuples`                 | `structs`                                    | الصفوف                                                   | علّمها كبنى مجهولة؛ وعلّم صيغة `.0`                                              |
| `tuple-structs`          | `tuples`، `structs`                          | بنى الصفوف (الصفوف المسمّاة)                              |
| `basic-enums`            | `unsigned-ints`                              | التعدادات الأساسية (بدون حقول)، `match`                  |
| `enums`                  | `basic-enums`، `tuple-structs`               | صيغة الصف لبدائل التعداد                                 |
| `option`                 | `enums`                                      | `Option<T>`                                              |
| `result`                 | `enums`                                      | `Result<T, E>`                                           |
| `mutability`             | `compiled-calculator`                        | عدم القابلية للتغيير افتراضيًا؛ القابلية الصريحة للتغيير  |
| `let-expressions`        | `loops`، `option`، `result`                  | `if let`، `while let`                                    | على الأرجح سيعتمد على أحد التمرينين `option` أو `result` فقط حسب التنفيذ          |
| `vectors`                | `slices`                                     | `Vec<T>`                                                 |
| `hashmaps`               | `vectors`                                    | `Hashmap<K, V>`                                          |
| `entry-api`              | `hashmaps`                                   | Entry API                                                |
| `hashsets`               | `hashmaps`                                   | `HashSet<K>`                                             |
| `btreemaps`              | `hashmaps`                                   | `BTreeMap<K, V>`                                         |
| `deriving-traits`        | `structs`                                    | `PartialEq`، `PartialOrd`، `Debug`، `Display`، `Default` |
| `implementing-traits`    | `deriving-traits`                            | تنفيذ سمة يدويًا                                          | على الأرجح تنفيذ `Iterator`                                                      |
| `collection-conversions` | `vectors`، `hashsets`، `implementing-traits` | `FromIterator`، `IntoIterator`                           |
