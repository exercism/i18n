# مقدمة

**التعبيرات النمطية** (regexes) هي تسلسلات من المحارف تحدّد نمط بحث في النص.

تعلّم صياغة التعبيرات النمطية خارج نطاق هذا الموضوع.
سنركّز على التعبيرات التي يوفّرها `jq` لاستخدام التعبيرات النمطية.

## صيغة التعبيرات النمطية

تنفّذ الأدوات المختلفة إصدارات مختلفة من التعبيرات النمطية.
يتضمّن `jq` مكتبة التعبيرات النمطية [Oniguruma][oniguruma] المتوافقة إلى حدٍّ كبير مع تعبيرات Perl v5.8 النمطية.

يمكن [إيجاد الصياغة المحددة التي يستخدمها `jq` على مستودع Oniguruma على GitHub][onig-syntax].

<!-- prettier-ignore -->
~~~~exercism/caution
لا يملك `jq` أي صياغة خاصة بالتعبيرات النمطية.
بل تُكتب ببساطة على هيئة سلاسل نصية.
وهذا يعني أن أي شرطة مائلة عكسية في التعبير النمطي يجب تهريبها داخل السلسلة النصية.

على سبيل المثال، فئة محارف الأرقام (`\d`) يجب كتابتها على الشكل `"\\d"`.
~~~~

<!-- prettier-ignore-end -->

## دوال التعبيرات النمطية

تقتصر التعبيرات النمطية في `jq` على [مجموعة من المرشّحات][jq-regex-funcs].

### المطابقة البسيطة

عندما تحتاج إلى معرفة ما إذا كانت سلسلة نصية تطابق نمطًا، استخدم المرشّح `test`.

```jq
STRING | test(REGEX)
STRING | test(REGEX; FLAGS)
STRING | test([REGEX, FLAGS])
```

يُخرج هذا المرشّح نتيجة _منطقية_.

```jq
"Hello World!" | test("W")    # => true
"Goodbye Mars" | test("W")    # => false
```

### معلومات عن المطابقة

عندما تحتاج إلى استخراج السلسلة الفرعية التي طابقت النمط فعليًا، استخدم المرشّح `match`.

```jq
STRING | match(REGEX)
STRING | match(REGEX; FLAGS)
STRING | match([REGEX, FLAGS])
```

يُخرج هذا المرشّح:

- لا شيء إذا لم تكن هناك مطابقة، أو
- كائنًا يحتوي على خصائص متنوعة إذا كانت هناك مطابقة.

يبحث هذا المثال عن حرفَي علة متتاليين متماثلين باستخدام صياغة الإحالة الخلفية، `\1`.

```jq
"Hello World!" | match("([aeiou])\\1")
# => empty

"Goodbye Mars" | match("([aeiou])\\1")
# => {
#      "offset": 1,
#      "length": 2,
#      "string": "oo",
#      "captures": [
#        {
#          "offset": 1,
#          "length": 1,
#          "string": "o",
#          "name": null
#        }
#      ]
#    }
```

يُرجع المرشّح `match` كائنًا لكل مطابقة.
يوضّح هذا المثال عمل العَلم `"g"` لإيجاد جميع حروف العلة.

```jq
"Goodbye Mars" | match("[aeiou]"; "g")
# => { "offset": 1, "length": 1, "string": "o", "captures": [] }
#    { "offset": 2, "length": 1, "string": "o", "captures": [] }
#    { "offset": 6, "length": 1, "string": "e", "captures": [] }
#    { "offset": 9, "length": 1, "string": "a", "captures": [] }
```

### السلاسل الفرعية المُلتقَطة

على غرار المرشّح `match`، يُرجع المرشّح `capture` كائنًا إذا كانت هناك مطابقة.

```jq
STRING | capture(REGEX)
STRING | capture(REGEX; FLAGS)
STRING | capture([REGEX, FLAGS])
```

الكائن المُرجَع هو خريطة **لعمليات الالتقاط المُسمّاة**.

```jq
"JIRAISSUE-1234" | capture("(?<project>\\w+)-(?<issue_num>\\d+)")
# => {
#      "project": "JIRAISSUE",
#      "issue_num": "1234"
#    }
```

### السلاسل الفرعية فقط

المرشّح `scan` مشابه للمرشّح `match` مع العَلم `"g"`.

```jq
STRING | scan(REGEX)
STRING | scan(REGEX; FLAGS)
```

سيُخرج `scan` _تدفّقًا_ من السلاسل الفرعية.

```jq
"Goodbye Mars" | scan("[aeiou]")
# => "o"
#    "o"
#    "e"
#    "a"
```

استخدم مُنشئ المصفوفة `[...]` لالتقاط السلاسل الفرعية.

```jq
"Goodbye Mars" | [ scan("[aeiou]") ]
# => ["o", "o", "e", "a"]
```

### تقسيم سلسلة نصية

إذا كنت تعرف أجزاء السلسلة النصية التي تريد **الاحتفاظ بها**، فاستخدم `match` أو `scan`.
وإذا كنت تعرف الأجزاء التي تريد **التخلّص منها**، فاستخدم `split`.

```jq
STRING | split(REGEX; FLAGS)
```

<!-- prettier-ignore -->
~~~~exercism/caution
يتعامل المرشّح `split` **ذو الوسيط الواحد** مع وسيطه على أنه **سلسلة نصية ثابتة**.

لاستخدام تعبير نمطي مع `split`، **يجب** عليك تمرير الوسيط الثاني؛ ولا بأس في استخدام سلسلة نصية فارغة.
~~~~

<!-- prettier-ignore-end -->

مثال يقسّم سلسلة نصية عند أي مسافات بيضاء.

```jq
"first   second           third fourth" | split("\\s+"; "")
# => ["first", "second", "third", "fourth"]
```

### الاستبدالات

يمكن للمرشّحَين `sub` و`gsub` تحويل سلسلة الإدخال، باستبدال الأجزاء المطابقة من الإدخال بسلسلة نصية بديلة.

لاستبدال أول مطابقة فقط، استخدم `sub`.
ولاستبدال جميع المطابقات، استخدم `gsub`.

```jq
STRING | sub(REGEX; REPLACEMENT)
STRING | sub(REGEX; REPLACEMENT; FLAGS)
STRING | gsub(REGEX; REPLACEMENT)
STRING | gsub(REGEX; REPLACEMENT; FLAGS)
```

```jq
"Goodnight kittens. Goodnight mittens." | sub("night"; " morning")
# => "Good morning kittens. Goodnight mittens."

"Goodnight kittens. Goodnight mittens." | gsub("night"; " morning")
# => "Good morning kittens. Good morning mittens."
```

يمكن لنص الاستبدال أن يشير إلى السلاسل الفرعية المطابقة؛ استخدم الالتقاطات المُسمّاة و[إقحام السلاسل النصية][jq-interp].

```jq
"Some 3-letter acronyms: gnu, csv, png"
| gsub( "\\b(?<tla>[[:alpha:]]{3})\\b";     # find words 3 letters long
        "\(.tla | ascii_upcase)" )          # upper-case the match
# => "Some 3-letter acronyms: GNU, CSV, PNG"
```

## الأعلام

في جميع المرشّحات أعلاه، يكون FLAGS سلسلة نصية تتكوّن من صفر أو أكثر من الأعلام المدعومة.

- `g` - بحث شامل (إيجاد جميع المطابقات، وليس الأولى فقط)
- `i` - بحث غير حسّاس لحالة الأحرف
- `m` - وضع الأسطر المتعددة (تطابق '.' محارف الأسطر الجديدة)
- `n` - تجاهل المطابقات الفارغة
- `p` - تفعيل الوضعين s و m معًا
- `s` - وضع السطر الواحد ('^' -> '\A', '$' -> '\Z')
- `l` - إيجاد أطول المطابقات الممكنة
- `x` - صيغة التعبير النمطي الموسّعة (تجاهل المسافات البيضاء والتعليقات)

على سبيل المثال

```jq
"JIRAISSUE-1234" | capture("(?<project>\\w+)-(?<issue_num>\\d+)")

# or with Extended formatting

"JIRAISSUE-1234" | capture("
                     (?<project>   \\w+ )  # the Jira project
                     -                     # followed by a hyphen
                     (?<issue_num> \\d+ )  # followed by digits
                   "; "x")
```
