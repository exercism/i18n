# If, Elseif, Else

تُعدّ الجمل الشرطية التي تستخدم `if` و `elseif` و `else` جزءًا أساسيًا من التحكم في مسار البرنامج.
تُقيّم جملة `if` تعبيرًا، وإذا كانت قيمته صحيحة، فإنها تنفّذ فرع الكود.

```php
<?php

if ($expression) {
    // .. executed if $expression is true
}
```

إذا لم يكن التعبير قيمة منطقية، فإن التقييم يحدّد ما إذا كانت القيمة تُعدّ صحيحة أم لا تُعدّ خطأً.
في PHP، تُعتبر القيم التالية مساوية للقيمة `false`:

- القيمة المنطقية `true`
- العدد الصحيح `0`
- العدد العشري `0.0` و `-0.0`
- المصفوفة الفارغة `[]`
- السلسلة النصية الفارغة `""` أو السلسلة النصية الرقمية `"0"`
- `null`

وتُعدّ جميع القيم الأخرى صحيحة.

## التعامل مع شروط متعددة

بعد جملة `if`، يمكنك ربط عدة شروط باستخدام `elseif` و `else`.

```php
<?php

if ($value === 0) {
    // .. do something
} elseif ($value === 1) {
    // .. do something else
} else {
    // ,, do this if nothing else
}
```

لن تُنفَّذ سوى جملة شرطية واحدة يُقيَّم شرطها على أنه صحيح.
لذلك، إذا كان من الممكن أن يُقيَّم أكثر من شرط على أنه صحيح، فإن ترتيب كتابتها مهم.

```php
<?php

if (true) {
    // .. always do something
} elseif (true)
    // .. will never be executed
} else {
    // .. will never be executed
}
```
