# التعليمات

اكتب دالة لتحويل الأعداد العادية إلى [الأعداد الترتيبية](https://en.wikipedia.org/wiki/Ordinal_numeral). أما الصفر (0) فما عليك سوى إرجاع "0" على هيئة سلسلة نصية.

الأعداد الترتيبية هي أعداد تصف موضع شيء ما في قائمة.
وفي هذا السياق ستُستخدم الأعداد الترتيبية، مع استخدام اسم مكتوب بالإنجليزية للعدد الترتيبي.

الأعداد الترتيبية هي (أو على الأقل أحد أشكالها):

```
1st 2nd 3rd 4th 5th... 9th 10th 11th 12th... 20th 21st 22nd 23rd 24th... etc.
```

لذا فإن إدخال عدد عادي يعطي مكافئه الترتيبي:

```
1 -> 1st
2 -> 2nd
3 -> 3rd
(and so on...)
```
