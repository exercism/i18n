لكن الأمور غير منظمة قليلًا: يبدو أن إحداثيات أزارا منسَّقة ومرتَّبة بطريقة مختلفة عن إحداثيات روي، وعليهما أن يظلّا يتنقلان بالنظر بين القائمتين لمعرفة أي الكنوز يقابل أي الأماكن.
ولأنهما مبرمجان ناشئان بلغة F#، فقد جاءا إليك طلبًا للمساعدة في كتابة برنامج صغير (مجموعة دوال في الحقيقة) لتنظيم معلومات رحلتهما بشكل أفضل.

## 1. استخراج الإحداثيات

نفّذ الدالة `getCooordinate()` التي تأخذ زوجًا `(treasure, coordinate)` من قائمة أزارا وتُرجع إحداثي الخريطة المستخرج فقط.

```fsharp
getCoordinate ("Scrimshaw Whale's Tooth", "2A")
// "2A"
```

## 2. تنسيق الإحداثيات

نفّذ الدالة `convertCoordinate()` التي تأخذ إحداثيًا بالصيغة "2A" وتُرجع صفًّا بالصيغة `(2, 'A')`.

```fsharp
convertCoordinate "2A"
// (2, 'A')
```

## 3. مطابقة الإحداثيات

نفّذ الدالة `compareRecords()` التي تأخذ زوجًا `(treasure, coordinate)` وسجلًّا `(location, coordinate, quadrant)` وتقارن الإحداثيات في كلٍّ منهما.
أرجع **`true`** إذا "تطابقت" الإحداثيات، وأرجع **`false`** إذا لم تتطابق.
أعد تنسيق الإحداثيات حسب الحاجة لإجراء مقارنة دقيقة.

```fsharp
compareRecords ("Brass Spyglass", "4B") ("Seaside Cottages", (1, 'C'), "blue")
// false

compareRecords ("Model Ship in Large Bottle", "8A") ("Harbor Managers Office", (8, 'A'), "purple")
// true
```

## 4. دمج السجلات المتطابقة

نفّذ الدالة `createrecord()` التي تأخذ زوجًا `(treasure, coordinate)` من قائمة أزارا وسجلًّا `(location, coordinate, quadrant)` من قائمة روي وتُرجع `(coordinate, location, quadrant, treasure)` **إذا تطابقت الإحداثيات**.
أما إذا _لم_ تتطابق الإحداثيات، فأرجع صفًّا بالشكل نفسه لكن مملوءًا بـ `""`.
أعد تنسيق الإحداثيات حسب الحاجة لإجراء مقارنة دقيقة.

```fsharp
createRecord ("Brass Spyglass", "4B") ("Abandoned Lighthouse", (4, 'B'), "Blue")
// ("4B", "Abandoned Lighthouse", "Blue", "Brass Spyglass")

createRecord ("Brass Spyglass", "4B") ("Seaside Cottages", (1, 'C'), "Blue")
// ("", "", "", "")
```
