# مقدمة

تُستخدم التعبيرات الشرطية لتنفيذ الكود بناءً على ما إذا كان الشرط **صحيحًا** أو **خطأً**. وتُكتب هذه التعبيرات على النحو التالي:

```haxe
if (condition) {
  expressions
};
```

ناتج الشرط من النوع `Bool`، لذا عندما يكون الناتج `true` تُنفَّذ التعبيرات.

أحيانًا، عندما يكون الشرط في الواقع `false`، نريد تنفيذ جزء آخر من الكود. وهنا يأتي دور تعبير `else`. ينفّذ `else` التعبيرات عندما يكون الشرط الأولي `false`. لكن ماذا لو أردنا فحص الشرط لاحتمالات متعددة؟ حينها نستخدم `else if (condition)`. إليك مثالًا كاملًا:

```haxe
var a = 10;

if (a == 2) {
  trace("a is 2");
} else if (a == 5) {
  trace("a is 5");
} else {
  trace("a is 10");
}

// a is 10
```
