# مقدمة

تُعرف الأنواع التي تُطبّق واجهة `IEnumerable<T>` بأنها _قابلة للتعداد_. وجميع أنواع المجموعات المدمجة تُطبّق هذه الواجهة.

يمكن تكرار عناصر النوع القابل للتعداد باستخدام حلقة `foreach`:

```csharp
var primes = new[] { 2, 3, 5, 7 };
foreach (var prime in primes)
{
    Console.Write(prime);
}
// => 2357
```

لتطبيق `IEnumerable<T>`، على النوع أن يُطبّق طريقة واحدة: `IEnumerator<T> GetEnumerator()`. وكما رأينا، يفوّض النوع القابل للتعداد عملية التكرار الفعلية على المجموعة إلى نوع `IEnumerator<T>`. وتحتوي هذه الواجهة على خاصية واحدة وثلاث طرق يجب تطبيقها:

- `public T Current { get; }`: الحصول على العنصر الحالي.
- `public bool MoveNext ();`: الانتقال إلى العنصر التالي، وتُرجع `true` إذا نجح الانتقال إلى العنصر التالي، و`false` إذا لم ينجح (لا مزيد من العناصر).
- `public void Reset ();`: إعادة تعيين المُعدِّد إلى حالته الأولية (قبل العنصر الأول).
