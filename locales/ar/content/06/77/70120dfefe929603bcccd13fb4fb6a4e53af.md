# مقدمة

التعبيرات النمطية طريقة بالغة المرونة _لمطابقة الأنماط_ في السلاسل النصية، باستخدام لغة خاصة بالمجال (Domain Specific Language, DSL) مصمَّمة لهذا الغرض.

كثير من قدرات التعبيرات النمطية مدمج أصلًا في Base R، وقد ترى أمثلة عليها في كود قديم.

أما في الكود الجديد، فمن الموصى به _بشدة_ استخدام مكتبة [`stringr`][web-stringr].

وكما ذُكر في [مفهوم السلاسل النصية][concept-strings]، توفّر `stringr` توثيقًا جيدًا، يكتبه عادةً مؤلف الحزمة أو مؤلفوها.

- [موقع مرجعي][web-stringr]
- [ورقة مرجعية سريعة][cheat-stringr].
- [فصل عن السلاسل النصية][book-strings] و[فصل عن التعبيرات النمطية][book-regex] في كتاب "R for Data Science".

كثير من الدوال التي سبق أن ناقشناها في [مفهوم `Strings`][concept-strings] مصمَّم أصلًا للبحث بالتعبيرات النمطية.

لقد أبقينا مفهوم Strings بسيطًا نسبيًا بالاقتصار على مطابقة السلاسل النصية الحرفية، لكن يمكن استخدام أي نمط تعبير نمطي بدلًا من ذلك.

من حيث الصيغة الرسمية، تُنشأ التعبيرات النمطية في R باستدعاء [`regex()`][ref-regex].
وللتسهيل، تتعامل دوال `stringr` مع أي سلسلة نصية تمثل نمطًا على أنها تعبير نمطي.
في المثال أدناه، الاستدعاء الأول لـ `str_replace_all()` اختصار مُيسَّر يعادل النسخة الثانية:

```R
input <- "Some input string"

# "\\s" matches any whitespace character
input |> str_replace_all("\\s", "_")
[1] "Some_input_string"

input |> str_replace_all(regex("\\s"), "_")
[1] "Some_input_string"
```

[الورقة المرجعية السريعة][cheat-stringr] دليل مفيد: كل الدوال التي تأخذ وسيطًا باسم `pattern` (المطبوع باللون الأحمر) تقبل تعبيرًا نمطيًا، وتلخّص الصفحة 2 صيغة التعبيرات النمطية.

لاحظ أن الدالة [`regex()`][ref-regex] قد تظل مهمة إذا احتجت إلى تجاوز الإعدادات الافتراضية، مثل حساسية حالة الأحرف أو الإعدادات المحلية.

```R
# default is case sensitive
"A Mixed Assortment" |> 
    str_replace_all(regex("[aeiou]", ignore_case = TRUE), "*")
#> [1] "* M*x*d *ss*rtm*nt"
```

تشمل العديد من رموز التعبيرات النمطية شرطة مائلة عكسية، مثل `\s` المستخدمة أعلاه.
في السلاسل النصية العادية في R، يجب تهرّيب `\` بمضاعفتها، ومن هنا جاءت `"\\s"`.

قد تتكاثر الشرطات المائلة العكسية وتصبح مربكة، لذا قد يساعدك استخدام [السلاسل النصية الخام][book-raw] في الحالات المعقدة.

افتراضيًا، صيغة تعريف السلسلة النصية الخام هي `r"( )"`، لكن يُسمح بفواصل أخرى.
ولأن الأقواس الهلالية `( )` والأقواس المربعة `[ ]` شائعتان في صيغة التعبيرات النمطية (لمجموعات الالتقاط ومجموعات الخيارات)، فقد تكون الأقواس المعقوفة `{ }` خيارًا جيدًا.

```R
input |> str_replace_all(r"{\s\w}", "__")
#> [1] "Some__nput__tring"
```

## اكتشاف المطابقات

فيما يلي بعض الأسئلة، ودوال يمكن أن تساعدك في الإجابة عنها.

تستخدم بعض الأمثلة `fruit`، وهو متجه يضم 80 اسمًا من أسماء الفواكه مرفق مع `stringr` للتدريب.

_هل تحتوي السلسلة النصية على مطابقة؟_
`str_detect()`، أو `str_starts()` و`str_ends()` لتجنّب استخدام مثبّتات `^` أو `$`.

```R
# berries begining with b
fruit |> str_detect("^b.*berry") |> head(15)
#> [1] FALSE FALSE FALSE FALSE FALSE  TRUE  TRUE FALSE FALSE  TRUE  TRUE FALSE FALSE FALSE FALSE

# alternative syntax
fruit |> str_starts("b.*berry") |> head(15)
#> [1] FALSE FALSE FALSE FALSE FALSE  TRUE  TRUE FALSE FALSE  TRUE  TRUE FALSE FALSE FALSE FALSE
```

_هل تريد إرجاع السلاسل النصية التي تحتوي على مطابقة فقط؟_
استخدم `str_subset()` للحصول على السلاسل النصية، و`str_which()` للحصول على الفهارس.

```R
fruit |> str_subset("a...e")
[1] "apple"       "blackberry"  "mandarine"   "nectarine"   "pineapple"   "pomegranate" "raspberry"   "salal berry"
> fruit |> str_which("a...e")
[1]  1  7 48 51 62 64 70 73
```

_كم عدد المطابقات في كل سلسلة نصية؟_
استخدم `str_count()`.

```R
# count vowels
fruit |> str_count("[aeiou]") |> head(10)
#> [1] 2 3 4 3 3 2 2 3 5 3
```

_أين توجد المطابقة؟_
`str_view()` للاستخدام التفاعلي، و`str_locate()` أو `str_locate_all()` بصفة عامة.

```R
# str_view only shows matching elements, with match in < > delimiters
fruit |> str_view("a...e")
 [1] │ <apple>
 [7] │ bl<ackbe>rry
[48] │ mand<arine>
[51] │ nect<arine>
[62] │ pine<apple>
[64] │ pomegr<anate>
[70] │ r<aspbe>rry
[73] │ sal<al be>rry

# str_locate returns all elements
fruit |> str_locate("a...e") |> head(10)
      start end
 [1,]     1   5
 [2,]    NA  NA
 [3,]    NA  NA
 [4,]    NA  NA
 [5,]    NA  NA
 [6,]    NA  NA
 [7,]     3   7
 [8,]    NA  NA
 [9,]    NA  NA
[10,]    NA  NA
```

## الالتقاط

غالبًا ما نريد معرفة _ما_ الذي يطابق.
ويتحقق ذلك بتضمين مجموعات الالتقاط بين أقواس هلالية داخل التعبير النمطي.

ويمكن الإشارة مرة أخرى إلى مجموعات الالتقاط داخل التعبير النمطي نفسه، باستخدام `\1` و`\2` وهكذا.
على سبيل المثال، إيجاد أزواج الحروف المتكررة:

```R
fruit |> str_subset("(..)\\1")
[1] "banana"      "coconut"     "cucumber"    "jujube"      "papaya"      "salal berry"
```

وبصيغة مشابهة، يمكن استخدام مجموعات الالتقاط في سلاسل الاستبدال النصية:

```R
# double to triple
fruit |> 
  str_subset("(..)\\1") |> 
  str_replace("(..)\\1", "\\1\\1\\1")
[1] "bananana"      "cococonut"     "cucucumber"    "jujujube"      "papapaya"      "salalal berry"
```

اجمع المطابقات لمعالجتها لاحقًا باستخدام الدالة `str_match()` إذا أردت المطابقة الأولى فقط، أو `str_match_all()` للحصول على جميع المطابقات.

تميل مجموعات الالتقاط إلى إنتاج مخرجات معقدة في أي لغة.
وأسلوب R (_وهو أيضًا قائم على المتجهات كتحدٍّ إضافي_) هو توليد مصفوفة من `str_match()`، بحيث يكون لكل سلسلة نصية مُدخَلة صف واحد، ويحتوي العمود 1 على السلسلة النصية المطابقة كاملة، بينما تحتوي الأعمدة الباقية على مجموعات الالتقاط المختلفة.

قد يكون استخدام المجموعات المُسمّاة ميزة، إذ تصبح أسماء الأعمدة في مصفوفة النتائج.

```R
recipe <- "dissolve 25g sugar in 200ml water"
recipe |> str_match("(\\d+g) .* (\\d+ml)")
     [,1]                 [,2]  [,3]   
[1,] "25g sugar in 200ml" "25g" "200ml"

# use named capture groups
recipe |> str_match("(?<wt>\\d+g) .* (?<vol>\\d+ml)")
                          wt    vol    
[1,] "25g sugar in 200ml" "25g" "200ml"
```

~~~~exercism/note
لم نقُل الكثير عن المصفوفات في هذا المنهج، مع أن هناك [مستند مفهوم][concept-matrices-arrays] يمكنك الاطّلاع عليه.
لا تنسجم المصفوفات جيدًا مع منظومة Tidyverse، على الرغم من كونها جزءًا من Base R منذ زمن طويل.

وباختصار سريع: تعامل مع المصفوفات كأنها متجهات لها فهرسان، بالترتيب `[rows, cols]`.
واترك أيًّا من الفهرسين فارغًا للحصول على الصف أو العمود كاملًا.

وعند الحصول على صف واحد `r` عبر `m[r,]` أو على عمود واحد `c` عبر `m[,c]`، فإن القيمة المُرجَعة تُسطَّح إلى متجه افتراضيًا.

```R
> amounts <- recipe |> str_match("(?<wt>\\d+g) .* (?<vol>\\d+ml)")

# get all of row 1, as a named vector
> amt1 <- amounts[1,]
> amt1
                                       wt                  vol 
"25g sugar in 200ml"                "25g"              "200ml" 

# get a vector element
amt1["wt"] |> unname()
[1] "25g"
```
~~~~

وبشكل حتمي، تنتج `str_match_all()` مخرجات ذات بنية أكثر تعقيدًا:

- النتيجة قائمة، ولكل سلسلة نصية مُدخَلة عنصر واحد.
- إذا كانت هناك سلسلة نصية مُدخَلة واحدة فقط، فاستخرج المحتوى من القائمة باستخدام الفهرسة `[[1]]` كما هو موضح في [مفهوم القوائم][concept-lists].
- كل عنصر مصفوفة، بأعمدة كما في `match()`.
- كل صف في المصفوفة يمثّل التقاطًا ناجحًا.

```R
mix <- "Mix 200g of sugar, 180g of flour and 150g of butter"

# raw output
> str_match_all(mix, "(\\d+)g")
[[1]]
     [,1]   [,2] 
[1,] "200g" "200"
[2,] "180g" "180"
[3,] "150g" "150"

# we just want the first list element
> str_match_all(mix, "(\\d+)g")[[1]]
     [,1]   [,2] 
[1,] "200g" "200"
[2,] "180g" "180"
[3,] "150g" "150"

# captures are in column 2, so get that as a vector
> str_match_all(mix, "(\\d+)g")[[1]][,2]
[1] "200" "180" "150"
```

```R
# failed match
recipe |> str_match("(not here)")
     [,1] [,2]
[1,] NA   NA  
```
