# تلميحات

من الاستخدامات الشائعة لـ `Either` الإشارة إلى عملية حسابية قد ينتج عنها خطأ (وإذا لم يكن الخطأ الفعلي مهمًا، فقد يكون النوع الأبسط `Option` خيارًا أفضل). وعند غياب الخطأ تكون النتيجة عادةً `Right` (للتذكير: القيمة «الصحيحة»)، بينما يكون الخطأ `Left`، مثل `Left[String]` الذي يحمل رسالة خطأ. لاحظ أن `Either` في Scala 2.12 متحيّز إلى اليمين افتراضيًا، لذا يعمل كما هو متوقع مع عمليات مثل `filter` و`map` و`flatMap` أو داخل for-comprehension. وإذا لم تكن على دراية بـ `Either` فيمكنك قراءة [هذا الدرس التعليمي](http://danielwestheide.com/blog/2013/01/02/the-neophytes-guide-to-scala-part-7-the-either-type.html)، لكن انتبه إلى أن هذا الدرس يتناول إصدارات Scala السابقة للإصدار 2.12. أما في Scala 2.12 فيمكنك تجاهل `RightProjection` وإسقاط `.right` بأمان. و`Either` هو ما يُعرف بـ [الموناد](https://en.wikipedia.org/wiki/Monad_(functional_programming))، وهو يغطي «جانبًا حسابيًا»، وهنا معالجة الأخطاء. والاستخدام الصحيح للمونادات قد يُنتج كودًا موجزًا جدًا مع أنه أنيق ومقروء، أما الاستخدام الخاطئ فقد يؤدي بسهولة إلى العكس. شاهد [هذا الفيديو](https://www.youtube.com/watch?v=Mw_Jnn_Y5iA) لتتعلّم المزيد.

## أخطاء شائعة يجب تجنّبها

هناك بعض القواعد العامة لـ `Either`:

1. إذا لم تكن بحاجة إليه فلا تستخدمه. فبدلًا من

```scala
def add1(x: Int): Either[String, Int] = Right(x + 1)
```

من الأفضل أن تكتب

```scala
def add1(x: Int): Int = x + 1
```

(فهناك `Either.map` لتطبيق مثل هذه الدوال البسيطة، فلا حاجة إلى إثقالها بـ `Either`).

2. لا «تفكّ» الغلاف إن لم تكن بحاجة حقيقية إلى ذلك. فغالبًا ما توجد دوال مدمجة تخدم غرضك. ومن مؤشرات فكّ الغلاف المتسرّع `isLeft/isRight` أو مطابقة الأنماط. فمثلًا، بدلًا من

```scala
val x: Either[String, Int] = ...

if (x.isRight) x.right.get + 1 else x.left.get
// or
x match {
  case Right(n) => n + 1
  case Left(s) => s
}
```

من الأفضل أن تكتب

```scala
x fold (identity, _ + 1)
```

3. يمكن استخدام المونادات داخل for-comprehension، وهذا أمر رائع. وهذا مستحسن عندما تريد «تركيب» عدة نسخ من `Either`. فبدلًا من

```scala
val xo: Either[String, Int] = ...
val yo: Either[String, Int] = ...
val zo: Either[String, Int] = ...

xo.flatMap(x =>
  yo.flatMap(y =>
    zo.map(z =>
	    x + y + z)))
```

من الأفضل أن تكتب

```scala
for {
  x <- xo
  y <- yo
  z <- zo
} yield x + y + z
```
