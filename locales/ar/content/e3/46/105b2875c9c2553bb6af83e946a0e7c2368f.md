# مقدمة

## البروتوكولات

البروتوكولات هي آلية لتحقيق تعدد الأشكال في Elixir عندما تريد أن يتغير السلوك حسب نوع البيانات.

تُعرَّف البروتوكولات باستخدام `defprotocol` وتحتوي على ترويسة دالة واحدة أو أكثر.

```elixir
defprotocol Reversible do
  def reverse(term)
end
```

يمكن تنفيذ البروتوكولات باستخدام `defimpl`.

```elixir
defimpl Reversible, for: List do
  def reverse(term) do
    Enum.reverse(term)
  end
end
```

يمكن تنفيذ بروتوكول لأي نوع بيانات موجود في Elixir أو لبنية.

عند استدعاء دالة بروتوكول، يتم اختيار التنفيذ المناسب تلقائيًا بناءً على نوع الوسيط الأول.
