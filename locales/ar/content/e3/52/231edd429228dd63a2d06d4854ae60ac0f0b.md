# التثبيت

## الإصدار المستهدف

يستخدم الاختبار في هذا المسار صورة Docker بالاسم `alpine:3.24.1`، وهي حتى سبتمبر 2026 تستخدم `sqlite3 version 3.53.4`.
نحرص على أن تعمل الأدوات التي يوفّرها هذا المسار مع أحدث إصدار من Ubuntu بدعم طويل الأمد (LTS).
وبينما قد يكون لدى المستخدمين إصدارات أحدث مثبّتة، فعليهم أن يدركوا أن بعض الميزات قد لا تعمل مع أداة تشغيل الاختبارات لدينا.
يمكن مقارنة الميزات في [سجل إصدارات SQLite][version-history].

## Windows

لتثبيت SQLite على Windows، اتبع الخطوات التالية:

1. نزّل الملفات الثنائية المُجمّعة مسبقًا لنظام Windows من [صفحة التنزيل الرسمية][sqlite-download].
2. استخرج ملف ZIP الذي نزّلته إلى مجلد تختاره.
   على سبيل المثال، `C:\Program Files\sqlite3`.
3. أضف المجلد الذي يحتوي على `sqlite3.exe` إلى متغير البيئة PATH في النظام.
   تختلف العملية قليلًا من إصدار Windows إلى آخر، لكن يمكن البحث عن المعلومات بسهولة.
   على سبيل المثال [تعليمات Windows 11][windows-11-install] و[تعليمات Windows 10][windows-10-install].

## macOS

في macOS، يكون SQLite مثبّتًا مسبقًا.
لكن إذا احتجت إلى إصدار أحدث، فيمكنك استخدام [Homebrew][homebrew]:

```bash
brew install sqlite
```

## Ubuntu / Debian

بالنسبة إلى Ubuntu والأنظمة المبنية على Debian، يمكنك تثبيت SQLite باستخدام apt:

```bash
sudo apt install sqlite3
```

## CentOS / Fedora / RHEL

على CentOS وFedora والأنظمة المبنية على Red Hat، يمكنك تثبيت SQLite باستخدام yum أو dnf:

```bash
sudo yum install sqlite3
# OR
sudo dnf install sqlite3
```

## Arch Linux

على Arch Linux، يمكنك تثبيت SQLite باستخدام pacman:

```bash
sudo pacman -S sqlite
```

## وسائل تثبيت أخرى وإصدارات أقدم

راجع [صفحة تنزيل SQLite][sqlite-download] لمزيد من المعلومات ووسائل التثبيت البديلة.
يحتوي قسم `Build Product Names and Info` على قالب التسمية لإصدارات SQLite المختلفة، لذا ينبغي أن تكون قادرًا على البحث عن الإصدار الذي تريده باستخدام محرك البحث المفضّل لديك.
