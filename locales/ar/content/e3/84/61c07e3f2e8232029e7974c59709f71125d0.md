# مقدمة

Java لغة ذات أنواع ثابتة، وهذا يعني أن نوع المتغير يكون معروفًا في وقت الترجمة.
إسناد قيمة إلى اسم يُسمّى تعريف متغير.
ويُعرَّف المتغير بتحديد نوعه بشكل صريح.

```java
int explicitVar = 10;
```

يتم تحديث قيمة المتغير عبر العامل `=`.
وهنا لا يمثل الرمز `=` المساواة الرياضية،
وإنما يسنِد قيمة إلى متغير فحسب.
وبمجرد تعريفه، لا يمكن أن يتغير نوع المتغير أبدًا.

```java
int count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning a different type
// count = false;
```

Java لغة [كائنية التوجه][object-oriented-programming] وتتطلب تعريف جميع الدوال داخل _صنف_.
وتُستخدم الكلمة المفتاحية `class` لتعريف صنف.

```java
class Calculator {
    // ...
}
```

تُسمّى الدالة داخل الصنف _طريقة_.
ويمكن أن تحتوي كل طريقة على صفر أو أكثر من المعاملات.
ويجب تحديد نوع جميع المعاملات بشكل صريح، فلا يوجد استنتاج للنوع بالنسبة إلى المعاملات.
وبالمثل، يجب أيضًا تحديد نوع الإرجاع بشكل صريح.
وتُرجَع القيم من الطرق باستخدام الكلمة المفتاحية `return`.
وللسماح باستدعاء الطريقة من أصناف أخرى، يجب إضافة معدِّل الوصول `public`.

```java
class Calculator {
    public int add(int x, int y) {
        return x + y;
    }
}
```

يتم استدعاء الطريقة بتحديد الصنف واسم الطريقة وتمرير وسائط لكل معامل من معاملات الطريقة.

```java
int sum = new Calculator().add(1, 2);  // here the  "add" method has been called to perform the task of addition
```

يُعرَّف النطاق في Java بين المحرفين `{` و`}`.

تدعم Java نوعين من التعليقات.
تسبق التعليقات أحادية السطر علامة `//`، أما التعليقات متعددة الأسطر فتوضع بين `/*` و`*/`.

[object-oriented-programming]: https://docs.oracle.com/javase/tutorial/java/javaOO/index.html
