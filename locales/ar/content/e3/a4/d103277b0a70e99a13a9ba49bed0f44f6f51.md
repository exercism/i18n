# مقدمة

*التوافيق والتباديل* هي الرياضيات التي تُعنى بعدّ الطرق التي يمكن بها اختيار مجموعة من العناصر أو ترتيبها، وسردها. وتغطي مفردات `math.combinatorics` في Factor السؤالين الأساسيين:

- **التوافيق**: اختيارات لا يهمّ فيها الترتيب.
- **التباديل**: ترتيبات يهمّ فيها الترتيب.

لكل سؤال كلمة *للعدّ* تُرجع عددًا، وكلمة *للسرد* تُرجع الاختيارات الفعلية، وإلى جانبهما صيغة `each-` التي تمرّ على العناصر وتستدعي اقتباسًا لكل واحد منها:

```
nCk              ( n k -- m )              ! count of k-combinations
nPk              ( n k -- m )              ! count of k-permutations
all-combinations ( seq k -- combinations )
all-permutations ( seq -- permutations )
each-combination ( seq k quot -- )
each-permutation ( seq quot -- )
```

```factor
USING: math.combinatorics prettyprint ;

5 2 nCk .                        ! => 10
{ 1 2 3 } 2 all-combinations .   ! => { { 1 2 } { 1 3 } { 2 3 } }
{ 1 2 } all-permutations .       ! => { { 1 2 } { 2 1 } }
```
