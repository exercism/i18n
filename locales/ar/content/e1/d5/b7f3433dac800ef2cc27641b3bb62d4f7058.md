# مقدمة

من الأساليب المهمة لتنظيم الكود استخدام فضاءات الأسماء.
قد يحدث تعارض في التسمية بين دالتين، ويمكن حلّه بوضعهما في فضاءَي أسماء مختلفين.
ويمكن أن تتداخل فضاءات الأسماء، وهو ما قد يساعد في هيكلة قواعد الأكواد الكبيرة.
ويتم الوصول إلى فضاءات الأسماء عبر عامل تحديد النطاق `::`.

يوضّح المثال التالي استخدام دالتين مختلفتين باسم `foo`.
ويُستخدمان معًا عبر كتابة فضاء الأسماء الخاص بكل منهما قبلهما.

```cpp
namespace my_ns {
    int foo() {
        return 44;
    }
    namespace my_inner_ns {
        int baz() {
            return 90;
        }
    }
}
namespace my_other_ns {
    int foo() {
        return -2;
    }
}

int myresult{my_ns::foo() + my_other_ns::foo() * my_ns::my_inner_ns::baz()};
```
