# التعليمات

في هذا التمرين ستكتب كودًا يساعد شركة لافتات على إنشاء رسائل مخصّصة للافتاتها.

## 1. أنشئ لافتة مناسبة

نفّذ الطريقة `build_sign( )` التي تقبل سلسلة نصية بوصفها المعامل `occasion` وسلسلة نصية تحمل اسم شخص بوصفها المعامل `name`. سيُدمج المعاملان في قالب سلسلة نصية لإظهار الرسالة على اللافتة.

```abap
build_sign( occasion = 'Birthday' 
            name     = 'Rob').
" => "Happy Birthday Rob!"
```

## 2. أنشئ لافتة عيد ميلاد

نفّذ الطريقة `build_birthday_sign( )` التي تقبل عمرًا، وبناءً على العمر ستحدّد جزءًا من الرسالة على اللافتة. إذا كان العمر 50 أو أكثر، فستتضمّن اللافتة كلمة _mature_، وإلا فستتضمّن اللافتة كلمة _young_.

```abap
build_birthday_sign( 45 ).
" => "Happy Birthday! What a young fellow you are."
```

## 3. أنشئ لافتة تخرّج

نفّذ الطريقة `graduation_for( )` التي تأخذ اسمًا كمعامل سلسلة نصية وسنة كمعامل رقمي، وتستخدم قوالب السلاسل النصية لإنشاء عبارة للافتة تفصل بين سطري الرسالة بسطر جديد.

```abap
graduation_for( name = 'Hannah' 
                year = 2022 ).
" => "Congratulations Hannah!\nClass of 2022"
```

## 4. احسب تكلفة اللافتة

نفّذ الدالة `cost_of( sign currency )` التي تأخذ سلسلة نصية تحمل محتوى اللافتة وسلسلة نصية تمثّل العملة.
للالافتة سعر أساسي قدره 20 بالعملة المعطاة. إضافةً إلى ذلك، يكلّف كل حرف 2. (تُحتسب المسافات البيضاء في الحساب.)
تشمل العبارة المُرجَعة تكلفة إنشاء اللافتة، مكتوبة برقمين بعد الفاصلة العشرية، تليها السلسلة النصية للعملة.

```abap
costOf( sign     = 'Happy Birthday Rob!'
        currency = 'euros');
// => "Your sign costs 58.00 euros."
```
