# حول

حلقة [`while`][while-loops] هي عبارة للتحكّم في مسار تنفيذ الكود، تسمح بتنفيذ الكود ما دام شرط معيّن صحيحًا.
توفّر Swift نوعين من حلقات `while`: حلقة `while` وحلقة `repeat-while`.
يُقيَّم شرط حلقة `while` قبل تنفيذ جسم الحلقة؛ فإذا كان الشرط خطأ، لن يُنفَّذ جسم الحلقة إطلاقًا.
تكون بنية حلقات `while` في Swift على الشكل التالي:

```swift
while <#condition#> {
  <#code#>
}
```

هنا ستُنفَّذ الحلقة ما دام `count` أكبر من 0، وستطبع بذلك العددين 2 و1 ثم `"Liftoff!"`.

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

حلقة [`repeat-while`][while-loops] شبيهة بحلقة `while`، لكن الشرط يُقيَّم بعد تنفيذ جسم الحلقة.
وهذا يعني أن جسم الحلقة سيُنفَّذ دائمًا مرة واحدة على الأقل، حتى لو كان الشرط خطأ.
تكون بنية حلقات `repeat-while` في Swift على الشكل التالي:

```swift
repeat {
  <#code#>
} while <#condition#>
```

هنا ستُنفَّذ الحلقة مرة واحدة فقط، لأن الشرط خطأ.
ولأنها حلقة `repeat-while`، سيُنفَّذ جسم الحلقة مرة واحدة قبل تقييم الشرط.

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```
