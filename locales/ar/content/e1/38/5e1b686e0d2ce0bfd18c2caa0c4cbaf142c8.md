# نبذة

## الصيغة العامة

تُعدّ حلقة `for` من أكثر العبارات استخدامًا لتنفيذ منطق معيّن بشكل متكرر.
وهي في Go تتكوّن من الكلمة المفتاحية `for`، وترويسة، وكتلة كود تحتوي على جسم الحلقة محاطة بالأقواس المعقوفة.
وتتكوّن الترويسة من 3 مكوّنات تفصل بينها فواصل منقوطة `;`: التهيئة، والشرط، والتحديث.

```go
for init; condition; post {
  // loop body - code that is executed repeatedly as long as the condition is true
}
```

- مكوّن **التهيئة** هو كود يُنفَّذ مرة واحدة فقط قبل أن تبدأ الحلقة.
- مكوّن **الشرط** يجب أن يكون تعبيرًا يُقيَّم إلى قيمة منطقية ويتحكّم في الوقت الذي ينبغي أن تتوقف فيه الحلقة.
  سيُنفَّذ الكود داخل الحلقة ما دام هذا الشرط يُقيَّم إلى صحيح.
  وبمجرد أن يُقيَّم هذا التعبير إلى خطأ، لن تُنفَّذ أي تكرارات أخرى للحلقة.
- مكوّن **التحديث** هو كود سيُنفَّذ في نهاية كل تكرار.

**ملاحظة:** خلافًا للغات الأخرى، لا توجد أقواس هلالية `()` تحيط بمكوّنات الترويسة الثلاثة.
بل إن إدراج مثل هذه الأقواس يُعدّ خطأ في التصريف.
ومع ذلك، فإن الأقواس المعقوفة `{ }` التي تحيط بجسم الحلقة مطلوبة دائمًا.

## حلقات `for` - مثال

عادةً ما يُهيّئ مكوّن التهيئة متغير عدّاد، ويتحقّق الشرط مما إذا كان ينبغي متابعة الحلقة أم إيقافها، وعادةً ما يزيد مكوّن التحديث العدّاد في نهاية كل تكرار.

```go
for i := 1; i < 10; i++ {
  fmt.Println(i)
}
```

ستطبع هذه الحلقة الأعداد من `1` إلى `9` (بما في ذلك `9`).
وغالبًا ما يتم تحديد الخطوة باستخدام عبارة زيادة أو إنقاص، كما في المثال أعلاه.

## المكوّنات الاختيارية للترويسة

مكوّنا التهيئة والتحديث في الترويسة اختياريان:

```go
var sum = 1
for sum < 1000 {
	sum += sum
}
fmt.Println(sum)
// Output: 1024
```

بإغفال مكوّني التهيئة والتحديث في حلقة `for` كما هو موضّح أعلاه، فإنك تنشئ حلقة `while` في Go.
لا توجد كلمة مفتاحية `while`.
وهذا مثال على مبدأ Go القائل بأن المفاهيم يجب أن تكون متعامدة.
فبما أنه توجد بالفعل فكرة لتحقيق سلوك حلقة `while`، ألا وهي حلقة `for`، لم تُضَف `while` كمفهوم إضافي.

## `break` و `continue`

داخل جسم الحلقة يمكنك استخدام الكلمة المفتاحية `break` لإيقاف تنفيذ الحلقة تمامًا:

```go
for n := 0; n <= 5; n++ {
  if n == 3 {
    break
  }
  fmt.Println(n)
}
// Output:
// 0
// 1
// 2
```

في المقابل، لا توقف الكلمة المفتاحية `continue` سوى تنفيذ التكرار الحالي وتتابع إلى التكرار التالي:

```go
for n := 0; n <= 5; n++ {
  if n%2 == 0 {
    continue
  }
  fmt.Println(n)
}
// Output:
// 1
// 3
// 5
```

## حلقة `for` اللانهائية

مكوّن الشرط في ترويسة الحلقة اختياري أيضًا.
بل يمكنك كتابة حلقة بلا ترويسة على الإطلاق:

```go
for {
  // Endless loop...
}
```

لن تنتهي هذه الحلقة أبدًا إلا إذا خرج البرنامج أو وُجد `break` في جسمها.

## التسميات و `goto`

عندما نستخدم `break`، يتوقف تنفيذ الحلقة الداخلية.
وبالمثل، عندما نستخدم `continue`، يُنفَّذ التكرار التالي في الحلقة الداخلية.

ومع ذلك، هذا ليس مرغوبًا فيه دائمًا.
يمكننا استخدام التسميات مع `break` و `continue` لتحديد الحلقة التي نريد الخروج منها أو متابعة التكرار فيها بدقة.

في هذا المثال ننشئ تسمية `OuterLoop` تشير إلى الحلقة الخارجية.
وفي الحلقة الداخلية، ولنقول إننا نريد الخروج من الحلقة الخارجية، نستخدم `break` متبوعة باسم تسمية الحلقة الخارجية:

```go
OuterLoop:
    for i := 0; i < 10; i++ {
        for j := 0; j < 10; j++ {
            // ...
            break OuterLoop
        }
    }
```

استخدام التسميات مع `continue` سيعمل أيضًا، وفي هذه الحالة سيُتابَع إلى التكرار التالي في الحلقة التي تشير إليها التسمية.

تمتلك Go أيضًا الكلمة المفتاحية `goto` التي تعمل بطريقة مشابهة وتتيح لنا الانتقال من قطعة كود إلى قطعة كود أخرى موسومة بتسمية.

**تحذير:** على الرغم من أن Go تتيح الانتقال إلى قطعة كود موسومة بتسمية، فإن استخدام هذه الميزة في اللغة قد يجعل الكود صعب القراءة للغاية.
ولهذا السبب، غالبًا لا يُنصح باستخدام التسميات.
