# مقدمة

TypeScript هو JavaScript مع صياغة للأنواع، ما يجعله لغة برمجة قوية الأنواع، تدعم أساليب البرمجة الكائنية والأمرية والتعريفية (مثل البرمجة الوظيفية)، وتمنحك أدوات أفضل مهما كان حجم مشروعك.

ولأنك [لا تستطيع تعلّم TypeScript دون تعلّم JavaScript][handbook-js-or-ts]، يركّز بعض محتوى هذا المسار على تعليم مفاهيم JavaScript، بينما يركّز بعضه الآخر على ميزات TypeScript الخاصة فقط.

## الإسناد وإعادة الإسناد

هناك بعض الأساليب الأساسية لإسناد القيم إلى الأسماء في TypeScript، إما باستخدام المتغيرات أو الثوابت.
في Exercism، تُكتب المتغيرات دائمًا بأسلوب [camelCase][wiki-camel-case]، وتُكتب الثوابت بأسلوب [SCREAMING_SNAKE_CASE][wiki-snake-case].
لا يوجد دليل رسمي يجب اتباعه، ولكل شركة أو مؤسسة دليل أسلوب خاص بها.
_لا تتردد في كتابة المتغيرات كما تشاء_.
وميزة كتابتها بالشكل الذي أُعدّت به التمارين أنها ستُبرَز بشكل مختلف في واجهة الويب وفي معظم بيئات التطوير.

يمكن تعريف المتغيرات في TypeScript باستخدام الكلمة المفتاحية [`const`][mdn-const] أو [`let`][mdn-let] أو [`var`][mdn-var].

يمكن للمتغير أن يشير إلى قيم مختلفة خلال عمره عند استخدام `let` أو `var`.
على سبيل المثال، يمكن تعريف `myFirstVariable` وإعادة تعريفه مرات عديدة باستخدام عامل الإسناد `=`:

```typescript
let myFirstVariable = 1
myFirstVariable = 0
myFirstVariable = 42
```

وعلى عكس `let` و`var`، فإن المتغيرات التي تُعرَّف بـ `const` يمكن إسنادها مرة واحدة فقط.
ويُستخدم هذا لتعريف الثوابت في TypeScript.

```typescript
const MY_FIRST_CONSTANT = 10

// Can not be re-assigned.
MY_FIRST_CONSTANT = 20
// => TypeError: Assignment to constant variable.
```

ولأن TypeScript يستطيع كشف ذلك بشكل ساكن، سيُصدر مترجم TypeScript خطأً أيضًا:

```typescript
// ^? Cannot assign to 'MY_FIRST_CONSTANT' because it is a constant.(2588)
```

هذا يعني أنك لست بحاجة إلى تشغيل الكود لكشف `TypeError`.

<!--prettier-ignore -->
~~~~exercism/note
💡 في تمرين تعليمي لاحق، يُستكشف الفرق بين إسناد _الثابت_ أو ربطه و_قيمة_ الثابت ويُشرح.
~~~~

## استنتاج الأنواع

دون التعمق كثيرًا في موضوع [استنتاج الأنواع][handbook-type-inference]، ينبغي أن تعرف أن المتغير المُسنَد له عادةً نوع مُستنتَج، حتى دون تعليق النوع.

```typescript
const MY_FIRST_CONSTANT = 10
// ^? const MY_FIRST_CONSTANT: number
```

ثم يُفرَض هذا النوع في جميع أنحاء الكود.
وهذا يعني أيضًا أن الكود التالي صالح في JavaScript:

```javascript
let myFirstVariable = 1
myFirstVariable = 'Some string'
```

لكن TypeScript يعترض عليه:

```typescript
let myFirstVariable = 1
myFirstVariable = 'Some string'
// ^? Type 'string' is not assignable to type 'number'.(2322)
```

تضمن هذه الميزة أمان الأنواع حتى عند عدم استخدام تعليقات النوع.

## إعلانات الدوال

في TypeScript، تُغلَّف وحدات الوظائف في _الدوال_، وعادةً ما تُجمَّع الدوال معًا في الملف نفسه إذا كانت تنتمي إلى بعضها.
يمكن لهذه الدوال أن تأخذ معاملات (وسائط)، وأن _تُرجع_ قيمة باستخدام الكلمة المفتاحية `return`.
تُستدعى الدوال باستخدام صياغة `()`.

```typescript
function add(num1: number, num2: number): number {
  return num1 + num2
}

add(1, 3)
// => 4
```

ينبغي عادةً تعليق نوع على معاملات الدالة باستخدام نقطتين (`:`) متبوعتين بالنوع.
ويمكن تعليق نوع على القيم التي تُرجعها الدالة بعد إغلاق قائمة المعاملات باستخدام نقطتين (`:`) متبوعتين بالنوع.

<!--prettier-ignore -->
~~~~exercism/note
💡 في TypeScript هناك _العديد_ من الأساليب المختلفة لإعلان دالة.
تبدو هذه الأساليب الأخرى مختلفة عن استخدام الكلمة المفتاحية `function`.
يحاول المسار تقديمها تدريجيًا، لكن إن كنت تعرفها بالفعل، فلا تتردد في استخدام أيٍّ منها.
في معظم الحالات، ليس استخدام أحدها أفضل أو أسوأ من الآخر.
~~~~

## تعليقات النوع

كما هو موضح في إعلان الدالة `add`، للمعاملات تعليق نوع صريح `: number`.
تدعم تعريفات المتغيرات، وخصائص الأصناف، وإعلانات الدوال وغيرها تعليقات النوع.

يُفرَض كلٌّ من تعليق النوع الصريح والأنواع المُستنتَجة بواسطة مدقّق الأنواع.

```typescript
add('foo', 3)
// ^? Argument of type 'string' is not assignable to parameter of type 'number'.(2345)
```

## الإتاحة لملفات أخرى

لجعل دالة أو ثابت أو متغير متاحًا في _ملفات أخرى_، يجب [تصديرها][mdn-export] باستخدام الكلمة المفتاحية `export`.
ويمكن لملف آخر بعد ذلك [استيراد][mdn-import] هذه العناصر باستخدام الكلمة المفتاحية `import`.
يُعرف هذا أيضًا بنظام الوحدات.
ومن الأمثلة الرائعة على ذلك كيفية عمل جميع الاختبارات.
لكل تمرين ملف واحد على الأقل، مثل `lasagna.ts`، يحتوي على _التنفيذ_.
وبالإضافة إلى ذلك، هناك ملف آخر على الأقل، مثل `lasagna.test.ts`، يحتوي على _الاختبارات_.
يستورد هذا الملف الكيانات العامة (أي المُصدَّرة) لاختبار التنفيذ:

```typescript
// file.ts
export const MY_VALUE = 10

export function add(num1, num2) {
  return num1 + num2
}

// file.test.ts
import { MY_VALUE, add } from './file.js'

add(MY_VALUE, 5)
// => 15
```
