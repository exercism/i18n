# مقدمة

التعبيرات النمطية وسيلة عالية المرونة _لمطابقة الأنماط_ في السلاسل النصية، باستخدام لغة خاصة بالمجال (DSL) مصممة لهذا الغرض.

كثير من قدرات التعبيرات النمطية مدمجة في Base R، وقد ترى أمثلة عليها في كود أقدم.

أما الكود الجديد، فيُوصى _بشدة_ باستخدام مكتبة [`stringr`][web-stringr].

وكما ذُكر في [مفهوم السلاسل النصية][concept-strings]، فإن `stringr` تتمتع بتوثيق جيد، يكتبه عادةً مؤلف الحزمة أو مؤلفوها.

- [موقع مرجعي][web-stringr]
- [ورقة مراجعة سريعة][cheat-stringr].
- [فصل السلاسل النصية][book-strings] و[فصل التعبيرات النمطية][book-regex] في كتاب "R for Data Science".

كثير من الدوال التي تحدثنا عنها بالفعل في [مفهوم][concept-strings] `Strings` مصممة أصلًا لعمليات البحث بالتعبيرات النمطية.

لقد أبقينا مفهوم السلاسل النصية بسيطًا نسبيًا بالاكتفاء بمطابقة السلاسل النصية الحرفية، لكن يمكن استخدام أي نمط تعبير نمطي بدلًا من ذلك.

رسميًا، يُنشأ التعبير النمطي في R باستدعاء [`regex()`][ref-regex].
وللتسهيل، تعامل دوال `stringr` أي سلسلة نمطية على أنها تعبير نمطي.
في المثال أدناه، أول استدعاء لـ `str_replace_all()` هو سكر نحوي للنسخة الثانية:

```R
input <- "Some input string"

# "\\s" matches any whitespace character
input |> str_replace_all("\\s", "_")
[1] "Some_input_string"

input |> str_replace_all(regex("\\s"), "_")
[1] "Some_input_string"
```

[ورقة المراجعة السريعة][cheat-stringr] دليل مفيد: كل الدوال التي تقبل معاملًا باسم `pattern` (المطبوعة بالأحمر) تقبل تعبيرًا نمطيًا، وتلخّص الصفحة 2 صياغة التعبيرات النمطية.

لاحظ أن دالة [`regex()`][ref-regex] قد تظل مهمة إذا احتجت إلى تجاوز الإعدادات الافتراضية، مثل حساسية حالة الأحرف أو الإعداد المحلي.

```R
# default is case sensitive
"A Mixed Assortment" |> 
    str_replace_all(regex("[aeiou]", ignore_case = TRUE), "*")
#> [1] "* M*x*d *ss*rtm*nt"
```

تتضمن كثير من رموز التعبيرات النمطية شرطة مائلة عكسية، مثل `\s` المستخدمة أعلاه.
في سلاسل R العادية، يجب تخطّي `\` بمضاعفتها، ومن هنا `"\\s"`.

قد تتكاثر الشرطات المائلة العكسية وتصبح مربكة، لذا قد يساعد استخدام [السلاسل النصية الخام][book-raw] في الحالات المعقدة.

افتراضيًا، صياغة تعريف السلسلة النصية الخام هي `r"( )"`، لكن يُسمح بمحددات أخرى.
ولأن الأقواس الهلالية `( )` والأقواس المربعة `[ ]` كلتيهما شائعتان في صياغة التعبيرات النمطية (لمجموعات الالتقاط ومجموعات الخيارات)، فقد تكون الأقواس المعقوفة `{ }` خيارًا جيدًا.

```R
input |> str_replace_all(r"{\s\w}", "__")
#> [1] "Some__nput__tring"
```

## اكتشاف المطابقات

إليك بعض الأسئلة، ودوال يمكنها المساعدة في الإجابة عنها.

تستخدم بعض الأمثلة `fruit`، وهو متجه يضم 80 اسمًا من أسماء الفواكه مرفق مع `stringr` للتدريب.

_هل تحتوي السلسلة النصية على مطابقة؟_
`str_detect()`، أو `str_starts()` و`str_ends()` لتجنّب استخدام المراسي `^` أو `$`.

```R
# berries begining with b
fruit |> str_detect("^b.*berry") |> head(15)
#> [1] FALSE FALSE FALSE FALSE FALSE  TRUE  TRUE FALSE FALSE  TRUE  TRUE FALSE FALSE FALSE FALSE

# alternative syntax
fruit |> str_starts("b.*berry") |> head(15)
#> [1] FALSE FALSE FALSE FALSE FALSE  TRUE  TRUE FALSE FALSE  TRUE  TRUE FALSE FALSE FALSE FALSE
```

_إرجاع السلاسل النصية التي تحتوي على مطابقة فقط؟_
استخدم `str_subset()` للحصول على السلاسل النصية، و`str_which()` للحصول على الفهارس.

```R
fruit |> str_subset("a...e")
[1] "apple"       "blackberry"  "mandarine"   "nectarine"   "pineapple"   "pomegranate" "raspberry"   "salal berry"
> fruit |> str_which("a...e")
[1]  1  7 48 51 62 64 70 73
```

_كم عدد المطابقات في كل سلسلة نصية؟_
استخدم `str_count()`.

```R
# count vowels
fruit |> str_count("[aeiou]") |> head(10)
#> [1] 2 3 4 3 3 2 2 3 5 3
```

_أين توجد المطابقة؟_
`str_view()` للاستخدام التفاعلي، و`str_locate()` أو `str_locate_all()` بشكل أعم.

```R
# str_view only shows matching elements, with match in < > delimiters
fruit |> str_view("a...e")
 [1] │ <apple>
 [7] │ bl<ackbe>rry
[48] │ mand<arine>
[51] │ nect<arine>
[62] │ pine<apple>
[64] │ pomegr<anate>
[70] │ r<aspbe>rry
[73] │ sal<al be>rry

# str_locate returns all elements
fruit |> str_locate("a...e") |> head(10)
      start end
 [1,]     1   5
 [2,]    NA  NA
 [3,]    NA  NA
 [4,]    NA  NA
 [5,]    NA  NA
 [6,]    NA  NA
 [7,]     3   7
 [8,]    NA  NA
 [9,]    NA  NA
[10,]    NA  NA
```

## الالتقاطات

غالبًا ما نريد معرفة _ما_ الذي يطابق.
ويُحقَّق ذلك بتضمين مجموعات الالتقاط بين أقواس داخل التعبير النمطي.

يمكن الإشارة إلى الالتقاطات داخل التعبير النمطي نفسه، باستخدام `\1` و`\2` وما إلى ذلك.
على سبيل المثال، إيجاد أزواج متكررة من الأحرف:

```R
fruit |> str_subset("(..)\\1")
[1] "banana"      "coconut"     "cucumber"    "jujube"      "papaya"      "salal berry"
```

وبصياغة مشابهة، يمكن استخدام الالتقاطات في السلاسل النصية البديلة:

```R
# double to triple
fruit |> 
  str_subset("(..)\\1") |> 
  str_replace("(..)\\1", "\\1\\1\\1")
[1] "bananana"      "cococonut"     "cucucumber"    "jujujube"      "papapaya"      "salalal berry"
```

اجمع المطابقات لمعالجتها لاحقًا باستخدام دالة `str_match()` لأول مطابقة فقط، أو `str_match_all()` لجميع المطابقات.

تميل مجموعات الالتقاط إلى إنتاج مخرجات معقدة في أي لغة.
أما نهج R (_وهو أيضًا قائم على المتجهات كتحدٍّ إضافي_) فهو توليد مصفوفة من `str_match()`، بصف واحد لكل سلسلة نصية مدخلة، ويحتوي العمود 1 على السلسلة النصية المطابقة كاملة، بينما تحتوي الأعمدة المتبقية على مجموعات الالتقاط المختلفة.

قد يكون استخدام المجموعات المُسمّاة ميزة، إذ تصبح أسماء الأعمدة في مصفوفة النتائج.

```R
recipe <- "dissolve 25g sugar in 200ml water"
recipe |> str_match("(\\d+g) .* (\\d+ml)")
     [,1]                 [,2]  [,3]   
[1,] "25g sugar in 200ml" "25g" "200ml"

# use named capture groups
recipe |> str_match("(?<wt>\\d+g) .* (?<vol>\\d+ml)")
                          wt    vol    
[1,] "25g sugar in 200ml" "25g" "200ml"
```

لم نتحدث كثيرًا عن المصفوفات في هذا المنهج، وإن كان هناك [مستند مفهوم][concept-matrices-arrays] يمكنك الوصول إليه.
لا تنسجم المصفوفات جيدًا مع منظومة Tidyverse، رغم أنها جزء من Base R منذ وقت طويل.

باختصار سريع: تعامل مع المصفوفات كمتجهات بفهرسين، بالترتيب `[rows, cols]`.
اترك أي فهرس فارغًا للحصول على الصف أو العمود كاملًا.

عند الحصول على صف واحد `r` بواسطة `m[r,]` أو عمود واحد `c` بواسطة `m[,c]`، تُسطَّح القيمة المُرجَعة إلى متجه افتراضيًا.

```R
> amounts <- recipe |> str_match("(?<wt>\\d+g) .* (?<vol>\\d+ml)")

# get all of row 1, as a named vector
> amt1 <- amounts[1,]
> amt1
                                       wt                  vol 
"25g sugar in 200ml"                "25g"              "200ml" 

# get a vector element
amt1["wt"] |> unname()
[1] "25g"
```

حتماً، تنتج `str_match_all()` مخرجات ذات بنية أكبر:

- تكون النتيجة قائمة، بعنصر واحد لكل سلسلة نصية مدخلة.
- إذا كانت هناك سلسلة نصية مدخلة واحدة فقط، فأزل تغليف القائمة عن المخرجات بفهرسة `[[1]]` كما هو موضح في [مفهوم القوائم][concept-lists].
- كل عنصر هو مصفوفة، بأعمدة كما في `match()`.
- كل صف في المصفوفة هو التقاط ناجح.

```R
mix <- "Mix 200g of sugar, 180g of flour and 150g of butter"

# raw output
> str_match_all(mix, "(\\d+)g")
[[1]]
     [,1]   [,2] 
[1,] "200g" "200"
[2,] "180g" "180"
[3,] "150g" "150"

# we just want the first list element
> str_match_all(mix, "(\\d+)g")[[1]]
     [,1]   [,2] 
[1,] "200g" "200"
[2,] "180g" "180"
[3,] "150g" "150"

# captures are in column 2, so get that as a vector
> str_match_all(mix, "(\\d+)g")[[1]][,2]
[1] "200" "180" "150"
```

بالطبع، قد تفشل المطابقات.
وتكون النتيجة حينها القيمة الخاصة `NA`.
كن مستعدًا لاختبار ذلك، كما هو موضح في [مفهوم العدم][concept-nothingness].

```R
# failed match
recipe |> str_match("(not here)")
     [,1] [,2]
[1,] NA   NA  
```
