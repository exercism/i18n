# التعليمات

أثناء عملك في _Instruments of Texas_، تُوكل إليك مهمة العمل على آلة حاسبة تجريبية مكتوبة بلغة C#. أنت تبني منصة اختبار للتحقق من عدد من دوال الآلة الحاسبة، بدءًا من الضرب. وستلاحظ أن هناك اهتمامًا خاصًّا عندما يكون طرفا عملية الضرب سالبين.

لقد زُوِّدت بالصنف `Calculator`، ولا ينبغي تعديله.

## 1. أكمل تعريف استثناء `CalculationException` المعرَّف من المستخدم

أكمل تعريف مُنشئ `CalculationException`، والذي سيحتاج إلى تخزين (تغليف) أي استثناء تُطلقه الآلة الحاسبة، إضافة إلى طرفَي العملية الجاري معالجتهما لحظة إطلاق الاستثناء.

## 2. تعامل مع حالات تجاوز السعة في الآلة الحاسبة وقدِّم معلومات موسَّعة إلى المستدعي

نفِّذ طريقة `CalculatorTestHarness.Multiply()`، التي ينبغي أن تستدعي طريقة `Calculator.Multiply()` في نسخة `Calculator` الممرَّرة إلى المُنشئ، مع تمرير القيمتين الصحيحتين `x` و `y`. إذا حدث تجاوز سعة في طريقة `Calculator.Multiply()`، فستُطلق استثناءً من نوع `OverflowException`. ينبغي التقاط هذا الاستثناء في طريقة `CalculatorTestHarness.Multiply()` ولفّه داخل `CalculationException`، وينبغي تخزين طرفَي العملية، وهما القيمتان `x` و `y` الممرَّرتان. كما ينبغي إطلاق كائن `CalculationException` المُنشأ حديثًا. ويمكنك تجاهل القيمة التي تُرجعها طريقة `Calculator.Multiply()` إذا نجحت.

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.Multiply(Int32.MaxValue, Int32.MaxValue);
// => throws an instance of CalculationException

var cth2 = new CalculatorTestHarness(new Calculator());
cth2.Multiply(3, 2);
// => silently exits
```

## 3. اختبر عملية الضرب بمدخلات صحيحة

نفِّذ طريقة `CalculatorTestHarness.TestMultiplication()` التي تأخذ عددين صحيحين وتستدعي طريقة `CalculatorTestHarness.Multiply()`. فتُرجع `"Multiply succeeded"`.

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.TestMultiplication(6, 7);
// => "Multiply succeeded"
```

## 4. اختبر عملية الضرب بمدخلات سالبة

عدِّل طريقة `CalculatorTestHarness.TestMultiplication()` بحيث تُرجع `"Multiply failed for negative operands. <INNER_EXCEPTION_MESSAGE>"` إذا كان الوسيطان الصحيحان سالبين (أقل من صفر).

ينبغي استبدال العنصر النائب `<INNER_EXCEPTION_MESSAGE>` برسالة الاستثناء الداخلي في `CalculationException`.

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.TestMultiplication(-2, -Int32.MaxValue);
// => "Multiply failed for negative operands. " + innerException.Message
```

## 5. اختبر عملية الضرب بمدخلات موجبة

عدِّل طريقة `CalculatorTestHarness.TestMultiplication()` بحيث تُرجع `"Multiply failed for mixed or positive operands. <INNER_EXCEPTION_MESSAGE>"` إذا كان أحد الوسيطين الصحيحين على الأقل غير سالب.

ينبغي استبدال العنصر النائب `<INNER_EXCEPTION_MESSAGE>` برسالة الاستثناء الداخلي في `CalculationException`.

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.TestMultiplication(Int32.MaxValue, Int32.MaxValue);
// => "Multiply failed for mixed or positive operands. " + innerException.Message
```
