# الاسم المستعار

تتيح لك [الصيغة الخاصة `alias`][alias] تقصير الاسم الذي تشير به إلى وحدة خارجية أو تغييره. ويمكن تحديد اسم مخصص باستخدام خيار `:as`.

```elixir
defmodule Square do
  alias Integer, as: I

  def area(a), do: I.pow(a, 2)
end
```

عند استخدامه بدون أي وسائط، يختصر اسم الوحدة إلى جزئه الأخير، على سبيل المثال:

```elixir
alias MyApp.Account.User
# is the same as
alias MyApp.Account.User, as: User
```

يمكن تجميع عدة أسماء مستعارة معًا باستخدام `{}`:

```elixir
alias MyApp.Account.{User, EmailValidation}
# is the same as
alias MyApp.Account.User
alias MyApp.Account.EmailValidation
```

عادةً تُضاف الأسماء المستعارة في بداية تعريف الوحدة، لكن يمكن إضافتها في أي مكان. ولها نطاق معجمي، ما يعني أن الاسم المستعار المضاف داخل تعريف دالة لن يكون متاحًا في دالة أخرى.

الأسماء المستعارة غير المستخدمة تسبب تحذيرات من المترجم.

[alias]: https://hexdocs.pm/elixir/Kernel.SpecialForms.html#alias/2
