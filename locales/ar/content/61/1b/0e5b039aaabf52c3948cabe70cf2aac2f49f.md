# التعليمات

تعمل فرقة الرقص على إعداد عرض نهاية العام: كم طريقة يمكن بها ترتيب الراقصين، وكيف يتوزع زمن العرض بين الفصول.

تُنجَز المهام الخمس كلها في الصنف `FORMATION_COUNT`.

## 1. كم عدد التشكيلات؟

مع وجود `n` من الراقصين، هناك مضروب العدد `n` من الطرق لترتيبهم في صف: `n` خيارات لمن يقف في المقدمة، ثم `n-1` لمن يليه، وهكذا. أرجِع ذلك على هيئة `INTI`. وصفر من الراقصين له تشكيل واحد بالضبط، وهو التشكيل الفارغ.

```sather
FORMATION_COUNT::line_ups(5)
-- => 120
FORMATION_COUNT::line_ups(20)
-- => 2432902008176640000
```

## 2. اكتبه كنص

العدد نفسه على هيئة سلسلة نصية، بكل رقم من أرقامه.

```sather
FORMATION_COUNT::line_ups_text(25)
-- => "15511210043330985984000000"
```

لا يستطيع `INT` أن يحمل هذا العدد، وهذا هو المقصود بالمهمة.

## 3. نصيب فصل واحد

عرض يتكوّن من `acts` من الفصول المتساوية يمنح كل فصل `1/acts` من زمن العرض. أرجِع ذلك على هيئة `RAT`.

```sather
FORMATION_COUNT::share(3)
-- => 1/3
```

## 4. فصلان معًا

اجمع نصيبين وأرجِع المجموع بدقة تامة.

```sather
FORMATION_COUNT::combined(FORMATION_COUNT::share(2), FORMATION_COUNT::share(3))
-- => 5/6
```

## 5. هل يملأ العرض كاملًا؟

أجب عمّا إذا كان نصيب ما هو العرض كاملًا بالضبط، أي إذا كان يساوي الواحد بالضبط.

```sather
FORMATION_COUNT::covers_whole_show(#RAT(3, 3))
-- => true
FORMATION_COUNT::covers_whole_show(#RAT(2, 3))
-- => false
```
