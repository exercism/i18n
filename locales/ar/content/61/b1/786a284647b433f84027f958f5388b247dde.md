# مقدمة

_النوع التعدادي_ هو نوع بيانات خاص يتيح للمتغير أن يكون واحدة من مجموعة ثوابت معرّفة مسبقًا.
يجب أن تكون قيمة المتغير مساوية لإحدى القيم المعرّفة مسبقًا له.
من الأمثلة الشائعة اتجاهات البوصلة (القيم `NORTH` و`SOUTH` و`EAST` و`WEST`) وأيام الأسبوع.

ولأنها ثوابت، تُكتب أسماء حقول النوع التعدادي بأحرف كبيرة.

## تعريف نوع تعدادي

في لغة البرمجة Java، تعرّف النوع التعدادي باستخدام الكلمة المفتاحية `enum`.
على سبيل المثال، تعرّف نوعًا تعداديًا لأيام الأسبوع على النحو التالي:

```java
public enum DayOfWeek {
    SUNDAY,
    MONDAY,
    TUESDAY,
    WEDNESDAY,
    THURSDAY,
    FRIDAY,
    SATURDAY
}
```

استخدم الأنواع التعدادية كلما احتجت إلى تمثيل مجموعة ثابتة من الثوابت.
ويشمل ذلك الأنواع التعدادية الطبيعية مثل الكواكب في نظامنا الشمسي، ومجموعات البيانات التي تعرف فيها كل القيم الممكنة وقت التصريف، مثل خيارات القائمة ومفاتيح سطر الأوامر وما إلى ذلك.

## استخدام نوع تعدادي

هذا كود يوضح كيف تستخدم النوع التعدادي `DayOfWeek` المعرّف أعلاه:

```java
public class Shop {
    public String getOpeningHours(DayOfWeek dayOfWeek) {
        switch (dayOfWeek) {
            case MONDAY:
            case TUESDAY:
            case WEDNESDAY:
            case THURSDAY:
            case FRIDAY:
                return "9am - 5pm";
            case SATURDAY:
                return "10am - 4pm"
            case SUNDAY:
                return "Closed.";
        }
    }
}
```

```java
var shop = new Shop();
shop.getOpeningHours(DayOfWeek.WEDNESDAY);
// => "9am - 5pm"
```

## إضافة طرق وحقول

الأنواع التعدادية في لغة البرمجة Java أقوى بكثير من نظيراتها في اللغات الأخرى.
يعرّف تعريف `enum` صنفًا (يسمى نوعًا تعداديًا).
يمكن أن يتضمن جسم صنف التعداد طرقًا وحقولًا أخرى:

```java
public enum Rating {
    GREAT(5),
    GOOD(4),
    OK(3),
    BAD(2),
    TERRIBLE(1);

    private final int numberOfStars;

    Rating(int numberOfStars) {
        this.numberOfStars = numberOfStars;
    }

    public int getNumberOfStars() {
        return this.numberOfStars;
    }
}
```

استدعاء الطريقة `getNumberOfStars` على أحد أعضاء النوع التعدادي `Rating`:

```java
Rating.GOOD.getNumberOfStars();
// => 4
```
