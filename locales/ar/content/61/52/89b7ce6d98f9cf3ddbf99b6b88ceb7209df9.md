# المقدمة

## السمات

توفر [سمة `Attribute` في C#](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/) وسيلة لتزيين تعريف ما وربط بيانات وصفية به: صنف، أو طريقة، أو تعداد، أو حقل، أو خاصية، أو أي [تعريفات أخرى مدعومة](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/#attribute-targets).

يمكنك تطبيق سمة بإضافتها في السطر الذي يسبق التعريف، باستخدام `ClassAttribute` و`FieldAttribute`:

```csharp
[Class]
class MyClass
{
    [Field]
    int myField;
}
```

تربط هذه البيانات الوصفية التعريفية معلومات منظمة إضافية بالكود فقط، ولا تغيّر سلوكه. لكن هذه البيانات الوصفية تستخدمها أجزاء أخرى من الكود لتغيير كيفية تصرف هدفها، أو لإضافة بعض وظائفها أو تغييرها أو إزالتها أو تقييدها.

هناك العديد من [السمات المعرّفة مسبقًا والمحجوزة](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/attributes/general#conditional-attribute)، مثل `Flags` و`Obsolete` و`Conditional` و`Experimental`. ولكل واحدة منها معنى دلالي محدد يمكنك البحث عنه في توثيق C#. لاحظ أن الاسم الكامل لسمة مثل [`Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute) يأخذ الصيغة `<Name>Attribute` (مثل `FlagsAttribute`).

## تعدادات الأعلام

يمثل [نوع `enum` في C#](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/builtin-types/enum) مجموعة ثابتة من الثوابت المسماة (تعداد).

عادةً، لا يمكن لعضو `enum` واحد أن يشير إلا إلى ثابت واحد بالضبط من تلك الثوابت المسماة. لكن أحيانًا يكون من المفيد الإشارة إلى أكثر من ثابت واحد. وللقيام بذلك يمكنك إضافة [سمة `Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute) إلى `enum`.

يمكن تعريف تعداد أعلام كما يلي (باستخدام تدوين الأعداد الصحيحة الثنائية `0b`):

```csharp
[Flags]
enum PhoneFeatures
{
    Call = 0b00000001,
    Text = 0b00000010
}
```

في أي نسخة من `PhoneFeatures` تكون قيمتها `0b00000011`، يكون علما `Call` _و_ `Text` فيها مضبوطين.

افتراضيًا، يُستخدم النوع `int` لقيم أعضاء التعداد. ويمكنك استخدام نوع عدد صحيح مختلف بتحديد النوع في تعريف التعداد:

```csharp
[Flags]
enum PhoneFeatures : byte
{
    Call = 0b00000001,
    Text = 0b00000010
}
```
