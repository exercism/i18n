# التعليمات

في هذا التمرين ستتعامل مع أسطر السجل.

كل سطر سجل هو سلسلة نصية بتنسيق كالتالي: `"[<LEVEL>]: <MESSAGE>"`.

هناك ثلاثة مستويات مختلفة للسجل:

- `INFO`
- `WARNING`
- `ERROR`

لديك ثلاث مهام، كل مهمة منها تأخذ سطر سجل وتطلب منك أن تفعل به شيئًا.

## 1. الحصول على الرسالة من سطر السجل

نفّذ الدالة `message` لتُرجع رسالة سطر السجل:

```fsharp
message "[ERROR]: Invalid operation"
// => "Invalid operation"
```

يجب إزالة أي مسافات بيضاء في البداية أو النهاية:

```fsharp
message "[WARNING]:  Disk almost full\r\n"
// => "Disk almost full"
```

## 2. الحصول على مستوى السجل من سطر السجل

نفّذ الدالة `logLevel` لتُرجع مستوى السجل الخاص بسطر السجل، بحروف صغيرة:

```fsharp
logLevel "[ERROR]: Invalid operation"
// => "error"
```

## 3. إعادة تنسيق سطر السجل

نفّذ الدالة `reformat` التي تعيد تنسيق سطر السجل، بحيث تأتي الرسالة أولًا ثم مستوى السجل بعدها بين الأقواس الهلالية:

```fsharp
reformat "[INFO]: Operation completed"
// => "Operation completed (info)"
```
