# نبذة

يوفّر JavaScript عاملي الزيادة والإنقاص.
وهما يُعدّلان المتغير في مكانه.
يضيف العامل `++` واحدًا إلى العدد، ويطرح العامل `--` واحدًا من العدد.

```javascript
let i = 3;
i++;
// i is now 4

let j = 0;
j--;
// j is now -1
```

يوضح المثال أعلاه عامل الزيادة والإنقاص في صيغته اللاحقة.
في هذه الحالة يوضع العامل بعد المتغير، وتكون القيمة المُرجَعة من التعبير هي قيمة المتغير _قبل_ الزيادة أو الإنقاص.

```javascript
let a = 3;
let b = a++;
// a = 4
// b = 3
```

وهناك أيضًا الصيغة السابقة، حيث يوضع العامل قبل المتغير.
وفي هذه الحالة تكون القيمة المُرجَعة هي قيمة المتغير _بعد_ الزيادة أو الإنقاص.

```javascript
let a = 3;
let b = ++a;
// a = 4
// b = 4
```
