# مقدمة

يقدّم هذا التمرين الجمل الشرطية: الاختيار بين مسارين أو أكثر من مسارات العمل بناءً على قيمة. وهو يبني على القيم المنطقية التي تعرّفت عليها في [تسلل أنالين][annalyns] وعلى الحساب على الأعداد الصحيحة من [تحويل العملات][currency-conversion].

## كلمات المقارنة

توجد هذه كلها في [`math`][math] (وفي [`kernel`][kernel] بالنسبة إلى `=`):

```
=  ( x y -- ? )    ! equal
<  ( x y -- ? )    ! less than
<= ( x y -- ? )    ! less than or equal
>  ( x y -- ? )    ! greater than
>= ( x y -- ? )    ! greater than or equal
```

```factor
3 3 = .     ! => t
2 3 < .     ! => t
3 3 <= .    ! => t
3 4 = not . ! => t    (inequality: combine = with not)
```

‏`zero?` (في [`math`][math]) اختصار لفحص `0 =` الشائع، فهي تستهلك العدد وتدفع ما إذا كان صفرًا:

```
zero? ( n -- ? )    ! t when n is 0
```

## فحوص النطاق

‏`between?` (في [`math.order`][math.order]) تفحص ما إذا كانت قيمة تقع ضمن نطاق شامل للطرفين. وهي مفيدة عندما يعتمد إجراء ما على النطاق الذي يقع فيه العدد:

```
between? ( x lo hi -- ? )    ! lo <= x <= hi (inclusive)
```

```factor
5 1 10 between? .    ! => t
0 1 10 between? .    ! => f
10 1 10 between? .   ! => t   (inclusive at both ends)
```

ستراها غالبًا كشرط في `cond`، مثل `dup 1 4 between?`، لاختيار فرع حسب النطاق بدلًا من قيمة واحدة.

## الاقتباسات

تُنتج كلمات المقارنة أعلاه قيمًا منطقية؛ ولكي *تتصرّف* بناءً على قيمة منطقية، تسلّم الجملة الشرطية **اقتباسًا** واحدًا أو أكثر. الاقتباس مقتطف من الكود محاط بأقواس مربعة، `[ ... ]`. وكتابته تدفع الكود إلى المكدس كقيمة بدلًا من تنفيذه، ثم تقرّر كلمة مثل `if` أي اقتباس يُنفَّذ.

```factor
[ neg ]   ! a quotation that negates the top of the stack
[ ]       ! the empty quotation — does nothing
```

يتناول تمرين لاحق الاقتباسات بالتفصيل؛ أما الآن، فاقرأ `[ ... ]` على أنها «الكود الذي سيُنفَّذ لهذا الفرع».

## `if`, `when`, `unless`

‏`if` (في [`kernel`][kernel]) تأخذ قيمة منطقية واقتباسين. تُنفّذ الاقتباس الأول عندما تكون القيمة المنطقية صحيحة، والثاني عندما تكون خطأ:

```
if ( ? then-quot else-quot -- )
```

```factor
: abs ( x -- y ) dup 0 < [ neg ] [ ] if ;
```

تُنفّذ `when` اقتباسها فقط عندما تكون القيمة المنطقية صحيحة، وتُنفّذ `unless` اقتباسها فقط عندما تكون خطأ:

```
when   ( ? quot -- )
unless ( ? quot -- )
```

## `if*` و`when*` و`unless*`

تتعامل ثلاث صيغ من `drop` مع القيمة المنطقية باعتبارها *قيمة* تستحق الإبقاء عليها عندما تكون صحيحة، وهذا مفيد عندما تُرجع كلمة «الشيء أو `f`»:

```
if*     ( ? true false -- )    ! truthy: true is called WITH ? on stack
when*   ( ? true       -- )    ! truthy: true is called WITH ? on stack
unless* ( ? false      -- )    ! falsy: false runs and pushes a default
```

‏`if*` هي الصيغة ذات الفرعين. يُستدعى فرع الصحة والقيمة لا تزال على المكدس، ويُستدعى فرع الخطأ بدونها:

```factor
42 [ ] [ "nothing" ] if* .   ! prints 42
f  [ ] [ "nothing" ] if* .   ! prints "nothing"
```

‏`unless*` هي التعبير القياسي لـ«قيمة أو افتراضي». إذا كانت القيمة صحيحة تُترك كما هي، وإذا كانت `f` تُسقَط القيمة ويُنفَّذ الاقتباس ليدفع قيمة بديلة:

```factor
"hello" [ "anonymous" ] unless* .   ! => "hello"
f       [ "anonymous" ] unless* .   ! => "anonymous"
```

‏`when*` هي الصيغة ذات الفرع الواحد من `if*`: فهي تُنفّذ اقتباسها (والقيمة لا تزال على المكدس) فقط عندما تكون القيمة صحيحة، وتُسقط القيمة ببساطة عندما تكون `f`. استخدمها لطيّ نتيجة «الشيء أو `f`» في قيمة جارية دون عناء معالجة حالة `f`:

```factor
0 41 [ + ] when* .   ! => 41   (truthy: 41 added to the running total)
0 f  [ + ] when* .   ! => 0    (falsy: f dropped, total left untouched)
```

## `cond`

عندما تكون لديك عدة إجراءات بديلة للاختيار بينها، فإن `cond` (في [`combinators`][combinators]) هي الخيار الطبيعي. تأخذ مصفوفة من أزواج `{ predicate body }` وتُنفّذ جسم أول شرط يُنتج قيمة صحيحة:

```factor
USING: combinators ;

: classify ( n -- label )
    {
        { [ dup 0 <  ] [ drop "negative" ] }
        { [ dup 0 =  ] [ drop "zero"     ] }
        [ drop "positive" ]
    } cond ;
```

بعض التفاصيل الجديرة بالذكر:

- تُجرَّب الأزواج بالترتيب، وأول تطابق يفوز.
- المدخل الذي لا يحتوي على شرط (اقتباس واحد فقط) في النهاية يعمل كحالة افتراضية.
- يفحص كل شرط المدخل، لكن ينبغي أن يترك مكدس البيانات كما وجده، والصيغة المعتادة هي `dup ... <test>`.
- يستقبل جسم الزوج المختار المكدس نفسه الذي رآه الشرط، لذا يبدأ عادةً بإسقاط المدخل ودفع النتيجة.
