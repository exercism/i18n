# مقدمة

## الوراثة

الوراثة مفهوم أساسي في البرمجة كائنية التوجه (Object-Oriented Programming).
وهي تمثّل علاقة "هو نوع من".
ومعناها في البرمجة هو نفسه معناها في اللغة الإنجليزية: أن ترث الخصائص من الأب (وفي البرمجة تكون الخصائص عادةً دوال ومتغيرات).

لننظر إلى صنف باسم `Animal` كما في المثال التالي،

```java
//Creating an Animal class with bark() as a member function.
public class Animal {

    public void bark() {
        System.out.println("This is an animal");
    }

}
```

الصنف `Animal` هو صنف أب، لأن الخصائص التي يمتلكها هذا الصنف يمكن أن تمتد إلى كل الحيوانات عمومًا.

لننظر إلى حيوان باسم `Lion`، له صنف كالتالي:

```java
//Lion class is a child class of Animal.
public class Lion extends Animal {

    @Override
    public void bark() {
        System.out.println("Lion here!!");
    }

}
```

~~~~exercism/note
يُستخدم التعليق التوضيحي `Override` للإشارة إلى أن طريقة في صنف فرعي تتجاوز طريقة في صنفها الأعلى.
وهو ليس ضروريًا تمامًا، لكن استخدامه من الممارسات الجيدة.
~~~~

الآن، عندما نكتب ما يلي،

```java
Animal animal = new Lion(); //creating instance of Animal, of type Lion
animal.bark();
```

ملاحظة: هنا نهيّئ الصنف `Animal` بواسطة `Lion`.
وستكون المخرجات كالتالي

```java
Lion here!!
```

وفقًا للبرمجة كائنية التوجه، هناك أنواع كثيرة للوراثة، لكن Java تدعم بعضها فقط (الوراثة متعددة المستويات والوراثة الهرمية).
لمعرفة المزيد عنها، اقرأ [هذا][java-inheritance].
