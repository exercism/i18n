# نبذة

تتيح لك [جملة `switch`][switch] مقارنة قيمة واحدة بعدة قيم مطابقة محتملة.
وتتيح لك كتابة كود أكثر إيجازًا من استخدام عدة جمل `else-if`.
تبدأ جملة `switch` بالكلمة المفتاحية `switch` متبوعة بالقيمة المراد مقارنتها.
ثم يمكنك تعريف الحالات باستخدام الكلمة المفتاحية `case` متبوعة بالقيمة التي ستُقارن بها.
وتُستخدم الكلمة المفتاحية `default` لتعريف الحالة الافتراضية عندما لا تتطابق أي من الحالات.
ومثل جمل `else-if`، لا تنفّذ جمل `switch` إلا كتلة الكود المرتبطة بأول حالة مطابقة.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

تأمّل المثال التالي:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

ويمكن بدلًا من ذلك كتابته هكذا:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```
