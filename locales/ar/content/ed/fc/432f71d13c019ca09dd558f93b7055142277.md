# التعليمات

ينقل متجر محلي مخزونه إلى مستودع أكبر.
تم توظيفك لتعبئة كل شيء ونقله.

لديك أربع مهام، وكلها متعلقة بإدارة عملية النقل.

~~~~exercism/note
These are the instructions mentioned in this concept:

| Instruction   | Description                                                     |
|---------------|-----------------------------------------------------------------|
| add a, b      | a = a + b                                                       |
| inc a         | a = a + 1                                                       |
| sub a, b      | a = a - b                                                       |
| dec a         | a = a - 1                                                       |
| imul a        | rdx:rax = a * rax (signed)                                      |
| imul a, b     | a = a * b (signed, truncated)                                   |
| imul a, b, c  | a = b * c (signed, truncated)                                   |
| mul a         | rdx:rax = a * rax (unsigned)                                    |
| div a         | rax = quotient, rdx = remainder of rdx:rax / a (unsigned)       |
| idiv a        | rax = quotient, rdx = remainder of rdx:rax / a (signed)         |
| movzx a, b    | a = b, adding 0 to the extra bits                               |
| movsx a, b    | a = b, adding 1 to the extra bits if b < 0 or 0 otherwise       |
~~~~

~~~~exercism/note
تذكّر أنه يمكنك الوصول إلى السجل نفسه بأحجام مختلفة عبر تغيير اسم المعامل.
على سبيل المثال: `rax` (64 بت)، و`eax` (32 بت)، و`ax` (16 بت)، و`al` (8 بت).

يمكنك الرجوع إلى [المفهوم السابق][basics] للاطلاع على الجدول الكامل.

[basics]: https://exercism.org/tracks/x86-64-assembly/concepts/basics
~~~~

## 1. احسب وزن كل صندوق

تُعبَّأ العناصر في صناديق يجب أن تُوسَم بوزنها.
لا يوجد ميزان في الجوار، لكن لحسن الحظ أنت تعرف متوسط وزن كل عنصر.

ولتنظيم الأمور على نحو أفضل، لا يحمل الصندوق إلا عناصر من منتجين مختلفين.

عرّف دالة `get_box_weight` تُرجع الوزن الإجمالي لصندوق، بوحدة `g`.
تأخذ هذه الدالة الوسائط التالية، بهذا الترتيب:

- عدد العناصر للمنتج الأول في الصندوق
- وزن كل عنصر من المنتج الأول، بوحدة `g`
- عدد العناصر للمنتج الثاني في الصندوق
- وزن كل عنصر من المنتج الثاني، بوحدة `g`

اعتبر أن الصندوق الفارغ يزن **500 غرام**.
المُثبَّت `WEIGHT_OF_EMPTY_BOX` معرّف في أعلى ملف الحل.

مثال:

```c
get_box_weight(30, 40, 50, 20);
// => 2700
```

جميع الوسائط أعداد صحيحة غير سالبة بطول 16 بت، والقيمة المُرجَعة عدد صحيح غير سالب بطول 32 بت.

## 2. احسب كم صندوقًا تتّسع له الشاحنة

تُكدَّس الصناديق وتُنقل إلى المستودع الجديد في شاحنة.
لكن المساحة الرأسية داخل الشاحنة محدودة.

عرّف دالة `max_number_of_boxes` تُرجع عدد الصناديق ذات ارتفاع معيّن التي يمكن تكديسها عموديًا (فوق بعضها بعضًا) داخل الشاحنة.

تأخذ هذه الدالة معاملًا واحدًا هو ارتفاع الصندوق، بوحدة `cm`.
اعتبر أن الارتفاع الداخلي للشاحنة **300 سم**.
المُثبَّت `TRUCK_HEIGHT` معرّف في أعلى ملف الحل.

مثال:

```c
max_number_of_boxes(30);
// => 10
```

الوسيط والقيمة المُرجَعة عددان صحيحان غير سالبان بطول 8 بت.
ارتفاع الصندوق لا يقل عن `2` دائمًا، لذا فإن النتيجة تتّسع في 8 بت.

## 3. تحقّق من أن جميع المنتجات محسوبة

توجد قائمة تحقّق في المستودع الجديد تضم عدد العناصر التي لم تُحسَب بعد لكل منتج.
لكل صندوق جديد يُنقل إلى هناك، عليك حساب القيمة الجديدة في قائمة التحقّق لكل منتج في الصندوق.

عرّف دالة `items_to_be_moved` تُرجع عدد العناصر المتبقية التي يجب نقلها إلى المستودع الجديد لمنتج معيّن.
تأخذ هذه الدالة الوسائط التالية، بهذا الترتيب:

- عدد العناصر التي لم تُحسَب بعد لمنتج ما
- عدد العناصر الخاصة بالمنتج في صندوق

مثال:

```c
items_to_be_moved(76532, 120);
// => 76412
```

الوسائط أعداد صحيحة غير سالبة بطول 32 بت.
القيمة المُرجَعة عدد صحيح بطول 32 بت.
في حال حدوث خطأ في العملية، قد تكون النتيجة عددًا سالبًا.

## 4. احصل على أجرك

يعتمد أجرك على عدد الصناديق التي نُقلت وعدد رحلات الشاحنة التي كانت ضرورية.
مقابل كل صندوق، ستحصل على **5 دولارات**، ومقابل كل رحلة، ستحصل على **220 دولارًا**.
المُثبَّتان `PAY_PER_BOX` و`PAY_PER_TRUCK_TRIP` معرّفان في أعلى ملف الحل.

لاحظ أنك ربما تكون قد تلقّيت جزءًا من هذا الأجر مقدمًا لتغطية التكاليف الأولية، وينبغي طرح هذه الدفعة المقدّمة من الأجر النهائي.
بالإضافة إلى ذلك، بعض المنتجات غير مشمولة بالتأمين، وسيُخصم من أجرك أيضًا قيمة أي من تلك العناصر المكسورة أو المفقودة.
ومن الممكن أن ينتهي بك الأمر مدينًا إن لم تكن حذرًا!

وهذا يعني أن المبلغ الصافي المستحق لك، أو الذي تدين به، هو:

```c
net = boxes * PAY_PER_BOX + trips * PAY_PER_TRUCK_TRIP - up_front - broken_items * item_value
```

يُقسَّم هذا الأجر، أو الدين، بالتساوي بينك وبين عدد من العمال الذين وظّفتهم.
وأي مال متبقٍّ، أو دين متبقٍّ، فهو لك.
على سبيل المثال، إذا كان المبلغ الصافي `100` يُقسَّم على `6` أشخاص (أنت و`5` عمال)، فستحصل على `20` (`100/(5 + 1) = 16` زائد `4` المتبقية).

عرّف دالة `calculate_payment` تُرجع المبلغ الذي ينبغي أن تتقاضاه، أو تدفعه، في النهاية.
تأخذ هذه الدالة الوسائط التالية، بهذا الترتيب:

- المبلغ الذي تلقّيته مقدمًا، كعدد صحيح غير سالب بطول 64 بت
- العدد الإجمالي للصناديق المنقولة، كعدد صحيح غير سالب بطول 32 بت
- عدد رحلات الشاحنة التي تمّت، كعدد صحيح غير سالب بطول 32 بت
- عدد العناصر المكسورة أو المفقودة، كعدد صحيح غير سالب بطول 32 بت
- قيمة كل عنصر مفقود، كعدد صحيح غير سالب بطول 64 بت
- عدد العمال الذين ستقسّم معهم الأجر أو الدين، كعدد صحيح موجب بطول 8 بت

مثال:

```c
calculate_payment(2000, 1000, 5, 21, 2, 1);
// => 2029
```

القيمة المُرجَعة عدد صحيح بطول 64 بت.
