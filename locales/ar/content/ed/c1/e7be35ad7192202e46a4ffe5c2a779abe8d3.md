# مقدمة

كل كود Common Lisp مكوّن من تعبيرات S (التعبيرات الرمزية). وتُسمى اختصارًا sexprs. كل تعبير S إما `atom` أو `cons`. عند تقييم تعبيرات S، فإنها تُرجع تلقائيًا قيمةً تحل محل التعبير. وعند كتابة دوالك الخاصة (باستخدام `defun`)، تُرجع الدالة تلقائيًا آخر قيمة داخل جسم `defun`:

```lisp
;; Defining a new function
(defun gimme-foo () 'foo)
;; Calling the function as an S-Expression
(gimme-foo) ; => FOO
```
