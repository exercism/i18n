# نبذة

عند مطابقة الأنماط على قيمة في Gleam، يجب أن نتأكد من أن الأنماط تطابق كل القيم الممكنة للنوع، وإلا فلن يُترجم الكود.

يجب رفض هذه الدالة لأنها لم تتعامل مع الحالة التي تكون فيها المصفوفة فارغة:

```gleam
pub fn get_first_element_or_crash(items: List(e)) -> e {
  case items {
    [item, ..] -> item
  }
}
```

في معظم برامج Gleam نريد التعامل مع كل الحالات الممكنة، لكن في بعض البرامج مثل النماذج الأولية والسكربتات السريعة قد نريد التركيز على المسار السعيد فقط دون كتابة كود للحالات الأخرى. وهنا يأتي دور `let assert` في Gleam.

مع تأكيدات `let assert`، يمكن للنمط أن يطابق بعض القيم الممكنة للنوع فقط، وإذا لم يطابق النمط قيمةً ما فسيتعطل البرنامج. وباستخدام `let assert` يمكننا كتابة الدالة السابقة هكذا:

```gleam
pub fn get_first_element_or_crash(items: List(e)) -> e {
  let assert [item, ..] = items
  item
}
```

ينبغي ألا تستخدم مكتبات Gleam تأكيدات `let assert` أبدًا، لأنها قد تُعطّل البرنامج، بل ينبغي لها أن تستخدم نوع `Result` وتترك لمطوّر التطبيق قرار كيفية التعامل مع الأخطاء.
