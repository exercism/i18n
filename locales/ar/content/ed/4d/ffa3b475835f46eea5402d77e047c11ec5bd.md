# التعليمات

فرقتك الوترية تُحيي حفلة موسيقية، وعلي أحدهم أن يكتب البرنامج.

تُوضع المهام الخمس كلها في صنف `PROGRAMME_NOTES`.

## 1. اذكر اسم المقطوعة ومؤلّفها

ضع اسم المقطوعة أولًا، ثم ` by `، ثم اسم المؤلّف.

```sather
PROGRAMME_NOTES::full_title("Nocturne", "Chopin")
-- => "Nocturne by Chopin"
```

## 2. قِس طول السطر

يحتاج مَن يطبع البرنامج إلى معرفة طول السطر.

```sather
PROGRAMME_NOTES::title_length("Nocturne")
-- => 8
```

## 3. الحروف الأولى

إذا أُعطيت عنوانًا وعددًا، فأرجِع من البداية عددًا من الحروف مساويًا لذلك العدد.

```sather
PROGRAMME_NOTES::opening_letters("Nocturne", 3)
-- => "Noc"
```

## 4. الحروف الأخيرة

الشيء نفسه، لكن بالعدّ من النهاية.

```sather
PROGRAMME_NOTES::closing_letters("Nocturne", 4)
-- => "urne"
```

## 5. اختصر عنوانًا طويلًا

العناوين التي لا تتّسع تُقصّ إلى حروفها الستة الأولى، وتُتبع بثلاث نقاط.

```sather
PROGRAMME_NOTES::short_title("Nocturne in E flat")
-- => "Noctur..."
```
