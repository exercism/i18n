# التعليمات

أنت ترسم مسار مشي عبر الأدغال. تأتي المسافات والمشاهدات كلتاهما على شكل متتاليات، لذا فكلتاهما مُكرِّرات.

تُوضع الأربعة جميعها في صنف `BUSH_WALK`. وكل واحد منها مُكرِّر، لذا ينتهي كل اسم بعلامة `!`.

## 1. العلامات

تأخذ `markers!` مسافة الفصل بالأمتار وعددًا، وتُرجع بُعد كل علامة عن نقطة البداية.

```sather
loop
   #OUT + BUSH_WALK::markers!(100, 3) + " ";
end;
-- 100 200 300
```

وإذا كان العدد صفرًا فلن تُرجع شيئًا على الإطلاق.

## 2. حتى ينتهي المسار

تأخذ `until_end!` المشاهدات على طول المسار وتُرجعها واحدةً تلو الأخرى، وتتوقف عندما تصادف `"end"`. ولا تُرجع `"end"` نفسها.

```sather
loop
   #OUT + BUSH_WALK::until_end!(|"gum", "wattle", "end", "banksia"|) + " ";
end;
-- gum wattle
```

وإذا لم يكن هناك `"end"`، فإنها تُرجع كل شيء.

## 3. الطيور فقط

تأخذ `birds!` المشاهدات وتُرجع فقط تلك التي تبدأ بحرف كبير، فهكذا تُدوّن هذه الدراسة أسماء الطيور.

```sather
loop
   #OUT + BUSH_WALK::birds!(|"gum", "Emu", "wattle", "Galah"|) + " ";
end;
-- Emu Galah
```

## 4. المرقّمة

تأخذ `numbered!` المشاهدات وتُعطي كل واحدة منها مع موقعها في المقدمة، بدءًا من واحد.

```sather
loop
   #OUT + BUSH_WALK::numbered!(|"gum", "Emu"|) + " ";
end;
-- 1. gum 2. Emu
```
