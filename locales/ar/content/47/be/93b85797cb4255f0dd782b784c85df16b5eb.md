# استخدام ترويسة الدالة

[comment]: # (يُعرض هذا الخطأ عندما يستخدم الحل ترويسة دالة)

لا تكون ترويسة الدالة (تعريف دالة بدون جسم) ضرورية إلا للدوال ذات الوسائط الافتراضية التي تمتلك عدة فروع.

```elixir
# necessary function header
def hello(what \\ "World")
def hello("Alice"), do: "Hello, darling!"
def hello(name), do: "Hello, #{name}!"
```

بالنسبة للدوال ذات الوسائط الافتراضية التي تمتلك فرعًا واحدًا فقط، يمكن تحديد الوسائط الافتراضية مباشرةً في ذلك الفرع.

```elixir
# preferred
def bye(name \\ "World"), do: "See you, #{name}!"

# not preferred - unnecessary function header
def bye(what \\ "World")
def bye(name), do: "See you, #{name}!"
```

لا تحتاج الدالة `two_fer/1` إلا إلى فرع واحد، وبالتالي فهي لا تحتاج إلى ترويسة دالة.
