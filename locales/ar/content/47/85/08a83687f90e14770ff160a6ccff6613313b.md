# الصفوف

الصفوف وسيلة خفيفة لتجميع مجموعة ثابتة من البيانات ذات الأنواع المختلفة معًا. ليس للصف اسم محدّد؛ فتسمية بنية البيانات تحوّلها إلى `struct`. ولا تملك حقول الصف أسماء؛ وإنما يُوصَل إليها عبر التفكيك أو عبر الموضع.

## الصياغة

الصفوف قائمة من الحقول محاطة بالأقواس الهلالية:

- `()` هو `unit type`، أي [حالة خاصة](https://doc.rust-lang.org/std/primitive.unit.html)
- **(** _تعبير_ **,)** هو تعبير صف من عنصر واحد
- **(** _نوع_ **,)** هو نوع صف من عنصر واحد
- **(** _تعبير_ **,** ... **)** هو تعبير صف عام
- **(** _نوع_ **,** ... **)** هو نوع صف عام

### الإنشاء

تُنشأ الصفوف دائمًا بتعبير صف:

```rust
// pointless but legal
let unit = ();
// single element
let single_element = ("note the comma",);
// two element
let two_element = (123, "elements can be of differing types");
```

ويمكن أن تحتوي الصفوف على أي عدد من العناصر.

### الوصول عبر التفكيك

يمكن الوصول إلى عناصر الصف عن طريق التفكيك. وهذا يعني ببساطة إسناد أسماء متغيرات إلى عناصر الصف الفردية، وهو ما يستهلك الصف.

```rust
let (elem1, _elem2) = two_element;
assert_eq!(elem1, 123);
```

### الوصول عبر الموضع

يمكن أيضًا الوصول إلى عناصر الصف عبر فهرس موضعي رقمي. والفهرسة، كما هو الحال دائمًا، تبدأ من 0.

```rust
let notation = single_element.0;
assert_eq!(notation, "note the comma");
```

## بنى الصف

ستُطلب منك أيضًا العمل مع بنى الصف. ومثل الـ`struct` العادية، فهي أنواع مُسمّاة؛ وبخلاف الـ`struct` العادية، لديها حقول مجهولة. وصياغتها شديدة الشبه بصياغة الصف العادية. ويجوز استخدام كلٍّ من التفكيك والوصول الموضعي.

```rust
struct TupleStruct(u8, i32);
let my_tuple_struct = TupleStruct(123, -321);
let borrowed_neg = &my_tuple_struct.1;
let TupleStruct(borrowed_byte, _) = &my_tuple_struct;
assert_eq!(borrowed_neg, &-321);
assert_eq!(borrowed_byte, &123);
```

### ظهور الحقول

جميع حقول الصفوف المجهولة عامة دائمًا. أما حقول بنى الصف فلديها ظهور فردي يكون خاصًّا افتراضيًّا، تمامًا مثل حقول الـ`struct` القياسية. ويمكنك جعل الحقول عامة باستخدام المُعدِّل `pub`، تمامًا كما في الـ`struct` القياسية.

```rust
// fails due to private fields
mod tuple { pub struct TupleStruct(u8, i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```

```rust
// succeeds: fields are public
mod tuple { pub struct TupleStruct(pub u8, pub i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```
