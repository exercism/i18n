# التثبيت

الإصدار الحالي من elm هو 0.19.1.
تتغير تعليمات التثبيت مع تطوّر اللغة.
للحصول على أحدث تعليمات التثبيت، انتقل إلى
[تعليمات التثبيت في دليل elm][elm-install].

[elm-install]: https://guide.elm-lang.org/install/elm.html

## أدوات إضافية

**elm-test**

الأداة المستخدمة لتشغيل الاختبارات من سطر الأوامر تُسمى elm-test.
تحتاج elm-test حاليًا إلى Node.js و npm، لذا إن لم تكن قد فعلت ذلك بعد،
فيرجى [تثبيت Node.js و npm أولًا][npm-install].
بعد تثبيت npm، يمكنك تثبيت elm-test بالأمر:

```shell
npm install --global elm-test@latest-0.19.1
```

مزيد من المعلومات متاحة على [الصفحة الرئيسية لـ elm-test على npm][elm-test].

[npm-install]: https://www.npmjs.com/get-npm
[elm-test]: https://www.npmjs.com/package/elm-test

**elm-format**

يستخدم معظم مبرمجي elm أداة elm-format لتنسيق كود elm الخاص بهم.
إنها أداة لتنسيق الكود بدون أي إعدادات.
قد تشعر بشيء من الإحباط في البداية إن لم تكن معتادًا
على أدوات التنسيق التلقائي، لكن بمجرد أن تعتاد عليها،
ستتساءل كيف كنت تبرمج بدونها سابقًا.
يمكن تثبيتها أيضًا باستخدام npm:

```shell
npm install --global elm-format@latest-0.19.1
```

مزيد من المعلومات متاحة على [الصفحة الرئيسية لـ elm-format على GitHub][elm-format].

[elm-format]: https://github.com/avh4/elm-format

**محرر نصوص**

دعم Elm جيد على الأقل في [IntelliJ][intellij]،
وفي محررات النصوص المتوافقة مع [خادم لغة elm][els]
مثل VS Code و Sublime Text و Vim.

[els]: https://github.com/elm-tooling/elm-language-server
[intellij]: https://github.com/klazuka/intellij-elm

## أخطاء الصلاحيات مع npm

قد تواجه خطأ الصلاحيات EACCESS مع npm
عند تثبيت elm-test أو elm-format.
يرجى اتباع التعليمات على موقع npm في هذه الحالة.
[حل أخطاء صلاحيات EACCES عند تثبيت الحزم عالميًا][eaccess].

[eaccess]: https://docs.npmjs.com/resolving-eacces-permissions-errors-when-installing-packages-globally
