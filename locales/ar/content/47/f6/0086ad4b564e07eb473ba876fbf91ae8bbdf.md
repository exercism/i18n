# مقدمة

قدّمنا الدوال سابقًا في مفهوم [الأساسيات][concept-basics]، بأمثلة مثل هذا:

```R
squareit <- function(x) {
    x * x
}

squareit(3)
#> [1] 9

# shorter form
squareit_short <- function(x) x ^ 2
```

إذا نظرنا عن قرب إلى تعريف `squareit`، يمكننا تمييز عدة أجزاء:

- تأخذ الدالة معاملًا رسميًا `x`.
- يوجد جسم للدالة، عادة داخل الأقواس المعقوفة `{ }`.
- وبمجرد إنشاء كائن الدالة، يُسند إلى متغير باسم `squareit`.

الدالة كائن من الدرجة الأولى في R، تمامًا مثل الأعداد والسلاسل النصية.
لذلك فإن `squareit <- function...` إسناد لا يختلف نحويًا عن `x <- 42`.

## الوسائط

لا تفرّق R تفريقًا واضحًا بين الوسائط الموضعية والوسائط المسمّاة، على عكس لغات برمجة نصية أخرى مثل Python وJulia.

يمكن لاستدعاءات الدوال تمرير القيم إما موضعيًا وإما بالاسم.
وهذا الأخير مفيد مع الدوال المعقّدة التي لها وسائط كثيرة يصعب تذكّر ترتيبها.

```R
f <- function(x, y) x / y

# call positionally
f(4, 2)
#> [1] 2

# call by name
f(y = 2, x = 4)
#> [1] 2
```

### الوسائط الاختيارية

يمكن تحديد القيم الافتراضية للوسائط في تعريف الدالة، لكن يجب أن تأتي بعد كل الوسائط التي لا قيم افتراضية لها.

بعد ذلك يمكننا أن نختار بين قبول القيمة الافتراضية أو تجاوزها.

```R
g <- function(x, y = 2) x / y

# default y value
g(6)
#> [1] 3

# explicit y value
g(6, 3)
#> [1] 2
```

### الوسائط الإضافية

لقبول عدد عشوائي من الوسائط الإضافية، استخدم `...` (علامة الحذف) في التعريف.
يمكن تحويل أي قيم إضافية في استدعاء الدالة إلى متجه، لكن تابع القراءة لتعرف طريقة أخرى لاستخدام هذه «الوسائط النقطية» (*وتُسمى "varargs" في عدة لغات أخرى*).

```R
var_f <- function(x, y, ...) {
  print(c(...))
}

var_f(2, 3, "opt1", "opt2")
#> [1] "opt1" "opt2"
```

## بيئة الدالة

قلنا سابقًا إن المعاملات الرسمية والجسم كلاهما من مكوّنات الدالة.

في الواقع، هناك مكوّن ثالث: *البيئة* التي تُعرَّف فيها الدالة.

يمكن توضيح ذلك بحالة الدوال المتداخلة:

```R
outer_func <- function(x) {
  inner_func <- function(y) {
    x * y
  }
  
  inner_func(3)
}

outer_func(5)
#> [1] 15
```

يمرّر استدعاء الدالة القيمة `x = 5` إلى الدالة الخارجية، وتكون هذه القيمة متاحة داخل جسم تلك الدالة.

الدالة الداخلية *جزء* من جسم الدالة الخارجية، ولها وصول إلى قيمة `x`.
وبعبارة أخرى، فإن `x = 5` موجودة في *بيئة* الدالة الداخلية.

من الناحية التقنية، يُعرف هذا باسم [إغلاق][wiki-closure].

تكتسب البيئة أهمية خاصة مع الوسائط النقطية، إذ يمكن تمرير أي قيم تُقدَّم بهذه الطريقة إلى استدعاءات الدوال داخل جسم الدالة.
ولا حاجة لأن تعرف الدالة الخارجية معنى الوسائط النقطية أو تهتم به.

```R
f_var <- function(x, ...) {
  sum(x, ...)
}

x <- c(1, 2, NA, 6)

# for sum(), na.rm defaults to FALSE
f_var(x)
#> [1] NA

# pass through the na.rm value
f_var(x, na.rm = TRUE)
#> [1] 9
```

تُستخدم هذه التقنية على نطاق واسع في مكتبات Tidyverse مثل [`stringr`][ref-stringr].
وكثير من دوال `stringr` ليست إلا غلافًا سهل الاستخدام حول دوال منخفضة المستوى من `stringi` و R الأساسية.

أما الوسائط الإضافية التي تُمرَّر إلى دوال `str_*()` فتُمرَّر ببساطة إلى تلك الدوال المنخفضة المستوى.

## الدوال كقيم إرجاع

يمكن للدالة الخارجية أن تعرّف دالة داخلية (سواء كانت مسمّاة أو مجهولة كما سنوضح أدناه) وأن تستخدمها كقيمة إرجاع.

وستتضمن الدالة المُرجَعة البيئة التي عُرِّفت فيها.

```R
times_y <- function(x) {
  # anonymous function - see next section
  \(y) x * y
}

f <- times_y(3)
class(f)
#> [1] "function"

f(4)
#> [1] 12
```

## الدوال المجهولة

عندما نعرّف دالة، نربط عادة كائن الدالة الناتج بمتغير:

```R
x <- 2

# function definition captures x from the environment
doubleit_short <- function(y) x * y
```

هذا يسهّل استخدام الدالة لاحقًا في النص البرمجي، لكن هذا الربط ليس ضروريًا.
فقد تكون دالة قصيرة تُستخدم مرة واحدة مفيدة في السياق المباشر.
وبدون ربطها باسم، تُسمى *دالة مجهولة*.

استخدام الدوال المجهولة شائع إلى حد أنه (*منذ الإصدار 4.1.0 من R*) توجد صياغة مختصرة لتعريفها: استبدل كلمة `function` بشرطة مائلة عكسية `\`.

وقد ورد مثال على ذلك في القسم السابق عن قيم الإرجاع.

## النسخ عند التعديل

تسمح R بالإسناد إلى عناصر فردية في المتجه.
وإذا مرّرنا متجهًا كوسيط لدالة، وعدّلناه في جسم الدالة قبل إرجاعه، فسنحصل على متجه معدَّل.

لكن ما الذي حدث للمتجه الأصلي؟

```R
f <- function(vec) {
  vec[1] <- 42
  vec
}

vals <- c(1, 3, 4)

# f() returns a modified vector
f(vals)
#> [1] 42  3  4  

# the original vector is unchanged.
vals
#> [1] 1 3 4
```

R لغة مصمَّمة لعلم البيانات.
وجمع تلك البيانات قد يكلّف الكثير من الوقت والجهد، وربما مبلغًا باهظًا للغاية من المال: *لذا من المهم ألا نُفسد هذه البيانات!*

والسياسة العامة (مع استثناءات قليلة) هي *النسخ عند التعديل*.
فإذا تغيّر كائن (مثل متجه) بطريقة قد تسبب مشكلات لاحقة، فإن R تُرجع *نسخة معدَّلة* وتترك الأصل دون مساس.

قد يكون نسخ بنى بيانات كبيرة مكلفًا حسابيًا، لكن هذا عمومًا أهون الشرّين حين يكون البديل هو إفساد البيانات.
