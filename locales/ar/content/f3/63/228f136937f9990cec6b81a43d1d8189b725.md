# التعليمات

في هذا التمرين، ستبني معالجة الأخطاء لآلة حاسبة بسيطة للأعداد الصحيحة.
ينبغي أن تدعم الآلة الحاسبة عمليات الجمع والضرب والقسمة، وأن تُرجع النتيجة على هيئة سلسلة نصية منسّقة.
ستُنفّذ أيضًا معالجة الأخطاء للتعامل مع العمليات غير الصحيحة والقسمة على صفر.

الهدف هو الحصول على آلة حاسبة تعمل وتُرجع سلسلة نصية بالصيغة التالية:

```rust
SimpleCalculator::calculate(16, 51, "+"); // => returns "16 + 51 = 67"

SimpleCalculator::calculate(32, 6, "*"); // => returns "32 * 6 = 192"

SimpleCalculator::calculate(512, 4, "/"); // => returns "512 / 4 = 128"
```

## 1. تنفيذ عمليات الآلة الحاسبة

الدالة الرئيسية لهذه المهمة هي `SimpleCalculator::calculate`، وهي تأخذ ثلاثة وسائط: عددان صحيحان و`ByteArray` يمثّل العملية.
نفّذ العمليات التالية:

- **الجمع** بالرمز `+`
- **الضرب** بالرمز `*`
- **القسمة** بالرمز `/`

## 2. التعامل مع العمليات غير الصحيحة

إذا كان رمز العملية أي شيء غير `+` أو `*` أو `/`، فعلى الآلة الحاسبة أن تُطلق `panic` أو أن تُرجع خطأ:

- إذا كانت العملية سلسلة نصية فارغة، فأطلق `panic` برسالة خطأ من نوع `ByteArray` نصّها `"Operation cannot be an empty string"`.
- ولأي عملية أخرى غير صحيحة، أرجِع `Result::Err("Operation is out of range")`.

```rust
SimpleCalculator::calculate(100, 10, "-"); // => returns Result::Err("Operation is out of range")

SimpleCalculator::calculate(8, 2, ""); // => panics with "Operation cannot be an empty string"
```

## 3. التعامل مع الأخطاء عند القسمة على صفر

عند محاولة القسمة على `0`، ينبغي أن تُطلق الآلة الحاسبة `panic` برسالة خطأ تفيد بأن القسمة على صفر غير مسموح بها.
ينبغي أن تكون النتيجة المُرجَعة قيمة `felt252` نصّها `'Division by zero is not allowed'`.

```rust
SimpleCalculator::calculate(512, 0, "/"); // => panics with 'Division by zero is not allowed'
```
