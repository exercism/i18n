# الكلمات المفتاحية `static` و`self` في الصنف

الصنف وحدة لتنظيم الكود في PHP، وكثيرًا ما يمثّل نسخة من شيء أو خدمة أو إجراء.
وباستخدام الكلمتين المفتاحيتين `static` و`self`، يمكن أن توجد الخصائص والطرق مرتبطةً بالصنف نفسه لا بنسخة معيّنة، فتكون متاحة لجميع النسخ (أو دون الحاجة إلى أي نسخة).

```php
<?php

class Book
{
    static $genre = 'Adventure';

    static function getGenre()
    {
        return self::$genre;
    }
}

// Usage
$genre = Book::$genre;
$genre = Book::getGenre();
```

## القيود

لا يمكن للطرق المعرّفة بـ`static` في الصنف أن تستدعي إلا خصائص أو طرقًا أخرى معرّفة بـ`static` من الصنف نفسه.
