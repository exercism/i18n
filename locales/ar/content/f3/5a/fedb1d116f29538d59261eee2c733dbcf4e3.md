# نبذة

توفّر Rust النوع [`char`][char type] لتمثيل محرف واحد. وتُوضع القيمة الحرفية من النوع `char` بين علامتَي اقتباس مفردتين، مثل `'a'`.
يشغل كل `char` أربعة بايتات من الذاكرة ويمثّل [قيمة يونيكود قياسية][unicode scalar] واحدة.

لكنّ [`char`][character type] ليس دائمًا ما نعتبره حرفًا. فهناك بعض اللغات، مثل الهندية، التي تستخدم [علامات التشكيل][diacritics]،
وهي رموز خاصة تُعدّل المحرف الذي تتصل به. ورغم أن علامة التشكيل في Rust محرف `char` منفصل، فإن ما نعتبره عادةً حرفًا هو علامة التشكيل
والمحرف الذي تُعدّله معًا.

ويُسمّى المحرف مع علامة التشكيل الخاصة به [عنقود الجرافيم][grapheme cluster]. وهناك حزم خارجية يمكن استخدامها لمعالجة عناقيد الجرافيم،
مثل [unicode-segmentation][unicode-segmentation].

مثال

```rust
pub fn main() {
    let text = "ü"; // a "u" with a diacritic
    let text_vec: Vec<char> = text.chars().collect(); // this gets the chars in "ü"
    println!("{:?}", text_vec.len()); // this prints the number of chars in "ü"
    println!("{:?}", text_vec[0]); // this prints the first char in "ü"
    println!("{:?}", text_vec[1]); // this prints the second char in "ü"
}
```

يطبع

```rust
2
'u'
'\u{308}'
```

`\u{308}` طريقة أخرى لكتابة القيمة الحرفية من النوع `char`. يشير `\u` إلى أنه محرف يونيكود من النوع `char`، حيث `{308}` هو رقم يونيكود الفريد لذلك المحرف
أو علامة التشكيل.
