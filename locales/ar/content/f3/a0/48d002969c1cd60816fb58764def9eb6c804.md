# التعليمات

Karl يريد متابعة مصفوفة من اللغات ليتعلّمها على موقع Exercism.
يحتاج Karl إلى أن يكون قادرًا على إضافة لغات جديدة، وحذف لغات قديمة، والتحقق مما إذا كانت لغات معيّنة موجودة في المصفوفة.
سيكون أمرًا مثيرًا جدًا أن يريد Karl تعلّم Java أو Kotlin!

## 1. عرّف دالة للتحقق مما إذا كانت مصفوفة اللغات فارغة

يحتاج Karl إلى معرفة ما إذا كانت مصفوفة لغاته ستفرغ يومًا ما، حتى يذهب للبحث عن المزيد ليتعلّمها!
عرّف طريقة باسم `isEmpty` تُرجع `true` إذا لم تكن هناك أي لغات في المصفوفة.

```java
if (languageList.isEmpty()) {
    findMoreLanguagesToLearn();
}
```

## 2. عرّف دالة لإضافة لغة إلى المصفوفة

يتطلع Karl إلى تعلّم Kotlin وPython!
ساعد Karl على البدء بتعريف طريقة باسم `addLanguage` تأخذ اللغة التي يريد تعلّمها وتضيفها إلى المصفوفة.

```java
languageList.addLanguage("Kotlin");
languageList.addLanguage("Python");
```

## 3. عرّف دالة لحذف لغة من المصفوفة

قرّر Karl أنه لا يريد تعلّم Scala الآن.
ساعد Karl على حذفها من المصفوفة بتعريف طريقة باسم `removeLanguage` تأخذ اللغة التي يحذفها وتحذفها من المصفوفة.

```java
languageList.removeLanguage("Scala");
```

## 4. عرّف دالة تُرجع العنصر الأول في المصفوفة

يريد Karl أن يتذكّر أول لغة أضافها إلى المصفوفة (والتي ما زالت في المصفوفة).
عرّف طريقة باسم `firstLanguage` تُرجع أول لغة في المصفوفة.

```java
String kotlin = languageList.firstLanguage(); // "Kotlin"
```

## 5. عرّف دالة تُرجع عدد اللغات في المصفوفة

يحتاج Karl إلى معرفة عدد اللغات التي يحاول تعلّمها.
ساعد Karl على إيجاد الإجابة بتعريف طريقة باسم `count` تُرجع عدد اللغات في المصفوفة.

```java
int two = languageList.count(); // 2
```

## 6. عرّف دالة لتحديد ما إذا كانت لغة ما موجودة في المصفوفة

يحاول Karl أن يتذكّر ما إذا كان يريد تعلّم Python أو Ruby.
عرّف طريقة باسم `containsLanguage` تأخذ اللغة التي يسأل عنها حتى يعرف Karl الإجابة!

```java
boolean learningPython = languageList.containsLanguage("Python"); // true
boolean learningRuby = languageList.containsLanguage("Ruby"); // false
```

## 7. عرّف دالة لتحديد ما إذا كانت المصفوفة مثيرة

إذا أراد Karl تعلّم Java أو Kotlin، فهذا مثير جدًا!
عرّف طريقة باسم `isExciting` تُرجع صحيحًا إذا أراد Karl تعلّم Java أو Kotlin.

```java
javaLanguageList.isExciting() // true
neitherKotlinNorJavaLanguageList.isExciting() // false
```
