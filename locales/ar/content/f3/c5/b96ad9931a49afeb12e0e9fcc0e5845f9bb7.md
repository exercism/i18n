# التعليمات

في هذا التمرين، أُوكلت إليك مهمة كتابة برمجيات جهاز تشفير يعمل بإجراء تحويلات على البيانات. وتحتاج إلى أسلوب يتيح لك إنشاء دوال معقدة بمرونة عبر دمج دوال أبسط بعضها ببعض.

في كل مهمة، أرجِع دالة مجهولة يمكن استدعاؤها من النطاق المستدعي.

## 1. أنشئ دالة جمع

نفّذ `secret_add`. يجب أن تُرجع دالة تأخذ وسيطًا واحدًا وتضيف إليه الوسيط المُمرَّر إلى `secret_add`.

```gleam
let adder = secret_add(2)
adder(2)
// -> 4
```

## 2. أنشئ دالة طرح

نفّذ `secret_subtract`. يجب أن تُرجع دالة تأخذ وسيطًا واحدًا وتطرح السر المُمرَّر إلى `secret_subtract` من ذلك الوسيط.

```gleam
let subtractor = secret_subtract(2)
subtractor(3)
// -> 1
```

## 3. أنشئ دالة ضرب

نفّذ `secret_multiply`. يجب أن تُرجع دالة تأخذ وسيطًا واحدًا وتضربه في السر المُمرَّر إلى `secret_multiply`.

```gleam
let multiplier = secret_multiply(7)
multiplier(3)
// -> 21
```

## 4. أنشئ دالة قسمة

نفّذ `secret_divide`. يجب أن تُرجع دالة تأخذ وسيطًا واحدًا وتقسمه على السر المُمرَّر إلى `secret_divide`.

```gleam
let divider = secret_divide(3)
divider(32)
// -> 10
```

## 5. أنشئ دالة دمج

نفّذ `secret_combine`. يجب أن تُرجع دالة تأخذ وسيطًا واحدًا وتطبّق عليه الدالتين المُمرَّرتين إلى `secret_combine` بالترتيب.

```gleam
let multiply = secret_multiply(7)
let divide = secret_divide(3)
let combined = secret_combine(multiply, divide)

combined(6)
// -> 14
```
