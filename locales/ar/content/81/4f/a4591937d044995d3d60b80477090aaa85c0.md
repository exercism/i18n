# مقدمة

## الأعداد الصحيحة

هناك نوعان مختلفان من الأعداد في Elixir: الأعداد الصحيحة والأعداد العشرية.

الأعداد الصحيحة هي أعداد بلا كسور.

```elixir
integer = 3
# => 3
```

## الأعداد العشرية

الأعداد العشرية هي أعداد بها رقم واحد أو أكثر بعد الفاصلة العشرية. وهي تستخدم صيغة الأعداد العائمة ذات الدقة المزدوجة بسعة 64 بت.

```elixir
float = 3.45
# => 3.45
```

### التعامل مع الأعداد

في وحدتي [`Integer`][integer-functions] و[`Float`][float-functions] تجد بعض الدوال المفيدة للتعامل مع هذين النوعين. أما عوامل الحساب الأساسية فمعرّفة في وحدة [`Kernel`][kernel-arithmetic-operators].

### التحويل

يمكن خلط الأعداد الصحيحة والأعداد العشرية معًا في تعبير حسابي واحد. واستخدام عدد عشري في تعبير يضمن أن تكون النتيجة عددًا عشريًا أيضًا.

```elixir
2 * 3
# => 6

2 * 3.0
# => 6.0
```

لكن عند إجراء القسمة، ستكون النتيجة دائمًا عددًا عشريًا، حتى لو استُخدمت أعداد صحيحة فقط.

```elixir
6 / 2
# => 3.0
```

لتحويل عدد عشري إلى عدد صحيح، يمكنك التخلص من الجزء العشري باستخدام [`trunc/1`][trunc-1].
