# حول

بما أن جميع أنواع البيانات القياسية في Clojure غير قابلة للتغيير، فإنها توفّر *أنواعًا مرجعية* تتيح تغييرًا محكومًا. وأبسط هذه الأنواع وأكثرها استخدامًا تُسمّى الذرات.

تُنشأ الذرات باستخدام الدالة `atom`، التي تأخذ قيمة أولية:

```clojure
(def players (atom ()))
```

تُقرأ القيمة الحالية للذرة بإلغاء الإشارة إليها باستخدام `deref` أو الصيغة المختصرة `@`:

```clojure
@players
;;=> ()
```

يمكن تعديل القيمة الحالية لذرة `players` باستخدام `swap!`، التي تحدّث القيمة بتطبيق دالة:

```clojure
(swap! players conj :player1)
;;=> (:player1)
```

تستبدل الدالة `reset!` قيمة الذرة دون اعتبار لقيمتها الحالية:

```clojure
(reset! players ())
```
