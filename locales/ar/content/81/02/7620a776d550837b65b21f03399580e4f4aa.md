# تعليمات

أنت مراقب طيور شغوف يتابع عدد الطيور التي زارت حديقتك خلال الأيام السبعة الماضية.

لديك ست مهام، وكلها تتعلق بأعداد الطيور التي زارت حديقتك.

## 1. تحقق من الأعداد في الأسبوع الماضي

لأغراض المقارنة، تحتفظ دائمًا بنسخة من أعداد الأسبوع الماضي قريبة منك، وهي: 0 و2 و5 و3 و7 و8 و4. نفّذ الطريقة (_الساكنة_) `BirdCount.LastWeek()` التي تُرجع أعداد الأسبوع الماضي:

```csharp
BirdCount.LastWeek();
// => [0, 2, 5, 3, 7, 8, 4]
```

## 2. تحقق من عدد الطيور التي زارت اليوم

نفّذ الطريقة `BirdCount.Today()` لتُرجع عدد الطيور التي زارت حديقتك اليوم. أعداد الطيور مرتّبة حسب اليوم، حيث يمثل العنصر الأول عدد أقدم يوم، ويمثل العنصر الأخير عدد اليوم.

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.Today();
// => 1
```

## 3. زد عدد اليوم

نفّذ الطريقة `BirdCount.IncrementTodaysCount()` لزيادة عدد اليوم:

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.IncrementTodaysCount();
birdCount.Today();
// => 2
```

## 4. تحقق مما إذا كان هناك يوم بلا طيور زائرة

نفّذ الطريقة `BirdCount.HasDayWithoutBirds()` التي تُرجع `true` إذا وُجد يوم لم تزر فيه أي طيور الحديقة؛ وإلا تُرجع `false`:

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.HasDayWithoutBirds();
// => true
```

## 5. احسب عدد الطيور الزائرة خلال عدد الأيام الأولى

نفّذ الطريقة `BirdCount.CountForFirstDays()` التي تُرجع عدد الطيور التي زارت حديقتك منذ بداية الأسبوع، مع حصر العدد في عدد الأيام المحدد من بداية الأسبوع.

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.CountForFirstDays(4);
// => 14
```

## 6. احسب عدد الأيام المزدحمة

بعض الأيام أكثر ازدحامًا من غيرها. اليوم المزدحم هو الذي زارت فيه خمسة طيور أو أكثر حديقتك.
نفّذ الطريقة `BirdCount.BusyDays()` لتُرجع عدد الأيام المزدحمة:

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.BusyDays();
// => 2
```
