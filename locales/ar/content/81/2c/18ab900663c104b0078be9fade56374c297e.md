# ملحق التعليمات

## السجلات

| السجل    | الاستخدام     | النوع    | الوصف                   |
| -------- | ------------- | -------- | ----------------------- |
| `$a0`    | إدخال         | عدد صحيح | عدد صفوف المثلث         |
| `$a1`    | إدخال/إخراج   | عنوان    | مصفوفة كلمات            |
| `$v0`    | إخراج         | عدد صحيح | عدد الكلمات الناتجة     |
| `$t0-9`  | مؤقت          | أي نوع   | للتخزين المؤقت          |
