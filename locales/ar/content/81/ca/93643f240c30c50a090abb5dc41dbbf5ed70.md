# نبذة

النوع `Bool` هو أحد اللبنات الأساسية في اللغة.
وهو يهدف إلى وصف ما إذا كان شيء ما صحيحًا أم خطأ، بالقيمتين `True` و `False`.
اسم `Bool` اختصار لكلمة Boolean، وهو مجال من الرياضيات يتعلق بالتفكير المنطقي، سُمّي تيمنًا بأعمال جورج بول.

## العوامل المنطقية

هناك دالتان وعاملان للتعامل مع قيم من النوع `Bool`.

- `not : Bool -> Bool`
  هذه الدالة تحوّل `True` إلى `False` و `False` إلى `True`.
- `(&&) : Bool -> Bool -> Bool`
  هذا العامل المسمّى "AND" يأخذ قيمتين منطقيتين ويُرجع `True` إذا كانتا كلتاهما `True`.
  على سبيل المثال، `True && True` يُرجع `True` لكن `True && False` يُرجع `False`.
- `(||) : Bool -> Bool -> Bool`
  هذا العامل المسمّى "OR" يأخذ قيمتين منطقيتين ويُرجع `True` إذا كانت واحدة منهما على الأقل `True`.
  على سبيل المثال، `False || False` يُرجع `False` لكن `True || False` يُرجع `True`.
- `xor : Bool -> Bool -> Bool`
  هذه الدالة (وليست عاملًا) المسمّاة "XOR" تأخذ قيمتين منطقيتين وتُرجع `True` إذا وفقط إذا كانت إحداهما `True` والأخرى `False`.

لا يتمتع العاملان `&&` و `||` بالأولوية نفسها.
أولوية `&&` أعلى من أولوية `||`، تمامًا كما هو الحال مع الضرب `*` والجمع `+`.
ونتيجةً لذلك، فإن التعبير `True || False && False` يكافئ `True || (False && False)`، وهو مختلف عن `(True || False) && False`.
فبينما يُرجع الأول `True` فإن الثاني يُرجع `False`.

## التفريع الشرطي

القيم المنطقية مفيدة جدًا لإنشاء تفريعات في الكود لا تُنفَّذ إلا عند تحقق شروط معينة.
في Elm، يتم هذا باستخدام تعبير `if-then-else`، بالشكل التالي.

```elm
if someCondition || (someOtherCondition && anotherCondition) then
    doSomething
else
    doSomethingElse
```

يمكن أن تكون القيمة `someCondition` أي تعبير يُرجع `Bool`.
إذا كانت تلك القيمة المنطقية `True`، فسيُنفّذ الكود `doSomething`.
وإلا فهي `False` وسيُنفّذ الكود `doSomethingElse`.
فرع `else` إلزامي، على خلاف بعض لغات البرمجة الأخرى.

إذا احتجت إلى تسلسل الشروط، يمكنك ببساطة تسلسل تعبيرات `if-then-else`.

```elm
if someCondition then
    doSomething
else if someOtherCondition then
    doAnotherThing
else
    doSomethingElse
```
