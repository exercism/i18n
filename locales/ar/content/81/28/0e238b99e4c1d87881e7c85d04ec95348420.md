# نبذة

في Rust، الطرق دوال تُعرَّف من أجل `struct` (أو `enum` أو كائن `trait`). وهذا يغيّر نمط الاستدعاء: فبدلًا من `frobnicate(foo)`، تُستدعى الطريقة هكذا `foo.frobnicate()`.

الطرق شبيهة بالدوال: فكلتاهما تُعرَّف بالكلمة المفتاحية `fn`، ولها اسم، ويمكن أن يكون لها معاملات وقيم مُرجعة.

وعلى خلاف الدوال، فإن المعامل الأول للطريقة هو دائمًا `self` (أو أحد صيغه)، وهو يمثّل نسخة `struct` التي تُستدعى الطريقة عليها (مزيد من التفاصيل أدناه).

لنُنشئ `enum` لبيوت هوجوورتس، و`struct` يصف حقلي `age` و`house` لدى الساحر:

```rust
#[derive(Debug)]
enum House {
    Gryffindor,
    Hufflepuff,
    Ravenclaw,
    Slytherin,
}

struct Wizard {
    age: u32,
    house: House,
}
```

## تعريف الطرق

لتعريف طرق من أجل `struct` المسمّى `Wizard`، نبدأ كتلة `impl` (اختصار كلمة implementation) خاصة بـ `Wizard`.

```rust
impl Wizard { }
```

كل ما داخل كتلة `impl` هذه سيكون مرتبطًا بنوع `Wizard`.
لاحظ أن `struct` يُسمح له بأن تكون له عدة كتل `impl`.

### استخدام `self`

يجب أن يكون المعامل الأول للطريقة معاملًا اسمه `self` من النوع `Self`.
النوع `Self` هو اسم بديل عن النوع الذي كُتبت كتلة `impl` من أجله.
في مثالنا، يمثّل `Self` النوع `Wizard`.

وتسهيلًا، تسمح لنا Rust باختصار ذلك بكتابة اسم `self` وحده في موضع المعامل الأول.
ومن أنواع `self` الشائعة في الطرق:

- `self`: اختصار لـ `self: Self`. التوقيع الذي يحمل `self` وحدها يستهلك النسخة.
- `&self`: اختصار لـ `self: &Self`. وهذا يستعير النسخة استعارة غير قابلة للتغيير.
- `&mut self`: اختصار لـ `self: &mut Self`. وهذا يستعير النسخة استعارة قابلة للتغيير.

وفي الكود الأكثر تقدمًا قد ترى أيضًا توقيعات مثل `self: Pin<&self>`، و`self: Rc<Self>`، وما إلى ذلك.
لكن هذا خارج نطاق هذا الدرس.

### تعريف طريقة باستخدام `&self`

إذا أردنا تنفيذ طريقة `info` لعرض المعلومات الأساسية للساحر، فيمكننا تعريفها داخل كتلة `impl` الخاصة بـ `Wizard`:

```rust
impl Wizard {
    fn info(&self) {
        println!(
            "A wizard of age {} who studies in House {:?} at Hogwarts",
            self.age,
            self.house,
        );
    }
}
```

لاحظ أننا في توقيع `info` نستعير النسخة استعارة غير قابلة للتغيير عبر `&self`.
وبهذه الطريقة يمكننا قراءة الحقلين `age` و`house` في نسخة `Wizard` دون تغييرهما.
ولو استخدمنا `self` المستهلكة بدل الاستعارة، لأصبحت النسخة غير قابلة للوصول بعد استدعاء الطريقة.

وبعد تنفيذ طريقة `info`، يمكننا إخراج المعلومات الأساسية لأحد السحرة:

```rust
let harry = Wizard { age: 11, house: House::Gryffindor };
harry.info();
// => A wizard of age 11 who studies in House Gryffindor at Hogwarts
```

### تعريف طريقة باستخدام `&mut self`

إذا أردنا تنفيذ طريقة تُعدّل حقول نسخة من `struct`، فإننا نستعير النسخة استعارة قابلة للتغيير عبر `&mut self` في توقيع الطريقة.

لنفترض أننا نريد وضع قاعدة جديدة في هوجوورتس تسمح للطلاب بتغيير بيوتهم.
يمكننا تنفيذ طريقة `switch_house` على النحو التالي:

```rust
impl Wizard {
    fn switch_house(&mut self, new_house: House) {
        self.house = new_house;
    }
}
```

الآن يمكننا تغيير بيت ساحر يدرس في هوجوورتس:

```rust
// Note that the variable must be mutable
let mut cedric = Wizard {age: 14, house: House::Hufflepuff};
cedric.info();
// => A wizard of age 14 who studies in House Hufflepuff at Hogwarts
cedric.switch_house(House::Slytherin);
cedric.info()
// => A wizard of age 14 who studies in House Slytherin at Hogwarts
```

## كتل `impl` المتعددة

في Rust، يُسمح لكل عنصر بأن تكون له عدة كتل `impl`.
لذا يمكننا تجميع كل الطرق في كتلة `impl` واحدة، أو استخدام عدة كتل `impl` لمجموعات مختلفة من الطرق.
كلا الأسلوبين صحيح نحويًا، لكن التنظيم المعتاد للمشاريع يستخدم كتلة `impl` واحدة لكل مجموعة فريدة من قيود `where` على مستوى `impl`.

## الدوال المرتبطة

يمكن تعريف دوال داخل كتلة `impl` لا تحتوي على معامل `self`.
ولأنها تفتقر إلى معامل `self` فهي ليست طرقًا.
ومع ذلك تبقى مرتبطة بالنوع الذي نُفِّذت من أجله، وتُستدعى بذكر اسم ذلك النوع.
ولهذا تُسمّى دوال مرتبطة (أو دوال مرتبطة بالنوع).

لقد رأيت بالفعل بعض الدوال المرتبطة، مثل `String::from()`:

```rust
let some_string = String::from("This is an associated function but not a method");
```

غالبًا ما تُنفَّذ دوال الإنشاء كدوال مرتبطة.
لنُنشئ دالة `new` مرتبطة بالنوع `Wizard`:

```rust
impl Wizard {
    fn new(age: u32, house: House) -> Self {
        Self {
            age,
            house,
        }
    }
}
```

لاحظ أنه يمكننا استخدام `Self` بدل `Wizard` للإشارة إلى النوع الذي ستُرجعه الدالة.
وليس إلزاميًا استخدام الاسم البديل `Self` بهذه الطريقة، لكنه قد يبسّط التنفيذ للأنواع ذات الأسماء المعقّدة أو الطويلة.
والآن يمكننا تشغيل ما يلي:

```rust
let myrtle = Wizard::new(14, House::Ravenclaw);

myrtle.info();
// => A wizard of age 14 who studies in House Ravenclaw at Hogwarts
```
