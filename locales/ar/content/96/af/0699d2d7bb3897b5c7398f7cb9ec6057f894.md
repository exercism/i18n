# حول

عند نمذجة بيانات لا يمكنها أن تأخذ إلا مجموعة محددة من الحالات الممكنة، مثل أيام الأسبوع أو اتجاهات البوصلة أو الأزرار في ذراع التحكم، فإن الأنواع الأساسية مثل `Int` أو `String` لها عيوب كبيرة.
مع الأعداد الصحيحة أو السلاسل النصية، يجب أن يتحقق كودك باستمرار من القيم غير الصالحة (مثل رمز حالة `999` أو خطأ مطبعي مثل `"leftt"`)، ولا يستطيع القارئ البشري أن يفهم بسهولة ماذا تمثّل الأرقام.

يحل Swift هذه المشكلة باستخدام [_التعدادات_][enumerations] (وتُختصر غالبًا إلى *enums*).
يعرّف التعداد نوعًا مشتركًا لمجموعة من القيم المرتبطة والمسمّاة. ولأن المصرِّف يعرف كل الحالات الممكنة مسبقًا، فإنه يستطيع التحقق من دقة كودك واكتماله في وقت التصريف.
ويمكن أن تحتوي التعدادات أيضًا على طرق ومُهيّئات وخصائص محسوبة.

## تعريف التعدادات

عرّف التعداد باستخدام الكلمة المفتاحية `enum` متبوعة باسم النوع، مع سرد حالاته داخل الأقواس المعقوفة.
بحسب اصطلاح Swift، يُكتب اسم النوع بنمط `UpperCamelCase`، بينما تُكتب كل حالة بنمط `lowerCamelCase`:

```swift
enum NESButton {
    case up
    case down
    case left
    case right
    case a
    case b
    case select
    case start
}
```

ويمكنك أيضًا تعريف عدة حالات في سطر واحد تفصل بينها فواصل:

```swift
enum NESButton {
    case up, down, left, right, a, b, select, start
}
```

للإشارة إلى حالة في تعداد، اكتب اسم نوع التعداد، ثم نقطة (`.`)، ثم اسم الحالة. وبمجرد أن يكون النوع معروفًا أو يمكن للمصرِّف استنتاجه، يمكنك حذف اسم النوع واستخدام الصيغة المختصرة بالنقطة:

```swift
var lastPressed = NESButton.up

// Swift infers the type, so you can omit the type name:
lastPressed = .down

let konamiCode: [NESButton] = [.up, .up, .down, .down, .left, .right, .left, .right, .b, .a]
```

## التعدادات وعبارات `switch`

تعمل التعدادات بسلاسة مع [عبارات `switch`][enums-and-switches].
ولأن عبارة `switch` في Swift يجب أن تكون شاملة لكل الحالات، يضمن المصرِّف أنك تعالج كل حالة ممكنة:

```swift
lastPressed = .left
switch lastPressed {
case .up: print("You pressed the UP button")
case .down: print("You pressed the DOWN button")
case .left: print("You pressed the LEFT button")
case .right: print("You pressed the RIGHT button")
case .a: print("You pressed the A button")
case .b: print("You pressed the B button")
case .select: print("You pressed the SELECT button")
case .start: print("You pressed the START button")
}
// Prints "You pressed the LEFT button"
```

إذا أهملت أي حالة دون توفير جملة `default`، فسيُبلغك المصرِّف بخطأ:

```swift
switch lastPressed {
case .up, .down, .left, .right:
    print("You pressed a direction button.")
}
// Error: Switch must be exhaustive
```

غالبًا ما يكون سرد كل الحالات صراحةً أفضل من استخدام `default`. وبهذه الطريقة، إذا أضفت حالة جديدة مستقبلًا، سينبهك المصرِّف فورًا إلى ضرورة تحديث كل عبارة `switch` تتعامل مع ذلك التعداد.

## الطرق والمُهيّئات

يمكن للتعدادات أن تعرّف طرقًا ومُهيّئات مخصصة تمامًا مثل الأصناف والبنى. وداخل طريقة في تعداد، تشير `self` إلى قيمة الحالة الحالية:

```swift
enum Coin {
    case heads
    case tails

    init(_ value: Int) {
        if value.isMultiple(of: 2) {
            self = .heads
        } else {
            self = .tails
        }
    }

    func flip() -> Coin {
        switch self {
        case .heads: return .tails
        case .tails: return .heads
        }
    }
}

let tails = Coin(13)     // .tails
let heads = Coin(0)      // .heads
let flipped = heads.flip() // .tails
```

## القيم الخام

يمكن تعبئة حالات التعداد بقيم افتراضية تُسمى [_القيم الخام_][raw-values].
ويجب أن تشترك كل القيم الخام في التعداد في النوع نفسه (مثل `Int` أو `String` أو `Character`):

```swift
enum NESButton: Character {
    case up = "⬆️"
    case down = "⬇️"
    case left = "⬅️"
    case right = "➡️"
    case a = "🅰️"
    case b = "🅱️"
    case select = "✅"
    case start = "🚦"
}

print(NESButton.left.rawValue) // Prints "⬅️"
```

يمكنك تهيئة تعداد من قيمة خام باستخدام `init(rawValue:)`. ولأنه قد تُمرَّر قيمة خام غير صالحة، فإن هذا المُهيّئ يُرجع قيمة اختيارية:

```swift
let upButton = NESButton(rawValue: "⬆️") // Optional(NESButton.up)
let invalid = NESButton(rawValue: "🙄")  // nil
```

يستطيع Swift إسناد قيم خام تلقائيًا لتعدادات `String` و`Int`:

- في تعدادات `String`، تكون القيمة الخام لكل حالة هي اسم الحالة افتراضيًا.
- وفي تعدادات `Int`، تبدأ القيم الخام من `0` وتزداد بمقدار 1 ما لم يُحدَّد خلاف ذلك.

```swift
enum Planet: Int {
    case mercury = 1, venus, earth, mars
}

print(Planet.earth.rawValue) // Prints 3
```

## القيم المرتبطة

يمكن لحالات التعداد أيضًا أن تخزّن قيمًا مخصصة من أنواع مختلفة إلى جانب كل حالة، وتُعرف هذه بـ[_القيم المرتبطة_][associated-values]:

```swift
enum Suit: Character {
    case diamonds = "♦️", clubs = "♣️", hearts = "♥️", spades = "♠️"
}

enum Card {
    case ace(Suit)
    case king(Suit)
    case queen(Suit)
    case jack(Suit)
    case number(Suit, Int)

    func description() -> String {
        switch self {
        case .ace(let suit): return "A\(suit.rawValue)"
        case .king(let suit): return "K\(suit.rawValue)"
        case .queen(let suit): return "Q\(suit.rawValue)"
        case .jack(let suit): return "J\(suit.rawValue)"
        case let .number(suit, value): return "\(value)\(suit.rawValue)"
        }
    }
}

let aceOfSpades = Card.ace(.spades)
let twoOfHearts = Card.number(.hearts, 2)

print(aceOfSpades.description()) // Prints "A♠️"
print(twoOfHearts.description()) // Prints "2♥️"
```

يمكن للتعداد أن يستخدم القيم الخام أو القيم المرتبطة، لكن ليس كليهما معًا.

## التعدادات العودية

[التعداد العودي][recursive-enumerations] هو تعداد يحمل نسخة أخرى من التعداد كقيمة مرتبطة لحالة واحدة أو أكثر.
لتمكين العودية، ضع الكلمة المفتاحية `indirect` قبل الحالة (أو قبل التعداد كاملًا):

```swift
enum BinaryTree {
    case leaf(value: Int)
    indirect case node(left: BinaryTree, value: Int, right: BinaryTree)
}

let tree: BinaryTree = .node(
    left: .leaf(value: 1),
    value: 3,
    right: .node(left: .leaf(value: 5), value: 6, right: .leaf(value: 9))
)
```
