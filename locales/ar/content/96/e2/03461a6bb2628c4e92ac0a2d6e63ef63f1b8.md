# ملحق التعليمات

## عن قدرة `Stream`

`Stream` قدرة في Unison تُستخدم لإصدار القيم.

قد تحتاج إلى استخدام قدرة `Stream` إذا كانت لديك دالة يُفترض أن تنتج قيمًا كأثر جانبي أثناء استدعائها. على سبيل المثال، تُرجع هذه الدالة القيمة الأخيرة في المصفوفة، لكنها تُصدر مجموعًا تراكميًا مع كل عنصر يمرّ:

```
emitRunningTotal : '{Stream Nat} Nat
emitRunningTotal = 'let
  use Nat +
  List.foldLeft (
    acc a -> let
      runningTotal = acc + a
      Stream.emit runningTotal
      a
    ) 0 [1,2,3,4,5]
```

يمكننا تجسيد `Stream` على هيئة مصفوفة إلى جانب القيمة المُرجَعة من الدالة التي تنتجه، باستخدام معالج قدرة:

```
> Stream.toListWithResult! emitRunningTotal
  ⧩
  ([1, 3, 5, 7, 9], 5)
```
