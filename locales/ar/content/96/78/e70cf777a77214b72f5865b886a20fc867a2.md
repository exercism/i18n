# مقدمة

في Haskell نوع `Num`، وهو النوع الأساسي لجميع الأنواع العددية.
وهناك أربعة أنواع فرعية رئيسية داخل نوع الأعداد: [`Int`][int] و[`Integer`][integer] و[`Double`][double] و[`Float`][float].

يوجد في Haskell نوعان من أنواع الأعداد الصحيحة، ويمثلان الأعداد الكاملة.
`Int` عدد صحيح ثابت الحجم، بينما `Integer` عدد صحيح بدقة غير محدودة.
يستوعب `Integer` أي عدد مهما كبر، حتى حدود ذاكرة جهازك، بينما يقابل `Int` مجموعة الأعداد الصحيحة الموجبة والسالبة التي يمكن التعبير عنها بـ 32 أو 64 بت (مضمون على الأقل من -2^29 إلى 2^29 - 1).

لاحظ أنه عند كتابة الأعداد السالبة، ينبغي استخدام الأقواس الهلالية لتجنب الغموض.

```haskell
1

(-1)
```

يقابل `Float` مجموعة الأعداد الحقيقية، محدودةً بدقة الحاسوب.
والعمليات المعرّفة على الأعداد تعمل عادةً على أحد النوعين، لا على كليهما.
`Double` عدد فاصلة عائمة بدقة مزدوجة.

```haskell
10.5
```

## التحويل بين الأعداد الصحيحة وأعداد الفاصلة العائمة

باستخدام الدالة `toFloat`، يمكنك تحويل `Int` أو `Integer` إلى `Float`.

```haskell
toFloat 1
-- -> 1.0
```

توجد أيضًا `fromIntegral` التي تحوّل أي نوع عددي إلى نوع العدد المستنتج المطلوب.

```haskell
fromIntegral 1
-- -> 1.0
```

لتحويل `Float` إلى `Int`، يمكنك استخدام دوال [`round`][round] أو [`floor`][floor] أو [`ceiling`][ceiling].
الدالة `round` تقرّب إلى أقرب عدد صحيح، و`floor` تقرّب للأسفل، و`ceiling` تقرّب للأعلى.

```haskell
round 1.5
-- -> 2

floor 1.5
-- -> 1

ceiling 1.5
-- -> 2
```

## عوامل العمليات الحسابية

يمكنك استخدام [عوامل العمليات الحسابية الأساسية][math] على الأنواع العددية.
العوامل هي `+` و`-` و`*` و`/` و`%`.
عند استخدام هذه العوامل، يجب أن تتطابق أنواع الأعداد.
ستحوّل الدالة `fromIntegral` حتى تتطابق الأنواع.

### الجمع والطرح والضرب

يُستخدم العامل `+` للجمع، والعامل `-` للطرح، والعامل `*` للضرب.

| العامل | مثال        |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### القسمة

تُستخدم القسمة لتقسيم الأعداد.
يُستخدم العامل `/` للقسمة.
ستكون النتيجة دائمًا عدد فاصلة عائمة.

```haskell
4.0 / 2.5
-- -> 1.6

4 / 2
-- -> 2.0
```

~~~~exercism/caution
في بعض لغات البرمجة، عند القسمة على صفر، ستكون النتيجة خطأ.

في Haskell، عند القسمة على صفر، تكون النتيجة `Infinity` أو `-Infinity`.
الاستثناء الوحيد هو قسمة صفر على صفر، مما ينتج `NaN` (ليس عددًا).

```haskell
1 / 0
-- -> Infinity

(-1) / 0
-- -> -Infinity

0 / 0
-- -> NaN
```
~~~~

## القسمة الصحيحة

تُستخدم القسمة الصحيحة لتقسيم الأعداد الصحيحة والحصول على الجزء الكامل من النتيجة.
لدى Haskell دالتان للقسمة الصحيحة، تختلفان في طريقة التقريب عندما تكون النتيجة سالبة:

- `div` تقرّب للأسفل، نحو سالب ما لا نهاية.
- `quot` تقرّب نحو الصفر.

```haskell
6 `div` 2
-- -> 3

5 `div` 2
-- -> 2

(-5) `div` 2
-- -> -3

5 `quot` 2
-- -> 2

(-5) `quot` 2
-- -> -2
```

~~~~exercism/caution
القسمة على صفر عند استخدام القسمة الصحيحة تؤدي إلى استثناء.
وهذا يختلف عن القسمة العادية.
~~~~

### الباقي

يمكن إيجاد باقي القسمة الصحيحة باستخدام `mod` أو `rem`.
يختلفان في إشارة النتيجة عندما يكون أحد العددين سالبًا:

- `mod` تتماشى مع `div`، وتكون لنتيجتها نفس إشارة المقسوم عليه.
- `rem` تتماشى مع `quot`، وتكون لنتيجتها نفس إشارة المقسوم.

```haskell
5 `mod` 3
-- -> 2

(-5) `mod` 3
-- -> 1

5 `mod` (-3)
-- -> -1

5 `rem` 3
-- -> 2

(-5) `rem` 3
-- -> -2

5 `rem` (-3)
-- -> 2
```

لأي `x` و`y` (حيث `y` ليس صفرًا)، تنطبق هاتان القاعدتان:

```haskell
(x `div` y) * y + (x `mod` y) == x
(x `quot` y) * y + (x `rem` y) == x
```

~~~~exercism/note
عندما يكون كلا العددين موجبين، تعطي `div` و`quot` النتيجة نفسها، وكذلك `mod` و`rem`.
في هذه الحالة يمكن أن تكون `quot` و`rem` أكثر كفاءة قليلًا، لأن `div` و`mod` تحتاجان إلى خطوات إضافية للتعامل مع الأعداد السالبة.
~~~~

~~~~exercism/caution
القسمة على صفر عند استخدام `mod` أو `rem` تؤدي إلى استثناء.
وهذا يختلف عن القسمة العادية.

```haskell
1 `mod` 0
-- Exception: divide by zero
```
~~~~

## الرفع إلى قوة

لدى Haskell ثلاثة عوامل "رفع إلى القوة" تعمل بطرق مختلفة وتأخذ أنواع وسائط مختلفة.

- `**` تأخذ **عددي فاصلة عائمة** وتستخدم اللوغاريتمات لحساب القوة.
- `^^` تأخذ **عدد فاصلة عائمة** وترفعه إلى قوة **عدد صحيح** موجب أو سالب.
- `^` تأخذ **أي نوع عددي** وترفعه إلى قوة **عدد صحيح موجب**.

```haskell
3.0 ** 2.1
-- -> 10.04510856630514

2.5 ^^ 2
-- -> 6.25

2 ^ 3
-- -> 8
```

## الأولوية والأقواس

تسمح Haskell باستخدام الأقواس الهلالية(`()`)، التي يمكن استخدامها لتجميع التعبيرات.
يفيد ذلك عندما تريد تغيير ترتيب العمليات.

عند استخدام عدة عوامل حسابية، يكون ترتيب العمليات هو نفسه في الرياضيات، ويُعرف أيضًا باسم [PEMDAS][pemdas].
يتبع ترتيب الأقواس الهلالية(`()`) والأسس(`**`) والضرب(`*`) والقسمة(`/`) والجمع(`+`) والطرح(`-`).

```haskell
2 + 3 - 4 * 4
-- -> -11

(2 + 3 - 4) * 4
-- -> 4
```
