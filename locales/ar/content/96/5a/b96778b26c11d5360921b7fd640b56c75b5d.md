# التعليمات

يدير رئيس البحّارة إحاطة يومية لنوبة الحراسة على سطح السفينة: تحية ثابتة، ثم نداء حضور الطاقم المناوب، ثم كلمة انصراف ختامية. ستقسّم الإحاطة إلى أسطر صغيرة مسمّاة ثم تركّبها.

ستحرّر **ملفين** في هذا التمرين:

- `bosuns-briefing/helpers/helpers.factor`: قطع صغيرة قابلة لإعادة الاستخدام. المفردات: `bosuns-briefing.helpers`.
- `bosuns-briefing/bosuns-briefing.factor`: الملف الرئيسي الذي يركّب الدوال المساعدة. المفردات: `bosuns-briefing`.

## 1. التحية

في `helpers.factor`، عرّف `greeting` لتُرجع سلسلة الافتتاح الثابتة `"All hands, attention!"`.

```factor
greeting .
! => "All hands, attention!"
```

## 2. سطر الطاقم

في `helpers.factor`، عرّف `crew-line` لتأخذ سلسلة نصية تمثّل اسمًا وتُرجع ذلك الاسم مسبوقًا بـ `"  - "` (مسافتان، ثم شرطة، ثم مسافة).

```factor
"Lopez" crew-line .
! => "  - Lopez"
```

## 3. الختام

في `helpers.factor`، عرّف `closing` لتُرجع سلسلة الانصراف الثابتة `"Carry on."`.

```factor
closing .
! => "Carry on."
```

## 4. كشف الطاقم

في `bosuns-briefing.factor`، عرّف `roster` لتأخذ مصفوفة من أسماء الطاقم وتُرجع سلسلة نصية واحدة متعددة الأسطر، منسّق فيها كل اسم بواسطة `crew-line`، وموصولة بمحارف السطر الجديد.

```factor
{ "Lopez" "Mwangi" } roster .
! => "  - Lopez\n  - Mwangi"

{ } roster .
! => ""
```

## 5. الإحاطة

في `bosuns-briefing.factor`، عرّف `briefing` لتأخذ مصفوفة من أسماء الطاقم وتُرجع الإحاطة الكاملة كسلسلة نصية واحدة: التحية في السطر الأول، وكشف الطاقم في الأسطر التالية، والختام في السطر الأخير. استخدم الدوال المساعدة و`roster`.

```factor
{ "Lopez" "Mwangi" } briefing .
! => "All hands, attention!\n  - Lopez\n  - Mwangi\nCarry on."

{ } briefing .
! => "All hands, attention!\n\nCarry on."
```
