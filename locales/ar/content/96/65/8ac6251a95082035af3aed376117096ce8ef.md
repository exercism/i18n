# التعليمات

في هذا التمرين، ستكتب بعض الكود لمساعدتك في الاستعداد لشراء مركبة.

لديك ثلاث مهام: واحدة لتحديد ما إذا كنت تحتاج إلى رخصة، وواحدة لمساعدتك في الاختيار بين مركبتين، وواحدة لتقدير السعر المقبول لمركبة مستعملة.

## 1. حدّد ما إذا كنت ستحتاج إلى رخصة قيادة

بعض أنواع المركبات تتطلب رخصة قيادة لتشغيلها.
افترض أن النوعين `"car"` و `"truck"` فقط هما اللذان يتطلبان رخصة، وأن كل ما عدا ذلك يمكن تشغيله دون رخصة.

نفّذ الدالة `NeedsLicense(kind)` التي تأخذ نوع المركبة وتُرجع قيمة منطقية تشير إلى ما إذا كنت تحتاج إلى رخصة لهذا النوع من المركبات.

```go
needLicense := NeedsLicense("car")
// => true

needLicense = NeedsLicense("bike")
// => false

needLicense = NeedsLicense("truck")
// => true
```

## 2. اختر بين مركبتين محتملتين للشراء

تقيّم خيارات المركبات المتاحة لديك.
تنجح في حصرها في خيارين، لكنك تحتاج إلى مساعدة لاتخاذ القرار النهائي.
ولهذا، نفّذ الدالة `ChooseVehicle(option1, option2)` التي تأخذ مركبتين كوسائط وتُرجع قرارًا يتضمن الخيار الذي يأتي أولًا في الترتيب المعجمي.

```go
vehicle := ChooseVehicle("Wuling Hongguang", "Toyota Corolla")
// => "Toyota Corolla is clearly the better choice."

ChooseVehicle("Volkswagen Beetle", "Volkswagen Golf")
// => "Volkswagen Beetle is clearly the better choice."
```

## 3. احسب تقديرًا لسعر مركبة مستعملة

الآن بعد أن اتخذت قرارًا، تريد أن تتأكد من حصولك على سعر عادل لدى الوكيل.
وبما أنك مهتم بشراء مركبة مستعملة، يعتمد السعر على عمر المركبة.
ولتقدير تقريبي، افترض أنه إذا كان عمر المركبة أقل من 3 سنوات، فإنها تكلف 80% من السعر الأصلي الذي كانت عليه عندما كانت جديدة تمامًا.
وإذا كان عمرها 10 سنوات على الأقل، فإنها تكلف 50%.
وإذا كان عمر المركبة 3 سنوات على الأقل ولكن أقل من 10 سنوات، فإنها تكلف 70% من السعر الأصلي.

نفّذ الدالة `CalculateResellPrice(originalPrice, age)` التي تطبق هذا المنطق باستخدام `if` و `else if` و `else` (يمكنك فعل ذلك بأساليب أخرى إن أردت التدريب).
تأخذ السعر الأصلي وعمر المركبة كوسائط وتُرجع السعر المقدّر لدى الوكيل.

```go
CalculateResellPrice(1000, 1)
// => 800

CalculateResellPrice(1000, 5)
// => 700

CalculateResellPrice(1000, 15)
// => 500
```

**ملاحظة**: القيمة المُرجعة هي `float64`.
