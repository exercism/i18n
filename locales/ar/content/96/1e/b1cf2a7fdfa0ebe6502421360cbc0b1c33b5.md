# نبذة

في C#، تُستخدم [القيمة الحرفية `null`][null-keyword] للدلالة على غياب القيمة. النوع _القابل لـ `null`_ هو نوع يسمح بقيم `null`.

قبل C# 8.0، كانت الأنواع المرجعية دائمًا قابلة لـ `null`، أما أنواع القيم فلم تكن كذلك. لكن يمكن [جعل نوع القيمة قابلًا لـ `null`][nullable-value-types] بإضافة علامة استفهام (`?`) إليه.

```csharp
string nullableReferenceType = "hello";
nullableReferenceType = null; // Valid as type is nullable

int nonNullableValueType = 5;
nonNullableValueType = null; // Compile error as type is not nullable

int? nullableValueType = 5; // Define nullable value type
nullableValueType = null;   // Valid as type is nullable
```

الوصول إلى عضو في متغير قيمته `null` سيُترجم بنجاح، لكنه سيؤدي إلى رمي استثناء `NullReferenceException` أثناء التنفيذ:

```csharp
string sentence = "What a nice day!";

// Throws NullReferenceException at runtime
sentence.Length;
```

لمواجهة هذا النوع الشائع من الأخطاء، يتيح C# 8 [تفعيل ميزة][nullable-csharp-8] تجعل [الأنواع المرجعية غير قابلة لـ `null` افتراضيًا][nullable-reference-types]:

```csharp
string nonNullableReferenceType = "book";
nonNullableReferenceType = null; // Compile warning (no error!)

string? nullableReferenceType = "movie";
nullableReferenceType = null; // Valid as type is nullable
```

للعمل [بأمان مع القيم القابلة لـ `null`][nullable-types-tutorial]، ينبغي التحقق مما إذا كانت `null` قبل التعامل معها:

```csharp
string NormalizedName(string? name)
{
    if (name == null)
    {
        return "UNKNOWN";
    }
    else
    {
        // Value is not null at this point, so no compile warning
        // and no runtime NullReferenceException being thrown
        return name.ToUpper();
    }
}

NormalizedName(null); // => "UNKNOWN"
NormalizedName("Elisabeth"); // => "ELISABETH"
```

يتيح [المعامل `??`][null-coalescing-operator] إرجاع قيمة افتراضية عندما تكون القيمة `null`:

```csharp
string? name1 = "John";
name1 ?? "Paul"; // => "John"

string? name2 = null;
name2 ?? "George"; // => "George"
```

يتيح [المعامل `?.`][null-conditional-operator] استدعاء الأعضاء بأمان على قيمة قد تكون `null`:

```csharp
string? fruit = "apple";
fruit?.Length; // => 5

string? vegetable = null;
vegetable?.Length; // => null
```

إذا اعتقد المترجم أن قيمة ما قد تكون `null` لكنك متأكد من أنها لن تكون كذلك، فيمكن استخدام [المعامل `!.`][null-forgiving-operator] لكتم التحذير. لكن لا تستخدم هذا المعامل إلا كحل أخير.

```csharp
void PrintName(string? name)
{
    // Assume that the IsValid() method only return true
    // when its argument is not null
    if (IsValid(name))
    {
        // No compile warning
        Console.WriteLine(name!.Length);
    }
}
```

إذا أردت معرفة المزيد عن التعامل مع المراجع القابلة لـ `null`، فاطّلع على [هذا الدرس التعليمي][nullable-reference-types-tutorial].
