# مقدمة

## جملة `switch`

مثل جملة _if/else_، تتيح لك جملة `switch` تغيير مسار تنفيذ البرنامج عبر تنفيذ الكود بشكل شرطي.
الفرق أن جملة `switch` لا يمكنها إلا مقارنة قيمة تعبير من نوع أولي أو من نوع سلسلة نصية بقيم ثابتة معرّفة مسبقًا.

هناك بعض الكلمات المفتاحية المفيدة عند استخدام جملة `switch`.

- `switch`: تتيح لك هذه الكلمة المفتاحية الإعلان عن بنية جملة `switch`.
  ويأتي بعدها التعبير أو المتغير الذي سيغيّر النتيجة.
- `case`: ستستخدم هذه الكلمة المفتاحية للإعلان عن الاحتمالات المختلفة للنتيجة.
- `break`: الكلمة المفتاحية `break` مفيدة جدًا لإيقاف تنفيذ جملة `switch` عند نهاية المسار المطلوب.
  وإذا نسيتها، فسيستمر البرنامج وقد يؤدي ذلك إلى نتائج غير متوقعة.
- `default`: كما يوحي اسمها، استخدمها كنتيجة افتراضية عندما لا تطابق أي حالة أخرى نتيجة تعبيرك.

في أبسط صورها، تختبر جملة `switch` تعبيرًا أوليًا أو نصيًا وتتخذ قرارًا بناءً على قيمته.
على سبيل المثال:

```java
String direction = getDirection();
switch (direction) {
    case "left":
        goLeft();
        break;
    case "right":
        goRight();
        break;
    default:
        // otherwise
        markTime();
        break;
}
```
