# نبذة

حلقات `repeat-while` تشبه حلقات `while`، لكن مع فرق رئيسي واحد: فحص الشرط يحدث *بعد* تنفيذ جسم الحلقة وليس قبلها.
ونتيجة لذلك، تضمن حلقة `repeat-while` تنفيذ كتلة الكود الخاصة بها مرة واحدة على الأقل.

```swift
repeat {
    print("This runs at least once")
} while false

print("Loop done")

// Prints:
// This runs at least once
// Loop done
```
