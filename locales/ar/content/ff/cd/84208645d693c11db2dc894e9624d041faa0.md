# نبذة

يُستخدم `Map` لتخزين أزواج من **المفتاح** و**القيمة**. ويُهيَّأ `Map` تمامًا مثل المصفوفة، لكنه يستخدم عامل الكتابة الحرفية `=>`. ويمكن أيضًا تعريف أنواع المفاتيح والقيم فيه بشكل صريح، أو يمكن استنتاج الأنواع. ويجب أن تكون المفاتيح فريدة، وإلا فسيُرمى خطأ.

```haxe
var map1:Map<Int, String> = [1 => "one", 2 => "two", 3 => "three"];

var map2 = ["one" => 1, "two" => 2, "three" => 3];

var map3 = [1 => "cat", 1 => "dog"]; // Error: Duplicate Key

var map4 = ["h" => "Hello", "b" => "Bye"];
trace(map4["h"]); // Hello
```

يمكن تكرار المرور على `Map` باستخدام حلقة `for`. ويمكنك المرور إما على القيم وإما على المفاتيح:

```haxe
for (value in map) {
  // ...
}

for (key in map.keys()) {
  // ...
}
```

خلف الكواليس، `Map` نوع مجرّد. وعند التصريف، يُحوَّل إلى أحد عدة أنواع متخصصة حسب نوع المفتاح:

- `String`: `haxe.ds.StringMap`
- `Int`: `haxe.ds.IntMap`
- `EnumValue`: `haxe.ds.EnumValueMap`
- `{}`: `haxe.ds.ObjectMap`

نوع `Maps` غير موجود في وقت التشغيل، وقد استُبدل بأحد الكائنات المذكورة أعلاه.
