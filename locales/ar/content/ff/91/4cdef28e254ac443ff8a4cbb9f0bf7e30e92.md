# التعلّم

* يُعدّ كتاب [The Rust Programming Language](https://doc.rust-lang.org/book/) مصدرًا ممتازًا للبدء مع Rust وكذلك للتعمّق في ميزات محددة منها.
* يعرض لك [Rust by Example](https://doc.rust-lang.org/stable/rust-by-example/) أمثلة على أكثر الأشياء شيوعًا التي ستكتبها بلغة Rust.
* [Into_rust()](http://intorust.com/) "مقاطع مصوّرة لتعلّم Rust."
* [Rustlings](https://github.com/carols10cents/rustlings) "تمارين صغيرة تعوّدك على قراءة كود Rust وكتابته."
* [Rust User Forum](http://users.rust-lang.org) يجيب عن أسئلة جميع المستويات
