# نبذة

أعداد الفاصلة العائمة هي أعداد كسرية أو صحيحة تتضمن فاصلة عشرية (مثل `3.14`، `-1.7`، `99.99`، `2048.0`)

ينقسم نوع الفاصلة العائمة في Common Lisp إلى عدة أنواع فرعية، لكل منها خصائصه ودقته: short-float وsingle-float وdouble-float وlong-float.

النوع الفرعي short-float يشغل عادةً أقل قدر من الذاكرة ويوفر أدنى دقة بين الأنواع الفرعية الأربعة. وهو مناسب للحالات التي يكون فيها استهلاك الذاكرة مصدر قلق، لكن يمكن قبول دقة أقل.

النوع الفرعي single-float يوفر توازنًا بين استهلاك الذاكرة والدقة. ويُستخدم عادةً في حسابات الفاصلة العائمة العامة.

النوع الفرعي double-float يوفر دقة أعلى من single-float، وهو مناسب للتطبيقات التي تتطلب حسابات أكثر دقة، مثل الحسابات العلمية والمحاكاة العددية.

النوع الفرعي long-float يوفر أعلى دقة بين الأنواع الفرعية الأربعة، لكنه قد يستهلك ذاكرة أكبر من غيره. ويُستخدم عادةً في التطبيقات المتخصصة التي تتطلب حسابات بالغة الدقة.

تتيح هذه الأنواع الفرعية لمبرمجي Common Lisp اختيار المستوى المناسب من الدقة واستهلاك الذاكرة بما يتوافق مع متطلبات تطبيقاتهم.

بشكل عام، إذا كنت تتعامل مع أعداد صحيحة فقط، فمن الأفضل أن تستخدم الأعداد الصحيحة، لأنها لا تعاني من فقدان الدقة الذي تعانيه أعداد الفاصلة العائمة على مدى حسابات عديدة.

## مراجع

```lisp
;; Rounding to the Nearest Whole Number
(round 3.14)  ; => 3
(round -3.14) ; => -3
(round 2.72)  ; => 3
(round -2.72) ; => -3

;; Rounding Towards Zero
(truncate 3.14)  ; => 3
(truncate -3.14) ; => -3
(truncate 2.72)  ; => 2
(truncate -2.72) ; => -2

;; Rounding Towards Negative Infinity
(floor 3.14)  ; => 3
(floor -3.14) ; => -4
(floor 2.72)  ; => 2
(floor -2.72) ; => -3

;; Rounding Towards Positive Infinity
(ceiling 3.14)  ; => 4
(ceiling -3.14) ; => -3
(ceiling 2.72)  ; => 3
(ceiling -2.72) ; => -2
```
