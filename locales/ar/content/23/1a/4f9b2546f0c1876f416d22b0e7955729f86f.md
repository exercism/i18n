# مقدمة

في C#، يمكن تعريف تدرّج هرمي للأصناف باستخدام _الوراثة_، التي تتيح لصنف مشتق (`Car`) أن يرث سلوك الصنف الأب (`Vehicle`) وبياناته. وإذا لم يُحدَّد صنف أب، فإن الصنف يرث من الصنف `object`.

يمكن للأصناف الآباء أن توفّر وظائف للأصناف المشتقة بثلاثة أساليب:

- تعريف طريقة عادية.
- تعريف طريقة `virtual`، وهي مثل الطريقة العادية لكن يمكن للأصناف المشتقة _تغييرها_.
- تعريف طريقة `abstract`، وهي طريقة بلا تنفيذ يجب على الأصناف المشتقة _أن تنفّذها_. والصنف الذي يحتوي طرقًا `abstract` يجب أن يُوسم هو أيضًا بـ `abstract`. ولا يمكن إنشاء كائنات من الأصناف المجردة.

يسمح مُعدِّل الوصول `protected` بالوصول إلى عضو من أعضاء الصنف الأب داخل صنف مشتق، لكنه يمنع وصول الأصناف الأخرى إليه.

يمكن للأصناف المشتقة الوصول إلى أعضاء الصنف الأب عبر الكلمة المفتاحية `base`.

```csharp
// Inherits from the 'object' class
abstract class Vehicle
{
    // Can be overridden
    public virtual void Drive()
    {
    }

    // Must be overridden
    protected abstract int Speed();
}

class Car : Vehicle
{
    public override void Drive()
    {
        // Override virtual method

        // Call parent implementation
        base.Drive();
    }

    protected override int Speed()
    {
        // Implement abstract method
    }
}
```

سيستدعي منشئ الصنف المشتق تلقائيًا منشئ الصنف الأب _قبل_ تنفيذ منطق المنشئ الخاص به. ويمكن تمرير الوسائط إلى منشئ الصنف الأب باستخدام الكلمة المفتاحية `base`:

```csharp
abstract class Vehicle
{
    protected Vehicle(int wheels)
    {
        Console.WriteLine("Called first");
    }
}

class Car : Vehicle
{
    public Car() : base(4)
    {
        Console.WriteLine("Called second");
    }
}
```

عندما يُشتق أكثر من صنف من صنف أساسي، فغالبًا ما تنفّذ تلك الأصناف (اثنان أو أكثر) نسخًا مختلفة من طريقة في الصنف الأساسي. وهذا مبدأ بالغ الأهمية يُسمى تعدد الأشكال. وعلى سبيل المثال، في تنويع على المثال السابق، نوضّح كيف يمكن للكود الذي يستخدم `Vehicle` أن يغيّر سلوكه تبعًا لنوع المركبة التي أُنشئت منها نسخة.

```csharp
abstract class Vehicle
{
   public abstract string GetDescription();
}

class Car : Vehicle
{
   public Car()
   {
   }

   public override string GetDescription()
   {
      return "Runabout";
   }
}

class Rig : Vehicle
{
   public Rig()
   {
   }

   public override string GetDescription()
   {
      return "Big Rig";
   }
}

Vehicle v1 = new Car();
Vehicle v2 = new Rig();

v1.GetDescription();
// => Runabout
v2.GetDescription();
// => Big Rig
```
