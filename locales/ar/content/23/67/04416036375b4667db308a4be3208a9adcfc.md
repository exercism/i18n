# مقدمة

## القيم المنطقية

تمثل Gleam القيم صحيح وخطأ بنوع `Bool`. لا توجد سوى قيمتين: `True` و`False`. يمكن ربط هذه القيم بمتغير:

```gleam
let true_variable = True
let false_variable = False
```

يمكن استخدام العوامل `&&` و`||` و`!` لمعالجة القيم المنطقية:

```gleam
True && True  // -> True
True && False // -> False

False || True  // -> True
False || False // -> False

!False // -> True
!True  // -> False
```

يستخدم العاملان `&&` و`||` التقييم قصير الدائرة، مما يعني أن التعبير على الجانب الأيمن من العامل لا يُقيَّم إلا عند الحاجة.

لكل عامل أسبقية مختلفة، حيث يُقيَّم العامل `!` قبل `&&` و`||`. يمكن استخدام الأقواس المعقوفة لتقييم جزء واحد من التعبير قبل الأجزاء الأخرى:

```gleam
!True && False   // -> False
!{True && False} // -> True
```
