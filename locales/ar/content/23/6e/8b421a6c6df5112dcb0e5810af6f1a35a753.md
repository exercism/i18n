# نبذة

[`Rational numbers`][rational] هي كسور بسطها عدد صحيح ومقامها عدد صحيح.

على سبيل المثال، يمكننا تخزين `2//3` في صورة كسر دقيق بدلًا من القيمة التقريبية `0.6666...` من النوع `Float64`.

وميزة ذلك أنه (باستثناء الحالة القصوى المتمثلة في [تجاوز سعة الأعداد الصحيحة][integer-overflow]) سيبقى العدد النسبي دقيقًا، ما يتجنب أخطاء التقريب التي كثيرًا ما تكون حتمية مع أعداد الفاصلة العائمة.

توجد بعض التفاصيل الإضافية في [صفحة الدليل][julia-rational] الخاصة بـ Julia.

الأعداد النسبية نوع عددي بسيط إلى حد كبير، وهي مصممة لتعمل كما تتوقع تمامًا.
ولأنها نوع قياسي في Julia منذ الإصدارات الأولى، فإن معظم الدوال تقبلها كمدخلات بالطريقة نفسها التي تقبل بها الأعداد الصحيحة وأعداد الفاصلة العائمة.

## إنشاء الأعداد النسبية

الإنشاء بسيط: استخدم `//` بين عددين صحيحين.

```julia-repl
julia> 3//4
3//4

julia> a = 3; b = 4;

julia> a//b
3//4
```

تُحذف العوامل المشتركة تلقائيًا، فيُختصر الكسر إلى [`"lowest terms"`][lowest-terms]: أصغر عددين صحيحين يمثلان الكسر تمثيلًا دقيقًا، مع مقام غير سالب.

```julia-repl
julia> 5//15
1//3

julia> 5//-15
-1//3
```

النتائج اللانهائية مقبولة، أما [`NaN`][NaN] فلا.

```julia-repl
julia> 1//0
1//0

julia> float(1//0)
Inf

julia> 0//0
ERROR: ArgumentError: invalid rational: zero(Int64)//zero(Int64)
```

## العمليات الحسابية على الأعداد النسبية

تعمل [`arithmetic operators`][operators] المعتادة `+ - * / ^ %` مع الأعداد النسبية، تمامًا كما تعمل مع الأنواع العددية الأخرى.

يمكن إشراك الأعداد الصحيحة وقيم `Rational` أخرى، فتكون النتيجة `Rational`.
وإشراك `float` في التعبير يعطي ناتجًا من نوع `float`، مع ما يترتب على ذلك من فقدان محتمل في الدقة.

وإذا أردت الحصول على `float`، فما عليك إلا استخدام الدالة `float()` لتحويل العدد النسبي.
ومن الطبيعي تمامًا استخدام الأعداد النسبية للحفاظ على الدقة خلال عملية حسابية طويلة، ثم التحويل إلى `float` في النهاية.

```julia-repl
julia> 3//4 + 1//3  # addition
13//12

julia> 3//4 * 1//3  # multiplication
1//4

julia> 3//4 / 1//3  # division
9//4

julia> 3//4 ^ 2  # exponentiation
3//16

julia> 3//4 + 5  # rational and int => rational
23//4

julia> 3//4 + 5.3  # rational and float => float
6.05

julia> float(3//4)  # casting
0.75
```

يمكن أيضًا دمج الأعداد النسبية مع [الأعداد المركبة][complex].
وتُناقش الأعداد المركبة في [مفهوم منفصل][complex-concept].

## عمليات أخرى

في Julia، الأعداد النسبية مجرد أعداد.
وعادةً ما يحوّل المترجم الأنواع عند الحاجة.

لكن انتبه إلى أن المقارنات تعمل مع الكسور التي لها تمثيل عشري منتهٍ:

```julia-repl
julia> 3//4 == 0.75
true

julia> 3//4 < 0.74
false
```

أما في غير ذلك، فينبغي تحويل `Rational` إلى `Float` قبل المقارنة:

```julia-repl
julia> 1//3 == 1/3
false

julia> float(1//3) == 1/3
true
```

تأخذ الدوال الرياضية الأعداد النسبية كمدخلات، لكنها قد تعطي نتيجة من نوع الفاصلة العائمة:

```julia-repl
julia> sqrt(9//16)
0.75
```
