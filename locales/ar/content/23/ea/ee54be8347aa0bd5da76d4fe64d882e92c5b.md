# مقدمة

للمصفوفات [المصفوفات][arrays-concept] طرق مدمجة لتحليل محتويات المصفوفة.
تأخذ معظم هذه الطرق كوسيط دالةً تُرجع صحيحًا أو خطأً.
وتُسمى هذه الدالة [`predicate`][predicate_in_programming].

الغرض من الطرق المدمجة هو استخدامها _بدلًا من حلقة `for`_ أو الطريقة المدمجة `forEach`:

مثال على التحليل باستخدام حلقة `for`:

```javascript
const numbers = [1, 'two', 3, 'four'];
for (var i = 0; i < numbers.length; i++) {
  if (numbers[i] === 'two') {
    return i;
  }
}
// => 1
```

مثال على التحليل باستخدام طريقة مدمجة:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.indexOf('two');
// => 1
```

فيما يلي بعض الطرق المدمجة المفيدة الأخرى المتاحة لتحليل مصفوفة. راجع [MDN][mdn-array-methods] للحصول على قائمة كاملة بطرق المصفوفات.

## `includes`

> تحدد طريقة `includes()` ما إذا كانت المصفوفة تحتوي على قيمة معينة بين عناصرها، فتُرجع صحيحًا أو خطأً وفقًا لذلك. [^1]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.includes(1);
// => true
numbers.includes('one');
// => false
```

## `every`

> تختبر طريقة `every()` ما إذا كانت جميع عناصر المصفوفة تجتاز الاختبار الذي تنفذه الدالة المقدَّمة. وهي تُرجع قيمة منطقية. [^2]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.every((num) => num % 2 !== 0);
// => true
```

## `some`

> تختبر طريقة `some()` ما إذا كان عنصر واحد على الأقل في المصفوفة يجتاز الاختبار الذي تنفذه الدالة المقدَّمة. [^3]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.some((num) => num % 2 !== 0);
// => true
```

## `find`

> تُرجع طريقة `find()` قيمة أول عنصر في المصفوفة المقدَّمة يحقق دالة الاختبار المقدَّمة. وإذا لم تحقق أي قيمة دالة الاختبار، فستكون القيمة المُرجَعة `undefined`. [^4]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.find((num) => num < 5);
// => 1
```

## `findIndex`

> تُرجع طريقة `findIndex()` فهرس أول عنصر في المصفوفة يحقق دالة الاختبار المقدَّمة. وإلا فإنها تُرجع `-1`، مما يشير إلى أن أي عنصر لم يجتز الاختبار. [^5]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.findIndex((num) => num > 7);
// => 4
numbers.findIndex((num) => num > 9);
// => -1
```
