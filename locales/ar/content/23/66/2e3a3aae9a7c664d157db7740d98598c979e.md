# الاختبارات

## سطر الأوامر

يمكنك استخدام الأمر التالي لتشغيل الاختبارات من سطر الأوامر:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)'
```

استبدل `<exercise>` باسم التمرين الذي تنفّذه.

## الوضع التفاعلي

لتشغيل prolog بشكل تفاعلي، شغّل أولًا:

```bash
swipl
```

بعد أن تبدأ وحدة تحكم prolog، حمّل تنفيذك وشغّل الاختبارات باستخدام:

```
?- ["<exercise>.pl"].
?- ["<exercise>_tests.plt"].
?- run_tests.
```

استبدل `<exercise>` باسم التمرين الذي تنفّذه.

### إعادة تحميل التغييرات

بعد تحميل الملفات أعلاه، يمكنك تطبيق أي تغييرات أجريتها بتشغيل:

```
?- make.
```

## الاختبارات المتخطّاة

عند بدء تمرين لأول مرة، لن يُشغَّل سوى الاختبار الأول. أما بقية الاختبارات فقد تم تخطّيها بإضافة `condition(pending)` إلى هدف `test`. وبعد نجاح الاختبار الأول، ألغِ تخطّي الاختبار التالي بتغيير `pending` في `condition(pending)` إلى `true`. كرّر ذلك مع كل اختبار حتى تعمل جميعها وتنجح.

### سطر الأوامر

أضف الوسيط `-- --all` إلى نهاية الأمر لتشغيل أي اختبارات معلّقة أيضًا:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)' -- --all
```
