# التعليمات

لدى أحد أصدقائك متجر بيع بالجملة قديم يُدعى **Gross Store**.
الاسم مأخوذ من كمية البضاعة التي يبيعها المتجر: فكل شيء عنده بوحدة [gross][gross-unit].
طلب منك صديقك أن تنفّذ نظام نقطة بيع (POS) لمتجره.
**أولًا، تريد بناء نموذج أولي له.**
**في نموذجك الأولي، سيسجّل نظامك الكمية فقط.**
أعطاك صديقك قائمة بالقياسات لمساعدتك:

| الوحدة             | القيمة |
| ------------------ | ----- |
| quarter_of_a_dozen | 3     |
| half_of_a_dozen    | 6     |
| dozen              | 12    |
| small_gross        | 120   |
| gross              | 144   |
| great_gross        | 1728  |

## 1. خزّن وحدة القياس في برنامجك

لكي تستخدم وحدة القياس، عليك تخزينها في برنامجك.

```go
units := Units()
fmt.Println(units)
// Output: map[...] with entries like ("dozen": 12)
```

## 2. أنشئ فاتورة جديدة للعميل

تحتاج إلى تنفيذ دالة تُنشئ فاتورة جديدة (فارغة) للعميل.

```go
bill := NewBill()
fmt.Println(bill)
// Output: map[]
```

## 3. أضف عنصرًا إلى فاتورة العميل

لتنفيذ ذلك، ستحتاج إلى:

- أرجِع `false` إذا لم تكن الوحدة `unit` المُعطاة موجودة في خريطة `units`.
- وإلا، أضف العنصر إلى `bill` الخاصة بالعميل، مُفهرَسًا باسم العنصر، ثم أرجِع `true`.
- إذا كان العنصر موجودًا بالفعل في الفاتورة، فزد كميته بالمقدار الذي تقابله الوحدة `unit` المُعطاة.

```go
bill := NewBill()
units := Units()
ok := AddItem(bill, units, "carrot", "dozen")
fmt.Println(ok)
// Output: true (since dozen is a valid unit)
```

> لاحظ أن القيمة المُرجَعة من النوع `bool`.

## 4. أزل عنصرًا من فاتورة العميل

لتنفيذ ذلك، ستحتاج إلى:

- أرجِع `false` إذا كان العنصر المُعطى **غير** موجود في الفاتورة
- أرجِع `false` إذا لم تكن الوحدة `unit` المُعطاة موجودة في خريطة `units`.
- أرجِع `false` إذا كانت الكمية الجديدة أقل من 0.
- إذا كانت الكمية الجديدة 0، فأزل العنصر تمامًا من `bill` ثم أرجِع `true`.
- وإلا، قلّل كمية العنصر وأرجِع `true`.

```go
bill := NewBill()
units := Units()
ok := RemoveItem(bill, units, "carrot", "dozen")
fmt.Println(ok)
// Output: false (because there are no carrots in the bill)
```

> لاحظ أن القيمة المُرجَعة من النوع `bool`.

## 5. أرجِع كمية عنصر معيّن موجود في فاتورة العميل

لتنفيذ ذلك، ستحتاج إلى:

- أرجِع `0` و`false` إذا لم يكن العنصر `item` موجودًا في الفاتورة.
- وإلا، أرجِع كمية العنصر في `bill` و`true`.

```go
bill := map[string]int{"carrot": 12, "grapes": 3}
qty, ok := GetItem(bill, "carrot")
fmt.Println(qty)
// Output: 12
fmt.Println(ok)
// Output: true
```

> لاحظ أن القيمتين المُرجَعتين من النوعين `int` و`bool`.

[gross-unit]: https://en.wikipedia.org/wiki/Gross_(unit)
