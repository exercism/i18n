# أصناف وخصائص القراءة فقط

تسمح الأصناف والخصائص للقراءة فقط للصنف بتعريف خصائص عامة يسهل الوصول إليها، لكنها تمنع تعديلها.
لكي تعرّف خاصية على أنها للقراءة فقط، يجب إضافة `readonly` قبل تحديد النوع.
يُسمح بإسناد الخاصية مرة واحدة، لكن أي محاولة لإعادة الإسناد أو تعديل القيمة ستؤدي إلى `Error`.

```php
<?php

class Block
{
    public function __construct(
        public readonly int $length;
        public readonly int $width;
    ) {
    }
}
```

تبني الأصناف للقراءة فقط على هذا السلوك؛ فعند تعريف الصنف بـ `readonly`، يُطبَّق تعريف القراءة فقط على كل خاصية من خصائصه.
إضافة إلى ذلك، يمنع هذا إضافة خصائص ديناميكية.

```php
<?php

readonly class Block
{
    public function __construct(
        public int $length;
        public int $width;
    ) {
    }
}
```
