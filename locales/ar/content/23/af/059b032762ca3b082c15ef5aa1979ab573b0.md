# مقدمة

الوراثة مفهوم أساسي في البرمجة كائنية التوجه (OOP).
وهي تمثل علاقة «هو نوع من».
وهي تعني حرفيًا في البرمجة ما تعنيه في اللغة الإنجليزية: وراثة الميزات من الصنف الأعلى (في البرمجة، الميزات عادةً هي الدوال والمتغيرات).

لنأخذ صنفًا، `Animal` كما هو موضح،

```java
//Creating an Animal class with bark() as a member function.
public class Animal {

    public void bark() {
        System.out.println("This is an animal");
    }

}
```

`Animal` هو صنف أعلى، لأن الخصائص التي يملكها هذا الصنف يمكن توريثها إلى كل الحيوانات عمومًا.

لنأخذ حيوانًا اسمه `Lion`، له صنف كالتالي:

```java
//Lion class is a child class of Animal.
public class Lion extends Animal {

    @Override
    public void bark() {
        System.out.println("Lion here!!");
    }

}
```

~~~~exercism/note
تُستخدم التعليمة `Override` للإشارة إلى أن طريقة في صنف فرعي تتجاوز طريقة في الصنف الأعلى الخاص بها.
ليست ضرورية تمامًا، لكن من الأفضل استخدامها.
~~~~

الآن، كلما نفّذنا:

```java
Animal animal = new Lion(); //creating instance of Animal, of type Lion
animal.bark();
```

ملاحظة: تهيئة الصنف `Animal` باستخدام `Lion`.
سيبدو الناتج كالتالي:

```java
Lion here!!
```

وفقًا للبرمجة كائنية التوجه، هناك أنواع كثيرة من الوراثة، لكن Java تدعم بعضها فقط (الوراثة متعددة المستويات والوراثة الهرمية).
لمزيد من المعلومات، يُرجى قراءة [هذا][java-inheritance].
