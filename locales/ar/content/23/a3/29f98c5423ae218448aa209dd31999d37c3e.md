# تدقيق مدفوعات قاعدة البيانات

## بيان المشكلة

تحتاج ABC Corp منك أن تُحمّل كل البيانات من قاعدة بيانات SQL إلى [جدول Ballerina](https://ballerina.io/learn/by-example/table-syntax/) لمزيد من المعالجة. ثم تحتاج إلى إيجاد أسماء الموظفين الذين لديهم مدخلات دفع يتجاوز مبلغها قيمةً معيّنة (مثل 3000.00) عبر الاستعلام من جدول Ballerina المُحمَّل.

**الخطوة 1:**

أنشئ جدول Ballerina بالأعمدة التالية.

`payment_id` - عدد صحيح

`amount` - عدد عشري

`employee_name` - سلسلة نصية

**الخطوة 2:**

املأ جدول Ballerina أعلاه بتحميل مجموعة البيانات الكاملة المقابلة في قاعدة بيانات H2. استخدم `payment_id` كمفتاح أساسي للجدول.

**الخطوة 3**

استعلم من جدول Ballerina باستخدام تعبيرات الاستعلام في Ballerina لإيجاد أسماء الموظفين الذين لديهم مدخلات دفع تتجاوز المبلغ المعطى. رتّب النتيجة حسب اسم الموظف تصاعديًا. أزل أسماء الموظفين المكررة من النتيجة قبل إرجاعها.

> ملاحظة: من الإلزامي استخدام جدول Ballerina لتنفيذ الحل.

## تفاصيل قاعدة البيانات

استخدم قاعدة بيانات H2 المرفقة لهذه المسألة.

> ملف قاعدة البيانات النموذجية هو `gofigure.mv.db`، واسم قاعدة البيانات هو `gofigure`. وهو موجود داخل مجلد `db`.

الجداول التالية موجودة بالفعل في قاعدة بيانات H2 النموذجية مع بعض البيانات النموذجية. أسماء الأعمدة وأنواع البيانات فيما يلي.

**اسم الجدول**: `Employee`

| **الأعمدة:**      | النوع |
| -----------       | ----------- |
| `employee_id`     | عدد صحيح، مفتاح أساسي يزداد تلقائيًا       |
| `name`            | سلسلة نصية        |
| `city`            | سلسلة نصية        |
| `department`      | سلسلة نصية        |
| `age`             | عدد صحيح        |

**اسم الجدول**: `Payment`

| **الأعمدة:**      | النوع |
| -----------       | ----------- |
| `payment_id`      | عدد صحيح، مفتاح أساسي يزداد تلقائيًا       |
| `date`            | تاريخ        |
| `amount`          | عدد عشري        |
| `employee_id`     | عدد صحيح        |
| `reason`          | سلسلة نصية        |

* ملف قاعدة البيانات هو `gofigure.mv.db`. استخدم رابط JDBC بالشكل `jdbc:h2:file:/path/to/db/file`
* اسم المستخدم: `root`
* كلمة المرور: `root`

## القيود

* استخدم ملف قاعدة بيانات H2 المرفق في مجلد `db` للتحقق من الاستعلامات ومن نموذج Ballerina
* استخدم أسلوب معاملات تبعية maven لإضافة مشغّل قاعدة بيانات H2 كتبعية منصة في ملف Ballerina.toml الخاص بك

## بيئة الاختبار

* يمكنك تشغيل الاختبارات عبر `bal test`، وستجري الاختبارات على قاعدة البيانات النموذجية المعطاة.
