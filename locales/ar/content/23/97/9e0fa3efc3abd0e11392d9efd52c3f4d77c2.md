# التعليمات

بصفتها ساحرة ناشئة، تحتاج Elyse إلى تحليل مجموعة أوراقها بطرق مختلفة عديدة. ولتبسيط الأمور، لا تستخدم إلا أوراقًا تحمل القيم من 1 إلى 10.

## 1. حدّد عدد الأوراق من نوع معيّن في المجموعة

تريد Elyse أن تعرف عدد الأوراق التي لديها من نوع معيّن في مجموعتها.

اكتب دالة `cardTypeCheck` تأخذ معاملين: مصفوفة أوراق (مجموعة Elyse) ونوع الورقة المطلوب عدّها.

<!--prettier-ignore -->
~~~exercism/note
ينبغي أن تستخدم الدالة `forEach` وأن تُرجع عدد الأوراق من النوع المحدّد في المجموعة.
~~~

```javascript
const cardType = 3;
cardTypeCheck([1, 2, 3, 4], cardType);
// => 1
```

## 2. حدّد عدد الأوراق الفردية أو الزوجية

من أجل حيلة أخرى، تحتاج Elyse إلى معرفة عدد الأوراق الفردية أو الزوجية في مجموعتها.

نفّذ دالة `determineOddEvenCards` تأخذ معاملين: مصفوفة أوراق (مجموعة Elyse)، وقيمة منطقية (صحيح تقابل "الزوجي"، وخطأ تقابل "الفردي").

ينبغي أن تُرجع هذه الدالة عددًا واحدًا: عدد الأوراق الفردية أو الزوجية (بناءً على قيمة الوسيط الثاني) في المجموعة.

<!--prettier-ignore -->
~~~exercism/note
للتدريب، استخدم هذه المرة حلقة `for...of` في تنفيذ الدالة.
~~~

```javascript
determineOddEvenCards([1, 2, 3, 1, 5, 6], true);
// => 2

determineOddEvenCards([1, 2, 3, 1, 5, 6], false);
// => 4
```
