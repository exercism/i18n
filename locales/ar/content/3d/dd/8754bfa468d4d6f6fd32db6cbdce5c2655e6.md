# تعليمات

يمتلئ دفتر ملاحظات المحقّق مع تقدّم القضية، ويفرغ مرة أخرى مع استبعاد خطوط التحقيق.

تقع المهام الخمس كلها في الصنف `CASE_NOTES`.

## 1. افتح قضية

أرجِع دفتر ملاحظات جديدًا فارغًا.

```sather
notes ::= CASE_NOTES::new_case;
notes.size
-- => 0
```

## 2. دوّن دليلًا

أضِف دليلًا إلى نهاية دفتر الملاحظات. لا تُرجع هذه الدالة شيئًا، بل تغيّر دفتر الملاحظات المعطى لها.

```sather
CASE_NOTES::add_clue(notes, "muddy boots");
notes.size
-- => 1
```

## 3. كم عدد الأدلة؟

```sather
CASE_NOTES::clue_count(notes)
-- => 1
```

## 4. استبعد دليلًا واحدًا

أخرِج الدليل الموجود في موضع معيّن من دفتر الملاحظات. وينتقل كل ما بعده إلى الأعلى. وهذه أيضًا لا تُرجع شيئًا.

```sather
CASE_NOTES::rule_out(notes, 0);
```

## 5. اقرأ القضية من جديد

أرجِع كل الأدلة في دفتر الملاحظات، مضمومة بـ `"; "`. أما دفتر الملاحظات الفارغ فيُقرأ على أنه السلسلة النصية الفارغة.

```sather
CASE_NOTES::summary(notes)
-- => "muddy boots; broken window"
```
