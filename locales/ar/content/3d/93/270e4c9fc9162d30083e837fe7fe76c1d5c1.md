# التعليمات

أنت مراقب طيور شغوف يتابع عدد الطيور التي زارت حديقتك خلال الأيام السبعة الماضية.

لديك خمس مهام، وكلها تتعلق بأعداد الطيور التي زارت حديقتك.

## 1. تحقق من أعداد الطيور في الأسبوع الماضي

لأغراض المقارنة، تحتفظ دائمًا بنسخة من أعداد الأسبوع الماضي قريبة منك، وهي: 0، 2، 5، 3، 7، 8 و4. نفّذ طريقة `BirdCount.last_week` التي تُرجع أعداد الأسبوع الماضي:

```ruby
BirdCount.last_week
# => [0, 2, 5, 3, 7, 8, 4]
```

## 2. تحقق من عدد الطيور التي زارت أمس

نفّذ طريقة `BirdCount#yesterday` لتُرجع عدد الطيور التي زارت حديقتك أمس. أعداد الطيور مرتبة حسب اليوم، حيث يكون العنصر الأول عدد أقدم يوم، والعنصر الأخير عدد اليوم.

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.yesterday
# => 4
```

## 3. احسب العدد الإجمالي للطيور الزائرة

نفّذ طريقة `BirdCount#total` لتُرجع العدد الإجمالي للطيور التي زارت حديقتك:

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.total
# => 19
```

## 4. احسب عدد الأيام المزدحمة

بعض الأيام أكثر ازدحامًا من غيرها. اليوم المزدحم هو الذي زارت فيه خمسة طيور أو أكثر حديقتك.
نفّذ طريقة `BirdCount#busy_days` لتُرجع عدد الأيام المزدحمة:

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.busy_days
# => 2
```

## 5. تحقق مما إذا كان هناك يوم بلا طيور زائرة

نفّذ طريقة `BirdCount#day_without_birds?` التي تُرجع `true` إذا كان هناك يوم لم تزر فيه أي طيور الحديقة؛ وإلا، فأرجع `false`:

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.day_without_birds?
# => true
```
