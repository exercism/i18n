# الاختبارات

## clojure.test

يأتي Babashka مرفقًا معه clojure.test. بمجرد أن تصبح مستعدًا للعمل على تمرين ما وتنشئ ملفًا يحتوي على حلّك (مثل `bob.clj`)، يمكنك تشغيل الاختبارات باستخدام `clojure.test/run-tests` [كما هو موضح هنا](http://clojure.github.io/clojure/clojure.test-api.html#clojure.test/run-tests).


تتيح لك بيئة REPL تشغيل الكود بسهولة والحصول على تغذية راجعة فورية، ويمكنك أيضًا استخدامها لتشغيل الاختبارات. ويُوصى باستخدام `rlwrap` لتمكين تحرير الأسطر وسجل الأوامر باستخدام السهمين لأعلى وأسفل. لاختبار تمرين ما، انتقل إلى مجلده وافتح REPL عبر socket مع إضافة مجلدي `src` و`test` إلى classpath:
``` bash
/bob $ rlwrap bb --classpath src:test socket-repl 1666
```

أولًا، استدعِ `require` على فضاء أسماء الاختبار:
``` clojure
=> (require 'bob-test)
nil
```

ثم استدعِ `run-tests` على `bob-test`:
``` clojure
=> (clojure.test/run-tests 'bob-test)

Testing bob-test

Ran 25 tests containing 25 assertions.
0 failures, 0 errors.
{:test 25, :pass 25, :fail 0, :error 0, :type :summary}
```

لإنشاء سكربت تشغيل الاختبارات:

``` clojure
#!/usr/bin/env bb

(require '[clojure.test :as t]
         '[babashka.classpath :as cp])

(cp/add-classpath "src:test")                        

(require 'bob-test)                  

(def test-results
  (t/run-tests 'bob-test))           

(def failures-and-errors
  (let [{:keys [:fail :error]} test-results]
    (+ fail error)))                                 

(System/exit failures-and-errors)
```
