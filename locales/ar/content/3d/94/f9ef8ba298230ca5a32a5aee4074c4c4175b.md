# مقدمة


## القيم المنطقية

يوفّر PowerShell النوع [`bool`][booleans] لتمثيل القيمتين صحيح وخطأ.
لا يوجد في هذا النوع سوى قيمتين: `True` و`False`.
يمكنك إسناد هاتين القيمتين إلى المتغيرات باستخدام البادئة `$`:

```powershell
> $TrueVar  = $true
> $FalseVar = $FALSE
#Case senstitivity doesn't matter here
```

يمكننا استخدام [العوامل المنطقية][logical-operators] مثل `-and` و`-or` و`-not` لدمج التعبيرات المنطقية وتقييمها.

```powershell
> $TrueVar  = $true -and $true
> $FalseVar = $true -and $false

> $TrueVar  = $true -or $false
> $FalseVar = $false -or $false

> $TrueVar  = -not $false
> $FalseVar = -not $true
```


## التعليمات القائمة على التعليقات

تساعد [`Comment-based help`][comment-based help] في PowerShell على تقديم معلومات مفصّلة عن الدوال والسكربتات المكتوبة في التعليقات.
وهي تستخدم كلمات مفتاحية خاصة في تعليقات التعليمات لتحديد الموضوعات المعنية، مثل `.SYNOPSIS` أو `.EXAMPLE` أو `.NOTES`.

```powershell
function ExampleFunction($Arg) {
    <#
    .DESCRIPTION
    A detailed description of the function or script. This keyword can be used only once in each topic.

    .PARAMETER Arg
    The description of a parameter, it must be follow with the parameter name.
    #>
}
```

يمكنك عرض معلومات التعليمات القائمة على التعليقات باستخدام الأمر `Get-Help`.

```powershell
> Get-Help -Name "ExampleFunction"
```
