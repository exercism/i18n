# مقدمة

## الأساسيات

في F#، يُشار إلى إسناد قيمة إلى اسم باسم _ارتباط_. الارتباطات غير قابلة للتغيير، مما يجعلها مشابهة للثوابت في لغات أخرى. بما أن F# لغة ذات أنواع ثابتة، يمتلك كل ارتباط نوعًا في وقت الترجمة.

تُعرّف الارتباطات باستخدام الكلمة المفتاحية `let`. تحديد نوع الارتباط اختياري في معظم الارتباطات، لأن _استنتاج النوع_ في F# يمكنه عادةً استنتاج النوع بناءً على قيمتها. يبدو الارتباط هكذا:

```fsharp
// Automatically inferred type
let fingers = 10
```

الدوال هي أيضًا ارتباطات عادية، لكن مع معامل واحد أو أكثر. تُرجع الدالة تلقائيًا تعبيرها الأخير. يعمل استنتاج النوع أيضًا مع معظم الدوال، من خلال تحليل القيم التي تُستدعى بها الدالة والقيمة التي تُرجعها.

```fsharp
// Automatically inferred types for parameters and return type
let add x y = x + y
```

يتم استدعاء الدالة بتحديد اسمها وتمرير وسائط لكل معامل من معاملات الدالة.

```fsharp
let five = add 2 3
```

إذا تعذّر استنتاج نوع ارتباط، فسيُبلغ المترجم عن خطأ. لإصلاح ذلك، أضف توصيفًا صريحًا للنوع إلى الارتباط.

```fsharp
// Explicit type annotation
let fingers: int = 10

// Explicit type annotation (also for parameters)
let add (x: int) (y: int): int = x + y
```

لا يمكن استخدام الارتباطات في F# إلا _بعد_ تعريفها. استخدام ارتباط قبل تعريفه يؤدي إلى خطأ ترجمة.

```fsharp
// Compile error as the add binding has not yet been defined
// let seven = add 3 4

let add x y = x + y
```

يستخدم F# المسافات البيضاء ذات الدلالة لتعريف النطاق. هذا يعني أن النطاق يُعرّف عبر إزاحة الكود بمسافات، نسبةً إلى السطر الذي يعرّف الارتباط. الاصطلاح الافتراضي هو استخدام أربع مسافات للإزاحة:

```fsharp
let toes =
    let left = 5
    let right = 5
    left + right

let multiplyPlusTwo x y =
    let product = x * y
    product + 2

// Trying to access the left, right or product bindings
// here would result in a compile error
```

عادةً ما تُنظَّم ارتباطات F# (التي تشمل الدوال) في وحدات. تجمع الوحدة وظائف مترابطة وتُعرّف باستخدام الكلمة المفتاحية `module`. يجب أن يسبق تعريف الوحدة ارتباطاتها:

```fsharp
module Calculator

let pi = 3.14

let add x y = x + y
```

يدعم F# نوعين من التعليقات. تسبق التعليقات أحادية السطر `//` وتُدرج التعليقات متعددة الأسطر بين `(*` و `*)`.
