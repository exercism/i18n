# المكرِّرات المخصّصة

```sather
   markers!(once spacing : INT, once count : INT) : INT is
      loop
         yield spacing * 1.upto!(count);
      end;
   end;
```

| | روتين | مكرِّر |
| --- | --- | --- |
| الاسم | `foo` | `foo!` |
| يُسلّم قيمة | `return` | `yield` |
| ينتهي | `return`، أو الوصول إلى النهاية | `quit`، أو نفاد العناصر |
| يمكن استدعاؤه | في أي مكان | فقط داخل `loop` |
| يحافظ على موضعه | لا | نعم |

## yield

يسلّم `yield` قيمة ويُعلّق التنفيذ. ويُستعاد كل شيء عند الدورة التالية: المتغيرات المحلية، والموضع في الحلقات الخاصة بالمكرِّر، ومواضع أي مكرِّرات أخرى يستدعيها هو نفسه.

`yield` داخل حلقات متداخلة يستأنف من الحلقة الأعمق، وهذا ما يجعل كتابة المرور على بنية متداخلة أمرًا مباشرًا:

```sather
   all_cells!(grid : ARRAY{ARRAY{INT}}) : INT is
      loop
         row ::= grid.elt!;
         loop
            yield row.elt!;
         end;
      end;
   end;
```

## quit

ينهي المكرِّر، ومن ثَمّ الحلقة التي تستدعيه. وهو لا يحمل أي قيمة: فـ`quit` ليس نتيجة أخيرة، بل إعلان بأنه لا توجد نتائج.

المكرِّر الذي له نوع إرجاع يجب أن يسلّم قيمة في كل مرة يسلّم فيها؛ و`quit` هو طريقته للامتناع عن ذلك.

## once

```sather
   markers!(once count : INT) : INT is
```

يُقيَّم وسيط `once` عند الدخول إلى الحلقة ويُحتفظ به. أما الوسيط العادي فيُعاد تقييمه في كل دورة، وهذا مهم عندما يحتوي التعبير المُمرَّر على استدعاء مكرِّر آخر:

```sather
   loop
      #OUT + TRAIL::markers!(sizes.elt!);     -- a new count every turn
   end;
```

علّم الوسائط بـ`once` إلا إذا كنت تريد ذلك تحديدًا. المكتبة كلها تفعل ذلك.

## self والمكرِّرات

يمكن استدعاء المكرِّر على كائن، وحينها يكون `self` هو ذلك الكائن. وحالته المعلّقة تنتمي إلى موضع الاستدعاء، لا إلى الكائن، لذا فإن حلقتين تمرّان على الكائن نفسه لا تتعارضان.

## متى تكتب مكرِّرًا

اكتب مكرِّرًا عندما تكون الإجابة عبارة عن متتالية ويجب على المستدعي أن يقرر كم منها سيأخذ. لا يكلّفك التوقف مبكرًا شيئًا، ولا يُبنى شيء لا يُستخدم، بينما الروتين الذي يُرجع `ARRAY` عليه أن يبني الشيء كله أولًا.
