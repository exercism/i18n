# مقدمة

يدعم Haxe الانعكاس في وقت التشغيل للأنواع والحقول. ولاستخدام الانعكاس استخدامًا صحيحًا، من الضروري أن تفهم أنواع العمليات المدعومة وأنواع العمليات غير المدعومة. ونظرًا للطبيعة الديناميكية للانعكاس، لا يمكن تحديد ذلك دائمًا في وقت الترجمة.

تتكوّن واجهة الانعكاس API من صنفين:

- `Reflect`: واجهة خفيفة تعمل بشكل أفضل مع البنى المجهولة، مع دعم محدود للأصناف.
- `Type`: واجهة أكثر متانة للتعامل مع الأصناف والتعدادات.

في المثال التالي، نستخدم هدف JavaScript:

```haxe
class Main {
  public static function main() {
    trace(Type.resolveClass("Main"));
  }
}

// This outputs
// class Test { static main() { console.log("Test.hx:3:",$hxClasses["Test"]); } }
```
