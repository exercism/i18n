# مقدمة

يمثّل Elixir القيمتين صحيح وخطأ بنوع القيمة المنطقية. لا توجد سوى قيمتين: `true` و`false`. ويمكن إسناد هاتين القيمتين إلى متغير:

```elixir
true_variable = true
false_variable = false
```

يمكننا تقييم تعبيرات منطقية صارمة باستخدام العوامل `and/2` و`or/2` و`not/1`.

```elixir
true_variable = true and true
false_variable = true and false

true_variable = false or true
false_variable = false or false

true_variable = not false
false_variable = not true
```

عند كتابة دالة تُرجع قيمة منطقية، من المألوف أن ينتهي اسم الدالة بعلامة `?`. ويمكن تطبيق الاصطلاح نفسه على المتغيرات التي تخزّن قيمًا منطقية.

```elixir
def either_true?(a?, b?) do
  a? or b?
end
```
