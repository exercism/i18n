# التعليمات

في هذا التمرين ستتعامل مع مدخلات السجل.

كل سطر سجل هو سلسلة نصية بتنسيق كالتالي: `"[<LEVEL>]: <MESSAGE>"`.

هناك ثلاثة مستويات مختلفة للسجل:

- `INFO`
- `WARNING`
- `ERROR`

لديك ثلاث مهام، تأخذ كل واحدة منها سطر سجل وتطلب منك فعل شيء به.
هناك طرق كثيرة لحل هذه المهام، اختر تقنياتك المفضلة من الأمثلة السابقة وانظر ما يمكنك التوصل إليه.

## 1. الحصول على الرسالة من سطر السجل

نفّذ الدالة `message` لتُرجع رسالة سطر السجل:

```jq
"[ERROR]: Invalid operation" | message
# => "Invalid operation"
```

يجب إزالة أي مسافات بيضاء في البداية أو النهاية:

```jq
"[WARNING]:  Disk almost full\r\n" | message
# => "Disk almost full"
```

## 2. الحصول على مستوى السجل من سطر السجل

نفّذ الدالة `log_level` لتُرجع مستوى السجل لسطر السجل، ويجب إرجاعه بحروف صغيرة:

```ruby
"[ERROR]: Invalid operation" | log_level
# => "error"
```

## 3. إعادة تنسيق سطر السجل

نفّذ الدالة `reformat` التي تعيد تنسيق سطر السجل، فتضع الرسالة أولًا ويليها مستوى السجل بين الأقواس الهلالية:

```ruby
"[INFO]: Operation completed" | reformat
# => "Operation completed (info)"
```
