# مقدمة

يتيح PHP تعريف الدوال داخل دوال أخرى. لا حاجة إلى تسمية هذه الدوال، لكن يمكن إسنادها إلى متغيرات أو حتى تمريرها مباشرة إلى دالة أخرى تتطلب معاملًا من نوع دالة.

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, function($num) {
        return $num % 2 === 1;
    });
}
```
