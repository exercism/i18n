# التعليمات

تصطف فرقة الرقص في صفوف، وأنت تتابع من يقف أين.

تُوضع المهمات الخمس كلها في الصنف `DANCE_FORMATION`.

## 1. كم عدد أفراد الصف؟

```sather
DANCE_FORMATION::dancer_count(|"Mia", "Ana", "Ben"|)
-- => 3
```

## 2. من يقود؟

القائد هو من يقف أولًا.

```sather
DANCE_FORMATION::leader(|"Mia", "Ana", "Ben"|)
-- => "Mia"
```

## 3. من في المؤخرة؟

من يقف في الخلف هو آخر فرد في الصف، مهما طال الصف.

```sather
DANCE_FORMATION::back_marker(|"Mia", "Ana", "Ben"|)
-- => "Ben"
```

## 4. التشكيل الافتتاحي

تفتتح الفرقة دائمًا بالترتيب نفسه: Mia وAna وBen. أرجِع هذا الصف.

```sather
DANCE_FORMATION::opening_row
-- => an array holding "Mia", "Ana" and "Ben", in that order
```

هذا الإجراء لا يتلقى أي وسائط.

## 5. احسب الخطوات

لكل راقص عدد من الخطوات يجب أن يؤديها. اجمعها.

```sather
DANCE_FORMATION::total_steps(|8, 16, 8|)
-- => 32
```

الصف الفارغ يعني صفر خطوات.
