# المعاملات ذات العدد المتغير

[_المعاملات ذات العدد المتغير_][variadic-parameters] في Swift تسمح بتمرير صفر أو أكثر من القيم من نفس النوع إلى معامل واحد في دالة.
يُشار إلى ذلك بإضافة `...` إلى تحديد النوع الخاص بالمعامل.

سيتم تجميع هذه القيم تلقائيًا في مصفوفة بعناصر من نفس نوع المعامل ذي العدد المتغير.

```swift
func geometricMean(_ numbers: Double...) -> Double {
  var total = 1.0
  for number in numbers {
      total *= number
  }
  return pow(total, 1.0 / Double(numbers.count))
}

geometricMean(1, 2, 3, 4, 5)
// Returns 2.605171084697352
```

عند استخدام المعاملات ذات العدد المتغير، لدى Swift قيدان:

1. تسمح Swift للدوال بامتلاك معامل واحد فقط ذو عدد متغير. لقد تقرر أن هذا القيد سيزال في إصدار مستقبلي من Swift، لكنه لا يزال مطبقًا حاليًا.
2. إذا كانت للدالة معاملات تلي المعامل ذا العدد المتغير في التعريف، فإن أول معامل يلي المعامل ذا العدد المتغير _مطلوب_ أن يكون له تسمية وسيط.
