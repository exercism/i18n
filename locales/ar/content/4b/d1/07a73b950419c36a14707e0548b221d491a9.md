# نبذة

يوفر PHP عددًا من العوامل لإجراء العمليات الحسابية. ويتبع PHP الترتيب الرياضي القياسي للعمليات عند استخدام هذه العوامل. وهذه هي العوامل التي يوفرها PHP:

* عامل الهوية (+)
* عامل النفي (-)
* عامل الجمع (+)
* عامل الطرح (-)
* عامل الضرب (*)
* عامل القسمة (/)
* عامل باقي القسمة (%)
* عامل الأس (**)

لنلقِ نظرة على كل منها وعلى كيفية استخدامه:

## عامل الهوية (+)

يعمل عامل الهوية (+) على قيمة واحدة (عامل أحادي). وهو يُرجع القيمة `float` أو `int` للمتغير.

```php
$value = '42';
$answer = +$value; // 42 (int)
```

## عامل النفي (-)

يعمل عامل النفي على قيمة واحدة (عامل أحادي) ويُرجع عكس القيمة العددية.

```php
$forward = 65;
$reverse = -$forward; // -65
```

## الجمع (+) والطرح (-)

يجمع عامل الجمع القيمتين الواقعتين على جانبيه، أما عامل الطرح فيطرح القيمة اليمنى من القيمة اليسرى.

```php
$apples = 5;
$yourApples = 0;

$apples = $apples - 2; // 3
$yourApples = $yourApples + 2; 2
```

## القسمة (/)

يعطي عامل القسمة ناتج قسمة القيمة اليسرى على القيمة اليمنى. وإذا كانت القيمة اليمنى 0، فسيؤدي ذلك إلى خطأ `DivisionByZeroError`.

```php
$slicesOfPizza = 8;
$people = 4;
$slicesPerPerson = $slicesOfPizza / $people; // 2
```

## الضرب (*)

يُرجع عامل الضرب ناتج ضرب القيمتين اليسرى واليمنى معًا.

```php
$tires = 4;
$priceOfTire = 250;
$totalCost = $tires * $priceOfTire; // 1000
```

## باقي القسمة (%)

يُرجع عامل باقي القسمة الباقي عند قسمة القيمة اليسرى على القيمة اليمنى. وهذا العامل مفيد جدًا لتحديد ما إذا كان عدد يقسم عددًا آخر قسمة تامة، ولتحديد ما إذا كانت قيمة زوجية أم فردية، وفي الكثير غير ذلك.

```php
$value = 3;
$isOdd = $value % 2;
if ($isOdd === 1) {
    echo 'Yes, it is odd!';
} else {
    echo 'It is even.';
}
```

## الأس (**)

يُستخدم عامل الأس لرفع القيمة اليسرى إلى قوة القيمة اليمنى. وقبل PHP 5.6 كنت بحاجة إلى استخدام الدالة `pow` للقيام بالشيء نفسه.

```php
$sideLength = 13;
$areaOfSquare = $sideLength ** 2; // 169
```

يدعم عامل الأس الأعداد الصحيحة والأعداد العشرية على كلا الجانبين، لذا يمكنك استخدامه لحساب الجذور التربيعية (أو الجذور الأخرى) أو قيم أسية أكثر تعقيدًا.

```php
$squareArea = 144;
$side = $squareArea ** .5; // 12
```

## ترتيب العمليات

يتبع PHP الترتيب القياسي للعمليات في الرياضيات. وهذا يعني أنه بدلًا من تنفيذ العمليات من اليسار إلى اليمين، لكل عامل أولوية، وتُنفَّذ العمليات وفقًا لهذه الأولوية. وترتيب العمليات هو:

* الأقواس
* الأس
* الضرب، القسمة
* الجمع، الطرح

الضرب والقسمة لهما المستوى نفسه من الأولوية. وبالمثل، الجمع والطرح لهما المستوى نفسه من الأولوية.

وهذا يعني أن القيمة أدناه ستكون 17 بدلًا من 10، لأن الضرب له أولوية أعلى من الجمع:

```php
$value = 2 + 3 * 5;
```

يوفر PHP أيضًا عددًا من عوامل الإسناد المفيدة التي تجمع بين العوامل الحسابية والإسناد عندما تُجري عملية على متغير وتُسند النتيجة إليه مرة أخرى. وسنغطي هذه العوامل في مفهوم `Assignment Operators`.
