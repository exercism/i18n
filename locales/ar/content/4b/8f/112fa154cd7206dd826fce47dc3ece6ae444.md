# نبذة

تُعرف هياكل البيانات التي يمكنها أن تحمل صفرًا أو أكثر من العناصر باسم _المجموعات_.
**المصفوفة** في Ruby هي مجموعة تحافظ على الترتيب الذي تُضاف به كائناتها.
يمكن للمصفوفة أن تحمل أي كائن.
يمكن إضافة الكائنات إلى المصفوفة أو استرجاعها منها باستخدام فهرس.
فهرسة المصفوفات في Ruby تبدأ من الصفر، أي أن فهرس العنصر الأول هو صفر دائمًا:

```ruby
# Declare an array containing two values
two_ints = [1,2]

# Assign first and second element by index
two_ints[0] = 7
two_ints[1] = 8

# Retrieve the second element by index
two_ints[1] # => 8

# Check the length of the array
two_ints.size # => 2
```

في Ruby توجد عدة أساليب لإنشاء مصفوفة:

- استخدام المُنشئ الحرفي `[]` _(الأكثر شيوعًا)_
- استدعاء `Array.new` صراحةً
- استدعاء طريقة `Array()` في Kernel

تدعم طريقة `Array.new` وسيطين اختياريين: الحجم الأولي للمصفوفة، وكائنًا افتراضيًا.

عند تمرير حجم وكائن افتراضي، تُملأ المصفوفة بعدد `size` من نسخ الكائن الافتراضي.

```ruby
a = Array.new(2, Hash.new)
# => [{}, {}]
```

ولأن جميع عناصر المصفوفة تخزّن نفس الـ hash، فإن التغيير في أحدها سيؤثر عليها جميعًا.

```ruby
a[0]['cat'] = 'feline'
a # => [{"cat"=>"feline"}, {"cat"=>"feline"}]

a[1]['cat'] = 'Felix'
a # => [{"cat"=>"Felix"}, {"cat"=>"Felix"}]
```

إذا أردت نسخًا متعددة، فعليك استخدام صيغة الكتلة، وهي تستخدم ناتج تلك الكتلة في كل مرة يحتاج فيها أحد عناصر المصفوفة إلى تهيئة:

```ruby
a = Array.new(2) {Hash.new}
a[0]['cat'] = 'feline'
a # => [{"cat"=>"feline"}, {}]
```

من الخصائص الأخرى لمصفوفات Ruby أنها تدمج وحدة [Enumerable][enumerable-module]، التي تضيف الكثير من الطرق المفيدة لتكرار عناصر المصفوفة والبحث فيها وترتيبها وتصفيتها وما إلى ذلك.
