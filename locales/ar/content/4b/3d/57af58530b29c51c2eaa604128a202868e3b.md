# التعليمات

ستُهيّئ مخازن مؤقتة فارغة وتسرد أول خمسة أعداد، أو عناصر، من متتالية فيبوناتشي.

متتالية فيبوناتشي مجموعة من الأعداد يكون فيها العنصر التالي مجموع العنصرين السابقين. نبدأ المتتالية من واحد. إذن أول عنصرين هما 1 و1.

## 1. أنشئ مخزنًا مؤقتًا يحتوي على `count` من الأصفار.

أنشئ دالة تُنشئ مخزنًا مؤقتًا يحتوي على `count` من الأصفار.

```rust
let my_buffer = create_buffer(5);
// [0, 0, 0, 0, 0]
```

## 2. اسرد أول خمسة عناصر من متتالية فيبوناتشي

أنشئ دالة تُرجع أول خمسة أعداد من متتالية فيبوناتشي.
أول خمسة عناصر فيها هي `1, 1, 2, 3, 5`

```rust
let first_five = fibonacci();
// [1, 1, 2, 3, 5]
```
