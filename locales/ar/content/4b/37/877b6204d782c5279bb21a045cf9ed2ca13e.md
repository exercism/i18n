# مقدمة

## القيم المنطقية في Julia

تُمثَّل القيم التي تكون إما صحيح أو خطأ بنوع `Bool`.
وهو يحتوي على قيمتين فقط: `true` و `false`.

```julia-repl
julia> true
true

julia> false
false
```

## العوامل المنطقية

توجد ثلاثة عوامل منطقية في Julia.

`&&` هو العامل المنطقي «و».
وتكون قيمته `true` إذا كان التعبيران على *كلا* جانبي `&&` يساويان `true`.

```julia-repl
julia> true && true
true

julia> true && false
false
```

`||` هو العامل المنطقي «أو».
وتكون قيمته `true` إذا كان أحد التعبيرين على *أحد* جانبي `||` يساوي `true`.

```julia-repl
julia> true || true
true

julia> false || true
true
```

`!` هو العامل المنطقي «ليس».
وهو يبدّل القيمتين `true` و `false`.

```julia-repl
julia> !true
false

julia> !false
true
```

للتعبيرات الأطول والأكثر تعقيدًا، من الأفضل استخدام الأقواس الهلالية لتوضيح قصدك.

```julia-repl
julia> (true || false) && (false && true)
false
```
