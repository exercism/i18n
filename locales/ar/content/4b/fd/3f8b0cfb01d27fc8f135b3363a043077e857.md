# مقدمة

## صحيح وخطأ

تُمثَّل الحالتان المنطقيتان صحيح وخطأ بالقيمتين `true` و`false` في Ruby.

```ruby
happy = true
sad = false
```

## المساواة والمقارنة

تتيح لك Ruby مقارنة الكائنات بعضها ببعض باستخدام رموز المساواة والمقارنة المعتادة:
- استخدم `==` لمعرفة ما إذا كان الكائنان متساويين
- استخدم `>` لمعرفة ما إذا كان الكائن على اليسار **أكبر من** الكائن على اليمين
- استخدم `<` لمعرفة ما إذا كان الكائن على اليسار **أصغر من** الكائن على اليمين.
- استخدم `>=` أو `<=` للتحقق من «أكبر من أو يساوي» و«أصغر من أو يساوي» على الترتيب.

يمكنك أيضًا استخدام العمليات المنطقية مع العوامل المعتادة:
- استخدم `&&` أو `and` للتحقق مما إذا كان `x and y` صحيحًا
- استخدم `||` أو `or` للتحقق مما إذا كان `x or y` صحيحًا.
- استخدم `!` أو `not` لعكس نتيجة المساواة، مثل `x != y` (أي أن `x` لا يساوي `y`)

إليك بعض الأمثلة:
```ruby
# Is "true equal to false"? 
true == false # false

# Is "true not equal to false"
true != false # true

# Is 5 greater than 4?
5 > 4 # true

# Is 3 less than or equal to 2?
3 <= 2 # false
```
