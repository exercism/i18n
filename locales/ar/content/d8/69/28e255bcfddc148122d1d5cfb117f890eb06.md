# التعليمات

أنت تتنزّه سيرًا على الأقدام في نيوزيلندا وتأخذ اتجاهاتك من بوصلة. الاتجاه عدد صحيح من الدرجات، وهو قيمة: فالدوران بمقدار 20 درجة لا يغيّر الاتجاه الذي أخذته، بل يعطيك اتجاهًا آخر.

اكتب `immutable class BEARING`. يمنحك الكود الأولي ترويسة الصنف وسمته.

## 1. أخذ اتجاه

تأخذ `create` عددًا من الدرجات وتُعطي اتجاهًا. تمتد الدرجات من 0 إلى 359، لذا فإن أي عدد خارج هذا النطاق يلتف ويعود من جديد: العدد 370 يعني 10، والعدد -10 يعني 350.

```sather
#BEARING(370).degrees
-- => 10
#BEARING(-10).degrees
-- => 350
```

## 2. الدوران

تأخذ `turned` عددًا من الدرجات لتدور بها وتُرجع الاتجاه الجديد. والدوران بعدد سالب يدور في الاتجاه المعاكس. أما الاتجاه الذي استُدعيت عليه فيبقى دون تغيير.

```sather
#BEARING(350).turned(20).degrees
-- => 10
```

## 3. المقارنة

تأخذ `is_eq` اتجاهًا آخر وتُرجع ما إذا كانا متماثلين. وبمجرد أن توجد، يعمل `=` على الاتجاهات.

```sather
#BEARING(10) = #BEARING(370)
-- => true
```

## 4. تسمية النقطة

تُرجع `point` نقطة البوصلة الأقرب إلى الاتجاه، وتكون واحدة من `"N"`، `"NE"`، `"E"`، `"SE"`، `"S"`، `"SW"`، `"W"`، `"NW"`.

تغطي كل نقطة 45 درجة، وتتمركز حول اتجاهها الدقيق: فالشمال يمتد من 337.5 مرورًا بـ 0 إلى 22.5، والشمال الشرقي من 22.5 إلى 67.5، وهكذا. ولأن الاتجاهات هنا أعداد صحيحة، فإن الاتجاه 22 هو `"N"` والاتجاه 23 هو `"NE"`.

```sather
#BEARING(0).point
-- => "N"
#BEARING(90).point
-- => "E"
#BEARING(225).point
-- => "SW"
```

## 5. كتابته

تُرجع `str` الدرجات والنقطة، مثل `"90 degrees (E)"`.

```sather
#BEARING(90).str
-- => "90 degrees (E)"
```
