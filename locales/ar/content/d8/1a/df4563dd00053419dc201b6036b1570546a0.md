# مقدمة

توفّر Common lisp عدة تعبيرات شرطية مختلفة، والفرق الرئيسي بينها هو عدد الفروع التي تدعمها.

- تسمح كل من `when` و `unless` بفرع واحد:

```lisp
(when (= 2 2) "All is well")      ; => "All is well"
(unless (= 2 2) "Time to panic!") ; => NIL
```

قد يحتوي الجزء الذي يلي تعبير الاختبار على أكثر من تعبير واحد.

- توفّر `if` البنية الكلاسيكية if-then-else:

```lisp
(if (= 2 2) 'how-honest 'you-liar) ; => HOW-HONEST
```

لاحظ أن جملتي then و else يمكن أن تكونا تعبيرًا واحدًا فقط.

- توفّر `cond` أسلوبًا للحصول على فروع متعددة دون تداخل تعبيرات `if`:

```lisp
(cond ((= 0 2) 'nope)
      ((= 1 2) 'try-again)
      ((= 2 2) 'quite-true)
      ((= 3 2) 'too-far)
      (t 'something-else))
; => QUITE-TRUE
```

لاحظ أنه لا يوجد حد لعدد التعبيرات التي تلي تعبير الاختبار.

- توفّر `case` بنية كلاسيكية بنمط «switch»: فهي تفحص قيمة واحدة مقابل عدد من الفروع:

```lisp
(case 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark")
  (otherwise "???"))
; => "???"
```

لاحظ أنه كما في `cond`، لا يوجد حد لعدد التعبيرات التي تلي تعبير الاختبار.
