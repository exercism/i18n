# التعليمات

في هذا التمرين، ستلعب لعبة تقمّص أدوار يمكن فيها لأنواع مختلفة من المقاتلين أن تتقاتل فيما بينها.
لكل نوع من المقاتلين قواعد مختلفة في اللعبة.
سنركّز على نوعين محددين: `Wizard` و`Warrior`.

بالنسبة إلى `Warrior`، هذه هي القواعد:

- لا يكون `Warrior` معرّضًا للضرر أبدًا.
- يُلحق `Warrior` `6` نقاط ضرر إذا لم يكن المقاتل الذي يهاجمه معرّضًا للضرر.
- يُلحق `Warrior` `10` نقاط ضرر إذا كان المقاتل الذي يهاجمه معرّضًا للضرر.

بالنسبة إلى `Wizard`، هذه هي القواعد:

- يستطيع `Wizard` تحضير تعويذة مسبقًا.
- يكون `Wizard` معرّضًا للضرر ما لم يحضّر تعويذة مسبقًا.
- يُلحق `Wizard` `12` نقطة ضرر إذا حضّر تعويذة مسبقًا.
- يُلحق `Wizard` `3` نقاط ضرر إذا لم يحضّر تعويذة مسبقًا.

## 1. إنشاء صنف `Warrior`

أنشئ صنفًا جديدًا باسم `Warrior`.
ينبغي أن يرث هذا الصنف من صنف `Fighter` الموجود.

## 2. وصف `Warrior`

حدّث صنف `Warrior` بحيث تصف طريقة `toString()` نوع المقاتل الذي يمثله.
ينبغي أن تُرجع الطريقة السلسلة النصية `"Fighter is a Warrior"`.

```java
Warrior warrior = new Warrior();
warrior.toString();
// => "Fighter is a Warrior"
```

## 3. جعل `Warrior` غير معرّض للضرر

حدّث صنف `Warrior` بحيث تُرجع طريقة `isVulnerable()` القيمة `false` دائمًا.

```java
Warrior warrior = new Warrior();
warrior.isVulnerable();
// => false
```

## 4. حساب نقاط الضرر التي يُلحقها `Warrior`

حدّث صنف `Warrior` بحيث تحسب طريقة `getDamagePoints(Fighter)` الضرر الذي يُلحقه `Warrior` وفقًا للقواعد أعلاه.

```java
Warrior warrior = new Warrior();
Wizard wizard = new Wizard();

warrior.getDamagePoints(wizard);
// => 10
```

## 5. إنشاء صنف `Wizard`

أنشئ صنفًا جديدًا آخر باسم `Wizard`.
ينبغي أن يرث هذا الصنف أيضًا من صنف `Fighter` الموجود.

## 6. وصف `Wizard`

حدّث صنف `Wizard` بحيث تصف طريقة `toString()` نوع المقاتل الذي يمثله.
ينبغي أن تُرجع الطريقة السلسلة النصية `"Fighter is a Wizard"`.

```java
Wizard wizard = new Wizard();
wizard.toString();
// => "Fighter is a Wizard"
```

## 7. السماح لـ `Wizard` بتحضير تعويذة وجعله معرّضًا للضرر عند عدم تحضير تعويذة

حدّث صنف `Wizard` لإضافة طريقة باسم `prepareSpell()`.
ينبغي أن يتذكر الصنف وقت استدعاء هذه الطريقة، وأن يحرص على ألا تُرجع طريقة `isVulnerable()` القيمة `false` إلا عند تحضير تعويذة.

```java
Wizard wizard = new Wizard();
wizard.prepareSpell();
wizard.isVulnerable();
// => false
```

## 8. حساب نقاط الضرر التي يُلحقها `Wizard`

حدّث صنف `Wizard` بحيث تحسب طريقة `getDamagePoints(Fighter)` الضرر الذي يُلحقه `Wizard` وفقًا للقواعد أعلاه.

```java
Wizard wizard = new Wizard();
Warrior warrior = new Warrior();

wizard.prepareSpell();
wizard.getDamagePoints(warrior);
// => 12
```
