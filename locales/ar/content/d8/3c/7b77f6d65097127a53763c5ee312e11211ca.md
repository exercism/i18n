# مقدمة

## التعليقات

يتيح Common Lisp للمبرمج أن يكتب «تعليقات» يتجاهلها الحاسوب.
تبدأ التعليقات أحادية السطر بفاصلة منقوطة واحدة أو أكثر (`;`)، وقد ترى أحيانًا ما يلي:

```lisp
(code...) ; => value
```

حيث يُستخدم التعليق هنا لبيان القيمة التي يُرجعها Common Lisp بعد تنفيذ الكود في ذلك السطر.

من الأسلوب المألوف أن تستخدم فاصلة منقوطة واحدة لتعليق قصير في نهاية السطر، واثنتين لتعليق أطول فوق قسم من الكود، وثلاثًا لتعليق طويل يصف شيئًا مثل دالة، وأربعًا لتعليق مثل ترويسة في أعلى ملف المصدر.

## أزواج cons

كل كائنات Common Lisp إما «ذرات» (قيم مفردة غير قابلة للتجزئة) وإما «أزواج cons» (تُبنى بالدالة البنائية `cons`).
يتكوّن زوج cons من جزأين: العنصر الأول وبقية العناصر.
ولأسباب تاريخية يُسمّى هذان الجزآن `car` و`cdr`.
وعندما تُقيَّم هذه الأزواج ككود، يمثّل العنصر الأول (`car`) الدالة التي تُستدعى، بينما تمثّل بقية العناصر (`cdr`) الوسائط التي تُمرَّر إلى تلك الدالة:

```lisp
(<function> <arg1> <arg2> ... <argN>)
; ^ car ^  |        ^ cdr ^
```

## التعبيرات

كل كود Common Lisp مكوّن من تعبيرات S (S-Expressions، التعبيرات الرمزية). وتُختصر تسميتها إلى sexprs. وكل sexpr إما ذرة وإما زوج cons. وعند تقييم تعبيرات S، فإنها تُرجع تلقائيًا قيمةً ما تحلّ محلّ التعبير. وعند كتابة دوالك الخاصة (باستخدام `defun`)، تُرجع تلقائيًا القيمة الأخيرة داخل جسم `defun`:

```lisp
;; Defining a new function
(defun gimme-foo () 'foo)
;; Calling the function as an S-Expression
(gimme-foo) ; => FOO
```

## الرموز

الرموز في Common Lisp قيم خاصة يمكنها أن تشير إلى قيم أخرى، أو إلى نفسها في حالة _الكلمات المفتاحية_.
وعندما يقيّم Lisp الرموز، تُستبدل بالقيم التي تشير إليها:

```lisp
foo  ; => <whatever-foo-points-to>
:foo ; => :FOO
```

لاحظ أن الكلمات المفتاحية تُكتب بنقطتين (`:`) في البداية.

الاقتباس، أي إضافة `'` قبل تعبير S، يخبر Lisp بألّا يقيّم ذلك التعبير.
باقتباس `'foo` في مثال `defun`، منعنا Lisp من أن يحاول البحث عن ما يُفترض أن يشير إليه `FOO` (وأن يفشل في العثور عليه)، بحيث يُرجع التعبير بدلًا من ذلك القيمة `FOO` نفسها.
وإذا لم يكن `FOO` معرَّفًا في أي مكان في برنامجنا:

```lisp
foo  ; => <ERROR! Lisp doesn't know what foo points to!>
'foo ; => FOO
```

في الوقت الحالي، يمكنك اعتبار هذا مجرد وسيلة لإرجاع الرموز من دالة، لكننا سنعود إلى الاقتباس ونستكشف آثاره أكثر في تمارين المفاهيم القادمة.
