# حول

تُستخدم [الحرّاس][guards] كمكمّل لـ[مطابقة الأنماط][exercism-pattern-matching]. وهي تتيح فحوصات أكثر تعقيدًا. ويمكن استخدامها في [بعض الحالات التي يمكن فيها استخدام مطابقة الأنماط، وليس كلها][where-guards-can-be-used]، مثل بنود الدالة أو بنود `case`.

```elixir
def empty?(list) when is_list(list) and length(list) == 0 do
  true
end
```

- تبدأ الحرّاس بالكلمة المفتاحية `when`، ويتبعها تعبير منطقي.
- تعبيرات الحرّاس دوال خاصة:
  - يجب أن تكون [نقية][pure-function] وألّا تغيّر أي حالة عامة.
  - يجب أن تُرجع قيم `true` أو `false` الصارمة.
- تجد قائمة بالحرّاس الشائعة في [توثيق Elixir][kernel-guards]. وهي تشمل:
  - التحقق من الأنواع: [`is_integer/1`][guard-is-integer]، و[`is_list/1`][guard-is-list]، و[`is_nil/1`][guard-is-nil] إلخ.
  - عوامل حسابية: [`+/2`][guard-plus]، و[`-/2`][guard-minus] إلخ.
  - عوامل المقارنة: [`==/2`][guard-equals]، و[`>/2`][guard-greater]، و[`</2`][guard-less] إلخ.
  - عوامل منطقية: [`and/2`][guard-and]، و[`or/2`][guard-or]، و[`not/1`][guard-not]
  - عامل الانتماء: [`in/2`][guard-in]
- يمكنك تعريف الحرّاس الخاص بك باستخدام [`defguard`][defguard].

  - وفقًا [لاصطلاحات التسمية][naming] في Elixir، يجب أن تبدأ أسماء الحرّاس بـ `is_`.

    ```elixir
    defmodule HTTP do
      defguard is_success(code) when code >= 200 and code < 300

      def handle_response(code) when is_success(code) do
        :ok
      end
    end
    ```
