# ملحق التعليمات

## السجلات

| السجل | الاستخدام | النوع | الوصف |
| -------- | ------------ | ------- | --------------------------------------- |
| `$a0`    | إدخال        | عنوان | سلسلة نصية للإدخال منتهية بمحرف صفري |
| `$a1`    | إدخال/إخراج | عنوان | مصفوفة كلمات تحتوي على أعداد النيوكليوتيدات النهائية |
| `$t0-9`  | مؤقت    | أي | للتخزين المؤقت |
