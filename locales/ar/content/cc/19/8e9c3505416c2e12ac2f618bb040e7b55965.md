# التعليمات

في هذا التمرين ستعمل على بعض الدوال لإدارة المواعيد.
يخزّن النظام كل شيء في سلاسل نصية بتنسيق ISO 8601، لكن هذه ليست الطريقة التي يستخدم بها الناس التقويم.
نحتاج إلى دوال متعددة للتحويل بين التنسيقات المختلفة.

## 1. أنشئ موعدًا

أنشئ موعدًا بعد `n` يومًا من الآن في الوقت الحالي.
الدالة تأخذ عدد الأيام `n` وتُرجع وقت الموعد بعد `n` يومًا من الآن.

```javascript
createAppointment(4, now);
// Given now is Sun Oct 05 2022 23:28:43 GMT+0600 (Bangladesh Standard Time)
// => Sun Oct 09 2022 23:28:43 GMT+0600 (Bangladesh Standard Time)
```

إذا لم يُستخدم المعامل الثاني `now`، فينبغي استخدام الوقت الحالي بدلًا منه.

## 2. حوّل تاريخًا إلى طابع زمني

أدوات متعددة لا تعمل إلا بالتنسيق القياسي الدولي ISO 8601.
اكتب الدالة `getAppointmentTimestamp` لتأخذ تاريخًا وتُرجع سلسلة نصية بهذا التنسيق.

```javascript
const appointment = new Date(Date.UTC(2010, 6, 16, 12, 42, 0, 0));

getAppointmentTimestamp(appointment);
// => '2010-07-16T12:42:00.000Z'
```

## 3. احصل على تفاصيل موعد

يصعب قراءة الطوابع الزمنية، ولذلك ستساعد دالة للحصول على تفاصيل الموعد في ذلك.
الدالة `getAppointmentDetails` تأخذ طابعًا زمنيًا بتنسيق ISO 8601، وتُرجع السنة والشهر واليوم والساعة والدقيقة.

```javascript
getAppointmentDetails('2022-04-24T08:15:00.000');
// => { year: 2022, month: 3, date: 24, hour: 8, minute: 15 }
```

## 4. حدّث موعدًا بالخيارات المعطاة

الدالة تستقبل الوسيط الأول وقت الموعد، والوسيط الثاني كائنًا يحمل بعض الخيارات.
عليك تحديث الموعد وفقًا للخيارات الموجودة في الكائن، وإرجاع تاريخ الموعد الجديد.
قد يحتوي كائن الخيارات على خيارات متعددة.

```javascript
updateAppointment('2022-02-09T09:20:00.000', { month: 6 });
// => { year: 2022, month: 6, date: 9, hour: 10, minute: 20 }
```

## 5. احصل على الوقت المتاح بين موعدين

الدالة تستقبل موعدين (طابعين زمنيين) كوسائط.
عليك إرجاع الفرق بين هذين الوقتين بالثواني.

ولأن نصف ثانية لا يعني شيئًا تقريبًا، قرّب العدد قبل إرجاعه.

```javascript
timeBetween('2022-12-12T09:20:00.000', '2022-12-18T08:30:00.000');
// => 515400
```

## 6. تحقق مما إذا كان الموعد صالحًا الآن أم لا

أخيرًا، عندما يُحدَّد الموعد، يحتاج النظام إلى التحقق مما إذا كان صالحًا.
بعبارة أخرى، يجب أن يكون الموعد في المستقبل، لا في الماضي.

اكتب الدالة `isValid` التي تأخذ وسيطين: طابعًا زمنيًا للموعد (سلسلة نصية)، والوقت الحالي كطابع زمني (سلسلة نصية)، وتُرجع `true` إذا كان الموعد في المستقبل بالنظر إلى الوقت الحالي.

```javascript
isValid('2022-02-11T23:00:00.000', '2022-02-08T23:00:00.000');
// => true
```
