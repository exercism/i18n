# نبذة

تُمثَّل القيم المنطقية في C++ بالنوع `bool`.
ويكون `bool` إما `true` أو `false`.

## العوامل المنطقية

تدعم C++ ثلاثة عوامل منطقية: `!` (النفي)، و`&&` (العطف)، و`||` (الفصل).
ويمكنك أيضًا استخدام الصيغ البديلة `not` و`and` و`or`.

```cpp
true || false // => true
true && false // => false
!true // => false
not false // => true
```

## الأسبقية

تختلف _أسبقية العوامل_ بين العوامل المنطقية الثلاثة.
وبناءً على ذلك، تُقيَّم بهذا الترتيب: `!` أولًا، ثم `&&`، وأخيرًا `||`.
وإذا أردت فرض ترتيب مختلف، يمكنك وضع تعبير منطقي بين الأقواس الهلالية (أي `()`)، إذ تتمتع الأقواس الهلالية بأسبقية عوامل أعلى.

```cpp
!true && false   // => false
!(true and false) // => true
```

## التحويل

إذا استخدمت `true` أو `false` في موضع يُتوقع فيه عدد، فسيُحوَّل كلٌّ منهما إلى `1` و`0` على الترتيب.
وإذا استخدمت عددًا في عملية منطقية، فسيُعامَل كل شيء عدا `0` على أنه `true`، حتى القيم السالبة.

```cpp
!true && 0.0   // => false
true + true + false // => 2
```
