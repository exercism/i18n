# نبذة

عند العمل مع المصفوفات، قد ترغب أحيانًا في تنفيذ كود لكل قيمة في المصفوفة.
ويُسمى ذلك التكرار على المصفوفة أو المرور عليها بحلقة.

سننظر هنا في الحالة التي لا ترغب فيها في تعديل المصفوفة أثناء ذلك.
أما لتحويل المصفوفات، فراجع [مفهوم تحويلات المصفوفة][concept-array-transformations] بدلًا من ذلك.

## حلقة `for`

أبسط طريقة للتكرار على مصفوفة، وهي عادةً سريعة جدًا، هي استخدام حلقة `for`، راجع [مفهوم حلقات `for`][concept-for-loops].

```javascript
const numbers = [6.0221515, 10, 23];

for (let i = 0; i < numbers.length; i++) {
  console.log(numbers[i]);
}
// => 6.0221515
// => 10
// => 23
```

## حلقة `for...of`

عندما تريد التعامل مع القيمة مباشرة في كل تكرار ولا تحتاج إلى الفهرس إطلاقًا، يمكنك استخدام حلقة `for...of`.

تعمل حلقة `for...of` مثل حلقة `for` الأساسية الموضحة أعلاه، لكن بدلًا من أن تتعامل مع _الفهرس_ كمتغير في الحلقة، تُمنح _القيمة_ مباشرة.

```javascript
const numbers = [6.0221515, 10, 23];

// Because re-assigning number inside the loop will be very
// confusing, disallowing that via const is preferable.
for (const number of numbers) {
  console.log(number);
}
// => 6.0221515
// => 10
// => 23
```

تمامًا كما في حلقات `for` العادية، يمكنك استخدام `continue` لإيقاف التكرار الحالي و`break` لإيقاف تنفيذ الحلقة بالكامل.

تحتوي JavaScript أيضًا على حلقة `for...in` للتكرار على المفاتيح في كائن.
ومن المهم ملاحظة أن `for...of` و`for...in` ليسا قابلين للتبادل، راجع [توثيق MDN][mdn-for-in-for-of] للحصول على تفاصيل حول ذلك.

## طريقة `forEach`

تتضمن كل مصفوفة طريقة `forEach` يمكن استخدامها أيضًا للمرور على العناصر في المصفوفة.

تقبل `forEach` [دالة رد الاتصال][concept-callbacks] كمعامل.
وتُستدعى دالة رد الاتصال مرة واحدة لكل عنصر في المصفوفة.

```javascript
const numbers = [6.0221515, 10, 23];

numbers.forEach((number) => console.log(number));
// => 6.0221515
// => 10
// => 23
```

في المثال أعلاه، تستخدم دالة رد الاتصال العنصر الحالي فقط كمعامل.
وعند الحاجة، يمكن لدالة رد الاتصال أن تستخدم ما يصل إلى ثلاثة معاملات.

- _القيمة_ الخاصة بالتكرار الحالي
- _الفهرس_ الخاص بالتكرار الحالي
- _المصفوفة_ كاملة

```javascript
const numbers = [6.0221515, 10, 23];

function callback(number, index, fullArray) {
  console.log(number, index, fullArray);
}

numbers.forEach(callback);
// => 6.0221515 0 [ 6.0221515, 10, 23 ]
// => 10 1 [ 6.0221515, 10, 23 ]
// => 23 2 [ 6.0221515, 10, 23 ]
```

إلى جانب دالة رد الاتصال، تقبل `forEach` سياق `this` الذي يُستخدم في التكرار كمعامل ثانٍ اختياري.
يمكنك رؤية مثال في [قسم «استخدام thisArg» على MDN][mdn-foreach-thisarg].

هناك بضعة أمور يجب أن تضعها في الاعتبار عند العمل مع `forEach`.

- لا توجد طريقة لإيقاف التكرار بعد أن تبدأ حلقة `forEach`.
  فلا وجود لعبارتي `break` و`continue` في هذا السياق.
- تتصرف `forEach` بغرابة إذا عدّلت المصفوفة بعد بدء الحلقة.
  فالعناصر التي تضيفها في النهاية ستُتجاهل، وقد يؤدي حذف عناصر إلى تخطّي عناصر أخرى، وهكذا.
  ولتجنّب هذه المشكلات، لا تعدّل المصفوفة الأساسية أبدًا داخل دالة رد الاتصال.
- قيمة الإرجاع من طريقة `forEach` نفسها هي `undefined`.
  ولهذا السبب، لا يمكنك تسلسل أي طرق أخرى للمصفوفات في النهاية.
- إذا كنت بحاجة إلى تحسين الكود من حيث الأداء، فيُفضّل أن تفكر في استخدام `for` أو `for...of` بدلًا منها، إذ إن كلتيهما أسرع بنحو ثلاث مرات.
