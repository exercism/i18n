# مقدمة

قد يكون التعامل مع البيانات الثنائية أمرًا صعبًا، لذا توفّر Gleam نوع `BitArray` وصيغة مرافقة له لبناء البيانات الثنائية ومطابقتها مع الأنماط.

تُعرَّف القيم الحرفية لمصفوفات البتات باستخدام الصيغة `<<>>`. وعند تعريف قيمة حرفية لمصفوفة بتات، فإنها تُعرَّف على شكل مقاطع. لكل مقطع قيمة ووسم توضيحي يفصل بينهما `:`. يحدّد الوسم التوضيحي عدد البتات المستخدمة لترميز القيمة، ويمكن حذفه كليًا، وعندها تكون القيمة الافتراضية عددًا صحيحًا من 8 بتات.

```gleam
// This defines a bit array with three segments of a single bit each
<<0:1, 1:1, 0:1>>

// This defines a bit array with three segments of 8 bits each
<<0, 1, 0>>
```

كتابة النوع بالصيغة `:1` هي اختصار لكتابة `:size(1)`. وعليك استخدام الصيغة الأطول إذا كان حجم البتات قادمًا من متغير.

```gleam
let segment_size = 1
<<0:size(segment_size), 1:size(segment_size), 0:size(segment_size)>>
```

## النظام الثنائي

عند كتابة القيم الحرفية للأعداد الصحيحة الثنائية، يمكننا كتابتها مباشرة بترميز الأساس 2 بإضافة البادئة `0b` إلى القيمة الحرفية. لاحظ أنها ستُعرض كأعداد عشرية عند طباعتها في الاختبارات أو في برنامجك.

```gleam
<<0b1011:4>> == <<11:4>>
// -> True
```

## الاقتطاع

إذا تجاوزت قيمة المقطع سعة نوع المقطع، فسيُقتطع من اليسار.

```gleam
<<0b1011:3>> == <<0b0011:3>>
// -> True
```

## الإضافة في البداية والإضافة في النهاية

يمكنك الإضافة في بداية مصفوفة بتات موجودة وفي نهايتها معًا باستخدام صيغة مصفوفة البتات. ويجب استخدام وسم `:bits` لمصفوفة البتات الموجودة.

```gleam
let value = <<0b110:3, 0b001:3>>
let new_value = <<0b011:3, value:bits, 0b000:3>>
// -> <<120, 8:size(4)>>
```

## الدمج

يمكننا دمج مصفوفات البتات المخزّنة في متغيرات باستخدام الصيغة. ويجب استخدام وسم `:bits` عند دمج مصفوفتَي بتات بحجمين متغيرين.

```gleam
let first = <<0b110:3>>
let second = <<0b001:3>>
let concatenated = <<first:bits, second:bits>>
// -> <<49:size(6)>>
```

## مطابقة الأنماط

يمكن أيضًا إجراء مطابقة الأنماط للحصول على قيم من مصفوفة البتات. وعليك معرفة عدد البتات في كل جزء تريد التقاطه، باستثناء واحد: يمكن استخدام وسم `:bits` لمطابقة الأنماط على مصفوفة بتات ذات حجم غير معروف، لكن هذا لا يُستخدم إلا مع الجزء الأخير.

```gleam
let assert <<value:4, rest:bits>> = <<0b01101001:8>>
value == 0b0110
// -> true
```

## فحص مصفوفات البتات

~~~~exercism/note
قد تُطبع مصفوفات البتات بتنسيق مختلف عن التنسيق الذي أُنشئت به. وكثيرًا ما يسبّب هذا ارتباكًا عند تعلّم مصفوفات البتات.
~~~~

افتراضيًا، تُعرض مصفوفات البتات على شكل أجزاء من 8 بتات (بايت)، حتى لو أنشأتها بأجزاء بحجم مختلف.

```gleam
<<2011:11>>
// -> <<251, 3:size(3)>>
```

إذا أنشأت مصفوفة بتات تمثّل سلسلة نصية قابلة للطباعة مرمّزة بترميز UTF-8، فقد تعرضها دوال مثل `io.debug` على شكل سلسلة نصية. ويعود ذلك إلى تفصيل في طريقة تمثيل Gleam للسلاسل النصية داخليًا.

```gleam
<<>>
// -> ""

<<65, 66, 67>>
// -> "ABC"
```
