# مفاهيم أعداد أرمسترونغ

> [عدد أرمسترونغ](https://en.wikipedia.org/wiki/Narcissistic_number) هو عدد يساوي مجموع أرقامه، حيث يُرفع كل رقم منها إلى قوة تساوي عدد الأرقام.

## حل نموذجي

```rust
pub fn is_armstrong_number(num: u32) -> bool {
    let digits = format!("{}", num);
    digits
        .chars()
        .map(|c| c.to_digit(10).unwrap().pow(digits.len() as u32))
        .sum::<u32>()
    == num
}
```

## المفاهيم

- الدوال: أساسية للتحقق من الحل وتحديد المنطق
- مجموعات الاختبارات: لازمة للتحقق من الحل
- الأعداد الصحيحة: `u32` للوسيط وتأكيدات التطابق
- `&str`: لازمة لحساب طول العدد لأن Rust لغة ذات أنواع صارمة
- `Option<T>`: لازمة للوصول إلى القيمة الفعلية الناتجة عن `char::to_digit`
- تحويل الأنواع: مطلوب لتطبيق العمليات الحسابية
- ميزات المكرِّر:
  - turbofish لتمكين حل بتعبير واحد
  - `map` و`sum` لاختزال التعبير بسهولة إلى ما نحتاج إلى تأكيده
