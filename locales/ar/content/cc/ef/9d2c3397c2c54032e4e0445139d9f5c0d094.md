# مقدمة

PowerShell لغة برمجة نصية دينامية ذات أنواع ضمنية (وتدعم كذلك المتغيرات قوية الأنواع)، طوّرتها Microsoft، وتركيزها الأساسي على أتمتة المهام وإدارة الإعدادات.

تدعم PowerShell البرمجة الأمرية والوظيفية والكائنية التوجه، وحتى الأسلوب القائم على خط الأنابيب.

بُنيت PowerShell على منصة .NET وصدرت لأول مرة في عام 2006.
وهي مضمنة افتراضيًا في جميع إصدارات Windows الحديثة، ويمكن تثبيتها على Mac و Linux.


## المتغيرات

هناك أسلوبان شائعان لتعريف متغير في PowerShell.

يجب أن يبدأ اسم المتغير في PowerShell بالرمز `$`، ويُستخدم عامل الإسناد `=` لربط اسم المتغير بقيمة.

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

ويمكنك أيضًا تحديد نوع المتغير صراحةً إذا أردت فرض [نوع][strong typed] معيّن.
وستحاول PowerShell بذل قصارى جهدها لتحويل القيمة من نوع إلى آخر إن أمكن.

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```


### الثوابت

الثوابت في PowerShell هي متغيرات للقراءة فقط لا يمكن **إزالتها** بعد تعريفها.
وهذا يقودنا إلى الأسلوب الثاني لتعريف المتغيرات باستخدام الأمر `New-Variable`.

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
```

وللاطلاع على أسلوب أكثر تفصيلًا وتقدمًا لإنشاء متغير جديد بخيارات متنوعة، راجع الأمر [New-Variable][New-Variable].


## الدوال

تُعرَّف [الدوال][functions] في PowerShell باستخدام الكلمة المفتاحية `function`.
ويمكن أن تحتوي كل دالة على صفر أو أكثر من [المعاملات][parameters] الرسمية بين الأقواس الهلالية `()`، يتبعها [نطاق][scope] خاص بها يبدأ بـ `{` وينتهي بـ `}`.

```powershell
function Greeting {
    return "Hello!"
}
```

يمكن للدوال في PowerShell أن تُرجع القيم صراحةً عبر الكلمة المفتاحية `return`، بعد استدعائها بالصيغة `FuncName $Arg`.

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

سنغطي في وحدة مفهوم `Functions` نظرة متقدمة على كيفية كتابة تعريف مفصّل للدالة، وكيف يمكن للدوال أن تُرجع القيم ضمنيًا.


## التعليقات

يبدأ التعليق المفرد في PowerShell بـ `#` وينتهي بنهاية السطر.
ويبدأ تعليق الكتلة في PowerShell بـ `<#` وينتهي بـ `#>`.
وسنغطي في وحدة مفهوم `Functions` عرضًا متقدمًا لكتلة التعليقات لإنشاء تعليمات مبنية على التعليقات.

```powershell
function Main() {
    #This is a comment
}
```
