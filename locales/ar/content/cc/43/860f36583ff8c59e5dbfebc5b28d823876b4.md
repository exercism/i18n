# مقدمة

## المصفوفات

`array` في F# هي مجموعة قابلة للتغيير مكوَّنة من صفر أو أكثر من القيم وذات طول ثابت. وهذا يعني أنه بمجرد إنشاء المصفوفة، لا يمكن أن يتغير حجمها، لكن يمكن أن تتغير قيمها. ويجب أن تكون جميع القيم في المصفوفة من النوع نفسه. ويمكن تعريف المصفوفات كما يلي:

```fsharp
let empty = [| |]
let emptyAlternative = Array.empty

let singleValue = [| 5 |]
let singleValueAlternative = Array.singleton 5

let threeValues = [| "a"; "b"; "c" |]
```

يمكن إسناد العناصر إلى المصفوفة أو استرجاعها منها باستخدام فهرس. ومصفوفات F# مفهرسة بدءًا من الصفر، بمعنى أن فهرس العنصر الأول يساوي صفرًا دائمًا:

```fsharp
let numbers = [| 2; 3; 5 |]

// Update value in array
numbers[2] <- 9

// Read value from array
numbers[2]
// => 9
```

تتم معالجة المصفوفات إما بدوال وعوامل معرَّفة في وحدة `Array`، أو يدويًا باستخدام مطابقة الأنماط عبر نمط _المصفوفة_:

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty"
    | [| 1; 2; three |] -> sprintf "1, 2, %d" three
    | _ -> "Other"

describe [| |]         // => "Empty"
describe [| 1; 2; 4 |] // => "1, 2, 4"
describe [| 5; 7; 9 |] // => "Other"
```

يمكنك أيضًا _تجاهل_ قيمة أثناء مطابقة الأنماط؛ فعندما لا _تهمّك_ قيمة في حالة معينة (أي أنك لن _تستخدم_ القيمة) يمكنك استخدام الشرطة السفلية (`'_'`) للدلالة على ذلك:

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty array"
    | [| x |] -> "Array with one item"
    | [| _; y |] -> "Array with two items (first item ignored)"
    | _ -> "Array with many items (all items ignored)"

describe [| |]          // => "Empty array"
describe [| 1 |]        // => "Array with one item"
describe [| 5; 7 |]     // => "Array with two items (first item ignored)"
describe [| 5; 7; 9 |]  // => "Array with many items (all items ignored)"
```

يجب أن تأتي الشرطة السفلية الواحدة `'_'` دائمًا في _النهاية_ عند مطابقة الأنماط، فأي قيمة _لا_ تطابق أيًّا من الحالات الأخرى ستُعالَج بهذه الحالة.
