# نبذة

[القوائم][list] نوع بيانات أساسي في Elixir لتخزين مجموعة من القيم. القوائم _غير قابلة للتغيير_، بمعنى أنه لا يمكن تعديلها. أي عملية تُغيّر قائمة ما تُرجع قائمة جديدة. وتُطبّق القوائم [بروتوكول Enumerable][enum-protocol]، ما يتيح استخدام الدوال في وحدتي [Enum][enum] و[Stream][stream].

تُنفَّذ القوائم في Elixir على هيئة [قوائم مترابطة][linked-list-wiki]، لا كمصفوفات من مواقع ذاكرة متجاورة. لذلك يستغرق الوصول إلى عنصر في القائمة وقتًا خطيًا يتوقف على طول القائمة.

يمكن كتابة القوائم بالصيغة الحرفية، أو بترميز الرأس والذيل (الذي يستخدم عامل `cons` وهو `|`)، أو بمزيج من الاثنين:

```elixir
# Literal Form
[]
[1]
[1, 2, 3]

# Head-tail Notation
[]
# same as [1]
[1 | []]
# same as [1, 2, 3]
[1 | [2 | [3 | []]]]

# Mixed
# same as [1, 2, 3]
[1 | [2, 3]]
```

وقد يكون هناك أكثر من عنصر واحد قبل العامل _cons_ (`|`).

```elixir
# Multiple prepends
[1, 2, 3 | [4, 5]]
```

يمكن استخدام ترميز الرأس والذيل لإضافة عناصر إلى نهاية القائمة.

```elixir
list = [2, 1]

[3, 2, 1] == [3 | list]
# => true
```

تُعدّ إضافة العناصر إلى نهاية القائمة أثناء التكرار نمطًا مضادًا. فإضافة عنصر تتطلب المرور على القائمة كاملة وإضافة العنصر في نهايتها؛ لذلك فإن إضافة عنصر جديد في كل تكرار تتطلب المرور على القائمة كاملة في كل مرة.

ويمكننا تحقيق النتيجة نفسها بإضافة العنصر إلى مقدمة القائمة المعكوسة، ثم عكس الناتج. فالإضافة إلى المقدمة عملية سريعة وتتطلب وقتًا ثابتًا.

```elixir
# Appending to the end of a list (potentially slow)
[1, 2, 3] ++ [4] ++ [5] ++ [6]

# Prepend to the start of a list (faster, due to the nature of linked lists)
[6 | [5 | [4 | [3, 2, 1]]]]
# then reverse!
```

وهناك عدة دوال شائعة في `Kernel` تخص القوائم:

- تُرجع [`hd/1`][hd] _رأس_ القائمة، أي _العنصر الأول_ فيها.
- تُرجع [`tl/1`][tl] _ذيل_ القائمة، أي القائمة _من دون_ العنصر الأول.
- تُرجع [`length/1`][length] عدد العناصر في القائمة.
- تُرجع [`in/2`][in] قيمة منطقية تحدد ما إذا كان العنصر موجودًا في القائمة.

وهناك أيضًا [وحدة `List`][list].

يمكن أن تحتوي القوائم على أي نوع بيانات، وعلى مزيج من أنواع بيانات مختلفة.

```elixir
list = [1, :a, 2.0, "string"]
```
