# نبذة

نوع `Option` هو آلية لغة F# للتعامل مع القيم التي قد توجد أو لا توجد.
وهو يوفّر بديلًا آمنًا من حيث النوع لاستخدام `null`، الشائع في لغات أخرى للتعامل مع مثل هذه القيم.
وهو مستخدم في كثير من دوال مكتبة F# القياسية، لذا فإن فهمه ضروري للاستخدام الفعّال لمكتبة F# القياسية.

## مزايا استخدام نوع `Option`

* **الأمان وقت الترجمة**: بجعل وجود القيمة أو غيابها صريحًا في نظام الأنواع، يستطيع المترجم أن يضمن تعاملك مع حالة "غياب القيمة"، فيمنع فئة كبيرة من الأخطاء التي قد تحدث عند استخدام `null`.

* **الأمان وقت التشغيل**: بدلًا من استخدام `null`، تستخدم F# القيمة `None` لتمثيل غياب القيمة، ما يجعل حدوث `NullReferenceException` مستحيلًا.

* **تفرض التعامل الصريح**: يشترط نظام الأنواع أن يتعامل الكود صراحةً مع كلٍّ من الحالتين `Some value` و`None`، ما يجعل كودك أكثر متانة وقابلية للتوقّع.

* **تتوافق مع مطابقة الأنماط**: تعمل قيم `Option` بسلاسة مع أسلوب مطابقة الأنماط في F#، فتوفّر طريقة نظيفة وآمنة لتفكيك القيمة والتعامل معها إن وُجدت، أو لتنفيذ إجراء مختلف إن لم توجد.

## الاستخدام 

نوع `Option` نوع عام (له نوع أساسي).  
قيم `Option` إما `Some value`، وتمثّل قيمة محدّدة، وإما `None`، وتمثّل غياب القيمة.

توضّح الدالة التالية كيفية إنشاء قيمة `Option`:

```fsharp
let keepIfPositive (a: int) : int option = if a > 0 then Some a else None
```

~~~~exercism/note
`T option` هي الصيغة اللاحقة المكافئة لـ `Option<T>`؛ ويمكن استخدام صيغتَي الكتابة بالتبادل.
غير أنه وفقًا لدليل أسلوب F#، تُفضَّل الصيغة اللاحقة لأنواع Option (انظر [قسم دليل أسلوب F# حول تنسيق الأنواع وتعليقات الأنواع](https://learn.microsoft.com/en-us/dotnet/fsharp/style-guide/formatting#for-types-prefer-prefix-syntax-for-generics-foot-with-some-specific-exceptions)). 
~~~~

من حالات الاستخدام النموذجية لـ `Option` دوال البحث. 
فمثلًا، تُرجع الدالة `List.tryFind` القيمة `Some index` عندما يكون العنصر موجودًا في القائمة (حيث `index` هو موضع القيمة المطلوبة في القائمة)، أو `None` عندما لا يكون العنصر في القائمة.

## قراءة محتوى قيمة `Option`

الطريقة المتّبعة لقراءة قيمة `Option` هي عبر مطابقة الأنماط، كما يوضّح المثال التالي:

```fsharp
// Returns "Hello, <name>!" if the name is provided; otherwise returns "Hello, you!"
let sayHello (optionalName: string option): string = 
    match optionalName with
    | Some name -> "Hello, " + name + "!"
    | None -> "Hello, you!"

sayHello (Some "Matthieu")
// --> "Hello, Matthieu!"

sayHello None
// --> "Hello, you!"
```

## فك تغليف قيم `Option` باستخدام قيم افتراضية

يمكن "فك تغليف" قيم `Option` (أي تحويلها إلى النوع الذي تحتويه) بتزويد قيم افتراضية عبر الدالة `Option.defaultValue`. 
وهذا مفيد بشكل خاص عندما تريد التأكد من أن القيمة ليست `None`.
فمثلًا:

```fsharp
Option.defaultValue "" (Some "F#")
// --> "F#"

Option.defaultValue 0 None
// --> 0
```

## مزيد من الدوال في وحدة `Option`

تضمّ وحدة `Option` أيضًا دوال تقابل الدوال المتاحة للقوائم والمصفوفات والمتتاليات وأنواع المجموعات الأخرى، مثل `Option.map` و`Option.iter` و`Option.forall` و`Option.count`. 
وتمكّن هذه الدوال من التعامل مع قيم `Option` كأنها مجموعة من صفر أو عنصر واحد.
