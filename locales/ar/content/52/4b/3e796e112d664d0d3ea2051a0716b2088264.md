# المدخلات

مدخلات هذا التمرين هي:

- `target`: سلسلة نصية (مثال: `'stone'`) ستكون _الوسيط الأيسر_.
- `candidates`: قائمة من السلاسل النصية المُعلَّبة (مثال: `'stone' ; 'tones' ; 'banana' ; 'tons' ; 'notes' ; 'Seton'`) ستكون _الوسيط الأيمن_.

سيُستدعى الفعل الذي تكتبه هكذا:

```j
  target     =. 'stone'
  candidates =. 'stone' ; 'tones' ; 'banana' ; 'tons' ; 'notes' ; 'Seton'
  
  subject findAnagrams candidates
```

## المُخرجات

يجب أن يُرجع الفعل _قائمة_ من الصناديق تحتوي على السلاسل النصية التي تُشكّل أناغرامات للهدف. إذا لم توجد أي أناغرامات، فستكون النتيجة `empty`.
