# الجمل الشرطية

تمتلك Ruby ما يُعرف بتعبيرات التحكم في التدفق، وهي تُستخدم للتحكم في طريقة عمل البرنامج، وتأخذ قيمة صحيحة أو خاطئة.
هناك عوامل يمكن استخدامها لإنشاء قيم صحيحة أو خاطئة، وتُعرف هذه بـ[عوامل المقارنة][comparison-operators].

هناك تعبيران رئيسيان للتحكم يُستخدمان لتحديد أي كود سيعمل وأي كود لن يعمل.
ويُقصد بذلك أيضًا تحديد الفرع الذي سيعمل.

هذان التعبيران هما: `if` وتعبير `unless`.

## عوامل المقارنة

تُستخدم [عوامل المقارنة][comparison-operators] لمقارنة القيم وإرجاع قيمة `true` أو `false`.
تتطلب العوامل التالية قيمتين من النوع نفسه للمقارنة بينهما.
وإذا لم تكن القيمتان من النوع نفسه، فسيرفع المُصرِّف خطأً.
وفي ما يلي قائمة بالعوامل ومثال على الحالة التي تُعطي فيها قيمة `true`:

| الطريقة | الوصف                 | مثال   |
| ------ | --------------------- | ------- |
| <      | أصغر من               | 4 < 5   |
| <=     | أصغر من أو يساوي      | 4 <= 4  |
| >      | أكبر من               | 3 > 1   |
| >=     | أكبر من أو يساوي      | 2 >= 2  |

يمكن استخدام عاملي التساوي وعدم التساوي لمقارنة أي نوع من القيم، على عكس العوامل المذكورة سابقًا.
يُستخدم العامل `==` للتحقق مما إذا كانت قيمتان متساويتين، ويشمل ذلك التحقق من نوع القيمة.
ويعمل `!=` بالطريقة نفسها، لكنه سيُرجع `true` إذا لم تكن القيمتان متساويتين، و`false` إذا كانتا متساويتين.
وفي ما يلي قائمة بعاملي التساوي وعدم التساوي ومثال على الحالة التي يُعطيان فيها قيمة `true`:

| الطريقة | الوصف     | مثال    |
| ------ | ------------ | ------- |
| ==     | يساوي        | 4 == 4  |
| !=     | لا يساوي     | 5 != 4  |

## الجملة الشرطية `if`

تُستخدم جملة [`if`][if] للتحقق مما إذا كان شرط معيّن صحيحًا أو خاطئًا.
إذا كان الشرط صحيحًا، فسينفَّذ الكود داخل جملة `if`.
تُنتهي جملة `if` بالكلمة المفتاحية `end`.

```ruby
value = 1
if value == 1
  "1 is equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
end
# => nil
```

## جملة `unless`

تعمل جملة `unless` بشكل مشابه جدًا لجملة `if`، لكنها تنفّذ الكود داخل جملة `unless` إذا كان الشرط خاطئًا.

```ruby
value = 1
unless value == 1
  "1 is not equal to 1"
end
# => nil

unless value > 2
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## جملة `else`

يمكن استخدام جملة `else` مع جملة `if`.
تُنفَّذ جملة `else` إذا لم يُنفَّذ فرع `if`.

```ruby
value = 1
if value == 1
  "1 is equal to 1"
else
  "1 is not equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
else
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## الجمل الشرطية المتسلسلة

يمكن استخدام جملة `elsif` مع جملة `if`.
تُنفَّذ جملة `elsif` إذا لم يُنفَّذ فرع `if` وكان شرط جملة `elsif` صحيحًا.
يمكن ربط جمل `elsif` ببعضها، وسيُنفَّذ أول شرط صحيح.
ويمكن أيضًا وضع جملة `else` في نهاية جملة `if`، وتُنفَّذ إذا لم يكن أي من الجمل السابقة صحيحًا.

```ruby
value = 1
if value == 0
  "1 is equal to 0"
elsif value > 2
  "1 is greater than 2"
else
  "1 is not equal to 0 and 1 is not greater than 2"
end
# => "1 is not equal to 0 and 1 is not greater than 2"
```
