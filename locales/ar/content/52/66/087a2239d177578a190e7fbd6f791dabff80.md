# التعليمات

أنت تتطوع في مركز الفنون المجتمعي، حيث تُقام فوق المدخل الأمامي فسيفساء طويلة من البلاط الخزفي. وقد رتّب فريق التصميم العمل **صفًّا صفًّا**: كل صف هو مصفوفة من ألوان البلاط، والفسيفساء كاملة مصفوفة من الصفوف.

وبينما يقطع المتطوعون البلاط ويضعونه ويعيدون ترتيبه، تكتب أنت كلمات صغيرة قابلة لإعادة الاستخدام لبناء أجزاء من التصميم ودمجها والبحث عنها.

## 1. شريط من بلاطة واحدة

عرّف `tile-strip` لتأخذ لونًا وتُرجع صفًّا من عنصر واحد يضم ذلك اللون فقط.

```factor
"sky-blue" tile-strip .
! => { "sky-blue" }
```

## 2. صف من ثلاث بلاطات

عرّف `row-of-three` لتأخذ ثلاثة ألوان من المكدس وتُرجع صفًّا من 3 عناصر.

```factor
"red" "white" "blue" row-of-three .
! => { "red" "white" "blue" }
```

## 3. دمج الصفوف في قائمة بلاطات مسطحة

يحتاج فريق التصميم إلى التحقق السريع من إجماليات الألوان في كل صفوف الفسيفساء. عرّف `combine-rows` لتأخذ مصفوفة من الصفوف وتُرجع تسلسلًا واحدًا يضم كل بلاطة بالترتيب.

```factor
{ { "red" "white" } { "blue" "red" } } combine-rows .
! => { "red" "white" "blue" "red" }
```

## 4. عكس صف

بالنسبة إلى الألواح المتماثلة، يعكس الفريق الصف قبل وضع النسخة على الجانب المقابل. عرّف `mirror-row` لتُرجع صفًّا بترتيب معكوس.

```factor
{ "red" "white" "blue" } mirror-row .
! => { "blue" "white" "red" }
```

## 5. أين يقع هذا اللون في الصف؟

عرّف `tile-position` لتأخذ صفًّا ولونًا وتُرجع فهرس أول بلاطة تحمل ذلك اللون في الصف (بدءًا من 0). إذا لم يكن اللون موجودًا، فتُرجع `f`.

```factor
{ "red" "white" "blue" } "white" tile-position .
! => 1

{ "red" "white" "blue" } "green" tile-position .
! => f
```

## 6. هل يحتوي هذا الصف على اللون؟

عرّف `has-colour?` لتأخذ صفًّا ولونًا وتُرجع `t` إذا ظهر اللون في أي مكان من الصف، وإلا فتُرجع `f`.

```factor
{ "red" "white" "blue" } "white" has-colour? .
! => t

{ "red" "white" "blue" } "green" has-colour? .
! => f
```
