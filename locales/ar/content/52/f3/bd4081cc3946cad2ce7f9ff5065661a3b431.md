# نبذة

يقسّم Factor إدخال/إخراج التيارات إلى طبقتين. الطبقة الدنيا هي واجهة *التيار الصريح*: كل كلمة تأخذ التيار كوسيط. أما الطبقة العليا فهي واجهة *التيار المحيط*: كلمات قصيرة من سطر واحد تعمل على التيار المرتبط حاليًا. تستند كلتا الطبقتين إلى [البروتوكول][stream-protocol] نفسه، وكل ما تفعله كلمات الطبقة العليا هو البحث عن التيار المحيط ثم تمرير الاستدعاء.

## كلمات التيار الصريح

```
stream-read       ( n stream -- seq/f )
stream-read1      ( stream -- elt/f )
stream-readln     ( stream -- str/f )
stream-write      ( seq stream -- )
stream-write1     ( elt stream -- )
stream-print      ( str stream -- )
stream-flush      ( stream -- )
stream-contents   ( stream -- seq )
stream-lines      ( stream -- seq )
```

`stream-contents` تستنزف كل شيء؛ و`stream-lines` تستنزف المحتوى وتقسّمه عند حدود الأسطر؛ و`stream-readln` تُرجع سطرًا واحدًا في كل مرة (أو `f` عند نهاية التيار).

## كلمات التيار المحيط

```
read1   ( -- elt/f )
read    ( n -- seq/f )
readln  ( -- str/f )
write   ( seq -- )
write1  ( elt -- )
print   ( str -- )
flush   ( -- )
```

هذه هي كلمات الإدخال/الإخراج اليومية. تبحث عن تيار الإدخال أو الإخراج الحالي في المتغيرات الديناميكية `input-stream` / `output-stream` ثم تمرّر الاستدعاء. ولهذا فإن إعادة توجيه `print` إلى سلسلة نصية ليست سوى مسألة ربط `output-stream` طوال مدة تنفيذ الاقتباس.

## بواني التيارات المضمّنة

| كلمة              | مفردات                | ما الذي تبنيه                  |
|-------------------|----------------------|---------------------------------|
| `<string-reader>` | [`io.streams.string`][io.streams.string]  | تقرأ سلسلة نصية حرفية          |
| `<string-writer>` | [`io.streams.string`][io.streams.string]  | تجمع الكتابات في سلسلة نصية   |
| `<file-reader>`   | [`io.files`][io.files]           | تقرأ ملفًا مع ترميز   |
| `<file-writer>`   | [`io.files`][io.files]           | تكتب ملفًا مع ترميز  |

جميع الأربعة تُنتج كائنات قابلة للتخلّص منها، فهي توسّع `disposable` من `destructors`، لذا تُحرّرها مُركّبات `with-…` أدناه عند الخروج.

## الربط المحدود النطاق

```
with-input-stream   ( stream quot -- )
with-output-stream  ( stream quot -- )
with-string-reader  ( str quot -- )
with-string-writer  ( quot -- str )
with-file-reader    ( path encoding quot -- )
with-file-writer    ( path encoding quot -- )
```

كل واحدة منها تفتح تيارًا، وتربطه كتيار الإدخال أو الإخراج المحيط للاقتباس الداخلي، ثم تتخلّص منه عند الخروج، حتى لو رفع الاقتباس استثناءً. إنها مُركّبات المدمّرات من `boatswains-bilge`، مخصّصة للتيارات.

`with-string-writer` مثال أنظف بشكل خاص: فهي تبني `<string-writer>` جديدًا تلقائيًا، وتنفّذ الاقتباس وبذاك الكاتب كتيار الإخراج المحيط، ثم تُرجع السلسلة النصية المتراكمة. نمط "التقاط مخرجات اقتباس" كله كلمة واحدة.

```factor
USING: io io.streams.string ;

[ "alpha" print "bravo" print ] with-string-writer .
! => "alpha\nbravo\n"
```

## لماذا التيار المحيط أصلًا؟

ربط المتغيرات الديناميكية هو السبب في أن `print` تعمل في برنامج لا يدري هل يُشغَّل تفاعليًا، أم في ملف سجل، أم في ذاكرة اختبار مُلتقطة. استبدل الربط مرة واحدة فتفعل كل كلمة تستدعي `print` الشيء الصحيح، دون أي إعادة توصيل. هذا هو الانعكاس الذي تكسبه من الطبقة العليا.

ولتطبيق تيار بنفسك، أي لتعريف صنفك الخاص الذي يتصل بالبروتوكول، راجع مفهوم `streams` (يُدرَّس في `telegraphers-tape`).
