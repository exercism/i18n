# مقدمة

تُستخدم الحلقات لتنفيذ منطق ما بشكل متكرر.
النوعان الأكثر شيوعًا هما `while loop` (التكرار غير المحدد) و`for loop` (التكرار المحدد أو المعدود).
وهناك أيضًا `for each` حلقة، ستأتي في مفهوم لاحق.


## الصيغة العامة

يتكوّن `for loop` من ترويسة وكتلة كود تحتوي على جسم الحلقة محاطًا بأقواس معقوفة.
تتكوّن الترويسة من 3 مكوّنات تفصل بينها فاصلات منقوطة `;`: عبارة التهيئة، والشرط، وتعبير آخر.
وقد يكون كل منها فارغًا.

```cpp
for (init-statement; condition; expression) {
  some_statement;
}
```

- المكوّن **init** هو كود يُنفَّذ مرة واحدة فقط قبل أن تبدأ الحلقة.
- المكوّن **condition** يجب أن يكون تعبيرًا يُقيَّم إلى قيمة منطقية ويتحكم في وقت توقف الحلقة.
سيُنفَّذ الكود داخل الحلقة طالما أن هذا الشرط يُقيَّم إلى صحيح.
وبمجرد أن يُقيَّم هذا التعبير إلى خطأ، لن تُنفَّذ أي تكرارات أخرى للحلقة.
- المكوّن **expression** هو كود سيُنفَّذ في نهاية كل تكرار.


تُنفِّذ `while loop` جسمها طالما أن فحص شرطها صحيح.
يوضّح مقتطف الكود التالي كيفية تحويل `for loop` إلى `while loop`.

```cpp
init-statement;
while(condition) {
    some_statement;
    expression;
}
```

## فاصل: الزيادة والإنقاص

عند العمل مع الحلقات، غالبًا ما يُطلب إضافة 1 أو طرح 1 من متغير عدّاد.
هذا شائع جدًا لدرجة أن للعملية عوامل خاصة: `++` و`--`.

تأتي في صيغة بادئة وصيغة لاحقة.
تُغيّر الصيغة البادئة المتغير قبل استخدامه في العبارة، بينما تفعل الصيغة اللاحقة ذلك بعده.
على الأرجح سترغب في الصيغة البادئة معظم الوقت.

```cpp
int a{3};
int b{--a};
// b is 2, a is now 2
int c{a++};
// c is 2, a is now 3
```

## حلقات `for`: مثال

عادةً ما يُهيّئ مكوّن التهيئة متغير عدّاد، ويتحقق الشرط مما إذا كان ينبغي متابعة الحلقة أو إيقافها، وعادةً ما يزيد المكوّن اللاحق العدّاد في نهاية كل تكرار.

```cpp
int sum{0};
for (int i{1}; i < 10; ++i) {
  sum += i;
}
```

ستجمع هذه الحلقة الأعداد من `1` إلى `9` (بما في ذلك `9`).

## `break` و`continue`

داخل جسم الحلقة، يمكنك استخدام الكلمة المفتاحية `break` لإيقاف تنفيذ الحلقة تمامًا:

```cpp
int sum{2};
while(true) {
    sum *= 2;
    if (sum > 1000)
        break;
}
// sum is now 1024
```

في المقابل، الكلمة المفتاحية `continue` توقف فقط تنفيذ التكرار الحالي وتتابع مع التكرار التالي:

```cpp
int equal_sum{0};
for (int i{1}; i < 7; ++i) {
  if  (i%2 == 1) {
    continue;
  }
  equal_sum += i;
}
// equal_sum is now 12
```
> ملاحظة: عادةً ما يكون من الأسهل فهم منطق الحلقة عندما يكون استخدام `break` و`continue` في أدنى حد أو متجنبًا تمامًا.
