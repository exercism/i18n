# مقدمة

## الحلقات

تُستخدم الحلقات لتنفيذ بعض المنطق بشكل متكرر.
النوعان الأكثر شيوعًا هما `while loop` (تكرار غير محدود) و `for loop` (تكرار محدد أو معدود).
وهناك أيضًا حلقة `for each`، التي ستظهر في مفهوم لاحق.

### الصيغة العامة

تتكوّن `for loop` من ترويسة ومن كتلة كود تحتوي على جسم الحلقة محاطًا بالأقواس المعقوفة.
تتكوّن الترويسة من 3 مكوّنات تفصل بينها الفواصل المنقوطة `;`: عبارة التهيئة، والشرط، وتعبير آخر.
ويمكن أن يكون كل منها فارغًا.

```cpp
for (init_statement; condition; expression) {
  some_statement;
}
```

- مكوّن **init_statement** هو كود يُنفَّذ مرة واحدة فقط قبل أن تبدأ الحلقة.
- يجب أن يكون مكوّن **condition** تعبيرًا يُقيَّم إلى `boolean` ويتحكم في الوقت الذي ينبغي أن تتوقف فيه الحلقة.
  سيُنفَّذ الكود داخل الحلقة طالما أن هذا الشرط يُقيَّم إلى `true`.
  وبمجرد أن يُقيَّم هذا التعبير إلى `false`، لن تُنفَّذ أي تكرارات أخرى للحلقة.
- مكوّن **expression** هو كود يُنفَّذ في نهاية كل تكرار.

تُنفِّذ `while loop` جسمها طالما أن فحص **condition** فيها هو `true`.
يوضّح مقتطف الكود التالي كيفية تحويل `for` إلى `while loop`.

```cpp
init_statement;
while(condition) {
    some_statement;
    expression;
}
```

### فاصل: الزيادة والنقصان

عند العمل مع الحلقات، غالبًا ما نحتاج إلى إضافة 1 أو طرح 1 من متغير عدّاد يتتبع التكرارات.
هذا أمر شائع جدًا، حتى إن عمليتي الزيادة والنقصان لهما عاملان خاصان: `++` و `--`.

وهما يأتيان في صيغة **prefix** وصيغة **postfix**.
تُغيّر صيغة **prefix** المتغير قبل استخدامه في العبارة، بينما تفعل صيغة **postfix** ذلك بعده.
وعلى الأرجح ستحتاج إلى صيغة **prefix** في معظم الأحيان.

```cpp
int a{3};
int b{--a};
// b is 2, a is now 2
int c{a++};
// c is 2, a is now 3
```

### حلقات `for` - مثال

عادةً ما يُهيّئ _init component_ متغير عدّاد، ويتحقق _condition_ مما إذا كان ينبغي متابعة الحلقة أو إيقافها، وعادةً ما يزيد _post component_ العدّاد في نهاية كل تكرار.

```cpp
int sum{0};
for (int i{1}; i < 10; ++i) {
  sum += i;
}
```

ستجمع هذه الحلقة الأعداد من `1` إلى `9` (بما في ذلك `9`).

### `break` و `continue`

داخل جسم الحلقة، يمكنك استخدام الكلمة المفتاحية `break` لإيقاف تنفيذ الحلقة بالكامل:

```cpp
int sum{2};
while(true) {
    sum *= 2;
    if (sum > 1000)
        break;
}
// sum is now 1024
```

في المقابل، توقف الكلمة المفتاحية `continue` تنفيذ التكرار الحالي فقط وتتابع مع التكرار التالي:

```cpp
int equal_sum{0};
for (int i{1}; i < 7; ++i) {
  if  (i%2 == 1) {
    continue;
  }
  equal_sum += i;
}
// equal_sum is now 12
```

~~~~exercism/note
عادةً ما يكون فهم منطق الحلقة أسهل عندما يكون استخدام `break` و `continue` في حده الأدنى أو مُتجنَّبًا تمامًا.
فكلتا الكلمتين المفتاحيتين تتخطيان أجزاء معينة من الكود، مما يجعل متابعته أصعب في كثير من الأحيان.
~~~~
