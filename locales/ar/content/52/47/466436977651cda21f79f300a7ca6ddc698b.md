## كيفية الاستخدام

### البناء

`npx blueprint build` أو `yarn blueprint build`

### الاختبار

`npx blueprint test` أو `yarn blueprint test`

### النشر أو تشغيل سكربت آخر

`npx blueprint run` أو `yarn blueprint run`

### إضافة عقد جديد

`npx blueprint create ContractName` أو `yarn blueprint create ContractName`
