# مقدمة

تُنفَّذ الذاكرة الديناميكية عبر دوال المكتبة التي يستخدمها المبرمج لتخصيص الذاكرة وتحريرها أثناء التشغيل.
وبما أن المبرمج يتحكم في تخصيص الذاكرة وتحريرها، فإن الذاكرة الديناميكية آمنة بقدر ما يكون المبرمج بعيدًا عن الخطأ البشري.
ولهذا السبب، تُعدّ الذاكرة الديناميكية أحد المصادر الرئيسية لـ bugs في البرمجة وأحد الأهداف الرئيسية لهجمات القرصنة.

## malloc

`malloc` دالة مُعلنة في `stdlib.h` تُستخدم لتخصيص ذاكرة ديناميكية.
إذا نجح التخصيص، تُرجع الدالة مؤشرًا يشير إلى عنوان أول بايت من الذاكرة المخصصة.
وإذا لم ينجح التخصيص، تُرجع الدالة `NULL`.
من الحكمة التحقق من نتيجة `malloc` بحثًا عن `NULL` والتعامل مع الفشل بشكل سليم.
المؤشر المُرجَع من النوع `pointer-to-void`، ويمكن اعتباره تقريبًا مؤشرًا «عامًّا» يمكن تحويله إلى النوع المحدد الذي تستخدمه الذاكرة.
لـ `malloc` معامل واحد، وهو حجم الذاكرة المطلوبة بالبايت.
الحجم الكلي لتخصيص مصفوفة هو حجم نوع بيانات كل عنصر مضروبًا في عدد العناصر.
ويُستخدم عامل `sizeof` عادةً للحصول على حجم نوع بيانات كل عنصر.
يوضح المثال التالي ذلك

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // pointer-to-void from malloc is converted to a pointer-to-int
    int * numbers = malloc(sizeof(int) * count);
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    // printed The size of numbers is 8 bytes (can vary by system)
    printf("The size of numbers is %zu bytes\n", sizeof(numbers));
    numbers[0] = 1;
    numbers[1] = 2;
    numbers[2] = 3;
    // prints The first element of the array is 1
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The second element of the array is 2
    printf("The second element of the array is %d\n", numbers[1]);
    // prints The third element of the array is 3
    printf("The third element of the array is %d\n", numbers[2]);
    free(numbers);
    numbers = NULL;
}
```

من المهم أن تتذكر أن الذاكرة المخصصة حديثًا بواسطة `malloc` ليست مُهيّأة، لكنها قد تحتوي على قيم عشوائية.
لاحظ أن `sizeof` المؤشر `numbers` ليس عدد عناصر المصفوفة، ولا الحجم الكلي للذاكرة المخصصة.
حجم المؤشر الذي تُرجعه `malloc` هو حجم أي مؤشر على ذلك النظام بعينه.
شُغّل كود المثال على نظام 64 بت، فكان حجم المؤشر 8 بايتات (مضروبًا في 8 بتات لكل بايت = 64 بت).
حُوّل نوع المؤشر ضمنيًا من pointer-to-void إلى pointer-to-int.
وكان يمكن أيضًا تحويله صراحةً هكذا: `int * numbers = (int *) malloc(sizeof(int) * count);`.
إذا كانت القيم ستُكتب بالتأكيد قبل قراءتها، فإن استخدام `malloc` يمكن أن يكون طريقة فعّالة لتخصيص الذاكرة.
لكن إذا كان هناك احتمال أن تُقرأ القيم قبل تهيئتها، فإن استخدام `malloc` محفوف بالمخاطر.
الطريقة الأكثر أمانًا لتخصيص الذاكرة هي استخدام `calloc`، فهو يهيّئ الذاكرة المخصصة حديثًا إلى صفر.

لاحظ في الأمثلة أعلاه استخدام `free(numbers)`.

## free

`free` دالة مُعلنة في `stdlib.h` تُستخدم لتحرير الذاكرة التي خُصّصت ديناميكيًا.
تبقى الذاكرة المخصصة ديناميكيًا محجوزة في الذاكرة حتى تُحرَّر بواسطة `free`.
قد تُحرّر بعض أنظمة التشغيل الذاكرة المخصصة ديناميكيًا تلقائيًا عند انتهاء البرنامج، لكن من أفضل الممارسات عدم الاعتماد على ذلك.
لـ `free` معامل واحد، وهو مؤشر إلى الذاكرة التي خُصّصت ديناميكيًا.
المؤشر الذي لا يُضبط على `NULL` بعد تحريره يُسمى مؤشرًا معلّقًا.
ويمكن أن يشير المؤشر المعلّق إلى ذاكرة غير التي كان المقصود بها.
وبالتالي، يمكن أن يؤدي المؤشر المعلّق إلى تلف البيانات واستبدال الكود وتنفيذه بشكل تعسفي.
يمكن استخدام مؤشر إلى ذاكرة مخصصة لم يُفرَّغ بضبطه على `NULL` لاختراق البرنامج.
من أفضل الممارسات ضبط المؤشر على `NULL` بعد تمريره إلى `free`.

## calloc

`calloc` دالة مُعلنة في `stdlib.h` تُستخدم لتخصيص الذاكرة الديناميكية وتهيئة الذاكرة المخصصة حديثًا إلى صفر في آنٍ واحد.
إذا نجح التخصيص، تُرجع الدالة مؤشرًا يشير إلى عنوان أول بايت من الذاكرة المخصصة.
وإذا لم ينجح التخصيص، تُرجع الدالة `NULL`.
من الحكمة التحقق من نتيجة `calloc` بحثًا عن `NULL` والتعامل مع الفشل بشكل سليم.
المؤشر المُرجَع من النوع `pointer-to-void`، ويمكن اعتباره تقريبًا مؤشرًا «عامًّا» يمكن تحويله إلى النوع المحدد الذي تستخدمه الذاكرة.
لـ `calloc` معاملان.
المعامل الأول يحدد عدد العناصر المراد تخصيصها من نوع البيانات المحدد.
المعامل الثاني يحدد حجم نوع البيانات المحدد المراد تخصيصه.

في المثال التالي، يجب أن تُظهر جميع عبارات `printf` القيمة `0` دائمًا، لأن `calloc` تضمن تصفير القيم المخصصة حديثًا.

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // allocates the amount of bytes in an int, multiplied by count
    int * numbers = calloc(count, sizeof(int));
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    // prints The first element of the array is 0
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The second element of the array is 0
    printf("The second element of the array is %d\n", numbers[1]);
    // prints The third element of the array is 0
    printf("The third element of the array is %d\n", numbers[2]);
    free(numbers);
    numbers = NULL;
}
```

## realloc

`realloc` دالة مُعلنة في `stdlib.h` تُستخدم لتوسيع الذاكرة المخصصة القائمة أو تقليصها.
إذا نجحت إعادة التخصيص، تُرجع الدالة مؤشرًا يشير إلى عنوان أول بايت من الذاكرة المعاد تخصيصها.
وإذا لم تنجح إعادة التخصيص، تُرجع الدالة `NULL`.
من الحكمة التحقق من نتيجة `realloc` بحثًا عن `NULL` والتعامل مع الفشل بشكل سليم.
لـ `realloc` معاملان.
المعامل الأول مؤشر إلى الذاكرة القائمة المراد إعادة تخصيصها.
المعامل الثاني يحدد حجم الذاكرة المعاد تخصيصها بالبايت.
تُحتفظ بالقيم التي ضُبطت قبل توسيع الذاكرة.
من المهم أن تتذكر أن الذاكرة المُضافة عند توسيع الذاكرة ليست مُهيّأة إلى صفر، وقد تكون قيمها أي شيء.
كذلك، الذاكرة المُزالة عند تقليص الذاكرة ليست مُهيّأة أيضًا، وقد تحتفظ بالقيم.
يوضح المثال التالي توسيع مصفوفة وتقليصها

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // allocates the amount of bytes in an int, multiplied by count
    int * numbers = calloc(count, sizeof(int));
    return numbers;
}

int * my_function_2 (int * ptr , int count) {
    // reallocates the memory to the size of an int multiplied by count
    int * numbers = realloc(ptr, sizeof(int) * count);
    // if realloc fails, exit the program
    if (!numbers) exit(-1);
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    numbers[0] = 1;
    numbers[1] = 2;
    numbers[2] = 3;
    // expand the size of the array
    numbers = my_function_2(numbers, 6);
    // prints The first element of the array is 1
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The sixth element of the array is [whatever is there]
    // the additional memory is not initialized, so it could be
    // 0 or it could be 18728 or anything else
    printf("The sixth element of the array is %d\n", numbers[5]);
    numbers[5] = 6;
    // shrink the size of the array
    numbers = my_function_2(numbers, 3);
    // prints The sixth element of the array is [whatever is there]
    // the removed memory is not initialized, so it could be
    // 6 or it could be 43164 or anything else
    printf("The sixth element of the array is %d\n", numbers[5]);
}
```
