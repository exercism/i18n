# الأعداد

تمتلك Crystal نوعًا يُسمّى `Number`، وهو النوع الأساس لكل الأنواع العددية.
ويوجد نوعان فرعيان رئيسيان داخل النوع `Number`: هما [`Int`][int] و[`Float`][float].

‏`Int` اختصار كلمة integer، ويمثّل الأعداد الصحيحة.
ويمكن أن يكون `Int` سالبًا أو موجبًا، وبدون فاصلة عشرية.

```crystal
1.class
# => Int32

-1.class
# => Int32
```

يمثّل `Float` الأعداد التي تحتوي على فاصلة عشرية.
ويمكن أن تكون قيم `Float` سالبة أو موجبة.

```crystal
10.5.class
# => Float64
```

## التحويل بين `Int` و`Float`

باستخدام الطريقتين `to_i` و`to_f` يمكنك التحويل بين `Int` و`Float`.
ويُقرَّب العدد إلى الأسفل عند التحويل من `Float` إلى `Int`.

```crystal
1.to_f
# => 1.0

1.0.to_i
# => 1

1.9.to_i
# => 1
```

## عوامل الحساب

يمكنك استخدام [عوامل الحساب الأساسية][math] مع `Int` و`Float`.
والعوامل هي `+` و`-` و`*` و`/` و`%`.
وعند استخدام هذه العوامل يمكنك الجمع بين `Int` و`Float`.

### الجمع والطرح والضرب

يُستخدم العامل `+` للجمع، والعامل `-` للطرح، والعامل `*` للضرب.

| العامل | مثال            |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### القسمة

تُستخدم القسمة لتقسيم الأعداد.
ويُستخدم العامل `/` للقسمة.
وستكون النتيجة دائمًا `Float`.

```crystal
4 / 2
# => 2.0

4.0 / 2
# => 2.0
```

~~~~exercism/caution
في بعض لغات البرمجة، عند القسمة على صفر تكون النتيجة خطأ.

أما في Crystal، فعند القسمة على صفر تكون النتيجة `Infinity` أو `-Infinity`.
والاستثناء الوحيد هو قسمة صفر على صفر، فتكون النتيجة `NaN` (ليس عددًا).
‏`Infinity` و`NaN` قيمتان خاصتان في النوع `Float`.

```crystal
1 / 0
# => Infinity

-1 / 0
# => -Infinity

0 / 0
# => NaN
```
~~~~

## القسمة الصحيحة

تُستخدم القسمة الصحيحة لتقسيم الأعداد والحصول على الجزء الصحيح من النتيجة.
وستُقرَّب النتيجة دائمًا إلى الأسفل لتصبح `Int`.

```crystal
4.0 // 2
# => 2

4.5 // 2
# => 2
```

~~~~exercism/caution
القسمة على صفر عند استخدام القسمة الصحيحة تُنتج `DivisionByZeroError`.
وهذا يختلف عن القسمة العادية.
~~~~

### باقي القسمة

تُستخدم عملية باقي القسمة لمعرفة ما يتبقّى من عملية القسمة.
ويُرمز إليها بالعامل `%`.

```crystal
5 % 2
# => 1

5.0 % 2
# => 1.0

5 % 3
# => 2
```

~~~~exercism/caution
القسمة على صفر عند استخدام باقي القسمة تُنتج `DivisionByZeroError`.
وهذا يختلف عن القسمة العادية.

```crystal
1 % 0
# Error: Unhandled exception: Division by 0 (DivisionByZeroError)
```
~~~~

## الرفع إلى قوة

يُستخدم الرفع إلى قوة لرفع عدد إلى قوة معيّنة.
ويُستخدم العامل `**` للرفع إلى قوة.
وستكون نتيجة العملية التي تجمع بين `Float` و`Int` من النوع `Float`.

```crystal
2 ** 2
# => 4

2.0 ** 2
# => 4.0
```

## التقريب

تأخذ الطريقة `round` وسيطًا اختياريًا: عدد المنازل العشرية التي يتم التقريب إليها.
وعدد المنازل العشرية الافتراضي هو 0.

```crystal
1.0.round
# => 1

1.5.round
# => 2

1.234.round(2)
# => 1.23
```

### التقريب إلى الأعلى وإلى الأسفل

يمكنك أيضًا التقريب إلى الأعلى أو إلى الأسفل نحو `Int` باستخدام الطريقتين `ceil` و`floor`.
فالطريقة `ceil` تقرّب إلى الأعلى، والطريقة `floor` تقرّب إلى الأسفل.

```crystal
1.0.ceil
# => 1

1.2.ceil
# => 2

1.7.floor
# => 1
```

## الأولوية والأقواس

تسمح Crystal باستخدام الأقواس الهلالية (`()`) التي يمكن استخدامها لتجميع التعبيرات.
وهذا مفيد عندما تريد تغيير ترتيب العمليات.

عند استخدام عدة عوامل حسابية، يكون ترتيب العمليات هو نفسه في الرياضيات، ويُعرف أيضًا باسم [PEMDAS][pemdas].
وهو يتبع ترتيب الأقواس الهلالية (`()`) ثم الأسس (`**`) ثم الضرب (`*`) والقسمة (`/`) ثم الجمع (`+`) والطرح (`-`).

```crystal
2 + 3 - 4 * 4
# => -11

(2 + 3 - 4) * 4
# => 4
```
