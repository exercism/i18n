# مقدمة

يمكن النظر إلى الأعداد الصحيحة ليس فقط كقيم عددية، بل كأنماط من البتات. تحتوي مفردات [`math`][math] في Factor على العمليات القياسية منخفضة المستوى على أنماط البتات هذه، وتضيف مفردات [`math.bitwise`][bitwise] بعض الأدوات المساعدة للتعامل مع القيم ذات العرض الثابت.

## إزاحة البتات

تُزيح `shift ( m n -- m' )` بتات `m`. فقيمة `n` *الموجبة* تُزيح إلى اليسار (ضرب في 2 مع كل خطوة)، وقيمة `n` *السلبية* تُزيح إلى اليمين (قسمة على 2 مع كل خطوة):

```factor
3 2 shift .     ! => 12   (3 << 2)
24 -3 shift .   ! => 3    (24 >> 3)
```

مع الأعداد الصحيحة الموجبة، تُسقط الإزاحة إلى اليمين بتات من الأسفل وتملأ بالأصفار. أما مع الأعداد الصحيحة *السالبة*، فإن `shift` في Factor إزاحة حسابية: فهي تحافظ على بت الإشارة، وتملأ من اليسار نظريًا بنسخ من بت الإشارة. (أعداد Factor الصحيحة ذات دقة غير محدودة، لذا تمتد "اليسار" بقدر ما يلزم.)

## المنطق على مستوى البتات

العمليات المنطقية الأربع الأساسية هي:

```
bitor  ( x y -- z )   ! 1 in either operand
bitand ( x y -- z )   ! 1 in both operands
bitxor ( x y -- z )   ! 1 in exactly one operand
bitnot ( x   -- z )   ! flip every bit
bit?   ( x n -- ? )   ! true when bit at position n is set
```

```factor
0b1011 0b0010 bitor .    ! => 11  (0b1011)
0b1011 0b0010 bitand .   ! => 2   (0b0010)
0b1011 0b0010 bitxor .   ! => 9   (0b1001)
0b1011 bitnot .          ! => -12
0b1011 0 bit? .          ! => t   (low bit is set)
0b1011 2 bit? .          ! => f   (bit 2 is clear)
```

ناتج `bitnot` على `0b1011` هو `-12` لأن أعداد Factor الصحيحة ذات دقة غير محدودة: فقلب بتات `0b1011` هو نظريًا "كلها آحاد مع قلب البتات الأربع الدنيا إلى `0100`"، وهي عند قراءتها كعدد كبير مُوقَّع تساوي `-12`.

## التعامل مع قيمة كأنها N بت

تُقنّع `bits ( x n -- y )` من `math.bitwise` القيمة `x` لتحتفظ ببتاتها `n` الدنيا. هذا هو أسلوب Factor في "إعادة تفسير قيمة كعدد صحيح غير مُوقَّع من N بت":

```factor
-1 8 bits .              ! => 255   (lowest 8 bits of -1 are all 1)
-2144333657 32 bits .    ! => 2150633639
```

هذا المثال الثاني مهم في هذا التمرين. إذا بدأت بقيمة Int32 سالبة بمتمم الاثنين وأردت إزاحتها لليمين "منطقيًا" (بتعبئة الأصفار من اليسار) بمقدار `amount`، فإن الصيغة الاصطلاحية في Factor هي:

```
( value -- shifted )
32 bits  amount neg  shift
```

قنّع القيمة إلى 32 بت أولًا للانتقال إلى التفسير غير المُوقَّع، ثم أزحها. ولأن القيمة المُقنَّعة غير سالبة، فإن `shift` تُسقط البتات من الأسفل وتملأ بالأصفار.
