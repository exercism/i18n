# مقدمة

بما أن Clojure لغة دالّية، فالدوال فيها مواطنون من الدرجة الأولى. هذا يعني أنه يمكن تمريرها إلى دوال أخرى، أو توليدها بواسطة دوال أخرى، تمامًا كما نتعامل مع البيانات. وتأتي Clojure على وجه الخصوص بمجموعة غنية من الدوال عالية الرتبة التي تشتق دوال جديدة انطلاقًا من دوال موجودة. سنستكشف هنا أربع حالات مهمة: `partial` و`comp` و`memoize` و`juxt`. تنتمي هذه الدوال المولِّدة للدوال إلى فئة أوسع من الدوال عالية الرتبة، مثل `map` و`reduce` و`apply` و`complement`، على سبيل المثال لا الحصر، وهي دوال تعمل على دوال موجودة.

## partial

بشكل عام، إذا كانت لدينا دالة موجودة `my-function` بمعاملات `p1, p2, ..., pN`، فيمكننا تثبيت بعض معاملاتها `p1, p2, ..., pM` على قيم ثابتة `v1, v2, ..., vM`. ونفعل ذلك بتطبيق `partial` كما يلي: `(partial my-function v1 v2 ... vM)`.

الناتج دالة جديدة تطبّق الدالة الأصلية `my-function` مع تثبيت `p1=v1, p2=v2, ..., pM=vM`. وتأخذ دالتنا الجديدة كمدخل المعاملات المتبقية `pM+1, pM+2, ..., pN`، التي لم تُحدَّد قيمها عند تطبيق `partial`:

```clojure
(def my-new-function 
  (partial my-function v1 v2 ... vM))
(my-new-function xM+1 xM+2 ... xN)
; => equivalent to (my-function v1 v2 ... vM xM+1 xM+2 ... xN)
```

وكمثال بسيط، لنعرّف دالة `inc-by-9` تزيد بمقدار ثابت هو 9 أيًّا كان ما نمرّره إليها. يمكننا تنفيذ دالة كهذه كما يلي:

```clojure
(def inc-by-9 (partial + 9))
(inc-by-9 5)
; => 14
```

وكمثال ثانٍ، لدينا دالة `generic-greetings` تستخدم اسم الشخص الذي نريد تحيته إلى جانب رسالة نصية أولى ورسالة نصية أخيرة:

```clojure
(defn generic-greetings
  [initial-text final-text name]
  (println (str initial-text name final-text)))
```

ونستخدم `partial` لتثبيت رسالة تحية محددة دائمًا:

```clojure
(def say-hello-and-how-are-you-doing 
  (partial generic-greetings "Hello " ", how are you doing?"))
(say-hello-and-how-are-you-doing "Mary")
; => Hello Mary, how are you doing?
```

## comp

يمكن استخدام `comp` لإنشاء تركيب من أي عدد من الدوال نريد تركيبها. وبشكل عام، تركيب `N` من الدوال `f1, f2, ..., fN` يعني تطبيق هذه الدوال بترتيب متتابع، مع تمرير ناتج الدالة السابقة إلى الدالة التالية. وفي الترميز الرياضي يُعبَّر عن ذلك كما يلي:

```
f1 (f2 (... fN(x)))
```

وفي Clojure، يكافئ ذلك كتابة:
```clojure
(f1 (f2 (... (fN x))))
```

وباستخدام `comp` يمكننا إنشاء دالة جديدة تنفّذ هذا التركيب نيابة عنا:

```clojure
(def my-function-composition 
  (comp f1 f2 ... fN))
(my-function-composition x)
; equivalent to
(f1 (f2 (... (fN x))))
```

وكمثال، لنفترض أننا نريد جمع مجموعة من الأعداد ثم ضرب الناتج في 6. يمكننا فعل ذلك كما يلي:


```clojure
(def six-times-result-sum 
  (comp (partial * 6) +))
(six-times-result-sum 3 2)
; = ((partial * 6) (+ 3 2))
; = (* 6 (+ 3 2))
; = 30
```

## memoize

يتيح `memoize` إعادة استخدام النتائج المحسوبة سابقًا والمرتبطة بمدخل معيّن. فعند تمرير المدخل نفسه، تُرجع الدالة *المخزَّنة* الناتج نفسه دون الحاجة إلى إعادة حسابه من جديد. وهي تستفيد من كون دوال `clojure` *شفافة مرجعيًا* افتراضيًا: فهي تُنتج الناتج نفسه دائمًا عند تمرير المدخل نفسه، ما يجعل إعادة استخدام الحسابات السابقة أمرًا سهلًا.

ولنرَ كيف يعمل ذلك، سنستخدم حالة اصطناعية تنتظر فيها الدالة ثانيتين قبل إنتاج الإخراج، حتى نتمكن بسهولة من مقارنة *زمن الحساب* قبل استخدام `memoize` وبعده.

```clojure
(defn my-time-consuming-fn
    "Original, time-consuming function"
    [x]
    (Thread/sleep 2000)
    (* x 2)
)

; We measure the time it takes for the original function
(time (my-time-consuming-fn 3))
; => "Elapsed time: 2007.785622 msecs"
; => 6

; We define a memoized function
(def my-memoized-fn 
  (memoize my-time-consuming-fn) )

; We call the memoized function and measure its execution time. 
; The first execution actually runs the function, taking
; similar time as the original.
(time (my-memoized-fn 3))
; => "Elapsed time: 2001.364052 msecs"
; => 6

; Subsequent calls reuse the previous computation, taking less
; time. Time is further reduced in additional calls.
(time (my-memoized-fn 3))
; => "Elapsed time: 1.190291 msecs"
; => 6

(time (my-memoized-fn 3))
; => "Elapsed time: 0.043701 msecs"
; => 6

; Changing the input makes the function be executed, so that
; we observe a similar computation time as the original 
(time (my-memoized-fn 4))
; => "Elapsed time: 2000.29306 msecs"
; => 8

; Again, repeating the same input will make the 
; execution be skipped, and the associated output returned
(time (my-memoized-fn 4))
; => "Elapsed time: 0.043701 msecs"
; => 8
```

## juxt

يولّد `juxt` دالة تطبّق الدوال المُمرَّرة إليها بترتيب من اليسار إلى اليمين. والناتج هو متجه تتكون عناصره من نتائج كل دالة على حدة:

```clojure
((juxt f g h) x) ; => [(f x) (g x) (h x)]
```

وكمثال بسيط، نولّد دالة تحسب حاصل ضرب x في عوامل متتالية من 2 إلى 5:
```clojure
((juxt (partial * 2) (partial * 3) (partial * 4) (partial * 5)) 10) ; => [20 30 40 50]
```
