# مقدمة

## تفكيك المصفوفات

صيغة تفكيك المصفوفات في JavaScript طريقة موجزة لاستخراج القيم من مصفوفة وإسنادها إلى متغيرات منفصلة.

في هذا المثال، تُسند كل قيمة في مصفوفة `numberOfMoons` إلى الكوكب المقابل لها:

```javascript
const numberOfMoons = [0, 2, 14];
const [venus, mars, neptune] = numberOfMoons;

neptune;
// => 14
```

باختصار:

- تتيح الصيغة تسمية العناصر _ذات الموضع_ في المصفوفة، وكذلك تبديل المتغيرات عبر إعادة الإسناد.
- صيغة التفكيك متاحة داخل معاملات الدالة، وهي متاحة على أي كيان قابل للتكرار.
- ترك موضع دون تسمية (بعدم كتابة _أي_ اسم متغير) يتجاهل ذلك الموضع بصمت.

## تفكيك الكائنات

توجد في JavaScript أيضًا صيغة تفكيك لاستخراج الخصائص من كائن وإسنادها إلى متغيرات منفصلة.

في هذا المثال، تُستخرج رموز الطقس من الكائن `weather`:

```javascript
const weather = {
  sun: '☀️',
  sun_behind_small_cloud: '🌤️',
  sun_behind_cloud: '⛅',
  sun_behind_large_cloud: '🌥️',
  sun_behind_rain_cloud: '🌦️',
  cloud: '☁️',
  cloud_with_rain: '🌧️',
  cloud_with_snow: '🌨️',
  cloud_with_lightning: '🌩️',
  cloud_with_lightning_and_rain: '⛈️',
};

const { sun, cloud, cloud_with_lightning: thunder } = weather;

sun;
// => '☀️'

cloud;
// => '☁️'

thunder;
// => '🌩️'
```

باختصار:

- تتيح الصيغة استخراج الخصائص، وكذلك استخراجها وإعادة تسميتها.
- صيغة التفكيك متاحة داخل معاملات الدالة.
