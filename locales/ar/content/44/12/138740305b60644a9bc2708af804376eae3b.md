# مقدمة

يتم إنشاء نسخة من صنف باستدعاء [_المُنشئ_][constructor] عبر العامل `new`. المُنشئ طريقة خاصة داخل الصنف، هدفها تهيئة الصنف. في Haxe، تحمل طريقة المُنشئ اسم `new()`.

```haxe
class Library {
  private var books:Int;

  public function new() {
    this.books = 10; // Initialize the books field
  }
}

var library = new Library(); // This calls the constructor
```

تمامًا مثل الطرق العادية، يمكن أن يكون للمُنشئات معاملات. تُخزَّن هذه المعاملات (عادةً) في حقول خاصة ويُوصَل إليها لاحقًا.

```haxe
class Building {
  private var numberOfStories:Int;
  private var totalHeight: Float;

  public function new(numberOfStories:Int, storyHeight:Float) {
    this.numberOfStories = numberOfStories;
    this.totalHeight = storyHeight * numberOfStories;
  }
}

var largeBuilding = new Building(55, 6.2);
```

**لا يمكنك** إنشاء نسخة جديدة من صنف إذا لم يكن له مُنشئ. لذلك لا سبيل آخر سوى استخدام مُنشئ فارغ.

```haxe
class Car {
  public var weight:Int = 1000;

  public function new() {}
}

var myCar = new Car();
```
