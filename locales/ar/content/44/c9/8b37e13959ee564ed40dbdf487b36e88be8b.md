# حول

يستخدم Elixir [_السلوكيات_][behaviours] لتوفير واجهات عامة مشتركة مع تسهيل تنفيذات محددة لكل وحدة تنفّذ السلوك. وأحد هذه السلوكيات هو _سلوك الوصول_.

يوفّر _سلوك الوصول_ واجهة مشتركة لاسترجاع البيانات المعتمدة على المفاتيح من بنية بيانات. وتنفّذه الخرائط وقوائم الكلمات المفتاحية.

تُعرّف وحدة [`Access`][access] الدوال الراجعة المطلوبة لهذه الواجهة، ثم تنفّذ وحدتا [`Map`][map] و[`Keyword`][keyword] الدوال الراجعة المطلوبة: [`fetch/2`][map-fetch] و[`get_and_update/3`][map-get-and-update] و[`pop/2`][map-pop].

لاستخدام السلوك، يمكنك أن تكتب _الأقواس المربعة_ بعد متغيّر مرتبط، ثم تستخدم المفتاح لاسترجاع القيمة المرتبطة به. وتدعم الخرائط المفاتيح من أي نوع، أما قوائم الكلمات المفتاحية فتدعم المفاتيح الذرّية فقط.

```elixir
# Atom as key
my_map = %{key: "my value"}
my_map[:key]
# => "my value"

# String as key
another_map = %{"key" => "my value"}
another_map["key"]
# => "my value"
```

وإذا لم يكن المفتاح موجودًا في بنية البيانات، فستُرجع القيمة `nil`. وقد يكون هذا مصدرًا لسلوك غير مقصود، لأنه لا يرفع خطأً.

```elixir
my_map = %{key: "my value"}
my_map[:wrong_key][:other_wrong_key]
# => nil
```

لاحظ أن `nil` نفسه ينفّذ سلوك الوصول ويُرجع دائمًا `nil` لأي مفتاح.

```elixir
nil[:key]
# => nil
```

لا تنفّذ الهياكل سلوك الوصول.
