# نبذة

`string` في Clojure هي سلسلة نصية من Java، وهي كائن يمثل نصًا غير قابل للتغيير كتسلسل من محارف Unicode (الحروف والأرقام وعلامات الترقيم وما إلى ذلك) وتُعرَّف كما يلي:

```clojure
(def fruit "Apple")
```

توفّر مكتبة `clojure.string` دوالًا قياسية كثيرة للتعامل مع السلاسل النصية ومعالجتها. بالإضافة إلى ذلك، تتوفّر جميع طُرق Java المعتادة للتعامل مع السلاسل النصية عبر التشغيل البيني.
