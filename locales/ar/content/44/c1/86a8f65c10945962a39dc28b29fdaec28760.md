# مقدمة

تُمثَّل القيم المنطقية في Go بالنوع المنطقي المعلن مسبقًا `bool`، ويمكن أن تكون قيمه إما `true` أو `false`. وهو نوع معرَّف.

```go
var closed bool    // boolean variable 'closed' implicitly initialized with 'false'
speeding := true   // boolean variable 'speeding' initialized with 'true'
hasError := false  // boolean variable 'hasError' initialized with 'false' 
```

يدعم Go ثلاثة عوامل منطقية يمكنها تقييم التعبيرات وصولًا إلى قيم منطقية، فتُرجع إما `true` أو `false`.

| العامل    | ما يعنيه                                 |
| ----------- | --------------------------------------------- |
| `&&` (و)  | تكون صحيحة إذا كانت القضيتان صحيحتين.       |
| `\|\|` (أو) | تكون صحيحة إذا كانت قضية واحدة على الأقل صحيحة. |
| `!` (ليس)   | تكون صحيحة فقط إذا كانت القضية خاطئة.    |
