# التثبيت

راجع [System/Installation][install-link] للحصول على تعليمات إعداد الأمور على نظامك.

~~~exercism/caution
إذا كان Java Development Kit (JDK) مثبّتًا على جهازك، فقد يتعارض الملف التنفيذي `jconsole` مع Java Console التي تستخدم الاسم نفسه.

تشمل الحلول الممكنة ما يلي:

- أعد تسمية الملف التنفيذي `jconsole` الخاص بلغة البرمجة J إلى اسم فريد (مثل `jconsole-jlang`).

- عدّل متغيرات البيئة في نظامك أو PATH لإعطاء الأولوية إلى `jconsole` الخاص بلغة البرمجة J.

- **لمستخدمي Linux**، يوجد نص برمجي bash في `bin/install.sh` ينشئ **رابطًا رمزيًا** باسم `ijconsole` في المجلد `/usr/`. يمكنك استخدام هذا الرابط بكتابة `ijconsole` في الطرفية.
~~~

بعد تثبيت J، افتح وحدة تحكم J في الطرفية وأدخل الأوامر التالية لتثبيت إطار عمل اختبارات الوحدة:

```j
  load 'pacman'
  'update' jpkg ''
  'install' jpkg 'general/unittest'
  exit 0
```
