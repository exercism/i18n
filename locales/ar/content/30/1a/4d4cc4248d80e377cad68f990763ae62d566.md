# نبذة

مهيّئات الكائن بديل عن المنشئات. الصياغة هي قائمة من أزواج اسم الحقل=القيمة مفصولة بفواصل، كما يوضّح المثال التالي:

```csharp
public class Person
{
    public string Name;
    public string Address;
}

var person = new Person{Name="The President", Address = "Élysée Palace"};
```

يمكن أيضًا تهيئة المجموعات بهذه الطريقة. وعادةً ما يتم ذلك بقوائم مفصولة بفواصل كما هو موضّح هنا:

```csharp
IList<Person> people = new List<Person>{ new Person(), new Person{Name="Joe Shmo"}};
```

يمكن استخدام هذا الأسلوب (وهذه الصياغة) مع أي صنف يُطبّق `IEnumerable` ويملك طريقة `Add()`.

يمكن إدراج الحقول بأي ترتيب أو حذفها بالكامل.

تستخدم القواميس الصياغة التالية:

```csharp
IDictionary<int, string> numbers = new Dictionary<int, string>{ [0] = "zero", [1] = "one"...};

// or

IDictionary<int, string> numbers = new Dictionary<int, string>{ {0, "zero" }, {1,  "one"}...};
```

يجب أن تكون الحقول المهيّأة متاحة للمستدعي. وعادةً يعني هذا أنها يجب أن تكون `public` أو `internal`.

هناك اتجاه قوي يدعو إلى الثبات بين مصمّمي اللغة وأبرز الممارسين، لذا يُنظر إلى قابلية تغيير الكائنات المهيّأة بهذه الطريقة على أنها عيب. وهناك مقترحات لإضافة بند `init` في الإصدار القادم من اللغة، C# 9، وهو ما قد يعالج هذه المسألة.

- توثيق [مهيّئ الكائن][object-initializers] يشرح كيفية استخدام المهيّئات.
- يقدّم توثيق [مهيّئ المجموعة][collection-initializers] لمحة عن كيفية استخدام المهيّئات مع المجموعات مثل القواميس والمصفوفات.

[object-initializers]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/classes-and-structs/object-and-collection-initializers#object-initializers
[collection-initializers]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/classes-and-structs/object-and-collection-initializers#collection-initializers
