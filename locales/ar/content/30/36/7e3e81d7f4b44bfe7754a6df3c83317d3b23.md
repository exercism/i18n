# ملحق التعليمات

## تنسيق حقل الألغام

يُمثَّل حقل الألغام بسلسلة نصية منتهية بـ null، مع محرف سطر جديد في نهاية كل صف.

ومن الأمثلة على ذلك `"   \n * \n   \n"`

## المسجلات

| المسجل | الاستخدام    | النوع   | الوصف                         |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | إدخال        | عنوان   | سلسلة إدخال منتهية بـ null    |
| `$a1`    | إدخال/إخراج  | عنوان   | سلسلة إخراج منتهية بـ null    |
| `$t0-9`  | مؤقت         | أي نوع  | للتخزين المؤقت                |
