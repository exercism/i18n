# مقدمة

في Clojure، يُشار إلى ربط قيمة باسم ما بمصطلح _متغير_. والمتغيرات العلوية (العامة) تشبه الثوابت في لغات أخرى، لكنها كثيرًا ما يُعاد تعريفها لتسهيل التطوير الديناميكي.

تُعرَّف المتغيرات العلوية باستخدام `def`:

```clojure
(def fingers 10)
```

يمكن استخدام ماكرو `defn` لتعريف دالة تأخذ صفرًا من الوسائط أو أكثر. وتُرجع الدالة دائمًا نتيجة آخر تعبير في جسمها.

```clojure
(defn add [x y]
  (+ x y))
```

يتم استدعاء الدالة بتحديد اسمها وتمرير وسيط لكل معامل من معاملاتها.

```clojure
(def five (add 2 3))
```

لا يمكن استخدام الدوال والقيم في Clojure إلا _بعد_ تعريفها. واستخدام أي منها قبل تعريفه يؤدي إلى خطأ في التصريف.

```clojure
;; Compile error as `add` has not yet been defined
(def seven (add 3 4))

(defn add [x y]
  (+ x y))
```

في Clojure، لا معنى للمسافات البيضاء إلا من ناحية التنسيق.

تُنظَّم دوال Clojure ومتغيراتها في فضاءات أسماء. وفضاء الأسماء يجمع الوظائف المترابطة، ويُعرَّف باستخدام ماكرو `ns`:

```clojure
(ns calculator)

(def pi 3.14)

(defn add [x y]
  (+ x y))
```

يدعم Clojure نوعين من التعليقات. التعليقات أحادية السطر تسبقها علامة `;`، وتُستخدم صيغة `comment` لمنع تقييم كل ما يقع بين `(comment` و `)`.
