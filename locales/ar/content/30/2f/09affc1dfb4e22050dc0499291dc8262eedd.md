# نبذة

`assocs` هو [بروتوكول][assoc-protocol]، وليس نوع بيانات واحدًا. تُطبّقه جداول التجزئة (`H{ }`)، وقوائم الترابط (سلاسل من أزواج `{ key value }`)، وخرائط الأشجار، ومعظم الكلمات في `assocs` قابلة للتبادل فيما بينها.

```factor
USING: assocs ;

H{ } clone "coal" over inc-at
"coal" over inc-at
"wood" over inc-at      ! => H{ { "coal" 2 } { "wood" 1 } }
```

السطح الكامل واسع (التكرار المرتّب، والتخطيط، والتصفية)، لكن معظم العمل على مستوى التمارين لا يتناول إلا مجموعة صغيرة:

| الكلمة      | التأثير                                       |
|-------------|-----------------------------------------------|
| `at`        | `( key assoc -- value/f )`                    |
| `at*`       | `( key assoc -- value ? )` تميّز بين f كقيمة وبين المفتاح الغائب |
| `key?`      | `( key assoc -- ? )`                          |
| `set-at`    | `( value key assoc -- )` ، تُعدّل في مكانها    |
| `change-at` | `( key assoc quot -- )` ، و`quot` هي `( old -- new )` |
| `inc-at`    | `( key assoc -- )` ، تزيد بمقدار `+1` وتُدرج `1` إن كان المفتاح غائبًا |
| `delete-at` | `( key assoc -- )` ، تُعدّل في مكانها          |
| `>alist`    | `( assoc -- pairs )`                          |

‏`sort-keys` و`sort-values` (في `sorting`) ترتّبان قائمة ترابط حسب الحقل المختار.

[assoc-protocol]: https://docs.factorcode.org/content/article-assocs-protocol.html
