# مقدمة
يمكن تقسيم أنواع الأعداد المدمجة في C++ إلى أعداد صحيحة وأعداد عشرية.
الأعداد الصحيحة هي أعداد كاملة مثل `0`، `691`، أو `-2`.
الأعداد العشرية هي أعداد تحتوي على فاصلة عشرية مثل `6.02214076`، `0.1`، أو `-1.616`.

## الأعداد الصحيحة
يوضح المثال التالي تعريف وتهيئة أربعة متغيرات مختلفة

```cpp
int m_morales{9241};              // base 10: 0-9
int a_apaec{0x24CD};              // base 16: 0-9 and A-F
int m_gargan{0b10010000011001};   // base  2: 0-1
int b_reilly{022031};             // base  8: 0-7
                                  // Leading with a 0 not the letter o.
```

عندما تُسند قيمة إلى متغير من النوع `int`، يمكنك فعل ذلك مباشرة بقيمة حرفية.
القيمة الحرفية هي عدد مثبت في الكود مثل `9241`.
توجد قيم حرفية صحيحة مختلفة لعدة أسس للتمثيل.
القيم الحرفية الصحيحة العشرية هي الأكثر شيوعًا وتستخدم الأرقام من `0` إلى `9`.
بإضافة بادئة خاصة، مثل `0x`، يمكن استخدام أسس أخرى.
يعرض المثال أعلاه العدد `9421` بتمثيلاته وبادئاته الأربعة.
جميع المتغيرات مهيأة إلى القيمة نفسها.

لمزيد من التفاصيل حول أنظمة التمثيل المختلفة، ألقِ نظرة على [درس صغير][cpp_numerical_bases].

يمكنك استخدام علامة اقتباس أحادية لفصل الأرقام لتسهيل القراءة.
`9'241` هي نفسها `0b0100'100'0001'1001` أو `92'4'1`.

## الأعداد العشرية

تأتي القيم الحرفية العشرية بنوعين.
بالإضافة إلى الصيغة البديهية `0.0024`، يمكن استخدام الترميز العلمي الخاص بها `2.4e-3`.
النوع العشري الأكثر شيوعًا هو `double`.

## العمليات الحسابية

تدعم C++ العوامل `+`، `-`، `*`، `/`، `(` و`)` و`%` لتكوين تعبيرات.
نتيجة العملية بين عددين صحيحين هي أيضًا عدد صحيح.
ستكون نتيجة `5 / 2` هي `2`.
عندما يكون أحد الأنواع المشاركة نوعًا عشريًا، ستكون النتيجة أيضًا من نوع عشري.
ستكون نتيجة `5.0 / 2` و`5 / 2.0` هي `2.5`.
`%` هو عامل الباقي ويُرجع باقي قسمة صحيحة: `5%3` هو `2`.

## عامل الإسناد

عامل الإسناد يُسند إلى متغير قيمة حرفية.
يحدث دائمًا من اليمين إلى اليسار، وليس العكس أبدًا.

```cpp
int length = 5;
int width = 2;
length = width;
```

هنا تُسند القيمة الصحيحة `5` إلى المتغير `length`.
ثم تُسند القيمة الصحيحة `2` إلى المتغير `width`.
أخيرًا، تُنسخ قيمة `width` إلى المتغير `length` وتضيع القيمة السابقة `5`.
لاحظ أيضًا أننا نُسند قيمة `width` إلى `length` فقط في لحظة عملية الإسناد.
لذلك، إذا تغيرت قيمة `width` في وقت لاحق، فلن يؤثر ذلك على القيمة التي يأخذها `length`.

يمكن دمج عامل الإسناد مع العوامل الأخرى (الحسابية والبتية) المعروفة باسم عوامل `compound assignment` `+=`، `-=`، `*=`، `/=`، `%=`.
تُعدّل هذه العوامل القيمة الحالية للمتغير بإجراء عملية عليها.

```cpp
// we start with 0 people
int people{};
// we need 0 eggs
int eggs{};
// two people joined:
people += 2;
// people is now 2
// let's add 3 eggs per person
eggs += 3 * people;
// eggs is now 6
```

المتغيران `people` و`eggs` مهيآن إلى `0`.
ثم نضيف القيمة الصحيحة `2` إلى القيمة الحالية `0` للمتغير `people` ونُسندها مرة أخرى إلى `people`.
يصبح `people` الآن `2`.
لاحقًا، نضيف `3` بيضات لكل شخص، ليصبح المجموع `6` بيضات.
الآن أضف هذه القيمة `6` إلى القيمة الحالية `0` للمتغير `eggs` ونُسندها مرة أخرى إلى `eggs`.
سيصبح `eggs` الآن `6`.
التعبير المكافئ سيكون `people = people + 2` و`eggs = eggs + (3 * people)`.
