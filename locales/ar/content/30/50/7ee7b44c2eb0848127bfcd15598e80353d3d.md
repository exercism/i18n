# ملحق التعليمات

## تلميحات

لإكمال هذا التمرين، عليك تنفيذ الدالة `score`، التي تأخذ تسلسلًا من *رميات* البولينج وتُرجع النتيجة النهائية أو الخطأ المناسب:

```haskell
score :: [Int] -> Either BowlingError Int

data BowlingError = IncompleteGame
                  | InvalidRoll { rollIndex :: Int, rollValue :: Int }
                  deriving (Eq, Show)
```

ستجد هذه التعريفات موجودة بالفعل، لكن تعريف الدالة متروك لك.

ضع في اعتبارك أن مجموعة الاختبارات تتوقع أن تكون الرميات مرقّمة بدءًا من الصفر.
