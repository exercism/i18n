# الاختبارات

يمكنك تشغيل الاختبارات المرفقة عبر DrRacket أو من سطر الأوامر.

لتشغيل الاختبار عبر DrRacket، ما عليك سوى فتح ملف الاختبار والنقر على زر 'Run' في أعلى اليمين.

لتشغيل الاختبار من سطر الأوامر، شغّله من مجلد التمرين. على سبيل المثال، إذا كانت مجموعة الاختبارات تُسمّى `hello-world-test.rkt`، يمكنك تشغيل الأمر التالي:

```
raco test hello-world-test.rkt
```

وسيُظهر لك ما يلي:

```
raco test: (submod "hello-world-test.rkt" test)
2 success(es) 0 failure(s) 0 error(s) 2 test(s) run
0
2 tests passed
```
