# التعليمات

مهمتك هي بناء ساعة إيقاف لتتبع أوقات اللفات بدقة.

تستخدم ساعة الإيقاف أربعة أوامر (start، stop، lap، reset) لتتبع:

1. الزمن المتتبَّع للفة الحالية
2. أوقات اللفات المسجَّلة سابقًا

تعتمد الأوامر التي يمكن استخدامها على الحالة التي تكون فيها ساعة الإيقاف:

1. Ready: الحالة الأولية
2. Running: تتبع الوقت
3. Stopped: لا تتبع الوقت

| الأمر | حالة البداية | حالة النهاية | التأثير                                                   |
| ------- | ----------- | --------- | -------------------------------------------------------- |
| Start   | Ready       | Running   | بدء تتبع الوقت                                            |
| Start   | Stopped     | Running   | استئناف تتبع الوقت                                        |
| Stop    | Running     | Stopped   | إيقاف تتبع الوقت                                          |
| Lap     | Running     | Running   | إضافة اللفة الحالية إلى اللفات السابقة، ثم إعادة ضبط اللفة الحالية |
| Reset   | Stopped     | Ready     | إعادة ضبط اللفة الحالية ومسح اللفات السابقة               |
