# عنصر نائب

## دوال الوقت

يتطلب هذا التمرين استخدام [دوال الوقت][time-func] في GNU awk.

بالنسبة لدوال تحليل وتنسيق التاريخ والوقت، تأكد من **ضبط علامة UTC**.
لتوضيح ذلك:

```sh
export TZ=Asia/Kolkata
gawk 'BEGIN {
    time = 1234567890
    print strftime("%Y-%m-%d %T", time)     # format for local timezone
    print strftime("%Y-%m-%d %T", time, 1)  # format for UTC
}'
```

يُخرج:

```none
2009-02-14 05:01:30
2009-02-13 23:31:30
```

[time-func]: https://www.gnu.org/software/gawk/manual/html_node/Time-Functions.html
