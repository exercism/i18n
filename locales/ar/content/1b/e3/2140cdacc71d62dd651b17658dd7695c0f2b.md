# الجمل الشرطية

تحتوي Crystal على ما يُعرف بتعبيرات التحكم، وهي تُستخدم للتحكم في الطريقة التي سيعمل بها البرنامج، وتأخذ قيمة صادقة أو كاذبة.
وهناك عوامل يمكن استخدامها لإنشاء قيم صادقة أو كاذبة، وتُعرف باسم [عوامل المساواة والمقارنة][equality-and-comparison].

هناك تعبيرا تحكم رئيسيان يُستخدمان للتحكم في أي كود سيعمل وأي كود لن يعمل.
أي أيضًا في تحديد الفرع الذي سيعمل.

وهما: تعبير `if` وتعبير `unless`.

## عوامل المقارنة

تُستخدم عوامل المقارنة لمقارنة القيم وإرجاع قيمة `true` أو `false`.
تتطلب هذه العوامل قيمتين من النوع نفسه لتتم مقارنتهما.
وإذا لم تكن القيمتان من النوع نفسه، فسيُصدر المترجم خطأ.
فيما يلي قائمة بعوامل المقارنة ومثال على الحالات التي تُرجع فيها قيمة `true`:

| الطريقة | الوصف           | المثال |
| ------ | --------------------- | ------- |
| <      | أصغر من             | 4 < 5   |
| <=     | أصغر من أو يساوي    | 4 <= 4  |
| >      | أكبر من          | 3 > 1   |
| >=     | أكبر من أو يساوي | 2 >= 2  |

## عوامل المساواة

عوامل المساواة مشابهة لعوامل المقارنة، لكنها تُستخدم للتحقق مما إذا كانت قيمتان متساويتين أم لا.

يتحقق العامل `==` مما إذا كانت قيمتان متساويتين، بما في ذلك نوع القيمة.
فإذا كانت القيمتان متساويتين فسيُرجع `true`، وإلا فسيُرجع `false`.
ويمكن للعامل `==` مقارنة أي نوع من القيم بأي نوع آخر.
ويعمل `!=` بالطريقة نفسها، لكنه يُرجع `true` إذا لم تكن القيمتان متساويتين، و`false` إذا كانتا متساويتين.

## عامل سفينة الفضاء

عامل سفينة الفضاء عامل مقارنة فريد، واسمه مشتق من شكله.
وهو فريد من حيث إنه لا يُرجع قيمة صادقة أو كاذبة بل يُرجع عددًا.
يُكتب على الصورة `<=>` ويُستخدم لمقارنة قيمتين.
سيُرجع `1` إذا كانت القيمة اليسرى أكبر من اليمنى، و`-1` إذا كانت اليسرى أصغر من اليمنى، و`0` إذا كانت القيمتان متساويتين.

```crystal
1 <=> 2 # => -1
2 <=> 2 # => 0
3 <=> 2 # => 1
```

## جملة `if` الشرطية

تُستخدم جملة [`if`][if] الشرطية للتحقق مما إذا كان شرط معيّن صادقًا أم كاذبًا.
فإذا كان الشرط صادقًا فسيعمل الكود داخل جملة `if`.
وتنتهي جملة `if` بالكلمة المفتاحية `end`.

```crystal
if 1 == 1
  puts "1 is equal to 1"
end
# => 1 is equal to 1

if 1 > 2
  puts "1 is greater than 2"
end
# => no output
```

## جملة `unless` الشرطية

تعمل جملة [`unless`][unless] الشرطية بشكل مشابه جدًا لجملة `if`، لكنها تشغّل الكود داخل جملة `unless` إذا كان الشرط كاذبًا.

```crystal
unless 1 == 1
  puts "1 is not equal to 1"
end
# => no output

unless 1 > 2
  puts "1 is not greater than 2"
end
# => 1 is not greater than 2
```

## جملة `else` الشرطية

يمكن استخدام جملة `else` مع جملتي `if` و`unless`.
وتُنفَّذ جملة `else` إذا لم يُنفَّذ فرع `if` أو فرع `unless`.

~~~~exercism/warning
حتى وإن كان من الممكن استخدام فرع `else` مع `unless,` فإن ذلك غير مستحسن لأنه يضر بقابلية القراءة.
بدلًا من ذلك، يُوصى باستخدام `if !condition` مع فرع `else`.
~~~~

```crystal
if 1 == 1
  puts "1 is equal to 1"
else
  puts "1 is not equal to 1"
end
# => 1 is equal to 1

unless 1 < 2
  puts "1 is not greater than 2"
else
  puts "1 is greater than 2"
end
# => 1 is greater than 2
```

## جمل "التتابع الشرطي"

يمكن استخدام جملة `elsif` مع جملة `if`.
وتُنفَّذ جملة `elsif` إذا لم يُنفَّذ فرع `if` وكان شرط جملة `elsif` صادقًا.
ويمكن ربط جمل `elsif` معًا، وسيُنفَّذ أول شرط صادق.
ويمكن أيضًا وجود جملة `else` في نهاية جملة `if`، وستعمل إذا لم يكن أي من الجمل السابقة صادقًا.

```crystal
if 1 != 1
  puts "1 is not equal to 1"
elsif 1 > 2
  puts "1 is greater than 2"
else
  puts "1 is not equal to 1 and 1 is not greater than 2"
end
# => 1 is not equal to 1 and 1 is not greater than 2
```

## العامل الثلاثي

تحتوي Crystal على عامل ثلاثي، وهو جملة شرطية مكتوبة في سطر واحد: `condition ? expression_if_truthy : expression_if_falsey`

```crystal
1 == 1 ? puts("1 is equal to 1") : puts("1 is not equal to 1")
# => 1 is equal to 1
```

## استخدام `if` و`unless` كلاحقة

يمكن أيضًا استخدام جملتي `if` و`unless` كـ[لاحقة][if-as-suffix]، وهذا مفيد عندما تريد تشغيل سطر واحد من الكود إذا كان الشرط صادقًا.
ويتم ذلك بوضع جملة `if` أو `unless` بعد الكود الذي تريد تشغيله.

```crystal
puts "1 is equal to 1" if 1 == 1
# => 1 is equal to 1

puts "1 is not equal to 1" unless 1 == 1
# => no output
```

## الأنواع مع الجمل الشرطية

عند الإسناد إلى أنواع مختلفة، سيحمل المتغير النوعين معًا.
وذلك لأن المترجم لا يعرف أي فرع سيُنفَّذ.
وهذا الإسناد المتعدد، المعروف أيضًا بالاتحاد، سيُشرح في مفاهيم لاحقة.
ويمكن رؤية ذلك في المثال التالي:

```crystal
if 1 == 1
  a = 1
else
  a = "1"
end

typeof(a) # => Int32 | String
```
