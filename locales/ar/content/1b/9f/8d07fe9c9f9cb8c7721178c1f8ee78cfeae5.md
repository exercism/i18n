# ملحق التعليمات

## نبذة عن `enum`

تتيح لك عبارة `enum` إنشاء مجموعة من التسميات ذات أنواع صارمة.
يمكنك استخدام هذا التعداد في الكود دون الحاجة إلى التحليل أو التحقق من الأخطاء الإملائية.

يُمثَّل التعداد داخليًا بأعداد صحيحة تبدأ قيمتها من الصفر.
افتراضيًا، تُسند PowerShell إلى أول تسمية في القائمة القيمة صفر، وتُسند إلى بقية التسميات أعدادًا صحيحة متتالية.

مثال:
```pwsh
Enum Fruits {
    APPLE       #default internal value 0
    ORANGE      #default internal value 1
    MANGO       #default internal value 2
}

$myFavFruit = [Fruits]::APPLE
Write-host $myFavFruit => APPLE
``````

لمعرفة المزيد عن `enum` في PowerShell، اطّلع على [وحدة `enum`.](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.core/about/about_enum)
