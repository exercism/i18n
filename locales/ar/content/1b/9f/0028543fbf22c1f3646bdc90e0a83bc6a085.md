# مقدمة

تتبع التعبيرات النمطية في Elixir مواصفة **PCRE** (**P**erl **C**ompatible **R**egular **E**xpressions)، على غرار لغات شائعة أخرى مثل Java أو JavaScript أو Ruby.

توفّر وحدة `Regex` دوالً للتعامل مع التعبيرات النمطية. كما تقبل بعض دوال وحدة `String` التعبيرات النمطية كوسائط.

~~~~exercism/note
يفترض هذا التمرين أنك تعرف بالفعل صياغة التعبيرات النمطية، بما في ذلك فئات الأحرف والمكمِّمات والمجموعات والالتقاطات.

إذا كنت بحاجة إلى تحديث معرفتك بالتعبيرات النمطية، فاطّلع على أحد هذه المصادر: [Regular-Expressions.info](https://www.regular-expressions.info)، [Rex Egg](https://www.rexegg.com/)، [RegexOne](https://regexone.com/)، [Regular Expressions 101](https://regex101.com/)، [RegExr](https://regexr.com/).
~~~~

## السيجيل

الأسلوب الأكثر شيوعًا لإنشاء التعبيرات النمطية هو استخدام سيجيل `~r`.

```elixir
~r/test/
```

لاحظ أن كل سيجيل في Elixir يدعم [أنواعًا مختلفة من المحددات][sigils]، وليس `/` فقط.

## المطابقة

يمكن استخدام العامل `=~/2` لإجراء مطابقة تعبير نمطي تُرجع نتيجة من النوع `boolean`. بدلًا من ذلك، توجد أيضًا دوال `match?/2` في وحدة `Regex` وكذلك في وحدة `String`.

```elixir
"this is a test" =~ ~r/test/
# => true

String.match?("Alice has 7 apples", ~r/\d{2}/)
# => false
```

## الالتقاط

إذا لم يكن فحص منطقي بسيط كافيًا، فاستخدم الدالة `Regex.run/3` للحصول على مصفوفة بكل الالتقاطات (أو `nil` إذا لم تكن هناك مطابقة). العنصر الأول في المصفوفة المُرجَعة هو دائمًا مطابقة للتعبير النمطي بأكمله، والعناصر التالية هي المجموعات المطابَقة.

```elixir
Regex.run(~r/(\d) apples/, "Alice has 7 apples")
# => ["7 apples", "7"]
```

## المعدّلات

يمكن تعديل سلوك التعبير النمطي بإضافة رايات خاصة. عند استخدام سيجيل لإنشاء تعبير نمطي، أضف المعدّلات بعد المحدد الثاني.

من المعدّلات الشائعة:
- `i` - يجعل المطابقة غير حساسة لحالة الأحرف.
- `u` - يفعّل أنماط يونيكود الخاصة مثل `\p` ويجعل فئات الأحرف مثل `\w` و`\s` وغيرها تطابق محارف يونيكود أيضًا.

```elixir
"this is a TEST" =~ ~r/test/i
# => true
```
