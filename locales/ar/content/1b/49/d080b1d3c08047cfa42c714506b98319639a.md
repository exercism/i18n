# الاختبارات

اختر نظام التشغيل الحالي لديك:

* [Windows](##windows)

* [Linux](##linux)

# تشغيل الاختبارات

## Windows

1. افتح Command Prompt.

2. نزّل التمرين الأول:

    ```batchfile
     C:\Users\USERNAME> exercism download --exercise hello-world --track cobol
    ```

3. انتقل إلى مجلد التمرين:

    ```batchfile
     C:\Users\USERNAME> cd C:\Users\USERNAME\exercism\cobol\hello-world
    ```
   
4. شغّل الاختبارات:

    ```batchfile
     C:\Users\USERNAME\exercism\cobol\hello-world> test.ps1
    ```
    *(لا تقلق إذا فشلت الاختبارات عند تشغيلها لأول مرة، فهكذا يبدأ كل تمرين.)*

5. حلّ التمرين. 
    اقرأ ملف `instructions.md` لتعرف كيفية حل التمرين ([اعرضه على GitHub](https://github.com/exercism/cobol/blob/main/exercises/practice/hello-world/.docs/instructions.md)).


حظًا سعيدًا، واستمتع، ومرحبًا بك في مسار COBOL!

----

## macOS

1. افتح نافذة Terminal.

2. نزّل التمرين الأول:

    ```
     $ exercism download --exercise hello-world --track cobol
    ```

3. انتقل إلى مجلد التمرين:

    ```
     $ cd /Users/USERNAME/exercism/cobol/hello-world
    ```

4. شغّل الاختبارات:

    ```
     $ bash test.sh
    ```
    *(لا تقلق إذا فشلت الاختبارات عند تشغيلها لأول مرة، فهكذا يبدأ كل تمرين.)*

    تلميح: إذا ظهرت لك رسالة تفيد بأن `basename` مفقود، فيمكنك استخدام [brew](https://brew.sh/) لتثبيت coreutils. (`brew install coreutils`)

5. حلّ التمرين. 

    اقرأ ملف `instructions.md` لتعرف كيفية حل التمرين ([اعرضه على GitHub](https://github.com/exercism/cobol/blob/main/exercises/practice/hello-world/.docs/instructions.md)).


حظًا سعيدًا، واستمتع، ومرحبًا بك في مسار COBOL!
