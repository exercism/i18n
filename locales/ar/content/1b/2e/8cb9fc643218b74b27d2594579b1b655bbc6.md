# الأصناف

الأصناف مفهوم محوري في [البرمجة الكائنية التوجه][object-oriented-programming].
[في Crystal، كل شيء كائن][everything-is-an-object]، ولكل كائن نوع، ويمكنه الاستجابة لبعض الطرق.
الأصناف مخططات لإنشاء الكائنات، توفّر قيمًا أولية للحالة، مثل المتغيرات، وتطبيقات للسلوك، مثل الطرق.
الكائنات هي نسخ الأصناف التي تحمل جميع متغيرات النسخة والحالات.

## تعريف الصنف

يُعرَّف الصنف باستخدام الكلمة المفتاحية `class`، متبوعة باسم الصنف مكتوبًا بنمط `UpperCamelCase`.

```crystal
class Account
end
```

## إنشاء نسخة

[لإنشاء نسخة من صنف][new-initialize]، استدعِ اسم الصنف باستخدام الطريقة `new`.

```crystal
class Account
end

account = Account.new
```

في المثال أعلاه، المتغير `account` نسخة من الصنف `Account`.

عند إنشاء نسخة، تؤدي طريقة خاصة تُسمى `initialize` دور الباني.
وتُستدعى عند إنشاء النسخة.
يتيح لك الباني تحديد الحالة الأولية للنسخة.
ويمكن للطريقة `initialize` أن تستقبل وسائط تُمرَّر عند إنشاء النسخة.

```crystal
class Account
  def initialize(number)
    5 + number # => 9
  end
end

Account.new(4)
```

~~~~exercism/note
لا تستطيع الطريقة `initialize` إرجاع قيمة يدويًا، بل تُرجع `new` النسخة المُنشأة حديثًا.

```crystal
class Account
  def initialize(number)
    5 + number
  end
end

Account.new(4)
# => #<Account:0x7f5dc33dcea0>
```
~~~~

## طرق النسخة

طريقة النسخة هي طريقة متاحة لنسخة من صنف، ويمكن استدعاؤها على تلك النسخة.
تُعرَّف طرق النسخة باستخدام الكلمة المفتاحية `def`، متبوعة باسم الطريقة.
وتُعرَّف داخل تعريف الصنف.

```crystal
class Account
  def balance
    100
  end
end

account = Account.new
account.balance # => 100
```

## متغيرات النسخة

[متغيرات النسخة][instance-variable] هي متغيرات متاحة في جميع طرق النسخة.
وللوصول إلى متغير نسخة تحتاج إلى تعريف طريقة نسخة.
ويمكن تهيئتها في الطريقة `initialize`.
وتُعرَّف باستخدام البادئة `@`.

```crystal
class Account
  def initialize
    @balance = 100
  end

  def balance
    @balance
  end
end

account = Account.new
account.balance
# => 100
```

يمكن أيضًا تعريف متغيرات النسخة داخل تعريف الصنف.

```crystal
class Account
  @age = 0
end
```

### متغيرات النسخة مع التهيئة

يمكن تهيئة متغيرات النسخة بوسيط يُمرَّر إلى الطريقة `initialize`.
وبما أن Crystal لا تستطيع استنتاج نوع الوسيط المستخدم عند التهيئة، يجب تحديده.
إذا أردت قراءة المزيد عن هذا، يمكنك الاطلاع على: [استنتاج النوع][type-inference].
ولتحديد نوع المتغير يمكنك استخدام الرمز `:`، متبوعًا بالنوع.
على سبيل المثال، إذا أردت إنشاء متغير نسخة باسم `balance` من النوع `Int32`، يمكنك فعل ما يلي: `@balance : Int32`.
أو إذا أردت إنشاء متغير نسخة باسم `raining` من النوع `Bool`، يمكنك فعل ما يلي: `@raining : Bool`.

هناك عدة أساليب لتنفيذ ذلك، إما بتعريف الوسيط مع نوعه في الطريقة `initialize` ثم إسناد متغير النسخة إلى الوسيط، كما في المثال التالي:

```crystal
class Account
  def initialize(balance : Int32)
    @balance = balance
  end

  def balance
    @balance
  end
end

account = Account.new(1)
account_2 = Account.new(5)

account.balance
# => 1

account_2.balance
# => 5
```

وأسلوب آخر هو تعريف نوع متغير النسخة في تعريف الصنف بالصيغة: `@<variable> : <Type>`، كما في المثال التالي:

```crystal
class Weather

  @raining : Bool

  def initialize(raining)
    @raining = raining
  end

  def raining
    @raining
  end
end

weather = Weather.new(true)
weather.raining
# => true
```

### صيغة مختصرة لتهيئة متغيرات النسخة

توجد صيغة مختصرة لتهيئة متغيرات النسخة في وسائط الطريقة `initialize`، باستخدام الصيغة نفسها `@<variable> : <Type>`.
وهي تجمع بين إسناد متغير النسخة إلى الوسيط وتعريف نوع متغير النسخة.

```crystal
class Account
  def initialize(@balance : Int32)
  end
end
```

## تعديل متغيرات النسخة

يمكن للطرق تعديل متغيرات النسخة.
ويمكن استدعاء هذه الطرق على نسخة الصنف.
وعندما تُعدّل طريقة متغير نسخة، يكون هذا التغيير متاحًا فقط في نسخة الصنف التي استدعيتها عليها.

```crystal
class Account
  def initialize(balance : Int32)
    @balance = balance
  end

  def withdraw(amount)
    @balance -= amount
  end

  def balance
    @balance
  end
end

account = Account.new(10)
account_2 = Account.new(10)
account.balance
# => 10

account_2.balance
# => 10

account.withdraw(5)
account.balance
# => 5

account_2.balance
# => 10
```

## طرق الصنف

[طرق الصنف][class-methods] هي طرق تُعرَّف لصنف وليس لنسخه.
وتوفّر أسلوبًا لإنشاء طرق لا تعتمد على حالة النسخة.
وتُعرَّف باستخدام الكلمة المفتاحية `def`، متبوعة بـ `self.<method name>`.
و`self` مرجع إلى نطاق الأسماء الذي يُستدعى منه `self`.
وفي هذه الحالة، يشير إلى الصنف `Account`.
وسيكون الأمر مماثلًا لو كتبت `Account.`، لكن `self.` هو الأسلوب المفضّل.

```crystal
class Account
  def self.balance
    100
  end
end

Account.balance
# => 100
```
