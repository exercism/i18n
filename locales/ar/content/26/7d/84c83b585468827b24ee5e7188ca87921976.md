# التعليمات

تُضبط الكمان بالأذن استنادًا إلى نغمة مرجعية. تتباعد الأوتار عن بعضها مسافة كبيرة في الطبقة الصوتية، والأعداد المستخدمة ليست أعدادًا صحيحة.

تُوضع المهام الخمس كلها داخل الصنف `TUNING_THE_STRINGS`.

## 1. أوكتاف للأعلى

النغمة الأعلى بأوكتاف تساوي ضعف التردد.

```sather
TUNING_THE_STRINGS::octave_up(440.0d)
-- => 880.0d
```

## 2. أوكتاف للأسفل

النغمة الأدنى بأوكتاف تساوي النصف.

```sather
TUNING_THE_STRINGS::octave_down(440.0d)
-- => 220.0d
```

## 3. المنتصف بينهما

إذا أُعطيت ترددان، فأرجع التردد الذي يقع في المنتصف بينهما تمامًا.

```sather
TUNING_THE_STRINGS::midpoint(440.0d, 442.0d)
-- => 441.0d
```

## 4. ما مقدار الانحراف؟

عندما تكون نغمتان متقاربتين لكن غير متطابقتين، تسمع ضربة واحدة كل ثانية مقابل كل دورة تفترقان بها. أرجع مقدار الفرق بين الترددين. الإجابة ليست سالبة أبدًا، أيًّا كانت النغمة الأعلى.

```sather
TUNING_THE_STRINGS::beats_per_second(441.5d, 440.0d)
-- => 1.5d
```

## 5. توزيع وقت التدريب

إذا أُعطيت عددًا من الدقائق وعددًا من العازفين، فكم دقيقة يحصل عليها كل واحد؟ الدقائق والعازفون أعداد صحيحة، لكن الإجابة قد لا تكون كذلك.

```sather
TUNING_THE_STRINGS::minutes_each(45, 2)
-- => 22.5d
```
