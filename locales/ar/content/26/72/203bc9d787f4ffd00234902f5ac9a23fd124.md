# حول

يمكن جعل معامل الطريقة اختياريًا عن طريق إسناد قيمة افتراضية له. عند استدعاء طريقة ذات معاملات اختيارية، لا يلزم المستدعي تمرير قيمة لها. إذا لم تُمرَّر أي قيمة لمعامل اختياري، فستُستخدم قيمته الافتراضية.

يجب أن تكون المعاملات الاختيارية في نهاية قائمة المعاملات؛ ولا يمكن أن تأتي بعدها معاملات غير اختيارية.

```haxe
class Card {
  static function newYear(year = 2021):String {
    return "Happy " + year;
  }
}

Card.newYear(); // Happy 2020
Card.newYear(1990); // Happy 1990
```

يمكن ضبط المعامل الاختياري على `null` باستخدام العامل `?` قبل اسم المتغير:

```haxe
function newYear(?year:Int) {
  if (year != null)
    return "It's " + year;
  return "Year is null";
}

newYear(); // Year is null
```
