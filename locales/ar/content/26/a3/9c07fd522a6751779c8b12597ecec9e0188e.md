# التعليمات

مثل أي شخص لديه وظيفة تقريبًا، تحتاج Layla، الكائن الفضائي من Lisp، أحيانًا إلى إعداد تقارير لإخبار الآخرين بمعلومات. وهي تطلب منك أن تساعدها في تنسيق البيانات التي لديها لهذه التقارير.

## 1. تنسيق القيم الربعية

أول ما تحتاجه Layla هو دالة: `format-quarter-value` تأخذ معاملين: الربع السنوي والقيمة، وتنسّقهما لإعداد تقرير. وينبغي أن تُقيّم إلى سلسلة نصية.

```lisp
(format-quarter-value "last" 3.14) ; => "The value last quarter: 3.14"
(format-quarter-value "this" 0) ; => "The value this quarter: 0"
```

## 2. تقرير الربعين

تشكرك Layla على دالة `format-quarter-value` وتقول إنها ستكون مفيدة جدًا في الدالة *التالية* المطلوبة.

يحتاج التقرير التالي إلى عرض الربع والقيمة لكل من الربعين مطبوعين على سطرين.

كما يجب أن يذهب الإخراج إلى المجرى المقدَّم كوسيط أول.

على سبيل المثال: `(format-two-quarters t "last" 3.14 "this" 0)` سينتج ما يلي على الإخراج القياسي:

```

The value last quarter: 3.14
The value this quarter: 0

```

لاحظ الأسطر الفارغة حوله.

## 3. مقروء للبشر مقابل مقروء لكائنات Lisp الفضائية

نسيت Layla أن تخبرك أن كائنات Lisp الفضائية تحب رؤية القيم بطريقة يمكن قراءتها كبيانات Lisp. لذا تحتاج كائنات Lisp الفضائية إلى دالة جديدة يمكن قراءتها كبيانات Lisp (مرة أخرى إلى المجرى المحدد):

```lisp
(format-two-quarters-for-reading nil "last" 3.14 "this" 0) ; =>

"(\"The value last quarter: 3.14\" \"The value this quarter: 0\")"
```
