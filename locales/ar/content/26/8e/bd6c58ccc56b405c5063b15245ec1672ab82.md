# نبذة

في Go 1.18، أضافت لغة Go دعمًا **للأنواع العامة**.
تتيح لك الأنواع العامة كتابة دوال وبُنى بيانات تعمل مع أنواع مختلفة دون تكرار الكود.

## لماذا الأنواع العامة؟

في Go، تعمل الدوال والأنواع عادةً مع أنواع محددة، مثل `int` أو `string`.
قبل الأنواع العامة، كان أمامك خياران لدعم أنواع متعددة.
أولًا، كان بإمكانك كتابة عدة دوال بأسماء مختلفة، مثل `SumInts` و`SumFloats`.
ينشئ هذا الأسلوب كودًا مكررًا يصعب صيانته.
ثانيًا، كان بإمكانك استخدام الواجهة الفارغة `any` (`interface{}`).
غير أن الواجهة الفارغة تلغي فحوص النوع في وقت الترجمة وتتطلب تأكيدات للنوع في وقت التشغيل.
تحل الأنواع العامة هذه المشكلة بتوفير أمان النوع مع تجنب تكرار الكود.

## الدوال العامة

تُعرّف دالة عامة بإضافة **معاملات النوع** بين الأقواس المربعة `[...]` بعد اسم الدالة.
إليك مثالًا لدالة عامة تُرجع شريحة معكوسة:

```go
func Reverse[T any](s []T) []T {
    result := make([]T, len(s))
    for i, v := range s {
        result[len(s)-1-i] = v
    }
    return result
}
```

في هذا المثال، `T` معامل نوع.
يمكنك التفكير في `T` كعنصر نائب عن نوع حقيقي.
الكلمة المفتاحية `any` داخل الأقواس المربعة هي **قيد نوع**.
يخبر القيد المترجم بالأنواع المسموح بها لـ`T`.
هنا، تعني `any` أن `T` يمكن أن يكون أي نوع.

### استدعاء الدوال العامة

يمكنك استدعاء دالة عامة بتمرير النوع الفعلي بين الأقواس المربعة.
يُسمى هذا النوع الفعلي **وسيط النوع**.

```go
numbers := []int{1, 2, 3}
reversedNumbers := Reverse[int](numbers)
```

في معظم الحالات، يستطيع مترجم Go استنتاج النوع تلقائيًا من وسائط الدالة.
تُسمى هذه الميزة **استنتاج النوع**.
مع استنتاج النوع، لا تحتاج إلى كتابة وسيط النوع بين الأقواس المربعة.

```go
words := []string{"apple", "banana"}
reversedWords := Reverse(words)
```

في هذا المثال، يرى المترجم أن `words` شريحة من السلاسل النصية، فيستنتج أن `T` هو `string`.

## قيود النوع

يجب أن يكون لكل معامل نوع قيد.
يحدد القيد الأنواع التي يمكنك استخدامها كوسائط نوع.
كما يحدد القيد العمليات المسموح لك بتنفيذها على قيم ذلك النوع.

### القيد `any`

يتيح القيد `any` أي نوع.
في Go، `any` اسم مستعار للواجهة الفارغة `interface{}`.
ولأن `any` يتيح كل نوع، فلا يمكن للدالة تنفيذ سوى العمليات التي تعمل مع جميع أنواع Go.
على سبيل المثال، إذا كانت لديك قيمتان من النوع `any` تحملان شرائح، فلا يمكن مقارنتهما بـ`==` لأن الشرائح لا يمكن مقارنتها باستخدام `==`.

### القيد `comparable`

توفر Go قيدًا مدمجًا يُسمى `comparable`.
يتيح القيد `comparable` أي نوع يدعم العاملين `==` و`!=`.
تشمل الأنواع القابلة للمقارنة القيم المنطقية والأعداد والسلاسل النصية والمؤشرات والقنوات والبُنى أو المصفوفات المكونة من أنواع قابلة للمقارنة.

إليك مثالًا لدالة تتحقق مما إذا كانت شريحة تحتوي على عنصر معين:

```go
func Contains[T comparable](elems []T, target T) bool {
    for _, elem := range elems {
        if elem == target {
            return true
        }
    }
    return false
}
```

ولأن `T` يستخدم القيد `comparable`، فإن استخدام `elem == target` صالح.
إذا استبدلت `comparable` بـ`any`، فسيبلغ المترجم عن خطأ.

### قيود مخصصة باستخدام مجموعات الأنواع في الواجهات

بدءًا من Go 1.18، يمكن للواجهات تعريف مجموعات من الأنواع إضافة إلى الطرق.
يمكنك استخدام علامة الأنبوب `|` لسرد الأنواع المسموح بها في واجهة.

```go
type Number interface {
    int | int64 | float64
}
```

يمكنك الآن استخدام `Number` كقيد لدالة:

```go
func Double[T Number](value T) T {
    return value * 2
}
```

ولأن جميع الأنواع في `Number` تدعم العامل `*`، تسمح Go بـ`value * 2` داخل الدالة.

### تقريب النوع الأساسي `~`

أحيانًا تُنشئ تعريف نوع مخصصًا انطلاقًا من نوع أولي:

```go
type MyInt int
```

القيد `Number` المعرّف أعلاه لا يسمح إلا بالأنواع المطابقة تمامًا `int` و`int64` و`float64`.
إذا مررت قيمة من النوع `MyInt` إلى `Double`، فسيُصدر المترجم خطأً لأن `MyInt` لا يطابق `int`.
للسماح بأي نوع نوعه الأساسي `int`، أضف علامة التلدة `~` قبل النوع:

```go
type Number interface {
    ~int | ~int64 | ~float64
}
```

الآن يمكنك استخدام `Double` مع قيم من النوع `MyInt`.

### القيد `cmp.Ordered`

توفر المكتبة القياسية القيد `cmp.Ordered` في [حزمة `cmp`][doc-cmp].
يتيح القيد `cmp.Ordered` أي نوع يدعم عوامل المقارنة `<` و`<=` و`>` و`>=`.

## الأنواع العامة

يمكنك أيضًا استخدام معاملات النوع لتعريف أنواع عامة، مثل البُنى.
إليك مثالًا لبنية بيانات `Stack` عامة:

```go
type Stack[T any] struct {
    elements []T
}

func (s *Stack[T]) Push(v T) {
    s.elements = append(s.elements, v)
}

func (s *Stack[T]) Pop() (T, bool) {
    if len(s.elements) == 0 {
        var zero T
        return zero, false
    }
    lastIndex := len(s.elements) - 1
    top := s.elements[lastIndex]
    s.elements = s.elements[:lastIndex]
    return top, true
}
```

عند تعريف متغير من نوع عام، يجب عليك تمرير وسيط النوع بين الأقواس المربعة:

```go
intStack := Stack[int]{}
intStack.Push(42)

stringStack := Stack[string]{}
stringStack.Push("hello")
```

لا يعمل استنتاج النوع إلا مع الدوال العامة.
يجب عليك دائمًا تحديد وسيط النوع عند إنشاء قيم من نوع عام.

## متى تستخدم الأنواع العامة

الأنواع العامة ميزة قوية، لكنك لست بحاجة إلى استخدامها في كل مشكلة.

استخدم الأنواع العامة في حالات كهذه:
- عندما تبني بُنى بيانات، مثل الأشجار أو القوائم المترابطة أو الذاكرات المؤقتة، تعمل مع أي نوع عنصر.
- عندما تكتب دوال مساعدة تعمل على شرائح أو خرائط من أي نوع، مثل التصفية أو الترتيب أو البحث.
- عندما تحتاج إلى التنفيذ نفسه تمامًا لعدة أنواع، وتريد أمان النوع في وقت الترجمة.

استخدم الواجهات بدلًا من ذلك في حالات كهذه:
- عندما يهمك السلوك والطرق أكثر من نوع البيانات الأساسي.
  على سبيل المثال، إذا أردت قراءة بيانات من مصادر متنوعة الأنواع (ملفات، شبكة، TTY) ومعالجتها، فستستخدم `func Process(src io.Reader)` بدلًا من `func Process[T](src T)`.
- عندما تتطلب أنواع مختلفة تنفيذات طرق مختلفة لإنجاز عملها.
