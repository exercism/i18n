# نبذة

[الإغلاقات][closures] في Swift هي كتل مستقلة من الكود يمكن تمرير معاملات إليها لتحفيز حسابها وإرجاع قيم. كما تلتقط الإغلاقات قيمًا من بيئتها وتستخدمها في حساباتها. ولأنها مستقلة بذاتها، يمكن تمريرها في البرنامج مثل بقية القيم أو إسنادها إلى ثوابت ومتغيرات.

قد تبدو الإغلاقات شبيهة جدًا بدوال Swift، وهي كذلك فعلًا، ولسبب وجيه. فالدوال في Swift حالات خاصة من الإغلاقات، ويُشترط أن يكون لها اسم، وتُعرَّف باستخدام صياغة مختلفة قليلًا.

ورغم أن الدوال في Swift هي إغلاقات من الناحية التقنية، فحين يشير الناس إلى «الإغلاقات» في Swift فهم يقصدون [تعبيرات الإغلاق][closure-expressions]. تُكتب تعبيرات الإغلاق على هيئة قائمة معاملات يتبعها نوع الإرجاع ثم الكلمة المفتاحية `in` ثم جسم الإغلاق، ويحتويها جميعًا زوج من الأقواس المعقوفة:

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}
```

هذا يعرّف تعبير إغلاق من النوع `(Double, Double) -> Double`، ويمكن تنفيذه بطريقة مشابهة لدالة من هذا النوع، أي بتطبيقه على معاملات من النوع المناسب:

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}(10.0, 15.0)
// returns 12.5
```

ولأن كتابة تعبير الإغلاق كاملًا في كل مرة نريد تنفيذه ليست مريحة كثيرًا، يمكن إسناد الإغلاقات إلى أسماء، مثل أي قيمة أخرى في Swift. وبعد ذلك يمكن استدعاؤها بتطبيق الاسم على المعاملات:

```swift
let mean = { (a: Double, b: Double) -> Double in
  (a + b) / 2.0
}

mean(13.0, 100.0)
// returns 56.5
```

وكما رأينا أعلاه، يمكن للإغلاقات، مثل الدوال العادية، أن تحذف الكلمة المفتاحية `return` إذا كان جسم الإغلاق تعبيرًا واحدًا.

في أغلب الأحيان تُستخدم الإغلاقات مع الدوال ذات الرتبة الأعلى، إما بتمريرها كمعاملات أو بإرجاعها كنتائج:

```swift
[11, 75, 3, 99, 53].contains(where: { (x: Int) -> Bool in x > 100 })
// returns false

["apple", "ball", "carrot"].sorted(by: { (s1: String, s2: String) -> Bool in s1.count < s2.count })
// returns ["ball", "apple", "carrot"]

func makeAdder(base: Int) -> (Int) -> Int {
  { (x: Int) -> Int in base + x }
}
```

## استنتاج أنواع الإغلاق

عندما يمكن [استنتاج نوع الإرجاع أو أنواع المعاملات من السياق][inferring-closure-types]، يصح حذفها من تعبير الإغلاق. كذلك، إذا أمكن حذف أنواع المعاملات، أمكن حذف الأقواس الهلالية المحيطة بأسماء المعاملات أيضًا:

```swift
let mean: (Double, Double) -> Double = { a, b in a + b / 2.0 }

func makeAdder(base: Int) -> (Int) -> Int {
  { x in base + x }
}

["apple", "ball", "carrot"].sorted(by: { s1, s2 in s1.count < s2.count })
```

- في المثال الأول، يمكن استنتاج النوع من التوصيف الموجود على الثابت `mean`.
- وفي الثاني، يعرف المترجم من تعريف `makeAdder` أن `base` عدد صحيح وأن الدالة المُرجعة يجب أن تكون من النوع `(Int) -> Int`. ومن هناك يستطيع التحقق من أنه إذا كان `x` من النوع `Int` فإن الإغلاق سيكون من النوع `(Int) -> Int`، وبالتالي يمكننا حذف توقيع النوع في الإغلاق لأن `(Int) -> Int` هو التوقيع الصالح الوحيد الممكن أن يكون للإغلاق.
- والمثال الثالث مشابه، لكن المترجم يحتاج إلى الحصول على بعض معلومات النوع من المصفوفة التي تُستخدم معها الطريقة. فهو يعرف أن الطريقة `sorted(by:)` تأخذ كمعامل إغلاقًا له معاملان من نفس نوع عناصر المجموعة التي تُرتَّب، ويُرجع قيمة منطقية `Bool`، لذا يستطيع المترجم أن يستنتج أن نوع إرجاع الإغلاق يجب أن يكون `Bool`. ولأن الطريقة تُستخدم مع مصفوفة من السلاسل النصية، يستطيع أن يحدد أن نوعي المعاملين `s1` و`s2` يجب أن يكونا `String` معًا.

## قيود الإغلاقات

كما ذُكر أعلاه، تتشابه الدوال والإغلاقات كثيرًا في Swift، لكن هناك بعض الفروق المهمة:

- لا يجوز للإغلاقات استخدام تسميات الوسائط الخارجية. فلا توجد طريقة لتعريفها، ومحاولة استخدام اسم معامل عند استدعاء الإغلاق تؤدي إلى خطأ:

```swift
let add5 = { x in x + 5 }
add5(x: 10)
// Error: Extraneous argument label 'x:' in call
```

- لا يمكن أن يكون لمعاملات الإغلاق قيمة افتراضية.
- يمكن أن تكون معاملات الإغلاق معاملات متغيرة العدد، لكن يجب أن يكون لها اسم وتوصيف للنوع.
