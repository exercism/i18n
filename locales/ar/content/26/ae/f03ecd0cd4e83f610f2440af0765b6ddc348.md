# ملحق التعليمات

## الكلمات

نفّذ:

- `grep ( pattern flags files -- lines )`

`pattern` هو سلسلة البحث النصية، و`flags` مصفوفة من صفر أو أكثر من سلاسل الأعلام النصية `"-n"` و`"-l"` و`"-i"` و`"-v"` و`"-x"`، و`files` مصفوفة من اسم ملف واحد أو أكثر. أرجِع الأسطر المطابقة (مع أي بادئات مطلوبة لأسماء الملفات وأرقام الأسطر) على هيئة مصفوفة من السلاسل النصية.

عند تمرير العلم `-l`، أرجِع مصفوفة بأسماء الملفات التي تحتوي على تطابق واحد على الأقل.

## قراءة الملفات

اقرأ أسطر الملف باستخدام `file-lines` مع تمرير ترميز:

```factor
USING: io.encodings.utf8 io.files ;

"iliad.txt" utf8 file-lines
! => { "Achilles sing, O Goddess! Peleus' son;" ... }
```

تُرفَق ملفات البيانات الثلاثة (`iliad.txt` و`midsummer-night.txt` و`paradise-lost.txt`) مع التمرين في مجلد العمل، لذا تكفي قراءتها بالاسم مباشرة.
