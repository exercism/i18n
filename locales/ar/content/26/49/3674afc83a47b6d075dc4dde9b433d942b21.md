# التثبيت

يعتمد هذا المسار على [Wren Console][wren-console] في كل مكان لتوفير بيئة تشغيل محلية لـ Wren. وهذا يعني أننا نفترض أن كل تنفيذ لـ Wren على حاسوبك سيتم باستخدام [Wren Console][wren-console]. يُرجى عدم الخلط بينه وبين <abbr title="واجهة سطر الأوامر (command-line interface)">CLI</abbr> الرسمي الخاص بـ Wren. في عالم مثالي كان يمكنك استخدام بيئة التشغيل تلك، لكنها حاليًا [تواجه](https://github.com/wren-lang/wren-cli/pull/74) [عدة](https://github.com/wren-lang/wren/pull/1006) [مشكلات](https://github.com/wren-lang/wren-cli/issues/108) [مختلفة](https://github.com/wren-lang/wren-cli/pull/105)، ما يجعلها خيارًا أقل من مثالي لتعلّم Wren مع Exercism.

Wren Console مشتقّ من Wren CLI، ويحلّ هذه المشكلات، ويضيف ميزات تجعل تجربة تعلّمك أكثر سلاسة. لا تقلق، فمعرفة لغة Wren والمفاهيم التي ستتعلّمها هنا ستنطبق أينما أردت استخدام Wren في المستقبل.

## نظرة عامة على التثبيت

- ثبّت Git للحصول على الأمر `git`
- ثبّت [Wren Console][wren-console] للحصول على الأمر `wrenc`

### تثبيت Git

ستحتاج إلى تثبيت الملف التنفيذي `git` وأن يكون ضمن مسارك. فهكذا يثبّت Wren Package الحزم (مثل مجموعة الاختبارات التي ستحتاجها لاختبار تمارينك، وغيرها).

- **Windows** - يُعدّ [تنزيل Git](https://git-scm.com/download/win) الرسمي نقطة بداية جيدة.
- **Linux** - سيساعدك مدير الحزم المفضّل لديك.
- **Mac** - جميع إصدارات Mac OS الحديثة تضمّن `git` مباشرةً دون أي إعداد.

يمكنك التأكد من تثبيت Git باستخدام `git --version`:

```
$ git --version
git version 2.31.1
```

لا تقلق إن لم يتطابق رقم الإصدار بالضبط، فالأمر عادةً ليس بهذه الأهمية.


### تثبيت Wren Console

#### Windows

على الأرجح ستريد [تنزيل أحدث إصدار][releases] من GitHub. بعد ذلك ستحتاج إلى فك ضغط الملف ونسخ الملف التنفيذي `wrenc` إلى مسارك.

يمكنك أيضًا [البناء من المصدر][build-from-source] باستخدام Visual Studio.

#### Linux

يمكنك [تنزيل أحدث إصدار][releases] من GitHub أو [البناء من المصدر][build-from-source].

```sh
wget -c https://github.com/joshgoebel/wren-console/releases/download/v0.3.1/wren-console-v0.3.1-linux.tar.gz
tar xzf wren-console-v0.3.1-linux.tar.gz
```

وتأكد من توفّره في `PATH` لديك.

```sh
cp bin/wrenc /usr/local/bin/
```


#### Mac

أسهل طريقة للتثبيت هي استخدام tap وformula الخاصين بـ Exercism على [Homebrew][homebrew]:

```
brew tap exercism/wren
brew install wren-console
```

بدلًا من ذلك، يمكنك [تنزيل أحدث إصدار][releases] من GitHub وتثبيته يدويًا كما هو موضّح في تعليمات Linux. كما أن البناء من المصدر بسيط جدًا إن كنت على دراية بمثل هذه الأمور.

### اختبار التثبيت

بعد أن تعتقد أنك ثبّت الملف التنفيذي بشكل صحيح، من الجيد أن تختبر ما إذا كان كل شيء يعمل.

1. افتح _نافذة طرفية_ (`Terminal`، `cmd`، `Powershell`، `bash`، ...)
2. نفّذ الأمر `wrenc -v`

ينبغي أن ترى إصداري `wrenc` وWren مدرجين:

```
wrenc v0.3.1 (wren v0.4.0)
```

**ملاحظة**: من المهم أن تفتح نافذة طرفية _جديدة_. قد لا تكون نوافذ الطرفية المفتوحة قد حُدّثت بعد اكتمال التثبيت. وهذا يعني أن نوافذ الطرفية المفتوحة لا تعرف أن برنامجًا جديدًا قد ثُبّت.

> _**مساعدة**_: `'wrenc' is not recognised`
>
> على الأرجح لم تضع `wrenc` في مسار النظام لديك... في MacOS وLinux يمكنك تعديل مسارك بإضافة ما يلي إلى أي من
> `~/.bash_profile` أو `~/.zshrc`:
>
> ```bash
> export PATH=/path/to/your/wrenc/:$PATH
> ```
> **لا أعرف إن كان أي من هذا صحيحًا.**
> في Windows، افتح قائمة ابدأ وابحث عن "environment variables". ستحتاج
> إلى تعديل مدخل `PATH` و_إضافة_ مسار ملفات `wrenc` التنفيذية هنا.
> عادةً ما توجد هذه في `C:\Program Files\nodejs`. إذا تصفّحت هذا الموقع
> باستخدام `File Explorer`، فستجد `node.exe` و`npm.bat` و`npx.bat`.
>
> أغلق أي نوافذ طرفية مفتوحة وافتح نافذة جديدة.

## متطلبات التمرين

يُرجى اتباع [هذه التعليمات][cli-walkthrough] لتنزيل CLI الخاص بـ `exercism` لنظام التشغيل لديك.

بعد إعداد CLI وتهيئته بالكامل، نزّل التمرين الأول، `hello-world`:

```bash
$ exercism download --exercise=hello-world --track=wren
```

بعد ذلك، يحتاج كل تمرين إلى بعض حزم Wren لتشغيل الاختبارات. يمكن تثبيتها
بتشغيل هذا الأمر داخل مجلد التمرين:

```bash
$ wrenc package.wren install
```
