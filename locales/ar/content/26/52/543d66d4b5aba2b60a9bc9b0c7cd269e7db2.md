# مقدمة

الطريقة دالة لها معامل خاص هو _المستقبِل_.
يظهر المستقبِل في قائمة معاملات خاصة به بين الكلمة المفتاحية `func` واسم الطريقة.

```go
func (receiver type) MethodName(parameters) (returnTypes) {

}
```

لا يمكنك تعريف طريقة إلا بمستقبِل نوعه معرَّف في نفس الحزمة التي تُعرَّف فيها الطريقة.

```go
type Person struct {
    Name string
}

func (p Person) Greetings() string {
	return fmt.Sprintf("Welcome %s!", p.Name)
}

s := Person{Name: "Bronson"}
fmt.Println(s.Greetings())
// Output: Welcome Bronson!
```

هناك نوعان من المستقبِلات: مستقبِلات القيمة ومستقبِلات المؤشر.

الطرق ذات مستقبِل القيمة تعمل على نسخة من القيمة الممرَّرة إليها، أي أن أي تعديل يجري على المستقبِل داخل الطريقة لا يراه المستدعي.

يمكنك تعريف طرق بمستقبِلات مؤشر لتعديل القيمة التي يشير إليها المستقبِل.
ويُفعل ذلك بوضع `*` قبل اسم النوع؛ فمثلًا مع النوع `rect` يُعرَّف مستقبِل المؤشر على الصورة `*rect`.
وهذه التعديلات يراها مستدعي الطريقة أيضًا.

```go
type rect struct {
	width, height int
}
func (r *rect) squareIt() {
	r.height = r.width
}

r := rect{width: 10, height: 20}
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 20

r.squareIt()
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 10

```
