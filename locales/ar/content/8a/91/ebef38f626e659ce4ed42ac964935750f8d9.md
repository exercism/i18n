# مقدمة

يبني هذا التمرين على العمليات الحسابية على الأعداد الصحيحة من [لازانيا ليا اللذيذة][lasagna]. ستتعامل هنا مع الأعداد العشرية وتختار كلمة القسمة المناسبة للمهمة.

## الأعداد الصحيحة والأعداد العشرية

يميّز Factor بين الأعداد الصحيحة (`1`، `42`، `1_000_000`) والأعداد العشرية (`1.0`، `3.14`، `6.02e23`). وإذا خلطت بين عدد صحيح وعدد عشري في عملية حسابية واحدة، تخرج النتيجة عددًا عشريًا:

```factor
2 3 + .      ! => 5
2 3.0 + .    ! => 5.0
```

يمكنك وضع شرطات سفلية داخل العدد لتجميع الأرقام (`1_000_000`)، وFactor يتجاهلها ببساطة.

## كلمات القسمة

لدى Factor كلمات منفصلة للقسمة. وكلها تقع في مفردات [`math`][math].

```
/    ( x y -- x/y )    ! exact: ratio for two integers, float if either is a float
/f   ( x y -- f   )    ! always a float
/i   ( x y -- q   )    ! integer division (truncates toward zero)
mod  ( x y -- r   )    ! remainder
/mod ( x y -- q r )    ! quotient and remainder together
```

```factor
1 2 / .        ! => 1/2     (a proper ratio)
16 3 / .       ! => 5+1/3   (an improper ratio, printed as a mixed numeral)
16 3 /f .      ! => 5.333333333333333
16 3 /i .      ! => 5      (truncated)
16 3 mod .     ! => 1
16 3 /mod .s   ! quotient and remainder in one pass
! => 5
! => 1
16.0 3 / .     ! => 5.333333333333333
```

ينتج `/` قيمة من نوع `ratio` (النوع النسبي الدقيق في Factor) عند قسمة عددين صحيحين، أو من نوع `float` إذا كان أحد المدخلين عددًا عشريًا. أما `/f` فيفرض نتيجة عشرية حتى مع عددين صحيحين. و`/i` يقتطع دائمًا نحو الصفر.

## التحقق

دوال فحص الأعداد من [`math`][math] و[`math.functions`][math.functions] و[`math.primes`][math.primes]:

```
zero?    ( x       -- ? )
even?    ( x       -- ? )
odd?     ( x       -- ? )
prime?   ( x       -- ? )
divisor? ( m n     -- ? )    ! true when n divides m
integer? ( x       -- ? )    ! true for ints (fixnum or bignum)
float?   ( x       -- ? )    ! true for floats
number?  ( x       -- ? )    ! true for any numeric kind
```

```factor
0 zero? .            ! => t
0.0 zero? .          ! => t
3 zero? .            ! => f

4 even? .            ! => t
7 even? .            ! => f
7 odd? .             ! => t

7 prime? .           ! => t
9 prime? .           ! => f

15 5 divisor? .      ! => t   (5 divides 15)
15 4 divisor? .      ! => f
```

## من عدد عشري إلى عدد صحيح

تُرجع كل من `floor` و`ceiling` و`round` من مفردات [`math.functions`][math.functions] عددًا عشريًا (`3.0`، وليس `3`). وللحصول على عدد صحيح حقيقي، أتبع النتيجة بـ `>integer`:

```factor
3.7 floor >integer .       ! => 3
3.2 ceiling >integer .     ! => 4
```

## الرفع إلى قوة والقيمة المطلقة

تحسب `sq` و`^` و`abs` (في [`math.functions`][math.functions]) المربعات والقوى بأي أس والقيم المطلقة:

```
sq  ( x   -- x*x )
^   ( x y -- x^y )
abs ( x   -- |x| )
```

```factor
5 sq .          ! => 25
2 10 ^ .        ! => 1024
2 0.5 ^ .       ! => 1.4142135623730951
-7 abs .        ! => 7
3 abs .         ! => 3
```

## الأدنى والأقصى

تُرجع كل من `min ( x y -- z )` و`max ( x y -- z )` (في [`math.order`][math.order]) الأصغر أو الأكبر من بين عددين:

```factor
3 7 min .       ! => 3
3 7 max .       ! => 7
```

الاستخدام الأكثر شيوعًا هو *حصر القيمة*، أي تثبيتها عند حد أدنى باستخدام `max` (مثلًا، يُبقي `0 max` القيمة غير سالبة) أو عند حد أعلى باستخدام `min`.

## دوال ترتيب المقارنة

توفّر `math.order` كذلك `before?` و`after?` و`before=?` و`after=?` لمقارنات تعمل مع أي نوع قابل للترتيب: الأعداد والسلاسل النصية والمحارف:

```
before?  ( obj1 obj2 -- ? )   ! obj1 <  obj2
before=? ( obj1 obj2 -- ? )   ! obj1 <= obj2
after?   ( obj1 obj2 -- ? )   ! obj1 >  obj2
after=?  ( obj1 obj2 -- ? )   ! obj1 >= obj2
```

استخدم هذه الدوال بدلًا من `<`/`<=` عندما قد تكون القيم سلاسل نصية، لأن عوامل الحساب لا تعمل مع السلاسل النصية.
