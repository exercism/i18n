# نبذة

تأخذ جميع الشروط في Factor **الاقتباسات** فروعًا لها: كود مكتوب بين الأقواس المربعة `[ ... ]`، يُدفع كقيمة بدل أن يُنفَّذ، إلى أن يختاره الشرط. (سنغطّي الاقتباسات نفسها بتفصيل كامل في تمرين لاحق.)

توجد الثلاثة الأساسية في `kernel`:

```
if      ( ? then-quot else-quot -- )
when    ( ? quot -- )
unless  ( ? quot -- )
```

تتعامل الصيغتان النجميتان مع القيمة المنطقية كقيمة تستحق استخدامها عندما تكون صحيحة، وهو الزوج المعتاد «قيمة أو `f`»:

```
if*     ( ? true false -- )    ! truthy: true called WITH value
unless* ( ? false      -- )    ! falsy: false runs and pushes default
```

```factor
: abs   ( x -- y ) dup 0 < [ neg ] [ ] if ;
: shout ( s -- )   dup empty? [ drop ] [ >upper print ] if ;
```

عند وجود أكثر من فرعين، تمرّ `cond` (في `combinators`) على مصفوفة من الأزواج `{ predicate body }` وتنفّذ جسم أول شرط يتحقق. يستخدم النمط المعتاد `dup` في كل شرط حتى يبقى المدخل، ويفتتح الجسم بـ `drop` للتخلص منه قبل دفع النتيجة:

```factor
{
    { [ dup 0 <  ] [ drop "negative" ] }
    { [ dup 0 =  ] [ drop "zero"     ] }
    [ drop "positive" ]
} cond
```

العنصر الأخير الخالي من شرط هو الفرع الافتراضي.
