# نبذة

يمكن استخدام الحلقات لتنفيذ المنطق بشكل متكرر. إذا كان يجب دائمًا تنفيذ الكود الموجود في حلقة مرة واحدة على الأقل، فيمكن استخدام حلقة `do`/`while`:

```csharp
int x = 0;

do
{
    x = GetX();
    // do something with x
}
while (x != 0);
```

تُستخدم هذه بشكل أقل تكرارًا من حلقة `while`، لكنها في بعض الحالات تنتج كودًا يبدو أكثر طبيعية.
