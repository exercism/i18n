# الاختبارات

يحتوي كل تمرين على ملف اختبار.
شغّل الاختبارات باستخدام برنامج `bats`.

```bash
bats hello_world.bats
```

إذا كنت بحاجة إلى طباعة مخرجات التنقيح أثناء تشغيل الاختبارات محليًا، فراجع [التنقيح محليًا][debugging].

سيلزم تثبيت `bats`.
راجع صفحة [الاختبار في مسار Bash][tests] للحصول على تعليمات تثبيت `bats` على نظامك.

[tests]: https://exercism.org/docs/tracks/bash/tests
[debugging]: https://exercism.org/docs/tracks/bash/debugging

## الاختبارات المتخطّاة

حل التمرين يعني اجتياز جميع اختباراته.
افتراضيًا، يُنفَّذ اختبار واحد فقط (الأول) عند تشغيل الاختبارات.
هذا مقصود، فهو يتيح لك التركيز على اجتياز هذا الاختبار الواحد فقط.
بمجرد اجتيازه، يمكنك تمكين الاختبار التالي بتعليق الإشارة التالية أو حذفها:

```bash
[[ $BATS_RUN_SKIPPED == true ]] || skip
```

## تجاوز التخطّي

لتشغيل جميع الاختبارات، بما فيها تلك التي تحمل إشارات `skip`، يمكنك تشغيل:

```bash
BATS_RUN_SKIPPED=true bats exercise_name.bats
```

قد يكون من المريح استخدام دالة غلاف لتوفير الكتابة:

```bash
bats() {
    BATS_RUN_SKIPPED=true command bats *.bats
}
```

ثم شغّل الاختبارات بمجرد:

```bash
bats
```
