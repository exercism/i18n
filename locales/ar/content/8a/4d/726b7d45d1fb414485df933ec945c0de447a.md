# فهم العودية في JavaScript

العودية مفهوم قوي في البرمجة يقوم على استدعاء الدالة لنفسها.
قد يكون فهمها صعبًا بعض الشيء في البداية، لكنك متى أدركت أساسياتها أصبحت أداة قيّمة لحل المسائل المعقدة.
في هذا الدرس، سنستكشف العودية في JavaScript من خلال أمثلة سهلة الفهم.

## ما هي العودية؟

تحدث العودية عندما تستدعي الدالة نفسها، سواء بشكل مباشر أو غير مباشر.
وهي تشبه الحلقة، لكنها تقوم على تقسيم المسألة إلى مسائل فرعية أصغر وأسهل في التعامل معها.

### مثال 1: العد التنازلي

لنبدأ بمثال بسيط: دالة العد التنازلي.

```javascript
function countdown(num) {
  // Base case
  if (num <= 0) {
    console.log('Blastoff!');
    return;
  }

  // Recursive case
  console.log(num);
  countdown(num - 1);
}

// Call the function
countdown(5);
```

في هذا المثال:

- **الحالة الأساسية**: عندما تصبح قيمة `num` أصغر من أو تساوي 0، تطبع الدالة "Blastoff!" وتتوقف عن استدعاء نفسها.
- **الحالة العودية**: تطبع الدالة قيمة `num` الحالية وتستدعي نفسها بالقيمة `num - 1`.

### مثال 2: المضروب

الآن، لنلقِ نظرة على مثال كلاسيكي على العودية: حساب مضروب عدد.

```javascript
function factorial(n) {
  // Base case
  if (n === 0 || n === 1) {
    return 1;
  }

  // Recursive case
  return n * factorial(n - 1);
}

// Test the function
console.log(factorial(5)); // Output: 120
```

في هذا المثال:

- **الحالة الأساسية**: عندما تكون قيمة `n` تساوي 0 أو 1، تُرجع الدالة 1.
- **الحالة العودية**: تضرب الدالة `n` في مضروب `n - 1`.

## المفاهيم الأساسية

### الحالة الأساسية

يجب أن تحتوي كل دالة عودية على حالة أساسية واحدة على الأقل، وهي شرط تتوقف عنده الدالة عن استدعاء نفسها.
وبدون حالة أساسية، ستستمر العودية بلا نهاية، مما يؤدي إلى تجاوز سعة المكدس.

### الحالة العودية

تحدد الحالة العودية كيفية استدعاء الدالة لنفسها بنسخة أصغر أو أبسط من المسألة.

## مزايا العودية وعيوبها

**المزايا:**

- حل أنيق لبعض المسائل.
- يحاكي مفهوم الاستقراء الرياضي.

**العيوب:**

- قد يكون أقل كفاءة من الحلول التكرارية.
- قد يؤدي إلى تجاوز سعة المكدس في حالات العودية العميقة.

## الخلاصة

العودية تقنية قيّمة يمكنها تبسيط المسائل المعقدة عبر تقسيمها إلى مسائل فرعية أصغر وأسهل في التعامل معها.
وفهم الحالات الأساسية والحالات العودية أمر بالغ الأهمية لتنفيذ حلول عودية فعّالة في JavaScript.
