# نبذة

تُمثَّل القيم المنطقية في Java بالنوع `boolean`، الذي تكون قيمه إما `true` أو `false`.

تدعم Java ثلاثة [عوامل منطقية][operators]:

- `!` (NOT): يعكس القيمة المنطقية
- `&&` (AND): يأخذ قيمتين منطقيتين ويكون الناتج صحيحًا إذا كانتا صحيحتين معًا
- `||` (OR): يكون الناتج صحيحًا إذا كانت إحدى القيمتين المنطقيتين صحيحة على الأقل

يستخدم العاملان `&&` و `||` _التقييم المختصر_، وهذا يعني أن الطرف الأيمن للعامل لا يُقيَّم إلا عند الحاجة.

تُعرف هذه أيضًا بالعوامل الشرطية أو المنطقية.
يُصنَّف `!` أحيانًا في التوثيق على أنه عملية على مستوى البتات، لكنه يحمل الدلالة التقليدية لـ _NOT_.

```java
true || false // => true
false || false // => false
false || true // => true
true && false // => false
true && true // => true
!true // => false
!false // => true
```

لكل من العوامل المنطقية الثلاثة [_أسبقية عوامل_][precedence] مختلفة.
وبناءً على ذلك، تُقيَّم بهذا الترتيب: `not` أولًا، ثم `&&`، وأخيرًا `||`.
وإذا أردت «الهروب» من هذه القواعد، يمكنك وضع تعبير منطقي بين الأقواس الهلالية (`()`)، لأن الأقواس الهلالية لها أسبقية عوامل أعلى.

```java
!true && false   // => false
!(true && false) // => true
```
