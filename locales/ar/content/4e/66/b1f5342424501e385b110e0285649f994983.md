# التعليمات

أنت مسؤول عن صيانة مجموعة أدوات توليد الكود في محطة إشارات.
كل ماكرو هو *استنسل*، أي قالب صغير يستخدمه المصرّف ليطبع كودًا متخصّصًا عند كل موقع استدعاء.

أنت تكتب الماكروات الأربعة فقط. يعرّف ملف الاختبار كلمات تغليف صغيرة *تستدعي* الماكروات التي تكتبها (لا يمكن ملاحظة الماكرو إلا من خلال الكود الذي يولّده)، ثم يتحقّق من نتائج الأغلفة في وقت التشغيل. اترك الأغلفة كما هي.

في كل مهمة، يستقبل جسم الماكرو المُدخلات الحرفية لموقع الاستدعاء على المكدّس، وعليه أن يترك **اقتباسًا واحدًا**. وتوضّح أسطر «يُترجم إلى» الكودَ الخطي الذي ينبغي أن يولّده اقتباسك.

## 1. مرّتين على التوالي

يأخذ `twice` اقتباسًا حرفيًّا ويُرجع اقتباسًا يُشغّل الأصل مرّتين على التوالي.

```factor
! : inc-twice ( x -- y ) [ 1 + ] twice ;
! body receives [ 1 + ]  ->  must build [ 1 + 1 + ]
5 inc-twice .   ! => 7
```

## 2. تكرار N مرّة

يأخذ `repeat-quot` اقتباسًا حرفيًّا وعددًا حرفيًّا `n`، ويُرجع اقتباسًا يُشغّل الأصل `n` من المرّات على التوالي.
وعندما يكون `n = 0` يُرجع الاقتباس الفارغ `[ ]`.

```factor
! : inc-thrice ( x -- y ) [ 1 + ] 3 repeat-quot ;
! body receives [ 1 + ] 3  ->  must build [ 1 + 1 + 1 + ]
5 inc-thrice .   ! => 8
```

## 3. دمج عدة اقتباسات

يأخذ `compose-many` مصفوفة حرفية من الاقتباسات ويُرجع اقتباسًا واحدًا يُشغّل كلًّا منها بالترتيب. والمصفوفة الفارغة تُرجع الاقتباس الفارغ.

```factor
! : pipeline ( x -- y ) { [ 1 + ] [ 2 * ] [ 1 - ] } compose-many ;
! body receives { [ 1 + ] [ 2 * ] [ 1 - ] }  ->  must build [ 1 + 2 * 1 - ]
5 pipeline .   ! => 11
```

## 4. تكرار مفكوك

يأخذ `each-literal` متتالية حرفية واقتباسًا. ويُرجع اقتباسًا يدفع، لكل عنصر من عناصر المتتالية، ذلك العنصر ثم يُشغّل الاقتباس: تكرار يحدث في وقت التصريف، فيكون الكود المولَّد خطيًّا.

```factor
! : sum-three ( -- n ) 0 { 10 20 30 } [ + ] each-literal ;
! body receives { 10 20 30 } [ + ]  ->  must build [ 10 + 20 + 30 + ]
sum-three .   ! => 60
```

هذا أكثر الماكروات الأربعة بنيوية: فطول المتتالية *وقيم* عناصرها معًا يشكّلان الكود المولَّد. وستأخذك التلميحات في بناءه خطوة بخطوة.
