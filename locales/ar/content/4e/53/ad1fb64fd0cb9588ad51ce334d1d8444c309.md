# مقدمة

رأينا في التمرين السابق أن هناك أسلوبين لكتابة التعليقات في Go: التعليقات أحادية السطر التي يسبقها `//`، وكتل التعليقات متعددة الأسطر التي يُحاط بها بـ `/*` و`*/`.

## تعليقات التوثيق

في Go، تلعب التعليقات دورًا مهمًا في توثيق الكود.
ويستخدمها الأمر `godoc`، الذي يستخرج هذه التعليقات لإنشاء توثيق عن حزم Go.
وينبغي أن يكون التعليق التوثيقي جملة كاملة تبدأ باسم الشيء الموصوف وتنتهي بنقطة.

وينبغي أن تسبق التعليقات الحزم وكذلك المعرّفات المصدَّرة، ومنها الدوال والطرق ومتغيرات الحزمة والثوابت و`struct`، وستتعلم المزيد عنها في التمارين القادمة.

قد يبدو متغير على مستوى الحزمة هكذا:

```go
// TemperatureCelsius represents a certain temperature in degrees Celsius.
var TemperatureCelsius float64
```

## تعليقات الحزمة

ينبغي كتابة تعليقات الحزمة مباشرةً قبل جملة الحزمة (`package x`) وأن تبدأ بـ `Package x ...` هكذا:

```go
// Package kelvin provides tools to convert
// temperatures to and from Kelvin.
package kelvin
```

## تعليقات الدوال

ينبغي كتابة تعليق الدالة مباشرةً قبل تعريف الدالة.
وينبغي أن يكون جملة كاملة تبدأ باسم الدالة.
على سبيل المثال، ينبغي أن يأخذ التعليق المصدَّر للدالة `Calculate` الصيغة `Calculate  ...`.
وينبغي أيضًا أن يوضّح ما الوسائط التي تأخذها الدالة، وما الذي تفعله بها، وما تعنيه قيم الإرجاع، وأن ينتهي بنقطة):

```go
// CelsiusFreezingTemp returns an integer value equal to the temperature at which water freezes in degrees Celsius.
func CelsiusFreezingTemp() int {
	return 0
}
```
