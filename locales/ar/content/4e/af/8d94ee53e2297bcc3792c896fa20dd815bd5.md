# مقدمة

## الواجهات

الواجهة نوع يحتوي على أعضاء تعرّف مجموعة من الوظائف المترابطة. وهي تفصل استخدامات الصنف عن التنفيذ، بما يتيح عدة تنفيذات مختلفة أو دعم سلوك عام مثل التنسيق أو المقارنة أو التحويل.

تشبه صياغة الواجهة صياغة الصنف أو البنية، إلا أن الطرق والخصائص تظهر كتوقيع فقط دون تقديم أي جسم لها.

```csharp
public interface ILanguage
{
    string LanguageName { get; set; }
    string Speak();
}

public class ItalianTaveller : ILanguage, ICloneable
{
    public string LanguageName { get; set; } =  "Italiano";

    public string Speak()
    {
        return "Ciao mondo";
    }

    public object Clone()
    {
        ItalianTaveller it = new ItalianTaveller();
        it.LanguageName = this.LanguageName;
        return it;
    }
}
```

يجب تنفيذ كل العمليات التي تعرّفها الواجهة.

يمكن أن تحتوي الواجهات على طرق وخصائص النسخة إلى جانب أعضاء أخرى

## الترتيب

لكي يمكن مقارنة كائن بكائن آخر، يجب أن ينفّذ واجهة `IComparable<T>`.
تحتوي هذه الواجهة على طريقة واحدة يجب تنفيذها: `int CompareTo(T other)`.

هناك ثلاث قيم إرجاع ممكنة لطريقة `CompareTo`:

- قيمة أصغر من صفر: الكائن الحالي أصغر من الكائن الآخر.
- قيمة أكبر من صفر: الكائن الحالي أكبر من الكائن الآخر.
- القيمة صفر: الكائن الحالي يساوي الكائن الآخر.
