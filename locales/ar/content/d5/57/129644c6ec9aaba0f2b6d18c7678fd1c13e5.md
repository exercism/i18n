# التعليمات

في هذا التمرين، ستعمل على مُنظّم مواعيد لصالون تجميل في نيويورك افتُتح في 15 سبتمبر 2012.

لديك أربع مهام، وكلها تتعلق بتواريخ المواعيد. ستستخدم التواريخ والأوقات واحدة من الصيغ الثلاث التالية:

- `"7/25/2019 13:45:00"`
- `"July 25, 2019 13:45:00"`
- `"Thursday, July 25, 2019 13:45:00:00"`

~~~~exercism/caution
ستضبط الاختبارات الإعدادات الثقافية تلقائيًا على `en-US`، فلا حاجة إلى ضبط الإعدادات الثقافية أو تحديدها بنفسك.
~~~~

## 1. تحليل تاريخ الموعد

نفّذ الدالة `schedule` التي يمكنها تحليل تمثيل نصي لتاريخ موعد إلى صيغة `DateTime` المقابلة:

```fsharp
schedule "7/25/2019 13:45:00"
// => DateTime(2019, 7, 25, 13, 45, 0)
```

## 2. التحقق مما إذا كان الموعد قد مضى

نفّذ الدالة `hasPassed` التي تأخذ تاريخ موعد وتتحقق مما إذا كان الموعد قد وقع في الماضي:

```fsharp
hasPassed (DateTime(1999, 12, 31, 9, 0, 0))
// => true
```

## 3. التحقق مما إذا كان الموعد بعد الظهر

نفّذ الدالة `isAfternoonAppointment` التي تأخذ تاريخ موعد وتتحقق مما إذا كان الموعد بعد الظهر (>= 12:00 و < 18:00):

```fsharp
isAfternoonAppointment (DateTime(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. وصف وقت الموعد وتاريخه

نفّذ الدالة `description` التي تأخذ تاريخ موعد وتُرجع وصفًا لذلك التاريخ والوقت:

```fsharp
description (DateTime(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on 3/29/2019 3:00:00 PM."
```

## 5. إرجاع تاريخ الذكرى السنوية

نفّذ الدالة `anniversaryDate` التي تُرجع تاريخ الذكرى السنوية لهذا العام، وهو 15 سبتمبر:

```fsharp
anniversaryDate()
// => DateTime(2019, 9, 15, 0, 0, 0)
```
