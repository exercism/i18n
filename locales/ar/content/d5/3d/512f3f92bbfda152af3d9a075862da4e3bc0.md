# الاختبار من سطر الأوامر

نفّذ الاختبارات باستخدام:

```bash
scarb cairo-test
```

تم تجاهل جميع الاختبارات ما عدا الاختبار الأول. بعد أن تنجح في اجتياز الاختبار الأول، افتح ملف مصدر الاختبارات الموجود في مجلد `tests`، وأزل علامة `#[ignore]` من الاختبار التالي ثم اجتزه بنجاح. كل اختبار منفصل هو دالة تعلوها علامة `#[test]`. تابع حتى تجتاز كل الاختبارات.

إذا أردت تشغيل _كل_ الاختبارات دون تعديل ملف مصدر الاختبارات، فاستخدم:

```bash
scarb cairo-test --include-ignored
```

لتشغيل اختبار معيّن بغض النظر عن كونه متجاهلًا أم لا، مثل `some_test`، يمكنك استخدام:

```bash
scarb cairo-test -f some_test
```

لمعرفة المزيد عن اختبارات Cairo، راجع [توثيق الاختبارات][cairo-tests] على الإنترنت.

[cairo-tests]: https://book.cairo-lang.org/ch10-01-how-to-write-tests.html
