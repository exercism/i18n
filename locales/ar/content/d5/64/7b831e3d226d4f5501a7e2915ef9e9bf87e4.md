# المقدمة

تُنشأ نسخة من _الصنف_ عن طريق استدعاء _منشئه_ باستخدام عامل `new`. المنشئ نوع خاص من الطرق هدفه تهيئة نسخة منشأة حديثًا. يشبه المنشئ الطرق العادية، لكنه بلا نوع إرجاع وباسم يطابق اسم الصنف.

```csharp
class Library
{
    private int books;

    public Library()
    {
        // Initialize the books field
        this.books = 10;
    }
}

// This will call the constructor
var library = new Library();
```

مثل الطرق العادية، يمكن أن يكون للمنشئ معاملات. عادةً ما تُخزَّن معاملات المنشئ في حقول (خاصة) للوصول إليها لاحقًا، أو تُستخدم في عملية حسابية تُجرى مرة واحدة. ويمكن تمرير الوسائط إلى المنشئ تمامًا كما تُمرَّر الوسائط إلى الطرق العادية.

```csharp
class Building
{
    private int numberOfStories;
    private int totalHeight;

    public Building(int numberOfStories, double storyHeight)
    {
        this.numberOfStories = numberOfStories;
        this.totalHeight = numberOfStories * storyHeight;
    }
}

// Call a constructor with two arguments
var largeBuilding = new Building(55, 6.2)
```
