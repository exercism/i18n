# نبذة

لغة C لغة ذات أنواع ثابتة، أي أن لكل شيء نوعًا في وقت التصريف.
ويُسمّى اختيار اسم [للمتغير][variable] وتحديد نوعه تصريحًا عن المتغير.

يُصرَّح عن المتغير بتحديد نوعه صراحةً.
ويجب أن يتبع اسم المتغير [بعض القواعد][name-rules]، مثل أن يبدأ بحرف أو بشرطة سفلية.
ولا يمكن استخدام بعض الأسماء لأنها محجوزة [للكلمات المفتاحية][reserved-keywords] أو [لمعرّفات أخرى][reserved-identifiers].

ويتم ضبط المتغير أو تحديثه عبر إسناد المتغير.
وضبط القيمة هو ما يعرّف المتغير.
ويُعرف تعريف المتغير أيضًا بالتهيئة.

```c
int foo;      // Declare an integer named var
foo = 10;     // Define the variable

int bar = 15; // Both can also be done in a single statement
```

يمكن إسناد قيمة المتغير وتحديثها باستخدام [عامل الإسناد البسيط `=`][assignment-operator].
وبمجرد تعريف المتغير، لا يمكن أن يتغير نوعه أبدًا.

```c
int foo = 10; // Assign initial value
foo = 25;     // Update to new value

foo = false;  // Compiler error when assigning value of a different type
```

لغة C هي لغة [أمرية][imperative] [إجرائية][procedural].
وتُنفَّذ كل العمليات الحسابية ضمن تسلسل من [العبارات][statements] التي تشكّل جزءًا من دالة أو من عدة دوال.

ويمكن أن تحتوي كل دالة على صفر أو أكثر من [المعاملات][parameters].
وعند تعريف دالة، يجب تحديد نوع جميع المعاملات وقيمة الإرجاع بشكل صريح.
وتُرجع الدوال القيم باستخدام [الكلمة المفتاحية `return`][return-keyword].
وللدوال [صنف تخزين][storage_class] خارجي افتراضيًا، أي أنها تبقى موجودة طوال عمر البرنامج ويمكن أن تكون مرئية خارج الملف.
ولمنع ذلك، يمكن إضافة الكلمة المفتاحية `static` لتحديد الظهور الداخلي.

```c
static int add(int x, int y) {
  return x + y;
}
```

في المثال أعلاه، لا يمكن استخدام المتغيرين `x` و`y` إلا داخل الدالة، أي أن نطاقهما هو نطاق الدالة.
[النطاق][scope] هو فكرة أن القيمة المرتبطة باسم (لعنصر برمجي) لا يمكن الوصول إليها إلا داخل "المنطقة" من الكود التي عُرِّفت فيها.
مناطق الكود الرئيسية في C هي:

- الملف
- الدالة
- الكتلة (كما في الحلقات وتراكيب أخرى)

وتُستدعى الدوال بتحديد اسم الدالة وتمرير وسائط لكل معامل من معاملات الدالة.

```c
int sum = add(1, 2);
```

تدعم لغة C نوعين من [التعليقات][comments].
تُسبق التعليقات أحادية السطر بالرمز `//` (منذ C99)، وتوضع التعليقات متعددة الأسطر بين `/*` و`*/`.
