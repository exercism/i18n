# التعليمات

في هذا التمرين ستتعامل مع أسطر السجل.

كل سطر سجل هو سلسلة نصية مُنسّقة على النحو التالي: `"[<LEVEL>]: <MESSAGE>"`.

هناك ثلاثة مستويات مختلفة للسجل:

- `INFO`
- `WARNING`
- `ERROR`

لديك ثلاث مهام، تأخذ كل منها سطر سجل وتطلب منك أن تفعل به شيئًا.
توجد أساليب كثيرة لحل هذه المهام؛ اختر أساليبك المفضلة من الأمثلة أعلاه وانظر ما يمكنك التوصل إليه.

## 1. استخراج الرسالة من سطر السجل

نفّذ الطريقة `LogLineParser#message` لتُرجع رسالة سطر السجل:

```ruby
LogLineParser.new('[ERROR]: Invalid operation').message
# => "Invalid operation"
```

يجب إزالة أي مسافات بادئة أو لاحقة:

```ruby
LogLineParser.new("[WARNING]:  Disk almost full\r\n").message
# => "Disk almost full"
```

## 2. استخراج مستوى السجل من سطر السجل

نفّذ الطريقة `LogLineParser#log_level` لتُرجع مستوى السجل الخاص بسطر السجل، ويجب أن يكون بحروف صغيرة:

```ruby
LogLineParser.new('[ERROR]: Invalid operation').log_level
# => "error"
```

## 3. إعادة تنسيق سطر السجل

نفّذ الطريقة `LogLineParser#reformat` التي تُعيد تنسيق سطر السجل، فتضع الرسالة أولًا ثم مستوى السجل بعدها بين الأقواس الهلالية:

```ruby
LogLineParser.new('[INFO]: Operation completed').reformat
# => "Operation completed (info)"
```
