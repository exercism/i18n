# ملحق التعليمات

## السجلات

| السجل | الاستخدام | النوع | الوصف                                                |
| -------- | --------- | ------- | ---------------------------------------------------------- |
| `$a0`    | إدخال     | عنوان | عناصر المصفوفة الأولى                                         |
| `$a1`    | إدخال     | عدد صحيح | حجم المصفوفة الأولى، بالكلمات                                |
| `$a2`    | إدخال     | عنوان | عناصر المصفوفة الثانية                                         |
| `$a3`    | إدخال     | عدد صحيح | حجم المصفوفة الثانية، بالكلمات                                |
| `$v0`    | إخراج    | عدد صحيح | `0` = equal، `1` = unequal، `2` = sublist، `3` = superlist |
| `$t0-9`  | مؤقت | أي نوع     | تُستخدم للتخزين المؤقت                                 |
