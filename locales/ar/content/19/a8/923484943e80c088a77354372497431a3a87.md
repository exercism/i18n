# مقدمة

## مصفوفات البتات

قد يكون التعامل مع البيانات الثنائية أمرًا صعبًا، لذا توفّر Gleam نوع `BitArray` مع صيغة مرافقة لإنشاء البيانات الثنائية ومطابقة أنماطها.

تُعرَّف القيم الحرفية لمصفوفات البتات باستخدام صيغة `<<>>`. وعند تعريف قيمة حرفية لمصفوفة بتات، فإنها تُعرَّف على شكل مقاطع. ولكل مقطع قيمة وتوصيف يفصل بينهما `:`. ويحدد التوصيف عدد البتات التي ستُستخدم لترميز القيمة، ويمكن حذفه تمامًا، وعندها تكون القيمة الافتراضية عددًا صحيحًا من 8 بتات.

```gleam
// This defines a bit array with three segments of a single bit each
<<0:1, 1:1, 0:1>>

// This defines a bit array with three segments of 8 bits each
<<0, 1, 0>>
```

تحديد النوع بالشكل `:1` هو اختصار لكتابة `:size(1)`. وتحتاج إلى استخدام الصيغة الأطول إذا كان حجم البتات قادمًا من متغير.

```gleam
let segment_size = 1
<<0:size(segment_size), 1:size(segment_size), 0:size(segment_size)>>
```

### الثنائية

عند كتابة القيم الحرفية للأعداد الصحيحة الثنائية، يمكننا كتابتها مباشرة بالترميز الثنائي (الأساس 2) بإضافة البادئة `0b` إلى القيمة الحرفية. لاحظ أنها ستُعرض كأعداد عشرية عند طباعتها في الاختبارات أو في برنامجك.

```gleam
<<0b1011:4>> == <<11:4>>
// -> True
```

### الاقتطاع

إذا تجاوزت قيمة المقطع سعة نوع المقطع، فستُقتطع من اليسار.

```gleam
<<0b1011:3>> == <<0b0011:3>>
// -> True
```

### الإضافة في البداية والإضافة في النهاية

يمكنك الإضافة في البداية والإضافة في النهاية إلى مصفوفة بتات موجودة باستخدام صيغة مصفوفة البتات. ويجب استخدام التوصيف `:bits` لمصفوفة البتات الموجودة.

```gleam
let value = <<0b110:3, 0b001:3>>
let new_value = <<0b011:3, value:bits, 0b000:3>>
// -> <<120, 8:size(4)>>
```

### الدمج

يمكننا دمج مصفوفات البتات المخزّنة في متغيرات باستخدام صيغة مصفوفة البتات. ويجب استخدام التوصيف `:bits` عند دمج مصفوفتين من البتات بأحجام متغيرة.

```gleam
let first = <<0b110:3>>
let second = <<0b001:3>>
let concatenated = <<first:bits, second:bits>>
// -> <<49:size(6)>>
```

### مطابقة الأنماط

يمكن أيضًا إجراء مطابقة الأنماط للحصول على قيم من مصفوفة البتات. ويجب أن تعرف عدد البتات لكل مقطع تريد التقاطه، مع استثناء واحد: يمكن استخدام التوصيف `:bits` لمطابقة أنماط مصفوفة بتات بحجم غير معروف، لكن هذا لا يمكن استخدامه إلا للمقطع الأخير.

```gleam
let assert <<value:4, rest:bits>> = <<0b01101001:8>>
value == 0b0110
// -> True
```

### فحص مصفوفات البتات

~~~~exercism/note
قد تُطبع مصفوفات البتات بصيغة مختلفة عن الصيغة التي استُخدمت لإنشائها. وغالبًا ما يسبب هذا ارتباكًا عند تعلّم مصفوفات البتات.
~~~~

افتراضيًا، تُعرض مصفوفات البتات على شكل مقاطع من 8 بتات (بايت)، حتى لو أنشأتها بمقاطع بحجم مختلف.

```gleam
<<2011:11>>
// -> <<251, 3:size(3)>>
```

إذا أنشأت مصفوفة بتات تمثل سلسلة نصية قابلة للطباعة مرمّزة بترميز UTF-8، فقد تعرضها دوال مثل `io.debug` على شكل سلسلة نصية. ويعود ذلك إلى تفصيل في التنفيذ يتعلق بكيفية تمثيل Gleam للسلاسل النصية داخليًا.

```gleam
<<>>
// -> ""

<<65, 66, 67>>
// -> "ABC"
```
