# مقدمة

الوراثة وسيلة لإنشاء علاقات أب وابن بين الأصناف.
الصنف الابن (ويُشار إليه أحيانًا بـ_الصنف الفرعي_) يستطيع الوصول إلى السلوك والبيانات المعرَّفة في الصنف الأب (ويُشار إليه أحيانًا بـ_الصنف الأعلى_).

```javascript
class Pet {
  constructor(name) {
    this.name = name;
  }

  introduce() {
    console.log(`This is my pet, ${this.name}.`);
  }
}

class Dog extends Pet {}

const dog = new Dog('Otis');
dog.introduce();
// => This is my pet, Otis.
```

الكلمة المفتاحية `extends` في تعريف الصنف الابن تُنشئ علاقة مع الصنف الأب عبر [سلسلة النموذج الأولي][prototype-chain].

الكائنات التي ينشئها مُنشئ الصنف الابن ستحتوي سلسلةُ النموذج الأولي الخاصة بها على نموذج الصنف الأب الأولي، ما يتيح لها الوصول إلى أي طُرق أو بيانات معرَّفة في الصنف الأب.

```javascript
const dog = new Dog('Otis');

Dog.prototype.isPrototypeOf(dog); // => true
Pet.prototype.isPrototypeOf(dog); // => true
Pet.prototype.isPrototypeOf(Dog.prototype); // => true

Pet.prototype.hasOwnProperty('introduce'); // => true
Dog.prototype.hasOwnProperty('introduce'); // => false
dog.hasOwnProperty('introduce'); // => false
```

[prototype-chain]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Inheritance_and_the_prototype_chain
