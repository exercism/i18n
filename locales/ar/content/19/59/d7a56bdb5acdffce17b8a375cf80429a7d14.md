# مقدمة

يمكن تطبيق المُعدِّل `const` (ويُستحسن عمومًا ذلك) على أي حقل تكون قيمته معروفة في وقت الترجمة ولن تتغير خلال عمر البرنامج.

```csharp
private const int num = 1729;
public const string title = "Grand" + " Master";
```

يمكن تطبيق المُعدِّل `readonly` (ويُستحسن عمومًا ذلك) على أي حقل لا يمكن جعله `const`، ولا تتغير قيمته خلال عمر البرنامج، ويُضبط إما عبر مُهيّئ مضمّن وإما أثناء إنشاء النسخة (بواسطة المنشئ أو طريقة يستدعيها المنشئ).

```csharp
private readonly int num;
private readonly System.Random rand = new System.Random();

public MyClass(int num)
{
    this.num = num;
}
```
