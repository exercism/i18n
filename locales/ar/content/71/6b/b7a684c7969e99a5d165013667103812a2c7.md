# ملحق التعليمات

## تلميحات

لإكمال هذا التمرين، عليك إنشاء نوع البيانات `Allergen`، مع نسختَي `Eq` و`Show`، وتنفيذ الدوال التالية:

- `allergies`
- `isAllergicTo`

ستجد تعريف بيانات وهميًا وتوقيعات الأنواع جاهزة في مكانها، لكن الأمر متروك لك لتعريف الدوال وإنشاء نوع بيانات أو `newtype` أو مرادف نوع ذي معنى.
