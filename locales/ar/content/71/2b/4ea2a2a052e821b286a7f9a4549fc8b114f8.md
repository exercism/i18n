# التعليمات

في هذا التمرين، ستُنفّذ آليات لعبة تقمص الأدوار.
تُمثَّل شخصية اللاعب بالنوع التالي:

```elm
type alias Player =
    { name : Maybe String
    , level : Int
    , health : Int
    , mana : Maybe Int
    }
```

يجب أن يصل اللاعبون في هذه اللعبة إلى المستوى 10 قبل أن يفتحوا مخزون المانا حتى يبدأوا في إلقاء التعاويذ.
أنت تعمل على جزأين من الوظائف في هذه اللعبة: آلية الإحياء وآلية إلقاء التعاويذ.

## 1. عرّف بنفسك

اكتب محتوى الدالة `introduce`.
قد يخفي اللاعبون المتخفّون أسماءهم وسيُعرَّف عنهم باسم `"Mighty Magician"`.
وإلا، فاستخدم اسمك فقط لتعرّف بنفسك.

```elm
introduce { name = Nothing, level = 2, health = 8, mana = Nothing }
    --> "Mighty Magician"

introduce { name = Just "Merlin", level = 2, health = 8, mana = Nothing }
    --> "Merlin"
```

## 2. نفّذ آلية الإحياء

ينبغي أن تتحقق دالة `revive` من أن شخصية اللاعب ميتة فعلًا (وصلت صحتها إلى 0).
وإذا كانت كذلك، فينبغي أن تُرجع نسخة جديدة من `Player` بصحة 100.
وإلا، إذا لم تكن شخصية اللاعب ميتة، فستُرجع دالة `revive` القيمة `Nothing`.

وإذا كان مستوى اللاعب 10 أو أكثر، فينبغي إحياؤه أيضًا بـ 100 مانا.
وإذا كان مستوى اللاعب أقل من 10، فينبغي أن تكون ماناه `Nothing`.
ينبغي أن تحافظ دالة `revive` على مستوى اللاعب.

```elm
deadPlayer = { name = Nothing, level = 2, health = 0, mana = Nothing }

revive deadPlayer
    --> Just { name = Nothing, level = 2, health = 100, mana = Nothing }
```

إذا استُدعيت الطريقة `revive` على لاعب صحته 1 أو أكثر، فينبغي أن تُرجع الدالة `Nothing`.

```elm
alivePlayer = { name = Nothing, level = 2, health = 42, mana = Nothing }

revive alivePlayer
    --> Nothing
```

## 3. نفّذ آلية إلقاء التعاويذ

تأخذ دالة `castSpell` كوسائط قيمة من النوع `Int` تشير إلى مقدار المانا التي تكلّفها التعويذة، بالإضافة إلى قيمة من النوع `Player`.
وتُرجع اللاعب المُحدَّث، بالإضافة إلى مقدار الضرر الذي تُحدثه التعويذة المُلقاة.
تُحدث التعويذة المُلقاة بنجاح ضررًا يساوي ضعف تكلفة المانا للتعويذة.
ومع ذلك، إذا كانت مانا اللاعب غير كافية، فلا يحدث شيء، ويبقى اللاعب دون تغيير، ولا يُحدث أي ضرر.
وإذا لم يكن لدى اللاعب مخزون مانا على الإطلاق، فإن محاولة إلقاء التعويذة يجب أن تُنقص صحته بمقدار تكلفة المانا للتعويذة ولا تُحدث أي ضرر.

```elm
wizard = { name = Nothing, level = 18, health = 123, mana = Just 30 }

( updatedWizard, damage ) = castSpell 14 wizard

updatedWizard.mana --> Just 16
damage             --> 28
```
