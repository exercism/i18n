# التعليمات

طلبت منك جمعية حيّك تنفيذ تطبيق سجل بسيط لإدارة تسجيلات حديقة المجتمع. وقد تم تزويدك ببنية `Plot` مسبقًا.

## 1. افتح الحديقة

نفّذ الدالة `CommunityGarden.start/1`، ويجب أن تستقبل قائمة اختيارية من الخيارات على شكل كلمات مفتاحية لتُمرَّر إلى _عملية الوكيل_. ويجب تهيئة الحالة الأولية للحديقة بحيث تمثّل مجموعة فارغة من قطع الأرض. ويجب أن تُرجع صفًا `:ok` يحمل `pid` الحديقة.

```elixir
{:ok, pid} = CommunityGarden.start()
# => {:ok, #PID<0.112.0>}
```

## 2. اسرد التسجيلات

نفّذ الدالة `CommunityGarden.list_registrations/1`. يجب أن تستقبل `pid` الخاص بحديقة المجتمع. ويجب أن تُرجع قائمة بقطع الأرض المخزّنة المسجّلة.

```elixir
CommunityGarden.list_registrations(pid)
# => []
```

> في هذه المرحلة، لم نضف بعد إمكانية تسجيل قطعة أرض، لذا يجب أن تكون هذه القائمة فارغة

## 3. سجّل قطع الأرض لشخص

نفّذ الدالة `CommunityGarden.register/2`. يجب أن تستقبل `pid` الخاص بحديقة المجتمع واسمًا لتسجيل قطعة الأرض باسمه. وعند نجاح العملية، يجب أن تُرجع بنية `Plot` مع معرّف قطعة الأرض والشخص المسجّلة باسمه.

يجب أن تكون المعرّفات متزايدة وفريدة. يمكنك الاحتفاظ بعدّاد للمعرّفات في حالة الوكيل.

```elixir
CommunityGarden.register(pid, "Emma Balan")
# => %Plot{plot_id: 1, registered_to: "Emma Balan"}
CommunityGarden.list_registrations(pid)
# => [%Plot{plot_id: 1, registered_to: "Emma Balan"}]
```

## 4. حرّر قطع الأرض

نفّذ الدالة `CommunityGarden.release/2`. يجب أن تستقبل `pid` و`id` الخاصين بقطعة الأرض المطلوب تحريرها. ويجب أن تُرجع `:ok` عند النجاح. عند تحرير قطعة أرض، لا يُعاد استخدام المعرّف، بل يُستخدم كمعرّف فريد فقط.

```elixir
CommunityGarden.release(pid, 1)
# => :ok
CommunityGarden.list_registrations(pid)
# => []
```

## 5. احصل على قطعة أرض مسجّلة

نفّذ الدالة `CommunityGarden.get_registration/2`. يجب أن تستقبل `pid` و`id` الخاصين بقطعة الأرض المطلوب التحقق منها. ويجب أن تُرجع قطعة الأرض إذا كانت مسجّلة، و`:not_found` إذا كانت غير مسجّلة.

```elixir
CommunityGarden.get_registration(pid, 1)
# => %Plot{plot_id: 1, registered_to: "Emma Balan"}
CommunityGarden.get_registration(pid, 7)
# => {:not_found, "plot is unregistered"}
```
