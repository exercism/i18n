# الاختبارات

## تشغيل الاختبارات

عندما تكون في مجلد تمرين، من المفترض أن ترى مجلدين فرعيين:

* `Sources/<Exercise>` يحتوي على حلّك للتمرين
* `Tests/<Exercise>Tests` يحتوي على الاختبارات التي يجب تشغيلها للتمرين

إذا كنت في المجلد الصحيح (أي المجلد الذي يحتوي على `Sources` و`Tests`)، يمكنك تشغيل اختبارات ذلك التمرين بتشغيل `swift test`:

```bash
$ pwd
/Users/johndoe/Code/exercism/swift/hello-world

$ ls
HELP.md  Package.swift  README.md  Sources  Tests

$ swift test
```

بعد نجاح اختبار، أزل `.enabled(if: RUNALL)` في عبارة `@Test` لتمكين الاختبار التالي، أو يمكنك تشغيل كل الاختبارات مع ضبط متغير البيئة `RUNALL` على `true` على Linux أو macOS:

```bash
$ export RUNALL=true
```

أو إذا كنت تستخدم PowerShell على Windows:

```powershell
set RUNALL=true
```

## إرسال حلّك

لرفع حل إلى Exercism، يجب أن تكون في المجلد الذي يحتوي على مجلدَي `Sources` و`Tests`.

```bash
$ exercism submit 
```
