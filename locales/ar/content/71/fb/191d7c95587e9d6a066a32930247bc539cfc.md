# مقدمة

## الأساسيات

Java لغة ذات أنواع ثابتة، أي أن نوع المتغير معروف في وقت التصريف.
ويُسمّى إسناد قيمة إلى اسم تعريف المتغير.
ويُعرَّف المتغير بتحديد نوعه صراحةً.

```java
int explicitVar = 10;
```

ويتم تحديث قيمة المتغير عبر العامل `=`.
هنا لا يمثل `=` المساواة الرياضية.
إنه يكتفي بإسناد قيمة إلى متغير.
وبعد تعريفه، لا يمكن أن يتغير نوع المتغير أبدًا.

```java
int count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning a different type
// count = false;
```

Java لغة [كائنية التوجه][object-oriented-programming] وتتطلب تعريف جميع الدوال داخل _صنف_.
وتُستخدم الكلمة المفتاحية `class` لتعريف صنف.

```java
class Calculator {
    // ...
}
```

وتُسمّى الدالة داخل الصنف _طريقة_.
ويمكن أن تحتوي كل طريقة على أي عدد من المعاملات، وقد لا تحتوي على أي منها.
ويجب تحديد نوع كل المعاملات صراحةً، فلا استنتاج للأنواع في المعاملات.
وبالمثل، يجب أيضًا تحديد نوع الإرجاع صراحةً.
وتُرجع الطرق القيم باستخدام الكلمة المفتاحية `return`.
وللسماح للأصناف الأخرى باستدعاء طريقة ما، يجب إضافة مُعدِّل الوصول `public`.

```java
class Calculator {
    public int add(int x, int y) {
        return x + y;
    }
}
```

ويتم استدعاء الطريقة بتحديد صنفها واسمها وتمرير الوسائط لكل معامل من معاملاتها.

```java
int sum = new Calculator().add(1, 2);  // here the  "add" method has been called to perform the task of addition
```

يُعرَّف النطاق في Java بين المحرفين `{` و`}`.

تدعم Java نوعين من التعليقات.
تُسبق التعليقات أحادية السطر بـ `//`، وتُدرج التعليقات متعددة الأسطر بين `/*` و`*/`.

[object-oriented-programming]: https://docs.oracle.com/javase/tutorial/java/javaOO/index.html
