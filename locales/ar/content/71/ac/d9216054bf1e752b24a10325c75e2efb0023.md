# مقدمة

تُرجع معظم الكلمات التي تعمل على المتتاليات في Factor متتاليات *جديدة*، وتترك مدخلاتها دون تغيير، لكن المصفوفات والمتجهات تدعم أيضًا **التعديل في المكان** عندما تريد تسجيل حالة تتطور بمرور الوقت.

تُغيّر الكلمتان `set-nth` و`change-nth` خانة في المكان، وتعملان على مصفوفة أو متجه. تبني الكلمة `<array>` مصفوفة قابلة للتعديل بطول ثابت، أما القيم الحرفية `V{ }` و`<vector>` و`push` و`pop` فهي المجموعة التي تعمل على المتجهات وحدها، لأن المصفوفات لا تستطيع تغيير طولها. وتنسخ `clone` المتتالية حتى لا تتسرب التعديلات اللاحقة إلى النسخة الأصلية.

```factor
USING: arrays kernel sequences ;

5 0 <array>                 ! a fresh array { 0 0 0 0 0 }
dup 7 2 swap set-nth        ! { 0 0 7 0 0 } — set position 2 to 7
.

V{ } clone                  ! a fresh, empty vector
"alice" over push           ! V{ "alice" }
"bob" over push             ! V{ "alice" "bob" }
dup pop .                   ! "bob"
.                           ! V{ "alice" }
```

[arrays]: https://docs.factorcode.org/content/vocab-arrays.html
[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
