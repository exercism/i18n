# مقدمة

في Ruby، **المصفوفات** مجموعات مرتّبة ومفهرسة بأعداد صحيحة من أي كائنات.
تبدأ فهارس المصفوفة من `0`.
يُفترض أن يكون الفهرس السالب نسبيًّا إلى نهاية المصفوفة، أي إن الفهرس `-1` يشير إلى العنصر الأخير في المصفوفة، و`-2` يشير إلى العنصر قبل الأخير فيها، وهكذا.
تدمج مصفوفات Ruby وحدة [Enumerable][enumerable-module]، التي تضيف عدة طرق للتجوال والبحث، بالإضافة إلى إمكانية الترتيب.

## إنشاء مصفوفة

- يمكن للمصفوفة في Ruby أن تحتوي على أنواع مختلفة من الكائنات.

```ruby
array = [1, "two", 3.0] #=> [1, "two", 3.0]
```

## إسناد العناصر

يمكن الوصول إلى العناصر أو تغييرها باستخدام الفهارس.
ويمكن الوصول إلى المصفوفات الفرعية بتحديد فهرس البداية والحجم.

```ruby
a = ["", "", "", "", ""]

a[4] = "hello"  #=> [nil, nil, nil, nil, "hello"]
a[0, 3] = [ 'a', 'b', 'c' ] #=> ["a", "b", "c", nil, "hello"]
```

- تعدّ الفهارس السالبة تنازليًّا من نهاية المصفوفة.

```ruby
a = ['a', 'b']

a[-1] = "Z"
a #=> ["a", "Z"]
```

## الإشارة إلى العناصر

- يمكن استرجاع العناصر في المصفوفة باستخدام الطريقة `#[]`.
- تُرجع العنصر عند الفهرس، أو تُرجع مصفوفة فرعية تبدأ عند فهرس البداية وتمتد بعدد من العناصر يساوي الطول.

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[2]    #=> "c"
a[6]    #=> nil
a[1, 2] #=> [ "b", "c" ]
```

- تعدّ الفهارس السالبة تنازليًّا من نهاية المصفوفة (`-1` هو العنصر الأخير)

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[-2]    #=> "d"
a[-3, 3] #=> [ "c", "d", "e" ]
```

## الحصول على معلومات عن مصفوفة

تتعقّب المصفوفات طولها في جميع الأوقات.
لمعرفة عدد العناصر التي تحتوي عليها المصفوفة، استخدم `length` أو `count` أو `size`.

```ruby
browsers = ['Chrome', 'Firefox', 'Safari', 'Opera', 'IE']
browsers.length #=> 5
browsers.count  #=> 5
browsers.size   #=> 5
```

## إضافة عناصر إلى المصفوفات

يمكن إضافة عناصر إلى نهاية المصفوفة باستخدام `push` أو `<<`:

```ruby
arr = [1, 2, 3, 4]
arr.push(5) #=> [1, 2, 3, 4, 5]
arr << 6    #=> [1, 2, 3, 4, 5, 6]
```

## إزالة عناصر من المصفوفة

الطريقة `pop` تحذف العنصر الأخير في المصفوفة وتُرجعه:

```ruby
arr = [1, 2, 3, 4, 5, 6]
arr.pop #=> 6
arr     #=> [1, 2, 3, 4, 5]
```
