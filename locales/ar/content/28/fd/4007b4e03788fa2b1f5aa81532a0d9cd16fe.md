# التعليمات

في هذا التمرين، أنت تلعب لعبة تقمّص أدوار تُسمى «Wizards and Warriors».
لتلعب هذه اللعبة، تحتاج إلى طريقة متعددة الأغراض لرمي حجر النرد لتحديد نتائج مختلفة.
سيكون هذا هو حجر النرد التقليدي ذا الأوجه الثمانية عشر، بأرقام من 1 إلى 18.
سيحتاج اللاعبون أيضًا إلى توليد قوة تعويذة عشوائية.

## 1. مكّن لاعبًا في _Wizards and Warriors_ من رمي حجر النرد

نفّذ طريقة `RollDie()` في صنف `Player`.

```csharp
var player = new Player();
player.RollDie();
// => >= 1 <= 18
```

## 2. يحتاج اللاعبون إلى قوتهم. وفّر وسيلة لتوليد قوة التعويذة

نفّذ طريقة `GenerateSpellStrength()` في صنف اللاعب.
تقع قوة التعويذة بين 0.0 و100.0، بحيث لا تشمل الحد الأعلى 100.0.

لاحظ أن قوة التعويذة يجب أن تكون عددًا عشريًا (وليس عددًا صحيحًا) لتقليل احتمال التعادل عند مقارنة قوة خصمين.

```csharp
var player = new Player();
player.GenerateSpellStrength();
// => >= 0.0 < 100.0
```
