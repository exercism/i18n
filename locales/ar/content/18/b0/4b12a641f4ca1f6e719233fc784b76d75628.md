# التعليمات

أنت تعمل في متجر بوتيك للأزياء على الإنترنت.
وقد أتيت بفكرة ميزة في الموقع تُقترح من خلالها أطقم الملابس على المستخدم.
ما يهمنا هنا هو أطقم الملابس المحتملة وأسعارها واستبعاد الخيارات المتضاربة.

~~~~exercism/note
قد توجد طرق مختلفة لحل المسائل التالية، لكن يمكن حلها جميعًا باستخدام الاستيعاب.
~~~~

## 1. إنشاء قطعة ملابس


نفّذ `clothingitem()` بحيث تأخذ `Tuple`s اثنين، أحدهما يحتوي على `categories` والآخر على `qualities` المقابلة لها.
ينبغي أن تُرجع الدالة `Dict` تكون فيه `categories` مفاتيح و`qualities` قيمًا.

```julia-repl
julia> categories = ("item_name", "price", "color", "base_color");

julia> qualities = ("Descriptive Name", 99.00, "Ochre Red", "red");

julia> clothingitem(categories, qualities)
Dict{String, Any} with 4 entries:
  "price"      => 99.0
  "item_name"  => "Descriptive Name"
  "base_color" => "red"
  "color"      => "Ochre Red"
```

ينبغي أن تكون دالتك قادرة على التعامل مع أي عدد من `categories`.

## 2. اقتراح التوليفات

نفّذ `get_combinations()` لتأخذ `Tuple` من القطع العلوية و`Tuple` من القطع السفلية.
ينبغي أن تُرجع الدالة `cartesian product` للصفوف على هيئة مصفوفة ثنائية الأبعاد (أي `Matrix`).
كل عنصر هو توليفة `(top, bottom)` على هيئة `Tuple`.
تتغير القطع العلوية على طول الصفوف، وتتغير القطع السفلية على طول الأعمدة.

```julia-repl
julia> tops = (
        Dict("item_name" => "Dress shirt"),
        Dict("item_name" => "Casual shirt")
        );

julia> bottoms = (
        Dict("item_name" => "Jeans"),
        Dict("item_name" => "Dress trousers")
       );

julia> get_combinations(tops, bottoms)
2×2 Matrix{Tuple{Dict{String, String}, Dict{String, String}}}:
 (Dict("item_name"=>"Dress shirt"), Dict("item_name"=>"Jeans"))   (Dict("item_name"=>"Dress shirt"), Dict("item_name"=>"Dress trousers"))
 (Dict("item_name"=>"Casual shirt"), Dict("item_name"=>"Jeans"))  (Dict("item_name"=>"Casual shirt"), Dict("item_name"=>"Dress trousers"))
```

## 3. جمع أسعار الأطقم

لكل قطعة ملابس حقل `price` مرتبط بها، لذا قد يكون من المفيد القدرة على مقارنة السعر الكامل للأطقم.
نفّذ `get_prices()` التي تأخذ مصفوفة من توليفات الملابس.
ينبغي أن تُرجع الدالة مصفوفة بالشكل نفسه تحتوي على أسعار الأطقم في مواضعها المقابلة.

```julia-repl
julia> tops = (
        Dict("item_name" => "Dress shirt", "base_color" => "blue", "price" => 35),
        Dict("item_name" => "Casual shirt", "base_color" => "black", "price" => 20)
       );

julia> bottoms = (
        Dict("item_name" => "Jeans", "base_color" => "blue", "price" => 30),
        Dict("item_name" => "Dress trousers", "base_color" => "black", "price" => 75)
       );

julia> combomatrix = get_combinations(tops, bottoms);

julia> get_prices(combomatrix)
2×2 Matrix{Int}::
 65  110
 50   95

julia> filteredmatrix = filter_clashing(combomatrix)
1-element Vector{Tuple{Dict{String, Any}, Dict{String, Any}}}:
 (Dict("price" => 20, "item_name" => "Casual shirt", "base_color" => "black"), Dict("price" => 30, "item_name" => "Jeans", "base_color" => "blue"))

julia> get_prices(filteredmatrix)
1-element Vector{Int}:
 50
```

## 4. استبعاد الأطقم المتضاربة

لكل قطعة ملابس حقل `base_color`.
استخدم هذا الحقل لإزالة كل التوليفات التي يكون فيها اللون الأساسي للقطعة العلوية مطابقًا للون الأساسي للقطعة السفلية.
نفّذ `filter_clashing()` لتأخذ مصفوفة من توليفات الملابس.
أرجِع مصفوفة أحادية البعد (أي `Vector`) تحتوي على التوليفات المطابقة.

```julia-repl
julia> tops = (
        Dict("item_name" => "Dress shirt", "base_color" => "blue", "price" => 35),
        Dict("item_name" => "Casual shirt", "base_color" => "black", "price" => 20)
       );

julia> bottoms = (
        Dict("item_name" => "Jeans", "base_color" => "blue", "price" => 30),
        Dict("item_name" => "Dress trousers", "base_color" => "black", "price" => 75)
       );

julia> combos = get_combinations(tops, bottoms);

julia> filter_clashing(combos)
1-element Vector{Tuple{Dict{String, Any}, Dict{String, Any}}}:
 (Dict("price" => 20, "item_name" => "Casual shirt", "base_color" => "black"), Dict("price" => 30, "item_name" => "Jeans", "base_color" => "blue"))
```
