# نبذة

تسمح [المعاملات المتغيّرة][variadic-parameters] للدالة بقبول صفر أو أكثر من القيم من نوع محدّد في معامل واحد.
وتُعرّف المعامل المتغيّر بإضافة ثلاث نقاط (`...`) إلى توصيف نوع المعامل.

وداخل جسم الدالة، يوفّر Swift هذه القيم على هيئة مصفوفة من النوع المحدّد:

```swift
import Foundation

func geometricMean(_ numbers: Double...) -> Double {
    var total = 1.0
    for number in numbers {
        total *= number
    }
    return pow(total, 1.0 / Double(numbers.count))
}

let result = geometricMean(1, 2, 3, 4, 5)
// result is 2.605171084697352
```

~~~~exercism/note
إذا كانت للدالة معاملات إضافية تأتي بعد المعامل المتغيّر، فيجب أن يحمل أول معامل يلي المعامل المتغيّر تسمية وسيط صريحة، حتى يعرف Swift أين تنتهي قائمة الوسائط المتغيّرة.
~~~~
