# تصحيح الأخطاء محليًا

عندما تشغّل اختبارات مسار Bash باستخدام [Bats](https://github.com/bats-core/bats-core)، يلتقط Bats كلاً من STDOUT و STDERR لتأكيدات المخرجات.

```exercism/caution
هذا يعمل محليًا مع `bats`، لكن **ليس** في محرر Exercism عبر الإنترنت.
```

إذا أردت طباعة مخرجات التصحيح دون التأثير على نتيجة الاختبار، فاكتبها إلى واصف الملف (fd) 3.

```bash
echo 'debug message' >&3
```

يعرض Bats المخرجات المكتوبة إلى fd 3 أثناء تشغيل الاختبار، لكنه لا يتضمن تلك المخرجات في التأكيدات مثل `assert_output`.

مثال على التشغيل:

```none
$ bats hello_world.bats
hello_world.bats
 ✓ Say Hi!
debug message
1 test, 0 failures
```

هذا مفيد عندما تشغّل الاختبارات محليًا.
