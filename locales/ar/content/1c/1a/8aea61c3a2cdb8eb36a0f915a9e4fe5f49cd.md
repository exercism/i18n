# التعليمات

ثلاثية فيثاغورس هي مجموعة من ثلاثة أعداد طبيعية {a, b, c} تحقق:

```text
a² + b² = c²
```

و:

```text
a < b < c
```

على سبيل المثال،

```text
3² + 4² = 5².
```

بمعطى عدد صحيح N، ابحث عن كل ثلاثيات فيثاغورس التي تحقق `a + b + c = N`.

على سبيل المثال، عند N = 1000، توجد ثلاثية فيثاغورس واحدة بالضبط تحقق `a + b + c = 1000`: `{200, 375, 425}`.
