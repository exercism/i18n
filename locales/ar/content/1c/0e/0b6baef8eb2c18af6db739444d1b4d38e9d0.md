# نبذة

[Nil][nil-dictionary] كلمة إنجليزية تعني "لا شيء" أو "صفر". في Elixir، `nil` قيمة خاصة تعني _غياب_ قيمة.

```elixir
# I do not have a favorite color
favorite_color = nil
```

`nil` ذرة، لكنه يُكتب عادةً بصيغة `nil` لا `:nil`. القيم المنطقية `true` و`false` هي أيضًا ذرات.

[//]: # (elixir-formatter-disable-next-block)

```elixir
nil === :nil
# => true

true === :true
# => true
```

يمكنك التحقق مما إذا كانت قيمة متغير هي `nil` باستخدام [`==`][kernel-equal]، أو عبر مطابقة الأنماط، أو باستخدام الحارس [`is_nil`][kernel-is-nil].

```elixir
def call(phone_number) do
  if phone_number == nil do
    :error
  end
end
```

```elixir
def call(phone_number) when is_nil(phone_number) do
  :error
end
```

```elixir
def call(nil) do
  :error
end
```
