# مقدمة

نوع `char` في F# هو قيمة بطول 16 بت تمثّل أصغر المكوّنات القابلة للعنونة في النص، وهو غير قابل للتغيير افتراضيًا.

يمكن تعريف قيم `char` كقيم حرفية بين علامتَي اقتباس مفردتين:

```fsharp
let ch = 'A'
// => val ch: char = 'A'
```

السلاسل النصية هي سلسلة من قيم `char`.

ويمكن استرجاع قيمة `char` مفردة من سلسلة نصية بالفهرسة (بدءًا من الصفر):

```fsharp
"Exercism"[4] //  =>  'c'
```

المرور على سلسلة نصية يُرجع قيمة `char` في كل خطوة.

يستخدم المثال التالي دالة عالية الرتبة ودالة مجهولة، من باب التسهيل.
سيُغطّى هذان المفهومان بشكل وافٍ لاحقًا في المنهج، لكنهما الآن طريقة موجزة لكتابة حلقة على قيم `char` في سلسلة نصية.

```fsharp
Seq.map (fun c -> c, int c) "F#"  //  =>  [('F', 70); ('#', 35)]
```

كما هو موضّح أعلاه، يمكن تحويل قيمة `char` إلى قيمة `int` المقابلة لها.
وهذا يعمل أيضًا (*في بعض الحالات على الأقل*) مع أنظمة كتابة أخرى:

```fsharp
Seq.map (fun c -> c, int c) "東京"  //  =>  [('東', 26481); ('京', 20140)]
```

تُستخدم قيمة Int16 الكامنة عند مقارنة المحارف:

```fsharp
'A' < 'D'  // =>  true
```

كما يمكن تحويل قيمة `int` إلى `char`:

```fsharp
char 77  // => 'M'
```

تحتوي مكتبة `System.Char` على المجموعة الكاملة من الطرق المتوقّعة في أي لغة من لغات .NET، مثل التحويل إلى الأحرف الكبيرة أو الصغيرة:

```fsharp
'a' |> System.Char.ToUpper  // =>  'A'

'Q' |> System.Char.ToLower  // =>  'q'
```
