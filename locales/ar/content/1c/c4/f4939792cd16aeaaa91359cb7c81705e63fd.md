# التعليمات

أنت مراقب طيور شغوف يتابع عدد الطيور التي زارت حديقتك خلال الأيام السبعة الأخيرة.

لديك خمس مهام، وكلها تتعلق بأعداد الطيور التي زارت حديقتك.

## 1. تحقق من أعداد الأسبوع الماضي

أنت تخزّن أعداد الطيور بصيغة JSON.
تخزّن مصفوفة «رئيسية» مصفوفات الأعداد الأسبوعية.
كل عدد أسبوعي عبارة عن مصفوفة من سبعة أعداد صحيحة، عدد واحد لكل يوم من أيام الأسبوع.
وأنت تضيف دائمًا الأسابيع الجديدة في نهاية المصفوفة الرئيسية.
نفّذ المرشّح الذي يُرجع أعداد الأسبوع الماضي.

```sh
$ cat bird-counting-data.json
[
  ...,
  [0, 2, 5, 3, 7, 8, 4],
  [4, 5, 9, 10, 9, 4, 3]
]

$ jq -f bird-count.jq < bird-counting-data.json
{
  "last_week": [0, 2, 5, 3, 7, 8, 4],
  ...
```

## 2. تحقق من عدد الطيور التي زارت أمس

نفّذ المرشّح لِيُرجع عدد الطيور التي زارت حديقتك أمس.
تُرتَّب أعداد الطيور حسب اليوم، إذ يكون العنصر الأول عدد أقدم يوم، والعنصر الأخير عدد اليوم الحالي.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "yesterday": 4,
  ...
```

## 3. احسب العدد الإجمالي للطيور الزائرة

نفّذ المرشّح لِيُرجع العدد الإجمالي للطيور التي زارت حديقتك هذا الأسبوع.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "total": 44,
  ...
```

## 4. احسب عدد الأيام المزدحمة

بعض الأيام أكثر ازدحامًا من غيرها.
اليوم المزدحم هو اليوم الذي زارت فيه خمسة طيور أو أكثر حديقتك.
نفّذ المرشّح لِيُرجع عدد الأيام المزدحمة هذا الأسبوع.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "busy_days": 4,
  ...
```

## 5. تحقق مما إذا كان هناك يوم بلا طيور زائرة

نفّذ المرشّح الذي يُرجع `true` إذا كان في هذا الأسبوع يوم لم تزر فيه أي طيور حديقتك، وإلا فأرجع `false`.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "has_day_without_birds": false
}
```
