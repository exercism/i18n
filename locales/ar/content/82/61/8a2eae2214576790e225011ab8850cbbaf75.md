# المتجهات كمكدس

المكدس بنية بيانات خطية مُحسَّنة للوصول من طرف واحد. تشبيه مناسب هو كومة من الأوراق على عمود: تُضاف الأوراق الجديدة دائمًا إلى الطرف نفسه، وتُزال الأوراق بالترتيب المعاكس لترتيب إضافتها. الأوراق التي أُضيفت أولًا تُزال أخيرًا، والتي أُضيفت أخيرًا تُزال أولًا.

بنية بيانات `Vec` في Rust مناسبة للاستخدام كمكدس. طريقة [`push`](https://doc.rust-lang.org/std/vec/struct.Vec.html#method.push) تضيف عناصر إلى ذيل المتجه. طريقة [`pop`](https://doc.rust-lang.org/std/vec/struct.Vec.html#method.pop) تزيل العنصر الأخير من المتجه. تتطلب كل من `push` و`pop` زمنًا مطفأً `O(1)` فقط.

## مثال

في هذا المثال، نستخدم متجهًا كمكدس لآلة حاسبة بسيطة تعمل بـ [الترميز البولندي العكسي (RPN)](https://en.wikipedia.org/wiki/Reverse_Polish_notation). يمكن العثور على الكود المصدري الكامل في [ساحة التجارب](https://play.rust-lang.org/?version=stable&mode=debug&edition=2018&gist=b40514e282cb753d0c3272778f92d736).

```rust
#[derive(Default)]
pub struct RpnCalculator {
    stack: Vec<Value>,
}

impl RpnCalculator {
    pub fn evaluate(&mut self, argument: Argument) -> Result<(), Error> {
        match argument {
            Argument::Value(value) => self.stack.push(value),
            Argument::Operator(operator) => {
                let b = self.stack.pop().ok_or(Error::StackUnderflow)?;
                let a = self.stack.pop().ok_or(Error::StackUnderflow)?;
                let output = operator.execute()(a, b);
                self.stack.push(output);
            }
        }
        Ok(())
    }

    pub fn conclude(self) -> Result<Value, Error> {
        if self.stack.len() == 1 {
            Ok(self.stack[0])
        } else {
            Err(Error::IncompleteCalculation)
        }
    }
}
```
