# التعليمات

في هذا التمرين، ستعالج رسائل السجل التي لها ستة مستويات خطورة.

كل سطر سجل هو سلسلة نصية منسّقة على النحو التالي: `"[<LVL>]: <MESSAGE>"`.

هذه هي مستويات السجل المختلفة:

| المستوى  | الرمز |
| --------- | ----- |
| `Trace`   | `TRC` |
| `Debug`   | `DBG` |
| `Info`    | `INF` |
| `Warning` | `WRN` |
| `Error`   | `ERR` |
| `Fatal`   | `FTL` |

## 1. تحليل مستوى السجل

عرّف تعداد `LogLevel` له ستة عناصر تقابل مستويات السجل المعرّفة أعلاه.
ثم عرّف الدالة `parse_log_level` التي تأخذ رسالة السجل معاملًا وتُرجع عضو التعداد المقابل لمستواها.

```python
parse_log_level("[INF]: File deleted")
#=> LogLevel.Info
```

## 2. دعم مستوى سجل غير معروف

لسوء الحظ، تظهر أحيانًا بعض رسائل السجل بمستوى خطورة _غير معروف_. للتعامل بسلاسة مع رسائل السجل "الغامضة" هذه في الدالة `parse_log_level`، أضف عضوًا اسمه `Unknown` إلى تعداد `LogLevel` يُرجع عند تحليل مستوى سجل غير معروف:

```python
parse_log_level("[XYZ]: Overly specific, out of context message")
#=> LogLevel.Unknown
```

## 3. تحويل رسالة السجل إلى الصيغة المختصرة

مستوى السجل في سطر السجل مطوّل جدًا. لتقليل مساحة القرص اللازمة لتخزين رسائل السجل، عُرّفت صيغة مختصرة: `"[<CODE_LEVEL>]:<MESSAGE>"`.

تتبع رموز مستويات السجل تعيينًا مباشرًا:

| المستوى  | الرمز |
| --------- | ---- |
| `Trace`   | `0`  |
| `Debug`   | `1`  |
| `Info`    | `4`  |
| `Warning` | `5`  |
| `Error`   | `6`  |
| `Fatal`   | `7`  |
| `Unknown` | `42` |

عرّف الدالة `convert_to_short_log()` التي تأخذ معاملين:

1. مستوى السجل: مستوى سجل الرسالة المُرسلة، مثل `LogLevel.Error`.
2. رسالة السجل: الرسالة من النوع `str`.

```python
convert_to_short_log(LogLevel.Error, "Stack overflow")
# => "6:Stack overflow"
```

## 4. إنشاء اسم مستعار

يبدو أن المستخدم أنشأ سجلات بـ `LogLevel.Warn` بدلًا من `LogLevel.Warning`. أنشئ `alias` لـ `LogLevel.Warning` وأرجع عضو الاسم المستعار الجديد في الدالة `get_warn_alias`.

يمكن فعل ذلك في صنف التعداد `LogLevel` نفسه المعرّف في أعلى الملف. ينبغي أن يشير كلا مستويي السجل إلى القيمة نفسها: `"WRN"`.

```python
get_warn_alias()
#=> LogLevel.Warn

get_warn_alias() == LogLevel.Warning
#=> True
```

## 5. جميع أسماء الأعضاء وقيمها

عرّف الدالة `get_members()`.

ينبغي أن تُرجع هذه الدالة مصفوفة من الصفوف `(name, value)` تحتوي على جميع أعضاء التعداد `LogLevel`.

```python
get_members()
#=> [('Trace', 'TRC'), ('Debug', 'DBG'), ('Info', 'INF'), ('Warning', 'WRN'),
# ('Error', 'ERR'), ('Fatal', 'FTL'), ('Unknown', 'UKN')]
```
