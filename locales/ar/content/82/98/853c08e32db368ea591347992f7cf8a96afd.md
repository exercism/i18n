# التعليمات

بصفتها ساحرةً ناشئة، تحتاج Elyse إلى التدرّب على بعض الأساسيات. لديها رزمة من البطاقات وتريد التعامل معها.

ولتسهيل الأمور قليلًا، لا تستخدم إلا البطاقات من 1 إلى 10، لذا يمكن تمثيل رزمة بطاقاتها بمصفوفة من الأعداد. ويقابل موضع كل بطاقة الفهرسَ في المصفوفة. أي أن الموضع 0 يشير إلى البطاقة الأولى، والموضع 1 إلى البطاقة الثانية، وهكذا.

<!-- prettier-ignore-start -->
~~~~exercism/note
يجب أن تُحدِّث جميع الدوال عدا دالتين مصفوفةَ البطاقات ثم تُرجع المصفوفة المعدَّلة، وهي طريقة شائعة للعمل تُعرف باسم نمط الباني، وتتيح لك ربط الدوال ببعضها بعضًا بطريقة أنيقة.

والاستثناءان هما `getItem`، التي يجب أن تُرجع البطاقة عند الموضع المعطى، و`checkSizeOfStack` التي يجب أن تُرجع `true` إذا تطابق الحجم المعطى.
~~~~

## 1. استرداد بطاقة من الرزمة

لاختيار بطاقة، أرجِع البطاقة عند الفهرس `position` من الرزمة المعطاة.

```javascript
const position = 2;
getItem([1, 2, 4, 1], position);
// => 4
```

## 2. استبدال بطاقة في الرزمة

أجرِ بعض خفة اليد واستبدل البطاقة عند الفهرس `position` بالبطاقة البديلة المعطاة.
أرجِع الرزمة المعدَّلة.

```javascript
const position = 2;
const replacementCard = 6;
setItem([1, 2, 4, 1], position, replacementCard);
// => [1, 2, 6, 1]
```

## 3. إدراج بطاقة في أعلى الرزمة

اجعل بطاقة تظهر بإدراج بطاقة جديدة في أعلى الرزمة.
أرجِع الرزمة المعدَّلة.

```javascript
const newCard = 8;
insertItemAtTop([5, 9, 7, 1], newCard);
// => [5, 9, 7, 1, 8]
```

## 4. إزالة بطاقة من الرزمة

اجعل بطاقة تختفي بإزالة البطاقة عند الموضع `position` المعطى من الرزمة.
أرجِع الرزمة المعدَّلة.

```javascript
const position = 2;
removeItem([3, 2, 6, 4, 8], position);
// => [3, 2, 4, 8]
```

## 5. إزالة البطاقة العليا من الرزمة

اجعل بطاقة تختفي بإزالة البطاقة العليا من الرزمة.
أرجِع الرزمة المعدَّلة.

```javascript
removeItemFromTop([3, 2, 6, 4, 8]);
// => [3, 2, 6, 4]
```

## 6. إدراج بطاقة في أسفل الرزمة

اجعل بطاقة تظهر بإدراج بطاقة جديدة في أسفل الرزمة.
أرجِع الرزمة المعدَّلة.

```javascript
const newCard = 8;
insertItemAtBottom([5, 9, 7, 1], newCard);
// => [8, 5, 9, 7, 1]
```

## 7. إزالة بطاقة من أسفل الرزمة

اجعل بطاقة تختفي بإزالة البطاقة من أسفل الرزمة.
أرجِع الرزمة المعدَّلة.

```javascript
removeItemAtBottom([8, 5, 9, 7, 1]);
// => [5, 9, 7, 1]
```

## 8. التحقق من حجم الرزمة

تحقّق مما إذا كان حجم الرزمة يساوي `stackSize` أم لا.

```javascript
const stackSize = 4;
checkSizeOfStack([3, 2, 6, 4, 8], stackSize);
// => false
```
