# ملحق التعليمات

## التنفيذ

الافتراضات:

1. يُمثَّل الصفر دائمًا في المخرجات بالشكل `[0]` وليس `[]`.
2. لا تظهر أصفار بادئة في أي مخرجات في حالات أخرى.
3. الأصفار البادئة مقبولة في المدخلات.
4. يُعتبر التسلسل الفارغ من أرقام الإدخال صفرًا وليس خطأً.

تعامل مع الحالات الإشكالية بإرجاع خطأ تُرجع طريقة `Error()` الخاصة به إحدى الرسائل التالية:

- input base must be >= 2
- output base must be >= 2
- all digits must satisfy 0 <= d < input base
