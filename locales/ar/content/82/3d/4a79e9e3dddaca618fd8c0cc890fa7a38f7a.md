# مقدمة

## التحميل الزائد للطرق

يسمح _التحميل الزائد للطرق_ بوجود عدة طرق في الصنف نفسه تحمل الاسم ذاته. ويجب أن تختلف الطرق المُحمَّلة عن بعضها إما بـ:

- عدد المعاملات
- نوع المعاملات

لا يوجد تحميل زائد للطرق بناءً على نوع الإرجاع.

سيستنتج المُصرِّف تلقائيًا أي طريقة مُحمَّلة يجب استدعاؤها بناءً على عدد المعاملات وأنواعها.

## الوسائط المُسمّاة

حتى الآن رأينا أن الوسائط المُمرَّرة إلى طريقة تُطابَق مع المعاملات المُعلَنة للطريقة بناءً على موضعها. وهناك أسلوب بديل، لا سيما حين تأخذ دالة عددًا كبيرًا من الوسائط، إذ يمكن للمُستدعي أن يطابق الوسائط بتحديد مُعرّف المعامل المُعلَن.

يوضح ما يلي الصياغة:

```csharp
class Card
{
    static string NewYear(int year, int month, int day)
    {
        return $"Happy {year}-{month}-{day}!";
    }
}

Card.NewYear(month: 1, day: 1, year: 2020);  // => "Happy 2020-1-1!"
```

## المعاملات الاختيارية

يمكن جعل معامل الطريقة اختياريًا بإسناد قيمة افتراضية له. وعند استدعاء طريقة ذات معاملات اختيارية، لا يُلزَم المُستدعي بتمرير قيمة لها. وإذا لم تُمرَّر أي قيمة لمعامل اختياري، فستُستخدم قيمته الافتراضية.

يجب أن تكون المعاملات الاختيارية _في نهاية_ قائمة المعاملات؛ فلا يمكن أن يليها معاملات غير اختيارية.

```csharp
class Card
{
    static string NewYear(int year = 2020)
    {
        return $"Happy {year}!";
    }
}

Card.NewYear();     // => "Happy 2020!"
Card.NewYear(1999); // => "Happy 1999!"
```
