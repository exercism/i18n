# مقدمة

في C#، تُعرف هياكل البيانات التي يمكنها أن تحمل صفرًا أو أكثر من العناصر باسم _المجموعات_. **المصفوفة** هي مجموعة لها حجم/طول ثابت، ويجب أن تكون جميع عناصرها من النوع نفسه. يمكن إسناد عناصر إلى المصفوفة أو استرجاعها منها باستخدام فهرس. المصفوفات في C# تبدأ من الصفر، أي أن فهرس العنصر الأول يكون دائمًا صفرًا:

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true
```

يمكن أيضًا تعريف المصفوفات باستخدام صيغة مختصرة تتيح لك إنشاء المصفوفة وتحديد قيمتها في الوقت نفسه. ولأن المترجم يستطيع الآن معرفة عدد العناصر التي ستحتويها المصفوفة، يمكن حذف الطول:

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

يمكن التعامل مع المصفوفات إما باستدعاء طرق نسخة المصفوفة أو خصائصها، أو باستخدام الطرق الثابتة المعرّفة في الصنف `Array`.
