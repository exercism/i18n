# نبذة

[الاستيعاب][for] يوفّر وسيلة لتحويل _الكائنات القابلة للتعداد_ بسهولة وبأسلوب تصريحي. وهو _سكر نحوي_ للمرور على الكائنات القابلة للتعداد في Elixir.

[//]: # (elixir-formatter-disable-next-block)

```elixir
for s <- ["a", "b", "hello", "c"], # 1. generator
  String.length(s) == 1,           # 2. filter
  into: "",                        # 3. collectable
  do: String.upcase(s)

# => "ABC"
```

يتكوّن الاستيعاب من ثلاثة أجزاء:

1. _المولّدات_:
   - قيم تُعدَّد من بنى تطبّق بروتوكول [_Enumerable_][enumerable].
   - تعبيرات مطابقة الأنماط لتفكيك القيم المُعدَّدة.
2. _المرشحات_: شروط من نوع القيم المنطقية، تُستخدم لاختيار القيم المُعدَّدة التي ستُستخدم عند إنشاء القيم الجديدة.
3. _الكائنات القابلة للتجميع_: بنية تطبّق بروتوكول [_Collectable_][collectable]، تُستخدم لتجميع القيم الجديدة.

توجد استيعابات أحادية الأسطر واستيعابات متعددة الأسطر. عند استخدام أكثر من مولّد واحد، يُعدَّد [الجداء الديكارتي][cartesian-product] للقيم المولّدة. وهذا يعني أن كل قيمة يولّدها المولّد الأول ستُقرن مرة واحدة مع كل قيمة يولّدها المولّد الثاني.

```elixir
for n <- [0, 1, 2, 3], do: n + 1
# => [1, 2, 3, 4]

for x <- [0, 1],
    y <- [0, 1] do
  {x, y}
end

# => [{0, 0}, {0, 1}, {1, 0}, {1, 1}]
```

تُدرَج القيمة الموجودة في كتلة `do` داخل _الكائن القابل للتجميع_ **لكل قيمة مولّدة** من _الكائن القابل للتعداد_.

```elixir
for _ <- [1, 2, 3], do: :a
# => [:a, :a, :a]
```

يمكن أن تحدث مطابقة الأنماط داخل الاستيعاب، إما على الجانب الأيسر من `<-` أو في سطر مستقل.

```elixir
for {atom, str} <- [a: "string"], do: str
# => ["string"]

for pair <- [a: "string"],
    {atom, str} = pair do
  str
end

# => ["string"]
```
