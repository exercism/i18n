# ملحق التعليمات

## السجلات

| السجل | الاستخدام | النوع | الوصف |
| -------- | --------- | ------- | ------------------------------------------------------ |
| `$a0`    | إدخال     | عنوان | اللون الأول كسلسلة نصية منتهية بـ `null` |
| `$a1`    | إدخال     | عنوان | اللون الثاني كسلسلة نصية منتهية بـ `null` |
| `$a2`    | إدخال     | عنوان | اللون الثالث كسلسلة نصية منتهية بـ `null` (قد تكون فارغة) |
| `$v0`    | إخراج     | عدد صحيح | قيمة المقاومة |
| `$t0-9`  | مؤقت | أي | للتخزين المؤقت |
