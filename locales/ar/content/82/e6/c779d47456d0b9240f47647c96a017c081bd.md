# مقدمة

مطابقة الأنماط هي عملية التفرّع بناءً على مطابقة قيمة لأنماط معطاة، قد تكون عميقة. في Haxe، تُجرى **مطابقة الأنماط** باستخدام تعبير `switch` وتعبيرات `case` المنفردة.

لنلقِ نظرة على بنية البيانات هذه:

```haxe
enum Tree<T> {
  Leaf(v:T);
  Node(l:Tree<T>, r:Tree<T>);
}
```

- تُطابَق الأنماط دائمًا من الأعلى إلى الأسفل.
- النمط الأعلى الذي يطابق القيمة المُدخَلة يُنفَّذ تعبيره.
- يطابق النمط `_` أي شيء، لذا فإن `case _:` يعادل `default:`

## مطابقة الـ `enum`

يمكن مطابقة أنواع الـ `enum` عبر مُنشئها بشكل طبيعي:

```haxe
var myTree = Node(Leaf("foo"), Node(Leaf("bar"), Leaf("foobar")));

var match = switch (myTree) {
  // Matches any Leaf
  case Leaf(_):
    "0";

  // Matches any Node that has r = Leaf
  case Node(_, Leaf(_)):
    "1";

  // Matches any Node that has
  // r = another Node which has
  // l = Leaf("bar")
  case Node(_, Node(Leaf("bar", _))):
    "2";

  // Matches anything
  case _:
    "3";
}

trace(match); // 2
```
