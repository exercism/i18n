# ملحق التعليمات

## صيغة الإخراج

من المتوقع أن تُرجع الطريقة `solve()` كائنًا له هذه الخصائص:

- `moves` - عدد عمليات الدلو اللازمة للوصول إلى الهدف
  (يشمل ملء دلو البداية)،
- `goalBucket` - اسم الدلو الذي بلغ مقدار الهدف،
- `otherBucket` - المقدار الموجود في الدلو الآخر.

مثال:

```json
{
  "moves": 5,
  "goalBucket": "one",
  "otherBucket": 2
}
```
