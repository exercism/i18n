# مقدمة

## الحزم

في Go يُنظَّم التطبيق في حزم.
الحزمة مجموعة من الملفات المصدرية الموجودة في المجلد نفسه.
يجب أن يكون لجميع الملفات المصدرية في المجلد اسم الحزمة نفسه في أعلى الملف.
وبحسب العُرف، تُسمّى الحزم بأسماء المجلدات التي تقع فيها.

```go
package greeting
```

توفّر Go مكتبة قياسية واسعة من الحزم يمكنك استخدامها في برنامجك عبر الكلمة المفتاحية `import`.
وتُستورد حزم المكتبة القياسية باستخدام أسمائها.

```go
package greeting

import "fmt"
```

ثم يُشار إلى الحزمة المستوردة باسم الحزمة:

```go
world := "World"
fmt.Sprintf("Hello %s", world)
```

تحدّد Go ما إذا كان يمكن استدعاء عنصر من الكود في حزم أخرى من خلال طريقة تعريفه.
لجعل دالة أو نوع أو متغير أو ثابت أو حقل بنية مرئيًا من الخارج (وهو ما يُعرف بأنه _مُصدَّر_)، يجب أن يبدأ الاسم بحرف كبير.

```go
package greeting

// Hello is a public function (callable from other packages).
func Hello(name string) string {
    return "Hello " + name
}

// hello is a private function (not callable from other packages).
func hello(name string) string {
    return "Hello " + name
}
```

## تنسيق السلاسل النصية

توفّر Go حزمة مدمجة تُسمى `fmt` (حزمة التنسيق) تقدّم مجموعة متنوعة من الدوال للتحكم في تنسيق المدخلات والمخرجات.
الدالة الأكثر استخدامًا هي `Sprintf`، وهي تستخدم أفعالًا مثل `%s` لإدراج القيم داخل سلسلة نصية وتُرجع تلك السلسلة النصية.

```go
import "fmt"

food := "taco"
fmt.Sprintf("Bring me a %s", food)
// Returns: Bring me a taco
```

في Go تُنسَّق قيم الأعداد العشرية بسهولة باستخدام أفعال `Sprintf`: `%g` (تمثيل مختصر)، و`%e` (أس)، و`%f` (بدون أس).
وتتيح الأفعال الثلاثة التحكم في عرض الحقل وموضعه الرقمي.

```go
import "fmt"

number := 4.3242
fmt.Sprintf("%.2f", number)
// Returns: 4.32
```

يمكنك العثور على قائمة كاملة بالأفعال المتاحة في [توثيق حزمة التنسيق][fmt-docs].

تحتوي `fmt` على دوال أخرى للتعامل مع السلاسل النصية، مثل `Println` الذي يطبع ببساطة الوسائط التي يستقبلها إلى وحدة التحكم، و`Printf` الذي ينسّق المدخلات بالطريقة نفسها التي يستخدمها `Sprintf` قبل طباعتها.

[fmt-docs]: https://pkg.go.dev/fmt
