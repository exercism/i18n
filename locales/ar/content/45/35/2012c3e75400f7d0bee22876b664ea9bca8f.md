# تصريح النوع

PHP لغة _ديناميكية الأنواع_، أي أن المتغير قد يحتوي على أي نوع من المعلومات.
تتيح PHP تصريحًا _اختياريًا_ وقويًا بالأنواع لخصائص الأصناف ووسائط الدوال وقيم الإرجاع من الدوال.
توفّر التصريحات القوية بالأنواع في PHP تحققات للنوع وقت التشغيل، غير أن PHP ستحاول تحويل الأنواع القياسية قسريًا لتطابق التصريح إن أمكن.
ويمكن تعطيل سلوك التحويل القسري باستخدام التصريح `strict_types` في أعلى الملف.

```php
<?php
declare(strict_types=1);
```

بالإضافة إلى ذلك، يمكن للدوال أن تُرجع نوع إرجاع `void` للإشارة إلى أنه لا توجد قيمة تُرجَع من الدالة.

```php
<?php
declare(strict_types=1);

class Driver
{
    string $serial_number;

    function setSerialNumber(string $number): void
    {
        $this->serial_number = $number;
    }

    function getSerialNumber(): string
    {
        return $this->serial_number; 
    }
}

$driver = new Driver(); 
$driver->setSerialNumber(1234);
// => This will throw a TypeError with strict_types=1
```

## اتحاد الأنواع

إذا أمكن أن يكون وسيط دالة أو القيمة المُرجَعة منها أو خاصية صنف من أكثر من نوع واحد، فيمكنك تصريح اتحاد أنواع.

```php
<?php

class IdentityCard
{
    private int|float $id = 0;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

## الأنواع المختلطة

عند العمل على الكود، قد لا نتمكن من تحديد نوع بعينه.
بدءًا من PHP 8.0، توفّر PHP نوعًا بمثابة منفذ هروب يُسمى `mixed`.
ويعادل `mixed` اتحاد الأنواع `object|resource|array|string|float|int|bool|null`.
