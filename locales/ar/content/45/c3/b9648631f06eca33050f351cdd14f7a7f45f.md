# التعليمات

بالنظر إلى مصفوفتين، حدّد ما إذا كانت المصفوفة الأولى محتواة داخل المصفوفة الثانية، أو كانت المصفوفة الثانية محتواة داخل المصفوفة الأولى، أو كانت كلتا المصفوفتين محتواة داخل الأخرى، أو لم يكن أيٌّ من ذلك صحيحًا.

وبشكل أدق، تكون المصفوفة A مصفوفة فرعية من المصفوفة B إذا حصلت، بحذف صفر أو أكثر من العناصر من مقدمة B وصفر أو أكثر من العناصر من مؤخرة B، على مصفوفة تساوي A تمامًا.

أمثلة:

 * A = [1, 2, 3]، B = [1, 2, 3, 4, 5]، المصفوفة A مصفوفة فرعية من B
 * A = [3, 4, 5]، B = [1, 2, 3, 4, 5]، المصفوفة A مصفوفة فرعية من B
 * A = [3, 4]، B = [1, 2, 3, 4, 5]، المصفوفة A مصفوفة فرعية من B
 * A = [1, 2, 3]، B = [1, 2, 3]، المصفوفة A تساوي B
 * A = [1, 2, 3, 4, 5]، B = [2, 3, 4]، المصفوفة A مصفوفة فائقة من B
 * A = [1, 2, 4]، B = [1, 2, 3, 4, 5]، المصفوفة A ليست مصفوفة فائقة من B ولا مصفوفة فرعية منها ولا مساوية لها
