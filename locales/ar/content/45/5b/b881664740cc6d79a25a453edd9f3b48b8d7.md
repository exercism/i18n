# التعليمات

في هذا التمرين ستتعامل مع أسطر السجل.

كل سطر سجل هو سلسلة نصية بالتنسيق التالي: `"[<LEVEL>]: <MESSAGE>"`.

هناك ثلاثة مستويات مختلفة للسجل:

- `INFO`
- `WARNING`
- `ERROR`

لديك ثلاث مهام، كل واحدة منها تأخذ سطر سجل وتطلب منك فعل شيء به.

## 1. استخراج الرسالة من سطر السجل

نفّذ الدالة `message` لتُرجع رسالة سطر السجل:

```clojure
(message "[ERROR]: Invalid operation")
;;=> "Invalid operation"
```

يجب إزالة أي مسافات بيضاء في البداية أو النهاية:

```clojure
(message "[WARNING]:  Disk almost full\r\n")
;;=> "Disk almost full"
```

## 2. استخراج مستوى السجل من سطر السجل

نفّذ الدالة `log-level` لتُرجع مستوى السجل الخاص بسطر السجل، ويجب إرجاعه بأحرف صغيرة:

```clojure
(log-level "[ERROR]: Invalid operation")
;;=> "error"
```

## 3. إعادة تنسيق سطر السجل

نفّذ الدالة `reformat` التي تعيد تنسيق سطر السجل، بوضع الرسالة أولًا ثم مستوى السجل بعدها بين الأقواس الهلالية:

```clojure
(reformat "[INFO]: Operation completed")
;;=> "Operation completed (info)"
```
