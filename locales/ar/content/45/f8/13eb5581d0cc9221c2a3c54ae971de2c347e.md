# الاختبارات

## الإعداد

اتّبع [تعليمات إعداد JavaScript][docs-exercism-javascript] لتثبيت التبعيات اللازمة.

## المتطلبات

ثبّت تبعيات التمرين:

```shell
corepack pnpm install
```

إذا اشتكى `corepack` من كونه غير ممكّن، فيمكنك تمكينه بتشغيل:

```bash
corepack enable pnpm
```

## اجتياز مجموعة الاختبارات

تأتي جميع التمارين مع مجموعة اختبارات تساعدك على التحقق من صحة حلّك قبل إرساله.
يمكنك تنفيذ هذه الاختبارات بفتح موجه أوامر في مجلد التمرين، ثم تشغيل:

```bash
corepack pnpm test
```

في بعض مجموعات الاختبارات، يتم تخطي جميع الاختبارات باستثناء الأول.

بمجرد نجاح اختبار واحد، يمكنك تمكين الاختبار التالي بتغيير `xtest` إلى `test`.

## كتابة اختبارات مخصّصة

إذا رغبت في كتابة اختبارات إضافية مخصّصة، فأنشئ ملفًا جديدًا اسمه `custom.spec.js`، وأرسله مع حلّك إلى جانب الملف الجديد:

```shell
exercism submit numbers.js custom.spec.js
```
