# مقدمة

في Go، الدوال قيم من الدرجة الأولى.
هذا يعني أنك تستطيع أن تفعل بالدوال الأشياء نفسها التي تفعلها مع بقية القيم: أن تسند الدوال إلى متغيرات، وأن تمرّرها كوسائط إلى دوال أخرى، بل وأن تُرجع دوال من دوال أخرى.

في المثال التالي ننشئ دالتين، `engGreeting` و`espGreeting`، ونسندهما إلى المتغير `greeting`:

```go
import "fmt"

func engGreeting(name string) string {
	return fmt.Sprintf("Hello %s, nice to meet you!", name)
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := engGreeting			// greeting is a variable of type func(string) string
fmt.Println(greeting("Alice"))	// Hello Alice, nice to meet you!

greeting = espGreeting
fmt.Println(greeting("Alice")) 	// ¡Hola Alice, mucho gusto!
```

تتيح لنا قيم الدوال أن نمرّر إلى الدوال لا البيانات فقط، بل السلوك أيضًا.
في المثال التالي نمرّر سلوكًا إلى الدالة `dialog` عبر المعامل `greetingFunc`:

```go
func dialog(name string, greetingFunc func(string) string) {
	fmt.Println(greetingFunc(name))
	fmt.Println("I'm a dialog bot.")
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := espGreeting
dialog("Alice", greeting)
// Output:
// ¡Hola Alice, mucho gusto!
// I'm a dialog bot.
```

قيمة المتغير غير المهيَّأ من نوع دالة هي `nil`.
لذلك فإن استدعاء قيمة دالة قيمتها `nil` يؤدي إلى `panic`.

```go
var dutchGreeting func(string) string
dutchGreeting("Alice") // panic: call of nil function
```

يمكن مقارنة قيم الدوال بـ `nil`.
وهذا مفيد لتجنّب حالات `panic` غير الضرورية في البرنامج.

```go
var dutchGreeting func(string) string
if dutchGreeting != nil {
	dutchGreeting("Alice") // safe to call dutchGreeting
}
```

## أنواع الدوال

استخدام قيم الدوال ممكن بفضل أنواع الدوال في Go.
نوع الدالة يدلّ على مجموعة كل الدوال التي لها التسلسل نفسه من أنواع المعاملات والتسلسل نفسه من أنواع النتائج.
ويمكن تعريف أنواع خاصة بالمستخدم فوق أنواع الدوال.
على سبيل المثال، يمكن تحديث الدالة `dialog` من الأمثلة السابقة كما يلي:

```go
type greetingFunc func(string) string

func dialog(name string, f greetingFunc) {
	fmt.Println(f(name))
	fmt.Println("I'm a dialog bot.")
}
```

## الدوال المجهولة

من الأدوات القوية الأخرى التي يتيحها لنا دعم الدوال من الدرجة الأولى: الدوال المجهولة.
تُعرَّف الدوال المجهولة عند موضع استخدامها، دون اسم يلي الكلمة المفتاحية `func`.
ولهذه الدوال وصول إلى متغيرات الدالة المحيطة بها.

على سبيل المثال:

```go
func fib() func() int {
	var n1, n2 int

	return func() int {
		if n1 == 0 && n2 == 0 {
			n1 = 1
		} else {
			n1, n2 = n2, n1 + n2
		}
		return n2
	}
}

next := fib()
for i := 0; i < N; i++ {
  fmt.Printf("F%d\t= %4d\n", i, next())
}
```

استدعاء `fib` يعرّف المتغيرين `n1` و`n2` ويُرجع دالة مجهولة تغيّر بدورها قيم هذين المتغيرين في كل مرة تُستدعى فيها الدالة.
الاستدعاء رقم N للدالة المجهولة يُرجع العدد رقم N من متتالية فيبوناتشي بدءًا من 0. وللدالة الداخلية المجهولة وصول إلى المتغيرات المحلية (`n1` و`n2`) في الدالة المحيطة `fib`.
وهذه طريقة رائعة لتُبقي قيم الدوال حالتها بين الاستدعاءات.
نقول إن الدالة المجهولة إغلاق للمتغيرين `n1` و`n2`.
[الإغلاقات][closure] شائعة الاستخدام في البرمجة، وقد ترى لغات أخرى تدعمها.

[closure]: https://en.wikipedia.org/wiki/Closure_(computer_programming)
