# مقدمة

## المقارنات

يدعم Python عوامل المقارنة الأساسية التالية:

| العامل | العملية                  | الوصف                                                               |
| -------- | -------------------------- | ------------------------------------------------------------------------- |
| `>`      | "أكبر من"             | تكون `a > b` مساوية لـ `True` إذا كانت قيمة `a` **أكبر تمامًا** من قيمة `b`        |
| `<`      | "أصغر من"                | تكون `a < b` مساوية لـ `True` إذا كانت قيمة `a` **أصغر تمامًا** من قيمة `b`           |
| `==`     | "يساوي"                 | تكون `a == b` مساوية لـ `True` إذا كانت قيمة `a` **مساوية تمامًا** لقيمة `b`           |
| `>=`     | "أكبر من أو يساوي" | تكون `a >= b` مساوية لـ `True` إذا كانت `a > b` أو `a == b` من حيث القيمة                        |
| `<=`     | "أصغر من أو يساوي"    | تكون `a <= b` مساوية لـ `True` إذا كانت `a < b` أو `a == b` من حيث القيمة                        |
| `!=`     | "لا يساوي"             | تكون `a != b` مساوية لـ `True` إذا كانت `a == b` مساوية لـ `False`                                 |
| `is`     | "الهوية"                 | تكون `a is b` مساوية لـ `True` إذا **_وفقط إذا_** كان `a` و`b` هما _الكائن_ نفسه |
| `is not` | "نفي الهوية"         | تكون `a is not b` مساوية لـ `True` إذا لم يكن `a` و`b` هما _الكائن_ نفسه       |
| `in`     | "اختبار الاحتواء"         | تكون `a in b` مساوية لـ `True` إذا كان `a` عضوًا في `b` أو مجموعة فرعية منها أو عنصرًا فيها            |
| `not in` | "نفي اختبار الاحتواء" | تكون `a not in b` مساوية لـ `True` إذا لم يكن `a` عضوًا في `b` ولا مجموعة فرعية منها ولا عنصرًا فيها  |

كلها لها الأولوية نفسها (_وهي أعلى من أولوية [العمليات المنطقية][boolean operations]، لكنها أقل من أولوية العمليات الحسابية أو عمليات البت_).

## المقارنة بين أنواع البيانات المختلفة

الكائنات التي تنتمي إلى أنواع مختلفة (_ما عدا الأنواع العددية_) لا تتساوى أبدًا عند المقارنة افتراضيًا.
كذلك فإن النسخ غير المتطابقة من `class` _**لن**_ تتساوى عند المقارنة، إلا إذا عرّف `class` طرق [المقارنة الغنية][rich comparisons] الخاصة التي تخصّص سلوك المقارنة الافتراضي لـ `object`.
سيُغطّى التخصيص عبر `rich comparisons` في تمرين لاحق.
لمزيد من التفاصيل (الكثير منها) حول هذا الموضوع، راجع [مقارنات القيم][value comparisons] في توثيق Python.

الأنواع العددية استثناء (في الغالب) من قاعدة تطابق الأنواع هذه.
**يمكن** اعتبار `integer` مساويًا لـ `float` (_أو اعتبار [`octal`][octal] مساويًا لـ [`hexadecimal`][hex]_)، ما دام من الممكن تحويل النوعين ضمنيًا لأغراض المقارنة.

بالنسبة إلى الأنواع العددية الأخرى في المكتبة القياسية لـ Python ([complex][complex numbers] و[decimal][decimal numbers] و[fractions][rational numbers])، تُعرَّف عوامل المقارنة حيث "يكون ذلك منطقيًا" (_حيث لا يغيّر التحويل الضمني النتيجة_)، لكنها تُطلق `TypeError` إذا تعذّر تحويل الكائنات الأساسية بدقة لأغراض المقارنة.
لمزيد من المعلومات عن القواعد التي يستخدمها Python في _التحويل العددي_، راجع [التحويلات الحسابية][arithmetic conversions] في توثيق Python.

```python
>>> import fractions

# A string cannot be converted to an int.
>>> 17 == '17'
False

# An int can be converted to float for comparison.
>>> 17 == 17.0
True

# The fraction 6/3 can be converted to the int 2
# The int 2 can be converted to 0b10 in binary.
>>> 6/3 == 0b10
True

# An int can be converted to a complex number with a 0 imaginary part.
>>> 17 == complex(17)
True

# The fraction 2/5 can be converted to the float 0.4
>>> 0.4 == 2/5
True

>>> complex(2/5, 1/2) == complex(0.4, 0.5)
True
```

أي مقارنة ترتيبية بين عدد ونوع `NaN` (_ليس عددًا_) تكون `False`.
ومن الآثار الجانبية المربكة لتعريف `NaN` في Python أن `NaN` لا يتساوى أبدًا مع `NaN` عند المقارنة.

```python
>>> x = float('NaN')

>>> 3 < x
False

>>> x < 3
False

# NaN never compares equal to NaN
>>> x == x
False
```

## مقارنة السلاسل النصية

على عكس الأعداد، تُقارَن السلاسل النصية (`str`) [معجميًا][lexographic order]، باستخدام نقاط ترميز Unicode الخاصة بها (_أي نتيجة تمرير كل نقطة ترميز في `str` إلى الدالة المدمجة [`ord()`][ord]، التي تُرجع `int`_).
إذا تطابقت جميع نقاط الترميز في السلسلتين وكانت _**بالترتيب نفسه**_، تُعدّ السلسلتان متساويتين.
تُجرى هذه المقارنة على أساس الأزواج: الأول مع الأول، والثاني مع الثاني، وهكذا.
في Python 3.x، لا يمكن تحويل `str` و`bytes` أو مقارنتهما مباشرة.

```python
>>> 'Python' > 'Rust'
False

>>> 'Python' > 'JavaScript'
True

# Examples with Mandarin.
# hello < goodbye
>>> '你好' < '再见'
True

# ord() of first characters
>>> ord('你'), ord('再')
(20320, 20877)

# ord() of second characters
>>> ord('好'), ord('见')
(22909, 35265)

# And with Korean words.
# Pretty < beautiful.
>>> '예쁜' < '아름다운'
False

>>> ord('예'), ord('아')
(50696, 50500)
```

## تسلسل المقارنات

يمكن ربط عوامل المقارنة _بأي شكل_، أي يمكن استخدامها في أي توليفة وبأي طول.
لاحظ أن تقييم التعبير يجري من `left` إلى `right`.

على سبيل المثال، `x < y <= z` تكافئ `x < y` `and` `y <= z`، باستثناء أن `y` يُقيَّم **مرة واحدة فقط**.
في كلتا الحالتين، _لا_ يُقيَّم `z` **إطلاقًا** عندما يكون `x < y` مساويًا لـ `False`.
يُسمى هذا غالبًا `short-circuit evaluation`، حيث يتوقف التقييم إذا كانت قيمة صدق التعبير قد تحددت بالفعل.

يدعم `Short circuiting` كلًا من العوامل المنطقية المتنوعة والدوال، وكذلك تسلسل المقارنات في Python.
وعلى عكس كثير من لغات البرمجة الأخرى، بما فيها `C` و`C++` و`C#` و`Java`، فإن التعبيرات المتسلسلة مثل `a < b < c` في Python تُفسَّر تفسيرًا رياضيًا تقليديًا وتتبع أسبقية تقليدية.

```python
>>> x = 2
>>> y = 5
>>> z = 10

>>> x < y < z
True

>>> x < y > z
False

>>> x > y < z
False
```

## مقارنة هوية الكائن

يختبر العاملان `is` و`is not` [_هوية_][object identity] الكائن، لا _قيمته_.
لا تتغير هوية الكائن أبدًا بعد إنشائه، ويمكن معرفتها باستخدام الدالة [`id()`][id function].

تكون `<apple> is <orange>` مساوية لـ `True` إذا **_وفقط إذا_** كان `id(<apple>)` == `id(<orange>)`.
ويكون `<apple> is not <orange>` عكس ذلك.

نظرًا إلى كونهما كائنين مفردين، ينبغي دائمًا مقارنة `None` و`NotImplemented` بالعناصر باستخدام `is` و`is not`.
راجع وثائق مرجع Python حول [مقارنات القيم][value comparisons none] و[PEP8][pep8 programming recommendations] لمزيد من التفاصيل عن هذه الاتفاقية.

```python
>>> my_fav_numbers = [1, 2, 3]

>>> your_fav_numbers = my_fav_numbers

>>> my_fav_numbers is your_fav_numbers
True

# The returned id will differ by system and python version.
>>> id(my_fav_numbers)
4517478208

# your_fav_numbers is only an alias pointing to the original my_fav_numbers object.
# Assigning a new name does not create a new object.
>>> id(your_fav_numbers)
4517478208


>>> my_fav_numbers is not your_fav_numbers
False

>>> my_fav_numbers is not None
True

>>> my_fav_numbers is NotImplemented
False
```

## مقارنات الانتماء

يختبر العاملان `in` و`not in` _الانتماء_.
تكون `<fish> in <soup>` مساوية لـ `True` إذا كان `<fish>` عضوًا في `<soup>` (_إذا كان `<fish>` مجموعة فرعية من `<soup>` أو محتوى داخلها_)، وتكون `False` خلاف ذلك.
وتُرجع `<fish> not in <soup>` النفي، أو _عكس_ `<fish> in <soup>`.

بالنسبة إلى نوعي السلسلة النصية وbytes، تكون `<name> in <fullname>` مساوية لـ `True` **_إذا وفقط إذا_** كانت `<name>` سلسلة فرعية من `<fullname>`.

```python
# A set of lucky numbers.
>>> lucky_numbers = {11, 22, 33}
>>> 22 in lucky_numbers
True

>>> 44 in lucky_numbers
False

# A dictionary of employee information.
>>> employee = {'name': 'John Doe', 
                'id': 67826, 'age': 33, 
                'title': 'ceo'}

# Checking for the membership of certain keys.
>>> 'age' in employee
True

>>> 33 in employee
False

>>> 'lastname' not in employee
True

# Checking for substring membership
>>> name = 'Super Batman'
>>> 'Bat' in name
True

>>> 'Batwoman' in name
False
```
