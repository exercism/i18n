# مقدمة

## مصفوفات الأحرف

تُنشأ مصفوفات الأحرف باستخدام Sigil ‏`~c`.

```elixir
~c"hello"
```

~~~~exercism/note
لاحظ أن مصفوفات الأحرف في الإصدارات الأقدم من Elixir كانت تُمثَّل بالشكل `'hello'` باستخدام علامات الاقتباس المفردة.
~~~~

رغم أنها تبدو شبيهة جدًا بالسلاسل النصية، فإن نوعي البيانات مختلفان تمامًا عن بعضهما. مصفوفة الأحرف هي مصفوفة من الأعداد الصحيحة. تُمثّل هذه الأعداد قيم Unicode لحرف معيّن، وتُعرف أيضًا بنقاط الترميز.

```elixir
[65, 66, 67]
# => ~c"ABC"
```

يمكنك أن تسبق الحرف بـ `?` للحصول على نقطة الترميز الخاصة به.

```elixir
?A
# => 65

[?:, ?)]
# => ~c":)"
```

ولأن مصفوفات الأحرف هي مصفوفات، يمكنك التعامل معها كما تتعامل مع أي مصفوفة أخرى، باستخدام الاستدعاء الذاتي ومطابقة الأنماط.

```elixir
[first_letter | _] = ~c"cat"
first_letter
# => 99
```

يمكنك دمج مصفوفتين باستخدام `++`.

```elixir
~c"hi" ++ ~c"!"
# => ~c"hi!"
```

كلما كانت المصفوفة الأولى أطول، صار الدمج أبطأ، لذا تجنّب الإلحاق المتكرر بمصفوفات ذات طول اعتباطي.

## `case`

بنية `case` هي بنية تحكّم في مسار التنفيذ تتيح لنا مقارنة قيمة معيّنة بعدة أنماط. تُقيَّم الفروع في تعبير `case` من الأعلى إلى الأسفل، حتى يتم العثور على تطابق.

```elixir
age = 15

case age do
  0 -> ~c"infant"
  age when age < 4 -> ~c"baby"
  age when age < 13 -> ~c"child"
  age when age < 18 -> ~c"teenager"
  _ -> ~c"adult"
end

# => ~c"teenager"
```
