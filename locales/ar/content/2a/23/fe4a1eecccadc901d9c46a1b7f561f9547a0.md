# حول

تتيح العوامل الثلاثية تعريف شروط `if` داخل التعبيرات بدلًا من كتل العبارات. وهذا يحاكي أساليب البرمجة الوظيفية، وغالبًا ما يجعل الكود أكثر تعبيرًا وأقل عرضة للأخطاء.

يجمع العامل الثلاثي بين 3 تعبيرات: شرط يتبعه تعبير يتم تقييمه وإرجاعه إذا كان الشرط صحيحًا (الجزء `if`، الذي يبدأ بـ `?`)، وتعبير يتم تقييمه وإرجاعه إذا كان الشرط خطأً (الجزء `else`، الذي يبدأ بـ `:`).

```haxe
trace(true ? "Haxe" : "Not Haxe"); // Haxe
trace(1 == 2 ? "Something is wrong" : "That's obvious"); // That's obvious
```
