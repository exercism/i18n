# الظهور

عند استخدام الأصناف لتنظيم الكود، يمكن أن يشجّع ظهور الخصائص والطرق والثوابت على تجريدات ومسؤوليات سليمة.
يُحدَّد ظهور الخصائص والطرق والثوابت من خلال استخدام الكلمات المفتاحية `public` أو `private` أو `protected` عند الإعلان عنها.
يشير الظهور دائمًا إلى الاستخدام الخارجي لخاصية الصنف أو طريقته أو ثابته.
أي أنه إذا أُعلنت خاصية كـ `public`، فإنها تكون قابلة للملاحظة والاستخدام من الاستدعاءات الخارجية.
الخصائص والطرق والثوابت الخاصة ليست قابلة للملاحظة أو الاستخدام من الاستدعاءات الخارجية.

```php
<?php

class SecretDocument
{
    private $encryption_key;

    public $title;

    public function __construct($encryption_key, $title)
    {
        $this->encryption_key = $encryption_key;
        $this->title = $title;
    }
}

$document = new SecretDocument('secret_password', 'Secret Plans');
$title = $document->title; // => succeeds
$key = $document->encryption_key; // => fails
```

الخصائص والطرق والثوابت المحمية لا يمكن ملاحظتها إلا من داخلها ومن أي أصناف ابنة (عبر الوراثة).

```php
<?php

class Shape
{
    protected $color = "blue";
}

class Square extends Shape
{
    public function getColor()
    {
        return $this->color;
    }
}

$square = new Square();
$color = $square->getColor(); // => succeeds
```
