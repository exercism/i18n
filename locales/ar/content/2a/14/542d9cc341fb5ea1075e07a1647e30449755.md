# مقدمة

الأعداد العشرية هي أعداد لها رقم واحد أو أكثر بعد الفاصلة العشرية. وهي تستخدم صيغة الفاصلة العائمة مزدوجة الدقة ذات 64 بت.

```elixir
float = 3.45
# => 3.45
```

## التعامل مع الأعداد

في وحدتَي [`Integer`][integer-functions] و[`Float`][float-functions] ستجد بعض الدوال المفيدة للتعامل مع هذين النوعين. وعوامل الحساب الأساسية معرّفة في وحدة [`Kernel`][kernel-arithmetic-operators].

## التحويل

يمكن خلط الأعداد الصحيحة والأعداد العشرية معًا في تعبير حسابي واحد. واستخدام عدد عشري في تعبير يضمن أن تكون النتيجة عددًا عشريًا أيضًا.

```elixir
2 * 3
# => 6

2 * 3.0
# => 6.0
```

لكن عند إجراء القسمة، ستكون النتيجة دائمًا عددًا عشريًا، حتى لو استُخدمت أعداد صحيحة فقط.

```elixir
6 / 2
# => 3.0
```

لتحويل عدد عشري إلى عدد صحيح، يمكنك التخلص من الجزء العشري باستخدام [`trunc/1`][trunc-1].
