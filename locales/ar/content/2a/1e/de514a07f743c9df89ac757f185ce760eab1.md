# نبذة

تحتاج الموارد التي تحتفظ بحالة نظام التشغيل (مقابض الملفات، والمقابس، والأقفال) إلى تنظيف *مضمون*، حتى عندما يفكّ استثناء المكدّس. وتوفّر وحدة [`destructors`][destructors] في Factor إطارًا صغيرًا لذلك، ومعظم الموارد المدمجة (`<file-reader>`، `<file-writer>`، والمقابس، …) تتصل به بالفعل.

## الصنف والدالة العامة

ينضم الصنف إلى الإطار بوراثة `disposable` وتنفيذ `dispose*`:

```factor
TUPLE: my-handle < disposable underlying ;

: <my-handle> ( underlying -- handle )
    my-handle new-disposable swap >>underlying ;

M: my-handle dispose* underlying>> dispose ;
```

تخصّص `new-disposable ( class -- obj )` الصف *وتسجّله* في نطاق المُدمِّر الحالي، بحيث لا يمكن لاستثناء يقع بين التخصيص ونقطة الأمان التالية أن يسرّب المورد. ويضمن الإطار أن `dispose*` تُنفَّذ **مرة واحدة على الأكثر** لكل كائن، ونداءات `dispose` المتكررة لا أثر لها.

## يستخدم المستدعون الخارجيون `dispose`

| الكلمة            | التأثير                                        |
|-------------------|-----------------------------------------------|
| `dispose`         | `( obj -- )`: يحرّر المورد، ومن الآمن استدعاؤه مرتين    |
| `with-disposal`   | `( disposable quot -- )`: يحصر موردًا واحدًا في نطاق |
| `with-destructors`| `( quot -- )`: يفتح نطاق سجلّ         |
| `&dispose`        | `( obj -- obj )`: يحرّر عند الخروج الطبيعي *أو* عند الفشل |
| `|dispose`        | `( obj -- obj )`: يحرّر فقط إذا فُكّ النطاق |

`with-disposal` هي صيغة المورد الواحد. ولأكثر من مورد واحد، افتح نطاق `with-destructors` وسجّل كل اقتناء بـ `&dispose` (فأنت تريد تحريره دائمًا) أو `|dispose` (التحرير عند الفشل فقط، إذ يبقيه مسار النجاح).

```factor
[
    "in.txt"  utf8 <file-reader> &dispose
    "out.txt" utf8 <file-writer> &dispose
    [ read1 ] [ write1 ] bi
] with-destructors
```

## الأولية المجرّدة هي `cleanup`

من أجل تركيب `try/finally` لمرة واحدة بدون سجلّ، تُعدّ [`cleanup`][cleanup] (من `continuations`) الكلمة الأدنى مستوى:

```
cleanup ( try cleanup-always cleanup-error -- )
```

`with-destructors` أقوى بشكل صارم (إذ يمكن للسجلّ أن ينمو أثناء التشغيل)، لكن `cleanup` هي الخيار الطبيعي عندما يكون اقتران الاقتناء والتحرير ثابتًا ومحليًا.
