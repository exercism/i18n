# التعليمات

أنت حارس منارة رأس كروزيه. من غرفة الفانوس تسجّل كل سفينة تمر بك، وتُعرَّف كل واحدة منها بإشارة نداء فريدة، كما تنسّق أيضًا عمليات ترحيل الإشارات مع بقية المنارات على امتداد الساحل.

## 1. دفتر سجل جديد

عرّف `empty-log` بحيث تُرجع مجموعة تجزئة فارغة وجديدة، جاهزة لجمع إشارات النداء.

```factor
empty-log .
! => HS{ }
```

## 2. تسجيل مشاهدة

عرّف `sight` بحيث تأخذ دفتر سجل وإشارة نداء، وتُسجّل المشاهدة في الموقع. لا تُرجع شيئًا.

```factor
empty-log dup "NS-1024" sight .
! => HS{ "NS-1024" }
```

## 3. هل رأينا هذا من قبل؟

عرّف `seen?` بحيث تأخذ دفتر السجل وإشارة النداء، وتُرجع `t` إذا كانت إشارة النداء مسجّلة و`f` خلاف ذلك.

```factor
HS{ "NS-1024" "WB-203" } "NS-1024" seen? .   ! => t
HS{ "NS-1024" "WB-203" } "X-99"    seen? .   ! => f
```

## 4. نسيان مشاهدة

عرّف `forget-sighting` بحيث تأخذ دفتر السجل وإشارة النداء وتحذف إشارة النداء من السجل في الموقع. لا تُرجع شيئًا. إذا لم تكن إشارة النداء موجودة، فلا تفعل شيئًا.

```factor
HS{ "NS-1024" "WB-203" } clone dup "WB-203" forget-sighting .
! => HS{ "NS-1024" }
```

## 5. كم عدد السفن المختلفة؟

عرّف `unique-count` لتُرجع عدد إشارات النداء المختلفة في السجل.

```factor
HS{ "NS-1024" "WB-203" "AC-77" } unique-count .   ! => 3
empty-log unique-count .                          ! => 0
```

## 6. المنارات التي يمكن الوصول إليها

تحتفظ خفر السواحل بجدول `relay-map`: جدول تجزئة بمفاتيح هي أسماء المنارات، وقيمة كل مفتاح مصفوفة بالمنارات التي يمكن للمنارة المقابلة أن ترحّل إليها مباشرة.

عرّف `reachable` بحيث تأخذ منارة `start` وجدول `relay-map`، وتُرجع مجموعة تجزئة بكل منارة يمكن الوصول إليها من `start` (بما فيها `start` نفسها) عبر ترحيلات متكررة.

```factor
H{
    { "Crozier"  { "Beacon"  "Hadley"  } }
    { "Beacon"   { "Crozier" "Spiral"  } }
    { "Hadley"   { "Crozier"           } }
    { "Spiral"   { "Beacon"  "Outpost" } }
    { "Outpost"  { "Spiral"            } }
    { "Far-Isle" { "Lonely"            } }
    { "Lonely"   { "Far-Isle"          } }
}
"Crozier" swap reachable .
! => HS{ "Crozier" "Beacon" "Hadley" "Spiral" "Outpost" }
```

يشكّل زوج `Far-Isle`/`Lonely` مكوّنًا متصلًا قائمًا بذاته، لذا لا يظهر أيٌّ منهما في النتيجة.
