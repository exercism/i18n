# مقدمة

## الدوال السهمية

إلى جانب تعريفات الدوال وتعبيرات الدوال، تمتلك JavaScript أيضًا صياغة أخرى موجزة جدًا لتعريف الدالة.
وتُسمّى هذه الدوال _الدوال السهمية_.

إليك مقارنة بين تعريف الدالة والدالة السهمية.

```javascript
function addUpTwoNumbers(num1, num2) {
  return num1 + num2;
}
// function keyword removed and => added
const addUpTwoNumbers = (num1, num2) => {
  return num1 + num2;
};
```

إذا كان جسم الدالة يحتوي على عبارة `return` فقط، كما في المثال أعلاه، فيمكن حذف الأقواس المعقوفة `{}` والكلمة المفتاحية `return`.
وإذا كان هناك معامل واحد فقط، فيمكن حذف الأقواس الهلالية `()` أيضًا.

<!-- prettier-ignore-start -->
```javascript
const addUpTwoNumbers = (num1, num2) => num1 + num2;
const square = num => num * num;
```
<!-- prettier-ignore-end -->

غالبًا ما تُستخدم الدوال السهمية لتعريف دوال استدعاء راجع قصيرة مباشرة داخل استدعاء الدالة.

<!-- prettier-ignore-start -->
```javascript
applyToSquare(number => number * number);
```
<!-- prettier-ignore-end -->

## تحليل المصفوفات

تمتلك [المصفوفات][arrays-concept] طرقًا مدمجة لتحليل محتوى المصفوفة.
تأخذ معظم هذه الطرق دالة تُرجع صحيحًا أو خطأ كوسيط.
وتُسمّى هذه الدالة [`predicate`][predicate_in_programming].

الغرض من هذه الطرق المدمجة هو استخدامها _بدلًا من حلقة `for`_ أو الطريقة المدمجة `forEach`:

مثال على التحليل باستخدام حلقة `for`:

```javascript
const numbers = [1, 'two', 3, 'four'];
for (var i = 0; i < numbers.length; i++) {
  if (numbers[i] === 'two') {
    return i;
  }
}
// => 1
```

مثال على التحليل باستخدام طريقة مدمجة:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.indexOf('two');
// => 1
```

فيما يلي بعض الطرق المدمجة المفيدة الأخرى المتاحة لتحليل مصفوفة.
راجع [MDN][mdn-array-methods] للحصول على قائمة كاملة بطرق المصفوفات.

### `includes`

تحدد طريقة `includes(value)` ما إذا كانت المصفوفة تتضمن قيمة معيّنة.
وتُرجع `true` عندما تكون القيمة متضمّنة، و`false` خلاف ذلك.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.includes(1);
// => true
numbers.includes('one');
// => false
```

### `every`

تأخذ طريقة `every(predicate)` دالة تكون _دالة شرطية_.
وهي تختبر ما إذا كانت كل العناصر في المصفوفة تُرجع `true` عند تمريرها إلى الدالة الشرطية.
بعبارة أخرى: تتحقق الطريقة من أن كل عناصرها تجتاز الاختبار المُمرَّر إلى استدعاء الدالة.
وتُرجع `true` عندما تجتاز كل العناصر اختبار الدالة الشرطية، و`false` خلاف ذلك.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.every((num) => num % 2 !== 0);
// => true
```

### `some`

طريقة `some(predicate)` هي نفسها طريقة `every`، لكنها تُرجع `true` إذا اجتاز عنصر واحد على الأقل في المصفوفة اختبار _الدالة الشرطية_.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.some((num) => num % 2 !== 0);
// => true
```

### `find`

تُرجع طريقة `find(predicate)` قيمة أول عنصر في المصفوفة يجتاز اختبار `predicate`.
فحيث تُرجع `some()` قيمة `true` عند الاجتياز، تُرجع `find()` القيمة الفعلية في المصفوفة.
وتُرجع الطريقة `undefined` عندما لا يجتاز أي من عناصر المصفوفة اختبار _الدالة الشرطية_.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.find((num) => num < 5);
// => 1
```

### `findIndex`

طريقة `findIndex(predicate)` هي نفسها طريقة `find()`، لكنها تُرجع الفهرس (الأول) للعنصر الذي يجتاز اختبار _الدالة الشرطية_ بدلًا من `value`.
وتُرجع الطريقة `-1` عندما لا يجتاز أي من عناصر المصفوفة اختبار _الدالة الشرطية_.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.findIndex((num) => num > 7);
// => 4
numbers.findIndex((num) => num > 9);
// => -1
```
