# الاختبارات

ثبّت التبعيات.

```sh
dart pub get
```

شغّل الاختبارات.

```sh
dart test
```

للحصول على مخرجات أكثر تفصيلًا لكل اختبار، استخدم مُبلِّغ الاختبارات الموسَّع.

```sh
dart test -r expanded
```

معظم التمارين تحتوي على عدة اختبارات، وجميعها متجاهَلة افتراضيًا باستثناء الأول.
للعمل على الاختبارات واحدًا تلو الآخر، غيّر `skip: true` إلى `skip: false` في كل اختبار أثناء تقدّمك.

بدلًا من ذلك، شغّل جميع الاختبارات دفعة واحدة دون تعديل الملف.

```sh
dart test --run-skipped
```

يشغّل مُشغِّل الاختبارات على الإنترنت جميع الاختبارات عند الإرسال، بما فيها المتجاهَلة.
