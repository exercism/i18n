# الأساسيات

لمزيد من المعلومات التفصيلية حول هذه المواضيع، زُر [صفحة المفهوم][exercism-concept].

## الصيغة العامة

يحدد وسم فتح PHP `<?php` بداية كود PHP.
يجب أن تنتهي كل عبارة بفاصلة منقوطة `;` لفصل التعليمات.

```php
<?php

$message = "Success!"; // Statement correctly ends with `;`
$message = "I fail." // PHP Parse error: syntax error, [...]
```

لتسهيل القراءة، لا تتضمن جميع أمثلة الكود وسم فتح PHP `<?php`.

## التعليقات

تبدأ التعليقات أحادية السطر بـ `//`.

```php
// Single line comment
```

## القيم والمتغيرات

باستخدام عامل الإسناد `=`، يمكن إسناد قيمة إلى متغير.
يجب أن تبدأ أسماء المتغيرات بعلامة الدولار `$` وأن تتبع [اصطلاحات التسمية][exercism-concept-naming-conventions].

```php
$count = 1; // Assign value of 1

// Strings can be created by enclosing the characters
// within single `'` quotes or double `"` quotes.
$message = "Success!";
```

## الدوال والطرق

يمكن تمرير القيم والمتغيرات إلى الدوال.
تصبح وسائط الدالة متغيرات جديدة لتحمل القيم الممررة.
يمكن للدوال إرجاع أي قيمة باستخدام الكلمة المفتاحية `return`.

```php
function window_height($height)
{
    return $height + 10;
}

window_height(100);
// => 110
```

تُسمى الدوال الموجودة داخل الأصناف ونسخها طرقًا.
لاستدعاء طريقة، يُسبق الاسم بالنسخة و`->`.
تستطيع الطرق الوصول إلى المتغير الخاص `$this`، الذي يشير إلى النسخة الحالية.

```php
<?php

class Calculator {
    public function sub($x, $y)
    {
        return $this->add($x, -$y); // Calls the method add() of the current instance
    }

    public function add($x, $y)
    {
        return $x + $y;
    }
}

$calculator = new Calculator(); // Creates a new instance of Calculator class
$calculator->sub(3, 1); // Calls the method sub() of the instance stored in $calculator
// => 2
```
