# التعليمات

في هذا التمرين، ستساعد حبيبَي المدرسة الثانوية على إعلان حبهما على وسائل التواصل الاجتماعي من خلال إنشاء مربع ASCII يحمل الأحرف الأولى لأسمائهما:

```
❤-------------------❤
|  J. K.  +  M. B.  |
❤-------------------❤
```

## 1. احصل على الحرف الأول من الاسم

نفّذ الدالة `HighSchoolSweetheart.first_letter/1`. يجب أن تأخذ اسمًا وتُرجع الحرف الأول منه، وأن تزيل أي مسافات بيضاء غير ضرورية من الاسم.

```elixir
HighSchoolSweetheart.first_letter("Jane")
# => "J"
```

## 2. نسّق الحرف الأول على هيئة اختصار

نفّذ الدالة `HighSchoolSweetheart.initial/1`. يجب أن تأخذ اسمًا وتُرجع حرفه الأول بحرف كبير متبوعًا بنقطة. احرص على إعادة استخدام الدالة `HighSchoolSweetheart.first_letter/1` التي عرّفتها في الخطوة السابقة.

```elixir
HighSchoolSweetheart.initial("Robert")
# => "R."
```

## 3. قسّم الاسم الكامل إلى الاسم الأول واسم العائلة

نفّذ الدالة `HighSchoolSweetheart.initials/1`. يجب أن تأخذ اسمًا كاملًا يتكوّن من اسم أول واسم أخير يفصل بينهما فراغ، وتُرجع الأحرف الأولى. احرص على إعادة استخدام الدالة `HighSchoolSweetheart.initial/1` التي عرّفتها في الخطوة السابقة.

```elixir
HighSchoolSweetheart.initials("Lance Green")
# => "L. G."
```

## 4. ضع الأحرف الأولى داخل مربع ASCII

نفّذ الدالة `HighSchoolSweetheart.pair/2`. يجب أن تأخذ اسمين كاملين وتُرجع الأحرف الأولى داخل مربع ASCII. لا حاجة لأن ترسم المربع بنفسك، بل استفد من المربع المضمّن في تعليق الكود. احرص على إعادة استخدام الدالة `HighSchoolSweetheart.initials/1` التي عرّفتها في الخطوة السابقة.

```elixir
HighSchoolSweetheart.pair("Blake Miller", "Riley Lewis")
# => """
# ❤-------------------❤
# |  B. M.  +  R. L.  |
# ❤-------------------❤
# """
```
