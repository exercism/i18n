# مقدمة

كون المصفوفة _مجموعة_ يعني أنه بالإضافة إلى الوصول إلى القيم عبر فهرسها، يمكنك المرور على _كل_ قيمها باستخدام حلقة `foreach`:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```
