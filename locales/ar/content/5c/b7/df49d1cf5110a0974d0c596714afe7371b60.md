# مقدمة

## العودية

**الدوال العودية** هي دوال تستدعي نفسها.

تحتاج _الدالة العودية_ إلى _حالة أساسية_ واحدة على الأقل وإلى _حالة عودية_ واحدة على الأقل.

تُرجع **الحالة الأساسية** قيمة دون استدعاء الدالة مرة أخرى.
أما **الحالة العودية** فتستدعي الدالة مرة أخرى مع تعديل المدخل بحيث يطابق الحالة الأساسية في مرحلة ما.

إليك مثالًا يعدّ عناصر مصفوفة.

```jq
def count:
  if length == 0 then
    0                       # base case
  else
    1 + (.[1:] | count)     # recursive case
  end;

([] | count),           # => 0
([11, 22, 33] | count)  # => 3
```

يمكن أن تحتوي _الدالة العودية_ على عدة _حالات أساسية_ و/أو عدة _حالات عودية_.
على سبيل المثال، [متتالية فيبوناتشي][wiki-fibonacci] متتالية عودية لها _حالتان أساسيتان_.

```jq
def fibonacci:
  if . == 0 then
    0
  elif . == 1 then
    1
  else
    (. - 1 | fibonacci) + (. - 2 | fibonacci)
  end;

10 | fibonacci          # => 55
```

وعدّ عدد مرات ظهور قيمة معطاة `x` في مصفوفة له _حالتان عوديتان_.

```jq
def count_occurrences(x):
  if length == 0 then
    0
  elif first == x then
    1 + (.[1:] | count_occurrences(x))
  else
    (.[1:] | count_occurrences(x))
  end;

[11, 22, 33, 22, 44] | count_occurrences(22)    # => 2
```

عمليًا، غالبًا ما يتم التكرار على المصفوفات وغيرها من بُنى البيانات القابلة للتعداد باستخدام دوال مدمجة،
مثل `map` و`reduce`، أو باستخدام [التدفقات][map-implementation] مثل `[.[] | select(...)]`.
وفي الخلفية، تُنفَّذ بعض الدوال المدمجة [باستخدام العودية][walk-implementation].
