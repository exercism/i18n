# التعليمات

في هذا التمرين ستلهو بسيارة تحكم عن بُعد، وقد ادّخرت أخيرًا ما يكفي من المال لشرائها.

تبدأ السيارات ببطارية ممتلئة (100%).
في كل مرة تقود فيها السيارة باستخدام وحدة التحكم، تقطع 20 مترًا وتستهلك واحدًا بالمئة من البطارية.
ولا يُعرف لقب السيارة إلا عند إنشائها.

تحتوي سيارة التحكم عن بُعد على شاشة LED أنيقة تعرض معلومتين:

- المسافة الإجمالية التي قطعتها، وتُعرض على الشكل التالي: `"<METERS> meters"`.
- شحن البطارية المتبقي، ويُعرض على الشكل التالي: `"Battery at <PERCENTAGE>%"`.

إذا وصلت البطارية إلى 0%، فلن تعود قادرًا على قيادة السيارة، وستعرض شاشة البطارية `"Battery empty"`.

## 1. أنشئ سيارة تحكم عن بُعد جديدة تمامًا

نفّذ الدالة `new_remote_control_car/0` لتُرجع كائن سيارة تحكم عن بُعد جديدة تمامًا:

```jq
new_remote_control_car
# => {
#      "battery_percentage": 100,
#      "distance_driven_in_meters": 0,
#      "nickname": null
#    }
```

## 2. أنشئ سيارة تحكم عن بُعد جديدة تمامًا مع لقب

نفّذ الدالة `new_remote_control_car/1` لتُرجع كائن سيارة تحكم عن بُعد جديدة تمامًا مع لقب مُعطى:

```jq
new_remote_control_car("Blue")
# => {
#      "battery_percentage": 100,
#      "distance_driven_in_meters": 0,
#      "nickname": "Blue"
#    }
```

## 3. اعرض المسافة

نفّذ الدالة `display_distance/0` التي تأخذ كائن سيارة كمدخل وتُخرج سلسلة نصية للمسافة كما تظهر على شاشة LED:

```jq
new_remote_control_car | display_distance
# => "0 meters"
```

## 4. اعرض نسبة شحن البطارية

نفّذ الدالة `display_battery/0` التي تأخذ كائن سيارة كمدخل وتُخرج سلسلة نصية لنسبة شحن البطارية كما تظهر على شاشة LED:

```jq
new_remote_control_car | display_battery
# => "Battery at 100%"
```

إذا وصلت البطارية إلى 0%، فستعرض شاشة البطارية "Battery empty".

## 5. القيادة تغيّر البطارية والمسافة المقطوعة

نفّذ الدالة `drive/0` التي:

- تأخذ كائن سيارة كمدخل
- تزيد عدد الأمتار المقطوعة بمقدار 20
- تستهلك 1% من البطارية
- تُخرج كائن السيارة بعد التعديل

```jq
new_remote_control_car("Red") | drive
# => {
#      "battery_percentage": 99,
#      "distance_driven_in_meters": 20,
#      "nickname": "Red"
#    }
```

## 6. تعامل مع القيادة ببطارية فارغة

حدّث الدالة `drive/0` بحيث لا تزيد المسافة المقطوعة ولا تنقص نسبة شحن البطارية عندما تكون البطارية فارغة (عند 0%):

```jq
{
  battery_percentage: 0,
  distance_driven_in_meters: 2000,
  nickname: "Red"
} | drive
# => {
#      "battery_percentage": 0,
#      "distance_driven_in_meters": 2000,
#      "nickname": "Red"
#    }
```
