# نبذة

الدوال **المعرّفة من المستخدم** تُنشأ باستخدام الكلمة المفتاحية `function`. ثم يجب أن يتبعها اسم الدالة وقائمة من الوسائط.

```php
function alarm($hour, $minute, $second)
{
    return 'Alarm!';
}
```

يمكن استدعاء الدوال في ملف قبل تعريفها، لأنها تُرفع إلى أعلى نطاقها.

## التسمية

تتبع أسماء الدوال في PHP قواعد بقية المعرّفات: يجب أن تبدأ بشرطة سفلية أو حرف، ثم قد يتبعها أي عدد من الحروف أو الأرقام أو الشروع السفلية.
