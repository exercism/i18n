# نبذة

Swift لغة برمجة مُصرَّفة ومتعددة الأنماط، صُمِّمت بثلاثة أهداف رئيسية:

- **الأمان**: تساعد ميزات مدمجة في اللغة على اكتشاف أخطاء bug ومنعها قبل تشغيل كودك في بيئة الإنتاج.
- **السرعة**: أداء مُحسَّن يضاهي أداء اللغات المبنية على C.
- **التعبيرية**: صياغة نظيفة وعصرية، ممتعة وسهلة في القراءة والكتابة.

أطلقت Apple لغة Swift في عام 2014 كبديل عصري للغة Objective-C، اللغة التي كانت تُستخدم سابقًا في تطوير iOS وmacOS.
واليوم أصبحت Swift مفتوحة المصدر، وتعمل على منصات Apple وLinux وWindows.

## البدء

### المتغيرات

يمكنك تخزين القيم وتسميتها بتعريف [متغير][constants-variables].
بعد تعريف المتغير، يمكنك استخدام اسمه للإشارة إلى تلك القيمة في كل أنحاء الكود.
المتغيرات _قابلة للتغيير_، أي أن قيمها يمكن أن تتغير بعد تعريفها.

عرّف متغيرًا بالكلمة المفتاحية `var`:

```swift
var variableName = 10
```

Swift لغة ذات أنواع ساكنة، أي أن نوع كل قيمة معروف في وقت التصريف.
يمكنك تحديد النوع صراحةً عبر [توصيف النوع][type annotations]، أو ترك مُصرِّف Swift [يستنتج النوع][type-inferring] من القيمة المُسنَدة:

```swift
var explicitVar: Int = 10 // Explicitly typed
var implicitVar = 10      // Implicitly typed (inferred as Int)
```

يمكنك تحديث قيمة متغير باستخدام عامل الإسناد (`=`):

~~~~exercism/note
لا يمكن أن يتغير نوع المتغير بعد التصريح عنه.

```swift
variableName = 13 // Allowed: same type (Int)

// Compiler error: cannot assign a different type
variableName = "Hello, world!" // Cannot assign value of type 'String' to type 'Int'
```
~~~~

يمكنك تعريف متغير دون قيمة ابتدائية بتحديد نوعه، لكن يجب أن تُسند إليه قيمة قبل استخدامه:

```swift
var someInt: Int

// This triggers a compiler error:
// print(someInt) // Variable 'someInt' used before being initialized

// Assign a value first
someInt = 169
print(someInt) // Prints 169
```

### الثوابت

تربط [الثوابت][constants-variables] أيضًا اسمًا بقيمة، لكن قيمها لا يمكن تغييرها بعد الإسناد.
فهي _غير قابلة للتغيير_.
عرّف ثابتًا بالكلمة المفتاحية `let`:

```swift
let constantName = 10          // Inferred constant
let explicitConstant: Int = 10 // Explicitly typed constant
```

### العوامل الحسابية

توفّر Swift [عوامل حسابية][arithmetical-operators] قياسية للعمليات الرياضية الأساسية:

- الجمع: `+`
- الطرح: `-`
- الضرب: `*`

```swift
print(1 + 1) // Prints 2
print(2 - 1) // Prints 1
print(2 * 2) // Prints 4
```

### الدوال

في Swift، [الدوال][functions] كتل مكتفية بذاتها من الكود تؤدي مهمة محددة.
يمكن للدوال أن تستقبل مدخلات، وأن تُرجع قيمة، وأن تُمرَّر كقيم إلى دوال أخرى.
عرّف دالة بالكلمة المفتاحية `func`، متبوعة باسم الدالة، وقائمة معاملات بين الأقواس الهلالية، ونوع إرجاع اختياري:

```swift
func functionName(argumentLabel parameterName: ParameterType) -> ReturnType {
    // Function body
}
```

تستخدم دوال Swift [تسميات الوسائط][argument-labels]، وهي تجعل الكود يُقرأ كجمل طبيعية:

- تُستخدم **تسمية الوسيط** عند استدعاء الدالة.
- يُستخدم **اسم المعامل** داخل جسم الدالة للوصول إلى القيمة.

إذا حدّدت اسمًا واحدًا فقط، تستخدمه Swift كتسمية للوسيط واسم للمعامل في آنٍ واحد:

```swift
func greet(name: String) {
    print("Hello, \(name)!")
}

greet(name: "Alice")
```

إذا كنت لا تريد تسمية للوسيط عند استدعاء الدالة، فاكتب شرطة سفلية (`_`) قبل اسم المعامل:

```swift
func square(_ number: Int) -> Int {
    return number * number
}

square(5) // Called without an argument label
```

جميع معاملات الدالة ثوابت (`let`) افتراضيًا، أي أنه لا يمكن تعديل قيمها داخل جسم الدالة.

لإرجاع قيمة من دالة، حدّد نوع الإرجاع بعد `->` واستخدم الكلمة المفتاحية `return`:

```swift
func addTen(to value: Int) -> Int {
    return value + 10
}

addTen(to: 10) // Returns 20
```

عندما لا تُرجع الدالة قيمة، يكون نوع إرجاعها `Void` (مكافئ لصف فارغ، `()`).
ويمكنك في مثل هذه الدوال حذف كلٍّ من نوع الإرجاع `-> Void` وعبارة `return`.

### التعليقات

تدعم Swift شكلين من [التعليقات][comments]:

- **التعليقات أحادية السطر** تبدأ بـ `//` وتستمر حتى نهاية السطر.
- **التعليقات متعددة الأسطر** تُحصر بين `/*` و`*/`.

```swift
// This is a single-line comment

/* This is a comment
   that spans multiple lines */
```
