# التعليمات

أنت مسؤول عن جدول رحلات عبارة صغيرة تخدم جزيرة. تُسجَّل أوقات المغادرة كتواريخ، وتحتاج إلى بعض الدوال المساعدة للتعامل معها.

## 1. تسجيل تاريخ رحلة

عرّف `make-date` لتأخذ سنة وشهرًا ويومًا وتُرجع الطابع الزمني المقابل.

```factor
2024 7 14 make-date .
! => T{ timestamp { year 2024 } { month 7 } { day 14 } ... }
```

## 2. تسمية يوم الأسبوع

عرّف `weekday-name` لتأخذ الطابع الزمني لرحلة وتُرجع اسم يوم الأسبوع الذي تقع فيه.

```factor
2024 1 8 make-date weekday-name .
! => "Monday"
```

## 3. السنوات الكبيسة

عرّف `leap?` لتأخذ سنة وتُرجع ما إذا كانت سنة كبيسة.

```factor
2024 leap? .   ! => t
2023 leap? .   ! => f
```

## 4. عدد الأيام في الشهر

عرّف `month-length` لتأخذ سنة وشهرًا وتُرجع عدد الأيام في ذلك الشهر (تذكّر فبراير).

```factor
2024 2 month-length .   ! => 29
2023 2 month-length .   ! => 28
```

## 5. الأيام اللاحقة

عرّف `add-days` لتأخذ طابعًا زمنيًا وعددًا من الأيام، وتُرجع الطابع الزمني بعد ذلك العدد من الأيام.

```factor
2024 2 28 make-date 1 add-days >date< .
! => 29   (2024-02-29)
```
