# ملحق التعليمات

## ملاحظات إضافية حول التنفيذ بلغة C++

توجد عدة أساليب لتحقيق التوازي في C++. يدعم مشغّل Exercism عبر الإنترنت الإصدار C++17، لذا يمكنك استخدام سياسات التنفيذ من [مكتبة الخوارزميات][algorithm].
وثمة خيار آخر هو إدارة [الخيوط][thread] يدويًا.
لكن انتبه إلى أن إنشاء خيط جديد مكلف إلى حد كبير (استخدام [مجمّع الخيوط][pool] سيساعد في ذلك).

عند العمل محليًا، يمكنك بالطبع استخدام ما تريد.
لكن الحل الذي يعتمد على مكتبات غير قياسية لن يعمل على الأرجح مع مشغّل Exercism عبر الإنترنت.

### قياس الأداء

عند العمل محليًا، يمكنك اختياريًا تشغيل قياس للأداء لتكوين فكرة عن مقدار التسريع الذي تحققه عمليات تنفيذ مختلفة.
تفعيل علامة CMake ‏`EXERCISM_INCLUDE_BENCHMARK` يفعّل قياس الأداء:
```
cmake -DEXERCISM_RUN_ALL_TESTS=1 -DEXERCISM_INCLUDE_BENCHMARK=1 .
```

### دعم المترجم للخوارزميات المتوازية

يعتمد تنفيذ GCC لمكتبة C++ القياسية (`libstdc++`) على [TBB][tbb].
إذا لم تكن TBB متاحة، فسيُستخدم إصدار تسلسلي بديل، حتى عند طلب التنفيذ المتوازي.

على Ubuntu، تحتاج إلى تثبيت حزمة `libtbb-dev`:
```
apt-get install libtbb-dev
```

على macOS، يمكنك استخدام [Homebrew][homebrew] لتثبيت TBB:
```
brew install tbb
```

يقدّم Clang `libc++` بدءًا من الإصدار 17 دعمًا تجريبيًا جزئيًا للخوارزميات المتوازية.
لتفعيله، يجب تمرير علامة المترجم `-fexperimental-library`.

_لا تدعم_ إصدارات Apple Clang حتى الإصدار 15 الخوارزميات المتوازية.

على Linux وmacOS ننصح باستخدام GCC (إلى جانب `libstdc++` الافتراضية) في هذا التمرين.

يدعم MSVC من Microsoft الخوارزميات المتوازية منذ VS 2017 15.7 على الأقل، دون الحاجة إلى تثبيت أي مكتبة إضافية.
