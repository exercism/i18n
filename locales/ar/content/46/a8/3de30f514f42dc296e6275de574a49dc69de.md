# الوحدات والمسارات في Cairo

يستخدم Cairo **الوحدات** لتنظيم الكود.

تساعد الوحدات في هيكلة المشاريع والتحكم في إمكانية الوصول إلى عناصر مثل الدوال والبنى والسمات.

## تعريف الوحدات

الوحدات تُعرَّف بالكلمة المفتاحية `mod` ويمكن أن تكون متداخلة:

```rust
mod front_of_house {
    pub mod hosting {
        pub fn add_to_waitlist() {}
    }
}
```

الدوال والبنى والسمات **خاصة افتراضيًا**.

استخدم `pub` لجعلها متاحة خارج وحدتها.

## المسارات: المطلقة مقابل النسبية

للإشارة إلى عنصر في وحدة أخرى، يمكنك استخدام:

- **المسارات المطلقة** (تبدأ من `crate::`):

  ```rust
  crate::front_of_house::hosting::add_to_waitlist();
  ```

- **المسارات النسبية** (تبدأ من الوحدة الحالية):

  ```rust
  front_of_house::hosting::add_to_waitlist();
  ```

  وهذا يعمل إذا كانت `front_of_house` في الوحدة نفسها.

## إدخال الوحدات إلى النطاق باستخدام `use`

كتابة المسارات الكاملة مرارًا وتكرارًا أمر غير مريح.

تتيح لك الكلمة المفتاحية `use` استخدام إشارات أقصر:

```rust
use crate::front_of_house::hosting;

pub fn eat_at_restaurant() {
    hosting::add_to_waitlist(); // Shorter path
}
```

ينطبق `use` **فقط في النطاق الذي يظهر فيه**؛ وإذا احتجته في مكان آخر، فعليك تكراره.

### الاستخدام المتعارف عليه لـ `use`

- أدخل **الوحدات** إلى النطاق، لا الدوال:

  ```rust
  use crate::front_of_house::hosting; // ✅
  hosting::add_to_waitlist();
  ```

  بدلًا من:

  ```rust
  use crate::front_of_house::hosting::add_to_waitlist; // ❌
  add_to_waitlist();
  ```

- أما **السمات والبنى والتعدادات**، فاستخدم المسار الكامل:

  ```rust
  use core::num::traits::BitSize;
  ```

### الأسماء البديلة مع `as`

أعِد تسمية الاستيرادات عند الحاجة:

```rust
use core::array::ArrayTrait as Arr;

fn main() {
    let mut arr = Arr::new();
    arr.append(1);
}
```

### استيراد عدة عناصر

بدلًا من عدة عبارات `use`، اجمع الاستيرادات:

```rust
use shapes::{Square, Circle, Triangle};
```

## إعادة التصدير باستخدام `pub use`

لإظهار وحدة ضمن بنية مختلفة، استخدم `pub use`:

```rust
pub use crate::front_of_house::hosting;
```

الآن يمكن للكود الخارجي استخدام `restaurant::hosting::add_to_waitlist()` بدلًا من `restaurant::front_of_house::hosting::add_to_waitlist()`.

## استخدام الحزم الخارجية مع Scarb

لإضافة اعتمادية، حدّث `Scarb.toml`:

```toml
[dependencies]
alexandria_math = { git = "https://github.com/keep-starknet-strange/alexandria.git" }
```

استخدم `scarb add <package>` لإضافة الاعتماديات و`scarb rm <package>` لإزالتها.

## عامل التعميم (`*`)

لاستيراد كل شيء من وحدة:

```rust
use core::num::traits::*;
```

ينبغي استخدامه بحذر، لأنه قد يجعل الكود أصعب في القراءة.
