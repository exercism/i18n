# العامل الثلاثي

يمكن النظر إلى _العوامل الثلاثية_ على أنها نسخة مختصرة من _if-else_. تُستخدم عادةً في عبارات الإرجاع (وليس فيها فقط)، وتحتاج إلى سطر واحد فقط لاتخاذ القرار، فتُرجع القيمة اليسرى إذا كان التعبير `true` والقيمة اليمنى إذا كان `false`.

يمكن تبسيط الكثير من تعبيرات _if/else_ البسيطة باستخدام _العوامل الثلاثية_.

```java
// this ternary statement
return 5 > 4 ? true : false;

// is equivalent to this if/else
if ( 5 > 4 ) {
    return true;
} else {
    return false;
}
```

إذن، كيف تختار بين _if-else_ و_العوامل الثلاثية_؟
حسنًا، تُستخدم _العوامل الثلاثية_ في الحالات البسيطة، حيث تحتاج فقط إلى إرجاع قيمة بناءً على شرط دون أي حسابات إضافية.
استخدم _if-else_ في كل ما عدا ذلك، مثل الشروط المتداخلة والتعبيرات الكبيرة، وعندما تحتاج إلى أكثر من سطر لتحديد القيمة المُرجعة.

يمكنك تداخل _العوامل الثلاثية_، لكن الكود غالبًا ما يصبح صعب القراءة.
في هذه الحالات، يُفضَّل استخدام جمل `if` المتداخلة.

```java
// hard to read
int value = expr1 ? expr2 && expr3 ? val1 : (val2 + val3) : expr4;

// easier to read
if (expr1){

    if (expr2 && expr3){

        return val1;
    }

    return val2 + val3;
}
return val4;


```

تُعد _العوامل الثلاثية_ وعبارات _if/else_ مثالًا جيدًا على أن لديك طرقًا مختلفة لتحقيق النتيجة نفسها عند البرمجة.
