# مقدمة

تُعدّ [`string`][ref-string] في Kotlin متتالية غير قابلة للتغيير من محارف Unicode.

تعني كلمة [`Immutable`][wiki-immutable] أن أي عملية تُجرى على سلسلة نصية يجب أن تُرجع سلسلة نصية جديدة: فلا يمكن أبدًا تغيير السلسلة النصية الأصلية.

تعني [`Unicode`][wiki-unicode] أنه يمكن تمثيل معظم أنظمة الكتابة في العالم، ولكن (على خلاف اللغات الأقدم مثل C) لا توجد مقابلة 1:1 بين المحارف والبایتات.

تُحاط السلسلة النصية بعلامتَي اقتباس مزدوجتين `" "`.

تحتاج بعض المحارف إلى الهروب: `\\`، إلى جانب المحارف غير المطبوعة المعتادة مثل `\t` (جدولة) و`\n` (سطر جديد).

```kotlin
val s = "Escape backslash \\."
// Escape backslash \.
```

تُحاط السلاسل النصية متعددة الأسطر بثلاث علامات اقتباس مزدوجة، ويمكنها أن تحتوي على أي نص (دون حاجة إلى الهروب).

```kotlin
val multi = """I'm a
    multi-line
    string with special characters \ \t """
//I'm a
//    multi-line
//    string with special characters  \ \t 
```

استخدم [trimIndent][trimIndent-doc] لإزالة المسافة البادئة المشتركة من الأسطر.
وهذا مفيد لتنسيق السلسلة النصية:

```kotlin
val multi = """
    I'm a
      multi-line
    string""".trimIndent()

//I'm a
//  multi-line
//string
```

بدلًا من ذلك، يتيح لك [trimMargin][trimMargin-doc] تحديد فاصل.
عندئذٍ يبدأ كل سطر في `String` بعد الفاصل.
الفاصل الافتراضي هو `|`، لكن يمكنك تحديد فاصل مختلف كمعامل.
على سبيل المثال:

```kotlin
val multi = """
    |I'm a
    |  multi-line
    |string""".trimMargin()

//I'm a
//  multi-line
//string

val multi2 = """
    start>I'm a
    start>  multi-line
    start>string""".trimMargin("start>")

//I'm a
//  multi-line
//string
```

يمكن ضمّ السلاسل النصية باستخدام `+`، لكن من الأفضل قصر ذلك على الحالات القصيرة والبسيطة.
فثمة خيارات أخرى وغالبًا ما تكون أفضل.

## قوالب السلاسل النصية

يشير هذا إلى ما تسميه بعض اللغات الأخرى «الإقحام».

إذا احتوت سلسلة نصية على علامة الدولار `$` يتبعها معرّف، أو احتوت على أقواس معقوفة (`{expression}`) تحيط بتعبير، فإنها تُستبدَل على الترتيب بالقيمة أو بنتيجة التعبير.

```kotlin
val x = 42
val st = "x is $x, x squared is {x * x}"
// x is 42, x squared is 1764
```

تلزم الأقواس المعقوفة `{ }` حول التعبيرات حين يكون التحليل غامضًا من دونها.

بوجه عام، يُعدّ استخدام قوالب السلاسل النصية طريقة أكثر كفاءة وأقرب إلى أسلوب اللغة في دمج السلاسل النصية من استخدام `+`.

## دوال السلاسل النصية

توفّر Kotlin _العديد_ من [`functions`][ref-string-functions] للتعامل مع السلاسل النصية.

في الغالب، هذه [`extensions functions`][ref-extensions] وليست أعضاء في صنف `String`، وإن كان لذلك أثر ضئيل على طريقة استخدامنا لها.

~~~~exercism/note
تُخفي صفحات [التوثيق][ref-string-functions] المعقّدة إلى حد كبير في Kotlin دوال الامتداد في العرض الافتراضي.
تأكد من النقر على `Members & Extensions` لتوسيع هذا القسم.

[ref-string-functions]: https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/
~~~~

تُظهر الأمثلة التالية مجموعة صغيرة فقط مما هو متاح:

```kotlin
val str = "Hello World!"

str.length              // => 12 (a property, not a function)
str.elementAt(6)        // => W
str.elementAtOrNull(20) // => null (index out of range)
str.substring(6, 11)    // => "World"
str.substringAfter(" ") // => "World!"

str.lowercase()         // => "hello world!"
str.uppercase()         // => "HELLO WORLD!"

str.startsWith("Hel")   // => true
str.endsWith("xyz")     // => false
str.indexOf("0")        // => 4

str.toCharArray()       // => [H, e, l, l, o,  , W, o, r, l, d, !]
"42".toInt() + 1        // => 43  (parsing; see also toFloat)

"Howdy!  ".trim()       // => "Howdy"
```
