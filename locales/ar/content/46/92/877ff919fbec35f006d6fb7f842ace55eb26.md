# التعليمات

انتهى تركيب فسيفساء مركز الفنون المجتمعي الشهر الماضي، والآن اكتشفتها مارج العقعق. في معظم الأيام تستبدل بلاطة أو اثنتين ببلاطات أكثر لمعانًا من **كنزها** القريب، أو تقتلع بلاطة وتغيب ساعة كاملة.

أنت المتطوّع الذي يسجّل كل تغيير. الفسيفساء نفسها **مصفوفة ثابتة الحجم**، فيها خانة واحدة لكل موضع بلاطة، تحمل سلسلة نصية تمثل لونًا أو `f` التي تعني "مفقود". أما كنز مارج العقعق فهو **متجه** من البلاطات المتناثرة التي سرقتها.

## 1. أنشئ صفًا جديدًا

عرّف `fresh-mosaic` لتأخذ طولًا `n` وتُرجع مصفوفة من `n` خانة فارغة (كل واحدة منها `f`).

```factor
4 fresh-mosaic .
! => { f f f f }
```

## 2. ضع بلاطة

عرّف `place-tile` لتأخذ صفًا وموضعًا ولونًا، وتُحدّث الصف في مكانه بحيث يحمل الموضع المذكور ذلك اللون. ولا تُرجع هذه الكلمة شيئًا.

```factor
5 fresh-mosaic   ! { f f f f f }
dup 2 "ruby" place-tile
.
! => { f f "ruby" f f }
```

## 3. اخلع بلاطة

عرّف `chip-tile` لتأخذ صفًا وموضعًا، وتُحدّث الصف في مكانه بحيث يصبح الموضع المذكور `f` مرة أخرى.

```factor
{ "ruby" "lapis" "jade" } 1 chip-tile .
! => { "ruby" f "jade" }
```

## 4. أعد تلوين بلاطة

عرّف `recolour-tile` لتأخذ صفًا وموضعًا و quotation بوسيط واحد، وتُحدّث الصف في مكانه بتطبيق quotation على البلاطة في ذلك الموضع.

```factor
{ "RUBY" "LAPIS" "JADE" } 1 [ >lower ] recolour-tile .
! => { "RUBY" "lapis" "JADE" }
```

## 5. التقط لقطة قبل أن تصل مارج

عرّف `snapshot-mosaic` لتأخذ صفًا وتُرجع نسخة مستقلة لا تتأثر بالتعديلات اللاحقة على الأصل.

```factor
{ "ruby" "lapis" "jade" } dup snapshot-mosaic    ! two equal but independent copies
swap 0 "amber" place-tile                        ! mutate the first
.s
! => { "ruby" "lapis" "jade" }                   (the snapshot)
! => { "amber" "lapis" "jade" }                  (the mutated original)
```

## 6. مارج تضع بلاطة في جيبها

عرّف `stash-tile` لتأخذ كنز مارج (متجهًا) ولونًا، وتضيف اللون إلى الكنز. ولا تُرجع شيئًا.

```factor
V{ } clone   ! a fresh empty hoard
dup "ruby"  stash-tile
dup "lapis" stash-tile
.
! => V{ "ruby" "lapis" }
```

## 7. مارج تُرجع بلاطة

عرّف `return-tile` لتأخذ كنز مارج، وتُزيل أحدث بلاطة مخزّنة (التي في الأعلى) وتُرجعها.

```factor
V{ "ruby" "lapis" "jade" } clone
dup return-tile .
! => "jade"
.
! => V{ "ruby" "lapis" }
```
