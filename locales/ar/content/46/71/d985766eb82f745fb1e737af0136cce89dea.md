# مقدمة

القاموس (`dict`) في Python بنية بيانات تربط _المفاتيح_ [القابلة للتجزئة][term-hashable] بـ_القيم_، ويُعرف في لغات البرمجة الأخرى باسم [جدول التجزئة][hashtable-wikipedia] القابل لتغيير حجمه، أو خريطة التجزئة، أو [المصفوفة الترابطية][associative-array]. والقواميس هي [نوع الربط][mapping-types-dict] المدمج الوحيد في Python.

يجب أن تكون `Keys` قابلة للتجزئة وفريدة في القاموس كله.
يمكن أن تشمل أنواع المفاتيح `numbers` أو `str` أو `tuples` (من قيم _غير قابلة للتغيير_).
ولا يمكنها أن تحتوي على بنى بيانات _قابلة للتغيير_ مثل `lists` أو `dict`s أو `set`s.
وبدءًا من Python 3.7، أصبح ترتيب مفاتيح `dict` مضمونًا ليطابق ترتيب إدخال العناصر.

ويمكن أن تكون `values` من أي نوع أو بنية بيانات.
كما يمكن للقيم أن تتداخل _بشكل تعسفي_، بحيث تشمل قوائم داخل قوائم، وقواميس فرعية، وبنى بيانات أخرى مخصصة أو مركّبة.

عند إعطاء `key`، تستطيع القواميس استرجاع `value` في زمن ثابت (في المتوسط) (_بغض النظر عن عدد العناصر_).
وبالمقارنة مع البحث عن قيمة داخل `list` أو `array` (_دون معرفة موضع `index`_)، يستهلك `dict` ذاكرة أكبر بكثير، لكن استرجاعه سريع جدًا.
وتكون القواميس مفيدة بشكل خاص حين تكون مجموعة العناصر كبيرة ويلزم الوصول إليها وتحديثها بشكل متكرر.

## إنشاء القاموس

يمكن إنشاء القواميس بطرق كثيرة.
وأبسط طريقتين هما استخدام المنشئ `dict()` أو الإعلان عن `dict` _حرفي_.

### منشئ الصنف `dict()`

يمكن استخدام `dict()` (_منشئ صنف القاموس_) مع أي كائن قابل للتكرار من أزواج `key` و`value`، أو مع سلسلة من _الوسائط_ `<name>=<value>`:

```python
#Passing a list of key,value tuples.
>>> wombat = dict([('name', 'Wombat'),('speed', 23),('land_animal', True)])
{'name': 'Wombat', 'speed': 23, 'land_animal': True}


#Using key=value arguments.
>>> bear = dict(name="Black Bear", speed=40, land_animal=True)
{'name': 'Black Bear', 'speed': 40, 'land_animal': True}
```

### القواميس الحرفية

يمكن أيضًا كتابة `dict` مباشرةً على هيئة _قاموس حرفي_، باستخدام الأقواس المعقوفة (`{}`) التي تُحيط بأزواج `key : value`:

```python
>>> whale = {"name": "Blue Whale", "speed": 35, "land_animal": False}
{'name': 'Blue Whale', 'speed': 35, 'land_animal': False}
```

## الوصول إلى القيم في القاموس

يمكنك الوصول إلى عنصر في القاموس باستخدام _مفتاح_ بين الأقواس المربعة (`[]`).
وإذا لم يكن `key` موجودًا في `dict`، يُرفع `KeyError`:

```python
>>> bear["speed"]
40

>>> bear["color"]
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'color'
```

يمكن تجنّب `KeyError` بالوصول إلى عنصر عبر الطريقة `.get(<key>, <default value>)`:

```python
>>> bear.get("color", 'not found')
'not found'
```

## تغيير قيم القاموس أو إضافتها

يمكنك تغيير `value` الخاص بعنصر عبر الإسناد إلى _المفتاح_ الخاص به:

```python
#Assigning the value "Grizzly Bear" to the name key.
>>> bear["name"] = "Grizzly Bear"
{'name': 'Grizzly Bear', 'speed': 40, 'land_animal': True}

>>> whale["speed"] = 25
{'name': 'Blue Whale', 'speed': 25, 'land_animal': False}
```

ويمكن _إضافة_ أزواج `key`:`value` جديدة بالطريقة نفسها:

```python
# Adding a new "color" key with a new "tawney" value.
>>> bear["color"] = 'tawney'
{'name': 'Grizzly Bear', 'speed': 40, 'land_animal': True, 'color': 'tawney'}

>>> whale["blowholes"] = 1
{'name': 'Blue Whale', 'speed': 25, 'land_animal': False, 'blowholes': 1}
```

## إزالة عناصر القاموس (عبر Pop)

يمكنك استخدام الطريقة `.pop(<key>)` لحذف عنصر من القاموس.
وتزيل `.pop()` الزوج (`key`, `value`) وتُرجع `value` للاستخدام.
ومثل `.get()`، تقبل `.pop(<key>)` وسيطًا ثانيًا (_`dict.pop(<key>, <default value>)`_) يُرجع إذا لم يُعثر على `key`.
وهذا يمنع رفع `KeyError`:

```python
#Using .pop() removes both the key and value, returning the value.
>>> bear.pop("name")
'Grizzly Bear'


#The "name" key is now removed from the dictionary.
#Attempting .pop() a second time will throw a KeyError.
>>> bear.pop("name")
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'name'


#Using a default argument with .pop() will prevent a KeyError from a missing key.
>>> bear.pop("name", "Unknown")
'Unknown'
```

## المرور على القاموس والتكرار خلاله

عند المرور على قاموس باستخدام `for item in dict` أو `while item`، سيتم التكرار على _المفاتيح_ فقط بشكل افتراضي.
ويمكنك الوصول إلى _القيم_ داخل الحلقة نفسها باستخدام _الأقواس المربعة_:

```python
>>> for key in bear:
>>>     print((key, bear[key])) #this forms a tuple of (key, value) and prints it.
('name', 'Black Bear')
('speed', 40)
('land_animal', True)
```

يمكنك أيضًا استخدام الطريقة `.items()`، التي تُرجع تلقائيًا صفوفًا من (`key`, `value`):

```python
#dict.items() forms (key, value tuples) that can be unpacked and iterated over.
>>> for key, value in whale.items():
>>>     print(key, ":", value)
name : Blue Whale
speed : 25
land_animal : False
blowholes : 1
```

وبالمثل، ستُرجع الطريقة `.keys()` المفاتيح `keys`، وستُرجع الطريقة `.values()` القيم `values`.
