# ملحق التعليمات

## السجلات

| السجل | الاستخدام | النوع | الوصف |
| -------- | --------- | ------- | ---------------------------------------------------------- |
| `$a0`    | إدخال     | عدد صحيح | الفئة: `0` = choice، `1` = ones، `2` = twos، `3` = threes، `4` = fours، `5` = fives، `6` = sixes، `7` = little_straight، `8` = big_straight، `9` = full_house، `10` = four_of_a_kind، `11` = yacht |
| `$a2`    | إدخال     | عنوان | النرد (مصفوفة كلمات) |
| `$v0`    | إخراج     | عدد صحيح | النتيجة الناتجة |
| `$t0-9`  | مؤقت      | أي | تُستخدم للتخزين المؤقت |
