# التعليمات

في هذا التمرين، ستُنفّذ مجموعة جزئية من الإجراءات المساعدة لمساعدة مطوّر على تنظيف أسماء المعرّفات.
في المهام الخمس ستبني تدريجيًا الإجراء `Clean`.
يتكوّن المعرّف الصالح من صفر أو أكثر من الحروف والشرطات السفلية.
في جميع الحالات، من المضمون أن سلسلة الإدخال ليست `null`.
وإذا مُرّرت سلسلة نصية فارغة إلى دالة `Clean`، فيجب إرجاع سلسلة نصية فارغة.
لاحظ أن على المستدعي أن يتجنّب استدعاء الإجراء `Clean` بمعرّف فارغ، لأن مثل هذه المعرّفات لا تأثير لها.

## 1. استبدل أي مسافات تصادفها بالشرطات السفلية

نفّذ الطريقة (_static_) `Identifier.Clean()` لاستبدال أي مسافات بالشرطات السفلية.
وينطبق هذا أيضًا على المسافات البادئة واللاحقة.

```csharp
Identifier.Clean("my   Id");
// => "my___Id"
```

## 2. استبدل أحرف التحكم بالسلسلة النصية "CTRL" المكتوبة بحروف كبيرة

عدّل الطريقة (_static_) `Identifier.Clean()` لاستبدال أحرف التحكم بالسلسلة النصية `"CTRL"` المكتوبة بحروف كبيرة.

```csharp
Identifier.Clean("my\0Id");
// => "myCTRLId",
```

## 3. حوّل kebab-case إلى camelCase

عدّل الطريقة (_static_) `Identifier.Clean()` لتحويل kebab-case إلى camelCase.

```csharp
Identifier.Clean("à-ḃç");
// => "àḂç"
```

## 4. تجاهل الأحرف التي ليست حروفًا

عدّل الطريقة (_static_) `Identifier.Clean()` لتجاهل أي أحرف ليست حروفًا.

```csharp
Identifier.Clean("1😀2😀3😀");
// => ""
```

## 5. تجاهل الحروف اليونانية الصغيرة

عدّل الطريقة (_static_) `Identifier.Clean()` لتجاهل أي حروف يونانية في النطاق من 'α' إلى 'ω'.

```csharp
Identifier.Clean("MyΟβιεγτFinder");
// => "MyΟFinder"
```
