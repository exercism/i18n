# مقدمة

## المعدّلات الزمنية

عند العمل مع كائنات `java.time` مثل `LocalDate`، غالبًا ما تحتاج إلى إجراء تعديلات معقّدة على التواريخ، مثل إيجاد «الثلاثاء الثاني من الشهر». وبدلًا من حساب ذلك يدويًا، يمكنك استخدام **`TemporalAdjusters`**.

يوفّر صنف الأدوات المساعدة `java.time.temporal.TemporalAdjusters` (لاحظ حرف s في آخره) دوال `static` لكثير من تعديلات التواريخ الشائعة. وتُطبّق هذه التعديلات باستخدام الطريقة `.with()` على كائن زمني (مثل `LocalDate`).

```exercism/note
استخدام `with(TemporalAdjuster)` يُرجع نسخة _جديدة_ ولا يحدّث النسخة الموجودة، لأن كائنات `java.time` غير قابلة للتغيير.
```

```java
import java.time.LocalDate;
import java.time.Month;
import java.time.DayOfWeek;
import java.time.temporal.TemporalAdjusters;

LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15 (a Thursday)

// Use a predefined adjuster: find the last day of the month
LocalDate lastDay = date.with(TemporalAdjusters.lastDayOfMonth());
// => 2024-08-31
```

إليك بعض المعدّلات الأساسية المفيدة في حسابات الجدولة:

### إيجاد اليوم الترتيبي في الأسبوع

استخدم `dayOfWeekInMonth(int ordinal, DayOfWeek dayOfWeek)` لإيجاد التكرار رقم n ليوم من أيام الأسبوع.

```java
// Find the second Tuesday of August 2024
LocalDate secondTuesday = date.with(TemporalAdjusters.dayOfWeekInMonth(2, DayOfWeek.TUESDAY));
// => 2024-08-13
```

### إيجاد أول/آخر يوم من أيام الأسبوع في الشهر

استخدم `firstInMonth(DayOfWeek dayOfWeek)` أو `lastInMonth(DayOfWeek dayOfWeek)`.

```java
// Find the last Monday of August 2024
LocalDate lastMonday = date.with(TemporalAdjusters.lastInMonth(DayOfWeek.MONDAY));
// => 2024-08-26
```

### التعديلات النسبية (التالي/السابق)

المعدّلات مثل `next()` و`previous()` و`nextOrSame()` و`previousOrSame()` تجد التكرار التالي أو السابق ليوم معيّن من أيام الأسبوع، نسبةً إلى التاريخ الحالي.

- `next()`/`previous()`: تستبعدان التاريخ الحالي إذا طابقه.
- `nextOrSame()`/`previousOrSame()`: تشملان التاريخ الحالي إذا طابقه.

```java
LocalDate thursday = LocalDate.of(2024, Month.AUGUST, 15); // A Thursday

// Find the next Thursday (exclusive)
LocalDate nextThursday = thursday.with(TemporalAdjusters.next(DayOfWeek.THURSDAY));
// => 2024-08-22

// Find the next Thursday (inclusive) - returns the same date
LocalDate nextOrSameThursday = thursday.with(TemporalAdjusters.nextOrSame(DayOfWeek.THURSDAY));
// => 2024-08-15

// Find the previous Monday (exclusive)
LocalDate previousMonday = thursday.with(TemporalAdjusters.previous(DayOfWeek.MONDAY));
// => 2024-08-12
```

### المعدّلات المخصّصة

`TemporalAdjuster` واجهة وظيفية، لذا يمكنك كتابة معدّل خاص بك على هيئة تعبير لامدا يستقبل الكائن الزمني المطلوب تعديله ويُرجع الكائن بعد التعديل. ويُطبَّق باستخدام `.with()` تمامًا مثل المعدّلات المعرّفة مسبقًا، ويمكنه أن يستخدمها داخليًا.

```java
import java.time.temporal.TemporalAdjuster;

// An adjuster that moves a weekend date to the following Monday
TemporalAdjuster skipWeekend = temporal -> {
    DayOfWeek day = DayOfWeek.from(temporal);
    if (day == DayOfWeek.SATURDAY || day == DayOfWeek.SUNDAY) {
        return temporal.with(TemporalAdjusters.next(DayOfWeek.MONDAY));
    }
    return temporal;
};

LocalDate saturday = LocalDate.of(2024, Month.AUGUST, 17);
LocalDate monday = saturday.with(skipWeekend);
// => 2024-08-19
```

إن استخدام هذه المعدّلات من صنف `TemporalAdjusters` يبسّط كثيرًا مهام التعامل مع التواريخ.
