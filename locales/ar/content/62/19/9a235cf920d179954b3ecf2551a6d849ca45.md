# مقدمة

يمكن تكييف عوامل الحساب والمقارنة الأساسية لتستخدمها مع **abstract** الخاص بك. يُعرف هذا باسم التحميل الزائد للعوامل.

استخدم حقل الصنف `@:op()` الخاص بالبيانات الوصفية لتحميل عامل:

```haxe
abstract MyAbstract(String) {
  public inline function new(s:String) {
    this = s;
  }

  @:op(A * B)
  public function repeat(rhs:Int):MyAbstract {
    var s:StringBuf = new StringBuf();
    for (i in 0...rhs)
      s.add(this);
    return new MyAbstract(s.toString());
  }
}

class Main {
  static public function main() {
    var a = new MyAbstract("foo");
    trace(a * 3); // foofoofoo
  }
}
```
