# الاختبارات

## ملفات التمرين

يتضمّن التمرين المُنزَّل هذه الملفات لبناء حلّك واختباره:

```text
hello-world/
├── HelloWorld.vb       # Your solution
├── HelloWorldTests.vb  # The test suite
├── HelloWorld.vbproj   # Project and build configuration
└── packages.lock.json  # Resolved project dependencies
```

تختلف أسماء الملفات باختلاف التمرين.
اكتب حلّك في ملف `.vb` الذي لا ينتهي اسمه بـ`Tests`.
الملف الذي ينتهي بـ`Tests.vb` هو مجموعة اختبارات xUnit؛ وعادةً لا ينبغي أن تعدّله إلا لحذف وسائط `Skip`.
وعادةً لا تحتاج إلى تعديل ملف المشروع أو ملف القفل.

## تشغيل الاختبارات

افتح نافذة طرفية في مجلد التمرين ثم شغّل:

```bash
dotnet test
```

يقوم هذا الأمر باستعادة اعتماديات المشروع، وبناء المشروع، وتشغيل اختباراته.
يمكنك أيضًا استخدام `dotnet watch test` لإعادة تشغيل الاختبارات كلما تغيّر أحد ملفات المصدر.

## الاختبارات المتخطّاة

في البداية، تُفعّل التمارين الاختبار الأول فقط، ما يتيح لك حلّ الباقي خطوة بخطوة.
افتح الملف الذي ينتهي بـ`Tests.vb` للعثور على الاختبارات.
كل اختبار هو إجراء فرعي `Sub` موسوم بسمة `<Fact>` من xUnit.
يُتخطّى الاختبار ما دامت سمة `<Fact>` الخاصة به تحتوي على وسيط `Skip`:

```vb
<Fact(Skip:="Remove this Skip property to run this test")>
Public Sub Lowercase_words()
    Assert.Equal("ROR", Abbreviate("Ruby on Rails"))
End Sub
```

لتفعيل الاختبار، احذف وسيط `Skip` فقط:

```vb
<Fact>
Public Sub Lowercase_words()
    Assert.Equal("ROR", Abbreviate("Ruby on Rails"))
End Sub
```

بعد نجاح الاختبار المفعّل حديثًا، كرّر هذه العملية مع الاختبار المتخطّى التالي.
عندما تصبح كل الاختبارات مفعّلة وناجحة، تكون قد انتهيت.
