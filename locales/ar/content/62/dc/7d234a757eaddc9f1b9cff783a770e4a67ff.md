# مقدمة

## العشوائية

يمكن استخدام نسخة من الصنف `java.util.Random` لتوليد أعداد عشوائية في Java.

### أعداد صحيحة عشوائية

يمكن توليد عدد صحيح عشوائي باستخدام الطريقة `nextInt()`.
سيولّد هذا قيمة في المدى من `Integer.MIN_VALUE` إلى `Integer.MAX_VALUE`.

```java
Random random = new Random();

random.nextInt();
// => -1169335537
```

لتحديد مدى القيم المولَّدة، استخدم `nextInt(int)`.
سيولّد هذا قيمة في المدى من `0` (شاملًا) إلى الحد الأعلى المعطى (غير شامل).

على سبيل المثال، سيولّد هذا عددًا عشوائيًا من `0` إلى `9`.

```java
Random random = new Random();

random.nextInt(10);
// => 6
```

وسيولّد هذا عددًا عشوائيًا من `10` إلى `19`.

```java
Random random = new Random();

10 + random.nextInt(10);
// => 11
```

### أعداد عشرية عشوائية

يمكن توليد عدد عشري عشوائي باستخدام الطريقة `nextDouble()`.
سيولّد هذا قيمة في المدى من `0.0` إلى `1.0`.

```java
Random random = new Random();

random.nextDouble();
// => 0.19250004204021398
```

وسيولّد هذا عددًا عشوائيًا من `100.0` إلى `200.0`.

```java
Random random = new Random();

100.0 + 100.0 * random.nextDouble();
// => 111.31849856260328
```
