# التثبيت

## تثبيت .NET

مسار F# مبني على منصة [.NET](https://dotnet.microsoft.com/learn/dotnet/what-is-dotnet)، وهي تعمل على Windows وLinux وmacOS. لبناء مشاريع .NET، يمكنك استخدام واجهة سطر الأوامر (command-line interface، أو CLI) الخاصة بـ .NET. هذه الواجهة جزء من .NET SDK، ويمكنك تثبيته باتباع [تعليمات التثبيت](https://dotnet.microsoft.com/download). ملاحظة: يتطلب مسار F# الإصدار 8.0 من SDK أو أحدث.

بعد إتمام التثبيت، يمكنك التحقق من نجاح تثبيت واجهة سطر الأوامر بتشغيل هذا الأمر في الطرفية:

```bash
dotnet --version
```

إذا كان الناتج إصدارًا أكبر من أو يساوي `8.0.100`، فقد ثُبّت .NET SDK بنجاح.

## استخدام بيئة تطوير متكاملة (IDE)

إذا كنت تريد تجربة تحرير أغنى بالمزايا، فالأرجح أنك تريد استخدام بيئة تطوير متكاملة (IDE). هذه أشهر بيئات التطوير المتكاملة التي تدعم بناء مشاريع .NET:

- [Visual Studio 2022](https://www.visualstudio.com/downloads/)
- [Visual Studio Code](https://code.visualstudio.com/download) مع [إضافة Ionide-fsharp](https://marketplace.visualstudio.com/items?itemName=Ionide.Ionide-fsharp)
- [Visual Studio for Mac](https://www.visualstudio.com/vs/visual-studio-mac/)
- [Project Rider](https://www.jetbrains.com/rider/download/)

ملاحظة: بما أن تنسيق مشاريع .NET يختلف اختلافًا كبيرًا عن الإصدارات السابقة، فإن بيئات التطوير الأقدم (مثل Visual Studio 2015) غير مدعومة.
