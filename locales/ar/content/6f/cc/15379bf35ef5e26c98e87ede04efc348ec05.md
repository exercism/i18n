# مقدمة

يتضمن تعريف المجموعة عادةً عنصرًا نائبًا بين الأقواس الزاوية، غالبًا `T` حسب الاصطلاح. وتُسمى هذه المجموعة نوعًا عامًا. وهذا يسمح لمستخدم المجموعة بتحديد نوع العناصر التي ستُخزَّن في المجموعة. وفي مثال الكود أعلاه، نُنشئ مصفوفة من السلاسل النصية.

يُجعل الصنف أو الدالة **عامًّا** باستخدام السمة `@:generic`. وهذا يجعل المترجم يتعرف على الصنف أو الدالة على أنهما عامان:

```haxe
@:generic
class MyValue<T> {
  public var value:T;

  public function new(value:T) {
    this.value = value;
  }
}

var a = MyValue<String>("Hello");
trace(a.value); // Hello
```
