# المقدمة

## القيم المنطقية

تُمثَّل القيم المنطقية في Java بالنوع `boolean`، ويمكن أن تكون قيمها إما `true` أو `false`.

تدعم Java ثلاثة عوامل منطقية:  

- `!` (NOT): يعكس القيمة المنطقية  
- `&&` (AND): يأخذ قيمتين منطقيتين ويُرجع `true` إذا كانتا كلتاهما `true`
- `||` (OR): يُرجع `true` إذا كانت إحدى القيمتين المنطقيتين `true`

### أمثلة

```java
!true // => false
!false // => true
true && false // => false
true && true // => true
false || false // => false
false || true // => true
```
