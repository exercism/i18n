# مقدمة

## السلاسل النصية

`String` في Java هو كائن يمثل نصًا غير قابل للتغيير على هيئة تسلسل من أحرف Unicode (حروف، وأرقام، وعلامات ترقيم، وغير ذلك).
تُستخدم علامات الاقتباس المزدوجة لتعريف نسخة من `String`:

```java
String fruit = "Apple";
```

يتم التعامل مع السلاسل النصية من خلال استدعاء طرق السلسلة النصية.
بمجرد إنشاء سلسلة نصية، لا يمكن أن تتغير قيمتها أبدًا.
أي طرق تبدو وكأنها تعدّل السلسلة النصية ستُرجع في الواقع سلسلة نصية جديدة.
يوفّر الصنف `String` بعض الطرق _static_ لتحويل السلاسل النصية.
