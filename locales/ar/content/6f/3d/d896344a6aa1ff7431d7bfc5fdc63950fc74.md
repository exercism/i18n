# نبذة

كما رأينا في مفهوم [`Nothingness`][concept-nothingness]، تتعدد في R طرق تمثيل البيانات الغائبة ([`NULL`][ref-null]) أو المجهولة ([`NA`][ref-na]) أو غير الصالحة رياضيًا ([`NaN`][ref-finite]، [`Inf`][ref-finite]). وعمومًا، تحاول R استخدام هذه القيم للإشارة إلى المشكلات في موضعها، ثم المتابعة دون رفع استثناء.

## `stop()`

بعض المشكلات جوهرية إلى حد لا يسمح للبرنامج بالمتابعة.
في هذه الحالة، استخدم [`stop(msg)`][ref-stop] لإيقاف البرنامج فورًا برفع خطأ `Error` وطباعة `msg`.

```R
f <- function() {
    stop("I have a problem")
}
f()
#> Error in f() : I have a problem
```

## `stopifnot()`

مثل [`assert`][wiki-assert] في لغات أخرى، تُعدّ [`stopifnot()`][ref-stopifnot] غلافًا مريحًا حول `stop()`.
الوسائط هي عدد اعتباطي من الشروط المنطقية، مفصولة بفواصل، ولن يتابع البرنامج إلا إذا كانت جميعها `TRUE`.

```R
stopifnot(1 < 2) # continues OK
stopifnot(1 < 2, 1 == 2)
#> Error: 1 == 2 is not TRUE
```

## `try()`

تمتلك R طرقًا متنوعة للتعامل مع الأخطاء.
وهي مبنية على Common Lisp وتختلف اختلافًا كبيرًا عن كثير من اللغات الشائعة.

أبسطها هو تغليف الكود الذي قد يسبب مشكلات داخل [`try()`][ref-try].

```R
g <- function(val) {
  log10(val)
}

g(3)
#> [1] 0.4771213

g("3")
#> Error in log10(val) : non-numeric argument to mathematical function

# with try() and a default value
h <- function(val) {
  result <- NA
  try(result <- log10(val))
  result
}

h(3) # works as before
#> [1] 0.4771213

h("3") # returns a default value plus the error message
Error in log10(val) : non-numeric argument to mathematical function
#> [1] NA
```

## [`warning()`][ref-warning] و[`message()`][ref-message]

هاتان استجابتان لحالات غير قاتلة، مثل:

- التحذير من مشكلة يستطيع البرنامج التعافي منها جزئيًا على الأقل.
- إبلاغ المستخدم بمدى التقدّم في برنامج طويل التشغيل.

من الفروق بينهما أن التحذيرات تُخزَّن مؤقتًا وتُخرَج (افتراضيًا) عند إرجاع الدالة، أما الرسائل فتُخرَج فورًا.
وهناك طرق كثيرة لتغيير السلوك الافتراضي، وهو ما يخرج عن نطاقنا هنا.

```R
w <- function() {
  warning("something strange happened")
  -1
}

w()
#> [1] -1
#> Warning message:
#> In w() : something strange happened

# if warnings are not wanted
suppressWarnings(w())
#> [1] -1
```

قد تكون الدالة [`suppressWarnings()`][ref-warning] مفيدة أحيانًا داخل Exercism، لتجنّب إرباك مُشغّل الاختبارات بمخرجات غير مرغوبة.
