# التثبيت

## المتطلبات

* معالج x86 بمعمارية 64 بت
* مُصرّف C حديث
* أداة البناء Make
* المُجمّع Netwide Assembler (NASM)

يُرجى ملاحظة أن هذا المسار يدعم فقط اصطلاح الاستدعاء الخاص بـ System V AMD64 ABI. ويحتاج مستخدمو Windows إلى تثبيت Windows Subsystem for Linux (WSL)، أو إعداد جهاز افتراضي يعمل بنظام Linux.

## Linux

ثبّت البرمجيات المطلوبة باستخدام مدير الحزم في نظامك:

* Ubuntu, Debian: `$ sudo apt-get install gcc make nasm`
* Fedora: `$ sudo dnf install gcc make nasm`
* CentOS, RHEL: `$ sudo yum install gcc make nasm`
* Arch Linux: `$ sudo pacman -S gcc make nasm`
* OpenSUSE: `$ sudo zypper install gcc make nasm`

## macOS

ثبّت أدوات سطر أوامر Xcode:

```bash
$ xcode-select --install
```

ثبّت NASM باستخدام [Homebrew](http://brew.sh/):

```bash
$ brew install nasm
```

## Windows

لتثبيت WSL، راجع https://docs.microsoft.com/en-us/windows/wsl/install-win10.
