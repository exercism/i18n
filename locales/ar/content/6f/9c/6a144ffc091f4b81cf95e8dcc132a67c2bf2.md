# المقدمة

في JavaScript، المصفوفة بنية شبيهة بالقائمة ليس لها طول ثابت، ويمكنها أن تحمل أي نوع من القيم الأولية أو الكائنات، حتى الأنواع المختلطة.

لإنشاء مصفوفة، أضف العناصر بين الأقواس المربعة `[]`.
للقراءة من المصفوفة، ضع الفهرس بين الأقواس المربعة `[]` بعد المُعرّف.
تبدأ فهارس المصفوفة من الصفر.

على سبيل المثال:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[2];
// => 3
```

لمعرفة عدد العناصر الموجودة في المصفوفة، استخدم خاصية `length`:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.length;
// => 4
```

لتغيير عنصر في المصفوفة، تُسند قيمة عند الفهرس:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[0] = 'one';
numbers;
// => ['one', 'two', 3, 'four']
```

## الطرق

يمكن استخدام بعض [الطرق][mdn-array] المتاحة على كل كائن `Array` لإضافة عناصر إلى المصفوفة أو إزالتها منها.
إليك بعضًا منها لتأخذها في الحسبان عند العمل على هذا التمرين:

### push

يمكن _إضافة_ `value` إلى نهاية المصفوفة باستخدام `.push(value)`.
تُرجع الطريقة الطول الجديد للمصفوفة.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.push(5); // => 5
numbers;
// => [1, 'two', 3, 'four', 5]
```

### pop

يمكن _إزالة_ آخر `value` من المصفوفة باستخدام `.pop()`
تُرجع الطريقة القيمة المُزالة.
سيقل طول المصفوفة بسبب هذا التغيير.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.pop(); // => four
numbers;
// => [1, 'two', 3]
```

### shift

يمكن _إزالة_ أول `value` من المصفوفة باستخدام `.shift()`
تُرجع الطريقة القيمة المُزالة.
سيقل طول المصفوفة بسبب هذا التغيير.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.shift(); // => 1
numbers;
// => ['two', 3, 'four']
```

### unshift

يمكن _إضافة_ `value` إلى بداية المصفوفة باستخدام `.unshift(value)`.
تُرجع الطريقة الطول الجديد للمصفوفة.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.unshift('one'); // => 5
numbers;
// => ['one', 1, 'two', 3, 'four']
```

### splice

يمكن _إزالة_ `value` عند `index` محدد من المصفوفة باستخدام `.splice(index, 1)`.
تُرجع الطريقة العنصر أو العناصر المُزالة.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.splice(2, 1, 'one'); // => [3]
numbers;
// => [1, 'two', 'one', 'four']
```

~~~exercism/advanced
هذه الطرق أقوى مما هو موصوف:

- تسمح لك كل من `push` و `unshift` بإضافة أو إدراج قيم متعددة دفعة واحدة، عبر إضافة وسائط أكثر.
  هذا ليس ضروريًا لإكمال هذا التمرين.
- يمكن لـ `splice` إزالة قيم متعددة بزيادة الوسيط الثاني.
  هذا ليس ضروريًا لإكمال هذا التمرين.
- يمكن لـ `splice` أيضًا إضافة قيم متعددة عبر تمريرها كوسائط بعد `deleteCount`.
  يمكن استخدام هذا لاستبدال قيم، أو لإدراج قيم في منتصف المصفوفة (على سبيل المثال عن طريق إزالة 0 عناصر).
  هذا ليس ضروريًا لإكمال هذا التمرين.
