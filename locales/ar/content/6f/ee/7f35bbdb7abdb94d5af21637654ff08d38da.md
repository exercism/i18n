# مقدمة

‏[`Set`][set] مجموعة من العناصر لها الخصائص التالية:

- غير مرتبة.
- عناصرها فريدة، لذا تُتجاهل محاولات إضافة عناصر مكررة بصمت.
- تدعم العديد من العمليات الشائعة في المجموعات الرياضية.

أنشئها باستخدام البانية `Set()`، مع تمرير أي مُكرِّر كمعامل.

```julia-repl
julia> s1 = Set(1:4)
Set([4, 2, 3, 1])
```

أضف عناصر جديدة باستخدام `push!()` (تمامًا كما في المصفوفات)، وأزلها باستخدام `delete!()`.

```julia-repl
julia> push!(s1, 5)
Set([5, 4, 2, 3, 1])

# Duplicates are ignored
julia> push!(s1, 3)
Set([5, 4, 2, 3, 1])

julia> delete!(s1, 5)
Set([4, 2, 3, 1])

julia> length(s1)  # length counts entries, despite the non-sequential type
4
```

## عمليات المجموعات

كما هو الحال مع عدة أنواع أخرى من المجموعات، تحقق من الانتماء باستخدام العامل `in` أو `∈` (اكتب `\in` ثم Tab للحصول على الرمز).

```julia-repl
julia> 3 ∈ s1
true
```

تدعم العمليات التالية على أزواج المجموعات (تظهر اختصارات رمز العامل بين قوسين).

- `union(A, B)` أو `A ∪ B` (`\cup`): كل العناصر الموجودة في A أو B أو فيهما معًا.
- `intersect(A, B)` أو `A ∩ B` (`\cap`): كل العناصر المشتركة بين A و B.
- `setdiff(A, B)` (بلا رمز): العناصر الموجودة في A وليس في B.
- `symdiff(A, B)` (بلا رمز): العناصر الموجودة في A أو B وليس فيهما معًا.
- `issubset(A, B)` أو `A ⊆ B` (`\subseteq`) أو `B ⊇ A` (`\supseteq`): ‏`true` إذا كانت كل العناصر في A موجودة أيضًا في B.
- `issetequal(A, B)` (بلا رمز): ‏`true` إذا كانت A و B تحتويان على العناصر نفسها تمامًا.
- `isdisjoint(A, B)` (بلا رمز): ‏`true` إذا لم يكن بين A و B أي عناصر مشتركة (أي أن التقاطع فارغ).

```julia-repl
julia> s1 = Set(1:4);
julia> s2 = Set(3:6);
julia> s1 ∪ s2  # union
Set([5, 4, 6, 2, 3, 1])

julia> s1 ∩ s2  # intersect
Set([4, 3])
  
julia> setdiff(s1, s2)
Set([2, 1])

julia> symdiff(s1, s2)
Set([5, 6, 2, 1])
  
julia> s1 ⊇ s2  # issubset
false
```

توجد أيضًا نسخ مُعدِّلة للعديد من هذه العمليات، بإضافة `!` إلى اسم الدالة.
راجع [الدليل][set] للحصول على قائمة كاملة بالدوال.
