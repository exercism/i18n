# مقدمة

من [الدليل][man-types]

> يدعم jq المجموعة نفسها من أنواع البيانات التي يدعمها JSON، وهي الأعداد، والسلاسل النصية، والقيم المنطقية، والمصفوفات، والكائنات (وهي في مصطلحات JSON تجزئات لا تحتوي إلا على مفاتيح من السلاسل النصية)، و"null".

لنركّز على **الأعداد**.

## الأعداد والعوامل العددية

جميع الأعداد، سواء أكانت صحيحة أم غير ذلك، هي أعداد فاصلة عائمة مزدوجة الدقة وفق معيار IEEE754.
وهذا يحدّنا بدقة تبلغ 53 بت.

العوامل المعتادة متاحة للاستخدام مع الأعداد:

- الحسابية: `+`، `-`، `*`، `/`، `%`
- المقارنة: `==`، `!=`، `<`، `<=`، `>=`، `>`
- [دوال الرياضيات][man-math] القياسية

  بالنسبة للدوال ذات المُدخل الواحد، مرّر القيمة إلى الدالة عبر الأنبوب

  ```sh
  $ jq -n '(1 | atan) * 4'
  3.141592653589793
  ```

  أما الدوال ذات المُدخلين فتتجاهل المُدخل وتتوقع المُدخلين كمعاملات (تذكّر أن المعاملات تُفصل بفواصل منقوطة)

  ```sh
  $ jq -n 'pow(2; 10)'
  1024
  ```

  الفاصلة المنقوطة هي الفاصل بين وسائط الدالة، وليست الفاصلة.

## تعبيرات `jq` أخرى

لحل التمرين، ستحتاج إلى معرفة التعبيرات الشرطية.

### التعبيرات الشرطية

يستخدم `jq` تعبير [`if-then-else`][if-then-else] من أجل **التعبيرات الشرطية**.
وبصفته _تعبيرًا_، فإنه يوضع داخل خط أنابيب.

الصيغة هي: `if CONDITION then TRUE_EXPR else FALSE_EXPR end`.

فرع `else` اختياري.

```jq
42 | if . < 33 then "small" else "larger" end
# => "larger"
```

تستخدم الشروط الإضافية `elif`

```jq
42 | if . < 33 then "small"
     elif . < 67 then "medium"
     else "large"
     end
# => "medium"
```
