# مقدمة

يكون النوع _نوعًا عامًّا_ عندما يمكنه أن يحتوي قيمًا من أي نوع باستخدام _معامل نوع_.

على سبيل المثال، نوع `Box` هذا له معامل النوع `a` (المكتوب بحروف صغيرة).

```gleam
pub type Box(a) {
  Box(a)
}
```

معامل النوع `a` هو عنصر نائب لأي نوع، لذا يمكن استخدام `Box` مع السلاسل النصية أو الأعداد الصحيحة أو أي نوع آخر.

```gleam
Box("Hello, Joe!") // The type is Box(String)

Box(42) // The type is Box(Int)
```

يمكن أن يكون للنوع عدة معاملات نوع، بفصلها بفواصل.

```gleam
pub type Pair(a, b) {
  Pair(a, b)
}
```

## الدوال العامة

يمكن أيضًا استخدام معاملات النوع في وسائط الدوال.

تأخذ هذه الدالة قيمة من النوع `a` وتستدعي مرتين دالةً تأخذ `a` وتُرجع `b`.

```gleam
pub fn twice(value: a, f: fn(a) -> b) -> b {
  f(value)
  f(value)
}
```
```gleam
// The type is fn(String, fn(String) -> Nil) -> Nil
twice("Hello, Joe!", io.println)
```
