# التعليمات

في هذا التمرين، ستُنفّذ منطق المهمة للعبة تقمّص أدوار جديدة يطوّرها صديق لك. الشخصية الرئيسية في اللعبة هي أنالين، فتاة شجاعة تمتلك كلبًا أليفًا شرسًا ووفيًا. ولسوء الحظ، تقع الكارثة، إذ اختُطف أعزّ أصدقائها بينما كان يبحث عن التوت في الغابة. وستحاول أنالين أن تجد أعزّ أصدقائها وتحرّره، ويمكنها أن تأخذ كلبها معها في هذه المهمة.

بعد أن تتبع أثر أعزّ أصدقائها لبعض الوقت، تجد المخيّم الذي سُجن فيه. ويتّضح أن هناك خاطفَين: فارس قويّ ورامٍ ماكر.

بعد أن وجدت الخاطفين، تدرس أنالين أيًّا من الإجراءات التالية يمكنها القيام به:

- الهجوم السريع: يمكن شنّ هجوم سريع إذا كان الفارس نائمًا، إذ يستغرق ارتداء درعه وقتًا، فيصبح عرضةً للخطر.
- التجسّس: يمكن التجسّس على المجموعة إذا كان أحد أفرادها على الأقل مستيقظًا. وإلا فإن التجسّس مضيعة للوقت.
- إرسال إشارة إلى السجين: يمكن إرسال إشارة إلى السجين باستخدام أصوات الطيور إذا كان السجين مستيقظًا والرامي نائمًا، لأن الرماة مدرّبون على التخاطب بأصوات الطيور فقد يعترضون الرسالة.
- _تحرير السجين_: يمكن لأنالين أن تحاول التسلل إلى المخيّم لتحرير السجين.
  هذا أمر محفوف بالمخاطر ولا ينجح إلا في إحدى الحالتين التاليتين:
  - إذا كان كلب أنالين الأليف معها، فيمكنها إنقاذ السجين إذا كان الرامي نائمًا.
    الفارس يخاف من الكلب ولن يكون لدى الرامي وقت للاستعداد قبل أن تتمكّن أنالين والسجين من الهرب.
  - إذا لم يكن كلب أنالين معها، فعليها هي والسجين أن يتسلّلا بحذر شديد!
    يمكن لأنالين تحرير السجين إذا كان السجين مستيقظًا وكان الفارس والرامي نائمين معًا، أما إذا كان السجين نائمًا فلا يمكن إنقاذه: إذ سيفزع السجين من ظهور أنالين المفاجئ فيوقظ الفارس والرامي.

لديك أربع مهام: تنفيذ المنطق الذي يحدّد ما إذا كانت الإجراءات أعلاه متاحة بناءً على حالة الشخصيات الثلاث الموجودة في الغابة وما إذا كان كلب أنالين الأليف حاضرًا أم لا.

## 1. تحقّق مما إذا كان إجراء 'الهجوم السريع' ممكنًا

نفّذ دالة باسم `canExecuteFastAttack` تأخذ قيمة منطقية تشير إلى ما إذا كان الفارس مستيقظًا. تُرجع هذه الدالة `true` إذا كان إجراء 'الهجوم السريع' متاحًا بناءً على حالة الشخصية. وإلا فإنها تُرجع `false`:

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

canExecuteFastAttack knightIsAwake
-- => false
```

## 2. تحقّق مما إذا كان إجراء 'التجسّس' ممكنًا

نفّذ دالة باسم `canSpy` تأخذ ثلاث قيم منطقية تشير على الترتيب إلى ما إذا كان الفارس والرامي والسجين مستيقظين. تُرجع الدالة `true` إذا كان إجراء 'التجسّس' متاحًا بناءً على حالة الشخصيات. وإلا فإنها تُرجع `false`:

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

archerIsAwake :: Boolean
archerIsAwake = true

prisonerIsAwake :: Boolean
prisonerIsAwake = true

canSpy knightIsAwake archerIsAwake prisonerIsAwake
-- => true
```

## 3. تحقّق مما إذا كان إجراء 'إرسال إشارة إلى السجين' ممكنًا

نفّذ دالة باسم `canSignalPrisoner` تأخذ قيمتين منطقيتين تشير على الترتيب إلى ما إذا كان الرامي والسجين مستيقظين. تُرجع الدالة `true` إذا كان إجراء 'إرسال إشارة إلى السجين' متاحًا بناءً على حالة الشخصيات. وإلا فإنها تُرجع `false`:

```purescript
archerIsAwake :: Boolean
archerIsAwake = false

prisonerIsAwake :: Boolean
prisonerIsAwake = true

canSignalPrisoner archerIsAwake prisonerIsAwake -- => true
```

## 4. تحقّق مما إذا كان إجراء 'تحرير السجين' ممكنًا

نفّذ دالة باسم `canFreePrisoner` تأخذ أربع قيم منطقية. تشير المعاملات الثلاثة الأولى على الترتيب إلى ما إذا كان الفارس والرامي والسجين مستيقظين. ويشير المعامل الأخير إلى ما إذا كان كلب أنالين الأليف حاضرًا. تُرجع الدالة `true` إذا كان إجراء 'تحرير السجين' متاحًا بناءً على حالة الشخصيات وحضور كلب أنالين الأليف. وإلا فإنها تُرجع `false`:

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

archerIsAwake :: Boolean
archerIsAwake = false

prisonerIsAwake :: Boolean
prisonerIsAwake = true

petDogIsPresent :: Boolean
petDogIsPresent = true

canFreePrisoner knightIsAwake archerIsAwake prisonerIsAwake petDogIsPresent
-- => false
```
