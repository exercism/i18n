# مقدمة

يضمّ النوع المنطقي في Lua القيمتين المنطقيتين التقليديتين: `true` و`false`. يمكن إسناد هذه القيم إلى متغير، ودمجها مع العوامل المنطقية (`and` و`or` و`not`)، واستخدامها في اختبارات شرطية (مثل بنى التحكم).

```lua
local is_true = true
local is_false = false

true and true  --> true
true and false --> false
false or true  --> true
false or false --> false
not false      --> true
not true       --> false

-- prints 0
if is_true == true then
  print(0)
else
  print(1)
end
```

تعتبر الاختبارات الشرطية والعوامل المنطقية كلا من قيمة `false` المنطقية و`nil` خطأ، وأي شيء آخر صحيح.
```lua
1 and 2          --> 2
nil and 2        --> nil
false and 2      --> false
1 or 2           --> 1
false or 'hello' --> "hello"
nil or false     --> false
```

يستخدم كل من `and` و`or` *التقييم القصير*، أي أنهما لا يقيّمان طرفهما الثاني إلا عند الضرورة. وتُقيَّم جميع العمليات وفقًا لـ[أسبقية العوامل](https://www.lua.org/manual/5.4/manual.html#3.4.8)، حيث يُقيَّم `not` قبل `and` و`or`.
