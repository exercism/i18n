# تعليمات

أنت تدير متجر بيتزا، وتقدّم ثلاثة أنواع من البيتزا:

- Margherita: $7
- Caprese: $9
- Formaggio: $10

إذا أراد العملاء، يمكنهم إضافة عدد غير محدود من الخيارات الإضافية: إما `ExtraSauce` مقابل $1 أو `ExtraToppings` مقابل $2.

مهمتك هي كتابة كود يساعد العميل في معرفة التكلفة التي سيدفعها.

## حساب سعر البيتزا

عند تمرير اسم البيتزا كأول وسيط، مع عدد غير محدود من الخيارات المضافة، احسب سعر البيتزا بالدولارات.

```js
pizzaPrice('Margherita');
// => 7

pizzaPrice('Caprese', 'ExtraSauce', 'ExtraToppings');
// => 12

pizzaPrice(
  'Caprese',
  'ExtraToppings',
  'ExtraToppings',
  'ExtraToppings',
  'ExtraToppings',
);
// => 17
```

## حساب السعر الإجمالي للطلب

تُستدعى دالتك بقائمة من كائنات `PizzaOrder`، ويجب أن تُرجع السعر الإجمالي للطلب بالدولارات.
كل `PizzaOrder` له خاصية `pizza` وهي اسم البيتزا، وخاصية `extras` وهي قائمة الخيارات الإضافية.

```js
const margherita = new PizzaOrder('Margherita');
const caprese = new PizzaOrder('Caprese', 'ExtraToppings');
orderPrice([margherita, caprese]);
// => 18
```

ستدرك أنك لا تستطيع كتابة هذه الدالة باستخدام الاستدعاء الذاتي، لأن اختبارًا واحدًا بعدد هائل من الطلبات سيرفع الخطأ `Maximum call stack size exceeded`.
لا تقلق، هذا مقصود. جرّب تنفيذ هذه الدالة باستخدام حلقة أمرية!
لديك خيارات كثيرة، منها على سبيل المثال لا الحصر استخدام `reduce` أو حلقة `for`.

عندما يشغّل مفسّر JavaScript كود JavaScript، فإنه يتتبّع الدوال التي دخلها (التي بدأ استدعاءها) في بنية بيانات تُسمى "المكدّس".
وعندما تُرجع الدالة (تنتهي)، تُزال من المكدّس.

لكن حجم هذا المكدّس محدود.
الخطأ الأكثر شيوعًا هو دالة تكرّر استدعاء نفسها ولا تنتهي أبدًا.
يُوضع كل استدعاء على المكدّس، وقبل أن يُرجع، يُوضع استدعاء آخر على المكدّس.

```javascript
function kaboom() {
  kaboom()
}

kaboom()
// => RangeError: Maximum call stack size exceeded
```

يُظهر تتبّع المكدّس لهذا الخطأ السطر نفسه مرارًا وتكرارًا، وهذا منطقي لأن الدالة تستدعي نفسها.
ورغم أنه لا فائدة عملية حقيقية له في معظم الحالات، يمكنك معرفة إلى أي ارتفاع يمكن أن يصل ذلك المكدّس.

```javascript
let calls = 0;
function kaboom() {
  calls +=1 ;
  kaboom()
}

kaboom()
// => RangeError: Maximum call stack size exceeded

console.log(calls)
// => a number, generally higher than 10.000
```

لا يوجد سوى حلّين عمليين لخطأ المكدّس الناتج عن دالة تكرّر استدعاء نفسها بشكل متزامن:
- تأكّد من أن الدوال تُرجع قبل الوصول إلى حد المكدّس، عادةً بإضافة حالة أساسية أو إصلاحها.
- أعد كتابة الدالة التكرارية على شكل حلقة أمرية، تنفّذ جسم الحلقة دون الحاجة إلى الدخول في دالة، وبالتالي دون زيادة المكدّس.
