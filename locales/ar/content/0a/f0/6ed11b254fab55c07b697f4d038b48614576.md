# مقدمة

## المقارنة

### المساواة

يمكن فحص أنواع Elm للتحقق من كونها «متطابقة» باستخدام عامل المساواة `(==)`.
وعامل عدم المساواة هو `(/=)` (*وليس* `!=` كما هو الحال في لغات كثيرة).
يعمل عامل المساواة على القيم الحرفية والصفوف والسجلات والأنواع المخصصة.

```elm
1 == 2
    --> False

1 /= 2
    --> True

(1, 2) == (2, 1)
    --> False

type alias MyRecord = { myInt : Int, myStrings : List String }
a : MyRecord
a = MyRecord (1 + 1) ["hello world"]

type alias MyOtherRecord = { myInt : Int, myStrings : List String }
myStrings =  (String.join " " ["hello", "world"]) :: []
b : MyOtherRecord
b = { myInt = 2, myStrings = myStrings}

a == b
    --> True
```

لاحظ أنه *يجب ألا* تقارن الدوال أبدًا، لأن ذلك سيتسبب في تعطّل البرنامج وقت التشغيل.

### المقارنات

تعمل عوامل المقارنة `(<)` و`(<=)` و`(>)` و`(>=)` والدوال `min` و`max` و`compare` على الأنواع `comparable`.
النوع `comparable` نوع خاص يجمع جميع الأنواع المدمجة التي يمكن مقارنتها: الأعداد والمحارف والسلاسل النصية والمصفوفات المكوّنة من عناصر قابلة للمقارنة والصفوف المكوّنة من عناصر قابلة للمقارنة.

```elm
1 < 1 + 1
    --> True

'x' < 'X'
    --> False

"abc" < "abz"
    --> True

"abc" < "abcd"
    --> True

"abc" < "b"
    --> True

min [1 , 2, 9000] [10]
    --> [1 , 2, 9000]

min (1, "hello") (3, "bye")
    --> (1, "hello")
```

لا يمكن مقارنة قيم الأنواع الأخرى، مثل السجلات أو الأنواع المخصصة، مباشرةً.

تشترط بعض الأنواع المدمجة أن يكون محتواها من النوع `comparable`، مثل مفاتيح `Set` أو `Dict`، لأن بنيتها تعتمد على ترتيب داخلي.

يمكن ترتيب مصفوفات القيم من النوع `comparable` باستخدام `List.sort`، ويمكن ترتيب مصفوفات القيم التي يمكن تحويلها إلى قيم قابلة للمقارنة باستخدام `List.sortBy`.
إذا احتجت ترتيبًا هرميًا (الترتيب حسب خاصية، وكسر التعادل بأخرى)، فيمكن أيضًا استخدام الصفوف أو المصفوفات مع `List.sortBy`، لأن الصفوف والمصفوفات تُرتَّب بترتيب معجمي.


```elm
List.sort ["hi", "hello", "bye", "goodbye"]
    --> ["bye", "goodbye", "hello", "hi"]

List.sortBy String.length ["hi", "hello", "bye", "goodbye"]
    --> ["hi", "bye", "hello", "goodbye"]

-- sort by length, then alphabetically
List.sortBy (\str -> (String.length str, str)) ["hi", "mum", "hello", "sis", "bye", "dad"]
    --> ["hi", "bye", "dad", "mum", "sis", "hello"]
```

تأخذ الدالة `compare` قيمتين من النوع `comparable` وتُرجع `Order`.
`Order` نوع يفحص في عملية واحدة ما إذا كانت قيمة أكبر (`GT`) أو مساوية (`EQ`) أو أصغر (`LT`) من قيمة أخرى.

```elm
compare 1 2
    --> LT

compare "" ""
    --> EQ

compare [12] []
    --> GT
```

يمكن إنشاء دوال مقارنة لأنواع اعتباطية واستخدامها، على سبيل المثال، لترتيبها باستخدام `List.sortWith`:

```elm
type Color = Red | Green | Blue

compareColors : Color -> Color -> Order
compareColors a b =
  case (a, b) of
    (Red, Red) -> EQ
    (Red, _) -> LT
    (_, Red) -> GT
    (Green, Green) -> EQ
    (Green, _) -> LT
    (_, Green) -> GT
    (Blue, Blue) -> EQ

List.sortWith compareColors [Blue, Red, Green, Green, Blue]
    --> [Red, Green, Green, Blue, Blue]
```
