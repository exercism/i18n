# ترتيب التعليقات التوضيحية للدالة

من المتعارف عليه أن تأتي التعليقات التوضيحية `@doc` قبل التعليقات التوضيحية `@spec`، وأن تأتي التعليقات التوضيحية `@spec` مباشرةً قبل الدالة. وإذا كانت للدالة عدة بنود، فينبغي أن تأتي التعليقات التوضيحية قبل البند الأول.

مثال:

```elixir
@doc """
This function counts the number elements in a list
"""
@spec count(list(any())) :: integer()
def count([]), do: 0
def count([h | t]), do: 1 + count(t)
```
