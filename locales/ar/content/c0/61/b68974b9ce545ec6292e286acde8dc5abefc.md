# مقدمة

كل نسخة من بنية أو صنف لديها خاصية ضمنية تُسمى `self`، تشير إلى النسخة نفسها.
الاستخدام الأكثر شيوعًا لـ `self` هو التمييز بين خاصية النسخة ومعامل يحمل الاسم نفسه:

```swift
struct Position {
    var x = 0

    mutating func move(x: Int) {
        // Here, 'self.x' refers to the struct's property,
        // while 'x' refers to the parameter passed to the method.
        self.x = x
    }
}
```

توفر أنواع Swift أيضًا كلمة مفتاحية `Self` تبدأ بحرف كبير، وهي تشير إلى *نوع* النسخة لا إلى النسخة نفسها.
