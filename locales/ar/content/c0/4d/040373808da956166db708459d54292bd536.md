# مقدمة

إلى جانب جملة `if` الشرطية، هناك أيضًا جملة `switch` لتنفيذ منطق معيّن بشكل شرطي. تُستخدم هذه الجملة عندما نحتاج إلى مقارنة متغير واحد بعدّة بدائل مختلفة. بالنسبة إلى متغير ما `x`، تأخذ جملة `switch` في Haxe الصيغة التالية.

```haxe
var a = 2;

switch (a) {
  case 0:
    trace("a is 0");
  case 1:
    trace("a is 1");
  case 2:
    trace("a is 2");
  default:
    trace("a is something else");
}

// a is 2
```

تُنفَّذ حالة `default` عندما لا تتطابق أي حالة أخرى.
