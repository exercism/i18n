# مقدمة

الملف مجرد تيار له اسم على القرص. تمنحك مفردات [`io.files`][io.files] أسلوبين للتعامل معه: كلمات جاهزة تتعامل مع الملف بأكمله، فتقرأ أو تكتب كل شيء في استدعاء واحد، وأدوات لفتح التيار عندما تريد القراءة أو الكتابة تدريجيًا.

كل كلمة تتعامل مع ملف تأخذ **ترميزًا**، وهو المخطط الذي يحوّل البايتات إلى محارف والعكس. وبالنسبة للنصوص، فهو دائمًا تقريبًا [`utf8`][utf8] من `io.encodings.utf8`.

## قراءة ملف كامل

```
file-contents   ( path encoding -- str )
file-lines      ( path encoding -- seq )
```

تُرجع `file-contents` الملف بأكمله كسلسلة نصية واحدة، بينما تُرجع `file-lines` مصفوفة من أسطره، مع إزالة فواصل الأسطر.

```factor
USING: io.encodings.utf8 io.files prettyprint ;

"sunny\ncloudy\n" "forecast.txt" utf8 set-file-contents

"forecast.txt" utf8 file-contents .
! => "sunny\ncloudy\n"

"forecast.txt" utf8 file-lines .
! => { "sunny" "cloudy" }
```

## كتابة ملف كامل

```
set-file-contents   ( str path encoding -- )
set-file-lines      ( seq path encoding -- )
```

كلاهما **يستبدل** محتوى الملف (وينشئه عند الحاجة). تكتب `set-file-contents` السلسلة النصية كما هي، بينما تكتب `set-file-lines` كل عنصر من عناصر متتالية في سطر خاص به، وتضيف فواصل الأسطر نيابة عنك.

```factor
USING: io.encodings.utf8 io.files prettyprint ;

{ "sunny" "cloudy" } "forecast.txt" utf8 set-file-lines
"forecast.txt" utf8 file-contents .
! => "sunny\ncloudy\n"
```

## الإضافة إلى ملف

لإضافة شيء إلى ملف دون محو ما هو موجود فيه بالفعل، افتحه باستخدام مُركِّب `with-…` واكتب إلى التيار المحيط داخل الاقتباس:

```
with-file-appender   ( path encoding quot -- )
with-file-reader     ( path encoding quot -- )
with-file-writer     ( path encoding quot -- )
```

```factor
USING: io io.encodings.utf8 io.files prettyprint ;

"sunny\ncloudy\n" "forecast.txt" utf8 set-file-contents
"forecast.txt" utf8 [ "rainy" print ] with-file-appender
"forecast.txt" utf8 file-contents .
! => "sunny\ncloudy\nrainy\n"
```

مثل كل مُركِّب `with-…`، هذه نطاقات مُدمِّرة: يُغلق مقبض الملف عند انتهاء الاقتباس، حتى إن طرح استثناءً.
