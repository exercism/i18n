# الجمل الشرطية

في Python، تُستخدم عبارات `if`[^] و`elif` (_وهي اختصار لعبارة 'else and if'_) و`else` من أجل [التحكم في مسار التنفيذ][control flow tools] واتخاذ القرارات داخل البرنامج.
وعلى خلاف كثير من لغات البرمجة الأخرى، لا تقدّم إصدارات Python 3.9 وما دونها عبارة case-switch رسمية، بل تستخدم عدة عبارات `elif` لتحقيق غرض مشابه.

وتقدّم Python 3.10 صيغة مختلفة من عبارة case-switch تُسمى `structural pattern matching`، وسنتناولها على حدة في مفهوم آخر.

تستخدم الجمل الشرطية تعبيرات يجب أن تُقيَّم إلى `True` أو `False`، إما بإرجاع قيمة من النوع `bool` مباشرةً، أو بالتقييم باعتبارها ["truthy" أو "falsy"][truth value testing].

```python
x = 10
y = 5

# The comparison '>' returns the bool 'True',
# so the statement is printed.
if x > y:
    print("x is greater than y")
...
>>> x is greater than y
```

عند اقترانها بـ `if`، تُنفَّذ كتلة الكود الاختيارية `else` عندما تُقيَّم حالة `if` الأصلية إلى `False`:

```python
x = 5
y = 10

# The comparison '>' here returns the bool 'False',
# so the 'else' block is executed instead of the 'if' block.
if x > y:
    print("x is greater than y")
else:
    print("y is greater than x")
...
>>> y is greater than x
```

تتيح `elif` عمليات تقييم/تفرّعات متعددة.

```python
x = 5
y = 10
z = 20

# The 'elif' statement allows for the checking of more conditions.
if x > y:
    print("x is greater than y and z")
elif y > z:
    print("y is greater than x and z")
else:
    print("z is greater than x and y")
...
>>> z is greater than x and y
```

يمكن دمج [العمليات المنطقية][boolean operations] و[المقارنات][comparisons] مع الجمل الشرطية لاختبارات أكثر تعقيدًا:

```python
>>> def classic_fizzbuzz(number):
        if number % 3 == 0 and number % 5 == 0:
            say = 'FizzBuzz!'
        elif number % 5 == 0:
            say = 'Buzz!'
        elif number % 3 == 0:
            say = 'Fizz!'
        else:
            say = str(number)
        
        return say

>>> classic_fizzbuzz(15)
'FizzBuzz!'

>>> classic_fizzbuzz(13)
'13'
```
