# الاختبارات

## Clojure CLI

تأتي تمارين Clojure على Exercism مع ملف `deps.edn` يحتوي على اسم مستعار `:test` لاستدعاء [cognitect-labs test-runner](https://github.com/cognitect-labs/test-runner):

``` bash
$ clj -X:test
```

سيبحث هذا الأمر في مجلد `test` داخل مشروعك عن أي اختبارات معرّفة باستخدام `clojure.test` ثم يشغّلها.

## Leiningen

لتشغيل اختبارات تمرين ما باستخدام Leiningen، ما عليك سوى تنفيذ الأمر التالي:

``` bash
$ lein test

lein test bob-test

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
```
