# التعليمات

يتواصل العمل على مشروع سيارة التحكم عن بُعد. النطاق الترددي في نظام القياس عن بُعد شحيح، وقد طُلب منك تنفيذ بروتوكول رسائل لنقل بيانات القياس عن بُعد.

تُرسل البيانات في مخزن مؤقت (مصفوفة بايتات). وعند إرسال الأعداد الصحيحة، يُقلَّل حجم المخزن المؤقت بتطبيق البروتوكول الموصوف أدناه.

ينبغي تمثيل كل قيمة بأصغر نوع صحيح ممكن (لا يُدرج نوعا `byte` و`sbyte` لأن التوفير سيكون ضئيلًا):

| من                         | إلى                       | النوع    |
| -------------------------- | ------------------------- | -------- |
| 4_294_967_296              | 9_223_372_036_854_775_807 | `long`   |
| 2_147_483_648              | 4_294_967_295             | `uint`   |
| 65_536                     | 2_147_483_647             | `int`    |
| 0                          | 65_535                    | `ushort` |
| -32_768                    | -1                        | `short`  |
| -2_147_483_648             | -32_769                   | `int`    |
| -9_223_372_036_854_775_808 | -2_147_483_649            | `long`   |

ينبغي تحويل القيمة إلى العدد المناسب من البايتات لنوعها المخصص. ويتكوّن المخزن المؤقت الكامل من بايت يشير إلى عدد البايتات الإضافية في المخزن المؤقت (_بايت البادئة_) تليه البايتات التي تحمل العدد الصحيح (_بايتات الحمولة_).

تستخدم بعض الأنواع العدد نفسه من البايتات (مثل نوعي `uint` و`int`). وفي المعتاد سيكون لها _بايت البادئة_ نفسه، لكن ذلك سيجعل فك الترميز إشكاليًا. ولتجاوز ذلك، يقدّم البروتوكول حيلة صغيرة: بالنسبة إلى الأنواع المُوقّعة، تكون قيمة _بايت البادئة_ لديها `256` ناقص عدد البايتات الإضافية في المخزن المؤقت.

لن يُرسل في الاتصال إلا بايت البادئة وعدد البايتات التالية التي تشير إليها البادئة. وداخليًا يُستخدم مخزن مؤقت من 9 بايتات (مع أصفار لاحقة عند الحاجة) في إجرائي الإرسال والاستقبال معًا.

## 1. ترميز قيمة صحيحة جاهزة للإرسال

يرجى تنفيذ الطريقة الساكنة `TelemetryBuffer.ToBuffer()` لترميز مخزن مؤقت، وهي تأخذ المعامل الممرَّر إلى الطريقة.

```csharp
// Type: ushort, bytes: 2, signed: no, prefix byte: 2
TelemetryBuffer.ToBuffer(5)
// => {0x2, 0x5, 0x0, 0x0, 0x0, 0x0, 0x0, 0x0, 0x0 };

// Type: int, bytes: 4, signed: yes, prefix byte: 256 - 4
TelemetryBuffer.ToBuffer(Int32.MaxValue)
// => {0xfc, 0xff, 0xff, 0xff, 0x7f, 0x0, 0x0, 0x0, 0x0 };
```

## 2. فك ترميز مخزن مؤقت مستلَم

يرجى تنفيذ الطريقة الساكنة `TelemetryBuffer.FromBuffer()` لفك ترميز المخزن المؤقت المستلَم وإرجاع القيمة على هيئة `long`.

```csharp
TelemetryBuffer.FromBuffer(new byte[] {0xfc, 0xff, 0xff, 0xff, 0x7f, 0x0, 0x0, 0x0, 0x0 })
// => 2147483647
```

إذا كانت قيمة بايت البادئة غير متوقعة، فينبغي إرجاع `0`.
