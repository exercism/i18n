# التعليمات

بصفتها ساحرةً ناشئة، تحتاج إيليز إلى ممارسة بعض الأساسيات. لديها رزمة بطاقات تريد التعامل معها.

ولتسهيل الأمور قليلًا، تستخدم البطاقات من 1 إلى 10 فقط.

## 1. استرجاع بطاقة من الرزمة

نفّذ الدالة `getCard` التي تُرجع البطاقة الموجودة عند الموضع `index` من الرزمة المعطاة. وإذا لم يكن الفهرس موجودًا في الرزمة، فأرجع Nothing.

```elm
getCard 2 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Just 4
getCard 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Nothing
```

## 2. تغيير بطاقة في الرزمة

نفّذ الدالة `setCard` التي تُرجع رزمة تغيّرت فيها البطاقة عند الموضع `index` إلى البطاقة الجديدة المعطاة.
وإذا لم يكن `index` موجودًا في الرزمة، فأرجع الرزمة الأصلية.

```elm
setCard 2 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Array.fromList [ 1, 2, 6, 1 ]
setCard 6 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Array.fromList [ 1, 2, 4, 1 ]
```

## 3. إضافة بطاقة إلى الرزمة

نفّذ الدالة `addCard` التي تُرجع رزمة أُضيفت إليها البطاقة الجديدة.

```elm
addCard 8 ( Array.fromList [ 5, 9, 7, 1 ] )
    --> Array.fromList [ 5, 9, 7, 1, 8 ]
```

## 4. إزالة بطاقة من الرزمة

نفّذ الدالة `removeCard` التي تُرجع رزمة أُزيلت منها البطاقة عند الموضع `index`.
وإذا لم يكن `index` المعطى فهرسًا صالحًا في الرزمة، فأرجع الرزمة الأصلية.

```elm
removeCard 2 ( Array.fromList [ 3, 2, 6, 4, 8 ] )
    --> Array.fromList [ 3, 2, 4, 8 ]
removeCard 2 ( Array.fromList [ 3, 2 ] )
    --> Array.fromList [ 3, 2 ]
```

## 5. عدّ عدد البطاقات ذات الأعداد الزوجية في الرزمة

نفّذ الدالة `evenCardCount` التي تعدّ عدد البطاقات ذات الأعداد الزوجية في الرزمة.

```elm
evenCardCount (Array.fromList [ 3, 8, 4, 5, 1, 6, 10 ] )
    --> 4
```
