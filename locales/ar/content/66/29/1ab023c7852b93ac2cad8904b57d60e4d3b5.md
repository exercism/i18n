# نبذة

تقدّم أصناف `java.time` الأساسية مثل `LocalDate` و`LocalDateTime` طرقًا أساسية لإضافة وحدات زمنية أو طرحها، لكن تعديلات التواريخ الأكثر تعقيدًا تحتاج غالبًا إلى منطق أكثر تطورًا (مثل إيجاد "يوم الثلاثاء الثاني من الشهر" أو "آخر يوم في السنة").

وتوفّر حزمة `java.time.temporal` الواجهة الوظيفية [`TemporalAdjuster`][temporaladjuster-docs] لهذا الغرض.
وهي تمثّل استراتيجية لتعديل كائن زمني (مثل `LocalDate`).
ويحتوي صنف الأدوات [`TemporalAdjusters`][temporaladjusters-docs] (لاحظ حرف الجمع 's') على طرق مصنع ثابتة تقدّم كثيرًا من تطبيقات المُعدِّل الشائعة المعرّفة مسبقًا.

## استخدام `TemporalAdjusters`

تملك الكائنات الزمنية مثل `LocalDate` و`LocalDateTime` طريقة `with()` تقبل مُعدِّلًا من نوع `TemporalAdjuster`.
وتُرجع هذه الطريقة كائنًا زمنيًا *جديدًا* مطبَّقًا عليه التعديل.

```exercism/note
إن استخدام `with(TemporalAdjuster)` يُرجع نسخة _جديدة_ ولا يحدّث النسخة الموجودة، لأن جميع أصناف `java.time` الزمنية غير قابلة للتغيير.
```

```java
import java.time.LocalDate;
import java.time.Month;
import java.time.DayOfWeek;
import java.time.temporal.TemporalAdjusters;

LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15 (a Thursday)

// Use a predefined adjuster from TemporalAdjusters
LocalDate firstDayOfNextMonth = date.with(TemporalAdjusters.firstDayOfNextMonth());
// => 2024-09-01

LocalDate nextSunday = date.with(TemporalAdjusters.next(DayOfWeek.SUNDAY));
// => 2024-08-18
```

## المُعدِّلات الشائعة المعرّفة مسبقًا

يوفّر صنف `TemporalAdjusters` طرقًا ثابتة كثيرة ومفيدة.
وفيما يلي بعض الأمثلة الشائعة:

### إيجاد يوم الأسبوع الترتيبي

يحدّد المُعدِّل `dayOfWeekInMonth(int ordinal, DayOfWeek dayOfWeek)` الموضع رقم n ليوم معيّن من أيام الأسبوع داخل الشهر.

```java
LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15

// Find the second Tuesday of August 2024
LocalDate secondTuesday = date.with(TemporalAdjusters.dayOfWeekInMonth(2, DayOfWeek.TUESDAY));
// => 2024-08-13

// Find the fourth Friday of August 2024
LocalDate fourthFriday = date.with(TemporalAdjusters.dayOfWeekInMonth(4, DayOfWeek.FRIDAY));
// => 2024-08-23
```

### إيجاد أول يوم أو آخر يوم من الأسبوع في الشهر

يحدّد المُعدِّلان `firstInMonth(DayOfWeek dayOfWeek)` و`lastInMonth(DayOfWeek dayOfWeek)` أول حدوث أو آخر حدوث ليوم معيّن من أيام الأسبوع داخل الشهر.

```java
LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15

// Find the first Sunday of August 2024
LocalDate firstSunday = date.with(TemporalAdjusters.firstInMonth(DayOfWeek.SUNDAY));
// => 2024-08-04

// Find the last Monday of August 2024
LocalDate lastMonday = date.with(TemporalAdjusters.lastInMonth(DayOfWeek.MONDAY));
// => 2024-08-26
```

### إيجاد أول يوم أو آخر يوم من الشهر أو السنة

هناك مُعدِّلات أبسط تجد أول يوم أو آخر يوم في الشهر الحالي أو السنة الحالية.

```java
LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15

LocalDate firstDay = date.with(TemporalAdjusters.firstDayOfMonth());
// => 2024-08-01

LocalDate lastDay = date.with(TemporalAdjusters.lastDayOfMonth());
// => 2024-08-31

LocalDate lastDayOfYear = date.with(TemporalAdjusters.lastDayOfYear());
// => 2024-12-31
```

### تعديلات نسبية (التالي/السابق)

تبحث مُعدِّلات مثل `next()` و`previous()` و`nextOrSame()` و`previousOrSame()` عن الحدوث التالي أو السابق ليوم معيّن من أيام الأسبوع، بالنسبة إلى التاريخ الحالي.

- `next()`/`previous()`: يستبعد التاريخ الحالي إذا كان يطابق اليوم المطلوب.
- `nextOrSame()`/`previousOrSame()`: يتضمّن التاريخ الحالي إذا كان يطابق اليوم المطلوب.

```java
LocalDate thursday = LocalDate.of(2024, Month.AUGUST, 15); // A Thursday

// Find the next Sunday (exclusive)
LocalDate nextSunday = thursday.with(TemporalAdjusters.next(DayOfWeek.SUNDAY));
// => 2024-08-18

// Find the next Thursday (exclusive)
LocalDate nextThursday = thursday.with(TemporalAdjusters.next(DayOfWeek.THURSDAY));
// => 2024-08-22

// Find the next Thursday (inclusive) - returns the same date
LocalDate nextOrSameThursday = thursday.with(TemporalAdjusters.nextOrSame(DayOfWeek.THURSDAY));
// => 2024-08-15

// Find the previous Monday (exclusive)
LocalDate previousMonday = thursday.with(TemporalAdjusters.previous(DayOfWeek.MONDAY));
// => 2024-08-12
```

## مُعدِّلات مخصصة

بما أن `TemporalAdjuster` واجهة [`@FunctionalInterface`][functionalinterface-docs]، يمكنك إنشاء مُعدِّلاتك المخصصة باستخدام تعبيرات لامدا للمنطق الذي لا تغطيه الطرق المعرّفة مسبقًا.
وتتطلب الواجهة تنفيذ طريقة واحدة: `Temporal adjustInto(Temporal temporal)`.

```java
// Example: An adjuster that finds the next workday (Mon-Fri), skipping weekends.
TemporalAdjuster nextWorkday = temporal -> {
    LocalDate result = (LocalDate) temporal; // Assuming input is LocalDate
    do {
        result = result.plusDays(1);
    } while (result.getDayOfWeek() == DayOfWeek.SATURDAY || result.getDayOfWeek() == DayOfWeek.SUNDAY);
    return result;
};

LocalDate friday = LocalDate.of(2024, Month.AUGUST, 16);
LocalDate nextWorkdayDate = friday.with(nextWorkday);
// => 2024-08-19 (Monday)

LocalDate sunday = LocalDate.of(2024, Month.AUGUST, 18);
LocalDate nextWorkdayFromSunday = sunday.with(nextWorkday);
// => 2024-08-19 (Monday)
```

مع أن المُعدِّلات المخصصة قوية، فإن المُعدِّلات المعرّفة مسبقًا في صنف `TemporalAdjusters` تغطي طائفة واسعة من حالات الاستخدام الشائعة.
