# التعليمات

بصفتها ساحرةً ناشئة، تحتاج Elyse إلى التدريب على بعض الأساسيات. لديها كومة من البطاقات تريد التلاعب بها.

ولتسهيل الأمور قليلًا، تستخدم البطاقات من 1 إلى 10 فقط، لذا يمكن تمثيل كومة بطاقاتها بمتجه من الأعداد. ويقابل موضع بطاقة معيّنة الفهرسَ في المتجه.

## 1. استرجاع بطاقة من الكومة

لاختيار بطاقة، أرجِع البطاقة عند الفهرس `position` من الكومة المعطاة.

```R
stack <- c(1, 2, 4, 1)
position <- 3
get_item(stack, position)
# => 4
```

## 2. استبدال بطاقة في الكومة

قم ببعض خفة اليد واستبدل البطاقة عند الفهرس `position` بالبطاقة البديلة المعطاة.
أرجِع الكومة المعدّلة.

```R
stack <- c(1, 2, 4, 1)
position <- 3
replacement_card <- 6
set_item(stack, position, replacement_card)
# => c(1, 2, 6, 1)
```

## 3. إدراج بطاقة في أعلى الكومة

اجعل بطاقة تظهر بإدراج بطاقة جديدة في أعلى الكومة.
أرجِع الكومة المعدّلة.

```R
stack <- c(5, 9, 7, 1)
new_card <- 8
insert_item_at_top(stack, new_card)
# => c(5, 9, 7, 1, 8)
```

## 4. إزالة بطاقة من الكومة

اجعل بطاقة تختفي بإزالة البطاقة عند `position` المعطى من الكومة.
أرجِع الكومة المعدّلة.

```R
stack <- c(3, 2, 6, 4, 8)
position <- 3
remove_item(stack, position)
# => c(3, 2, 4, 8)
```

## 5. التحقق من حجم الكومة

تحقّق مما إذا كان حجم الكومة يساوي `stack_size` أم لا.

```R
stack <- c(3, 2, 6, 4, 8)
stack_size <- 4
check_size_of_stack(stack, stack_size)
# => FALSE
```

## 6. إزالة البطاقة العليا من الكومة

اجعل بطاقة تختفي بإزالة البطاقة التي في أعلى الكومة.
أرجِع الكومة المعدّلة.

```R
stack <- c(3, 2, 6, 4, 8)
remove_item_from_top(stack)
# => c(3, 2, 6, 4)
```

## 7. إدراج بطاقة في أسفل الكومة

اجعل بطاقة تظهر بإدراج بطاقة جديدة في أسفل الكومة.
أرجِع الكومة المعدّلة.

```R
stack <- c(5, 9, 7, 1)
new_card <- 8
insert_item_at_bottom(stack, new_card)
# => c(8, 5, 9, 7, 1)
```

## 8. إزالة بطاقة من أسفل الكومة

اجعل بطاقة تختفي بإزالة البطاقة التي في أسفل الكومة.
أرجِع الكومة المعدّلة.

```R
stack <- c(8, 5, 9, 7, 1)
remove_item_at_bottom(stack)
# => c(5, 9, 7, 1)
```
