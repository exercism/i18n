# مقدمة

في كل مرة تُستدعى فيها دالة، يُنشأ إطار مكدس جديد في الذاكرة لتخزين وسائط الدالة ومتغيراتها المحلية، ويُحرَّر هذا الإطار عند إرجاع الدالة. ولأن Gleam تستخدم استدعاءات دوال عودية بدلًا من صيغة الحلقات، فقد يستهلك ذلك قدرًا كبيرًا من الذاكرة في هذه الإطارات.

لتفادي هذه المشكلة تدعم Gleam تحسين استدعاء الذيل، الذي يسمح للمترجم بإعادة استخدام إطار المكدس الخاص بالدالة الحالية إذا كان استدعاء الدالة هو آخر ما تفعله الدالة. وهذا يعني أن الدالة يمكنها أن تستدعي نفسها عددًا لا نهائيًا من المرات دون استخدام أي ذاكرة إضافية.

يمكن غالبًا إعادة كتابة الدوال العودية غير المحسَّنة على هيئة دوال محسَّنة باستدعاء الذيل، وذلك باستخدام _مُجمِّع_.

المُجمِّع متغير يُمرَّر إلى جانب البيانات. ويُستخدم لتمرير الحالة الراهنة لتنفيذ الدالة، إلى أن نصل إلى الحالة الأساسية.

ينبغي أن يقوم مؤلف الدالة بتهيئة المُجمِّعات، لا مستخدم الدالة. ولتحقيق ذلك، عرِّف دالتين: دالة عامة تأخذ البيانات الضرورية فقط كوسائط وتهيّئ المُجمِّع، ودالة خاصة تأخذ المُجمِّع أيضًا.

```gleam
// Count the length of a list without tail call optimisation
pub fn count(list: List(String)) -> Int {
  case list {
    [] -> 0
    [_, ..rest] -> {
      let amount = count(rest) // Non-tail recursive call
      amount + 1
    }
  }
}
```

```gleam
// Count the length of a list with tail call optimisation
pub fn count(list: List(String)) -> Int {
  count_elements(list, 0)
}

fn count_elements(list: List(String), accumulator: Int) -> Int {
  case list {
    [] -> accumulator
    [_, ..rest] -> {
      let accumulator = accumulator + 1
      count_elements(rest, accumulator) // Tail recursive call
    }
  }
}
```
