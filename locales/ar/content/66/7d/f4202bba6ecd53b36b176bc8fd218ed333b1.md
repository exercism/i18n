# التعليمات

أنت تدير لوحة النتائج في مباراة كرة شبكة. وخلافًا لكل ما سبق، على لوحة النتائج أن تتذكر ما حدث.

يحتاج صنف `SCOREBOARD` إلى ما يلي. يمنحك الهيكل المبدئي الصنف وإعلانَي السمتين؛ أضف الباقي.

## 1. تهيئة لوحة النتائج

تستقبل `create` اسم الفريق المضيف واسم الفريق الضيف، وتُرجع لوحة نتائج نتيجتا الفريقين فيها صفر.

```sather
board ::= #SCOREBOARD("Vixens", "Magpies");
board.home_score
-- => 0
```

## 2. تسجيل هدف

تضيف `home_goal` واحدًا إلى نتيجة الفريق المضيف، وتضيف `away_goal` واحدًا إلى نتيجة الفريق الضيف. وكلتاهما لا تُرجعان أي شيء.

```sather
board.home_goal;
board.home_score
-- => 1
```

## 3. قراءة لوحة النتائج

تُرجع `summary` اللوحة كما ستُكتب في السجل: اسم الفريق المضيف، ونتيجته، وشرطة، ونتيجة الفريق الضيف، ثم اسم الفريق الضيف.

```sather
board.summary
-- => "Vixens 1 - 0 Magpies"
```

المسافات كما هي معروضة تمامًا، والشرطة هي `-` وحدها.

## 4. مَن المتقدم؟

تُرجع `leader` اسم الفريق المتقدم، أو `"Draw"` عندما تتعادل النتيجتان.

```sather
board.leader
-- => "Vixens"
```

## 5. بكم يتقدم؟

تُرجع `margin` عدد الأهداف التي تفصل بين الفريقين. وهي ليست سالبة أبدًا، أيًّا كان المتقدم.

```sather
board.margin
-- => 1
```
