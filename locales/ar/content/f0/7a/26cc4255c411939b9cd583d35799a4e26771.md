# الإرجاع

في Crystal، تُرجع الطريقة قيمة آخر تعبير فيها.
لكنك تحتاج أحيانًا إلى إرجاع قيمة قبل آخر تعبير.
لهذا، يمكنك استخدام الكلمة المفتاحية `return`، والتي ستُرجع قيمة التعبير التالي.
الكود المكتوب بعد الكلمة المفتاحية `return` لن يُنفَّذ.

```crystal
def speed_limit(road_number)
    if road_number == 1
        return 50
        puts "This will not be executed"
    elsif road_number == 2
        return 80
        puts "This will not be executed"
    end
    100
end

p speed_limit(1) # => 50
p speed_limit(2) # => 80
p speed_limit(3) # => 100
```

~~~~exercism/note
يجب حذف الكلمة المفتاحية `return` عندما يكون آخر تعبير في الطريقة هو القيمة التي ينبغي إرجاعها.
~~~~
