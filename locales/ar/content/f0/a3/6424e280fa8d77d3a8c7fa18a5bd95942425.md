# نبذة

## الأنواع الاختيارية

يستخدم Swift [_الأنواع الاختيارية_][optionals] ليتمكن المبرمجون من تمثيل احتمال غياب القيمة.
النوع الاختياري نوع يمكنه إما أن يحمل قيمة، وإما أن يكون [`nil`][nil] الذي يمثل غياب القيمة.
ويتطلب استخدام النوع الاختياري أن يتحقق البرنامج من وجود القيمة بعد فكّ تغليفها قبل استخدامها.

يمكن تحويل أي نوع إلى نوع اختياري بإضافة `?` إلى نهاية اسم النوع.
فيكون نوع العدد الصحيح الاختياري `Int?`، ويكون نوع السلسلة النصية الاختيارية `String?`.
وتعريف الثوابت أو المتغيرات من نوع اختياري وإسناد القيم إليها يتم بالكيفية نفسها التي تُتبع مع قيم الأنواع غير الاختيارية.

```swift
let x: Int? = 42
var y: String? = "Hello"
y = "Goodbye"
```

يمكنك إسناد غياب القيمة إلى متغير من نوع اختياري بأن تسند إليه القيمة الخاصة `nil`.
يمكن استخدام `nil` مع جميع الأنواع الاختيارية، لكن قيمتَا `nil` المُسندتان إلى نوعين اختياريين مختلفين ليستا من النوع نفسه، ولا يمكن تبادلهما ولا حتى مقارنتهما.

```swift
let intOpt: Int? = nil
let stringOpt: String? = nil

intOpt = stringOpt
// Compiler error: Cannot assign value of type 'String?' to type 'Int?'

intOpt == stringOpt
// Compiler error: Binary operator '==' cannot be applied to operands of type 'Int?' and 'String?'
```

لاحظ أيضًا أنه على الرغم من إمكان إسناد `nil` إلى أي نوع اختياري، فلا يمكن إسناده إلى نوع غير اختياري (حتى لو لم يكن يحمل `nil` فعلًا).
كما لا يمكن تمرير نوع اختياري إلى طريقة تتوقع نوعًا غير اختياري دون فكّ تغليفه أولًا.

```swift
var x: Int = 42
var y: Int? = 42

y = x
// Works fine
x = y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
x + y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
```

## استخدام الأنواع الاختيارية

لأن الأنواع الاختيارية ليست هي أنواعها الأساسية نفسها، فلا يمكن استخدام النوعين بالكيفية نفسها.
على سبيل المثال: يؤدي `Int("123") + 1` إلى خطأ من المترجم "Value of optional type 'Int?' must be unwrapped to a value of type 'Int'".
وذلك لأن `Int("123")` تُرجع نوعًا اختياريًا هو `Int?` لا نوع `Int`، لأنه إذا تعذّر تحويل السلسلة النصية إلى عدد صحيح، فستكون النتيجة `nil`.
وللوصول إلى `Int` من ناتج التحويل، عليك فكّ تغليفه أولًا.

ويُفعل هذا في Swift في الغالب باستخدام التركيبين `if-let` و`guard-let` الخاصين بـ _الربط الاختياري_، وهما يتحققان من `nil` ويسلكان مسارًا برمجيًا واحدًا تكون فيه القيمة المفكوكة مربوطة باسم معطى إذا وُجدت قيمة، ويسلكان مسارًا آخر إذا وُجد `nil`.

```swift
if let safeNum = Int("123") {
	let sum = safeNum + 1
	…
} else {
  // code for the case where nil was found -- may be left out
}
```

تجدر الإشارة إلى أن المتغير `safeNum` من النوع `Int` لا `Int?`.
وفي المثال أدناه، `num` من النوع `Int?` و`safeNum` من النوع `Int`.

```swift
let num = Int("123")
if let safeNum = num {
  // num is of type Int
}
```

هذا _الربط الاختياري_ مهم لأنه يفكّ تغليف القيمة ويزيل عنها النوع الاختياري، ما يسمح باستخدامها قيمةً غير اختيارية.
أما إذا اقتصرت على تحقق شرطي من كون القيمة `nil`، فستظل القيمة من نوع اختياري:

```swift
let num = Int("123")
if num != nil {
  // num is of type Int?
}
```

ويمكن أيضًا استخدام خيار `guard-let` في الحالات التي تريد فيها الخروج المبكر من الدالة:

```swift
guard let num = Int("123") else { return nil }
let sum = num + 1
…
```

## مقارنة الأنواع الاختيارية

لاحظ أنه حتى لو أمكن مقارنة النوع الأساسي لزوج من الأنواع الاختيارية باستخدام عوامل المقارنة القياسية، فلا يمكن مقارنة النوعين الاختياريين نفسيهما.
بل يمكن فقط التحقق من تساويهما.
ويكون النوعان الاختياريان متساويين إذا كان كلاهما `nil`، أو إذا كانت القيمتان اللتان يغلّفانهما متساويتين ضمن نوعيهما الأساسيين.

مع ذلك، يمكن كتابة كود لإجراء مقارنة مخصصة بين قيمتين اختياريتين.
وفيما يلي مثال على عبارة `switch` تُرجع `true` فقط إذا كانت قيمتَا الخيارين غير مساويتين لـ `nil` وكانت القيمة الأولى أصغر من الثانية.
ولتحقيق ذلك تستخدم _النمط الاختياري_ `varName?`، الذي لا يطابق إلا الأنواع الاختيارية التي ليست `nil`، فيربط القيمة داخل النوع الاختياري بالاسم `varName`.

```swift
switch (optionalA, optionalB) {
case let (valA?, valB?): return valA < valB
default: return false
}
```

## دمج nil

ثمة خيار آخر لفكّ التغليف، وهو إمكانية استخدام [قيمة احتياطية][fallback] عند وجود `nil`.
ويمكن فعل ذلك باستخدام _عامل دمج nil_، أي `??`.
بافتراض أن `x` من النوع `Int?`، إذا كتبت `let y = x ?? 0`، فسيتحقق Swift مما إذا كانت `x` تساوي `nil`.
فإن لم تكن كذلك، فسيفكّ تغليف `x` ويسند القيمة المفكوكة إلى `y`، وإن كانت `x` _تساوي_ `nil`، فسيسند 0 إلى `y`.

ولأن `x ?? y` ليس سوى اختصار لـ `x != nil ? x! : y`، فإذا لم تكن `x` مساوية لـ `nil`، فلن يُقيَّم التعبير `y` إطلاقًا.

وأخيرًا، تجدر الإشارة إلى أن عامل دمج nil يتمتع بالترابط من جهة اليمين، وهو ما قد يؤدي إلى نتائج مفاجئة لمن لا يعرف ذلك.

```swift
let k = 42 ?? 0 + 1    // returns 42
let j = nil ?? 0 + 1   // returns 1
```
