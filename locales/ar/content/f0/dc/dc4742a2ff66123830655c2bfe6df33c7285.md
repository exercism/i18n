# مقدمة

في Factor، تُعرّف كلمة جديدة بالصيغة `: name ( stack-effect ) body ;`.
والجسم تسلسل من الكلمات؛ وعندما تستدعي كلمتك الجديدة فإنها تشغّلها
بالترتيب.

```factor
USING: kernel ;
IN: my-vocab

: shout ( str -- str ) "!" append ;
```

عندما يكبر روتين ما، يمكنك، بل ينبغي لك، أن تجزّئه إلى عوامل: اجمع
مجموعات من الكلمات في كلمات أصغر مسمّاة، لكل واحدة منها مهمة واحدة.
ومن هذا التجزئة أخذت اللغة اسمها.

## المفردات

يُعلن كل ملف `.factor` عن مفرداته باستخدام `IN:`. وتستطيع الكلمات في
مفرداتٍ ما أن تستدعي كلماتٍ من مفرداتٍ أخرى بإدراج المفردات الأخرى في
`USING:`.

```factor
! file: my-vocab/helpers/helpers.factor
USING: kernel ;
IN: my-vocab.helpers

: shout-line ( str -- str ) "!" append ;
```

```factor
! file: my-vocab/my-vocab.factor
USING: kernel my-vocab.helpers sequences ;
IN: my-vocab

: announce ( names -- strs )
    [ shout-line ] map ;
```

يتبع ترتيب المجلدات اسم المفردات المنقّط: تقع مفردات `my-vocab`
في `my-vocab/my-vocab.factor`؛ وتقع مفردات `my-vocab.helpers` في
`my-vocab/helpers/helpers.factor`. ويتبع محمّل Factor تصريحات
`USING:` على نحو تعدٍّ، فيحمّل كل مفردات عند الطلب.
