# نبذة

## الأعداد والعوامل الرقمية

جميع **الأعداد**، سواء كانت أعدادًا صحيحة أو غير ذلك، هي أعداد عائمة مزدوجة الدقة وفق معيار IEEE754.
يعتمد تطبيق `jq` على النوع `double` في لغة C.
وهذا يحدّنا عند دقة تبلغ 53 بتًا.

تتوفر العوامل المعتادة للاستخدام مع الأعداد:

- الحسابية: `+`, `-`, `*`, `/`, `%`
- المقارنة: `==`, `!=`, `<`, `<=`, `>=`, `>`
- [الدوال الرياضية القياسية][man-math]

  بالنسبة للدوال التي تأخذ مدخلًا واحدًا، مرّر القيمة إلى الدالة عبر خط الأنابيب

  ```sh
  $ jq -n '(1 | atan) * 4'
  3.141592653589793
  ```

  أما الدوال التي تأخذ مدخلين، فتتجاهل المدخل وتتوقع مرور المدخلات كمعاملات

  ```sh
  $ jq -n 'pow(2; 10)'
  1024
  ```

  الفاصلة المنقوطة هي الفاصل بين وسائط الدالة، وليست الفاصلة.

## التعبيرات الشرطية

يستخدم `jq` [تعبير `if-then-else`][if-then-else] من أجل **التعبيرات الشرطية**.
وبصفته _تعبيرًا_، فإنه يوضع داخل خط الأنابيب.

الصيغة هي: `if CONDTITION then TRUE_EXPR else FALSE_EXPR end`.

وجملة `else` اختيارية.

```jq
42 | if . < 33 then "small" else "larger" end
# => "larger"
```

ولإضافة شروط أخرى استخدم `elif`

```jq
42 | if . < 33 then "small"
     elif . < 67 then "medium"
     else "large"
     end
# => "medium"
```
