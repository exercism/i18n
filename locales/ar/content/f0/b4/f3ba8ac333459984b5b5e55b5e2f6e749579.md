# نبذة

إذا أمكن استنتاج أنواع المعاملات، فإن Swift تسمح أيضًا بحذف أسماء المعاملات والكلمة المفتاحية `in` من تعريف الإغلاق. وبدلًا من ذلك، يمكن الإشارة إلى المعاملات باستخدام [صيغة مختصرة خاصة][shorthand-argument-names]، حيث يشير `$0` إلى المعامل الأول، ويشير `$1` إلى الثاني، وهكذا.

```swift
let mean: (Double, Double) -> Double = { $0 + $1 / 2.0 }

["apple", "ball", "carrot"].sorted(by: { $0.count < $1.count })
```

يُستخدم هذا الأسلوب غالبًا عند تمرير الإغلاقات إلى دوال ذات رتبة أعلى وعندما يُقدَّر الإيجاز.

[shorthand-argument-names]: https://docs.swift.org/swift-book/LanguageGuide/Closures.html#ID100
