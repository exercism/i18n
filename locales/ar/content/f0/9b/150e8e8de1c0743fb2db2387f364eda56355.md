# Debug

```pyret
fun print-forty-two():
  print(42) # 42
end
```

```pyret
fun return-forty-two() block:
  print(42) # 42
  42
end
```

[print][print] تعبير يُرجع قيمة.
لا يسمح Pyret إلا بتعبير واحد داخل كتلة كود معيّنة، ما لم تكن الكتلة الخارجية معلَّمة بـ `block`.
في المثال الثاني، تتيح لنا إضافة `block` إلى تعريف الدالة طباعة 42 قبل إرجاعه.

## الجواسيس

```pyret
fun do-something():
    x = "foo"
    y = "bar"
    spy "strings": x, y end
    a = 1
    b = 2
    spy "numbers": a, b end
end
do-something();

# Spying "strings" (at <clipped>/example.arr:4:4-4:27)
#  x: "foo"
#  y: "bar"
# Spying "numbers" (at <clipped>/example.arr:7:4-7:27)
#  a: 1
#  b: 2
```

تأخذ عبارة `spy` تسمية اختيارية ومتغيرًا واحدًا أو أكثر، وتُبلِّغ عن كل متغير وقيمته.
ولأنها ليست تعبيرًا، يمكن استخدام عبارة `spy` في كتلة دون اشتراط أن تكون الكتلة الخارجية معلَّمة بـ `block`.

[print]: https://pyret.org/docs/latest/_global_.html#%28idx._%28gentag._57%29%29
[spy]: https://pyret.org/docs/latest/s_spies.html
