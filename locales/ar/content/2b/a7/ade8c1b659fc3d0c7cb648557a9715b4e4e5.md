# التعليمات

كنت تعمل على مشروع يتيح للمستخدمين رفع الملفات إلى الخادم لمشاركتها مع مستخدمين آخرين. وقد أُوكلت إليك مهمة كتابة دالة للتحقق من أن الملف المرفوع يطابق [نوع الوسائط][mimetype] الخاص به. وبعد بعض البحث، تكتشف أن البايتات القليلة الأولى من الملف تكون عادةً فريدة لهذا النوع من الملفات، مما يمنحه نوعًا من البصمة.

استخدم الجدول التالي كمرجع:

| نوع الملف | الامتداد الشائع | نوع الوسائط                 | 'التوقيع' الثنائي                                |
| --------- | ---------------- | ---------------------------- | ------------------------------------------------ |
| ELF       | `"exe"`          | `"application/octet-stream"` | `0x7F, 0x45, 0x4C, 0x46`                         |
| BMP       | `"bmp"`          | `"image/bmp"`                | `0x42, 0x4D`                                     |
| PNG       | `"png"`          | `"image/png"`                | `0x89, 0x50, 0x4E, 0x47, 0x0D, 0x0A, 0x1A, 0x0A` |
| JPG       | `"jpg"`          | `"image/jpg"`                | `0xFF, 0xD8, 0xFF`                               |
| GIF       | `"gif"`          | `"image/gif"`                | `0x47, 0x49, 0x46`                               |

## 1. عند إعطائك امتدادًا، أرجِع نوع الوسائط المتوقع

نفّذ الدالة `type_from_extension/1`. ينبغي أن تأخذ امتداد ملف (سلسلة نصية) وتُرجع نوع الوسائط (سلسلة نصية)، أو nil إذا لم يطابق الامتداد الامتدادات المتوقعة.

```elixir
FileSniffer.type_from_extension("exe")
# => "application/octet-stream"

FileSniffer.type_from_extension("txt")
# => nil
```

## 2. عند إعطائك ملفًا ثنائيًا، أرجِع نوع الوسائط المتوقع

نفّذ الدالة `type_from_binary/1`. ينبغي أن تأخذ ملفًا (ثنائيًا) وتُرجع نوع الوسائط (سلسلة نصية)، أو nil إذا لم يطابق توقيع الملف التوقيعات المتوقعة.

```elixir
file = File.read!("application.exe")
FileSniffer.type_from_binary(file)
# => "application/octet-stream"

file = File.read!("example.txt")
FileSniffer.type_from_binary(file)
# => nil
```

لا تقلق بشأن قراءة الملف كبيانات ثنائية. افترض أن هذا قد تم نيابةً عنك، وأن الاختبارات تمرّره إليك كوسيط.

## 3. عند إعطائك امتدادًا وملفًا ثنائيًا، تحقّق من مطابقة الملف للنوع المتوقع

نفّذ الدالة `verify/2`. ينبغي أن تأخذ ملفًا (ثنائيًا) وامتدادًا (سلسلة نصية) وتُرجع صفًا `:ok` أو `:error`.

```elixir
file = File.read!("application.exe")

FileSniffer.verify(file, "exe")
# => {:ok, "application/octet-stream"}

FileSniffer.verify(file, "png")
# => {:error, "Warning, file format and file extension do not match."}
```

[mimetype]: https://en.wikipedia.org/wiki/Media_type
