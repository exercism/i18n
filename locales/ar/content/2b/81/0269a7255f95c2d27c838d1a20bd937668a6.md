# حول

تستخدم لوا تمثيلين للأعداد: أعداد صحيحة بعرض 64 بت، وأعداد الفاصلة العائمة ثنائية الدقة.

~~~~exercism/note
قبل الإصدار 5.3، كانت لوا تمثّل جميع الأعداد باستخدام صيغة أعداد الفاصلة العائمة ثنائية الدقة.
~~~~

يمكن كتابة الأعداد بجزء عشري اختياري، إضافة إلى أس عشري اختياري.
```lua
1               --> 1
0.2             --> 0.2
0.3e4           --> 3000.0
4.0e-3          --> 0.004
5.0e+20         --> 5e+20
```

يُعتبر العدد الذي يحتوي على فاصلة عشرية أو أس عددًا من أعداد الفاصلة العائمة، أما العدد الذي لا يحتوي عليهما فيُعامل كعدد صحيح، لكن كليهما له النوع `number`.
```lua
type(1)         --> number
type(2.0)       --> number
```

إذا أردنا التمييز بين أعداد الفاصلة العائمة والأعداد الصحيحة، يمكن استخدام دالة `type` في وحدة `math`.
```lua
math.type(1)    --> integer
math.type(2.0)  --> float
```

## المقارنة

الأعداد الصحيحة وأعداد الفاصلة العائمة التي لها القيمة نفسها تُقارن على أنها متساوية:
```lua
1 == 1.0        --> true
-2 == -2.0      --> true
0.3e3 == 300    --> true
```

## العمليات الحسابية

تدعم لوا المجموعة المعتادة من عوامل الحساب: الجمع، والطرح، والضرب، والقسمة، والنفي. إضافة إلى ذلك، تدعم القسمة الأرضية وباقي القسمة والرفع إلى قوة.

### الجمع والطرح والضرب والنفي

إذا كان كلا المعاملين عددين صحيحين، فإن نتيجة العملية عدد صحيح. وينطبق الأمر نفسه على أعداد الفاصلة العائمة.
```lua
1 + 2     --> 3
1.0 + 2.0 --> 3.0
```

إذا كان أحد المعاملين من أعداد الفاصلة العائمة، فسيتم تحويل الأعداد الصحيحة المتبقية إلى أعداد الفاصلة العائمة أيضًا، وتكون نتيجة العملية عددًا من أعداد الفاصلة العائمة.
```lua
1.0 + 2   --> 3.0
```

### القسمة

تعمل القسمة دائمًا على أعداد الفاصلة العائمة وتعطي عددًا من أعداد الفاصلة العائمة كنتيجة.
```lua
1.0 / 2.0 --> 0.5
2 / 1     --> 2.0
```

القسمة على صفر ستؤدي إلى `inf` أو `-inf`. وقسمة صفر على صفر ستؤدي إلى `-nan`.
```lua
1 / 0     --> inf
-1 / 0    --> -inf
0 / 0     --> -nan
```

### القسمة الأرضية

إذا كانت هناك حاجة إلى نتيجة صحيحة، فيمكن استخدام القسمة الأرضية. تقرّب القسمة الأرضية خارج القسمة دائمًا نحو سالب اللانهاية، مما يضمن نتيجة صحيحة لجميع المعاملات.

~~~~exercism/note
قبل الإصدار 5.3، لم يكن لدى لوا عامل حسابي للقسمة الأرضية.
~~~~

```lua
3 // 2    --> 1
6 // 2    --> 3
```

تتبع القسمة الأرضية القواعد نفسها التي تتبعها عوامل الجمع والطرح والضرب والنفي: إذا كان كلا المعاملين عددين صحيحين، فإن نتيجة العملية عدد صحيح، وإلا فإن النتيجة عدد من أعداد الفاصلة العائمة.

```lua
3.0 // 2   --> 1.0
6.0 // 2.0 --> 3.0
```

عند القسمة على صفر باستخدام القسمة الأرضية، سترفع لوا خطأً.
```lua
3 // 0     --> stdin:1: attempt to divide by zero
```

### باقي القسمة

يُستخدم باقي القسمة للحصول على باقي قسمة معاملين.
```lua
8 % 2      --> 0
13 % 9     --> 4
-13 % -9   --> -4
-13 % 9    --> 5
13 % -9    --> -5
0.3 % 0.2  --> 0.1
```

### الرفع إلى قوة

مثل القسمة، يعمل الرفع إلى قوة أيضًا على أعداد الفاصلة العائمة ويعطي نتائج من أعداد الفاصلة العائمة.
```lua
10 ^ 2    --> 100.0
```

## الأسبقية

تُقيَّم جميع العمليات وفقًا لـ [أسبقية العوامل](https://www.lua.org/manual/5.4/manual.html#3.4.8). ويمكن استخدام الأقواس الهلالية لتغيير أسبقية تعبير.

```lua
1 + 2 * 3   --> 7
(1 + 2) * 3 --> 9
```

## التقريب

توفّر وحدة `math` ثلاث دوال للتقريب: `floor` تقرّب "إلى الأسفل" (نحو سالب اللانهاية)، و`ceil` تقرّب "إلى الأعلى" (نحو موجب اللانهاية)، و`modf` تقرّب نحو الصفر.

### `math.floor`

تقرّب الدالة `floor` نحو سالب اللانهاية.
```lua
math.floor(1.3)    --> 1
math.floor(-1.3)   --> -2
```

### `math.ceil`

تقرّب الدالة `ceil` نحو موجب اللانهاية.
```lua
math.ceil(1.3)    --> 2
math.ceil(-1.3)   --> -1
```

### `math.modf`

تقرّب الدالة `modf` نحو الصفر. وتُرجع الدالة القيمة المقرّبة إضافة إلى الجزء الكسري من العدد، وهو دائمًا عدد من أعداد الفاصلة العائمة.
```lua
math.modf(1.3)    --> 1    0.3
math.modf(-1.3)   --> -1   -0.3
```

## التحويل

إذا أردنا تحويل عدد صحيح إلى عدد من أعداد الفاصلة العائمة، يمكننا إضافة `0.0` إليه.
```lua
1 + 0.0         --> 1.0
```

إذا أردنا تحويل عدد من أعداد الفاصلة العائمة إلى عدد صحيح، يمكننا إجراء عملية OR على مستوى البتات مع الصفر، أو استخدام دالة `tointeger` من وحدة `math`.
```lua
1.0 | 0              --> 1
math.tointeger(1.0)  --> 1
```

إذا تعذّر تحويل العدد إلى عدد صحيح، فإن عامل OR سيرفع خطأً وستُرجع دالة `tointeger` القيمة `nil`.
```lua
1.1 | 0              --> stdin:1: number has no integer representation
math.tointeger(1.1)  --> nil
```

## الأعداد الست عشرية

مثل كثير من لغات البرمجة الأخرى، تدعم لوا الأعداد الست عشرية بوضع البادئة `0x` قبلها، ولكن بخلاف كثير من لغات البرمجة الأخرى، تدعم لوا أيضًا أعداد الفاصلة العائمة الست عشرية. يمكن أن تحتوي على جزء كسري وأس ثنائي، مع بادئة `p` أو `P`.
```lua
0xff            --> 255
0x0.2           --> 0.125
0x3p-1          --> 1.5
0xa.bp2         --> 42.75
```
