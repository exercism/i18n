# التعليمات

إيلينا، مديرة الجودة الجديدة في مصنع للصحف، تطلب منك كتابة برنامج صغير لمراقبة غرفة الإنتاج.

## 1. عرّف خطأً مخصصًا

عرّف صنف خطأ من نوع tuple باسم `machine-error` باستخدام كلمة التحليل `ERROR:`. ولا يحتاج إلى أي خانات.

```factor
machine-error   ! throws a fresh machine-error
```

## 2. افحص الرطوبة

عرّف `check-humidity`. تأخذ قراءة رطوبة من المكدس، وترمي السلسلة النصية `"humidity too high"` عبر `throw` عندما تكون القراءة أكبر تمامًا من `70`. وإلا فإنها لا تُرجع شيئًا.

```factor
50 check-humidity   ! returns nothing
80 check-humidity   ! throws "humidity too high"
```

## 3. افحص درجة الحرارة

عرّف `check-temperature`. تأخذ قراءة لدرجة الحرارة، وترمي السلسلة النصية `"temperature too high"` عبر `throw` عندما تكون القراءة أكبر تمامًا من `500`. وإلا فإنها لا تُرجع شيئًا.

```factor
400 check-temperature   ! returns nothing
600 check-temperature   ! throws "temperature too high"
```

## 4. راقب الآلة

عرّف `monitor` لتأخذ الرطوبة ودرجة الحرارة من المكدس وتُشغّل الفحصين معًا. إذا رمى أحد الفحصين، فعلى `monitor` أن ترمي كائن `machine-error` جديدًا بدلًا من ذلك. وإذا نجح الفحصان، فإن `monitor` لا تُرجع شيئًا.

```factor
50 400 monitor   ! returns nothing
80 400 monitor   ! throws a machine-error
50 600 monitor   ! throws a machine-error
```

## 5. راقب دفعة من القراءات

عرّف `monitor-batch` لتأخذ مصفوفة من القراءات على شكل `{ humidity temperature }` وتُرجع عدد القراءات التي ستفشل (أي عدد القراءات التي ستجعل `monitor` ترمي).

```factor
{ { 50 400 } { 80 400 } { 50 600 } { 60 200 } } monitor-batch .
! => 2
```
