# التثبيت

كل ما تحتاجه لتشغيل هذه التمارين هو تثبيت [CommandBox CLI](https://commandbox.ortusbooks.com/getting-started-guide) و[Java 8](https://java.com/en/download/). يدعم CommandBox CLI أنظمة Mac وLinux وWindows، ويمكنك العثور على دليل التثبيت هنا:

[https://commandbox.ortusbooks.com/setup/installation](https://commandbox.ortusbooks.com/setup/installation)

مثال على إعداد CommandBox CLI إذا كنت من مستخدمي Homebrew على Mac:

```bash
brew install commandbox
```

بعد تثبيت واجهة سطر الأوامر، يمكنك التجربة في REPL:

```bash
box repl
```

ويمكنك تنفيذ صفحات .cfm مباشرةً:

```bash
box exec myTest.cfm
```

ويمكنك حتى تشغيل خادم ويب في أي مجلد على القرص الصلب لديك:

```bash
box server start
```

يمتلك CommandBox صدفة تفاعلية يمكنك استخدامها، وتتميز بإكمال تلقائي محسّن بزر Tab وتعمل أسرع. ادخل إليها بتشغيل الملف التنفيذي `box` بدون أي وسائط.

```bash
box
```
