# حول

توجد أساسًا نوعان من الحلقات:

1. التكرار حتى يتحقق شرط.
2. التكرار على عناصر مجموعة.

كلاهما [ممكن في R][web-loops]، وإن كان الأول أكثر شيوعًا.

## `while` و`repeat`

في المسائل المفتوحة التي لا يُعرف فيها مسبقًا عدد مرات دوران الحلقة، توفّر R حلقة [`while`][ref-control] مع شرط، وحلقة [`repeat`][ref-control] بدون شرط (وهي مكافئة لـ `while (TRUE)`).

الصيغة الأساسية بسيطة إلى حدّ كبير:

```R
while (condition) {
  do_something()
}
```

في هذه الحالة، يواصل البرنامج الدوران في الحلقة حتى لا تعود `condition` تساوي `TRUE`.

هناك أسلوبان للخروج المبكر من الحلقة:

- تؤدي `break` إلى الخروج من الحلقة، ويستمر التنفيذ من السطر التالي بعد القوس المعقوف المغلق للحلقة `}`.
- توقف `return(x)` تنفيذ الدالة الحالية وتُرجع القيمة `x` إلى مستدعيها.

مع توفّر هذين الخيارين، قد يكون من المناسب أحيانًا إنشاء حلقة "لا نهائية" باستخدام `repeat { ... }`، ثم الاعتماد على إيجاد شرط توقف داخل جسم الحلقة لتفعيل `break` أو `return`.

هذه الصيغ الثلاث متكافئة، وتنتهي جميعها بـ `x == 0.4444...`

```R
x <- 12
while (x > 1) {
  x <- x / 3
}

x <- 12
while (TRUE) {
  x <- x/3
  if (x <= 1) break
}

x <- 12
# no boolean clause 
repeat { 
  x <- x/3
  if (x <= 1) break
}
```

## التكرار على متجه (أو مجموعة أخرى)

غالبًا ما يكون هذا غير ضروري في R.
كما نوقش في مفاهيم أخرى، تعمل دوال كثيرة على المتجهات بأكملها.

لكن لا يمكن أحيانًا تجنّب الحلقات الصريحة.
وهذا صحيح بشكل خاص عندما:

- يكون لجسم الحلقة آثار جانبية مثل الطباعة أو القراءة والكتابة في الملفات.
- يستمر التكرار حتى الوصول إلى معيار ما، بعد عدد غير متوقّع من التكرارات.

يجب أن يكون شرط الحلقة بين الأقواس الهلالية.
وكما هو الحال مع أجسام الدوال، تكون الأقواس المعقوفة اختيارية (لكنها تُضمَّن غالبًا) في أجسام الحلقات ذات السطر الواحد.

```R
words <- c("This", "is", "a", "loop")
for (w in words) { print(w) } # the braces are optional here
#> [1] "This"
#> [1] "is"
#> [1] "a"
#> [1] "loop"
```

إذا لم يحقّق التكرار الحالي شرطًا ما، فيمكنك الانتقال فورًا إلى التكرار التالي باستخدام `next`:

```R
for (n in 1:5) {
  if (n %% 2 == 0) next
  print(n)
}
#> [1] 1
#> [1] 3
#> [1] 5
```

إذا احتجت إلى الفهرس الرقمي، فاستخدم [`seq_along()`][ref-seq_along].

```R
v <- LETTERS[1:3]
v
#> [1] "A" "B" "C"

for (i in seq_along(v)) { print(sprintf("%s%i", v[i], i)) }
#> [1] "A1"
#> [1] "B2"
#> [1] "C3"
```

لا يُنصح باستخدام `i in 1:length(v)`، لأنه قد يسبب مشكلات عندما تكون `length(v)` صفرًا.
النطاق `1:0` مكافئ لـ `c(1, 0)`، لذا سيُنفَّذ جسم الحلقة ويفشل على الأرجح.
صُمّمت دالة `seq_along()` للتعامل مع هذه الحالة بشكل صحيح.
