# اختبار التمارين

اتبع الخطوات أدناه لتطوير حل لتمرين ما واختباره على جهازك.

## نزّل التمرين

افتح Command Prompt ونفّذ الأمر أدناه مع اسم التمرين الذي تريده لتنزيله.

```sh
exercism download --track ballerina --exercise <exercise-name>
```

## طوّر حلك

1. نفّذ الأمر أدناه للانتقال إلى مجلد التمرين الذي نزّلته للتو.

     >**تلميح:** يعتمد موقع المجلد في الأمر أدناه على نظام التشغيل لديك وعلى مساحة عمل Exercism التي أعددتها. يمكنك معرفة موقع مساحة عملك بتنفيذ الأمر `exercism configure`.

     ```sh
     cd ~/exercism/ballerina/hello-world/
     ```

2. اتبع التعليمات المرفقة وطوّر حلًا للتمرين.

## اختبر حلك

بعض تمارين Ballerina لها اختبار واحد، وبعضها الآخر له عدة اختبارات. تجد الاختبارات في ملف الاختبار المقابل داخل مجلد `/tests` في المجلد الجذر للتمرين.

### اختبار تمرين له اختبار واحد

نفّذ الأمر أدناه لتشغيل اختبار التمرين.

افتراضيًا، لا يُفعَّل إلا الاختبار الأول. وهذا مقصود، إذ يسمح لك بالتركيز على اجتياز هذا الاختبار وحده.

```sh
bal test
```

### اختبار تمرين له عدة اختبارات

اتبع الخطوات أدناه لاختبار تمرين له عدة اختبارات.

1. بعد أن يجتاز الاختبار الأول، فعّل الاختبار التالي بإزالة الخاصية `enable: false` من تعليق `@test:Config`.

     ```ballerina
     @test:Config {
       enable: false
     }
     function nextTestCase() {
     }
     ``` 

2.  نفّذ الأمر أدناه لتشغيل الاختبار المفعَّل.

   ```sh
     bal test
   ```

3. كرّر الخطوتين أعلاه لتفعيل بقية الاختبارات.

لقد أكملت التمرين بنجاح بتفعيل كل الاختبارات والتأكد من أن تنفيذك يجتاز كل واحد منها.
