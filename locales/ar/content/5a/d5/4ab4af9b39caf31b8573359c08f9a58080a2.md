# التعليمات

مهمتك هي إيجاد ترتيب الجلوس المثالي على الطاولة.
ستفعل ذلك بتعريف _حقائق_ (أمور صحيحة دائمًا) و_قواعد_ (أمور صحيحة شرطيًا).

## 1. اسرد الأشخاص الثرثارين

عرّف الحقيقة `chatty` لتمثيل الأشخاص الثرثارين.
تأخذ الحقيقة `chatty` وسيطًا واحدًا: الاسم بحروف صغيرة للشخص الثرثار.

```prolog
chatty(gustavo).
true.
```

## 2. اسرد من يحب من

عرّف الحقيقة `likes` لتمثيل من يحب من.
تأخذ الحقيقة `likes` وسيطين:

1. الاسم بحروف صغيرة للشخص الذي يحب الشخص الآخر
2. الاسم بحروف صغيرة للشخص الذي يحبه الشخص الآخر

```prolog
likes(esteban, malena).
true.
```

## 3. الأشخاص الذين يحبون بعضهم بعضًا يشكّلون اقترانًا جيدًا

عرّف القاعدة `pairing` لتكون صحيحة عندما يحب كل منهما الآخر.
تأخذ قاعدة `pairing` وسيطين:

1. الاسم بحروف صغيرة للشخص الأول
2. الاسم بحروف صغيرة للشخص الثاني

```prolog
pairing(malena, esteban).
true.
```

## 4. الأشخاص الثرثارون يقترنون بأي شخص

عرّف القاعدة `pairing` لتكون صحيحة عندما يكون (على الأقل) أحد الشخصين المقترنين ثرثارًا.

```prolog
pairing(valeria, jaime).
true.
```

## 5. تحقق من ترتيب الجلوس

عرّف القاعدة `seating` لتكون صحيحة عندما تكون الأزواج الخمسة كلها اقترانات جيدة.

تأخذ قاعدة `seating` خمسة وسائط:

1. الاسم بحروف صغيرة للشخص الأول
2. الاسم بحروف صغيرة للشخص الثاني
3. الاسم بحروف صغيرة للشخص الثالث
4. الاسم بحروف صغيرة للشخص الرابع
5. الاسم بحروف صغيرة للشخص الخامس

استخدم الحقائق والقواعد المعرّفة للتو للتحقق من ترتيب الجلوس.

```prolog
seating(esteban, jaime, gustavo, malena, valeria).
false.
```
