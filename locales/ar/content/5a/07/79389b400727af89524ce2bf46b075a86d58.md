# نبذة

إلى جانب الجملة الشرطية `if`، توجد أيضًا جملة `switch` لتنفيذ المنطق شرطيًا. تُستخدم عندما يلزم مقارنة متغير واحد بعدة حالات مختلفة. وبالنسبة لمتغير ما `x`، تكون جملة `switch` في Haxe بالصيغة التالية.

```haxe
var a = 2;

switch (a) {
  case 0:
    trace("a is 0");
  case 1:
    trace("a is 1");
  case 2:
    trace("a is 2");
  default:
    trace("a is something else");
}

// a is 2
```

تُنفَّذ الحالة `default` عندما لا تتطابق أي من الحالات الأخرى.
