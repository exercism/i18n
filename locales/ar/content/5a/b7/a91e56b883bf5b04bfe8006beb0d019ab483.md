## القيم المنطقية في R

تُمثَّل القيم التي تكون صحيحة أو خطأ بالنوع `logical`.
وهو لا يحتوي إلا على قيمتين: `TRUE` و`FALSE`.

```R
TRUE
#> [1] TRUE
FALSE
#> [1] FALSE
typeof(TRUE)
#> [1] "logical"
```

## عوامل القيم المنطقية

يوجد في R خمسة عوامل للقيم المنطقية، لكن ثلاثة فقط منها مهمة في هذه المرحلة من المنهج.
وسيكون العاملان الآخران مهمين عند التعامل مع المتجهات، وهو ما ستغطيه عدة مفاهيم لاحقة.

`&&` هو عامل «و» للقيم المنطقية.
وتكون قيمته `TRUE` إذا كانت التعبيرات على *كلا* جانبي `&&` تساوي `TRUE`.

```R
TRUE && TRUE
#> [1] TRUE
TRUE && FALSE
#> [1] FALSE
```

`||` هو عامل «أو» للقيم المنطقية.
وتكون قيمته `TRUE` إذا كان تعبير على *أيٍّ* من جانبي `||` يساوي `TRUE`.

```R
TRUE || TRUE
#> [1] TRUE
FALSE || TRUE
#> [1] TRUE
```

`!` هو عامل «ليس» للقيم المنطقية.
وهو يبادل بين القيمتين `TRUE` و`FALSE`.

```R
!TRUE
#> [1] FALSE
!FALSE
#> [1] TRUE
```

بالنسبة إلى التعبيرات الأطول والأكثر تعقيدًا، من الأفضل استخدام الأقواس الهلالية لتوضيح ما تقصده.

```R
(TRUE || FALSE) && (FALSE && TRUE)
#> [1] FALSE

TRUE || FALSE && (FALSE && TRUE)
#> [1] TRUE
```
