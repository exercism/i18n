# Char

`Char` هو نوع بيانات في Crystal يمثّل نقطة ترميز [يونيكود][unicode] بسعة 32 بت.
حجمه يجعله موفّرًا للذاكرة ويمنحه خصائص معينة لا تمتلكها السلاسل النصية.
وتُنشأ قيم `Char` باستخدام علامات الاقتباس المفردة (`'`) ولا تسمح إلا بوضع نقطة ترميز يونيكود واحدة بداخلها.

```crystal
'a' # => 'a'
'a'.class # => Char
```

من الشائع جدًا العمل بقيم `Char` عند التعامل مع السلاسل النصية في Crystal، لأن عددًا لا بأس به من الطرق في الصنف `String` تُرجع قيم `Char` أو تأخذ قيم `Char` كوسائط.
على سبيل المثال، تُرجع الطريقة [`String#[]`][index] قيمة `Char`، أو تُرجع الطريقة [`String#chars`][chars] مجموعة من قيم `Char`.

## الزيادة / النقصان

نظرًا لأن `Char` يمثّل نقطة ترميز يونيكود بسعة 32 بت، فإنه يدعم الزيادة والنقصان. وهذا يعني أنه إذا كانت لديك `'a'` فيمكنك الحصول على `'b'` بإضافة واحد.

```crystal
'a' + 5
# => 'f'

'z' - 25
# => 'a'
```

هناك أيضًا طريقة تُسمى [`Char#succ`][succ] تُرجع الحرف التالي في جدول يونيكود، و[`Char#pred`][pred] التي تُرجع الحرف السابق في جدول يونيكود.

```crystal
'a'.succ
# => 'b'

'z'.pred
# => 'y'
```

## الدمج

نظرًا لأن قيم `Char` مخصصة فقط لتمثيل نقطة ترميز يونيكود بسعة 32 بت، فلا يمكن دمج حرفين معًا.
لذلك لا يمكن دمج قيم `Char` إلا مع السلاسل النصية.

```Crystal
'a' + "bc"
# => "abc"

'a' + 'b'
# => error: expected argument #1 to 'Char#+' to be Int or String, not Char
```

## طرق الخصائص

يمتلك Crystal بعض الطرق للحصول على معلومات عن حرف، مثل ما إذا كان رقمًا أو حرفًا أبجديًا أو ما إذا كان بحالة صغيرة أو كبيرة.
إليك قائمة ببعض هذه الطرق، وللاطلاع على القائمة الكاملة راجع [واجهة Char API][char-api]:

| الطريقة                           | الوصف                                                |
| --------------------------------- | ---------------------------------------------------- |
| [`Char#number?`][number]          | تُرجع `true` إذا كان `Char` رقمًا                     |
| [`Char#letter?`][letter]          | تُرجع `true` إذا كان `Char` حرفًا أبجديًا             |
| [`Char#lowercase?`][lowercase]    | تُرجع `true` إذا كان `Char` بحالة صغيرة               |
| [`Char#uppercase?`][uppercase]    | تُرجع `true` إذا كان `Char` بحالة كبيرة               |
| [`Char#ascii?`][ascii]            | تُرجع `true` إذا كان `Char` محرف ASCII                |
| [`Char#whitespace?`][whitespace]  | تُرجع `true` إذا كان `Char` محرف مسافة بيضاء          |

## التحويل

### التحويل بين نقاط الترميز وقيم `Char`

نظرًا لأن `Char` يمثّل نقطة ترميز يونيكود بسعة 32 بت، يمكنك التحويل بين قيم `Char` ونقاط الترميز (`Int`).
يمكن القيام بذلك باستخدام الطريقة [`Char#ord`][ord] التي ستُرجع نقطة ترميز الحرف، أو الطريقة [`Int#chr`][chr] التي ستُرجع الحرف المقابل لنقطة الترميز.

```crystal
'a'.ord
# => 97

97.chr
# => 'a'
```

### التحويل بين الأنواع

كما هو الحال مع أنواع البيانات الأخرى، تمتلك قيم `Char` بعض الطرق للتحويل بين الأنواع.
أكثرها شيوعًا هي الطريقة `Char#to_s`، التي تحوّل `Char` إلى سلسلة نصية. لكن هناك أيضًا الطريقة `Char#to_i`، التي تحوّل `Char` إلى `Int`، والطريقة `Char#to_f`، التي تحوّل `Char` إلى `Float`.

```crystal
'a'.to_s
# => "a"

'4'.to_i
# => 4

'a'.to_i
# => Error: Invalid integer: a (ArgumentError)
```

## التخطّي

كما هو الحال مع السلاسل النصية، هناك محارف معينة لا يمكن كتابتها مباشرة، ولكتابتها تحتاج إلى تخطّيها.
يمكنك استخدام المحرف `\` لكتابة تسلسل تخطٍّ يتبعه المحرف الذي تريد تخطّيه.

هذه هي المحارف الخاصة في Crystal:

| القيمة   | الوصف                          |
| -------- | ------------------------------ |
| `\a`     | تنبيه                          |
| `\b`     | مسافة للخلف                    |
| `\e`     | تخطٍّ                           |
| `\f`     | تغذية النموذج                  |
| `\n`     | تغذية سطر أو سطر جديد          |
| `\r`     | إرجاع المؤشر                   |
| `\t`     | مسافة جدولة أفقية              |
| `\v`     | مسافة جدولة رأسية              |
| `\\`     | شرطة مائلة عكسية               |
| `\'`     | علامة اقتباس مفردة             |
| `\"`     | علامة اقتباس مزدوجة            |
| `\377`   | محرف ASCII ثماني               |
| `\xFF`   | محرف ASCII سادس عشري           |
| `\uFFFF` | محرف يونيكود سادس عشري         |
