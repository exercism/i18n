# نبذة

يمكن للدوال أن تُعلن [قيمًا افتراضية][default-arguments] لواحد أو أكثر من الوسائط.

```elixir
def number(n \\ 13), do: "That's not my favorite"
```

- عند تصريف المثال أعلاه، يُنشأ تعريف دالة لكل من `number/0` (بدون وسائط) و`number/1` (وسيط واحد).
- إذا كان أكثر من وسيط واحد له قيمة افتراضية، فستُطبَّق القيم الافتراضية على الدالة من اليسار إلى اليمين لتعويض الوسائط الناقصة.
- إذا كانت للدالة عدة فروع، فيلزم كتابة [رأس الدالة][function-header] للقيم الافتراضية.
- يمكن لأي تعبير أن يكون القيمة الافتراضية.
- لا يمكن أن يكون للدوال المجهولة وسائط افتراضية.

```elixir
def guess(number \\ 5)
def guess(number) when number != 5, do: false
def guess(number) when number == 5, do: true

guess()
# => true
```
