# مقدمة

الكتلة مجموعة من العبارات والإعلانات مجمّعة في وحدة نحوية واحدة.
وغالبًا ما تُعرَّف الكتل داخل الأقواس المعقوفة، لكن ليس دائمًا.
ويمكن أن تتداخل الكتل داخل الدوال وداخل كتل أخرى.

تتصرّف الدالة إلى حد ما مثل الكتلة.
فلا يمكن رؤية معرّف متغير معرَّف داخل دالة من خارج الدالة، تمامًا كما لا يمكن رؤية معرّف متغير معرَّف داخل كتلة من خارج الكتلة.
ويمكن لمتغيّرين في دالتين مختلفتين أن يحملا الاسم نفسه، لأن الدالتين لا تريان ما بداخل بعضهما البعض، تمامًا كما يمكن لمتغيّرين في كتلتين مختلفتين أن يحملا الاسم نفسه، لأن الكتلتين لا تريان ما بداخل بعضهما البعض.
لكن الدوال والكتل ليست متطابقة.
فلا يمكن أن تتداخل دالة داخل دالة أخرى، لكن يمكن أن تتداخل كتلة داخل كتلة أخرى.

في المثال التالي، المتغير `number` معرَّف داخل الدالة `main`.
والمتغير `flag` معرَّف داخل كتلة `if` المتداخلة داخل الدالة `main`.
والمتغيرات المعرَّفة داخل كتلة صالحة داخل تلك الكتلة فقط.
لذلك فإن محاولة تصريف الكود تؤدي إلى خطأ في التصريف.

```c
#include <stdio.h>

int main() {

  int number = 1;

  if (number == 1) {
      int flag = 1;
      printf("%d", flag);
  }

  // this line generates a compilation error
  // error: 'flag' undeclared (first use in this function)
  printf("%d", flag);
    
}
```

قد تكون رسالة الخطأ مربكة، لأن `flag` مُستخدَم _فعلًا_ في موضع سابق داخل الدالة.
غير أن `flag` معرَّف داخل كتلة تقع داخل الدالة.
فالكتلة الداخلية تستطيع أن «ترى» المتغير `number` في الدالة الخارجية، لكن الدالة الخارجية لا تستطيع أن «ترى» المتغير `flag` المعرَّف داخل كتلتها الداخلية.
وبمجرد أن يخرج التنفيذ من الكتلة، يُدمَّر المتغير `flag` تلقائيًا ولم يعد متاحًا للبرنامج.
وترى الدالة `main` نفسها المعرّف `flag` للمرة الأولى في عبارة `printf` الأخيرة.
وإذا حُذفت عبارة `printf` الأخيرة، فسيُصرَّف البرنامج وسيطبع `1` عند تشغيله.
ويعود السبب إلى أن المتغير `flag` صالح في الكتلة التي تحتوي على عبارة `printf` الأولى.

بدءًا من `C99`، تُعدّ عبارات `if` و`for` و`while` و`do` ذات السطر الواحد كتلًا أيضًا.
وفي المثال التالي، ومع أن `i` غير معرَّف داخل الأقواس المعقوفة، فهو لا يوجد إلا في الكتلة التي تعرّفها عبارة `for`، ولا يكون مرئيًا للدالة `main` الخارجية.

```c
#include <stdio.h>

int main() {

    for (int i = 0, j = 11; i < j; i+=2)
        printf("%d", i);

    // this line generates a compilation error
    // error: 'i' undeclared (first use in this function)
    printf("%d", i);
    
}
```

وإذا حُذفت عبارة `printf` الأخيرة، فسيُصرَّف البرنامج وسيطبع `0 2 4 6 8 10 ` عند تشغيله.
وبعض اللغات، مثل Go وRust، تنص صراحة على أن العبارات الشرطية وعبارات الحلقات ذات السطر الواحد تشكّل كتلة.
وهي تشترط أن تظل هذه العبارات ذات السطر الواحد محاطة بالأقواس المعقوفة.
