# مقدمة

## المنشئات

يتم إنشاء نسخة من _الصنف_ عن طريق استدعاء _المنشئ_ الخاص به باستخدام العامل `new`.
المنشئ نوع خاص من الطرق، هدفه تهيئة نسخة أُنشئت للتو.
تشبه المنشئات الطرق العادية، لكنها بدون نوع إرجاع، واسمها مطابق لاسم الصنف.

```java
class Library {
    private int books;

    public Library() {
        // Initialize the books field
        this.books = 10;
    }
}

// This will call the constructor
var library = new Library();
```

ومثل الطرق العادية، يمكن أن تحتوي المنشئات على معاملات.
عادةً ما تُخزَّن معاملات المنشئ في حقول (خاصة) للرجوع إليها لاحقًا، أو تُستخدم في عملية حسابية لمرة واحدة.
ويمكن تمرير الوسائط إلى المنشئات تمامًا كما تُمرَّر الوسائط إلى الطرق العادية.

```java
class Building {
    private int numberOfStories;
    private int totalHeight;

    public Building(int numberOfStories, double storyHeight) {
        this.numberOfStories = numberOfStories;
        this.totalHeight = numberOfStories * storyHeight;
    }
}

// Call a constructor with two arguments
var largeBuilding = new Building(55, 6.2);
```
