# تعليمات خاصة بـ SQLite

* يحتوي عمود **digits** على قائمة أعداد صحيحة مُرمَّزة بصيغة JSON.
  مثال:
  ```json
  [1,0,1,0,1,0]
  ```
* يجب أن يحتوي عمود **result** على بيانات مُرمَّزة بصيغة JSON: كائن يحوي الأرقام كأعداد صحيحة، أو وصف لأي أخطاء.
  أمثلة:
  ```json
  {"digits":[1,0,1,0,1,0]}
  ```
  أو
  ```json
  {"error":"some error description"}
  ```

## مخطط الجدول

```sql
CREATE TABLE IF NOT EXISTS "all-your-base" (
  input_base  INTEGER NOT NULL,
  digits      TEXT    NOT NULL, -- json array
  output_base INTEGER NOT NULL,
  result      TEXT              -- json object
);
```
