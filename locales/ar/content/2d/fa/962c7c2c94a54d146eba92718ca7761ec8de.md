# لا يوجد تصدير مُسمّى

لم يُعثر على [`export %{export.name}`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/export). لن تنجح الاختبارات من دونه.

تأكد من وجود `%{export.name}` وأضف `export` أمامه:
```javascript
// exporting a "const"
export const %{export.name} = /*...*/

// exporting a named function declaration
export function %{export.name}() { /* ... */ }
```
