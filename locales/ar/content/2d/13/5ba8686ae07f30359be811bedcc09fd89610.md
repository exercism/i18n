# مقدمة

## القيم المنطقية

يحتوي النوع المنطقي في Lua على القيمتين المنطقيتين التقليديتين: `true` و`false`. ويمكن إسناد هاتين القيمتين إلى متغير، ودمجهما بالعوامل المنطقية (`and`، `or`، `not`)، واستخدامهما في اختبارات شرطية (كما في تراكيب التحكم على سبيل المثال).

```lua
local is_true = true
local is_false = false

true and true  --> true
true and false --> false
false or true  --> true
false or false --> false
not false      --> true
not true       --> false

-- prints 0
if is_true == true then
  print(0)
else
  print(1)
end
```

تَعتبر الاختبارات الشرطية والعوامل المنطقية كلاً من `false` و`nil` خطأ، وأي شيء آخر صحيحًا.
```lua
1 and 2          --> 2
nil and 2        --> nil
false and 2      --> false
1 or 2           --> 1
false or 'hello' --> "hello"
nil or false     --> false
```

يستخدم كلٌّ من `and` و`or` *التقييم قصير الدائرة*، أي أنهما لا يقيّمان الطرف الثاني فيهما إلا عند الضرورة. وتُقيَّم جميع العمليات وفقًا لـ[أسبقية العوامل](https://www.lua.org/manual/5.4/manual.html#3.4.8)، حيث يُقيَّم `not` قبل `and` و`or`.
