# مقدمة

## الأساسيات

سنشير إلى _اللغة_ باسم **AWK**، وإلى _البرنامج التنفيذي_ الذي يفسّر برامج AWK باسم **`awk`** أو **`gawk`**.

### الأنماط والإجراءات

يتكوّن برنامج AWK من **أزواج النمط والإجراء**

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

يمكن أن يكون **النمط** تعبيرًا نمطيًا يُطابَق به مع المدخلات.
ويمكن أن يكون أيضًا أي تعبير يُنتج قيمة صحيحة أو خاطئة.

و**الإجراء** هو أمر واحد أو أكثر من أوامر AWK.
ويلزم وجود الأقواس المعقوفة المحيطة به.

وإذا كانت نتيجة النمط _صحيحة_، فسيُقيَّم الإجراء المقابل.

### السجلات والحقول

يحلّل AWK المدخلات على شكل مجموعة من **السجلات**.
ويُقسَّم كل سجل إلى صفر أو أكثر من **الحقول**.

السلوك الافتراضي هو:

- تقسيم المدخلات إلى سجلات باستخدام السطر الجديد كـ«فاصل للسجلات»، فيكون كل _سطر_ سجلًا.
- تقسيم السجل إلى حقول باستخدام الفراغات البيضاء كـ«فاصل للحقول»، فتكون كل _كلمة_ حقلًا.

### الأنماط والإجراءات (تابع)

يمكن حذف النمط، وفي هذه الحالة يُقيَّم الإجراء _لكل سجل من سجلات المدخلات_.

ويمكن حذف الإجراء، وفي هذه الحالة يكون الإجراء الافتراضي هو طباعة السجل الحالي.

#### أنماط خاصة

هناك نمطان خاصان يُستخدمان كثيرًا.

- `BEGIN` يقيّم الإجراء المرتبط به قبل استهلاك أي مدخلات.
- `END` يقيّم الإجراء المرتبط به بعد استهلاك كل المدخلات.

### متغيرات الحقول

تشير إلى الحقول بالصيغة `$1` و`$2` و`$3` وهكذا.

والسجل الحالي هو `$0`.

وفيما يلي بعض المتغيرات المدمجة الأخرى كثيرة الاستخدام.

#### المتغيرات المدمجة التي تتحكم في تحليل المدخلات

- `RS` هو فاصل سجلات المدخلات.
  وكما ذُكر، فإن قيمته الافتراضية سطر جديد.
- `FS` هو فاصل حقول المدخلات.

غالبًا ما تُضبط هذه المتغيرات في كتلة إجراء `BEGIN`.

#### المتغيرات المدمجة التي تنقل المعلومات

تُضبط هذه المتغيرات تلقائيًا بواسطة AWK أثناء تنفيذ البرنامج.

- يخزّن `NF` عدد الحقول في السجل الحالي.
  - للحصول على قيمة الحقل الأخير، استخدم `$NF`.
- يخزّن `NR` رقم السجل الحالي.
  - عند معالجة عدة ملفات مدخلات، سيحتفظ `NR` بالعدد الإجمالي للسجلات التي جرى معالجتها حتى الآن.
- يخزّن `FNR` رقم السجل الحالي في ملف المدخلات الحالي.
  - ولتوضيح الفرق بين `NR` و`FNR`، إليك تعبيرًا شائعًا في AWK.
    ```awk
    NR == FNR {action}
    ```
    ويعني هذا: «إذا كان العدد المتراكم للسجلات مساويًا لرقم السجل في الملف الحالي».
    ولا يمكن أن يكون هذا صحيحًا إلا لسجلات _ملف المدخلات الأول_.

### صحة القيم

يستخدم AWK مفهوم صحة القيم نفسه الذي تستخدمه لغة C.

- العدد `0` خطأ.
- وأي عدد آخر صحيح.

وبما أن AWK لغة لمعالجة النصوص، فإن قيم الصحة تمتد لتشمل السلاسل النصية.

- السلسلة النصية الفارغة `""` خطأ.
- وأي سلسلة نصية غير فارغة صحيحة.

### التعليقات

تبدأ التعليقات بالمحرف `#` وتمتد إلى نهاية السطر.

### أمثلة

في الأنظمة الشبيهة بـ Unix، يحتوي `/etc/passwd` على معلومات عن المستخدمين.
ويوصف كل مستخدم في سطر منفصل، مع فصل الحقول بنقطتين رأسيتين.

لعرض أسماء المستخدمين:

```sh
awk '
    BEGIN { FS = ":" }
    { print $1 }
' /etc/passwd
```

لاحظ أن الإجراء `{print $1}` ليس له نمط، لذلك يُنفَّذ مع كل سجل.

وإذا أردنا حصر المخرجات على المستخدمين الذين يستخدمون bash كصدفة دخول لهم فقط، فيمكننا فعل ما يلي:

```sh
awk '
    BEGIN { FS = ":" }
    $7 == "/bin/bash" { print $1 }
' /etc/passwd
```
