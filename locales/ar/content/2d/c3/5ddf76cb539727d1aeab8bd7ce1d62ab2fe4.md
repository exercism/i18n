# المقدمة

سيتطلب منك مسار Julia بأكمله أن تتعامل مع حلّك كما لو كان مكتبة صغيرة، أي أنك تحتاج إلى تعريف دوال وأنواع وغيرها، ثم تُشغَّل هذه التعريفات مقابل مجموعة اختبارات.
ولهذا السبب، سنقدّم الدوال المُسمّاة باعتبارها المفهوم الأول.

Julia لغة برمجة ديناميكية ذات أنواع قوية.
وأسلوب البرمجة فيها وظيفي في الأساس، وإن كان أكثر مرونة من لغات مثل Haskell.

## المتغيرات والإسناد

لا حاجة إلى الإعلان عن متغير مسبقًا.
أسنِد فقط قيمة إلى اسم مناسب:

```julia-repl
julia> myvar = 42  # an integer
42

julia> name = "Maria"  # strings are surrounded by double-quotes ""
"Maria"
```

## الثوابت

إذا كانت هناك قيمة يجب أن تكون متاحة في كل البرنامج، لكن لا يُتوقع أن تتغير، فمن الأفضل تعريفها كثابت.

وضع الكلمة المفتاحية `const` قبل الإسناد يتيح للمُصرِّف توليد كود أكثر كفاءة مما هو ممكن مع متغير.

تساعدك الثوابت أيضًا على الحماية من الأخطاء البرمجية.
فمحاولة تغيير قيمة `const` دون قصد ستعطيك تحذيرًا:

```julia-repl
julia> const answer = 42
42

julia> answer = 24
WARNING: redefinition of constant Main.answer. This may fail, cause incorrect answers, or produce other errors.
24
```

لاحظ أن `const` يمكن الإعلان عنه *خارج* أي دالة فقط.
ويكون ذلك عادةً قرب أعلى ملف `*.jl`، قبل تعريفات الدوال.

## عوامل الحساب

هذه هي نفسها في كثير من اللغات الأخرى:

```julia
2 + 3  # 5 (addition)
2 - 3  # -1 (subtraction)
2 * 3  # 6 (multiplication)
8 / 2  # 4.0 (division with floating-point result)
8 % 3  # 2 (remainder)
```

## الدوال

هناك أسلوبان شائعان لتعريف دالة مُسمّاة في Julia:

1. باستخدام الكلمة المفتاحية `function`

    ```julia
    function muladd(x, y, z)
        x * y + z
    end
    ```

    المسافة البادئة بأربع فراغات عُرف متبع لتحسين القراءة، لكن المُصرِّف يتجاهلها.
    أما الكلمة المفتاحية `end` فلا غنى عنها.

    لاحظ أنه كان بإمكاننا كتابة `return x * y + z`.
    لكن دوال Julia تُرجع دائمًا آخر تعبير يُقيَّم، لذا فالكلمة المفتاحية `return` اختيارية.
    ويُفضّل كثير من المبرمجين إدراجها لتوضيح نواياهم أكثر.

2. باستخدام "صيغة الإسناد"

    ```julia
    muladd(x, y, z) = x * y + z
    ```

    وهذا هو الأكثر شيوعًا لكتابة دوال موجزة ذات تعبير واحد.

    ولا تُستخدم الكلمة المفتاحية `return` *أبدًا* في صيغة الإسناد.

الصيغتان متكافئتان، ويُستخدم كل منهما على النحو ذاته تمامًا، لذا اختر أيّهما أوضح للقراءة.

يتم استدعاء الدالة بتحديد اسمها وتمرير وسائط لكل معامل من معاملات الدالة:

```julia
# invoking a function
muladd(10, 5, 1)

# and of course you can invoke a function within the body of another function:
square_plus_one(x) = muladd(x, x, 1)
```

## اصطلاحات التسمية

مثل كثير من اللغات، تشترط Julia أن تبدأ الأسماء (أسماء المتغيرات والدوال وأشياء أخرى كثيرة) بحرف، يتبعه أي مزيج من الحروف والأرقام والشرطات السفلية.

وبحسب العُرف، تُكتب أسماء المتغيرات والثوابت والدوال *بحروف صغيرة*، مع إبقاء الشرطات السفلية عند حد أدنى معقول.
