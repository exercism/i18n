# التعليمات

أنت تساعد في مسح للطيور. كل يوم يجلس شخص في مخبأ ويعدّ ما يمرّ طائرًا، وتعود أعداد ذلك اليوم في مصفوفة.

تُوضع المهام الخمس كلها في الصنف `BIRD_SURVEY`.

## 1. المجموع

اجمع أعداد كل يوم.

```sather
BIRD_SURVEY::total_seen(|3, 0, 7|)
-- => 10
```

المسح الذي لا يحتوي على أي يوم على الإطلاق يُحصي صفرًا من الطيور.

## 2. أفضل يوم

أرجِع أكبر عدد. وإذا لم تكن هناك أيام، فالإجابة صفر.

```sather
BIRD_SURVEY::busiest_day(|3, 0, 7|)
-- => 7
```

## 3. الأيام المزدحمة

كم يومًا كان عدده فوق عدد معيّن؟

```sather
BIRD_SURVEY::days_over(|3, 0, 7|, 2)
-- => 2
```

«فوق» تعني فوق: العدد الذي يساوي 2 بالضبط لا يُحتسب.

## 4. المخابئ التي يجب فحصها

في اليوم الأول من المسح تفحص مخبأً واحدًا، وفي اليوم الثاني مخبأين، وهكذا. فكم عدد فحوص المخابئ في المجموع؟

```sather
BIRD_SURVEY::hides_to_check(4)
-- => 10
```

أي 1 + 2 + 3 + 4.

## 5. أول يوم مزدحم

أي يوم كان الأول الذي تجاوز عدده عددًا معيّنًا؟ تُرقَّم الأيام بدءًا من صفر، تمامًا كما تُرقَّم مواضع المصفوفة. وإذا لم يكن أي يوم بهذا الازدحام، فالإجابة `-1`.

```sather
BIRD_SURVEY::first_busy_day(|3, 0, 7|, 5)
-- => 2
BIRD_SURVEY::first_busy_day(|3, 0, 7|, 9)
-- => -1
```
