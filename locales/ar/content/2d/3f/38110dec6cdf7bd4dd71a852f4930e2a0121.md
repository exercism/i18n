# نبذة

توفر Swift عبارات نقل التحكم لتغيير مسار تنفيذ الحلقات وجمل `switch`. فإلى جانب `return`، تتضمن Swift كلا من `continue` و`break` وتسميات الحلقات و`fallthrough`.

## العبارة `continue`

تخبر عبارة `continue` الحلقةَ بالتوقف عن تنفيذ التكرار الحالي والبدء بالتكرار التالي فورًا. في حلقة `while` أو `repeat-while`، تنتقل مباشرة إلى فحص الشرط. وفي حلقة `for-in`، تنتقل إلى العنصر التالي في المتتالية.

```swift
var count = 1
while count < 6 {
    count += 1
    if count == 4 {
        continue
    }
    print(count)
}

// Prints:
// 2
// 3
// 5
// 6
```

## العبارة `break`

تخرج عبارة `break` من الحلقة أو جملة `switch` بأكملها فورًا. ويستأنف التنفيذ من أول سطر كود بعد الحلقة أو جملة `switch`.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    if !fruit.count.isMultiple(of: 2) {
        break
    }
    print(fruit)
}

// Prints:
// banana
// grapes
```

## العبارات ذات التسميات

في الحلقات المتداخلة، قد ترغب في أن يؤثر `break` أو `continue` في حلقة خارجية بدلًا من الحلقة الأعمق. يمكنك تسمية الحلقة بوضع اسم متبوع بنقطتين رأسيتين قبلها (`labelName:`). ثم يمكنك تمرير هذه التسمية إلى `break` أو `continue`:

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    print("\n--- \(fruit) ---")
    for letter in fruit {
        guard letter != "n" else {
            break outerLoop
        }
        print(letter)
    }
}

// Prints:
// --- banana ---
// b
// a
```

## العبارة `fallthrough`

في Swift، لا تنتقل جمل `switch` إلى الحالة التالية افتراضيًا؛ بل يتوقف التنفيذ تلقائيًا عند نهاية الحالة المطابقة. وإذا أردت صراحةً أن يستمر التنفيذ في الحالة التالية دون تقييم نمطها، فاستخدم الكلمة المفتاحية `fallthrough`:

```swift
let value = 1
switch value {
case 1:
    print("One")
    fallthrough
case 2:
    print("Two")
default:
    break
}

// Prints:
// One
// Two
```
