# مقدمة

تُمثَّل القيم المنطقية في Cairo بالنوع المنطقي المعرَّف مسبقًا `bool`، الذي يمكن أن تأخذ قيمه إما `true` أو `false`.

```rust
let speeding = true;   // Boolean variable 'speeding' set to 'true'
let has_error = false; // Boolean variable 'has_error' set to 'false' 
```

يدعم Cairo ثلاثة عوامل منطقية يمكنها تقييم التعبيرات وصولًا إلى قيم منطقية، فتُرجع إما `true` أو `false`.

| العامل        | ما معناه                                             |
| ----------- | --------------------------------------------- |
| `&&` (و)    | يكون صحيحًا إذا كانت كلتا القضيتين صحيحتين.       |
| `\|\|` (أو) | يكون صحيحًا إذا كانت قضية واحدة على الأقل صحيحة. |
| `!` (لا)    | يكون صحيحًا فقط إذا كانت القضية خاطئة.    |
