# مقدمة

`str` في Python هو [تسلسل غير قابل للتغيير][text sequence] من [نقاط ترميز يونيكود][unicode code points].
وقد تشمل هذه النقاط الحروف وعلامات التشكيل ومحارف التموضع والأعداد ورموز العملات والرموز التعبيرية وعلامات الترقيم ومسافات متنوعة وفواصل الأسطر وغير ذلك.

تنفّذ السلاسل النصية جميع [عمليات التسلسل الشائعة][common sequence operations]، ويمكن التكرار عليها باستخدام الصيغة `for item in <str>` أو `for index, item in enumerate(<str>)`.
ويمكن دمجها باستخدام `<str> + <other str>` أو `<str>.join(<iterable>)`، وتقسيمها باستخدام `<str>.split(<separator>)`، كما توفر خيارات متعددة للتنسيق والتجميع.

وللتعامل مع السلاسل النصية بشكل أوسع، توفر Python مجموعة غنية من [طرق السلاسل النصية][str-methods] التي تساعد في البحث والتنظيف والتحويل والترجمة وغيرها من العمليات.

ولأن السلسلة النصية _غير قابلة للتغيير_، فإن قيمة كائن `str` في الذاكرة لا تتغيّر؛ والطرق التي تبدو وكأنها تعدّل السلسلة النصية تُرجع نسخة جديدة أو مثيلًا جديدًا من كائن `str` هذا.

[str-methods]: https://docs.python.org/3/library/stdtypes.html#string-methods
[text sequence]: https://docs.python.org/3/library/stdtypes.html#text-sequence-type-str
