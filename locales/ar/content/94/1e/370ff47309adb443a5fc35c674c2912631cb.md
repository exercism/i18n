# المصروفات الكبيرة في قاعدة البيانات

## نص المسألة

تحتاج شركة ABC Corp إلى أن تجد اسم وقسم الموظفين الذين لديهم مدفوعات تزيد قيمتها عن مبلغ معيّن (مثل `3000.00`).

أنشئ سجلًا باسم `HighPayment` لإرجاع البيانات المطلوبة. وتعريف السجل كما يلي.

```ballerina
type HighPayment record {
    string name;
    string department;
    decimal amount;
    string reason;
};
```

استخدم عملية `query` في عميل JDBC للحصول على البيانات المطلوبة من قاعدة البيانات.

> ملاحظة: رتّب النتيجة حسب `payment_id` بترتيب تصاعدي.

## تفاصيل قاعدة البيانات

استخدم قاعدة بيانات H2 الموفّرة لحل هذه المسألة.

> ملف قاعدة البيانات النموذجية هو `gofigure.mv.db`، واسم قاعدة البيانات هو `gofigure`. وهو موجود داخل مجلد `db`.

الجداول التالية موجودة بالفعل في قاعدة بيانات H2 النموذجية مع بعض البيانات النموذجية. وفيما يلي أسماء الأعمدة وأنواع البيانات.

**اسم الجدول** : `Employee`

| **الأعمدة:**      | النوع |
| -----------       | ----------- |
| `employee_id`     | عدد صحيح، مفتاح أساسي يتزايد تلقائيًا       |
| `name`            | سلسلة نصية        |
| `city`            | سلسلة نصية        |
| `department`      | سلسلة نصية        |
| `age`             | عدد صحيح        |

**اسم الجدول**: `Payment`

| **الأعمدة:**      | النوع |
| -----------       | ----------- |
| `payment_id`      | عدد صحيح، مفتاح أساسي يتزايد تلقائيًا       |
| `date`            | تاريخ        |
| `amount`          | عدد عشري        |
| `employee_id`     | عدد صحيح        |
| `reason`          | سلسلة نصية        |

* ملف قاعدة البيانات هو `gofigure.mv.db`. استخدم عنوان JDBC بالشكل `jdbc:h2:file:/path/to/db/file`
* اسم المستخدم: `root`
* كلمة المرور: `root`

## القيود

* استخدم ملف قاعدة بيانات H2 الموفّر في مجلد `db` للتحقق من الاستعلامات ومن النموذج في Ballerina
* استخدم أسلوب معاملات اعتماديات maven لإضافة مشغّل قاعدة بيانات H2 كاعتمادية منصة في ملف Ballerina.toml

## بيئة الاختبار

* يمكنك تشغيل الاختبارات باستخدام `bal test`، وستُشغَّل مقابل قاعدة البيانات النموذجية الموفّرة.

## تلميحات

* استخدم وحدة [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc) للتعامل مع قاعدة البيانات
* راجع قسم [المتطلبات المسبقة](https://lib.ballerina.io/ballerinax/java.jdbc/latest) لمعرفة خطوات إضافة مشغّل JDBC كاعتمادية
* استخدم الطريقة البعيدة [query](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-query) لاستعلام البيانات من قاعدة البيانات
* راجع مثال [استعلام بسيط](https://ballerina.io/learn/by-example/mysql-query-operation)
* استخدم نوع [stream](https://ballerina.io/learn/by-example/stream-type) في Ballerina للوصول إلى البيانات
* استخدم عمليات الربط في SQL لإيجاد مجموعة البيانات المطلوبة من قاعدة البيانات
