# مقدمة

## حلقات `for`

عبارة `for` تكرر كتلة من الكود.
ويتحكم سطرها الأول في عدد مرات تكرار الكتلة:

```go
for init; condition; post {
    // loop body
}
```

- تُنفَّذ عبارة **التهيئة** مرة واحدة قبل التكرار الأول. من الشائع تعريف متغير عدّاد تستخدمه الحلقة وتهيئته.
- **الشرط** تعبير منطقي يُقيَّم قبل كل تكرار. وتتوقف الحلقة عندما يُقيَّم هذا الشرط إلى `false`.
- تُنفَّذ عبارة **الخطوة اللاحقة** بعد اكتمال كل تكرار. ويمكن استخدامها لتحديث العدّاد.

لا تُحِط `init; condition; post` بالأقواس الهلالية.
ومع ذلك، فالأقواس المعقوفة التي تحيط بجسم الحلقة مطلوبة دائمًا.

تبدأ هذه الحلقة `i` من `1`، وتطبع القيمة الحالية لـ `i`، وتزيدها من أجل التكرار التالي، وتتوقف عندما تصل `i` إلى `10`:

```go
for i := 1; i < 10; i++ {
    fmt.Println(i)
}
```
