# حول

تكون الدالة [عودية ذيلية][recursion-tc] إذا كان _آخر_ ما تنفذه الدالة هو استدعاء لنفسها.

في كل مرة تُستدعى فيها أي دالة، يُوضع _إطار مكدس_ يحوي متغيراتها المحلية ووسائطها في أعلى [مكدس استدعاء الدوال][call-stack]. وعندما تُرجع الدالة، يُزال إطار المكدس من المكدس.

تتيح الدوال العودية الذيلية [تحسين الاستدعاء الذيّلي][tail-call-optimization] (أو حذف الاستدعاء الذيّلي). وهو تحسين يسمح بإعادة استخدام إطار المكدس الأخير في استدعاء الدالة التالي عندما يكون من المؤكد أن الدالة السابقة لن تحتاجه بعد الآن. وهذا يخفف من المخاوف المتعلقة بتجاوز سعة مكدس استدعاء الدوال، وهي حالة يوجد فيها عدد كبير جدًا من الإطارات على مكدس استدعاء الدوال لدرجة أنه لم تبقَ ذاكرة كافية لإنشاء إطار آخر.

## تحسين الاستدعاء الذيّلي في Elm

في بعض الحالات، يستطيع مترجم Elm أن ينفّذ تلقائيًا تحسين الاستدعاء الذيّلي عند التصريف إلى JavaScript.

يمكن أن يحدث هذا التحسين في دالة عودية عندما تكون آخر عملية في الفرع استدعاءً للدالة نفسها في تطبيق دالة بسيط. لنلقِ نظرة على بعض الأمثلة:

```elm
factorial : Int -> Int
factorial n =
  if n <= 1 then
    n
  else
    n * factorial (n-1)
```

التنفيذ أعلاه ليس عوديًا ذيليًا، لأن آخر عملية في فرع `else` هي عملية ضرب `n *`.

```elm
factorial : Int -> Int
factorial n =
  factorialHelper n n

factorialHelper : Int -> Int -> Int
factorialHelper n resultSoFar =
  if n <= 1 then
    resultSoFar
  else
    factorialHelper (n-1) (n * resultSoFar)
```

التنفيذ أعلاه عودي ذيلي وسيُحسَّن، لأن آخر عملية في فرع `else` هي استدعاء `factorialHelper` لنفسها. ولن يكون هذا ممكنًا لدالة بتوقيع النوع `Int -> Int`، وفي الممارسة العملية يتحقق تحسين الاستدعاء الذيّلي غالبًا عبر تعريف دوال مساعدة.

## حالات خاصة

في بعض الحالات، لا يستطيع المترجم تحسين الدوال العودية، لنلقِ نظرة على بعض الأمثلة.

بينما يكون `f x = f (x - 1)` عوديًا ذيليًا، فإن `f x = (x - 1) |> f` ليس كذلك، لأن تطبيق الدالة `|>` هو آخر عملية ويُعتبر منفصلًا عن `f`. وبالمثل، الدوال التي تنتهي بشروط منطقية مثل `f x = x > 0 || f (x - 1)` ليست عودية ذيلية.

الدالة `f x = if f (x - 1) then 1 else 0` ليست عودية ذيلية، لأن التعبير داخل `if` لا يُعتبر فرعًا. وبالمثل، لن يُحسَّن استدعاء عودي داخل عبارة `case` أيضًا.

الدالة `f x = let y = f (x - 1) in y` ليست عودية ذيلية لأنها تستدعي نفسها داخل عبارة `let`، وهي لا تُعتبر فرعًا. لكن في `f x = let g x = g (x - 1) in g x` تكون الدالة `g` عودية ذيلية وستُحسَّن رغم أنها معرّفة داخل عبارة `let`.

ستُحسَّن الدالة `f x = if x > 0 then f (x + 1) else 1 + f x` _جزئيًا_: يمكن تحسين فرع `then` لكن لا يمكن تحسين فرع `else`. والتحسين الجزئي هو أفضل ما يمكن تحقيقه في بعض الحالات، مثل اجتياز بنى شجرية أو تعريف دوال عودية متزامنة.
