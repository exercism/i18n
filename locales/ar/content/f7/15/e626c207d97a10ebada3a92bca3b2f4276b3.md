# التعليمات

يستمر عملك في _Instruments of Texas_ على آلة حاسبة RPN تجريبية. بنى فريقك بعض النماذج الأولية التي تحتاج إلى فحص شامل، لاختيار أفضل نموذج يمكن إنتاجه بكميات كبيرة.

تريد إجراء نوعين من الفحوصات.

أولًا، فحص الموثوقية الذي سيكتشف المدخلات التي تتعطل عندها الآلة الحاسبة الخاضعة للفحص أو لا تستجيب بسرعة كافية. لعزل الأعطال، يجب تشغيل الحسابات الخاصة بكل مُدخل في عملية منفصلة. يمكن استخدام الربط واعتراض رسائل الخروج في العملية المستدعية لاكتشاف ما إذا كانت العملية الحسابية قد انتهت أم تعطلت.

ثانيًا، فحص الصحة الذي سيتحقق مما إذا كانت النتيجة التي تُرجعها الآلة الحاسبة لمُدخل معين هي كما هو متوقع. الآلات الحاسبة التي اجتازت فحص الموثوقية فقط هي التي ستخضع لفحص الصحة، لذا لا داعي للقلق بشأن التعطل. ومع ذلك، ينبغي تشغيل العمليات بشكل متزامن لتسريع الإجراء، ما يجعلها حالة استخدام مثالية للمهام غير المتزامنة.

## 1. بدء فحص موثوقية لمُدخل واحد

نفّذ الدالة `RPNCalculatorInspection.start_reliability_check/2`. ينبغي أن تأخذ وسيطين: دالة (الآلة الحاسبة) ومُدخلًا للآلة الحاسبة. وينبغي أن تُرجع خريطة تحتوي على المُدخل ومعرّف العملية (PID) للعملية المُنشأة.

ينبغي أن تستدعي العملية المُنشأة دالة الآلة الحاسبة المعطاة بالمُدخل المعطى. وينبغي أن تكون العملية مرتبطة بالعملية المستدعية.

```elixir
RPNCalculatorInspection.start_reliability_check(fn _ -> 0 end, "2 3 +")
# => %{input: "2 3 +", pid: #PID<0.169.0>}
```

## 2. تفسير نتائج فحص الموثوقية

نفّذ الدالة `RPNCalculatorInspection.await_reliability_check_result/2`. ينبغي أن تأخذ وسيطين. الوسيط الأول خريطة تحتوي على مُدخل فحص الموثوقية ومعرّف العملية التي تُجري فحص الموثوقية لهذا المُدخل، كما تُرجعها الدالة `RPNCalculatorInspection.start_reliability_check/2`. والوسيط الثاني خريطة تعمل كمُجمِّع لنتائج فحوصات الموثوقية ذات المدخلات المختلفة.

ينبغي أن تنتظر الدالة رسالة خروج.

إذا استلمت رسالة خروج (`{:EXIT, from, reason}`) بالسبب `:normal` من العملية نفسها التي تُجري فحص الموثوقية، فينبغي أن تُرجع خريطة النتائج مع إضافة القيمة `:ok` تحت المفتاح `input`.

إذا استلمت رسالة خروج بسبب مختلف من العملية نفسها التي تُجري فحص الموثوقية، فينبغي أن تُرجع خريطة النتائج مع إضافة القيمة `:error` تحت المفتاح `input`.

وإذا لم تستلم أي رسائل تطابق هذه المعايير خلال 100 مللي ثانية، فينبغي أن تُرجع خريطة النتائج مع إضافة القيمة `:timeout` تحت المفتاح `input`.

```elixir
# when an exit message is waiting for the process in its inbox
send(self(), {:EXIT, pid, :normal})

RPNCalculatorInspection.await_reliability_check_result(
  %{input: "5 7 -", pid: pid},
  %{}
)

# => %{"5 7 -" => :ok}

# when there are no messages in the process inbox
RPNCalculatorInspection.await_reliability_check_result(
  %{input: "3 2 *", pid: pid},
  %{"5 7 -" => :ok}
)

# => %{"5 7 -" => :ok, "3 2 *" => :timeout}
```

## 3. تشغيل فحص موثوقية متزامن لعدة مدخلات

نفّذ الدالة `RPNCalculatorInspection.reliability_check/2`. ينبغي أن تأخذ وسيطين: دالة (الآلة الحاسبة) ومصفوفة مُدخلات للآلة الحاسبة.

لكل مُدخل في المصفوفة، ينبغي أن تبدأ فحص الموثوقية في عملية جديدة مرتبطة باستخدام `start_reliability_check/2`. ثم، لكل عملية بدأت بهذه الطريقة، ينبغي أن تنتظر نتائجها باستخدام `await_reliability_check_result/2`.

قبل بدء أي عمليات، تحتاج الدالة إلى تعيين علامة للعملية الحالية لاعتراض رسائل الخروج، حتى تتمكن من استلامها. بعد ذلك، ينبغي أن تعيد هذه العلامة إلى قيمتها الأصلية.

ينبغي أن تُرجع الدالة خريطة تحتوي على نتائج فحوصات الموثوقية لجميع المدخلات.

```elixir
fake_broken_calculator = fn input ->
  if String.ends_with?(input, "*"), do: raise("oops")
end

inputs = ["2 3 +", "10 3 *", "20 2 /"]

RPNCalculatorInspection.reliability_check(fake_broken_calculator, inputs)
# => %{
#       "2 3 +" => :ok,
#       "10 3 *" => :error,
#       "20 2 /" => :ok
#     }
```

## 4. تشغيل فحص صحة متزامن لعدة مدخلات

نفّذ الدالة `RPNCalculatorInspection.correctness_check/2`. ينبغي أن تأخذ وسيطين: دالة (الآلة الحاسبة) ومصفوفة مُدخلات للآلة الحاسبة.

لكل مُدخل في المصفوفة، ينبغي أن تبدأ مهمة غير متزامنة تستدعي الآلة الحاسبة بالمُدخل المعطى. ثم، لكل مهمة بدأت بهذه الطريقة، ينبغي أن تنتظر نتائجها لمدة 100 مللي ثانية.

```elixir
fast_cheating_calculator = fn input -> 14 end
inputs = ["13 1 +", "50 2 *", "1000 2 /"]
RPNCalculatorInspection.correctness_check(fast_cheating_calculator, inputs)
# => [14, 14, 14]
```
