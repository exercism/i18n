# مقدمة

يمثّل [النوع `enum`](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/builtin-types/enum) في C# مجموعة ثابتة من الثوابت المسماة (أي التعداد).

عادةً، لا يمكن لعضو واحد في `enum` أن يشير إلا إلى ثابت واحد بالتحديد من تلك الثوابت المسماة. لكن أحيانًا يكون من المفيد الإشارة إلى أكثر من ثابت واحد. وللقيام بذلك، يمكنك إضافة [السمة `Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute) إلى `enum`.

يمكن تعريف تعداد الأعلام على النحو التالي (باستخدام ترميز الأعداد الصحيحة الثنائي `0b`):

```csharp
[Flags]
enum PhoneFeatures
{
    Call = 0b00000001,
    Text = 0b00000010
}
```

إن نسخةً من `PhoneFeatures` قيمتها `0b00000011` يكون فيها العلَمَان `Call` _و_ `Text` مضبوطين.

افتراضيًا، يُستخدم النوع `int` لقيم أعضاء enum. ويمكنك استخدام نوع عدد صحيح مختلف بتحديد النوع في تعريف enum:

```csharp
[Flags]
enum PhoneFeatures : byte
{
    Call = 0b00000001,
    Text = 0b00000010
}
```
