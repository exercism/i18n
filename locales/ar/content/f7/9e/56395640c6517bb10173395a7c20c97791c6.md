# سير العمل

يستخدم GitHub Actions مفهوم _سير العمل_، وهي سكربتات تعمل تلقائيًا كلما وقع حدث معين (مثل دفع `commit`).

يُعرَّف كل سير عمل في GitHub Actions في ملف `.yml` داخل المجلد `.github/workflows`.
لمزيد من المعلومات عن سير العمل، اطّلع على الوثائق التالية:

- [صيغة سير العمل](https://docs.github.com/en/actions/writing-workflows/workflow-syntax-for-github-actions)
- [اختيار وقت تشغيل سير العمل](https://docs.github.com/en/actions/writing-workflows/choosing-when-your-workflow-runs/triggering-a-workflow)
- [اختيار مكان تشغيل سير العمل](https://docs.github.com/en/actions/writing-workflows/choosing-where-your-workflow-runs)
- [اختيار ما يقوم به سير العمل](https://docs.github.com/en/actions/writing-workflows/choosing-what-your-workflow-does)
- [كتابة سير العمل](https://docs.github.com/en/actions/writing-workflows)
- [أفضل الممارسات](/docs/building/github/gha-best-practices)

## سير العمل المشترك

بعض سير العمل مشترك بين المستودعات.

```exercism/caution
تتم مزامنة سير العمل المشترك تلقائيًا (من [مستودع org-wide-files](https://github.com/exercism/org-wide-files/)).
لذا لا ينبغي لك تغيير محتواها يدويًا.
```

### سير العمل العام

- [مزامنة التسميات](/docs/building/tracks/ci/workflows/sync-labels): مزامنة تسميات المستودع من ملف

### سير العمل الخاص بالمسار

- [configlet](/docs/building/tracks/ci/workflows/configlet): يتحقق مما إذا كانت ملفات المسار (الإعداد) مُهيكلة بشكل صحيح، من الناحيتين التركيبية والدلالية
- [لم تتغير ملفات مهمة](/docs/building/tracks/ci/workflows/no-important-files-changed): يعلّق على طلبات السحب التي قد تؤدي إلى إعادة اختبار الحلول الموجودة
- [Test](/docs/building/tracks/new/setup-continuous-integration#h-test-workflow): التحقق من تمارين المسار

### سير العمل الخاص بالأدوات

- [النشر](/docs/building/tracks/ci/workflows/deploy): نشر صورة Docker الخاصة بأدوات المسار إلى Docker Hub وECR

### سير العمل الاختياري

هناك أيضًا بعض سير العمل التي قد تختار المسارات الانضمام إليها:

- [إيقاف مساهمات المجتمع](/docs/building/tracks/ci/workflows/pause-community-contributions): تعليق تلقائي على المشكلات وطلبات السحب الجديدة التي ينشئها مستخدمون ليسوا أعضاء في منظمة Exercism على GitHub
