# مقدمة

## التعبيرات النمطية في JavaScript

[التعبير النمطي][mdn-regular-expressions] (أو Regex) هو تسلسل من المحارف يمكننا استخدامه لاستهداف عناصر معينة في السلاسل النصية والتلاعب بها. وهكذا يمكننا:

- **البحث** عن نص في سلسلة نصية
- **استبدال** سلاسل فرعية في سلسلة نصية
- **استخراج** المعلومات من سلسلة نصية

> 💡 صيغة JavaScript للتعبيرات النمطية جزء من معيار ECMA-262 الخاص باللغة. وهذا يعني أنك لست مضطرًا للقلق بشأن التوافق الخاص بكل متصفح.

## كيف ننشئ التعبيرات النمطية

في JavaScript، يُكتب التعبير النمطي غالبًا بالصيغة `/pattern/modifiers`.

لدينا طريقتان لإنشاء تعبير نمطي:

1. **التعبير النمطي الحرفي**:

```javascript
const regex = /[a-z]/;
```

2. بانية **RegExp**:

```javascript
const regex = new RegExp('[a-z]');
```

في كلتا الحالتين، يُنشئ JavaScript كائنًا من التعبير النمطي. ويُنصح باستخدام أنماط ثابتة مع الصيغة الحرفية بشكل افتراضي.

يمكن استخدام بانية `RegExp` في الحالات التي سيتغير فيها التعبير النمطي أو التي لا نعرفه فيها بعد (مثل قيمة مُدخلة).

## 🏴‍☠️ الأعلام

للتعبيرات النمطية قدرات خارقة اختيارية تُسمى [`flags`][mdn-flags] وتتيح ميزات إضافية.

من أكثرها استخدامًا:

- `/g` - بحث شامل
- `/i` - تجاهل حالة الأحرف
- `/m` - بحث متعدد الأسطر

إليك مثالًا بسيطًا:

```javascript
const re = /home/gi;
const str = 'Home, sweet home.';
const myArray = str.match(re);
console.log(myArray);

// => ["Home", "home"]
```

يسمح لنا المحرف `g` بمطابقة كل التطابقات الممكنة داخل سلسلة نصية. فلولا هذه الميزة، لاستخرجت JavaScript أول تطابق لـ`Home` فقط.

يتيح لنا علم تجاهل حالة الأحرف `/i` مرونة أكبر عند البحث عن نمط. وبذلك لا يهم إن كان ما نبحث عنه مكتوبًا بأحرف `UPPERCASE` أو `lowercase`.

عند استخدام بانية `RegExp`، تختلف صيغة إضافة الأعلام.

```javascript
let regex = /[a-z]/gi; // literal notation
let regex = new RegExp('[a-z]', 'gi'); // constructor with string pattern as first argument
let regex = new RegExp(/[a-z]/, 'gi'); // constructor with regular expression literal as first argument (Starting with ECMAScript 6)
```

## الدوال الأكثر شيوعًا

عندما تُدمج التعبيرات النمطية مع الدوال المدمجة الحالية في JavaScript، نحصل على أساليب قوية للتلاعب بالسلاسل النصية واستخراج البيانات منها.

هذه بعض الدوال الأكثر شيوعًا التي تُستخدم إلى جانب التعبيرات النمطية.

### Test

تُجري الطريقة [test()][mdn-regex-test]] بحثًا عن تطابق بين تعبير نمطي وسلسلة نصية محددة. وتُرجع صحيحًا أو خطأ.

```javascript
const str = 'It is difficult to test if you have a virus';
const result = /virus$/.test(str);

console.log(result);

// => true
```

### Match

باستخدام الطريقة [match()][mdn-regex-match] نحصل على مصفوفة مفيدة يعتمد محتواها على وجود التطابقات التي عثرنا عليها أو غيابها.

وبهذه الطريقة نستطيع أن **نبحث** في أي سلسلة نصية و**نستخرج** منها المعلومات. على سبيل المثال:

```javascript
const funnyQuote =
  'If you see someone crying, ask if it is because of their haircut.';
const regex1 = /someone/;
const regex2 = /happy/;

funnyQuote.match(regex1);
// => ["someone", index: 3, input: "If you see someone crying, ask if it is because of their haircut.", groups: undefined]

funnyQuote.match(regex2);
// => null
```

عند وجود علم البحث الشامل `/g`، فبدلًا من الحصول على التطابق الوحيد مع معلومات مفيدة مثل الفهرس أو المُدخل، تُرجع الطريقة كل التطابقات معروضة في المصفوفة:

```javascript
const funnyQuote =
  'If you see someone crying, ask if it is because of their haircut.';

const regex3 = /if/gi;

funnyQuote.match(regex3);
// => ["If", "if"];
```

### Replace

تتيح لنا الطريقة [replace()][mdn-regex-replace] في JavaScript البحث عن قيمة داخل سلسلة نصية معينة واستبدالها بقيمة جديدة نريدها.

```javascript
string.replace(searchValue, newValue);
```

يمكن أن يكون النمط المستخدم في البحث عن الاستبدال سلسلة نصية واحدة أو تعبيرًا نمطيًا.

```javascript
let string = 'I like dogs!';
let result = string.replace('dogs', 'cats');

let string = 'I would love to travel to Japan';
let result = string.replace(/Japan/g, 'Hawaii');
```

علاوة على ذلك، يمكننا تطبيق دالة على موضع الاستبدال لإجراء تغييرات إضافية على كل قيمة.

```javascript
let text = 'Say hello to the chatbot.';
let result = text.replace(/chatbot|hello/gi, function (word) {
  return word.toUpperCase();
});

// => "Say HELLO to the CHATBOT"
```

### Split

تمثل الطريقة [split()][mdn-regex-split] في JavaScript أسلوبًا مختلفًا لاستخدام السلاسل النصية والتلاعب بها باستخدام التعبيرات النمطية.

وبهذه الطريقة، سنستخدم التعبير النمطي لتقسيم سلسلة نصية معينة عبر التعرف على نمط، مثل `str.split(/[,.\s]/)`. سيُستخدم هذا النمط بوصفه `separator`.

```javascript
const str = 'hello,user.how are.you';

const result = str.split(/[,.\s]/);

console.log(result);
// => ['hello', 'user', 'how', 'are', 'you']
```
