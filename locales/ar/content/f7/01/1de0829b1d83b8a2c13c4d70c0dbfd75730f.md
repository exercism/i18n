# مقدمة

## العودية

القدرة على تعريف شيء ما من خلال نفسه تُسمى العودية. في F#، تظهر العودية غالبًا في الدوال العودية، وهي دوال تستدعي نفسها.

تحتاج الدالة العودية إلى _حالة أساسية_ واحدة على الأقل وإلى _حالة عودية_ واحدة على الأقل. تُرجع _حالة أساسية_ قيمة دون استدعاء الدالة مرة أخرى. تستدعي _حالة عودية_ الدالة مرة أخرى، مع تعديل المدخل بحيث يطابق الحالة الأساسية في مرحلة ما.

تُعرَّف الدوال العودية مثل الدوال العادية، ولكن باستخدام المعدِّل `rec`. بدون هذا المعدِّل، _لن_ تتمكن الدالة من استدعاء نفسها، وأي محاولة لفعل ذلك ستؤدي إلى خطأ في الترجمة. لذلك يجب اختيار العودية صراحةً.

```fsharp
let rec factorial x =
    // Base case
    if x = 1 then
        1
    // Recursive case
    else
        x * factorial (x - 1)
```

يدعم F# أيضًا الأنواع العودية من خلال أنواع الاتحاد المميز. النوع العودي من نوع الاتحاد المميز تكون فيه حالة واحدة أو أكثر من حالاته تشير إلى نوع الاتحاد المميز نفسه في بياناتها. مثل الدوال العودية، يجب أن يكون للأنواع العودية حالة أساسية. وعلى عكس الدوال العودية، لا تستخدم الأنواع العودية الكلمة المفتاحية `rec`.

```fsharp
type RussianDoll =
    | Doll                 // Base case
    | Layer of RussianDoll // Recursive case
```
