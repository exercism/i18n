# التعليمات

أنت تدير متجر أزياء على الإنترنت. كل عنصر في مخزونك عبارة عن
مصفوفة من عنصرين `{ name price }`، والمخزون كله مصفوفة من العناصر.

السعر المفقود يُسجّل بـ `f`.

## 1. رتّب المخزون حسب السعر

عرّف `sort-by-price` بحيث تُرجع مصفوفة جديدة تحتوي على العناصر مرتّبة حسب
السعر، تصاعديًا.

```factor
{ { "Maxi Brown Dress" 65 } { "Red Skirt" 50 } { "Bamboo Socks Cats" 20 } }
sort-by-price .
! => { { "Bamboo Socks Cats" 20 } { "Red Skirt" 50 } { "Maxi Brown Dress" 65 } }
```

## 2. اعثر على العناصر التي ليس لها سعر محدد

عرّف `with-missing-price` بحيث تُرجع مصفوفة تحتوي فقط على العناصر
التي سعرها `f`.

```factor
{ { "Black T-shirt" 40 } { "Denim Pants" f } { "Orange T-shirt" 40 } }
with-missing-price .
! => { { "Denim Pants" f } }
```

## 3. عُدّ العناصر الغالية

عرّف `expensive-items` بحيث تأخذ مخزونًا وحدًا سعريًا،
وتُرجع عدد العناصر التي تكلّف أكثر من الحد تمامًا.

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } { "Dress" 80 } }
50 expensive-items .
! => 2

{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } { "Dress" 80 } }
0 expensive-items .
! => 4
```

## 4. اعثر على أرخص عنصر

عرّف `cheapest-item` بحيث تُرجع العنصر ذا السعر الأدنى.
العناصر التي ليس لها سعر (`f`) لن تظهر في المدخلات.

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } } cheapest-item .
! => { "Hat" 25 }
```

## 5. اجمع كل الأسعار

عرّف `total-price` بحيث تُرجع مجموع كل الأسعار. العناصر التي
ليس لها سعر (`f`) لن تظهر في المدخلات.

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } } total-price .
! => 195
```

## 6. نسّق العنصر على شكل بطاقة سعر

عرّف `format-price-tag` بحيث تُرجع سلسلة نصية بالصيغة `"name: $price"`
لعنصر ما. العناصر التي ليس لها سعر (`f`) لن تظهر هنا.

```factor
{ "Skirt" 50 } format-price-tag .
! => "Skirt: $50"
```
