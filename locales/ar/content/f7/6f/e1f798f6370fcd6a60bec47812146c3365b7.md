# الاختبارات

لتشغيل الاختبارات، اتبع الخطوات التالية:

- انتقل إلى مجلد التمرين (مثل `~/Exercism/hello-world`).
- ابدأ جلسة `jconsole` (مثلًا بكتابة `jconsole` أو `ijconsole`) في الطرفية.
- حمّل ملف حلّك (مثل `load 'hello-world.ijs'`)
- حمّل إطار اختبار الوحدات بكتابة `load  'general/unittest'`
- اختبر حلّك بكتابة `unittest 'test.ijs'`.
<br></br>
- بدلًا من ذلك، يمكنك تشغيل الاختبارات في سطر واحد هكذا: `jconsole -js "load 'hello-world.ijs'" "echo unittest 'test.ijs'" "exit 0"`.

## الاختبارات المتخطّاة

في البداية، سيُفعّل الاختبار الأول فقط.
يشجّعك الأسلوب على حلّ التمرين خطوة بخطوة.
يتضمّن كل اختبار اسمًا فوق تعريفه، ينتهي بـ _'\_ignore'_.
لتشغيل الاختبار، غيّر قيمته إلى 0.

### مثال:

```
    leap_test_02_ignore=: 1 NB. Change this value to 0 to run this test
    test_leap_test_02  =: monad define
    ...                     NB. test definitions
    )
```
