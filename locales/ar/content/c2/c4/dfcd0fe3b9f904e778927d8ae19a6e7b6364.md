# مقدمة

[`string`][ref-string] في Kotlin هي سلسلة نصية غير قابلة للتغيير من محارف Unicode.

[`Immutable`][wiki-immutable] تعني أن أي عملية على سلسلة نصية يجب أن ترجع سلسلة نصية جديدة: فلا يمكن أن تتغير السلسلة النصية الأصلية أبدًا.

[`Unicode`][wiki-unicode] تعني أنه يمكن تمثيل معظم أنظمة الكتابة في العالم، لكن (على عكس اللغات الأقدم مثل C) لا توجد مطابقة بنسبة 1:1 بين المحارف والبايتات.

عادةً ما تُحاط السلسلة النصية بعلامتَي اقتباس مزدوجتين `" "`.

بعض المحارف تحتاج إلى تهريب: `\'` و`\\`، إضافة إلى المحارف غير الطابعة المعتادة مثل `\t` (جدولة) و`\n` (سطر جديد).

```kotlin
val s = "Escape apostrophe \' and backslash \\."
// Escape apostrophe ' and backslash \.
```

السلاسل النصية متعددة الأسطر تُحاط بثلاث علامات اقتباس مزدوجة، ويمكن أن تحتوي على أي نص (دون حاجة إلى التهريب).

```kotlin
val multi = """I'm a
    multi-line
    string with special characters \ \t """
//I'm a
//    multi-line
//    string with special characters  \ \t 
```

استخدم [trimIndent][trimIndent-doc] لإزالة الإزاحة المشتركة من الأسطر.
وهذا مفيد لتنسيق السلسلة النصية:

```kotlin
val multi = """
    I'm a
      multi-line
    string""".trimIndent()

//I'm a
//  multi-line
//string
```

بدلًا من ذلك، يتيح لك [trimMargin][trimMargin-doc] تحديد فاصل.
حينها يبدأ كل سطر في `String` بعد الفاصل.
الفاصل الافتراضي هو `|`، لكن يمكنك تحديد فاصل مختلف كمعامل.
على سبيل المثال:

```kotlin
val multi = """
    |I'm a
    |  multi-line
    |string""".trimMargin()

//I'm a
//  multi-line
//string

val multi2 = """
    start>I'm a
    start>  multi-line
    start>string""".trimMargin("start>")

//I'm a
//  multi-line
//string
```

يمكن دمج السلاسل النصية باستخدام `+`، لكن من الأفضل أن يقتصر ذلك على الحالات القصيرة والبسيطة.
وهناك خيارات أخرى، وغالبًا ما تكون أفضل.

## قوالب السلاسل النصية

يشير هذا إلى ما تسميه بعض اللغات الأخرى "الإقحام".

إذا احتوت سلسلة نصية على علامة الدولار `$` متبوعة بمعرّف، أو على أقواس معقوفة (`{expression}`) تحيط بتعبير، فيُستبدَل ذلك بالقيمة أو بنتيجة التعبير على التوالي.

```kotlin
val x = 42
val st = "x is $x, x squared is {x * x}"
// x is 42, x squared is 1764
```

تُلزم الأقواس المعقوفة `{ }` حول التعبيرات عندما يكون التحليل غامضًا لولا وجودها.

بشكل عام، يُعد استخدام قوالب السلاسل النصية وسيلة أكثر كفاءة وأقرب إلى أسلوب اللغة لدمج السلاسل النصية من استخدام `+`.

## دوال السلاسل النصية

يوفر Kotlin _العديد_ من [`functions`][ref-string-functions] للتعامل مع السلاسل النصية.

في الغالب تكون هذه [`extensions functions`][ref-extensions] وليست أعضاء في صنف `String`، مع أن لذلك أثرًا ضئيلًا على طريقة استخدامنا لها.

~~~~exercism/note
صفحات [التوثيق][ref-string-functions] المعقدة نوعًا ما في Kotlin تخفي دوال الامتداد في العرض الافتراضي.
احرص على النقر على `Members & Extensions` لتوسيع هذا القسم.

[ref-string-functions]: https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/
~~~~

تعرض الأمثلة التالية مجموعة صغيرة فحسب مما هو متاح:

```kotlin
val str = "Hello World!"

str.length              // => 12 (a property, not a function)
str.elementAt(6)        // => W
str.elementAtOrNull(20) // => null (index out of range)
str.substring(6, 11)    // => "World"
str.substringAfter(" ") // => "World!"

str.lowercase()         // => "hello world!"
str.uppercase()         // => "HELLO WORLD!"

str.startsWith("Hel")   // => true
str.endsWith("xyz")     // => false
str.indexOf("0")        // => 4

str.toCharArray()       // => [H, e, l, l, o,  , W, o, r, l, d, !]
"42".toInt() + 1        // => 43  (parsing; see also toFloat)

"Howdy!  ".trim()       // => "Howdy"
```
