# مقدمة

لنبدأ رحلة C++ بالمتغيرات واستدعاءات الدوال والتعليقات.

## التعليقات

تأتي التعليقات على نوعين: أحادية السطر ومتعددة الأسطر.
كل ما يأتي بعد `//` في السطر نفسه يتجاهله المترجم.
تُعرف التعليقات متعددة الأسطر أيضًا بتعليقات نمط C.
وهي محاطة بـ `/*` و `*/`.
وأي شيء يقع بينهما سيُتجاهل أيضًا.

## المتغيرات

C++ لغة ذات أنواع.
يجب معرفة جميع الأنواع في وقت التصريف، وتحتاج عمومًا إلى ذكرها صراحةً.
لا يمكن أن يتغير نوع المتغير.
يمكن الإعلان عن متغير صحيح باسم `years` هكذا:

```cpp
int years;
```

من الممارسات الجيدة تهيئة المتغيرات عند الإعلان عنها.
وتوفر C++ آليات مختلفة لفعل ذلك.
الصيغة ذات الأقواس المعقوفة أقرب إلى C++ الحديثة، لكن الصيغة ذات علامة التساوي شائعة جدًا أيضًا.

```cpp
int tomatoes{80};
int potatoes = 40;
```

~~~~exercism/caution
تسمح C++ فعلًا باستخدام متغيرات غير مهيّأة.
وما لم تُضبط قيمة المتغير عمدًا، فإنها غير معرّفة وقد تحتوي على أي شيء.
لتجنّب أخطاء الاستخدام قبل الضبط والسلوك غير المعرّف، يُنصح بـ**التهيئة دائمًا**.
قد يؤدي السلوك غير المعرّف إلى انهيار برنامجك في أسوأ لحظة ممكنة، بعد أن كان يعمل بشكل جيد من قبل.
لا يمكن التأكيد على هذا بما يكفي: تجنّب السلوك غير المعرّف بأي ثمن.
~~~~

## العمليات الحسابية

يمكن أن تكون عوامل الحساب مثل `*` و `+` و `-` جزءًا من تعبير مثل `3 * 2` أو `tomatoes + potatoes`.

## تحديث المتغيرات

يمكنك إعادة إسناد قيم للمتغيرات، ما دامت تحافظ على نوعها:

```cpp
tomatoes = tomatoes - 5; // tomatoes is now 75
potatoes = (32 * 2) + 11; // potatoes is now 75 as well
```

## الدوال

للدوال اسم ونوع إرجاع وقائمة معاملات (قد تكون فارغة).
مثال على دالة باسم `always_fortyseven` تُرجع دائمًا 47 سيبدو هكذا:

```cpp
int always_fortyseven() {
    return 47;
}
```

وهذه `vip_fee`، ولها معامل واحد:
```cpp
int vip_fee(int standard_fee) {
    /*
    vip_fee calculates the vip fee based on the standard_fee.
    */
    int vip_multi{3};
    return standard_fee * vip_multi;
}
```

أو `total_fee`، وهي دالة بثلاثة معاملات تستدعي دالة أخرى.

```cpp
int total_fee(int vips, int adults, int kids) {
    /*
    total_fee calculates the total price for a group of VIP and adult guests with kids.
    Kids get a flat discount on the standard fee.
    VIP guest fees are calculated by calling vip_fee.
    */
    int standard_fee{30};
    int kids_discount{15};

    int kids_total_fee = kids  * (standard_fee - kids_discount);
    int vips_total_fee = vips * vip_fee(standard_fee);
    int adult_total_fee = adults * standard_fee;

    return vips_total_fee + adult_total_fee + kids_total_fee;
}
```

لا تُرجع الدوال في C++ قيمة العبارة الأخيرة كما في بعض اللغات الأخرى.
الكلمة المفتاحية `return` ضرورية كي يُصرّف الكود.

### المسافات البيضاء

تُستخدم المسافات البيضاء لتنسيق الكود المصدري، وهي تشمل المسافات ومحارف الجدولة والأسطر الجديدة.
ولأن المترجم يتجاهل المسافات البيضاء غير الضرورية، يمكنك استخدامها لتنظيم الكود.
والاستخدام الذكي للمسافات البيضاء يمكن أن يحسّن وضوح الكود.
هناك معايير تنسيق مختلفة، لكنها كلها عرفية ولا يفرضها المترجم.

```cpp
// Formatting makes it easier to find bugs

int eggs_yolks =  3;
int      yeast = 15;

int flour=500;int sugar=200;// compact, but difficult to read
```
