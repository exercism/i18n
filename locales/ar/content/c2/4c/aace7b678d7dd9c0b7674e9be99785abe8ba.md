# مقدمة

Elixir لغة ديناميكية الأنواع، وهذا يعني أنها لا توفر فحوصات للأنواع وقت التصريف. ومع ذلك، يمكن استخدام مواصفات الأنواع كشكل من أشكال التوثيق.

يمكن إضافة مواصفة نوع إلى دالة باستخدام سمة الوحدة `@spec` مباشرةً قبل تعريف الدالة. يأتي بعد `@spec` اسم الدالة وقائمة بأنواع جميع وسائطها، بين الأقواس الهلالية، مفصولة بفواصل. ويُفصل نوع القيمة المُرجَعة عن وسائط الدالة بنقطتين مزدوجتين `::`.

```elixir
@spec longer_than?(String.t(), non_neg_integer()) :: boolean()
def longer_than?(string, length), do: String.length(string) > length
```

## الأنواع

من أكثر الأنواع استخدامًا:

- القيم المنطقية: `boolean()`
- السلاسل النصية: `String.t()`
- الأعداد: `integer()`, `non_neg_integer()`, `pos_integer()`, `float()`
- المصفوفات: `list()`
- قيمة من أي نوع: `any()`

يمكن أيضًا أن تكون بعض الأنواع مُعامَلة، فمثلًا `list(integer)` هي مصفوفة من الأعداد الصحيحة.

يمكن أيضًا استخدام القيم الحرفية كأنواع.

يمكن كتابة اتحاد أنواع باستخدام الشريط العمودي `|`. فمثلًا، `integer() | :error` تعني إما عددًا صحيحًا وإما القيمة الحرفية للذرّة `:error`.

تجد قائمة كاملة بجميع الأنواع في ["قسم Typespecs" في التوثيق الرسمي][types].

## تسمية الوسائط

يمكن أيضًا تسمية الوسائط في مواصفة النوع، وهذا مفيد للتمييز بين عدة وسائط من النوع نفسه. يأتي اسم الوسيط، متبوعًا بنقطتين مزدوجتين، قبل نوع الوسيط.

```elixir
@spec to_hex({hue :: integer, saturation :: integer, lightness :: integer}) :: String.t()
```

## الأنواع المخصصة

لا تقتصر مواصفات الأنواع على الأنواع المدمجة فقط. يمكن تعريف أنواع مخصصة باستخدام سمة الوحدة `@type`. يبدأ تعريف النوع المخصص باسم النوع، متبوعًا بنقطتين مزدوجتين ثم النوع نفسه.

```elixir
@type color :: {hue :: integer, saturation :: integer, lightness :: integer}

@spec to_hex(color()) :: String.t()
```

يمكن استخدام النوع المخصص من الوحدة نفسها التي عُرِّف فيها، أو من وحدة أخرى.
