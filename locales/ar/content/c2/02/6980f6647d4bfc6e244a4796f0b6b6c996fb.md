# التثبيت

سنستخدم *PolyML* كتنفيذٍ للغة Standard ML.

إذا كنت تستخدم Windows، فيمكنك تنزيل برنامج تثبيت من [https://github.com/polyml/polyml/releases](https://github.com/polyml/polyml/releases).
أما التعليمات العامة لأنظمة Linux/OS X/Free BSD فتجدها على [https://github.com/polyml/polyml#readme](https://github.com/polyml/polyml#readme).

وإذا أردت التثبيت من المصدر، فالعملية سهلة جدًا:

```sh
$ git clone https://github.com/polyml/polyml.git
$ cd polyml
$ ./configure
```

وإذا أردت تثبيته في موقع مخصص، مثل `$HOME/.local` على سبيل المثال:

```sh
$ ./configure --prefix=$HOME/.local
```

الخطوة الأخيرة:

```sh
$ make compiler
$ make install
```

تأكد من أنه ثُبّت بشكل صحيح:

```sh
$ poly
```

إذا ظهر لك المفسّر، فأنت جاهز!
وإن لم يظهر، فغالبًا ستحتاج إلى إضافة `$HOME/.local/bin` (أو `<you prefix>/bin`) إلى `$PATH`.
