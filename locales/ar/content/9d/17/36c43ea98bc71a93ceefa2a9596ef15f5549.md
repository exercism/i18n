# مقدمة

عند نمذجة بيانات لا يمكنها أن تأخذ إلا مجموعة محددة من الحالات الممكنة، مثل أيام الأسبوع أو اتجاهات البوصلة أو أزرار وحدة التحكم، فإن الأنواع الأساسية مثل `Int` أو `String` لها عيوب كبيرة.
مع الأعداد الصحيحة أو السلاسل النصية، يجب أن يتحقق الكود باستمرار من القيم غير الصالحة (مثل رمز حالة `999` أو خطأ كتابي مثل `"leftt"`)، ولا يستطيع القرّاء من البشر معرفة ما الذي تمثله الأرقام بسهولة.

يحل Swift هذه المشكلة باستخدام [_التعدادات_][enumerations] (وكثيرًا ما تُختصر إلى *enums*).
يُعرّف `enum` نوعًا مشتركًا لمجموعة من القيم المرتبطة المسماة. ولأن المترجم يعرف كل الحالات الممكنة مسبقًا، فإنه يستطيع التحقق من دقة كودك واكتماله في وقت الترجمة.
ويمكن أن تحتوي التعدادات أيضًا على طرق ومهيّئات وخصائص محسوبة.

## تعريف التعدادات

تُعرّف التعدادات باستخدام الكلمة المفتاحية `enum` متبوعةً باسم النوع، مع سرد حالاتها داخل الأقواس المعقوفة.
بحسب اصطلاح Swift، يُكتب اسم النوع بـ `UpperCamelCase`، بينما تُكتب كل حالة بـ `lowerCamelCase`:

```swift
enum NESButton {
    case up
    case down
    case left
    case right
    case a
    case b
    case select
    case start
}
```

يمكنك أيضًا تعريف عدة حالات في سطر واحد تفصل بينها فواصل:

```swift
enum NESButton {
    case up, down, left, right, a, b, select, start
}
```

للإشارة إلى حالة تعداد، اكتب اسم نوع التعداد، ثم نقطة (`.`)، ثم اسم الحالة. وبمجرد أن يُعرف النوع أو يستطيع المترجم استنتاجه، يمكنك حذف اسم النوع واستخدام صيغة النقطة الأقصر:

```swift
var lastPressed = NESButton.up

// Swift infers the type, so you can omit the type name:
lastPressed = .down

let konamiCode: [NESButton] = [.up, .up, .down, .down, .left, .right, .left, .right, .b, .a]
```

## الطرق والمهيّئات

يمكن للتعدادات أن تعرّف طرقًا ومهيّئات مخصصة تمامًا مثل الأصناف والبنى. وداخل طريقة في تعداد، يشير `self` إلى قيمة الحالة الحالية:

```swift
enum Coin {
    case heads
    case tails

    init(_ value: Int) {
        if value.isMultiple(of: 2) {
            self = .heads
        } else {
            self = .tails
        }
    }

    func flip() -> Coin {
        switch self {
        case .heads: return .tails
        case .tails: return .heads
        }
    }
}

let tails = Coin(13)     // .tails
let heads = Coin(0)      // .heads
let flipped = heads.flip() // .tails
```

## القيم الخام

يمكن أن تُملأ حالات التعداد مسبقًا بقيم افتراضية تُسمى [_القيم الخام_][raw-values].
يجب أن تشترك جميع القيم الخام في التعداد في النوع نفسه (مثل `Int` أو `String` أو `Character`):

```swift
enum NESButton: Character {
    case up = "⬆️"
    case down = "⬇️"
    case left = "⬅️"
    case right = "➡️"
    case a = "🅰️"
    case b = "🅱️"
    case select = "✅"
    case start = "🚦"
}

print(NESButton.left.rawValue) // Prints "⬅️"
```

يمكنك تهيئة تعداد من قيمة خام باستخدام `init(rawValue:)`. ولأنه قد تُمرَّر قيمة خام غير صالحة، فإن هذا المهيّئ يُرجع قيمة اختيارية:

```swift
let upButton = NESButton(rawValue: "⬆️") // Optional(NESButton.up)
let invalid = NESButton(rawValue: "🙄")  // nil
```

يستطيع Swift إسناد القيم الخام تلقائيًا لتعدادات `String` و `Int`:

- في تعدادات `String`، تكون القيمة الخام لكل حالة هي اسم الحالة افتراضيًا.
- في تعدادات `Int`، تبدأ القيم الخام من `0` وتزداد بمقدار 1 ما لم يُحدَّد خلاف ذلك.

```swift
enum Planet: Int {
    case mercury = 1, venus, earth, mars
}

print(Planet.earth.rawValue) // Prints 3
```
