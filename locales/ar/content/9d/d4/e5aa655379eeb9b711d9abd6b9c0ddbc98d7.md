# التعليمات

في هذا التمرين، ستُنفّذ وسيلة لتتبّع أعلى النتائج للعبة الأكثر شعبية في صالة الألعاب في حيّك.

## 1. أضف لاعبين إلى لوحة النتائج العليا

لإضافة لاعب إلى لوحة النتائج العليا، عرّف طريقتين باسم `add_player!` تأخذان الوسائط التالية:

- الوسيط الأول هو قاموس النتائج.
- الوسيط الثاني هو اسم اللاعب في صورة سلسلة نصية.
- الوسيط الثالث هو النتيجة في صورة عدد صحيح.
  هذا الوسيط اختياري؛ فعندما لا تُعطى قيمة، يجب ضبط النتيجة على 0.

```julia-repl
julia> scores = Dict{String, Int}()
Dict{String, Int64}()

julia> add_player!(scores, "Liselot", 486373)
Dict{String, Int64} with 1 entry:
  "Liselot" => 486373

julia> add_player!(scores, "Éimhín")
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0
```

## 2. أزل اللاعبين من لوحة النتائج

لإزالة لاعب من لوحة النتائج العليا، عرّف `remove_player!`، وهي تأخذ وسيطين:

- الوسيط الأول هو قاموس النتائج.
- الوسيط الثاني هو اسم اللاعب في صورة سلسلة نصية.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> remove_player!(scores, "Liselot")
Dict{String, Int64} with 1 entry:
  "Éimhín" => 0
```

## 3. حدّث نتيجة لاعب

لتحديث نتيجة لاعب باستبدال النتيجة السابقة، عرّف `update_score!`، وهي تأخذ 3 وسائط:

- الوسيط الأول هو قاموس النتائج.
- الوسيط الثاني هو اسم اللاعب في صورة سلسلة نصية، وهو اللاعب الذي تريد تحديث نتيجته.
- الوسيط الثالث هو النتيجة التي تريد ضبط النتيجة العليا المخزّنة عليها.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> update_score!(scores, "Éimhín", 89479) # TODO: Should this return the dict?
89479

julia> scores
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 89479
```

## 4. أعد ضبط نتيجة لاعب

لإعادة ضبط نتيجة لاعب، عرّف `reset_score!`، وهي تأخذ وسيطين:

- الوسيط الأول هو قاموس النتائج.
- الوسيط الثاني هو اسم اللاعب في صورة سلسلة نصية، وهو اللاعب الذي تريد إعادة ضبط نتيجته.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> reset_score!(scores, "Liselot") # TODO: Should this return the dict?
0

julia> scores
Dict{String, Int64} with 2 entries:
  "Liselot" => 0
  "Éimhín"  => 0
```

## 5. احصل على مصفوفة اللاعبين

للحصول على مصفوفة اللاعبين، عرّف `players`، وهي تأخذ وسيطًا واحدًا:

- الوسيط الأول هو قاموس النتائج.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> players(scores)
2-element Vector{String}:
 "Liselot"
 "Éimhín"
```
