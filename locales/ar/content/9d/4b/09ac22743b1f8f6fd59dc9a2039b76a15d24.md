# مقدمة

## التعبيرات النمطية في JavaScript

التعبير النمطي [Regular Expression][mdn-regular-expressions] (أو Regex) هو متتالية من المحارف يمكننا استخدامها لاستهداف عناصر معينة في السلاسل النصية والتلاعب بها. وبهذا يمكننا:

- **البحث** عن نص في سلسلة نصية
- **الاستبدال** لسلاسل نصية فرعية في سلسلة نصية
- **الاستخراج** للمعلومات من سلسلة نصية

> 💡 صيغة التعبيرات النمطية في JavaScript جزء من معيار ECMA-262 الخاص باللغة. هذا يعني أنك لا تحتاج إلى القلق بشأن التوافق مع متصفح بعينه.

## كيفية إنشاء التعبيرات النمطية

في JavaScript، تُكتب التعبيرات النمطية غالبًا بالصيغة `/pattern/modifiers`.

ولدينا طريقتان لإنشاء تعبير نمطي:

1. **التعبير النمطي الحرفي**:

```javascript
const regex = /[a-z]/;
```

2. البانية **RegExp**:

```javascript
const regex = new RegExp('[a-z]');
```

في كلتا الحالتين، تُنشئ JavaScript كائنًا من التعبير النمطي. ويُوصى باستخدام أنماط غير قابلة للتغيير مع اعتماد الصيغة الحرفية كخيار افتراضي.

يمكن استخدام البانية `RegExp` في الحالات التي سيتغير فيها التعبير النمطي أو التي لا نعرفه فيها بعد (مثل مُدخل).

## 🏴‍☠️ الأعلام

تمتلك التعبيرات النمطية قوى خارقة اختيارية تُسمى [`flags`][mdn-flags] تتيح ميزات إضافية.

ومن أكثرها استخدامًا:

- `/g` - البحث الشامل
- `/i` - تجاهل حالة الأحرف
- `/m` - البحث متعدد الأسطر

وإليك مثالًا بسيطًا:

```javascript
const re = /home/gi;
const str = 'Home, sweet home.';
const myArray = str.match(re);
console.log(myArray);

=> // ["Home", "home"]
```

يسمح لنا المحرف `g` بتحليل جميع المطابقات الممكنة داخل السلسلة النصية. فبدون هذه الميزة، كانت JavaScript ستستخرج أول تطابق `Home` فقط.

يتيح لنا علم تجاهل حالة الأحرف `/i` مرونة أكبر عند البحث عن نمط. وبذلك لا يهم إن كان ما نبحث عنه بحروف `UPPERCASE` أو `lowercase`.

عند استخدام البانية `RegExp`، تختلف صيغة إضافة الأعلام.

```javascript
let regex = /[a-z]/gi; // literal notation
let regex = new RegExp('[a-z]', 'gi'); // constructor with string pattern as first argument
let regex = new RegExp(/[a-z]/, 'gi'); // constructor with regular expression literal as first argument (Starting with ECMAScript 6)
```

## الدوال الأكثر شيوعًا

عندما تُدمج التعبيرات النمطية مع الدوال المدمجة الحالية في JavaScript، نحصل على أساليب قوية للتلاعب بالبيانات واستخراجها من السلاسل النصية.

هذه بعض الدوال الأكثر شيوعًا التي تُستخدم إلى جانب التعبيرات النمطية.

### الاختبار

تُنفّذ الطريقة [test()][mdn-regex-test] بحثًا عن تطابق بين تعبير نمطي وسلسلة نصية محددة. وتُرجع صحيحًا أو خطأ.

```javascript
const str = 'It is difficult to test if you have a virus';
const result = /virus$/.test(str);

console.log(result);

// => true
```

### المطابقة

باستخدام الطريقة [match()][mdn-regex-match]، نحصل على مصفوفة مفيدة يعتمد محتواها على وجود المطابقات التي وُجدت أو غيابها.

وبهذا نستطيع أن **نبحث** و**نستخرج** معلومات من أي سلسلة نصية. على سبيل المثال:

```javascript
const funnyQuote =
  'If you see someone crying, ask if it is because of their haircut.';
const regex1 = /someone/;
const regex2 = /happy/;

funnyQuote.match(regex1);
// => ["someone", index: 11, input: "If you see someone crying, ask if it is because of their haircut.", groups: undefined]

funnyQuote.match(regex2);
// => null
```

عند وجود علم البحث الشامل `/g`، بدلًا من الحصول على المطابقة الوحيدة مع معلومات مفيدة مثل الفهرس أو المُدخل، تُرجع الطريقة جميع الحالات الظاهرة في المصفوفة:

```javascript
const funnyQuote =
  'If you see someone crying, ask if it is because of their haircut.';

const regex3 = /if/gi;

funnyQuote.match(regex3);
// => ["If", "if"];
```

### الاستبدال

تتيح لنا الطريقة [replace()][mdn-regex-replace] في JavaScript البحث عن قيمة داخل سلسلة نصية معينة واستبدالها بقيمة جديدة مرغوبة.

```javascript
string.replace(searchValue, newValue);
```

يمكن أن يكون النمط المستخدم في البحث والاستبدال سلسلة نصية واحدة أو تعبيرًا نمطيًا.

```javascript
let string = 'I like dogs!';
let result = string.replace('dogs', 'cats');

let string = 'I would love to travel to Japan';
let result = string.replace(/Japan/g, 'Hawaii');
```

علاوة على ذلك، يمكننا تمرير دالة في موضع الاستبدال لإجراء تغييرات إضافية على كل قيمة.

```javascript
let text = 'Say hello to the chatbot.';
let result = text.replace(/chatbot|hello/gi, function (word) {
  return word.toUpperCase();
});
// => "Say HELLO to the CHATBOT"
```

### التقسيم

تمثّل الطريقة [split()][mdn-regex-split] في JavaScript أسلوبًا مختلفًا لاستخدام السلاسل النصية والتلاعب بها باستخدام التعبيرات النمطية.

وبهذا، سنستخدم التعبير النمطي لتقسيم سلسلة نصية معينة عبر التعرف على نمط، مثل `str.split(/[,.\s]/)`. وسيُستخدم هذا النمط كـ `separator`.

```javascript
const str = 'hello,user.how are.you';

const result = str.split(/[,.\s]/);

console.log(result);
// => ['hello', 'user', 'how', 'are', 'you']
```
