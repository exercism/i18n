# التعليمات

في هذا التمرين، ستكتب كودًا يساعد شركة لافتات على إنشاء رسائل مخصصة للافتاتها.

## 1. أنشئ مجموعة من السلاسل النصية المفيدة

عرّف السلاسل النصية الثابتة التالية التي ستُستخدم لإنشاء اللافتات:

- `birthday`: يحمل هذا الثابت القيمة "Birthday"
- `valentine`: يحمل هذا الثابت القيمة "Valentine's Day"
- `anniversary`: يحمل هذا الثابت السلسلة النصية "Anniversary"

## 2. أنشئ مجموعة من المحارف المفيدة

عرّف المحارف الثابتة التالية التي ستُستخدم لإنشاء اللافتات:

- `space`: يحمل هذا الثابت القيمة " " (مسافة واحدة)
- `exclamation`: يحمل هذا الثابت القيمة "!"

## 3. اجمع العبارات لبناء الرسائل

نفّذ الدالة `buildSign(for:name:)` التي تأخذ الوسيط `for` الذي يحمل إحدى السلاسل النصية الثلاث التي عرّفتها في المهمة الأولى، والوسيط `name` وهو سلسلة نصية تحمل اسم الشخص التي صُنعت اللافتة من أجله.
استخدم دمج السلاسل النصية لبناء رسالة اللافتة، وتذكّر إعادة استخدام الثوابت المعرّفة مسبقًا.
ينبغي أن تُرجع الدالة رسالة اللافتة كسلسلة نصية.

```swift
buildSign(for: birthday, name: "Otto")
// returns "Happy Birthday Otto!"

buildSign(for: anniversary, name: "Valentina")
// returns "Happy Anniversary Valentina!"
```

## 4. ابنِ لافتة تخرج

نفّذ الدالة `graduationFor(name:year:)` التي تأخذ الوسيط `name` وهو سلسلة نصية تحمل اسم الشخص التي صُنعت اللافتة من أجله، والوسيط `year` وهو عدد صحيح يحمل السنة التي يتخرّج فيها الشخص.
استخدم القوالب النصية لبناء رسالة اللافتة.
ينبغي أن تُرجع الدالة رسالة اللافتة كسلسلة نصية.

```swift
graduationFor(name: "Padma", year: 2023)
// returns "Congratulations Padma!\nClass of 2023"
```

## 5. احسب تكلفة اللافتة

نفّذ الدالة `costOf(sign:)` التي تأخذ الوسيط `sign` وهو سلسلة نصية تحمل رسالة اللافتة.
للافتة سعر أساسي قدره 20 في العملة المحددة. بالإضافة إلى ذلك، يكلّف كل حرف 2 (تُحتسب المسافات البيضاء ضمن الحساب).
ينبغي أن تُرجع الدالة تكلفة اللافتة كعدد صحيح.

```swift
costOf(sign: "Happy Birthday Grandma!")
// returns 66
```
