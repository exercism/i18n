# الاختبارات

تتيح لك واجهة REPL في ClojureScript تشغيل الكود بسهولة، والحصول على تغذية راجعة فورية، ويمكنك استخدامها أيضًا لتشغيل الاختبارات.

## Leiningen

لفتح REPL باستخدام Clojure CLI، انتقل إلى المجلد الذي يحتوي على التمرين ثم شغّل:

``` bash
$ clojure -m cljs.main -re node
```

لاحظ أنّه يجب تثبيت Node على نظامك.

بعد أن تصبح مستعدًا للعمل على تمرين، وتنشئ ملفًا يحتوي على حلّك (مثل `bob.cljs`)، يمكنك تشغيل الاختبارات من الطرفية باستخدام `$ clojure -A:test`.

أولًا، استدعِ `require` على فضاء أسماء الاختبار:

``` clojure
=> (require 'bob-test)
nil
;; and the test namespace
=> (require 'cljs.test)
```

غيّر `ns` إلى فضاء أسماء الاختبار:

```clojure
=> (ns bob-test)
nil
```

ثم استدعِ `run-tests` على `bob-test`:

``` clojure
=> (cljs.test/run-tests)

Testing bob-test

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
{:test 14, :pass 14, :fail 0, :error 0, :type :summary}
```

لتشغيل اختبارات تمرين باستخدام Clojure CLI، استدعِ ببساطة:

``` bash
$ clojure -M:test

Testing bob-tests

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
```
