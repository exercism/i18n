# ملحق التعليمات

## التنفيذ

لإكمال هذا التمرين، تحتاج إلى تنفيذ struct عبر تعريف نوع البيانات `school` وتنفيذ الدوال التالية:

- newSchool
- add
- roster
- grade

يناقش الفصل الثالث من [Notes on Programming SML/NJ][notes] استخدام signatures و structs.

[notes]: https://www.cs.cornell.edu/riccardo/prog-smlnj/notes-011001.pdf
