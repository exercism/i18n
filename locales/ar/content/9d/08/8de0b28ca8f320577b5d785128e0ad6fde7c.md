# مقدمة

رأينا في المفاهيم السابقة أن الأنواع في Julia تُشكّل هرمًا يقع `Any` في قمته.

الأنواع المجردة مثل `Number` لها أنواع فرعية، لكن لا يمكن إنشاء كائنات منها هي نفسها.
عند إسناد متغير إلى نوع مجرد، فإنك _تُقيّد_ قيم ذلك المتغير لتكون أي نوع فرعي من النوع المجرد.
على سبيل المثال:

```julia-repl
julia> x::Number = 3
3
julia> typeof(x)  # one subtype of Number
Int64
julia> x = 4.2
4.2
julia> typeof(x) # another subtype of Number
Float64
julia> x = "fail" # not a number type!
ERROR: MethodError: Cannot `convert` an object of type String to an object of type Number
```

يمنحنا هذا شكلًا من أشكال المرونة في تقييد المدخلات الصالحة.

لكن، لنفترض أننا نريد لمتغير أن يقبل قيمًا عددية صحيحة وسلاسل نصية في الوقت نفسه؟
فهذان النوعان لا يقعان في الفرع نفسه من الهرم.

يمكننا إسناد النوع `Any`، أو ترك هذا هو الافتراضي، لكننا حينها نفقد كل تحكم في الأنواع المسموح بها.

ولأسلوب أفضل، لدينا الصياغة `Union{ }`، التي ندرج داخلها نوعين أو أكثر بين الأقواس المعقوفة.

```julia-repl
julia> y::Union{Integer, String} = 4
4
julia> typeof(y)
Int64
julia> y = "works"
"works"
julia> typeof(y)
String
julia> y = 5.3
ERROR: MethodError: Cannot `convert` an object of type 
  Float64 to an object of type 
  Union{Integer, String}
```

وهذا مثال آخر يستخدم اتحاد الأنواع نفسه في توقيع دالة:

```julia-repl
julia> IntOrString = Union{Integer, String}
Union{Integer, String}
julia> f(z::IntOrString) = z^3
f (generic function with 1 method)
julia> f(2) # integers are cubed
8
julia> f("ab") # strings are repeated 3 times
"ababab"
```

هنا أعطينا النوع اسمًا، وقد يوفر ذلك اختصارًا مريحًا، لكنه ليس ضروريًا بالمعنى الدقيق.
الدالة `g(z::Union{Integer, String}) = z^3` تسلك السلوك نفسه.

سيأتي الكثير مما يمكن قوله عن تواقيع الدوال في مفهوم الإرسال المتعدد.

## الاتحادات مع لا شيء

توجد في لغات أخرى عديدة أنواع قد تحمل قيمة أو لا تحملها، بأسماء مثل `Option` و`Nullable` و`Maybe`.

لا تمتلك Julia صياغة خاصة بذلك، لكن اتحادات الأنواع تعميم للفكرة نفسها.

رأينا في مفهوم `Nothingness` أن Julia توفر أساليب متنوعة لتمثيل القيم غير الموجودة، منها `nothing` و`missing`.
ويمكن إدراج أيٍّ منهما في اتحاد أنواع.

على سبيل المثال، عند تعريف نوع من القوائم المترابطة، نحتاج إلى وسيلة لإنهاء القائمة إذا لم تعد هناك عُقد.
النوع `Nothing` هو النوع ذو القيمة الوحيدة `nothing`، وهذا التعريف للنوع `Node` يجعل من الممكن الإشارة إلى نهاية سلسلة العُقد:

```julia-repl
julia> struct Node
           value::Any
           next::Union{Node, Nothing}
       end
```

وبالمثل، يمكن استخدام `missing` عنصرًا نائبًا للقيم الغائبة، لا سيما في المجموعات مثل المتجهات.
المثال التالي متكلف جدًا، لكن القيم المفقودة شائعة في مجموعات البيانات الواقعية.

```julia-repl
julia> q(x::Real) = x >= 0 ? sqrt(x) : missing  # skip negative values
q (generic function with 1 method)
julia> vals::Vector{Union{Real, Missing}} = q.([4, 3.1, -1, 0])
4-element Vector{Union{Missing, Float64}}:
 2.0
 1.760681686165901
  missing
 0.0
```
