# مقدمة

## التحويل

التحويل وتحويل الأنواع أسلوبان مختلفان لتغيير تعبير من نوع بيانات إلى آخر.

يمكن تحويل تعبير إلى نوع آخر باستخدام عامل التحويل `(<type>)`.

```csharp
long l = 1000L;
int i = (int)l;

object o = new Random();
Random r = (Random)o;
```

إذا لم يكن النوعان متوافقين، فيُطرح استثناء من النوع `InvalidCastException`. وفي حالة الأعداد، يشير هذا إلى أن النوع المستقبل لا يستطيع تمثيل القيمة المحوَّلة. أما في حالة الأصناف، فيجب أن يكون أحد النوعين مشتقًّا من الآخر (وهذا ينطبق أيضًا على البُنى بشكل بديهي).

وثمة بديل عن _التحويل_ هو _تحويل الأنواع_ باستخدام العامل `is`. ويُطبَّق هذا عادةً على أنواع المراجع والأنواع القابلة لأن تكون فارغة.

```csharp
object o = new Random();
if (o is Random rand)
{
    int ii = rand.Next();
    // now, do something random
}
```

إذا احتجت إلى التعرّف على النوع الدقيق لكائن، فقد يكون العامل `is` متسامحًا أكثر مما ينبغي، لأنه سيُرجع صحيحًا بالنسبة إلى صنف وأي من الأصناف والواجهات التي اشتُقّ منها مباشرةً أو بشكل غير مباشر. وفي هذه الحالة يكون الحل هو `typeof` و`Object.GetType()`.

```csharp
object o = new List<int>();

o is ICollection<int> // true
o.GetType() == typeof(ICollection<int>) // false
o is List<int> // true
o.GetType() == typeof(List<int>) // true
```
