# نبذة

تسمح [السلاسل النصية الحرفية][verbatim-strings] بكتابة سلاسل نصية تمتد على عدة أسطر. تُكتب بإضافة علامة `@` في بدايتها، ويمكن استخدامها مع تضمين القيم داخل السلاسل النصية. أضف فقط `"$"` قبل علامة الاقتباس الافتتاحية.

```csharp
string str = @"
See no wretched
quotes everywhere
";
```

[verbatim-strings]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/strings/#regular-and-verbatim-string-literals
