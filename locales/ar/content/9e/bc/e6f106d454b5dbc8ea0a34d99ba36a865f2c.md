# التعليمات

في هذا التمرين، تعمل في مطعم بيتزا يوصل الطلبات إلى العملاء.

أنت تقدّم ثلاثة أنواع من البيتزا:

- Margherita: \$7
- Caprese: \$9
- Formaggio: \$10

ويمكن للعملاء أيضًا اختيار خيارين إضافيين مقابل رسم إضافي بسيط:

1. صلصة إضافية: \$1
1. مكوّنات إضافية: \$2

عندما يقدّم العملاء طلبًا، تُضاف رسوم إضافية إذا طلبوا بيتزا واحدة أو بيتزتين فقط:

- بيتزا واحدة: \$3
- بيتزتان: \$2

لديك ثلاث مهام، تتعامل كل واحدة منها مع البيتزا وسعرها.

## 1. عرّف أنواع البيتزا وخياراتها

عرّف الاتحاد المميّز `Pizza` لتمثيل أنواع البيتزا والخيارين الإضافيين اللذين يمكن إضافتهما إلى البيتزا:

- `Margherita`
- `Caprese`
- `Formaggio`
- `ExtraSauce`
- `ExtraToppings`

## 2. احسب سعر البيتزا

نفّذ الدالة `pizzaPrice` لحساب سعر البيتزا:

```fsharp
pizzaPrice Caprese
// => 9
```

## 3. احسب سعر الطلب

نفّذ الدالة `orderPrice` لحساب سعر طلب البيتزا:

```fsharp
orderPrice [Margherita; Formaggio]
// => 19
```
