# الاختبارات

ستحتاج إلى تثبيت [Godot][installation] بشكل صحيح لاستخدام مشغّل الاختبارات.

## تشغيل الاختبارات

يُستخدم [مشغّل الاختبارات][test runner] لتحميل الحلول واختبارها.
لتشغيل مشغّل الاختبارات، نزّله محليًا ثم شغّله باستخدام `godot`.
في المستقبل، سيُنزَّل مشغّل الاختبارات تلقائيًا مع التمارين عند استخدام `exercism download`.

```bash
godot --headless -s /path/to/test_runner.gd -- <solution-slug> <path/to/solution>
```
