# التعليمات

تعمل جين في غرفة الفرز في مصنع كبير.
تحتاج غرفة الفرز إلى معالجة كل ما يصل إليها بتصنيفه ووضع ملصق عليه.
جين مسؤولة عن الأشياء التي صُنّفت مسبقًا كأعداد، وتحتاج إلى برنامج يساعدها في الفرز.

معظم القيم الأولية ينبغي أن تحصل على ملصقات مباشرة.
بالنسبة إلى الأعداد، تريد سلاسل نصية تقول `"This is the number 2.0"` (إذا كان العدد 2).
تريد جين المخرَج نفسه للأعداد الصحيحة والأعداد العشرية.

هناك بعض الواجهات `Box` التي يجب فكّها للحصول على محتوياتها.
بالنسبة إلى `NumberBox`، تريد سلاسل نصية تقول `"This is a box containing the number 3.0"` (إذا أرجعت الطريقة `Number()` القيمة 3).
وبالنسبة إلى `FancyNumberBox`، تريد سلاسل نصية تقول `"This is a fancy box containing the number 4.0"`، ولكن فقط إذا كان النوع `FancyNumber`.

أي شيء غير متوقع ينبغي أن يقول `"Return to sender"` حتى تتمكن جين من إعادته إلى مصدره.

## 1. وصف الأعداد البسيطة

تريد جين أن تُرجع الأعداد سلاسل نصية مثل `"This is the number 2.0"` (مع رقم واحد بعد الفاصلة العشرية):

```go
fmt.Println(DescribeNumber(-12.345))
// Output: This is the number -12.3
```

## 2. وصف صندوق الأعداد

تريد جين أن تُرجع صناديق الأعداد سلاسل نصية مثل `"This is a box containing the number 2.0"` (مرة أخرى، مع رقم واحد بعد الفاصلة العشرية):

```go
fmt.Println(DescribeNumberBox(numberBoxContaining{12}))
// Output: This is a box containing the number 12.0
```

## 3. تنفيذ طريقة تستخرج العدد من صندوق أعداد مميّز

تحتاج جين إلى دالة مساعدة لاستخراج العدد من `FancyNumberBox`.
إذا كان `FancyNumberBox` من نوع `FancyNumber`، فاستخرج قيمته وحوّلها من `string` إلى `int`.
أي نوع آخر من `FancyNumberBox` ينبغي أن يُرجع 0.

```go
fmt.Println(ExtractFancyNumber(FancyNumber{"10"}))
// Output: 10
fmt.Println(ExtractFancyNumber(AnotherFancyNumber{"4"}))
// Output: 0
```

## 4. وصف صندوق الأعداد المميّز

إذا كان `FancyNumberBox` من نوع `FancyNumber`، تريد جين سلاسل نصية تقول `"This is a fancy box containing the number 4.0"`.
أي نوع آخر من `FancyNumberBox` ينبغي أن يقول `"This is a fancy box containing the number 0.0"`.

```go
fmt.Println(DescribeFancyNumberBox(FancyNumber{"10"}))
// Output: This is a fancy box containing the number 10.0
fmt.Println(DescribeFancyNumberBox(AnotherFancyNumber{"4"}))
// Output: This is a fancy box containing the number 0.0
```

ملاحظة: ينبغي أن نستخدم الدالة `ExtractFancyNumber`!

## 5. تنفيذ `DescribeAnything` التي تستخدمها جميعًا

هذه هي الدالة الرئيسية التي تحتاجها جين، وهي تأخذ أي مدخل.
ينبغي أن تُفوّض `DescribeAnything` إلى الدوال الأخرى بناءً على نوع القيمة المُمرَّرة.
وبشكل أكثر تحديدًا:

- ينبغي أن تُفوّض كلٌّ من `int` و`float64` إلى `DescribeNumber`
- ينبغي أن تُفوّض `NumberBox` إلى `DescribeNumberBox`
- ينبغي أن تُفوّض `FancyNumberBox` إلى `DescribeFancyNumberBox`
- أي شيء آخر ينبغي أن تكون نتيجته `"Return to sender"`

```go
fmt.Println(DescribeAnything(numberBoxContaining{12.345}))
// Output: This is a box containing the number 12.3
fmt.Println(DescribeAnything("some string"))
// Output: Return to sender
```
