# مقدمة

الدالة هي كتلة من الكود المنظّم القابل لإعادة الاستخدام، تُستخدم لتنفيذ إجراء ما.
وهناك عدة أساليب لتعريف الدوال في JavaScript.
سنتعرف هنا على _إعلانات الدوال_ و_تعبيرات الدوال_.
أما الاحتمالات الأخرى مثل [الدوال السهمية][concept-arrow-functions] فسنغطيها في مفاهيم أخرى.

## إعلان الدالة

الطريقة القياسية لتعريف دالة في JavaScript هي _إعلان الدالة_، ويُسمى أيضًا _تعريف الدالة_ أو _عبارة الدالة_.

ويتكوّن من الكلمة المفتاحية `function`، واسم الدالة، وقائمة معاملات مفصولة بفواصل داخل الأقواس الهلالية.
ويلي ذلك جسم الدالة (مجموعة من العبارات تحدّد ما تفعله الدالة) محاطًا بالأقواس المعقوفة.

```javascript
function someName(param1, param2, param3) {
  // ...
}
```

في JavaScript، تُستدعى الدالة (أي تُنادى) بكتابة اسم الدالة متبوعًا بأقواس هلالية تحتوي على الوسائط.

```javascript
someName(arg1, arg2, arg3);
```

## المعاملات

عند التعامل مع المعاملات داخل جسم الدالة، انتبه إلى الآثار الجانبية المحتملة.

- قيم [أنواع البيانات الأولية][mdn-primitives] _غير قابلة للتغيير_.
  فالقيمة الأصلية لا تتأثر أبدًا بما يحدث للوسيط داخل جسم الدالة.
- أما بقية القيم (الكائنات والمصفوفات والدوال)، فإن إعادة الإسناد لا تؤثر على القيمة الأصلية.
  لكن إذا عدّلت وسيطًا كهذا (مثلًا بإضافة مفتاح إلى كائن)، فإن ذلك يعدّل أيضًا القيمة الأصلية التي مُرّرت.

افتراضيًا، جميع المعاملات المعرّفة في إعلان الدالة اختيارية في JavaScript.
إذا مرّرت وسائط أقل من عدد المعاملات، فستكون الوسائط الناقصة `undefined` داخل الدالة، راجع [`null` و `undefined`][concept-null-undefined].
وفي كثير من الحالات، من المنطقي إسناد قيمة افتراضية أنسب من `undefined`.
ويمكن فعل ذلك بتحديد معاملات افتراضية مباشرةً في تعريف الدالة.

```javascript
function someName(param1 = defaultValue1, param2 = defaultValue2) {
  // ...
}
```

## عبارة `return`

تُنهي عبارة `return` تنفيذ الدالة وتحدّد قيمة تُرجَع إلى مستدعي الدالة. ويمكن أن تحتوي الدالة على عدة عبارات `return`.

```javascript
function checkNumber(num) {
  if (num === 0) {
    return 'You passed 0, please provide another number.';
  }

  return 'Thanks for passing such a nice number.';
}
```

نتيجة الدالة التي لا تُرجع قيمة أو التي لا تحتوي على عبارة `return` هي `undefined`.
ولا توجد عبارات `return` ضمنية في JavaScript.

```javascript
function nakedReturn(a) {
  a * 2;
  return;
}

nakedReturn(1);
// => undefined

function noReturn(a) {
  a * 2;
}

noReturn(1);
// => undefined
```

في JavaScript، يمكنك إرجاع قيمة واحدة فقط.
وإذا أردت تمرير معلومات أكثر، فعليك دمجها أولًا في كيان واحد، عادةً في [كائن][concept-objects] أو [مصفوفة][concept-arrays].

```javascript
function divide(a, b) {
  return {
    quotient: Math.floor(a / b),
    remainder: a % b,
  };
}
```

## تعبير الدالة

إعلان الدالة عبارة قائمة بذاتها.
لكن من المفيد أحيانًا تعريف دالة كجزء من تعبير آخر، مثلًا داخل إسناد، أو كمعامل دالة ([دالة رد نداء][concept-callbacks])، أو كقيمة في [كائن][concept-objects].
ويمكن فعل ذلك باستخدام تعبير الدالة.
وهو مماثل لإعلان الدالة في الصيغة، غير أنه يمكن حذف اسم الدالة لإنشاء _دالة مجهولة_.

```javascript
const someFunction = function (param) {
  // ...
};

someOtherFunction(function (param) {
  // ...
});

const obj = {
  someFunction: function (param) {
    // ...
  },
};
```
