# نبذة

[الرموز][symbols] هي معرّفات مُسمّاة يمكن استخدامها للإشارة إلى قيمة.
تُنشأ الرموز من خلال قيمة حرفية للرمز، وهي كتابة النقطتين `:` قبل الاسم، مثل `:foo`.
ويمكن أيضًا كتابتها بين علامتي تنصيص، مثل `:"foo"`، وهو ما يسمح مثلًا بوجود مسافات في الاسم.

```ruby
:foo # => :foo
:"foo boo" # => :"foo boo"
```

تُستخدم الرموز في مواضع كثيرة من اللغة، بما في ذلك كمفاتيح في جداول التجزئة، ولتمثيل أسماء الطرق وأسماء المتغيرات.

## المعرّف

ما يميّز الرموز عن السلاسل النصية أنها معرّفات، ولا تمثّل بيانات أو نصًا.
وهذا يعني أن رمزين يحملان الاسم نفسه هما دائمًا الكائن نفسه.

```ruby
"foo".object_id # => 60
"foo".object_id # => 80
:foo.object_id # => 1086748
:foo.object_id # => 1086748
```

## تعديل الرموز

الرموز غير قابلة للتعديل، أي أنه لا يمكن تغييرها.
وهذا يعني أنك حين "تعدّل" رمزًا فأنت في الحقيقة تنشئ رمزًا جديدًا.
هناك بعض الطرق التي يمكن استخدامها للتعامل مع الرموز، وكلها تُرجع رموزًا جديدة.
ويمكن العثور على جميع الطرق في [واجهة API الخاصة بالرمز][symbols-api].

```ruby
:foo.upcase # => :FOO

:foo.object_id # => 1086748
:foo.upcase.object_id # => 60
```

وميزة كون الرموز غير قابلة للتعديل أنها أكثر كفاءة في استخدام الذاكرة من السلاسل النصية، كما أنها أكثر أمانًا عند استخدامها كمعرّفات.

## التحويل

يمكن تحويل الرموز إلى سلاسل نصية والعكس.
ويفيد ذلك عندما تريد تعديل رمز، أو عندما تريد استخدام رمز كسلسلة نصية.
لعرض سلسلة نصية كرمز يمكنك استخدام الطريقة `String#to_sym`، وللقيام بالعكس يمكنك استخدام الطريقة `Symbol#to_s`.
ولأن الرموز تمتلك مجموعة محدودة من الطرق، فقد يفيد تحويل الرمز إلى سلسلة نصية لتطبيق طرق السلاسل النصية عليه، إن كنت بحاجة إلى رمز جديد.

```ruby
:foo.to_s # => "foo"
"foo".to_sym # => :foo
```
