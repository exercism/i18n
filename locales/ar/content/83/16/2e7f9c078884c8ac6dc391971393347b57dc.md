# مقدمة

## الأنواع العامة

النوع _نوع عام_ عندما يمكنه أن يحتوي على قيم من أي نوع باستخدام _معامل نوع_.

على سبيل المثال، نوع `Box` هذا له معامل النوع `a` (مكتوب بحروف صغيرة).

```gleam
pub type Box(a) {
  Box(a)
}
```

معامل النوع `a` هو عنصر نائب لأي نوع، لذا يمكن استخدام `Box` مع السلاسل النصية أو الأعداد الصحيحة أو أي نوع آخر.

```gleam
Box("Hello, Joe!") // The type is Box(String)

Box(42) // The type is Box(Int)
```

يمكن للنوع أن يمتلك عدة معاملات نوع عبر فصلها بفواصل.

```gleam
pub type Pair(a, b) {
  Pair(a, b)
}
```

### الدوال العامة

يمكن أيضًا استخدام معاملات النوع في وسائط الدوال.

تأخذ هذه الدالة قيمة من النوع `a` وتستدعي دالةً مرتين، تأخذ قيمة من النوع `a` وتُرجع قيمة من النوع `b`.

```gleam
pub fn twice(value: a, f: fn(a) -> b) -> b {
  f(value)
  f(value)
}
```
```gleam
// The type is fn(String, fn(String) -> Nil) -> Nil
twice("Hello, Joe!", io.println)
```
