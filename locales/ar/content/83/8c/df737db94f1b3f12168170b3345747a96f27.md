# مقدمة

تمثّل السلسلة النصية بيانات نصية.
في Swift، السلسلة [`String`][strings-and-characters] هي مجموعة مرتّبة من قيم `Character`، حيث يمثّل كل محرف منها محرفًا يونيكوديًا واحدًا.

تنشئ سلسلة نصية باستخدام قيمة حرفية نصية، وهي متتالية من المحارف محاطة بعلامتي اقتباس مزدوجتين (`"`).
أما السلاسل النصية الممتدة على عدة أسطر، فاستخدم ثلاث علامات اقتباس مزدوجة (`"""`):

```swift
let hello: String = "Hello, World!"

let poem: String = """
Roses are red,
Violets are blue.
Sugar is sweet,
And so are you.
"""
```

تتواصل السلاسل النصية في Swift بسلاسة مع صنف [`NSString`][nsstring-docs] في إطار عمل Foundation، مما يتيح الوصول إلى قدرات واسعة لمعالجة النصوص.

## المحارف

يمثّل `Character` عنقودًا رسوميًا موسّعًا واحدًا، أي محرفًا يمكن للإنسان قراءته ويتكوّن من قيمة واحدة أو أكثر من [قيم يونيكود العددية][unicode-scalar-values].
وقيمة يونيكود العددية هي نقطة ترميز من 21 بت في النطاق من `U+0000` إلى `U+D7FF` شاملًا الطرفين، أو من `U+E000` إلى `U+10FFFF` شاملًا الطرفين.

```swift
let aChar: Character = "A"
```

## استنتاج النوع

عندما تكتب قيمة حرفية نصية، يستنتج Swift نوعها تلقائيًا على أنه `String`.
ولتخزين محرف واحد على هيئة `Character`، عليك تقديم تعليق نوع صريح:

```swift
let aString = "A"        // Inferred as String
let aChar: Character = "A" // Explicitly typed as Character
print(type(of: aString)) // Prints String
print(type(of: aChar))   // Prints Character

// The following code will not compile:
let badChar: Character = "Too many characters"
// Error: Cannot convert value of type 'String' to specified type 'Character'
```

## الدمج

يمكنك ضمّ السلاسل النصية بعضها إلى بعض باستخدام عامل الجمع (`+`):

```swift
print("honey" + "comb")
// Prints "honeycomb"
```

لا يمكنك دمج `Character` مباشرةً مع `String` باستخدام `+` دون تحويل المحرف إلى سلسلة نصية أولًا.
لكن يمكنك استخدام طريقة [`append(_:)`][append] لإضافة سلسلة نصية أو محرف مباشرةً إلى سلسلة نصية قابلة للتغيير:

```swift
var greeting = "Hello"
let world = ", world"
let period: Character = "."

greeting.append(world)
print(greeting) // Prints "Hello, world"

greeting.append(period)
print(greeting) // Prints "Hello, world."
```

## تداخل السلاسل النصية

يتيح لك [تداخل السلاسل النصية][string-interpolation] بناء سلسلة نصية عبر تضمين الثوابت والمتغيرات والقيم الحرفية والتعبيرات داخل القيم الحرفية النصية.
ضع كل تعبير بين قوسين هلاليين مسبوقين بشرطة مائلة عكسية (`\(` ... `)`):

```swift
let radius = 5.0
let circle = "The area of a circle with radius \(radius) is \(Double.pi * radius * radius)"
print(circle) // Prints "The area of a circle with radius 5.0 is 78.53981633974483"
```

## خصائص السلاسل النصية والمحارف

توفّر السلاسل النصية والمحارف عدة خصائص لفحص محتواها.

### خصائص السلاسل النصية

من الخصائص الشائعة للسلاسل النصية:

| الخاصية  | الوصف                                          | مثال                             |
| --------- | ---------------------------------------------- | -------------------------------- |
| `isEmpty` | تُرجع `true` إذا لم تحتوِ السلسلة النصية على أي محارف | قيمتها `"Hello".isEmpty` هي `false` |
| `count`   | تُرجع عدد المحارف في السلسلة النصية            | قيمتها `"Hello".count` هي `5`    |

للاطلاع على قائمة كاملة بالخصائص، راجع [توثيق String في Apple][string-docs].

### خصائص المحارف

من الخصائص الشائعة للمحارف:

| الخاصية        | الوصف                                         | مثال                                 |
| -------------- | --------------------------------------------- | ------------------------------------ |
| `isLowercase`  | تُرجع `true` إذا كان المحرف صغيرًا             | قيمتها `"a".isLowercase` هي `true`   |
| `isUppercase`  | تُرجع `true` إذا كان المحرف كبيرًا             | قيمتها `"A".isUppercase` هي `true`   |
| `isNumber`     | تُرجع `true` إذا كان المحرف رقمًا              | قيمتها `"1".isNumber` هي `true`      |
| `isWhitespace` | تُرجع `true` إذا كان المحرف مسافة بيضاء        | قيمتها `" ".isWhitespace` هي `true`  |

للاطلاع على قائمة كاملة بالخصائص، راجع [توثيق Character في Apple][character-docs].

## تحويل الأنواع

يمكنك تحويل أنواع أخرى إلى سلاسل نصية باستخدام مُهيّئ `String(_:)`، الذي يدعم أنواعًا قياسية مثل `Int` و`Double` و`Character`:

```swift
let charX: Character = "x"
print(String(charX))     // Prints "x"
print(String(110))       // Prints "110"
print(String(Double.pi)) // Prints "3.141592653589793"
```

## المحارف الخاصة

تدعم القيم الحرفية النصية في Swift عدة [متتاليات هروب][special-characters] للمحارف الخاصة:

| المتتالية | الوصف                         |
| ---------- | ----------------------------- |
| `\0`       | محرف فارغ                     |
| `\\`       | شرطة مائلة عكسية              |
| `\t`       | علامة جدولة أفقية             |
| `\n`       | تغذية سطر (سطر جديد)          |
| `\r`       | إرجاع المؤشر                  |
| `\'`       | علامة اقتباس مفردة            |
| `\"`       | علامة اقتباس مزدوجة           |
| `\u{n}`    | قيمة يونيكود عددية اعتباطية (بالنظام الست عشري) |

```swift
let quote: String = "\"Hello\", he said."
print(quote) // Prints "Hello", he said.

let unicode: Character = "\u{1F496}"
print(unicode) // Prints 💖
```
