# نبذة

تحتوي وحدة `gleam/order` في المكتبة القياسية لـ Gleam على النوع `Order`، الذي يُستخدم لمقارنة القيم.

تعريف `Order` يبدو كما يلي:

```gleam
pub type Order {
  Gt
  Eq
  Lt
}
```

للنوع ثلاث صيغ، تُستخدم كل واحدة منها لتمثيل العلاقة بين قيمة وقيمة أخرى:

- `Gt` - القيمة _أكبر_ من القيمة الأخرى.
- `Eq` - القيمة _مساوية_ للقيمة الأخرى.
- `Lt` - القيمة _أصغر_ من القيمة الأخرى.

إذا أمكن مقارنة نوع بيانات حسب الحجم، فمن الشائع أن تعرّف الوحدة دالة `compare` تُرجع قيمة من النوع `Order`. على سبيل المثال، تُعرّف `gleam/float` و`gleam/int` دالتَي `compare` تعملان على الأعداد العشرية والأعداد الصحيحة على التوالي.

```gleam
int.compare(1, 2)
// -> Lt

int.compare(2, 2)
// -> Eq

float.compare(1.0, 2.0)
// -> Lt
```

عادةً ما تأخذ دوال الترتيب مثل `list.sort` دالةً تُرجع قيمة من النوع `Order`، ما يتيح للمستدعي تحديد كيفية ترتيب القائمة.

```gleam
list.sort([3, 7, 3, 1], by: int.compare)
// -> [1, 3, 3, 7]
```
