# Case

[`case`][case] (يُشار إليه غالبًا بـ switch في لغات أخرى) هو أحد أشكال تعبيرات التحكم مثل if-else.
يتيح `case` ربط عدة عبارات if-else-if معًا، وقد يكون أكثر قابلية للقراءة، ويتيح تراكيب قوية.

يُعرَّف `case` بالكلمة المفتاحية `case` متبوعة بتعبير اختياري.
ثم تُستخدم الكلمة المفتاحية `when` لكل حالة، متبوعة بتعبير يُقارَن بتعبير `case`.
وينبغي ألا تُزاح الكلمة المفتاحية `when` عن الكلمة المفتاحية `case`.
ويأتي بعد الكلمة المفتاحية `when` الكود الذي ينبغي تنفيذه إذا طابق تعبير `case` تعبير `when`.
ويتيح `case` عبارة `else` اختيارية تُنفَّذ إذا لم تتطابق أي حالة أخرى.

يُقيَّم تعبير `case` ثم يُقارَن بكل تعبير `when`.
وتتم المقارنة باستخدام [عامل الاندراج في `case` (`===`)][case-subsumption].

```Crystal
case 1
when 1
  puts "One"
when 2
  puts "Two"
else
  puts "Other"
end
# => One

# This is the same as:
tmp = 1
if 1 === tmp
  puts "One"
elsif 2 === tmp
  puts "Two"
else
  puts "Other"
end
```

## عامل الاندراج في `case` (`===`)

يختلف عامل الاندراج في `case` (`===`) قليلًا عن عامل المساواة (`==`).
يتحقق العامل مما إذا كان الطرف الأيمن عضوًا في المجموعة التي يصفها الطرف الأيسر.
وهذا يعني أن موضع كل طرف مهم.
وتعتمد طريقة عمله على نوع الطرف الأيسر؛ فمثلًا يتحقق `Range` مما إذا كان الطرف الأيمن داخل المدى، بينما يتحقق `Object` مما إذا كان الطرف الأيمن نسخة من `Object`.

```Crystal
(1..3) == 1  # => false
(1..3) === 1 # => true

String == "foo"  # => false
String === "foo" # => true
```

## الحالات مع عدة تعبيرات

تتيح الحالات مطابقة عدة تعبيرات في حالة واحدة، مع فصل كل قيمة ممكنة بفاصلة.
وسيُنفَّذ الكود إذا طابق أي من التعبيرات.
وقد يكون هذا مفيدًا لحالة واحدة لها عدة قيم ممكنة.

```Crystal
case 1
when 1, 2
  puts "One or two"
else
  puts "Other"
end
```

## الحالات مع المديات

يمكن للحالات أيضًا التحقق مما إذا كانت قيمة ما داخل مدى.
ويتم ذلك بوضع مدى كتعبير `when`.

```Crystal
case var
when 1..3
  puts "One to three"
else
  puts "Other"
end
```

## الحالات بدون تعبير `case`

عندما لا تكون هناك حاجة إلى تعبير `case`، يمكن حذفه.
وسيؤدي ذلك إلى تقييم كل تعبير `when` من حيث كونه صحيحًا أو خطأً.
فتبدو هذه الحالات وكأنها تتصرف مثل عبارات if-else-if.

```Crystal
case
when 1 == 1
  puts "One is equal to one"
when 1 > 2
  puts "One is greater than two"
else
  puts "Other"
end
```

## `when` في سطر واحد

يتيح Crystal عبارات `case` في سطر واحد.
ويمكن استخدام ذلك عندما تكون لديك عبارة بسيطة من سطر واحد.
وتُكتب عبارة `when` في السطر الواحد بالشكل `when <expression> then <statement>.`
وعند استخدامها في عبارة `else`، تُكتب بالشكل `else <statement>`.

```Crystal
case var
when 1 then puts "One"
when 2 then puts "Two"
else puts "Other"
end
```

## الحالات مع الأنواع

يتيح `case` المطابقة مع الأنواع.
وستستخدم المقارنة عامل `is_a?` للتحقق من نوع المتغير.
فمثلًا، يتيح ذلك فرعًا لكل نوع في نوع اتحادي.

```Crystal
case var
when Int32
  puts "Int32"
when String
  puts "String"
else
  puts "Other"
end
```

## الكائن الضمني

يتيح `case` استخدام كائن ضمني.
فمثلًا، يتيح ذلك أن يكون تعبير `when` استدعاءً لطريقة على تعبير `case`.
وبناءً على ما إذا كانت الطريقة تُرجع قيمة صحيحة أو خاطئة، ستتطابق الحالة أو لا.

```Crystal
case 1
when .odd?
  puts "Odd"
when .even?
  puts "Even"
end
```
