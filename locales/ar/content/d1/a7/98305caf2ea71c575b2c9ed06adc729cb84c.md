# مقدمة

المصفوفات مدمجة في لغة Elixir. وهي تُعدّ نوعًا أساسيًا، ويُرمز إليها بالأقواس المربعة. قد تكون المصفوفات فارغة أو تحتوي على أي عدد من العناصر من أي نوع. على سبيل المثال:

```elixir
empty_list = []
one_item_list = [1]
two_item_list = [1, 2]
multiple_type_list = [1, :pi, 3.14, "four"]
```

تنفّذ Elixir المصفوفات كمصفوفة مترابطة، حيث تخزّن كل عقدة قيمتين: العنصر الأول ومصفوفة أخرى تضم بقية العناصر. يُشار إلى العنصر الأول في المصفوفة بـ _الرأس_، بينما تُسمّى بقية العناصر _الذيل_. يمكننا استخدام هذا الترميز في الكود:

```elixir
# [1] represented in [head | tail] notation
[1 | []]

# [1, 2, 3] represented in [head | tail] notation
[1 | [2 | [3 | []]]]
```

يمكننا استخدام ترميز _`[head | tail]`_ لإضافة عناصر في مقدمة المصفوفة:

```elixir
# Suppose
list = [2, 1]

[3, 2, 1] == [3 | list]
# => true
```

توجد عدة دوال في وحدة `Kernel` للتعامل مع المصفوفات، إضافة إلى وحدة `List` بأكملها.

```elixir
# Check if 1 is a member of the list
1 in [1, 2, 3, 4]
# => true
```
