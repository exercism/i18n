# مقدمة

توفّر لغات كثيرة وسيلة مثل `null` أو `none` للإشارة إلى قيمة غير موجودة.
ولأن Julia مصمّمة للتعامل مع كميات كبيرة من البيانات (التي غالبًا ما تكون غير منظّمة)، فإنها تملك عدة أشكال للعدم.

الهدف العام هو الإشارة إلى القيم المفقودة أو المشكوك فيها عند مواجهتها، ثم المتابعة دون رفع استثناء.

## `nothing`

إذا كانت القيمة غير موجودة فعلًا، فإنها تُمثَّل بـ `nothing`. وهذا أقرب ما يكون إلى ما تفعله لغة C (عبر `NULL`) أو Python (عبر `None`).

```julia-repl
julia> n = nothing

julia> isnothing(n)
true

julia> typeof(n)
Nothing
```

إذن `nothing` قيمة وحيدة من النوع `Nothing`، ويمكننا اختبارها.

من الاستخدامات الشائعة لـ `nothing` أن يكون قيمة الإرجاع (أو عدم وجودها) للدوال التي تُستخدم من أجل آثارها الجانبية فقط (الطباعة، أو إعداد الشبكة، أو ما شابه ذلك).

## `missing`

في الحالات التي تكون فيها القيمة موجودة نظريًا لكننا لا نعرف ما هي، نستخدم `missing`. على سبيل المثال، عند إحصاء المركبات التي تسير على طريق، قد يحتاج المراقبون البشريون إلى استراحة أو تتعطل المستشعرات الآلية، لكن حركة المرور تستمر.

وبالتالي فإن `missing` عنصر نائب، ينبّه البشر إلى أنهم بحاجة إلى اتخاذ قرار بشأن كيفية التعامل مع هذه الفجوة في البيانات.

```julia-repl
julia> mv = [1, 2, missing]
3-element Vector{Union{Missing, Int64}}:
 1
 2
  missing

julia> typeof(mv)
Vector{Union{Missing, Int64}} (alias for Array{Union{Missing, Int64}, 1})

julia> ismissing.(mv)  # broadcast function, displays as 1 for true, 0 for false
3-element BitVector:
 0
 0
 1
```

قليل من اللغات الأخرى تملك هذه الميزة مدمجة، لكن نظيراتها القريبة هي `NA` في R أو `NULL` في SQL.

تُرجع التعبيرات عادةً `missing` افتراضيًا إذا كانت هناك قيم `missing` موجودة.
وإذا أردت تجاهل هذه القيم، فاستخدم الدالة `skipmissing()` لجعل ذلك صريحًا:

```julia-repl
julia> mv = [1, 2, missing]
3-element Vector{Union{Missing, Int64}}:
 1
 2
  missing

julia> sum(mv)  # missing in, missing out
missing

julia> skipmissing(mv)
skipmissing(Union{Missing, Int64}[1, 2, missing])

julia> collect(skipmissing(mv))
2-element Vector{Int64}:
 1
 2

julia> sum(skipmissing(mv))  # functions like sum() can work with iterators
3
```

ولأن `skipmissing` تُنشئ مكرِّرًا، فغلّفها بـ `collect()` إذا احتجت إلى متجه.

أحيانًا يكون من المفيد استبدال قيم `missing` بقيمة افتراضية ما.
وماكرو `@coalesce()` مفيد لهذا الغرض، إذ يُرجع أول قيمة غير `missing` (أو `missing` إذا لم يكن هناك غيرها).

```julia-repl
julia> str = ["I", "exist", missing]
3-element Vector{Union{Missing, String}}:
 "I"
 "exist"
 missing

julia> [@coalesce(s, "-") for  s in str]
3-element Vector{String}:
 "I"
 "exist"
 "-"
```

## `NaN`

اختصار لـ "Not a Number"، وتشير NaN إلى مشكلة حسابية في الحالات التي كان يُتوقع فيها عدد.

```julia-repl
julia> v = [0, 1, -1]
3-element Vector{Int64}:
  0
  1
 -1

julia> v / 0
3-element Vector{Float64}:
 NaN
  Inf
 -Inf
 
julia> sum(v / 0)
NaN
```

أي نوع من الحسابات على بيانات تتضمن NaN سيعطي نتيجة `NaN`.

لا توجد حاليًا دالة خاصة لإزالة قيم `NaN`، لكن الدالة القياسية `filter()` تستطيع فعل ذلك ببساطة.
لن تُنسخ إلى مصفوفة النتيجة إلا القيم التي يكون فيها شرط معطى مساويًا لـ `true`:

```julia-repl
julia> filter(!isnan, [1, 2, NaN])
2-element Vector{Float64}:
 1.0
 2.0
```
