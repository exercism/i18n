# تشغيل الاختبارات

بعد تثبيت `sbt`، يمكن تنفيذ الاختبارات من سطر الأوامر باستخدام:

```bash
$ sbt test
```

لاحظ أن تنفيذ `sbt test` في كل مرة سيكون بطيئًا، لأنه يعيد تهيئة `sbt` عند كل تشغيل.

يعمل `sbt` مثل صدفة الأوامر، وبمجرد تشغيله يمكنك تنفيذ أوامر بداخله.

على سبيل المثال، يمكنك استخدام `sbt` لإعادة تشغيل اختباراتك كلما تغيّرت ملفات المصدر:
```bash
$ sbt
>~ test
```

لاحظ أن جميع الاختبارات معطّلة ما عدا الأول، لتعمل عليه.
للمتابعة، ما عليك سوى إزالة الكلمة المفتاحية `pending` من بداية كل حالة اختبار.

توجّه [هنا](https://www.scala-sbt.org/) لتعلّم المزيد عن `sbt`.


يمكنك أيضًا تشغيل الاختبارات داخل بيئات التطوير المتكاملة التالية

* [Metals](https://scalameta.org/metals/docs/#running-tests)
* [IntelliJ IDEA مع إضافة Scala](https://www.jetbrains.com/idea/)
