# ملحق التعليمات

## تلميحات

عليك تنفيذ الدالة `responseFor` التي تُرجع ردّ Bob على مدخل معيّن. يمكنك استخدام التوقيع المرفق إن لم تكن متأكدًا من الأنواع، لكن لا تدعه يقيّد إبداعك:

```haskell
responseFor :: String -> String
```

لحل هذا التمرين، يمكنك الاطّلاع على:

- [الحرّاس][guards]

[guards]: https://www.futurelearn.com/courses/functional-programming-haskell/0/steps/27226

يتعامل هذا التمرين مع بيانات نصية. لأسباب تاريخية، فإن نوع `String` في Haskell مرادف لـ `[Char]`، وهو مصفوفة من المحارف. ولمعالجة بيانات نصية بكفاءة أكبر، يمكن استخدام نوع `Text`.

وكإضافة اختيارية إلى هذا التمرين، يمكنك

- أن تقرأ عن [أنواع السلاسل النصية](https://haskell-lang.org/tutorial/string-types) في Haskell.
- أن تضيف `- text` إلى قائمة الاعتماديات لديك في package.yaml.
- أن تستورد `Data.Text` [بالطريقة التالية](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

    ```haskell
    import qualified Data.Text as T
    import           Data.Text (Text)
    ```

- يمكنك الآن كتابة شيء مثل `responseFor :: Text -> Text` والإشارة إلى مُركّبات `Data.Text` مثل `T.isSuffixOf`.
- أن تطّلع على توثيق [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html)،
- يمكنك بعد ذلك استبدال كل مواضع `String` بـ `Text` في Bob.hs:

    ```haskell
    responseFor :: Text -> Text
    ```

هذا الجزء اختياري بالكامل.
