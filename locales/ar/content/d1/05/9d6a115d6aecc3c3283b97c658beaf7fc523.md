# مقدمة

## الطوابير

تُنفّذ مكتبة Gleam القياسية نوع `Queue` في وحدة `gleam/queue`. وهو مشابه لنوع `List`، لكن مع بعض الفروق الجوهرية:

- لا يمتلك نوع `Queue` صياغة حرفية يمكن استخدامها لإنشاء الطوابير أو مطابقة الأنماط عليها.
- يمكن إضافة العناصر وإزالتها بكفاءة من مقدمة نوع `Queue` ومؤخرته معًا، بينما لا يستطيع نوع `List` إضافة العناصر وإزالتها بكفاءة إلا من المقدمة.

في معظم الأحيان سترغب في استخدام نوع `List`، لكن عندما تحتاج إلى القدرة على الإضافة والإزالة من نهاية مجموعة ما، فإن نوع `Queue` خيار جيد.

يمكن إنشاء الطوابير باستخدام الدالتين `queue.new` و`queue.from_list`:

```gleam
let empty = queue.new()
let one_to_four = queue.from_list([1, 2, 3, 4])
```

يمكن إضافة العناصر إلى الطابور باستخدام الدالتين `queue.push_front` و`queue.push_back`:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
let one_to_five = queue.push_back(one_to_four, 5)
let zero_to_five = queue.push_front(one_to_five, 0)
```

يمكن إزالة العناصر من الطابور باستخدام الدالتين `queue.pop_front` و`queue.pop_back`:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])

queue.pop_back(one_to_four)
// -> Ok(#(4, queue.from_list([1, 2, 3])))

queue.pop_front(one_to_four)
// -> Ok(#(1, queue.from_list([2, 3, 4])))

queue.pop_front(queue.new())
// -> Error(Nil)
```

يمكن تحويل طابور إلى مصفوفة باستخدام دالة `queue.to_list`:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
queue.to_list(one_to_four)
// -> [1, 2, 3, 4]
```

### تساوي الطوابير

نظرًا لكيفية تنفيذ الطوابير، قد لا يكون طابوران يحملان العناصر نفسها بالترتيب نفسه متساويين وفقًا للعامل `==`، الذي يقارن القيم بنيويًا. على سبيل المثال:

```gleam
let empty = queue.new()
let a = queue.push_front(empty, 1)
let b = queue.push_back(empty, 1)
a == b
// -> False
```

إذا احتجت إلى مقارنة طابورين من أجل التساوي، يمكنك استخدام دالة `queue.is_logically_equal`.

```gleam
queue.is_logically_equal(a, b, fn(x, y) { x == y })))
// -> True
```
