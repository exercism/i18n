# مقدمة

في Common Lisp يمكن للدالة أن تحتوي على معاملات مُسمّاة (يُشار إليها باسم «المعاملات المفتاحية»).
وتُحدَّد هذه المعاملات في قائمة لامدا بكلمة قائمة لامدا المفتاحية `&key`.
المعاملات المفتاحية ليست معاملات مطلوبة.
ومثل المعاملات الاختيارية، يمكن أن تُعطى قيمًا افتراضية، ورموزًا تُربط بحالتها: هل قُدِّم المعامل أم لا.

عند استدعاء دالة لها معاملات مفتاحية، يُكتب اسم المعامل ككلمة مفتاحية قبل قيمة المعامل.
ويمكن لمستدعي الدالة أن يحدد المعاملات المفتاحية بأي ترتيب.

```lisp
(defun keyword-parameters (&key x (y 'default) (z nil z-supplied-p))
  (list x y (if z-supplied-p (list :z-was-supplied z)
                             (list :z-was-not-supplied z))))

(keyword-parameters)            ; => (NIL DEFAULT (:Z-WAS-NOT-SUPPLIED NIL))
(keyword-parameters :y 5)       ; => (NIL 5 (:Z-WAS-NOT-SUPPLIED NIL))
(keyword-parameters :z 10 :x 5) ; => (5 DEFAULT (:Z-WAS-SUPPLIED 10))
```

يجب توخي الحذر عند الجمع بين المعاملات الاختيارية والمعاملات المفتاحية، لأن المعاملات الاختيارية قد تستهلك اسم الكلمة المفتاحية والوسيط:

```lisp
(defun could-be-confusing (&optional x y &key z) (list x y z))
(could-be-confusing :z 'huh?) ; => (:Z HUH? NIL)
```
