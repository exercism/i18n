# التعليمات

مرحبًا، أيها العميل Double-Null0111.

مهمتك، إن اخترت قبولها، هي كتابة أداتين تساعدانك على التسلل إلى مقر UMBRA (United Minions Being Really Awful) واستعادة مخططات أحدث خططهم الشنيعة. ستحتاج إلى أداتين لإنجاز هذه المهمة.

## 1. احمِ الخطط السرية المستعادة بكلمة مرور

بعد حصولك على الخطط السرية، ستحتاج إلى حمايتها بحيث لا يتمكن من استعادتها إلا من يعرف كلمة المرور.

للقيام بذلك، ستحتاج إلى تنفيذ الدالة `protectSecret(_ secret: String, withPassword password: String) -> (String) -> String`.
ستُرجع هذه الدالة دالة أخرى تأخذ سلاسل نصية محتملة لكلمات المرور كمدخل.
إذا كانت كلمة المرور المُدخَلة صحيحة، تُرجع الدالة الجديدة السر المخفي، أما إذا كانت كلمة المرور غير صحيحة، فتُرجع الدالة "Sorry. No hidden secrets here."

```swift
let secretFunction = protectSecret("Steal the world's supply of french fries!", withPassword: "5up3r53cr37")

secretFunction("Open sesame")
// Returns "Sorry. No hidden secrets here."

secretFunction("5up3r53cr37")
// Returns "Steal the world's supply of french fries!"
```

## 2. أنشئ تركيبة لفتح خزنتهم

علمنا أن UMBRA تبني جميع تركيبات خزائنها على رقم الغرفة التي تقع فيها.
تُولَّد تركيبات الخزنة بتطبيق دالة خاصة على رقم الغرفة بشكل متكرر.
لذا فإن الرقم الأول في التركيبة ينتج عن تطبيق الدالة على رقم الغرفة، والثاني ينتج عن تطبيق الدالة على الرقم الأول، والثالث عن تطبيق الدالة على الرقم الثاني.

ومع ذلك، تغيّر UMBRA بانتظام الدالة المستخدمة لتوليد التركيبات، لذا ستحتاج أداتك إلى أخذ رقم الغرفة والدالة المناسبة معًا لتوليد التركيبة.

نفّذ الدالة `generateCombination(forRoom room: Int, usingFunction f: (Int) -> Int) -> (Int, Int, Int)` لتوليد التركيبة التي ستحتاج إليها.

```swift
func makeCombo(_ x: Int) -> Int {
  (x * 13) % 256
}

generateCombination(forRoom: 227, usingFunction: makeCombo)
// Returns (135, 219, 31)
```
