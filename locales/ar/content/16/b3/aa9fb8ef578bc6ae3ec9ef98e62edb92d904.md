# مقدمة

عادةً، لا تقبل الدوال إلا عددًا ثابتًا من الوسائط.
لكن إذا أضفت `...` قبل نوع المعامل الأخير، فيمكن للدالة أن تقبل أي عدد من الوسائط اللاحقة.
وهذا يجعل المعامل الأخير _معاملًا متعدّد الوسائط_.

```go
func sum(nums ...int) int {
    total := 0
    for _, n := range nums {
        total += n
    }
    return total
}
```

داخل الدالة، يكون المعامل متعدّد الوسائط شريحة:

```go
sum(1, 2, 3)    // nums is []int{1, 2, 3}
sum(1, 2, 3, 4) // nums is []int{1, 2, 3, 4}
sum()           // nums is []int{}
```

يمكن أن يكون للدالة معاملات غير متعدّدة الوسائط قبل المعامل متعدّد الوسائط.
ويمكن أن تحتوي الدالة على معامل واحد متعدّد الوسائط على الأكثر، ويجب أن يكون هو المعامل الأخير.

```go
func greet(greeting string, names ...string) {
    for _, name := range names {
        fmt.Printf("%s, %s!\n", greeting, name)
    }
}
```

## نشر شريحة

لمرر شريحة إلى المعامل متعدّد الوسائط، أضف `...` بعدها:

```go
nums := []int{1, 2, 3}
sum(nums...) // equivalent to sum(1, 2, 3)
```

لا يصح استخدام `...` إلا عند تمرير شريحة إلى معامل متعدّد الوسائط.
