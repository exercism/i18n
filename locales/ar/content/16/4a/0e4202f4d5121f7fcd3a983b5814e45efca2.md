# مقدمة

تحتاج برامج كثيرة إلى قيم عشوائية (_على ما يبدو_) لمحاكاة أحداث من الواقع.

من الأمثلة الشائعة المألوفة:
- رمي قطعة نقدية: قيمة عشوائية من `('Heads', 'Tails')`.
- رمي حجر نرد: عدد صحيح عشوائي من 1 إلى 6.
- خلط مجموعة أوراق لعب: ترتيب عشوائي لقائمة الأوراق.
- إنشاء الأشجار والشجيرات في محاكاة رسوميات ثلاثية الأبعاد.

يُعد توليد قيم عشوائية _حقيقية_ باستخدام الحاسوب [تحديًا تقنيًا صعبًا بشكل مفاجئ][truly-random]، لذلك قد ترى هذه النتائج مُشارًا إليها باسم «العشوائية الزائفة».

عمليًا، مكتبة مصممة جيدًا مثل وحدة [`random`][random] في مكتبة Python القياسية سريعة ومرنة، وتُعطي نتائج جيدة بما يكفي لمعظم التطبيقات في النمذجة والمحاكاة والألعاب.

في هذه المقدمة الموجزة، نعرض الدوال الأربع الأكثر استخدامًا من هذه الوحدة.
نشجعك على استكشاف توثيق [`random`][random] الكامل، إذ توجد أدوات وخيارات كثيرة.


~~~~exercism/caution

بدلًا من ذلك، تُوفر Python وحدة [`secrets`][secrets].
فهي مُحسّنة خصيصًا للأمان التشفيري.

قبل أن تتمكن من استخدام الأدوات في وحدة `random`، عليك أولًا استيرادها:

```python
>>> import random

# Choose random integer from a range
>>> random.randrange(1000)
360

>>> random.randrange(-1, 500)
228

>>> random.randrange(-10, 11, 2)
-8

# Choose random integer between two values (inclusive)
>>> random.randint(5, 25)
22

```

لتجنب كتابة اسم الوحدة، يمكنك استيراد دوال معينة بالاسم:

```python
>>> from random import choice, choices

# Using choice() to pick Heads or Tails 10 times
>>> tosses = []
... for side in range(10):
...    tosses.append(choice(['H', 'T']))    

>>> print(tosses)
['H', 'H', 'H', 'H', 'H', 'H', 'H', 'T', 'T', 'H']


# Using choices() to pick Heads or Tails 8 times
>>> picks = []
... picks.extend(choices(['H', 'T'], k=8))
... print(picks)
['T', 'H', 'H', 'T', 'H', 'H', 'T', 'T']
```



## الدالتان `randrange()` و`randint()`

كما ظهر في المثال الأول أعلاه، للدالة `randrange()` ثلاث صيغ:

1. تُعطي `randrange(stop)` عددًا صحيحًا `n` بحيث `0 <= n < stop`
2. تُعطي `randrange(start, stop)` عددًا صحيحًا `n` بحيث `start <= n < stop`
3. تُعطي `randrange(start, stop, step)` عددًا صحيحًا `n` بحيث `start <= n < stop`
    و`n` ينتمي إلى المتتابعة `start, start + step, start + 2*step...`

في الحالة الأكثر شيوعًا حيث `step == 1`، قد تكون `randint(a, b)` أكثر ملاءمة وسهولة في القراءة.
النتائج المحتملة من `randint()` _تشمل_ الحد الأعلى، لذا فإن `randint(a, b)` تكافئ استخدام `randrange(a, b+1)`.



## الدالتان `choice()` و`choices()`

تفترض هاتان الدالتان أنك تبدأ من [متتابعة][sequence-types] أو أي حاوية أخرى.
وهذه عادةً من نوع `list`، أو مع بعض القيود من نوع `tuple` أو `set` (_`tuple` غير قابل للتغيير، و`set` غير مرتّبة_).

تُرجع الدالة `choice()` عنصرًا واحدًا مختارًا عشوائيًا من متتابعة معينة، وتُرجع `choices()` عددًا محددًا من العناصر (`k`) مختارة عشوائيًا من متتابعة معينة.
في الأمثلة أعلاه، افترضنا قطعة نقدية عادلة باحتمال متساوٍ لظهور الوجه أو الظهر، لكن يمكن أيضًا تحديد الأوزان.

على سبيل المثال، إذا كان كيس يحتوي على 10 كرات حمراء و15 كرة خضراء، وأردنا سحب واحدة منه عشوائيًا:


```python
>>> random.choices(['red', 'green'], [10, 15])
['red']
```
