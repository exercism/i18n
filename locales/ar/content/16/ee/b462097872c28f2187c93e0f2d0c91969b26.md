# مقدمة

في Go، `struct` هو تسلسل من عناصر مسماة تُسمى _الحقول_، ولكل حقل اسم ونوع.
ويجب أن يكون اسم الحقل فريدًا داخل `struct`.
ويمكن مقارنة `struct` بـ _الأصناف_ في نمط البرمجة كائنية التوجّه.

## تعريف `struct`

تُنشئ `struct` جديدة باستخدام الكلمتين المفتاحيتين `type` و `struct`، وتحدّد اسم الحقول ونوعها صراحةً.
على سبيل المثال، نعرّف هنا `struct` تُسمى `Shape`، وهي تحمل اسم شكل وحجمه:

```go
type Shape struct {
    name string
    size int
}
```

تتبع أسماء الحقول في `struct` اصطلاح Go: فالحقول التي يبدأ اسمها بحرف صغير لا تكون مرئية إلا للكود الموجود في الحزمة نفسها، أما الحقول التي يبدأ اسمها بحرف كبير فتكون مرئية في الحزم الأخرى.

## إنشاء نسخ من `struct`

بعد أن تُعرّف `struct`، تحتاج إلى إنشاء نسخة جديدة تحدّد فيها الحقول باستخدام أسماء الحقول وبأي ترتيب:

```go
s := Shape {
    name: "Square",
    size: 25,
}
```

لقراءة حقول النسخة أو تعديلها، استخدم ترميز النقطة `.`:

```go
// Update the name and the size
s.name = "Circle"
s.size = 35
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 35
```

الحقول التي لم تُسنَد إليها قيمة أولية ستأخذ قيمتها الصفرية.
على سبيل المثال:

```go
s := Shape{name: "Circle"}
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 0
```

يمكنك إنشاء نسخة من `struct` دون استخدام أسماء الحقول، ما دمت تحدّد الحقول _بالترتيب_:

```go
s := Shape {
	"Oval",
	20,
}
```

غير أن هذا التركيب يُعدّ _كودًا هشًا_، لأنه قد يتعطل عند إضافة حقل، خصوصًا إذا كان الحقل الجديد من نوع مختلف.
في المثال التالي، نضيف حقلًا إضافيًا إلى `Shape`:

```go
type Shape struct {
	name        string
	description string // new field 'description' added
	size        int
}

s := Shape{
    "Circle",
    20,
}
// Since the second field of the struct is now a string and not an int,
// the compiler will throw an error when compiling the program:
// Output: cannot use 20 (type untyped int) as type string in field value
// Output: too few values in Shape{...}
```

## دوال `New`

أحيانًا يكون من الجيد أن تكون لدينا دوال تساعدنا في إنشاء نسخ من `struct`.
بحسب الاصطلاح، تُسمى هذه الدوال عادةً `New` أو تبدأ أسماؤها بـ `New`، ولكن لأنها مجرد دوال عادية، يمكنك أن تمنحها أي اسم تريد.
قد تذكّرك بالدوال المنشئة في لغات أخرى، لكنها في Go ليست سوى دوال عادية.

في المثال التالي، تُستخدم إحدى دوال `New` لإنشاء نسخة جديدة من `Shape` وتعيين قيمة افتراضية للحقل `size` في الشكل تلقائيًا:

```go
func NewShape(name string) Shape {
	return Shape{
		name: name,
		size: 100, //default-value for size is 100
	}
}

NewShape("Triangle")
// => Shape { name: "Triangle", size: 100 }

```

قد يكون لاستخدام دوال `New` المزايا التالية:

* التحقق من القيم المعطاة
* التعامل مع القيم الافتراضية
* بما أن دوال `New` تُعرَّف غالبًا في الحزمة نفسها التي تحتوي على `struct` التي تهيّئها، فيمكنها تهيئة الحقول الخاصة في `struct` أيضًا
