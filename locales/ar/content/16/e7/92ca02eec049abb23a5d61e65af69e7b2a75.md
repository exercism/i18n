# مقدمة

تضم وحدة `gleam/order` في مكتبة Gleam القياسية النوع `Order`، وهو يُستخدم لمقارنة القيم.

يبدو تعريف `Order` هكذا:

```gleam
pub type Order {
  Gt
  Eq
  Lt
}
```

للنوع ثلاث صيغ، تُستخدم كل واحدة منها لتمثيل العلاقة بين قيمة وقيمة أخرى:

- `Gt` - القيمة _أكبر_ من القيمة الأخرى.
- `Eq` - القيمة _مساوية_ للقيمة الأخرى.
- `Lt` - القيمة _أصغر_ من القيمة الأخرى.

إذا كان يمكن مقارنة نوع بيانات ما حسب الحجم، فمن الشائع أن تُعرّف الوحدة دالة `compare` تُرجع قيمة من نوع `Order`. على سبيل المثال، تُعرّفان وحدتا `gleam/float` و `gleam/int` دالتَي `compare` اللتين تعملان على الأعداد العشرية والأعداد الصحيحة على التوالي.

```gleam
int.compare(1, 2)
// -> Lt

int.compare(2, 2)
// -> Eq

float.compare(1.0, 2.0)
// -> Lt
```

عادةً ما تأخذ دوال الترتيب مثل `list.sort` دالةً تُرجع قيمة من نوع `Order`، ما يتيح للمستدعي تحديد كيفية ترتيب المصفوفة.

```gleam
list.sort([3, 7, 3, 1], by: int.compare)
// -> [1, 3, 3, 7]
```
