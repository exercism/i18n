# تلميحات

## 1. توليد كوكب عشوائي

- لا توفّر Java دالة لاختيار عنصر من مجموعة بشكل عشوائي.
- تذكّر أن بإمكانك استرجاع عنصر من مصفوفة عبر فهرسه، والفهرس عدد صحيح.

## 2. توليد رقم تسجيل عشوائي لسفينة الفضاء

- يوفّر الصنف `java.util.Random` طريقة لتوليد قيمة `int` عشوائية بين 0 وحد أقصى معطى.

## 3. توليد تاريخ نجمي عشوائي

- تُرجع طريقة الصنف `java.util.Random` لتوليد قيمة `double` عشوائية دائمًا عددًا بين `0.0` و`1.0`.
