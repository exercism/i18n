# مقدمة

تحتاج أحيانًا إلى النظر إلى تسلسل باعتباره تتابعًا من *القطع* بدلًا من التعامل معه عنصرًا عنصرًا. تمنحك مفردات [`grouping`][grouping] و[`splitting`][splitting] و[`splitting.monotonic`][splitting.monotonic] أربع طرق لفعل ذلك.

## `group`: كتل منفصلة بحجم *n*

```
group ( seq n -- groups )
```

```factor
USING: grouping ;

{ 1 2 3 4 5 6 7 } 3 group .
! => { { 1 2 3 } { 4 5 6 } { 7 } }
```

إذا لم يكن طول التسلسل من مضاعفات *n*، تكون الكتلة الأخيرة أقصر من *n*.

## `clump`: نافذة منزلقة متداخلة بحجم *n*

```
clump ( seq n -- clumps )
```

```factor
USING: grouping ;

{ 1 2 3 4 5 } 2 clump .
! => { { 1 2 } { 2 3 } { 3 4 } { 4 5 } }
```

إذا كان التسلسل أقصر من *n*، تكون النتيجة فارغة.

## `split-when`: التقسيم حيثما يتحقق اختبار شرطي

```
split-when ( seq quot: ( elt -- ? ) -- pieces )
```

```factor
USING: splitting ;

{ 1 2 0 3 4 0 5 } [ zero? ] split-when .
! => { { 1 2 } { 3 4 } { 5 } }
```

يحصل كل عنصر على استدعاء الاختبار الشرطي الخاص به؛ العناصر التي يُرجع عنها قيمة صحيحة هي *نقاط القطع* ولا تُحتفظ بها في النتيجة.

## `monotonic-split`: تقسيم المقاطع المتتالية عندما يفشل فحص الزوج المتجاور

```
monotonic-split ( seq quot: ( a b -- ? ) -- pieces )
```

```factor
USING: splitting.monotonic ;

{ 1 1 2 2 2 3 } [ = ] monotonic-split .
! => { { 1 1 } { 2 2 2 } { 3 } }
```

يعمل الاختبار الشرطي على *الأزواج المتجاورة*. ما دام يُرجع قيمة صحيحة، يستمر المقطع؛ وعندما يُرجع `f`، يبدأ مقطع جديد. مع `[ = ]` تحصل على مقاطع من عناصر متساوية؛ ومع `[ <= ]` تحصل على مقاطع غير متناقصة؛ وهكذا.

## متى تستخدم أيًّا منها

- **`group`/`clump`**: تعرف *الحجم* الذي تريده.
- **`split-when`**: تعرف كيف يبدو *عنصر القطع*.
- **`monotonic-split`**: تعرف ما الذي يجعل عنصرين متجاورين *ينتميان معًا*.
