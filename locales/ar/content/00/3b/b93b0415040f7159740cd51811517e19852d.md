# الاختبارات

ستحتاج إلى تثبيت [Godot][installation] بشكل صحيح لاستخدام مشغّل الاختبارات.

## تشغيل الاختبارات

يُستخدم [مشغّل الاختبارات][test runner] لتحميل الحلول واختبارها.
لتشغيل مشغّل الاختبارات، نزّله محليًا ثم شغّله باستخدام `godot`.
في المستقبل، سيُنزَّل مشغّل الاختبارات تلقائيًا مع التمارين عند استخدام `exercism download`.

### تنزيل مشغّل الاختبارات

يمكن استخدام مقتطف الصدفة التالي لتنزيل مشغّل الاختبارات.

```bash
exercism download --track gdscript --exercise hello-world
cd "$(exercism workspace)/gdscript"
curl --remote-name https://raw.githubusercontent.com/exercism/gdscript-test-runner/refs/heads/main/bin/test_runner.gd
```

### تشغيل مشغّل الاختبارات

يُشغَّل مشغّل الاختبارات باستخدام `godot` في الوضع بلا واجهة (بدون IDE).
يخبر `-s` أو `--script` برنامج Godot بتشغيل نص مشغّل الاختبارات.
يتوقّع مشغّل الاختبارات وسيطين: المُعرّف المختصر ومسار مجلد الحل.

```bash
godot --headless -s to/test_runner.gd -- <solution-slug> <path/to/solution>
```

على سبيل المثال،

```bash
godot --headless -s "$(exercism workspace)/gdscript/test_runner.gd" -- hello-world "$(exercism workspace)/gdscript/hello-world
```
