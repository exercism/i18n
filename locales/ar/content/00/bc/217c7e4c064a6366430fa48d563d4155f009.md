# مقدمة

من الطرق الشائعة لتنفيذ منطق بشكل شرطي في JavaScript استخدام الجملة الشرطية `if`.
وتتكوّن من الكلمة المفتاحية `if`، ومن شرط محاط بالأقواس الهلالية، وكتلة كود محاطة بالأقواس المعقوفة.
ولا تُنفَّذ كتلة الكود إلا إذا كان ناتج تقييم الشرط هو `true`.

```javascript
if (condition) {
  // code that is executed if "condition" is true
}
```

ويمكن استخدامها وحدها أو مع الكلمة المفتاحية `else`.

```javascript
if (condition) {
  // code that is executed if "condition" is true
} else {
  // code that is executed otherwise
}
```

ولتضمين شرط آخر داخل فرع `else` يمكنك استخدام `else if`.

```javascript
if (condition1) {
  // code that is executed if "condition1" is true
} else if (condition2) {
  // code that is executed if "condition2" is true
  // but "condition1" was false
} else {
  // code that is executed otherwise
}
```
