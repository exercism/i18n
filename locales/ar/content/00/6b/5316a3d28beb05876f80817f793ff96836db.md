# نبذة

يمكن إرسال الدوال في Elixir ديناميكيًا.

جميع أسماء الوحدات هي ذرات. وتُضاف البادئة `Elixir.` تلقائيًا إلى جميع أسماء وحدات Elixir عند ترجمتها.

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```

تستطيع Elixir تحديد الدالة التي ستُستدعى في وقت التشغيل، باستخدام اسم الوحدة لإجراء عملية البحث. ويمكن إجراء هذا البحث ديناميكيًا إذا كان اسم الوحدة مرتبطًا بمتغير.

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```
