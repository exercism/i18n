# مقدمة

`string` في Go هو تسلسل ثابت من البايتات، لا يلزم أن يمثّل أحرفًا بالضرورة.

تُكتب السلسلة النصية الحرفية بين علامتي تنصيص مزدوجتين:

```go
const name = "Jane"
```

يمكن دمج السلاسل النصية باستخدام العامل `+`:

```go
"Jane" + " " + "Austen"
// => "Jane Austen"
```

بعض الأحرف الخاصة يجب تهريبها بشرطة مائلة عكسية تسبقها، مثل `\t` لعلامة الجدولة و`\n` لسطر جديد داخل السلاسل النصية.

```go
"How is the weather today?\nIt's sunny"  
// =>
// How is the weather today?
// It's sunny
```

تحتوي حزمة `strings` على دوال مفيدة كثيرة للعمل على السلاسل النصية.
لمزيد من المعلومات عن دوال السلاسل النصية، راجع [توثيق حزمة strings](https://pkg.go.dev/strings).
وفيما يلي بعض الأمثلة:

```go
import "strings"

// strings.ToLower returns the string given as argument with all its characters lowercased
strings.ToLower("MaKEmeLoweRCase")
// => "makemelowercase"

// strings.Repeat returns a string with a substring given as argument repeated many times
strings.Repeat("Go", 3)
// => "GoGoGo"
```
