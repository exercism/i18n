# الأساسيات

برنامج Sather مكوّن من **أصناف**. الصنف هو صندوق مُسمّى يحتوي على إجراءات. و**الإجراء** هو قطعة عمل مُسمّاة تنتج إجابة.

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

end; -- class GREETER
```

لنقرأ ذلك من الأعلى:

- `class GREETER is` يفتح الصندوق ويسمّيه. أسماء الأصناف تُكتب بحروف كبيرة.
- `hello : STR is` يبدأ إجراءً اسمه `hello` ينتج `STR`، وهي قطعة نصية تُسمى *سلسلة نصية*. و`: STR` وعد بنوع الإجابة التي ستعود.
- `return "Hello!";` يُرجع الإجابة. يُكتب النص بين علامتي اقتباس مزدوجتين.
- `end;` يغلق الإجراء، و`end;` الثانية تغلق الصنف.

كل ما يأتي بعد `--` في السطر هو **تعليق**. Sather يتجاهله؛ فهو موجود من أجل الناس.

```sather
-- This line is for the reader, not the computer.
```

لاستخدام إجراء من مكان آخر، اكتب اسم الصنف، ثم نقطتين، ثم اسم الإجراء:

```sather
GREETER::hello        -- this is "Hello!"
```

داخل الصنف نفسه، يمكنك الاستغناء عن اسم الصنف:

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

   greeting_again : STR is
      return hello;      -- calls the routine just above
   end;

end; -- class GREETER
```

الإجراء الذي لا يأخذ وسائط يُستدعى بدون الأقواس الهلالية، أي `hello` وليس `hello()`.
