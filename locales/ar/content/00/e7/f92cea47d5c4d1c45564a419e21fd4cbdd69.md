# مقدمة

## الأصناف

الأصناف وحدة من وحدات تنظيم الكود في PHP.
يمكن تجميع الكود الذي يمثّل سلوك عنصر ما أو سلوك عملية ما في صنف واحد.
وبحكم الاصطلاح، تُسمّى الدوال التي تُسنَد إلى صنف `methods`.

```php
<?php

class Door
{
    function lock()
    {
        // ...
    }

    function unlock()
    {
        // ...
    }
}
```

نُنشئ نسخة من الصنف بالكلمة المفتاحية `new`، وهذا يخصّص ذاكرة لنسخة الصنف ويستدعي طريقة البناء الخاصة بالصنف.
ويمكن إسناد الأصناف المُنشأة إلى متغير.
ولاستدعاء طُرق نسخة صنف ما، يمكننا استخدام عامل الوصول `->`.

```php
<?php

$a_door = new Door();
$a_door->lock();
$a_door->unlock();
```

يمكن للصنف المُنشأ أن يشير إلى نسخته الخاصة باستخدام المتغير الخاص `$this`.
وقد تمتلك الأصناف أيضًا خصائص، وهي تعمل بمثابة متغيرات مرتبطة بنسخة كائن الصنف.
ويمكن الإشارة إلى هذه الخصائص داخليًا أو خارجيًا.

```php
<?php

class Car
{
    public $color;

    function __construct($color)
    {
        $this->color = $color;
    }

    function getColor()
    {
        return $this->color;
    }
}

$a_car = new Car("red");
$a_car->color; // => "red" by accessing the property
$a_car->getColor(); // => "red" by invoking the instance method
```
