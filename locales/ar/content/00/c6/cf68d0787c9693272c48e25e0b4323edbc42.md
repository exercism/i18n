# مقدمة

الصفوف طريقة خفيفة لتجميع مجموعة ثابتة من البيانات ذات أنواع متعددة معًا. ولا يحمل الصف اسمًا بعينه؛ فتسمية بنية البيانات تحوّلها إلى `struct`. كما أن حقول الصف بلا أسماء؛ إذ يتم الوصول إليها عبر التفكيك أو عبر الموضع.

## الصياغة

### الإنشاء

تُنشأ الصفوف دائمًا بتعبير صفّي:

```rust
// pointless but legal
let unit = ();
// single element
let single_element = ("note the comma",);
// two element
let two_element = (123, "elements can be of differing types");
```

ويمكن أن يحتوي الصف على أي عدد من العناصر.

### الوصول عبر التفكيك

يمكن الوصول إلى عناصر الصف عبر التفكيك. وهذا يعني ببساطة إسناد أسماء متغيرات إلى كل عنصر من عناصر الصف، مما يستهلك الصف نفسه.

```rust
let (elem1, _elem2) = two_element;
assert_eq!(elem1, 123);
```

### الوصول عبر الموضع

يمكن أيضًا الوصول إلى عناصر الصف عبر فهرس موضعي رقمي. والفهرسة، كما هو الحال دائمًا، تبدأ من 0.

```rust
let notation = single_element.0;
assert_eq!(notation, "note the comma");
```

## بنى الصف

سيُطلب منك أيضًا العمل مع بنى الصف. ومثل البنى العادية، هذه أنواع مُسمّاة؛ وعلى خلاف البنى العادية، لها حقول مجهولة. وصياغتها شبيهة جدًا بصياغة الصفوف العادية. ويجوز استخدام كلٍّ من التفكيك والوصول عبر الموضع.

```rust
struct TupleStruct(u8, i32);
let my_tuple_struct = TupleStruct(123, -321);
let neg = my_tuple_struct.1;
let TupleStruct(byte, _) = my_tuple_struct;
assert_eq!(neg, -321);
assert_eq!(byte, 123);
```

### ظهور الحقول

جميع حقول الصفوف المجهولة عامة دائمًا. أما حقول بنى الصف فلكل حقل منها ظهوره الخاص الذي يكون خاصًّا افتراضيًا، تمامًا كحقول البنى العادية. ويمكنك جعل الحقول عامة باستخدام المُعدِّل `pub`، تمامًا كما في البنية العادية.

```rust
// fails due to private fields
mod tuple { pub struct TupleStruct(u8, i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```

```rust
// succeeds: fields are public
mod tuple { pub struct TupleStruct(pub u8, pub i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```
