# التعليمات

أثناء عملك في _Instruments of Texas_، تُكلَّف بالعمل على آلة حاسبة تجريبية بالترميز البولندي المعكوس [RPN] مكتوبة بلغة Elixir. يواجه فريقك مشكلة تتمثل في أن بعض العمليات ترفع أخطاء وتتسبب في انهيار العملية. وقد أُوكلت إليك مهمة كتابة دالة تُغلّف دالة العملية بحيث يمكن التعامل مع الأخطاء بأسلوب أكثر أناقة باستخدام كود Elixir اصطلاحي.

## 1. حذّر الفريق

نفّذ الدالة `calculate!/2` لاستدعاء دالة العملية مع تمرير المكدس كوسيط وحيد. دالة العملية معرّفة في مكان آخر، لكنك تعرف أنها إما أن تكتمل بنجاح أو ترفع خطأ.

```elixir
stack = []
operation = fn _ -> :ok end
RPNCalculator.calculate!(stack, operation)
# => :ok

stack = []
operation = fn _ -> raise ArgumentError, "An error occurred" end
RPNCalculator.calculate!(stack, operation)
# => ** (ArgumentError) An error occurred
```

> أسماء الدوال التي تنتهي بعلامة `!` هي تنبيه للمبرمجين إلى أن هذه الدالة قد ترفع خطأ

## 2. غلّف الخطأ

عند إجراء مزيد من البحث، تلاحظ أن العديد من الدوال تستخدم الذرات والصفوف للإشارة إلى نجاحها أو فشلها. نفّذ `calculate/2` باستخدام هذه الاستراتيجية.

```elixir
stack = []
operation = fn _ -> "operation completed" end
RPNCalculator.calculate(stack, operation)
# => {:ok, "operation completed"}

stack = []
operation = fn _ -> raise ArgumentError, "An error occurred" end
RPNCalculator.calculate(stack, operation)
# => :error
```

## 3. انقل الرسالة

تحتوي بعض الأخطاء على معلومات مهمة يحتاج زملاؤك في العمل إلى معرفتها لضمان التشغيل الصحيح للنظام. نفّذ `calculate_verbose/2` لنقل رسالة الخطأ. الخطأ عبارة عن بنية تحتوي على حقل `:message`.

```elixir
stack = []
operation = fn _ -> "operation completed" end
RPNCalculator.calculate_verbose(stack, operation)
# => {:ok, "operation completed"}

stack = []
operation = fn _ -> raise ArgumentError, "An error occurred" end
RPNCalculator.calculate_verbose(stack, operation)
# => {:error, "An error occurred"}
```
