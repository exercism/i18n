# ملحق التعليمات

## صيغة الإدخال

معامل `board`، الذي يمثّل لوحة اللعب، يكون على هيئة مصفوفة من السلاسل النصية.

```javascript
['  B  ', ' B B ', 'B W B', ' W W ', '  W  '];
```

يمثّل كل حرف في السلسلة النصية خلية.
القيم الصحيحة للخلية هي:

- ` ` مسافة بيضاء تقابل خلية فارغة
- `B` خلية يملكها اللاعب الأسود
- `W` خلية يملكها اللاعب الأبيض

## صيغ الإخراج

يُتوقع من الدالة `getTerritory` أن تُرجع كائنًا له خاصيتان:

- `owner` مالك المنطقة (`NONE` أو `BLACK` أو `WHITE`)
- `territory` مصفوفة من الإحداثيات تمثّل كل خلية في المنطقة.

```javascript
{
    owner: 'BLACK',
    territory: [
        [0, 0],
        [0, 1],
        [1, 0],
    ],
}
```

يُتوقع من الدالة `getTerritories` أن تُرجع كائنًا له 3 خصائص:

- `territoryBlack` مصفوفة من الإحداثيات تمثّل المناطق التي يملكها اللاعب `BLACK`
- `territoryWhite` مصفوفة من الإحداثيات تمثّل المناطق التي يملكها اللاعب `WHITE`
- `territoryNone` مصفوفة من الإحداثيات تمثّل المناطق التي لا يملكها أيٌّ من اللاعبَين

```javascript
{
    territoryBlack: [
        [0, 0],
        [0, 1],
    ],
    territoryWhite: [
        [3, 0],
        [3, 1],
    ],
    territoryNone: [],
}
```
