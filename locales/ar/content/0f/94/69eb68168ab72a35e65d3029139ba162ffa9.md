# مقدمة

الدالة كتلة من الكود المنظَّم القابل لإعادة الاستخدام، وتُستخدم لتنفيذ إجراء ما.
هناك أساليب متعددة لتعريف الدوال في JavaScript.
سنتناول هنا _تصريحات الدوال_ و_تعبيرات الدوال_.
وسنغطي احتمالات أخرى مثل [الدوال السهمية][concept-arrow-functions] في مفاهيم أخرى.

## تصريح دالة

الأسلوب المعتاد لتعريف دالة في JavaScript هو _تصريح الدالة_، ويُسمى أيضًا _تعريف الدالة_ أو _عبارة الدالة_.

ويتكوّن من الكلمة المفتاحية `function`، واسم الدالة، وقائمة معاملات مفصولة بفواصل داخل الأقواس الهلالية.
ويتبع ذلك جسم الدالة (مجموعة العبارات التي تحدّد ما تفعله الدالة) محصورًا بين الأقواس المعقوفة.

```javascript
function someName(param1, param2, param3) {
  // ...
}
```

في JavaScript، تُستدعى الدالة (يُنادى عليها) بكتابة اسم الدالة متبوعًا بأقواس هلالية تحتوي على الوسائط.

```javascript
someName(arg1, arg2, arg3);
```

## المعاملات

عند التعامل مع المعاملات داخل جسم الدالة، انتبه إلى الآثار الجانبية المحتملة.

- قيم [أنواع البيانات الأولية][mdn-primitives] _غير قابلة للتغيير_.
  فلا تتأثر القيمة الأصلية أبدًا بما يحدث للوسيط داخل جسم الدالة.
- أما بقية القيم (الكائنات والمصفوفات والدوال)، فإن إعادة الإسناد لا تؤثر على القيمة الأصلية.
  لكن إذا عدّلت وسيطًا كهذا (مثلًا بإضافة مفتاح إلى كائن)، فسيؤدي ذلك أيضًا إلى تعديل القيمة الأصلية التي مُرّرت.

افتراضيًا، جميع المعاملات المعرَّفة في تصريح الدالة اختيارية في JavaScript.
وإذا مرّرت وسائط أقل من عدد المعاملات، فستكون الوسائط الناقصة `undefined` داخل الدالة، راجع [`null` و`undefined`][concept-null-undefined].
وفي كثير من الحالات يكون من المنطقي إسناد قيمة افتراضية أنسب من `undefined`.
ويمكن فعل ذلك بتحديد معاملات افتراضية مباشرة في تعريف الدالة.

```javascript
function someName(param1 = defaultValue1, param2 = defaultValue2) {
  // ...
}
```

## عبارة `return`

تُنهي عبارة `return` تنفيذ الدالة، وتحدّد قيمة تُرجع إلى من استدعى الدالة. ويمكن أن تحتوي الدالة على عدة عبارات `return`.

```javascript
function checkNumber(num) {
  if (num === 0) {
    return 'You passed 0, please provide another number.';
  }

  return 'Thanks for passing such a nice number.';
}
```

يمكن تخزين القيمة المُرجَعة من الدالة في متغير.

```javascript
function sum(x, y) {
  return x + y;
}

const total = sum(5, 10);
// => 15
```

نتيجة دالة لا تُرجع أي قيمة، أو لا تحتوي على عبارة `return`، هي `undefined`.
ولا توجد عمليات إرجاع ضمنية في JavaScript.

```javascript
function nakedReturn(a) {
  a * 2;
  return;
}

nakedReturn(1);
// => undefined

function noReturn(a) {
  a * 2;
}

noReturn(1);
// => undefined
```

في JavaScript، يمكنك إرجاع قيمة واحدة فقط.
وإذا أردت تمرير معلومات أكثر، عليك دمجها أولًا في كيان واحد، غالبًا في [كائن][concept-objects] أو [مصفوفة][concept-arrays].

```javascript
function divide(a, b) {
  return {
    quotient: Math.floor(a / b),
    remainder: a % b,
  };
}
```

## تعبير دالة

تصريح الدالة عبارة مستقلة.
لكن من المفيد أحيانًا تعريف دالة كجزء من تعبير آخر، مثل داخل إسناد، أو كمعامل دالة ([دالة الاستدعاء الرجعي][concept-callbacks])، أو كقيمة في [كائن][concept-objects].
ويمكن فعل ذلك بتعبير دالة.
صياغته مطابقة لصياغة تصريح الدالة، إلا أنه يمكن حذف اسم الدالة لإنشاء _دالة مجهولة_.

```javascript
const someFunction = function (param) {
  // ...
};

someOtherFunction(function (param) {
  // ...
});

const obj = {
  someFunction: function (param) {
    // ...
  },
};
```
