# مقدمة

يمكن استخدام تعبير `if/elif/else` لتنفيذ المنطق بشكل شرطي. ولدى F# أيضًا طريقة أخرى أقوى لتنفيذ المنطق بشكل شرطي: مطابقة الأنماط. فبمطابقة الأنماط، يمكن اختبار قيمة مقابل _نمط_ واحد أو أكثر. ومن أمثلة هذه الأنماط _نمط الثابت_، الذي يطابق قيمة مقابل ثابت (مثل `1` أو `"hello"`).

في F#، تتم مطابقة الأنماط عبر الكلمة المفتاحية `match`:

```fsharp
let describe number =
    match number with
    | 0 -> "Zero"
    | 1 -> "One"
```

قد يبدو هذا مشابهًا لعبارات `switch` في لغات أخرى، لكن مطابقة الأنماط تبدأ في إظهار قوتها عند استخدام أنماط أخرى أيضًا. ومن هذه الأنماط _نمط المتغير_، الذي يسمح بالتقاط قيمة:

```fsharp
match number with
| 0 -> "Zero"
| i -> sprintf "Non zero: %d" i
```

في بعض الحالات، قد ترغب في إضافة شرط إضافي إلى نمط. ويُعرف هذا بـ_الحارس_ (أو جملة الحارس)، ويمكن إضافته باستخدام الكلمة المفتاحية `when`:

```fsharp
match number with
| 0 -> "Zero"
| i when i < 0 -> "Negative number"
```

في المثال أعلاه، لن يكون لكل المدخلات الممكنة نمط مطابق. سيكتشف المترجم ذلك ويُصدر تحذيرًا. ويُعرف هذا بـ_الفحص الشامل_. وللتخلص من التحذير، يجب معالجة جميع الحالات. ولهذا، يمكن استخدام _نمط البديل العام_، وهو نمط يطابق أي قيمة:

```fsharp
match number with
| i when i < 0 -> "Negative number"
| _ -> "Positive number"

// No compiler warning
```

تختبر مطابقة الأنماط قيمةً ما مقابل كل نمط من الأعلى إلى الأسفل، حتى تجد نمطًا مطابقًا وتنفّذ المنطق المرتبط بذلك النمط. ترتيب الأنماط مهم!
