# مقدمة

يوجد في Java نوعان مختلفان من الأعداد:

- الأعداد الصحيحة: أعداد ليس لها أي رقم بعد الفاصلة العشرية (أعداد كاملة). أمثلة على ذلك: `-6` و`0` و`1` و`25` و`976` و`-500000`.
- الأعداد العشرية: أعداد بها صفر أو أكثر من الأرقام بعد الفاصلة العشرية. أمثلة على ذلك: `-20.4` و`0.1` و`2.72` و`16.984025` و`1024.0`.

النوعان الرقميان الأكثر شيوعًا في Java هما `int` و`double`. إنّ `int` عدد صحيح بطول 32 بت، و`double` عدد عشري بطول 64 بت.

تُجرى العمليات الحسابية باستخدام عوامل الحساب القياسية. ويمكن مقارنة الأعداد باستخدام عوامل المقارنة الرقمية القياسية (مثل `5 > 4` و`4 <= 5`) وعاملي المساواة (`==`) وعدم المساواة (`!=`).

توفّر Java نوعين من التحويلات الرقمية:

1. التحويلات الضمنية: لا تُفقد أي بيانات ولا تُطلب أي صياغة إضافية.
2. التحويلات الصريحة: قد تُفقد البيانات وتُطلب صياغة إضافية على شكل _تحويل قسري_.

ولأن `int` أقل دقة من `double`، فإن التحويل من `int` إلى `double` آمن، ولذلك يُعد تحويلًا ضمنيًا. أما التحويل من `double` إلى `int` فقد يعني فقدان البيانات، لذلك يتطلب تحويلًا صريحًا.
