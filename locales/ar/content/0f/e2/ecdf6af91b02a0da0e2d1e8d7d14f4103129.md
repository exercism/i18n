# مقدمة

تذكّر أن برنامج `jq` هو _خط أنابيب من التعبيرات_.
يخضع **إسناد المتغير** لهذه القاعدة: _إسناد المتغير_ تعبير يبدو هكذا:

```jq
... | expr as $varname | ...
```

## ناتج المرشّح هو مدخله نفسه

مثل _تعبير الهوية_ `.`، فإن ناتج _إسناد المتغير_ هو نفسه مدخله.
أما ضبط قيمة المتغير فهو أثر جانبي.

يوضّح المثال التالي أن `.` بعد الإسناد هو نفسه المدخل الأولي:

```sh
$ jq -c -n '42 | (. * 2) as $double | [., $double]'
[42,84]
```

## نطاق المتغير

نطاق المتغير «معجمي»: يبقى المتغير داخل النطاق لبقية خط الأنابيب.
أما المتغيرات المعرَّفة داخل الدوال (وسنصل إلى الدوال لاحقًا) فهي «محلية» بالنسبة إلى الدالة.

## أسماء المتغيرات

يجب أن يبدأ المتغير بالرمز `$`.
أما بقية اسم المتغير فهي **معرّف**: يبدأ بحرف أو شرطة سفلية، يتبعها حروف أو أرقام أو شرطات سفلية.

## إسناد التفكيك

من الدليل:

> يمكن تعريف عدة متغيرات باستخدام تعبير `as` واحد، عبر توفير نمط _يطابق بنية المدخل_ (ويُعرف هذا بـ«التفكيك»).

أمثلة:

```jq
[1, 2, 3] as [$a, $b, $c]
| [$a, $b, $c]     # => [1, 2, 3]
```

```jq
{"foo": "bar", "len": [10, 20]} as {foo: $f, len: [$h, $w]}
| [$f, $h, $w]     # => ["bar", 10, 20]
```

مطابقة اسم المتغير مع _مفتاح الكائن_ توفّر اختصارًا:

```jq
{"x": 4, "y": 7} as {$x, $y}
| [$x, $y]         # => [4, 7]
```

```jq
{"foo": "bar", "len": [10, 20]} as {$foo, $len}
| [$foo, $len]     # => ["bar", [10, 20]]
```

## الثوابت

كما يوضّح المثال السابق، المتغيرات مفيدة لتخزين الثوابت.
ومن الأفضل أن تُسمّي الثوابت بدلًا من أن تظهر «أرقام سحرية» في الكود.

## غالبًا لا نحتاج إلى المتغيرات

كثيرًا ما يكون حذف المتغيرات أكثر وضوحًا للقراءة.

لننظر في حساب متوسط مصفوفة من الأعداد

```jq
[2, 4, 8, 7]
| add as $sum
| length as $len
| $sum / $len
```

مقارنةً بـ

```jq
[2, 4, 8, 7] | add / length
```

وهذا يُبرز واحدًا من أقوى جوانب `jq`: فمدخل المرشّح يُتاح لـ_كل_ تعبير فرعي:

- تُمرَّر مصفوفة المدخل `[2,4,8,7]` إلى `add` (التي تجمع الأعداد بتطبيق العامل `+` على جميع العناصر)
- _وبالتوازي_، تُمرَّر `[2,4,8,7]` أيضًا إلى `length`
- وعندما تكتمل هذه التعبيرات الفرعية، تُقسَم نتائجها، فتُرجع متوسط قيم الأعداد في مصفوفة المدخل.
