# التثبيت

## أي `awk` لديّ؟

يستخدم مسار AWK في Exercism الأداة `gawk`، وهي نسخة GNU من AWK.
قد تكون مثبتة لديك بالفعل؛ للتحقق من ذلك، نفّذ الأمر التالي:
```sh
awk --version
```

إذا أعاد هذا:

* شيئًا مثل `GNU Awk 5.1.0 ...`
    - فأنت تملك بالفعل نسخة GNU من `awk`، ويمكنك المتابعة مع التمارين.

* شيئًا مثل `awk version 20200816`
    - هذا هو `nawk`، المعروف أيضًا باسم BWK awk (نسبةً إلى Brian Kernighan) أو «one true awk».
    - هذا ما يأتي مرفقًا مع MacOS وأنظمة BSD.
    - اقرأ أدناه للحصول على تعليمات التثبيت.

* الخطأ `awk: not an option: --version`
    - على الأرجح لديك `mawk`.
    - تأكد من ذلك بالأمر: `awk -W version`، وقد يُرجع `mawk 1.3.4 20200120`.
    - `mawk` تنفيذ جيد جدًا وسريع لـ `awk`، لكنه لا يوفّر بعض الميزات الخاصة بـ `gawk` التي سنستخدمها في المسار.
    - اقرأ أدناه للحصول على تعليمات التثبيت.

* الخطأ `awk: unrecognized option: version` متبوعًا بـ `BusyBox v1.35.0 ...`
    - ربما تستخدم Alpine Linux.
    - اقرأ أدناه للحصول على تعليمات التثبيت.

* خطأ «command not found»
    - حينها إما أن يكون `PATH` لديك معطوبًا، أو أنك ببساطة لم تثبّت `awk`.
    - اقرأ أدناه للحصول على تعليمات التثبيت.

### Linux

يختلف الأمر حسب مدير الحزم في توزيعتك. عادةً:
```sh
apt install gawk
yum install gawk
apk add gawk
# and so on
```
قد تحتاج إلى استخدام `sudo` لتنفيذ الأمر المناسب.

### MacOS

‏[Homebrew][brew] صديقك. اتبع الرابط لتثبيته ثم نفّذ:
```sh
brew install gawk
```

### Windows

بالنسبة إلى [WSL][wsl]، راجع تعليمات Linux أعلاه.
أما cygwin، فثبّت حزمة `gawk`.

### التجميع من المصدر

لأصحاب الجرأة، التعليمات [متوفرة في دليل `gawk`][build].
