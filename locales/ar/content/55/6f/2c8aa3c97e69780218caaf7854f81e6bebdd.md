# المصفوفات

المصفوفات في PHP هي خرائط مرتبة.
الخريطة بنية بيانات تربط مفتاحًا بقيمة.
المصفوفات مرنة ويمكن التعامل معها كمصفوفة خطية (كما في `C` أو `Java`)، أو قائمة [متجه]، أو جدول تجزئة، أو قاموس، أو مجموعة، أو مكدس، أو طابور.

المفتاح اختياري، لكنه إن حُدِّد فيجب أن يكون `int` أو `string`.
وعندما لا يُحدَّد مفتاح، تستخدم PHP افتراضيًا مفاتيح من الأعداد الصحيحة بترتيب متزايد، ابتداءً من `0`.

```php
$no_keys = ["my", "first", "array"];
$integer_keys = [0 => "my", 1 => "first", 2 => "array"];

$no_keys == $integer_keys // => equal returns true
$no_keys === $integer_keys // => strictly equal returns true
```

تستطيع المصفوفة تخزين قيم من جميع الأنواع.
ويمكن أن يكون لكل قيمة نوع مختلف.

```php
$my_arr = [
  1,
  "second",
  new \DateTimeImmutable()
];
```

## استخدام المصفوفات

يمكن الإعلان عن المصفوفات بصيغة حرفية (مكتوبة في الكود، كما فعلنا أعلاه) أو إنشاؤها ومعالجتها باستخدام الدوال.

```php
$my_empty_arr = [];

// or
$my_empty_arr = array(); // => []

// or
$letters = mb_str_split("Hello"); // => ["H", "e", "l", "l", "o"] 
```

يمكنك الوصول إلى القيم وإسنادها وإضافتها باستخدام عامل الفهرس:

```php
$prime_numbers = [2, 3, 5, 6];

$prime_numbers[3] = 7; // replace 6 with 7

$prime_numbers[] = 11; // array now contains [2, 3, 5, 7, 11]
```

كرّر على عناصر المصفوفة باستخدام `foreach`:

```php
$names = ["Ani", "Jack", "Rami"]

// Iterate just the values
foreach ($names as $name) {
  echo $name;
}

// Iterate keys and values
foreach ($names as $index => $name) {
  echo "$index => $name";
}
```
