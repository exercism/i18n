# مقدمة

## الأنواع المتداخلة

يمكن تعريف أنواع C# ضمن نطاق صنف أو بنية. يوفّر النوع الحاوي نوعًا من مساحة الأسماء. يتم الوصول إلى النوع عبر النوع الحاوي باستخدام صيغة النقطة.

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

يمكنك تحديد مستويات الوصول للأنواع الداخلية.

تكون أعضاء النوع الخارجي الخاصة ضمن نطاق أعضاء النوع الداخلي، ولكن ليس العكس.
