# المقدمة

نوع `Option` هو الآلية التي توفّرها لغة F# للتعامل مع القيم التي قد توجد أو لا توجد.
وهو يوفّر بديلًا آمنًا من ناحية الأنواع لاستخدام `null`، الشائع في لغات أخرى للتعامل مع مثل هذه القيم.
ويُستخدم في الكثير من دوال مكتبة F# القياسية، لذا فإن فهمه ضروري للاستخدام الفعّال لمكتبة F# القياسية.

## الاستخدام 

نوع `Option` هو نوع عام (له نوع أساسي).  
تكون قيم `Option` إما `Some value`، وهي تمثّل قيمة محددة، وإما `None`، وهي تمثّل غياب أي قيمة.

توضّح الدالة التالية كيفية إنشاء قيمة `Option`:

```fsharp
let keepIfPositive (a: int) : int option = if a > 0 then Some a else None
```

~~~~exercism/note
`T option` هي صيغة لاحقة مكافئة لـ `Option<T>`؛ ويمكن استخدام صيغتَي الكتابة هاتين بالتبادل.
لكن وفقًا لدليل أسلوب F#، تُفضَّل الصيغة اللاحقة مع أنواع `Option` (انظر [قسم تنسيق الأنواع وتوصيفات الأنواع في دليل أسلوب F#](https://learn.microsoft.com/en-us/dotnet/fsharp/style-guide/formatting#for-types-prefer-prefix-syntax-for-generics-foot-with-some-specific-exceptions)). 
~~~~

## قراءة محتوى قيمة `Option`

أفضل أسلوب لقراءة قيمة `Option` هو مطابقة الأنماط، كما يوضّح المثال التالي:

```fsharp
// Returns "Hello, <name>!" if the name is provided; otherwise returns "Hello, you!"
let sayHello (optionalName: string option): string = 
    match optionalName with
    | Some name -> "Hello, " + name + "!"
    | None -> "Hello, you!"

sayHello (Some "Matthieu")
// --> "Hello, Matthieu!"

sayHello None
// --> "Hello, you!"
```

## فك تغليف `Option` باستخدام القيم الافتراضية

يمكن "فك تغليف" قيم `Option` (أي تحويلها إلى النوع الذي تحتويه) من خلال توفير قيم افتراضية باستخدام الدالة `Option.defaultValue`. 
وهذا مفيد بشكل خاص عندما تريد التأكد من أن القيمة ليست `None`.
على سبيل المثال:

```fsharp
Option.defaultValue "" (Some "F#")
// --> "F#"

Option.defaultValue 0 None
// --> 0
```
