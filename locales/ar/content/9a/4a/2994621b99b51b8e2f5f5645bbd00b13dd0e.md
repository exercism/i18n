# التعليمات

توجد مدرسة محلية قريبة منك لديها جمعية طلاب نشطة للغاية. تُدار جمعية الطلاب بواسطة رئيس، وكل سنتين تُجرى انتخابات لانتخاب رئيس جديد.

في انتخابات هذا العام، تقرر أن هناك حاجة إلى نظام رقمي جديد لعدّ الأصوات. تحتاج المدرسة إلى مساعدتك في بناء هذا النظام الجديد.

## 1. الحصول على عدد الأصوات من `ElectionResult`

سيحتاج النظام الجديد إلى وسيلة للحصول على عدد الأصوات من عدّاد.

تم إنشاء بنية نتيجة الانتخابات مسبقًا، وهي معرّفة كما يلي:

```cpp
struct ElectionResult {
    // Name of the candidate
    std::string name{};
    // Number of votes the candidate has
    int votes{};
};
```

بما أن جميع الأعضاء في `struct` عامة، لا تحتاج إلى كتابة `constructor` لتهيئة كائن `ElectionResult`. يمكنك استخدام `initializer list` بدلاً من ذلك:

```cpp
ElectionResult hamilton{"Alex", 1804};
// => the hamilton object was initialized with the name "Alex" and 1804 votes.
```

أنشئ دالة `vote_count` تأخذ مرجعًا إلى `ElectionResult` كوسيط وتُرجع عدد الأصوات في `ElectionResult`.

```cpp
vote_count(hamilton);
// => 1804
```

## 2. زيادة أصوات `ElectionResult`

حان وقت معالجة الأصوات أخيرًا! الآن تحتاج إلى وسيلة لزيادة الأصوات في `ElectionResult`.

أنشئ دالة `void` باسم `increment_vote_count` تأخذ مرجعًا إلى `ElectionResult` كوسيط وعددًا من الأصوات، وتزيد `ElectionResult` بذلك العدد من الأصوات.

```cpp
ElectionResult burr{"Aaron " 1801};

increment_vote_count(burr, 3);

vote_count(burr);
// => 1804
```

## 3. عدّ الأصوات والرئاسة

سلّمت المدرسة أصواتها، وحان الآن وقت التحقق من النتائج لمعرفة الفائز.

أنشئ دالة `determine_result` تستقبل مرجعًا إلى العدّ النهائي وتُرجع مرجعًا إلى `ElectionResult` الخاص بالرئيس الجديد. يجب أن تغيّر أيضًا اسم الفائز بإضافة "President" في بدايته. يُعطى العدّ النهائي على شكل `reference` إلى `std::vector<ElectionResult>`، وهو متجه يحتوي على `ElectionResults` لجميع المرشحين المشاركين.

```cpp
ElectionResult sanchez{"Pedro", 471};
ElectionResult wheatley{"Summer", 340};
std::vector<ElectionResult> final_count{sanchez, wheatley};

ElectionResult& winner = determine_result(final_count);

winner.name;
// => "President Pedro"
```

لتبسيط الأمور، يمكنك افتراض ما يلي:
- يحتوي `vector` على عنصر واحد على الأقل.
- لن يكون هناك تعادل على المركز الأول.
