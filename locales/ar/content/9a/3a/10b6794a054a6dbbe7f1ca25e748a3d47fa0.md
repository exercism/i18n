# نبذة

افتراضيًا، تقتصر المتغيرات على النطاق الذي تُعرَّف فيه. فإذا عُرِّفت في ملف خارج دالة أو صنف، فإنها تقتصر على نطاق الملف. وإذا عُرِّفت داخل دالة أو صنف، فإنها تقتصر على نطاق تلك الدالة أو الصنف.

```php
<?php

$file_scoped = "I am file scoped";

function example(): void
{
  $function_scoped = "I am function scoped!";
}
```

## النطاق العام

استخدام الكلمة المفتاحية `global` قبل إسناد متغير يُنشئ متغيرًا ذا نطاق عام. غالبًا ما يُنصح بتجنّب هذا النمط لأنه يُنشئ [كودًا شديد الترابط](<https://en.wikipedia.org/wiki/Coupling_(computer_programming)#Disadvantages_of_tight_coupling>).

```php
function example(): void
{
  global $hello = "World!";
}

echo $hello; // #=> "World!"
```

## النطاق الساكن

استخدام الكلمة المفتاحية `static` قبل إسناد متغير أو الإعلان عنه يحافظ على نطاق المتغير، لكن قيمته تبقى محفوظة بين نطاقات التنفيذ.

```php
function counter(): int
{
  static $count = 0;
  $count += 1;
  return $count;
}
```

في هذا المثال، يُهيَّأ المتغير `$count` إلى 0 _فقط عند أول استدعاء للدالة_. وفي كل استدعاء بعده، تنتقل القيمة إلى الاستدعاء التالي. لذا فإن كل استدعاء للدالة يُرجع عددًا صحيحًا متزايدًا.
