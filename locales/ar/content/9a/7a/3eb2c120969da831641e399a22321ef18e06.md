# نبذة

## حلقات `for`

تُكرّر عبارة `for` كتلةً من الكود.
ويتحكّم سطرها الأول في عدد مرات تكرار الكتلة:

```go
for init; condition; post {
    // loop body
}
```

- عبارة **التهيئة** تُنفَّذ مرة واحدة قبل التكرار الأول. ومن الشائع تعريف متغير عدّاد تستخدمه الحلقة وتهيئته.
- **الشرط** هو تعبير منطقي يُقيَّم قبل كل تكرار. وتتوقف الحلقة عندما يُقيَّم هذا التعبير إلى `false`.
- عبارة **التحديث** تُنفَّذ بعد اكتمال كل تكرار. ويمكن استخدامها لتحديث العدّاد.

لا تُحِط `init; condition; post` بأقواس هلالية.
ومع ذلك، فإن الأقواس المعقوفة `{ }` التي تحيط بجسم الحلقة مطلوبة دائمًا.

تبدأ هذه الحلقة `i` من `1`، وتطبع القيمة الحالية لـ `i`، وتزيدها استعدادًا للتكرار التالي، وتتوقف عندما يصل `i` إلى `10`:

```go
for i := 1; i < 10; i++ {
    fmt.Println(i)
}
```

## صيغ أخرى للحلقات

### حلقة بشرط فقط

يمكن إغفال عبارتي التهيئة والتحديث.
وعبارة `for` التي تحتوي على شرط فقط تؤدي الغرض نفسه الذي تؤديه حلقة `while` في لغات أخرى.
لا توجد كلمة مفتاحية `while` في Go.

```go
sum := 1
for sum < 1000 {
    sum += sum
}
fmt.Println(sum)
// Output: 1024
```

### الحلقة اللانهائية

يمكن كتابة عبارة `for` دون شرط:

```go
for {
    // loop body
}
```

لا تنتهي هذه الحلقة من تلقاء نفسها.
ويجب أن يخرج التنفيذ منها صراحةً، مثلًا باستخدام `break` أو `return`.

## التحكم في الحلقات

### `break` و `continue`

في هذه الحلقة، تؤدي `break` إلى الخروج من الحلقة:

```go
for n := 0; n <= 5; n++ {
    if n == 3 {
        break
    }
    fmt.Println(n)
}
// Output:
// 0
// 1
// 2
```

وتتخطّى `continue` ما تبقّى من جسم الحلقة الحالي وتبدأ التكرار التالي:

```go
for n := 0; n <= 5; n++ {
    if n % 2 == 0 {
        continue
    }
    fmt.Println(n)
}
// Output:
// 1
// 3
// 5
```

### `break` و `continue` مع التسميات

في الحلقات المتداخلة، ينطبق `break` أو `continue` غير الموسوم بتسمية على الحلقة الداخلية.
لوسم حلقة محيطة، ضع معرّفًا يتبعه نقطتان رأسيتان في السطر الذي يعلوها مباشرة.
ثم اكتب تسمية الحلقة بعد `break` أو `continue` لتوجيه التنفيذ إليها:

```go
OuterLoop:
for i := 0; i < 10; i++ {
    for j := 0; j < 10; j++ {
        if i + j == 10 {
            break OuterLoop
        }
    }
}
```
