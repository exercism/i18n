# نبذة

يمكن جعل معامل الطريقة اختياريًا بإسناد قيمة افتراضية إليه. وعندما يكون المعامل اختياريًا، لا يُلزَم المستدعي بتمرير وسيط لهذا المعامل، وفي هذه الحالة تُستخدم القيمة الافتراضية. ويجب أن تكون [المعاملات الاختيارية][optional-arguments] _في نهاية_ قائمة المعاملات؛ فلا يمكن أن يأتي بعدها معاملات غير اختيارية. وإذا كانت للطريقة عدة معاملات اختيارية، فيمكنك تحديد بعضها فقط باستخدام [الوسائط المسماة][named-arguments].

```csharp
class Card
{
    static string NewYear(int year = 2020, string sender = "me")
    {
        return $"Happy {year} from {sender}!";
    }
}

Card.NewYear();     // => "Happy 2020 from me!"
Card.NewYear(1999); // => "Happy 1999 from me!"
Card.NewYear(sender: "mom"); // => "Happy 2020 from mom!"
```

ويجب أن تكون قيمة المعامل الاختياري إحدى الحالتين:

- تعبير ثابت (مثل `"hi"` و`2` و`DayOfWeek.Friday` و`null` وما إلى ذلك)
- تعبير `new` لنوع قيمة
- تعبير `default` لنوع قيمة
