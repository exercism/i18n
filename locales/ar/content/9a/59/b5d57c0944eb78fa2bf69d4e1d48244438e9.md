# التعليمات

أنت مراقب طيور متحمّس يتابع عدد الطيور التي زارت حديقتك خلال الأيام السبعة الماضية.

لديك ست مهام، وكلها تتعلق بأعداد الطيور التي زارت حديقتك.

## 1. تحقّق من أعداد الأسبوع الماضي

لأغراض المقارنة، تحتفظ دائمًا بنسخة من أعداد الأسبوع الماضي في متناول يدك، وهي: 0، 2، 5، 3، 7، 8، و4. عرّف ارتباط `lastWeek` الذي يحتوي على أعداد الأسبوع الماضي:

```fsharp
lastWeek
// => [| 0; 2; 5; 3; 7; 8; 4 |]
```

## 2. تحقّق من عدد الطيور التي زارتك أمس

نفّذ دالة `yesterday` لتُرجع عدد الطيور التي زارت حديقتك أمس. تُرتَّب أعداد الطيور حسب اليوم، حيث يمثل العنصر الأول عدد أقدم يوم، ويمثل العنصر الأخير عدد اليوم.

```fsharp
yesterday [| 3; 5; 0; 7; 4; 1 |]
// => 4
```

## 3. احسب إجمالي عدد الطيور الزائرة

نفّذ دالة `total` لتُرجع إجمالي عدد الطيور التي زارت حديقتك:

```fsharp
total [| 3; 5; 0; 7; 4; 1 |]
// => 20
```

## 4. تحقّق مما إذا كان هناك يوم بلا طيور زائرة

نفّذ دالة `dayWithoutBirds` التي تُرجع `true` إذا كان هناك يوم لم تزره فيه أي طيور؛ وإلا فإنها تُرجع `false`:

```fsharp
dayWithoutBirds [| 3; 5; 0; 7; 4; 1 |]
// => true
```

## 5. زد عدد طيور اليوم

نفّذ دالة `incrementTodaysCount` لتزيد عدد طيور اليوم وتُرجع الأعداد المحدَّثة:

```fsharp
let birdCount = [| 3; 5; 0; 7; 4; 1 |]
incrementTodaysCount birdCount
// => [| 3; 5; 0; 7; 4; 2 |]
```

## 6. تحقّق من وجود أسبوع غير معتاد

خلال العام الماضي، وجدت أن بعض الأسابيع تتكرر فيها الأنماط غير المعتادة ذاتها:
- في كل يوم زوجي من أيام الأسبوع، لم تكن هناك أي طيور
- في كل يوم زوجي من أيام الأسبوع، رُصد 10 طيور بالضبط
- في كل يوم فردي من أيام الأسبوع، رُصد 5 طيور بالضبط

نفّذ دالة `unusualWeek` التي تُرجع `true` إذا طابق نمط أعداد الطيور في هذا الأسبوع أحد الأنماط غير المعتادة:

```fsharp
unusualWeek [| 1; 0; 5; 0; 12; 0; 2 |]
// => true

unusualWeek [| 5; 0; 5; 12; 5; 3; 5|]
// => true
```

(لاحظ أن زوجية الأيام مفهرسة بدءًا من 1، وليس من 0؛ فأول عنصر في المصفوفة يقابل يومًا فرديًا)
