# مقدمة

الأصناف مثل `LocalDate` و`LocalDateTime` تصف _نقطة_ في الزمن.
تحتوي حزمة `java.time` أيضًا على صنفين يصفان _مقدارًا_ من الزمن:

- `java.time.Period` هو مقدار من الزمن بالسنوات والأشهر والأيام، مثل «شهرين و5 أيام».
- `java.time.Duration` هو مقدار من الزمن بالساعات والدقائق والثواني والمللي ثانية والنانو ثانية، مثل «ساعة و30 دقيقة».

يتبع `Period` التقويم، لذلك يُستخدم مع التواريخ وقيم التاريخ والوقت.
أما `Duration` فيقيس الزمن الدقيق، لذلك يُستخدم مع الأوقات وقيم التاريخ والوقت، ولكن ليس مع التواريخ.

```exercism/note
مثل بقية أصناف `java.time`، فإن `Period` و`Duration` غير قابلين للتغيير.
الطرق التي تبدو وكأنها تغيّرهما تُرجع نسخة _جديدة_ بدلًا من ذلك.
```

## `Period`

يُنشأ `Period` بإحدى طرق المصنع الساكنة الخاصة به:

```java
Period.ofDays(10);
// => P10D

Period.ofMonths(3);
// => P3M

Period.of(1, 2, 15);
// => P1Y2M15D
```

تستخدم نتيجة `toString()` تدوين [ISO-8601][iso-8601-durations]: الحرف `P` (اختصارًا لكلمة «فترة») متبوعًا بعدد السنوات (`Y`) والأشهر (`M`) والأيام (`D`).

يمكن إضافة فترة إلى تاريخ أو طرحها منه:

```java
LocalDate date = LocalDate.of(2024, 3, 10);

date.plus(Period.ofMonths(2));
// => 2024-05-10

date.minus(Period.ofDays(10));
// => 2024-02-29
```

لأن الأشهر تتفاوت في أطوالها، فقد تؤدي إضافة أشهر إلى الوصول إلى يوم غير موجود.
في هذه الحالة تُنقل النتيجة إلى آخر يوم صالح في الشهر:

```java
LocalDate.of(2025, 1, 31).plus(Period.ofMonths(1));
// => 2025-02-28
```

تُرجع `Period.between()` الفترة من تاريخ (شاملًا له) إلى تاريخ آخر (غير شامل له):

```java
LocalDate start = LocalDate.of(2023, 3, 10);
LocalDate end = LocalDate.of(2024, 5, 25);

Period period = Period.between(start, end);
// => P1Y2M15D

period.getYears();
// => 1
period.getMonths();
// => 2
period.getDays();
// => 15
```

## عدّ الوحدات باستخدام `ChronoUnit`

يحفظ `Period` سنواته وأشهره وأيامه منفصلة عن بعضها.
لذلك تُرجع `getDays()` الجزء الخاص بالأيام من الفترة فقط، وليس العدد الإجمالي للأيام.
لحساب العدد الإجمالي لوحدة واحدة بين تاريخين، استخدم طريقة `between()` في [`java.time.temporal.ChronoUnit`][chronounit-docs]:

```java
LocalDate start = LocalDate.of(2024, 1, 15);
LocalDate end = LocalDate.of(2024, 3, 20);

Period.between(start, end);
// => P2M5D

Period.between(start, end).getDays();
// => 5

ChronoUnit.DAYS.between(start, end);
// => 65
```

تكون النتيجة سالبة عندما يسبق التاريخ الثاني التاريخ الأول:

```java
ChronoUnit.DAYS.between(end, start);
// => -65
```

## `Duration`

يُنشأ `Duration` أيضًا باستخدام طرق المصنع الساكنة:

```java
Duration.ofMinutes(90);
// => PT1H30M

Duration.ofHours(2).plusMinutes(15);
// => PT2H15M
```

في تدوين ISO-8601، يفصل الحرف `T` جزء التاريخ عن جزء الوقت، ولهذا تُكتب المدد بالصيغة `PT...`.

يمكن إضافة مدة إلى تاريخ ووقت أو طرحها منه:

```java
LocalDateTime start = LocalDateTime.of(2024, 3, 10, 22, 30);

start.plus(Duration.ofMinutes(90));
// => 2024-03-11T00:00
```

تُرجع `Duration.between()` مقدار الوقت الدقيق بين قيمتَي تاريخ ووقت:

```java
LocalDateTime checkIn = LocalDateTime.of(2024, 3, 10, 18, 5);
LocalDateTime checkOut = LocalDateTime.of(2024, 3, 10, 19, 40);

Duration.between(checkIn, checkOut);
// => PT1H35M
```

يمكن تحويل مدة إلى وحدة واحدة باستخدام طرق مثل `toHours()` و`toMinutes()` و`toSeconds()`.
تُرجع هذه الطرق المقدار _الإجمالي_ بتلك الوحدة، بعد تقريبه للأسفل:

```java
Duration duration = Duration.ofMinutes(95);

duration.toHours();
// => 1
duration.toMinutes();
// => 95
```

لتقسيم مدة إلى أجزائها، كما هو الحال في الساعة، استخدم طرق `toXxxPart()` بدلًا من ذلك:

```java
Duration duration = Duration.ofMinutes(95);

duration.toHoursPart();
// => 1
duration.toMinutesPart();
// => 35
```
