# تثبيت Python

إذا لم يكن Python متاحًا بالفعل على نظامك، فستجد تعليمات مفصّلة حسب نظام التشغيل في قسم [إعداد Python واستخدامه][using python] من الوثائق الرسمية.
كما يقدّم موقع Real Python [دليلًا رائعًا][helpful guide] للتثبيت على منصات مختلفة، بما في ذلك iOS و Android.

وأخيرًا، يقدّم منشورا Brett Cannon [دليلًا سريعًا وعمليًا][quick-and-dirty] و[لماذا ينبغي أن تستخدم `python -m pip`][python-m-pip] نصائح مفيدة جدًا حول كيفية إدارة تثبيتات Python والحزم.

**ملاحظة لمستخدمي MacOS:** قبل إصدار MacOS Monterey (12.3)، كان `Python 2.7` يأتي مثبّتًا مسبقًا مع نظام التشغيل.
استخدام `Python 2.7` مع Exercism أو معظم البرامج الأخرى غير مدعوم.
بدلًا من ذلك، عليك تثبيت [Python 3][Python-three downloads] بإحدى الطرق الموضّحة أدناه.
وابتداءً من MacOS Monterey (12.3)، لن يأتي أي إصدار من Python مثبّتًا مسبقًا عبر MacOS.

بعض الروابط السريعة إلى الوثائق حسب نظام التشغيل:

-  [Windows][windows] بالإضافة إلى ذلك، هذا المقال من Microsoft حول [تثبيت Python على Windows][python-on-windows] مفيد.
-  [أنظمة Unix و Linux][unix-and-linux] (_وهي تناسب MacOS إلى حد كبير أيضًا_)
-  [MacOS][macos]

   نوصي أيضًا بالاطلاع على بعض الطرق الواردة في مقال Real Python بعنوان [تثبيت Python][installing-python] أو في مقالات Brett Cannon المذكورة أعلاه.


تدعم اختبارات Exercism وأدواتها حاليًا الإصدارات `3.10` - `3.13.5` (_الاختبارات_) و[`Python 3.13.5`][313-new-features] (_الأدوات_).
وتُذكر الاستثناءات على هذا الدعم حيثما وردت.
معظم التمارين ستعمل مع `Python 3.6+` أو حتى إصدارات أقدم.
لكننا لا نضمن الدعم للإصدارات غير المذكورة في [إصدارات Python النشطة][active-python-releases].


يرجى الرجوع إلى [وثائق Python 3.13.x][3.13 docs] لمعرفة ما هو مدعوم حاليًا.
