# مقدمة

تتيح لك تحويلات الأنواع في Cairo نقل البيانات من نوع إلى آخر، مما يمكّنك من معالجة البيانات بمرونة وأمان.

## الأساسيات

يوفر Cairo عدة آليات لتحويل الأنواع:

### التحويل المباشر

بالنسبة للأنواع العددية المتوافقة، يمكنك استخدام التحويل المباشر:

```rust
let small_number: u8 = 42;
let big_number: u32 = small_number.into();
```

### سمة `Into`

تتيح سمة `Into` التحويل من نوع إلى آخر:

```rust
let value: u16 = 100;
let converted: u32 = value.into();
```

### سمة `TryInto`

بالنسبة للتحويلات التي قد تفشل، استخدم `TryInto`، وهي تُرجع `Option`:

```rust
let large_value: u32 = 70000;
let small_value: Option<u16> = large_value.try_into();

match small_value {
    Option::Some(v) => println!("Converted: {}", v),
    Option::None => println!("Conversion failed"),
}
```

## تحويلات الأنواع المخصصة

يمكنك تنفيذ `Into` لأنواعك الخاصة:

```rust
#[derive(Drop)]
struct Celsius {
    value: i32,
}

#[derive(Drop)]
struct Fahrenheit {
    value: i32,
}

impl CelsiusIntoFahrenheit of Into<Celsius, Fahrenheit> {
    fn into(self: Celsius) -> Fahrenheit {
        Fahrenheit { value: (self.value * 9) / 5 + 32 }
    }
}
```

## اعتبارات الأمان

- استخدم `TryInto` عندما قد يفشل التحويل (مثلًا، التحويل من نوع كبير إلى نوع صغير)
- استخدم `Into` عندما ينجح التحويل دائمًا
- تعامل دائمًا مع حالات `Option::None` الناتجة من `TryInto`
- ضع في اعتبارك الفائض والنقصان عند التحويل بين الأنواع الموقّعة وغير الموقّعة
