# التعليمات

سارة تعمل على لعبة تقمّص أدوار جديدة وتحتاج إلى مساعدتك في آليات اللاعب.

## 1. تعريف الصف `player`

عرّف صنف الصف `player` بأربع خانات وقيم افتراضية:

| الخانة   | القيمة الافتراضية |
| -------- | ------- |
| `name`   | `f`     |
| `level`  | `0`     |
| `health` | `100`   |
| `mana`   | `f`     |

وبعد تعريفه، يمكنك إنشاء لاعب على هيئة قيمة حرفية:

```factor
T{ player { name "Merlin" } { level 5 } } .
! => T{ player { name "Merlin" } { level 5 } }
```

## 2. تقديم اللاعب

عرّف `introduce` بحيث تُرجع اسم اللاعب. اللاعبون المتخفّون يخفون أسماءهم (`name` تساوي `f`)، وينبغي تقديمهم باسم `"Mighty Magician"`.

```factor
T{ player { name "Merlin" } } introduce .
! => "Merlin"

T{ player { health 8 } } introduce .
! => "Mighty Magician"
```

## 3. إحياء لاعب ساقط

عرّف `revive` بحيث تُرجع لاعبًا *جديدًا* تكون فيه `health` مساوية لـ 100 و`mana` مساوية لـ 100، ولكن فقط إذا كانت `health` لدى اللاعب تساوي `0`. وإذا كان اللاعب ما زال حيًّا، فأرجع `f`.

```factor
T{ player { name "Merlin" } { health 0 } } revive .
! => T{ player { name "Merlin" } { health 100 } { mana 100 } }

T{ player { health 50 } } revive .
! => f
```

## 4. تلقّي الضرر

عرّف `take-damage` بحيث تُرجع لاعبًا *جديدًا* انخفضت فيه `health` بمقدار المقدار المعطى، دون أن تنزل أبدًا تحت `0`.

```factor
T{ player { health 100 } } 30 take-damage .
! => T{ player { health 70 } }

T{ player { health 5 } } 30 take-damage .
! => T{ player { health 0 } }
```
