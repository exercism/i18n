# نبذة

يمثّل Elixir قيمتي صحيح وخطأ بالنوع المنطقي. ولا توجد سوى قيمتين: `true` و`false`. ويمكن دمج هاتين القيمتين باستخدام العوامل المنطقية ([`and/2`][strict-and]، و[`or/2`][strict-or]، و[`not/1`][strict-not]):

```elixir
true_variable = true and true
false_variable = true and false

true_variable = false or true
false_variable = false or false

true_variable = not false
false_variable = not true
```

العوامل [`and/2`][strict-and] و[`or/2`][strict-or] و[`not/1`][strict-not] منطقية بشكل صارم، أي أنها تشترط أن تكون وسيطتها _الأولى_ قيمة منطقية. وهناك أيضًا عوامل منطقية مكافئة تعمل مع أي نوع من الوسائط، وهي [`&&/2`][and] و[`||/2`][or] و[`!/1`][not].

تستخدم العوامل المنطقية التقييم قصير الدائرة (short-circuit evaluation)، أي أن التعبير الواقع على الجانب الأيمن من العامل لا يُقيَّم إلا عند الحاجة.

لكل عامل أولوية مختلفة، حيث يُقيَّم `not/1` قبل `and/2` و`or/2`. ويمكن استخدام الأقواس الهلالية لتقييم جزء من التعبير قبل الأجزاء الأخرى:

```elixir
not true and false
# => false

not (true and false)
# => true
```

عند كتابة دالة تُرجع قيمة منطقية، فمن الأسلوب المألوف أن ينتهي اسم الدالة بـ `?`. ويمكن اتباع الاصطلاح نفسه مع المتغيرات التي تخزّن قيمًا منطقية.

```elixir
def either_true?(a?, b?) do
  a? or b?
end
```
