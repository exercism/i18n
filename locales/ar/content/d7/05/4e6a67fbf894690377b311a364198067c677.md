# مقدمة

**الكائن** في JSON هو، بمصطلحات اللغات الأخرى، «جدول تجزئة» أو «خريطة» أو «قاموس».

يعرّف JSON _الكائن_ بأنه:

> الكائن مجموعة غير مرتبة من أزواج **الاسم**/**القيمة**.
> يبدأ الكائن بقوس معقوف أيسر `{` وينتهي بقوس معقوف أيمن `}`.
> ويتبع كل _اسم_ نقطتان رأسيتان `:`، وتُفصل أزواج _الاسم/القيمة_ بفاصلة `,`.

يجب أن يكون _الاسم_ **سلسلة نصية**.
وهناك كلمة أخرى مرادفة لـ_الاسم_ هي _المفتاح_.

يمكن أن تكون _القيمة_ من أي نوع من أنواع JSON.
ويمكن أن تكون _القيم_ المختلفة في الكائن نفسه من أنواع مختلفة، كما في هذا المثال.

<!-- prettier-ignore -->
```json
{
  "name": "Jane",
  "age": 42,
  "pets": ["cat", "fish"],
  "address": {"street": "123 Main St", "city": "Springfield"}
}
```

<!-- prettier-ignore-end -->

لاحظ أنه **يجب ألا** توجد فاصلة بعد _آخر_ زوج من المفتاح والقيمة.

## إنشاء الكائنات

استخدم الأقواس المعقوفة لتجميع أزواج الاسم/القيمة.
ورغم أن الأسماء يجب أن تكون سلاسل نصية، فإنها لا تحتاج إلى وضعها بين علامتي تنصيص إذا كانت **شبيهة بالمعرّفات** (مكوّنة من محارف أبجدية رقمية وشرطة سفلية، ولا تبدأ برقم).

```jq
{name: "Jane", age: 42}
```

من الصحيح استخدام مفاتيح ليست _شبيهة بالمعرّفات_.
ضعها فقط بين علامتي تنصيص.

```jq
{"first name": "Jane", "last name": "Lopez", age: 42}
```

إذا كان الاسم ناتجًا عن تعبير، فيجب أن يكون التعبير **بين قوسين هلاليين**.

```sh
$ echo "Jane" | jq -Rc '{.: 42}'
# verbose error message ...

$ echo "Jane" | jq -Rc '{(.): 42}'
{"Jane":42}
```

## الفهرسة

تُسترجَع القيم من الكائن باستخدام **تدوين النقطة**.

```jq
{name: "Jane", age: 42} | .age    # => 42
```

وإذا تعذّر عليك الإشارة إلى المفتاح كمعرّف، فاستخدم **تدوين الأقواس المربعة**.

```jq
"name" as $key | {name: "Jane", age: 42} | .$key    # => error
"name" as $key | {name: "Jane", age: 42} | .[$key]  # => "Jane"
```

## إضافة أزواج المفتاح والقيمة أو تغييرها

لإضافة زوج جديد من المفتاح والقيمة إلى مصفوفة، أو لتحديث قيمة مفتاح موجود، استخدم معامل الإسناد `=`، مع تعبير فهرس على الجانب الأيسر.

```jq
{name: "Jane", age: 42} | .sport = "tennis" | .age = 21
# => {
#      "name": "Jane",
#      "age": 21,
#      "sport": "tennis"
#    }
```

ويعمل معامل `+` على _دمج_ الكائنات.

```jq
{Richard: 54} + {Jane: 42}
# => {
#      "Richard": 54,
#      "Jane": 42
#    }
```

## إزالة مفتاح

استخدم دالة `del` لإزالة مفتاح.
وهي تُرجع الكائن المحدَّث.

```jq
{name: "Jane", age: 42} | del(.age)   # => {"name": "Jane"}
```

المعامل الذي تستقبله `del` هو **تعبير فهرس** (بتدوين النقطة أو بتدوين الأقواس المربعة) يُحلّ إلى مفتاح في الكائن.
وتسميه `jq` **تعبير مسار**.
ولا يكفي مجرد إعطاء سلسلة نصية.

```jq
{name: "Jane", age: 42} | del(name)        # error: name/0 is not defined
{name: "Jane", age: 42} | del("name")      # error: Invalid path expression with result "name"
{name: "Jane", age: 42} | del(.name)       # OK
{name: "Jane", age: 42} | del(.["name"])   # OK
```

## الانتماء

- لاختبار ما إذا كان الكائن يحتوي على مفتاح، استخدم دالة `has`.

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ($example | has("name")),    # => true
    ($example | has("sport"))    # => false
  ```

- اختبر ما إذا كان مفتاح موجودًا في كائن باستخدام `in`.

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ("name"  | in($example)),    # => true
    ("sport" | in($example))     # => false
  ```

## سرد جميع المفاتيح

استخدم دالة `keys` لإخراج مصفوفة بجميع المفاتيح.

```jq
{name: "Jane", age: 42} | keys   # => ["age", "name"]
```

لاحظ أن `keys` _ترتّب_ المفاتيح.
وللحصول على المفاتيح بترتيبها الأصلي، استخدم `keys_unsorted`.

لا توجد دالة مكافئة لسرد جميع _القيم_.
ومع ذلك، يُخرج مرشّح `.[]` قيم الكائن على هيئة _تدفق_، ويمكن التقاط هذا التدفق باستخدام مُنشئ المصفوفة `[...]`.

```jq
[{first: "Jane", last: "Lopez", status: "awesome!"} | .[]]
# => ["Jane", "Lopez", "awesome!"]
```

## التكرار

- تُطبّق دالة `map_values(filter)` المرشّح على كل _قيمة_ في الكائن.

  ```jq
  {first: "Jane", last: "Lopez", status: "awesome!"}
  | map_values(ascii_upcase)
  # => {"first": "JANE", "last": "LOPEZ", "status": "AWESOME!"}
  ```

- لكي نتكرر على كائن، يجب أولًا تحويله إلى مصفوفة من كائنات المفتاح والقيمة.
  وتقوم دالة `to_entries` بذلك.

  ```jq
  {name: "Jane", age: 42} | to_entries'
  # => [
  #      {
  #        "key": "name",
  #        "value": "Jane"
  #      },
  #      {
  #        "key": "age",
  #        "value": 42
  #      }
  #    ]
  ```

  وعند هذه النقطة، يمكننا استخدام دوال التكرار على المصفوفات، مثل `map`.

- ودالة `from_entries` هي العملية العكسية: تحوّل مصفوفة من كائنات المفتاح والقيمة إلى كائن.

  ```jq
  [
    {"key":"name", "value":"Jane"},
    {"key":"age", "value":42}
  ] | from_entries                  # =>{"name": "Jane", "age": 42}
  ```

- لتطبيق مرشّح على _كل_ زوج من المفتاح والقيمة في كائن، استخدم دالة `with_entries(filter)`.

  على سبيل المثال، إذا كان لدينا كائن يربط اسمًا بعمر، فيمكن تبديل المفاتيح والقيم كما يلي.

  ```jq
  {"Jane": 42, "Richard": 54}
  | with_entries({key: (.value | tostring), value: .key})
  ```

  فيكون الناتج

  ```json
  {
    "42": "Jane",
    "54": "Richard"
  }
  ```

  و`with_entries(filter)` تكافئ

  ```jq
  to_entries | map(filter) | from_entries
  ```
