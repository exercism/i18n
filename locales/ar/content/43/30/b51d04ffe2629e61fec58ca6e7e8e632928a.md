# التعليمات

هناك مدرسة محلية قريبة منك لديها جمعية طلابية نشطة للغاية.
تُدار الجمعية الطلابية بواسطة رئيس، وتُجرى الانتخابات مرة كل عامين لاختيار رئيس جديد.
في انتخابات هذا العام، تقرر أن هناك حاجة إلى نظام رقمي جديد لإحصاء الأصوات.

تحتاج المدرسة إلى مساعدتك في بناء هذا النظام الجديد.

## 1. إنشاء عدّاد أصوات

من أول الأشياء التي يحتاجها نظام التصويت الجديد هو عدّاد أصوات.
هذا العدّاد وسيلة لتتبّع الأصوات التي حصل عليها مرشّح معيّن.

أنشئ دالة `new_vote_counter` تقبل عدد الأصوات الأولية لمرشّح وتُرجع لقطة من بنية `VoteCounter` مُهيّأة بعدد الأصوات الأولية المعطى.

```rust
let initial_votes: u32 = 2;
let counter: @VoteCounter = new_vote_counter(initial_votes);
// @VoteCounter {
//     value: 2,
// }
```

## 2. الحصول على عدد الأصوات من عدّاد

أصبح لديك الآن وسيلة لإنشاء عدّادات جديدة!
لكنك تدرك الآن أن النظام الجديد سيحتاج أيضًا إلى وسيلة للحصول على عدد الأصوات من عدّاد.

أنشئ دالة `vote_count` تأخذ عدّادًا (`@VoteCounter`) كوسيط وتُرجع عدد الأصوات في العدّاد.

```rust
let initial_votes: u32 = 3;
let vote_counter: @VoteCounter = new_vote_counter(initial_votes);

let count = vote_count(vote_counter);
// => 3
```

## 3. زيادة أصوات عدّاد

حان الوقت أخيرًا لإحصاء الأصوات!
تحتاج الآن إلى وسيلة لزيادة الأصوات في عدّاد.

أنشئ دالة `increment_vote_count` تأخذ عدّادًا (`@VoteCounter`) كوسيط وعددًا من الأصوات، وتزيد العدّاد بذلك العدد من الأصوات.

```rust
let votes: u32 = 3;
let vote_counter: @VoteCounter = new_vote_counter(initial_votes);
let vote_counter: VoteCounter = increment_vote_count(vote_counter, 2);

let count = vote_count(@vote_counter);
// => 5
```

## 4. إنشاء نتائج الانتخابات

بعد إحصاء كل الأصوات الآن، حان الوقت لتحضير إعلان النتائج أمام المدرسة كلها.
لهذا، تلاحظ أن وجود عدّادات للأصوات وحدها لا يكفي.
لا بد من وسيلة لربط عدد الأصوات بمرشّح معيّن.

أنشئ دالة `new_election_result` تستقبل اسم مرشّح وعدد أصواته وتُرجع نتيجة انتخابية جديدة.

```rust
let result: ElectionResult = new_election_result("Peter", 3);
// ElectionResult {
//     name: "Peter",
//     votes: @VoteCounter {
//         value: 3,
//     },
// }
```

بنية نتيجة الانتخابات منشأة لك بالفعل، وهي معرّفة كما يلي:

```rust
struct ElectionResult {
    name: ByteArray,
    counter: @VoteCounter,
}
```

## 5. إعلان النتائج

حان الوقت لإعلان الرئيس الجديد للمدرسة!
سيُعلن الرئيس على لوحات الرسائل الرقمية الصغيرة الموجودة في المدرسة.

يجب أن تُظهر الرسالة اسم الرئيس الجديد وعدد الأصوات التي حصل عليها، بالصيغة التالية: `<candidate_name> (<votes>)`.
وهذا مثال على رسالة كهذه: `"Peter (51)"`.

أنشئ دالة `display_result` تستقبل `@ElectionResult` كوسيط وتُرجع `ByteArray` يحتوي الرسالة المراد عرضها.

```rust
let result = ElectionResult {
    name: "John",
    votes: @VoteCounter {
        value: 32,
    },
};

let msg = display_result(@result);
// => "John (32)"
```

## 6. إعادة إحصاء الأصوات

للتأكد من دقة النتائج النهائية، أُعيد إحصاء الأصوات.
وفي إعادة الإحصاء، وُجد أن عدد الأصوات لبعض المرشّحين كان بفارق واحد.

أنشئ دالة `decrement_votes_of_candidate` تستقبل النتائج النهائية واسم مرشّح ينبغي إنقاص عدد أصواته.
تُعطى النتائج النهائية على شكل `Felt252Dict<u32>`، حيث المفاتيح هي أسماء المرشّحين والقيم هي مجموع أصواتهم.

```rust
let mut final_results: Felt252Dict<u32> = Default::default();
final_results.insert('Mary', 10);
final_results.insert('John', 51);

decrement_votes_of_candidate(ref final_results, 'Mary');

let decremented_votes = final_results.get('Mary');
// => 9
```
