# السلاسل النصية

تمتلك Crystal نوعًا يُعرف باسم [`String`][strings]، ويُستخدم لتمثيل النصوص.
السلاسل النصية في Crystal عبارة عن متتاليات من أحرف يونيكود.
السلاسل النصية غير قابلة للتغيير، أي أنه لا يمكن تغييرها بعد إنشائها.
وهذا يعني أن سلسلة نصية جديدة تُنشأ في كل مرة تعدّل فيها سلسلة نصية، لذلك لا تتغير السلسلة النصية الأصلية.

لتعريف سلسلة نصية تستخدم علامتي الاقتباس المزدوجتين `"`.

```crystal
"Hello World"
```

## الدمج

لدمج سلسلتين نصيتين، استخدم العامل `+`.
سيُرجع العامل `+` سلسلة نصية جديدة تجمع السلسلتين.

```crystal
hello = "Hello"
hello + " World"
# => "Hello World"
```

## التحويل بين السلاسل النصية والأعداد

تُحوّل الطريقة `to_i` سلسلة نصية إلى عدد صحيح.
وبدلًا من ذلك، يمكن استخدام الطريقة `to_f` لإرجاع عدد عشري.
إذا تعذّر تحويل السلسلة النصية إلى عدد، فسيُرفع استثناء `ArgumentError`.

```crystal
"1".to_i
# => 1

"1.0".to_f
# => 1.0

"Hello".to_i
# => ArgumentError: Invalid integer: Hello
```

ويمكن تحويل عدد صحيح أو عدد عشري إلى سلسلة نصية باستخدام الطريقة `to_s`.

```crystal
1.to_s
# => "1"

1.0.to_s
# => "1.0"
```

## الإدراج

الإدراج أسلوب ملائم لدمج السلاسل النصية وتضمين التعبيرات فيها.
لإدراج قيمة في سلسلة نصية، يمكنك استخدام المحرف `#` متبوعًا بالأقواس المعقوفة `{}` مع التعبير داخل الأقواس.

```crystal
name = "World"
"Hello #{name}!"
# => "Hello World!"
```

ستحوّل Crystal نتيجة التعبير تلقائيًا إلى سلسلة نصية.

```crystal
"Hello #{1 + 1}!"
# => "Hello 2!"
```

## الحجم

عندما تحتاج إلى معرفة عدد الأحرف في سلسلة نصية، يمكنك استخدام الطريقة `size`، التي تُرجع طول السلسلة النصية كعدد صحيح.
حجم السلسلة النصية خاصية مخزّنة فيها، لذا لا يلزم حساب الحجم في كل مرة تستدعي فيها الطريقة، ما يجعلها سريعة جدًا.

```crystal
"Hello World".size
# => 11
```

## الفهرسة

الفهرسة هي الحصول على حرف معيّن من سلسلة نصية.
للحصول على حرف من `String`، يمكنك استخدام صيغة الأقواس المربعة المألوفة.

~~~~exercism/note
`[]` مُنفَّذة كطريقة على كائن `String`، حيث يكون الفهرس هو وسيط الطريقة.
~~~~

في Crystal، يقع الحرف الأول في سلسلة نصية عند الفهرس 0.

```crystal
"Hello World"[0]
# => 'H'

"Hello World"[6]
# => 'W'
```

للحصول على حرف من نهاية سلسلة نصية، يمكنك أخذ طول السلسلة ناقص واحد للحصول على فهرس الحرف الأخير، وللحصول على الحرف قبل الأخير تأخذ طول السلسلة ناقص اثنين، وهكذا.
هناك اختصار لذلك، وهو استخدام فهرس سالب ببساطة، حيث يقع الحرف الأخير عند الفهرس -1، والحرف قبل الأخير عند الفهرس -2، وهكذا.

```crystal
name = "Hello World"
name[name.size - 1]
# => 'd'

name[-1]
# => 'd'
```

## الهروب

بعض الأحرف لا يمكن كتابتها في سلسلة نصية مباشرة، وبدلًا من ذلك عليك استخدام متتالية هروب.
على سبيل المثال، إذا أردت استخدام علامتي اقتباس مزدوجتين داخل سلسلة نصية، فيجب أن تسبقهما بمتتالية هروب.
يمكنك استخدام المحرف `\` لكتابة متتالية هروب متبوعة بالحرف الذي تريد تهريبه.

هذه هي الأحرف الخاصة في Crystal:

| القيمة   | الوصف                          |
| -------- | ------------------------------ |
| `\a`     | تنبيه                          |
| `\b`     | مسافة للخلف                    |
| `\e`     | هروب                           |
| `\f`     | تغذية النموذج                  |
| `\n`     | تغذية السطر أو سطر جديد        |
| `\r`     | إرجاع العربة                   |
| `\t`     | علامة جدولة أفقية              |
| `\v`     | علامة جدولة رأسية              |
| `\\`     | شرطة مائلة عكسية               |
| `\'`     | علامة اقتباس مفردة             |
| `\"`     | علامة اقتباس مزدوجة            |
| `\377`   | محرف ASCII ثماني               |
| `\xFF`   | محرف ASCII ست عشري             |
| `\uFFFF` | محرف يونيكود ست عشري           |

```crystal
puts "Hello \"World\""
# => Hello "World"

puts "Hello \nWorld"
# => Hello
# => World
```

## السلاسل النصية متعددة الأسطر

لكتابة سلسلة نصية متعددة الأسطر، تستخدم الصيغة نفسها التي تستخدمها مع سلسلة نصية من سطر واحد، لكن تنشئ سطرًا جديدًا لكل سطر تريده في السلسلة.

```crystal
"Hello
World"
# => "Hello\nWorld"
```
