# التعليمات

في هذا التمرين، ستُنفّذ طريقة لتتبّع أعلى الدرجات لأكثر لعبة شعبية في صالة الألعاب في منطقتك.

عليك تنفيذ 7 دوال، جميعها تتعلق بإرجاع قاموس من بيانات أعلى الدرجات والتعامل معه.

## 1. عرّف قاموس أعلى درجات جديد

أنشئ دالة `newScoreBoard()` لا تأخذ أي معاملات وتُرجع قاموس أعلى درجات جديد يستخدم قيمًا من النوع `String` للمفاتيح وقيمًا من النوع `Int` للقيم.

## 2. أضف لاعبين إلى قاموس أعلى الدرجات

لإضافة لاعب إلى قاموس أعلى الدرجات، عرّف `addPlayer(_:_:_:)`، وهي دالة تأخذ 3 معاملات:

- المعامل الأول هو قاموس الدرجات.
    يجب أن يكون معامل إدخال وإخراج.
- المعامل الثاني هو اسم اللاعب كسلسلة نصية.
- المعامل الثالث هو الدرجة كعدد صحيح.
    المعامل اختياري، نفّذ المعامل الثالث بقيمة افتراضية مقدارها 0.

```swift
var highScores = newScoreBoard()
addPlayer(&highScores, "Dave Thomas")
// Returns ["Dave Thomas": 0]
addPlayer(&highScores, "José Valim", 486_373)
// Returns ["Dave Thomas": 0, "José Valim": 486_373]
```

## 3. أزل اللاعبين من قاموس الدرجات

لإزالة لاعب من قاموس أعلى الدرجات، عرّف `removePlayer(_:_:)`، وهي تأخذ معاملين:

- المعامل الأول هو قاموس الدرجات.
    يجب أن يكون معامل إدخال وإخراج.
- المعامل الثاني هو اسم اللاعب كسلسلة نصية.

يجب أن تُزيل هذه الدالة اللاعب من القاموس إذا كان موجودًا فيه، وألا تفعل شيئًا خلاف ذلك.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373]
removePlayer(&highScores, "Dave Thomas")
// Returns ["José Valim": 486_373]
removePlayer(&highScores, "Rose Fanaras")
// Returns ["José Valim": 486_373]
```

## 4. أعد ضبط درجة لاعب

لإعادة ضبط درجة لاعب، عرّف `resetPlayer(_:_:)`، وهي تأخذ معاملين:

- المعامل الأول هو قاموس الدرجات.
    يجب أن يكون معامل إدخال وإخراج.
- المعامل الثاني هو اسم اللاعب كسلسلة نصية، الذي تريد إعادة ضبط درجته.

ستجعل الدالة درجة اللاعب مساوية لـ 0.
إذا لم يكن اللاعب موجودًا في القاموس، فلا ينبغي أن يحدث أي شيء.

```swift
var highScores = ["Dave Thomas": 486_373, "José Valim": 10]
resetScore(&highScores, "Dave Thomas")
// Returns ["Dave Thomas": 0, "José Valim": 10]
```

## 5. حدّث درجة لاعب

لتحديث درجة لاعب بإضافتها إلى الدرجة السابقة، عرّف `updateScore`، وهي تأخذ 3 معاملات:

- المعامل الأول هو قاموس الدرجات. يجب أن يكون معامل إدخال وإخراج.
- المعامل الثاني هو اسم اللاعب كسلسلة نصية، الذي تريد تحديث درجته.
- المعامل الثالث هو الدرجة التي تريد **إضافتها** إلى الدرجة المخزنة.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373]
addPlayer(&highScores, "Freyja Ćirić", 12_771_008)
updateScore(&highScores, "Freyja Ćirić", 73)
// Returns ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_081]
```

## 6. احصل على قائمة باللاعبين مع الدرجات مرتبة حسب اسم اللاعب

عرّف الدالة `orderByPlayers`، التي تأخذ معاملًا واحدًا:

- المعامل الأول هو قاموس الدرجات.

ستُرجع الدالة مصفوفة من الصفوف `(String, Int)` التي تمثل اللاعبين ودرجاتهم الأعلى، مرتبة ترتيبًا تصاعديًا حسب اسم اللاعب.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_091]
orderByPlayers(highScores)
// Returns [("Dave Thomas", 0), ("Freyja Ćirić", 12_771_091), ("José Valim", 486_373)]
```

## 7. احصل على قائمة باللاعبين مرتبة حسب درجة اللاعب بترتيب تنازلي

للحصول على قائمة من اللاعبين مرتبة حسب الدرجات بترتيب تنازلي، عرّف `orderByScores`، التي تأخذ معاملًا واحدًا:

- المعامل الأول هو قاموس الدرجات.

ستُرجع الدالة مصفوفة من الصفوف `(String, Int)` التي تمثل اللاعبين ودرجاتهم الأعلى، مرتبة ترتيبًا تنازليًا حسب درجة اللاعب.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_091]
orderByScores(highScores)
// Returns [("Freyja Ćirić", 12_771_091), ("José Valim", 486_373), ("Dave Thomas", 0)]
```
