### الاستدعاء الديناميكي للدوال

دوال awk ليست كائنات من الدرجة الأولى: فلا يمكن تمريرها كما تسمح بعض اللغات الأخرى بذلك.
لكن يمكن لمتغير أن يحمل _اسم_ دالة (سلسلة نصية)، وتُستدعى الدالة باستخدام صيغة خاصة `@varname(args)`.
مثال:

```awk
function greet(name) {
    print "Hello, " name
}
BEGIN {
    greet("John")       # => "Hello, John"

    f = "greet"
    f("Bill")           # => error
    @f("Bill")          # => "Hello, Bill"
}
```
يُشرح هذا في [الاستدعاءات غير المباشرة للدوال][indirect].
هذا امتداد خاص بـ `gawk`.
