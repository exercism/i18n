# مقدمة

طرق التوسعة تتيح لك إضافة طرق إلى أنواع موجودة دون إنشاء نوع مشتق جديد، أو إعادة تصريف الكود، أو أي تعديل آخر على النوع الأصلي. تُعرَّف هذه الطرق كطرق ثابتة، لكنها تُستدعى باستخدام صياغة استدعاء الطرق على الكائنات. يسبق معاملها الأول المُعدِّل `this`، وهو يحدد النوع الذي تعمل عليه الطريقة، كما أنها تصبح ضمن النطاق على مستوى مساحة الأسماء.

```csharp
public static int WordCount(this string str)
{
    return str.Split().Length;
}

"Hello World".WordCount();
// => 2
```
