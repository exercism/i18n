# مقدمة

[المعاملات ذات العدد المتغير][variadic-parameters] تسمح لدالة بقبول صفر أو أكثر من القيم من نوع محدد لمعامل واحد.
تُعرّف المعامل ذا العدد المتغير بإضافة ثلاث نقاط (`...`) إلى تحديد النوع الخاص بالمعامل.

داخل جسم الدالة، تجعل Swift هذه القيم متاحة كمصفوفة من النوع المحدد:

```swift
import Foundation

func geometricMean(_ numbers: Double...) -> Double {
    var total = 1.0
    for number in numbers {
        total *= number
    }
    return pow(total, 1.0 / Double(numbers.count))
}

let result = geometricMean(1, 2, 3, 4, 5)
// result is 2.605171084697352
```

~~~~exercism/note
إذا تضمّنت الدالة معاملات إضافية بعد المعامل ذي العدد المتغير، فإن أول معامل يلي المعامل ذا العدد المتغير **يجب** أن يكون له تسمية وسيط صريحة حتى تعرف Swift أين تنتهي قائمة الوسائط ذات العدد المتغير.
~~~~
