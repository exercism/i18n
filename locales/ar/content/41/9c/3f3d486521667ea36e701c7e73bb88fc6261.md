# المقدمة

`Complex numbers` ليست معقدة.
إنها تحتاج فقط إلى اسم أقل إثارة للقلق.


إنها مفيدة جدًا، خاصة في الهندسة والعلوم، لدرجة أن Python تتضمن [`complex`][complex] كنوع عددي قياسي، إلى جانب الأعداد الصحيحة ([`int`s][ints]) وأعداد الفاصلة العائمة ([`float`s][floats]).


قيمة `complex` في Python هي في جوهرها زوج من أعداد الفاصلة العائمة:

```python
>>> my_complex = 5.443+6.77j
(5.443+6.77j)
```

ويُطلق على هذين الجزأين اسم الجزء "الحقيقي" و"التخيلي".
قد تكون سمعت أن "`i` (أو `j`) هو الجذر التربيعي لـ -1".
في الوقت الحالي، كل ما يعنيه هذا هو أن الجزء التخيلي _بحكم التعريف_ يحقق المساواة `1j * 1j == -1`.
هذه فكرة بسيطة، لكنها تؤدي إلى نتائج رياضية مثيرة للاهتمام.

في Python، يُرمز إلى الجزء "التخيلي" بالحرف `j` (_وليس `i` كما تراه في كتب الرياضيات_)، ويجب أن يتبع `j` رقمًا مباشرةً، حتى لا يعتبره Python اسم متغير:


```python
>>> j
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
NameError: name 'j' is not defined

>>> 1j
1j

>>> type(1j)
<class 'complex'>
```


هناك أسلوبان شائعان لإنشاء الأعداد المركبة.

1) يأخذ الباني [`complex(real, imag)`][complex] معاملين من النوع `float`:

    ```python
    >>> z1 = complex(1.5, 2.0)
    >>> z1
    (1.5+2j)
    ```

    يستطيع الباني أيضًا تحليل سلسلة نصية كمدخل.
    ولهذا قيد غريب: فهو يفشل إذا احتوت السلسلة النصية على مسافات.

    ```python
    >>> complex('4+2j')
    (4+2j)
    
    >>> complex('4 + 2j')
    Traceback (most recent call last):
      File "<stdin>", line 1, in <module>
    ValueError: complex() arg is a malformed string
    ```


2) يمكن تحديد العدد المركب على هيئة قيمة حرفية `<real part> + <complex part>j`، أو `<complex part>j` فقط إذا كان الجزء الحقيقي صفرًا:


    ```python
    >>> z2 = 2.0 + 1.5j
    >>> z2
    (2+1.5j)
    ```
    النتيجة النهائية مطابقة لاستخدام الباني `complex()`.


## العمليات الحسابية

معظم [`operators`][operators] المستخدمة مع أعداد الفاصلة العائمة والأعداد الصحيحة تعمل أيضًا مع الأعداد المركبة.

القسمة الصحيحة _**غير**_ ممكنة على الأعداد المركبة، لذا سيفشل العاملان `//` و `%` ودالة `divmod()` مع نوع الأعداد المركبة.

شرح قواعد ضرب الأعداد المركبة وقسمتها خارج نطاق هذا المفهوم (_ومن غير المرجح أن تحتاج إلى إجراء هذه العمليات "يدويًا" في كثير من الأحيان_).

أي مقدمة [رياضية][math-complex] أو [في الهندسة الكهربائية][engineering-complex] عن الأعداد المركبة ستغطي هذه الحالات، إن أردت التعمق في الموضوع.

تحتوي مكتبة Python القياسية على وحدة [`math`][math-module] مليئة بالوظائف المفيدة للتعامل مع الأعداد الحقيقية، ووحدة [`cmath`][cmath] هي المقابل لها للتعامل مع الأعداد المركبة.
