# نبذة

تأتي Ruby مزوّدة بمكتبة قياسية (يُختصر اسمها غالبًا إلى «stdlib»)، وهي مجموعة من الأصناف للتعامل مع أشياء مثل التواريخ وjson والشبكات.
كما توفّر بعض الوظائف المفيدة التي تسهّل التعامل مع الكود.

‏`OpenStruct` جزء من المكتبة القياسية، ويتيح لك إنشاء كائن من `Hash` بسهولة.
فبدلًا من الاضطرار إلى الوصول عبر مفاتيح `Hash`، يتيح لك `OpenStruct` استخدام الطرق للوصول إلى القيم وضبطها.

عند استخدام أصناف من المكتبة القياسية، أو من أي مكتبة أخرى، تحتاج إلى استدعاء ذلك الصنف باستخدام الطريقة `require`.

```ruby
require 'ostruct'

attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

ومن المزايا الإضافية لهذا أنك تستطيع الاستفادة من اختصار عند استخدام صيغة الكتلة.
فعندما تستدعي الكتلة طريقة واحدة، يمكنك استبدال الكتلة بـ`&:` متبوعة باسم الطريقة.
على سبيل المثال، هذان السطران مترادفان:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```
