# البنى

تجمع البنى مجموعة ثابتة غير متجانسة من البيانات في وحدة واحدة. وللبنى في Rust الخصائص التالية:

- لكل نوع بنية اسم معيّن.
- يُسمّى كل عضو في البنية **حقلًا**.
- لكل حقل في البنية اسم معيّن.
- تُتتبَّع الرؤية على مستوى الحقل: فقد يكون كل حقل عامًّا أو خاصًّا أو غيره[^1]، كلٌّ على حدة.

# نظرة عامة على البنى

تُعرَّف البنى باستخدام الكلمة المفتاحية `struct`، متبوعة باسم النوع الذي تصفه البنية.
وقد يلي الاسمَ أقواس معقوفة (لبنية قياسية)، أو أقواس هلالية (لبنية صفية)، أو فاصلة منقوطة (لبنية وحدة).

```rust
struct Item {}
```

ثم تُضاف أنواع إضافية إلى جسم البنية بوصفها _حقولًا_ لها، ولكل حقل نوعه الخاص:

```rust
struct Item {
    name: String,
    weight: f32,
    worth: u32,
}
```

وأخيرًا، يمكن تعريف طرق على البنى داخل كتلة `impl`:

```rust
impl Item {
    // initializes and returns a new instance of our Item struct
    fn new() -> Self {
        todo!()
    }
}
```

# أشكال البنى

تأتي البنى في ثلاثة أشكال: بنى بحقول مُسمّاة (البنى القياسية)، والبنى الصفية، وبنى الوحدة.

البنى شبيهة جدًّا بـ**الصفوف**. في الواقع، الفرق الوحيد بين البنى والصفوف يتعلق بما هو مجهول. والشكل العام كالتالي:

- البنى مُسمّاة ولها حقول مُسمّاة:

  ```rust
  struct Foo {
      bar: Bar,
      bat: Bat,
  }
  ```

  يُوصَل إلى الحقول بالاسم:

  ```rust
  let bar = foo.bar;
  ```

- البنى الصفية مُسمّاة ولها حقول مجهولة:

  ```rust
  Foo(Bar, Bat)
  ```

  يُوصَل إلى الحقول بالتفكيك أو بالفهرس الرقمي:

  ```rust
  // unpacking
  let (bar, bat) = foo;
  ```

  ```rust
  // numeric index
  let bar = foo.0;
  let bat = foo.1;
  ```

- الصفوف مجهولة ولها حقول مجهولة:

  ```rust
  (Bar, Bat)
  ```

  وكما في البنى الصفية، يُوصَل إلى الحقول بالتفكيك أو بالفهرس الرقمي.

- البنى المجهولة، كما يوحي الاسم، مجهولة لكن بحقول مُسمّاة. وقد تكون مألوفة لديك من لغات أخرى مثل Go أو Java. وهي غير موجودة في Rust، ويُعدّ استخدام الصف بدلًا منها هو الأسلوب المعتاد.

# الأنواع صفرية الحجم

يمكن أن تحتوي البنية على أكبر عدد ممكن من الحقول أو أقل عدد ممكن حسب الحاجة. ويترتب على ذلك أنه من الجائز أن تكون البنية بلا حقول. والبنية بلا حقول تُسمّى **النوع صفري الحجم**، ولها معالجة خاصة في المُصرِّف: فالأنواع صفرية الحجم (وكثيرًا ما تُختصر إلى **ZSTs**) لا تستهلك أي مساحة على المكدس أو الكومة، حتى حين تتوقع أن تفعل ذلك. على سبيل المثال، لا يحجز `Box<T>` أي ذاكرة على الكومة إذا كان `T` نوعًا صفري الحجم.

يمكنك استخدام صيغة البنية القياسية أو الصيغة الصفية عند كتابة نوع صفري الحجم:

```rust
// declaration
struct Foo {}
// instantiation
let foo = Foo {}
```

```rust
// declaration
struct Foo();
// instantiation
let foo = Foo();
```

وهناك أيضًا صيغة مختصرة للأنواع صفرية الحجم:

```rust
// declaration
struct Foo;
// instantiation
let foo = Foo;
```

وعادةً ما تُفضَّل الصيغة المختصرة عند كتابة نوع صفري الحجم، إذ لا يمكنك الخلط بين الصيغ: فأي أسلوب استُخدم لتعريف نوع صفري الحجم[^2] هو نفسه الأسلوب المطلوب لإنشاء نسخة منه.

بعد كل هذا الحديث عن صيغة الأنواع صفرية الحجم، لننتقل إلى سبب الرغبة في شيء كهذا. فالنوع صفري الحجم لا يخزّن أي بيانات، لكنه ممتاز لتنفيذ السمات عليه.

---

[^1]: [تشرح هذه الوثائق](https://doc.rust-lang.org/reference/visibility-and-privacy.html) بعض خيارات الرؤية الأقل شيوعًا.
[^2]: هذه حالة خاصة من قاعدة عامة: أي أسلوب استُخدم لتعريف أي نوع بنية هو نفسه الأسلوب المطلوب لإنشاء نسخة منه.
