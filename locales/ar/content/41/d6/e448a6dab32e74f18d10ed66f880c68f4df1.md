# نبذة

تقدّم المكتبة القياسية في Elixir 4 وحدات مختلفة للتعامل مع التواريخ والوقت، ولكل منها بنيتها الخاصة.

- وحدة [`Date`][date]. يمكن إنشاء بنية `Date` باستخدام العلامة [`~D`][sigil-d].
    ```elixir
    ~D[2021-01-01]
    ```

- وحدة [`Time`][time]. يمكن إنشاء بنية `Time` باستخدام العلامة [`~T`][sigil-t].
    ```elixir
    ~T[12:00:00]
    ```

- وحدة [`NaiveDateTime`][naivedatetime] للتواريخ والأوقات بدون منطقة زمنية. يمكن إنشاء بنية `NaiveDateTime` باستخدام العلامة [`~N`][sigil-n].
    ```elixir
    ~N[2021-01-01 12:00:00]
    ```

- وحدة [`DateTime`][datetime] للتواريخ والأوقات مع منطقة زمنية. يتطلب استخدام هذه الوحدة مع مناطق زمنية غير UTC اعتمادية خارجية، هي قاعدة بيانات للمناطق الزمنية. يمكن تمثيل بنية `DateTime` باستخدام العلامة [`~U`][sigil-u]، لكن ينبغي إنشاءها باستخدام دوال `DateTime` بدلًا من ذلك.
    ```elixir
    DateTime.new!(~D[2021-01-01], ~T[12:00:00], "Etc/UTC")
    # => ~U[2021-01-01 12:00:00Z]
    ```

## المقارنات

لمقارنة التواريخ أو الأوقات ببعضها، ابحث عن دالة `compare` أو `diff` في الوحدة المقابلة. تبدو عوامل المقارنة مثل `==` و`>` و`<` *تعمل*، لكنها لا تُجري مقارنة دلالية صحيحة على هذه البنى.

```elixir
Date.compare(~D[2020-11-30], ~D[2020-12-01])
# => :lt

Time.diff(~T[13:45:00], ~T[13:46:30])
# => -90
```

## الإزاحة

يمكن إزاحة التواريخ والأوقات وقيم التاريخ والوقت إلى الأمام وإلى الخلف باستخدام دالة `add/2` من الوحدة المقابلة.

```elixir
# add 4 days
Date.add(~D[2021-01-01], 4)
# => ~D[2021-01-05]

# subtract 1 second
Time.add(~T[12:00:00], -1)
# => ~T[11:59:59.000000]

# add 4 days and 30 seconds
NaiveDateTime.add(~N[2021-01-01 12:00:00], 4 * 24 * 60 * 60 + 30)
# => ~N[2021-01-05 12:00:30]
```

## التحويلات

يمكن تفكيك بنية `NaiveDateTime` إلى بنية `Date` وبنية `Time` باستخدام [`NaiveDateTime.to_date/1`][naivedatetime-to-date] و[`NaiveDateTime.to_time/1`][naivedatetime-to-time]. ويمكن تحقيق العكس باستخدام [`NaiveDateTime.new!/2`][naivedatetime-new].

```elixir
NaiveDateTime.to_date(~N[2021-01-01 12:00:00])
# => ~D[2021-01-01]

NaiveDateTime.to_time(~N[2021-01-01 12:00:00])
# => ~T[12:00:00]

NaiveDateTime.new!(~D[2021-01-01], ~T[12:00:00])
# => ~N[2021-01-01 12:00:00]
```
