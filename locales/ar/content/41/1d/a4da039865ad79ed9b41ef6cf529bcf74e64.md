# التثبيت

أولًا، تأكد من تثبيت Erlang، باتباع التعليمات الواردة في صفحة تثبيت [Erlang][1] حسبما يقتضي الأمر.
[1]: /languages/erlang

## Homebrew على Mac OS X

حدّث Homebrew إلى أحدث إصدار:

```bash
$ brew update
```

ثبّت LFE:

```bash
$ brew install lfe
```

## التثبيت من المصدر
ثبّت "أدوات المطوّر" أو "حزم البناء الأساسية" في نظامك، إضافة إلى `git` و`erl` الخاص بـ Erlang.

على سبيل المثال، على Ubuntu 18.04:

```bash
$ sudo apt-get install build-essential git erlang erlang-base-hipe
```

بعد ذلك يمكنك تنزيل LFE وبناؤه بالأوامر التالية:

```bash
$ git clone https://github.com/lfe/lfe.git
$ cd lfe
$ make
$ make install
```

بعد أن تُجمَّع LFE، يمكنك تشغيل REPL (الجلسة التفاعلية) بتنفيذ الملف التنفيذي ``lfe``:

```bash
$ ./bin/lfe
```
