# مقدمة

الـ`bit` هو أدق قيمة في الحوسبة.
كلمة `bit` اختصار لـ"رقم ثنائي".
وهو وحدة لتخزين البيانات في بيئة التنفيذ، كبيرة بما يكفي لاستيعاب كائن يمكن أن يحمل إحدى قيمتين.
وبذلك تكون له قيمة ثنائية إما `1` أو `0`.
تتكوّن جميع أنواع البيانات الأخرى من عدة `bits`.
على سبيل المثال، يتكوّن الـ`byte` عادةً من ثمانية `bits`.

## أقنعة البتات

يمكن أن يكون قناع البتات أي قيمة تُستخدم لضبط بتات فردية.
على سبيل المثال، تحتوي الأبجدية الإنجليزية على ستة وعشرين حرفًا.
يمكن استخدام قيمة لا تقل عن ستة وعشرين بتًا، مثل عدد صحيح بدون إشارة بسعة 32 بت، كقناع بتات لضبط شرط `true` أو `false` لكل حرف إنجليزي.
أي قيمة تحتوي على بتات كافية للتعامل مع مجموعة مطلوبة من شروط `true` أو `false` يمكن أن تصلح كقناع بتات.
ويتم ضبط البتات الفردية وقراءتها باستخدام العوامل على مستوى البت.

## العوامل على مستوى البت

لنفترض أننا نريد تتبّع الحروف التي تظهر في `string`.
في مثالنا، سنستخدم الحروف الستة والعشرين في الأبجدية الإنجليزية فقط.
سيكون قناع البتات لدينا عددًا صحيحًا بدون إشارة بسعة 32 بت.
ستُمثّل `0` عدم ظهور الحرف.
ستُمثّل `1` ظهور الحرف مرة واحدة أو أكثر.
في البداية، سيكون التمثيل البتي لقناع البتات لدينا 32 من `0s` متتالية: `00000000000000000000000000000000`.
سيكون الموضع الأيمن مخصصًا للحرف `A`.
وسيكون الثاني من اليسار للحرف `B`، وهكذا.
لنفترض أننا نعالج جميع حروف السلسلة النصية في حلقة، لذلك نريد سطرًا واحدًا من الكود يعمل مع ضبط أي حرف.

### العامل على مستوى البت للإزاحة لليسار: أسلوب لتحديد موضع بت

`<<` هو العامل على مستوى البت للإزاحة لليسار.

إذا كان حرفنا هو `A` فلا نريد الإزاحة لليسار، أما إذا كان حرفنا `B` فنريد الإزاحة لليسار موضعًا واحدًا، وإذا كان حرفنا `C` فنريد الإزاحة لليسار موضعين، وهكذا.
على الرغم من أننا نرى `chars` كحروف مثل `A` أو `B`، فإن `char` يُنفَّذ في الذاكرة كنوع صحيح، لذا يمكننا إجراء عمليات حسابية بسيطة على `char`.
بافتراض متغير اسمه `letter` يمثّل الـ`char` الذي نعالجه، يمكننا الإزاحة لليسار بالعدد المطلوب من المواضع عبر إزاحة `1` لليسار بمقدار الفرق بين `letter` والحرف `A`، هكذا: `1 << letter - 'A'`.
`A` - `A` يساوي `0`، لذا ستُزيح `0` موضع لليسار إذا كان `letter` هو `A`.
`B` - `A` يساوي `1`، لذا ستُزيح `1` موضع لليسار إذا كان `letter` هو `B`، وهكذا.

### العامل على مستوى البت لـ OR الشامل: أسلوب لضبط بت

بمجرد أن نعرف _أين_ نريد ضبط بت، يمكننا ضبطه فعليًا باستخدام العامل على مستوى البت OR الشامل، وهو `|`.
ستكون نتيجة العامل `|` هي `1` في كل موضع يكون فيه لأحد المعاملين، الأيسر أو الأيمن، بت مضبوط.
إذن، نتيجة `0010 | 0001` ستكون `0011`.
(من المهم أن تتذكر أن القيمة هي `11` في النظام الثنائي، لكنها `3` في النظام العشري.)
لإسناد النتيجة إلى قيمة، يمكن دمج العامل `|` مع عامل الإسناد لضبط البتات هكذا: `|=`.
لتبسيط الأمر، لا يستخدم المثال التالي حلقة، لكنه يوضّح كيف يمكننا معالجة الحروف `ABA` في قناع بتات.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    // it's important to initialize the mask to 0 so we don't get garbage values
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    mask |= 1 << letter_A_again - 'A';
    // prints 3
    printf("%d", mask);
}
```

ضبطنا الجزء الأيمن من قناعنا على `0001` للحرف `A`، ثم ضبطنا القناع على `0011` للحرف `B`.
ضبط `A` أخرى لا يُحدث أي تغيير في القناع الحالي.
كان بإمكاننا تجنّب ضبط البت مرة أخرى بالتحقق مما إذا كان `A` قد ضُبط بالفعل.

### العامل على مستوى البت AND: أسلوب لقراءة بت

`&` هو العامل على مستوى البت AND.
ستكون نتيجة العامل `&` هي `1` في كل موضع يكون فيه لكلٍّ من المعاملين، الأيسر والأيمن، بت مضبوط.
إذن، نتيجة `0011 & 0001` ستكون `0001`.
يمكننا رؤية ذلك أثناء العمل في المثال التالي.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    // prints A already set
    if (mask & 1 << letter_A_again - 'A')
        printf("A already set\n");
    else
        mask |= 1 << letter_A_again - 'A';
    printf("%d", mask);
}
```

### العامل على مستوى البت لـ OR الحصري: أسلوب لقلب بت

`^` هو العامل على مستوى البت OR الحصري.
وجود عامل OR _شامل_ يعني وجود عامل OR _حصري_ بسلوك مختلف.
ستكون نتيجة العامل `^` هي `1` في كل موضع يكون فيه _واحد فقط_ من المعاملين، الأيسر أو الأيمن، بت مضبوط.
إذن، نتيجة `0001 ^ 0011` ستكون `0010`.
لن يُضبط البت الأيمن لأن _كلا_ المعاملين يحتوي على `1` في الموضع الأيمن.
يُرمز لعملية OR الحصري أحيانًا بـ XOR.
إذا كانت نتيجة قيمة خضعت لعملية XOR قد خضعت هي نفسها لعملية XOR أخرى، فستُرجع القيمة الأصلية.
يمكن استخدام هذا لتشفير بسيط جدًا حيث يُستخدم المفتاح نفسه لتشفير البيانات وفك تشفيرها.
على سبيل المثال

```c
#include <stdio.h>

int main() {
    char a = 'a';
    char b = 'b';
    char c = 'c';
    // we will use "a" for the "key"
    char first = a ^ 'a';
    char second = b ^ 'a';
    char third = c ^ 'a';
    // prints three "dots" for unprintable characters
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 0 3 2
    printf("%d %d %d\n", first, second, third);
    first = first ^ 'a';
    second = second ^ 'a';
    third = third ^ 'a';
    // prints a b c
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 97 98 99
    printf("%d %d %d\n", first, second, third);
}
```

## حقول البتات

رأينا كيف يمكن مخاطبة البتات المحزومة في نوع بيانات بسيط من خلال موضعها.
ويمكن مخاطبة البتات المحزومة في `struct` بالاسم.
ويُسمى نوع البيانات هذا `bit field`.
من حالات استخدام `bit fields` الحاجة إلى مجموعة من الأعلام بحالتي تشغيل/إيقاف مع الرغبة في تقليل استهلاك الذاكرة.

```c
#include <stdio.h>

int main() {

    struct lights {
        unsigned int number_of_lights;
        unsigned int red   : 1;
        unsigned int green : 1;
        unsigned int blue  : 1;
    };
    struct lights lightboard = {3, 0, 0, 0};
     
    //  prints 000
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    lightboard.green = 1;

    //  prints 010
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    // prints 3
    printf("%d\n", lightboard.number_of_lights);
}
```

الصيغة `unsigned int variable_name : 1;` تُنشئ حقلًا بحجم `1` بت داخل `unsigned int` موضوع داخل البنية.
وبدلًا من `unsigned int`، يمكن استخدام `signed int`، أو، بدءًا من C99 أو ما بعده، يمكن استخدام نوع `bool`.
يمكن للبنية التي تحتوي على حقول بتات أن تحتوي أيضًا على حقول من أنواع بيانات أخرى، مثل `number_of_lights` في المثال أعلاه.
