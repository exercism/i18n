# فهم الاستدعاء الذاتي في JavaScript

الاستدعاء الذاتي مفهوم قوي في البرمجة، وهو أن تستدعي الدالة نفسها.
قد يكون فهمه صعبًا بعض الشيء في البداية، لكنك متى فهمت أساسياته أصبح أداة قيّمة لحل المشكلات المعقّدة.
سنستكشف الاستدعاء الذاتي في JavaScript من خلال أمثلة سهلة الفهم.

## ما هو الاستدعاء الذاتي؟

يحدث الاستدعاء الذاتي عندما تستدعي الدالة نفسها، بشكل مباشر أو غير مباشر.
وهو يشبه الحلقة، لكنه قد يتضمّن تقسيم المشكلة إلى مسائل فرعية أصغر وأسهل في التعامل.

### المثال 1: العدّ التنازلي

لنبدأ بمثال بسيط: دالة العدّ التنازلي.

```javascript
function countdown(num) {
  // Base case
  if (num <= 0) {
    console.log('Blastoff!');
    return;
  }

  // Recursive case
  console.log(num);
  countdown(num - 1);
}

// Call the function
countdown(5);
```

في هذا المثال:

- **الحالة الأساسية**: عندما يصبح `num` أصغر من 0 أو يساويها، تطبع الدالة "Blastoff!" وتتوقف عن استدعاء نفسها.
- **الحالة الاستدعائية الذاتية**: تطبع الدالة قيمة `num` الحالية وتستدعي نفسها بـ `num - 1`.

### المثال 2: المضروب

الآن، لنلقِ نظرة على مثال كلاسيكي للاستدعاء الذاتي: حساب المضروب لعدد.

```javascript
function factorial(n) {
  // Base case
  if (n === 0 || n === 1) {
    return 1;
  }

  // Recursive case
  return n * factorial(n - 1);
}

// Test the function
console.log(factorial(5)); // Output: 120
```

في هذا المثال:

- **الحالة الأساسية**: عندما تكون `n` تساوي 0 أو 1، تُرجع الدالة 1.
- **الحالة الاستدعائية الذاتية**: تضرب الدالة `n` في مضروب `n - 1`.

## المفاهيم الأساسية

### الحالة الأساسية

يجب أن تحتوي كل دالة استدعاء ذاتي على حالة أساسية واحدة على الأقل، وهي شرط تتوقف عنده الدالة عن استدعاء نفسها.
وبدون الحالة الأساسية، سيستمر الاستدعاء الذاتي إلى ما لا نهاية، ما يؤدي إلى تجاوز سعة المكدس.

### الحالة الاستدعائية الذاتية

تحدد الحالة الاستدعائية الذاتية كيفية استدعاء الدالة لنفسها بنسخة أصغر أو أبسط من المشكلة.

## مزايا الاستدعاء الذاتي وعيوبه

**المزايا:**

- حل أنيق لبعض المشكلات.
- يحاكي مفهوم الاستقراء الرياضي.

**العيوب:**

- قد يكون أقل كفاءة من الحلول التكرارية.
- قد يؤدي إلى تجاوز سعة المكدس عند الاستدعاء الذاتي العميق.

## الخاتمة

الاستدعاء الذاتي تقنية قيّمة تبسّط المشكلات المعقّدة بتقسيمها إلى مسائل فرعية أصغر وأسهل في التعامل.
