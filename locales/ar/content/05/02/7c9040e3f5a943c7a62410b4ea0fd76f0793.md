# التعليمات

في هذا التمرين ستُنشئ رسائل سجل شبه مُهيكلة.

## 1. أصدر رسائل شبه مُهيكلة

ستبدأ ببعض الدوال غير المكتملة وبالتعداد التالي:

```rust
#[derive(Clone, PartialEq, Debug)]
pub enum LogLevel {
    Info,
    Warning,
    Error,
}
```

هدفك هو إصدار رسالة سجل بالشكل التالي: `"[<LEVEL>]: <MESSAGE>"`.
ستحتاج إلى تنفيذ دوال تقابل مستويات السجل.

على سبيل المثال، يوضح المقطع التالي المخرَج المتوقع من دالة `log`.

```rust
log(LogLevel::Error, "Stack overflow")
// Returns: "[ERROR]: Stack overflow"
```

وبالنسبة إلى `info`:

```rust
info("Timezone changed")
// Returns: "[INFO]: Timezone changed"
```

استمتع!

## 2. تدريب إضافي اختياري

يوجد في هذه المجموعة اختبار مقيَّد بميزة.
بوابات الميزات تعطّل التصريف كليًا لأقسام معينة من برنامجك.
ستُغطّى لاحقًا.
في الوقت الحالي، اعلم فقط أن هناك اختبارًا يُبنى ويُشغَّل فقط عند استخدام استدعاء اختبار خاص:

```sh
cargo test --features add-a-variant
```

الغرض من هذا الاختبار أن يوضح لك كيفية إضافة متغيّر جديد إلى تعدادك.
