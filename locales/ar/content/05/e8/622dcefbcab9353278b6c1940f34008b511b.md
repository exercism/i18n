# تعليمات

في هذا التمرين ستكتب بعض الكود لمساعدتك في إعداد لازانيا رائعة من كتاب الطبخ المفضل لديك.

لديك أربع مهام، وكلها تتعلق بالوقت المستغرق في طهي اللازانيا.

## 1. عرّف زمن الفرن المتوقع بالدقائق

عرّف ثابتًا باسم `$expected_minutes_in_oven`.
وفقًا لكتاب الطبخ، فإن زمن الفرن المتوقع بالدقائق هو 40:

```sh
$ jq -n -f lasagna.jq
{
  "expected_minutes_in_oven": 40,
  ...
```

## 2. احسب زمن الفرن المتبقي بالدقائق

تأخذ هذه القيمة الزمن الفعلي بالدقائق الذي قضته اللازانيا في الفرن كمدخل، وتُرجع عدد الدقائق التي لا تزال اللازانيا بحاجة إلى قضائها في الفرن، استنادًا إلى زمن الفرن المتوقع بالدقائق من المهمة السابقة.

```sh
$ echo '{"actual_minutes_in_oven": 18}' | jq -f lasagna.jq
{
  "expected_minutes_in_oven": 40,
  "remaining_minutes_in_oven": 22,
  ...
```

## 3. احسب زمن التحضير بالدقائق

زمن التحضير هو المدة اللازمة لتجهيز اللازانيا قبل وضعها في الفرن.
يستغرق تحضير كل طبقة دقيقتين.

```sh
$ echo '{"number_of_layers": 3}' | jq -f lasagna.jq
{
  ...
  "preparation_time": 6,
  ...
```

## 4. احسب إجمالي وقت العمل بالدقائق

احسب عدد الدقائق الإجمالي التي عملتها في طهي اللازانيا.
هذا هو مجموع زمن التحضير بالدقائق والوقت بالدقائق الذي قضته اللازانيا في الفرن في هذه اللحظة.

```sh
$ echo '{"actual_minutes_in_oven": 10, "number_of_layers": 2}' | jq -f lasagna.jq
{
  ...
  "total_time": 14,
  ...
```
