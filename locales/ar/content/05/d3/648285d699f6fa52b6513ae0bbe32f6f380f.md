# معلومات إضافية

## GNU awk والحساب ذو الدقة الاعتباطية

بشكل افتراضي، تُمثَّل الأعداد في `awk` كأعداد عشرية عائمة ذات دقة مزدوجة. وهذا يوفّر دقة مقدارها 53 بتًا (انظر [الجدول 16.3][table-16.3] في الدليل). وللأسف، هذا لا يكفي لإتمام هذا التمرين (تنبيه بحرق الأحداث: أحد الاختبارات يتطلب دقة مقدارها 63 بتًا).

تبدو رسالة «الدقة غير كافية» هكذا:
```sh
$ gawk 'BEGIN {
  n = 2 ^ 54
  if (n == n + 1)
    print "not enough precision"
  else
    print "OK"
}'
```
```none
not enough precision
```

تستطيع `awk` من GNU استخدام أعداد ذات دقة اعتباطية، إذا كانت المكتبات اللازمة قد ضُمّنت في الملف التنفيذي لـ `awk`. تحقّق من إصدار `awk` وابحث عن "GNU MPFR":
```sh
$ gawk --version
GNU Awk 5.0.1, API: 2.0 (GNU MPFR 4.0.2, GNU MP 6.2.0)
...
```

إذا كان موجودًا، فعّل هذه الإمكانية باستخدام الخيار `-M`:
```sh
$ gawk -M 'BEGIN {
  n = 2 ^ 54
  if (n == n + 1)
    print "not enough precision"
  else
    print "OK"
}'
```
```none
OK
```

ماذا لو لم يكن الخيار `-M` متاحًا في `awk` لديّ؟ سيتعيّن عليك استدعاء برنامج خارجي قادر على إجراء حسابات ذات دقة اعتباطية، مثل `bc`. راجع قسم [استخدام `getline` لإسناد قيمة إلى متغير من أنبوب][getline-pipe] للاطّلاع على مثال يوضّح كيفية ذلك.
