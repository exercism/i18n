# مقدمة

[العامل الشرطي الثلاثي][ternary-operator] صيغة مختصرة موجزة لكتابة تعبير `if-else`. فهو يقيّم شرطًا ويُرجع إحدى قيمتين بناءً على ما إذا كان هذا الشرط `true` أو `false`.

يستخدم هذا العامل ثلاثة أجزاء: `condition ? trueExpression : falseExpression`. إذا قيّم `condition` إلى `true`، فسيُقيَّم `trueExpression` ويُرجَع؛ وإلا فسيُقيَّم `falseExpression` ويُرجَع.

العامل الثلاثي مثالي للاختيارات البسيطة ذات السطر الواحد:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = showFahrenheit ? temperatureInCelsius * 9 / 5 + 32 : temperatureInCelsius
print(temperature)
// Prints 86
```

المثال أعلاه مكافئ بشكل مختصر لما يلي:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = if showFahrenheit {
    temperatureInCelsius * 9 / 5 + 32
} else {
    temperatureInCelsius
}
```

[ternary-operator]: https://docs.swift.org/swift-book/LanguageGuide/BasicOperators.html#ID71
