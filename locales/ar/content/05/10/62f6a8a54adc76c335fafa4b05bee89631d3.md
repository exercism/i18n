# مقدمة الأساسيات

[Go](https://golang.org) لغة برمجة ذات أنواع ثابتة ومُصرَّفة.
تتشابه Go نحويًا مع لغة C.
كثيرًا ما تُسمى اللغة Golang بسبب اسم نطاقها السابق، golang.org، لكن اسمها الصحيح هو Go.

سيقدّم مفهوم الأساسيات ثلاث ميزات رئيسية في اللغة: الحزم، والدوال، والمتغيرات.

## الحزم

تُنظَّم تطبيقات Go في حزم.
الحزمة مجموعة من ملفات المصدر الموجودة في الدليل نفسه.
ويجب أن تشترك جميع ملفات المصدر في الدليل الواحد في اسم الحزمة ذاته.
ومن المتعارف عليه أن يكون اسم الحزمة هو الدليل الأخير في مسار الاستيراد.
على سبيل المثال، تبدأ الملفات في [حزمة "math/rand"](https://golang.org/src/math/rand/) بالعبارة `package rand`.
وعند استيراد حزمة، لا يمكن استخدام أو الوصول إلا إلى الكيانات (الدوال والأنواع والمتغيرات والثوابت) التي تبدأ أسماؤها بحرف كبير.
النمط الموصى به للتسمية في Go هو أن تُسمّى المعرّفات باستخدام `camelCase`، باستثناء تلك المقصود أن تكون متاحة عبر الحزم، فينبغي أن تكون `PascalCase`.

```go
package lasagna
```

## المتغيرات

Go ذات أنواع ثابتة، ما يعني أن كل المتغيرات [يجب أن يكون لها نوع محدَّد](https://en.wikipedia.org/wiki/Type_system) وقت التصريف.

يمكن تعريف المتغيرات بتحديد نوعها صراحةً:

```go
var explicit int // Explicitly typed
```

يمكنك أيضًا استخدام قيمة أوّلية، وسيُسنِد المُصرِّف نوع المتغير ليطابق نوع تلك القيمة.

```go
implicit := 10   // Implicitly typed as an int
```

بعد الإعلان عن المتغير، يمكن إسناد القيم إليه باستخدام عامل `=`.
وبعد الإعلان عنه، لا يمكن أن يتغيّر نوعه أبدًا.

```go
count := 1 // Assign initial value
count = 2  // Update to new value

count = false // This throws a compiler error due to assigning a non `int` type
```

## الثوابت

تحمل الثوابت قيمة بيانات تمامًا كما تحملها المتغيرات، لكن قيمتها لا يمكن أن تتغير أثناء تنفيذ البرنامج.

تُعرَّف الثوابت باستخدام الكلمة المفتاحية `const`، ويمكن أن تكون أعدادًا أو محارف أو سلاسل نصية أو قيمًا منطقية:

```go
const Age = 21 // Defines a numeric constant 'Age' with the value of 21
```

## الدوال

تقبل دوال Go صفرًا أو أكثر من المعاملات.
ويجب تحديد أنواع المعاملات صراحةً، فلا يوجد استنتاج للأنواع.

وتُرجَع القيم من الدوال باستخدام الكلمة المفتاحية `return`.

تُستدعى الدالة بتحديد اسمها وتمرير وسائط لكل معامل من معاملاتها.

لاحظ أن Go تدعم نوعين من التعليقات.
تسبق التعليقات أحادية السطر علامة `//`، أما التعليقات متعددة الأسطر فتوضع بين `/*` و `*/`.

```go
package greeting

// Hello is a public function.
func Hello (name string) string {
    return hi(name)
}

// hi is a private function.
func hi (name string) string {
    return "hi " + name
}
```
