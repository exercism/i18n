# مقدمة

## الإعلان عن الأنواع

توفّر الإعلانات عن الأنواع في PHP تحققات على الأنواع وقت التشغيل لوسائط الدوال وقيم الإرجاع وخصائص الأصناف.
وفي الدوال، يمكن إضافة نوع إرجاع `void` للدلالة على أن الدالة لا تُرجع أي قيمة.
كما تعمل الأنواع المعلنة بمثابة تحققات وقت التشغيل من أن الدوال تُرجع استجابة بنوع سليم.

```php
<?php

class Driver
{
    private int $serial_number;

    public function setSerialNumber(int $number): void
    {
        $this->serial_number = $number;
    }

    public function getSerialNumber(): int
    {
        return $this->serial_number; 
    }
}

$driver = new Driver();
$driver->setSerialNumber("Version 1b"); // This will throw a TypeError
```

### اتحاد الأنواع

إذا كان وسيط دالة أو قيمة إرجاع أو خاصية صنف يمكن أن يكون أكثر من نوع واحد، فيمكن الإعلان عن اتحاد أنواع.

```php
<?php

class IdentityCard
{
    private int|null $id = null;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

### الأنواع المختلطة

عند العمل على الكود، قد لا نتمكن من تحديد نوع.
بدءًا من PHP 8.0، يُتاح نوع بمثابة مخرج طوارئ يُسمى `mixed`.
النوع `mixed` يكافئ اتحاد أنواع من `object|resource|array|string|float|int|bool|null`.
