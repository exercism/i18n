# التثبيت

- macOS: شغّل `brew install futhark`
- linux: شغّل `brew install futhark`
- Windows: استخدم WSL أو اتبع [التعليمات الخاصة بـ Windows][windows-specific-instructions]

يمكن العثور على أساليب تثبيت بديلة في [تعليمات التثبيت الرسمية][instructions].

[instructions]: https://futhark.readthedocs.io/en/stable/installation.html
[windows-specific-instructions]: https://futhark.readthedocs.io/en/stable/installation.html#windows-installation
