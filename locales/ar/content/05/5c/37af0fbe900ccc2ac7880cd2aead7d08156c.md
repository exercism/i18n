# نبذة

عادةً، لا تقبل الدوال إلا عددًا ثابتًا من الوسائط.
ومع ذلك، إذا وضعت `...` قبل نوع المعامل الأخير، فيمكن للدالة أن تقبل أي عدد من الوسائط اللاحقة.
وهذا يجعل المعامل الأخير _معاملًا متغيّر العدد_.

```go
func sum(nums ...int) int {
    total := 0
    for _, n := range nums {
        total += n
    }
    return total
}
```

داخل الدالة، يكون المعامل متغيّر العدد شريحة:

```go
sum(1, 2, 3)    // nums is []int{1, 2, 3}
sum(1, 2, 3, 4) // nums is []int{1, 2, 3, 4}
sum()           // nums is []int{}
```

يمكن أن تحتوي الدالة على معاملات غير متغيّرة العدد قبل المعامل متغيّر العدد.
ويمكن أن تحتوي الدالة على معامل واحد متغيّر العدد على الأكثر، ويجب أن يكون المعامل الأخير.

```go
func greet(greeting string, names ...string) {
    for _, name := range names {
        fmt.Printf("%s, %s!\n", greeting, name)
    }
}
```

## نشر شريحة

لتمرير شريحة إلى المعامل متغيّر العدد، أتبعها بـ `...`:

```go
nums := []int{1, 2, 3}
sum(nums...) // equivalent to sum(1, 2, 3)
```

لا يكون `...` صالحًا إلا عند تمرير شريحة إلى معامل متغيّر العدد.
