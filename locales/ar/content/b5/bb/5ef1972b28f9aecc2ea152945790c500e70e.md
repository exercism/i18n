# التعليمات

بدأ مشروع سيارة التحكم عن بُعد الذي أطلقته في تمرين `classes` يسير على ما يرام (تهانينا!)، وبفضل عدد من صفقات الرعاية الأخيرة أصبح هناك مال في الميزانية مخصّص للتحسينات.

ويُستخدم جزء من الميزانية لتوفير بعض بيانات القياس عن بُعد.

ولإبقاء الرعاة راضين، ثُبِّتت لوحة على السيارة لعرض أسماء الرعاة أثناء سيرها على المضمار.

وستلاحظ أن إدخال هذه التقنيات الجديدة البرّاقة قلّل بشكل كبير من عمر بطارية السيارة.

## 1. تمكين سيارة التحكم عن بُعد من عرض أسماء الرعاة

نفّذ `SetSponsors()` لتأخذ اسم راعٍ واحدًا أو أكثر وتخزّنه في السيارة.

لاحظ أن وسيط الطريقة `SetSponsors()` مضمون ألّا يكون `null`.

نفّذ `DisplaySponsor()` لعرض الراعي المحدَّد. أول راعٍ يُمرَّر له `sponsorNum` يساوي 0، والثاني 1، وهكذا.

```csharp
var car = RemoteControlCar.Buy();
car.SetSponsors("Exercism", "Walker Industries", "Acme Co.");
var sp2 = car.DisplaySponsor(sponsorNum: 1);
// => "Walker Industries"
```

## 2. الحصول على بيانات القياس عن بُعد للسيارة

نفّذ الطريقة `RemoteControlCar.GetTelemetryData()`.

ينبغي أن تجعل `GetTelemetryData()` نسبة البطارية والمسافة المقطوعة بالأمتار متاحتين عبر معاملات `out`.

ينبغي أن تُرجع `GetTelemetryData()` القيمة `false` إذا كان وسيط `serialNum` أقل من القيمة المستلمة سابقًا. (ثمّة مشكلة ما تتعلق بتورّط عدة عُقد للقياس عن بُعد). في هذه الحالة سيُضبط `serialNum` على أعلى قيمة سابقة له، وستُضبط نسبة البطارية والأمتار المقطوعة كلتاهما على `-1`. أما إذا نجح الاستدعاء فيبقى `serialNum` دون تغيير.

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
int serialNum = 4;
car.GetTelemetryData(ref serialNum, out int batteryPercentage, out int distanceDrivenInMeters);
// => true, 4L, 80, 4

serialNum = 1;
car.GetTelemetryData(ref serialNum, out batteryPercentage, out distanceDrivenInMeters);
// => false, 4L, -1, -1
```

## 3. إضافة وظائف تتيح لنظام القياس عن بُعد الحصول على استهلاك البطارية لكل متر

نفّذ الطريقة `TelemetryClient.GetBatteryUsagePerMeter()`.

ستستدعي هذه الطريقة `RemoteControlCar.GetTelemetryData()`. وإذا أرجعت `GetTelemetryData()` القيمة `false` أو لم تكن السيارة قد قِيقت بعد، فينبغي أن يُرجع هذا الإجراء "no data". وإذا أرجعت `GetTelemetryData()` القيمة `true` فينبغي أن تُرجع رسالة بالصيغة التالية "usage-per-meter=BATTERY-USAGE-PER-METER"، حيث الحساب هو (100 - نسبة البطارية الحالية) مقسومًا على المسافة المقطوعة بالأمتار حتى الآن.

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
var tc = new TelemetryClient(car);
int serialNum = 4;
tc.GetBatteryUsagePerMeter(serialNum);
// => "usage-per-meter=5"

serialNum = 1;
tc.GetBatteryUsagePerMeter(serialNum);
// => "no data"
```
