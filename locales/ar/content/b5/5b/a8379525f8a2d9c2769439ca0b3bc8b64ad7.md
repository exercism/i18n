# نبذة

يدعم Haxe الانعكاس على الأنواع والحقول في وقت التشغيل. ولكي تستخدم الانعكاس استخدامًا صحيحًا، عليك أن تفهم أي أنواع من العمليات مدعومة وأيها ليست كذلك. وبالنظر إلى الطبيعة الديناميكية للانعكاس، لا يمكن دائمًا تحديد ذلك في وقت الترجمة.

يتكوّن API الانعكاس من صنفين:

- `Reflect`: واجهة API خفيفة الوزن تعمل بشكل أفضل مع البنى المجهولة، وبدعم محدود للأصناف.
- `Type`: واجهة API أكثر متانة للعمل مع الأصناف والتعدادات.

الطرق المتاحة موضّحة بالتفصيل في API الخاص بـ [Reflect][reflect] و[Type][type].

في المثال التالي، نستخدم JavaScript كهدف:

```haxe
class Main {
  public static function main() {
    trace(Type.resolveClass("Main"));
  }
}

// This outputs
// class Test { static main() { console.log("Test.hx:3:",$hxClasses["Test"]); } }
```

[reflect]: https://api.haxe.org/Reflect.html
[type]: https://api.haxe.org/Type.html
