# مقدمة

## الكائنات

**الكائن** في JSON هو، بمصطلحات اللغات الأخرى، "hash" أو "map" أو "dictionary".

يعرّف JSON _الكائن_ بأنه:

> الكائن مجموعة غير مرتبة من أزواج **الاسم**/**القيمة**.
> يبدأ الكائن بـ `{` قوس معقوف أيسر وينتهي بـ `}` قوس معقوف أيمن.
> ويأتي بعد كل _اسم_ النقطتان `:`، وتُفصل أزواج _الاسم/القيمة_ بفاصلة `,`.

_الاسم_ **يجب أن يكون سلسلة نصية**.
وثمة كلمة أخرى مرادفة لـ _الاسم_ هي _المفتاح_.

أما _القيمة_ فيمكن أن تكون من أي نوع من أنواع JSON.
ويمكن أن تكون _القيم_ المختلفة في الكائن نفسه من أنواع مختلفة، كما في هذا المثال.

<!-- prettier-ignore -->
```json
{
  "name": "Jane",
  "age": 42,
  "pets": ["cat", "fish"],
  "address": {"street": "123 Main St", "city": "Springfield"}
}
```

<!-- prettier-ignore-end -->

لاحظ أنه **يجب ألا** توجد فاصلة بعد _آخر_ زوج مفتاح وقيمة.

### إنشاء الكائنات

استخدم الأقواس المعقوفة لتجميع أزواج الاسم/القيمة.
ومع أن الأسماء يجب أن تكون سلاسل نصية، فإنها لا تحتاج إلى وضعها بين علامتي تنصيص إذا كانت **شبيهة بالمعرّفات** (تتكوّن من حروف وأرقام وشرطة سفلية، ولا تبدأ برقم).

```jq
{name: "Jane", age: 42}
```

يجوز استخدام مفاتيح ليست _شبيهة بالمعرّفات_.
فقط ضعها بين علامتي تنصيص.

```jq
{"first name": "Jane", "last name": "Lopez", age: 42}
```

إذا كان الاسم ناتجًا عن تعبير، فيجب أن يكون التعبير **بين الأقواس الهلالية**.

```sh
$ echo "Jane" | jq -Rc '{.: 42}'
# verbose error message ...

$ echo "Jane" | jq -Rc '{(.): 42}'
{"Jane":42}
```

### الفهرسة

تُسترجَع القيم من الكائن باستخدام **الترميز النقطي**.

```jq
{name: "Jane", age: 42} | .age    # => 42
```

وإذا لم تستطع الإشارة إلى المفتاح كمعرّف، فاستخدم **الترميز بالأقواس**.

```jq
"name" as $key | {name: "Jane", age: 42} | .$key    # => error
"name" as $key | {name: "Jane", age: 42} | .[$key]  # => "Jane"
```

### إضافة أزواج المفتاح والقيمة أو تغييرها

لإضافة زوج مفتاح وقيمة جديد إلى مصفوفة، أو لتحديث قيمة مفتاح موجود، استخدم عامل الإسناد `=` مع تعبير فهرس على الجانب الأيسر.

```jq
{name: "Jane", age: 42} | .sport = "tennis" | .age = 21
# => {
#      "name": "Jane",
#      "age": 21,
#      "sport": "tennis"
#    }
```

وعامل `+` _يدمج_ الكائنات.

```jq
{Richard: 54} + {Jane: 42}
# => {
#      "Richard": 54,
#      "Jane": 42
#    }
```

### إزالة مفتاح

استخدم الدالة `del` لإزالة مفتاح.
وهي تُرجع الكائن المحدَّث.

```jq
{name: "Jane", age: 42} | del(.age)   # => {"name": "Jane"}
```

المعامل الذي تأخذه `del` هو **تعبير فهرس** (بالترميز النقطي أو الترميز بالأقواس) يُشير إلى مفتاح في الكائن.
ويسمّيه `jq` **تعبير مسار**.
ولا يكفي مجرد تمرير سلسلة نصية.

```jq
{name: "Jane", age: 42} | del(name)        # error: name/0 is not defined
{name: "Jane", age: 42} | del("name")      # error: Invalid path expression with result "name"
{name: "Jane", age: 42} | del(.name)       # OK
{name: "Jane", age: 42} | del(.["name"])   # OK
```

### العضوية

- للتحقق مما إذا كان الكائن يحتوي على مفتاح، استخدم الدالة `has`.

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ($example | has("name")),    # => true
    ($example | has("sport"))    # => false
  ```

- اختبر وجود مفتاح في كائن باستخدام `in`.

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ("name"  | in($example)),    # => true
    ("sport" | in($example))     # => false
  ```

### سرد جميع المفاتيح

استخدم الدالة `keys` لإخراج قائمة بجميع المفاتيح.

```jq
{name: "Jane", age: 42} | keys   # => ["age", "name"]
```

لاحظ أن `keys` _ترتّب_ المفاتيح.
وللحصول على المفاتيح بالترتيب الأصلي، استخدم `keys_unsorted`.

لا توجد دالة مكافئة لسرد جميع _القيم_.
غير أن المرشّح `.[]` يُخرج قيم الكائن كـ _تدفق_، ويمكن التقاط هذا التدفق باستخدام مُنشئ المصفوفة `[...]`.

```jq
[{first: "Jane", last: "Lopez", status: "awesome!"} | .[]]
# => ["Jane", "Lopez", "awesome!"]
```

### التكرار

- الدالة `map_values(filter)` تطبّق المرشّح على كل _قيمة_ في الكائن.

  ```jq
  {first: "Jane", last: "Lopez", status: "awesome!"}
  | map_values(ascii_upcase)
  # => {"first": "JANE", "last": "LOPEZ", "status": "AWESOME!"}
  ```

- للتكرار على كائن، علينا أولًا تحويله إلى مصفوفة من كائنات المفتاح والقيمة.
  وتقوم الدالة `to_entries` بذلك.

  ```jq
  {name: "Jane", age: 42} | to_entries'
  # => [
  #      {
  #        "key": "name",
  #        "value": "Jane"
  #      },
  #      {
  #        "key": "age",
  #        "value": 42
  #      }
  #    ]
  ```

  عند هذه النقطة، يمكننا استخدام دوال التكرار على المصفوفات، مثل `map`.

- الدالة `from_entries` هي العكس: تحوّل مصفوفة من كائنات المفتاح والقيمة إلى كائن.

  ```jq
  [
    {"key":"name", "value":"Jane"},
    {"key":"age", "value":42}
  ] | from_entries                  # =>{"name": "Jane", "age": 42}
  ```

- لتطبيق مرشّح على _كل_ زوج مفتاح وقيمة في كائن، استخدم الدالة `with_entries(filter)`.

  على سبيل المثال، بفرض كائن يربط اسمًا بعمر، يمكن تبديل المفاتيح والقيم كما يلي.

  ```jq
  {"Jane": 42, "Richard": 54}
  | with_entries({key: (.value | tostring), value: .key})
  ```

  فيُخرِج

  ```json
  {
    "42": "Jane",
    "54": "Richard"
  }
  ```

  ‏`with_entries(filter)` تكافئ

  ```jq
  to_entries | map(filter) | from_entries
  ```
