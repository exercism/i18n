# التعليمات

مهمتك هي أن تأخذ قائمة بمسجّلي الأهداف في مباراة، وتحصي عدد الأهداف التي سجّلها كل لاعب.

`PlayerName` هو اسم مستعار للنوع `String`، لجعل الكود أسهل في القراءة، ولتمييز هذا الاستخدام لـ `String` عن الاستخدامات الأخرى لـ `String`.

## 1. تجميع المسجّلين

أولًا، نفّذ `updateGoalCountForPlayer` لتهيئة عدد أهداف اللاعب أو زيادته.
ثم نفّذ دالة `aggregateScorers` لإحصاء عدد الأهداف التي سجّلها كل لاعب، باستخدام `updateGoalCountForPlayer`.
تأخذ هذه الدالة `List PlayerName` (أسماء اللاعبين الذين سجّلوا الأهداف، وقد تحتوي على أسماء لاعبين مكرّرة)، وتُرجع `Dict PlayerName Int` يحتوي على جميع اللاعبين في القائمة مع عدد الأهداف التي سجّلوها.

```elm
aggregateScorers [ "Betty", "Cedd", "Betty" ]
--> Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ]
```

## 2. إزالة اللاعبين غير المهمّين

نفّذ دالة `removeInsignificantPlayers` لاستبعاد اللاعبين الذين سجّلوا أهدافًا أقل من العتبة.

```elm
removeInsignificantPlayers 2 (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> Dict.fromList [ ( "Betty", 2 ) ]
```

## 3. إعادة تعيين عدد أهداف اللاعب

نفّذ دالة `resetPlayerGoalCount` لإعادة تعيين عدد الأهداف المسجّلة للاعب إلى صفر.

```elm
resetPlayerGoalCount "Cedd" (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 0 ) ]
```

## 4. تنسيق عدد الأهداف للاعب واحد

نفّذ دالة `formatPlayer` لتنسيق عدد الأهداف للاعب واحد على شكل سلسلة نصية. إذا لم يكن اللاعب موجودًا في القاموس، فافترض أن عدد أهدافه صفر.

```elm
formatPlayer "Betty" (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> "Betty: 2"
```

## 5. تنسيق عدد الأهداف لجميع اللاعبين

نفّذ دالة `formatPlayers` لتنسيق عدد الأهداف لجميع اللاعبين على شكل سلسلة نصية. يجب ترتيب اللاعبين حسب اسم اللاعب.

```elm
formatPlayers (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> "Betty: 2, Cedd: 1"
```

## 6. دمج المباريات

نفّذ دالة `combineGames`، مع إحصاء العدد الإجمالي للأهداف التي سجّلها كل لاعب في المباراتين.

```elm
combine Games
  (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
  (Dict.fromList [ ( "Betty", 2 ), ( "Mario", 3 ) ] )
--> Dict.fromList [ ( "Betty", 4 ), ( "Cedd", 1 ), ( "Mario", 3 ) ]
```
