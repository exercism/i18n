# مقدمة

مُهيّئات الكائنات بديل عن المُنشئات. وفيما يلي توضيح للصياغة: حيث تقدّم قائمة من أزواج الاسم والقيمة مفصولة بفواصل، ويُفصل بين الاسم والقيمة بعلامة `=`، وذلك داخل الأقواس المعقوفة:

```csharp
public class Person
{
    public string Name;
    public string Address;
}

var person = new Person{Name="The President", Address = "Élysée Palace"};
```

يمكن أيضًا تهيئة المجموعات بهذه الكيفية. وعادةً ما يتم ذلك بقوائم مفصولة بفواصل، كما هو موضح هنا:

```csharp
IList<Person> people = new List<Person>{ new Person(), new Person{Name="Joe Shmo"}};
```

تستخدم القواميس الصياغة التالية:

```csharp
IDictionary<int, string> numbers = new Dictionary<int, string>{ [0] = "zero", [1] = "one"...};

// or

IDictionary<int, string> numbers = new Dictionary<int, string>{ {0, "zero" }, {1,  "one"}...};
```
