# مقدمة

## المصفوفات

يعرّف JSON **المصفوفة** بأنها:

> المصفوفة مجموعة مرتّبة من القيم.
> تبدأ المصفوفة بقوس مربع أيسر `[` وتنتهي بقوس مربع أيمن `]`.
> وتُفصل القيم بفاصلة `,`.

يمكن أن تحتوي المصفوفة على صفر أو أكثر من _أي نوع_ من قيم JSON.
ولا يلزم أن تكون عناصر المصفوفة جميعها من النوع نفسه.

### إنشاء المصفوفات

استخدم الأقواس لتجميع العناصر في مصفوفة.

```jq
[1, 2, 3]
```

يمكن التقاط عناصر _تيار_ في مصفوفة عبر إحاطته بالأقواس.

```jq
range(5)     # => a stream of 5 numbers
[range(5)]   # => the array [0, 1, 2, 3, 4]
```

### الحجم

تُرجع الدالة `length` عدد العناصر في المصفوفة.

### الفهرسة والتقطيع

تبدأ فهرسة المصفوفة من الصفر.

استرجع عنصرًا من المصفوفة باستخدام تعبير أقواس:
`.[2]` يجلب العنصر الثالث.

تُعد الفهارس السالبة من نهاية المصفوفة إلى الخلف:
`.[-1]` يجلب العنصر الأخير، و`.[-2]` هو العنصر قبل الأخير.

**المقطع** هو تتابع فرعي من عناصر المصفوفة.
يُرجع `.[10:15]` 5 عناصر بدءًا من الفهرس 10، ولا يتضمن فهرس النهاية.

وهناك بعض الدوال المساعدة:

- `first` يجلب العنصر الأول.
- `last` يجلب العنصر الأخير.
- `nth(n)` يجلب العنصر عند الفهرس `n`.

### التكرار

يوفر `jq` العديد من الدوال لتغطية وظائف التكرار الشائعة:

- تُرجع `map(expr)` مصفوفة جديدة يُطبَّق فيها `expr` على كل عنصر بدوره.

  ```jq
  [1, 2, 3] | map(. * 10)    # => [10, 20, 30]

  ```

- `select(expr)` دالة تُطبِّق `expr` على _قيمة واحدة_؛
  فإذا كانت نتيجة التعبير صحيح، تُرجع القيمة؛
  وإذا كانت النتيجة خطأ، فلا تُرجع _شيئًا_، وليس `null`، بل لا شيء فعلًا.

  ولتطبيق ذلك على مصفوفة، اجمعه مع `map`.

  ```jq
  [range(10)] | map(select(. % 2 == 0))    # => [0, 2, 4, 6, 8]
  ```

  أو بدلًا من ذلك، طبّق `select` على _تيار_ واجمع النتائج.

  ```jq
  [range(10) | select(. % 2 == 0)]    # => [0, 2, 4, 6, 8]
  ```

- تُرجع `any(condition)` و`all(condition)` قيمة منطقية تحدد ما إذا كان أي من عناصر المصفوفة أو كلها يحقق الشرط.

  ```jq
  [1, 2, 3, 4] | any(. > 4)    # false
  [1, 2, 3, 4] | any(. >= 4)   # true

  [1, 2, 3, 4] | all(. >= 4)   # false
  [1, 2, 3, 4] | all(. <= 4)   # true
  ```
