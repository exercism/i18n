# التثبيت

يتطلّب مسار لغة C أن تكون البرامج التالية مثبّتة على نظامك:

* مترجم C حديث
* أداة البناء Make

يجمع Xcode IDE من Apple بين المترجم ونظام البناء الأصلي في IDE واحد (بيئة تطوير متكاملة).
عادةً ما توفّر بيئات Linux المترجم ونظام البناء الأصلي كأدوات سطر أوامر منفصلة.

## Linux

سيحتاج مستخدمو Linux إلى gcc أو clang للمترجم، وسيلزم `make` لعملية البناء الأصلية.
أداة Make مثبّتة مسبقًا على معظم أنظمة unix، لكنها متاحة على الأرجح عبر مدير الحزم لديك.
على التوزيعات المبنية على Debian و Ubuntu يمكن تثبيت كل ما تحتاجه بالأمر `sudo apt-get install build-essential` إن لم يكن مثبّتًا.

## MacOS

يمكن لمستخدمي MacOS تثبيت gcc أو clang باستخدام [Homebrew][] عبر `brew install gcc` أو `brew install llvm`.

## Windows

يُنصح مستخدمو Windows 10 باستخدام [Windows Subsystem for Linux][]، ثم اتباع تعليمات Linux أعلاه.

إذا كنت تستخدم إصدارًا أقدم من Windows أو لم يكن WSL Bash متاحًا لك، فيمكنك استخدام [MSYS][] أو [mingw-w64][].

[Homebrew]: https://brew.sh
[Windows Subsystem for Linux]: https://docs.microsoft.com/en-gb/windows/wsl/about
[MSYS]: https://www.msys2.org
[mingw-w64]: http://mingw-w64.org
