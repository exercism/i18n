# مقدمة

## التلاعب بالبتات

توفّر Java عوامل لمعالجة بتات `byte` و`short` و`int` و`long` أو `char`.

### عوامل الإزاحة

استخدم `<<` لإزاحة البتات نحو اليسار و`>>` للإزاحة نحو اليمين.

```java
// Shift two places to the left
0b0000_1011 << 2;
// # => 0b0010_1100

// Shift two places to the right
0b0000_1011 >> 2;
// # => 0b0000_0010
```

يُدخل العامل `<<` أصفارًا دائمًا على الجانب الأيمن.
أما `>>` فإنه يُدخل البتة نفسها الموجودة في أقصى اليسار (1 إذا كان العدد سالبًا أو 0 إذا كان موجبًا).

```java
// Shift 2 places to the right preserves the sign
// This is a negative value, whose binary representation is
// 1000_0000_0000_0000_0000_0000_0010_0110
int value = -0x7FFFFFDA;

// Shift two places to the right, preserving the sign bit
value >> 2;
// # => 1110_0000_0000_0000_0000_0000_0000_1001
```

استخدم `>>>` بدلًا من ذلك عندما نريد إدخال أصفار عند الإزاحة نحو اليمين.

```java
// Shift two places to the right, inserting 0s on the left
value >>> 2;
// # => 0010_0000_0000_0000_0000_0000_0000_1001
```

### عمليات البتات

#### AND البتّي

يأخذ العامل AND البتّي (`&`) قيمتين وينفّذ عملية AND على كل بتة.
فهو يقارن كل بتة من القيمة الأولى بالبتة التي تقع في الموضع نفسه من القيمة الثانية.
إذا كانت كلتاهما 1، فإن بتة النتيجة تكون 1.
وإلا فإن بتة النتيجة تكون 0.

```java
0b0110_0101 & 0b0011_1100;
// # => 0b0010_0100
```

#### OR البتّي

يأخذ العامل OR البتّي (`|`) قيمتين وينفّذ عملية OR على كل بتة.
فهو يقارن كل بتة من القيمة الأولى بالبتة التي تقع في الموضع نفسه من القيمة الثانية.
إذا كانت إحداهما 1، فإن بتة النتيجة تكون 1.
وإلا فإنها تكون 0.

```java
0b0110_0101 | 0b0011_1100;
// # => 0b0111_1101
```

#### XOR البتّي

ينفّذ العامل XOR البتّي (`^`) عملية XOR بتّية على قيمتين.
ومثل عاملي AND البتّي وOR البتّي، فهو يقارن كل بتة من القيمة الأولى بالبتة التي تقع في الموضع نفسه من القيمة الثانية.
إذا كانت إحداهما فقط 1، فإن بتة النتيجة تكون 1.
وإلا فإنها تكون 0.

```java
0b0110_0101 ^ 0b0011_1100;
// # => 0b0101_1001
```

#### NOT البتّي (`~`)

أخيرًا، يقلب العامل NOT البتّي (`~`) كل بتة.
وخلافًا للعوامل السابقة، هذا عامل أحادي، يعمل على قيمة واحدة فقط.

```java
~0b0110_0101;
// # => 0b1001_1010
```
