# ملحق التعليمات

## السجلات

| السجل   | الاستخدام | النوع      | الوصف                          |
| -------- | --------- | ------- | ----------------------------- |
| `$a0`    | إدخال     | عنوان | مصفوفة كلمات العوامل         |
| `$a1`    | إدخال     | عدد صحيح | عدد العوامل             |
| `$a2`    | إدخال     | عدد صحيح | الحد                         |
| `$v0`    | إخراج     | عدد صحيح | مجموع المضاعفات ضمن الحد |
| `$t0-9`  | مؤقت | أي     | يُستخدم للتخزين المؤقت    |
