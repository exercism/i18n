# القيم المنطقية

في Haskell نوع يُعرف باسم [`Bool`][bools].
وهو تعداد للقيمتين `True` و`False`.

## العوامل المنطقية

في Haskell ثلاثة عوامل منطقية (`not` و`||` و`&&`)، وهي تدمج القيم المنطقية وتنشئ تعبيرات تنتج قيمًا مختلفة.

### العامل «و» (`&&`)

يُمثَّل [عامل «و»][and] في Haskell بالرمز `&&`، ويُرجع `True` إذا كانت القيمتان `True`، وإلا فإنه يُرجع `False`.
عند استخدام عامل «و»، توضع قيمة منطقية على يمين `&&` وأخرى على يساره.

```haskell
True && True
-- -> True

True && False
-- -> False
```

### العامل «أو» (`||`)

يُمثَّل [عامل «أو»][or] في Haskell بالرمز `||`، ويُرجع `True` إذا كانت **قيمة واحدة على الأقل** من القيم المعطاة هي `True`. 
إذا كانت القيمتان `False`، فإنه يُرجع `False`.
عند استخدام عامل «أو»، ينبغي وضع قيمة منطقية على يمين `||` وأخرى على يساره.

```haskell
True || True
-- -> True

True || False
-- -> True

False || False
-- -> False
```

### النفي (`not`)

يُمثَّل عامل النفي في Haskell بـ `not`، ويُرجع `True` إذا كانت القيمة المنطقية المعطاة `False`، ويُرجع `False` إذا كانت القيمة المعطاة `True`.
عند استخدام عامل النفي، ينبغي وضع قيمة منطقية بعد العامل (`not`).

```haskell
not True
-- -> False

not False
-- -> True
```

## استخدام الأقواس الهلالية (`()`)

عند التعامل مع القيم المنطقية، يمكنك استخدام الأقواس الهلالية لتحديد أي القيم المنطقية تُقيَّم أولًا.
قد تختلف النتيجة حسب كيفية استخدام الأقواس.
في Haskell، يُقيَّم ما داخل الأقواس أولًا.

```haskell
True && False && False || True
-- -> True

True && False && (False || True)
-- -> False
```

بما أن ما داخل الأقواس يُقيَّم أولًا، سينطبق عامل النفي على التعبير داخل الأقواس في المثال التالي.

```haskell
not True && False
-- -> False

not (True && False)
-- -> True
```
