# التعليمات

يحتاج نادي كرة الشبكة الخاص بك إلى حساب جدول ترتيبه بعد كل جولة.

تُنجَز المهام الأربع كلها داخل الصنف `NETBALL_LADDER`.

## 1. نقاط الترتيب

الفوز يساوي 4 نقاط والتعادل نقطتين. أما الخسارة فلا تساوي شيئًا.

```sather
NETBALL_LADDER::ladder_points(3, 1)
-- => 14
```

## 2. فارق الأهداف

الأهداف المسجَّلة ناقص الأهداف التي دخلت مرماك. وقد يكون الفارق سالبًا.

```sather
NETBALL_LADDER::goal_difference(180, 205)
-- => -25
```

## 3. الأشواط الكاملة التي لُعبت

الشوط 15 دقيقة. إذا أُعطيت عددًا من الدقائق، فكم شوطًا كاملًا يمثّل ذلك؟

```sather
NETBALL_LADDER::whole_quarters(38)
-- => 2
```

## 4. الدقائق داخل الشوط

إذا أُعطيت العدد نفسه من الدقائق، فما مدى تقدّمنا داخل الشوط الحالي؟

```sather
NETBALL_LADDER::minutes_into_quarter(38)
-- => 8
```
