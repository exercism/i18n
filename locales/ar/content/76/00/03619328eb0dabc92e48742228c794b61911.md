# مقدمة

في Common Lisp، السلاسل النصية هي [متجهات][concept-vectors] من [المحارف][concept-characters]. وتُكتب كمحارف محاطة بعلامات تنصيص مزدوجة (مثل "Hello World!").

لا تُرجع دالة الفحص `stringp` القيمة صحيح إلا إذا كانت القيمة المعطاة سلسلة نصية.

يمكن تقسيم السلسلة النصية إلى سلاسل نصية فرعية باستخدام الدالة `subseq`، وهي تأخذ السلسلة النصية وفهرس البداية، ويمكنها أن تأخذ فهرس النهاية أيضًا. وتبدأ الفهرسة من الصفر.

```lisp
(subseq "Hello World" 1 5)   ; => "ello"
(subseq "skip to the end" 5) ; => "to the end"
```

يمكن مقارنة السلاسل النصية من حيث التساوي باستخدام `string=`.
وإذا أردنا تجاهل حالة المحارف، فيمكن استخدام `string-equal`.

```lisp
(string= "macaroni" "macaroni")      ; => T
(string= "macaroni" "MACARONI")      ; => NIL
(string-equal "macaroni" "MACARONI") ; => T
```

يمكن تنفيذ عمليات مثل تحويل السلسلة النصية إلى أحرف كبيرة، أو إلى أحرف صغيرة، أو كتابتها بحروف استهلالية، باستخدام `string-upcase` و`string-downcase` و`string-capitalize`.

```lisp
(string-upcase "not too loud")                ; => "NOT TOO LOUD"
(string-downcase "YELL IT FROM THE ROOFTOPS") ; => "yell it from the rooftops"
(string-capitalize "practical COMMON LiSP")   ; => "Practical Common Lisp"
```
