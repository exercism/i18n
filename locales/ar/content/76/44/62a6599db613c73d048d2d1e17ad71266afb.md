# حول

`reduce` هو الطي العام في Factor: فهو يمرّ عبر متتالية، ويمرّر مِراكمًا عبر quotation ثنائية تستقبل المِراكم الجاري والعنصر التالي وتُنتج المِراكم الجديد.

```
reduce ( seq init quot: ( prev elt -- next ) -- result )
```

```factor
USING: math sequences ;

{ 1 2 3 4 } 0 [ + ] reduce .         ! => 10
{ 1 2 3 4 } 1 [ * ] reduce .         ! => 24
```

تتيح البذرة المخصّصة لـ `reduce` التعبير عن عمليات طي لا تستطيع `sum` أو `product` التعبير عنها. على سبيل المثال، أكبر قيمة في متتالية، مع قيمة افتراضية إذا خسرت كل العناصر:

```factor
USING: math.order ;

{ 3 1 -4 5 -2 } 0 [ max ] reduce .   ! => 5
{ -3 -1 -4 }    0 [ max ] reduce .   ! => 0
```

تشارك البذرة `0` في المقارنة، لذا فإن متتالية سالبة بالكامل لا تزال تُنتج `0` بدلًا من أصغر قيمة فيها.

## `produce`: الفرد

النظير المقابل لـ `reduce` هو `produce` (في [`sequences`][sequences]): فبينما *يستهلك* `reduce` متتالية، *يولّد* `produce` واحدة. تختبر quotation شرطية الحالة الجارية؛ وطالما أنها تُرجع قيمة صحيحة، تُنتج quotation الجسم العنصر التالي.

```
produce ( pred quot -- seq )
```

وعند استخدامهما معًا، يشكّل `reduce` و`produce` زوج الطي والفرد في Factor.

## عمليات الطي التراكمي

تُرجع العائلة التراكمية في [`math.statistics`][math.statistics] متتالية بطول المدخل نفسه، حيث يكون كل عنصر فيها هو ناتج الطي على البادئة حتى ذلك الموضع شاملًا له:

| الكلمة        | العملية الجارية    |
|---------------|-------------------|
| `cum-sum`     | المجموع الجاري     |
| `cum-product` | الجداء الجاري      |
| `cum-min`     | الحد الأدنى الجاري |
| `cum-max`     | الحد الأقصى الجاري |

```factor
USING: math.statistics ;

{ 3 1 4 1 5 9 2 6 } cum-sum .         ! => { 3 4 8 9 14 23 25 31 }
{ 3 1 4 1 5 9 2 6 } cum-min .         ! => { 3 1 1 1 1 1 1 1 }
{ 3 1 4 1 5 9 2 6 } cum-max .         ! => { 3 3 4 4 5 9 9 9 }
```

تفيدك عمليات الطي التراكمي عندما تريد فحص *كيفية* تطوّر كمية ما عبر المتتالية، لا قيمتها النهائية فحسب. كما يفيد ربطها ببعضها: فمخرجات إحداها هي نفسها متتالية، جاهزة لأن تُغذّى في أخرى.

[math.statistics]: https://docs.factorcode.org/content/vocab-math.statistics.html
[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
