# الإرجاع

في Crystal، آخر تعبير في الطريقة يُرجع قيمتها.
لكن في بعض الأحيان تحتاج إلى إرجاع قيمة قبل التعبير الأخير.
لهذا، يمكنك استخدام الكلمة المفتاحية `return`، التي ستُرجع قيمة التعبير الذي يليها.
الكود المكتوب بعد الكلمة المفتاحية `return` لن يُنفَّذ.

```crystal
def speed_limit(road_number)
    if road_number == 1
        return 50
        puts "This will not be executed"
    elsif road_number == 2
        return 80
        puts "This will not be executed"
    end
    100
end

p speed_limit(1) # => 50
p speed_limit(2) # => 80
p speed_limit(3) # => 100
```

~~~~exercism/note
ينبغي حذف الكلمة المفتاحية `return` عندما يكون آخر تعبير في الطريقة هو القيمة التي يجب إرجاعها.
~~~~
