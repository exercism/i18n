# مقدمة

## المصطلحات

لقد استخدمت دوال C++ وكتبتها بالفعل في بضعة مفاهيم.
حان وقت التطرق إلى التفاصيل التقنية.
يعرض مقتطف الكود التالي المصطلحات الأكثر شيوعًا كمرجع سريع.
ولأن C++ تتجاهل المسافات البيضاء، غُيّر التنسيق ليضع كل عنصر في سطر واحد.

```cpp
// Function declaration:
bool                                              // Return type
admin_detected(string user, string password)      // Type signature
;                                                 // Don't forget the ';' for the declaration

// Function definition:
bool                                              // Return type
admin_detected                                    // Function name
(string user, string password)                    // Parameter list
{ return user == "admin" && password == "1234"; } // Function body
```
~~~~exercism/advanced
يعمل التصريح كملاحظة إلى المترجم، مفادها أن هناك دالة بهذا الاسم ونوع الإرجاع وقائمة المعاملات.
لن يعمل الكود إذا كان التعريف مفقودًا.
التصريحات اختيارية، وهي مطلوبة إذا استخدمت الدالة قبل تعريفها.
يمكن أن تحل التصريحات مشكلات مثل المراجع الدائرية، ويمكن استخدامها لفصل الواجهة عن التنفيذ.
~~~~

## مُحدِّد `const`

أحيانًا تريد التأكد من أن القيم لا يمكن تغييرها بعد تهيئتها.
تستخدم C++ الكلمة المفتاحية `const` كمُحدِّد للثوابت.

```cpp
const int number_of_dragon_balls{7};
number_of_dragon_balls--; // compilation error
```

~~~~exercism/note
سترى الثوابت غالبًا مكتوبة بنمط _UPPER_SNAKE_CASE_.
يُنصح بحصر هذا النمط على الماكرو، إن لم توجد اتفاقية أخرى.
~~~~

إذا حاولت تغيير متغير ثابت بعد تعيينه، فلن يُترجم كودك.
يساعد ذلك على تجنب التغييرات غير المقصودة، لكنه يفتح أيضًا إمكانيات تحسين أمام المترجم.
وبصفتك إنسانًا، يصبح استيعاب الكود أسهل أيضًا إذا علمت أن أجزاءً معينة لن تتأثر.

يمكنك أيضًا استخدام `const` كمُحدِّد لمعاملات الدالة.

```cpp
string guess_number(const int& secret, const int& guess) {
    if (secret < guess) return "lower.";
    if (secret > guess) return "higher.";
    return "exact!";
}
```

عندما تمرر مرجعًا `const` إلى الدالة، يمكنك أن تثق بأنه سيُترك دون تغيير.
سترى غالبًا مراجع `const` لكائنات قد يكون نسخها مكلفًا، مثل السلاسل النصية الطويلة.
ومن حالات الاستخدام الثالثة لمُحدِّد `const` دوال الأعضاء التي لا تغيّر نسخة الصنف.

```cpp
class Stubborn {
    public:
    Stubborn(string reply) {
        response = reply;
    }
    string answer(const string& question) const {
        if (question.length() == 0) { return ""; }
        return response;
    }
    private:
    string response{};
};
```

تستخدم دالة العضو `answer` في الصنف `Stubborn` مرجعًا `const string&` كمعامل.
يتجنب ذلك عملية نسخ من الكائن الأصلي الذي مُرّر إلى الدالة.

## التحميل الزائد للدوال

يمكن لعدة دوال أن تحمل الاسم نفسه إذا اختلفت قائمة المعاملات.
ويُسمى ذلك التحميل الزائد للدوال، ويُجرى عادةً عندما تؤدي هذه الدوال مهام متشابهة جدًا.

ترويسة الدالة بدون نوع الإرجاع هي __توقيع النوع__ الخاص بالدالة.
أي تغيير في توقيع النوع ينتج عنه دالة جديدة.

يحتوي مثال `play_sound` على ستة تحميلات زائدة مختلفة لتلائم سيناريوهات مختلفة:

```cpp
// different argument types:
void play_sound(char note);         // C, D, E, ..., B
void play_sound(string solfege);    // do, re, mi, ..., ti
void play_sound(int jianpu);        // 1, 2, 3, ..., 7

// different number of arguments:
void play_sound(string solfege, double duration);

// different qualifiers:
void play_sound(vector<string>& solfege);
void play_sound(const vector<string>& solfege);
```

~~~~exercism/advanced
يُعرَّف توقيع النوع باسم الدالة وعدد المعاملات وأنواعها ومُحدِّداتها (وليس أسماءها).
نوع الإرجاع ليس جزءًا من توقيع النوع بشكل صريح، وستحصل على أخطاء ترجمة إذا كان لديك دالتان تختلفان في نوع الإرجاع فقط.
سيشتكي المترجم لأن الأمر غير واضح، أي الدالتين ينبغي استخدامها.
~~~~

## الوسائط الافتراضية

قد تصبح بعض الدوال طويلة جدًا، وقد تستخدم كثير من استدعاءاتها القيم نفسها لمعظم المعاملات.
يمكن تجنب التكرار في تلك الاستدعاءات باستخدام الوسائط الافتراضية.

```cpp
void record_new_horse_birth(string name, int weight, string color="brown-ish", string dam="Alruccaba", string sire="Poseidon");

record_new_horse_birth("Urban Sea", 130); // color will be brown, dam "Alruccabam", sire "Poseidon"
record_new_horse_birth("Highclere", 175, "off-white", "Fall Aspen");   // sire will be "Poseidon"
```

ولأن تصريح الدالة يُقرأ غالبًا قبل التعريف، فهو المكان الأفضل لضبط الوسائط الافتراضية.
إذا كان لأحد المعاملات قيمة افتراضية في التصريح، فإن كل المعاملات الواقعة إلى يمينه تحتاج إلى قيمة افتراضية أيضًا.
أحيانًا يمكن إعادة هيكلة التحميلات الزائدة المعقدة للدوال إلى دوال أقل مع وسائط افتراضية، لتحسين قابلية الصيانة.
