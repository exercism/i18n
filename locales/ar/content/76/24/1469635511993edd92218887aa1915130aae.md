# حول

توفّر الصيغة الخاصة [`with`][with] طريقةً للتركيز على «المسار السعيد» لتسلسل من الخطوات التي قد تفشل، والتعامل مع الإخفاقات لاحقًا.

لنفترض أنك تريد التحقق من اسم مستخدم عبر عدة فحوصات. قد تلجأ إلى `case`:

```elixir
case check_ascii(username) do
  {:ok, username} ->
    case check_starts_with_letter(username) do
      {:ok, username} ->
        {:ok, username}

      {:error, "usernames may only start with a letter"} = err ->
        err
    end

  {:error, "usernames may only contain ascii letters"} = err ->
    err
end
```

قد يكون مقروءًا الآن، لكنه سيصبح أكثر فوضوية إذا أضفت المزيد من الفحوصات المتداخلة. في هذه الحالة، استخدم `with`:


```elixir
with {:ok, username} <- check_ascii(username),
     {:ok, username} <- check_starts_with_letter(username),
     {:ok, username} <- check_not_a_joke_name(username),
     {:ok, username} <- check_if_available(username) do
  {:ok, "#{username} is a fine username and you deserve it!"}
end
```

في كل خطوة، إذا تطابق بند، يستمر التسلسل حتى يُنفَّذ بلوك `do`. وإذا فشل أحد التطابقات، يتوقف التسلسل ويُرجَع البند غير المطابق.

يمكنك استخدام الحرّاس في التسلسل، وكذلك العامل `=` للمطابقات العادية.

```elixir
with {:ok, id} <- get_id(username),
     {:ok, avatar} when is_bitstring(avatar) <- fetch_avatar(id),
     avatar_size = bit_size(avatar),
     {:ok, image_type} <- check_valid_image_type(avatar) do
  {:ok, image_type, avatar_size, avatar}
end
```

أخيرًا، لديك خيار استخدام بلوك `else` لالتقاط المطابقات الفاشلة وتعديل القيمة المُرجَعة.

```elixir
with {:ok, id} <- get_id(username),
     {:ok, avatar} when is_bitstring(avatar) <- fetch_avatar(id),
     avatar_size = bit_size(avatar),
     {:ok, image_type} <- check_valid_image_type(avatar) do
  {:ok, image_type, avatar_size, avatar}
else
  :not_found ->
    {:error, "invalid username"}

  {:error, "not an image"} ->
    {:error, "avatar associated to #{username} is not an image"}

  err ->
    err
end
```

يشبه `else` جملة `case` لأي قيمة غير مطابقة لأحد بنود `with`. وتُستخدم أول قيمة تتطابق.

[with]: https://hexdocs.pm/elixir/Kernel.SpecialForms.html#with/1
