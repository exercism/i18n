# مقدمة

JavaScript لغة ديناميكية تدعم أساليب البرمجة كائنية التوجه والأمرية والتعريفية (مثل البرمجة الوظيفية).

## الإسناد (وإعادة الإسناد)

توجد عدة طرق أساسية لإسناد القيم إلى الأسماء في JavaScript، وذلك باستخدام المتغيرات أو الثوابت. في Exercism، تُكتب المتغيرات دائمًا بأسلوب [camelCase][wiki-camel-case]، وتُكتب الثوابت بأسلوب [SCREAMING_SNAKE_CASE][wiki-snake-case]. لا يوجد دليل رسمي يجب اتباعه، ولكل شركة أو مؤسسة دليل أسلوب خاص بها. _لا تتردد في كتابة المتغيرات بالطريقة التي تريدها_. وميزة كتابتها بالطريقة التي أُعدّت بها التمارين أنها ستُميَّز بصريًا بشكل مختلف في واجهة الويب ومعظم بيئات التطوير المتكاملة.

يمكن تعريف المتغيرات في JavaScript باستخدام الكلمة المفتاحية [`const`][mdn-const] أو [`let`][mdn-let] أو [`var`][mdn-var].

يمكن للمتغير أن يشير إلى قيم مختلفة خلال فترة حياته عند استخدام `let` أو `var`. على سبيل المثال، يمكن تعريف `myFirstVariable` وإعادة تعريفه مرات عديدة باستخدام عامل الإسناد `=`:

```javascript
let myFirstVariable = 1
myFirstVariable = 'Some string'
myFirstVariable = new SomeComplexClass()
```

وعلى عكس `let` و `var`، لا يمكن إسناد قيمة إلى المتغيرات المعرّفة بـ `const` إلا مرة واحدة. ويُستخدم هذا لتعريف الثوابت في JavaScript.

```javascript
const MY_FIRST_CONSTANT = 10

// Can not be re-assigned.
MY_FIRST_CONSTANT = 20
// => TypeError: Assignment to constant variable.
```

> 💡 في تمرين مفاهيمي لاحق سنستكشف الفرق بين إسناد _الثابت_ أو ربطه وبين _قيمة_ الثابت، وسنشرحه.

## تعريف الدوال

في JavaScript، تُغلَّف وحدات الوظائف داخل _الدوال_، ويُجمَع عادةً بين الدوال في الملف نفسه إذا كانت تنتمي إلى بعضها. ويمكن لهذه الدوال أن تستقبل معاملات (وسائط)، وأن _تُرجع_ قيمة باستخدام الكلمة المفتاحية `return`. وتُستدعى الدوال باستخدام صيغة الأقواس الهلالية `()`.

```javascript
function add(num1, num2) {
  return num1 + num2
}

add(1, 3)
// => 4
```

> 💡 توجد في JavaScript طرق _كثيرة_ ومختلفة لتعريف دالة. وتبدو هذه الطرق الأخرى مختلفة عن استخدام الكلمة المفتاحية `function`. ويسعى المسار إلى تقديمها تدريجيًا، لكن إن كنت تعرفها بالفعل فلا تتردد في استخدام أي منها. وفي معظم الحالات، لا يكون استخدام إحداها أفضل أو أسوأ من الأخرى.

## إتاحة الكود لملفات أخرى

لجعل `function` أو ثابت أو متغير متاحًا في _ملفات أخرى_، يجب [تصديره][mdn-export] باستخدام الكلمة المفتاحية `export`. ويمكن لملف آخر بعد ذلك [استيراد][mdn-import] هذه العناصر باستخدام الكلمة المفتاحية `import`. ويُعرف هذا أيضًا بنظام الوحدات. ومن الأمثلة الرائعة على ذلك طريقة عمل جميع الاختبارات. فكل تمرين يحتوي على ملف واحد على الأقل، مثل `lasagna.js`، يحتوي على _التنفيذ_. وبالإضافة إلى ذلك يوجد ملف آخر على الأقل، مثل `lasagna.spec.js`، يحتوي على _الاختبارات_. وهذا الملف _يستورد_ الكيانات العامة (أي المصدَّرة) من أجل اختبار التنفيذ:

```javascript
// file.js
export const MY_VALUE = 10

export function add(num1, num2) {
  return num1 + num2
}

// file.spec.js
import { MY_VALUE, add } from './file'

add(MY_VALUE, 5)
// => 15
```
