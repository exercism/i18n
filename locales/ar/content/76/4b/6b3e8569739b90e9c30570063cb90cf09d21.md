# نبذة

لنبدأ رحلة C++ هذه بالمتغيرات واستدعاءات الدوال والتعليقات.

## التعليقات

تأتي التعليقات بنوعين: أحادية الأسطر ومتعددة الأسطر.
كل ما يأتي بعد `//` في السطر نفسه يتجاهله المترجم.
تُعرف التعليقات متعددة الأسطر أيضًا بتعليقات نمط C.
وهي محاطة بـ `/*` و `*/`.
وكل ما يأتي بينهما سيُتجاهل أيضًا.

## المتغيرات

C++ لغة ذات أنواع.
يجب معرفة جميع الأنواع في وقت الترجمة، وتحتاج عمومًا إلى ذكرها صراحةً.
لا يمكن أن يتغيّر نوع المتغير.
يمكن الإعلان عن متغير صحيح باسم `years` هكذا:

```cpp
int years;
```

من الممارسات الجيدة تهيئة المتغيرات عند الإعلان عنها.
توفّر C++ آليات مختلفة للقيام بذلك.
النسخة ذات الأقواس المعقوفة أكثر توافقًا مع C++ الحديثة، لكن نسخة علامة التساوي شائعة جدًا أيضًا.

```cpp
int tomatoes{80};
int potatoes = 40;
```

~~~~exercism/caution
تسمح C++ فعلًا باستخدام متغيرات غير مُهيّأة.
وإلى أن يتم تعيين المتغير عمدًا، فإنه غير معرّف وقد يحتوي على أي شيء.
لتجنّب أخطاء الاستخدام قبل التعيين والسلوك غير المعرّف، يُنصح بأن **تهيّئ دائمًا**.
قد يُسقط السلوك غير المعرّف برنامجك في أسوأ لحظة ممكنة، بعد أن كان يعمل بلا مشاكل من قبل.
لا يمكن التأكيد على هذا بما يكفي: تجنّب السلوك غير المعرّف بأي ثمن.
~~~~

## العمليات الحسابية

يمكن أن تكون العوامل الحسابية مثل `*` و `+` و `-` جزءًا من تعبير مثل `3 * 2` أو `tomatoes + potatoes`.

## تحديث المتغيرات

يمكنك إعادة إسناد القيم إلى المتغيرات، ما دامت تحافظ على نوعها:

```cpp
tomatoes = tomatoes - 5; // tomatoes is now 75
potatoes = (32 * 2) + 11; // potatoes is now 75 as well
```

## الدوال

للدوال اسم ونوع إرجاع وقائمة معاملات (قد تكون فارغة).
مثال على دالة باسم `always_fortyseven` تُرجع دائمًا 47 سيبدو هكذا:

```cpp
int always_fortyseven() {
    return 47;
}
```

وهذه `vip_fee`، ولها معامل واحد:
```cpp
int vip_fee(int standard_fee) {
    /*
    vip_fee calculates the vip fee based on the standard_fee.
    */
    int vip_multi{3};
    return standard_fee * vip_multi;
}
```

أو `total_fee`، دالة بثلاثة معاملات واستدعاء لدالة أخرى.

```cpp
int total_fee(int vips, int adults, int kids) {
    /*
    total_fee calculates the total price for a group of VIP and adult guests with kids.
    Kids get a flat discount on the standard fee.
    VIP guest fees are calculated by calling vip_fee.
    */
    int standard_fee{30};
    int kids_discount{15};

    int kids_total_fee = kids  * (standard_fee - kids_discount);
    int vips_total_fee = vips * vip_fee(standard_fee);
    int adult_total_fee = adults * standard_fee;

    return vips_total_fee + adult_total_fee + kids_total_fee;
}
```

لا تُرجع الدوال في C++ قيمة العبارة الأخيرة كما في بعض اللغات الأخرى.
الكلمة المفتاحية `return` مطلوبة لكي يُترجم الكود.

### المسافات البيضاء

تُستخدم المسافات البيضاء لتنسيق الكود المصدري، وتشمل المسافات وعلامات الجدولة والأسطر الجديدة.
ولأن المترجم يتجاهل المسافات البيضاء غير الضرورية، يمكنك استخدامها لتنظيم الكود.
الاستخدام الذكي للمسافات البيضاء يمكن أن يحسّن قابلية قراءة الكود.
توجد معايير تنسيق مختلفة، لكنها كلها عُرفية ولا يفرضها المترجم.

```cpp
// Formatting makes it easier to find bugs

int eggs_yolks =  3;
int      yeast = 15;

int flour=500;int sugar=200;// compact, but difficult to read
```
