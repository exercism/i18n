# نبذة

الثوابت قيم تُحدَّد في وقت الترجمة ولا يمكن إعادة إسنادها.
استخدم الكلمة المفتاحية `const` لتعريف ثابت واحد:

```go
const greeting = "hello"
```

ويمكن تعريف عدة ثوابت داخل كتلة واحدة.
وداخل الكتلة، يعيد الثابت الذي لا تُحدَّد له قيمة صريحة التعبير السابق نفسه:

```go
const (
    greeting    = "hello"
    buffSize    = 4096
    chunkSize   // 4096
)
```

وعادةً ما تُعرَّف الثوابت على مستوى الحزمة، وإن كان يمكن تعريفها داخل دالة أيضًا.

## الثوابت ذات النوع والثوابت بلا نوع

عند تعريف ثابت دون تحديد نوعه يصبح بلا نوع.
والثابت بلا نوع ليس له نوع محدد؛ وقيمته هي التي تحدد الأنواع التي يتوافق معها.
وطالما أن القيمة الأساسية متوافقة، سيحوّله المترجم إلى النوع المطلوب عند كل استخدام:

```go
const numA = 2

math.Sqrt(numA)  // numA is treated as float64 here
var numB int = numA  // numA is treated as int here
```

أما الثابت ذو النوع فيثبّت النوع عند تعريفه:

```go
const num int = 2

math.Sqrt(num)  // compile error because a float is expected
```

## ما الذي يمكن أن يكون ثابتًا

لا يمكن للثوابت أن تحمل إلا القيم المنطقية والأعداد والسلاسل النصية وقيم `rune`.
ولأن القيم تُحدَّد في وقت الترجمة، فلا يمكن استخدام نتيجة استدعاء دالة في تعريف ثابت.

```go
const s = math.Sqrt(4)  // compile error because the value isn't known at compile time
```

## Iota

داخل كتلة من الثوابت، يمثّل `iota` موضع الثابت داخل الكتلة:

```go
const (
    Sunday    = iota // 0
    Monday           // 1
    Tuesday          // 2
    Wednesday        // 3
)
```

كل ثابت بعد الأول يرث التعبير نفسه، مع زيادة `iota` بمقدار واحد.

ويعمل `iota` أيضًا داخل التعبيرات.

```go
const (
    _  = iota             // position 0: value discarded
    KB = 1 << (10 * iota) // position 1: 1 << 10 = 1024
    MB                    // position 2: 1 << 20 = 1048576
    GB                    // position 3: 1 << 30 = 1073741824
)
```
