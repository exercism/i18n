# التعليمات

في هذا التمرين، ستكتب كودًا يساعد مستقلًا على التواصل مع مدير مشروع.
مهمتك هي توفير بعض الأدوات المساعدة لحساب المعدلات اليومية والشهرية بسرعة، مع إمكانية تطبيق خصم معيّن.

نضع أولًا بعض القواعد بين المستقل ومدير المشروع:

- المعدل اليومي يساوي 8 أضعاف المعدل في الساعة.
- الشهر فيه 22 يومًا قابلة للفوترة.

أحيانًا يعرض المستقل تطبيق خصم على معدله اليومي (مثلًا لعملائه الأكثر ولاءً أو للعملاء غير الربحيين).

يُمثَّل الخصم بأعداد عشرية تمثل نسبًا مئوية، على سبيل المثال `25.0` (25%).

~~~~exercism/note
هذه هي اللاحقات الخاصة بتعليمات الفاصلة العائمة:

| اللاحقة | حجم المعامل |
|--------|--------------|
| `ss`   | 32 بت       |
| `sd`   | 64 بت       |

هذه بعض التعليمات المذكورة في هذا المفهوم:

| التعليمة       | الوصف                                                  |
|-------------------------|--------------------------------------------------------|
| movss/movsd a, b        | ينسخ b إلى a                                          |
| addss/addsd a, b        | a = a + b                                              |
| subss/subsd a, b        | a = a - b                                              |
| mulss/mulsd a, b        | a = a * b                                              |
| divss/divsd a, b        | a = a / b                                              |
| cvtsi2ss/cvtsi2sd a, b  | يحوّل العدد الصحيح b إلى عدد ذي فاصلة عائمة a                 |
| roundss/roundsd a, b, c | يقرّب العدد ذا الفاصلة العائمة b وفقًا لـ c ويخزّنه في a |
| cvtss2si/cvtsd2si a, b  | يحوّل العدد ذا الفاصلة العائمة b إلى عدد صحيح a                 |
| comiss/comisd a, b      | يجري مقارنة بين a و b، ويُطلق استثناءً إذا كانت القيمة `NaN` |
| ucomiss/ucomisd a, b    | يجري مقارنة بين a و b، ويضبط `PF` إذا كانت القيمة `NaN` |

هذه هي أرقام التحكم في التقريب في `roundss` و `roundsd`:

| الرقم | النمط         |
|:-------|:-------------|
| 0      | الأقرب      |
| 1      | التقريب لأسفل |
| 2      | التقريب لأعلى    |
| 3      | الاقتطاع     |
~~~~

## 1. احسب المعدل اليومي انطلاقًا من المعدل في الساعة

نفّذ دالة باسم `daily_rate` لحساب المعدل اليومي، ويُمرَّر إليها معامل هو المعدل في الساعة، على هيئة عدد ذي فاصلة عائمة بطول 64 بت.
ينص العقد على أن اليوم فيه 8 ساعات قابلة للفوترة.

```c
daily_rate(60)
// => 480.0
```

يجب أن يكون المعدل اليومي المُرجَع عددًا ذا فاصلة عائمة بطول 64 بت.

## 2. احسب السعر بعد الخصم

نفّذ دالة `apply_discount` لحساب السعر بعد الخصم.
يجب أن تقبل معاملين: السعر الأصلي ونسبة الخصم بالمئة، وكلاهما على هيئة عدد ذي فاصلة عائمة بطول 64 بت.

```c
apply_discount(150.0, 10.0)
// => 135.0
```

يجب أن تكون القيمة المُرجَعة دائمًا عددًا ذا فاصلة عائمة بطول 64 بت.

## 3. احسب المعدل الشهري انطلاقًا من المعدل في الساعة ونسبة الخصم

نفّذ دالة `monthly_rate` لحساب المعدل الشهري بعد الخصم.
تأخذ معاملين: المعدل في الساعة ونسبة الخصم بالمئة، وكلاهما على هيئة عدد ذي فاصلة عائمة بطول 64 بت.

```c
monthly_rate(77.0, 10.5)
// => 12130
```

يجب تقريب المعدل الشهري المُرجَع لأعلى (أي أخذ السقف) إلى أقرب عدد صحيح بطول 64 بت.

## 4. احسب عدد أيام العمل الكاملة انطلاقًا من الميزانية والمعدل في الساعة ونسبة الخصم

نفّذ دالة `days_in_budget` تأخذ المعاملات التالية:

1. ميزانية، على هيئة عدد صحيح بدون إشارة بطول 64 بت.
2. المعدل في الساعة، على هيئة عدد ذي فاصلة عائمة بطول 64 بت.
3. نسبة الخصم بالمئة، على هيئة عدد ذي فاصلة عائمة بطول 64 بت.

يجب أن تُرجع هذه الدالة عدد أيام العمل الكاملة التي تغطيها الميزانية.

```c
days_in_budget(20000, 80, 11.0)
// => 35
```

يجب تقريب عدد الأيام المُرجَع لأسفل (أي أخذ الأرضية) إلى أقرب عدد صحيح بطول 32 بت.
