# بدون rescue

لا تستخدم الاستثناءات للتحكم في مسار التنفيذ.
حاول حل هذا التمرين دون استخدام `rescue`.

إذا كنت تستخدم دالة من المكتبة القياسية ينتهي اسمها بعلامة `!` (ترفع الأخطاء)، فابحث عن دالة مكافئة بدون `!` (غالبًا ما تُرجع `{:ok, result}` أو `{:error, message}`).

ملاحظة: إذا ظهر لك هذا التعليق التلقائي على حلّك، فربما لا تكون التعليقات التلقائية الأخرى دقيقة.
أصلح هذه المشكلة أولًا!

```elixir
# preferred: for example `case`

case Date.new(1999, 13, 1) do
  {:ok, date} -> date
  {:error, _} -> nil
end

# discouraged: rescuing exceptions

try do
  Date.new!(1999, 13, 1)
rescue
  ArgumentError ->
    nil
end
```
