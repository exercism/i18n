# مقدمة

تُعدّ حلقة `for` واحدة من أكثر العبارات شيوعًا لتنفيذ بعض المنطق بشكل متكرر.
في JavaScript، تتكوّن من الكلمة المفتاحية `for`، و_رأس_ محاط بالأقواس الهلالية، وكتلة كود تحتوي على _جسم_ الحلقة محاطة بالأقواس المعقوفة.

```javascript
for (initialization; condition; step) {
  // code that is executed repeatedly as long as the condition is true
}
```

عادةً ما تُهيّئ التهيئة متغير عدّاد، ويتحقق الشرط من وجوب استمرار الحلقة أو توقفها، وتزيد الخطوة قيمة العدّاد في نهاية كل تكرار.
وتفصل الفواصل المنقوطة بين الأجزاء المختلفة من الرأس.

```javascript
const list = ['a', 'b', 'c'];
for (let i = 0; i < list.length; i++) {
  // code that should be executed for each item list[i]
}
```

غالبًا ما يتم تعريف الخطوة باستخدام عامل الزيادة أو النقصان في JavaScript، كما يوضّح المثال أعلاه.
تُعدّل هذه العوامل المتغير في مكانه.
يضيف `++` واحدًا إلى العدد، ويطرح `--` واحدًا من العدد.

```javascript
let i = 3;
i++;
// i is now 4

let j = 0;
j--;
// j is now -1
```
