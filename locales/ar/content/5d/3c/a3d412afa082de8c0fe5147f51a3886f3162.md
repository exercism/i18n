# مقدمة

Ruby هي لغة [كائنية التوجه][object-oriented-programming] ديناميكية.
كل شيء في Ruby هو [كائن][object].

هناك أسلوبان أساسيان لإسناد الكائنات إلى الأسماء في Ruby: استخدام المتغيرات أو الثوابت.
تُكتب المتغيرات دائمًا بأسلوب [snake case][snake-case].
ويمكن للمتغير أن يشير إلى كائنات مختلفة خلال مدة وجوده.
فعلى سبيل المثال، يمكن تعريف `my_first_variable` وإعادة تعريفه مرات عديدة باستخدام العامل `=`:

```ruby
my_first_variable = 1
my_first_variable = "Some string"
my_first_variable = SomeComplexObject.new
```

أما الثوابت فيُقصد بها أن تُسند مرة واحدة.
ويجب أن تبدأ بحروف كبيرة، وتُكتب عادةً بحروف كبيرة بالكامل مع فصل الكلمات بشرطات سفلية.

فعلى سبيل المثال:

```ruby
MY_FIRST_CONSTANT = 10

# Redefining not allowed
# MY_FIRST_CONSTANT = "Some String"
```

يتنظّم Ruby في أصناف.
وتُعرَّف الأصناف باستخدام الكلمة المفتاحية `class` متبوعة باسم الصنف.
وتُنشأ الكائنات عمومًا بإنشاء نسخ من الأصناف باستخدام الطريقة `.new`.

فعلى سبيل المثال:

```ruby
# Define the class
class Calculator
  #...
end

# Create an instance of it and assign it to a variable
my_first_calc = Calculator.new
```

تُغلَّف وحدات الوظائف في طُرق، على غرار _الدوال_ في لغات أخرى.
يمكن اختياريًا تعريف الطريقة بوسائط موضعية، و/أو وسائط مفتاحية تُعرَّف وتُستدعى باستخدام الصيغة `:`.
وإما أن تُرجع الطرق ضمنيًا نتيجة آخر عبارة نُفِّذت، وإما أن تُرجع صراحةً كائنًا عبر الكلمة المفتاحية `return`.
وتُستدعى الطرق باستخدام الصيغة `.`.

```ruby
class Calculator

  # Unnamed params
  def add(num1, num2)
    return num1 + num2 # Explicit return
  end

  # Named params
  def multiply(num1:, num2:)
    num1 * num2 # Implicit return
  end
end

calc = Calculator.new
calc.add(1, 3)
calc.multiply(num1: 2, num2: 5)
```
