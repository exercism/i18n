# حول

تمتلك الدوال ارتباطًا خارجيًا بشكل افتراضي، ويمكن استدعاؤها من أي ملف آخر في المشروع.
لمزيد من التفاصيل عن الارتباط، راجع [مفهوم الارتباط](../linkage/introduction.md#Introduction).
لا يمكن استدعاء دالة `static` إلا داخل ملف المصدر الذي تُعرَّف فيه.

على سبيل المثال

```c
// file scope, internal linkage
// can only be called from within this file
static void some_function()
{
    // code snipped
}

// file scope, external linkage by default
// can be called from any other file in the project
int main()
{
    // code snipped
}
```

حتى لو أُعلنت دالة في ملف ترويسة، فإذا عُرِّفت على أنها `static` فلن يكون بالإمكان استدعاؤها من خارج ملف المصدر الخاص بها.
قد يُضمِّن ملف مصدر ملف الترويسة، ويستدعي دالة `static` المُعلَنة فيه، ويُصرَّف بنجاح، لكن الرابط سيفشل في العثور على تعريف دالة `static`.
الدالة التي تُوسَم بـ `static` في ملف مصدر لا ينبغي إعلانها في ملف الترويسة الخاص بها.
