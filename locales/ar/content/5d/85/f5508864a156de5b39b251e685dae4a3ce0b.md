# مقدمة

يمكن جعل معامل الطريقة اختياريًا بإسناد قيمة افتراضية إليه. وعند استدعاء طريقة لها معاملات اختيارية، لا يُطلب من المستدعي تمرير قيمة لها. وإذا لم تُمرَّر أي قيمة لمعامل اختياري، فستُستخدم قيمته الافتراضية.

يجب أن تكون المعاملات الاختيارية في نهاية قائمة المعاملات؛ فلا يمكن أن تأتي بعدها معاملات غير اختيارية.

```csharp
class Card
{
    static string NewYear(int year = 2020)
    {
        return $"Happy {year}!";
    }
}

Card.NewYear();     // => "Happy 2020!"
Card.NewYear(1999); // => "Happy 1999!"
```
