# تشغيل الاختبارات

## نزّل تمرينًا

استخدم [واجهة سطر الأوامر الخاصة بـ Exercism][cli] لتنزيل التمرين الذي تريد العمل عليه.

```sh
exercism download --track=dart --exercise=hello-world
```

ثم انتقل إلى مجلد التمرين.

```sh
cd /path/to/exercism/dart/hello-world
```

## ثبّت التبعيات

قبل تشغيل الاختبارات، نزّل تبعيات التمرين.

```sh
dart pub get
```

## شغّل الاختبارات

```sh
dart test
```

## العمل على الاختبارات تدريجيًا

معظم التمارين تحتوي على عدة اختبارات، وكلها متخطّاة افتراضيًا باستثناء الأول.

```dart
void main() {
  final twoFer = TwoFer();

  group('TwoFer', () {
    test('no name given', () {
      final result = twoFer.statement();
      expect(result, equals('One for you, one for me.'));
    }, skip: false);

    test('a name given', () {
      final result = twoFer.statement('Alice');
      expect(result, equals('One for Alice, one for me.'));
    }, skip: true);

    test('another name given', () {
      final result = twoFer.statement('Bob');
      expect(result, equals('One for Bob, one for me.'));
    }, skip: true);
  });
}
```

لتنجز الاختبارات واحدًا تلو الآخر، غيّر `skip: true` إلى `skip: false` في كل اختبار كلما تقدّمت.
أو شغّل جميع الاختبارات دفعة واحدة دون تعديل الملف.

```sh
dart test --run-skipped
```

يشغّل مشغّل الاختبارات عبر الإنترنت جميع الاختبارات عند التسليم، بما فيها المتخطّاة.

## التعامل مع الخطأ "Could not find a command named frontend_server.dart.snapshot"

لنفترض أن لديك تمرينًا حللته وسلّمته بالفعل، وعدت إليه بعد فترة.
قد تصادف هذا الخطأ عند اختباره:

```sh
$ dart test
...
Could not find a command named "/path/to/frontend_server.dart.snapshot".
```

الحل هو حذف ملف `pubspec.lock`.
ثم شغّل أمر dart مرة أخرى.
