# مقدمة

تُعدّ مفاهيم التغاير واللاتغاير في PHP مهمة، لأن PHP تفرض الالتزام بهذه القواعد عند توسيع الأصناف أو الواجهات.

يحافظ التغاير على العلاقة بين نوعين، بينما يعكس اللاتغاير هذه العلاقة. وباختصار، هذا يعني أنه عند توسيع الأصناف وإعادة تعريف الدوال، يمكنك السماح بأنواع أكثر أو أقل تحديدًا لمعاملات طريقتك، ويمكنك إرجاع أنواع أقل أو أكثر تحديدًا من الطريقة.

## أمثلة

تأمّل الصنف التالي:

```php
class Calculator 
{
    public function add(int $x, int $y): int 
    {
        return $x + $y;
    }
}
```

إذا وسّعنا الصنف، فيمكننا السماح بأنواع معاملات أكثر مما أُعلن عنه في الأصل، لكن لا يمكننا إرجاع أي شيء غير أنواع الإرجاع الأصلية.

```php
class Floatulator extends Calculator
{
    // This is valid
    public function add(int|float $x, int|float $y): int 
    {
        return (int)($x + $y);
    }
}
```

الصنف الموسّع التالي غير صالح، لأن إرجاع أنواع إضافية أو أوسع غير مسموح به:

```php
class BrokenCalculator extends Calculator 
{
    // This is invalid and will not compile
    public function add(int|float $x, int|float $y): int|float{
        return $x + $y;
    }
}
```
