# مقدمة

الصف هو تجميع _غير قابل للتغيير_ لقيم غير مسمّاة لكن مرتّبة.
يمكن للصفوف أن تحمل أي نوع بيانات أو عدة أنواع، بما في ذلك صفوف أخرى.

تُعرَّف الصفوف كقيم مفصولة بفواصل بين المحرفين `(` و`)`: `(<element_1>, ... , <element_n>)`.

```fsharp
("one", 2) // Tuple pair (2 values)
("one", 2, true) // Tuple triplet (3 values)
```

لا يمكن مقارنة إلا الصفوف التي لها الطول نفسه والأنواع نفسها (بالترتيب نفسه).
للصفوف تساوٍ بنيوي، أي أنها تكون متساوية _فقط_ إذا كانت جميع قيمها متساوية.

```fsharp
(1, 2) = (1, 2) // Same length, same types, same values, same order
// => true

(1, 2) = (2, 1) // Same length, same types, same values, different order
// => false

(1, 2) = (1, "2") // Same length, different types
// compiler error

(1, 2) = (1, 2, 3) // Different length
// compiler error
```

توجد ثلاث أساليب لاستخراج القيم من الصف:

- الدالتان `fst` و`snd`
- تفكيك الصف
- مطابقة الأنماط

```fsharp
let person = ("Jordan", 170)

// Option 1: fst/snd
let name1 = fst person
let length2 = snd person

// Option 2: deconstruction
let (name2, length2) = person
// => name2 = "Jordan"
// => length2 = 170

// Option 3: pattern matching
match person with
| name3, length3 -> printf "%s: %d" name3 length3
```
