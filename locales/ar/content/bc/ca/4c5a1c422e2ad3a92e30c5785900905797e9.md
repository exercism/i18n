# أذونات مستودع المشرفين

مشرف المسار هو شخص عضو في فريق المسار على GitHub.
لا يمكن أن تصبح عضوًا في فريق مسار إلا _بالدعوة فقط_.

```exercism/note
إذا كنت ترغب في أن تصبح مشرف مسار، فالرجاء فتح موضوع على [المنتدى](https://forum.exercism.org/c/exercism/building-exercism/125).
```

## فئة الصيانة

هناك خمس فئات للصيانة:

1. `wip-track`
2. `unmaintained`
3. `maintained-solitary`
4. `maintained-autonomous`
5. `maintained`

تُحدَّد فئة صيانة المسار بثلاثة متغيرات:

1. ما إذا كان المسار نشطًا (أي أن الطلاب يمكنهم الانضمام إلى المسار على الموقع)
2. عدد مشرفي المسار
3. عدد مشرفي المسار الذين هم أيضًا في فريق `cross-track-maintainers` على GitHub

لتحديد فئة الصيانة، ابحث عن أول فئة تطابق المسار في هذا الجدول:

| الفئة                 | نشط؟ | عدد المشرفين | عدد المشرفين بين المسارات |
| --------------------- | ------- | --------------------- | --------------------------------- |
| wip-track             | لا      | أي                    | أي                               |
| unmaintained          | نعم     | 0                     | 0                                 |
| maintained-autonomous | نعم     | > 0                   | = عدد المشرفين                    |
| maintained-solitary   | نعم     | 1                     | 0                                 |
| maintained            | نعم     | > 1                   | < عدد المشرفين                    |

## أذونات المستودع

تُستخدم فئة الصيانة لضبط أذونات مستودع (مستودعات) المسار على GitHub.

| الفئة                 | يتطلب PR | يتطلب موافقة على PR | مراجعات فريق المسارات المتقاطعة |
| --------------------- | ----------- | -------------------- | ------------------------ |
| wip-track             | لا          | لا                   | لا                       |
| unmaintained          | نعم         | نعم                  | نعم                      |
| maintained-solitary   | نعم         | نعم                  | نعم                      |
| maintained-autonomous | نعم         | لا                   | لا                       |
| maintained            | نعم         | لا                   | لا                       |

```exercism/caution
فئة `wip-track` هي الفئة الوحيدة التي تسمح للمشرفين بالدفع إلى `main`.
```

```exercism/caution
ستتطلب مستودعات الأدوات _دائمًا_ موافقة على PR، لأن محتوياتها محمية عبر [ملف CODEOWNERS](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-code-owners).
```
