# نبذة

هناك نوعان مختلفان من الأعداد في Elixir: الأعداد الصحيحة والأعداد العشرية.

الأعداد الصحيحة هي أعداد كاملة.

```elixir
integer = 3
# => 3
```

يمكن العثور على بعض الدوال المفيدة للتعامل مع الأعداد الصحيحة في وحدة [`Integer`][integer].

```elixir
Integer.digits(123)
# => [1, 2, 3]
```

عادةً ما تُنسّق الأعداد الصحيحة الكبيرة (وكذلك الأعداد العشرية) بفصل كل 3 خانات إلى مجموعات باستخدام شرطة سفلية.

```elixir
1_000_000
# => 1000000
```

لا يقتصر الحد الأقصى لحجم الأعداد في Elixir إلا على الذاكرة المتاحة في النظام، لأن Elixir تستخدم [حسابًا بدقة اعتباطية][arbitrary-precision-arithmetic].

تدعم Elixir أيضًا صيغًا مختصرة لإدخال [الأعداد الثنائية والثمانية والست عشرية][integers-in-other-bases].

```elixir
0b0100
# => 4

0o555
# => 365

0xFF
# => 255
```

## المقارنة

يمكن اعتبار الأعداد الصحيحة والأعداد العشرية متساوية ([`==`][kernel-equal]) إذا كانت لهما القيمة نفسها. لكن، لاختلاف نوعيهما، فإنهما لا يتساويان تساويًا صارمًا أبدًا ([`===`][kernel-strictly-equal]).

```elixir
1 == 1.0
# => true

1 === 1.0
# => false
```
