# المقدمة

يستطيع تعبير `switch` مطابقة قيمة مع حالة واحدة من مجموعة من الأنماط، ثم إرجاع القيمة المرتبطة أو تنفيذ الإجراء المرتبط. ويُشار إلى هذا الارتباط بالرمز `=>`. وبالإضافة إلى ذلك، يمكن لكل نمط أن يحتوي على حارس حالة اختياري يُقدَّم بالكلمة المفتاحية `when`. ويجب أن يُقيَّم تعبير حارس الحالة إلى صحيح حتى يُختار ذلك «الذراع» من `switch`. وتُقيَّم الحالات (وتُعرف أيضًا بـ«أذرع `switch`») بالترتيب الذي كُتبت به في النص، فتتوقف العملية فور العثور على تطابق وتُرجَع القيمة المرتبطة.

```csharp
double xx = 42d;

string interesting = xx switch
{
    0 => "I suppose zero is interesting",
    3.14 when DateTime.Now.Day == 14 && DateTime.Now.Month == 3 => "Mmm pie!",
    3.14 => "π",
    42 => "a bit of a cliché",
    1729 => "only if you are a pure mathematician",
    _ => "not interesting"
};

// => interesting == "a bit of a cliché"
```
