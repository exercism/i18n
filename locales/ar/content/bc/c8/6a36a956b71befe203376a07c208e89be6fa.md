# مقدمة

تمثل Unison قيم صحيح وخطأ بالنوع `Boolean`. لا توجد سوى قيمتين: `true` و`false`.

```unison
trueVariable = true
falseVariable = false
```

يمكننا تقييم التعبيرات المنطقية باستخدام العوامل and وor وnot، حيث يُمثَّل and بـ`&&`، وor بـ`||`، وnot بـ`not`.

```unison
trueVariable = true && true
falseVariable = true && false

trueVariable = false || true
falseVariable = false || false

trueVariable = not false
falseVariable = not true
```

تسمح تعبيرات Unison المنطقية بالتقييم القصير؛ فإذا كان الوسيط الأول في تعبير `&&` هو `false`، فلا سبب لمواصلة تقييم الوسيط الثاني. وبالمثل، إذا كان الوسيط الأول في تعبير `||` هو `true`، فسيُرجع التعبير `true` فورًا.

```unison
> false && (base.bug "oh no")
  ⧩
  false
```

```unison
> true || (base.bug "oh no")
  ⧩
  true
```
