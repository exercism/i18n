# مقدمة

## الدوال المجهولة

تمتلك Gleam دوالًا من الدرجة الأولى، أي أن الدوال قيم عادية يمكن إسنادها إلى المتغيرات، وتمريرها كوسائط، وإرجاعها من دوال أخرى.

يمكن الإشارة إلى دالة مُسمّاة معرَّفة في وحدة باسمها.

```gleam
pub fn main() {
  // Assign the function to a variable
  let f = add_one
  
  // Invoke the function
  f(1) // -> 2
  f(2) // -> 3
}

fn add_one(x) {
  x + 1
}
```

تمتلك Gleam أيضًا دوالًا مجهولة، تُعرَّف داخل دوال أخرى.

```gleam
// Define the function
let f = fn(x) { x + 1 }

// Invoke the function
f(1) // -> 2
f(2) // -> 3
```

يُكتب نوع الدالة بصيغة مشابهة لصيغة الدوال المجهولة. يُكتب نوع دالة تأخذ `Int` و`Float` وتُرجع `Int` هكذا:

```gleam
fn(Int, Float) -> Int
```

يمكن للدوال المجهولة أن تشير إلى متغيرات كانت في النطاق عند تعريفها، ما يجعلها _إغلاقات_.

```gleam
let secret_number = 42

// This function always returns 42
fn() { secret_number }
```

توفّر صيغة _التقاط الدالة_ اختصارًا ملائمًا لإنشاء دوال مجهولة تمرّر وسيطًا واحدًا إلى دالة. هذان التعبيران متكافئان:

```gleam
// Anonymous function syntax
let f = fn(x) { my_function(1, 2, x) }

// Function capture syntax
let f = my_function(1, 2, _)
```
