# مقدمة

تسمح التعدادات في Cairo لك بتعريف نوع يمكن أن يكون واحدًا من عدة خيارات مسماة.

## الأساسيات

التعدادات، وهي اختصار كلمة enumerations، تحصر جميع القيم الممكنة لبعض البيانات في مجموعة محددة مسبقًا.
تسمى القيم الممكنة لـ `enum` خيارات:

```rust
#[derive(Drop)]
enum Direction {
    North,
    South,
    East,
    West,
}
```

أنشئ قيم التعداد بتحديد الخيار:

```rust
let my_direction = Direction::North;
let another_direction = Direction::West;
```

## مطابقة الأنماط

استخدم `match` للتعامل مع خيارات التعداد المختلفة:

```rust
match my_direction {
    Direction::North => println!("Going north!"),
    Direction::South => println!("Going south!"),
    Direction::East => println!("Going east!"),
    Direction::West => println!("Going west!"),
}
```

يتعامل كل فرع من فروع `match` مع خيار واحد من التعداد.

## التعدادات ذات البيانات

يمكن لخيارات التعداد أن تحمل بيانات إضافية:

```rust
struct Location {
    x: u32,
    y: u32,
}

enum Message {
    Text: ByteArray,
    Number: u32,
    Location: Location,
}
```

استخدم مطابقة الأنماط لاستخراج البيانات:

```rust
match msg {
    Message::Text(content) => println!("Text: {}", content),
    Message::Number(val) => println!("Number: {}", val),
    Message::Location(Location { x, y }) => println!("Position: ({}, {})", x, y),
}
```
