# التعليمات

كانت شركة التصميم التي تعمل بها تعتمد أساسًا على تحويلات CSS لبناء صفحات الويب. وبعد بعض النقاش، اتُّخذ قرار بالبدء في استخدام Clojure لإجراء بعض الحسابات ديناميكيًا. بعض زملائك في الفريق أقل خبرة بـ Clojure، لذا تقرر استخدام إغلاق دالة لإنشاء تحويلات قابلة لإعادة الاستخدام لأزواج الإحداثيات `{x, y}`.

## 1. إزاحة الإحداثيات

نفّذ الدالة `translate2d` التي تُرجع دالة تستفيد من إغلاق لإجراء إزاحة ثنائية الأبعاد قابلة للتكرار لزوج إحداثيات.

```clojure
(def move-coordinates-right-2px (translate2d 2 0))
(def result (move-coordinates-right-2px 4 8))
;; result => [6 8]
```

## 2. تحجيم الإحداثيات

نفّذ الدالة `scale2d` التي تُرجع دالة تستفيد من إغلاق لإجراء تحجيم ثنائي الأبعاد قابل للتكرار لزوج إحداثيات.

> في هذا التمرين، افترض أن قيم التحجيم موجبة فقط.

```clojure
(def double-scale (scale2d 2 2))
(def result (double-scale 6 -3))
;; result => [12 -6]
```

## 3. تركيب دوال التحويل

اجمع بين دالتي تحويل لإجراء تحويل قابل للتكرار. يُسمى هذا غالبًا _تركيب الدوال_، حيث تُستخدم نتيجة الدالة الأولى _'f(x)'_ كمدخل للدالة الثانية _'g(x)'_.

```clojure
(def move-coordinates-right-2px (translate2d 2 0))
(def double-coordinates (scale2d 2 2))
(def composed-transformations 
  (compose-transform move-coordinates-right-2px 
                     double-coordinates))
(def result (composed-transformations 0 1))
;; result => [4 2]
```

## 4. احفظ نتائج الدوال

نفّذ الدالة `memoize-transform`. تأخذ دالة يُراد _حفظ نتائجها_، ثم تُرجع دالة جديدة تتذكر المدخلات الممرَّرة إلى الدالة المعطاة، بحيث يمكن "تذكّر" قيمة الإرجاع الأخيرة وحسابها مرة واحدة فقط إذا استُدعيت مجددًا بالوسائط نفسها.

> يُسمى حفظ النتائج أحيانًا _البرمجة الديناميكية_، وهو يسمح بتنفيذ العمليات المكلفة مرة واحدة فقط نظرًا لتذكّر نتيجتها.

```clojure
(def triple-scale (scale2d 3 3))
(def memoized-scale (memoize-transform triple-scale))

(memoized-scale 4 3)
;; => [12, 9], this is computed since it hasn't been computed before for the arguments

(memoized-scale 4 3)
;; => [12, 9], this is remembered, since it was computed already
```
