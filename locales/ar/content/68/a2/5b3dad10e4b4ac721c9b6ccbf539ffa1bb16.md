# الاختبارات

على MacOS/Linux، شغّل الأمر التالي:

```sh
$ chmod +x gradlew
```

نفّذ الاختبارات بالأمر التالي:

```sh
$ ./gradlew test
```

> استخدم `gradlew.bat` إذا كنت تستخدم Windows

## الاختبارات المتجاهَلة

بعد نجاح الاختبار الأول أو الاختبارات الأولى، تابع بتعليق تعليقات `@Ignore` التي تسبق بقية الاختبارات أو بحذفها.
