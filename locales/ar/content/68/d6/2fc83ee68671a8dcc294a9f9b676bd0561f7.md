# السمات

تحدّد السمة مجموعة من الطرق التي يمكن لنوع أن ينفّذها.
والسمات مفيدة لتعريف طرق ينبغي أن تكون مشتركة بين الأنواع.
وعند استخدام السمات مع الأنواع العامة، يمكن استدعاء الطرق المعرّفة على نوع معيّن، كما يمكن استدعاؤها على نوع بيانات آخر.
وبشكل تجريدي، يمكننا باستخدام _قيود السمات_ أن نحدّد أن النوع العام يجب أن يتشارك سلوكًا معيّنًا.

> **ملاحظة:** تشترك السمات في ميزات مشابهة لما يُعرف بالواجهات في لغات البرمجة الأخرى، مع بعض الاختلافات.

## تعريف السمة

يساعد تعريف السمة على تحديد توقيع الدالة الذي يشكّل مجموعة السلوكيات التي يمكن لنوع أن ينفّذها للوصول إلى نتيجة.
وتشكّل هذه الطرق سلوك النوع.
وإذا استطعنا استدعاء الطرق نفسها على أنواع مختلفة، فهذا يعني أن الأنواع المعنية تشترك في السلوك نفسه.

```rust
#[derive(Drop)]
pub struct NewsArticle {
    pub headline: ByteArray,
    pub location: ByteArray,
    pub author: ByteArray,
    pub content: ByteArray,
}

// A trait for NewsArticle struct type
pub trait Summary {
    fn summarize(self: @NewsArticle) -> ByteArray;
}
```

وفقًا لتعريف سمة `Summary` أعلاه، فإن الطريقة `summarize` سلوك لا يمكن استدعاؤه إلا من بنية `NewsArticle`.
وإذا استُدعيت على نسخ من أنواع أخرى، فإنها تُطلق خطأ في التصريف.
وإعلان السمة بالكلمة المفتاحية `pub` يجعل السمة في هذه الحزمة مرئية لحزم أخرى تنوي استخدامها أيضًا.
لاحظ أيضًا أننا نستخدم فاصلة منقوطة بعد إعلان توقيعات الطرق في السمات.

ويمكن تعريف السمة بوسيط عام يتيح لدالة أن تستقبل وسيطًا من أي نوع بيانات.
وهذا يمنح توقيع الدالة مرونة تتيح له التعامل مع أنواع بيانات متنوعة.
وفي حالة سمة `Summary` أدناه، أُعيد تصميمها لتعمل مع أي نوع بيانات، بحيث عندما تُستدعى الطريقة `summarize` عليها، فإنها تُرجع `ByteArray`.

```rust
// A trait for a generic type
pub trait Summary<T> {
    fn summarize(self: @T) -> ByteArray;
}
```

ويمكن أن تحتوي السمة على أكثر من طريقة في جسمها؛ وكل توقيع طريقة مُعلَن يقع في سطر واحد ينتهي بفاصلة منقوطة.

## تنفيذ السمة على نوع

بعد تعريف توقيعات الدوال التي تشكّل السمة، يفرض المصرّف وجود تنفيذ معرَّف جيدًا للأنواع التي تتبنّى السمة.
كتبنا أدناه حزمة مكتبة إعلامية باسم `aggregator` تلخّص بعض البيانات من نسخ من `NewsArticle` و`Tweet`.
وبالنسبة لبنية `NewsArticle`، سنستخدم العنوان والكاتب والموقع لإرجاع قيمة الطريقة `summarize` من سمة `Summary`، بينما سنستخدم في بنية `Tweet` اسم المستخدم والمحتوى، بافتراض أن محتوى التغريدة محدود بـ 280 حرفًا.

```rust
mod aggregator {
    pub trait Summary<T> {
        fn summarize(self: @T) -> ByteArray;
    }

    #[derive(Drop)]
    pub struct NewsArticle {
        pub headline: ByteArray,
        pub location: ByteArray,
        pub author: ByteArray,
        pub content: ByteArray,
    }

    impl NewsArticleSummary of Summary<NewsArticle> {
        fn summarize(self: @NewsArticle) -> ByteArray {
            format!("{} by {} ({})", self.headline, self.author, self.location)
        }
    }

    #[derive(Drop)]
    pub struct Tweet {
        pub username: ByteArray,
        pub content: ByteArray,
        pub reply: bool,
        pub retweet: bool,
    }

    impl TweetSummary of Summary<Tweet> {
        fn summarize(self: @Tweet) -> ByteArray {
            format!("{}: {}", self.username, self.content)
        }
    }
}

use aggregator::{Summary, NewsArticle, Tweet};

fn main() {
    let news = NewsArticle {
        headline: "Cairo has become the most popular language for developers",
        location: "Worldwide",
        author: "Cairo Digger",
        content: "Cairo is a new programming language for zero-knowledge proofs",
    };

    let tweet = Tweet {
        username: "EliBenSasson",
        content: "Crypto is full of short-term maximizing projects. \n @Starknet and @StarkWareLtd are about long-term vision maximization.",
        reply: false,
        retweet: false
    };

    println!("New article available! {}", news.summarize());
    println!("New tweet! {}", tweet.summarize());
}
```

## التنفيذات الافتراضية

أحيانًا يمكن تعريف السمة بتنفيذ افتراضي لبعض الطرق التي تشكّلها أو لكلها.
وذلك لتجنّب اشتراط تنفيذ كل الطرق على كل نوع، ولتحسين قابلية قراءة الكود.
وإذا احتاج نوع معيّن إلى تنفيذ خاص لإحدى طرق السمة، فيمكنه تجاوز التنفيذ الافتراضي.

```rust
mod aggregator {
    pub trait Summary<T> {
        fn summarize(self: @T) -> ByteArray {
            "(Read more...)"
        }
    }

    #[derive(Drop)]
    pub struct NewsArticle {
        pub headline: ByteArray,
        pub location: ByteArray,
        pub author: ByteArray,
        pub content: ByteArray,
    }

    impl NewsArticleSummary of Summary<NewsArticle> {}

    #[derive(Drop)]
    pub struct Tweet {
        pub username: ByteArray,
        pub content: ByteArray,
        pub reply: bool,
        pub retweet: bool,
    }

    impl TweetSummary of Summary<Tweet> {
        fn summarize(self: @Tweet) -> ByteArray {
            format!("{}: {}", self.username, self.content)
        }
    }
}

use aggregator::{Summary, NewsArticle, Tweet};

fn main() {
    let news = NewsArticle {
        headline: "Cairo has become the most popular language for developers",
        location: "Worldwide",
        author: "Cairo Digger",
        content: "Cairo is a new programming language for zero-knowledge proofs",
    };

    println!("New article available! {}", news.summarize()); // prints "New article available! (Read more...)"


    let tweet = Tweet {
        username: "Alice",
        content: "Cairo is fun and engaging.",
        reply: true,
        retweet: true,
    };
    println!("New tweet from {}", tweet.summarize()); // prints "New tweet from Alice: Cairo is fun and engaging."
}
```

## استخدام السمات الخارجية وإدارتها

يمكن تعريف السمات والتنفيذات في وحدة خارجية واستخدامها في وحدات أخرى، ما دامت مستوردة بشكل صحيح.
لنفترض أن لدينا سمة `ShapeGeometry` ذات الطريقة `boundary` التي يجب تنفيذها لكل من بنيتي `Circle` و`Rectangle`.
وفيما يلي مثال على كيفية استيراد السمة والتنفيذ وإدارتهما واستخدامهما عبر الوحدات.

```rust
// Here T is an alias type which will be provided during implementation
pub trait ShapeGeometry<T> {
    fn boundary(self: T) -> u64;
    fn area(self: T) -> u64;
}

mod rectangle {
    // Importing ShapeGeometry is required to implement this trait for Rectangle
    use super::ShapeGeometry;

    #[derive(Copy, Drop)]
    pub struct Rectangle {
        pub height: u64,
        pub width: u64,
    }

    // Implementation RectangleGeometry passes in <Rectangle>
    // to implement the trait for that type
    impl RectangleGeometry of ShapeGeometry<Rectangle> {
        fn boundary(self: Rectangle) -> u64 {
            2 * (self.height + self.width)
        }
        fn area(self: Rectangle) -> u64 {
            self.height * self.width
        }
    }
}

mod circle {
    // Importing ShapeGeometry is required to implement this trait for Circle
    use super::ShapeGeometry;

    #[derive(Copy, Drop)]
    pub struct Circle {
        pub radius: u64
    }

    // Implementation CircleGeometry passes in <Circle>
    // to implement the imported trait for that type
    impl CircleGeometry of ShapeGeometry<Circle> {
        fn boundary(self: Circle) -> u64 {
            (2 * 314 * self.radius) / 100
        }
        fn area(self: Circle) -> u64 {
            (314 * self.radius * self.radius) / 100
        }
    }
}

use rectangle::Rectangle;
use circle::Circle;

fn main() {
    let rect = Rectangle { height: 5, width: 7 };
    println!("Rectangle area: {}", ShapeGeometry::area(rect)); //35
    println!("Rectangle boundary: {}", ShapeGeometry::boundary(rect)); //24

    let circ = Circle { radius: 5 };
    println!("Circle area: {}", ShapeGeometry::area(circ)); //78
    println!("Circle boundary: {}", ShapeGeometry::boundary(circ)); //31
}
```

ولا يلزم أن تكون رؤية التنفيذ لكل من `CircleGeometry` و`RectangleGeometry` عامة، لأن سمة `ShapeGeometry` جُعلت عامة وينبغي أن يجدها المصرّف بسهولة.

## الأسماء البديلة لـ `impl`

يمكن إعطاء التنفيذات اسمًا بديلًا عند استيرادها، باستخدام الكلمة المفتاحية `impl`.
ويساعد ذلك عند إنشاء نسخة من تنفيذ عام لأنواع محددة.
لنعرّف تنفيذًا بسيطًا لسمة `Two` لكل الأنواع التي تنفّذ سمة `One`، وذلك ببساطة بجمع قيمة `One` مرّتين وإرجاع حاصل الجمع.
ويمكننا بعد ذلك إتاحة تنفيذ `Two` الذي يعمل فقط مع نوعي `u8` و`u128`.

```rust
trait Two<T> {
    fn two() -> T;
}

mod one_based {
    pub impl TwoImpl<
        T, +Copy<T>, +Drop<T>, +Add<T>, impl One: core::num::traits::One<T>
    > of super::Two<T> {
        fn two() -> T {
            One::one() + One::one()
        }
    }
}

pub impl U8Two = one_based::TwoImpl<u8>;
pub impl U128Two = one_based::TwoImpl<u128>;
```

يمكن كتابة التنفيذ العام في وحدة خاصة، وباستخدام الاسم البديل لـ`impl` يمكننا إنشاء نسخة من التنفيذ العام لهذين النوعين المحددين.
وتكمن فائدة استخدام تنفيذ عام خاص وغير مُتاح في أنه يمنع تكرار الكود بين الملفات.
كما يحافظ هذا أيضًا على بساطة ووضوح واجهة API العامة.
