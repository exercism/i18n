# حول

أحيانًا عندما تأخذ دالة وسائط كثيرة، قد يصعب تذكّر الترتيب الذي ينبغي تقديمها به. ولتسهيل القراءة، تسمح Gleam بتسمية الوسائط باسم.

لتسمية وسيط، اكتب اسم التسمية قبل اسم الوسيط، مع الفصل بينهما بمسافة.

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

عند استدعاء دالة ذات وسائط مُسمّاة، يمكن تقديم الوسائط بأي ترتيب. وكل هذه الاستدعاءات إلى `replace` متكافئة:

```gleam
replace(in: "🍔🍔🍔" each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

التسميات اختيارية دائمًا. وحتى لو كانت للدالة وسائط مُسمّاة، فيمكن استدعاؤها دون تسميات.

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```

عند تعريف دالة ذات وسائط مُسمّاة، يجب أن تكون كل الوسائط التي تأتي بعد أول وسيط مُسمّى مُسمّاة أيضًا.

```gleam
// This function is valid
pub fn valid(
  x: Int,
  label1 y: Int,
  label2 z: Int
) -> Int {
  // ...
}

// This function is invalid
pub invalid(
  x: Int,
  label1 y: Int,
  z: Int
) -> Int {
  // ...
}
```
