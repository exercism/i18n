# مقدمة

يُعرّف JSON **المصفوفة** بأنها:

> المصفوفة مجموعة مرتّبة من القيم.
> تبدأ المصفوفة بقوس مربع أيسر `[` وتنتهي بقوس مربع أيمن `]`.
> وتُفصل القيم بفاصلة `,`.

يمكن أن تحتوي المصفوفات على صفر أو أكثر من _أي نوع_ من قيم JSON.
ولا يلزم أن تكون عناصر المصفوفة جميعها من النوع نفسه.

## إنشاء المصفوفات

استخدم الأقواس لتجميع العناصر في مصفوفة.

```jq
[1, 2, 3]
```

يمكن التقاط عناصر _تيار_ داخل مصفوفة بوضعه بين قوسين.

```jq
range(5)     # => a stream of 5 numbers
[range(5)]   # => the array [0, 1, 2, 3, 4]
```

## الحجم

تُرجع الدالة `length` عدد العناصر في المصفوفة.

## الفهرسة والتقطيع

تبدأ فهرسة المصفوفات من الصفر.

استرجع عنصرًا من مصفوفة بتعبير قوسي:
`.[2]` يجلب العنصر الثالث.

تعُدّ الفهارس السالبة من نهاية المصفوفة إلى الوراء:
`.[-1]` يجلب العنصر الأخير، و`.[-2]` يجلب العنصر قبل الأخير.

**المقطع** هو تسلسل فرعي من المصفوفة.
يُرجع `.[10:15]` خمسة عناصر بدءًا من الفهرس 10؛ وفهرس النهاية _غير مشمول_.

توجد بعض الدوال المساعدة:

- `first` لجلب العنصر الأول.
- `last` لجلب العنصر الأخير.
- `nth(n)` لجلب العنصر عند الفهرس `n`.

## التكرار

يوفّر `jq` دوال عديدة تغطي وظائف التكرار الشائعة:

- تُرجع `map(expr)` مصفوفة جديدة يُطبَّق فيها `expr` على كل عنصر بالترتيب.

  ```jq
  [1, 2, 3] | map(. * 10)    # => [10, 20, 30]

  ```

- `select(expr)` دالة تُطبّق `expr` على _قيمة واحدة_؛
  فإن كانت نتيجة التعبير صحيحة أُرجعت القيمة،
  وإن كانت النتيجة خاطئة لم يُرجَع _شيء_، لا `null`، بل لا شيء فعليًا.

  ولتطبيق ذلك على مصفوفة، اجمعه مع `map`.

  ```jq
  [range(10)] | map(select(. % 2 == 0))    # => [0, 2, 4, 6, 8]
  ```

  أو طبّق `select` على _تيار_ واجمع النتائج.

  ```jq
  [range(10) | select(. % 2 == 0)]    # => [0, 2, 4, 6, 8]
  ```

- تُرجع كلٌّ من `any(condition)` و`all(condition)` قيمة منطقية تشير إلى ما إذا كان أيٌّ من عناصر المصفوفة أو جميعها يستوفي الشرط.

  ```jq
  [1, 2, 3, 4] | any(. > 4)    # false
  [1, 2, 3, 4] | any(. >= 4)   # true

  [1, 2, 3, 4] | all(. >= 4)   # false
  [1, 2, 3, 4] | all(. <= 4)   # true
  ```
