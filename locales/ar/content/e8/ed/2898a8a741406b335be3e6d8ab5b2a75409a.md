# مقدمة

تختار الجمل الشرطية في Factor بين **الاقتباسات**، وهي مقتطفات من الكود تُكتب بين أقواس مربعة، `[ ... ]`. إن كتابة `[ ... ]` تدفع الكود إلى المكدس كقيمة بدلًا من تشغيله، ثم تقرر الجملة الشرطية أي اقتباس تشغّله. (سنتناول الاقتباسات بالكامل في تمرين لاحق.)

الجملة الشرطية الأساسية في Factor هي `if` (في [`kernel`][kernel]). وهي تأخذ قيمة منطقية واقتباسين، فتشغّل الأول إذا كانت القيمة المنطقية صحيحة، والثاني إذا لم تكن كذلك.

```
if ( ? then-quot else-quot -- )
```

```factor
: abs ( x -- y ) dup 0 < [ neg ] [ ] if ;
```

لا يُشغّل `when` اقتباسه إلا عندما تكون القيمة المنطقية صحيحة، ولا يُشغّل `unless` اقتباسه إلا عندما تكون غير صحيحة. وللفرع في أكثر من اتجاه، هناك `cond` (في [`combinators`][combinators]):

```factor
USING: combinators ;

: classify ( n -- s )
    {
        { [ dup 0 <  ] [ drop "negative" ] }
        { [ dup 0 =  ] [ drop "zero"     ] }
        [ drop "positive" ]
    } cond ;
```
