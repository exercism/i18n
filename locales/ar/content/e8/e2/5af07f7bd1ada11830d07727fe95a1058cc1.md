# التعليمات

في هذا التمرين عليك تنفيذ بعض الدوال للتعامل مع قائمة من لغات البرمجة.

## 1. عرّف دالة تُرجع قائمة لغات فارغة

عرّف الدالة `new/0` التي لا تأخذ أي وسائط وتُرجع قائمة فارغة.

```elixir
LanguageList.new()
# => []
```

## 2. عرّف دالة تضيف لغة إلى القائمة

عرّف الدالة `add/2` التي تأخذ وسيطين (‏_قائمة لغات_ وسلسلة نصية حرفية تمثل _لغة_). يجب أن تُرجع القائمة الناتجة مع إضافة اللغة الجديدة إلى مقدمة القائمة المعطاة.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Clojure")
# => ["Clojure"]
language_list = LanguageList.add(language_list, "Haskell")
# => ["Haskell", "Clojure"]
```

## 3. عرّف دالة تحذف لغة من القائمة

عرّف الدالة `remove/1` التي تأخذ وسيطًا واحدًا (‏_قائمة لغات_). يجب أن تُرجع القائمة دون العنصر الأول. افترض أن القائمة تحتوي دائمًا على عنصر واحد على الأقل.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Clojure")
# => ["Clojure"]
language_list = LanguageList.add(language_list, "Haskell")
# => ["Haskell", "Clojure"]
language_list = LanguageList.remove(language_list)
# => ["Clojure"]
```

## 4. عرّف دالة تُرجع العنصر الأول في القائمة

عرّف الدالة `first/1` التي تأخذ وسيطًا واحدًا (‏_قائمة لغات_). يجب أن تُرجع أول لغة في القائمة. افترض أن القائمة تحتوي دائمًا على عنصر واحد على الأقل.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elm")
# => ["Elm"]
language_list = LanguageList.add(language_list, "Prolog")
# => ["Prolog", "Elm"]
LanguageList.first(language_list)
# => "Prolog"
```

## 5. عرّف دالة تُرجع عدد اللغات في القائمة

عرّف الدالة `count/1` التي تأخذ وسيطًا واحدًا (‏_قائمة لغات_). يجب أن تُرجع عدد اللغات في القائمة.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elm")
# => ["Elm"]
language_list = LanguageList.add(language_list, "Prolog")
# => ["Prolog", "Elm"]
LanguageList.count(language_list)
# => 2
```

## 6. عرّف دالة تحدد ما إذا كانت القائمة تتضمن لغة دالية

عرّف الدالة `functional_list?/1` التي تأخذ وسيطًا واحدًا (‏_قائمة لغات_). يجب أن تُرجع قيمة منطقية. يجب أن تُرجع صحيحًا إذا كانت _"Elixir"_ إحدى اللغات في القائمة.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elixir")
# => ["Elixir"]
LanguageList.functional_list?(language_list)
# => true
```
