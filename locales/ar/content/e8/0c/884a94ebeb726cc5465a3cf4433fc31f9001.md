# مقدمة

## الجمل الشرطية `if`

### العوامل المنطقية

تدعم Java ثلاثة عوامل منطقية: `&&` (AND)، و`||` (OR)، و`!` (NOT).

### جملة `if` الشرطية

النوع الأساسي لأي عملية شرطية هو النوع `boolean`، ويمكن أن تكون قيمته `true` أو `false`. تُستخدم الجمل الشرطية غالبًا كآليات للتحكم في مسار التنفيذ للتحقق من شروط مختلفة. وللتحقق من حالة معينة يمكن استخدام جملة شرطية `if`، وهي تنفّذ الكود الخاص بها إذا كان الشرط الأساسي `true`، كما يلي:

```java
int val;

if(val == 9) {
    // conditional code
}
```

في الحالات التي تتضمن أكثر من حالة، يمكن ربط عدة جمل شرطية `if` معًا باستخدام `else if` و`else`.

```java
if(val == 10) {
    // conditional code
} else if(val == 17) {
    // conditional code
} else {
    // executes when val is different from 10 and 17
}
```

### جملة `switch`

توفر Java أيضًا جملة `switch` للحالات التي تحتوي على خيارات متعددة.

```java
int val;

// switch statement on variable content
switch(val) {
    case 1:
        // conditional code
        break;
    case 2: case 3: case 4:
        // conditional code
        break;
    default:
        // if all cases fail
        break;
}
```
