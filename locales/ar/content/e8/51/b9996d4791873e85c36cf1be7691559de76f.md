# الباقي

في الرياضيات، **الباقي** هو المقدار "المتبقي" بعد إجراء عملية حسابية ما.
على سبيل المثال، الباقي من `5 / 3` هو `2`.

تستخدم العديد من لغات البرمجة علامة النسبة المئوية (`%`) كعامل لحساب الباقي.
على سبيل المثال:
```javascript
5 % 3 == 2
```

يمكن غالبًا حساب الباقي لكل من الأعداد الصحيحة والأعداد ذات الفاصلة العائمة.
على سبيل المثال،
```javascript
5.3 % 3 == 2.3
```

عند التعامل مع الأعداد السالبة، تكون النتيجة دائمًا لها الإشارة نفسها التي للمقسوم (العدد الموجود على الجانب الأيسر والذي تتم قسمته).
على سبيل المثال:
```javascript
-5 % 3 == -2
5 % -3 == 2
-5 % -3 == -2
```

تستخدم بعض اللغات (مثل Python) العامل `%` لحساب المقياس، وليس الباقي.
وهذا يعامل الأعداد السالبة بشكل مختلف.
يمكنك معرفة المزيد حول هذا [على ويكيبيديا](https://en.wikipedia.org/wiki/Modulo).
