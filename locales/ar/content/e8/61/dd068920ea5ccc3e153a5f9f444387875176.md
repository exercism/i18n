# نبذة

حلقة [`while`][while-loops] هي عبارة للتحكم في مسار التنفيذ تسمح بتنفيذ الكود ما دام شرط معيّن صحيحًا.
توفّر Swift نوعين من حلقات `while`: حلقات `while` وحلقات `repeat-while`.
يُقيَّم شرط حلقة `while` قبل تنفيذ جسم الحلقة؛ فإذا كان الشرط خطأ، لن يُنفَّذ جسم الحلقة على الإطلاق.
تأخذ حلقات `while` في Swift البنية التالية:

```swift
while <#condition#> {
  <#code#>
}
```

هنا ستُنفَّذ الحلقة ما دام `count` أكبر من 0، وستطبع بذلك العددين 2 و1 و"Liftoff!".

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

حلقة [`repeat-while`][while-loops] تشبه حلقة `while`، لكن الشرط يُقيَّم بعد تنفيذ جسم الحلقة.
وهذا يعني أن جسم الحلقة سيُنفَّذ دائمًا مرة واحدة على الأقل، حتى لو كان الشرط خطأ.
تأخذ حلقات `repeat-while` في Swift البنية التالية:

```swift
repeat {
  <#code#>
} while <#condition#>
```

هنا ستُنفَّذ الحلقة مرة واحدة فقط، لأن الشرط خطأ.
ولأنها حلقة `repeat-while`، سيُنفَّذ جسم الحلقة مرة واحدة قبل تقييم الشرط.

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```

## حلقات الربط الاختياري

من الصور الشائعة لحلقات `while` في Swift حلقة `while` ذات الربط الاختياري.
تتكرر هذه الحلقات ما دام استدعاء دالة تُرجع قيمة اختيارية يعطي قيمة غير `nil`.
ثم تُربَط تلك القيمة (غير الاختيارية) باسم تختاره، ويمكن استخدامها في جسم الحلقة.

```swift
var arr = [1,2]
while let count = arr.popLast() {
  print("\(count)…")
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```
