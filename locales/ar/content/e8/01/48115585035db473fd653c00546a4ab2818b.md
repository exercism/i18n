# حول

تُمثَّل القيم المنطقية في Rust بالنوع `bool`، الذي تكون قيمه إما `true` أو `false`.

تدعم Rust [عامل نفي منطقي][negation operators] واحدًا: `!` (النفي).

تدعم Rust ستة [عوامل مقارنة][comparison operators]: `==` (يساوي)، `!=` (لا يساوي)، `>` (أكبر من)، `<` (أصغر من)، `>=` (أكبر من أو يساوي)، `<=` (أصغر من أو يساوي). ويمكن استخدامها لتقييم العلاقة بين قيم غير منطقية وتحويلها إلى قيمة منطقية.

```rust
1 > 0 // true
1 < 0 // false
1 == 0 // false
1 != 0 // true
1 >= 0 // true
1 <= 0 // false
```

على خلاف بعض اللغات الأخرى، ليست `0` هي `false`، وليس العدد غير الصفري هو `true`.

تدعم Rust ثلاثة [عوامل ثنائية منطقية][logical binary operators]: `&` (و المنطقية)، `|` (أو المنطقية)، `^` (أو الحصرية المنطقية).

تدعم Rust [عاملي قيمة منطقية][lazy boolean operators] اثنين: `||` (أو)، `&&` (و). وهما يختلفان عن `|` و `&` في أن الطرف الأيمن لا يُقيَّم إلا عندما لا يكون الطرف الأيسر قد حدد نتيجة التعبير بالفعل. أي أن `||` لا يقيّم طرفه الأيمن إلا عندما يُقيَّم الطرف الأيسر إلى `false`، و`&&` لا يفعل ذلك إلا عندما يُقيَّم الطرف الأيسر إلى `true`.

```rust
true || false // == true; the right-hand side was not evaluated
true && false // == false
```
