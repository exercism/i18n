# مقدمة

أحيانًا يحتاج جزء من الحالة إلى أن يكون مشتركًا بين عدة كلمات
دون تمريره عبر آثار المكدس الخاصة بها في كل مرة. *المتغيرات
الديناميكية* في Factor، المُعلنة باستخدام `SYMBOL:`، تمنح
كل كلمة إمكانية الوصول إلى قيمة مخزنة في مساحة أسماء.

## `SYMBOL:` و`SYMBOLS:`

`SYMBOL: name` تُعلن متغيرًا واحدًا. و`SYMBOLS: a b c ;`
تُعلن عدة متغيرات دفعة واحدة:

```factor
USING: namespaces ;

SYMBOLS: counter total ;
```

## الضبط والقراءة

`set-global` و`get-global` (في [`namespaces`][namespaces])
تعملان على مساحة الأسماء العامة:

```
set-global    ( value variable -- )
get-global    ( variable -- value )
change-global ( variable quot: ( old -- new ) -- )
```

```factor
0 counter set-global
counter get-global .         ! => 0
counter [ 10 + ] change-global
counter get-global .         ! => 10
```

بالنسبة للحالة على مستوى الوحدة، فإن صيغ `-global` هي ما تريده.

## ارتباطات نطاقية باستخدام `with-variable`

يدعم المتغير الدينامي أيضًا صيغة ثانية *نطاقية*. `set` /
`get` / `change` (بدون لاحقة `-global`) تقرأ وتكتب في النطاق
الدينامي *الحالي*، و`with-variable` (في [`namespaces`][namespaces])
تُنشئ نطاقًا جديدًا طوال مدة تنفيذ اقتباس:

```
with-variable ( value variable quot -- )
set           ( value variable -- )
get           ( variable -- value )
change        ( variable quot: ( old -- new ) -- )
```

يُربط المتغير بـ`value` أثناء تشغيل `quot`؛ وبمجرد انتهائه،
يختفي الارتباط. يتيح هذا للمستدعي الخارجي "حقن" قيمة يمكن
للكود الداخلي قراءتها دون تمريرها عبر كل توقيع مكدس.

```factor
SYMBOL: greeting

"Hello" greeting [
    greeting get .                ! => "Hello"
    "Howdy" greeting set
    greeting get .                ! => "Howdy"
    greeting [ "!" append ] change
    greeting get .                ! => "Howdy!"
] with-variable

greeting get-global .    ! => f   (the scoped binding is gone)
```

يستخدم هذا التمرين الصيغة العامة في كل مكان، لكن إدراك
عائلة `set`/`get`/`change` المتوازية مفيد عندما تقرأ كود
الآخرين.

## المتجهات القابلة للتغيير

لأن المتغيرات الديناميكية تحمل مرجعًا، يمكنك الاحتفاظ بمجموعة
*قابلة للتغيير* داخل أحدها وتحديثها في مكانها:

```factor
SYMBOL: history

V{ } clone history set-global
"first event" history get-global push
"second event" history get-global push
history get-global .
! => V{ "first event" "second event" }
```

`V{ … }` هو متجه حرفي. استخدم `clone` دائمًا على `V{ }` الحرفي
قبل تخزينه: فالقيم الحرفية مشتركة بين الاستدعاءات.

## `find`: أول تطابق

`find` (في [`sequences`][sequences]) تُرجع أول عنصر يكون
محموله صحيحًا، بالإضافة إلى فهرسه:

```
find ( seq quot -- index elt/f )
```

إذا لم يطابق شيء، فكلتا القيمتين `f`. إسقاط الفهرس باستخدام
`nip` واستخدام `unless*` هو المزيج القياسي "الافتراضي عند
الغياب".

## `reject`: إسقاط المطابقات

`reject` (أيضًا في [`sequences`][sequences]) هي عكس `filter`:
تُرجع العناصر التي *تفشل* في اختبار المحمول.
