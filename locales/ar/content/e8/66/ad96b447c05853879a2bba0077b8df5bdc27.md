# مقدمة

## Try/Rescue/Else/After

استخدام `try..rescue` تركيب قوي لالتقاط الأخطاء عند حدوثها. والتقاط الأخطاء يسمح للدوال بإرجاع قيم محددة عند الحاجة. كما يقدّم لنا تركيب `try..rescue` ميزتين إضافيتين يمكننا الاستفادة منهما:

- كتلة `else`
  - عندما تنجح كتلة `try`، تُطابَق النتيجة مع هذه الكتلة.
- كتلة `after`
  - سواء نجحت كتلة `try` أو رفعت استثناءً، فإن الكود الموجود في كتلة `after` يُنفَّذ دائمًا ما دام البرنامج قيد التشغيل عند هذه النقطة.
  - لا تُرجَع نتيجة كتلة `after` إلى النطاق المستدعي.

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```

## الإرسال الديناميكي

عندما يحلّ Elixir الدالة المطلوب استدعاؤها، فإنه يستخدم اسم الوحدة لإجراء البحث. ويمكن إجراء هذا البحث ديناميكيًا إذا كان اسم الوحدة مرتبطًا بمتغير.

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```

داخليًا، اسم الوحدة هو ذرّة. وجميع ذرّات الوحدات في Elixir تُسبق تلقائيًا بـ `Elixir.`

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```
