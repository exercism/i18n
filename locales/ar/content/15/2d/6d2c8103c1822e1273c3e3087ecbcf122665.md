# تطبيع الـ representer

يطبّق [representer الخاص بـ JavaScript][github-javascript-representer] التطبيعات التالية:

## إزالة التعليقات

تُزال جميع التعليقات.
الأمثلة التالية متكافئة:

### مثال مع التعليقات

```javascript
/**
 * Returns the string literal 'hi there' just to say hello
 * @return [String]
 */
function hello(/* nothing*/) {
  // just return it
  return 'hi there';
}
```

### مثال بدون تعليقات

```javascript
function hello() {
  return 'hi there';
}
```

## تطبيع المسافات البيضاء

عند تمثيل الكود، يكون _الترتيب_ مهمًا، أما موضعه الفعلي فليس كذلك.
وهذا يعني أن المسافات البيضاء تخضع للتطبيع.
الأمثلة التالية متكافئة:

### مثال بمسافة بادئة من مسافتين

```javascript
function hello() {
  return 'hello world';
}
```

### مثال بمسافة بادئة من أربع مسافات

```javascript
function hello() {
  return 'hello world';
}
```

### مثال بمسافة بادئة مثيرة للاهتمام

```javascript
function hello() {
  return 'hello world';
}
```

## تطبيع المعرِّفات

تُطبَّع المعرِّفات إلى قيمة نائبة.

### قبل

```javascript
const MY_CONSTANT = 42;

function answer(multiplier, addition = 1) {
  return MY_CONSTANT * multiplier + addition;
}
```

### بعد

```javascript
const PLACEHOLDER_1 = 42;

function PLACEHOLDER_2(PLACEHOLDER_3, PLACEHOLDER_4 = 1) {
  return PLACEHOLDER_1 * PLACEHOLDER_3 + PLACEHOLDER_4;
}
```
