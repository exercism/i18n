# مقدمة

يوفّر Python ثلاثة أنواع مختلفة من الأعداد المدمجة: الأعداد الصحيحة ([`int`][int])، وأعداد الفاصلة العائمة ([`float`][float])، والأعداد المركبة ([`complex`][complex]).
كما يمكن استيراد الكسور ([`fractions.Fraction`][fractions]) والأعداد العشرية ([`decimal.Decimal`][decimals]) من المكتبة القياسية.

الأعداد الصحيحة، بما فيها الأعداد السادس عشرية ([_`hex()`_][hex]) والثمانية ([_`oct()`_][oct]) والثنائية ([_`bin()`_][bin])، **بدون** منازل عشرية، تُصنَّف أيضًا على أنها `ints`:

```python
# Ints are whole numbers.
>>> 1234
1234
>>> type(1234)
<class 'int'>

>>> -12
-12
```

الأعداد التي تحتوي على فاصلة عشرية (سواء كان لها أجزاء كسرية أو لا) تُصنَّف على أنها `floats`:

```python
>>> 3.45
3.45
>>> type(3.45)
<class 'float'>
```

## العمليات الحسابية

يدعم Python العمليات الحسابية بالكامل بين أنواع الأعداد المختلفة هذه، ويحوّل الأعداد الأضيق لتوافق نظيراتها الأوسع عند استخدامها مع عوامل الحساب الثنائية (`+` و`-` و`*` و`/` و`//` و`%`).

### الجمع والطرح

يتصرّف عاملا الجمع والطرح كما في الرياضيات العادية.
وإذا كان أحد طرفَي العملية، أو أكثر، من نوع `float`، فسيُحوَّل ما تبقّى من `int` إلى `float` أيضًا:

```python
>>> 5 - 3
2
# The int is widened to a float here, and a float is returned.
>>> 3 + 4.0
7.0
```

### الضرب

وكما في الجمع والطرح، يحوّل الضرب الأعداد الأضيق لتوافق نظيراتها الأوسع:

```python
>>> 3 * 2
6

>>> 3 * 2.0
6.0
```

### القسمة

تُرجع القسمة دائمًا `float`، حتى لو كانت النتيجة عددًا صحيحًا:

```python
>>> 6/5
1.2

>>> 6/2
3.0
```

### القسمة الصحيحة

إذا احتجت إلى نتيجة من نوع `int`، يمكنك استخدام القسمة الصحيحة لاقتطاع النتيجة.
وتُنفَّذ القسمة الصحيحة باستخدام عامل `//`:

```python
>>> 6//5
1

>>> 6//2
3
```

### باقي القسمة

يُرجع عامل باقي القسمة (`%`) باقي قسمة طرفَي العملية:

```python
# The result of % is zero here, because dividing 8 by 2 leaves no remainder
>>> 8 % 2
0

# The result of % is 2 here, because 3 only goes into 5 once, with 2 leftover
>>> 5 % 3
2
```

وإليك أسلوبًا آخر للنظر إلى 5 % 3:

```python
>>> whole_part = int(5/3)
1

>>> decimal_part = 5/3 - whole_part
0.6666666666666667

>>> whole_remainder = decimal_part * 3
2.0
```

## التقريب

يوفّر Python دالة مدمجة هي [`round(number, <decimal_places>)`][round] لتقريب عدد ذي فاصلة عائمة إلى عدد معيّن من المنازل العشرية.
وإذا لم يُحدَّد عدد المنازل العشرية، يُقرَّب العدد إلى أقرب عدد صحيح، وستُرجع الدالة `int`:

```python
>>> round(3.1415926535, 2)
3.14

>>> round(3.1415926535)
3
```

## الأولوية والأقواس الهلالية

يتيح لك Python استخدام الأقواس الهلالية لتجميع التعبيرات.
وهذا مفيد عندما تريد تجاوز الترتيب الافتراضي للعمليات.

```python
>>> 2 + 3 * 4
14

>>> (2 + 3) * 4
20
```

يتبع Python قاعدة [PEMDAS][pemdas] لأسبقية العوامل.
وهذا يعني أن العمليات الحسابية داخل `()` لها الأولوية الأعلى، ثم يأتي `**`، ثم `*` و`/` و`//` و`%` و`+` و`-`:

```python
>>> 2 + 3 - 4 * 4
-11

>>> (2 + 3 - 4) * 4
4

# In the following example, the `**` operator has the highest priority, then `*`, then `+`
# Meaning we first do 4 ** 4, then 3 * 64, then 2 + 192
>>> 2 + 3 * 4 ** 4
770
```

## الدقة والتمثيل

تتمتّع الأعداد الصحيحة في Python بـ[دقة غير محدودة][arbitrary-precision]، فلا يحدّ عددَ منازلها سوى الذاكرة المتاحة في النظام المضيف.

عادةً ما تُنفَّذ أعداد الفاصلة العائمة باستخدام النوع `double` في لغة C (_بدقة 15 منزلة عشرية_)، لكن تمثيلها يختلف بحسب النظام المضيف.
وللأعداد المركبة جزء `real` وجزء `imaginary`، وكلاهما يُمثَّل بأعداد الفاصلة العائمة.

لمناقشة أكثر تفصيلًا للمشكلات والقيود التي يعاني منها حساب الفاصلة العائمة في مختلف لغات البرمجة، ألقِ نظرة على [0.30000000000000004.com][0.30000000000000004.com] و[الدرس التعليمي لـ Python][floating point math].
