# مقدمة

تتيح لنا وحدة [`fractions`][fractions] إنشاء [الأعداد النسبية][rational] والتعامل معها: كسور بسطها عدد صحيح ومقامها عدد صحيح.
على سبيل المثال، يمكننا تخزين `2/3` في صورة كسر دقيق بدلًا من القيمة التقريبية `0.6666...` من النوع `float`.

وعلى خلاف الأعداد من نوع `int` و`float` و`complex`، ليس للكسور صيغة حرفية.
لكن دالة إنشاء الكسور مرنة للغاية.

والأكثر وضوحًا أنها يمكن أن تستقبل عددين صحيحين كوسيطين.
تُحذف العوامل المشتركة تلقائيًا، فيُختصر الكسر إلى «أبسط صورة» (_أصغر عددين صحيحين يمثلان الكسر بدقة_):

```python
>>> from fractions import Fraction

>>> f1 = Fraction(2, 3) # 2/3
>>> f1
Fraction(2, 3)

>>> f2 = Fraction(6, 9)
>>> f2
Fraction(2, 3)  # automatically simplified

>>> f1 == f2
True
```

كما يمكن لدالة إنشاء الكسور تحليل تمثيل نصي:

```python
>>> f3 = Fraction('2/3')
>>> f3
Fraction(2, 3)
```

ويمكن للكسور أيضًا العمل مع معاملات من نوع `float`، لكن هذا قد يصطدم بمشكلات ناتجة عن الطبيعة التقريبية لتمثيل القيمة العشرية داخليًا بصيغة ثنائية.
لمزيد من التفاصيل حول مسألة التمثيل هذه، راجع موقع [0.30000000000000004][0.30000000000000004]، و[حساب الفاصلة العائمة: المشكلات والقيود ][fp-issues] في وثائق Python.

للحصول على نتيجة أكثر موثوقية عند استخدام أعداد `float` مع الكسور، هناك طريقة `<fraction>.limit_denominator()`.


## العمليات الحسابية على الكسور

ستعمل [`arithmetic operators`][operators] المعتادة `+ - * / **` مع الكسور، كما هو الحال مع الأنواع العددية الأخرى.

ويمكن إدخال أعداد صحيحة وكسور `Fraction` أخرى في المعادلة لتُعطي ناتجًا من نوع `Fraction`.
أما إدخال عدد `float` في التعبير فيعطي ناتجًا من نوع `float`، مع فقدان (محتمل) في الدقة تبعًا لذلك:

```python
>>> Fraction(2, 3) + Fraction(1, 4) # addition
Fraction(11, 12)

>>> Fraction(2, 3) * Fraction(6, 5) # multiply fractions
Fraction(4, 5)

>>> Fraction(2, 3) * 6 / 5 # fraction with integers
Fraction(4, 5)

>>> Fraction(2, 3) * 1.2  # fraction with float -> float
0.7999999999999999

>>> Fraction(2, 3) ** 2  # exponentiation with integer
Fraction(4, 9)
```

كذلك تُعطي كثير من دوال Python العددية القياسية النتيجة التي قد تتوقعها عند التعامل مع النوعين `int` و`rational numbers`:

```python
>>> round(Fraction(11, 3))
4

>>> from math import floor, ceil
>>> floor(Fraction(11, 3))
3
>>> ceil(Fraction(11, 3))
4

>>> float(Fraction(11, 3))
3.6666666666666665
```
