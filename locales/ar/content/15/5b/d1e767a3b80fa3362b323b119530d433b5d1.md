# مقدمة

تذكّر من مفهوم الأساسيات أن برنامج AWK يتكوّن من **أزواج النمط والإجراء**.

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

## ما الذي نعنيه بـ"النمط"؟

"النمط" هو أي تعبير في AWK.
وقيمة صحة نتيجة التعبير هي التي تحدّد ما إذا كان الإجراء سيُنفَّذ.

## النمط الفارغ

يمكن حذف النمط.
وفي هذه الحالة يُنفَّذ الإجراء على كل سجل.

يمكننا طباعة جميع أسماء المستخدمين في ملف passwd.

```sh
awk -F: '{print $1}' /etc/passwd
```

## التعبيرات النمطية

يستطيع AWK مقارنة السلاسل النصية بالتعبيرات النمطية للحصول على قيمة منطقية.

استخدم عامل مطابقة التعبير النمطي `~` لمطابقة حقل معيّن.
يأخذ هذا العامل سلسلة نصية في الطرف الأيسر وتعبيرًا نمطيًا في الطرف الأيمن.
ويوضع التعبير النمطي الحرفي بين خطين مائلين `/`.

لإيجاد المستخدمين في ملف passwd الذين يسجّلون الدخول باستخدام bash:

```sh
awk -F: '$7 ~ /bash/ {print $1}' /etc/passwd
```

العامل `!~` هو عامل "عدم مطابقة التعبير النمطي".

ولمطابقة تعبير نمطي مع السجل الحالي، يمكنك كتابة `$0 ~ /regex/`.
هذا شائع لدرجة أن هناك صيغة مختصرة: يمكنك حذف `$0` و `~` وكتابة `/regex/` فقط

```sh
awk '/regex/' data.txt
```

قارن أمر AWK المكوّن من سطر واحد بأمر grep المكافئ له

```sh
grep 'regex' data.txt
```

~~~~

سنتعمّق أكثر في صيغة التعبيرات النمطية في GNU AWK ضمن مفهوم لاحق.

## التعبيرات

يمكن استخدام تعبيرات AWK (الحسابية أو المنطقية أو غيرها) كأنماط.

لاستخراج كل المستخدمين الذين يساوي معرّفهم UID الرقم 1000 أو يزيد عليه:

```sh
awk -F: '$3 >= 1000' /etc/passwd
```

تذكّر أن القيم الزائفة في AWK هي العدد صفر والسلسلة النصية الفارغة، وأن كل الأعداد أو السلاسل النصية الأخرى صحيحة.
وأي تعبير يُقيَّم إلى عدد أو سلسلة نصية يمكن استخدامه كنمط.

## الدوال

يمكن استخدام أي دالة [مدمجة][builtins] أو [معرّفة من المستخدم][user-defined] في تعبير، ومن ثم في النمط.
ومثالان على ذلك:

```awk
length($1) {print "first field is not empty"}
```
```awk
toupper(substr($1, 1, 1)) ~ /[AEIOU]/ {print "starts with a vowel"}
```

## الأنماط الثابتة

من التعابير الشائعة في AWK:

```sh
{
    xyz()   # some code that transforms each record
}
1
```

النمط `1` نمط صحيح القيمة وليس له إجراء مرتبط به.
وهذا يعني "طباعة السجل الحالي".
