# نبذة

[`Array`][array] في Elm مجموعة سريعة غير قابلة للتغيير، تضم صفرًا أو أكثر من القيم من النوع نفسه.
ولأن المصفوفات غير قابلة للتغيير، فبمجرد إنشاء مصفوفة لا يمكن تغيير قيمتها أبدًا.
لا توجد صيغة حرفية لكتابة المصفوفات (على عكس `List`)، ولهذا تُستخدم بدلًا منها صيغة `Array.fromList`.
على سبيل المثال، تُعرض المصفوفة `Array` التي تحتوي على "a" و"b" و"c" عادةً بالشكل `Array.fromList ["a", "b", "c"]`.
سترى ذلك في مخرجات وحدة التحكم، وفي أداة تصحيح الأخطاء، وفي أماكن أخرى مشابهة.

وعلى خلاف `List` الذي يُعد [استيرادًا افتراضيًا][default-imports]، يجب استيراد وحدة `Array` صراحةً، باستخدام `import Array` أو ما شابه ذلك.

يمكن تعريف تعليقات النوع للمصفوفات كما يلي

```elm
Array String --> an array of String
Array Int --> an array of Int
```

يمكن تعريف المصفوفات كما يلي:

```elm
import Array exposing (Array)

empty : Array Char
empty = Array.empty

singleValue = Array.fromList [ 5 ] --> Array Int

repeatSingleValue = Array.repeat 2 5 --> Array.fromList [ 5, 5 ]

initialiseFromIndex = Array.initialise 3 (\index -> index * 2) --> Array.fromList [ 0, 2, 4 ]

initialisefromList = Array.fromList [ "a", "b", "c" ] --> Array.fromList [ "a", "b", "c" ]
```

تُضاف العناصر إلى المصفوفة باستخدام `Array.push`:

```elm
twoToFour = Array.fromList [ 2, 3, 4 ]
oneToFour = Array.push 1 twoToFour --> Array.fromList [ 1, 2, 3, 4 ]
```

وتُلحق المصفوفات باستخدام `Array.append`:

```elm
sixSeven = Array.fromList [ 6, 7 ]
eightNine = Array.fromList [ 8, 9 ]
Array.append sixSeven eightNine --> Array.fromList [ 6, 7, 8, 9 ]
```

ويُسترجَع عنصر من المصفوفة باستخدام `Array.get`:

```elm
sixSeven = Array.fromList [ 6, 7 ]
Array.get 0 sixSeven --> Just 6
```

ويُضبط عنصر في المصفوفة باستخدام `Array.set`:

```elm
sixSeven = Array.fromList [ 6, 7 ]
Array.set 1 8 sixSeven --> Array.fromList [ 6, 8 ]
```

وتُعالَج المصفوفات بالدوال المعرّفة في [وحدة `Array`][array-module].

```elm
oneTwo = Array.fromList [ 1, 2 ]
Array.length oneTwo --> 2
```

أي دالة أو عامل يبدو أنه يعدّل `Array` (مثل إضافة عنصر) سيُرجع في الواقع `Array` جديدة.
ومع ذلك، لا يمثّل الأداء مشكلة عادةً، لأن تنفيذ `Array` يمنع عمليات التخصيص والنسخ غير الضرورية.
