# مقدمة

تناول مفهوم Pairs and Dicts أساسيات نوع القواميس في Julia.

ولأن كائنات `Dict` نوع مهم وكثير الاستخدام من أنواع المجموعات، فإن هناك أيضًا دوال كثيرة للتعامل معها.

## استرجاع المدخلات

أبسط طريقة لاسترجاع مدخل هي استخدام مفتاحه (كما في كثير من اللغات).
لكن طلب مفتاح غير موجود يؤدي إلى `KeyError`.

```julia-repl
julia> d = Dict(i => ('a':'c')[i] for i in 1:3)
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'
julia> d[2]
'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
# missing key
julia> d[4]
ERROR: KeyError: key 4 not found
```

يمكننا التحقق من وجود المفتاح قبل محاولة استرجاعه (باستخدام شيء مثل `haskey(d, 4)`)، لكن قد يكون من المفيد الحصول مباشرة على قيمة افتراضية للمفاتيح غير الموجودة.

لهذا الغرض، لدينا الدالة `get()` وصيغتها المعدِّلة `get!()`.
ويختلفان في ما إذا كان المفتاح «غير الموجود» يُضاف إلى `Dict` أم لا.

```julia-repl
julia> get(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
# get() leaves Dict unchanged
julia> d
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'
julia> get!(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
# get!() adds new key to Dict
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'
```

رأينا في المفهوم السابق أن `delete!()` تحذف مدخلًا حسب مفتاحه.
ويمكن الجمع بين ذلك واسترجاع القيمة باستخدام الدالة `pop!()`.

```julia-repl
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'
# popped value is returned
julia> pop!(d, 3)
'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)
# Dict is shrunk
julia> d
Dict{Int64, Char} with 3 entries:
  4 => '!'
  2 => 'b'
  1 => 'a'
```

## التكرار

عند التكرار على `Dict`، يكون السلوك الافتراضي هو إعطاء أزواج `key => value`.
ويمكن الوصول إلى مكوّني كل زوج بالتسمية المعتادة `.first` و `.second`.

```julia-repl
# d is from the previous example
julia> [(kv.first, kv.second) for kv in d]
3-element Vector{Tuple{Int64, Char}}:
 (4, '!')
 (2, 'b')
 (1, 'a')
```

وغالبًا ما نريد استخدام المفاتيح فقط أو القيم فقط، وهذا أمر سهل.

```juliajulia> [k for k in keys(d)]
julia> [k for k in keys(d)]
3-element Vector{Int64}:
 4
 2
 1
julia> [v for v in values(d)]
3-element Vector{Char}:
 '!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
```

## الدمج

قد يكون دمج كائنين من `Dict` مفيدًا، لكن يجب أن نكون واضحين بشأن ما ننوي فعله بالمفاتيح الموجودة في أكثر من مُدخل واحد.

تدمج الدالتان `merge()` و `merge!()` أي عدد من كائنات `Dict` المُمرَّرة من اليسار إلى اليمين.

تُستبدل قيم المفاتيح الموجودة ببساطة، لذا فإن `Dict` الأقرب إلى اليمين هو الذي «يفوز».

```julia-repl
julia> d3 = Dict("color" => "red", "shape" => "circle")
Dict{String, String} with 2 entries:
  "shape" => "circle"
  "color" => "red"
julia> d4 = Dict("color" => "blue", "coords" => (3, 2))
Dict{String, Any} with 2 entries:
  "color"  => "blue"
  "coords" => (3, 2)
# color from d3 is lost
julia> merge(d3, d4)
Dict{String, Any} with 3 entries:
  "shape"  => "circle"
  "color"  => "blue"
  "coords" => (3, 2)
```

تتيح لنا الدالتان `mergewith()` و `mergewith!()` تمرير دالة كوسيط أول لتحديد كيفية دمج المفاتيح المتكررة.
والجمع مثال بسيط على ذلك.

```julia-repl
julia> d5 = Dict("color" => "red", "area" => 3)
Dict{String, Any} with 2 entries:
  "area"  => 3
  "color" => "red"
julia> d6 = Dict("shape" => "circle", "area" => 5)
Dict{String, Any} with 2 entries:
  "shape" => "circle"
  "area"  => 5
# area values are added, not overwritten
julia> mergewith(+, d5, d6)
Dict{String, Any} with 3 entries:
  "shape" => "circle"
  "area"  => 8
  "color" => "red"
```

لاحظ أن دوال `mergewith` مثال جيد على الدوال عالية الرتبة في العمل.
