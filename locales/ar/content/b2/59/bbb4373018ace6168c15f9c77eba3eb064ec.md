# مقدمة

## تأكيدات `let`

عند مطابقة الأنماط على قيمة في Gleam، علينا التأكد من أن الأنماط تطابق كل قيمة ممكنة من النوع، وإلا فلن يُصرَّف الكود.

يجب رفض هذه الدالة لأنها لم تتعامل مع الحالة التي تكون فيها المصفوفة فارغة:

```gleam
pub fn get_first_element_or_crash(items: List(e)) -> e {
  case items {
    [item, ..] -> item
  }
}
```

في معظم الأحيان نريد في برامج Gleam التعامل مع كل حالة ممكنة، لكن في بعض البرامج، مثل النماذج الأولية والسكربتات السريعة، قد نريد التركيز على المسار السعيد فقط وعدم كتابة كود للحالات الأخرى. وهنا يأتي دور `let assert` في Gleam.

مع تأكيدات `let`، يمكن للنمط أن يطابق بعض القيم الممكنة للنوع فقط، وإذا لم يطابق النمط قيمةً ما فسيتعطل البرنامج. وباستخدام `let assert` يمكننا كتابة الدالة أعلاه هكذا:

```gleam
pub fn get_first_element_or_crash(items: List(e)) -> e {
  let assert [item, ..] = items
  item
}
```

يجب ألا تستخدم مكتبات Gleam تأكيدات `let` أبدًا، لأنها قد تُعطّل البرنامج. وبدلًا من ذلك، عليها استخدام النوع `Result` وتترك لمطوّر التطبيق أن يقرر كيفية التعامل مع الأخطاء.
