# ملحق التعليمات

يُمثَّل كل صف من صفوف الشبكة بكلمة.

على سبيل المثال،

```
    0 1 0
    1 0 0
    1 1 0
```

تُمثَّل كما يلي:

```
0x2
0x4
0x6
```

تحتوي الشبكة على 32 عمودًا كحدٍّ أقصى.

## السجلات

| السجل    | الاستخدام     | النوع    | الوصف                       |
| -------- | ------------- | -------- | --------------------------- |
| `$a0`    | مدخل          | عدد صحيح | عدد الصفوف                  |
| `$a1`    | مدخل          | عدد صحيح | عدد الأعمدة                 |
| `$a2`    | مدخل          | عنوان    | شبكة الجيل الحالي            |
| `$a3`    | مدخل/مخرج     | عنوان    | شبكة الجيل التالي            |
| `$t0-9`  | مؤقت          | أي نوع   | للتخزين المؤقت              |
