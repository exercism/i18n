# ملحق التعليمات

## تنسيق الإخراج

أخرِج نباتات الطالب على هيئة سلسلة نصية منتهية بالبايت الصفري، باستخدام فاصلة ومسافة كفاصلين.

## السجلات

| السجل    | الاستخدام     | النوع   | الوصف                          |
| -------- | ------------ | ------- | ------------------------------ |
| `$a0`    | إدخال        | عنوان   | مخطط الحديقة                   |
| `$a1`    | إدخال        | عنوان   | اسم الطالب                     |
| `$a2`    | إدخال/إخراج  | عنوان   | سلسلة الإخراج المنتهية بالبايت الصفري |
| `$t0-9`  | مؤقت         | أي      | تُستخدم للتخزين المؤقت          |
