# مقدمة

_العامل الثلاثي_ بديل خفيف وموجز لجمل _if/else_ الشرطية البسيطة.
يُستخدم عادةً في عبارات الإرجاع (لكنه ليس محصورًا بها)، ولا يحتاج إلا سطرًا واحدًا لاتخاذ القرار، فيُرجع القيمة اليسرى إذا كان التعبير `true` والقيمة اليمنى إذا كان `false`، كما يلي:

```java
boolean expr = 0 != 200;

// Ternary statement
int value = expr ? 22 : 33;
// => 22
```

يمكن تبسيط الكثير من تعبيرات _if/else_ البسيطة باستخدام _العوامل الثلاثية_.
