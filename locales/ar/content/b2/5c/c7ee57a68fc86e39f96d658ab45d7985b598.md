# الاختبارات

تستخدم جميع التمارين إطار عمل [Pester][pester] للمحاكاة والاختبار.
ستكون جميع الاختبارات في ملف باسم `[Exercise].tests.ps1`، كما هو المعتاد في إطار عمل Pester.
إذا كنت في المجلد الصحيح (أي المجلد الذي يحتوي على `[Exercise].ps1` و`[Exercise].tests.ps1`).
يمكنك تشغيل الاختبارات من PowerShell باستدعاء:

``` PowerShell
Invoke-Pester
```

سيشغّل هذا جميع ملفات `.tests.ps1` التي يجدها في المجلد.

إذا كنت تستخدم صدفة أخرى غير PowerShell، يمكنك تشغيل الاختبارات باستدعاء:

``` PowerShell
pwsh -Command "Invoke-Pester"
```

## تشغيل الاختبارات في Visual Studio Code

يجب أن تتأكد من أنك ثبّتت [إضافة PowerShell][extension] في Visual Studio Code.

يمكنك تشغيل الاختبارات في Visual Studio Code بعدة طرق:

- تشغيل سكربت `.Tests.ps1` من قائمة Debug. اختصارات لوحة المفاتيح هي: `F5` أو `Shift + F5`
- من داخل المحرر بالنقر على رابط "Run Tests" فوق الكلمة المفتاحية `Describe` في كود الاختبار نفسه
- تهيئة Task لتشغيل إطار عمل Pester

[pester]: https://github.com/pester/Pester
[extension]: https://marketplace.visualstudio.com/items?itemName=ms-vscode.PowerShell
