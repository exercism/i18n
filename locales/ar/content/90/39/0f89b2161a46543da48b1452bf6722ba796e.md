# أساسيات Unison

## الحدود والدوال

الحدود والدوال هما الوحدتان الأساسيتان عند كتابة برنامج بلغة Unison.

«الحد» هو ما نسميه قيمة ثابتة. يُعرَّف بصيغة `name = expression`، ويمكن أن يسبقه توقيع النوع بالشكل `name : MyType`. تدعم Unison استنتاج الأنواع، لذلك قد ترى توقيع النوع محذوفًا في التعريفات البسيطة.

```
myTerm = 42

helloThere : Text
helloThere = "Hello, World!"
```

تبدو دوال Unison بالشكل `myFunctionName argument1 argument2 = myImplementation`؛ فهي تبدأ باسم الدالة متبوعًا بوسائط مفصولة بمسافات.

```
getMax a b = Nat.max a b
```

يمكن أن تتضمن الدوال توقيع النوع اختياريًا. النوع الأخير على اليمين هو دائمًا نوع الإرجاع النهائي للدالة، وتُفصل كل وسيطة عن التي تليها بسهم الدالة `->`.

```
getMax : Nat -> Nat -> Nat
getMax a b = Nat.max a b
```

لاستدعاء دالة، استخدم اسمها متبوعًا بوسائطها مفصولة بمسافات فقط.

```
maximum = getMax 1 10

> maximum
  ⧩
  10
```

عند استدعاء دالة، تحاول Unison أن تعامل أي شيء يأتي مباشرة إلى يمينها كوسيطة لها، وهذا لا يُنتج دائمًا ترتيب تقييم الدوال الذي نريده.

لنفترض أننا نريد الحصول على القيمة `1` من التعبير التالي

```
shouldBe1 = getMax 1 10 - 10

> shouldBe1
  ⧩
  0
```

كما هو مكتوب، يُقيَّم `shouldBe1` إلى `0` لأن ترتيب تطبيق الدالة المفهوم هو `getMax 1 10`، وهو `10`، ثم `10 - 10`، وهو `0`.

يمكنك استخدام الأقواس الهلالية لإعادة تجميع التعبير بالترتيب المطلوب للعمليات.

```
shouldBe1 = getMax 1 (10 - 10)

shouldBe1
  ⧩
  1
```

## تعبيرات المراقبة

توفر Unison طريقة لتقييم الكود بسرعة تُسمى «تعبير المراقبة». يبدأ تعبير المراقبة بالرمز `>` ويتبعه التعبير المراد تقييمه. يمكن كتابة تعبيرات المراقبة في أي ملف ينتهي بـ `.u`. عند حفظ الملف، سترى نتيجة تقييم التعبير في وحدة تحكم Unison Codebase Manager (UCM). وحيثما أمكن في هذه الوثائق، سنحاول عرض التعبير مع ناتجه المتوقع بعد تقييمه في تعبير مراقبة.

```
> helloThere
  ⧩
  "Hello, World!"
```

## الدوال متعددة الأسطر

تستخدم دوال Unison متعددة الأسطر الإزاحة أو كتل `let` لتحديد حدود الكود، أي ما يُعرف بـ«النطاق المعجمي».

```
swapOrder : Text -> Text -> Text -> Text
swapOrder beg middle end =
  newBeginning = end ++ middle
  newBeginning ++ beg
```

كل ما يقع عند المستوى نفسه من الإزاحة يتشارك النطاق نفسه، ولهذا يمكننا الإشارة إلى المتغير `newBeginning` في السطر الأخير.

## فضاءات الأسماء وعبارات `use`

فضاءات الأسماء هي الطريقة التي نجمّع بها دوال Unison وننظمها. يمكنك التفكير فيها على أنها أشبه بـ«المجلدات». فهي توفر البنية والتجميع المنطقي.

يمكنك إدخال الدوال الموجودة في فضاء أسماء إلى النطاق باستخدام عبارة `use`.

لنفترض أنك تكتب دالة تستفيد من قيم `List` في Unison. وتعلم أنك ستحتاج دوال مثل `List.map` و`List.flatMap`، حيث `List` هو فضاء الأسماء و`map` و`flatMap` دالتان. ولتجنب التكرار، قد تختار إدخال كل شيء من فضاء الأسماء `List` إلى النطاق المعجمي داخل دالتك على النحو التالي:

```
listProcessing: [Nat] -> [Text]
listProcessing nats =
  use List
  map Nat.toText nats |>
  flatMap (fill 2)
```

يزيل السطر `use List` الغموض عن الإشارات إلى `map` و`flatMap`. يمكنك قراءة المزيد عن [عبارات `use` هنا][use-statements].

## المكتبة القياسية في Unison

تُسمى المكتبة القياسية في Unison بـ `base`. إذا اتبعت دليل البدء السريع وأنشأت قاعدة كود محليًا، فمن المفترض أن المكتبة القياسية قد نُزّلت تلقائيًا. يمكنك تصفح توثيق المكتبة القياسية عبر الإنترنت على [Unison Share][unison-share-base].

## التعليقات والمُدخلات التوثيقية

التعليقات في Unison ميزة غير معتادة بعض الشيء. عند كتابة كود Unison، يمكنك إنشاء نص في ملفك المنتهي بـ `.u` لا يُفسَّر، باستخدام الصيغة التالية:

```
-- a single line comment
-- another single line comment

{-
  a multiline comment
  spanning multiple lines
-}
```

_لكن_، بما أن كود Unison يُحفظ كتجزئة لشجرة التركيب المجردة الخاصة به، وليس كملفات نصية على نظام الملفات، فإن التعليقات التي هي «زخارف» نصية لدالة أو حد معين في الملف لا يمكن حقًا حفظها وإعادة عرضها للمشاركة. وإذا أردت إضافة معلومة إلى حد Unison لديك بطريقة تُخزَّن ليقرأها الآخرون ويفهموها، فيمكنك استخدام مُدخل توثيقي.

التوثيق قيمة من الدرجة الأولى في لغة البرمجة Unison. وهذا يعني أنه يمكن إسناد عنصر `Doc` إلى قيمة، أو تمريره كقيمة إلى دالة، أو إرجاعه كقيمة من الدالة. تُفتح المُدخلات التوثيقية وتُغلق باستخدام الأقواس المعقوفة المزدوجة. وإليك كيف يمكننا استخدام عنصر `Doc` كتعليق.

```
myFunction: Nat -> Boolean
myFunction n =

  {{ when n is `4` we have a special important business logic exception}}

  if n === 4 then true
  else
    if isEven n then false
    else true
```
