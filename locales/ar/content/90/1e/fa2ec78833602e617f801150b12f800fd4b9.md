# المقدمة

المصفوفة (`array`) في F# هي مجموعة قابلة للتغيير من صفر أو أكثر من القيم، وبطول ثابت. وهذا يعني أنه بمجرد إنشاء المصفوفة، لا يمكن تغيير حجمها، لكن يمكن تغيير قيمها. ويجب أن تكون جميع القيم في المصفوفة من النوع نفسه. يمكن تعريف المصفوفات على النحو التالي:

```fsharp
let empty = [| |]
let emptyAlternative = Array.empty

let singleValue = [| 5 |]
let singleValueAlternative = Array.singleton 5

let threeValues = [| "a"; "b"; "c" |]
```

يمكن إسناد العناصر إلى المصفوفة أو استرجاعها منها باستخدام فهرس. مصفوفات F# تبدأ من الصفر، أي أن فهرس العنصر الأول يساوي صفرًا دائمًا:

```fsharp
let numbers = [| 2; 3; 5 |]

// Update value in array
numbers[2] <- 9

// Read value from array
numbers[2]
// => 9
```

يمكن التعامل مع المصفوفات إما عبر دوال وعوامل معرّفة في وحدة `Array`، أو يدويًا باستخدام مطابقة الأنماط عبر نمط _المصفوفة_:

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty"
    | [| 1; 2; three |] -> sprintf "1, 2, %d" three
    | _ -> "Other"

describe [| |]         // => "Empty"
describe [| 1; 2; 4 |] // => "1, 2, 4"
describe [| 5; 7; 9 |] // => "Other"
```

يمكنك أيضًا _تجاهل_ قيمة عند مطابقة الأنماط؛ فعندما لا _تهمّك_ قيمة في حالة معينة (أي أنك لن _تستخدم_ القيمة) يمكنك استخدام شرطة سفلية (`'_'`) للدلالة على ذلك:

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty array"
    | [| x |] -> "Array with one item"
    | [| _; y |] -> "Array with two items (first item ignored)"
    | _ -> "Array with many items (all items ignored)"

describe [| |]          // => "Empty array"
describe [| 1 |]        // => "Array with one item"
describe [| 5; 7 |]     // => "Array with two items (first item ignored)"
describe [| 5; 7; 9 |]  // => "Array with many items (all items ignored)"
```

يجب أن تأتي `'_'` المفردة دائمًا في _الآخر_ عند مطابقة الأنماط، فكل قيمة _لا_ تطابق أيًّا من الحالات الأخرى ستُعالَج في هذه الحالة.
