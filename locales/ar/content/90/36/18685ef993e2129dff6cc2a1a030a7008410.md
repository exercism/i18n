# مقدمة

## الأساسيات

### المتغيرات

Elixir لغة ذات أنواع ديناميكية، أي أن نوع المتغير لا يُفحص إلا أثناء تنفيذ البرنامج. وباستخدام عامل المطابقة `=` يمكننا ربط قيمة من أي نوع باسم متغير:

```elixir
# Bound an integer value of 1
count = 1
# You may re-bind variables
count = 2

# You may re-bind any type to a variable
count = false

# Strings can be created by enclosing characters within double quotes
message = "Success!"
```

### الوحدات

Elixir لغة [برمجة وظيفية][functional-programming] تتطلب تعريف جميع الدوال المسماة داخل _وحدة_. وتُستخدم الكلمة المفتاحية `defmodule` لتعريف وحدة. جميع الوحدات متاحة لجميع الوحدات الأخرى في وقت التنفيذ، ولا تحتاج إلى _معدِّل وصول_ لتجعلها مرئية لأجزاء أخرى من البرنامج. وتشبه _الوحدة_ _الصنف_ في لغات البرمجة الأخرى.

```elixir
defmodule Calculator do
  # ...
end
```

### الدوال المسماة

يجب تعريف _الدوال المسماة_ داخل وحدة. وتُستخدم الكلمة المفتاحية `def` لتعريف دالة مسماة _عامة_.

يمكن أن تأخذ كل دالة صفرًا أو أكثر من الوسائط. وقيمة آخر تعبير في الدالة _تُرجَع ضمنيًا_ دائمًا.

```elixir
defmodule Calculator do
  def add(x, y) do
    x + y
  end
end
```

لاستدعاء دالة، حدّد اسم وحدتها واسم الدالة، ومرّر وسيطًا لكل من وسائط الدالة.

```elixir
sum = Calculator.add(1, 2)
# => 3
```

يمكن استخدام الكلمة المفتاحية `defp` بدلًا من `def` لتعريف دالة _خاصة_. ولا يمكن استخدام الدوال الخاصة إلا من داخل الوحدة نفسها التي عرّفتها.

عند استدعاء دالة من داخل الوحدة نفسها التي عُرّفت فيها، يمكن حذف اسم الوحدة.

يمكنك أيضًا كتابة دوال قصيرة باستخدام صيغة من سطر واحد (لاحظ الفاصلة `,` والنقطتين `:` حول الكلمة المفتاحية `do`).

```elixir
defmodule Calculator do
  def subtract(x, y) do
    private_subtract(x, y)
  end

  defp private_subtract(x, y), do: x - y
end

difference = Calculator.subtract(7, 2)
# => 5

difference = Calculator.private_subtract(7, 2)
# => ** (UndefinedFunctionError) function Calculator.private_subtract/2 is undefined or private
#       Calculator.private_subtract(7, 2)
```

### عدد وسائط الدوال

من الشائع الإشارة إلى الدوال بـ_عدد الوسائط_. و_عدد الوسائط_ للدالة هو عدد الوسائط التي تقبلها.

```elixir
# add/3 because this function has three arguments, thus an arity of 3
def add(x, y, z) do
  x + y + z
end
```

### اصطلاحات التسمية

يُفضّل أن تستخدم أسماء الوحدات `PascalCase`. ويجب أن يبدأ اسم الوحدة بحرف كبير `A-Z`، ويمكن أن يحتوي على حروف `a-zA-Z` وأرقام `0-9` وشرطات سفلية `_`.

يُفضّل أن تستخدم أسماء المتغيرات والدوال `snake_case`. ويجب أن يبدأ اسم المتغير أو الدالة بحرف صغير `a-z` أو شرطة سفلية `_`، ويمكن أن يحتوي على حروف `a-zA-Z` وأرقام `0-9` وشرطات سفلية `_`، وقد ينتهي بعلامة استفهام `?` أو علامة تعجب `!`.

### المكتبة القياسية

لدى Elixir مكتبة قياسية غنية جدًا وموثّقة جيدًا. التوثيق متاح على الإنترنت على [hexdocs.pm/elixir][docs]. احفظ هذا الرابط في مكان ما، فستستخدمه كثيرًا!

لمعظم أنواع البيانات المدمجة وحدة مقابلة توفّر دوالًا للتعامل مع ذلك النوع، فعلى سبيل المثال هناك وحدة `Integer` للأعداد الصحيحة، ووحدة `String` للسلاسل النصية، ووحدة `List` للمصفوفات، وهكذا.

من الوحدات البارزة وحدة `Kernel`. فهي توفّر الإمكانات الأساسية التي بُنيت عليها بقية المكتبة القياسية، مثل عوامل العمليات الحسابية، وماكرو التحكم في سير البرنامج، وغيرها الكثير. وتُستورد دوال وحدة `Kernel` تلقائيًا، لذا يمكنك استخدامها دون البادئة `Kernel.`.
