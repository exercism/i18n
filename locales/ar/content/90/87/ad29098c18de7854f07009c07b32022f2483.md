# مقدمة

## العوامل الثلاثية

العامل الثلاثي هو بديل خفيف وموجز للجمل الشرطية `if/else` البسيطة.
يُستخدم عادةً في عبارات الإرجاع (وليس حصرًا فيها)، ويحتاج إلى سطر واحد فقط لاتخاذ القرار، فيُرجع القيمة اليسرى إذا كان التعبير `true`، والقيمة اليمنى إذا كان `false`، كما يلي:

```java
boolean expr = 0 != 200;

// Ternary statement
int value = expr ? 22 : 33;
// => 22
```

يمكن تبسيط الكثير من تعبيرات `if/else` البسيطة باستخدام العوامل الثلاثية.
