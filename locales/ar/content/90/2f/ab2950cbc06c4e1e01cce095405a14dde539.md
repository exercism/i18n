# العقود

```sather
   spare_capacity(load : INT) : INT
      pre load >= 0 and load <= limit
      post result >= 0
   is
      return limit - load;
   end;
```

| البند | ما ينصّ عليه | على من يقع اللوم عند المخالفة |
| --- | --- | --- |
| `pre` | ما يجب أن يتحقق عند الدخول | على المستدعي |
| `post` | ما يتحقق عند الرجوع | على الدالة |

كلاهما يأخذ قيمة من النوع `BOOL`، ويمكن لكلٍّ منهما استخدام وسائط الدالة وخصائص الكائن. ويمكن لـ `post` أيضًا استخدام `result`، أي القيمة التي تُرجعها الدالة.

## assert

داخل جسم الدالة، تنصّ `assert` على أمر يجب أن يكون صحيحًا عند تلك النقطة:

```sather
      assert load <= limit;
```

وتُفحص بالمفتاح نفسه الذي تُفحص به بقية الفحوص.

## ثوابت الصنف

قد ينصّ الصنف على أمر يصدق على كل كائن منه بين الاستدعاءات:

```sather
   invariant : BOOL is
      return checks >= 0 and limit > 0;
   end;
```

ويُفحص عند الدخول إلى كل دالة عامة وعند الخروج منها، متى كان الفحص مُفعَّلًا.

## تفعيل الفحص

| المفتاح | ما يفحصه |
| --- | --- |
| `-chk` | كل شيء: pre، post، assert، invariant، الحدود، العمليات الحسابية |
| `-chk_no` | لا شيء |

لاحظ أن `-chk_pre` وحده *لا* يُفعّل فحص الشروط المسبقة في هذا المترجم؛ وإنما `-chk` هو الذي يعمل. وعند المخالفة، يُطبع اسم الدالة وسطر المصدر، ويتوقف البرنامج. فهي ليست استثناءً، ولن يلتقطها `protect`.

الترتيب المعتاد هو أن تُطوّر وتختبر باستخدام `-chk`، ثم تُصدر دونها، فلا تكلّف الفحوص شيئًا في البرنامج الصادر. وهذا لا يجدي إلا إذا كانت الاختبارات تمرّ فعلًا على تلك المسارات.

## ما الذي يجعل العقد جيدًا

قل ما تحتاجه الدالة، لا كيف تعمل:

```sather
   pre load >= 0 and load <= limit        -- yes
   pre load /= 47                         -- what?
```

أما `post` الذي يعيد صياغة جسم الدالة فلا يعلّم أحدًا أي شيء:

```sather
   post result = limit - load             -- says the body twice
   post result >= 0                       -- says something worth knowing
```

## الوراثة

يمكن للنوع الفرعي أن يُضعف `pre` ويقوّي `post`، أي أن يقبل أكثر ويعد بأكثر، لكن ليس العكس أبدًا، وإلا انكسر الكود المكتوب وفق النوع الأعلى. وهذه هي القاعدة التي وُجدت العقود لجعلها قابلة للفحص.
