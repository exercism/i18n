# نبذة

[السجل][records] هو مجموعة من الحقول (التي قد تكون من أنواع مختلفة) المرتبطة ببعضها. لتعريف سجل تُستخدم الكلمة المفتاحية `type`. تُعرَّف حقول السجل بين المحرفين `{` و`}`، ولكل حقل اسم _و_نوع.

```fsharp
type Address =
    { Street: string
      HouseNumber: int }
```

لإنشاء سجل، حدّد أسماء الحقول وأسند إليها قيمًا بين المحرفين `{` و`}`. يجب إسناد قيمة إلى جميع حقول السجل عند إنشائه. يمكن تحديد الحقول بأي ترتيب، ولا يلزم أن يطابق ترتيب تعريف نوع السجل. وللوصول إلى قيم حقول نسخة السجل، يُستخدم ترميز النقطة.

```fsharp
let oldAddress: Address =
    { Street = "Main Street"
      HouseNumber = 17 }

oldAddress.Street      // => "Main Street"
oldAddress.HouseNumber // 17
```

عند تعريف سجل أو إنشائه، يجب أن يكون كل حقل في سطر منفصل، أو مفصولًا بفاصلة منقوطة (`;`) عند وضعه في سطر واحد:

```fsharp
type Address = { Street: string; HouseNumber: int }

let oldAddress: Address = { Street = "Main Street"; HouseNumber = 17 }
```

إذا كانت أسماء حقول السجل فريدة، فتعليقات النوع اختيارية، لأن المترجم سيتمكن من استنتاج النوع تلقائيًا. أما إذا كانت مجموعة أسماء الحقول _غير_ فريدة، فيمكنك مساعدة المترجم على اختيار السجل الصحيح، إما باستخدام نوع صريح في ارتباط السجل، أو بإضافة نوع السجل كبادئة إلى حقل واحد أو أكثر:

```fsharp
type Boat = { Weight: int; Length: int }
type Car = { Weight: int; Length: int }

// Let compiler infer type. As there are multiple matching record types,
// the last matching type is used (Car)
let typeEqualsLastMatch = { Weight = 5000; Length = 15 }

// Use type annotation on binding to force type to Boat
let typeAnnotation: Boat = { Weight = 5000; Length = 15 }

// Use fully qualified name for field to force type to Boat
let fullyQualifiedField = { Boat.Weight = 5000; Length = 15}
```

بما أن السجلات غير قابلة للتغيير، فلا يمكن لقيم حقولها أن تتغير أبدًا بعد إنشائها. وإذا أردت تغيير قيم سجل، فالكلمة المفتاحية `with` تتيح لك [إنشاء نسخة من سجل موجود، مع قيم جديدة لحقل واحد أو أكثر][create].

```fsharp
// Copy the old address but change the house number
let newAddress = { oldAddress with HouseNumber = 86 }
newAddress.Street      // => "Main Street"
newAddress.HouseNumber // => 86
```

تتمتع السجلات بـ [_المساواة البنيوية_][equality]، وهذا يعني أن نسختين من السجل نفسه بقيم متطابقة متكافئتان:

```fsharp
let address1 = { Street = "Main Street"; HouseNumber = 17 }
let address2 = { Street = "Main Street"; HouseNumber = 17 }
let address3 = { Street = "Broadway"; HouseNumber = 17 }

address1 = address2 // => true
address1 = address3 // => false
```

إلى جانب إمكانية استخدام ترميز النقطة للوصول إلى حقول السجل، يمكن أيضًا _تفكيك_ السجلات في الارتباطات وفي مطابقة الأنماط باستخدام [نمط السجل][record-patterns]:

```fsharp
let myAddress = { Street = "Broadway"; HouseNumber = 123 }
let { Street = myStreet; HouseNumber = myHouseNumber } = myAddress

match myAddress with
| { HouseNumber = 1 } -> printfn "First house"
| { HouseNumber = houseNumber; Street = street } -> printfn "House number %d on %s" houseNumber street
// => "House number 123 on Broadway
```
