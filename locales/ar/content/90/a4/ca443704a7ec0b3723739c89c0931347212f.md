# قسم عن التعليقات

توفّر Go [إرشادات ممتازة](https://golang.org/doc/effective_go.html) حول كيفية كتابة التعليقات. وهناك صيغة قياسية يمكنك استخدامها لتعليقات التوثيق، ثم تحوّلها أداة `godoc` تلقائيًا إلى توثيق جميل.

ينبغي أن يبدأ تعليق الحزمة بكلمة `Package` متبوعة باسم الحزمة، هكذا:

```go
// Package cook provides handy conversion methods for units typically used in recipes.
package cook
```

وبالنسبة إلى الدوال والطرق والثوابت ومتغيرات الحزمة المُصدَّرة، ينبغي أن يبدأ التعليق بالاسم ثم يتبعه تركيب فعلي:

```go
// TbsToMl converts tablespoons to milliliters.
func TbsToMl(tbs int) int {
	// ...
}
```

ويحدّد ويكي [CodeReviewComments](https://github.com/golang/go/wiki/CodeReviewComments#comment-sentences) كذلك أن تعليقات التوثيق ينبغي أن تكون جملًا كاملة تنتهي بنقطة.

وإلى جانب تحسين قابلية القراءة، فإن اتباع هذه التوصيات يحسّن شكل الكود في [أدوات توثيق Go](http://whipperstacker.com/2015/09/30/go-documentation-godoc-godoc-godoc-org-and-go-doc/) مثل [godoc.org](http://godoc.org) و`godoc` و`go doc`.

خُذ لحظة لقراءة القسم الخاص بتعليقات التوثيق في دليل الأسلوب الرسمي، [Effective Go](https://golang.org/doc/effective_go.html)، لترى الحكمة وراء هذه الخيارات.
