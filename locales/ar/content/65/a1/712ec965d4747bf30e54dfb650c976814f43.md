# الأصناف والخصائص للقراءة فقط

تتيح الأصناف والخصائص للقراءة فقط تحديد خصائص عامة يسهل الوصول إليها، لكنها تمنع تعديلها.
لجعل خاصية ما للقراءة فقط، يجب إضافة `readonly` قبل تحديد النوع.
يُسمح بإسناد الخاصية مرة واحدة، لكن أي محاولة لإعادة إسناد القيمة أو تعديلها ستؤدي إلى `Error`.

```php
<?php

class Block
{
    public function __construct(
        public readonly int $length,
        public readonly int $width,
    ) {
    }
}
```

تستند الأصناف للقراءة فقط إلى هذا السلوك؛ فعندما يُعرّف الصنف باستخدام `readonly`، يُطبّق تعريف القراءة فقط على كل خاصية من خصائصه.
بالإضافة إلى ذلك، يمنع إضافة خصائص ديناميكية.

```php
<?php

readonly class Block
{
    public function __construct(
        public int $length,
        public int $width,
    ) {
    }
}
```
