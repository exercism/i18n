# مقدمة

يمكن للتعريف الذي يبدأ بـ `:` أن يستدعي نفسه مباشرة. ويستنتج مترجم Factor تأثير المكدس للكلمات العودية تمامًا كما يفعل مع أي كلمة أخرى، فلا حاجة إلى أي تصريح خاص من أجل العودية العادية.

```factor
: total ( seq -- sum )
    [ 0 ] [ unclip swap total + ] if-empty ;

{ 4 0 9 0 5 } total .    ! => 18
```

وهذان النصفان هما *الحالة الأساسية* للعودية (وهنا، المتتالية الفارغة مجموعها `0`) و*الخطوة العودية* (ننزع عنصرًا واحدًا، ثم نستدعي الدالة نفسها على الباقي، ثم ندمج النتائج).

و`if-empty` و`unclip` هما الرفيقان المعتادان في العودية على المتتاليات. تشغّل `if-empty ( seq emptyquot nonemptyquot -- )` أحد الاقتباسين حسب المتتالية؛ وتنزع `unclip` العنصر الأول حتى يكون أمام الخطوة العودية شيء أبسط.
