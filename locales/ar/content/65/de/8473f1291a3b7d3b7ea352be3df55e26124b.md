# نبذة

ينشئ تعريف النوع نوعًا جديدًا مسمّى، متميّزًا عن كل نوع آخر، حتى لو كان نوع آخر يشترك معه في النوع الأساسي.

## تعريف الأنواع

يبدأ تعريف النوع بالكلمة المفتاحية `type`، ثم اسم النوع الجديد ونوعه الأساسي:

```go
type File []bool
```

يشير `File` هنا إلى عمود رأسي واحد على رقعة الشطرنج، يُسمّى عادةً من A إلى H.
يمثّل كل مربّع في هذا العمود قيمة منطقية تحدّد ما إذا كان مشغولًا أم لا.
وبعد تعريف `File`، يمكننا استخدامه داخل تعريفات أخرى:

```go
type Chessboard map[string]File

board := Chessboard{
    "A": File{true, false, true},
    "B": File{false, true, false},
}
```

تربط خريطة `Chessboard` معرّفات الأعمدة بقيم `File`.
وكل `File` شريحة من القيم المنطقية تمثّل المربعات في عمود واحد من أعمدة الرقعة.
لولا تعريفات الأنواع هذه، لكان `board` من النوع `map[string][]bool`، وهو ما يصعّب فهم ما نمثّله.

## الأنواع المعرّفة متميّزة

على الرغم من أن `Score` و `int` يحملان قيمًا صحيحة، فإن التحويل بينهما يتطلب تحويلًا صريحًا:

```go
type Score int

var number int = 42

// var score Score = number is a compile error
var score Score = Score(number)
var converted int = int(score)
```

`42` ثابت بلا نوع، لذا يمكن إسناده مباشرةً إلى متغير من النوع `Score`.

يمكن أن تمتلك الأنواع المعرّفة طُرُقًا أيضًا، وهي مشروحة في مفهوم الطُرُق.

## أنواع البُنى

تستخدم تعريفات البُنى الكلمة المفتاحية `type` نفسها:

```go
type Player struct {
    Name  string
    Score Score
}
```

وتُشرح أنواع البُنى في مفهوم البُنى.

## الأسماء البديلة للأنواع

ينشئ الاسم البديل للنوع اسمًا آخر لنوع موجود بدلًا من إنشاء نوع جديد.
ولأن الاسم البديل ونوعه الأصلي متماثلان، يمكن استخدام قيمهما بالتبادل.
تُعرَّف الأسماء البديلة باستخدام الكلمة المفتاحية `type`، واسم البديل، وعلامة التساوي (`=`)، والنوع الموجود.

```go
type Square = bool

var isOccupied bool = true
var square Square = isOccupied // no conversion needed
```
