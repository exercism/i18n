# مقدمة

الأصناف هي البنية الأساسية للبرمجة كائنية التوجه في F#.

يتكوّن الصنف في F# من حقوله وطرقه. تُعرف حقول الصنف وطرقه باسم _الأعضاء_.

تُعرَّف الأصناف في F# باستخدام الكلمة المفتاحية `type`. وتُعرَّف الطرق باستخدام الكلمة المفتاحية `member`، وهي دائمًا عامة. ولتعريف الحقول (الخاصة)، يمكن استخدام ارتباطات `let`.

```fsharp
type Shoe() =
    let size = 8

    member this.Describe() = $"This is a size {size} shoe"
```

الأصناف قوالب تُنشأ بها الكائنات. ولإنشاء نسخة من صنف، استدعِ اسم الصنف كأنه دالة. تُعرف نسخة الصنف أيضًا باسم _الكائن_.

يمكن الوصول إلى أعضاء الكائن باستخدام الترميز النقطي.

```fsharp
let myShoe = Shoe()
myShoe.Describe()
// => "This is a size 8 shoe"
```
