# المساهمة عبر GitHub

تتم المساهمة في قاعدة كود Exercism عبر [GitHub][github].

وكما يوحي اسمه، يستخدم GitHub نظام [git][git] للتحكم في الإصدارات.
وإذا لم تكن معتادًا على Git، فأفضل مصدر على الإنترنت هو [Pro Git][pro-git].

وإذا لم تكن على دراية بـ GitHub وسير عمل المساهمة، فإليك بعض المصادر التي قد تساعدك على البدء:

- [مقدمة إلى GitHub - دورة تفاعلية][github-course]
- [كيفية إنشاء Pull Request على GitHub - درس تعليمي][pr-tutorial]
- [كيفية عمل Pull Request بسيط على GitHub - فيديو من anthonywritescode][anthonywritescode]

## الأدلة

يمكنك قراءة المزيد حول كيفية ضمان أن مساهمتك موضع ترحيب في دليل [كيفية إنشاء Pull Request رائع][great-pr].

لدينا أيضًا عدة أدلة خاصة بـ Exercism حول طلبات السحب (Pull Requests):

- [كيفية إنشاء Pull Request رائع][how-to-make-a-great-pr]
- [دليل المساهمين حول طلبات السحب][contributors-pr-guide]
- [دليل المشرفين حول طلبات السحب][maintainers-pr-guide]
- [صلاحيات المستودعات للمشرفين][maintainers-repo-permissions]
