# مقدمة

في Gleam يمكن استخدام تعبير `case` لتنفيذ الكود شرطيًا. وباستخدام تعبير `case` يمكن اختبار قيمة مقابل نمط واحد أو أكثر من _الأنماط_. ومن أمثلة هذه الأنماط _النمط الحرفي_، الذي يطابق قيمة مقابل قيمة حرفية (مثل `1` أو `"hello"`).

تُكتب تعبيرات `case` باستخدام الكلمة المفتاحية `case`:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    1 -> "One"
  }
}
```

قد يبدو هذا مشابهًا لعبارات `switch` في لغات أخرى، لكن مطابقة الأنماط تتألق عند استخدام أنماط أخرى أيضًا. ومن هذه الأنماط _نمط المتغير_، الذي يسمح بإسناد قيمة إلى متغير. في هذا المثال، سيُسند إلى المتغير `i` قيمة `number` إذا لم تكن `0`:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i -> "Non zero"
  }
}
```

في بعض الحالات، قد ترغب في إضافة شرط إضافي إلى نمط ما. يُعرف هذا بـ _الحارس_ (الشرط)، ويمكن إضافته باستخدام الكلمة المفتاحية `if`:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
  }
}
```

لأسباب تتعلق بالأداء، يُسمح في الحُرّاس بعوامل العمليات الحسابية والمنطقية الأساسية فقط، ولا يمكن استخدام دوال أخرى في الحُرّاس.

في المثال أعلاه، لن يكون لكل المُدخلات الممكنة نمط مطابق. سيكتشف المُصرِّف ذلك ويُخرج خطأً. يُعرف هذا بـ _فحص الشمولية_. ولحل هذا التحذير، عليك معالجة كل الحالات. ولهذا يمكن استخدام _نمط التجاهل_، وهو نمط يطابق أي قيمة:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
    _ -> "Positive number"
  }
}

// No compiler error
```

تختبر تعبيرات `case` قيمة ما مقابل كل نمط من الأعلى إلى الأسفل، حتى تجد نمطًا مطابقًا وتنفّذ المنطق المرتبط بذلك النمط. ترتيب الأنماط مهم!
