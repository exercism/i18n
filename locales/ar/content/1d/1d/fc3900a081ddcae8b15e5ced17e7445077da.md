# نبذة

يعني تحضير قيمة للإرسال ثلاثة أمور في آنٍ واحد: تسلسلها، وانتقاء الجزء الصحيح منها، وتجنّب النسخ حين لا تحتاج إليه. وتغطّي ثلاثة أساليب في Factor هذا المجال.

## `unparse`: من القيمة إلى المصدر

تُرجع [`unparse`][unparse] (في `prettyprint`) النص بصيغة المصدر لأي قيمة. وهي عكس المحلّل: فالرحلة ذهابًا وإيابًا `dup unparse parse` تعيد بناء القيمة.

```factor
USING: prettyprint ;

{ 1 2 3 } unparse .   ! => "{ 1 2 3 }"
"hi" unparse .        ! => "\"hi\""
123 unparse .         ! => "123"
```

قارن ذلك بـ `>string` (الذي يعمل على متتاليات المحارف فقط) و`number>string` (الأعداد فقط). `unparse` هي الأداة الشاملة، لكن على حساب إنتاج صيغة Factor (فالسلاسل النصية المقتبسة تحتفظ بعلامات الاقتباس)، لذا فهي الأداة المناسبة عندما يعيد المستقبِل تحليل النص، وغير المناسبة للمخرجات المقروءة بشريًا.

## الشرائح: عروض لا نُسخ

| الكلمة        | التأثير                                        |
|---------------|------------------------------------------------|
| `head`        | `( seq n -- newseq )`: ينسخ أول n               |
| `head-slice`  | `( seq n -- slice )`: عرض لأول n                |
| `tail`        | `( seq n -- newseq )`: ينسخ من الفهرس n فصاعدًا  |
| `tail-slice`  | `( seq n -- slice )`: عرض من الفهرس n فصاعدًا   |
| `head*`       | `( seq n -- newseq )`: ينسخ كل العناصر عدا آخر n |
| `head-slice*` | `( seq n -- slice )`: عرض لكل العناصر عدا آخر n |
| `tail*`       | `( seq n -- newseq )`: ينسخ آخر n               |
| `tail-slice*` | `( seq n -- slice )`: عرض لآخر n                |

`slice` صفّ يحمل فهرس البداية وفهرس النهاية والمتتالية الأساسية، ويطبّق [بروتوكول المتتاليات][sequence-protocol]، لذا تعمل عليه أي عملية على المتتاليات. الجأ إلى صيغ الشرائح حين لا تحتاج سوى إلى القراءة، وإلى الصيغ الناسخة حين تحتاج إلى الاحتفاظ بالبيانات بعد أن تتغيّر المتتالية الأساسية.

## `cleave` متعدد المدخلات: `2bi`، `3bi`، `2tri`، `3tri`

كلمات `cleave` العادية `bi` و`tri` تطبّق اقتباسين أو ثلاثة اقتباسات على مُدخل *واحد* في المكدّس. أما الصيغ المسبوقة بـ `2` والمسبوقة بـ `3` فتطبّق كل اقتباس على *مدخلين* أو *ثلاثة* مدخلات:

```
bi   ( x       p q   -- )
2bi  ( x y     p q   -- )
3bi  ( x y z   p q   -- )

tri  ( x       p q r -- )
2tri ( x y     p q r -- )
3tri ( x y z   p q r -- )
```

يتلقّى كل اقتباس *جميع* المدخلات، لذا استخدم `2bi` عندما يعتمد كلا الإسقاطين على الزوج، لا عندما تريد تطبيق الإسقاط نفسه على كل مدخل على حدة (فتلك هي `bi@`).

```factor
1 2 [ + ] [ * ] 2bi . .       ! => 2  3   (both use 1 and 2)
1 2 3 [ + + ] [ * * ] 3bi . . ! => 6  6
```

أما إذا أردت *اقتباسًا واحدًا* يُطبَّق على كل مدخل على حدة، فالجأ إلى `bi@` (لمدخلين) أو `tri@` (لثلاثة مدخلات) بدلًا من ذلك: العائلة نفسها، لكن الشكل مختلف.
