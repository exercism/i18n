# نبذة

أهم ما يجب تذكّره عن السلاسل النصية في Java هو أنها كائنات غير قابلة للتغيير، تمثّل النص على هيئة تسلسل من محارف Unicode (الحروف والأرقام وعلامات الترقيم وغيرها).
تُستخدم علامات الاقتباس المزدوجة لتعريف نسخة من `String`:

```java
String fruit = "Apple";
```

يمكن التعامل مع السلسلة النصية باستخدام طريقة من الصنف [`String`][string-class].
ولأن قيم السلاسل النصية لا يمكن أن تتغير بعد تعريفها، فإن جميع طرق التعامل مع السلاسل النصية تُرجع سلسلة نصية جديدة.

تُحدَّد السلسلة النصية بعلامات الاقتباس المزدوجة (`"`).
وتحتاج بعض المحارف الخاصة إلى إفلات باستخدام محرف الشرطة المائلة العكسية (`\`).
المحارف التي يجب إفلاتها في Java:

- `"`
- `\`

```java
String escaped = "c:\\test.txt";
// => c:\test.txt
```

وأخيرًا، هناك طرق عديدة لدمج السلاسل النصية.
أبسطها هو العامل `+`:

```java
String name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

ولأي تنسيق للسلاسل النصية أكثر تعقيدًا من الدمج البسيط، يُفضَّل استخدام الطريقة `String.format`.

```java
String name = "Jane";
String.format("Hello %s!",name);
// => "Hello Jane!"
```
