# نبذة

## الجمل الشرطية

الجمل الشرطية هي عبارات لاتخاذ القرار، يمكنها إما تنفيذ آثار جانبية أو التحكم في مسار التنفيذ داخل البرنامج.
تشمل الجمل الشرطية عبارات `if` و`if/else` و`switch` و`ternary`.

تُستخدم الجمل الشرطية لطرح أسئلة حول قيمة ما أو علاقة بين قيم.
يُقيَّم السؤال إلى إجابة منطقية، لكن جملة `if` نفسها يمكنها إرجاع أي قيمة أو أن تنفّذ أثرًا جانبيًا فحسب.

## جمل `if`

أبسط جملة `if` تُقيّم تعبيرًا وتنفّذ سطرًا واحدًا.
التعبير الذي يجري اختباره يوضع دائمًا بين الأقواس الهلالية.

يمكنها تنفيذ أثر جانبي

```c
if (count > 10)
    printf("count is greater than 10");
```

أو يمكنها تغيير مسار التنفيذ


```c
if (count > 10)
    return sum;
```

إذا نفّذت جملة `if` أكثر من سطر واحد، وجب وضع الأسطر بين الأقواس المعقوفة

```c
if (count > 10) {
    printf("count is greater than 10");
    return sum;
}
```

قد تتفق بعض فرق البرمجة على أن تستخدم جمل `if` الأقواس المعقوفة دائمًا، حتى مع سطر واحد.


## `if` و`else`

يمكن ربط جملة `if` بـ `else`

```c
if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## `else if`


يمكن ربط `else` بجملة `if` أخرى لإنشاء ما يُسمى بـ `if-else-if ladder`.

```c
if (number == 0)
    return "zero";
else if (number < 0)
    return "negative";
else if (number < 10)
    return "single digit";   
else if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## `switch`


أحيانًا يمكن تمثيل `if-else-if ladder` بشكل أفضل باستخدام `switch`.
وكما في `if`، يوضع التعبير الذي يجري اختباره دائمًا بين الأقواس الهلالية.

```c
switch (number) {
    case -1:
        return "negative one";
    case 0:
        return "zero";
    case 1:
        return "positive one";
    case 10:
        return "positive ten";
    case -10:
        return "negative ten";
    default:
        return "don't care";
}
```

تُنفَّذ حالة `default` إذا لم تطابق القيمة التي يجري اختبارها أيًّا من الحالات السابقة.

إذا لم تُرجع حالة `switch` قيمة، فيُدرَج عادةً `break` لإنهاء كل حالة، وإلا فإن المنطق «ينتقل» إلى الحالة التالية.
وأحيانًا يُستخدم الانتقال التلقائي عن قصد

```c
switch (number) {
    case 0:
        msg = "zero"; break;
    case 1:
        msg = "one"; break;
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

عندما يحدث الانتقال التلقائي دون قصد فإنه bug.

```c
switch (number) {
    case 0:
        msg = "zero"; // bug! fallthrough of 0 will set msg to "one"
    case 1:
        msg = "one"; break; 
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

قد يكون `switch` مفيدًا عند الاختبار مقابل قيم محددة بدلًا من نطاق من القيم.
وقد يكون أسرع من `if-else-if ladder` لأن المترجم قد يتمكن من تحسين جملة `switch` بطرق لا يستطيع تطبيقها مع `if-else-if ladder`.
وأحيانًا قد يبدو `switch` أكثر وضوحًا في القراءة من `if-else-if ladder`.

## العامل الثلاثي (المعروف أيضًا بالعامل الشرطي)

العامل الثلاثي عبارة شرطية من ثلاثة أجزاء تُستخدم غالبًا لإسناد قيمة.
يوضع التعبير المراد اختباره قبل علامة الاستفهام، وليس بالضرورة بين الأقواس الهلالية.
القيمة التي تُرجع إذا كان الشرط صحيحًا تأتي قبل النقطتين، والقيمة التي تُرجع إذا كان خاطئًا تأتي بعد النقطتين.
يمكن إرجاع قيمة حرفية أو متغير.

```c
int i = j > 5 ? 5: j;
```

يمكن تضمين العوامل الثلاثية بعضها في بعض لتقليل الفوضى النحوية.

```c
// the below could also be 
i = j > 5 ? j :k > 5 ? k: 10;
// but that may not be quite as readable

i = j > 5 ? j
    :k > 5 ? k
    :10;

// which is the same as
if (j > 5) i = j;
else if (k > 5) i = k;
else i = 10;
```

## المقارنات الشرطية لقيم الفاصلة العائمة

بسبب طريقة تمثيل أعداد الفاصلة العائمة، قد تؤدي عملية حسابية بسيطة إلى خطأ في التقريب، ما قد يجعل اختبار التساوي لا يُرجع النتيجة المتوقعة.

```c
    a = 1.345f;
    b = 1.123f;
    c = a + b;
    // c may equal something like 2.4679999352
    if (c == 2.468)
        return "I won the lottery!";
```

يمكن استخدام قيمة تفاوت، يُشار إليها بـ `epsilon`، لتحديد نطاق يمكن أن تقع فيه قيمة لتُعتبر مساوية عند مقارنتها بقيمة أخرى.
تمتلك بعض المنصات ثوابت مدمجة لقيم `epsilon` للنوعين `float` و`double`.
راجع وثائق المترجم الخاص بك لمعرفة المزيد.
قد يكون حساب `epsilon` معقدًا، وقد يختلف من منصة إلى أخرى، بل حتى بين جهاز وآخر.
إليك برنامجًا مثالًا يستخدم مقارنة بسيطة.

```c
#include <stdio.h>
#include <math.h>
#include <stdbool.h>

const double MY_EPSILON = .002;

bool same(double x, double y)
{
    return fabs(x - y) < MY_EPSILON;
}

int main()
{
    // Same should return true if the difference is less than MY_EPSILON
    printf("%s\n", same(1.1, 1.099) ? "true" : "false"); // prints true
    printf("%s\n", same(1.1, 1.098) ? "true" : "false"); // prints false
    return 0;
}
```

احذر عند مقارنة قيم `float` أو `double` من أجل التساوي!
