# نبذة

`string` في C++ كائن قابل للتعديل يمثّل نصًا على هيئة تسلسل من المحارف (حروف، وأرقام، وعلامات ترقيم، وما إلى ذلك).
نتعامل مع السلاسل النصية من خلال استدعاء طُرق السلسلة النصية.

## مكتبة السلاسل النصية

في C++ يجب تضمين النوع `string` والدوال المرتبطة به من مكتبة السلاسل النصية قبل استخدامها.
يمكنك فعل ذلك بإضافة `#include <string>` إلى أعلى ملفك.
وعندها ستُضاف جميعها إلى فضاء الأسماء `std`.
السلسلة النصية الحرفية تستخدم علامة التنصيص المزدوجة: `"`.

```cpp
#include <string>
std::string w_berry_quote{"A well-made sentence, I think, is a thing of beauty."};
```

## العمليات الشائعة على السلاسل النصية

يمكنك استخدام العامل `+` لدمج السلاسل النصية:

```cpp
std::string original_title{"The School of Rock"};
std::string sequel_indicator{"Electric Boogaloo"};
std::string next_movie_title = original_title + " 2: " + sequel_indicator;
```

لاستخدام مكتبة السلاسل النصية، عليك أن تعرف أنه يمكن استدعاء دالة تنتمي إلى كائن.
ويُطلق على هذه اسم الدوال الأعضاء.
لاحقًا في المنهج، ستتعلم المزيد عن الدوال الأعضاء وعن مفهوم الصنف المرتبط بها.

```cpp
std::string qualification{"awesome"};
// 1st argument: from the index to the end of the string:
std::string who_is_awesome = qualification.substr(5);
// => "me"

// 2nd optional argument for the length:
std::string material{"haunted books"};
std::string ghost = material.substr(8, 3);
// => "boo"
```


دالة `find` مفيدة جدًا أيضًا.
تُستدعى على السلسلة النصية كدالة عضو، وتأخذ سلسلة نصية كوسيط لها.
وتُرجع دالة `find` موضع أول ظهور في السلسلة النصية، حيث يبدأ الفهرس من صفر.

```cpp
std::string new_release{"apple released a new app!"};
new_release.find("app");
// => 0
new_release.find("!");
// => 24
```

وهناك أيضًا دالة `to_string`، التي يمكن استخدامها لتحويل الأعداد الصحيحة وقيم `float`/`double` إلى سلسلة نصية.
وتُرجع دالة `to_string` سلسلة نصية.

```cpp
int num{92};
double exponent{0.92e2};
std::string msg{ std::to_string(num) + " can also be written as " + std::to_string(exponent)};
// => 92 can also be written as 92.0000000
```
