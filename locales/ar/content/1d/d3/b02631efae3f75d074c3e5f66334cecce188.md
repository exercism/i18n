# مقدمة

الأنواع الشبحية هي معاملات نوع لنوع مخصص لا تُستخدم في أي من منشئات قيم ذلك النوع.

هذا تجريدي بعض الشيء، لذا إليك مثال:

```gleam
pub type Length(unit) {
  Length(amount: Float)
}
```

في هذا المثال، لا يُستخدم معامل النوع `unit` في منشئ القيمة `Length`، لذا فإن `unit` نوع شبحي.

قد يبدو معامل النوع غير المستخدم هذا عديم الفائدة، لكن يمكن استخدامه لإضافة قيود أخرى على كيفية استخدام قيم `Length`.

على سبيل المثال، يمكن أن تكون لدينا دالة `double`، التي تضرب الطول. إنها تعمل مع أطوال من أي وحدة، لذا فإن معامل النوع هو متغير نوع عام.

```gleam
// This function accepts all Length values
pub fn double(length: Length(unit)) -> Length(unit) {
  Length(length.amount *. 2.0)
}
```

يمكن أن تكون لدينا أيضًا دالة `add_inch`، التي تعمل فقط إذا كان الطول بالبوصات.

```gleam
// A unit type for inches. It is never constructed so we don't
// define any constructors for it.
pub type Inches

pub fn add_inch(length: Length(Inches)) -> Length(Inches) {
  Length(length.amount +. 1.0)
}
```

لن تقبل دالة `add_inch` أطوالًا من أي معامل وحدة آخر، فقد استُخدم النوع الشبحي لضمان استخدام الوحدة الصحيحة فقط.

يمكن أيضًا كتابة دالة لضمان أن قيمتي طول من نفس الوحدة، باستخدام نفس متغير النوع لكليهما.

```gleam
pub fn add(a: Length(unit), b: Length(unit)) -> Length(unit) {
  Length(a.amount +. b.amount)
}
```
```gleam
let two_meters: Length(Meters) = Length(2.0)
let two_inches: Length(Inches) = Length(2.0)

add(two_meters, two_meters)
// -> Length(4.0): Length(Meters)

add(two_meters, two_inches)
// Type error! The unit type parameters do not match.
```

يمكن أن تعمل الأنواع الشبحية جيدًا مع الأنواع المعتمة. إذا لم تتمكن وحدات أخرى من إنشاء قيم `Length`، فيمكننا ضمان عدم إنشائها بنوع وحدة غير صالح، وأن الدوال المعرفة أعلاه فقط هي التي يمكن استخدامها معها.
