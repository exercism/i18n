# تثبيت Emacs

بما أن Emacs Lisp (elisp) هي لغة التوسيع الخاصة بـ Emacs، ستحتاج أولًا إلى تثبيت [GNU Emacs](http://www.gnu.org/software/emacs/).

يُنصح بالحصول على أحدث إصدار من Emacs، لكن ينبغي اعتبار الإصدار 28.1 أو أعلى هو التنفيذ المستهدف للتمارين.
وإذا كان Emacs مثبتًا لديك بالفعل، يمكنك التحقق من إصدار Emacs عبر `M-x emacs-version RET`.

## على OS X
أسهل طريقة هي زيارة [Emacs For Mac OS X](http://emacsformacosx.com/) وتنزيل ملف dmg، والذي سيثبّت
GNU Emacs كتطبيق OS X مُحزَّم.

توجد بدائل، مثل Aquamacs (غير موصى به) أو التثبيت عبر
[Homebrew](https://formulae.brew.sh/formula/emacs)، إن كنت تفضّل ذلك.

## على Linux
في بعض التوزيعات، يكون Emacs مثبتًا بالفعل، لأنه جزء من GNU.

### Ubuntu
الطريقة الموصى بها حاليًا لتثبيت أحدث إصدار من Emacs هي عبر [snap](https://snapcraft.io/emacs):

```
sudo snap install emacs --classic
```

إذا كنت لا تريد استخدام snap يمكنك أيضًا تثبيت Emacs عبر snap، لكن الإصدار المتاح من مستودعات Ubuntu غالبًا ما يكون قديمًا.
وإذا كنت تريد تثبيت إصدار أحدث من Emacs عبر apt فستحتاج إلى استخدام [PPA](https://launchpad.net/ubuntu/+ppas?name_filter=emacs) أو [البناء من المصدر](https://www.emacswiki.org/emacs/BuildingEmacs).

إذا لم تكن تهتم بتثبيت أحدث إصدار، فكل ما عليك فعله هو

```
sudo apt-get install emacs
```

### Arch
غالبًا ما يأتي Arch بأحدث إصدار من Emacs، لذا نفّذ:

```
sudo pacman -S emacs
```

وستكون جاهزًا.

### التوزيعات الأخرى
تحقّق من توزيعتك لمعرفة الإصدار الحالي، ثم استخدم مدير الحزم لديك أو ابنِ من المصدر حسب الاقتضاء.

### Windows
لتثبيت Emacs على Windows، توجّه إلى أقرب
[مرآة لأرشيف FTP](https://ftpmirror.gnu.org/emacs/windows)، ونزّل المثبّت (=emacs-XX.X-installer.exe=)، ثم شغّله.
وإذا كنت تريد استخدام Emacs دون تثبيته، يمكنك تنزيل الملف الذي يطابق النمط =emacs-XX.x.zip=، وفكّ ضغطه وتشغيل `bin\runemacs.exe`.

إذا كنت تستخدم [MSYS2](https://www.msys2.org/) فيمكنك تثبيت إصدار 64 بت من Emacs عبر

```
pacman -S mingw-w64-x86_64-emacs
```

أو إصدار 32 بت عبر

```
pacman -S mingw-w64-i686-emacs
```
