# ملحق التعليمات

## صيغة الإخراج

أخرِج كلمات الأغنية على هيئة سلسلة نصية منتهية بمحرف فارغ.

## المسجّلات

| المسجّل | الاستخدام   | النوع   | الوصف                              |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | إدخال        | عدد صحيح | عدد الزجاجات في البداية       |
| `$a1`    | إدخال        | عدد صحيح | عدد الزجاجات التي تُنزَّل      |
| `$a2`    | إدخال/إخراج  | عنوان   | سلسلة الإخراج النصية المنتهية بمحرف فارغ |
| `$t0-9`  | مؤقت         | أي      | للتخزين المؤقت                 |
