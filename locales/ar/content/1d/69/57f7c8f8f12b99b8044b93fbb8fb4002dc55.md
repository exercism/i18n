# نبذة

مطابقة الأنماط هي عملية التفرّع بناءً على مطابقة قيمةٍ ما لأنماطٍ معطاة، قد تكون متداخلة بعمق. في Haxe، تُجرى **مطابقة الأنماط** باستخدام تعبير `switch` وتعبيرات `case` الفردية.

لنلقِ نظرة على بنية البيانات التالية:

```haxe
enum Tree<T> {
  Leaf(v:T);
  Node(l:Tree<T>, r:Tree<T>);
}
```

- تُطابَق الأنماط دائمًا من الأعلى إلى الأسفل.
- النمط الأول الذي يطابق قيمة الإدخال يُنفَّذ تعبيره.
- يطابق نمط `_` أي شيء، لذا فإن `case _:` يكافئ `default:`

## مطابقة التعدادات

يمكن مطابقة التعدادات من خلال المنشئ الخاص بها بشكل طبيعي:

```haxe
var myTree = Node(Leaf("foo"), Node(Leaf("bar"), Leaf("foobar")));

var match = switch (myTree) {
  // Matches any Leaf
  case Leaf(_):
    "0";

  // Matches any Node that has r = Leaf
  case Node(_, Leaf(_)):
    "1";

  // Matches any Node that has
  // r = another Node which has
  // l = Leaf("bar")
  case Node(_, Node(Leaf("bar", _))):
    "2";

  // Matches anything
  case _:
    "3";
}

trace(match); // 2
```
