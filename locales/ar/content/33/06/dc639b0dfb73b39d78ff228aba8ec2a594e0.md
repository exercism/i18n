# نبذة

القائمة [`list`][lists] في F# هي مجموعة غير قابلة للتغيير من صفر أو أكثر من القيم. ويجب أن تكون جميع القيم في القائمة من النوع نفسه. ولأن القوائم غير قابلة للتغيير، فلا يمكن لقيمة القائمة أن تتغير أبدًا بعد إنشائها. ولقائمة F# _رأس_ (العنصر الأول) و_ذيل_ (كل ما يأتي بعد العنصر الأول). وذيل القائمة هو نفسه قائمة.

يمكن تعريف القوائم كما يلي:

```fsharp
let empty = []
let emptyAlternative = List.empty

let singleValue = [5]
let singleValueAlternative = List.singleton 5

let threeValues = ["a"; "b"; "c"]
```

الأسلوب الأكثر شيوعًا لإضافة عنصر إلى قائمة هو عبر العامل `::` (cons):

```fsharp
let twoToFour = [2; 3; 4]
let oneToFour = 1 :: twoToFour
// => [1; 2; 3; 4]
```

يمكن ضمّ القوائم باستخدام العامل `@` أو `List.append`:

```fsharp
[6; 7] @ [8; 9]           // => [6; 7; 8; 9]
List.append [6; 7] [8; 9] // => [6; 7; 8; 9]
```

تُعالَج القوائم بواسطة دوال وعوامل معرَّفة في [وحدة `List`][list-module]. وبعض هذه الدوال متاحة أيضًا كـ[خصائص][list-properties] على نسخة من `list`:

```fsharp
List.length [7; 8] // => 2
[7; 8].Length      // => 2
```

لا يوجد خيار صحيح أو خاطئ هنا. بشكل عام، تنسجم دوال وحدة `List` على نحو أفضل مع استنتاج النوع، في حين تتيح الخصائص كتابة كود أكثر إيجازًا.

أي دوال أو عوامل تبدو وكأنها تعدّل القائمة (مثل إضافة عنصر) فإنها في الواقع تُرجع قائمة جديدة. ومع ذلك، لا يمثل الأداء مشكلة عادةً، لأن تنفيذ القوائم يمنع عمليات التخصيص والنسخ غير الضرورية.

وبما أن القوائم مُنفَّذة كقوائم مترابطة أحادية الاتجاه، فإن إضافة عنصر في البداية (باستخدام العامل `::`) سريعة جدًا، بينما الوصول إلى عنصر عبر الفهرس قد يكون بطيئًا نسبيًا.

يمكن أيضًا معالجة القوائم باستخدام مطابقة الأنماط عبر نمطي [_list_][list-pattern] و[_cons_][cons-pattern]:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [ 1 ] -> "Singleton list with 1"
    | head::tail -> sprintf "Non-empty list with head: %d" head

describe []        // => "Empty list"
describe [1]       // => "Singleton list with 1"
describe [5; 7; 9] // => "Non-empty with head: 5"
```

يمكنك أيضًا _تجاهل_ قيمة عند مطابقة الأنماط؛ فعندما _لا_ تهتم بقيمة في حالة معينة (أي أنك لن _تستخدم_ القيمة) يمكنك استخدام شرطة سفلية (`'_'`) للإشارة إلى ذلك:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [x] -> "List with one item"
    | [_; y] -> "List with two items (first item ignored)"
    | _ -> "List with many items (all items ignored)"

describe []        // => "Empty list"
describe [1]       // => "List with one item"
describe [5; 7]     // => "List with two items (first item ignored)"
describe [5; 7; 9] // => "List with many items (all items ignored)"
```

يجب أن تأتي `'_'` الواحدة دائمًا في _الموضع الأخير_ عند مطابقة الأنماط، وأي قيمة _لا_ تطابق أيًّا من الحالات الأخرى ستتولّى هذه الحالة معالجتها.
