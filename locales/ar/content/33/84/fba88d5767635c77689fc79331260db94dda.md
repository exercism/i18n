# التعليمات

إنه الموسم الختامي في النادي المحلي. أنت تدير لوحة المتصدرين عند خط النهاية: المتسابقون يعبرون بالترتيب، والممرات تحتاج إلى لافتات، ويجب تدوين السجل الرسمي قبل الشوط التالي.

تصل أسماء المتسابقين في مصفوفة، بترتيب الوصول: فالاسم ذو الفهرس 0 هو الفائز، والاسم ذو الفهرس 1 هو الوصيف، وهكذا.

## 1. تعيين أرقام الصدر

عرّف `assign-bibs` لتأخذ مصفوفة من أسماء المتسابقين وتُرجع مصفوفة من الأزواج `{ position name }`، بحيث يأتي الموضع أولًا.

```factor
{ "Bolt" "Comet" "Spirit" } assign-bibs .
! => { { 0 "Bolt" } { 1 "Comet" } { 2 "Spirit" } }
```

## 2. لافتات الممرات

عرّف `lane-labels` لتأخذ مصفوفة من أسماء المتسابقين وتُرجع سلاسل نصية مثل `"Lane 0: Bolt"`.

```factor
{ "Bolt" "Comet" } lane-labels .
! => { "Lane 0: Bolt" "Lane 1: Comet" }
```

## 3. وسم المتسابقين

عرّف `tag-racers` لتأخذ مصفوفة من أسماء المتسابقين *و* سلسلة نصية للوسم، وتُرجع لافتات بالصيغة `"<tag>/<index>: <name>"`. تُدمج الوسمة نفسها في كل لافتة.

```factor
{ "Bolt" "Comet" } "Green" tag-racers .
! => { "Green/0: Bolt" "Green/1: Comet" }
```

## 4. تدوين نتائج الوصول

عرّف `record-finishes` لتأخذ مصفوفة من أسماء المتسابقين وسجلًا (متجهًا). ولكل متسابق، أضف سلسلة نصية بالصيغة `"<index>: <name>"` إلى السجل في مكانه. ولا تُرجع شيئًا.

```factor
V{ } clone   ! a fresh empty ledger
{ "Bolt" "Comet" } over record-finishes
.
! => V{ "0: Bolt" "1: Comet" }
```

## 5. أجراس اللفات

عرّف `lap-bells` لتأخذ عددًا `laps` وتُرجع سلسلة نصية مكوّنة من `"ding "` مكرّرة `laps` مرة.

```factor
0 lap-bells .   ! => ""
3 lap-bells .   ! => "ding ding ding "
```
