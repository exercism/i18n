# ملحق التعليمات

## عوامل الأعداد المركبة

تدعم الدوال الحسابية الاستدعاء العادي للدوال، والإرسال الساكن (أي صيغة استدعاء الطريقة)، والعوامل:

| استدعاء الدالة | استدعاء الطريقة | العامل |
| --- | --- | --- |
| `plus(z1, z2)` | `z1.plus(z2)` | `z1 + z2` |
| `minus(z1, z2)` | `z1.minus(z2)` | `z1 - z2` |
| `times(z1, z2)` | `z1.times(z2)` | `z1 * z2` |
| `div_by(z1, z2)` | `z1.div_by(z2)` | `z1 / z2` |
