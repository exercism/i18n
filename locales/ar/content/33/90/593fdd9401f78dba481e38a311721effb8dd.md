# ملحق التعليمات

## التنفيذ

في هذا التمرين ستُطبّق إجراءً مهمته تخصيص السلسلة النصية التي يُرجعها. وتقع مسؤولية إلغاء تخصيص هذه السلسلة النصية على عاتق من يستدعي الإجراء.

```odin
// The procedure will be called like that:
formatted := format("Gianna", 4)
// ...
// and eventually the caller will delete the string
delete(formatted)
```
