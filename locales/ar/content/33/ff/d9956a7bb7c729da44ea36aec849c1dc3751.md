# الاختبارات

لتنزيل تمرين، مثل `hello-world`، افتح الطرفية وشغّل:

```bash
exercism download --track roc --exercise hello-world
```

ثم انتقل إلى مجلد التمرين وعدّل الكود لحل التمرين. على سبيل المثال:

```bash
cd {your Exercism folder}/roc/hello-world
edit HelloWorld.roc
```

يأتي كل تمرين مصحوبًا بمجموعة اختبارات. يمكنك تشغيل الاختبارات باستخدام الأمر `roc test`، على سبيل المثال:

```
roc test hello-world-test.roc
```

إذا كنت قد حللت التمرين، فمن المفترض أن ترى 0 اختبار فاشل، على سبيل المثال:

```
All (5) tests passed in 123.4 ms.
```

لكن إذا كان في الكود أي أخطاء، فستبدو هكذا:

```
── EXPECT FAILED in hello-world-test.roc ───────────────────────────────────────

This expectation failed:

6│  expect hello == "Hello, World!"
    ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^


1 failed and 0 passed in 123.4 ms.
```

سيساعدك هذا على إصلاح الكود. وعندما يعمل الكود، يمكنك إرساله باستخدام الأمر `exercism submit` (راجع `HELP.md` في مجلد التمرين لمزيد من التفاصيل).
