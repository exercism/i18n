# حول

البروتوكولات هي:

- آلية لتحقيق تعدد الأشكال.
- تُعرَّف باستخدام [`defprotocol`][defprotocol].
- تُنفَّذ لنوع بيانات معيّن باستخدام [`defimpl`][defimpl].

من أكبر مزايا البروتوكولات أن تنفيذ بروتوكولٍ ما لنوع بيانات معيّن لا يلزم أن يُرفَق مع تعريف نوع البيانات ولا مع تعريف البروتوكول. وهذا يتيح كتابة مكتبات يستطيع مستخدموها توسيعها بسهولة لتتعامل مع أنواع البيانات المخصّصة التي يستخدمونها، دون الحاجة إلى تعديل المكتبة.

## التنفيذ

من الممكن تنفيذ البروتوكولات لجميع أنواع Elixir: `Tuple`، و`Atom`، و`List`، و`BitString`، و`Integer`، و`Float`، و`Function`، و`PID`، و`Map`، و`Port`، و`Reference`، و`Any`، والبنى (structs).

يمكن تنفيذ البروتوكولات لعدة أنواع في وقت واحد:

```elixir
defimpl Reversible, for: [Map, List] do
  def reverse(term) do
    Enum.reverse(term)
  end
end
```

عند تنفيذ بروتوكول لبنية مباشرةً داخل الوحدة التي تعرّفها، يمكن حذف الوسيط `:for`:

```elixir
defmodule ShoppingCart do
  defstruct [:items]

  defimpl Reversible do
    def reverse(shopping_cart) do
      Enum.reverse(shopping_cart)
    end
  end
end
```

## الرجوع الاحتياطي إلى `Any`

بشكل افتراضي، يؤدي استدعاء بروتوكول لنوع بيانات لم يُنفَّذ من أجله إلى رفع خطأ `Protocol.UndefinedError`:

```elixir
to_string({})
# => ** (Protocol.UndefinedError) protocol String.Chars not implemented for {} of type Tuple
#        (elixir 1.10.3) lib/string/chars.ex:3: String.Chars.impl_for!/1
#        (elixir 1.10.3) lib/string/chars.ex:22: String.Chars.to_string/1
```

يمكن تجنّب ذلك بتوفير تنفيذ احتياطي يُستخدَم في مثل هذه الحالة. لفعل ذلك، اضبط سمة الوحدة [`@fallback_to_any`][fallback-to-any] على `true` عند تعريف البروتوكول، واكتب تنفيذًا للنوع `Any`:

```elixir
defprotocol Reversible do
  @fallback_to_any true
  def reverse(term)
end

defimpl Reversible, for: Any do
  def reverse(term) do
    term
  end
end
```

لاحظ أنه في معظم الحالات يكون رفع خطأ هو الأسلوب المفضّل، لأنه من الصعب افتراض سلوك معقول لبروتوكولٍ يشمل _جميع_ أنواع البيانات.

## بروتوكولات مدمجة جديرة بالملاحظة

- [`Enumerable`][enumerable] - دوال الوحدتين `Enum` و`Stream` تعمل مع أنواع البيانات التي تنفّذ هذا البروتوكول.
- [`Collectable`][collectable] - تستخدم الدالة [`Enum.into/2`][enum-into] هذا البروتوكول لإدراج قيمة قابلة للتعداد في مجموعة.
- [`Inspect`][inspect] - يمكنك تنفيذ هذا البروتوكول لتغيير الطريقة التي تمثّل بها [`Kernel.inspect/2`][kernel-inspect] نوع بيانات معيّنًا على هيئة سلسلة نصية.
- [`String.Chars`][string-chars] - يمكنك تنفيذ هذا البروتوكول لتغيير الطريقة التي تمثّل بها [`Kernel.to_string/1`][kernel-to-string] نوع بيانات معيّنًا على هيئة سلسلة نصية.
