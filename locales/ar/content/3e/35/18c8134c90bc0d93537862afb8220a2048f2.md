# مقدمة

يمكن فهم الواجهة على أنها توقيع الصنف، لأنها تصف الحقول العامة فيه. والصنف _يُطبّق_ `interface` باستخدام الكلمة المفتاحية `implments`.

تشبه صياغتها صياغة الصنف كثيرًا، إلا أن الطرق تظهر فيها كتوقيعات دون أجسام:

```haxe
interface Language {
  private var languageName:String;

  public function speak():String;
}

class FrenchSpeaker implements Language {
  var languageName = "French";

  public function speak():String {
    return "Bonjour!";
  }
}
```

الحقول التي تُطبَّق من واجهة **يجب** أن تستخدم دائمًا نفس مُعدِّل الوصول. على سبيل المثال، إذا كان المتغير `a` معرَّفًا بـ `public` في واجهة، وجب أن يكون تنفيذه هو أيضًا `public`.
