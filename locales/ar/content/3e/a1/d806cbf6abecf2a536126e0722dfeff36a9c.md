# مقدمة

`string` في C# هو كائن يمثّل نصًا غير قابل للتغيير على هيئة تسلسل من محارف يونيكود (حروف وأرقام وعلامات ترقيم وغيرها). تُستخدم علامات الاقتباس المزدوجة لتعريف نسخة من `string`:

```csharp
string fruit = "Apple";
```

نتعامل مع السلاسل النصية باستدعاء طرقها. بمجرد إنشاء سلسلة نصية، لا يمكن أن تتغيّر قيمتها أبدًا. وأي طرق تبدو وكأنها تعدّل السلسلة النصية ستُرجع في الواقع سلسلة نصية جديدة.

يمكن دمج عدة سلاسل نصية (جمعها) معًا. وأبسط أسلوب للقيام بذلك هو استخدام العامل `+`.

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

لأي تنسيق للسلاسل النصية أكثر تعقيدًا من الدمج البسيط، يُفضّل استخدام إقحام السلاسل النصية. ولاستخدام الإقحام في سلسلة نصية، اسبقها بعلامة الدولار (`$`). بعد ذلك يمكنك استخدام الأقواس المعقوفة (`{}`) للوصول إلى أي متغيرات داخل السلسلة النصية.

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
