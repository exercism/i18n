# الاختبارات

إذا نزّلت تمرينًا باستخدام أداة واجهة سطر الأوامر، فسترى ملف Uiua يحمل اسم التمرين وملف `tests.ua`.
يحتوي هذا الملف على جميع حالات الاختبار، وهي مطابقة لتلك التي يشغّلها مشغّل الاختبارات عند رفع حلّك.
لا تتردد في إضافة حالات اختبار إضافية للتجربة.
ومع ذلك، لا يؤثر تعديل الاختبارات في عملية مشغّل الاختبارات على الإنترنت.

## الاختبار محليًا

لتشغيل اختبارات تمرين ما، افتح الطرفية في مجلد التمرين ونفّذ الأمر `uiua test tests.ua`.

على سبيل المثال، قد يبدو ناتج تمرين `hello-world` غير المعدَّل هكذا:

```bash
$ uiua test tests.ua
Error: Goodbye, Mars!
  at tests.ua:3:1
3 | ⍤⤙≍ "Hello, World!" Hello
    ─
Test failed
```

يعرض سطر `Error` الناتج الفعلي للكود.
ويشير رقم السطر إلى موضع النتيجة المتوقعة في `tests.ua`.
وينتج الحل الصحيح:

```bash
$ uiua test tests.ua
Test passed
```
