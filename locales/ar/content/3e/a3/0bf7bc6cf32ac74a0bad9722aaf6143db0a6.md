# مقدمة إلى المصفوفات

يوفّر Bash نوعين من المعاملات: القيم «القياسية» والمصفوفات.
ويمكن أن تكون القيمة القياسية سلسلة نصية أو عددًا، وهي تمثّل «شيئًا» واحدًا.

في معظم الأحيان تكفي القيم القياسية لاحتواء بياناتك.
لكنك تحتاج أحيانًا إلى تخزين قائمة من القيم القياسية.
في هذه الحالة ستستخدم _مصفوفة_.

هناك نوعان من المصفوفات:

* المصفوفات المفهرسة رقميًا تربط مفتاحًا صحيحًا بقيمة نصية.
  (قد تسمّيها لغات أخرى «قائمة» أو «تسلسلًا».)
* المصفوفات الترابطية تربط مفتاحًا من نوع سلسلة نصية بقيمة من نوع سلسلة نصية.
  (قد تسمّيها لغات أخرى «خريطة» أو «قاموسًا».)

ستتناول الأقسام الأولى من هذا المستند المصفوفات المفهرسة رقميًا (وسنسميها فيما بعد ببساطة «المصفوفات»).
وستظهر تفاصيل المصفوفات الترابطية في النهاية.

~~~~exercism/caution
لا تستطيع مصفوفات Bash تخزين _سوى_ القيم القياسية.
ولا توجد إمكانية لإنشاء مصفوفة ثنائية الأبعاد (مصفوفة من المصفوفات).
~~~~

## تعريف متغير مصفوفة وتهيئته

يمكنك تهيئة مصفوفة بإسناد قائمة من العناصر بين قوسين هلاليين (وقد تكون فارغة) إلى متغير.

```bash
myarray=("one" "two" "three")
```

وكما هي الحال في كل إسناد لمتغير، يجب ألا تكون هناك مسافات حول علامة التساوي.

لاحظ أنه لا توجد فواصل بين العناصر، فهي قائمة من السلاسل النصية مفصولة بمسافات.

بل إن مقدار المسافات داخل الأقواس الهلالية أمر متروك تمامًا.
يُسمح بالأسطر الجديدة، فاستخدم منها ما تشاء لتحسين قابلية القراءة.

```bash
myarray=(
    "first element"
    "second element"
    "this is the last element"
)
```

إسناد قائمة من السلاسل النصية إلى متغير مصفوفة بهذه الطريقة سيخزّن السلسلة الأولى عند الفهرس صفر، والتالية عند الفهرس واحد، والتي بعدها عند الفهرس اثنين، وهكذا.

ويمكن تهيئة «مصفوفة متفرقة» بتحديد الفهارس التي تحتاجها.

```bash
raindrops=([3]="Pling" [5]="Plang [7]="Plong")
```

~~~~exercism/note
للتذكير: فهارس المصفوفة تبدأ من الصفر.
تُخرج هذه القطعة «true»:

```bash
myarray=("one" "two" "three")
[[ "${myarray[0]}" == "one" ]] && echo true || echo false
```
~~~~

يمكنك استخدام الأمر `declare` (أو `local` داخل دالة) لتحديد أن متغيرًا ما سيحمل مصفوفة.

```bash
declare -a myarray
```

والأسلوب الأكثر شيوعًا هو الاكتفاء بإسناد قائمة بين قوسين هلاليين (قد تكون فارغة) لتهيئة المتغير.

## الوصول إلى عناصر المصفوفة

كما رأيت في الملاحظة أعلاه، صيغة الوصول إلى عنصر في المصفوفة هي `${myarray[$index]}`.
ويُكتب الفهرس بين قوسين مربعين.
والأقواس المعقوفة ضرورية.

~~~~exercism/note
في المصفوفات المفهرسة رقميًا، يكون الفهرس تعبيرًا حسابيًا.
يذكر [دليل Bash][arithmetic]:

> يمكن أيضًا، داخل تعبير حسابي، الإشارة إلى متغيرات الصدفة بالاسم دون استخدام صيغة توسيع المعاملات.

وهذا يعني أن `$` ليس ضروريًا لتوسيع المتغيرات «البسيط».
ويمكنك الوصول إلى العناصر هكذا، وهو أسهل قليلًا في القراءة:

```bash
i=5
echo "${myarray[i]}"
# ..............^
```

[arithmetic]: https://www.gnu.org/software/bash/manual/bash.html#Shell-Arithmetic
~~~~

إذا لم يكن الفهرس المعطى موجودًا في المصفوفة، فستكون نتيجة التوسيع سلسلة نصية فارغة.

## الإسناد إلى مصفوفة

لإسناد قيمة إلى عنصر معين في المصفوفة، استخدم هذه الصيغة:

```bash
myarray[10]="hello"
```

وللإلحاق بمصفوفة، استخدم معامل الإسناد والدمج `+=` مع الأقواس الهلالية:

```bash
myarray+=("new element 1" "new element 2")
```

## التكرار عبر المصفوفة

ستحتاج عادةً إلى التكرار عبر _قيم_ المصفوفة.
استخدم حلقة `for` (التي رأيتها في مفهوم [الحلقات][looping]):

```bash
myarray=("one" "two" "three")
for value in "${myarray[@]}"; do
    echo "$value"
done
```

لاحظ الصيغة الخاصة لتوسيع المصفوفة: `"${myarray[@]}"`
هذا الشكل من توسيع المعاملات يستبدل قيم المصفوفة ككلمات منفصلة.
وهو مكافئ إلى حد ما لـ:

```bash
for value in "${myarray[0]}" "${myarray[1]}" ... "${myarray[n]}"
```

تعمل صيغة `"${myarray[@]}"` مع المصفوفات المتفرقة، إذ تتوسع إلى القيم المعرّفة فقط.

هذا التوسيع الخاص، حيث يكون الفهرس هو الرمز `@`، لا يكون خاصًا إلا داخل علامات الاقتباس المزدوجة.

#### توسيعات خاصة أخرى للمعاملات

إليك بضعة أجزاء أخرى من الصيغة الخاصة التي نحتاجها للتكرار عبر المصفوفة.
وهي موصوفة في الدليل ضمن [توسيع معاملات الصدفة][man-expn].

لمعرفة _طول_ المصفوفة، استخدم `${#myarray[@]}` مع علامة `#` قبل الاسم.
و«طول» المصفوفة يعني عدد عناصرها.

ولاستخراج قائمة _فهارس_ المصفوفة، استخدم `"${!myarray[@]}"` مع علامة `!` قبل الاسم ووضع التوسيع بين علامتي اقتباس مزدوجتين.
وفي المصفوفات المفهرسة رقميًا، تُوسَّع الفهارس بترتيب عددي.

### التكرار عبر فهارس المصفوفة

تحتاج أحيانًا إلى الفهرس إلى جانب القيمة.
وهناك طريقتان لفعل ذلك.

1. عندما تعرف أن الفهارس تشكّل تسلسلًا غير منقطع، يمكنك استخدام حلقة `for` _حسابية_.

   ```bash
   for ((i = 0; i < ${#myarray[@]}; i++)); do
       echo "$i -> ${myarray[i]}"
   done
   ```

   لاحظ صيغة `${#myarray[@]}` مع وجود الحرف `#` قبل اسم المصفوفة.
   ولأن المصفوفات تستخدم فهرسة تبدأ من الصفر، فإن آخر فهرس في المصفوفة يقل بواحد عن طولها.

2. عندما تكون المصفوفة متفرقة، يمكنك استخدام هذا الشكل:

   ```bash
   for index in "${!raindrops[@]}"; do
       echo "$index -> ${raindrops[index]}"
   done
   ```

   لاحظ صيغة `${!myarray[@]}` مع وجود الحرف `!` قبل اسم المصفوفة.

## فحص المصفوفة

إذا أردت الاطلاع على محتويات مصفوفة، فاستخدم الأمر `declare` مع الخيار `-p`:

```bash
a=("the 'first' element"
   second
   third
   'the "last" element')
declare -p a
```

وهذا يُخرج المحتويات بصيغة اقتباس الصدفة القياسية.

```bash
declare -a a=([0]="the 'first' element" [1]="second" [2]="third" [3]="the \"last\" element")
```

## المصفوفات الترابطية

للتذكير، تستخدم المصفوفات الترابطية سلاسل نصية للفهارس وليس أعدادًا.
وكل ما كُتب أعلاه ينطبق على المصفوفات الترابطية، لكن مع اختلافات صغيرة.
وبوجه عام، نستخدم مصطلح «مفتاح» لا «فهرس»، فالمصفوفات الترابطية تربط المفاتيح بالقيم.

### تعريف مصفوفة ترابطية

على عكس المصفوفات، **يجب** تعريف المصفوفات الترابطية.
استخدم الخيار `-A` مع `declare` (أو `local` داخل دالة):

```bash
declare -A mymap

myfunc() {
    local -A my_local_map
    # ...
}
```

### تهيئة مصفوفة ترابطية

تُحدَّد أزواج المفتاح والقيمة داخل القائمة المحصورة بين قوسين هلاليين:

```bash
mymap=([first]=foo [second]=bar [third]=baz)
declare -p mymap
```

وهذا يُخرج:

```
declare -A mymap=([second]="bar" [first]="foo" [third]="baz")
```

~~~~exercism/note
انتبه إلى أن المصفوفات الترابطية **غير مرتبة**.
~~~~

ويمكن أن يحدث التعريف والتهيئة في سطر واحد.

```bash
declare -A mymap=([first]=foo [second]=bar [third]=baz)
```

وفي إصدارات Bash الحديثة، يمكن أن تستخدم التهيئة قائمة بالشكل `(key value key value ...)`.

```bash
declare -A mymap=(first foo second bar third baz)
```

### الوصول إلى القيم

تُستخدم الصيغة نفسها السابقة للوصول إلى العناصر: `${mymap[$key]}`.

لا تُقيَّم مفاتيح المصفوفات الترابطية في سياق حسابي.
بل يلزم استخدام صيغة توسيع المعاملات المعتادة.

### الإسناد إلى مصفوفة ترابطية

يستخدم الإسناد الصيغة نفسها السابقة:

```bash
mymap[$key]="$value"
```

### التكرار

يمكنك استخدام حلقة `for value in "${mymap[@]}"` للتكرار.
غير أنك تحتاج عادةً أيضًا إلى المفتاح بجانب القيمة.

استخدم صيغة `"${!mymap[@]}"` التي رأيناها أعلاه.

```bash
for key in "${!mymap[@]}"; do
    echo "$key -> ${mymap[$key]}"
done
```

وهذا يُخرج

```
second -> bar
first -> foo
third -> baz
```

وللتأكيد مجددًا، لا يوجد ترتيب للمفاتيح.
