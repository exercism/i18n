# ملحق التعليمات

## السجلات

| السجل | الاستخدام | النوع | الوصف |
| ------ | --------- | ----- | ----- |
| `$a0`  | مدخل      | عدد صحيح | الضلع a |
| `$a1`  | مدخل      | عدد صحيح | الضلع b |
| `$a2`  | مدخل      | عدد صحيح | الضلع c |
| `$v0`  | مخرج      | عدد صحيح | نوع المثلث (`0` = مختلف الأضلاع، `1` = متساوي الساقين، `2` = متساوي الأضلاع، `3` = غير صالح) |
| `$t0-9` | مؤقت      | أي شيء   | يُستخدم للتخزين المؤقت |
