# التعليمات

في هذا التمرين ستعمل على جدولة المواعيد في صالون تجميل.

لديك ثلاث مهام، وكلها تتعلق بتواريخ المواعيد.

## 1. تحقق مما إذا كان الموعد قد مضى

نفّذ الروتين الفرعي `appointment_has_passed` الذي يأخذ سلسلة نصية تمثّل تاريخًا ويتحقق مما إذا كان الموعد في وقت ما في الماضي:

```perl
appointment_has_passed("2019-07-25T13:45:00")
// => true
```

ستُمرَّر سلاسل التواريخ بصيغة ISO 8601 للتاريخ والوقت: `YYYY-mm-ddTHH:MM:SS`

ستحتاج إلى تنفيذ الروتين الفرعي الخاص `_parse_datetime`.
نقترح عليك وحدتين:

- [Time::Piece][time-piece] وحدة أساسية في Perl.
- [DateTime::Tiny][datetime-tiny] متاحة من CPAN.

## 2. تحقق مما إذا كان الموعد بعد الظهر

نفّذ الدالة `is_afternoon_appointment` التي تأخذ سلسلة نصية تمثّل تاريخًا وتتحقق مما إذا كان الموعد بعد الظهر (>= 12:00 و < 18:00):

```perl
is_afternoon_appointment("2019-07-25T13:45:00")
// => true
```

## 3. صِف وقت الموعد وتاريخه

نفّذ الدالة `describe_appointment` التي تأخذ سلسلة نصية تمثّل تاريخًا وتُرجع وصفًا لذلك التاريخ والوقت:

```perl
describe_appointment("2019-07-25T13:45:00")
// => "You have an appointment on 07/25/2019 1:45 PM"
```

لاحظ أن الساعة تقع في النطاق 0-12 ولا تحتوي على صفر أو مسافة في البداية.

[time-piece]: https://perldoc.perl.org/Time::Piece
[datetime-tiny]: https://metacpan.org/pod/DateTime::Tiny
