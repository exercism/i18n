# مقدمة

سيطلب منك مسار Julia بأكمله أن تتعامل مع حلّك كأنه مكتبات صغيرة، أي أنك ستحتاج إلى تعريف دوال وأنواع وغيرها، ثم تُشغَّل هذه مقابل مجموعة اختبارات.
لهذا السبب، سنقدّم الدوال المُسمّاة كأول مفهوم على الإطلاق.

Julia لغة برمجة ديناميكية قوية الأنواع.
أسلوب البرمجة فيها وظيفي في الأساس، وإن كان أكثر مرونة ممّا هو عليه في لغات مثل Haskell.

## المتغيرات والإسناد

لا حاجة للإعلان عن متغير مسبقًا.
يكفي أن تُسند قيمة إلى اسم مناسب:

```julia-repl
julia> myvar = 42  # an integer
42

julia> name = "Maria"  # strings are surrounded by double-quotes ""
"Maria"
```

## الثوابت

إذا احتجت أن تكون قيمة متاحة في كل البرنامج، لكن لا يُتوقّع أن تتغيّر، فمن الأفضل تعليمها كثابت.

بدء الإسناد بالكلمة المفتاحية `const` يسمح للمترجم بتوليد كود أكثر كفاءة ممّا هو ممكن للمتغير.

تساعدك الثوابت أيضًا على الحماية من الأخطاء البرمجية.
محاولة تغيير قيمة `const` عن غير قصد ستُصدر تحذيرًا:

```julia-repl
julia> const answer = 42
42

julia> answer = 24
WARNING: redefinition of constant Main.answer. This may fail, cause incorrect answers, or produce other errors.
24
```

لاحظ أنه لا يمكن تعريف `const` إلا *خارج* أي دالة.
سيكون هذا عادةً قرب أعلى ملف `*.jl`، قبل تعريفات الدوال.

## العوامل الحسابية

هذه هي نفسها في لغات أخرى كثيرة:

```julia
2 + 3  # 5 (addition)
2 - 3  # -1 (subtraction)
2 * 3  # 6 (multiplication)
8 / 2  # 4.0 (division with floating-point result)
8 % 3  # 2 (remainder)
```

## الدوال

هناك طريقتان شائعتان لتعريف دالة مُسمّاة في Julia:

1. باستخدام الكلمة المفتاحية `function`

    ```julia
    function muladd(x, y, z)
        x * y + z
    end
    ```

    الإزاحة بأربع مسافات عُرف متّبع لتحسين القراءة، لكن المترجم يتجاهلها.
    الكلمة المفتاحية `end` ضرورية.

    لاحظ أنه كان بإمكاننا كتابة `return x * y + z`.
    لكن دوال Julia تُرجع دائمًا آخر تعبير يُقيَّم، لذا فإن الكلمة المفتاحية `return` اختيارية.
    يفضّل كثير من المبرمجين تضمينها لجعل نواياهم أكثر وضوحًا.

2. باستخدام "صيغة الإسناد"

    ```julia
    muladd(x, y, z) = x * y + z
    ```

    تُستخدم هذه في الغالب لصنع دوال موجزة ذات تعبير واحد.

    لا تُستخدم الكلمة المفتاحية `return` *أبدًا* في صيغة الإسناد.

الصيغتان متكافئتان، وتُستخدمان بالطريقة نفسها تمامًا، فاختر أيّهما أكثر قابلية للقراءة.

استدعاء دالة يتم بتحديد اسمها وتمرير وسائط لكل معامل من معاملات الدالة:

```julia
# invoking a function
muladd(10, 5, 1)

# and of course you can invoke a function within the body of another function:
square_plus_one(x) = muladd(x, x, 1)
```

## اصطلاحات التسمية

مثل لغات كثيرة، تشترط Julia أن تبدأ الأسماء (أسماء المتغيرات والدوال وأشياء أخرى كثيرة) بحرف، يتبعه أي مزيج من الحروف والأرقام والشرطات السفلية.

بحسب الاصطلاح، تُكتب أسماء المتغيرات والثوابت والدوال *بأحرف صغيرة*، مع إبقاء الشرطات السفلية عند حد أدنى معقول.
