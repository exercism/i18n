# التعليمات

إليز، الساحرة الناشئة، تواصل تدريبها. ستُعطى عدة أكوام من البطاقات تحتاج إليها لأداء حِيَلها. ولتسهيل الأمور قليلًا، تستخدم البطاقات من 1 إلى 10 فقط.

في هذا التمرين، استخدم الطرق المدمجة لتحليل محتويات مصفوفة.

## 1. إيجاد موضع بطاقة

تريد إليز معرفة موضع بطاقة في الكومة (فهرسها).

```javascript
const card = 2;
getCardPosition([9, 7, 3, 2], card);
// => 3
```

## 2. تحديد ما إذا كانت بطاقة موجودة

تريد إليز تحديد ما إذا كانت بطاقة موجودة في الكومة، بعبارة أخرى، ما إذا كانت الكومة تحتوي على `number` محدد.

```javascript
const card = 3;
doesStackIncludeCard([2, 3, 4, 5], card);
// => true
```

## 3. تحديد ما إذا كانت كل بطاقة زوجية

تريد إليز معرفة ما إذا كانت كل بطاقة زوجية، بعبارة أخرى، ما إذا كان كل `number` في الكومة عددًا زوجيًا.

```javascript
isEachCardEven([2, 4, 6, 7]);
// => false
```

## 4. التحقق مما إذا كانت الكومة تحتوي على بطاقة بقيمة فردية

تريد إليز معرفة ما إذا كان في الكومة عدد فردي.

```javascript
doesStackIncludeOddCard([3, 2, 6, 4, 8]);
// => true
```

## 5. الحصول على أول بطاقة فردية من الكومة

تريد إليز معرفة قيمة أول بطاقة فردية.

```javascript
getFirstOddCard([4, 2, 8, 7, 9]);
// => 7
```

## 6. تحديد موضع أول بطاقة زوجية

تريد إليز معرفة موضع أول بطاقة زوجية.

```javascript
getFirstEvenCardPosition([5, 2, 3, 1]);
// => 1
```
