# حلقات `for`

التكرار مفهوم أساسي في البرمجة، فهو يتيح لك تنفيذ كتلة من الكود عدة مرات.
في Swift، هناك نوعان من الحلقات: حلقات [`for-in`][for-loops] وحلقات `while`.
في هذا الفصل، ستتعرّف على حلقات `for-in`.

تتيح لك حلقات `for` التكرار على تسلسل من القيم، بحيث تأخذ كل عنصر بدوره وتربطه بمتغير تختاره بنفسك.
تتيح لك Swift التكرار على تشكيلة من التسلسلات، مثل المديات والمصفوفات والسلاسل النصية (وأنواع أخرى سنتناولها لاحقًا).
وعندما يتم التكرار على كل عنصر في التسلسل، تنتهي الحلقة.

تُعرَّف حلقات `for` باستخدام الكلمة المفتاحية `for`، تليها اسم متغير، ثم الكلمة المفتاحية `in`، ثم تسلسل من القيم المراد التكرار عليها.
المتغير المعطى في حلقة `for-in` غير قابل للتغيير، أي أنه لا يمكنك تغيير قيمته داخل الحلقة.
إليك مثالًا على حلقة `for-in` تكرّر على مصفوفة من الأعداد:

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
  print(number)
}
print("Done with numbers")

// prints:
// 3
// 10
// 7
// 11
// Done with numbers
```

~~~~exercism/note
المتغير `number` مُعرَّف داخل حلقة `for-in`، وهو متاح فقط ضمن نطاق الحلقة.

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
    number + 1
}
number + 1
// Error: Use of unresolved identifier 'number'
```
~~~~

## التكرار على مدى

يمكنك أيضًا التكرار على مدى من الأعداد باستخدام حلقة `for-in`.
يتيح لك هذا تنفيذ كتلة من الكود عددًا محددًا من المرات، فمثلًا المدى `1...5` سيكرّر على الأعداد 1 و2 و3 و4 و5، وبذلك تُنفَّذ الحلقة 5 مرات.
قد ترغب أحيانًا في التكرار على الفهارس في بنية بيانات مثل مصفوفة، وحينها يمكنك استخدام المدى `0..<array.count`.

```swift
let numbers = [3, 10, 7, 11]

for i in 0..<numbers.count {
  print(numbers[i])
}

// prints:
// 3
// 10
// 7
// 11
```

## التكرار على سلسلة نصية

يمكنك أيضًا التكرار على سلسلة نصية باستخدام حلقة `for-in`.
يتيح لك هذا التكرار على كل حرف في السلسلة النصية، ولاحظ تحديدًا أن النوع المعطى في الحلقة هو `Character`.

```swift
let message = "Hello!"

for character in message {
  print(character)
}

// prints:
// H
// e
// l
// l
// o
// !
```

## المتغيرات غير المستخدمة

إذا لم تكن بحاجة إلى قيمة المتغير في الحلقة، يمكنك استخدام الشرطة السفلية `_` لتجاهلها.

```swift
let numbers = [3, 10, 7, 11]

for _ in numbers {
  print("Hello!")
}
```

## `stride`

توفر Swift أيضًا دالة `stride` تتيح لك إنشاء تسلسل على مدى بخطوة محددة.
ويمكن بعد ذلك التكرار عليه باستخدام حلقة `for-in`.
تُعرَّف `stride` بالصيغتين [`stride(from:to:by:)`][stride-to] أو [`stride(from:through:by:)`][stride-through]، فالصيغة الأولى حصرية والثانية شاملة.

```swift
for i in stride(from: 0, to: 10, by: 2) {
  print(i)
}

// prints:
// 0
// 2
// 4
// 6
// 8
```

لاحظ أن المعامل `to` حصري، لذا ستكرّر الحلقة حتى العدد الذي يسبق المعامل `to`، أما المعامل `through` فهو شامل، وفي هذه الحالة سيضم العدد `10` أيضًا.

[stride-to]: https://developer.apple.com/documentation/swift/stride(from:to:by:)
[stride-through]: https://developer.apple.com/documentation/swift/stride(from:through:by:)
[for-loops]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
