# مقدمة

## المصفوفات

توفّر مكتبة Cairo الأساسية نوع `Array`.

وهو مشابه لأنواع المصفوفات المعتادة في لغات البرمجة الأخرى، لكن مع بعض الاختلافات الجوهرية:

- يمكن إضافة العناصر بكفاءة إلى مؤخرة نوع `Array` فقط، ولا يمكن إزالتها بكفاءة إلا من مقدمته.
- من المستحيل تعيين عنصر يدويًا باستخدام فهرس المصفوفة.

يمكن إنشاء المصفوفات باستخدام دالة `ArrayTrait::new` وكذلك ماكرو `array!`:

```rust
let empty: Array<u32> = ArrayTrait::new();
let one_to_four = array![1, 2, 3, 4];
```

يمكن إضافة عناصر إلى المصفوفة باستخدام دالة `ArrayTrait::append`:

```rust
let mut num_array = array![1, 2, 3, 4];
num_array.append(5);
// -> [1, 2, 3, 4, 5]
```

يمكن إزالة عناصر من المصفوفة باستخدام دالة `ArrayTrait::pop_front`:

```rust
let mut one_to_four = array![1, 2, 3, 4];

one_to_four.pop_front();
// -> [2, 3, 4]
```

تقدّم Cairo أيضًا نوع `Span` يتصرّف كلقطة من `Array`.

يمكن تحويل كل `Array` إلى `Span` باستخدام دالة `ToSpanTrait::span`:

```rust
let one_to_four = array![1, 2, 3, 4];
let one_to_four_span = one_to_four.span();
// -> [1, 2, 3, 4]
```

تحويل مصفوفة إلى `Span` فعّال جدًا، لأن `Span` مجرد بنية بيانات تتيح لـ Cairo أن «يطّلع» على قسم من المصفوفة، ولا تعدّلها بأي شكل.

وبتحويل مصفوفة إلى `Span`، تتيح Cairo تنفيذ عمليات أكثر مما هو مسموح به على `Array` مباشرة، مثل إزالة عنصر من مقدمة `Span`.

```rust
let one_to_four = array![1, 2, 3, 4];
let mut one_to_four_span = one_to_four.span();
one_to_four_span.pop_back();
// -> [2, 3, 4]
```

لاحظ أننا اضطررنا إلى جعل `one_to_four_span` قابلًا للتغيير باستخدام الكلمة المفتاحية `mut` حتى نستدعي `pop_back`، وهو ما يعدّل الـ `Span` عبر تقصير القسم الذي «يطّلع» عليه من المصفوفة.
