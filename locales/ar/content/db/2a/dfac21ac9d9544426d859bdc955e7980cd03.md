# التعليمات

يعمل Josh على لعبة تقمّص أدوار جديدة، ويحتاج إلى مساعدتك في تنفيذ بعض آليات اللعبة.

## 1. عرّف بنفسك

نفّذ الدالة `introduce`.

قد يخفي اللاعبون المتخفّون أسماءهم، وسيُعرَّفون باسم `"Mighty Magician"`. وإلا، فاستخدم اسم اللاعب للتعريف به.

```gleam
introduce(Player(name: None, level: 2, health: 8, mana: None))
// -> "Mighty Magician"

introduce(Player(name: Some("Merlin"), level: 2, health: 8, mana: None))
// -> "Merlin"
```

## 2. نفّذ آلية الإحياء

ينبغي أن تتحقق الدالة `revive` من أن شخصية اللاعب ميتة فعلًا (وصلت صحتها إلى 0). وإذا كانت كذلك، فينبغي أن تُرجع نسخة جديدة من `Player` بصحة 100. وإلا، إذا لم تكن شخصية اللاعب ميتة، فإن الدالة `revive` تُرجع `None`.

وإذا كان مستوى اللاعب 10 أو أعلى، فينبغي إحياؤه أيضًا بـ100 من المانا. وإذا كان مستوى اللاعب أقل من 10، فينبغي أن تبقى المانا كما هي دون تغيير. وينبغي أن تحافظ الدالة `revive` على مستوى اللاعب.

```gleam
let dead_player = Player(name: None, level: 2, health: 0, mana: None)

revive(dead_player)
// -> Some(Player(name: None, level: 2, health: 100, mana: None))
```

إذا استُدعيت الدالة `revive` على لاعب صحته 1 أو أكثر، فينبغي أن تُرجع `None`.

```gleam
let alive_player = Player(name: None, level: 2, health: 42, mana: None)

revive(alive_player)
// -> None
```

## 3. نفّذ آلية إلقاء التعاويذ

تأخذ الدالة `cast_spell` كوسائط قيمة `Int` تشير إلى مقدار المانا التي تكلّفها التعويذة، إضافةً إلى `Player`. وتُرجع اللاعب المحدَّث، إضافةً إلى مقدار الضرر الذي تُحدثه التعويذة. يُحدث إلقاء التعويذة الناجح ضررًا يساوي ضعف تكلفة المانا الخاصة بالتعويذة. ومع ذلك، إذا لم يمتلك اللاعب مانا كافية، فلن يحدث شيء، ويبقى اللاعب كما هو، ولا يقع أي ضرر. وإذا لم يكن لدى اللاعب أي مانا على الإطلاق، فإن محاولة إلقاء التعويذة يجب أن تُنقص صحته بمقدار تكلفة المانا الخاصة بالتعويذة، ولا تُحدث أي ضرر. انتبه إلى أن صحة اللاعب لا يمكن أن تكون أقل من صفر (0).

```gleam
let wizard = Player(name: None, level: 18, health: 123, mana: Some(30))
let #(wizard, damage) = cast_spell(wizard, 14)

wizard.mana // -> Some 16
damage      // -> 28
```
