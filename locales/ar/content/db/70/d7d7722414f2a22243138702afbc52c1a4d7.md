# التعليمات

في هذا التمرين ستقوم بنمذجة آلة وزن، بحيث تكون الكيلوغرامات هي الوحدة المستخدمة.

لديك 6 مهام، تتطلب كل واحدة منها تنفيذ خاصية أو أكثر:

## 1. السماح لآلة الوزن بأن تمتلك دقة

لتلبية المتطلبات المختلفة، نسمح بتخصيص كل آلة وزن بدقة معينة (عدد الأرقام بعد الفاصلة العشرية).
نفّذ الصنف `WeighingMachine` بحيث يمتلك خاصية `Precision` للقراءة فقط، تُضبط على وسيط `precision` الخاص بالمُنشئ:

```csharp
var wm = new WeighingMachine(precision: 3);

//  => wm.Precision == 3
```

## 2. السماح بضبط الوزن على آلة الوزن

نفّذ الخاصية `WeighingMachine.Weight` للسماح بقراءة الوزن _و_ ضبطه:

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = 60.5;

//  => wm.Weight == 60.5
```

## 3. التأكد من رفض وزن مُدخل سالب

من الواضح أنه لا يمكن أن يكون وزن شخص ما سالبًا.
أضف تحققًا إلى الخاصية `WeighingMachine.Weight` لترمي استثناء `ArgumentOutOfRangeException` عند محاولة ضبطها على وزن سالب:

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = -10; // Throws an ArgumentOutOfRangeException
```

## 4. السماح بتطبيق تعديل الوزن الفارغ على آلة الوزن

يمكن أن يكون تعديل الوزن الفارغ أي قيمة (حتى قيمة سالبة، أو قيمة تجعل الوزن المعروض سالبًا)
نفّذ الخاصية `WeighingMachine.TareAdjustment` للسماح بضبط تعديل الوزن الفارغ:

```csharp
var wm = new WeighingMachine(precision: 3);
wm.TareAdjustment = -10.6;

// => wm.TareAdjustment == -10.6
```

## 5. التأكد من أن لآلة الوزن تعديل وزن فارغ افتراضيًا

بعد إجراء اختبارات دقيقة، تبيّن أنه بسبب مشكلة في التصنيع، تميل جميع آلات الوزن إلى المبالغة في تقدير الوزن بمقدار `5`.
غيّر الخاصية `WeighingMachine.TareAdjustment` لتكون `5` كقيمة افتراضية لها.

```csharp
var wm = new WeighingMachine(precision: 3);

// => wm.TareAdjustment == 5.0
```

## 6. السماح باسترجاع الوزن

نفّذ الخاصية `WeighingMachine.DisplayWeight` التي يجب أن تُرجع سلسلة نصية تُظهر الوزن بعد تعديل الوزن الفارغ، مع تطبيق الدقة الصحيحة وإضافة الوحدة.
لاحظ أن:
``` display-weight = input-weight - tare-adjustment ```

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = 60.567;
wm.TareAdjustment = 10;

// => wm.DisplayWeight == "50.567 kg"
```
