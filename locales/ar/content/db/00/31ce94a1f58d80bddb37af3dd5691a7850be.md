# مقدمة

تُمثَّل القيم المنطقية في Rust بالنوع `bool`، الذي يمكن لقيمه أن تكون إما `true` أو `false`.

يدعم Rust ستة عوامل مقارنة: `==` (يساوي)، و`!=` (لا يساوي)، و`>` (أكبر من)، و`<` (أصغر من)، و`>=` (أكبر من أو يساوي)، و`<=` (أصغر من أو يساوي). يمكن استخدامها لتقييم العلاقة بين قيم غير منطقية والحصول على قيمة منطقية.

```rust
1 > 0 // true
1 < 0 // false
1 == 0 // false
1 != 0 // true
1 >= 0 // true
1 <= 0 // false
```

على عكس بعض اللغات الأخرى، القيمة `0` ليست `false`، وغير الصفر ليس `true`.

ويدعم Rust عاملين منطقيين: `||` (أو)، و`&&` (و). لا يُقيَّم الطرف الأيمن لهذين العاملين إلا عندما لا يحدد الطرف الأيسر بالفعل نتيجة التعبير. أي أن العامل `||` لا يقيّم طرفه الأيمن إلا عندما تكون قيمة الطرف الأيسر `false`، والعامل `&&` لا يقيّم طرفه الأيمن إلا عندما تكون قيمة الطرف الأيسر `true`.
