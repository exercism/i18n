# تلميحات

## 1. عرّف بنفسك

يجب أن تقوم دالة `introduce` بـ«فك تغليف» القيمة الموجودة في `player.Name`.
فكّر في استخدام دالة [`Options.defaultValue`][defaultvalue] لتحويل `player.Name` إلى قيمته «المغلّفة» عندما تكون `Some`، أو إلى القيمة الافتراضية المطلوبة عندما تكون `None`.

## 2. نفّذ آلية الإحياء

يجب أن تُرجع دالة `revive` إما `Some <player>` أو `None`، حيث `<player>` سجل `Player` ربما مع بعض الحقول المعدّلة.

## 3. نفّذ آلية إلقاء التعاويذ

فكّر في استخدام تعبير مطابقة لتغطية كلتا الحالتين `Some` و`None`، كما في المثال التالي:

```fsharp
let exists (x: int option) =
    match x with
    | Some n -> true
    | None -> false
```

[defaultvalue]: https://learn.microsoft.com/en-us/dotnet/fsharp/language-reference/options#converting-options-with-default-values
