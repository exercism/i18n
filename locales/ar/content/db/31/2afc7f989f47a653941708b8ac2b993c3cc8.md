# التعليمات

في هذا التمرين، مهمتك كتابة البرمجيات لجهاز تشفير يعمل بإجراء تحويلات على البيانات. وتحتاج إلى أسلوب يتيح لك إنشاء دوال معقدة بمرونة عبر دمج دوال أبسط معًا.

لكل مهمة، أرجِع دالة مجهولة يمكن استدعاؤها من نطاق الاستدعاء.

يجب أن تتوقع جميع الدوال وسائط من نوع عدد صحيح. والأعداد الصحيحة مناسبة أيضًا لإجراء عمليات على مستوى البت في Elixir.

## 1. أنشئ دالة جمع

نفّذ `Secrets.secret_add/1`. يجب أن تُرجع دالة تأخذ وسيطًا واحدًا وتضيف إليه الوسيط المُمرَّر إلى `secret_add`.

```elixir
adder = Secrets.secret_add(3)
adder.(2)
# => 5
```

## 2. أنشئ دالة طرح

نفّذ `Secrets.secret_subtract/1`. يجب أن تُرجع دالة تأخذ وسيطًا واحدًا وتطرح السر المُمرَّر إلى `secret_subtract` من ذلك الوسيط.

```elixir
subtractor = Secrets.secret_subtract(2)
subtractor.(3)
# => 1
```

## 3. أنشئ دالة ضرب

نفّذ `Secrets.secret_multiply/1`. يجب أن تُرجع دالة تأخذ وسيطًا واحدًا وتضربه في السر المُمرَّر إلى `secret_multiply`.

```elixir
multiplier = Secrets.secret_multiply(7)
multiplier.(3)
# => 21
```

## 4. أنشئ دالة قسمة

نفّذ `Secrets.secret_divide/1`. يجب أن تُرجع دالة تأخذ وسيطًا واحدًا وتقسمه على السر المُمرَّر إلى `secret_divide`.

```elixir
divider = Secrets.secret_divide(3)
divider.(32)
# => 10
```

استخدم القسمة الصحيحة حتى يكون الناتج متوافقًا مع المُدخل المتوقع للدوال الأخرى.

## 5. أنشئ دالة للعملية البتية `and`

نفّذ `Secrets.secret_and/1`. يجب أن تُرجع دالة تأخذ وسيطًا واحدًا وتُجري عليه عملية `and` البتية مع السر المُمرَّر إلى `secret_and`.

```elixir
ander = Secrets.secret_and(1)
ander.(2)
# => 0
```

## 6. أنشئ دالة للعملية البتية `xor`

نفّذ `Secrets.secret_xor/1`. يجب أن تُرجع دالة تأخذ وسيطًا واحدًا وتُجري عليه عملية `xor` البتية مع السر المُمرَّر إلى `secret_xor`.

```elixir
xorer = Secrets.secret_xor(1)
xorer.(3)
# => 2
```

## 7. أنشئ دالة لدمج الدوال

نفّذ `Secrets.secret_combine/2`. يجب أن تُرجع دالة تأخذ وسيطًا واحدًا وتطبّق عليه الدالتين المُمرَّرتين إلى `secret_combine` بالترتيب.

```elixir
add_one = Secrets.secret_add(1)
multiply_by_2 = Secrets.secret_multiply(2)
combined = Secrets.secret_combine(add_one, multiply_by_2)

combined.(3)
# => 8
```
