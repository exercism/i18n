# التعليمات

لقد أُغرِيت بالعودة إلى Hyperia (ذات التضخم المرتفع) مقابل أجر يومي باهظ.

يدرس البنك المركزي إدخال الدولار الأمريكي كعملة ثانية، لذا يجب تكييف جميع الأنظمة المحاسبية للتعامل مع عملات متعددة.

طُلب منك تنفيذ كائن مبلغ العملة.

## 1. تمكين التحقق من تساوي مبلغ العملة

يُرجى تعديل struct ‏`CurrencyAmount` للتعامل مع التساوي. إذا لم يكن لكل من كائني struct مبلغ العملة العملةُ نفسها ("USD" أو "HD")، فيجب رمي نسخة من `ArgumentException`.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
CurrencyAmount amountB = new CurrencyAmount(55, "HD");
CurrencyAmount amountC = new CurrencyAmount(55, "USD");
amountA == amountB
// => true
amountA != amountB
// => false
amountA == amountC
// => ArgumentException
amountA != amountC
// => ArgumentException
```

## 2. مقارنة مبالغ العملة

يُرجى تعديل struct ‏`CurrencyAmount` للتعامل مع المقارنات (فقط `>` و `<`). إذا لم يكن لكل من كائني struct مبلغ العملة العملةُ نفسها ("USD" أو "HD")، فيجب رمي نسخة من `ArgumentException`.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
amountA > new CurrencyAmount(50, "HD")
// => true
amountA < new CurrencyAmount(50, "HD")
// => false
amountA > new CurrencyAmount(50, "USD")
// => ArgumentException
```

## 3. جمع مبالغ العملة وطرحها

يُرجى تعديل struct ‏`CurrencyAmount` للتعامل مع الجمع والطرح الحسابي (فقط `+` و `-`). إذا لم يكن لكل من كائني struct مبلغ العملة العملةُ نفسها ("USD" أو "HD")، فيجب رمي نسخة من `ArgumentException`.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
CurrencyAmount amountB = new CurrencyAmount(100, "HD");
CurrencyAmount amountC = new CurrencyAmount(55, "USD");
amountA + amountB
// => {155, HD}
amountB - amountA
// => {45, HD}
amountA + amountC
// => ArgumentException
```

## 4. ضرب مبالغ العملة وقسمتها

يُرجى تعديل struct ‏`CurrencyAmount` للتعامل مع الضرب والقسمة الحسابية (فقط `*` و `/`).

```csharp
CurrencyAmount amountA = new CurrencyAmount(10, "HD");
amountA * 2m
// => {20, HD}
amountA / 2m
// => {5, HD}
```

## 5. تحويل مبلغ العملة إلى double

يُرجى تعديل struct ‏`CurrencyAmount` بحيث يمكن تحويل نسخة منه صراحةً إلى `double`.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55.5m, "HD");
(double)amountA
// => 55.5d
```

## 6. تحويل مبلغ العملة إلى decimal

يُرجى تعديل struct ‏`CurrencyAmount` بحيث يمكن تحويل نسخة منه ضمنيًا إلى `decimal`.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55.5m, "HD");
decimal d = amountA;
// => d == 55.5m
```
