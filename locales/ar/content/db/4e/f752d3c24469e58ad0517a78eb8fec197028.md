# مقدمة

## الأسماء المستعارة للأنواع

### الأسماء المستعارة للأنواع

يمكنك في Gleam استخدام الاسم المستعار للنوع لمنح اسم ملائم لنوع موجود تكون كتابته مرهقة بخلاف ذلك.

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

عند كتابته باستخدام `pub type` يمكن استخدام الاسم المستعار خارج الوحدة التي عُرّف فيها. وإذا حُذفت `pub` يصبح الاسم المستعار خاصًّا ولا يمكن الإشارة إليه في وحدات أخرى.

## القواميس

القواميس في Gleam هي بنية البيانات المخصصة لتخزين المعلومات في أزواج من المفاتيح والقيم. وفي لغات أخرى، قد تُعرف أيضًا باسم المصفوفات الترابطية أو جداول التجزئة أو القواميس.

يمكن استخدام أي نوع لمفاتيح القاموس وقيمه، وهي لا تضمن ترتيب مدخلاتها عند الوصول إليها أو إرجاعها.

### التعامل مع القواميس

تُنشأ القواميس وتُعالج باستخدام دوال من وحدة `gleam/dict`.

```gleam
// Create an empty dict
let dict1 = dict.new()

// Create a dict with some values
let dict2 = dict.from_list([
  #("name", "Gleam"),
  #("colour", "Pink"),
])

// Add a value to a dict
let dict3 = dict.insert(dict2, "website", "https://gleam.run")

// Get a value from a dict
let name = dict.get(dict3, "name")
// -> Ok("Gleam")
```
