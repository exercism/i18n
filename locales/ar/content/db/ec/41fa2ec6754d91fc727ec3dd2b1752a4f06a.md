# إعلان النوع

توفر إعلانات الأنواع في PHP تحققات من النوع في وقت التنفيذ على وسائط الدوال والقيم المُرجعة وخصائص الأصناف.
في الدوال، يمكن إضافة نوع إرجاع `void` للإشارة إلى أن الدالة لا تُرجع أي قيمة.
وتعمل الأنواع المُعلَنة أيضًا كتحققات في وقت التنفيذ من أن الدوال تُرجع استجابة ذات نوع معقول.

```php
<?php

class Driver
{
    private int $serial_number;

    public function setSerialNumber(int $number): void
    {
        $this->serial_number = $number;
    }

    public function getSerialNumber(): int
    {
        return $this->serial_number; 
    }
}

$driver = new Driver();
$driver->setSerialNumber("Version 1b"); // This will throw a TypeError
```

## اتحادات الأنواع

إذا كان من الممكن أن يكون وسيط دالة أو قيمة مُرجعة أو خاصية صنف أكثر من نوع واحد، فيمكن الإعلان عن اتحاد أنواع.

```php
<?php

class IdentityCard
{
    private int|null $id = null;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

## الأنواع المختلطة

عند العمل مع الكود، قد لا نتمكن من تحديد نوع.
بدءًا من PHP 8.0، تم توفير نوع بمثابة مخرج طارئ باسم `mixed`.
ويعادل `mixed` اتحاد أنواع من `object|resource|array|string|float|int|bool|null`.
