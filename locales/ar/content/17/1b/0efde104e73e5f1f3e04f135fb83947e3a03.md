# مقدمة

الواجهة نوع يحتوي على أعضاء تُعرّف مجموعةً من الوظائف المترابطة. وهي تفصل استخدامات الصنف عن تنفيذه، ما يتيح وجود عدة تنفيذات مختلفة أو دعم سلوك عام مثل التنسيق أو المقارنة أو التحويل.

صياغة الواجهة تشبه صياغة الصنف، إلا أن الطرق تظهر كتوقيع فقط دون توفير جسم لها.

```java
public interface Language {
    String getLanguageName();
    String speak();
}

public class ItalianTraveller implements Language, Cloneable {

    // from Language interface
    public String getLanguageName() {
        return "Italiano";
    }

    // from Language interface
    public String speak() {
        return "Ciao mondo";
    }

    // from Cloneable interface
    public Object clone() {
        ItalianTraveller it = new ItalianTraveller();
        return it;
    }
}
```

يجب أن يُنفّذ الصنف المنفِّذ كل العمليات التي تُعرّفها الواجهة.

عادةً ما تحتوي الواجهات على طرق الكائنات.

من الأمثلة على الواجهات الموجودة في مكتبة أصناف Java، إلى جانب `Cloneable` المذكورة أعلاه، الواجهة `Comparable<T>`.
يمكن تنفيذ الواجهة `Comparable<T>` عندما يُطلب ترتيب فرز عام افتراضي في المجموعات.
