# التعليمات

تم التعاقد مع شركتك لإنشاء سجلات CSV من مدخلات المستخدم.

نحتاج إلى منشئ لسجل CSV وفقًا للمعيار المحدد في [RFC 4180](https://tools.ietf.org/html/rfc4180).

رغم وجود مواصفة رسمية، فإن شركتك تحتاج فقط إلى تنفيذ الوظائف التالية:
- إنشاء منشئ سجلات جديد
- إضافة حقل منفرد إلى السجل
- تسلسل السجل مع الهروب الأساسي

يعني الهروب الأساسي ما يلي:

- يجب إحاطة الحقول التي تحتوي على فواصل أسطر أو علامات اقتباس مزدوجة أو فواصل بعلامات اقتباس مزدوجة.

- إذا استُخدمت علامات الاقتباس المزدوجة لإحاطة الحقول، فيجب هروب علامة اقتباس مزدوجة تظهر داخل حقل بوضع علامة اقتباس مزدوجة أخرى قبلها.


## 1. إنشاء منشئ جديد

ستحتاج إلى تنفيذ الطريقة `new` لإنشاء منشئ جديد.

```rust
let mut builder = CsvRecordBuilder::new();
```

## 2. إضافة حقول منفردة إلى السجل

ستحتاج إلى تنفيذ الطريقة `add` لإلحاق الحقول بمنشئ السجلات لديك.
تأخذ `add` مقاطع من سلاسل نصية غير قابلة للتعديل، `&str`، كوسيط.

```rust
builder.add("ant");
builder.add("ba\"t");
builder.add("cat");
```


## 3. تسلسل السجل مع الهروب الأساسي

ستحتاج إلى تنفيذ الطريقة `build`.
تستهلك `build` المنشئ وتُرجع سجل CSV.
```rust
let record = builder.build();
// Note that from now on we cannot use `builder`
assert_eq!(&record, r#"ant,"ba""t",cat"#);
```
