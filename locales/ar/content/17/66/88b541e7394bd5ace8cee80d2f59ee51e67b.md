# نبذة

يمكن أن تحتوي الطرق على معامل varargs يتيح للمستدعي تحديد صفر أو أكثر من الوسائط كما لو كانت معاملات عادية. وستستقبل الطريقة هذه الوسائط في مصفوفة واحدة.

لجعل معامل ما معامل varargs، أضف [الكلمة المفتاحية `params`](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/params) إلى تعريف المعامل:

```csharp
public static void PrintNumbers(params int[] numbers)
{
    foreach (var number in numbers)
    {
        Console.Write(number)
    }
}

// No values for a varags parameter is allowed
PrintNumbers();

PrintNumbers(1);
// => 1

PrintNumbers(1, 2, 3);
// => 123
```
