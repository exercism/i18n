# التعليمات

أنت المُشير على متن سفينة دورية ساحلية. حقيبة اليوم تحتاج إلى خمس كلمات صغيرة جاهزة قبل أن تبدأ نوبة الصباح.

## 1. اقتبس قيمة

يسجّل دفتر السجل كل ملاحظة بـ*صيغة مصدر Factor*، وهي النص نفسه الذي سيعيد المُحلِّل قراءته. عرّف `quote-value` لتحويل أي قيمة إلى سلسلة نصية بصيغتها المصدرية.

```factor
123 quote-value .   ! => "123"
"hi" quote-value .  ! => "\"hi\""
```

## 2. أزل إطار العلم

تصل أعلام الإشارة الواردة مؤطّرة بمحرف علامة عند كل طرف. عرّف `flag-body` لتُرجِع كل ما *بين* العلامتين، مع حذف المحرف الأول وحذف المحرف الأخير.

أرجِع مقطعًا (عرضًا) بدلًا من النسخ.

```factor
"#NS-1024#" flag-body .   ! => "NS-1024"
```

## 3. قسّم علمًا

كل علم يحمل رمز بادئة قصيرًا يتبعه الحمولة. عرّف `split-flag` لتأخذ علمًا وطول ترويسة، وتُرجِع *كلا* مقطعي الترويسة والمتن.

```factor
"NS-1024" 2 split-flag .s
! => "NS"
! => "-1024"
```

## 4. أجرِ التثليث من قراءتين

قراءتان متتاليتان للإشارة تعطيان ثلاثة قياسات مشتقة: *الفرق* بينهما `a - b`، و*نقطة المنتصف* `(a + b) / 2`، و*النسبة* `a / b`. كل قياس يستخدم القراءتين معًا.

عرّف `triangulate` لتُرجِع الثلاثة من زوج من القراءات.

```factor
100 50 triangulate .s
! => 50
! => 75
! => 2
```

## 5. لخّص ثلاث قراءات

ثلاث قراءات متتالية تُلخَّص على شكل **المجموع**، و**الجداء**، و**القيمة العظمى**. كل إحصاء يستخدم القراءات الثلاث كلها.

عرّف `triangle-stats` لتُرجِع الثلاثة.

```factor
5 3 8 triangle-stats .s
! => 16
! => 120
! => 8
```
