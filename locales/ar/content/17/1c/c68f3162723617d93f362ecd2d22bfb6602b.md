# مقدمة

## الأعداد

توفّر Swift فئتين رئيسيتين من الأعداد: الأعداد الصحيحة والأعداد العشرية.

- [الأعداد الصحيحة][integers] تمثّل أعدادًا كاملة بلا جزء كسري، مثل `0` و`1` و`-1` و`42` و`-273`.
- [الأعداد العشرية][floatingpoint] تمثّل أعدادًا ذات جزء كسري، مثل `0.0` و`3.14` و`-1.36969e-10`.

يمكنك إدراج علامات الشرطة السفلية (`_`) داخل القيم العددية الحرفية لتحسين القراءة: `1_000_000` مطابق لـ `1000000`.
ويمكن كتابة الأعداد العشرية الحرفية بالترميز العشري أو الترميز الأسي.

في معظم الحالات، تستخدم [`Int`][int] للأعداد الصحيحة و[`Double`][double] للأعداد العشرية:

```swift
let speed: Int = 42                           // Explicit Int
let pi: Double = 3.14                         // Explicit Double
let giga: Double = 1_000_000_000              // Double with readability underscores
let plancksConstant: Double = 6.62607015e-34  // Double in scientific notation
```

## العوامل الحسابية

توفّر Swift [العوامل الحسابية][arithmetic-operators] القياسية لإجراء الحسابات على الأعداد:

| العامل | الوصف    | مثال |
| -------- | -------------- | ------- |
| `+`      | جمع       | `4 + 6` تساوي `10` |
| `-`      | طرح    | `15 - 10` تساوي `5` |
| `*`      | ضرب | `2 * 3` تساوي `6`  |

~~~~exercism/caution
Swift آمنة من حيث الأنواع ولا تسمح بخلط أنواع عددية مختلفة في العمليات الحسابية.
لا يمكنك جمع `Int` و`Double` أو ضربهما مباشرةً، بل يجب أن تحوّل أحد النوعين ليطابق الآخر أولًا.
~~~~

### القسمة

ينفّذ العامل `/` عملية القسمة.
عندما يكون الطرفان عددين صحيحين، تحذف قسمة الأعداد الصحيحة أي باقٍ كسري:

```swift
5.0 / 2.0 // 2.5 (Double division)
5 / 2     // 2 (integer division truncates the remainder)
```

تقسيم عدد عشري غير صفري على صفر ينتج `inf` أو `-inf`.
وتقسيم `0.0` على `0.0` ينتج `nan` (ليس عددًا).
في المقابل، يؤدي تقسيم عدد صحيح على صفر إلى خطأ في وقت الترجمة أو في وقت التشغيل:

```swift
print(5.0 / 0.0)  // Prints inf
print(-5.0 / 0.0) // Prints -inf
print(0.0 / 0.0)  // Prints nan

// The following line will not compile:
// print(5 / 0) // Error: Division by zero
```

### عامل الباقي

يحسب [عامل الباقي][remainder-operator] (`%`) الباقي المتبقي بعد قسمة عددين صحيحين:

```swift
5 % 2  // 1
-5 % 2 // -1

// Dividing by zero produces an error:
// 5 % 0 // Error: Division by zero
```

~~~~exercism/note
في Swift، العامل `%` هو عامل *باقٍ* حقيقي وليس عامل مودولو.
تأخذ النتيجة دائمًا إشارة الطرف الأول (المقسوم)، بغض النظر عن إشارة الطرف الثاني:

```swift
5 % -2  // 1
-5 % 2  // -1
```
~~~~

## تقريب الأعداد العشرية

يمكنك تقريب عدد عشري باستخدام الطريقة `rounded()`.
افتراضيًا، تقرّب `rounded()` إلى أقرب عدد صحيح.
ويمكنك أيضًا تمرير [قاعدة تقريب][rounding-rule] محددة، مثل `.up` أو `.down`:

```swift
let x = 3.14
let y = x.rounded()      // 3.0
let w = x.rounded(.down) // 3.0
let z = x.rounded(.up)   // 4.0
```

## استنباط النوع

عندما تعرّف ثابتًا أو متغيرًا عدديًا دون تحديد النوع، يستنتج Swift نوعه:

- الأعداد الكاملة تُعامل افتراضيًا على أنها `Int`.
- الأعداد التي تحتوي على نقطة عشرية تُعامل افتراضيًا على أنها `Double`.

```swift
let x = 42         // Inferred as Int
let y = 42.0       // Inferred as Double
let z: Double = 42 // Explicitly typed as Double
```

## تحويل النوع

لإجراء عمليات بين قيم من أنواع مختلفة، حوّل إحدى القيم باستخدام مُهيّئات النوع مثل `Double(_:)` أو `Int(_:)`:

```swift
let integerCount = 42
let floatingCount = Double(integerCount)
print(floatingCount) // Prints 42.0

let pi = 3.14
let integerPi = Int(pi)
print(integerPi) // Prints 3 (fractional part is truncated)
```
