# تعليمات خاصة بـ SQLite

يحتوي العمودان **list_one** و **list_two** على قائمة من الأعداد الصحيحة مُرمّزة بصيغة JSON.

مثال:

```json
[1, 2, 3]
```

## مخطط الجدول

```sql
CREATE TABLE sublist (
    list_one TEXT NOT NULL,     -- json array
    list_two TEXT NOT NULL,     -- json array
    result   TEXT
);
```
