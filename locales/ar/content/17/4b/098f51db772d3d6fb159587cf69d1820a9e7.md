# مقدمة

يمكن لدالة `switch()` أن تكون بديلًا موجزًا عن سلسلة طويلة من اختبارات `if` ... `else if`. وغالبًا ما يكون المتغير الذي يتم التبديل عليه سلسلة نصية، وإن كان كذلك فيمكن حذف علامات الاقتباس من المحدِّد.

```R
star <- function(type) {
  switch(type,
    M = , # will "fall through" if no value given
    K = "red dwarf",
    G = "Earth-like",
    "bigger star" # only correct for O,B,A,F
  )
}

> star("M")
[1] "red dwarf"
```

لاحظ أن الخيارات لن تنتقل إلى الخيار التالي إلا إذا تُركت القيمة فارغة، كما في الحالة `M` في المثال أعلاه. ولا حاجة إلى تضمين عبارات `break` كما هو الحال في بعض اللغات الأخرى.

عند التبديل على أنواع `character`، تكون القيمة الأخيرة هي القيمة الافتراضية، كما هنا. أما أنواع الأعداد الصحيحة فلا يمكن إعطاؤها قيمة افتراضية.

### الدالتان `recode_values` و`replace_values`

تسمح هاتان الدالتان المرتبطتان بإجراء تحويل شبيه بالتبديل على مستوى المتجهات، يربط القيم القديمة بقيم جديدة.

الفرق الأساسي بينهما هو أن `recode_values()` تُنشئ متجهًا جديدًا بالكامل، بينما تسمح `replace_values()` بتحديثات جزئية لمتجه موجود.

المطابقة لا تزال تامة، لكن:

- يمكن أن تكون الخيارات على اليسار متجهات، ويتحقق التطابق إذا طابق أي عنصر منها.
- تُربط الخيارات على اليسار بالنتائج على اليمين بعلامة التلدة `~` بدلًا من `=`.
- يمكن تحديد قيمة افتراضية في جميع الحالات.

```R
library(dplyr)

x <- c("a", "b", "a", "d", "b", NA, "c", "e", "z")
recode_values(
  x,
  "a" ~ 1,
  "b" ~ 2,
  "c" ~ 3,
  c("d", "e") ~ 4, # either "d' or "e" will match
  NA ~ 0,          # matches missing values
  default = 100   # note the different syntax for the default
)
#> [1]   1   2   1   4   2   0   3   4 100
```

### دالة `case_when`

تأخذ `case_when` صياغة `case_match` خطوة إلى الأمام، إذ تسمح بأي تعبير منطقي على يسار `~`.

لا يُمرَّر متجه الإدخال (`x` في المثال أدناه) كوسيط، بل يكفي أن يكون معرَّفًا مسبقًا.

```R
x <- 1:10
case_when(
  x < 3 ~ "low",
  between(x, 3, 5) ~ "mid",
  between(x, 6, 8) ~ "high",
  .default = "what?"
)
#>  [1] "low"   "low"   "mid"   "mid"   "mid"   "high"  "high"  "high"  "what?" "what?"
```

دالة `between()` هي أيضًا جزء من `dplyr`.
