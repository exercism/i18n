# مقدمة

مثل معظم لغات البرمجة، لدى Gleam «آثار جانبية»، إذ يمكن للدوال أن تقرأ حالة العالم وتغيّرها، وأن تُرجع قيمة أيضًا.

توفر وحدة `gleam/io` في مكتبة Gleam القياسية دوالًا لطباعة السلاسل النصية على الطرفية.

```gleam
io.println("Hello, Joe!")
// Hello, Joe!
// -> Nil
```

قد توفر حزم أخرى دوال إدخال وإخراج أخرى، مثل `simplifile`، وهي حزمة توفر دوالًا لقراءة الملفات وكتابتها.

```gleam
simplifile.read("favourite-colour.txt")
// -> Ok("Pink\n")
```
