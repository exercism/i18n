# التعليمات

أنت تعمل على تنفيذ نظام لمراقبة الصحة. وكجزء من ذلك، تحتاج إلى تتبّع الإحصاءات الصحية للمستخدمين.

ستبدأ ببعض الدوال غير المُنفَّذة في كتلة `impl` بالإضافة إلى تعريف `struct` التالي:

```rust
pub struct User {
    name: String,
    age: u32,
    weight: f32,
}
```

هدفك هو تنفيذ الطرق غير المُنفَّذة على `struct` المسمّى `User` والمعرَّف في كتلة `impl`.

على سبيل المثال، يجب أن تُرجع الطريقة `new` نسخة من `struct` المسمّى `User` بالقيم المحدَّدة للاسم والعمر والوزن.

```rust
let mut bob = User::new(String::from("Bob"), 32, 155.2);
// Returns: a User with name "Bob", age 32, and weight 155.2
```

يجب أن تُرجع الطريقة `weight` وزن `User`.

```rust
bob.weight();
// Returns: 155.2
```

يجب أن تضبط الطريقة `set_age` عمر `User`.

```rust
bob.set_age(33);
// Updates Bob's age to 33; happy birthday Bob!
```

استمتع بوقتك!
