# إضافة إلى التعليمات

## التنفيذ

يُسمح باستخدام ميزات اللغة الأساسية لبناء المصفوفات وتفكيكها عبر التفكيك، وباستخدام الأقواس المربعة `[]` لكتابة مصفوفة حرفية، لكن لا يجوز استخدام أي دوال من `Array.prototype`.

ولكي تتمكن من اختبار حلك، تأكد من تنفيذ `forEach`.

```typescript
const list = List.create(1, 2)
list.forEach((item) => console.log(item))
// =>
//    1
//    2
```
