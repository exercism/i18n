# التعليمات

في هذا التمرين، أنت تعمل في مطعم بيتزا يوصّل الطلبات إلى العملاء.

توفّر ثلاثة أنواع من البيتزا:

- Margherita: \$7
- Caprese: \$9
- Formaggio: \$10

يمكن للعملاء أيضًا اختيار خيارين إضافيين مقابل رسوم إضافية بسيطة:

1. صلصة إضافية: \$1
1. مكوّنات إضافية: \$2

عندما يقدّم العملاء طلبًا، تُضاف رسوم إضافية إذا طلبوا بيتزا واحدة أو بيتزتين فقط:

- بيتزا واحدة: \$3
- بيتزتان: \$2

لديك ثلاث مهام، كل واحدة منها تتعامل مع البيتزا وسعرها.

## 1. عرّف أنواع البيتزا وخياراتها

عرّف النوع المخصص `Pizza` لتمثيل الأنواع المختلفة من البيتزا والخيارات:

- `Margherita`
- `Caprese`
- `Formaggio`
- `ExtraSauce`
- `ExtraToppings`

يجب أن يُغلّف كلٌّ من `ExtraSauce` و`ExtraToppings` النوع `Pizza`.

## 2. احسب سعر البيتزا

نفّذ الدالة `pizza_price` لحساب سعر البيتزا:

```gleam
pizza_price(Caprese)
// -> 9
```

## 3. احسب سعر الطلب

نفّذ الدالة `order_price` لحساب سعر طلب البيتزا:

```gleam
order_price([Margherita, Formaggio])
// -> 19
```
