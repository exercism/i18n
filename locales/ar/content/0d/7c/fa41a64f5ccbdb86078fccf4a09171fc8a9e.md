# نبذة

يمكن لأي قيمة أن تكون خطأً. الكلمة `throw` (في `kernel`) تُطلق إشارة؛
فيُهجَر أثر المكدس للكلمة الحالية، ويرتد التحكم إلى أقرب `recover` محيط.

```factor
[ 0 1 / ] [ "div by zero" prepend ] recover
```

`ERROR:` كلمة تحليل تُعرّف صنف صف خطأ *و* كلمة بناء في خطوة واحدة:

```factor
ERROR: not-found path ;
! defines:
!   TUPLE: not-found path ;
!   : not-found ( path -- * ) \ not-found boa throw ;
!   : not-found? ( object -- ? ) … class predicate
```

وهكذا يحصل كل خطأ مخصص على صنف فريد، وكلمة بناء ودودة تُطلق الخطأ، ومحمول
صنف (`name?`) لاختبار الأخطاء الملتقطة به:

```factor
[ "/missing" not-found ]
[ dup not-found? [ path>> "missing: " prepend ] [ drop "other" ] if ]
recover
```

للتنظيف على نمط `finally`، انظر `cleanup` في `continuations`. وللحالات
القابلة لإعادة التشغيل، انظر `condition`.
