# مقدمة

## المصفوفات

في C#، تُعرف بنى البيانات التي يمكنها أن تحمل صفرًا أو أكثر من العناصر باسم _المجموعات_. و**المصفوفة** مجموعة لها حجم/طول ثابت، ويجب أن تكون جميع عناصرها من النوع نفسه. يمكن إسناد العناصر إلى المصفوفة أو استرجاعها منها باستخدام فهرس. وتبدأ مصفوفات C# العدّ من الصفر، أي أن فهرس العنصر الأول يساوي صفرًا دائمًا:

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true
```

يمكن أيضًا تعريف المصفوفات باستخدام صيغة مختصرة تتيح لك إنشاء المصفوفة وتحديد قيمتها في الوقت نفسه. ولأن المترجم أصبح قادرًا على معرفة عدد عناصر المصفوفة، يمكن حذف الطول:

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

يمكن التعامل مع المصفوفات إما باستدعاء طرق نسخة المصفوفة أو خصائصها، وإما باستخدام الدوال الثابتة المعرّفة في الصنف `Array`.

## حلقات `for`

تتيح لك حلقة `for` تكرار تنفيذ الكود في حلقة حتى يتحقق شرط معيّن.

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

تتكوّن حلقة `for` من أربعة أجزاء:

1. المُهيّئ: يُنفَّذ مرة واحدة قبل الدخول إلى الحلقة. ويُستخدم عادةً لتعريف المتغيرات المستخدمة داخل الحلقة.
2. الشرط: يُنفَّذ قبل كل تكرار للحلقة. وتستمر الحلقة في التنفيذ ما دام هذا الشرط يُقيَّم إلى `true`.
3. المُكرِّر: يُنفَّذ بعد كل تكرار للحلقة. ويُستخدم عادةً لتعديل متغيّرات الحلقة (غالبًا بالزيادة أو النقصان).
4. الجسم: الكود الذي يُنفَّذ في كل تكرار للحلقة.

## حلقات `foreach`

كون المصفوفة _مجموعة_ أيضًا يعني أنه، إلى جانب الوصول إلى القيم عبر الفهرس، يمكنك المرور على _كل_ قيمها باستخدام حلقة `foreach`:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```
