# التعليمات

بينما كنت تستعد لخبز الكوكيز لأصدقائك، اكتشفت أن عليك تحويل بعض القياسات المستخدمة في الوصفة.
وبما أنك لا تعرف سوى النظام المتري، فأنت بحاجة إلى إيجاد طريقة لتحويل قياسات الخبز الأمريكية الشائعة إلى المليلتر (mL) لتسهيل الأمر عليك.

استخدم جدول التحويل التالي في حلك:

| الوحدة المراد تحويلها | الحجم | بالمليلتر (mL) |
| --------------- | ------ | ------------------- |
| mL              | 1      | 1                   |
| كوب أمريكي          | 1      | 240                 |
| أونصة سائلة أمريكية  | 1      | 30                  |
| ملعقة صغيرة أمريكية | 1      | 5                   |
| ملعقة كبيرة أمريكية | 1      | 15                  |

وبما أنك مبرمج موهوب في طور التدريب، فقد قررت استخدام المليلتر كوحدة وسيطة لتسهيل التحويل من أي وحدة مذكورة إلى أي وحدة أخرى (حتى إلى نفسها).

## 1. استخراج المكوّن الرقمي من زوج الحجم

نفّذ الطريقة `KitchenCalculator.get_volume`.
عند تمرير زوج الحجم، ينبغي أن تُرجع المكوّن الرقمي فقط.

```crystal
KitchenCalculator.get_volume({:cup, 2.0})
# => 2.0
```

## 2. تحويل زوج الحجم إلى مليلترات

نفّذ الطريقة `KitchenCalculator.to_milliliter`.
عند تمرير زوج الحجم، ينبغي أن تُحوّل الحجم إلى مليلترات باستخدام جدول التحويل.

```crystal
KitchenCalculator.to_milliliter({:cup, 2.5})
# => {:milliliter, 600.0}
```

## 3. تحويل زوج الحجم بالمليلتر إلى وحدة أخرى

نفّذ الطريقة `KitchenCalculator.from_milliliter`.
عند تمرير زوج الحجم والوحدة المطلوبة، ينبغي أن تُحوّل الحجم إلى الوحدة المطلوبة باستخدام جدول التحويل.

```crystal
KitchenCalculator.from_milliliter({:milliliter, 1320.0}, :cup)
# => {:cup, 5.5}
```

## 4. التحويل من أي وحدة إلى أي وحدة

نفّذ الطريقة `KitchenCalculator.convert`.
عند تمرير زوج الحجم والوحدة المطلوبة، ينبغي أن تُحوّل الحجم المُعطى إلى الوحدة المطلوبة.

```crystal
KitchenCalculator.convert({:teaspoon, 9.0}, :tablespoon)
# => {:tablespoon, 3.0}
```
