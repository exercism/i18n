# التعليمات

يريد مدير المسرح أن يُنسخ نص البروفة كتابةً، وأجزاء عدة منه تُبنى بتكرار أشياء أو ضمّها بعضها إلى بعض.

المهام الأربع كلها تُنفَّذ داخل الصنف `REHEARSAL_SCRIPT`.

## 1. كرّر إشارة

عندما تُعطى إشارة وعددًا، أرجِع الإشارة مكرّرة ذلك العدد من المرات، دون أي شيء بينها.

```sather
REHEARSAL_SCRIPT::repeat_cue("Ha", 3)
-- => "HaHaHa"
```

تكرار شيء صفر مرات يعطي سلسلة نصية فارغة.

## 2. الأحرف الأولى للممثلين

عندما تُعطى قائمة الممثلين، أرجِع الحرف الأول من كل اسم مجمّعةً معًا.

```sather
REHEARSAL_SCRIPT::initials(|"Mia", "Ana", "Ben"|)
-- => "MAB"
```

## 3. رقّم الأسطر

عندما تُعطى أسطر مشهد، رقّمها بدءًا من واحد، كل سطر في سطره الخاص.

```sather
REHEARSAL_SCRIPT::numbered_lines(|"Enter", "Exit"|)
-- => "1. Enter\n2. Exit"
```

يوجد سطر جديد *بين* الأسطر، ولا يوجد بعد السطر الأخير. المشهد الذي لا يحتوي على أسطر هو سلسلة نصية فارغة.

## 4. اصرخ بسطر

أرجِع سطرًا مُحوَّلًا فيه كل حرف إلى حرف كبير.

```sather
REHEARSAL_SCRIPT::shout("quiet please")
-- => "QUIET PLEASE"
```
