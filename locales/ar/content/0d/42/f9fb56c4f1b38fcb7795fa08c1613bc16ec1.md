# نبذة

الأصناف لبنة أساسية في برامج Swift.
فهي تتيح لك تجميع الخصائص المترابطة (البيانات) والطُرق (الدوال) في وحدات وظيفية قائمة بذاتها.

### تعريف الأصناف

لتعريف صنف، استخدم الكلمة المفتاحية `class` متبوعةً باسم الصنف، مع وضع تعريف الصنف بين الأقواس المعقوفة:

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id = makeRandomID()
}
```

يمكن أن يحتوي جسم الصنف على خصائص مخزّنة، تُعرَّف وتتصرّف مثل الثوابت (`let`) أو المتغيرات (`var`) العادية.

### النسخ

يعمل تعريف الصنف كمخطط: فهو يعرّف نوعًا جديدًا ويصف شكل قيمه، لكنه لا ينشئ أي نسخ بمفرده.

لإنشاء *نسخة* من صنف، استدعِ مُهيّئه بكتابة اسم الصنف متبوعًا بالأقواس الهلالية:

```swift
let someCharacter = GameCharacter()
```

يُنشئ هذا نسخة جديدة تُهيَّأ خصائصها بالقيم الافتراضية المحددة في تعريف الصنف.
أما الخصائص الاختيارية التي لا تحمل قيمًا افتراضية صريحة (مثل `name`)، فإن Swift يجعل قيمتها `nil` افتراضيًا.

### الوصول إلى الخصائص

يمكنك الوصول إلى خصائص النسخة باستخدام *الترميز النقطي*: اكتب اسم النسخة، ثم نقطة (`.`)، ثم اسم الخاصية.
ويعمل الترميز النقطي أيضًا مع الخصائص المتداخلة.

يمكنك استخدام الترميز النقطي لقراءة القيم، ولإسناد قيم جديدة إذا كانت الخاصية قابلة للتغيير (`var`):

```swift
someCharacter.name
// => nil

someCharacter.name = "Luther"
someCharacter.name
// => "Luther"

someCharacter.id = "new id"
// Error: Cannot assign to property: 'id' is a 'let' constant
```

### الطُرق

إضافة إلى الخصائص، يمكن للأصناف تعريف *الطُرق*، وهي دوال مرتبطة بالصنف.

عرّف الطُرق داخل جسم الصنف بصيغة `func` المعتادة.
وإذا عدّلت طريقةٌ خاصيةً ما، وجب إعلان تلك الخاصية بـ `var`:

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id: String = makeRandomID()

    func takesDamage(_ damage: Double) {
        if damage > 100 {
            active = false
        }
    }

    func sayName() -> String {
        return "My name is \(name ?? "no one"), my class is \(characterClass ?? "undetermined")"
    }
}
```

استدعِ الطُرق على النسخة باستخدام الترميز النقطي، تمامًا كما تفعل مع الخصائص:

```swift
var myChar = GameCharacter()
myChar.active = true
myChar.takesDamage(200)
myChar.active
// => false
```

### Self

لكل نسخة من الصنف خاصية ضمنية تُسمّى `self`، وهي تشير إلى النسخة نفسها.
ومع أن ذكرها يُحذف غالبًا عند الإشارة إلى الخصائص أو الطُرق، فمن الشائع استخدام `self` للتمييز بين أسماء الخصائص وأسماء معاملات الطُرق عندما تتشابه أسماؤها.
