# ملحق التعليمات

## التنفيذ

لإكمال هذا التمرين، عليك تعريف نوع البيانات `stopwatch` وتنفيذ الدوال:

- newStopwatch
- start
- stop
- lap
- reset
- advanceTime
- getState
- currentLap
- total
- previousLaps

ستجد تعريفًا لنوع مبدئي جاهزًا في مكانه، لكن الأمر متروك لك لتعريف الدوال وإنشاء نوع بيانات ذي معنى.
