# المقدمة

في Haxe، يمكن تعريف هرمية الأصناف باستخدام _الوراثة_، التي تتيح لصنف مشتق (`Car`) أن يرث سلوك صنفه الأصلي (`Vehicle`) وبياناته.

في الصنف الأصلي، يمكنك:

- طرق يمكن تجاوزها
- طرق مجردة يجب على الأصناف المشتقة تنفيذها

```haxe
abstract class Vehicle {
  public function new() {}

  // Can be overridden
  public function drive() {
    // ...
  }

  // Must be implemented
  public abstract function getSpeed():Int;
}

class Car extends Vehicle {
  public function new() {
    super(); // Runs the parent class' constructor
  }

  public override function drive() {
    // ...
  }

  public function getSpeed():Int {
    // ...
  }
}
```

إذا كان للصنف الأصلي مُنشئ، فإننا نستخدم `super()` لاستدعائه:

```haxe
abstract class Vehicle {
  var wheels:Int;

  public function new(wheels:Int) {
    this.wheels = wheels
  }
}

class Car extends Vehicle {
  var color:String;

  public function new(wheels:Int, color:String) {
    super(wheels);
    this.color = color;
  }
}

```
