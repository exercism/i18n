# الأساسيات

## البدء

### المتغيرات

لتعريف [متغير][variables]، استخدم عامل الإسناد `=`.
في Crystal، يُفضّل أن تُكتب المتغيرات بصيغة [snake_case][snake-case].

```crystal
number = 1
puts number # => 1

number = 2
puts number # => 2
```

### الثوابت

تُعرَّف [الثوابت][constants] باستخدام عامل الإسناد `=` نفسه، لكنها تُكتب بحروف كبيرة بالكامل، وهو ما يُعرف بـ SCREAMING_SNAKE_CASE.

```crystal
NUMBER = 1
puts NUMBER # => 1
```

إسناد قيمة إلى ثابت مُعرَّف مسبقًا يؤدي إلى خطأ في وقت الترجمة.

```crystal
NUMBER = 1

NUMBER = 2
# Error: already initialized constant NUMBER
```

### الأنواع

Crystal لغة مُترجَمة، أي أن كل متغير أو وسيط طريقة يُسنَد إليه نوع في وقت الترجمة.
المترجم قادر على استنتاج نوع المتغير أو وسيط الطريقة.
لكن في بعض الحالات، يلزم تحديد النوع صراحةً.
الحالات التي تتطلب تحديد النوع سنشرحها في مفاهيم لاحقة.

### الطرق

[الطرق][methods] وسيلة لتجميع مجموعة من التعليمات القابلة لإعادة الاستخدام.
في Crystal، تُعرَّف الطرق غالبًا داخل صنف أو وحدة أو بنية.
لكن يمكن أيضًا تعريف الطرق خارج صنف أو وحدة أو بنية.
تُعرَّف الطرق باستخدام الكلمة المفتاحية `def`، متبوعة باسم الطريقة.
في Crystal، يُفضّل أن تُكتب الطرق بصيغة snake_case.
يمكنك حذف الأقواس الهلالية عندما لا تكون للطريقة أي وسائط.
لتحديد نهاية الطريقة، يجب استخدام الكلمة المفتاحية `end`.

```crystal
def hello
  puts "Hello World!"
end
```

استخدام طريقة غير موجودة لنوع المتغير أو وسيط الطريقة يؤدي إلى خطأ في وقت الترجمة.

```crystal
number = 1
number + "1"
# Error: no overload matches 'Int32#+' with type String
```

### الوسائط

يمكن أن تكون للطرق [وسائط][arguments].
الوسائط هي بيانات تُمرَّر إلى الطريقة.
لتتمكن من تمرير وسائط إلى طريقة، يجب تحديد اسم الوسيط.
في Crystal، يُفضّل أن تُكتب الوسائط بصيغة snake_case.
يمكن أن تكون للطريقة عدة وسائط، لكن يجب فصل الوسائط بفاصلة.

```crystal
def hello(name)
  puts "Hello #{name}!"
end
```

يمكن أن تكون للطرق أيضًا عدة وسائط.
في هذه الحالة، يجب فصل الوسائط بفاصلة.

```crystal
def hello(name, language)
  puts "Hello #{name}! You are learning #{language}."
end
```

### استدعاء الطرق

عند استدعاء طريقة تنتمي إلى صنف أو وحدة أو بنية، يجب استخدام عامل النقطة(`.`).
تكون الصيغة كالتالي: `<ClassName>.<method_name>`.
وعندما لا تنتمي الطريقة إلى صنف أو وحدة أو بنية، يمكنك ببساطة استدعاؤها بكتابة اسمها.
تُرجع الطرق دائمًا قيمة التعبير الأخير ضمنيًا.

عندما تكون للطريقة وسائط، يمكنك استخدام الأقواس الهلالية عند تحديد الوسائط في استدعاء الطريقة وتعريفها، كما يلي: `<method_name>(<argument_1>, <argument_2>, ...)`.
وعندما لا تكون للطريقة وسائط، يجب حذف الأقواس الهلالية.

```crystal
def hello(name)
  "Hello #{name}!"
end

hello("Crystal")
# => Hello Crystal!
```

عند استدعاء طريقة بعدة وسائط، يجب فصل الوسائط بفاصلة.
ويجب إعطاء الوسائط بالترتيب نفسه الذي وردت به في وسائط الطريقة.

```crystal
def hello_language(name, language)
  "Hello #{name}! You are learning #{language}."
end

hello_language("World", "Crystal")
# => Hello World! You are learning Crystal.
```

استدعاء طريقة بعدد خاطئ من الوسائط يؤدي إلى خطأ في وقت الترجمة.

```crystal
hello_language("Crystal")
# wrong number of arguments for 'hello_language' (given 1, expected 2)
```

### الجمع والطرح والضرب

في Crystal، يمكنك استخدام العامل `+` لجمع عددين معًا.
ويمكنك أيضًا استخدام العامل `-` لطرح عددين.
ويمكنك استخدام العامل `*` لضرب عددين.

```crystal
1 + 1
# => 2

2 - 1
# => 1

2 * 2
# => 4
```

### التعليقات

في Crystal، تُكتب [التعليقات][comments] بالرمز `#`، متبوعًا بمسافة ثم التعليق.
تُستخدم التعليقات لتوثيق الكود.
لا ينفّذ المترجم التعليقات.

```crystal
# This is a comment
```
