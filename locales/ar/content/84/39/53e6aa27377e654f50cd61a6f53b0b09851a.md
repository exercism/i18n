# التعليمات

في هذا التمرين، ستساعد حبيبَي المدرسة الثانوية على إعلان حبهما على وسائل التواصل الاجتماعي عبر توليد قلب بتنسيق ASCII يحمل الحرف الأول من اسميهما:

```
❤ J.  +  M. ❤
```

## 1. تنظيف الاسم

نفّذ طريقة `HighSchoolSweetheart.clean_up_name`.
يجب أن تستقبل اسمًا فتحذف منه جميع محارف `-` وتستبدلها بمسافة.
كما يجب أن تحذف أي مسافات بيضاء من بداية الاسم ونهايته.

```crystal
HighSchoolSweetheart.clean_up_name("Jane-Ann")
# => "Jane Ann"
```

## 2. الحصول على الحرف الأول من الاسم

نفّذ طريقة `HighSchoolSweetheart.first_letter`.
يجب أن تستقبل اسمًا وتُرجع الحرف الأول منه.
احرص على إعادة استخدام `HighSchoolSweetheart.clean_up_name` التي عرّفتها في الخطوة السابقة.

```crystal
HighSchoolSweetheart.first_letter("Jane")
# => "J"
```

## 3. تنسيق الحرف الأول ليصبح حرفًا أوّليًا

نفّذ طريقة `HighSchoolSweetheart.initial`.
يجب أن تستقبل اسمًا وتُرجع الحرف الأول منه بحرف كبير متبوعًا بنقطة.
احرص على إعادة استخدام `HighSchoolSweetheart.first_letter` التي عرّفتها في الخطوة السابقة.

```crystal
HighSchoolSweetheart.initial("Robert")
# => "R."
```

## 4. وضع الأحرف الأولى داخل القلب

نفّذ طريقة `HighSchoolSweetheart.pair`.
يجب أن تستقبل اسمين وتُرجع الأحرف الأولى مع قلوب إيموجي حولها.
احرص على إعادة استخدام `HighSchoolSweetheart.initial` التي عرّفتها في الخطوة السابقة.

```crystal
HighSchoolSweetheart.pair("Blake Miller", "Riley Lewis")
# => "❤ B.  +  R. ❤"
```
