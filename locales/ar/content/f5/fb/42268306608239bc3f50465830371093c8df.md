# مقدمة

## العودية

قدرة الشيء على تعريف نفسه بنفسه تُسمّى العودية. وفي Gleam، تظهر العودية في أغلب الأحيان في الدوال العودية، وهي الدوال التي تستدعي نفسها.

تحتاج الدالة العودية إلى حالة أساسية واحدة على الأقل وإلى حالة عودية واحدة على الأقل. الحالة الأساسية تُرجع قيمة دون استدعاء الدالة مرة أخرى. أما الحالة العودية فتستدعي الدالة مرة أخرى، مع تعديل المدخل بحيث يطابق الحالة الأساسية في نقطة ما.

```gleam
pub fn factorial(x: Int) -> Int {
  case x {
    // Base case
    1 -> 1

    // Recursive case
    _ -> x * factorial(x - 1)
  }
}
```

لا تمتلك Gleam صيغة خاصة لكتابة الحلقات، لذا تُنجَز جميع الحلقات باستخدام العودية.

```gleam
pub fn list_length(list: List(String)) -> Int {
  case list {
    [] -> 0
    [_, ..rest] -> 1 + list_length(rest)
  }
}
```

تدعم Gleam أيضًا الأنواع المخصصة العودية. النوع المخصص العودي هو نوع تشير فيه صيغة واحدة أو أكثر من صيغه إلى نفسه ضمن البيانات التي تحتفظ بها.

```gleam
pub type RussianDoll {
  Child               // Base case
  Mother(RussianDoll) // Recursive case
}
```
```gleam
let very_big_doll = Mother(Mother(Mother(Child)))
let small_doll = Mother(Child)
```
