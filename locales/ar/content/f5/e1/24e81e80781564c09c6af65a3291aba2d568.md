# التعليمات

تعلّم كيفية دمج البيانات من جدولين داخليين مختلفين في جدول داخلي واحد كنتيجة.

سيُعطى صنفك جدولين داخليين يحتويان على مجموعتي بيانات مختلفتين تمامًا، وهما ALPHAS و NUMS.

```abap
TYPES: BEGIN OF alphatab_type,
         cola TYPE string,
         colb TYPE string,
         colc TYPE string,
       END OF alphatab_type.
TYPES: alphas TYPE STANDARD TABLE OF alphatab_type.
TYPES: BEGIN OF numtab_type,
         col1 TYPE string,
         col2 TYPE string,
         col3 TYPE string,
       END OF numtab_type.
TYPES: nums TYPE STANDARD TABLE OF numtab_type.
```

البيانات في جدول ALPHAS كما هو موضح أدناه.

| COLA | COLB | COLC |
| --- | --- | --- |
| A | B | C | 
| D | E | F |
| G | H | I |

البيانات في جدول NUMS كما هو موضح أدناه.

| COL1 | COL2 | COL3 |
| --- | --- | --- |
| 1 | 2 | 3 | 
| 4 | 5 | 6 |
| 7 | 8 | 9 |

مهمتك هي إرجاع جدول داخلي يحتوي على سجلات تدمج قيم كل خلية من الجدول الداخلي ALPHAS والجدول الداخلي NUMS معًا. على سبيل المثال، يجب أن تكون قيمة العمود الأول من الصف الأول في الجدول الداخلي COMBINED_DATA هي "A1".

جدول الإرجاع المتوقع له التعريف التالي:

```abap
TYPES: BEGIN OF combined_data_type,
         colx TYPE string,
         coly TYPE string,
         colz TYPE string,
       END OF combined_data_type.
TYPES: combined_data TYPE STANDARD TABLE OF combined_data_type WITH EMPTY KEY.
```
