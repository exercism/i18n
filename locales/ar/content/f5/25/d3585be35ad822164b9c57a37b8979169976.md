# التعليمات

في هذا التمرين، ستُنفّذ برنامجًا يحدد حالة لعبة [تيك تاك تو][tic-tac-toe].
(_قد تعرف اللعبة أيضًا باسم "noughts and crosses" أو "Xs and Os"._)

تُلعب اللعبة على شبكة 3×3.
يتناوب اللاعبان وضع `X` و`O` على الشبكة.
تنتهي اللعبة عندما يفوز أحد اللاعبين بوضع ثلاث علامات في صف أو عمود أو على أحد قطري الشبكة، أو عندما تمتلئ الشبكة بالكامل.

في هذا التمرين، سنفترض أن `X` يبدأ.

مهمتك هي تحديد الحالة التي وصلت إليها لعبة معينة.

هناك 3 حالات محتملة للعبة:

- اللعبة في حالة **ongoing**.
- انتهت اللعبة في حالة **draw**.
- انتهت اللعبة في حالة **win**.

إذا كانت اللوحة المعطاة غير صالحة، فارفع خطأً مناسبًا.

إذا استوفت اللوحة الشروط التالية، فهي غير صالحة:

- لا يمكن الوصول إلى اللوحة المعطاة عندما تُلعب الأدوار بالترتيب الصحيح (تذكّر أن `X` يبدأ).
- استمر اللعب بعد انتهاء اللعبة.

## الأمثلة

### لعبة جارية

```text
   |   |
 X |   |
___|___|___
   |   |
   | X | O
___|___|___
   |   |
 O | X |
   |   |
```

### التعادل

```text
   |   |
 X | O | X
___|___|___
   |   |
 X | X | O
___|___|___
   |   |
 O | X | O
   |   |
```

### الفوز

```text
   |   |
 X | X | X
___|___|___
   |   |
   | O | O
___|___|___
   |   |
   |   |
   |   |
```

### غير صالحة

#### ترتيب أدوار خاطئ

```text
   |   |
 O | O | X
___|___|___
   |   |
   |   |
___|___|___
   |   |
   |   |
   |   |
```

#### استمرار اللعب بعد الفوز

```text
   |   |
 X | X | X
___|___|___
   |   |
 O | O | O
___|___|___
   |   |
   |   |
   |   |
```
