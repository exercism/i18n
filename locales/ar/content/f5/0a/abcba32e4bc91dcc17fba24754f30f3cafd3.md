# ملحق التعليمات

## تنسيق الشبكة

تُمثَّل الشبكة بسلسلة نصية منتهية بـ `null`، مع محرف سطر جديد في نهاية كل صف.

## السجلات

| السجل   | الاستخدام      | النوع   | الوصف                                                                          |
| -------- | ------------ | ------- | ------------------------------------------------------------------------- |
| `$a0`    | مدخل        | عنوان | سلسلة نصية مُدخلة منتهية بـ `null`                                        |
| `$a1`    | مدخل/مخرج | عنوان | سلسلة نصية ناتجة منتهية بـ `null`، وتكون فارغة إذا كانت أبعاد الشبكة غير صالحة |
| `$v0`    | مخرج       | عدد صحيح | حالة الشبكة (`0` = `ok`، `-1` = `invalid columns`، `-2` = `invalid rows`) |
| `$t0-9`  | مؤقت    | أي نوع     | للتخزين المؤقت                                                     |
