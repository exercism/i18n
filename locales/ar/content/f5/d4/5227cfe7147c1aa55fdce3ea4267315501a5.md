# الاختبارات

يحتوي كل تمرين على ملف اختبار.
شغّل الاختبارات باستخدام برنامج `bats`.

```bash
bats test-hello-world.bats
```

ستحتاج إلى تثبيت `bats`.
راجع صفحة [الاختبار في مسار Bash][bash] للحصول على تعليمات تثبيت `bats` على نظامك.

### bats مكتوب بلغة bash

ملف bats هو سكربت bash، مع بعض الدوال الخاصة التي يتعرّف عليها أمر `bats`.
سترى بعض الاختبارات التي تبدو هكذا:

```sh
jq -f some-exercise.jq <<< "{some,json,here}"
```

صيغة `<<<` هذه هي [Here String][here-string] في bash.
وهي تُرسل السلسلة النصية الواقعة على الجانب الأيمن إلى الإدخال القياسي للبرنامج الواقع على الجانب الأيسر.
وهي ([تقريبًا][so]) مماثلة لما يلي:

```sh
echo "{some,json,here}" | jq -f some-exercise.jq
```

## المساعدة بشأن دوال التحقق

تستخدم الاختبارات دوالًا من مكتبة [bats-assert][bats-assert].
وتجد هناك مساعدة بشأن دوال `assert*` المختلفة.

## الاختبارات المتخطّاة

حلّ التمرين يعني أن تجعل جميع اختباراته تنجح.
افتراضيًا، لا يُنفَّذ عند تشغيل الاختبارات سوى اختبار واحد (الأول).
وهذا مقصود، فهو يتيح لك التركيز على جعل هذا الاختبار وحده ينجح.
بمجرد أن ينجح، يمكنك تمكين الاختبار التالي بتحويل ما يلي إلى تعليق أو حذفه:

    [[ $BATS_RUN_SKIPPED == true ]] || skip

وهي تعليقات توضيحية تسبق الاختبارات الأخرى.

## تجاوز التخطّي

لتشغيل جميع الاختبارات، بما فيها الاختبارات التي تحمل تعليقات `skip` التوضيحية، يمكنك تشغيل:

```bash
BATS_RUN_SKIPPED=true bats test-some-exercise.bats
```

قد يكون من المريح استخدام دالة غلاف لتوفير الكتابة: في `bash` يمكنك أن تفعل ما يلي:

```bash
bats() {
    BATS_RUN_SKIPPED=true command bats *.bats
}
```

ثم شغّل الاختبارات بما يلي فقط:

```bash
bats
```

## تصحيح الأخطاء في `jq`

يأتي `jq` مزوّدًا بمرشّح [`debug`][debug] مفيد.
استخدمه أثناء تطويرك لحلول تمارينك لفحص البيانات الموجودة حاليًا في خط أنابيب jq.
راجع [مستند تصحيح الأخطاء][debugging] لمزيد من التفاصيل.
