# حول

`for` حلقات هي أكثر أنواع الحلقات تعقيدًا في PHP. وهي تتصرف مثل `for` حلقات في `C`، `Java`، و`JavaScript`. وصيغتها الأساسية هي:

```php
for (expr1; expr2; expr3) {
  // statements
}
```

يُقيَّم التعبير الأول (_expr1_) قبل أن تبدأ الحلقة. ويُقيَّم التعبير الثاني (_expr2_) قبل كل تكرار، وإذا قُيِّم إلى قيمة _صحيحة_، تُنفَّذ العبارات. وبعد تنفيذ العبارات، يُقيَّم التعبير الثالث (_expr3_).
