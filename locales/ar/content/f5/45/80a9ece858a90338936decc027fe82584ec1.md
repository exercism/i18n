# الأصناف العامة

```sather
class LOST_BOX{T} is
   attr item : T;
   create(thing : T) : SAME is
      box ::= new;
      box.item := thing;
      return box;
   end;
end;
```

## ما هو المعامل

يمثّل `T` نوعًا يُقدَّم عند موضع الاستخدام. ويبني Sather صنفًا مستقلًا لكل تركيبة تُستخدم فعليًا، عند تصريف البرنامج. لذا:

- `LOST_BOX{STR}` و`LOST_BOX{INT}` نوعان لا تربطهما صلة؛
- لا يوجد فحص عند التشغيل، ولا تغليف، ولا تحويل؛
- يظهر أي خطأ في الصنف عند كل نوع يُستخدم معه.

هذا هو الأسلوب نفسه المتبع في قوالب C++ أو الأنواع العامة في Rust، وهو يختلف عن الأنواع العامة في Java، حيث يُمحى النوع ويكون كل شيء في الحقيقة كائنًا.

## المعاملات المقيّدة

يمكن إسناد `T` المجرّد وتمريره وإرجاعه، ولا شيء غير ذلك، لأنه لا يُعرف عنه أي شيء آخر. ولاستدعاء إجراءات عليه، حدّد ما يجب أن يطابقه:

```sather
class LOST_BOX{T < $STR} is
   describe : STR is return "a box holding " + item.str; end;
end;
```

يشترط `T < $STR` أن يطابق `T` النوع `$STR`، وفي المقابل يسمح باستدعاء `item.str`. وأي شيء لا يستطيع `T` المجرّد فعله، فالقيد هو السبيل للسماح به.

بدون القيد، لن يُصرَّف `item.str`، وستشير رسالة الخطأ إلى السطر داخل الصنف العام، لا إلى السطر الذي استخدمه.

## إجراءات عامة؟

لا توجد أي منها. الأصناف وحدها هي التي تأخذ معاملات. والإجراء الذي يحتاج إلى العمل على عدة أنواع إما أن يكون داخل صنف عام، وإما أن يأخذ نوعًا مجرّدًا مثل `$STR`.

## الاختيار بينهما

| | صنف عام | صنف مجرّد |
| --- | --- | --- |
| يُحدَّد | عند التصريف | عند التشغيل |
| يحتوي | نوعًا واحدًا لكل إنشاء | أي نوع مطابق |
| الكلفة | لا شيء | إرسال |

يستخدم `ARRAY{$ACT}` الاثنين معًا: عام في نوع العنصر، ومجرّد في ما يمكن أن يكون عليه ذلك العنصر.

اختر صنفًا عامًا عندما يكون النوع واحدًا في كل الحالات ويعرفه مستخدم الصنف. واختر صنفًا مجرّدًا عندما يجب أن تتعايش عدة أنواع في مجموعة واحدة.
