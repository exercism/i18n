# مقدمة

## عوامل المقارنة

عوامل المقارنة في Julia تشبه نظيرتها في لغات أخرى كثيرة، وإن كانت تتضمن بعض الخيارات الإضافية لمحبي الرياضيات.

أما للمساواة، فالعاملان هما `==` (يساوي) و`!=` أو `≠` (لا يساوي).

```julia
txt = "abc"
txt == "abc"  # true
txt != "abc"  # false
txt ≠ "abc"  # false (synonym for !=)
```

بالإضافة إلى ذلك، لدينا مختلف عوامل المقارنة الأكبر والأصغر.

```julia
1 < 3  # true
3 > 3  # false
3 <= 3  # true
3 ≤ 3  # true (synonym for <=)
4 >= 3  # true
4 ≥ 3  # true (synonym for >=)
```

وكما يحدث غالبًا مع Julia، فإن استخدام الرمز الرياضي يصبح سهلًا مع محرر مناسب. اكتب `\ne` أو `\le` أو `\ge` ثم `TAB` للحصول على `≠` أو `≤` أو `≥`.

يستخدم المثال السابق الأعداد فقط، لكننا سنرى في أجزاء أخرى من المقرر أن أنواعًا إضافية متنوعة لها معنى ترتيبي، ويمكن اختبارها بأكبر من وأصغر من.

يمكن ربط عوامل المقارنة بعضها ببعض، وهو ما يتيح صياغة واضحة وموجزة:

```julia
n = 3
1 ≤ n ≤ 5  # true (n "between" two limits)
```

المثال السابق مرادف للتعبير `1 ≤ n && n ≤ 5`.

## التفريع باستخدام `if`

هذه هي الصيغة الكاملة للجملة الشرطية `if`:

```julia
if conditional1
    statements...
elseif conditional2
    statements...
else
    statements...
end
```

لا حاجة إلى الأقواس الهلالية `()` أو الأقواس المعقوفة `{}`، والإزاحة موجودة «فقط» لتحسين سهولة القراءة _(لكن سهولة القراءة مهمة جدًا!)_.

كلٌّ من `elseif` و`else` اختياري، ويمكن أن توجد عدة كتل `elseif`.
لكن `end` مطلوب.

يمكن تداخل الجمل الشرطية `if`، وإن كنت قد ترغب في تحسين سهولة القراءة بالاستخدام المدروس للأقواس الهلالية والإزاحات والتعليقات.

أقصر صيغة للجملة الشرطية `if` ستكون شيئًا كهذا:

```julia
if n < 0
    n = 0
end
```

وللتذكير: التعبيرات التي تُقيَّم إلى `true` أو `false` فقط هي التي يمكن استخدامها كشروط.
وتتجنب Julia عمدًا أي فكرة عن «صحة القيمة»، لذا فالقيم الصفرية والسلاسل النصية الفارغة والمصفوفات الفارغة _ليست_ مكافئة لـ `false`. 

## العامل الثلاثي

من الحالات البسيطة والشائعة اختيار إحدى قيمتين بناءً على شرط.

Julia، مثل كثير من اللغات، لديها عامل ثلاثي يجعل هذا أكثر إيجازًا.

الصيغة هي `conditional ? value_if_true : value_if_false`.

لذا يمكن إعادة كتابة المثال السابق على النحو التالي:

```julia
n = n < 0 ? 0 : n
```

لا يطلب المترجم الأقواس الهلالية، لكنها قد تحسّن سهولة القراءة.
