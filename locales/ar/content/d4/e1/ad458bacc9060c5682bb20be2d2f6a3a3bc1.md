# مقدمة

في Cairo، تتيح إعادة تعريف العوامل لك تعريف سلوك مخصص للعوامل القياسية مثل `+`، `-`، `==`، `<`، وغيرها، عند التعامل مع أنواعك الخاصة.

يتم ذلك عبر تنفيذ سمات محددة لأنواعك المخصصة.

## السمات الأساسية للعوامل

### `Add` و`Sub`

السمتان `Add` و`Sub` تتيحان لك تعريف كيفية عمل الجمع (`+`) والطرح (`-`) مع نوعك:

```rust
impl MyTypeAdd of Add<MyType> {
    fn add(lhs: MyType, rhs: MyType) -> MyType {
        // Define addition behavior
    }
}
```

### `PartialEq`

سمة `PartialEq` تتيح مقارنة المساواة (`==` و`!=`) بين نسخ نوعك.

يمكن غالبًا اشتقاق هذا تلقائيًا باستخدام `#[derive(PartialEq)]`.

### `PartialOrd`

سمة `PartialOrd` تتيح عمليات المقارنة (`<`، `>`، `<=`، `>=`) بين نسخ نوعك.

وهي تتطلب منك تنفيذ طريقة `lt` (أقل من) على الأقل:

```rust
impl MyTypePartialOrd of PartialOrd<MyType> {
    fn lt(lhs: MyType, rhs: MyType) -> bool {
        // Define "less than" behavior
    }
}
```
