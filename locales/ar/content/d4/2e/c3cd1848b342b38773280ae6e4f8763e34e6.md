# التعليمات

مرحبًا بك في عالم *ChronoRealms*، أرض سحرية يتحكم فيها الـTimekeepers الأقوياء في مسار الزمن.

في هذا العالم، يدير الـTimekeepers وحدات خاصة تُسمى "TimeShards"، ويمكن جمعها وطرحها ومقارنتها، بل وفحص تساويها.

مهمتك هي مساعدة الـTimekeepers عبر تنفيذ عوامل مخصصة للتعامل مع وحدات TimeShards هذه.

يحتاج الـTimekeepers منك إنشاء بنية مخصصة `TimeShard` تدعم العمليات التالية:

1. **جمع الـTimeShards وطرحها**: يحتاج الـTimekeepers إلى جمع الـTimeShards وطرحها للتحكم في الخط الزمني.
2. **مقارنة الـTimeShards**: أحيانًا يلزم مقارنة الـTimeShards لمعرفة أيّها أكبر، أو ما إذا كانت متساوية.
3. **فحص التساوي**: يحتاج الـTimekeepers إلى فحص ما إذا كانت وحدتي TimeShard متطابقتين في القيمة.

مهمتك هي تنفيذ السمات التالية لبنية `TimeShard`:

1. **الجمع (`Add`)**: تمكين جمع نسختين من `TimeShard` معًا.
2. **الطرح (`Sub`)**: تمكين طرح `TimeShard` من أخرى.
3. **التساوي (`PartialEq`)**: السماح للـTimekeepers بفحص ما إذا كانت نسختان من `TimeShard` متطابقتين.
4. **المقارنة (`PartialOrd`)**: السماح بمقارنة نسختين من `TimeShard` لمعرفة أيّهما أكبر أو أصغر.

ستُمثَّل `TimeShard` ببنية تحمل قيمة عدد صحيح (`i32`).

نفّذ السمات اللازمة لتسهيل مهمة الـTimekeepers.

```rust
let shard1 = TimeShard { value: 5 };
let shard2 = TimeShard { value: 3 };

// Adding TimeShards
let sum = shard1 + shard2; // TimeShard { value: 8 }

// Subtracting TimeShards
let difference = shard1 - shard2; // TimeShard { value: 2 }

// Checking equality
let are_equal = shard1 == shard2; // false

// Comparing TimeShards
let is_greater = shard1 > shard2; // true
```
