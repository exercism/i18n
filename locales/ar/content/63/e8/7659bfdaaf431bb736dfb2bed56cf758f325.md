# التعليمات

في هذا التمرين، ستحتاج إلى ترجمة بعض القواعد من اللعبة الكلاسيكية Pac-Man إلى دوال Haskell.

لديك أربع قواعد لترجمتها، وكلها متعلقة بحالات اللعبة.

> لا تقلق بشأن كيفية اشتقاق الوسائط، ركّز فقط على دمج الوسائط لإرجاع النتيجة المقصودة.

## 1. حدّد ما إذا كان Pac-Man يأكل شبحًا

عرّف الدالة `eatsGhost` التي تأخذ وسيطين (_ما إذا كان لدى Pac-Man حبة طاقة نشطة_ و_ما إذا كان Pac-Man يلمس شبحًا_) وتُرجع قيمة `Bool` عندما يكون Pac-Man قادرًا على أكل الشبح.
ينبغي أن تُرجع الدالة `True` فقط عندما يملك Pac-Man حبة طاقة نشطة ويلمس شبحًا.

```haskell
eatsGhost False True
-- -> False
```

## 2. حدّد ما إذا كان Pac-Man يسجّل

عرّف الدالة `scores` التي تأخذ وسيطين (_ما إذا كان Pac-Man يلمس حبة طاقة_ و_ما إذا كان Pac-Man يلمس نقطة_) وتُرجع قيمة `Bool` إذا سجّل Pac-Man.
ينبغي أن تُرجع الدالة `True` عندما يلمس Pac-Man حبة طاقة أو نقطة.

```haskell
scores True True
-- -> True
```

## 3. حدّد ما إذا كان Pac-Man يخسر

عرّف الدالة `loses` التي تأخذ وسيطين (_ما إذا كان لدى Pac-Man حبة طاقة نشطة_ و_ما إذا كان Pac-Man يلمس شبحًا_) وتُرجع قيمة `Bool` إذا خسر Pac-Man.
ينبغي أن تُرجع الدالة `True` عندما يلمس Pac-Man شبحًا ولا يملك حبة طاقة نشطة.

```haskell
loses False True
-- -> True
```

## 4. حدّد ما إذا كان Pac-Man يفوز

عرّف الدالة `wins` التي تأخذ ثلاثة وسائط (_ما إذا كان Pac-Man قد أكل كل النقاط_، _ما إذا كان لدى Pac-Man حبة طاقة نشطة_، و_ما إذا كان Pac-Man يلمس شبحًا_) وتُرجع قيمة `Bool` إذا فاز Pac-Man.
ينبغي أن تُرجع الدالة `True` عندما يكون Pac-Man قد أكل كل النقاط _و_ لم يخسر بناءً على الوسائط المعرّفة في الجزء 3.

```haskell
wins False True False
-- -> False
```
