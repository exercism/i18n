# مقدمة

يتيح النوع `Result` للدالة أن تُرجع قيمة واحدة تشير إلى كل ما يلي:
- ما إذا نجحت العملية أم فشلت
- عند النجاح، القيمة الناتجة عن العملية
- عند الفشل، سبب الفشل

## الاستخدام

النوع `Result` هو نوع عام يضم نوعين أساسيين:
- نوع القيمة الناتجة عند نجاح العملية
- نوع الخطأ عند الفشل

النوع `Result` هو أيضًا [اتحاد مميز][discriminated-union] له الحالات المحتملة التالية:
* `Ok <value>` ويمثّل نتيجة ناجحة
* `Error <reason>` ويمثّل فشلًا

توضّح الدالة التالية كيفية إنشاء قيمة من النوع `Result`:

```fsharp
let validateName (name: string) : Result<string, string> = 
    match name with
    | null -> Error "Name not found."
    | "" -> Error "Name is empty."
    | _ -> Ok name
```

في هذا المثال، قيمة `Ok` هي سلسلة نصية (الاسم المُعطى)، وقيمة `Error` هي أيضًا سلسلة نصية (سبب الخطأ، بصيغة يسهل على الإنسان قراءتها).

## قراءة محتوى قيمة `Result`

تأمّل تعريف النوع وتوقيع الدالة التاليين:

```
type FileOpenError = 
| NotFound
| AccessDenied
| FileLocked

let openFile (filename: string) : Result<int, FileOpenError> =
```

يمكن للكود الذي يستدعي الدالة `openFile` أن يستخدم مطابقة الأنماط للتعامل مع حالتي النجاح والفشل، كما في المثال التالي:

```fsharp
match openFile(filename) with
| Ok handle -> doSomethingWithFile(handle)
| Error NotFound -> printfn $"Error: file {filename} was not found."
| Error AccessDenied -> printfn $"Error: you do not have permission to open the file {filename}."
| Error FileLocked -> printfn $"Error: file {filename} is already in use."
```
