# التعليمات

أنت تُعِدّ دليلًا ميدانيًا: خريطة تربط اسم الحيوان بالموطن الذي يعيش فيه.

المهام الخمس كلها توضع في صنف `FIELD_GUIDE`.

## 1. هل هو مُدرج في الدليل؟

```sather
FIELD_GUIDE::is_listed(guide, "emu")
-- => true
```

## 2. أين يعيش؟

أرجِع الموطن المسجَّل لحيوان ما. وإذا لم يسمع الدليل به من قبل، فأرجِع `"Unknown"`.

```sather
FIELD_GUIDE::habitat_of(guide, "emu")
-- => "grassland"
FIELD_GUIDE::habitat_of(guide, "moa")
-- => "Unknown"
```

## 3. أضِف مدخلًا

أرجِع الدليل مع حيوان إضافي فيه. وأي حيوان مُدرج بالفعل يُستبدل موطنه.

```sather
FIELD_GUIDE::add_entry(guide, "wombat", "forest")
-- => the guide, now with wombat in it
```

وما تُرجعه هذه الدالة هو الدليل الذي ستستخدمه من بعد ذلك. والإضافة إلى دليل فارغ تمامًا تعمل وتُعطي دليلًا فيه حيوان واحد.

## 4. كم عدد الحيوانات؟

```sather
FIELD_GUIDE::entry_count(guide)
-- => 3
```

## 5. ما المواطن؟

أرجِع مجموعة المواطن التي يذكرها الدليل. قد تشترك عدة حيوانات في الموطن نفسه، وينبغي أن يظهر مرة واحدة.

```sather
FIELD_GUIDE::all_habitats(guide)
-- => a set holding "grassland" and "forest"
```
