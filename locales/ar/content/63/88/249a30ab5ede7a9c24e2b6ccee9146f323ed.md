# مقدمة

بدءًا من `PHP 8.0.0`، تقبل **إعلانات الأنواع الاتحادية** قيمًا من أنواع مختلفة ومتعددة، بدلًا من نوع واحد. تُكتب تعريفات الأنواع الاتحادية باستخدام الخط العمودي (`|`) للفصل بين الأنواع.

```php
function add(int|float $a, int|float $b): int|float
{
    return $a + $b;
}
```

في الوضع الصارم، سيُطلق PHP استثناء `TypeError` إذا لم تكن المعاملات الواردة من النوع `float` أو `int`. وفي الوضع غير الصارم، سيُطلق خطأ في النوع إذا تعذّر تحويل المعاملات الواردة إلى `float` أو `int`.

وبالمثل، إذا لم تُرجع الدالة أحد الأنواع المُعلنة، سيُطلق PHP استثناء `TypeError` أثناء التنفيذ.
