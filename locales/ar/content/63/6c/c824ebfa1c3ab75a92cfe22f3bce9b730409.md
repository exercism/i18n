# القيم المنطقية

بعض الأسئلة لها إجابتان فقط: نعم أو لا. نوع Sather لمثل هذه الإجابة هو `BOOL`،
وتُكتب الإجابتان `true` و`false`.

```sather
   ready : BOOL is
      return true;
   end;
```

## المقارنة

مقارنة عددين تُنتج `BOOL`.

| العامل | السؤال |
| --- | --- |
| `=` | هل هما متماثلان؟ |
| `/=` | هل هما مختلفان؟ |
| `<` | هل القيمة اليسرى أصغر؟ |
| `<=` | أصغر، أم مساوٍ؟ |
| `>` | هل القيمة اليسرى أكبر؟ |
| `>=` | أكبر، أم مساوٍ؟ |

```sather
   old_enough(age : INT) : BOOL is
      return age >= 13;
   end;
```

لاحظ أن `=` يطرح سؤالًا. أمّا إسناد قيمة *إلى* شيء ما فيتم بـ`:=`، وقد رأيته من
قبل، وهما ليسا الشيء نفسه.

## الدمج

ثلاثة عوامل تبني أسئلة أكبر من أسئلة أصغر.

يكون `and` صحيحًا عندما يكون **كلا** الطرفين صحيحًا.

```sather
harness_on and rope_checked
```

يكون `or` صحيحًا عندما يكون **أحد** الطرفين صحيحًا، أو كلاهما.

```sather
mat_below or net_below
```

يقلب `~` الإجابة: فهو يحوّل صحيحًا إلى خطأ، وخطأ إلى صحيح.

```sather
~ready       -- true exactly when ready is false
```

يأتي `and` و`or` بين إجابتين؛ أمّا `~` فيأتي أمام إجابة واحدة.
