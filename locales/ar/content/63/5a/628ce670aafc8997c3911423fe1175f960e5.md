# التعليمات

صديقة لوسيان في طريقها إلى المنزل، ولم يُعدّ عشاء الذكرى السنوية لهما بعد!

في هذا التمرين، ستكتب بعض الكود لمساعدة لوسيان على طهي لازانيا شهية من كتاب الطبخ المفضّل لديه.

لديك أربع مهام، كلها تتعلق بالوقت المستغرق في طهي اللازانيا.

## 1. حدّد الزمن المتوقّع في الفرن بالدقائق

عرّف الطريقة `Lasagna.ExpectedMinutesInOven()` التي لا تأخذ أي معاملات وتُرجع عدد الدقائق التي ينبغي أن تبقى فيها اللازانيا في الفرن. وفقًا لكتاب الطبخ، الزمن المتوقّع في الفرن بالدقائق هو 40:

```csharp
var lasagna = new Lasagna();
lasagna.ExpectedMinutesInOven();
// => 40
```

## 2. احسب الزمن المتبقّي في الفرن بالدقائق

عرّف الطريقة `Lasagna.RemainingMinutesInOven()` التي تأخذ عدد الدقائق الفعلية التي قضتها اللازانيا في الفرن كمعامل، وتُرجع عدد الدقائق التي ما زال على اللازانيا أن تبقاها في الفرن، استنادًا إلى الزمن المتوقّع في الفرن بالدقائق من المهمة السابقة.

```csharp
var lasagna = new Lasagna();
lasagna.RemainingMinutesInOven(30);
// => 10
```

## 3. احسب زمن التحضير بالدقائق

عرّف الطريقة `Lasagna.PreparationTimeInMinutes()` التي تأخذ عدد الطبقات التي أضفتها إلى اللازانيا كمعامل، وتُرجع عدد الدقائق التي استغرقتها في تحضير اللازانيا، بافتراض أن تحضير كل طبقة يستغرق منك دقيقتين.

```csharp
var lasagna = new Lasagna();
lasagna.PreparationTimeInMinutes(2);
// => 4
```

## 4. احسب الزمن المنقضي بالدقائق

عرّف الطريقة `Lasagna.ElapsedTimeInMinutes()` التي تأخذ معاملين: المعامل الأول هو عدد الطبقات التي أضفتها إلى اللازانيا، والمعامل الثاني هو عدد الدقائق التي قضتها اللازانيا في الفرن. ينبغي أن تُرجع الدالة عدد الدقائق التي عملتها في طهي اللازانيا، وهو مجموع زمن التحضير بالدقائق، والوقت بالدقائق الذي قضته اللازانيا في الفرن حتى هذه اللحظة.

```csharp
var lasagna = new Lasagna();
lasagna.ElapsedTimeInMinutes(3, 20);
// => 26
```
