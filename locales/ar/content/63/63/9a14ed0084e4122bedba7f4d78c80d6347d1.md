# أساسيات صياغة Elm 2

## تصدير الدوال

تناولنا تصدير الدوال في المفهوم الأول، وهذه مراجعة سريعة.

كل ملف في Elm هو وحدة، ويجب أن يحتوي على عبارة `module` قبل بقية الكود.

يجب أن تطابق أسماء الوحدات أسماء ملفاتها، فوحدة `Calculator` يجب أن تكون في ملف Calculator.elm، ووحدة `Parser.Utils` يجب أن تكون في ملف Parser/Utils.elm.

أي شيء يُعرَّف داخل وحدة يكون نطاقه خاصًّا بها، ولا يمكن الوصول إليه من خارج هذه الوحدة، إلا إذا كان مُدرجًا في `exposing`.

```elm
-- Calculator.elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Calculator.elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## استيراد الدوال من وحدات أخرى

يتم الوصول إلى الدوال المعرَّفة في وحدات أخرى عبر الاستيراد.
عند استيراد وحدة، تصبح كل الدوال التي أتاحتها متاحة.
لكن طريقة الوصول إليها تختلف حسب طريقة استيراد الوحدة.

الاستيراد المؤهَّل هو الافتراضي، ويتم الوصول إلى دالة داخل وحدة كهذه (مثل دالة `map` في وحدة `List`) بوضع اسم الوحدة قبلها (`List.map`).

أما الاستيراد المفتوح فيتيح الوصول المباشر إلى الدوال المُتاحة في تلك الوحدة، دون بادئة. ويتم باستخدام الكلمة المفتاحية `exposing`، على غرار نظيرتها المستخدمة في التصدير. يمكنك إتاحة كل الدوال المتاحة (باستخدام `..`)، أو دوال محددة (مثل `map`).

يمكنك أيضًا استيراد الأنواع ومُنشئاتها من وحدات أخرى، وهذا مفهوم لاحق.

يُفضَّل الاستيراد المؤهَّل لتعزيز الوضوح وتجنّب تعارض الأسماء.

```elm
-- qualified imports
import List                            -- List.map, List.foldl
import List as L                       -- L.map, L.foldl

-- open imports
import List exposing (..)              -- map, foldl, concat, ...
import List exposing ( map, foldl )    -- map, foldl, List.concat
```

https://elm-lang.org/docs/syntax#modules

## توصيفات الأنواع

تُعرَّف توصيفات الأنواع بالشكل `name : parameter types -> return type`، مع فصل أنواع المعاملات أيضًا بـ `->`.

```elm
add : Int -> Int -> Int
add number1 number2 = number1 + number2
```

يمكن استخدام الأقواس الهلالية لتعريف معاملات الدالة (وهي نفسها تُعرَّف بالصياغة ذاتها، ومن هنا الحاجة إلى الأقواس).

```elm
-- Transform every character in a string
map : (Char -> Char) -> String -> String
map charMapperFunction string =
    -- ...
```

https://elm-lang.org/docs/syntax#type-annotations

## الأعداد

يوجد نوعان من الأعداد في Elm، يحددهما النوعان `Int` و`Float`.
يقابل `Int` مجموعة الأعداد الصحيحة الموجبة والسالبة.
ويقابل `Float` مجموعة الأعداد الحقيقية، محدودة بدقة الحاسوب.
العمليات المعرَّفة على الأعداد تعمل عادةً على أحد النوعين، لا على خلط بينهما.
توجد دوال للتحويل بين النوعين، مثل `toFloat` التي تحوّل `Int` إلى `Float`، و`round` و`floor` و`ceiling` و`truncate` التي تحوّل `Float` إلى `Int` بدلالات مختلفة.

https://package.elm-lang.org/packages/elm/core/latest/Basics#Int

## عمليات السلاسل النصية

لوصف الكلمات والجمل في الكود، لدى Elm نوع `String` أصلي.
تُكتب السلاسل النصية الحرفية بين علامتي تنصيص مزدوجتين، مثل `"Hello World!"`.
يتوفر عامل دمج السلاسل النصية `++` وعامل التساوي `==` افتراضيًّا.

```elm
hello : String -> String
hello subject = "Hello " ++ subject

hello "World!" --> "Hello World!"
```

معظم دوال السلاسل النصية الأخرى موجودة في وحدة `String`، التي يجب استيرادها.

https://package.elm-lang.org/packages/elm/core/latest/String
