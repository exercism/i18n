# نبذة

يمكن تعريف أنواع C# ضمن نطاق صنف أو `struct`. ويوفّر النوع المُحيط ما يشبه مساحة الأسماء. ويتم الوصول إلى النوع من خلال النوع المُحيط باستخدام صيغة النقطة.

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

## مستويات الوصول

يمكن تطبيق مستويات الوصول على الأنواع الداخلية. فمثلًا، إذا كان الصنف `private` فلا يمكن رؤيته خارج نطاق النوع المُحيط، وبالطبع لا يمكن رؤية النسخ أو استخدامها خارج النطاق.

الأعضاء الخاصة في الصنف الخارجي تقع ضمن نطاق جميع أعضاء الصنف الداخلي، لكن الأعضاء غير الخاصة في الصنف الداخلي فقط هي التي تقع ضمن نطاق أعضاء الصنف الخارجي. وللوصول إلى أعضاء الصنف الخارجي، يجب منح الصنف الداخلي نسخة من الصنف الخارجي.

ويمكن ملاحظة ذلك في المثال التالي:

```csharp
class Outer
{
    public class InnerImpl
    {
        private Outer outer;

        public int Interesting = 42;

        public InnerImpl(Outer outer, int interesting)
        {
            this.outer = outer;
            Interesting = interesting;
        }

    }

    public InnerImpl Inner;
    public Outer()
    {
        Inner = new InnerImpl(this, 42);
    }
}

var outer = new Outer();
outer.Inner.Interesting
// => 42
var inner = new Outer.InnerImpl(outer, 1729);
outer.Inner.Interesting
// => 1729
```

## منع إنشاء نسخ مستقلة

هناك نمط يمنع إنشاء نسخ من النوع من خارج النوع المُحيط. فتكشف واجهة عامة، لكن تُبقي الصنف الذي ينفّذها خاصًا.

```csharp
class Outer
{
    public interface IInner
    {
        void DoSomething();
    }

    private class InnerImpl : IInner
    {
        private Outer outer;
        public InnerImpl(Outer outer)
        {
            this.outer = outer;
        }
        public void DoSomething()
        {
            outer.DoSomethingElse();
        }
    }

    public IInner Inner;

    public Outer()
    {
        Inner = new InnerImpl(this);
    }
    private void DoSomethingElse()
    {
    }
}

var outer = new Outer();
outer.Inner.DoSomething();

// NOT var inner = new Outer.Inner(outer);
```

## ملاحظة لمطوّري Java

الأصناف المتداخلة في C# مزيج بين الأصناف المتداخلة الثابتة والأصناف الداخلية في Java. ففي C#، تقع الأعضاء الخاصة في الصنف المُحيط ضمن نطاق أعضاء الصنف المتداخل، لكن لا توجد صيغة خاصة لإنشاء نسخ منها وربطها بنسخة من الصنف المُحيط. عليك استخدام أحد أشكال النمط الموضح في الأمثلة أعلاه.

توجد في C# أصناف متداخلة ثابتة بالفعل، لكنها ليست سوى أصناف مُحاطة ذات سلوك ثابت.
