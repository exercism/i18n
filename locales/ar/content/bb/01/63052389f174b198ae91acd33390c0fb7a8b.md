# مقدمة

## تعبيرات `case`

في Gleam، يمكن استخدام تعبير `case` لتنفيذ الكود بشكل شرطي. باستخدام تعبير `case` يمكن اختبار قيمة مقابل نمط واحد أو أكثر من _الأنماط_. مثال على هذا النمط هو _النمط الحرفي_، الذي يطابق قيمة مقابل قيمة حرفية (مثل `1` أو `"hello"`).

تُكتب تعبيرات `case` باستخدام الكلمة المفتاحية `case`:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    1 -> "One"
  }
}
```

قد يبدو هذا مشابهًا لعبارات `switch` في لغات أخرى، لكن مطابقة الأنماط تتألق حقًا عند استخدام أنماط أخرى أيضًا. أحد هذه الأنماط هو _النمط المتغير_، الذي يسمح بإسناد قيمة إلى متغير. في هذا المثال، سيُسنَد إلى المتغير `i` قيمة `number` إذا لم تكن `0`:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i -> "Non zero"
  }
}
```

في بعض الحالات، قد ترغب في إضافة شرط إضافي إلى نمط. يُعرف هذا بـ _الحارس_ (الجملة الحارسة)، ويمكن إضافته باستخدام الكلمة المفتاحية `if`:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
  }
}
```

لأسباب تتعلق بالأداء، لا يُسمح في الحراس إلا بالعوامل الرياضية والمنطقية الأساسية، ولا يمكن استخدام دوال أخرى في الحراس.

في المثال أعلاه، لن يكون لكل مدخل ممكن نمط مطابق. سيكتشف المترجم هذا ويُخرج خطأً. يُعرف هذا بـ _التحقق الشامل_. لحل التحذير، يجب معالجة جميع الحالات. لهذا، يمكن استخدام _نمط التجاهل_، وهو نمط يطابق أي قيمة:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
    _ -> "Positive number"
  }
}

// No compiler error
```

يمكن مطابقة أنماط متعددة في جملة واحدة باستخدام `|` للفصل بين كل نمط. يمكن إضافة حارس واحد فقط إلى الجملة:

```gleam
pub fn describe(number: Int) -> String {
  let yell = True
  case number {
    0 -> "Zero"
    3 | 5 -> "One of the first odd prime numbers"
    2 | 4 | 6 | 8 if !yell -> "One of the even numbers less than 10"
    i if i % 2 == 0 && yell -> "[Yelling] I'm telling you! It's a even nunber"
    i if i < 0 -> "Negative number"
    _ -> "Positive number"
  }
}
// No compiler error
```

تختبر تعبيرات `case` قيمة ما مقابل كل نمط من الأعلى إلى الأسفل، حتى تجد نمطًا مطابقًا وتنفّذ المنطق المرتبط بذلك النمط. ترتيب الأنماط مهم!
