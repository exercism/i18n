# الأصناف ذات الحالة

كل صنف رأيناه حتى الآن كان صندوقًا من الإجراءات. أخذ كل واحد منها وسائطه، وحسب جوابًا، ثم نسي كل شيء.

في المقابل، يمكن للصنف أن **يتذكّر** الأشياء. ولوحة النتائج يجب أن تفعل ذلك: فالنتيجة الآن تعتمد على كل هدف سُجّل منذ بداية المباراة.

## السمات

`attr` يمنح الصنف شيئًا يتذكّره.

```sather
class SCOREBOARD is

   attr home_score : INT;
   attr away_score : INT;

end; -- class SCOREBOARD
```

يتحوّل كل `attr` إلى إجراء يقرأ القيمة، وإلى إجراء آخر يغيّرها:

```sather
   board.home_score            -- read it
   board.home_score := 4;      -- change it
```

ويمكن للسمات من النوع نفسه أن تشترك في تصريح واحد، كما تفعل الوسائط:

```sather
   attr home_score, away_score : INT;
```

## الكائنات

الصنف الذي له سمات هو قالب لصنع **الكائنات**. ولكل كائن نسخته الخاصة من السمات، لذا تحتفظ لوحتا نتائج بنتيجتين.

`new` يصنع كائنًا. وهو يُستدعى داخل إجراء يُسمّى `create`، يملأ الكائن ثم يُرجعه:

```sather
   create(home, away : STR) : SAME is
      board ::= new;
      board.home_team := home;
      board.away_team := away;
      return board;
   end;
```

`SAME` تعني «هذا الصنف». وكتابة `SCOREBOARD` في مكانها ستقول الشيء نفسه، لكن `SAME` تظل تعمل إذا أُعيدت تسمية الصنف.

## إنشاء كائن

`#` تستدعي `create`:

```sather
   board ::= #SCOREBOARD("Vixens", "Magpies");
```

كنت تستخدم `#` منذ `rehearsal-script`، و`#FSTR` هو هذا بالضبط.

## إجراءات تغيّر الكائن

داخل الصنف، تُستخدم السمة باسمها، دون أي كائن أمامها. وهي تعني الكائن الذي استُدعي عليه الإجراء.

```sather
   home_goal is
      home_score := home_score + 1;
   end;
```

لا يصرّح `home_goal` بأي نوع إرجاع، لأنه لا يُرجع شيئًا، بل يغيّر الكائن بدلًا من ذلك. استدعِه كعبارة:

```sather
   board.home_goal;
```

## السمات تبدأ فارغة

السمة التي لم يضبطها أحد تحمل صفرًا إذا كانت من نوع `INT`، و`false` إذا كانت من نوع `BOOL`، و`void` إذا كانت سلسلة نصية أو كائنًا. لذا تقرأ لوحة النتائج الجديدة 0 مقابل 0 دون أن يقول أي شيء ذلك.
