# مقدمة

## المحارف `char`

النوع الأولي `char` في Java هو تمثيل بطول 16 بت لمحرف واحد.
يمكن لعدة محارف `char` أن تشكّل سلسلة نصية، مثل `"word"`، أو يمكن معالجة محارف `char` كلٌّ على حدة.
تُحاط القيمة الحرفية من النوع `char` بعلامات اقتباس مفردة (مثل `'A'`).

```java
char lowerA = 'a';
char upperB = 'B';
```

## الحصول على محارف `String`

تُرجع الطريقة `String.toCharArray` محارف سلسلة نصية على هيئة مصفوفة.
وكما ذُكر في المصفوفات، يمكنك استخدام `for` حلقة للمرور على عناصر المصفوفة.

```java
String text = "Hello";
char[] asArray = text.toCharArray();

for (char ch: asArray) {
    System.out.println(ch);
}

// Outputs:
// H
// e
// l
// l
// o
```

## الصنف `Character`

توجد العديد من الدوال المدمجة في المكتبة لفحص محارف `char` ومعالجتها.
يمكن إيجادها كدوال `static` في الصنف `java.lang.Character`.
إليك بعض الأمثلة:

```java
Character.isWhitespace(' ');    // true
Character.isWhitespace('#');    // false

Character.isLetter('a');        // true
Character.isLetter('3');        // false

Character.isDigit('6');         // true
Character.isDigit('?');         // false
```

## إضافة `char` إلى `String`

يمكن استخدام العامل `+` لإضافة `char` إلى `String`.

```java
'a' + " banana"     // => "a banana"
"banana " + 'a'     // => "banana a"
```

~~~~exercism/caution
احرص على _ألّا_ تستخدم `+` لضم محرفَي `char` معًا لتكوين `String`!
إضافة محرفَي `char` بهذه الطريقة تُعطي `int`، _وليس_ `String`!
على سبيل المثال:

```java
'b' + 'c';
// => 197 (not the String "bc")
```

وذلك لأن Java تُرقّي `char` إلى `int` (انظر [4.2 الأنواع والقيم الأولية][jls-primitives] في [مواصفة لغة Java][jls-main]).

[jls-main]: https://docs.oracle.com/javase/specs/jls/se21/html/
[jls-primitives]: https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.2
~~~~

ومع ذلك، عندما يكون عدد المحارف المراد إضافتها كبيرًا، قد يكون استخدام `StringBuilder` أكثر كفاءة:

```java
StringBuilder builder = new StringBuilder();
builder.append('a');
builder.append('b');
builder.append('c');

String builtString = builder.toString();
// => abc
```
