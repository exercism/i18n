# التعليمات

أنت تتولّى صيانة مكتبة الماكرو التي بُني عليها محرّك تنضيد المجلة.
المحرّك نفسه، أي الدوال التي تنسّق كل صفحة، ثابت ولا تكتبه أنت.
ما تكتبه أنت هو الآليات التي يُبنى منها المحرّك في وقت التجميع.

لا يطلب منك هذا التمرين كتابة أي دالة، بل الماكرو فقط.
ثم تُضمَّن هذه الماكروات وتُستدعى في دوال معرّفة مسبقًا في ملف آخر.

لديك أربع مهام.

~~~~exercism/caution
يُستدعى كل ماكرو بالاسم نفسه وترتيب الوسائط نفسه الذي تحدده مهمته، فاكتبها تمامًا كما هي.
وإلا فلن يُجمَّع الملف.
~~~~

## 1. سمِّ ثوابت التنسيق

تنسيق المجلة بضعة أعداد ثابتة، وبقية التخطيط يشير إليها بالاسم فقط.
عليك أن تمنح كل واحد منها اسمًا مقروءًا في وقت التجميع:

- `COLUMN_COUNT` يساوي `4`
- `COLUMN_STRIDE` يساوي `18`
- `SPACE` يساوي `0x20`، وهو البايت الفارغ
- `RULE` يساوي `0x3D`، وهو البايت `=`
- `RULE_WIDTH` يساوي `4`
- `PLAIN` يساوي `0x2E`، وهو البايت `.`
- `RULED` يساوي `0x2D`، وهو البايت `-`
- `BOXED` يساوي `0x23`، وهو البايت `#`

يُبلّغ المحرّك عن هذه القيم بالترتيب أعلاه.

```c
out = {4, 18, 32, 61, 4, 46, 45, 35} // the eight named values, in order
```

## 2. اكتب الماكرو `fill_run`

يُفرّغ المحرّك مساحة التنضيد ويرسم خطوط الترويسة عن طريق طبع متتالية من بايت واحد مكرّر.
التقط هذه الخطوة في ماكرو متعدّد الأسطر يمكن للمحرّك استدعاؤه كلما احتاج إلى ملء متتالية.

أولًا، عرّف اسمًا مقروءًا `COUNTER` للسجل `rcx`.
ثم عرّف الماكرو `fill_run` الذي ينبغي أن يملأ مصفوفة بـ `N` نسخة من بايت.
يأخذ ثلاثة وسائط بهذا الترتيب:

1. عنوان الوجهة، ويُمرَّر في سجل عام بطول 64 بت.
2. عدد البايتات (`N`) المطلوب كتابتها، ويُمرَّر في سجل عام بطول 64 بت أو كقيمة فورية.
3. البايت المطلوب كتابته، ويُمرَّر كقيمة فورية.

```x86asm
fill_run rdi, rax, SPACE
fill_run rdx, RULE_WIDTH, RULE
```

يجوز للماكرو `fill_run` أن يطمس `COUNTER` بحرية، ولكن ليس أي سجل آخر.

لاحظ أن عدد البايتات قد يُمرَّر في سجل عام بطول 64 بت، مثل `rax` أو `rsi`، أو كقيمة فورية، مثل `10` أو `4`.
ويمكنك اعتبار أن هذا العدد ليس سالبًا أبدًا.

يُستدعى هذا الماكرو ثلاث مرات، في دالتين مختلفتين.

```c
length = 8
page   = {32, 32, 32, 32, 32, 32, 32, 32}

width  = 8
page   = {61, 61, 61, 61, 32, 32, 32, 32} // '====' then spaces
```

## 3. اكتب الماكرو `lay_columns`

الشبكة ثابتة بالنسبة إلى التنسيق، لذا يمكن حساب بدايات الأعمدة في وقت التجميع.

عرّف الماكرو `lay_columns`، الذي يكتب عددًا من الإزاحات مقداره `COLUMN_COUNT`، كل واحدة عدد صحيح بطول 64 بت.
يأخذ وسيطين بهذا الترتيب:

1. عنوان الوجهة، ويُمرَّر في سجل عام بطول 64 بت
2. الهامش الأيسر، ويُمرَّر في سجل عام بطول 64 بت

```x86asm
lay_columns rsi, rax
```

عدد الإزاحات التي ستُكتب في عنوان الوجهة ثابت ويساوي `COLUMN_COUNT`.

كل إزاحة قيمة بطول 64 بت تُحسب بالصيغة `offset[i] = margin + i * COLUMN_STRIDE`، حيث `i` هو فهرس الإزاحة بدءًا من `0`، و`margin` هو الوسيط الثاني.

يجوز لهذا الماكرو أن يطمس وسيطيه من السجلات، ولا غيرهما.
يُستدعى مرة واحدة.

```c
margin = 3
out    = {3, 21, 39, 57}
```

## 4. اكتب الماكرو `set_header`

لكل قسم من الأقسام الثابتة الثلاثة نمط ترويسة يحدده التنسيق، لذا فالبايت معروف في وقت التجميع.

عرّف `set_header`، وهو يأخذ وسيطين بهذا الترتيب:

1. عنوان الوجهة.
2. معرّف نمط حرفي يُمرَّر كقيمة فورية، حيث يمثّل `0` النمط البسيط، و`1` المسطّر، و`2` المؤطّر.

عنوان الوجهة هو تعبير عن عنوان ذاكرة فعّال.
وهو يتألف من سجل أساس يمكن جمعه مع سجل فهرس مضروب في `1` أو `2` أو `4` أو `8`، وقيمة فورية:

```x86asm
set_header rdx+8*rcx+2, 1
```

اختر بايت الترويسة (`PLAIN` أو `RULED` أو `BOXED`) عبر التجميع الشرطي (`%if` / `%elif` / `%else`) بدلًا من تفرّع أثناء التشغيل.

ينبغي ألا يطمس هذا الماكرو أي سجل.
يُستدعى ثلاث مرات في الدالة نفسها.

```c
pitch = 4
out   = {46, 0, 0, 0, 45, 0, 0, 0, 35} // '.', '-', '#'
```
