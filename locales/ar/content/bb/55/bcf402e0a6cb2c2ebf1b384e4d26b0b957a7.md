# التعليمات

يتناول هذا التمرين تحليل ملفات السجلات.

بعد مراجعة أمنية حديثة، طُلب منك تنظيف ملفات السجلات المؤرشفة في المؤسسة.

جميع السلاسل النصية التي تُمرَّر إلى الطرق مضمونة بأنها ليست `null` وخالية من المسافات البادئة واللاحقة.

## 1. تحديد أسطر السجل المشوَّشة

تحتاج إلى فكرة عن عدد أسطر السجل في أرشيفك التي لا تتوافق مع المعايير الحالية. وتعتقد أن اختبارًا بسيطًا يكشف ما إذا كان سطر السجل صالحًا. ولكي يُعتبر السطر صالحًا، يجب أن يبدأ بواحدة من السلاسل النصية التالية:

- [TRC]
- [DBG]
- [INF]
- [WRN]
- [ERR]
- [FTL]

نفّذ الطريقة `LogParser.IsValidLine()` لتُرجع `false` إذا لم تكن السلسلة النصية صالحة، و`true` خلاف ذلك.

```csharp
var lp = new LogParser();
lp.IsValidLine("[ERR] A good error here");
// => true
lp.IsValidLine("Any old [ERR] text");
// => false
lp.IsValidLine("[BOB] Any old text");
// => false
```

## 2. تقسيم سطر السجل

انضم فريق جديد إلى المؤسسة، وتكتشف أن ملفات سجلاته تستخدم فاصلًا غريبًا بين "الحقول". فبدلًا من شيء منطقي مثل النقطتين ":"، يستخدمون سلسلة نصية مثل "<--->" أو "<=>" (لأنها أجمل)، بل أي سلسلة نصية يبدأ أول حرف فيها بـ "<" وينتهي آخر حرف فيها بـ ">" ويقع في ما بينهما أي مزيج من الأحرف "^" و"\*" و"=" و"-".

نفّذ الطريقة `LogParser.SplitLogLine()` التي تأخذ سطرًا وتُرجع مصفوفة من السلاسل النصية، كل منها يحتوي على حقل.

```csharp
var lp = new LogParser();
lp.SplitLogLine("Section 1<===>Section 2<^-^>Section 3");
// => {"Section 1", "Section 2", "Section 3"}
```

## 3. عدّ الأسطر التي تحتوي على كلمة مرور بين علامات اقتباس

يحتاج الفريق إلى معرفة كلمات المرور الواردة داخل نص محاط بعلامات اقتباس حتى يمكن فحصها يدويًا.

نفّذ الطريقة `LogParser.CountQuotedPasswords()` لتقديم مؤشر على الحجم المحتمل للعمل اليدوي.

حدّد أسطر السجل التي تكون فيها السلسلة النصية الحرفية "password"، التي قد تأتي بأي مزيج من الأحرف الكبيرة أو الصغيرة، محاطة بعلامات اقتباس.
يجب أن تراعي احتمال وجود محتوى إضافي بين علامات الاقتباس قبل "password" وبعده.

قد تكون الأسطر التي تُمرَّر إلى الدالة صالحة أو غير صالحة وفقًا لما حُدِّد في المهمة 1. ونعالجها بالطريقة نفسها، سواء كانت صالحة أم لا.

```csharp
string lines =
    "[INF] passWord " + Environment.NewLine + // contains 'password' but not surrounded by quotation marks
    "\"passWord\"" + Environment.NewLine + // count this one
    "[INF] User saw error message \"Unexpected Error\" on page load." + Environment.NewLine + //does not contain 'password'
    "[INF] \"The secret password was added by the user\""; // count this one

var lp = new LogParser();
lp.CountQuotedPasswords(lines);
// => 2
```

## 4. إزالة الآثار من السجل

اكتشفت أن بعض المعالجة الأولية للسجلات كانت تنثر النص "end-of-line" متبوعًا برقم سطر (دون مسافة فاصلة) في أنحاء السجلات.

نفّذ الطريقة `LogParser.RemoveEndOfLineText()` لتأخذ سلسلة نصية وتزيل نص نهاية السطر وتُرجع سلسلة نصية "نظيفة".

يجب إرجاع الأسطر التي لا تحتوي على نص نهاية السطر دون تعديل.

أزل سلسلة نص نهاية السطر فقط. ولا تحاول تعديل المسافات البيضاء.

```csharp
var lp = new LogParser();
lp.RemoveEndOfLineText("[INF] end-of-line23033 Network Failure end-of-line27");
// => "[INF]  Network Failure "
```

## 5. سرد الأسطر ذات كلمات المرور الضعيفة للغاية حتى يُعاقب المذنبون

قبل محو كلمات المرور من الملف، نحتاج إلى سرد كل الحالات التي تبدأ فيها كلمات المرور بالنص "password".

نفّذ الطريقة `LogParser.ListLinesWithPasswords()` لطبع كلمة المرور المخالفة متبوعة بالسطر الكامل.

لقد أُزيلت بالفعل الأسطر التي تحتوي على كلمات مرور بين علامات اقتباس، وأنت تعالج الأسطر بغض النظر عما إذا كانت صالحة (وفقًا للمهمة 1).

يجب إرجاع الأسطر التي تحتوي على كلمة مرور مخالفة مسبوقة بـ "<password>: ".

يجب إرجاع الأسطر التي لا تحتوي على كلمة مرور مخالفة مسبوقة بـ "--------: ".

```csharp
var lp = new LogParser();
lp.ListLinesWithPasswords(new string[] {"my passwordsecret is great"});
// => "passwordsecret: my passwordsecret is great"
lp.ListLinesWithPasswords(new string[] {"my password secret"});
// => {"--------: my password secret"}

```
