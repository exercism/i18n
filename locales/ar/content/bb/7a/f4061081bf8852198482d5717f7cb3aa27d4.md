# التعليمات

ينتقل فريق التصميم لديك من تحويلات CSS إلى Factor في بعض أعمال التخطيط. ولإبقاء بقية الفريق سعيدًا، ستبني تحويلات صغيرة قابلة لإعادة الاستخدام على هيئة `quotation` تأخذ نقطة ثنائية الأبعاد وتُرجع نقطة ثنائية الأبعاد.

النقطة هي مصفوفة مكوّنة من عنصرين `{ x y }`.

## 1. إزاحة الإحداثيات

عرّف `translate-2d` بحيث تأخذ قيمتين `dx` و `dy` من المكدس وتُرجع `quotation` يُزيح نقطة بمقدار `(dx, dy)`.

```factor
{ 4 8 } 2 0 translate-2d call( p -- p' ) .
! => { 6 8 }
```

## 2. تحجيم الإحداثيات

عرّف `scale-2d` بالكيفية نفسها، بحيث تُرجع `quotation` يُحجّم نقطة بمقدار `(sx, sy)`.

```factor
{ 6 -3 } 2 2 scale-2d call( p -- p' ) .
! => { 12 -6 }
```

## 3. تركيب تحويلين

عرّف `compose-transformations` بحيث تأخذ `quotation` للتحويل `f` و `quotation` آخر للتحويل `g`، وتُرجع `quotation` واحدًا يطبّق `f` أولًا ثم `g`.

```factor
{ 0 1 } 2 0 translate-2d 2 2 scale-2d compose-transformations
call( p -- p' ) .
! => { 4 2 }
```

## 4. تطبيق تحويل

عرّف `apply-transformation` بحيث تأخذ من المكدس نقطة و `quotation` تحويليًا، وتُرجع النقطة بعد التحويل.

```factor
{ 4 8 } 2 0 translate-2d apply-transformation .
! => { 6 8 }
```

## 5. تحويل نقاط متعددة دفعة واحدة

عرّف `transform-points` بحيث تأخذ مصفوفة من النقاط و `quotation` تحويليًا، وتُرجع مصفوفة النقاط بعد التحويل.

```factor
{ { 0 0 } { 1 1 } { 2 2 } } 1 0 translate-2d transform-points .
! => { { 1 0 } { 2 1 } { 3 2 } }
```
