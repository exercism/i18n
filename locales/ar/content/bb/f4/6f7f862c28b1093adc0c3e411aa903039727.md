# التعليمات

في هذا التمرين، ستقوم بمزيد من العمل على سيارات التحكم عن بُعد.

طُوّرت سيارة تجريبية، ويحتاج مضمار الاختبار إلى تكييف ليتعامل مع الطرازين الإنتاجي والتجريبي.
وقد صُنع نوعا السيارتين بالفعل، وعليك إيجاد أسلوب للتعامل مع كليهما على مضمار الاختبار.

إضافة إلى ذلك، بدأت السيارات الإنتاجية تحقق بعض النجاح.
ويتطلع رئيس الفريق إلى الحفاظ على الروح التنافسية بنشر تصنيف للسيارات الإنتاجية.

## 1. تنفيذ الواجهة

يُرجى إضافة طريقتين إلى واجهة `RemoteControlCar`:

- `drive()`، ولا تُرجع شيئًا، و
- `getDistanceTravelled()`، وتُرجع قيمة `int`.

ثم اجعل `ProductionRemoteControlCar` و`ExperimentalRemoteControlCar` ينفّذان واجهة `RemoteControlCar`.
ويشمل ذلك تنفيذ جميع الطرق التي تتطلبها الواجهة.

## 2. القيادة

ينبغي لكل استدعاء لـ `.drive()` أن يجعل السيارة تقطع مسافة معينة:

- السيارة `ProductionRemoteControlCar` تقطع 10 وحدات،
- والسيارة `ExperimentalRemoteControlCar` تقطع 20 وحدة.

ينبغي أن تُرجع طريقة `.getDistanceTravelled()` عدد الوحدات التي قطعتها السيارة طوال عمرها.

```java
ProductionRemoteControlCar prod = new ProductionRemoteControlCar();
prod.drive();
prod.getDistanceTravelled();
// => 10
        
ExperimentalRemoteControlCar exp = new ExperimentalRemoteControlCar();
exp.drive();
exp.getDistanceTravelled();
// => 20
```

## 3. السباق

نفّذ طريقة `TestTrack.race(RemoteControlCar car)`، التي تتاح فيها للسيارات `car` فرصة استدعاء `drive()`.

```java
TestTrack.race(new ProductionRemoteControlCar());
TestTrack.race(new ExperimentalRemoteControlCar());
// this should execute without an exception being thrown
```

## 4. تمكين ترتيب السيارات الإنتاجية

يُرجى تنفيذ واجهة `Comparable<T>` في صنف `ProductionRemoteControlCar`.
ينبغي أن يكون ترتيب الفرز الافتراضي للسيارات تنازليًا حسب عدد الانتصارات.

نفّذ الطريقة الثابتة `TestTrack.getRankedCars()` لتُرجع السيارات الممرَّرة، مرتبة تنازليًا حسب عدد الانتصارات.

```java
ProductionRemoteControlCar prc1 = new ProductionRemoteControlCar();
ProductionRemoteControlCar prc2 = new ProductionRemoteControlCar();
prc1.setNumberOfVictories(2);
prc2.setNumberOfVictories(3);
List<ProductionRemoteControlCar> unsortedCars = new ArrayList<>();
unsortedCars.add(prc1);
unsortedCars.add(prc2);
List<ProductionRemoteControlCar> rankings = TestTrack.getRankedCars(unsortedCars);
// => rankings.get(0) == prc2
// => rankings.get(1) == prc1
```
