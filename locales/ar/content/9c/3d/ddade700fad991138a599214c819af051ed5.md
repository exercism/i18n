# مقدمة

في Go، كل متغير له قيمة.
تعريف متغير دون إسناد قيمة له يضبطه على القيمة الصفرية لنوعه.

الأنواع الأساسية، بما فيها `bool` والأنواع العددية و`string`، لكل منها قيمة صفرية ثابتة:

| النوع                  | القيمة الصفرية |
| ---------------------- | ---------- |
| bool                   | `false`    |
| int, int8, int64، إلخ. | `0`        |
| float32, float64       | `0`        |
| complex64, complex128  | `0+0i`     |
| string                 | `""`       |

المؤشرات والدوال والواجهات والشرائح والقنوات والخرائط، لكل منها قيمة صفرية هي `nil`.

المصفوفات والبنى ليست `nil` أبدًا لأنها تحمل البيانات مباشرة، وليس مرجعًا إليها.
يُهيّأ كل عنصر في مصفوفة وكل حقل في بنية إلى القيمة الصفرية لنوعه.
على سبيل المثال، `var a [3]int` يُنشئ المصفوفة `[0, 0, 0]`.

## تعريف القيم الصفرية

استخدم `var` للإعلان عن متغير:

```go
var myBool bool   // false
var mySlice []int // nil
```

استخدم تركيبًا حرفيًا مركبًا `T{}` للبنى:

```go
type Person struct {
    Name string
    Age  int
}

myPerson := Person{} // Person{Name: "", Age: 0}
```
