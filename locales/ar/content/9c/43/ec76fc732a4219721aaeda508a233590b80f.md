# مقدمة

المصفوفات هي نوع التسلسل الأساسي ثابت الطول في Factor، وتُكتب `{ … }`: يمكنك تغيير العناصر، لكن ليس الطول. تمنحك مفردات `arrays` و`sequences` معًا منشئات صغيرة تأخذ القيم من المكدس، إضافة إلى عمليات يومية للدمج والعكس والبحث عن العناصر.

```factor
USING: arrays sequences ;

42 1array .                ! => { 42 }
"a" "b" "c" 3array .       ! => { "a" "b" "c" }
{ { 1 2 } { 3 4 } } concat .   ! => { 1 2 3 4 }
{ 1 2 3 } reverse .            ! => { 3 2 1 }
```

[arrays]: https://docs.factorcode.org/content/vocab-arrays.html
[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
