# التعليمات

ستستبدل محطة الطقس في ويلينغتون نظامها اليدوي لتسجيل درجات الحرارة بنظام رقمي جديد.
في النظام القديم، كانت الحسابات تُجرى يدويًا.
وفي النظام الجديد، ستصبح آلية.
تشمل هذه الحسابات تحويل درجة الحرارة من المئوية إلى الفهرنهايت وإيجاد متوسط درجة الحرارة.
يحتوي النظام الجديد على مستشعرات لتسجيل بيانات درجات الحرارة بالمئوية.

تريد محطة الطقس في ويلينغتون مساعدتك في النظام الجديد.

## 1. تحويل درجة الحرارة من المئوية إلى الكلفن

للمحطة قسم على موقعها الإلكتروني مخصص للباحثين.
يهتم الباحثون بدرجة الحرارة بالكلفن.

الكلفن وحدة تُستخدم لقياس درجة الحرارة.
وهو على المقياس نفسه الذي تستخدمه المئوية، لكن بنقطة بداية مختلفة.
نقطة بدايته هي الصفر المطلق، أي 0K (كلفن) أو -273.15°C (مئوية).

إليك جدولًا يوضح التحويل بين المئوية والكلفن:

| مئوية(°C) | كلفن(K) |
| ----------- | --------- |
| -273.15     | 0         |
| -100        | 173.15    |
| 0           | 273.15    |
| 100         | 373.15    |

تريد منك المحطة تنفيذ طريقة تحوّل درجة الحرارة من المئوية إلى الكلفن.

نفّذ الطريقة `Temperature#to_kelvin` التي تأخذ وسيطًا `celsius` وتُرجع درجة الحرارة بالكلفن بإضافة 273.15 إلى القيمة المعطاة `celsius`.

```crystal
Temperature.new.to_kelvin(0)
# => 273.15
```

## 2. تقريب درجة الحرارة

مستشعر درجة الحرارة في المحطة دقيق.
يمكنه قياس درجة الحرارة حتى أقرب 0.0001°C.
تريد المحطة عرض درجة الحرارة مقرّبة إلى منزلة عشرية واحدة فقط، لأن معظم المستخدمين لا يهمهم هذا المستوى من الدقة.

تريد منك المحطة تنفيذ طريقة تقرّب درجة الحرارة إلى منزلة عشرية واحدة.

نفّذ الطريقة `Temperature#round` التي تأخذ وسيطًا `celsius` وتُرجع درجة الحرارة مقرّبة إلى منزلة عشرية واحدة.

```crystal
Temperature.new.round(10.1234)
# => 10.1

Temperature.new.round(10.1567)
# => 10.2
```

## 3. تحويل درجة الحرارة من المئوية إلى الفهرنهايت

للمحطة قسم على موقعها الإلكتروني مخصص للسياح.
يهتم السياح بدرجة الحرارة بالفهرنهايت.

فهرنهايت وحدة لقياس درجة الحرارة.
وهو يستخدم مقياسًا مختلفًا عن المئوية.
0°C تساوي 32°F، وتعادل الدرجة المئوية الواحدة 1.8 درجة فهرنهايت.

إليك جدولًا يوضح التحويل بين المئوية والفهرنهايت:

| مئوية(°C) | فهرنهايت(°F) |
| ----------- | -------------- |
| -273.15     | -459.8         |
| -100        | -148            |
| 0           | 32             |
| 100         | 212            |

تريد منك المحطة تنفيذ طريقة تحوّل درجات الحرارة من المئوية إلى الفهرنهايت.

نفّذ الطريقة `Temperature#to_fahrenheit` التي تأخذ وسيطًا `celsius` وتُرجع درجة الحرارة بالفهرنهايت كعدد صحيح.

```crystal
Temperature.new.to_fahrenheit(10)
# => 50
```

## 4. معرفة عدد المستشعرات المفقودة

أثناء تركيب مستشعرات الحرارة، اكتشف عمال الصيانة أن بعض المستشعرات مفقودة.
تحتاج كل وحدة قياس لدرجة الحرارة إلى أربعة مستشعرات حرارة.
أحصى فريق الصيانة عدد المستشعرات التي لديه، لكنه احتاج إلى معرفة عدد المفقود منها.
ويرغب في المساعدة لحساب عدد المستشعرات التي يحتاج إلى شرائها لبناء وحدة قياس حرارة كاملة أخرى.

نفّذ الطريقة `Temperature#number_missing_sensors` التي تأخذ وسيطًا `number_of_sensors` وتُرجع عدد المستشعرات المفقودة.

```crystal
Temperature.new.number_missing_sensors(10)
# => 2
```
