# مقدمة

## متغيرات الكائن

يمكن للكائنات أن تحتفظ بحالتها الخاصة عبر تعيين _متغيرات الكائن_.
تعيش هذه المتغيرات داخل الكائن، وتُستخدم عادةً لتخزين بعض الحالة الداخلية.

تبدأ متغيرات الكائن دائمًا بعلامة `@`.
يمكنك إنشاء متغير كائن جديد بتعيين متغير يبدأ بـ `@`.
على سبيل المثال:

```ruby
class Repeater
  def hear(something)
    # Save what's been heard into a new instance variable called @heard
    @heard = something
  end

  def repeat
    # Return the value of the instance variable
    @heard
  end
end

repeater = Repeater.new
repeater.hear("Hello, friend!")
print repeater.repeat # Prints "Hello, friend!"
```

عادةً ما تُعيّن الكائنات حالتها الأولية في طريقة `initialize`، وهي طريقة تُستدعى تلقائيًا عند استدعاء `new` على صنف.

```ruby
class Airplane
  def initialize
    @wings = 2
  end

  def wings
    @wings
  end
end

plane = Airplane.new
plane.wings # returns 2
```

يمكن لطريقة `initialize` أيضًا أن تأخذ وسائط، بحيث يبدأ كل كائن بحالة مخصصة:

```ruby
class Suitcase
  def initialize(locked)
    @locked = locked
  end
end
```

من الممارسات الجيدة أن تعتبر _متغيرات الكائن_ خاصة، بحيث لا تُقرأ ولا تُكتب من الخارج.
وبدلًا من ذلك، نعرّف طرقًا للحصول على قيمها وتعيينها.
على سبيل المثال:

```ruby
class Suitcase
  def initialize
    @locked = false
  end

  def locked? # Query methods should be named with a trailing `?`
    @locked
  end

  def lock! # Methods which mutate state should have trailing `!`
    @locked = true
  end
end

suitcase = Suitcase.new
suitcase.locked? # false
suitcase.lock!
suitcase.locked? # true
```

## Nil

[Nil][nil-dictionary] كلمة إنجليزية تعني «لا شيء» أو «صفر».
في Ruby، يُستخدم `nil` للتعبير عن _غياب_ الكائن.
وفي لغات برمجة أخرى، قد تؤدي قيم مثل `null` أو `none` دورًا مشابهًا.

```ruby
# I do not have a favorite color
favorite_color = nil
```

يمنح Ruby أي متغير كائن القيمة الافتراضية `nil` عند أول ظهور له، إلى أن تُسند إليه قيمة أخرى.

```ruby
print @favourite_color # prints nil
@favourite_color = "blue"
print @favourite_color # prints "blue"
```
