# حول

أهم ما يجب تذكّره عن السلاسل النصية في C# هو أنها كائنات غير قابلة للتغيير تمثّل نصًّا على هيئة تسلسل من محارف يونيكود (حروف، وأرقام، وعلامات ترقيم، وغيرها). تُستخدم علامات الاقتباس المزدوجة لتعريف نسخة من `string`:

```csharp
string fruit = "Apple";
```

يمكن التعامل مع السلسلة النصية باستدعاء إحدى [طرقها][methods] أو [خصائصها][properties]. ولأن قيم السلاسل النصية لا يمكن أن تتغيّر بعد تعريفها، فإن جميع طرق التعامل مع السلاسل النصية ستُرجع سلسلة نصية جديدة.

تُحدَّد السلسلة النصية بعلامات الاقتباس المزدوجة (`"`). بعض المحارف الخاصة تحتاج إلى [الهروب][escaping] باستخدام الشرطة المائلة العكسية (`\`). ويمكن أيضًا أن تُسبق السلاسل النصية بالرمز (`@`)، مما يجعلها [سلسلة نصية حرفية][verbatim] تتجاهل أي محارف مهروبة.

```csharp
string escaped = "c:\\test.txt";
string verbatim = @"c:\test.txt";
escaped == verbatim;
// => true
```

إذا كنت تحتاج إلى جزء من السلسلة النصية فقط، فيمكنك استخدام [الطريقة `Substring()`][substring] لاستخراج ذلك الجزء فقط:

```csharp
string sentence = "Frank chases the bus.";
string name = sentence.Substring(0, 5);
// => "Frank"
```

ويمكن استخدام [الطريقة `IndexOf`()][indexof] للعثور على فهرس أول ظهور لـ `string` داخل `string`، وهي تُرجع `-1` إذا تعذّر العثور على القيمة المحددة:

```csharp
"continuous-integration".IndexOf("integration")
// => 11

"continuous-integration".IndexOf("deployment")
// => -1
```

وأخيرًا، هناك [أساليب عديدة لدمج السلاسل النصية][concatenation]. أبسطها استخدام [العامل `+`][plus-operator].

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

لأي تنسيق سلاسل نصية أكثر تعقيدًا من الدمج البسيط، يُفضَّل [إدراج التعبيرات في السلاسل النصية][interpolation]. ولتفعيل الإدراج في سلسلة نصية، اسبقها بالرمز (`$`).

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
