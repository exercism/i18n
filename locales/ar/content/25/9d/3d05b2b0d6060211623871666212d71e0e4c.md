# التعليمات

أنت تسجّل أعداد الطيور التي تزور حديقتك كل يوم. تُخزَّن هذه البيانات في مصفوفة من الأعداد الصحيحة، بحيث يكون **عدّ اليوم في المقدمة**.

## 1. عدّ اليوم

عرّف `today` بحيث تأخذ مصفوفة من الأعداد اليومية من المكدس وتُرجع عدّ اليوم، أو `f` إذا كانت المصفوفة فارغة.

```factor
{ 2 5 1 } today .
! => 2

{ } today .
! => f
```

## 2. زيادة عدّ اليوم

عرّف `increment-day-count` لتُرجع مصفوفة جديدة زاد فيها عدّ اليوم بمقدار واحد. إذا كان المُدخَل فارغًا، أرجِع `{ 1 }`.

```factor
{ 4 0 2 } increment-day-count .
! => { 5 0 2 }

{ } increment-day-count .
! => { 1 }
```

## 3. هل كان هناك يوم بلا طيور؟

عرّف `has-day-without-birds?` لتُرجع `t` إذا سجّل يوم واحد على الأقل صفر طيور، وإلا فـ `f`.

**استخدم العودية** بدلًا من `any?` أو غيرها من الكلمات عالية الرتبة التي تعمل على المتسلسلات.

```factor
{ 2 0 4 } has-day-without-birds? .   ! => t
{ 3 8 1 5 } has-day-without-birds? . ! => f
```

## 4. إجمالي الطيور منذ أن بدأت

عرّف `total` لتُرجع مجموع كل الأعداد.

**استخدم العودية** بدلًا من `sum`.

```factor
{ 4 0 9 0 5 } total .
! => 18
```

## 5. الأيام المزدحمة

اليوم المزدحم هو يوم شوهدت فيه خمسة طيور أو أكثر. عرّف `busy-days` لتُرجع عدد الأيام المزدحمة.

**استخدم العودية** بدلًا من `count`.

```factor
{ 4 5 0 0 6 } busy-days .
! => 2
```
