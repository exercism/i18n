# مقدمة في التعامل مع البتات

تحتوي Java على عوامل للتعامل مع بتات `byte` و`short` و`int` و`long` و`char`.

## عوامل الإزاحة

استخدم `<<` لإزاحة البتات إلى اليسار و`>>` لإزاحتها إلى اليمين.

```java
// Shift two places to the left
0b0000_1011 << 2;
// # => 0b0010_1100

// Shift two places to the right
0b0000_1011 >> 2;
// # => 0b0000_0010
```

يُدخل العامل `<<` دائمًا أصفارًا في الطرف الأيمن.
أما `>>` فيُدخل البت نفسه الموجود في أقصى اليسار (1 إذا كان العدد سالبًا أو 0 إذا كان موجبًا).

```java
// Shift 2 places to the right preserves the sign
// This is a negative value, whose binary representation is
// 1000_0000_0000_0000_0000_0000_0010_0110
int value = -0x7FFFFFDA;

// Shift two places to the right, preserving the sign bit
value >> 2;
// # => 1110_0000_0000_0000_0000_0000_0000_1001
```

استخدم `>>>` بدلًا منه عندما تريد إدخال أصفار عند الإزاحة إلى اليمين.

```java
// Shift two places to the right, inserting 0s on the left
value >>> 2;
// # => 0010_0000_0000_0000_0000_0000_0000_1001
```

## العمليات على مستوى البتات

### العملية AND على مستوى البتات

يأخذ العامل AND على مستوى البتات (`&`) قيمتين ويجري عملية AND على كل بت.
يقارن كل بت من القيمة الأولى بالبت الذي يقابله في الموضع نفسه من القيمة الثانية.
إذا كان كلاهما 1، فإن بت الناتج يكون 1.
وإلا فإن بت الناتج يكون 0.

```java
0b0110_0101 & 0b0011_1100;
// # => 0b0010_0100
```

### العملية OR على مستوى البتات

يأخذ العامل OR على مستوى البتات (`|`) قيمتين ويجري عملية OR على كل بت.
يقارن كل بت من القيمة الأولى بالبت الذي يقابله في الموضع نفسه من القيمة الثانية.
إذا كان أي من البتين 1، فإن بت الناتج يكون 1.
وإلا فإنه يكون 0.

```java
0b0110_0101 | 0b0011_1100;
// # => 0b0111_1101
```

### العملية XOR على مستوى البتات

يجري العامل XOR على مستوى البتات (`^`) عملية XOR على قيمتين.
ومثل عاملي AND وOR على مستوى البتات، يقارن كل بت من القيمة الأولى بالبت الذي يقابله في الموضع نفسه من القيمة الثانية.
إذا كان واحد منهما فقط 1، فإن بت الناتج يكون 1.
وإلا فإنه يكون 0.

```java
0b0110_0101 ^ 0b0011_1100;
// # => 0b0101_1001
```

### العملية NOT على مستوى البتات (`~`)

وأخيرًا، يقلب العامل NOT على مستوى البتات (`~`) كل بت.
وخلافًا للعوامل السابقة، هذا عامل أحادي يعمل على قيمة واحدة فقط.

```java
~0b0110_0101;
// # => 0b1001_1010
```
