# نبذة

[الصف](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples) هو تجميع _غير قابل للتغيير_ لقيم غير مسماة ولكن مرتبة.
يمكن للصفوف أن تحمل أي نوع بيانات (أو عدة أنواع بيانات)، بما في ذلك صفوف أخرى.

تُعرَّف الصفوف كقيم مفصولة بفواصل بين المحرفين `(` و `)`: `(<element_1>, ... , <element_n>)`.

```fsharp
("one", 2) // Tuple pair (2 values)
("one", 2, true) // Tuple triplet (3 values)
```

لا يمكن مقارنة إلا الصفوف التي لها الطول نفسه والأنواع نفسها (وبالترتيب نفسه).
للصفوف تساوٍ بنيوي، وهذا يعني أنها متساوية _فقط_ إذا كانت جميع قيمها متساوية.

```fsharp
(1, 2) = (1, 2) // Same length, same types, same values, same order
// => true

(1, 2) = (2, 1) // Same length, same types, same values, different order
// => false

(1, 2) = (1, "2") // Same length, different types
// compiler error

(1, 2) = (1, 2, 3) // Different length
// compiler error
```

توجد [ثلاث طرق يمكنك من خلالها استخراج القيم من صف](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples#obtaining-individual-values):

- الدالتان `fst` و `snd`
- تفكيك الصف
- مطابقة الأنماط

```fsharp
let person = ("Jordan", 170)

// Option 1: fst/snd
let name1 = fst person
let length1 = snd person

// Option 2: deconstruction
let (name2, length2) = person

// Option 3: pattern matching
match person with
| name3, length3 -> printf "%s: %d" name3 length3
```

~~~~exercism/note
من الناحية التقنية، يمكنك الوصول إلى قيمة صف باستخدام خصائصه `.Item1` و `.Item2` و ...، لكن هذا غير مستحسن ويؤدي إلى تحذير من المترجم.
~~~~

## نقاط أساسية حول الصفوف

بعض الأمور الأساسية التي ينبغي معرفتها عن الصفوف هي:

- نسخة معينة من نوع الصف هي كائن واحد، أشبه بمصفوفة من عنصرين في C#، على سبيل المثال. وعند استخدامها مع الدوال، تُحسب معاملًا واحدًا. والاستثناء الوحيد هو عند استدعاء كود ليس بـ F# بمعاملات متعددة، وفي هذه الحالة تمرر صفًا وستُستخرج قيمه تلقائيًا إلى قيمة المعامل المقابل.
- لا يمكن إعطاء أنواع الصفوف أسماء صريحة. و«اسم» نوع الصف يُحدَّد من خلال تركيبة الأنواع التي تُضرب معًا.
- الفاصلة هي الرمز الحاسم الذي يعرّف الصفوف، وليس الأقواس الهلالية. يمكنك تعريف الصفوف دون الأقواس الهلالية، مع أن ذلك قد يكون مربكًا أحيانًا. في F#، إذا رأيت فاصلة، فمن المحتمل أنها جزء من صف.
- يمكن استخدام الصفوف كوسائط للدالة وكقيمة إرجاع للدالة.
