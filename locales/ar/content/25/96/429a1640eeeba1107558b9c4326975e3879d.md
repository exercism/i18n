# حول

عندما تقبل الدالة دالةً أخرى (أو إغلاقًا) في صورة معامل، فإن ذلك الإغلاق الممرَّر يُسمى *غير هارب* افتراضيًا.
ويُقال إن الإغلاق *يهرب* من الدالة عندما يُستدعى بعد أن تكون الدالة نفسها قد أرجعت بالفعل.

يحدث هذا الموقف عادةً في الحالات الآتية:

- يُخزَّن الإغلاق في متغير أو خاصية خارجية.
- يُنفَّذ الإغلاق بشكل غير متزامن بعد اكتمال عملية ما.
- يُرجَع الإغلاق من الدالة ليُستدعى لاحقًا.

لنتأمل المثال الآتي:

```swift
func emptyKitchen(_ order: String) -> String {
    "Sorry, we're all out of \(order)."
}

func prepare(order: String, kitchen: (String) -> String) -> (String) -> String {
    func newKitchen(_ newOrder: String) -> String {
        if newOrder == order {
            return "One \(order) coming up!"
        } else {
            return kitchen(newOrder)
        }
    }
    return newKitchen
}
```

في هذا الكود، تقبل الدالة `prepare` دالةً اسمها `kitchen`، وتبني دالة جديدة `newKitchen` تستدعي `kitchen`، ثم تُرجع `newKitchen`.
ومحاولة تصريف هذا الكود تُنتج خطأً: `Escaping local function captures non-escaping parameter 'kitchen'`.

بما أن `newKitchen` تبقى موجودة بعد انتهاء `prepare`، فإن الإغلاق `kitchen` يهرب.
للسماح بذلك، أضف السمة `@escaping` إلى نوع المعامل.

```swift
func prepare(order: String, kitchen: @escaping (String) -> String) -> (String) -> String {
    func newKitchen(_ newOrder: String) -> String {
        if newOrder == order {
            return "One \(order) coming up!"
        } else {
            return kitchen(newOrder)
        }
    }
    return newKitchen
}

let restaurant = prepare(
    order: "sandwich",
    kitchen: prepare(
        order: "chicken",
        kitchen: prepare(order: "steak", kitchen: emptyKitchen)
    )
)

print(restaurant("pork chop"))
// Prints "Sorry, we're all out of pork chop."

print(restaurant("chicken"))
// Prints "One chicken coming up!"
```

السمة `@escaping` تُخبر مُصرِّف Swift بأن الإغلاق سيبقى حيًّا بعد انتهاء استدعاء الدالة المباشر، وهو ما يسمح لـ Swift بإدارة الذاكرة والمراجع التي يلتقطها على النحو الصحيح.

[escaping]: https://docs.swift.org/swift-book/LanguageGuide/Closures.html#ID546
