# التعليمات

أنت تعمل مع فريق تطوير ويب لصيانة موقع إلكتروني لفريق كرة سلة محلي. فريق تطوير الويب ليس ملمًّا بـ Elixir بشكل كبير، وهو يطلب دالة تستطيع استخراج البيانات من سلسلة من الخرائط المتداخلة لتسهيل التطوير السريع.

## 1. استخراج البيانات من بنية خرائط متداخلة

نفّذ الدالة `extract_from_path/2` بحيث تأخذ وسيطين:

- `data`: بنية خرائط متداخلة تحتوي على بيانات عن فريق كرة السلة.
- `path`: سلسلة نصية تتكوّن من مفاتيح مفصولة بنقاط للحصول على القيمة المرتبطة بالمفتاح الأخير.

إذا لم توجد القيمة أو المفتاح في أي نقطة على المسار، فيجب إرجاع `nil`

```elixir
data = %{
  "team_mascot" => %{
    "animal" => "bear",
    "actor" => %{
      "first_name" => "Noel"
    }
  }
}

BasketballWebsite.extract_from_path(data, "team_mascot.animal")
# => "bear"
BasketballWebsite.extract_from_path(data, "team_mascot.colors")
# => nil
```

استخدم _Access Behaviour_ عند تنفيذ هذه الدالة.

لا تستخدم أي دوال من وحدتي `Map` أو `Kernel` للتعامل مع بنية الخرائط المتداخلة.

## 2. إعادة الهيكلة باستخدام الدوال المضمّنة

يخبرك زميلك الذي يراجع كودك عن دالة في وحدة `Kernel` تفعل شيئًا مشابهًا جدًا لتنفيذك.

نفّذ `get_in_path/2` لتستخدم دالة وحدة `Kernel` هذه.

الوسائط المتوقعة هي نفسها كما في الجزء 1.

```elixir
BasketballWebsite.get_in_path(data, "team_mascot.actor.first_name")
# => "Noel"
```
