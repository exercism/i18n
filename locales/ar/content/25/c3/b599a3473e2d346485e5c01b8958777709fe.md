# مقدمة إلى التنصيص

نصيحة واحدة سيسمعها مبرمجو bash الجدد مرارًا وتكرارًا:

> ضع متغيراتك بين علامات تنصيص!

لماذا؟

عند توسيع متغير (مثل `$name`) فإنك في الغالب تريد استخدام _قيمة_ المتغير كسلسلة نصية واحدة (أو عدد واحد).
ولا تريد أن تُعالَج القيمة بشكل غير متوقع كسلسلتين نصيتين منفصلتين أو أكثر.

## التنصيص

التنصيص هو الآلية الأساسية لضمان معاملة قطعة من النص ككلمة واحدة.
وهناك نوعان رئيسيان من علامات التنصيص.

### علامات التنصيص المزدوجة

تسمح علامات التنصيص المزدوجة بتوسيع المعاملات والتوسيع الحسابي واستبدال الأوامر بداخلها.

```bash
echo "This is bash version $BASH_VERSION"
```

يمكنك تضمين علامة تنصيص مزدوجة حرفية داخل سلسلة نصية محاطة بعلامات تنصيص مزدوجة بوضع شرطة مائلة عكسية قبلها.

```bash
echo "She said \"Let me teach you about bash.\""
```

### علامات التنصيص المفردة

علامات التنصيص المفردة _لا تسمح_ بأي توسيع بداخلها.

```bash
echo 'This is bash version $BASH_VERSION'
# ...^..................................^
# prints exactly: This is bash version $BASH_VERSION
```

_لا يمكن_ تضمين علامة تنصيص مفردة داخل سلسلة نصية محاطة بعلامات تنصيص مفردة.

## أهمية التنصيص

ما الخطأ في `echo $name` بالضبط؟

عندما تحلّل الصدَفة سطرًا من الكود، فإنها تنفذ [عدة أنواع من التوسيعات][expansions] بالترتيب.
اثنان من التوسيعات الأخيرة هما _تقسيم الكلمات_ و_توسيع أسماء الملفات_.

### تقسيم الكلمات

أي نتائج ناتجة عن توسيع المعاملات أو استبدال الأوامر أو التوسيع الحسابي _ولم تحدث داخل علامات التنصيص المزدوجة_ تكون مرشّحة لـ"تقسيم الكلمات".
تأخذ الصدَفة النتيجة الموسَّعة، وتقسّمها عند أي تسلسل من المحارف موجود في قيمة `$IFS`.
وهو افتراضيًا: المسافة، والجدولة، ومحرف السطر الجديد.

يمكننا أن نرى ذلك أثناء العمل باستخدام حلقة في الصدَفة:

```bash
sentence="The quick brown fox jumps."
i=0
for word in "$sentence"; do echo "$((++i)) $word"; done
# ..........^.........^
```
الناتج:
```none
1 The quick brown fox jumps.
```

لكن بدون تنصيص:

```bash
i=0
for word in $sentence; do echo "$((++i)) $word"; done
# .........^.........^
```
الناتج:
```none
1 The
2 quick
3 brown
4 fox
5 jumps.
```

لنرَ ذلك بقيمة مختلفة لـ`$IFS`:

```bash
csv="first,second,third"
IFS=","
for word in $csv; do echo "$word"; done
```
الناتج:
```none
first
second
third
```

#### تعطيل تقسيم الكلمات

إحدى التقنيات لتعطيل تقسيم الكلمات هي ضبط `$IFS` على سلسلة نصية فارغة

```bash
sentence="The quick brown fox jumps."
IFS=    # or explicitly, IFS=""
i=0
for word in $sentence; do echo "$((++i)) $word"; done
# .........^.........^
```
الناتج:
```none
1 The quick brown fox jumps.
```

لكن ترك المتغيرات بدون تنصيص غير مستحسن إلا إذا عطّلت أيضًا توسيع أسماء الملفات.
وسنرى كيف نفعل ذلك أدناه.

### توسيع أسماء الملفات

تُستخدم أنماط "glob" للتعبير عن نمط موجز يطابق مجموعة من الملفات.
فعلى سبيل المثال، قد تطابق جميع ملفات Markdown في مجلد باستخدام `*.md`.
توجد [أنماط glob][glob] منذ اختراع يونكس.

محارف البدائل في glob هي:

* `*` يطابق صفرًا أو أكثر من أي محرف،
* `?` يطابق محرفًا واحدًا بالضبط من أي نوع،
* `[...]` يطابق محرفًا واحدًا بالضبط من مجموعة المحارف المدرجة بين القوسين المربعين.

   ~~~~exercism/advanced
   <details><summary>
   هناك تفاصيل كثيرة حول مجموعات المحارف.
   انقر هنا لعرضها.
   </summary>

    * `[abc]` يطابق محرفًا واحدًا بالضبط يكون إما `a` أو `b` أو `c`.
        * لتضمين قوس إغلاق مربع حرفي في التعبير، اجعله المحرف الأول بعد قوس الفتح المربع (بعد `^` اختياري)
            * `[][]` مجموعة محارف تطابق إما قوس إغلاق أو قوس فتح.
            * أو تخطَّه بشرطة مائلة عكسية: `[[\]]`
    * `[x-y]` يطابق محرفًا واحدًا بالضبط يقع في _النطاق_ من `x` إلى `y`
        * لتضمين محرف شرطة حرفي في مجموعة محارف، يجب أن يكون إما المحرف الأول بعد قوس الفتح المربع (بعد `^` اختياري) أو المحرف الأخير قبل قوس الإغلاق المربع.
            * `[-xy]` أو `[xy-]` كلاهما يطابق محرفًا واحدًا بالضبط يكون `-` أو `x` أو `y`
            * أو تخطَّه بشرطة مائلة عكسية: `[x\-y]`
        * يمكن تحديد نطاقات متعددة، فمثلًا `[0-9A-Fa-f]` يطابق رقمًا سادس عشريًا
    * `[^abc]` يطابق محرفًا واحدًا بالضبط **ليس** `a` ولا `b` ولا `c`،
    * `[^x-y]` يطابق محرفًا واحدًا بالضبط **ليس** في النطاق من `x` إلى `y`
    * `[[:character_class:]]` يطابق محرفًا واحدًا ينتمي إلى "character_class" المسمّى
        * مجموعات المحارف المتاحة هي: 
            * `lower` -- حروف صغيرة
            * `upper` -- حروف كبيرة
            * `alpha` -- حروف
            * `digit` -- أرقام
            * `alnum` -- حروف وأرقام
            * `space` -- مسافات بيضاء
            * `blank` -- مسافات بيضاء أفقية (المسافة والجدولة)
            * `xdigit` -- أرقام سادسة عشرية
            * `word` -- محارف مسموح بها في المعرّف (حروف، وأرقام، وشرطة سفلية)
            * `punct` -- علامات ترقيم
            * `cntrl` -- محارف تحكم
            * `graph` -- محارف "مرئية"
            * `print` -- المحارف المرئية إضافة إلى المسافة
        * يمكن دمجها:
            * مجموعة `[[:alpha:]]` تتكون من `[[:lower:][:upper:]]`
            * مجموعة `[[:alnum:]]` تتكون من `[[:alpha:][:digit:]]`
            * مجموعة `[[:word:]]` تتكون من `[[:alnum:]_]`
            * الشرطة السفلية (بالنظام الثماني 137) تنتمي إلى كل من `[[:word:]]` و`[[:punct:]]`
            * مجموعة `[[:graph:]]` تتكون من `[[:alnum:][:punct:]]`
            * مجموعة `[[:print:]]` تتكون من `[[:graph:] ]` -- المسافة فقط (بالنظام الثماني 040) وليس أي مسافة بيضاء أخرى.
   </details>

#### التكرار عبر قائمة من الملفات

يمكنك التكرار عبر قائمة من الملفات باستخدام حلقة `for`

```bash
for file in *.csv; do
    do_something_with "$file"
done
```

لاحظ أن المتغير `"$file"` موضوع بين علامات تنصيص.
قد يعثر نمط glob على ملفات تحتوي أسماؤها على مسافات.
نحتاج إلى وضع المتغير بين علامات تنصيص حتى يتلقى الأمر `do_something_with` وسيطًا واحدًا بالضبط، وهو اسم الملف.

#### أنماط Glob ليست تعبيرات نمطية

أنماط glob **ليست** تعبيرات نمطية.

* مطابقة محرف واحد بالضبط
   * في التعبير النمطي `.`
   * في glob `?`
* مطابقة صفر أو أكثر من المحارف
   * في التعبير النمطي `.*`
   * في glob `*`
        * نمط glob `.*` يعني "طابق اسم ملف يكون محرفه الأول نقطة حرفية تليها صفر أو أكثر من أي محارف".
* مطابقة محرف واحد أو أكثر
   * في التعبير النمطي `.+`
   * في glob `?*`
* مجموعات محارف التعبيرات النمطية ومجموعات محارف glob تعمل بالطريقة نفسها.

#### التنصيص وتوسيع أسماء الملفات

هناك أوقات تريد فيها منع توسيع أسماء الملفات.
ومعالجة إدخال المستخدم إحدى هذه الأوقات.
تأمل مقتطف الكود هذا

```bash
read -p "Enter something: " user_input
echo $user_input
```

إذا أدخل المستخدم نجمة (`*`)، فما الذي سيُطبع؟ 
قائمة الملفات في المجلد الحالي.
وهذا على الأرجح ليس ما تريد فعله.

ومن الأمثلة الأخرى تمرير أنماط كوسائط إلى برامج تتوقع أنماطًا.
كثيرًا ما يُستخدم برنامج `tr` لمعالجة النصوص. ولتحويل قيمة متغير إلى حروف صغيرة، يمكنك فعل هذا

```bash
var="My Puppet"
echo "$var" | tr '[:upper:]' '[:lower:]'
```
الناتج:
```none
my puppet
```

من الأخطاء الشائعة نسيان وضع وسائط `tr` بين علامات تنصيص: `tr [:upper:] [:lower:]`

~~~~exercism/caution
لماذا يُعد ذلك مشكلة؟ 
أنماط glob غير الموضوعة بين علامات تنصيص ستُوسَّع إلى قائمة الملفات المطابقة.
افترض أن من يستخدم سكربتك لديه ملفات باسم `p` و`u` و`w` في المجلد الحالي:

```bash
touch p u w
var="My Puppet"
echo "$var" | tr [:upper:] [:lower:]
```

وهذا يؤدي إلى خطأ!

النمط `[:upper:]` غير الموضوع بين علامات تنصيص يطابق أيًا من `:` أو `u` أو `p` أو `e` أو `r`.
والنمط `[:lower:]` غير الموضوع بين علامات تنصيص يطابق أيًا من `:` أو `l` أو `o` أو `w` أو `e` أو `r`.
يطابق bash الملفين `p` و`u` بالنسبة للنمط الأول، والملف `w` بالنسبة للنمط الثاني، فيُستدعى `tr` هكذا

```bash
echo "$var" | tr p u w
```

وهذا عدد خاطئ من الوسائط بالنسبة لـ`tr`.
~~~~

#### تعطيل توسيع أسماء الملفات

يمكنك استخدام الأمر [`set`][set] لتعطيل توسيع أسماء الملفات.

```bash
echo *      # prints a list of files
set -f      # disable filename expansion
echo *      # prints a literal asterisk
set +f      # enable filename expansion
```

#### التحكم في توسيع أسماء الملفات

هناك عدة إعدادات للأمر المضمّن [`shopt`][shopt] تتحكم في كيفية عمل توسيع أسماء الملفات.
ومن الإعدادات المثيرة للاهتمام:

* `shopt -s nocaseglob` -- إجراء مطابقة لا تتأثر بحالة الأحرف
* `shopt -s extglob` -- تمكين الأنماط الموسّعة
* `shopt -s nullglob` -- إذا لم يطابق أي ملف، استبدل النمط بلا شيء.
   والسلوك الافتراضي هو إبقاء النمط في مكانه كسلسلة نصية حرفية.
