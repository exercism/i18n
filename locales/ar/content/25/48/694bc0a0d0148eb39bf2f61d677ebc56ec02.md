# التعليمات

أنت جزء من مكتب مساعدة تقنية المعلومات، وتريد تحسين نظام التذاكر ليكون أكثر كفاءة وتوفير إحصاءات لمديرك.

للتذكرة حالة (جديد، قيد التنفيذ...)، ومنشئ (يُعرَّف باسم مستخدم ومعرّف موظف)، ويمكن إسنادها إلى موظف في تقنية المعلومات، وتحتوي على سجل من التعليقات.

إليك أربع مهام ستحسّن نظام التذاكر الحالي.

## 1. اكتشاف التعليقات الفارغة

التعليقات الفارغة تزدحم بها الواجهة ولا تقدّم أي معلومات، لذلك تريد تصفيتها.

عرّف دالة مساعدة `emptyComment` تأخذ زوجًا من المستخدم والتعليق وتُرجع `True` للتعليقات الفارغة.

استخدم التفكيك لاستخراج المستخدم والتعليق مباشرةً في وسيط الدالة. تجاهل المستخدم لأنك لا تحتاج هذه المعلومة.

```elm
emptyComment ( User "Alice", "" )
-- => True
```

## 2. حساب عدد التعليقات من المنشئ

مديرك يريد الحصول على إحصاءات عن مشاركة المستخدمين في عملية التذاكر.
وهي تطلب منك التحقق من عدد التعليقات التي يضيفها منشئ التذكرة.

عرّف `numberOfCreatorComments` التي تأخذ تذكرة وتُرجع عدد التعليقات التي أضافها منشئ التذكرة.

استخدم التفكيك في وسيط الدالة لاستخراج السجل من نوع `Ticket`، في الوقت نفسه الذي تستخرج فيه الحقول التي تحتاجها من السجل.
ثم فكّك `createdBy` في ارتباط `let` حتى تتمكن من عدّ التعليقات ذات الصلة.
استخدم دوال `List` لإجراء العدّ، واستخدم التفكيك في وسيط الدالة لدالة مجهولة لفصل زوج المستخدم والتعليق.

```elm
numberOfCreatorComments
numberOfCreatorComments
    (Ticket
        { status = Closed
        , createdBy = ( User "Chiaki", 1 )
        , assignedTo = Nothing
        , comments = [ ( User "Chiaki", "Never mind, fixed it." ) ]
        }
    )
-- => 1
```

## 3. اكتشاف التذاكر المُسندة إلى فريق التطوير

بعض التذاكر يجب تصعيدها إلى Alice أو Bob أو Charlie من فريق التطوير.
من المهم متابعة هذه التذاكر للتأكد من أنها تحرز تقدمًا.

عرّف دالة مساعدة `assignedToDevTeam` تتحقق مما إذا كانت التذكرة مُسندة إلى أحد أعضاء فريق التطوير.

استخدم التفكيك في وسيط الدالة لاستخراج السجل من نوع `Ticket` وكذلك الحقل الذي تحتاجه.
ثم استخدم عبارة `case` واحدة للتحقق مما إذا كانت التذكرة مُسندة إلى Alice أو Bob أو Charlie، وذلك باستخدام مطابقة الأنماط العودية لاستخراج أسماء المستخدمين الخاصة بهم ومطابقة الأنماط الحرفية لمطابقتها.

```elm
assignedToDevTeam
    (Ticket
        { status = InProgress
        , createdBy = ( User "Bill", 2 )
        , assignedTo = Just (User "Alice")
        , comments = [ ( User "Bill", "What's an 'undefined'?" ) ]
        }
    )
-- => True
```

## 4. إسناد التذاكر إلى موظفي تقنية المعلومات

أحيانًا يلزم إعادة إسناد مجموعة من التذاكر إلى موظفي تقنية معلومات آخرين.

عرّف دالة `assignTicketTo` لمساعدتك في ذلك. تستقبل الدالة وسيطين: مستخدمًا تُسند إليه التذكرة وتذكرة.
إذا كانت حالة التذكرة `New`، فأسندها إلى المستخدم الجديد وغيّر الحالة إلى `InProgress`.
أما بالنسبة للحالات الأخرى، فأعد إسناد التذكرة إلى المستخدمين الجدد ببساطة، باستثناء التذاكر ذات الحالة `Archived` التي لا ينبغي تعديلها على الإطلاق.

استخدم التفكيك في وسيط الدالة لاستخراج السجل من نوع `Ticket` وكذلك الحقل الذي تحتاجه، واستخدم أيضًا الكلمة المفتاحية `as` لالتقاط السجل بأكمله كما هو.
استخدم عبارة `case` واحدة لمطابقة نمط الحالة وإرجاع التذكرة المناسبة، المنشأة من تعديل السجل الأصلي الذي التقطته بالكلمة المفتاحية `as`.

```elm
assignTicketTo (User "Danny")
    (Ticket
        { status = New
        , createdBy = ( User "Jesse", 3 )
        , assignedTo = Just (User "Alice")
        , comments = [ ( User "Jesse", "I've been waiting for 6 months!!" ) ]
        }
    )
-- => Ticket
--        { status = InProgress
--        , createdBy = ( User "Jesse", 3 )
--        , assignedTo = Just (User "Danny")
--        , comments = [ ( User "Jesse", "I've been waiting for 6 months!!" ) ]
--        }
```
