# مقدمة

## المصفوفات

المصفوفات في PHP هي خرائط مرتّبة.
والخريطة بنية بيانات تربط مفتاحًا بقيمة.
المصفوفات مرنة ويمكن التعامل معها كمصفوفة خطية (كما في `C` أو `Java`)، أو قائمة [متجه]، أو جدول تجزئة، أو قاموس، أو مجموعة، أو مكدّس، أو طابور.

المفتاح اختياري، لكنه إذا حُدِّد وجب أن يكون إما `int` أو `string`.
وعندما لا يُحدَّد مفتاح، تستخدم PHP افتراضيًا مفاتيح من نوع عدد صحيح بترتيب متزايد، بدءًا من `0`.

```php
$no_keys = ["my", "first", "array"];
$integer_keys = [0 => "my", 1 => "first", 2 => "array"];

$no_keys == $integer_keys // => equal returns true
$no_keys === $integer_keys // => strictly equal returns true
```

يمكن للمصفوفة أن تخزّن قيمًا من جميع الأنواع.
ويمكن أن يكون لكل قيمة نوع مختلف.

### استخدام المصفوفات

يمكن الإعلان عن المصفوفات كقيمة حرفية (مكتوبة في الكود، كما في المثال أعلاه) أو إنشاؤها والتعامل معها باستخدام دوال.
ويمكنك الوصول إلى القيم وإسنادها وإلحاقها باستخدام عامل الفهرس:

```php
$prime_numbers = [2, 3, 5, 6];

$prime_numbers[3] = 7; // replace 6 with 7

$prime_numbers[] = 11; // array now contains [2, 3, 5, 7, 11]
```

## الوسائط متغيرة الطول

يمكن تحديد وسائط الدالة بحيث تقبل أي عدد من الوسائط:

```php
<?php

function actOnItems(...$items) {
  // $items is an array containing 0 or more values
  // used to call the function.
}

actOnItems(1, 2, 3, 4); // $items => [1, 2, 3, 4]
```
