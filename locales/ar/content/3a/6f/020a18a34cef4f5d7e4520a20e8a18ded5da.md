# مقدمة

تُمثَّل القيم المنطقية في C++ بالنوع `bool`. والقيمة من النوع `bool` تكون إما `true` أو `false`.

## العوامل المنطقية

يدعم C++ ثلاثة عوامل منطقية: `!` (النفي)، و`&&` (العطف)، و`||` (الفصل). ويمكنك أيضًا استخدام الصيغ البديلة `not` و`and` و`or`.

```cpp
true || false // => true
true && false // => false
!true // => false
not false // => true
```

## الأسبقية

لكل من العوامل المنطقية الثلاثة _أسبقية عوامل_ مختلفة. وبناءً على ذلك، تُقيَّم بهذا الترتيب: `!` أولًا، ثم `&&`، وأخيرًا `||`. وإذا أردت فرض ترتيب مختلف، فيمكنك إحاطة تعبير منطقي بالأقواس الهلالية (أي `()`)، لأن الأقواس الهلالية لها أسبقية أعلى.

```cpp
!true && false   // => false
!(true and false) // => true
```

## التحويل

إذا استخدمت `true` أو `false` في موضع يُتوقع فيه عدد، فسيُحوَّلان إلى `1` و`0` على الترتيب. وإذا استخدمت عددًا في عملية منطقية، فكل شيء عدا `0` يُعامَل على أنه `true`، حتى القيم السالبة.

```cpp
!true && 0.0   // => false
true + true + false // => 2
```
