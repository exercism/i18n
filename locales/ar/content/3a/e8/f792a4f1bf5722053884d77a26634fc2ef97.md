# نبذة

[الهياكل][getting-started] هي [خرائط][maps] خاصة لها مجموعة محددة من المفاتيح.

- توفّر الهياكل فحوصات وقت الترجمة وقيمًا افتراضية.
- يُسمّى الهيكل باسم الوحدة التي عُرّف فيها.
- لتعريف هيكل، استخدم التركيب [`defstruct`][docs-defstruct].
  - يأتي هذا التركيب عادةً مباشرةً بعد تعريف الوحدة.
- يقبل `defstruct` إما قائمة من [الذرات][atom] (لقيم افتراضية قيمتها `nil`) أو قوائم الكلمات المفتاحية (لقيم افتراضية محددة).
  - يجب أن تسبق الحقول التي بلا قيم افتراضية الحقول التي لها قيم افتراضية.

```elixir
defmodule Plane do
  defstruct [:engine, wings: 2]
end

plane = %Plane{}
# => %Plane{engine: nil, wings: 2}
```

## الوصول إلى الحقول وتحديثها

- معظم الدوال التي تعمل مع [الخرائط][maps] ستعمل أيضًا مع الهياكل.
  - يُشكّل [_سلوك الوصول_][access-behaviour] استثناءً، و**لا** يُنفَّذ للهياكل.
- يُوصى باستخدام _عامل الوصول الساكن_ `.` للوصول إلى حقول الهيكل.

- الحصول على قيم الحقول أو جلبها:

  ```elixir
  plane = %Plane{}
  plane.engine
  # => nil
  Map.fetch(plane, :wings)
  # => {:ok, 2}
  ```

- تحديث قيم الحقول

  ```elixir
  plane = %Plane{}
  %{plane | wings: 4}
  # => %Plane{engine: nil, wings: 4}
  ```

## فرض تهيئة قيم الحقول

- [سمة الوحدة `@enforce_keys`][enforcing-keys] تُنشئ فحصًا في وقت التشغيل يفرض تهيئة الحقول المحددة بقيمة **غير** `nil` عند إنشاء الهيكل.
- يأتي بعد `@enforce_keys` قائمة بمفاتيح الحقول (وهي [ذرات][atom]).
- إذا لم يُهيَّأ مفتاح مفروض، يُرفع خطأ.

```elixir
defmodule User do
  @enforce_keys [:username]
  defstruct [:username]
end

%User{}
# => (ArgumentError) the following keys must also be given when building struct User: [:username]
```
