# ملحق التعليمات

## السجلات

| السجل    | الاستخدام | النوع   | الوصف                           |
| -------- | --------- | ------- | ------------------------------- |
| `$a0`    | إدخال     | عنوان   | اللون في صورة سلسلة نصية منتهية بمحرف صفري |
| `$v0`    | إخراج     | عدد صحيح | قيمة المقاومة                   |
| `$t0-9`  | مؤقت      | أي نوع  | للتخزين المؤقت                  |
