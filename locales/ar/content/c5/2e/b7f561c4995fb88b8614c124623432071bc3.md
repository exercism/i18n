# التعليمات

في هذا التمرين ستقوم بتوليد رسائل سجل شبه مهيكلة.

## أصدر رسائل شبه مهيكلة

ستبدأ ببعض الدوال الهيكلية وبالتعداد التالي:

```rust
#[derive(Drop, Clone, PartialEq, Debug)]
pub enum LogLevel {
    Info,
    Warning,
    Error,
    Debug
}
```

هدفك هو إصدار رسالة سجل بالشكل التالي: `"[<LEVEL>]: <MESSAGE>"`.
ستحتاج إلى تنفيذ دوال تقابل مستويات السجل.

على سبيل المثال، يوضّح المقطع التالي مخرجات متوقعة من دالة `log`.

```rust
log(LogLevel::Error, "Stack overflow")
// Returns: "[ERROR]: Stack overflow"
```

وللدالة `info`:

```rust
info("Timezone changed")
// Returns: "[INFO]: Timezone changed"
```

استمتع!
