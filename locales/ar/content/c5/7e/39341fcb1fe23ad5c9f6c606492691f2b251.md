# مقدمة

حلقات `for` هي أكثر أنواع الحلقات تعقيدًا في PHP. وهي تعمل مثل حلقات `for` في `C` و`Java` و`JavaScript`. وهذه صيغتها الأساسية:

```php
for (expr1; expr2; expr3) {
  // statements
}
```

يُقيَّم التعبير الأول (_expr1_) قبل أن تبدأ الحلقة. ويُقيَّم التعبير الثاني (_expr2_) قبل كل تكرار، وإذا كان ناتجه قيمة صحيحة منطقيًا، تُنفَّذ العبارات. وبعد تنفيذ العبارات، يُقيَّم التعبير الثالث (_expr3_).
