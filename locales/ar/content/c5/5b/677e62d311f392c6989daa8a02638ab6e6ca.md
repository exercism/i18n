# مقدمة

## تحويل الأنواع

يتطلب Go تحويلًا صريحًا بين الأنواع المختلفة.
يتم التحويل بين الأنواع (المعروف أيضًا بـ **type casting**) عبر دالة تحمل اسم النوع المراد التحويل إليه.
على سبيل المثال، لتحويل `int` إلى `float64` عليك القيام بما يلي:

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
```

## التحويل بين الأنواع الأولية والسلاسل النصية

توجد حزمة `strconv` للتحويل بين الأنواع الأولية (مثل `int`) و`string`.

```go
import "strconv"

var intString string = "42"
var i, err = strconv.Atoi(intString)

var number int = 12
var s string = strconv.Itoa(number)
```

## تأكيدات النوع

قد تُدخل الواجهات في Go غموضًا بشأن النوع الكامن.
يتيح لنا تأكيد النوع استخراج القيمة الملموسة الكامنة لقيمة الواجهة باستخدام هذه الصيغة: `interfaceVariable.(concreteType)`.

على سبيل المثال:

```go
var input any = 12
number := input.(int)
```

ملاحظة: سيؤدي هذا إلى `panic` إذا لم يحتوِ متغير الواجهة على قيمة من النوع الملموس.

يمكننا اختبار ما إذا كانت قيمة الواجهة تحمل نوعًا ملموسًا محددًا بالاستفادة من قيمتي الإرجاع لتأكيد النوع: القيمة الكامنة وقيمة منطقية تخبرنا ما إذا نجح التأكيد.
على سبيل المثال:

```go
str, ok := input.(string) // no panic if input is not a string
```

إذا كانت `input` تحمل `string`، فستكون `str` هي القيمة الكامنة وستكون `ok` هي صحيح.
وإذا لم تكن `input` تحمل `string`، فستكون `str` هي القيمة الصفرية للنوع `string` (أي `""`، السلسلة النصية الفارغة) وستكون `ok` هي خطأ.
ولا يحدث `panic` في أي حالة.

## تبديل النوع

يمكن لـ**تبديل النوع** إجراء عدة تأكيدات نوع بالتتابع.
وهو يستخدم الصيغة نفسها التي يستخدمها تأكيد النوع (`interfaceVariable.(concreteType)`)، لكن يُستبدل `concreteType` بالكلمة المفتاحية `type`.
إليك مثالًا:

```go
var i any = 12 // try: 12.3, true, int64(12), []int{}, map[string]int{}

switch v := i.(type) {
case int:
    fmt.Printf("the integer %d\n", v)
case string:
    fmt.Printf("the string %s\n", v)
default:
    fmt.Printf("type, %T, not handled explicitly: %#v\n", v, v)
}
```
