# Docker

تُنشر مُشغّلات الاختبارات لدينا كصور Docker.

يُرجى قراءة [معلومات Docker العامة الخاصة بالأدوات](/docs/building/tooling/docker) للتعرّف على كيفية عملها.

## التكامل

عندما نشغّل مُشغّل اختبارات لاختبار حلٍّ ما، نُشغّل أمر Docker يبدو هكذا:

```shell
docker run \
        --rm \
        --network none \
        --mount type=bind,src="${solution_dir}",dst=/solution \
        --mount type=bind,src="${output_dir}",dst=/output \
        --tmpfs /tmp:rw \
        "exercism/${track_slug}-test-runner" \
        "${exercise_slug}" "/solution" "/output"
```

كما ترى، نمرّر ثلاثة وسائط إلى صورة Docker:

1. المعرّف المختصر للتمرين
2. مسار دليل الحل
3. مسار دليل الإخراج

## الاصطلاحات

تستخدم جميع مُشغّلات الاختبارات لدينا الاصطلاحات التالية في تنفيذها:

- يوجد ملف `Dockerfile` في الدليل الجذر للمستودع.
- ينبغي أن يكون دليل العمل هو `/opt/test-runner`.
- نقطة الدخول هي `/opt/test-runner/bin/run.sh`
- يأخذ السكربت `/opt/test-runner/bin/run.sh` ثلاثة وسائط:
  1. المعرّف المختصر للتمرين
  2. مسار دليل الحل
  3. مسار دليل الإخراج

لمزيد من المعلومات، راجع [الواجهة](/docs/building/tooling/test-runners/interface).

```exercism/note
ستستخدم مستودعات مُشغّلات الاختبار الجديدة هذه الاصطلاحات افتراضيًا.
```
