# نبذة

في Haxe، **المصفوفة** مجموعة من العناصر التي تكون (عادةً) من النوع نفسه. هناك ثلاثة أساليب لإنشاء مصفوفة في Haxe؛ إما باستخدام المُنشئ أو باستخدام صيغة إعلان. في Haxe، فهرس العنصر الأول في المصفوفة هو صفر:

```haxe
var a = [1, 2, 3];
trace(a); // [1,2,3]

// Here the second element is called by index
trace(a[1]); // 2

// The actual first element's index is 0
trace(a[0]); // 1
```

لإنشاء مصفوفة باستخدام المُنشئ، عليك تمرير نوع العناصر التي ستُضمَّن في المصفوفة:

```haxe
var a:Array<Int> = [0, 1, 2, 3];
a[1] = "Hello"; // Error: the array a takes integers only
```

بما أن الوصول إلى عناصر المصفوفة في Haxe غير مقيّد، أي أنه مضمون بألا يُطلق استثناءً، فإن هذا يحتاج إلى تفصيل إضافي:

- إذا أُجريت عملية قراءة على فهرس غير موجود، فستُرجع قيمة تعتمد على الهدف.
- إذا أُجريت عملية كتابة بفهرس موجب خارج الحدود، فإن `null` (أو القيمة الافتراضية للأنواع الأساسية على الأهداف الثابتة) يُدرَج في كل المواضع بين آخر فهرس معرّف والفهرس المكتوب حديثًا.
- إذا أُجريت عملية كتابة بفهرس سالب، فستكون النتيجة غير محددة.

إذا أردنا أن تحتوي المصفوفة على أنواع متعددة من العناصر، نضيف النوع `Dynamic` إلى محدد النوع:

```haxe
var a:Array<Dynamic> = [10, "Bob", true]
```

## التكرار

يمكن اجتياز عناصر المصفوفة باستخدام حلقة `for`:

```haxe
var nums = [2, 3, 5];
var sum = 0;
for (num in nums) {
  sum += num;
}
trace(sum); // 10
```
