# تعليمات

توجد في مدرسة محلية قريبة منك جمعية طلابية نشطة للغاية.
تُدار الجمعية الطلابية بواسطة رئيس، وكل سنتين تُجرى انتخابات لاختيار رئيس جديد.

في انتخابات هذا العام، تقرر أن هناك حاجة إلى نظام رقمي جديد لعدّ الأصوات.
تحتاج المدرسة إلى مساعدتك في بناء هذا النظام الجديد.

## 1. إنشاء عدّاد أصوات

من أول الأشياء التي يحتاجها نظام التصويت الجديد عدّاد أصوات.
هذا العدّاد وسيلة لتتبّع الأصوات التي حصل عليها مرشح معيّن.

أنشئ دالة `NewVoteCounter` تقبل عدد الأصوات الأولية لمرشح وتُرجع مؤشرًا يشير إلى `int`، مُهيَّأ بعدد الأصوات الأولية المعطى.

```go
var initialVotes int
initialVotes = 2

var counter *int
counter = NewVoteCounter(initialVotes)
*counter == initialVotes // true
```

## 2. الحصول على عدد الأصوات من عدّاد

أصبح لديك الآن وسيلة لإنشاء عدّادات جديدة! لكنك تدرك الآن أن النظام الجديد سيحتاج أيضًا إلى وسيلة للحصول على عدد الأصوات من عدّاد.

أنشئ دالة `VoteCount` تأخذ عدّادًا (`*int`) كوسيط وتُرجع عدد الأصوات في العدّاد.
إذا كان العدّاد `nil`، فافترض أن العدّاد لا يحتوي على أصوات:

```go
var votes int
votes = 3

var voteCounter *int
voteCounter = &votes

VoteCount(voteCounter)
// => 3

var nilVoteCounter *int
VoteCount(nilVoteCounter)
// => 0
```

## 3. زيادة أصوات عدّاد

حان الوقت أخيرًا لعدّ الأصوات! تحتاج الآن إلى وسيلة لزيادة الأصوات في عدّاد.

أنشئ دالة `IncrementVoteCount` تأخذ عدّادًا (`*int`) كوسيط وعددًا من الأصوات، وتزيد العدّاد بمقدار ذلك العدد من الأصوات.
يمكنك افتراض أن المؤشر الممرَّر لن يكون `nil` أبدًا.

```go
var votes int
votes = 3

var voteCounter *int
voteCounter = &votes

IncrementVoteCount(voteCounter, 2)

votes == 5          // true
*voteCounter == 5   // true
```

## 4. إنشاء نتائج الانتخابات

بعد أن أصبحت جميع الأصوات معدودة، حان الوقت لتحضير إعلان النتائج أمام المدرسة كلها.
لهذا، تلاحظ أن وجود عدّادات للأصوات فقط غير كافٍ.
لا بد من وسيلة لربط عدد الأصوات بمرشح معيّن.

أنشئ دالة `NewElectionResult` تستقبل اسم مرشح وعدد أصواته وتُرجع نتيجة انتخابية جديدة.

```go
var result *ElectionResult
result = NewElectionResult("Peter", 3)

result.Name == "Peter"  // true
result.Votes == 3       // true
```

البنية `ElectionResult` للنتيجة الانتخابية أُنشئت لك بالفعل، وهي مُعرَّفة كما يلي:

```go
type ElectionResult struct {
    // Name of the candidate
    Name    string
    // Votes of votes the candidate had
    Votes   int
}
```

## 5. إعلان النتائج

حان الوقت لإعلان الرئيس الجديد للمدرسة!
سيُعلن الرئيس في لوحات الرسائل الرقمية الصغيرة الموجودة في المدرسة.
يجب أن تُظهر الرسالة اسم الرئيس الجديد وعدد الأصوات التي حصل عليها، بالصيغة التالية: `<candidate_name> (<votes>)`.
وهذا مثال على هذه الرسالة: `"Peter (51)"`.

أنشئ دالة `DisplayResult` تستقبل `*ElectionResult` كوسيط وتُرجع سلسلة نصية تحتوي على الرسالة التي ستُعرض.

```go
var result *ElectionResult
result = &ElectionResult{
    Name: "John",
    Votes: 32,
}

DisplayResult(result)
// => John (32)
```

## 6. إعادة عدّ الأصوات

للتأكد من دقة النتائج النهائية، أُعيد عدّ الأصوات.
وخلال إعادة العدّ، وُجد أن عدد أصوات بعض المرشحين كان يختلف بمقدار واحد.

أنشئ دالة `DecrementVotesOfCandidate` تستقبل النتائج النهائية واسم المرشح الذي يجب إنقاص عدد أصواته.
تُعطى النتائج النهائية على شكل `map[string]int`، حيث المفاتيح هي أسماء المرشحين والقيم هي إجمالي أصواتهم.

```go
var finalResults = map[string]int{
    "Mary":  10,
    "John":  51,
}

DecrementVotesOfCandidate(finalResults, "Mary")

finalResults["Mary"]
// => 9
```
