# مقدمة

يمكن تكييف عوامل الحساب والمقارنة الأساسية لتستخدمها مع أصنافك ومع `struct` التي تعرّفها بنفسك. ويُعرف هذا باسم _تحميل العوامل_.

تأخذ معظم العوامل الصورة التالية:

```csharp
static <return type> operator <operator symbols>(<parameters>);
```

أما عوامل التحويل فتأخذ الصورة التالية:

```csharp
static (explicit|implicit) operator <cast-to-type>(<cast-from-type> <parameter name>);
```

تسلك العوامل المسلك نفسه الذي تسلكه الطرق الثابتة. فرمز العامل يحل محل معرّف الطريقة، وللعوامل معاملات ونوع إرجاع. وقواعد الأنواع الخاصة بالمعاملات ونوع الإرجاع تسير وفق حدسك، ويمكنك الاعتماد على المترجم ليمنحك إرشادات مفصّلة.
