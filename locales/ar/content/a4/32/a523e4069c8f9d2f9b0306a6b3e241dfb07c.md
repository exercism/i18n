## الأسماء المستعارة للأنواع

يمكن استخدام اسم مستعار للنوع في Gleam لإعطاء اسم ملائم لنوع موجود تكون كتابته مرهقة بخلاف ذلك.

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

عند كتابة الاسم المستعار باستخدام `pub type`، يمكن استخدامه خارج الوحدة التي عُرّف فيها. إذا حُذف `pub` يصبح الاسم المستعار خاصًا ولا يمكن الإشارة إليه من وحدات أخرى.
