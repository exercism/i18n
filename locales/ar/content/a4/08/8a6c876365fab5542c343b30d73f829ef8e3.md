# التعدادات

التعدادات هي نوع بيانات في Cairo يُستخدم لتعريف مجموعة من الحالات المحددة مسبقًا، بهدف جعل الكود أكثر وضوحًا وأمانًا.
في Cairo، يمكن تعريف حالات `enum` بحيث تحمل أنواع بيانات مختلفة (أعداد صحيحة، وتراكيب، ومجموعات مرتّبة، وتعدادات أخرى، وما إلى ذلك).

يوضح مقتطف الكود التالي كيف يمكن تعريف التعدادات:

```rust
#[derive(Drop)]
enum Direction {
    North,
    East,
    South,
    West,
}
```

تعداد `Direction` المعرّف أعلاه تعداد بسيط له أربع حالات: `North` و`East` و`South` و`West`.
اتفاق التسمية هو استخدام PascalCase لأسماء حالات التعداد.
كل حالة تمثل قيمة مميزة من قيم نوع التعداد `Direction`.
لا تحمل أي حالة في هذا المثال قيمة مرتبطة بها، ويمكن إنشاء نسخة منها باستخدام هذه الصيغة:

```rust
let direction = Direction::North;
```

في ما يلي تعداد `Direction` نفسه، لكن بحالات تحمل قيمًا مرتبطة بها، تخزّن الدرجة الدقيقة للاتجاه:

```rust
#[derive(Drop)]
enum Direction {
    North: u128,
    East: u128,
    South: u128,
    West: u128,
}
```

يتضح من هذا المثال أن كل حالة في تعداد `Direction` لها قيمة مرتبطة من النوع `u128`.
ويمكن إنشاء نسخة من هذا النوع من التعدادات كما يلي:

```rust
let direction = Direction::North(10);
```

## مثال على تعداد معقّد بأنواع مخصّصة

يمكن تعريف تعداد بمزيج من أنواع بيانات مختلفة كحالات له.
في المثال أدناه، `Action` تعداد معقّد يجمع `Quit` و`Direction` و`SendMessage` و`ChangeAvatar` و`ProfileState` كحالات له.

```rust
#[derive(Drop)]
struct Move {
    up: u32,
    down: u32,
    right: u32,
    left: u32,
}

#[derive(Drop)]
enum UserCommand {
    Login,
    UpdateProfile,
    Logout,
}

#[derive(Drop)]
enum Action {
    Quit, //  variant with no associated value
    Direction: Move, // variant with the `Move` struct associated value
    SendMessage: felt252, // a single felt252 variant
    ChangeAvatarColor: (u8, u8, u8), // variant with the tuple of three associated values
    ProfileState: UserCommand // variant with an enum associated value
}
```

## تنفيذ السمات للتعدادات

في Cairo، يمكن تعريف السمات وتنفيذها على تعدادات مخصّصة.
يتيح لك ذلك تعريف طرق وخصائص مرتبطة بتعداد ما.
في ما يلي مثال على ذلك، حيث نعرّف تعداد `Message` وننفّذ سمة `Processing` له:

```rust
#[derive(Drop)]
enum Message {
    Quit,
    Echo: felt252,
    Move: (u128, u128),
}

trait Processing {
    fn process(self: Message);
}

impl ProcessingImpl of Processing {
    fn process(self: Message) {
        match self {
            Message::Quit => { println!("quitting") },
            Message::Echo(value) => { println!("echoing {}", value) },
            Message::Move((x, y)) => { println!("moving from {} to {}", x, y) },
        }
    }
}
```

إليك كيف يمكن استخدام السمة لمعالجة رسالة `Quit`:

```rust
let msg: Message = Message::Quit;
msg.process(); // prints "quitting"
```

في كثير من الحالات، تكون التعدادات مفيدة، ولا سيما عند استخدامها مع تدفق `match` كما في تنفيذ السمات أعلاه.
اقرأ المزيد عن تدفق `match` في [كتاب Cairo][match].

[match]: https://book.cairo-lang.org/ch06-02-the-match-control-flow-construct.html
