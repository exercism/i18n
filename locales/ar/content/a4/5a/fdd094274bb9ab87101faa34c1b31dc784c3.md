# القيمة العدمية

القيمة العدمية هي نوع قيمة أولية لها قيمة واحدة فقط: `null`.
غالبًا ما تُستخدم القيمة العدمية لتمثيل العدم.
تُعتبر قيمة كاذبة، لكنها تختلف عن `false` وقيم كاذبة أخرى.

```php
<?php

is_null(null); // => true
isset(null); // => false

null == true; // => false
null === true; // => false

null == false; // => true
null === false; // => false
```

## التعامل مع القيم العدمية

في PHP، غالبًا ما تكون القيم العدمية سببًا شائعًا للأخطاء، إذ تُرجع كثيرًا بدلًا من حالة خطأ أو لتمثيل العدم.
غالبًا ما يتطلب منع حدوث الأخطاء التحقق من القيمة العدمية للتأكد من أن القيمة ليست `null` قبل التعامل معها.

```php
<?php

$value = null;

$value->doSomething(); // throws an error as a null value is not an object instance.

if (!is_null($value)) {
    $value->doSomething(); // succeeds
}
```

قد يؤدي التحقق المتكرر من `null` إلى الأخطاء، لذا توفر PHP عاملين للتعامل مع القيم العدمية: عامل الوصول الآمن `?->` وعامل الدمج `??`.

```php
<?php

$value = null;
$result = $value?->doSomething(); // => return null rather than error
$result = $result ?? "default"; // => "default" is assigned to $result
```
