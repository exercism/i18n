# مقدمة

إنّ *القابل للتحرير* هو كل ما يحتفظ بمورد من موارد نظام التشغيل (ملف مفتوح، أو مقبس، أو قفل مسنود بجدول تجزئة)، ويجب تحريره عندما تنتهي منه. تغلّف مفردات [`destructors`][destructors] في Factor هذه الموارد في إطار صغير، بحيث يحدث التنظيف حتى عندما يفكّ استثناء المكدّس.

```factor
USING: destructors io.files io.encodings.utf8 ;

"log.txt" utf8 <file-writer> [
    "hello, world" write
] with-disposal
! file is closed even if write throws
```

تشغّل `with-disposal ( disposable quot -- )` الاقتباس مع المورد وتحرّره عند الخروج. وإذا كان لديك أكثر من مورد واحد، فافتح نطاقًا باستخدام `with-destructors` وسجّل كل مورد باستخدام `&dispose` (يُحرَّر عند الخروج الطبيعي *وعند* وقوع خطأ) أو `|dispose` (يُحرَّر عند وقوع خطأ فقط).

ينضم الصنف إلى الإطار بوراثة `disposable` وتنفيذ الدالة العامة `dispose*`، ويستدعيها الإطار مرة واحدة فقط لكل كائن. أما الكلمة العامة التي يستدعيها المستخدمون فهي `dispose`.

[destructors]: https://docs.factorcode.org/content/vocab-destructors.html
