# نبذة

تُنشأ مصفوفات المحارف باستخدام Sigil `~c`.

```elixir
~c"hello"
```

~~~~exercism/note
لاحظ أن مصفوفات المحارف كانت تُمثَّل في الإصدارات الأقدم من Elixir على هيئة `'hello'` باستخدام علامات الاقتباس المفردة.
~~~~

مصفوفة المحارف هي مصفوفة من الأعداد الصحيحة. تمثل هذه الأعداد قيم يونيكود لمحرف معيّن، وتُعرف أيضًا بنقاط الترميز.

```elixir
[65, 66, 67]
# => ~c"ABC"
```

## مصفوفات المحارف _هي_ مصفوفات

```elixir
~c"" === []
# => true

is_list(~c"hello")
# => true
```

ولأن مصفوفات المحارف هي مصفوفات، يمكنك التعامل معها كما تتعامل مع أي مصفوفة أخرى، سواء باستخدام الاستدعاء الذاتي ومطابقة الأنماط، أو باستخدام وحدة [`List`][list].

```elixir
[first_letter | _] = ~c"cat"
first_letter
# => 99

List.first(~c"hello")
# => 104
List.pop_at(~c"hello", 0)
# => {104, ~c"ello"}

```

يمكنك دمج مصفوفتين معًا باستخدام [`++`][kernel-concat-list].

```elixir
~c"hi" ++ ~c"!"
# => ~c"hi!"
```

كلما كانت المصفوفة الأولى أطول، كان الدمج أبطأ، لذا تجنّب الإلحاق المتكرر بمصفوفات مهما كان طولها.

## قابلية الطباعة

إذا كانت مصفوفة الأعداد الصحيحة تحتوي فقط على أعداد صحيحة تمثل نقاط ترميز محارف قابلة للطباعة، فستُعرض على هيئة مصفوفة محارف، حتى لو عُرِّفت باستخدام الصيغة `[]`.

```elixir
~c"ABC"
# => ~c"ABC"

[65, 66, 67]
# => ~c"ABC"
```

وإذا احتوت مصفوفة الأعداد الصحيحة على نقطة ترميز واحدة لمحرف غير قابل للطباعة (مثل `0-6` و`14-26` و`28-31`)، فستُعرض على هيئة مصفوفة، حتى لو عُرِّفت باستخدام الصيغة `~c""`.

```elixir
~c"ABC\0"
# => [65, 66, 67, 0]

[65, 66, 67, 0]
# => [65, 66, 67, 0]
```

يمكن التحقق من قابلية الطباعة باستخدام [`List.ascii_printable?`][list-ascii-printable].

```elixir
List.ascii_printable?([65, 66, 67])
# => true
List.ascii_printable?([65, 66, 67, 0])
# => false
```

ضع في اعتبارك أن هاتين طريقتان مختلفتان _لعرض_ البيانات نفسها؛ فالقيم متساوية تمامًا.

```elixir
~c"ABC" === [65, 66, 67]
# => true
```

عند طباعة مصفوفة باستخدام [`IO.inspect`][io-inspect]، يمكنك استخدام الخيار [`:charlists`][inspect-opts] للتحكم في كيفية طباعة المصفوفات.

```elixir
IO.inspect(~c"ABC", charlists: :as_charlists)
# => prints ~c"ABC"

IO.inspect(~c"ABC", charlists: :as_lists)
# => prints [65, 66, 67]
```

## نقاط الترميز

يمكنك وضع `?` قبل المحرف للحصول على نقطة ترميزه.

```elixir
?A
# => 65

[?:, ?)]
# => ~c":)"
```

## مصفوفات المحارف مقابل السلاسل النصية

لا تُعتبر مصفوفات المحارف والسلاسل النصية المكوّنة من المحارف نفسها متساوية.

```elixir
~c"hello" == "hello"
false
```

كل قيمة في مصفوفة المحارف هي [نقطة ترميز يونيكود لمحرف][unicode-table]، أما في السلسلة النصية فتُرمَّز نقاط الترميز وفق [UTF-8][utf8].

```elixir
IO.inspect(~c"tschüss", charlists: :as_lists)
# => prints [116, 115, 99, 104, 252, 115, 115]

IO.inspect("tschüss", binaries: :as_binaries)
# => prints <<116, 115, 99, 104, 195, 188, 115, 115>>
```

لاحظ كيف يُرمَّز الحرف `ü`، ونقطة ترميزه `252`، في UTF-8 على هيئة `195` و`188`.

**من الناحية العملية، نادرًا ما تُستخدم مصفوفات المحارف**. أهم استخدام لها هو التفاعل مع Erlang، لا سيما عند استخدام مكتبات أقدم لا تقبل البيانات الثنائية كوسائط.

عند العمل مع Elixir، **استخدم السلاسل النصية لتخزين النصوص**. فوحدة `String` تقدّم مجموعة واسعة من الدوال لمعالجة النصوص، وهي دوال غير متاحة لمصفوفات المحارف.

يمكن تحويل مصفوفات المحارف إلى سلاسل نصية باستخدام [`to_string`][kernel-to-string].

```elixir
to_string(~c"hello")
# => "hello"
```
