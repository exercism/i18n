# مقدمة

تُمثّل Python القيمتين صحيح وخطأ بالنوع [`bool`][bools]، وهو صنف فرعي من `int`.
لا توجد تحت هذا النوع سوى قيمتين: `True` و`False`.
ويمكن إسناد هاتين القيمتين إلى متغير:

```python
>>> true_variable = True
>>> false_variable = False
```

يمكننا تقييم تعبيرات منطقية باستخدام العوامل `and` و`or` و`not`.

```python
>>> true_variable = True and True
>>> false_variable = True and False

>>> true_variable = False or True
>>> false_variable = False or False

>>> true_variable = not False
>>> false_variable = not True
```

[bools]: https://docs.python.org/3/library/stdtypes.html#typebool
