# الاختبارات

## تشغيل الاختبارات

لتشغيل الاختبارات، نفّذ الأمر التالي:

```bash
dotnet test
```

## حل التمرين

حل التمرين يعني إنجاح جميع اختباراته. بشكل افتراضي، يُنفَّذ اختبار واحد فقط (الأول) عند تشغيل الاختبارات. هذا مقصود، لأنه يتيح لك التركيز على إنجاح هذا الاختبار الواحد فقط. وبمجرد أن ينجح، يمكنك تفعيل الاختبار التالي بإزالة `Skip = "Remove this Skip property to run this test"` من سمة `[<Fact>]` أو `[<Theory>]` الخاصة بالاختبار. وعندما تُفعّل جميع الاختبارات ويجعلها تطبيقك تنجح كلها، تكون قد حللت التمرين!

ولمساعدتك على البدء، يأتي كل تمرين بملف تطبيق مبدئي. يمكنك استخدام هذا الملف كنقطة انطلاق لبناء حلّك. ولا تتردد في حذف هذا الملف أو تغييره إذا رأيت أن ذلك هو الصواب.

## استخدام الحزم

ينبغي أن تكون قادرًا على حل معظم التمارين دون استخدام أي حزم خارجية. ومع ذلك، في التمارين التي تريد فيها فعلًا استخدام حزمة خارجية، يمكنك إضافتها إلى مشروعك بتنفيذ الأمر التالي:

```bash
dotnet add package [package-name]
```
