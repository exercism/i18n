# ملحق التعليمات

## السجلات

| السجل   | الاستخدام      | النوع   | الوصف                                  |
| -------- | ------------ | ------- | -------------------------------------- |
| `$a0`    | إدخال        | عنوان   | اللون الأول كسلسلة نصية منتهية بمحرف فارغ  |
| `$a1`    | إدخال        | عنوان   | اللون الثاني كسلسلة نصية منتهية بمحرف فارغ |
| `$a2`    | إدخال        | عنوان   | اللون الثالث كسلسلة نصية منتهية بمحرف فارغ |
| `$a3`    | إدخال/إخراج  | عنوان   | سلسلة الإخراج المنتهية بمحرف فارغ         |
| `$t0-9`  | مؤقت         | أي      | يُستخدم للتخزين المؤقت                  |
