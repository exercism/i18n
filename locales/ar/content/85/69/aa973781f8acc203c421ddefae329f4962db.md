# مقدمة

## الأعداد

يوجد في Java نوعان مختلفان من الأعداد:

- الأعداد الصحيحة: أعداد لا تحتوي على أي أرقام بعد الفاصلة العشرية (أعداد كاملة).
  من أمثلتها `-6` و`0` و`1` و`25` و`976` و`-500000`.
- الأعداد العشرية: أعداد تحتوي على صفر أو أكثر من الأرقام بعد الفاصلة العشرية.
  من أمثلتها `-20.4` و`0.1` و`2.72` و`16.984025` و`1024.0`.

أكثر نوعين عدديين شيوعًا في Java هما `int` و`double`.
النوع `int` عدد صحيح بسعة 32 بت، والنوع `double` عدد عشري بسعة 64 بت.

تُجرى العمليات الحسابية باستخدام عوامل الحساب المعيارية.
يمكن مقارنة الأعداد باستخدام عوامل المقارنة العددية المعيارية (مثل `5 > 4` و`4 <= 5`) وعاملي التساوي (`==`) وعدم التساوي (`!=`).

يوجد في Java نوعان من التحويلات العددية:

1. التحويلات الضمنية: لن تُفقد أي بيانات ولن تُطلب أي صياغة إضافية.
2. التحويلات الصريحة: قد تُفقد البيانات وتُطلب صياغة إضافية على شكل _تحويل قسري_.

ولأن النوع `int` أقل دقة من النوع `double`، فإن التحويل من `int` إلى `double` آمن، لذلك فهو تحويل ضمني.
أما التحويل من `double` إلى `int` فقد يعني فقدان بيانات، لذا فهو يتطلب تحويلًا صريحًا.

## عبارات `if-else`

### عبارة _if-then_

أبسط عبارة للتحكم في التدفق في Java هي عبارة _if-then_.
تُستخدم هذه العبارة لتنفيذ مقطع من الكود فقط عندما يكون شرط معيّن هو `true`.
تُعرَّف عبارة _if-then_ باستخدام جملة `if`:

```java
class Car {
    void drive() {
        // the "if" clause: the car needs to have fuel left to drive
        if (fuel > 0) {
            // the "then" clause: the car drives, consuming fuel
            fuel--;
        }
    }
}
```

في المثال أعلاه، إذا نفد وقود السيارة، فلن يؤدي استدعاء الطريقة `Car.drive` إلى أي شيء.

### عبارة _if-then-else_

توفّر عبارة _if-then-else_ مسارًا بديلًا للتنفيذ عندما تكون نتيجة الشرط في جملة `if` هي `false`.
يأتي هذا المسار البديل للتنفيذ بعد جملة `if`، ويُعرَّف باستخدام جملة `else`:

```java
class Car {
    void drive() {
        if (fuel > 0) {
            fuel--;
        } else {
            stop();
        }
    }
}
```

في المثال أعلاه، إذا نفد وقود السيارة، فسيؤدي استدعاء الطريقة `Car.drive` إلى استدعاء طريقة أخرى لإيقاف السيارة.

تدعم عبارة _if-then-else_ أيضًا تعدد الشروط باستخدام جملة `else if`:

```java
class Car {
    void drive() {
        if (fuel > 5) {
            fuel--;
        } else if (fuel > 0) {
            turnOnFuelLight();
            fuel--;
        } else {
            stop();
        }
    }
}
```

في المثال أعلاه، قيادة السيارة عندما يكون الوقود أقل من `5` أو يساويها ستُحرّك السيارة، لكنها ستُضيء مصباح الوقود.
وعندما يصل الوقود إلى `0`، تتوقف السيارة عن السير.
