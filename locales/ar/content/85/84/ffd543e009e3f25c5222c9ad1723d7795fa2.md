# تشغيل الاختبارات

لتشغيل مجموعة الاختبارات، نفّذ الأمر التالي:

```bash
stack test
```

#### إذا ظهرت لك رسالة خطأ كهذه...

```
No .cabal file found in directory
```

أو

```
RedownloadInvalidResponse Request {
...
}
 "/home/username/.stack/build-plan/lts-xx.yy.yaml" (Response {responseStatus = Status {statusCode = 404, statusMessage = "Not Found"},
```

فأنت على الأرجح تشغّل إصدارًا قديمًا من `stack` وتحتاج إلى ترقيته. جرّب تنفيذ:

```bash
stack upgrade
```

أو اطّلع على خيارات أخرى للترقية في [وثائق Stack](https://docs.haskellstack.org/en/stable/install_and_upgrade/#upgrade).

#### وإلا، إذا ظهرت لك رسالة خطأ كهذه...

```
No compiler found, expected minor version match with...
Try running "stack setup" to install the correct GHC...
```

فافعل ما تقوله لك فحسب، وسيقوم بتنزيل إصدار المترجم الصحيح وتثبيته:

```bash
stack setup
```

# تشغيل *GHCi*

إذا أردت أن تلهو بحلّك داخل GHCi، فما عليك سوى تنفيذ الأمر:

```bash
stack ghci
```
