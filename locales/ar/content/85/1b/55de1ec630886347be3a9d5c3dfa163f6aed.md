# مقدمة

## أنواع الدوال

لو أزلنا كل الأسماء والتسميات من توقيع دالة في Swift، فلن يتبقى لدينا سوى نوع الدالة.

```swift
func shoppingList(item: String, quantity: Int) -> String {
  "You need to buy \(quantity) \(item)."
}
// shoppingList: (String, Int) -> String

func repeater(_ phrase: String, times: Int) -> String {
  var result = ""
  for _ in 1...times {
    result += phrase
  }
  return result
}
// repeater: (String, Int) -> String

func printString(line: String) {
  print(line)
}
// printString: (String) -> ()
```

لاحظ أن نوعي الدالتين الأولى والثانية متماثلان، وهو `(String, Int) -> String`، رغم أن التوقيعين مختلفان وأن الدالتين تعملان بطريقة مختلفة تمامًا. كلتا الدالتين تأخذان `String` و`Int` كمدخل، وتُرجعان `String`. وكما يتبيّن من نوع الدالة الثالثة، فرغم أن جسم الدالة لا يبدو أنه يُرجع أي شيء، فإنه في الواقع يُرجع ضمنيًا `()`، وهي القيمة الوحيدة من النوع `Void`.

يمكن استخدام أنواع الدوال هذه بالطريقة نفسها التي تُستخدم بها أي أنواع أخرى في Swift، فعلى سبيل المثال، يمكن استخدامها في تعريف المتغيرات أو الثوابت. ولأن الدوال قيم في Swift، يمكن إسناد الدوال الموجودة بالفعل إلى هذه الثوابت أو المتغيرات:

```swift
var stringAndIntToString: (String, Int) -> String

stringAndIntToString = shoppingList
stringAndIntToString("carrots", 3)
// => "You need to buy 3 carrots."
```

وكما هو الحال مع المتغيرات والثوابت الأخرى، يجب أن تكون القيمة التي تُسند إليها من النوع الصحيح:

```swift
stringAndIntToString = printShoppingList
// Error: Cannot assign value of type '(String) -> ()' to type '(String, Int) -> String'
```

## أنواع الدوال كأنواع للمعاملات

ولأن أنواع الدوال يمكن استخدامها في أي مكان يمكن استخدام أنواع أخرى فيه، فإنه يمكن استخدامها كأنواع للمعاملات، وتمريرها إلى دوال أخرى، ومنادتها من داخل تلك الدوال.

```swift
func apply3(to str: String, function f: (String, Int) -> String) -> String {
  f(str,3)
}
// apply3: ([String], (String, Int) -> String) -> [String]

apply3(to: "eggs", function: shoppingList)
// => "You need to buy 3 eggs."

apply3(to: "eggs", function: repeater)
// => "eggseggseggs"
```

## أنواع الدوال كأنواع للإرجاع

وبالمثل، يمكن استخدام أنواع الدوال كأنواع للإرجاع. بعبارة أخرى، يمكنك كتابة دوال تُنشئ دوال أخرى وتُرجعها. وعند إنشاء هذه الدوال، يمكن للدالة التي تُرجَع أن تستخدم المعاملات الأخرى الممرَّرة إلى الدالة أو المتغيرات المحلية المُنشأة داخل الدالة الأم.

```swift
func makeAdder(base: Int) -> (Int) -> Int {
  func adder(_ i: Int) -> Int {
    base + i
  }
  return adder
}
// makeAdder: (Int) -> (Int) -> Int

let add10 = makeAdder(base: 10)
// add10: (Int) -> Int

let subtract20 = makeAdder(base: -20)
// subtract20: (Int) -> Int

add10(5)
// => 15

subtract20(5)
// => -15
```
