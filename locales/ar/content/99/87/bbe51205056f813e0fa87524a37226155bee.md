* **عدّة تطوير Java** (Java Development Kit، اختصارًا JDK): تُصرَّف Kotlin إلى بايت كود Java، لذا تحتاج إلى تثبيت JDK الذي يشمل كلا من بيئة تشغيل Java (Java Runtime) *و* أدوات التطوير (وأبرزها مصرّف Java)؛ و
* **Gradle**: أداة بناء مخصّصة لمشاريع JVM وتدعم Kotlin.

## Windows

افتح موجّه أوامر بصلاحيات المسؤول.  (إذا احتجت إلى مساعدة في فتح موجّه أوامر بصلاحيات إدارية، فراجع [فتح موجّه أوامر بصلاحيات مرتفعة في Windows 8+](http://www.howtogeek.com/194041/how-to-open-the-command-prompt-as-administrator-in-windows-8.1/) (أو [Windows 7](http://www.howtogeek.com/howto/windows-vista/run-a-command-as-administrator-from-the-windows-vista-run-box/)).

1. إذا لم تكن قد ثبّت Chocolatey، فثبّته الآن:

      ```batchfile
        C:\Windows\system32> @powershell -NoProfile -ExecutionPolicy unrestricted -Command "iex ((new-object net.webclient).DownloadString('https://chocolatey.org/install.ps1'))" && SET PATH=%PATH%;%ALLUSERSPROFILE%\chocolatey\bin
      ```

2.  ثبّت JDK:

       ```batchfile
        C:\Windows\system32> choco install openjdk11
        ...
        C:\Windows\system32> refreshenv
        ...
       ```

نوصي بإغلاق موجّه الأوامر الإداري وفتح موجّه أوامر جديد، فلا تحتاج إلى صلاحيات المسؤول للتدرّب على تمارين Exercism.

أنت الآن جاهز للبدء مع مسار Kotlin في Exercism!

للبدء، راجع «[تشغيل الاختبارات](https://exercism.org/docs/tracks/kotlin/tests)».

## macOS

فيما يلي تعليمات التثبيت باستخدام الطريقة الأكثر شيوعًا، أي باستخدام Homebrew.  وإذا كنت تفضّل ذلك، يمكنك أيضًا [التثبيت على macOS بدون Homebrew](#h-installing-on-macos-without-homebrew).

### التثبيت

1. إذا لم تكن قد ثبّت [Homebrew](http://brew.sh) بعد، فثبّته الآن:

      ```sh
        $ /usr/bin/ruby -e "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/master/install)"
      ```

2. أضف مستودع [Homebrew Cask](https://caskroom.github.io/)، فهو يتيح لنا تثبيت حزم ثنائية جاهزة مثل JDK.

      ```
        $ brew tap adoptopenjdk/openjdk
      ```

3.  ثبّت JDK:

       ```
        $ brew install --cask adoptopenjdk11
       ```

أنت الآن جاهز للبدء مع مسار Kotlin في Exercism!

للبدء، راجع «[تشغيل الاختبارات](https://exercism.org/docs/tracks/kotlin/tests)».

### Debian

إذا كنت تستخدم Debian أو إحدى توزيعاتها المشتقّة منها (مثل Ubuntu أو Linux Mint)، فاستخدم APT:

*(تم التحقق منها على: Ubuntu 14 و16 و18)*

1. ثبّت JDK:

      ```sh
        $ sudo apt-get update
        $ sudo apt-get install software-properties-common
        $ sudo add-apt-repository ppa:openjdk-r/ppa
        $ sudo apt-get update
        $ sudo apt-get install openjdk-11-jdk
      ```

### توزيعات Linux أخرى

توجد طرق كثيرة لتثبيت Jdk 11، لكن إحدى أسهل الطرق هي استخدام SDKMAN،
الذي يتيح لك تثبيت OpenJdk11 بسهولة. اتبع الخطوات التالية:

1. ثبّت SDKMAN:
    ```sh
    $ curl -s "https://get.sdkman.io" | bash
    ``` 
    (إذا لم ينجح ذلك، فألقِ نظرة على التعليمات الموجودة هنا: https://sdkman.io/install )
1. ثبّت openjdk11:
    ```
    $ sdk install java 11.0.2-open
    ```
