# مقدمة

القيم الحرفية هي قيم ثابتة تُستخدم مباشرةً في الكود.
وهي لا تحتاج إلى أي حساب أثناء التنفيذ.
وتأتي بأشكال متنوعة لتمثيل أنواع مختلفة من البيانات بكفاءة.
وأكثر القيم الحرفية شيوعًا هي القيم العددية، لكن توجد أيضًا عوامل حرفية لأنواع التاريخ والوقت والسلسلة النصية.
وسيوضح مفهوم لاحق كيف يمكن استخدام العوامل الحرفية التي يعرّفها المستخدم.

## القيم الحرفية العددية

تشمل القيم الحرفية العددية التمثيلات العشرية والثمانية والست عشرية والثنائية.
وقد غطّينا هذه الأساسيات بالفعل في [مفهوم الأعداد][numbers-concept].

يفهم المترجم كل التمثيلات مثل `23` و`0x50f7ba11` و`0xba5eba11` على أنها من النوع `int`.
النوع العام `int` موقّع، و([بحسب المترجم والنظام][in-depth-integers]) غالبًا ما يمتد مداه من `-2'147'483'648` إلى `2'147'483'647`.
وهذا كافٍ في معظم الأحيان، ولا داعي للقلق بشأن النوع المحدد.

تتطلب بعض حالات الاستخدام مديات أكبر أو بصمات ذاكرة صغيرة جدًا للبرامج.
ولتكون صريحًا يمكنك تحديد أنواع أعداد صحيحة معينة مباشرةً مع القيمة الحرفية العددية.

عندما لا تكون هناك حاجة إلى الأعداد السالبة، مع الرغبة في المدى الإضافي، تُستخدم اللاحقة `u` أو `U` للأعداد الصحيحة _غير الموقّعة_.
وللحصول على مديات أكبر يمكن استخدام `L` أو حتى `LL` للنوعين long و long long.

~~~~exercism/caution
يُسمح باستخدام الحرف الصغير `l`، لكن يسهل الخلط بينه وبين الرقم `1`، ولذلك يُنصح بتجنّبه.
~~~~

```cpp
auto net_worth_christian_grey{2'500'000'000U}; // out of range for 32-bit integers
auto net_worth_carlisle_cullen{46'000'000'000LL}; // int and uint are not enough
```

عادةً ما تُحل الأعداد ذات الفاصلة العائمة إلى النوع `double` أثناء التصريف.
وهذه حالة افتراضية جيدة، وحالات الاستخدام مع النوع الأضيق `float` أقل شيوعًا من مثال العدد غير الموقّع أعلاه.

~~~~exercism/advanced
يقدّم [معيار C++23][cpp23-literals] تحكمًا أدقّ مع قيم حرفية مثل `f128` أو `F16`.
وتسمح بعض المترجمات بقيمها الحرفية الخاصة.
يسمح GCC باستخدام `d` كقيمة حرفية، لكن هذا غير منصوص عليه في المعيار وقد يعيق التوافق بين الأنظمة الأساسية.

[cpp23-literals]: https://en.cppreference.com/w/cpp/language/floating_literal

~~~~

```cpp
auto light_year_in_m{9.46073e+15f}; // well in the range of float
auto earth_to_edge_comoving_distance_in_nm{4.32355e+32}; // needs double type for magnitude
auto eulers_number{2.718281828459045}; // needs double type for precision
```

## القيم الحرفية للمحارف والسلاسل النصية

استخدمت مفاهيم أخرى بالفعل قيمًا حرفية للمحارف بين علامتي اقتباس مفردتين مثل `'}'` أو `'@'`.

في C++ يقتصر `char` على أول 128 من [رموز محارف ASCII][ascii-code].
ولاستخدام عدة محارف ASCII أو محارف ASCII الموسّعة مثل `‰` أو حتى محارف يونيكود مثل `麗` و`ẞ`، تلزم أنواع أخرى.
وفي مفهوم سابق قُدّمت القيم الحرفية للسلسلة النصية بعلامات _الاقتباس المزدوجة_: `"一体どういう意味ですか。C++です"`.
والنوع الفعلي لهذه العبارة اليابانية هو `const char (&)[46]`، أي سلسلة نصية بنمط C.

استخدام القيم الحرفية للسلسلة النصية غير مُفعّل افتراضيًا.
ولاستخدام القيمة الحرفية _للسلسلة النصية_ `""s` أو القيمة الحرفية _لعرض السلسلة النصية_ `""sv`، على المستخدم تحديد استخدامهما عبر استخدام مساحة الأسماء المتعلقة:

```cpp
#include <string>
#include <string_view>

using namespace std::literals;

auto green_light{"무궁화 꽃 이 피었 습니다"};
// green_light type is const char (&)[36]
auto umbrella{"달고나"s};
// umbrella type is std::basic_string<char>, the same as std::string
auto il_nam{"보는 것이 하는 것보다 더 재미있을 수가 없지"sv};
// il_nam type is std::basic_string_view<char>
```

يمكن اعتبار _string_view_ مرجعًا إلى سلسلة نصية ثابتة.

[ascii-code]: https://www.ascii-code.com/
