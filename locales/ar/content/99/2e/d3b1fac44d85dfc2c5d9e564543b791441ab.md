# ملحق التعليمات

## السجلات

| السجل | الاستخدام    | النوع   | الوصف                        |
| -------- | ------------ | ------- | ---------------------------- |
| `$a0`    | إدخال        | عدد صحيح | N، مجموع أضلاع المثلث        |
| `$a1`    | إدخال/إخراج  | عنوان   | قيم a                        |
| `$a2`    | إدخال/إخراج  | عنوان   | قيم b                        |
| `$a3`    | إدخال/إخراج  | عنوان   | قيم c                        |
| `$v0`    | إخراج        | عدد صحيح | عدد الثلاثيات                |
| `$t0-9`  | مؤقت         | أي      | للتخزين المؤقت               |
