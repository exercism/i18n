# التعليمات

قرصان يخطّط لمسار عبر خريطة لخلجان مخفية.
الخريطة جدول تجزئة مفاتيحه أسماء الخلجان، وكل قيمة فيه
مصفوفة بالخلجان التي يمكنك الوصول إليها مباشرة من ذلك الخليج.

## 1. تفريغ طابور المد

عرّف `tide-queue` بحيث يأخذ مصفوفة من العناصر، ويدفع كل عنصر
إلى طابور مزدوج جديد (بالترتيب)، ثم يُخرجها جميعًا إلى مصفوفة
تحافظ على الترتيب الأصلي. هذا هو نمط الوارد أولًا يخرج أولًا (FIFO):
الدفع إلى الخلف، والإخراج من الأمام.

```factor
{ "alpha" "bravo" "charlie" } tide-queue .
! => { "alpha" "bravo" "charlie" }
```

## 2. الخلجان التي يمكن الوصول إليها

عرّف `coves-reachable` بحيث يأخذ خليجًا نقطة انطلاق وخريطة،
ويُرجع مجموعة تجزئة بكل خليج يمكن الوصول إليه من `start`،
بما في ذلك `start` نفسه.

```factor
"Skull Bay" H{
    { "Skull Bay"   { "Hidden Cove" } }
    { "Hidden Cove" { "Reef Point"  } }
    { "Reef Point"  { } }
} coves-reachable .
! => HS{ "Skull Bay" "Hidden Cove" "Reef Point" }
```

استخدم `<dlist>` كحدٍّ أمامي لبحث العرض (BFS) و`HS{ }` للمجموعة
المزارة.

## 3. عدد القفزات

عرّف `hop-count` بحيث يأخذ خليج بداية، وخليج هدف، وخريطة،
ويُرجع أقل عدد من القفزات بينهما، أو `f` إذا تعذّر الوصول إلى الهدف.

```factor
"Skull Bay" "Hidden Cove"
H{
    { "Skull Bay"   { "Hidden Cove" } }
    { "Hidden Cove" { } }
} hop-count .
! => 1
```

احمل كل خليج مع مسافته من البداية في الطابور المزدوج (مصفوفة من
عنصرين تكفي).

## 4. عدد الذهب

يُعلن الهيكل `gold-count` بالرمز `:`. غيّره إلى `MEMO:`
(وليس `:`) بحيث تُحسب نتيجة كل خليج مرة واحدة وتُخزَّن.
ابحث عن ذهب الخليج في الثابت `gold-distribution` الذي يوفّره
التمرين.
أي خليج غير موجود في التوزيع ذهبه صفر.

```factor
"Smuggler's Hollow" gold-count .   ! => 200
"Davy Jones' Locker" gold-count .  ! => 0
```

## 5. مسار الكنز

عرّف `treasure-route` بحيث يأخذ خليج بداية وخريطة،
ويُرجع الخليج القابل للوصول صاحب أكبر قدر من الذهب. استخدم
`coves-reachable` من المهمة 2 و`gold-count` من المهمة 4.

```factor
"Skull Bay" some-chart treasure-route .
! => "Smuggler's Hollow"   (the richest reachable cove)
```

الـ `gold-count` المخزَّن مؤقتًا يجعل الاستعلامات المتكررة بلا كلفة، وهذا
مفيد عندما تستشير عدة أجزاء من الخوارزمية الخليج نفسه.
