# مقدمة

**الإغلاقات** هي نمط برمجي [في Clojure][clojure-guide-closures] يسمح باستخدام متغيرات من [النطاق المعجمي][wiki-lexical-scope] الخارجي داخل دالة. تدعم Clojure الإغلاقات بشفافية، وكثيرًا ما تُستخدم دون معرفة ماهيتها.

```clojure
;; Top-level definitions are global-scope
(def dozen 12)

;; Functions create a new scope.
;; Referencing the outer variable here is a closure.
(fn [n] (* dozen n))
```

## الإغلاقات لحفظ الحالة وتمرير القيم

استخدام `atom` يسمح بالحفاظ على بعض الحالة:

```clojure
;; This function closure increments the counter's state
;; in the outer lexical context.
;; This way the counter can be shared between many calling contexts.

(def increment
  (let [counter (atom 0)]
    (fn [] (swap! counter inc))))
```

كل استدعاء متتالٍ للدالة `increment` يزيد قيمة العدّاد:

``` clojure
(increment)
;;=> 1
(increment)
;;=> 2
```
