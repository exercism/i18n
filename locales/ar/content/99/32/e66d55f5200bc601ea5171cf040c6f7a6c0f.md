# مقدمة

قبل أن يُقدَّم صنف `Promise`، لم يكن هناك سوى أسلوب واحد للتعامل مع الكود غير المتزامن: _نمط الاستدعاء الراجع_.

الاستدعاء الراجع دالة تُمرَّر كوسيط إلى دالة أخرى، وتُستدعى بمجرد انتهاء إجراء ما في تلك الدالة الأخرى. ومن الشائع في دوال الاستدعاء الراجع هذه أن تقبل «خطأ» كمعامل أول (انظر المثال أدناه).

```javascript
function callback(error, arg2, arg3) {}
```

وما علاقة ذلك بالكود غير المتزامن؟

تاريخيًا، استُخدمت دوال الاستدعاء الراجع لكي تتيح لنا القيام ببعض العمل بعد انتهاء مهمة غير متزامنة ودون حجب البرنامج بأكمله.

```javascript
fetchProduct(productId, function (error, data) {
  if (error) {
    // Handle the error
  } else {
    // Do some work
  }
});
```

في المثال أعلاه، تأخذ الدالة `fetchProduct` (وهي غير متزامنة) استدعاءً راجعًا كوسيط ثانٍ يحدد ما ينبغي فعله عند استرجاع بيانات المنتج.
