# ملحق التعليمات

## نصيحة

الدالة التي لها *نوع إرجاع* لا يمكنها إرجاع إلا بيانات من ذلك *النوع* و`null`.
ومع ذلك، فإن من يستدعي الدالة يتوقع نوع بيانات واحدًا فقط.

مثال:
```dart
String hello(int a){
    if ( a == 0){
        return "a";
    } else {
        return null;
    }
}
```
ولتوضيح أن هذه الدالة يمكنها أيضًا إرجاع `null` أو أنواع بيانات أخرى، استخدم `dynamic`.
```dart
dynamic hello(int a){
    if ( a == 0){
        return "a";
    } else {
        return null;
    }
}
