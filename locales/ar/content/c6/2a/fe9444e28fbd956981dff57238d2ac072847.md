# مقدمة

## طرق الامتداد

تسمح طرق الامتداد بإضافة طرق إلى أنواع موجودة دون إنشاء نوع مشتق جديد، أو إعادة ترجمة، أو تعديل النوع الأصلي بأي شكل آخر. تُعرَّف كطرق `static` ولكن يتم استدعاؤها باستخدام صيغة استدعاء طرق المثيل. يسبق معاملها الأول المُعدِّل `this`، وهو يحدد النوع الذي تعمل عليه الطريقة، وتُدخَل في النطاق على مستوى مساحة الأسماء.

```csharp
public static int WordCount(this string str)
{
    return str.Split().Length;
}

"Hello World".WordCount();
// => 2
```
