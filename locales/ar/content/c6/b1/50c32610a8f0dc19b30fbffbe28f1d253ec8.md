# مقدمة

في JavaScript، تتيح لك _السلاسل النصية القالبية_ تضمين تعبيرات داخل السلاسل النصية، وهو ما يُعرف أيضًا بالتداخل النصي.
تُوسّع هذه الإمكانية وظائف الكائن العام المدمج [`String`][string-reference].

يمكنك إنشاء السلاسل النصية القالبية في JavaScript بتغليف النص بعلامات الاقتباس الخلفية.
فهي لا تتيح للنص أن يتضمّن أسطرًا جديدة ومحارف خاصة أخرى فحسب، بل تتيح لك أيضًا تضمين المتغيرات وتعبيرات أخرى.

```javascript
const num1 = 1;
const num2 = 2;

`Adding ${num1} and ${num2} gives ${num1 + num2}.`;
// => Adding 1 and 2 gives 3.
```

في المثال أعلاه، تُستخدم علامات الاقتباس الخلفية - (<code>\`\`</code>) - لتمثيل سلسلة نصية قالبية. أما `${...}` فهي العنصر النائب المستخدم للاستبدال.
وأي أنواع غير نصية تُحوَّل _ضمنيًا_ إلى سلاسل نصية.
ويُغطّي هذا الموضوع مفهوم [تحويل الأنواع][type-conversion-concept].
ويمكن استخدام جميع أنواع التعبيرات مع السلاسل النصية القالبية.

```javascript
const track = 'JavaScript';

`This track on exercism.org is ${track.toUpperCase()}.`;
// => This track on exercism.org is JAVASCRIPT.
```

عندما تحتاج إلى تنسيق السلاسل النصية على عدة أسطر:

```javascript
`This is an example of using template
strings to accomplish multiple
lines`;
```

مع إمكانات الاستبدال المتاحة، يمكنك أيضًا إدخال منطق إلى العملية لتحديد الشكل الذي ينبغي أن تكون عليه السلسلة النصية الناتجة.

مثال على ذلك تضمين [عامل ثلاثي][ternary-operator].
هذا العامل صيغة مختصرة لكتابة عبارة `if/else`.
وصيغته هي `condition ? consequent-expression : alternative-expression`.
إذا كان الشرط صحيحًا منطقيًا، فستُرجع القيمة الواقعة على يسار النقطتين.
وإلا فإن نتيجة التعبير الثلاثي هي القيمة الواقعة على يمين النقطتين.

```javascript
const grade = 95;

`You have ${grade > 90 ? 'passed' : 'failed'} the exam.`;
// => You have passed the exam.
```
