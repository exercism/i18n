# مقدمة

## البانيات

يتم إنشاء نسخة من _صنف_ باستدعاء _بانيته_ عبر العامل `new`. البانية نوع خاص من الطُرق، هدفها تهيئة نسخة منشأة حديثًا. تبدو البانيات كالطُرق العادية، لكن دون نوع إرجاع، وباسم يطابق اسم الصنف.

```csharp
class Library
{
    private int books;

    public Library()
    {
        // Initialize the books field
        this.books = 10;
    }
}

// This will call the constructor
var library = new Library();
```

مثل الطُرق العادية، يمكن للبانيات أن تملك معاملات. وعادةً ما تُخزَّن معاملات البانية في حقول (خاصة) للوصول إليها لاحقًا، أو تُستخدم في عملية حسابية لمرة واحدة. ويمكن تمرير الوسائط إلى البانيات تمامًا كما تُمرَّر الوسائط إلى الطُرق العادية.

```csharp
class Building
{
    private int numberOfStories;
    private int totalHeight;

    public Building(int numberOfStories, double storyHeight)
    {
        this.numberOfStories = numberOfStories;
        this.totalHeight = numberOfStories * storyHeight;
    }
}

// Call a constructor with two arguments
var largeBuilding = new Building(55, 6.2)
```
