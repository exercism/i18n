# مقدمة

في هذا التمرين عليك تنفيذ منطق بشكل شرطي. الطريقة الأكثر شيوعًا للقيام بذلك في C# هي استخدام جملة شرطية `if/else`:

```csharp
int x = 6;

if (x == 5)
{
    // Execute logic if x equals 5
}
else if (x > 7)
{
    // Execute logic if x greater than 7
}
else
{
    // Execute logic in all other cases
}
```

يجب أن يكون شرط جملة `if` الشرطية من النوع `bool`. لا يوجد في C# مفهوم القيم _truthy_.
