# التعليمات

أنت تنشئ لعبة إلكترونية بسيطة يمكن لصديق أن يخمّن فيها عددًا سريًا. تريد تقديم بعض الملاحظات، لكن دون أن تكشف الإجابة عبر التخمين. عليك تصميم دالة تقدّم ردودًا مختلفة بناءً على علاقة التخمين بالعدد السري.

| الشرط                                                     | الرد       |
| ------------------------------------------------------------- | -------------- |
| عندما يطابق التخمين العدد السري                      | "Correct"      |
| عندما يكون التخمين أكبر من العدد السري بواحد أو أصغر منه بواحد | "So close"     |
| عندما يكون التخمين أكبر من العدد السري              | "Too high"     |
| عندما يكون التخمين أصغر من العدد السري              | "Too low"      |
| عندما لا يُقدَّم أي تخمين                                       | "Make a guess" |

جميع التخمينات والأعداد السرية أعداد صحيحة.

## 1. اجعل الرد عندما يطابق التخمين العدد السري

نفّذ الدالة `compare/2` التي تأخذ وسيطين، `secret_number` و `guess`، وكلاهما أعداد صحيحة.

```elixir
GuessingGame.compare(5, 5)
# => "Correct"
```

## 2. اجعل الرد عندما يكون التخمين أكبر من العدد السري

عدّل الدالة `compare` لتستجيب للتخمينات التي تكون أكبر من العدد السري.

```elixir
GuessingGame.compare(5, 8)
# => "Too high"
```

## 3. اجعل الرد عندما يكون التخمين أصغر من العدد السري

عدّل الدالة `compare` لتستجيب للتخمينات التي تكون أصغر من العدد السري.

```elixir
GuessingGame.compare(5, 2)
# => "Too low"
```

## 4. اجعل الردود عندما يكون التخمين أكبر من العدد السري بواحد أو أصغر منه بواحد

عدّل الدالة `compare` لتستجيب للتخمينات القريبة من العدد السري.

```elixir
GuessingGame.compare(5, 6)
# => "So close"
GuessingGame.compare(5, 4)
# => "So close"
```

## 5. اجعل الرد عندما لا يوجد تخمين

عدّل الدالة `compare` لتستجيب لغياب التخمين.

```elixir
GuessingGame.compare(5)
# => "Make a guess"

GuessingGame.compare(5, :no_guess)
# => "Make a guess"
```
