# التثبيت

## متطلبات مسار لغة PowerShell

يتطلب مسار لغة PowerShell على Exercism أن تكون العناصر التالية مثبّتة على نظامك:

- PowerShell أو Windows PowerShell Core
- وحدة إطار الاختبار والمحاكاة Pester مثبّتة

(ملاحظة: الدعم المقدَّم لـ PowerShell محدود بالإصلاحات الحرجة. أما PowerShell Core فيُصان باستمرار ويتمتع بدعم أوسع عبر الأنظمة الأساسية)

### تثبيت PowerShell

يأتي PowerShell مثبّتًا مسبقًا على جميع إصدارات Windows بدءًا من Windows 7 SP1 فصاعدًا.

يمكنك العثور على أحدث إصدار من PowerShell وتعليمات التثبيت لجميع الأنظمة الأساسية (Linux وmacOS وWindows) [هنا][installation].

يتوفر أيضًا الكود المصدري والتثبيت اليدوي لـ [PowerShell][source-code].

### تثبيت إطار العمل Pester وتحديثه

[Pester][pester] هو إطار اختبار PowerShell.
بدءًا من الإصدار 4.0.9 أصبح متوافقًا مع PowerShell Core على Windows وLinux وMacOS (مع بعض القيود).

إنه مثبّت مسبقًا على Windows 10، لكن يُنصح بتحديثه بتنفيذ أمر PowerShell التالي:

```PowerShell
Install-Module -Name Pester -Force -SkipPublisherCheck
```

وللتحديثات اللاحقة، نفّذ:

```PowerShell
Update-Module -Name Pester
```

وإذا لزم الأمر، تتوفر تعليمات إضافية للتثبيت على: [https://github.com/pester/Pester/wiki/Installation-and-Update]()

## استخدام بيئة تطوير متكاملة (IDE)

إذا كنت تريد تجربة تحرير أكثر اكتمالًا بالمزايا، فالأرجح أنك تريد استخدام بيئة تطوير متكاملة (IDE).
هذه هي أشهر بيئات التطوير المتكاملة التي تدعم بناء مشاريع PowerShell:

### جميع الأنظمة الأساسية

- [PowerShell ISE (بيئة البرمجة النصية المتكاملة)][ise]، بيئة تطوير متكاملة رسومية مدمجة تأتي مع PowerShell (على Windows فقط).
  لتشغيل PowerShell ISE، اكتب `powershell_ise.exe` في وحدة تحكم PowerShell.
- [Visual Studio Code][vsc] مع [إضافة PowerShell][vsc-extension].
  سيتيح لك Visual Studio Code أيضًا تشغيل الاختبارات وتصحيح الكود.
- [Sublime Text 3][sublime] مع [حزمة PowerShell][sublime-package].
