# مقدمة

## جمل `switch`

تصف ويكيبيديا جملة `switch` بأنها "نوع من آليات التحكم في الاختيار تُستخدم للسماح لقيمة متغير أو تعبير بتغيير مسار تنفيذ البرنامج".

تتضمن هذه الآلية الكلمات المفتاحية التالية: `switch` و`case` و`break` و`default`.

في أبسط صورها، تختبر جملة `switch` تعبيرًا أوليًا أو تعبيرًا نصيًا وتتخذ قرارًا بناءً على قيمته. على سبيل المثال:

```csharp
string direction = GetDirection();
switch (direction)
{
    case "left":
        GoLeft();
        break;
    case "right":
        GoRight();
        break;
    default:
        MarkTime();
        break;
}
```

وفي أكثر صورها تطورًا، تُدخل التحويل النازل `case <Type> <variable>:` والحمايات (`when`).

```csharp
Animal animal = GetAnimal();

switch (animal)
{
    case Dog canine:
    case Coyote canine:
        canine.Bark();
        break;
    case Cat cat when cat.HasOnly8Lives():
        cat.IsCareful();
        cat.Meow();
        break;
    case Cat cat:
        cat.Meow();
        break;
}
```
