# مقدمة

تتيح لك الدالة تجميع الكود في وحدة واحدة قابلة لإعادة الاستخدام.
وتتكوّن من الكلمة المفتاحية `func`، واسم الدالة، وقائمة من صفر أو أكثر من المعاملات والأنواع مفصولة بفواصل بين الأقواس الهلالية.

## معاملات الدالة

يجب تحديد نوع كل المعاملات صراحةً؛ فلا يوجد استنتاج للنوع بالنسبة للمعاملات.
ولا توجد قيم افتراضية للمعاملات، لذا فإن جميع معاملات الدالة مطلوبة.

```go
import "fmt"

// No parameters
func PrintHello() {
    fmt.Println("Hello")
}

// One parameter
func PrintHelloName(name string) {
  fmt.Println("Hello " + name)
}
```

ويمكن الإعلان عن معاملات من النوع نفسه معًا، يتبعها إعلان نوع واحد.

```go
import "fmt"

func PrintGreetingName(greeting, name string) {
  fmt.Println(greeting + " " + name)
}
```

## المعاملات مقابل الوسائط

لنستعرض سريعًا مصطلحين كثيرًا ما يُخلط بينهما: `parameters` و`arguments`.
معاملات الدالة هي الأسماء المعرَّفة في توقيع الدالة، مثل `greeting` و`name` في الدالة `PrintGreetingName` أعلاه.
أما وسائط الدالة فهي القيم الفعلية التي تُمرَّر إلى معاملات الدالة عند استدعائها.
على سبيل المثال، في المثال أدناه، `"Hello"` و`"Katrina"` هما الوسيطان المُمرَّران إلى المعاملين `greeting` و`name`:

```go
PrintGreetingName("Hello", "Katrina")
```

## القيم المُرجَعة

تأتي بعد معاملات الدالة صفر أو أكثر من القيم المُرجَعة، والتي يجب أيضًا تحديد أنواعها صراحةً.
تُكتب القيمة المُرجَعة الواحدة مجرّدة، أما القيم المُرجَعة المتعددة فتُحاط بالأقواس الهلالية.
وتُرجع الدوال القيم إلى الكود المُستدعي باستخدام الكلمة المفتاحية `return`.
وقد توجد عدة عبارات `return` في الدالة الواحدة.
وينتهي تنفيذ الدالة بمجرد وصوله إلى إحدى عبارات `return` تلك.
وإذا أرادت الدالة إرجاع عدة قيم، فتُفصل هذه القيم بفواصل.

```go
func Hello(name string) string {
  return "Hello " + name
}

func HelloAndGoodbye(name string) (string, string) {
  return "Hello " + name, "Goodbye " + name
}
```

## استدعاء الدوال

يتم استدعاء الدالة بتحديد اسم الدالة وتمرير وسائط لكل معامل من معاملاتها بين الأقواس الهلالية.

```go
import "fmt"

// No parameters, no return value
func PrintHello() {
    fmt.Println("Hello")
}
// Called like this:
PrintHello()

// One parameter, one return value
func Hello(name string) string {
  return "Hello " + name
}
// Called like this:
greeting := Hello("Dave")

// Multiple parameters, multiple return values
func SumAndMultiply(a, b int) (int, int) {
    return a+b, a*b
}
// Called like this:
aplusb, atimesb := SumAndMultiply(a, b)
```

## تسمية القيم المُرجَعة والإرجاع المجرّد

وكما هو الحال مع المعاملات، يمكن اختياريًا تسمية القيم المُرجَعة.
وإذا استُخدمت قيم مُرجَعة مُسمّاة، فإن عبارة `return` بدون وسائط ستُرجع تلك القيم.
ويُعرف هذا بالإرجاع «المجرّد».

```go
func SumAndMultiplyThenMinus(a, b, c int) (sum, mult int) {
    sum, mult = a+b, a*b
    sum -= c
    mult -= c
    return
}
```
