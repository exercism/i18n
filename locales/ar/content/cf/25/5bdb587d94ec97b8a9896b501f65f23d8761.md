# طرق `String`

تحتوي `String` على عدة طرق يمكن استخدامها للتعامل مع السلاسل النصية.  
تُستدعى هذه الطرق على السلسلة النصية نفسها، وغالبًا ما تُربط معًا لتنفيذ عدة عمليات على سلسلة نصية واحدة.

فيما يلي قائمة ببعض الطرق الأكثر شيوعًا.
راجع [توثيق API الخاص بـ `String`][string-api] للحصول على قائمة كاملة بالطرق.

## String#upcase & String#downcase

تُرجع طريقة [`upcase`][upcase] سلسلة نصية جديدة تتحوّل فيها جميع الأحرف إلى أحرف كبيرة.

```crystal
"hello".upcase
# => "HELLO"
```

تُرجع طريقة [`downcase`][downcase] سلسلة نصية جديدة تتحوّل فيها جميع الأحرف إلى أحرف صغيرة.

```crystal
"HELLO".downcase
# => "hello"
```

## String#capitalize & String#camelcase & String#underscore & String#titleize

يمكن لعدة طرق تنفيذ تحويلات أكثر تحديدًا لحالة الأحرف.
وقد يكون ذلك مفيدًا عند تحويل سلسلة نصية إلى صيغة معيّنة.
إليك قائمة ببعض الطرق الأكثر شيوعًا:

| الطريقة                          | الوصف                                                                                                               | المثال                                               |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------- |
| [`String#capitalize`][capitalize] | تحوّل الحرف الأول إلى حرف كبير وباقي الأحرف إلى أحرف صغيرة                                                          | `"hEllO" # => "Hello"`                               |
| [`String#camelcase`][camel-case]  | تحوّل الشرطة السفلية إلى صيغة camelcase                                                                            | `"eiffel_tower" # => "EiffelTower"`                  |
| `String#camelcase(lower: true)`   | مثل `String#camelcase` لكنها تُبقي الحرف الأول بحالة صغيرة                                                           | `"empire_state_building" # => "empireStateBuilding"` |
| [`String#underscore`][underscore] | تحوّل جميع الأحرف إلى حالة صغيرة وتضع شرطة سفلية بين حرف صغير وحرف كبير                                            | `"PartyInTheUSA" # => "party_in_the_usa"`            |
| [`String#titleize`][titleize]     | تجعل الحرف الأول من كل كلمة كبيرًا وتحوّل باقي الأحرف إلى أحرف صغيرة                                                | `"the great gatsBY" # => "The Great Gatsby"`         |

## String#sub & String#gsub

توفّر Crystal طرقًا لاستبدال أجزاء من سلسلة نصية.
تُعرف هاتان الطريقتان بـ [`sub`][sub] (_الاستبدال_) و[`gsub`][gsub] (_الاستبدال الشامل_).

يمكن لهذه الطرق أن تأخذ سلسلة نصية أو محرفًا أو تعبيرًا نمطيًا كوسيط أول، وسلسلة نصية أو محرفًا كوسيط ثانٍ.
الوسيط الأول هو الجزء من السلسلة النصية الذي سيُستبدل، والوسيط الثاني هو البديل.
سنشرح `Char` والتعبير النمطي في مفاهيم لاحقة.

تستبدل طريقة `sub` أول ظهور للوسيط الأول بالوسيط الثاني.

```crystal
"hello".sub("l", "r")
# => "herlo"
```

تعمل طريقة `gsub` تمامًا كما تعمل `sub`، لكنها تستبدل جميع حالات ظهور الوسيط الأول بالوسيط الثاني.

```crystal
"hello".gsub("l", "r")
# => "herro"
```

## String#chomp & String#strip

يمكن استخدام `chomp` و`strip` لإزالة الأحرف غير المرغوب فيها من سلسلة نصية.

تُزيل طريقة [`chomp`][chomp] افتراضيًا آخر محرف من المحارف `\r` أو `\n` أو `\r\n` من سلسلة نصية.
وإذا استُدعيت الطريقة بوسيط، فستزيل القيمة المعطاة من نهاية السلسلة النصية،
إن كانت موجودة في نهاية السلسلة.

```crystal
"hello\n".chomp
# => "hello"

"hello".chomp("llo")
# => "he"
```

افتراضيًا، تُزيل طريقة [`strip`][strip] كل المسافات البيضاء من بداية السلسلة النصية ونهايتها.
وإذا استُدعيت الطريقة بوسيط، فستزيل ذلك الوسيط من بداية السلسلة النصية ونهايتها،
إن كان موجودًا في بدايتها أو نهايتها.

```crystal
" hello ".strip
# => "hello"
```

## String#reverse

يمكنك استخدام طريقة [`reverse`][reverse] لعكس سلسلة نصية.
ستُرجع هذه الطريقة سلسلة نصية جديدة بأحرف مرتبة ترتيبًا معاكسًا.

```crystal
"hello".reverse
# => "olleh"
```

## String#index

يمكن استخدام طريقة [`index`][index] للعثور على فهرس محرف داخل سلسلة نصية.
تأخذ طريقة `index` سلسلة نصية أو `Char` أو تعبيرًا نمطيًا كوسيط.
ويمكنها أن تأخذ وسيطًا ثانيًا اختياريًا لتحديد الفهرس الذي يبدأ منه البحث.
وتُرجع طريقة `index` فهرس أول ظهور للوسيط.

```crystal
"hello".index("l")
# => 2

"hello".index("l", 3)
# => 3
```

## String#delete_at

يمكنك استخدام طريقة [`delete_at`][delete_at] لإزالة محرف من سلسلة نصية.
تأخذ طريقة `delete_at` فهرسًا كوسيط وتزيل المحرف عند ذلك الفهرس.

```crystal
"hello".delete_at(0)
# => "ello"

"hello".delete_at(3)
# => "helo"
```

## String#insert

يمكن استخدام طريقة [`insert`][insert] لإدراج سلسلة نصية عند فهرس محدّد.
تأخذ طريقة `insert` فهرسًا كوسيط أول وسلسلة نصية كوسيط ثانٍ.
وتُرجع طريقة `insert` سلسلة نصية جديدة مُدرجًا فيها الوسيط الثاني عند ذلك الفهرس.

```crystal
"hello".insert(0, "h")
# => "hhello"

"hello".insert(3, "l")
# => "helllo"
```
