# نبذة

البنية الأساسية في البرمجة كائنية التوجه في Java هي _الصنف_، وهو مزيج من البيانات ([_الحقول_][fields])، وتُعرف أيضًا بمتغيرات النسخة، والسلوك ([_الطُرق_][methods]). وتُعرف حقول الصنف وطُرقه باسم _أعضائه_.

يمكن التحكم في الوصول إلى الأعضاء عبر محدِّدات الوصول، وأكثرها شيوعًا اثنان:

- [`public`][public]: يمكن لأي كود الوصول إلى العضو (دون قيود).
- [`private`][private]: لا يمكن الوصول إلى العضو إلا من كود داخل الصنف نفسه.

في Java، إذا لم يُحدَّد أي محدِّد وصول، فالوضع الافتراضي هو _الظهور على مستوى الحزمة_. وفي هذه الحالة يكون العضو مرئيًا لجميع الأصناف المعرَّفة داخل الحزمة نفسها.

يُعرف تجميع البيانات والسلوك المرتبطين المذكور أعلاه، مع تقييد الوصول إلى الأعضاء، باسم [_التغليف_][encapsulation]، وهو أحد المفاهيم الأساسية في البرمجة كائنية التوجه.

يمكنك التفكير في الصنف على أنه قالب لإنشاء نسخ منه. ولإنشاء [نسخة من صنف][creating-objects] (وتُعرف أيضًا باسم _الكائن_)، تُستخدم [الكلمة المفتاحية `new`][new]:

```java
class Car {
}

// Create two car instances
Car myCar = new Car();
Car yourCar = new Car();
```

[الحقول][fields] لها نوع واسم (يُكتب الاسم بأسلوب [camelCase][camel-case])، ويمكن تعريفها في أي مكان داخل الصنف (ويُكتب اسم الصنف بأسلوب [PascalCase][pascal-case]).

```java
class Car {
    // Accessible by anyone
    public int weight;

    // Only accessible by code in this class
    private String color;
}
```

يمكنك اختياريًا إسناد قيمة ابتدائية لحقل. وإذا _لم_ يُحدِّد الحقل قيمة ابتدائية، فسيُضبط على [القيمة الافتراضية][default-values] لنوعه. ويمكن الوصول إلى قيم حقول النسخة وتحديثها باستخدام الترميز النقطي.

```java
class Car {
    // Will be set to specified value
    public int weight = 2500;

    // Will be set to default value (0)
    public int year;
}

Car newCar = new Car();
newCar.weight; // => 2500
newCar.year;   // => 0

// Update value of the field
newCar.year = 2018;
```

عادةً ما تُحدَّث حقول `private` كأثر جانبي لاستدعاء طريقة. وهذه الطُرق لا تُرجع عادةً أي قيمة، وفي هذه الحالة ينبغي أن يكون نوع الإرجاع [`void`][void]:

```java
class CarImporter {
    private int carsImported;

    public void importCars(int numberOfCars)
    {
        // Update private field
        carsImported = carsImported + numberOfCars;
    }
}
```

لاحظ أنه ليس من المعتاد استخدام حقول `public` في أصناف Java. فعادةً ما تُستخدم حقول `private` التي يُوصَل إليها عبر [_الدوال القارئة والكاتبة_][so-getters-setters].

داخل الصنف، تشير [الكلمة المفتاحية `this`][this] إلى الصنف الحالي. ويكون هذا مفيدًا بشكل خاص إذا حمل معامل الاسم نفسه الذي يحمله حقل:

```java
class CarImporter {
    private int carsImported;

    public void setImportedCars(int carsImported)
    {
        // Update private field from public method
        this.carsImported = carsImported;
    }
}
```
