# مقدمة

تتيح لك حلقة `for` تكرار تنفيذ الكود حتى يتحقق شرط معيّن.

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

تتكوّن حلقة `for` من أربعة أجزاء:

1. المُهيّئ: يُنفَّذ مرة واحدة قبل الدخول إلى الحلقة. يُستخدَم عادةً لتعريف المتغيرات المستخدَمة داخل الحلقة.
2. الشرط: يُنفَّذ قبل كل دورة من دورات الحلقة. وتستمر الحلقة في التنفيذ ما دام هذا الشرط يعطي القيمة `true`.
3. المُكرِّر: يُنفَّذ بعد كل دورة من دورات الحلقة. ويُستخدَم عادةً لتعديل متغيرات الحلقة (غالبًا بالزيادة أو النقصان).
4. الجسم: الكود الذي يُنفَّذ في كل دورة من دورات الحلقة.
