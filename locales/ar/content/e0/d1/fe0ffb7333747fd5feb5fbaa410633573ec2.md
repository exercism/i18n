# تلميحات

## عام

- تُعدّ وثائق Python حول [أدوات التحكم في التدفق][control flow tools] ودرس Real Python حول [الجمل الشرطية][real python conditionals] من أفضل نقاط البداية.
- يمكن أن تكون وثائق Python حول [العمليات المنطقية][boolean operations] مراجعة ممتازة لـ`bools`، وكذلك درس Real Python حول [القيم المنطقية][python booleans].
- يمكن أن تكون وثائق Python حول [المقارنات][comparisons] و[أمثلة المقارنات][python comparisons examples] مراجعة ممتازة للمقارنات.

## 1. التحقق من الحالة الحرجة

- يمكن دمج عوامل المقارنة ([مراجعة المقارنات][comparisons review]) والعمليات المنطقية ([concept:python/bools]()) واستخدامها مع الجمل الشرطية.
- يجب أن تُقيَّم التعبيرات الشرطية إلى `True` أو `False`.
- يمكن استخدام `else` لكتلة كود تُنفَّذ عندما تُرجع جميع الاختبارات الشرطية القيمة `False`.

  ```python
     >>> item = 'blue'
     >>> item_2 = 'green'
     
     >>>  if len(item) >= 3 and len(item_2) < 5:
            print('Both pass the test!')
          elif len(item) >= 3 or len(item_2) < 5:
            print('One passes the test!')
          else:
            print('None pass the test!')
    ...
    One passes the test!
  ```

## 2. تحديد نطاق خرج القدرة

- يمكن دمج عوامل المقارنة واستخدامها مع الجمل الشرطية.
- يمكن استخدام أي عدد من جمل `elif` كـ"فروع" للقرار.
- يمكن أن يحتوي كل "فرع" على `return` منفصل، وإن اعتبرته أدوات فحص الكود "أسلوبًا سيئًا".
- إذا اشتكت أداة فحص الكود، فكّر في إسناد ناتج الفرع إلى متغير مشترك، ثم إرجاعه باستخدام `return`.

## 3. آلية الأمان عند الفشل

- يمكن دمج عوامل المقارنة واستخدامها مع الجمل الشرطية.
