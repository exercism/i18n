# التعليمات

في هذا التمرين ستتحقق من أذونات حسابات المستخدمين في منتدى على الإنترنت. يدعم المنتدى ثلاثة أذونات مختلفة:

- Read
- Write
- Delete

هناك ثلاثة أنواع من الحسابات، ولكل منها أذونات افتراضية مختلفة:

- الضيوف: يمكنهم قراءة المنشورات.
- المستخدمون: يمكنهم قراءة المنشورات وكتابتها.
- المشرفون: يمكنهم قراءة المنشورات وكتابتها وحذفها، ولديهم جميع الأذونات.

أحيانًا يمكن تعديل الأذونات الفردية؛ فمثلًا، من الممكن منح حساب ضيف إذن كتابة المنشورات أيضًا، كما أن سحب جميع الأذونات من حساب ما يؤدي إلى عدم امتلاكه أيًّا من الأذونات.

## 1. الحصول على الأذونات الافتراضية لنوع حساب

أولًا، عرّف تعداد `AccountType` لتمثيل أنواع الحسابات الثلاثة: `Guest` و`User` و`Moderator`.

بعد ذلك، عرّف تعداد `Permission` لتمثيل أنواع الأذونات الثلاثة: `Read` و`Write` و`Delete`، بالإضافة إلى نوعين إضافيين: `All` لامتلاك جميع الأذونات، و`None` لعدم امتلاك أي إذن.

ثم نفّذ الطريقة (_static_) `Permissions.Default()` لإرجاع الأذونات الافتراضية لنوع حساب معيّن:

```csharp
Permissions.Default(AccountType.Guest)
// => Permission.Read
```

## 2. منح إذن

نفّذ الطريقة (_static_) `Permissions.Grant()` التي تمنح (تضيف) إذنًا:

```csharp
Permissions.Grant(current: Permission.None, grant: Permission.Read)
// => Permission.Read
```

## 3. سحب إذن

نفّذ الطريقة (_static_) `Permissions.Revoke()` التي تسحب (تزيل) إذنًا:

```csharp
Permissions.Revoke(current: Permission.Read, revoke: Permission.Read)
// => Permission.None
```

## 4. التحقق من إذن

نفّذ الطريقة (_static_) `Permissions.Check()` التي تأخذ أذونات الحساب الحالي وتتحقق مما إذا كان الحساب مخوَّلًا بإذن معيّن:

```csharp
Permissions.Check(current: Permission.Write, check: Permission.Read)
// => false
```
