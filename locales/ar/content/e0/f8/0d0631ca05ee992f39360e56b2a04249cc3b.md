# مثال

```riscvasm
.equ FRAME_SIZE, 16

.text
.global is_triple
```

الأسطر التي تبدأ بنقطة هي _توجيهات_: تعليمات للمجمّع، لا للمعالج.
`.equ` يعطي الاسم `FRAME_SIZE` للعدد 16.
`.text` يقول إن ما يلي هو كود.
`.global` يجعل العلامة `is_triple` مرئية خارج هذا الملف، حتى يستطيع كود آخر استدعاءها.
قد ترى أيضًا `.globl`، وهو يعني الشيء نفسه.

```riscvasm
/* bool is_triple(unsigned a, unsigned b, unsigned c); */
is_triple:
```

تتحقق `is_triple` مما إذا كان `a² + b² = c²`، وتُرجع 1 إذا كان كذلك، و0 خلاف ذلك.
على سبيل المثال، `(6, 8, 10)` يعطي 1، لأن `36 + 64 = 100`.
العلامة `is_triple` تحدد حيث تبدأ الدالة.
تُستدعى مع `a` و `b` و `c` في السجلات `a0` و `a1` و `a2`.

```riscvasm
        addi    sp, sp, -FRAME_SIZE
        sw      ra, 12(sp)      /* save the return address */
        sw      a1, 8(sp)       /* save b */
        sw      a2, 4(sp)       /* save c */
```

السجل `ra` يحمل _عنوان العودة_، المكان الذي نعود إليه في المستدعي عندما ننتهي.
كل `call` يكتب فوق `ra`، لذا نحفظه أولًا على _المكدس_.
ينمو المكدس نحو الأسفل، نحو عناوين أصغر، لذا فإن طرح 16 من مؤشر المكدس `sp` يحجز لنا 16 بايت.
(`sp` يجب أن يكون دائمًا من مضاعفات 16.)
نحفظ أيضًا `b` و `c`، لأن الدالة التي نستدعيها مسموح لها بتغيير سجلات `a`.

```riscvasm
        call    square          /* a0 = a * a */
        sw      a0, 0(sp)       /* save a * a */
```

`a` موجود بالفعل في `a0`، حيث تتوقع `square` مدخلها.
يضبط `call` قيمة `ra` إلى التعليمة التالية، ثم يقفز إلى `square`، التي تُرجع نتيجتها في `a0`.

```riscvasm
        lw      a0, 8(sp)       /* a0 = b */
        call    square          /* a0 = b * b */
        lw      t0, 0(sp)       /* t0 = a * a */
        add     t0, t0, a0      /* t0 = a * a + b * b */
        sw      t0, 0(sp)       /* save a * a + b * b */
```

نُحمّل `b` مرة أخرى من المكدس، ونربّعه، ثم نضيفه إلى `a * a`.

```riscvasm
        lw      a0, 4(sp)       /* a0 = c */
        call    square          /* a0 = c * c */
        lw      t0, 0(sp)       /* t0 = a * a + b * b */
        sub     a0, t0, a0      /* a0 = a * a + b * b - c * c */
        seqz    a0, a0          /* a0 = 1 if that is zero, otherwise 0 */
```

يكون الفرق صفرًا بالضبط عندما يكون `a² + b² = c²`.
`seqz` ("يضبط إذا كان يساوي صفرًا") يحوّل ذلك إلى 1 أو 0.

```riscvasm
        lw      ra, 12(sp)      /* restore the return address */
        addi    sp, sp, FRAME_SIZE
        ret
```

نستعيد `ra` ونعيد الـ 16 بايت من المكدس.
ثم يقفز `ret` إلى العنوان الموجود في `ra`، عائدًا إلى المستدعي.

```riscvasm
/* unsigned square(unsigned n); */
square:
        mul     a0, a0, a0      /* n * n */
        ret
```

لا تستدعي `square` أي دالة أخرى، لذا يبقى `ra` سليمًا ولا يوجد شيء لحفظه.
لم تُعلَّم بـ `.global`، لأن `is_triple` وحدها تستخدمها.
