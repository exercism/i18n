# مقدمة

في Java، تُستخدم القيمة الحرفية `null` للدلالة على غياب القيمة.

جميع أنواع البيانات الأولية في Java لها قيمة افتراضية، ولذلك لا يمكن أن تكون `null` أبدًا. وكما هو متعارف عليه، تبدأ بحرف صغير، مثل `int`.

تحتوي الأنواع المرجعية على عنوان الذاكرة لكائن ما، ويمكن أن تكون قيمتها `null`. وعادةً ما تبدأ بحرف كبير، مثل `String`.

إن محاولة إسناد قيمة `null` إلى متغير أولي ستؤدي إلى خطأ في وقت الترجمة، لأن المتغير يحمل دائمًا قيمة أولية من النوع المُسنَد إليه.

```java
//Throws compile time error stating the required type is int, but null was provided
int number = null;
```

لن يؤدي إسناد قيمة `null` إلى متغير مرجعي إلى خطأ في وقت الترجمة، لأن المتغيرات المرجعية تقبل أن تكون `null`.

```java
//No error will occur as the String variable str is nullable
String str = null;
```
