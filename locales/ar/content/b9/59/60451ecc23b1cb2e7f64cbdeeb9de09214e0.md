# مقدمة

## المدد والفترات

تصف أصناف مثل `LocalDate` و`LocalDateTime` _نقطة_ في الزمن.
وتحتوي حزمة `java.time` أيضًا على صنفين يصفان _مقدارًا_ من الزمن:

- `java.time.Period` هو مقدار من الزمن بالسنوات والأشهر والأيام، مثل «شهرين و5 أيام».
- `java.time.Duration` هو مقدار من الزمن بالساعات والدقائق والثواني والملي ثانية والنانو ثانية، مثل «ساعة و30 دقيقة».

يتبع `Period` التقويم، لذا يُستخدم مع التواريخ ومع قيم التاريخ والوقت.
أما `Duration` فيقيس الزمن الدقيق، لذا يُستخدم مع الأوقات ومع قيم التاريخ والوقت، وليس مع التواريخ.

~~~~exercism/note
مثل بقية أصناف `java.time`، فإن `Period` و`Duration` غير قابلة للتغيير.
والطرق التي تبدو وكأنها تغيّرها تُرجع نسخة _جديدة_ بدلًا من ذلك.
~~~~

### `Period`

يُنشأ `Period` بإحدى طرقه الثابتة لإنشاء الكائنات:

```java
Period.ofDays(10);
// => P10D

Period.ofMonths(3);
// => P3M

Period.of(1, 2, 15);
// => P1Y2M15D
```

يستخدم ناتج `toString()` ترميز [ISO-8601][iso-8601-durations]: الحرف `P` (اختصارًا لكلمة period) يليه عدد السنوات (`Y`) والأشهر (`M`) والأيام (`D`).

ويمكن جمع فترة إلى تاريخ أو طرحها منه:

```java
LocalDate date = LocalDate.of(2024, 3, 10);

date.plus(Period.ofMonths(2));
// => 2024-05-10

date.minus(Period.ofDays(10));
// => 2024-02-29
```

ولأن الأشهر تختلف في طولها، فقد تؤدي إضافة أشهر إلى الانتهاء عند يوم غير موجود.
في هذه الحالة يُنقل الناتج إلى آخر يوم صالح في الشهر:

```java
LocalDate.of(2025, 1, 31).plus(Period.ofMonths(1));
// => 2025-02-28
```

تُرجع `Period.between()` الفترة من تاريخ (شاملًا) إلى تاريخ آخر (غير شامل):

```java
LocalDate start = LocalDate.of(2023, 3, 10);
LocalDate end = LocalDate.of(2024, 5, 25);

Period period = Period.between(start, end);
// => P1Y2M15D

period.getYears();
// => 1
period.getMonths();
// => 2
period.getDays();
// => 15
```

### حساب الوحدات باستخدام `ChronoUnit`

يحتفظ `Period` بسنواته وأشهره وأيامه منفصلة.
لذا تُرجع `getDays()` الجزء الخاص بالأيام فقط من الفترة، وليس العدد الإجمالي للأيام.
ولحساب العدد الإجمالي لوحدة واحدة بين تاريخين، استخدم طريقة `between()` في [`java.time.temporal.ChronoUnit`][chronounit-docs]:

```java
LocalDate start = LocalDate.of(2024, 1, 15);
LocalDate end = LocalDate.of(2024, 3, 20);

Period.between(start, end);
// => P2M5D

Period.between(start, end).getDays();
// => 5

ChronoUnit.DAYS.between(start, end);
// => 65
```

ويكون الناتج سالبًا عندما يسبق التاريخ الثاني التاريخ الأول:

```java
ChronoUnit.DAYS.between(end, start);
// => -65
```

### `Duration`

يُنشأ `Duration` أيضًا بطرق ثابتة لإنشاء الكائنات:

```java
Duration.ofMinutes(90);
// => PT1H30M

Duration.ofHours(2).plusMinutes(15);
// => PT2H15M
```

في ترميز ISO-8601 يفصل الحرف `T` بين جزء التاريخ وجزء الوقت، ولهذا تُكتب المدد بالصيغة `PT...`.

ويمكن جمع مدة إلى قيمة تاريخ ووقت أو طرحها منها:

```java
LocalDateTime start = LocalDateTime.of(2024, 3, 10, 22, 30);

start.plus(Duration.ofMinutes(90));
// => 2024-03-11T00:00
```

تُرجع `Duration.between()` مقدار الزمن الدقيق بين قيمتَي تاريخ ووقت:

```java
LocalDateTime checkIn = LocalDateTime.of(2024, 3, 10, 18, 5);
LocalDateTime checkOut = LocalDateTime.of(2024, 3, 10, 19, 40);

Duration.between(checkIn, checkOut);
// => PT1H35M
```

ويمكن تحويل مدة إلى وحدة واحدة بطرق مثل `toHours()` و`toMinutes()` و`toSeconds()`.
تُرجع هذه الطرق المقدار _الإجمالي_ في تلك الوحدة، مقرّبًا للأسفل:

```java
Duration duration = Duration.ofMinutes(95);

duration.toHours();
// => 1
duration.toMinutes();
// => 95
```

ولتقسيم مدة إلى أجزائها كما في الساعة، استخدم طرق `toXxxPart()` بدلًا من ذلك:

```java
Duration duration = Duration.ofMinutes(95);

duration.toHoursPart();
// => 1
duration.toMinutesPart();
// => 35
```
