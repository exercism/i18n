## عام

لا تُنفّذ البنية `SimpleLinkedList` كغلاف حول `Vec`. بدلًا من ذلك، خصّص العُقد على الكومة.

يمكن تنفيذ ذلك على النحو التالي:

```
pub struct SimpleLinkedList<T> {
    head: Option<Box<Node<T>>>,
}
```

يشير الحقل `head` إلى أول عنصر (Node) في هذه القائمة المترابطة.

يتطلب هذا التنفيذ أيضًا بنية `Node` تحتوي على الحقول التالية:

```
struct Node<T> {
    data: T,
    next: Option<Box<Node<T>>>,
}
```

يحتوي `data` على البيانات المخزّنة، ويشير `next` إلى العقدة التالية (إن وُجدت) أو إلى None.

## لماذا `Option<Box<Node<T>>>` وليس `Option<Node<T>>` فقط؟

جرّب ذلك بنفسك. ستحصل على الخطأ التالي.

```
| struct Node<T>
| ^^^^^^^^^^^^^^ recursive type has infinite size
...
|     next: Option<Node<T>>,
|     --------------------- recursive without indirection
```

المشكلة أن حجم `next` يجب أن يكون معروفًا في وقت الترجمة.
ولأن `next` عودي («عقدة تحتوي على عقدة تحتوي على عقدة...»)، لا يعرف المصرّف مقدار الذاكرة التي يجب تخصيصها.
في المقابل، فإن [Box](https://doc.rust-lang.org/std/boxed/) مؤشر على الكومة بحجم محدّد.
