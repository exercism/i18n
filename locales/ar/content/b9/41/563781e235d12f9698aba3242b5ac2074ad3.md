# الاختبارات

## تشغيل الاختبارات

عندما تكون داخل مجلد التمرين، سترى مجلدين فرعيين:

* يحتوي `src` على حلك للتمرين
* يحتوي `spec` على الاختبارات التي ستُشغَّل للتمرين

إذا كنت في المجلد الصحيح (أي المجلد الذي يحتوي على `src` و`spec`)، يمكنك تشغيل اختبارات هذا التمرين بتنفيذ `crystal spec`:

```bash
$ pwd
/Users/johndoe/Code/exercism/crystal/hello-world

$ ls
GETTING_STARTED.md README.md          spec               src

$ crystal spec
```

سيشغّل هذا جميع ملفات الاختبار في مجلد `spec`.

في كل ملف اختبار، جرى تخطّي جميع الاختبارات باستثناء الأول.

بمجرد أن ينجح أحد الاختبارات، يمكنك إلغاء تخطّي الاختبار التالي بتغيير `pending` إلى `it`.

## تنسيق Crystal

قبل الإرسال، يُنصح بتشغيل `crystal tool format` على حلك.

يمكنك تنسيق كل شيء في مجلدك الحالي عبر:

```bash
$ crystal tool format ./
```

أو يمكنك تنسيق ملفات محددة عبر:

```bash
$ crystal tool format ./<path>/<to>/<file>
```

## إرسال حلك

تأكد من إرسال الملف المصدري في مجلد `src` عند إرسال حلك:

```bash
$ exercism submit src/<exercise>.cr
```
