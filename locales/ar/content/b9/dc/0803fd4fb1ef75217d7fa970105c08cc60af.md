# نبذة

تمثّل القيمة المنطقية ما إذا كان شرط ما `true` أو `false`.
وفي Go، لا يمكن لنوع `bool` أن يكون إلا إحدى هاتين القيمتين.

```go
isDoorLocked := true
hasKey := true
knowsCode := false
```

## العوامل المنطقية

تعمل العوامل المنطقية على قيمة منطقية واحدة أو قيمتين وتُنتج نتيجة منطقية.

| العامل | الاسم | السلوك                                          |
| -------- | ---- | ---------------------------------------------- |
| `!`      | NOT  | يُرجع عكس قيمة منطقية واحدة                    |
| `&&`     | AND  | يُرجع `true` فقط عندما يكون الجانبان `true`     |
| `\|\|`   | OR   | يُرجع `true` إذا كان أي من الجانبين `true`      |

استخدم `!` (NOT) عندما تحتاج إلى عكس قيمة منطقية:

```go
!isDoorLocked // false
```

استخدم `&&` (AND) عندما يجب أن يكون كلا الشرطين `true`:

```go
canUnlockDoor := isDoorLocked && hasKey // true
```

استخدم `||` (OR) عندما يجب أن يكون شرط واحد على الأقل `true`:

```go
canOpenDoor := canUnlockDoor || knowsCode // true
```

تُقيَّم العوامل المنطقية بهذا الترتيب: أولًا `!`، ثم `&&`، ثم `||`.
استخدم الأقواس الهلالية لتجميع الكود والتحكم في العمليات التي تُنفَّذ أولًا:

```go
!true && false   // false because !true is evaluated first
!(true && false) // true because true && false is evaluated first
```
