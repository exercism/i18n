# الاختبارات

## الإعداد

اتّبع [تعليمات الإعداد الخاصة بـ WebAssembly][docs-exercism-wasm] لتثبيت التبعيات اللازمة.

## المتطلبات

ثبّت تبعيات التمرين:

```shell
# Using npm
npm install

# Alternatively using yarn
yarn
```

## اجتياز مجموعة الاختبارات

تأتي جميع التمارين مع مجموعة اختبارات تساعدك على التحقق من حلّك قبل إرساله.
يمكنك تشغيل هذه الاختبارات بفتح سطر أوامر في مجلد التمرين، ثم تشغيل:

```bash
# Using npm
npm test

# Alternatively using yarn
yarn test
```

في بعض مجموعات الاختبارات تكون جميع الاختبارات عدا الأول متخطّاة.

بعد أن ينجح أحد الاختبارات، يمكنك تمكين الاختبار التالي بتغيير `xtest` إلى `test`.

## كتابة اختبارات مخصّصة

إذا أردت كتابة اختبارات إضافية مخصّصة، فأنشئ ملفًا جديدًا باسم `custom.spec.js`، وأرسله مع حلّك إلى جانب الملف الجديد:

```shell
exercism submit numbers.wat custom.spec.js
```
