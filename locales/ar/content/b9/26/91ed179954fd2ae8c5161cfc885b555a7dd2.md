# مقدمة

تتيح لك التعليقات ترك ملاحظات في الكود دون التأثير على طريقة تشغيله.
تبدأ التعليقات أحادية السطر بـ `//`، أما التعليقات متعددة الأسطر فتُحاط بـ `/*` و `*/`:

```go
// This is a single-line comment.

/*
This is a
multiline comment.
*/
```

تخدم التعليقات أغراضًا مختلفة حسب موضع ظهورها.

## تعليقات الكود

تشرح تعليقات الكود سبب القيام بشيء ما، لا ما الذي يُفعَل.
استخدمها عندما لا يكون السبب وراء قرار ما واضحًا من الكود:

```go
results = results[1:] // skipping the header row
```

## تعليقات التوثيق

تقع تعليقات التوثيق مباشرة قبل التعريف، دون سطر فارغ يفصل التعليق عن التعريف.
يُحلّلها [`godoc`][godoc] لتوليد توثيق الحزمة.
ينبغي أن يكون تعليق التوثيق جملة كاملة تبدأ باسم المُعرّف وتنتهي بنقطة.

تبدأ تعليقات الحزمة باسم الحزمة:

```go
// Package kelvin provides tools to convert temperatures to and from Kelvin.
package kelvin
```

تبدأ تعليقات الدالة باسم الدالة:

```go
// CelsiusFreezingTemp returns an integer value equal to the temperature at which water freezes in degrees Celsius.
func CelsiusFreezingTemp() int {
	return 0
}
```

[godoc]: https://go.dev/blog/godoc
