# السلاسل النصية

يحمل `STR` نصًا. وتُكتب السلسلة النصية بين علامتي تنصيص مزدوجتين.

```sather
   composer : STR is
      return "Sibelius";
   end;
```

لا يتغير `STR` أبدًا بمجرد أن يوجد. وكل ما يلي يجيب بسلسلة نصية *جديدة* بدلًا من تعديل السلسلة النصية التي سُئل عنها.

## الدمج

```sather
"Jean" + " " + "Sibelius"      -- "Jean Sibelius"
```

يدمج `+` أيضًا عددًا في سلسلة نصية، وهكذا يدخل العدد في جملة:

```sather
"Opus " + 27           -- "Opus 27"
```

## الطول

```sather
"Sibelius".size        -- 8
"".size                -- 0
```

يعدّ `.size` الأحرف، والجواب من النوع `INT`.

## الأجزاء

| الاستدعاء | الجواب |
| --- | --- |
| `"Sibelius".head(3)` | `"Sib"` |
| `"Sibelius".tail(4)` | `"lius"` |

طلب أكثر مما هو موجود يُرجع ما هو موجود بدلًا من أن يفشل.

## المقارنة

يسأل `=` عمّا إذا كانت السلسلتان النصيتان النص نفسه، ويسأل `/=` عمّا إذا كانتا مختلفتين.

```sather
"forte" = "forte"      -- true
"forte" = "Forte"      -- false
```

حالة الأحرف مهمة. و`.upper` و`.lower` تُرجعان نسخة بحالة واحدة، وهي الطريقة المعتادة للمقارنة دون الاهتمام بحالة الأحرف:

```sather
"Forte".lower                    -- "forte"
"Forte".lower = "forte".lower    -- true
```

## كلمة عن الحجم

`STR` صفّ من البايتات، و`.size` يعدّ البايتات. بالنسبة للنص الإنجليزي، هذا مماثل لعَدّ الأحرف. أما بالنسبة للنص الذي يحتوي على علامات تشكيل أو أبجديات أخرى، فالأمر ليس كذلك، لأن كل حرف من تلك الحروف يشغل أكثر من بايت واحد.
