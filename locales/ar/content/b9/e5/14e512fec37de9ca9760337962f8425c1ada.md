لكن الأمور غير منظمة بعض الشيء: يبدو أن إحداثيات آزارا منسّقة ومرتبة بشكل مختلف عن إحداثيات روي، وعليهما مواصلة التنقل بين القائمتين لمعرفة أي الكنوز تنتمي إلى أي المواقع.
وبما أنهما من محبي Python الناشئين، فقد لجآ إليك طلبًا للمساعدة في كتابة برنامج صغير (مجموعة دوال في الحقيقة) لتنظيم معلومات رحلة البحث بشكل أفضل.


## 1. استخراج الإحداثيات

نفّذ الدالة `get_coordinate()` التي تأخذ زوجًا `(treasure, coordinate)` من قائمة آزارا وتُرجع إحداثي الخريطة المستخرج فقط.


```python
>>> get_coordinate(('Scrimshawed Whale Tooth', '2A'))
2A
```

## 2. تنسيق الإحداثيات

نفّذ الدالة `convert_coordinate()` التي تأخذ إحداثيًا بالصيغة "2A" وتُرجع صفًا بالصيغة `("2", "A")`.


```python
>>> convert_coordinate("2A")
("2", "A")
```

## 3. مطابقة الإحداثيات

نفّذ الدالة `compare_records()` التي تأخذ زوجًا `(treasure, coordinate)` وسجلًا `(location, coordinate, quadrant)` وتقارن الإحداثيات في كل منهما.
أعِد **`True`** إذا تطابقت الإحداثيات، وأعِد **`False`** إذا لم تتطابق.
أعِد تنسيق الإحداثيات حسب الحاجة لإجراء مقارنة دقيقة.


```python
>>> compare_records(('Brass Spyglass', '4B'), ('Seaside Cottages', ('1', 'C'), 'blue'))
False

>>> compare_records(('Model Ship in Large Bottle', '8A'), ('Harbor Managers Office', ('8', 'A'), 'purple'))
True
```

## 4. دمج السجلات المتطابقة

نفّذ الدالة `create_record()` التي تأخذ زوجًا `(treasure, coordinate)` من قائمة آزارا وسجلًا `(location, coordinate, quadrant)` من قائمة روي وتُرجع `(treasure, coordinate, location, coordinate, quadrant)` **إذا تطابقت الإحداثيات**.
إذا _لم_ تتطابق الإحداثيات، فأعِد السلسلة النصية **"not a match"**.
أعِد تنسيق الإحداثي حسب الحاجة لإجراء مقارنة دقيقة.


```python
>>> create_record(('Brass Spyglass', '4B'), ('Abandoned Lighthouse', ('4', 'B'), 'Blue'))
('Brass Spyglass', '4B', 'Abandoned Lighthouse', ('4', 'B'), 'Blue')

>>> create_record(('Brass Spyglass', '4B'), ('Seaside Cottages', ('1', 'C'), 'blue'))
"not a match"
```
