# طرق المصفوفات

المصفوفات بنية بيانات شائعة للعمل بها.
ولذلك توجد مجموعة من الطرق يمكن استخدامها للتعامل مع المصفوفات،
تشمل الترتيب والعكس والإدراج وغير ذلك الكثير.

بعض هذه الطرق مدمِّرة، أي أنها تعدّل المصفوفة الأصلية.
وبعضها الآخر غير مدمِّر، أي أنها تُرجع مصفوفة جديدة ولا تعدّل المصفوفة الأصلية.

إليك بعض الطرق الأكثر شيوعًا التي يمكن استخدامها عند التعامل مع المصفوفات:

## insert

عند إدراج عنصر في مصفوفة، يمكنك استخدام الطريقة [`insert`][insert]، التي تأخذ فهرسًا وعنصرًا كوسائط.
سيُدرَج العنصر عند الفهرس المحدد، وستُزاح بقية المصفوفة إلى اليمين.
إذا كان الفهرس خارج الحدود، فسيُرفع `IndexError`.

```crystal
numbers = [1, 2, 3]
numbers.insert(1, 4)
numbers # => [1, 4, 2, 3]

numbers.insert(5, 5) # => Error: Index out of bounds (IndexError)
```

## delete

عندما تريد حذف عنصر معيّن من مصفوفة، يمكنك استخدام الطريقة [`delete`][delete]، التي تأخذ عنصرًا كوسيط.
تُرجع الطريقة العنصر الذي حُذف.
إذا لم يكن العنصر موجودًا في المصفوفة، فسيُرجع `nil`.

```crystal
numbers = [1, 2, 3]
numbers.delete(2) # => 2
numbers           # => [1, 3]
```

## first & last

عندما تريد الحصول على العنصر الأول أو الأخير في مصفوفة، يمكنك استخدام الطريقتين [`first`][first] و[`last`][last].
تأخذ هاتان الطريقتان وسيطًا اختياريًا يحدد عدد العناصر التي ستُرجَع.
يمكن أن يحسّن هذا من سهولة القراءة مقارنةً باستخدام الفهرس `0` أو `-1` أو باستخدام نطاق.
إذا كانت المصفوفة فارغة، فسيُرفع `Enumerable::EmptyError`.

```crystal
numbers = [1, 2, 3]
numbers.first # => 1
numbers.last  # => 3

numbers.first(2) # => [1, 2]
numbers.last(2)  # => [2, 3]

empty_array = [] of Int32
empty_array.last # => Error: Empty enumerable (Enumerable::EmptyError)
```

## reverse

عندما تريد عكس مصفوفة، يمكنك استخدام الطريقة [`reverse`][reverse]، التي تُرجع مصفوفة جديدة بعناصر بترتيب معكوس.
من المهم ملاحظة أن `reverse` تُرجع مصفوفة جديدة ولا تعدّل المصفوفة الأصلية.
إذا أردت تعديل المصفوفة الأصلية، فأضف `!` إلى نهاية اسم الطريقة.

```crystal
numbers = [1, 2, 3]
numbers.reverse # => [3, 2, 1]
numbers         # => [1, 2, 3]

numbers.reverse! # => [3, 2, 1]
numbers          # => [3, 2, 1]
```

## Concat(`+`)

تفيد طريقة الإلحاق (`<<`) عندما تريد إضافة كائنات إلى مصفوفة.
ومع ذلك، عند دمج مصفوفتين، يمكنك استخدام العامل [`+`][concat]، الذي يُرجع مصفوفة جديدة بعناصر المصفوفتين.

```crystal
[1, 2] + [3, 4] # => [1, 2, 3, 4]
```

إذا ألحقت مصفوفة بمصفوفة أخرى، فستُضاف المصفوفة كعنصر واحد.

```crystal
[1, 2] << [3, 4] # => [1, 2, [3, 4]]
```

## empty?

عند التحقق مما إذا كانت المصفوفة فارغة، يمكنك استخدام الطريقة [`empty?`][empty?]، التي تُرجع `true` إذا كانت المصفوفة فارغة و`false` بخلاف ذلك.
يحسّن هذا من سهولة القراءة مقارنةً بمقارنة طول المصفوفة بـ `0`.

```crystal
[].empty? # => true
[1, 2, 3].empty? # => false
```

## index

عندما تريد الحصول على فهرس عنصر في مصفوفة، يمكنك استخدام الطريقة [`index`][index]، التي تأخذ عنصرًا كوسيط.
إذا لم يكن العنصر موجودًا في المصفوفة، فسيُرجع `nil`.

```crystal
numbers = [1, 2, 3]
numbers.index(2) # => 1
```

## size

عندما تريد معرفة عدد العناصر في مصفوفة، يمكنك استخدام الطريقة [`size`][size].

```crystal
numbers = [1, 2, 3]
numbers.size # => 3
```

## count

عندما تريد حساب عدد المرات التي يوجد فيها عنصر في مصفوفة، يمكنك استخدام الطريقة [`count`][count].

```crystal
fruits = ["apple", "banana", "apple"]
fruits.count("apple")      # => 2
fruits.count("banana")     # => 1
fruits.count("watermelon") # => 0
```

## sort

عندما تريد ترتيب مصفوفة، يمكنك استخدام الطريقة [`sort`][sort]، التي تُرجع مصفوفة جديدة بعناصر مرتّبة.
وكما في `reverse`، تُرجع هذه الطريقة مصفوفة جديدة ولا تعدّل المصفوفة الأصلية.

```crystal
numbers = [3, 2, 1]
numbers.sort # => [1, 2, 3]
numbers      # => [3, 2, 1]

numbers.sort! # => [1, 2, 3]
numbers       # => [1, 2, 3]
```
