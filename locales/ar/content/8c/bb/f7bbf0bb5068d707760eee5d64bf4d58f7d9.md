# التثبيت

## ثبّت بيئة تشغيل R
زُر [الصفحة الرئيسية لـ CRAN](https://cran.r-project.org/). ستجد هناك روابط التنزيل لأنظمة Linux وMac OSX وWindows. نزّل برنامج التثبيت الخاص بنظام التشغيل لديك وشغّله.

## ثبّت بيئة التطوير RStudio (مُوصى به)
RStudio هي بيئة تطوير متكاملة (IDE) شائعة ومتعددة المنصات للبرمجة بلغة R (وتدعم أيضًا لغات أخرى مثل Python وJavaScript وMarkdown). سيجعل استخدام RStudio كتابة حلولك البرمجية وتشغيل الاختبارات أسهل.

نزّل [الإصدار المستقر الحالي من RStudio](https://www.rstudio.com/products/rstudio/download/) وثبّته. أو احصل بدلًا من ذلك على [إصدار المعاينة](https://www.rstudio.com/products/rstudio/download/preview/) لإصدار قادم.

## ثبّت إضافة R لـ Visual Studio Code (بديل)
تدعم إضافة R لـ Visual Studio Code إبراز الصياغة الموسّع، وإكمال الكود، وفحص الكود، والتنسيق، والتفاعل مع أطراف R، وعرض البيانات والرسوم البيانية ومتغيرات مساحة العمل وصفحات المساعدة، وإدارة الحزم، والعمل مع مستندات R Markdown.

نزّل [الإصدار الحالي من إضافة R](https://code.visualstudio.com/docs/languages/r) وثبّته

## ثبّت حزم R لتشغيل الاختبارات
مشغّل اختبارات المواصفات هو مكتبة [`testthat`](https://github.com/hadley/testthat) من Hadley Wickham، وهي خيار شائع لمؤلفي حزم R.

لتثبيت هذه المكتبة، اكتب ما يلي في وحدة تحكم RStudio (أو في أي مكان آخر تستخدم فيه R).

```{R}
install.packages("testthat")
```

ولئن كان من غير المرجّح أن _تحتاج_ إلى تثبيت حزم لحل مسائل Exercism، فقد ترغب في إضافة حزمة أدوات عامة مثل [`tidyverse`](https://github.com/tidyverse/tidyverse) تناسب أسلوبك في البرمجة. لتثبيت حزمة مثل `tidyverse` وتحميلها:

```{R}
install.packages("tidyverse")
library(tidyverse)
```
