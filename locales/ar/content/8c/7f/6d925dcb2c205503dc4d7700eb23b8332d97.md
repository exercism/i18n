# مقدمة

تُشغّل `call` (في [`kernel`][kernel]) اقتباسًا. وعندما يتعذّر استنتاج أثر مكدس الاقتباس (عادةً لأن الاقتباس جاء من مكان آخر) صرّح بالأثر على `call` صراحةً:

```
call( stack-effect ) ! e.g. call( a b -- c )
```

```factor
3 4 [ + ] call .                 ! => 7
3 4 [ + ] call( a b -- c ) .     ! => 7

: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .         ! => 2
```

ولأن الاقتباسات قيم، يمكن للمصفوفة أن تحمل مزيجًا من الأعداد والاقتباسات، مما يجعل «البرنامج» مجرد تسلسل آخر:

```factor
{ [ 1 + ] [ 2 * ] } 5 swap [ call( x -- y ) ] each .   ! 5 -> 6 -> 12
```

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
