### تصدير الدوال

تناولنا تصدير الدوال في المفهوم الأول، وهذه مراجعة سريعة.

كل ملف في Elm هو وحدة، ويجب أن يحتوي على عبارة `module` قبل أي كود آخر.

يجب أن تطابق أسماء الوحدات أسماء ملفاتها، فوحدة `Calculator` يجب أن تكون في الملف Calculator.elm، ووحدة `Parser.Utils` يجب أن تكون في الملف Parser/Utils.elm.

أي شيء يُعرَّف داخل وحدة يكون نطاقه خاصًّا بها ولا يمكن الوصول إليه من خارجها، إلا إذا كان مُدرجًا في `exposing`.

```elm
-- Calculator.elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Calculator.elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

### استيراد الدوال من وحدات أخرى

يتم الوصول إلى الدوال المعرَّفة في وحدات أخرى عبر الاستيرادات.
عند استيراد وحدة ما، تصبح كل الدوال التي أتاحتها تلك الوحدة متاحة للوصول.
لكن طريقة الوصول إليها تختلف حسب طريقة استيراد الوحدة.

الاستيراد المؤهَّل هو الوضع الافتراضي، ويتم الوصول إلى دالة داخل وحدة كهذه (مثل دالة `map` في وحدة `List`) بوضع اسم الوحدة قبلها (`List.map`).

أما الاستيراد المفتوح فيتيح الوصول المباشر إلى الدوال المتاحة داخل تلك الوحدة، دون إضافة بادئة. ويتم ذلك بالكلمة المفتاحية `exposing`، تمامًا كما في التصدير. يمكنك إتاحة جميع الدوال (باستخدام `..`)، أو إتاحة دوال بعينها (مثل `map`).

يمكنك أيضًا استيراد الأنواع ومُنشِئاتها من وحدات أخرى، وهو ما سنتناوله في مفهوم لاحق.

ويُفضَّل الاستيراد المؤهَّل لما يوفره من وضوح ولتجنّب تعارض الأسماء.

```elm
-- qualified imports
import List                            -- List.map, List.foldl
import List as L                       -- L.map, L.foldl

-- open imports
import List exposing (..)              -- map, foldl, concat, ...
import List exposing ( map, foldl )    -- map, foldl, List.concat
```

https://elm-lang.org/docs/syntax#modules

### توصيفات النوع

تُعرَّف توصيفات النوع بالصيغة `name : parameter types -> return type`، مع فصل أنواع المعاملات أيضًا بـ `->`.

```elm
add : Int -> Int -> Int
add number1 number2 = number1 + number2
```

يمكن استخدام الأقواس الهلالية لتعريف معاملات الدالة (وهي نفسها تُعرَّف بالصيغة ذاتها، ومن هنا تأتي الحاجة إلى الأقواس).

```elm
-- Transform every character in a string
map : (Char -> Char) -> String -> String
map charMapperFunction string =
    -- ...
```

https://elm-lang.org/docs/syntax#type-annotations

### الأعداد

يتوفر في Elm نوعان من الأعداد، يُعرَّفان بالنوعين `Int` و `Float`.
يقابل `Int` مجموعة الأعداد الصحيحة الموجبة والسالبة.
ويقابل `Float` مجموعة الأعداد الحقيقية، محدودةً بدقة الحاسوب.
العمليات المعرَّفة على الأعداد تعمل عادةً على أحد النوعين، دون خلط بينهما.
وتوجد دوال للتحويل بين النوعين، مثل `toFloat` الذي يحوّل `Int` إلى `Float`، و`round` و`floor` و`ceiling` و`truncate` التي تحوّل `Float` إلى `Int` بدلالات مختلفة.

https://package.elm-lang.org/packages/elm/core/latest/Basics#Int

### عمليات السلاسل النصية

لوصف الكلمات والجمل في الكود، يمتلك Elm نوعًا أصليًّا هو `String`.
تُكتب السلاسل النصية الحرفية بين علامتي اقتباس مزدوجتين، مثل `"Hello World!"`.
ويتوفر افتراضيًّا عامل دمج السلاسل النصية `++` وعامل التساوي `==`.

```elm
hello : String -> String
hello subject = "Hello " ++ subject

hello "World!" --> "Hello World!"
```

معظم دوال السلاسل النصية الأخرى موجودة في وحدة `String`، التي تحتاج إلى استيراد.

https://package.elm-lang.org/packages/elm/core/latest/String
