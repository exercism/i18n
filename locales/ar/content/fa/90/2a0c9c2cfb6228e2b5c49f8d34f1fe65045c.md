# مقدمة

السجل هو مجموعة من الحقول (قد تكون من أنواع مختلفة) يرتبط بعضها ببعض. لتعريف سجل نستخدم الكلمة المفتاحية `type`. تُعرَّف حقول السجل بين المحرفين `{` و `}`، ولكل حقل اسم _و_ نوع. ولإنشاء سجل، حدّد أسماء الحقول وأسند إليها قيمًا بين المحرفين `{` و `}`. ويجب إسناد قيمة إلى كل الحقول عند إنشاء سجل. ويمكن الوصول إلى قيم حقول نسخة السجل باستخدام تدوين النقطة.

عند تعريف سجل أو إنشائه، يجب أن يكون كل حقل في سطر منفصل، أو أن تفصل بينها بفواصل منقوطة (`;`) إذا جاءت في سطر واحد.

```fsharp
// Define a record
type Address =
    { Street: string
      HouseNumber: int }

// Create a record
let oldAddress: Address =
    { Street = "Main Street"
      HouseNumber = 17 }

// Single-line alternative
type ConciseAddress = { Street: string; HouseNumber: int }
let conciseAddress: ConciseAddress = { Street = "Main Street"; HouseNumber = 17 }
```

بما أن السجلات غير قابلة للتغيير، فبعد إنشاء السجل لا يمكن أبدًا تغيير قيم حقوله. وإذا أردت تغيير قيم سجل، تتيح لك الكلمة المفتاحية `with` إنشاء نسخة من سجل موجود، لكن بقيم جديدة لحقل واحد أو أكثر.

```fsharp
// Copy the old address but change the house number
let newAddress: Address = { oldAddress with HouseNumber = 86 }
newAddress.Street      // => "Main Street"
newAddress.HouseNumber // => 86
```

تتمتع السجلات بـ _المساواة البنيوية_، ما يعني أن نسختين من السجل نفسه بقيم متطابقة متكافئتان.

وإلى جانب إمكانية استخدام تدوين النقطة للوصول إلى حقول السجل، يمكن أيضًا _تفكيك_ السجلات في الارتباطات وفي مطابقة الأنماط:

```fsharp
let myAddress: Address = { Street = "Broadway"; HouseNumber = 123 }
let { Street = myStreet; HouseNumber = myHouseNumber } = myAddress

match myAddress with
| { HouseNumber = 1 } -> printfn "First house"
| { HouseNumber = houseNumber; Street = street } -> printfn "House number %d on %s" houseNumber street
// => "House number 123 on Broadway
```
