# للمشرفين

## سكربت مساعد لإنشاء اختبارات Fortran: create_fortran_test.py

يمكنك بسهولة إنشاء اختبار لتمرين باستخدام السكربت `bin/create\_fortran\_test.py`.

استخدم هذا السكربت لإنشاء ملف <exercise>\_test.f90 أولي يمكن استخدامه قالبًا لاختبارك. وفي العادة ستحتاج إلى استبدال الدالة 'response' في الملف المُنشأ باستدعاء الدالة الصحيح.

لاحظ أيضًا أن Fortran يعاني من مشكلات مع الأحرف الخاصة مثل `\n` و `\t`، لذا توخَّ الحذر الشديد عند التعامل معها.

### المتطلبات المسبقة

- أن يعمل كلٌّ من CMake ومترجم Fortran
- Python3.x (يمكنك أن تجعله يعمل مع Python2، لكنني لم أبذل جهدًا لجعله متوافقًا مع الإصدارات السابقة)
- أحدث إصدار من https://github.com/exercism/problem-specifications.git
- git

### سير العمل لإنشاء اختبار جديد

- اسحب أحدث التغييرات من `exercism/problem-specifications`، مثل git clone git@github.com:exercism/problem-specifications.git
- أنشئ فرعًا جديدًا لإنشاء تمرين جديد، مثل git checkout -b exercise-bob
- شغّل هذا السكربت على المثال الذي تريد إنشاءه
- انسخ `config/CMakeLists.txt` إلى مجلد التمرين (يمكنك استخدام `bin/update-cmake-files` لذلك)
- نفّذ التمرين ليعمل
- أصلح الاختبارات التي قد تكون إشكالية (انظر مثلًا exercise/bob "Test 20" و "Test 24")
- تأكد من أن الأمر `ctest` يتحقق دون أخطاء
- انسخ حلّك إلى .meta/example.f90 وأزل التنفيذ الفعلي من ملف التمرين، مثل bob.f90
- حدّث مجلدي .docs و .meta
  - cp ../problem-specifications/exercises/bob/description.md exercises/practice/bob/.docs/instructions.md
    - استبدل "# Description" بـ "# Instructions"
  - املأ .meta/tests.toml يدويًا (حتى تتوفر وسيلة آلية)
  - املأ .meta/config.json يدويًا (حتى تتوفر وسيلة آلية)
    - استخدم ../problem-specifications/exercises/bob/metadata.yml
- افتح طلب سحب بتغييراتك

لمثال bob:

```bash
$ python bin/create_fortran_test.py -j ../problem-specifications/main/exercises/bob/canonical-data.json -t exercises/practice/bob/bob_test.f90
Namespace(json='../problem-specifications/main/exercises/bob/canonical-data.json', target='exercises/practice/bob/bob_test.f90')
Wrote : exercises/practice/bob/bob_test.f90
$ cp config/CMakeLists.txt exercises/practice/bob/.
$ cd exercises/practice/bob
$ touch bob.f90
$ mkdir build
$ cd build
$ cmake ..
$ make
$ ctest -V
```

### تغيير `CMakeLists.txt`

عند تغيير ملف cmake، حدّث النسخة الرئيسية في `config/` واستخدم `bin/update-cmake-files` لنسخها إلى جميع مجلدات التمارين.

## الحل

عندما يكون لديك حل، انسخ هذا الحل إلى مجلد ".meta" باسم "example.f90".

وربما تريد أن تترك تنفيذًا هيكليًا للدالة أو الإجراء الفرعي يساعد الطالب، وأن تترك الملف الذي يحمل اسم التمرين في مجلد التمرين.
