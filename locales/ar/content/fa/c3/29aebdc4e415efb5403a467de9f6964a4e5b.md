# الأصناف

الأصناف مفهوم محوري في [البرمجة كائنية التوجه][object-oriented-programming].
[في Crystal، كل شيء كائن][everything-is-an-object]، ولكل كائن نوع، ويمكنه الاستجابة لبعض الطرق.
الأصناف مخططات لإنشاء الكائنات، توفر قيمًا ابتدائية للحالة، مثل المتغيرات، وتنفيذات للسلوك، مثل الطرق.
الكائنات هي نسخ من الأصناف تحمل جميع متغيرات المثيل والحالات.

## تعريف الصنف

يُعرَّف الصنف باستخدام الكلمة المفتاحية `class`، متبوعة باسم الصنف مكتوبًا بنمط `UpperCamelCase`.

```crystal
class Account
end
```

## إنشاء نسخة

لإنشاء نسخة من صنف ما، نادِ اسم الصنف باستخدام الطريقة `new`.

```crystal
class Account
end

account = Account.new
```

في المثال أعلاه، المتغير `account` هو نسخة من الصنف `Account`.

عند إنشاء نسخة، تعمل طريقة خاصة تُسمى `initialize` عمل دالة البناء.
وتُستدعى عند إنشاء النسخة.
تتيح لك دالة البناء ضبط الحالة الابتدائية للنسخة.
يمكن لطريقة `initialize` أن تستقبل وسائط، تُمرَّر عند إنشاء النسخة.

```crystal
class Account
  def initialize(number)
    5 + number # => 9
  end
end

Account.new(4)
```

~~~~exercism/note
لا يمكن لطريقة `initialize` أن تُرجع قيمة يدويًا، بل تُرجع `new` النسخة المنشأة حديثًا.

```crystal
class Account
  def initialize(number)
    5 + number
  end
end

Account.new(4)
# => #<Account:0x7f5dc33dcea0>
```
~~~~

## طرق المثيل

طريقة المثيل هي طريقة متاحة لنسخة من صنف ما، ويمكن استدعاؤها على تلك النسخة.
تُعرَّف طرق المثيل باستخدام الكلمة المفتاحية `def`، متبوعة باسم الطريقة.
وتُعرَّف داخل تعريف الصنف.

```crystal
class Account
  def balance
    100
  end
end

account = Account.new
account.balance # => 100
```

## متغيرات المثيل

[متغيرات المثيل][instance-variable] هي متغيرات متاحة في جميع طرق النسخة.
للوصول إلى متغير مثيل، تحتاج إلى تعريف طريقة مثيل.
يمكن تهيئتها في طريقة `initialize`.
وتُعرَّف باستخدام البادئة `@`.

```crystal
class Account
  def initialize
    @balance = 100
  end

  def balance
    @balance
  end
end

account = Account.new
account.balance
# => 100
```

يمكن أيضًا تعريف متغيرات المثيل داخل تعريف الصنف.

```crystal
class Account
  @age = 0
end
```

### متغيرات المثيل مع التهيئة

يمكن تهيئة متغيرات المثيل بوسيط يُمرَّر إلى طريقة `initialize`.
لأن Crystal لا يستطيع استنتاج نوع الوسيط المستخدم أثناء التهيئة، يجب تحديده.
إذا أردت قراءة المزيد عن هذا، يمكنك الاطلاع على: [استنتاج النوع][type-inference].
لتحديد نوع المتغير، يمكنك استخدام الرمز `:`، متبوعًا بالنوع.
على سبيل المثال، إذا أردت إنشاء متغير مثيل اسمه `balance` من النوع `Int32`، يمكنك فعل ما يلي: `@balance : Int32`.
أو إذا أردت إنشاء متغير مثيل اسمه `raining` من النوع `Bool`، يمكنك فعل ما يلي: `@raining : Bool`.

هناك عدة أساليب لتنفيذ ذلك، إما بتعريف الوسيط بنوعه في طريقة `initialize`، ثم إسناد متغير المثيل إلى الوسيط، كما في المثال التالي:

```crystal
class Account
  def initialize(balance : Int32)
    @balance = balance
  end

  def balance
    @balance
  end
end

account = Account.new(1)
account_2 = Account.new(5)

account.balance
# => 1

account_2.balance
# => 5
```

أسلوب آخر هو تعريف نوع متغير المثيل في تعريف الصنف بالصيغة: `@<variable> : <Type>`، كما في المثال التالي:

```crystal
class Weather

  @raining : Bool

  def initialize(raining)
    @raining = raining
  end

  def raining
    @raining
  end
end

weather = Weather.new(true)
weather.raining
# => true
```

## تعديل متغيرات المثيل

يمكن للطرق تعديل متغيرات المثيل.
ويمكن استدعاء هذه الطرق على نسخة الصنف.
عندما تعدّل طريقة متغير مثيل، فإن هذا التغيير متاح فقط في نسخة الصنف التي استدعيتها عليها.

```crystal
class Account
  def initialize(balance : Int32)
    @balance = balance
  end

  def withdraw(amount)
    @balance -= amount
  end

  def balance
    @balance
  end
end

account = Account.new(10)
account_2 = Account.new(10)
account.balance
# => 10

account_2.balance
# => 10

account.withdraw(5)
account.balance
# => 5

account_2.balance
# => 10
```

## طرق الصنف

[طرق الصنف][class-methods] هي طرق تُعرَّف لصنف ما وليس لنسخه.
وهي توفر أسلوبًا لإنشاء طرق لا تعتمد على حالة النسخة.
تُعرَّف باستخدام الكلمة المفتاحية `def`، متبوعة بـ `self.<method name>`.
`self` إشارة إلى النطاق الذي يُستدعى منه `self`.
في هذه الحالة، يشير إلى الصنف `Account`.
سيكون الأمر مماثلًا لو كتبت `Account.`، لكن `self.` هو الأسلوب المفضل.

```crystal
class Account
  def self.balance
    100
  end
end

Account.balance
# => 100
```
