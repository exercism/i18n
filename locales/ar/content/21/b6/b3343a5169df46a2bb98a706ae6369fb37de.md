بصفتها ساحرةً ناشئة، تحتاج Elyse إلى التدرب على بعض الأساسيات.
لديها رزمة بطاقات تريد التلاعب بها.

ولتسهيل الأمور قليلًا، تستخدم البطاقات من 1 إلى 10 فقط.

## 1. استرجاع بطاقة من الرزمة

أعد البطاقة الواقعة في الموضع `idx` من الرزمة المعطاة.

```julia-repl
julia> idx = 2;

julia> card([1, 3, 4, 1], idx)
3
```

## 2. استبدال بطاقة في الرزمة

استبدل البطاقة الواقعة في الموضع `idx` بالبطاقة الجديدة المعطاة، وأعد الرزمة المعدَّلة.
لاحظ أن هذا سيغيّر (يعدّل) المتجه المدخل، وهذا مقبول.

```julia-repl
julia> idx = 2; new_card = 6;

julia> replace_card!([1, 3, 4, 1], idx => new_card)
[1, 6, 4, 1]
```

## 3. إدراج بطاقة في أعلى الرزمة

أدرج بطاقة جديدة في أعلى الرزمة وأعد الرزمة.

```julia-repl
julia> new_card = 8;

julia> insert_card_at_top!([1, 3, 4, 1], new_card)
[1, 3, 4, 1, 8]
```

## 4. إزالة بطاقة من الرزمة

أزل البطاقة الواقعة في الموضع `idx` من الرزمة وأعد الرزمة.

```julia-repl
julia> idx = 2;

julia> remove_card!([1, 3, 4, 1], idx)
[1, 4, 1]
```

## 5. إزالة البطاقة العليا من الرزمة

أزل البطاقة الواقعة في أعلى الرزمة وأعد الرزمة.

```julia-repl
julia> remove_card_from_top!([1, 3, 4, 1])
[1, 3, 4]
```

## 6. إدراج بطاقة في أسفل الرزمة

أدرج بطاقة جديدة في أسفل الرزمة وأعد الرزمة.

```julia-repl
julia> new_card = 8;

julia> insert_card_at_bottom!([1, 3, 4, 1], new_card)
[8, 1, 3, 4, 1]
```

## 7. إزالة بطاقة من أسفل الرزمة

أزل البطاقة الواقعة في أسفل الرزمة وأعد الرزمة.

```julia-repl
julia> remove_card_at_bottom!([1, 3, 4, 1])
[3, 4, 1]
```

## 8. التحقق من حجم الرزمة

تحقق مما إذا كان حجم الرزمة يساوي قيمة `deck_size` المعطاة أم لا.

```julia-repl
julia> deck_size = 4;

julia> check_deck_size([1, 3, 4, 1], deck_size)
true

julia> check_deck_size([1, 3, 4, 1, 5], deck_size)
false
```
