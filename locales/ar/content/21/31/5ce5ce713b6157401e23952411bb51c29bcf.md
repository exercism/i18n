# التعليمات

لقد عُدتَ إلى المطبخ لتحسين وصفة اللازانيا الواردة في [لازانيا ليا اللذيذة][lasagna]. تطلب منك المهام هنا التعامل مع عدة مدخلات في آنٍ واحد، وهنا بالضبط تُثبت *المتغيرات المحلية* (الارتباطات المسماة في Factor) قيمتها.

## 1. تحديد حالة الطهي

عرّف `cooking-status` بحيث تأخذ قراءة المؤقّت من المكدّس وتُرجع سلسلة نصية تمثّل الحالة.

- `0` → `"Lasagna is done."`
- `f` (لم يُضبط المؤقّت مطلقًا) → `"You forgot to set the timer."`
- أي عدد آخر → `"Not done, please wait."`

```factor
12 cooking-status .   ! => "Not done, please wait."
0 cooking-status .    ! => "Lasagna is done."
f cooking-status .    ! => "You forgot to set the timer."
```

## 2. تقدير زمن التحضير

عرّف `preparation-time` بحيث تأخذ مصفوفة بأسماء الطبقات ومتوسط عدد الدقائق لكل طبقة، وتُرجع زمن التحضير الإجمالي.

```factor
{ "sauce" "noodles" "sauce" "meat" "mozzarella" "noodles" } 3 preparation-time .
! => 18
```

## 3. حساب ما يلزم من المعكرونة والصلصة

عرّف `quantities` بحيث تأخذ مصفوفة بأسماء الطبقات وتُرجع *قيمتين*: عدد غرامات المعكرونة اللازمة (50 غرامًا لكل طبقة معكرونة) وعدد لترات الصلصة اللازمة (`1/5` لتر لكل طبقة صلصة).

```factor
{ "sauce" "noodles" "sauce" "meat" "mozzarella" "noodles" } quantities .s
! => 100
! => 2/5
```

## 4. إضافة المكوّن السرّي

يرسل لك صديقك قائمة مكوّنات، والعنصر *الأخير* فيها هو سرّه. عرّف `add-secret-ingredient` بحيث تأخذ قائمته وقائمتك وتُرجع قائمتك بعد إلحاق السرّ بها.

```factor
{ "noodles" "sauce" "mozzarella" "kampot pepper" }
{ "noodles" "meat" "sauce" "mozzarella" }
add-secret-ingredient .
! => { "noodles" "meat" "sauce" "mozzarella" "kampot pepper" }
```

## 5. إعادة تحجيم الوصفة

تكفي وصفة الكتاب لحصتين. عرّف `scale-recipe` بحيث تأخذ وصفة (جدول تجزئة يربط اسم المكوّن بكميته) وعددًا مستهدفًا من الحصص، وتُرجع وصفة جديدة مُحجّمة بما يتناسب مع ذلك.

```factor
H{ { "noodles" 200 } { "sauce" 1/2 } { "mozzarella" 1 } { "meat" 100 } }
4 scale-recipe .
! => H{ { "noodles" 400 } { "sauce" 1 } { "mozzarella" 2 } { "meat" 200 } }
```
