# مقدمة

## تطبيقات الويب

Elm لغة ممتعة لبناء تطبيقات ويب موثوقة.
فهي تقدّم رسائل خطأ ودّية، وأداءً رائعًا، وحجمًا صغيرًا للأصول، ولا استثناءات وقت التشغيل.

ولعلّ أشهر جزء من Elm وأكثره اقتباسًا هو معمارية Elm، وهي نمط بسيط لبناء تطبيقات الويب، وعليها تُكتب جميع تطبيقات Elm.

الفكرة الجوهرية هي أن كودك يدور حول `Model` يحمل حالة تطبيقك، وحول طريقةٍ لتحديثه عبر `update`، وطريقةٍ لعرضه عبر `view`.

يحتوي `Model` على حالة التطبيق، أي كل البيانات التي يحتاجها التطبيق.
إذا تخيّلت تطبيقًا بسيطًا فيه مربّع نص، ونصٌّ يعرض ذلك النص معكوسًا، فسيبدو `Model` كما يلي.
يمكنك أيضًا رؤية هذا المثال في [دليل Elm][elm-guide-text-fields].

```elm
type alias Model =
  { text : String
  }
```

`update` دالة تُستدعى مع `Msg` عند حدوث تغيير (مثل نقر المستخدم على زر).
وهي تأخذ `Msg` و`Model` الحالي، وتُرجع `Model` جديدًا.

```elm
type Msg
  = TextChanged String

update : Msg -> Model -> Model
update msg model =
  case msg of
    TextChanged newText ->
      { model | text = newText }
```

`view` دالة تُرجع HTML لعرضه للمستخدم في المتصفح.
وهي تأخذ `Model` الحالي وتُرجع `Html Msg` (النوع الذي يستخدمه Elm لتمثيل HTML).

```elm
view : Model -> Html Msg
view model =
  Html.div []
    [ Html.input
      [ Html.Attributes.placeholder "Text to reverse"
      , Html.Attributes.value model.text
      , Html.Events.onInput TextChanged
      ]
      []
    , Html.div [] [ Html.text (String.reverse model.text) ]
    ]
```

[elm-guide-text-fields]: https://guide.elm-lang.org/architecture/text_fields
