# مقدمة

يتشابه `Tuple` كثيرًا مع `Vector` (أي `array` أحادي البعد) من نواحٍ عديدة.
مع ذلك، هناك بعض الفروق المهمة.

- تُكتب الصفوف بين قوسين هلاليين `( )` بدلاً من قوسين مربعين `[ ]`، رغم أنه يمكن حذف الأقواس الهلالية عندما يكون المعنى واضحًا.
- لا يُشترط أن تكون الصفوف متجانسة: يُخزَّن نوع كل عنصر بشكل مستقل.
- الصفوف غير قابلة للتغيير.

تسمح عدم قابلية التغيير بمزيد من تحسينات المصرّف وتجعل الصفوف أعلى أداءً من المتجهات، لذا يُفضَّل استخدامها عندما لا تكون قابلية التغيير ضرورية.

```julia-repl
julia> t = (3, 5.2, "xyz")
(3, 5.2, "xyz")

# Non-homogeneous:
julia> dump(t)
Tuple{Int64, Float64, String}
  1: Int64 3
  2: Float64 5.2
  3: String "xyz"

julia> t[2]
5.2

# Immutable:
julia> t[2] = 7.3
ERROR: MethodError: no method matching setindex!(::Tuple{Int64, Float64, String})
```

يوجد أيضًا منشئ `Tuple()`، وهو يحوّل أي مجموعة قابلة للتكرار إلى صف.
ومن المفيد أنه يتعامل مع السلسلة النصية كمجموعة قابلة للتكرار من المحارف.

```julia-repl
julia> Tuple("Julia")
('J', 'u', 'l', 'i', 'a')
```

بالنسبة لأي صف، يمكن الوصول إلى العناصر عبر الفهرس أو التكرار عليها.

يمكن أيضًا استخدام أي صف عددي بحت في الدوال الرياضية مثل `sum()`، تمامًا مثل المصفوفات.

## التفكيك

يمكن تفكيك الصف إلى عناصر فردية باستخدام الإسناد المتعدد.
وللعناصر غير المطلوبة، استخدم الشرطة السفلية `_` كمتغير وهمي.

```julia-repl
julia> tup = (1, "Julia", true)
(1, "Julia", true)

julia> num, name, _ = tup
(1, "Julia", true)

julia> uppercase(name), 2num
("JULIA", 2)
```

سيكون مبرمجو Python على دراية كبيرة بصيغة الإسناد المتعدد هذه.

## الصفوف المسماة

يحتوي `Tuple` على القيم فقط.
بينما يقرن `NamedTuple` كل قيمة باسم.

يمكن بعد ذلك الوصول إلى الحقول الفردية باستخدام تدوين "النقطة":

```jullia-repl
julia> nt = (a = 1, b = 7.3)
(a = 1, b = 7.3)

julia> dump(nt)
@NamedTuple{a::Int64, b::Float64}
  a: Int64 1
  b: Float64 7.3

julia> nt.b
7.3
```

يُخزَّن الاسم داخليًا كـ `Symbol` (نوع غير قابل للتغيير، ويُسبَق الاسم بعلامة النقطتين `:`)، لذا تتوفر صيغة بديلة:

```julia-repl
julia> nt[:b]
7.3
```

من السهل الحصول على الأسماء (وتسمى أيضًا "المفاتيح") أو القيم كل على حدة:

```julia-repl
julia> nt
(a = 1, b = 7.3)

julia> keys(nt)
(:a, :b)

julia> values(nt)
(1, 7.3)
```

لاحظ أن التكرار على صف مسمى ينتج _القيم_ فقط، ويتم تجاهل _الأسماء_.

تُعد الصفوف (المسماة أو غير المسماة) طريقة شائعة جدًا لنقل البيانات المهيكلة من وإلى الدوال.
عدم قابلية التغيير مفيد في حالة الاستخدام هذه، إذ يوفر أمان البيانات ويسمح للمصرّف بتحسينات أكثر جرأة.
