# التعليمات

تحاول Astrid، وهي خيميائية مُغامِرة، أن توحّد الوحدات السحرية للقياس التي تجمعها من عوالم مختلفة.
تستخدم بعض العوالم قياسات مُوقَّعة (يمكن أن تكون سالبة)، بينما تستخدم عوالم أخرى قياسات غير مُوقَّعة (وهي دائمًا موجبة).
وفوق ذلك، لدى Astrid نوعان مُخصَّصان لمكوّنات نادرة معيّنة، وهي تحتاج إلى وسيلة للتحويل بسهولة بين هذين النوعين.

مهمتك هي مساعدة Astrid على التحويل بين الأعداد الصحيحة المُوقَّعة وغير المُوقَّعة، وإنشاء تحويلات مُخصَّصة لأنواع مكوّناتها الخاصة باستخدام السمتين `Into` و`TryInto` في Cairo.

## 1. تحويل الوحدات السحرية بين القيم المُوقَّعة وغير المُوقَّعة

لدى Astrid قياسات تأتي أحيانًا بقيم موجبة أو سالبة (أعداد صحيحة مُوقَّعة)، لكنها تحتاج في بعض المهام إلى التأكد من أن القيم موجبة دائمًا (أعداد صحيحة غير مُوقَّعة).

ساعد Astrid بكتابة دالة تُحوِّل:

1. عددًا صحيحًا مُوقَّعًا (`i32`) إلى عدد صحيح غير مُوقَّع (`u16`).
2. عددًا صحيحًا غير مُوقَّع (`u16`) إلى عدد صحيح مُوقَّع (`i32`).

```rust
let signed_value: i32 = -42;
match convert_signed_to_unsigned(signed_value) {
    Option::Some(v) => println!("Converted to unsigned: {}", v),
    Option::None => println!("Failed to convert: {}", signed_value),
} // prints "Failed to convert: -42"

let unsigned_value: u16 = 42;
let signed_value: i32 = convert_unsigned_to_signed(unsigned_value);
println!("Converted to signed: {}", signed_value); // prints "Converted to signed: 42"
```

## 2. تحويل أنواع المكوّنات المُخصَّصة

تعمل Astrid مع مكوّنين نادرين، **Essence** و**Elixir**، وهما مُمثَّلان بنوعين مُخصَّصين.
وهي تريد أن تستطيع تحويل **Essence** إلى **Elixir**، وليس العكس.

ساعد Astrid بإنشاء نوعين مُخصَّصين، `Essence` و`Elixir`، وتنفيذ سمة `Into` للتحويل من `Essence` إلى `Elixir`.

اكتب دالة تستقبل `Essence` وتحوّلها إلى `Elixir` باستخدام `.into()`.

```rust
#[derive(Drop)]
struct Essence {
    potency: u16,
}

#[derive(Drop)]
struct Elixir {
    strength: u16,
}

fn convert_essence_to_elixir(essence: Essence) -> Elixir {
    // Convert the Essence to Elixir using the Into trait.
    essence.into()
}

fn main() {
    let essence = Essence { potency: 100 };
    let elixir: Elixir = convert_essence_to_elixir(essence);
    println!("Elixir strength: {}", elixir.strength); // Elixir strength: 100
}
```
