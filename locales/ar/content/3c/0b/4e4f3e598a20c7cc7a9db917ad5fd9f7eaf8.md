# مقدمة

تستطيع الكائنات الاحتفاظ بحالتها الخاصة عبر تعيين _متغيرات المثيل_، وهي تُنشأ بإضافة `@` قبل اسم المتغير.

```ruby
@name = 2
```

عادةً ما تضبط الكائنات حالتها الأولية داخل طريقة `initialize`، التي تُستدعى تلقائيًا عند استدعاء `new` على صنف.

```ruby
class Airplane
  def initialize
    @wings = 2
  end
end
```

ويمكن لطريقة `initialize` أيضًا أن تستقبل وسائط، بحيث يبدأ كل مثيل بحالة مخصّصة:

```ruby
class Suitcase
  def initialize(locked)
    @locked = locked
  end
end
```

اعتبر _متغيرات المثيل_ خاصة، لا تُقرأ ولا تُكتب من الخارج. وينبغي استخدام _طرق المثيل_ لقراءة متغيرات المثيل وإسنادها:

```ruby
class Suitcase
  #...

  def locked? # Query methods should be named with a trailing `?`
    @locked
  end

  def unlock! # Methods which mutate state should have trailing `!`
    @locked = false
  end
end
```
