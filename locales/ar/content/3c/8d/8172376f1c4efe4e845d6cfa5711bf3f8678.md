# مقدمة

الطريقة هي دالة لها وسيط خاص هو _المستقبِل_.
يظهر المستقبِل في قائمة وسائط خاصة به بين الكلمة المفتاحية `func` واسم الطريقة.

```go
func (receiver type) MethodName(parameters) (returnTypes) {
}
```

لا يمكنك تعريف طريقة إلا إذا كان نوع مستقبِلها معرّفًا في الحزمة نفسها التي تُعرَّف فيها الطريقة.

```go
package person 

type Person struct {
	Name string
}

func (p Person) Greetings() string {
	return fmt.Sprintf("Welcome %s!", p.Name)
}
```

يمكن استدعاء الطريقة المعرّفة على البنية عبر الترميز النقطي.

```go
p := Person{Name: "Bronson"}
fmt.Println(p.Greetings())
// Output: Welcome Bronson!
```

لاحظ كيف استدعينا الطريقة `Greetings()` على النسخة `p` من `Person`.
إنه تمامًا مثل استدعائك للطرق في لغة برمجة كائنية التوجه.

تذكّر: الطريقة ليست سوى دالة لها وسيط مستقبِل.
تساعد الطرق على تجنّب تعارض الأسماء، فلأن الطريقة مرتبطة بنوع مستقبِل معيّن، يمكنك استخدام اسم الطريقة نفسه مع أنواع مختلفة.

```go
import "math"

type rect struct {
	width, height int
}
func (r rect) area() int {
	return r.width * r.height
}

type circle struct {
	radius int
}
func (c circle) area() float64 {
	return math.Pow(float64(c.radius), 2) * math.Pi
}
```

هناك نوعان من المستقبِلات: مستقبِلات القيم ومستقبِلات المؤشرات.

كل الطرق التي رأيناها حتى الآن لها مستقبِل قيمة، أي أنها تستقبل نسخة من القيمة التي تُمرَّر إلى الطريقة، ما يعني أن أي تعديل يجري على المستقبِل داخل الطريقة لا يراه المستدعي.

يمكنك تعريف طرق بمستقبِلات مؤشرات لتعديل القيمة التي يشير إليها المستقبِل.
يتم ذلك بوضع `*` قبل اسم النوع.
على سبيل المثال، مع النوع `rect`، يُعرَّف مستقبِل المؤشر بالشكل `*rect`.
وتكون هذه التعديلات مرئية أيضًا لمستدعي الطريقة.

```go
type rect struct {
	width, height int
}
func (r *rect) squareIt() {
	r.height = r.width
}

r := rect{width: 10, height: 20}
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 20

r.squareIt()
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 10
```
