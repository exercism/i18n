# نبذة

مخزن السلاسل النصية أسلوب فعّال لبناء سلسلة نصية كبيرة بإضافة عناصر صغيرة بعضها إلى بعض. وخلافًا لـ `String`، فإن نسخة من `StringBuf` ليست ثابتة، إذ يمكن تمريرها كوسيط إلى دوال تعدّلها بإضافة المزيد من القيم.

```haxe
var a = new StringBuf();
a.add("Hello");
trace(a.toString()); // Hello
a.add("Haxe!");
trace(a.toString()); // HelloHaxe
```
