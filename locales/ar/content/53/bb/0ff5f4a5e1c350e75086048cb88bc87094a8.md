## المتغيرات والإسناد

R لغة ذات أنواع ديناميكية، لذا لا يلزم عمومًا تحديد نوع المتغير. عامل الإسناد المفضل هو `<-`

```R
x <- 42
avogadro <- 6.02e23
mystr <- "Hello, World!"
```

استخدام `=` بدلًا من `<-` سينجح غالبًا لكن ليس دائمًا، ولا يُنصح به لأنه أسلوب رديء.
وإذا كنت تعمل في RStudio، يمكنك إدخاله باختصار لوحة المفاتيح `Alt-minus`.

معظم العوامل مألوفة، لكن انتبه إلى `%/%` و`%%`:

```R
2 + 3   # 5
2 - 3   # -1
2 * 3   # 6
2 / 3   # 0.6666667
8 %/% 3 # 2 (integer division)
8 %% 3  # 2 (remainder)
2 ^ 3   # 8 (exponential)
```

في R، تبدأ `#` تعليقًا من سطر واحد.
ولا توجد صيغة منفصلة للتعليقات متعددة الأسطر.

## الدوال

لتعريف دالة:

```R
squareit <- function(x) {
    x * x
}
```

يمكن للدالة أن تحتوي على صفر أو أكثر من الوسائط، مفصولة بفواصل.
الأقواس الهلالية `()` ضرورية مع `function()`، حتى لو لم توجد أي معاملات.

يمكن تحديد قيم افتراضية لوسائط الدالة، لكن يجب أن تأتي بعد أي وسائط بلا قيم افتراضية، ويُستخدم `=` لا `<-` في إسناد القيمة الافتراضية.
وكمثال لا فائدة كبيرة منه:

```R
squareit <- function(x = 42) {
    x * x
}

squareit()
#> [1] 1764
```

الأقواس المعقوفة `{ }` ليست ضرورية تمامًا لأجسام الدوال المكوّنة من سطر واحد، لكن إدراجها يُعدّ أسلوبًا جيدًا.

ستُرجع R تلقائيًا القيمة الأخيرة للدالة، كما في الأمثلة أعلاه.

يمكن استخدام `return()` في أي مكان داخل جسم الدالة لجعل قيمة الإرجاع صريحة.

استدعاء دالة يشبه ما هو عليه في كثير من اللغات الأخرى:

```R
squareit(3)
#> [1] 9
```
