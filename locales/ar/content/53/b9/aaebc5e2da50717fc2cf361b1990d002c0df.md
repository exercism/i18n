# التثبيت

## ثبّت .NET 10

يعتمد مسار Visual Basic على .NET 10.
لبناء التمارين واختبارها محليًا، ثبّت [.NET 10 SDK الخاص بنظام التشغيل لديك][install-sdk]:
ثبّت حزمة SDK، وليس بيئة التشغيل فقط.

## تحقّق من التثبيت

افتح نافذة طرفية جديدة ثم نفّذ:

```bash
dotnet --version
```

ينبغي أن يُخرج الأمر `10.0.0` أو أحدث.

## دعم المحررات

كل ما تحتاجه لإكمال التمارين هو .NET SDK ومحرر نصوص بسيط.
وللحصول على ميزات أكثر تقدمًا مثل إكمال الكود وتصحيح الأخطاء، جرّب أحد هذه المحررات:

- [Visual Studio 2026][visual-studio] على Windows
- [Visual Studio Code][visual-studio-code] على Windows أو Linux أو macOS
- [JetBrains Rider][rider] على Windows أو Linux أو macOS

[rider]: https://www.jetbrains.com/rider/
