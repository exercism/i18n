# المديات

تمثل [المديات][range] فترة بين قيمتين.
أكثر الأنواع شيوعًا التي تدعم المديات هي `Integer` و`String`.
ويمكن استخدامها في أمور كثيرة، مثل إنشاء مجموعة بسرعة، وتقطيع السلاسل النصية، والتحقق مما إذا كانت قيمة ما تقع ضمن مدى، والتكرار.
وتُنشأ باستخدام معامل المدى `..` أو `...` (شامل للطرف الأخير وغير شامل له على الترتيب).

```ruby
1..5  # => 1..5
1...5 # => 1...5

(1..5).to_a # => [1, 2, 3, 4, 5]
(1...5).to_a # => [1, 2, 3, 4]
```

سبب وجود معاملي مدى هو السماح بإنشاء مديات تشمل القيمة النهائية أو تستبعدها، وهو أمر مفيد عند التعامل مع فهارس تبدأ من الصفر على سبيل المثال.

يمكن أيضًا إنشاء المديات باستخدام المُهيّئ `Range`.

```ruby
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
عند إنشاء مدى في Ruby باستخدام معاملي المدى `..` أو `...`، وأردت استدعاء طريقة على المدى، فستحتاج إلى وضع المدى بين الأقواس الهلالية.
السبب أن الطريقة ستُستدعى بخلاف ذلك على الوسيط الثاني لمعامل المدى.

```ruby
(1..5).sum # => 15
1..5.sum # => Error: undefined method `sum' for 5:Integer (NoMethodError)
```
~~~~

## الحصول على سلاسل فرعية

عند الرغبة في تقطيع سلسلة نصية، يمكنك استخدام معامل المدى للحصول على سلسلة فرعية.
أي عن طريق إنشاء مدى من فهرس بداية السلسلة الفرعية وفهرس نهايتها.

```ruby
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

يمكنك أيضًا استخدام فهارس سالبة للحصول على السلسلة الفرعية من نهاية السلسلة النصية.

```ruby
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## طرق المدى

للمديات مجموعة من الطرق التي يمكن استخدامها للتعامل معها.
على سبيل المثال، يمكن استخدام هذه الطرق للحصول على مجموع كل القيم في المدى أو للتحقق مما إذا كان المدى يضم قيمة ما.

| الطريقة                | الوصف                                                             | مثال                         |
| ----------------------- | ----------------------------------------------------------------------- | ------------------------------- |
| [`sum`][sum]            | تُرجع مجموع كل القيم في المدى                          | `(1..5).sum # => 15`            |
| [`size`][size]          | تُرجع حجم المدى                                           | `(1..5).size # => 5`            |
| [`include?`][indlude]   | تُرجع `true` إذا كان المدى يضم القيمة المعطاة، وإلا فتُرجع `false` | `(1..5).include?(3) # => true` |

## المديات اللامتناهية والمديات بلا بداية

يمكن أن يكون المدى لا متناهيًا أو بلا بداية.
في المدى اللامتناهي أو الذي بلا بداية تكون قيمة بدايته أو نهايته `nil`، لكن عند تعريف المدى يمكن حذف `nil`.

استخدام المديات التي بلا بداية أو اللامتناهية مفيد عندما تريد، على سبيل المثال، تقطيع سلسلة نصية من بدايتها أو إلى نهايتها.

```ruby
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
إن لم يُستخدم المدى اللامتناهي على مجموعة، فقد ينتج عنه تسلسل لا متناهٍ إذا لم يُستخدم بحذر.
~~~~

## مديات السلاسل النصية

يمكن أيضًا استخدام السلاسل النصية في المديات، وهذا يتيح الحصول على فترة من السلاسل النصية بين سلسلتين.
وقد يكون سلوكه غير متوقع مع بعض السلاسل النصية، لذا استخدمه بحذر.

```ruby
"aa".."az".to_a # => ["aa", "ab", "ac", ..., "az"]
```
