# التثبيت

## تثبيت Clojure CLI

توفّر Clojure أدوات سطر أوامر من أجل: تشغيل REPL تفاعلي (حلقة القراءة والتقييم والطباعة)، وتشغيل برامج Clojure، وتقييم تعبيرات Clojure.
نشجعك على استخدام Clojure CLI مع التمارين. لتثبيت [Clojure CLI](https://clojure.org/guides/deps_and_cli):

### Windows
لمعرفة تعليمات التثبيت على Windows راجع: [تثبيت Clojure CLI](https://clojure.org/guides/getting_started#_installation_on_windows).

### Linux
لمعرفة تعليمات التثبيت على معظم الأنظمة راجع: [تثبيت Clojure CLI](https://clojure.org/guides/getting_started#_installation_on_linux).

### Homebrew على Mac OS X
حدّث Homebrew:

``` bash
$ brew update
```

ثبّت Clojure CLI:
``` bash
$ brew install node clojure/tools/clojure
```

يلزم وجود `Node` من أجل بيئة node.

## اختبار التثبيت

لاختبار صحة التثبيت، شغّل `clojure --help` وسترى رقم الإصدار إذا سار كل شيء على ما يرام.

```bash
$ clojure --help
Version: 1.10.1.547
...
```
