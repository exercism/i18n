# نبذة

عند المرور على متتالية، لا يكفي العنصر وحده أحيانًا، فأنت تحتاج إلى الموضع أيضًا. كلمات *التكرار المفهرس* في Factor تعطي `quotation` الخاصة بكل عنصر كليهما، مع وجود الفهرس في أعلى المكدس. أما `times` فهي الكلمة المرتبطة بالتكرار المعدود من دون متتالية أساسية.

```factor
USING: io kernel math.parser sequences ;

! map-index: build a new sequence; quot sees ( elt index )
{ "alice" "bob" "carol" }
[ number>string ": " glue ] map-index .
! => { "alice: 0" "bob: 1" "carol: 2" }

! each-index: for side effect; quot sees ( elt index )
{ "alice" "bob" } [
    number>string ": " glue print
] each-index
! prints alice: 0
! prints bob: 1

! times: run a quotation N times
3 [ "tick " print ] times
```

| الكلمة       | الأثر                                                                 |
|--------------|----------------------------------------------------------------------|
| `each-index` | `( seq quot: ( elt index -- ) -- )`                                  |
| `map-index`  | `( seq quot: ( elt index -- newelt ) -- newseq )`                    |
| `times`      | `( n quot: ( -- ) -- )`، لكن انظر أدناه                              |

وثمة تفصيل دقيق في `times`: فرغم أن `quotation` الخاصة بها موثّقة بصيغة `( -- )`، فإن الكلمة نفسها `inline`، لذا تعمل `quotation` متوازنة الأثر مثل `( str -- str )` بلا مشكلة، وتمرّر المكدس عبر التكرارات. وهذا يمنحك مجمّعًا معدودًا من دون أي حالة قابلة للتغيير:

```factor
USING: kernel sequences ;

"" 3 [ "clop " append ] times .    ! => "clop clop clop "
```

والحيلة نفسها تنفع مع `each-index` و`map-index`: فالأثر المعلن لكل عنصر هو *حد أدنى*، لا حد أقصى.
