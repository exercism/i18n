# حول

مثل معظم لغات البرمجة، لدى Gleam "آثار جانبية"، فالدوال تستطيع قراءة حالة العالم وتغييرها، وكذلك إرجاع قيمة.

وحدة `gleam/io` في مكتبة Gleam القياسية توفر دوال لطباعة السلاسل النصية إلى الطرفية.

```gleam
io.println("Hello, Joe!")
// Hello, Joe!
// -> Nil
```

قد توفر حزم أخرى دوال إدخال وإخراج أخرى، مثل `simplifile`، وهي حزمة توفر دوال لقراءة الملفات وكتابتها.

```gleam
simplifile.read("favourite-colour.txt")
// -> Ok("Pink\n")
```
