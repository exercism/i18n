# ملحق التعليمات

## السجلات

| السجل | الاستخدام | النوع | الوصف |
| -------- | ------------ | ------- | ----------------------------------- |
| `$a0`    | إدخال        | عدد صحيح | العدد الطبيعي المراد تحليله إلى عوامل أولية     |
| `$a1`    | إدخال/إخراج | عنوان | مصفوفة الوجهة للعوامل الأولية |
| `$v0`    | إخراج       | عدد صحيح | عدد العوامل                   |
| `$t0-9`  | مؤقت    | أي     | تُستخدم للتخزين المؤقت          |
