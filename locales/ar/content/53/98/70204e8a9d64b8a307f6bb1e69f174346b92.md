# نبذة

يمكنك استخدام [أنواع التعداد][enumeration types] كلما كانت لديك مجموعة ثابتة من القيم. ويمنحك استخدام `enum` طريقة آمنة من حيث النوع للتعامل مع القيم الثابتة. ويتم تعريف التعداد من خلال الكلمة المفتاحية `enum`. ويُشار إلى عضو التعداد بوضع اسم التعداد ونقطة قبله (مثال: `Status.Active`).

كل عضو في التعداد هو اقتران بين اسم وقيمة من النوع `int`. وإذا لم يكن للعضو الأول قيمة صريحة، فستُضبط قيمته على `0`. وإذا لم تُعرَّف قيمة صريحة لأي عضو في التعداد، فستُسنَد قيمته تلقائيًا إلى قيمة العضو السابق زائد `1`.

```csharp
enum Season
{
    Spring,     // Auto set 0
    Summer = 2, // Set the value 2
    Autumn,     // Auto set 3
    Winter = 7  // Set the value 7
}
```

التعدادات تصريحية للغاية. قارن بين استدعاءَي الطريقة التاليين:

```csharp
Users.WithStatus(1)
Users.WithStatus(Status.Active)
```

بالنسبة لمن يقرأ الكود، ستكون النسخة الثانية (التي تستخدم التعداد) أسهل في الفهم.

## التعدادات ذات النوع العددي

على الرغم من أن النوع العددي الافتراضي للقيم هو `int`، فإنه يمكن تغييره بتحديد أي نوع آخر من [الأنواع العددية الصحيحة][integral numeric] بشكل صريح.

يستخدم التعداد التالي النوع العددي `byte` لقيمه:

```csharp
enum Priority : byte
{
    Low = 0,
    Medium = 127,
    High = 255
}
```

## التحويل إلى عضو في التعداد

ينبغي أن تفكر دائمًا في استخدام تعداد كلما أردت نمذجة شيء يشبه القيمة المنطقية. وإلى جانب فوائد القراءة المذكورة آنفًا، تتمتع التعدادات بميزة أخرى على القيم المنطقية: إذ يمكن دائمًا إضافة قيم جديدة إلى التعداد، بينما لن تكون قيمة منطقية سوى `true` أو `false`. لذا فإن استخدام التعداد أكثر أمانًا على المدى الطويل.

```csharp
enum Status
{
    Inactive = 0,
    Active = 1
}

Status active = (Status) 1;
active == Status.Active; // True
```

لاحظ أنه على الرغم من أنه _يمكن_ تحويل قيم الأعداد الصحيحة إلى تعداد، فإن القيام بذلك قد يؤدي إلى نتائج غير متوقعة عندما لا تقابل قيمة العدد الصحيح أي قيمة من قيم التعداد:

```csharp
Status status = (Status) 2;
status == Status.Inactive; // False
status == Status.Active;   // False
```

## تحليل قيمة التعداد

يُفيد أحيانًا تحويل سلسلة نصية إلى عضو في التعداد بناءً على اسمه باستخدام [`Enum.Parse`][enum parse]:

```csharp
var input = "Inactive";
Status status = (Status)Enum.Parse(typeof(Status), input);
// Inactive
```

للتحقق مما إذا كان اسم أو قيمة موجودين في التعداد، يمكنك استخدام [`Enum.TryParse`][enum tryparse] أو [`Enum.IsDefined`][enum isdefined]، وكلاهما يُرجعان قيمة منطقية تشير إلى ما إذا كان عضو التعداد موجودًا:

```csharp
bool doesExist = Enum.IsDefined(typeof(Status), "Inexistent");
// False
```
