# مقدمة

القدرة على تعريف شيء ما من خلال نفسه تُسمّى العودية. وفي F#، تظهر العودية في أغلب الأحيان في الدوال العودية، وهي دوال تستدعي نفسها.

تحتاج الدالة العودية إلى _حالة أساسية_ واحدة على الأقل، وإلى _حالة عودية_ واحدة على الأقل. الحالة الأساسية تُرجع قيمة دون استدعاء الدالة مرة أخرى. أما الحالة العودية فتستدعي الدالة مرة أخرى، مع تعديل المدخل بحيث يطابق الحالة الأساسية في مرحلة ما.

تُعرَّف الدوال العودية مثل الدوال العادية، لكن مع مُعدِّل `rec`. وبدون هذا المعدِّل، لن تتمكن الدالة من استدعاء نفسها، وأي محاولة لفعل ذلك ستؤدي إلى خطأ في الترجمة. ولهذا يجب اختيار العودية بشكل صريح.

```fsharp
let rec factorial x =
    // Base case
    if x = 1 then
        1
    // Recursive case
    else
        x * factorial (x - 1)
```

تدعم F# أيضًا الأنواع العودية عبر أنواع الاتحاد المميّز. ونوع الاتحاد المميّز العودي تشير حالة واحدة أو أكثر من حالاته إلى نوع الاتحاد المميّز نفسه في بياناتها. ومثل الدوال العودية، يجب أن يكون للأنواع العودية حالة أساسية. وعلى عكس الدوال العودية، لا تستخدم الأنواع العودية الكلمة المفتاحية `rec`.

```fsharp
type RussianDoll =
    | Doll                 // Base case
    | Layer of RussianDoll // Recursive case
```
