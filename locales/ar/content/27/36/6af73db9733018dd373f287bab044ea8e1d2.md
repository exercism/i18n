# مقدمة

المجموعة المرتبة هي حاوية مرتبة للقيم. وكما هو الحال مع جميع أنواع البيانات في Gleam، فإن المجموعات المرتبة غير قابلة للتغيير. ويمكن أن يكون كل عنصر من عناصر المجموعة المرتبة من نوع مختلف، بل يمكن أن تكون العناصر نفسها مجموعات مرتبة أخرى.

تُعرَّف المجموعات المرتبة على أنها قيم مفصولة بفواصل بين `#(` و`)`: `#(1, 2.0, "Three")`.

```gleam
#("one", 2)      // Tuple pair (2 values)
#("one", 2, 3.0) // Tuple triplet (3 values)
```

يمكن مقارنة المجموعات المرتبة التي لها الطول نفسه والأنواع نفسها (بالترتيب نفسه) للتحقق من تساويها.

```gleam
#(1, 2) == #(1, 2) // Same length, same types, same values, same order
// -> True

#(1, 2) == #(2, 1) // Same length, same types, same values, different order
// -> False

#(1, 2) == #(1, "2") // Same length, different types
// Compile error!

#(1, 2) == #(1, 2, 3) // Different length
// Compile error!
```

يمكنك استخراج القيم الموجودة داخل المجموعة المرتبة بثلاثة أساليب:

- الفهرسة.
- مطابقة الأنماط باستخدام `let`.
- مطابقة الأنماط باستخدام `case`.

```gleam
let person = #("Jordan", 52)

// Option 1: Indexing
person.0 // -> "Jordan"
person.1 // -> 52

// Option 2: let
let #(name2, length2) = person
// -> name2 = "Jordan"
// -> length2 = 52

// Option 3: case
case person {
  #(name3, length3) -> {
    name3   // -> "Jordan"
    length3 // -> 52
  }
}
```

يمكن استخدام فهرسة المجموعات المرتبة داخل حراس تعبيرات `case`.

```gleam
pub fn is_18(person) {
  case person {
    _ if person.1 >= 18 -> True
    _ -> False
  }
}
```
