# التعليمات

في هذا التمرين ستكتب بعض الكود لمساعدتك على طهي لازانيا رائعة من كتاب الطبخ المفضل لديك.

لديك أربع مهام، وكلها تتعلق بالوقت المستغرق في طهي اللازانيا.

~~~~exercism/note
هذه هي التعليمات المذكورة في هذا المفهوم:

| التعليمة | الوصف                     |
|-------------|---------------------------------|
| mov a, b    | تنسخ المحتوى من `b` إلى `a` |
| add a, b    | a = a + b                       |
| sub a, b    | a = a - b                       |
| imul a, b   | a = a * b                       |
| call a      | تستدعي الدالة `a`                |
| ret         | تعود من الدالة         |
~~~~

## 1. حدّد زمن الفرن المتوقع بالدقائق

عرّف الدالة `expected_minutes_in_oven` التي لا تأخذ أي معاملات وتُرجع عدد الدقائق التي ينبغي أن تبقى فيها اللازانيا في الفرن.
وفقًا لكتاب الطبخ، فإن زمن الفرن المتوقع بالدقائق هو 40:

```c
expected_minutes_in_oven();
// => 40
```

## 2. احسب زمن الفرن المتبقي بالدقائق

عرّف الدالة `remaining_minutes_in_oven` التي تأخذ عدد الدقائق الفعلية التي قضتها اللازانيا في الفرن كمعامل وتُرجع عدد الدقائق التي لا يزال يتعين على اللازانيا أن تبقى فيها في الفرن، بناءً على زمن الفرن المتوقع بالدقائق من المهمة السابقة.

```c
remaining_minutes_in_oven(30);
// => 10
```

## 3. احسب زمن التحضير بالدقائق

عرّف الدالة `preparation_time_in_minutes` التي تأخذ عدد الطبقات التي أضفتها إلى اللازانيا كمعامل وتُرجع عدد الدقائق التي قضيتها في تحضير اللازانيا، بافتراض أن تحضير كل طبقة يستغرق منك دقيقتين.

```c
preparation_time_in_minutes(2);
// => 4
```

## 4. احسب الزمن المنقضي بالدقائق

عرّف الدالة `elapsed_time_in_minutes` التي تأخذ معاملين، بهذا الترتيب:

1. عدد الطبقات التي أضفتها إلى اللازانيا.
2. عدد الدقائق التي قضتها اللازانيا في الفرن.

ينبغي أن تُرجع الدالة عدد الدقائق التي عملتها في طهي اللازانيا.
وهذا هو مجموع زمن التحضير بالدقائق، والزمن بالدقائق الذي قضته اللازانيا في الفرن في تلك اللحظة.

```c
elapsed_time_in_minutes(3, 20);
// => 26
```
