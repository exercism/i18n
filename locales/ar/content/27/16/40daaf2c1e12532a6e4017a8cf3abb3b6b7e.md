# نبذة

## مقدمة

الأنواع العامة ميزة في اللغة تتيح إعادة استخدام الكود.
على سبيل المثال، لا ينبغي أن يهم نوع العناصر التي تحملها المصفوفة عند حساب طولها.
لهذا السبب تستخدم دالة `length` معامل نوع عام اسمه `a` في توقيع النوع الخاص بها.

```elm
length : List a -> Int
```

## معاملات الأنواع

عندما يكون نوع ما عامًّا بالنسبة إلى نوع آخر، نستخدم اسمًا بحروف صغيرة لذلك النوع الآخر، ونسميه معامل النوع.
من الأمثلة الشائعة الأنواع المخصصة `List` و`Maybe` و`Result`.

```elm
-- Maybe is generic over the type a
type Maybe a
    = Nothing
    | Just a

someString : Maybe String
someString = Just "hello"

someInt : Maybe Int
someInt = Just 42
```

من الملاحظات المهمة حول أسماء معاملات الأنواع أنها قد تتكون من أكثر من حرف.
الشرط الوحيد هو أن تكون أسماءها بحروف صغيرة.
لذلك، عندما يكون ذلك مفيدًا، نميل إلى إعطائها أسماء وصفية.

يمكن أن يكون النوع عامًّا بالنسبة إلى عدة أنواع أخرى، وبالتالي أن يمتلك عدة معاملات أنواع.
في هذه الحالة، يحصل كل نوع مستقل على اسم مختلف بحروف صغيرة.
كونها مستقلة لا يمنعها من أن تصبح النوع نفسه، بل يتيح لها فقط أن تكون مختلفة.

```elm
-- Result is generic over the types error and value
type Result error value
    = Ok value
    | Err error
```

يمكن أن تحتوي الأسماء المستعارة لأنواع السجلات أيضًا على معاملات أنواع، وإن كان ذلك أقل شيوعًا.

```elm
-- Event is generic over the type a
type alias Event a =
    { at : Time
    , data : a 
    }
```

## معاملات الأنواع في الدوال

بما أن الأنواع يمكن أن تكون عامة، فكذلك يمكن للدوال.
يمكن كتابة دوال تتعامل مع أنواع عامة، مثل `Maybe.withDefault`.

```elm
withDefault : a -> Maybe a -> a
withDefault default maybe =
    case maybe of
      Just value -> value
      Nothing -> default
```

الدوال التي تأخذ دوالًا أخرى كمعاملات تُسمى الدوال عالية الرتبة، ويمكن أن تكون هذه أيضًا عامة.

```elm
map : (a -> b) -> Maybe a -> Maybe b
map function maybe =
  case maybe of
    Just value ->
      Just (function value)

    Nothing ->
      Nothing
```
