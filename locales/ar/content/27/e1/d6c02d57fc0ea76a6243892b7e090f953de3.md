# مقدمة

إن `string` في F# كائن يمثّل نصًا غير قابل للتغيير على هيئة تتالية من محارف Unicode (الحروف والأرقام وعلامات الترقيم، إلخ)، ويُعرَّف على النحو التالي:

```fsharp
let fruit = "Apple"
```

يتم التعامل مع السلاسل النصية إما باستدعاء طُرق السلسلة النصية، أو باستخدام دوال وحدة `String`. وبمجرد إنشاء سلسلة نصية، لا يمكن أن تتغير قيمتها أبدًا. وأي طُرق أو دوال تبدو وكأنها تعدّل السلسلة النصية ستُرجع في الحقيقة سلسلة نصية جديدة.

يمكن دمج السلاسل النصية أو تنسيقها بأساليب مختلفة.
* يمكنك استخدام العامل `+` للدمج:
```fsharp
let sentence = "Apple" + " is a type of fruit."
```
* يمكنك استخدام الدالة `sprintf` لتنسيق النص، حيث تضع عناصر نائبة في نص تنسيقي (`%s` تمثّل `string`) وتمرّر القيم كوسائط:
```fsharp
let sentence = sprintf "%s is a type of %s." "Apple" "fruit"
```
