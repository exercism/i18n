# مقدمة

في Go، `map` نوع بيانات مدمج يربط المفاتيح بالقيم.
في لغات البرمجة الأخرى، قد تكون على دراية بمفهوم `map` كقاموس، أو جدول تجزئة، أو مخزن مفتاح/قيمة، أو مصفوفة ترابطية.

من الناحية التركيبية، يبدو `map` هكذا:

```go
map[KeyType]ElementType
```

من المهم أيضًا معرفة أن كل مفتاح فريد، مما يعني أن إسناد المفتاح نفسه مرتين سيؤدي إلى الكتابة فوق قيمة المفتاح المقابل.

لإنشاء خريطة، يمكنك القيام بما يلي:

```go
  // With map literal
  foo := map[string]int{}
```

أو

```go
  // or with make function
  foo := make(map[string]int)
```

إليك بعض العمليات التي يمكنك إجراؤها على خريطة

```go
  // Add a value in a map with the `=` operator:
  foo["bar"] = 42
  // Here we update the element of `bar`
  foo["bar"] = 73
  // To retrieve a map value, you can use
  baz := foo["bar"]
  // To delete an item from a map, you can use
  delete(foo, "bar")
```

إذا حاولت استرداد قيمة مفتاح غير موجود في الخريطة، فستُرجع القيمة الصفرية لنوع القيمة.
قد يربكك هذا، خاصةً إذا كانت قيمة `ElementType` الافتراضية لديك (على سبيل المثال، 0 لـ int) قيمةً صالحة.
للتحقق مما إذا كان المفتاح موجودًا في الخريطة، يمكنك استخدام

```go
  value, exists := foo["baz"]
  // If the key "baz" does not exist,
  // value: 0; exists: false
```
