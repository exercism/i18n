# التعليمات

أنت تنشئ بوابة إلكترونية جديدة ليتمكن عملاؤك من طلب فاكهتهم طازجة من البقال.
لدى البقال API يمكنك استخدامها لمعرفة ما إذا كان يمتلك المخزون الذي يريده عملاؤك.
تحتاج إلى إنشاء مكتبة صغيرة من الدوال للتفاعل مع API البقال.

## 1. أبلغ عميلك عندما ينجح طلبه

على البوابة أن تُبلغ عميلك إذا نجح طلبه.
عرّف دالة الاستدعاء الراجعة `onSuccess` التي ستُستدعى إذا نجح الطلب لأن البقال لديه فاكهة كافية في المخزون.
ينبغي أن تستدعي هذه الدالة الدالة `notify` المستوردة، وتمرّر إليها `{ message: 'SUCCESS' }` لإعلام عميلك بنجاح طلبه.

```javascript
onSuccess();
// => `notify` called with `{ message: 'SUCCESS' }`
```

## 2. أبلغ عميلك عندما يفشل طلبه

على البوابة أن تُبلغ عميلك إذا فشل طلبه.
عرّف دالة الاستدعاء الراجعة `onError` التي ستُستدعى إذا فشل الطلب لأن البقال _لا يملك_ الفاكهة في المخزون أو حدث خطأ.
ينبغي أن تستدعي هذه الدالة الدالة `notify` المستوردة، وتمرّر إليها `{ message: 'ERROR' }` لإعلام عميلك بفشل طلبه.

```javascript
onError();
// => `notify` called with `{ message: 'ERROR' }`
```

## 3. أنشئ غلاف API حول دالة طلب البقال

تُقدَّم طلبات الفاكهة عبر API البقال من خلال الدالة `order` المتاحة.
تستقبل هذه الدالة ثلاثة وسائط: _استعلام_ يحتوي على `variety` و`quantity` للفاكهة المطلوبة، ودالة _استدعاء راجعة_ تُستدعى عند نجاح الطلب، ودالة _استدعاء راجعة_ تُستدعى عندما يواجه الطلب خطأ.

تريد أن تعزل الكود الخاص بك عن التغييرات الخارجية المحتملة، فتقرّر أن تلفّ الاستدعاء إلى الدالة `order` داخل دالة جديدة باسم `orderFromGrocer`.
نفّذ الدالة `orderFromGrocer` التي تحاول تقديم طلب عبر استدعاء الدالة `order` في API البقال، مع الحرص على تمرير الوسائط التي يستقبلها `orderFromGrocer` إلى استدعاء API.

يتخذ الاستعلام شكل _كائن_:

```typescript
const query = {
  variety: string,
  quantity: number,
};
```

```javascript
orderFromGrocer(
  { variety: 'pear', quantity: 12 },
  exampleSuccessCallback,
  exampleErrorCallback,
);
// => `order` was called with the query and the callbacks
```

## 4. بسّط التعامل مع الطلبات المُقدَّمة

أصبح عملاؤك الآن قادرين على تقديم طلبات الفاكهة عبر بوابتك، لكنك تلاحظ أنك تستدعي الدالة `orderFromGrocer` في أماكن كثيرة مختلفة في الكود، وفي كل مرة عليك تمرير `query` ودالتَي `callback` كوسائط.
وبعد أن سنحت لك فرصة إعادة هيكلة الكود، ترى أنه سيكون أبسط لو تمكنت من تقديم طلب بمجرد تمرير `variety` و`quantity` للفاكهة المطلوبة.
عرّف الدالة المساعدة `postOrder` التي تأخذ `variety` و`quantity` كوسائط وتحاول تقديم طلب إلى البقال.

```javascript
postOrder('peach', 100);
// => order placed for 100 peaches
```
