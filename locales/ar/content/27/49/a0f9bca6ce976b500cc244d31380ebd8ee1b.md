# التعليمات

في هذا التمرين ستتعامل مع أسطر السجل.

كل سطر سجل هو سلسلة نصية مُنسّقة على النحو التالي: `"[<LVL>]: <MESSAGE>"`.

هذه هي مستويات السجل المختلفة:

- `TRC` (تتبع)
- `DBG` (تصحيح)
- `INF` (معلومات)
- `WRN` (تحذير)
- `ERR` (خطأ)
- `FTL` (خطأ فادح)

لديك ثلاث مهام.

## 1. تحليل مستوى السجل

عرّف تعداد `LogLevel` يحتوي على ستة عناصر تقابل مستويات السجل المذكورة أعلاه.

- `Trace`
- `Debug`
- `Info`
- `Warning`
- `Error`
- `Fatal`

بعد ذلك، نفّذ الطريقة (_static_) `LogLine.ParseLogLevel()` لتحليل مستوى السجل في سطر السجل:

```csharp
LogLine.ParseLogLevel("[INF]: File deleted")
// => LogLevel.Info
```

## 2. دعم مستوى سجل غير معروف

لسوء الحظ، تحتوي بعض أسطر السجل أحيانًا على مستوى سجل غير معروف. للتعامل مع أسطر السجل هذه بسلاسة، أضف عنصرًا `Unknown` إلى تعداد `LogLevel`، ويجب إرجاعه عند تحليل مستوى سجل غير معروف:

```csharp
LogLine.ParseLogLevel("[XYZ]: Overly specific, out of context message")
// => LogLevel.Unknown
```

## 3. تحويل سطر السجل إلى صيغة مختصرة

مستوى السجل في سطر السجل مُطوّل جدًا. لتقليل مساحة القرص اللازمة لتخزين أسطر السجل، طُوّرت صيغة مختصرة: `"[<ENCODED_LEVEL>]:<MESSAGE>"`.

مستوى السجل المُرمّز هو تعيين بسيط من مستوى السجل إلى عدد:

- `Unknown` - `0`
- `Trace` - `1`
- `Debug` - `2`
- `Info` - `4`
- `Warning` - `5`
- `Error` - `6`
- `Fatal` - `42`

نفّذ الطريقة (_static_) `LogLine.OutputForShortLog()` التي يمكنها إخراج صيغة سطر السجل المختصرة:

```csharp
LogLine.OutputForShortLog(LogLevel.Error, "Stack overflow")
// => "6:Stack overflow"
```
