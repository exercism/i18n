# نبذة

يحتوي النوع المنطقي في Lua على القيمتين المنطقيتين التقليديتين: `true` و`false`. يمكن إسناد هذه القيم إلى متغير، ودمجها بالعوامل المنطقية (`and` و`or` و`not`)، واستخدامها في الاختبارات الشرطية (مثل بنى التحكم).

```lua
local is_true = true
local is_false = false

true and true  --> true
true and false --> false
false or true  --> true
false or false --> false
not false      --> true
not true       --> false

-- prints 0
if is_true == true then
  print(0)
else
  print(1)
end
```

تعتبر الاختبارات الشرطية والعوامل المنطقية كلا من `false` و`nil` خطأً، وأي شيء آخر صحيحًا.

```lua
1 and 2          --> 2
nil and 2        --> nil
false and 2      --> false
1 or 2           --> 1
false or 'hello' --> "hello"
nil or false     --> false
```

يستخدم كلٌّ من `and` و`or` *التقييم القصير*، أي أنهما لا يقيّمان معاملهما الثاني إلا عند الحاجة. وتُقيَّم جميع العمليات وفقًا لـ[أسبقية العوامل](https://www.lua.org/manual/5.4/manual.html#3.4.8)، حيث يُقيَّم `not` قبل `and` و`or`.

وبما أن `false` و`nil` هما وحدهما ما يُعتبر خطأً، وأن كل شيء آخر صحيح، فإن من التعابير الشائعة في Lua:

```lua
x = x or y
```

وهو مكافئ لـ:

```lua
if not x then
  x = y
end
```

ومن الشائع جدًا استخدام هذا في الدوال لإسناد قيمة افتراضية إذا لم يكن للمعامل قيمة (أي أنه `nil`):

```lua
local function hello(name)
  name = name or "World"
  print("Hello " .. name)
end

hello()       --> "Hello World"
hello('Mars') --> "Hello Mars"
```
