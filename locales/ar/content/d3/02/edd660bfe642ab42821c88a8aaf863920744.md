# مقدمة

يمكن أن تحتوي الطرق على معامل متغيّر الوسائط، وهو يسمح للمستدعي بتحديد صفر أو أكثر من الوسائط كما لو كانت معاملات عادية. وتستقبل الطريقة هذه الوسائط في مصفوفة واحدة.

لتحويل معامل إلى معامل متغيّر الوسائط، أضف الكلمة المفتاحية `params` إلى تصريح المعامل:

```csharp
public static void PrintNumbers(params int[] numbers)
{
    foreach (var number in numbers)
    {
        Console.Write(number)
    }
}

// No values for a varags parameter is allowed
PrintNumbers();

PrintNumbers(1);
// => 1

PrintNumbers(1, 2, 3);
// => 123
```
