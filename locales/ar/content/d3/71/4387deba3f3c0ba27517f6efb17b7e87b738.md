# مقدمة

تحتوي Pyret على قيمتين منطقيتين بدائيتين مختلفتين، هما `true` و`false`.
تمثل هاتان القيمتان ما إذا كانت عبارة أو شرط صالحًا أم لا.

```pyret
"a" == "a" # true
"a" == "b" # false
```

توفّر Pyret عاملي `and` و`or` اللذين يمكنهما دمج القيم المنطقية.

يُرجع عامل `and` صحيح إذا كان الطرفان صحيحين، وخطأ في جميع التركيبات الأخرى.

```pyret
true and true # true
true and false # true
false and true # false
false and false # false
```

يُرجع عامل `or` صحيح إذا كان أحد الطرفين على الأقل صحيحًا، وخطأ إذا كان كلا الطرفين غير صحيحين.

```pyret
true or true # true
true or false # true
false or true # true
false or false # false
```

`not()` دالة مدمجة تقلب صحيحًا إلى خطأ أو خطأً إلى صحيح.

```pyret
not(true) # false
not(false) # true
```
