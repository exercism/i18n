# التثبيت

## Windows (موصى به)

هل تستخدم نظام تشغيل Windows؟

اضغط `Windows Key`، واكتب `cmd`، ثم اضغط `enter`.

> لغة Batch مثبّتة بالفعل على نظامك إذا كان نظام تشغيلك هو Windows.

إذا كنت تستخدم نظام تشغيل مختلفًا، يمكنك تثبيت Batch باتباع التعليمات أدناه.

## Mac OS

1. يجب ألا يكون Gatekeeper مضبوطًا على حظر الحزم غير الموقّعة.
2. افتح تطبيق Terminal.
3. نفّذ الأمر التالي لتثبيت Batch:

```bash
brew install --cask --no-quarantine wine-stable
```

## Ubuntu

1. إذا كان نظامك 64 بت، فعّل معمارية 32 بت (إن لم تكن قد فعلت ذلك بالفعل):

```bash
sudo dpkg --add-architecture i386
```

2. أضف مستودع WineHQ:

```bash
sudo mkdir -pm755 /etc/apt/keyrings
sudo wget -O /etc/apt/keyrings/winehq-archive.key https://dl.winehq.org/wine-builds/winehq.key
sudo apt update
```

3. ثبّت WineHQ:

```bash
sudo apt install --install-recommends winehq-stable
```

## Fedora

1. فعّل مستودع Wine:

```bash
# Fedore 39
dnf config-manager --add-repo https://dl.winehq.org/wine-builds/fedora/39/winehq.repo

# Fedora 40
dnf config-manager --add-repo https://dl.winehq.org/wine-builds/fedora/40/winehq.repo
```

2. ثبّت WineHQ:

```bash
dnf install winehq-stable
```
