# مقدمة

## Maybe

النوع `Maybe` هو الحل في لغة Elm للقيم الاختيارية.
لذلك يظهر في توقيعات الأنواع لعدد كبير من دوال Elm الأساسية، وفهمه أمر بالغ الأهمية.
يُعرَّف النوع `Maybe` كما يلي:

```elm
type Maybe a = Nothing | Just a
```

يُعرف هذا باسم تعريف «النوع المخصص» في مصطلحات Elm.
وهو يشير إلى أن قيمة من هذا النوع يمكن أن تكون إما `Nothing` أو أن تكون `Just` شيئًا من النوع `a`.
يتم إنشاء قيمة `Maybe` باستخدام أحد مُنشئَيها: `Nothing` و`Just`.
وتتم قراءة محتوى `Maybe` عبر مطابقة الأنماط.

```elm
matthieu : Maybe String
matthieu = Just "Matthieu"

anon : Maybe String
anon = Nothing

sayHello : Maybe String -> String
sayHello maybeName =
    case maybeName of
        Nothing -> "Hello, World!"
        Just someName -> "Hello, " ++ someName ++ "!"

sayHello matthieu
    --> "Hello, Matthieu!"

sayHello anon
    --> "Hello, World!"
```

هناك أيضًا عدد من الدوال المفيدة في وحدة `Maybe` للتعامل مع أنواع `Maybe`.

```elm
sayHelloAgain : Maybe String -> String
sayHelloAgain name = "Hello, " ++ Maybe.withDefault "World" name ++ "!"

capitalizeName : Maybe String -> Maybe String
capitalizeName name = Maybe.map String.toUpper name

capitalizeName matthieu
    --> Just "MATTHIEU"

capitalizeName anon
    --> Nothing
```
