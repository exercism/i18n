# التعليمات

أثناء استعدادك لخبز البسكويت لأصدقائك، اكتشفت أنك بحاجة إلى تحويل بعض القياسات المستخدمة في الوصفة. وبما أنك لا تعرف سوى النظام المتري، فأنت بحاجة إلى إيجاد طريقة لتحويل قياسات الخبز الأمريكية الشائعة إلى ملليلترات (mL) لتسهيل الأمر عليك.

استخدم جدول التحويل التالي في حلّك:

| الوحدة المراد تحويلها | الحجم | بالمليلتر (mL) |
| --------------- | ------ | ------------------- |
| mL              | 1      | 1                   |
| كوب أمريكي          | 1      | 240                 |
| أونصة سائلة أمريكية  | 1      | 30                  |
| ملعقة صغيرة أمريكية     | 1      | 5                   |
| ملعقة كبيرة أمريكية   | 1      | 15                  |

ولأنك مبرمج موهوب لا يزال في طور التدريب، تقرر استخدام الملليلترات كوحدة انتقالية لتسهيل التحويل من أي وحدة مدرجة إلى أي وحدة أخرى (حتى إلى نفسها).

## 1. الحصول على المكوّن العددي من زوج الحجم

نفّذ الدالة `KitchenCalculator.get_volume/1`. عند تمرير زوج حجم إليها، يجب أن تُرجع المكوّن العددي فقط.

```elixir
KitchenCalculator.get_volume({:cup, 2.0})
# => 2.0
```

## 2. تحويل زوج الحجم إلى ملليلترات

نفّذ الدالة `KitchenCalculator.to_milliliter/1`. عند تمرير زوج حجم إليها، يجب أن تحوّل الحجم إلى ملليلترات باستخدام جدول التحويل.

استخدم عدة بنود للدالة ومطابقة الأنماط لإنشاء دوال لكل وحدة. الذرات المستخدمة للدلالة على كل وحدة هي: `:cup`، `:fluid_ounce`، `:teaspoon`، `:tablespoon`، `:milliliter`. ويجب أن تُرجع نتيجة التحويل ملفوفة في زوج.

```elixir
KitchenCalculator.to_milliliter({:cup, 2.5})
# => {:milliliter, 600.0}
```

## 3. تحويل زوج الحجم بالمليلتر إلى وحدة أخرى

نفّذ الدالة `KitchenCalculator.from_milliliter/2`. عند تمرير زوج حجم والوحدة المطلوبة إليها، يجب أن تحوّل الحجم إلى الوحدة المطلوبة باستخدام جدول التحويل.

استخدم عدة بنود للدالة ومطابقة الأنماط لإنشاء دوال لكل وحدة. الذرات المستخدمة للدلالة على كل وحدة هي: `:cup`، `:fluid_ounce`، `:teaspoon`، `:tablespoon`، `:milliliter`

```elixir
KitchenCalculator.from_milliliter({:milliliter, 1320.0}, :cup)
# => {:cup, 5.5}
```

## 4. التحويل من أي وحدة إلى أي وحدة

نفّذ الدالة `KitchenCalculator.convert/2`. عند تمرير زوج حجم والوحدة المطلوبة إليها، يجب أن تحوّل الحجم المعطى إلى الوحدة المطلوبة.

```elixir
KitchenCalculator.convert({:teaspoon, 9.0}, :tablespoon)
# => {:tablespoon, 3.0}
```
