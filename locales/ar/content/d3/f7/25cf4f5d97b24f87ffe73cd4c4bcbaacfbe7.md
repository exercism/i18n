# نبذة

ColdFusion (CFML) لغة برمجة نصية تعمل على JVM وبنيتها مشابهة لـ C أو JavaScript. 
تُترجم لحظة التشغيل (JIT) إلى كود بايت يعمل على JVM، لكنها ديناميكية وذات أنواع مرنة، ما يجعل التطوير بها سريعًا وسهلًا. 
CF لغة متعددة الأنماط، تدعم البرمجة الكائنية التقليدية والبرمجة الدالية.

كما تمتلك CFML لغة قوالب مدمجة قائمة على الوسوم تجعلها مثالية لتطبيقات الويب. 
وتعمل داخل حاوية J2EE مع كثير من المكتبات المرفقة التي تزيد إنتاجيتها دون الحاجة إلى تثبيت حزم كثيرة. 
ولـ CFML دعم مدمج لملفات zip، وإنشاء PDF وExcel، والبريد الإلكتروني، وFTP، وHTTP، وأنظمة ملفات S3، ومكتبات ESAPI الأمنية، ومشغلات JDBC، وJSON و REST APIs.  

يمكن لـ CFML أيضًا الاستفادة من أي مشروع Java بمجرد وضع ملفات jar في المشروع وإنشاء كائنات Java مباشرة في الكود.
