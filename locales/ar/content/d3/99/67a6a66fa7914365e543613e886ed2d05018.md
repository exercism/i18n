## استخدام تعبيرات `use`

في Gleam من الشائع كتابة الدوال عالية الرتبة واستخدامها، أي الدوال التي تأخذ دوالًا أخرى كوسائط. وأحيانًا، عند استخدام العديد من الدوال عالية الرتبة في آنٍ واحد، قد يصبح الكود صعب القراءة بسبب كثرة مستويات الإزاحة.

على سبيل المثال، إليك دالة تستدعي عدة دوال تُرجع `Result(Int, Nil)`، وتجمع القيم إذا نجحت الأربع جميعًا.

```gleam
import gleam/result

pub fn main() -> Result(Int, Nil) {
  result.try(function1(), fn(a) {
    result.try(function2(), fn(b) {
      result.try(function3(), fn(c) {
        result.try(function4(), fn(d) {
          Ok(a + b + c + d)
        })
      })
    })
  })
}
```

تسمح لنا تعبيرات `use` في Gleam بكتابة هذا الكود دون الإزاحة، مما يجعله غالبًا أسهل في القراءة.

```gleam
import gleam/result

pub fn main() -> Result(Int, Nil) {
  use a <- result.try(function1())
  use b <- result.try(function2())
  use c <- result.try(function3())
  use d <- result.try(function4())
  Ok(a + b + c + d)
}
```

يجمع تعبير `use` كل العبارات التي تليه في الكتلة، ويمرّرها كدالة استدعاء راجعة كوسيط أخير إلى استدعاء الدالة. والمتغيرات الواقعة بين الكلمة المفتاحية `use` ورمز `<-` هي أسماء الوسائط التي ستُمرَّر إلى دالة الاستدعاء الراجعة.

```gleam
// This use expression
use a <- function(1, 2)
io.println("Hello!")
a

// Is equivalent to this normal function call
function(1, 2, fn(a) {
  io.println("Hello!")
  a
})
```

يمكن لدالة الاستدعاء الراجعة أن تأخذ أي عدد من الوسائط، أو ألا تأخذ أي وسيط على الإطلاق.

```gleam
use a, b, c, d <- call_4_function()

use <- call_0_function()
```

لا توجد متطلبات خاصة لإنشاء دالة يمكن استدعاؤها بتعبير `use`، عدا أن تأخذ دالة استدعاء راجعة كوسيط أخير.

```gleam
pub fn call_twice(function: fn() -> t) -> #(t, t) {
  let first = function()
  let second = function()
  #(first, second)
}
```

تعبيرات `use` في Gleam ميزة قوية جدًا يمكن تطبيقها على الكثير من المسائل، لكن الإفراط في استخدامها قد يجعل الكود صعب القراءة. ويُفضَّل عمومًا استخدام صيغة استدعاء الدوال العادية، وألا نلجأ إلى تعبيرات `use` إلا عندما تجعل الكود أسهل في القراءة.
