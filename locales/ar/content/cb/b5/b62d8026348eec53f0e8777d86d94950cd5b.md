# التعليمات

أنت متحمّس للانضمام إلى Paola's Prestigious Pizza كمدير مطعم جديد.
لديك خطط كثيرة لإدارة المكان بكفاءة، وللقيام بذلك تحتاج إلى بعض البيانات.
أولًا وقبل كل شيء، عليك تحليل قائمة الطعام.

على قائمة الطعام أنواع كثيرة من البيتزا، وقد أعطتك Paola قائمة في ملف نصي، بواقع بيتزا واحدة في كل سطر.
يتكوّن كل صنف بيتزا من ثلاثة عناصر: الاسم، ومؤشر نباتي اختياري، وسعر.

## 1. تحليل سعر البيتزا

تنظر إلى أول سطرين من قائمة الطعام:

```
Regina: tomato, ham, mushrooms, cantal - 11€
Formaggio (v): tomato, emmental - 8€
...
```

يبدو السعر نقطة بداية جيدة.
جميع الأسعار أعداد صحيحة بعملة اليورو.

نفّذ `priceParser` لتحليل الأسعار.
بما أن جميع الأسعار باليورو، فلست بحاجة إلى تتبّع العملة، وإن كنت لا تزال بحاجة إلى تحليلها.

```elm
Parser.run priceParser "8€"
    --> Ok 8
Parser.run priceParser "8"
    --> Err [{ problem = ExpectingSymbol "€", col = 2, row = 1 }]
```

## 2. تحليل مؤشر النباتية

تنظر إلى قائمة الطعام مرة أخرى:

```
Regina: tomato, ham, mushrooms, cantal - 11€
Formaggio (v): tomato, emmental - 8€
...
```

مؤشر النباتية `"(v)"` بسيط أيضًا، فتقرّر أن تنتقل إليه بعد ذلك!

نفّذ `vegetarianParser` لتحليل المؤشر.
ينبغي أن يُرجع المحلّل قيمة `Bool`، وهي `True` إذا كان المؤشر موجودًا و`False` خلاف ذلك.

```elm
Parser.run vegetarianParser "(v)"
    --> Ok True
Parser.run vegetarianParser ""
    --> Ok False
```

## 3. تحليل أسماء البيتزا والمكوّنات

حسنًا، ما التالي؟

```
Regina: tomato, ham, mushrooms, cantal - 11€
Formaggio (v): tomato, emmental - 8€
...
```

تبدو أسماء المكوّنات والبيتزا واضحة تمامًا: فكلها كلمات مفردة مكوّنة من أحرف ASCII كبيرة وصغيرة.

نفّذ `wordParser` لتحليل الأسماء.
وبينما أنت في ذلك، اجعل جميع الكلمات بأحرف صغيرة لتحقيق التناسق.

```elm
Parser.run wordParser "REGINA"
    --> Ok "regina"
Parser.run wordParser "tomato"
    --> Ok "tomato"
Parser.run wordParser "(v)"
    --> Ok ""
Parser.run wordParser ""
    --> Ok ""
```

## 4. تحليل قائمة مكوّنات

غير أن المكوّنات تأتي في مجموعة:

```
Regina: tomato, ham, mushrooms, cantal - 11€
Formaggio (v): tomato, emmental - 8€
...
```
إنها كلمات مفردة تفصل بينها فواصل، وربما مسافات أيضًا.

نفّذ `ingredientsParser` لتحليل المكوّنات.

```elm
Parser.run ingredientsParser "tomato, emmental"
    --> Ok ["tomato", "emmental"]
Parser.run ingredientsParser "tomato"
    --> Ok ["tomato"]
```

## 5. تحليل بيتزا كاملة

الآن وقد حصلت على جميع المكوّنات، حان وقت صنع بعض `Pizza`!

```
Regina: tomato, ham, mushrooms, cantal - 11€
Formaggio (v): tomato, emmental - 8€
...
```

أولًا لديك اسم البيتزا، ثم المؤشر النباتي الاختياري، ثم نقطتان `':'`، فقائمة المكوّنات، فشرطة `'-'`، ثم السعر، مع احتمالية وجود مسافات متفرقة.

نفّذ `pizzaParser` لتحليل البيتزا الكاملة.

```elm
Parser.run pizzaParser "Regina: tomato, ham, mushrooms, cantal - 11€"
    --> Ok (Pizza "regina" False ["tomato", "ham", "mushrooms", "cantal"] 11)
```

## 6. تحليل القائمة الكاملة

وقت الاحتفال!

نفّذ `menuParser` لتحليل قائمة بجميع البيتزا مفصولة بمحرف سطر جديد `'\n'` في الملف النصي.
تأكّد من أنك التقطت جميع البيتزا بتشغيل المحلّل حتى يصل إلى نهاية الملف.

```elm
Parser.run menuParser "Regina: tomato, ham, mushrooms, cantal - 11€\nFormaggio (v): tomato, emmental - 8€"
    --> Ok [Pizza "regina" False ["tomato", "ham", "mushrooms", "cantal"] 11,
    --      Pizza "formaggio" True ["tomato", "emmental"] 8]
Parser.run menuParser "Regina: tomato, ham, mushrooms, cantal - 11€\[END]"
    --> Err [{ problem = ExpectingEnd, col = 1, row = 2 }]
```

## 7. تحليل أسماء المكوّنات متعددة الكلمات

أوه لا، يبدو أنك أغفلت شيئًا.
في مكان أبعد في القائمة، بعض المكوّنات ليست كلمات مفردة:

```
...
Tonno: tomato sauce, tuna - 10€
Hawaii: tomato sauce, fresh pineapple, ham - 9€
...
```

نفّذ `oneIngredientParser` الذي سيقبل أحرف ASCII الكبيرة والصغيرة أو المسافات `' '`.
واغتنم الفرصة لتجنّب خلل صغير كان في `wordParser`، بالتأكد من أن السلاسل النصية الفارغة لا تُعتبر مكوّنات صالحة، وأن تُصدر بدلًا من ذلك `Problem "empty string"`.
وبينما أنت في ذلك، احرص على جعل السلاسل النصية بأحرف صغيرة، وعلى إزالة محارف المسافات من الجانبين.

```elm
Parser.run oneIngredientParser "Tomato Sauce"
    --> Ok "tomato sauce"
Parser.run oneIngredientParser "   tomato sauce     "
    --> Ok "tomato sauce"
Parser.run oneIngredientParser ""
    --> Err [{ problem = Problem "empty string", col = 1, row = 1 }]
```

بمجرد أن يصبح المحلّل معرّفًا، استخدمه داخل `ingredientsParser`.
