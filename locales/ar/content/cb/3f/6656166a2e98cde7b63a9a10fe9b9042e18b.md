# التعليمات

في هذا التمرين ستتعامل مع سيارة تعمل بالتحكم عن بُعد، وقد ادّخرت أخيرًا ما يكفي من المال لشرائها.

تبدأ السيارة ببطارية ممتلئة بالكامل (100%). وفي كل مرة تقود فيها السيارة باستخدام وحدة التحكم عن بُعد، تقطع 20 مترًا وتستهلك واحدًا في المئة من البطارية.

تحتوي السيارة التي تعمل بالتحكم عن بُعد على شاشة LED أنيقة تعرض معلومتين:

- المسافة الكلية التي قطعتها، وتُعرض بالشكل التالي: `"Driven <METERS> meters"`.
- شحن البطارية المتبقي، ويُعرض بالشكل التالي: `"Battery at <PERCENTAGE>%"`.

إذا وصل شحن البطارية إلى 0%، فلن تتمكن من قيادة السيارة بعد ذلك، وستعرض شاشة البطارية `"Battery empty"`.

لديك ست مهام، وستتعامل كل واحدة منها مع نسخ من السيارة التي تعمل بالتحكم عن بُعد.

## 1. اشترِ سيارة جديدة تمامًا تعمل بالتحكم عن بُعد

نفّذ الطريقة (`_static_`) `JedliksToyCar.buy()` لتُرجع نسخة جديدة تمامًا من السيارة التي تعمل بالتحكم عن بُعد:

```java
JedliksToyCar car = JedliksToyCar.buy();
```

## 2. اعرض المسافة المقطوعة

نفّذ الطريقة `JedliksToyCar.distanceDisplay()` لتُرجع المسافة كما تُعرض على شاشة LED:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.distanceDisplay();
// => "Driven 0 meters"
```

## 3. اعرض نسبة شحن البطارية

نفّذ الطريقة `JedliksToyCar.batteryDisplay()` لتُرجع نسبة شحن البطارية كما تُعرض على شاشة LED:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.batteryDisplay();
// => "Battery at 100%"
```

## 4. حدّث عدد الأمتار المقطوعة عند القيادة

نفّذ الطريقة `JedliksToyCar.drive()` التي تحدّث عدد الأمتار المقطوعة:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.drive();
car.drive();
car.distanceDisplay();
// => "Driven 40 meters"
```

## 5. حدّث نسبة شحن البطارية عند القيادة

حدّث الطريقة `JedliksToyCar.drive()` لتحدّث نسبة شحن البطارية:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.drive();
car.drive();
car.batteryDisplay();
// => "Battery at 98%"
```

## 6. امنع القيادة عند نفاد شحن البطارية

حدّث الطريقة `JedliksToyCar.drive()` بحيث لا تزيد المسافة المقطوعة ولا تنقص نسبة شحن البطارية عند نفاد شحن البطارية (عند 0%):

```java
JedliksToyCar car = JedliksToyCar.buy();

// Drain the battery
// ...

car.distanceDisplay();
// => "Driven 2000 meters"

car.batteryDisplay();
// => "Battery empty"
```
