# التعليمات

في هذا التمرين ستُنشئ بعض الثوابت اللازمة لتشغيل أحد البنوك.

لديك خمس مهام:

## 1. تمثيل سعر الفائدة الثابت على قرض

أنشئ الثابت العددي غير المحدد النوع `FixedInterestRate` ليحمل قيمة 5% (5/100)، ثم نفّذ الدالة `GetFixedInterestRate` لتُرجعها:

```go
GetFixedInterestRate()
// => 0.05
```

## 2. تمثيل عدد أيام السنة

أنشئ الثابت `DaysPerYear` من النوع `int` ليحمل القيمة 365، ثم نفّذ الدالة `GetDaysPerYear` لتُرجعها:

```go
GetDaysPerYear()
// => 365
```

## 3. تمثيل أشهر السنة

داخل كتلة، استخدم مُعدِّد Go لإنشاء اثني عشر ثابتًا عدديًا غير محدد النوع لتحمل القيم من 1 إلى 12 لأشهر السنة.
سمِّها `Jan` و`Feb` و`Mar` وهكذا، ثم نفّذ الدالة `GetMonth` لتُرجع قيمة شهر معيّن:

```go
GetMonth(Jan)
// => 1
```

## 4. تمثيل رقم حساب

أنشئ الثابت `AccountNo` غير المحدد النوع من نوع السلسلة النصية ليحمل القيمة XF348IJ، ثم نفّذ الدالة `GetAccountNumber` لتُرجعها:

```go
GetAccountNumber()
// => "XF348IJ"
```
