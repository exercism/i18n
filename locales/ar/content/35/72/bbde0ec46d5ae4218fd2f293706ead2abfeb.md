# الحلقات

تفعل **الحلقة** الشيء نفسه مرارًا وتكرارًا.

```sather
   loop
      ...
   end;
```

بمفردها لا تتوقف أبدًا، لذا يجب أن يُنهيها شيء من داخلها.

## مكان لحفظ العدّ

تحتاج الحلقة دائمًا تقريبًا إلى قيمة تتغير مع تقدمها. هذا **متغير**، و`::=` ينشئ واحدًا:

```sather
   total ::= 0;
```

يُسمّى المتغير `total`، ويبدأ من `0`، ويستنتج Sather من `0` أنه يحمل `INT`. بعد ذلك، يضع `:=` قيمة جديدة فيه:

```sather
   total := total + 5;
```

اقرأ ذلك بدءًا من الجزء الأيمن: خذ ما تساويه `total` الآن، وأضف 5، ثم ضع الناتج مرة أخرى في `total`.

يعيش المتغير المُنشأ بهذه الطريقة حتى نهاية الروتين.

## until!

يأخذ `until!` سؤالًا. يُطرح في كل دورة، وعندما تكون الإجابة صحيحة تتوقف الحلقة عندها فورًا.

```sather
   sum_to(last : INT) : INT is
      total ::= 0;
      n ::= 1;
      loop
         until!(n > last);
         total := total + n;
         n := n + 1;
      end;
      return total;
   end;
```

يعدّ `n` القيم 1، 2، 3 ... وتنتهي الحلقة في أول مرة يتجاوز فيها `n` القيمة `last`. لولا `n := n + 1` لما تغيّرت إجابة السؤال أبدًا، ولظلت الحلقة تعمل إلى الأبد.

لا يلزم أن يكون `until!` في السطر الأول. ضعه حيث يكون السؤال منطقيًا: في الأعلى، قد لا تعمل الحلقة مطلقًا؛ وفي الأسفل، تعمل دائمًا مرة واحدة على الأقل.

علامة `!` جزء من الاسم. يميّز Sather أشياء معينة بهذه الطريقة؛ وسيأتي معنى هذه العلامة لاحقًا.

## break!

يُنهي `break!` الحلقة فورًا، دون أي سؤال مرتبط به. يكون مفيدًا عندما يظهر سبب التوقف في منتصف العمل.

```sather
   loop
      if too_far then break!; end;
      ...
   end;
```

لا يعني `until!` و`break!` شيئًا إلا داخل `loop`. ولا يمكن استخدام أيٍّ منهما بمفرده.
