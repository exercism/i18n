# عدم استخدام gofmt

شغّل `gofmt` على الحل، فهي تساعد في تنسيق الكود بلغة Go.

تنسيق الكود في Go مهم جدًا لدى المجتمع.
يمكن ضبط معظم بيئات التطوير المتكاملة على تنسيق الكود تلقائيًا عند كل حفظ. على سبيل المثال:

- يوفّر Visual Studio Code [دعمًا ممتازًا للغة Go](https://code.visualstudio.com/docs/languages/go)
- كما يوفّر Vim [إضافة رائعة للغة Go](https://github.com/fatih/vim-go)
- أما [Jetbrains Goland](https://www.jetbrains.com/go/) فهي بيئة تطوير متكاملة كاملة للغة Go

لتشغيل `gofmt` يدويًا:

```bash
# will only show the differences
gofmt -d filename.go

# will apply the changes
gofmt -w filename.go
```

```git
%{gofmt}
```
