# مقدمة

يناقش هذا التمرين بعض تفاصيل معاملات الطرق واستخدامها في C#.

المعاملات تنقل المعلومات من طريقةٍ مستدعية إلى طريقةٍ مستدعاة.

- يمكن تعديل سلوك المعاملات باستخدام معدِّلات مثل `ref` و`out`.

- المعامل الذي يحمل المُعدِّل `out` ينقل قيمةً عائدةً من الطريقة المستدعاة إلى المستدعي. ويمكن تمريره إلى الطريقة المستدعاة دون تهيئته، وفي كل الأحوال يُتعامل معه داخل الطريقة المستدعاة كما لو أنه لم يُهيَّأ عند الدخول. ويمكن اكتساب فهم سلوك معدِّلات المعاملات وقواعدها بأسهل طريقة من خلال الأمثلة (انظر أدناه) ورسائل المُصرِّف.

```csharp
void Foo(out int val)
{
    val = 42;
}
void Bar(int val)
{
    val = 42;
}

int importantValue = 1729;
Foo(out importantValue);
var result = importantValue == 42;
// => true

importantValue = 1729;
Bar(importantValue);
result = importantValue == 1729;
// => true
```

- يجب إسناد قيمةٍ إلى معاملات `out` داخل الطريقة المستدعاة.

- المعامل الذي يحمل المُعدِّل `ref` يمرّر قيمةً إلى الطريقة المستدعاة. وعندما تُرجع الطريقة، سيجد المستدعي أي تحديثات أجرتها الطريقة المستدعاة على ذلك المعامل.

```csharp
void Foo(ref int val)
{
    val *= 7;
}

int importantValue = 6;
Foo(ref importantValue);
return importantValue;
// => 42
```

- يجب أن تكون معاملات `ref` متغيرات، لأن الطريقة المستدعاة ستعمل مباشرةً على المعامل كما يراه المستدعي.
- المُعدِّلان `out` و`ref` مطلوبان في توقيع الطريقة المستدعاة وفي موضع الاستدعاء معًا.
