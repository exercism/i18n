# مقدمة

## صيغ استيعاب القوائم

توفّر صيغ الاستيعاب وسيلة لتحويل _Enumerables_ بسهولة وبأسلوب تصريحي.

لتعريف استيعاب بسيط جدًا، يمكننا استخدام الكلمة المفتاحية `for` متبوعة بـ_مُولِّد_ و_كتلة `do`_ تُنشئ القيم الجديدة من القيم المُعدَّدة.

```elixir
for n <- [0, 1, 2, 3], do: n + 1
# => [1, 2, 3, 4]
```

يمكن أن تحتوي صيغ الاستيعاب أيضًا على _مرشّحات_. تُحذف القيم التي لا تجتاز المرشّح من القائمة النهائية:

```elixir
for n <- [0, 1, 2, 3], n > 1, do: n + 1
# => [3, 4]
```

يمكننا تعريف استيعابات أكثر تعقيدًا على عدة أسطر:

```elixir
for {atom, number} <- [a: 1, b: 2, c: 3, d: 4],
    rem(number, 2) == 0 do
  atom
end

# => [:b, :d]
```

يمكن إنشاء _جداء ديكارتي_ باستخدام عدة مُولِّدات. وهذا يعني أن كل قيمة يُولِّدها المُولِّد الأول ستُقرَن مرة واحدة بكل قيمة يُولِّدها المُولِّد الثاني:

```elixir
for x <- [0, 1],
    y <- [0, 1] do
  {x, y}
end

# => [{0, 0}, {0, 1}, {1, 0}, {1, 1}]
```
