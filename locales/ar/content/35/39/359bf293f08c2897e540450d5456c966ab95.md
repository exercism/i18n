# التعليمات

في هذا التمرين، ستساعد حبيبين من المدرسة الثانوية على التعبير عن حبهما على وسائل التواصل الاجتماعي.

## 1. اعرض اسمي الثنائي مفصولين بقلب

يرجى تنفيذ طريقة `HighSchoolSweethearts.DisplaySingleLine()` الثابتة لتستقبل اسمين وتعرضهما مفصولين بقلب.
يجب أن يكون النص المنسّق بعرض 61 محرفًا، مع وجود القلب في منتصف السلسلة النصية.

جميع الأسماء مضمونة لتتسع بسهولة ضمن عرض السطر.

```csharp
HighSchoolSweethearts.DisplaySingleLine("Lance Green", "Pat Riley");
// => "                  Lance Green ♡ Pat Riley                    "
```

## 2. اعرض الأحرف الأولى للثنائي داخل قلب من فن الرسم النصي (ASCII)

نفّذ طريقة `HighSchoolSweethearts.DisplayBanner()` الثابتة، والتي تعرض مجموعتي الأحرف الأولى مفصولتين بعلامة زائد.

```csharp
HighSchoolSweethearts.DisplayBanner("L. G.", "P. R.");
// see the ascii art below
```

## 3. يجب أن نجعل طلاب التبادل الألمان يشعرون بأنهم في وطنهم باستخدام تصريحات تراعي الإعدادات المحلية.

نفّذ طريقة `HighSchoolSweethearts.DisplayGermanExchangeStudents()` الثابتة لعرض تاريخ بدء العلاقة والمدة الزمنية لطلاب التبادل الألمان لدينا.

```csharp
HighSchoolSweethearts.DisplayGermanExchangeStudents("Norbert", "Heidi", new DateTime(2019, 1, 22), 1535.22f);
// => "Norbert and Heidi have been dating since 22.01.2019 - that's 1.535,22 hours"
```
