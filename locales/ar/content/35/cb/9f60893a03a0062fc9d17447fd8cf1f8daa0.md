# العامل الثلاثي

يوفّر العامل الثلاثي صيغة بديلة لإجراء مقارنة `if..else..` وإرجاع قيمة.

## الصيغة

يوفّر PHP جملة شرطية يمكن فيها تقييم إجراء بناءً على "صوابية" الشرط.

```php
if ($condition) {
  $value = 1;
} else {
  $value = 2
}
```

وبدلًا من ذلك، يمكن للعامل الثلاثي أن يمثّل العملية نفسها:

```php
$value = $condition
  ? 1  // True branch
  : 2; // False branch
```

صيغة المقارنة قصيرة، وتُمثَّل بـ `(condition) ? (evaluate if true) : (evaluate if false);`.
