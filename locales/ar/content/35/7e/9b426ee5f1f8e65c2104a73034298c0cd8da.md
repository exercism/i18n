# تكامل Babashka مع محررات النصوص

## nREPL

### Emacs: [CIDER](https://cider.mx/)

هذا هو ما بدأ كل شيء، ونظامه البيئي [Orchard](https://metaredux.com/posts/2018/11/09/ciders-orchard-the-heart.html) يشغّل العديد من الإضافات الأخرى.

1. ثبّت [Emacs](https://www.gnu.org/software/emacs/download.html) على منصّتك.

2. اختر توزيعة Emacs جاهزة ([Prelude](https://prelude.emacsredux.com/) و[Spacemacs](https://www.spacemacs.org/) و[Doom Emacs](https://github.com/hlissner/doom-emacs) كلها ممتازة) أو أضف هذا إلى ملف `init.el`:

```elisp
(unless (package-installed-p 'cider)
  (package-install 'cider))
  
(add-hook 'clojure-mode-hook #'cider-mode)
```

ملخّص من [وثائق CIDER](https://docs.cider.mx/cider/platforms/babashka.html):

ابدأ خادم nREPL من مجلد المشروع:

```bash
$ bb --nrepl-server
```

أنشئ أي ملف Clojure (`.clj`) أو افتحه باستخدام `C-x C-f`، ثم اتصل به باستخدام `C-c C-x c j` (`cider-connect-clj`).

[اختصارات CIDER الأساسية](https://docs.cider.mx/cider/usage/cider_mode.html#key-reference):

* `cider-load-buffer` - `C-c C-k`
* `cider-eval-last-sexp` - `C-x C-e` أو `C-c C-e`
* `cider-eval-defun-at-point` - `C-M-x` أو `C-c C-c`

### VSCode: [Calva](https://github.com/BetterThanTomorrow/calva)

1. ثبّت [VSCode](https://code.visualstudio.com/).

2. ثبّت [Calva](https://marketplace.visualstudio.com/items?itemName=betterthantomorrow.calva).

حاليًا، يعتبر Calva أن الكود المصدري لديك يقع في سياق مجلد، أي مشروع Clojure. ومن الأساليب الجيدة لإنشاء مشروع استخدام [clj-new](https://github.com/seancorfield/clj-new):

```bash
$ clj -A:new lib myorg/bbtest
Generating a project called bbtest based on the 'lib' template.
The lib template is intended for library projects, not applications.
```
3. ابدأ خادم nREPL من مجلد المشروع:

```bash
$ cd bbtest
bbtest$ bb --nrepl-server 1667
Started nREPL server at localhost:1667
For more info visit https://github.com/borkdude/babashka/blob/master/doc/repl.md#nrepl.
```

افتح مجلد المشروع في VSCode (`Ctrl+K Ctrl+O`) أو من طرفية أخرى:

```bash
$ cd bbtest
bbtest$ code .
```

4. في VSCode، نفّذ أمر Calva `Connect to a running REPL` (`ctrl+alt+c ctrl+alt+c`). اختر المشروع `Generic` عند مطالبتك بذلك، ثم أدخل `localhost:1667`.

أوامر REPL:

* `Load Current File and Dependencies` `ctrl+alt+c enter`
* `Evaluate Current Form Inline` `ctrl+alt+c e`
* `Evaluate Current Top Level Form (defun)` `ctrl+alt+c space`

### IntelliJ: [Cursive](https://cursive-ide.com/)

1. نزّل IntelliJ من [هنا](https://www.jetbrains.com/idea/download/index.html).
2. ثبّت Cursive باتباع [دليل المستخدم](https://cursive-ide.com/userguide/) و[تهيئة التبعيات](https://cursive-ide.com/userguide/deps.html).
3. راجع [Cursive: العمل مع Babashka](https://cursive-ide.com/userguide/babashka.html) لمزيد من المعلومات.

## Socket REPL

### Atom: [chlorine](https://github.com/mauricioszabo/atom-chlorine)

1. ثبّت [atom](https://flight-manual.atom.io/getting-started/sections/installing-atom/)

2. ثبّت حزمة `chlorine`

3. ابدأ Socket REPL:

 ```
$ bb --socket-repl 1666
Babashka socket REPL started at localhost:1666
 ```

4. افتح لوحة الأوامر في Atom (`ctrl+shift+p`) ونفّذ الأمر `Connect Clojure Socket REPL` مع `localhost` و`1666`

5. عدّل اختصارات المفاتيح في `keymap.cson` عبر قائمة `Edit` ثم `Keymap...`:

```
'atom-text-editor[data-grammar="source clojure"]':
  'ctrl-; y':       'chlorine:connect-clojure-socket-repl'
  'ctrl-; e':       'chlorine:disconnect'
  'ctrl-; k':       'chlorine:clear-console'
  'ctrl-shift-enter':       'chlorine:load-file'
  'ctrl-enter':       'chlorine:evaluate-block'
  'shift-enter':       'chlorine:evaluate-top-block'
  'ctrl-; i':       'chlorine:inspect-block'
  'ctrl-; I':       'chlorine:inspect-top-block'
  'ctrl-; s':       'chlorine:evaluate-selection'
  'ctrl-; c':       'chlorine:break-evaluation'
  'ctrl-; S':       'chlorine:source-for-var'
  'ctrl-; d':       'chlorine:doc-for-var'
  'ctrl-; x':       'chlorine:run-tests-in-ns'
  'ctrl-; t':       'chlorine:run-test-for-var'
```

### Emacs: [inf-clojure](https://github.com/clojure-emacs/inf-clojure)

بالنسبة إلى Emacs، ثبّت [inf-clojure](https://github.com/clojure-emacs/inf-clojure) بإضافة هذا إلى ملف `init.el`:

```
(unless (package-installed-p 'inf-clojure)
  (package-refresh-contents)
  (package-install 'inf-clojure))

(add-hook 'clojure-mode-hook #'inf-clojure-minor-mode)
```

ابدأ Socket REPL كما سبق، ثم نفّذ في Emacs الأمر `M-x inf-clojure-connect` (`C-c M-c`).

قيّم الصيغ باستخدام `C-c C-e`. وللحصول على قائمة بكل الأوامر المتاحة في `inf-clojure-mode` (المعروف أيضًا بـ REPL) و`inf-clojure-minor-mode`، يمكنك إما استدعاء `C-h f RET inf-clojure-mode` و`C-h f RET inf-clojure-minor-mode`، أو ببساطة تصفّح قوائمهما.

### Vim: [vim-iced](https://github.com/liquidz/vim-iced)

نزّل [Neovim appimage](https://github.com/neovim/neovim/releases/download/v0.4.3/nvim.appimage) وأنشئ له اسمًا مستعارًا `vim`.

* ثبّت [vim-plug](https://github.com/junegunn/vim-plug):

```
$ curl -fLo ~/.local/share/nvim/site/autoload/plug.vim --create-dirs \
    https://raw.githubusercontent.com/junegunn/vim-plug/master/plug.vim
```

أنشئ `~/.config/nvim/init.vim`:

```
call plug#begin('~/.vim/plugged')

Plug 'liuchengxu/vim-clap'
Plug 'guns/vim-sexp',    {'for': 'clojure'}
Plug 'liquidz/vim-iced', {'for': 'clojure'}

call plug#end()

" Enable vim-iced's default key mapping
" This is recommended for newbies
let g:iced_enable_default_key_mappings = v:true
```

افتح Neovim ونفّذ الأمر `:PlugInstall`.

أضف الأمر `iced` إلى `$PATH`:

`$ export PATH=$PATH:~/.vim/plugged/vim-iced/bin`

* ابدأ خادم Socket REPL، وافتح ملف الكود المصدري، ونفّذ `:IcedConnectSocketRepl 1666`.

أوامر REPL الافتراضية (القيمة الافتراضية لـ `<Leader>` هي `\`):

- `<Leader>ei` : قيّم العنصر الداخلي
- `<Leader>ee` : قيّم القائمة الخارجية
- `<Leader>et` : قيّم القائمة العلوية الخارجية
