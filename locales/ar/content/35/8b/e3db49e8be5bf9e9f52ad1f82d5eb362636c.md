# نبذة

محارف Factor هي *أعداد صحيحة*، أي نقاط ترميز في Unicode، لذلك فإن عوامل المقارنة الرقمية `<` و`>` و`=` تمنحك بالفعل ترتيبًا حساسًا لحالة الأحرف. وتضيف مفردات [`unicode`][unicode] فوق ذلك محمولات تراعي Unicode وتحويلًا لحالة المحرف الواحد.

## المحمولات

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
digit>   ( c -- n )    ! the integer value of a digit char
blank?   ( c -- ? )    ! whitespace
alpha?   ( c -- ? )    ! letter or decimal digit
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
CHAR: \n blank? .    ! => t
```

## تحويل حالة الأحرف

```
ch>upper  ( c -- c' )
ch>lower  ( c -- c' )
ch>title  ( c -- c' )
```

وتطبّق `>upper` و`>lower` و`>title` على مستوى السلسلة النصية هذه التحويلات على كل محرف من محارف السلسلة.

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```
