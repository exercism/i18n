# مقدمة

عندما تحتاج quotation إلى *تذكّر* قيم من محيطها، وهو ما تسمّيه لغات أخرى *إغلاقًا*، يستخدم Factor أداتين: الكلمة `curry` وصيغة *fry* المكتوبة بالشكل `'[ ]`.

## `curry`: التقاط قيمة واحدة

‏`curry` (في [`kernel`][kernel]) يأخذ قيمة وquotation، ويُرجع quotation جديدة دُمجت فيها تلك القيمة:

```
curry ( value quot -- newquot )
```

```factor
3 [ + ] curry .
! => [ 3 + ]

10 3 [ + ] curry call .
! => 13
```

طبّق `curry` مرتين لالتقاط قيمتين:

```factor
2 3 [ + + ] curry curry .
! => [ 2 3 + + ]
```

## `compose`: ضم quotationين

‏`compose` (في [`kernel`][kernel]) يلصق quotationين معًا:

```
compose ( quot1 quot2 -- quot )
```

```factor
[ 1 + ] [ 2 * ] compose .
! => [ 1 + 2 * ]

5 [ 1 + ] [ 2 * ] compose call .
! => 12
```

## quotations بصيغة fry: التقاط عدة قيم

عند التقاط أكثر من قيمة أو قيمتين، يصبح استدعاء `curry` المتسلسل صعب القراءة. تستخدم صيغة *fry* التركيب `'[ … ]` مع عنصر نائب `_` واحد أو أكثر؛ ويُستبدل كل `_` بقيمة تُسحب من مكدس البيانات، بالترتيب:

```factor
2 3 '[ _ _ + + ] .
! => [ 2 3 + + ]
```

كل من `curry` و fry *يستهلك* قيمه من المكدس في اللحظة التي يُبنى فيها الإغلاق. والسطر أعلاه لا يترك شيئًا على المكدس، وهو بديل مباشر عن `[ + + ] curry curry`.

تُملأ العناصر النائبة من اليسار إلى اليمين بقيم المكدس من الأسفل إلى الأعلى: `2 3 '[ _ _ ]` تساوي `[ 2 3 ]`، وليست `[ 3 2 ]`.

كما تتغلغل صيغة fry *داخل* الـ quotations المتداخلة، ما يتيح لك وضع القيم الملتقطة حيث تريدها بالضبط:

```factor
2 '[ [ _ > ] filter ] { 1 2 3 4 5 } swap call( s -- s ) .
! => { 3 4 5 }
```

يقع `_` داخل `[ … ]` الداخلية، لكن fry مع ذلك يملؤه.

## `call` مع تأثير مُعلن

عندما تُشغّل quotation مخزّنة في النهاية، أعلن تأثيرها على المكدس عبر `call` ليتمكن المصرّف من التحقق من أنواعها:

```factor
{ 3 4 5 } [ first2 + ] call( p -- n ) .
! => 7

{ 3 4 5 } [ first ] call( p -- n ) .
! => 3
```

## حساب المتجهات

تجمع مفردات [`math.vectors`][math.vectors] متتابعتين متساويتين في الطول عنصرًا بعنصر. و`v+` و`v*` تجمعانهما أو تضربانهما؛ أما `vmax` و`vmin` فتحتفظان بالأكبر أو الأصغر من كل مكوّن. وكل واحدة منها تُرجع مصفوفة من عنصرين:

```factor
{ 1 1 } { 3 4 } v+ .    ! => { 4 5 }
{ 2 5 } { 3 -1 } v* .   ! => { 6 -5 }
{ 1 9 } { 4 4 } vmax .  ! => { 4 9 }
{ 1 9 } { 4 4 } vmin .  ! => { 1 4 }
```
