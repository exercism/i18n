# استخدام مواصفات الأنواع

[comment]: # (يُرفع هذا التحذير عندما لا تحتوي الحل على مواصفة نوع)

أدرج [مواصفات الأنواع](https://elixir-lang.org/getting-started/typespecs-and-behaviours.html#types-and-specs) (`@spec`) لتوضيح العقد بين مدخلات الدالة وما تُرجعه.

- Elixir لغة ذات أنواع ديناميكية، بمعنى أن فحص الأنواع لا يحدث إلا في وقت التشغيل. ويتيح استخدام مواصفات الأنواع لأدوات الفحص والتحليل الساكن مثل [`Dialyxir`](https://hexdocs.pm/dialyxir/readme.html) (المبني على [`Dialyzer`](http://erlang.org/doc/man/dialyzer.html) الخاص بـ Erlang) أن تقيّم الكود بحثًا عن سلوكيات غير مقصودة.
- يمكنك العثور على [قائمة كاملة](https://hexdocs.pm/elixir/typespecs.html#basic-types) بجميع الأنواع المضمّنة في [توثيق اللغة](https://hexdocs.pm/elixir/typespecs.html#content)
- يمكن كتابة الأنواع مع الأقواس الهلالية أو بدونها، مثل `atom()` مقابل `atom`
  - أسلوب Exercism في Elixir هو الكتابة بدون أقواس.

```elixir
# Example 1
@spec add_one(int) :: int
def add_one(n) when is_integer(n) do
  n + 1
end

# Example 2
@spec hello(String.t) :: String.t
def hello(what \\ "world") when is_binary(what) do
  "Hello, #{what}"
end
```
