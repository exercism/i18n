# التعليمات

أنت تكتب نظامًا مدمجًا لآلة Take-A-Number. إنه طراز بسيط جدًا. يمكنه توزيع أرقام متتالية والإبلاغ عن آخر رقم وزّعه.

## 1. تشغيل الآلة

نفّذ الدالة `start/0`. يجب أن تُنشئ عملية جديدة وأن تُرجع `PID` الخاص بها. لا تحتاج العملية الجديدة إلى فعل أي شيء بعد.

```elixir
TakeANumber.start()
# => #PID<0.138.0>
```

لاحظ أن `PID` قد يختلف في كل مرة تُشغّل فيها هذا الكود.

## 2. الإبلاغ عن حالة الآلة

عدّل الآلة بحيث تكون العملية المُنشأة حديثًا جاهزة لاستقبال الرسائل (ابدأ _حلقة استقبال_) بحالة ابتدائية قيمتها `0`. يجب أن تكون قادرة على استقبال رسائل `{:report_state, sender_pid}`. وكردّ على تلك الرسائل، تُرسل حالتها الحالية (رقم التذكرة الأخيرة التي وزّعتها) إلى `sender_pid` ثم تنتظر مزيدًا من الرسائل.

```elixir
machine_pid = TakeANumber.start()

# a client sending a message to the machine
send(machine_pid, {:report_state, self()})

# a client receiving a message from the machine
receive do
  msg -> msg
end

# => 0
```

## 3. توزيع الأرقام

عدّل الآلة بحيث تستطيع استقبال رسائل `{:take_a_number, sender_pid}`. يجب أن تزيد حالتها بمقدار 1، وتُرسل الحالة الجديدة إلى `sender_pid`، ثم تنتظر مزيدًا من الرسائل.

```elixir
machine_pid = TakeANumber.start()

# a client sending a message to the machine
send(machine_pid, {:take_a_number, self()})

# a client receiving a message from the machine
receive do
  msg -> msg
end

# => 1
```

## 4. إيقاف الآلة

عدّل الآلة بحيث تستطيع استقبال رسالة `:stop`. يجب أن تتوقف عن انتظار مزيد من الرسائل.

## 5. تجاهل الرسائل غير المتوقعة

عدّل الآلة بحيث تتجاهل أي رسالة غير متوقعة تستقبلها وتواصل انتظار مزيد من الرسائل.
