# تعليمات خاصة بـ SQLite

يجب أن يحتوي العمود **result** على كائن من الكائنات مرمّز بصيغة JSON، تكون فيه كل كلمة مفتاحًا وعدد مرات ظهورها عددًا صحيحًا.

على سبيل المثال، تأمّل الجملة أعلاه: `"That's the password: 'PASSWORD 123'!", cried the Special Agent.\nSo I fled.`
ينبغي أن تكون **result** لهذا المدخل:

```json
{"123":1,"agent":1,"cried":1,"fled":1,"i":1,"password":2,"so":1,"special":1,"that's":1,"the":2}
```

## مخطط الجدول

```sql
CREATE TABLE "word-count" (
    sentence TEXT NOT NULL,
    result   TEXT               -- json object
);
```
