# مقدمة

## المكرِّرات

النوع `Iterator` في Gleam يشبه المصفوفة من حيث إنه مجموعة مرتبة من القيم، حيث تكون كل القيم من النوع نفسه. ويختلف عن المصفوفة في أنه كسول، أي أنه لا يخزّن كل قيمه في الذاكرة دفعة واحدة، بل يحسبها عند الحاجة إليها.

يكون هذا مفيدًا عند التعامل مع متتاليات كبيرة جدًا أو حتى لا نهائية الحجم، لأنه يتيح لنا التعامل معها عندما لا نملك ذاكرة حرة كافية لتخزينها كلها دفعة واحدة.

تُعرّف وحدة `gleam/iterator` النوع `Iterator` بالإضافة إلى دوال للتعامل مع المكرِّرات.

العديد من دوال المصفوفات موجودة أيضًا للمكرِّرات، مثل `map` و`filter` و`take`. تُرجع هذه الدوال مكرِّرات، لذا لا تنفّذ الدوال أي عمل فعلي حتى يتم استهلاك المكرِّر.

```gleam
let iter = 
  [1, 2, 3, 4, 5, 6]
  |> iterator.from_list
  |> iterator.filter(fn(x) { x > 2 })
  |> iterator.take(2)

// No work has been done yet as the iterator has not been consumed

// Consume the iterator and collect the values into a list
iterator.to_list(iter)
// -> [3, 4]
```

يمكن استخدام الدالة `unfold` لإنشاء مكرِّرات من دالة تُستدعى بشكل متكرر لإنتاج القيمة التالية في المتتالية.

هنا تُستخدم الدالة `unfold` لإنشاء مكرِّر ينتج متتالية فيبوناتشي:

```gleam 
iterator.unfold(#(0, 1), fn(pair) {
  let x = pair.0 + pair.1
  iterator.Next(element: x, accumulator: #(pair.1, x))
})
|> iterator.take(6)
|> iterator.to_list
// -> [1, 2, 3, 5, 8, 13]
```

المتتالية هنا لا نهائية، لذا تُستخدم الدالة `take` لجعلها منتهية قبل تجميع القيم في مصفوفة. إذا استُدعيت `to_list` على مكرِّر لا نهائي، فسيستمر البرنامج في العمل حتى تنفد ذاكرة البرنامج ويتعطل.
