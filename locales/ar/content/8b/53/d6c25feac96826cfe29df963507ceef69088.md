# مقدمة

## التعدادات

_النوع التعدادي_ هو نوع بيانات خاص يسمح للمتغير بأن يأخذ واحدة من مجموعة ثوابت محددة مسبقًا.
يجب أن تكون قيمة المتغير مساوية لإحدى القيم المحددة مسبقًا له.
من الأمثلة الشائعة اتجاهات البوصلة (القيم `NORTH` و`SOUTH` و`EAST` و`WEST`) وأيام الأسبوع.

ولأنها ثوابت، فإن أسماء حقول النوع التعدادي تُكتب بأحرف كبيرة.

### تعريف نوع تعدادي

في لغة برمجة Java، تُعرّف نوعًا تعداديًا باستخدام الكلمة المفتاحية `enum`.
على سبيل المثال، تُحدّد نوعًا تعداديًا لأيام الأسبوع هكذا:

```java
public enum DayOfWeek {
    SUNDAY,
    MONDAY,
    TUESDAY,
    WEDNESDAY,
    THURSDAY,
    FRIDAY,
    SATURDAY
}
```

يُستحسن استخدام الأنواع التعدادية كلما احتجت إلى تمثيل مجموعة ثابتة من الثوابت.
يشمل ذلك الأنواع التعدادية الطبيعية مثل كواكب مجموعتنا الشمسية، ومجموعات البيانات التي تعرف فيها كل القيم الممكنة وقت الترجمة، مثل الخيارات في قائمة، أو أعلام سطر الأوامر، وما إلى ذلك.

### استخدام نوع تعدادي

إليك كودًا يوضح لك كيفية استخدام التعداد `DayOfWeek` المعرّف أعلاه:

```java
public class Shop {
    public String getOpeningHours(DayOfWeek dayOfWeek) {
        switch (dayOfWeek) {
            case MONDAY:
            case TUESDAY:
            case WEDNESDAY:
            case THURSDAY:
            case FRIDAY:
                return "9am - 5pm";
            case SATURDAY:
                return "10am - 4pm"
            case SUNDAY:
                return "Closed.";
        }
    }
}
```

```java
var shop = new Shop();
shop.getOpeningHours(DayOfWeek.WEDNESDAY);
// => "9am - 5pm"
```

### إضافة طرق وحقول

الأنواع التعدادية في لغة برمجة Java أقوى بكثير من نظيراتها في لغات أخرى.
تعريف `enum` يعرّف _صنفًا_ (يُسمى _نوعًا تعداديًا_).
يمكن أن يحتوي جسم الصنف التعدادي على طرق وحقول أخرى:

```java
public enum Rating {
    GREAT(5),
    GOOD(4),
    OK(3),
    BAD(2),
    TERRIBLE(1);

    private final int numberOfStars;

    Rating(int numberOfStars) {
        this.numberOfStars = numberOfStars;
    }

    public int getNumberOfStars() {
        return this.numberOfStars;
    }
}
```

استدعاء الطريقة `getNumberOfStars` على عضو من النوع التعدادي `Rating`:

```java
Rating.GOOD.getNumberOfStars();
// => 4
```
