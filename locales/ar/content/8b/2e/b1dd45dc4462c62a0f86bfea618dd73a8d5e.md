# مقدمة

يوجد في Gleam نوعان مختلفان من الأعداد: الأعداد الصحيحة والأعداد العشرية.

الأعداد الصحيحة هي أعداد كاملة.

```gleam
let integer = 3
// -> 3
```

يمكن أيضًا إضافة الشرطات السفلية إلى الأعداد الصحيحة للوضوح.

```gleam
1_000_000 // One million
```

لدى Gleam عدة عوامل تعمل مع الأعداد الصحيحة.

```gleam
1 + 1 // -> 2
5 - 1 // -> 4
5 / 2 // -> 2
3 * 3 // -> 9
5 % 2 // -> 1

2 > 1  // -> True
2 < 1  // -> False
2 >= 1 // -> True
2 <= 1 // -> False
```
