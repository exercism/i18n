# مقدمة

## الدوال الخارجية

يمكن تشغيل Gleam على الآلة الافتراضية Erlang (BEAM)، أو على بيئات تشغيل JavaScript. وهناك لغات أخرى كثيرة تستخدم بيئات التشغيل هذه، ويكون من المفيد غالبًا القدرة على استدعاء كود مكتوب بهذه اللغات من Gleam.

تتيح ميزة _الدوال الخارجية_ في Gleam استيراد دوال مكتوبة بلغات أخرى إلى Gleam واستدعاءها دون أي تكلفة أثناء التشغيل.

إذا كان مشروع Gleam لديك يعمل على الآلة الافتراضية Erlang وأردت استدعاء الدالة `reverse` من وحدة `lists` في Erlang، فيمكنك فعل ذلك بإضافة السمة `@external` إلى ترويسة دالة Gleam هكذا:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

ويمكن بعد ذلك استدعاؤها كدالة Gleam عادية:

```gleam
let reversed = reverse_list([1, 2, 3])
// -> [3, 2, 1]
```

إذا حاولت ترجمة هذا الكود لبيئات تشغيل JavaScript فسيفشل برسالة خطأ لعدم وجود تنفيذ لـ JavaScript. ويمكن تحديد تنفيذ آخر لبيئات تشغيل JavaScript هكذا:

```gleam
@external(erlang, "lists", "reverse")
@external(javascript, "./my_module.mjs", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

من الممكن أيضًا كتابة تنفيذ بلغة Gleam يُستخدم عند عدم وجود تنفيذ خارجي لهدف الترجمة الحالي:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a) {
  tail_recursive_reverse(x, [])
}

fn tail_recursive_reverse(list, reversed) {
  case list {
    [] -> reversed
    [x, ..xs] -> tail_recursive_reverse(xs, [x, ..reversed])
  }
}
```

## الأنواع الخارجية

يمكن استخدام الأنواع الخارجية للإشارة إلى أنواع بيانات معرّفة في لغات أخرى، مثل Erlang أو JavaScript.

لتعريف نوع خارجي، عرّف نوعًا لكن دون تقديم أي منشئات. ويمكن بعد ذلك استخدامه بالطريقة نفسها كأي نوع آخر.

```gleam
pub type OrderedDictionary(element)
```
