# مقدمة

## العودية

الدوال العودية هي دوال تستدعي نفسها.

تحتاج الدالة العودية إلى وجود _حالة أساسية_ واحدة على الأقل و_حالة عودية_ واحدة على الأقل.

_حالة أساسية_ تُرجع قيمة دون استدعاء الدالة مرة أخرى.
_حالة عودية_ تستدعي الدالة مرة أخرى، وتُعدّل المدخل بحيث يتطابق في مرحلة ما مع الحالة الأساسية.

في Elm، تُعرَّف الدوال العودية عادةً باستخدام مطابقة الأنماط مع تعبيرات `case` أو عدة جمل تعريفية للدالة.

```elm
count : List a -> Int
count list =
    case list of
        [] ->
            0  -- base case

        _ :: tail ->
            1 + count tail  -- recursive case
```

### الحلقات من خلال العودية

بسبب عدم قابلية القيم للتغيير، تُكتب الحلقات في Elm بشكل مختلف عن اللغات الأمرية.
على سبيل المثال، غالبًا ما تبدو الحلقات هكذا:

```c
for(i = 0; i < array.length; i++) {
  // do something with array[i]
}
```

في لغة وظيفية مثل Elm، لا يمكن تعديل المتغيرات.
لذلك، يجب تنفيذ الحلقات باستخدام العودية.

المكافئ لحلقة `for` في Elm سيبدو هكذا:

```elm
loop : List a -> (a -> b) -> List b
loop list f =
    case list of
        [] ->
            []

        head :: tail ->
            f head :: loop tail f
```

عمليًا، غالبًا ما يتم التكرار على المصفوفات وغيرها من هياكل البيانات في Elm باستخدام دوال من وحدة `List`، مثل `List.map` و`List.filter` و`List.foldl`.
خلف الكواليس، تُنفَّذ هذه الدوال باستخدام العودية.
