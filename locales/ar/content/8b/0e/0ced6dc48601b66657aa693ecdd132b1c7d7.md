# التعليمات

أنت في طور تطوير لعبة جديدة ستلقى إعجابًا كبيرًا: **Crystal Hunter**.
في اللعبة، أنت شخصية تتحرك هنا وهناك وتجمع البلورات.
يفوز اللاعب عندما يلتقط كل البلورات.
وإذا لمس اللاعب قاطع طريق، فسيفقد كل بلوراته ويخسر اللعبة.
وهناك استثناء لهذه القاعدة: يمكن أن يمتلك اللاعب تعزيزًا نشطًا يجعله غير مرئي لقطّاع الطرق.

هدفك هو كتابة بعض القواعد التي ستُستخدم في اللعبة.

## 1. حدّد ما إذا كانت الشخصية تحصل على نقاط إضافية

في اللعبة، تحصل الشخصية على نقاط إضافية إذا لمست قاطع طريق وهي تمتلك تعزيزًا نشطًا.

عرّف الطريقة `Rules#bonus_points?` التي تأخذ وسيطين (_ما إذا كانت الشخصية تمتلك تعزيزًا نشطًا_ و_ما إذا كانت الشخصية تلمس قاطع طريق_) وتُرجع قيمة منطقية تخبرنا ما إذا كانت الشخصية ستحصل على نقاط إضافية.
ينبغي أن تُرجع الطريقة `true` فقط إذا كانت الشخصية تمتلك تعزيزًا نشطًا وتلمس قاطع طريق، و`false` فيما عدا ذلك.

```Crystal
Rules.new.bonus_points?(false, true)
# => false
```

## 2. حدّد ما إذا كانت الشخصية تحرز نقاطًا

يحصل اللاعب على نقاط في اللعبة عند التقاط بلورة أو تعزيز.

عرّف الطريقة `Rules#score?`، التي تأخذ وسيطين (_ما إذا كانت الشخصية تلمس تعزيزًا_ و_ما إذا كانت الشخصية تلمس بلورة_) وتُرجع قيمة منطقية تشير إلى ما إذا كانت الشخصية قد أحرزت نقاطًا أم لا.
ينبغي أن تُرجع الطريقة `true` إذا لمست الشخصية تعزيزًا أو بلورة، وأن تُرجع `false` فيما عدا ذلك.

```crystal
Rules.new.score?(true, true)
# => true
```

## 3. حدّد ما إذا كانت الشخصية تخسر

عرّف الطريقة `Rules#lose?`، التي تأخذ وسيطين (_ما إذا كانت الشخصية تمتلك تعزيزًا نشطًا_ و_ما إذا كانت الشخصية تلمس قاطع طريق_) وتُرجع قيمة منطقية تشير إلى ما إذا كانت الشخصية تخسر أم لا.
ينبغي أن تُرجع الطريقة `true` إذا لمست الشخصية قاطع طريق ولم تكن تمتلك تعزيزًا نشطًا، وأن تُرجع `false` فيما عدا ذلك.

```crystal
Rules.new.lose?(false, true)
# => true
```

## 4. حدّد ما إذا كانت الشخصية تفوز

عرّف الطريقة `Rules#win?`، التي تأخذ ثلاثة وسائط (_ما إذا كانت الشخصية قد التقطت كل البلورات_، و_ما إذا كانت الشخصية تمتلك تعزيزًا نشطًا_، و_ما إذا كانت الشخصية تلمس قاطع طريق_) وتُرجع قيمة منطقية تشير إلى ما إذا كانت الشخصية تفوز أم لا.
ينبغي أن تُرجع الطريقة `true` إذا جمعت الشخصية كل البلورات ولم تخسر وفقًا للوسائط المعرّفة في الجزء 3، وأن تُرجع `false` فيما عدا ذلك.

```crystal
Rules.new.win?(false, true, false)
# => false
```
