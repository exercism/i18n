# مقدمة

يدعم ABAP نموذج برمجة كائني التوجه يقوم على الأصناف والواجهات في ABAP Objects.

## الإسناد وإعادة الإسناد

هناك بضعة أساليب أساسية لإسناد القيم إلى الأسماء في ABAP، باستخدام المتغيرات أو الثوابت. في Exercism، تُكتب المتغيرات دائمًا بـ [snake-case][wiki-snake-case]. لا يوجد دليل رسمي يجب اتباعه، وللشركات والمؤسسات المختلفة أدلة أسلوب متباينة. _لا تتردد في كتابة المتغيرات كما تشاء_. وميزة كتابتها بالشكل الذي أُعدّت به التمارين هي أنها ستُبرَز بشكل مختلف في واجهة الويب وفي معظم بيئات التطوير المتكاملة.

يمكن تعريف المتغيرات في ABAP باستخدام الكلمتين المفتاحيتين [`constant`][constant] أو [`data`][data].

يمكن للمتغير أن يشير إلى قيم مختلفة خلال فترة وجوده عند استخدام `data`. على سبيل المثال، يمكن تعريف `my_first_variable` وإعادة تعريفه مرات كثيرة باستخدام [عامل الإسناد `=`][assignment]:

```abap
DATA my_first_variable TYPE i. " integer

my_first_variable = 1.
my_first_variable = 4711 * 3.
my_first_variable = some_complex_calculation( ).
```

وعلى عكس `data`، لا يمكن إسناد قيمة إلى المتغيرات المعرَّفة بـ `constant` إلا مرة واحدة. ويُستخدم ذلك لتعريف الثوابت في ABAP.

```abap
CONSTANT my_first_constant TYPE i VALUE 10.

" Can not be re-assigned
my_first_constant = 20.
// => SyntaxError: Assignment to constant variable.
```

## تعريفات الأصناف والطرق

في ABAP، تُحتوى وحدات الوظائف في _الطرق_، وغالبًا ما تُجمع الطرق المرتبطة ببعضها في [الصنف][classes] نفسه. يمكن لهذه الطرق أن تأخذ معاملات (وسائط)، وأن _تُرجع_ قيمة باستخدام الكلمة المفتاحية `returning` في تعريف الطريقة. وتُستدعى الطرق باستخدام صيغة `( )`.

```abap
CLASS my_class DEFINITION.

  PUBLIC SECTION.

    METHODS add
      IMPORTING
        num1          TYPE i
        num2          TYPE i
      RETURNING
        VALUE(result) TYPE i.

ENDCLASS.

CLASS my_class IMPLEMENTATION.

  METHOD add.
    result = num1 + num2.
  ENDMETHOD.

ENDCLASS.

add( num1 = 1 num2 = 3 ).
// => 4
```

> 💡 في ABAP توجد _أساليب_ كثيرة ومختلفة لتعريف الأصناف والطرق. يحاول المسار تقديمها تدريجيًا، لكن إن كنت تعرفها بالفعل فلا تتردد في استخدام أي منها. وفي معظم الحالات، ليس استخدام أحدها أفضل أو أسوأ من الآخر.
