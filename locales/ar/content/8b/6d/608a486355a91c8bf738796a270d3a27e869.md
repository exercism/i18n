# الاختبارات


نستخدم [pytest][pytest: Getting Started Guide] كأداة تشغيل الاختبارات على موقعنا.
ستحتاج إلى تثبيت `pytest` على جهاز التطوير لديك إذا أردت تشغيل اختبارات مسار Python محليًا.
ينبغي أيضًا أن تثبّت إضافات `pytest` التالية:

- [pytest-cache][pytest-cache]
- [pytest-subtests][pytest-subtests]

تجد معلومات موسّعة في [دليل اختبار Python][Python track tests page] على موقعنا.


### تشغيل الاختبارات

لتشغيل الاختبارات المضمّنة، انتقل إلى المجلد الذي يوجد فيه التمرين باستخدام `cd` في الطرفية (استبدل `<exercise-folder-location>` أدناه بمسارك).
تحمل ملفات الاختبار عادةً الامتداد `_test.py`، وهي الاختبارات نفسها التي تُشغَّل على الموقع عند رفع الحل.

Linux/MacOS
```bash
$ cd <path/to/exercise-folder-location>
```

Windows
```powershell
PS C:\Users\foobar> cd <path\to\exercise-folder-location>
```

<br>

بعد ذلك، شغّل أمر `pytest` في الطرفية، مع استبدال `<exercise_test.py>` باسم ملف الاختبار:

Linux/MacOS
```bash
$ python3 -m pytest -o markers=task <exercise_test.py>
==================== 7 passed in 0.08s ====================
```

Windows
```powershell
PS C:\Users\foobar> py -m pytest -o markers=task <exercise_test.py>
==================== 7 passed in 0.08s ====================
```


### خيارات شائعة
- `-o` : تجاوز الإعدادات الافتراضية في `pytest.ini` (_يمكنك استخدامه لتجنّب تحذيرات العلامات_)
- `-v` : تفعيل الإخراج المفصّل.
- `-x` : إيقاف تشغيل الاختبارات عند أول فشل.
- `--ff` : تشغيل حالات الفشل من الاختبار السابق قبل تشغيل بقية حالات الاختبار.

لمزيد من الخيارات، استخدم `python3 -m pytest -h` أو `py -m pytest -h`.


### إصلاح التحذيرات

إذا لم تستخدم `pytest -o markers=task` عند تشغيل `pytest`، فقد تتلقى تحذير `PytestUnknownMarkWarning` في الاختبارات التي تستخدم الصيغة الجديدة:

```bash
PytestUnknownMarkWarning: Unknown pytest.mark.task - is this a typo?  You can register custom marks to avoid this warning - for details, see https://docs.pytest.org/en/stable/mark.html
```

لتجنّب كتابة `pytest -o markers=task` في كل اختبار تشغّله، يمكنك استخدام ملف إعدادات `pytest.ini`.
أعددنا ملفًا يمكن تنزيله من المستوى الأعلى لمجلد مسار Python: [pytest.ini][pytest.ini].

يمكنك أيضًا إنشاء ملف `pytest.ini` خاص بك بالمحتوى التالي:

```ini
[pytest]
markers =
    task: A concept exercise task.
```

وضع ملف `pytest.ini` في الدليل _الجذر_ أو _العمل_ لتمارين مسار Python يسجّل العلامات ويوقف التحذيرات.
تجد مزيدًا من المعلومات عن علامات pytest في وثائق `pytest` حول [وسم دوال الاختبار][pytest: marking test functions with attributes] وفي وثائق `pytest` حول [العمل بالعلامات المخصّصة][pytest: working with custom markers].

تجد معلومات عن تخصيص إعدادات pytest في وثائق `pytest` حول [صيغ ملفات الإعدادات][pytest: configuration file formats].
