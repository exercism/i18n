# مقدمة

## دوال الرياضيات

يصعب حساب الجذور التربيعية والزوايا ومنحنيات النمو باستخدام `+` و`-` و`*` و`/` فقط. تحتوي مفردات [`math.functions`][math.functions] على كلمات تحسبها لك، وتحتوي [`math.constants`][math.constants] على π. ومثل كل كلمة أخرى، تأخذ كل واحدة مدخلاتها من المكدس وتترك إجابتها هناك.

## الجذور التربيعية

```
sqrt ( x -- y )
```

```factor
USING: kernel math math.constants math.functions math.libm prettyprint ;

9 sqrt .     ! => 3.0
2 sqrt .     ! => 1.4142135623730951
```

سلم طوله 5 أمتار، وتبعد قاعدته 3 أمتار عن حائط، يصل ارتفاعه عليه إلى 4 أمتار:

```factor
5 sq 3 sq - sqrt .   ! => 4.0
```

## باي

`pi` (من `math.constants`) يضع π على المكدس، وهو عدد المرات التي يدخل فيها قطر الدائرة في محيطها:

```factor
: wheel-edge ( diameter -- edge ) pi * ;

2 wheel-edge .   ! => 6.283185307179586
```

## الزوايا بالراديان

```
sin ( x -- y )
cos ( x -- y )
tan ( x -- y )
```

تأخذ `sin` و`cos` و`tan` زاوية، ولكن ليس بالدرجات. إنها تستخدم **الراديان**، حيث تكون نصف الدورة π بدلًا من 180. إعطاؤها درجات ليس خطأً: لكنه يعطي إجابة خاطئة بهدوء.

`deg>rad` يحوّل الدرجات إلى راديان، ويحوّل `rad>deg` في الاتجاه المعاكس. وهما مثل الضرب في π والقسمة على 180، أو العكس:

```
deg>rad ( x -- y )
rad>deg ( x -- y )
```

```factor
30 deg>rad .       ! => 0.5235987755982988
30 pi * 180 / .    ! => 0.5235987755982988
pi rad>deg .       ! => 180.0
```

حوّل الدرجات إلى راديان قبل استدعاء `sin`:

```factor
: ramp-rise ( length degrees -- rise ) deg>rad sin * ;

10 30 ramp-rise .   ! => 4.999999999999999
```

منحدر طوله 10 أمتار بزاوية 30 درجة يرتفع 5 أمتار. تُطبع الإجابة على هيئة `4.999999999999999` لأن دوال الرياضيات تعطي أقرب عدد عشري، لا القيمة الدقيقة. وبدون التحويل، يتعامل `30 sin` مع 30 على أنها راديان (قرابة خمس دورات كاملة)، وكان المنحدر سيُظهر «ارتفاعًا» مقداره `-9.88` متر.

## إيجاد زاوية

`fatan2` يسير في الاتجاه المعاكس: فحين تعطيه مقدار الصعود ومقدار الامتداد الأفقي، يجيب عن الزاوية بالراديان. وهو موجود في [`math.libm`][math.libm]. توضع مسافة *الصعود* على المكدس أولًا، ثم مسافة *الامتداد الأفقي*:

```
fatan2 ( y x -- radians )
```

```factor
1.0 1.0 fatan2 .              ! => 0.7853981633974483
1.0 1.0 fatan2 rad>deg .      ! => 45.0
-1.0 -1.0 fatan2 rad>deg .    ! => -135.0
0.0 -1.0 fatan2 rad>deg .     ! => 180.0
```

تُقاس الزاوية من الاتجاه الأفقي الموجب. ينظر `fatan2` إلى إشارتي المسافتين، لذا يمكنه أن يجيب بأي زاوية بين −180 و180 درجة.

## قوى العشرة: 10^ وlog10

`10^` يرفع العدد 10 إلى قوة:

```factor
5 10^ .     ! => 100000
2 10^ .     ! => 100
0.5 10^ .   ! => 3.1622776601683795
```

`log10` يعود في الاتجاه المعاكس. وهو يجيب عن السؤال: «10 مرفوعًا إلى أي قوة يعطي هذا العدد؟» وتلك الإجابة هي **لوغاريتم** العدد:

```factor
100000 log10 .   ! => 5.0
100 log10 .      ! => 2.0
1 log10 .        ! => 0.0
0.001 log10 .    ! => -3.0
```

## e^ وlog

`e^` و`log` هما الزوج نفسه، مع *e* (نحو 2.718) بدلًا من 10. يرفع `e^` *e* إلى قوة، ويجيب `log` عن السؤال: «إلى أي قوة تُرفع *e* لتعطي هذا العدد؟»

```
e^  ( x -- y )
log ( x -- y )
```

يستخدم علماء الرياضيات *e* مع أي شيء ينمو أو يتقلص بالنسبة الكسرية نفسها في كل خطوة. والمال الذي يدرّ فائدة مثال على ذلك، وفنجان الشاي الذي يبرد مثال آخر:

```factor
! 80 degrees hotter than the room, the gap shrinking by 5% a minute
: tea-gap ( minutes -- gap ) -0.05 * e^ 80 * ;

0 tea-gap .    ! => 80.0
10 tea-gap .   ! => 48.52245277701067
```

`log` يعكس عمل `e^`. وهذا يجيب عن السؤال بالاتجاه المعاكس: كم دقيقة حتى تنخفض الفجوة إلى 40 درجة؟

```factor
80 40 / log 0.05 / .   ! => 13.862943611198904
```
