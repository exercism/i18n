# التعليمات

مهمتك هي أن تحدد ما ستقوله وأنت تعطي الكعكة الإضافية.

إذا كنت تعرف اسم الشخص (مثلًا إذا كان اسمه Do-yun)، فستقول:

```text
One for Do-yun, one for me.
```

وإذا لم تكن تعرف اسم الشخص، فستقول _you_ بدلًا من ذلك.

```text
One for you, one for me.
```

إليك بعض الأمثلة:

| الاسم   | الحوار                    |
| :----- | :-------------------------- |
| Alice  | One for Alice, one for me.  |
| Bohdan | One for Bohdan, one for me. |
|        | One for you, one for me.    |
| Zaphod | One for Zaphod, one for me. |
