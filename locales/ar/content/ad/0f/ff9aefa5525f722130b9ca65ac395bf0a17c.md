# التثبيت

## ما المطلوب

الأساسيات المطلوبة للتطوير بلغة Common Lisp هي:

- تطبيق Lisp، وهو ما يتيح لك ترجمة الكود وتنفيذه، إلى جانب توفير REPL.
- محرر نصوص يتضمن أدوات خاصة بكود Lisp.
- (من المستحسن وجوده) المرجع الأكثر استخدامًا للغة Common Lisp، وهو ["Common Lisp Hyperspec"][hyperspec].

## Roswell

[Roswell][roswell] أمر لتثبيت تطبيقات Common Lisp وإدارتها، ويوفر مزايا كثيرة تجعل تطوير تطبيقات Lisp وتوزيعها أمرًا سهلًا.
نستخدمه لتبسيط خطوات التثبيت والاختبار.

### تثبيت Roswell

راجع [دليل التثبيت][ros-inst] واتبع التعليمات الخاصة بنظامك.
بالنسبة لمعظم المستخدمين، سيكون ما يلي كافيًا:

* على MacOS و Linux، يجعل [Homebrew][brew] هذا بسيطًا:
  ```sh
  brew install roswell
  ```
* على Windows، استخدم [Scoop][scoop]:
  ```powershell
  scoop install roswell
  ```

عند أول استخدام لك Roswell، سيجلب SBCL و Quicklisp ويثبّتهما.
فقط نفّذ هذا:
```sh
ros help
```

ادخل إلى REPL باستخدام
```sh
ros run
```

## اضبط محرر النصوص لديك

يمكن لمن هم جدد على Common Lisp، وخاصة من لديهم خبرة سابقة مع Emacs، أن يبدأوا بسرعة وسهولة عبر تثبيت [Portacle، بيئة Common Lisp المحمولة][portacle].
إنه مجاني وبكامل ميزاته، ويعمل على جميع المنصات الشائعة، ويأتي مُهيأً مسبقًا "جاهزًا للاستخدام". سوف يوفر:

- تطبيق لـ Lisp: SBCL، بما في ذلك Quicklisp و ASDF.
- محرر نصوص: Emacs

... مع الكثير من الإضافات لكتابة كود Lisp:
- SLIME، وهو "Superior Lisp Interaction Mode for Emacs"، يحوّل Emacs إلى بيئة تطوير متكاملة (IDE) لـ Common Lisp
- ParEdit، الذي يسهّل التعامل مع الأقواس الهلالية.

كل شيء يأتي مُهيأً مسبقًا وجاهزًا للاستخدام. ثبّت Portacle بتنزيله من [الصفحة الرئيسية][portacle].

ملاحظة: قد يكون Emacs (محرر النصوص) مربكًا في البداية إن لم تكن معتادًا عليه. لحسن الحظ، هناك العديد من الأدلة التعريفية حول Emacs و SLIME متاحة على الإنترنت.

## البدء بالطريقة التقليدية

إذا كنت تفضّل تثبيت الأدوات المطلوبة بشكل منفصل، فستحتاج إلى تثبيت وإعداد:

- محرر نصوص يدعم Lisp: يعد [Emacs][emacs] مع حزمة [Slime][slime] أو [Sly][sly] خيارًا شائعًا، لكن [VIM][vim] مع [SLIMV][slimv]، أو [Atom][atom] مع [SLIMA][slima]، أو [VSCode][vscode] مع [إضافة Common Lisp][vscode-plugin] خيارات جيدة أيضًا.
- تطبيق لـ Common Lisp: يعد [SBCL][sbcl] خيارًا "آمنًا" يعمل على Linux و MacOS و Windows. ولأن اللغة مبنية على معيار، فإن [تطبيقات أخرى مطابقة للمعيار][awesome-cl-implementations] ستعمل أيضًا.
- [Quicklisp][quicklisp] لإدارة المكتبات. بعد تنزيله، اتبع [التعليمات][quicklisp-install] للتأكد من دمجه بشكل صحيح مع تطبيق Common Lisp لديك.
