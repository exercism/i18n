# مقدمة

## البُنى

البنى امتداد مبني فوق [الخرائط][exercism-maps]، وهي توفر فحوصات وقت الترجمة وقيمًا افتراضية. تُسمّى البنية على اسم الوحدة التي عُرّفت فيها. لتعريف بنية، استخدم التركيب `defstruct`. غالبًا ما يأتي هذا التركيب مباشرةً بعد تعريف الوحدة. يقبل `defstruct` إما قائمة من الذرات (لقيم افتراضية `nil`) أو قائمة كلمات مفتاحية (لقيم افتراضية محددة). يجب أن تأتي الحقول بدون قيم افتراضية قبل الحقول ذات القيم الافتراضية.

```elixir
defmodule Plane do
  defstruct [:engine, wings: 2]
end

plane = %Plane{}
# => %Plane{engine: nil, wings: 2}
```

### الوصول إلى الحقول وتحديثها

بما أن البُنى مبنية على الخرائط، يمكننا استخدام معظم دوال الخرائط للحصول على القيم والتعامل معها. **لا** تُنفَّذ _Access Behaviour_ للبنى. يوصى باستخدام _عامل الوصول الساكن_ `.` للوصول إلى حقول البنية بدلًا من ذلك.

- جلب/استرجاع قيم الحقول:

  ```elixir
  plane = %Plane{}
  plane.engine
  # => nil
  Map.fetch(plane, :wings)
  # => {:ok, 2}
  ```

- تحديث قيم الحقول

  ```elixir
  plane = %Plane{}
  %{plane | wings: 4}
  # => %Plane{engine: nil, wings: 4}
  ```

### مطابقة الأنماط

يمكن استخدام البُنى في مطابقة الأنماط مع اسم البنية أو بدونه.

```elixir
plane = %Plane{}
%Plane{wings: wings} = plane
%{wings: wings} = plane
```

بتضمين اسم البنية في النمط، يمكنك التأكد من أن كلا الجانبين الأيسر والأيمن بنيتان من النوع نفسه.

```elixir
defmodule Helicopter do
  defstruct [:engine, rotors: 1]
end

%Plane{} = %Helicopter{}
# => (MatchError) no match of right hand side value: %Helicopter{engine: nil, rotors: 1}
```

### فرض تهيئة قيم الحقول

يمكننا استخدام سمة الوحدة `@enforce_keys` مع قائمة مفاتيح الحقول لضمان تهيئة القيم عند إنشاء البنية. إذا لم يُدرج مفتاح، فستكون قيمته `nil` كما في المثال أعلاه. إذا لم تتم تهيئة مفتاح مفروض، فسيُرفَع خطأ.

```elixir
defmodule User do
  @enforce_keys [:username]
  defstruct [:username]
end

%User{}
# => (ArgumentError) the following keys must also be given when building struct User: [:username]
```
