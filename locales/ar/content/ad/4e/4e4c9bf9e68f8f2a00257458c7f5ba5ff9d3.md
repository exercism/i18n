# مقدمة

## التعدادات

حتى الآن، تعاملنا في معظم الأحيان مع الأعداد والسلاسل النصية.
ولنمذجة العالم الواقعي، قد نحتاج إلى عدد محدود من القيم التي يمكن أن يأخذها المتغير.
قد ترغب في نوع مخصّص له بضع قيم مميّزة بأسماء مميّزة.
على سبيل المثال، في مصنع ألواح التزلج، أن تكون مادة اللوح محصورة في خشب القيقب أو الخيزران أو البلاستيك فقط.

يمكنك استخدام الأعداد الصحيحة لترميز هذه القيم، لكن سيتعيّن عليك كتابة كود إضافي للتحقق مما إذا كانت هناك قيمة غير صالحة تأتي من النظام لمادة اللوح.
يصعب تتبّع معنى تلك [_الأرقام السحرية_][magic numbers] عبر الكود المصدري، وهي عرضة للالتباس.
يمكن استخدام `enumerations` لتشجيع كتابة كود معبّر وللحدّ من أخطاء المقارنة غير المتعمّدة.

## مثال على الاستخدام

المصطلح المحدّد لهذا النوع من التعدادات هو `scoped enumeration`.
يعرض المقطع التالي كيفية كتابة `enumeration` باسم `DeckMaterial`.
لاحظ الكلمة المفتاحية `enum class` والفاصلة المنقوطة `;` في نهاية التعريف:

```cpp
enum class DeckMaterial {
    maple,
    bamboo,
    plastic
};
```
الآن، انظر إلى دالة تسعير في متجر ألواح التزلج ولاحظ عامل تحديد النطاق (`::`) الذي يحدّد `enumerator` من `enumeration`:

```cpp
double deck_price(double base_price, DeckMaterial material) {
    if(material == DeckMaterial::plastic) {
        return base_price * 0.9;
    }
    return base_price * 1.3;
}
```

## تحديد النطاق

تخيّل أن لديك `enumeration` ثانيًا لمادة العجلات:

```cpp
enum class WheelMaterial {
    steel,
    clay,
    plastic
};
```
وعلى الرغم من أن العجلات واللوح يمكن أن يكونا مصنوعين من _البلاستيك_، لا يمكن الخلط بينهما.
فهما _نوعان_ مختلفان: بلاستيك `DeckMaterial` وبلاستيك `WheelMaterial`.
سيكون لكل `enumeration` ما يخصّها من `enumerators` داخل نطاقها الخاص، أي `namespace` الخاصة بها.
ولهذا السبب تُسمّى `scoped enumerations`.

## التعدادات غير محدَّدة النطاق
قد تعتقد أنه ما دام الاسم `scoped` موجودًا، فلا بد أن توجد أيضًا تعدادات `unscoped`، وأنت محق.
أصبحت `Unscoped enumerations` أقل شيوعًا لأنها جميعًا تتشارك النطاق العام نفسه.
وبسبب هذا التشارك، لا يمكن أن يكون لديك `unscoped enumerations` اثنان يشتركان في `enumerators` نفسها مثل _البلاستيك_ في المثال أعلاه.

كذلك، تتحوّل `unscoped enumerations` ضمنيًا إلى أعداد صحيحة.
انظر إلى المثال التالي للحصول على نتيجة مفاجئة:

```cpp
enum CitrusFruits {
    lemons,  // 0
    oranges, //1
};

enum IceCream {
    walnut,  // 0
    apples,  // 1
};

bool comparison{apples == oranges};
// => true

// Example from above:
bool comparison{DeckMaterial::plastic == WheelMaterial::plastic};
// => Does not compile!
```

إذا أردت تحويل `scoped enumerations` إلى أعداد صحيحة، يمكنك استخدام `static_cast<int>`.
