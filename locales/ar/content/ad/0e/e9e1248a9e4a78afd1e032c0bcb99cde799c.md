# مقدمة

تُمثَّل القيم المنطقية في C++ بالنوع `bool`.
تكون قيمة `bool` إما `true` أو `false`.

## العوامل المنطقية

يدعم C++ ثلاثة عوامل منطقية: `!` (NOT)، و`&&` (AND)، و`||` (OR).
يمكنك أيضًا استخدام الصيغ البديلة `not`، و`and`، و`or`.

```cpp
true || false // => true
true && false // => false
!true // => false
not false // => true
```

## الأسبقية

تختلف _أسبقية العوامل_ بين العوامل المنطقية الثلاثة.
وبناءً على ذلك، تُقيَّم بهذا الترتيب: `!` أولًا، ثم `&&`، وأخيرًا `||`.
إذا أردت فرض ترتيب مختلف، يمكنك وضع تعبير منطقي بين الأقواس الهلالية (أي `()`)، لأن للأقواس الهلالية أسبقية عوامل أعلى.

```cpp
!true && false   // => false
!(true and false) // => true
```

## التحويل

إذا استخدمت `true` أو `false` في موضع يُتوقع فيه عدد، فسيُحوَّلان إلى `1` و`0` على الترتيب.
إذا استخدمت عددًا في عملية منطقية، فكل شيء عدا `0` يُعامَل على أنه `true`، حتى القيم السالبة.

```cpp
!true && 0.0   // => false
true + true + false // => 2
```
