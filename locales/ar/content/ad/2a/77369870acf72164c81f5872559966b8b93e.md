# مقدمة

## الأسماء البديلة للأنواع

يمكن استخدام اسم بديل للنوع في Gleam لإعطاء اسم مناسب لنوع موجود يصعب كتابته لولا ذلك.

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

عند كتابته باستخدام `pub type`، يمكن استخدام الاسم البديل خارج الوحدة التي عُرّف فيها. إذا حُذفت `pub`، يصبح الاسم البديل خاصًا ولا يمكن الإشارة إليه في وحدات أخرى.
