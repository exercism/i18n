# مقدمة

## الأنواع المخصصة

الأنواع المخصصة هي الطريقة التي تُعرَّف بها أنواع البيانات الجديدة في Gleam. يمكن أن تحتوي على عدة _حالات_، لكل منها اسمه الخاص.

```gleam
pub type Season {
  Spring
  Summer
  Autumn
  Winter
}
```

يمكن لكل حالة من حالات النوع المخصص أن تحمل بعض البيانات اختياريًا، ويمكن أن تحتوي الحالات المختلفة على أنواع مختلفة من البيانات. عندما تحمل الحالة بيانات، فإنها تسمى _سجلًا_.

```gleam
pub type Number {
  SomeInt(Int)
  SomeFloat(Float)
  Invalid
}
```

يمكن إنشاء قيمة لحالة محددة بالإشارة إلى اسمها إذا لم تكن تحتوي على بيانات إضافية (`Spring`)، أو باستدعائها كدالة إذا كانت تحتوي عليها (`SomeInt(2)`).

```gleam
let spring = Spring
let integerTwo = SomeInt(2)
```

الأنواع المخصصة، مثل كل شيء في Gleam، لديها _تساوٍ بنيوي_، ما يعني أن قيمتين من الحالة نفسها وبالبيانات نفسها متكافئتان.

```gleam
Spring == Spring // -> True
Spring == Autumn // -> False
SomeInt(2) == SomeInt(2) // -> True
SomeInt(2) == SomeFloat(2.0) // -> False
```

يمكن إجراء مطابقة الأنماط على حالات الأنواع المخصصة باستخدام تعبيرات `case`.

```gleam
import gleam/int
import gleam/float

pub fn describe(flexible_number: Number) -> String {
  case flexible_number {
    SomeFloat(f) -> "Float: " <> float.to_string(f)
    SomeInt(i) -> "Int: " <> int.to_string(i)
    Invalid -> "Neither a float nor an int"
  }
}
```
