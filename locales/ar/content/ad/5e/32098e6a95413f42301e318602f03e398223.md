# مقدمة

قدّم مفهوم [`Basics`][basics] طريقتين لتعريف دالة.

الأكثر عمومية، الصيغة متعددة الأسطر:

```julia
function muladd(x, y, z)
    x * y + z
end
```

وصيغة "الإسناد"، أو "السطر الواحد"، للتعريفات القصيرة:
```julia
muladd(x, y, z) = x * y + z
```

وفي صيغة ثالثة أقصر منها، يمكن إنشاء دالة قصيرة تُستخدم مرة واحدة دون اسم:

```julia-repl
julia> map(x -> 2x, 1:3)
4-element Vector{Int64}:
 2
 4
 6

julia> map((x, y) -> x * y, 1:3, 4:6)
3-element Vector{Int64}:
  4
 10
 18
```

في هذه الحالة، يُعد `x -> 2x` "دالة مجهولة".
وهي تكافئ ما تسميه بعض اللغات الأخرى "دالة لامبدا".

لاحظ أن الوسائط المتعددة تحتاج إلى أقواس هلالية، كما في `(x, y) -> x * y`.

الدوال المجهولة شائعة في كود Julia، لا سيما عند دمجها مع دوال عالية الرتبة مثل `map()` و`filter()`.

## وسائط الدالة

حتى الآن في المنهج، نظرنا فقط في الدوال التي لها عدد محدد من الوسائط، والتي تتطلب أن يوفّر استدعاء الدالة جميعها، بالترتيب الصحيح.
سيكون هذا مقيّدًا وغير مريح، لذا توجد خيارات أخرى عدة.

### الوسائط الاختيارية

مثل لغات كثيرة، تسمح Julia لتعريفات الدوال بتوفير قيم افتراضية لوسائط فردية.

يمكن لاستدعاء الدالة حينها إما أن يوفّر قيمة لذلك الوسيط، أو أن يحذفه ويعتمد على القيمة الافتراضية.

```julia-repl
julia> f(x, y=10) = x * y
f (generic function with 2 methods)

julia> f(2, 3)
6

julia> f(2)
20
```

يجب أن تأتي كل الوسائط _بدون_ قيم افتراضية قبل أي وسيط _له_ قيمة افتراضية، ما يعني أن `f(x=2, y)` سيكون غير صالح.

### الوسائط المفتاحية

تستخدم كل الأمثلة حتى الآن `positional arguments`، حيث يجب أن تطابق القيم الموفَّرة في استدعاء الدالة ترتيب الوسائط المقابلة في تعريف الدالة.

ومثل لغات كثيرة، تسمح Julia أيضًا بـ `keyword arguments`.
يجب أن يحدد استدعاء الدالة اسم الوسيط، لكن يمكن بعد ذلك تحديد عدة وسائط مفتاحية بأي ترتيب.

من السمات المميزة لـ Julia أن الوسائط المفتاحية (إن وُجدت) في تعريف الدالة يجب أن تسبقها فاصلة منقوطة `;` لفصلها عن أي وسائط موضعية.
ويمكن لاستدعاء الدالة أن يستخدم إما `;` أو `,` بين آخر وسيط موضعي وأول وسيط مفتاحي.

```julia-repl
julia> b(x; y) = x + y
b (generic function with 1 method)

julia> b(2, y=3)
5

# keyword is required when calling
julia> b(2, 3)
ERROR: MethodError: no method matching b(::Int64, ::Int64)
The function `b` exists, but no method is defined for this combination of argument types.
```

يمكن اختياريًا تحديد قيم افتراضية، تمامًا كما في الوسائط الموضعية.

من الشائع أن ينتهي بك الأمر إلى صياغة مثل `myarg=myarg` داخل استدعاء دالة، عندما يكون متغير يحمل الاسم نفسه الذي يحمله المعامل قد حُسب مسبقًا.
وتُسمح صيغة مختصرة في هذه الحالة:

```julia-repl
julia> width = 4.0
4.0

julia> height = √ width
2.0

julia> area(; width, height) = width * height
area (generic function with 1 method)

# repetition
julia> area(; width=width, height=height)
8.0

# shorthand form
julia> area(; width, height)
8.0
```

### Splat و slurp

هذان هما الاسمان المعتادان لجانب مفيد من صياغة Julia، إن كنت تتساءل.
كلاهما يشير إلى العامل `...`.

#### Splat

يُستخدم الـ splat في _استدعاءات_ الدوال، لبسط المجموعات إلى قيم فردية تتطلبها الدالة.

قد يكون عرض ذلك أسهل من شرحه:

```julia-repl
julia> fxyz(x, y, z) = x * y * z
fxyz (generic function with 1 method)

julia> xyz = [2, 3, 4]
3-element Vector{Int64}:
 2
 3
 4

# Using the vector directly in a function call is invalid
julia> fxyz(xyz)
ERROR: MethodError: no method matching fxyz(::Vector{Int64})
The function `fxyz` exists, but no method is defined for this combination of argument types.

# splatting converts the vector to 3 numbers, used as positional arguments
julia> fxyz(xyz...)
24
```

بعض "استدعاءات الدوال" مخفية بالسكر النحوي، لذا يمكن استخدام الـ splat بطرق أقل وضوحًا.

على سبيل المثال، يستخدم الإسناد المتعدد دالة إنشاء الصفوف داخليًا:

```julia-repl
julia> first, rest... = [1, 2, 3, 4]
4-element Vector{Int64}:
 1
 2
 3
 4

julia> first
1

julia> rest
3-element Vector{Int64}:
 2
 3
 4
```

يمكن أيضًا توفير الوسائط المفتاحية عبر الـ splat، عادةً باستخدام `named tuple`.
وسيعمل `Dict` أيضًا، لكن يجب أن تكون المفاتيح رموزًا (لن تعمل السلاسل النصية).

```julia-repl
# function with 3 keyword arguments
julia> fabc(; a, b, c) = a + b + c
fabc (generic function with 1 method)

# named tuple
julia> abc_nt = (a=2, b=3, c=4)
(a = 2, b = 3, c = 4)

# there are no positional arguments, so need to use ; before kw argument
julia> fabc(;abc_nt...)
9

# Dict
julia> abc_dict = Dict(:a=>2, :b=>3, :c=>4)
Dict{Symbol, Int64} with 3 entries:
  :a => 2
  :b => 3
  :c => 4

julia> fabc(;abc_dict...)
9
```

#### Slurp

يُستخدم الـ slurp في _تعريف_ الدالة، لحزم عدد اعتباطي من القيم الفردية في مجموعة.

```julia-repl
julia> f_more(i, j, more...) = i + j + sum(more)
f_more (generic function with 1 method)

julia> f_more(1, 3, 5, 7, 9, 11)
36
```

لا يهم اسم الوسيط الذي جُمع بهذه الطريقة (في هذه الحالة `more`).
يختار المصرّف نوع هذا المتغير، لكنه في حالة الوسائط الموضعية يكون غالبًا `tuple` أو ما شابه.

يمكن أيضًا جمع الوسائط المفتاحية بالـ slurp، ما يعطي `Dict` (أو ما شابه).

```julia-repl
julia> f_kwslurp(x, y; switches...) = :mult in keys(switches) ? x * y : x + y
f_kwslurp (generic function with 1 method)

julia> f_kwslurp(5, 6; mult=true)
30

julia> f_kwslurp(5, 6)
11
```

يمكن استخدام أي وسائط مفتاحية في الاستدعاء.
ويعود إلى تعريف الدالة قرار تحديد الكلمات المفتاحية التي يستجيب لها وتلك التي يتجاهلها.
