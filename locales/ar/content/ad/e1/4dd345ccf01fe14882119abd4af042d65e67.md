# تشغيل الاختبارات

اختر نظام التشغيل لديك:

- [Windows](#windows)
- [macOS](#macos)
- [Linux](#linux)

## Windows

1. افتح Command Prompt.
2. نزّل التمرين الأول:

   ```batchfile
   C:\Users\JohnDoe>exercism download --exercise hello-world --track java
   ```

3. انتقل إلى مجلد التمرين:

   ```batchfile
   C:\Users\JohnDoe>cd C:\Users\JohnDoe\exercism\java\hello-world
   ```

4. شغّل الاختبارات:

   ```batchfile
   C:\Users\JohnDoe>gradlew.bat test
   ```

   _(لا تقلق إذا فشلت الاختبارات في البداية، فهكذا تبدأ كل تمرين.)_

5. حلّ التمرين. اعثر على دليل `instructions.append.md` واعمل من خلاله ([اعرضه على GitHub](https://github.com/exercism/java/blob/main/exercises/practice/hello-world/.docs/instructions.append.md#tutorial)).

حظًا سعيدًا! استمتع!
