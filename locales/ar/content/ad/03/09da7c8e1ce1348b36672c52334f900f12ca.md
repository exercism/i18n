# التعليمات

تحب Lilly الطهي.
وهي تريد إقامة حفلة بيتزا مع أصدقائها.
ولكي تستفيد إلى أقصى حد من مكوّناتها، تحتاج إلى معرفة الكمية التي تحتاجها من كل مكوّن قبل أن تبدأ.

ولحل هذه المشكلة، أعدّت Lilly برنامجًا لأتمتة جزء من التخطيط، لكنها تحتاج إلى مساعدتك لإكماله.
فهل ستساعد Lilly في إقامة حفلة البيتزا المثالية من حيث النسب؟

## 1. نسبة العجين

تحب Lilly البيتزا الرقيقة المقرمشة ذات القشرة الرفيعة.
العجين اللازم للجزء الأوسط 200 غرام كحد أدنى، لكن كل شخص تخدمه البيتزا يحتاج إلى 20 غرامًا إضافية من العجين.

`grams = pizzas * ((persons * 20) + 200)`

تحتاج Lilly إلى دالة تقوم بما يلي:

- تأخذ عدد البيتزات
- عدد الأشخاص الذين ستخدمهم كل بيتزا
- وتُرجع كمية العجين اللازمة مقرّبة إلى أقرب غرام.

مثلًا، لإعداد 4 بيتزات تكفي 8 أشخاص:

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateDoughRequirement(4, 8);
// => 1440
```

## 2. رشة من الصلصة

Lilly دقيقة جدًا في توزيع صلصتها، لكن أحجام بيتزاتها قد تكون متفاوتة.
ومن خبرتها، تعرف أن كل بيتزا تحتاج إلى 125 مل من الصلصة.
تحتاج Lilly إلى دالة تحسب عدد علب الصلصة التي يجب شراؤها.

`cans of sauce = pizzas * sauce per pizza / sauce can volume`

مثلًا، إذا كانت Lilly بحاجة إلى إعداد 8 بيتزات، وكانت كل علبة 250 مل:

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateSauceRequirement(8, 250);
// => 4
```

## 3. قليل من الجبن، من فضلك

يُباع الجبن على شكل مكعبات تامة حسب الحجم.

الصيغة التي تستخدمها Lily ليست صيغة مساحة البيتزا، لأنها _لا_ تريد أن تغطي الجبنة المساحة كاملة.
لذلك قررت استخدام الصيغة التالية لمعرفة عدد البيتزات ذات قطر معيّن (`diameter`) التي يمكن إعدادها من مكعب جبن بطول ضلع معيّن (`cheese_dimension`):

`pizzas = (cheese_dimension³) / (thickness * PI * diameter)`

أنشئ دالة تقوم بما يلي:

- تأخذ طول ضلع مكعب الجبن
- تأخذ السماكة المطلوبة لطبقة الجبن
- تأخذ قطر البيتزا
- وتستخدم صيغة Lilly لتُرجع عدد البيتزات التي يمكن إعدادها مع التقريب للأسفل.

مثلًا، إذا كان لدينا مكعب جبن بأبعاد 25x25x25 سم، وطبقة جبن بسماكة 0.5 سم، وبيتزات بقطر 30 سم:

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateCheeseCubeCoverage(25, 0.5, 30);
// => 331
```

## 4. نصيب عادل

وأخيرًا، تريد Lilly أن تُقسَّم بيتزاتها إلى 8 شرائح لكل بيتزا وأن تُوزَّع بالتساوي بين أصدقائها.

أنشئ دالة تقوم بما يلي:

- تأخذ عدد البيتزات وعدد الأصدقاء
- وتُرجع عدد الشرائح المتبقية إذا أخذ كل شخص عددًا متساويًا من الشرائح.

مثلًا:

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateLeftOverSlices(2, 4);
// => 0
$pizza_pi->calculateLeftOverSlices(4, 3);
// => 2
```
