# مقدمة

*الاقتباس* (وهو كود بين الأقواس المربعة `[ ]`) هو نفسه قيمة في Factor، تمامًا مثل العدد أو السلسلة النصية. يمكنك تخزينه في متغير، ووضعه في مصفوفة، وتمريره إلى دالة أخرى، ثم *استدعائه* لاحقًا.

## `call`

تُشغّل `call` (الموجودة في [`kernel`][kernel]) اقتباسًا:

```factor
3 4 [ + ] call .
! => 7
```

عندما تستدعي اقتباسًا بـ `call` في سياق لا يستطيع فيه Factor استنتاج تأثير المكدس الخاص به، فعليك التصريح بالتأثير صراحةً:

```
call( stack-effect ) ! e.g. call( a b -- c )
```

```factor
: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .
! => 2
```

يُترجم هذا إلى فحص يُجرى أثناء التشغيل للتأكد من أن الاقتباس يمتلك فعلًا التأثير المُعلَن.

## الاقتباسات في التسلسلات

ولأن الاقتباسات قيم، يمكن للمصفوفة أن تحتوي على مزيج من الأعداد والاقتباسات:

```factor
{ 3 4 [ + ] }
```

وهذا يجعل «البرنامج» تسلسلًا عاديًا، ويصبح `each` أسلوبًا طبيعيًا لتشغيله:

```
each ( seq quot -- )
```

```factor
{ [ 1 + ] [ 2 * ] } 5 swap [ call( x -- y ) ] each .
! 5 -> 6 -> 12
```

## اقتطاع نهاية تسلسل

تُرجع `head*` كل شيء ما عدا آخر `n` من العناصر؛ وتُرجع `last2` العنصرين الأخيرين:

```
head* ( seq n -- headseq )
last2 ( seq -- penultimate last )
```

```factor
{ 1 2 3 4 5 } 2 head* .    ! => { 1 2 3 }
{ 1 2 3 4 5 } last2 .s
! => 4
! => 5
```

ومع `suffix`، يصبح لديك كل ما تحتاجه لكتابة عملية مكدس «تستهلك العنصرين العلويين وتَدفع نتيجة واحدة».
