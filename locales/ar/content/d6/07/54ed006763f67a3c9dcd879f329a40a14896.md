# القيم المنطقية

في Crystal نوع يُعرف باسم [`Bool`][bools].
وهو يمثّل القيمتين `true` و `false`.

## العوامل المنطقية

تحتوي Crystal على ثلاثة عوامل منطقية (`!` و `||` و `&&`)، وهي تدمج القيم المنطقية وتُنتج تعبيرات ذات قيم مختلفة.

### And (`&&`)

يُمثَّل عامل [_and_][and] في Crystal بـ `&&`، ويُرجع `true` إذا كانت كلتا القيمتين `true`؛ وإلا فإنه يُرجع `false`.
عند استخدام عامل _and_، تُوضع قيمة منطقية على يمين `&&` وأخرى على يساره.

```crystal
true && true
# => true

true && false
# => false
```

### Or (`||`)

يُمثَّل عامل [_or_][or] في Crystal بـ `||`، ويُرجع `true` إذا كانت **واحدة على الأقل** من القيم المعطاة `true`.
وإذا كانت كلتا القيمتين `false`، فإنه يُرجع `false`.
عند استخدام عامل _or_، ينبغي وضع قيمة منطقية على يمين `||` وأخرى على يساره.

```crystal
true || true
# => true

true || false
# => true

false || false
# => false
```

### Not (`!`)

يُمثَّل عامل _not_ في Crystal بـ `!`، ويُرجع `true` إذا كانت القيمة المنطقية المعطاة `false`، ويُرجع `false` إذا أُعطيت `true`.
عند استخدام عامل _not_، ينبغي وضع قيمة منطقية بعد العامل (`!`).

```crystal
!true
# => false

!false
# => true
```

## استخدام الأقواس الهلالية (`()`)

عند التعامل مع القيم المنطقية، يمكنك استخدام الأقواس الهلالية لتحديد أي القيم المنطقية تُقيَّم أولًا.
وقد تختلف النتيجة حسب طريقة استخدام الأقواس الهلالية.
في Crystal، يُقيَّم ما بداخل الأقواس الهلالية أولًا.

```crystal
true && false && false || true
# => true

true && false && (false || true)
# => false
```

ولأن ما بداخل الأقواس الهلالية يُقيَّم أولًا، فسيُطبَّق عامل _not_ على التعبير الموجود داخل الأقواس الهلالية في المثال التالي.

```crystal
!true && false
# => false

!(true && false)
# => true
```

~~~~exercism/note
ينبغي استخدام الأقواس الهلالية فقط عندما تؤثر في النتيجة؛ وإلا فينبغي حذفها.
~~~~
