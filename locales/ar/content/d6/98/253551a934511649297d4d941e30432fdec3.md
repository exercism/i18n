# مقدمة

الدالة [`function`][function] هي أسلوب لتقسيم الكود إلى وحدات مستقلة بحيث يمكن استدعاؤها بالاسم من مكان واحد أو أكثر في البرنامج.
وتُستخدم الدوال لتنفيذ مهام محددة ومتكررة.

وبشكل أكثر رسمية: الدالة هي أي كائن في Python يمكن تطبيق عملية [`function call`][calls] عليه.
قد تُستخدم الدالة من أجل [`return`][return] قيمة واحدة أو أكثر نتيجة عملية أو أكثر، أو قد تُستخدم من أجل [`side effects`][side effects] واحد أو أكثر.
وإذا لم تحدد الدالة قيمة إرجاع، فستظل تُرجع `None`.

وفيما يلي مثال على دالة لها تأثير جانبي:

```python
>>> def hello():
...     print("Hello")
...
>>> hello()
Hello

```

في المثال أعلاه، تُستخدم الكلمة المفتاحية [`def`][def] للإشارة إلى بداية تعريف الدالة.
و`hello` هو اسم الدالة.
وتمثّل الأقواس الهلالية الفارغة عدم تمرير أي قيم إلى الدالة.
وجسم الدالة هو العبارة الوحيدة `print("Hello")`.
و`print` أيضًا دالة.
والقيمة `"Hello"` الواقعة بين الأقواس الهلالية للدالة `print` تُعرف باسم [`argument`][arguments].
وتستخدم الدالة `print` الوسيط لتعرف ما يجب طباعته.
لاحظ أن جسم الدالة مُزاح.
والإزاحة مهمة لأن Python تعتمد عليها لتعرف أين تنتهي كتلة الكود تلك.
وينتهي جسم الدالة إما عند نهاية البرنامج، أو قبل السطر التالي من الكود الذي _ليس_ مُزاحًا مباشرة.
وبما أن `hello()` لا تحدد قيمة `return`، فإنها تنفّذ تأثيرها الجانبي، وهو استدعاء `print()`، ثم تُرجع `None`.
وأخيرًا، نستدعي الدالة باستخدام اسمها والأقواس الهلالية، وهو ما يشير إلى مفسّر Python بأن هذا اسم _قابل للاستدعاء_.

وفيما يلي مثال على دالة لها قيمة إرجاع:

```python
>>> def hello():
...     return "Hello"
... 
print(hello())
Hello

```

لقد تغيّر جسم هذه الدالة من _استدعاء_ `print` إلى _إرجاع_ `string` بقيمة "Hello".
وفي النهاية، لا يزال الكود يطبع `"Hello"`، لكن التأثير الجانبي يحدث في _الكود المستدعي_ بدلًا من دالة `hello`.
وإذا حذفنا الأقواس الهلالية عند استدعاء دالة `hello` (مثل `print(hello)`)، فسيطبع `print` شيئًا كالتالي

```
<function hello at 0x0000026E18E93E20>
```

من المهم أنه حتى لو كانت الدالة لا تقبل أي وسائط (_أي ليس لها معاملات_)، فيجب استخدام الأقواس الهلالية الفارغة لـ_استدعائها_ بشكل صحيح.
وهذا مختلف عن لغة مثل Ruby لا تشترط أقواسًا هلالية فارغة لاستدعاء دالة بدون أي وسائط.

يمكن للدالة أن تعرّف صفرًا أو أكثر من [`parameters`][parameters]. ويحدد المعامل أي وسيط أو وسائط تقبلها الدالة.

وفيما يلي مثال على دالة تقبل وسيطًا:

```python
>>> def hello(name):
...     return f"Hello, {name}"
... 
>>> print(hello("Bob"))
Hello, Bob

```

المعامل معرّف باسم `name`.
أما `"Bob"` فهو الوسيط الذي يمرّره البرنامج إلى دالة `hello`.
وتُ_رجع_ الدالة `string` بقيمة "Hello, Bob".

ماذا لو استدعى أحدهم `hello` دون تمرير وسيط؟
فإن البرنامج يُطلق خطأً:

```python
print(hello())
Traceback (most recent call last):

  Input In in <line: 1>
    print(hello())

TypeError: hello() missing 1 required positional argument: 'name'
```

إذا لم نرد أن يُطلق البرنامج خطأً عند غياب الوسيط (_لكننا نريد السماح للكود المستدعي بعدم تمرير وسيط_)، فيمكننا تعريف [وسيط افتراضي][default arguments].
ويحدد الوسيط الافتراضي القيمة التي تُستخدم إذا غاب الوسيط عند استدعاء الدالة.

وفيما يلي مثال على دالة لها وسيط افتراضي:

```python
>>> def hello(name="you"):
...     return f"Hello, {name}"
... 
>>> print(hello())
Hello, you

```

أُعطي المعامل `name` الوسيط الافتراضي `"you"`، لذا يُخرج البرنامج `Hello, you` إذا لم يُمرَّر إليه وسيط `name`.

لمزيد من المعلومات عن وسائط الدوال، راجع مفهوم [وسائط الدالة][function arguments].
