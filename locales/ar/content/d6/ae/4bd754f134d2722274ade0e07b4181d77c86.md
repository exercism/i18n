# نبذة

النوع الأولي `char` في Java هو تمثيل بـ 16 بت لمحرف Unicode واحد.

~~~~exercism/note
يعتمد نوع `char` على [مواصفة Unicode الأصلية][unicode-specification]، التي كانت تستخدم 16 بت لتمثيل المحارف.
وهذا كافٍ لتغطية معظم الحروف الشائعة، ويغطي المحارف في النطاق من 0x0000 إلى 0xFFFF.
وقد وسّعت المواصفة منذ ذلك الحين نطاق المحارف الممكنة حتى 0x01FFFF.

[unicode-specification]: https://www.unicode.org/versions/Unicode1.0.0/
~~~~

يمكن لعدة محارف `char` أن تكوّن سلسلة نصية، مثل `"word"`، كما يمكن معالجة محارف `char` كلٌّ على حدة.
وتُحاط القيمة الحرفية من النوع `char` بعلامات اقتباس مفردة (مثل `'A'`).

```java
char lowerA = 'a';
char upperB = 'B';
```

## الحصول على محارف `char` من `String`

تُرجع الطريقة `String.toCharArray` محارف `String` على هيئة مصفوفة.
وكما ورد في [المصفوفات][concept-arrays]، يمكنك استخدام حلقة `for` للتنقل عبر المصفوفة.

```java
String text = "Hello";
char[] asArray = text.toCharArray();

for (char ch: asArray) {
    System.out.println(ch);
}

// Outputs:
// H
// e
// l
// l
// o
```

## صنف [Character][docs-character]

توجد العديد من الطرق المدمجة في المكتبة لفحص محارف `char` ومعالجتها.
ويمكن إيجادها كطرق ثابتة في صنف [`java.lang.Character`][docs-character].
إليك بعض الأمثلة:

```java
Character.isWhitespace(' ');    // true
Character.isWhitespace('#');    // false

Character.isLetter('a');        // true
Character.isLetter('3');        // false

Character.isDigit('6');         // true
Character.isDigit('?');         // false
```

~~~~exercism/note
بعض الطرق في صنف Character لها نسخة محمّلة بحيث يمكنها أن تقبل إما `char` أو `int`.
على سبيل المثال، للطريقة `isDigit` نسخة تقبل [`char`][is-digit-char] وأخرى تقبل [`int`][is-digit-int].
وكما ذُكر سابقًا، يمكن لنوع `char` أن يمثّل المحارف في النطاق من 0x0000 إلى 0xFFFF فقط.
أما `int`، فيمكنه تمثيل جميع المحارف، ومن هنا جاءت النسخ المحمّلة التي تقبل `int`.

[is-digit-char]: https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/Character.html#isDigit(char)
[is-digit-int]: https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/Character.html#isDigit(int)
~~~~

## إضافة `char` إلى `String`

يمكن استخدام العامل `+` لإضافة `char` إلى `String`.

```java
'a' + " banana"     // => "a banana"
"banana " + 'a'     // => "banana a"
```

~~~~exercism/caution
احترس من _ألّا_ تستخدم `+` لضم محرفَي `char` معًا لتكوين `String`!
فجمع محرفَي `char` بهذه الطريقة يعطي `int`، _وليس_ `String`!
على سبيل المثال:

```java
'b' + 'c';
// => 197 (not the String "bc")
```

وذلك لأن Java تُرقّي `char` إلى `int` (انظر [4.2 Primitive Types and Values ][jls-primitives] من [Java Language Specification][jls-main]).

[jls-main]: https://docs.oracle.com/javase/specs/jls/se21/html/
[jls-primitives]: https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.2
~~~~

ولكن عندما يكون هناك العديد من المحارف التي يجب إضافتها، فقد يكون استخدام [`StringBuilder`][docs-stringBuilder] أكثر كفاءة:

```java
StringBuilder builder = new StringBuilder();
builder.append('a');
builder.append('b');
builder.append('c');

String builtString = builder.toString();
// => abc
```
