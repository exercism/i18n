# الاختبارات

قبل محاولة تنفيذ الاختبارات، تأكد من إعداد مجلد التمرين بشكل صحيح عبر اتباع خطوات التثبيت، وتحديدًا `corepack yarn install` وإعداد Editor SDK.

نفّذ الاختبارات باستخدام:

```bash
$ corepack yarn test
```

احرص على أن يتبع كودك أفضل الممارسات، كما يفعل المستخدمون الآخرون، باستخدام eslint، وهي أداة تُجري تحليلًا ساكنًا على كودك.
أدوات كهذه توفّر عليك بعض الوقت في اكتشاف الأخطاء المطبعية أو الأخطاء السخيفة في كودك:

```bash
$ corepack yarn lint
```

أو نفّذ الاثنين في الوقت نفسه:

```bash
$ corepack yarn test && corepack yarn lint
```

لا يفرض مسار TypeScript على Exercism _أسلوب_ الكود، لذا لك حرية الاختيار بين الفواصل المنقوطة، وعلامات الجدولة مقابل المسافات، وكل ما يقع بينهما.

## إنشاء وحدتك الأولى

عادةً ما تحمّل الاختبارات في هذا المسار تطبيقك عن طريق استيراده كوحدة: `import Bob from './bob';`.
ولكي يعمل ذلك، عليك تصدير تطبيقك من الملف الذي تبحث فيه الاختبارات عن وحدتك، وهو `bob.ts`:

```typescript
export class Bob {
  public hey(message: string) {
    // Your solution here
  }
}
```

لقد وفّرنا هياكل أولية في كل تمرين ووضعنا فيه عبارة `export` هذه من أجلك.
