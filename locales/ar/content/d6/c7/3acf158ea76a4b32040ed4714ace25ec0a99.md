# ملحق التعليمات

## الكلمات

عرّف صفًا باسم `linked-list-node`.

عرّف صفًا باسم `linked-list` ووفّر طريقة `M: linked-list length` (من `sequences`) حتى تستطيع الاختبارات استدعاء `length` مباشرةً على قائمتك.

- `<linked-list> ( -- linked-list )`: لإنشاء قائمة فارغة.
- `>linked-list ( seq -- linked-list )`: لدفع كل عنصر من `seq` إلى قائمة جديدة، بالترتيب.
- `linked-list>array ( linked-list -- array )`: لإرجاع القيم، بدءًا من قمة القائمة.
- `list-push ( linked-list value -- linked-list )`: لدفع قيمة إلى القمة.
- `list-pop ( linked-list -- linked-list value )`: لحذف قيمة القمة وإرجاعها.
- `list-peek ( linked-list -- value )`: لإرجاع قيمة القمة دون حذفها.
- `list-reverse ( linked-list -- linked-list )`: لإرجاع قائمة بعناصرها بترتيب معكوس.

اطرح صنف خطأ `list-empty` من `list-pop` و`list-peek` عندما تكون القائمة فارغة.
