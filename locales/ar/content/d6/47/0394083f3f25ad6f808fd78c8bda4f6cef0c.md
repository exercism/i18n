# حول الدوال المجهولة والإغلاقات

تسمح PHP بتعريف الدوال داخل دوال أخرى. لا تحتاج هذه الدوال إلى اسم، لكن يمكن إسنادها إلى متغيرات أو حتى تمريرها مباشرة إلى دالة أخرى تتطلب معامل دالة.

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, function($num) {
        return $num % 2 === 1;
    });
}
```

الدالة المعرَّفة والممرَّرة إلى `array_filter` أعلاه هي دالة مجهولة. تستخدم دالة `array_filter` هذه الدالة لتحديد ما إذا كانت قيمة معينة في مصفوفة ستُرجَع ضمن نتيجة `array_filter`. إذا أرجعت الدالة `true` لقيمة ما، فستُضمَّن تلك القيمة في مصفوفة النتيجة.

يمكن أيضًا استخدام الدوال المجهولة للإشارة من داخل الدالة إلى متغيرات تقع في نطاق خارجها. يُعرف هذا بأن نطاق الدالة «يُغلق» على المتغير المستخدم فيها، ومن هنا جاء اسم «إغلاق». في بعض اللغات، يُسمح تلقائيًا باستخدام كل المتغيرات الواقعة في النطاق داخل الإغلاق. أما في PHP، فيُسمح تلقائيًا باستخدام `$this`، الذي يشير إلى الكائن الحالي، داخل الإغلاق. أما بقية المتغيرات فيجب الإشارة إليها صراحةً باستخدام الكلمة المفتاحية `use`.

```php
function makeAdderFunction(int $number) {
    return function(int $x) use($number) {
        return $x + $number;
    }
}

$add5 = makeAdderFunction(5);
echo $add5(4); // echos 9
```

في دالة `makeAdderFunction` أعلاه، تُغلَق قيمة `$number` الممرَّرة داخل الدالة المجهولة المعرَّفة داخليًا، والتي تُرجَع بعد ذلك. ثم متى نُفِّذت تلك الدالة فإنها تعرف قيمة `$number` التي مُرِّرت. وإذا استدعيت هذه الدالة مرة أخرى برقم آخر، فستُرجع دالة مختلفة تمامًا. ولن يغيّر ذلك القيم أو السلوك الذي أرجعه استدعاء الدالة الأول.
إذا احتجت إلى الإغلاق على أكثر من متغير واحد، فيمكن إضافتها إلى الكلمة المفتاحية `use` مفصولةً بفاصلة.

تمتلك PHP أيضًا صيغة أقصر للدوال تُسمى `arrow functions`. ويُشترط أن تكون بسيطة إلى حد كبير. وشكلها الأساسي هو:

```php
fn(arguments) => expression
```

في هذا النمط من الدوال، لا تحتاج إلى استخدام `use`. فهي تُغلق تلقائيًا على أي قيم في النطاق الأب وتلتقطها. ويُرجَع التعبير في هذه الدوال السهمية تلقائيًا دون الحاجة إلى استخدام الكلمة المفتاحية `return`. وهذا يسمح لنا بإعادة كتابة دالة `onlyOdds` أعلاه على النحو التالي:

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, fn($n) => $n % 2 == 1);
}
```

ويمكن إعادة كتابة `makeAdderFunction` أعلاه هكذا:

```php
function makeAdderFunction(int $number) {
    return fn(int $x) => $x + $number;
}
```

**ملاحظة:** إذا تعذّر كتابة الدالة على هيئة تعبير، فلا يمكن استخدام صيغة الدوال السهمية الأقصر.

تُمرَّر المتغيرات إلى الدوال المجهولة والإغلاقات وتُستخدم داخلها بالقيمة. وهذا يعني أنك إذا غيّرت قيمة المتغير داخل الدالة، فلن يؤثر ذلك على قيمة المتغير خارج الدالة. وإذا احتجت إلى تعديل القيمة، فيمكنك تمريرها بالمرجع.

```php
function positiveAverage(array $numbers): float
{
    $total = 0;
    $count = 0;
    return array_walk(
      $numbers,
      function($num) use (&$count, &$total) {
          $total += abs($num);
          $count++;
      }
    );
    return $total / $count;
}
```

في المثال أعلاه، تمر `array_walk` على كل عنصر في المصفوفة، وترسل كل قيمة إلى الدالة المُعرَّفة في الاستدعاء. وهي تحتفظ بمجموع تراكمي في `$total`، حيث تكون كل قيمة تُضاف هي القيمة المطلقة للعدد. كما تتابع عدد الأعداد الموجودة. ويُستخدم كلا المتغيرين في الإغلاق بالمرجع، ويُشار إلى ذلك بعلامة `&` أمام كل متغير داخل قسم `use`. وهذا يعني أن التغييرات التي تطرأ على المتغيرين ستبقى سارية عند اكتمال `array_walk`، فتتمكن الدالة من إرجاع متوسط القيم المطلقة للأعداد في المصفوفة.

يمكن أن توفر الدوال المجهولة والإغلاقات أسلوبًا مريحًا لتعريف دالة قد لا تحتاج إليها إلا في سياق واحد، أو لتعريف دالة تُرجع دالة ديناميكية استنادًا إلى مجموعة من المعاملات المعروفة في وقت مختلف عن وقت استخدام الدالة فعليًا.
