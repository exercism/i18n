# مقدمة

## الأعداد

من [الدليل][man-types]

> يدعم jq المجموعة نفسها من أنواع البيانات التي يدعمها JSON: الأعداد، والسلاسل النصية، والقيم المنطقية، والمصفوفات، والكائنات (وهي في لغة JSON جداول تجزئة لا تحتوي إلا على مفاتيح نصية)، و"null".

لنركّز على **الأعداد**.

### الأعداد والعوامل العددية

جميع الأعداد، سواء كانت صحيحة أو غير ذلك، هي أعداد ذات فاصلة عائمة مزدوجة الدقة وفق معيار IEEE754. وهذا يقيّدنا بدقة مقدارها 53 بت.

العوامل المعتادة متاحة للاستخدام مع الأعداد:

- الحساب: `+`, `-`, `*`, `/`, `%`
- المقارنة: `==`, `!=`, `<`, `<=`, `>=`, `>`
- [دوال الرياضيات][man-math] القياسية

  بالنسبة للدوال ذات المُدخل الواحد، مرّر القيمة إلى الدالة عبر الأنبوب

  ```sh
  $ jq -n '(1 | atan) * 4'
  3.141592653589793
  ```

  بالنسبة للدوال ذات المُدخلين، تتجاهل الدوال المُدخل وتتوقع المُدخلين كمعاملات (تذكّر أن المعاملات تفصل بينها الفواصل المنقوطة)

  ```sh
  $ jq -n 'pow(2; 10)'
  1024
  ```

  الفاصلة المنقوطة هي الفاصل بين وسائط الدالة، لا الفاصلة.

### تعبيرات `jq` أخرى

لحل التمرين، ستحتاج إلى معرفة التعبيرات الشرطية.

#### التعبيرات الشرطية

يستخدم `jq` [تعبير `if-then-else`][if-then-else] من أجل **التعبيرات الشرطية**.
وبما أنه _تعبير_، فإنه يوضع داخل خط الأنابيب.

الصيغة هي: `if CONDITION then TRUE_EXPR else FALSE_EXPR end`.

عبارة `else` اختيارية.

```jq
42 | if . < 33 then "small" else "larger" end
# => "larger"
```

تُستخدم `elif` لإضافة شروط أخرى

```jq
42 | if . < 33 then "small"
     elif . < 67 then "medium"
     else "large"
     end
# => "medium"
```
