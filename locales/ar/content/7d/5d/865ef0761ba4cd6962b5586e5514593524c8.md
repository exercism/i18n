# مقدمة إلى القوائم

**القوائم** هي المجموعة ذات التسلسل المرتّب في Java.
وبخلاف المصفوفات، يستطيع [`List`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/List.html) أن ينمو في الحجم ليستوعب أي عدد من العناصر.
ومن التطبيقات القياسية `ArrayList`، وهو مبنيّ على مصفوفة قابلة لإعادة تغيير حجمها.
ومن التطبيقات القياسية الأخرى صنف `LinkedList`، وهو مبنيّ على قائمة مترابطة ثنائية الاتجاه.

قد تكون كائنات `List` فارغة أو تحمل أي عدد من العناصر (بما في ذلك العناصر المكرّرة).
والقوائم `List` هي **واجهة عامة** مُقيَّدة بنوع يحدّد نوع الكائنات التي يمكن أن تحتوي عليها.
على سبيل المثال:

```java
List<String> emptyListOfStrings = List.of();
List<Integer> singleInteger = List.of(1);
List<Boolean> threeBooleans = List.of(true, false, true);
List<Object> listWithMultipleTypes = List.of("hello", 1, true);
```

توفّر القوائم `List` طُرقًا مفيدة متعددة لإضافة عنصر أو حذفه أو جلبه أو التحقق من وجوده:

```java
List<Character> vowels = new ArrayList<>(List.of('a', 'e', 'i', 'o', 'i', 'e', 'a'));
int startingSize = vowels.size(); // 7
vowels.add('u'); // vowels is now ['a', 'e', 'i', 'o', 'i', 'e', 'a', 'u']
char a = vowels.get(0); // 'a'
boolean hadI = vowels.remove('i'); // true and vowels is now ['a', 'e', 'o', 'i', 'e', 'a', 'u']
boolean hasI = vowels.contains('i'); // true (still have one more left)
```
