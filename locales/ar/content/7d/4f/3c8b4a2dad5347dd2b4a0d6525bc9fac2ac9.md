# مقدمة

الاستثناءات شكل من أشكال معالجة الأخطاء. وسُمّيت استثناءات لأنها تظهر عادةً عند التعامل مع حدث غير متوقع.

في أي موضع من الكود يمكننا رفع استثناء. ونفعل ذلك باستخدام طريقة `raise`، بتمرير كائن إليها، وهو عادةً كائن `Exception`، مع أننا نستطيع أيضًا استخدام سلاسل نصية بسيطة.
على سبيل المثال، سترى في هياكل التمارين الأولية أننا نستخدم `RuntimeError` المدمج لإخبار Ruby بأن طريقةً ما لم تُنفَّذ بعد.
ويمكنك أيضًا استخدام الصيغة المختصرة `raise(ExceptionObject, params)`.
وإذا حُذف صنف الاستثناء، استُخدم `RuntimeError` افتراضيًا.
على سبيل المثال:

```ruby
# These are equivalent
raise RuntimeError.new("Please implement this method")
raise RuntimeError, "Please implement this method"
raise "Please implement this method"
```

عندما يرى Ruby هذا، فإنه يُصعّد الخطأ إلى أعلى البرنامج ثم يخرج.
على سبيل المثال، إذا حاولت قسمة شيء ما على صفر، سترى شيئًا كهذا:
```ruby
5/0

#=> Traceback (most recent call last):
#=> ...
#=> ZeroDivisionError (divided by 0)
```
