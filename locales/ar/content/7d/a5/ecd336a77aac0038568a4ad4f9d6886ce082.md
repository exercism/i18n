# مقدمة

## التحميل الزائد للعوامل

يمكن تكييف العوامل الحسابية وعوامل المقارنة الرئيسية لتستخدمها أصنافك وبنياتك الخاصة. ويُعرف هذا باسم _التحميل الزائد للعوامل_.

تأخذ معظم العوامل الصيغة التالية:

```csharp
static <return type> operator <operator symbols>(<parameters>);
```

وتأخذ عوامل التحويل الصيغة التالية:

```csharp
static (explicit|implicit) operator <cast-to-type>(<cast-from-type> <parameter name>);
```

تتصرّف العوامل بالكيفية نفسها التي تتصرّف بها الطرق `static`. فرمز العامل يحلّ محل مُعرِّف الطريقة، ولها معاملات ونوع إرجاع. وتتبع قواعد الأنواع الخاصة بالمعاملات ونوع الإرجاع حدسك، ويمكنك الاعتماد على المترجم لتقديم إرشاد مفصّل.
