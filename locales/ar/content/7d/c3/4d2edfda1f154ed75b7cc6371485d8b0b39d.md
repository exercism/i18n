# التعليمات

ترجم تسلسلات الحمض النووي الريبوزي (RNA) إلى بروتينات.

يمكن تقسيم RNA إلى تسلسلات من ثلاثة نيوكليوتيدات تُسمى الكودونات، ثم تُترجم إلى عديد ببتيد كما يلي:

RNA: `"AUGUUUUCU"` => تُترجم إلى

الكودونات: `"AUG", "UUU", "UCU"`
=> لتصبح عديد ببتيد بالتسلسل التالي =>

البروتين: `"Methionine", "Phenylalanine", "Serine"`

هناك 64 كودونًا تقابل بدورها 20 حمضًا أمينيًا؛ لكن ليست كل تسلسلات الكودونات والأحماض الأمينية الناتجة مهمة في هذا التمرين.
إذا نجح الأمر مع كودون واحد، فينبغي أن ينجح البرنامج معها جميعًا.
ومع ذلك، لا تتردد في توسيع القائمة في مجموعة الاختبارات لتشملها كلها.

هناك أيضًا ثلاثة كودونات مُنهية (تُعرف أيضًا باسم كودونات «STOP»)؛ إذا صادف الريبوسوم أيًا من هذه الكودونات، تنتهي عملية الترجمة بالكامل ويتوقف بناء البروتين.

تُتجاهل بعد ذلك جميع الكودونات التالية، هكذا:

RNA: `"AUGUUUUCUUAAAUG"` =>

الكودونات: `"AUG", "UUU", "UCU", "UAA", "AUG"` =>

البروتين: `"Methionine", "Phenylalanine", "Serine"`

لاحظ أن كودون التوقف `"UAA"` يُنهي الترجمة، فلا يُترجم الميثيونين الأخير إلى تسلسل البروتين.

فيما يلي الكودونات والأحماض الأمينية الناتجة المطلوبة في هذا التمرين.

| الكودون             | البروتين      |
| :----------------- | :------------ |
| AUG                | Methionine    |
| UUU, UUC           | Phenylalanine |
| UUA, UUG           | Leucine       |
| UCU, UCC, UCA, UCG | Serine        |
| UAU, UAC           | Tyrosine      |
| UGU, UGC           | Cysteine      |
| UGG                | Tryptophan    |
| UAA, UAG, UGA      | STOP          |

تعرّف على المزيد حول [ترجمة البروتين على ويكيبيديا][protein-translation].

[protein-translation]: https://en.wikipedia.org/wiki/Translation_(biology)
