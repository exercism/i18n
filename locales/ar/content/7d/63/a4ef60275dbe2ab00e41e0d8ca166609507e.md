# التعليمات

يخطّط صديقك تشاندلر لزيارة بلدان غريبة في جميع أنحاء العالم.
وللأسف، مهارات تشاندلر في الرياضيات ليست جيدة.
وهو قلق جدًا من أن يتعرّض للاحتيال في محلات صرف العملات أثناء رحلته، ويريد منك أن تصنع له حاسبة عملات.

وهذه هي مواصفاته للتطبيق.

~~~~exercism/note
الدوال في هذا التمرين معلنة في ملف مصدري بلغة C بالتوقيعات المرفقة.
يجب أن يتبع كود x86-64-assembly الخاص بك هذه المواصفات.
~~~~

## 1. تتبّع العملات المختلفة

لقد أنشأت `enum currency_t` لتتبّع العملات المختلفة التي يستخدمها تشاندلر في رحلاته:

```c
enum currency_t {
    GBP,
    EUR,
    JPY,
    AUD,
    BRL,
    CNY,
    CAD,
    INR
};
```

تحتاج أحيانًا إلى طباعة هذه العملات على الشاشة لتتحقق مما إذا كانت صحيحة.

أنشئ الدالة `stringify_currency`:

```c
void stringify_currency(char *buffer, enum currency_t currency);
```

لا تُرجع هذه الدالة أي قيمة، وينبغي أن تخزّن سلسلة نصية بأسلوب C في الموقع الذي يشير إليه `buffer`.
ينبغي أن تمثّل السلسلة النصية بصريًا نوع العملة التي مُرّرت إلى الدالة:

```c
char buffer[4];
stringify_currency(buffer, CAD);
// => "CAD"
```

## 2. تحقّق من سعر الصرف

أنشئ الدالة `exchange_rate`:

```c
double exchange_rate(enum currency_t domestic_currency, enum currency_t foreign_currency, const double *value_in_US_dollars);
```

يمثّل الوسيط `domestic_currency` عملة تشاندلر المحلية التي ستُصرف مقابل `foreign_currency`.

`value_in_US_dollars` هو مؤشر إلى مصفوفة من النوع `double` تحتوي على قيمة وحدة واحدة من كل عملة بالدولار الأمريكي.
العملات هي فهارس في هذه المصفوفة.
فإذا كان `EUR` عنصرًا صالحًا في `enum currency_t`، فإن `value_in_US_dollars[EUR]` يعطي قيمة `1 EUR` بالدولار الأمريكي.

ينبغي أن تُرجع هذه الدالة قيمة وحدة واحدة من العملة الأجنبية بالعملة المحلية.

```c
const double value_in_US_dollars[8] = {
    1.33329, 1.16443, 0.00654374, 0.650888,
    0.185577, 0.140420, 0.714142, 0.0113863
};

exchange_rate(JPY, GBP, value_in_US_dollars);
// => 203.750454633
```

## 3. احسب قيمة الأوراق النقدية

أنشئ الدالة `get_value_of_bills`:

```c
uint64_t get_value_of_bills(unsigned long long denomination, unsigned short number_of_bills);
```

الوسيط `denomination` هو قيمة ورقة نقدية واحدة، أما `number_of_bills` فهو العدد الإجمالي للأوراق النقدية.

لا يتعامل كشك الصرف هذا إلا مع نقود نقدية بمضاعفات محددة.
يجب أن يكون الإجمالي الذي تحصل عليه قابلًا للقسمة على قيمة "ورقة" واحدة أو وحدة واحدة، وقد يتبقى كسر أو باقٍ.
ينبغي أن تُرجع دالتك القيمة الإجمالية للأوراق النقدية فقط (_باستثناء المبالغ الكسرية_) التي سيعيدها الكشك.
ولسوء الحظ، يحتفظ الكشك بالباقي/الفكة كمكافأة إضافية.

```c
get_value_of_bills(5, 128);
// => 640
```

## 4. احسب عدد الأوراق النقدية

أنشئ الدالة `get_number_of_bills`:

```c
unsigned int get_number_of_bills(float amount, unsigned long long denomination);
```

ينبغي أن تُرجع هذه الدالة _عدد الأوراق النقدية_ التي يمكنك الحصول عليها ضمن _المبلغ_ المعطى.
بعبارة أخرى: كم عدد _الأوراق النقدية الكاملة_ التي تتسع لها قيمة المبلغ المبدئي؟
تذكّر أنك لا تستطيع الحصول إلا على _أوراق نقدية كاملة_، لا أجزاء من الأوراق، لذا تذكّر أن تقسم على هذا الأساس.
أنت في الواقع تقرّب _للأسفل_ إلى أقرب ورقة/فئة نقدية كاملة.

```c
get_number_of_bills(127.5, 5);
// => 25
```

## 5. احسب القيمة بعد الصرف

أنشئ الدالة `exchangeable_value`:

```c
uint32_t exchangeable_value(float budget, double exchange_rate, uint8_t spread, unsigned long long denomination);
```

المعامل `spread` هو _النسبة المئوية المقتطعة_ كرسوم صرف، مكتوبة كعدد صحيح.
يجب تحويله إلى قيمة عشرية بقسمته على 100.
لاحظ أن الهامش يُضاف إلى سعر الصرف، بحيث يؤدي هامش قدره `10` إلى سعر صرف أعلى بنسبة 10%.

ينبغي أن تُرجع هذه الدالة القيمة القصوى للعملة الجديدة بعد حساب *سعر الصرف* المعدّل حسب *الهامش*.
تذكّر أن *فئة* العملة عدد صحيح، ولا يمكن تجزئتها.

```c
exchangeable_value(127.25, 0,873350884, 10, 20);
// => 120
exchangeable_value(127.25, 0,873350884, 10, 5);
// => 130
```
