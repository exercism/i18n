# مقدمة

افتراضيًا، تقتصر المتغيرات على النطاق الذي تُعرَّف فيه. وإذا عُرِّفت في ملف خارج دالة أو صنف، فإنها تقتصر على نطاق الملف. وإذا عُرِّفت داخل دالة أو صنف، فإنها تقتصر على نطاق الدالة أو الصنف.

```php
<?php

$file_scoped = "I am file scoped";

function example(): void
{
  $function_scoped = "I am function scoped!";
}
```

ويمكن أيضًا الإعلان عن المتغيرات لتكون ذات نطاق `global` أو `static`.
