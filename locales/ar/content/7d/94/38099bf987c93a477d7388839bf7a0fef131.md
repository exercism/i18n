# التعليمات

في هذا التمرين، ستحتاج إلى تنفيذ بعض الطرق للتعامل مع مصفوفة من لغات البرمجة.

## 1. عرّف طريقة تُرجع مصفوفة لغات فارغة

عرّف الطريقة `LanguageList.list` التي لا تأخذ أي وسائط وتُرجع مصفوفة فارغة من النوع `Array(String)`.

```crystal
LanguageList.list()
# => []
```

## 2. عرّف طريقة تضيف لغة إلى المصفوفة

عرّف الطريقة `LanguageList.add` التي تأخذ وسيطين (مصفوفة لغات و سلسلة نصية حرفية تمثل لغة).
ينبغي أن تُرجع الطريقة المصفوفة بعد إضافة اللغة الجديدة إلى نهاية المصفوفة.

```crystal
language_list = LanguageList.list()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
```

## 3. عرّف طريقة تحذف لغة من المصفوفة

عرّف الطريقة `LanguageList.remove` التي تأخذ وسيطًا واحدًا (مصفوفة لغات).
ينبغي أن تُرجع الطريقة المصفوفة دون العنصر الأخير.
افترض أن المصفوفة تحتوي دائما على عنصر واحد على الأقل.

```crystal
language_list = LanguageList.list()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
language_list = LanguageList.remove(language_list)
# => ["Crystal"]
```

## 4. عرّف طريقة تُرجع العنصر رقم n في المصفوفة

عرّف الطريقة `LanguageList.at` التي تأخذ وسيطين (مصفوفة لغات و فهرس).
ينبغي أن تُرجع الطريقة اللغة الموجودة عند الفهرس n في المصفوفة.
افترض أن هناك دائما لغة عند هذا الفهرس.

```crystal
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
LanguageList.at(language_list, 1)
# => "Ruby"
```

## 5. عرّف طريقة تحلّل سلسلة نصية من اللغات

عرّف الطريقة `LanguageList.parse` التي تأخذ وسيطًا واحدًا (سلسلة نصية حرفية من اللغات مفصولة بفاصلة).
ينبغي أن تُرجع الطريقة مصفوفة من اللغات.

```crystal
LanguageList.parse("Crystal, Ruby")
# => ["Crystal", "Ruby"]
```
