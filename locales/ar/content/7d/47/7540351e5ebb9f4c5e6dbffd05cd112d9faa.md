# ملحق التعليمات

## تنسيق الحديقة

تُمثَّل الحديقة بسلسلة نصية منتهية بـ `null`، مع محرف سطر جديد في نهاية كل صف.

ومن الأمثلة على ذلك `"   \n * \n   \n"`

## السجلات

| السجل    | الاستخدام    | النوع   | الوصف                              |
| -------- | ------------ | ------- | ---------------------------------- |
| `$a0`    | إدخال        | عنوان   | سلسلة الإدخال النصية المنتهية بـ `null`  |
| `$a1`    | إدخال/إخراج  | عنوان   | سلسلة الإخراج النصية المنتهية بـ `null`  |
| `$t0-9`  | مؤقت         | أي      | للتخزين المؤقت                     |
