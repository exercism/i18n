# تشغيل الاختبارات

لتشغيل اختبار تمرين معيّن، انتقل بـ `cd` إلى مجلد التمرين ثم شغّل ما يلي:

```bash 
box task run TestRunner
# Or start up a test watcher that will rerun when files change
box task run TestRunner --:watcher
```

تعتمد الاختبارات على مكتبة تُسمى TestBox تدعم أسلوبي الاختبار xUnit وBDD. ستُكتب جميع مجموعات الاختبار بنمط [BDD](https://testbox.ortusbooks.com/content/primers/bdd/specs.html)، وهو نمط يستخدم الإغلاقات لتعريف مواصفات الاختبار. لن تحتاج إلى القلق بشأن تثبيت TestBox، فمُشغّل الاختبارات في واجهة سطر الأوامر سيتولى ذلك عنك. كل ما عليك هو أن تكون متصلًا بالإنترنت في أول مرة تشغّله. يمكنك قراءة المزيد عنه هنا:

[https://testbox.ortusbooks.com](https://testbox.ortusbooks.com)
