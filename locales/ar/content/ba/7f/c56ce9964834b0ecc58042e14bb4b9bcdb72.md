# مقدمة

توفّر العديد من اللغات وسيلة مثل `null` أو `none` للإشارة إلى قيمة غير موجودة.
ولأن R مصمَّمة للتعامل مع كميات ضخمة من البيانات (الفوضوية في كثير من الأحيان)، فإنها تمتلك عدة صور للعدم.

الهدف العام هو الإشارة إلى القيم المفقودة أو المشكوك فيها عند مواجهتها، ثم المتابعة دون رفع استثناء.

## NULL

إذا لم تكن القيمة موجودة فعلًا، فإنها تُمثَّل بـ `NULL`. وهذا على الأرجح أقرب ما تفعله C أو Python.

```R
v <- c() # zero-length vector
v
#> NULL
is.null(v)
#> [1] TRUE
```

في سياقات كثيرة، تُتجاهل قيم `NULL` ببساطة:

```R
c(2, 3, NULL, 5)
#> [1] 2 3 5
```

## NA

في الحالات التي توجد فيها قيمة لكننا لا نعرف ما هي، نستخدم `NA`. على سبيل المثال، عند عدّ المركبات التي تسير على طريق ما، قد يمرض المراقبون البشريون أو تتعطل المستشعرات الآلية، لكن حركة المرور تستمر.

```R
v <- c(1, 2, NA, 4, 5)
v
#> [1]  1  2 NA 4  5
is.na(v) # test for data gaps
#> [1] FALSE FALSE  TRUE FALSE FALSE
```

وهكذا فإن `NA` قيمة نائبة تُنبّه البشر إلى أنهم بحاجة إلى اتخاذ قرار بشأن كيفية التعامل معها.

## المتجهات الفارغة

وربما من المفاجئ أن R لا تمتلك طريقة قياسية للتحقق من الفراغ، رغم أن بعض الحزم الخارجية تنفّذ دوالها الخاصة مثل `is.empty()`.

حتى إنشاء متجه فارغ ليس بالأمر الواضح تمامًا.
رأينا في قسم سابق أن `c()` بدون وسائط تُرجع `NULL`، وليس متجهًا.

```R
is.vector(c())
#> [1] FALSE
```

تأخذ دوال مثل `logical()` أو `integer()` وسيطًا يحدد الطول المطلوب، وقد يكون هذا الطول صفرًا.

```R
z <- logical(0)
is.vector(z)
#> [1] TRUE
length(z)
#> [1] 0
```

يمكننا أيضًا إنشاء متجه ثم حذف كل عنصر من عناصره، كما هو موضح في [مفهوم المتجهات][concept-vectors].
ينتج عن ذلك متجه بطول صفر من النوع المناسب.

```R
v <- 5
v[-1]  # delete the first element
#> numeric(0)
```
