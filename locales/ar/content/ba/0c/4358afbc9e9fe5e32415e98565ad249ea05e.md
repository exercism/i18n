# مقدمة

## عامل الأنبوب

يُسمى العامل `|>` عامل الأنبوب. يمكن استخدامه لربط استدعاءات الدوال معًا بحيث تُمرَّر القيمة التي أرجعها استدعاء الدالة السابق إلى استدعاء الدالة التالي.

```gleam
"hello"
|> string.uppercase
|> string.append("?!")
// -> "HELLO?!"
```

الكود أعلاه مكافئ لما يلي:

```gleam
string.append(string.uppercase("hello"), "?!")
```

سيُمرِّر عامل الأنبوب القيمة إما كوسيط أول إلى استدعاء الدالة، أو كوسيط وحيد إلى استدعاء جديد، حسب أيهما له النوع الصحيح.

```gleam
100
|> function_that_takes_two_arguments(1)

// Is equivalent to
function_that_takes_two_arguments(100, 1)
```

```gleam
100
|> function_that_returns_a_function(1)

// Is equivalent to
function_that_returns_a_function(1)(100)
```

أحيانًا نريد تمرير القيمة إلى موضع آخر، وفي هذه الحالة يمكن استخدام العنصر النائب `_` للإشارة إلى الموضع الذي ينبغي إدراج القيمة فيه.

```gleam
100
|> some_function(1, _, 2)
```
