# التعليمات

أنت من يُطلق الإشارات في عرض مدرستك. يريد مدير المسرح تدوين السطور القياسية حتى يتمكن أي شخص من إدارة طاولة التحكم.

لديك أربع مهام، جميعها في صنف `STAGE_DIRECTIONS`.

## 1. أعلِن بداية العرض

أرجِع السطر الذي يفتتح العرض.

```sather
STAGE_DIRECTIONS::opening_line
-- => "The curtain rises."
```

## 2. أعلِن الفاصل

أرجِع السطر الذي يُنادى به عند منتصف العرض.

```sather
STAGE_DIRECTIONS::interval_line
-- => "Interval. Fifteen minutes."
```

## 3. أعلِن النهاية

أرجِع السطر الذي يختتم العرض.

```sather
STAGE_DIRECTIONS::closing_line
-- => "The curtain falls."
```

## 4. أطلِق الإشارة الأخيرة

الإشارة الأخيرة هي نفس السطر الذي يختتم العرض. وبدلًا من كتابة النص مرة ثانية، استدعِ الدالة التي كتبتها بالفعل.

```sather
STAGE_DIRECTIONS::final_cue
-- => "The curtain falls."
```
