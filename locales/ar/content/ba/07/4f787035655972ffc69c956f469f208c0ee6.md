# المقدمة

تذكّر أن برنامج `jq` هو _خط أنابيب من التعبيرات_.
**إسناد المتغير** يتبع هذه القاعدة: _إسناد المتغير_ تعبير يبدو كالتالي:

```jq
... | expr as $varname | ...
```

## ناتج المرشّح هو المُدخل

مثل _تعبير الهوية_ `.`، فإن ناتج _إسناد المتغير_ هو نفسه مُدخله.
وضبط قيمة المتغير أثر جانبي.

مثال يوضّح أن `.` بعد الإسناد هو نفسه المُدخل الأولي:

```sh
$ jq -c -n '42 | (. * 2) as $double | [., $double]'
[42,84]
```

## نطاق المتغير

نطاق المتغير «معجمي»، أي أن المتغير يبقى داخل النطاق لبقية خط الأنابيب.
أما المتغيرات المعرَّفة داخل الدوال (وسنصل إلى الدوال لاحقًا) فهي «محلية» بالنسبة إلى الدالة.

## أسماء المتغيرات

يجب أن يبدأ المتغير بـ `$`.
وباقي اسم المتغير هو **معرّف**: يبدأ بحرف أو شرطة سفلية، تتبعه حروف أو أرقام أو شرطات سفلية.

## إسناد التفكيك

من الدليل:

> يمكن الإعلان عن عدة متغيرات باستخدام تعبير `as` واحد، وذلك بتقديم نمط _يطابق بنية المُدخل_ (وهذا ما يُعرف بـ «التفكيك»).

أمثلة:

```jq
[1, 2, 3] as [$a, $b, $c]
| [$a, $b, $c]     # => [1, 2, 3]
```

```jq
{"foo": "bar", "len": [10, 20]} as {foo: $f, len: [$h, $w]}
| [$f, $h, $w]     # => ["bar", 10, 20]
```

مطابقة اسم المتغير مع _مفتاح الكائن_ توفّر اختصارًا:

```jq
{"x": 4, "y": 7} as {$x, $y}
| [$x, $y]         # => [4, 7]
```

```jq
{"foo": "bar", "len": [10, 20]} as {$foo, $len}
| [$foo, $len]     # => ["bar", [10, 20]]
```

## الثوابت

كما يظهر في المثال أعلاه، المتغيرات مفيدة لتخزين الثوابت.
ومن الأفضل أن تمنح الثوابت أسماء بدلًا من أن تظهر «الأرقام السحرية» في الكود.

## غالبًا لا حاجة إلى المتغيرات

غالبًا ما يكون حذف المتغيرات أسهل في القراءة.

تأمّل حساب متوسط مصفوفة من الأعداد

```jq
[2, 4, 8, 7]
| add as $sum
| length as $len
| $sum / $len
```

مقارنةً بـ

```jq
[2, 4, 8, 7] | add / length
```

وهذا يُبرز أحد أقوى جوانب `jq`: فالمُدخل إلى المرشّح يُقدَّم إلى _كل_ تعبير فرعي:

- تُمرَّر مصفوفة المُدخل `[2,4,8,7]` إلى `add` (التي تجمع الأعداد بتطبيق عامل `+` على كل العناصر)
- _وبالتوازي_، تُمرَّر `[2,4,8,7]` أيضًا إلى `length`
- وعندما تكتمل هذه التعبيرات الفرعية، تُقسَم نتائجها بعد ذلك، لتُعطي متوسط قيم الأعداد في مصفوفة المُدخل.

## عوامل `jq` التي ستحتاجها في تمرين التعلّم

### عامل البديل: `//`

التعبير `a // b` يُعطي `b` إذا كانت `a` تساوي خطأ أو null، وإلا فهو يُعطي `a`.
وفي سياق ضبط متغير، هذا مفيد جدًا لتوفير قيمة افتراضية:

```jq
(.input.theAnswer // 42) as $answer | ...
```

### عوامل الحساب

- `+` و`-` و`*` هي عوامل الجمع والطرح والضرب العددية المعتادة.
