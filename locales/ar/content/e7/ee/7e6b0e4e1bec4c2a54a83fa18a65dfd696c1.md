# مقدمة

هناك ثلاثة أنواع رئيسية من الجمل الشرطية المستخدمة في Julia:

- تعبيرات `if`
- العامل الثلاثي
- التقييم قصير الدائرة

## تعبيرات `if`

تعبيرات `if` في Julia شبيهة بتلك الموجودة في اللغات الأخرى:

```julia-repl
julia> function say_if_positive(n)
           if n > 0
               println("n is positive!")
           else
               println("n is not positive!")
           end
       end
say_if_positive (generic function with 1 method)

julia> say_if_positive(10)
n is positive!

julia> say_if_positive(-10)
n is not positive!
```

إذا كان ناتج تقييم التعبير المنطقي الذي يلي `if` هو `true`، فسيُنفَّذ أول بلوك من الكود وتُتخطى الكتلة الثانية.
وإذا كان ناتج تقييمه `false`، فستُتخطى أول كتلة من الكود وتُنفَّذ الكتلة الثانية.
ثم يواصل البرنامج التنفيذ من أول سطر كود بعد الكلمة المفتاحية `end`.

~~~~exercism/note
في Julia، تشير الكلمة المفتاحية `end` إلى نهاية جميع تعبيرات الكتل.
هذا التركيب ليس خاصًّا بتعبيرات `if` أو تعريفات الدوال.
~~~~

في الحالات التي تكون فيها الكتلة الثانية مجرد تعبير `if` آخر، يتيح لنا `elseif` تجنّب تضمين تعبيرات `if` داخل الكتلة:

```julia-repl
julia> function dessert(fruit)
           if fruit == "apple"
               return "Apple Crumble"
           elseif fruit == "lemon"
               return "Lemon Meringue Pie"
           else
               return "Fruit Salad"
           end
       end
dessert (generic function with 1 method)

julia> dessert("apple")
"Apple Crumble"

julia> dessert("lemon")
"Lemon Meringue Pie"

julia> dessert("peach")
"Fruit Salad"
```

إذا كان تعبير `if` لا يحتاج إلى تنفيذ الكود إلا في حالة واحدة، فلا حاجة لكتابة فرع `else`.

## العامل الثلاثي

يمكن أيضًا كتابة الجمل البسيطة من نوع `if-else` باستخدام العامل الثلاثي `a ? b : c`.
إذا كانت `a` صحيحة، فسيُقيَّم `b`.
وإلا فيُقيَّم `c`.

على سبيل المثال، الدالة التالية

```julia-repl
julia> function diagnose(heartrate)
           if heartrate > 100
               println("Elevated heart rate.")
           else
               println("Nominal heart rate or dead.")
           end
       end
diagnose (generic function with 1 method)
```

يمكن أيضًا كتابتها على النحو التالي

```julia-repl
julia> diagnose(heartrate) = heartrate > 100 ? println("Elevated heart rate.") : println("Nominal heart rate or dead.")
diagnose (generic function with 1 method)
```

يكون هذا مفيدًا بشكل خاص عندما تريد إسناد قيمة مختلفة إلى متغير بناءً على شرط.
عند تنفيذ `x = a ? b : c` سيُسنَد `b` إلى `x` إذا كانت `a` هي `true`، وإلا سيُسنَد `c` إلى `x`.
على سبيل المثال:

```julia-repl
julia> function patient_status(heartrate)
           status = heartrate > 0 ? "alive" : "dead"

           println("The patient is ", status)
       end

julia> patient_status(100)
The patient is alive

julia> patient_status(0)
The patient is dead
```

## التقييم قصير الدائرة

إذا رُبطت عدة تعبيرات منطقية معًا باستخدام العاملين `&&` و`||`، فلن تُقيّم Julia إلا أقل عدد ممكن من التعبيرات اللازمة لتحديد قيمة التسلسل بأكمله.

على سبيل المثال، تخيّل تسلسل التعبيرات `n > 0 && k > 10`.
إذا كان `n` يساوي `5`، فالجزء الأول من التسلسل، `n > 0`، يساوي `true`، ويصبح من الضروري تقييم التعبير الثاني `k > 10` لتحديد ما إذا كان التعبير بأكمله `true`.
ومع ذلك، إذا كان `n` يساوي `-5`، فنحن نعلم أن التسلسل بأكمله **لا يمكن** أن يكون `true` لأن تعبيره الأول `false`.

أما إذا نظرنا إلى `n > 0 || k > 10` بدلًا من ذلك، فسيحدث العكس.
إذا كان `n` يساوي `5`، فالجزء الأول من التسلسل، `n > 0`، يساوي `true`، ونعلم أن التسلسل بأكمله سيكون `true` بغض النظر عن التعبير الثاني.
ومع ذلك، إذا كان `n` يساوي `-5`، فيصبح من الضروري تقييم التعبير الثاني.

يمكن استخدام هذا السلوك لكتابة جمل `if` قصيرة جدًا:

```julia
if a
    b
end
```

يُكافئ

```julia
a && b
```

لا يلزم أن يكون التعبير الأخير في تسلسل من `&&` و`||` تعبيرًا منطقيًا.
ستجد هذه الميزة مستخدمة كثيرًا للأخطاء أو الإرجاع المبكر.
على سبيل المثال، باستخدام الدالة `dessert(fruit)` المذكورة أعلاه:

```julia-repl
julia> function whats_for_dessert(fruit, allergic_to)
           fruit == allergic_to && return "I can't eat that, guess I'll not have dessert tonight!"

           return dessert(fruit)
       end
whats_for_dinner (generic function with 1 method)

julia> whats_for_dinner("apple", "peach")
"Apple Crumble"

julia> whats_for_dinner("apple", "apple")
"I can't eat that, guess I'll not have dessert tonight!"
```
