# لا يوجد تصدير مُسمّى

لم يتم العثور على [تصدير](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/export) باسم `%{export.name}`. لن تنجح الاختبارات بدونه.

تأكد من وجود `%{export.name}` وأضف `export` أمامه:
```javascript
// exporting a "const"
export const %{export.name} = /*...*/

// exporting a named function declaration
export function %{export.name}() { /* ... */ }
```
