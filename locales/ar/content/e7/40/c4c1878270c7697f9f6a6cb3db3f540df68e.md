# الدوال في `jq`

يمكنك تعريف **دوال مخصصة** خاصة بك في `jq` لتغليف أي منطق تحتاجه.
_Dوال_ تعمل تمامًا مثل الدوال المدمجة: فهي تأخذ مدخلًا وتُخرج صفرًا أو واحدًا أو أكثر من المخرجات.

## تعريف دالة

يمكنك تعريف _دالة_ في `jq` باستخدام الصياغة التالية:

```jq
# no arguments
def funcname: expression;

# or with arguments
def funcname(args): expression;
```

- تبدأ بالكلمة المفتاحية `def`،
- ونقطتان رأسيتان قبل جسم الدالة،
- ويتكوّن الجسم من تعبير واحد،
- وتنتهي بفاصلة منقوطة،
- وكما هو الحال مع بقية صياغة `jq`، يمكنك استخدام أي قدر من المسافات لتحسين القراءة.

## أين توضع الدوال

_الدوال_ يجب تعريفها قبل استخدامها، وإلا فسيحدث خطأ:

```jq
def A: B(10);
def B(n): n + 1;
A
# => error: B/1 is not defined
```

وهذا يعني أنه عليك وضع _الدوال_ في أعلى كود `jq`، قبل التعبير «الرئيسي».

### الدوال المتداخلة

_الدوال_ يمكن أن تتداخل:

```jq
def A:
    def B(n): n + 1;
    B(10)
    ;
A
# => 11
```

هنا، لا تكون _الدالة_ `B` مرئية إلا داخل جسم `A`.

## النطاق

تُنشئ _الدالة_ **نطاقًا** جديدًا للمتغيرات والدوال المتداخلة.

## الوسائط

**وسائط** _الدالة_ تُفصل باستخدام _الفواصل المنقوطة_، لا الفواصل العادية.
على سبيل المثال، _دالة_ تأخذ عددًا، ثم تجمع عددًا وتضرب في عدد:

```jq
def add_mul(adder; multiplier): (. + adder) * multiplier;

10 | add_mul(5; 4)    # => 60
```

<!-- prettier-ignore -->
~~~~exercism/note
نحتاج إلى الفواصل المنقوطة لأن الفاصلة العادية لها استخدام قائم في `jq`: فهي عامل يضم التدفقات.

استخدام فاصلة بدل الفاصلة المنقوطة سيحاول إجراء استدعاءين لـ_دالة_ `add_mul` ذات _وسيط واحد_، وهي غير موجودة، ولذلك سيفشل عند أول استدعاء:

```jq
10 | add_mul(5, 4)
# error: add_mul/1 is not defined
```

الفاصلة في `5, 4` تدمج العددين 5 و4 في تدفق.
عندما نستدعي دالة بتدفق كوسيط، سيستدعي `jq` تلك الدالة عدة مرات، مرة لكل قيمة في التدفق.
هذا مثال على «التكرار الضمني» المتأصل في تدفقات `jq`.
`10 | add_mul(5, 4)` يكافئ ما يلي.

```jq
(10 | add_mul(5)), (10 | add_mul(4))
```
الآن يمكننا أن نرى كيف يظهر الخطأ `add_mul/1 is not defined`.
~~~~

<!-- prettier-ignore-end -->

### الوسائط _تعبيرات_

_وسائط_ الدالة مرشّحات، لا قيم.
وبهذا المعنى، فهي تعمل كما تعمل ما تسميه اللغات الأخرى دوال الاستدعاء الرجعي:

لنأخذ الدالة `add_mul` مثالًا:

```jq
10 | add_mul(. + 5; . - 2)    # => 200
```

ما الذي يحدث هنا؟

- يحصل الوسيط `adder` على _التعبير_ `. + 5`
  - فعندما تنفّذ الدالة `. + adder`، يصبح ذلك `. + . + 5`
  - وتكون قيمته 25 لأن `. == 10`
- وبالمثل، الوسيط `multiplier` هو التعبير `. - 2`
  - وتكون قيمته 8
  - ثم تكون النتيجة `25 * 8 == 200`

### الوسائط كقيم

قد ترغب أحيانًا في «تجسيد» _الوسيط_ في متغير:

```jq
def my_func(arg):
    arg as $arg
    | other stuff ...
;
```

وهناك صيغة مختصرة لذلك:

```jq
def my_func($arg):
    other stuff ...
;
```

لاحظ أن هذا مجرد «سكر نحوي»: فالاسم `arg` بدون `$` يظل داخل النطاق في _الدالة_.

<!-- prettier-ignore -->
~~~~exercism/caution
على سبيل المثال، كتبت شيئًا كهذا لحل تمرين:

```jq
# function that encodes the input value
def code:
    # expression here
    ;

def equals($code):
    (. | code) as $this_code
    | $code == $this_code
    ;

("some key value" | code) as $key
| ["array", "of", "values"]
| map(select(equals($key)))
```

وفوجئت بأن كل قيمة في المصفوفة كانت مساوية للمفتاح.

حدث هذا لأن jq رأى الدالة `equals` على النحو التالي

```jq
def equals(code):
    code as $code
    | (. | code) as $this_code
    | $code == $this_code
    ;
```

**الوسيط** `code` _طغى_ على **الدالة** `code` المعرّفة سابقًا.
وهذا يعني أن `(. | code)` يُخرج ببساطة **الوسيط** بدلًا من حساب كود جديد بناءً على قيمة المدخل.
وهكذا كان `$this_code` و`$code` متطابقين دائمًا.
~~~~

## عدد الوسائط

للدوال **عدد وسائط**، أي عدد _الوسائط_ التي تأخذها.

_الدوال_ يمكنها استخدام الاسم نفسه بعدد وسائط مختلف.
وتوضح دالة [`range`][man-range] المدمجة ذلك: فالدوال `range/1` و`range/2` و`range/3` تتعايش جميعًا.

وقد يفيد هذا في تعريف دوال ذاتية الاستدعاء تحمل حالتها عبر الوسائط.
على سبيل المثال، _يمكن_ تنفيذ `map` هكذا:

```jq
def my_map($accumulator; func):
    if length == 0
        then $accumulator
        else first as $elem | .[1:] | my_map($accumulator + [$elem | func]; func)
    end
    ;

def my_map(func):
    my_map([]; func)
    ;

[1, 2, 3, 4] | my_map(. * 10)   # => [10, 20, 30, 40]
```

## الاستدعاء الذاتي

يُجري `jq` تحسين الاستدعاء الذَيليّ، لكن للدوال التي عدد وسائطها 0 فقط.

## الوحدات

وحدة `jq` هي ملف لا يحتوي إلا على دوال.
وتُضمّن الوحدات في برنامج jq باستخدام الأمرين [`include`][man-include] أو [`import`][man-import].
