# to_i{bit}

يُعد استخدام طريقة `to_i{bit}` وسيلة صحيحة لتحويل قيمة إلى أساس معيّن.
لكن عند تعريف [عدد حرفي][int]، يصبح استخدام اللاحقة `_i{bit}` أكثر توافقًا مع الأسلوب المتبع.

```crystal
# Rather than:
500034214414.to_i64

# Consider:
500034214414_i64
```

[int]: https://crystal-lang.org/reference/latest/syntax_and_semantics/literals/integers.html
