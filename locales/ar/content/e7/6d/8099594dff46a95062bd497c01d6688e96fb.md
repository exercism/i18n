# مقدمة

## مطابقة الأنماط للقيم الحرفية

بينما يمكن استخدام تعبيرات `if/else` لتنفيذ منطق شرطي، فإن Haskell تمتلك أيضًا طريقة أقوى لتنفيذ المنطق الشرطي: [مطابقة الأنماط][pattern-matching].
باستخدام مطابقة الأنماط، يمكن اختبار قيمة ما مقابل نمط واحد أو أكثر.
ومن أمثلة هذه الأنماط _النمط الثابت_، وهو يطابق قيمة ما مع ثابت (مثل `1` أو `"hello"`).

عند تعريف الدوال، يمكنك تعريف أجسام دوال منفصلة لأنماط مختلفة.
وهذا يؤدي إلى كود نظيف بسيط وسهل القراءة.
يمكنك مطابقة الأنماط على أي نوع بيانات: الأعداد، والمحارف، والمصفوفات، والصفوف، إلخ.

على سبيل المثال، يمكن التعبير عن دالة بسيطة تأخذ عددًا صحيحًا (`Int`) وتجعله أقرب إلى _0_ بمقدار _1_ هكذا:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero 1 = 0
```

تبدأ مطابقة الأنماط في إظهار قوتها عندما تُستخدم مع أنماط أخرى، مثل _النمط المتغير_:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero n = n - 1
```

يعامل المثال السابق جميع المدخلات غير _0_ بالطريقة نفسها، وسينتج نتائج خاطئة للأعداد السالبة.
يمكن حل ذلك باستخدام أنماط شرطية تُعرف باسم _الحرّاس_، وتُعبَّر عنها بالرمز `|`:

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
```

في الأمثلة السابقة، لا تمتلك كل المدخلات الممكنة نمطًا مطابقًا.
سيكتشف المصرّف ذلك ويصدر تحذيرًا.
وهذه ميزة مفيدة جدًا في Haskell تساعد على ضمان تغطية جميع المسارات الممكنة لتجنّب أخطاء وقت التشغيل.
وتُعرف هذه الميزة باسم _الفحص الشامل_.
وللتخلص من التحذير، عليك معالجة جميع الحالات.
ويمكنك داخل _الحرّاس_ استخدام التعبير `otherwise` كسكر نحوي يعبّر عن `True` لالتقاط جميع الأنماط المتبقية.

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
    | otherwise = 0
```

تختبر مطابقة الأنماط قيمة ما مقابل كل نمط من الأعلى إلى الأسفل، حتى تجد نمطًا مطابقًا وتنفّذ المنطق المرتبط بذلك النمط.
