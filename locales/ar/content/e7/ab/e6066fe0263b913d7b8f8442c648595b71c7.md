# ملحق التعليمات

## تلميحات

لاجتياز الاختبار، ستحتاج إلى إنشاء بعض الأنواع التي يعمل عليها الكود. ستحتاج إلى كائن باسم `School` يحمل تسلسلًا من النوع `Student`، وهو صف يتكوّن من `string` و`int` لتخزين اسم الطالب ومستواه الدراسي.

إليك بعض الكود الخاص بهذه الأنواع، وقد يفيدك عند البدء:

```nim
type
  Student* = tuple[name: string, grade: int]
  School* = object
    students*: seq[Student]
```
