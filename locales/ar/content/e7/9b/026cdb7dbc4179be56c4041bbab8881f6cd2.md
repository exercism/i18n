# نبذة

تسمح السمة `Flags` بتمثيل القيم المُعرَّفة في الاتحاد المميز كمواضع بتات (أي أعلام).
وبصفتها أعلامًا، يمكن دمج هذه القيم، ما يجعل من الممكن تمثيل شروط منطقية متعددة في قيمة واحدة.

```fsharp
[<Flags>]
type PhoneFeatures =
| Call = 1
| Text = 2
```

```fsharp
[<Flags>]
type PhoneFeaturesBinary =
| Call = 0b00000001
| Text = 0b00000010
```

يمكن ضبط علم باستخدام عامل OR على مستوى البتات (`|||`)، ويمكن إلغاء ضبط علم باستخدام مزيج من عامل AND على مستوى البتات (`&&&`) وعامل النفي على مستوى البتات (`~~~`).
وبينما يمكن التحقق من حالة العلم باستخدام عامل AND على مستوى البتات، يمكن أيضًا استخدام الطريقة `HasFlag()`.

```fsharp
let features = PhoneFeatures.Call

// Set the Text flag
let moreFeatures = features ||| PhoneFeatures.Text

moreFeatures.HasFlag(PhoneFeatures.Call) // => true
moreFeatures.HasFlag(PhoneFeatures.Text) // => true

// Unset the Call flag
let lessFeatures = features &&& ~~~PhoneFeatures.Call

lessFeatures.HasFlag(PhoneFeatures.Call) // => false
lessFeatures.HasFlag(PhoneFeatures.Text) // => true
```
