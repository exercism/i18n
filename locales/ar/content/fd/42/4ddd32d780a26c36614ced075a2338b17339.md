# التعليمات

أنت من أشد المعجبين بقناة [Numberphile على يوتيوب](https://www.youtube.com/watch?v=PeUbRXnbmms) وقد شاهدت للتو فيديو رائعًا عن _متتالية أعداد لوكاس_. وتريد إنشاء هذه المتتالية باستخدام Elixir.

أثناء تصميم دالتك، تريد الاستفادة من _التقييم الكسول_، بحيث يمكنك توليد ما تريد من الأعداد، لكن فقط عند الحاجة إليها. لذلك تقرر استخدام تدفّق.

## 1. التقاط الوسائط غير الصالحة

أضف عبارة حماية لرفع خطأ إذا استُخدم عدد غير صحيح أو عدد صحيح أقل من 1 لإنشاء المتتالية. القيام بذلك كخطوة أولى سيمنع أخطاء bug الخاصة بالاستدعاء الذاتي اللانهائي في الخطوات اللاحقة.

```elixir
LucasNumbers.generate("Hello World")
# => ** (ArgumentError) count must be specified as an integer >= 1
```

## 2. إنشاء الحالتين الأساسيتين

أنت تعلم أن المتتالية تبدأ بعددين لا يتبعان القاعدة نفسها. اكتب عبارتي حالة أساسية لإرجاع هذين العددين:

```elixir
LucasNumbers.generate(1)
# => [2]

LucasNumbers.generate(2)
# => [2, 1]
```

## 3. إنشاء الحالة المعمَّمة

لأي متتالية أطول من 2، تعلم أنك تحتاج إلى جمع العددين السابقين للحصول على العدد التالي، وهكذا. اكتب الحالة المعمَّمة.

```elixir
LucasNumbers.generate(3)
# => [2, 1, 3]

LucasNumbers.generate(4)
# => [2, 1, 3, 4]
```
