# مقدمة

أكثر كلمات التسلسل فائدةً تأخذ *quotation* كأحد مدخلاتها وتستخدمه لتوجيه العملية:

```
each   ( seq quot -- )
map    ( seq quot -- newseq )
filter ( seq quot -- newseq )
reject ( seq quot -- newseq )
count  ( seq quot -- n )
any?   ( seq quot -- ? )
all?   ( seq quot -- ? )
```

```factor
{ 1 2 3 4 5 } [ even? ] filter .   ! => { 2 4 }
{ 1 2 3 4 5 } [ sq ] map .         ! => { 1 4 9 16 25 }
{ 1 2 3 4 5 } [ 2 > ] count .      ! => 3
```

`map-sum` (أيضًا في `sequences`) تطبّق quotation على عناصر التسلسل وتجمع النتائج في مرور واحد. النمط نفسه يشغّل `sort-by` (في [`sorting`][sorting]) و`minimum-by` / `maximum-by` (في `sequences`).

[sorting]: https://docs.factorcode.org/content/vocab-sorting.html
