# مقدمة

تحتوي Swift على مجموعة من العبارات التي يمكن استخدامها لتغيير مسار التحكم الطبيعي في الحلقات.
تُعرف هذه بعبارات نقل التحكم.
لقد رأيت بالفعل `return`؛ وسيقدّم لك هذا المفهوم عبارات أخرى، من بينها `continue` و`break` والتسميات.
لن نتناول `fallthrough` في هذا المفهوم، لكن يمكنك القراءة عنه في [كتاب Swift][fallthrough].

## Continue

أحيانًا نحتاج إلى الانتقال مبكرًا إلى التكرار التالي في الحلقة، دون إكمال بقية العبارات في التكرار الحالي.
يمكن استخدام الكلمة المفتاحية `continue` لهذا الغرض.
عند تنفيذ `continue`، تنتقل الحلقة إلى الفحص التالي لمعرفة ما إذا كان يمكن تنفيذ التكرار التالي، أي `while` في حلقتَي while و repeat-while، أو الفحص الذي يتحقق مما إذا كان هناك عنصر آخر في التسلسل في حلقات for-in.

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

## Break

يُستخدم `break` للخروج من الحلقة مبكرًا.
عند تنفيذ `break`، تخرج الحلقة فورًا ويتابع البرنامج التنفيذ من أول عبارة تأتي بعد الحلقة.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

## التسميات

عندما تكون الحلقات متداخلة، قد نحتاج أحيانًا إلى استخدام `break` أو `continue` للخروج من الحلقات الخارجية التي تحتوي على الحلقة التي استُخدم فيها `break` أو `continue`، أو لإعادة بدئها.
في حالات كهذه، يمكن استخدام التسميات لتحديد الحلقة التي نريد الخروج منها أو إعادة بدئها.
يمكن تسمية الحلقة بوضع اسم متبوع بنقطتين قبل الكلمة المفتاحية `while` أو `repeat` أو `for` التي تبدأ الحلقة.

لرؤية أثر استخدام التسميات بهذه الطريقة، تأمّل الحلقة التالية.

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```
