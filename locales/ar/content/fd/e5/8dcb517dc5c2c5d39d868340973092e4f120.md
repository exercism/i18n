# مقدمة

في Go، الثابت قيمة بسيطة لا تتغير، تُسند إلى اسم باستخدام الكلمة المفتاحية `const`:

```go
const myWebsite = "Exercism"
```

هذه الثوابت بلا نوع، لكن يُمنح لها نوع افتراضي بناءً على صياغتها عندما يكون النوع مطلوبًا، كما هو الحال عند تمريرها إلى طريقة.
يمكن إنشاء ثوابت ذات نوع بإضافة نوع بشكل صريح:

```go
const myWebsite string = "Exercism"
```

لا تحتوي Go على أنواع تعدادية كما في بعض اللغات الأخرى، لكنها تمتلك معرّفًا مُعلنًا مسبقًا يُسمى `iota` لإنشاء ثوابت تعدادية.
الثوابت داخل كتلة تتكرر ضمنيًا:

```go
const (
    a = 9
    b
    c
    d = iota
    e
    f
    g
)
fmt.Print(a, b, c, d, e, f, g)
// Output: 9 9 9 3 4 5 6
```
