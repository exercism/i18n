# التعليمات

في هذا التمرين ستتعامل مع أسطر السجل.

كل سطر سجل هو سلسلة نصية منسّقة على النحو التالي: `"[<LEVEL>]: <MESSAGE>"`.

هناك ثلاثة مستويات مختلفة للسجل:

- `INFO`
- `WARNING`
- `ERROR`

لديك ثلاث مهام، كل مهمة منها تأخذ سطر سجل وتطلب منك أن تفعل به شيئًا.

## 1. استخرج الرسالة من سطر السجل

نفّذ الدالة `message()` لتُرجع رسالة سطر السجل:

```haxe
message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

يجب إزالة أي مسافات فارغة في البداية أو في النهاية:

```haxe
message("[WARNING]:  Disk almost full\r\n")/ => "Disk almost full"
```

## 2. استخرج مستوى السجل من سطر السجل

نفّذ الدالة `logLevel()` لتُرجع مستوى السجل لسطر السجل، على أن يُرجع بأحرف صغيرة:

```haxe
logLevel("[ERROR]: Invalid operation")
// => "error"
```

## 3. أعد تنسيق سطر السجل

نفّذ الدالة `reformat()` التي تعيد تنسيق سطر السجل، فتضع الرسالة أولًا ثم مستوى السجل بعدها بين الأقواس الهلالية:

```haxe
reformat("[INFO]: Operation completed")
// => "Operation completed (info)"
```
