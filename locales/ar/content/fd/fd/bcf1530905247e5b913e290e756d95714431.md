# مقدمة

*الكومة* مجموعة تعرف دائمًا أصغر عنصر فيها وتتيح لك إزالته بسرعة. إنها التنفيذ الطبيعي *لطابور الأولوية*. الأكوام توجد في مفردات [`heaps`][heaps].

`<min-heap>` تبني كومة فارغة يخرج أصغر مفتاح فيها أولًا؛ `<max-heap>` هي الصورة المعكوسة. كل عنصر هو *قيمة* مخزنة تحت *مفتاح*، والمفتاح هو الأولوية:

```
<min-heap> ( -- min-heap )
heap-push  ( value key heap -- )
```

```factor
USING: heaps ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
```

الكومة *قابلة للتغيير*، و`heap-push` تُغيّرها في مكانها. `heap-peek` تُرجع القيمة والمفتاح الأماميين دون إزالتهما. `heap-pop` تُزيله وتُرجع قيمته ومفتاحه، و`heap-pop-all` تستنزف الكومة إلى قائمة اقتران من أزواج `{ key value }` بترتيب الأولوية:

```
heap-peek    ( heap -- value key )
heap-pop     ( heap -- value key )
heap-pop-all ( heap -- alist )
```

```factor
USING: heaps kernel prettyprint ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
dup heap-peek drop .     ! => "bob"
heap-pop-all .           ! => { { 2 "bob" } { 5 "alice" } }
```
