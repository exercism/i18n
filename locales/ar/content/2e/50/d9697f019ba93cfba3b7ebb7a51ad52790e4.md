# مقدمة

في F#، يُشار إلى إسناد قيمة إلى اسم بـ _الارتباط_. الارتباطات غير قابلة للتغيير، وهذا يجعلها شبيهة بالثوابت في لغات أخرى. ولأن F# لغة ثابتة الأنواع، فإن لكل ارتباط نوعًا في وقت التصريف.

تُعرَّف الارتباطات باستخدام الكلمة المفتاحية `let`. تحديد نوع الارتباط اختياري في معظم الارتباطات، لأن _استنتاج النوع_ في F# يستطيع عادةً استنتاج النوع انطلاقًا من قيمته. ويبدو الارتباط هكذا:

```fsharp
// Automatically inferred type
let fingers = 10
```

الدوال أيضًا ارتباطات عادية، لكن بمعامل واحد أو أكثر. وتُرجع الدالة تلقائيًا آخر تعبير لديها. ويعمل استنتاج النوع أيضًا مع معظم الدوال، من خلال تحليل القيم التي تُستدعى بها الدالة والقيمة التي تُرجعها.

```fsharp
// Automatically inferred types for parameters and return type
let add x y = x + y
```

تتم استدعاء الدالة بتحديد اسمها وتمرير وسائط لكل معامل من معاملات الدالة.

```fsharp
let five = add 2 3
```

إذا تعذّر استنتاج نوع الارتباط، فسيُبلغ المصرّف عن خطأ. ولإصلاح ذلك، أضف تحديدًا صريحًا للنوع إلى الارتباط.

```fsharp
// Explicit type annotation
let fingers: int = 10

// Explicit type annotation (also for parameters)
let add (x: int) (y: int): int = x + y
```

لا يمكن استخدام الارتباطات في F# إلا _بعد_ تعريفها. واستخدام ارتباط قبل تعريفه يؤدي إلى خطأ في التصريف.

```fsharp
// Compile error as the add binding has not yet been defined
// let seven = add 3 4

let add x y = x + y
```

يستخدم F# المسافات ذات الدلالة لتحديد النطاق. وهذا يعني أن النطاق يُحدَّد بإزاحة الكود بالمسافات نسبةً إلى السطر الذي يُعرّف فيه الارتباط. والاصطلاح الافتراضي هو استخدام أربع مسافات للإزاحة:

```fsharp
let toes =
    let left = 5
    let right = 5
    left + right

let multiplyPlusTwo x y =
    let product = x * y
    product + 2

// Trying to access the left, right or product bindings
// here would result in a compile error
```

عادةً ما تُنظَّم ارتباطات F# (التي تشمل الدوال) في وحدات. والوحدة تجمع وظائف مترابطة وتُعرَّف باستخدام الكلمة المفتاحية `module`. ويجب أن يسبق تعريف الوحدة ارتباطاتها:

```fsharp
module Calculator

let pi = 3.14

let add x y = x + y
```

يدعم F# نوعين من التعليقات. تسبق التعليقات أحادية السطر علامة `//`، أما التعليقات متعددة الأسطر فتُكتب بين `(*` و `*)`.
