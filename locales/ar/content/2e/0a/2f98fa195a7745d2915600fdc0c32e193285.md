# نبذة

في Rust، المكرِّر هو أي قيمة تُطبِّق سمة [`Iterator`](https://doc.rust-lang.org/stable/std/iter/trait.Iterator.html).
ويمكن تقديم قيم المكرِّر يدويًا باستدعاء طريقة `next` عليه.

```rust
trait Iterator {
    type Item;
    fn next(&mut self) -> Option<Self::Item>;
    // many built-in methods implemented
}
```

تُطبِّق العديد من [`collections`](https://doc.rust-lang.org/std/collections/index.html) في Rust سمة
[`IntoIterator`](https://doc.rust-lang.org/std/iter/trait.IntoIterator.html)،
وهي قادرة على إنتاج `Iterator` من قيم المجموعة.

```rust
trait IntoIterator where Self::IntoIter: Iterator<Item=Self::Item> {
    type Item;
    type IntoIter: Iterator;
    fn into_iter(self) -> Self::IntoIter;
}
```

لاحظ أنه في حين أن `IntoIterator::into_iter` يستهلك نوع `self` الخاص به، فليس من الضروري أن يكون هذا النوع قيمة مملوكة.
ولذلك توجد تطبيقات لـ `IntoIterator` من أجل [`Vec`](https://doc.rust-lang.org/std/vec/struct.Vec.html#impl-IntoIterator-2)،
ومن أجل [`&'a Vec`](https://doc.rust-lang.org/std/vec/struct.Vec.html#impl-IntoIterator)،
ومن أجل [`&'a mut Vec`](https://doc.rust-lang.org/std/vec/struct.Vec.html#impl-IntoIterator-1).
وتوفّر هذه التطبيقات، بدرجات مختلفة من الملكية، مرونة مفيدة.

لا حاجة إلى فهم `traits` في هذا المفهوم، وسنخصص لك تمرينًا كاملًا لتتقن `traits`.
في الوقت الحالي، تذكّر فقط ما يلي:

- أي نوع يُطبِّق `IntoIterator` يُسمّى _قابلًا للتكرار_، لأنه يمكن تحويله إلى مكرِّر.
- أي نوع يُطبِّق `Iterator` هو مكرِّر، _يُنتج_ القيم و_يمكن التكرار عليه_.
- يمكنك الحصول على مكرِّر من أي نوع يُطبِّق `IntoIterator` باستدعاء طريقة `into_iter` الخاصة به.
- كل مكرِّر [يُطبِّق `IntoIterator`](https://doc.rust-lang.org/std/iter/trait.IntoIterator.html#impl-IntoIterator-25) ويُنتج نفسه.
- تعمل حلقات `for` دائمًا على المكرِّرات، وتستدعي `IntoIterator` ضمنيًا على وسيط المدى الخاص بها.

## `into_iter` وحلقات `for`

من المحتمل أنك معتاد على حلقات `for` التي تمرّ على متجه:

```rust
// lor is a `Vec`, which implements `IntoIterator`
let lor = vec!["Ainur", "Elves", "Men", "Dwarves", "Hobbits", "Orcs", "Dragons"];
for people in &lor {
    println!("{people}");
}
```

في جوهرها، ليست حلقة `for` سوى اختصار لاستدعاء طريقة `into_iter` الخاصة بوسيطها،
ثم استدعاء `next()` حتى تتوقف عن إنتاج العناصر. بعبارة أخرى، تُفكَّك الحلقة السابقة إلى ما يلي:

```rust
{
    let mut iterator = (&lor).into_iter();
    while let Some(people) = iterator.next() {
        println!("{people}");
    }
}
```

## الطريقتان `iter` و`iter_mut`

توفّر معظم أنواع المجموعات في Rust طريقتَي `iter` و`iter_mut`.
وبالنسبة لمجموعة من النوع `T`، تفعل هاتان الطريقتان ما يلي بحكم الاصطلاح:

- المكرِّر الذي تُرجعه `iter` يُنتج قيمًا من النوع `&T` مستعارة استعارةً غير قابلة للتغيير.
- المكرِّر الذي تُرجعه `iter_mut` يُنتج قيمًا من النوع `&mut T` مستعارة استعارةً قابلة للتغيير.

```rust
let mut v = vec![1, 2, 3];

// Using `iter` method
let mut iterator = v.iter();
assert_eq!(iterator.next(), Some(&1));
assert_eq!(iterator.next(), Some(&2));
assert_eq!(iterator.next(), Some(&3));
assert_eq!(iterator.next(), None);

// Using `iter_mut` method
for value in v.iter_mut() {
     *value *= *value;
}
println!("{v:?}");
// => [1, 4, 9]
```

## الفرق بين `iter` و`iter_mut` و`into_iter`

إذا كانت `iter` و`iter_mut` و`into_iter` كلها تُنتج مكرِّرات، فما الفرق بينها؟

- المكرِّر الذي تُرجعه `iter` يُنتج، بحكم الاصطلاح، قيمًا من النوع `&T` مستعارة استعارةً غير قابلة للتغيير.
- المكرِّر الذي تُرجعه `iter_mut` يُنتج، بحكم الاصطلاح، قيمًا من النوع `&mut T` مستعارة استعارةً قابلة للتغيير.
- المكرِّر الذي يُرجعه `into_iter` قد يُنتج قيمًا من النوع `T` أو `&T` أو `&mut T`، حسب سياقه.

وما المقصود بالسياق في استدعاء `into_iter`؟
إنه نوع `self` الخاص به.
تذكّر أن هناك تطبيقات لـ `IntoIterator` من أجل `Vec` و`&'a Vec` و`&'a mut Vec`.
لذلك:

- `(&v).into_iter()` مكافئة لـ `v.iter()` => تُرجع `&T`
- `(&mut v).into_iter()` مكافئة لـ `v.iter_mut()` => تُرجع `&mut T`
- `v.into_iter()` => تُرجع `T` وتنقل القيم

وهذا أوضح ما يكون في حلقات `for`:

- `for num in &v {...}` => تربط `&T`
- `for num in &mut v {...}` => تربط `&mut T`
- `for num in v {...}` => تربط `T` وتنقل القيم

غالبًا ما يكون كتابة `v.iter()` أوضح من كتابة `(&v).into_iter()`.
ولذلك توجد أسباب تتعلق بسهولة الاستخدام تدفع إلى تفضيل `iter` و`iter_mut` على `into_iter`.

## استخدام الطرق المدمجة للمكرِّرات

توفّر المكرِّرات العديد من الطرق المدمجة، مثل `map` و`filter` و`collect`.
وتُستخدم هذه الطرق أحيانًا مع الإغلاقات.

تستخدم `map` إغلاقًا لتحويل قيم المكرِّر.
وتقصّ `take` مكرِّرًا (قد يكون لا نهائيًا) إلى مكرِّر يتوقف بعد عدد من العناصر لا يتجاوز العدد المحدَّد.

```rust
for even_number in (0..).into_iter().map(|x| x * 2).take(4) {
    let odd_number = even_number + 1;
    println!("{even_number} => {odd_number}");
}
// 0 => 1
// 2 => 3
// 4 => 5
// 6 => 7
```

تحوِّل `filter` المكرِّر إلى مكرِّر لا يُرجع إلا القيم التي يكون ناتج الإغلاق عندها `true`.
وتستهلك `count` المكرِّر، فتُرجع عدد العناصر المُنتَجة.

```rust
let lor = vec!["Ainur", "Elves", "Men", "Dwarves", "Hobbits", "Orcs", "Dragons"];
let short_people = ["Dwarves", "Hobbits"];
let num_tall_people = lor.iter().filter(|people| !short_people.contains(people)).count();
assert_eq!(num_tall_people, 5);
```

تحوِّل `flat_map` مكرِّرًا عبر تحويل كل عنصر إلى مكرِّر جديد بواسطة الإغلاق المُمرَّر،
ثم تسطّح كل المكرِّرات الجديدة الناتجة بربطها ببعضها.
وتُنتج `collect` مجموعة جديدة،
ما دام نوع المجموعة يُطبِّق [`FromIterator`](https://doc.rust-lang.org/std/iter/trait.FromIterator.html).

```rust
let words = ["alpha", "beta", "gamma"];
// chars() returns an iterator
let merged: String = words.iter()
                          .flat_map(|s| s.chars())
                          .collect();
assert_eq!(merged, "alphabetagamma");
```

توفّر [سمة `Iterator`](https://doc.rust-lang.org/std/iter/trait.Iterator.html) _العديد_ من تحويلات المكرِّرات المفيدة كهذه؛
ويستحق الأمر قراءة التوثيق والتعرّف عليها.

## الكسل

من المهم أن تعرف أن مكرِّرات Rust كسولة:
فهي لا تُنتج أي قيم حتى نستهلك المكرِّر.
إذا كتبت الكود التالي وشغّلته:

```rust
(0..5).map(|x| x * x);
```

فستحصل على خطأ المترجِم التالي:

```rust
 --> src/main.rs:2:5
  |
2 |     (0..5).map(|x| x * x);
  |     ^^^^^^^^^^^^^^^^^^^^^^
  |
  = note: `#[warn(unused_must_use)]` on by default
  = note: iterators are lazy and do nothing unless consumed
```

وذلك لأن `map` طريقة محوِّلة تُرجع مكرِّرًا آخر.

لاستهلاك المكرِّر، استخدم حلقة `for` أو استخدم طريقة من طرق المكرِّر تُنتج قيمة ليست بحد ذاتها مكرِّرًا.

على سبيل المثال، `collect` طريقة مستهلِكة (فتوقيع الدالة الخاصة بها لا يُرجع مكرِّرًا بل نوعًا عامًّا):

```rust
//         Iterator   Adaptor        Consumer
//                |      |               |
let v: Vec<_> = (0..5).map(|x| x * x).collect();
```
