# التعليمات

في هذا التمرين ستكتب كودًا لتتبّع مصفوفة من لغات البرمجة التي تريد تعلّمها على Exercism.

لديك ست مهام، وكلها ستتضمّن التعامل مع المصفوفات.

## 1. إنشاء مصفوفة جديدة

لتتبّع اللغات التي تريد تعلّمها، ستحتاج إلى إنشاء مصفوفة جديدة. عرّف الدالة `new_list` التي تُرجع مصفوفة جديدة فارغة.

```gleam
new_list()
// -> []
```

## 2. تعريف مصفوفة موجودة

حاليًا، لديك ورقة مكتوب عليها اللغات التي تريد تعلّمها: Gleam وGo وTypeScript. عرّف الدالة `existing_list` لتُرجع هذه المصفوفة.

```gleam
existing_list()
// -> ["Gleam", "Go", "TypeScript"]
```

## 3. إضافة لغة جديدة إلى مصفوفة

بينما تستكشف Exercism وتجد لغات أكثر إثارة للاهتمام، سترغب في إضافتها إلى مصفوفتك. نفّذ الدالة `add_language` لإضافة لغة جديدة إلى بداية مصفوفتك.

```gleam
add_language(["OCaml", "Elixir"], "Scheme")
// -> ["Scheme", "OCaml", "Elixir"]
```

## 4. عدّ اللغات في المصفوفة

عدّ اللغات واحدة تلو الأخرى غير عملي. نفّذ الدالة `count_languages` لعدّ عدد اللغات في مصفوفتك.

```gleam
count_languages(["jq", "Elm", "Rust", "Kotlin"])
// -> 4
```

## 5. عكس المصفوفة

في مرحلة ما، تدرك أن مصفوفتك مرتّبة بالعكس فعليًا! نفّذ الدالة `reverse_list` لعكس مصفوفتك.

```gleam
reverse_list(["Python", "Julia", "Idris", "COBOL"])
// -> ["COBOL", "Idris", "Julia", "Python"]
```

## 6. التحقق مما إذا كانت المصفوفة مثيرة

رغم أنك تحب كل اللغات، فإن لـGleam مكانة خاصة في قلبك. ولهذا، تتحمّس كثيرًا لمصفوفة من اللغات إذا:

- كانت الأولى في المصفوفة هي Gleam.
- كان العنصر الثاني في المصفوفة هو Gleam وكانت المصفوفة تحتوي على لغتين أو ثلاث لغات.

نفّذ الدالة `exciting_list` للتحقق مما إذا كانت مصفوفة اللغات مثيرة:

```gleam
exciting_list(["Lua", "Gleam"])
// -> True
```
