# مقدمة

## شرح

إلى جانب أنواع البيانات الأولية مثل `number` و`string`، هناك نوع بيانات مهم آخر في JavaScript يُسمى `object`.
الكائنات مجموعات من أزواج المفتاح والقيمة.
وعلى هذا النحو، يمكن استخدامها لما يُشار إليه غالبًا بالخرائط أو القواميس في لغات أخرى.

في لغات أخرى، غالبًا ما تحتاج جميع القيم في الخريطة إلى نوع البيانات نفسه.
أما في JavaScript، فلا يُقيَّد سوى نوع المفتاح: يجب أن يكون سلسلة نصية.
ويمكن أن تكون القيم داخل الكائن الواحد من أنواع مختلفة.
فقد تكون أنواعًا أولية مثل الأعداد، ولكن أيضًا مصفوفات أو كائنات أخرى أو حتى دوال.
وهذا ما يجعل الكائنات مرنة للغاية، حتى إنها تُعد أيضًا كيانات أساسية في [البرمجة كائنية التوجه][oop] (OOP) في JavaScript.

فيما يلي، سنركّز على الكائنات بوصفها مجموعات أو خرائط. وسنغطي حالات استخدام أخرى للكائنات في مفاهيم أخرى، انظر على سبيل المثال [الأصناف][concept-classes].

## إنشاء كائن

يمكنك إنشاء كائن باستخدام الأقواس المعقوفة.
ويمكنك أيضًا تضمين بعض المدخلات مباشرة.
وللقيام بذلك، اذكر المفتاح أولًا، ثم ضع بعده نقطتين رأسيتين، ثم القيمة.

```javascript
const emptyObject = {};

const obj = {
  favoriteNumber: 42,
  greeting: 'Hello World',
  useGreeting: true,
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
  fruits: ['melon', 'papaya'],
  addNumbers: function (a, b) {
    return a + b;
  },
};
```

الفاصلة الأخيرة بعد المدخلة الأخيرة اختيارية في JavaScript.

قد تتساءل لماذا لا تُحاط المفاتيح بعلامات الاقتباس رغم أنه يُفترض أن تكون سلاسل نصية.
هذا ترميز مختصر.
إذا اتبع المفتاح قواعد التسمية الخاصة بـ [المعرّف][mdn-identifier] في JavaScript، يمكنك حذف علامات الاقتباس.
أما المفاتيح التي تحتوي على أحرف خاصة في الاسم، فتحتاج إلى استخدام ترميز السلسلة النصية المعتاد.

```javascript
const obj = {
  '1keyStartsWithNumber': '...',
  'key/with/slashes': '...',
  'key-with-dashes': '...',
  'key with spaces': '...',
  '#&()[]{}èä樹keyWithSpecialChars': '...',
};
```

## استرجاع قيمة

هناك طريقتان لاسترجاع قيمة مفتاح معيّن: الترميز النقطي وترميز الأقواس المربعة.

```javascript
const obj = { greeting: 'hello world' };

obj.greeting;
// => hello world

obj['greeting'];
// => hello world

// Bracket notation also works with variables.
const key = 'greeting';
obj[key];
// => hello world
```

استخدام الترميز النقطي كاختصار له القيد نفسه الذي لحذف علامات الاقتباس.
فهو لا يعمل إلا إذا اتبع المفتاح قواعد تسمية المعرّفات.
بعبارة أخرى، إذا لم يكن مفتاحك كلمة واحدة تتكوّن من الحروف فقط، فعليك استخدام ترميز الأقواس المربعة.

## إضافة قيمة أو تغييرها

يمكنك إضافة قيمة أو تغييرها باستخدام عامل الإسناد `=`.
ومرة أخرى، يتوفر الترميز النقطي وترميز الأقواس المربعة.

```javascript
const obj = { greeting: 'hello world' };

obj.greeting = 'Hi there!';
obj['greeting'] = 'Welcome.';

obj.newKey1 = 'new value 1';
obj['new key 2'] = 'new value 2';

const key = 'new key 3';
obj[key] = 'new value 3';
```

## حذف مدخلة

يمكنك حذف زوج المفتاح والقيمة من كائن باستخدام الكلمة المفتاحية `delete`.

```javascript
const obj = {
  key1: 'value1',
  key2: 'value2',
};

delete obj.key1;
delete obj['key2'];
```

## التحقق من وجود مفتاح

يمكنك التحقق مما إذا كان مفتاح معيّن موجودًا في كائن باستخدام الطريقة `hasOwnProperty`.

```javascript
const obj = { greeting: 'hello world' };

obj.hasOwnProperty('greeting');
// => true

obj.hasOwnProperty('age');
// => false
```

## المرور على كائن بحلقة

توجد حلقة خاصة `for...in` للمرور على جميع مفاتيح الكائن.

```javascript
const obj = {
  name: 'Ali',
  age: 65,
};

for (let key in obj) {
  console.log(key, obj[key]);
}
// name Ali
// age 65
```

لتجنّب الأخطاء الدقيقة، افترض دائمًا أن حلقة `for...in` تمرّ على المفاتيح بترتيب غير محدّد.
وكن على علم أيضًا أن `for...in` تُضمّن [المفاتيح الموروثة][concept-inheritance] في مرورها.
