# مقدمة

يغلب استخدام مطابقة الأنماط في الكود التأكيدي والأصيل في Elixir. قد تتذكر أن `=/2` يوصف بأنه عامل مطابقة وليس عامل إسناد. عند استخدام عامل المطابقة، إذا تطابق النمط الموجود على اليسار مع الطرف الأيمن، تُربط أي متغيرات على اليسار، وتُرجَع قيمة الطرف الأيمن. ويُرفع `MatchError` إذا لم يحدث تطابق.

```elixir
2 = 2
# => 2
# Literals can be matched if they are the same

2 = 3
# => ** (MatchError) no match of right hand side value: 3

{_, denominator} = Float.ratio(0.25)
# => {1, 4}
# the variable `denominator` is bound to the value 4
```

تذكّر أن المطابقة تحدث من الطرف الأيمن إلى الطرف الأيسر.

في المثال الأخير، إذا لم نكن بحاجة إلى متغير في مطابقة النمط، يمكننا تجاهله بالإشارة إلى `_`. وأي متغير يبدأ بـ `_` لا تتعقبه بيئة التشغيل.

## مطابقة الأنماط في الدوال المسماة

تعد مطابقة الأنماط أداة مفيدة أيضًا عند إنشاء عدة فروع للدالة. يمكن استخدام مطابقة الأنماط على وسائط الدوال، وهو ما يحدد فرع الدالة الذي سيُستدعى، بدءًا من أعلى الملف إلى الأسفل حتى أول تطابق. وقد تُربط المتغيرات في رأس الدالة وتُستخدم في جسم الدالة.

```elixir
defmodule Example do
  def named_function(:a = variable_a) do
    {variable_a, 1}
  end

  def named_function(:b = variable_b) do
    {variable_b, 2}
  end
end

Example.named_function(:a)
# => {:a, 1}

Example.named_function(:b)
# => {:b, 2}

Example.named_function(:c)
# => ** (FunctionClauseError) no function clause matching in Example.named_function/1
```
