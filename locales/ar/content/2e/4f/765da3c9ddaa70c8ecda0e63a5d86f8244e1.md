# نبذة

## مقارنة الأعداد

في `jq` يمكن مقارنة الأعداد باستخدام عوامل العلاقة والمساواة التالية.

| المقارنة                | العامل    |
| ----------------------- | --------- |
| أكبر من                 | `a > b`   |
| أكبر من أو يساوي        | `a >= b`  |
| أصغر من                 | `a < b`   |
| أصغر من أو يساوي        | `a <= b`  |
| يساوي                   | `a == b`  |
| لا يساوي                | `a != b`  |

نتيجة المقارنة هي دائمًا قيمة منطقية، أي إما `true` أو `false`.

```jq
1 < 3,      # => true
2 != 2,     # => false
1 == 1.0    # => true
            # All numbers are floating-points, so this is different syntax
            # for the exact same value.
```

## مقارنة السلاسل النصية

يمكن أيضًا استخدام عوامل المقارنة أعلاه لمقارنة السلاسل النصية.
في هذه الحالة، يُطبَّق ترتيب معجمي (قاموسي).
ويعتمد الترتيب على [قيمة نقطة ترميز يونيكود][sort].

[sort]: https://jqlang.org/manual/#sort-sort_by

```jq
"Apple" > "Pear",   # => false
"a" < "above",      # => true
"a" == "A"          # => false
```

يجب أن تكون حذرًا عند مقارنة متغيرين يبدو أنهما يحتويان على قيم رقمية لكن نوعهما سلسلة نصية.
بسبب الترتيب المعجمي، لن تكون النتيجة مماثلة لمقارنة قيم من نوع العدد.

```jq
10 < 2,     # => false
"10" < "2"  # => true (because "1" comes before "2")
```

## المساواة "الصارمة"

عامل `==` في `jq` يشبه `===` في Javascript من حيث أن الأشياء التي «تبدو» متطابقة لكن أنواعها مختلفة لا تكون متساوية.

```jq
"3" == 3    # => false
            # the value on the left has type string,
            # the value on the right has type number.
```

## مقارنة المصفوفات

تكون المصفوفتان متساويتين إذا كانت جميع العناصر المتناظرة متساوية.

```jq
[1, 2, 3] == [1, 2, 3]      # => true
[1, 2, 3] == [1, 3, 2]      # => false, different order
[1, 2, 3] == [1, 2, "3"]    # => false, different types
```

## مقارنة الكائنات

يكون الكائنان متساويين إذا كانا يمتلكان أزواج المفتاح والقيمة نفسها.

```jq
{name: "Joe", age: 42} == {age: 42, name: "Joe"}                # => true
{name: "Joe", age: 42} == {age: 42, name: "Jane"}               # => false
{name: "Joe", age: 42} == {age: "42", name: "Joe"}              # => false
{name: "Joe", age: 42} == {age: 42, name: "Joe", height: 175}   # => false

# comparisons will drill down as deeply as required
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2]}}}                  # => true
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2, 3]}}}               # => false
```
