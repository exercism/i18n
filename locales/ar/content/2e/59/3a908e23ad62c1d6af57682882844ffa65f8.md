# مقدمة

بينما يمنع معدِّل `readonly` الكتابة فوق القيمة أو المرجع في حقل، فإنه لا يوفّر أي حماية لأعضاء النوع المرجعي.

```csharp
readonly List<int> ints = new List<int>();

void Foo()
{
    ints.Add(1);    // ok
    ints = new List<int>(); // fails to compile
}
```

لضمان حماية جميع أعضاء النوع المرجعي، يمكن جعل الحقول `readonly` وتعريف خصائص تلقائية بدون مُوصِّل `set`.

توفّر مكتبة الأصناف الأساسية (BCL) بعض النسخ المعدّة للقراءة فقط من المجموعات عندما تكون هناك حاجة إلى منع تحديث عناصر المجموعة. وتأتي هذه على هيئة مُغلِّفات:

- يتيح `ReadOnlyDictionary<T>` الوصول إلى `Dictionary<T>` للقراءة فقط.
- يتيح `ReadOnlyCollection<T>` الوصول إلى `List<T>` للقراءة فقط.
