# التثبيت

## Mac

ثبّته باستخدام Homebrew عبر الأمر `brew install swi-prolog`.
أو نزّل المصدر الخاص بجهازك من [SWI Prolog Website](http://www.swi-prolog.org/download/devel).

## Windows

نزّل المصدر الخاص بجهازك من [SWI Prolog Website](http://www.swi-prolog.org/download/devel).

## Linux

اتبع التعليمات الخاصة بتوزيعتك من [هنا](http://www.swi-prolog.org/build/unix.html).
