# تعبيرات `match`

يُقيِّم تعبير `match` قيمةً وشرطًا لكي يُرجع تعبيرًا سيُقيَّم بدوره. وكما في العامل الثلاثي، إذا لم يتحقق الشرط، لا يُقيَّم التعبير المُرجَع. ولمطابقة شرط ما، يُجرى فحص للهوية [المساواة الصارمة أو `===`].

```php
<?php
$some_value = 42;

$return_value = match($some_value) {
    0 => 'number is 0',
    1 => 'number is 1',
    default => 'number is something else'
}
```

ولإجراء فحص للمساواة [`==`]، يمكنك إعادة ترتيب الشرط:

```php
<?php
$some_value = 42;

$return_value = match(true) {
    $some_value < 100 => 'number is less than 100',
    $some_value > 100 => 'number is greater than 100',
    $some_value == 100 => 'number is 100',
}
```

في تعبير `match`، إذا لم يتحقق أي شرط، سيُطلَق استثناء `UnhandledMatchError`.
