# مقدمة

النوع [`Time`][time] في Go هو نوع يصف لحظة زمنية.
يمكن الوصول إلى معلومات التاريخ والوقت ومقارنتها والتلاعب بها عبر طُرق هذا النوع، لكن هناك أيضًا بعض الدوال التي تُستدعى على حزمة `time` نفسها.
ويمكن الحصول على التاريخ والوقت الحاليين عبر الدالة [`time.Now`][now].

وتحلّل الدالة [`time.Parse`][parse] السلاسل النصية إلى قيم من النوع `Time`.
وللغة Go أسلوب خاص لتعريف التنسيق الذي تتوقعه لعملية التحليل.
وعليك أن تكتب مثالًا على التنسيق باستخدام القيم من هذا الطابع الزمني الخاص:
`Mon Jan 2 15:04:05 -0700 MST 2006`.

على سبيل المثال:

```go
import "time"

func parseTime() time.Time {
    date := "Tue, 09/22/1995, 13:00"
    layout := "Mon, 01/02/2006, 15:04"

    t, err := time.Parse(layout,date) // time.Time, error
}

// => 1995-09-22 13:00:00 +0000 UTC
```

وتُرجع طريقة [`Time.Format()`][format] تمثيلًا نصيًا للوقت.
وكما هو الحال مع الدالة `Parse`، يُعرَّف التنسيق الهدف مرة أخرى عبر مثال يستخدم القيم من الطابع الزمني الخاص.

على سبيل المثال:

```go
import (
    "fmt"
    "time"
)

func main() {
    t := time.Date(1995,time.September,22,13,0,0,0,time.UTC)
    formattedTime := t.Format("Mon, 01/02/2006, 15:04") // string
    fmt.Println(formattedTime)
}

// => Fri, 09/22/1995, 13:00
```

## خيارات التنسيق

لإنشاء تنسيق مخصص، استخدم مزيجًا من هذه الخيارات.
وفي Go، تتوفر أيضًا [ثوابت تنسيق][const] جاهزة للتاريخ والطابع الزمني.

| الوقت        | الخيارات                                        |
| ----------- | ---------------------------------------------- |
| السنة        | 2006 ; 06                                      |
| الشهر        | Jan ; January ; 01 ; 1                         |
| اليوم        | 02 ; 2 ; \_2 (بدلًا من الصفر البادئ)                 |
| يوم الأسبوع     | Mon ; Monday                                   |
| الساعة        | 15 ( صيغة 24 ساعة ) ; 3 ; 03 (AM أو PM) |
| الدقيقة        | 04 ; 4                                         |
| الثانية        | 05 ; 5                                         |
| علامة AM/PM  | PM                                             |
| يوم السنة | 002 ; \_\_2                                    |

وللنوع `time.Time` طُرق متنوعة للوصول إلى وقت معيّن. مثلًا: الساعة: [`Time.Hour()`][hour]، والشهر: [`Time.Month()`][month].
ويمكنك معرفة المزيد عن كيفية عمل ذلك في [الوثائق الرسمية][time].

وتتضمن حزمة [`time`][time] نوعًا آخر هو [`Duration`][duration]، الذي يمثّل الوقت المنقضي، إضافة إلى دعم المواقع/المناطق الزمنية والمؤقتات وغيرها من الوظائف ذات الصلة التي ستُغطّى في مفهوم آخر.
