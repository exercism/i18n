# مقدمة

باستخدام حلقة `while` يمكنك تنفيذ الكود بشكل متكرر طالما أن شرط معين يتحقق.
تُكتب باستخدام الكلمة المفتاحية `while` متبوعة بشرط محاط بالأقواس الهلالية وكتلة كود تحتوي على _جسم_ الحلقة بين الأقواس المعقوفة.

```javascript
while (condition) {
  // code that is executed repeatedly as long as the condition is true
}
```

تمتلك JavaScript أيضًا حلقة `do-while`.
هنا يُفحص الشرط بعد تنفيذ جسم الحلقة.
يكون هذا مفيدًا عندما يعتمد الشرط على نتيجة الكود في الجسم.

```javascript
do {
  // The code here will always be executed once and then
  // repeatedly while the condition is true.
} while (condition);
```

داخل جسم الحلقة يمكنك استخدام الكلمة المفتاحية `break` لإيقاف تنفيذ الحلقة بالكامل.
في المقابل، الكلمة المفتاحية `continue` توقف تنفيذ التكرار الحالي فقط وتنتقل إلى التكرار التالي.
باستخدام `continue` يمكنك غالبًا تجنّب تغليف أجزاء كبيرة من جسم الحلقة في جملة شرطية.

```javascript
let i = 0;

while (i < 100) {
  i = i + 2;

  if (i % 3 === 0) {
    continue;
  }

  // The code here will only be executed when i was not divisible
  // by 3 in the check above.
}
```
