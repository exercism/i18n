# مفاهيم السنة الكبيسة

أفضّل حل المثال الأول لأن إيجازه يتماشى مع ما رأيته من كتابة Rust الاصطلاحية. كما أنه يتجنب إضافة مفهوم الإغلاق الواردة في الحل القياسي.

## المفاهيم المستخلصة

### عام

- منطق القيم المنطقية
  - قيمة منطقية
- التعبيرات
  - دوال Rust تُرجع التعبيرات ضمنيًا
- الحساب
  - باقي القسمة

### الأنواع

- أعداد صحيحة بدون إشارة - `u64`
- قيم منطقية - `bool`

## مثال التمرين 1

حل ["desi-belokonska"](https://exercism.org/tracks/rust/exercises/leap/solutions/01d024321b6a491690321844aedf8b09)

```rust
pub fn is_leap_year(year: u64) -> bool {
  year % 400 == 0 || year % 4 == 0 && year % 100 != 0
}
```

## مثال التمرين 2

[الحل القياسي](https://github.com/exercism/rust/blob/master/exercises/leap/example.rs)

```rust
pub fn is_leap_year(year: u64) -> bool {
    let has_factor = |n| year % n == 0;
    has_factor(4) && (!has_factor(100) || has_factor(400))
}
```
