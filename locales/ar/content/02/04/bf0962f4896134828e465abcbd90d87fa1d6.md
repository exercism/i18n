# مقدمة

توفّر Gleam دوالًا من الدرجة الأولى، أي أنّ الدوال قيم عادية يمكن إسنادها إلى المتغيرات، وتمريرها كوسائط، وإرجاعها من دوال أخرى.

يمكن الإشارة إلى دالة مُسمّاة معرَّفة في وحدة برمجية باسمها.

```gleam
pub fn main() {
  // Assign the function to a variable
  let f = add_one
  
  // Invoke the function
  f(1) // -> 2
  f(2) // -> 3
}

fn add_one(x) {
  x + 1
}
```

توفّر Gleam أيضًا دوال مجهولة تُعرَّف داخل دوال أخرى.

```gleam
// Define the function
let f = fn(x) { x + 1 }

// Invoke the function
f(1) // -> 2
f(2) // -> 3
```

يُكتب نوع الدالة بصيغة مشابهة لصيغة الدوال المجهولة. ويُكتب نوع الدالة التي تأخذ `Int` و`Float` وتُرجع `Int` هكذا:

```gleam
fn(Int, Float) -> Int
```

يمكن للدوال المجهولة أن تشير إلى متغيرات كانت ضمن النطاق لحظة تعريفها، ما يجعلها _إغلاقات_.

```gleam
let secret_number = 42

// This function always returns 42
fn() { secret_number }
```

توفّر صيغة _التقاط الدالة_ اختصارًا مريحًا لإنشاء دوال مجهولة تمرّر وسيطًا واحدًا إلى دالة. هذان التعبيران متكافئان:

```gleam
// Anonymous function syntax
let f = fn(x) { my_function(1, 2, x) }

// Function capture syntax
let f = my_function(1, 2, _)
```
