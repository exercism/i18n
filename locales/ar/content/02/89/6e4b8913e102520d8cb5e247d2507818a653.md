# تلميحات

## 1. أنشئ متجهًا يضم جميع العربات

- حلقة `for`/`while` تقليدية مع `push!` إلى `Vector` ستفي بالغرض.
- وإلا فإن دالة [`collect()`][collect] قد تكون أكثر إيجازًا.
- وبدلًا من ذلك، يعمل التفريغ داخل مُنشئ المتجه:

```julia-repl
julia> input = (1, 5, 9)
(1, 5, 9)

julia> [input...]
3-element Vector{Int64}:
 1
 5
 9
```

## 2. أصلح متجه العربات

- من المفيد فصل العربات الأمامية والقاطرة عن كل ما عداها، حتى يمكن إعادة تجميعها بالترتيب الصحيح.
- قد يفيدك الإسناد المتعدد مع التفريغ (انظر المقدمة).

## 3. أضف المحطات الناقصة

- تذكّر أن هذه الدالة لا تعدّل المدخل! أنشئ `Dict` جديدًا.
- يلزم اسم المحطة فقط، لا رقم المحطة، لذا يجب فصل كل زوج.
- هناك أساليب متعددة لتجميع متجه الأسماء:
  -  حلقة `for`/`while` مع `push!()` إلى `Vector`.
  -  [استيعاب][comprehensions] المصفوفة
  -  استخدام [`map()`][map] لتطبيق دالة على المتجه.
  -  [البث][broadcasting] لدالة [مجهولة][anonymous] ممكن:

 ```julia-repl
julia> (x -> x^4).([1, 2, 3]) == [1, 16, 81]
true
 ```

## 4. وسّع معلومات التوجيه

- بعد التقاط الوسائط، تكون `more_route_information` مجموعة `Pairs()`.
- دالة [`merge()`][merge] ستدمج اثنين أو أكثر من `Dict`، لكنها ستقبل أيضًا مجموعة `Pairs()`.
  التحويل الصريح لمجموعة `Pairs()` إلى `Dict` ممكن لكنه غير ضروري.
