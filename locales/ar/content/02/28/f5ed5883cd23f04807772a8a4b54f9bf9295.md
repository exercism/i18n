# دفعات المدفوعات في قاعدة البيانات

## المسألة

عليك إدراج دفعة من بيانات المدفوعات في جدول `Payment`. مهمتك هي قراءة بيانات المدفوعات من ملف JSON المُدخل المعطى، واستخدام عملية `batchExecute` في عميل JDBC لإدراج بيانات المدفوعات في جدول `Payment`. ملف الإدخال النموذجي مُعطى باسم `payments.json`.

يعتمد محتوى ملف JSON المُدخل على مخطط JSON التالي.

```json
{
  "type": "array",
  "items": [
    {
      "type": "object",
      "properties": {
        "employee_id": {
          "type": "integer"
        },
        "amount": {
          "type": "number"
        },
        "reason": {
          "type": "string"
        },
        "date": {
          "type": "string"
        }
      },
      "required": [
        "employee_id",
        "amount",
        "reason",
        "date"
      ]
    }
  ]
}

```

يجب أن تُرجع معرّفات المدفوعات المُولَّدة تلقائيًا لبيانات المدفوعات المُدرجة في الدفعة كمخرَج، دون إصدار استعلام آخر إلى قاعدة البيانات.

يمكنك افتراض أن قيم `employee_id` الواردة في ملف `payments.json` صالحة وموجودة بالفعل في جدول `Employee`.

## تفاصيل قاعدة البيانات

استخدم قاعدة بيانات H2 المُقدَّمة لهذه المسألة.

> ملف قاعدة البيانات النموذجي هو `gofigure.mv.db`، واسم قاعدة البيانات هو `gofigure`. وهو موجود داخل مجلد `db`.

الجداول التالية موجودة بالفعل في قاعدة بيانات H2 النموذجية مع بعض البيانات النموذجية. أسماء الأعمدة وأنواع البيانات موضحة أدناه.

**اسم الجدول** : `Employee`

| **الأعمدة:**      | النوع |
| -----------       | ----------- |
| `employee_id`     | عدد صحيح، مفتاح أساسي يزداد تلقائيًا       |
| `name`            | سلسلة نصية        |
| `city`            | سلسلة نصية        |
| `department`      | سلسلة نصية        |
| `age`             | عدد صحيح        |

**اسم الجدول**: `Payment`

| **الأعمدة:**      | النوع |
| -----------       | ----------- |
| `payment_id`      | عدد صحيح، مفتاح أساسي يزداد تلقائيًا       |
| `date`            | تاريخ        |
| `amount`          | عدد عشري        |
| `employee_id`     | عدد صحيح        |
| `reason`          | سلسلة نصية        |

* ملف قاعدة البيانات هو `gofigure.mv.db`. استخدم رابط JDBC بالشكل `jdbc:h2:file:/path/to/db/file`
* اسم المستخدم: `root`
* كلمة المرور: `root`

## القيود

* استخدم ملف قاعدة بيانات H2 المُقدَّم في مجلد `db` للتحقق من الاستعلامات ونموذج Ballerina
* استخدم أسلوب معاملات تبعية maven لإضافة مشغّل قاعدة بيانات H2 كتبعية للمنصة في `Ballerina.toml`
* عليك إيجاد معرّفات المدفوعات المُولَّدة تلقائيًا دون إصدار استعلام آخر إلى قاعدة البيانات.

## بيئة الاختبار

* يمكنك تشغيل الاختبارات بالأمر `bal test`، وسيشغّل الاختبارات على قاعدة البيانات النموذجية المعطاة.

## أمثلة

### المثال 1

**المُدخل:** dbFilePath: `"/path/to/file/gofigure"`، paymentFilePath: `"/path/to/file/payments.json"`

بيانات ملف `payments.json` النموذجية:

```json
[{
        "employee_id": 4,
        "amount": 12500.50,
        "reason": "Fuel for the month January",
        "date": "2022-02-03"
    },
    {
        "employee_id": 1,
        "amount": 10500.50,
        "reason": "Medical Expenses for the month January",
        "date": "2022-02-04"
    },
    {
        "employee_id": 4,
        "amount": 500.50,
        "reason": "Fuel for the month February",
        "date": "2022-03-03"
    }
]

```

**المُخرَج:** `[1,2,3]`

## تلميحات

* استخدم وحدة [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc) للتعامل مع قاعدة البيانات
* راجع قسم [المتطلبات المسبقة](https://lib.ballerina.io/ballerinax/java.jdbc/latest) للاطلاع على خطوات إضافة مشغّل JDBC كتبعية
* استخدم [io:fileReadJson](https://lib.ballerina.io/ballerina/io/latest/functions#fileReadJson) لقراءة ملف JSON المُدخل
* حوّل قيم JSON إلى أنواع خاصة بالتطبيق للتعامل مع البيانات بطريقة آمنة من حيث الأنواع. راجع مثال [التحويل إلى نوع مُعرَّف من المستخدم](https://ballerina.io/learn/by-example/convert-from-json-to-user-defined-type/)
* استخدم [sql:ParameterizedQuery](https://lib.ballerina.io/ballerina/sql/latest#ParameterizedQuery) وطريقة الاستدعاء عن بُعد [batchExecute](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-batchExecute) للتعامل مع قاعدة البيانات
* راجع مثال [تنفيذ الدفعات](https://ballerina.io/learn/by-example/mysql-batch-execute-operation/)
