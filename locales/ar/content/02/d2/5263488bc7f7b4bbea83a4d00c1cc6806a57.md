# نبذة

تتيح لك [جملة `switch`][switch] مقارنة قيمة بعدة قيم محتملة مطابقة. وهي تتيح لك كتابة كود أكثر إيجازًا مما تتيحه عبارات `else-if` المتعددة. تبدأ جملة `switch` بالكلمة المفتاحية `switch` متبوعة بالقيمة المراد مقارنتها. ثم يمكنك تعريف الحالات باستخدام الكلمة المفتاحية `case` متبوعة بالقيمة المراد المقارنة معها. وتُستخدم الكلمة المفتاحية `default` لتعريف الحالة الافتراضية عندما لا تطابق أي من الحالات. ومثل عبارات `else-if`، لا تنفّذ جمل `switch` إلا كتلة الكود المرتبطة بأول حالة مطابقة.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

خذ المثال التالي:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

ويمكن بدلًا من ذلك كتابته هكذا:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## الربط وجمل `where`

يمكن أيضًا ربط القيم التي تُطابَق في جمل `switch` بأسماء يمكن استخدامها في جسم الحالة. ويمكن استخدامها كذلك في شروط `where`، وهي تعبيرات منطقية إضافية يجب أن تُقيَّم بـ`true` حتى تطابق الحالة.

```swift
let x = 1337
switch sumOfDivisors(of: x) {
case let total where total == x:
  print(total, "is a perfect number")
default:
  print(x, "is not a perfect number")
}
```
