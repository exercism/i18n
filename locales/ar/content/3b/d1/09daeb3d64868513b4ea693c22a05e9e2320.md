# نبذة

من الجوانب الأساسية عند التعامل مع الأعداد في C# التمييز بين الأعداد الصحيحة (الأعداد التي لا يوجد أي رقم بعد الفاصلة العشرية) والأعداد العشرية (الأعداد التي يوجد بعد الفاصلة العشرية صفر من الأرقام أو أكثر).

النوعان العدديان الأكثر استخدامًا في C# هما `int` (عدد صحيح بطول 32 بت) و`double` (عدد عشري بطول 64 بت).

```csharp
int i = 123;
double d = 54.29;
```

يمكن استخدام المحرف `_` بصفته _فاصلًا للأرقام_ في كل من الأعداد الصحيحة والأعداد العشرية، وهو ما يساعد عند تعريف أعداد كبيرة:

```csharp
int largeInt = 1_000_000;
// => 1000000

double largeDouble = 9_876_543.21;
// => 9876543.21
```

تُجرى العمليات الحسابية باستخدام [عوامل الحساب][arithmetic-operators] القياسية (`+`، `-`، `*`، وغيرها). ويمكن مقارنة الأعداد باستخدام [عوامل المقارنة][comparison-operators] القياسية (`<`، `>=`، وغيرها)، وكذلك [عامل المساواة][equality-operators] (`==`) و[عامل عدم المساواة][equality-operators] (`!=`).

```csharp
5 * 6;
// => 30

1.2 > 0.8
// => true

2 != 4
// => true
```

عند التحويل بين الأنواع العددية، يوجد نوعان من التحويلات العددية:

1. التحويلات الضمنية: لا تُفقد أي بيانات ولا تلزم أي صيغة إضافية.
2. التحويلات الصريحة: قد تُفقد البيانات، ويلزم استخدام صيغة إضافية على هيئة _تحويل قسري_.

ولأن دقة `int` أقل من دقة `double`، فإن التحويل من `int` إلى `double` آمن، ولذلك يُعد تحويلًا ضمنيًا. أما التحويل من `double` إلى `int` فقد يعني فقدان البيانات، ولذلك يتطلب تحويلًا صريحًا.

```csharp
int i = 9;
double d = 2.66;

// Safe conversion, thus implicit conversion
double fromInt = i;

// Potentially unsafe conversion, thus explicit conversion
int fromDouble = (int)d;
```
