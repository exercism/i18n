# إنشاء الملفات باستخدام Configlet

عند إضافة مقاربة أو مقال أو تمرين جديد، ستحتاج إلى إنشاء ملفات بأسماء محددة بدقة.
كما أنها تتطلب إضافة ملفات الإعداد أو تحديثها.
باستخدام الأمر `create`، يمكن لـ [configlet](/docs/building/configlet) أن يقوم بكل هذا نيابة عنك.

## الاستخدام

يمكن استخدام الأمر `create` لإنشاء الملفات اللازمة لإضافة مقاربة أو مقال أو تمرين جديد، وكذلك لتعديل أي ملفات إعداد.

```shell
configlet [global-options] create [command-options]

Options for create:
      --approach <slug>           The slug of the approach
      --article <slug>            The slug of the article
      --practice-exercise <slug>  The slug of the practice exercise
      --concept-exercise <slug>   The slug of the concept exercise
  -e, --exercise <slug>           Only operate on this exercise
  -o, --offline                   Do not update the cached 'problem-specifications' data
```

## إنشاء تمرين تدريبي

تتضمن [وثائق إضافة تمرين تدريبي](/docs/building/tracks/practice-exercises/add) تعليمات مفصلة حول كيفية إضافة تمرين تدريبي.

## إنشاء تمرين مفاهيمي

لإنشاء تمرين مفاهيمي، يجب تحديد `slug` الخاص به:

```shell
configlet create --concept-exercise bird-watcher
```

سيؤدي هذا إلى إنشاء الملفات المطلوبة للتمرين المفاهيمي، كما هو محدد في [وثائق تمارين المفاهيم](/docs/building/tracks/concept-exercises).

بالطبع، هذه مجرد الخطوة الأولى نحو إنشاء تمرين.
بعد ذلك سيتعين عليك:

- إضافة اختبارات إلى ملف الاختبارات
- إضافة تنفيذ نموذجي
- تحديد محتوى ملف البداية
- كتابة المقدمة في `.docs/introduction.md`
- كتابة التعليمات في `.docs/instructions.md`
- داخل ملف `.meta/config.json` الخاص بالتمرين:
  - إضافة اسم المستخدم على GitHub لمؤلفي التمرين إلى مفتاح `authors`
- داخل ملف `config.json` الخاص بالمسار:
  - التحقق من صعوبة التمرين أو تحديثها
  - إضافة مفاهيم إلى مفتاح `concepts`
  - إضافة مفاهيم إلى مفتاح `prerequisites`

## إنشاء مقاربة

لإنشاء ملفات المقاربة، يجب تحديد `slug` الخاص بالمقاربة والتمرين المرتبط بها:

```shell
configlet create --approach recursion --exercise collatz-conjecture
```

سيؤدي هذا إلى إنشاء الملفات المطلوبة للمقاربة، كما هو محدد في [وثائق المقاربات](/docs/building/tracks/approaches).

## إنشاء مقال

لإنشاء ملفات المقال، يجب تحديد `slug` الخاص بالمقال والتمرين المرتبط به:

```shell
configlet create --article performance --exercise collatz-conjecture
```

سيؤدي هذا إلى إنشاء الملفات المطلوبة للمقال، كما هو محدد في [وثائق المقالات](/docs/building/tracks/articles).
