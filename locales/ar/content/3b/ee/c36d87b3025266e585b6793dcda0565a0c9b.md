# التعليمات

بصفتها ساحرةً مبتدئة، تحتاج Elyse إلى التدرّب على بعض الأساسيات.

لديها مكدس من البطاقات تريد التلاعب به.

ولتسهيل الأمور قليلًا، تستخدم البطاقات من 1 إلى 10 فقط.

يمثّل مكدس البطاقات قيمة من نوع `Array`، بحيث يكون أسفل المكدس في مقدمة المصفوفة، وأعلى المكدس في نهايتها.

## 1. أدخل بطاقة في أعلى المكدس

نفّذ الدالة `insert_top` التي تُرجع نسخة من المكدس بعد إضافة البطاقة الجديدة المعطاة إلى أعلى المكدس.

```rust
let stack = array![5, 9, 7, 1];
insert_top(stack, 8);
// -> [5, 9, 7, 1, 8]
```

## 2. أزل البطاقة العلوية من المكدس

نفّذ الدالة `remove_top_card` التي تُرجع نسخة من المكدس بعد إزالة بطاقته العلوية.

إذا كان المكدس المعطى فارغًا، فيجب إرجاع المكدس الأصلي دون تغيير.

```rust
let stack = array![3, 2, 6, 4, 8];
remove_top_card(stack);
// -> [3, 2, 6, 4]
```

## 3. أدخل بطاقة في أسفل المكدس

نفّذ الدالة `insert_bottom` التي تُرجع نسخة من المكدس بعد إضافة البطاقة الجديدة المعطاة إلى أسفل المكدس.

```rust
let stack = array![5, 9, 7, 1];
insert_bottom(stack, 8);
// -> [8, 5, 9, 7, 1]
```

## 4. أزل بطاقة من أسفل المكدس

نفّذ الدالة `remove_bottom_card` التي تُرجع نسخة من المكدس بعد إزالة بطاقته السفلية.

إذا كان المكدس المعطى فارغًا، فيجب إرجاع المكدس الأصلي دون تغيير.

```rust
let stack = array![8, 5, 9, 7, 1];
remove_bottom_card(stack);
// -> [5, 9, 7, 1]
```

## 5. تحقّق من حجم المكدس

نفّذ الدالة `check_size_of_stack` التي تتحقق مما إذا كان حجم المكدس يساوي قيمة `stack_size` المعطاة أم لا.

```rust
let stack = array![3, 2, 6, 4, 8];
check_size_of_stack(stack, 4);
// -> false
```
