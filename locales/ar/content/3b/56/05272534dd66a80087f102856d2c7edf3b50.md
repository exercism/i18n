# القابلية للتغيير

تعتمد Cairo، بتصميمها الموجّه نحو سلاسل الكتل، نموذج ذاكرة غير قابل للتغيير افتراضيًا. وهذا يعني أنه بمجرد كتابة قيمة في الذاكرة، لا يمكن الكتابة فوقها، بل قراءتها فقط. غير أن Cairo توفّر آلية لإنشاء متغيرات قابلة للتغيير باستخدام الكلمة المفتاحية `mut`. وعندما يُعلَن متغير قابل للتغيير وتتغيّر قيمته، تُكتب القيمة الجديدة في خلية ذاكرة جديدة، ويُحدَّث المتغير ليشير إلى الخلية الجديدة. وتتيح هذه الآلية المرونة مع الحفاظ على فوائد عدم القابلية للتغيير.

في المثال أدناه، يُعلَن `x` كمتغير غير قابل للتغيير. وإذا تغيّرت قيمة `x`، فسيُصدر المترجم خطأً.

```rust
let x = 5;
x = 2; // Error: cannot assign twice to immutable variable
```

يمكننا إعلان `x` كمتغير قابل للتغيير باستخدام الكلمة المفتاحية `mut`. وهذا يسمح بتغيير قيمة `x` بعد إعلانها.

```rust
let mut x = 5;
x = 10;
```

في النهاية، قرار استخدام القابلية للتغيير من عدمه متروك لك، ويعتمد على ما تراه الأوضح في تلك الحالة بعينها.

## الثوابت

مثل المتغيرات غير القابلة للتغيير، الثوابت قيم تُربط باسم ولا يُسمح لها بالتغيير، لكن هناك بعض الفروق بين الثوابت والمتغيرات:

- تُعلَن الثوابت باستخدام الكلمة المفتاحية `const`
- لا يُسمح لك باستخدام `mut` مع الثوابت
- يجب دائمًا تحديد نوع القيمة صراحةً
- لا يمكن إعلان الثوابت إلا في النطاق العام
- لا يمكن ضبط الثوابت إلا على تعبيرات ثابتة، وليس على نتيجة قيمة تُحسب في وقت التشغيل

```rust
struct AnyStruct {
    a: u256,
    b: u32
}

enum AnyEnum {
    A: felt252,
    B: (usize, u256)
}

const ONE_HOUR_IN_SECONDS: u32 = 3600;
const STRUCT_INSTANCE: AnyStruct = AnyStruct { a: 0, b: 1 };
const ENUM_INSTANCE: AnyEnum = AnyEnum::A('any enum');
const BOOL_FIXED_SIZE_ARRAY: [bool; 2] = [true, false];
```

من الممكن استخدام الماكرو `consteval_int!` لإنشاء متغير `const` يكون نتيجة بعض العمليات الحسابية.

```rust
const ONE_HOUR_IN_SECONDS: u32 = consteval_int!(60 * 60);
```

## التظليل

من الممكن، وغالبًا ما يكون أسلوبًا مألوفًا، إعادة استخدام اسم متغير عند تحويل قيمة معيّنة، عبر إعادة إعلانه باستدعاءات `let` متعددة.
يُعرف هذا باسم _التظليل_.
في الواقع، يُظلِّل المتغير الثاني المتغير الأول، فيستحوذ على أي استخدامات لاسم المتغير لنفسه حتى يُظلَّل هو نفسه أو ينتهي النطاق.

```rust
fn main() {
    let s: ByteArray = "my string";
    let s: ByteArray = s + " and a shadow";
    {
        let s: ByteArray = "a nested shadow";
        println!(s); // emits "a nested shadow"
    }
    println!(s); // emits "my string and a shadow"
}
```

باستخدام التظليل، يمكننا حتى تغيير نوع المتغير مع إعادة استخدام اسم المتغير نفسه.

```rust
fn main() {
    let x: u64 = 2;
    println!("x is u64, value: {}", x);               // prints "x is u64, value: 2"
    let x: ByteArray = format!("fizz");               // converts x to a ByteArray, type annotation is required
    println!("x is now ByteArray, value: \"{}\"", x); // prints 'x is now ByteArray, value: "fizz"'
}
```
