# التعليمات

كانت دافني تعمل على نظام لتشغيل تجاربها وتسجيل نتائجها. أصبح بعض الكود مطوّلًا ومكررًا نوعًا ما، لذا طلبت منك كتابة بعض تعبيرات `use` للمساعدة في تنظيفه.

## 1. عرّف دالة `with_retry`

قد تفشل التجارب أحيانًا بسبب خطأ عابر، لذا إذا فشلت تجربة ما، تريد دافني إعادة محاولتها لمعرفة ما إذا كانت ستنجح في المرة الثانية.

عرّف دالة `with_retry` التي تأخذ دالةً تُرجع نتيجة كوسيط.

إذا أرجعت الدالة قيمة `Ok` فينبغي أن تُرجع `with_retry` تلك القيمة.

وإذا أرجعت الدالة قيمة `Error` فينبغي أن تستدعي `with_retry` الدالة مرة أخرى وتُرجع نتيجة ذلك الاستدعاء.

ستستخدم دافني الدالة هكذا:

```gleam
pub fn main() {
  use <- with_retry
  // Perform the experiment here
}
```

## 2. عرّف دالة `record_timing`

تسجّل دافني المدة التي تستغرقها كل تجربة في التشغيل عبر استدعاء دالة لتسجيل الوقت قبل كل تجربة وبعدها.

عرّف دالة `record_timing` التي تأخذ وسيطين:
- دالة لتسجيل الوقت لا تأخذ أي وسائط وتُرجع `Nil`.
- دالة للتجربة لا تأخذ أي وسائط وتُرجع نتيجة.

ينبغي أن تستدعي `record_timing` دالة تسجيل الوقت، ثم تستدعي دالة التجربة، ثم تستدعي دالة تسجيل الوقت مرة أخرى، وأخيرًا تُرجع نتيجة دالة التجربة.

ستستخدم دافني الدالة هكذا:

```gleam
pub fn main() {
  use <- record_timing(time_logger)
  // Perform the experiment here
}
```

## 3. عرّف دالة `run_experiment`

تتكوّن التجارب من ثلاث مراحل: التهيئة، والإجراء، والتسجيل. تُرجع المراحل الثلاث نتائج، وتحتاج كل مرحلة إلى النتيجة الناجحة للمرحلة السابقة لكي تعمل.

عرّف دالة `run_experiment` التي تأخذ أربعة وسائط:
- اسم التجربة كـ`String`.
- دالة تهيئة لا تأخذ أي وسائط وتُرجع نتيجة.
- دالة إجراء تأخذ قيمة `Ok` الخاصة بدالة التهيئة كوسيط وتُرجع نتيجة.
- دالة تسجيل تأخذ قيمتي `Ok` لدالتي التهيئة والإجراء كوسيطين وتُرجع نتيجة.

إذا نجحت الدوال الثلاث كلها فينبغي أن تُرجع `run_experiment` القيمة `Ok(#(experiment_name, recording_data))`.

وإذا أرجعت أي من الدوال قيمة `Error` فينبغي أن تُرجع `run_experiment` تلك القيمة.

ستستخدم دافني الدالة هكذا:

```gleam
pub fn main() {
  use setup_data, action_data <- run_experiment("Test 1", setup, action)
  // Record the results here
}
```
