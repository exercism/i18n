# عبارات `case`

```sather
   case zone
   when 0 then return 0;
   when 1, 2 then return 550;
   else return 920;
   end;
```

## كيف تتم المطابقة

تتم مقارنة القيمة التي تأتي بعد `case` بكل قيمة من قيم `when` باستخدام `=`، من الأعلى إلى الأسفل. تُنفَّذ أول مطابقة، وهي وحدها. تُتخطى أجزاء `when` المتبقية، ويستمر التنفيذ بعد `end`.

يمكن استخدام أي نوع يدعم `=`: `INT` و`CHAR` و`STR` و`BOOL`.

## الجزء `else`

عبارة `case` لا تطابق أي قيمة، ومن دون `else`، تُسبب خطأً فادحًا وقت التشغيل. اكتبه دائمًا. وحين لا يُفترض أن تحدث الحالات المتبقية بحق، فصرّح بذلك هناك بدلًا من الاستغناء عنه:

```sather
   else
      raise "unknown zone: " + zone;
   end;
```

سنأتي إلى `raise` لاحقًا؛ وإلى ذلك الحين، لا بأس بإرجاع قيمة افتراضية معقولة.

## متى تفضّل `if`

تقارن `case` قيمة واحدة بالثوابت. وأي شيء آخر يحتاج `if`:

```sather
   -- ranges
   if age < 13 then ... elsif age < 16 then ... end;

   -- more than one value at a time
   if score >= 8 and sings then ... end;
```

محاولة حشر نطاق داخل `case` تُنتج شيئًا أطول وأسوأ من `if` الذي استبدلته.

## `case` كتعبير

`case` عبارة وليست تعبيرًا، لذا فما يلي ليس كود Sather صحيحًا:

```sather
   -- wrong
   fare := case zone when 1 then 550 else 920 end;
```

أرجِع من داخل كل فرع، أو أسنِد إلى متغير داخل كل فرع.
