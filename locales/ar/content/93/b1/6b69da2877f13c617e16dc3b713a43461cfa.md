# مقدمة

## دوال الاستدعاء الراجع

دوال الاستدعاء الراجع هي دوال تُمرَّر كوسائط. يُنشئ هذا النمط البرمجي تسلسلًا من استدعاءات الدوال، في البرمجة المتزامنة وغير المتزامنة على حد سواء. لا تختلف كتابة دالة الاستدعاء الراجع عن كتابة أي دالة أخرى؛ غير أن دالة الاستدعاء الراجع يجب أن تطابق التوقيع الذي تحدده الدالة المستدعية.

```javascript
const sideLength = 5;

// Caller function takes a callback function
function applySideLength(callback) {
  return callback(sideLength);
}

// Callback must expect the possible argument from the calling function
function areaOfSquare(side) {
  return side * side;
}

applySideLength(areaOfSquare); // => 25
```

يمكنك أيضًا كتابة دوال الاستدعاء الراجع كتعبير دالة:

```javascript
applySideLength(function squarePerimeterLength(side) {
  return side * 4;
});
```
