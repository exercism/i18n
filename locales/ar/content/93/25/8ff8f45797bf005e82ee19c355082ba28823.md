# نبذة

أربع كلمات من `grouping` و`splitting` تغطي تقريبًا كل ما تحتاجه عند «تقطيع متتالية إلى قطع»:

```factor
USING: grouping kernel sequences splitting splitting.monotonic ;

! Disjoint chunks of N elements
{ 1 2 3 4 5 6 7 } 3 group .
! => { { 1 2 3 } { 4 5 6 } { 7 } }

! Overlapping sliding window of N elements
{ 1 2 3 4 5 } 2 clump .
! => { { 1 2 } { 2 3 } { 3 4 } { 4 5 } }

! Split wherever a predicate fires on an element
{ 1 2 0 3 4 0 5 } [ zero? ] split-when .
! => { { 1 2 } { 3 4 } { 5 } }

! Group runs where adjacent elements are "the same" by some test
{ 1 1 2 2 2 3 } [ = ] monotonic-split .
! => { { 1 1 } { 2 2 2 } { 3 } }
```

| كلمة              | التأثير                                                                  |
|-------------------|-------------------------------------------------------------------------|
| `group`           | `( seq n -- groups )`: قطع منفصلة بحجم *n*                              |
| `clump`           | `( seq n -- clumps )`: نوافذ متداخلة بحجم *n*                           |
| `split-when`      | `( seq quot: ( elt -- ? ) -- pieces )`: يقطع عندما تكون نتيجة `quot` صحيحة |
| `monotonic-split` | `( seq quot: ( a b -- ? ) -- pieces )`: يقطع عندما تكون نتيجة `quot` على عنصرين *متجاورين* هي `f` |

نموذج ذهني مفيد:

- **`group` / `clump`** تنظران إلى الأحجام؛ فالمعامل *n* يحدد حجم كل نافذة.
- **`split-when`** تنظر إلى *العناصر المفردة*؛ فالشرط يحدد ما إذا كان كل عنصر يمثل «فاصلًا».
- **`monotonic-split`** تنظر إلى *الأزواج*؛ فالشرط يحدد ما إذا كان عنصران متجاوران لا يزالان ينتميان إلى التتابع نفسه.
