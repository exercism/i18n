# مقدمة

الهياكل امتداد مبني فوق [الخرائط][exercism-maps]، وتوفّر فحوصات وقت التصريف وقيمًا افتراضية. يأخذ الهيكل اسمه من الوحدة التي يُعرَّف فيها. ولتعريف هيكل، استخدم التركيب `defstruct`. وعادةً ما يأتي هذا التركيب مباشرةً بعد تعريف الوحدة. ويقبل `defstruct` إما قائمة ذرات (لقيم افتراضية من نوع `nil`) أو قائمة كلمات مفتاحية (لقيم افتراضية محدَّدة). ويجب أن تأتي الحقول التي لا تحتوي على قيم افتراضية قبل الحقول التي لها قيم افتراضية.

```elixir
defmodule Plane do
  defstruct [:engine, wings: 2]
end

plane = %Plane{}
# => %Plane{engine: nil, wings: 2}
```

## الوصول إلى الحقول وتحديثها

بما أن الهياكل مبنية على الخرائط، يمكننا استخدام معظم دوال الخرائط للحصول على القيم والتلاعب بها. ولا يتم تنفيذ _سلوك الوصول_ على الهياكل، ويُوصى بدلًا من ذلك باستخدام _عامل الوصول الثابت_ `.` للوصول إلى حقول الهيكل.

- الحصول على قيم الحقول أو جلبها:

  ```elixir
  plane = %Plane{}
  plane.engine
  # => nil
  Map.fetch(plane, :wings)
  # => {:ok, 2}
  ```

- تحديث قيم الحقول

  ```elixir
  plane = %Plane{}
  %{plane | wings: 4}
  # => %Plane{engine: nil, wings: 4}
  ```

## مطابقة الأنماط

يمكن استخدام الهياكل في مطابقة الأنماط مع اسم الهيكل أو من دونه.

```elixir
plane = %Plane{}
%Plane{wings: wings} = plane
%{wings: wings} = plane
```

وعند تضمين اسم الهيكل في النمط، يمكنك التأكد من أن الطرفين الأيسر والأيمن هما هيكلان من النوع نفسه.

```elixir
defmodule Helicopter do
  defstruct [:engine, rotors: 1]
end

%Plane{} = %Helicopter{}
# => (MatchError) no match of right hand side value: %Helicopter{engine: nil, rotors: 1}
```

## فرض تهيئة قيم الحقول

يمكننا استخدام سمة الوحدة `@enforce_keys` مع قائمة بمفاتيح الحقول للتأكد من تهيئة القيم عند إنشاء الهيكل. وإذا لم يُدرَج مفتاح ما، فستكون قيمته `nil` كما في المثال أعلاه. وإذا لم يُهيَّأ مفتاح مفروض، يُرفع خطأ.

```elixir
defmodule User do
  @enforce_keys [:username]
  defstruct [:username]
end

%User{}
# => (ArgumentError) the following keys must also be given when building struct User: [:username]
```
