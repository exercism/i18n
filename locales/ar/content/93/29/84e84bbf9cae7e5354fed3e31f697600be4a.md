# مقدمة

## المصفوفات

`list` في F# مجموعة غير قابلة للتغيير تتكوّن من صفر أو أكثر من القيم. ويجب أن تكون جميع القيم في المصفوفة من النوع نفسه. ولأن المصفوفات غير قابلة للتغيير، فبمجرد إنشاء المصفوفة لا يمكن أن تتغيّر قيمتها أبدًا. وأي دوال أو عوامل تبدو وكأنها تعدّل المصفوفة (مثل إضافة عنصر) ستُرجع في الواقع مصفوفة جديدة.

يمكن تعريف المصفوفات على النحو التالي:

```fsharp
let empty = []
let singleValue = [5]
let threeValues = ["a"; "b"; "c"]
```

الأسلوب الأكثر شيوعًا لإضافة عنصر إلى مصفوفة هو استخدام المعامل `::` (cons):

```fsharp
let twoToFour = [2; 3; 4]
let oneToFour = 1 :: twoToFour
// => [1; 2; 3; 4]
```

تحتوي المصفوفة في F# على _رأس_ (العنصر الأول) و_ذيل_ (كل ما يأتي بعد العنصر الأول). وذيل المصفوفة هو بذاته مصفوفة.

يتم التعامل مع المصفوفات إما عبر دوال وعوامل معرّفة في وحدة `List`، أو يدويًا باستخدام مطابقة الأنماط عبر نمطي _list_ و_cons_:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | head::tail -> sprintf "Non-empty list with head: %d" head

describe []        // => "Empty list"
describe [1]       // => "Non-empty with head: 1"
describe [5; 7; 9] // => "Non-empty with head: 5"
```

يمكنك أيضًا _تجاهل_ قيمة عند مطابقة الأنماط؛ فعندما _لا_ تهتم بقيمة ما في حالة معيّنة (أي أنك لن _تستخدم_ القيمة) يمكنك استخدام شرطة سفلية (`'_'`) للدلالة على ذلك:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [x] -> "List with one item"
    | [_; y] -> "List with two items (first item ignored)"
    | _ -> "List with many items (all items ignored)"

describe []        // => "Empty list"
describe [1]       // => "List with one item"
describe [5; 7]     // => "List with two items (first item ignored)"
describe [5; 7; 9] // => "List with many items (all items ignored)"
```

ينبغي أن تأتي `'_'` المفردة دائمًا _أخيرًا_ عند مطابقة الأنماط، فكل قيمة _لا_ تطابق أيًّا من الحالات الأخرى ستُعالَج بواسطة هذه الحالة.
