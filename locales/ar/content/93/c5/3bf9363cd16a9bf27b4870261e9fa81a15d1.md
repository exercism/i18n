# التلاعب بالأنواع

قد يُعرف التلاعب بالأنواع أيضًا بالتحويل القسري للأنواع.
يحدث التلاعب بالأنواع عندما تُحوَّل قيمتان من نوعين مختلفين قسرًا إلى النوع نفسه لتنفيذ عملية ما.

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15 // int
```

عند تقييم التعبير، تُحوَّل قيمة السلسلة النصية ضمنيًا إلى `int` لتوافق ما يتوقعه العامل `*`.
ويقرر PHP أي نوع سيُحوَّل قسرًا وفقًا لقواعد العملية، وهذه القواعد تتفاوت كثيرًا.

يحدث التحويل القسري للأنواع أيضًا عند استدعاء الدوال والطرق:

```php
strlen(12321);
# => 5
```

## صبّ الأنواع

بدلًا من الاعتماد على التحويل القسري الضمني، يمكننا أن نجبر قيمة صراحةً على أن تُقيَّم كنوع معين باستخدام صبّ الأنواع على طريقة `C`:

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

سيحوّل هذا القيمة إلى النوع المحدد بين الأقواس الهلالية `(...)`.
ويمكن استخدام كل الأنواع الأولية كنوع هدف: `bool`، `int`، `float`، `string`، `array`، `object`.

## تحويل مؤقت فقط

لا **يغيّر** التلاعب بالأنواع ولا الصبّ نوع القيمة المخزنة في متغير.
لا يُحوَّل سوى المُدخل إلى العملية.

```php
$apples_per_basket = "3" // string
5 * $apples_per_basket
# $apples_per_basket => "3" // string

$my_number = (int) $apples_per_basket // cast string to int
# $apples_per_basket => "3" // string
```

## فقدان المعلومات

عند تحويل قيمة قسرًا إلى نوع آخر، قد يحدث فقدان للمعلومات أثناء ذلك:

```php
$exact_distance = 15.5
$rough_distance = (int) $exact_distance
// => 15

$is_distant = (bool) $exact_distance
// => true

$erroneous_distance = (float) $is_distant
// => 1.0
```

قد يؤدي الاعتماد على الصبّ، صراحةً أو ضمنيًا، إلى أخطاء في نظام أكبر.

## الصبّ الصريح إلى `array` و`object`

يمكن أيضًا صبّ القيم إلى النوعين `array` و`object`.
إذا صُبّت قيمة ليست مصفوفة ولا كائنًا إلى `array`، فإنها تُحوَّل إلى عنصر واحد داخل مصفوفة:

```php
$day_of_the_week = 'Monday';
(array) $day_of_the_week
// => array(1) {
//      [0]=>
//        string(6) "Monday"
//    }
```

وعند صبّها إلى `object`، تُضبط القيمة في خاصية عامة تُسمّى `scalar`:

```php
$car = "Honda"
(object) $car
// => object(stdClass)#1 (1) {
//      ["scalar"]=>
//        string(5) "Honda"
//    }
```

> `stdClass` هو نوع صنف مجهول مدمج في PHP.
