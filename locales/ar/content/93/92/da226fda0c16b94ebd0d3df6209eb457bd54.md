# حول

المصفوفات في C# هي مجموعات من القيم الأولية أو من نسخ البنى (`struct`) أو الأصناف. وهي مُنفَّذة في مكتبة الأصناف الأساسية باسم [`List<T>`][lists-docs]، حيث `T` هو نوع العنصر في المصفوفة. وتوفّر واجهة API مجموعة غنية من الطرق لإنشاء المصفوفات والتعامل معها.

```csharp
var listOfStrings = new List<string>();
var listOfIntegers = new List<int>();
var listOfRandoms = new List<Random>();
var listOfBigIntegers = new List<BigInteger>();
```

يتضمّن تعريف المجموعة عادةً عنصرًا نائبًا بين الأقواس الزاوية، وغالبًا ما يكون `T` بحسب العُرف. ويتيح ذلك لمستخدم المجموعة تحديد نوع العناصر التي يريد تخزينها فيها.

وعلى عكس [concept:csharp/arrays]()، تستطيع المصفوفات تغيير حجمها ديناميكيًا.

## LINQ

رغم أن واجهة API المدمجة في `List<T>` غنية، وتشمل التعيينات والمرشحات مثل `ConvertAll` و`FindAll` و`Foreach`، وأن [صيغة التكرار][for-each] فيها واضحة جدًا، وأنك بالتأكيد بحاجة إلى الإلمام بهذه الواجهة، فإن الاستعلام المتكامل مع اللغة ([LINQ][linq]) متاح للعديد من المهام. بل إنه أقوى وأكثر انتشارًا، ويتميز بتوفير واجهة موحّدة عبر مجموعات المكتبات والمجموعات من أطراف ثالثة وأصنافك الخاصة.
