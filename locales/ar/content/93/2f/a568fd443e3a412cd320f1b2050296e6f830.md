# نبذة

Perl لغة برمجة أنشأها Larry Wall، وأُصدرت أول مرة عام 1987.

## الحزم والوحدات

الحزمة مجموعة من الكود، غالبًا ما تكون داخل ملف وحدة يحمل الاسم نفسه بالامتداد `.pm`.
ويمكن بعد ذلك استيراد الوحدة إلى ملف آخر، عادةً باستخدام الكلمة المفتاحية `use`.

```perl
# Foo.pm
package Foo;

# Accessible with `Foo::bar` when module is used
# or just `bar` if the subroutine is exported.
sub bar () {
    return 1;
}
```

## المتغيرات

توجد ثلاثة أنواع من المتغيرات: المتغيرات القياسية (`$foo`)، والمصفوفات (`@bar`)، والتجزئات (`%baz`).
وللتبسيط، سنستخدم هنا المتغيرات القياسية فقط.
يمكن أن تكون قيمة المتغير القياسي واحدة مما يلي: سلسلة نصية، أو عدد، أو قيمة منطقية، أو [مرجع][perlreftut] إلى شيء ما.
وغياب القيمة هو `undef`.


تُعرّف الكلمتان المفتاحيتان `my` و`our` متغيرًا في النطاق المعجمي، مثل `my $foo;`.
ومع `our`، سيكون المتغير أيضًا اسمًا مستعارًا لمتغير حزمة يحمل الاسم نفسه.
وهناك طرق أخرى لتعريف المتغيرات لن نتناولها هنا.

يمكنك إسناد قيمة إلى متغير باستخدام العامل `=`، مثل `$foo = 1;`، ويمكنك فعل ذلك في الوقت نفسه الذي تُعرّف فيه المتغير، مثل `my $foo = 1;`.

```perl
package Foo;

sub baz () {
    our $bar = 1; # Sets both $bar and $Foo::bar as 1.
    return $bar;
}

$Foo::bar = 2; # $bar is not accessible here, but $Foo::bar is.

# Both of these will print 1.
say baz;
say $Foo::bar;
```

## الإجراءات الفرعية

تُعرّف الكلمة المفتاحية `sub` [إجراءً فرعيًا][perlsub].
وتُنهي الكلمة المفتاحية `return` الإجراء الفرعي، فتُرجع القيم المحددة، أو قائمة فارغة إن لم يُعطَ شيء.
وبدون `return` محدد، تتحدد القيمة المُرجَعة حسب سياق الإجراء الفرعي المستخدم (قياسي، أو قائمة، أو فارغ) وعبارته الأخيرة.

```perl
sub hello () {
    return 'Hello, World!';
}
```

تتيح لك الإصدارات الحديثة من Perl تحديد المعاملات الرسمية في [توقيع][perlsubsig].
ويمكن أن تحتوي قائمة المعاملات على متغيرات قياسية أو مصفوفات أو تجزئات.
وقائمة المعاملات الفارغة تعني أن الإجراء الفرعي لا يقبل أي وسيط.
أما الإصدارات الأقدم من Perl فكانت تتطلب جلب الوسائط من المتغير الخاص `@_`، وهو ما لن نتناوله هنا.
