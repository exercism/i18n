# مقدمة إلى تأكيدات النوع

قد تُدخل الواجهات في Go غموضًا حول النوع الأساسي.
يتيح لنا تأكيد النوع استخراج القيمة الأساسية الفعلية لقيمة الواجهة باستخدام هذه الصيغة: `interfaceVariable.(concreteType)`.

على سبيل المثال:

```go
var input interface{} = 12
number := input.(int)
```

ملاحظة: سيؤدي هذا إلى `panic` إذا لم يحمل متغير الواجهة قيمة من النوع الفعلي.

يمكننا اختبار ما إذا كانت قيمة الواجهة تحمل نوعًا فعليًا معينًا بالاستفادة من قيمتَي الإرجاع في تأكيد النوع: القيمة الأساسية وقيمة منطقية تخبرنا ما إذا نجح التأكيد.
على سبيل المثال:

```go
str, ok := input.(string) // no panic if input is not a string
```

إذا حمل `input` سلسلة نصية، فستكون `str` هي القيمة الأساسية، وستكون قيمة `ok` هي صحيح.
وإذا لم يحمل `input` سلسلة نصية، فستكون `str` هي القيمة الصفرية للنوع `string` (أي `""`، السلسلة النصية الفارغة)، وستكون قيمة `ok` هي خطأ.
ولا يحدث `panic` في أي من الحالتين.

## تبديلات النوع

يمكن أن يُجري **تبديل النوع** عدة تأكيدات نوع على التوالي.
له الصيغة نفسها التي لتأكيد النوع (`interfaceVariable.(concreteType)`)، لكن يُستبدل `concreteType` بالكلمة المفتاحية `type`.
وهذا مثال:

```go
var i interface{} = 12 // try: 12.3, true, int64(12), []int{}, map[string]int{}

switch v := i.(type) {
case int:
    fmt.Printf("the integer %d\n", v)
case string:
    fmt.Printf("the string %q\n", v)
default:
    fmt.Printf("type, %T, not handled explicitly: %#v\n", v, v)
}
```
