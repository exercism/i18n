# المقدمة

تُستخدم القيمة `null` للدلالة على _غياب_ قيمة. النوع **القابل للعدم** هو نوع يسمح للمتغير بأخذ القيمة `null`. لجعل أي نوع قابلًا للعدم، نغلّفه باستخدام `Null<T>`:

```haxe
var a:Int = null; // Error
var b:Null<Int> = null; // Allowed
```

للتحقق مما إذا كانت قيمة ما تساوي `null` حاليًا، ما عليك سوى استخدام تعبير `if`:

```haxe
var a:Null<Int> = 10;

if (a != null) {
  trace("a is not null"); // a is not null
}
```
