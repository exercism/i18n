# ملحق التعليمات

يتطلب رفع الأعداد النسبية إلى قوة عدد حقيقي حساب عدد مرفوع إلى قوة عدد غير صحيح، وهي إمكانية غير متاحة أصلاً في WebAssembly.

لكن يمكنك أيضًا كتابة `x ^ y` على الصورة `x ^ y = exp(y * ln(x))`.

ولحسن الحظ، يمكن استخدام متسلسلات مختلفة لحساب الدالة الأسية واللوغاريتم الطبيعي.

## الدالة الأسية

أفضل حل للدالة الأسية هو [متسلسلة تايلور](https://en.wikipedia.org/wiki/Taylor_series):

```
exp(x) ≃ 1 + x + x ^ 2 / 2! + x ^ 3 / 3! + x ^ 4 / 4! + ... + x ^ n / n!
```

## دالة اللوغاريتم (من أجل x موجب)

هناك طرق متعددة لحساب اللوغاريتم الطبيعي بكفاءة. إحداها متسلسلة مبنية على [الظل الزائدي العكسي](https://en.wikipedia.org/wiki/Logarithm#Inverse_hyperbolic_tangent):

```
ln(x) / 2 ≃ y + y ^ 3 / 3 + y ^ 5 / 5 + ... + y ^ n / n where y = (x - 1) / (x + 1)
```

وهناك أيضًا متسلسلة تايلور أخرى لحساب اللوغاريتم الطبيعي:

```
ln(x) = (x - 1) - (x - 1) ^ 2 / 2 + (x  - 1) ^ 3 / 3 - (x - 1) ^ 4 / 4 ... + (x - 1) ^ n / n
```

وهي دقيقة فقط عندما تكون `x` بين 0 و2. لكن يمكننا أيضًا استخدام `ln(x) = - ln(1 / x)`

## رفع الأعداد الصحيحة إلى قوة

من الأفضل عند رفع الأعداد الصحيحة إلى قوة استخدام الضرب مع حلقة أو استدعاء ذاتي، وذلك لأسباب تتعلق بالأداء والدقة. ولتحسين الأداء أكثر، يمكن استخدام [طريقة هورنر](https://en.wikipedia.org/wiki/Horner%27s_method) لتقليل عدد عمليات الضرب.
