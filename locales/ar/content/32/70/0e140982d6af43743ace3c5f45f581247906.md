# حول

عند كتابة دوال Haskell، يمكننا الاستفادة من [مطابقة الأنماط][pattern-matching].
مطابقة الأنماط ميزة قوية جدًا في Haskell تسمح لك بمطابقة منشئات البيانات وربط المتغيرات بالقيم الموجودة بداخلها.
وكما يوحي الاسم، ما نفعله هو مطابقة القيم مع الأنماط، وإذا طابقت القيمة النمط، يمكننا ربط المتغيرات بالقيم داخل النمط.
تتكون مطابقة الأنماط بشكل أساسي من هذه المفاهيم: التعرف على القيم، وربط المتغيرات، وتفكيك القيم.

~~~~exercism/note
تختلف مطابقة الأنماط في لغات مثل Elixir قليلاً عن مطابقة الأنماط في Haskell.
فعلى سبيل المثال، تسمح Elixir بتكرار أسماء الربط نفسها في النمط، بينما لا تسمح Haskell بذلك.
~~~~

خذ هذه الدالة على سبيل المثال:

```haskell
lucky :: Int -> String
lucky 7 = "Lucky number seven!"
lucky x = "Sorry, you're out of luck, pal!"
```

لدينا هنا دالة `lucky` تأخذ `Int` وتُرجع `String`.
لقد عرّفنا نمطين للدالة، أحدهما يطابق العدد `7` والآخر يطابق أي عدد آخر، يمكن أن يكون الاسم أي شيء (طالما يتبع اصطلاح تسمية Haskell)، لكننا نستخدم `x` هنا.
إذا كان العدد `7`، فستُرجع الدالة `"Lucky number seven!"`، وإلا فستُرجع `"Sorry, you're out of luck, pal!"`.
ما يهم ملاحظته هنا هو أن الأنماط تُفحص من الأعلى إلى الأسفل، لذا لو كنا قد بدّلنا ترتيب الأنماط، لكانت الدالة تُرجع دائمًا `"Lucky number seven!"`.

## أنماط المصفوفات

يُعد المطابقة على المصفوفات نمطًا شائعًا جدًا، ويتم ذلك بأخذ رأس المصفوفة وذيلها.
وذلك لأن المصفوفات بطبيعتها مترابطة.
إليك مثالاً لدالة تُرجع رأس المصفوفة وذيلها:

```haskell
headAndTail :: [Int] -> (Int, [Int])
headAndTail [] = error "Can't call head on an empty list"
headAndTail (x:xs) = (x, xs)
```

لدينا نمطان هنا، أحدهما يطابق مصفوفة فارغة والآخر يطابق مصفوفة تحتوي على عنصر واحد على الأقل.
وذلك لأنه إذا كانت المصفوفة فارغة، نحتاج إلى حالة خاصة لها، وإلا فسنحصل على خطأ أثناء التشغيل.
إذا لم تكن المصفوفة فارغة، يمكننا مطابقة رأس المصفوفة مع `x` وذيل المصفوفة مع `xs`.
يتم هذا باستخدام العامل `:` (cons)، الذي يُستخدم لإضافة عنصر إلى مقدمة المصفوفة.
لكنه في مطابقة الأنماط يسمح لنا بتفكيك المصفوفة إلى رأسها وذيلها، أي بمعنى آخر فعل العكس.

الـ `xs` اسم شائع لذيل المصفوفة، وهو يبرز أنها مصفوفة، لكن إذا كنت تعمل مع مصفوفة متداخلة، يمكنك استخدام `xss` لإبراز أنها مصفوفة من المصفوفات.

## أنماط الأزواج

كما هو الحال مع المصفوفات، يمكننا أيضًا المطابقة على الأزواج.
إليك مثالاً لدالة تأخذ زوجًا وتُرجع العنصرين الأول والثاني:

```haskell
sumTuple :: (Int, Int) -> Int
sumTuple (x, y) = x + y
```

لدينا هنا نمط يطابق زوجًا مكوّنًا من عنصرين، العنصر الأول مرتبط بـ `x` والعنصر الثاني مرتبط بـ `y`.

## أنماط البدل

أحيانًا لا نهتم بقيمة المتغير، نريد فقط المطابقة على النمط.
هنا يأتي دور نمط البدل، ويُشار إليه بشرطة سفلية `_`.

إليك مثالاً لدالة تُرجع العنصر الأول من مصفوفة:

```haskell
head' :: [Int] -> Int
head' [] = error "Can't call head on an empty list"
head' (x:_) = x
```

هنا نقول إننا لا نحتاج ذيل المصفوفة، لذا نستخدم نمط البدل لتجاهله.

## أنماط الأنواع

يمكننا أيضًا المطابقة على الأنواع، ويتم ذلك باستخدام مُنشئ النوع المذكور.
يمكننا أيضًا استخراج القيم من النوع، كما فعلنا مع الأزواج.

```haskell
data AccountType = Guest | User String 

greet :: AccountType -> String
greet Guest = "Welcome, guest!"
greet (User name) = "Welcome, " ++ name ++ "!"
```

في النمط الأول نطابق مُنشئ `Guest`، وفي النمط الثاني نطابق مُنشئ `User` ونربط القيمة الموجودة بداخله بـ `name`.

[pattern-matching]: https://en.wikibooks.org/wiki/Haskell/Pattern_matching
