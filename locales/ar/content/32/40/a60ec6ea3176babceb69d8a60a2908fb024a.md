# نبذة

الأنواع المعتمة في Gleam هي أنواع مخصصة، لا يمكن إنشاء قيم من هذا النوع أو مطابقتها بنمط إلا في الوحدة التي تعرّف النوع. وهذا مفيد لإنشاء أنواع لا يُراد استخدامها إلا على نحو محدّد.

وتُعرَّف الأنواع المعتمة باستخدام الكلمة المفتاحية `opaque`.

```gleam
pub opaque type PositiveInt {
  PositiveInt(inner: Int)
}
```

نوع `PositiveInt` هذا مخصّص للاستخدام في الحالات التي نحتاج فيها إلى عدد صحيح، لكن بشرط أن يكون صفرًا أو أكبر. فلا يمكن استخدام `Int` العادي في Gleam، لأنه قد يكون سالبًا أيضًا.

يمكن للوحدة التي تعرّف هذا النوع أن تعرّف دالة للحصول على قيمة العدد الصحيح الداخلية، ودالة لإنشاء نوع `PositiveInt` تُرجع خطأً إذا لم تكن القيمة موجبة.

```gleam
pub fn from_int(i: Int) -> Result(PositiveInt, String) {
  case i {
    _ if i < 0 -> Error("Value must be positive")
    _ -> Ok(PositiveInt(i))
  }
}

pub fn to_int(i: PositiveInt) -> Int {
  i.inner
}
```

ومع هذه الـ API، لا تستطيع الوحدات الأخرى إنشاء `PositiveInt` بقيمة سالبة، لذا يمكن لأي دالة تأخذ `PositiveInt` أن تتأكد أن القيمة موجبة.
