# مقدمة

إلى جانب الجملة الشرطية `if`، تمتلك JavaScript أيضًا جملة `switch` لتنفيذ منطق بشكل شرطي.
وهي تُستخدم عندما نحتاج إلى مقارنة متغير واحد بعدة خيارات مختلفة.
وتتم المقارنة بالتحقق من التساوي التام (`===`)، انظر [مفهوم المقارنة][concept-comparison].
بالنسبة لمتغير ما `x`، تأخذ جملة `switch` في JavaScript الصيغة التالية.

<!-- prettier-ignore-start -->
```javascript
switch (x) {
  case option1:
    // code that is executed when "x === option1" is true
    break;
  case option2:
    // code that is executed when "x === option2" is true
    break;
  default:
    // code that is executed when x does not equal any of the options
}
```
<!-- prettier-ignore-end -->

الحالة `default` اختيارية، وتُستخدم عندما تريد تنفيذ بعض الكود إذا لم يطابق المتغير أيًّا من الخيارات الأخرى.

نحتاج إلى عبارات `break` أعلاه لأن جميع الحالات تنتقل افتراضيًا إلى الحالة التالية في JavaScript.
وهذا يعني أنه بدون أي عبارة `break` سيُنفَّذ كل الكود في الحالات الواقعة بعد أول خيار مطابق حتى لو لم يطابق `x` تلك الخيارات.
يُعد هذا السلوك، أي الانتقال التلقائي إلى الحالة التالية افتراضيًا، خطأً شائعًا عند استخدام `switch` في JavaScript.
وداخل الدالة يمكن أيضًا استخدام `return` بدل `break` لتجنّب هذه المشكلة.
