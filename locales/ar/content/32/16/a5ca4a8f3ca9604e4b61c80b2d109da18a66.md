# تلميحات

## عام

- يأتي العقد بعد نوع الإرجاع وقبل `is`:

  ```sather
     spare_capacity(load : INT) : INT
        pre load >= 0
     is
        ...
     end;
  ```

- داخل العقد يمكنك استخدام الوسائط وخصائص الكائن، لذا فإن `limit` متاح.
- تُبنى الاختبارات بدون `-chk`، لذا لن يفشّلها عقد خاطئ. اكتبها من أجل القارئ.

## 1. جهّز حزام الأمان

- `pre kg > 0`، في `create`.
- الجسم هو `new` المعتاد: عيّن الخاصية ثم أرجعها.

## 2. كم تبقّى من السعة؟

- شرطان موصولان بـ `and`: `pre load >= 0 and load <= limit`.
- `post result >= 0`. هذا يتبع من `pre`، وهو ما يجعله جديرًا بالذكر: فهو يسجّل سبب إمكانية الوثوق بالإجابة.

## 3. ما مدى امتلائه؟

- `pre load >= 0` و `post result >= 0`.
- `load * 100 / limit`، بهذا الترتيب. القسمة أولًا ستُضيع كل شيء، كما سيحدث في `tuning-the-strings`.

## 4. هل هو آمن؟

- لا يوجد `pre` إطلاقًا: المقصود كله أن أي حمل قد يُسأل عنه.
- تُعيد `post` صياغة السؤال: `post result = (load <= limit)`. الأقواس الهلالية، لأن `=` مستخدم مرتين لشيئين مختلفين.
