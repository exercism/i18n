# أعداد الفاصلة العائمة

تُستخدم أعداد الفاصلة العائمة في PHP لتمثيل مجموعة فرعية من الأعداد الحقيقية.
وهي تبدأ برقم واحد أو أكثر تفصل بينها فاصلة عشرية.

```php
<?php

$a = 1.234; 
$b = 1.2e3; 
$c = 7E-10;
$d = 1_234.567; // as of PHP 7.4.0
```

## أخطاء شائعة

لا يمكن تمثيل كل الأعداد ولا إجراء كل العمليات الحسابية باستخدام أعداد الفاصلة العائمة.
قد يؤدي استخدام أعداد الفاصلة العائمة لتمثيل الدولارات والسنتات إلى أخطاء في التقريب.

```php
<?php

$result = 0.1 + 0.2; // => 0.30000000000000004
```
