# حول

تتبع التعبيرات النمطية في Gleam مواصفة **PCRE** (**P**erl **C**ompatible **R**egular **E**xpressions)، على غرار لغات شائعة أخرى مثل Java وJavaScript وRuby.

توفر وحدة `gleam/regex` دوالًا للتعامل مع التعبيرات النمطية.

~~~~exercism/note
يفترض هذا التمرين أنك تعرف بالفعل صيغة التعبيرات النمطية، بما في ذلك فئات الأحرف، ومحددات الكمية، والمجموعات، والالتقاطات.

إذا احتجت إلى تحديث معرفتك بالتعبيرات النمطية، فراجع أحد هذه المصادر: [Regular-Expressions.info](https://www.regular-expressions.info)، [Rex Egg](https://www.rexegg.com/)، [RegexOne](https://regexone.com/)، [Regular Expressions 101](https://regex101.com/)، [RegExr](https://regexr.com/).
~~~~

الطريقة الأكثر شيوعًا لإنشاء التعبيرات النمطية هي استخدام الدالة `regex.from_string`.

```gleam
let assert Ok(re) = regex.from_string("test")
```

تُرجع الدالة `regex.from_string` قيمة `Error` إذا كانت صيغة التعبير النمطي غير صالحة، لذلك استُخدم تأكيد let هنا لضمان أن التعبير النمطي صالح.

يمكن استخدام الدالة `regex.check` للتحقق مما إذا كان التعبير النمطي يطابق سلسلة نصية.

```gleam
let assert Ok(re) = regex.from_string("test")

regex.check(re, "this is a test")
// -> True

regex.check(re, "this is too")
// -> False
```


## الالتقاطات

إذا أردت التقاط سلاسل نصية فرعية باستخدام تعبير نمطي، فيمكن استخدام الدالة `regex.scan` لإرجاع مصفوفة من المطابقات.

```gleam
let assert Ok(re) = regex.from_string("[oi]n a (\\w+)")
regex.scan(with: re, content: "I am on a boat in a lake.")
// -> [
//   Match(
//     content: "on a boat",
//     submatches: [Some("boat")]
//   ),
//   Match(
//     content: "in a lake",
//     submatches: [Some("lake")]
//   )
// ]
```

## المعدّلات

يمكن تعديل سلوك التعبير النمطي بإنشائه باستخدام الدالة `regex.compile` وتمرير الخيارات.

```gleam
let options = regex.Options(case_insensitive: True, multi_line: False)
let assert Ok(re) = regex.compile("[A-Z]", with: options)
regex.check(re, "abc123")
// -> True
```
