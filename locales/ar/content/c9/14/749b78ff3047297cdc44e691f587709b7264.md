# مصادر التعلّم الموصى بها

أهلًا بك في تعلّم ColdFusion (CFML)! إنّ CFML لغة برمجة نصية ديناميكية ومرنة الأنواع تعمل على JVM. ولها نوعان مختلفان من الملفات. ملفات `.cfm` (وهي ترميز ColdFusion) إجرائية بالكامل وتستخدم صيغة الوسوم لقالبة HTML. وستستخدم هذه الملفات في العروض إذا كنت تبني موقع ويب:

**index.cfm**

```xml
<cfoutput>
	<html>
		<h1>Welcome to my site, #FirstName# #LastName#!
	</html>
</cfoutput>
```

النوع الآخر من الملفات هو `.cfc` (وهو مكوّن ColdFusion)، وبه تُعرّف الصنف. تُستخدم المكوّنات لمنطق الأعمال والنماذج والمتحكّمات. وهي تستخدم عادةً صيغة السكربت، التي تشبه JavaScript في قراءتها.

**Car.cfc**

```js
component accessors=true {
	property name='make' type='string';
	property name='model' type='string';
	property name='year' type='number';

	function init() {
		return this;
	}
 
}
```
