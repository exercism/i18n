# الاختبارات

## تشغيل الاختبارات

لتشغيل الاختبارات، نفّذ الأمر التالي:

```bash
dotnet test
```

لتشغيل الاختبارات تلقائيًا كلما تغيّر أحد ملفات المصدر، نفّذ الأمر التالي:

```bash
dotnet watch test
```

## حل التمرين

حل التمرين يعني اجتياز جميع اختباراته. افتراضيًا، لا يُنفَّذ عند تشغيل الاختبارات إلا اختبار واحد (الأول). وهذا مقصود، لأنه يتيح لك التركيز على اجتياز ذلك الاختبار الواحد فحسب. وبمجرد اجتيازه، يمكنك تفعيل الاختبار التالي عبر حذف `Skip = "Remove this Skip property to run this test"` من السمة `[Fact]` أو `[Theory]` الخاصة بالاختبار. وعندما تُفعَّل جميع الاختبارات ويجتازها تطبيقك بالكامل، تكون قد حللت التمرين!

ولمساعدتك على البدء، يأتي كل تمرين مصحوبًا بملف تطبيق أوّلي. يمكنك استخدام هذا الملف نقطة انطلاق لبناء حلك. ولا تتردد في حذف هذا الملف أو تغييره إذا رأيت أن ذلك هو الصواب.

## استخدام الحزم

ينبغي أن تكون قادرًا على حل معظم التمارين دون استخدام أي حزم خارجية. ومع ذلك، في التمارين التي ترغب فيها فعلًا في استخدام حزمة خارجية، يمكنك إضافتها إلى مشروعك بتشغيل الأمر التالي:

```bash
dotnet add package [package-name]
```
