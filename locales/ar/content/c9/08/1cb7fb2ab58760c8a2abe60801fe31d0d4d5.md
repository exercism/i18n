# مقدمة

حلقة `for` هي واحدة من أكثر العبارات استخدامًا لتنفيذ منطق ما بشكل متكرر.
في JavaScript، تتكوّن من الكلمة المفتاحية `for`، و_ترويسة_ محاطة بالأقواس الهلالية، وكتلة كود تحتوي على _جسم_ الحلقة محاطًا بالأقواس المعقوفة.

```javascript
for (initialization; condition; step) {
  // code that is executed repeatedly as long as the condition is true
}
```

عادةً ما تُهيّئ التهيئة متغير عدّاد، ويتحقق الشرط مما إذا كان ينبغي متابعة الحلقة أو إيقافها، وتزيد الخطوة العدّاد في نهاية كل تكرار.
وتفصل الفواصل المنقوطة بين الأجزاء الفردية للترويسة.

```javascript
const list = ['a', 'b', 'c'];
for (let i = 0; i < list.length; i++) {
  // code that should be executed for each item list[i]
}
```
