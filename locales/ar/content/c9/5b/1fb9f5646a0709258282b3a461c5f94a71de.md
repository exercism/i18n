# ملحق التعليمات

## السجلات

| السجل | الاستخدام | النوع | الوصف |
| -------- | --------- | ------- | ------------------------------------------------ |
| `$a0`    | إدخال     | عدد صحيح | السنة المراد فحصها                                    |
| `$v0`    | إخراج     | قيمة منطقية | المدخل سنة كبيسة (`0` = `false`، `1` = `true`) |
| `$t0-9`  | مؤقت | أي نوع     | يُستخدم للتخزين المؤقت                       |
