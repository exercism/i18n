# تحويل الوقود إلى JSON

## نص المسألة

يحصل كل موظف في شركة ABC Corp على بدل وقود غير محدود. ويُطلب من الموظفين إرسال سجل في كل مرة يعبّئون فيها سياراتهم بالوقود. تُضاف هذه السجلات إلى الملف نفسه بصيغة JSON وتُعالَج في نهاية الشهر.

بصفتك عضوًا في فريق العمليات الرقمية، مهمتك أن تقرأ ملف JSON هذا وتكتب النتائج في ملف JSON آخر. ينبغي أن يحتوي ملف الخرج على مدخل لكل موظف يتضمن التفاصيل التالية:

- رقم الموظف
- عدد مرات تعبئة الوقود
- إجمالي تكلفة الوقود
- إجمالي الغالونات
- إجمالي الأميال المتراكمة

ستُعطى وسيطين اثنين من النوع `string`.

1. مسار ملف JSON المُدخل.
1. مسار ملف JSON المُخرج.

يحتوي ملف JSON المُدخل على مصفوفة من كائنات JSON. يأخذ كل كائن JSON الشكل التالي.


```json
{
    "type": "array",
    "items": {
        "type": "object",
        "properties": {
            "employeeId": {
                "type": "integer"
            },
            "odometerReading": {
                "type": "integer"
            },
            "gallons": {
                "type": "number"
            },
            "gasPrice": {
                "type": "number"
            }
        },
        "required": [
            "employeeId",
            "odometerReading",
            "gallons",
            "gasPrice"
        ]
    }
}
```

```ballerina
// Ballerina record type definition
type FillUpEntry record {|
    int employeeId;
    int odometerReading;
    decimal gallons;
    decimal gasPrice;
|};
```

مهمتك أن تحوّل دخل JSON إلى صيغة JSON التالية وتكتب المحتوى إلى المسار المعطى. ينبغي أن يحتوي ملف الخرج على مدخل لكل موظف، مرتبةً تصاعديًا حسب `employeeId`.

```json
{
    "type": "array",
    "items": {
        "type": "object",
        "properties": {
            "employeeId": {
                "type": "integer"
            },
            "gasFillUpCount": {
                "type": "integer"
            },
            "totalFuelCost": {
                "type": "number"
            },
            "totalGallons": {
                "type": "number"
            },
            "totalMilesAccrued": {
                "type": "integer"
            }
        },
        "required": [
            "employeeId",
            "gasFillUpCount",
            "totalFuelCost",
            "totalGallons",
            "totalMilesAccrued"
        ]
    }
 }
```

```ballerina
// Ballerina record type definition
type EmployeeFillUpSummary record {|
    int employeeId;
    int gasFillUpCount;
    decimal totalFuelCost;
    decimal totalGallons;
    int totalMilesAccrued;
|};
```

## القيود

- عدد سجلات التعبئة `n` في ملف JSON المُدخل:  0 <= n <= 1000
- عدد الموظفين في الشركة: 97
- سعر الوقود لكل غالون
- لا توجد سجلات تعبئة مفقودة

## تلميحات

- استخدم [وحدة `ballerina/io`](https://lib.ballerina.io/ballerina/io/latest) لقراءة ملفات JSON وكتابتها.
- حوّل قيم JSON إلى أنواع خاصة بالتطبيق للتعامل مع البيانات بطريقة آمنة نوعيًا. راجع [مثال التحويل إلى نوع معرّف من المستخدم](https://ballerina.io/learn/by-example/convert-from-json-to-user-defined-type) في Ballerina By Examples (BBE) للحصول على المعلومات.

```ballerina
   json jsonPayload = {id: "2", title: "Jeru", artist: "Gerry Mulligan", price: 17.99};

   // Using cloneWithType  
   Album album1 = check jsonPayload.cloneWithType();
   io:println(album1);
 
   // Using fromJsonWithType
   Album album2 = check jsonPayload.fromJsonWithType();
   io:println(album2);
```

- قد يكون [تفكيك السجلات](https://ballerina.io/learn/by-example/destructure-records-using-query) مفيدًا في تقليل إسهاب الكود.

```ballerina
   Album {id, title, artist, price} = album1;
   io:println(id);
   io:println(title);
```

- استخدم دوالًا بجسم تعبيري للدوال التي تحتوي على تعبير واحد فقط. مثل الدوال التي تحتوي على عبارة الإرجاع فقط.

```ballerina
   function cfr(int deaths, int cases) returns decimal => <decimal>deaths / <decimal>cases * 100;
```
