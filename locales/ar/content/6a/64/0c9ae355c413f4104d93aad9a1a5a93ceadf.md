# التعليمات

في هذا التمرين ستقوم بمزيد من العمل على سيارات التحكم عن بُعد.

طُوّرت سيارة تجريبية، ويحتاج مسار الاختبار إلى تعديل ليتعامل مع الطرازات الإنتاجية والتجريبية معًا.

صُنع النوعان من السيارات بالفعل، وعليك إيجاد أسلوب للتعامل معهما معًا على مسار الاختبار.

بالإضافة إلى ذلك، بدأت سيارات الإنتاج تحقق بعض النجاح. ومدير الفريق حريص على الحفاظ على الروح التنافسية بنشر ترتيب لسيارات الإنتاج.

## 1. تمكين السيارات من السير على مسار الاختبار نفسه

من فضلك أضف طريقة إلى واجهة `IRemoteControlCar` بحيث تكشف تنفيذات `Drive()` للنوعين من السيارات.

```csharp
TestTrack.Race(new ProductionRemoteControlCar());
TestTrack.Race(new ExperimentalRemoteControlCar());
// this should execute without an exception being thrown
```

## 2. تمكين مقارنة المسافة التي تقطعها الطرازات المختلفة على مسار الاختبار

من فضلك أضف خاصية إلى واجهة `IRemoteControlCar` بحيث تكشف تنفيذات الخاصية `DistanceTravelled` للنوعين من السيارات.

```csharp
var prod = new ProductionRemoteControlCar();
TestTrack.Race(prod);
var exp = new ExperimentalRemoteControlCar();
TestTrack.Race(exp);
prod.DistanceTravelled
// => 10
exp.DistanceTravelled
// => 20
```

## 3. السماح بترتيب سيارات الإنتاج

من فضلك نفّذ الواجهة `IComparable<T>` في الصنف `ProductionRemoteControlCar`. وينبغي أن يكون ترتيب الفرز الافتراضي للسيارات تصاعديًا حسب عدد الانتصارات.

نفّذ الطريقة الثابتة `TestTrack.GetRankedCars()` لتُرجع السيارات المُمرَّرة مرتّبة ترتيبًا تصاعديًا حسب عدد الانتصارات.

```csharp
var prc1 = new ProductionRemoteControlCar();
var prc2 = new ProductionRemoteControlCar();
prc1.NumberOfVictories = 3;
prc2.NumberOfVictories = 2;
var rankings = TestTrack.GetRankedCars(prc1, prc2);
// => rankings[1] == prc1
```
