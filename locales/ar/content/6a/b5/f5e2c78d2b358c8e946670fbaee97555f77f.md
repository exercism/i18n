# مقدمة

## التعبيرات النمطية

تتبع التعبيرات النمطية في Elixir مواصفة **PCRE** (**P**erl **C**ompatible **R**egular **E**xpressions)، على غرار لغات شائعة أخرى مثل Java وJavaScript وRuby.

توفّر وحدة `Regex` دوالًا للعمل مع التعبيرات النمطية. كما تقبل بعض دوال وحدة `String` تعبيرات نمطية كوسائط أيضًا.

~~~~exercism/note
يفترض هذا التمرين أنك تعرف بالفعل صياغة التعبيرات النمطية، بما في ذلك أصناف المحارف ومحددات الكمية والمجموعات والالتقاطات.

إذا كنت بحاجة إلى تحديث معرفتك بالتعبيرات النمطية، فراجع أحد هذه المصادر: [Regular-Expressions.info](https://www.regular-expressions.info)، و[Rex Egg](https://www.rexegg.com/)، و[RegexOne](https://regexone.com/)، و[Regular Expressions 101](https://regex101.com/)، و[RegExr](https://regexr.com/).
~~~~

### السيجيلات

أكثر الأساليب شيوعًا لإنشاء التعبيرات النمطية هو استخدام سيجيل `~r`.

```elixir
~r/test/
```

لاحظ أن جميع سيجيلات Elixir تدعم [أنواعًا مختلفة من المحددات][sigils]، وليس `/` فقط.

### المطابقة

يمكن استخدام العامل `=~/2` لإجراء مطابقة تعبير نمطي تُرجع نتيجة من النوع `boolean`. وبدلًا من ذلك، توجد أيضًا دوال `match?/2` في وحدة `Regex` وكذلك في وحدة `String`.

```elixir
"this is a test" =~ ~r/test/
# => true

String.match?("Alice has 7 apples", ~r/\d{2}/)
# => false
```

### الالتقاط

إذا لم يكفِ فحص منطقي بسيط، فاستخدم الدالة `Regex.run/3` للحصول على قائمة بكل الالتقاطات (أو `nil` إذا لم تكن هناك مطابقة). العنصر الأول في القائمة المُرجَعة هو دائمًا مطابقة للتعبير النمطي كاملًا، والعناصر التالية هي مجموعات مطابِقة.

```elixir
Regex.run(~r/(\d) apples/, "Alice has 7 apples")
# => ["7 apples", "7"]
```

### المُعدِّلات

يمكن تعديل سلوك التعبير النمطي بإضافة أعلام خاصة. وعند استخدام سيجيل لإنشاء تعبير نمطي، أضف المُعدِّلات بعد المحدِّد الثاني.

من المُعدِّلات الشائعة:
- `i` - يجعل المطابقة غير حساسة لحالة الأحرف.
- `u` - يفعّل أنماط Unicode الخاصة مثل `\p` ويجعل أصناف المحارف مثل `\w` و`\s` وغيرها تطابق محارف Unicode أيضًا.

```elixir
"this is a TEST" =~ ~r/test/i
# => true
```
