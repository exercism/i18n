# الحلقات

يمكن استخدام الحلقات في Rust لتنفيذ كتلة من الكود بشكل متكرر حتى تطلب منها التوقف أو حتى يتحقق شرط معين.

أبسط صورة للحلقة تستخدم الكلمة المفتاحية `loop`:

```rust
fn main() {
    loop {
        println!("again!");
    }
}
```

مقطع الكود أعلاه يُنشئ حلقة لا نهائية. للخروج من الحلقة استخدم الكلمة المفتاحية `break`:

```rust
fn main() {
    let mut count = 0;
    loop {
        println!("again!");
        count += 1;
        if count > 10 { break; }
    }
}
```

## حلقات باستخدام `for` و `while`

بصرف النظر عن الكلمة المفتاحية `loop`، يمكنك أيضًا إنشاء حلقات باستخدام `for` و `while`.

تُستخدم حلقة `for` للمرور على عناصر مجموعة أو مُكرِّر.

```rust
fn main() {
    let a = [10, 20, 30, 40, 50];

    for x in a {
        println!("the value is: {x}");
    }
}
```

النطاقات مُكرِّرات أيضًا، وهذا ما يجعل المرور عليها بحلقة `for` مريحًا جدًا:

```rust
fn main() {
    for x in 0..10 {
        println!("the value is: {x}");
    }
}
```

تظل حلقة `while` تُكرِّر الكود حتى يتحقق شرط. يمكننا إعادة كتابة المثال السابق باستخدام حلقة `while` على النحو التالي:

```rust
fn main() {
    let a = [10, 20, 30, 40, 50];
    let mut index = 0;

    while index < 5 {
        println!("the value is: {}", a[index]);

        index += 1;
    }
}
```

راجع [https://doc.rust-lang.org/book/ch03-05-control-flow.html#repetition-with-loops](repetition with loops) في كتاب Rust لمزيد من المعلومات عن الحلقات.
