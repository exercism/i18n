# مفاهيم تواتر الحروف المتوازي

يزخر هذا التمرين بتشكيلة واسعة من الحلول الممكنة، مدعومة بالاستعانة بحزم خارجية. وللحفاظ على حجم العمل ضمن حدود معقولة، يضمّ هذا المستند مجموعة صغيرة مختارة من الاحتمالات. وتتشابه حلول Crossbeam في المفاهيم مع ما هو مذكور هنا، بينما لا يحتاج Rayon إلا إلى مجموعة فرعية منها.

## عام

- السلاسل النصية: تحديدًا، يبقى `str` عاملًا أساسيًا هنا دائمًا.
- يونيكود: تنازلات الأداء والمزايا بين طُرق ASCII وطُرق يونيكود. وتكون نتائج القياس مضلّلة عندما يستخدم القياس طُرق يونيكود ويستخدم الحل طُرق ASCII.
- المكرّرات: التكرار عبر المدخل أو عبر أجزاء منه.
- المجموعات: التكرار عبر `HashMap` واستخدام `Entry`. وغالبًا ما تُجمع المقابض في `Vec`.
- المراجع
- الأعداد: سمة `Add` تحديدًا
- حلقة `for`: لا يمكن ضمّ الخيوط في مكرّر بسبب `move`.
- **اختياري** الظهور: إبقاء تفاصيل التنفيذ غير عامة
- **اختياري** الشرائح: `.chunks()` طريقة كثيرة الاستخدام لتقسيم المدخل بين خيوط العمل. وبدلًا من ذلك تُستخدم شرائح فرعية.
- **اختياري** الدوال عالية الرتبة: يمكن دمج خرائط `HashMap` بواسطة دالة عالية الرتبة مع مكرّر.
- **اختياري** الأنواع: لتقسيم المدخل يمكننا تحويل الأعداد الصحيحة إلى قيم الفاصلة العائمة لتطبيق التقريب.
- **اختياري** الحزم

## نهج المكتبة القياسية مع القنوات أو بدونها

- التوازي: موضوع فرعي هو إنشاء الخيوط وضمّها.
- المكرّرات: موضوع فرعي هو التقييم الكسول: إنشاء الخيوط وضمّها باستخدام المكرّر نفسه يمنع التوازي.
- فترات الحياة: موضوعان فرعيان هما `'static lifetime` ودلالات `move` الصريحة.
- المكرّرات/فترات الحياة: موضوع فرعي هو المكرّرات المستهلكة: لا يمكن ضمّ الخيوط باستخدام المكرّر.
- نوع `Option`: فكّ تغليف نتائج الخيوط أو القنوات.
- الدوال: تحديدًا، الدوال عالية الرتبة مطلوبة لإنشاء الخيوط، والإغلاقات خيار وارد هنا.

## نهج المكتبة القياسية مع القنوات

- التوازي: موضوع فرعي هو القنوات.
- الصفوف: `mpsc::channel()` تُرجع صفًا.
- التفكيك: يمكن تفكيك الصف عند الإسناد.
- فترات الحياة: `drop()`

## نهج بديل بمتغيرات مشتركة

- عدّ المراجع: مشاركة البيانات المجمّعة بين الخيوط باستخدام مجموعة معدودة المراجع.
- **إشارة تستحق الذكر**: التوازي: موضوع فرعي هو أقفال `Mutex`. ليست ضرورية أو مفيدة لهذا التمرين، لكنها مع ذلك مفهوم شائع. وذات صلة: `RwLock`.

### مثال على المكتبة القياسية مع القنوات

```rust
use std::collections::HashMap;
use std::thread;
use std::sync::mpsc;

pub fn frequency(input: &[&str], worker_count: usize) -> HashMap<char, usize> {
    let (tx, rx) = mpsc::channel();

    let _handles = input.chunks((input.len() as f64 / worker_count as f64).ceil() as usize)
        .map(|slice| slice.concat())
        .map(|slice| {
            let tx = tx.clone();
            thread::spawn(move || {
                let mut map: HashMap<char, usize> = HashMap::new();
                for chr in slice.chars().filter(|c| c.is_alphabetic()) {
                    if let Some(c) = chr.to_lowercase().next() {
                        (*map.entry(c).or_insert(0)) += 1;
                    };
                }
                tx.send(map).unwrap()
            })
        }).collect::<Vec<_>>();

    drop(tx);

    let mut result: HashMap<char, usize> = HashMap::new();
    for received in rx {
        for (c, count) in received {
            *result.entry(c).or_insert(0) += count;
        }
    }

    result
}
```

### مثال على حزمة مع Arc

```rust
use std::collections::HashMap;
use std::iter::FromIterator;
use std::sync::Arc;
use dashmap::DashMap;

pub fn frequency(input: &[&str], worker_count: usize) -> HashMap<char, usize> {
    let map: Arc<DashMap<char, usize>> = Arc::new(DashMap::new());

    let handles = input
        .chunks((input.len() as f64 / worker_count as f64).ceil() as usize)
        .map(|slice| slice.concat())
        .map(|slice| {
            let map = map.clone();
            std::thread::spawn(move || {
                for c in slice.chars().filter(|c|c.is_alphabetic())
                  .flat_map(|c| c.to_lowercase().next()) {
                    *map.entry(c).or_insert(0) += 1;
                }
            })
        }).collect::<Vec<_>>();

    for h in handles {
        h.join().unwrap();
    }

    map.iter().map(|x| (*x.key(), *x.value())).collect()
}
```
