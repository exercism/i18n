# مقدمة

في JavaScript، تتيح لك _السلاسل النصية القالبية_ تضمين التعبيرات داخل السلاسل النصية، وهو ما يُعرف أيضًا بإقحام القيم في النص.
توسّع هذه الميزة إمكانات الكائن العام [`String`][string-reference] المدمج.

يمكنك إنشاء سلاسل نصية قالبية في JavaScript بتطويق النص بعلامات الاقتباس الخلفية.
فهي لا تسمح فقط بأن يتضمن النص أسطرًا جديدة ورموزًا خاصة أخرى، بل تتيح لك أيضًا تضمين المتغيرات وتعبيرات أخرى.

```javascript
const num1 = 1;
const num2 = 2;

`Adding ${num1} and ${num2} gives ${num1 + num2}.`;
// => Adding 1 and 2 gives 3.
```

في المثال أعلاه، تُستخدم علامات الاقتباس الخلفية، وهي (<code>\`\`</code>)، لتمثيل سلسلة نصية قالبية. و`${...}` هو العنصر النائب المستخدم للاستبدال.
تُحوَّل أي أنواع غير نصية إلى سلاسل نصية _ضمنيًا_.
يتناول هذا الموضوع مفهوم [تحويل الأنواع][type-conversion-concept].
ويمكن استخدام جميع أنواع التعبيرات مع السلاسل النصية القالبية.

```javascript
const track = 'JavaScript';

`This track on exercism.org is ${track.toUpperCase()}.`;
// => This track on exercism.org is JAVASCRIPT.
```

وعندما تحتاج إلى تنسيق السلاسل النصية على عدة أسطر:

```javascript
`This is an example of using template
strings to accomplish multiple
lines`;

/* => This is an example of using template
     strings to accomplish multiple
     lines
*/
```

إذا أردت تمثيل سطر جديد داخل سلسلة نصية عادية بدلًا من استخدام سلسلة نصية قالبية (أي دون استخدام علامات الاقتباس الخلفية)، فيمكنك استخدام تسلسل الهروب `\n` الخاص بالسطر الجديد:

```javascript
'This is an example of using the newline escape sequence!\nWithout backticks';

/* => This is an example of using the newline escape sequence!
      Without backticks
*/
```

وبفضل إمكانات الاستبدال المتاحة، يمكنك أيضًا إدخال منطق في العملية لتحديد ما ينبغي أن تكون عليه السلسلة النصية الناتجة.
ومن الأساليب المتاحة للتعامل مع هذا المنطق استخدام [العامل الثلاثي][ternary-operator].
فهو يقدّم الوظائف الشرطية نفسها التي يقدّمها `if/else`، لكن بصيغة مختلفة قليلًا.

ولتطبيق المنطق داخل صيغة السلسلة النصية القالبية:

```javascript
const grade = 95;

`You have ${grade > 90 ? 'passed' : 'failed'} the exam.`;
// => You have passed the exam.
```
