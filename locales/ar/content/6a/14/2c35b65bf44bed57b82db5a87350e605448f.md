# أساسيات `match`

يقارن عامل `match` قيمةً بمجموعة من الأنماط، ثم ينفّذ الكود بناءً على النمط الذي يطابقها.

## مطابقة القيم الحرفية

في أبسط صوره، يقارن `match` قيمةً بعدة احتمالات للمطابقة، ويختار أول فرع يطابقها. ولا يُختار إلا فرع واحد، ولا «يتدفق» التنفيذ أبدًا إلى فرع آخر. و`match` تعبير يمكن أن يُقيَّم إلى قيمة.

```rust
enum TrollNumber {
    One,
    Two,
    Many,
    Lots,
}

fn estimated_value(troll_number: TrollNumber) -> u32 {
    match troll_number {
        TrollNumber::One => 1,
        TrollNumber::Two => 2,
        TrollNumber::Many => 10,
        TrollNumber::Lots => 100,
    }
}
```

## الشمولية

المطابقة شاملة دائمًا: فلن يُصرّف Rust برنامجًا إذا أمكن أن تتسلل منه قيمة عبر الثغرات. وللمساعدة في ذلك، يُعد `_` نمط بدل يطابق أي شيء.

```rust
fn ordinal(n: u32) -> String {
    let ordinal = match n % 10 {
        1 => "st",
        2 => "nd",
        3 => "rd",
        _ => "th",
    };
    format!("{n}{ordinal}")
}
```

## المطابقة كتحكم في مسار التنفيذ

بينما يمكن استخدام `match` كتعبير لإنتاج قيمة، يمكن استخدام `match` أيضًا كعبارة لا لشيء إلا للتحكم في مسار التنفيذ.

```rust
// pretend that we've already filtered the key events relevant to the space bar (we don't want a keylogger)
fn space_timer(&mut self, event: Event) {
    match event {
        Event::KeyDown => self.timer = Some(Instant::now()),
        Event::KeyUp => {
            let duration = Instant::now() - self.timer.take().expect("can't have KeyUp without KeyDown");
            self.durations.push(duration);
        }
        // we don't care about any other events; the empty scope is a no-op
        _ => {}
    }
}
```

## مطابقة المدى

لا يلزم تحديد فروع المطابقة كقيم مفردة؛ إذ يمكن أن تكون مديات أيضًا.

```rust
fn ascii_type(ch: u8) -> &'static str {
    match ch {
        0..=31 => "non-printable control code",
        32..=126 => "printable character",
        127 => "DEL",
        _ => "extended ASCII; region-specific",
    }
}
```

## أنماط «أو»

يمكن لفرع المطابقة أن يطابق أحد عدة خيارات ممكنة، وذلك باستخدام الرمز `|` فاصلًا بينها.

```rust
fn should_retry(error: std::io::Error) -> bool {
    use std::io::ErrorKind;

    match error.kind() {
        ErrorKind::TimedOut | ErrorKind::Interrupted => true,
        _ => false,
    }
}
```

## المطابقة البنيوية والربط

يمكن للمطابقة أن تنتج ربطًا صالحًا داخل فرع مطابقة معيّن. وهذا مفيد بشكل خاص لفكّ أنواع `enum` التي تحمل بيانات في صيغها.

```rust
/// Consume a result and proceed, logging any errors.
trait OrLog {
    fn or_log(self);
}

impl<E: std::fmt::Display> OrLog for Result<(), E> {
    fn or_log(self) {
        match self {
            // discard Ok results
            Ok(()) => {},
            // log errors
            Err(err) => println!("ERROR: {err}"),
        }
    }
}
```

تجد المزيد حول هذا الموضوع في مفهوم `match-advanced`.
