# NuVoc

يُعدّ [NuVoc][nuvoc-link] المرجع النهائي للغة J. وهو نظرة عامة شديدة الإيجاز وكثيفة المعلومات على أوليات J واللغة.

# Rosetta Code

العديد من مهام Rosetta Code لها حلول بلغة `J`.
وهو مصدر جيد للعثور على برامج بلغة J لدراستها.
[هنا](https://rosettacode.org/wiki/Sudoku#J) حلّال سودوكو من تأليف Roger Hui.
