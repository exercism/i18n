# ملحق التعليمات

## التنفيذ

في الحزمة `twobucket`، نفّذ دالة `Solve` بلغة Go بالتوقيع التالي:

```go
func Solve(sizeBucketOne,
	sizeBucketTwo, goalAmount int, startBucket string,
) (goalBucket string, numSteps, otherBucketLevel int, e error)
```

تُرجع `Solve` أربع قيم: دلو الهدف الناتج ("one" أو "two")، وعدد الحركات/الخطوات اللازمة للوصول إلى الكمية المستهدفة، وعدد اللترات المتبقية في الدلو الآخر، وقيمة خطأ.
أرجِع خطأً عند وجود أي معامل غير صالح أو عند تعذّر إيجاد حل.
