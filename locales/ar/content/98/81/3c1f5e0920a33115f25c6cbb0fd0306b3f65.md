# ملحق التعليمات

## الكلمات

عرّف `custom-set` كصف، وأعلنه نسخة من مزيج `set` باستخدام `INSTANCE: custom-set set`.

- `<custom-set> ( -- set )`: لإنشاء مجموعة فارغة.
- `>custom-set ( seq -- set )`: لبناء مجموعة من تسلسل، مع إسقاط التكرارات بصمت.

ثم وفّر طُرق `M:` (من `sets`) للكلمات `members` و`in?` و`adjoin` و`set-like` من أجل `custom-set`. مع إعلان `INSTANCE:` وتلك الطُرق الأربع في مكانها، فإن `null?` و`union` و`intersect` و`diff` و`subset?` و`set=` و`intersects?` من مفردات `sets` تعمل كلها على مجموعتك عبر التنفيذات الافتراضية للبروتوكول، إذ تستدعي الاختبارات تلك الكلمات مباشرة.

`adjoin ( elt set -- )` عملية تعديلية: تضيف `elt` إلى `set` في مكانها إن لم يكن موجودًا بالفعل.
