# تلميحات

## 1. عرّف الموافقة

- يمكن تعريف الأنواع المخصصة باستخدام الصيغة `pub type Name { Variant1 }`.

## 4. عرّف النشاط

- يمكن تعريف الأنواع المخصصة التي تحتوي على بيانات باستخدام الصيغة `pub type Name { Variant1(SomeType) }`.

## 5. قيّم النشاط

- يمكن مطابقة بدائل الأنواع المخصصة باستخدام تعبيرات `case`.
- إذا أردت إضافة شرط إضافي إلى النمط، يمكنك إضافة حارس إلى النمط باستخدام الكلمة المفتاحية `if`.
