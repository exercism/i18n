# مقدمة

الهاش نوع بيانات في Perl يحتوي على مجموعة غير مرتبة من مفاتيح نصية مقترنة بقيم مفردة.

عادةً ما يُعبّأ متغير الهاش بإسناد مصفوفة إليه، مثل `my %scores = (Alice => 10, Bob => 15, Charlie => 20);`.

تُفصل عناصر المصفوفة عادةً بالفاصلات، لكنك سترى كثيرًا ما يُعرف بـ«الفاصلة السمينة» `=>` لفصل المفاتيح عن القيم في المصفوفة.
وسلوكها يكاد يكون مطابقًا لسلوك الفاصلة، لكن لها ميزة إضافية هي أنها تفسّر العنصر الواقع على الجانب الأيسر على أنه سلسلة نصية.

يمكن تعبئة الهاش بالإسناد إلى مفاتيح فردية، مثل `$scores{Alice} = 10;`.

يمكن الوصول إلى قيم الهاش بتحديد المفاتيح عبر رمز سفلي، مثل `$scores{Bob} # 15`.

المفاتيح في الهاش فريدة.
وإذا أُعطي المفتاح نفسه أكثر من مرة، فلن تُحفظ إلا آخر قيمة أُعطيت له.

## الدوال

تشمل دوال التعامل مع الهاشات [keys][keys] و[values][values]، اللتين تسترجعان كلًّا من هذين الجزأين من الهاش على هيئة مصفوفة.
والمصفوفات التي تُرجعها دالتا [keys][keys] و[values][values] قد تكون مفيدة مع دوال المصفوفات مثل [grep][grep] و[map][map] و[sort][sort]، وكذلك مع حلقات [for][for].

ومن دوال الهاش الأخرى [exists][exists]، للتحقق من وجود مفتاح في الهاش (حتى لو كانت قيمته `undef`)، و[delete][delete]، لإزالة مفتاح من الهاش.

## اختلاف العلامة

عند الحصول على قيم الهاش، تحدد العلامة المكتوبة النتيجة.
والرمز السفلي `{}` في نهاية اسم المتغير هو ما يخبر Perl بأنك تصل إلى هاش بهذا الاسم.

```perl
my %names = (Alice => 10, Bob => 15, Charlie => 20);

$names{Alice}; # 10            <- A scalar
@names{Alice}; # (10)          <- A slice (with only one key, this probably isn't what you want. There will be a warning.)
%names{Alice}; # ('Alice', 10) <- A key/index + value slice

$names{'Bob', 'Charlie'}; #                            <- An error (disabled syntax for an ancient feature.)
@names{'Bob', 'Charlie'}; # (15, 20)                   <- A slice
%names{'Bob', 'Charlie'}; # ('Bob', 15, 'Charlie', 20) <- A key/index + value slice
```

ومع أن ذلك مسموح، يُستحسن ألا تتشارك أنواع المتغيرات المختلفة الاسم نفسه، من أجل سهولة القراءة.
