# التعليمات

في هذا التمرين ستعمل على مُجدوِل مواعيد لصالون تجميل في نيويورك افتُتح في 15 سبتمبر 2012.

## 1. تحليل تاريخ الموعد

نفّذ طريقة `AppointmentScheduler.schedule()` لتحليل تمثيل نصي لتاريخ موعد وتحويله إلى كائن `LocalDateTime` المقابل:

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.schedule("7/25/2019 13:45:00");
// => LocalDateTime.of(2019, 7, 25, 13, 45, 0)
```

## 2. تحقق مما إذا كان الموعد قد مضى

نفّذ طريقة `AppointmentScheduler.hasPassed()` التي تأخذ تاريخ موعد وتتحقق مما إذا كان الموعد قد وقع في وقت ما في الماضي:

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.hasPassed(LocalDateTime.of(1999, 12, 31, 9, 0, 0));
// => true
```

## 3. تحقق مما إذا كان الموعد في فترة ما بعد الظهر

نفّذ طريقة `AppointmentScheduler.isAfternoonAppointment()` التي تأخذ تاريخ موعد وتتحقق مما إذا كان الموعد في فترة ما بعد الظهر (>= 12:00 و < 18:00):

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.isAfternoonAppointment(LocalDateTime.of(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. صف وقت الموعد وتاريخه

نفّذ طريقة `AppointmentScheduler.getDescription()` التي تأخذ تاريخ موعد وتُرجع وصفًا لذلك التاريخ والوقت:

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.getDescription(LocalDateTime.of(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on Friday, March 29, 2019, at 3:00 PM."
```

## 5. أرجع تاريخ الذكرى السنوية

نفّذ طريقة `AppointmentScheduler.getAnniversaryDate()` التي تُرجع تاريخ الذكرى السنوية لهذا العام، وهو 15 سبتمبر:

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.getAnniversaryDate()
// => LocalDate.of(<current year>, 9, 15)
```
