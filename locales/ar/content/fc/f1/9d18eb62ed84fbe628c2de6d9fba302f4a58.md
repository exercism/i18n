# التعليمات

كل روتين تؤدّيه فرقة الرقص مبنيّ على الإحماء نفسه، ثم يمضي في طريقه الخاص.

يمنحك الهيكل `WARM_UP`. اكتب ثلاثة أصناف أخرى تحته.

## 1. روتين الجاز

يأخذ `JAZZ_ROUTINE` كل شيء من `WARM_UP` دون تغيير، ولا يضيف شيئًا.

```sather
JAZZ_ROUTINE::counts
-- => 8
JAZZ_ROUTINE::describe
-- => "8 counts"
```

## 2. روتين النقر

يأخذ `TAP_ROUTINE` الخاصية `counts` من `WARM_UP` لكنه يصف نفسه بأسلوبه الخاص. اترك `describe` خارج include واكتب واحدًا جديدًا.

```sather
TAP_ROUTINE::counts
-- => 8
TAP_ROUTINE::describe
-- => "Tap: 8 counts"
```

## 3. الختام

يأخذ `FINALE` الخاصية `counts` من `WARM_UP` تحت اسم `warm_up_counts`، ويترك `describe` خارجًا. ثم تكون له الخاصية `counts` الخاصة به، وهي ضعف خاصية الإحماء، و`describe` الخاصة به.

```sather
FINALE::warm_up_counts
-- => 8
FINALE::counts
-- => 16
FINALE::describe
-- => "Finale: 16 counts"
```

لاحظ ما يوضّحه هذا: `FINALE::counts` ليست `WARM_UP::counts`، وكلتاهما متاحة تحت اسمين مختلفين في الصنف نفسه.
