# مقدمة

تُستخدم عبارة `guard` في Swift للإرجاع المبكر من دوال Swift عندما لا يتحقق شرط ضروري يجب توفره لاستمرار المعالجة، على سبيل المثال:

```swift
guard myValue >= 0 else { return 0 }
let root = myValue.squareRoot()
```

هنا تتحقق `guard` مما إذا كان التعبير المنطقي الذي يلي الكلمة المفتاحية `guard` يُقيَّم كقيمة صحيحة. إذا كان كذلك، تستمر المعالجة بالكود الذي يلي عبارة `guard` (هنا `let root = myValue.squareRoot()`). وإلا فستُنفَّذ الجملة الموجودة في `else`. وخلافًا للجملة الشرطية `if`، يجب أن تحتوي عبارة `guard` على جملة `else`، وخلافًا لجملة `else` في `if-else`، يجب أن تُخرج جملة `else` الخاصة بـ `guard` من نطاق عبارة `guard`. أي أنه يجب أن تستخدم عبارة نقل تحكم مثل `return` أو `continue` أو `break`، أو أن ترمي خطأ أو تُنهي البرنامج.
