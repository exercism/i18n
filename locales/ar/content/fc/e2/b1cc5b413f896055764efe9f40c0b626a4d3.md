# الخرائط والمجموعات

| النوع | يحتوي على | البحث بواسطة |
| --- | --- | --- |
| `ARRAY{T}` | قيم مرتبة | الموضع |
| `FMAP{K,T}` | أزواج مفتاح-هدف | المفتاح |
| `FSET{T}` | قيم بلا تكرار | العضوية |

## FMAP

```sather
   m ::= #FMAP{STR,INT};
   m := m.insert("emu", 2);
   m.get("emu")          -- 2
   m.has_ind("emu")      -- true
   m.size                -- 1
   m := m.delete("emu");
```

قراءة الخريطة لا تتم عبر `m["emu"]`، فـ`FMAP` لا يملك روتينًا كهذا، ولن يُصرَّف هذا السطر. الطريقة الصحيحة هي `get`.

### المفاتيح الغائبة

`get` على مفتاح غير موجود تُرجع القيمة الفارغة لذلك النوع بدلًا من أن تشكو: `0` أو `false` أو `void`. و`STR` بقيمة `void` لن تفشل عند إنتاجها، بل تفشل لاحقًا، حيثما استُخدمت أخيرًا. والبدء بـ`has_ind` عادةٌ تستحق أن تكتسبها.

## FSET

```sather
   s ::= #FSET{STR};
   s := s.insert("emu");
   s.has("emu")          -- true
   s.size                -- 1
   s := s.delete("emu");
```

تتحد المجموعات:

```sather
   a.union(b)            -- in either
   a.intersect(b)        -- in both
   a.difference(b)       -- in a but not b
   a.is_subset(b)
```

## إعادة الإسناد، والنسخ

`insert` و`delete` تُرجعان الحاوية التي ستُستخدم من الآن فصاعدًا. عادةً تكون هذه الحاوية الكائن نفسه، معدَّلًا في مكانه؛ وعندما يضطر إلى النمو، تكون كائنًا جديدًا أكبر. لذلك:

```sather
   m := m.insert(k, v);     -- always
```

والاسم الموجود على اليسار هو الوحيد الموثوق به بعد ذلك. وقد يصبح أي اسم آخر لنفس الخريطة، أُخذ قبل `insert`، قديمًا.

للاحتفاظ بنسخة مستقلة، خُذ نسخة أولًا:

```sather
   n ::= m.copy.insert(k, v);      -- m is unchanged
```

مع تحفّظ واحد: الخريطة التي لم يُدرَج فيها شيء قط تكون **`void`**، وتفشل `copy` على خريطة `void`. أما `insert` و`get` و`has_ind` و`size` فتتعامل جميعها مع خريطة `void` (`#FMAP{K,T}` قيمة `void`، والإدراج فيها هو ما يجعل الخريطة توجد لأول مرة)، لكن `copy` لا تفعل ذلك.

`HMAP` و`HSET` هما النسختان اللتان لا تتغيران إلا في مكانهما. إنهما أسرع لبناء شيء كبير، لكنهما الخيار الافتراضي غير المناسب أثناء التعلم.

## المرور عبره

| المكرِّر | ما يعطيه |
| --- | --- |
| `m.ind!` | كل مفتاح |
| `m.target!` | كل هدف |
| `m.pair!` | كل مفتاح وهدفه معًا |
| `s.elt!` | كل قيمة في المجموعة |

لا ترتيب لخريطة ولا لمجموعة. وقد يمر عليهما تشغيلان بترتيبين مختلفين، فلا تكتب أبدًا أي شيء يعتمد على أيّهما يأتي أولًا.

```sather
   loop
      #OUT + guide.ind! + "\n";
   end;
```
