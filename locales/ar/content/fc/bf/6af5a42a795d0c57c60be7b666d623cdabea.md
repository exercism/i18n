# Char

`Char` هو نوع بيانات في Crystal يمثل نقطة ترميز [يونيكود][unicode] بعرض 32 بت.
حجمها يجعلها موفّرة للذاكرة، ويمنحها خصائص معيّنة لا تملكها السلاسل النصية.
وتُنشأ باستخدام علامات التنصيص المفردة (`'`) وتسمح بوضع نقطة ترميز يونيكود واحدة فقط بداخلها.

```crystal
'a' # => 'a'
'a'.class # => Char
```

من الشائع جدًا التعامل مع قيم `Char` عند العمل مع السلاسل النصية في Crystal، لأن عددًا لا بأس به من الطرق في صنف `String` تُرجع قيم `Char` أو تأخذ قيم `Char` كوسائط.
فمثلًا، تُرجع الطريقة [`String#[]`][index] قيمة `Char`، كما تُرجع الطريقة [`String#chars`][chars] مجموعة من قيم `Char`.

## الزيادة والإنقاص

ولأن `Char` يمثل نقطة ترميز يونيكود بعرض 32 بت، فهو يدعم الزيادة والإنقاص، وهذا يعني أنه إذا كانت لديك القيمة `'a'` يمكنك الحصول على `'b'` بإضافة واحد إليها.

```crystal
'a' + 5
# => 'f'

'z' - 25
# => 'a'
```

توجد أيضًا طريقة تُسمى [`Char#succ`][succ] تُرجع المحرف التالي في جدول يونيكود، و[`Char#pred`][pred] تُرجع المحرف السابق في جدول يونيكود.

```crystal
'a'.succ
# => 'b'

'z'.pred
# => 'y'
```

## الدمج

ولأن `Char` مخصص فقط لتمثيل نقطة ترميز يونيكود بعرض 32 بت، فلا يمكن دمج محرفين معًا.
لذلك يمكن دمج `Char` مع السلاسل النصية فقط.

```Crystal
'a' + "bc"
# => "abc"

'a' + 'b'
# => error: expected argument #1 to 'Char#+' to be Int or String, not Char
```

## طرق الخصائص

يمتلك Crystal بعض الطرق للحصول على معلومات عن المحرف، مثل ما إذا كان عددًا أم حرفًا، أو ما إذا كان بحروف صغيرة أم كبيرة.
إليك قائمة ببعض هذه الطرق، وللاطلاع على القائمة الكاملة راجع [واجهة API الخاصة بـ `Char`][char-api]:

| الطريقة                          | الوصف                                                |
| -------------------------------- | ---------------------------------------------------- |
| [`Char#number?`][number]         | تُرجع `true` إذا كان المحرف عددًا                     |
| [`Char#letter?`][letter]         | تُرجع `true` إذا كان المحرف حرفًا                     |
| [`Char#lowercase?`][lowercase]   | تُرجع `true` إذا كان المحرف بحروف صغيرة               |
| [`Char#uppercase?`][uppercase]   | تُرجع `true` إذا كان المحرف بحروف كبيرة               |
| [`Char#ascii?`][ascii]           | تُرجع `true` إذا كان المحرف محرف ASCII               |
| [`Char#whitespace?`][whitespace] | تُرجع `true` إذا كان المحرف مسافة بيضاء              |

## التحويل

### التحويل بين نقاط الترميز وقيم `Char`

ولأن `Char` يمثل نقطة ترميز يونيكود بعرض 32 بت، يمكنك التحويل بين قيم `Char` ونقاط الترميز (من النوع `Int`).
يمكن القيام بذلك باستخدام الطريقة [`Char#ord`][ord] التي تُرجع نقطة ترميز المحرف، أو الطريقة [`Int#chr`][chr] التي تُرجع المحرف المقابل لنقطة الترميز.

```crystal
'a'.ord
# => 97

97.chr
# => 'a'
```

### التحويل بين الأنواع

وكما هو الحال مع أنواع البيانات الأخرى، يمتلك `Char` بعض الطرق للتحويل بين الأنواع.
أكثرها شيوعًا هي الطريقة `Char#to_s` التي تحوّل المحرف إلى سلسلة نصية. غير أن هناك أيضًا الطريقة `Char#to_i` التي تحوّل المحرف إلى عدد صحيح، والطريقة `Char#to_f` التي تحوّل المحرف إلى عدد عشري.

```crystal
'a'.to_s
# => "a"

'4'.to_i
# => 4

'a'.to_i
# => Error: Invalid integer: a (ArgumentError)
```
