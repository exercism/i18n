# حول

[Groovy](http://www.groovy-lang.org/) هي لغة ديناميكية قوية من مؤسسة Apache، يمكن كتابتها بأنماط اختيارية، وتتضمّن أيضًا قدرات التنميط الساكن والترجمة الساكنة.

تهدف Groovy إلى تحسين إنتاجية المطوّرين بفضل صياغة موجزة وسهلة التعلّم.
وهي تسهّل البرمجة النصية، وتأليف اللغات الخاصة بمجال معيّن، والبرمجة الفوقية وقت التشغيل ووقت الترجمة، والبرمجة الوظيفية.

وتتيح الوصول إلى منظومة مكتبات Java بأكملها، وتتكامل بسلاسة مع تطبيقات Java.

ويمكن استخدامها كلغة برمجة نصية بسيطة، أو إضافتها إلى أطر عمل Java المعقّدة.
وهي المحرّك وراء تقنيات مثل:
* Gradle،
* Spock،
* Ratpack،
* Grails،
* والبرمجة النصية في Jenkins.

وفوق ذلك، فهي ممتعة.
