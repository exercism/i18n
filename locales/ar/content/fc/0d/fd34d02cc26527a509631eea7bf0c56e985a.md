# المحارف

**المحرف** هو حرف واحد أو رقم واحد أو مسافة أو علامة. النوع المخصص لمحرف واحد في Sather هو `CHAR`، ويُكتب المحرف بين علامتي اقتباس مفردتين.

```sather
   initial : CHAR is
      return 'M';
   end;
```

علامتان مفردتان لمحرف واحد، وعلامتان مزدوجتان لسلسلة نصية. `'M'` و`"M"` نوعان مختلفان ولا يمكن تبديل أحدهما بالآخر.

## المحارف داخل السلسلة النصية

السلسلة النصية صف من المحارف، والأقواس المربعة تصل إلى محرف منها حسب موضعه، بدءًا من الصفر، تمامًا كما في المصفوفة.

```sather
"Marlowe"[0]      -- 'M'
"Marlowe"[3]      -- 'l'
```

## السؤال عن محرف

| الاستدعاء | الإجابة |
| --- | --- |
| `c.is_alpha` | هل هو حرف؟ |
| `c.is_digit` | هل هو أحد الأرقام من `0` إلى `9`؟ |
| `c.is_upper` | هل هو حرف كبير؟ |
| `c.is_lower` | هل هو حرف صغير؟ |

كل استدعاء منها يُرجع `true` أو `false`.

```sather
'M'.is_alpha      -- true
'7'.is_alpha      -- false
'7'.is_digit      -- true
```

## تغيير حالة الأحرف

تُرجع `.upper` الحرف الكبير من الحرف، وتُرجع `.lower` الحرف الصغير. وأي شيء ليس حرفًا يُرجع كما هو دون تغيير.

```sather
'm'.upper         -- 'M'
'M'.lower         -- 'm'
'7'.upper         -- '7'
```

## المحارف كأعداد

لكل محرف عدد. تُرجع `.int` ذلك العدد، وتُحوّل `.char` عددًا إلى محرف مرة أخرى.

```sather
'a'.int           -- 97
'b'.int           -- 98
98.char           -- 'b'
```

الأعداد الدقيقة نادرًا ما تهم. المهم أن الحروف من `a` إلى `z` مرتّبة ومتجاورة، لذا فإن `'c'.int - 'a'.int` يساوي 2، أي مقدار بُعد `c` عن بداية الأبجدية. وهذا ما يجعل عجلة التشفير تعمل.
