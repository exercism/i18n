# مقدمة

إلى جانب مجموعات المحارف والمكممات، تستطيع التعبيرات النمطية أن تصف *البنية* و*السياق*. توجد هذه الميزات في المفردات نفسها `regexp` وفي الصيغة الحرفية نفسها `R/ /`.

تجمع الأقواس الهلالية `( )` جزءًا من النمط حتى ينطبق المكمم أو الرمز `|` ("هذا أو ذاك") على المجموعة كاملة؛ وإضافة `?` بعد مجموعة تجعلها اختيارية:

```factor
USING: regexp ;

"abab"    R/ (ab)+/ matches? .             ! => t
"$100"    R/ \$\d+(\.\d{2})?/ matches? .   ! => t   (optional group)
```

تثبّت المراسي النمط في موضع معيّن: `^` (البداية)، و`$` (النهاية)، و`\b` (حدّ الكلمة).

تُطابق ميزة *النظر حول الموقع* بحسب ما يحيط بالموضع دون أن تستهلكه:

```
(?=...)    ! lookahead — ... must follow
(?!...)    ! negative lookahead — ... must not follow
(?<=...)   ! lookbehind — ... must come before
```

```factor
USING: regexp ;

"spent $100 and $25" R/ (?<=\$)\d+/ all-matching-subseqs .
! => { "100" "25" }

"up 5% then 12%" R/ \d+(?=%)/ all-matching-subseqs .
! => { "5" "12" }
```

يغيّر حرف الخيار الذي يأتي بعد `/` الختامي النمط بأكمله؛ و`i` يجعل المطابقة غير حساسة لحالة الأحرف:

```factor
USING: regexp ;

"REFUND" R/ refund/i matches? .   ! => t
```

يستخدم Factor ميزة النظر حول الموقع بدلًا من مجموعات الالتقاط: فهو لا يملك استخراج مجموعات الالتقاط، ولا الإحالات الخلفية، ولا المكممات الكسولة.
