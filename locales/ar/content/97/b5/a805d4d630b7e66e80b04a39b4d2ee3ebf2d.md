# مقدمة

## الأعداد ذات الفاصلة العائمة

العدد ذو الفاصلة العائمة هو عدد يحتوي على صفر أو أكثر من الأرقام بعد الفاصلة العشرية. أمثلة على ذلك: `-2.4`، `0.1`، `3.14`، `16.984025` و `1024.0`.

يمكن لأنواع مختلفة من الأعداد ذات الفاصلة العائمة تخزين أعداد مختلفة من الأرقام بعد الفاصلة العشرية، ويُشار إلى ذلك باسم الدقة.

تحتوي C# على ثلاثة أنواع من الأعداد ذات الفاصلة العائمة:

- `float`: 4 بايت (دقة تبلغ نحو 6-9 أرقام). يُكتب على الصورة `2.45f`.
- `double`: 8 بايت (دقة تبلغ نحو 15-17 رقمًا). هذا هو النوع الأكثر شيوعًا. يُكتب على الصورة `2.45` أو `2.45d`.
- `decimal`: 16 بايت (دقة تبلغ نحو 28-29 رقمًا). يُستخدم عادةً عند التعامل مع البيانات النقدية، لأن دقته تقلل من احتمال حدوث أخطاء التقريب. يُكتب على الصورة `2.45m`.

كما ترى، يمكن لكل نوع تخزين عدد مختلف من الأرقام. على سبيل المثال، عند محاولة تخزين باي في `float`، لن يُخزَّن سوى أول 6 منازل عشرية (مع تقريب آخر رقم مخزَّن).

## حلقات `while`

في هذا التمرين قد ترغب في استخدام حلقة. هناك عدة أساليب لكتابة الحلقات في C#، لكن حلقة `while` هي الأنسب هنا:

```csharp
int x = 23;

while (x > 10)
{
    // Execute logic if x > 10
    x = x - 2;
}
```

## حلقات `do`/`while`

إذا كان يجب تنفيذ الكود داخل الحلقة مرة واحدة على الأقل، فيمكن استخدام حلقة `do`/`while`:

```csharp
int x = 23;

do
{
    // Execute body, repeating only if x > 10
    x = x - 2;
} while (x > 10);
```
