# التعليمات

في هذا التمرين ستُنظّم سباقات بين أنواع مختلفة من السيارات التي تُتحكَّم عن بُعد.
لكل سيارة سرعتها وخصائص استهلاكها للبطارية الخاصة بها.

تبدأ السيارات ببطارية ممتلئة (100%). وفي كل مرة تقود فيها السيارة باستخدام وحدة التحكم عن بُعد، تقطع مسافة تساوي سرعة السيارة بالأمتار، وتنقص نسبة البطارية المتبقية بمقدار استهلاكها للبطارية.

إذا انخفضت بطارية السيارة عن نسبة استهلاكها للبطارية، فلن تتمكن من قيادتها بعد ذلك.

لكل مضمار سباق طوله الخاص. وتُختبر السيارات بالتحقق مما إذا كانت قادرة على إكمال المضمار دون أن تنفد بطاريتها.

## 1. أنشئ سيارة تُتحكَّم عن بُعد

عرّف قائمة `car` بالعناصر التالية:

- speed
- battery_drain
- battery
- distance_traveled

يمكنك إنشاء سيارة تُتحكَّم عن بُعد بتعريف دالة `new_car` تأخذ سرعة السيارة بالأمتار ونسبة استهلاك البطارية كمعاملين لها، وتُرجع قائمة `car`.

في السيارة الجديدة تكون البطارية عند 100% وتكون المسافة المقطوعة صفرًا.

```R
speed <- 5
battery_drain <- 2
car <- new_car(speed, battery_drain)
str(car)
#> List of 4
#>  $ speed             : num 5
#>  $ battery_drain     : num 2
#>  $ battery           : num 100
#>  $ distance_traveled : num 0
```

## 2. أنشئ مضمار سباق

عرّف قائمة أخرى تُسمى `track` بعنصر واحد هو `track_length`.
يمكنك إنشاء مضمار سباق بتعريف دالة `new_track` تأخذ مسافة المضمار بالأمتار:

```R
track_length <- 800
track <- new_track(track_length)
str(track)
#> List of 1
#>  $ track_length: num 800
```

## 3. تحقق من نفاد البطارية

نفّذ الدالة `battery_drained()` التي تشير إلى ما إذا كانت البطارية قد نفدت.
تُعتبر البطارية منفدة إذا لم يتبقَّ فيها ما يكفي للتحرك مرة أخرى.

```R
speed <- 5;
battery_drain <- 2;
car <- new_car(speed, battery_drain);
car <- drive(car);

battery_drained(car);
#> [1] FALSE
```

## 4. قُد السيارة

نفّذ الدالة `drive` التي تحدّث عدد الأمتار المقطوعة بناءً على سرعة السيارة، وتنقص البطارية وفقًا لاستهلاكها للبطارية.
وإذا لم تكن البطارية كافية للتحرك مرة أخرى، فلن تتحرك السيارة.

```R
speed <- 5
battery_drain <- 2
car <- new_car(speed, battery_drain)
car <- drive(car)
str(car)
#> List of 4
#>  $ speed             : num 5
#>  $ battery_drain     : num 2
#>  $ battery           : num 98
#>  $ distance_traveled : num 5
```

## 5. تحقق مما إذا كانت سيارة تُتحكَّم عن بُعد قادرة على إكمال السباق

لكي تُكمل السيارة سباقًا، يجب أن تكون قادرة على قطع مسافة السباق كاملة. وهذا يعني ألا تنفد بطاريتها قبل أن تعبر خط النهاية.

نفّذ الدالة `can_finish` التي تأخذ `car` و`track` كمعامل لها، وتُرجع `TRUE` إذا كانت السيارة قادرة على إكمال السباق، وإلا فتُرجع `FALSE`.

افترض أنك الآن عند خط بداية السباق وأنك تشغّل محرك السيارة للسباق. وضع في اعتبارك أن بطارية السيارة قد لا تكون مشحونة بالكامل عند بدء السباق.

```R
speed <- 5
battery_drain <- 5
car <- new_car(speed, battery_drain)

name <- "track1"
track_length <- 100
track <- new_track(track_length)

can_finish(car, track)
#> [1] TRUE

# partial battery charge
car$battery <- 50
can_finish(car, track)
#> [1] FALSE
```

## 6. احفظ ما إذا كانت السيارة قادرة على إكمال مضمار ببطارية ممتلئة

لقد أنشأت عدة مضامير بأطوال مختلفة، وتحتاج إلى حفظ ما إذا كانت سيارتك قادرة على إكمالها إذا كانت مشحونة بالكامل.

نفّذ الدالة `store_track` التي تأخذ سيارة ومضمارًا واسم مضمار، وتُرجع سيارة محدَّثة بعنصر إضافي.
يجب أن يحمل هذا العنصر `name` المضمار، وأن تكون قيمته قائمة فرعية تضم `track_length` وقيمة `complete` التي تبين ما إذا كانت السيارة قادرة على إكمال المضمار.

قد لا تكون السيارة المُمرَّرة في الوسيط مشحونة بالكامل، لذا تأكد من إعادة ضبط البطارية والمسافة المقطوعة قبل استخدامها.

```R
speed <- 5
battery_drain <- 5
car <- new_car(speed, battery_drain)
car$battery <- 50

name <- "track1"
track_length <- 100
track <- new_track(track_length)

track1 <- store_track(car, track, "Imola")
str(track1)
#> List of 5
#>  $ speed             : num 5
#>  $ battery_drain     : num 5
#>  $ battery           : num 100
#>  $ distance_traveled : num 0
#>  $ Imola             :List of 2
#>   ..$ track_length: num 100
#>   ..$ complete    : logi TRUE
```
