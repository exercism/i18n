# نبذة

يمثّل Gleam القيمتين صحيح وخطأ بالنوع `Bool`. لا توجد سوى قيمتين: `True` و`False`. ويمكن إسناد هاتين القيمتين إلى متغير:

```gleam
let true_variable = True
let false_variable = False
```

يمكن استخدام العوامل `&&` و`||` و`!` للتعامل مع القيم المنطقية:

```gleam
True && True  // -> True
True && False // -> False

False || True  // -> True
False || False // -> False

!False // -> True
!True  // -> False
```

يستخدمان العاملان `&&` و`||` التقييم المختصر، وهذا يعني أن التعبير على الجانب الأيمن من العامل لا يُقيَّم إلا عند الحاجة.

ولكل من هذه العوامل أسبقية مختلفة، حيث يُقيَّم `!` قبل `&&` و`||`. ويمكن استخدام الأقواس المعقوفة لتقييم جزء من التعبير قبل الأجزاء الأخرى:

```gleam
!True && False   // -> False
!{True && False} // -> True
```
