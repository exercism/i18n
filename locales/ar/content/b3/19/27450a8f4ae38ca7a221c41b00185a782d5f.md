# حلقات `for`

التكرار مفهوم أساسي في البرمجة، فهو يتيح لك تنفيذ كتلة من الكود عدة مرات.
في Swift، هناك نوعان من الحلقات: حلقات [`for-in`][for-loops] وحلقات `while`.
في هذا الفصل، ستتعلم حلقات `for-in`.

تتيح لك حلقات `for` المرور على تسلسل من القيم، آخذةً كل عنصر بالترتيب وربطه بمتغير تختاره.
يتيح لك Swift المرور على مجموعة متنوعة من التسلسلات، مثل المديات والمصفوفات والسلاسل النصية (وأنواع أخرى سنغطيها لاحقًا).
وعندما يُمرّ على كل عنصر في التسلسل، تنتهي الحلقة.

تُعرَّف حلقات `for` باستخدام الكلمة المفتاحية `for`، متبوعة باسم متغير، ثم الكلمة المفتاحية `in`، ثم تسلسل من القيم المراد المرور عليها.
المتغير المعطى في حلقة `for-in` غير قابل للتغيير، أي أنه لا يمكنك تغيير قيمته داخل الحلقة.
إليك مثالًا على حلقة `for-in` تمر على مصفوفة من الأعداد:

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
  print(number)
}
print("Done with numbers")

// prints:
// 3
// 10
// 7
// 11
// Done with numbers
```

~~~~exercism/note
يُعرَّف المتغير `number` داخل حلقة `for-in`، ولا يكون متاحًا إلا ضمن نطاق الحلقة.

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
    number + 1
}
number + 1
// Error: Use of unresolved identifier 'number'
```
~~~~

## المرور على مدى

يمكنك أيضًا المرور على مدى من الأعداد باستخدام حلقة `for-in`.
يتيح لك ذلك تنفيذ كتلة من الكود عددًا محددًا من المرات؛ فعلى سبيل المثال، يمر المدى `1...5` على الأعداد 1 و2 و3 و4 و5، لذا ستنفَّذ الحلقة 5 مرات.
وأحيانًا قد ترغب في المرور على الفهارس في بنية بيانات مثل مصفوفة، وحينها يمكنك استخدام المدى `0..<array.count`.

```swift
let numbers = [3, 10, 7, 11]

for i in 0..<numbers.count {
  print(numbers[i])
}

// prints:
// 3
// 10
// 7
// 11
```

## المرور على سلسلة نصية

يمكنك أيضًا المرور على سلسلة نصية باستخدام حلقة `for-in`.
يتيح لك ذلك المرور على كل حرف في السلسلة النصية، ولاحظ تحديدًا أن النوع المعطى في الحلقة هو `Character`.

```swift
let message = "Hello!"

for character in message {
  print(character)
}

// prints:
// H
// e
// l
// l
// o
// !
```

## `stride`

يوفّر Swift أيضًا دالة `stride` تتيح لك إنشاء تسلسل على مدى بخطوة محددة.
ويمكن بعد ذلك المرور عليه باستخدام حلقة `for-in`.
تُعرَّف `stride` بالصيغتين [`stride(from:to:by:)`][stride-to] أو [`stride(from:through:by:)`][stride-through]، الأولى حصرية والثانية شاملة.

```swift
for i in stride(from: 0, to: 10, by: 2) {
  print(i)
}

// prints:
// 0
// 2
// 4
// 6
// 8
```

لاحظ أن المعامل `to` حصري، لذا ستمر الحلقة حتى العدد الذي يسبق المعامل `to`، أما المعامل `through` فشامل، لذا فإنه في هذه الحالة سيشمل العدد `10` أيضًا.

[stride-to]: https://developer.apple.com/documentation/swift/stride(from:to:by:)
[stride-through]: https://developer.apple.com/documentation/swift/stride(from:through:by:)
[for-loops]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
