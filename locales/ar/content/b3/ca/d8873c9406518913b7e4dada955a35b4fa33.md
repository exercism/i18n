# مقدمة

في Common Lisp كما في لغات أخرى، المصفوفة هي مجموعة من العناصر يتم الوصول إليها عبر فهارس صحيحة.
يمكن أن تكون أنواع العناصر غير متجانسة.
يمكن أن تكون المصفوفة متعددة الأبعاد (وليست أحادية البعد فقط).

## الإنشاء

`make-array` تتيح إنشاء المصفوفات.
لها العديد من الخيارات، لكن أبسط صورها تتيح إنشاء مصفوفات ذات N من الأبعاد مع تهيئة جميع العناصر إلى قيمة واحدة، أو تهيئة المصفوفة إلى القيم الموجودة في متتالية أخرى (مثل قائمة).
وسيطها الأول قائمة بأحجام كل بعد.

```lisp
(make-array '(4) :initial-element 3)    ; => #(3 3 3 3)
(make-array '(2 2) :initial-element 'x) ; => #2A((X X) (X X))
```

(لاحظ كيف تُطبع المصفوفات ذات N من الأبعاد مع عدد الأبعاد.)

يمكن أيضًا إنشاء المصفوفات باستخدام نفس التنسيق الذي تُطبع به:

```lisp
#(x y z)         ; => #(X Y Z)
#2A((1 2) (3 4)) ; => #2A((1 2) (3 4))
```

## الوصول إلى العناصر

للوصول إلى عناصر متجه، استخدم `aref`، الفهارس تبدأ من الصفر.
يجب أن يتطابق عدد الفهارس المقدمة مع رتبة المصفوفة.

```lisp
(aref #2A((1 2 3) (3 4 5)) 
       1 0)           ; => 3
(aref #3A(((a b) (c d)) 
           ((e f) (g h)) 
           ((t u) (v w))) 
       2 0 1)         ; => U
(aref #2A((1) (2)) 0) ; => ERROR (because not enough indexes provided)
```
