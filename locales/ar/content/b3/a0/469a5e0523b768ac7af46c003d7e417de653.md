# مقدمة

*الكومة* مجموعة تعرف دائمًا أصغر عنصر فيها، وتتيح لك إخراج ذلك العنصر سريعًا. إنها الأداة الطبيعية *لطابور الأولوية*: صف انتظار يُخدَم فيه العنصر الأهم تاليًا، لا العنصر الذي انتظر أطول مدة. توجد الأكوام في مفردات [`heaps`][heaps].

## بناء كومة

`<min-heap>` يبني كومة فارغة يخرج منها *أصغر* مفتاح أولًا، و`<max-heap>` صورتها المرآتية.

```
<min-heap> ( -- min-heap )
<max-heap> ( -- max-heap )
```

## إضافة عناصر

يُخزَّن كل عنصر كـ*قيمة* إلى جانب *مفتاح*، والمفتاح هو الأولوية التي يرتّب Factor وفقها. وتضيف `heap-push` عنصرًا واحدًا:

```
heap-push ( value key heap -- )
```

```factor
USING: heaps ;

<min-heap>
"alice" 5 pick heap-push   ! value "alice", priority 5
"bob"   2 pick heap-push   ! value "bob",   priority 2
```

الكومة *قابلة للتغيير*: `heap-push` تغيّرها في مكانها بدل أن تُرجع كومة جديدة. و`keep` مفيدة لاستعادة الكومة إلى المكدس بعد أن تستهلكها `heap-push`.

## النظر إلى المقدمة وإزالتها

تُرجع `heap-peek` العنصر الأمامي، أي القيمة ذات أصغر مفتاح، *دون* إزالته. وتُرجع `heap-pop` ذلك العنصر *وتزيله*. وتُخبرك `heap-empty?` هل بقي شيء، لتعرف متى تتوقف عن سحب العناصر. وتزيل `heap-pop-all` كل شيء دفعة واحدة، فتُرجع قائمة اقتران من أزواج `{ key value }` بترتيب الأولوية.

```
heap-peek    ( heap -- value key )
heap-pop     ( heap -- value key )
heap-empty?  ( heap -- ? )
heap-pop-all ( heap -- alist )
```

```factor
USING: assocs heaps kernel prettyprint ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
dup heap-empty? .        ! => f      (two items waiting)
dup heap-peek drop .     ! => "bob"  (smallest key, still in the heap)
dup heap-pop drop .      ! => "bob"  (smallest key, now removed)
heap-pop-all .           ! => { { 5 "alice" } }
```

`heap-pop` و`heap-empty?` هما حجر الأساس لخدمة العناصر واحدًا واحدًا: انظر إلى المقدمة أو اسحبها، واعمل عليها، ثم توقف بمجرد أن تُرجع `heap-empty?` القيمة `t`. تستخدم المهام أدناه `heap-pop-all` لتفريغ الطابور كله في خطوة واحدة، لكن الترتيب نفسه ينتج عن السحب حتى تفرغ الكومة.

الأزواج التي تُرجعها `heap-pop-all` هي *قائمة اقتران*: `values` (في `assocs`) تُبقي القيم فقط وتُسقط المفاتيح.
