# حول

يرتبط نطاق القيمة بالمكان الذي يمكن فيه الوصول إلى تلك القيمة داخل البرنامج.

## أنواع النطاقات الأربعة: الكتلة؛ الدالة؛ نموذج الدالة؛ الملف

### نطاق الكتلة

لا يمكن الوصول إلى قيمة ذات نطاق كتلة إلا من داخل الكتلة التي عُرّفت فيها. لمزيد من المعلومات حول الكتل، راجع [مفهوم الكتل](../blocks/introduction.md#Introduction).

### نطاق الدالة

نطاق الدالة نوع خاص من النطاق ينطبق على التسميات المستخدمة مع عبارات `goto`. لا يمكن استخدام تسميتين بالاسم نفسه في الدالة نفسها، حتى لو كانت التسميتان معرّفتين في كتل منفصلة داخل الدالة.

### نطاق نموذج الدالة

نطاق نموذج الدالة نوع خاص آخر من النطاق ينطبق فقط على المعاملات المُسمّاة داخل النموذج (ويُشار إليه أيضًا بالتصريح، مع الأخذ في الاعتبار أن ليست كل التصريحات نماذج). عادةً ما يكون اسم المعامل اختياريًا في تصريح الدالة، ولا يكون نطاق الاسم ذا أهمية إلا داخل التصريح. في المثال التالي يُعرَّف المُعرّف `len` ثم يُشار إليه لاحقًا في تصريح الدالة.

```c
#include <stdio.h>

// len is defined and then referred to
void my_func(int len, int numbers[len]);

int main() {
    int numbers[2];
    numbers[0] = 1;
    numbers[1] = 2;
    my_func(2, numbers);
}

void my_func(int length, int numbers[length]) {
    // prints numbers should have 2 elements
    printf("numbers should have %d elements", length);
}
```

لاحظ أن الأسماء داخل التصريح يجب أن تتوافق عند الإشارة إلى المتغير نفسه. فإذا صُرّح عن `my_func` بالشكل `void my_func(int len, int numbers[length]);` فسيُنشأ خطأ في التصريف شبيه بهذا

```
/tmp/scn62kKPEZ.c:4:35: error: 'length' undeclared here (not in a function)
    3 | void my_func(int len, int numbers[length]);
      |                                   ^~~~~~
/tmp/scn62kKPEZ.c: In function 'main':
/tmp/scn62kKPEZ.c:10:16: error: type of formal parameter 2 is incomplete
   10 |     my_func(2, numbers);
```

لا يلزم أن يستخدم تعريف الدالة اسم المعامل نفسه الذي استُخدم في تصريح الدالة. في المثال أعلاه، استُخدم `len` في التصريح واستُخدم `length` في التعريف، ما يوضّح أن نطاق المُعرّف `len` كان داخل تصريح الدالة فقط.

### نطاق الملف

يمكن الوصول إلى قيمة ذات نطاق ملف من أي مكان في الملف. وكل قيمة من هذا القبيل تُعرَّف خارج دالة.
