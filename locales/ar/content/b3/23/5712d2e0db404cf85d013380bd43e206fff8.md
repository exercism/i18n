# مقدمة

## المساواة

يمكن التحقق من أنواع Elm من حيث "كونها متماثلة" باستخدام عامل المساواة `(==)`.
وعامل عدم المساواة هو `(/=)` (*وليس* `!=` كما في كثير من اللغات).
يعمل عامل المساواة على القيم الحرفية والأزواج والسجلات والأنواع المخصصة.

```elm
1 == 2
    --> False

1 /= 2
    --> True

(1, 2) == (2, 1)
    --> False

type alias MyRecord = { myInt : Int, myStrings : List String }
a : MyRecord
a = MyRecord (1 + 1) ["hello world"]

type alias MyOtherRecord = { myInt : Int, myStrings : List String }
myStrings =  (String.join " " ["hello", "world"]) :: []
b : MyOtherRecord
b = { myInt = 2, myStrings = myStrings}

a == b
    --> True
```

لاحظ أنه *يجب ألا* تقارن الدوال أبدًا، لأن ذلك سيجعل البرنامج يتعطّل أثناء التشغيل.

## المقارنات

تعمل عوامل المقارنة `(<)` و`(<=)` و`(>)` و`(>=)` والدوال `min` و`max` و`compare` على الأنواع القابلة للمقارنة `comparable`.
النوع `comparable` هو نوع خاص يجمع كل الأنواع المدمجة التي يمكن مقارنتها: الأعداد والمحارف والسلاسل النصية والمصفوفات المكوّنة من أشياء قابلة للمقارنة والأزواج المكوّنة من أشياء قابلة للمقارنة.

```elm
1 < 1 + 1
    --> True

'x' < 'X'
    --> False

"abc" < "abz"
    --> True

"abc" < "abcd"
    --> True

"abc" < "b"
    --> True

min [1 , 2, 9000] [10]
    --> [1 , 2, 9000]

min (1, "hello") (3, "bye")
    --> (1, "hello")
```

لا يمكن مقارنة قيم أنواع أخرى مثل السجلات أو الأنواع المخصصة مباشرةً.

بعض الأنواع المدمجة، مثل `Set` أو مفاتيح `Dict`، تتطلب أن يكون محتواها من النوع `comparable`، لأن بنيتها تعتمد على ترتيب داخلي.

يمكن ترتيب مصفوفات القيم القابلة للمقارنة باستخدام `List.sort`، ويمكن ترتيب مصفوفات القيم التي يمكن تحويلها إلى قيم قابلة للمقارنة باستخدام `List.sortBy`.
وإذا احتجت إلى ترتيب هرمي (الترتيب حسب خاصية واحدة، ثم حسم التعادل بخاصية أخرى)، فيمكنك أيضًا استخدام الأزواج أو المصفوفات مع `List.sortBy`، لأن الأزواج والمصفوفات تُرتَّب ترتيبًا معجميًا.


```elm
List.sort ["hi", "hello", "bye", "goodbye"]
    --> ["bye", "goodbye", "hello", "hi"]

List.sortBy String.length ["hi", "hello", "bye", "goodbye"]
    --> ["hi", "bye", "hello", "goodbye"]

-- sort by length, then alphabetically
List.sortBy (\str -> (String.length str, str)) ["hi", "mum", "hello", "sis", "bye", "dad"]
    --> ["hi", "bye", "dad", "mum", "sis", "hello"]
```

تأخذ الدالة `compare` قيمتين من النوع `comparable` وتُرجع `Order`.
و`Order` نوع يتحقق في عملية واحدة مما إذا كانت قيمة ما أكبر (`GT`) أو مساوية (`EQ`) أو أصغر (`LT`) من أخرى.

```elm
compare 1 2
    --> LT

compare "" ""
    --> EQ

compare [12] []
    --> GT
```

يمكن إنشاء دوال مقارنة لأنواع اعتباطية، ويمكن استخدامها، على سبيل المثال، لترتيبها باستخدام `List.sortWith`:

```elm
type Color = Red | Green | Blue

compareColors : Color -> Color -> Order
compareColors a b =
  case (a, b) of
    (Red, Red) -> EQ
    (Red, _) -> LT
    (_, Red) -> GT
    (Green, Green) -> EQ
    (Green, _) -> LT
    (_, Green) -> GT
    (Blue, Blue) -> EQ

List.sortWith compareColors [Blue, Red, Green, Green, Blue]
    --> [Red, Green, Green, Blue, Blue]
```
