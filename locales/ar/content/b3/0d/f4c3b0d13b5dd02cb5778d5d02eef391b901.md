# حلقات `while` و `until`

الحلقة بنية تحكم تسمح بتنفيذ الكود بشكل متكرر بناءً على شرط معيّن.

## حلقات `while`

`while` حلقة هي بنية تحكم تسمح بتنفيذ الكود بشكل متكرر بناءً على شرط معيّن.
يستمر الكود داخل حلقة `while` في التنفيذ ما دام الشرط يُقيَّم على أنه صحيح.
غالبًا ما تُستخدم حلقات `while` عندما يكون عدد التكرارات غير معروف مسبقًا، ويمكن استخدامها في أي حالة تحتاج فيها إلى حلقة.

يُقيَّم الشرط قبل تنفيذ الكود داخل الحلقة، وهذا يعني أنه إذا كان الشرط خطأ، فلن يُنفَّذ الكود داخل الحلقة أبدًا.

```crystal
i = 0
while i < 3
  puts i
  i += 1
end

# Output:
# 0
# 1
# 2
```

عندما تريد المرور على سلسلة نصية، يمكنك استخدام حلقة تمر على طول السلسلة النصية.

```crystal
str = "Hello"
i = 0
while i < str.size
  puts str[i]
  i += 1
end

# Output:
# H
# e
# l
# l
# o
```

## حلقات `until`

تعمل حلقات `until` بالطريقة نفسها التي تعمل بها حلقات `while`، إلا أن الكود داخل الحلقة يستمر في التنفيذ حتى يُقيَّم الشرط على أنه صحيح.
وهو الفرق نفسه بين `if` و `unless`.

```crystal
i = 0
until i == 3
  puts i
  i += 1
end
```

### الحلقات اللانهائية

من الأخطاء الشائعة في حلقات `while` الدخول في «حلقة لانهائية» لا تنتهي أبدًا.
قد تنشأ الحلقة اللانهائية عن شرط _لا_ يُقيَّم أبدًا على أنه صحيح ولا خطأ.
وغالبًا ما يكون السبب خطأ من المبرمج، مثل نسيان زيادة متغير الحلقة.
لكن في بعض الأحيان تكون الحلقة اللانهائية أوضح أسلوب لتنفيذ منطق البرنامج.
أو يكون التكرار إلى الأبد أمرًا ضروريًا؛ فعلى سبيل المثال، ينتظر خادم HTTP اتصالًا واردًا، ويعالجه، ثم ينتظر الاتصال التالي.

## Break

يمكن استخدام الكلمة المفتاحية `break` للخروج من الحلقة مبكرًا.
قد يكون ذلك مناسبًا عندما تريد الخروج من الحلقة مبكرًا في ظروف معيّنة.

```crystal
i = 0
while i <= 3
  puts i
  i += 1
  if i == 2
    break
  end
end

# Output:
# 0
# 1
```

## Next

يمكن استخدام الكلمة المفتاحية `next` للانتقال إلى التكرار التالي في الحلقة.
قد يكون ذلك مناسبًا عندما تريد تخطي تكرارات معيّنة في الحلقة.

```crystal
i = 0
while i <= 3
  i += 1
  if i == 2
    next
  end
  puts i
end

# Output:
# 1
# 3
```

## الأنواع أثناء التكرار

قد يختلف نوع المتغير أثناء التكرار.
في المثال التالي، نوع `a` هو `Int32 | String` لأنه قد يكون `Int32` أو `String` في الجزء الأول من الحلقة.
لن يحمل المتغير `a` النوع `Int32 | String` إلا في الجزء الأول من الحلقة، لأنه عند بدء الحلقة يحمل `Int32`، وفي التكرار الثاني يحمل `String`.
سيُشرح نظام الأنواع المتعددة هذا بالتفصيل لاحقًا.
ولكن بما أننا متأكدون من أن الجزء الثاني من الحلقة سيحمل `String` فقط، فإن نوع `a` هو `String` في الجزء الثاني من الحلقة.
وعند التنفيذ، لن يحمل `Int32` و `String` في الوقت نفسه أبدًا.

```crystal
i = 0
a = 4
while i < 3
  p typeof(a)
  # => Int32 | String
  a = "4"
  p typeof(a)
  # => String
  i += 1
end
```

# Return

في Crystal، يُرجع التعبير الأخير في الطريقة قيمته.
لكنك تحتاج أحيانًا إلى إرجاع قيمة قبل التعبير الأخير.
ولهذا، يمكنك استخدام الكلمة المفتاحية `return`، التي تُرجع قيمة التعبير التالي.
لن يُنفَّذ الكود المكتوب بعد الكلمة المفتاحية `return`.

```crystal
def speed_limit(road_number)
    if road_number == 1
        return 50
        puts "This will not be executed"
    elsif road_number == 2
        return 80
        puts "This will not be executed"
    end
    100
end

p speed_limit(1) # => 50
p speed_limit(2) # => 80
p speed_limit(3) # => 100
```

~~~~exercism/note
ينبغي حذف الكلمة المفتاحية `return` عندما يكون التعبير الأخير في الطريقة هو القيمة التي ينبغي إرجاعها.
~~~~
