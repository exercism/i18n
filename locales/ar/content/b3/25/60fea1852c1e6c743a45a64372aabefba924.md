# التعليمات

في هذا التمرين ستكتب بعض الكود لمساعدتك في تحضير لازانيا رائعة من كتاب الطبخ المفضل لديك.

لديك خمس مهام، وكلها مرتبطة بالوقت المستغرق في طهي اللازانيا.

## 1. عرّف زمن الفرن المتوقع بالدقائق

عرّف المتغير غير القابل للتغيير `expectedMinutesInOven` الذي يُرجع عدد الدقائق التي ينبغي أن تبقى فيها اللازانيا في الفرن.
يجب تصديره.
وفقًا لكتاب الطبخ، زمن الفرن المتوقع بالدقائق هو 40:

```nim
nim> expectedMinutesInOven
40 == type int
```

## 2. احسب الوقت المتبقي في الفرن بالدقائق

نفّذ الإجراء `remainingMinutesInOven` الذي يأخذ عدد الدقائق الفعلية التي قضتها اللازانيا في الفرن كمعامل، ويُرجع عدد الدقائق التي لا تزال اللازانيا بحاجة إلى البقاء فيها في الفرن، استنادًا إلى زمن الفرن المتوقع بالدقائق من المهمة السابقة.

```nim
nim> remainingMinutesInOven(30)
10 == type int
```

## 3. احسب زمن التحضير بالدقائق

نفّذ الإجراء `preparationTimeInMinutes` الذي يأخذ عدد الطبقات التي أضفتها إلى اللازانيا كمعامل، ويُرجع عدد الدقائق التي استغرقتها في تحضير اللازانيا، بافتراض أن كل طبقة تستغرق منك 2 دقيقة للتحضير.

```nim
nim> preparationTimeInMinutes(2)
4 == type int
```

## 4. احسب إجمالي وقت العمل بالدقائق

نفّذ الإجراء `totalTimeInMinutes` الذي يأخذ معاملين: المعامل `numberOfLayers` هو عدد الطبقات التي أضفتها إلى اللازانيا، والمعامل `actualMinutesInOven` هو عدد الدقائق التي قضتها اللازانيا في الفرن.
ينبغي أن يُرجع الإجراء إجمالي عدد الدقائق التي عملتها في طهي اللازانيا، وهو مجموع زمن التحضير بالدقائق، والوقت بالدقائق الذي قضته اللازانيا في الفرن في هذه اللحظة.

```nim
nim> totalTimeInMinutes(3, 20)
26 == type int
```
