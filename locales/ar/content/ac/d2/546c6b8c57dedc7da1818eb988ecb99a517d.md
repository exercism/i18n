# مقدمة

يجمع *الاختزال* عناصر المتتالية في قيمة واحدة (أو في متتالية مشتقة من قيم جارية). دالة الاختزال العامة في Factor هي `reduce`، أما `math.statistics` فتضيف مجموعة من العمليات التراكمية (المجاميع الجارية، والجداءات الجارية، والقيم الصغرى، والقيم العظمى)، عندما تريد كل نتيجة وسيطة بدلًا من النتيجة الأخيرة وحدها.

```factor
USING: math math.statistics sequences ;

{ 2 5 1 3 } 0 [ + ] reduce .         ! => 11

{ 2 5 1 3 } cum-sum .                ! => { 2 7 8 11 }
{ 2 5 1 3 } cum-product .            ! => { 2 10 10 30 }
{ 2 5 1 3 } cum-min .                ! => { 2 2 1 1 }
{ 2 5 1 3 } cum-max .                ! => { 2 5 5 5 }
```

[math.statistics]: https://docs.factorcode.org/content/vocab-math.statistics.html
