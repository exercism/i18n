# مقدمة

تتيح لك الدالة تجميع الكود في وحدة قابلة لإعادة الاستخدام.
وهي تتكون من الكلمة المفتاحية `func`، واسم الدالة، وقائمة مفصولة بفواصل من صفر أو أكثر من المعاملات والأنواع بين الأقواس الهلالية.

## معاملات الدالة

يجب تحديد نوع جميع المعاملات صراحةً؛ فلا يوجد استنتاج للنوع بالنسبة للمعاملات.
ولا توجد قيم افتراضية للمعاملات، لذا فإن جميع معاملات الدالة مطلوبة.

```go
import "fmt"

// No parameters
func PrintHello() {
    fmt.Println("Hello")
}

// Two parameters
func PrintGreetingName(greeting string, name string) {
  fmt.Println(greeting + " " + name)
}
```

يمكن الإعلان عن المعاملات من النوع نفسه معًا، يتبعها إعلان واحد للنوع.

```go
import "fmt"

func PrintGreetingName(greeting, name string) {
  fmt.Println(greeting + " " + name)
}
```

## المعاملات مقابل الوسائط

لنستعرض سريعًا مصطلحين كثيرًا ما يُخلط بينهما: `parameters` و`arguments`.
معاملات الدالة هي الأسماء المعرَّفة في توقيع الدالة، مثل `greeting` و`name` في الدالة `PrintGreetingName` أعلاه.
أما وسائط الدالة فهي القيم الفعلية التي تُمرَّر إلى معاملات الدالة عند استدعائها.
على سبيل المثال، في المثال أدناه، `"Hello"` و`"Katrina"` هما الوسيطان الممرَّران إلى المعاملين `greeting` و`name`:

```go
PrintGreetingName("Hello", "Katrina")
```

## قيم الإرجاع

تأتي بعد معاملات الدالة صفر أو أكثر من قيم الإرجاع، والتي يجب أيضًا تحديد نوعها صراحةً.
تُكتب قيمة الإرجاع المفردة دون أقواس، أما قيم الإرجاع المتعددة فتُحاط بالأقواس الهلالية.
وتُرجع الدوال القيم إلى الكود المستدعي باستخدام الكلمة المفتاحية `return`.
ويمكن أن توجد عدة عبارات `return` في الدالة الواحدة.
وينتهي تنفيذ الدالة بمجرد وصوله إلى إحدى عبارات `return` هذه.
وإذا كان يجب إرجاع قيم متعددة من دالة، فإنها تُفصل بفواصل.

```go
func Hello(name string) string {
  return "Hello " + name
}

func HelloAndGoodbye(name string) (string, string) {
  return "Hello " + name, "Goodbye " + name
}
```

## استدعاء الدوال

يتم استدعاء الدالة بتحديد اسم الدالة وتمرير وسائط لكل معامل من معاملات الدالة بين الأقواس الهلالية.

```go
import "fmt"

// No parameters, no return value
func PrintHello() {
    fmt.Println("Hello")
}
// Called like this:
PrintHello()

// One parameter, one return value
func Hello(name string) string {
  return "Hello " + name
}
// Called like this:
greeting := Hello("Dave")

// Multiple parameters, multiple return values
func SumAndMultiply(a, b int) (int, int) {
    return a+b, a*b
}
// Called like this:
aplusb, atimesb := SumAndMultiply(a, b)
```

## قيم الإرجاع المُسمّاة والإرجاع المجرّد

إلى جانب المعاملات، يمكن اختياريًا تسمية قيم الإرجاع.
وإذا استُخدمت قيم إرجاع مُسمّاة، فإن عبارة `return` بدون وسائط ستُرجع تلك القيم.
ويُعرف هذا بالإرجاع المجرّد.

```go
func SumAndMultiplyThenMinus(a, b, c int) (sum, mult int) {
    sum, mult = a+b, a*b
    sum -= c
    mult -= c
    return
}
```

## التمرير بالقيمة مقابل التمرير بالمرجع

من المهم أيضًا توضيح مفهوم التمرير بالقيمة والتمرير بالمرجع.

أولًا، لنوضّح التمرير بالقيمة.
في المثال أدناه، عندما نمرّر المتغير `val` إلى الدالة `MultiplyByTwo`، فإننا نمرّر نسخة من `val`.
وبسبب ذلك، تحمل `newVal` القيمة المحدَّثة `4`، لكن المتغير الأصلي `val` ما زال `2`.
وخلف الكواليس، يُنشئ Go نسخة من القيمة الأصلية، بحيث لا تُعدّل الدالة سوى هذه النسخة، أي `v`.

```go
val := 2
func MultiplyByTwo(v int) int {
    v = v * 2
    return v
}
newVal := MultiplyByTwo(val)
// newval is 4, val is still 2 because only a copy of its value was passed into the function
```

بالمعنى الدقيق، تُمرَّر جميع الوسائط بالقيمة في Go، أي تُصنع نسخة من القيمة أو البيانات المقدَّمة إلى الدالة.
لكن إذا كنت لا تريد إنشاء نسخة من البيانات الممرَّرة إلى دالة وتريد تغيير البيانات داخل الدالة،
فعليك استخدام `pointers` كوسائط، أي التمرير بالمرجع.

## المؤشرات

نستخدم `pointer` لتحقيق التمرير بالمرجع.
وبتمرير وسائط من نوع `pointer` إلى دالة،
يمكننا تعديل البيانات الأساسية الممرَّرة إلى الدالة بدلًا من العمل على نسخة منها فقط.

في الوقت الحالي، يكفي أن تعرف أن أنواع المؤشرات يمكن تمييزها بعلامة `*` أمام النوع في توقيع الدالة.

```go
func HandlePointers(x, y *int) {
    // Some logic to handle integer values referenced by pointers x and y
}
```

إذا كان مفهوم `pointer` مربكًا، فلا تقلق.
لدينا قسم مخصص لاحقًا في المنهج لمساعدتك على إتقان المؤشرات.

## الاستثناءات

لاحظ أن `slices` و`maps` استثناءات من القاعدة المذكورة أعلاه.
فعندما نمرّر `slice` أو `map` كوسائط إلى دالة، فإنها تُعامَل كأنواع مؤشرات حتى لو لم توجد علامة `*` صريحة في النوع.
وهذا يعني أننا إذا مرّرنا `slice` أو `map` إلى دالة وعدّلنا بياناته الأساسية،
فستنعكس التغييرات على `slice` أو `map` الأصليين.
