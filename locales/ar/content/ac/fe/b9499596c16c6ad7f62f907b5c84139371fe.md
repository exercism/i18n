# التعليمات

أنت تعمل على بناء نظام لمراقبة الصحة. وكجزء من ذلك، تحتاج إلى تتبّع الإحصاءات الصحية للمستخدمين.

ستبدأ ببعض الدوال المبدئية داخل كتلة `impl`، إضافة إلى تعريف الـ `struct` التالي:

```rust
pub struct User {
    name: String,
    age: u32,
    weight: u32,
}
```

هدفك هو تنفيذ الطرق المبدئية المعرّفة على الـ `struct` المسمّى `User` داخل كتلة `impl`.

على سبيل المثال، يجب أن تُرجع الطريقة `new` نسخة من الـ `struct` المسمّى `User` بالاسم والعمر والوزن المحدَّدين.

```rust
let mut bob = User::new("Bob", 32, 72);
// Returns: a User with name "Bob", age 32, and weight 72
```

يجب أن تُرجع الطريقة `weight` وزن الـ `User`.

```rust
bob.weight();
// Returns: 72
```

يجب أن تضبط الطريقة `set_age` عمر الـ `User`.

```rust
bob.set_age(33);
// Updates Bob's age to 33; happy birthday Bob!
```

أتمنى لك وقتًا ممتعًا!
