# المولِّدات

`generator` هو دالة أو تعبير يُرجع نوعًا خاصًا من [المكرِّرات][iterator] يُسمى [`generator iterator`][generator-iterator].
`Generator-iterator`s هي [مكرِّرات كسولة][lazy iterator]: فهي لا تخزّن `values` في الذاكرة، بل _تولّد_ قيمها عند الحاجة.

دالة المولِّد تبدو كأي دالة أخرى، لكنها تحتوي على تعبير [`yield`][yield expression] واحد أو أكثر.
كل `yield` سيُعلّق تنفيذ الكود، مع حفظ حالة التنفيذ الحالية (_بما في ذلك جميع المتغيرات المحلية وعبارات `try`_).
وعندما يستأنف المولِّد عمله، يستكمل الحالة من نقطة التعليق، بخلاف الدوال العادية التي تُعاد تهيئتها مع كل استدعاء.


## إنشاء مولِّد

تُبنى المولِّدات على نحو يشبه كثيرًا الدوال الأخرى ذات الحلقات أو الدوال التي تستدعي نفسها، لكنها تحتاج إلى [تعبير `yield`](#the-yield-expression)، وسنتعمّق في شرحه بعد قليل.

مثال على ذلك دالة تُرجع _مربّعات_ الأعداد الواردة في قائمة معطاة.
بالصيغة المكتوبة حاليًا، يجب معالجة كل المدخلات قبل أن يمكن إرجاع أي قيمة:

```python
>>> def squares(list_of_numbers):
...     squares = []
...     for number in list_of_numbers:
...         squares.append(number ** 2)
...     return squares
```

يمكنك تحويل تلك الدالة إلى مولِّد هكذا:

```python
>>> def squares_generator(list_of_numbers):
...     for number in list_of_numbers:
...         yield number ** 2
```

السبب في ذلك هو أنك تستخدم مولِّدًا عندما لا تحتاج إلى إنتاج كل القيم _دفعة واحدة_.
فهذا يوفّر الذاكرة وقوة المعالجة، لأن القيمة الوحيدة التي _تعمل عليها حاليًا_ هي التي تُحسب.


## استخدام المولِّد

يمكن استخدام المولِّدات بدلًا من معظم `iterables` في Python.
ويشمل ذلك _الدوال_ أو _الكائنات_ التي تتطلب `iterable`/`iterator` كوسيط.

لاستخدام مولِّد `squares_generator()`:

```python
>>> squared_numbers = squares_generator([1, 2, 3, 4])

>>> for square in squared_numbers:
...     print(square)
...
1
4
9
16
```

يمكن أيضًا إنتاج القيم داخل `generator` أو الوصول إليها عبر الدالة `next()`.
تستدعي `next()` الطريقة `__next__()` في كائن المولِّد المكرِّر، فتقوم «بتقديم» الكود أو تقييمه حتى تعبير `yield` الخاص به، الذي «يولّد» أو يُرجع قيمة عندئذ:

```python
>>> squared_numbers = squares_generator([1, 2])

>>> next(squared_numbers)
1
>>> next(squared_numbers)
4
```

عندما يُستهلك `generator-iterator` بالكامل ولا تبقى لديه قيم يُرجعها، فإنه يطلق خطأ `StopIteration`.

```python
>>> next(squared_numbers)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
StopIteration
```


~~~~exercism/note

المولِّدات المكرِّرة مجموعة فرعية خاصة من [المكرِّرات][iterator].
`Iterators` هي الآلية أو البروتوكول الذي يتيح المرور على _العناصر القابلة للتكرار_.
تتصرّف المولِّدات المكرِّرة والمكرِّرات التي تُرجعها [`iterables`][iterables] الشائعة في Python بطريقة متشابهة جدًا، لكن هناك بعض الفروق المهمة التي يجب ملاحظتها:

- إنها _[تُقيَّم بتكاسل][lazy evaluation]_؛ فالتكرار _في اتجاه واحد_ ولا يوجد «رجوع» إلى قيمة سابقة.
- إنها _تُستهلك_ بالمرور على القيم المُرجَعة؛ فلا إعادة ضبط ولا حفظ في الذاكرة.
- لا يمكن ترتيبها ولا عكسها.
- إنها ليست من أنواع المتتاليات، و_ليس_ لها `indexes`. 
  لا يمكنك الإشارة إلى قيمة سابقة أو لاحقة باستخدام الجمع أو الطرح، ولا يمكنك استخدام صيغة الأقواس المربعة (`[]`) أو التقطيع.
- لا يمكن استخدامها مع الدالة `len()`، لأنه ليس لها طول.
- يمكن أن تكون _محدودة_ أو _لانهائية_، فاحذر عند جمع كل القيم من `generator-iterator` _لانهائي_!

## تعبير `yield`

يشبه [تعبير `yield`][yield expression] كثيرًا تعبير `return`.
و_بخلاف_ تعبير `return`، فإن `yield` يسلّم القيم إلى المستدعي عند _نقطة محددة_، فيُعلّق تقييم أو إرجاع أي قيم إضافية حتى تُطلب.
وعند تقييم `yield`، فإنه يوقف تنفيذ الدالة الحاوية ويُرجع أية قيم للدالة _عند تلك اللحظة_.
ثم تبقى الدالة _في النطاق_، وعند استدعاء `__next__()` يستأنف التنفيذ حتى يُصادف `yield` مرة أخرى.


~~~~exercism/note
يُحظر استخدام تعبيرات `yield` خارج الدوال.
~~~~

```python
>>> def infinite_sequence():
...     current_number = 0
...     while True:
...         yield current_number
...         current_number += 1

>>> lets_try = infinite_sequence()
>>> lets_try.__next__()
0
>>> lets_try.__next__()
1
```


## لماذا ننشئ مولِّدًا؟

المولِّدات مفيدة في كثير من التطبيقات.

عند التعامل مع مجموعة قيم قد تكون كبيرة، قد لا ترغب في وضعها كلها في الذاكرة.
ويمكن استخدام المولِّد لمعالجة بيانات أكبر قطعة قطعة، مما يوفّر الذاكرة ويحسّن الأداء.

تكون المولِّدات مفيدة أيضًا عندما تكون العملية أو الحساب _معقدًا_ أو _مكلفًا_ أو _لانهائيًا_:

```python
>>> def infinite_sequence():
...     current_number = 0
...     while True:
...         yield current_number
...         current_number += 1
```

الآن، كلما استُدعيت `__next__()` على كائن `infinite_sequence`، فستُرجع _العدد السابق_ + 1.
