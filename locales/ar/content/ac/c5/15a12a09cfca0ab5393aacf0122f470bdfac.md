# ملحق التعليمات

## السجلات

| السجل | الاستخدام        | النوع    | الوصف                   |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | مدخل        | عدد صحيح | العدد المعطى                  |
| `$a1`    | مدخل/مخرج | عنوان | سلسلة نصية منتهية بـ null |
| `$t0-9`  | مؤقت     | أي     | للتخزين المؤقت         |
