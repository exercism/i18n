# مقدمة

تُسمّى قدرة الشيء على أن يُعرَّف بدلالة نفسه الاستدعاء الذاتي. وفي Gleam، يظهر الاستدعاء الذاتي غالبًا في الدوال ذاتية الاستدعاء، وهي دوال تستدعي نفسها.

تحتاج الدالة ذاتية الاستدعاء إلى حالة أساسية واحدة على الأقل وإلى حالة استدعائية ذاتية واحدة على الأقل. الحالة الأساسية تُرجع قيمة دون استدعاء الدالة مرة أخرى. أما الحالة الاستدعائية الذاتية فتستدعي الدالة مرة أخرى، مع تعديل المُدخل بحيث يطابق الحالة الأساسية في مرحلة ما.

```gleam
pub fn factorial(x: Int) -> Int {
  case x {
    // Base case
    1 -> 1

    // Recursive case
    _ -> x * factorial(x - 1)
  }
}
```

لا يمتلك Gleam صياغة خاصة لكتابة الحلقات، لذلك تتم كل الحلقات عبر الاستدعاء الذاتي.

```gleam
pub fn list_length(list: List(String)) -> Int {
  case list {
    [] -> 0
    [_, ..rest] -> 1 + list_length(rest)
  }
}
```

يدعم Gleam أيضًا الأنواع المخصصة ذاتية الاستدعاء. النوع المخصص ذاتي الاستدعاء يشير أحد بدائله أو أكثر إلى نفسه في البيانات التي يحتويها.

```gleam
pub type RussianDoll {
  Child               // Base case
  Mother(RussianDoll) // Recursive case
}
```
```gleam
let very_big_doll = Mother(Mother(Mother(Child)))
let small_doll = Mother(Child)
```
