# التعليمات

بوب مستشار مالي يساعد الناس على إدارة نفقاتهم.
يرسل عملاء بوب سجلات نفقاتهم إليه لتحليلها.
ولدى بوب سجلات للفترات السابقة حتى يرى التغيّرات في الإنفاق.
لا يحب بوب التقاويم، ويستخدم *حقبة بوب* بدلًا من التواريخ.
وحقبة بوب هي عدد الأيام المنقضية منذ أن بدأ عميل بوب نشاطه.

في هذا التمرين، ستبني برنامجًا يساعد بوب على إدارة نفقات عملائه وتحليلها.

يتعامل بوب مع `Record` و`DaysPeriod`.

يمثّل `Record` سجل نفقات يحتوي على اليوم الذي تم فيه الإنفاق، والمبلغ المنفق، وفئة النفقة.

```go
// Record represents an expense record.
type Record struct {
	Day         int
	Amount      float64
	Category    string
}
```

يمثّل `DaysPeriod` نطاقًا من الأيام يشمل كل الأيام من اليوم `From` حتى اليوم `To`.
ويشمل النطاق طرفيه.

```go
// DaysPeriod represents a period of days.
type DaysPeriod struct {
	From int
	To   int
}

p := DaysPeriod{From: 1, To: 31}
// p represents all days from the day 1 to the day 31:
//  - days 1, 20, 16 and 31 are examples of days that are included
//    in the range of time specified by p
//  - days 50 and 40 are examples of days that are not included
//    in the range of time specified by p
```

## 1. نفّذ مرشّحًا عامًا للسجلات

يتعامل بوب مع الكثير من السجلات كل يوم، لكن ليس كلها مثيرًا للاهتمام، إذ يعتمد ذلك على التحليل الذي يجريه بوب.
لنساعد بوب على إجراء بعض التصفية الأساسية للسجلات.

نفّذ الدالة العامة `Filter` لتصفية السجلات وفق معيار تعطيه دالة.
تستقبل دالة التصفية هذه مجموعة من السجلات ودالة شرطية، وتُرجع فقط السجلات في المجموعة التي تحقق الشرط.

```go
records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
}

// Day1Records only returns true for records that are from day 1
func Day1Records(r Record) bool {
  return r.Day == 1
}

Filter(records, Day1Records)
// =>
// [
//   {Day: 1, Amount: 15, Category: "groceries"}
// ]
```

## 2. صفِّ السجلات ضمن فترة زمنية

يحتاج بوب كثيرًا إلى تصفية السجلات الواقعة في فترة زمنية معيّنة.

نفّذ الدالة `ByDaysPeriod` التي ستساعد بوب على إنشاء مرشّحات كهذه.
تستقبل هذه الدالة `DaysPeriod` وتُرجع دالة تأخذ سجلًا وتخبرنا ما إذا كان السجل ضمن الفترة الزمنية التي يحددها `DaysPeriod` المُمرَّر كوسيط.

```go
records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
  {Day: 26, Amount: 300, Category: "university"},
  {Day: 28, Amount: 1300, Category: "rent"},
}

period := DaysPeriod{From: 1, To: 15}

Filter(records, ByDaysPeriod(period))
// =>
// [
//   {Day: 1, Amount: 15, Category: "groceries"},
//   {Day: 11, Amount: 300, Category: "utility-bills"},
//   {Day: 12, Amount: 28, Category: "groceries"},
// ]
```

## 3. صفِّ السجلات حسب الفئة

إلى جانب تصفية السجلات حسب فترة زمنية، يحتاج بوب أيضًا إلى تصفية السجلات حسب فئتها.

نفّذ الدالة `ByCategory` التي ستساعد بوب على إنشاء مرشّحات كهذه.
تستقبل هذه الدالة فئة وتُرجع دالة تأخذ سجلًا وتخبرنا ما إذا كانت فئة هذا السجل مطابقة للفئة المُمرَّرة كوسيط.

```go
records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
  {Day: 28, Amount: 1300, Category: "rent"},
}

Filter(records, ByCategory("groceries"))
// =>
// [
//   {Day: 1, Amount: 15, Category: "groceries"},
//   {Day: 12, Amount: 28, Category: "groceries"},
// ]
```

## 4. احسب المبلغ الإجمالي للنفقات في فترة

يريد بوب أيضًا معرفة المبلغ الإجمالي للنفقات في فترة زمنية.

نفّذ الدالة `TotalByPeriod` لتُرجع مجموع النفقات في فترة الأيام.

```go
records := []Record{
  {Day: 15, Amount: 16, Category: "entertainment"},
  {Day: 32, Amount: 20, Category: "groceries"},
  {Day: 40, Amount: 30, Category: "entertainment"}
}

p1 := DaysPeriod{From: 1, To: 30}
p2 := DaysPeriod{From: 31, To: 60}

TotalByPeriod(records, p1)
// => 16

TotalByPeriod(records, p2)
// => 50
```

## 5. احسب إجمالي النفقات لسجلات فئة معيّنة في فترة

في أكثر التقارير تعقيدًا التي يقدّمها بوب لعملائه، يحتاج بوب إلى تصفية السجلات حسب الفئة والفترة الزمنية في الوقت نفسه.
أي أن بوب يريد معرفة إجمالي النفقات لسجلات فئة معيّنة في فترة زمنية معيّنة.

نفّذ الدالة `CategoryExpenses` التي تُرجع المبلغ الإجمالي للنفقات في فئة خلال فترة أيام معيّنة.
ينبغي أن تفرّق الدالة أيضًا بين حالة عدم وجود الفئة المعطاة في سجلات النفقات، وحالة عدم وجود نفقات لهذه الفئة في الفترة المحددة.
وعندما لا تكون الفئة فئةً لأي من السجلات (بغض النظر عن الفترة الزمنية)، ينبغي أن تُرجع الدالة خطأً.

```go
p1 := DaysPeriod{From: 1, To: 30}
p2 := DaysPeriod{From: 31, To: 60}

records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
  {Day: 26, Amount: 300, Category: "university"},
  {Day: 28, Amount: 1300, Category: "rent"},
}

CategoryExpenses(records, p1, "entertainment")
// => 0, error(unknown category entertainment)

CategoryExpenses(records, p1, "rent")
// => 1300, nil

CategoryExpenses(records, p2, "rent")
// => 0, nil
```
