# مقدمة

## الأساسيات

C# هي لغة ذات أنواع ثابتة، مما يعني أن لكل شيء نوعًا في وقت الترجمة. يُشار إلى إسناد قيمة إلى اسم بتعريف متغير. يمكن تعريف المتغير إما بتحديد نوعه صراحةً، وإما بترك مترجم C# يستنتج نوعه بناءً على القيمة المُسندة (وتُعرف هذه العملية بـ _استنتاج النوع_). لذلك، فإن التعريفين التاليين لمتغير متكافئان:

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

يتم تحديث قيمة المتغير عبر العامل `=`. بمجرد تعريفه، لا يمكن أن يتغير نوع المتغير أبدًا.

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

C# هي [لغة كائنية التوجه][object-oriented-programming] وتتطلب أن تُعرَّف جميع الدوال داخل _صنف_. تُستخدم الكلمة المفتاحية `class` لتعريف صنف. تُنشأ الكائنات (أو _المثيلات_) باستخدام الكلمة المفتاحية `new`.

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

يُشار إلى الدالة الموجودة داخل صنف باسم _طريقة_. يمكن أن يكون لكل طريقة صفر أو أكثر من المعاملات. يجب تحديد نوع جميع المعاملات صراحةً، فلا يوجد استنتاج للنوع بالنسبة للمعاملات. وبالمثل، يجب أيضًا تحديد نوع الإرجاع صراحةً. تُرجع القيم من الطرق باستخدام الكلمة المفتاحية `return`. للسماح باستدعاء طريقة من كود في ملفات أخرى، يجب إضافة معدّل الوصول `public`.

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

تُستدعى الطرق باستخدام صيغة النقطة (`.`) على مثيل، مع تحديد اسم الطريقة المطلوب استدعاؤها وتمرير الوسائط لكل معامل من معاملات الطريقة. يمكن للوسائط اختياريًا تحديد اسم المعامل المقابل.

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

يُعرَّف النطاق في C# بين المحرفين `{` و`}`.

تدعم C# نوعين من التعليقات. تسبق التعليقات أحادية السطر بـ `//`، وتُدرج التعليقات متعددة الأسطر بين `/*` و`*/`.
