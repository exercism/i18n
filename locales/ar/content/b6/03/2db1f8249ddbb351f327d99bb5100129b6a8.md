# ملحق التعليمات

## السجلات

| السجل    | الاستخدام    | النوع   | الوصف                              |
| -------- | ------------ | ------- | ---------------------------------- |
| `$a0`    | مُدخل        | عنوان   | سلسلة نصية من الأرقام منتهية بـ null |
| `$a1`    | مُدخل        | عدد صحيح | المدى                             |
| `$v0`    | مُخرج        | عدد صحيح | حاصل ضرب أكبر سلسلة أرقام          |
| `$t0-9`  | مؤقت         | أي نوع  | للتخزين المؤقت                     |
