# مقدمة

يمثّل [المدى][range] فترة بين قيمتين.
ويُستخدم المدى عادةً مع أنواع مثل `Int` و`String` و`Character` للتكرار عبر المتتاليات، أو لاقتطاع أجزاء من المجموعات، أو للتحقق مما إذا كانت قيمة تقع ضمن حدوده.

توفر Swift عاملي مدى أساسيين:

- **عامل المدى المغلق (`...`)**: يشمل كلًّا من قيمة البداية وقيمة النهاية (`1...5` يشمل 1 و2 و3 و4 و5).
- **عامل المدى نصف المفتوح (`..<`)**: يشمل قيمة البداية لكنه يستثني قيمة النهاية (`1..<5` يشمل 1 و2 و3 و4).

```swift
let closed = 1...5
let halfOpen = 1..<5
```

~~~~exercism/note
عندما تستدعي طريقةً ما مباشرةً على مدى مكتوب حرفيًا، ضع تعبير المدى بين الأقواس الهلالية حتى يقيّم المترجم المدى أولًا:

```swift
(1...5).contains(3) // Returns true
// 1...5.contains(3) // Error: value of type 'Int' has no member 'contains'
```
~~~~

## تحويل المدى إلى مصفوفة

يمكنك تحويل مدى من الأعداد إلى `Array` باستخدام المهيّئ `Array(_:)`:

```swift
let range = 1...5
let numbers = Array(range)
// numbers is [1, 2, 3, 4, 5]
```

## اقتطاع أجزاء من مصفوفة باستخدام المدى

يمكنك استخدام المدى لاقتطاع أجزاء فرعية من مصفوفة:

```swift
let array = [10, 20, 30, 40, 50]
let slice = array[1...3]
// slice contains [20, 30, 40]
```

## خصائص المدى وطرقه

تشمل العمليات الشائعة على المدى ما يلي:

| العضو                  | الوصف                                                | المثال                              |
| ----------------------- | ---------------------------------------------------------- | ------------------------------------ |
| `count`                 | تُرجع عدد العناصر في المدى                | `(1...5).count` تُرجع `5`          |
| [`contains(_:)`][contains] | تُرجع `true` إذا كان المدى يشمل القيمة المحددة | `(1...5).contains(3)` تُرجع `true` |

## المدى أحادي الجانب

تدعم Swift أيضًا المدى أحادي الجانب (الجزئي)، حيث تحذف قيمة البداية أو قيمة النهاية:

- `array[2...]`: من الفهرس 2 إلى نهاية المجموعة.
- `array[...2]`: من بداية المجموعة حتى الفهرس 2 ضمنًا.
- `array[..<2]`: من بداية المجموعة حتى الفهرس 2 (دون تضمينه).

## مدى السلاسل النصية والمحارف

يمكن أيضًا إنشاء مدى بين محرفين أو سلسلتين نصيتين تتوافقان مع `Comparable`:

```swift
let letters = "a"..."z"
print(letters.contains("m")) // Prints true
print(letters.contains("A")) // Prints false
```
