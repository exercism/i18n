# التثبيت

## بداية سريعة

``` shellsession
$ bash <(curl -s https://raw.githubusercontent.com/borkdude/babashka/master/install)
```

سيُثبّت هذا افتراضيًا في `/usr/local/bin`. لتغيير ذلك، مرّر اسم الدليل:

``` shellsession
$ bash <(curl -s https://raw.githubusercontent.com/borkdude/babashka/master/install) /tmp
```

## Brew

تتوفّر ملفات ثنائية لنظامي Linux وmacOS عبر brew.

للتثبيت:

    brew install borkdude/brew/babashka

للترقية:

    brew upgrade babashka

## Arch (Linux)

`babashka` [متاح](https://aur.archlinux.org/packages/babashka-bin/) في [مستودع مستخدمي Arch](https://aur.archlinux.org). ويمكن تثبيته باستخدام مساعد [AUR](https://aur.archlinux.org) المفضّل لديك مثل [yay](https://github.com/Jguer/yay)، و[yaourt](https://github.com/archlinuxfr/yaourt)، و[apacman](https://github.com/oshazard/apacman) و[pacaur](https://github.com/rmarquis/pacaur). وهذا مثال باستخدام `yay`:

    yay -S babashka-bin

## Windows

على Windows يمكنك التثبيت باستخدام [scoop](https://scoop.sh/) ودلو [scoop-clojure](https://github.com/littleli/scoop-clojure).

## تنزيل

يمكنك أيضًا تنزيل ملف ثنائي من [Github](https://github.com/borkdude/babashka/releases). يتوفّر لنظام Linux ملف ثنائي ثابت يمكن استخدامه على Alpine.

## Docker

اطّلع على الصورة على [Docker hub](https://hub.docker.com/r/borkdude/babashka/).
