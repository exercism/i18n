# المصفوفات

في Cairo، المصفوفة بنية بيانات تتيح لك تخزين مجموعة من العناصر من النوع نفسه.
خيارات التعديل على المصفوفات في Cairo محدودة.
ويمكنك فقط إضافة عناصر إلى نهاية المصفوفة وحذف عناصر من مقدمتها.
والمصفوفات في الحقيقة طوابير لا يمكن تعديل قيمها.

## إنشاء المصفوفة

تُنشأ المصفوفات أساسًا باستخدام السمة `ArrayTrait`، بأي من الطرق الأربع التالية لإنشاء مصفوفة من العناصر `[1, 2]`:

```rust
// 1. Passing the type to the `ArrayTrait`
let mut arr_type_in_trait = ArrayTrait::<felt252>::new();
arr_type_in_trait.append(1);
arr_type_in_trait.append(2);

// 2. Setting the type on the variable itself
let mut arr_explicit_type: Array<felt252> = ArrayTrait::new();
arr_explicit_type.append(1);
arr_explicit_type.append(2);

// 3. Using the `array!` macro
let mut arr_from_macro: Array<felt252> = array![1, 2]; // assign values in-line

// 4. Allowing the compiler to infer the type from the type of values being assigned to it
let mut arr_implicit_type = ArrayTrait::new(); // compiler "knows" this is a `felt252` array
arr_implicit_type.append(1);
arr_implicit_type.append(2);
```

> كل استدعاء لـ `append()` يضع رقمًا جديدًا في نهاية المصفوفة.

## حذف عناصر المصفوفة

لا يمكنك حذف عناصر من مصفوفة في Cairo إلا من المقدمة.
وتتولّى هذه العملية طريقة `pop_front()`، وهي تُرجع `Option` يمكن فكّها، تحتوي على العنصر المحذوف، أو `Option::None` إذا كانت المصفوفة فارغة.

```rust
fn main() {
    let mut a = array![10, 1, 2];
    let first_value = a.pop_front().unwrap(); // `unwrap()` is used to get the value from `Option`
    println!("The first value is {}", first_value); // prints "The first value is 10"
}
```

## الوصول إلى القيم في المصفوفة

للوصول إلى عناصر المصفوفة، يمكنك استخدام طريقتَي `get()` و`at()` الخاصتين بالمصفوفة، وهما تُرجعان أنواعًا مختلفة.
ويعادل `arr.at(index)` عامل الاشتراك `arr[index]`.

### استخدام طريقة `get()`

طريقة `get()` أشبه بالبحث عن عنصر في المصفوفة عبر رقمه.
وهذا ما تفعله:

- يتيح لك `arr.get(index)` جلب عنصر عند موضع محدد (الفهرس) في المصفوفة.
- تُرجع `Option::Some(value)` إذا وُجد العنصر عند الفهرس المعطى، أو `Option::None` إذا كان الفهرس خارج الحدود.

هذه الطريقة مثالية عندما تريد التعامل مع حالات قد يكون فيها الفهرس غير صالح دون أن يتعطّل برنامجك.

```rust
fn main() {
    let arr: Array<u32> = array![1, 2, 3];

    let index = 1;

    match arr.get(index) {
        Option::Some(value) => { println!("Element at index {}: {}", index, value.unbox()); },
        Option::None => { println!("Index {} is out of bounds!", index); }
    }
}
```

### استخدام طريقة `at()`

تمنحك طريقة `at()` لقطة مباشرة للعنصر عند فهرس محدد باستخدام عملية `unbox()` لاستخراج القيمة المخزّنة من الصندوق.
والاختصار لهذه الطريقة هو استخدام عامل الاشتراك `arr[index]`.
وإذا حاولت الوصول إلى فهرس غير موجود (خارج الحدود)، فسيتعطّل البرنامج بخطأ.

```rust
fn main() {
    let a: Array<u32> = array![5, 8];

    println!("First: {}", *a.at(0)); // prints "First: 5"
    println!("Second: {}", a[1]); // prints "Second: 8"
    println!("Third: {}", a[2]); // panics with 'Index out of bounds'
}
```

## طرق متعلقة بالحجم

لتحديد عدد العناصر في مصفوفة، استخدم طريقة `len()`.
قيمة الإرجاع من النوع `usize`.

وإذا أردت معرفة ما إذا كانت المصفوفة فارغة أم لا، يمكنك استخدام طريقة `is_empty()`، التي تُرجع `true` إذا كانت المصفوفة فارغة و`false` خلاف ذلك.

## `Span`

`Span` بنية تمثّل لقطة من `Array`.
وقد صُمّمت لتوفير وصول آمن ومنضبط إلى عناصر المصفوفة دون تعديل المصفوفة الأصلية.
و`Span` مفيد بشكل خاص لضمان سلامة البيانات وتجنّب مشكلات الاستعارة عند تمرير المصفوفات بين الدوال أو عند تنفيذ عمليات القراءة فقط.

> يمكن استخدام كل الطرق التي يوفّرها `Array` مع `Span` أيضًا، باستثناء طريقة `append()`.

لإنشاء `Span` من `Array`، استدعِ طريقة `span()`:

```rust
let my_array: Array<u32> = array![1, 2, 3];
let my_span: Span<u32> = my_array.span();
```

## نوع `Array` ثابت الحجم

نكتب القيم في مصفوفة ثابتة الحجم كقائمة مفصولة بفواصل داخل الأقواس المربعة.
ويُكتب نوع المصفوفة باستخدام الأقواس المربعة مع نوع كل عنصر، ثم فاصلة منقوطة، ثم عدد العناصر في المصفوفة.

```rust
let arr: [u64; 5] = [1, 2, 3, 4, 5];
```

> ملاحظة: لا يمكن استخدام سوى المصفوفات ثابتة الحجم كثوابت

يمكن الوصول إلى عناصر مصفوفة ثابتة الحجم إما بتفكيك المصفوفة أو بتحويلها إلى `Span`، الذي يدعم الفهرسة.

```rust
fn main() {
    let arr = [1, 2, 3, 4, 5]; // implicit `felt252` array type

    // Accessing elements of a fixed-size array by deconstruction
    let [a, b, c, _, _] = arr;
    println!("c: {}", c); // c: 3
    
    // Accessing elements of a fixed-size array by index
    let my_span = arr.span();
    println!("my_span[2]: {}", my_span[2]); // my_span[2]: 3
}
```
