# مقدمة

عندما يحتاج الاقتباس إلى أن *يتذكّر* قيمًا من محيطه، يقدّم Factor أداتين: `curry`/`compose` من [`kernel`][kernel]، وصيغة fry المتمثلة في `'[ … ]` من [`fry`][fry].

تُدرج `curry` قيمة واحدة في مقدمة الاقتباس:

```
curry ( value quot -- newquot )
```

```factor
3 [ + ] curry .          ! => [ 3 + ]
10 3 [ + ] curry call .  ! => 13
```

تجمع `compose` اقتباسين معًا:

```factor
[ 1 + ] [ 2 * ] compose .       ! => [ 1 + 2 * ]
5 [ 1 + ] [ 2 * ] compose call . ! => 12
```

إذا احتجت إلى التقاط أكثر من قيمة أو قيمتين، فإن fry أنظف. يُملأ كل عنصر نائب `_`، بالترتيب، بقيمة مأخوذة من المكدس:

```factor
2 3 '[ _ _ + + ] .    ! => [ 2 3 + + ]
```

كما تمتد fry إلى الاقتباسات المتداخلة.

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
[fry]: https://docs.factorcode.org/content/vocab-fry.html
