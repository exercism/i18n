# نبذة

[الصف][tuple] هو تجميعة _غير قابلة للتغيير_ من العناصر في _تسلسل_.

مثل معظم التجميعات (_انظر إلى الأنواع المدمجة [`list`][list] و[`dict`][dict] و[`set`][set]_)، يمكن أن تحتوي `tuples` أي نوع (أو أنواعًا متعددة) من البيانات، بما في ذلك `tuples` أخرى.
يمكن التكرار على عناصر الصف باستخدام البنية `for item in <tuple>`.
وإذا كنت تحتاج إلى كل من فهرس العنصر وقيمته، فيمكنك استخدام `for index, item in enumerate(<tuple>)`.

مثل أي [تسلسل][sequence]، يمكن الوصول إلى العناصر داخل `tuples` عبر _ترميز الأقواس المربعة_ باستخدام رقم `0-based index` من اليسار أو رقم `-1-based index` من اليمين.
ويمكن نسخ الصفوف كاملة أو جزئيًا عبر _ترميز الشرائح_ أو `<tuple>.copy()`، وتدعم `tuples` كل [عمليات التسلسل الشائعة][common sequence operations].
ولأنها _غير قابلة للتغيير_، فإن `tuples` **لا تدعم** [عمليات التسلسل القابلة للتغيير][mutable sequence operations].

تشغل الصفوف مساحة ذاكرة صغيرة جدًا مقارنة بأنواع التجميعات الأخرى، وزمن الوصول فيها ثابت (_O(1)_) عند استخدام فهرس.
غير أنها لا يمكن تغيير حجمها أو ترتيبها أو تعديلها بعد إنشائها، لذا فهي أقل مرونة عند الحاجة إلى تغييرات أو تحديثات متكررة على البيانات.
وإذا كنت بحاجة إلى تحديثات أو توسعات متكررة، فقد تكون `list` أو `collections.deque` أو `array.array` بنية بيانات أفضل.

## إنشاء الصفوف

يمكن إنشاء الصفوف بطرق متعددة، إما باستخدام مُنشئ الصنف `tuple` أو بالتعريف `(<element_1>, <element_2>)` (_الصف الحرفي_).

### استخدام مُنشئ `tuple()` فارغًا أو مع _كائن قابل للتكرار_:

```python
>>> no_elements = tuple()
()

# The constructor *requires* an iterable, so single elements must be passed in a list or another tuple.
>>> one_element = tuple([16])
(16,)
```

السلاسل النصية قابلة للتكرار، لذا فإن استخدام `str` واحدة كوسيط لمُنشئ `tuple()` قد يعطي نتائج مفاجئة:

```python
# String elements (characters) are iterated through and added to the tuple
>>> multiple_elements_string = tuple("Timbuktu")
('T', 'i', 'm', 'b', 'u', 'k', 't', 'u')
```

وهناك كائنات أخرى قابلة للتكرار تُضاف عناصرها واحدًا واحدًا:

```python
>>> multiple_elements_list = tuple(["Parrot", "Bird", 334782])
("Parrot", "Bird", 334782)

>>> multiple_elements_set = tuple({2, 3, 5, 7, 11})
(2,3,5,7,11)
```

التكرار الافتراضي على `dict` يكون على **المفاتيح**.
ولتضمين كل من المفاتيح والقيم في صف مُنشأ من قاموس، استخدم `<dict>.items()`، التي ستُرجع مكرِّرًا من `tuples` بالشكل (`key`, `value`).

```python
>>> source_data = {"fish": "gold", "monkey": "brown"}

>>> multiple_elements_dict_1 = tuple(source_data)
('fish', 'monkey')

>>> multiple_elements_dict_2 = tuple(source_data.items())
(('fish', 'gold'), ('monkey', 'brown'))
```

#### تعريف صف كـ_قيمة حرفية_:

ولأن مُنشئ `tuple()` لا يأخذ إلا _كائنات قابلة للتكرار_ (أو لا شيء) كوسائط، فمن الأسهل بكثير إنشاء صف من عنصر واحد بالطريقة الحرفية.

```python
>>> no_elements = ()
()

>>> one_element = ("Guava",)
("Guava",)
```

لاحظ أن الأقواس الهلالية **ليست** مطلوبة عمومًا لإنشاء `tuple` بالطريقة الحرفية، بل الفواصل فقط.
غير أن استخدام `(<element_1>, <element_2>)` يُعد أكثر وضوحًا في معظم الحالات.
وتلزم الأقواس الهلالية أيضًا في حالات الالتباس، مثل صف فارغ أو صف من عنصر واحد، أو عندما تأخذ دالة صفًا كوسيط.

```python
>>> elements_separated_with_commas = "Parrot", "Bird", 334782
("Parrot", "Bird", 334782)

>>> elements_with_commas_and_parentheses = ("Triangle", 60, 60, 60)
("Triangle", 60, 60, 60)
```

يمكن تضمين بنى بيانات أخرى كعناصر في `tuple`، بما في ذلك `tuples` أخرى.

```python
>>> nested_data_structures = ({"fish": "gold", "monkey": "brown", "parrot" : "grey"}, ("fish", "mammal", "bird"))
({"fish": "gold", "monkey": "brown", "parrot" : "grey"}, ("fish", "mammal", "bird"))

>>> nested_data_structures_1 = (["fish", "gold", "monkey", "brown", "parrot", "grey"], ("fish", "mammal", "bird"))
(["fish", "gold", "monkey", "brown", "parrot", "grey"], ("fish", "mammal", "bird"))
```

يمكن دمج الصفوف باستخدام عامل الجمع `+`، الذي يفكّ كل `tuple`، منشئًا `tuple` جديدًا مدمجًا.

```python
>>> new_via_concatenate = ("George", 5) + ("cat", "Tabby")
("George", 5, "cat", "Tabby")

#likewise, using the multiplication operator * is the equivalent of using + n times
>>> first_group = ("cat", "dog", "elephant")

>>> multiplied_group = first_group * 3
('cat', 'dog', 'elephant', 'cat', 'dog', 'elephant', 'cat', 'dog', 'elephant')
```

## الوصول إلى البيانات

يمكن الوصول إلى العناصر داخل الصفوف (_مثل نوعي التسلسل الآخرين `str` و`list`_) عبر _ترميز الأقواس المربعة_.
ويمكن أن تكون الفهارس من **`left`** --> **`right`** (_بدءًا من الصفر_) أو من **`right`** --> **`left`** (_بدءًا من -1_).
ويمكن أيضًا نسخ الصفوف كاملة أو جزئيًا عبر _ترميز الشرائح_ أو باستخدام `<tuple>.copy()`.

```python
>>> student_info = ("Alyssa", "grade 3", "female", 8)

#name is at index 0 or index -4
>>> student_name = student_info[0]
Alyssa

>>> student_name = student_info[-4]
Alyssa

#age is at index 3 or index -1
>>> student_age_1 = student_info[3]
8

>>> student_age_2 = student_info[-1]
8
```

## التكرار على العناصر

يمكن _التكرار على_ العناصر داخل الصفوف في حلقة باستخدام الصيغة `for item in <tuple>`.
وإذا كنت تحتاج إلى كل من الفهارس والقيم، فيمكنك استخدام `for index, item in enumerate(<tuple>)`.

```python
>>> student_info = ("Alyssa", "grade 3", "female", 8)
>>> for item in student_info:
...   print(item)
...
Alyssa
grade 3
female
8

>>> for index, item in enumerate(student_info):
...  print("Index is: " + str(index) + ", value is: " + str(item) + ".")
...
Index is: 0, value is: Alyssa.
Index is: 1, value is: grade 3.
Index is: 2, value is: female.
Index is: 3, value is: 8.
```


## الصفوف كمعلومات متجانسة

غالبًا ما تُستخدم الصفوف كـ_سجلات_ تحتوي بيانات متجانسة _تنظيميًا_ أو _مفاهيميًا_ وتُعامل كوحدة معلومات واحدة، حتى لو كانت العناصر الفردية من أنواع بيانات _غير متجانسة_.

```python
>>> student_info = ("Alyssa", "grade 3", "female", 8)
```

وتُستخدم الصفوف أيضًا عندما نحتاج إلى تسلسلات متجانسة غير قابلة للتغيير من البيانات من أجل [`hashability`][hashability]، أو التخزين في `set`، أو إنشاء مفاتيح في قاموس.

لاحظ أنه رغم أن `tuples` غير قابلة للتغيير في معظم الحالات، فبما أنها قد تحتوي _أي_ بنية بيانات أو كائن، فقد _تصبح قابلة للتغيير_ إذا كان أي من عناصرها من _نوع قابل للتغيير_.
واستخدام نوع بيانات قابل للتغيير داخل `tuple` يجعله **غير قابل للتجزئة**.

```python
>>> cmyk_color_map = {
        (.69, .3, .48, .1) : ("Teal 700", (59, 178, 146), 0x3BB292),
        (0, .5, 1, 0) : ("Pantone 151", (247, 127, 1), 0xF77F01),
        (.37, .89, 0, .44) : ("Pantone 267", (89, 16, 142), 0x59108E),
        (0, 1, .46, .45) : ("Pantone 228", (140, 0, 76), 0x8C004C)
    }

>>> unique_rgb_colors = {
        (59, 178, 146),
        (247, 127, 1),
        (89, 16, 142),
        (140, 0, 76),
        (76, 0, 140)
     }

>>> teal_700 = hash((59, 178, 146))

>>> teal_700 = hash(("Pantone 228", [(140, 0, 76), 0x8C004C]))
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: unhashable type: 'list'
```

## الصفوف الموسَّعة وأنواع البيانات ذات الصلة

غالبًا ما تُستخدم الصفوف كـ_سجلات_، لكن لا يمكن الوصول إلى البيانات داخلها إلا عبر _الموضع_/_الفهرس_.
ويوسّع الصنف [`namedtuple()`][namedtuple] في وحدة [`collections`][collections] وظائف الصف الأساسية للسماح بالوصول إلى العناصر بالـ_اسم_.
وبالإضافة إلى ذلك، يمكن للمستخدمين تكييف [`dataclass`][dataclass] لتوفير وظائف سمات مسمّاة مشابهة، مع بعض [الإيجابيات والسلبيات][dataclass pros and cons].
