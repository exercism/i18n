# التعليمات

انتهت تجارب الأداء الخاصة بمسرحية المدرسة، ويحتاج المخرج إلى تدوين القرارات.

المهام الأربع كلها توضع داخل الصنف `CASTING_CALL`.

## 1. الحكم

يُقيَّم كل مؤدٍّ بدرجة من عشر. ثمانية أو أكثر فيُمنح الدور، ومن خمسة إلى سبعة فيُستدعى مرة أخرى، وأقل من خمسة فيُشكر.

```sather
CASTING_CALL::audition_outcome(8)
-- => "Cast"
CASTING_CALL::audition_outcome(6)
-- => "Recalled"
CASTING_CALL::audition_outcome(2)
-- => "Thank you"
```

## 2. أي مجموعة؟

المؤدون الذين تقل أعمارهم عن 13 عامًا هم Juniors. ومن عمر 13 إلى 15 فهم Middles. ومن عمر ستة عشر عامًا أو أكثر فهم Seniors.

```sather
CASTING_CALL::age_group(13)
-- => "Middles"
```

## 3. موعد العودة

يُستدعى Juniors في الساعة الرابعة، و Middles في الخامسة، والبقية جميعًا في السادسة.

```sather
CASTING_CALL::callback_time("Middles")
-- => "5pm"
```

الوسيط هو اسم مجموعة، مكتوب تمامًا كما ورد في المهمة الثانية.

## 4. ماذا يُكتب على الورقة؟

من حصل على ثمانية أو أكثر ويستطيع الغناء فهو `"Lead"`. ومن حصل على ثمانية أو أكثر دون أن يغني فهو `"Speaking part"`. وأي شخص آخر فهو `"Chorus"`.

```sather
CASTING_CALL::casting_note(9, true)
-- => "Lead"
CASTING_CALL::casting_note(9, false)
-- => "Speaking part"
CASTING_CALL::casting_note(4, true)
-- => "Chorus"
```
