# مقدمة

المصفوفات في C# هي مجموعات من القيم الأولية أو من كائنات البُنى أو الأصناف. وهي مُنفَّذة في مكتبة الأصناف الأساسية بصيغة `List<T>`، حيث `T` هو نوع العنصر في المصفوفة. وتوفّر API مجموعة غنية من الطرق لإنشاء المصفوفات والتعامل معها.

يمكن إضافة العناصر إلى المصفوفات وإزالتها منها، وهي تكبر وتصغر حسب الحاجة.

```csharp
var listOfStrings = new List<string>();
```
