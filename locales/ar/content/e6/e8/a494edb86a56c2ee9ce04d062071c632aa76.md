# مقدمة

## السلاسل البتية

يُعدّ العمل مع البيانات الثنائية مفهومًا مهمًا في أي لغة، ويوفّر Elixir صياغة أنيقة لكتابة البيانات الثنائية ومطابقتها وبنائها.

في Elixir، يُشار إلى البيانات الثنائية بنوع السلسلة البتية. أما _نوع_ البيانات الثنائية (ولا يُخلط بينه وبين البيانات الثنائية عمومًا) فهو شكل خاص من السلسلة البتية، وسنناقشه في تمرين لاحق.

تُعرَّف القيم الحرفية للسلاسل البتية باستخدام الصيغة الخاصة `<<>>`. وعند تعريف قيمة حرفية لسلسلة بتية، فإنها تُعرَّف على شكل مقاطع. لكل مقطع قيمة ونوع، يفصل بينهما العامل `::`. ويحدد النوع عدد البتات التي ستُستخدم لترميز القيمة. ويمكن حذف النوع تمامًا، وفي هذه الحالة يكون الافتراضي قيمة عدد صحيح من 8 بتات.

```elixir
# This defines a bitstring with three segments of a single bit each
<<0::1, 1::1, 0::1>>
```

كتابة النوع بالصيغة `::1` اختصار لكتابة `::size(1)`. عليك استخدام الصيغة الأطول إذا كان حجم البتات قادمًا من متغير.

### البيانات الثنائية

عند كتابة القيم الحرفية للأعداد الصحيحة الثنائية، يمكننا كتابتها مباشرة بصيغة الأساس 2 بوضع البادئة `0b` قبل القيمة الحرفية. لاحظ أنها ستُعرض على أي حال كأعداد عشرية عند طباعتها في نتائج الاختبارات أو عند استخدام iex.

```elixir
<<0b1011::4>> == <<11::4>>
# => true
```

### الاقتطاع

إذا تجاوزت قيمة المقطع سعة نوع المقطع، فستُقتطع من اليسار.

```elixir
<<0b1011::3>> == <<0b0011::3>>
# => true
```

### الإضافة في البداية وفي النهاية

يمكنك الإضافة إلى بداية سلسلة بتية موجودة وإلى نهايتها باستخدام الصيغة الخاصة. ويجب استخدام النوع `::bitstring` على السلسلة البتية الموجودة إذا كان حجمها غير معروف.

```elixir
value = <<0b110::3, 0b001::3>>
new_value = <<0b011::3, value::bitstring, 0b000::3>>
# => <<120, 8::size(4)>>
```

### الدمج

يمكننا دمج السلاسل البتية المخزنة في متغيرات باستخدام الصيغة الخاصة. ويجب استخدام النوع `::bitstring` عند دمج سلسلتين بتيتين بحجمين غير معروفين.

```elixir
first = <<0b110::3>>
second = <<0b001::3>>
concatenated = <<first::bitstring, second::bitstring>>
# => <<49::size(6)>>
```

### مطابقة الأنماط

يمكن أيضًا إجراء مطابقة الأنماط للحصول على قيم من الصيغة الخاصة. عليك معرفة عدد البتات لكل جزء تريد التقاطه، باستثناء واحد: يمكن استخدام النوع `::bitstring` لمطابقة نمط سلسلة بتية بحجم غير معروف، لكن هذا لا يصلح إلا للجزء الأخير.

```elixir
<<value::4, rest::bitstring>> = <<0b01101001::8>>
value == 0b0110
# => true
```

### فحص السلاسل البتية

~~~~exercism/note
قد تُطبع السلاسل البتية (بواسطة مشغّل الاختبارات أو في iex) بصيغة
مختلفة عن الصيغة التي أُنشئت بها. وهذا غالبًا ما يسبّب الارتباك عند تعلّم السلاسل البتية.
~~~~

افتراضيًا، تُعرض السلاسل البتية في مقاطع من 8 بتات (بايت)، حتى لو أنشأتها بمقاطع بحجم مختلف.

```elixir
<<2011::11>>
# => <<251, 3::size(3)>>
```

إذا أنشأت سلسلة بتية تمثّل سلسلة نصية قابلة للطباعة بترميز UTF-8، فستُعرض على هيئة سلسلة نصية.

```elixir
<<>>
# => ""

<<65, 66, 67>>
# => "ABC"
```
