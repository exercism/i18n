# المقدمة

## المصفوفات

المصفوفة [`List`][lists] في Elm هي مجموعة غير قابلة للتغيير من صفر أو أكثر من القيم من النوع نفسه.

يمكن تعريف المصفوفات على النحو التالي:

```elm
empty = []
singleValue = [ 5 ]
threeValues = [ "a", "b", "c" ]
```

أكثر الأساليب شيوعًا لإضافة عنصر إلى مصفوفة هو استخدام العامل `::` (cons):

```elm
twoToFour = [ 2, 3, 4 ]
oneToFour = 1 :: twoToFour --> [ 1, 2, 3, 4 ]
```

يتم التعامل مع المصفوفات بواسطة دوال وعوامل معرَّفة في [وحدة `List`][list-module] أو عبر [مطابقة الأنماط][list-destructuring]

```elm
describe : List String -> String
describe list =
    case list of
        [] ->
            "Empty list"

        [ "hello" ] ->
            "Singleton list with: hello"

        x :: xs ->
            "Non-empty list with head: " ++ x

describe []                   --> "Empty list"
describe [ "hello" ]          --> "Singleton list with: hello"
describe [ "hello", "world" ] --> "Non-empty list with head: hello"
```
