# نبذة

تُمثَّل القيم المنطقية في F# بالنوع `bool`، الذي يمكن أن تكون قيمه إما `true` أو `false`.

تدعم F# ثلاثة [عوامل منطقية][operators]: `not` (النفي)، و`&&` (و)، و`||` (أو). العاملان `&&` و`||` يستخدمان _التقييم قصير الدائرة_، ما يعني أن الطرف الأيمن للعامل لا يُقيَّم إلا عند الحاجة.

```fsharp
true || false // => true
true && false // => false
```

لكل من العوامل المنطقية الثلاثة [_أسبقية العوامل_][precedence] مختلفة. وبالتالي، تُقيَّم بهذا الترتيب: `not` أولًا، ثم `&&`، وأخيرًا `||`. إذا أردت «تجاوز» هذه القواعد، يمكنك وضع تعبير منطقي بين الأقواس الهلالية (`()`)، لأن الأقواس الهلالية لها أسبقية عوامل أعلى.

```fsharp
not true && false   // => false
not (true && false) // => true
```

[precedence]: https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/symbol-and-operator-reference/#operator-precedence
