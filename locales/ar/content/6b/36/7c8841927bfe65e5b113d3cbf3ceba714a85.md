# تعليمات إضافية

## تلميحات

عليك تنفيذ الدالتين `decode` و `encode`، اللتين تفكّان تشفير قيمة من النوع `String` وتشفّرانها باستخدام الشيفرة الأفينية.
يمكنك استخدام التوقيع المعطى إن لم تكن متأكدًا من الأنواع، لكن لا تدعه يقيّد إبداعك.

يتعامل هذا التمرين مع بيانات نصية.
ولأسباب تاريخية، فإن النوع `String` في Haskell مرادف للنوع `[Char]`، وهو مصفوفة من المحارف.
ولمعالجة البيانات النصية بكفاءة أكبر، يمكن استخدام النوع `Text`.

وكإضافة اختيارية إلى هذا التمرين، يمكنك

- إضافة `- text` إلى قائمة التبعيات في `package.yaml`.
- استيراد `Data.Text` [بالطريقة التالية](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- استخدام النوع `Text` مثلًا `decode :: Text -> Text`، والإشارة إلى دوال التركيب في `Data.Text` كما في `T.pack` مثلًا.
- البحث عن التوثيق الخاص بـ [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html).
- استبدال جميع مواضع `String` بـ `Text` في `Affine.hs`، أي:

```haskell
encode :: (Int, Int) -> Text -> Maybe Text
encode key plainText = ...

decode :: (Int, Int) -> Text -> Maybe Text
decode key cipherText = ...
```

هذا الجزء اختياري تمامًا.
