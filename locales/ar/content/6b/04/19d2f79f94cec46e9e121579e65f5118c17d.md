# التعليمات

في هذا التمرين ستُنفّذ مجموعة جزئية من الدوال المساعدة لمساعدة مطوّر على تنظيف أسماء SqueakyClean.

ستبني الطريقة `clean` تدريجيًا عبر 4 مهام.
يتكوّن اسم SqueakyClean الصالح من صفر أو أكثر من الحروف والشرطات السفلية.

في جميع الحالات، من المضمون أن السلسلة النصية المدخلة لن تكون `null`. لاحظ أن الطريقة `clean` يجب أن تعامل السلسلة النصية الفارغة على أنها صالحة.

## 1. استبدل أي مسافات تصادفها بشرطات سفلية

نفّذ الطريقة (`static`) `SqueakyClean.clean()` لاستبدال أي مسافات بشرطات سفلية. ينطبق هذا أيضًا على المسافات في بداية السلسلة ونهايتها.

```java
SqueakyClean.clean("my   Id");
// => "my___Id"
```

## 2. حوّل `kebab-case` إلى `camelCase`

عدّل الطريقة (`static`) `SqueakyClean.clean()` لتحويل `kebab-case` إلى `camelCase`.

```java
SqueakyClean.clean("a-bc");
// => "aBc"
```

## 3. حوّل لييت إلى نص عادي

عدّل الطريقة (`static`) `SqueakyClean.clean()` لتحويل [لييت][leet-speak] إلى نص عادي.

للتبسيط، سنستبدل فقط `4` و`3` و`0` و`1` و`7` بـ `a` و`e` و`o` و`l` و`t` على الترتيب.

```java
SqueakyClean.clean("H3ll0 W0rld");
// => "Hello_World"
SqueakyClean.clean("4 73s7");
// => "a_test"
```

## 4. استبعد المحارف التي ليست حروفًا

عدّل الطريقة (`static`) `SqueakyClean.clean()` لاستبعاد أي محارف ليست حروفًا.

```java
SqueakyClean.clean("a$#.b");
// => "ab"
```

[leet-speak]: https://en.wikipedia.org/wiki/Leet
