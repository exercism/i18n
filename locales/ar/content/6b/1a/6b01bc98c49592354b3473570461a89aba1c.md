# نبذة

## الوحدات

يُنظَّم كود Gleam في وحدات، وكل ملف هو وحدة Gleam واحدة.

حتى الآن كتبنا الدوال بصيغة `pub fn`، وهي تعرّف دالة متاحة علنًا للوحدات الأخرى. أما الدوال المعرّفة بـ `fn` فهي خاصة بالوحدة التي عُرّفت فيها، ولا يمكن للوحدات الأخرى استخدامها.

```gleam
// This function is public
pub fn add(x, y) {
  x + y
}

// This function is private
fn subtract(x, y) {
  x - y
}
```

لوحدات Gleam أسماء، ويُشتق الاسم من مسار ملفها داخل مجلد `src` أو `test`.

على سبيل المثال، الوحدة المعرّفة في `src\geometry\rectangle.gleam` (على Windows) أو `src/geometry/rectangle.gleam` (على أنظمة تشغيل شبيهة بـ UNIX) سيكون اسمها `geometry/rectangle`.

## استيراد الدوال من وحدات أخرى

يتم الوصول إلى الدوال المعرّفة في وحدات أخرى عبر الاستيراد.
وعند استيراد وحدة ما، تصبح جميع الدوال التي أتاحتها تلك الوحدة متاحة.
لكن طريقة الوصول إليها تختلف حسب طريقة استيراد الوحدة.

الاستيراد المؤهَّل هو الوضع الافتراضي، ويتم الوصول إلى دالة داخل وحدة كهذه (مثل دالة `map` في وحدة `gleam/list`) بكتابة اسم الوحدة قبلها (`list.map`).

```gleam
// Import the int module
import gleam/int

pub fn run(x: Int) -> String {
  // Use the to_string function from the int module
  int.to_string(x)
}
```

افتراضيًا، الاسم المستخدم للإشارة إلى الوحدة هو الجزء الأخير من اسم الوحدة، وهو هنا `int`، لكن يمكن تغيير ذلك باستخدام الكلمة المفتاحية `as`.

```gleam
// Import the int module and refer to it as i
import gleam/int as i

pub fn run(x: Int) -> String {
  i.to_string(x)
}
```

يتيح الاستيراد غير المؤهَّل الوصول المباشر إلى الدوال المتاحة داخل تلك الوحدة، دون كتابة اسم الوحدة قبلها.

```gleam
// Import the to_string function from the int module
import gleam/int.{to_string}

pub fn run(x: Int) -> String {
  to_string(x)
}
```

يُفضَّل الاستيراد المؤهَّل لأنه يوضّح للقارئ مصدر الدالة، ولتجنّب تعارض الأسماء.
