# مقدمة

تُمثّل Unison القيمتين صحيح وخطأ بنوع `Boolean`. ولا توجد سوى قيمتين اثنتين: `true` و`false`.

```unison
trueVariable = true
falseVariable = false
```

يمكننا تقييم التعبيرات المنطقية باستخدام العوامل `and`، الذي يُرمز إليه بـ `&&`، و`or`، الذي يُرمز إليه بـ `||`، و`not`، الذي يُرمز إليه بـ `not`.

```unison
trueVariable = true && true
falseVariable = true && false

trueVariable = false || true
falseVariable = false || false

trueVariable = not false
falseVariable = not true
```
