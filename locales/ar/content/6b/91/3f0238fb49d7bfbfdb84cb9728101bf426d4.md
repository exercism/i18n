# عن المكرِّرات

يشبه `Iterator` في Gleam المصفوفة في كونه مجموعة مرتبة من القيم، تكون جميعها من النوع نفسه. ويختلف عن المصفوفة في أنه كسول، أي أنه لا يخزّن كل قيمه في الذاكرة دفعة واحدة، بل يحسبها عند الحاجة إليها.

ويفيدنا هذا عند التعامل مع متتاليات ضخمة جدًا أو حتى لانهائية الحجم، لأنه يتيح لنا التعامل معها عندما لا تتوفر لدينا ذاكرة حرة تكفي لتخزينها كلها دفعة واحدة.

تُعرّف وحدة `gleam/iterator` النوع `Iterator` إضافة إلى دوال للتعامل مع المكرِّرات.

وكثير من دوال المصفوفات متاحة أيضًا للمكرِّرات، مثل `map` و`filter` و`take`. وهذه الدوال تُرجع مكرِّرات، لذا فهي لا تقوم بأي عمل فعلي حتى يُستهلك المكرِّر.

```gleam
let iter = 
  [1, 2, 3, 4, 5, 6]
  |> iterator.from_list
  |> iterator.filter(fn(x) { x > 2 })
  |> iterator.take(2)

// No work has been done yet as the iterator has not been consumed

// Consume the iterator and collect the values into a list
iterator.to_list(iter)
// -> [3, 4]
```

ويمكن استخدام الدالة `unfold` لإنشاء مكرِّرات انطلاقًا من دالة تُستدعى مرارًا لتوليد القيمة التالية في المتتالية.

وهنا تُستخدم الدالة `unfold` لإنشاء مكرِّر يولّد متتالية فيبوناتشي:

```gleam 
iterator.unfold(#(0, 1), fn(pair) {
  let x = pair.0 + pair.1
  iterator.Next(element: x, accumulator: #(pair.1, x))
})
|> iterator.take(6)
|> iterator.to_list
// -> [1, 2, 3, 5, 8, 13]
```

المتتالية هنا لانهائية، لذا تُستخدم الدالة `take` لجعلها منتهية قبل تجميع القيم في مصفوفة. وإذا استُدعيت `to_list` على مكرِّر لانهائي فسيستمر البرنامج في العمل حتى تنفد ذاكرته فينهار.
