# نبذة

الشرائح في Go مشابهة للمصفوفات في لغات أخرى.
فهي تحمل عدة عناصر من نوع معيّن (أو واجهة).

تعتمد الشرائح في Go على المصفوفات.
والمصفوفات لها حجم ثابت.
أما الشريحة، في المقابل، فهي عرض مرن لعناصر المصفوفة يتحدد حجمه ديناميكيًا.

تُكتب الشريحة على الصورة `[]T`، حيث `T` هو نوع العناصر في الشريحة:

```go
var empty []int                 // an empty slice
withData := []int{0,1,2,3,4,5}  // a slice pre-filled with some data
```

يمكنك قراءة عنصر أو تغييره عند فهرس معيّن يبدأ من الصفر باستخدام الأقواس المربعة:

```go
withData[1] = 5
x := withData[1] // x is now 5
```

يمكنك إنشاء شريحة جديدة من شريحة موجودة بأخذ نطاق من العناصر.
مرة أخرى بالأقواس المربعة، لكن مع تحديد فهرس البداية (ضمًّا) وفهرس النهاية (استثناءً).
إذا لم تحدد فهرس البداية، فسيكون 0 افتراضيًا.
وإذا لم تحدد فهرس النهاية، فسيكون طول الشريحة افتراضيًا.

```go
newSlice := withData[2:4]
// => []int{2,3}
newSlice := withData[:2]
// => []int{0,1}
newSlice := withData[2:]
// => []int{2,3,4,5}
newSlice := withData[:]
// => []int{0,1,2,3,4,5}
```

يمكنك إضافة عناصر إلى الشريحة باستخدام الدالة `append`.
فيما يلي نضيف `4` و`2` إلى الشريحة `a`.

```go
a := []int{1, 3}
a = append(a, 4, 2)
// => []int{1,3,4,2}
```

تُرجع `append` دائمًا شريحة جديدة، وعندما نريد فقط إضافة عناصر إلى شريحة موجودة، فمن الشائع إعادة إسنادها إلى متغير الشريحة الذي نمرّره كوسيط أول، كما فعلنا أعلاه.

يمكن أيضًا استخدام `append` لدمج شريحتين:

```go
nextSlice := []int{100,101,102}
newSlice  := append(withData, nextSlice...)
// => []int{0,1,2,3,4,5,100,101,102}
```

## الفهارس في الشرائح

ينبغي دائمًا حماية التعامل مع فهارس الشرائح بطريقة ما عبر تحقق يتأكد من وجود الفهرس فعلًا.
وإلا فسيتعطّل التطبيق بأكمله.

## الشرائح الفارغة

الشرائح من نوع `nil` هي الشريحة الفارغة الافتراضية.
ولا تعاني من أي عيوب مقارنة بشريحة لا تحتوي على أي قيم.
فالدالة `len` تعمل على الشرائح `nil`، ويمكن إضافة عناصر إليها دون تهيئتها، وهكذا.
إذا كنت تنشئ شريحة جديدة، ففضّل `var s []int` (شريحة `nil`) على `s := []int{}` (شريحة فارغة ليست `nil`).

## الأداء

عند إنشاء شرائح ستُملأ بشكل تكراري، هناك طريقة سهلة لتحسين الأداء إذا كان الحجم النهائي للشريحة معروفًا.
المفتاح هو تقليل عدد مرات حجز الذاكرة، وهي عملية مكلفة نوعًا ما وتحدث إذا نمت الشريحة بما يتجاوز مساحة الذاكرة المحجوزة لها.
وأأمن طريقة لذلك هي تحديد سعة `cap` للشريحة عبر `s := make([]int, 0, cap)` ثم استخدام `append` مع الشريحة كالمعتاد.
وبهذه الطريقة تُحجز المساحة اللازمة لعدد `cap` من العناصر فورًا بينما يكون طول الشريحة صفرًا.
وعمليًا، غالبًا ما يكون `cap` هو طول شريحة أخرى: `s := make([]int, 0, len(otherSlice))`.

## الدالة `append` ليست دالة نقية

دالة `append` في Go مُحسّنة للأداء، ولذلك لا تنسخ شريحة الإدخال.
وهذا يعني أن الشريحة الأصلية (المعامل الأول في `append`) ستتغير أحيانًا.
