# نبذة

يكون النوع _نوعًا عامًّا_ عندما يستطيع أن يحتوي على قيم من أي نوع باستخدام _معامل نوع_.

على سبيل المثال، هذا النوع `Box` له معامل النوع `a` (يُكتب بحروف صغيرة).

```gleam
pub type Box(a) {
  Box(a)
}
```

معامل النوع `a` بديل عن أي نوع، لذا يمكن استخدام `Box` مع السلاسل النصية والأعداد الصحيحة وأي نوع آخر.

```gleam
Box("Hello, Joe!") // The type is Box(String)

Box(42) // The type is Box(Int)
```

يمكن للنوع أن يمتلك عدة معاملات نوع بفصلها بفواصل.

```gleam
pub type Pair(a, b) {
  Pair(a, b)
}
```

## الدوال العامة

يمكن أيضًا استخدام معاملات النوع في وسائط الدوال.

تأخذ هذه الدالة قيمة من النوع `a` وتستدعي مرتين دالة تأخذ `a` وتُرجع `b`.

```gleam
pub fn twice(value: a, f: fn(a) -> b) -> b {
  f(value)
  f(value)
}
```
```gleam
// The type is fn(String, fn(String) -> Nil) -> Nil
twice("Hello, Joe!", io.println)
```
