# نبذة

هناك نوعان رئيسيان من الخصائص:

1. الخصائص المُنفَّذة تلقائيًا، حيث لا يكون لدالتَي الوصول `get` و `set` أي جسم.
   وقد تكون مُهيَّأة صراحةً وقد لا تكون. على سبيل المثال:
   ```csharp
   public int MyProperty {get; set;} = 42;
   ```
2. الخصائص التي تُقيّم فيها دالتا الوصول تعبيرات وتنفّذ عبارات. وقد يكون الكود
   في أبسط صوره إرجاع حقل خلفي أو إسناد قيمة إليه. على سبيل المثال:
   ```csharp
   private int myField;
   public int MyProperty
   {
     get { return myField; }
     set { myField = value; }
   }
   ```

هناك تداخل كبير في السلوك والقدرة بين الخصائص والطرق.
وعندما لا تكون الخصائص مُنفَّذة تلقائيًا، يمكنها أن تحتوي على أي عبارة أو تعبير
يمكن أن يظهر داخل نطاق الصنف. وفي الحالة الشائعة، كثيرًا ما تُوصف بأنها تُغلّف
حقلًا خلفيًا.
وعلى الرغم من أنه في كثير من الحالات يكون واضحًا ما إذا كان ينبغي برمجة سلوك ما كخاصية أم كطريقة،
فإنه غالبًا ما يكون قرارًا اجتهاديًا يتخذه المبرمج، ولا سيما مقدار الكود الذي ينبغي
تنفيذه داخل دالتَي الوصول. ومن الشائع وجود التحقق من الصحة في دالة الوصول `set`، وحساب بسيط أو تنسيق في
دالة الوصول `get`:

```csharp
private float fraction;
public float Percentage
{
  get { return fraction * 100; }
  set
  {
    if (value < 0 || value > 100)
    {
      throw new ArgumentException("Percentage must be between 0 and 100");
    }
    fraction = value / 100;
  }
}
```

وعلى غرار أعضاء الصنف الأخرى، يمكن أن يكون للخصائص مستويات وصول.
وفي معظم الأحيان يكون لخصائص مستوى وصول غير خاص، بما يتوافق مع
غرضها الأساسي. وأحيانًا يكون لإحدى دالتَي الوصول مستوى وصول
مختلف عن مستوى وصول الخاصية. وفي حالة `TareWeight`،
وفي ظل قيد "الأمان" المصطنع نوعًا ما، كانت هناك فرصة
لوجود خاصية عامة بدالة وصول `get` خاصة. وهذا يعني أن الكود الموجود خارج
الصنف يستطيع إسناد قيمة إلى الخاصية، لكن لا يمكن قراءتها (أي `get`) إلا بواسطة الكود الموجود داخل
الصنف.

```csharp
public int ConfidentialValueUsedInternally {private get; set; }
```

كما أن دالات الوصول `set` غير العامة مدعومة أيضًا، لكن الحالة الأكثر شيوعًا هي أن
تُحذف دالة الوصول `set` تمامًا. وقد يكون السبب أن
قيمة الخاصية تُسند في مُنشئ الصنف.

```csharp
class MyClass
{
  public MyClass( int importantValue)
  {
    ConstructedValue = importantValue;
  }
  public int ConstructedValue {get;}
}
```

تناول هذا التمرين الاستخدام الأساسي للخصائص. وستجد موضوعات أكثر تقدمًا
في تمارين أخرى:

- الخصائص ذات الجسم التعبيري، ودالتا الوصول `get` و `set` (يُغطّيه تمرين الأعضاء ذات الجسم التعبيري)
- الخصائص في الواجهات (يُغطّيه تمرين الواجهات)
- الخصائص والخصائص المجردة في الأصناف المجردة (يُغطّيه تمرين الوراثة)
- استخدام الكلمة المفتاحية `readonly` مع الخصائص (يُغطّيه تمرين الثبات)
- الخصائص الساكنة (يُغطّيه تمرين الأعضاء الساكنة)
- المفهرِسات (يُغطّيه تمرين المفهرِسات)
