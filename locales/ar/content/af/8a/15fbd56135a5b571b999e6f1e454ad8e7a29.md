# مقدمة

سيعلّمك هذا التمرين اللبنات الأساسية للغة Ruby.
يتناول الكثير من الموضوعات، لكن لا تقلق إن بدا الأمر مربكًا، فسنخوض في كل شيء بعمق أكبر بكثير مع تقدّمنا في المسار.

من الأمور الأساسية التي يجب فهمها عن Ruby أنها [لغة كائنية التوجه][object-oriented-programming]، وأن **كل شيء في Ruby هو [كائن][object]**. الأعداد والسلاسل النصية والمصفوفات، كلها كائنات.

## المتغيرات والثوابت

نميل إلى استخدام الكائنات عبر إسناد أسماء إليها، إما باستخدام المتغيرات أو الثوابت.

تُكتب المتغيرات دائمًا بأسلوب [حالة الثعبان][snake-case].
يمكن للمتغير أن يشير إلى كائنات مختلفة على مدار عمره.
على سبيل المثال، يمكن تعريف `my_first_variable` وإعادة تعريفه مرات عديدة باستخدام العامل `=`:

```ruby
my_first_variable = 1
my_first_variable = "Some string"
my_first_variable = SomeComplexObject.new
```

أما الثوابت فيُقصد بها أن تُسند مرة واحدة.
يجب أن تبدأ بحرف كبير، وتُكتب عادةً بحروف كبيرة بالكامل مع فصل الكلمات بشرطات سفلية.
على سبيل المثال:

```ruby
MY_FIRST_CONSTANT = 10

# Redefining not allowed
# MY_FIRST_CONSTANT = "Some String"
```

## الأصناف

تنتظم Ruby في أصناف.
تُعرَّف الأصناف باستخدام الكلمة المفتاحية `class` متبوعة باسم الصنف.
تُنشأ الكائنات عمومًا عن طريق إنشاء نسخة من الصنف باستخدام الطريقة `.new`.
على سبيل المثال:

```ruby
# Define the class
class Calculator
  #...
end

# Create an instance of it and assign it to a variable
my_first_calc = Calculator.new
```

## الطرق

تُغلَّف وحدات الوظائف في طرق، على غرار _الدوال_ في لغات أخرى.

يمكن تعريف الطريقة بوسائط موضعية، أو وسائط مفتاحية (تُعرَّف وتُستدعى باستخدام الصيغة `:`)، أو ألا يكون لها وسائط على الإطلاق.

إما أن تُرجع الطرق ضمنيًا نتيجة آخر عبارة جرى تقييمها، أو يمكنها أن تُرجع كائنًا صراحةً عبر الكلمة المفتاحية `return`.

```ruby
class Calculator

  # Positional arguments
  def add(num1, num2)
    return num1 + num2 # Explicit return
  end

  # Keyword arguments
  def multiply(num1:, num2:)
    num1 * num2 # Implicit return
  end
end
```

تُستدعى الطرق باستخدام صيغة النقطة `.`:

```ruby
calc = Calculator.new
calc.add(1, 3)
calc.multiply(num1: 2, num2: 5)
```
