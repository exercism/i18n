# مقدمة

الأنواع المعتمة في Gleam هي أنواع مخصصة لا يمكن إلا للوحدة التي تعرّف النوع أن تنشئ قيمًا من هذا النوع أو تطابق قيمها بالنمط. وهذا مفيد لإنشاء أنواع ينبغي استخدامها بطريقة محددة فقط.

تُعرَّف الأنواع المعتمة باستخدام الكلمة المفتاحية `opaque`.

```gleam
pub opaque type PositiveInt {
  PositiveInt(inner: Int)
}
```

يُستخدم النوع `PositiveInt` في الحالات التي نحتاج فيها إلى عدد صحيح، لكن يجب أن يكون صفرًا أو أكبر. لا يمكن استخدام `Int` العادي في Gleam، لأن قيم هذا النوع يمكن أن تكون سالبة أيضًا.

يمكن للوحدة التي تعرّف هذا النوع أن تعرّف دالة للحصول على قيمة العدد الصحيح الداخلية، ودالة لإنشاء النوع `PositiveInt` تُرجع خطأً إذا لم تكن القيمة موجبة.

```gleam
pub fn from_int(i: Int) -> Result(PositiveInt, String) {
  case i {
    _ if i < 0 -> Error("Value must be positive")
    _ -> Ok(PositiveInt(i))
  }
}

pub fn to_int(i: PositiveInt) -> Int {
  i.inner
}
```

مع API هذه، لا تستطيع الوحدات الأخرى إنشاء قيمة `PositiveInt` بقيمة سالبة، لذا يمكن لأي دالة تأخذ `PositiveInt` أن تتأكد من أن القيمة موجبة.
