# نبذة

إلى جانب فئات المحارف ومحددات الكمية، تستطيع التعبيرات النمطية وصف *بنية* النص و*سياقه*. وتقع هذه الميزات في المفردات نفسها [`regexp`][regexp]، وتُكتب بالصيغة الحرفية `R/ /`.

## التجميع والتناوب

الأقواس الهلالية `( )` تجمع جزءًا من النمط بحيث ينطبق محدد الكمية أو الرمز `|` («هذا أو ذاك») على المجموعة بأكملها. ووجود `?` بعد المجموعة يجعلها اختيارية:

```factor
USING: regexp ;

"abab"    R/ (ab)+/ matches? .             ! => t
"cat"     R/ cat|dog/ matches? .           ! => t
"$100.50" R/ \$\d+(\.\d{2})?/ matches? .   ! => t
"$100"    R/ \$\d+(\.\d{2})?/ matches? .   ! => t   (group optional)
```

## المراسي

```
^    ! start of the string
$    ! end of the string
\b   ! a word boundary
```

*حد الكلمة* (`\b`) هو الموضع الذي يلتقي فيه محرف من محارف الكلمة (حرف أو رقم أو شرطة سفلية) بمحرف ليس من محارف الكلمة، بما في ذلك طرفا السلسلة النصية. لذا فإن `\bcat\b` لا يطابق `cat` إلا عندما ترد وحدها:

```factor
USING: regexp ;

"cat nap" R/ \bcat\b/ re-contains? .   ! => t
"scatter" R/ \bcat\b/ re-contains? .   ! => f
```

## التطلّع

يختبر *التطلّع* ما يأتي قبل موضع معين أو بعده مباشرةً دون أن يجعل تلك المحارف جزءًا من التطابق، فهو ذو عرض صفري:

```
(?=...)    ! lookahead
(?!...)    ! negative lookahead
(?<=...)   ! lookbehind
```

```factor
USING: regexp ;

"spent $100 and $25" R/ (?<=\$)\d+/ all-matching-subseqs .
! => { "100" "25" }

"up 5% then 12%" R/ \d+(?=%)/ all-matching-subseqs .
! => { "5" "12" }
```

## الخيارات

حرف الخيار بعد الشرطة المائلة الختامية `/` يغيّر النمط بأكمله. و`i` تعني تجاهل حالة الأحرف:

```factor
USING: regexp ;

"REFUND" R/ refund/i matches? .   ! => t
```

## تحويل كل تطابق

تشغّل `map-matches` كتلة برمجية على كل تطابق وتجمع النتائج؛ وتفعل `each-match` الشيء نفسه من أجل الآثار الجانبية فقط. وكلتاهما تمرران إلى الكتلة البرمجية فهرس `start` للتطابق، وفهرس `end`، والسلسلة النصية كاملة، لذا تستعيد `subseq` النص المطابق:

```
map-matches ( string regexp quot: ( start end string -- obj ) -- seq )
each-match  ( string regexp quot: ( start end string --     ) --     )
```

```factor
USING: math regexp sequences ;

"a1 b22 c333" R/ \d+/ [ subseq length ] map-matches .
! => { 1 2 3 }
```

## ما لا يدعمه Factor

لا يملك محرك التعبيرات النمطية في Factor **استخراج المجموعات الالتقاطية** (فالمجموعة `( )` تنظّم النمط لكن لا يمكنك قراءة النص الذي طابقته)، ولا **الإحالات الخلفية** (`\1`)، ولا محدِّدات الكمية **الكسولة/غير الشرهة** (`*?`، `+?`). والتطلّع هو البديل الاصطلاحي للمجموعات الالتقاطية: طابق الجزء الذي تريده، متعرَّفًا عليه من السياق المحيط به.
