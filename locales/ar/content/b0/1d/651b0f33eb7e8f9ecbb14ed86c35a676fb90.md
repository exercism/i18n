# تفضيل ثابت على المستوى الأعلى

فكّر في استخراج العدد `GIGASECOND` إلى ثابت:

```javascript
const %{name} = %{value}

// the rest of your code below it
export const gigasecond = (...)
```

الدوال والأصناف والثوابت التي تكون `export`ed فقط هي التي تكون مرئية ومتاحة من الخارج. ومن المنطقي عادةً أن تُعطي [الأعداد السحرية](https://en.wikipedia.org/wiki/Magic_number_%%28programming%%29) اسمًا، فهذا يحسّن قابلية الصيانة. ويمكن أن تبقى هذه الثوابت في الملف نفسه دون أن تُكشف لأي كود آخر.
