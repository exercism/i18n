# حول

لكل نسخة من بنية أو صنف خاصية ضمنية باسم `self`، وهي تشير إلى النسخة نفسها.
الاستخدام الأكثر شيوعًا لـ `self` هو إزالة الالتباس بين خاصية النسخة ومعامل يحمل الاسم نفسه:

```swift
struct Position {
    var x = 0

    mutating func move(x: Int) {
        // Here, 'self.x' refers to the struct's property,
        // while 'x' refers to the parameter passed to the method.
        self.x = x
    }
}
```

كما توفر أنواع Swift كلمةً مفتاحية `Self` تبدأ بحرف كبير، وتشير إلى *نوع* النسخة وليس إلى النسخة نفسها.
