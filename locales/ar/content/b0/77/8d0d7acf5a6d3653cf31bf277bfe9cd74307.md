# تلميحات لتمرين كاسحة الألغام في Bash

يبدو أن هذا التمرين يتطلب مصفوفة ثنائية الأبعاد.
لا توفر Bash سوى [المصفوفات][array] المفهرسة أو الترابطية أحادية البعد.

يمكن محاكاة المصفوفات متعددة الأبعاد باستخدام مصفوفة ترابطية: رمّز الفهارس في سلسلة نصية تفصل بينها فواصل، ثم استخدمها مفتاحًا للمصفوفة.

```bash
# store this matrix:
#   a b
#   c d
declare -A array2d
array2d["0,0"]="a"
array2d["0,1"]="b"
array2d["1,0"]="c"
array2d["1,1"]="d"
```

[array]: https://www.gnu.org/software/bash/manual/bash.html#Arrays
