# التعليمات

في هذا التمرين ستبني معالجة الأخطاء لآلة حاسبة بسيطة.

الهدف هو الحصول على آلة حاسبة تعمل وتُرجع سلسلة نصية بالصيغة التالية: `16 + 51 = 67`، عند تمرير الوسائط `16` و`51` و`+`.

```ruby
SimpleCalculator.calculate(16, 51, "+")
# => "16 + 51 = 67"
SimpleCalculator.calculate(32, 6, "*")
# => "32 * 6 = 192"
SimpleCalculator.calculate(512, 4, "/")
# => "512 / 4 = 128"
```

## 1. تعامل مع الكود الذي قد يرفع أخطاءً داخل الطريقة `calculate`

الطريقة الرئيسية للتنفيذ في هذه المهمة هي طريقة الصنف `SimpleCalculator.calculate()`.
وهي تأخذ ثلاثة وسائط.
الوسيطان الأولان عددان ستُجرى عليهما العملية.
الوسيط الثالث من النوع سلسلة نصية، ومن الضروري في هذا التمرين تنفيذ العمليات التالية:

- الجمع باستخدام السلسلة النصية `+`
- الضرب باستخدام السلسلة النصية `*`
- القسمة باستخدام السلسلة النصية `/`

## 2. تعامل مع العمليات غير المسموح بها

حدّث الطريقة `SimpleCalculator.calculate()` لترفع استثناء `UnsupportedOperation` عند رموز العمليات غير المعروفة.

```ruby
SimpleCalculator.calculate(1, 2, '-')
# => Raises an UnsupportedOperation
```

~~~~exercism/note
في هذا التمرين، يُتوقع منك تعريف استثناء `UnsupportedOperation` لنطاق محدد.
~~~~

## 3. تعامل مع الوسائط غير الصالحة

حدّث الطريقة `SimpleCalculator.calculate()` لترفع استثناء `ArgumentError` عند أنواع الوسائط غير الصالحة.

```ruby
SimpleCalculator.calculate(1, '2', '*')
# => Raises an ArgumentError
```

## 4. تعامل مع استثناءات القسمة على صفر

حدّث الطريقة `SimpleCalculator.calculate()` لتتعامل مع استثناءات `ZeroDivisionError`.
يجب أن يُرجع كود المعالجة سلسلة نصية تحتوي على `Division by zero is not allowed.`.
ولا ينبغي للطريقة `SimpleCalculator.calculate()` أن تتعامل مع أي استثناء آخر.

```ruby
SimpleCalculator.calculate(512, 0, "/")
# => returns "Division by zero is not allowed."
```
