# مقدمة

## حلقات `while`

باستخدام حلقة `while`، يمكنك تنفيذ الكود بشكل متكرر طالما تحقّق شرط معيّن.
وتُكتب بالكلمة المفتاحية `while` متبوعةً بشرط محاط بالأقواس الهلالية، وبكتلة كود تحتوي على _جسم_ الحلقة محاطة بالأقواس المعقوفة.

```javascript
while (condition) {
  // code that is executed repeatedly as long as the condition is true
}
```

لدى JavaScript أيضًا حلقة `do-while`.
هنا يُفحص الشرط بعد تنفيذ جسم الحلقة.
وهذا مفيد عندما يعتمد الشرط على عمليات تقييم تُجرى داخل الجسم.

```javascript
do {
  // The code here will always be executed once and then
  // repeatedly while the condition is true.
} while (condition);
```

داخل جسم الحلقة، يمكنك استخدام الكلمة المفتاحية `break` لإيقاف تنفيذ الحلقة كليًا.
وعلى العكس من ذلك، فإن الكلمة المفتاحية `continue` توقف تنفيذ الدورة الحالية فقط وتنتقل إلى الدورة التالية.
وباستخدام `continue` يمكنك غالبًا تجنّب تغليف أجزاء كبيرة من جسم الحلقة داخل جملة شرطية.

```javascript
let i = 0;

while (i < 100) {
  i = i + 2;

  if (i % 3 === 0) {
    continue;
  }

  // The code here will only be executed when i was not divisible
  // by 3 in the check above.
}
```

## جمل `switch`

إلى جانب الجملة الشرطية، لدى JavaScript أيضًا جملة `switch` لتنفيذ المنطق بشكل شرطي.
وتُستخدم عندما يلزم مقارنة متغير واحد بعدة حالات مختلفة.
وتتم المقارنة بالتحقق من التساوي الصارم (`===`)، راجع [المقارنة][concept-comparison].
وبالنسبة لمتغير ما `x`، تأخذ جملة `switch` في JavaScript الصيغة التالية.

<!-- prettier-ignore-start -->
```javascript
switch (x) {
  case option1:
    // code that is executed when "x === option1" is true
    break;
  case option2:
    // code that is executed when "x === option2" is true
    break;
  default:
    // code that is executed when x does not equal any of the options
}
```
<!-- prettier-ignore-end -->

حالة `default` اختيارية، وتُستخدم عندما تريد تنفيذ بعض الكود إن لم يطابق المتغير أيًّا من الخيارات الأخرى.

جمل `break` أعلاه ضرورية لأن جميع الحالات "تتساقط" افتراضيًا في JavaScript.
وهذا يعني أنه بدون أي جملة `break` سيُنفَّذ كل الكود في الحالات الواقعة أسفل أول خيار مطابق، حتى لو لم يطابق `x` تلك الخيارات.
وهذا السلوك، أي "التساقط الافتراضي"، خطأ شائع عند استخدام `switch` في JavaScript.
وداخل دالة، يمكن أيضًا استخدام `return` بدلًا من `break` لتجنّب هذه المشكلة.
