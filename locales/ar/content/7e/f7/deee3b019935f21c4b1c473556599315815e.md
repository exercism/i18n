# الدوال في `jq`

يمكنك تعريف **دوال مخصصة** بنفسك في `jq` لتغليف أي منطق تحتاج إليه.
تعمل _الدوال_ تمامًا مثل الدوال المدمجة: فهي تأخذ مدخلًا وتُصدر صفرًا أو واحدًا أو أكثر من المخارج.

## تعريف دالة

يمكنك تعريف _دالة_ في `jq` باستخدام الصياغة التالية:

```jq
# no arguments
def funcname: expression;

# or with arguments
def funcname(args): expression;
```

- يبدأ بالكلمة المفتاحية `def`،
- وجود نقطتين قبل جسم الدالة،
- يتكوّن الجسم من تعبير واحد،
- ينتهي بفاصلة منقوطة،
- وكما في بقية صياغة `jq`، يمكنك استخدام أي قدر من المسافات البيضاء لتحسين القراءة.

## أين تضع الدوال

يجب تعريف _الدوال_ قبل استخدامها: فهذا خطأ:

```jq
def A: B(10);
def B(n): n + 1;
A
# => error: B/1 is not defined
```

وهذا يعني أنه عليك وضع _الدوال_ في أعلى كود `jq`، قبل التعبير «الرئيسي».

### الدوال المتداخلة

يمكن أن تكون _الدوال_ متداخلة:

```jq
def A:
    def B(n): n + 1;
    B(10)
    ;
A
# => 11
```

هنا، _الدالة_ `B` مرئية فقط داخل جسم `A`.

## النطاق

تُنشئ _الدالة_ **نطاقًا** جديدًا للمتغيرات والدوال المتداخلة.

## الوسائط

تُفصل **وسائط** الدالة بـ _الفاصلة المنقوطة_ لا بالفاصلة.
على سبيل المثال، _دالة_ تأخذ عددًا، ثم تضيف إليه عددًا وتضرب في عدد:

```jq
def add_mul(adder; multiplier): (. + adder) * multiplier;

10 | add_mul(5; 4)    # => 60
```

10 | add_mul(5, 4)

### الوسائط هي _تعبيرات_

_وسائط_ الدالة هي مرشحات، وليست قيمًا.
وبهذا المعنى، فهي تعمل مثل ما تصفه اللغات الأخرى بدوال رد النداء:

باستخدام الدالة `add_mul` كمثال:

```jq
10 | add_mul(. + 5; . - 2)    # => 200
```

ما الذي يحدث هنا؟

- يحصل الوسيط `adder` على _التعبير_ `. + 5`
  - فعندما تُجري الدالة `. + adder`، يصبح ذلك `. + . + 5`
  - وهذا يُقيَّم إلى 25 بما أن `. == 10`
- وبالمثل، الوسيط `multiplier` هو التعبير `. - 2`
  - وهذا يُقيَّم إلى 8
  - ثم تكون النتيجة `25 * 8 == 200`

### الوسائط كقيم

أحيانًا قد ترغب في «تجسيد» _الوسيط_ في متغير:

```jq
def my_func(arg):
    arg as $arg
    | other stuff ...
;
```

وهناك اختصار لذلك:

```jq
def my_func($arg):
    other stuff ...
;
```

لاحظ أن هذا مجرد «سكر نحوي»: فاسم `arg` بدون `$` لا يزال داخل النطاق في _الدالة_.

## عدد الوسائط

للدوال **عدد وسائط**، وهو عدد _الوسائط_ التي تأخذها.

يمكن للدوال استخدام الاسم نفسه بأعداد وسائط مختلفة.
وتوضح الدالة المدمجة [`range`][man-range] ذلك: فـ `range/1` و `range/2` و `range/3` تتواجد جميعًا معًا.

قد يكون هذا مفيدًا لتعريف دوال ذاتية الاستدعاء تحمل حالتها عبر الوسائط.
على سبيل المثال، _يمكن_ تنفيذ `map` هكذا:

```jq
def my_map($accumulator; func):
    if length == 0
        then $accumulator
        else first as $elem | .[1:] | my_map($accumulator + [$elem | func]; func)
    end
    ;

def my_map(func):
    my_map([]; func)
    ;

[1, 2, 3, 4] | my_map(. * 10)   # => [10, 20, 30, 40]
```

## الاستدعاء الذاتي

سيُجري `jq` تحسين استدعاء الذيل، لكن للدوال التي لا تأخذ أي وسائط فقط.

## الوحدات

وحدة `jq` هي ملف يحتوي على الدوال فقط.
تُضمّن الوحدات في برنامج jq باستخدام الأمرين [`include`][man-include] أو [`import`][man-import].
