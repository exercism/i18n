# التعليمات

أنت مراقب طيور شغوف يتابع عدد الطيور التي زارت حديقتك خلال الأيام السبعة الماضية.

أمامك ست مهام، وكلها تتعلق بأعداد الطيور التي زارت حديقتك.

## 1. تحقّق من عدد الطيور التي زارت اليوم

نفّذ الدالة `today()` لتُرجع عدد الطيور التي زارت حديقتك اليوم. أعداد الطيور مرتبة حسب اليوم، بحيث يكون العنصر الأول عدد أقدم يوم، والعنصر الأخير عدد اليوم الحالي.

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
today(birds_per_day)
# => 1
```

## 2. زد عدد اليوم

نفّذ الدالة `increment_todays_count()` لزيادة عدد اليوم:

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
increment_todays_count(birds_per_day)
# => c(2, 5, 0, 7, 4, 2)
```

## 3. تحقّق مما إذا كان هناك يوم بلا طيور زائرة

نفّذ الدالة `has_day_without_birds()` التي تُرجع `TRUE` إذا كان هناك يوم لم تزر فيه أي طيور الحديقة؛ وإلا فتُرجع `FALSE`:

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
has_day_without_birds(birds_per_day)
# => true
```

## 4. احسب عدد الطيور الزائرة خلال أول عدد من الأيام

نفّذ الدالة `count_for_first_days()` التي تُرجع عدد الطيور التي زارت حديقتك منذ بداية الأسبوع، لكن اقتصر العدد على عدد الأيام المحدد من بداية الأسبوع.

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
count_for_first_days(birds_per_day, 4)
# => 14
```

## 5. احسب عدد الأيام المزدحمة

بعض الأيام أكثر ازدحامًا من غيرها. اليوم المزدحم هو الذي زارت فيه خمسة طيور أو أكثر حديقتك.
نفّذ الدالة `busy_days()` لتُرجع عدد الأيام المزدحمة:

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
busy_days(birds_per_day)
# => 2
```

## 6. احسب المجموع التراكمي لزيارات الطيور خلال الأسبوع الماضي

أنت فضولي لمعرفة العدد الإجمالي للطيور التي زارت حتى الآن هذا الأسبوع.
احسب المجاميع التراكمية لكل يوم.

```R
running_total(c(7, 6, 5, 4, 3, 2, 1))
#> [1]  7 13 18 22 25 27 28
```

## 7. رتّب أسماء الأيام حسب مدى ازدحامها

تشك أن زيارات الطيور تتأثر بأنماط حركة المرور على الطرق القريبة، فتختلف في عطلة نهاية الأسبوع عنها في أيام الأسبوع.

رتّب اختصارات الأيام بترتيب _تنازلي_ حسب عدد الطيور التي زارت.

```R
day_names <- c("Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun")
birds_per_day <- c(5, 2, 4, 6, 0, 9, 8)
busy_days_of_week(birds_per_day, day_names)
#> [1] "Sat" "Sun" "Thu" "Mon" "Wed" "Tue" "Fri"
```
