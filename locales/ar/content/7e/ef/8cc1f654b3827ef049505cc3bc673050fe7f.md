# مقدمة

لا يمتلك R نوع بيانات منفصلًا للمجموعات، بل يستخدم دوالًا متنوعة لتنفيذ عمليات مشابهة على المتجهات.

يختبر العامل `%in%` عضوية العنصر في المجموعة.

```R
2 %in% 1:10 # TRUE
12 %in% 1:10 # FALSE
```

تشمل الدوال ذات الصلة `unique` (لإزالة التكرارات)، إضافة إلى `union()` و`intersect()` و`setdiff()` و`setequal()` للعمل على أزواج من المجموعات.

```R
> set_1 <- c("a", "b", "c", "b", "a")
> unique(set_1) # deduplicate
[1] "a" "b" "c"

> set_2 <- c('a', "c", "d")
> union(set_1, set_2) # values in either set
[1] "a" "b" "c" "d"

> intersect(set_1, set_2) # values in both sets
[1] "a" "c"

> setdiff(set_1, set_2) # values in set_1 but not set_2
[1] "b"

> setdiff(set_2, set_1) # values in set_2 but not set_1
[1] "d"

setequal(set_1, c("c", "b", "a", "b")) # are elements the same after deduplication?
[1] TRUE
```

في كل حالة، يبقى `set_1` و`set_2` دون تغيير.
