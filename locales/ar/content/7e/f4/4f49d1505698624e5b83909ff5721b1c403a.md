# مقدمة

تأتي Ruby مع مكتبة قياسية (يُختصر اسمها غالبًا إلى "stdlib")، وهي مجموعة من الأصناف للتعامل مع أشياء مثل التواريخ و json والشبكات.
كما توفّر إمكانات مفيدة تجعل التعامل مع الكود أسهل.

`OpenStruct` جزء من المكتبة القياسية، وهو يتيح لك إنشاء كائن من `Hash` بسهولة.
فبدلًا من أن تضطر إلى الوصول عبر مفاتيح `Hash`، يتيح لك `OpenStruct` استخدام الطرق للوصول إلى القيم وضبطها.

عند استخدام أصناف من المكتبة القياسية، أو من أي مكتبة أخرى، تحتاج إلى تحميل ذلك الصنف باستخدام الطريقة `require`.

```ruby
require 'ostruct'

attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

من المزايا الإضافية هنا أنك تستطيع الاستفادة من اختصار عند استخدام صيغة الكتلة.
في الحالات التي تستدعي فيها الكتلة طريقة واحدة، يمكنك استبدال الكتلة بـ `&:` ثم اسم الطريقة.
على سبيل المثال، هذان السطران مترادفان:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```
