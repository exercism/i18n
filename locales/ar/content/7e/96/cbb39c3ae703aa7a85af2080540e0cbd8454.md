# مقدمة

## المصفوفات والمتجهات

توفّر C++ حاويات مختلفة لتخزين عناصر من النوع نفسه بطريقة مرتبة.
توجد `std::array` للحاويات ذات الحجم الثابت، و`std::vector` التي تأتي بإمكانات تغيير الحجم ديناميكيًا.

### الإنشاء

عندما تُعرّف مصفوفة أو متجهًا، فأنت بحاجة إلى تحديد نوع العناصر التي ستضمّها تلك الحاوية.
تحتاج المصفوفات أيضًا إلى حجم.
انظر إلى هذه الأمثلة لترى كيفية تهيئة نوعي الحاويات:

```cpp
#include <array>
#include <string>

// std::array<element_type, size> variable_name {list of elements}
std::array<std::string, 3> indie_rock {"yeah", "yeah", "yeah"};
// indie_rock contains the elements "yeah" three times
```

عادةً ما تحتاج المتجهات إلى مساحة أكبر، لأنها تخصص ذاكرة لنموّ إضافي.
لست بحاجة إلى تحديد حجم:

```cpp
#include <vector>

// std::vector<element_type> variable_name {list of elements}
std::vector<int> countdown {3, 2, 1};
// countdown contains the elements 3, 2 and 1
```

> ملاحظة: لست بحاجة إلى معرفة الآلية الدقيقة وراء مفهوم القوالب بعد، فسيكون له مفهومه الخاص في مكان لاحق من شجرة المنهج.

### الوصول إلى العناصر

المتجهات والمصفوفات تشترك في الدوال نفسها للوصول إلى عناصرها.
يمكنك استخدام الدالتين العضويتين `front` و`back` للحصول على العنصر الأول والأخير في الحاوية.
توجد أيضًا الدالة `at` والعامل `[]` للوصول إلى عناصر محددة.

```cpp
countdown[0];
// => 3
countdown.at(2);
// => 1
countdown[1] = 4;
// countdown now contains 3, 4 and 1
indie_rock.back() = "yeahs";
// indie_rock is now "yeah", "yeah", "yeahs"
```

> ملاحظة: إذا اخترت موضعًا خارج نطاق حاويتك، فقد يؤدي العامل `[]` إلى سلوك غير معرّف.
> أما الدالة `at` فسترفع استثناءً، مما قد يسهّل حياتك على المدى الطويل.

### معدّلات المتجه

بما أنّ `vector` غير ثابت الحجم، فمن الممكن إضافة عناصر أو إزالتها.
دالتان شائعتان لهذا الغرض هما `emplace_back` و`pop_back`.

```cpp
std::vector<std::string> witches {"Holly", "Alyssa", "Shannen"};
witches.pop_back();
// Shannen is no longer with the witches
witches.emplace_back("Rose");
// Rose has joined the team
```

### السعة

يمكنك التحقق من فراغ الحاويات باستخدام الدالة العضوية `empty`.
وإذا أردت معرفة عدد العناصر، يمكنك استخدام `size`.
