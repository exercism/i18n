تُعدّ Raku لغة برمجة غنية ومرنة وقوية إلى حدٍّ كبير. وتتيح مرونتها للمبرمجين كتابة كود تعبيري يناسب أسلوبهم الخاص.

Raku لغة واسعة، وفيها عمق كبير يمكنك تعلّمه واستكشافه والتجريب فيه. ويهدف هذا المنهج إلى تغطية الأساسيات لتنطلق منها.

البرمجة كائنية التوجه في صميم Raku، لكنها لا تفرض ممارسات البرمجة كائنية التوجه. ونظرًا لطبيعتها كائنية التوجه، سيشير هذا المنهج غالبًا إلى [الكائنات والأصناف والطرق][object-orientation].

## المتغيرات

سنستخدم فقط [المتغيرات][variables] القياسية في الأساسيات لتبسيط الأمور.

المتغيرات القياسية هي [معرّفات][identifiers] مسبوقة بعلامة `$`.

يمكن للمتغيرات القياسية أن تحتوي على أي شيء تقريبًا، ونوعها الافتراضي هو [`Any`][Any].

معظم المتغيرات التي ستستخدمها ستحتاج إلى [إعلان][variable-declarator]. في الوقت الحالي، اكتفِ بـ [`my`][my] و[`constant`][constant].

```raku
my $foo;
constant $BAR;
```

## الدوال الفرعية

تُعلَن الدالة الفرعية باستخدام المُعلِن [`sub`][sub-declarator].

يأتي بعد إعلان `sub` [معرّف][identifiers] اختياري، ثم [توقيع][signatures] اختياري، ثم [كتلة][blocks].

يمكن تصدير الدوال الفرعية (من بين أمور أخرى) بإضافة السمة [`is export`][exporting].

يمكن استدعاء دالة فرعية بوضع [عامل لاحق محيط `( )`][postcircumfix-()] بعد المعرّف.

```raku
sub foo ($bar) is export { ... } # Subroutine definition

foo($bar); # Subroutine call
```

## العوامل

تحتوي Raku على تنوّع واسع من [العوامل][operators]. سنستخدم بعض العوامل الرياضية الأساسية في Raku، مثل `+` و`-`، في تمارين مفهوم الأساسيات.

```raku
say 0.1 + 0.2 - 0.3;
# Raku is not like other languages -> https://0.30000000000000004.com/#raku
```

يمكنك بسهولة تعريف عوامل خاصة بك في Raku إذا أردت. كما تتوفّر معظم العوامل المدمجة أيضًا كدوال فرعية.

## الحزم والوحدات

هناك عدة أنواع من [الحزم][package-declarator] في Raku. سنستخدم `module` فقط في الأساسيات.

لإعلان ملف كامل كـ `module`، يُسبَق إعلان الوحدة بـ `unit`.

```raku
unit module Foo;

sub bar () { ... }
```

## التعليقات

توفّر Raku تعليقات [أحادية السطر][single-line-comments] و[متعددة الأسطر/مضمّنة][multi-line-comments].

تبدأ التعليقات أحادية السطر بـ `#` وتستمر حتى نهاية السطر.

تبدأ التعليقات متعددة الأسطر/المضمّنة بعلامة `#` يتبعها اقتباس خلفي ثم محرف فتح من محارف علامات الترقيم في يونيكود. وتنتهي بمحرف إغلاق مطابق يقابله.

```raku
# This is a single-line comment

#`(
    This is a
    multi-line/embedded comment
)
```

## اصطلاحات التنسيق

تُكتب [معرّفات][identifiers] المتغيرات والدوال الفرعية في Raku بأسلوب `kebab-case`. وتُكتب الثوابت بأسلوب `ALL-CAPS`. وتُكتب أسماء الحزم بأسلوب `PascalCase`.
