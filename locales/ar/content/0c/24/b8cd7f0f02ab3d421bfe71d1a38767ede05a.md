# نبذة

[المعامل الشرطي الثلاثي][ternary-operator] صيغة مختصرة موجزة للتعبير `if-else`.
فهو يُقيّم شرطًا ويُرجع إحدى قيمتين حسب كون هذا الشرط `true` أو `false`.

يستخدم هذا المعامل ثلاثة أجزاء: `condition ? trueExpression : falseExpression`.
إذا قُيِّم `condition` إلى `true`، قُيِّم `trueExpression` وأُرجع؛ وإلا قُيِّم `falseExpression` وأُرجع.

المعامل الثلاثي مثالي للاختيارات البسيطة التي تُكتب في سطر واحد:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = showFahrenheit ? temperatureInCelsius * 9 / 5 + 32 : temperatureInCelsius
print(temperature)
// Prints 86
```

المثال أعلاه مكافئ مختصر لـ:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = if showFahrenheit {
    temperatureInCelsius * 9 / 5 + 32
} else {
    temperatureInCelsius
}
```

[ternary-operator]: https://docs.swift.org/swift-book/LanguageGuide/BasicOperators.html#ID71
