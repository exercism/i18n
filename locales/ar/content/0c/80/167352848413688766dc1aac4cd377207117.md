# نبذة

الاستدعاء الذاتي طريقة لتكرار الكود داخل دالة عن طريق استدعاء الدالة لنفسها.
وهو أسلوب آخر لعمل الحلقات والتكرار. وكما في الحلقات، ينبغي أن تختبر الدالة تعبيرًا منطقيًا لتعرف متى تنتهي.
وعلى خلاف الحلقات، فإن الاستدعاء الذاتي الذي لا ينتهي لن يعمل إلى ما لا نهاية.
وقد تُوضع القيم المستخدمة في كل استدعاء للدالة في إطار خاص بها على المكدس.
وإذا شغل عدد استدعاءات الدوال مساحة أكبر من المساحة المتاحة على المكدس، فسينتج عن ذلك خطأ تجاوز سعة المكدس.

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return i;
    printf("The number is %i\n", i++);
    printIncrement(i, maxValue);
}

int main() {
    printIncrement(1, 2);
    printf("After recursion");
    return 0;
}
```

سيُخرج هذا

```
The number is 1
The number is 2
After recursion
```

قد تكون هناك بعض الحالات التي تكون أكثر وضوحًا أو أسهل في الفهم عند التعبير عنها بالاستدعاء الذاتي مما هي عليه عند التعبير عنها بالحلقات.


## الاستدعاء الذيلي

الاستدعاء الذيلي هو أن تكون آخر عبارة في الدالة مجرد استدعاء للدالة نفسها ولا شيء غير ذلك.

الاستدعاء الذيلي شكل خاص من الاستدعاء الذاتي، وقد يسمح للمُصرِّف بتحويل الاستدعاء الذاتي إلى حلقة في الكود المُصرَّف.
وهذا يجمع بين أفضل ما في الأمرين: وضوح الاستدعاء الذاتي وأداء الحلقة.
ويُسمى تحويل الاستدعاء الذاتي إلى حلقة `tail call elimination` أو `tail call optimization.`

عندما يُصرَّف استدعاء ذيلي إلى حلقة، لا يُنشأ إطار مكدس جديد عند كل استدعاء للدالة.
ويُمرَّر إلى عنوان الدالة في موضع استدعائها الأصلي القيمُ المحدَّثة، ما يوفّر مساحة المكدس ويحسّن الأداء.

هذا المثال ليس استدعاءً ذيليًا، لأن الدالة تضيف 1 إلى ناتج استدعائها لنفسها

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return 1;
    printf("The number is %i\n", i++);
    return 1 + printIncrement(i, maxValue);
}

int main() {
    int j = printIncrement(1, 2);
    printf("j is %i after recursion", j);
    return 0;
}
```

سيُخرج هذا

```
The number is 1
The number is 2
j is 3 after recursion
```

لإعادة صياغته كاستدعاء ذيلي، اجعل `j` أحد معاملات `printIncrement`

```c
int printIncrement (int i, int maxValue, int j){
    if (i > maxValue) return j;
    printf("The number is %i\n", i++);
    return printIncrement(i, maxValue, ++j);
}

int main() {
    int j = printIncrement(1, 2, 1);
    printf("j is %i after recursion", j);
    return 0;
}
```

قد تجد أن الاستدعاء الذيلي أسهل في الفهم من استدعاء ذاتي ليس ذيليًا.
لكن المُصرِّفات لا تضمن عادةً أن تُحسَّن جميع الاستدعاءات الذيلية.
ومن المهم دائمًا عند استخدام الاستدعاء الذاتي أن تعرف أن عدد التكرارات لن يكون كبيرًا لدرجة تفيض فيها المكدس.
