# مقدمة

في Go، الـ `struct` عبارة عن تتابع من عناصر مسماة تُسمّى _حقولًا_، ولكل حقل اسم ونوع. يجب أن يكون اسم الحقل فريدًا داخل الـ `struct`. ويمكن مقارنة الـ `struct` بـ _الأصناف_ في نمط البرمجة الكائنية التوجه.

## تعريف `struct`

تُنشئ `struct` جديدة باستخدام الكلمتين المفتاحيتين `type` و `struct`، وتحدّد صراحةً أسماء الحقول وأنواعها.
على سبيل المثال، نعرّف هنا `struct` باسم `Shape`، يحمل اسم الشكل وحجمه:

```go
type Shape struct {
    name string
    size int
}
```

تتبع أسماء الحقول في الـ `struct` عُرف Go، فالحقول التي يبدأ اسمها بحرف صغير لا تكون مرئية إلا للكود الموجود في الحزمة نفسها، أما الحقول التي يبدأ اسمها بحرف كبير فتكون مرئية في الحزم الأخرى.

## إنشاء نسخ من `struct`

بعد تعريف الـ `struct`، تحتاج إلى إنشاء نسخة جديدة وتحديد الحقول بأسمائها وبأي ترتيب تريده:

```go
s := Shape {
    name: "Square",
    size: 25,
}
```

لقراءة حقول النسخة أو تعديلها، استخدم صيغة `.`:

```go
// Update the name and the size
s.name = "Circle"
s.size = 35
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 35
```

الحقول التي لم تُسنَد إليها قيمة ابتدائية تأخذ القيمة الصفرية لنوعها.
على سبيل المثال:

```go
s := Shape{name: "Circle"}
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 0
```

يمكنك إنشاء نسخة من `struct` دون استخدام أسماء الحقول، ما دمت تعرّف الحقول _بالترتيب_:

```go
s := Shape {
	"Oval",
	20,
}
```

لكن هذه الصيغة تُعتبر _كودًا هشًا_ لأنها قد تتعطل عند إضافة حقل، خصوصًا إذا كان الحقل الجديد من نوع مختلف.
في المثال التالي نضيف حقلًا إضافيًا إلى `Shape`:

```go
type Shape struct {
	name        string
	description string // new field 'description' added
	size        int
}

s := Shape{
    "Circle",
    20,
}
// Since the second field of the struct is now a string and not an int,
// the compiler will throw an error when compiling the program:
// Output: cannot use 20 (type untyped int) as type string in field value
// Output: too few values in Shape{...}
```

## دوال `New`

أحيانًا يكون من الجيد أن تكون لدينا دوال تساعدنا في إنشاء نسخ من الـ `struct`.
بحسب العُرف، تُسمّى هذه الدوال عادةً `New` أو تبدأ أسماؤها بـ `New`، ولكن بما أنها دوال عادية فحسب، فيمكنك تسميتها بأي اسم تريد.
قد تُذكّرك بالدوال البانية في لغات أخرى، لكنها في Go دوال عادية فحسب.

في المثال التالي، تُستخدم إحدى دوال `New` هذه لإنشاء نسخة جديدة من `Shape` وضبط قيمة افتراضية تلقائيًا لحقل `size` في الشكل:

```go
func NewShape(name string) Shape {
	return Shape{
		name: name,
		size: 100, //default-value for size is 100
	}
}

NewShape("Triangle")
// => Shape { name: "Triangle", size: 100 }

```

قد يكون لاستخدام دوال `New` المزايا التالية:

* التحقق من القيم المُعطاة
* التعامل مع القيم الافتراضية
* بما أن دوال `New` تُعرَّف غالبًا في الحزمة نفسها التي تحتوي على الـ `struct` الذي تُهيّئه، فإنها تستطيع تهيئة حتى الحقول الخاصة في الـ `struct`

للتعمّق أكثر في هذا النوع، يمكنك الاطلاع على هذه المصادر: [Go by Example: Structs][go-by-example-structs]، [A Tour of Go: Structs][tour-of-go-structs] أو [Structures in Go (structs)][medium-structures-in-go]

## الدالة المدمجة `new`

هناك طريقة أخرى لإنشاء نسخة جديدة من الـ `struct`، وهي استخدام الدالة المدمجة `new`:

```go
s := new(Shape) // s will be of type *Shape (pointer to shape)
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name:  size: 0
```

في هذا المثال، تُنشئ `new` نسخة من الـ `struct` المسمّى `Shape` مع تهيئة جميع القيم إلى القيمة الصفرية لنوعها، وتُرجع مؤشرًا إليها.

~~~~exercism/note
في معظم الحالات، لن ترى نسخًا جديدة من الـ `struct` تُنشأ باستخدام الدالة المدمجة `new`.
فضّل دائمًا استخدام الكتابة الحرفية للـ `struct`، أو دالة `New` مخصّصة، أو أي دالة أخرى توفّرها الحزمة ويمكنها مساعدتك في بناء `struct`.
ولا تلجأ إلى الدالة المدمجة `new` لإنشاء نسخ جديدة من الـ `struct` إلا كحل أخير.
~~~~
