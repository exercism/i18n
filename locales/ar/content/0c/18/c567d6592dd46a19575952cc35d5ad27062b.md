# التعليمات

توري صحفية متخصصة في شؤون المناخ، وتريد كتابة مقال عن الطقس في مدن مختلفة. لديها بيانات عن الطقس في مدن مختلفة وتريد ترتيبها حسب درجة حرارتها، لكن بعض درجات الحرارة بالفهرنهايت وبعضها بالمئوية. إنها تحتاج إلى مساعدتك لتحويل درجات الحرارة إلى الوحدة نفسها ثم ترتيبها.

## 1. حوّل الفهرنهايت إلى مئوية

عرّف الدالة `fahrenheit_to_celsius` التي تأخذ درجة حرارة بالفهرنهايت كوسيط وتُرجع درجة الحرارة بالمئوية.

لتحويل الفهرنهايت إلى مئوية، اطرح 32 من قيمة الفهرنهايت، ثم اقسم الناتج على 1.8.

```gleam
fahrenheit_to_celsius(72.5)
// -> 22.5
```

## 2. قارن بين درجتي حرارة

عرّف الدالة `compare_temperature` التي تأخذ درجتي حرارة وتُرجع قيمة `Order` تشير إلى ما إذا كانت درجة الحرارة الأولى أقل من الثانية أو مساوية لها أو أكبر منها.

```gleam
compare_temperature(Celsius(30.5), Fahrenheit(82.1))
// -> Gt
```

## 3. رتّب المدن حسب درجة الحرارة

عرّف الدالة `sort_cities_by_temperature` التي تأخذ مصفوفة مدن وتُرجعها من الأبرد إلى الأدفأ.

```gleam
sort_cities_by_temperature([
  City(name: "London", temperature: Celsius(30.5)),
  City(name: "Paris", temperature: Fahrenheit(82.1))
])
// -> [
//   City(name: "Paris", temperature: Fahrenheit(82.1)),
//   City(name: "London", temperature: Celsius(30.5)))
// ]
```
