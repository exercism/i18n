# مقدمة

توفّر Swift عبارات نقل التحكم لتغيير مسار تنفيذ الحلقات وعبارات `switch`.
وإلى جانب `return`، تتضمن Swift `continue` و`break` وتسميات الحلقات و`fallthrough`.

## Continue

تُخبر عبارة `continue` الحلقةَ بالتوقف عن تنفيذ التكرار الحالي والبدء بالتكرار التالي فورًا.
في حلقة `while` أو `repeat-while`، تنتقل مباشرةً إلى فحص الشرط.
وفي حلقة `for-in`، تنتقل إلى العنصر التالي في التسلسل.

```swift
var count = 1
while count < 6 {
    count += 1
    if count == 4 {
        continue
    }
    print(count)
}

// Prints:
// 2
// 3
// 5
// 6
```

## Break

تخرج عبارة `break` من الحلقة كاملةً أو من عبارة `switch` فورًا.
ويستأنف التنفيذ من أول سطر من الكود يأتي بعد الحلقة أو عبارة `switch`.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    if !fruit.count.isMultiple(of: 2) {
        break
    }
    print(fruit)
}

// Prints:
// banana
// grapes
```

## العبارات ذات التسميات

في الحلقات المتداخلة، قد ترغب في أن يؤثر `break` أو `continue` في حلقة خارجية بدلًا من الحلقة الداخلية.
يمكنك تسمية الحلقة بوضع اسم متبوع بنقطتين (`labelName:`) قبلها.
ثم يمكنك تمرير تلك التسمية إلى `break` أو `continue`:

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    print("\n--- \(fruit) ---")
    for letter in fruit {
        guard letter != "n" else {
            break outerLoop
        }
        print(letter)
    }
}

// Prints:
// --- banana ---
// b
// a
```
