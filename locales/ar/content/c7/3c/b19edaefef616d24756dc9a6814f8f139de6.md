## الصف

تُستخدم [الصفوف][tuple] عادةً لتجميع المعلومات، وتختلف عن المصفوفات في أنها ثابتة الحجم ويمكنها أن تحمل أنواع بيانات مختلفة.
تُنشأ الصفوف باستخدام الأقواس المعقوفة، `()`، وغالبًا ما تُستخدم لإرجاع عدة قيم من دالة.

```haskell
tuple = (1, "abc", False)
```

يكون هذا مفيدًا عندما تريد، على سبيل المثال، تخزين إحداثي في فضاء ثنائي الأبعاد، فتعرف حينها أن الصف سيحتوي دائمًا على عنصرين، وهما الإحداثي x والإحداثي y.

```haskell
coordinate = (3, 4)
```

### الوصول إلى العناصر

كثيرًا ما تتعامل مع صفوف قصيرة، ويمكنك الوصول إلى عناصرها باستخدام الدالتين `fst` و `snd`.

```haskell
x = fst coordinate
-- x = 3
y = snd coordinate
-- y = 4
```

## مطابقة الأنماط

عند كتابة دوال Haskell، يمكننا الاستفادة من [أسلوب تأكيدي][assertive-style] مع [مطابقة الأنماط][pattern-match-doc]:
مطابقة الأنماط ميزة قوية جدًا في Haskell تتيح لك المطابقة على بواني البيانات وربط المتغيرات بالقيم الموجودة داخلها.
وكما يوحي الاسم، فإن ما نفعله هو مطابقة القيم مع الأنماط، وإذا طابقت القيمة النمط، أمكننا ربط المتغيرات بالقيم الموجودة داخل النمط.
وتتكوّن مطابقة الأنماط أساسًا من هذه المفاهيم: التعرّف على القيم، وربط المتغيرات، وتفكيك القيم.

خُذ هذه الدالة على سبيل المثال:

```haskell
lucky :: Int -> String
lucky 7 = "Lucky number seven!"
lucky x = "Sorry, you're out of luck, pal!"
```

لدينا هنا دالة `lucky` تأخذ `Int` وتُرجع `String`.
عرّفنا للدالة نمطين، أحدهما يطابق العدد `7` والآخر يطابق أي عدد آخر، ويمكن أن يكون الاسم أي شيء (طالما يتبع اصطلاح التسمية في Haskell)، لكننا نستخدم `x` هنا.
إذا كان العدد `7`، فستُرجع الدالة `"Lucky number seven!"`، وإلا فستُرجع `"Sorry, you're out of luck, pal!"`.
وما يهم ملاحظته هنا أن الأنماط تُفحص من الأعلى إلى الأسفل، فلو بدّلنا ترتيب النمطين، لكانت الدالة تُرجع دائمًا `"Lucky number seven!"`.

### أنماط المصفوفات

من الأنماط الشائعة جدًا المطابقة على المصفوفات، أي أخذ رأس المصفوفة وذيلها.
وذلك لأن طبيعة المصفوفة أنها بنية مترابطة العناصر.
وإليك مثالًا لدالة تُرجع رأس المصفوفة وذيلها:

```haskell
headAndTail :: [Int] -> (Int, [Int])
headAndTail [] = error "Can't call head on an empty list"
headAndTail (x:xs) = (x, xs)
```

لدينا نمطان هنا: نمط يطابق مصفوفة فارغة، ونمط يطابق مصفوفة فيها عنصر واحد على الأقل.
وذلك لأننا إذا كانت المصفوفة فارغة، نحتاج إلى حالة خاصة بها، وإلا فسنحصل على خطأ أثناء التنفيذ.
وإذا لم تكن المصفوفة فارغة، يمكننا مطابقة رأسها مع `x` وذيلها مع `xs`.
ويتم ذلك باستخدام العامل `:` (cons)، الذي يُستخدم لإضافة عنصر إلى مقدمة المصفوفة.
لكنه في مطابقة الأنماط يتيح لنا تفكيك المصفوفة إلى رأس وذيل، أي أنه يفعل العكس تمامًا.

الاسم `xs` شائع لذيل المصفوفة، فهو يبرز أنها مصفوفة، أما إذا كنت تتعامل مع مصفوفة متداخلة، فيمكنك استخدام `xss` لإبراز أنها مصفوفة من المصفوفات.

### أنماط الصفوف

كما هو الحال مع المصفوفات، يمكننا أيضًا المطابقة على الصفوف.
وإليك مثالًا لدالة تأخذ صفًا وتُرجع العنصرين الأول والثاني:

```haskell
sumTuple :: (Int, Int) -> Int
sumTuple (x, y) = x + y
```

لدينا هنا نمط يطابق صفًا مكوّنًا من عنصرين، العنصر الأول مربوط بـ `x` والعنصر الثاني مربوط بـ `y`.

### أنماط البدل

أحيانًا لا تهمّنا قيمة متغير ما، بل نريد فقط المطابقة على النمط.
وهنا يأتي دور نمط البدل، ويُشار إليه بشرطة سفلية `_`.

وإليك مثالًا لدالة تُرجع العنصر الأول من مصفوفة:

```haskell
head' :: [Int] -> Int
head' [] = error "Can't call head on an empty list"
head' (x:_) = x
```

نقول هنا إننا لا نحتاج إلى ذيل المصفوفة، لذا نستخدم نمط البدل لتجاهله.

### أنماط الأنواع

يمكننا أيضًا المطابقة على الأنواع، ويتم ذلك باستخدام باني هذا النوع.
ويمكننا أيضًا استخراج قيم من النوع، كما فعلنا مع الصفوف.

```haskell
data AccountType = Guest | User String 

greet :: AccountType -> String
greet Guest = "Welcome, guest!"
greet (User name) = "Welcome, " ++ name ++ "!"
```

في النمط الأول نطابق الباني `Guest`، وفي النمط الثاني نطابق الباني `User` ونربط القيمة الموجودة داخله بـ `name`.

[tuple]: https://hackage.haskell.org/package/base/docs/Data-Tuple.html
