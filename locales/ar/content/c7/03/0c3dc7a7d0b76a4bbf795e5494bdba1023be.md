# ملحق التعليمات

## الكلمات

عرّف صفًّا باسم `robot` له خانات `x` و`y` و`direction`. وتحمل خانة `direction` أحد الرموز `north` أو `east` أو `south` أو `west` (المعرّفة في مفردات هذا التمرين).

- `<robot> ( x y direction -- robot )`: لإنشاء روبوت.
- `move ( robot instructions -- robot )`: تطبّق سلسلة نصية مكوّنة من تعليمات `R` و`L` و`A` وتُرجع الروبوت المحدَّث.
