## المحررات

### مجانية ومفتوحة المصدر

- [VS Code](https://code.visualstudio.com)

  VS Code محرر أكواد مفتوح المصدر. يمكنك أن تجد معلومات عن كيفية إعداد TypeScript [هنا](https://code.visualstudio.com/docs/languages/typescript). VS Code محرر شائع لـ TypeScript لأن Microsoft تُطوّر كليهما: VS Code و TypeScript، لذا فهو يعمل جيدًا مع اللغة؛ كما يدعم TypeScript دون أي إعداد إضافي. بل إن VS Code نفسه كُتب باستخدام TypeScript!

  من المشكلات الشائعة مع VS Code و TypeScript أن تختلف نسخة المحرر عن نسخة المشروع، وهذا قد يجعل VS Code يعرض رسالة خطأ مربكة. تجد تعليمات التعامل مع هذا الخطأ [هنا](https://code.visualstudio.com/docs/typescript/typescript-compiling#_using-newer-typescript-versions).

### بترخيص مدفوع

- [Sublime Text](https://www.sublimetext.com)

  Sublime Text محرر أكواد شائع يدعم معظم اللغات عبر إضافات يمكن تثبيتها. تجربته مجانية، لكن ستُطالب بانتظام بشراء ترخيص تبلغ تكلفته حاليًا 70 دولارًا أمريكيًا.

- [WebStorm](https://www.jetbrains.com/webstorm/)

  WebStorm بيئة تطوير متكاملة (IDE) غنية بالمزايا لـ JavaScript و TypeScript. يدعم TypeScript دون أي إعداد إضافي، ويضم اختبارًا وتصحيحًا للأخطاء وتحليلًا للكود. تجربته مجانية لمدة 30 يومًا، ثم يكلف الترخيص السنوي 129 دولارًا أمريكيًا في السنة الأولى.
