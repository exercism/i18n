# المصفوفات

المصفوفات في PHP هي خرائط مرتّبة.
الخريطة بنية بيانات تربط مفتاحًا بقيمة.
المصفوفات مرنة ويمكن التعامل معها كمصفوفة خطية (كما في `C` أو `Java`)، أو قائمة [متجه]، أو جدول تجزئة، أو قاموس، أو مجموعة، أو مكدس، أو طابور.

المفتاح اختياري، لكنه إذا حُدِّد فيجب أن يكون إما `int` أو `string`.
وعندما لا يُحدَّد مفتاح، يستخدم PHP افتراضيًا مفاتيح من الأعداد الصحيحة بترتيب متزايد يبدأ من `0`.

```php
$no_keys = ["my", "first", "array"];
$integer_keys = [0 => "my", 1 => "first", 2 => "array"];

$no_keys == $integer_keys // => equal returns true
$no_keys === $integer_keys // => strictly equal returns true
```

يمكن للمصفوفة أن تخزّن قيمًا من جميع الأنواع.
ويمكن أن يكون لكل قيمة نوع مختلف.

## استخدام المصفوفات

يمكن الإعلان عن المصفوفات كتعبير حرفي (مكتوب في الكود، كما فعلنا أعلاه) أو إنشاؤها والتعامل معها عبر الدوال.
يمكنك الوصول إلى القيم وإسنادها وإضافتها باستخدام عامل الفهرس:

```php
$prime_numbers = [2, 3, 5, 6];

$prime_numbers[3] = 7; // replace 6 with 7

$prime_numbers[] = 11; // array now contains [2, 3, 5, 7, 11]
```
