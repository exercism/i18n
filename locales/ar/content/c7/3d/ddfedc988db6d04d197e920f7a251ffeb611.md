كتل الكود مستخدمة بحرية في Raku.
فهي أساسية للدوال، لكنها تُستخدم أيضًا في أدوات مثل `grep` و`map`، وكتل لعبارات `if` و`for` و`while` و`given`، وحتى في فهارس المصفوفات.

## الإجراءات

إن [`Subs`][type/Sub] و[`Methods`][type/Method] نوعان من [`Routines`][type/Routine] في Raku.

يمكن إنهاء الإجراء في أي وقت بقيمة إرجاع باستخدام الكلمة المفتاحية [`return`][control-return]، وهي أداة مفيدة لإنشاء الدوال.
وإذا لم يُحدَّد `return`، فستكون العبارة الأخيرة في الإجراء هي قيمة إرجاعه الضمنية.

ويمكن أن يحتوي الإجراء على [`Signature`][language/signatures] داخل الأقواس الهلالية قبل كتلة الكود.

[`Routine`][type/Routine] صنف فرعي من [`Block`][type/Block].

```raku
sub add ($x, $y --> Int) { return $x + $y }
say add(1, 2); # 3
```

سنغطي الطرق في مفهوم منفصل يتعلق بالأصناف والكائنات.

## الكتل

[`Block`][type/Block] كائن كود قابل لإعادة الاستخدام، يُستخدم عادةً لإنشاء دوال لامدا.

العبارة الأخيرة في الكتلة هي قيمة إرجاعها الضمنية.

ويمكن أن تحتوي الكتلة على [`Signature`][language/signatures] مسبوقة بـ `->` قبل كتلة الكود.

[`Block`][type/Block] صنف فرعي من [`Code`][type/Code]، وهو الصنف الأساسي الأسمى لكل كائنات الكود في Raku.

```raku
my $add = -> $x, $y { $x + $y };
say $add(1, 2); # 3
```

## التوقيعات

يتكوّن [`Signature`][language/signatures] من صفر أو أكثر من [`Parameters`][type/Parameter]، تفصل بينها فواصل.

وفي نهاية التوقيع، يمكن تحديد نوع الإرجاع باستخدام [سهم نوع الإرجاع][signatures-return-type-arrow] `-->`.

ويمكن استخدام التوقيع لتحديد الوسائط التي ستقبلها `Block`.

سيبقي هذا المفهوم التوقيعات بسيطة، فسيستخدم فقط معاملات موضعية بمتغيرات ذات علامة عددية، ونوع إرجاع.
وسنوسّع هذه النقاط في مفاهيم أخرى.

## الإرسال المتعدد

يتيح Raku كتابة عدة إجراءات بالاسم نفسه لكن بتوقيعات مختلفة باستخدام الكلمة المفتاحية `multi`.
تُعرف هذه الميزة باسم [الإرسال المتعدد][multi-dispatch].
وعندما يُستدعى الإجراء باسمه، تحدّد بيئة التشغيل المرشح المناسب وتستدعيه.

وسنغطي هذا بمزيد من التفصيل في مفهوم عن الأنواع.

```raku
multi foo () { say 'No arguments given'}

multi foo ($bar) { say "One argument given: $bar" }
```

## WhateverCode

عندما تُستخدم نجمة [`Whatever`][type/Whatever]، أي `*`، مع معظم العوامل، يُنشأ كائن [`WhateverCode`][type/WhateverCode].
وهذا يتيح لك إنشاء كتل بصيغة أبسط.

```raku
# These will all give code blocks that increment a single argument by 1:
-> $x { $x  + 1 }; # Explicit signature
      { $^x + 1 }; # Signature via placeholder variable
      { $_  + 1 }; # Topic variable
          * + 1;   # WhateverCode
```
