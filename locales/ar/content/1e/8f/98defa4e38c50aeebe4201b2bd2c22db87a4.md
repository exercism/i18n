# التعليمات

أوكل إليك قسم المطالبات في Isaac's Asteroid Exploration Co. مهمة تحسين أداء نظام المطالبات بالأراضي الخاص بالشركة.

في كل مرة يصبح كويكب جاهزًا للاستغلال، يُدعى المضاربون إلى تسجيل مطالبتهم بقطعة أرض.
تُقسَّم أرض الكويكب إلى قطع مستطيلة غير متداخلة.
تختلف أبعادها، لكن أضلاعها جميعًا موازية لمحاور الإحداثيات.
ويطالب المضاربون بإحدى قطع الأرض بتحديد إحداثياتها.

هدفك هو تطوير نظام عالي الأداء للتعامل مع التهافت على الأراضي الذي سبق أن تسبّب في تعطّل الموقع.

وحدة القياس هي 100 متر، لكن يمكن تجاهلها في هذه المهام.

## 1. عرّف نقطة

عرّف `struct` لتخزين الإحداثيين `x` و `y`.
هذان عددان صحيحان غير سالبان وصغيران نسبيًا، لذا استخدم النوع `UInt16`.

```julia-repl
julia> Coord(7, 3)
Coord(0x0007, 0x0003)  # unsigned integers display in hex format by default
```

## 2. عرّف قطعة أرض

لأن جميع القطع يجب أن تكون مستطيلة، بأضلاع أفقية ورأسية، فلا يلزم إلا ركنان متقابلان لتعريفها.

نفّذ بنية `Plot`، على أن تأخذ بنيتَي `Coord` في الباني الخاص بها.

يجب أن تكون `Plot` بنية بكلمات مفتاحية، بحقلَي `bottom_left` و `top_right`.

```julia-repl
julia> plot = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2))
Plot(Coord(0x000a, 0x0001), Coord(0x0014, 0x0002))

julia> plot.top_right
Coord(0x0014, 0x0002)
```

## 3. تحقق مما إذا كانت مطالبتك قد سُجّلت بالفعل

هناك منافسة على هذه المطالبات، لذا قبل قبول مطالبتك ستُقارَن بالمطالبات الموجودة في السجل.

نفّذ الدالة `is_claim_staked()` لتحديد ما إذا كانت المطالبة قد سُجّلت من قبل.

```julia-repl
julia> claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));
julia> register = Set{Plot}();
julia> is_claim_staked(claim, register)
false
```

## 4. يمكن للمضاربين تسجيل مطالبتهم بتحديد قطعة أرض تُعرَّف بإحداثيات ركنيها

نفّذ الدالة المعدِّلة `stake_claim!()` للسماح بتسجيل المطالبة.

إذا كانت المطالبة نفسها قد سُجّلت من قبل، فأرجِع `false`.

إذا كانت هناك مطالبة جديدة ممكنة، فأضفها إلى السجل وأرجِع `true`.

```julia_repl
julia> claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));
julia> register = Set{Plot}();
julia> stake_claim!(claim, register)
true
```

## 5. جِد طول الضلع الأطول في قطعة الأرض.

نفّذ الدالة `get_longest_side()` للحصول على الضلع الأطول (الأفقي أو الرأسي) في المطالبة.

```julia-repl
claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));

julia> get_longest_side(claim)
0x000a
```

## 6. جِد القطعة المُطالَب بها ذات الضلع الأطول، لأغراض بحثية

نفّذ الدالة `get_claim_with_longest_side()` لفحص جميع المطالبات المسجّلة وإرجاع المطالبة (أو المطالبات) ذات الضلع الأطول.

```julia-repl
julia> plot1 = Plot(bottom_left=Coord(5, 3), top_right=Coord(10, 5));
julia> plot2 = Plot(bottom_left=Coord(0, 0), top_right=Coord(3, 3));
julia> register = Set{Plot}([plot1, plot2]);

julia> get_claim_with_longest_side(register)
Plot(Coord(0x0005, 0x0003), Coord(0x000a, 0x0005))
```

أرجِع القطعة (أو القطع) على شكل `Set`، بعنصر واحد إذا كانت هناك قطعة واحدة ذات ضلع أطول، وبعدة عناصر في حال التعادل.
