# مقدمة

## الفيض

يحدث الفيض الحسابي عندما يؤدي حساب، مثل عملية حسابية أو تحويل نوع، إلى قيمة أكبر من سعة النوع المستقبِل.

ستلتف تعبيرات من النوع `int` و`long` ونظيراتها غير الموقعة بصمت في هذه الظروف.

يمكن تعديل سلوك حسابات الأعداد الصحيحة باستخدام الكلمة المفتاحية `checked`. عندما يحدث فيض داخل كتلة `checked`، يُطرح مثيل من `OverflowException`.

```csharp
int one = 1;
checked
{
    int expr = int.MaxValue + one;   // OverflowException is thrown
}

// or

int expr2 = checked(int.MaxValue + one);     // OverflowException is thrown
```

ستأخذ تعبيرات من النوع `float` و`double` قيمة خاصة هي اللانهاية.

ستطرح تعبيرات من النوع `decimal` مثيلًا من `OverflowException`.
