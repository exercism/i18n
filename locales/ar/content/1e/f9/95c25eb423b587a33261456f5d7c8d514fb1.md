# حول

اكتب كودًا يُقرأ كما تُقرأ اللغة الإنجليزية العادية.

يعمل Visual Basic على بيئة تشغيل .NET نفسها التي يعمل عليها C# وF#.
فستحصل على LINQ والأدوات العامة (generics) وasync/await، لكن بناء الجملة مصمّم ليُقرأ لا ليُفكّ شفرته.

إذا كنت تعرف C# أو F# بالفعل، فستجد بيئة تشغيل .NET ومكتباتها مألوفة.
وإذا كنت تعرف VB6 أو VBA أو VBScript، فإن بناء الجملة المألوف لديك يستند الآن إلى بيئة تشغيل .NET التي صقلتها تجربة طويلة.

لا أقواس معقوفة عليك أن توازنها، ولا فواصل منقوطة عليك أن تلاحقها.
