# مقدمة

لا تحتوي لغة R على نوع منفصل للمجموعة، بل تستخدم مجموعة متنوعة من الدوال لإجراء عمليات مشابهة على المتجهات.

يختبر العامل [`%in%`][ref-match] العضوية في المجموعة.
هذا العامل البيني مرادف للدالة `is.element()`.

```R
2 %in% 1:10 # TRUE
12 %in% 1:10 # FALSE
```

تشمل الدوال ذات الصلة:

- [`unique()`][ref-unique] لإزالة التكرارات.
- [`union()`][ref-sets] لدمج المجموعات (رياضيًا، `A ∪ B`).
- [`intersect()`][ref-sets] لإيجاد العناصر المشتركة بين المجموعتين (`A ∩ B`).
- [`setdiff()`][ref-sets] لطرح مجموعة من مجموعة أخرى (`A - B`).
- [`setequal`][ref-sets] لاختبار تساوي المجموعتين، مع تجاهل التكرارات والترتيب.

```R
> set_1 <- c("a", "b", "c", "b", "a")
> unique(set_1) # deduplicate
[1] "a" "b" "c"

> set_2 <- c('a', "c", "d")
> union(set_1, set_2) # values in either set
[1] "a" "b" "c" "d"

> intersect(set_1, set_2) # values in both sets
[1] "a" "c"

> setdiff(set_1, set_2) # values in set_1 but not set_2
[1] "b"

> setdiff(set_2, set_1) # values in set_2 but not set_1
[1] "d"

setequal(set_1, c("c", "b", "a", "b")) # are elements the same after deduplication?
[1] TRUE
```

في كل حالة، تُرجع الدالة نسخة وتترك الوسائط دون تغيير.

## جداول التجزئة

تُعد عمليات المتجهات الموصوفة أعلاه جزءًا من R الأساسية.
وهي مفيدة للمسائل الصغيرة، لكنها تصبح بطيئة مع المجموعات الكبيرة.

توفّر حزم خارجية متعددة [جداول التجزئة][wiki-hash] لتحسين الأداء في بعض السياقات.

على سبيل المثال، توفّر حزمة [`hashtable`][ref-hashtable] تطبيقات لكل من `hashmap` و`hashset`، وهما أكثر قابلية للتوسع.
وكما هو الحال مع معظم الحزم الخارجية، هذه الحزمة غير متاحة داخل Exercism، لكنها جديرة بالاستكشاف للمشكلات الواقعية.
