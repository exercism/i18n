# نوع الصف

الصف هو نوع بيانات مركّب متعدد الاستخدامات وفعّال في Cairo، يتيح لك تجميع عدة قيم من أنواع مختلفة في كيان واحد.
للصفوف طول ثابت، أي أنه بمجرد الإعلان عنها لا يمكن أن يتغير حجمها.

## إنشاء الصفوف

لإنشاء صف، تكتب قائمة قيم مفصولة بفواصل داخل الأقواس الهلالية.
لكل موضع في الصف نوع محدد، ويمكن أن تختلف هذه الأنواع عن بعضها.

```rust
fn main() {
    let tup: (u32, u64, bool) = (10, 20, true);
}
```

يمكن للصف أن يحتوي على عدة قيم من أنواع بيانات مختلفة، بما في ذلك صفوف أخرى.
على سبيل المثال:

```rust
fn main() {
    let nested_tup: ((i32, u64), (u8, bool)) = ((10, 3), (5, false));
}
```

هنا، المتغير `nested_tup` صف يحتوي على صفين، ما يوضح أن الصفوف يمكن أن تحتوي على صفوف أخرى كعناصر.

## تفكيك الصفوف

للوصول إلى القيم الفردية داخل صف، يمكنك استخدام مطابقة الأنماط لتفكيك الصف.
وهذا يفكّك الصف إلى أجزائه المكوّنة له.

```rust
fn main() {
    let tup = (500, 6, true);

    let (x, y, z) = tup;

    println!("x is: {x}"); // prints "x is: 500"
    println!("y is: {y}"); // prints "x is: 6"
    println!("z is: {z}"); // prints "z is: true"
}
```

## الإعلان والتفكيك في آن واحد

يمكنك أيضًا الإعلان عن صف وتفكيكه في آن واحد.

```rust
fn main() {
    let (x, y): (felt252, felt252) = (2, 3);
}
```

## نوع الوحدة `()`

نوع الوحدة نوع خاص في Cairo له قيمة واحدة فقط: `()`.
ويُمثَّل بصف بدون عناصر.
حجم نوع الوحدة صفر دائمًا، وهو مضمون ألا يوجد في الكود المُجمَّع.

في Cairo، يُرجع كل تعبير قيمة، وعندما لا يُرجع تعبير أي شيء، فإنه يُرجع `()` ضمنيًا.
وقد يكون هذا مفيدًا للدوال التي تحتاج إلى إرجاع قيمة لكن ليس لديها قيمة ذات معنى تُرجعها.

## الإعلان عن نوع صف مُسمّى

يتيح لك الصف المُسمّى إنشاء اسم بديل أكثر وصفًا لنوع صف ما، ما يحسّن وضوح الكود.

```rust
type Point = (u32, u32);

fn main() {
    let point: Point = (10, 8);
    println!("{point:?}"); // prints "(10, 8)"
}
```

في هذا المثال، `Point` هو نوع صف مُسمّى يمثّل زوجًا من الأعداد الصحيحة غير الموقّعة بطول 32 بت، ما يجعل الكود أكثر تعبيرًا.
