# التعليمات

أنت مراقب طيور شغوف يتتبّع عدد الطيور التي زارت حديقتك خلال الأيام السبعة الماضية.

لديك ست مهام، وكلها تتعلق بأعداد الطيور التي زارت حديقتك.

## 1. تحقق من الأعداد في الأسبوع الماضي

لأغراض المقارنة، تحتفظ دائمًا بنسخة من أعداد الأسبوع الماضي قريبة منك، وهي: 0، 2، 5، 3، 7، 8 و4. أنشئ متجهًا يحتوي على أعداد الأسبوع الماضي:

```clojure
last-week
;;=> [0 2 5 3 7 8 4]
```

## 2. تحقق من عدد الطيور التي زارت اليوم

نفّذ الدالة `today` لتُرجع عدد الطيور التي زارت حديقتك اليوم. أعداد الطيور مرتبة حسب اليوم، إذ يمثل العنصر الأول عدد أقدم يوم، ويمثل العنصر الأخير عدد اليوم.

```clojure
(def birds-per-day [2 5 0 7 4 1])
(today birds-per-day)
;;=> 1
```

## 3. زد عدد اليوم

نفّذ الدالة `inc-bird` لزيادة عدد اليوم:

```clojure
(inc-bird birds-per-day)
;;=> [2 5 0 7 4 2]
```

## 4. تحقق مما إذا كان هناك يوم بلا طيور زائرة

نفّذ الدالة `day-without-birds?` التي تُرجع قيمة منطقية، فتُرجع `true` إذا كان هناك يوم لم تزر فيه أي طيور الحديقة، وإلا فتُرجع `false`:

```clojure
(day-without-birds? birds-per-day)
;;=> true
```

## 5. احسب عدد الطيور الزائرة خلال أول عدد محدد من الأيام

نفّذ الدالة `n-days-count` التي تُرجع عدد الطيور التي زارت حديقتك من بداية الأسبوع، لكن اقتصر العدّ على عدد الأيام المحدد من بداية الأسبوع.

```clojure
(n-days-count birds-per-day 4)
;;=> 14
```

## 6. احسب عدد الأيام المزدحمة

بعض الأيام أكثر ازدحامًا من غيرها. اليوم المزدحم هو الذي زارت فيه خمسة طيور أو أكثر حديقتك.
نفّذ الدالة `busy-days` لتُرجع عدد الأيام المزدحمة:

```clojure
(busy-days birds-per-day)
;;=> 2
```

## 7. تحقق من الأسبوع الفردي

خلال العام الماضي، وجدت أن بعض الأسابيع تُشكّل النمط الفردي نفسه، حيث تتناوب الأعداد بين طائر واحد وصفر من الطيور الزائرة. نفّذ الدالة `odd-week?` التي تُرجع `true` إذا طابق نمط أعداد الطيور لهذا الأسبوع النمط الفردي:

```clojure
(odd-week? [1 0 1 0 1 0 1])
;;=> true
```
