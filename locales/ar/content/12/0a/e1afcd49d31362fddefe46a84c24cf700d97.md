# مقدمة

Perl لغة برمجة أنشأها لاري وول، وصدرت أول مرة عام 1987.

## الحزم والوحدات

الحزمة مجموعة من الكود، وغالبًا ما تكون داخل ملف وحدة يحمل الاسم نفسه وله الامتداد `.pm`.
وبعد ذلك يمكن استيراد الوحدة إلى ملف آخر، عادةً باستخدام الكلمة المفتاحية `use`.

```perl
# Foo.pm
package Foo;

# Accessible with `Foo::bar` when module is used
# or just `bar` if the subroutine is exported.
sub bar () {
    return 1;
}
```

## المتغيرات

توجد متغيرات قياسية (`$foo`)، ومتغيرات مصفوفة (`@bar`)، ومتغيرات تجزئة (`%baz`).
وللتبسيط، لن نستخدم هنا سوى المتغيرات القياسية.
يمكن أن تكون القيمة القياسية واحدة مما يلي: سلسلة نصية، أو عدد، أو قيمة منطقية، أو [مرجع][perlreftut] إلى شيء ما.
وغياب القيمة هو `undef`.


الكلمتان المفتاحيتان `my` و`our` تُعلنان عن متغير في النطاق المعجمي، مثل `my $foo;`.
ومع `our`، سيُمنح المتغير أيضًا اسمًا مستعارًا لمتغير حزمة يحمل الاسم نفسه.
وهناك طرق أخرى للإعلان عن المتغيرات لن نتناولها هنا.

يمكنك إسناد قيمة إلى متغير باستخدام العامل `=`، مثل `$foo = 1;`، ويمكن فعل ذلك في الوقت نفسه الذي تُعلن فيه عن المتغير، مثل `my $foo = 1;`.

```perl
package Foo;

sub baz () {
    our $bar = 1; # Sets both $bar and $Foo::bar as 1.
    return $bar;
}

$Foo::bar = 2; # $bar is not accessible here, but $Foo::bar is.

# Both of these will print 1.
say baz;
say $Foo::bar;
```

## الدوال الفرعية

تُعلن الكلمة المفتاحية `sub` عن [دالة فرعية][perlsub].
وتُنهي الكلمة المفتاحية `return` الدالة الفرعية، فتُرجع القيم المحددة، أو قائمة فارغة إذا لم تُحدَّد أي قيمة.
وبدون `return` محدد، تتحدد القيمة المُرجَعة حسب السياق (قياسي، أو قائمة، أو فارغ) للدالة الفرعية المستخدَمة وعبارتها الأخيرة.

```perl
sub hello () {
    return 'Hello, World!';
}
```

تتيح لك الإصدارات الحديثة من Perl تحديد معاملات رسمية في [توقيع][perlsubsig].
ويمكن أن تحتوي قائمة المعاملات على متغيرات قياسية أو مصفوفة أو تجزئة.
وقائمة المعاملات الفارغة تعني أن الدالة الفرعية لا تقبل أي وسائط.
أما الإصدارات الأقدم من Perl فكانت تتطلب جلب الوسائط من المتغير الخاص `@_`، وهو أمر لن نتناوله هنا.
