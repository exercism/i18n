# ملحق التعليمات

## السجلات

| السجل | الاستخدام    | النوع   | الوصف                               |
| ------ | ------------ | ------- | ----------------------------------- |
| `$a0`  | إدخال        | عدد صحيح | الحد                                |
| `$a1`  | إدخال/إخراج  | عنوان   | مصفوفة الوجهة للأعداد الأولية        |
| `$v0`  | إخراج        | عدد صحيح | عدد الأعداد الأولية                  |
| `$t0-9`| مؤقت         | أي نوع  | تُستخدم لتخزين مؤقت                   |
