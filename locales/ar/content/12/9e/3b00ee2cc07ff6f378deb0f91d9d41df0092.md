# مقدمة

`String` في Java هو كائن يمثل نصًا غير قابل للتغيير كتسلسل من محارف يونيكود (الحروف والأرقام وعلامات الترقيم، وما إلى ذلك).
تُستخدم علامات الاقتباس المزدوجة لتعريف نسخة من `String`:

```java
String fruit = "Apple";
```

يتم التعامل مع السلاسل النصية عبر استدعاء طُرق السلسلة النصية.
بمجرد إنشاء سلسلة نصية، لا يمكن أن تتغير قيمتها أبدًا.
أي طُرق تبدو وكأنها تعدّل سلسلة نصية ستُرجع في الواقع سلسلة نصية جديدة.
يوفر صنف `String` بعض الطُرق _static_ لتحويل السلاسل النصية.
