# الجمل الشرطية

تختار **الجملة الشرطية** بين مسارين للتنفيذ اعتمادًا على ما إذا كان شيء ما صحيحًا.

```sather
   verdict(score : INT) : STR is
      if score >= 5 then
         return "Recalled";
      else
         return "Thank you";
      end;
   end;
```

لنقرأ ذلك: `if`، ثم سؤال تكون إجابته `true` أو `false`، ثم `then`. تُنفَّذ الأسطر التي تلي `then` عندما تكون الإجابة صحيحة، وتُنفَّذ الأسطر التي تلي `else` عندما تكون خاطئة، ويُغلق `end;` الكتلة كلها.

## أكثر من مسارين

تضيف `elsif` سؤالًا آخر لا يُطرح إلا إذا كانت الأسئلة التي قبلها قد جاءت خاطئة.

```sather
   verdict(score : INT) : STR is
      if score >= 8 then
         return "Cast";
      elsif score >= 5 then
         return "Recalled";
      else
         return "Thank you";
      end;
   end;
```

الترتيب مهم. النتيجة `9` تلتقطها الجملة الأولى ولا تصل أبدًا إلى الثانية، رغم أن `9 >= 5` صحيحة أيضًا. وكتابة الشروط بترتيب خاطئ هي السبب المعتاد للوقوع في هذا الخطأ.

وتُكتب `elsif` هكذا، وليس `elseif` ولا `else if`.

## حذف `else`

يمكن حذف `else` عندما لا يكون هناك شيء لفعله في تلك الحالة.

```sather
   if late then
      apologise;
   end;
```

الدالة التي يجب أن تُرجع قيمة تحتاج إلى أن تُرجع قيمة في كل مسار من مساراتها، لذلك يحتفظ كل `if` في هذا التمرين بـ `else`.
