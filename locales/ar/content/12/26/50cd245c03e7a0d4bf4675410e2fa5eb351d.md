# دمج السلاسل النصية

دمج السلاسل النصية صالح تمامًا داخل Ruby، لكن الأسلوب الأكثر شيوعًا لتكوين سلسلة نصية هو [إقحام النصوص](http://ruby-for-beginners.rubymonstas.org/bonus/string_interpolation.html). على سبيل المثال:

```ruby
# Rather than:
"One for " + %{name_variable} + ", one for me"

# Consider:
"One for #{%{name_variable}}, one for me."
```
