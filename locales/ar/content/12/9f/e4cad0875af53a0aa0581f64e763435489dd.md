# حول

يمكن تكرار [concept:csharp/enumerables]() باستخدام [حلقة `foreach`][foreach-statement]:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```

تتكوّن حلقة `foreach` من ثلاثة أجزاء:

1. الإعلان: تعريف المتغير الذي سيحتوي على القيمة المكررة. لا يمكن استخدام هذا المتغير إلا داخل الحلقة.
2. الكائن القابل للتكرار: الكائن الذي يمكن التكرار عليه.
3. جسم الحلقة.

## حلقات `for` مقابل حلقات `foreach`

ومع ذلك، تكون حلقة `foreach` مفضّلة عمومًا على حلقة `for` للأسباب التالية:

- تضمن حلقة `foreach` التكرار على _جميع_ القيم. أما مع حلقة `for`، فيسهل تفويت بعض العناصر، مثلًا بسبب خطأ بمقدار واحد.
- حلقة `foreach` أكثر _تصريحية_، فالكود يوضّح _ماذا_ تريد أن يفعل، بدلًا من حلقة `for` التي توضّح _كيف_ تريد تنفيذه.
- حلقة `foreach` مضمونة ولا مجال فيها للخطأ، بينما يسهل الوقوع في خطأ بمقدار واحد مع حلقات `for`.
- تعمل حلقة `foreach` على جميع أنواع المجموعات، بما فيها تلك التي لا تدعم استخدام الفهرسة للوصول إلى العناصر.

ولضمان تكرار حلقة `foreach` على _جميع_ القيم، لا يسمح المترجم بتحديث المجموعة داخل حلقة `foreach`:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

لحلقة `for` بعض المزايا على حلقة `foreach`:

- يمكنك البدء أو التوقف عند الفهرس الذي تريده.
- يمكنك استخدام أي شرط إنهاء (منطقي) تريده.
- يمكنك تخطّي عناصر معينة بتخصيص طريقة زيادة متغير الحلقة.
- يمكنك معالجة المجموعات من النهاية إلى البداية بالعدّ تنازليًا.
- يمكنك استخدام حلقات `for` في حالات لا تتضمن مجموعات.

مواضيع ذات صلة:

- من المفيد أن تعرف أن C# يدعم [المصفوفات متعددة الأبعاد][multi-dimensional-arrays] مثل `int[,] arr = new int[10, 5]`، وقد تكون مفيدة جدًا.
- ينبغي أن تعرف أيضًا أنه يمكنك إنشاء كائنات من النوع [`System.Array`][system-array-object] باستخدام `Array.CreateInstance`. هذه الكائنات قليلة الفائدة، وهي أساسًا للتوافق البيني مع كود VB.NET. ولا يمكن استخدامها بدلًا من المصفوفات القياسية (`T[]`). كما يمكن أن يكون لها حد أدنى لا يساوي صفرًا.
