# التعليمات

يبدأ نادي الشعر المحلي موسمًا جديدًا. ينضم الشعراء إلى النادي، وكلما كتب اثنان منهم قصيدة معًا صارا جزءًا من *دائرة كتابة* نفسها. يريد النادي تتبّع من يشارك من في أي دائرة، وقد طُلب منك كتابة الكلمات التي تدير ذلك.

تناسب المجموعات المنفصلة هذا الغرض تمامًا: فكل شاعر ذرّة، ودائرة الكتابة جماعة.

## 1. افتح النادي

عرّف `new-club`، بحيث يأخذ متتالية من الشعراء ويُرجع مجموعة منفصلة جديدة مسجَّل فيها كل شاعر. يبدأ كل شاعر في دائرة كتابة خاصة به.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
! => a disjoint set holding the three poets
```

## 2. سجّل تعاونًا

عرّف `collaborate`، بحيث يأخذ شاعرين وناديًا. إنه يدمج دائرتي كتابة الشاعرين ويُرجع النادي، بحيث يمكن تسجيل التعاونات واحدًا بعد الآخر.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Keats" "Byron" rot collaborate
! => the club, with Keats and Byron now in one circle
```

## 3. اعثر على دائرة شاعر

عرّف `circle-of`، بحيث يأخذ شاعرًا وناديًا ويُرجع ممثّل دائرة كتابة ذلك الشاعر. الشاعران اللذان يشتركان في دائرة واحدة يُبلّغان دائمًا بالممثّل نفسه.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Dickinson" swap circle-of
! => "Dickinson"   (still in a circle of their own)
```

## 4. هل يشتركان في دائرة؟

عرّف `same-circle?`، بحيث يأخذ شاعرين وناديًا ويُرجع `t` عندما ينتمي الشاعران إلى دائرة كتابة واحدة، و`f` فيما عدا ذلك. قارن ممثّلي الشاعرين بدلًا من استخدام اختبار تكافؤ مدمج.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Keats" "Byron" rot collaborate
dup [ "Keats" "Byron" ] dip same-circle? .      ! => t
    [ "Keats" "Dickinson" ] dip same-circle? .  ! => f
```
