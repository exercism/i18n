# التعليمات

يحفظ مكتب المفقودات في المدرسة كل شيء في صناديق، وما يمكن أن يدخل الصندوق قد يكون أي شيء: كنزة، أو عددًا من الأشياء، أو اسمًا.

اكتب صنف `LOST_BOX{T}`. الهيكل الأولي يمنحك ترويسة الصنف.

## 1. استلام شيء

`create` تأخذ الشيء واسم مَن سلّمه، وتُرجع صندوقًا. ويبدأ الصندوق غير مُطالَب به.

```sather
box ::= #LOST_BOX{STR}("blue jumper", "Mia");
box.item
-- => "blue jumper"
box.handed_in_by
-- => "Mia"
box.claimed
-- => false
```

## 2. المطالبة به

تُعلّم `claim` الصندوق بأنه مُطالَب به. وهي لا تُرجع أي قيمة.

```sather
box.claim;
box.claimed
-- => true
```

## 3. هل ما زال في الانتظار؟

تُرجع `waiting` ما إذا كان الصندوق لم يُطالَب به بعد.

```sather
box.waiting
-- => false
```

## 4. استبدال المحتوى

تأخذ `replace` شيئًا جديدًا، وتضعه في الصندوق، وتُرجع ما كان موجودًا قبله. والشيء الداخل والشيء الخارج كلاهما من النوع `T`.

```sather
old ::= box.replace("red jumper");
old
-- => "blue jumper"
box.item
-- => "red jumper"
```

## 5. كتابة الوصف

تُرجع `describe` سطرًا عن الصندوق، مثل `"blue jumper, handed in by Mia"`.

لوضع العنصر داخل سلسلة نصية، يحتاج الصنف إلى معرفة أن `T` يمكن تحويله إلى سلسلة نصية. قيّد المعامل: اكتب ترويسة الصنف بالشكل `class LOST_BOX{T < $STR}`، وعندئذٍ يصبح `item.str` مسموحًا.

```sather
box.describe
-- => "blue jumper, handed in by Mia"
```
