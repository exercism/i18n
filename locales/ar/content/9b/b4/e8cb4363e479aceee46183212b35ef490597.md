## العوامل الحسابية

توفّر JavaScript 6 عوامل مختلفة لإجراء عمليات حسابية أساسية على الأعداد.

- `+`: يُستخدم عامل الجمع لإيجاد مجموع الأعداد.

  ```javascript
  1 + 2; // => 3
  2.5 + 3.9; // => 6.5
  ```

- `-`: يُستخدم عامل الطرح لإيجاد الفرق بين عددين

  ```javascript
  19 - 2; // => 17
  7.4 - 1.2; // => 6.2
  ```

- `*`: يُستخدم عامل الضرب لإيجاد حاصل ضرب عددين

  ```javascript
  7 * 5; // => 35
  9.2 * 6.3; // => 57.959999999999994
  ```

- `/`: يُستخدم عامل القسمة لقسمة عددين.
  بما أن الأعداد في JavaScript هي دائمًا أعداد الفاصلة العائمة، فلا توجد قسمة على الأعداد الصحيحة.

  ```javascript
  8 / 2; // => 4
  25 / 3; // => 8.333333333333334
  ```

- `%`: يُستخدم عامل الباقي لإيجاد باقي عملية القسمة.

  ```javascript
  40 % 4; // => 0
  11 % 4; // => 3
  -11 % 4; // => -3
  ```

- `**`: يُستخدم عامل الأس لرفع عدد إلى قوة.
  وهو مكافئ لاستخدام [`Math.pow()`][mdn-math-pow]

  ```javascript
  4 ** 3; // => 64
  4 ** 1 / 2; // => 2
  ```

## ترتيب العمليات

عند استخدام عدة عوامل في سطر واحد، تتّبع JavaScript ترتيبًا للأسبقية كما هو موضح في [جدول الأسبقية هذا][mdn-operator-precedence].
ولتبسيط ذلك في سياقنا، تستخدم JavaScript قاعدة PEDMAS (الأقواس، الأسس، القسمة/الضرب، الجمع/الطرح) التي تعلمناها في حصص الرياضيات في المرحلة الابتدائية.

<!-- prettier-ignore-start -->
```javascript
const result = 3 ** 3 + 9 * 4 / (3 - 1);
// => 3 ** 3 + 9 * 4/2
// => 27 + 9 * 4/2
// => 27 + 18
// => 45
```
<!-- prettier-ignore-end -->

## عوامل الإسناد المختصرة

عوامل الإسناد المختصرة طريقة أقصر لكتابة كود يُجري عمليات حسابية على متغير، ويُسند القيمة الجديدة إلى المتغير نفسه.
على سبيل المثال، لنأخذ متغيرين `x` و `y`.
إذن، `x += y` تكافئ `x = x + y`.
وغالبًا ما يُستخدم هذا مع عدد بدلًا من المتغير `y`.
ويمكن إجراء العمليات الخمس الأخرى بالطريقة نفسها أيضًا.

```javascript
let x = 5;
x += 25; // x is now 30

let y = 31;
y %= 3; // y is now 1
```
