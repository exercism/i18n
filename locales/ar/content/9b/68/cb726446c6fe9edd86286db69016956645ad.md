## MacOS

أولًا، ثبّت Lua و[Luarocks][2] باستخدام [Homebrew][1]:

```shell
$ brew install lua luarocks
```

ثم ثبّت إطار الاختبار [Busted][3] للغة Lua:

```shell
$ luarocks install --local busted
```

أضف `~/.luarocks/bin` إلى `$PATH` في نظامك

```shell
export PATH="$HOME/.luarocks/bin:$PATH"
```

لاحظ أن هذا مؤقت فقط. لإضافته بشكل دائم إلى `$PATH`، ستحتاج إلى إضافته إلى `.bashrc` أو `.zshrc` أو `config.fish` حسب الصدفة التي تستخدمها.

ثم شغّل اختباراتك:

```shell
$ busted
```

## Windows 10: WSL

أولًا، يجب عليك تمكين [WSL (النظام الفرعي لنظام Linux في Windows)][7] باستخدام [PowerShell][8] (كمسؤول):

```shell
PS> Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Windows-Subsystem-Linux
```

يتطلب هذا إعادة تشغيل.

بعد ذلك، ثبّت Ubuntu من [Microsoft Store][9]، **أو** نزّله ثم ثبّته باستخدام PowerShell:

```shell
PS> curl.exe -L -o ubuntu1804.appx https://aka.ms/wsl-ubuntu-1804
PS> Add-AppxPackage .\ubuntu1804.appx; rm .\ubuntu1804.appx
PS> ubuntu1804
```

ثم حدّث قائمة الحزم:

```shell
PS> wsl
$ sudo apt-get update
```

الآن أنت جاهز لتثبيت [LuaRocks][2] و[Busted][3] باتباع [تعليمات Ubuntu](#ubuntu) أعلاه.

بعد الانتهاء، يمكنك تشغيل اختباراتك مباشرة من أي سطر أوامر في Windows:

```cmd
C:\> wsl busted
```

## Windows 10: Docker

### تثبيت Gitbash

هذه الخطوة اختيارية. قد تحتاج إلى تعديل الخطوات التالية قليلًا إذا كنت تفضّل استخدام واجهة سطر الأوامر الأصلية في Windows أو واجهة سطر أوامر أخرى.

نزّله من [هنا][10].
تعليمات التثبيت [هنا][11].

### تثبيت Docker

اتبع التعليمات لتثبيت [Docker for Windows][12].
بعد الانتهاء من التثبيت، يمكنك تشغيل الأمر التالي للتأكد من تثبيته بشكل صحيح.

```shell
$ docker --version
```

_قد تواجه خطأً عند محاولة تشغيل Docker لأول مرة._

`cannot enable hyper-v service`

_إذا حدث هذا، يمكنك اتباع هذه التعليمات [لتمكين Hyper V][13]. قد تحتاج إلى تعطيل الإعداد، ثم إعادة تشغيل جهازك، ثم إعادة تمكينه بعد الإقلاع._

### تثبيت busted

بعد تثبيت Gitbash وDocker، ستتمكن من تثبيت 'حاوية' busted.

في Gitbash شغّل ما يلي:

نزّل حاوية Docker واسعة الاستخدام هذه بتشغيل ما يلي:

```shell
$ docker pull imega/busted
```

أنشئ دالة حتى لا تضطر إلى كتابة الأمر كاملًا في كل مرة.
أضف هذا إلى `.bashrc`:

```shell
dbusted() { docker run --rm -t -v "/$@":/data imega/busted; }
```

الآن، في واجهة سطر الأوامر، يمكنك الانتقال إلى المجلد الذي تريد تشغيل اختباراتك فيه. شغّل ما يلي:

```shell
$ dbusted $PWD
```

يجب أن ترى مخرجات اختبارات busted.
