# نبذة

في PHP، يمكن استدعاء المتغير كدالة بإضافة الأقواس الهلالية [`()`] إليه. وعندما يحاول PHP استدعاء الدالة، فإنه يبحث عن دالة يحمل الاسم نفسه الذي تحمله قيمة المتغير.

```php
function foo(): string
{
    return "foo() invoked";
}

$func = 'foo';
$func(); // This calls foo()
```

## استدعاء الدوال الساكنة في الصنف

يمكن استدعاء الدوال الساكنة في الصنف بالطريقة نفسها:

```php
class Rocket
{
    public static function launch()
    {
        return '3, 2, 1, Liftoff!';
    }
}

$func = 'Rocket::launch';
$func(); // This calls Rocket::launch()
```

## استدعاء دوال نسخة الصنف

يمكن أيضًا استدعاء دالة تابعة لنسخة من الصنف:

```php
class Rocket
{
    public function openDoor()
    {
        return 'Door open.';
    }
}

$rocket = new Rocket();
$func = [$rocket, 'openDoor'];
$func(); // This calls Rocket::openDoor()
```
