# مقدمة

يمكن تعريف أنواع C# داخل نطاق صنف أو بنية. ويوفّر النوع المحيط ما يشبه مساحة أسماء. ويكون الوصول إلى النوع من خلال النوع المحيط باستخدام صيغة النقطة.

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

يمكنك تحديد مستويات الوصول للأنواع الداخلية.

الأعضاء الخاصة في النوع الخارجي تقع ضمن نطاق أعضاء النوع الداخلي، لكن العكس غير صحيح.
