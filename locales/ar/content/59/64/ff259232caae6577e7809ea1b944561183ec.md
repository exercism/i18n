# مقدمة

## التواريخ والوقت

تقدم المكتبة القياسية في Elixir أربع وحدات مختلفة للتعامل مع التواريخ والوقت، ولكل منها بنيتها الخاصة.

- وحدة `Date`. يمكن إنشاء بنية `Date` باستخدام سيجيل `~D`.

  ```elixir
  ~D[2021-01-01]
  ```

- وحدة `Time`. يمكن إنشاء بنية `Time` باستخدام سيجيل `~T`.

  ```elixir
  ~T[12:00:00]
  ```

- وحدة `NaiveDateTime` لقيم التاريخ والوقت بدون منطقة زمنية. يمكن إنشاء بنية `NaiveDateTime` باستخدام سيجيل `~N`.

  ```elixir
  ~N[2021-01-01 12:00:00]
  ```

- وحدة `DateTime` لقيم التاريخ والوقت مع منطقة زمنية. يتطلب استخدام هذه الوحدة مع مناطق زمنية غير UTC اعتمادية خارجية، وهي قاعدة بيانات للمناطق الزمنية.

### المقارنات

لمقارنة التواريخ أو الأوقات بعضها ببعض، ابحث عن دالة `compare` أو `diff` في الوحدة المقابلة. عوامل المقارنة مثل `==` و`>` و`<` _تبدو_ وكأنها تعمل، لكنها لا تُجري مقارنة دلالية صحيحة لهذه البنيات.
