# نبذة

رأينا في مفاهيم سابقة أن الأنواع في Julia تشكّل تسلسلًا هرميًا، ويكون `Any` في قمته.

الأنواع المجرّدة مثل `Number` لها أنواع فرعية، لكن لا يمكن إنشاء نسخة منها بذاتها. وعند إسناد متغير إلى نوع مجرّد، فإن ذلك _يقيّد_ قيم المتغير لتكون أي نوع فرعي من النوع المجرّد. على سبيل المثال:

```julia-repl
julia> x::Number = 3
3

julia> typeof(x)  # one subtype of Number
Int64

julia> x = 4.2
4.2

julia> typeof(x) # another subtype of Number
Float64

julia> x = "fail" # not a number type!
ERROR: MethodError: Cannot `convert` an object of type String to an object of type Number
```

هذا يمنحنا نوعًا من المرونة في تقييد المدخلات الصالحة.

لكن لنفترض أننا نريد لمتغير أن يقبل قيمًا صحيحة وقيمًا نصية معًا؟ فهذان النوعان ليسا في الفرع نفسه من التسلسل الهرمي.

يمكننا اختيار النوع [`Any`][any] له، أو تركه يأخذ هذا النوع افتراضيًا، لكننا حينها نفقد السيطرة كاملة على الأنواع المسموح بها.

ولأسلوب أفضل، لدينا صيغة [`Union{ }`][union]، حيث نُدرج نوعين أو أكثر داخل الأقواس المعقوفة.

```julia-repl
julia> y::Union{Integer, String} = 4
4

julia> typeof(y)
Int64

julia> y = "works"
"works"

julia> typeof(y)
String

julia> y = 5.3
ERROR: MethodError: Cannot `convert` an object of type 
  Float64 to an object of type 
  Union{Integer, String}
```

مثال آخر يستخدم اتحاد الأنواع نفسه في توقيع دالة:

```julia-repl
julia> IntOrString = Union{Integer, String}
Union{Integer, String}

julia> f(z::IntOrString) = z^3
f (generic function with 1 method)

julia> f(2) # integers are cubed
8

julia> f("ab") # strings are repeated 3 times
"ababab"
```

هنا أعطينا النوع اسمًا، وهو ما يوفّر اختصارًا مريحًا، لكنه ليس ضروريًا. والدالة `g(z::Union{Integer, String}) = z^3` تتصرف بالطريقة نفسها.

سيكون لدينا الكثير لنقوله عن توقيعات الدوال في مفهوم الإرسال المتعدد.

## اتحادات تشمل `nothing`

في لغات أخرى عديدة أنواع قد تحتوي على قيمة أو لا تحتوي، بأسماء مثل `Option` و`Nullable` و`Maybe`.

لا تملك Julia صيغة خاصة بذلك، لكن اتحادات الأنواع تعميم للفكرة نفسها.

رأينا في مفهوم [`Nothingness`][nothingness] أن Julia تملك طرقًا متنوعة لتمثيل القيم غير الموجودة، ومنها [`nothing`][nothing] و[`missing`][missing]. ويمكن إدراج أيٍّ منهما في اتحاد أنواع.

على سبيل المثال، عند تعريف نوع من [القوائم المترابطة][linked]، نحتاج إلى طريقة لإنهاء القائمة إذا لم تبقَ عُقد أخرى. النوع `Nothing` هو النوع الذي قيمته الوحيدة `nothing`، وتعريف `Node` هذا يجعل من الممكن الإشارة إلى نهاية القائمة:

```julia-repl
julia> struct Node
           value::Any
           next::Union{Node, Nothing}
       end
```

وبالمثل، يمكن استخدام `missing` كقيمة نائبة عن القيم الغائبة، ولا سيّما في المجموعات مثل المتجهات. المثال التالي مفتعل جدًا، لكن القيم الغائبة شائعة في مجموعات البيانات الواقعية.

```julia-repl
julia> q(x::Real) = x >= 0 ? sqrt(x) : missing  # skip negative values
q (generic function with 1 method)

julia> vals::Vector{Union{Real, Missing}} = q.([4, 3.1, -1, 0])
4-element Vector{Union{Missing, Float64}}:
 2.0
 1.760681686165901
  missing
 0.0
```
