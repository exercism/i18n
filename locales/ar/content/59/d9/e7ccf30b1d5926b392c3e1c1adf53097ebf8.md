# التعليمات

في هذا التمرين، تلعب لعبة تقمّص أدوار تُسمّى "Wizard and Warriors"، تتيح لك أن تلعب إما بشخصية `Wizard` أو بشخصية `Warrior`.

توجد قواعد مختلفة لكل من `Warrior` و`Wizard` تحدد مقدار نقاط الضرر التي يسببها كل منهما.

وهذه هي القواعد بالنسبة إلى `Warrior`:

- يلحق 6 نقاط ضرر إذا لم تكن الشخصية التي يهاجمها عرضة للضرر
- يلحق 10 نقاط ضرر إذا كانت الشخصية التي يهاجمها عرضة للضرر

وهذه هي القواعد بالنسبة إلى `Wizard`:

- يلحق 12 نقطة ضرر إذا جهّز `Wizard` تعويذة مسبقًا
- يلحق 3 نقاط ضرر إذا لم يجهّز تعويذة مسبقًا

بشكل عام، لا تكون الشخصيات عرضة للضرر أبدًا. لكن شخصيات `Wizard` _تكون_ عرضة للضرر إذا لم تجهّز تعويذة.

لديك ستّ مهام تتعامل مع شخصيات `Warrior` و`Wizard`.

## 1. صف شخصية

أعد تعريف طريقة `ToString()` في صنف `Character` بحيث تُرجع وصفًا للشخصية بالصيغة `"Character is a <CHARACTER_TYPE>"`.

```csharp
var warrior = new Warrior();
warrior.ToString();
// => "Character is a Warrior"
```

## 2. اجعل الشخصيات غير عرضة للضرر افتراضيًا

تأكد من أن طريقة `Character.Vulnerable()` تُرجع دائمًا `false`.

```csharp
var warrior = new Warrior();
warrior.Vulnerable();
// => false
```

## 3. اسمح لشخصيات `Wizard` بتجهيز تعويذة

نفّذ طريقة `Wizard.PrepareSpell()` لتتيح لشخصية `Wizard` تجهيز تعويذة مسبقًا.

```csharp
var wizard = new Wizard();
wizard.PrepareSpell();
```

## 4. اجعل شخصيات `Wizard` عرضة للضرر عندما لا تجهّز تعويذة

تأكد من أن طريقة `Vulnerable()` تُرجع `true` إذا لم يجهّز `Wizard` تعويذة، وتُرجع `false` بخلاف ذلك.

```csharp
var wizard = new Wizard();
wizard.Vulnerable();
// => true
```

## 5. احسب نقاط الضرر لشخصية `Wizard`

نفّذ طريقة `Wizard.DamagePoints()` لتُرجع نقاط الضرر التي يلحقها: 12 نقطة ضرر عند تجهيز تعويذة، و3 نقاط ضرر عند عدم تجهيزها.

```csharp
var wizard = new Wizard();
var warrior = new Warrior();

wizard.PrepareSpell();
wizard.DamagePoints(warrior);
// => 12
```

## 6. احسب نقاط الضرر لشخصية `Warrior`

نفّذ طريقة `Warrior.DamagePoints()` لتُرجع نقاط الضرر التي يلحقها: 10 نقاط ضرر عندما يكون الهدف عرضة للضرر، و6 نقاط ضرر عندما لا يكون.

```csharp
var warrior = new Warrior();
var wizard = new Wizard();

warrior.DamagePoints(wizard);
// => 10
```
