# التعليمات

في هذا التمرين ستتلاعب بسيارة تحكّم عن بُعد، وقد ادّخرت أخيرًا ما يكفي من المال لشرائها.

تبدأ السيارات ببطارية ممتلئة (100%). في كل مرة تقود فيها السيارة باستخدام جهاز التحكم عن بُعد، تقطع 20 مترًا وتستهلك واحدًا بالمئة من شحن البطارية.

تحتوي سيارة التحكم عن بُعد على شاشة LED أنيقة تعرض معلومتين:

- المسافة الإجمالية التي قطعتها، وتُعرض بالشكل: `"Driven <METERS> meters"`.
- شحن البطارية المتبقي، ويُعرض بالشكل: `"Battery at <PERCENTAGE>%"`.

إذا وصل شحن البطارية إلى 0%، فلن تستطيع قيادة السيارة بعد ذلك، وستعرض شاشة البطارية `"Battery empty"`.

لديك ست مهام، وستتعامل كل مهمة مع نسخة من سيارة التحكم عن بُعد.

## 1. اشترِ سيارة تحكّم عن بُعد جديدة تمامًا

نفّذ طريقة (_static_) `RemoteControlCar.Buy()` لتُرجع نسخة جديدة تمامًا من سيارة التحكم عن بُعد:

```csharp
RemoteControlCar car = RemoteControlCar.Buy();
```

## 2. اعرض المسافة المقطوعة

نفّذ طريقة `RemoteControlCar.DistanceDisplay()` لتُرجع المسافة كما تظهر على شاشة LED:

```csharp
var car = RemoteControlCar.Buy();
car.DistanceDisplay();
// => "Driven 0 meters"
```

## 3. اعرض نسبة شحن البطارية

نفّذ طريقة `RemoteControlCar.BatteryDisplay()` لتُرجع نسبة شحن البطارية كما تظهر على شاشة LED:

```csharp
var car = RemoteControlCar.Buy();
car.BatteryDisplay();
// => "Battery at 100%"
```

## 4. حدّث عدد الأمتار المقطوعة عند القيادة

نفّذ طريقة `RemoteControlCar.Drive()` التي تُحدّث عدد الأمتار المقطوعة:

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
car.DistanceDisplay();
// => "Driven 40 meters"
```

## 5. حدّث نسبة شحن البطارية عند القيادة

حدّث طريقة `RemoteControlCar.Drive()` لتُحدّث نسبة شحن البطارية:

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
car.BatteryDisplay();
// => "Battery at 98%"
```

## 6. امنع القيادة عندما تكون البطارية فارغة

حدّث طريقة `RemoteControlCar.Drive()` بحيث لا تزيد المسافة المقطوعة ولا تنقص نسبة شحن البطارية عندما تكون البطارية فارغة (عند 0%):

```csharp
var car = RemoteControlCar.Buy();

// Drain the battery
// ...

car.DistanceDisplay();
// => "Driven 2000 meters"

car.BatteryDisplay();
// => "Battery empty"
```
