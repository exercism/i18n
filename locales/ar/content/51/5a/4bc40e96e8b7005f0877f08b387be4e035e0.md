# التعليمات

في هذا التمرين، ستكتب كودًا لطباعة شارات الأسماء لعاملي المصنع.

## 1. طباعة شارة لموظف

لدى الموظفين معرّف واسم واسم قسم.
تُنسّق تسميات شارات الموظفين على النحو التالي: `"[id] - name - DEPARTMENT"`.
نفّذ الطريقة `printBadge()` لتُرجع تسمية شارة الموظف:

```kotlin
printBadge(734, "Ernest Johnny Payne", "Strategic Communication")
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

~~~~exercism/note
لاحظ أن اسم القسم يجب أن يكون بحروف كبيرة على الشارة.
~~~~

## 2. طباعة شارة لموظف جديد

بسبب خلل غريب في نظام الحاسوب، لا يملك الموظفون الجدد أحيانًا معرّفًا بعد عند بدء عملهم في المصنع.
ولأن الشارات مطلوبة، سيحصلون على شارة مؤقتة بدون بادئة المعرّف.
عدّل الطريقة `printBadge()` لتدعم الموظفين الجدد الذين ليس لديهم معرّف بعد:

```kotlin
printBadge(null, "Jane Johnson", "Procurement")
// => "Jane Johnson - PROCUREMENT"
```

## 3. طباعة شارة للمالك

حتى مالك المصنع عليه أن يرتدي شارة في جميع الأوقات.
لكن المالك ليس لديه قسم.
في هذه الحالة، ينبغي أن تطبع التسمية `"OWNER"` بدلًا من اسم القسم.
عدّل الطريقة `printBadge()` لتطبع تسمية للمالك:

```kotlin
printBadge(254, "Charlotte Hale", null)
// => "[254] - Charlotte Hale - OWNER"
```

~~~~exercism/note
لاحظ أنه من الممكن أن يكون المالك موظفًا جديدًا أيضًا:

```kotlin
printBadge(null, "Charlotte Hale", null)
// => "Charlotte Hale - OWNER"
```
~~~~
