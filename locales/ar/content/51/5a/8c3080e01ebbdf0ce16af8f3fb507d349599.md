# مقدمة

توفّر وحدة `Agent` تجريدًا لإنشاء [العمليات وحلقة _الاستقبال والإرسال_][exercism-processes]. من هنا، سنسمي العمليات التي تُبدأ باستخدام وحدة `Agent` _«عمليات الوكيل»_. قد تُختار _عملية وكيل_ لتمثيل حالة مشتركة مركزية.

لبدء _عملية وكيل_، توفّر وحدة `Agent` الدالة `start/2`. الدالة المُمرَّرة عند استخدام `start` لبدء _عملية الوكيل_ تُرجع الحالة الابتدائية للعملية:

```elixir
# Start an agent process with an initial value of an empty list
{:ok, agent_pid} = Agent.start(fn -> [] end)
```

تمامًا مثل `Map` أو `List`، توفّر وحدة `Agent` دوالًا كثيرة للتعامل مع _عمليات الوكيل_.

من المعتاد تنظيم كل الوظائف المرتبطة بـ`Agent` وتغليفها في وحدة خاصة بالمجال الذي يجري نمذجته.

[exercism-processes]: https://exercism.org/tracks/elixir/concepts/processes
