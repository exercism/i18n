# حول

يمكن تكييف عوامل الحساب والمقارنة الأساسية لتعمل مع **abstract** الذي تكتبه أنت. وهذا ما يُعرف بالتحميل الزائد للعوامل.

استخدم حقل الصنف الموصوف بالبيانات الوصفية `@:op()` لتطبيق التحميل الزائد على أحد العوامل:

```haxe
abstract MyAbstract(String) {
  public inline function new(s:String) {
    this = s;
  }

  @:op(A * B)
  public function repeat(rhs:Int):MyAbstract {
    var s:StringBuf = new StringBuf();
    for (i in 0...rhs)
      s.add(this);
    return new MyAbstract(s.toString());
  }
}

class Main {
  static public function main() {
    var a = new MyAbstract("foo");
    trace(a * 3); // foofoofoo
  }
}
```
