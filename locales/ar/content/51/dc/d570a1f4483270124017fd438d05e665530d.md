# مقدمة

تُنشأ قوائم المحارف باستخدام Sigil ‏`~c`.

```elixir
~c"hello"
```

~~~~exercism/note
لاحظ أنه في الإصدارات الأقدم من Elixir، تُمثَّل قوائم المحارف بالشكل `'hello'` مستخدمة علامات الاقتباس المفردة.
~~~~

على الرغم من أنها تبدو شبيهة جدًا بالسلاسل النصية، فإن نوعي البيانات مختلفان تمامًا عن بعضهما. قائمة المحارف هي مصفوفة من الأعداد الصحيحة. تمثّل هذه الأعداد قيم Unicode لمحرف معيّن، وتُعرف أيضًا بنقاط الترميز.

```elixir
[65, 66, 67]
# => ~c"ABC"
```

يمكنك أن تسبق المحرف بعلامة `?` للحصول على نقطة الترميز الخاصة به.

```elixir
?A
# => 65

[?:, ?)]
# => ~c":)"
```

ولأن قوائم المحارف هي مصفوفات، يمكنك التعامل معها تمامًا كما تتعامل مع أي مصفوفة أخرى، أي باستخدام الاستدعاء الذاتي ومطابقة الأنماط.

```elixir
[first_letter | _] = ~c"cat"
first_letter
# => 99
```

يمكنك دمج مصفوفتين باستخدام `++`.

```elixir
~c"hi" ++ ~c"!"
# => ~c"hi!"
```

كلما كانت المصفوفة الأولى أطول، كان الدمج أبطأ، لذا تجنّب الإضافة المتكررة إلى مصفوفات ذات طول غير محدد.
