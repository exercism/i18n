# نبذة

تأتي متتاليات Factor بنوعين عندما تحتاج إلى *تعديلها*:

- **المصفوفات** (`{ … }`) لها طول ثابت. يمكنك تغيير ما يوجد *عند* كل موضع باستخدام
  `set-nth` / `change-nth`، لكن لا يمكنك توسيعها أو تقليصها.
- **المتجهات** (`V{ … }`) متغيرة الطول. تضيف `push` إلى النهاية، وتزيل `pop`
  العنصر الأخير وتُرجعه.

```factor
USING: arrays kernel sequences ;

! Fixed-length: build a counter array of zeros, then bump one slot.
3 0 <array>            ! { 0 0 0 }
dup [ 1 + ] 1 rot change-nth
.                      ! { 0 1 0 }

! Variable-length: build a vector of names by pushing.
V{ } clone
"alice" over push
"bob" over push
dup pop drop           ! removes "bob"
.                      ! V{ "alice" }
```

| الكلمة          | التأثير                                        |
|-----------------|------------------------------------------------|
| `<array>`       | `( n elt -- array )`، مصفوفة من `n` نسخة من `elt` |
| `<vector>`      | `( n -- vector )`، متجه فارغ بسعة `n`          |
| `V{ }`          | متجه فارغ مكتوب حرفيًا                          |
| `set-nth`       | `( elt n seq -- )`، إسناد العنصر عند الفهرس `n` |
| `change-nth`    | `( i seq quot -- )`، تطبيق `quot` على العنصر عند `i` |
| `push`          | `( elt seq -- )`، إلحاق بمتجه                  |
| `suffix!`       | `( seq elt -- seq )`، إلحاق في المكان نفسه، ويُرجع المتجه |
| `pop`           | `( seq -- elt )`، إزالة العنصر الأخير وإرجاعه   |
| `pop*`          | `( seq -- )`، إزالة العنصر الأخير والتخلص منه   |
| `clone`         | `( obj -- copy )`، نسخة مستقلة جديدة           |
| `new-sequence`  | `( n exemplar -- newseq )`، متتالية جديدة من الصنف نفسه الذي ينتمي إليه `exemplar` |
| `new-resizable` | `( n exemplar -- newseq )`، نسخة جديدة قابلة لتغيير الحجم |

عندما تعدّل متتالية مرّرها المستدعي، يكون التغيير مرئيًا للمستدعي، فهو يحمل
الكائن نفسه. إذا لم يكن هذا ما تريده، فاستخدم `clone` أولًا للحصول على نسخة
مستقلة.
