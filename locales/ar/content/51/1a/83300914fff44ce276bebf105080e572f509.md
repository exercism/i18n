# أساسيات `match`

يتيح لك تعبير `match` مقارنة قيمة بسلسلة من الأنماط بسهولة، ثم تشغيل الكود بناءً على النمط الذي تحققت مطابقته. يتكوّن النمط من قيم حرفية وأسماء متغيرات ورموز شاملة وأشياء أخرى كثيرة.

```rust
#[derive(Drop)]
enum Color {
    Red,
    Yellow,
    Green,
}

fn print_color_type(color: Color) {
    match color {
        Color::Red => println!("The color is Red"),
        Color::Yellow => println!("The color is Yellow"),
        Color::Green => println!("The color is Green"),
    }
}

fn main() {
    let color = Color::Yellow;
    print_color_type(color); // prints "The color is Yellow"
}
```

للتعامل مع عدة أسطر من الكود، يجب تغليف فرع `match` بالأقواس المعقوفة `{}`:

```rust
fn specified_color(color: Color) -> felt252 {
    let mut response: felt252 = '';

    match color {
        Color::Red => {
            response = 'You passed in Red';
        },
        Color::Yellow => {
            response = 'You passed in Yellow';
        },
        Color::Green => {
            response = 'You passed in Green';
        },
    }

    response
}
```

يمتلك تعبير `match` أيضًا خاصية الربط بالقيم التي تطابق النمط. وهذا يجعل من الممكن استخراج القيمة المرتبطة ببديل التعداد.

```rust
#[derive(Drop, Debug)]
enum ColorType {
    Light,
    Dark,
}

#[derive(Drop)]
enum Color {
    Red: ColorType,
    Yellow,
    Green,
}

fn print_color_type(color: Color) {
    match color {
        Color::Red(state) => {
            println!("The color is Red");
            println!("The Color Type is {:?}", state);
        },
        Color::Yellow => println!("The color is Yellow"),
        Color::Green => println!("The color is Green"),
    }
}

fn main() {
    let color = Color::Red(ColorType::Dark);
    print_color_type(color);
}
```

وسّعنا البديل `Red` في تعداد `Color` ليكون له تعداد مرتبط. وبمساعدة تعبير `match`، أصبحنا قادرين على استخراج القيمة المرتبطة؛ `state`. وهذا مجرد اسم متغير يمكن استخدامه لاحقًا في فرع الكود.

## مطابقة تعداد `Option`

يمكن أيضًا التعامل مع تعداد `Option` المدمج باستخدام تعبير `match`.

لنصمّم دالة تأخذ معاملًا من النوع `Option<u8>`.
إذا وُجدت قيمة في المعامل المُمرَّر، فأضف واحدًا إلى هذه القيمة، وإلا فيجب أن تُرجع الدالة القيمة `None` دون أي عملية.

```rust
fn add_one(x: Option<u8>) -> Option<u8> {
    match x {
        Option::Some(val) => Option::Some(val + 1),
        Option::None => Option::None,
    }
}

fn main() {
    let three: Option<u8> = Option::Some(3);
    let four: Option<u8> = add_one(three);
    let none = add_one(Option::None);

    println!("{three:?}"); // prints "Option::Some(3)"
    println!("{four:?}"); // prints "Option::Some(4)"
    println!("{none:?}"); // prints "Option::None(())"
}
```

> ملاحظة: `{:?}` صيغة تنسيق خاصة تتيح طباعة شكل تصحيحي للمعامل المُمرَّر إلى الماكرو `println!`.
> يمكنك العثور على مزيد من المعلومات حولها في [The Cairo Book][debugging].

من مزايا استخدام بنية التحكم في التدفق `match` طبيعتها الشاملة: يجب أن تغطي أنماط الأفرع _كل_ الاحتمالات.
تأمّل النسخة التالية من المثال السابق، التي لا تتعامل مع الحالة `None`:

```rust
fn add_one(x: Option<u8>) -> Option<u8> {
    match x {
        Option::Some(val) => Option::Some(val + 1),
    }
     // this code does not compile, as we forgot to handle the `None` case
}
```

## نمط الالتقاط الشامل مع الرمز الشامل `_`

باستخدام التعدادات، يمكننا أيضًا اتخاذ إجراءات خاصة لبعض القيم المعينة، بينما ننفّذ إجراءً افتراضيًا واحدًا لكل القيم الأخرى بإضافة فرع جديد يكون فيه `_` هو النمط الخاص بالفرع الأخير من تعبير `match`.
النمط `_` نمط خاص يطابق أي قيمة ولا يرتبط بها.

تستقبل دالة `is_red` معاملًا وتُرجع `true` إذا كان اللون `Red` و `false` لأي لون آخر:

```rust
fn is_red(color: Color) -> bool {
    match color {
        Color::Red => true,
        _ => false,
    }
}
```

## مطابقة الأنماط باستخدام عامل `|`

تتيح بنية التحكم في التدفق `match` في Cairo مطابقة قيمة مع عدة أنماط باستخدام عامل `|` (_أو_).
وهذا يساعد على تبسيط الكود.

على سبيل المثال، باستخدام تعداد `Color`، نريد كتابة دالة تُرجع `true` للونين `Red` أو `Green` و `false` للألوان الأخرى:

```rust
fn is_red_or_green(color: Color) -> bool {
    match color {
        Color::Red | Color::Green => true,
        _ => false,
    }
}
```

## مطابقة الأنماط مع `felt252` والمتغيرات الصحيحة

من الممكن مطابقة متغيرات `felt252` والمتغيرات الصحيحة مع مجموعة من القيم.
لكن هناك بعض القيود؛

- تُدعم فقط الأعداد الصحيحة التي تتسع لها قيمة `felt252` واحدة (أي أن `u256` غير مدعوم).
- يجب أن يكون 0 هو الفرع الأول.
- يجب أن يتبع كل فرع مقطعًا متسلسلًا، متجاورًا مع الأفرع الأخرى.

لننفّذ لعبة رمي حجر نرد بستة أوجه.
عند رمي هذا الحجر، نحصل على عدد بين 0 و 5.
إذا أعطى الرمي 0 أو 1 أو 2، فقد فزت.
وترمي مرة أخرى إذا حصلت على 3.
وتخسر مع القيم الأخرى:

```rust
fn toss(value: u8) {
    match value {
        0 | 1 | 2 => println!("you won!"),
        3 => println!("you can roll again!"),
        _ => println!("you lost...")
    }
}

fn main() {
    toss(2); // prints "you won!".
    toss(3); // prints "you can roll again!".
    toss(5); // prints "you lost...".
}
```

## مطابقة الصفوف

يمكن أيضًا مطابقة الصفوف مع مجموعة من الأنماط.
وتُصمَّم هذه الأنماط بطريقة مشابهة للصف.

```rust
#[derive(Drop)]
enum DayType {
    Week,
    Weekend,
    Holiday
}

enum Coin {
    Penny,
    Nickel,
    Dime,
    Quarter,
}

fn vending_machine_accept(c: (DayType, Coin)) -> bool {
    match c {
        (DayType::Week, _) => true, // accepts all coins during week day
        (_, Coin::Dime) | (_, Coin::Quarter) => true, // accepts only Dime or Quarter coin for all specified days
        (_, _) => false, // returns false for other instances
    }
}
```

في فرع المطابقة الأخير، لا يهم إن استخدمنا `(_, _)` أو الرمز الشامل `_` فقط لمطابقة أي توليفة من اليوم واللون، لأنهما متماثلان وظيفيًا.
