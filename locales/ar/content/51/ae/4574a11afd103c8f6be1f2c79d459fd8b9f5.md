# مقدمة

## إمكانية أن تكون القيمة `null`

في Java، تُستخدم القيمة الحرفية `null` للدلالة على غياب القيمة.

أنواع البيانات الأولية في Java لها جميعًا قيمة افتراضية، ولذلك لا يمكن أن تكون `null` أبدًا. وبحسب الاصطلاح، تبدأ بحرف صغير، مثل `int`.

أنواع المراجع تحمل عنوان ذاكرة الكائن، ويمكن أن تكون قيمتها `null`. وهي تبدأ عمومًا بحرف كبير، مثل `String`.

محاولة إسناد القيمة `null` إلى متغير أولي ستؤدي إلى خطأ في وقت الترجمة، لأن المتغير يحمل دائمًا قيمة أولية من النوع المُسنَد إليه.

```java
//Throws compile time error stating the required type is int, but null was provided
int number = null;
```

إسناد القيمة `null` إلى متغير مرجعي لن يؤدي إلى خطأ في وقت الترجمة، لأن المتغيرات المرجعية يمكن أن تكون `null`.

```java
//No error will occur as the String variable str is nullable
String str = null;
```
