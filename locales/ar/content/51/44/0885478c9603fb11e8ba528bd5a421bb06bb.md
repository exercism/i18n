# نبذة

في Clojure، يُشار إلى ربط قيمة باسم ما بـ [_var_][vars]. ومتغيرات var العلوية (العامة) شبيهة بالثوابت في لغات أخرى، لكنها تُعاد تعريفها عادةً لتسهيل التطوير الديناميكي.

تُعرَّف متغيرات var العلوية باستخدام [`def`][def]:

```clojure
(def fingers 10)
```

يمكنك استخدام الدوال الأساسية من أجل [العمليات على الأعداد][operators] لإجراء الحسابات على القيم.

يمكن استخدام الماكرو `defn` لتعريف [دالة][functions] تأخذ صفرًا أو أكثر من الوسائط. والدالة تُرجع دائمًا نتيجة آخر تعبير في جسمها.

```clojure
(defn add [x y]
  (+ x y))
```

يتم استدعاء الدالة بتحديد اسمها وتمرير الوسائط لكل معامل من معاملات الدالة.

```clojure
(def five (add 2 3))
```

لا يمكن استخدام الدوال والقيم في Clojure إلا _بعد_ تعريفها. واستخدامها قبل تعريفها يؤدي إلى خطأ في الترجمة.

```clojure
;; Compile error as `add` has not yet been defined
(def seven (add 3 4))

(defn add [x y]
  (+ x y))
```

في Clojure، لا أهمية للمسافات البيضاء إلا في التنسيق.

تُنظَّم دوال Clojure ومتغيرات var في فضاءات الأسماء. وفضاء الأسماء يجمع وظائف مترابطة، ويُعرَّف باستخدام الماكرو `ns`:

```clojure
(ns calculator)

(def pi 3.14)

(defn add [x y]
  (+ x y))
```

تدعم Clojure نوعين من التعليقات. التعليقات أحادية السطر تُسبق بـ `;`، وتُستخدم صيغة `comment` لمنع تقييم كل ما يقع بين `(comment` و`)`.
