# مقدمة

الحلقة أسلوب لتنفيذ عبارة أو أكثر بشكل متكرر.
وتُسمّى كل مرة تُنفَّذ فيها مجموعة من العبارات تكرارًا.

## `while` حلقة

`while` حلقة تنفّذ مجموعة من العبارات ما دام التعبير المنطقي في أعلى الحلقة صحيحًا.
وعندما يصبح التعبير المنطقي خطأً تتوقف الحلقة عن العمل، وينتقل التنفيذ إلى السطر التالي من الكود بعد الحلقة.

إذا كان التعبير المنطقي خطأً منذ البداية فلن تُنفَّذ `while` حلقة إطلاقًا، وسينتقل التنفيذ إلى السطر التالي من الكود بعد الحلقة.

```c
int main() {
    int i = 0;
    while (i < 5) {
        printf("Number is %i\n", i++);
    }    
    return 0;
}
```

من المهم أن يوجد شرط يُنهي الحلقة؛ وإلا فإنها تصبح حلقة لانهائية تعطّل أي تقدّم في الكود.
لو أزلنا `++` من `i` في الكود أعلاه لأصبحت حلقة لانهائية.

## `do` حلقة

يُختبَر التعبير المنطقي في `do` حلقة عند أسفل الحلقة.
و`do` حلقة تُنفَّذ دائمًا مرة واحدة على الأقل، كما في المثال التالي:

```c
do {
    printf("Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
} while (answer != 42); 
// Note that a semicolon is needed after the Boolean expression.
```

مع `while` حلقة سيكون هذا أكثر إسهابًا

```c
printf(""Enter the Answer to the Ultimate Question of Life: ");
scanf("%d", &answer);
while (answer != 42) {
    printf(""Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
}
```

## `for` حلقة

غالبًا ما تُحدّث الحلقة متغيرًا وتنتهي عندما يبلغ المتغير قيمة معينة.
`for` حلقة أسلوب لتهيئة متغير واحد أو أكثر وتحديثه واختباره في سطر واحد داخل الأقواس الهلالية.
القسم الأول لتهيئة المتغير، والقسم الثاني لاختبار المتغير، والقسم الثالث لتحديث قيمة المتغير.

```c
for (int i = 0; i < 5; i++) {
    printf("Number is %i\n", i);
}
```

هذا أقل إسهابًا من نظيره بحلقة `while`، ومع ذلك يبقى مقروءًا.
