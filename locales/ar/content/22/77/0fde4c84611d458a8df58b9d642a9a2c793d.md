# مقدمة

`str` في Python هي [متتالية غير قابلة للتغيير][text sequence] من [نقاط ترميز يونيكود][unicode code points].
وقد تتضمن هذه حروفًا وعلامات تشكيل ومحارف تحديد الموضع وأرقامًا ورموز عملات وإيموجي وعلامات ترقيم ومحارف مسافات وفواصل الأسطر، وغير ذلك الكثير.

تطبّق السلاسل النصية جميع [عمليات المتتاليات الشائعة][common sequence operations]، ويمكن المرور عليها عنصرًا عنصرًا باستخدام الصيغة `for item in <string>` أو `for index, item in enumerate(<string>)`.

يمكن ربط السلاسل النصية بـ `<str> + <other str>` أو `<str>.join(<iterable>)`، وتقسيمها عبر `<str>.split(<separator>)`.
وتوفّر أيضًا خيارات إضافية متعددة للتنسيق والتجميع والقوالب.

ولأنها غير قابلة للتغيير، فإن قيمة كائن `str` في الذاكرة لا تتغير؛ أما الطُرق التي تبدو وكأنها تعدّل السلسلة النصية فتُرجع نسخة جديدة أو كائنًا جديدًا من `str`.

للتعمق في المعلومات التي تُرمّزها السلسلة النصية (أو، _«كيف يعرف الحاسوب كيف يترجم الأصفار والآحاد إلى حروف؟»_)، فإن [منشور المدونة هذا مفيد على الدوام][joel-on-text].
كما تقدّم وثائق Python أيضًا [دليل يونيكود][unicode how-to] المفصّل جدًا، والذي يناقش دعم Python لمعيار يونيكود في وحدات `str` و`bytes` و`re`، واعتبارات اللغات المحلية، وبعض المشكلات الشائعة في الترميز والتحويل.
