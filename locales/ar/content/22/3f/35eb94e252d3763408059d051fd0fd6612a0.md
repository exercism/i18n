# نبذة
يمكن تقسيم أنواع الأعداد المدمجة في C++ إلى أعداد صحيحة وأعداد الفاصلة العائمة.
الأعداد الصحيحة هي أعداد كاملة مثل `0` و`691` و`-2`.
أعداد الفاصلة العائمة هي أعداد تحتوي على فاصلة عشرية مثل `6.02214076` و`0.1` و`-1.616`.

## الأعداد الصحيحة
يوضح المثال التالي تعريف وتهيئة أربعة متغيرات مختلفة

```cpp
int m_morales{9241};              // base 10: 0-9
int a_apaec{0x24CD};              // base 16: 0-9 and A-F
int m_gargan{0b10010000011001};   // base  2: 0-1
int b_reilly{022031};             // base  8: 0-7
                                  // Leading with a 0 not the letter o.
```

عند إسناد قيمة إلى متغير من النوع `int`، يمكنك فعل ذلك مباشرة بقيمة حرفية.
القيمة الحرفية عدد مكتوب مباشرة في الكود مثل `9241`.
توجد قيم حرفية صحيحة مختلفة لعدة أسس للتمثيل.
القيم الحرفية الصحيحة العشرية هي الأكثر شيوعًا وتستخدم الأرقام من `0` إلى `9`.
بإضافة بادئة خاصة، مثل `0x`، يمكن استخدام أسس أخرى.
يعرض المثال أعلاه العدد `9421` بتمثيلاته وببادئاته الأربعة.
جميع المتغيرات مهيأة إلى القيمة نفسها.

لمزيد من التفاصيل حول أنظمة التمثيل المختلفة، ألقِ نظرة على [درس تعليمي صغير][cpp_numerical_bases].

يمكنك استخدام الفاصلة العليا لفصل الأرقام لتسهيل القراءة.
`9'241` هو نفسه `0b0100'100'0001'1001` أو `92'4'1`.

## أعداد الفاصلة العائمة

تأتي القيم الحرفية للفاصلة العائمة بنوعين.
بالإضافة إلى الصيغة البديهية `0.0024`، يمكن استخدام ترميزها العلمي `2.4e-3`.
أكثر أنواع الفاصلة العائمة شيوعًا هو `double`.

## العمليات الحسابية

يدعم C++ العوامل `+` و`-` و`*` و`/` و`(` و`)` و`%` لتكوين تعبيرات.
نتيجة العملية بين عددين صحيحين هي أيضًا عدد صحيح.
ستكون نتيجة `5 / 2` هي `2`.
عندما يكون أحد النوعين المتضمنين نوع فاصلة عائمة، ستكون النتيجة أيضًا من نوع الفاصلة العائمة.
ستكون نتيجة `5.0 / 2` و`5 / 2.0` هي `2.5`.
العامل `%` هو عامل الباقي ويُرجع باقي قسمة صحيحة: `5%3` يساوي `2`.

## عامل الإسناد

يُسند عامل الإسناد قيمة حرفية إلى متغير.
تتم العملية دائمًا من اليمين إلى اليسار، وليس العكس أبدًا.

```cpp
int length = 5;
int width = 2;
length = width;
```

هنا تُسند القيمة الصحيحة `5` إلى المتغير `length`.
ثم تُسند القيمة الصحيحة `2` إلى المتغير `width`.
أخيرًا تُنسخ قيمة `width` إلى المتغير `length` وتضيع القيمة السابقة `5`.
لاحظ أيضًا أننا نُسند قيمة `width` إلى `length` فقط في لحظة عملية الإسناد.
لذلك، إذا تغيرت قيمة `width` لاحقًا، فلن يؤثر ذلك على القيمة التي يأخذها `length`.

يمكن دمج عامل الإسناد مع العوامل الأخرى (الحسابية والبتية) المعروفة بعوامل `compound assignment` وهي `+=` و`-=` و`*=` و`/=` و`%=`.
تعدّل هذه العوامل القيمة الحالية للمتغير بإجراء عملية عليها.

```cpp
// we start with 0 people
int people{};
// we need 0 eggs
int eggs{};
// two people joined:
people += 2;
// people is now 2
// let's add 3 eggs per person
eggs += 3 * people;
// eggs is now 6
```

المتغيران `people` و`eggs` مهيآن إلى `0`.
ثم نضيف القيمة الصحيحة `2` إلى القيمة الحالية `0` للمتغير `people` ونُسندها مرة أخرى إلى `people`.
يصبح `people` الآن `2`.
لاحقًا، نضيف `3` بيضات لكل شخص، ليصبح المجموع `6` بيضات.
الآن نضيف هذه `6` إلى القيمة الحالية `0` للمتغير `eggs` ونُسندها مرة أخرى إلى `eggs`.
سيصبح `eggs` الآن `6`.
التعبير المكافئ سيكون `people = people + 2` و`eggs = eggs + (3 * people)`.

## التحويل

التحويل هو تغيير نوع إلى نوع آخر.
إذا احتجنا إلى `double`، فيمكن استخدام `int` بدلًا منه.
تُعالج حالة المثال `5.0 / 2` من الأعلى بتحويل ضمني للقيمة `2` إلى `2.0`.
قد يفقد `double` الذي يُحوَّل إلى `int` بعض المعلومات.
من الممارسات الجيدة جعل هذه التحويلات إلى نوع آخر T صريحة عبر `static_cast<T>`.
لا يُنصح بالتحويل القديم بأسلوب C عبر `(T)` في C++ الحديثة، لكن يجب معرفته مع ذلك.

```cpp
double pi{3.14};
int about_2_times_pi_cpp{static_cast<int>(pi) * 2};
// Old C-style cast:
int about_2_times_pi_c{(int)pi * 2};
```

## الدقة والتمثيل

لا يمكن أن تكون الأعداد في C++ كبيرة بشكل اعتباطي.
`int` مثلًا يُمثَّل بـ 32 بت.
هذا يكفي لمجموعة من `2^32` عددًا، أي نحو 4 مليارات.
بما يشمل `0`، يحدد هذا أكبر وأصغر عدد `int` على أنهما `-2^31` و`2^31 - 1`.

عادةً ما تُنفَّذ أعداد الفاصلة العائمة باستخدام دقة تبلغ 15 منزلة عشرية، لكن تمثيلها يختلف حسب النظام المضيف.
