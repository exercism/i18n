# نبذة

الملف تيار له اسم على القرص. توفّر مفردات [`io.files`][io.files] طريقتين للتعامل معه: كلمات مريحة تعمل على الملف كاملًا فتقرأ كل شيء أو تكتبه في نداء واحد، وفواتح للتيار (مُركِّبات `with-…`) للقراءة أو الكتابة تدريجيًا. وكلتاهما تقومان على [بروتوكول التيار][stream-protocol] نفسه الذي تقوم عليه التيارات الموجودة في الذاكرة من مفهوم `io-streams`: فـ `<file-reader>` و`<string-reader>` تستجيبان للكلمات نفسها.

تأخذ كل كلمة من كلمات الملفات **ترميزًا**، وهو المخطط الذي يحوّل البايتات إلى محارف والعكس. وبالنسبة إلى النصوص يكون هذا الترميز دائمًا تقريبًا [`utf8`][utf8] من `io.encodings.utf8`، أما العمل مع البيانات الثنائية فيستخدم `latin1` أو ترميز `<byte-array>`.

## قراءة الملف كاملًا

```
file-contents   ( path encoding -- str )
file-lines      ( path encoding -- seq )
```

تُرجع `file-contents` الملف بأكمله في صورة سلسلة نصية واحدة. وتُرجع `file-lines` أسطره في صورة مصفوفة، بعد إزالة نهايات الأسطر منها، وذلك مفيد عندما يمثل كل سطر سجلًا.

```factor
USING: io.encodings.utf8 io.files ;

"forecast.txt" utf8 file-contents   ! => "sunny\ncloudy\n"
"forecast.txt" utf8 file-lines      ! => { "sunny" "cloudy" }
```

## كتابة الملف كاملًا

```
set-file-contents   ( str path encoding -- )
set-file-lines      ( seq path encoding -- )
```

كلتاهما **تستبدلان** الملف، وتنشئانه إن لم يكن موجودًا. تكتب `set-file-contents` سلسلة نصية كما هي، بينما تكتب `set-file-lines` كل عنصر من عناصر التسلسل في سطر مستقل، مع إضافة الأسطر الجديدة اللازمة.

```factor
{ "sunny" "cloudy" } "forecast.txt" utf8 set-file-lines
! forecast.txt now holds "sunny\ncloudy\n"
```

## التيارات محدَّدة النطاق

عندما تريد الإضافة إلى ملف، أو القراءة والكتابة قطعة قطعة، فافتحه بواسطة أحد مُركِّبات `with-…` واستخدم كلمات التيار الحالية داخل `quotation`:

```
with-file-reader     ( path encoding quot -- )
with-file-writer     ( path encoding quot -- )
with-file-appender   ( path encoding quot -- )
```

```factor
USING: io io.encodings.utf8 io.files ;

"log.txt" utf8 [ "another line" print ] with-file-appender
```

تُفرِّغ `with-file-writer` الملف أولًا، أما `with-file-appender` فتحتفظ بالمحتوى الموجود وتكتب بعده. وكل واحدة منها نطاق مُدمِّر: يُغلق مقبض الملف عند انتهاء `quotation`، حتى لو طرح استثناءً، وهو الضمان نفسه الذي توفره مُركِّبات `boatswains-bilge`، لكنه هنا مخصص للملفات.

## الملف كاملًا أم النطاق المحدَّد؟

استخدم `file-contents` / `file-lines` / `set-file-contents` / `set-file-lines` عندما يكون الملف صغيرًا بما يكفي ليُحفظ في الذاكرة وتريد الملف بأكمله دفعة واحدة. واستخدم فواتح `with-…` عندما تحتاج إلى الإضافة، أو إلى تمرير ملف كبير سطرًا سطرًا باستخدام `readln`، أو إلى مزج القراءات بالكتابات، أي في كل موضع يكون فيه حفظ الملف بأكمله في الذاكرة مضيعةً أو خطأً.
