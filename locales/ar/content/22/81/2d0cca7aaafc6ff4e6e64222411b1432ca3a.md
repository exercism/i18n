# الاختبارات

ستحتاج إلى تثبيت [Godot][installation] بشكل صحيح لاستخدام مشغّل الاختبارات.

## تشغيل الاختبارات

يُستخدم [مشغّل الاختبارات][test runner] لتحميل الحلول واختبارها.
عند تنزيل تمرين محليًا، تُضمَّن نسخة من مشغّل الاختبارات، إلى جانب نص صدفي لاستدعائه.

لتشغيل التمرين، شغّل ببساطة نص `run_tests` في مجلد التمرين باستخدام `bash`.

على سبيل المثال،

```bash
cd "$(exercism workspace)/gdscript/hello-world"
bash run_tests
```
