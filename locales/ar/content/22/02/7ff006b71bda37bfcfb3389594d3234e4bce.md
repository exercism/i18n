# نبذة

المصفوفة في Gleam هي مجموعة غير قابلة للتغيير تتكوّن من صفر أو أكثر من القيم. ويجب أن تكون جميع القيم في المصفوفة من النوع نفسه. ولأن المصفوفات غير قابلة للتغيير، فبمجرد إنشاء المصفوفة لا يمكن أن تتغير قيمتها أبدًا. وأي دوال أو عوامل تبدو وكأنها تعدّل المصفوفة، مثل إضافة عنصر، ستُرجع في الحقيقة مصفوفة جديدة.

يمكن تعريف المصفوفات كما يلي:

```gleam
let empty = []
let singleValue = [5]
let threeValues = ["a", "b", "c"]
```

الطريقة الأكثر شيوعًا لإضافة عنصر إلى مصفوفة هي إضافته في مقدمتها باستخدام صيغة الانتشار:

```gleam
let two_to_four = [2, 3, 4]
let one_to_four = [1, ..two_to_four]
// -> [1, 2, 3, 4]
```

تحتوي وحدة [`gleam/list`](https://hexdocs.pm/gleam_stdlib/gleam/list.html) في مكتبة Gleam القياسية على العديد من الدوال المفيدة للتعامل مع المصفوفات. وهذه الوحدة شائعة الاستخدام جدًا في كود Gleam، لذا من الجيد أن تكون على دراية بها.

يمكن استخدام أنماط المصفوفات في تعبيرات `case` للمطابقة مع المصفوفات وإسناد القيم التي تحتويها إلى متغيرات:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [] -> "Empty list"
    [x] -> "List with one item: " <> x
    [x, y] -> "List with two items: " <> x <> " and " <> y
    _ -> "List with three or more items"
  }
}
```

وإلى جانب المطابقة مع المصفوفات ذات الطول المحدد، يمكن استخدام صيغة الانتشار للمطابقة مع المصفوفات التي يبلغ طولها حدًا أدنى معينًا:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [_, _, ..] -> "List with at least two items"
    [_] -> "List with one item"
    [] -> "Empty list"
  }
}
```

يمكن أيضًا استخدام صيغة الانتشار لإسناد بقية المصفوفة إلى متغير:

```gleam
pub fn remove_first_item(list: List(String)) -> List(String) {
  case list {
    // Return the list without the first item
    [_, ..rest] -> rest

    // There's no first item to remove, return an empty list
    _ -> []
  }
}
```

ينبغي أن تحتوي تعبيرات `case` على نمط لكل قيمة ممكنة من النوع الذي تتم المطابقة عليه، لذا يُستخدم غالبًا نمط تجاهل أخير (`_`) للتعامل مع أي قيم متبقية.
