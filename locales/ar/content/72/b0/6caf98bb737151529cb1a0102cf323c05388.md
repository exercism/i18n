# الاختبارات

لتشغيل اختبار التمرين باستخدام واجهة سطر الأوامر، نفّذ الأمر التالي من مجلد التمرين:

```bash
clojure -M:test
```

## REPL

لتشغيل اختبار التمرين باستخدام REPL، نفّذ الأمر التالي من مجلد التمرين:

```bash
$ clojure -m cljs.main -re node
```

ثم استدعِ `require` على فضاء أسماء اختبار التمرين وفضاء أسماء اختبار Clojure):

```clojure
;; replace <exercise> with the exercise's name
=> (require '<exercise>-test)
nil
;; and the test namespace
=> (require 'cljs.test)
```

غيّر `ns` إلى فضاء أسماء الاختبار:

```clojure
;; replace <exercise> with the exercise's name
=> (ns <exercise>-test)
nil
```

ثم استدعِ `run-tests`:

```clojure
=> (cljs.test/run-tests)
```
