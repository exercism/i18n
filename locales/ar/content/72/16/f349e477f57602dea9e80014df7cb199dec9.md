# التثبيت

## خيارات التثبيت

يتوفّر الإصدار الحالي من Unison لمستخدمي Mac OS X وLinux 64-bit وWindows! نأمل أن تأتي وتتحدّث إلينا في منتدى Exercism أو في [Unison Discord](https://unison-lang.org/discord) إذا كنت تجرّب Unison. تعال واطرح أسئلتك، وأبلغنا عن أي مشكلات قد تواجهها! نريد أن تكون تجربتك عند البداية مرحّبة وإيجابية! 😊

يمكنك تنزيل Unison عبر [homebrew](https://brew.sh/) أو [Nix](https://github.com/ceedubs/unison-nix/#usage)، أو مباشرةً عبر الحزم الثنائية الجاهزة. كل خيارات التنزيل هذه موصوفة في [صفحة تعليمات التثبيت على موقعنا](https://www.unison-lang.org/learn/quickstart/#installation-options). وبعد أن تثبّت UCM، عُد إلى هنا!

### الخيار 1: استخدام Homebrew

أولًا [ثبّت homebrew](https://brew.sh/) إن لم تكن قد فعلت ذلك بعد.

ثم أدخل هذه الأوامر من سطر الأوامر:

```
brew tap unisonweb/unison
brew install unison-language
```

سيؤدي هذا إلى تثبيت الملف التنفيذي لمدير قاعدة كود Unison، وهو `ucm`. وإذا كنت تُرقّي من إصدار سابق، فما عليك سوى تنفيذ

```
brew upgrade unison-language.
```

ملاحظة: إذا طُلب منك اسم مستخدم GitHub وكلمة مرور في هذه المرحلة، فتأكّد من أنك كتبت unisonweb/unison بشكل صحيح.

### الخيار 2: التثبيت يدويًا لمستخدمي Mac وLinux

[روابط التثبيت اليدوي لـ Linux وMac متوفّرة هنا](https://www.unison-lang.org/learn/quickstart/#installation-options) ضمن قسم التنزيل اليدوي الخاص بكل من Linux وMac.

ستنفّذ في صدفة الأوامر أمرًا يشبه هذا، لكن الرابط أعلاه يحتوي على أحدث ملف ثنائي:

```
mkdir unisonlanguage
curl -L https://github.com/unisonweb/unison/releases/download/release_VERSION_NAME/ucm-YOUR_PLATFORM.tar.gz --output unisonlanguage/ucm.tar.gz
tar -xzf unisonlanguage/ucm.tar.gz -C unisonlanguage
./unisonlanguage/ucm
```

### الخيار 3: التثبيت يدويًا لمستخدمي Windows

1. اضبط تطبيق الطرفية الافتراضي لديك على "Windows Terminal" للحصول على أفضل النتائج. ابحث عن "Terminal" في الإعدادات، أو اتبع [هذا الدليل.](https://bit.ly/3IXwdlY)
2. إذا لم تكن متأكدًا من أنك تملكه بالفعل، فثبّت Git:
  * عبر winget: `winget install --id Git.Git -e --source winget`
  * إذا كنت تستخدم Windows 10 وليس لديك winget، فيمكنك تثبيته من [متجر Microsoft](https://www.microsoft.com/en-us/p/app-installer/9nblggh4nns1)، ثم تنفيذ الأمر أعلاه.
3. [نزّل UCM عبر الرابط الموجود هنا](https://www.unison-lang.org/learn/quickstart/#installation-options) واستخرجه إلى الموقع الذي تختاره.
4. نفّذ `ucm.exe`

### الخيار 4: التثبيت عبر Nix
توجّه إلى [https://github.com/ceedubs/unison-nix/#usage](https://github.com/ceedubs/unison-nix/#usage) واتبع التعليمات الموجودة في ملف readme هناك.

## أنشئ قاعدة كود Unison

نفّذ `ucm` لتهيئة قاعدة كود Unison في `$HOME/.unison`. هنا سيخزّن Unison تعريفات الدوال والأنواع وفضاءات الأسماء، وما إلى ذلك. وبشكل افتراضي، سيبدأ مدير قاعدة كود Unison (ويُختصر بـ "UCM") في تنزيل المكتبة القياسية المسماة `base`، والتي ستستخدمها لكتابة كود Unison. قد يستغرق هذا لحظة! 🕰

## سير العمل في Unison

عندما تريد كتابة كود Unison، ستنفّذ أمر `ucm` لبدء مدير قاعدة الكود. سيراقب UCM عندئذٍ التغييرات في أي ملف ينتهي بـ `.u` في المجلد الذي نُفّذ منه. على سبيل المثال، قد تنفّذ دوال في ملف يُسمّى `scratch.u` داخل مجلد يُسمّى `~/exercism/unison/my-exercise/`. ينبغي أن تنتقل بـ `cd` إلى `~/exercism/unison/my-exercise/` وتنفّذ `ucm`. هذا يضمن أن UCM يراقب ملف `scratch.u` بحثًا عن التغييرات.

وإذا التبس عليك الأمر حول المجلد الذي يراقب فيه `ucm` تغييرات الملفات، فسيُطبع ذلك في شاشة الترحيب عند بدء تشغيل واجهة سطر الأوامر.

```
👀 I'm watching for changes to .u files under /Users/myUser/exercism/unison/my-exercise
```

[اطّلع على مزيد من نصائح سير العمل هنا!](https://exercism.org/docs/tracks/unison/workflow)

## دعم المحرّرات

يمكنك استخدام أي محرّر نصوص لكتابة ملفات `.u` الخاصة بك. يدعم Unison [بروتوكول خادم اللغة](https://github.com/unisonweb/unison/blob/trunk/docs/language-server.markdown)، لذا يمكن لبيئة التطوير المتكاملة المفضّلة لديك المساعدة في أمور مثل عرض الأنواع عند التحويم والإكمال التلقائي. فيما يلي بعض المحرّرات الشائعة التي تدعم Unison:

### Vim

باستخدام [vim-plug](https://github.com/junegunn/vim-plug):

1. ثبّت [`vim-plug`](https://github.com/junegunn/vim-plug) إن لم تكن قد فعلت ذلك بعد.
2. أضف ما يلي إلى ملف .vimrc: `Plug 'unisonweb/unison', { 'branch': 'trunk', 'rtp': 'editor-support/vim' }`
3. نفّذ أمر vim التالي `:PlugInstall`.

لمزيد من المعلومات نفّذ `:help unison` من داخل vim أو اطّلع على [مستند المساعدة على الإنترنت](https://github.com/unisonweb/unison/blob/trunk/editor-support/vim/doc/unison.txt).

### Atom
من الطرفية، نفّذ:

```
apm install unisonweb/atom-unison
```

### VS Code

1. افتح عرض الإضافات بالنقر على أيقونة الإضافات في شريط الأنشطة على جانب VS Code، أو باستخدام ⇧⌘X.
2. ابحث عن "unison"
3. ثبّت [إضافة Unison لـ VS Code](https://marketplace.visualstudio.com/items?itemName=unison-lang.unison)

### Emacs
ثبّت [`unison-mode`](https://github.com/dariooddenino/unison-mode-emacs).
