# التعليمات

في هذا التمرين، ستكتب بعض الكود لمساعدتك في الاستعداد لشراء مركبة.

لديك ثلاث مهام: مهمة لتحديد ما إذا كنت تستطيع تحمّل الدفعات الشهرية، ومهمة لمساعدتك في الاختيار بين مركبتين وتحديد الرخصة التي ستحتاج إليها، ومهمة لتقدير السعر المقبول لمركبة مستعملة.

## 1. احسب ما إذا كنت تستطيع تحمّل الدفعات الشهرية لسيارة معينة

يقدّم جميع تجار السيارات في مدينتك عرضًا ترويجيًا لمدة خمس سنوات بفائدة 0%، وتودّ الاستفادة منه.
لكنك لست متأكدًا مما إذا كنت تستطيع تحمّل الدفعات الشهرية للسيارة التي تريدها.

الدفعة الشهرية هي السعر الإجمالي للسيارة مقسومًا على عدد الأشهر في فترة الخمس سنوات.

نفّذ الدالة `canIBuy(vehicle:price:monthlyBudget:)` التي تأخذ الوسائط التالية:
- `vehicle` - اسم المركبة التي تريد شراءها.
- `price` - سعر المركبة التي تريد شراءها.
- `monthlyBudget` - المبلغ الذي يمكنك تحمّل دفعه كل شهر.

يجب أن تُرجع الدالة الرسالة التالية وفقًا للشروط التالية:
- إذا كانت الدفعة الشهرية للمركبة أقل من أو تساوي الميزانية الشهرية، فأرجع الرسالة `"Yes! I'm getting a <vehicle>"`.
- إذا تجاوزت الدفعة الشهرية ميزانيتك الشهرية بنسبة تصل إلى 10% (شاملة)، فأرجع الرسالة `"I'll have to be frugal if I want a <vehicle>"`.
- إذا تجاوزت الدفعة الشهرية ميزانيتك الشهرية بنسبة تزيد على 10%، فأرجع الرسالة `"Darn! No <vehicle> for me"`.

```swift
canIBuy(vehicle: "1974 Ford Pinto", price: 516.32, monthlyBudget: 100.00)
// returns "Yes! I'm getting a 1974 Ford Pinto"
canIBuy(vehicle: "2011 Bugatti Veyron", price: 2_250_880.00, monthlyBudget: 10000.00)
// returns "Darn! No 2011 Bugatti Veyron for me"
canIBuy(vehicle: "2020 Indian FTR 1200", price: 12_500, monthlyBudget: 200)
// returns "I'll have to be frugal if I want a 2020 Indian FTR 1200"
```

## 2. حدّد نوع رخصة القيادة التي ستحتاج إليها

لقد قررت شراء مركبة مستعملة، وتحتاج إلى تحديد نوع رخصة القيادة التي ستحتاج إليها لقيادتها.

نفّذ الدالة `licenseType(numberOfWheels:)` التي تأخذ الوسيط `numberOfWheels`، وهو عدد عجلات المركبة التي تريد شراءها.

يجب أن تُرجع الدالة الرسالة التالية وفقًا للشروط التالية:
- إذا كان عدد العجلات 2 أو 3، فأرجع الرسالة `"You will need a motorcycle license for your vehicle"`.
- إذا كان عدد العجلات 4 أو 6، فأرجع الرسالة `"You will need an automobile license for your vehicle"`.
- إذا كان عدد العجلات 18، فأرجع الرسالة `"You will need a commercial trucking license for your vehicle"`.
- إذا كان العدد أي عدد آخر، فأرجع الرسالة `"We do not issue licenses for those types of vehicles"`.

```swift
licenseType(numberOfWheels: 2)
// returns "You will need a motorcycle license for your vehicle"
licenseType(numberOfWheels: 6)
// returns "You will need an automobile license for your vehicle"
licenseType(numberOfWheels: 18)
// returns "You will need a commercial trucking license for your vehicle"
licenseType(numberOfWheels: 0)
// returns "We do not issue licenses for those types of vehicles"
```

## 3. احسب تقديرًا لسعر مركبة مستعملة

الآن بعد أن اتخذت قرارك، تريد التأكد من حصولك على سعر عادل عند الوكالة.
وبما أنك مهتم بشراء مركبة مستعملة، فإن السعر يعتمد على عمر المركبة.
وكتقدير تقريبي، افترض أنه إذا كان عمر المركبة أقل من 3 سنوات، فسيبلغ سعرها 80% من سعرها الأصلي عندما كانت جديدة تمامًا.
وإذا كان عمرها 10 سنوات على الأقل، فسيبلغ سعرها 50%.
وإذا كان عمر المركبة 3 سنوات على الأقل ولكن ليس أكثر من 10 سنوات، فسيبلغ سعرها 70% من السعر الأصلي.

نفّذ الدالة `calculateResellPrice(originalPrice:yearsOld:)` التي تأخذ الوسيطين `originalPrice`، الذي يحمل السعر الأصلي للمركبة، و`yearsOld`، الذي يحمل عمر المركبة بالسنوات.
ويجب أن تُرجع الدالة سعر إعادة بيع المركبة.

```swift
calculateResellPrice(originalPrice: 1000, yearsOld: 1)
// returns 800
calculateResellPrice(originalPrice: 1000, yearsOld: 5)
// returns 700
calculateResellPrice(originalPrice: 1000, yearsOld: 15)
// returns 500
```
