# التعليمات

أنت تدير ألعاب الحظ في صالة الألعاب على ممشى الشاطئ. يرمي اللاعبون النرد، وتلتقط آلة المخالب جائزة، وتحتاج طاولة البطاقات إلى خلط رزمتها وتوزيع الأيدي. كل ذلك يعمل بالعشوائية. وفي نهاية الليلة تريد أيضًا ميزة "إعادة التشغيل" حتى يمكن تشغيل لعبة متنازع عليها مرة أخرى من البذرة نفسها.

## 1. ارمِ حجر النرد

عرّف `roll-die` بحيث تأخذ عدد الأوجه وتُرجع رمية في النطاق من `1` إلى `sides` (شاملًا الطرفين).

```factor
6 roll-die .
! => 4   (some value from 1..6)
```

## 2. التقط جائزة

عرّف `pick-prize` بحيث تأخذ متتالية من الجوائز وتُرجع واحدة منها عشوائيًا.

```factor
{ "teddy" "goldfish" "keyring" } pick-prize .
! => "goldfish"
```

## 3. اخلط الرزمة

عرّف `shuffle-deck` بحيث تأخذ رزمة (متتالية) وتُرجعها وقد رُتّبت بطاقاتها بترتيب عشوائي.

```factor
{ 1 2 3 4 5 } shuffle-deck .
! => { 3 1 5 2 4 }
```

## 4. وزّع يدًا

عرّف `deal-hand` بحيث تأخذ رزمة وعددًا `n`، وتُرجع `n` من البطاقات *المختلفة* من الرزمة.

```factor
{ 10 20 30 40 50 } 3 deal-hand .
! => { 40 10 30 }
```

## 5. أعِد التشغيل من بذرة

عرّف `play-seeded` بحيث تأخذ بذرة و`quotation`، وتشغّل `quotation` باستخدام مولّد بذرته ذلك العدد الصحيح، بحيث تُنتج البذرة نفسها دائمًا النتيجة نفسها. وينبغي إرجاع نتيجة `quotation` إلى المستدعي.

```factor
42 [ 6 roll-die ] play-seeded .
! => the same value every time for seed 42

! Same seed, same game:
99 [ 5 deal-hand ] play-seeded   99 [ 5 deal-hand ] play-seeded   =  .
! => t
```
