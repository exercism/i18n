# مقدمة

## العودية الذيلية

عند استخدام [العودية][exercism-recursion] للتنقل عبر الكائنات القابلة للتعداد (المصفوفات، وسلاسل البتات، والسلاسل النصية)، غالبًا ما يكون هناك اعتباران:

- مقدار الذاكرة اللازمة لتخزين أثر استدعاءات الدوال العودية
- كيفية بناء الحل بكفاءة

للتعامل مع هذين الاعتبارين، يمكن استخدام _مُراكم_.

المُراكم متغيّر يُمرَّر إلى جانب البيانات. ويُستخدم لتمرير الحالة الحالية لتنفيذ الدالة، من استدعاء إلى آخر، إلى أن نصل إلى _الحالة الأساسية_. وفي الحالة الأساسية، يُستخدم المُراكم لإرجاع القيمة النهائية لاستدعاء الدالة العودية.

يجب أن يهيّئ المُراكم كاتب الدالة، لا مستخدمها. ولتحقيق ذلك، عرّف دالتين: دالة عامة تستقبل البيانات الضرورية فقط كوسائط وتهيّئ المُراكم، ودالة خاصة تستقبل المُراكم أيضًا. في Elixir، من الأنماط الشائعة إضافة البادئة `do_` إلى اسم الدالة الخاصة.

```elixir
# Count the length of a list without an accumulator
def count([]), do: 0
def count([_head | tail]), do: 1 + count(tail)

# Count the length of a list with an accumulator
def count(list), do: do_count(list, 0)

defp do_count([], count), do: count
defp do_count([_head | tail], count), do: do_count(tail, count + 1)
```

يتيح استخدام المُراكم تحويل الدوال العودية إلى دوال _عودية ذيلية_. وتكون الدالة عودية ذيلية إذا كان _آخر_ ما تنفّذه هو استدعاء لنفسها.
