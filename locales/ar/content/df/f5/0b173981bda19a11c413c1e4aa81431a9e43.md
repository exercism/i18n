# مقدمة

## الأعداد

توجد في Python ثلاثة أنواع مختلفة من الأعداد المدمجة: `ints` و`floats` و`complex`. لكنك في هذا التمرين ستتعامل مع `ints` و`floats` فقط.

### ints

`ints` هي أعداد صحيحة، مثل `1234` و`-10` و`20201278`.

تتمتع الأعداد الصحيحة في Python بـ[دقة تعسفية][arbitrary-precision]، فلا يحد عدد أرقامها إلا الذاكرة المتاحة في النظام المضيف.

### floats

`floats` هي أعداد تحتوي على فاصلة عشرية، مثل `0.0` و`3.14` و`-9.01`.

عادةً ما تُنفَّذ أعداد الفاصلة العائمة في Python باستخدام `double` في C (_بدقة 15 خانة عشرية_)، لكن تمثيلها يختلف حسب النظام المضيف وتفاصيل التنفيذ الأخرى. وقد يُسبب هذا بعض المفاجآت عند التعامل مع `floats`، لكنه "جيد بما يكفي" في معظم الحالات.

## العمليات الحسابية

تدعم Python العمليات الحسابية بين `ints` و`floats` بشكل كامل. وهي تُحوّل الأعداد الأضيق لتطابق نظيراتها الأوسع عند استخدامها مع العوامل الحسابية الثنائية (`+` و`-` و`*` و`/` و`//` و`%`).

تعتبر Python أن `ints` أضيق من `floats`. لذا فإن استخدام `float` في تعبير يضمن أن تكون النتيجة `float` أيضًا. لكن عند إجراء القسمة، تكون النتيجة دائمًا `float` حتى لو استُخدمت أعداد صحيحة فقط.

```python
# The int is widened to a float here, and a float type is returned.
>>> 3 + 4.0
7.0
>>> 3 * 4.0
12.0
>>> 3 - 2.0
1.0
# Division always returns a float.
>>> 6 / 2
3.0
>>> 7 / 4
1.75
# Calculating remainders.
>>> 7 % 4
3
>>> 2 % 4
2
>>> 12.75 % 3
0.75
```

إذا احتجت إلى نتيجة من نوع `int`، فيمكنك استخدام `//` لقطع النتيجة.

```python
>>> 6 // 2
3
>>> 7 // 4
1
```

لتحويل `float` إلى `int`، يمكنك استخدام `int()`. ولتحويل `int` إلى `float`، يمكنك استخدام `float()`.

```python
>>> int(6 / 2)
3
>>> float(1 + 2)
3.0
```
