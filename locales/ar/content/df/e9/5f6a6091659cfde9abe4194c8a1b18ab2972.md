# مقدمة

تشكّل المحارف والسلاسل النصية الأساس لتمثيل النصوص في Elm.
يمكن اعتبار السلاسل النصية مصفوفات من المحارف، ولمعظم دوال `List` مقابل في وحدة `String`.

## المحارف

يمثّل النوع `Char` محرف يونيكود واحدًا محاطًا بعلامتي اقتباس مفردتين، مثل `'a'`.
وتوفّر وحدة `Char` دوال تحقق (`Char -> Bool`) لفحص خصائص المحرف: `isUpper` و`isLower` و`isAlpha` و`isAlphaNum`.
كما توفّر الوحدة دوال لتحويل المحرف عبر `toUpper` و`toLower` و`toLocaleUpper` و`toLocaleLower`، وكذلك التحويل من قيمته العددية في يونيكود (`Int`) وإليها عبر `toCode` و`fromCode`.

## السلاسل النصية

يوفّر النوع `String` تمثيلًا مدمجًا لمعالجة السلاسل النصية بكفاءة، ويمكنه تمثيل أي تسلسل من محارف يونيكود.
تُمثَّل السلاسل النصية بعلامتي اقتباس مزدوجتين: `"this is a string"`.
أما السلاسل النصية متعددة الأسطر فتُمثَّل بثلاث علامات اقتباس مزدوجة، ويمكن أن تحتوي على علامات اقتباس وأسطر جديدة غير مُهرَّبة.

```elm 
haiku = 
"""
    Code's strings entwine
    , In binary, thoughts combine
    , Logic's elegant line.
"""
```

## معالجة السلاسل النصية

`reverse : String -> String` تعكس السلسلة النصية.
```elm 
reverse "Hello world." 
    --> ".dlrow olleH"
```

`repeat : Int -> String -> String` تكرّر سلسلة نصية n مرة.
```elm 
repeat 2 "Hello world." 
    --> "Hello world.Hello world."
```

`replace : String -> String -> String -> String` تستبدل كل حالات ظهور سلسلة نصية فرعية معيّنة.
```elm
replace "Hello" "Goodbye cruel" "Hello world." 
    --> "Goodbye cruel world."
```

`append : String -> String -> String` تلحق سلسلتين نصيتين ببعضهما.
ويمكن أيضًا استخدام العامل `++` للقيام بذلك.
```elm
append "butter" "fly" 
    --> "butterfly"
"butter" ++ "fly" 
    --> "butterfly"
```

`concat : List String -> String` تدمج مصفوفة من السلاسل النصية في سلسلة نصية واحدة.
```elm
concat ["never", "the", "less"] 
    --> "nevertheless"
```

`split : String -> String -> List String` تقسّم سلسلة نصية إلى مصفوفة من السلاسل النصية عند الفاصل المعطى.
```elm
split ";" "cat;dog;cow" 
    --> ["cat", "dog", "cow"]
```

`join : String -> List String -> String` تجمع مصفوفة من السلاسل النصية معًا باستخدام فاصل معيّن.
```elm
join "a" ["H", "w", "ii", "n"] 
    --> "Hawaiian"
```

`words : String -> List String` تقسّم سلسلة نصية إلى سلاسل نصية، بالتفريق عند مقاطع من المسافات البيضاء.
```elm
words "How are \t you? \n Good?" 
    --> ["How", "are", "you?", "Good?"]
```

`lines : String -> List String` تقسّم سلسلة نصية إلى أسطر، بالتفريق عند الأسطر الجديدة.
```elm
lines "How are you?\nGood?" 
    --> ["How are you?", "Good?"]
```

`cons : Char -> String -> String` تضيف محرفًا إلى بداية سلسلة نصية.
```elm
cons 'T' "he truth is out there" 
    --> "The truth is out there"
```

`uncons : String -> Maybe ( Char, String )` تقسّم سلسلة نصية غير فارغة إلى رأسها وذيلها.
يتيح لك هذا إجراء مطابقة الأنماط على السلاسل النصية تمامًا كما تفعل مع المصفوفات.
أما السلاسل النصية الفارغة فتُرجع `Nothing`.
```elm
uncons "abc" 
    --> Just ('a', "bc")
uncons ""
    --> Nothing
```

## الحصول على السلاسل النصية الفرعية

`slice : Int -> Int -> String -> String` تأخذ سلسلة نصية فرعية بناءً على فهرس بداية وفهرس نهاية.
تُحسب الفهارس السالبة بدءًا من نهاية المصفوفة.
```elm
slice 0 6 "snakes on a plane!" 
    --> "snakes"
slice 0 -7 "snakes on a plane!"
    --> "snakes on a"
```

`left : Int -> String -> String` و`right : Int -> String -> String` تأخذان n محرفًا من الجانب الأيسر أو الأيمن للسلسلة النصية على الترتيب.

```elm
left 2 "Mulder" 
    --> "Mu"
right 2 "Scully" 
    --> "ly"
```

`dropLeft : Int -> String -> String` و`dropRight : Int -> String -> String` تحذفان n محرفًا من الجانب الأيسر أو الأيمن للسلسلة النصية على الترتيب.
```elm
dropRight 6 "Hello world." 
    --> "Hello"
dropLeft 6 "Hello world." 
    --> "world"
```

## فحص خصائص السلاسل النصية

`length : String -> Int` تُرجع عدد المحارف في سلسلة نصية.
```elm 
length "Hello world." 
    --> 12
```

`isEmpty : String -> Bool` تحدّد ما إذا كانت سلسلة نصية فارغة.
```elm 
isEmpty "Hello world." 
    --> False
```

`contains : String -> String -> Bool` تتحقق مما إذا كانت السلسلة النصية الثانية تحتوي على الأولى.
```elm
contains "the" "theory" 
    --> True
contains "THE" "theory" 
    --> False
```

`startsWith : String -> String -> Bool` و`endsWith : String -> String -> Bool` تتحققان مما إذا كانت السلسلة النصية الثانية تبدأ أو تنتهي بسلسلة نصية فرعية معيّنة.
```elm
startsWith "the" "theory" 
    --> True
endsWith "ory" "theory" 
    --> True
```

`indexes : String -> String -> List Int` تحصل على مصفوفة تضم كل فهارس البداية لسلسلة نصية فرعية داخل سلسلة نصية أخرى.
```elm
indexes "ss" "Mississippi"  
    --> [2, 5]
```

## تحويل السلاسل النصية
`toInt : String -> Maybe Int` تحاول تحويل سلسلة نصية إلى `Just Int`، وتُرجع `Nothing` للسلاسل النصية سيئة التنسيق.
```elm
toInt "-42" 
    --> Just -42
toInt "3.1" 
    --> Nothing
toInt "two" 
    --> Nothing
```

`fromInt : Int -> String` تحوّل عددًا صحيحًا إلى سلسلة نصية.
```elm
fromInt -42 
    --> "-42"
```

`toFloat : String -> Maybe Float` تحاول تحويل سلسلة نصية إلى عدد عشري، وتفشل مع السلاسل النصية سيئة التنسيق.
```elm
toFloat "-42" 
    --> Just -42.0
toFloat "3.1" 
    --> Just 3.1
toFloat "two" 
    --> Nothing
```

`fromFloat : Float -> String` تحوّل عددًا عشريًا إلى سلسلة نصية.
```elm
fromFloat 3.9 
    --> "3.9"
```

`toList : String -> List Char` و`fromList : List Char -> String` تحوّلان سلسلة نصية إلى مصفوفة من المحارف والعكس على الترتيب.
```elm 
toList "abc" 
    --> ['a', 'b', 'c']
fromList ['a', 'b', 'c'] 
    --> "abc"
```

`fromChar : Char -> String` تحوّل محرفًا إلى سلسلة نصية.
```elm
fromChar 'a' 
    --> "a"
```

## تنسيق السلاسل النصية

`toUpper : String -> String` و`toLower : String -> String` تحوّلان السلاسل النصية إلى أحرف كبيرة كلها أو أحرف صغيرة كلها على الترتيب.
وهي مفيدة في المقارنات غير الحساسة لحالة الأحرف.
```elm
toUpper "skinner" 
    --> "SKINNER"
toLower "X-FILES" 
    --> "x-files"
```

`pad : Int -> Char -> String -> String` تحشو سلسلة نصية من الجانبين بالمحرف `Char` المعطى حتى تصل إلى الطول المحدد.
```elm
pad 5 ' ' "11"  
    --> "  11 "
```
وبالمثل، تحشو `padLeft` و`padRight` سلسلة نصية من أحد الجانبين حتى تصل إلى طول محدّد.

`trim : String -> String` تزيل المسافات البيضاء من جانبي سلسلة نصية.
```elm
trim "  hats  \n" 
    --> "hats"
```
وتزيل `trimLeft` و`trimRight` المسافات البيضاء من أحد جانبي سلسلة نصية.

## الدوال ذات الرتبة الأعلى

`map : (Char -> Char) -> String -> String` تحوّل كل محرف في سلسلة نصية بواسطة الدالة المعطاة.
لاحظ أن الدالة المقدَّمة يجب أن تكون اقترانًا من `Char` وإليه.
```elm
map (\c -> if c == '/' then '.' else c) "a/b/c" 
    --> "a.b.c"
```

`filter : (Char -> Bool) -> String -> String` تُبقي فقط المحارف التي تجتاز الاختبار.
```elm
filter isDigit "R2-D2" 
    --> "22"
```

`foldl : (Char -> b -> b) -> b -> String -> b` تختزل سلسلة نصية بدءًا من اليسار.
تُطبَّق الدالة بحيث يكون المحرف الأول معاملها الأول، والقيمة الابتدائية المعطاة معاملها الثاني.
يجب أن تكون نتيجة الدالة من النوع نفسه الذي للقيمة الابتدائية المعطاة، وتُطبَّق على كل محرف بالتتابع.
```elm
foldl (\c acc -> Char.toCode c + acc) 0 "the sum of my unicode is " 
    --> 2260
```
وتفعل `foldr` الشيء نفسه، لكن بدءًا من الجانب الأيمن للسلسلة النصية.

`any : (Char -> Bool) -> String -> Bool` تحدّد ما إذا كان أي محرف يُرجع `True` لدالة التحقق المعطاة.
```elm
any isDigit "R2-D2" 
    --> True
any isDigit "heart" 
    --> False
```
`all : (Char -> Bool) -> String -> Bool` تحدّد ما إذا كانت كل المحارف في سلسلة نصية تُرجع `True` لدالة التحقق المعطاة.
```elm
all isDigit "R2-D2" 
    --> False
all isAlpha "heart" 
    --> True
```
