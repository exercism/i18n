# التعليمات

في مختبر أبحاث الحمض النووي (DNA) الخاص بك، كنت تعمل على طرق مختلفة لضغط بيانات بحثك لتوفير مساحة التخزين. ويقترح أحد زملائك تحويل بيانات الحمض النووي إلى تمثيل ثنائي:

| الحمض النووي | الكود |
| ------------ | ----- |
| Adenine      |  `00` |
| Cytosine     |  `01` |
| Guanine      |  `10` |
| Thymine      |  `11` |

تتأمل هذه الفكرة، إذ قد تقلل تكاليف تخزين البيانات المطلوبة، لكن على حساب سهولة القراءة البشرية. فتقرر كتابة وحدة برمجية لترميز بياناتك وفك ترميزها، وقياس مقدار التوفير الذي ستحققه.

## 1. ترميز الحمض النووي إلى قيمة ثنائية

نفّذ `encode_nucleotide` لتقبل نيوكليوتيدًا وتُرجع القيمة العددية `int` للرمز المرموز.

```gleam
encode_nucleotide(Cytosine)
// -> 1
// (which is equal to 0b01)
```

## 2. فك ترميز القيمة الثنائية إلى الحمض النووي

نفّذ `decode_nucleotide` لتقبل القيمة العددية الصحيحة للرمز المرموز وتُرجع النيوكليوتيد.

```gleam
decode_nucleotide(0b01)
// -> Ok(Cytosine)
```

## 3. ترميز مصفوفة الحمض النووي

نفّذ `encode` لتقبل مصفوفة من النيوكليوتيدات وتُرجع مصفوفة بتات للبيانات المرموزة.

```gleam
encode([Adenine, Cytosine, Guanine, Thymine])
// -> <<27>>
```

## 4. فك ترميز مصفوفة بتات الحمض النووي

نفّذ `decode` لتقبل مصفوفة بتات تمثل الحمض النووي وتُرجع البيانات بعد فك الترميز كمصفوفة من النيوكليوتيدات.

```gleam
decode(<<27>>)
// -> Ok([Adenine, Cytosine, Guanine, Thymine])
```
