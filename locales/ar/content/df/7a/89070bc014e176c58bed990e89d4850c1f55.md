# التعليمات

أنت مدرّس.
في نهاية العام، أنشأت درجة رقمية لكل طالب من طلابك.
والآن عليك تحويلها إلى تقدير حرفي، وإحصاء عدد الطلاب الذين حصلوا على كل تقدير حرفي

## 1. حوّل درجة رقمية إلى تقدير حرفي

دالة `letter_grade` تأخذ درجة رقمية كمدخل، وتُرجع التقدير الحرفي.
استخدم هذه النطاقات:

| التقدير |      الدرجة |
| :----: | ---------: |
|   A    | 90% - 100% |
|   B    |  80% - 89% |
|   C    |  70% - 79% |
|   D    |  60% - 69% |
|   F    |   0% - 59% |

مثال:

```jq
75 | letter_grade   # => "C"
```

## 2. أحصِ عدد الطلاب لكل تقدير حرفي

الدالة `count_letter_grades` تأخذ كائنًا يربط أسماء الطلاب بدرجاتهم.
وستُرجع كائنًا يربط كل تقدير حرفي بعدد الطلاب الحاصلين على ذلك التقدير.

مثال:

```jq
{"Joe": 78, "Jane": 93, "Richard": 72} | count_letter_grades
# => {"A": 1, "B": 0, "C": 2, "D": 0, "F": 0}
```

هناك عدة أساليب لحل هذه المسألة.
استخدم المرشّح `reduce` للتدريب.
