# نبذة

طابعة Common Lisp هي الوسيلة المسؤولة عن إخراج البيانات إلى التدفقات. ومن الدوال الشائعة في هذه الوسيلة الدالة `format`.

تأخذ `format` معاملَين إلزاميَّين: تدفقًا تُكتب إليه، وسلسلة نصية للتحكم. ويحدِّد محتوى سلسلة النص للتحكم كيفية استخدام أي وسائط إضافية.

للمعامل الأول قيمتان خاصتان: `t` و `nil`. تشير `t` إلى أنه ينبغي استخدام التدفق المرتبط بـ `*standard-output*`، وتشير `nil` إلى أنه ينبغي إنشاء سلسلة نصية وإرجاعها. وتُقيَّم `format` إلى `nil` ما لم يكن معامل التدفق هو `nil`.

يمكن أن تحتوي سلسلة النص للتحكم على توجيهات تنسيق، يُشار إليها بعلامة `~` يتبعها حرف (ولا يهمّ حال الحرف). ويحدِّد توجيه التنسيق ما إذا كان يستهلك أي وسائط، وكيف تُنسَّق هذه الوسائط إلى التدفق.

توجيهات التنسيق الأساسية المهمة هي:

* `~A` - تنسيق _جمالي_ بطريقة «مقروءة للبشر».
* `~S` - تنسيق بالنمط _القياسي_ ليكون «مقروءًا للآلة».
* `~%` - إخراج سطر جديد.
* `~&` - إخراج سطر جديد ما لم يكن المؤشر في بداية سطر بالفعل.
* `~~` - إخراج علامة التلدة.

أمثلة:

```lisp
(format nil "The list is: ~A~%" (list 1 2 3)) ; => "The list is: (1 2 3)
                                                   "
(format nil "(format t ~S)" "hello world")    ; => "(format t \"hello world\""
(format nil "~&fresh~&lines")                 ;=> "fresh
                                                   lines"
(format nil "directives start with a ~~")     ; => "directives start with a ~"
```
