# التعليمات

أنت مراقب طيور شغوف تتابع عدد الطيور التي زارت حديقتك خلال الأيام السبعة الماضية.

لديك ست مهام، وكلها تتعلق بأعداد الطيور التي زارت حديقتك.

## 1. تحقّق من أعداد الأسبوع الماضي

لأغراض المقارنة، تحتفظ دائمًا بنسخة من أعداد الأسبوع الماضي في متناول يدك، وهي: 0، 2، 5، 3، 7، 8 و4. نفّذ الطريقة `BirdWatcher.getLastWeek()` التي تُرجع أعداد الأسبوع الماضي:

```java
BirdWatcher.getLastWeek();
// => [0, 2, 5, 3, 7, 8, 4]
```

## 2. تحقّق من عدد الطيور التي زارت اليوم

نفّذ الطريقة `BirdWatcher.getToday()` لتُرجع عدد الطيور التي زارت حديقتك اليوم. أعداد الطيور مرتبة حسب اليوم، حيث يكون العنصر الأول عدد أقدم يوم، والعنصر الأخير عدد اليوم.

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getToday();
// => 1
```

## 3. زد عدد اليوم

نفّذ الطريقة `BirdWatcher.incrementTodaysCount()` لزيادة عدد اليوم:

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.incrementTodaysCount();
birdCount.getToday();
// => 2
```

## 4. تحقّق مما إذا كان هناك يوم لم تزره أي طيور

نفّذ الطريقة `BirdWatcher.hasDayWithoutBirds()` التي تُرجع `true` إذا كان هناك يوم لم تزر فيه أي طيور الحديقة؛ وإلا فأرجع `false`:

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.hasDayWithoutBirds();
// => true
```

## 5. احسب عدد الطيور الزائرة في أول عدد من الأيام

نفّذ الطريقة `BirdWatcher.getCountForFirstDays()` التي تُرجع عدد الطيور التي زارت حديقتك منذ بداية الأسبوع، لكن مع حصر العدد في عدد الأيام المحدد من بداية الأسبوع.

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getCountForFirstDays(4);
// => 14
```

## 6. احسب عدد الأيام المزدحمة

بعض الأيام أكثر ازدحامًا من غيرها. واليوم المزدحم هو الذي زارت فيه خمس طيور أو أكثر حديقتك.
نفّذ الطريقة `BirdWatcher.getBusyDays()` لتُرجع عدد الأيام المزدحمة:

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getBusyDays();
// => 2
```
