# نبذة

توفّر لغة Go حزمة مدمجة تُسمى `fmt` (حزمة التنسيق)، وهي تقدّم مجموعة متنوعة من الدوال للتعامل مع تنسيق المُدخلات والمُخرجات.
الدالة الأكثر استخدامًا هي `Sprintf`، وهي تستخدم _أفعال_ مثل `%s` لإدراج القيم داخل سلسلة نصية، ثم تُرجع تلك السلسلة النصية.

```go
import "fmt"

food := "taco"
fmt.Sprintf("Bring me a %s", food)
// Returns: Bring me a taco
```

في Go يمكن تنسيق قيم الفاصلة العائمة بسهولة باستخدام أفعال `Sprintf`: `%g` (تمثيل مختصر)، و`%e` (الأس)، و`%f` (بدون أُس).
وتتيح الأفعال الثلاثة التحكم في عرض الحقل وعدد المنازل العشرية.

```go
import "fmt"

number := 4.3242
fmt.Sprintf("%.2f", number)
// Returns: 4.32
```

يمكنك العثور على قائمة كاملة بالأفعال المتاحة في [توثيق حزمة التنسيق][fmt-docs].

وتحتوي `fmt` على دوال أخرى للتعامل مع السلاسل النصية، مثل `Println` التي تطبع ببساطة الوسائط التي تستقبلها إلى وحدة التحكم، و`Printf` التي تنسّق المُدخل كما تفعل `Sprintf` قبل طباعته.

[fmt-docs]: https://pkg.go.dev/fmt
