## القيم المنطقية في R

تُمثَّل قيمتا صحيح وخطأ بالنوع `logical`.
وهو لا يحتوي إلا على قيمتين: `TRUE` و`FALSE`.

```R
TRUE
#> [1] TRUE
FALSE
#> [1] FALSE
typeof(TRUE)
#> [1] "logical"
```

## عوامل القيم المنطقية

توجد خمسة عوامل منطقية في R، لكن ثلاثة منها فقط مهمة في هذه المرحلة من المنهج.
أما العاملان الآخران فسيصبحان مهمّين عند التعامل مع المتجهات، وهو موضوع تتناوله عدة مفاهيم لاحقة.

`&&` هو العامل المنطقي «و».
ويُقيَّم إلى `TRUE` إذا كان التعبيران على *كلا* جانبي `&&` يساويان `TRUE`.

```R
TRUE && TRUE
#> [1] TRUE
TRUE && FALSE
#> [1] FALSE
```

`||` هو العامل المنطقي «أو».
ويُقيَّم إلى `TRUE` إذا كان التعبير على *أي* من جانبي `||` يساوي `TRUE`.

```R
TRUE || TRUE
#> [1] TRUE
FALSE || TRUE
#> [1] TRUE
```

`!` هو العامل المنطقي «ليس».
وهو يبدّل بين قيمتَي `TRUE` و`FALSE`.

```R
!TRUE
#> [1] FALSE
!FALSE
#> [1] TRUE
```

في التعبيرات الأطول والأكثر تعقيدًا، من الأفضل استخدام الأقواس الهلالية لتوضيح ما تقصده.

```R
(TRUE || FALSE) && (FALSE && TRUE)
#> [1] FALSE
```
