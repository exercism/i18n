# مقدمة

`Rational numbers` هي كسور بسطها عدد صحيح وقاسمها عدد صحيح.

على سبيل المثال، يمكننا تخزين `2//3` ككسر دقيق بدلًا من قيمة `Float64` التقريبية `0.6666...`

الميزة هي أنه (باستثناء الحالة القصوى لتجاوز سعة الأعداد الصحيحة) سيبقى العدد النسبي دقيقًا، مما يجنّب أخطاء التقريب التي كثيرًا ما تكون حتمية مع أعداد الفاصلة العائمة.

الأعداد النسبية نوع عددي بسيط للغاية، وهي مصممة لتعمل كما تتوقع تمامًا.
ولأنها نوع قياسي في Julia منذ الإصدارات الأولى، فإن معظم الدوال تقبلها كمدخلات بالطريقة نفسها التي تقبل بها الأعداد الصحيحة وأعداد الفاصلة العائمة.

## إنشاء الأعداد النسبية

الإنشاء بسيط كل البساطة: استخدم `//` بين عددين صحيحين.

```julia-repl
julia> 3//4
3//4

julia> a = 3; b = 4;

julia> a//b
3//4
```

تُحذف العوامل المشتركة تلقائيًا، فيُختصر الكسر إلى "أبسط صورة": أصغر الأعداد الصحيحة التي تمثّل الكسر بدقة، وبمقام غير سالب.

```julia-repl
julia> 5//15
1//3

julia> 5//-15
-1//3
```

## العمليات الحسابية على الأعداد النسبية

يمكنك استخدام `arithmetic operators` المعتادة `+ - * / ^ %` مع الأعداد النسبية، كما تستخدمها مع الأنواع العددية الأخرى تمامًا.

يمكن تضمين الأعداد الصحيحة وأنواع `Rational` أخرى، فيكون الناتج `Rational`.
أما تضمين `float` في التعبير فيعطي ناتجًا من نوع `float`، مع ما يترتب على ذلك من فقدان محتمل للدقة.

إذا أردت `float`، فما عليك سوى استخدام الدالة `float()` لتحويل العدد النسبي.
ومن الطبيعي تمامًا أن تستخدم الأعداد النسبية للحفاظ على الدقة خلال عملية حسابية طويلة، ثم تحوّل الناتج إلى عدد الفاصلة العائمة في النهاية.

```julia-repl
julia> 3//4 + 1//3  # addition
13//12

julia> 3//4 * 1//3  # multiplication
1//4

julia> 3//4 / 1//3  # division
9//4

julia> 3//4 ^ 2  # exponentiation
3//16

julia> 3//4 + 5  # rational and int => rational
23//4

julia> 3//4 + 5.3  # rational and float => float
6.05

julia> float(3//4)  # casting
0.75
```

## عمليات أخرى

في Julia، الأعداد النسبية مجرد أعداد.
وعادةً ما يحوّل المصرّف الأنواع حسب الحاجة.

لكن انتبه: المقارنات تنجح مع الكسور ذات التمثيل العشري المنتهي:

```julia-repl
julia> 3//4 == 0.75
true

julia> 3//4 < 0.74
false
```

أما في غير ذلك، فينبغي تحويل `Rational` إلى `Float` قبل المقارنات:

```julia-repl
julia> 1//3 == 1/3
false

julia> float(1//3) == 1/3
true
```

تقبل الدوال الرياضية الأعداد النسبية كمدخلات، لكنها قد تعطي ناتجًا من أعداد الفاصلة العائمة:

```julia-repl
julia> sqrt(9//16)
0.75
```
