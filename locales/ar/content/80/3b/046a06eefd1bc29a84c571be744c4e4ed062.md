# ملحق التعليمات

## ملاحظات التنفيذ

تعريف واجهة Cipher موجود في `cipher.go`.

يجب أن تتوافق تطبيقاتك مع واجهة Cipher.

```go
type Cipher interface {
    Encode(string) string
    Decode(string) string
}
```

من المتوقع أن تتجاهل `Encode` كل القيم في السلسلة النصية التي لا تنتمي إلى A-Za-z، فلن تظهر هذه القيم في الناتج.
وسيُحوَّل الناتج أيضًا إلى أحرف صغيرة.

الدوال المستخدمة للحصول على الشيفرات هي:

```go
func NewCaesar() Cipher { }

func NewShift(distance int) Cipher { }

func NewVigenere(key string) Cipher { }
```

يجب أن تكون قيمة الوسيط الممرَّر إلى `NewShift` ضمن النطاق من 1 إلى 25 أو من -1 إلى -25.
الصفر غير مسموح.
وعند تمرير وسائط غير صالحة، تُرجع `NewShift` القيمة nil.

يجب أن تتكوّن قيمة الوسيط الممرَّر إلى `NewVigenere` من أحرف صغيرة a-z فقط.
لا يُسمح بالقيم التي تتكوّن بالكامل من الحرف 'a'.
وعند تمرير وسائط غير صالحة، تُرجع `NewVigenere` القيمة `nil`.
