# المحارف

`CHAR` محرف واحد، يُكتب بين علامتي اقتباس مفردتين.

```sather
   c : CHAR := 'M';
```

## المحارف الخاصة

بعض المحارف لا يمكن كتابتها مباشرة، وتُكتب باستخدام الشرطة المائلة العكسية:

| مكتوب | معناه |
| --- | --- |
| `'\n'` | سطر جديد |
| `'\t'` | مسافة جدولة |
| `'\''` | علامة اقتباس مفردة |
| `'\\'` | شرطة مائلة عكسية |

## الأسئلة

```sather
'M'.is_alpha      -- true
'7'.is_digit      -- true
'M'.is_upper      -- true
' '.is_space      -- true
'M'.is_alphanum   -- true, a letter or a digit
```

## حالة الأحرف

يغيّر كل من `.upper` و`.lower` حالة الحرف ويترك كل ما عدا ذلك على حاله، لذا من الآمن تطبيقهما على محرف لم تتحقق منه بعد.

## الأعداد

```sather
'a'.int           -- 97
97.char           -- 'a'
```

`.int` و`.char` متعاكسان تمامًا. ومن الحقائق المفيدة عن هذا الترقيم أن المحارف من `'a'` إلى `'z'` متتالية، ومن `'A'` إلى `'Z'` متتالية، ومن `'0'` إلى `'9'` متتالية، لذا:

```sather
   c.int - 'a'.int          -- how far c is along the alphabet
   ('a'.int + n).char       -- the letter n places along
   d.int - '0'.int          -- the value of a digit character
```

## الالتفاف الدوري

عجلة الشيفرة تدور متجاوزة `z` وعائدة إلى `a`. والعامل `%` يفعل ذلك تمامًا:

```sather
   ('a'.int + (c.int - 'a'.int + places) % 26).char
```

لا يُرجع عامل `%` في Sather قيمة سالبة أبدًا عندما يكون الطرف الأيمن موجبًا، لذا يصلح هذا لتدوير العجلة إلى الخلف كما إلى الأمام.

## المحارف والسلاسل النصية

`STR` هو تسلسل من البايتات، و`CHAR` بايت واحد. في النص الإنجليزي يمثل البايت حرفًا واحدًا، لذا فإن قيمة `"Marlowe".size` هي 7، وقيمة `"Marlowe"[0]` هي `'M'`. أما في النص الذي يحوي علامات تشكيل أو أبجدية أخرى، فقد يشغل الحرف الواحد عدة بايتات، وحينها لا ينطبق أي من الأمرين.
