# التعليمات

في هذا التمرين، تنفّذ طريقة لتتبّع أعلى النتائج للعبة الأكثر شعبية في صالة الألعاب القريبة منك.

عليك تنفيذ 6 دوال، معظمها يتعلق بالتعامل مع كائن يحمل أعلى النتائج.

## 1. أنشئ لوحة نتائج عالية جديدة

اكتب دالة `create_score_board` تُنشئ كائنًا يعمل كلوحة نتائج عالية.
ستكون مفاتيح هذا الكائن أسماء اللاعبين، وستكون قيمه نتائجهم.
لأغراض الاختبار، تريد تضمين إدخال واحد مباشرة في الكائن.
يجب أن يتكوّن هذا الإدخال الأولي من `"The Best Ever"` اسمًا للاعب و`1000000` نتيجةً.

```jq
create_score_board
# returns an object with one initial entry
```

## 2. أضف لاعبين إلى لوحة النتائج

لإضافة لاعب إلى لوحة النتائج العالية، نفّذ الدالة `add_player`.
تأخذ لوحة نتائج كمدخل، وتحتاج معاملين: اسم اللاعب ونتيجة اللاعب.
تُرجع الدالة كائن لوحة النتائج مع اللاعب الجديد مضافًا إليه.

```jq
{"José Valim", 486373}
| add_player("Dave Thomas"; 0)
# => {"Dave Thomas": 0, "José Valim": 486373} -- in some order
```

إذا كان اللاعب على اللوحة بالفعل، تُرجع اللوحة دون تغيير.

## 3. أزل لاعبين من لوحة النتائج

إذا خالف اللاعبون قواعد صالة الألعاب، يُزالون يدويًا من لوحة النتائج العالية.
نفّذ `remove_player` التي تأخذ لوحة كمدخل ومعاملًا واحدًا هو اسم اللاعب المراد إزالته.
ينبغي أن تُزيل هذه الدالة إدخال اللاعب المعطى من اللوحة وتُرجع اللوحة الجديدة.
إذا لم يكن اللاعب على اللوحة من الأساس، فلا شيء يحدث للوحة؛ فلتُرجع كما هي.

```q
{"Dave Thomas": 0} | remove_player("Dave Thomas")
# => {}

{"Dave Thomas": 0} | remove_player("Rose Fanaras")
# => {"Dave Thomas": 0}
```

## 4. زد نتيجة لاعب

إذا أنهى لاعب جولة أخرى في صالة الألعاب، تُضاف كمية معينة من النقاط إلى النتيجة السابقة على اللوحة.
نفّذ `update_score` التي تأخذ لوحة نتائج كمدخل، وتحتاج معاملين: اسم اللاعب ومقدار النتيجة المراد إضافته.
ينبغي أن تُرجع الدالة لوحة النتائج بعد إجراء التحديث.

```jq
{"Freyja Ćirić": 12771000} | update_score("Freyja Ćirić"; 73)
# => {"Freyja Ćirić": 12771073}
```

ينبغي أن تضيف هذه الدالة اللاعب إلى اللوحة إن لم يكن عليها بالفعل.

## 5. طبّق نقاط مكافأة الاثنين

تحتفظ صالة الألعاب بلوحة نتائج منفصلة أيام الاثنين.
في نهاية اليوم، يحصل كل لاعب على تلك اللوحة على 100 نقطة إضافية.

نفّذ الدالة `apply_monday_bonus`.
تُضيف الدالة نقاط المكافأة لكل لاعب مدرج على تلك اللوحة.

```jq
{
  "Dave Thomas": 44,
  "Freyja Ćirić": 539,
  "José Valim": 265
}
| apply_monday_bonus
# => {"Dave Thomas": 144, "Freyja Ćirić": 639, "José Valim": 365}
```

## 6. احسب النتيجة الإجمالية

تتنافس صالات الألعاب المختلفة فيما بينها لتحديد من لديه أفضل اللاعبين.
تفوز الصالة ذات أعلى نتيجة إجمالية بهذا الشرف.

اكتب دالة `total_score`.
تأخذ لوحة نتائج كمدخل، وتُرجع مجموع نتائج جميع اللاعبين.

```jq
{
  "Dave Thomas": 44,
  "Freyja Ćirić": 539,
  "José Valim": 265
}
| total_score
# => 848
```
