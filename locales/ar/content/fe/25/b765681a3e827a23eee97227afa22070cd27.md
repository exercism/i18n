# الأعداد العشرية

تُستخدم الأعداد العشرية في PHP لتمثيل مجموعة فرعية من الأعداد الحقيقية.
وهي تبدأ برقم واحد أو أكثر تفصل بينها فاصلة عشرية.

```php
<?php

$a = 1.234; 
$b = 1.2e3; 
$c = 7E-10;
$d = 1_234.567; // as of PHP 7.4.0
```

## أخطاء شائعة

لا يمكن إجراء جميع الأعداد والعمليات الحسابية باستخدام الأعداد العشرية.
غالبًا ما يؤدي استخدام الأعداد العشرية لتمثيل الدولارات والسنتات إلى أخطاء في التقريب.

```php
<?php

$result = 0.1 + 0.2; // => 0.30000000000000004
```
