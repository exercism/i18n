# مقدمة

قدّم مفهوم [`Basics`][basics] أسلوبين لتعريف دالة.

الأكثر عمومية هو الصيغة متعددة الأسطر:

```julia
function muladd(x, y, z)
    x * y + z
end
```

وصيغة «الإسناد»، أو الصيغة «أحادية السطر»، للتعريفات القصيرة:
```julia
muladd(x, y, z) = x * y + z
```

وفي صيغة ثالثة أقصر منها، يمكن إنشاء دالة قصيرة تُستخدم مرة واحدة دون اسم:

```julia-repl
julia> map(x -> 2x, 1:3)
4-element Vector{Int64}:
 2
 4
 6

julia> map((x, y) -> x * y, 1:3, 4:6)
3-element Vector{Int64}:
  4
 10
 18
```

في هذه الحالة، تُعدّ `x -> 2x` «دالة مجهولة».
وهذا مكافئ لما تسميه لغات أخرى «دالة لامبدا».

لاحظ أن الوسائط المتعددة تحتاج إلى أقواس هلالية، كما في `(x, y) -> x * y`.

تكثر الدوال المجهولة في كود Julia، خصوصًا عند دمجها مع دوال ذات رتبة أعلى مثل `map()` و`filter()` (والتي سنتناولها بمزيد من التفصيل في مفهوم لاحق).

```julia-repl
julia> map(x -> x^4, [1, 2, 3])
3-element Vector{Int64}:
  1
 16
 81
```

## وسائط الدوال

حتى الآن في المنهج، اطّلعنا فقط على دوال لها عدد محدد من الوسائط، وتتطلب أن يوفّر نداء الدالة جميع هذه الوسائط بالترتيب الصحيح.
سيكون هذا مقيّدًا وغير مريح، لذا توجد خيارات أخرى عديدة.

### وسائط اختيارية

مثل كثير من اللغات، تسمح Julia لتعريفات الدوال بتوفير قيم افتراضية لكل وسيط على حدة.

ويمكن لنداء الدالة حينها إما توفير قيمة لهذا الوسيط، وإما حذفه والاعتماد على القيمة الافتراضية.

```julia-repl
julia> f(x, y=10) = x * y
f (generic function with 2 methods)

julia> f(2, 3)
6

julia> f(2)
20
```

يجب أن تأتي جميع الوسائط _بدون_ قيم افتراضية قبل أي وسائط _لها_ قيم افتراضية، ما يعني أن `f(x=2, y)` سيكون غير صالح.

### وسائط الكلمات المفتاحية

تستخدم كل الأمثلة حتى الآن `positional arguments`، حيث يجب أن تطابق القيم الموفَّرة في نداء الدالة ترتيب الوسائط المقابلة لها في تعريف الدالة.

ومثل كثير من اللغات، تسمح Julia أيضًا باستخدام `keyword arguments`.
يجب أن يحدد نداء الدالة اسم الوسيط، لكن يمكن بعد ذلك تحديد عدة وسائط مفتاحية بأي ترتيب.

من السمات المميزة لـ Julia أن الوسائط المفتاحية (إن وُجدت) في تعريف الدالة يجب أن تسبقها فاصلة منقوطة `;` لفصلها عن أي وسائط موضعية.
ويمكن لنداء الدالة استخدام `;` أو `,` بين آخر وسيط موضعي وأول وسيط مفتاحي.

```julia-repl
julia> b(x; y) = x + y
b (generic function with 1 method)

julia> b(2, y=3)
5

# keyword is required when calling
julia> b(2, 3)
ERROR: MethodError: no method matching b(::Int64, ::Int64)
The function `b` exists, but no method is defined for this combination of argument types.
```

يمكن اختياريًا تحديد قيم افتراضية، تمامًا كما في الوسائط الموضعية.

من الشائع أن ينتهي بك الأمر إلى صياغة مثل `myarg=myarg` داخل نداء الدالة، عندما يكون متغير يحمل اسم المعامل نفسه قد حُسب مسبقًا.
وتُسمح صياغة مختصرة في هذه الحالة:

```julia-repl
julia> width = 4.0
4.0

julia> height = √ width
2.0

julia> area(; width, height) = width * height
area (generic function with 1 method)

# repetition
julia> area(; width=width, height=height)
8.0

# shorthand form
julia> area(; width, height)
8.0
```

### Splat و slurp

هذان هما الاسمان المعتادان على جانب مفيد من صياغة Julia، إن كنت تتساءل.
وكلاهما يشير إلى المعامل `...`.

#### Splat

يُستخدم splat في نداءات _الدوال_، لتوسيع المجموعات إلى قيم فردية تحتاجها الدالة.

قد يكون عرض هذا أسهل من شرحه:

```julia-repl
julia> fxyz(x, y, z) = x * y * z
fxyz (generic function with 1 method)

julia> xyz = [2, 3, 4]
3-element Vector{Int64}:
 2
 3
 4

# Using the vector directly in a function call is invalid
julia> fxyz(xyz)
ERROR: MethodError: no method matching fxyz(::Vector{Int64})
The function `fxyz` exists, but no method is defined for this combination of argument types.

# splatting converts the vector to 3 numbers, used as positional arguments
julia> fxyz(xyz...)
24
```

بعض «نداءات الدوال» مخفية وراء السكر النحوي، لذا يمكن استخدام splat أيضًا بأساليب أقل وضوحًا.

على سبيل المثال، يستخدم الإسناد المتعدد داخليًا دالة لبناء tuple:

```julia-repl
julia> first, rest... = [1, 2, 3, 4]
4-element Vector{Int64}:
 1
 2
 3
 4

julia> first
1

julia> rest
3-element Vector{Int64}:
 2
 3
 4
```

يمكن أيضًا توفير الوسائط المفتاحية عبر splat، عادةً باستخدام `named tuple`. 
كما يعمل `Dict` أيضًا، لكن يجب أن تكون المفاتيح من نوع symbols (لن تعمل السلاسل النصية).

```julia-repl
# function with 3 keyword arguments
julia> fabc(; a, b, c) = a + b + c
fabc (generic function with 1 method)

# named tuple
julia> abc_nt = (a=2, b=3, c=4)
(a = 2, b = 3, c = 4)

# there are no positional arguments, so need to use ; before kw argument
julia> fabc(;abc_nt...)
9

# Dict
julia> abc_dict = Dict(:a=>2, :b=>3, :c=>4)
Dict{Symbol, Int64} with 3 entries:
  :a => 2
  :b => 3
  :c => 4

julia> fabc(;abc_dict...)
9
```

#### Slurp

يُستخدم slurp في _تعريف_ الدالة، لحزم عدد عشوائي من القيم الفردية في مجموعة.

```julia-repl
julia> f_more(i, j, more...) = i + j + sum(more)
f_more (generic function with 1 method)

julia> f_more(1, 3, 5, 7, 9, 11)
36
```

اسم الوسيط الذي يلتقطه slurp (وهو هنا `more`) ليس مهمًا.
يختار المترجم نوع هذا المتغير، لكنه غالبًا سيكون `tuple` أو شيئًا مشابهًا بالنسبة إلى الوسائط الموضعية.

يمكن أيضًا التقاط الوسائط المفتاحية باستخدام slurp، ما يمنحك `Dict` (أو ما يشبهه).

```julia-repl
julia> f_kwslurp(x, y; switches...) = :mult in keys(switches) ? x * y : x + y
f_kwslurp (generic function with 1 method)

julia> f_kwslurp(5, 6; mult=true)
30

julia> f_kwslurp(5, 6)
11
```

يمكن استخدام أي وسائط مفتاحية في النداء.
ويعود القرار إلى تعريف الدالة في تحديد أي الكلمات المفتاحية يستجيب لها وأيها يتجاهل.
