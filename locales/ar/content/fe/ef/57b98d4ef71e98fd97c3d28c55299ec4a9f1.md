# مقدمة

## المتغيرات

تذكّر أن برنامج `jq` هو _تسلسل من التعبيرات_.
يتبع **إسناد المتغير** هذه القاعدة: _إسناد المتغير_ تعبير يبدو هكذا:

```jq
... | expr as $varname | ...
```

### يُخرج المرشّح المُدخل

مثل _تعبير الهوية_ `.`، فإن مُخرج _إسناد المتغير_ هو نفسه مُدخله.
ضبط قيمة المتغير أثر جانبي.

مثال يوضّح أن `.` بعد الإسناد هو نفسه المُدخل الأولي:

```sh
$ jq -c -n '42 | (. * 2) as $double | [., $double]'
[42,84]
```

### نطاق المتغير

نطاق المتغير "معجمي"، أي أن المتغير سيبقى داخل النطاق لبقية التسلسل.
المتغيرات المعرّفة داخل الدوال (سنصل إلى الدوال لاحقًا) تكون "محلية" بالنسبة للدالة.

### أسماء المتغيرات

يجب أن يبدأ المتغير بـ `$`.
بقية اسم المتغير **معرّف**: يبدأ بحرف أو شرطة سفلية تتبعها حروف أو أعداد أو شرطات سفلية.

### إسناد التفكيك

من الدليل:

> يمكن تعريف عدة متغيرات باستخدام تعبير `as` واحد عبر تقديم نمط _يطابق بنية المُدخل_ (يُعرف هذا بـ "التفكيك").

أمثلة:

```jq
[1, 2, 3] as [$a, $b, $c]
| [$a, $b, $c]     # => [1, 2, 3]
```

```jq
{"foo": "bar", "len": [10, 20]} as {foo: $f, len: [$h, $w]}
| [$f, $h, $w]     # => ["bar", 10, 20]
```

مطابقة اسم المتغير مع _مفتاح الكائن_ توفّر اختصارًا:

```jq
{"x": 4, "y": 7} as {$x, $y}
| [$x, $y]         # => [4, 7]
```

```jq
{"foo": "bar", "len": [10, 20]} as {$foo, $len}
| [$foo, $len]     # => ["bar", [10, 20]]
```

### الثوابت

كما يوضّح المثال أعلاه، المتغيرات عملية لتخزين الثوابت.
من الأفضل إعطاء الثوابت اسمًا بدلًا من ظهور "الأعداد السحرية" في الكود.

### غالبًا ما لا تكون المتغيرات ضرورية

غالبًا ما يكون حذف المتغيرات أكثر وضوحًا للقراءة.

لننظر في حساب المتوسط لمصفوفة من الأعداد

```jq
[2, 4, 8, 7]
| add as $sum
| length as $len
| $sum / $len
```

مقارنة بـ

```jq
[2, 4, 8, 7] | add / length
```

يُبرز هذا أحد أقوى جوانب `jq`: إذ يُتاح المُدخل إلى المرشّح لـ _كل_ تعبير فرعي:

- تُمرَّر مصفوفة المُدخل `[2,4,8,7]` إلى `add` (التي تجمع الأعداد بتطبيق عامل `+` على كل العناصر)
- _بالتوازي_، تُمرَّر `[2,4,8,7]` أيضًا إلى `length`
- وعندما تكتمل هذه التعبيرات الفرعية، تُقسَم نتائجها، فنحصل على متوسط قيم الأعداد في مصفوفة المُدخل.

### عوامل `jq` التي ستحتاجها في التمرين التعليمي

#### عامل البديل: `//`

يُخرج التعبير `a // b` القيمة `b` إذا كان `a` خطأ أو `null`، وإلا فإنه يُخرج `a`.
في سياق إسناد متغير، هذا مفيد جدًا لتوفير قيمة افتراضية:

```jq
(.input.theAnswer // 42) as $answer | ...
```

#### العوامل الحسابية

- `+` و`-` و`*` هي عوامل الجمع والطرح والضرب العددية المعتادة.
