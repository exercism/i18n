# مقدمة

تستخدم Lua تمثيلين للأعداد: أعداد صحيحة بطول 64 بت، وأعداد الفاصلة العائمة مزدوجة الدقة. وهي تدعم المجموعة المعتادة من عوامل الحساب: الجمع والطرح والضرب والقسمة والسالب. كما تدعم القسمة الصحيحة وباقي القسمة والرفع إلى قوة.

| العامل | المثال             |
| -------- | ------------------- |
| `+`      | `1 + 2 --> 3`       |
| `-`      | `2 - 1 --> 1`       |
| `*`      | `2 * 2 --> 4`       |
| `/`      | `4 / 2 --> 2.0`     |
| `//`     | `11 // 3 --> 3`     |
| `%`      | `11 % 3 --> 2`      |
| `^`      | `10 ^ 2 --> 100.0`  |
| `-`      | `-(2 * 2) --> -4`   |
