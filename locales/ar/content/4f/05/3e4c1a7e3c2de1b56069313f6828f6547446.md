بينما يمكن دمج السلاسل النصية يدويًا في Haxe، فإن Haxe يدعم [إدراج السلاسل النصية][string-interpolation]، وهو ما يوفّر صياغة أقصر وأكثر ملاءمة:

```haxe
var x = 42;
//The following two statements are equivalent:

// manual concatenation
trace("the number is " + x);

// using interpolation
trace('the number is $x');
```

وكما يظهر أعلاه، تُحاط السلاسل النصية المُدرَجة بعلامات الاقتباس المفردة (`'`)، على عكس [السلاسل النصية][strings] العادية، وقد تحتوي على معرّفات خاصة يُشار إليها بعلامة الدولار (`$`) تُفعّل الإدراج.

ويمكن تضمين تعبيرات كاملة باستخدام `${expr}`، حيث `expr` هو أي تعبير صالح في Haxe:

```haxe
trace('the next number is ${x + 1}');
```

ولإيقاف الإدراج عندما يكون المقصود علامة دولار فعلية، يمكن استخدام `$$`:

```haxe
trace('the price is $$42'); // outputs: the price is $42
```

وأخيرًا، لاحظ أن إدراج السلاسل النصية ميزة تعمل في وقت الترجمة وليس لها أي تأثير على أداء وقت التشغيل. فداخليًا، يولّد مترجم Haxe الكود المكافئ للدمج اليدوي.

[string-interpolation]: https://haxe.org/manual/lf-string-interpolation.html
[strings]: https://haxe.org/manual/std-String.html
