# مقدمة

تحتوي Python على تركيبين للتكرار.
حلقات `while` من أجل التكرار _غير المحدود_ (غير المعدود)، وحلقات `for` من أجل التكرار _المحدود_ (المعدود).
تساعد الكلمات المفتاحية `break` و`continue` و`else` على تخصيص سلوك الحلقة.
تساعد الدالتان `range(<length of sequence>)` و`enumerate(<iterable>)` في عدّ الحلقة والفهرسة.


لا تُحدَّد لحلقات `while` عددٌ معيّن من التكرارات، وهي تستمر ما دام تعبير `loop` أو «الاختبار» يُقيَّم إلى `True`.
تتوقف الحلقة عندما يُقيَّم تعبير الحلقة إلى `False`.

```python
while expression:
    set_of_statements
```

تمرّ حلقات `for` عبر قيم أي تسلسل، وتتوقف عندما لا تعود هناك قيم تُرجع.
توفّر دالة `range(<length of sequence>)` عدّادًا `loop` أو تسلسلًا عندما لا توجد بنية بيانات أو كائن آخر قابل للتكرار للمرور عليه.

```python
# Python will keep track of the loop count internally.
for item in sequence:
    set_of_statements
    
# `range()` is used as an explicit loop counter.  
# This will loop 12 times, from index 0 to index 11.
for item in range(12):
    set_of_statements
```
