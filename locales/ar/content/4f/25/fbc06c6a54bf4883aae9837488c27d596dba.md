# تشغيل الاختبارات

من الطرفية، انتقل إلى المجلد الأساسي للتمرين ثم نفّذ الاختبارات بالأمر التالي:

```bash
$ gleam test
```

سيؤدي هذا إلى تشغيل ملف الاختبار الموجود في المجلد الفرعي `test`، وهو ملف ينتهي بـ `_test.gleam`.

## دوال الاختبار

تستخدم الاختبارات [إطار اختبار مخصصًا](https://github.com/exercism/gleam-test-runner/tree/main/runner). سيعتبر إطار الاختبار أي دالة عامة في مجلد `test` ينتهي اسمها بـ `_test` اختبارًا.

على سبيل المثال:

```gleam
import bob
import exercism/should

pub fn shouting_test {
  bob.hey("WATCH OUT!")
  |> should.equal("Whoa, chill out!")
}
```
