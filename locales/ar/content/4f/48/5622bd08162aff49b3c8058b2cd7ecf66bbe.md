# مقدمة

## النتائج

لا يستخدم Gleam الاستثناءات لمعالجة الأخطاء، بل تُرجع الدوال التي قد تنجح أو تفشل نوع `Result` العام.

نوع `Result` مدمج في اللغة، لذا لا تحتاج إلى تعريفه أو استيراده، لكن لو عرّفته بنفسك فسيبدو هكذا:

```gleam
pub type Result(value, error) {
  Ok(value)
  Error(error)
}
```

تُرجع الصيغة `Ok` عندما تنجح الدالة، وتُرجع الصيغة `Error` عندما تفشل الدالة.

تكثر النتائج في Gleam، وكثيرًا ما يستخدم مبرمجو Gleam [وحدة `gleam/result`](https://hexdocs.pm/gleam_stdlib/gleam/result.html) لتسهيل التعامل معها.

يمكن استخدام دالة `result.map` لاستدعاء دالة على القيمة الموجودة داخل نتيجة إذا كانت `Ok`، أو لتمرير `Error` دون تغيير.

```gleam
Ok(1)
|> result.map(fn(x) { x + 1 })
// -> Ok(2)

Error("Oh no!")
|> result.map(fn(x) { x + 1 })
// -> Error("Oh no!")
```

دالة `result.try` مشابهة، لكن يُتوقع من دالة رد النداء أن تُرجع نتيجة. هذا مفيد لربط عدة دوال تُرجع نتائج معًا.

```gleam
Ok(1)
|> result.try(fn(x) { Ok(x + 1) })
// -> Ok(2)

Ok(1)
|> result.try(fn(x) { Error("Nope!") })
// -> Error("Nope!")
```
