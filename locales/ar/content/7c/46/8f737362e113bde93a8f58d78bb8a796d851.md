# مقدمة

المتغيرات التي تُعلَن باستخدام الكلمة المفتاحية `final` بدلًا من `var` يمكن إسناد قيمة لها مرة واحدة فقط.

```haxe
final a = "hello";
var b = "world";
trace(a, b); // hello, world
b = "haxe";
trace(a, b); // hello, haxe

// The following line would cause a compilation error:
// a = "bye";
```
