# نبذة

## القيم الاختيارية

يستخدم Swift [_القيم الاختيارية_][optionals] ليتيح للمبرمجين تمثيل غياب القيمة المحتمل.
النوع الاختياري نوع يمكنه أن يحمل قيمة أو أن يكون [`nil`][nil]، الذي يمثّل غياب القيمة.
ويتطلب استخدام قيمة اختيارية أن يتحقق البرنامج من وجود القيمة فعلًا قبل استخدامها بعد فكّ تغليفها.

يمكن تحويل أي نوع إلى نوع اختياري بإضافة `?` إلى نهاية اسم النوع.
فيكون نوع العدد الصحيح الاختياري `Int?`، ويكون نوع السلسلة النصية الاختيارية `String?`.
وتعريف الثوابت أو المتغيرات من نوع اختياري وإسناد القيم إليها يتم بالطريقة نفسها المتبعة مع قيم الأنواع غير الاختيارية.

```swift
let x: Int? = 42
var y: String? = "Hello"
y = "Goodbye"
```

يمكنك إسناد غياب القيمة إلى متغير من نوع اختياري بإسناد القيمة الخاصة `nil` إليه.
ويمكن استخدام `nil` مع جميع الأنواع الاختيارية، لكن قيم `nil` المُسندة إلى نوعين اختياريين مختلفين ليست من النوع نفسه، ولا يمكن تبادلها أو حتى مقارنتها.

```swift
let intOpt: Int? = nil
let stringOpt: String? = nil

intOpt = stringOpt
// Compiler error: Cannot assign value of type 'String?' to type 'Int?'

intOpt == stringOpt
// Compiler error: Binary operator '==' cannot be applied to operands of type 'Int?' and 'String?'
```

لاحظ أيضًا أنه على الرغم من إمكانية إسناد `nil` إلى أي نوع اختياري، فلا يمكن إسناده إلى نوع غير اختياري (حتى لو لم يكن يحمل `nil` فعلًا).
كما لا يمكن تمرير نوع اختياري إلى طريقة تتوقع نوعًا غير اختياري دون فكّ تغليفه أولًا.

```swift
var x: Int = 42
var y: Int? = 42

y = x
// Works fine
x = y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
x + y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
```

## استخدام القيم الاختيارية

لأن الأنواع الاختيارية ليست هي أنواعها الأساسية نفسها، فلا يمكن استخدام النوعين بالطريقة ذاتها.
على سبيل المثال: يؤدي التعبير `Int("123") + 1` إلى خطأ من المُصرِّف نصّه "Value of optional type 'Int?' must be unwrapped to a value of type 'Int'".
ويرجع السبب إلى أن `Int("123")` تُرجع نوعًا اختياريًا `Int?` لا نوع `Int`، فإذا تعذّر تحويل السلسلة النصية إلى عدد صحيح، ستكون النتيجة `nil`.
وللوصول إلى `Int` من نتيجة التحويل، لا بد من "فكّ تغليفها" أولًا.

ويُفعل ذلك عادةً في Swift باستخدام تركيبَي `if-let` و`guard-let` من أجل [_الربط الاختياري_][optional-binding]، وهما يتحققان من `nil` ويسلكان مسارًا برمجيًا تُربط فيه القيمة بعد فكّ تغليفها باسم مُعطى إذا وُجدت القيمة، ويسلكان مسارًا آخر إذا وُجد `nil`.

```swift
if let safeNum = Int("123") {
	let sum = safeNum + 1
	…
} else {
  // code for the case where nil was found -- may be left out
}
```

يجدر التنبيه إلى أن المتغير `safeNum` من النوع `Int` لا `Int?`.
في المثال أدناه، المتغير `num` من النوع `Int?` والمتغير `safeNum` من النوع `Int`.

```swift
let num = Int("123")
if let safeNum = num {
  // num is of type Int
}
```

هذا _الربط الاختياري_ مهم لأنه يفكّ تغليف النوع الاختياري عن القيمة (أو "يزيله")، مما يسمح باستخدامها كقيمة غير اختيارية.
أما إذا اكتفيت بإجراء فحص شرطي لمعرفة ما إذا كانت القيمة `nil`، فستبقى القيمة من النوع الاختياري:

```swift
let num = Int("123")
if num != nil {
  // num is of type Int?
}
```

يمكن أيضًا استخدام خيار `guard-let` في الحالات التي يُراد فيها العودة المبكرة:

```swift
guard let num = Int("123") else { return nil }
let sum = num + 1
…
```

## مقارنة القيم الاختيارية

لاحظ أنه حتى إذا أمكن مقارنة النوع الأساسي لزوج من القيم الاختيارية باستخدام عوامل المقارنة القياسية، فلا يمكن مقارنة القيمتين الاختياريتين نفسيهما.
إذ يمكن فحصهما للتساوي فقط.
وتكون القيمتان الاختياريتان متساويتين إذا كانتا `nil` معًا أو إذا كانت القيمتان اللتان تغلّفانهما متساويتين ضمن نوعيهما الأساسيين.

ومع ذلك، يمكن كتابة كود لإجراء مقارنة مخصصة بين قيمتين اختياريتين.
في ما يلي مثال على عبارة `switch` تُرجع `true` فقط إذا كانت القيمتان الاختياريتان غير `nil` وكانت القيمة الأولى أقل من الثانية.
وللقيام بذلك، تستخدم _النمط الاختياري_ `varName?` الذي لا يطابق إلا القيم الاختيارية غير `nil`، فتربط القيمة داخل النوع الاختياري بالاسم `varName`.

```swift
switch (optionalA, optionalB) {
case let (valA?, valB?): return valA < valB
default: return false
}
```
