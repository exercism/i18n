# حول

يتيح الامتداد الساكن تمديد الأنواع الموجودة تمديدًا ظاهريًا دون تعديل مصدرها. ويتحقق ذلك باستخدام عبارة `using`. يمكن أن تكون الامتدادات الساكنة أداة قوية تتيح تعزيز الأنواع دون تغييرها فعليًا.

```haxe
using Main.IntExtender;

class Main {
  public static function main() {
    trace(2.triple()); // 6
  }
}

class IntExtender {
  public static function triple(i:Int):Int {
    return i * 3;
  }
}
```
