# للمشرفين

## إنشاء الاختبارات: `bin/generate_tests.py`

تُنشأ ملفات الاختبار من البيانات القياسية في
[exercism/problem-specifications](https://github.com/exercism/problem-specifications)
باستخدام قالب Jinja مخزّن في كل تمرين في `.meta/template.j2`.

```bash
bin/generate_tests.py bob            # regenerate one exercise
bin/generate_tests.py                # regenerate every exercise that has a template
bin/generate_tests.py --no-pull bob  # skip `git pull` of problem-specifications
```

يقرأ السكربت problem-specifications من ذاكرة configlet المؤقتة
(`~/.cache/exercism/configlet/problem-specifications`، التي يملؤها `bin/configlet sync`)،
أو من مجلد أب اسمه `problem-specifications`.
ولا تُنشأ إلا الحالات المضمّنة في `.meta/tests.toml`.

لا يمكن أن تحتوي السلاسل النصية الحرفية في Fortran على محارف هروب مثل `\n` و `\t`.
لذا يعيد مرشّح القالب `escape_quote_whitespace` كتابتها على هيئة
`" // NEWLINE // "` و `" // TAB // "` و `" // CARRIAGE_RETURN // "`،
لذا يجب أن يعلن القالب عن تلك الثوابت (انظر `exercises/practice/bob/.meta/template.j2`).

### المتطلبات المسبقة

- أن يعمل كلٌّ من CMake ومترجم Fortran
- Python 3.12+ مع `jinja2`
- git

### سير العمل لإضافة تمرين جديد

باستخدام `bob` كمثال:

- أنشئ فرعًا جديدًا، مثل `git checkout -b exercise-bob`
- شغّل `bin/add-exercise bob` (يحتاج إلى `jq` و `curl`). وهو يقوم بما يلي:
  - يجلب configlet ويشغّل `configlet create`، الذي يضيف التمرين إلى `config.json` ويزامن مستنداته وبياناته الوصفية و `tests.toml` من problem-specifications
  - يرتّب `config.json` باستخدام `bin/reorder-exercises`
  - ينسخ `exercises/shared/CMakeLists.txt` إلى مجلد التمرين
  - يكتب حلًا مبدئيًا، وملف `.meta/example.f90` مبدئيًا، وقالب بداية `.meta/template.j2` (من `exercises/shared/template.j2`)

  ويسألك عن اسم المستخدم في GitHub ما لم تمرّر `-a <username>`، ويضبط الصعوبة على 1 ما لم تمرّر `-d <difficulty>`.

- حرّر `.meta/template.j2` بحيث تستدعي كل حالة الدالة الصحيحة بالمدخلات الصحيحة، ثم أنشئ الاختبارات:

  ```bash
  bin/generate_tests.py bob
  ```

- اكتب حلًا يعمل في `.meta/example.f90`. واستبدل ملف الطالب (مثل `bob.f90`) بهيكل من الدوال أو الإجراءات الفرعية التي تستدعيها الاختبارات، لمساعدة الطالب على البدء
- تأكد من نجاح جميع الاختبارات، بتشغيل البناء الكامل من جذر المستودع:

  ```bash
  mkdir -p build && cd build
  cmake ..
  cmake --build .
  ctest -V -R bob
  ```

- شغّل `bin/reorder-exercises` و `bin/configlet lint`
- إذا نجح كل شيء، افتح طلب سحب بتغييراتك

### تغيير `CMakeLists.txt`

عند تغيير ملف cmake، حدّث النسخة الرئيسية في `exercises/shared/` واستخدم `bin/update-cmake-files` لنسخها إلى جميع مجلدات التمارين.
