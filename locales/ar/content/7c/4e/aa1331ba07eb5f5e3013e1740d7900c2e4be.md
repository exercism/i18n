# نبذة

‏C# لغة ذات أنواع ثابتة، وهذا يعني أن لكل شيء نوعًا في وقت التصريف. يُسمّى اختيار اسم لـ [متغير][variable] تعريفًا للمتغير. وبعد تعريف المتغير، يُسمّى ضبط قيمته أو تحديثها إسناد المتغير. ويمكن تعريف المتغير إما بتحديد نوعه صراحةً، وإما باستخدام [الكلمة المفتاحية `var`][var] ليستنتج مترجم C# نوعه بناءً على القيمة المُسندة. ويُعرف استخدام `var` بـ _استنتاج النوع_.

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

يمكن إسناد قيمة المتغير وتحديثها باستخدام [العامل `=`][assignment]. وبعد تعريفه، لا يمكن أن يتغير نوع المتغير أبدًا.

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

‏C# لغة كائنية التوجه، وتتطلب تعريف كل [الدوال][function] داخل _صنف_، ويُعرَّف الصنف باستخدام [الكلمة المفتاحية `class`][classes]. وتُنشأ الكائنات (أو _المثيلات_) باستخدام الكلمة المفتاحية `new`.

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

وتُسمّى الدالة داخل الصنف _طريقة_. ويمكن أن يكون لكل [طريقة][methods] صفر أو أكثر من المعاملات. ويجب تحديد نوع جميع المعاملات صراحةً، فلا يوجد استنتاج للنوع في المعاملات. وبالمثل، يجب أيضًا تحديد نوع الإرجاع صراحةً. وتُرجع الطرق القيم باستخدام [الكلمة المفتاحية `return`][return]. وللسماح باستدعاء الطريقة من كود في ملفات أخرى، يجب إضافة مُحدِّد الوصول `public`.

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

تُستدعى الطرق باستخدام صيغة النقطة (`.`) على مثيل، مع تحديد اسم الطريقة المراد استدعاؤها وتمرير الوسائط لكل معامل من معاملات الطريقة. ويمكن للوسائط اختياريًا تحديد اسم المعامل المقابل.

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

إذا كانت الطريقة المراد استدعاؤها معرَّفة في الصنف نفسه الذي يحتوي على الطريقة المستدعية، فيمكن حذف اسم الصنف.

وإذا لم تستخدم الطريقة أي _حالة_ للكائن، فيمكن جعلها _ثابتة_ باستخدام مُحدِّد `static`. وتُستدعى الطرق الثابتة أيضًا بصيغة النقطة (`.`)، لكن على الصنف نفسه بدلًا من مثيل للصنف.

وإذا كان الصنف يحتوي على طرق ثابتة فقط، فيمكن جعله ثابتًا هو أيضًا باستخدام مُحدِّد `static`. وهذا يعبّر عن الغرض من الصنف.

```csharp
static class Calculator
{
    public static int Multiply(int x, int y)
    {
        return x * y;
    }
}

Calculator.Multiply(2, 4); // => 8
```

يُعرَّف النطاق في C# بين المحرفين `{` و `}`.

‏C# يدعم نوعين من [التعليقات][comments]. تسبق التعليقات أحادية السطر علامة `//`، وتُوضع التعليقات متعددة الأسطر بين `/*` و `*/`.

تُعرَّف القيم الصحيحة على أنها رقم واحد أو أكثر (متتالٍ)، وتدعم [عوامل الحساب الافتراضية][operators].

يجب أن يتبع [اسم المتغير بعض القواعد][identifier-names] مثل أن يبدأ بحرف أو بشرطة سفلية، و[يُستحسن أن يتبع اصطلاحات تسمية C#][naming-guidelines]. وإذا تعارض اسم المتغير مع [كلمة مفتاحية محجوزة في C#][csharp-keywords]، فيجب الهروب منه باستخدام `@`. ولا يُنصح باستخدام هذا الترميز، لكنه قد يُصادَف في حالات استثنائية، مثل: `var @this` أو `var @class` أو `var @var`.

هناك مفهومان أساسيان جدًا في لغة من عائلة C مثل C#، بحيث يظهران تلقائيًا في أي قطعة كود غير بسيطة تقريبًا. وهما [التغيير][mutation] و[النطاق][scope]. التغيير هو فكرة أن قيمة المتغير يمكن أن تتغير خلال عمر البرنامج. والنطاق هو فكرة أن القيمة المرتبطة باسم (لعُنصر برمجي) لا يمكن الوصول إليها إلا داخل "مساحة" الكود التي عُرِّفت فيها. ومناطق الكود الرئيسية في C# هي _الصنف/البنية_ و_الدالة_ (عادةً الطرق)، لكنها قد تشمل أيضًا أجسام الحلقات وتركيبات أخرى.
