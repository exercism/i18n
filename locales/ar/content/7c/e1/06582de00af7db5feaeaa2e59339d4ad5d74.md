# مقدمة

بينما يمكن استخدام تعبيرات `if/else` لتنفيذ منطق شرطي، فإن هناك أسلوبًا أقوى في Haskell لتنفيذ المنطق الشرطي: [مطابقة الأنماط][pattern-matching].
مع مطابقة الأنماط، يمكن اختبار قيمة مقابل نمط واحد أو أكثر من _الأنماط_.
ومن أمثلة هذا النمط _النمط الثابت_، الذي يطابق قيمة مقابل ثابت (مثل `1` أو `"hello"`).

عند تعريف الدوال، يمكنك تعريف أجسام دوال منفصلة لأنماط مختلفة.
وهذا يؤدي إلى كود نظيف بسيط ومقروء.
يمكنك مطابقة الأنماط على أي نوع بيانات: الأعداد، والمحارف، والمصفوفات، والصفوف، وغير ذلك.

على سبيل المثال، دالة بسيطة تأخذ عددًا صحيحًا (`Int`) وتجعله أقرب إلى _0_ بمقدار _1_ يمكن التعبير عنها هكذا:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero 1 = 0
```

تبدأ مطابقة الأنماط بالتألق عند استخدامها مع أنماط أخرى، مثل _النمط المتغير_:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero n = n - 1
```

يتعامل المثال أعلاه مع جميع المدخلات بخلاف _0_ بالطريقة نفسها، وسينتج نتائج غير صحيحة للأعداد السالبة.
يمكن حل ذلك باستخدام أنماط شرطية تُعرف باسم _الحراس_، وتُعبَّر عنها بالرمز `|`:

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
```

في الأمثلة أعلاه، ليست كل المدخلات الممكنة لها نمط مطابق.
سيكتشف المترجم ذلك ويصدر تحذيرًا.
هذه ميزة مفيدة جدًا في Haskell تساعد على ضمان تغطية جميع المسارات الممكنة لتجنب أخطاء وقت التشغيل.
وتُعرف باسم _الفحص الشامل_.
لحل التحذير، عليك التعامل مع جميع الحالات.
وداخل _الحراس_ يمكنك استخدام التعبير `otherwise` كسكر نحوي لـ `True` لالتقاط جميع الأنماط المتبقية.

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
    | otherwise = 0
```

ستختبر مطابقة الأنماط قيمة مقابل كل نمط من الأعلى إلى الأسفل، حتى تجد نمطًا مطابقًا وتنفّذ المنطق المرتبط بذلك النمط.
