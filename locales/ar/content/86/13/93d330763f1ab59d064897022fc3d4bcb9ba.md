# مقدمة

توجد معظم البيانات في Factor داخل *المتسلسلات*. فالمصفوفات والمتجهات والسلاسل النصية كلها متسلسلات، وتشترك في مجموعة مشتركة من الكلمات من مفردات [`sequences`][sequences].

## المصفوفات الحرفية

تستخدم المصفوفة الحرفية `{ }` مع مسافات بيضاء بين العناصر:

```factor
{ 1 2 3 } .          ! => { 1 2 3 }
{ "a" "b" "c" } .    ! => { "a" "b" "c" }
```

المصفوفات ثابتة الطول، لذا فإن كلمات مثل `suffix` و`remove-nth`، التي تغيّر عدد العناصر، تُرجع متسلسلة *جديدة* بدلًا من توسيع المصفوفة الأصلية.

## الطول والفهرسة

```
length   ( seq -- n   )
first    ( seq -- elt )
rest     ( seq -- tailseq )    ! everything but the first element
last     ( seq -- elt )
but-last ( seq -- headseq )    ! everything but the last element
nth      ( n seq -- elt )      ! 0-based
?nth     ( n seq -- elt/f )    ! 0-based; f when out of bounds
```

```factor
{ 10 20 30 } length .       ! => 3
{ 10 20 30 } first .        ! => 10
{ 10 20 30 } rest .         ! => { 20 30 }
{ 10 20 30 } last .         ! => 30
{ 10 20 30 } but-last .     ! => { 10 20 }
1 { 10 20 30 } nth .        ! => 20
```

`?nth` هي النسخة الآمنة تجاه الحدود: يمكنك فحص موضع دون التحقق من الطول أولًا.

```factor
1 { 10 20 30 } ?nth .       ! => 20
9 { 10 20 30 } ?nth .       ! => f  (out of bounds, no error)
```

## التقطيع

```
head ( seq n -- headseq )    ! first n elements
tail ( seq n -- tailseq )    ! drop first n
```

```factor
{ 1 2 3 4 5 } 3 head .   ! => { 1 2 3 }
{ 1 2 3 4 5 } 3 tail .   ! => { 4 5 }
```

كلتاهما ترمي استثناءً إذا كان `n` أكبر من المتسلسلة. وإذا كان `n` كبيرًا جدًا، فإن `index-or-length` تُقلّصه إلى طول المتسلسلة، بحيث لا يتجاوز التقطيع الذي يليه نهايتها:

```
index-or-length ( seq n -- seq n' )
```

```factor
{ 10 20 30 40 50 } 3 index-or-length head .   ! => { 10 20 30 }
{ 10 20 } 3 index-or-length head .            ! => { 10 20 }
```

أما الصيغ المعلَّمة بنجمة، `head*` و`tail*`، فتحسب من النهاية: تُسقط `head*` آخر `n`، وتُبقي `tail*` آخر `n`:

```
head* ( seq n -- headseq )   ! everything except the last n
tail* ( seq n -- tailseq )   ! the last n elements
```

```factor
{ 1 2 3 4 5 } 2 head* .   ! => { 1 2 3 }
{ 1 2 3 4 5 } 2 tail* .   ! => { 4 5 }
```

وللتقطيع العشوائي بين فهرسين، تأخذ `subseq` *البداية* (شاملة) و*النهاية* (غير شاملة):

```
subseq ( from to seq -- subseq )
```

```factor
1 4 { 10 20 30 40 50 } subseq .   ! => { 20 30 40 }
1 4 "hello" subseq .              ! => "ell"
```

وعندما يكون لديك *بداية وطول*، اجمع بينهما للحصول على النهاية:

```factor
2 dup 3 + "hello world" subseq .  ! => "llo"
```

(هذا هو نطاق الفهارس `[2, 5)`، أي ثلاثة أحرف بدءًا من الموضع 2.)

أما السؤال المعاكس، أي *أين* تظهر متسلسلة فرعية، فتجيب عنه `subseq-index`، التي تُرجع فهرس بداية أول تطابق، أو `f` عند عدم وجود أي تطابق:

```
subseq-index ( seq subseq -- i/f )
```

```factor
"hello world" "o w" subseq-index .   ! => 4
"hello world" "xyz" subseq-index .   ! => f
```

## الحشو

```
pad-head ( seq n elt -- padded )    ! prepend copies of elt
pad-tail ( seq n elt -- padded )    ! append copies of elt
```

تمدد كلتاهما `seq` حتى يصبح طولها `n` على الأقل. وإذا كانت `seq` بهذا الطول بالفعل، فستُعاد كما هي دون تغيير.

```factor
{ 2 5 0 } 6 0 pad-tail .   ! => { 2 5 0 0 0 0 }
{ 4 1 } 5 9 pad-head .     ! => { 9 9 9 4 1 }
```

## الكلمات نفسها تعمل على السلاسل النصية

السلسلة النصية هي متسلسلة من الأحرف، لذا فإن كل ما سبق يعمل على السلاسل النصية أيضًا، لكن النتيجة تكون سلسلة نصية أخرى بدلًا من مصفوفة:

```factor
"hello" length .            ! => 5
"hello" 3 head .             ! => "hel"
"abc" 6 CHAR: . pad-tail .   ! => "abc..."
```

## التجميع

تجمع `sum` و`product` (في [`sequences`][sequences]) عناصر متسلسلة عددية أو تضربها:

```factor
{ 2 5 0 7 } sum .        ! => 14
{ 2 5 3 7 } product .    ! => 210
```

تشغّل `count` محمولًا على المتسلسلة وتُرجع عدد العناصر التي جعلته صحيحًا:

```
count ( seq quot -- n )
```

```factor
{ 2 5 0 7 4 1 } [ even? ] count .    ! => 3
```

## المحمولات على المتسلسلة كاملة

```
any?   ( seq quot -- ? )
all?   ( seq quot -- ? )
empty? ( seq -- ? )
```

```factor
{ 2 5 0 7 } [ 4 > ] any? .      ! => t
{ 2 5 0 7 } [ 0 > ] all? .      ! => f
```

## بناء متسلسلة جديدة

تضيف `suffix` عنصرًا إلى نهاية المتسلسلة، وتضيف `prefix` عنصرًا إلى بدايتها. وتنزع `unclip` العنصر الأول، وتنزع `unclip-last` العنصر الأخير:

```
prefix      ( seq elt -- newseq )
suffix      ( seq elt -- newseq )
unclip      ( seq -- rest first )
unclip-last ( seq -- butlast last )
```

```factor
{ 7 9 } 3 prefix .             ! => { 3 7 9 }
{ 7 9 } 3 suffix .             ! => { 7 9 3 }
{ 4 0 9 } unclip .s
! => { 0 9 }
! => 4
```

الجمع بين `unclip-last` و`suffix` يمنحك تحديثًا غير مُتلف للعنصر الأخير (و`unclip` مع `prefix` يفعل الشيء نفسه للعنصر الأول):

```factor
{ 10 20 30 } unclip-last 2 * suffix .
! => { 10 20 60 }
```

## التحويل بين أنواع المتسلسلات

تُجبر `>array` و`>vector` و`>string` (في [`arrays`][arrays] والمفردات المقابلة) المتسلسلة على أن تصبح نوعًا ملموسًا معينًا. وهذا مفيد عندما تُرجع عملية ما تقطيعًا أو متسلسلة عامة وتحتاج إلى استعادة مصفوفة (أو سلسلة نصية).

```factor
{ 1 2 3 } 1 tail >array .   ! => { 2 3 }
"hello" >array .            ! => { 104 101 108 108 111 }
{ 65 66 67 } >string .      ! => "ABC"
```
