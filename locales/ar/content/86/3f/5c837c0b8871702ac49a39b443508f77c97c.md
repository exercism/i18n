# مقدمة

## عوامل المقارنة

[عوامل المقارنة][comparison-operators] تقارن قيمتين من النوع نفسه وتُرجع قيمة `Bool` (`true` أو `false`).
إذا حاولت المقارنة بين قيم من أنواع مختلفة، فسيُنتج المترجم خطأً.

عوامل المقارنة القياسية في Swift هي:

| العامل | الوصف | المثال |
| -------- | ------------------------ | --------------- |
| `==`     | يساوي                 | `1 == 1` (صحيح) |
| `!=`     | لا يساوي                 | `1 != 2` (صحيح) |
| `<`      | أصغر من                | `4 < 5`  (صحيح) |
| `<=`     | أصغر من أو يساوي    | `4 <= 4` (صحيح) |
| `>`      | أكبر من                 | `3 > 1`  (صحيح) |
| `>=`     | أكبر من أو يساوي | `2 >= 2` (صحيح) |

## جمل `if` و `else`

[الجملة الشرطية][conditional-statement] تنفّذ كودًا بناءً على ما إذا كان الشرط يُقيَّم إلى `true` أو `false`.
أكثر الجمل الشرطية شيوعًا هي [الجملة الشرطية `if`][if]، وهي تنفّذ كتلة من الكود فقط عندما يكون شرطها `true`.
اكتب جملة `if` باستخدام الكلمة المفتاحية `if`، متبوعةً بالشرط وكتلة الكود المحصورة بين الأقواس المعقوفة:

```swift
let wheelCount = 4
if wheelCount == 4 {
    print("Your vehicle is a car")
}
// Prints "Your vehicle is a car"
```

يمكنك إقران `if` بجملة `else` لتنفيذ كود بديل عندما يكون الشرط `false`:

```swift
let precipitationInMM = 0.5
if precipitationInMM > 0.5 {
    print("You will need an umbrella")
} else {
    print("You will not need an umbrella")
}
// Prints "You will not need an umbrella"
```

لاختبار عدة شروط بالتتابع، اربط الجمل معًا باستخدام `else if`.
جملة `if` لا تتطلب فرع `else`، لكن يمكنك تضمين واحد للتعامل مع الحالات التي لا يتحقق فيها أي من الشروط:

```swift
let favoriteFruit = "Apple"

if favoriteFruit == "Banana" {
    print("Your favorite fruit is a banana")
} else if favoriteFruit == "Orange" {
    print("Your favorite fruit is an orange")
} else if favoriteFruit == "Apple" {
    print("Your favorite fruit is an apple")
} else {
    print("Your favorite fruit is not a banana, orange, or apple")
}
// Prints "Your favorite fruit is an apple"
```

## تعبيرات `if`

في Swift الحديثة، يمكن استخدام جمل `if` أيضًا كتعبيرات تُنتج قيمة.
كل فرع يُقيَّم إلى قيمة، ما يسهّل إسناد النتائج شرطيًا:

```swift
let cpuBits = 32
let architecture = if cpuBits == 64 {
    "x86_64"
} else {
    "x86_32"
}

print(architecture)
// Prints "x86_32"
```

## العامل الثلاثي

[العامل الشرطي الثلاثي][ternary-operator] اختصار موجز لتعبير `if-else`.
يُقيّم شرطًا ويُرجع إحدى قيمتين حسب ما إذا كان ذلك الشرط `true` أو `false`.

يستخدم العامل ثلاثة أجزاء: `condition ? trueExpression : falseExpression`.
إذا قُيِّم `condition` إلى `true`، فسيُقيَّم `trueExpression` ويُرجَع. وإلا، فسيُقيَّم `falseExpression` ويُرجَع.

العامل الثلاثي مثالي للاختيارات البسيطة ذات السطر الواحد:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = showFahrenheit ? temperatureInCelsius * 9 / 5 + 32 : temperatureInCelsius
print(temperature)
// Prints 86
```

المثال أعلاه مكافئ مختصر لما يلي:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = if showFahrenheit {
    temperatureInCelsius * 9 / 5 + 32
} else {
    temperatureInCelsius
}
```
