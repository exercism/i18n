# التعليمات

يسير صالون التجميل في نيويورك الذي ساعدته في تمرين «الحجز من أجل الجمال» على ما يرام، وقد أصبح الكثير من عملائه من العملاء الدائمين.
فبدلًا من حجز كل زيارة على حدة، لدى العميل الدائم اتفاق ثابت: «كل ثلاثاء ثانٍ»، «آخر جمعة في الشهر»، وهكذا.
وقد طلبت منك صاحبة الصالون مساعدًا يحسب التواريخ الكامنة وراء هذه الاتفاقات، وكذلك تواريخ الروتين الشهري للصالون نفسه.

## 1. إيجاد الموعد الثابت لعميل دائم

نفّذ الطريقة `SalonCalendar.standingAppointment()` التي تأخذ سنة وشهرًا ورقم المرة (`1` للمرة الأولى، و`2` للمرة الثانية، وهكذا) ويومًا من أيام الأسبوع.
وهي تُرجع تاريخ تلك المرة من يوم الأسبوع داخل الشهر:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.standingAppointment(2024, Month.AUGUST, 2, DayOfWeek.TUESDAY);
// => LocalDate.of(2024, 8, 13)
```

## 2. إيجاد موعد آخر الشهر لعميل دائم

يفضّل بعض العملاء الدائمين المرة الأخيرة من يومهم في الشهر.
نفّذ الطريقة `SalonCalendar.lastAppointment()` التي تأخذ سنة وشهرًا ويومًا من أيام الأسبوع، وتُرجع تاريخ آخر مرة من ذلك اليوم من أيام الأسبوع داخل الشهر:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.lastAppointment(2024, Month.AUGUST, DayOfWeek.FRIDAY);
// => LocalDate.of(2024, 8, 30)
```

## 3. إيجاد أقرب يوم متاح لعميل بدون موعد

يطلب أحد العملاء عند مكتب الاستقبال «السبت القادم».
وإذا كان اليوم الذي يسأل فيه هو السبت نفسه، فهو يعني ذلك اليوم ذاته.
نفّذ الطريقة `SalonCalendar.nextAvailable()` التي تأخذ تاريخًا ويومًا من أيام الأسبوع، وتُرجع أول تاريخ في التاريخ المعطى أو بعده يوافق ذلك اليوم من أيام الأسبوع:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.nextAvailable(LocalDate.of(2024, 8, 15), DayOfWeek.SATURDAY);
// => LocalDate.of(2024, 8, 17)
calendar.nextAvailable(LocalDate.of(2024, 8, 17), DayOfWeek.SATURDAY);
// => LocalDate.of(2024, 8, 17)
```

## 4. إيجاد يوم إقفال الدفاتر

يُقفل الصالون دفاتره في آخر يوم من كل شهر.
غير أن الصالون مغلق في عطلات نهاية الأسبوع، فإذا وافق آخر يوم في الشهر يوم سبت أو أحد، أُقفلت الدفاتر يوم الجمعة الذي قبله.
نفّذ الطريقة `SalonCalendar.bookkeepingDay()` التي تأخذ سنة وشهرًا، وتُرجع يوم إقفال الدفاتر في ذلك الشهر:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.bookkeepingDay(2024, Month.SEPTEMBER);
// => LocalDate.of(2024, 9, 30)
calendar.bookkeepingDay(2024, Month.AUGUST);
// => LocalDate.of(2024, 8, 30)
```

## 5. إعادة استخدام قاعدة عطلة نهاية الأسبوع ليوم الرواتب

يتقاضى الموظفون رواتبهم في الخامس عشر من كل شهر، وبنفس قاعدة عطلة نهاية الأسبوع: فإذا وافق الخامس عشر يوم سبت أو أحد، كان يوم الرواتب هو الجمعة الذي قبله.
بدلًا من كتابة القاعدة مرة ثانية، حوّلها إلى مُعدِّل قابل لإعادة الاستخدام.

نفّذ الطريقة `SalonCalendar.precedingWorkday()` التي تُرجع `TemporalAdjuster` يترك أيام الأسبوع كما هي، ويعيد يوم السبت أو الأحد إلى يوم الجمعة الذي قبله.
ثم نفّذ الطريقة `SalonCalendar.payday()` التي تأخذ سنة وشهرًا، بالاستعانة بذلك المُعدِّل:

```java
SalonCalendar calendar = new SalonCalendar();
LocalDate.of(2024, 6, 15).with(calendar.precedingWorkday());
// => LocalDate.of(2024, 6, 14)
calendar.payday(2024, Month.JUNE);
// => LocalDate.of(2024, 6, 14)
calendar.payday(2024, Month.AUGUST);
// => LocalDate.of(2024, 8, 15)
```

لا تتردد في العودة واستخدام المُعدِّل في `bookkeepingDay()` أيضًا.
