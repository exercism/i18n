# التعلّم

Coq نظام لإدارة البراهين الصورية. وهو يوفّر لغة صورية لكتابة التعريفات الرياضية والخوارزميات القابلة للتنفيذ والمبرهنات، إلى جانب بيئة لتطوير البراهين التي يتحقق منها الحاسوب تطويرًا شبه تفاعلي.

وهناك بعض المصادر المجانية لتعلّم Coq، مثل:

* سلسلة كتب Software Foundations:
    + [المجلد الأول: Logical Foundations](https://softwarefoundations.cis.upenn.edu/lf-current/index.html)
    + [المجلد الثاني: Programming Language Foundations](https://softwarefoundations.cis.upenn.edu/plf-current/index.html)
    + [المجلد الثالث: Verified Functional Algorithms](https://softwarefoundations.cis.upenn.edu/vfa-current/index.html)
* كتاب Certified Programming with Dependent Types:
    + وهو متاح مجانًا على [موقع Adam Chipala](http://adam.chlipala.net/cpdt/).
