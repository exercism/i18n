# التعليمات

في هذا التمرين ستعمل على جدول مواعيد لصالون تجميل في نيويورك افتُتح في 15 سبتمبر 2012.

لديك أربع مهام، وكلها ستتعلق بتواريخ المواعيد. ستستخدم التواريخ والأوقات أحد التنسيقات الثلاثة التالية:

- `"7/25/2019 13:45:00"`
- `"July 25, 2019 13:45:00"`
- `"Thursday, July 25, 2019 13:45:00"`

ستضبط الاختبارات الثقافة تلقائيًا على `en-US`، ولست بحاجة إلى ضبط الثقافة أو تحديدها بنفسك.

## 1. تحليل تاريخ الموعد

نفّذ الطريقة (_static_) `Appointment.Schedule()` التي تحلّل تمثيلًا نصيًا لتاريخ موعد إلى تنسيق `DateTime` المقابل:

```csharp
Appointment.Schedule("7/25/2019 13:45:00")
// => new DateTime(2019, 7, 25, 13, 45, 0)
```

## 2. التحقق مما إذا كان الموعد قد مضى

نفّذ الطريقة (_static_) `Appointment.HasPassed()` التي تأخذ تاريخ موعد وتتحقق مما إذا كان الموعد قد وقع في وقت ما في الماضي:

```csharp
Appointment.HasPassed(new DateTime(1999, 12, 31, 9, 0, 0))
// => true
```

## 3. التحقق مما إذا كان الموعد في فترة بعد الظهر

نفّذ الطريقة (_static_) `Appointment.IsAfternoonAppointment()` التي تأخذ تاريخ موعد وتتحقق مما إذا كان الموعد في فترة بعد الظهر (>= 12:00 و < 18:00):

```csharp
Appointment.IsAfternoonAppointment(new DateTime(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. وصف وقت الموعد وتاريخه

نفّذ الطريقة (_static_) `Appointment.Description()` التي تأخذ تاريخ موعد وتُرجع وصفًا لذلك التاريخ والوقت:

```csharp
Appointment.Description(new DateTime(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on 3/29/2019 3:00:00 PM."
```

## 5. إرجاع تاريخ الذكرى السنوية

نفّذ الطريقة (_static_) `Appointment.AnniversaryDate()` التي تُرجع تاريخ الذكرى السنوية لهذا العام، وهو 15 سبتمبر:

```csharp
Appointment.AnniversaryDate()
// => new DateTime(2019, 9, 15, 0, 0, 0)
```
