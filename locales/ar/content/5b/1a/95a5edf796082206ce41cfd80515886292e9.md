# مقدمة

Factor لغة *تسلسلية*: كل كلمة تقرأ مدخلاتها من **مكدس البيانات** المشترك وتدفع مخرجاتها إليه مرة أخرى. وليس هناك أسلوب آخر لتمرير القيم.

كتابة قيمة حرفية تدفعها إلى قمة المكدس، ويُقرأ الكود من اليسار إلى اليمين:

```factor
1 2 3    ! stack (bottom → top): 1 2 3
```

تعريف *تأثير المكدس* يوثّق عقد الكلمة:

```factor
: restow ( a b -- b a ) swap ;
```

تقول `( a b -- b a )` إن الكلمة تسحب قيمتين وتترك قيمتين بترتيب معكوس. الأسماء للتوثيق فقط، فالمترجم لا يتحقق إلا من *عدد* المدخلات والمخرجات، والاسم على اليمين هو قمة المكدس.

وتعيد **كلمات إعادة الترتيب** المعتادة في `kernel` ترتيب قمة المكدس:

```
dup  ( x   -- x x   )
drop ( x   --       )
swap ( x y -- y x   )
over ( x y -- x y x )
nip  ( x y -- y     )
rot  ( x y z -- y z x )
```

تُعرَّف الكلمات بـ `:` وتنتهي بـ `;`، ويرفض المترجم أي تعريف لا يطابق جسمه التأثير المُعلن.
