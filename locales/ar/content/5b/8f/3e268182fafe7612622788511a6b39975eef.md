# التعليمات

في هذا التمرين، ستُحاكي نظام حاسوب قائمًا على النوافذ.
ستُنشئ بعض النوافذ التي يمكن نقلها وتغيير حجمها.
توضّح الصورة التالية القيم التي ستعمل عليها أدناه.

```text
 ╔════════════════════════════════════════════════════════════╗
 ║                                                            ║
 ║        position::$y,_                                      ║
 ║        position::$x  \                                     ║

 ║                 ^      *──────────────────────┐            ║
 ║                 |      │        title         │            ║
 ║                 |      ├──────────────────────┤            ║

 ║          size::$height │                      │            ║
 ║                 |      │       contents       │            ║
 ║                 |      │                      │            ║
 ║                 |      │                      │            ║
 ║                 v      └──────────────────────┘            ║
 ║                                                            ║
 ║                                                            ║
 ╚════════════════════════════════════════════════════════════╝
```

## 1. عرّف خصائص نافذة البرنامج

باستخدام هيكل الصنف المقدَّم، عرّف الخصائص الخاصة بقيم `y` و`x` و`height` و`width`.

```php
<?php

$window = new ProgramWindow();
$window->y; // => null
$window->x; // => null
$window->height; // => null
$window->width; // => null
```

## 2. عرّف القيم الأولية لنافذة البرنامج

عرّف دالة بناء لـ `ProgramWindow`.
يجب ألا تأخذ أي وسائط، لكن أثناء تنفيذ دالة البناء عيّن القيم الافتراضية لخصائصها.
يجب أن تعيّن القيم الأولية لـ `y` و`x` إلى `0`.
يجب أن تعيّن `height` و`width` الأوليين إلى حجم شاشة `600x800`.

```php
<?php

$window = new ProgramWindow();
$window->y; // => 0 
$window->x; // => 0
$window->height; // => 600
$window->width; // => 800
```

## 3. عرّف دالة لتغيير حجم النافذة

عرّف صنفًا جديدًا في `Size.php` لصنف `Size`.
يجب أن تأخذ وسائط لدالة البناء لتعيين خاصيتي `height` و`width`.
بالإضافة إلى ذلك، يحتاج `ProgramWindow` إلى دالة لتغيير الحجم، تستقبل نسخة كائن `Size` وتحدّث خصائصه الخاصة.

```php
<?php 

$window = new ProgramWindow();
$size = new Size(764, 1080);
$window->resize($size)

$window->height;
// => 764
$window->width;
// => 1080
```

## 4. عرّف دالة لنقل النافذة

عرّف صنفًا جديدًا في `Position.php` لصنف `Position`.
يجب أن تأخذ وسائط لدالة البناء لتعيين خاصيتي `y` و`x`.
بالإضافة إلى ذلك، يحتاج `ProgramWindow` إلى دالة للنقل، تستقبل نسخة كائن `Position` وتحدّث خصائصه الخاصة.

```php
<?php 

$window = new ProgramWindow();
$position = new Position(80, 313);
$window->move($position)

$window->y;
// => 80
$window->x;
// => 313
```
