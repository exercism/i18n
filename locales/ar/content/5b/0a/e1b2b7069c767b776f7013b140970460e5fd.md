# نبذة

في Haxe، يُعدّ `class` البنية الأساسية للبيانات، وهو يغلّف البيانات (الحقول) والسلوك (الطرق). وتُسمّى الحقول والطرق أيضًا أعضاء الصنف.

يمكن تقييد الوصول إلى الأعضاء باستخدام [محددات الوصول][visibility]، وهي:

- `public`: يمكن الوصول إلى العضو من أي مكان.
- `private`: لا يمكن الوصول إلى العضو إلا من داخل الصنف نفسه.

يمكن النظر إلى الأصناف على أنها قوالب لإنشاء النسخ. ولإنشاء [نسخة][class-instance]، استخدم الكلمة المفتاحية `new` مباشرةً:

```haxe
class Car {
  public function new() {}
}

var myCar = new Car();
var yourCar = new Car();
```

لتعريف حقل، استخدم محدّد وصول يتبعه اسم المتغير ونوعه:

```haxe
class Car {
  public var weight:Int; // Accessable by anyone

  private var color:String; // Accessable only within this class
}
```

يمكنك أيضًا تحديد قيمة ابتدائية عند تعريف حقل. وإذا لم يحدد الحقل قيمة ابتدائية، فسيأخذ القيمة `null`. ويمكنك الوصول إلى الحقل باستخدام الترميز النقطي:

```haxe
class Car {
  public var weight:Int = 2500; // Weight will be set to 2500
  public var year:Int; // year will be null

  public function new() {}
}

var newCar = new Car();
newCar.weight; // 2500
newCar.year; // null

// Update value of field
newCar.year = 2020;
```
