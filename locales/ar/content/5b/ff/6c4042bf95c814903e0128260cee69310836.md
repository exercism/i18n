# مقدمة

## الثوابت والدوال

تُعرَّف القيمة الثابتة بـ `name = expression`، حيث إن كل شيء في Elm، باستثناء التعريفات، يُعد تعبيرًا.

```elm
five = 5

six = 3 + 3
```

تُعرَّف الدوال بـ `name parameters... = expression`، ولا تُفصل المعاملات عن بعضها إلا بمسافة.

```elm
add number1 number2 = number1 + number2
```

استدعاء الدالة هو أيضًا تعبير، ويتم بتحديد اسم الدالة وتمرير وسائط لكل معامل من معاملاتها، مفصولة بمسافة، تمامًا كما في تعريف الدالة.

```elm
five = add 2 3
```

يمكن استخدام الأقواس الهلالية لتحديد ترتيب تقييم تعبير ما.

```elm
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## الإزاحة / المسافات ذات الدلالة

لا يستخدم Elm علامات نحوية مثل الأقواس المعقوفة أو الأقواس الهلالية أو الفواصل المنقوطة لتحديد حدود الكود. بل يستخدم المسافات والإزاحات بدلًا من ذلك.

- يجب أن تبدأ تعريفات الوحدة والاستيراد والدوال من المستوى الأعلى في أقصى العمود إلى اليسار.
- إذا قُسّم تعبير على عدة أسطر، فيجب إزاحة الكود الذي هو جزء من ذلك التعبير تحت ذلك التعبير بمسافة واحدة على الأقل.
- يجب إزاحة أجزاء التعبير التي تُجمَّع معًا بعدد متساوٍ من المسافات.

```elm
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://elmprogramming.com/indentation.html

## الوحدات

كل ملف في Elm هو وحدة، ويجب أن يحتوي على عبارة `module` قبل أي كود آخر.
يجب أن تطابق أسماء الوحدات أسماء ملفاتها، لذا يجب أن تكون الوحدة `Calculator` في الملف Calculator.elm.
وكل ما يُعرَّف داخل وحدة يكون ضمن نطاق خاص بها
ولا يمكن الوصول إليه من خارج هذه الوحدة، إلا إذا ذُكر في `exposing`.

```elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## التعليقات

التعليق هو نص داخل ملف Elm لا يُفسَّر ككود.
والغرض منه أساسًا أن تقرأه أنت وبرمجيون آخرون.
توجد صيغة مبسطة للتعليقات ذات السطر الواحد، تعتمد على الشرطتين المتصلتين.
ويمكن أيضًا كتابة تعليقات متعددة الأسطر باستخدام الزوج `{-` و `-}`
من الفواصل الافتتاحية والختامية.

```elm
-- a single line comment
-- another single line comment

{- a multiline comment
   spawning multiple lines
-}
```
