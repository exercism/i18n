# مقدمة

تُمثّل Factor التواريخ والأوقات بمفردات [`calendar`][calendar]. اللحظة الزمنية هي `timestamp`، والفترة الزمنية هي `duration`.

## إنشاء تاريخ

تبني `<date>` (ضمن [`calendar`][calendar]) قيمة `timestamp` عند منتصف الليل في اليوم المعطى:

```
<date> ( year month day -- timestamp )
```

```factor
USING: calendar ;

1904 11 16 <date> .
! a timestamp at midnight on 1904-11-16
```

وتُقسّم `>date<` قيمة `timestamp` مرة أخرى إلى أجزائها:

```
>date< ( timestamp -- year month day )
```

```factor
1904 11 16 <date> >date< .   ! => 16   (with 1904 and 11 below it)
```

## فحص تاريخ

تُرجع `day-of-week` يوم الأسبوع كعدد صحيح، `0` للأحد وحتى `6` للسبت. أما `day-names` (ضمن [`calendar.english`][english]) فهي قائمة الأسماء المقابلة، لذا يحوّل `day-names nth` الرقم إلى اسم:

```factor
USING: calendar calendar.english sequences ;

2024 1 8 <date> day-of-week .          ! => 1
day-names .   ! { "Sunday" "Monday" ... "Saturday" } — Sunday first
```

ويقبل `leap-year?` سنة (أو قيمة `timestamp`)، وتُرجع `days-in-month` طول شهر قيمة `timestamp`، مع احتساب السنوات الكبيسة بالفعل:

```
leap-year?    ( obj -- ? )
days-in-month ( timestamp -- n )
```

```factor
2024 leap-year? .                ! => t
2024 2 1 <date> days-in-month .  ! => 29
```

## العمليات الحسابية على التواريخ

تبني كلمات مثل `days` و`weeks` و`hours` قيمة `duration`، ويُزيح `time+` قيمة `timestamp` بمقدار `duration` واحدة:

```
days  ( x -- duration )
time+ ( timestamp duration -- timestamp )
```

```factor
2024 2 28 <date> 1 days time+ >date< .
! => 29   (2024-02-29, with 2024 and 2 below it)
```

تنتقل العمليات الحسابية بشكل صحيح عبر حدود الشهر والسنة، وتتساوى قيمتا `timestamp` اللتان تشيران إلى اللحظة نفسها عند المقارنة بـ`=`.

## أوقات اليوم

تبني `<timestamp>` قيمة `timestamp` كاملة، حتى الثانية. معاملها الأخير هو الإزاحة عن UTC؛ ويُبقي `instant` (وهي `duration` تساوي صفرًا) قيمة `timestamp` عند UTC:

```
<timestamp> ( year month day hour minute second gmt-offset -- timestamp )
```

```factor
USING: calendar ;

1969 7 21 2 56 15 instant <timestamp> .
! a timestamp at 02:56:15 on 1969-07-21
```

وتُعدّ `>time<` النظير لـ`>date<`، إذ تُقسّم قيمة `timestamp` إلى ساعتها ودقيقتها وثانيتها:

```
>time< ( timestamp -- hour minute second )
```

```factor
1969 7 21 2 56 15 instant <timestamp> >time< .   ! => 15   (with 2 and 56 below it)
```

وتبني `seconds` و`minutes` قيمة `duration` تمامًا مثل `days` و`weeks` و`hours`، لذا يمكن تمرير أيٍّ منها إلى `time+`:

```
seconds ( x -- duration )
minutes ( x -- duration )
```

وتُقرأ الحقول المفردة لقيمة `timestamp` عبر دوال الوصول `year>>` و`month>>` و`day>>` و`hour>>` و`minute>>` و`second>>`:

```factor
1969 7 21 2 56 15 instant <timestamp> hour>> .   ! => 2
```
