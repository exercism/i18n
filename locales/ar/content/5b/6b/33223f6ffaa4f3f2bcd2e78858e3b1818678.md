# مقدمة

PowerShell لغة برمجة نصية ديناميكية ومُحدَّدة النوع ضمنيًا (_لكنها تدعم أيضًا [المتغيرات قوية النوع][strong typed]_) من Microsoft، وتُركّز في الغالب على أتمتة المهام وإدارة الإعدادات.

تدعم PowerShell الأسلوب الأمرّي والوظيفي والكائني التوجه، وحتى البرمجة بأسلوب خطوط الأنابيب.

بُنيت PowerShell على منصة .NET وصدرت لأول مرة عام 2006.
وهي مضمنة افتراضيًا في جميع إصدارات Windows الحديثة، ويمكن أيضًا تثبيتها على Mac وLinux.


## المتغيرات

هناك أسلوبان شائعان لتعريف متغير في PowerShell.

يجب أن تبدأ أسماء المتغيرات في PowerShell بالرمز `$`، وأن تستخدم عامل الإسناد `=` لربط اسم المتغير بقيمة.

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

يمكنك أيضًا تحديد نوع المتغير صراحةً، إذا أردت فرض أن تكون القيمة من نوع معين أو اشتراط ذلك.
وستبذل PowerShell قصارى جهدها لتحويل القيمة من نوع إلى آخر إن أمكن.

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```


### الثوابت

الثوابت في PowerShell متغيرات لا يمكن **تغييرها** ولا **إزالتها** بعد تعريفها.
وهذا يقودنا إلى الأسلوب الثاني لتعريف المتغيرات: استخدام الأمر `New-Variable`.

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
```

لمزيد من الأساليب التفصيلية والمتقدمة لإنشاء متغير جديد، اقرأ [New-Variable][New-Variable].


## الدوال

تُعرَّف [الدوال][functions] في PowerShell باستخدام الكلمة المفتاحية `function`.
يمكن أن تحتوي كل دالة على أي عدد من المعاملات الشكلية، بدءًا من صفر، بين الأقواس الهلالية `()`، يتبع ذلك نطاق الدالة الذي يبدأ بـ `{` وينتهي بـ `}`.

```powershell
function Greeting {
    return "Hello!"
}
```

يمكن للدوال في PowerShell أن تُرجع القيم صراحةً عبر الكلمة المفتاحية `return`، وذلك بعد استدعائها بالصيغة `FuncName $Arg`.

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

سنغطي نظرة متقدمة على كيفية كتابة تعريف دالة مفصّل، وكيف يمكن للدوال أن تُرجع القيم ضمنيًا، في وحدة مفهوم `Functions`.


## التعليقات

تبدأ التعليقات المفردة في PowerShell بـ `#` وتنتهي بنهاية السطر.
تبدأ كتل التعليقات في PowerShell بـ `<#` وتنتهي بـ `#>`.
سنعرض في وحدة مفهوم `Functions` مثالًا متقدمًا على استخدام كتلة التعليقات لإنشاء Comment-Based Help.

```powershell
function Main() {
    #This is a comment
    <#
    And this is a comment block
    that can span multiple lines
    #>
}
```
