# ملحق التعليمات

## تلميحات

في هذا التمرين، قدّمنا تعريف [نوع البيانات الجبري](https://learnyouahaskell.github.io/making-our-own-types-and-typeclasses) المسمّى `Planet`.
عليك أن تنفّذ الدالة `ageOn`، وهي تحسب كم سيكون عمر شخص بالسنوات على `Planet` إذا أُعطي عمره بالثواني.

يمكنك استخدام التوقيع المرفق إذا لم تكن متأكدًا من الأنواع، لكن لا تدعه يقيّد إبداعك:

```haskell
ageOn :: Planet -> Float -> Float
```
