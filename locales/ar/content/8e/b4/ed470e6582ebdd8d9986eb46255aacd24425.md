# التعليمات

عُدّ المستطيلات في مخطط ASCII مثل المخطط أدناه.

```text
   +--+
  ++  |
+-++--+
|  |  |
+--+--+
```

يحتوي المخطط أعلاه على هذه المستطيلات الستة:

```text


+-----+
|     |
+-----+
```

```text
   +--+
   |  |
   |  |
   |  |
   +--+
```

```text
   +--+
   |  |
   +--+


```

```text


   +--+
   |  |
   +--+
```

```text


+--+
|  |
+--+
```

```text

  ++
  ++


```

يمكنك أن تفترض أن المدخل مستطيل سليم دائمًا (أي أن طول كل سطر يساوي طول السطر الأول).
