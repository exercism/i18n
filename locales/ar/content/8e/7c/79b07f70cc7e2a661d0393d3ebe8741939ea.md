# مقدمة

Haxe لغة ذات أنواع صارمة، لكن يمكن التحايل على نظام الأنواع عند الحاجة. يُقصد بتعريف المتغير إسناد قيمة إلى اسم. ويمكن تعريف المتغير إما بتحديد نوعه صراحةً، وإما بترك الأمر لمُصرِّف Haxe ليستنتج النوع. لذلك فإن تعريفَي المتغير التاليين متكافئان:

```haxe
var explicitVariable:Int = 10; // Explicitly typed
var implicitVariable = 10; // Implicit typed
```

يمكن تحديث المتغير باستخدام العامل `=`:

```haxe
var number = 0; // Initial value
number = 1; // Updated value
```

سيُطلق المُصرِّف خطأً عند محاولة إسناد قيمة يختلف نوعها عن نوع المتغير:

```haxe
var number = 1; // Variable number is of integer type
number = "Hello" // Error trying to assign a string to an integer variable
```

تُسمّى الدالة الموجودة داخل صنف _طريقة_. وقد لا تحتوي الطريقة على أي معامل، أو تحتوي على واحد أو أكثر. ويجب تحديد نوع كل المعاملات صراحةً. وكما هو الحال مع المعاملات، لا يمكن استنتاج نوع الإرجاع للطريقة، بل يجب تحديده. وتُرجع الطرق القيم باستخدام الكلمة المفتاحية `return`:

```haxe
function add(x:Int, y:Int):Int {
  return x + y;
}
```

يتم استدعاء الطريقة بتحديد الصنف واسم الطريقة وتمرير الوسائط:

```haxe
var sum = add(1, 2) // sum = 3
```

يُحدَّد النطاق في Haxe بين المحرفين `{` و `}`.

يدعم Haxe نوعين من التعليقات. تسبق التعليقات أحادية السطر العلامة `//`، أما التعليقات متعددة الأسطر فتوضع بين `/*` و `*/`.
