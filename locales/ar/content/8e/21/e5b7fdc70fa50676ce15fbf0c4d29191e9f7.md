# التحميل الزائد للعوامل

التحميل الزائد للعوامل ميزة في بعض لغات البرمجة، فهو يسمح بإعادة تعريف العوامل القياسية، مثل الجمع (`+`) والطرح (`-`) والضرب (`*`) والقسمة (`/`)، لتعمل مع الأنواع المعرّفة من قبل المستخدم.

وهذا يجعل صياغة الكود أكثر بداهة، إذ يتيح كتابة العمليات على الأنواع المعرّفة من قبل المستخدم بالطريقة نفسها التي تُكتب بها العمليات على الأنواع الأولية.

وفي Cairo، يتحقق التحميل الزائد للعوامل من خلال تنفيذ سمات محددة.

لكل عامل سمة مرتبطة به، ويستلزم تحميل ذلك العامل تقديم تنفيذ لتلك السمة من أجل نوع مخصص.
ومع ذلك، من الضروري استخدام التحميل الزائد للعوامل بحكمة.

فقد تؤدي إساءة استخدامه إلى الالتباس وجعل الكود أصعب في الصيانة، كما هو الحال عندما لا يكون للعامل المُحمَّل أي معنى دلالي.

خذ مثالًا نحتاج فيه إلى دمج اثنتين من `Potions`.

تحتوي `Potions` على حقلَي بيانات: *mana* و *health*.

دمج اثنتين من `Potions` ينبغي أن يجمع حقولهما المقابلة.

```rust
struct Potion {
    health: felt252,
    mana: felt252,
}

impl PotionAdd of Add<Potion> {
    fn add(lhs: Potion, rhs: Potion) -> Potion {
        Potion { health: lhs.health + rhs.health, mana: lhs.mana + rhs.mana }
    }
}

fn main() {
    let health_potion: Potion = Potion { health: 100, mana: 0 };
    let mana_potion: Potion = Potion { health: 0, mana: 100 };
    let super_potion: Potion = health_potion + mana_potion;
    // Both potions were combined with the `+` operator.
    assert(super_potion.health == 100, '');
    assert(super_potion.mana == 100, '');
}
```

في الكود أعلاه، ننفّذ السمة `Add` من أجل النوع `Potion`.

تأخذ الدالة `add` وسيطين: `lhs` و `rhs` (الجانب الأيسر والجانب الأيمن).

يُرجع جسم الدالة نسخة جديدة من `Potion`، وقيم حقولها مزيج من `lhs` و `rhs`.

وكما يوضح المثال، يتطلب تحميل العامل تحديد النوع الملموس الذي يتم تحميله.

السمة العامة المُحمَّلة هي `Add<T>`، ونعرّف تنفيذًا ملموسًا للنوع `Potion` عبر `Add<Potion>`.
