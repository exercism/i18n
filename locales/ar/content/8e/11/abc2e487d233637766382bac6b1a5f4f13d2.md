# مقدمة

تحتوي Swift على مجموعة من العبارات التي يمكن استخدامها لتغيير المسار الطبيعي للتحكم في الحلقات. تُعرف هذه بعبارات نقل التحكم. لقد رأيت `return` من قبل؛ وسيعرّفك هذا المفهوم على عبارات أخرى، منها `continue` و`break` والتسميات.

## Continue

أحيانًا يلزم الانتقال مبكرًا إلى التكرار التالي من الحلقة، دون إكمال بقية العبارات في التكرار الحالي. يمكن استخدام الكلمة المفتاحية `continue` لهذا الغرض. عند تنفيذ `continue`، تنتقل الحلقة إلى الفحص التالي لمعرفة ما إذا كان يمكن تشغيل التكرار التالي، أي شرط `while` في حلقات `while` و`repeat-while`، أو الفحص للتأكد من وجود عنصر آخر في المتتالية في حلقات `for-in`.

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

## Break

تُستخدم `break` للخروج من الحلقة مبكرًا. عند تنفيذ `break`، تخرج الحلقة فورًا ويتابع البرنامج تنفيذه من أول عبارة بعد الحلقة.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

## التسميات

عندما تكون الحلقات متداخلة، قد يرغب المرء أحيانًا في استخدام `break` أو `continue` للخروج من الحلقات الخارجية التي تحتوي على الحلقة المستخدم فيها `break` أو `continue`، أو لإعادة تشغيلها. في حالات كهذه، يمكن استخدام التسميات لتحديد الحلقة المطلوب الخروج منها أو إعادة تشغيلها. يمكن تسمية الحلقة بوضع اسم متبوع بنقطتين رأسيتين قبل الكلمة المفتاحية `while` أو `repeat` أو `for` التي تبدأ الحلقة.

لرؤية تأثير استخدام التسميات بهذه الطريقة، تأمل الحلقة التالية.

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```

## Fallthrough

تُستخدم الكلمة المفتاحية `fallthrough` للانتقال إلى الحالة التالية في جملة `switch`. وهذا يعني تنفيذ الكود داخل الحالة التالية دون فحص شرطها. وبذلك تتصرف جملة `switch` كما في لغات البرمجة الأخرى التي لا تتطلب عبارة `break` للخروج من جملة `switch` بعد مطابقة حالة. يمكنك قراءة المزيد عن `fallthrough` في [كتاب Swift][fallthrough].

```swift
let value = 1
switch value {
case 1:
  print("One")
  fallthrough
case 2:
  print("Two")
}

// prints:
// One
// Two
```

[fallthrough]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#Fallthrough
