# الاختبارات

## Clojure CLI

تأتي تمارين Clojure على Exercism مصحوبة بملف `deps.edn` يتضمّن اسمًا مستعارًا `:test` لاستدعاء [cognitect-labs test-runner](https://github.com/cognitect-labs/test-runner):

``` bash
$ clj -X:test
```

## Leiningen

يمكنك أيضًا استخدام Leiningen لتشغيل اختبار التمرين بتنفيذ الأمر التالي من مجلد التمرين:

```bash
lein test
```

## REPL

لتشغيل اختبار التمرين باستخدام REPL، نفّذ الأمر التالي من مجلد التمرين:

```bash
$ clj
```

أو

```bash
$ lein repl
```

ثم استدعِ `require` على فضاء الأسماء الخاص باختبار التمرين وفضاء أسماء اختبار Clojure):

```clojure
;; replace <exercise> with the exercise's name
=> (require '<exercise>-test)
```

ثم استدعِ `run-tests` على `<exercise>-test`:

```clojure
;; replace <exercise> with the exercise's name
=> (clojure.test/run-tests '<exercise>-test)
```
