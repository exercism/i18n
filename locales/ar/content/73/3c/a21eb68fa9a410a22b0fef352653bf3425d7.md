# الاختبارات

يمكنك استخدام المحرر على الإنترنت في موقع Exercism لحل التمارين.
أو نزّل التمارين إلى حاسوبك، وحلّها محليًا ثم أرسلها إلى Exercism.
يتناول باقي هذا المستند العمل محليًا.

## واجهة سطر أوامر Exercism

ستحتاج إلى أداة سطر الأوامر `exercism` لتنزيل التمارين وإرسالها.
راجع [توثيق واجهة سطر أوامر exercism][exercism-cli] للحصول على تعليمات تنزيلها وتهيئتها.

لتنزيل تمرين، نفّذ ما يلي:

```bash
exercism download --track 8th --exercise hello-world
```

ثم انتقل إلى مجلد التمرين:

```bash
cd /path/to/your/exercism_workspace/8th/hello-world
```

أو إذا كنت تستخدم Windows:

```cmd
cd \path\to\your\exercism_workspace\8th\hello-world
```

لاحظ أنه يمكنك معرفة مساحة عمل exercism لديك باستخدام الأمر `exercism configure`.

## الاختبار محليًا

لتشغيل اختبارات تمرين ما، يجب أن تكون في مجلد التمرين الصحيح.
ثم شغّل الاختبارات بهذا الأمر:

```bash
8th -f test.8th
```

## الاختبارات المتخطّاة

حلّ التمرين يعني اجتياز جميع اختباراته.
بشكل افتراضي، يُنفَّذ اختبار واحد فقط (الأول) عند تشغيل الاختبارات.
وهذا مقصود، لأنه يتيح لك التركيز على اجتياز ذلك الاختبار الواحد فقط.
وبعد أن يجتازه، يمكنك تفعيل الاختبار التالي بنقل السطر `SKIP-REST-OF-TESTS` إلى أسفله.

### تجاوز التخطّي

لتشغيل جميع الاختبارات، بما فيها تلك التي تأتي بعد الكلمة `SKIP-REST-OF-TESTS`، يمكنك ضبط متغير بيئة باسم `RUN_ALL_TESTS` على القيمة `true`. 
ومن طرق ضبطه لمدة تشغيل الاختبارات فقط (على macOS وLinux):

```bash
RUN_ALL_TESTS=true 8th -f test.8th
```

## أرسل حلّك

لرفع حلّك إلى موقع Exercism باستخدام أداة exercism:

```bash
exercism submit
```

لاحظ أنه يمكنك رفع الكود الخاص بك حتى إن لم يجتز جميع الاختبارات.
وهذا مفيد إذا كنت متعثرًا وتحتاج إلى مساعدة من مرشد.
