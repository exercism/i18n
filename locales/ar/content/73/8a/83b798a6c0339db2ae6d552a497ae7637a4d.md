# مقدمة

هناك نوعان أساسيان من الحلقات:

1. التكرار حتى يتحقق شرط.
2. التكرار على عناصر مجموعة.

وكلاهما ممكن في R، وإن كان الأول أكثر شيوعًا على الأرجح.

## `while` و `repeat`

في المسائل المفتوحة التي لا يُعرف فيها عدد مرات التكرار مسبقًا، توفّر R حلقة `while` ذات شرط، وحلقة `repeat` بدون شرط (أي ما يعادل `while (TRUE)`).

الصيغة الأساسية بسيطة إلى حد كبير:

```R
while (condition) {
  do_something()
}
```

في هذه الحالة، يظل البرنامج يدور في الحلقة حتى يصبح `condition` غير `TRUE`.

هناك أسلوبان للخروج من الحلقة مبكرًا:

- يؤدي `break` إلى الخروج من الحلقة، ويستمر التنفيذ من السطر التالي بعد القوس المعقوف الختامي `}` للحلقة.
- يوقف `return(x)` تنفيذ الدالة الحالية، ويمرّر القيمة المُرجَعة `x` إلى الجهة التي استدعته.

مع توفّر هذه الخيارات، قد يكون من المناسب أحيانًا إنشاء حلقة "لا نهائية" باستخدام `repeat { ... }`، ثم الاعتماد على إيجاد شرط للتوقف داخل جسم الحلقة لتحفيز `break` أو `return`.

هذه الصيغ الثلاث متكافئة، وتنتهي جميعها عند `x == 0.4444...`

```R
x <- 12
while (x > 1) {
  x <- x / 3
}

x <- 12
while (TRUE) {
  x <- x/3
  if (x <= 1) break
}

x <- 12
# no boolean clause 
repeat { 
  x <- x/3
  if (x <= 1) break
}
```

## التكرار على متجه

غالبًا ما يكون هذا غير ضروري في R.
وكما نوقش في مفاهيم أخرى، فإن العديد من الدوال تعمل على المتجهات كاملة.

ومع ذلك، لا يمكن أحيانًا تجنّب الحلقات الصريحة.
وهذا صحيح بشكل خاص عندما:

- يكون لجسم الحلقة آثار جانبية مثل الطباعة أو إدخال/إخراج الملفات.
- يستمر التكرار حتى الوصول إلى معيار ما، بعد عدد غير متوقع من التكرارات.

يجب وضع شرط الحلقة بين الأقواس الهلالَين.
وكما في أجسام الدوال، فإن الأقواس المعقوفة اختيارية (لكنها تُضمَّن غالبًا) في أجسام الحلقات ذات السطر الواحد.

```R
words <- c("This", "is", "a", "loop")
for (w in words) { print(w) } # the braces are optional here
#> [1] "This"
#> [1] "is"
#> [1] "a"
#> [1] "loop"
```

إذا لم يستوفِ التكرار الحالي شرطًا ما، أمكن الانتقال فورًا إلى التكرار التالي باستخدام `next`:

```R
for (n in 1:10) {
    if (is_useless(n)) next
     
    # we decided this iteration could be useful
    do_something_slow(n)
}
```

إذا احتجت إلى الفهرس الرقمي، فاستخدم `seq_along()`.

```R
v <- LETTERS[1:3]
v
#> [1] "A" "B" "C"

for (i in seq_along(v)) { print(sprintf("%s%i", v[i], i)) }
#> [1] "A1"
#> [1] "B2"
#> [1] "C3"
```

لا يُوصى باستخدام `i in 1:length(v)`، لأنه قد يسبب مشكلات عندما يكون `length(v)` صفرًا.
فالنطاق `1:0` مكافئ لـ `c(1, 0)`، لذلك سيُنفَّذ جسم الحلقة وعلى الأرجح سيفشل.
وقد صُمّمت الدالة `seq_along()` للتعامل مع هذه الحالة بشكل صحيح.
