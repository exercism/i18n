# نبذة

تتصرّف [تعبيرات `switch`][switch-expressions] بطريقة مشابهة لـ[عبارات `switch`][switch-statements] التي تناولناها في [concept:csharp/switch-statements](). وهي تدعم نوعًا من جداول القرارات التي تربط شروط الإدخال بإجراءات أو قيم.

في قلب تعبير `switch` تكمن _مطابقة الأنماط_. في تمرين البرمجة طابقنا قيمًا مع أنماط `const`. وفي هذه الحالة فإن مدخلات `switch` هي _تعبير مدى_ يُطابَق مع قيم `const` ومع القيم التي تستخدمها _حُرّاس الحالات_.

تُقيَّم الحالات (وتُعرف أيضًا باسم _أذرع `switch`_) بترتيب ورودها في النص، وبمجرد العثور على تطابق تتوقف العملية وتُرجَع القيمة المرتبطة.

الحالة `_` التي تأتي أخيرًا في القائمة مفيدة لضمان أن المطابقة شاملة ولتجنّب أخطاء وقت التشغيل المحتملة.

```csharp
double xx = 42d;

string interesting = xx switch
{
    0 => "I suppose zero is interesting",
    3.14 when DateTime.Now.Day == 14 && DateTime.Now.Month == 3 => "Mmm pie!",
    3.14 => "π",
    42 => "a bit of a cliché",
    1729 => "only if you are a pure mathematician",
    _ => "not interesting"
};

// => interesting == "a bit of a cliché"
```

يُختار «ذراع» من أذرع `switch` عندما يطابق النمط متغير المدى وتكون نتيجة أي حارس حالة صحيحة.

تدعم تعبيرات `switch` أيضًا [أنماط الأنواع][pattern-matching] والمطابقة التعاودية.
