# مقدمة

## عوامل الحساب

توفّر JavaScript 6 عوامل مختلفة لتنفيذ العمليات الحسابية الأساسية على الأعداد.

- `+`: يُستخدم عامل الجمع لإيجاد مجموع الأعداد.
- `-`: يُستخدم عامل الطرح لإيجاد الفرق بين عددين
- `*`: يُستخدم عامل الضرب لإيجاد حاصل ضرب عددين.
- `/`: يُستخدم عامل القسمة لقسمة عددين.

```javascript
2 - 1.5; //=> 0.5
19 / 2; //=> 9.5
```

- `%`: يُستخدم عامل الباقي لإيجاد باقي عملية القسمة.

  ```javascript
  40 % 4; // => 0
  -11 % 4; // => -3
  ```

- `**`: يُستخدم عامل الأس لرفع عدد إلى قوة.

  ```javascript
  4 ** 3; // => 64
  4 ** 1 / 2; // => 2
  ```

## ترتيب العمليات

عند استخدام عدة عوامل في سطر واحد، تتبع JavaScript ترتيبًا للأسبقية كما هو موضح في [جدول الأسبقية هذا][mdn-operator-precedence].
وبتبسيط ذلك في سياقنا، تستخدم JavaScript قاعدة PEDMAS (الأقواس الهلالية، الأسس، القسمة/الضرب، الجمع/الطرح) التي تعلمناها في حصص الرياضيات في المرحلة الابتدائية.

<!-- prettier-ignore-start -->
```javascript
const result = 3 ** 3 + 9 * 4 / (3 - 1);
// => 3 ** 3 + 9 * 4/2
// => 27 + 9 * 4/2
// => 27 + 18
// => 45
```
<!-- prettier-ignore-end -->

## عوامل الإسناد المختصرة

عوامل الإسناد المختصرة أسلوب أقصر لكتابة كود يجري عمليات حسابية على متغير، ويسند القيمة الجديدة إلى المتغير نفسه.
على سبيل المثال، لنأخذ متغيرين هما `x` و `y`.
حينها، `x += y` تكافئ `x = x + y`.
وغالبًا ما يُستخدم هذا مع عدد بدلًا من المتغير `y`.
ويمكن تنفيذ العمليات الخمس الأخرى بالأسلوب نفسه.

```javascript
let x = 5;
x += 25; // x is now 30

let y = 31;
y %= 3; // y is now 1
```
