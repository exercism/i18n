# التعليمات

أنت مشغّل التلغراف اللاسلكي على متن سفينة شحن. تصل الإشارة عبر خط مشوّش: آلات السفينة، وتشويش الطقس، وثرثرة أجنبية عابرة، متشابكة مع شفرة مورس التي تنتظرها. وللالتقاط الرسالة تمرّر السلك عبر جهاز *شريط* لا يُبقي إلا رموز مورس الصالحة (`.` و`-` والمسافة التي تفصل بين الحروف).

مهمتك أن تبني الشريط كتيار إدخال مخصّص في Factor.

## 1. عرّف الشريط

عرّف tuple باسم `tape` يمتد من `disposable` ويحوي خانة واحدة، `wire`، لتيار الإدخال الأساسي.

```factor
TUPLE: tape < disposable wire ;
```

ثم اكتب البانية `<tape> ( wire -- tape )`. استخدم `new-disposable` (وليس `new`) لكي يسجّل إطار عمل المُدمِّر الشريط، وخزّن التيار الأساسي في الخانة `wire`.

## 2. انضم إلى mixin تيار الإدخال

أعلن أن `tape` هو `input-stream`:

```factor
INSTANCE: tape input-stream
```

وبذلك تُوجَّه المُركِّبات الافتراضية في البروتوكول إلى صنفك.

## 3. اقرأ رمز مورس واحدًا

نفّذ `M: tape stream-read1 ( tape -- elt/f )`. اقرأ البايتات من السلك الأساسي حتى تصادف أحد `CHAR: .` أو `CHAR: -` أو `CHAR: \s` (مسافة). أرجِع ذلك البايت. وإذا أرجع السلك `f` (نهاية التيار)، فأرجِع `f` أيضًا، فقد انتهى الشريط.

```factor
"x.y -ab cz" <string-reader> <tape>
[ stream-read1 ] [ stream-read1 ] [ stream-read1 ] tri
! => CHAR: . CHAR: - CHAR: \s
```

## 4. فوّض نوع العنصر

نفّذ `M: tape stream-element-type ( tape -- type )` بالتفويض إلى السلك: فالشريط لا يغيّر نوع العناصر المقروءة.

## 5. نظّف الموارد

نفّذ `M: tape dispose* ( tape -- )`. يستدعي إطار العمل طريقتك مرة واحدة بالضبط لكل استدعاء لـ `dispose`؛ كل ما عليك هو التخلّص من السلك الأساسي.

وبعد اكتمال هذه القطع الخمس، يعمل الشريط كتيار إدخال عادي: `with-input-stream` و`stream-read` وباقي كلمات البروتوكول كلها تُوجَّه إلى طرقك تلقائيًا.
