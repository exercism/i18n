# ملحق التعليمات

## السجلات

| السجل | الاستخدام | النوع | الوصف |
| -------- | --------- | ------- | -------------------------- |
| `$a0`    | مُدخل     | عدد صحيح | فهرس العدد الأولي |
| `$v0`    | مُخرج     | عدد صحيح | قيمة العدد الأولي ذي الترتيب n |
| `$t0-9`  | مؤقت      | أي نوع | يُستخدم للتخزين المؤقت |
