# تشغيل اختبارات Ceylon

قبل تشغيل الاختبارات، يجب ترجمة الكود الخاص بك عبر الأمر [`ceylon compile`](https://ceylon-lang.org/documentation/current/reference/tool/ceylon/subcommands/ceylon-compile.html).

نُشغّل الاختبارات بالأمر [`ceylon test`](https://ceylon-lang.org/documentation/reference/tool/ceylon/subcommands/ceylon-test.html).

يتوقّع الأمر `ceylon test` اسم وحدة ليشغّل عليها الاختبارات.
في مسار Ceylon، يتكوّن كل تمرين من وحدة واحدة فقط.

لذلك يمكنك تشغيل الاختبارات بالأمر التالي:

```bash
ceylon compile && ceylon test $(basename source/*)
```
