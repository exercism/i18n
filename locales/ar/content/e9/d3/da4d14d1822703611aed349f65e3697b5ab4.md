# مقدمة

للاطلاع على الأساسيات المتعلقة بوسائط الدالة، راجع [مفهوم الدالة][function concept].

## أسماء المعاملات

[أسماء المعاملات][parameters]، مثل أسماء المتغيرات، يجب أن تبدأ بحرف أو شرطة سفلية، ويمكن أن تحتوي على حروف أو شرطات سفلية أو أعداد.
يجب ألا تحتوي أسماء المعاملات على مسافات أو علامات ترقيم.


## الوسائط الموضعية

الوسائط الموضعية هي القيم التي تُمرَّر إلى دالة بالترتيب نفسه الذي تأتي به المعاملات المرتبطة بها.
ويمكن تمريرها اختياريًا باستخدام اسم المعامل الخاص بها:


```python
def concat(greeting, name):
    return f"{greeting}{name}"
 
# Passing data to the function by position.
print(concat("Hello, ", "Judy"))
#->  Hello, Judy

# Passing data to the function using the parameter name.
print(concat(name="Sally", greeting="Hello, "))
#-> Hello, Sally
```

النداء الأول على `concat` يمرّر الوسائط حسب الموضع.
أما النداء الثاني على `concat` فيمرّر الوسائط _بالاسم_، ما يسمح بتغيير مواضعها.

لاحظ أن الوسائط الموضعية لا يمكن أن تأتي بعد الوسائط الممرَّرة بالاسم (_وتُسمّى أيضًا [الوسائط المفتاحية][keyword-arguments]. **ولا** ينبغي الخلط بينها وبين المعاملات الموضعية المتغيّرة أو [**kwargs][kwargs]**).

هذه المجموعة من الوسائط:

```python
>>> print(concat(greeting="Hello, ", "Zed"))
```

ستؤدي إلى هذا الخطأ:

```
SyntaxError: positional argument follows keyword argument
```

## قيم الوسائط الافتراضية

يمكن توفير [القيم الافتراضية][default arguments] لواحد أو أكثر من الوسائط في قائمة المعاملات.
وهذا يسمح باستدعاء الدالة بعدد _أقل_ من الوسائط عند الحاجة.
ويمكن تجاوز القيم الافتراضية باستدعاء الدالة بوسائط جديدة تحلّ محلّ القيم الافتراضية:


```python
# Note the default arguments for both greeting and name.
def concat(greeting="Hello, ", name="you"):
    return f"{greeting}{name}"
 
# Function call overriding the defaults
print(concat(name="Jerry", greeting="Hello, "))
#-> Hello, Jerry

# Function call without arguments resulting in the defaults being used.
print(concat())
#-> Hello, you
```

## الوسائط المفتاحية

تستخدم الوسائط المفتاحية اسم المعامل عند تمرير الوسائط إلى دالة.
ويمكن الإشارة إليها اختياريًا حسب الموضع:


```python
# Note the default arguments for both greeting and name.
def concat(greeting="Hello, ", name="you"):
    return f"{greeting}{name}"

# Function call using parameter names as argument keywords.
print(concat(name="Jerry", greeting="Hello, "))
#-> Hello, Jerry

# Function call with positional data as arguments.
print(concat("Hello, ", "Isaac"))
#-> Hello, Isaac
```
