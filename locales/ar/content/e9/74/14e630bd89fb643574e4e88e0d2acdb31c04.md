# الاختبارات

ستنزّل Exercism ملف اختبار فقط. وسيلزمك أن تنشئ يدويًا ملف الترويسة وملف المصدر المرتبطين بالتمرين. وستحتاج إلى توليد ملف مشروع Xcode يضم ملف الاختبار وملف الترويسة (`.h`) وملف المصدر (`.m`). أو يمكنك استخدام مشغّل اختبارات مشروح أدناه.

## إنشاء المشروع في Xcode

* شغّل Xcode وأنشئ مشروعًا جديدًا.
* اختر OS X > Application ثم Command Line Tool.
* انقر على Next، ويُستحسن أن تسمّي المشروع `ExerciseName`.
* انقر على Next واحفظ المشروع في مجلد التمرين الخاص بـ Exercism.
* بعد إنشاء المشروع، انقر على Editor > Add Target.
* اختر OS X > Test ثم اختر OS X Unit Testing Bundle.
* سمِّ الهدف ExerciseName Tests.
* في اللوحة اليسرى (المعروفة باسم navigator)، افتح Project navigator ووسّع مجلد ExerciseName Tests، ثم افتح الملف `ExerciseName_Tests.m`.
* استبدل محتواه بملف الاختبار الذي حصلت عليه من Exercism.
* في ذلك الملف، استبدل كل حالات "test_suite" بـ "ExerciseName_Tests".
* انتقل إلى مكتبة File Template في اللوحة اليمنى (أو استخدم CTRL+OPTION+CMD+1)، واسحب قالب Cocoa Class إلى مجلد `ExerciseName_Tests` في Project navigator.
* سمِّه `ExerciseName` واختر ExerciseName Tests ليكون هدفه.
* سيكون لديك الآن ملفان جديدان في مجلد `ExerciseName_Tests`: `ExerciseName.h` و`ExerciseName.m`.
* انقر على مشروعك في Project navigator.
* انقر على ExerciseName Tests في قائمة الأهداف.
* اختر Build Phases في شريط تنقّل المحرّر.
* تأكد من وجود ملفَّي `.m` في قائمة compile sources.
* استخدم CMD+5 للانتقال إلى Test navigator.
* انقر بزر الفأرة الأيمن على الحزمة المسماة ExerciseName Tests، ثم انقر على Enable ExerciseName_Tests.
* شغّل الاختبارات بالنقر على المثلث المتجه إلى اليمين الذي يظهر عند تمرير المؤشر فوق الحزمة في Test navigator، أو استخدم CMD+U.

ستُشغَّل الاختبارات عبر Xcode.

__ملاحظة:__ إذا ظهرت لك رسالة الخطأ "No visible `@interface` for ExerciseName declares the selector ExerciseSelector," فأنت قد اتبعت الخطوات بشكل صحيح، لكنك لم تكتب شيئًا في ملف الترويسة أو ملف التنفيذ. بعد أن تُعلن عن الطريقة في ملف `.h` وتعرّفها في ملف `.m`، سيعرض لك اختبارك رسائل خطأ أكثر إفادة تأخذ بيدك نحو إكمال التمرين. اقرأ هذا [التمهيد إلى أصناف Objective-C](http://blog.teamtreehouse.com/beginners-guide-objective-c-classes-objects) لمزيد من المعلومات المتعمقة.

## مشغّل اختبارات

بديل عن توليد ملف المشروع يدويًا هو استخدام مشغّل اختبارات مكتوب بلغة Ruby، وهو [`objc`](https://rubygems.org/gems/objc/)، ينشئ لك ملف مشروع يضم ملف الاختبار وملف الترويسة وملف المصدر.

```bash
$ gem install objc
```

شغّل الاختبارات بالأمر:

```bash
$ objc -x ExerciseName
```

(لاحظ المفتاح `-x`/`--xcodebuild`، الذي يحدد استخدام `xcodebuild` بدلًا من `xctool`. فالأخير لا يعمل مع أحدث إصدارات Xcode.)

تستخدم أداة `objc` اسم التمرين للعثور على ملف الاختبار `ExerciseNameTest.m`، وملف الترويسة `ExerciseName.h`، وملف المصدر `ExerciseName.m`. تُدرَج الملفات في مشروع Xcode مؤقت، ثم يُستخدم `xcodebuild` لتشغيل اختبارات المشروع.

ومع أن أداة `objc` تُغنيك عن تشغيل Xcode لإكمال هذه التمارين، فإن رسائل الخطأ والتغذية الراجعة عبر سطر الأوامر ليست بذلك الوضوح الذي تجده في واجهة Xcode.
