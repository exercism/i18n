# نبذة

- النوع [الثنائي][binary] هو حالة خاصة من النوع [سلسلة البتات][bitstring].
- تتكوّن القيم الثنائية من [البايتات][wiki-byte].
  - يتكوّن البايت من 8 بتات.
  - يمكن للبايت أن يمثّل أعدادًا تتراوح من `0` إلى `255`
  - القيم العددية [الست عشرية][wiki-hexadecimal] شائعة عند التعامل مع البايتات: من `0x00` إلى `0xFF`.
- تُعرَّف القيم الثنائية الحرفية باستخدام [الصيغة الخاصة `<<>>`][special-form].
  - إذا استخدمت عددًا صحيحًا أكبر من `255` لبايت واحد، فسيُستخدم آخر 8 بتات فقط، إلا إذا حدّدت [الوحدة و/أو الحجم المراد استخدامهما][bin-size] باستخدام العامل [`::`][type-operator].
- يمكن استخدام [`<>/2`][bin-concat] لدمج سلاسل البتات والقيم الثنائية والسلاسل النصية.

```elixir
<<255>> == <<0xFF>>
# Overflowing bits are truncated
<<256>> == <<0>>
<<256::size(16)>> == <<1, 0>>

<<"Hello">> == <<72, 101, 108, 108, 111>>
```

الـ _البايت الفارغ_ اسم آخر لـ `<<0>>`.

## السلاسل النصية بيانات ثنائية مُرمَّزة

- السلاسل النصية بيانات ثنائية مرمّزة بتنسيق [UTF-8][wiki-utf8].
  - وهي تُرمَّز في مقاطع من 8 بتات (بايت واحد)، وتستخدم حتى 4 بايتات لتمثيل أكثر من 255 حرفًا.
  - قد لا يتطابق [طول السلسلة النصية][string-length] مع [حجمها بالبايتات][byte-size].

```elixir
# This string has a string length of 5, but is made up of 7 bytes
string = "cześć"
String.length(string) != byte_size(string)

# Even emoji strings are encoded binaries
"👍" == <<240, 159, 145, 141>>
```

## مطابقة الأنماط على البيانات الثنائية

- يمكن [مطابقة القيم الثنائية كنمط كاملةً أو باستخدام الصيغة الخاصة][special-form] لمطابقة جزء واحد فقط.
  - الجزء الأخير فقط في مطابقة النمط يمكن أن يكون متغيّر الحجم.

```elixir
# Ignore the first 8 bytes, bind the remaining variable sized binary to `body`
<<_::binary-size(8), body::binary>>
```

يمكن فعل ذلك أيضًا مع السلاسل النصية:

```elixir
# bind the first 5 bytes to `name`,
# match the string literal " the ",
# bind remaining bytes to `species`
<<name::binary-size(5), " the ", species::binary>> = <<"Frank the Walrus">>
{name, species}
# => {"Frank", "Walrus"}
```
