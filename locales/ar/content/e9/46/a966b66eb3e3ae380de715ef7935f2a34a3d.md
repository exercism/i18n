# نبذة

يمكن توسيع مفهوم `try .. rescue` الأساسي ليدعم جملتي `else` و`after`:

- كتلة `else`:
  - حيث تجري مطابقة النمط مع النتيجة الناجحة الصادرة عن كتلة `try`.
- كتلة `after`:
  - حيث تُستدعى الدوال سواء نجحت كتلة `try` أو جرى إنقاذها، طالما أن البرنامج قيد التشغيل.
  - لا تُرجع نتيجة كتلة `after` إلى نطاق الاستدعاء.

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```
