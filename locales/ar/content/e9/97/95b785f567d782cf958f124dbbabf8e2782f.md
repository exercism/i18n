# الاختبارات

لتشغيل الاختبارات المرفقة، ستحتاج إلى مكتبة Minitest. افتح نافذة الطرفية ونفّذ الأمر التالي لتثبيت minitest:

```
gem install minitest
```


شغّل الاختبارات من مجلد التمرين باستخدام الأمر التالي:

```
ruby <snake-case-exercise>_test.rb
```

يرجى استبدال `<snake-case-exercise>` باسم تمرينك مكتوبًا بصيغة snake_case.

## المخرجات الملوّنة

يمكنك استخدام `require 'minitest/pride'` أو تنفيذ الأمر التالي للحصول على مخرجات ملوّنة:

```
ruby -r minitest/pride <snake-case-exercise>_test.rb
```
