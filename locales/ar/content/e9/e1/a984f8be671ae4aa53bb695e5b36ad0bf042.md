# مقدمة

## الأعضاء ذات الجسم التعبيري

يمكن للعديد من أنواع أعضاء struct والصنف (باستثناء الحقول بشكل أساسي) استخدام صيغة العضو ذي الجسم التعبيري. غالبًا ما ينتج تعريف العضو باستخدام تعبير كودًا أكثر إيجازًا وأسهل قراءة من الكتل أو العبارات التقليدية.

الطرق والخصائص للقراءة فقط من بين الأعضاء التي يمكن تعريفها بأجسام تعبيرية.

```csharp
public int Times3(int input) => input * 3;

public int Interesting => 1729;
```

## تعبيرات switch

يمكن لتعبير switch مطابقة قيمة مع حالة واحدة في مجموعة من الأنماط وإرجاع القيمة المرتبطة أو اتخاذ الإجراء المرتبط. يُشار إلى الارتباط بالرمز `=>`. بالإضافة إلى ذلك، يمكن أن يحتوي كل نمط على حارس حالة اختياري يُقدَّم بالكلمة المفتاحية `when`. يجب أن يُقيَّم تعبير حارس الحالة إلى صحيح حتى يتم اختيار ذلك "الذراع" من switch. تُقيَّم الحالات (المعروفة أيضًا بـ _أذرع switch_) بترتيب النص، وتُقطع العملية وتُرجَع القيمة المرتبطة بمجرد العثور على تطابق.

```csharp
double xx = 42d;

string interesting = xx switch
{
    0 => "I suppose zero is interesting",
    3.14 when DateTime.Now.Day == 14 && DateTime.Now.Month == 3 => "Mmm pie!",
    3.14 => "π",
    42 => "a bit of a cliché",
    1729 => "only if you are a pure mathematician",
    _ => "not interesting"
};

// => interesting == "a bit of a cliché"
```

## العوامل الثلاثية الشرطية

تسمح العوامل الثلاثية بتعريف الشروط باستخدام تعبيرات بدلًا من كتل العبارات. وهذا يعكس أساليب البرمجة الوظيفية، ويمكنه غالبًا جعل الكود أكثر تعبيرًا وأقل عرضة للأخطاء.

يجمع العامل الثلاثي 3 تعبيرات: شرطًا يتبعه تعبير يُقيَّم ويُرجَع إذا كان الشرط صحيحًا (جزء `if`، الذي يُقدَّم بـ `?`) وتعبيرًا يُقيَّم ويُرجَع إذا كان الشرط خطأً (جزء `else`، الذي يُقدَّم بـ `:`).

```csharp
int a = 3, b = 4;
int max = a > b ? a : b;
// => 4
```

## تعبيرات throw

تُعد تعبيرات `throw` بديلًا عن عبارات `throw`، ويمكنها على وجه الخصوص أن تضيف إلى قوة العوامل الثلاثية والتعبيرات المركبة الأخرى.

```csharp
string trimmed = str == null ? throw new ArgumentException() : str.Trim();
```
