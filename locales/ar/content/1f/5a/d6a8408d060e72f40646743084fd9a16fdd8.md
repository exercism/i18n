# القيمة العدمية

القيمة العدمية نوع قيمي بدائي له قيمة واحدة فقط: `null`.
وكثيرًا ما تُستخدم القيمة العدمية للتعبير عن اللاشيء.
وتُعدّ قيمة كاذبة، لكنها تختلف عن `false` وعن بقية القيم الكاذبة.

```php
<?php

is_null(null); // => true
isset(null); // => false

null == true; // => false
null === true; // => false

null == false; // => true
null === false; // => false
```

## التعامل مع القيم العدمية

في PHP، قد تكون القيم العدمية سببًا شائعًا للأخطاء، إذ كثيرًا ما تُرجع بدلًا من حالة خطأ أو لتمثيل اللاشيء.
وكثيرًا ما يتطلب منع حدوث الأخطاء التحقق من القيمة العدمية للتأكد من أنها ليست `null` قبل التعامل معها.

وقد يكون تكرار التحقق من القيمة العدمية عرضةً للخطأ، لذلك توفّر PHP عاملين للتعامل مع القيم العدمية: عامل الوصول الآمن من `null` `?->`، وعامل الدمج مع `null` `??`.
