# نبذة

`while` و `until` (في [`kernel`][kernel]) مُركّبان حلقيان يعتمدان على `quotation`، ويُستخدمان في الحالة التي لا تعرف فيها عدد التكرارات مسبقًا:

```
while ( pred: ( -- ? ) body: ( -- ) -- )
until ( pred: ( -- ? ) body: ( -- ) -- )
```

يواصل `while` العمل طالما أن `pred` يترك قيمة تُعتبر صحيحة، بينما يواصل `until` العمل طالما أن `pred` يترك `f`. ويتوقف كلٌّ منهما ويُرجع بمجرد أن ينقلب شرطه.

```factor
USING: kernel math ;

! Halve down to 1
16 [ dup 1 > ] [ 2 / ] while .   ! => 1

! Double up to 100
1 [ dup 100 >= ] [ 2 * ] until .   ! => 128
```

عندما لا تكفي قيمة واحدة تتدفق على المكدّس لتمثيل الحالة، كأن تكون لديك قائمة متبقية وإجمالي جارٍ وعدّاد في الوقت نفسه، فإن أنظف نمط هو استخدام *متغيرات محلية* مُسمّاة من أجل الوضوح. ستُقدَّم المتغيرات المحلية بمزيد من التفصيل لاحقًا في المنهج؛ ويكفي هنا أن تعرف أن `:: word ( a b -- c )` تُعلن المدخلات كمتغيرات محلية مُسمّاة، وأن `:> name!` تضيف متغيرًا محليًا قابلًا للتعديل يمكن للجسم تحديثه بـ `value name!`.

```factor
USING: kernel locals math sequences ;

! Sum a sequence by hand
:: sum-by-hand ( seq -- total )
    seq :> rest!
    0 :> running!
    [ rest length 0 > ] [
        rest unclip [ rest! ] dip
        running + running!
    ] while
    running ;
```
