# الموارد

## إنشاء أول وحدة CoffeeScript لديك

لإنشاء وحدة يمكن تحميلها عبر `Bob = require './bob'`، ضع هذا الكود في `bob.coffee`:

```coffeescript
class Bob

module.exports = Bob
```

يمكنك العثور على مزيد من المعلومات حول الوحدات في [توثيق Node](http://nodejs.org/api/modules.html#modules_module_exports).

## Visual Studio على Windows

إذا كانت لديك نسخة مدفوعة من Visual Studio، فيمكنك تنزيل solution جاهز مسبقًا للعمل مع CoffeeScript وبقية اللغات التي يدعمها Visual Studio.

![Solution Explorer](https://raw.githubusercontent.com/exercism/coffeescript/main/docs/img/SolutionExplorer.png)

1. نزّل [قالب Exercism.io لـ Visual Studio](https://github.com/rprouse/Exercism.VisualStudio) من GitHub بالنقر على زر Download Zip في الصفحة.
2. فك ضغط القالب في مجلد التمارين لديك، على سبيل المثال `C:\src\exercises`
2. ثبّت [Exercism CLI](http://exercism.io/cli)
3. افتح موجّه أوامر في مجلد التمارين لديك
4. أضف مفتاح API الخاص بك إلى exercism `exercism configure --key=YOUR_API_KEY`
5. اضبط مجلد المصدر في exercism `exercism configure --dir=C:\src\exercises`
6. [اجلب أول تمرين لديك](http://exercism.io/languages/coffeescript) `exercism fetch coffeescript`
7. افتح solution الخاص بـ Exercism في Visual Studio
8. وسّع مشروع Exercism.coffeescript
9. انقر على **Show All Files** في Solution Explorer (انظر أدناه)
10. سيظهر التمرين الذي جلبته للتو باهتًا. انقر بزر الفأرة الأيمن على المجلد ثم اختر **Include In Project**
11. ابدأ البرمجة...

![Add files](https://raw.githubusercontent.com/exercism/coffeescript/main/docs/img/AddFiles.png)

للعمل مع CoffeeScript في Visual Studio، عليك تثبيت إضافة [Web Essentials](http://vswebessentials.com/). وستجعل هذه الإضافة العمل مع JavaScript أسهل بكثير أيضًا.

يمكنك تشغيل اختبارات الوحدة من سطر أوامر node.js باستخدام الملف الدفعي الموجود في المشروع.

```bash
C:\Src\exercises\coffeescript> test example\bob_test.spec.coffee
.................

Finished in 0.02 seconds
17 tests, 17 assertions, 0 failures, 0 skipped
```

إذا لم تظهر أي مخرجات عند تشغيل الاختبارات، فالأرجح أنك لست في موجّه أوامر Node.js.
