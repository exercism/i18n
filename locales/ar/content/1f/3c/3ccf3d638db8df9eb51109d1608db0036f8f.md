# مقدمة

في Python، يُستخدم `None` كثيرًا لتمثيل غياب القيمة، فهو عنصر نائب لتعريف متغير أو كائن أو وسيط `null` (فارغ).

إذا سمعت من قبل عن نوع `NULL` أو `nil` في لغة برمجة أخرى أو استخدمته، فسيكون استخدام `None` في Python مألوفًا لك.
يساعدك `None` على تعريف متغيرات أو وسائط دوال لم تحدد لها قيمًا بعد.
ويمكن لاحقًا إعادة إسنادها إلى قيم محددة عند الحاجة:


```python
a = None
print(a)
#=> None

type(a)
#=> <class 'NoneType'>

# Adding a default argument with `None`
def add_to_todos(new_task, todo_list=None):
    if todo_list is None:
        todo_list = []  
    todo_list.append(new_task)
     
  return todo_list
```

تُقيَّم `None` إلى `False` عند استخدامها في فحص شرطي، لذا فهي مفيدة للتحقق من «وجود» قيمة أو «غيابها»، أيًّا كانت تلك القيمة، وهو نمط يُستخدم كثيرًا عندما قد تُرجع دالة أو عملية ما `error` أو `object` أو رسالة.

```python
a = None
if a: #<-- a will be evaluated to False when it is used in a conditional check.
    print("This will not be printed")
```
