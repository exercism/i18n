# مقدمة

## القواميس

القاموس هو مجموعة من العناصر، حيث يتكوّن كل عنصر من مفتاح وقيمة، بحيث إذا مُرِّر مفتاح إلى إحدى طرق القاموس فإنها تُرجع القيمة المرتبطة به. وله الدور نفسه الذي تؤديه الخرائط أو المصفوفات الترابطية في لغات أخرى.

يمكن إنشاء قاموس كما يلي:

```csharp
new Dictionary<int, string>();
// Empty dictionary
```

أو

```csharp
new Dictionary<int, string>
{
    [1] = "One",
    [2] = "Two"
};

// Or

new Dictionary<int, string>
{
    {1, "One"},
    {2, "Two"}
};
// 1 => "One", 2 => "Two"
```

لاحظ أن نوعَي المفتاح والقيمة جزءان من تعريف القاموس.

بعد إنشائه، يمكن إضافة المدخلات إلى القاموس أو حذفها منه باستخدام طريقتيه المدمجتين `Add` و`Remove`.

يجري استرجاع القيم في القاموس أو تحديثها عبر فهرسته باستخدام مفتاح:

```csharp
var numbers = new Dictionary<int, string>
{
   {1, "One"},
   {2, "Two"}
};

// Set the value of the element with key 2 to "Deux"
numbers[2] = "Deux";

// Get the value of the element with key 2
numbers[2];
// => "Deux"
```

يمكنك التحقق مما إذا كانت قيمة موجودة في القاموس باستخدام:

```csharp
var dict = new Dictionary<string, string>{/*...*/};
dict.ContainsKey("some key that exists");
// => true
```

عند التعداد على قاموس، سيتم التعداد على أزواج المفتاح/القيمة الخاصة به. وللقواميس أيضًا خصائص تُتيح التعداد على مفاتيحه أو قيمه.
