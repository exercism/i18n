# مقدمة

تقدّم مفردات [`random`][random] في Factor كلمة عامة واحدة، `random`، تتكيّف مع وسيطها، إضافة إلى دوال مساعدة لخلط المتتاليات وسحب عيّنات منها.

```factor
USING: random ;

6 random .                       ! a value from 0..5
{ "rock" "paper" "scissors" } random .   ! a random element
{ 1 2 3 4 5 } randomize .        ! the same cards, reordered
{ 1 2 3 4 5 } 2 sample .         ! two distinct elements
```

عند تطبيق `random` على عدد صحيح `n` فإنه يُرجع قيمة في المجال `[0, n)`؛ وعند تطبيقه على متتالية يُرجع عنصرًا عشوائيًا. أما `randomize` فيخلط العناصر في مكانها، و`sample` يسحب عناصر متمايزة.

افتراضيًا، تسحب هذه الدوال من مولّد عام تُستمدّ بذرته من ساعة النظام. ولجعل النتائج قابلة للتكرار، أنشئ مولّدًا ذا بذرة باستخدام `<mersenne-twister>` (من [`random.mersenne-twister`][mt]) مع `with-random`:

```factor
USING: random random.mersenne-twister ;

42 <mersenne-twister> [ 6 random ] with-random .   ! same value every run
```

[mt]: https://docs.factorcode.org/content/vocab-random.mersenne-twister.html
