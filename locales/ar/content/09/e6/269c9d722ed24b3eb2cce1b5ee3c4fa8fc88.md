# مقدمة

## الحزم والوحدات

### الاستيراد

تُحمَّل الوحدة عادةً بالكلمة المفتاحية `use`، وهي تحمّلها وتستدعي الطريقة `import` عليها، فتستورد أي رموز مُصدَّرة.

تُستورد الرموز الموجودة في مصفوفة `@EXPORT` الخاصة بالحزمة تلقائيًا، أما الرموز الموجودة في مصفوفة `@EXPORT_OK` فيجب استيرادها صراحةً.

### التصدير

لكي يُستورد أي رمز، يجب أولًا تصديره. ووحدة [Exporter][Exporter] مضمّنة مع Perl، وهي من أيسر الخيارات للتصدير.

تعريف الوحدة:
```perl
package Foo;

use Exporter ('import');
our @EXPORT_OK = ('bar');

sub bar { ... }
```

استخدام الوحدة:
```perl
use Foo ('bar');

bar();
```

### الوحدات الأساسية

إلى جانب [Exporter][Exporter]، توفّر Perl مجموعة كبيرة ومتنوعة من [الوحدات الأساسية][perl-core-modules] الجاهزة للاستخدام. ومن الأمثلة المفيدة للتمارين التي قد تصادفها هنا [List::Util][List::Util] و[Time::Piece][Time::Piece] و[Math::BigRat][Math::BigRat].

### CPAN

بالإضافة إلى الوحدات الأساسية، يضم [CPAN][metacpan] آلاف الوحدات الإضافية التي أنشأها مجتمع Perl والمتاحة للتثبيت. ويستخدم مسار Perl ملف [cpanfile][test-runner-cpanfile] لتثبيت مجموعة مختارة من الوحدات التي يمكن استخدامها مع مشغّل اختبارات Perl الخاص بـ Exercism.
