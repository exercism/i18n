لكن الأمور غير منظّمة قليلًا: يبدو أن إحداثيات Aazra منسّقة ومرتّبة بطريقة مختلفة عن إحداثيات Rui، وعليهما أن يتنقّلا باستمرار بين القائمتين لمعرفة أي الكنوز يقابل أي الأماكن. ولأنهم من Gleamlins الناشئين، فقد جاءوا إليك طلبًا للمساعدة في كتابة برنامج صغير (مجموعة دوال في الحقيقة) لتنظيم معلومات رحلتهم بشكل أفضل.

## 1. تحويل المواقع

نفّذ الدالة `place_location_to_treasure_location` التي تأخذ موقع مكان (مثل `#("C", 1)`) وتحوّله إلى موقع كنز (مثل `#(1, "C")`).

```gleam
place_location_to_treasure_location(#("C", 1))
// -> #(1, "C")
```

## 2. مقارنة مواقع الكنوز والأماكن

نفّذ الدالة `treasure_location_matches_place_location` التي تأخذ موقع مكان (مثل `#("C", 1)`) وتُرجع `True` إذا طابق موقع كنز (مثل `#(1, "C")`).

```gleam
treasure_location_matches_place_location(#("C", 1), #(1, "C"))
// -> True

treasure_location_matches_place_location(#("C", 1), #(2, "C"))
// -> False
```

## 3. عدّ مواقع الكنوز

نفّذ الدالة `count_place_treasures` التي تأخذ مكانًا (مثل `#("Aqua Lagoon (Island of Mystery)", #("F", 1))`) وقائمة الكنوز، وتُرجع عدد الكنوز التي يمكن العثور عليها هناك.

```gleam
let place = #("Aqua Lagoon (Island of Mystery)", #("F", 1))

count_place_treasures(place, treasures)
// -> 2
```

## 4. أماكن خاصة

نفّذ الدالة `special_case_swap_possible`، التي تأخذ كنزًا (مثل `#("Amethyst Octopus", #(1, "F"))`) ومكانًا (مثل `#("Seaside Cottages", #("C", 1))`) وكنزًا مرغوبًا (مثل `#("Crystal Crab", #(6, "A"))`)، وتُرجع `True` في التركيبات التالية:

- يمكن مبادلة Brass Spyglass بأي كنز آخر في Abandoned Lighthouse.
- يمكن مبادلة Amethyst Octopus بـ Crystal Crab أو Glass Starfish في Stormy Breakwater.
- يمكن مبادلة Vintage Pirate Hat بـ Model Ship in Large Bottle أو Antique Glass Fishnet Float في Harbor Managers Office.
