# تلميحات

## عام

- الصف `plot`، والرموز `registrations` و`next-id` و`not-found`، مُعلَّنة بالفعل في ملف التمرين.
- وللحالة على مستوى الوحدة، استخدم `set-global` و`get-global` و`change-global`.

## 1. افتح الحديقة واعرض تسجيلاتها

- `V{ } clone` هي القيمة الابتدائية الصحيحة لـ`registrations` (استخدم `clone` دائمًا حتى لا تُشارَك القيمة الحرفية بين الاستدعاءات).
- العبارة `1 next-id set-global` تضبط العدّاد.
- وبالنسبة إلى `list-registrations`، يكفي `registrations get-global` وحده.

## 2. سجّل قطعة أرض

- اقرأ `next-id` أولًا، ثم `plot boa` لبناء قطعة الأرض من `id` و`name`.
- وزِد العدّاد باستخدام `next-id [ 1 + ] change-global`.
- إنّ `push` (في [`sequences`][sequences]) يضيف إلى المتجه في مكانه، وهذا مثالي مع `registrations get-global`.

## 3. حرّر قطعة أرض

- تعريف `:: release ( id -- )` يجعل `id` متاحًا داخل محمول الفلترة.
- `[ id>> id = ] reject` يُبقي كل قطعة أرض *لا* تتطابق خانتها `id` مع المتغير المحلي `id`. واستخدمه جسمًا لـ`change-global`.

## 4. احصل على قطعة أرض مسجّلة

- تُرجع `find` القيمة `( index elt/f )`. وتحذف `nip` الفهرس.
- وتضع العبارة `[ not-found ] unless*` الرمز بديلًا عندما لا يُعثر على شيء.

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
