# مقدمة

[Stringer][stringer-interface] واجهة لتحديد الصيغة النصية للقيم.

تتكوّن الواجهة من طريقة `String` وحيدة:

```go
type Stringer interface {
    String() string
}
```

يجب أن تمتلك الأنواع التي تريد تنفيذ هذه الواجهة طريقة `String()` تُرجع تمثيلًا نصيًا مقروءًا للبشر.
ستبحث حزمة [fmt][fmt-package] (وكثير من الحزم الأخرى) عن هذه الطريقة لتنسيق القيم وطباعتها.

## مثال: المسافات

لنفترض أننا نعمل على تطبيق يتعامل مع مسافات جغرافية مقيسة بوحدات مختلفة.
عرفنا النوعين `DistanceUnit` و`Distance` كما يلي:

```go
type DistanceUnit int

const (
	Kilometer    DistanceUnit = 0
	Mile         DistanceUnit = 1
)

type Distance struct {
	number float64
	unit   DistanceUnit
}
```

في المثال أعلاه، `Kilometer` و`Mile` ثابتان من النوع `DistanceUnit`.

لا تنفّذ هذه الأنواع الواجهة `Stringer` لأنها تفتقر إلى الطريقة `String`.
لذلك ستطبع دوال `fmt` قيم `Distance` باستخدام «الصيغة الافتراضية» في Go:

```go
mileUnit := Mile
fmt.Sprint(mileUnit)
// => 1
// The result is '1' because that is the underlying value of the 'Mile' constant (see constant declarations above)

dist := Distance{number: 790.7, unit: Kilometer}
fmt.Sprint(dist)
// => {790.7 0}
// not a very useful output!
```

لكي يصبح المُخرَج أكثر إفادة، ننفّذ الواجهة `Stringer` للنوعين `DistanceUnit` و`Distance` بإضافة طريقة `String` إلى كل نوع:

```go
func (sc DistanceUnit) String() string {
	units := []string{"km", "mi"}
	return units[sc]
}

func (d Distance) String() string {
	return fmt.Sprintf("%v %v", d.number, d.unit)
}
```

ستستدعي دوال حزمة `fmt` هذه الطُرق عند تنسيق قيم `Distance`:

```go
kmUnit := Kilometer
kmUnit.String()
// => km

mileUnit := Mile
mileUnit.String()
// => mi

dist := Distance{
	number: 790.7,
	unit: Kilometer,
}
dist.String()
// => 790.7 km
```
