# التعليمات

في هذا التمرين ستُنفّذ مجموعة جزئية من الدوال المساعدة التي تساعد المطوّر على تنظيف أسماء المعرّفات.

في المهام الست ستُطوّر تدريجيًا الدالة `transform` لتحويل الأحرف المفردة، والدالة `clean` لتحويل السلاسل النصية.

يتكوّن المعرّف الصالح من صفر أو أكثر من الحروف والشرطات السفلية والشرطات وعلامات الاستفهام والإيموجي.

إذا مُرّرت سلسلة نصية فارغة إلى الدالة `clean`، فيجب إرجاع سلسلة نصية فارغة.

## 1. استبدال أي شرطات تصادفها بشرطات سفلية

نفّذ الدالة `transform` لاستبدال أي شرطات بشرطات سفلية.

```fsharp
transform '-'  // => "_"
```

## 2. إزالة كل المسافات البيضاء

أزل كل أحرف المسافات البيضاء.
ويشمل ذلك المسافات البيضاء في البداية والنهاية.

```fsharp
transform ' '  // => ""
```

## 3. تحويل camelCase إلى kebab-case

عدّل الدالة `transform` لتحويل camelCase إلى kebab-case

```fsharp
transform 'D'  // => "-d"
```

## 4. حذف الأحرف التي تكون أرقامًا

عدّل الدالة `transform` لحذف أي أحرف رقمية.

```fsharp
transform '7'  // => ""
```

## 5. استبدال الحروف اليونانية الصغيرة بعلامات استفهام

عدّل الدالة `transform` لاستبدال أي حروف يونانية في النطاق من 'α' إلى 'ω'.

```fsharp
transform 'β' // => "?"
```

## 6. دمج هذه العمليات لتعمل على سلسلة نصية

نفّذ الدالة `clean` لتطبيق هذه العمليات على سلسلة نصية كاملة.

الأحرف التي تقع خارج القواعد يجب أن تمرّ دون تغيير.

```fsharp
clean "  a2b Cd-ω😀  " //  => "ab-cd_?😀"
```

## تجميع سلسلة نصية من الأحرف

سيُغطّى هذا الموضوع بتفصيل لاحقًا في المنهج.

في الوقت الحالي، قد يكون من المفيد أن تعرف أن هناك [دالة ذات رتبة أعلى][higher-order-function] تُسمى [`String.collect`][string-collect] تحوّل مجموعة من `char` إلى سلسلة نصية، باستخدام دالة توفّرها أنت.

```fsharp
let transform ch = $"{ch}_"
String.collect transform "abc"  // =>  "a_b_c_"
```
