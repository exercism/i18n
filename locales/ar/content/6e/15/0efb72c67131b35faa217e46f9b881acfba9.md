# مقدمة

في JavaScript، قد تكون القيم من أنواع مختلفة. ويمكن تغيير نوع متغير عبر _تحويل النوع_ الصريح.
وإلى جانب ذلك، تُجري JavaScript أيضًا _إكراهًا نوعيًا_ (تحويلًا ضمنيًا للنوع) عندما يتطلب السياق ذلك.

## تحويل النوع

لا تملك JavaScript بنيةً لتحويل قيمة إلى نوع (مختلف) كما تفعل لغات كثيرة أخرى، لكن يمكن استخدام بعض الأدوات المساعدة المدمجة بدلًا من ذلك.
وأبرزها `Boolean` و`Number` و`String`، إذ يمكن استخدامها كدوال لتحويل قيمة إلى النوع المقابل.

### التحويل إلى قيمة منطقية (القيم الصادقة والكاذبة)

باستخدام `Boolean(value)` يمكنك تحويل أي قيمة إلى قيمة منطقية.
وهناك مجموعة ثابتة من القيم، تُسمى القيم _الكاذبة_، تتحوّل إلى `false`.
والأهم أن `false` و`0` والسلسلة النصية الفارغة و`null` و`undefined` و`NaN` كلها قيم كاذبة.

أما جميع القيم الأخرى فتُرجع `Boolean` لها `true`.
وتُسمى هذه القيم _صادقة_.

```javascript
Boolean(-1);
// => true

Boolean(0);
// => false

Boolean(' ');
// => true

Boolean('');
// => false
```

لاحظ أنه بفضل القواعد الموصوفة، فإن `'0'` و`'false'` و`[]` و`{}` قيم **صادقة** في JavaScript.

### التحويل إلى عدد

يمكن استخدام `Number(value)` لتحويل قيمة إلى عدد.
تُتجاهل المسافات البيضاء في بداية السلسلة النصية ونهايتها، وتُحوَّل السلسلة النصية الفارغة إلى `0`.
وإذا حاولت تحويل قيمة غير أولية أو سلسلة نصية لا تمثّل عددًا، فستكون النتيجة `NaN` ([ليس عددًا][mdn-nan]).

```javascript
Number('  -12.34  ');
// => -12.34

Number('1,2');
// => NaN

Number('');
// => 0

Number({ num: 123 });
// => NaN
```

### التحويل إلى سلسلة نصية

باستخدام `String(value)` يمكنك تحويل قيمة إلى سلسلة نصية.
وتكون النتيجة كما تتوقع بالنسبة إلى القيم الأولية.

```javascript
String(12.34);
// => '12.34'

String(false);
// => 'false'

String(null);
// => 'null'

String(undefined);
// => 'undefined'
```

أما المصفوفات، فتطبّق دالة `String` تحويل السلسلة النصية على كل عنصر وتدمج النتائج بفاصلة.
ويمكنك أيضًا تطبيق طريقة [`join`][mdn-join] بنفسك، مثلًا لتخصيص الفاصل.
لاحظ أنه في هذه الحالات ستُحوَّل `null` و`undefined` إلى سلسلة نصية فارغة.

```javascript
String([42, null, true, 'abc']);
// => '42,,true,abc'
```

أما الكائنات، فتُرجع `String` افتراضيًا نصًا غير مفيد.

```javascript
String({ key: 'value' });
// => '[object Object]'
```

## الإكراه النوعي

في سياقات معينة، تحوّل JavaScript قيمةً تلقائيًا إلى نوع بيانات آخر قبل أن تُقيّم عبارة ما.
ويُسمى هذا التحويل الضمني _الإكراه النوعي_.

### السياق المنطقي

عند استخدام قيمة غير منطقية في سياق منطقي، تُطبّق JavaScript القواعد نفسها التي تطبّقها دالة `Boolean` لتحويل القيمة ضمنيًا.

ويحدث الإكراه إلى قيمة منطقية عادةً في:

- شرط [الجملة الشرطية][concept-conditionals]
- الطرف الأول لعامل [الشرط الثلاثي][mdn-ternary] `?`
- طرف عامل النفي المنطقي `!`
- طرفَي عاملي AND المنطقي `&&` و OR المنطقي `||` (نتيجة التعبير هي أحد الطرفين، وليست بالضرورة قيمة منطقية)

```javascript
const num = 0;
if (num) {
  // this block is NOT executed because 0 is falsy
}
```

### سياق السلسلة النصية

إذا استُخدم عامل الجمع `+` مع قيم أولية وكان أحد الطرفين سلسلة نصية، فسيُحوَّل الطرف الآخر إلى سلسلة نصية أيضًا.
ومنطق التحويل هو نفسه المستخدم في دالة `String`.
بعد ذلك، تُدمج السلسلتان النصيتان.

```javascript
let name;
'hello ' + name;
// => 'hello undefined'
```

### السياق العددي

تحوّل عوامل كثيرة أطرافها إلى أعداد (عند الحاجة) وفق منطق دالة `Number` الموضّح أعلاه.

- العوامل الحسابية: `+` (إذا لم تكن هناك سلسلة نصية)، `-`، `*`، `/`، `%`، `**`
- عاملا الزائد الأحادي والنفي الأحادي: `+`، `-`
- عوامل المقارنة (لأطراف غير نصية): `>`، `>=`، `<`، `<=`
- العوامل البتّية: `|`، `&`، `^`، `~`

راجع [قائمة العوامل في MDN][mdn-operators] لمزيد من التفاصيل عن أي من هذه العوامل.

لتجنّب الأخطاء، من الممارسات الجيدة استدعاء `Number` صراحةً دائمًا قبل تطبيق هذه العوامل.
