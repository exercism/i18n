# حول

لدى Haskell نوع هو `Num`، وهو النوع الأساسي لجميع الأنواع العددية.
يحتوي نوع العدد على أربعة أنواع فرعية رئيسية: [`Int`][int] و[`Integer`][integer] و[`Double`][double] و[`Float`][float].

يوجد في Haskell نوعان من أنواع الأعداد الصحيحة، وكلاهما يمثّل الأعداد الكاملة.
`Int` عدد صحيح ذو حجم ثابت، بينما `Integer` عدد صحيح ذو دقة اعتباطية.
يحتوي `Integer` على أي عدد مهما كان كبيرًا، حتى حدود ذاكرة جهازك، بينما يقابل `Int` مجموعة الأعداد الصحيحة الموجبة والسالبة التي يمكن التعبير عنها بـ 32 أو 64 بت (مع ضمان على الأقل من -2^29 إلى 2^29 - 1).

لاحظ أنك عند كتابة الأعداد السالبة ينبغي أن تستخدم الأقواس الهلالية لتجنّب الالتباس.

```haskell
1

(-1)
```

يقابل `Float` مجموعة الأعداد الحقيقية، محدودة بدقة الحاسوب.
تعمل العمليات المعرّفة على الأعداد عادةً على أحد النوعين، وليس على كليهما.
`Double` عدد ذو فاصلة عائمة بدقة مزدوجة.

```haskell
10.5
```

## التحويل بين الأعداد الصحيحة والأعداد العائمة

تتيح لك الدالة `toFloat` تحويل `Int` أو `Integer` إلى `Float`.

```haskell
toFloat 1
-- -> 1.0
```

توجد أيضًا الدالة `fromIntegral`، وهي تحوّل أي نوع عددي إلى النوع العددي المستنتج المطلوب.

```haskell
fromIntegral 1
-- -> 1.0
```

لتحويل `Float` إلى `Int`، يمكنك استخدام دوال [`round`][round] أو [`floor`][floor] أو [`ceiling`][ceiling].
تُقرّب الدالة `round` إلى أقرب عدد صحيح، وتُقرّب `floor` نحو الأسفل، وتُقرّب `ceiling` نحو الأعلى.

```haskell
round 1.5
-- -> 2

floor 1.5
-- -> 1

ceiling 1.5
-- -> 2
```

## العوامل الحسابية

يمكنك استخدام [العوامل الحسابية الأساسية][math] على الأنواع العددية.
العوامل هي `+` و`-` و`*` و`/` و`%`.
عند استخدام هذه العوامل، يجب أن تتطابق أنواع الأعداد.
ستحوّل الدالة `fromIntegral` الأنواع حتى تتطابق.

### الجمع والطرح والضرب

يُستخدم العامل `+` للجمع، والعامل `-` للطرح، والعامل `*` للضرب.

| العامل | مثال           |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### القسمة

تُستخدم القسمة لتقسيم الأعداد.
يُستخدم العامل `/` للقسمة.
تكون النتيجة دائمًا عددًا عائمًا.

```haskell
4.0 / 2.5
-- -> 1.6

4 / 2
-- -> 2.0
```

~~~~exercism/caution
في بعض لغات البرمجة، تكون نتيجة القسمة على صفر خطأً.

في Haskell، تكون نتيجة القسمة على صفر هي `Infinity` أو `-Infinity`.
الاستثناء الوحيد هو قسمة صفر على صفر، فتكون النتيجة `NaN` (ليس عددًا).

```haskell
1 / 0
-- -> Infinity

(-1) / 0
-- -> -Infinity

0 / 0
-- -> NaN
```
~~~~

## قسمة الأعداد الصحيحة

تُستخدم قسمة الأعداد الصحيحة لتقسيم الأعداد الكاملة والحصول على الجزء الصحيح من النتيجة.
لدى Haskell دالتان لقسمة الأعداد الصحيحة، تختلفان في طريقة التقريب عندما تكون النتيجة سالبة:

- `div` تُقرّب نحو الأسفل، باتجاه اللانهاية السالبة.
- `quot` تُقرّب نحو الصفر.

```haskell
6 `div` 2
-- -> 3

5 `div` 2
-- -> 2

(-5) `div` 2
-- -> -3

5 `quot` 2
-- -> 2

(-5) `quot` 2
-- -> -2
```

~~~~exercism/caution
القسمة على صفر عند استخدام قسمة الأعداد الصحيحة تؤدي إلى استثناء.
وهذا يختلف عن القسمة العادية.
~~~~

### الباقي

يمكن إيجاد باقي قسمة الأعداد الصحيحة باستخدام `mod` أو `rem`.
وهما يختلفان في إشارة النتيجة عندما يكون أحد العددين سالبًا:

- `mod` تعمل مع `div`، ونتيجتها تحمل إشارة المقسوم عليه.
- `rem` تعمل مع `quot`، ونتيجتها تحمل إشارة المقسوم.

```haskell
5 `mod` 3
-- -> 2

(-5) `mod` 3
-- -> 1

5 `mod` (-3)
-- -> -1

5 `rem` 3
-- -> 2

(-5) `rem` 3
-- -> -2

5 `rem` (-3)
-- -> 2
```

لأي `x` و`y` (حيث `y` لا يساوي صفرًا)، تصحّ القاعدتان التاليتان:

```haskell
(x `div` y) * y + (x `mod` y) == x
(x `quot` y) * y + (x `rem` y) == x
```

~~~~exercism/note
عندما يكون العددان موجبين، تُعطي `div` و`quot` النتيجة نفسها، وكذلك `mod` و`rem`.
في هذه الحالة قد تكون `quot` و`rem` أكثر كفاءة قليلًا، لأن `div` و`mod` تحتاجان إلى خطوات إضافية للتعامل مع الأعداد السالبة.
~~~~

~~~~exercism/caution
القسمة على صفر عند استخدام `mod` أو `rem` تؤدي إلى استثناء.
وهذا يختلف عن القسمة العادية.

```haskell
1 `mod` 0
-- Exception: divide by zero
```
~~~~

## الرفع إلى قوة

لدى Haskell ثلاثة عوامل «رفع إلى قوة» تعمل بطرق مختلفة وتأخذ أنواع وسائط مختلفة.

- `**` يأخذ **عددين من الأعداد ذات الفاصلة العائمة** ويستخدم اللوغاريتمات لحساب القوة.
- `^^` يأخذ **عددًا ذا فاصلة عائمة** ويرفعه إلى قوة **عدد صحيح** موجب أو سالب.
- `^` يأخذ **أي نوع عددي** ويرفعه إلى قوة **عدد صحيح موجب**.

```haskell
3.0 ** 2.1
-- -> 10.04510856630514

2.5 ^^ 2
-- -> 6.25

2 ^ 3
-- -> 8
```

## الأولوية والأقواس الهلالية

تسمح Haskell بالأقواس الهلالية (`()`) التي يمكن استخدامها لتجميع التعبيرات.
وهذا مفيد عندما تريد تغيير ترتيب العمليات.

عند استخدام عدة عوامل حسابية، يكون ترتيب العمليات كما هو في الرياضيات، ويُعرف أيضًا باسم [PEMDAS][pemdas].
وهو يتبع ترتيب الأقواس الهلالية (`()`) ثم الأسس (`**`) ثم الضرب (`*`) والقسمة (`/`) ثم الجمع (`+`) والطرح (`-`).

```haskell
2 + 3 - 4 * 4
-- -> -11

(2 + 3 - 4) * 4
-- -> 4
```
