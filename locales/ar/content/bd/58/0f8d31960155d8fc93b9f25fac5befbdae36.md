# مقدمة

## البدء

### المتغيرات

يمكنك تخزين القيم وتسميتها بتعريف [متغير][constants-variables].
بعد تعريف متغير، يمكنك استخدام اسمه للإشارة إلى تلك القيمة في كل أنحاء الكود.
المتغيرات _قابلة للتغيير_، وهذا يعني أن قيمها يمكن أن تتغير بعد تعريفها.

عرّف متغيرًا بالكلمة المفتاحية `var`:

```swift
var variableName = 10
```

Swift لغة ذات أنواع ساكنة، وهذا يعني أن لكل قيمة نوعًا معروفًا وقت الترجمة.
يمكنك الإعلان صراحةً عن نوع باستخدام [تعليق النوع][type annotations]، أو أن تدع مترجم Swift [يستنتج النوع][type-inferring] من القيمة المُسنَدة:

```swift
var explicitVar: Int = 10 // Explicitly typed
var implicitVar = 10      // Implicitly typed (inferred as Int)
```

يمكنك تحديث قيمة متغير باستخدام عامل الإسناد (`=`):

~~~~exercism/note
لا يمكن لنوع المتغير أن يتغير بعد إعلانه.

```swift
variableName = 13 // Allowed: same type (Int)

// Compiler error: cannot assign a different type
variableName = "Hello, world!" // Cannot assign value of type 'String' to type 'Int'
```
~~~~

يمكنك إعلان متغير دون قيمة ابتدائية بتحديد نوعه، لكن يجب أن تُسند إليه قيمة قبل استخدامه:

```swift
var someInt: Int

// This triggers a compiler error:
// print(someInt) // Variable 'someInt' used before being initialized

// Assign a value first
someInt = 169
print(someInt) // Prints 169
```

### الثوابت

[الثوابت][constants-variables] تربط أيضًا اسمًا بقيمة، لكن لا يمكن تغيير قيمها بعد الإسناد.
فهي _غير قابلة للتغيير_.
عرّف ثابتًا باستخدام الكلمة المفتاحية `let`:

```swift
let constantName = 10          // Inferred constant
let explicitConstant: Int = 10 // Explicitly typed constant
```

### العوامل الحسابية

توفّر Swift [عوامل حسابية][arithmetical-operators] قياسية للعمليات الرياضية الأساسية:

- الجمع: `+`
- الطرح: `-`
- الضرب: `*`

```swift
print(1 + 1) // Prints 2
print(2 - 1) // Prints 1
print(2 * 2) // Prints 4
```

### الدوال

في Swift، [الدوال][functions] كتل من الكود قائمة بذاتها تؤدي مهمة محددة.
يمكن للدوال أن تستقبل مدخلات، وأن تُرجع قيمة، وأن تُمرَّر كقيم إلى دوال أخرى.
عرّف دالة بالكلمة المفتاحية `func`، يتبعها اسم الدالة، وقائمة معاملات بين أقواس هلالية، ونوع إرجاع اختياري:

```swift
func functionName(argumentLabel parameterName: ParameterType) -> ReturnType {
    // Function body
}
```

تستخدم دوال Swift [تسميات الوسائط][argument-labels]، التي تجعل الكود يُقرأ كجمل طبيعية:

- تُستخدم **تسمية الوسيط** عند استدعاء الدالة.
- ويُستخدم **اسم المعامل** داخل جسم الدالة للوصول إلى القيمة.

إذا حددت اسمًا واحدًا فقط، تستخدمه Swift كتسمية للوسيط واسم للمعامل معًا:

```swift
func greet(name: String) {
    print("Hello, \(name)!")
}

greet(name: "Alice")
```

إذا كنت لا تريد تسمية وسيط عند استدعاء الدالة، فاكتب شرطة سفلية (`_`) قبل اسم المعامل:

```swift
func square(_ number: Int) -> Int {
    return number * number
}

square(5) // Called without an argument label
```

جميع معاملات الدالة ثوابت (`let`) افتراضيًا، وهذا يعني أنه لا يمكن تعديل قيمها داخل جسم الدالة.

لإرجاع قيمة من دالة، حدّد نوع الإرجاع بعد `->` واستخدم الكلمة المفتاحية `return`:

```swift
func addTen(to value: Int) -> Int {
    return value + 10
}

addTen(to: 10) // Returns 20
```

عندما لا تُرجع دالة قيمة، يكون نوع الإرجاع `Void` (مكافئ لصف فارغ، `()`).
يمكنك حذف نوع الإرجاع `-> Void` وعبارة `return` معًا في مثل هذه الدوال.

### التعليقات

تدعم Swift شكلين من [التعليقات][comments]:

- تبدأ **التعليقات أحادية السطر** بـ `//` وتستمر حتى نهاية السطر.
- تُحاط **التعليقات متعددة الأسطر** بين `/*` و`*/`.

```swift
// This is a single-line comment

/* This is a comment
   that spans multiple lines */
```
