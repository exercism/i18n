# مقدمة

_السلسلة النصية_ هي نوع البيانات في JavaScript لتخزين البيانات النصية.

## إنشاء سلسلة نصية

يمكنك إنشاء سلسلة نصية بتطويق النص بعلامات اقتباس مفردة أو مزدوجة.
في Exercism، تُستخدم علامات الاقتباس المفردة.

<!-- prettier-ignore-start -->
```javascript
'Hello, World!'
"Hello, World!"
```
<!-- prettier-ignore-end -->

## السلاسل النصية كمصفوفات من المحارف

يمكن التعامل مع السلسلة النصية كمصفوفة من المحارف، حيث يكون فهرس المحرف الأول `0`.
يمكنك الوصول إلى محرف واحد من السلسلة النصية باستخدام الأقواس المربعة وفهرس الحرف الذي تريد استرجاعه.

```javascript
'cat'[1];
// => 'a'
```

يمكنك تحديد عدد المحارف في السلسلة النصية من خلال الوصول إلى خاصية `length`.

```javascript
'cat'.length;
// => 3
```

## دمج السلاسل النصية والطرق

أبسط وسيلة لدمج السلاسل النصية هي استخدام عامل الجمع `+`.

```javascript
'I like' + ' ' + 'cats.';
// => "I like cats."
```

توفّر السلاسل النصية الكثير من الطرق المساعدة، راجع [توثيق MDN لطرق السلاسل النصية][mdn-string-methods] للحصول على القائمة الكاملة.
تعرض القائمة التالية بعض الطرق المساعدة الشائعة الاستخدام.

- [`toUpperCase`][mdn-to-upper-case] و[`toLowerCase`][mdn-to-lower-case] - تغيير حالة جميع المحارف
- [`trim`][mdn-trim] - إزالة الفراغات في البداية والنهاية
- [`includes`][mdn-includes] و[`startsWith`][mdn-starts-with] و[`endsWith`][mdn-ends-with] - تحديد ما إذا كانت سلسلة نصية أخرى جزءًا من السلسلة النصية المعطاة
- [`slice`][mdn-slice] - استخراج قسم من السلسلة النصية

السلاسل النصية غير قابلة للتغيير في JavaScript. لذلك فإن أي "تعديل"، مثل ما تقوم به بعض الطرق أعلاه، سينشئ دائمًا سلسلة نصية جديدة بدلًا من ذلك.
