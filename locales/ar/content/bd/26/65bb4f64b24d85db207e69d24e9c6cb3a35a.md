# Debug

عندما يفشل أحد الاختبارات، تظهر رسالة توضّح ما الذي حدث من خطأ، ولأي مدخل كان ذلك. يمكنك فحص أي قيم تشاء في برنامجك بتمريرها إلى الطريقة `debug` (المتاحة في `exercism/test_runner`)، وسيلتقط هذا القيم ويعرض لك المخرجات.

```gleam
import exercism/test_runner.{ debug }

let value: String = "test"
debug("The value is " <> value)
```
