# مقدمة

يُتيح النوع `Result` للدالة أن تُرجع قيمة واحدة تشير إلى كل ما يلي:

- ما إذا نجحت العملية أم فشلت
- عند النجاح، القيمة الناتجة عن العملية
- عند الفشل، سبب الفشل

## الاستخدام

النوع `Result` نوع عام يحتوي على نوعين أساسيين:

- نوع القيمة الناتجة عند نجاح العملية
- النوع الذي يمثّل سبب الفشل عند الفشل

كما أن النوع `Result` هو [اتحاد مميّز][discriminated-union] له الحالات المحتملة التالية:

- `Ok <value>`: يمثّل نتيجة ناجحة
- `Error <reason>`: يمثّل فشلًا

توضّح الدالة التالية كيفية إنشاء قيمة `Result`:

```fsharp
let validateName (name: string) : Result<string, string> =
    match name with
    | null -> Error "Name not found."
    | "" -> Error "Name is empty."
    | _ -> Ok name
```

في هذا المثال، قيمة `Ok` هي سلسلة نصية (الاسم المعطى)، وقيمة `Error` هي أيضًا سلسلة نصية (سبب الخطأ، بصيغة يمكن للإنسان قراءتها).

## قراءة محتوى قيمة `Result`

لنتأمل تعريف النوع وتوقيع الدالة التاليين:

```
type FileOpenError =
| NotFound
| AccessDenied
| FileLocked

let openFile (filename: string) : Result<int, FileOpenError> =
```

يمكن للكود الذي يستدعي الدالة `openFile` استخدام مطابقة الأنماط للتعامل مع حالتَي النجاح والفشل، كما في المثال التالي:

```fsharp
match openFile(filename) with
| Ok handle -> doSomethingWithFile(handle)
| Error NotFound -> printfn $"Error: file {filename} was not found."
| Error AccessDenied -> printfn $"Error: you do not have permission to open the file {filename}."
| Error FileLocked -> printfn $"Error: file {filename} is already in use."
```
