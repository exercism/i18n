# ملحق التعليمات

## ابنِ DSL الخاصة بك

في هذا التمرين، لك مطلق الحرية في تصميم DSL الرسم البياني الذي تحلم به.

لا تطلب منك الاختبارات سوى إنشاء بعض الرسوم البيانية المحددة، وطريقة بنائها متروكة لك تمامًا.

ولمضاعفة المتعة، يمكنك اختياريًا أن تحاول تنفيذ دالة `to_dot` تحوّل رسمك البياني إلى صيغة DOT!

## تمثيل الرسم البياني

عرّف DSL الخاصة بك في `Graph.roc`، ثم استخدمها لبناء الرسوم البيانية التي يطلبها الملف الأولي.
يجب ترتيب معرّفي العقدتين في كل `EdgeId` ترتيبًا أبجديًا.

| التعريف | الرسم البياني المطلوب بناؤه |
| --- | --- |
| `empty_graph` | رسم بياني فارغ |
| `graph_with_one_node` | عقدة واحدة |
| `graph_with_one_node_with_attribute` | عقدة واحدة ذات سمة |
| `graph_with_one_edge` | حافة واحدة |
| `graph_with_one_attribute` | سمة واحدة للرسم البياني |
| `graph_with_nodes_edges_and_attributes` | عقد وحافات وسمات |
| `multiple_edges_on_one_line` | حافات متعددة معبَّر عنها في سطر واحد |
| `only_1_edge_between_nodes` | حافة واحدة فقط بين كل زوج من العقد |
