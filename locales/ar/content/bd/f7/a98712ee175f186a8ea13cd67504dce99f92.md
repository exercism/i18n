# مقدمة

## مساحات الأسماء

مساحات الأسماء طريقة لتجميع الكود المرتبط ببعضه ولتجنّب تعارض الأسماء، وهي موجودة عمومًا في كل قواعد الكود باستثناء أبسطها.

الصيغة كالتالي:

```csharp
namespace MyNameSpace
{
    public class MyClass {}

    public class OtherClass {}
}
```

الأنواع المُضمَّنة داخل مساحات الأسماء يُشار إليها من خارج نطاق مساحة الأسماء بإضافة بادئة إلى اسم النوع باستخدام صيغة النقطة. وبدلًا من ذلك، وفي الغالب الأعم، يمكنك وضع توجيه `using` في أعلى الملف (أو داخل مساحة الأسماء) ليُستخدم النوع بدون بادئة. وداخل مساحة الأسماء نفسها، لا حاجة لتأهيل أسماء الأنواع.

```csharp
namespace MySpace
{
    public class MyClass {}

    public class Foo
    {
        public void Bar()
        {
            var baz = new MyClass();
        }
    }
}

public class Qux
{
    public void Box()
    {
        var nux = new MySpace.MyClass();
    }
}

namespace OtherSpace
{
    using MySpace;

    public class Tix
    {
        public void Jeg()
        {
            var lor = new MyClass();
        }
    }
}
```

يمكنك إنشاء اسم مستعار لمساحة الأسماء بالصيغة `using MyAlias = MySpace;` ثم استخدام هذا الاسم المستعار في أي موضع يمكن فيه استخدام مساحة الأسماء.
