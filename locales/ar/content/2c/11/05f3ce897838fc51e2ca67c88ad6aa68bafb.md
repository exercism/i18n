# حول

## القيم المنطقية

توفّر PowerShell النوع [`bool`][booleans] لتمثيل قيمتَي صحيح وخطأ.
لا يوجد في هذا النوع سوى قيمتين: `True` و`False`.
يمكنك إسناد هذه القيم إلى المتغيرات باستخدام البادئة `$`:

```powershell
> $TrueVar  = $true
> $FalseVar = $FALSE
#Case senstitivity doesn't matter here
```

يمكننا استخدام [العوامل المنطقية][logical-operators] مثل `-and` و`-or` و`-not` لدمج التعبيرات المنطقية وتقييمها.

```powershell
> $TrueVar  = $true -and $true
> $FalseVar = $true -and $false

> $TrueVar  = $true -or $false
> $FalseVar = $false -or $false

> $TrueVar  = -not $false
> $FalseVar = -not $true
```

## التحويل والصدقية

تستطيع PowerShell معاملة أي نوع كأنه قيمة منطقية بشكل ضمني.
ومع ذلك، يمكنك أيضًا استخدام مسرّع النوع المنطقي `[bool]` لإجراء تحويل صريح.

فيما يلي بعض القواعد العامة التي تستخدمها PowerShell لتحويل الأنواع الأخرى إلى قيم منطقية:

`$false`:
- السلاسل النصية الفارغة مثل `''` أو `""`
- القيم المعدومة مثل `$null`
- النوع العددي ذو القيمة صفر (0)

`$true`:
- السلاسل النصية غير الفارغة
- نسخ من أي نوع آخر غير أنواع المجموعات

```powershell
> [bool] 0
False

> [bool] 0.0
False

> [bool] ""
False

> [bool] "Hello"
True

> [bool] 1234
True
```

لمعرفة القواعد المتعمقة حول تحويل القيم المنطقية من أنواع المجموعات، اقرأ [هنا][collection-conversion].
