# جمل `case`

عند مقارنة قيمة واحدة بقائمة من الاحتمالات، يكرر تسلسل من جمل `elsif` الشيء نفسه مرارًا وتكرارًا:

```sather
   if zone = 0 then
      return 0;
   elsif zone = 1 then
      return 550;
   elsif zone = 2 then
      return 370;
   else
      return 920;
   end;
```

أما جملة `case` فتقول ذلك مرة واحدة فقط:

```sather
   case zone
   when 0 then return 0;
   when 1 then return 550;
   when 2 then return 370;
   else return 920;
   end;
```

تأتي القيمة بعد `case`، ويقدّم كل `when` قيمة تُقارَن بها، وأول قيمة تطابقها هي التي تُنفَّذ.

## قيم متعددة في `when` واحد

يمكن أن يضم `when` الواحد عدة قيم تفصل بينها فواصل:

```sather
   case day
   when "Sat", "Sun" then return "Weekend";
   when "Mon", "Tue", "Wed", "Thu", "Fri" then return "Weekday";
   else return "Unknown";
   end;
```

يعمل هذا مع الأعداد الصحيحة والمحارف والسلاسل النصية، أي مع أي شيء يمكن مقارنته بـ `=`.

## لا غنى عن `else`

**جملة `case` لا تطابق شيئًا وليس لها `else` هي خطأ يوقف البرنامج عند حدوثه.**

وهذا يختلف عن `if`، حيث يعني حذف `else` ببساطة أن شيئًا لن يحدث. ويختلف أيضًا عن معظم اللغات، حيث لا تفعل جملة `case` غير المطابِقة شيئًا في صمت.

لذا تحتاج كل جملة `case` إلى `else`، حتى عندما تكون واثقًا من أن أجزاء `when` تغطي كل القيم بالفعل. فقد تُضاف منطقة رابعة لاحقًا، ولا تُحدَّث جملة `case` لتطابقها، فيتوقف البرنامج عند أول راكب يستخدمها.

## لا يُنفَّذ إلا `when` واحد

عندما يطابق `when` ما، تُنفَّذ العبارات التي تلي `then` وتنتهي جملة `case`، ثم يواصل البرنامج بعد `end`. ولا يُنظر أبدًا إلى أجزاء `when` التي تليه، فليس عليك كتابة أي شيء لمنع الجزء التالي من التنفيذ أيضًا.
