# التعليمات

في هذا التمرين ستكتب كودًا لمعالجة مصفوفة من لغات البرمجة التي تخطط للتدرّب عليها من منصة Exercism.

لديك ست مهام.

## 1. إنشاء مصفوفة جديدة

قبل أن تتمكن من إضافة اللغات، ستحتاج إلى البدء بإنشاء مصفوفة جديدة. عرّف دالة تُرجع مصفوفة فارغة.

```clojure
(new-list)
;; => ()
```

## 2. إضافة لغة جديدة إلى المصفوفة

بينما تستكشف Exercism وتجد لغات تريد تعلّمها، ستحتاج إلى إمكانية إضافتها إلى مصفوفتك. عرّف دالة تضيف لغة جديدة إلى بداية مصفوفتك.

```clojure
(add-language "JavaScript" '("Clojurescript"))
;; => '("JavaScript" "Clojurescript")
```

## 3. التحقق من اللغة المُضافة أخيرًا

ستريد أن تتحقق بسرعة من اللغة التي أضفتها للتو. عرّف دالة تُرجع أول لغة من مصفوفتك.

```clojure
(first-language '("Haskell" "Python"))
;; => "Haskell"
```

## 4. إزالة أول لغة من المصفوفة

أحيانًا ستغيّر رأيك في لغة أضفتها للتو. عرّف دالة تزيل أول لغة من مصفوفتك.

```clojure
(remove-language '("Common Lisp" "Racket" "Scheme"))
;; => '("Racket" "Scheme")
```

## 5. حساب عدد اللغات في المصفوفة

عدّ اللغات واحدة تلو الأخرى أمر غير مريح. عرّف دالة تحسب عدد اللغات في مصفوفتك.

```clojure
(count-languages '("C#" "Racket" "Rust" "Ruby"))
;; => 4
```

## 6. جمع كل ذلك معًا

عرّف دالة `learning-list` ستستخدم داخلها بعض الدوال التي عرّفتها أعلاه.

- أنشئ مصفوفة فارغة.
- أضف لغتَي برمجة جديدتين إلى المصفوفة.

  - "Clojure"
  - "Lisp"

- أزل "Lisp" من المصفوفة، فقد لا يتوفر لديك وقت كافٍ خلال السنة، وهي تشبه Clojure كثيرًا.
- أضف لغتَي برمجة إضافيتين إلى المصفوفة.

  - "Java"
  - "JavaScript"

- اجعل الدالة تُرجع العدد الإجمالي للغات. تلميح: يجب أن يكون 3.

```clojure
(learning-list)
;; => 3
```
