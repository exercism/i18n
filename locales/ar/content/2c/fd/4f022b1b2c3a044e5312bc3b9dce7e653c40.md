# المهام

المهام هي مشكلات على GitHub نودّ أن يساعد الناس في حلّها، بدءًا من تدقيق النص وصولًا إلى بناء تمارين المفاهيم.
تُعرض على الموقع وتُربط بالمشكلات المقابلة لها على GitHub.
تُوسَم كل مهمة بخاصية واحدة أو أكثر، تُستمد من تسميات المشكلة.
يمكن للمستخدم بعد ذلك تصفية المهام بناءً على خصائصها.

## الوسوم

لكي تُعتبر المشكلة مهمة، يجب أن تحمل تسمية أو أكثر خاصة بالمهام.
وبذلك يمكن للقائمين على الصيانة أن يختاروا إظهار بعض المشكلات فقط كمهام.

تُعرَّف تسمية كل مهمة على النحو التالي: `x:<type>/<value>`، وتُدعم خمسة أنواع من تسميات المهام:

- `action`
- `knowledge`
- `module`
- `size`
- `type`

### وسم الإجراء

تصف التسميات `x:action/<value>` نوع العمل الذي سينخرط فيه المساهم عند العمل على المشكلة.

| الوسم                | الوصف                                   |
| -------------------- | --------------------------------------- |
| `x:action/create`    | العمل على شيء من الصفر                  |
| `x:action/fix`       | إصلاح مشكلة                             |
| `x:action/improve`   | تحسين وظائف أو محتوى قائم               |
| `x:action/proofread` | تدقيق النص                              |
| `x:action/sync`      | مزامنة المحتوى مع أحدث إصدار له         |

### وسم المعرفة

تصف التسميات `x:knowledge/<value>` مقدار معرفة Exercism المطلوب من المساهم.

| الوسم                      | الوصف                                      |
| -------------------------- | ------------------------------------------ |
| `x:knowledge/none`         | لا تُشترط معرفة سابقة بـ Exercism          |
| `x:knowledge/elementary`   | تُشترط معرفة قليلة بـ Exercism             |
| `x:knowledge/intermediate` | تُشترط معرفة لا بأس بها بـ Exercism        |
| `x:knowledge/advanced`     | تُشترط معرفة شاملة بـ Exercism             |

### وسم الوحدة

تشير التسميات `x:module/<value>` إلى الجزء الذي سيعمل عليه المساهم في Exercism.

| الوسم                        | الوصف                       |
| ---------------------------- | --------------------------- |
| `x:module/analyzer`          | العمل على المحلّلات         |
| `x:module/concept`           | العمل على المفاهيم          |
| `x:module/concept-exercise`  | العمل على تمارين المفاهيم   |
| `x:module/generator`         | العمل على مولّدات التمارين  |
| `x:module/practice-exercise` | العمل على التمارين التدريبية |
| `x:module/representer`       | العمل على الممثّلات         |
| `x:module/test-runner`       | العمل على مشغّلات الاختبارات |

### وسم الحجم

تصف التسميات `x:size/<value>` مقدار العمل المتوقع من المساهم.

| الوسم            | الوصف                  |
| ---------------- | ---------------------- |
| `x:size/tiny`    | قدر ضئيل من العمل      |
| `x:size/small`   | قدر صغير من العمل      |
| `x:size/medium`  | قدر متوسط من العمل     |
| `x:size/large`   | قدر كبير من العمل      |
| `x:size/massive` | قدر ضخم من العمل       |

### وسم النوع

تصف التسميات `x:type/<value>` نوع العمل الذي سينخرط فيه المساهم.

| الوسم            | الوصف                                                                                                                                                                                                    |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `x:type/ci`      | العمل على التكامل المستمر (مثل سير عمل GitHub Actions)                                                                                                                                                 |
| `x:type/coding`  | كتابة كود لا يكون جزءًا من المحتوى الموجّه إلى الطلاب. تكون هذه عادةً مهام مرتبطة بأدوات الإنتاج (مثل مشغّلات الاختبارات)، أو الأدوات الداخلية (المولّدات)، أو المكتبات التي تتولى Exercism صيانتها. |
| `x:type/content` | العمل على المحتوى (مثل التمارين، والمفاهيم)                                                                                                                                                                     |
| `x:type/docker`  | العمل على ملفات Dockerfile                                                                                                                                                                                            |
| `x:type/docs`    | العمل على التوثيق                                                                                                                                                                                          |

## الوسوم المُطالَب بها مقابل غير المُطالَب بها

لإخفاء مهمة لأن شخصًا يعمل عليها بالفعل، يمكن إضافة التسمية `x:status/claimed` إلى المشكلة.
