# نبذة

يمكن تنفيذ الكود تنفيذًا شرطيًا باستخدام [تعبيرات `if/elif/else`][conditional-expression]. ويجب أن تكون الشروط المستخدمة في تعبير `if/elif/else` من النوع `bool`. ولا يوجد في F# مفهوم للقيم التي تُقيَّم كصحيحة.

```fsharp
if x = 5 then
    printfn "x equals 5"
elif x > 7 then
    printfn "x is not 5 and greater than 7"
else
    printfn "x is not 5 and not greater than 7"
```

ولأن `if/elif/else` تعبير، فيمكن إسناده إلى اسم أو إرجاعه من دالة.

```fsharp
let message =
    if x = 5 then
        "x equals 5"
    elif x > 7 then
        "x is not 5 and greater than 7"
    else
        "x is not 5 and not greater than 7"
```

يجب أن تُرجع جميع الفروع النوع نفسه. وعدم فعل ذلك يؤدي إلى خطأ من المترجم:

```fsharp
if x = 5 then
    true
elif x > 7 then
    5.6

// Results in compiler error
```

فرعا `else` و`elif` اختياريان، لكن فقط إذا كان نوع التعبير المُرجَع هو [`unit`][unit-type].

```fsharp
// Valid if expression
if x > 2 then
    printfn "x is greater than two"

// Invalid if expression, results in compiler warning
if x > 2 then
    true
```

يمكن أيضًا وضع تعبير `if/else` في سطر واحد. ولا ينبغي استخدام ذلك إلا مع تعبيرات `if` البسيطة.

```fsharp
let y = if x > 5 then 10 else 20
```
