# مقدمة

يتيح الامتداد الساكن تمديد أنواع موجودة تمديدًا زائفًا دون تعديل مصدرها، ويتحقق ذلك عبر جملة `using`. ويمكن أن يكون الامتداد الساكن أداة قوية تُضيف إمكانات إلى الأنواع دون تغييرها فعليًا.

```haxe
using Main.IntExtender;

class Main {
  public static function main() {
    trace(2.triple()); // 6
  }
}

class IntExtender {
  public static function triple(i:Int):Int {
    return i * 3;
  }
}
```
