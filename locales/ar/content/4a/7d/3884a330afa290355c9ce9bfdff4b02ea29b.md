# مقدمة

تتمتع الدوال في Kotlin بمكانة المواطن من الدرجة الأولى.
وهذا يعني أنه يمكن تخزينها في المتغيرات، وتمريرها كوسائط، بل وإرجاعها من دوال أخرى.
على سبيل المثال، إسناد دالة إلى المتغير `addOne`:

```kotlin
val addOne = fun (num : Int) : Int {
    return num + 1
}
```

كما يمكن للدالة أن تُرجع دالة أخرى:

```kotlin
fun makeAddOne() : (Int) -> Int {
    return fun(num : Int) : Int {
        return num + 1
    }
}

val addOne = makeAddOne()
```

بعد الإسناد، يمكن استدعاء الدالة عبر المتغير كما لو كانت دالة أخرى فحسب:
```kotlin
addOne(3)
// => 4
```

## الإعلان عن أنواع الدوال

يمكن الإعلان عن نوع المتغير أو المعامل باستخدام الصيغة `(parameter types) -> return type`.
على سبيل المثال، الإعلان عن متغير:

```kotlin
val addOne : (Int) -> Int = fun (num : Int) : Int {
    return num + 1
}
```

ولمعامل دالة:

```kotlin
fun perform(operation : (Int) -> Int) {
    operation(3)
}
```

## تعبيرات لامبدا

تعبير لامبدا أسلوب أقصر لتعريف دالة.
وتُكتب على الصيغة `{ parameters -> body }`.
ويُرجع التعبير القيمة الأخيرة من آخر عبارة في الجسم.
على سبيل المثال:

```kotlin
// Assigning to a variable
val addOne = { num : Int -> num +  1}

// In a function call
perform({ num : Int -> num + 1 })
```

يستطيع Kotlin استنتاج الأنواع عندما تتوفر معلومات كافية.
على سبيل المثال، يمكن كتابة الأمثلة أعلاه أيضًا على النحو التالي:

```kotlin
// Assigning to a variable
val addOne : (Int) -> Int = { num -> num + 1 }

// Or ...
val addOne  = { num : Int -> num + 1 }

// Using in a function
perform({ num -> num + 1 })
```

## `it` مع لامبدا ذات معامل واحد

عندما يكون للتعبير معامل واحد فقط، يمكن حذف المعامل.
عندها يجعل Kotlin معاملًا باسم `it` متاحًا داخل الجسم.
على سبيل المثال:

```kotlin
val addOne : (Int) -> Int = { it +  1 }
```

## تمرير اللامبدا اللاحقة

عندما يكون آخر وسيط للدالة عبارة عن لامبدا، تُكتب اللامبدا مباشرةً _بعد_ الأقواس الهلالية.
على سبيل المثال:

```kotlin
// Function that takes a function as last argument
fun calculateFrom(from : Int, operation : (Int) -> Int) : Int {
    return operation(from)
}

// Call the calculateFrom function
calculateFrom(2) { it * 3 }
// => 6
```
