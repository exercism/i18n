# نبذة

يمكن استخدام العديد من العوامل أيضًا كـ[إسنادات مركبة][compound-assignment]، وهي صيغة مختصرة يمكن فيها كتابة `x = op y` بالشكل `x op= y`:

```csharp
var features = PhoneFeatures.Call;
features |= PhoneFeatures.Text;
features &= ~PhoneFeatures.Call;
```
