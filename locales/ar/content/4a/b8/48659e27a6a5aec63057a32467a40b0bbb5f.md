# ملحق التعليمات

## السجلات

| السجل | الاستخدام | النوع | الوصف |
| -------- | --------- | ------- | ---------------------------------------- |
| `$a0`    | مُدخل     | عنوان | سلسلة نصية مُدخلة منتهية بـ null             |
| `$v0`    | مُخرج     | قيمة منطقية | صحة ISBN (`0` = `false`، `1` = `true`) |
| `$t0-9`  | مؤقت | أي     | يُستخدم للتخزين المؤقت               |
