# مقدمة

## السجلات

السجل مجموعة من الحقول (التي يمكن أن تكون من أنواع مختلفة) ترتبط ببعضها. لتعريف سجل تُستخدم الكلمة المفتاحية `type`. تُعرَّف حقول السجل بين المحرفين `{` و`}`، ولكل حقل اسم _و_نوع. ولإنشاء سجل، حدّد أسماء الحقول وأسنِد إليها قيمًا بين المحرفين `{` و`}`. ويجب إسناد قيمة إلى كل الحقول عند إنشاء السجل. ويمكن الوصول إلى قيم حقول نسخة السجل باستخدام الترميز النقطي.

عند تعريف سجل أو إنشائه، يجب أن يكون كل حقل في سطر منفصل، أو أن تفصل بين الحقول بفواصل منقوطة (`;`) إذا كانت في سطر واحد.

```fsharp
// Define a record
type Address =
    { Street: string
      HouseNumber: int }

// Create a record
let oldAddress: Address =
    { Street = "Main Street"
      HouseNumber = 17 }

// Single-line alternative
type ConciseAddress = { Street: string; HouseNumber: int }
let conciseAddress: ConciseAddress = { Street = "Main Street"; HouseNumber = 17 }
```

بما أن السجلات غير قابلة للتغيير، فبعد إنشاء السجل لا يمكن أبدًا تغيير قيم حقوله. وإذا أردت تغيير قيم سجل ما، فإن الكلمة المفتاحية `with` تتيح لك إنشاء نسخة من سجل موجود، لكن بقيم جديدة لحقل واحد أو أكثر.

```fsharp
// Copy the old address but change the house number
let newAddress: Address = { oldAddress with HouseNumber = 86 }
newAddress.Street      // => "Main Street"
newAddress.HouseNumber // => 86
```

للسجلات _مساواة بنيوية_، وهذا يعني أن نسختين من السجل نفسه بقيم متطابقة تكونان متكافئتين.

وإلى جانب إمكانية استخدام الترميز النقطي للوصول إلى حقول السجل، يمكن أيضًا _تفكيك_ السجلات في الارتباطات وفي مطابقة الأنماط:

```fsharp
let myAddress: Address = { Street = "Broadway"; HouseNumber = 123 }
let { Street = myStreet; HouseNumber = myHouseNumber } = myAddress

match myAddress with
| { HouseNumber = 1 } -> printfn "First house"
| { HouseNumber = houseNumber; Street = street } -> printfn "House number %d on %s" houseNumber street
// => "House number 123 on Broadway
```
