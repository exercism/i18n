# نبذة

تسمح [العوامل الثلاثية][ternary-operators] بتعريف شروط `if` داخل التعبيرات بدلًا من كتل العبارات. وهذا يتوافق مع أساليب البرمجة الوظيفية، وغالبًا ما يجعل الكود أكثر تعبيرًا وأقل عرضة للأخطاء.

يجمع العامل الثلاثي ثلاثة تعبيرات: شرطًا يليه تعبير يُقيَّم ويُرجع إذا كان الشرط صحيحًا (الجزء `if`، ويسبقه الرمز `?`)، وتعبيرًا يُقيَّم ويُرجع إذا كان الشرط خطأً (الجزء `else`، ويسبقه الرمز `:`).

```csharp
int a = 3, b = 4;
int max = a > b ? a : b;
// => 4
```

[ternary-operators]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/operators/conditional-operator
