# التعليمات

أنت مسؤول المؤن على السفينة، وتدير مخزون المؤن. المخزون هو جدول تجزئة حيث يكون كل مفتاح اسم عنصر، وتكون القيمة هي الكمية الموجودة في المخزون.

## 1. أنشئ مخزونًا من قائمة

عرّف `create-inventory` بحيث تأخذ تسلسلًا من أسماء العناصر وتُرجع جدول تجزئة يقرن كل اسم فريد بكميته.

```factor
{ "coal" "wood" "wood" "diamond" "diamond" "diamond" } create-inventory .
! => H{ { "coal" 1 } { "wood" 2 } { "diamond" 3 } }
```

## 2. أضف المزيد من العناصر

عرّف `add-items` بحيث تأخذ مخزونًا وتسلسلًا من العناصر وتُرجع مخزونًا جديدًا زادت كمياته لكل عنصر مدرج. يجب ألا يُعدّل المخزون الأصلي.

```factor
H{ { "coal" 1 } } { "wood" "iron" "coal" "wood" } add-items .
! => H{ { "coal" 2 } { "wood" 2 } { "iron" 1 } }
```

## 3. أنقص الكميات

عرّف `decrement-items` بحيث تأخذ مخزونًا وتسلسلًا من العناصر وتُرجع مخزونًا جديدًا نقصت كمياته بمقدار واحد لكل عنصر مدرج. يجب ألا تنخفض الكميات أبدًا إلى ما دون الصفر، ويجب استبعاد العناصر غير الموجودة أصلًا في المخزون (لا تُدرج إدخالات سالبة).

```factor
H{ { "coal" 3 } { "diamond" 1 } { "iron" 5 } }
{ "diamond" "coal" "iron" "iron" } decrement-items .
! => H{ { "coal" 2 } { "diamond" 0 } { "iron" 3 } }
```

## 4. أزل عنصرًا بالكامل

عرّف `remove-item` بحيث تأخذ مخزونًا وعنصرًا وتُرجع مخزونًا جديدًا بعد إزالة ذلك العنصر. إذا لم يكن العنصر موجودًا، تُرجع نسخة دون تغيير.

```factor
H{ { "coal" 2 } { "wood" 1 } { "diamond" 2 } } "coal" remove-item .
! => H{ { "wood" 1 } { "diamond" 2 } }
```

## 5. اسرد العناصر المتاحة

عرّف `list-inventory` بحيث تأخذ مخزونًا وتُرجع مصفوفة من أزواج `{ name quantity }` تحتوي فقط على العناصر التي تكون كميتها أكبر من صفر، مرتبة أبجديًا حسب الاسم.

```factor
H{ { "coal" 7 } { "wood" 11 } { "diamond" 2 } { "iron" 7 } { "silver" 0 } }
list-inventory .
! => { { "coal" 7 } { "diamond" 2 } { "iron" 7 } { "wood" 11 } }
```
