# نبذة

الثوابت في Gleam وسيلة لإعطاء أسماء للقيم، وتُعرَّف باستخدام الكلمة المفتاحية `const`.

```gleam
pub const pi: Float = 3.14159

pub fn circle_area(radius: Float) -> Float {
  radius *. radius *. pi
}
```

عند تعريف ثوابت الوحدة باستخدام الكلمة المفتاحية `pub` يمكن الوصول إليها من وحدات أخرى، وإلا فلا يمكن الوصول إليها إلا من داخل الوحدة التي عُرِّفت فيها.
