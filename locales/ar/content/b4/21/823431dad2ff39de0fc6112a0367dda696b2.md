# التعليمات

أنت مسؤول عن دفاتر شركة صغيرة، وتصل معاملات كل يوم على هيئة أسطر نصية غير مرتبة. ستستخدم التعبيرات النمطية للتحقق من صحة المبالغ، واستخراج الأرقام عبر الرمز الذي يسبقها، ووضع علامة على الأسطر التي تحتاج إلى نظرة أدق.

## 1. تحقق من صحة مبلغ

المبلغ الصحيح البنية هو `$` يتبعه رقم واحد أو أكثر، ثم جزء سنتات *اختياري* يتكوّن من نقطة تليها رقمان بالضبط: `$100` أو `$100.50`، وليس `$100.5`. عرّف `valid-amount?`، بحيث تُرجع `t` عندما تكون السلسلة *كاملةً* مبلغًا صحيح البنية.

```factor
"$100.50" valid-amount? .   ! => t
"$100"    valid-amount? .   ! => t
"$100.5"  valid-amount? .   ! => f
```

## 2. استخرج مبالغ الدولار

عرّف `dollar-amounts`، بحيث تُرجع كل عدد يلي `$` مباشرةً في السطر، الأرقام فقط دون `$`، بالترتيب.

```factor
"spent $100 and $25 today" dollar-amounts .
! => { "100" "25" }
```

## 3. استخرج النسب المئوية

عرّف `percentages`، بحيث تُرجع كل عدد تليه `%` مباشرةً.

```factor
"up 5% then down 12%" percentages .
! => { "5" "12" }
```

## 4. ضع علامة على سطر

عرّف `flagged?`، بحيث تُرجع `t` عندما يذكر السطر `refund` أو `chargeback` بأي مزيج من الحروف الكبيرة والصغيرة.

```factor
"Issued a REFUND today" flagged? .   ! => t
"a normal sale"         flagged? .   ! => f
```
