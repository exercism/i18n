# مقدمة

## الخصائص

الخاصية في C# هي عضو في صنف يوفّر الوصول إلى البيانات داخل ذلك الصنف.
يمكن لمن يستدعي الخاصية أن يعيّن البيانات أو يسترجعها (`get`). يمكن أن تكون الخصائص منفّذة تلقائيًا أو أن يكون لها حقل داعم. تتكوّن من مُوصِّل `set` و/أو مُوصِّل `get`.
في بعض اللغات الأخرى، يكون "mutator" مكافئًا تقريبًا لمُوصِّل `set`، ويكون "accessor" مكافئًا تقريبًا لمُوصِّل `get`، وإن كانت بنية الصياغة مختلفة تمامًا.

عند تعيين قيمة خاصية، يمكن التحقق من القيمة المُدخلة أو تنسيقها أو معالجتها بأي طريقة أخرى، بل يمكن تنفيذ أي عملية برمجية يمكن للكود في الصنف الوصول إليها.

وبالمثل، عند استرجاع قيمة خاصية، يمكن حساب البيانات أو تنسيقها، ومرة أخرى يمكن تنفيذ أي عملية برمجية متاحة للصنف.

للخصائص معدّلات وصول (`public`، `private` وغيرها) تمامًا مثل بقية أعضاء الصنف، لكن قد يكون لمُوصِّل `set` مستوى وصول مستقلًا عن مُوصِّل الاسترجاع (`get`)، والعكس صحيح. ولا يلزم أن تحتوي الخاصية على كلا المُوصِّلين، بل يمكن أن تحتوي على واحد فقط (إما `get` أو `set`).

يمكن أن تأخذ الصيغة الأساسية للتعبير عن الخصائص شكلين:

### الخصائص المدعومة بحقل/تعبير:

```csharp
private int myField;
public int MyProperty
{
    get { return myField; }
    set { myField = value; }
}
```

### الخصائص المنفّذة تلقائيًا

```
public int MyProperty { get; private set; } = 42;
```
