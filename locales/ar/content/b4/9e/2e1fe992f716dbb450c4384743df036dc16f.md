# ملحق التعليمات

## السجلات

| السجل | الاستخدام | النوع | الوصف |
| -------- | --------- | ------- | ------------------------------------------------------------------------------------- |
| `$a0`    | مدخل     | عدد صحيح | عدد                                                                                |
| `$v0`    | مخرج     | عدد صحيح | تصنيف (`1` = `perfect`، `2` = `abundant`، `3` = `deficient`، `-1` = `error`) |
| `$t0-9`  | مؤقت     | أي     | يُستخدم للتخزين المؤقت                                                            |
