# حول العوامل الحسابية

## العوامل

تدعم لغة Go العوامل الحسابية التالية:

| العامل | المثال |
| -------- | -------------- |
| `+`      | `4 + 6 == 10`  |
| `-`      | `15 - 10 == 5` |
| `*`      | `2 * 3 == 6`   |
| `/`      | `13 / 3 == 4`  |
| `%`      | `13 % 3 == 1`  |

في القسمة الصحيحة، يُهمَل الباقي (على سبيل المثال `5 / 2 == 2`).

يدمج العامل `+` أيضًا السلاسل النصية: `"foo" + "bar" == "foobar"`.

## العمليات الحسابية بين الأنواع المختلفة

لا تسمح لغة Go بإجراء عمليات حسابية بين أنواع عددية مختلفة:

```go
x := 42
n := 2.0
value := n * x // invalid operation: n * x (mismatched types float64 and int)
```

يجب أن يكون الطرفان من النوع نفسه، مما يتطلب أحيانًا تحويلًا صريحًا:

```go
x := float64(42)
n := 2.0
value := n * x 
```

## الإسناد المختصر

لكل عامل صيغة إسناد مختصرة تحدّث المتغير في مكانه:

```go
a := 1
a += 2 // same as a = a + 2 == 3

b := 2
b -= 2 // same as b = b - 2 == 0

c := 4
c *= 2 // same as c = c * 2 == 8

d := 8
d /= 2 // same as d = d / 2 == 4

e := 16
e %= 2 // same as e = e % 2 == 0
```

## الزيادة والنقصان

عند وضعهما بعد متغير، فإن عبارتي الزيادة (`++`) والنقصان (`--`) تزيدان أو تنقصان قيمته العددية المخزنة بمقدار 1.
وضعهما قبل متغير خطأ نحوي.

```go
a := 10
a++ // same as a += 1, a == 11

b := 10
b-- // same as b -= 1, b == 9
```

لأنهما عبارتان، فإنهما لا تُرجعان قيمة.
