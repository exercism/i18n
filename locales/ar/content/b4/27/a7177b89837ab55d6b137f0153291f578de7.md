## المتغيرات

المتغيرات أسماء رمزية تشير إما إلى قيم أو إلى حاويات.
قد يبدأ اسم المتغير بحرف خاص يُسمى [sigil][sigils] أو بدونه، يتلوه معرّف.
وقد يتبعه ما يُعرف بـ [twigil][twigils].

المتغيرات ذات علامات sigil المختلفة تحمل أنواعًا مختلفة من بنى البيانات.

```raku
my $scalar; # Assigned value will be stored as-is
my @array;  # Assigned value will be coerced into an array
my %hash;   # Assigned value will be coerced into a hash
my &code;   # Assigned value must be a code object
```

من الـtwigils التي ستراها كثيرًا `^` و`:`, وهما يعملان كاختصارات لتوقيعات كتل الكود.
الـ`^` مخصص للمعاملات الموضعية.
والـ`:` مخصص للمعاملات المسماة.

```raku
{ $^a + $^b }; #`[same as] ->  $a,  $b { $a + $b }; # Called with (1, 2)
{ $:a + $:b }; #`[same as] -> :$a, :$b { $a + $b }; # Called with (a => 1, b => 2)
```

## الحاويات

الحاويات هي ما يسمح بتعديل المتغير.

المتغيرات المُعلنة بـ`constant`، والمتغيرات بلا sigil (المُعلنة بشرطة مائلة `\` قبل المعرّف)، ليس لها حاويات، بل تشير إلى القيم مباشرة.

```raku
my $foo = 1;
$foo = 2;

constant $bar = 3;
my \baz = 4;

# The following will fail
$bar = 5;
baz  = 6;
```

## الأنواع

يمكن تعريف المتغيرات بقيد نوع.
ويمكن أن تتضمن قيود الأنواع تحويلات أيضًا، بإعطاء نوع مقبول كوسيط للنوع المطلوب.

```raku
my Bool   $foo = True; # Booleans only.
my Bool() $bar = 0;    # Accepts type `Any`. Coerced to False.

my Str(Bool(Int)) $baz;
$baz = 1;   # "True"
$baz = "1"; # "1"
```

يُعدّ استخدام قيود الأنواع أحد أساليب الاستفادة من الإجراءات متعددة الإرسال.

```raku
multi foo (Int $bar) { say 'Type of arg to $bar is Int!' }
multi foo (Str $bar) { say 'Type of arg to $bar is Str!' }
```

الأنواع في Raku ليست إلا نوعًا آخر من الكائنات.
ويُعدّ تعريف `class` أو `role` أو `enum` من طرق إنشاء كائنات أنواع خاصة بك.
على سبيل المثال، النوع المدمج `Bool` مبني باستخدام enum: `enum Bool <False True>`.

يمكنك أيضًا إنشاء قيود أنواع بسيطة مبنية على أنواع أخرى باستخدام الكلمة المفتاحية `subset`.
ويمكنك زيادة تقييد هذا النوع الجديد باستخدام جملة `where`.
ويمكن أيضًا استخدام جملة `where` في التوقيع.

```raku
subset PositiveInt of Int where * > 0;

sub is-even (PositiveInt $n where  %% 2) { say "$n is even!" }
```
