# ملحق التعليمات

يتطلب رفع الأعداد المركبة إلى قوى وجود دالة أسية ودالة جيب ودالة جيب تمام، وليس أي منها متاحًا في WebAssembly. لحسن الحظ، يمكن استخدام [متسلسلة تايلور](https://en.wikipedia.org/wiki/Taylor_series) لحسابها. ينبغي أن تحصل على دقة `1/26!` على الأقل لتتوافق مع القيم المتوقعة.

## الدالة الأسية

```
exp(x) ≃ 1 + x + x ^ 2 / 2! + x ^ 3 / 3! + x ^ 4 / 4! + ... + x ^ n / n!
```

## دالة الجيب

```
sin(x) ≃ x - x ^ 3 / 3! + x ^ 5 / 5! - x ^ 7 / 7! + ... - x ^ n / n!
```

## دالة جيب التمام

```
cos(x) ≃ 1 - x ^ 2 / 2! + x ^ 4 / 4! - x ^ 6 / 6! + ... - x ^ n / n!
```
