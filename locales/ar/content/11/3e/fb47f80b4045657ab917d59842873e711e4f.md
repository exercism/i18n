# مقدمة

رأينا في المفاهيم السابقة أن الأنواع في Julia تشكّل تدرجًا هرميًا، يقع `Any` في قمته.

الأنواع المجردة مثل `Number` لها أنواع فرعية، لكن لا يمكن إنشاؤها هي نفسها.
إسناد متغير إلى نوع مجرد _يقيّد_ قيم المتغير لتكون أي نوع فرعي من النوع المجرد.
على سبيل المثال:

```julia-repl
julia> x::Number = 3
3

julia> typeof(x)  # one subtype of Number
Int64

julia> x = 4.2
4.2

julia> typeof(x) # another subtype of Number
Float64

julia> x = "fail" # not a number type!
ERROR: MethodError: Cannot `convert` an object of type String to an object of type Number
```

يمنحنا هذا نوعًا واحدًا من المرونة في تقييد المدخلات الصالحة.

لكن لنفترض أننا نريد لمتغير أن يقبل قيمًا صحيحة وقيمًا نصية معًا؟
فهذان النوعان ليسا في الفرع نفسه من التدرج.

يمكننا ضبط النوع على `Any`، أو تركه يأخذ ذلك افتراضيًا، لكننا عندئذ نفقد كل التحكم في الأنواع المسموح بها.

ولأسلوب أفضل، لدينا صيغة `Union{ }`، التي تُدرَج فيها أنواع اثنان أو أكثر بين الأقواس المعقوفة.

```julia-repl
julia> y::Union{Integer, String} = 4
4

julia> typeof(y)
Int64

julia> y = "works"
"works"

julia> typeof(y)
String

julia> y = 5.3
ERROR: MethodError: Cannot `convert` an object of type 
  Float64 to an object of type 
  Union{Integer, String}
```

مثال آخر يستخدم اتحاد الأنواع نفسه في توقيع دالة:

```julia-repl
julia> IntOrString = Union{Integer, String}
Union{Integer, String}

julia> f(z::IntOrString) = z^3
f (generic function with 1 method)

julia> f(2) # integers are cubed
8

julia> f("ab") # strings are repeated 3 times
"ababab"
```

هنا أعطينا النوع اسمًا، وهو ما قد يوفّر اختصارًا مريحًا لكنه ليس ضروريًا تمامًا.
الدالة `g(z::Union{Integer, String}) = z^3` تتصرف بالطريقة نفسها.

سيكون لدينا الكثير لنقوله عن تواقيع الدوال في مفهوم الإرسال المتعدد.

## الاتحادات مع العدم

لعدة لغات أخرى أنواع قد تحتوي قيمة أو لا تحتوي، بأسماء مثل `Option` و`Nullable` و`Maybe`.

لا تملك Julia صيغة خاصة لهذا، لكن اتحادات الأنواع تعميم للفكرة نفسها.

رأينا في مفهوم `Nothingness` أن Julia لديها طرق متعددة لتمثيل القيم غير الموجودة، منها `nothing` و`missing`.
يمكن إدراج أي منهما في اتحاد أنواع.

على سبيل المثال، عند تعريف نوع من القوائم المترابطة، نحتاج إلى وسيلة لإنهاء القائمة إذا لم تعد هناك عُقد.
النوع `Nothing` هو النوع الذي قيمته الوحيدة `nothing`، وهذا التعريف للعقدة `Node` يجعل من الممكن الإشارة إلى نهاية القائمة:

```julia-repl
julia> struct Node
           value::Any
           next::Union{Node, Nothing}
       end
```

وبالمثل، يمكن استخدام `missing` كعنصر نائب للقيم الغائبة، خاصة في المجموعات مثل المتجهات.
المثال أدناه مصطنع للغاية، لكن القيم المفقودة شائعة في مجموعات البيانات الواقعية.

```julia-repl
julia> q(x::Real) = x >= 0 ? sqrt(x) : missing  # skip negative values
q (generic function with 1 method)

julia> vals::Vector{Union{Real, Missing}} = q.([4, 3.1, -1, 0])
4-element Vector{Union{Missing, Float64}}:
 2.0
 1.760681686165901
  missing
 0.0
```
