# التعليمات

تكون نقاط نهاية HTTP أفضل مع التحقق من الأنواع. إضافة نوع سجل إلى طلب POST تضمن إرسال البيانات الصحيحة في كل مرة.

## الأهداف

- عدّل الكود المقدم.
- أضف السمات اللازمة إلى هذا السجل لقبول قيمتين وعامل.
- أضف دالة مورد HTTP لقبول طلب POST على المسار '/calc'
- يجب أن تقبل الدالة نوع السجل Calculation كحمولة وتُرجع كائن JSON عام

### المدخلات

```json
{ "operand1": 4, "operand2": 10.2, "operator": "+" }
```

### المخرجات

```json
{ "expression": "4+10.2", "result": 14.2 }
```
