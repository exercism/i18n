# Tests

لتشغيل الاختبارات من سطر الأوامر، نفّذ الأمر التالي من مجلد التمرين:

```bash
java -jar /path/to/mars.jar nc runner.mips impl.mips
```

## الواجهة الرسومية

لتشغيل الاختبارات عبر الواجهة الرسومية لمحاكي MARS، أضف تنفيذك إلى أسفل ملف `runner.mips` باستخدام `include`، وذلك بإزالة التعليق عن السطر الأخير.
