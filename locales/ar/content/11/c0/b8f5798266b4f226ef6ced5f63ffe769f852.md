# حول

## التكرار على المصفوفة

تسمح حلقة `for` بالتكرار على مصفوفة وتنفيذ الكود لكل عنصر:

```haxe
var fruitList = ["apple", "banana", "pear"];

for (fruit in fruitList) {
  trace(fruit);
}

// apple
// banana
// pear
```

في المثال أعلاه، `fruit` هو المتغير الذي يحمل قيمة عنصر واحد من المصفوفة `fruitList`. يتحقق المترجم من إمكانية التكرار على `fruitList`، وإلا فسيوقف التنفيذ.

## التكرار على المدى

يمكنك التكرار على الأعداد باستخدام عامل المدى. يأخذ هذا العامل قيمتين من النوع `Int` ويُكتب بالشكل `min...max`. قيمة `min` مشمولة وقيمة `max` غير مشمولة (`min` <= i و `max` > i)

```haxe
for (i in 0...10) {
  trace(i); // from 0 to 9
}
```

## التكرار على أزواج المفتاح والقيمة

من الممكن التكرار على مجموعات من أزواج المفتاح والقيمة. الفرق الوحيد في الصياغة هو أنه بدلًا من متغير واحد، يُستخدم معرّف متغير المفتاح، يتبعه `=>`، ثم معرّف متغير القيمة:

```haxe
var map = [1 => 101, 2 => 202, 3 => 303];

for (k => v in map) {
  trace(key, value);
}

// 1, 101
// 2, 202
// 3, 303
```
