# التعليمات

بنى أندرو، وهو مطوّر في شركته، مؤخرًا أداة خفيفة لتوليد استعلامات SQL من أجل أداة ترحيل قواعد البيانات.
عمل تنفيذه الأولي الساذج على نحو مثالي مع مجموعات البيانات الصغيرة.
غير أنه أثناء عمليات الترحيل الكبيرة في بيئة الإنتاج، بدأ التطبيق يستهلك ذاكرة مفرطة وعانى تحت الحمل الثقيل.
وبعد تحليل أداء التطبيق، أدرك أندرو أن دمج السلاسل النصية التقليدي داخل الحلقات كان يجبر Go على إعادة تخصيص الذاكرة باستمرار.
والآن يحتاج إلى مساعدتك لإعادة هيكلة الأداة باستخدام `strings.Builder` من Go، حتى يتوسّع التطبيق جيدًا ويتعامل مع كميات كبيرة من النصوص دون أن يسحق ذاكرة الكومة.

## 1. توليد استعلامات SELECT

نفّذ الدالة `BuildSelectQuery`.
تأخذ الدالة اسم جدول (`string`) وشريحة من أسماء الأعمدة (`[]string`).
وينبغي أن تُرجع عبارة `SELECT` مكتملة بصيغة SQL تنتهي بفاصلة منقوطة.
وإذا كانت شريحة الأعمدة فارغة أو كانت `nil`، فعلى الاستعلام أن يعود إلى استخدام محرف البدل `*` لاختيار كل الأعمدة.

```go
columns := []string{"id", "name", "email"}
BuildSelectQuery("users", columns)
// Function return: "SELECT id, name, email FROM users;"

BuildSelectQuery("orders", nil)
// Function return: "SELECT * FROM orders;"
```

## 2. توليد عبارات INSERT دفعة واحدة

نفّذ الدالة `BuildBatchInserts`.
تأخذ الدالة اسم جدول (`string`) وشريحة ثنائية الأبعاد تمثّل صفوف قاعدة البيانات (`[][]ColumnValue`).
يربط كل عنصر في الصف اسم عمود محدد بقيمته النصية.
ويجب أن تُرجع الدالة شريحة من سلاسل نصية منفصلة، كل منها عبارة `INSERT` بصيغة SQL.
ويضمن تنسيق الشريحة المهيكل ترتيبًا متوقعًا وثابتًا لمخرجات الاستعلام.
إذا كانت شريحة الصفوف المُدخلة فارغة، فأرجع شريحة سلاسل نصية فارغة.
وإذا كان أي صف منفرد فارغًا، فتخطَّه.
ويجب أن تُحاط القيم النصية داخل بند `VALUES` بعلامتي تنصيص مفردتين `'`.

```go
rows := [][]ColumnValue{
    {
        {Column: "title", Value: "Book"},
        {Column: "price", Value: "100"},
    },
    {
        {Column: "title", Value: "Magazine"},
        {Column: "price", Value: "15"},
    },
}

BuildBatchInserts("products", rows)
// Function returns string slice: [
//   "INSERT INTO products (title, price) VALUES ('Book', '100');",
//   "INSERT INTO products (title, price) VALUES ('Magazine', '15');"
// ]
```
