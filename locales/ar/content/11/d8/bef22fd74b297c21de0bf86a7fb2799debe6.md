# التعليمات

أنت ضابط المراقبة على متن سفينة تعبر مضيق بيرينغ. ثلاثة مصادر تُعلن عن موقع كل طوف جليدي ورأس أرض في مرمى النظر:

- **مكتب الخرائط** يتكلم بجهات البوصلة: `north`، `east`، `south`، `west`. اتجاه فقط، دون مسافة.
- **الملّاح** يتكلم بإحداثيات *قطبية* انطلاقًا من آخر تحديد لموقع السفينة: مقدار بالميل البحري، وزاوية بالدرجات باتجاه عقارب الساعة من الشمال (حيث `0` شمال، و`90` شرق، و`180` جنوب، و`270` غرب).
- **المراقب في قمة الصاري** يتكلم بإحداثيات *نسبية*: مسافة إلى الأمام، وواحدة من `ahead`، `starboard`، `behind`، `port`. تُقاس الاتجاهات النسبية مقابل *اتجاه السفينة الحالي*، وهو اتجاه يعلنه القبطان على الجسر قبل كل نوبة.

مهمتك تحويل هذه الأنواع الثلاثة إلى إطار ديكارتي مشترك `(x, y)` حتى يمكن رسم الخريطة. الاتجاهات بالدرجات؛ `(0, 1)` تعني ميلًا بحريًا واحدًا نحو الشمال، و`(1, 0)` ميلًا بحريًا واحدًا نحو الشرق.

## 1. نموذج البيانات، والتحويل الديكارتي للاتجاه الأصلي

أولًا، عرّف الأجزاء التي تشترك فيها التمرين كله:

- عرّف ثلاثة صفوف: `cardinal` (خانة واحدة، `direction`)، و`polar` (خانتا `magnitude` و`bearing`)، و`relative` (خانتا `distance` و`bearing`).
- أعلن رموز الاتجاهات باستخدام `SYMBOLS:`: `north`، `east`، `south`، `west`، `ahead`، `starboard`، `behind`، `port`.
- أعلن متغيرًا ديناميكيًا باسم `heading` باستخدام `SYMBOL:` (المهمة 3 تستخدمه).
- أعلن كلمتين عامّتين، `GENERIC: >cartesian ( direction -- x y )` و`GENERIC: flip ( direction -- direction' )`. ستضيف طرائقهما في المهام التالية.

ثم أضف الطريقة `M: cardinal` للكلمة `>cartesian`، بحيث تُرجع متجه الوحدة للاتجاه المسمّى.

```factor
T{ cardinal { direction north } } >cartesian . .
! => 1
! => 0
! (top of stack is `y`, just below it is `x`)
```

## 2. التحويل الديكارتي للإحداثيات القطبية

أضف الطريقة `M: polar` إلى `>cartesian`، وهي تحوّل الصيغة القطبية إلى `(x, y)`:

```
x = magnitude * sin(bearing-in-radians)
y = magnitude * cos(bearing-in-radians)
```

```factor
T{ polar { magnitude 10 } { bearing 90 } } >cartesian . .
! => 0   (close to zero — the cosine of π/2 isn't exactly 0 in floats)
! => 10
```

## 3. التحويل الديكارتي للإحداثيات النسبية

أضف الطريقة `M: relative` إلى `>cartesian`. وهنا المفاجأة: الاتجاه النسبي يُقاس مقابل *اتجاه السفينة الحالي*، وهو ليس جزءًا من الصف. اقرأ المتغير `heading` (المعلن في المهمة 1) عبر `heading get`، وأضف إزاحة الاتجاه (`ahead = 0`، `starboard = 90`، `behind = 180`، `port = 270`)، ثم أنتج النقطة الديكارتية. ويضبط المستدعي قيمة `heading` داخل كتلة `with-variable`.

```factor
0 heading [
    T{ relative { distance 5 } { bearing starboard } } >cartesian
] with-variable . .
! => 0   (heading 0 is north; starboard is east; (5, 0))
! => 5
```

## 4. `flip`

أضف طرائق الكلمة العامة `flip` (المعلنة في المهمة 1) بحيث تُرجع الاتجاه المعاكس.

- بالنسبة إلى `cardinal`: north ↔ south، وeast ↔ west.
- بالنسبة إلى `polar`: أضف 180° إلى الاتجاه (باقي القسمة على 360).
- بالنسبة إلى `relative`: ahead ↔ behind، وstarboard ↔ port.

```factor
T{ cardinal { direction north } } flip .
! => T{ cardinal { direction south } }

T{ polar { magnitude 10 } { bearing 90 } } flip .
! => T{ polar { magnitude 10 } { bearing 270 } }

T{ relative { distance 5 } { bearing ahead } } flip .
! => T{ relative { distance 5 } { bearing behind } }
```

## 5. جمع الاتجاهات

عرّف `add-bearings ( a b -- x y )` بحيث تحوّل كلا الاتجاهين إلى إحداثيات ديكارتية وتُرجع مجموعهما. وهي تعمل مع أي مزيج من `cardinal` و`polar` و`relative`، وهذا هو ثمرة استخدام كلمة عامة من أجل `>cartesian`.

```factor
T{ cardinal { direction north } } T{ cardinal { direction east } } add-bearings . .
! => 1
! => 1
```
