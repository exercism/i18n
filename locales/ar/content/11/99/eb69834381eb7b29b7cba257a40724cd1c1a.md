# مقدمة

يُمثّل النوع `enum` في C# مجموعة ثابتة من الثوابت المسماة (أي تعداد). وغرضه الأساسي هو توفير طريقة آمنة من حيث النوع للتعامل مع الثوابت العددية، مع حصر القيم المتاحة في مجموعة محددة مسبقًا. يمكن تعريف تعداد بسيط كما يلي:

```csharp
enum Season
{
    Spring,
    Summer,
    Autumn,
    Winter
}
```

إذا لم تُعرَّف صراحةً، فسيتم إسناد قيم عددية صحيحة متزايدة تلقائيًا إلى أعضاء التعداد، وتكون القيمة الأولى صفرًا. ومن الممكن أيضًا إسناد القيم صراحةً:

```csharp
enum Answer
{
    Maybe = 1,
    Yes = 3,
    No = 5
}
```
