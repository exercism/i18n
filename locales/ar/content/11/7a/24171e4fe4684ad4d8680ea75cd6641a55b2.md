## التعليمات

لقد وظّفك مركز لإعادة التدوير.
بسبب نقص المساحة، تُوضع جميع المنتجات على الحزام الناقل نفسه، لكن هذا أدى إلى اختلاط مواد مختلفة معًا، مما جعلها غير قابلة للاستخدام.
لحل هذه المشكلة، أُوكلت إليك مهمة إنشاء دوال لتحديد نوع المنتج.

### 1. تحقّق مما إذا كانت القيمة قيمة منطقية

نفّذ الدالة `isBoolean`، التي تتحقق مما إذا كانت القيمة قيمة منطقية.

```javascript
isBoolean(true);
// => true

isBoolean(null);
// => false
```

### 2. تحقّق مما إذا كانت القيمة عددًا.

نفّذ الدالة `isNumber`، التي تتحقق مما إذا كانت القيمة `number` أو `bigint` _منتهية_، أي ليست `NaN` أو `Infinity`.

أحيانًا، يفشل جهاز قراءة المعرّفات ويقرأ قيمة غير رقمية على أنها `NaN` (ليس عددًا) أو `Infinity`.
وينبغي أن تتعامل دالتك مع هذا بشكل صحيح أيضًا.

```javascript
isNumber(42);
// => true

isNumber('Hello, World!');
// => false

isNumber(42n);
// => true

isNumber(NaN);
// => false
```

### 3. تحقّق مما إذا كانت القيمة كائنًا

نفّذ الدالة `isObject`، التي ينبغي أن تتحقق مما إذا كانت القيمة كائنًا.
على الحزام الناقل، `null` ليس شيئًا ولا يُعتبر كائنًا.

```javascript
isObject({ greeting: 'Hello' });
// => true

isObject(25n);
// => false
```

### 4. تحقّق مما إذا كانت السلسلة النصية رقمية

نفّذ الدالة `isNumericString`، التي ينبغي أن تتحقق مما إذا كانت القيمة سلسلة نصية تتكوّن فقط من أرقام، أو من إشارة ناقص متبوعة بأرقام تشير إلى عدد سالب.
يجب أن نتعامل مع الأعداد الصحيحة فقط؛ فلا تُعتبر الأعداد العشرية رقمية في هذا الفحص الخاص بروبوت إعادة التدوير.

```javascript
isNumericString(42);
// => false

isNumericString('42');
// => true

isNumericString('Hi!');
// => false
```

### 5. تحقّق مما إذا كان الكائن إلكترونيًا

نفّذ الدالة `isElectronic`، التي تتحقق مما إذا كان الكائن نسخة من الصنف `ElectronicDevice` المزوّد أو من أحد أصنافه الفرعية.

```javascript
class Duck {
  //...
}

class WashingMachine extends ElectronicDevice {
  //...
}

isElectronic(new Duck());
// => false

isElectronic(new WashingMachine());
// => true
```

### 6. تحقّق مما إذا كانت القيمة مصفوفة غير فارغة

نفّذ الدالة `isNonEmptyArray`، التي تتحقق مما إذا كانت القيمة مصفوفة غير فارغة.

```javascript
isNonEmptyArray([1, 2, 3]);
// => true

isNonEmptyArray([]);
// => false
```

### 7. تحقّق مما إذا كانت القيمة مصفوفة فارغة

نفّذ الدالة `isEmptyArray`، التي تتحقق مما إذا كانت القيمة مصفوفة فارغة.

```javascript
isEmptyArray([1, 2, 3]);
// => false

isEmptyArray([]);
// => true
```

### 8. تحقّق مما إذا كان للكائن خاصية أو طريقة باسم `type`

نفّذ الدالة `hasType`، التي تتحقق مما إذا كان للكائن خاصية أو طريقة باسم `type`.

```javascript
class Keyboard(){
  type(){
    // ...
  }
}
hasType({ type:"car", color:"red" })
// => true

hasType({ color:"green" })
// => false

hasType(new Keyboard())
// => true
```

### 9. ارمِ خطأً إذا لم يكن للكائن خاصية أو طريقة باسم `id`

نفّذ الدالة `assertHasId`، التي سترمي خطأ من نوع `Error` إذا كان الكائن يفتقد الخاصية `id`.

وإذا كان للكائن الخاصية `id` بالفعل، فلا ينبغي أن تُرجع أي شيء.

```javascript
assertHasId({ id: 42, color: 'red' });
// => undefined

assertHasId({ color: 'green' });
// Error: "Object is missing the 'id' property"
```

### 10. تحقّق مما إذا كان للكائن خاصية باسم `id`

نفّذ الدالة `hasIdProperty`، التي تتحقق مما إذا كان للكائن خاصية `id`.

```javascript
class SimpleData {
  constructor() {
    this.number = '42';
    this.id = 'BC269327FE1D9B95';
  }
}

class StealingData extends SimpleData {}

class MethodData {
  constructor() {
    this.number = '42';
    this._id = 'BC269327FE1D9B95';
  }

  get id() {
    return this._id;
  }
}

hasIdProperty(new SimpleData());
// => true

hasIdProperty(new MethodData());
// => false

hasIdProperty(new StealingData());
// => false
```

### 11. تحقّق مما إذا كان للكائن خاصية `type` معرّفة

نفّذ الدالة `hasDefinedType`، التي تتحقق مما إذا كان للكائن خاصية `type` لا تساوي `undefined`.

```javascript
hasDefinedType({ type: undefined, color: 'red' });
// => false

hasDefinedType({ type: 'car', color: 'green' });
// => true
```
