# حول

`TUPLE:` يعرّف صنفًا له خانات مسماة. يولّد Factor تلقائيًا كلمة إنشاء (مع إضافة اللاحقة `new` إلى اسم الصنف)، وكلمة إنشاء `boa` («حسب ترتيب الوسائط»)، وصيغة حرفية `T{ class … }`، وكلمات وصول لكل خانة.

```factor
TUPLE: player
    { name initial: f }
    { level initial: 0 }
    { health initial: 100 } ;

player new .                                    ! T{ player }
3 100 "Merlin" player boa .                     ! by-order construction
T{ player { name "Merlin" } { health 50 } } .   ! literal syntax
```

يوفر نظام الوصول في [`accessors`][accessors] أربع صيغ لكل خانة: `name>>`، و`>>name`، و`change-name`، والزوج المعدِّل `[ … ] change-name`. تعدّل `>>name` و`change-name` الصف؛ استخدم `clone` أولًا عندما تحتاج إلى ترك الأصل دون تغيير.

تدعم الصفوف `=` بالمساواة البنيوية، وتُطبع مع إظهار قيم خاناتها غير الافتراضية.

[accessors]: https://docs.factorcode.org/content/vocab-accessors.html
