# التعليمات

تدير مركز أرصاد جوية صغيرًا على ضفاف نهر فلتافا في براغ، وفي كل وردية تدوّن قراءات درجة الحرارة في سجل نصي بسيط، قراءة واحدة في كل سطر. خمس كلمات صغيرة تتولى كل ما يلزم وردية واحدة من التسجيل.

تُمرَّر إلى كل كلمة مسار ملف السجل.

## 1. اقرأ كل قراءة

عرّف `read-readings` لتُرجع جميع قراءات السجل على هيئة مصفوفة من السلاسل النصية، قراءة واحدة في كل سطر.

```factor
"weather.log" read-readings .
! => { "21.5" "19.0" "22.3" }
```

## 2. اعثر على أحدث قراءة

عرّف `latest-reading` لتُرجع أحدث قراءة، وهي آخر سطر في السجل.

```factor
"weather.log" latest-reading .
! => "22.3"
```

## 3. اقرأ السجل الخام

عرّف `log-text` لتُرجع ملف السجل كاملًا على هيئة سلسلة نصية واحدة، تمامًا كما هو مخزّن.

```factor
"weather.log" log-text .
! => "21.5\n19.0\n22.3\n"
```

## 4. سجّل قراءة

عرّف `record-reading` لتُضيف قراءة جديدة إلى نهاية السجل في سطر خاص بها، دون المساس بالقراءات السابقة. ولا تُرجع أي شيء.

```factor
"23.1" "weather.log" record-reading
"weather.log" log-text .
! => "21.5\n19.0\n22.3\n23.1\n"
```

## 5. أعد كتابة السجل

عرّف `rewrite-log` لتستبدل السجل كاملًا بمصفوفة جديدة من القراءات، قراءة واحدة في كل سطر.

```factor
{ "10.0" "11.0" } "weather.log" rewrite-log
"weather.log" log-text .
! => "10.0\n11.0\n"
```
