# التعليمات

في هذا التمرين، ستكتب كودًا لتتبّع أفضل النقاط لأكثر لعبة شعبية في صالة الألعاب القريبة منك.

لديك 5 دوال لتُنفّذها، ومعظمها يتعلق بالتعامل مع كائن يحمل أفضل النقاط.

## 1. أنشئ لوحة أفضل نقاط جديدة

أنشئ دالة `createScoreBoard` تُنشئ كائنًا يعمل كلوحة أفضل النقاط.
ستكون مفاتيح هذا الكائن أسماء اللاعبين، وستكون قيمه نقاطهم.
لأغراض الاختبار، تريد تضمين مدخل واحد مباشرةً في الكائن.
يجب أن يتضمّن هذا المدخل الأولي `The Best Ever` اسمًا للاعب و`1000000` كنقاط.

```javascript
createScoreBoard();
// returns an object with one initial entry
```

## 2. أضف لاعبين إلى لوحة أفضل النقاط

لإضافة لاعب إلى لوحة أفضل النقاط، عرّف الدالة `addPlayer`.
وهي تقبل 3 معاملات:

- المعامل الأول هو كائن لوحة أفضل النقاط موجود.
- المعامل الثاني هو اسم اللاعب كسلسلة نصية.
- المعامل الثالث هو النقاط كعدد.

تُرجع الدالة كائن لوحة أفضل النقاط نفسه الذي مُرّر إليها بعد إضافة اللاعب الجديد.

```javascript
addPlayer({ 'Dave Thomas': 0 }, 'José Valim', 486373);
// => {'Dave Thomas': 0, 'José Valim': 486373}
```

## 3. أزل لاعبين من لوحة أفضل النقاط

إذا خالف اللاعبون قواعد صالة الألعاب، يُزالون يدويًا من لوحة أفضل النقاط.
عرّف `removePlayer`، وهي تقبل معاملين:

- المعامل الأول هو كائن لوحة أفضل النقاط موجود.
- المعامل الثاني هو اسم اللاعب كسلسلة نصية.

يجب أن تُزيل هذه الدالة مدخل اللاعب المحدد من اللوحة، ثم تُرجع اللوحة بعد ذلك.
إذا لم يكن اللاعب موجودًا على اللوحة من الأساس، فلا يحدث أي تغيير في اللوحة، وتُرجَع كما هي.

```javascript
removePlayer({ 'Dave Thomas': 0 }, 'Dave Thomas');
// => {}

removePlayer({ 'Dave Thomas': 0 }, 'Rose Fanaras');
// => { 'Dave Thomas': 0 }
```

## 4. زد نقاط لاعب

إذا أنهى لاعب لعبة أخرى في صالة الألعاب، تُضاف كمية معيّنة من النقاط إلى النقاط السابقة على اللوحة.
نفّذ `updateScore`، وهي تقبل 3 معاملات:

- المعامل الأول هو كائن لوحة أفضل النقاط موجود.
- المعامل الثاني هو اسم اللاعب الذي ينبغي زيادة نقاطه.
- المعامل الثالث هو النقاط التي تريد **إضافتها** إلى أفضل النقاط المخزّنة.

يجب أن تُرجع الدالة لوحة أفضل النقاط بعد إجراء التحديث.

```javascript
updateScore({ 'Freyja Ćirić': 12771008 }, 'Freyja Ćirić', 73);
// => {"Freyja Ćirić", 12771081}
```

## 5. طبّق نقاط مكافأة الاثنين

تحتفظ صالة الألعاب بلوحة أفضل نقاط منفصلة أيام الاثنين.
في نهاية اليوم، يحصل كل لاعب على تلك اللوحة على 100 نقطة إضافية.

نفّذ الدالة `applyMondayBonus` التي تقبل لوحة أفضل النقاط.
تُضيف الدالة نقاط المكافأة لكل لاعب مدرج على تلك اللوحة، ثم تُرجع اللوحة بعد ذلك.

```javascript
const scoreBoard = {
  'Dave Thomas': 44,
  'Freyja Ćirić': 539,
  'José Valim': 265,
};

applyMondayBonus(scoreBoard);
// => { 'Dave Thomas': 144, 'Freyja Ćirić': 639, 'José Valim': 365 }
```
