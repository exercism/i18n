# الاختبارات

نفّذ الاختبارات باستخدام:

```shell
npm run test
```

يمكنك أيضًا تشغيل Jest في وضع "watch"، وهو سيعيد تشغيل اختباراتك تلقائيًا عند حفظ التغييرات في الكود أو وحدة الاختبار:

```shell
npm run watch
```

## فهم تخطّي الاختبارات

تُخبر طريقة `skip` مجموعة الاختبارات بألّا تشغّل اختبارًا معيّنًا، ويمكن استخدام هذه الدالة أيضًا تحت الأسماء البديلة: `it.skip(name, fn)` أو `xit(name, fn)` أو `xtest(name, fn)`

- لماذا يتم تخطّيها؟

لتمكين المستخدمين من التركيز على اختبار واحد في كل مرة، وتفعيلها واحدًا تلو الآخر مع تطوّرهم في الحل.

- كيف تُفعّلها؟

غيّر `xtest` إلى `test`.

```javascript
test("title cased phrases", () => {
  expect(Acronyms.parse("Portable Network Graphics")).toEqual("PNG");
});
```
