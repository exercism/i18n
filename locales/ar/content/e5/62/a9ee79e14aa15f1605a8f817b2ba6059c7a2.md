# مقدمة

*التعبير النمطي* (regex) هو نمط صغير يصف الشكل الذي ينبغي أن يكون عليه نص ما. فبدلًا من فحص سلسلة نصية محرفًا محرفًا بنفسك، تكتب الشكل الذي تريده مرة واحدة وتدع Factor يقوم بالمطابقة. أدوات التعابير النمطية في Factor موجودة في مفردات [`regexp`][regexp].

## كتابة نمط

في Factor تكتب تعبيرًا نمطيًا بين `R/ ` و`/`:

```factor
R/ cat/      ! the pattern that matches the letters c, a, t
```

معظم المحارف في النمط تعني نفسها فحسب، فـ `R/ cat/` يطابق النص `cat`. وتأتي القوة من بضعة أجزاء خاصة تدل على *أنواع* المحارف أو على *عدد* تكرارها.

### أصناف المحارف: «محرف واحد من مجموعة»

```
\d        ! any digit, 0–9
\D        ! any NON-digit (the opposite of \d)
\s        ! any space, tab, or newline
\S        ! any NON-space character (the opposite of \s)
\w        ! a "word" character: a letter, a digit, or an underscore
\W        ! any NON-word character (the opposite of \w)
[A-Z]     ! any one capital letter A to Z
[a-z]     ! any one lowercase letter
[0-9]     ! any one digit (same as \d)
.         ! any single character at all
```

يطابق صنف المحارف محرفًا *واحدًا* فقط. فـ `[A-Z]` يطابق `Q` لكنه لا يطابق `QQ`.

### محددات الكمية: «كم مرة»

ضع أحد هذه *بعد* الجزء لتبيّن عدد المرات التي قد يتكرر فيها:

```
{4}       ! exactly 4 times
{2,5}     ! between 2 and 5 times
+         ! one or more
*         ! zero or more
?         ! zero or one (optional)
```

إذًا `\d{4}` تعني أربعة أرقام متتالية، و`[A-Z]+` تعني حرفًا كبيرًا واحدًا أو أكثر. وبجمعها معًا، يصف `R/ [A-Z]+-\d+/` «حرفًا كبيرًا واحدًا أو أكثر، ثم شرطة، ثم رقمًا واحدًا أو أكثر»، أي نصًا مثل `SALE-2024`. والشرطة `-` هنا محرف عادي: خارج `[ ]` تطابق الشرطة شرطةً فحسب (أما داخل الصنف، كما في `[A-Z]`، فهي تحدد مدًى).

## مطابقة سلسلة نصية كاملة

تُجيب `matches?` عن سؤال «هل تطابق هذه السلسلة النصية *كاملةً* النمط؟»، إذ يجب أن يأخذ النمط في الحسبان كل محرف، من البداية إلى النهاية:

```
matches? ( string regexp -- ? )
```

```factor
USING: regexp ;

"SALE-2024"     R/ [A-Z]+-\d+/ matches? .   ! => t
"GET SALE-2024" R/ [A-Z]+-\d+/ matches? .   ! => f   (extra text before)
"SALE-2024 NOW" R/ [A-Z]+-\d+/ matches? .   ! => f   (extra text after)
"sale-2024"     R/ [A-Z]+-\d+/ matches? .   ! => f   (lowercase letters)
```

فرغم أن `SALE-2024` يقع داخل `"GET SALE-2024"`، تظل `matches?` تقول `f`: فالمحارف الزائدة جزء من السلسلة النصية ولا تطابق النمط. وعندما يهمك فقط ما إذا كان النمط يظهر *في مكان ما*، فاستخدم `re-contains?`، فهي تُرجع `t` تمامًا حيث أرجعت `matches?` القيمة `f`:

```
re-contains? ( string regexp -- ? )
```

```factor
USING: regexp ;

"GET SALE-2024" R/ [A-Z]+-\d+/ matches? .      ! => f
"GET SALE-2024" R/ [A-Z]+-\d+/ re-contains? .  ! => t
```

## العثور على مطابقات داخل نص أطول

تخبرك `re-contains?` فقط *ما إذا* كان النمط موجودًا هناك. أما الكلمات التالية فتنظر إلى الداخل وتخبرك *بما* طابق: تُرجع `all-matching-subseqs` كل موضع يطابق فيه النمط، على هيئة متتالية من السلاسل النصية، بينما تكتفي `count-matches` بعدّها:

```
all-matching-subseqs ( string regexp -- seq )
count-matches        ( string regexp -- n )
```

```factor
USING: regexp ;

"3 cats, 12 dogs, 1 fish" R/ \d+/ all-matching-subseqs .
! => { "3" "12" "1" }            (every run of digits)

"the quick fox" R/ \S+/ all-matching-subseqs .
! => { "the" "quick" "fox" }     (every run of non-space characters)

"id_7!" R/ \w/ count-matches .   ! => 4   (i, d, _ and 7 count; ! does not)
```

## استبدال المطابقات

تستبدل `re-replace` كل مطابقة بقطعة من نص الاستبدال وتُرجع السلسلة النصية الجديدة:

```
re-replace ( string regexp replacement -- result )
```

```factor
USING: regexp ;

"page 7 of 12" R/ \d+/ "N" re-replace .
! => "page N of N"
```

تحتوي مفردات `regexp` على كلمات أخرى تستحق المعرفة. اتبع الروابط للتفاصيل: [`first-match`][first-match] (أول مطابقة فقط) و[`re-split`][re-split] (تقسيم سلسلة نصية عند كل موضع يطابق فيه النمط).
