# نبذة

يصف الارتباط من أين يمكن الوصول إلى المعرّف في الكود.
القيم ذات نطاق الكتلة أو نطاق الدالة أو نطاق النموذج الأولي للدالة ليس لها ارتباط.
وهذا يعني أنه لا يمكن الوصول إليها من خارج نطاقها.
لمزيد من المعلومات حول النطاق، راجع [مفهوم النطاق](../scope/introduction.md#Introduction).

## الارتباط الخارجي

المعرّفات ذات نطاق الملف لها ارتباط خارجي افتراضيًا.
يمكن استدعاء معرّف له ارتباط خارجي من أي ملف في البرنامج.

## الارتباط الداخلي

يمكن جعل معرّف ذي نطاق ملف ذا ارتباط داخلي باستخدام المحدد `static`.
لا يمكن استخدام معرّف له ارتباط داخلي إلا داخل ملفه.

على سبيل المثال

```c
int public_count = 0; // file scope, external linkage by default
static int private_count = 0;  // file scope, internal linkage 

// file scope, internal linkage
static void some_function()
{
    // code snipped
}

// file scope, external linkage by default
int main()
{
    // code snipped
}
```

لا ينبغي الخلط بين الارتباط الساكن ومدة التخزين الساكنة.
لمزيد من المعلومات حول مدة التخزين الساكنة، راجع [مفهوم مدة التخزين](https://github.com/exercism/c/blob/main/concepts/storage-class-specifiers/about.md#static-the-storage-specifier-not-to-be-confused-with-the-static-linkage-type).

إذا أُعلنت قيمة (على عكس دالة) في ملف ترويسة ولكنها عُرّفت في الملف المصدر كمعرّف `static` ذي نطاق ملف وله قيمة مُهيّأة، فلن تكون قيمته المُهيّأة متاحة من خارج ملفه المصدر.
قد تُترجم وتُربط وتُشغَّل دون خطأ، لكن القيمة ستكون القيمة الصفرية للمعرّف، حتى لو أُعلنت القيمة باستخدام `extern`.
(لمزيد من المعلومات حول `extern`، راجع [مفهوم extern](https://github.com/exercism/c/blob/main/concepts/storage-class-specifiers/about.md#extern-how-to-access-a-variable-in-another-translation-unit).)
لا ينبغي إعلان معرّف ذي نطاق ملف وموسوم بـ `static` في الملف المصدر داخل ملف الترويسة الخاص به.
