# الاختبارات

لكل مثال، يجب اتباع الخطوات العامة التالية.

أولًا، انتقل إلى مجلد التمرين الذي تريد التدرب عليه، وهو هنا `bob`.

```bash
$ cd </path/to/exercism>/lfe/bob
```

بعد ذلك شغّل الاختبارات. يعتمد هدف `test` في make على `compile`، لذا فإن تشغيل `make test` يضمن ترجمة مصدرك، ثم ينتقل إلى تشغيل الاختبارات.


```bash
$ make test
```

تهانينا! لديك اختبارات فاشلة!!!

الآن اقرأ `README.md` لتعرف ما عليك فعله لجعل جميع اختباراتك تنجح.


أصلح أول خطأ يبلّغ عنه الاختبار، ثم شغّل الاختبارات مرة أخرى.

```bash
$ make test
```

تابع بإصلاح الاختبار الفاشل التالي في الكود المصدري، وشغّل اختبارك حتى تنجح جميع الاختبارات.

وبعد أن تنجح جميع اختباراتك، ألقِ نظرة أخيرة على الكود في مجلد `src` لتتأكد من رضاك عنه، ثم أرسله للمراجعة.

احصل على الملاحظات، وراجع الحل، وأرسله، ثم جرّب التمرين التالي، وكرّر ذلك حتى تتحقق استنارة LFE.
