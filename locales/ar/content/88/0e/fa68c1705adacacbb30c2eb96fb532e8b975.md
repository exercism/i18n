# مقدمة

## التعبيرات النمطية

تتبع التعبيرات النمطية في Gleam مواصفة **PCRE** (التعبيرات النمطية المتوافقة مع Perl)، شأنها شأن لغات شائعة أخرى مثل Java وJavaScript وRuby.

توفّر وحدة `gleam/regexp` من حزمة `gleam_regexp` دوالً للتعامل مع التعبيرات النمطية.

~~~~exercism/note
يفترض هذا التمرين أنك تعرف بالفعل صيغة التعبيرات النمطية، بما في ذلك فئات الأحرف، ومحددات الكمية، والمجموعات، والالتقاطات.

إذا كنت بحاجة إلى تحديث معرفتك بالتعبيرات النمطية، فاطّلع على أحد هذه المصادر: [Regular-Expressions.info](https://www.regular-expressions.info)، [Rex Egg](https://www.rexegg.com/)، [RegexOne](https://regexone.com/)، [Regular Expressions 101](https://regex101.com/)، [RegExr](https://regexr.com/).
~~~~

الأسلوب الأكثر شيوعًا لإنشاء التعبيرات النمطية هو استخدام الدالة `regexp.from_string`.

```gleam
let assert Ok(re) = regexp.from_string("test")
```

تُرجع دوال إنشاء التعبيرات النمطية خطأً إذا كانت صيغة التعبير النمطي غير صالحة، لذلك استُخدم هنا `let assert` للتأكد من أن التعبير النمطي صالح.

يمكن استخدام الدالة `regexp.check` للتحقق مما إذا كان تعبير نمطي يطابق سلسلة نصية.

```gleam
let assert Ok(re) = regexp.from_string("test")

regexp.check(re, "this is a test")
// -> True

regexp.check(re, "this is too")
// -> False
```


### الالتقاط

إذا أردت التقاط سلاسل نصية فرعية باستخدام تعبير نمطي، فيمكن استخدام الدالة `regexp.scan` لإرجاع مصفوفة من المطابقات.

```gleam
let assert Ok(re) = regexp.from_string("[oi]n a (\\w+)")
regexp.scan(with: re, content: "I am on a boat in a lake.")
// -> [
//   Match(
//     content: "on a boat",
//     submatches: [Some("boat")]
//   ),
//   Match(
//     content: "in a lake",
//     submatches: [Some("lake")]
//   )
// ]
```

### المعدّلات

يمكن تعديل سلوك تعبير نمطي بإنشائه عبر الدالة `regexp.compile` وتمرير الخيارات.

```gleam
let options = regexp.Options(case_insensitive: True, multi_line: False)
let assert Ok(re) = regexp.compile("[A-Z]", with: options)
regexp.check(re, "abc123")
// -> True
```
