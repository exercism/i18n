# الترتيب

ترتيب الأشياء أمر شائع بما يكفي لتتولّاه المكتبة عنك.

```sather
   scores : ARRAY{INT} := |3, 1, 2|;
   scores.sort;              -- 1, 2, 3
```

تعمل `sort` على أي شيء يعرف مسبقًا كيف يقارن نفسه: الأعداد والسلاسل النصية تفعل ذلك، لأن لديها `is_lt`.

## الترتيب وفق قاعدتك الخاصة

معظم الترتيبات ليست الترتيب المدمج. فجدول ترتيب كرة الشبكة ليس أبجديًا ولا حسب طول الاسم، بل حسب النقاط، ثم حسب فارق الأهداف للفرق المتساوية في النقاط. ولا سبيل لـ`ARRAY` إلى تخمين ذلك.

لذا سلّم الترتيب بنفسك، في صورة روتين مرتبط:

```sather
   before(a, b : STR) : BOOL is
      return a.size < b.size;
   end;

   ...

   words.insertion_sort_by(bind(before(_, _)));
```

تأخذ `insertion_sort_by` قيمة `ROUT{T,T}:BOOL`، وهي روتين يأخذ اثنين من العناصر التي تُرتَّب ويجيب عمّا إذا كان الأول يسبق الثاني. وتستدعي ذلك الروتين بالقدر الذي تحتاجه، ثم تضع المصفوفة بالترتيب الذي توحي به الإجابات.

لهذا وُجد `understudy`. فالمكتبة تعرف كيف ترتّب، ولا تعرف شيئًا عن تصوّرك للترتيب؛ والروتين المرتبط هو نقطة التقاء الاثنين.

## كتابة المقارنة

يجيب الروتين بـ**صحيح عندما يأتي الوسيط الأول أولًا**.

```sather
   -- shortest first
   return a.size < b.size;

   -- longest first: turn it round
   return a.size > b.size;
```

وإذا كانت القاعدة تتكوّن من أكثر من جزء، فتعامل مع الأجزاء حسب أهميتها:

```sather
   higher(a, b : TEAM) : BOOL is
      if a.points /= b.points then
         return a.points > b.points;      -- more points comes first
      end;
      return a.difference > b.difference; -- level: better difference wins
   end;
```

تحسم جملة `if` الأولى الأمر كلما اختلفت النقاط. ولا يكون للسطر الثاني رأي إلا عند التساوي. ولو كتبت كسر التعادل أولًا، لما كانت النقاط ذات أثر قط.

## الترتيب يغيّر المصفوفة

ترتّب `insertion_sort_by` المصفوفة نفسها ولا تُرجع شيئًا:

```sather
   teams.insertion_sort_by(bind(higher(_, _)));   -- teams is now sorted
```

وإذا كان الترتيب الأصلي مهمًا، فرتّب نسخة منه:

```sather
   ranked ::= teams.copy;
   ranked.insertion_sort_by(bind(higher(_, _)));
   return ranked;
```
