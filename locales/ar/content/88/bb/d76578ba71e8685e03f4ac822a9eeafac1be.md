# التعليمات

بعد مراجعة أمنية حديثة، طُلب منك تنظيف ملفات السجل المؤرشفة الخاصة بالمؤسسة.

## 1. تحديد أسطر السجل المشوّشة

تحتاج إلى معرفة تقريبية بعدد أسطر السجل في أرشيفك التي لا تتوافق مع المعايير الحالية.
وتعتقد أن اختبارًا بسيطًا يكشف ما إذا كان سطر السجل صالحًا أم لا.
لكي يُعتبر السطر صالحًا، يجب أن يبدأ بأحد السلاسل النصية التالية:

- [DEBUG]
- [INFO]
- [WARNING]
- [ERROR]

نفّذ الدالة `valid_line?/1` لتُرجع `true` إذا كان سطر السجل صالحًا.

```elixir
LogParser.valid_line?("[ERROR] Network Failure")
# => true

LogParser.valid_line?("Network Failure")
# => false
```

## 2. تقسيم سطر السجل

بعد وقت قصير من بدء مشروع تحليل السجلات، تدرك أن سجلات أحد التطبيقات ليست مقسّمة إلى أسطر مثل البقية. في هذا المشروع، ما كان يجب أن يكون أسطرًا منفصلة صار في سطر واحد، متصلًا بأسهم مزخرفة مثل `<--->` أو `<*~*~>`.

في الواقع، أي سلسلة نصية يبدأ محرفها الأول بـ `<` وينتهي محرفها الأخير بـ `>` وتحتوي في ما بينهما على أي مزيج من المحارف التالية `~` و `*` و `=` و `-` يمكن استخدامها فاصلًا في سجلات هذا المشروع.

نفّذ الدالة `split_line/1` التي تأخذ سطرًا وتُرجع قائمة من السلاسل النصية.

```elixir
LogParser.split_line("[INFO] Start.<*>[INFO] Processing...<~~~>[INFO] Success.")
# => ["[INFO] Start.", "[INFO] Processing...", "[INFO] Success."]
```

## 3. إزالة الشوائب من السجل

اكتشفت أن بعض المعالجة الأولية للسجلات كانت تنثر النص "end-of-line" متبوعًا برقم سطر (بدون مسافة فاصلة بينهما) في أنحاء السجلات.

نفّذ الدالة `remove_artifacts/1` لتأخذ سلسلة نصية وتزيل كل ظهورات نص end-of-line (دون اعتبار لحالة الأحرف) وتُرجع سطر سجل نظيفًا.

تُعاد الأسطر التي لا تحتوي على نص end-of-line دون تعديل.

أزل فقط نص end-of-line، فلا حاجة لتعديل المسافات البيضاء.

```elixir
LogParser.remove_artifacts("[WARNING] end-of-line23033 Network Failure end-of-line27")
# => "[WARNING]  Network Failure "
```

## 4. وسم الأسطر بأسماء المستخدمين

لاحظت أن بعض أسطر السجل تتضمن جملًا تشير إلى مستخدمين.
تحتوي هذه الجمل دائمًا على السلسلة النصية `"User"`، متبوعة بمحرف مسافة بيضاء واحد أو أكثر، ثم اسم مستخدم.
فتقرر وسم مثل هذه الأسطر.

نفّذ الدالة `tag_with_user_name/1` التي تعالج أسطر السجل:

- الأسطر التي لا تحتوي على السلسلة النصية `"User"` تبقى دون تغيير.
- الأسطر التي تحتوي على السلسلة النصية `"User"`، أضف إليها في البداية `[USER]` متبوعًا باسم المستخدم.

```elixir
LogParser.tag_with_user_name("[INFO] User Alice created a new project")
# => "[USER] Alice [INFO] User Alice created a new project"
```

يمكنك أن تفترض ما يلي:

- كل ظهور للسلسلة النصية `"User"` يتبعه محرف مسافة بيضاء واحد أو أكثر ثم اسم المستخدم.
- يوجد على الأكثر ظهور واحد للسلسلة النصية `"User"` في كل سطر.
- أسماء المستخدمين سلاسل نصية غير فارغة لا تحتوي على مسافات بيضاء.
