# الأعداد

تحتوي لغة Crystal على نوع يُسمى `Number`، وهو النوع الأساسي لجميع الأنواع العددية.
يوجد داخل النوع `Number` نوعان فرعيان رئيسيان: [`Int`][int] و [`Float`][float].

`Int` اختصار لكلمة integer، ويمثّل الأعداد الصحيحة.
يمكن أن يكون `Int` سالبًا أو موجبًا، وبدون فاصلة عشرية.

```crystal
1.class
# => Int32

-1.class
# => Int32
```

يمثّل `Float` الأعداد التي تحتوي على فاصلة عشرية.
ويمكن أن تكون قيم `Float` سالبة أو موجبة.

```crystal
10.5.class
# => Float64
```

## التحويل بين `Int` و `Float`

باستخدام الطريقتين `to_i` و `to_f`، يمكنك التحويل بين `Int` و `Float`.
ويُقرَّب العدد لأسفل عند التحويل من `Float` إلى `Int`.

```crystal
1.to_f
# => 1.0

1.0.to_i
# => 1

1.9.to_i
# => 1
```

## العوامل الحسابية

يمكنك استخدام [عوامل الحساب الأساسية][math] على `Int` و `Float`.
هذه العوامل هي `+` و `-` و `*` و `/` و `%`.
وعند استخدامها يمكنك الجمع بين `Int` و `Float` بحرية.

### الجمع والطرح والضرب

يُستخدم العامل `+` للجمع، والعامل `-` للطرح، والعامل `*` للضرب.

| العامل | مثال           |
| ------ | -------------- |
| `+`    | `4 + 6 => 10`  |
| `-`    | `15 - 10 => 5` |
| `*`    | `2 * 3 => 6`   |

### القسمة

تُستخدم القسمة لتقسيم الأعداد.
ويُستخدم العامل `/` للقسمة.
ستكون النتيجة دائمًا من نوع `Float`.

```crystal
4 / 2
# => 2.0

4.0 / 2
# => 2.0
```

~~~~exercism/caution
في بعض لغات البرمجة، تكون نتيجة القسمة على صفر خطأً.

أما في Crystal، فنتيجة القسمة على صفر هي `Infinity` أو `-Infinity`.
والاستثناء الوحيد هو قسمة صفر على صفر، فتكون النتيجة `NaN` (ليس عددًا).
و `Infinity` و `NaN` قيمتان خاصتان في النوع `Float`.

```crystal
1 / 0
# => Infinity

-1 / 0
# => -Infinity

0 / 0
# => NaN
```
~~~~

### باقي القسمة

تُستخدم عملية باقي القسمة لإيجاد ما يتبقى بعد القسمة.
ويُستخدم العامل `%` لباقي القسمة.

```crystal
5 % 2
# => 1

5.0 % 2
# => 1.0

5 % 3
# => 2
```

~~~~exercism/caution
القسمة على صفر عند استخدام باقي القسمة تؤدي إلى الخطأ `DivisionByZeroError`.
وهذا يختلف عن القسمة العادية.

```crystal
1 % 0
# Error: Unhandled exception: Division by 0 (DivisionByZeroError)
```
~~~~

## التقريب

تأخذ الطريقة `round` وسيطًا اختياريًا: عدد المنازل العشرية التي تريد التقريب إليها.
والقيمة الافتراضية لعدد المنازل العشرية هي 0.

```crystal
1.0.round
# => 1

1.5.round
# => 2

1.234.round(2)
# => 1.23
```

## الأولوية والأقواس

تسمح Crystal باستخدام الأقواس الهلالية (`()`)، ويمكن استخدامها لتجميع التعبيرات.
ويفيد ذلك عندما تريد تغيير ترتيب العمليات.

عند استخدام عدة عوامل حسابية، يكون ترتيب العمليات كما هو في الرياضيات، ويُعرف أيضًا بـ [PEMDAS][pemdas].
وهو يتبع ترتيب الأقواس الهلالية (`()`)، ثم الأسس (`**`)، ثم الضرب (`*`) والقسمة (`/`)، ثم الجمع (`+`) والطرح (`-`).

```crystal
2 + 3 - 4 * 4
# => -11

(2 + 3 - 4) * 4
# => 4
```
