# مقدمة

محارف Factor هي أعداد صحيحة، أي نقاط ترميز Unicode، لذا تمنحك عوامل المقارنة `<` و`>` و`=` ترتيبًا حسّاسًا لحالة الأحرف مباشرةً. وتضيف مفردات [`unicode`][unicode] محمولات واعية بـ Unicode وتحويلًا لحالة محرف واحد.

## محمولات المحارف

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
blank?   ( c -- ? )    ! whitespace
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
```

## تحويل الحالة

تعكس `ch>upper` و`ch>lower` حالة محرف واحد. أما `>upper` و`>lower` على مستوى السلسلة النصية، فتطبّقان التحويل نفسه على كل محرف في السلسلة.

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```
