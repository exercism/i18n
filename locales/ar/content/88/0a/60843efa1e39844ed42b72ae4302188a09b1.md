# مقدمة

المؤشرات الذكية في Cairo هي هياكل بيانات متقدمة تضمن إدارة آمنة وفعّالة للذاكرة من خلال إضافة ميزات أمان إلى المؤشرات العادية، فتمنع المشكلات الشائعة مثل إلغاء الإشارة إلى مؤشر فارغ أو الوصول إلى ذاكرة غير مُهيّأة.

## ما هو المؤشر الذكي؟

يتصرف المؤشر الذكي مثل المؤشر العادي، لكنه يتتبع الملكية ويضمن الوصول الآمن إلى الذاكرة، فيمنع مشكلات مثل إلغاء الإشارة إلى مؤشر فارغ أو معلّق.

## أنواع المؤشرات الذكية

يوفر Cairo عدة أنواع من المؤشرات الذكية، مثل `Box<T>` و`Nullable<T>`:

- **`Box<T>`**: يخزّن البيانات في مقطع ذاكرة خاص، وهو مثالي للبيانات الكبيرة أو ذات الحجم الديناميكي. ويتيح نقل الملكية دون نسخ البيانات.
- **`Nullable<T>`**: يشير إما إلى قيمة صالحة من النوع `T` أو إلى `null`، وهو مفيد للتعامل مع القيم الاختيارية.

## أمان الذاكرة

تساعد المؤشرات الذكية على منع الوصول غير الآمن إلى الذاكرة، وتضمن تحرير الذاكرة تلقائيًا عند عدم الحاجة إليها، ما يقلل من خطر تسرب الذاكرة.

### مثال: استخدام `Box<T>` مع الأنواع العودية

تتيح المؤشرات الذكية مثل `Box<T>` التعامل الآمن مع الأنواع العودية، كما في الشجرة الثنائية، عبر تخصيص الذاكرة بكفاءة وتجنب العودية اللانهائية.

```rust
use core::box::{BoxTrait};

#[derive(Copy, Drop)]
enum BinaryTree {
    Leaf: u32,
    Node: (u32, Box<BinaryTree>, Box<BinaryTree>),
}

fn main() {
    let leaf1 = BinaryTree::Leaf(1);
    let leaf2 = BinaryTree::Leaf(2);
    let node = BinaryTree::Node((3, BoxTrait::new(leaf1), BoxTrait::new(leaf2)));
    println!("{:?}", node);
}
```

## مزايا الأداء

تحسّن المؤشرات الذكية الأداء عبر تمرير مراجع إلى البيانات بدلًا من نسخ هياكل كبيرة، ما يقلل من عبء الذاكرة.

```rust
// `Cart` is a large struct that contains a lot of information
fn pass_pointer(cart: Box<Cart>) {
    let cart = cart.unbox();
    println!("{} is shopping today and bought {} items", cart.buyer, cart.items);
}
```
