# مقدمة

البنية الأساسية للبرمجة كائنية التوجه في C# هي _الصنف_، وهو مزيج من البيانات (_الحقول_) والسلوك (_الطرق_). تُعرف حقول الصنف وطرقه باسم _أعضائه_.

يمكن تقييد الوصول إلى الأعضاء من خلال محدّدات الوصول، وأكثرها شيوعًا اثنان:

- `public`: يمكن لأي كود الوصول إلى العضو (بدون قيود).
- `private`: لا يمكن الوصول إلى العضو إلا من كود موجود في الصنف نفسه.

يمكنك أن تتخيل الصنف كقالب لإنشاء نسخ منه. ولإنشاء نسخة من صنف (وتُعرف أيضًا بـ_الكائن_)، تُستخدم الكلمة المفتاحية `new`:

```csharp
class Car
{
}

// Create two car instances
var myCar = new Car();
var yourCar = new Car();
```

للحقول نوع، ويمكن تعريفها في أي مكان داخل الصنف.
تُعرَّف الحقول العامة بنمط PascalCase، والحقول الخاصة بنمط camelCase مع بادئة شرطة سفلية `_`:

```csharp
class Car
{
    // Accessible by anyone
    public int Weight;

    // Only accessible by code in this class
    private string _color;
}
```

يمكن اختياريًا إسناد قيمة ابتدائية إلى حقل. وإذا لم يحدّد الحقل قيمة ابتدائية، فسيُضبط على القيمة الافتراضية لنوعه. ويمكن الوصول إلى قيم حقول النسخة وتحديثها باستخدام تدوين النقطة.

```csharp
class Car
{
    // Will be set to specified value
    public int Weight = 2500;

    // Will be set to default value (0)
    public int Year;
}

var newCar = new Car();
newCar.Weight; // => 2500
newCar.Year;   // => 0

// Update value of the field
newCar.Year = 2018;
```

عادةً ما تُحدَّث الحقول الخاصة كأثر جانبي لاستدعاء طريقة. ومثل هذه الطرق لا تُرجع أي قيمة عادةً، وفي هذه الحالة يكون نوع الإرجاع `void`:

```csharp
class CarImporter
{
    private int _carsImported;

    public void ImportCars(int numberOfCars)
    {
        // Update private field from public method
        _carsImported = _carsImported + numberOfCars;
    }
}
```
