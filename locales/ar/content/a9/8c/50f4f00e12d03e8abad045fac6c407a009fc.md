# نبذة

الحلقة وسيلة لتكرار تنفيذ عبارة واحدة أو أكثر في دفعة واحدة.
يُسمى كل تنفيذ لمجموعة من العبارات تكرارًا.

## `while` حلقة

تنفّذ حلقة `while` مجموعة من العبارات ما دام تعبير منطقي في أعلى الحلقة صحيحًا.
وعندما يصبح التعبير المنطقي خطأً تتوقف الحلقة عن العمل وينتقل التنفيذ إلى سطر الكود التالي بعد الحلقة.

وإذا كان التعبير المنطقي خطأً منذ البداية، فلن تعمل حلقة `while` إطلاقًا وينتقل التنفيذ إلى سطر الكود التالي بعد الحلقة.

```c
int main() {
    int i = 0;
    while (i < 5) {
        printf("Number is %i\n", i++);
    }    
    return 0;
}
```

من المهم وجود شرط لإنهاء الحلقة؛ وإلا فإنها تصبح حلقة لا نهائية تعطّل أي تقدّم في الكود.
لو حُذف `++` من `i` في الكود أعلاه لأصبحت حلقة لا نهائية.

## `do` حلقة

تكون تعبير حلقة `do` المنطقي موضع اختبار في أسفل الحلقة.
وتعمل حلقة `do` دائمًا مرة واحدة على الأقل، كما في المثال التالي

```c
do {
    printf("Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
} while (answer != 42); 
// Note that a semicolon is needed after the Boolean expression.
```

مع حلقة `while` سيكون هذا أكثر إسهابًا

```c
printf(""Enter the Answer to the Ultimate Question of Life: ");
scanf("%d", &answer);
while (answer != 42) {
    printf(""Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
}
```

## `for` حلقة

غالبًا ما تحدّث الحلقة متغيرًا وتنتهي عندما يبلغ المتغير قيمة معينة.
وحلقة `for` طريقة لتهيئة متغير واحد أو أكثر وتحديثه واختباره في سطر واحد بين الأقواس الهلالية.
القسم الأول لتهيئة المتغير، والقسم الثاني لاختبار المتغير، والقسم الثالث لتحديث قيمة المتغير.

```c
for (int i = 0; i < 5; i++) {
    printf("Number is %i\n", i);
}
```

هذا أقل إسهابًا من المكافئ بحلقة `while`، ومع ذلك يبقى مقروءًا.

وقد يتعامل قسمَا التهيئة والتحديث في حلقة `for` مع أكثر من متغير واحد باستخدام عامل الفاصلة لفصل التعبيرات داخل الشروط.

```c
    int i, j;
    for (i = 0, j = 5; i < 5 && j > 2; i++, j--) {
        printf("i is %i\n", i);
        printf("j is %i\n", j);
    }
    printf("After the loop");
```

سيطبع هذا

```
i is 0
j is 5
i is 1
j is 4
i is 2
j is 3
After the loop
```

لا يلزم تعريف أي من أقسام `for`.
التعبير الاختباري الفارغ يُقيَّم إلى صحيح، لذا يمكن استخدام حلقة `for` لتعريف حلقة لا نهائية هكذا

```c
int i = 0;
for (;;) {
    printf("Number is %i\n", i++);
    if (i == 5) break;
}
```

يشبه هذا حلقة `while` من حيث أن `i` يُهيَّأ قبل الحلقة ويزداد داخل الحلقة.
كذلك يُختبر `i` داخل الحلقة وتنتهي الحلقة بعبارة `break`.

## عبارة `break`

أحيانًا قد تحتاج الحلقة إلى الانتهاء عند شرط خاص لا يُختبر في تعبيرها المنطقي.
تُنهي عبارة `break` الحلقة وينتقل التنفيذ إلى سطر الكود التالي بعد الحلقة.

```c
int i, j, k;
for (int i = 0, j = 5, k = 3; i < 5 && j > 2; i++, j--) {
    printf("i is %i\n", i);
    printf("j is %i\n", j);
    if (k == 3) break;
}
printf("After the loop");
```

سيطبع هذا

```
i is 0
j is 5
After the loop
```

## عبارة `continue`

أحيانًا قد تحتاج الحلقة إلى بدء تكرارها التالي دون إكمال تكرارها الحالي.
توقف عبارة `continue` تنفيذ التكرار الحالي وتتابع التنفيذ من بداية التكرار التالي.

```c
int i, j;
for (int i = 0, j = 4; i < 4 && j > 0; i++, j--) {
    if (i == j) continue;
    printf("i is %i\n", i);
    printf("j is %i\n", j);
}
printf("After the loop");
```

سيطبع هذا

```
i is 0
j is 4
i is 1
j is 3
i is 3
j is 1
After the loop
```

ولا يطبع هذا قيمتي `i` و`j` عند بلوغهما القيمة `2` معًا.
