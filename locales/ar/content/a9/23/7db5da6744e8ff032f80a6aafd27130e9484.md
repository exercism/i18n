# مقدمة

## المصفوفات

في Ruby، **المصفوفات** مجموعات مرتّبة ومفهرسة بأعداد صحيحة ويمكنها أن تحتوي على أي نوع من الكائنات.
تبدأ فهرسة المصفوفات من `0`.
ويُفترض أن يكون الفهرس السالب نسبيًا إلى نهاية المصفوفة، فعلى سبيل المثال يشير الفهرس `-1` إلى العنصر الأخير في المصفوفة، و`-2` إلى العنصر قبل الأخير فيها، وهكذا.

### إنشاء المصفوفات

عادةً ما تُنشأ المصفوفات باستخدام الصيغة `[]`.
ويمكنها أن تحتوي على أي نوع مختلف من الكائنات.

```ruby
array = [1, "two", 3.0]
```

### الإشارة إلى العناصر

يمكن استرجاع عناصر المصفوفة بواسطة فهارسها باستخدام الطريقة `#[]`.
وهي تُرجع العنصر عند الفهرس المحدد، أو تُرجع مصفوفة فرعية تبدأ عند فهرس البداية وتمتد بطول محدد.
تُعد الفهارس السالبة تنازليًا من نهاية المصفوفة.

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[2]       #=> "c"
a[6]       #=> nil
a[1, 3]    #=> [ "b", "c", "d" ]

a[-1]      #=> "e"
a[-2]      #=> "d"
a[-3, 2]   #=> ["c", "d"]
```

### طرق مساعدة

هناك العديد من الطرق المساعدة المفيدة في المصفوفات.
إليك بعضًا من أكثرها شيوعًا:

```ruby
fibonacci = [0, 1, 1, 2, 3, 5, 8, 13]

fibonacci.size      #=> 8
fibonacci.sum       #=> 33
fibonacci.reverse   #=> [13, 8, 5, 3, 2, 1, 1, 0]
```

## التعداد

بدلًا من استخدام الحلقات للتنقل عبر المجموعات، نستخدم في Ruby التعداد.

التعداد هو الانتقال عبر مجموعة (وهي هنا مصفوفة) وتنفيذ إجراء ما على كل كائن.  والتعداد مفهوم أساسي في Ruby، ويُستخدم في أمور مثل الترتيب والتجميع والتحويل والاختزال وغيرها الكثير.

وسيبدو التعداد الذي يُخرج كل كلمة في مصفوفة هكذا:

```ruby
words = ["the", "cat", "sat"]
words.each do |word|
  puts word
end

# Output:
# the
# cat
# sat
```

في هذا المثال، استدعينا الطريقة `.each` على مصفوفتنا ومرّرنا _كتلة_ تأخذ معاملًا واحدًا (`word`) وتُخرجه.

سنلقي نظرة على _الكتل_ بتفصيل أكبر بكثير لاحقًا في المسار، لكن اعتبرها الآن دوالًا مجهولة يمكنها أن تأخذ صفرًا أو أكثر من الوسائط.
ويمكن تعريفها باستخدام صيغة `do...end` (أعلاه)، أو صيغة `{}` (أدناه).

إليك بعض الأمثلة الأخرى على طرق المصفوفات التي تستخدم الكتل:

```ruby
fibonacci = [0, 1, 1, 2, 3, 5, 8, 13]

fibonacci.count  { |number| number == 1 }   #=> 2
fibonacci.any?   { |number| number == 6 }   #=> false
fibonacci.select { |number| number.odd? }   #=> [1, 1, 3, 5, 13]
fibonacci.all?   { |number| number < 20 }   #=> true
fibonacci.map    { |number| number * 2  }   #=> [0, 2, 2, 4, 6, 10, 16, 26]
```
