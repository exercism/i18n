# نبذة

تُعدّ [البنى][structs-and-classes] (وتُسمى عادةً *structs*) إحدى اللبنات الأساسية لبرامج Swift.
تتيح لك البنى إنشاء أنواع مخصّصة تجمع الخصائص (البيانات) والطرق (السلوك) المترابطة معًا.
في الواقع، جميع الأنواع القياسية في Swift، بما فيها `Int` و`Double` و`Bool` و`String` و`Array` و`Dictionary`، مُنفَّذة كبنى.

## تعريف البنى

عرّف بنية باستخدام الكلمة المفتاحية `struct`، متبوعة باسم النوع والأقواس المعقوفة التي تحتوي على تعريفها.
وفقًا لأسلوب Swift، تُكتب أسماء البنى بنمط `UpperCamelCase`:

```swift
struct CharacterStats {
    var health = 0.0
    var speed = 0
    var strength = 0
}
```

## إنشاء النسخ

تعريف البنية هو مخطط.
لإنشاء *نسخة* من بنية، استدعِ مُهيّئها بكتابة اسم النوع متبوعًا بالأقواس الهلالية:

```swift
var someStats = CharacterStats()
```

يؤدي هذا إلى إنشاء نسخة مزوّدة بقيم الخصائص الافتراضية من التعريف.

تُنشئ Swift أيضًا **مُهيّئًا حسب الأعضاء** تلقائيًا للبنى، وهو ما يتيح لك تهيئة الخصائص بأسمائها:

```swift
let customStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

## الوصول إلى الخصائص وتعديلها

يمكنك الوصول إلى خصائص نسخة وتعديلها باستخدام *تدوين النقطة*:

```swift
var stats = CharacterStats()

print(stats.health) // Prints 0.0

stats.health = 87.3
print(stats.health) // Prints 87.3
```

لأن البنى من أنواع القيم، فإن تعديل خصائص نسخة يتطلب أن تكون النسخة نفسها معرّفة باستخدام `var`.
وإذا عُرّفت النسخة باستخدام `let`، تصبح جميع خصائصها غير قابلة للتعديل.
