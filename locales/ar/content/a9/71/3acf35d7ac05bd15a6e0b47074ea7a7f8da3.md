# مقدمة

السلسلة النصية في Factor هي متتالية من المحارف. معظم الكلمات من مفردات [`sequences`][sequences] تعمل على السلاسل النصية، بالإضافة إلى الكلمات المخصّصة للتعامل مع السلاسل النصية في [`splitting`][splitting] و[`ascii`][ascii] وما شابهها.

## السلاسل النصية الحرفية

تُكتب السلاسل النصية بين علامتي تنصيص مزدوجتين. وتُدعم تسلسلات الهروب المعتادة، وهي `\n` و`\t` و`\r` و`\\` و`\"`:

```factor
"hello, world" .                 ! => "hello, world"
"first\nsecond" print            ! prints two lines
```

## الطول والفهرسة

لأن السلسلة النصية متتالية، فإن الكلمتين `length` و`nth` من [`sequences`][sequences] تعملان عليها مباشرة.

تُرجع `length` عدد المحارف:

```factor
"hello" length .    ! => 5
```

تأخذ `nth` فهرسًا يبدأ من 0 والمتتالية، وتُرجع العنصر عند ذلك الموضع. وبالنسبة إلى سلسلة نصية، فإن العنصر هو *محرف*، أي نقطة ترميز (عدد صحيح)، وليس سلسلة فرعية طولها محرف واحد:

```factor
0 "hello" nth .     ! => 104   (CHAR: h)
4 "hello" nth .     ! => 111   (CHAR: o)
```

## من محرف إلى سلسلة نصية

لتحويل نقطة ترميز واحدة إلى سلسلة نصية من محرف واحد، استخدم `1string ( char -- str )` من مفردات [`strings`][strings]. أما `CHAR:` فهي الصيغة التي يفهمها المحلل لكتابة نقطة ترميز حرفيًا:

```factor
CHAR: A 1string .                ! => "A"
0 "hello" nth 1string .          ! => "h"
```

## التقسيم

تقسّم مفردات [`splitting`][splitting] السلسلة النصية إلى أجزاء.

يقطّع `split1` عند *أول* ظهور للفاصل ويُرجع النصفين معًا:

```
split1 ( seq subseq -- before after )
```

```factor
"foo: bar" ": " split1 .s
! => "foo"
! => "bar"
```

يقطّع `split` عند *أي* من المحارف في مجموعة الفواصل، وقد ينتج أجزاء فارغة:

```factor
"[ERROR]: Stack overflow" "[]" split .
! => { "" "ERROR" ": Stack overflow" }
```

تُسقط `harvest` (من [`sequences`][sequences]) الأجزاء الفارغة:

```factor
"[ERROR]: Stack overflow" "[]" split harvest .
! => { "ERROR" ": Stack overflow" }
```

## انتقاء جزء

بعد تقسيم السلسلة النصية إلى مصفوفة من الأجزاء، تُرجع `first` و`second` و`third` و`fourth` (من [`sequences`][sequences]) الجزء عند ذلك الموضع:

```factor
"apple,bee,carrot,duck" "," split first .    ! => "apple"
"apple,bee,carrot,duck" "," split second .   ! => "bee"
"apple,bee,carrot,duck" "," split third .    ! => "carrot"
"apple,bee,carrot,duck" "," split fourth .   ! => "duck"
```

وعندما تريد كل الأجزاء الأولى على المكدس دفعة واحدة، تستخرج `first2` و`first3` اثنين أو ثلاثة منها في خطوة واحدة:

```factor
"apple,bee,carrot,duck" "," split first2 .s
! => "apple"
! => "bee"

"apple,bee,carrot,duck" "," split first3 .s
! => "apple"
! => "bee"
! => "carrot"
```

وعلى السلسلة النصية نفسها، تُرجع `first` أول **محرف**، أي نقطة ترميز، وليس سلسلة فرعية:

```factor
"hello" first .                         ! => 104   (CHAR: h)
```

## إزالة الفراغات

تزيل `[ blank? ] trim` (من [`sequences`][sequences]، مع `blank?` من مفردات [`ascii`][ascii]) الفراغات البادئة واللاحقة:

```factor
"  Disk full \r\n" [ blank? ] trim .
! => "Disk full"
```

## تحويل حالة الأحرف

تُرجع `>lower` و`>upper` (من [`ascii`][ascii]) سلسلة نصية جديدة مع تغيير حالة الأحرف:

```factor
"WARNING" >lower .    ! => "warning"
"hello" >upper .      ! => "HELLO"
```

## الربط

هناك كلمتان من [`sequences`][sequences] تستخدمان لتركيب السلاسل النصية:

تغلّف `surround` السلسلة النصية ببادئة ولاحقة:

```
surround ( seq pre post -- new-seq )
```

```factor
"warning" "(" ")" surround .    ! => "(warning)"
```

وتضمّ `glue` سلسلتين نصيتين مع فاصل بينهما:

```
glue ( s1 s2 sep -- s )
```

```factor
"Disk full" "(error)" " " glue .    ! => "Disk full (error)"
```
