# ملحق التعليمات

## بنية المشروع

تستخدم تمارين Clojure في Exercism أداة [leiningen](http://leiningen.org/) لتهيئة الكود وتشغيله، وتتبع [بنية المجلدات القياسية في leiningen](https://github.com/technomancy/leiningen/blob/master/doc/TUTORIAL.md#directory-layout).

ستجد ملف اختبار باسم `hello_world_test.clj` داخل مجلد `test`.
اكتب الكود في `src/hello_world.clj`. وينبغي أن يستخدم فضاء الأسماء `hello-world` حتى تتمكن الاختبارات من العثور عليه.

## تشغيل الاختبارات

شغّل الاختبارات باستخدام الأمر `lein test` واجعلها تنجح:

```
$ lein test

lein test hello-world-test

Ran 3 tests containing 3 assertions.
0 failures, 0 errors.
```

ثم أرسل التمرين باستخدام:

```
$ exercism submit src/hello_world.clj
```

لمزيد من التعليمات التفصيلية ومصادر التعلّم، راجع [صفحة لغة Clojure على Exercism](http://exercism.io/languages/clojure).
