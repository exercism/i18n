# مقدمة

## الصفوف

الصف هو تجميع _غير قابل للتغيير_ لقيم غير مسمّاة لكن مرتّبة.
ويمكن أن تحتوي الصفوف على أي نوع بيانات (أو عدة أنواع)، بما في ذلك صفوف أخرى.

تُعرَّف الصفوف بأنها قيم مفصولة بفواصل توضع بين المحرفين `(` و `)`: `(<element_1>, ... , <element_n>)`.

```fsharp
("one", 2) // Tuple pair (2 values)
("one", 2, true) // Tuple triplet (3 values)
```

لا يمكن المقارنة بين الصفوف إلا إذا كان لها الطول نفسه والأنواع نفسها (بالترتيب نفسه).
وللصفوف تساوٍ بنيوي، أي أنها لا تكون متساوية _إلا_ إذا كانت جميع قيمها متساوية.

```fsharp
(1, 2) = (1, 2) // Same length, same types, same values, same order
// => true

(1, 2) = (2, 1) // Same length, same types, same values, different order
// => false

(1, 2) = (1, "2") // Same length, different types
// compiler error

(1, 2) = (1, 2, 3) // Different length
// compiler error
```

هناك ثلاثة أساليب لاستخراج القيم من الصف:

- دالتا `fst` و `snd`
- تفكيك الصف
- مطابقة الأنماط

```fsharp
let person = ("Jordan", 170)

// Option 1: fst/snd
let name1 = fst person
let length2 = snd person

// Option 2: deconstruction
let (name2, length2) = person
// => name2 = "Jordan"
// => length2 = 170

// Option 3: pattern matching
match person with
| name3, length3 -> printf "%s: %d" name3 length3
```
