# نبذة

تُستخدم المكرِّرات في Haxe للمرور على قيمة باستخدام حلقة `for`. وهناك نوعان من المكرِّرات:

- `Iterator`، وهو يمرّ على قيمة.
- بيانات `Iterable`، التي تتيح المرور على نوع بيانات.

ويُمثَّل هذان المفهومان بـ `Iterator<T>` و `Iterable<T>`:

```haxe
typedef Iterator<T> = {
  function hasNext():Bool;
  function next():T;
}

typedef Iterable<T> = {
  function iterator():Iterator<T>;
}
```

أي صنف يتوافق مع أحد هذين النوعين يمكن المرور عليه باستخدام حلقة `for`. فإذا عرّف صنف ما الطريقتين `hasNext` و `next` فإنه يُعدّ مكرِّرًا، وإما إذا عرّف طريقة `iterator` فإنه يُعدّ نوعًا قابلًا للمرور عليه:

```haxe
class MyStringIterator {
  var str:String;
  var i:Int;

  public function new(str:String) {
    this.str = str;
    i = 0;
  }

  public function hasNext():Bool {
    return i < str.length;
  }

  public function next():String {
    return str.charAt(i++);
  }
}
```

في المثال أعلاه، يُعدّ الصنف `MyStringIterator` مكرِّرًا لأنه ينفّذ الطريقتين `hasNext` و `next`، ما يجعله متوافقًا مع `Iterator<String>`.

```haxe
class MyArrayWrap<T> {
  var arr:Array<T>;

  public function new(a:Array<T>) {
    this.a = a;
  }

  public function iterator() {
    return a.iterator();
  }
}
```

وهنا يُعدّ الصنف `MyArrayWrap` نوع بيانات قابلًا للمرور عليه لأنه متوافق مع `Iterable<Array<T>>`.
