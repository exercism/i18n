# نبذة

Elm لغة ممتعة لبناء تطبيقات ويب موثوقة.
تتميّز برسائل خطأ ودّية، وأداء ممتاز، وملفات صغيرة الحجم، وبدون استثناءات وقت التشغيل.

ولعلّ الجزء الأكثر شهرة والأكثر اقتباسًا من Elm هو معمارية Elm، وهي نمط بسيط لهيكلة تطبيقات الويب، وعليه تُبنى جميع تطبيقات الويب بلغة Elm.

الفكرة الجوهرية هي أن الكود الخاص بك يُبنى حول `Model` يمثّل حالة تطبيقك، ووسيلة لتحديث هذا النموذج عبر `update`، ووسيلة لعرضه عبر `view`.

يحتوي `Model` على حالة التطبيق، أي كل البيانات التي يحتاجها التطبيق.
إذا تخيّلت تطبيقًا بسيطًا فيه مربع نص، ونص يعرض عكس ذلك النص، فسيبدو النموذج كما يلي.
يمكنك أيضًا رؤية هذا المثال في [دليل Elm][elm-guide-text-fields].

```elm
type alias Model =
  { text : String
  }
```

`update` دالة تُستدعى مع `Msg` عند حدوث تغيير (مثل نقر المستخدم على زر).
وهي تأخذ `Msg` و`Model` الحالي، وتُرجع `Model` جديدًا.

```elm
type Msg
  = TextChanged String

update : Msg -> Model -> Model
update msg model =
  case msg of
    TextChanged newText ->
      { model | text = newText }
```

`view` دالة تُرجع HTML لعرضه للمستخدم في المتصفح.
وهي تأخذ `Model` الحالي وتُرجع `Html Msg` (وهو النوع الذي يستخدمه Elm لتمثيل HTML).

```elm
view : Model -> Html Msg
view model =
  Html.div []
    [ Html.input
      [ Html.Attributes.placeholder "Text to reverse"
      , Html.Attributes.value model.text
      , Html.Events.onInput TextChanged
      ]
      []
    , Html.div [] [ Html.text (String.reverse model.text) ]
    ]
```

[elm-guide-text-fields]: https://guide.elm-lang.org/architecture/text_fields
