# مقدمة

يمكن أن تكون الدالة `switch()` بديلاً موجزًا عن تسلسل طويل من اختبارات `if` ... `else if`.
المتغير الذي يتم التبديل عليه غالبًا ما يكون سلسلة نصية، وإذا كان كذلك يمكن حذف علامات الاقتباس من المحدِّد.

```R
star <- function(type) {
  switch(type,
    M = , # will "fall through" if no value given
    K = "red dwarf",
    G = "Earth-like",
    "bigger star" # only correct for O,B,A,F
  )
}

> star("M")
[1] "red dwarf"
```

لاحظ أن الخيارات لن تنتقل تلقائيًا إلى الخيار التالي إلا إذا تُركت القيمة فارغة، كما هو الحال مع `M` في المثال أعلاه.
لا حاجة إلى تضمين عبارات `break` كما في بعض اللغات الأخرى.

عند التبديل على أنواع `character`، تكون القيمة الأخيرة قيمة افتراضية، كما هنا.
أما مع أنواع الأعداد الصحيحة، فلا يمكن إعطاء قيمة افتراضية.

### الدالتان `recode_values` و`replace_values`

تسمح هاتان الدالتان المرتبطتان بتحويل متجهي شبيه بـ `switch` من القيم القديمة إلى قيم جديدة.

الفرق الرئيسي بينهما أن `recode_values()` تنشئ متجهًا جديدًا بالكامل، بينما تسمح `replace_values()` بتحديثات جزئية لمتجه موجود.

لا تزال المطابقة تامة، لكن:

- يمكن أن تكون الخيارات على اليسار متجهات، ويتطابق المدخل إذا تطابق أي عنصر.
- تُربط الخيارات على اليسار والنتائج على اليمين بعلامة التلدة `~` بدلًا من `=`.
- يمكن تحديد قيمة افتراضية في جميع الحالات.

```R
library(dplyr)

x <- c("a", "b", "a", "d", "b", NA, "c", "e", "z")
recode_values(
  x,
  "a" ~ 1,
  "b" ~ 2,
  "c" ~ 3,
  c("d", "e") ~ 4, # either "d' or "e" will match
  NA ~ 0,          # matches missing values
  default = 100   # note the different syntax for the default
)
#> [1]   1   2   1   4   2   0   3   4 100
```

### الدالة `case_when`

تأخذ `case_when` صيغة `case_match` خطوة أخرى إلى الأمام، إذ تسمح بأي تعبير منطقي على يسار `~`.

لا يُمرَّر متجه الإدخال (`x` في المثال أدناه) كوسيط، بل يحتاج فقط إلى أن يكون معرَّفًا مسبقًا.

```R
x <- 1:10
case_when(
  x < 3 ~ "low",
  between(x, 3, 5) ~ "mid",
  between(x, 6, 8) ~ "high",
  .default = "what?"
)
#>  [1] "low"   "low"   "mid"   "mid"   "mid"   "high"  "high"  "high"  "what?" "what?"
```

تعد الدالة `between()` أيضًا جزءًا من `dplyr`.
