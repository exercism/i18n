# مقدمة

`when` في Kotlin تعبير شرطي لاختيار أحد عدة خيارات. وهو شبيه بـ `switch` في Java، وأكثر مرونة من تسلسل من `if` ... `else if` ... `else`.

ومثل `if`، يمكن استخدام `when` تعبيرًا يُنتج قيمة.

## مطابقة قيمة

مرّر إلى `when` القيمة التي تريد مطابقتها بين الأقواس الهلالية.
يقارن كل فرع القيمة بنمطه حتى يتحقق التطابق:

```kotlin
val animal = "chicken"
val type = when (animal) {
    "chicken" -> "bird"
    "poodle" -> "dog"
    else -> "unknown"
}
// type => "bird"
```

- يُكتب كل فرع على الصورة `pattern -> result`.
- تُجرَّب الفروع من الأعلى إلى الأسفل حتى يُعثر على تطابق.
  ولا يُنفَّذ سوى الفرع الأول.
- استخدم `else` لأي قيمة غير مذكورة أعلاه (على غرار `else` الأخيرة في تسلسل `if`).

يشبه هذا [مطابقة الأنماط][pattern-matching].
يمكن أن يكون `pattern` قيمة تُطابَق، أو يمكن استخدام `is` للمطابقة حسب النوع:

```kotlin
fun typeText(subject: Any): String {
    return when(subject) {
        is Animal -> "Animal"
        is Fruit -> "Fruit"
        is String -> "Text"
        else -> "Unknown"
    }
}
```

أو استخدام `in` للتحقق من وجوده في مدى أو مجموعة أو سلسلة نصية أو أي شيء آخر يمتلك طريقة `contains`:

```kotlin
fun describe(number: Int, position: String) {
    // Range
    when(number) {
        in 1..10 -> println("From 1 to 10")
        in 11..20 -> println("From 11 to 20")
    }

    // Collection
    when(number) {
        in listOf(2, 4, 6) -> println("small even")
        in listOf(3, 5, 7) -> println("small odd")
    }

    // String
    when(position) {
        in "center middle" -> println("inner")
        in "left right boundary" -> println("outer")
    }
}
```

## شروط الحراسة

عند مطابقة قيمة، يمكن وضع شروط إضافية داخل `if` بعد النمط.
وتُسمّى هذه الشروط شروط الحراسة.

```kotlin
val x = 5
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else -> "other"
}
// description => "x is 5, y is even"
```

بل يمكن استخدام `else if` أيضًا.

```kotlin
val x = 7
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else if y % 2 == 0 -> "y is an even number"
    else -> "other"
}
// description => "y is an even number"
```


## مطابقة الشروط

بدلًا من ذلك، يمكن حذف القيمة ووضع شروط منطقية في كل فرع:

```kotlin
val x = 5
val y = 8
val description = when {
    x % 2 != 0 -> "x is odd"
    y % 2 == 0 -> "y is even"
    else -> "neither condition matched first"
}
// description => "x is odd"
```

ومرة أخرى، تُفحص الفروع من الأعلى إلى الأسفل، ولا يُنفَّذ سوى أول فرع شرطه `true`.

## استخدام `when` تعبيرًا

عندما يُستخدم `when` من أجل نتيجته (بأن يُسند إلى متغير، أو تُرجعه دالة، وما إلى ذلك)، يجب تغطية كل حالة ممكنة.

- عند المطابقة بقيمة، أضف `else` ما لم تكن كل القيم الممكنة معالَجة بالفعل (مثلًا كل قيم `Boolean` أو `enum`).
- عند مطابقة الشروط، يلزم وجود فرع `else`، لأن المترجم لا يستطيع أن يعرف أن شروطك تغطي كل الحالات.

```kotlin
fun label(n: Int): String = when (n) {
    0 -> "zero"
    1 -> "one"
    else -> "other"
}
```
