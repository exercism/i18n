# تعليمات

في هذا التمرين، ستُنفّذ محاكاةً للقاءات.
سيمنحك هذا إلمامًا بأساسيات الإرسال المتعدد، وهو النموذج الرئيسي في Julia.

~~~~exercism-important
For this exercise, all function definitions should be a single-line declaration with no if/else logic.
~~~~

بشكل عام، يتضمّن اللقاء كيانًا `a` يلتقي كيانًا آخر `b` ويتفاعل معه.

```julia
encounter(a, b) = "$(name(a)) meets $(name(b)) and $(meets(a, b))."
```

في البداية، سنحاكي ما يحدث عندما تلتقي القطط والكلاب.

## 1. عرّف أنواعًا مخصّصة

أولًا، أضف نوعًا مجرّدًا `Pet`.

ثم عرّف النوعين `Cat` و `Dog` كنوعين فرعيين من `Pet`.
لكلٍّ منهما حقل واحد هو `name`.

## 2. احصل على اسم الحيوان الأليف.

نفّذ دالة `name()` تُرجع اسم الحيوان الأليف.

```julia-repl
julia> fido = Dog("Fido")
Dog("Fido")

julia> name(fido)
"Fido"
```

## 3. حدّد ما يحدث عندما تلتقي القطط والكلاب

نفّذ طرق `meets()` للقاءات التالية:

- عندما يلتقي كلبان، فإنهما **sniff** بعضهما البعض.
- عندما يلتقي قطّ بكلب، فإنه **hisses** في وجه الكلب.
- عندما يلتقي كلب بقطّ، فإنه **chases** القطّ.
- عندما يلتقي قطّان، فإنهما **slink**.

```julia-repl
julia> ginger = Cat("Ginger")
Cat("Ginger")

julia> meets(ginger, fido)
"hisses"
```

## 4. عرّف لقاءً بين كيانين.

نفّذ دالة `encounter()` بطريقة واحدة، لتُبلّغ عمّا يحدث عندما يلتقي كيانان لهما اسمان.

```julia-repl
julia> encounter(ginger, fido)
"Ginger meets Fido and hisses."
```

## 5. حدّد ردّ فعل احتياطيًا للقاءات بين الحيوانات الأليفة

ماذا يحدث إذا صادفوا حيوانًا أليفًا مختلفًا أثناء نزهتهم، مثل [حصان](https://www.dw.com/en/horse-takes-daily-stroll-through-frankfurt-without-owner/a-47833431)؟

- إذا التقى حيوان أليف بحيوان أليف آخر لا يعرفه، فإنه **is cautious**.

```julia-repl
julia> bella = Horse("Bella")
Horse("Bella")

julia> encounter(fido, bella)
"Fido meets Bella and is cautious."
```

## 6. حدّد ردًّا احتياطيًا إذا صادف حيوان أليف شيئًا لا يعرفه

هناك أشياء أخرى كثيرة قد تصادفها الحيوانات الأليفة وليست حيوانات أليفة: السيارات والبشر والنباتات والكوارث الطبيعية والكويكبات… فماذا يحدث حينها؟

- إذا التقى حيوان أليف بشيء لم يره من قبل، فإنه **runs away**.

```julia-repl
julia> colnago = Bicycle("Colnago")
Bicycle("Colnago")

julia> encounter(ginger, colnago)
"Ginger meets Colnago and runs away."
```

## 7. حدّد ردًّا احتياطيًا عامًّا

هناك لقاءات أخرى كثيرة قد تحدث في محاكاتنا.
سيارة تلتقي بكلب، وإلكترونان يلتقيان ويتفاعلان…

من المستحيل تغطية كل اللقاءات مسبقًا، لذلك سننفّذ ردًّا احتياطيًا عامًّا.

- إذا التقى شيئان أو كائنان مجهولان، فإن **nothing happens**.

```julia-repl
julia> γ1 = Photon("γ1")
Photon("γ1")

julia> γ2 = Photon("γ2")
Photon("γ2")

julia> encounter(γ1, γ2)
"γ1 meets γ2 and nothing happens." 
# This is true, photons just pass through each other.
```
