# تلميحات

## 1. التقاط المعلومات اللازمة لإنشاء البطاقات باستخدام التعبيرات النمطية

- `\p{L}` يطابق أي نوع من الحروف من أي لغة.
- يمكنك استخدام التعبير التالي لالتقاط المعلومات:
  ```julia
  re = r"""»(.*)«                     # title
           \ –\ (.*?)                 # name
           (?:\ \((.*?)\)|)           # optional pronouns
           (?:,\ from\ (.*?)|).       # optional organisation
           \ Start:\ (.*?),\          # start time
           (?:Q&A:\ (.*?),\ |)        # optional Q&A time
           End:\ (.*)                 # end time
        """x
  ```
