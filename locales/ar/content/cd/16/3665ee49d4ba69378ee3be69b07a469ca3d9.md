# الـ`getter` والـ`setter`

الـ`getter` والـ`setter` طريقتان تتيحان لك قراءة قيمة خاصية كائن وكتابتها.
تمتلك Crystal ماكروات، وهذا يسهّل تعريف `getter` و`setter` لخاصية ما.
الماكروات وسيلة لتوليد الكود في وقت الترجمة، وسنغطيها لاحقًا في مفهوم الماكرو.

في Ruby تُعرَّف هذه الطرق باستخدام الطرق `attr_reader` و`attr_writer` و`attr_accessor`، وهي تشبه من حيث المظهر تطبيق Crystal لها إلى حد كبير.
وقد عرّفت Crystal هذه في صورة ماكروات `getter` و`setter` و`property`.

## الـ`getter`

`getter` ماكرو يعرّف طريقة تُرجع قيمة متغير نسخة.
وهذا يعني أنك لم تعد مضطرًا لكتابة `@` أمام متغير النسخة عندما تريد الوصول إليه (داخل الطرق، باستثناء `initialize`)؛ وبدلًا من ذلك يمكنك استدعاء الطريقة التي عرّفها ماكرو `getter`.

يمكن لماكرو `getter` أن يقبل عدة متغيرات نسخة تفصل بينها فواصل.

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name
    @name
  end

  def age
    @age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  getter name, :age
end
```

كما ترى، يقلّل استخدام `getter` من كمية الكود الذي تكتبه، ويجعل قراءته أسهل.
وتختلف Crystal عن Ruby أيضًا في أنها تقبل اسم المتغير والرمز معًا كوسائط لماكرو `getter`.
وسنغطي الرموز لاحقًا في مفهوم الرموز.

## الـ`setter`

`setter` ماكرو يعرّف طريقة تضبط قيمة متغير نسخة.
لا يُصادف هذا الماكرو كثيرًا، وعادةً يُستخدم ماكرو `property` بدلًا منه.
ستبدو الطرق التي ستُنشَأ على هيئة `name_of_method=`؛ فعلامة `=` هي ما يتيح ضبط الخاصية.

تعريف هذه الطريقة خاص بعض الشيء، لأن الوسيط الذي تستقبله الطريقة يأتي بعد علامة `=`.
وتستخدم طرق أخرى خاصة عديدة في Crystal هذا التركيب، مثل طريقة `+`.

وكما في ماكرو `getter`، عندما تريد تحديث قيمة متغير نسخة بعد تعريف `setter`، يمكنك استدعاء الطريقة التي عرّفها ماكرو `setter`.

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name=(name : String)
    @name = name
  end

  def age=(age : Int32)
    @age = age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  setter name, :age
end
```

## `property`

`property` ماكرو يعرّف كلاً من `getter` و`setter` لمتغير نسخة.

```crystal
class Person
  @name : String
  @age : Int32

  property name, :age
end
```
