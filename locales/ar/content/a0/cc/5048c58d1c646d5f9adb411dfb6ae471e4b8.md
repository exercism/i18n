# مقدمة

تحتوي العديد من اللغات على وسيلة مثل `null` أو `none` للإشارة إلى قيمة غير موجودة.
ولأن لغة R مصممة للتعامل مع كميات كبيرة من البيانات (التي غالبًا ما تكون غير مرتبة)، فإنها تمتلك عدة أشكال للتعبير عن العدم.

الهدف العام هو الإشارة إلى القيم المفقودة أو المشكوك فيها عند مصادفتها، ثم المتابعة دون رفع استثناء.

## NULL

إذا كانت القيمة غير موجودة فعلًا، فإنها تُمثَّل بـ `NULL`. وهذا على الأرجح أقرب ما تفعله لغة C أو Python.

```R
v <- c() # zero-length vector
v
#> NULL
is.null(v)
#> [1] TRUE
```

في سياقات كثيرة، تُتجاهل قيم `NULL` ببساطة:

```R
c(2, 3, NULL, 5)
#> [1] 2 3 5
```

## NA

في الحالات التي توجد فيها القيمة لكننا لا نعرف ما هي، نستخدم `NA`. على سبيل المثال، عند إحصاء المركبات التي تسير على طريق، قد يمرض المراقبون البشريون أو تتعطل المستشعرات الآلية، لكن حركة المرور تستمر في التدفق.

```R
v <- c(1, 2, NA, 4, 5)
v
#> [1]  1  2 NA 4  5
is.na(v) # test for data gaps
#> [1] FALSE FALSE  TRUE FALSE FALSE
```

وهكذا فإن `NA` قيمة نائبة، تنبّه البشر إلى أنهم بحاجة إلى اتخاذ قرار بشأن كيفية التعامل معها.

## NaN

`NaN` اختصار لعبارة "Not a Number"، وتشير إلى مشكلة في الحساب في الحالات التي كان يُتوقع فيها عدد.

```R
n <- c(0, 2, 4)
d <- c(0, 1, 2)
n / d
#> [1] NaN   2   2  # 0/0 is mathematically undefined
is.nan(n / d)
#> [1]  TRUE FALSE FALSE
```

ليست هذه الاحتمال الوحيد للحسابات "غير الصالحة".
القسمة على صفر ستُرجع `Inf` أو `-Inf` عند وجود بسط غير صفري، دون رفع خطأ.

```R
1 / 0
#> [1] Inf
```

## المتجهات الفارغة

قد يكون مفاجئًا أن لغة R لا تملك طريقة قياسية للتحقق من الفراغ.

حتى إنشاء متجه فارغ ليس واضحًا تمامًا.
رأينا في قسم سابق أن `c()` بدون وسائط تُرجع `NULL`، وليس متجهًا.

```R
is.vector(c())
#> [1] FALSE
```

تأخذ دوال مثل `logical()` أو `integer()` وسيطًا يحدد الطول المطلوب، والذي يمكن أن يكون صفرًا.

```R
z <- logical(0)
is.vector(z)
#> [1] TRUE
length(z)
#> [1] 0
```

يمكننا أيضًا إنشاء متجه ثم حذف كل عنصر فيه، كما هو موضح في [مفهوم المتجهات][concept-vectors].
ينتج عن ذلك متجه بطول صفر من النوع المناسب.

```R
v <- 5
v[-1]  # delete the first element
#> numeric(0)
```

[concept-vectors]: https://exercism.org/tracks/r/concepts/vectors
