# نبذة

**الإغلاق** نمط برمجي [في Clojure][clojure-guide-closures] يسمح باستخدام متغيرات من [نطاق معجمي][wiki-lexical-scope] خارجي داخل دالة. تدعم Clojure الإغلاق بشكل شفاف، وغالبًا ما يستخدمه المبرمجون دون أن يعرفوا ما هو.

```clojure
;; Top-level definitions are global-scope
(def dozen 12)

;; Functions create a new scope.
;; Referencing the outer variable here is a closure.
(fn [n] (* dozen n))
```

## استخدام الإغلاق لحفظ الحالة وتمرير القيم

يتيح استخدام `atom` الحفاظ على بعض الحالة:

```clojure
;; This function closure increments the counter's state
;; in the outer lexical context.
;; This way the counter can be shared between many calling contexts.

(def increment
  (let [counter (atom 0)]
    (fn [] (swap! counter inc))))
```

كل استدعاء متتالٍ لـ `increment` يزيد عدّاده:

``` clojure
(increment)
;;=> 1
(increment)
;;=> 2
```
