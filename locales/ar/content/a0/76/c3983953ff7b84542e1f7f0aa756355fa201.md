# نبذة

الكلمة المفتاحية `when` هي المستخدمة في تصفية الاستثناءات. تُوضع بعد جملة `catch`، ويمكنها أن تأخذ تعبيرًا منطقيًا يحتوي على أي قيم موجودة في النطاق في تلك اللحظة، وليس بالضرورة أن تكون هذه القيم أعضاء في الاستثناء نفسه. إذا تطابق نوع الاستثناء وكان ناتج التعبير صحيحًا، فستُنفَّذ الكتلة المرتبطة بجملة `catch` تلك، وإلا انتقلنا إلى جملة `catch` التالية إن وُجدت لنفحصها.

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```
