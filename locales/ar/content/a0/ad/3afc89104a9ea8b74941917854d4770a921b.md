احذف كل الاستدعاءات الصريحة لـ `Boolean(...)`.

في JavaScript، لا تحتاج نتيجة التعبير إلى _تحويل_ إلى نوع محدد. على سبيل المثال، يمكن إرجاع نتيجة تعبير ثنائي كما هي، من دون الحاجة إلى استدعاء آخر لتحويلها إلى `boolean`.

```javascript
// instead of
return Boolean(some_expression);

// ...In JavaScript, in general, values don't need to be explicitly changed
return some_expression;
```
