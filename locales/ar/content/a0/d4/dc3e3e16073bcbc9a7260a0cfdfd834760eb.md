# ملحق التعليمات

## السجلات

| السجل | الاستخدام    | النوع | الوصف                         |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | مدخل        | عنوان | سلسلة نصية مُدخلة منتهية بمحرف صفري  |
| `$a1`    | مدخل        | عدد صحيح | مفتاح الإزاحة                     |
| `$a2`    | مدخل/مخرج | عنوان | سلسلة نصية ناتجة منتهية بمحرف صفري |
| `$t0-9`  | مؤقت        | أي     | للتخزين المؤقت                 |
