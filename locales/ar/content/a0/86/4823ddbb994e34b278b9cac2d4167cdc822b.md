# إضافة إلى التعليمات

## التعامل مع التواريخ في Prolog

دعم Prolog المدمج للتواريخ [بدائي إلى حد ما][built-in-dates-support].
وهناك أسلوب أجمل بكثير للتعامل مع التواريخ، وهو استخدام [حزمة date_time][date_time-package].

### تثبيت حزمة date_time

إذا كان إصدار Swipl المثبّت لديك حديثًا نسبيًا، يمكنك تثبيت الحزمة بتشغيل:

```bash
swipl pack install date_time
```

إذا لم ينجح ذلك، يمكنك تشغيل:

```shell
swipl -g 'pack_install(date_time)'
```

~~~~exercism/note
إذا كنت تستخدم المحرر على الإنترنت، فلست بحاجة إلى تثبيت أي شيء يدويًا.
~~~~

### استخدام حزمة date_time

أضف الكود التالي إلى أعلى ملف الحل لاستخدام حزمة `date_time`:

```prolog
:- use_module(library(date_time)).
```

~~~~exercism/note
نصيحة: [مصدر حزمة date_time][https://www.swi-prolog.org/pack/file_details/date_time/prolog/date_time.pl?show=src] موثّق توثيقًا جيدًا، وقد يكون عونًا كبيرًا لك!
~~~~
