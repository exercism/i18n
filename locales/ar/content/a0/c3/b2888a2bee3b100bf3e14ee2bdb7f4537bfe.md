# مقدمة

هناك نوعان مختلفان من الأعداد في C#:

- الأعداد الصحيحة: أعداد لا توجد فيها أي أرقام بعد الفاصلة العشرية (أعداد كاملة). أمثلة عليها: `-6`، `0`، `1`، `25`، `976` و`500000`.
- الأعداد العشرية: أعداد بها صفر أو أكثر من الأرقام بعد الفاصلة العشرية. أمثلة عليها: `-2.4`، `0.1`، `3.14`، `16.984025` و`1024.0`.

النوعان الرقميان الأكثر شيوعًا في C# هما `int` و`double`. النوع `int` هو عدد صحيح بطول 32 بت، والنوع `double` هو عدد عشري بطول 64 بت.

تُجرى العمليات الحسابية باستخدام عوامل الحساب القياسية. ويمكن مقارنة الأعداد باستخدام عوامل المقارنة الرقمية القياسية، وكذلك عاملي التساوي (`==`) وعدم التساوي (`!=`).

يحتوي C# على نوعين من التحويلات الرقمية:

1. التحويلات الضمنية: لا تُفقد أي بيانات ولا حاجة إلى أي صياغة إضافية.
2. التحويلات الصريحة: قد تُفقد البيانات وتلزم صياغة إضافية على شكل _cast_.

ولأن دقة `int` أقل من دقة `double`، فإن التحويل من `int` إلى `double` آمن، ولذلك يُعد تحويلًا ضمنيًا. أما التحويل من `double` إلى `int` فقد يعني فقدان البيانات، ولذلك يتطلب تحويلًا صريحًا.

```csharp
int softCool = 1358938113;
double notLost = 4.8151623;

// implicit cast: no loss of information
double macDebug = softCool;         // 1358938113.0

// explicit cast: possible loss of information 
int somethingLost = (int)notLost;   // 4
```
