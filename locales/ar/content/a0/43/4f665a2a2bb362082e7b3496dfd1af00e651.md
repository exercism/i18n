# مقدمة

في Haxe، **مصفوفة** مجموعة من العناصر (عادةً) من النوع نفسه. هناك ثلاث طرق لإنشاء مصفوفة في Haxe؛ إما بواسطة مُنشئ أو بواسطة صيغة التصريح. في Haxe، أول عنصر في المصفوفة فهرسه صفر:

```haxe
var a = [1, 2, 3];
trace(a); // [1,2,3]

// Here the second element is called by index
trace(a[1]); // 2

// The actual first element's index is 0
trace(a[0]); // 1
```

لإنشاء مصفوفة باستخدام مُنشئ، تحتاج إلى تمرير نوع العناصر التي ستُضمّن في المصفوفة:

```haxe
var a:Array<Int> = [0, 1, 2, 3];
a[1] = "Hello"; // Error: the array a takes integers only
```

إذا أردنا أن تحتوي مصفوفة على أنواع متعددة من العناصر، نضيف النوع `Dynamic` إلى محدد النوع:

```haxe
var a:Array<Dynamic> = [10, "Bob", true]
```
