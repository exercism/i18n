# مقدمة

في Go، يُنظَّم التطبيق على شكل حزم.
الحزمة مجموعة من الملفات المصدرية الموجودة في المجلد نفسه.
يجب أن تحمل جميع الملفات المصدرية في المجلد اسم الحزمة نفسه في أعلى الملف.
وبحسب العُرف، تُسمّى الحزمة باسم المجلد الذي توجد فيه.

```go
package greeting
```

توفّر Go مكتبة قياسية واسعة من الحزم يمكنك استخدامها في برنامجك عبر الكلمة المفتاحية `import`.
تُستورد حزم المكتبة القياسية باسمها.

```go
package greeting

import "fmt"
```

ثم يُشار إلى الحزمة المستوردة باسمها:

```go
world := "World"
fmt.Sprintf("Hello %s", world)
```

تحدّد Go إمكانية استدعاء عنصر ما من قِبل الكود في الحزم الأخرى من خلال طريقة تعريفه.
ولجعل دالة أو نوع أو متغير أو ثابت أو حقل `struct` ظاهرًا خارجيًا (وهو ما يُعرف بـ _المُصدَّر_)، يجب أن يبدأ الاسم بحرف كبير.
وهذا مشابه لِما تفعله لغات برمجة أخرى مثل Java التي تستخدم مُحدِّدات الوصول مثل `public` و`private`.

```go
package greeting

// Hello is a public function (callable from other packages).
func Hello(name string) string {
    return "Hello " + name
}

// hello is a private function (not callable from other packages).
func hello(name string) string {
    return "Hello " + name
}
```
