# التثبيت

## ثبّت Node.js

**لمستخدمي Windows وOS X**: ثبّت [Node.js][node] [عبر مدير الحزم][node-download].

**لمستخدمي Linux**: ثبّت [Node.js][node] باتّباع التعليمات الخاصة بتوزيعتك على [مدير حزم Node.js][linstall].

## ثبّت `jasmine-node` و`coffeescript`

بالنسبة لمعظم المستخدمين، كل ما عليك فعله هو تشغيل الأمر التالي:

```bash
$ npm install -g jasmine-node coffeescript
```

قد تحتاج، حسب إعدادات نظامك، إلى صلاحيات المستخدم الخارق لتثبيت وحدة `npm` على المستوى العام.
وهذا هو الحال إذا استخدمت المثبّت الرسمي المذكور أعلاه.
وإذا أظهر لك NPM خطأً يفيد بأنك لا تملك صلاحية الوصول، فأضف `sudo` إلى الأمر أعلاه:

```bash
$ sudo npm install -g jasmine-node coffeescript
```

إذا كنت قد استخدمت المثبّت الرسمي، فمن المفترض أن يكون `PATH` لديك قد ضُبط تلقائيًا. لكن إذا واجهت الصدفة صعوبة في العثور على وحداتك المثبّتة على المستوى العام، أو إذا كنت تبني Node.js من المصدر، فحدّث `PATH` ليشمل ملفات `npm` التنفيذية بإضافة ما يلي إلى `~/.bash_profile` أو `~/.zshrc`:

```bash
$ export PATH=/usr/local/share/npm/bin:$PATH
```
