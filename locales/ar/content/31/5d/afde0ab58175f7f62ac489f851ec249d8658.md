# حول

[الأصناف](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/classes) هي البنية الأساسية لممارسة البرمجة كائنية التوجه في F#.

يتكوّن الصنف في F# من حقوله وطرقه. وتُعرف حقول الصنف وطرقه باسم _أعضائه_.

تُعرَّف الأصناف في F# باستخدام الكلمة المفتاحية `type`. وتُعرَّف الطرق باستخدام الكلمة المفتاحية `member`، وهي دائمًا عامة. ولتعريف الحقول (الخاصة)، يمكن استخدام ارتباطات `let`.

```fsharp
type Shoe() =
    let size = 8

    member this.Describe() = $"This is a size {size} shoe"
```

الأصناف قوالب تُنشئ بها الكائنات. ولإنشاء نسخة من صنف، استدعِ اسم الصنف كما تستدعي دالة. وتُعرف نسخة الصنف أيضًا باسم _الكائن_.

يمكن الوصول إلى أعضاء الكائن باستخدام تدوين النقطة.

```fsharp
let myShoe = Shoe()
myShoe.Describe()
// => "This is a size 8 shoe"
```
