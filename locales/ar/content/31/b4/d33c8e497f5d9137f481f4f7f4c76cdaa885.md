# مقدمة

## تصفية الاستثناءات

`when` هي الكلمة المفتاحية في تصفية الاستثناءات. توضع بعد عبارة `catch` ويمكن أن تأخذ تعبيرًا منطقيًا يحتوي على أي قيم في النطاق في تلك اللحظة. إذا كان ناتج التعبير صحيحًا فستُنفَّذ الكتلة المرتبطة بعبارة `catch` تلك، وإلا فتُفحَص عبارة `catch` التالية، إن وُجدت.

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```

## الاستثناءات المعرَّفة من المستخدم

الاستثناء المعرَّف من المستخدم هو أي صنف معرَّف في الكود لديك ومشتق من `System.Exception`. يخضع لكل قواعد وراثة الأصناف، لكن إضافةً إلى ذلك يعامل المُصرِّف وبيئة تشغيل اللغة هذه الأصناف معاملة خاصة تسمح بإطلاق نُسخها والتقاطها خارج مسار التحكم المعتاد، كما نوقش في تمرين `exceptions`.

غالبًا ما تُستخدم الاستثناءات المعرَّفة من المستخدم لحمل معلومات إضافية، مثل رسالة وبيانات أخرى ذات صلة، لتكون متاحة لإجراءات الالتقاط.
