# عوامل المقارنة

تحتوي PHP على عشرة عوامل مقارنة مدمجة:

| الاسم | مثال | النتيجة |
| ----- | ---------- | -------------------------------------------------- |
| يساوي | `$a == $b` | صحيح إذا كانت قيمة `$a` مساوية لقيمة `$b` بعد تحويل الأنواع. |
| مطابق | `$a === $b` | صحيح إذا كانت قيمة `$a` مساوية لقيمة `$b` ومن النوع نفسه. |
| لا يساوي | `$a != $b` | صحيح إذا لم تكن قيمة `$a` مساوية لقيمة `$b` بعد تحويل الأنواع. |
| لا يساوي | `$a <> $b` | صحيح إذا لم تكن قيمة `$a` مساوية لقيمة `$b` بعد تحويل الأنواع. |
| غير مطابق | `$a !== $b` | صحيح إذا لم تكن قيمة `$a` مساوية لقيمة `$b` أو لم تكن من النوع نفسه. |
| أصغر من | `$a < $b` | صحيح إذا كانت قيمة `$a` أصغر تمامًا من قيمة `$b`. |
| أكبر من | `$a > $b` | صحيح إذا كانت قيمة `$a` أكبر تمامًا من قيمة `$b`. |
| أصغر من أو يساوي | `$a <= $b` | صحيح إذا كانت قيمة `$a` أصغر من قيمة `$b` أو مساوية لها. |
| أكبر من أو يساوي | `$a >= $b` | صحيح إذا كانت قيمة `$a` أكبر من قيمة `$b` أو مساوية لها. |
| سفينة الفضاء | `$a <=> $b` | يُرجع عددًا صحيحًا أصغر من `0`i أو مساويًا له أو أكبر منه عندما `$a`. |

لدى PHP تعريفات متمايزة تفرّق بين `equal` و`identical`. ويُشار إلى `identical` أحيانًا باسم `strictly equal`.

```php
<?php

// Comparisons between integer and numeric string values
1 == "1"; // => true, equal
1 === "1"; // => false, not identical

// Comparisons between integers and floating point values
1 == 1.0; // => true
1 === 1.0; // => false

// Comparisons between object instances
new stdClass() == new stdClass(); // => true, properties are equal
new stdClass() === new stdClass(); // => false, references are not identical
```
