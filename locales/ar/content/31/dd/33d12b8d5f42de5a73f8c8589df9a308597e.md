# مقدمة

## الأساسيات

لنبدأ رحلة C++ بالمتغيرات واستدعاءات الدوال والتعليقات.

### التعليقات

تأتي التعليقات على نوعين: تعليقات من سطر واحد وتعليقات متعددة الأسطر.
كل ما يأتي بعد `//` في السطر نفسه يتجاهله المترجم.
تُعرف التعليقات متعددة الأسطر أيضًا بتعليقات نمط C.
وهي محاطة بـ `/*` و `*/`.
وكل ما يأتي بينهما سيُتجاهل كذلك.

### المتغيرات

C++ لغة ذات أنواع.
يجب أن تكون كل الأنواع معروفة وقت الترجمة، وعليك عمومًا ذكرها صراحةً.
لا يمكن أن يتغير نوع المتغير.
يمكن تعريف متغير من النوع الصحيح باسم `years` هكذا:

```cpp
int years;
```

من الممارسات الجيدة تهيئة المتغيرات عند تعريفها.
وتوفّر C++ آليات مختلفة لفعل ذلك.
النسخة بالأقواس المعقوفة أكثر انسجامًا مع C++ الحديثة، لكن نسخة علامة المساواة شائعة جدًا أيضًا.

```cpp
int tomatoes{80};
int potatoes = 40;
```

~~~~exercism/caution
تسمح C++ فعلًا باستخدام متغيرات غير مهيّأة.
وإلى أن تُسند إلى المتغير قيمة عن قصد، يكون غير معرّف وقد يحتوي على أي شيء.
لتجنّب أخطاء الاستخدام قبل الإسناد والسلوك غير المعرّف، يُستحسن أن **تهيّئ دائمًا**.
قد يتسبب السلوك غير المعرّف في انهيار برنامجك في أسوأ لحظة ممكنة، رغم أنه كان يعمل بشكل جيد قبل ذلك.
لا يمكن التأكيد على هذا بما يكفي: تجنّب السلوك غير المعرّف مهما كان الثمن.
~~~~

### العمليات الحسابية

يمكن أن تكون العوامل الحسابية مثل `*` أو `+` أو `-` جزءًا من تعبير مثل `3 * 2` أو `tomatoes + potatoes`.

### تحديث المتغيرات

يمكنك إعادة إسناد المتغيرات، ما دامت تحافظ على نوعها:

```cpp
tomatoes = tomatoes - 5; // tomatoes is now 75
potatoes = (32 * 2) + 11; // potatoes is now 75 as well
```

### الدوال

للدوال اسم ونوع إرجاع وقائمة معاملات (قد تكون فارغة).
مثال على دالة باسم `always_fortyseven` تُرجع دائمًا 47 سيبدو هكذا:

```cpp
int always_fortyseven() {
    return 47;
}
```

وهذه `vip_fee`، ولها معامل واحد:

```cpp
int vip_fee(int standard_fee) {
    /*
    vip_fee calculates the vip fee based on the standard_fee.
    */
    int vip_multi{3};
    return standard_fee * vip_multi;
}
```

أو `total_fee`، دالة بثلاثة معاملات تستدعي دالة أخرى.

```cpp
int total_fee(int vips, int adults, int kids) {
    /*
    total_fee calculates the total price for a group of VIP and adult guests with kids.
    Kids get a flat discount on the standard fee.
    VIP guest fees are calculated by calling vip_fee.
    */
    int standard_fee{30};
    int kids_discount{15};

    int kids_total_fee = kids * (standard_fee - kids_discount);
    int vips_total_fee = vips * vip_fee(standard_fee);
    int adult_total_fee = adults * standard_fee;

    return vips_total_fee + adult_total_fee + kids_total_fee;
}
```

لا تُرجع الدوال في C++ قيمة العبارة الأخيرة كما تفعل بعض اللغات الأخرى.
الكلمة المفتاحية `return` ضرورية حتى يُترجم الكود.

### المسافات البيضاء

تُستخدم المسافات البيضاء لتنسيق الكود المصدري، وتشمل المسافات وعلامات الجدولة والأسطر الجديدة.
ولأن المترجم يتجاهل المسافات البيضاء غير الضرورية، يمكنك استخدامها لتنظيم الكود.
الاستخدام الذكي للمسافات البيضاء قد يحسّن قابلية قراءة الكود.
هناك معايير تنسيق مختلفة، لكنها كلها عرفية ولا يفرضها المترجم.

```cpp
// Formatting makes it easier to find bugs

int eggs_yolks =  3;
int      yeast = 15;

int flour=500;int sugar=200;// compact, but difficult to read
```
