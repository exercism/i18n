# التعليمات

تعمل Elaine على لعبة جديدة للأطفال تضم حيوانات وعصيًا سحرية. حان الوقت لكتابة دوال ترمي حجر النرد، وتولّد طاقة عشوائية للعصا السحرية، وتخلط شريحة.

## 1. ارمِ حجر النرد

نفّذ دالة `RollADie`.

سيكون هذا حجر النرد التقليدي ذا العشرين وجهًا، بأرقام من 1 إلى 20.

```go
d := RollADie() // d will be assigned a random int, 1 <= d <= 20
```

## 2. ولّد طاقة العصا السحرية

نفّذ دالة `GenerateWandEnergy`.
ينبغي أن تكون طاقة العصا السحرية عددًا عشريًا عشوائيًا أكبر من أو يساوي 0.0 وأقل من 12.0.

```go
f := GenerateWandEnergy()  // f will be assigned a random float64, 0.0 <= f < 12.0
```

## 3. اخلط شريحة

تتضمن اللعبة ثمانية حيوانات مختلفة:

- ant
- beaver
- cat
- dog
- elephant
- fox
- giraffe
- hedgehog

اكتب دالة `ShuffleAnimals` تُرجع شريحة تحتوي على الحيوانات الثمانية بترتيب عشوائي.
