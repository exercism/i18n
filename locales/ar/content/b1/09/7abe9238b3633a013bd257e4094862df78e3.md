# التعليمات

تدير أليزيه متجر أزياء عبر الإنترنت. يقترب موعد البيع السنوي الكبير، لذا تريد إنشاء بعض الوظائف للمساعدة في جرد المخزون.

يُمثَّل كل عنصر في المخزون باستخدام نوع مخصص.

```gleam
Item(
  name: "White Shirt",
  price: 40,
  quantity: 6,
)
```

## 1. أرجع مصفوفة بأسماء العناصر

نفّذ دالة `item_names`، التي تأخذ مكرّرًا من العناصر وتُرجع مكرّرًا بأسمائها بالترتيب نفسه.

```gleam
[
  Item(price: 65, name: "Maxi Brown Dress", quantity: 8),
  Item(price: 50, name: "Red Short Skirt", quantity: 0),
  Item(price: 29, name: "Black Short Skirt", quantity: 4),
  Item(price: 20, name: "Bamboo Socks Cats", quantity: 7),
]
|> iterator.from_list
|> item_names
|> iterator.to_list

// -> ["Maxi Brown Dress", "Red Short Skirt", "Black Short Skirt", "Bamboo Socks Cats"]
```

## 2. أرجع العناصر الرخيصة

نفّذ الدالة `cheap`، التي تأخذ مكرّرًا من العناصر وتُرجع مكرّرًا بالعناصر التي يقل سعرها عن 30.

```gleam
[
  Item(price: 65, name: "Maxi Brown Dress", quantity: 8),
  Item(price: 50, name: "Red Short Skirt", quantity: 0),
  Item(price: 29, name: "Black Short Skirt", quantity: 4),
  Item(price: 20, name: "Bamboo Socks Cats", quantity: 7),
]
|> iterator.from_list
|> cheap
|> iterator.to_list

// -> [
//   Item(price: 29, name: "Black Short Skirt", quantity: 4),
//   Item(price: 20, name: "Bamboo Socks Cats", quantity: 7),
// ]
```

## 3. أرجع العناصر التي نفد مخزونها

نفّذ الدالة `out_of_stock` التي تُرجع العناصر التي لا يتوفر لها مخزون.

```gleam
[
  Item(price: 65, name: "Maxi Brown Dress", quantity: 8),
  Item(price: 50, name: "Red Short Skirt", quantity: 0),
  Item(price: 29, name: "Black Short Skirt", quantity: 4),
  Item(price: 20, name: "Bamboo Socks Cats", quantity: 7),
]
|> iterator.from_list
|> out_of_stock
|> iterator.to_list

// -> [
//   Item(price: 50, name: "Red Short Skirt", quantity: 0),
// ]
```

## 4. أرجع إجمالي المخزون

نفّذ الدالة `total_stock` التي تحسب العدد الإجمالي للعناصر في مخزنك:

```gleam
[
  Item(price: 65, name: "Maxi Brown Dress", quantity: 8),
  Item(price: 50, name: "Red Short Skirt", quantity: 0),
  Item(price: 29, name: "Black Short Skirt", quantity: 4),
  Item(price: 20, name: "Bamboo Socks Cats", quantity: 7),
]
|> iterator.from_list
|> total_stock

// -> 19
```
