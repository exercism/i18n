# ملحق التعليمات

## الكلمات

- `tick ( matrix cols -- matrix' )`: تنقل الشبكة إلى الجيل التالي وتُرجع الشبكة الجديدة.

يُمثَّل كل صف من صفوف الشبكة بعدد صحيح 64 بت؛ و`cols` هو عدد الأعمدة (بحد أقصى 64). على سبيل المثال،

```
    0 1 0
    1 0 0
    1 1 0
```

تُمثَّل كما يلي:

```
0b010
0b100
0b110
```
