# نبذة

[السلاسل النصية][strings] في Haxe هي كائنات غير قابلة للتغيير تُمثّل نصًا على شكل تسلسل من محارف يونيكود (حروف، أرقام، علامات ترقيم، إلخ). تُستخدم علامات الاقتباس المزدوجة لتعريف نسخة من `string`:

```haxe
var fruit:String = "Apple";
```

يمكن التعامل مع السلسلة النصية باستدعاء إحدى [طرقها أو خصائصها][string-api]. وبما أن قيم السلاسل النصية لا يمكن أن تتغير أبدًا بعد تعريفها، فإن كل طرق التعامل مع السلاسل النصية ستُرجع سلسلة نصية جديدة.

تُحدّد السلسلة النصية بمحرفي علامة الاقتباس المزدوجة (`"`). تحتاج بعض المحارف الخاصة إلى [تخطٍّ][escaping] باستخدام محرف الشرطة المائلة العكسية (`\`). بالإضافة إلى ذلك، يمكن أن تمتد سلاسل Haxe على عدة أسطر، ما يتيح بناء سلاسل نصية حرفية طويلة بسهولة:

```haxe
var escaped:String = "c:\\test.txt";
var multiline:String = "
- apple
- pear
- banana";
```

أبسط أسلوب لدمج السلاسل النصية هو استخدام [عامل `+`][plus-operator].

```haxe
var name:String = "Jane";
trace("Hello " + name + "!");
// => "Hello Jane!"
```

لتنسيق أكثر تعقيدًا للسلاسل النصية، يُفضّل [إقحام السلاسل النصية][interpolation]. ويتم ذلك بإحاطة السلسلة النصية بمحرفي علامة الاقتباس المفردة (`'`) واستخدام علامة الدولار (`$`) لتشغيل إقحام المتغيرات. ويمكن أيضًا تقييم تعبيرات كاملة باستخدام `${expr}`، حيث `expr` أي تعبير صالح في Haxe:

```haxe
var name:String = "Jane";
trace('Hello $name!');
// => "Hello Jane!"
trace('HELLO ${name.toUpperCase()}!');
// => "HELLO JANE!"
```
