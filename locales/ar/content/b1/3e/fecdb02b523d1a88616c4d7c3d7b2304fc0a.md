# مقدمة

التعامل مع البيانات الثنائية مفهوم مهم في أي لغة، وتوفّر Elixir صيغة أنيقة لكتابة البيانات الثنائية ومطابقتها وبنائها.

في Elixir، يُشار إلى البيانات الثنائية بنوع سلسلة البتات. أما _نوع_ البيانات الثنائية (لا ينبغي الخلط بينه وبين البيانات الثنائية عمومًا) فهو شكل محدد من سلسلة البتات، وسنناقشه في تمرين لاحق.

تُعرَّف القيم الحرفية لسلسلة البتات باستخدام الصيغة الخاصة `<<>>`. وعند تعريف قيمة حرفية لسلسلة بتات، فإنها تُعرَّف على شكل مقاطع. لكل مقطع قيمة ونوع، يفصل بينهما العامل `::`. يحدد النوع عدد البتات التي ستُستخدم لترميز القيمة. ويمكن حذف النوع تمامًا، وفي هذه الحالة يكون الافتراضي قيمة عدد صحيح من 8 بتات.

```elixir
# This defines a bitstring with three segments of a single bit each
<<0::1, 1::1, 0::1>>
```

تحديد النوع بالصيغة `::1` اختصار لكتابة `::size(1)`. وتحتاج إلى استخدام الصيغة الأطول إذا كان حجم البتات يأتي من متغير.

## الثنائي

عند كتابة القيم الحرفية للأعداد الصحيحة الثنائية، يمكننا كتابتها مباشرة بترميز الأساس 2 عبر إضافة البادئة `0b` إلى القيمة الحرفية. لاحظ أنها ستُعرض على أي حال كأعداد عشرية عند طباعتها في نتائج الاختبارات أو عند استخدام `iex`.

```elixir
<<0b1011::4>> == <<11::4>>
# => true
```

## الاقتطاع

إذا تجاوزت قيمة المقطع سعة نوع المقطع، فستُقتطع البتات الزائدة من اليسار.

```elixir
<<0b1011::3>> == <<0b0011::3>>
# => true
```

## الإضافة في البداية والنهاية

يمكنك الإضافة إلى بداية سلسلة بتات موجودة وإلى نهايتها باستخدام الصيغة الخاصة. ويجب استخدام النوع `::bitstring` مع سلسلة البتات الموجودة إذا كان حجمها غير معروف.

```elixir
value = <<0b110::3, 0b001::3>>
new_value = <<0b011::3, value::bitstring, 0b000::3>>
# => <<120, 8::size(4)>>
```

## الدمج

يمكننا دمج سلاسل البتات المخزَّنة في متغيرات باستخدام الصيغة الخاصة. ويجب استخدام النوع `::bitstring` عند دمج سلسلتي بتات بحجمين غير معروفين.

```elixir
first = <<0b110::3>>
second = <<0b001::3>>
concatenated = <<first::bitstring, second::bitstring>>
# => <<49::size(6)>>
```

## مطابقة الأنماط

يمكن أيضًا استخدام مطابقة الأنماط للحصول على قيم من الصيغة الخاصة. عليك معرفة عدد البتات في كل جزء تريد التقاطه، باستثناء واحد: يمكن استخدام النوع `::bitstring` لمطابقة أنماط سلسلة بتات بحجم غير معروف، لكن هذا لا يصلح إلا للجزء الأخير.

```elixir
<<value::4, rest::bitstring>> = <<0b01101001::8>>
value == 0b0110
# => true
```

## فحص سلاسل البتات

~~~~exercism/note
قد تُطبع سلاسل البتات (بواسطة مشغّل الاختبارات أو في `iex`) بتنسيق مختلف عن التنسيق الذي استُخدم لإنشائها. وغالبًا ما يسبب ذلك ارتباكًا عند تعلّم سلاسل البتات.
~~~~

افتراضيًا، تُعرض سلاسل البتات في أجزاء من 8 بتات (بايت واحد)، حتى لو أنشأتها بأجزاء بحجم مختلف.

```elixir
<<2011::11>>
# => <<251, 3::size(3)>>
```

إذا أنشأت سلسلة بتات تمثل سلسلة نصية مطبوعة مرمّزة بترميز UTF-8، فستُعرض على هيئة سلسلة نصية.

```elixir
<<>>
# => ""

<<65, 66, 67>>
# => "ABC"
```
