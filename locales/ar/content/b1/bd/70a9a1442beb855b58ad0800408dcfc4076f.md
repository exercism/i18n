# نبذة

تنفّذ مكتبة Gleam القياسية نوع `Queue` في وحدة `gleam/queue`. وهو يشبه نوع `List`، لكن مع بعض الفروق الرئيسية:

- لا يملك نوع `Queue` صيغة حرفية يمكن استخدامها لإنشاء الطوابير أو لمطابقة أنماطها.
- يمكن إضافة العناصر إلى مقدمة نوع `Queue` ومؤخرته وإزالتها منهما بكفاءة، بينما لا يستطيع نوع `List` إضافة العناصر وإزالتها بكفاءة إلا من المقدمة.

في معظم الأحيان ستريد استخدام نوع `List`، لكن عندما تحتاج إلى إضافة عناصر إلى نهاية مجموعة وإزالتها منها، فإن نوع `Queue` خيار جيد.

يمكن إنشاء الطوابير باستخدام الدالتين `queue.new` و`queue.from_list`:

```gleam
let empty = queue.new()
let one_to_four = queue.from_list([1, 2, 3, 4])
```

يمكن إضافة العناصر إلى الطابور باستخدام الدالتين `queue.push_front` و`queue.push_back`:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
let one_to_five = queue.push_back(one_to_four, 5)
let zero_to_five = queue.push_front(one_to_five, 0)
```

يمكن إزالة العناصر من الطابور باستخدام الدالتين `queue.pop_front` و`queue.pop_back`:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])

queue.pop_back(one_to_four)
// -> Ok(#(4, queue.from_list([1, 2, 3])))

queue.pop_front(one_to_four)
// -> Ok(#(1, queue.from_list([2, 3, 4])))

queue.pop_front(queue.new())
// -> Error(Nil)
```

يمكن تحويل الطابور إلى مصفوفة باستخدام دالة `queue.to_list`:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
queue.to_list(one_to_four)
// -> [1, 2, 3, 4]
```

## تساوي الطوابير

بسبب طريقة تنفيذ الطوابير، قد لا يكون طابوران يحويان العناصر نفسها بالترتيب نفسه متساويين وفقًا لعامل `==` الذي يقارن القيم بنيويًا. على سبيل المثال:

```gleam
let empty = queue.new()
let a = queue.push_front(empty, 1)
let b = queue.push_back(empty, 1)
a == b
// -> False
```

إذا احتجت إلى مقارنة طابورين للتحقق من تساويهما، فيمكنك استخدام دالة `queue.is_logically_equal`.

```gleam
queue.is_logically_equal(a, b, fn(x, y) { x == y })))
// -> True
```
