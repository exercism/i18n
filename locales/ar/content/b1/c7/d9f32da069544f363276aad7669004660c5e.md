# تلميحات

## عام

- كل كلمة تتعلق بالقراءة والكتابة توجد في [`io.files`][io.files]؛ وترميز `utf8` الذي تأخذه جميعها يأتي من [`io.encodings.utf8`][utf8].

## 1. اقرأ كل قراءة

- تُرجع `file-lines` مصفوفة من الأسطر بعد إزالة محارف السطر الجديد.

## 2. جد أحدث قراءة

- اقرأ الأسطر باستخدام `file-lines`، ثم خذ العنصر `last` (من `sequences`).

## 3. اقرأ السجل الخام

- تُرجع `file-contents` الملف على هيئة سلسلة نصية واحدة، بما في ذلك محارف السطر الجديد.

## 4. سجّل قراءة

- افتح الملف للإلحاق، ثم استخدم `print` لطباعة القراءة داخل الاقتباس: `with-file-appender ( path encoding quot -- )`. تُستخدم القراءة داخل الاقتباس بينما يُستهلك المسار قبل القراءة، لذا تُبقي المتغيرات المحلية `::` جسم الاقتباس مقروءًا: `:: record-reading ( reading path -- ) path utf8 [ reading print ] with-file-appender ;`.

## 5. أعد كتابة السجل

- تكتب `set-file-lines` كل عنصر من عناصر المتسلسلة في سطر خاص به، وتضيف محارف السطر الجديد نيابةً عنك.
