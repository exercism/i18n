# ملحق التعليمات

## السجلات

| السجل | الاستخدام | النوع | الوصف |
| -------- | --------- | ------- | ------------------------------------------- |
| `$a0`    | إدخال     | عنوان | سلسلة نصية منتهية بمحرف فارغ من المحارف الست عشرية |
| `$v0`    | إخراج     | عدد صحيح | القيمة العشرية للسلسلة النصية المُدخلة      |
| `$t0-9`  | مؤقت      | أي     | تُستخدم للتخزين المؤقت                      |
