# مقدمة

## التعدادات

يمثّل نوع `enum` في C# مجموعة ثابتة من الثوابت المُسمّاة (التعداد). وغرضه الرئيسي توفير طريقة آمنة نوعيًا للتعامل مع الثوابت العددية، بحيث تحصر القيم المتاحة في مجموعة محددة مسبقًا. ويمكن تعريف تعداد بسيط كما يلي:

```csharp
enum Season
{
    Spring,
    Summer,
    Autumn,
    Winter
}
```

إذا لم تُعرَّف القيم صراحةً، فسيُسنَد إلى أعضاء التعداد تلقائيًا قيم عددية صحيحة متزايدة، وتكون القيمة الأولى هي الصفر. ويمكن أيضًا إسناد القيم صراحةً:

```csharp
enum Answer
{
    Maybe = 1,
    Yes = 3,
    No = 5
}
```
