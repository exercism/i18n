# Docker

تُنشر المحلّلات لدينا كصور Docker.

اقرأ [معلومات Docker العامة الخاصة بالأدوات](/docs/building/tooling/docker) لتتعرّف على كيفية عملها.

## التكامل

عندما نشغّل محلّلًا لتحليل حل، نشغّل أمر Docker يبدو هكذا:

```shell
docker run \
        --rm \
        --network none \
        --mount type=bind,src="${solution_dir}",dst=/solution \
        --mount type=bind,src="${output_dir}",dst=/output \
        --tmpfs /tmp:rw \
        "exercism/${track_slug}-analyzer" \
        "${exercise_slug}" "/solution" "/output"
```

كما ترى، نمرّر ثلاث وسائط إلى صورة Docker:

1. مُعرّف التمرين
2. مسار دليل الحل
3. مسار دليل المخرجات

## الاصطلاحات

تستخدم جميع المحلّلات لدينا الاصطلاحات التالية في تنفيذها:

- يوجد ملف `Dockerfile` في الدليل الجذر للمستودع.
- يجب أن يكون دليل العمل هو `/opt/analyzer`.
- نقطة الدخول هي `/opt/analyzer/bin/run.sh`
- يأخذ السكربت `/opt/analyzer/bin/run.sh` ثلاث وسائط:
  1. مُعرّف التمرين
  2. مسار دليل الحل
  3. مسار دليل المخرجات

لمزيد من المعلومات، راجع [الواجهة](/docs/building/tooling/analyzer/interface).

```exercism/note
ستستخدم مستودعات المحلّلات الجديدة هذه الاصطلاحات افتراضيًا.
```
