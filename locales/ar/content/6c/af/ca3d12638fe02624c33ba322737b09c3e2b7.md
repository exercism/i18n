# الأمداء

[الأمداء][range] تمثّل فترة بين قيمتين.
أكثر الأنواع شيوعًا التي تدعم الأمداء هي `Integer` و`String`.
يمكن استخدامها في أمور كثيرة، مثل إنشاء مجموعة بسرعة، وتقطيع السلاسل النصية، والتحقق مما إذا كانت قيمة ما ضمن مدى، والتكرار.
وتُنشأ باستخدام عامل المدى `..` أو `...` (شامل وغير شامل على الترتيب).

```ruby
1..5  # => 1..5
1...5 # => 1...5

(1..5).to_a # => [1, 2, 3, 4, 5]
(1...5).to_a # => [1, 2, 3, 4]
```

السبب في وجود عاملي مدى هو السماح بإنشاء أمداء تشمل قيمة النهاية أو تستثنيها، وقد يكون ذلك مفيدًا عندما تتعامل مثلًا مع فهارس تبدأ من الصفر.

يمكن أيضًا إنشاء الأمداء باستخدام باني `Range`، أي `new`.

```ruby
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
عند إنشاء مدى في Ruby باستخدام عاملي المدى `..` أو `...`، ثم أردت استدعاء طريقة على المدى، فستحتاج إلى إحاطة المدى بالأقواس الهلالية.
لأن الطريقة ستُستدعى، بخلاف ذلك، على الوسيط الثاني لعامل المدى.

```ruby
(1..5).sum # => 15
1..5.sum # => Error: undefined method `sum' for 5:Integer (NoMethodError)
```
~~~~

## الحصول على سلاسل فرعية

عندما تريد تقطيع سلسلة نصية، يمكنك استخدام عامل المدى للحصول على سلسلة فرعية.
أي بإنشاء مدى يحدد فهرسَي بداية السلسلة الفرعية ونهايتها.

```ruby
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

يمكنك أيضًا استخدام فهارس سالبة للحصول على السلسلة الفرعية من نهاية السلسلة النصية.

```ruby
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## طرق الأمداء

للأمداء مجموعة من الطرق يمكن استخدامها للتعامل معها.
على سبيل المثال، يمكن استخدام هذه الطرق للحصول على مجموع كل القيم في المدى أو التحقق مما إذا كان المدى يتضمن قيمة.

| الطريقة                 | الوصف                                                                    | المثال                          |
| ----------------------- | ----------------------------------------------------------------------- | ------------------------------- |
| [`sum`][sum]            | تُرجع مجموع كل القيم في المدى                                            | `(1..5).sum # => 15`            |
| [`size`][size]          | تُرجع حجم المدى                                                          | `(1..5).size # => 5`            |
| [`include?`][indlude]   | تُرجع `true` إذا كان المدى يتضمن القيمة المعطاة، وإلا فتُرجع `false`      | `(1..5).include?(3) # => true` |

## الأمداء اللانهائية والأمداء بلا بداية

يمكن أن يكون المدى لانهائيًا وبلا بداية.
في المدى اللانهائي أو المدى بلا بداية تكون قيمة البداية أو النهاية مساوية لـ `nil`، ولكن يمكن حذف `nil` عند تعريف المدى.

يكون استخدام الأمداء بلا بداية واللانهائية مفيدًا عندما تريد، على سبيل المثال، تقطيع سلسلة نصية من بدايتها أو حتى نهايتها.

```ruby
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello "
```

~~~~exercism/caution
إذا لم يُستخدم على مجموعة، فقد يتسبب المدى اللانهائي في تسلسل لا نهائي إن لم يُستخدم بحذر.
~~~~

## أمداء السلاسل النصية

يمكن أيضًا استخدام السلاسل النصية في الأمداء، ما يتيح الحصول على فترة من السلاسل النصية بين سلسلتين.
وقد يكون سلوكها غير متوقع بعض الشيء مع سلاسل نصية معينة، لذا استخدمها بحذر.

```ruby
("aa".."az").to_a # => ["aa", "ab", "ac", ..., "az"]
```
