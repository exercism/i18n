# التعليمات

في هذا التمرين ستكتب كودًا لطباعة شارات الأسماء لموظفي المصنع.

## 1. اطبع شارة لموظف

لدى الموظفين معرّف واسم واسم قسم. تُنسَّق تسميات شارات الموظفين على النحو التالي: `"[id] - name - DEPARTMENT"`. نفّذ الطريقة (_static_) `Badge.Print()` لتُرجع تسمية شارة الموظف:

```csharp
Badge.Print(734, "Ernest Johnny Payne", "Strategic Communication");
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

لاحظ أنه يجب كتابة اسم القسم بأحرف كبيرة في التسمية.

## 2. اطبع شارة لموظف جديد

بسبب خلل في نظام الحاسوب، لا يملك الموظفون الجدد أحيانًا معرّفًا بعد عندما يبدأون العمل في المصنع. ولأن الشارات مطلوبة، سيحصلون على شارة مؤقتة بدون بادئة المعرّف. عدّل الطريقة (_static_) `Badge.Print()` لتدعم الموظفين الجدد الذين ليس لديهم معرّف بعد:

```csharp
Badge.Print(id: null, "Jane Johnson", "Procurement");
// => "Jane Johnson - PROCUREMENT"
```

## 3. اطبع شارة للمالك

حتى مالك المصنع عليه أن يرتدي شارة في جميع الأوقات. لكن المالك ليس لديه قسم. في هذه الحالة، يجب أن تطبع التسمية `"OWNER"` بدلًا من اسم القسم. عدّل الطريقة (_static_) `Badge.Print()` لتطبع تسمية للمالك:

```csharp
Badge.Print(254, "Charlotte Hale", department: null);
// => "[254] - Charlotte Hale - OWNER"
```

لاحظ أنه من الممكن أن يكون المالك أيضًا موظفًا جديدًا:

```csharp
Badge.Print(id: null, "Charlotte Hale", department: null);
// => "Charlotte Hale - OWNER"
```
