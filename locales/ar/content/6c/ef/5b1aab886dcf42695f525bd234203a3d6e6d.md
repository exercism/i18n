# مقدمة

تحتوي كثير من لغات البرمجة على أنواع عددية محددة لتمثيل أنواع مختلفة من الأعداد، لكن JavaScript لا تمتلك سوى نوعين:

- `number`: نوع بيانات عددي بصيغة الفاصلة العائمة ذات الدقة المزدوجة وبسعة 64 بت (IEEE 754).
  ومن أمثلته `-6` و`-2.4` و`0` و`0.1` و`1` و`3.14` و`16.984025` و`25` و`976` و`1024.0` و`500000`.
- `bigint`: نوع بيانات عددي يمكنه تمثيل _الأعداد الصحيحة_ بصيغة الدقة الاعتباطية.
  ومن أمثلته `-12n` و`0n` و`4n` و`9007199254740991n`.

إذا كنت تحتاج إلى [الدقة الاعتباطية][ref-arbitrary-precision] أو تتعامل مع أعداد كبيرة للغاية، فاستخدم النوع `bigint`.
وإلا فإن النوع `number` هو الخيار الأفضل على الأرجح.

## التقريب

يوجد كائن عام مدمج يُدعى `Math` يوفّر [دوال تقريب][ref-math-object-rounding] متنوعة. على سبيل المثال، يمكنك تقريب الأعداد العشرية إلى أقرب عدد صحيح، سواء للأسفل (`floor`) أو للأعلى (`ceil`).

```javascript
Math.floor(234.34); // => 234
Math.ceil(234.34); // => 235
```
