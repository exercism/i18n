# مقدمة

## البنى والأصناف

البنى والأصناف من اللبنات الأساسية في برمجة Swift. وكلاهما وسيلة لتجميع البيانات والدوال المترابطة في وحدات وظيفية قائمة بذاتها. وعندما تُعرّف بنيةً أو صنفًا، فأنت تُعرّف نوعًا جديدًا لاستخدامه داخل Swift، تمامًا كما استخدمت الأنواع التي عملت بها من قبل، مثل `Int` و`String`.

توجد أوجه تشابه كثيرة بين البنى والأصناف في Swift. فمن بين أوجه التشابه الأخرى، يستطيع كلاهما تخزين القيم في _خصائص_ وتقديم الوظائف من خلال استخدام _طرق_.

ويقدّم كلٌّ منهما بعض الوظائف الإضافية التي تخرج عن نطاق هذا التمرين.

### تعريف البنى والأصناف

تُعرَّف البنى والأصناف بالطريقة نفسها تقريبًا. فهي تبدأ بالكلمة المفتاحية المناسبة، تليها اسم النوع الذي يُعرَّف، ثم يأتي جسم البنية/الصنف موضوعًا بين الأقواس المعقوفة.

قد يتكون الجسم من خصائص مخزنة، تُعرَّف وتتصرّف تمامًا مثل الثوابت أو المتغيرات العادية.

```swift
struct CharacterStats {
  var health = 0.0
  var speed = 0
  var strength = 0
}

class GameCharacter {
  var stats = CharacterStats()
  var characterClass: String?
  var name: String?
  var active = false
  let id = makeRandomID()
}
```

### النسخ

كما ذُكر أعلاه، تعريف بنية أو صنف ليس سوى تعريف _نوع_ جديد. وهو مجرد مخطط لما ستبدو عليه قيم ذلك النوع، لكنه لا يُنشئ فعليًا أي قيم من ذلك النوع لتعمل عليها.

ولإنشاء _نسخة_ من ذلك النوع، عليك كتابة اسم النوع متبوعًا بزوج من الأقواس الهلالية.

```swift
let someStats = CharacterStats()
let someCharacter = GameCharacter()
```

سيؤدي هذا إلى إنشاء قيم من هذه الأنواع، حيث تُملأ الخصائص بالقيم الافتراضية المزوّدة في التعريف. لاحظ أنه في الحالات الاختيارية، مثل خاصية `name` في GameCharacter، وما لم تُزوَّد الخاصية بقيمة، فستكون قيمتها الافتراضية nil، تمامًا كما عند تعريف أنواع اختيارية عادية لا تُزوَّد فيها القيمة على الفور.

وفي حالة البنى، توفر Swift تلقائيًا شيئًا يُسمى _مهيّئ الأعضاء_، حيث يمكن تزويد قيم خصائص البنية داخل الأقواس الهلالية، فتستبدل القيم الافتراضية الواردة في التعريف.

```swift
let differentStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

### الوصول إلى الخصائص

يمكن الوصول إلى خصائص البنية والصنف باستخدام _الترميز النقطي_، حيث يتبع اسم القيمة نقطة (`.`) ثم اسم الخاصية. وإذا كانت لخاصية في بنية أو صنف خصائص خاصة بها، فيمكن استخدام هذا الترميز النقطي للوصول إلى هذه الخصائص المتداخلة أيضًا.

ويمكن استخدام هذا الترميز لاسترجاع قيمة الخاصية، وكذلك، حيثما كان ذلك مسموحًا، لتغييرها.

```swift
someStats.health
// => 0
someCharacter.name
// => nil

someStats.health = 87.3
someStats.health
// => 87.3
someCharacter.name = "Luther"
someCharacter.name
// => "Luther"

someCharacter.id  = "new id"
// Error: Cannot assign to property: 'id' is a 'let' constant
```

### الطرق

وكما هو الحال مع الخصائص التي تخزّن البيانات في بنيتك وأصنافك، يمكنك أيضًا تعريف _طرق_ تخزّن دوال في بنيتك أو صنفك.

تُعرَّف الطرق بالطريقة نفسها التي تُعرَّف بها الدالة العادية، لكن داخل جسم البنية أو الصنف فقط. لاحظ أنه إذا غيّرت دالة قيمة خاصية داخل بنية، فيجب أن تسبقها الكلمة المفتاحية `mutating`. وإضافةً إلى ذلك، إذا كان بإمكان طريقة تغيير خاصية، فيجب تعريف تلك الخاصية باستخدام `var` بدلًا من `let`، تمامًا مثل المتغيرات العادية.

```swift
struct CharacterStats {
  var health = 0.0
  var speed = 0
  var strength = 0

  mutating func takeHit(_ damage: Double) {
    health = max(0.0, health - damage)
  }
  func canLift(_ weight: Int) -> Bool {
    weight < strength * 100
  }
}

class GameCharacter {
  var stats = CharacterStats()
  var characterClass: String?
  var name: String?
  var active = false
  let id: String = makeRandomID()

  func takesDamage(_ damage: Double) {
    stats.takeHit(damage)
    if stats.health <= 0 {
      active = false
    }
  }
  func sayName() -> String {
    return "My name is \(name ?? "no one"), my class is \(characterClass ?? "undetermined")"
  }
  func lift(_ weight: Int) -> String {
    if stats.canLift(weight) {
      return "No problem!"
    } else {
      return "Ooof! No way."
    }
  }
}
```

ويمكن استدعاء هذه الطرق باستخدام الترميز النقطي، تمامًا مثل الخصائص.

```swift
var myChar = GameCharacter()
myChar.stats = CharacterStats(health: 72.8, speed: 19, strength: 6)
myChar.active = true

myChar.lift(750)
// => "Ooof! No way."
myChar.takesDamage(80)
myChar.active
// => false
```

### Self

تحتوي كل نسخة من بنية أو صنف على خاصية ضمنية تُسمى `self`، وتشير إلى النسخة نفسها.
والاستخدام الأكثر شيوعًا لـ `self` هو إزالة الالتباس بين خاصية النسخة ومعامل يحمل الاسم نفسه:

```swift
struct Position {
    var x = 0

    mutating func move(x: Int) {
        // Here, 'self.x' refers to the struct's property,
        // while 'x' refers to the parameter passed to the method.
        self.x = x
    }
}
```

وتوفر أنواع Swift أيضًا كلمة مفتاحية `Self` بحرف كبير، تشير إلى *نوع* النسخة بدلًا من النسخة نفسها.
