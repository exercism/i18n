# التعليمات

في مختبر أبحاث DNA الخاص بك، كنت تجرّب طرقًا متعددة لضغط بيانات بحثك لتوفير مساحة التخزين. يقترح أحد زملائك في الفريق تحويل بيانات DNA إلى تمثيل ثنائي:

| الحمض النووي | الكود   |
| ------------ | ------ |
| مسافة        | `0000` |
| A            | `0001` |
| C            | `0010` |
| G            | `0100` |
| T            | `1000` |

تتأمل الفكرة، فهي قد تخفض تكاليف تخزين البيانات المطلوبة إلى النصف، لكن على حساب سهولة القراءة البشرية. تقرر كتابة وحدة لترميز بياناتك وفك ترميزها لقياس مقدار التوفير الذي ستحققه.

## 1. ترميز الحمض النووي إلى قيمة ثنائية

نفّذ `encode_nucleotide/1` لتقبل نقطة الكود الخاصة بالحمض النووي وتُرجع القيمة الصحيحة للكود المُرمَّز.

```elixir
DNA.encode_nucleotide(?A)
# => 1
# (which is equal to 0b0001)
```

## 2. فك ترميز القيمة الثنائية إلى الحمض النووي

نفّذ `decode_nucleotide/1` لتقبل القيمة الصحيحة للكود المُرمَّز وتُرجع نقطة الكود الخاصة بالحمض النووي.

```elixir
DNA.decode_nucleotide(0b0001)
# => 65
# (which is equal to ?A)
```

## 3. ترميز قائمة محارف DNA

نفّذ `encode/1` لتقبل قائمة محارف تمثّل أحماضًا نووية وفجوات، وتُرجع البيانات بعد ترميزها في صورة سلسلة بتات.

```elixir
DNA.encode(~c"AC GT")
# => <<18, 4, 8::size(4)>>
```

## 4. فك ترميز سلسلة بتات DNA

نفّذ `decode/1` لتقبل سلسلة بتات تمثّل أحماضًا نووية وفجوات، وتُرجع البيانات بعد فك ترميزها في صورة قائمة محارف.

```elixir
DNA.decode(<<132, 2, 1::size(4)>>)
# => ~c"TG CA"
```
