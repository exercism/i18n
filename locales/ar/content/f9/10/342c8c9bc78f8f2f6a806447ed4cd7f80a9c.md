# مقدمة

*quotation* هي قطعة من الكود توضع بين الأقواس المربعة `[ ]`. وهي قيمة: يمكنك دفعها إلى المكدّس، أو تمريرها إلى كلمة أخرى، أو تخزينها في مصفوفة.

```factor
[ 1 + ] .          ! => [ 1 + ]
5 [ 1 + ] call .   ! => 6
```

معظم الكلمات ذات الرتبة الأعلى تأخذ *quotation* وسيطًا ثانيًا لها:

```factor
{ 1 2 3 } [ sq ] map .    ! => { 1 4 9 }
{ 1 2 3 } [ even? ] filter .  ! => { 2 }
```

جسم الـ*quotation* ليس إلا كود Factor عاديًا: نفس العوامل وتأثيرات المكدّس التي تستخدمها في كل مكان آخر.

عندما تبني كودًا من بيانات، بدمج الأجزاء بعضها ببعض أو بربط الرموز بالعمليات، تكون النتيجة تسلسلًا؛ مرّرها عبر `>quotation` لتصبح قابلة للاستدعاء:

```factor
{ [ 1 ] [ 2 + ] [ 3 * ] } concat >quotation call .   ! => 9
```
