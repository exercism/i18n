# مقدمة

مثل الجملة الشرطية `if/else`، تتيح لك عبارة `switch` تغيير مسار البرنامج عبر تنفيذ الكود بشكل شرطي.
الفرق أن عبارة `switch` لا يمكنها سوى مقارنة قيمة تعبير أولي أو سلسلة نصية بقيم ثابتة محددة مسبقًا.

بعض الكلمات المفتاحية مفيدة عند استخدام عبارة `switch`.

- `switch`: تتيح لك هذه الكلمة المفتاحية الإعلان عن بنية `switch`.
  ويتبعها التعبير أو المتغير الذي سيغيّر النتيجة.
- `case`: ستستخدم هذه الكلمة المفتاحية للإعلان عن الاحتمالات المختلفة للنتيجة.
- `break`: الكلمة المفتاحية `break` مفيدة جدًا لإيقاف تنفيذ `switch` عند نهاية المسار المطلوب.
  إذا نسيتها، سيتابع البرنامج وقد يؤدي ذلك إلى نتائج غير متوقعة.
- `default`: كما يوحي الاسم، استخدمها كنتيجة افتراضية عندما لا تطابق أي `case` أخرى نتيجة تعبيرك.

في أبسط صورها، تختبر تعبيرًا أوليًا أو سلسلة نصية وتتخذ قرارًا بناءً على قيمته.
على سبيل المثال:

```java
String direction = getDirection();
switch (direction) {
    case "left":
        goLeft();
        break;
    case "right":
        goRight();
        break;
    default:
        // otherwise
        markTime();
        break;
}
```
