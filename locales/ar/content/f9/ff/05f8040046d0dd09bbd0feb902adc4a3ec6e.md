# نبذة

التعبير المنطقي سؤال يُطرح على قيمة واحدة أو أكثر، ويمكن الإجابة عنه بـ `true` أو `false`.
التعبير الذي قيمته صحيحة يُرجع `1`، والتعبير الذي قيمته خاطئة يُرجع `0`.
كذلك، للأعداد قيم صحيحة أو خاطئة: الصفر `false`، وغير الصفر `true`.

الكود القديم المكتوب بلغة C إما أن يستخدم النوع `int` مباشرةً لتمثيل القيم المنطقية، أو يكون المبرمج قد عرّف ثوابت مثل `TRUE` و`FALSE` لربط `1` و`0` بتمثيل منطقي.

وفي الإصدار C99 أُضيف النوع `_Bool`.
يعرّف ملف الترويسة `stdbool.h` ثلاثة رموز منطقية جديدة: `bool` و`true` و`false`.
يُقابل `true` القيمة `1`، ويُقابل `false` القيمة `0`، ويُقابل `bool` النوع `_Bool`.
فالآن، بدلًا من استخدام `int` مباشرةً أو ابتكار تمثيلات منطقية خاصة بهم، يمكن للمبرمجين تضمين `stdbool.h` والحصول تلقائيًا على الرموز المنطقية في كودهم.

## عوامل المقارنة

تدعم لغة C ستة عوامل مقارنة: `==` (يساوي)، `!=` (لا يساوي)، `>` (أكبر من)، `<` (أصغر من)، `>=`(أكبر من أو يساوي)، `<=` (أصغر من أو يساوي).
تقارن هذه العوامل العلاقات بين القيم وتحوّلها إلى قيم منطقية.

```c
0 == 0 // true. Although 0 is false, 0 equals 0 is true.
0 != 0 // false
1 > 0 // true
1 < 0 // false
1 >= 0 // true
1 <= 0 // false
```

## العوامل المنطقية

تدعم C ثلاثة عوامل منطقية: `||` (أو)، `&&` (و)، و`!` (ليس). 

يُستخدم `!` مع طرف واحد.
فيعكس القيمة المنطقية لهذا الطرف.
فمثلًا، قيمة `0` هي `false`، لكن قيمة `!0` هي `true`.

أما `||` و`&&` فيُستخدمان مع طرفين.
ولا يُقيَّم الطرف الأيمن إلا إذا لم يكن الطرف الأيسر قد حدّد نتيجة التعبير بالفعل.
أي أن `||` لا يُقيّم طرفه الأيمن إلا إذا أعطى طرفه الأيسر القيمة `false`.
و`&&` لا يُقيّم طرفه الأيمن إلا إذا أعطى طرفه الأيسر القيمة `true`.


## التقييم القصير

عدم تقييم جميع الأطراف يُعرف بـ«التقييم القصير».
التقييم القصير أسلوب موجز وقوي للتعامل مع مواقف معيّنة.
فمثلًا، من الأساليب الشائعة التحقق من أن المؤشر ليس `NULL`، ثم (`&&`) إن لم يكن `NULL`، فك الإشارة إليه، وبذلك نتجنب فك الإشارة إلى مؤشر `NULL`.
لكن التقييم القصير قد يؤدي أيضًا إلى bugs.
أحيانًا ينسى المبرمج أن الطرف الأيمن في `||` أو `&&` قد لا يُقيَّم دائمًا.
فإذا كان الطرف الأيمن تعبيرًا له أثر جانبي متوقع حدوثه دائمًا، فسيكون ذلك bug يتوقف على القيمة المنطقية للطرف الأيسر.


## إرجاع تعبير منطقي

يمكن إرجاع نتيجة التعبير المنطقي مباشرةً.
فمثلًا، جملة `if` الشرطية هذه

```c
if (count > 0)
    return true;
else
    return false;
end
```

يمكن استبدالها بـ

```c
return count > 0;
```
