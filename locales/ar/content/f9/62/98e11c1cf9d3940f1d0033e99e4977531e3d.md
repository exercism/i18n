# حول

تُستخدم القيمة `null` للدلالة على _غياب_ القيمة. النوع **القابل لأن يكون `null`** هو نوع يسمح للمتغير بأن يأخذ القيمة `null`. ولجعل أي نوع كذلك، نغلّفه بـ `Null<T>`:

```haxe
var a:Int = null; // Error
var b:Null<Int> = null; // Allowed
```

للتحقق مما إذا كانت قيمة ما تساوي `null` في الوقت الحالي، استخدم ببساطة تعبير `if`:

```haxe
var a:Null<Int> = 10;

if (a != null) {
  trace("a is not null"); // a is not null
}
```
