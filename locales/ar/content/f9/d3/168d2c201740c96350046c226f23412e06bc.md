# نبذة

في Go، السلاسل النصية غير قابلة للتغيير. ربط السلاسل النصية باستخدام `+` داخل حلقة يؤدي إلى تخصيصات متكررة ونسخ البيانات عدة مرات. توفر [حزمة `strings`](https://pkg.go.dev/strings) النوع [`Builder`](https://pkg.go.dev/strings#Builder) لتقليل الحمل على الذاكرة عبر تجميع السلاسل النصية بكفاءة.

## بناء السلاسل النصية

القيمة الصفرية لـ `strings.Builder` جاهزة للاستخدام فورًا دون أي تهيئة صريحة أو تخصيص. يمكنك دفع بيانات جديدة إلى الباني باستخدام طرق كتابة محددة. كل طريقة كتابة تُرجع قيمة خطأ لتتوافق مع واجهات Go القياسية، لكنها مضمونة أن تكون `nil` دائمًا، ويُتجاهلها عادةً في الكود اليومي.

أكثر الطرق استخدامًا هي:

- `WriteString(s string) (int, error)`: تُلحق سلسلة نصية بالمخزن المؤقت.
- `WriteRune(r rune) (int, error)`: تُلحق ترميز UTF-8 الخاص بـ `rune`.
- `WriteByte(c byte) error`: تُلحق بايتًا واحدًا.

```go
var sb strings.Builder

sb.WriteString("Hello")
var r rune = ' '
sb.WriteRune(r)
var b byte = '.'
sb.WriteByte(b)
```

## الاسترجاع وإعادة التهيئة

بمجرد انتهائك من تجميع النص، يمكنك استخراج المحتوى المتراكم كسلسلة نصية قياسية في Go عبر استدعاء الطريقة `String()`. استدعاء `String()` عملية رخيصة جدًا لأنها تُرجع شريحة البايتات الأساسية كسلسلة نصية مباشرة دون نسخ البيانات المتراكمة.

إذا احتجت إلى إعادة استخدام نفس نسخة الباني لتجميع سلسلة نصية جديدة (مثلًا داخل حلقة)، يمكنك استدعاء الطريقة `Reset()`. تُفرغ هذه الطريقة المخزن المؤقت الداخلي، ما يتيح لك البدء من جديد وبناء السلسلة النصية التالية مع الاحتفاظ داخليًا بسعة الذاكرة المخصصة مسبقًا.

```go
var sb strings.Builder

sb.WriteString("Task One")
fmt.Println(sb.String()) // Output: Task One

// Clear the buffer for resource reuse
sb.Reset()

sb.WriteString("Task Two")
fmt.Println(sb.String()) // Output: Task Two
```
