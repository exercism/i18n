# مقدمة

## عوامل المقارنة

تمتلك لغة R مجموعة من العوامل المشابهة لتلك الموجودة في كثير من اللغات الأخرى:

```R
1 == 2 # FALSE
1 != 2 # TRUE
1 < 2 # TRUE
1 > 2 # FALSE
1 <= 2 # TRUE
1 >= 2 # FALSE
```

## التشعب

الصيغة الأساسية للجملة الشرطية `if-else` هي 

```R
if (x > 10) {
    y <- "big"
} else if (x > 2) {
    y <- "medium"
} else {
    y <- "tiny"
}
```

في هذه الحالة، لا بد من الأقواس الهلالية `()` حول القيمة المنطقية والأقواس المعقوفة `{}` حول العبارة.
يمكن اختصار الجملة الشرطية `if` البسيطة:

```R
if (x == 0) return("success")
```
