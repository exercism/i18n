# مقدمة

## المزيد عن الأنماط

تذكّر من مفهوم الأساسيات أن برنامج AWK يتكوّن من **أزواج النمط والإجراء**.

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

### ما الذي نعنيه بـ«النمط»؟

«النمط» هو أي تعبير في AWK.
ويحدّد كون نتيجة التعبير صحيحة أو خاطئة ما إذا كان الإجراء سيُنفَّذ.

### النمط الفارغ

يمكن حذف النمط.
وفي هذه الحالة يُنفَّذ الإجراء عند كل سجل.

يمكننا طباعة كل أسماء المستخدمين في ملف passwd.

```sh
awk -F: '{print $1}' /etc/passwd
```

### التعبيرات النمطية

يستطيع AWK مقارنة السلاسل النصية بالتعبيرات النمطية للحصول على قيمة منطقية.

استخدم عامل مطابقة التعبيرات النمطية `~` لمطابقة حقل معيّن.
يأخذ هذا العامل سلسلة نصية بوصفها المعامل الأيسر، وتعبيرًا نمطيًا بوصفه المعامل الأيمن.
ويُحاط التعبير النمطي الحرفي بشرطتين مائلتين `/`.

للعثور على المستخدمين في ملف passwd الذين يسجّلون الدخول باستخدام bash:

```sh
awk -F: '$7 ~ /bash/ {print $1}' /etc/passwd
```

`!~` هو عامل «التعبير النمطي **لا** يطابق».

ولمطابقة تعبير نمطي مع السجل الحالي، يمكنك كتابة `$0 ~ /regex/`.
هذا شائع لدرجة أن هناك صيغة مختصرة: يمكنك حذف `$0` و`~` وكتابة `/regex/` مباشرة

```sh
awk '/regex/' data.txt
```

~~~~exercism/note
قارن أمر AWK ذاك المؤلف من سطر واحد بما يكافئه من أمر grep

```sh
grep 'regex' data.txt
```

يمنحك AWK لغة برمجة كاملة دون التضحية بالإيجاز.
~~~~

سنتعمّق أكثر في طابع التعبيرات النمطية في GNU AWK في مفهوم لاحق.

### التعبيرات

يمكن استخدام تعبيرات AWK (حسابية أو منطقية أو غير ذلك) كأنماط.

لاستخراج كل المستخدمين ذوي معرّف المستخدم 1000 أو أعلى:

```sh
awk -F: '$3 >= 1000' /etc/passwd
```

تذكّر أن القيم الخاطئة في AWK هي العدد صفر والسلسلة النصية الفارغة، وأن كل الأعداد أو السلاسل النصية الأخرى صحيحة.
وأي تعبير يُقيَّم إلى عدد أو سلسلة نصية يمكن استخدامه كنمط.

### الدوال

يمكن استخدام أي دالة [مدمجة][builtins] أو [معرّفة من المستخدم][user-defined] في تعبير، ومن ثم في النمط.
مثالان:

```awk
length($1) {print "first field is not empty"}
```
```awk
toupper(substr($1, 1, 1)) ~ /[AEIOU]/ {print "starts with a vowel"}
```

### الأنماط الثابتة

من الأساليب الشائعة في AWK:

```sh
{
    xyz()   # some code that transforms each record
}
1
```

`1` هو نمط صحيح بلا إجراء مرتبط به.
هذا يعني «اطبع السجل الحالي».
