# نبذة

تُعرف الأنواع التي تُنفّذ الواجهة [`IEnumerable<T>`][IEnumerable] بأنها _قابلة للتعداد_.
وتُنفّذ جميع أنواع المجموعات المدمجة هذه الواجهة.

يمكن المرور على عناصر النوع القابل للتعداد باستخدام حلقة `foreach`:

```csharp
var primes = new[] { 2, 3, 5, 7 };
foreach (var prime in primes)
{
    Console.Write(prime);
}
// => 2357
```

ولتنفيذ `IEnumerable<T>`، على النوع أن يُنفّذ طريقة واحدة: `IEnumerator<T> GetEnumerator()`.
وكما رأينا، يُفوّض النوع القابل للتعداد عملية المرور الفعلية على المجموعة إلى نوع `IEnumerator<T>`.
وتحتوي هذه الواجهة على خاصية واحدة وثلاث طرق لتنفيذها:

- `public T Current { get; }`: الحصول على العنصر الحالي.
- `public bool MoveNext ();`: الانتقال إلى العنصر التالي، وتُرجع `true` إذا نجح الانتقال إلى العنصر التالي، و`false` إن لم ينجح (لا مزيد من العناصر).
- `public void Reset ();`: إعادة المُعدِّد إلى حالته الأولية (قبل العنصر الأول).

[IEnumerable]: https://docs.microsoft.com/en-us/dotnet/api/system.collections.generic.ienumerable-1
