# التثبيت

## أي إصدار تختار؟

نشجّعك على استخدام إصدار PHP مستقر يحظى بدعم فعّال.
حاليًا هذه الإصدارات هي **PHP 8.2 و8.3 و8.4**.
تجد تفاصيل الإصدارات الحالية وجداولها الزمنية في [وثائق PHP الرسمية](https://www.php.net/supported-versions.php).

## ثبّت PHP

توفّر معظم مديري الحزم على Linux وmacOS حزمًا جاهزة.
يمكنك تنزيل PHP وبناؤه من المصدر، وهو متاح على [php.net/downloads.php](https://php.net/downloads.php) أو [windows.php.net/download](https://windows.php.net/download).

~~~~exercism/note
لا تحتاج إلى خادم ويب مثل nginx أو خادم Apache HTTP لإكمال التمارين.
~~~~

### Linux

تختلف الطريقة بين التوزيعات المختلفة.
ينبغي أن تكون قادرًا على

```shell
yum install php
```

أو

```shell
apt-get install php
```

حسب مدير الحزم لديك.

لمزيد من التعليمات، اقرأ دليل PHP حول [التثبيت على أنظمة Unix](https://www.php.net/manual/en/install.unix.php).

### macOS

مع أن PHP غالبًا ما يأتي مضمّنًا مع macOS، فإنه كثيرًا ما يكون قديمًا.
نوصي بتثبيت PHP عبر [Homebrew](https://brew.sh/).
يمكنك تثبيت Homebrew باتباع التعليمات [على صفحته الرئيسية](https://brew.sh/#install).

للتأكد من تثبيته، جرّب الأمر التالي، وينبغي أن يُخرج Homebrew `4.5.x` وقت كتابة هذه الوثيقة.

```shell
brew --version 
```

ثبّت PHP عبر homebrew

```shell
brew install php@8.4
```

ينبغي أن يعرض هذا الإصدار المثبّت الآن من PHP، وهو `8.2.0` على الأقل.

```shell
php -v
```

لمزيد من التعليمات، اقرأ الدليل حول [التثبيت على macOS](https://www.php.net/manual/en/install.macosx.php).

### Windows

يمكنك تنزيل ملفات PHP التنفيذية الرسمية لنظام Windows من [windows.php.net/download](https://windows.php.net/download).

توجد حزم جاهزة منها [WAMP](https://www.wampserver.com/en/) (Windows وApache وMySQL وPHP) و[XAMPP](https://www.apachefriends.org/de/index.html).

لمزيد من التعليمات، اقرأ الدليل حول [التثبيت على أنظمة Windows](https://www.php.net/manual/en/install.windows.php).

### Docker

إذا كنت تفضّل الحلول المعتمدة على الحاويات، يمكنك تنزيل [صورة PHP الرسمية من Docker Hub](https://hub.docker.com/_/php).
ستحتاج أيضًا إلى [Docker](https://docs.docker.com/engine/install/).

### أنظمة أخرى

إذا أردت استخدام نظام تشغيل آخر، فاطّلع على التعليمات على [php.net/manual/en/install](https://www.php.net/manual/en/install.php).

## ثبّت PHPUnit

~~~~exercism/note
لم يُدعم PHPUnit 12 بعد!
~~~~

### عبر أرشيف PHP (PHAR)

أسهل طريقة لاستخدام PHPUnit في تمارين Exercism هي تنزيل توزيعة مغلّفة كأرشيف PHP (PHAR)، وهي أيضًا الطريقة الموصى بها لاستخدام PHPUnit.
ضع ملف PHAR حيث وضعت واجهة سطر الأوامر `exercism` لتشغيل PHPUnit من أي مكان.

يمكنك تنزيل إصدار من حزم PHPUnit كأرشيف PHP:

```shell
wget -O phpunit.phar https://phar.phpunit.de/phpunit-11.phar
```

ثم اجعل الملف الذي نزّلته قابلًا للتنفيذ:

```shell
chmod +x phpunit.phar
```

وانقله إلى الموضع نفسه الذي نقلت إليه واجهة سطر الأوامر `exercism`، وسمِّ الأمر `phpunit`:

```shell
mv phpunit.phar ~/bin/phpunit
```

الآن يمكنك تشغيل `phpunit` من أي مكان، كما هو موضّح في [وثائق اختبار مسار PHP](https://exercism.org/docs/tracks/php/tests):

```shell
phpunit --version
```

ينبغي أن يبدو الناتج هكذا:

```text
PHPUnit 11.5.45 by Sebastian Bergmann and contributors.
```

يمكنك أيضًا اتباع [تعليمات تثبيت PHPUnit](https://docs.phpunit.de/en/11.5/installation.html#installing-phpunit) الرسمية لتثبيت PHPUnit.

### عبر Composer

يمكن أيضًا تثبيت PHPUnit الإصدار 11 عبر [Composer](https://getcomposer.org).

#### ثبّت Composer

ثبّت [Composer](https://getcomposer.org) باتباع [تعليمات التثبيت](https://getcomposer.org/doc/00-intro.md) الخاصة بنظام تشغيل جهازك. نوصي بتثبيته تثبيتًا عامًّا ليسهل استخدامه.

#### أضف PHPUnit كأداة عامة

باستخدام الأمر التالي:

```shell
composer global require phpunit/phpunit ^11.5
```

تأكد من تثبيت الإصدار 11.5 أو أحدث.
