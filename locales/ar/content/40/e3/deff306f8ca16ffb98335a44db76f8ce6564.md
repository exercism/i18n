# مقدمة

توجد معظم البيانات في Factor داخل *المتتاليات*. تشترك المصفوفات (`{ … }`) والمتجهات (`V{ … }`) والسلاسل النصية جميعًا في البروتوكول نفسه من [`sequences`][sequences].

```factor
{ 1 2 3 } length .    ! => 3
{ 1 2 3 } first .     ! => 1
{ 1 2 3 } last .      ! => 3
{ 1 2 3 4 5 } 3 head .! => { 1 2 3 }
```

التجميعات مثل `sum` و`count` و`any?` و`all?`، والمحمولات مثل `empty?` و`member?` تعمل بشكل موحّد عبر كل نوع من أنواع المتتاليات. بناء متتاليات جديدة دون تحوير: `prefix` و`suffix` و`append` و`unclip` و`unclip-last`.

تقوم `>array` و`>vector` و`>string` (في [`arrays`][arrays] والمفردات المقابلة) بالتحويل بين أنواع المتتاليات عندما تحتاج إلى الحصول مرة أخرى على نوع ملموس معيّن من عملية عامة.

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
