# نبذة

يدعم ABAP العوامل الحسابية المعتادة على القيم الرقمية:

- `+` يجمع القيم.
- `-` يطرح القيم.
- `*` يضرب القيم.
- `/` يقسم القيم.
- `MOD` يُرجع باقي القسمة الصحيحة.

```abap
DATA total TYPE i.
total = 6 + 4 * 2.

DATA remaining_days TYPE i.
remaining_days = 70 MOD 22.
```

تُحسب عمليتا الضرب والقسمة قبل الجمع والطرح. استخدم الأقواس الهلالية عندما يلزم تجميع الحساب صراحةً.

```abap
DATA result TYPE i.
result = ( 6 + 4 ) * 2.
```
