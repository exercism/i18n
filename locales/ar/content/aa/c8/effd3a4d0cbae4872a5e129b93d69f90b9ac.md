# نبذة

تُمثَّل القيم المنطقية في C# بالنوع `bool`، الذي يمكن أن تكون قيمته إما `true` أو `false`.

تدعم C# أربعة [عوامل منطقية][operators]: `!` (NOT)، و`&&` (AND)، و`||` (OR)، و`^` (XOR). ويستخدم العاملان `&&` و `||` _التقييم قصير الدائرة_، أي أن الطرف الأيمن من العامل لا يُقيَّم إلا عند الحاجة.

```csharp
true || false // => true
true && false // => false
true ^ false  // => true
true ^ true   // => false
```

لكل من العوامل المنطقية الثلاثة [_أسبقية_][precedence] مختلفة. ونتيجة لذلك، تُقيَّم بهذا الترتيب: `not` أولًا، ثم `&&`، ثم `^`، وأخيرًا `||`. وإذا أردت "الخروج" عن هذه القواعد، يمكنك وضع تعبير منطقي بين الأقواس الهلالية (`()`)، لأن الأقواس الهلالية لها أسبقية أعلى في العوامل.

```csharp
!true && false   // => false
!(true && false) // => true
```
