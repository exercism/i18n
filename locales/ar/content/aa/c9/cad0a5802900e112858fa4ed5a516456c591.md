# نبذة

بينما اعتاد مبرمجو Elixir على مقولة «دعه ينهار» وكتابة الكود من أجل «المسار السعيد»، فكثيرًا ما نحتاج إلى التقاط الخطأ في نداء الدالة لإرجاع قيمة محددة أو رسالة، أو لتحرير موارد النظام.

- الدوال التي ترفع أخطاءً في الظروف العادية ينبغي أن تنتهي أسماؤها بعلامة `!`.
- ويمكن للدوال بدلًا من ذلك أن تُرجع ذرّات وصفوفًا للدلالة على النجاح والفشل:

  ```elixir
  Map.fetch(%{a: 1}, :a)
  # => {:ok, 1}
  Map.fetch(%{a: 1}, :b)
  # => :error

  Map.fetch!(%{a: 1}, :b)
  # => raises KeyError
  ```

## تجنّب الأنماط المضادة

تجنّب أنماط البرمجة التي تستخدم الأخطاء للتحكم في التدفق المنطقي. هذا نمط مضاد في Elixir.

```elixir
# Avoid using errors for control-flow.
try do
  {:ok, value} = MyModule.janky_function()
  "All good! #{value}."
rescue
  e in RuntimeError ->
    reason = e.message
    "Uh oh! #{reason}."
end

# Rather, use control-flow structures for control-flow.
case MyModule.janky_function() do
  {:ok, value} -> "All good! #{value}."
  {:error, reason} -> "Uh oh! #{reason}."
end
```
