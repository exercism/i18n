# ملحق التعليمات

## السجلات

| السجل | الاستخدام | النوع | الوصف |
| -------- | --------- | ------- | ------------------------------------------------- |
| `$a0`    | إدخال     | عدد صحيح | العدد الابتدائي                                   |
| `$v0`    | إخراج     | عدد صحيح | عدد الخطوات المتوقع، و -1 إذا كان العدد غير صالح |
| `$t0-9`  | مؤقت | أي نوع     | يُستخدم للتخزين المؤقت                        |
