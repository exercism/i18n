# مقدمة

في Elixir، يمكننا تعريف سمات الوحدة التي يمكن استخدامها كثوابت في دوالنا.

```elixir
defmodule Example do
  # Defines the attribute as the value 1
  @constant_number 1

  def example_value() do
    # Returns the value 1
    @constant_number
  end
end
```

عند استخدامها لتعريف ثوابت الوحدة، يمكن أن تكون السمات أي تعبير يمكن تقييمه في وقت التصريف. بعد التصريف، لا يمكن الوصول إلى سمات الوحدة لأنها تُوسَّع أثناء التصريف، على غرار الماكروات المعرّفة في لغات مثل C.
