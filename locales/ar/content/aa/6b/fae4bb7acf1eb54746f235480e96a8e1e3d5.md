# حول

الجمل الشرطية هي عبارات تنفذ كودًا مختلفًا حسب ما إذا كان الشرط `true` أو `false`.

جملة [`if` الشرطية][if_statement] تنفذ جسمها فقط عندما يكون شرطها `true`. لا يوجد في Go مفهوم القيم الصحيحة أو الخاطئة، لذا يجب أن يكون الشرط من النوع `bool`. تعبيرات مثل `if mySlice { ... }` أو `if 1 { ... }` هي أخطاء تصريف.

```go
func describe(val string) string {
    if val == "val" {
        return "was val"
    }
    return "was not val"
}
```

استخدم `else if` للتحقق من شروط إضافية، و`else` كخيار احتياطي إذا لم يتحقق أي منها. يتم تقييم الشروط من الأعلى إلى الأسفل، وسيتم تنفيذ الفرع الأول فقط الذي يكون شرطه صحيحًا.

```go
number := 0
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

عمومًا، تفضّل Go الإرجاع المبكر من الحالة الاستثنائية وتجنّب `else`.

```go
func getVal(connected bool) int {
    if !connected {
        return readLocalVal()
    }

    return readVal()
}
```

يمكن أن تتضمن جملة `if` الشرطية أيضًا عبارة تهيئة قصيرة. يُستخدم هذا عادةً للتحقق من خطأ مباشرةً بعد استدعاء:

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```

المتغيرات المعرّفة في عبارة التهيئة تكون فقط في النطاق داخل تسلسل `if`/`else` بأكمله. ومن الجدير بالذكر أن Go لا تحتوي على عامل ثلاثي، وهو خيار تصميمي متعمد للحفاظ على سهولة قراءة الكود.

لمعرفة المزيد، راجع [Go by Example: If/Else][go_by_example_if].
