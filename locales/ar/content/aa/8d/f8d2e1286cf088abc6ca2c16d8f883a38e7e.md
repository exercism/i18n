# إضافة التعليمات

## السجلات

| Register | Usage     | Type    | Description                                      |
| -------- | --------- | ------- | ------------------------------------------------ |
| `$a0`    | مُدخَل     | عنوان   | سلسلة نصية للإدخال منتهية بـ `null`               |

| `$t0-9`  | مؤقت      | أي نوع  | تُستخدم للتخزين المؤقت                            |
