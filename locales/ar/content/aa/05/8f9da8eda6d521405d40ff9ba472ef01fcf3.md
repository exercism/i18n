# الاختبار من سطر الأوامر

نفّذ الاختبارات بالأمر التالي:

```bash
$ cargo test
```

جميع الاختبارات باستثناء الأول تم تجاهلها. بعد أن تنجح في اجتياز الاختبار الأول، افتح ملف الاختبارات المصدري الموجود في مجلد `tests`، وأزل السمة `#[ignore]` من الاختبار التالي ثم اجتزه بنجاح مرة أخرى. كل اختبار منفصل هو دالة تحمل السمة `#[test]` فوقها. استمر على هذا النحو حتى تجتاز كل الاختبارات.

إذا أردت تشغيل الاختبارات _المُتجاهَلة فقط_ دون تعديل ملف الاختبارات المصدري، فاستخدم:

```bash
$ cargo test -- --ignored
```

إذا كنت تستخدم Rust 1.51 أو أحدث، فيمكنك تشغيل _جميع_ الاختبارات بالأمر:

```bash
$ cargo test -- --include-ignored
```

لتشغيل اختبار محدد، مثل `some_test`، يمكنك استخدام:

```bash
$ cargo test some_test
```

وإذا كان الاختبار المحدد متجاهلًا، فاستخدم:

```bash
$ cargo test some_test -- --ignored
```

لمعرفة المزيد عن اختبارات Rust، راجع [توثيق الاختبارات][rust-tests] على الإنترنت.

[rust-tests]: https://doc.rust-lang.org/book/ch11-02-running-tests.html
