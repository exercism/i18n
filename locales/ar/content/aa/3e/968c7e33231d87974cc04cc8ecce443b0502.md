# ملحق التعليمات

## السجلات

| السجل | الاستخدام | النوع | الوصف |
| -------- | --------- | ------- | --------------------------------------------------------- |
| `$a0`    | إدخال     | عنوان | سلسلة نصية للإدخال تنتهي بمحرف `null`                     |
| `$v0`    | إخراج     | قيمة منطقية | يحتوي المدخل على أقواس متوازنة (`0` = `false`، `1` = `true`) |
| `$t0-9`  | مؤقت      | أي | يُستخدم للتخزين المؤقت                                     |
