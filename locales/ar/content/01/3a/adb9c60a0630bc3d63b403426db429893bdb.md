# نبذة

يمكن فهم الواجهة على أنها توقيع الصنف، لأنها تصف الحقول العامة للصنف. الصنف _يُنفّذ_ واجهة `interface` باستخدام الكلمة المفتاحية `implments`.

بنيتها تشبه إلى حد كبير بنية الصنف، إلا أن الطرق تظهر فيها كتوقيعات بدون أجسام:

```haxe
interface Language {
  private var languageName:String;

  public function speak():String;
}

class FrenchSpeaker implements Language {
  var languageName = "French";

  public function speak():String {
    return "Bonjour!";
  }
}
```

الحقول التي تُنفَّذ انطلاقًا من واجهة **يجب** أن تستخدم دائمًا مُعدِّل الرؤية نفسه. على سبيل المثال، إذا كان المتغير `a` موسومًا بـ `public` في واجهة، فيجب أن يكون تنفيذه `public` أيضًا.
