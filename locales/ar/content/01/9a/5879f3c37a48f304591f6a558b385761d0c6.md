# مقدمة

التوثيق في Elixir مواطن من الدرجة الأولى.

هناك سمتان للوحدة تُستخدمان عادةً لتوثيق الكود: `@moduledoc` لتوثيق وحدة، و`@doc` لتوثيق دالة تلي السمة. تظهر سمة `@moduledoc` عادةً في السطر الأول من الوحدة، وتظهر سمة `@doc` عادةً مباشرةً قبل تعريف دالة، أو قبل مواصفة النوع الخاصة بالدالة إن وُجدت. ويُكتب التوثيق عادةً داخل سلسلة نصية متعددة الأسطر باستخدام صيغة heredoc.

توثيق Elixir مكتوب باستخدام [**Markdown**][markdown].

```elixir
defmodule String do
  @moduledoc """
  Strings in Elixir are UTF-8 encoded binaries.
  """

  @doc """
  Converts all characters in the given string to uppercase according to `mode`.

  ## Examples

      iex> String.upcase("abcd")
      "ABCD"

      iex> String.upcase("olá")
      "OLÁ"
  """
  def upcase(string, mode \\ :default)
end
```

[markdown]: https://docs.github.com/en/github/writing-on-github/basic-writing-and-formatting-syntax
