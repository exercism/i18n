# مقدمة

## المحارف

### المحارف

النوع الأولي `char` في Java هو تمثيل بـ16 بتة لمحرف واحد.
يمكن أن تتكوّن سلسلة نصية من عدة محارف من النوع `char`، مثل `"word"`، كما يمكن معالجة كل محرف من النوع `char` على حدة.
القيمة الحرفية من النوع `char` تُحاط بعلامة اقتباس مفردة (مثل `'A'`).

```java
char lowerA = 'a';
char upperB = 'B';
```

### الحصول على محارف `String`

تُرجع طريقة `String.toCharArray` محارف السلسلة النصية في هيئة مصفوفة.
وكما ذُكر في المصفوفات، يمكنك استخدام حلقة `for` للمرور على عناصر المصفوفة.

```java
String text = "Hello";
char[] asArray = text.toCharArray();

for (char ch: asArray) {
    System.out.println(ch);
}

// Outputs:
// H
// e
// l
// l
// o
```

### صنف `Character`

توجد طرق مدمجة كثيرة في المكتبة لفحص المحارف من النوع `char` ومعالجتها.
يمكن إيجادها كطرق ساكنة في صنف `java.lang.Character`.
إليك بعض الأمثلة:

```java
Character.isWhitespace(' ');    // true
Character.isWhitespace('#');    // false

Character.isLetter('a');        // true
Character.isLetter('3');        // false

Character.isDigit('6');         // true
Character.isDigit('?');         // false
```

### إضافة محرف من النوع `char` إلى سلسلة نصية

يمكن استخدام العامل `+` لإضافة محرف من النوع `char` إلى سلسلة نصية.

```java
'a' + " banana"     // => "a banana"
"banana " + 'a'     // => "banana a"
```

~~~~exercism/caution
احذر _ألا_ تستخدم `+` لضم محرفين من النوع `char` معًا لتكوين سلسلة نصية!
إضافة محرفين بهذه الطريقة تعطي `int`، وليس سلسلة نصية!
على سبيل المثال:

```java
'b' + 'c';
// => 197 (not the String "bc")
```

وذلك لأن Java ترفع المحرف من النوع `char` إلى `int` (انظر [4.2 الأنواع الأولية والقيم][jls-primitives] في [مواصفات لغة Java][jls-main]).

[jls-main]: https://docs.oracle.com/javase/specs/jls/se21/html/
[jls-primitives]: https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.2
~~~~

ومع ذلك، عندما يكون عدد المحارف المراد إضافتها كبيرًا، فقد يكون من الأكثر كفاءة استخدام `StringBuilder` بدلًا من ذلك:

```java
StringBuilder builder = new StringBuilder();
builder.append('a');
builder.append('b');
builder.append('c');

String builtString = builder.toString();
// => abc
```
