# استخدام الاستدعاء الذَّيلي

الغرض من هذا التمرين هو تعليم الاستدعاء الذَّيلي. حلّه دون استخدام دوال عودية غير ذيلية.

الدوال العودية الذيلية الموجودة في حلك: %{tail_call_recursive_functions}. الدوال العودية الأخرى الموجودة في حلك: %{non_tail_call_recursive_functions}.

تذكّر أن الاستدعاء الذَّيلي يحدث عندما يكون التعبير _الأخير_ الذي تُقيّمه الدالة استدعاءً لنفسها.

```elixir
# this is tail call recursion,
# the last expression is a call to `do_encode`
defp do_encode([n | rest], acc) do
  do_encode(rest, <<acc::bitstring, encode_nucleotide(n)::4>>)
end

# this is not tail call recursion,
# the last expression is a call to `<<>>`
def encode([head | tail]) do
  <<encode_nucleotide(head)::4, encode(tail)::bitstring>>
end
```
