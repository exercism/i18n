# ملحق التعليمات

## تنسيق الإخراج

أخرِج كلمات الأغنية على هيئة سلسلة نصية منتهية بـ `null`.

## السجلات

| السجل    | الاستخدام     | النوع   | الوصف                          |
| -------- | ------------ | ------- | ------------------------------ |
| `$a0`    | إدخال        | عدد صحيح | مقطع البداية                   |
| `$a1`    | إدخال        | عدد صحيح | مقطع النهاية                   |
| `$a2`    | إدخال/إخراج  | عنوان   | سلسلة نصية للإخراج منتهية بـ `null` |
| `$t0-9`  | مؤقت         | أي      | للتخزين المؤقت                 |
