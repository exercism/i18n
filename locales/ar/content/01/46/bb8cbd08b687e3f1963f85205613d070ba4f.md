# مقدمة

الجمل الشرطية عبارات تنفّذ كودًا مختلفًا تبعًا لما إذا كان الشرط `true` أم `false`.

لا تنفّذ الجملة الشرطية `if` جسمها إلا إذا كان شرطها `true`.
لا يوجد في Go مفهوم القيم الصحيحة أو الخاطئة ضمنيًا، لذلك يجب أن يكون الشرط من النوع `bool`.
تعبيرات مثل `if mySlice { ... }` أو `if 1 { ... }` تُسبب أخطاء تصريف.

```go
func describe(val string) string {
    if val == "val" {
        return "was val"
    }
    return "was not val"
}
```

استخدم `else if` للتحقق من شروط إضافية، و`else` كخيار احتياطي إذا لم يتحقق أي منها.
تُقيَّم الشروط من الأعلى إلى الأسفل، ولن يُنفَّذ إلا أول فرع يكون شرطه صحيحًا.

```go
number := 0
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

يمكن أن تتضمن الجملة الشرطية `if` أيضًا عبارة تهيئة قصيرة.
المتغيرات المعرَّفة بهذه الطريقة لا تكون ضمن النطاق إلا داخل سلسلة `if`/`else` كاملة.

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```
