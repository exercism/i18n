# Debug

يمكنك استخدام [Debug.log](https://package.elm-lang.org/packages/elm/core/latest/Debug#log) لإرفاق رسائل بالاختبارات الفاشلة، هكذا:

```elm
hoursToSeconds : Int -> Int
hoursToSeconds hours =
    let
        secondsInOneHour =
            Debug.log "secondsInOneHour" (60 * 60)
    in
    hours * secondsInOneHour
```

عند فشل اختبار، سيكون السجل المرفق هو `secondsInOneHour: 3600`.

هناك تحذير واحد: تُقيَّم الثوابت على المستوى الأعلى مرة واحدة فقط قبل أن تبدأ الاختبارات بالعمل، لذلك لا تستطيع الاختبارات التقاط رسائل سجلها. على سبيل المثال:

```elm
secondsInOneHour : Int
secondsInOneHour =
    Debug.log "secondsInOneHour" (60 * 60)
```

لن يسجّل أي شيء أثناء الاختبارات لأن متغير JavaScript المرتبط بـ `secondsInOneHour` قد قُيِّم بالفعل إلى القيمة 3600.
