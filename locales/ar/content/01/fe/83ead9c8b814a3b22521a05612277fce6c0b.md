# الدوال

الدوال أساسية في Cairo.

بحسب الاصطلاح، يستخدم Cairo **حالة الثعبان** لأسماء الدوال والمتغيرات، حيث تكون الكلمات بأحرف صغيرة ويفصل بينها شرطات سفلية.

إليك مثالًا:

```rust
fn another_function() {
    println!("Another function.");
}

fn main() {
    println!("Hello, world!");
    another_function();
}
```

تُعرَّف الدوال باستخدام `fn`، متبوعة باسم، ثم الأقواس الهلالية للمعاملات (إن وُجدت)، ثم جسم محاط بالأقواس المعقوفة.

يمكنك استدعاء دالة باسمها متبوعًا بالأقواس الهلالية.

ترتيب الدوال لا يهم ما دامت ضمن النطاق.

## المعاملات

يمكن للدوال أن تأخذ **معاملات**، وهي متغيرات مُعرَّفة في توقيع الدالة.

عند استدعاء الدالة، تُقدِّم **وسائط**، وهي القيم التي تُمرَّر إلى هذه المعاملات.

```rust
fn main() {
    another_function(5);
}

fn another_function(x: felt252) {
    println!("The value of x is: {}", x);
}
```

هنا، `x` معامل من النوع `felt252`.

عند استدعائها بالقيمة `5`، تطبع الدالة "The value of x is: 5".

تُفصل المعاملات المتعددة بفواصل:

```rust
fn main() {
    print_labeled_measurement(5, "h");
}

fn print_labeled_measurement(value: u128, unit_label: ByteArray) {
    println!("The measurement is: {value}{unit_label}");
}
```

يطبع هذا: `The measurement is: 5h`.

## العبارات والتعبيرات

تتكوّن دوال Cairo من **عبارات** و**تعبيرات**:

- **العبارات** تنفّذ إجراءات لكنها لا تُرجع قيمًا.
على سبيل المثال، `let x = 3;` عبارة.
- **التعبيرات** تُقيَّم إلى قيمة.
على سبيل المثال، `5 + 6` تُقيَّم إلى `11`.

الكتل المحاطة بالأقواس المعقوفة هي أيضًا تعبيرات، وتُرجَع قيمتها الأخيرة:

```rust
fn main() {
    let y = {
        let x = 3;
        x + 1
    };
    println!("The value of y is: {}", y);
}
```

هنا، تُسند القيمة `4` إلى `y`.

## القيم المُرجَعة

يمكن للدوال أن تُرجع قيمًا باستخدام الصيغة `->` لتحديد نوع الإرجاع.

افتراضيًا، تُرجع الدالة قيمة تعبيرها الأخير:

```rust
fn five() -> u32 {
    5
}

fn main() {
    let x = five();
    println!("The value of x is: {}", x);
}
```

يُخرج هذا: `The value of x is: 5`.

في الحالات الأكثر تعقيدًا:

```rust
fn plus_one(x: u32) -> u32 {
    x + 1
}

fn main() {
    let x = plus_one(5);
    println!("The value of x is: {}", x);
}
```

يطبع هذا: `The value of x is: 6`.

احرص على عدم إضافة فاصلة منقوطة في نهاية التعبير الأخير، لأن ذلك سيحوّل التعبير إلى عبارة، مما يجعل الدالة تُرجع `()` (نوع الوحدة) بدلًا من القيمة المتوقعة.
