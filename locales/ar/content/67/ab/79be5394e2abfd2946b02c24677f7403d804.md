# نبذة

Elm لغة وظيفية خالصة، لذا لا توجد فيها عبارات، بل تعبيرات فقط، وكل دالة فيها ليست إلا تعبيرًا واحدًا.

يشجّع هذا على كتابة دوال صغيرة وبسيطة، وهو عمومًا أمر جيد، لكن الدوال تصير أحيانًا أكثر تعقيدًا بشكل لا مفر منه، فنحتاج إلى أسلوب يضمن كتابة هذه الدوال بأناقة.

وهنا يأتي دور تعبيرات `let`. فهي تتكون من جزأين: قسم `let` حيث يمكنك إنشاء ما تحتاج إليه من تعريفات، ثم قسم `in`، وهو تعبير واحد يمكنه استخدام هذه التعريفات.

من منظور الحوسبة، يُنشئ `let` نطاقًا محليًا بالنسبة إلى التعبير الموجود في قسم `in`.

يفيد تعبير `let` في بضع حالات:

- تبسيط التعبيرات
- تسمية نتائج التعبيرات الوسيطة
- تقسيم التعبير إلى أجزاء أصغر إذا صار كبيرًا

يمكنك أن تفعل معظم الأشياء داخل تعبير `let`، بما في ذلك التفكيك، لكن ما يلي غير مسموح به:

- الأنواع المخصصة
- الأسماء المستعارة للأنواع
- تظليل الأسماء (لا يمكنك إعادة تعريف اسم موجود بالفعل في النطاق أو إعادة استخدامه)

## تبسيط التعبيرات

هذا التعبير يجمع مكعبات 3 أرقام، لكن قراءته صعبة، ويسهل أن يختلف الحساب من رقم لآخر.

```elm
(a * a * a) + (b * b * b) + (c * c * c)
```

يمكننا تعريف دالة `cube` داخل تعبير `let` لنجعل الحساب أبسط وأكثر تعبيرًا وأكثر أمانًا. وقد يكون لدى هذه الدالة تعليق نوعي، لكن هذا نادر نسبيًا في الكود الاصطلاحي في Elm.

```elm
let
  cube x = x * x * x
in
  cube a + cube b + cube c
```

## تسمية نتائج التعبيرات الوسيطة

يعرّف هذا الكود `sideArea` و`topArea` ليجعل الحساب أبسط وأكثر تعبيرًا.

```elm
cylinderArea : Float -> Float -> Float
cylinderArea radius height =
    let
        sideArea = 2 * pi * radius * height
        topArea = pi * radius ^2
    in
        sideArea + 2 * topArea
```

## تقسيم تعبير كبير

ينشئ هذا الكود نمطًا أوليًا للعبة [Game of Life](https://playgameoflife.com/) (وهي تمرين برمجي شائع يُستخدم كمثال).

ليس من المهم أن تفهم بالضبط كيف يعمل، لكن نأمل أن يكون واضحًا أنه سيكون كبيرًا جدًا لو كُتب كتعبير واحد، بدون `let`.

```elm
beginWithPattern : Size -> Padding -> Pattern -> GameOfLife
beginWithPattern minimumSize padding pattern =
    let
        size = calculateSize minimumSize padding pattern

        center = Size.center size

        centeredPattern = Pattern.centerAt center pattern

        dimensions = { width = size, height = size }

        deadCells = Matrix.create dimensions Dead
    in
    GameOfLife (bringPatternToLife deadCells centeredPattern)
```
