# نبذة

في Haxe، يمكن تعريف تسلسل هرمي للأصناف باستخدام _الوراثة_، وهي تسمح لصنف مشتق (`Car`) بأن يرث سلوك صنفه الأصل (`Vehicle`) وبياناته.

في الصنف الأصل، يمكنك:

- تعريف طرق يمكن تجاوزها
- تعريف طرق مجردة يجب أن تنفّذها الأصناف المشتقة

```haxe
abstract class Vehicle {
  public function new() {}

  // Can be overridden
  public function drive() {
    // ...
  }

  // Must be implemented
  public abstract function getSpeed():Int;
}

class Car extends Vehicle {
  public function new() {
    super(); // Runs the parent class' constructor
  }

  public override function drive() {
    // ...
  }

  public function getSpeed():Int {
    // ...
  }
}
```

إذا كان للصنف الأصل منشئ، فإننا نستخدم `super()` لاستدعائه:

```haxe
abstract class Vehicle {
  var wheels:Int;

  public function new(wheels:Int) {
    this.wheels = wheels
  }
}

class Car extends Vehicle {
  var color:String;

  public function new(wheels:Int, color:String) {
    super(wheels);
    this.color = color;
  }
}

```
