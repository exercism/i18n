# مقدمة

يمكن للعديد من أنواع أعضاء البنية والصنف (الحقول هي الاستثناء الأساسي) استخدام صيغة الأعضاء ذات الجسم التعبيري. غالبًا ما ينتج تعريف عضو باستخدام تعبير كودًا أكثر إيجازًا وأسهل قراءة من الكتل أو العبارات التقليدية.

الطرق والخصائص للقراءة فقط من بين الأعضاء التي يمكن تعريفها بأجسام تعبيرية.

```csharp
public int Times3(int input) => input * 3;

public int Interesting => 1729;
```
