# كيفية استخدام Markdown في الإرشاد

يمكنك استخدام Markdown في تعليقاتك الإرشادية على GitHub.
يتيح لك ذلك تضمين مقتطفات من الكود، وإضافة عناوين، وخط عريض، وخط مائل، وقوائم، وغير ذلك، واقتباس جمل سابقة.

ندعم أيضًا بعض عناصر «Markdown بنكهة GitHub» على Exercism، وتحديدًا تظليل الصياغة، والجداول، والشطب.

إذا لم تكن على دراية بـ Markdown أو إضافات GitHub، فننصحك بقراءة [دليل GitHub إلى Markdown](https://guides.github.com/features/mastering-markdown/).
