# التعليمات

تعلّم الأساسيات حول الجداول الداخلية في ABAP.

يحتوي صنفك على جدول داخلي باسم `initial_data`، وله ثلاثة أعمدة: `GROUP` و`NUMBER` و`DESCRIPTION`.

```abap
TYPES group TYPE c LENGTH 1.
TYPES: BEGIN OF initial_type,
         group       TYPE group,
         number      TYPE i,
         description TYPE string,
       END OF initial_type,
       initial_data TYPE STANDARD TABLE OF initial_type WITH EMPTY KEY.
```

## الخطوة 1

مهمتك الأولى هي إكمال الطريقة `fill_itab` ووضع 6 سجلات في هذا الجدول بالقيم التالية:

| GROUP | NUMBER | DESCRIPTION |
| --- | ----------- | ----------- |
| A | 10 | Group A-2 |
| B | 5 | Group B |
| A | 6 | Group A-1 |
| C | 22 | Group C-1 |
| A | 13 | Group A-3 |
| C | 500 | Group C-2 |

## الخطوة 2

بعد ذلك، نفّذ الطريقة `add_to_itab` لإضافة سجل إلى نهاية الجدول الداخلي بالقيمة التالية:

| GROUP | NUMBER | DESCRIPTION |
| --- | ----------- | ----------- |
| A | 19 | Group A-4 |

## الخطوة 3

الآن، رتّب الجدول الداخلي في الطريقة `sort_itab` بحيث يكون العمود `GROUP` بترتيب أبجدي والعمود `NUMBER` بترتيب تنازلي.

## الخطوة 4

في الطريقة `search_itab`، ابحث في الجدول المرتّب وأرجع فهرس السجل الذي تكون قيمة عموده `NUMBER` مساوية لـ 6.
