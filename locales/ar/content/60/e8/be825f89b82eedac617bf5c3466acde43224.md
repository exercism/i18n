# تلميحات

## عام

- توجد كلمات القراءة في [`io`][io]؛ أما مُنشئات تدفق السلاسل النصية و`with-string-writer` فتوجد في [`io.streams.string`][io.streams.string].
- في مهمة تفريغ الكاتب، تُبقي المتغيرات المحلية (`::` و`:>`) جسم الكلمة مقروءًا عندما تحتاج إلى استخدام التدفق نفسه مرتين.

## 1. استمع إلى كل المحتوى

- كلمة واحدة: `stream-contents`.

## 2. احسب عدد الرسائل

- `stream-lines` تقسّم التدفق إلى مصفوفة من الأسطر؛ وتُرجع `length` العدد.

## 3. أعِد صدى آخر نداء

- نفس `stream-lines` كما سبق، ثم `last`، ثم `>upper` (من `ascii`).

## 4. بثّ رسالة

- `stream-write` تكتب الرسالة، و`stream-flush` تدفعها للخارج. يُستخدم الكاتب مرتين، لذا استعن بالمتغيرات المحلية `::`: `:: broadcast ( message writer -- ) message writer stream-write
  writer stream-flush ;`.

## 5. التقط مخرجات اقتباس

- كلمة واحدة: `with-string-writer`. أضف `inline` بعد الفاصلة المنقوطة `;` الختامية حتى يرى المصرّف عبر وسيط الاقتباس: `: capture ( quot -- captured ) with-string-writer ; inline`.
