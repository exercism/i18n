# مقدمة

توفّر [سمة `Attribute` في C#](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/) وسيلة لتزيين تصريح ما لربط بيانات وصفية به: صنف، أو طريقة، أو تعداد، أو حقل، أو خاصية، أو أي من [التصريحات الأخرى المدعومة](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/#attribute-targets).

يمكنك تطبيق سمة بإضافتها في السطر الذي يسبق التصريح باستخدام `ClassAttribute` و`FieldAttribute`:

```csharp
[Class]
class MyClass
{
    [Field]
    int myField;
}
```

تربط هذه البيانات الوصفية التصريحية معلومات منظّمة إضافية بالكود فقط، ولا تعدّل سلوكه، لكن أجزاء أخرى من الكود تستخدم هذه البيانات الوصفية لتغيير كيفية تصرّف هدفها، أو لإضافة بعض وظائفها أو تغييرها أو حذفها أو تقييدها.

هناك العديد من [السمات المعرّفة مسبقًا والمحجوزة](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/attributes/general#conditional-attribute)، مثل: `Flags` و`Obsolete` و`Conditional`، ولكل منها خصوصية يمكن البحث عنها في وثائق C#. لاحظ أن الاسم الكامل لسمة مثل [`Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute) هو `FlagsAttribute` وفقًا للاصطلاح، لكن يمكن حذف اللاحقة _Attribute_ عند تطبيقها على تصريح.
