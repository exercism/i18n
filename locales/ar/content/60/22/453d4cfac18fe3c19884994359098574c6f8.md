# مقدمة

## المقارنة

في Go يمكن مقارنة الأعداد باستخدام عوامل المقارنة والمساواة التالية.

| المقارنة          | العامل    |
| ------------------| --------- |
| يساوي             | `==`      |
| لا يساوي          | `!=`      |
| أصغر من           | `<`       |
| أصغر من أو يساوي  | `<=`      |
| أكبر من           | `>`       |
| أكبر من أو يساوي  | `>=`      |

نتيجة المقارنة دائمًا قيمة منطقية، أي إما `true` أو `false`.

```go
a := 3

a != 4 // true
a > 5  // false
```

يمكن أيضًا استخدام عوامل المقارنة أعلاه لمقارنة السلاسل النصية.
في هذه الحالة يُطبَّق ترتيب معجمي (قاموسي).
على سبيل المثال:

```Go
	"apple" < "banana"  // true
	"apple" > "banana"  // false
```

## الجمل الشرطية

الجمل الشرطية في Go تشبه الجمل الشرطية في لغات أخرى.
النوع الأساسي لأي عملية شرطية هو نوع `bool`، الذي يمكن أن تكون قيمته `true` أو `false`.
غالبًا ما تُستخدم الجمل الشرطية كآليات للتحكم في مسار التنفيذ للتحقق من شروط مختلفة.

للتحقق من حالة معينة يمكن استخدام جملة `if`، وهي تنفذ الكود إذا كان الشرط `true` كما يلي:

```go
var value string

if value == "val" {
    return "was val"
}
```

في الحالات التي تتضمن أكثر من حالة، يمكن ربط عدة جمل `if` معًا باستخدام جملتي `else if` و`else`.

```go
var number int
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

يمكن أن تتضمن جمل `if` أيضًا عبارة تهيئة قصيرة يمكن استخدامها لتهيئة متغير واحد أو أكثر للجملة الشرطية.
على سبيل المثال:

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```

> ملاحظة: أي متغيرات تُنشأ في عبارة التهيئة تخرج من النطاق بعد نهاية الجملة الشرطية.
