# عوامل المقارنة

تحتوي PHP على عشرة عوامل مقارنة مدمجة:

| الاسم  | المثال    | النتيجة                                             |
| ----- | ---------- | -------------------------------------------------- |
| يساوي | `$a == $b` | صحيح إذا كان `$a` يساوي `$b` بعد التحويل التلقائي للأنواع. |
| مطابق | `$a === $b` | صحيح إذا كان `$a` يساوي `$b` ومن النوع نفسه. |
| لا يساوي | `$a != $b` | صحيح إذا كان `$a` لا يساوي `$b` بعد التحويل التلقائي للأنواع. |
| لا يساوي | `$a <> $b` | صحيح إذا كان `$a` لا يساوي `$b` بعد التحويل التلقائي للأنواع. |
| غير مطابق | `$a !== $b` | صحيح إذا كان `$a` لا يساوي `$b` أو ليس من النوع نفسه. |
| أصغر من | `$a < $b` | صحيح إذا كان `$a` أصغر تمامًا من `$b`. |
| أكبر من | `$a > $b` | صحيح إذا كان `$a` أكبر تمامًا من `$b`. |
| أصغر من أو يساوي | `$a <= $b` | صحيح إذا كان `$a` أصغر من `$b` أو يساويه. |
| أكبر من أو يساوي | `$a >= $b` | صحيح إذا كان `$a` أكبر من `$b` أو يساويه. |
| سفينة الفضاء | `$a <=> $b` | يُرجع عددًا صحيحًا أصغر من `0` أو مساويًا له أو أكبر منه بحسب قيمة `$a`. |

لدى PHP تعريفات متمايزة تفرّق بين `equal` و`identical`.
يُشار إلى `identical` أحيانًا أيضًا باسم `strictly equal`.

```php
<?php

// Comparisons between integer and numeric string values
1 == "1"; // => true, equal
1 === "1"; // => false, not identical

// Comparisons between integers and floating point values
1 == 1.0; // => true
1 === 1.0; // => false

// Comparisons between object instances
new stdClass() == new stdClass(); // => true, properties are equal
new stdClass() === new stdClass(); // => false, references are not identical
```
