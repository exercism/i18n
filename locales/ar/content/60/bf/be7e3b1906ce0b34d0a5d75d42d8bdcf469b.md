# مقدمة

**الخريطة** بنية بيانات لتخزين أزواج المفتاح والقيمة.
وهي مشابهة للقواميس في لغات البرمجة الأخرى.
وتعرّف واجهة [الخريطة][map-javadoc] العمليات التي يمكن إجراؤها عليها.

توفّر Java عددًا من تنفيذات الخريطة المختلفة.
و[HashMap][hashmap-javadoc] أحد التنفيذات الشائعة الاستخدام.

```java
// Make an instance
Map<String, Integer> fruitPrices = new HashMap<>();
```

أضف مدخلات إلى الخريطة باستخدام [put][map-put-javadoc].

```java
fruitPrices.put("apple", 100);
fruitPrices.put("pear", 80);
// => { "apple" => 100, "pear" => 80 }
```

لا يمكن ربط أكثر من قيمة واحدة بكل مفتاح.
واستدعاء `put` بالمفتاح نفسه يحدّث قيمة ذلك المفتاح.

```java
fruitPrices.put("pear", 40);
// => { "apple" => 100, "pear" => 40 }
```

استخدم [get][map-get-javadoc] للحصول على قيمة مفتاح معيّن.

```java
fruitPrices.get("apple"); // => 100
```

استخدم [containsKey][map-containskey-javadoc] لمعرفة ما إذا كانت الخريطة تحتوي على مفتاح معيّن.

```java
fruitPrices.containsKey("apple");   // => true
fruitPrices.containsKey("orange");  // => false
```

أزِل المدخلات باستخدام [remove][map-remove-javadoc].

```java
fruitPrices.put("plum", 90);  // Add plum to map
fruitPrices.remove("plum");   // Removes plum from map
```

تُرجع الطريقة [size][map-size-javadoc] عدد المدخلات.

```java
fruitPrices.size();  // Returns 2
```

يمكنك استخدام الطريقتين [keySet][map-keyset-javadoc] أو [values][map-values-javadoc] للحصول على المفاتيح أو القيم في الخريطة على هيئة `Set` أو `Collection` على الترتيب.

```java
fruitPrices.keySet();  // Returns "apple" and "pear" in a set
fruitPrices.values();  // Returns 100 and 80, in a Collection
```
