# ملحق التعليمات

## السجلات

| السجل | الاستخدام | النوع | الوصف |
| -------- | --------- | ------- | ------------------------------------------------- |
| `$a0`    | إدخال     | عدد صحيح | عدد                                            |
| `$v0`    | إخراج     | قيمة منطقية | هل هو عدد أرمسترونغ (`0` = `false`، `1` = `true`) |
| `$t0-9`  | مؤقت | أي     | يُستخدم للتخزين المؤقت                        |
