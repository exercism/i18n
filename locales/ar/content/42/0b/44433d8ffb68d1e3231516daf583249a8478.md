# نبذة

القيم الحرفية هي قيم ثابتة تُستخدم مباشرةً في الكود.
وهي لا تحتاج إلى أي عملية حساب أثناء التشغيل.
وتأتي بأشكال متعددة لتمثيل أنواع مختلفة من البيانات بكفاءة.
أكثر القيم الحرفية شيوعًا هي القيم العددية، لكن هناك أيضًا عوامل حرفية لأنواع التاريخ والوقت والسلسلة النصية.
وسيوضح مفهوم لاحق كيف يمكن استخدام العوامل الحرفية المعرّفة من المستخدم.

## القيم الحرفية العددية

تشمل القيم الحرفية العددية التمثيلات العشرية والثمانية والست عشرية والثنائية.
سبق أن تناولنا هذه الأساسيات في [مفهوم الأعداد][numbers-concept].

يفهم المُصرِّف كل التمثيلات مثل `23` و`0x50f7ba11` و`0xba5eba11` على أنها `int`.
النوع العام `int` مُوقَّع، و([حسب المُصرِّف والنظام][in-depth-integers]) غالبًا ما يتراوح مداه بين `-2'147'483'648` و`2'147'483'647`.
وهذا كافٍ في معظم الحالات، فلا داعي للقلق بشأن النوع المحدد.

تتطلب بعض حالات الاستخدام مدىً أكبر أو بصمة ذاكرة صغيرة جدًا للبرامج.
ولكي تكون صريحًا، يمكنك تحديد أنواع أعداد صحيحة معينة مباشرةً عبر القيمة الحرفية العددية.

عندما لا تحتاج إلى أعداد سالبة، لكنك تريد المدى الإضافي، تُستخدم اللاحقة `u` أو `U` للأعداد الصحيحة _غير المُوقَّعة_.
ولمدىً أكبر يمكن استخدام `L` أو حتى `LL` للنوعين long و long long.

~~~~exercism/caution
يُسمح باستخدام الحرف الصغير `l`، لكنه يُلتبس بسهولة بالعدد `1`، لذا يُنصح بتجنّبه.
~~~~

```cpp
auto net_worth_christian_grey{2'500'000'000U}; // out of range for 32-bit integers
auto net_worth_carlisle_cullen{46'000'000'000LL}; // int and uint are not enough
```

تُعامَل الأعداد ذات الفاصلة العائمة عادةً على أنها `double` أثناء التصريف.
هذه حالة افتراضية جيدة، وحالات الاستخدام مع النوع الأضيق `float` أقل شيوعًا من مثال الأعداد غير المُوقَّعة أعلاه.

```cpp
auto light_year_in_m{9.46073e+15f}; // well in the range of float
auto earth_to_edge_comoving_distance_in_nm{4.32355e+32}; // needs double type for magnitude
auto eulers_number{2.718281828459045}; // needs double type for precision
```

## القيم الحرفية للمحارف والسلاسل النصية

استخدمت مفاهيم أخرى بالفعل قيمًا حرفية للمحارف بين علامتي تنصيص مفردتين مثل `'}'` أو `'@'`.

في C++ يقتصر النوع `char` على أول 128 من [رموز المحارف ascii][ascii-code].
ولاستخدام عدة محارف ascii أو محارف ascii الممتدة مثل `‰`، أو حتى محارف unicode مثل `麗` و`ẞ`، تحتاج إلى أنواع أخرى.
في مفهوم سابق، قُدِّمت القيم الحرفية للسلاسل النصية بعلامتي تنصيص مزدوجتين: `"一体どういう意味ですか。C++です"`.
النوع الفعلي لهذه العبارة اليابانية هو `const char (&)[46]`، أي سلسلة نصية بنمط C.

استخدام القيم الحرفية للسلاسل النصية غير مُفعَّل افتراضيًا.
ولاستخدام القيمة الحرفية _للسلسلة النصية_ `""s` أو القيمة الحرفية _لعرض السلسلة_ `""sv`، يجب على المستخدم تحديد استخدامها عبر مساحة الأسماء ذات الصلة:

```cpp
#include <string>
#include <string_view>

using namespace std::literals;

auto green_light{"무궁화 꽃 이 피었 습니다"};
// green_light type is const char (&)[36]
auto umbrella{"달고나"s};
// umbrella type is std::basic_string<char>, the same as std::string
auto il_nam{"보는 것이 하는 것보다 더 재미있을 수가 없지"sv};
// il_nam type is std::basic_string_view<char>
```

يمكن النظر إلى _string_view_ على أنها مرجع إلى سلسلة نصية ثابتة.
