# تصحيح الأخطاء

لمساعدتك في تصحيح الأخطاء، يمكنك الاستفادة من أن كل مخرجات الطرفية ستُلتقط وتُعرض في نافذة نتائج الاختبارات.
يمكنك إخراج أي قيمة بتمريرها إلى `@show`.

يعرض `@show` تعبيرًا ونتيجته، ثم يُرجع النتيجة.

```julia
@show uppercase("hello") # HELLO will be shown as debug output
```

```julia-repl
julia> function f(a, b)
           @show a b
           return (@show a^b) / 1000
       end
f (generic function with 1 method)

julia> f(3, 5)
a = 3
b = 5
a ^ b = 243
0.243
```

يمكنك أيضًا استخدام [`println`](https://docs.julialang.org/en/v1/base/io-network/#Base.println) أو أي طريقة أخرى تكتب مخرجاتها إلى [`stdout`](https://en.wikipedia.org/wiki/Standard_streams#Standard_output_(stdout)).
