# نبذة

يتم إنشاء نسخة من _صنف_ عن طريق استدعاء [_المنشئ_][constructors] الخاص به عبر [عامل `new`][new]. المنشئ هو نوع خاص من الطرق هدفه تهيئة نسخة أُنشئت حديثًا. [تبدو المنشئات مثل الطرق العادية][constructor-syntax]، لكنها بدون نوع إرجاع وباسم يطابق اسم الصنف.

```csharp
class Library
{
    private books;

    public Library()
    {
        this.books = 10;
    }
}

// This will call the constructor
var library = new Library();
```

مثل الطرق العادية، يمكن أن يكون للمنشئات معاملات. وعادةً ما تُخزَّن معاملات المنشئ في [حقول][fields] (خاصة) للوصول إليها لاحقًا، أو تُستخدم في حساب يُجرى مرة واحدة. ويمكن تمرير الوسائط إلى المنشئات تمامًا كما تُمرَّر الوسائط إلى الطرق العادية.

```csharp
class Building
{
    private int numberOfStories;
    private int totalHeight;

    public Building(int numberOfStories, double storyHeight)
    {
        this.numberOfStories = numberOfStories;
        this.totalHeight = numberOfStories * storyHeight;
    }
}

// Call a constructor with two arguments
var largeBuilding = new Building(55, 6.2);
```

تحديد منشئ أمر اختياري. وإذا لم يُحدَّد أي منشئ، يولّد المترجم [منشئًا بدون معاملات][parameterless-constructors]:

```csharp
class Elevator
{
}

// This will call the (empty) generated constructor
var elevator = new Elevator();
```

إذا كان للحقول قيمة ابتدائية مُسندة إليها، فسيُخرج المترجم كودًا يتم فيه الإسناد فعليًا داخل المنشئ. وعليه، فإن تعريفات الأصناف التالية متكافئة (من حيث الوظيفة):

```csharp
class UsingFieldInitialization
{
    private int players = 5;
}

class UsingConstructorInitialization
{
    private int players;

    public UsingConstructorInitialization()
    {
        players = 5;
    }
}
```
