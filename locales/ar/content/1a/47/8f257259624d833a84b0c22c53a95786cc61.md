# نبذة

مفردات [`calendar`][calendar] في Factor مبنيّة حول صفّين:

- `timestamp`، وهي لحظة زمنية (`year` و`month` و`day` و`hour` و`minute` و`second`، وإزاحة توقيت غرينتش).
- `duration`، وهي مدّة زمنية (الحقول نفسها، مستخدمة ككميات).

## الطوابع الزمنية

لبناء طابع زمني عند منتصف الليل استخدم `<date>`، ولفصل طابع زمني إلى أجزائه استخدم `>date<`:

```
<date> ( year month day -- timestamp )
>date< ( timestamp -- year month day )
```

```factor
USING: calendar ;

2024 7 14 <date> >date< .   ! => 14   (2024 and 7 below it)
```

استعلامات شائعة:

```factor
USING: calendar calendar.english sequences ;

2024 1 8 <date> day-of-week .          ! => 1   (0 = Sunday .. 6 = Saturday)
2024 1 8 <date> day-of-week day-names nth .   ! => "Monday"
2024 leap-year? .                      ! => t
2024 2 1 <date> days-in-month .        ! => 29
```

توجد `day-names` (و`month-names`) في [`calendar.english`][english].

## المدد والحساب

تبني كلمات مثل `days` و`weeks` و`hours` و`minutes` قيمة `duration`، بينما يزيح `time+` / `time-` طابعًا زمنيًا بمقدار مدّة واحدة:

```
days  ( x -- duration )
time+ ( timestamp duration -- timestamp )
```

```factor
2024 2 28 <date> 1 days time+ >date< .   ! => 29   (2024-02-29)
```

تمتدّ العمليات الحسابية عبر حدود الأشهر والسنوات، وطابعان زمنيان يشيران إلى اللحظة نفسها يتساويان عند استخدام `=`.

وإضافةً إلى ذلك، يوفّر `calendar` أوقات اليوم (`set-time`، `+hour`)، والتحويل بين المناطق الزمنية (`>gmt`، `>local-time`)، والوقت الحالي (`now`)، وكذلك التحليل والتنسيق عبر `calendar.format`.
