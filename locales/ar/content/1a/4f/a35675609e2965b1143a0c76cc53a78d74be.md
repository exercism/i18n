# مقدمة
## جملة `switch`

تتيح لك [جملة `switch`][switch] مقارنة قيمة بعدة قيم محتملة قد تطابقها.
وهي تتيح لك كتابة كود أكثر إيجازًا من استخدام عدة عبارات `else-if`.
تبدأ جملة `switch` بالكلمة المفتاحية `switch` متبوعة بالقيمة المراد مقارنتها.
ثم يمكنك تعريف الحالات باستخدام الكلمة المفتاحية `case` متبوعة بالقيمة التي ستُقارن بها.
وتُستخدم الكلمة المفتاحية `default` لتعريف الحالة الافتراضية عندما لا تطابق أي من الحالات.
ومثل عبارات `else-if`، لا تنفّذ جمل `switch` إلا كتلة الكود المرتبطة بأول حالة مطابقة.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

تأمّل المثال التالي:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

يمكن بدلًا من ذلك كتابته هكذا:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## حلقات `while`

[حلقة `while`][while-loops] عبارة تحكّم في مسار التنفيذ تتيح تنفيذ الكود ما دام شرط معيّن صحيحًا.
يوفّر Swift نوعين من حلقات `while`: حلقة `while` وحلقة `repeat-while`.
يُقيَّم شرط حلقة `while` قبل تنفيذ جسم الحلقة؛ فإذا كان الشرط خطأ، فلن يُنفَّذ جسم الحلقة إطلاقًا.
تكون بنية حلقات `while` في Swift على النحو التالي:

```swift
while <#condition#> {
  <#code#>
}
```

هنا ستستمر الحلقة في التنفيذ ما دام `count` أكبر من 0، وستطبع بذلك العددين 2 و1 ثم "Liftoff!".

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

[حلقة `repeat-while`][while-loops] تشبه حلقة `while`، لكن الشرط يُقيَّم بعد تنفيذ جسم الحلقة.
وهذا يعني أن جسم الحلقة سيُنفَّذ مرة واحدة على الأقل دائمًا، حتى لو كان الشرط خطأ.
تكون بنية حلقات `repeat-while` في Swift على النحو التالي:

```swift
repeat {
  <#code#>
} while <#condition#>
```

هنا ستُنفَّذ الحلقة مرة واحدة فقط، لأن الشرط خطأ.
ولأنها حلقة `repeat-while`، سيُنفَّذ جسم الحلقة مرة واحدة قبل تقييم الشرط.

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```

## نقل التحكّم

يمتلك Swift مجموعة من العبارات التي يمكن استخدامها لتغيير مسار التحكّم الطبيعي للحلقات.
تُعرف هذه بعبارات نقل التحكّم.
لقد رأيت `return` من قبل؛ وسيعرّفك هذا المفهوم بعبارات أخرى، منها `continue` و`break` والتسميات.
لن نتناول `fallthrough` في هذا المفهوم، لكن يمكنك القراءة عنه في [كتاب Swift][fallthrough].

### `continue`

أحيانًا يلزم الانتقال مبكرًا إلى التكرار التالي في الحلقة، دون إكمال بقية العبارات في التكرار الحالي من الحلقة.
يمكن استخدام الكلمة المفتاحية `continue` لهذا الغرض.
عند تنفيذ `continue`، تنتقل الحلقة إلى الفحص التالي لمعرفة ما إذا كان يمكن تشغيل التكرار التالي من الحلقة، أي `while` في حلقات `while` و`repeat-while`، أو التحقق من وجود عنصر آخر في المتتالية في حلقات `for-in`.

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

### `break`

يُستخدم `break` للخروج من الحلقة مبكرًا.
عند تنفيذ `break`، تخرج الحلقة فورًا ويتابع البرنامج التنفيذ من أول عبارة بعد الحلقة.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

### التسميات

عندما تكون الحلقات متداخلة، قد تحتاج أحيانًا إلى استخدام `break` أو `continue` للخروج من الحلقات الخارجية التي تحتوي الحلقة التي استُخدم فيها `break` أو `continue`، أو لإعادة تشغيلها.
في حالات كهذه، يمكن استخدام التسميات لتحديد الحلقة المطلوب الخروج منها أو إعادة تشغيلها.
يمكن تسمية الحلقة بوضع اسم متبوع بنقطتين قبل `while` أو `repeat` أو `for` التي تبدأ الحلقة.

لترى أثر استخدام التسميات بهذه الطريقة، تأمّل الحلقة التالية.

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```
