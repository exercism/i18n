# لا تقارن القيم المنطقية بـ صحيح أو خطأ

مقارنة القيم المنطقية بـ صحيح أو خطأ زائدة عن الحاجة.
استخدام `==` يُنتج قيمة منطقية، لذا لا حاجة لمقارنتها بقيمة منطقية أخرى مضمّنة في الكود.
وإذا أردت عكس القيمة المنطقية، فاستخدم العامل `!`.

```crystal
# Rather than:
some_bool == true
some_bool == false

# Consider:
some_bool
!some_bool
```
