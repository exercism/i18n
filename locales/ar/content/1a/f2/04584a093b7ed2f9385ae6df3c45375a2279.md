# التعليمات

في هذا التمرين ستكتب كودًا لتتبّع مصفوفة لغات البرمجة التي تريد تعلّمها على Exercism.
لديك ست مهام، وكلها ستتضمن التعامل مع المصفوفات.

## 1. أنشئ مصفوفة جديدة

لتتبّع اللغات التي تريد تعلّمها، ستحتاج إلى إنشاء مصفوفة جديدة.
عرّف الثابت `newList` الذي يحتوي على مصفوفة جديدة فارغة.

```elm
newList
    --> []
```

## 2. عرّف مصفوفة موجودة

حاليًا، لديك ورقة مكتوب عليها اللغات التي تريد تعلّمها: Elm وClojure وHaskell.
عرّف الثابت `existingList` لتمثيل هذه المصفوفة.

```elm
existingList
    --> [ "Elm", "Clojure", "Haskell" ]
```

## 3. أضف لغة جديدة إلى مصفوفة

بينما تستكشف Exercism وتجد لغات أكثر إثارة للاهتمام، تريد إضافتها إلى مصفوفتك.
نفّذ الدالة `addLanguage` لإضافة لغة جديدة إلى بداية مصفوفتك.

```elm
addLanguage "TypeScript" [ "JavaScript", "CoffeeScript" ]
    --> [ "TypeScript", "JavaScript", "CoffeeScript" ]
```

## 4. احسب عدد اللغات في المصفوفة

عدّ اللغات يدويًا أمر غير مريح.
نفّذ الدالة `countLanguages` لعدّ عدد اللغات في مصفوفتك.

```elm
countLanguages [ "C#", "Racket", "Rust", "Ruby" ]
    --> 4
```

## 5. اعكس ترتيب المصفوفة

في مرحلة ما، تدرك أن ترتيب مصفوفتك معكوس فعلًا!
نفّذ الدالة `reverseList` لعكس ترتيب مصفوفتك.

```elm
reverseList [ "Prolog", "C", "Idris", "Assembly" ]
    --> [ "Assembly", "Idris", "C", "Prolog" ]
```

## 6. تحقق مما إذا كانت المصفوفة مثيرة

رغم أنك تحب جميع اللغات، فإن Elm له مكانة خاصة في قلبك.
لذلك، تتحمس كثيرًا لمصفوفة لغات إذا:

- كان العنصر الأول في المصفوفة هو Elm.
- أو كان العنصر الثاني في المصفوفة هو Elm وتحتوي المصفوفة على ثلاث لغات أو أقل.

نفّذ الدالة `excitingList` للتحقق مما إذا كانت مصفوفة اللغات مثيرة:

```elm
excitingList [ "Nim", "Elm" ]
    --> True
```
