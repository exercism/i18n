# التعليمات

لقد عدتَ للعمل على نظام ORM (تخطيط العلاقات بين الكائنات) الذي قدمناه في [exercise:csharp/object-relational-mapping]().

يُظهر تحليلنا لاستخدام ORM أن 95% من المعاملات تُنفَّذ من داخل طريقة استدعاء واحدة، وقد تقرر أنه من الأنسب أن تكون لدينا طريقة ORM واحدة تفتح المعاملة وتكتبها وتُثبّتها.

تحتوي قاعدة البيانات على طرق النسخة التالية:

- تبدأ `Database.BeginTransaction()` معاملة على قاعدة البيانات.
- تكتب `Database.Write(string data)` البيانات إلى قاعدة البيانات داخل المعاملة. وإذا استقبلت بيانات غير صالحة، فسيُطرح استثناء. ومحاولة استدعاء هذه الطريقة دون استدعاء `BeginTransaction()` ستؤدي إلى طرح استثناء. وإذا نجحت، ستتغير الحالة الداخلية لقاعدة البيانات إلى `DataWritten`.
- تُثبّت `Database.EndTransaction()` المعاملة في قاعدة البيانات. وقد تطرح استثناءً إذا لم تتمكن من إغلاق المعاملة أو إذا لم يكن `Database.BeginTransaction()` قد استُدعي.
- يؤدي استدعاء `Database.Dispose()` إلى تنظيف قاعدة البيانات إذا طُرح استثناء أثناء معاملة. وسيغيّر هذا حالة قاعدة البيانات إلى `Closed`.

## 1. الكتابة إلى قاعدة البيانات

نفّذ الطريقة `Orm.Write()` لبدء معاملة على قاعدة البيانات، وكتابة البيانات الممرَّرة، وتثبيت المعاملة. ينبغي السماح لجميع الاستثناءات، بما فيها `InvalidOperationException`، بالمرور إلى المستدعي دون تسجيلها أو أي تدخل آخر.

```csharp
Database db = new Database();
Orm orm = new Orm(db);
orm.Write("good write");
// => database has an internal state of State.Closed
orm.Write("bad write");
// => an exception is thrown but database is left with an internal state of State.Closed
orm.Write("bad commit");
// => an exception is thrown but database is left with an internal state of State.Closed
```

## 2. الكتابة إلى قاعدة البيانات وإرجاع مؤشر إلى المستدعي يوضح ما إذا كانت الكتابة ناجحة

مضت بضعة أشهر منذ أن أُدخلت `Orm.Write()`، وهناك انقسام في الفريق. يودّ العديد من المطورين أن يتعامل _ORM_ مع الأخطاء عند طرح الاستثناءات، وأن يُرجع ببساطة مؤشرًا على النجاح إلى المستدعي.

يرجى تنفيذ الطريقة `Orm.WriteSafely()` لبدء معاملة على قاعدة البيانات، وكتابة البيانات الممرَّرة، وتثبيت المعاملة (كما سبق). وينبغي أن تُرجع `true` إذا كانت _الكتابة_ ناجحة، و`false` خلاف ذلك. لا تحاول تسجيل الاستثناء.

```csharp
Database db = new Database();
Orm orm = new Orm(db);
orm.WriteSafely("good write");
// => true
orm.WriteSafely("bad write");
// => false
orm.WriteSafely("bad commit");
// => false
```
