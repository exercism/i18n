# مقدمة

## المجموعات

المجموعة [`Set`][set-docs] هي تجمّع غير مرتب من العناصر، وبخلاف `List`، نضمن أنها لا تحتوي على أي قيم مكررة.

معامل النوع العام لواجهة `Set` يحدد نوع العناصر الموجودة في المجموعة:

```java
Set<Integer> ints = Set.of(1, 2, 3);
Set<String> strings = Set.of("alpha", "beta", "gamma");
Set<Object> mixed = Set.of(1, false, "foo");
```

لاحظ أن الطريقة `Set.of()` تُنشئ نسخة [`Set` غير قابلة للتعديل][unmodifiable-set-docs].
محاولة استدعاء طرق مثل `add` و `remove` على هذه النسخة ستؤدي إلى استثناء في وقت التشغيل.

لإنشاء `Set` قابلة للتعديل، تحتاج إلى إنشاء كائن من صنف يطبّق واجهة `Set`.
الصنف المدمج الأكثر استخدامًا الذي يطبّق هذه الواجهة هو الصنف [`HashSet`][hashset-docs].

```java
Set<Integer> ints = new HashSet<>();
```

واجهة `Set` ترث من واجهتي [`Collection`][collection-docs] و [`Iterable`][iterable-docs]، ولذلك تتشارك الكثير من الطرق مع أنواع أخرى من التجمّعات.
لكن الفرق الملحوظ عن واجهة `Collection` هو أن طرقًا مثل `add` و `remove` تُرجع قيمة `boolean` (بدلًا من `void`) تشير إلى ما إذا كان العنصر موجودًا في المجموعة عند استدعاء تلك الطريقة:

```java
Set<Integer> set = new HashSet<>();
set.add(1);
// => true
set.add(2);
// => true
set.add(1);
// => false
set.size();
// => 2
set.contains(1);
// => true
set.contains(3);
// => false
set.remove(3);
// => false
set.remove(2);
// => true
set.size();
// => 1
```
