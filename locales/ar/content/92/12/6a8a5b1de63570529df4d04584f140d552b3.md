# ملحق التعليمات

## الكود المبدئي

يحتوي الملف `src/TreeBuilding.hs` بالفعل على حل عامل ينجح في اجتياز جميع الاختبارات.
لكنه بطيء وصعب القراءة؛ ومهمتك هي تحسينه دون أن تُفسد الاختبارات.

تُرجع `buildTree` القيمة `Nothing` عندما لا تشكّل السجلات شجرة صالحة.

## تغيير التمثيل

لا تستخدم الاختبارات دوال البناء الخاصة بـ `Tree` مباشرةً.
بل تبني الأشجار المتوقعة بالدالة

```haskell
node :: Int -> [Tree] -> Tree
```

حيث `node i children` هي العقدة ذات المعرّف `i` والأبناء المعطاة، بترتيب تصاعدي للمعرّف.

هذا يعني أنك حرّ في تغيير كيفية تمثيل `Tree`، مثلًا إلى

```haskell
import qualified Data.Tree as T

type Tree = T.Tree Int

node :: Int -> [Tree] -> Tree
node = T.Node
```

بشرط أن يظل `Tree` يملك نسختَي النوع `Eq` و`Show`، وأن يحتفظ `node` بمعناه.
وإذا استخدمت مكتبة مثل `containers`، فتذكّر إضافتها إلى `dependencies` في `package.yaml`.
