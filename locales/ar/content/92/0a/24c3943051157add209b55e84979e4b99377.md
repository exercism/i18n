# التعليمات

في هذا التمرين، ستساعد في إدارة العمليات اليومية لمخبز صغير باستخدام تراكيب التحكم في مسار التنفيذ التي توفرها Cairo.

## 1. احسب إجمالي الطلب

نفّذ الدالة `calculate_total` التي تحسب تكلفة الطلب بناءً على نوع المعجنات والكمية:

- كرواسون: 3 عملات لكل قطعة
- مافن: عملتان لكل قطعة
- بسكويت: عملة واحدة لكل قطعة

```rust
calculate_total(Pastry::Croissant, 4) // Returns: 12 (4 * 3)
calculate_total(Pastry::Cookie, 10)   // Returns: 10 (10 * 1)
```

## 2. طبّق خصومات الكمية

نفّذ الدالة `apply_discount` التي تطبّق الخصومات بناءً على إجمالي الطلب.
طبّق نسبة الخصم على الإجمالي، ثم قرّب النتيجة إلى أقرب عملة كاملة نحو الأسفل (floor).

- الطلبات ≥ 20 عملة: خصم بنسبة 10%
- الطلبات ≥ 10 عملات: خصم بنسبة 5%
- الطلبات < 10 عملات: بلا خصم

```rust
apply_discount(25) // Returns: 22
apply_discount(15) // Returns: 14
apply_discount(8)  // Returns: 8
```

## 3. أنشئ جدول الخَبز

نفّذ الدالة `baking_schedule` التي تنشئ خطة خَبز يومية.
تُخبز الطلبات في دفعات من 5 طلبات كل ساعة:

```rust
baking_schedule(18) // Returns: [5, 5, 5, 3] (3 full batches + 3 remaining)
baking_schedule(10) // Returns: [5, 5] (2 full batches)
baking_schedule(3)  // Returns: [3] (1 partial batch)
```

استخدم تراكيب التحكم المناسبة (`if`/`else`، `loop`) لحل كل مشكلة بكفاءة.
