# التعليمات

في هذا التمرين، عليك ترجمة بعض القواعد من اللعبة الكلاسيكية Pac-Man إلى دوال بلغة Gleam.

لديك أربع قواعد لترجمتها، وكلها متعلقة بحالات اللعبة.

> لا تقلق بشأن كيفية اشتقاق الوسائط، ركّز فقط على دمج الوسائط لإرجاع النتيجة المطلوبة.

## 1. حدّد ما إذا كان Pac-Man يأكل شبحًا

عرّف الدالة `eat_ghost` التي تأخذ وسيطين (_إذا كانت حبة الطاقة نشطة لدى Pac-Man_ و_إذا كان Pac-Man يلامس شبحًا_) وتُرجع قيمة منطقية إذا كان Pac-Man قادرًا على أكل الشبح. يجب أن تُرجع الدالة `True` فقط إذا كانت حبة الطاقة نشطة لدى Pac-Man وكان يلامس شبحًا.

```gleam
eat_ghost(False, True)
// -> False
```

## 2. حدّد ما إذا كان Pac-Man يسجّل نقاطًا

عرّف الدالة `score` التي تأخذ وسيطين (_إذا كان Pac-Man يلامس حبة طاقة_ و_إذا كان Pac-Man يلامس نقطة_) وتُرجع قيمة منطقية إذا سجّل Pac-Man نقاطًا. يجب أن تُرجع الدالة `True` إذا كان Pac-Man يلامس حبة طاقة أو نقطة.

```gleam
score(True, True)
// -> True
```

## 3. حدّد ما إذا كان Pac-Man يخسر

عرّف الدالة `lose` التي تأخذ وسيطين (_إذا كانت حبة الطاقة نشطة لدى Pac-Man_ و_إذا كان Pac-Man يلامس شبحًا_) وتُرجع قيمة منطقية إذا خسر Pac-Man. يجب أن تُرجع الدالة `True` إذا كان Pac-Man يلامس شبحًا ولم تكن لديه حبة طاقة نشطة.

```gleam
lose(False, True)
// -> True
```

## 4. حدّد ما إذا كان Pac-Man يفوز

عرّف الدالة `win` التي تأخذ ثلاثة وسائط (_إذا كان Pac-Man قد أكل كل النقاط_، و_إذا كانت حبة الطاقة نشطة لدى Pac-Man_، و_إذا كان Pac-Man يلامس شبحًا_) وتُرجع قيمة منطقية إذا فاز Pac-Man. يجب أن تُرجع الدالة `True` إذا كان Pac-Man قد أكل كل النقاط ولم يخسر وفقًا للوسائط المعرّفة في الجزء 3.

```gleam
win(False, True, False)
// -> False
```
