# نوع القيمة المنطقية

في Cairo، يُعدّ نوع القيمة المنطقية أساسيًا للعمليات المنطقية والجمل الشرطية.
القيم المنطقية في Cairo بحجم `felt252` واحد، مما يضمن استخدامًا فعّالًا للمساحة مع الحفاظ على بساطة منطق الصحيح والخطأ.

يُحدَّد نوع القيمة المنطقية في Cairo باستخدام الكلمة المفتاحية `bool`.
وهذا يتيح تعريف المتغيرات المنطقية والتعامل معها داخل اللغة.
على سبيل المثال، انظر إلى المثال التالي:

```rust
fn main() {
    let t = true;
    let f: bool = false; // with explicit type annotation
}
```

في هذا المثال، يُعرَّف متغيّران منطقيان.
يُسند إلى المتغير `t` القيمة `true` ويُعرَّف ضمنيًا كنوع منطقي، بينما يُوسم المتغير `f` صراحةً بنوع `bool` وتُسند إليه القيمة `false`.

من الجوانب المهمة التي تجدر ملاحظتها أنه عند تعريف متغيّر منطقي في Cairo، يجب استخدام إحدى القيمتين الحرفيتين `true` أو `false` كقيمة.
وهذا يعني أنه لا يمكن استخدام القيم الحرفية للأعداد الصحيحة، مثل `0` أو `1`، بديلًا عن `false` أو `true`.
ويضمن التطبيق الصارم لهذه القاعدة سلامة الأنواع ويمنع الأخطاء المنطقية المحتملة في تطوير العقود الذكية.

## العوامل المنطقية في Cairo

- `||` (OR المنطقي): يُرجع `true` إذا كان أحد طرفي العملية على الأقل `true`.
- `&&` (AND المنطقي): يُرجع `true` إذا كان كلا الطرفين `true`.
- `!` (NOT المنطقي): يُرجع القيمة المنطقية المعاكسة للطرف.

## مثال على الكود

يوضّح مقطع الكود التالي كيفية استخدام الأنواع المنطقية في Cairo.
فهو يعرض تعريف المتغيرات المنطقية، وإسناد التعبيرات المنطقية، واستخدام التأكيدات للتحقق من صحة منطق القيم المنطقية:

```rust
fn main() {
    // Declaration of Boolean variables
    let t: bool = true;
    let f: bool = false;

    // Boolean expression evaluation
    let true_expr = 5 == 5; // true
    let false_expr = 7 == 5; // false

    // Using Boolean operators
    let or_expr = t || f; // true || false => true
    let and_expr = t && f; // true && false => false
    let not_expr = !f; // !false => true

    // Assertions to verify the correctness
    assert(t == true_expr, 'this should be true'); // t == true
    assert(f == false_expr, 'this should be false'); // f == false
    assert(or_expr == true, 'this should be true for OR'); // true
    assert(and_expr == false, 'this should be false for AND'); // false
    assert(not_expr == true, 'this should be true for NOT'); // true
}
```
