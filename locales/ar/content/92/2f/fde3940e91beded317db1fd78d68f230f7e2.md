# التعليمات

أنت في غرفة اللاسلكي الساحلية، تراقب الأحاديث على القناة: تصل الرسائل عبر السلك، فتدوّنها، ثم تدفع الردود عائدة. خمس كلمات صغيرة تكفي لعمل وردية كاملة.

تمرّر إليك الاختبارات مدخلات من نوع `<string-reader>` (الحركة الواردة) وتستخدم `<string-writer>` للحركة الصادرة، لكن كل كلمة هنا تعمل بالطريقة نفسها مع `<file-reader>` حقيقي أو مقبس شبكة.

## 1. اسمع كل شيء حتى النهاية

عرّف `hear-out` لتستنزف تدفق الإدخال في سلسلة نصية واحدة.

```factor
"all quiet on the channel" <string-reader> hear-out .
! => "all quiet on the channel"
```

## 2. أحصِ الرسائل

عرّف `count-messages` لتقرأ كل سطر من تدفق الإدخال وتُرجع عددها.

```factor
"alpha\nbravo\ncharlie\n" <string-reader> count-messages .
! => 3
```

## 3. أعِد آخر نداء

عرّف `echo-back` لتقرأ كل سطر وتُرجع **آخره بأحرف كبيرة**، وهو الرد اللاسلكي المعتاد «قلتَ X».

```factor
"alpha\nbravo\n" <string-reader> echo-back .
! => "BRAVO"
```

## 4. بثّ رسالة

عرّف `broadcast` لتكتب رسالة إلى الكاتب المعطى وتفرّغ التدفق حتى تخرج فورًا. لا تُرجع شيئًا.

```factor
[ "mayday" output-stream get broadcast ] with-string-writer .
! => "mayday"
```

## 5. التقط مخرجات quotation

عرّف `capture` لتشغيل quotation بكائن كتابة نصية جديد كمخرج محيط، وتُرجع كل ما طبعه quotation. لا يأخذ quotation أي وسائط، بل يكتب فقط في التدفق المحيط كما اعتاد.

```factor
[ "test broadcast" print ] capture .
! => "test broadcast\n"
```
