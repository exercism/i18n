# مقدمة

تُشكّل الأحرف والسلاسل النصية أساس تمثيل النصوص في Elm.
يمكن اعتبار السلاسل النصية مصفوفات من الأحرف، ولمعظم دوال `List` مقابل في وحدة `String`.

## الأحرف

يمثّل النوع `Char` حرف يونيكود واحدًا، ويُكتب بين علامتَي اقتباس مفردتين، مثل `'a'`.
توفّر وحدة `Char` دوالَّ اختبار (`Char -> Bool`) لفحص خصائص الحرف: `isUpper` و`isLower` و`isAlpha` و`isAlphaNum`.
كما توفّر الوحدة دوالَّ لتحويل الحرف: `toUpper` و`toLower` و`toLocaleUpper` و`toLocaleLower`، وكذلك التحويل من قيمته الرقمية في يونيكود (`Int`) وإليها عبر `toCode` و`fromCode`.

## السلاسل النصية

يوفّر النوع `String` تمثيلًا مدمجًا لمعالجة السلاسل النصية بكفاءة، ويمكنه تمثيل أي تسلسل من أحرف يونيكود، مثل "this is an Elm string."
تُمثَّل السلاسل النصية متعددة الأسطر بثلاث علامات تنصيص مزدوجة، ويمكن أن تحتوي على علامات تنصيص وأسطر جديدة غير مهرَّبة.
```elm
"""
    This is a multiline string.
All line-breaks and whitespace,
are preserved. 
"""
```

## دوال السلاسل النصية

تحتوي وحدة `String` على جميع الدوال الملخّصة في الجدول أدناه.
ومن أكثر الدوال استخدامًا:

`cons : Char -> String -> String` تُضيف حرفًا إلى بداية السلسلة النصية.
```elm
cons 'T' "he truth is out there" 
    --> "The truth is out there"
```

`(++): String -> String -> String` تُلحق سلسلتين نصيتين إحداهما بالأخرى.
```elm
"butter" ++ "fly" 
    --> "butterfly"
```

`split : String -> String -> List String` تُقسّم سلسلة نصية إلى مصفوفة من السلاسل النصية عند الفاصل المعطى.
```elm
split ";" "cat;dog;cow" 
    --> ["cat", "dog", "cow"]
```

`join : String -> List String -> String` تُدمج مصفوفة من السلاسل النصية معًا باستخدام فاصل معطى.
```elm
join "a" ["H", "w", "ii", "n"] 
    --> "Hawaiian"
```
`replace : String -> String -> String -> String` تستبدل كل مواضع سلسلة نصية فرعية معطاة.
```elm
replace "Hello" "Goodbye cruel" "Hello world." 
    --> "Goodbye cruel world."
```

`length : String -> Int` تُرجع عدد الأحرف في السلسلة النصية.
```elm 
length "Hello world." 
    --> 12
```

`toInt : String -> Maybe Int` تحاول تحويل سلسلة نصية إلى `Just Int`، وتُرجع `Nothing` للسلاسل النصية التي لا تكون بتنسيق صحيح.
```elm
toInt "-42" 
    --> Just -42
```    

`contains : String -> String -> Bool` تتحقّق مما إذا كانت السلسلة النصية الثانية تحتوي على الأولى.
```elm
contains "the" "theory" 
    --> True
```

`map : (Char -> Char) -> String -> String` تُطبّق دالة معطاة على كل `Char` في السلسلة النصية.
لاحظ أن الدالة المقدَّمة يجب أن تكون تحويلًا من `Char` وإلى `Char`.
```elm
map (\c -> if c == '/' then '.' else c) "a/b/c" 
    --> "a.b.c"
```
