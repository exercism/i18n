# أساسيات Unison

## الحدود والدوال

الحدود والدوال هي الوحدات الأساسية لكتابة برنامج في Unison.

«الحدّ» هو ما نسميه قيمة ثابتة. ويُعرَّف باستخدام `name = expression`، مع إمكانية أن يسبقه توقيع نوع بالصيغة `name : MyType`. يدعم Unison استنتاج الأنواع، لذا قد ترى توقيع النوع محذوفًا في التعريفات البسيطة.

```
myTerm = 42

helloThere : Text
helloThere = "Hello, World!"
```

تبدو دوال Unison بالشكل `myFunctionName argument1 argument2 = myImplementation`؛ فهي تبدأ باسم الدالة متبوعًا بوسائط مفصولة بمسافات.

```
getMax a b = Nat.max a b
```

يمكن أن تتضمن الدوال توقيع نوع اختياريًا. والنوع الأخير على اليمين هو دائمًا نوع الإرجاع النهائي للدالة، وتُفصل كل وسيطة عن غيرها بسهم الدالة `->`.

```
{{getMax accepts two arguments of type Nat and its return type is a Nat}}
getMax : Nat -> Nat -> Nat
getMax a b = Nat.max a b
```

لاستدعاء دالة، استخدم اسمها متبوعًا بوسائطها مفصولة بمسافات فقط.

```
maximum = getMax 1 10

> maximum
  ⧩
  10
```

عند استدعاء دالة، سيحاول Unison التعامل مع ما يأتي مباشرة على يمينها باعتباره وسيطها، وهذا قد لا يُنتج دائمًا ترتيب تقييم الدوال المطلوب.

لنفترض أننا نريد الحصول على القيمة `1` من التعبير التالي

```
shouldBe1 = getMax 1 10 - 10

> shouldBe1
  ⧩
  0
```

كما هو مكتوب، تُقيَّم `shouldBe1` إلى `0` لأن ترتيب تطبيق الدالة الضمني هو `getMax 1 10`، أي `10`، ثم `10 - 10`، أي `0`.

يمكنك استخدام الأقواس الهلالية لإعادة تجميع التعبير بالترتيب المطلوب للعمليات.

```
shouldBe1 = getMax 1 (10 - 10)

shouldBe1
  ⧩
  1
```

## تعبيرات المراقبة

يوفر Unison طريقة سريعة لتقييم الكود تُسمى «تعبير المراقبة». يبدأ تعبير المراقبة بالرمز `>` ويتبعه التعبير المراد تقييمه. ويمكن كتابة تعبيرات المراقبة في أي ملف بامتداد `.u`. وعند حفظ الملف، سترى ناتج تقييم التعبير في وحدة تحكم Unison Codebase Manager (UCM). وحيثما أمكن في هذه الوثائق، سنحاول عرض التعبير مع مخرجاته المتوقعة بعد تقييمه في تعبير مراقبة.

```
> helloThere
  ⧩
  "Hello, World!"
```

## الدوال متعددة الأسطر

تستخدم دوال Unison متعددة الأسطر المسافة البادئة أو كتل `let` لتحديد حدود الكود، أي «النطاق المعجمي».

```
swapOrder : Text -> Text -> Text -> Text
swapOrder beg middle end =
  newBeginning = end ++ middle
  newBeginning ++ beg
```

كل ما يقع عند المستوى نفسه من المسافة البادئة يتشارك النطاق نفسه، ولهذا يمكننا الإشارة إلى المتغير `newBeginning` في السطر الأخير.

## مساحات الأسماء وعبارات `use`

مساحات الأسماء هي الطريقة التي نجمّع وننظّم بها دوال Unison. يمكنك اعتبارها شبيهة بـ«المجلدات». فهي توفّر البنية والتجميع المنطقي.

ويمكنك إدخال الدوال الموجودة في مساحة أسماء إلى النطاق باستخدام عبارة `use`.

لنفترض أنك تكتب دالة تستفيد من قيم `List` في Unison. وأنت تعلم أنك ستحتاج إلى دوال مثل `List.map` و `List.flatMap`، حيث `List` هي مساحة الأسماء و `map` و `flatMap` دوال. ولتجنّب تكرار نفسك، قد تختار إدخال كل شيء من مساحة الأسماء `List` إلى النطاق المعجمي داخل دالتك على النحو التالي:

```
listProcessing: [Nat] -> [Text]
listProcessing nats =
  use List
  map Nat.toText nats |>
  flatMap (fill 2)
```

يزيل سطر `use List` الالتباس عن الإشارات إلى `map` و `flatMap`. يمكنك قراءة المزيد عن عبارات `use` [هنا][use-statements].

## المكتبة القياسية في Unison

تُسمى المكتبة القياسية في Unison `base`. وإذا كنت قد اتبعت دليل البدء السريع وأنشأت قاعدة كود محليًا، فيُفترض أن المكتبة القياسية قد نُزّلت تلقائيًا. يمكنك تصفّح توثيق المكتبة القياسية على الإنترنت في [Unison Share][unison-share-base].

## التعليقات وحرفيات التوثيق

التعليقات في Unison ميزة غير معتادة بعض الشيء. فعند كتابة كود Unison، يمكنك إنشاء نص في ملف بامتداد `.u` لا يُفسَّر، باستخدام الصياغة التالية:

```
-- a single line comment
-- another single line comment

{-
  a multiline comment
  spanning multiple lines
-}
```

_لكن_، ولأن كود Unison يُحفظ كتجزئة لشجرة التركيب المجردة الخاصة به، لا كملفات نصية على نظام الملفات، فإن التعليقات التي هي «زخارف» نصية لدالة أو حدّ معيّن في الملف لا يمكن حفظها وإعادة عرضها للمشاركة فعليًا. وإذا أردت إضافة معلومات إلى حدّ Unison لديك بطريقة تُخزَّن ليقرأها الآخرون ويفهموها، فيمكنك استخدام حرفي التوثيق.

التوثيق قيمة من الدرجة الأولى في لغة البرمجة Unison. وهذا يعني أنه يمكن إسناد عنصر `Doc` إلى قيمة، أو تمريره كقيمة إلى دالة، أو إرجاعه كقيمة لدالة. وتُفتح عناصر حرفي التوثيق وتُغلق بالأقواس المعقوفة المزدوجة. وإليك كيف يمكننا استخدام عنصر `Doc` كتعليق.

```
myFunction: Nat -> Boolean
myFunction n =

  {{ when n is `4` we have a special important business logic exception}}

  if n === 4 then true
  else
    if isEven n then false
    else true
```
