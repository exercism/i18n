# التعليمات

كل دور في مسرحية المدرسة له ممثل بديل: شخص يمكنه أن يحلّ محلّه ويؤدي ما يتطلبه الدور، دون أن يعرف مدير المسرح من يكون.

تُوضع المهام الخمس كلها في صنف `UNDERSTUDY`. المهمتان الأوليان إجراءان عاديان ستربطهما المهام اللاحقة.

## 1. طريقتان لنطق سطر

اكتب `shout`، وهي تُرجع السطر بأحرف كبيرة، واكتب `whisper`، وهي تُرجع السطر بأحرف صغيرة مع `"..."` على الطرفين.

```sather
UNDERSTUDY::shout("who's there")
-- => "WHO'S THERE"
UNDERSTUDY::whisper("Who's There")
-- => "...who's there..."
```

## 2. التمرّن على سطر

تأخذ `rehearse` سطرًا وأسلوبًا لنطقه، وتُرجع النتيجة. وسيطها الثاني من النوع `ROUT{STR}:STR`.

```sather
UNDERSTUDY::rehearse("who's there", bind(UNDERSTUDY::shout(_)))
-- => "WHO'S THERE"
```

## 3. المشهد كاملًا

تأخذ `run_scene` مصفوفة من الأسطر وأسلوبًا لنطقها، وتُرجعها كلها منطوقة بذلك الأسلوب، موصولة بـ `" "`.

```sather
UNDERSTUDY::run_scene(|"Enter", "Exit"|, bind(UNDERSTUDY::shout(_)))
-- => "ENTER EXIT"
```

المشهد الفارغ هو السلسلة النصية الفارغة.

## 4. إعادة أسلوب لنطق الأشياء

تأخذ `understudy_for` اسم أسلوب، وهو `"shout"` أو أي شيء آخر، وتُرجع `ROUT{STR}:STR`. يعطي `"shout"` الأسلوب الصارخ؛ وأي شيء آخر يعطي الأسلوب الهامس.

```sather
part ::= UNDERSTUDY::understudy_for("shout");
part.call("who's there")
-- => "WHO'S THERE"
```

## 5. تثبيت وسيط

اكتب `repeat`، وهي تأخذ عددًا من المرات وسطرًا وتُرجع السطر مكرّرًا ذلك العدد من المرات دون أي شيء بين التكرارات:

```sather
UNDERSTUDY::repeat(3, "Ha")
-- => "HaHaHa"
```

ثم اكتب `doubler`، وهي لا تأخذ أي وسائط وتُرجع `ROUT{STR}:STR` يكرّر ما يُعطى له مرتين، وذلك بربط `repeat` مع العدد مُعبّأً من قبل.

```sather
UNDERSTUDY::doubler.call("Ha")
-- => "HaHa"
```
