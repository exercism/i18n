# التعليمات

حنينك إلى بطاقات Blorkemon™️ لا يبدو أنه سيخبو؛ فقد بدأت تجمعها من جديد، وتجعل أصدقاءك ينضمون إليك.

في هذا التمرين، ستستخدم واجهة `Set` لمساعدتك على إدارة مجموعتك، لأن البطاقات المكررة لا تهم عندما يكون هدفك جمع كل البطاقات الموجودة.

## 1. ابدأ مجموعة

لقد وجدت للتو مخزونك القديم من بطاقات Blorkemon™️!
يحتوي المخزون على مجموعة من البطاقات المكررة، لذا حان الوقت لبدء مجموعة جديدة بإزالة المكرر منها.

أنت تتوق حقًا لأن ينضم أصدقاؤك إلى جنون Blorkemon™️، وأفضل طريقة لذلك هي أن تطلق مجموعتهم بمنحهم بطاقة واحدة.

نفّذ طريقة `newCollection` التي تحوّل مصفوفة من البطاقات إلى `Set` يمثل مجموعتك الجديدة.

```java
GottaSnatchEmAll.newCollection(List.of("Newthree", "Newthree", "Newthree"));
// => {"Newthree"}
```

## 2. وسّع المجموعة

بمجرد أن تصبح لديك مجموعة، فإنها تستقل بحياتها الخاصة ويجب أن تنمو.

نفّذ طريقة `addCard` التي تأخذ بطاقة جديدة ومجموعة بطاقاتك الحالية. ينبغي للطريقة أن تضيف البطاقة الجديدة إلى المجموعة إن لم تكن موجودة فيها من قبل، وأن تُرجع قيمة `boolean` تشير إلى ما إذا كانت المجموعة قد تحدّثت.

```java
Set<String> collection = GottaSnatchEmAll.newCollection("Newthree");
GottaSnatchEmAll.addCard("Scientuna",collection);
// => true

collection.contains("Scientuna");
// => true
```

## 3. ابدأ المقايضة

أنت تتوق حقًا لأن ينضم أصدقاؤك إلى جنون Blorkemon™️، لذا حان وقت المقايضة!

عند المقايضة مع الأصدقاء، ليست كل مقايضة تستحق أو يمكن إجراؤها أصلًا.
ينبغي ألا تقايض إلا إذا كانت لديك أنت وصديقك بطاقة لا يملكها الطرف الآخر.

نفّذ طريقة `canTrade` التي تأخذ مجموعتك الحالية ومجموعة أحد أصدقائك.
وينبغي أن تُرجع قيمة `boolean` تشير إلى ما إذا كانت المقايضة ممكنة، وفق القواعد أعلاه.

```java
Set<String> myCollection = Set.of("Newthree");
Set<String> theirCollection = Set.of("Scientuna");
GottaSnatchEmAll.canTrade(myCollection, theirCollection);
// => true
```

## 4. حدّد البطاقات المشتركة

تجتمع أنت وأصدقاؤك المهووسون بـ Blorkemon™️ وتتساءلون أي البطاقات هي الأكثر شيوعًا.

نفّذ طريقة `commonCards` التي تأخذ مصفوفة من المجموعات وتُرجع مجموعة من البطاقات التي تملكها كل المجموعات.

```java
GottaSnatchEmAll.commonCards(List.of(Set.of("Scientuna"), Set.of("Newthree","Scientuna")));
// => {"Scientuna"}
```

## 5. كل البطاقات

هل تملك أنت وأصدقاؤك مجتمعين كل بطاقات Blorkemon™️؟

نفّذ طريقة `allCards` التي تأخذ مصفوفة من المجموعات وتُرجع مجموعة بكل البطاقات المختلفة في جميع المجموعات مجتمعة.

```java
GottaSnatchEmAll.allCards(List.of(Set.of("Scientuna"), Set.of("Newthree","Scientuna")));
// => {"Newthree", "Scientuna"}
```
