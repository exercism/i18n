# مقدمة

## الأعداد

تحتوي العديد من لغات البرمجة على أنواع عددية محددة لتمثيل أنواع مختلفة من الأعداد، لكن JavaScript لديها نوعان فقط:

- `number`: نوع بيانات عددي بصيغة الفاصلة العائمة ثنائية الدقة بسعة 64 بت (IEEE 754).
  ومن الأمثلة على ذلك `-6`، `-2.4`، `0`، `0.1`، `1`، `3.14`، `16.984025`، `25`، `976`، `1024.0` و`500000`.
- `bigint`: نوع بيانات عددي يمكنه تمثيل _الأعداد الصحيحة_ بصيغة الدقة الاعتباطية.
  ومن الأمثلة على ذلك `-12n`، `0n`، `4n`، و`9007199254740991n`.

إذا كنت بحاجة إلى دقة اعتباطية أو كنت تتعامل مع أعداد كبيرة جدًا، فاستخدم النوع `bigint`.
وإلا، فمن المرجح أن يكون النوع `number` هو الخيار الأفضل.

### التقريب

يوجد كائن عام مدمج يُسمى `Math` يوفر [دوال تقريب][ref-math-object-rounding] متنوعة.
على سبيل المثال، يمكنك تقريب الأعداد العشرية للأسفل (`floor`) أو للأعلى (`ceil`) إلى أقرب عدد صحيح.

```javascript
Math.floor(234.34); // => 234
Math.ceil(234.34); // => 235
```

## العوامل الحسابية

توفر JavaScript 6 عوامل مختلفة لإجراء العمليات الحسابية الأساسية على الأعداد.

- `+`: يُستخدم عامل الجمع لإيجاد مجموع الأعداد.
- `-`: يُستخدم عامل الطرح لإيجاد الفرق بين عددين
- `*`: يُستخدم عامل الضرب لإيجاد حاصل ضرب عددين.
- `/`: يُستخدم عامل القسمة لقسمة عددين.

```javascript
2 - 1.5; //=> 0.5
19 / 2; //=> 9.5
```

- `%`: يُستخدم عامل الباقي لإيجاد باقي عملية القسمة.

  ```javascript
  40 % 4; // => 0
  -11 % 4; // => -3
  ```

- `**`: يُستخدم عامل الأس لرفع عدد إلى قوة.

  ```javascript
  4 ** 3; // => 64
  4 ** 1 / 2; // => 2
  ```

### ترتيب العمليات

عند استخدام عدة عوامل في سطر واحد، تتبع JavaScript ترتيب أسبقية كما هو موضح في [جدول الأسبقية هذا][mdn-operator-precedence].
وبتبسيط ذلك في سياقنا، تستخدم JavaScript قاعدة PEDMAS (الأقواس، الأسس، القسمة/الضرب، الجمع/الطرح) التي تعلمناها في حصص الرياضيات في المرحلة الابتدائية.

<!-- prettier-ignore-start -->
```javascript
const result = 3 ** 3 + 9 * 4 / (3 - 1);
// => 3 ** 3 + 9 * 4/2
// => 27 + 9 * 4/2
// => 27 + 18
// => 45
```
<!-- prettier-ignore-end -->

### عوامل الإسناد المختصرة

عوامل الإسناد المختصرة هي طريقة أقصر لكتابة كود يجري عمليات حسابية على متغير، ويسند القيمة الجديدة إلى المتغير نفسه.
على سبيل المثال، اعتبر متغيرين `x` و`y`.
إذن، `x += y` تكافئ `x = x + y`.
غالبًا ما يُستخدم هذا مع عدد بدلًا من المتغير `y`.
ويمكن إجراء 5 عمليات أخرى بالأسلوب نفسه أيضًا.

```javascript
let x = 5;
x += 25; // x is now 30

let y = 31;
y %= 3; // y is now 1
```
