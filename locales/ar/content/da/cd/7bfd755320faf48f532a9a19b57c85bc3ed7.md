# نبذة

في Python، [التعداد][enum-docs] هو مجموعة من الأسماء الفريدة المرتبطة بقيم فريدة و**ثابتة**.
تُعرَّف `Enums` بالوراثة من صنف `Enum`.
أنواع التعداد المدمجة متاحة في الوحدة `enum`، ويمكن استيراد الصنف `Enum` باستخدام `from enum import Enum`.


```python
from enum import Enum

class Color(Enum):
    RED = 1
    GREEN = 2
```

لاحظ أن قيم أعضاء `enum` يمكن أن تكون أي أنواع بيانات مثل `str` و`tuple` و`float` وغيرها.

```python
class Color(Enum):
    RED = 'red'
    GREEN = 'green'
```

يمكن أيضًا إنشاء `Enums` باستخدام [صيغة استدعاء الدالة][enum-functional-example].

```python
from enum import Enum

Animal = Enum('Animal', 'ANT BEE CAT DOG')
list(Animal)
#=> [<Animal.ANT: 1>, <Animal.BEE: 2>, <Animal.CAT: 3>, <Animal.DOG: 4>]

Animal.ANT.value
#=> 1
```

عند إسناد القيمة نفسها إلى عضوين في `enum`، يصبح العضو المُسنَد لاحقًا اسمًا مستعارًا للعضو الأول. ولا يُسمح باستخدام الاسم نفسه لعضوين مختلفين في `enum`.

```python
class Color(Enum):
    RED = 1
    GREEN = 2
    ALIAS_OF_RED = 1

Color.ALIAS_OF_RED
#=> <Color.RED: 1>
```

يمكن التكرار على أعضاء التعداد باستخدام الصيغة المعتادة `for member in`:

```python
for member in Color:
    print((member.name, member.value))
#=> (RED, 1)
#=> (GREEN, 2)

# __members__.items() helps you to loop through alias as well
for member in Color.__members__.items():
    print(member)
#=> ('RED', <Color.RED: 1>)
#=> ('GREEN', <Color.GREEN: 2>)
#=> ('ALIAS_OF_RED', <Color.RED: 1>)
```

يمكن مقارنة أعضاء `Enum` باستخدام [`is` (_عامل الهوية_)][identity-keyword] أو `is not`. ويعمل `==` و`!=` (_عاملا المساواة_) بالطريقة نفسها:


```python
a = Color.RED

a is Color.RED
#=> True

a == Color.RED
#=> True
```

لإسناد قيم صحيحة، تبدأ [دالة `auto()`][enum-auto-docs] بالقيمة `1` وتضبط القيم التالية تلقائيًا.

```python
class Shape(Enum):
    CIRCLE = auto()
    SQUARE = auto()
    OVAL = auto()
```

لمنع الأسماء المستعارة (_منع القيم المكررة بأسماء مختلفة_)، يمكن استخدام [مُزخرف الصنف][class-decorator] [`@enum.unique`][enum-unique-decorator].

```python
@enum.unique
class Shape(Enum):
    CIRCLE = 1
    SQUARE = 2
    TRIANGLE = 1
#=> ValueError: duplicate values found in <enum 'Shape'>: TRIANGLE -> CIRCLE
```

للوصول إلى عضو `enum` عند قيمة معينة، يمكن استخدام هذه الصيغة: `<EnumName>(<value>)`.

```python
g = Color(2)

g is Color.GREEN
#=> True

g
#=> <Color.GREEN: 2>
```

يمكن كتابة [`Enum` مقيَّد][restricted-enums] مخصص بإنشاء صنف فرعي من الصنف `Enum` مع أي صنف مزيج أو نوع بيانات.
على سبيل المثال:


```python
class StrEnum(str, Enum):
    pass
```

لا يُسمح بإنشاء صنف فرعي من `Enum` إلا إذا كان `enum` **لا** يعرّف أي أعضاء.
