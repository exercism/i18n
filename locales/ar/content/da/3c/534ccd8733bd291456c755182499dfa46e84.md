# مقدمة

تسمح لك الدالة في Cairo بتجميع الكود في وحدة قابلة لإعادة الاستخدام، مما يجعل برامجك أكثر معيارية وأسهل في الفهم.
تتكون الدوال في Cairo من الكلمة المفتاحية `fn`، يتبعها اسم الدالة، وقائمة من المعاملات بين الأقواس الهلالية، وكتلة كود تحدد ما تفعله الدالة.

## معاملات الدالة

في Cairo، يجب تحديد نوع جميع معاملات الدالة صراحةً.
وخلافًا لبعض اللغات، لا يستنتج Cairo الأنواع، ولا توجد قيم افتراضية للمعاملات، لذا فجميع المعاملات مطلوبة.

```rust
// Function with no parameters
fn print_hello() {
    // Function body
}

// Function with two parameters
fn print_greeting_name(greeting: ByteArray, name: ByteArray) {
    // Function body
}
```

## المعاملات مقابل الوسائط

من المهم التمييز بين `parameters` و`arguments`:

- **المعاملات** هي أسماء المتغيرات المستخدمة في تعريف الدالة، مثل `greeting` و`name` في الدالة `print_greeting_name`.
- **الوسائط** هي القيم الفعلية التي تُمرَّر إلى الدالة عند استدعائها.

```rust
// Calling the function with arguments
print_greeting_name(123, 456)
```

## العبارات والتعبيرات

تتكون أجسام الدوال من مجموعة من العبارات تنتهي اختياريًا بتعبير.

- العبارات هي تعليمات تنفذ إجراءً ما ولا تُرجع قيمة.
- التعبيرات تُقيَّم إلى قيمة ناتجة.

إنشاء متغير وإسناد قيمة إليه باستخدام الكلمة المفتاحية `let` هو عبارة.

```rust
let y = 6;
```

لكن `6` في العبارة أعلاه تعبير يُقيَّم إلى القيمة `6`.

استدعاء الدالة تعبير، لأنه يُقيَّم دائمًا إلى قيمة: قيمة الإرجاع الصريحة للدالة إن حُددت، أو نوع «الوحدة» `()` بخلاف ذلك.

## قيم الإرجاع

يمكن لدوال Cairo أن تُرجع قيمًا إلى الكود الذي يستدعيها.
تُذكر قيم الإرجاع بعد المعاملات، مفصولةً عنها بسهم `->`.
في Cairo، قيمة إرجاع الدالة مرادفة لقيمة التعبير الأخير في كتلة جسم الدالة.
يمكنك الإرجاع مبكرًا من الدالة باستخدام الكلمة المفتاحية `return` وتحديد قيمة.

```rust
// Function returning the last (and only) expression
fn hello(name: ByteArray) -> ByteArray {
    "Hello " + name
}

// Function returning using the `return` keyword
fn double_if_even(value: u32) -> u32 {
    if value % 2 == 0 {
        return value * 2;
    }
    return value;
}
```

## استدعاء الدوال

لاستدعاء دالة في Cairo، ما عليك سوى استخدام اسم الدالة متبوعًا بالوسائط بين الأقواس الهلالية.

```rust
// Calling a function with no parameters
print_hello()

// Calling a function with one parameter
let greeting = hello("John")

// Calling a function with multiple parameters
print_greeting_name("Howdy", "Joel")
```
