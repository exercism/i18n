# مصادر

## مصادر التعلّم الموصى بها

Clojurescript هي لهجة مصممة بعناية من Clojure. يمكنك الاستفادة من معرفتك بـ Clojure، أعني معرفتك باللغة نفسها لا بمنصة تشغيل جافا الافتراضية JVM، في Clojurescript.

- [ClojureScript API](http://cljs.github.io/api/) توثيق API الرسمي.
- [Clojurescript Cheat-Sheet](https://clojure.org/api/cheatsheet)، وهي ورقة مرجعية سريعة رسمية.
- [Learn Clojurescript Syntax in 15 minutes](https://github.com/shaunlebron/ClojureScript-Syntax-in-15-minutes) مستودع GitHub لتعليمك صياغة اللغة.
