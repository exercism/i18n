# مقدمة

الثوابت قيم تُحدَّد في وقت التصريف ولا يمكن إعادة إسنادها.
استخدم الكلمة المفتاحية `const` لتعريف ثابت واحد:

```go
const greeting = "hello"
```

يمكن تعريف عدة ثوابت داخل كتلة.
وداخل الكتلة، الثابت الذي لا تُحدَّد له قيمة صراحةً يُكرّر التعبير السابق:

```go
const (
    greeting    = "hello"
    buffSize    = 4096
    chunkSize   // 4096
)
```

عادةً ما تُعرَّف الثوابت على مستوى الحزمة، وإن كان يمكن تعريفها أيضًا داخل دالة.

## الثوابت المحدَّدة وغير المحدَّدة النوع

تعريف الثابت دون تحديد نوعه يجعله غير محدَّد النوع.
الثابت غير المحدَّد النوع ليس له نوع ثابت، بل تُحدِّد قيمته الأنواع التي يتوافق معها.
وما دامت القيمة الأساسية متوافقة، سيحوّله المصرّف إلى النوع المطلوب عند كل استخدام:

```go
const numA = 2

math.Sqrt(numA)  // numA is treated as float64 here
var numB int = numA  // numA is treated as int here
```

أما الثابت المحدَّد النوع فيثبّت النوع عند تعريفه:

```go
const num int = 2

math.Sqrt(num)  // compile error because a float is expected
```

## ما الذي يمكن أن يكون ثابتًا

لا يمكن أن تحمل الثوابت إلا القيم المنطقية والأعداد والسلاسل النصية وقيم `rune`.
ولأن القيم تُحدَّد في وقت التصريف، لا يمكن استخدام نتائج استدعاء دالة لتعريف ثابت.

```go
const s = math.Sqrt(4)  // compile error because the value isn't known at compile time
```

## iota

داخل كتلة الثوابت، يمثّل `iota` موضع الثابت ضمن الكتلة:

```go
const (
    Sunday    = iota // 0
    Monday           // 1
    Tuesday          // 2
    Wednesday        // 3
)
```

وكل ثابت بعد الأول يَرِث التعبير نفسه، مع ازدياد `iota` بمقدار واحد.

ويعمل `iota` أيضًا داخل التعبيرات.

```go
const (
    _  = iota             // position 0: value discarded
    KB = 1 << (10 * iota) // position 1: 1 << 10 = 1024
    MB                    // position 2: 1 << 20 = 1048576
    GB                    // position 3: 1 << 30 = 1073741824
)
```
