# التثبيت

## تمهيد

على الرغم من أن Regina Rexx قد نُقلت إلى منصات كثيرة، فإن تعليمات التثبيت هنا ستركّز على منصات سطح المكتب بمعمارية 64 بت التي تعمل بنظام Windows أو Linux أو MacOS.

## خطوات التثبيت

يُرجى ملاحظة أن هذا المسار يتوقع تثبيت أحدث إصدار من [Regina](https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/) (وهو 3.9.5 وقت كتابة هذه الصفحة). ينقلك الرابط أعلاه مباشرةً إلى قسم الملفات، حيث تختار الملف الذي تريد تنزيله.

### Windows

يمكنك بسهولة تثبيت Regina ليعمل أصلاً تحت Windows (عبر نافذة CMD أو Powershell) من المتصفح باستخدام زر [`Download Latest Version`](https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/Regina395w64.exe/download). كل ما عليك فعله هو النقر ثم التنزيل ثم التثبيت.

إذا كانت لديك، أو كنت ترغب في استخدام، بيئات محاكاة Linux مثل:

* [Git for Windows](https://gitforwindows.org/)
* [Cygwin](https://cygwin.com/)
* [MinGW](http://mingw.org/)

فمن المفترض أن تكون ملفات Regina التنفيذية الخاصة بـ Windows متاحة، لذا يمكنك تشغيلها مباشرةً في هذه البيئات، وهذا كافٍ في معظم الحالات.

غير أن هناك تحذيرًا واحدًا: تعليمة ADDRESS لا تعمل بشكل صحيح (لأنها تتعامل مع نظام التشغيل المضيف). وللحصول على أفضل النتائج في هذه البيئات، أحضر الحزمة الخاصة بالبيئة وثبّتها. فموقع Regina، على سبيل المثال، يستضيف نسخة [خاصة بـ Cygwin](https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/regina-rexx-3.9.5-x86_64-pc-cygwin.tgz/download) يمكن تثبيتها.

أو إذا كانت لديك، أو كنت ترغب في استخدام، توزيعة Linux _حقيقية_ تحت Windows مثل [WSL](https://docs.microsoft.com/en-us/windows/wsl/about) أو [Virtual Box](https://www.virtualbox.org/)، فاتبع ببساطة التعليمات الواردة في قسم Linux الخاصة بالتوزيعة المعنية.

### Linux

عادةً ما يكون التثبيت على Linux مباشرًا إلى حد كبير عند استخدام مدير الحزم الخاص بالنظام. لكنه يصبح مشكِلًا حين لا تكون الحزم المتاحة هي _أحدث_ إصدار متوفر. وهذا للأسف هو حال Regina.

يبقى التثبيت عبر الحزم ممكنًا إذا أحضرت أحدث حزمة يدويًا. ويستضيف موقع [Regina](https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/) حزمًا لعائلة توزيعات Debian (وتشمل Ubuntu) وعائلة RHEL (وتشمل Fedora وCentOS وRocky وAlma)، وغيرها.

بالنسبة للتوزيعة التي تختارها، ستحتاج إلى تنزيل حزمتين: حزمة مكتبة وحزمة ملفات تنفيذية. وعلى سبيل المثال، للتثبيت على Debian أو Ubuntu، افعل ما يلي:

```plain
sudo apt update && sudo apt -y install curl
curl -sLk https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/regina-rexx_3.9.5-2_amd64-Debian-11.deb > regina-rexx_3.9.5-2_amd64-Debian-11.deb
curl -sLk https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/libregina3_3.9.5-2_amd64-Debian-11.deb > libregina3_3.9.5-2_amd64-Debian-11.deb
sudo apt -y install libregina3_3.9.5-2_amd64-Debian-11.deb regina-rexx_3.9.5-2_amd64-Debian-11.deb
```

وعلى CentOS وRHEL 7، جرّب:
```plain
sudo yum update && sudo yum install curl
curl -sLk https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/regina-rexx-3.9.5-220823.1647.x86_64-CentOS-7.9.2009.rpm > regina-rexx-3.9.5-220823.1647.x86_64-CentOS-7.9.2009.rpm
curl -sLk https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/libregina3-3.9.5-220823.1647.x86_64-CentOS-7.9.2009.rpm > libregina3-3.9.5-220823.1647.x86_64-CentOS-7.9.2009.rpm
sudo yum localinstall libregina3-3.9.5-220823.1647.x86_64-CentOS-7.9.2009.rpm regina-rexx-3.9.5-220823.1647.x86_64-CentOS-7.9.2009.rpm
```

وعلى Fedora وRocky وAlma، جرّب:
```plain
sudo dnf update && sudo dnf install curl
curl -sLk https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/regina-rexx-3.9.5-220826.0951.x86_64-rocky-9.0.rpm > regina-rexx-3.9.5-220826.0951.x86_64-rocky-9.0.rpm
curl -sLk https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/libregina3-3.9.5-220826.0951.x86_64-rocky-9.0.rpm > libregina3-3.9.5-220826.0951.x86_64-rocky-9.0.rpm
sudo dnf localinstall libregina3-3.9.5-220826.0951.x86_64-rocky-9.0.rpm regina-rexx-3.9.5-220826.0951.x86_64-rocky-9.0.rpm
```

وحين لا يكون التثبيت عبر الحزم ممكنًا، أو يثبت أنه مشكِل، يبقى البناء من المصدر ممكنًا دائمًا، ويمكنك الحصول على الأرشيف من:

```plain
curl -sLk https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/regina-rexx-3.9.5.tar.gz > regina-rexx-3.9.5.tar.gz
```

بافتراض أن أدوات البناء القياسية (gcc وmake) مثبّتة (وإن لم تكن كذلك، فاتبع التعليمات هنا: [Install Development Tools](https://ostechnix.com/install-development-tools-linux/))، نفّذ الخطوات التالية:

```plain
tar -xzvf regina-rexx-3.9.5.tar.gz && cd regina-rexx-3.9.5
./configure
sudo make
sudo make install
```

وتُثبَّت المكتبة (`libregina.so`) ومجموعتان من الملفات التنفيذية (`rexx` و`regina`) في الموضع الافتراضي `/usr/local/bin`.

الملف التنفيذي `rexx` مرتبط ارتباطًا ساكنًا، لذا فهو مكتفٍ بذاته وجاهز للاستخدام.

أما الملف التنفيذي `regina` فمرتبط ارتباطًا ديناميكيًا، ولذلك يحتاج إلى بعض الإعداد ليجد المكتبة المشتركة `libregina.so` أثناء التشغيل. وللقيام بذلك اتبع الخطوات التالية:

```plain
# Configure shared library location
sudo su
echo /usr/local/lib64/ > /etc/ld.so.conf.d/regina-rexx-3.9.5-x86_64.conf
echo /usr/local/lib64/regina-rexx/addons > /etc/ld.so.conf.d/regina-rexx-addons-x86_64.conf
cd /usr/local/lib64
rm -f libregina.so libregina.so.3
ln -s libregina.so.3.9 libregina.so
ln -s libregina.so.3.9 libregina.so.3
ldconfig
exit

# Check symbolic link creation
ls -l /usr/local/lib64/

# Output should be similar. Note symbolic links.
-rw-r--r--. 1 root root 3887554 Dec  1 18:22 libregina.a
lrwxrwxrwx. 1 root root      16 Dec  2 06:03 libregina.so -> libregina.so.3.9
lrwxrwxrwx. 1 root root      16 Dec  2 06:03 libregina.so.3 -> libregina.so.3.9
-rwxr-xr-x. 1 root root  574104 Dec  1 18:22 libregina.so.3.9
drwxr-xr-x. 2 root root      26 Dec  1 18:22 pkgconfig
drwxr-xr-x. 4 root root      33 Dec  1 18:22 regina-rexx

# Check library path, and executable using that path
ldconfig -p | grep regina
ldd /usr/local/bin/regina

# Alternate for local user
export LD_LIBRARY_PATH=${LD_LIBRARY_PATH}:/usr/local/lib64:/usr/local/lib64/regina-rexx/addons
```

يُرجى ملاحظة أن البناء من المصدر، وما يصحبه من إعداد للنظام، مهمة يُفضَّل أن يتولاها مستخدمون ذوو خبرة.

### MacOS

يتكوّن التثبيت من ثلاث خطوات:

* ثبّت مدير الحزم [Homebrew](https://brew.sh)
* ابحث عن تطبيق `Terminal` وشغّله
* من سطر أوامر `Terminal`، أدخل ما يلي:

   `brew install regina-rexx`

وهذا _يفترض_ أن يثبّت أحدث إصدار.

وإن لم يفعل، يمكنك تنزيل حزمة [Regina for MacOS](https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/regina-rexx-3.9.5-x86_64-apple-darwin21.6.0.tgz/download) وتثبيتها يدويًا.

## بعد التثبيت

### التحقق من التثبيت

بعد إتمام التثبيت، يمكنك التحقق من نجاح تثبيت [Regina](https://sourceforge.net/projects/regina-rexx/files/regina-rexx/3.9.5/) بتشغيل هذا الأمر في الطرفية:

```plain
rexx --version=v
```

على منصتي Windows وLinux، سيظهر الناتج التالي في الطرفية:

```plain
3.9.5
```

وهو رقم إصدار المفسّر.

ويُثبَّت أيضًا ملف تنفيذي ثانٍ هو `regina`. وهو مطابق لـ `rexx` في كل شيء إلا أنه يرتبط بمكتبة مشتركة، وهو المفسّر الذي تستخدمه بدلًا منه إذا أردت الوصول إلى دوال مساعدة خارجية. راجع قسم [الوصول إلى إجراءات خارجية](###accessing-external-routines).

ولا حاجة إلى تثبيت أي مكوّنات برمجية أخرى لبدء استخدام المسار (بافتراض أن واجهة سطر أوامر Exercism مثبّتة).

ستمنحك ملاحظات الاستخدام أدناه أساسًا أوليًا في استخدام المفسّر من سطر الأوامر.

### الاستخدام

عادةً ما يكون لنص Rexx البرمجي امتداد _`.rexx`_، وإن لم يكن ذلك إلزاميًا، لأن المفسّر سيحاول تنفيذ أي اسم ملف يُمرَّر إليه كوسيط، وإن كان يحتوي على كود Rexx صالح فسينجح تشغيله.

سيحاول الأمر التالي تنفيذ ملف اسمه `hello.rexx`:

```plain
rexx hello.rexx
```

بافتراض أن الملف يحتوي على الكود التالي:

```rexx
say "Hello, world!"
exit 0
```

فسيكون الناتج في الطرفية:

```plain
Hello, world!
```

وسيظهر الناتج نفسه إذا أُعيدت تسمية الملف إلى `hello.txt` ونُفِّذ كما يلي:

```plain
rexx hello.txt
```

ومن المفيد جدًا أن تعرف أيضًا أنه يمكن تمرير كود النص البرمجي إلى المفسّر عبر أنبوب بدلًا من وجوده في ملف. ويمكن تنفيذ الكود السابق عبر الأنبوب كما يلي:

```plain
echo "say 'Hello, world' ; exit 0" | rexx
```

وهو يعمل بالقدر نفسه من طرفية Linux أو من طرفية Windows Powershell.

### استخدامات متقدمة

يمكن تمرير وسيط واحد أو أكثر من وسائط سطر الأوامر إلى ملفات النصوص البرمجية، وقد تُرجع هذه الملفات رموز إرجاع عشوائية صحيحة. غير أن المفسّر يحتاج إلى معرفة أن وسائط متعددة ستُمرَّر إلى النص البرمجي، ويتم ذلك عبر الخيار `-a`.

على سبيل المثال، افترض أن الملف `multiarg.rexx` يحتوي على الكود التالي:

```rexx
say "My name is" ARG(1) || ", your name is" ARG(2) || ", and the script return code will be" ARG(3) || "."
exit ABS(ARG(3))
```

ولضمان تفسير وسائط النص البرمجي المتعددة تفسيرًا صحيحًا، يُنفَّذ النص البرمجي كما يلي:

```plain
rexx -a multiarg.rexx "John" "Jill" 5
```

فينتج عن ذلك الناتج التالي في الطرفية:

```plain
My name is John, your name is Jill, and the script return code will be 5.
```

ويُضبط رمز إرجاع البرنامج (يمكن الوصول إليه عبر `$?` في Linux أو `%errorlevel%` في Windows) على القيمة 5.

### الوصول إلى إجراءات خارجية

يدعم Regina استخدام إجراءات مقيمة في مكتبات مشتركة خارجية. ويتوفر العديد منها على موقع Regina. لكننا لا نناقش هنا تثبيت مثل هذه المكتبات.

لكن Regina تأتي مرفقة بإحدى هذه المكتبات، وهي _regutil_. وتحتوي على عدة إجراءات عامة الغرض، منها ما يتعلق بالرياضيات والتعامل مع الملفات ونظام الملفات ومهام الوصول إلى النظام.

ولا حاجة إلى خطوات تثبيت إضافية. غير أن استخدام هذه الإجراءات في نص برمجي يتطلب تسجيلها عند تحميل المفسّر. ولا يحتاج ذلك إلى أكثر من استدعاءين لدالتين، ونوضّح العملية هنا.

يحتوي الملف `access-external.rexx` على الكود التالي:

```rexx
/* Register external library and functions */
call RxFuncAdd 'SysLoadFuncs', 'regutil', 'SysLoadFuncs'
call SysLoadFuncs

say "Value of pi is" SysPi()
say "Square root of 25 is" SysSqrt(25)
say "Square root of 2 is" SysSqrt(2)

/* Deregister */
call SysDropFuncs

exit 0
```

لتحميل هذه الإجراءات واستخدامها، يجب استخدام الملف التنفيذي `regina`، لذا يُنفَّذ النص البرمجي كما يلي:

```plain
regina access-external.rexx
```

فيظهر الناتج التالي في الطرفية:

```plain
Value of pi is 3.141592654
Square root of 25 is 5.000000000
Square root of 2 is 1.414213562
```

أما إذا استُخدم الملف التنفيذي `rexx` بدلًا منه، فسيكون الناتج في الطرفية على منصة Windows:

```plain

operable program or batch file.
'SYSPI' is not recognized as an internal or external command,
operable program or batch file.
'SYSSQRT' is not recognized as an internal or external command,
operable program or batch file.
'SYSSQRT' is not recognized as an internal or external command,
operable program or batch file.
'SYSDROPFUNCS' is not recognized as an internal or external command,
operable program or batch file.
```

```plain

sh: SYSSQRT: command not found

```
