# الكلمتان المفتاحيتان `break` و `continue`

عند استخدام بنية تحكم حلقية أو تكرارية، تساعدك الكلمتان المفتاحيتان `break` و `continue` على التحكم في مسار تنفيذ البرنامج.
تخرج الكلمة المفتاحية `break` من سياق الحلقة إلى النطاق الخارجي، فتنهي الحلقة بذلك.
وتتخطى الكلمة المفتاحية `continue` ما تبقى من التكرار الحالي، ثم تعيد سياق الحلقة إلى بداية التكرار التالي.
ورغم أن ذلك غير شائع، يمكن تمرير عدد مع الكلمة المفتاحية للتحكم في عدد السياقات التي تخرج منها أو تنتقل منها إلى التكرار التالي.

```php
<?php
$i = 1;
while ($i <= 10) {

    if ($i <= 5) {
        i += 1;
        continue;
    }
    break;
}
```

في المثال السابق تُنفَّذ `continue` خمس (5) مرات، لكن في التكرار السادس (6) تُنفَّذ `break`، فيخرج الكود من الحلقة.
