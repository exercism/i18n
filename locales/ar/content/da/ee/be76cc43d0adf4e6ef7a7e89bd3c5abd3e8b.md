# التعليمات

انتهى موسم كرة الشبكة، وجدول الترتيب هو ما يحدّد من يلعب النهائيات.

يمنحك الهيكل المبدئي صنف `TEAM`. اكتب `FINALS_LADDER` أسفله.

## 1. مَن فوق مَن؟

تأخذ `higher` فريقين وتجيب عمّا إذا كان الأول يستحق أن يعلو الثاني. الأكثر نقاطًا يأتي أولًا. والفرق المتساوية في النقاط يفصل بينها فارق الأهداف، الأعلى أولًا.

```sather
FINALS_LADDER::higher(#TEAM("Vixens", 24, 40), #TEAM("Magpies", 20, 90))
-- => true
```

## 2. جدول الترتيب

تأخذ `ladder` الفرق بأي ترتيب وتجيب بها مرتّبة. ويجب أن تبقى المصفوفة المُسلَّمة على حالها.

```sather
FINALS_LADDER::ladder(teams)
-- => the same teams, best first
```

## 3. اقرأ جدول الترتيب

تأخذ `names` مصفوفة من الفرق وتجيب بأسمائها موصولة بـ `", "`.

```sather
FINALS_LADDER::names(FINALS_LADDER::ladder(teams))
-- => "Vixens, Magpies, Swifts"
```

## 4. المتصدّرون

تأخذ `premiers` الفرق بأي ترتيب وتجيب باسم الفريق في القمة. وعند عدم وجود أي فرق، تكون الإجابة `""`.

```sather
FINALS_LADDER::premiers(teams)
-- => "Vixens"
```

## 5. ترتيب مختلف تمامًا

تأخذ `shortest_first` مصفوفة من السلاسل النصية وتجيب بها مرتّبة حسب الطول، الأقصر أولًا. والسلاسل النصية المتساوية في الطول تُرتَّب أبجديًا.

```sather
FINALS_LADDER::shortest_first(|"Magpies", "Vixens", "Swifts"|)
-- => "Swifts", "Vixens", "Magpies"
```

كسر التعادل ليس مجرد زخرفة. فالترتيب ليس مستقرًّا، ولولاه فقد يخرج اسمان بالطول نفسه بأي من الاتجاهين.

هذا هو نفس إجراء الترتيب في المهمة 2، مع تمرير قاعدة مختلفة إليه. وهذا هو مغزى التمرين.
