# مقدمة

تُستخدم المكرِّرات في Haxe للتكرار على قيمة باستخدام حلقة `for`. وهناك نوعان من المكرِّرات:

- `Iterator` وهو يكرِّر على قيمة.
- بيانات `Iterable`، وهي التي تتيح التكرار على نوع بيانات.

ويُمثَّل كلا المفهومين بالنوعين `Iterator<T>` و `Iterable<T>`:

```haxe
typedef Iterator<T> = {
  function hasNext():Bool;
  function next():T;
}

typedef Iterable<T> = {
  function iterator():Iterator<T>;
}
```

أي صنف يتوافق مع أحد هذين النوعين يمكن التكرار عليه باستخدام حلقة `for`. وإذا عرّف صنف ما الطريقتين `hasNext` و `next` فإنه يُعتبر مكرِّرًا، وإلا إذا عرّف طريقة `iterator` فإنه يُعتبر نوعًا قابلًا للتكرار.
