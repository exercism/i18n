تُمثَّل القيم المنطقية في Haxe بالنوع `Bool`، الذي يمكن لقيمه أن تكون إما `true` أو `false`.

يدعم Haxe ثلاثة عوامل منطقية: `!` (النفي الأحادي)، و`&&` (العطف الثنائي AND)، و`||` (الفصل الثنائي OR).

تستخدم التعبيرات المنطقية المركّبة (`&&` و`||`) تقييمًا قصير الدائرة، حيث تُقيَّم التعبيرات من اليسار إلى اليمين، ولكن بالقدر الضروري فقط. وهذا مهم في حالات مثل ما يلي:

```haxe
object != null && object.field == x
```

يضمن الفحص المنطقي الأول ألا يُلجأ إلى `object.field` إلا إذا لم يكن `object` مساويًا لـ `null`، وهو ما يحمي من خطأ في وقت التشغيل.

تختلف أسبقية العوامل المنطقية الثلاثة، وتُقيَّم بهذا الترتيب: `!` -> `&&` -> `||`.

يسمح حصر التعبيرات بين الأقواس الهلالية `()` بتجاوز قواعد الأسبقية هذه، لأن الأقواس الهلالية ذات أسبقية أعلى.

```haxe
!true && false   // => false
!(true && false) // => true
```
