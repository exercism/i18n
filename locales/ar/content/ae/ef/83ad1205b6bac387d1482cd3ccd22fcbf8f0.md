# التعليمات

في هذا التمرين، ستتولى إدارة نظام مخزون.

ينبغي أن يُنظَّم المخزون حسب اسم العنصر وأن يتتبع عدد العناصر المتاحة.

سيكون عليك التعامل مع إضافة عناصر إلى المخزون.
في كل مرة يظهر فيها عنصر في متجه معيّن، ينبغي زيادة كمية العنصر بمقدار `1` في المخزون.
سيكون عليك أيضًا التعامل مع حذف عناصر من المخزون عبر إنقاص الكميات بمقدار `1` عند الطلب.

وأخيرًا، ستحتاج إلى تنفيذ دالة تُرجع جميع أزواج المفتاح والقيمة في مخزون معيّن على هيئة `vector` من `pair`s.

~~~~exercism/note
الاختبارات في هذا التمرين محايدة تجاه التعديل، لكن أسماء الدوال تشير إلى أنه ينبغي ألا تُعدّل المدخل.
إذا أردت استخدام دوال من المقدمة دون تعديل المدخل، فستكون الدالة `copy()` مفيدة.
~~~~

## 1. إنشاء مخزون انطلاقًا من متجه

نفّذ الدالة `create_inventory(<input vector>)` التي تنشئ "مخزونًا" من متجه مُدخل من العناصر.
ينبغي أن تُرجع `dict` يحتوي على كل اسم عنصر مقترنًا بكميته المقابلة.

```julia-repl
julia> create_inventory(["coal", "wood", "wood", "diamond", "diamond", "diamond"])
Dict("coal" => 1, "wood" => 2, "diamond" => 3)
```

## 2. إضافة عناصر من متجه إلى قاموس موجود

نفّذ الدالة `add_items(<inventory dict>, <item vector>)` التي تضيف متجهًا من العناصر إلى المخزون المُمرَّر:

```julia-repl
julia> add_items(Dict("coal" => 1), ["wood", "iron", "coal", "wood"])
Dict("coal" => 2, "wood" => 2, "iron" => 1)
```

## 3. إنقاص العناصر من المخزون

نفّذ الدالة `decrement_items(<inventory dict>, <items vector>)` التي تأخذ `vector` من العناصر.
ينبغي أن تطرح دالتك `1` من عدد العنصر في كل مرة يظهر فيها ذلك العنصر في `vector`:

```julia-repl
julia> decrement_items(Dict("coal" => 3, "diamond" => 1, "iron" => 5), ["diamond", "coal", "iron", "iron"])
Dict("coal" => 2, "diamond" => 0, "iron" => 3)
```

لا ينبغي السماح لأعداد العناصر في المخزون بأن تنزل تحت 0.
إذا تجاوز عدد المرات التي يظهر فيها عنصر في `vector` المُدخل العدد المتاح، فستبقى الكمية المدرجة لذلك العنصر عند 0.
تُتجاهل الطلبات الإضافية لإنقاص العدد بمجرد أن يصل العدد إلى صفر.

```julia-repl
julia> decrement_items(Dict("coal" => 2, "wood" => 1, "diamond" => 2), ["coal", "coal", "wood", "wood", "diamond"])
Dict("coal" => 0, "wood" => 0, "diamond" => 1)
```

## 4. إزالة مُدخَلة بالكامل من المخزون

نفّذ الدالة `remove_item(<inventory dict>, <item>)` التي تزيل عنصرًا وعدده بالكامل من المخزون:

```julia-repl
julia> remove_item!(Dict("coal" => 2, "wood" => 1, "diamond" => 2), "coal")
Dict("wood" => 1, "diamond" => 2)
```

إذا لم يُعثر على العنصر في المخزون، فستُرجع الدالة المخزون الأصلي دون تغيير.

```julia-repl
julia> remove_item(Dict("coal" => 2, "wood" => 1, "diamond" => 2), "gold")
Dict("coal" => 2, "wood" => 1, "diamond" => 2)
```

## 5. إرجاع المحتوى الكامل للمخزون

نفّذ الدالة `list_inventory(<inventory dict>)` التي تأخذ مخزونًا وتُرجع متجهًا من أزواج `(item, quantity)`.

ينبغي أن يضم المتجه العناصر _المتاحة_ فقط (_تلك التي كميتها أكبر من صفر_)، وأن يُرتَّب حسب العناصر ترتيبًا أبجديًا:

```julia-repl
julia> list_inventory(Dict("coal" => 7, "wood" => 11, "diamond" => 2, "iron" => 7, "silver" => 0))
["coal" => 7, "diamond" => 2, "iron" => 7, "wood" => 11]
```
