# مقدمة

الجمل الشرطية في C++ تشبه الجمل الشرطية في لغات البرمجة الأخرى.
النوع الأساسي لأي عملية شرطية هو النوع `bool`، ويمكن أن يأخذ القيمة `true` أو `false`.
كثيرًا ما تُستخدم الجمل الشرطية كآليات للتحكم في مسار التنفيذ للتحقق من شروط مختلفة.

يمكن استخدام جملة شرطية `if`، وهي تنفّذ الكود الخاص بها إذا كان الشرط `true`، كما يلي:

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

في الحالات التي تتضمن أكثر من حالة واحدة، يمكن ربط عدة جمل شرطية `if` معًا باستخدام جملتي `else if` و `else`.

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

منذ C++17، يمكن أن تتضمن الجمل الشرطية `if` عبارة تهيئة قصيرة يمكن استخدامها لتهيئة متغير واحد أو أكثر للجملة الشرطية `if`.
على سبيل المثال:

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> ملاحظة: لا يمكن الوصول إلى أي متغيرات تُنشأ في التهيئة بعد نهاية الجملة الشرطية `if`.
