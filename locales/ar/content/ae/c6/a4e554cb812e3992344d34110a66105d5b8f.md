# مقدمة إلى الحلقات

لدى Bash شكلان من الحلقات:

* تكرار بعض الأوامر _لكل عنصر في قائمة من العناصر_،
* تكرار بعض الأوامر _طالما أن شرطًا ما صحيح (أو خطأ)_.

## حلقات `for`

للتكرار على قائمة من العناصر، نستخدم `for` حلقة.

```bash
for varname in words; do COMMANDS; done
```

يتم توسيع `words` باستخدام تقسيم الكلمات وتوسيع أسماء الملفات (الذي تعرّفنا عليه في [مفهوم الاقتباس][quoting]).
تُسند كل كلمة إلى `varname` بالترتيب، ثم تُنفَّذ الأوامر.

إليك بعض الأمثلة التي تُظهر متى يمكن أن تكون `for` حلقة مفيدة

* تنفيذ بعض الأوامر على مجموعة من الملفات.

    ```bash
    # source all the bash library files in the current directory
    for file in ./*.bash; do
        source "$file"
    done
    ```

* تنفيذ أمر ما على كل معامل من معاملات سكربت أو دالة.

    ```bash
    for arg in "$@"; do
        echo "argument: ${arg}"
    done
    ```

* تنفيذ أمر ما لكل كلمة مفصولة بمسافات بيضاء في مخرجات أمر.

    ```bash
    for i in $(seq 10); do
        echo "${i} squared is $((i * i))"
    done
    ```

    سنرى بعض التحذيرات حول هذا الأسلوب لاحقًا.

### `for` حلقة حسابية

لدى Bash حلقة حسابية.
ستبدو هذه مألوفة إلى حد ما لمستخدمي لغات البرمجة الأخرى.

```bash
for ((INITIALIZATION; CONDITION; INCREMENT)); do COMMANDS; done
```

تمثّل الأقواس الهلالية المزدوجة في Bash سياقًا حسابيًا (سنرى المزيد عن العمليات الحسابية في Bash في مفهوم لاحق).
يمكن كتابة المثال أعلاه الذي يستخدم `seq` هكذا

```bash
for ((i = 1; i <= 10; i++)); do
    echo "${i} squared is $((i * i))"
done
```

### متى لا تستخدم `for`

[لا تقرأ الأسطر باستخدام `for`][bashfaq1].

هذا نمط مضاد ستراه كثيرًا: التكرار على مخرجات `cat`.

```bash
for line in $(cat some.file); do 
    do_something_with "$line"
done
```

هذا خطأ من ناحيتين.

1. استبدال الأوامر غير مُقتبَس، لذا فهو عرضة لتقسيم الكلمات.
   تقسيم الكلمات، افتراضيًا، يقسّم عند _المسافات البيضاء_ وليس فقط الأسطر الجديدة.
   `for` حلقة هذه تكرّر على **الكلمات** في الملف، وليس على الأسطر.
2. استبدال الأوامر غير مُقتبَس، لذا فهو عرضة لتوسيع أسماء الملفات.
   ستتم مطابقة كل كلمة في الملف كنمط glob.

كما تعرّفنا في [مفهوم الاقتباس][quoting]، يمكن التحكم في تقسيم الكلمات باستخدام المتغير `IFS`، ويمكن إيقاف توسيع أسماء الملفات.
لكن هذا يميل إلى أن يكون حلًا هشًا.
استخدام `for` هو الأسلوب الخاطئ للتكرار على أسطر ملف.
الأسلوب الاصطلاحي لقراءة ملف هو استخدام حلقة `while`.

## حلقات `while`

استخدم `while` لتكرار تسلسل من الأوامر _طالما_ أن شرطًا ما صحيح.

```bash
while CONDITION_COMMANDS; do COMMANDS; done
```

كما هو الحال مع `if` (كما تعرّفنا في [مفهوم الجمل الشرطية][conditionals])، لا توجد بنية خاصة لـ CONDITION_COMMANDS.
ستحدد حالة خروج قائمة الأوامر ما إذا كانت النتيجة «صحيح» أو «خطأ».

## التحكم في الحلقات

أمر `break` يقفز خارج الحلقة.
يستأنف التحكم عند الأمر الذي يلي المُنهي `done` الخاص بالحلقة.

أمر `continue` يقفز إلى التكرار التالي من الحلقة.

## قراءة أسطر ملف

كما ذُكر، حلقة `while` هي الأسلوب الاصطلاحي لقراءة ملف.

```bash
while IFS= read -r line; do
    do_something_with "$line"
done < some.file
```

* يُقدَّم محتوى الملف كمدخل إلى الحلقة باستخدام إعادة التوجيه `<`.
* يُرجع أمر `read` القيمة «صحيح» إذا استطاع قراءة سطر كامل من مدخله.
  عندما يُستهلك المدخل، أو إذا انتهى السطر الأخير دون سطر جديد في النهاية، فإن `read` يُرجع «خطأ».
  * الأسلوب الاصطلاحي _حقًا_ لقراءة أسطر ملف، حتى لو لم ينتهِ السطر الأخير بسطر جديد، هو

    ```bash
    while IFS= read -r line || [[ -n "$line" ]]; do ...
    ```

* يخبر الخيار `-r` أمر `read` بعدم استبدال تسلسلات الشرطة المائلة العكسية: الشرطة المائلة العكسية مجرد حرف عادي.
* يُسند `IFS=` سلسلة نصية فارغة إلى `IFS` فقط طوال مدة أمر `read`.
  يوقف هذا تقسيم الكلمات مؤقتًا بحيث تُحفظ أي مسافات بيضاء بادئة أو لاحقة في سطر النص الوارد.

## `until`

تركيب `until` يكرر تسلسلًا من الأوامر طالما أن شرطًا ما **خطأ**.
تتكرر الحلقة _حتى_ يصبح الشرط صحيحًا.

```bash
until CONDITION_COMMANDS; do COMMANDS; done
```

من النادر استخدام `until`.
الأكثر شيوعًا هو استخدام حلقة `while` المنفية.

```bash
while ! CONDITION_COMANDS; do ...
```

## الحلقات اللانهائية

أحيانًا تريد التكرار إلى الأبد.
إليك أسلوبان للقيام بذلك.

1. حلقة `while` بشرط له دائمًا حالة خروج ناجحة

    ```bash
    while true; do ...
    ```

2.  `for` حلقة حسابية بتعبيرات فارغة

    ```bash
    for ((;;)); do ...
    ```

## Do-While

لا يوجد تركيب do-while صريح، لكن يمكنك تحقيق نفس التأثير:

```bash
while true; do
    COMMANDS

    if END_CONDITION; then
        break
    fi
done
```
