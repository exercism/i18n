# التثبيت

## Ubuntu (ومعظم التوزيعات الأخرى المبنية على Debian)

لبناء الكود محليًا، ستحتاج إلى `gcc` و`make`، ويمكن تثبيتهما باستخدام

```shell
sudo apt install gcc make
```

إذا لم تكن تعمل على عتاد ARM64، فثبّت محاكي [QEMU][] ومجموعة أدوات GCC ARM64 للترجمة المتقاطعة باستخدام

```shell
sudo apt install qemu-user libc6-dev-arm64-cross gcc-aarch64-linux-gnu
```

## Windows

استخدم [Windows Subsystem for Linux][] مع توزيعة مبنية على Debian، ثم اتبع تعليمات Ubuntu الواردة أعلاه.
أو بدلًا من ذلك، جهّز آلة افتراضية تعمل بنظام Linux.

## macOS

يمكن تشغيل آلة افتراضية تعمل بنظام Linux باستخدام أي أداة افتراضية مناسبة (مثل [Lima][]).

[QEMU]: https://www.qemu.org/
[Windows Subsystem for Linux]: https://docs.microsoft.com/en-gb/windows/wsl/about
[Lima]: https://lima-vm.io/
