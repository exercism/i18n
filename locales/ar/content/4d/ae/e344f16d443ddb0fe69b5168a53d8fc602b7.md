# مقدمة

## دوال رد الاتصال

دوال رد الاتصال هي دوال تُمرَّر كوسائط.
ينشئ هذا النمط البرمجي تسلسلًا من استدعاءات الدوال في البرمجة المتزامنة وغير المتزامنة على حد سواء.
لا تختلف كتابة دالة رد الاتصال عن كتابة أي دالة أخرى؛ غير أن دالة رد الاتصال يجب أن تطابق التوقيع الذي تحدده الدالة المستدعية.

```javascript
const squareLength = 5;

// Caller function takes a callback function
function applyToSquare(callback) {
  return callback(squareLength);
}

// Callback must expect the possible argument from the calling function
function areaOfSquare(number) {
  return number * number;
}

applyToSquare(areaOfSquare); // => 25
```

يمكنك أيضًا كتابة دوال رد الاتصال كتعبير دالة، أو تعبير دالة مجهول، أو تعبير دالة سهمي:

```javascript
applyToSquare(function squarePerimeter(side) {
  return side * 4;
});

applyToSquare(function (side) {
  return side * 4;
});

applyToSquare((side) => {
  return side * 4;
});
```
