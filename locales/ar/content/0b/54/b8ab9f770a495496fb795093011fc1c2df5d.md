# تجاهل

## خيارات سطر الأوامر الإضافية لـ `jq`

ستلاحظ خيارات إضافية لـ `jq` في الاختبارات.

```sh
run jq -s -R -c -f flower-field.jq << 'END_INPUT'
```

ما هي؟

- `-s`

  هذا هو وضع «slurp».
  فبدلًا من التعامل مع المدخل كتدفق من كائنات JSON،
  ستُجمع كل المدخلات في مصفوفة واحدة.

  ```sh
  $ seq 5 | jq -c '.'
  1
  2
  3
  4
  5
  $ seq 5 | jq -s -c '.'
  [1,2,3,4,5]
  ```

- `-R`

  ربما رأيت الخيار `-r` من قبل، وهو يُخرج سلاسل نصية «خام» (بدون علامات اقتباس).
  أما هذا الخيار فهو العكس تمامًا.
  ويُعتبر كل سطر من المدخل سلسلة نصية.

  مثالان:

  ```sh
  $ seq 5 | jq -R -c .
  "1"
  "2"
  "3"
  "4"
  "5"

  $ echo 42 | jq '. * 2'      # input is a JSON number
  84
  $ echo 42 | jq -R '. * 2'   # input is a JSON string
  "4242"
  ```

عندما تجمع بين هذين الخيارين، لن تحصل على مصفوفة من السلاسل النصية:
بل ستحصل على المدخل كله كسلسلة نصية واحدة، بما في ذلك محارف السطر الجديد في نهاية كل سطر.

```sh
$ seq 5 | jq -s -R -c .
"1\n2\n3\n4\n5\n"
```

التعامل مع هذا جزء من تحدّي هذا التمرين.
