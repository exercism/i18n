# الأعداد الصحيحة

الأعداد الصحيحة هي أعداد كاملة تنتمي إلى المجموعة `{..., -2, -1, 0, 1, 2, ...}`.
تتحدد القيمة العظمى والقيمة الصغرى للعدد الصحيح حسب النظام الذي يعمل عليه PHP.
في معظم الأنظمة الحديثة، يكون العدد الصحيح بقيمة 64 بت، أي أنه يستطيع تمثيل القيم من `-9_223_372_036_854_775_808` إلى `9_223_372_036_854_775_807` ضمناً.

```php
<?php

$a = 1234;
$a = 1_234_567;
```

يمكنك كتابة القيم الحرفية للأعداد الصحيحة في أساس غير الأساس 10 باستخدام بادئة الأساس:

```php
<?php

$a = 0123; // octal number (equivalent to 83 decimal)
$a = 0o123; // octal number (as of PHP 8.1.0)
$a = 0x1A; // hexadecimal number (equivalent to 26 decimal)
$a = 0b11111111; // binary number (equivalent to 255 decimal)
```
