# ملحق التعليمات

## تعليمات خاصة بالمسار

في هذا التمرين، عليك تعريف **بيئة** باسم `robot` تعرّف **الأسماء** `position` و`direction` و**فعلًا** `move`.

- فعل `create` الخاص بـ `robot` يأخذ الموضع والاتجاه الابتدائيين كمصفوفة من الصناديق.
    
    ```j
      r=. (0 0;'north') conew 'robot'
    ```
- `move` يحدّث قيم `position` و`direction` في **النسخة** المنشأة.
    ```j
      r=. (0,0;'north') conew 'robot'
      
      NB. initial state
      NB. ====================================
      position__r
        0 0
      direction__r
        north
      
      NB. new states after `move` is executed 
      NB. ====================================
      move__r 'LA'
      position__r
        _1 0
      direction__r
        west      
    ```
