# مقدمة

البنية الأساسية للبرمجة كائنية التوجه في Java هي _الصنف_، وهو مزيج من البيانات (_الحقول_) والسلوك (_الطرق_).
تُعرف حقول الصنف وطرقه باسم _أعضائه_.

يمكن التحكم في الوصول إلى الأعضاء من خلال معدِّلات الوصول، وأكثرها شيوعًا اثنان:

- `public`: يمكن لأي كود الوصول إلى العضو (دون قيود).
- `private`: لا يمكن الوصول إلى العضو إلا من الكود الموجود في الصنف نفسه.

يمكنك التفكير في الصنف كقالب لإنشاء نسخ من ذلك الصنف.
ولإنشاء نسخة من صنف (وتُعرف أيضًا باسم _الكائن_)، تُستخدم الكلمة المفتاحية `new`:

```java
class Car {
}

// Create two car instances
Car myCar = new Car();
Car yourCar = new Car();
```

للحقول نوع واسم (يُكتب الاسم بأسلوب camelCase)، ويمكن تعريفها في أي مكان داخل الصنف (ومن المعتاد أن تُكتب بأسلوب PascalCase):

```java
class Car {
    // Accessible by anyone
    public int weight;

    // Only accessible by code in this class
    private String color;
}
```

يمكنك اختياريًا إسناد قيمة ابتدائية إلى الحقل.
وإذا لم يحدد الحقل قيمة ابتدائية، فسيُضبط على القيمة الافتراضية لنوعه.
ويمكن الوصول إلى قيم حقول النسخة وتحديثها باستخدام ترميز النقطة.

```java
class Car {
    // Will be set to specified value
    public int weight = 2500;

    // Will be set to default value (0)
    public int year;
}

Car newCar = new Car();
newCar.weight; // => 2500
newCar.year;   // => 0

// Update value of the field
newCar.year = 2018;
```

عادةً ما تُحدَّث الحقول الخاصة كأثر جانبي لاستدعاء طريقة.
وهذه الطرق عادةً لا تُرجع أي قيمة، وفي هذه الحالة ينبغي أن يكون نوع الإرجاع `void`:

```java
class CarImporter {
    private int carsImported;

    public void importCars(int numberOfCars)
    {
        // Update private field from public method
        carsImported = carsImported + numberOfCars;
    }
}
```
