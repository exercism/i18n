# الاختبارات

نفّذ الاختبارات باستخدام:

```bash
$ wrenc exercise-name.spec.wren
```

على سبيل المثال، بالنسبة إلى `hello-world`:

```bash
$ wrenc hello-world.spec.wren
```


## فهم اختبارات التخطي

تُخبر طريقة `skip` مجموعة الاختبارات بعدم تشغيل اختبار معيّن.

- لماذا يتم تخطيها؟

لتمكين المستخدمين من التركيز على اختبار واحد في كل مرة، ثم تفعيلها واحدًا تلو الآخر أثناء تطويرهم للحل.

- كيف يتم تفعيلها؟

اختبار متخطّى:

```js
// this test will be skipped and not run
skip.test("title cased phrases") {
    Expect.value(Acronyms.parse("Portable Network Graphics")).toEqual("PNG")
}
```

ما عليك سوى تغيير `skip.test` إلى `do.test`.

```js
// now the test will be run normally
do.test("title cased phrases") {
    Expect.value(Acronyms.parse("Portable Network Graphics")).toEqual("PNG")
}
```

## إنشاء أول وحدة Wren لديك

تُحمّل اختبارات هذا المسار تنفيذك عن طريق استيراده كوحدة Wren:
`import "./bob" for Bob`. لا توجد صياغة خاصة لتصدير تنفيذك. كل ما عليك فعله هو تسمية صنفك `Bob` ليطابق عبارات الاستيراد `for
Bob`، وسيعمل كل شيء كما ينبغي.

```javascript
class Bob {
  static hey(message) {
    // Your solution to the exercise goes here
  }
}
```

يمكنك العثور على مزيد من المعلومات حول الوحدات في
[توثيق وحدات Wren][modularity].
ولتسهيل البدء، يوجد ملف Wren _هيكلي_ في مجلد كل تمرين.

[modularity]: https://wren.io/modularity.html
