# نبذة

في Go، يمكننا مقارنة القيم باستخدام عاملي التساوي والترتيب.
لدينا 6 من هذه العوامل:

| المقارنة          | العامل    |
| ------------------| --------- |
| يساوي             | `==`      |
| لا يساوي          | `!=`      |
| أصغر              | `<`       |
| أصغر أو يساوي     | `<=`      |
| أكبر              | `>`       |
| أكبر أو يساوي     | `>=`      |

نتيجة المقارنة دائمًا قيمة منطقية:

```go
a := 3

a != 4 // true
a > 5  // false
```

## عوامل التساوي

يتحقق عاملَا التساوي `==` و`!=` مما إذا كانت قيمة مساوية لأخرى أم لا، على الترتيب.
يمكننا استخدام عاملي التساوي مع معظم الأنواع في Go.
إليك بعض الأمثلة الشائعة:

```go
2 == 3 // false, integer comparison

2.1 != 2.2 // true, float comparison 

"hello" == "hello" // true, string comparison

'a' != 'b' // true, rune/byte comparison
```

## عوامل الترتيب

تتحقق عوامل الترتيب مما إذا كانت قيمة أكبر من (`>`) أو أكبر من أو تساوي (`>=`) أو أصغر من (`<`) أو أصغر من أو تساوي (`<=`) قيمة أخرى.
هذا النوع من المقارنة متاح للأعداد و`byte` و`rune` والسلاسل النصية.
عند مقارنة السلاسل النصية، يُتّبع الترتيب القاموسي (المعروف أيضًا بالترتيب المعجمي).

```go
2 > 3 // false, integer comparison

1.2 < 1.3 // true, float comparison

'a' > 'b' // false, rune/byte comparison

"Hello" < "World" // true, string comparison
```
