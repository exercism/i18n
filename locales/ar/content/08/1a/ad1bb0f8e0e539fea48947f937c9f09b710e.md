# التعليمات

في هذا التمرين، ستحاكي نظامًا حاسوبيًا قائمًا على النوافذ.
ستنشئ بعض النوافذ التي يمكن تحريكها وتغيير أحجامها وعرض محتوياتها.
الصورة التالية توضّح القيم التي ستعمل عليها أدناه.


## 1. عرّف بنية Size

عرّف بنية باسم `Size` لها خاصيتان من النوع `Int` هما `width` و`height` تخزّنان العرض والارتفاع الحاليين للنافذة على الترتيب.
ينبغي أن يكون العرض والارتفاع الابتدائيان 80 و60 على الترتيب.
أضف طريقة `resize(newWidth:newHeight:)` تأخذ معاملَي العرض والارتفاع الجديدين وتغيّر الخصائص لتعكس الحجم الجديد.

```swift
let size1080x764 = Size(width: 1080, height: 764)
// Returns Size
var size1200x800 = size1080x764
// Returns Size
size1200x800.resize(newWidth: 1200, newHeight: 800)
size1200x800.height
// Returns 800
```

## 2. عرّف بنية Position

عرّف بنية باسم `Position` لها خاصيتان من النوع `Int` هما `x` و`y` تخزّنان الموضع الأفقي والرأسي الحاليين، على الترتيب، للزاوية العلوية اليسرى للنافذة.
ينبغي أن تكون القيمة الابتدائية لكل من x و y هي 0. الموضع (0، 0) هو الزاوية العلوية اليسرى للشاشة، وتزداد قيم `x` كلما تحرّكت يمينًا وتزداد قيم `y` كلما تحرّكت لأسفل.

أضف طريقة `moveTo(newX:newY:)` تأخذ معاملَي x و y الجديدين وتغيّر الخصائص لتعكس الموضع الجديد.

```swift
var point = Position(x: 10, y: 20)
// Returns Position
point.moveTo(newX: 100, newY: -100)
point.y
// Returns -100
```

## 3. عرّف صنف Window

عرّف صنف نافذة بالخصائص التالية:

- `title` : `String`، القيمة الابتدائية هي "New Window"
- `screenSize` : `Size`، قيمة ثابتة حيث `width` = 800 و`height` = 600
- `size` : `Size`، القيمة الابتدائية هي القيمة الافتراضية لبنية `Size`
- `position` : `Position`، القيمة الابتدائية هي القيمة الافتراضية لبنية `Position`
- `contents` : `String?`، القيمة الابتدائية هي `nil`

ينبغي أيضًا أن تعرّف مُهيّئًا فارغًا للصنف.

```swift
let window = Window()
window.title
// Returns "New Window"
```

## 4. أضف طريقة لتغيير حجم النوافذ

- `resize(to:)` : `(Size) -> ()` - تأخذ هذه الطريقة بنية `Size` كمدخل وتحاول تغيير حجم النافذة إلى الحجم المحدد. ومع ذلك، لا يمكن للحجم الجديد أن يتجاوز حدودًا معينة.
- أصغر ارتفاع أو عرض مسموح به هو 1.
  أي ارتفاع أو عرض مطلوب أقل من 1 سيُقلَّص إلى 1.
- يعتمد الحد الأقصى للارتفاع والعرض على الموضع الحالي للنافذة؛ فلا يمكن لحواف النافذة أن تتجاوز حواف الشاشة.
  القيم الأكبر من هذه الحدود ستُقلَّص إلى أكبر حجم يمكن أن تتخذه.
  على سبيل المثال، إذا كان موضع النافذة عند `x` = 400، `y` = 300 وطُلب تغيير الحجم إلى `height` = 400، `width` = 300، فسيُغيَّر حجم النافذة إلى `height` = 300، `width` = 300 لأن الشاشة ليست كبيرة بما يكفي في اتجاه `y` لاستيعاب الطلب بالكامل.

## 5. أضف طريقة لتحريك النوافذ

- `move(to:)` : `(Position) -> ()` - هذه الطريقة مشابهة لـ `resize(to:)`، لكنها تضبط _موضع_ النافذة إلى القيمة المطلوبة بدلًا من الحجم. وكما في `resize`، لا يمكن للموضع الجديد أن يتجاوز حدودًا معينة.
- أصغر موضع هو 0 لكل من `x` و`y`.
- يعتمد الموضع الأقصى في أي من الاتجاهين على الحجم الحالي للنافذة؛ فلا يمكن للحواف أن تتجاوز حواف الشاشة.
       القيم الأكبر من هذه الحدود ستُقلَّص إلى أكبر حجم يمكن أن تتخذه. على سبيل المثال، إذا كان حجم النافذة عند `x` = 250، `y` = 100 وطُلب الانتقال إلى `x` = 600، `y` = 200، فستُحرَّك النافذة إلى `x` = 550، `y` = 200 لأن الشاشة ليست كبيرة بما يكفي في اتجاه `x` لاستيعاب الطلب بالكامل.

## 6. أضف طرقًا لتحديث نص النافذة وعرض معلومات النافذة

- `update(title:)` : `(String) -> ()` - تضبط هذه الطريقة خاصية `title` على قيمة السلسلة النصية التي مُرِّرت.
- `update(text:)` : `(String?) -> ()` - تضبط هذه الطريقة خاصية `contents` على قيمة السلسلة النصية الاختيارية التي مُرِّرت.
- `display()` : `() -> String` - تُرجع هذه الطريقة سلسلة نصية تصف الحالة الحالية للنافذة. على سبيل المثال، إذا كانت النافذة تحمل العنوان `title` بالقيمة "My First Window" مع الموضع: x = 10، y = 100؛ والحجم: width = 200، height = 150؛ والمحتويات: "I 😍 my window"، فينبغي أن تُرجع السلسلة النصية: `"My First Window\nPosition: (10, 100), Size: (200 x 150)\nI 😍 my window\n"` - إذا كانت `contents` تساوي nil، فينبغي أن يكون السطر الأخير "[This window intentionally left blank]"

## 7. أنشئ مُهيّئًا لصنف Window

ينبغي أن يكون لنظام النوافذ مُهيّئ بحيث يمكن إنشاء النافذة بمدخلات مخصصة.
أنشئ مُهيّئًا **آخر** لصنف `Window`.
ينبغي أن يأخذ المُهيّئ المعاملات التالية: `title` و`contents`، ومعاملين اختياريين هما `size` و`position`.
ينبغي أن تكون القيمة الافتراضية لـ `size` و`position` هي القيم الافتراضية لبنيتَي `Size` و`Position`.

```swift
let window = Window(title: "My First Window", contents: "I 😍 my window")
window.display()
// Returns "My First Window\nPosition: (0, 0), Size: (80 x 60)\nI 😍 my window\n"

let window2 = Window(title: "My Second Window", contents: "I 😍 my window", size: Size(width: 200, height: 150), position: Position(x: 10, y: 100))
window2.display()
// Returns "My Second Window\nPosition: (10, 100), Size: (200 x 150)\nI 😍 my window\n"
```
