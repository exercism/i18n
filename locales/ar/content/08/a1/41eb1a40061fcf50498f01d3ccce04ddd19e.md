# مقدمة

يتيح لك التحكم في مسار التنفيذ في Cairo توجيه مسار برامجك بناءً على الشروط والتكرار.

## التنفيذ الشرطي

استخدم تعبيرات `if` لتنفيذ الكود بناءً على شروط:

```rust
let number = 42;
if number > 0 {
    println!("Positive number");
} else if number < 0 {
    println!("Negative number");  
} else {
    println!("Zero");
}
```

`if` تعبير، لذا يمكنه أن يُرجع قيمًا:

```rust
let result = if condition { 5 } else { 10 };
```

## الحلقات

استخدم `loop` لتكرار الكود.
تعمل الحلقة بلا توقف ما لم توقفها بنفسك؛ استخدم `break` للخروج من الحلقة عند تحقق شرط معيّن.

```rust
let mut counter = 0;
loop {
    if counter == 5 {
        break;
    }
    println!("Counter: {}", counter);
    counter += 1;
}
```

يمكن للحلقات أن تُرجع قيمًا باستخدام `break`:

```rust
let result = loop {
    counter += 1;
    if counter == 10 {
        break counter * 2; // Returns 20
    }
};
```

استخدم `continue` لتجاوز ما تبقّى والانتقال إلى التكرار التالي:

```rust
let mut i = 0;
loop {
    i += 1;
    if i % 2 == 0 {
        continue; // Skip even numbers
    }
    if i > 10 {
        break;
    }
    println!("{}", i); // Only prints odd numbers
}
```
