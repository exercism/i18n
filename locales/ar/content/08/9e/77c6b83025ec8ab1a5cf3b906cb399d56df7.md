# حول الأساسيات

قدّم مفهوم الأساسيات لغة [Go](https://golang.org) كلغة برمجة ذات أنواع ثابتة ومصرّفة.
غالبًا ما يُشار إلى اللغة باسم Golang بسبب اسم النطاق السابق لها، golang.org، غير أن الاسم الصحيح هو Go.

يقدّم مفهوم الأساسيات ثلاث سمات رئيسية في اللغة: الحزم والدوال والمتغيرات.

## الحزم

تُنظَّم تطبيقات Go في حزم.
الحزمة مجموعة من الملفات المصدرية الموجودة في الدليل نفسه.
ويجب أن تشترك جميع الملفات المصدرية في الدليل في اسم الحزمة نفسه.
ومن المعتاد أن يكون اسم الحزمة هو الدليل الأخير في مسار الاستيراد.
على سبيل المثال، تبدأ الملفات في [حزمة "math/rand"](https://golang.org/src/math/rand/) بالعبارة `package rand`.
وعند استيراد حزمة ما، لا يمكن استخدام أو الوصول إلا إلى الكيانات (الدوال والأنواع والمتغيرات والثوابت) التي تبدأ أسماؤها بحرف كبير.
وأسلوب التسمية الموصى به في Go هو تسمية المعرّفات باستخدام `camelCase`، باستثناء تلك التي يُقصد أن تكون متاحة عبر الحزم، إذ ينبغي أن تكون بصيغة `PascalCase`.

```go
package lasagna
```

## المتغيرات

Go لغة ذات أنواع ثابتة، وهذا يعني أن جميع المتغيرات [يجب أن يكون لها نوع محدّد](https://en.wikipedia.org/wiki/Type_system) وقت التصريف.

يمكن تعريف المتغيرات بتحديد نوعها صراحةً:

```go
var explicit int // Explicitly typed
```

ويمكنك أيضًا استخدام قيمة ابتدائية، وسيُسنِد المصرّف إلى المتغير نوعًا يطابق نوع القيمة الابتدائية.

```go
implicit := 10   // Implicitly typed as an int
```

وبعد الإعلان عن المتغير، يمكن إسناد قيم إليه باستخدام العامل `=`.
وبعد الإعلان عن المتغير، لا يمكن أن يتغيّر نوعه أبدًا.

```go
count := 1 // Assign initial value
count = 2  // Update to new value

count = false // This throws a compiler error due to assigning a non `int` type
```

## الثوابت

تحمل الثوابت قطعة من البيانات تمامًا كما تفعل المتغيرات، لكن قيمتها لا يمكن أن تتغيّر أثناء تنفيذ البرنامج.

وتُعرَّف الثوابت باستخدام الكلمة المفتاحية `const`، ويمكن أن تكون أعدادًا أو محارف أو سلاسل نصية أو قيمًا منطقية:

```go
const Age = 21 // Defines a numeric constant 'Age' with the value of 21
```

## الدوال

تقبل دوال Go صفرًا أو أكثر من المعاملات.
ويجب تحديد أنواع المعاملات صراحةً، فلا يوجد استنتاج للأنواع.

وتُرجَع القيم من الدوال باستخدام الكلمة المفتاحية `return`.

وتُستدعى الدالة بتحديد اسمها وتمرير وسائط لكل معامل من معاملاتها.

لاحظ أن Go تدعم نوعين من التعليقات.
تسبق التعليقات أحادية السطر علامة `//`، أما التعليقات متعددة الأسطر فتُكتب بين `/*` و `*/`.

```go
package greeting

// Hello is a public function.
func Hello (name string) string {
    return hi(name)
}

// hi is a private function.
func hi (name string) string {
    return "hi " + name
}
```
