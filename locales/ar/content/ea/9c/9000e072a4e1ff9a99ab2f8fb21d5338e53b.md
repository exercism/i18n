# مقدمة

في Python، [التعداد](https://docs.python.org/3/library/enum.html) هو مجموعة من الأسماء المرتبطة بقيم `literal` أو `constant` فريدة. ويُعرَّف التعداد بوراثة صنف `Enum`. تتوفر أنواع التعداد المضمّنة في الوحدة `enum`، ويمكن استيراد الصنف `Enum` باستخدام `from enum import Enum`.

```python
class Color(Enum):
    RED = 1
    GREEN = 2
```

لاحظ أن قيم أعضاء التعداد يمكن أن تكون أي نوع من أنواع البيانات مثل `str` و`tuple` و`float` وغيرها.

```python
class Color(Enum):
    RED = 'red'
    GREEN = 'green'
```

عند إسناد القيمة نفسها لعضوين في التعداد، يصبح العضو المُسنَد لاحقًا اسمًا مستعارًا للعضو المُشكَّل أولًا. ولا يُسمح باستخدام الاسم نفسه لعضوين في التعداد.

```python
class Color(Enum):
    RED = 1
    GREEN = 2
    ALIAS_OF_RED = 1

Color.ALIAS_OF_RED
#=> <Color.RED: 1>

Color.ALIAS_OF_RED.value
#=> 1
```

يمكن المرور على أعضاء التعداد باستخدام الصيغة القياسية `for member in`:

```python
for member in Color:
    print((member.name, member.value))
#=> (RED, 1)
#=> (GREEN, 2)
```

يمكن مقارنة أعضاء التعداد باستخدام [`is` (_عامل الهوية_)](https://www.w3schools.com/python/ref_keyword_is.asp) أو `is not`. وتعمل `==` أو `!=` (_عوامل المساواة_) بالمثل.

```python
a = Color.RED

a is Color.RED
#=> True

a == Color.RED
#=> True
```

للوصول إلى عضو في التعداد مقابل قيمة معيّنة، يمكن استخدام `EnumName(value)`:

```python
g = Color(2)

g is Color.GREEN
#=> True

g
#=> <Color.GREEN: 2>
```
