# مقدمة

## الجمل الشرطية

الجمل الشرطية هي جمل لاتخاذ القرار يمكنها إما تنفيذ آثار جانبية وإما التحكم في مسار تنفيذ البرنامج.
تشمل الجمل الشرطية جمل `if` و`if/else` و`switch` و`ternary`.

تُستخدم الجمل الشرطية لطرح أسئلة حول قيمة أو علاقة بين قيم.
يُقيَّم السؤال إلى إجابة منطقية، لكن جملة `if` نفسها يمكنها إرجاع أي قيمة أو ببساطة تنفيذ أثر جانبي.

## جمل `if`

أبسط جملة `if` تُقيِّم تعبيرًا وتنفّذ سطرًا واحدًا.
التعبير الذي يجري اختباره يُضمَّن دائمًا بين الأقواس الهلالية.

يمكنها تنفيذ أثر جانبي

```c
if (count > 10)
    printf("count is greater than 10");
```

أو يمكنها تغيير مسار التنفيذ


```c
if (count > 10)
    return sum;
```

إذا نفّذت جملة `if` أكثر من سطر واحد فيجب وضع الأسطر بين الأقواس المعقوفة

```c
if (count > 10) {
    printf("count is greater than 10");
    return sum;
}
```

قد توحّد بعض فرق البرمجة أن جمل `if` يجب أن تستخدم الأقواس المعقوفة دائمًا، حتى لسطر واحد.


## `if` و`else`

يمكن ربط جملة `if` بـ`else`

```c
if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## `if` و`else if`


يمكن ربط `else` بـ`if` أخرى لإنشاء ما يسمى `if-else-if ladder`.

```c
if (number == 0)
    return "zero";
else if (number < 0)
    return "negative";
else if (number < 10)
    return "single digit";   
else if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## `switch`


أحيانًا يمكن تمثيل `if-else-if ladder` بشكل أفضل باستخدام `switch`.
وكما في `if`، يوضَع التعبير الذي يجري اختباره دائمًا بين الأقواس الهلالية.

```c
switch (number) {
    case -1:
        return "negative one";
    case 0:
        return "zero";
    case 1:
        return "positive one";
    case 10:
        return "positive ten";
    case -10:
        return "negative ten";
    default:
        return "don't care";
}
```

تُنفَّذ حالة `default` إذا لم تطابق القيمة التي يجري اختبارها أيًّا من الحالات السابقة.

إذا لم تكن حالة `switch` تُرجع قيمة، فيُدرَج `break` عادةً لإنهاء كل حالة، وإلا فإن المنطق "يتساقط" إلى الحالة التالية.
وأحيانًا يُستخدم التساقط عن قصد

```c
switch (number) {
    case 0:
        msg = "zero"; break;
    case 1:
        msg = "one"; break;
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

عندما يحدث التساقط دون قصد فهو Bug.

```c
switch (number) {
    case 0:
        msg = "zero"; // bug! fallthrough of 0 will set msg to "one"
    case 1:
        msg = "one"; break; 
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

قد تكون جملة `switch` مفيدة عند الاختبار مقابل قيم محددة بدلًا من نطاق من القيم.
وقد تكون أسرع من `if-else-if ladder` لأن المترجم قد يتمكن من تحسين جملة `switch` بطرق لا يستطيعها مع السلّم.
وأحيانًا قد تبدو جملة `switch` أكثر قابلية للقراءة من السلّم.

## المعامل الثلاثي (المعروف أيضًا بالمعامل الشرطي)

المعامل الثلاثي هو جملة شرطية من ثلاثة أجزاء تُستخدم غالبًا لإسناد قيمة.
يوضَع التعبير الذي يجري اختباره قبل علامة الاستفهام ولا يلزم وضعه بين الأقواس الهلالية.
القيمة المُرجَعة إذا كان الشرط صحيحًا تقع قبل النقطتين الرأسيتين، والقيمة المُرجَعة إذا كان خطأً تقع بعدهما.
ويمكن إرجاع قيمة حرفية أو متغير.

```c
int i = j > 5 ? 5: j;
```

يمكن تداخل المعاملات الثلاثية لتقليل الفوضى النحوية.

```c
// the below could also be 
i = j > 5 ? j :k > 5 ? k: 10;
// but that may not be quite as readable

i = j > 5 ? j
    :k > 5 ? k
    :10;

// which is the same as
if (j > 5) i = j;
else if (k > 5) i = k;
else i = 10;
```
