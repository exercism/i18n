# مقدمة

[Go](https://golang.org) لغة برمجة ثابتة الأنواع ومُصرَّفة.
يقدّم هذا التمرين ثلاث ميزات رئيسية في اللغة: الحزم، والدوال، والمتغيرات.

## الحزم

تُنظَّم تطبيقات Go في حزم.
والحزمة مجموعة من الملفات المصدرية الموجودة في المجلد نفسه.
ويجب أن تشترك كل الملفات المصدرية في المجلد في اسم الحزمة نفسه.
وعند استيراد حزمة، لا يمكن استخدام أو الوصول إلا إلى الكيانات (الدوال والأنواع والمتغيرات والثوابت) التي تبدأ أسماؤها بحرف كبير.
والأسلوب الموصى به للتسمية في Go هو تسمية المُعرِّفات باستخدام `camelCase`، باستثناء تلك التي يُقصد بها أن تكون متاحة عبر الحزم المختلفة، فهذه ينبغي أن تكون `PascalCase`.

```go
package lasagna
```

## المتغيرات

لغة Go ثابتة الأنواع، وهذا يعني أن كل المتغيرات [يجب أن يكون لها نوع محدَّد](https://en.wikipedia.org/wiki/Type_system) وقت التصريف.

يمكن تعريف المتغيرات بتحديد النوع صراحةً:

```go
var explicit int // Explicitly typed
```

يمكنك أيضًا استخدام مُهيِّئ، وسيُسنِد المُصرِّف نوع المتغير ليطابق نوع المُهيِّئ.

```go
implicit := 10   // Implicitly typed as an int
```

بعد الإعلان عن المتغيرات، يمكن إسناد قيم إليها باستخدام العامل `=`.
وبعد الإعلان عن المتغير، لا يمكن أن يتغير نوعه أبدًا.

```go
count := 1 // Assign initial value
count = 2  // Update to new value

count = false // This throws a compiler error due to assigning a non `int` type
```

## الثوابت

تحمل الثوابت قطعة من البيانات تمامًا كالمتغيرات، لكن قيمتها لا يمكن أن تتغير أثناء تنفيذ البرنامج.

تُعرَّف الثوابت باستخدام الكلمة المفتاحية `const`، ويمكن أن تكون أعدادًا أو محارف أو سلاسل نصية أو قيمًا منطقية:

```go
const Age = 21 // Defines a numeric constant 'Age' with the value of 21
```

## الدوال

تقبل دوال Go صفرًا أو أكثر من المعاملات.
ويجب تحديد نوع المعاملات صراحةً، فلا يوجد استنتاج للنوع.

وتُرجع الدوال القيم باستخدام الكلمة المفتاحية `return`.

ويُستدعى الدالة بتحديد اسم الدالة وتمرير وسائط لكل معامل من معاملات الدالة.

لاحظ أن Go تدعم نوعين من التعليقات.
تسبق التعليقات أحادية السطر ب`//`، أما التعليقات متعددة الأسطر فتوضع بين `/*` و `*/`.

```go
package greeting

// Hello is a public function.
func Hello (name string) string {
    return hi(name)
}

// hi is a private function.
func hi (name string) string {
    return "hi " + name
}
```
