# ملحق التعليمات

## بنية المشروع

تدعم تمارين Clojure في Exercism أداتين من أكثر الأدوات شيوعًا لإدارة التبعيات والاختبار، [leiningen][leiningen] و[واجهة سطر الأوامر الخاصة بـ Clojure][clojure-cli].

ستجد ملف اختبار باسم `hello_world_test.clj` داخل مجلد `test`.
اكتب الكود في `src/hello_world.clj`. وينبغي أن يستخدم فضاء الأسماء `hello-world` حتى تتمكن الاختبارات من العثور عليه.

### تشغيل الاختبارات باستخدام واجهة سطر الأوامر الخاصة بـ Clojure

```
$ clj -X:test
```

### تشغيل الاختبارات باستخدام Leiningen

```
$ lein test

lein test hello-world-test

Ran 3 tests containing 3 assertions.
0 failures, 0 errors.
```

ثم أرسل التمرين باستخدام:

```
$ exercism submit src/hello_world.clj
```

لمزيد من التعليمات التفصيلية ومصادر التعلّم، راجع [صفحة لغة Clojure على Exercism][exercism-clojure].

[leiningen]: https://leiningen.org
[clojure-cli]: https://clojure.org/guides/deps_and_cli
[exercism-clojure]: https://exercism.org/tracks/clojure
