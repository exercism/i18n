# أنواع البيانات العامة

تتيح لك الأنواع العامة في Cairo كتابة كود قابل لإعادة الاستخدام يعمل مع أنواع مختلفة، فتتجنب التكرار وتعزّز قابلية الصيانة.

يمكنك استخدام الأنواع العامة مع الدوال والبنى والتعدادات والسمات والطرق.

## الدوال العامة

تعمل الدالة العامة على أنواع مختلفة دون الحاجة إلى تطبيقات منفصلة.

على سبيل المثال:

```rust
fn largest_list<T>(l1: Array<T>, l2: Array<T>) -> Array<T> {
    if l1.len() > l2.len() {
        l1
    } else {
        l2
    }
}
```

هنا، `T` عنصر نائب لأي نوع.

غير أن Cairo تشترط قيود السمات لضمان أن النوع العام يلبّي متطلبات محددة.

إذا احتجنا إلى أن يكون `T` قابلًا للإسقاط، يمكننا تحديث التوقيع:

```rust
fn largest_list<T, impl TDrop: Drop<T>>(l1: Array<T>, l2: Array<T>) -> Array<T> {
    if l1.len() > l2.len() {
        l1
    } else {
        l2
    }
}
```

تضيف قيود السمات، مثل `Drop` أو `PartialOrd`، قيودًا على الأنواع العامة من أجل عمليات محددة.

## القيود المجهولة

إذا لم يُستخدم تنفيذ سمة مباشرةً داخل دالة، يمكنك كتابة قيود مجهولة باستخدام `+`:

```rust
fn smallest_element<T, +PartialOrd<T>, +Drop<T>, +Copy<T>>(list: @Array<T>) -> T {
    let mut smallest = *list[0];
    let mut index = 1;

    while index < list.len() {
        if *list[index] < smallest {
            smallest = *list[index];
        }
        index += 1;
    };

    smallest
}
```

يتجنب هذا تسمية السمات مثل `TPartialOrd`، ما يقلل من الإطالة.

## البنى مع الأنواع العامة

تتيح الأنواع العامة في البنى أن تكون الحقول مرنة.

على سبيل المثال:

```rust
#[derive(Drop)]
struct Wallet<T> {
    balance: T,
}

let w = Wallet { balance: 42 };
```

إذا احتاجت البنية إلى عدة أنواع عامة، أضف المزيد من العناصر النائبة:

```rust
#[derive(Drop)]
struct Wallet<T, U> {
    balance: T,
    address: U,
}

let w = Wallet { balance: 42, address: '0xabc' };
```

## التعدادات مع الأنواع العامة

يمكن للتعدادات أن تحمل أنواع بيانات عامة أيضًا.

على سبيل المثال:

```rust
enum Option<T> {
    Some: T,
    None,
}
```

يستطيع التعداد `Option<T>` تمثيل قيمة اختيارية من أي نوع.

وبالمثل، يسمح `Result<T, E>` بتعريف نوعَي النجاح والفشل:

```rust
enum Result<T, E> {
    Ok: T,
    Err: E,
}
```

## الطرق العامة

يمكن للطرق أيضًا استخدام الأنواع العامة.

على سبيل المثال:

```rust
#[derive(Copy, Drop)]
struct Wallet<T> {
    balance: T,
}

trait WalletTrait<T> {
    fn balance(self: @Wallet<T>) -> T;
}

impl WalletImpl<T, +Copy<T>> of WalletTrait<T> {
    fn balance(self: @Wallet<T>) -> T {
        *self.balance
    }
}

let w = Wallet { balance: 50 };
assert!(w.balance() == 50);
```

يمكنك أيضًا تعريف طرق لأنواع عامة محددة، مثل `Wallet<u128>`:

```rust
trait WalletReceiveTrait {
    fn receive(ref self: Wallet<u128>, value: u128);
}

impl WalletReceiveImpl of WalletReceiveTrait {
    fn receive(ref self: Wallet<u128>, value: u128) {
        self.balance += value;
    }
}

let mut w = Wallet { balance: 50 };
w.receive(100);
assert!(w.balance() == 150);
```

## مزج الأنواع العامة

تستطيع الأنواع العامة التعامل مع تركيبات معقدة.

على سبيل المثال، دمج نسختين من `Wallet` من نوعين مختلفين:

```rust
trait WalletMixTrait<T1, U1> {
    fn mixup<T2, +Drop<T2>, U2, +Drop<U2>>(
        self: Wallet<T1, U1>, other: Wallet<T2, U2>,
    ) -> Wallet<T1, U2>;
}

impl WalletMixImpl<T1, +Drop<T1>, U1, +Drop<U1>> of WalletMixTrait<T1, U1> {
    fn mixup<T2, +Drop<T2>, U2, +Drop<U2>>(
        self: Wallet<T1, U1>, other: Wallet<T2, U2>,
    ) -> Wallet<T1, U2> {
        Wallet { balance: self.balance, address: other.address }
    }
}

let w1 = Wallet { balance: true, address: 10 };
let w2 = Wallet { balance: 32, address: 100 };
let w3 = w1.mixup(w2);

assert!(w3.balance);
assert!(w3.address == 100);
```

بإضافة قيود `+Drop`، يضمن المصرّف التعامل السليم مع الموارد.

الأنواع العامة قوية لكنها تتطلب إدارة حذرة للقيود.

استخدمها لكتابة كود قابل لإعادة الاستخدام، ومستقل عن الأنواع، وموجز.
