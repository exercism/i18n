# مقدمة

## الثوابت

يمكن تطبيق المُعدِّل `const` (ويُستحسن عمومًا ذلك) على أي حقل تكون قيمته معروفة وقت الترجمة ولن تتغير خلال عمر البرنامج.

```csharp
private const int num = 1729;
public const string title = "Grand" + " Master";
```

يمكن تطبيق المُعدِّل `readonly` (ويُستحسن عمومًا ذلك) على أي حقل لا يمكن جعله `const`، حيث لن تتغير قيمته خلال عمر البرنامج، ويُضبط إما بواسطة مهيّئ مضمّن أو أثناء الإنشاء (بواسطة المنشئ أو طريقة يستدعيها المنشئ).

```csharp
private readonly int num;
private readonly System.Random rand = new System.Random();

public MyClass(int num)
{
    this.num = num;
}
```

## النسخ الدفاعي

في المواقف الحساسة أمنيًا (أو حتى ببساطة في قاعدة كود كبيرة حيث يكون للمطورين أولويات وأجندات مختلفة)، ينبغي أن تتجنب السماح بالتحايل على واجهة API العامة لأي صنف عبر قبول وتخزين معاملات قابلة للتغيير لإحدى الطرق، أو عبر كشف عضو قابل للتغيير في صنف من خلال قيمة مُرجعة أو كمعامل `out`.

## المجموعات للقراءة فقط

بينما يمنع المُعدِّل `readonly` الكتابة فوق القيمة أو المرجع في حقل ما، فإنه لا يوفر أي حماية لأعضاء نوع مرجعي.

```csharp
readonly List<int> ints = new List<int>();

void Foo()
{
    ints.Add(1);    // ok
    ints = new List<int>(); // fails to compile
}
```

لضمان حماية جميع أعضاء نوع مرجعي، يمكن جعل الحقول `readonly`، ويمكن تعريف خصائص تلقائية بدون مُوصِّل `set`.

توفر مكتبة الصنف الأساسية (BCL) بعض الإصدارات للقراءة فقط من المجموعات عندما تكون هناك حاجة إلى منع تحديث أعضاء المجموعة. وتأتي هذه في شكل أغلفة:

- يتيح `ReadOnlyDictionary<T>` استخدام `Dictionary<T>` للقراءة فقط.
- يتيح `ReadOnlyCollection<T>` استخدام `List<T>` للقراءة فقط.
