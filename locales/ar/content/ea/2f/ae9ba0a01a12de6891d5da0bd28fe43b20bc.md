# التعليمات

في هذا التمرين ستكتب الكود لطباعة شارات الأسماء لعاملي المصنع.

## 1. اطبع شارة لموظف

لدى الموظفين معرّف واسم واسم قسم. تُنسّق نصوص شارات الموظفين على النحو التالي: `"[id] - name - DEPARTMENT"`.
نفّذ طريقة `Badge.print()` لتُرجع نص شارة الموظف:

```java
Badge badge = new Badge();
badge.print(734, "Ernest Johnny Payne", "Strategic Communication");
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

لاحظ أن القسم يجب أن يكون بأحرف كبيرة في نص الشارة.

## 2. اطبع شارة لموظف جديد

بسبب خلل في نظام الحاسوب، في بعض الأحيان لا يكون لدى الموظفين الجدد معرّف بعد عند بدء العمل في المصنع.
ولأن الشارات مطلوبة، سيحصلون على شارة مؤقتة بدون بادئة المعرّف. عدّل طريقة `Badge.print()` لدعم الموظفين الجدد الذين ليس لديهم معرّف بعد:

```java
Badge badge = new Badge();
Badge.print(null, "Jane Johnson", "Procurement");
// => "Jane Johnson - PROCUREMENT"
```

## 3. اطبع شارة للمالك

حتى مالك المصنع يجب أن يرتدي شارة في جميع الأوقات.
ومع ذلك، ليس للمالك قسم. في هذه الحالة، يجب أن يطبع نص الشارة `"OWNER"` بدلًا من اسم القسم.
عدّل طريقة `Badge.print()` لطباعة نص شارة للمالك:

```java
Badge badge = new Badge();
badge.print(254, "Charlotte Hale", null);
// => "[254] - Charlotte Hale - OWNER"
```

لاحظ أنه من الممكن أن يكون المالك أيضًا موظفًا جديدًا:

```java
Badge badge = new Badge();
badge.print(null, "Charlotte Hale", null);
// => "Charlotte Hale - OWNER"
```
