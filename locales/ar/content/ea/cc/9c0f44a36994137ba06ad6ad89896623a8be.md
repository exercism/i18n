# التعليمات

وظّفتك للتو شركة Mecha Munch™، وهي شركة لأتمتة التسوق في البقالة، للعمل على تطبيق الطلبات الخاص بها.
فريقك مكلّف ببناء MVP (_[منتج أدنى قابل للتطبيق][mvp]_) يدير كل أنشطة عربة التسوق الأساسية، ويتيح للمستخدمين إضافة طلبات البقالة وإزالتها وترتيبها.
لحسن الحظ، هناك فريق آخر يتولى كل وظائف الأموال والدفع!

## 1. أضف صنفًا أو أصنافًا إلى عربة تسوق المستخدم

ينبغي أن يتيح المنتج الأدنى القابل للتطبيق للمستخدم إضافة أصناف إلى عربة تسوقه.
قد يكون هذا صنفًا واحدًا أو عدة أصناف دفعة واحدة.
وبما أن هذا منتج أدنى قابل للتطبيق، فإن كمية الصنف تُشار إليها بـ_التكرار_.
إذا أراد المستخدم إضافة برتقالتين، فستظهر 'Oranges' مرتين في المدخل القابل للتكرار.
وإذا كان الصنف موجودًا بالفعل في عربة المستخدم، فينبغي زيادة كميته فيها بمقدار 1.
أما إذا كان الصنف _جديدًا_ على العربة، فيُضاف بكمية مقدارها 1.

أنشئ الدالة `add_items!(<cart>, <items>)` التي تأخذ قاموس العربة وكائنًا قابلًا للتكرار من الأصناف المطلوب إضافتها كوسائط.
ينبغي أن تُرجع قاموس عربة التسوق المُحدَّث للمستخدم.

```julia-repl
julia> additems!(Dict("Banana" => 3, "Apple" => 2, "Orange" => 1),
                 ("Apple", "Apple", "Orange", "Apple", "Banana"))
Dict{String, Int64} with 3 entries:
  "Apple"  => 5
  "Orange" => 2
  "Banana" => 4

julia> additems!(Dict("Banana" => 3, "Apple" => 2, "Orange" => 1),
                 ["Banana", "Orange", "Blueberries", "Banana"])
Dict{String, Int64} with 4 entries:
  "Blueberries" => 1
  "Apple"       => 2
  "Orange"      => 2
  "Banana"      => 5
```

## 2. حدّث قسم "الأفكار" للوصفات

يحتوي التطبيق على قسم "الأفكار" مملوء بوصفات جاهزة من مطابخ متنوعة.
ويمكن للمستخدم اختيار أي وصفة من هذه الوصفات وإضافة جميع مكوناتها إلى عربة تسوقه تلقائيًا.
وقد طلب منك مدير المشروع إيجاد أسلوب لتحرير وصفات "الأفكار" هذه، لأن فريق المحتوى يغيّر المكونات والكميات باستمرار.

أنشئ الدالة `update_recipes!(<ideas>, <updates>)` التي تأخذ قاموس "الأفكار" وقاموسًا بتحديثات الوصفات كوسائط.

## 3. أرسل عربة تسوق المستخدم إلى المتجر لتجهيز الطلب

يحتاج التطبيق إلى إرسال عربة مستخدم معيّن إلى المتجر لتجهيز الطلب.
غير أن المتسوقين في المتجر بحاجة إلى معرفة مكان وجود الصنف عبر رمز مميّز للممر.
ولهذا يجب ترتيب "عربة التجهيز" وفقًا لرموز ممرات الأصناف، لمساعدة المتسوقين على العمل بكفاءة أكبر.

أنشئ الدالة `send_to_store(<cart>, <aislecodes>)` التي تأخذ عربة تسوق المستخدم وقاموسًا يحتوي على أرقام ممرات المتجر.
ينبغي أن تُرجع الدالة "عربة تجهيز" مدمجة تحتوي على زوج `aislecode => quantity` لكل صنف يطلبه العميل.
وينبغي أن تظهر الأصناف بترتيب رموز ممراتها.

```julia-repl
julia> cart = Dict("Orange" => 1, "Milk" => 2, "Banana" => 3, "Apple" => 2, "Chocolate" => 2);

julia> aislecodes = Dict("Orange" => 2.4, "Milk" => 3.3, "Banana" => 2.6, "Apple" => 2.2, "Chocolate" => 5.7);

julia> send_to_store(cart, aislecodes)
5-element Vector{Pair{Float64, Int64}}:
 2.2 => 2
 2.4 => 1
 2.6 => 3
 3.3 => 2
 5.7 => 2
```

## 4. حدّث مخزون المتجر ليعكس ما طلبه المستخدم.

لا يستطيع التطبيق أن يرسل طلبات العملاء بلا نهاية.
ففي النهاية ستنفد منتجات متنوعة من المتجر.
لذلك يحتاج منتجك الأدنى القابل للتطبيق إلى تحديث مخزون المتجر في كل مرة يرسل فيها المستخدم طلبه إلى المتجر.
وإلا سيطلب العملاء منتجات غير متاحة فعلًا.

أنشئ الدالة `update_store_inventory!(<inventory>, <cart>)` التي تأخذ `cart` و`inventory`.
ينبغي أن تُنقص الدالة كميات مخزون المتجر بمقدار العدد "المطلوب" في `cart`، ثم تُرجع قاموسًا بالأصناف التي نفد مخزونها (أي التي وصلت إلى `0`).

```julia-repl
julia> inventory = Dict("Banana" => 15, "Apple" => 12, "Orange" => 1, "Milk" => 4);

julia> cart = Dict("Orange" => 1, "Milk" => 2, "Banana" => 3, "Apple" => 2);

julia> update_store_inventory!(inventory, cart)
Dict{String, Int64} with 1 entry:
  "Orange" => 0

julia> inventory
Dict{String, Int64} with 4 entries:
  "Milk"   => 2
  "Apple"  => 10
  "Orange" => 0
  "Banana" => 12
```

## 5. أعد طلب الأصناف التي نفد مخزونها.

إضافة إلى تحديث المخزون، يمكن لتطبيقك المساعدة في إعادة تخزينه.
ينبغي أن يكون منتجك الأدنى قابلًا لتحضير طلب مصغّر بأي أصناف نفد مخزونها بعد طلب العميل.
سيساعد ذلك في تبسيط إطلاق طلب كبير.
علاوة على ذلك، توجد أحيانًا أصناف ترويجية لفترة محدودة غير مدرجة في قائمة المخزون.
وإذا نفدت هذه الأصناف قبل انتهاء فترة الترويج، فهذا دليل على شعبيتها، ويمكن إضافتها إلى قائمة المخزون.

أنشئ الدالة `reorder!(<outofstock>, <stock>)` التي تأخذ `outofstock` و`stock`.
يحتوي قاموس `stock` على أصناف المخزون القياسية وكميات إعادة طلبها.
وقاموس `outofstock` هو ناتج `update_store_inventory!`، أي قاموس بالأصناف التي كميتها صفر.
ينبغي تحديث كميات `outofstock` لتطابق تلك الموجودة في `stock` ثم إرجاعها.
كذلك، ينبغي إضافة أي أصناف في `outofstock` غير موجودة في `stock` إلى `stock` بكمية افتراضية مقدارها `100`.

```julia-repl
julia> inventory = Dict("Banana" => 15, "Apple" => 12, "Orange" => 1, "Milk" => 4, "Chocolate" => 2);

julia> cart = Dict("Orange" => 1, "Milk" => 2, "Banana" => 3, "Apple" => 2, "Chocolate" => 2);

julia> stock = Dict("Banana" => 150, "Apple" => 120, "Orange" => 120, "Milk" => 45);

julia> outofstock = update_store_inventory!(inventory, cart)
Dict{String, Int64} with 1 entry:
  "Orange"    => 0
  "Chocolate" => 0

julia> reorder!(outofstock, stock)
Dict{String, Int64} with 1 entry:
  "Orange"    => 120
  "Chocolate" => 100

julia> stock 
Dict{String, Int64} with 5 entries:
  "Milk"      => 45
  "Apple"     => 120
  "Chocolate" => 100
  "Orange"    => 120
  "Banana"    => 150
```
