# Exercism API

## الوصف

تستخدم معظم مسارات Exercism اللغوية أداة سطر الأوامر `exercism` لجلب التمارين وإرسالها، وهي تتفاعل مع `exercism.io` عبر REST API. أما مسار لغة Pharo Smalltalk فيستخدم REST API نفسها لجلب التمارين وإخراجها من صورة Pharo دون استخدام أي أدوات وسيطة. يوضّح هذا المستند واجهة Exercism API مع التركيز على طريقة استخدام مسار لغة Pharo Smalltalk لها، وهو موجّه إلى القائمين على صيانة أدوات Pharo Smalltalk.

## الترويسات

تتطلب جميع نقاط النهاية ضبط ترويسات الطلب على القيم التالية:

```
Authorization: Bearer <token>
```

القيمة `<token>` هي رمز مصادقة واجهة سطر الأوامر الخاص بالمستخدم، وهو متاح على `https://exercism.io/my/settings`.

## جلب التمارين

```
Content-Type: application/json
```

`GET api.exercism.io/v1/solutions/latest?exercise_id=<slug>&track_id<language> HTTP/1.1`

في الرابط أعلاه، `<slug>` هو اسم التمرين، مثل `hello-world`، و`<language>` هو مسار اللغة، مثل `pharo-smalltalk`.

### الاستجابة

#### 200

يرسل الطلب الناجح استجابةً تحتوي على حمولة JSON. وتتضمن حمولة JSON معلومات عن التمرين ورابطًا يمكن تنزيل ملفات التمرين منه.

```json
"solution":{
	"id":"<id-string>",
	"url":"https://exercism.io/my/solutions/<id-string>",
	"team":null,
	"user":{
		"handle":"<exercism-user-name>",
		"is_requester":true
		},
		"exercise":{
			"id":"isogram",
			"instructions_url":"https://exercism.io/my/solutions/<id-string>",
			"auto_approve":false,
			"track":{
				"id":"pharo-smalltalk",
				"language":"Pharo"
				}
			},
			"file_download_base_url":"https://api.exercism.io/v1/solutions/<id-string>/files/",
			"files":[
				"IsogramTest.class.st",
				"README.md"
				],
			"iteration":null
		}
	}
```

#### 400

اسم مسار اللغة غامض، أو أن ملفات التمارين المُرسلة لم تتغير.

#### 403

الحل غير مفتوح للمستخدم، أو أن مسار اللغة غير منضم.

#### 404

تعذّر العثور على مسار اللغة أو التمرين.

## إرسال التمارين

```
Content-Type: application/octet-stream
```

`PATCH api.exercism.io//v1/solutions/<some-kind-of-token-or-hash> HTTP/1.1`

### الاستجابة

#### 201

إرسال ناجح.

#### 400

أحد الملفات المُرسلة كبير جدًا (أكبر من ميغابايت واحد)، أو أن الحل مكرر.

#### 403

الحل غير متاح للمستخدم. معرّف المستخدم الخاص بالحل ومعرّف المستخدم الحالي غير متطابقين.

#### 404

لم يتم العثور على معرّف الحل.
