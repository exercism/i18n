# المقدمة

يتكوّن نظام الأخطاء في Factor من ثلاثة أجزاء: الكلمة `throw` (في [`kernel`][kernel]) ترفع خطأً، والكلمة `recover` (في [`continuations`][continuations]) تلتقطه، والكلمة `ERROR:` تعرّف صنف أخطاء من نوع الصفّ.

```factor
! "file not found" throw          (raises a string as the error)

[ "boom" throw ] [ drop "caught" ] recover .
! => "caught"
```

الكلمة `recover ( try recovery -- )` تشغّل اقتباس *try*؛ فإن رفع خطأً، يُدفع الخطأ ويُشغَّل اقتباس *recovery*.

الكلمة `ERROR:` تعرّف الصنف *و*كلمة إنشاء ترفع نسخة جديدة:

```factor
! DOCTEST: SKIP
ERROR: not-found path ;

"/missing" not-found
! throws T{ not-found { path "/missing" } }
```

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
[continuations]: https://docs.factorcode.org/content/vocab-continuations.html
