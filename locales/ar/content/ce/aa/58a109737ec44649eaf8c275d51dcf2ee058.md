# عن الدوال عالية الرتبة

الدوال في Kotlin عناصر من الدرجة الأولى.
وهذا يعني أنه يمكن تخزينها في متغيرات، وتمريرها كوسائط، بل وإرجاعها من دوال أخرى.
مثلًا، إسناد دالة إلى المتغير `addOne`:

```kotlin
val addOne = fun (num : Int) : Int {
    return num + 1
}
```

يمكن للدالة أيضًا أن تُرجع دالة أخرى:

```kotlin
fun makeAddOne() : (Int) -> Int {
    return fun(num : Int) : Int {
        return num + 1
    }
}
```

بعد الإسناد، يمكن استدعاء الدالة عبر المتغير كما لو كانت دالة عادية:
```kotlin
addOne(3)
// => 4
```

## الإعلان عن أنواع الدوال

يمكن الإعلان عن نوع متغير أو معامل باستخدام الصيغة `(parameter types) -> return type`.
مثلًا، الإعلان عن متغير:

```kotlin
val addOne : (Int) -> Int = fun (num : Int) : Int {
    return num + 1
}
```

ولمعامل دالة:

```kotlin
fun perform(operation : (Int) -> Int) {
    operation(3)
}
```

## تعبيرات لامبدا

تعبير لامبدا أسلوب أقصر لتعريف دالة.
وتُكتب على الشكل `{ parameters -> body }`.
ويُرجع التعبير آخر قيمة من آخر عبارة في الجسم.
مثلًا:

```kotlin
// Assigning to a variable
val addOne = { num : Int -> num +  1}

// In a function call
perform({ num : Int -> num + 1 })
```

يمكن لـ Kotlin استنتاج الأنواع عندما تتوفر معلومات كافية.
على سبيل المثال، يمكن كتابة الأمثلة السابقة أيضًا على النحو التالي:

```kotlin
// Assigning to a variable
val addOne : (Int) -> Int = { num -> num + 1 }

// Or ...
val addOne  = { num : Int -> num + 1 }

// Using in a function
perform({ num -> num + 1 })
```

## `it` للامبدا ذات المعامل الواحد

عندما يكون للتعبير معامل واحد فقط، يمكن حذف المعامل.
وعندئذٍ يصبح معامل يُسمى `it` متاحًا في الجسم.
مثلًا:

```kotlin
val addOne : (Int) -> Int = { it +  1 }
```

## تمرير اللامبدا اللاحقة

عندما يكون الوسيط الأخير في دالة تعبير لامبدا، يُكتب تعبير اللامبدا مباشرةً _بعد_ الأقواس الهلالية.
مثلًا:

```kotlin
// Function that takes a function as last argument
fun calculateFrom(from : Int, operation : (Int) -> Int) : Int {
    return operation(from)
}

// Call the calculateFrom function
calculateFrom(2) { it * 3 }
// => 6
```
