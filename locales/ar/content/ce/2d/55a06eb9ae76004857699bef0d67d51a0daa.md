# استخدام الحُرّاس

[comment]: # (يُرفع هذا الخطأ عندما لا يستخدم الحل الحُرّاس إطلاقًا)

استخدم [الحُرّاس](https://hexdocs.pm/elixir/master/guards.html) لمنع `two_fer/1` من تنفيذ الكود بمدخلات غير ثنائية.

> تذكّر أن [السلاسل النصية](https://elixir-lang.org/getting-started/binaries-strings-and-char-lists.html) تُعتبر [بيانات ثنائية](https://elixir-lang.org/getting-started/binaries-strings-and-char-lists.html) في Elixir.

```elixir
# Consider this function with a guard:
def hello(what) when is_binary(what) do
  "Hello, #{what}!"
end
```

> يمكن اختبار هذا الحارس في `iex`

```shell
iex> hello("world")
"Hello, world!"
iex> hello(123)
** (FunctionClauseError) no function clause matching in hello/1

    The following arguments were given to hello/1:

        # 1
        123
```
