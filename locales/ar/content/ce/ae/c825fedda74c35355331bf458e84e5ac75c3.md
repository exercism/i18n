# مقدمة

التلاعب بالمكدس مقبول مع الكلمات القصيرة. لكن عندما تكون لكلمة عدة
مدخلات وتحتاج إلى الإشارة إليها بأسمائها، توفّر لك Factor
*locals*، وهي ارتباطات مُسمّاة تُعرَّف بـ `::` (لتعريفات الكلمات)
أو `[| | ]` (للامبدا المضمّنة)، وكلاهما من [`locals`][locals].

```factor
USING: locals ;

:: hypotenuse ( a b -- c )
    a a *
    b b *
    + sqrt ;
```

داخل الاقتباس، يكون `[| inputs | body ]` دالة لامبدا بمدخلات
مُسمّاة:

```factor
USING: assocs locals ;

H{ { "a" 1 } { "b" 2 } }
[| key value | key value 10 * ] assoc-map .
! => H{ { "a" 10 } { "b" 20 } }
```

[locals]: https://docs.factorcode.org/content/vocab-locals.html
