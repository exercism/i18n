# الوصف

ثلاثية فيثاغورس هي مجموعة من ثلاثة أعداد طبيعية، {a, b, c}، بحيث

```text
a² + b² = c²
```

و

```text
a < b < c
```

على سبيل المثال،

```text
3² + 4² = 5².
```

إذا أُعطينا عددًا صحيحًا N كمدخل، فأوجد جميع ثلاثيات فيثاغورس التي يحقق فيها `a + b + c = N`.

على سبيل المثال، عندما N = 1000، توجد ثلاثية فيثاغورس واحدة فقط يحقق فيها `a + b + c = 1000`: `{200, 375, 425}`.
