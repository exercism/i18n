# مقدمة

`String` في Haxe هو كائن يمثّل نصًّا غير قابل للتغيير على هيئة تسلسل من محارف يونيكود (حروف، وأرقام، وعلامات ترقيم، وغيرها). تُستخدم علامات الاقتباس المزدوجة لتعريف نسخة من `String`:

```haxe
var fruit:String = "Apple";
```

تتم معالجة السلاسل النصية عن طريق استدعاء طرقها. وبمجرد إنشاء سلسلة نصية، لا يمكن أن تتغيّر قيمتها أبدًا. وأي طرق تبدو وكأنها تعدّل السلسلة النصية ستُرجع في الواقع سلسلة نصية جديدة.

يمكن دمج عدة سلاسل نصية (جمعها) معًا. وأبسط أسلوب لتحقيق ذلك هو استخدام العامل `+`.

```haxe
var name:String = "Jane";
trace("Hello " + name + "!");
// => "Hello Jane!"
```

لأي تنسيق لسلسلة نصية أكثر تعقيدًا من الدمج البسيط، يُفضّل استخدام الإدراج داخل السلسلة النصية. ولاستخدام الإدراج داخل سلسلة نصية، ضعها بين علامتي اقتباس مفردتين (`'`). ثم يمكنك استخدام علامة الدولار (`$`) لتفعيل الإدراج داخل السلسلة النصية:

```haxe
var name:String = "Jane";
trace('Hello $name!');
// => "Hello Jane!"
```
