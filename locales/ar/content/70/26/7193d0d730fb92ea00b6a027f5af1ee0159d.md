# مقدمة

سنشير إلى _اللغة_ باسم **AWK** وإلى _البرنامج التنفيذي_ الذي يفسّر برامج AWK باسم **`awk`** أو **`gawk`**.

## الأنماط والإجراءات

يتكوّن برنامج AWK من **أزواج النمط والإجراء**

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

يمكن أن يكون **النمط** نمط تعبير نمطي للمطابقة مع المدخلات.
ويمكن أن يكون أيضًا أي تعبير ينتج عنه قيمة صحيح/خطأ.

**الإجراء** هو أمر AWK واحد أو أكثر.
والأقواس المعقوفة المحيطة به مطلوبة.

إذا كانت نتيجة النمط _صحيحة_، فسيُقيَّم الإجراء المقابل.

## السجلات والحقول

يحلّل AWK المدخلات إلى تسلسل من **السجلات**.
ويُقسَّم كل سجل إلى صفر أو أكثر من **الحقول**.

السلوك الافتراضي هو:

- تقسيم المدخلات إلى سجلات باستخدام محرف السطر الجديد "فاصل السجلات"، بحيث يصبح كل _سطر_ سجلًا.
- تقسيم السجل إلى حقول باستخدام المسافات البيضاء "فاصل الحقول"، بحيث تصبح كل _كلمة_ حقلًا.

## الأنماط والإجراءات (تابع)

يمكن حذف النمط، وفي هذه الحالة يُقيَّم الإجراء _لكل سجل من سجلات المدخلات_.

ويمكن حذف الإجراء، وفي هذه الحالة يكون الإجراء الافتراضي هو طباعة السجل الحالي.

### أنماط خاصة

هناك نمطان خاصان يُستخدمان كثيرًا.

- سيقيّم `BEGIN` الإجراء المرتبط به قبل استهلاك أي مدخلات.
- سيقيّم `END` الإجراء المرتبط به بعد استهلاك كل المدخلات.

## متغيرات الحقول

تشير إلى الحقول بالصيغة `$1` و`$2` و`$3` وهكذا.

والسجل الحالي هو `$0`.

وإليك بعض المتغيرات المدمجة الأخرى كثيرة الاستخدام.

### متغيرات مدمجة تتحكم في تحليل المدخلات

- `RS` هو فاصل سجلات المدخلات.
  وكما ذُكر، فإن قيمته الافتراضية محرف سطر جديد.
- `FS` هو فاصل حقول المدخلات.

غالبًا ما تُضبط هذه المتغيرات في كتلة إجراء `BEGIN`.

### متغيرات مدمجة تحمل معلومات

تضبط AWK هذه المتغيرات تلقائيًا أثناء تنفيذ البرنامج.

- يخزّن `NF` عدد الحقول في السجل الحالي.
  - للحصول على قيمة الحقل الأخير، استخدم `$NF`.
- يخزّن `NR` رقم السجل الحالي.
  - عند معالجة ملفات إدخال متعددة، سيحتفظ `NR` بالعدد الإجمالي للسجلات المعالَجة حتى الآن.
- يخزّن `FNR` رقم السجل الحالي في ملف الإدخال الحالي.
  - لتوضيح الفرق بين NR وFNR، إليك تعبيرًا اصطلاحيًا شائعًا في AWK.
    ```awk
    NR == FNR {action}
    ```
    ويعني هذا "إذا كان رقم السجل المتراكم يساوي رقم السجل في الملف الحالي".
    ولا يمكن أن يكون هذا صحيحًا إلا بالنسبة لسجلات في _ملف الإدخال الأول_.

## ما يُعتبر صحيحًا

يستخدم AWK المفهوم نفسه الذي تستخدمه لغة C لتحديد ما يُعتبر صحيحًا.

- العدد `0` خطأ.
- أي عدد آخر صحيح.

وبما أن AWK لغة لمعالجة النصوص، فإن قيم الصحة تمتد لتشمل السلاسل النصية.

- السلسلة النصية الفارغة `""` خطأ.
- أي سلسلة نصية غير فارغة صحيحة.

## التعليقات

تبدأ التعليقات بالمحرف `#` وتمتد إلى نهاية السطر.

## أمثلة

في الأنظمة الشبيهة بـUnix، يحتوي الملف `/etc/passwd` على معلومات عن المستخدمين.
ويُوصف كل مستخدم في سطر منفصل، مع فصل الحقول بنقطتين رأسيتين.

لسرد أسماء المستخدمين:

```sh
awk '
    BEGIN { FS = ":" }
    { print $1 }
' /etc/passwd
```

لاحظ أن الإجراء `{print $1}` ليس له نمط، لذا يُنفَّذ لكل سجل.

وإذا أردنا حصر المخرجات على المستخدمين الذين يستخدمون bash كصدفة تسجيل دخولهم فقط، يمكننا فعل ما يلي:

```sh
awk '
    BEGIN { FS = ":" }
    $7 == "/bin/bash" { print $1 }
' /etc/passwd
```
