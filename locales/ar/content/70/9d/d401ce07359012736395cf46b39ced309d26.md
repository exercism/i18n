# ملحق التعليمات

## السجلات

| السجل | الاستخدام | النوع | الوصف |
| -------- | --------- | ------- | -------------------------- |
| `$a0`    | إدخال     | عنوان | مصفوفة أوزان العناصر      |
| `$a1`    | إدخال     | عنوان | مصفوفة قيم العناصر       |
| `$a2`    | إدخال     | عدد صحيح | عدد العناصر            |
| `$a3`    | إدخال     | عدد صحيح | الوزن الأقصى             |
| `$v0`    | إخراج     | عدد صحيح | القيمة القصوى              |
| `$t0-9`  | مؤقت | أي     | تُستخدم للتخزين المؤقت |
