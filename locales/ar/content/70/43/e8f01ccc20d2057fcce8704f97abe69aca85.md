# الاختبارات

تتحقق معظم الاختبارات من أنك تُرجع القيمة المتوقعة عبر الإسناد إلى [result] أو تمرير قيمة إلى [exit].

وتتحقق بعض الاختبارات من أنك [raise] الاستثناء المتوقع.

## تشغيل الاختبارات

أداة `make` متطلب ضروري لتشغيل الاختبارات.

من داخل مجلد التمرين، اكتب في وحدة التحكم/الطرفية:

```sh
make
```

إذا لم تلمس ملف حل التمرين إطلاقًا، فسترى رسالة مثل:

```
Please implement your solution.
```

لذا، احذف هذا السطر قبل أن تبدأ في كتابة حلك.

افتراضيًا، يُنفَّذ الاختبار الأول فقط.

```text
TAP version 14
1..10
ok 1 - ...
```

لتشغيل جميع الاختبارات، اكتب:

```sh
make test=all
```

```text
TAP version 14
1..10
ok 1 - empty_sentence
ok 2 - perfect_lower_case
ok 3 - only_lower_case
ok 4 - missing_the_letter_x
ok 5 - missing_the_letter_h
ok 6 - with_underscores
ok 7 - with_numbers
ok 8 - missing_letters_replaced_by_numbers
ok 9 - mixed_case_and_punctuation
ok 10 - am_and_AM_are_26_different_characters_but_not_a_pangram
```

بمجرد نجاح جميع الاختبارات، تكون قد انتهيت من التمرين ويمكنك إرسال الحل.

يمكنك اختيار اختبار واحد لتشغيله عبر تمرير الرقم المقابل، على سبيل المثال:

```sh
make test=2
```

فسيُنفَّذ الاختبار الثاني فقط.
