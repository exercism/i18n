# مقدمة

C# لغة ذات أنواع ثابتة، ما يعني أن لكل شيء نوعًا في وقت الترجمة. يُشار إلى إسناد قيمة إلى اسم بتعريف متغير. ويمكن تعريف المتغير إما بتحديد نوعه صراحةً، وإما بترك مترجم C# يستنتج نوعه بناءً على القيمة المُسندة (وهذا ما يُعرف بـ_استنتاج النوع_). لذلك، فإن تعريفي المتغير التاليين متكافئان:

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

يتم تحديث قيمة المتغير من خلال العامل `=`. وبمجرد تعريفه، لا يمكن أن يتغير نوع المتغير أبدًا.

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

C# [لغة كائنية التوجه][object-oriented-programming] وتشترط تعريف جميع الدوال داخل _صنف_. وتُستخدم الكلمة المفتاحية `class` لتعريف صنف. أما الكائنات (أو _النسخ_) فتُنشأ باستخدام الكلمة المفتاحية `new`.

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

يُشار إلى دالة داخل صنف بـ_طريقة_. ويمكن أن تحتوي كل طريقة على صفر أو أكثر من المعاملات. ويجب تحديد نوع جميع المعاملات صراحةً، فلا يوجد استنتاج للنوع في المعاملات. وبالمثل، يجب أيضًا تحديد نوع الإرجاع صراحةً. وتُرجع الطرق القيم باستخدام الكلمة المفتاحية `return`. وللسماح باستدعاء طريقة من كود في ملفات أخرى، يجب إضافة محدّد الوصول `public`.

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

تُستدعى الطرق باستخدام صيغة النقطة (`.`) على نسخة، مع تحديد اسم الطريقة المراد استدعاؤها وتمرير الوسائط لكل معامل من معاملات الطريقة. ويمكن للوسائط اختياريًا تحديد اسم المعامل المقابل.

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

يُعرَّف النطاق في C# بين المحرفين `{` و `}`.

تدعم C# نوعين من التعليقات. تسبق التعليقات أحادية السطر علامة `//`، أما التعليقات متعددة الأسطر فتُدرج بين `/*` و `*/`.
