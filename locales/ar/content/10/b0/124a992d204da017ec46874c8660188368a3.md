# مقدمة

في Go، السلاسل النصية غير قابلة للتعديل.
ربط السلاسل النصية باستخدام `+` داخل حلقة يؤدي إلى عمليات تخصيص متكررة وإلى نسخ البيانات عدة مرات.
توفر [حزمة `strings`](https://pkg.go.dev/strings) النوع [`Builder`](https://pkg.go.dev/strings#Builder) لتقليل استهلاك الذاكرة عبر تجميع السلاسل النصية بكفاءة.

## بناء السلاسل النصية

القيمة الصفرية لـ `strings.Builder` جاهزة للاستخدام فورًا دون أي تهيئة أو تخصيص صريح.
يمكنك دفع بيانات جديدة إلى المُجمِّع باستخدام طرق كتابة مخصصة.
تُرجع كل طريقة كتابة قيمة خطأ لتتوافق مع واجهات Go القياسية، لكنها مضمونة بأن تكون دائمًا `nil`، ويُتجاهلها عادةً في الكود اليومي.

أكثر الطرق استخدامًا هي:

- `WriteString(s string) (int, error)`: تُلحق سلسلة نصية بالمخزن المؤقت.
- `WriteRune(r rune) (int, error)`: تُلحق ترميز UTF-8 الخاص بـ `rune`.
- `WriteByte(c byte) error`: تُلحق بايتًا واحدًا.

```go
var sb strings.Builder

sb.WriteString("Hello")
var r rune = ' '
sb.WriteRune(r)
var b byte = '.'
sb.WriteByte(b)
```

## الاستخراج وإعادة الضبط

بعد أن تنتهي من تجميع نصك، يمكنك استخراج المحتوى المتراكم على هيئة سلسلة نصية قياسية في Go عبر استدعاء الطريقة `String()`.
استدعاء `String()` عملية رخيصة جدًا لأنها تُرجع شريحة البايتات الأساسية على هيئة سلسلة نصية مباشرة دون نسخ البيانات المتراكمة.

وإذا احتجت إلى إعادة استخدام نسخة المُجمِّع نفسها لتجميع سلسلة نصية جديدة (مثلًا داخل حلقة)، فيمكنك استدعاء الطريقة `Reset()`.
تُفرغ هذه الطريقة المخزن المؤقت الداخلي، ما يتيح لك البدء من جديد وبناء السلسلة النصية التالية مع الحفاظ على سعة الذاكرة المخصصة مسبقًا في الخلفية.

```go
var sb strings.Builder

sb.WriteString("Task One")
fmt.Println(sb.String()) // Output: Task One

// Clear the buffer for resource reuse
sb.Reset()

sb.WriteString("Task Two")
fmt.Println(sb.String()) // Output: Task Two
```
