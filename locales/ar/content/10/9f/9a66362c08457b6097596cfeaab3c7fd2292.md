# مقدمة

الدوال العودية هي دوال تستدعي نفسها.

تحتاج الدالة العودية إلى _حالة أساسية_ واحدة على الأقل وإلى _حالة عودية_ واحدة على الأقل.

تُرجع _الحالة الأساسية_ قيمة دون استدعاء الدالة مرة أخرى.
أما _الحالة العودية_ فتستدعي الدالة مرة أخرى، مع تعديل المدخلات بحيث تتطابق في مرحلة ما مع الحالة الأساسية.

في Elm، تُعرَّف الدوال العودية عادةً باستخدام مطابقة الأنماط مع تعبيرات `case` أو عدة فروع للدالة.

```elm
count : List a -> Int
count list =
    case list of
        [] ->
            0  -- base case

        _ :: tail ->
            1 + count tail  -- recursive case
```

## الحلقات من خلال العودية

بسبب عدم قابلية التغيير، تُكتب الحلقات في Elm بطريقة مختلفة عن اللغات الأمرية.
على سبيل المثال، تبدو الحلقات عادةً هكذا:

```c
for(i = 0; i < array.length; i++) {
  // do something with array[i]
}
```

في لغة دالية مثل Elm، لا يمكن تغيير قيم المتغيرات.
لذلك، يجب تنفيذ الحلقات باستخدام العودية.

يبدو مكافئ حلقة `for` في Elm هكذا:

```elm
loop : List a -> (a -> b) -> List b
loop list f =
    case list of
        [] ->
            []

        head :: tail ->
            f head :: loop tail f
```

عمليًا، غالبًا ما يتم المرور على المصفوفات وهياكل البيانات الأخرى في Elm باستخدام دوال من وحدة `List`، مثل `List.map` و`List.filter` و`List.foldl`.
وتحت الغطاء، تُنفَّذ هذه الدوال باستخدام العودية.
