# التعليمات

في هذا التمرين ستكتب كودًا لإدارة قاموس لأكواد الاتصال الدولية باستخدام `Map`.

يتيح القاموس البحث عن اسم بلد ما (قيمة الخريطة، بوصفها `String`) من خلال كود الاتصال الدولي (مفتاح الخريطة، بوصفه `Integer`)،

## 1. أرجِع الأكواد في خريطة

نفّذ الطريقة `getCodes` التي لا تأخذ أي معاملات وتُرجع خريطة تربط أكواد الاتصال بالبلدان الموجودة حاليًا في القاموس.

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.getCodes();
// => empty map 
```

## 2. أضِف مدخلات إلى القاموس

يجب تعبئة القاموس.
نفّذ الطريقة `setDialingCode` التي تأخذ كود اتصال والبلد المقابل له وتضيف كود الاتصال والبلد.
إذا كان كود الاتصال موجودًا بالفعل في الخريطة، فحدّث الخريطة بالكود والبلد المقدمين.

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.setDialingCode(679, "Unknown");
// => { 679 => "Unknown" }

dialingCodes.setDialingCode(679, "Fiji");
// => { 679 => "Fiji" }
```

## 3. ابحث عن بلد كود الاتصال

نفّذ الطريقة `getCountry` التي تأخذ كود اتصال وتُرجع اسم البلد المرتبط بكود الاتصال.

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.setDialingCode(55, "Brazil");
dialingCodes.getCountry(55);
// => "Brazil"
```

## 4. لا تسمح بالتكرار

عند إضافة كود اتصال، يجب الحرص على منع إضافة كود أو بلد مرتين.
في الحالات التي يحدث فيها ذلك، يمكن افتراض أن المدخل الأول هو المدخل الصحيح.
نفّذ الطريقة `addNewDialingCode` التي تضيف مدخلًا لكود الاتصال والبلد المحددين.
وعلى عكس الطريقة `setDialingCode`، لا تفعل شيئًا إذا كان كود الاتصال أو البلد موجودًا بالفعل في الخريطة.

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.addNewDialingCode(32, "Belgium");
dialingCodes.addNewDialingCode(379, "Vatican City");
// => { 32 => "Belgium", 379 => "Vatican City" }


dialingCodes.addNewDialingCode(32, "Other");
dialingCodes.addNewDialingCode(39, "Vatican City");
// => { 32 => "Belgium", 379 => "Vatican City" }
```

## 5. اعثر على كود اتصال البلد

هذا نادر، لكن الأخطاء تحدث.
لتصحيح الخطأ، سنحتاج إلى معرفة كود الاتصال الذي يرتبط به البلد حاليًا.
للعثور على كود الاتصال الذي يحتاج إلى تصحيح، نفّذ الطريقة `findDialingCode` التي تأخذ بلدًا وتُرجع كود اتصال البلد.
أرجِع `null` إذا كان البلد _غير موجود_ في الخريطة.

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.addDialingCode(44, "UK");
dialingCodes.findDialingCode("UK");
// => 44

dialingCodes.findDialingCode("Unlisted");
// => null
```

## 6. حدّث كود اتصال البلد

الآن بعد أن عرفنا كود الاتصال الذي يحتاج إلى تصحيح، لننتقل إلى تحديث الكود.
نفّذ الطريقة `updateCountryDialingCode` التي تأخذ كود الاتصال الجديد للبلد واسم البلد وتُجري التحديث وفقًا لذلك.
لا تفعل شيئًا إذا كان البلد _غير موجود_ في الخريطة (فهذه الطريقة غرضها الوحيد المساعدة في تصحيح الأخطاء).

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.addDialingCode(88, "Japan");
// => { 88 => "Japan" }

dialingCodes.updateCountryDialingCode(81, "Japan");
// => { 81 => "Japan" }

dialingCodes.updateCountryDialingCode(32, "Mars");
// => { 81 => "Japan"}
```
