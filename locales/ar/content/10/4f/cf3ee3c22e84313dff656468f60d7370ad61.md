# Case

[Case][case] (يُشار إليه غالبًا باسم `switch` في لغات أخرى) هو أحد أشكال تعبيرات التحكم مثل `if-else`. تتيح جملة `case` ربط عدة عبارات `if-else-if` معًا، ويمكن أن تكون أكثر وضوحًا في القراءة مع أنها توفّر التحكم في مسار التنفيذ.

تُعرَّف جملة `case` بالكلمة المفتاحية `case` متبوعةً بتعبير اختياري. ثم تُستخدم الكلمة المفتاحية `when` لكل حالة، متبوعةً بتعبير يُقارَن بتعبير `case`. ولا ينبغي إزاحة الكلمة المفتاحية `when` عن الكلمة المفتاحية `case`. وبعد الكلمة المفتاحية `when` يأتي الكود الذي يجب تنفيذه إذا طابق تعبير `case` تعبير `when`. وتتيح جملة `case` عبارة `else` اختيارية تُنفَّذ إذا لم تطابق أي حالة أخرى.

يُقيَّم تعبير `case` ثم يُقارَن بكل تعبير `when`. وتُجرى المقارنة باستخدام عامل تساوي `case` (`===`).

```ruby
value = 1
case value
when 1
  "One"
when 2
  "Two"
else
  "Other"
end

# This is the same as:
value = 1
if 1 === value
  "One"
elsif 2 === value
  "Two"
else
  "Other"
end
```

## عامل تساوي `case` (`===`)

يختلف عامل تساوي `case` (`===`) قليلًا عن عامل المساواة (`==`). يتحقق هذا العامل مما إذا كان الطرف الأيمن عضوًا في المجموعة التي يصفها الطرف الأيسر. وهذا يعني أن موضع كل طرف مهم. وتتوقف كيفية عمل ذلك على نوع الطرف الأيسر، فمثلًا يتحقق `Range` مما إذا كان الطرف الأيمن ضمن المدى، ويتحقق `Object` مما إذا كان الطرف الأيمن نسخةً من `Object`.

```ruby
(1..3) == 1  # => false
(1..3) === 1 # => true

String == "foo"  # => false
String === "foo" # => true
```

## `case` مع تعبيرات متعددة

تتيح جملة `case` مطابقة عدة تعبيرات في حالة واحدة، مع فصل كل قيمة ممكنة بفاصلة. وسيُنفَّذ الكود إذا طابق أي من التعبيرات. وقد يكون ذلك مفيدًا عندما تريد أن تكون لحالة واحدة عدة قيم ممكنة.

```ruby
case var
when 1, 2
  "One or two"
else
  "Other"
end
```

## `case` مع المدى

يمكن لجملة `case` أيضًا التحقق مما إذا كانت قيمة ما ضمن مدى. ويتم ذلك بوضع مدى كتعبير `when`.

```ruby
case var
when 1..3
  puts "One to three"
else
  puts "Other"
end
```

## `case` بدون تعبير

عندما لا تكون هناك حاجة إلى تعبير `case`، يمكن حذفه. سيؤدي ذلك إلى تقييم كل تعبير `when` من حيث كونه صحيحًا أو خطأً، فتصبح جملة `case` أشبه بعبارات `if-else-if`.

```ruby
case
when 1 == 1
  "One is equal to one"
when 1 > 2
  "One is greater than two"
else
  "Other"
end
```

## `when` في سطر واحد

تتيح Ruby كتابة جمل `case` في سطر واحد. ويمكن استخدام ذلك عندما تكون لديك عبارة بسيطة في سطر واحد. وتُكتب عبارة `when` في سطر واحد بالصيغة `when <expression> then <statement>`. وعند استخدامها في عبارة `else` تُكتب بالصيغة `else <statement>`.

```ruby
case var
when 1 then "One"
when 2 then "Two"
else "Other"
end
```

## `case` مع الأنواع

تتيح جملة `case` المطابقة مع الأنواع. وهذا مفيد عندما تريد سلوكًا مختلفًا حسب نوع المتغير.

```ruby
case var
when Integer
  "Integer"
when String
  "String"
else
  "Other"
end
```
