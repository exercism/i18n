# نبذة

يمكن تشغيل Gleam على الآلة الافتراضية Erlang ‏(BEAM)، أو على بيئات تشغيل JavaScript. وهناك لغات أخرى كثيرة تستخدم بيئات التشغيل هذه، وغالبًا ما يكون من المفيد أن تستطيع استدعاء كود مكتوب بهذه اللغات من داخل Gleam.

تتيح ميزة _الدوال الخارجية_ في Gleam استيراد دوال من لغات أخرى إلى Gleam واستدعاءها دون أي عبء إضافي في وقت التشغيل.

إذا كان مشروع Gleam لديك يعمل على الآلة الافتراضية Erlang وأردت استدعاء الدالة `reverse` من وحدة `lists` في Erlang، فيمكنك فعل ذلك بإضافة السمة `@external` إلى ترويسة دالة Gleam على النحو التالي:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

ويمكن بعد ذلك استدعاؤها كدالة Gleam عادية:

```gleam
let reversed = reverse_list([1, 2, 3])
// -> [3, 2, 1]
```

إذا حاولت ترجمة هذا الكود لبيئات تشغيل JavaScript فسيفشل مع رسالة خطأ لأنه لا يوجد تنفيذ لـ JavaScript. ويمكن تحديد تنفيذ آخر لبيئات تشغيل JavaScript على النحو التالي:

```gleam
@external(erlang, "lists", "reverse")
@external(javascript, "./my_module.mjs", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

ومن الممكن أيضًا كتابة تنفيذ بـ Gleam يُستخدم عندما لا يوجد تنفيذ خارجي لهدف الترجمة الحالي:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a) {
  tail_recursive_reverse(x, [])
}

fn tail_recursive_reverse(list, reversed) {
  case list {
    [] -> reversed
    [x, ..xs] -> tail_recursive_reverse(xs, [x, ..reversed])
  }
}
```
