# التكرار

في البرمجة، يشير [التكرار][iteration] إلى عملية إعادة تنفيذ كتلة من الكود عدة مرات.
ويمكن تحقيق ذلك باستخدام مفاهيم مثل حلقات `while` وحلقات `until`.
ويمكن أيضًا تحقيقه باستخدام العودية، وهي دالة تستدعي نفسها.

لكن في أغلب الأحيان تريد التكرار عبر مجموعة من العناصر، مثل `Array` أو `Range` أو `String`.
الصنفان `Array` و`Range` في Crystal يشملان وحدة [`Enumerable`][enumerable]، التي توفّر عددًا من الطرق للتكرار عبر العناصر.
وفي المقابل، يمتلك صنف `String` مجموعته الخاصة من الطرق للتكرار عبر الأحرف.

كذلك لا تمتلك Crystal أي جملة `for` مثل اللغات الأخرى.
وبدلًا من ذلك، لديها عدة طرق يمكن استخدامها للتكرار.

## كيف نكرّر

أكثر أسلوب شيوعًا للتكرار عبر مجموعة هو استخدام طريقة [`each`][each]، التي تمرّر كل عنصر في المجموعة إلى كتلة.
ويمكن فعل ذلك بسهولة باستخدام `Range`.
لنفترض أنك تريد التكرار بين 1 و3، يمكنك استخدام طريقة `each` للتكرار عبر هذا `Range`.

```crystal
(1..3).each do |n|
  puts n
end

# Output:
# 1
# 2
# 3
```

وبشكل أبسط، إذا أردت فقط التكرار عددًا من المرات، يمكنك استخدام طريقة [`times`][times] الموجودة في صنف `Int`.

```crystal
3.times do |n|
  puts n
end

# Output:
# 0
# 1
# 2
```

## التكرار عبر `String`

`String` هي تسلسل من الأحرف ولا تنتمي إلى وحدة `Enumerable`، ما يعني أن لها مجموعتها الخاصة من الطرق للتكرار عبر الأحرف.
أكثر أسلوب شيوعًا للتكرار عبر `String` هو استخدام طريقة [`each_char`][each_char]، التي تمرّر كل حرف في `String` إلى كتلة.

~~~~exercism/note
تمرّر طريقة `each_char` كائن `Char` وليس كائن `String` إلى الكتلة.
~~~~

```crystal
str = "hello"
str.each_char { |char| puts char }

# Output:
# h
# e
# l
# l
# o
```

وهناك أسلوب آخر للتكرار عبر `String` وهو استخدام طريقة [`each_line`][each_line].
وتُستخدم هذه الطريقة غالبًا عند قراءة ملف سطرًا بسطر.

```crystal
str = "hello\nworld"
str.each_line do |line|
  puts line
end

# Output:
# hello
# world
```

## التكرار عبر كائن يشمل وحدة `Enumerable`

توفّر وحدة [`Enumerable`][enumerable] عددًا من الطرق للتكرار عبر عناصر مجموعة.
والمجموعات التي تشمل وحدة `Enumerable` هي `Array` و`Range` و`Hash` و`Set` وغيرها، وسيُغطّى ما تبقّى منها في المفاهيم اللاحقة.

أكثر أسلوب شيوعًا للتكرار عبر `Array` هو استخدام طريقة [`each`][each]، التي تمرّر كل عنصر في `Array` إلى كتلة.

```crystal
arr = [5, 2, 3]
arr.each do |element|
  puts element
end

# Output:
# 5
# 2
# 3
```

### `map`

طريقة [`map`][map] هي أسلوب آخر للتكرار عبر `Array`، وهي تُرجع `Array` جديدة تحتوي على نتائج تطبيق الكتلة على كل عنصر.
وهي مشابهة لطريقة `each`، لكنها تُرجع `Array` جديدة بالعناصر المتحوّلة.
التحويل مفيد جدًا عندما تريد تطبيق دالة على كل عنصر من عناصر المجموعة، وهي عملية شائعة.

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  element * 2
end

new_arr
# => [2, 4, 6]
```

وباستخدام بنية تحكم مثل `if` يمكنك أيضًا تصفية العناصر التي تريد تحويلها.

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  if element.odd?
    element * 2
  else
    element
  end
end

new_arr
# => [2, 2, 6]
```

## الصيغة المختصرة

في Crystal، توجد صيغة مختصرة للتكرار وتطبيق طريقة على كل عنصر من عناصر المجموعة.
وهذه مفيدة عند التعامل مع منطق بسيط لا يحتاج إلا إلى تحويله بطريقة واحدة.
ويتم ذلك باستخدام صيغة `&.` متبوعة باسم الطريقة.

```crystal
arr = [1, 2, 3]
arr.map(&.to_s)
# => ["1", "2", "3"]
```

### مع الفهرس

أحيانًا تحتاج إلى معرفة فهرس العنصر الذي تكرّر عليه، ويمكنك استخدام طريقة [`each_with_index`][each_with_index] أو [`map_with_index`][map_with_index] لذلك.
فهي تمرّر كل عنصر وفهرسه إلى كتلة، كما تقبل الطريقة وسيطًا اختياريًا لتحديد فهرس البداية.

```crystal
arr = [1, 2, 3]
arr.each_with_index(4) do |element, index|
  puts "Element: #{element}, Index: #{index}"
end

# Output:
# Element: 1, Index: 4
# Element: 2, Index: 5
# Element: 3, Index: 6
```

لاحظ أن طريقة [`each_char_with_index`][each_char_with_index] متاحة أيضًا لكائنات `String`.

### `sum`

تُرجع طريقة [`sum`][sum] مجموع كل عناصر المجموعة، كما تقبل كتلة اختيارية لتحويل العناصر قبل جمعها.
وتقبل أيضًا وسيطًا اختياريًا لتحديد القيمة الأولية للمجموع.

```crystal
arr = [1, 2, 3]
arr.sum
# => 6

arr.sum(2) { |n| n * 2 }
# => 14
```

### `reduce`

‏`reduce`، أو `fold` كما تُعرف في لغات أخرى، هي طريقة تأخذ دالة دمج وقيمة أولية، فتُدمج جميع عناصر المجموعة.
ولطريقة `reduce` مراكم يُمرَّر إلى الكتلة، والمراكم هو نتيجة التكرار السابق.
وهكذا تصبح عملية عودية تُدمج جميع عناصر المجموعة.

```crystal
arr = [1, 2, 3]
arr.reduce(0) do |acc, n|
  acc + n
end
# => 6
```

قد تبدو `reduce` مشابهة لـ `sum`، لكن `reduce` أكثر مرونة لأنها تتيح لك تحديد القيمة الأولية للمراكم ودالة الدمج.
ويمكن استخدام `reduce` لتنفيذ `sum` و`count` وطرق أخرى.
