# مقدمة

الخاصية في Haxe هي عضو في صنف يوفّر الوصول إلى البيانات داخل ذلك الصنف. ويستطيع المستدعون ضبط هذه البيانات أو استرجاعها. وتتكوّن الخاصية من دالة وصول للضبط و/أو دالة وصول للاسترجاع.

للخصائص معدّلات وصول (`public`، `private` وغيرها) بالطريقة نفسها المتبعة مع أعضاء الصنف الأخرى، لكن قد يكون لدالة وصول الضبط مستوى وصول مستقل عن دالة وصول الاسترجاع، والعكس صحيح. ولا يلزم أن تمتلك الخاصية دالتي الوصول معًا؛ يمكن أن تمتلك واحدة فقط (إما الضبط أو الاسترجاع).

ينعكس وصول القراءة ووصول الكتابة مباشرةً في الصياغة، كما يوضّح المثال التالي:

```haxe
class Main {
  public var x(default, null):Int;
}
```

كلا `default` و`null` هما **معرّفا وصول** خاصان. يحدّد معرّفا الوصول السلوك عند قراءة الحقل (المعرّف الأول) وعند كتابة الحقل (المعرّف الثاني). والقيم المقبولة هي:

- `default`: يسمح بالوصول العادي إلى الحقل إذا كان الحقل عامًّا.
- `null`: يسمح بالوصول من داخل الصنف المُعرِّف فقط.
- `get/set`: يُولَّد الوصول على هيئة استدعاء لدالة وصول (`get_x()`).
- `dynamic`: مثل `get/set`، لكن لا يمكن التحقق من وجود دالة الوصول.
- `never`: لا يسمح بأي وصول على الإطلاق.

إليك مثالًا كاملًا:

```haxe
class Main {
  public var x(default, set):Int;

  public function set_x(x:Int):Int {
    return this.x = x + 2;
  }

  public function main() {
    trace(x); // null
    x = 2;
    trace(x); // 4
  }
}
```
