# حول

لغة Go ذات أنواع ثابتة، لذا سيكون لكل متغير نوع معروف وقت التصريف.
وبعد الإعلان عن المتغير، لا يمكن أن يتغير نوعه.

## إنشاء متغير

تستطيع عبارة `var` أن تعلن عن نوع متغير جديد، أو تحدد قيمته، أو تفعل الاثنين معًا:

```go
var total int     // Type explicitly declared, value implicitly set (see note on zero values below)
var count int = 1 // Type explicitly declared, value explicitly set
var sum = 100     // Type implictly declared, value explicitly set
```

وداخل دالة، يمكن أيضًا استخدام عبارة الإسناد المختصرة `:=`.

```go
count := 1 // Type implictly declared, value explicitly set
```

المتغير في Go له دائمًا قيمة.
وإذا لم تُضبط له قيمة عند الإعلان، توفر Go قيمة [تُسمى القيمة الصفرية][zero-values]، اعتمادًا على نوع المتغير.

```go
var total int     // 0
var name string   // ""
var ready bool    // false
```

## تحديث متغير

وداخل دالة، يستطيع عامل الإسناد `=` تحديد قيمة جديدة لمتغير موجود:

```go
count := 1
count = 2
```

يجب أن تكون القيمة الجديدة من نوع المتغير نفسه:

```go
count := 1
count = false // compile error: a Boolean is not an int
```

[zero-values]: https://exercism.org/tracks/go/concepts/zero-values
