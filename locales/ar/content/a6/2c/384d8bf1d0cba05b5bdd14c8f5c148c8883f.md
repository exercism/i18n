# تلميحات

في كل هذه المهام، ستحتاج إلى الأمر `print`:
```awk
{print "something", "something else"}
```

## 1. اسرد أسماء المستخدمين

* استخدم [المتغير `FS`][var-fs] لتعريف فاصل الحقول.

## 2. اطبع أرقام الأسطر

* استخدم [المتغير `NR` المدمج][var-nr] للحصول على رقم السطر.

## 3. اطبع السجلات ذات الأدلة الرئيسية غير الصالحة.

* الدليل الرئيسي هو الحقل السادس.
* استخدم دالة `startsWith` المعطاة.
* استخدم [عوامل منطقية][boolean-ops]: `&&`، `||`، `!`.

## 4. اطبع عدد المستخدمين الصالحين الذين يستخدمون bash

* صدفة تسجيل الدخول هي الحقل الأخير؛ يمكنك استخدام [المتغير `NF`][var-nf].
