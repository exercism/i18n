# نبذة

التصفية هي عملية إنشاء تسلسل من تسلسل آخر عبر نسخ جميع عناصر التسلسل الأصلي ما عدا عناصر معينة.
ويمكن اختيار العناصر التي ستُضمّ إلى التسلسل الجديد عبر دالة تحقق (دالة يكون ناتجها قيمة منطقية)، أو عبر التساوي مع كائن محدد.

## الإزالة باستخدام دالة تحقق

`remove-if` دالة تأخذ دالة تحقق وتسلسلًا كوسائط، وتُرجع تسلسلًا يحتوي فقط على العناصر التي كانت دالة التحقق عندها قيمة خطأ.
بعبارة أخرى، هي "تُزيل" كل عناصر التسلسل التي تكون دالة التحقق صحيحة عندها. ولكن لاحظ أن هذه الدالة لا تُعدّل التسلسل الأصلي!
بل تُرجع تسلسلًا جديدًا بدون العناصر المطابقة. وإذا كانت دالة التحقق صحيحة لكل القيم، فسيُرجع تسلسل فارغ.

```lisp
(remove-if #'evenp '(1 2 3 4 5)) ; => (1 3 5)
(remove-if #'oddp '(1 3 5))      ; => ()
```

## الإبقاء على العناصر باستخدام دالة تحقق

توجد دالة `remove-if-not` تشبه `remove-if` تمامًا، إلا أنها *تُبقي* على العنصر الذي تكون دالة التحقق صحيحة عنده.

وكبديل، يمكن استخدام `complement` لتحويل دالة تحقق إلى 'عكسها'.

```lisp
(remove-if #'evenp '(1 2 3 4 5 6))             ; => (1 3 5)
(remove-if-not #'oddp '(1 2 3 4 5 6))          ; => (1 3 5)
(remove-if (complement #'oddp) '(1 2 3 4 5 6)) ; => (1 3 5)
```

## إزالة عنصر محدد

إذا أردت إزالة عنصر محدد من تسلسل، يمكنك استخدام `remove` التي تأخذ العنصر المراد إزالته والتسلسل.
وتُرجع كل القيم في التسلسل التي لا تساوي العنصر المراد إزالته.

```lisp
(remove 1 '(1 2 1 3 1 4)) ; => (2 3 4)
(remove #\l "hello")      ; => "heo"
```

يمكن تحديد الدالة المستخدمة للتحقق من التساوي عبر [معامل الكلمة المفتاحية][concept-keyword-parameters] `:test`.

لاحظ أنه يمكن تنفيذ `remove` باستخدام `remove-if` عبر كتابة دالة تحقق تختبر تساوي كائن مع عنصر محدد.

## خيارات كثيرة

تأخذ كل من هذه الدوال أيضًا [معاملات كلمات مفتاحية][concept-keyword-parameters] أخرى كثيرة تتيح لها العمل على تسلسلات فرعية فقط، أو التطبيق عددًا معينًا من المرات، وغير ذلك. راجع [توثيق Hyperspec][hyperspec-remove] للتفاصيل الكاملة


## خيارات مُدمِّرة

بالإضافة إلى `remove` و`remove-if` و`remove-if-not`، هناك `delete` و`delete-if` و`delete-if-not`، ولها الأثر نفسه، إلا أنها قد تُعدّل التسلسل المُمرَّر إليها.
