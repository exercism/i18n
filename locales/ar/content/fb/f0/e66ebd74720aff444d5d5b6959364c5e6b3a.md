# ملحق التعليمات

## تلميحات

يستخدم هذا التمرين بيانات نصية. ولأسباب تاريخية، فإن النوع `String` في Haskell مرادف لـ `[Char]`، أي مصفوفة من المحارف. ولمعالجة البيانات النصية بكفاءة أكبر، يمكن استخدام النوع `Text`.

كإضافة اختيارية إلى هذا التمرين، يمكنك

- قراءة المزيد عن [أنواع السلاسل النصية](https://haskell-lang.org/tutorial/string-types) في Haskell.
- إضافة `- text` إلى قائمة التبعيات في package.yaml.
- استيراد `Data.Text` [بالطريقة التالية](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

        import qualified Data.Text as T
        import           Data.Text (Text)

- يمكنك الآن كتابة مثل `transform :: Map Int Text -> Map Char Int` والرجوع إلى مُركِّبات `Data.Text` مثل `T.toLower`.
- اطّلع على التوثيق الخاص بـ [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html).

هذا الجزء اختياري بالكامل.
