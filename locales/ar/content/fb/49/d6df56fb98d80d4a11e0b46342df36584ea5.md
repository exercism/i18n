# حول

تُستخدم عبارة `guard` في Swift للإرجاع المبكر من دوال Swift عندما لا يتحقق شرط ضروري يجب استيفاؤه لمواصلة المعالجة، على سبيل المثال:

```swift
guard myValue = 0 else { return 0 }
let root = myValue.squareRoot()
```

هنا، تتحقق عبارة `guard` مما إذا كان التعبير المنطقي الذي يلي الكلمة المفتاحية `guard` يُقيَّم على أنه صحيح. إذا كان كذلك، تستمر المعالجة بالكود الذي يلي عبارة `guard` (هنا `let root = myValue.squareRoot()`). وإلا فسيُنفَّذ الكود الموجود في فرع `else`. وعلى عكس الجملة الشرطية `if`، _يجب_ أن تحتوي عبارة `guard` على فرع `else`، وعلى عكس فرع `else` في `if`-`else`، _يجب_ أن يخرج فرع `else` في `guard` من نطاق عبارة `guard`. أي أنه يجب أن يستخدم عبارة نقل تحكم مثل `return` أو `continue` أو `break`، أو أن يرمي خطأً أو يُنهي البرنامج.

ومن أمثلة استخدامه دالة sinc، وهي تساوي sin(x)/x مع تعريف sinc(0) على أنه يساوي 1، مما يتجنب مشكلات القسمة على صفر. ويمكن كتابة هذه الدالة في Swift باستخدام `guard` على النحو التالي:

```swift
func sinc(_ x: Double) -> Double {
    guard x != 0 else { return 1 }
    return sin(x) / x
}

sinc(0)              // returns 1
sinc(Double.pi / 2)  // returns 0.6366197723675814
```
