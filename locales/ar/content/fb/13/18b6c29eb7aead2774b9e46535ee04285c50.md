# التعليمات

في هذا التمرين ستتعامل مع أسطر السجل.

كل سطر سجل هو سلسلة نصية بالتنسيق التالي: `"[<LEVEL>]: <MESSAGE>"`.

هناك ثلاثة مستويات سجل مختلفة:

- `INFO`
- `WARNING`
- `ERROR`

لديك عدة مهام، كل منها تأخذ سطر سجل وتطلب منك القيام بشيء به.

## 1. السماح باسترجاع السلسلة النصية بعد سلسلة نصية فرعية معيّنة

بالنظر إلى سجلات الشهر الماضي، ترى أن رسالة الاختبار تقع دائمًا بعد سلسلة نصية فرعية معيّنة. ولأنك تتوقع أن تحتاج إلى استخراج رسالة الاختبار في وقت قريب، فقد قررت إنشاء طريقة مساعدة تساعدك في ذلك.

نفّذ طريقة الامتداد (_static_) `LogAnalysis.SubstringAfter()`، التي تأخذ فاصلًا نصيًا وتُرجع السلسلة النصية الفرعية الواقعة بعد الفاصل.

```csharp
var log = "[INFO]: File Deleted.";
log.SubstringAfter(": "); // => returns "File Deleted."
```

## 2. السماح باسترجاع السلسلة النصية الواقعة بين سلسلتين نصيتين فرعيتين

عند التدقيق أكثر، ترى أن مستوى السجل يقع دائمًا بين الأقواس المربعة (`[` و `]`). ولأنك تتوقع أيضًا أن تحتاج إلى استخراج مستوى السجل في وقت قريب، فقد قررت إنشاء طريقة مساعدة أخرى تساعدك في ذلك.

نفّذ طريقة الامتداد (_static_) `LogAnalysis.SubstringBetween()` التي تأخذ فاصلين نصيين، وتُرجع السلسلة النصية الفرعية الواقعة بين الفاصلين.

```csharp
var log = "[INFO]: File Deleted.";
log.SubstringBetween("[", "]"); // => returns "INFO"
```

## 3. تحليل الرسالة في سجل

نفّذ طريقة الامتداد (_static_) `LogAnalysis.Message()` لإرجاع الرسالة المضمّنة في سجل.

```csharp
var log = "[ERROR]: Missing ; on line 20.";
log.Message(); // => returns "Missing ; on line 20."
```

## 4. تحليل مستوى السجل في سجل

نفّذ طريقة الامتداد (_static_) `LogAnalysis.LogLevel()` لإرجاع مستوى السجل في سجل.

```csharp
var log = "[ERROR]: Missing ; on line 20.";
log.LogLevel(); // => returns "ERROR"
```
