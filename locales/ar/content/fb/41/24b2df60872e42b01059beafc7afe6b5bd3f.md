# مقدمة

كما يمكن إنشاء مؤشر إلى `int` أو أي نوع بيانات أساسي آخر، يمكن أيضًا إنشاء مؤشر إلى دالة.
ويمكن استخدام مؤشر الدالة لتمرير دالة إلى دالة أخرى.
الدالة التي تُمرَّر كقيمة معامل إلى دالة أخرى تُعرف باسم دالة من الدرجة الأولى.
والدالة التي تأخذ دالة واحدة أو أكثر كمعامل، أو التي تُرجع دالة، تُعرف باسم دالة عالية الرتبة.

في المثال التالي، `is_even` و`is_odd` دالتان من الدرجة الأولى.
أما الدالة عالية الرتبة فهي `test_number`.

```c
#include <stdio.h>
#include <stdbool.h>

bool is_even (int number) {
    return number & 1 != 1;
}

bool is_odd (int number) {
    return number & 1 == 1;
}

// this function takes any other function which takes a number and returns a bool
void test_number(bool (*func) (int), int number, char *text){
    printf(text, number, func(number)? "true": "false");
}

int main() {
    // prints Testing odd for 3 is true
    test_number(is_odd, 3,"Testing odd for %d is %s\n");
    // prints Testing even for 3 is false
    test_number(is_even, 3,"Testing even for %d is %s\n");
}
```
توقيع الدالة `bool (*func) (int)` الخاص بالوسيط الأول لـ `test_number` يطابق توقيع الدوال الممرَّرة.
فكلتا الدالتين `is_even` و`is_odd` تأخذان معاملًا من النوع `int` وتُرجِعان قيمة من النوع `bool`.
وفي `(*func)` يمثّل `func` اسم الدالة المُراد استخدامها.
ولو استُخدم `(*fn)` لكانت قد استُدعيت هكذا: `printf(text, number, fn(number)? "true": "false");`.
ولتلبية معامل مؤشر الدالة، نمرّر اسم دالة لها التوقيع المتوقَّع عند استدعاء `test_number`.
وهكذا نرى أن اسم الدالة يشير إلى عنوان تلك الدالة المسمّاة.
