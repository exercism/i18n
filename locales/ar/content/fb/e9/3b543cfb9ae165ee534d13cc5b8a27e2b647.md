# التعليمات

لديك رغبة مفاجئة في أكل البان كيك.
وبصفتك شخصًا عصريًا ذا ميول تقنية، تكتب قائمة تسوق لمكوّنات البان كيك بصيغة JSON.
بنية القائمة هي:

```json
{
  "name": "name of shopping list",
  "ingredients": [ ...list of ingredients... ],
  "optional ingredients": [ ...list of ingredients... ]
}
```

يُمثَّل المكوّن ككائن JSON، هكذا:

```json
{
  "item": "flour",
  "amount": {
    "quantity": 2,
    "unit": "cup"
  }
}
```

للمكوّن خاصية اختيارية باسم `"substitute"` تحمل سلسلة نصية تمثل عنصرًا آخر يمكن استخدامه بدلًا منه.

لنرَ كيف يمكننا فحص قائمة التسوق باستخدام `jq`

## 1. استخراج اسم قائمة التسوق

اكتب تعبيرًا يُخرج عنصر `"name"` من قائمة التسوق.

## 2. احسب عدد المكوّنات المطلوبة

احسب المكوّنات `"required"` فقط. لا تُدرج المكوّنات الاختيارية.

## 3. كم كمية السكر؟

اكتب تعبيرًا يُخرج كمية السكر.
المطلوب هو الجزء الرقمي فقط.

## 4. اربط المكوّنات القابلة للاستبدال

يمكن استبدال بعض المكوّنات (إذا لم يتوفر لديك المكوّن X يمكنك استخدام Y).
أخرِج كائن JSON يربط كل مكوّن موصى به ببديله.
أدرِج المكوّنات الاختيارية في الخريطة.
