# أساسيات الصياغة في Elm 1

## الثوابت والدوال

تتكوّن برامج Elm من تعريفات وتعبيرات.
وكل شيء في Elm إمّا تعريف وإمّا تعبير.

تُعرَّف القيمة الثابتة بالصيغة `name = expression`.

```elm
five = 5

six = 3 + 3
```

وتُعرَّف الدوال بالصيغة `name parameters... = expression`،
مع فصل المعاملات بالمسافات فقط.

```elm
add number1 number2 = number1 + number2
```

استدعاء الدالة هو أيضًا تعبير، ويتم بتحديد اسمها
وتمرير وسائط لكل معامل من معاملات الدالة،
مفصولة بالمسافات، تمامًا كما في تعريف الدالة.

```elm
five = add 2 3
```

يمكن استخدام الأقواس الهلالية لتحديد ترتيب تقييم التعبير.

```elm
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## المسافات البادئة / المسافات البيضاء ذات الدلالة

لا يستخدم Elm علامات صياغية مثل الأقواس المعقوفة أو الأقواس الهلالية أو الفواصل المنقوطة لتحديد حدود الكود، بل يستخدم المسافات البيضاء والمسافات البادئة بدلًا من ذلك.

- يجب أن تبدأ تعريفات الوحدات والاستيراد والدوال على المستوى الأعلى من أقصى عمود إلى اليسار.
- إذا قُسّم التعبير على عدة أسطر، وجب إزاحة الكود الذي هو جزء من ذلك التعبير أسفل منه بمسافة واحدة على الأقل.
- ينبغي إزاحة أجزاء التعبير التي تُجمَّع معًا بالعدد نفسه من المسافات.

```elm
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://elmprogramming.com/indentation.html

## الوحدات

كل ملف في Elm هو وحدة، ويجب أن يحتوي على عبارة `module` قبل أي كود آخر.
يجب أن تطابق أسماء الوحدات أسماء ملفاتها، لذا يجب أن تكون الوحدة `Calculator` في الملف Calculator.elm.
وكل ما يُعرَّف داخل وحدة يكون ضمن نطاقها الخاص
ولا يمكن الوصول إليه من خارج هذه الوحدة، إلا إذا ذُكر في `exposing`.

```elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## التعليقات

التعليق نصّ داخل ملف Elm لا يُفسَّر ككود.
والغرض منه أساسًا أن يقرأه أنت والمبرمجون الآخرون.
توجد صياغة بسيطة للتعليقات ذات السطر الواحد، تعتمد على الشرطتين المتصلتين.
ويمكن أيضًا كتابة تعليقات متعددة الأسطر باستخدام الزوج `{-` و`-}`
من علامات الفتح والإغلاق.

```elm
-- a single line comment
-- another single line comment

{- a multiline comment
   spawning multiple lines
-}
```
