# نبذة

[Java](https://go.java/index.html) من أكثر لغات البرمجة شيوعًا، بفضل تعدد استخداماتها وتوافقها.
وهي تُستخدم على نطاق واسع في تطوير البرمجيات وتطبيقات الهاتف وبناء الأنظمة الكبيرة.

ظهرت Java عام 1995، وتتولى [Oracle](https://www.oracle.com/index.html) رعايتها.
ورغم أنها ليست حديثة كبعض اللغات الجديدة، فإن Java لا تزال تحظى بشعبية كبيرة.
فقد صُممت لتكون سريعة وآمنة وموثوقة وسهلة على المبتدئين وقابلة للنقل بدرجة عالية.
وهذه الميزة الأخيرة موجودة لأن Java تُنفَّذ على [آلة Java الافتراضية (Java Virtual Machine - JVM)](https://en.wikipedia.org/wiki/Java_virtual_machine) متوافقة مع مختلف الأنظمة.
وتُطوَّر تطبيقات Android أيضًا باستخدام Java، لأن [نظام تشغيل Android](<https://en.wikipedia.org/wiki/Android_(operating_system)>) يعمل في بيئة لغة Java.

مجتمع Java ضخم!
فمثلًا يضم GitHub أكثر من 1.5 مليون مشروع Java.
ومن الجدير بالذكر أيضًا أن Java لديها ثاني أكبر مجتمع على [StackOverflow](https://stackoverflow.com/questions/tagged/java)!
وهذا مهم لأن مجتمع لغة البرمجة كلما كبر، زاد الدعم الذي يحتمل أن تحصل عليه.

وتمتلك Java أيضًا مجموعة قوية ومصممة جيدًا من [واجهات برمجة التطبيقات (API)](https://docs.oracle.com/en/java/javase/11/docs/api/index.html) المدمجة، والتي يمكن استخدامها في أنشطة متنوعة مثل الاتصال بقواعد البيانات والشبكات والإدخال والإخراج وتحليل XML والأدوات المساعدة وغير ذلك الكثير.

من الحواسيب المحمولة إلى مراكز البيانات، ومن أجهزة الألعاب إلى الحواسيب الفائقة العلمية، ومن الهواتف الخلوية إلى الإنترنت، [Java في كل مكان](https://en.wikipedia.org/wiki/Write_once,_run_anywhere)!
