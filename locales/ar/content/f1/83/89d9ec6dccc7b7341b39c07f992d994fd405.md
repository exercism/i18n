# التعليمات

يخدم بنك مزدحم العملاء المنتظرين حسب *الأولوية* لا حسب ترتيب وصولهم. يحصل كل عميل على رقم أولوية عند أخذ تذكرة، ويخدم أمين الصندوق دائمًا صاحب الرقم الأصغر تاليًا (`1` هو الأكثر إلحاحًا). والكومة الصغرى هي طابور الانتظار الأمثل.

## 1. افتح الطابور

عرّف `new-queue`، وهي لا تأخذ شيئًا وتُرجع طابور أولوية جديدًا فارغًا.

```factor
new-queue
! => an empty priority queue
```

## 2. أضف عميلًا

عرّف `join-queue`، وهي تأخذ اسم عميل ورقم أولوية وطابورًا. تضيف العميل إلى الطابور وتُرجع الطابور، بحيث يمكن إضافة العملاء واحدًا بعد الآخر.

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue
! => the queue, now holding alice (5) and bob (2)
```

## 3. من التالي؟

عرّف `next-name`، وهي تأخذ طابورًا وتُرجع اسم العميل الذي ينبغي خدمته تاليًا، أي صاحب أصغر رقم أولوية، *دون* إزالته.

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue next-name .
! => "bob"
```

## 4. اخدم الجميع

عرّف `serve-all`، وهي تأخذ طابورًا وتُرجع أسماء جميع العملاء المنتظرين، بالترتيب الذي ستُخدم به.

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue
"carol" 9 rot join-queue serve-all .
! => { "bob" "alice" "carol" }
```
