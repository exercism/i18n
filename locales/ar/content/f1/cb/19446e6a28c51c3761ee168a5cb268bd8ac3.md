# مقدمة

على خلاف كثير من اللغات الأخرى، يوجد في JavaScript كيانان مختلفان يمثلان غياب قيمة (ذات معنى). هما `null` و`undefined`.

## `null`

تُستخدم القيمة الأولية `null` كـ"قيمة فارغة" مقصودة للمتغيرات من أي نوع.

```javascript
let name = null;
// name is intentionally set to "empty" because it is not
// available
```

يمكنك التحقق مما إذا كان المتغير `null` باستخدام [عامل المساواة الصارمة][mdn-strict-equality] `===`.

```javascript
let name = null;

name === null;
// => true
```

## `undefined`

> المتغير الذي لم تُسنَد إليه قيمة يكون من النوع `undefined`.[^1]

وهذا يعني أنه بينما يمثل `null` قيمة فارغة (لكنها ما زالت قيمة)، فإن `undefined` يمثل الغياب التام للقيمة. 🤯

يظهر `undefined` في سياقات مختلفة.

- إذا عُرِّف متغير دون قيمة (تهيئة)، فإنه يكون `undefined`.

  ```js
  let name;
  console.log(name); // => undefined
  ```

- إذا حاولت الوصول إلى قيمة مفتاح غير موجود في كائن، فستحصل على `undefined`.

  ```js
  let obj = {
    name: 'John',
  };
  console.log(obj.age); // => undefined
  ```

- إذا لم تُرجع دالة قيمة، فإن النتيجة تكون `undefined`.

  ```js
  function printName(name) {
    'My name is ' + name;
  }
  console.log(printName('John')); // => undefined
  ```

- إذا لم يُمرَّر وسيط إلى دالة، فإنه يكون `undefined`، ما لم يكن لذلك الوسيط قيمة افتراضية.

  ```js
  function printName(name) {
    return name;
  }
  console.log(printName()); // => undefined
  ```

يمكنك التحقق مما إذا كان المتغير `undefined` باستخدام عامل المساواة الصارمة `===`.

```javascript
let name;

name === undefined;
// => true
```

## التسلسل الاختياري

إذا حاولت استرجاع قيمة متداخلة في كائن لكن المفتاح الأب غير موجود، فستُطلق JavaScript خطأً.
ولتجنب ذلك بسهولة، أُضيف التسلسل الاختياري إلى مواصفات اللغة في عام 2020.
باستخدام عامل التسلسل الاختياري `?.` يمكنك أن تضمن أن JavaScript لا تحاول الوصول إلى المفتاح المتداخل إلا إذا لم يكن المفتاح الأب `null` أو `undefined`.
وإلا فستُرجع JavaScript القيمة `undefined`.

```javascript
const obj = {
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
};

obj.address.zipCode;
// => undefined

obj.residence.street;
// => TypeError: Cannot read property 'street' of undefined

obj.residence?.street;
// => undefined
```

## الدمج الصفري

هناك حالات تريد فيها تطبيق قيمة افتراضية عندما يكون المتغير `null` أو `undefined` (ولكن في هذه الحالات فقط).
ولمعالجة ذلك، أُدخل عامل الدمج الصفري `??` في عام 2020.
وهو يُرجع الطرف الأيمن فقط عندما يكون الطرف الأيسر `null` أو `undefined`.
وإلا فيُرجع الطرف الأيسر.

```javascript
let amount = null;
amount = amount ?? 1;
// => 1

amount = 0;
amount = amount ?? 1;
// => 0
```
