# مقدمة

## المقارنة

### مقارنة الأعداد

في `jq`، يمكن مقارنة الأعداد باستخدام عوامل العلاقة والمساواة التالية.

| المقارنة                | العامل   |
| ----------------------- | -------- |
| أكبر من                 | `a > b`  |
| أكبر من أو يساوي        | `a >= b` |
| أصغر من                 | `a < b`  |
| أصغر من أو يساوي        | `a <= b` |
| يساوي                   | `a == b` |
| لا يساوي                | `a != b` |

نتيجة المقارنة دائمًا قيمة منطقية، أي إما `true` أو `false`.

```jq
1 < 3,      # => true
2 != 2,     # => false
1 == 1.0    # => true
            # All numbers are floating-points, so this is different syntax
            # for the exact same value.
```

### مقارنة السلاسل النصية

يمكن أيضًا استخدام عوامل المقارنة أعلاه لمقارنة السلاسل النصية.
في هذه الحالة، يُطبَّق ترتيب قاموسي (معجمي).
ويكون الترتيب _حسب قيمة نقطة ترميز يونيكود_.

```jq
"Apple" > "Pear",   # => false
"a" < "above",      # => true
"a" == "A"          # => false
```

عليك أن تكون حريصًا عند مقارنة متغيرين يبدوان وكأنهما يحتويان على قيم عددية، لكن نوعهما سلسلة نصية.
بسبب الترتيب القاموسي، لن تكون النتيجة مماثلة لمقارنة قيم من النوع عدد.

```jq
10 < 2,     # => false
"10" < "2"  # => true (because "1" comes before "2")
```

### المساواة "الصارمة"

عامل `==` في `jq` يشبه `===` في JavaScript من حيث أن الأشياء التي "تبدو" متشابهة، ولكنها من أنواع مختلفة، ليست متساوية.

```jq
"3" == 3    # => false
            # the value on the left has type string,
            # the value on the right has type number.
```

### مقارنة المصفوفات

تكون المصفوفتان متساويتين إذا كانت جميع عناصرهما المتناظرة متساوية.

```jq
[1, 2, 3] == [1, 2, 3]      # => true
[1, 2, 3] == [1, 3, 2]      # => false, different order
[1, 2, 3] == [1, 2, "3"]    # => false, different types
```

### مقارنة الكائنات

يكون الكائنان متساويين إذا كان لهما نفس أزواج المفتاح والقيمة.

```jq
{name: "Joe", age: 42} == {age: 42, name: "Joe"}                # => true
{name: "Joe", age: 42} == {age: 42, name: "Jane"}               # => false
{name: "Joe", age: 42} == {age: "42", name: "Joe"}              # => false
{name: "Joe", age: 42} == {age: 42, name: "Joe", height: 175}   # => false

# comparisons will drill down as deeply as required
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2]}}}                  # => true
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2, 3]}}}               # => false
```

## الجمل الشرطية

### تعبير `if`

**التعبير الشرطي** في `jq` هو `if A then B else C end`.

`if-then-else` مرشّح شأنه شأن جميع الدوال المدمجة في `jq`: يأخذ مدخلًا وينتج مخرجًا.

إذا أنتج التعبير `A` قيمة "تُعتبر صحيحة"، فإن مرشّح `if` يقيّم `B`.
وإلا فإنه يقيّم `C`.
وسيُمرَّر مدخل مرشّح `if` إلى `B` أو `C`.

```jq
42 | if . < 50 then "small" else "big" end      # => "small"
```

```jq
5 | if . % 2 == 0 then . / 2 else . * 4 end     # => 20
```

~~~~exercism/note
جملة `else` **اختيارية**؛ العبارتان التاليتان متكافئتان.

```jq
if A then B else . end
if A then B end
```
~~~~

### الجمل الشرطية المتداخلة

يمكن إضافة المزيد من الشروط باستخدام `elif`.

```jq
42 | if . < 33 then "small"
     elif . < 66 then "medium"
     else "big"
     end
# => "medium"
```

استخدم ما تحتاجه من جمل `elif`.

### الصدقية

القيم "الخاطئة" الوحيدة في `jq` هي: `false` و `null`.
وكل ما عدا ذلك "صحيح"، حتى العدد صفر والسلسلة النصية الفارغة والمصفوفة الفارغة والكائن الفارغ.

### العوامل المنطقية

يمكن استخدام **العوامل المنطقية** `and` و `or` لبناء استعلامات معقدة.

```jq
42 | if . < 33 or . > 66 then "big or small"
     else "medium"
     end
```

للنفي، استخدم `not`. فهذا **مرشّح** وليس عاملًا.

```jq
42 | if (. < 33 or . > 66 | not) then "medium"
     else "big or small"
     end
```

### العامل البديل

يتيح لك **العامل البديل** تحديد قيمة "افتراضية" إذا كان التعبير خطأ أو `null`.

```jq
A // B

# This is identical to
if A then A else B end
```

للتوضيح

```jq
[3, 5, 18] | add / 2       # => 13
[]         | add / 2       # => error: null (null) and number (2) cannot be divided
[]         | add // 0 / 2  # => 0
```
