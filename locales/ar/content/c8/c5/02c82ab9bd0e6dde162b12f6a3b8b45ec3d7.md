# `if` و`elseif` و`else`

الجمل الشرطية التي تستخدم `if` و`elseif` و`else` جزء أساسي من التحكم في مسار البرنامج.
تُقيّم جملة `if` تعبيرًا، وإذا كانت قيمته `true`، فإنها تنفّذ فرع الكود.

```php
<?php

if ($expression) {
    // .. executed if $expression is true
}
```

إذا لم يكن التعبير قيمة منطقية، فإن التقييم يحدد ما إذا كانت القيمة "صحيحة" أم "غير خاطئة".
في PHP، تُعتبر القيم التالية مساوية لـ `false`:

- قيمة منطقية `false`
- عدد صحيح `0`
- عدد عشري `0.0` و`-0.0`
- مصفوفة فارغة `[]`
- سلسلة نصية فارغة `""` أو سلسلة نصية رقمية `"0"`
- `null`

وتُعتبر جميع القيم الأخرى صحيحة.

## التعامل مع عدة شروط

بعد جملة `if`، يمكنك ربط عدة شروط باستخدام `elseif` و`else`.

```php
<?php

if ($value === 0) {
    // .. do something
} elseif ($value === 1) {
    // .. do something else
} else {
    // ,, do this if nothing else
}
```

لن تُنفَّذ إلا جملة شرطية واحدة قُيِّمت بأنها صحيحة.
لذلك إذا كان من الممكن أن تُقيَّم عدة شروط بأنها صحيحة، فإن ترتيب كتابتها مهم.

```php
<?php

if (true) {
    // .. always do something
} elseif (true)
    // .. will never be executed
} else {
    // .. will never be executed
}
```
