# الأساسيات

يتكوّن برنامج Sather من **أصناف** تحتوي على **إجراءات**.

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

end; -- class GREETER
```

## الأصناف

يُسمّى الصنف بأحرف كبيرة، مع شرطات سفلية بين الكلمات: `GREETER`، `STAGE_DIRECTIONS`. وعادة ما يطابق اسم الملف الاسم نفسه بأحرف صغيرة: `stage_directions.sa`.

كل إجراء يوجد داخل صنف. ولا يوجد أي كود خارج صنف.

## الإجراءات

الإجراء الذي يُنتج قيمة يعلن نوع تلك القيمة بعد نقطتين:

```sather
   hello : STR is
      return "Hello!";
   end;
```

`STR` هو نوع النصوص. والإجراء الذي لا يستقبل وسائط يُكتب ويُستدعى بدون قوسين هلاليين.

ويمكن للإجراء أن يستقبل وسائط، تُكتب بين قوسين هلاليين بعد الاسم:

```sather
   louder(word : STR) : STR is
      return word;
   end;
```

يُرجع `return` القيمة ويوقف الإجراء في الحال، لذا تُتجاهل أي أسطر تليه.

## الاستدعاء

من خارج الصنف، اذكر اسم الصنف، ثم `::`، ثم الإجراء:

```sather
GREETER::hello
```

ومن داخل الصنف نفسه، يمكن الاستغناء عن اسم الصنف. وهذا هو الأسلوب المعتاد للسماح لإجراء بأن يستخدم إجراءً آخر:

```sather
   greeting_again : STR is
      return hello;
   end;
```

## التعليقات

تبدأ الشرطتان تعليقًا يمتد إلى نهاية السطر.

```sather
   -- Explain why, not what: the code already says what.
   hello : STR is
      return "Hello!";   -- a trailing comment is fine too
   end;
```

بحسب العُرف، ينتهي الصنف بتعليق يسمّيه. فالإجراءات والحلقات والأصناف كلها تُغلق بـ `end;`، لذا يوضّح التعليق أيّها يعود إليه هذا `end;`:

```sather
end; -- class GREETER
```

## الفواصل المنقوطة

تنتهي العبارات بفاصلة منقوطة. والفاصلة المنقوطة بعد آخر عبارة في الإجراء اختيارية، لكن كتابتها في كل مرة توفّر عليك التفكير في أمر واحد.
