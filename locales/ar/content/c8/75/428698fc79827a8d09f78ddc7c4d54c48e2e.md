# مقدمة

المتجه مصفوفة أحادية البعد.
وقد يحتوي على عناصر من أنواع مختلفة.

## إنشاء المتجهات

يمكن إنشاء المتجهات عبر الدالة `vector` أو باستخدام صيغة القارئ الخاصة بها `#()`

```lisp
(vector 1 t "foo" 'b) ; => #(1 t "foo" B)
#(2 nil "bar" a)      ; => #(2 nil "bar" A)
```

## الوصول إلى العناصر

للوصول إلى عناصر المتجه استخدم `aref`، فالفهارس تبدأ من الصفر:

```lisp
(aref #(1 2 3) 1) ; => 2
(aref #(a b c) 0) ; => A
```
