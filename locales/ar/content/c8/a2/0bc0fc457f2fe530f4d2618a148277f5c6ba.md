# التعليمات

في هذا التمرين، تحتاج إلى تنفيذ بعض الدوال للتعامل مع مصفوفة من لغات البرمجة.

## 1. تعريف دالة تُرجع مصفوفة لغات فارغة

عرّف دالة `language_list` التي لا تستقبل أي وسائط وتُرجع مصفوفة فارغة.

```php
<?php

language_list();
// => []
```

## 2. تعديل الدالة لإنشاء مصفوفة من أي عدد من اللغات

عدّل دالة `language_list` بحيث تستقبل وسائط متغيرة من اللغات (سلاسل نصية). ويجب أن تُرجع المصفوفة الناتجة التي تحتوي على اللغات.

```php
<?php

$language_list = language_list();
// => []
$language_list = language_list("Clojure", "PHP");
// => ["Clojure", "PHP"]
$language_list = language_list("PHP", "Haskell", "Java", "C++", "Rust")
// => ["PHP", "Haskell", "Java", "C++", "Rust"]
```

## 3. تعريف دالة لإضافة لغة إلى المصفوفة

عرّف دالة `add_to_language_list` التي تستقبل وسيطين: مصفوفة لغات، واللغة الجديدة.

```php
<?php

$language_list = language_list();
// => []
$language_list = add_to_language_list($language_list, "Clojure");
// => ["Clojure"]
```

## 4. تعريف دالة لإزالة عنصر من مصفوفة اللغات

عرّف دالة `prune_language_list` لإزالة أول لغة من مصفوفة اللغات.

```php
<?php

$language_list = language_list("PHP");
// => ["PHP"]
$language_list = prune_language_list($language_list);
// => []
```

## 5. تعريف دالة للحصول على أول عنصر في المصفوفة

عرّف دالة `current_language` التي تستقبل وسيطًا واحدًا (_مصفوفة لغات_). ويجب أن تُرجع أول لغة في المصفوفة. افترض أن المصفوفة ستحتوي دائمًا على عنصر واحد على الأقل.

```php
<?php

$language_list = language_list("PHP", "Prolog");
// => ["PHP", "Prolog"]
$first = current_language($language_list);
// => "PHP"
```

## 6. تعريف دالة تُرجع عدد اللغات في المصفوفة

عرّف دالة `language_list_length` التي تستقبل وسيطًا واحدًا (_مصفوفة لغات_). ويجب أن تُرجع عدد اللغات في المصفوفة.

```php
<?php

$language_list = language_list("PHP", "Prolog", "Wren");
// => ["PHP", "Prolog", "Wren"]
language_list_length($language_list);
// => 3
```
