# طرق السلاسل النصية

تحتوي `String` على عدة طرق يمكن استخدامها للتعامل مع السلاسل النصية.
تُستدعى هذه الطرق على السلسلة النصية نفسها، وغالبًا ما تُربط معًا لتنفيذ عدة عمليات على السلسلة النصية.

فيما يلي قائمة ببعض الطرق الأكثر شيوعًا.
راجع [توثيق `String` API][string-api] للحصول على قائمة كاملة بالطرق.

## String#upcase & String#downcase

تُرجع طريقة [`upcase`][upcase] سلسلة نصية جديدة بعد تحويل جميع أحرفها إلى أحرف كبيرة.

```crystal
"hello".upcase
# => "HELLO"
```

تُرجع طريقة [`downcase`][downcase] سلسلة نصية جديدة بعد تحويل جميع أحرفها إلى أحرف صغيرة.

```crystal
"HELLO".downcase
# => "hello"
```

## String#sub & String#gsub

توفّر Crystal طرقًا لاستبدال أجزاء من السلسلة النصية.
وتُعرف هذه الطرق بـ [`sub`][sub] (_الاستبدال_) و[`gsub`][gsub] (_الاستبدال الشامل_).

يمكن لهذه الطرق أن تأخذ سلسلة نصية أو محرفًا أو تعبيرًا نمطيًا كوسيط أول، وسلسلة نصية أو محرفًا كوسيط ثانٍ.
الوسيط الأول هو الجزء من السلسلة النصية الذي سيُستبدل، والوسيط الثاني هو البديل.
سيُشرح `Char` والتعبير النمطي في مفاهيم لاحقة.

تستبدل طريقة `sub` أول ظهور للوسيط الأول بالوسيط الثاني.

```crystal
"hello".sub("l", "r")
# => "herlo"
```

تعمل طريقة `gsub` مثل `sub` تمامًا، لكنها تستبدل جميع ظهورات الوسيط الأول بالوسيط الثاني.

```crystal
"hello".gsub("l", "r")
# => "herro"
```

## String#chomp & String#strip

يمكن استخدام `chomp` و`strip` لإزالة الأحرف غير المرغوبة من السلسلة النصية.

تُزيل طريقة [`chomp`][chomp] افتراضيًا آخر محرف من `\r` أو `\n` أو `\r\n` في نهاية السلسلة النصية.
وإذا استُدعيت الطريقة بوسيط، فستُزيل القيمة المعطاة من نهاية السلسلة النصية.
وذلك إن كانت القيمة موجودة فعلًا في نهاية السلسلة النصية.

```crystal
"hello\n".chomp
# => "hello"

"hello".chomp("llo")
# => "he"
```

تُزيل طريقة [`strip`][strip] افتراضيًا كل المسافات البيضاء من بداية السلسلة النصية ونهايتها.
وإذا استُدعيت الطريقة بوسيط، فستُزيل ذلك الوسيط من بداية السلسلة النصية ونهايتها.
وذلك إن كان الوسيط موجودًا فعلًا في بدايتها أو نهايتها.

```crystal
" hello ".strip
# => "hello"
```

## String#index

يمكن استخدام طريقة [`index`][index] لإيجاد فهرس محرف داخل سلسلة نصية.
تأخذ طريقة `index` سلسلة نصية أو `Char` أو تعبيرًا نمطيًا كوسيط.
ويمكنها أن تأخذ وسيطًا ثانيًا اختياريًا لتحديد الفهرس الذي يبدأ منه البحث.
وتُرجع طريقة `index` فهرس أول ظهور للوسيط.

```crystal
"hello".index("l")
# => 2

"hello".index("l", 3)
# => 3
```

## String#delete_at

يمكنك استخدام طريقة [`delete_at`][delete_at] لإزالة محرف من سلسلة نصية.
تأخذ طريقة `delete_at` فهرسًا كوسيط، وتُزيل المحرف الموجود عند ذلك الفهرس.

```crystal
"hello".delete_at(0)
# => "ello"

"hello".delete_at(3)
# => "helo"
```

## String#insert

يمكن استخدام طريقة [`insert`][insert] لإدراج سلسلة نصية عند فهرس محدد.
تأخذ طريقة `insert` فهرسًا كوسيط أول وسلسلة نصية كوسيط ثانٍ.
وتُرجع طريقة `insert` سلسلة نصية جديدة بعد إدراج الوسيط الثاني عند الفهرس.

```crystal
"hello".insert(0, "h")
# => "hhello"

"hello".insert(3, "l")
# => "helllo"
```
