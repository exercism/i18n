# نبذة

أحد الجوانب الأساسية في التعامل مع الأعداد في F# هو التمييز بين الأعداد الصحيحة (الأعداد التي لا تحتوي على أرقام بعد الفاصلة العشرية) والأعداد العشرية (الأعداد التي تحتوي على صفر أو أكثر من الأرقام بعد الفاصلة العشرية).

أكثر نوعين استخدامًا للأعداد في F# هما `int` (عدد صحيح بطول 32 بت) و`float` (عدد عشري بطول 64 بت).

```fsharp
let i = 123   // Type is `int`
let d = 54.29 // Type is `float`
```

يمكن لكل من الأعداد الصحيحة والأعداد العشرية استخدام المحرف `_` كـ_فاصل للأرقام_، وهو ما يساعد عند كتابة أعداد كبيرة:

```fsharp
let largeInt = 1_000_000
// => 1000000

let largeFloat = 9_876_543.21
// => 9876543.21
```

تُجرى العمليات الحسابية باستخدام [عوامل الحساب][arithmetic-operators] القياسية (`+`، `-`، `*`، إلخ). ويمكن مقارنة الأعداد باستخدام [عوامل المقارنة][comparison-operators] القياسية (`<`، `>=`، إلخ)، وعاملي المساواة (`=`) وعدم المساواة (`<>`).

```fsharp
5 * 6
// => 30

1.2 > 0.8
// => true

2 <> 4
// => true
```

للتحويل بين أنواع الأعداد، عليك استخدام [عامل التحويل][conversion-operators] المدمج. تُسمّى هذه العوامل تبعًا للنوع الذي تُحوّل إليه.

```fsharp
let floatFromInt = float 2
let intFromFloat = int 3.39
```

عند التحويل بين الأنواع، كن حذرًا دائمًا. إذا تعذّر تمثيل قيمة ما بالنوع الهدف، فستحدث للقيمة حالة _تجاوز السعة_.
