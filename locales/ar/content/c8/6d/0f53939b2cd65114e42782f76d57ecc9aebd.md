# التعليمات

يعمل Josh على لعبة تقمّص أدوار جديدة ويحتاج إلى مساعدتك في تنفيذ بعض آليات اللعبة.

## 1. تعريف اتحادات الأنواع

عرّف اتحاد أنواع يجمع بين `String` و `Missing` باسم `StringOrMissing` بحيث يمكن استخدامه في الكود لاحقًا.
عرّف اتحاد أنواع يجمع بين `Int64` و `Nothing` باسم `IntOrNothing` بحيث يمكن استخدامه في الكود لاحقًا.

## 2. تنفيذ النوع المركّب `Player`

يجب أن يحتوي النوع المركّب `Player` على أربعة حقول، لكل منها تعليق نوع وقيمة افتراضية:
- `name` من النوع `StringOrMissing`، وقيمته الافتراضية `missing`
- `level` من النوع `Int64`، وقيمته الافتراضية `0`
- `health` من النوع `Int64`، وقيمته الافتراضية `100`
- `mana` من النوع `IntOrNothing`، وقيمته الافتراضية `nothing`

```julia-repl
julia> defaultplayer = Player()
Player(missing, 0, 100, nothing)

julia> wealthyplayer = Player(mana=100)
Player(missing, 0, 100, 100)

julia> namedplayer = Player(name="Guilian", level=10)
Player("Guilian", 10, 100, nothing)
```

## 3. عرّف بنفسك

نفّذ الدالة `introduce`.

قد يُخفي اللاعبون المتخفّون أسماءهم، وسيُعرَّف بهم باسم `"Mighty Magician"`. وإلا فاستخدم اسم اللاعب فقط للتعريف به.

```julia-repl
julia> introduce(Player(level=2, health=8))
"Mighty Magician"

julia> introduce(Player(name="Merlin", level=2, health=8))
"Merlin"
```

## 4. تنفيذ طرق `increment`

للدالة المساعدة `increment` طريقتان، لكل منهما توقيع دالة مختلف.
ويحتاج وسيط كل منهما إلى تعليق نوع لجعل التوقيع صريحًا.

يجب أن تأخذ طريقة `increment` الخاصة بالأسماء قيمة `name` للاعب.
- إذا كان الاسم `missing` فأرجع اللقب "The Great".
- وإلا فيُضاف اللقب " the Great" إلى الاسم.

تُرجع طريقة `increment` هذه الاسم الجديد.

```julia-repl
julia> player1 = Player(name="Ogre", level=5, health=49, mana=26)
Player("Ogre", 5, 49, 26)

julia> increment(player1.name)
"Ogre the Great"

julia> player2 = Player(level=32, mana=57)
Player(missing, 32, 100, 57)

julia> increment(player2.name)
"The Great"
```

يجب أن تأخذ طريقة `increment` الخاصة بـ `mana` قيمة `mana` للاعب.
- إذا كانت قيمة `mana` للاعب هي `missing`، فأرجع القيمة `50`.
- وإلا فيجب زيادة `mana` بمقدار `100`.

تُرجع طريقة `increment` هذه قيمة `mana` المحدَّثة.

```julia-repl
julia> player3 = Player(level=3)
Player(missing, 3, 100, nothing)

julia> increment(player3.mana)
50

julia> player4 = Player("Goblin", level=15, health=49, mana=26)
Player("Goblin", 5, 49, 26)

julia> increment(player4.mana)
126
```

## 5. تنفيذ الدالة `title!`

أعلى مستوى في اللعبة هو `42`.  وتقديرًا لإنجاز اللاعبين الذين يبلغون هذا المستوى، يُلحق لقب بأسمائهم.  وتحدّث الدالة `title!` اسم اللاعب على النحو التالي.

- إذا كان مستوى اللاعب 42، فيُحدَّث الاسم باستخدام الدالة `increment`.
- وإلا فيبقى الاسم دون تغيير.

وفي كلتا الحالتين، تُرجع الدالة `title!` اسم اللاعب.

```julia-repl
julia> player1 = Player(level=42, health=12)
Player(missing, 42, 12, nothing)

julia> title!(player1)
"The Great"

julia> player1.name
"The Great"

julia> player2 = Player(name="Svengali", level=42, health=36, mana=54)
Player("Svengali", 42, 36, 54)

julia> title!(player2)
"Svengali the Great"

julia> player2.name
"Svengali the Great"

julia> player3 = Player(name="Rasputin", level=21, health=100, mana=54)
Player("Rasputin", 21, 100, 54)

julia> title!(player3)
"Rasputin"

julia> player3.name
"Rasputin"
```

## 6. تنفيذ الدالة `revive!`

يجب أن تتحقق الدالة `revive!` من أن شخصية اللاعب ميتة فعلًا (وصلت صحتها إلى `0`).

إذا كان اللاعب ميتًا:
- يجب إحياء اللاعب بصحة `100`.
- يجب زيادة `mana` الخاص باللاعب باستخدام الدالة `increment`.

إذا كان اللاعب على قيد الحياة، فلا يحدث له شيء.

يجب أن تُرجع الدالة `revive!` اللاعب.

```julia-repl
julia> deadplayer1 = Player(level=2, health=0)
Player(missing, 2, 0, nothing)

julia> revive!(deadplayer1)
Player(missing, 2, 100, 50)

julia> deadplayer2 = Player(level=12, health=0, mana=5)
Player(missing, 12, 0, 5)

julia> revive!(deadplayer2)
Player(missing, 12, 100, 105)

julia> aliveplayer = Player(level=23, health=1)
Player(missing, 23, 1, nothing)

julia> revive!(aliveplayer)
Player(missing, 23, 1, nothing)
```
