# مقدمة

القاموس مجموعة من العناصر، يتكوّن كل عنصر فيها من مفتاح وقيمة، بحيث إذا مرّرت مفتاحًا إلى إحدى طرق القاموس، أرجعت القيمة المرتبطة به. ويؤدي القاموس الدور نفسه الذي تؤديه الخرائط أو المصفوفات الترابطية في لغات أخرى.

يمكنك إنشاء قاموس على النحو التالي:

```csharp
new Dictionary<int, string>();
// Empty dictionary
```

أو

```csharp
new Dictionary<int, string>
{
    [1] = "One",
    [2] = "Two"
};

// Or

new Dictionary<int, string>
{
    {1, "One"},
    {2, "Two"}
};
// 1 => "One", 2 => "Two"
```

لاحظ أن نوعي المفتاح والقيمة جزء من تعريف القاموس.

بعد إنشاء القاموس، يمكنك إضافة مُدخلات إليه أو حذفها منه باستخدام طريقتيه المدمجتين `Add` و `Remove`.

تتم قراءة القيم في القاموس أو تحديثها بالفهرسة فيه باستخدام مفتاح:

```csharp
var numbers = new Dictionary<int, string>
{
   {1, "One"},
   {2, "Two"}
};

// Set the value of the element with key 2 to "Deux"
numbers[2] = "Deux";

// Get the value of the element with key 2
numbers[2];
// => "Deux"
```

يمكنك التحقق مما إذا كانت قيمة ما موجودة في القاموس باستخدام:

```csharp
var dict = new Dictionary<string, string>{/*...*/};
dict.ContainsKey("some key that exists");
// => true
```

عند التعداد على قاموس، يجري التعداد على أزواج المفتاح والقيمة فيه. وللقواميس أيضًا خصائص تتيح لك التعداد على مفاتيحها أو على قيمها.
