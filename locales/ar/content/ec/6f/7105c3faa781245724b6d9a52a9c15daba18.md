# مقدمة

## الخرائط

الخرائط في Elixir هي بنية البيانات المخصصة لتخزين المعلومات في أزواج من المفتاح والقيمة. وفي لغات أخرى، قد تُعرف هذه أيضًا باسم المصفوفات الترابطية (PHP)، أو الهاشات (Perl 5، Raku)، أو القواميس (Python).

يمكن أن تكون المفاتيح والقيم من أي نوع بيانات، لكن إذا كان المفتاح ذرة يمكننا استخدام صيغة مختصرة. ولا تضمن الخرائط ترتيب عناصرها عند الوصول إليها أو إرجاعها.

### الصيغ الحرفية

تُعرَّف الخريطة الفارغة ببساطة بالصيغة `%{}`. وإذا أردنا إضافة عناصر إلى خريطة حرفية، يمكننا استخدام صيغتين:

```elixir
# If the key is an atom:
%{atom_key: 1}

# If the key is a different type:
%{1 => :atom_value}

# You can even mix these if the atom form comes second:
%{"first_form" => :a, atom_form: :b}
```

ورغم أنه لا توجد صيغة قياسية، اختر أسلوبًا متسقًا لتمثيل أزواج المفتاح والقيمة الحرفية.

### دوال وحدة Map

توفر Elixir دوال كثيرة للعمل مع الخرائط في _وحدة Map_. بعض دوال _وحدة Map_ تتطلب تمرير دالة _مجهولة_ إليها للمساعدة في تحويل الخريطة.

## سمات الوحدة كثوابت

في Elixir، يمكننا تعريف سمات الوحدة التي يمكن استخدامها كثوابت في دوالنا.

```elixir
defmodule Example do
  # Defines the attribute as the value 1
  @constant_number 1

  def example_value() do
    # Returns the value 1
    @constant_number
  end
end
```

عند استخدام السمات لتعريف ثوابت الوحدة، يمكن أن تكون السمة أي تعبير يمكن تقييمه في وقت التصريف. وبعد التصريف، لا يمكن الوصول إلى سمات الوحدة لأنها تُوسَّع أثناء التصريف، على غرار وحدات الماكرو المعرّفة في لغات مثل C.
