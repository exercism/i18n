# نبذة

## أنواع البُنى

رأينا أنواع البُنى من قبل، وبالتذكير: `struct` تسلسل من عناصر مسمّاة تُسمّى _حقولًا_، ولكل حقل اسم ونوع.
يجب أن يكون اسم الحقل فريدًا داخل البنية.
يمكن مقارنة `Structs` بـ _الصنف_ في نمط البرمجة كائنية التوجه.

تنشئ بنية جديدة باستخدام الكلمتين المفتاحيتين `type` و `struct`، ثم تعرّف اسم الحقول ونوعها صراحةً كما في المثال أدناه.

```go
type StructName struct{
    field1 fieldType1
    field2 fieldType2
}
```

## الأنواع غير البنيوية

من الممكن أيضًا تعريف أنواع غير بنيوية تستخدمها كاسم بديل لتعريفات الأنواع المدمجة.

```go
type Name string
func SayHello(n Name) {
  fmt.Printf("Hello %s\n", n)
}
n := Name("Fred")
SayHello(n)
// Output: Hello Fred
```

كما يمكنك تعريف أنواع غير بنيوية مكوّنة من المصفوفات والخرائط.

```go
type Names []string
func SayHello(n Names) {
  for _, name := range n {
    fmt.Printf("Hello %s\n", name)
  }
}
n := Names([]string{"Fred", "Bill"})
SayHello(n)
// Output:
// Hello Fred
// Hello Bill
```
