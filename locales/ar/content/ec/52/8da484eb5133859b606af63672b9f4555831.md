# مقدمة

## عوامل المقارنة

تقارن [عوامل المقارنة][comparison-operators] بين قيمتين من النوع نفسه وتُرجع قيمة `Bool` (`true` أو `false`).
وإذا حاولت المقارنة بين قيمتين من نوعين مختلفين، فسيُنتج المصرِّف خطأ.

عوامل المقارنة القياسية في Swift هي:

| العامل | الوصف | مثال |
| -------- | ------------------------ | --------------- |
| `==`     | يساوي                 | `1 == 1` (صحيح) |
| `!=`     | لا يساوي                 | `1 != 2` (صحيح) |
| `<`      | أصغر من                | `4 < 5`  (صحيح) |
| `<=`     | أصغر من أو يساوي    | `4 <= 4` (صحيح) |
| `>`      | أكبر من               | `3 > 1`  (صحيح) |
| `>=`     | أكبر من أو يساوي | `2 >= 2` (صحيح) |

## جمل `if` و `else`

تُنفِّذ [الجملة الشرطية][conditional-statement] كودًا بناءً على ما إذا كان الشرط يُقيَّم إلى `true` أو `false`.
وأكثر الجمل الشرطية شيوعًا هي [جملة `if` الشرطية][if]، التي تنفّذ كتلة من الكود فقط عندما يكون شرطها `true`.
اكتب جملة `if` باستخدام الكلمة المفتاحية `if`، ثم يأتي بعدها الشرط وكتلة الكود المحصورة بين الأقواس المعقوفة:

```swift
let wheelCount = 4
if wheelCount == 4 {
    print("Your vehicle is a car")
}
// Prints "Your vehicle is a car"
```

ويمكنك إقران `if` بفرع `else` لتنفيذ كود بديل عندما يكون الشرط `false`:

```swift
let precipitationInMM = 0.5
if precipitationInMM > 0.5 {
    print("You will need an umbrella")
} else {
    print("You will not need an umbrella")
}
// Prints "You will not need an umbrella"
```

ولاختبار عدة شروط بالتتابع، اربط الجمل معًا باستخدام `else if`.
لا تتطلب جملة `if` وجود فرع `else`، لكن يمكنك تضمينه للتعامل مع الحالات التي لا يتحقق فيها أي من الشروط:

```swift
let favoriteFruit = "Apple"

if favoriteFruit == "Banana" {
    print("Your favorite fruit is a banana")
} else if favoriteFruit == "Orange" {
    print("Your favorite fruit is an orange")
} else if favoriteFruit == "Apple" {
    print("Your favorite fruit is an apple")
} else {
    print("Your favorite fruit is not a banana, orange, or apple")
}
// Prints "Your favorite fruit is an apple"
```

## تعبيرات `if`

في الإصدارات الحديثة من Swift، يمكن أيضًا استخدام جمل `if` كتعبيرات تُنتج قيمة.
يُقيَّم كل فرع إلى قيمة، مما يسهّل إسناد النتائج بشكل شرطي:

```swift
let cpuBits = 32
let architecture = if cpuBits == 64 {
    "x86_64"
} else {
    "x86_32"
}

print(architecture)
// Prints "x86_32"
```
