# نبذة

يعتمد الإدخال والإخراج في Factor على بروتوكول واحد يمكن لأي مصدر بيانات أو وجهة أن يطبّقه. أما التدفقات المضمّنة، وهي `<file-reader>` و`<file-writer>` و`<string-reader>` و`<string-writer>` ومقابس الشبكة ومصفوفات البايتات وأجهزة `tty`، فكلها أصناف تطبّق المجموعة نفسها من الدوال العامة الواردة من [`io`][io] وترث `disposable` من [`destructors`][destructors].

```factor
USING: io ;

GENERIC: stream-read1        ( stream -- elt/f )
GENERIC: stream-read-unsafe  ( n buf stream -- count )
GENERIC: stream-write1       ( elt stream -- )
GENERIC: stream-write        ( seq stream -- )
GENERIC: stream-flush        ( stream -- )
GENERIC: stream-element-type ( stream -- type )
```

`stream-read-unsafe` هي القراءة المجمّعة منخفضة المستوى: تملأ مخزنًا مؤقتًا يوفّره المستدعي وتُرجع عدد العناصر التي كُتبت. وتُبنى عليها `stream-read` و`stream-read-partial` العامتان، وهما تتولّيان تخصيص الذاكرة. ومعظم التدفقات التي يعرّفها المستخدم تطبّق إما `stream-read1` (حين تقرأ عنصرًا واحدًا في كل مرة) وإما `stream-read-unsafe` (حين يمكن القراءة على دفعات).

وتُرجع `stream-element-type` أحد رمزين مفردين: `+byte+` لتدفقات البايتات (قارئات الملفات، المقابس) و`+character+` لتدفقات المحارف (قارئات السلاسل النصية، أجهزة `tty`). والتدفق المُغلِّف عادةً ما يفوّض الأمر إلى التدفق الأساسي الذي يغلّفه.

## الانضمام إلى الخلائط

```factor
INSTANCE: my-stream input-stream
INSTANCE: my-stream output-stream
```

يمكن للصنف أن يكون أحدهما أو الآخر أو كليهما. وعند الانضمام إلى الخليط، تُوجّه الدوال الافتراضية في `input-stream` / `output-stream` الاستدعاء إلى صنفك، وهو نمط الخليط المفتوح نفسه الذي نجده في `set` من مفردات `sets`.

## إطار العمل `disposable`

تسجّل `new-disposable ( class -- disposable )` نسخة جديدة في نطاق المدمّرات الحالي، بحيث يكون التراجع نظيفًا إذا وقع استثناء في منتصف إعداد الموارد:

```factor
USING: destructors ;

[
    "log.txt" utf8 <file-writer>   ! registered automatically
    "log.txt" utf8 <file-reader>   ! and so is this one
    ! ... use them ...
] with-destructors
! both files closed even if an error is thrown above
```

`dispose` هي الكلمة العامة، أما `dispose*` فهي الدالة العامة التي يطبّقها الصنف. وعند تجاوز `dispose*` في صنف فرعي، ينبغي أن ينظّف حالته الخاصة ثم يتخلّص من أي موارد يملكها:

```factor
M: my-stream dispose* underlying>> dispose ;
```

ويضمن إطار العمل ألا تُنفَّذ `dispose*` أكثر من مرة واحدة لكل كائن، فالاستدعاءات المتكررة لـ `dispose` لا تفعل شيئًا.

## أدوات وصول محدودة النطاق

تُهيّئ ثلاث دوال تجميعية التدفق العام الحالي للإدخال والإخراج الذي تستخدمه `print` و`read1` وغيرهما:

```
with-input-stream   ( stream quot -- )    ! reads in quot use stream
with-output-stream  ( stream quot -- )    ! writes in quot use stream
with-disposal       ( disposable quot -- )! generic — any disposable
```

وكل واحدة منها تتخلّص من المورد عند الخروج، حتى لو رفع المقطع استثناءً. وبهذه الطريقة يستخدم معظم الكود تدفقًا مخصصًا بدل تمريره في كل استدعاء.
