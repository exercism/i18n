# مقدمة

تذكّر أنّ `jq` يدعم أنواع البيانات نفسها التي يدعمها JSON.
يصف JSON **السلاسل النصية** بأنها:

> السلسلة النصية هي تسلسل من صفر أو أكثر من محارف يونيكود، محاطة بعلامات اقتباس مزدوجة، باستخدام تسلسلات الهروب بالشرطة المائلة العكسية.

## تسلسلات الهروب

داخل السلسلة النصية، استخدم محرف الشرطة المائلة العكسية لتضمين محارف "خاصة":

- `\"` علامة اقتباس حرفية،
- `\\` شرطة مائلة عكسية حرفية،
- محارف المسافات البيضاء `\n` و`\t` و`\r` و`\f` و`\b`
- محارف يونيكود `\uAAAA` حيث `A` رقم ست عشري

## طول السلسلة النصية

لإيجاد عدد المحارف، استخدم دالة `length`.

```sh
$ jq -cn --args  '$ARGS.positional[] | length' "Hello world!" "❄🌡🤧🤒🏥🕰😀"
12
7
```

## السلاسل النصية الفرعية

يمكن استخدام تعبير **التقطيع** لاستخراج سلاسل نصية فرعية.
الصيغة هي `.[i:j]`.
السلسلة النصية الفرعية المُرجَعة طولها `j - i`، وتُرجع محارف من الفهرس `i` (شاملاً إياه) إلى الفهرس `j` (غير شامل له).
يمكن أن يكون أيٌّ من الفهرسَين سالباً، وفي هذه الحالة يُحسب تنازلياً من نهاية السلسلة النصية.
يمكن حذف أيٍّ من الفهرسَين، وفي هذه الحالة يشير إلى بداية السلسلة النصية أو نهايتها.
الفهارس تبدأ من الصفر.

```jq
"abcdefghij"[3:6]   # => "def"
"abcdefghij"[3:]    # => "defghij"
"abcdefghij"[:-2]   # => "abcdefgh"
```

## الدمج

استخدم `+` لدمج السلاسل النصية:

```jq
"Hello" + " " + "world!"
# => "Hello world!"
```

استخدم `add` عند التعامل مع مصفوفة من السلاسل النصية:

```jq
["Hello", " ", "world!"] | add
# => "Hello world!"
```

## التقسيم والضم

يستخدم التقسيم دالة `split/1` أو العامل `/`:

```jq
"Hello beautiful world!" | split(" ")   # => ["Hello", "beautiful", "world!"]
```

```jq
"Hello beautiful world!" / " "          # => ["Hello", "beautiful", "world!"]
```

عكس `split/1` هو `join/1`.

غالباً ما نحتاج إلى تحويل سلسلة نصية إلى مصفوفة من المحارف.
هناك طريقتان لفعل ذلك:

1. التقسيم عند سلسلة نصية فارغة

   ```jq
   "Hi friend 😀" / ""   # => ["H","i"," ","f","r","i","e","n","d"," ","😀"]
   ```

1. `explode` إلى مصفوفة من _نقاط الترميز_

   ```jq
   "Hi friend 😀" | explode   # => [72,105,32,102,114,105,101,110,100,32,128512]
   ```

   `implode` هو عكس `explode`.

## إيجاد فهرس سلسلة نصية فرعية

استخدم دالة `index/1`؛ فالفهرس يبدأ من الصفر.

```jq
"hello" | index("el")'   # => 1
```

إذا لم تكن السلسلة النصية الفرعية موجودة في السلسلة النصية، فالناتج هو `null`

```jq
"hello" | index("elk")   # => null
```

## الإقحام في السلسلة النصية

داخل السلسلة النصية، يُدرج التسلسل `\(expression)` _ناتجَ_ ذلك التعبير [في السلسلة النصية][interpolate]:

```jq
"The current datetime is \(now | strflocaltime("%c"))"   # => "The current datetime is Wed Nov 16 17:06:33 2022"
```

## تحويل حالة الأحرف

استخدم دالتَي `ascii_downcase` و`ascii_upcase`.

## التعبيرات النمطية

يقدّم `jq` دعماً غنياً للتعبيرات النمطية: سيكون هذا موضوع درس لاحق.
