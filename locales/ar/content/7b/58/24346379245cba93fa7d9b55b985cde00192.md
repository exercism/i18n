# مقدمة

[حلقات `repeat-while`][repeat-loops] تشبه حلقات `while`، لكن مع فرق أساسي واحد: يحدث فحص الشرط *بعد* تنفيذ جسم الحلقة وليس قبله.
ونتيجة لذلك، تضمن حلقة `repeat-while` تنفيذ كتلة الكود الخاصة بها مرة واحدة على الأقل.

```swift
repeat {
    print("This runs at least once")
} while false

print("Loop done")

// Prints:
// This runs at least once
// Loop done
```

[repeat-loops]: https://docs.swift.org/swift-book/LanguageGuide/ControlFlow.html#ID126
