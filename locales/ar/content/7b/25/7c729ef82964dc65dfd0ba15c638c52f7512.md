# مقدمة

الأنواع المخصصة هي الطريقة التي تُعرَّف بها أنواع البيانات الجديدة في Gleam. ويمكن أن تحتوي على عدة _حالات_، لكل منها اسم خاص بها.

```gleam
pub type Season {
  Spring
  Summer
  Autumn
  Winter
}
```

يمكن لكل حالة من حالات النوع المخصص أن تحمل بعض البيانات، ويمكن أن تحمل الحالات المختلفة أنواعًا مختلفة من البيانات. وعندما تحمل الحالة بيانات، فإنها تُسمى _سجلًا_.

```gleam
pub type Number {
  SomeInt(Int)
  SomeFloat(Float)
  Invalid
}
```

يمكنك إنشاء قيمة لحالة معينة بالإشارة إلى اسمها إذا لم تكن تحتوي على بيانات إضافية (`Spring`)، أو باستدعائها كدالة إذا كانت تحتوي عليها (`SomeInt(2)`).

```gleam
let spring = Spring
let integer_two = SomeInt(2)
```

تتمتع الأنواع المخصصة، شأنها شأن كل شيء في Gleam، بـ _التساوي البنيوي_، أي أن أي قيمتين من الحالة نفسها وبالبيانات نفسها متكافئتان.

```gleam
Spring == Spring // -> True
Spring == Autumn // -> False
SomeInt(2) == SomeInt(2) // -> True
SomeInt(2) == SomeFloat(2.0) // -> False
```

يمكن مطابقة الأنماط على حالات النوع المخصص باستخدام تعبيرات `case`.

```gleam
import gleam/int
import gleam/float

pub fn describe(flexible_number: Number) -> String {
  case flexible_number {
    SomeFloat(f) -> "Float: " <> float.to_string(f)
    SomeInt(i) -> "Int: " <> int.to_string(i)
    Invalid -> "Neither a float nor an int"
  }
}
```
