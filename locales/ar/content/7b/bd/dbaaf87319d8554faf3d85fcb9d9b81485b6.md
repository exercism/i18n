# مقدمة

لا يمتلك Cairo نوعًا أصليًا للسلاسل النصية، لكنه يوفر طريقتين للتعامل معها: السلاسل النصية القصيرة باستخدام علامات الاقتباس المفردة، و`ByteArray` باستخدام علامات الاقتباس المزدوجة.

السلسلة النصية القصيرة هي سلسلة نصية بترميز ASCII يُرمَّز فيها كل حرف في بايت واحد.

النوع الذي يستخدمه Cairo افتراضيًا للسلاسل النصية القصيرة هو `felt252`، ما يجعل طولها الأقصى 31 حرفًا فقط.

```rust
// below are different ways to write the same value
let name: felt252 = 'Jane';     // short string format
let name: felt252 = 0x4a616e65; // byte format
let name: felt252 = 1247899237; // decimal format
```

من الناحية التقنية، يمكن تمثيل أي نوع عدد صحيح أصغر من `felt252` باستخدام صيغة السلسلة النصية القصيرة.

```rust
// all of the below are equal u8 values, they are just written using different formats!
let lowercase_a_in_ascii: u8 = 'a';  // short string format
let lowercase_a_in_ascii: u8 = 0x61; // byte format
let lowercase_a_in_ascii: u8 = 97;   // decimal format
```

أما السلاسل النصية الأطول من 31 حرفًا، فيوفر لها Cairo النوع `ByteArray`، الذي له طول غير محدود.

```rust
let long_string: ByteArray = "this is a string which has more than 31 characters";
```

يمكن دمج قيم ByteArray باستخدام العامل `+`:

```rust
"Jane" + " " + "Austen"
// => "Jane Austen"
```

تحتاج بعض الأحرف الخاصة إلى شرطة مائلة عكسية قبلها، مثل `\t` لعلامة الجدولة و`\n` لسطر جديد داخل السلاسل النصية.

```rust
"How is the weather today?\nIt's sunny"  
// =>
// How is the weather today?
// It's sunny
```

يمكنك حتى الوصول إلى بايتات فردية داخل ByteArray باستخدام فهرسه.

لكن انتبه، فنوع البايت المُرجَع هو `u8` وليس `ByteArray`!

```rust
let hello: ByteArray = "Hello World!";
let exclamation_mark: u8 = hello[11];
// => 33
```

توفر المكتبة الأساسية العديد من الطرق والعوامل المفيدة للتعامل مع قيم ByteArray.

لمزيد من المعلومات حول طرق ByteArray، اطّلع على [توثيق ByteArrayTrait][docs].

إليك بعض الأمثلة:

```rust
let name: felt252 = 'Jane';
let mut greeting: ByteArray = "Welcome ";

// append_word appends a single word of a given number of bytes to the end of the ByteArray 
greeting.append_word(name, 4);
// => "Welcome Jane"

// rev returns a ByteArray with the all characters reversed
let rev_greeting = greeting.rev();
// => "enaJ emocleW"
```

[docs]: https://docs.swmansion.com/scarb/corelib/core-byte_array-ByteArrayTrait.html
