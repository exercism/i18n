لدى Elixir اصطلاحات محددة للتسمية، من بينها كيفية تسمية [الدوال التي تُرجع قيمة منطقية](https://hexdocs.pm/elixir/naming-conventions.html#trailing-question-mark-foo):

> الدوال التي تُرجع قيمة منطقية تُسمّى بعلامة استفهام في آخر الاسم.

```elixir
# this is the expected name of functions that return a boolean

%{expected}

# this is the current name

%{actual}
```

لاحظ أن الحرّاس، وبعض الدوال والماكرو المدمجة التي تُرجع قيمًا منطقية وتصلح للاستخدام في الحرّاس، تتبع اصطلاحًا آخر وتُسمّى ببادئة `is_` (`def is_integer`، `defguard is_foo`، `defmacro is_foo`). ولا يجوز الخلط بين الاصطلاحين.
