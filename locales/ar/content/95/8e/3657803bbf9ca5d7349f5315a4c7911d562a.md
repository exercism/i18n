# مقدمة

في Go، يمكنك التكرار على `slice` باستخدام `for` وفهرس، أو يمكنك استخدام `range`. كما يسمح لك `range` بالتكرار على `map`.

كل تكرار يُرجع قيمتين: الفهرس/المفتاح ونسخةً من العنصر عند ذلك الفهرس/المفتاح.

## التكرار على `slice`

سهل للغاية، فالحلقات على `slice` مرتّبة كما هو متوقع.

```go
xi := []int{10, 20, 30}
for i, x := range xi {
  fmt.Println(i, x)
}
// outputs:
// 0, 10
// 1, 20
// 2, 30
```

## التكرار على `map`

التكرار على `map` يطرح مشكلة جديدة.
فالترتيب الآن عشوائي.

```go
hash := map[int]int{9: 10, 99: 20, 999: 30}
for k, v := range hash {
  fmt.Println(k, v)
}
// outputs, for example:
// 99 20
// 999 30
// 9 10
```

~~~~exercism/note
قد يبدو المخرَج أعلاه غير صحيح، إذ يتوقع المرء أن يكون أول زوج مفتاح/قيمة عند تعريف `map`، أي `9 10`، هو أول ما يُطبع لا آخره.
لكن `map` غير مرتّبة بطبيعتها، فليس فيها زوج مفتاح/قيمة أول أو أخير.
ولهذا السبب، عند التكرار على مدخلات `map`، يكون الترتيب الذي ستُزار به المدخلات عشوائيًا ولا يتبع أي نمط محدّد.
هذا يعني أن المخرَج أعلاه ممكن، لكنه قد يختلف عمّا ستحصل عليه إذا جرّبت تشغيل هذا بنفسك.
لمعرفة المزيد عن هذا، راجع [مواصفات لغة Go: جملة `range`](https://go.dev/ref/spec#RangeClause).
~~~~

## التكرار مع حذف المفتاح أو القيمة

في Go، المتغير غير المستخدم يؤدي إلى خطأ في وقت البناء.
أحيانًا تحتاج إلى القيمة فقط، كما في المثال الأول:

```go
xi := []int{10, 20, 30}
for i, x := range xi {
  fmt.Println(x)
}
// Go build failed: i declared but not used
```

يمكنك استبدال `i` بـ `_`، وهذا يخبر المترجم بأننا لا نستخدم تلك القيمة:

```go
xi := []int{10, 20, 30}
for _, x := range xi {
  fmt.Println(x)
}
// outputs:
// 10
// 20
// 30
```

إذا أردت طباعة الفهرس فقط، يمكنك استبدال `x` بـ `_`،
أو ببساطة حذف التعريف:

```go
xi := []int{10, 20, 30}
// for i, _ := range xi {
for i := range xi {
  fmt.Println(i)
}
// outputs:
// 0
// 1
// 2
```

## تعريف الأنواع

يُنشئ تعريف النوع نوعًا جديدًا مُسمّى، متميّزًا عن كل نوع آخر، حتى لو كان له النوع الأساسي نفسه.

```go
type File []bool
```

يشير `File` هنا إلى عمود رأسي واحد على رقعة الشطرنج، يُرمز إليه عادةً بالحروف من A إلى H.
وتُمثَّل كل خانة في هذا العمود بقيمة منطقية تحدّد ما إذا كانت مشغولة أم لا.
وبعد أن صار `File` معرَّفًا، يمكننا استخدامه داخل تعريفات أخرى:

```go
type Chessboard map[string]File

board := Chessboard{
    "A": File{true, false, true},
    "B": File{false, true, false},
}
```

يربط `Chessboard` معرّفات الأعمدة بقيم `File`.
وكل `File` عبارة عن `slice` من القيم المنطقية تُمثّل خانات عمود واحد على رقعة الشطرنج.
وبدون تعريفات الأنواع هذه، سيكون `board` من نوع `map[string][]bool`، وهذا يجعل فهم ما نمثّله أصعب.
