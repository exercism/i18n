# نبذة

عادةً ما يتضمّن تعريف المجموعة عنصرًا نائبًا بين قوسين زاويين، هو `T` غالبًا حسب العُرف. وتُسمّى مثل هذه المجموعة نوعًا عامًّا. وهذا يسمح لمن يستخدم المجموعة بتحديد نوع العناصر التي ستُخزَّن فيها. في مثال الكود أعلاه، نُنشئ نسخةً من مصفوفة من السلاسل النصية.

نجعل الصنف أو الدالة **عامًّا** باستخدام السمة `@:generic`. وهذا يجعل المترجم يعرّف الصنف أو الدالة على أنهما عامّان:

```haxe
@:generic
class MyValue<T> {
  public var value:T;

  public function new(value:T) {
    this.value = value;
  }
}

var a = MyValue<String>("Hello");
trace(a.value); // Hello
```
