# مقدمة

## الاستثناءات

توفر الاستثناءات في C# طريقة منظمة وموحدة وآمنة من حيث الأنواع للتعامل مع حالات الخطأ التي تحدث أثناء التنفيذ. وتُعد المعالجة السليمة للاستثناءات والأخطاء أمرًا مهمًا عند محاولة منع تعطّل التطبيق.

في C#، يشترك جميع الاستثناءات في أن الصنف `System.Exception` هو نوعها الأساسي. وهو يحتوي على خصائص مهمة مثل `Message`، التي تحوي وصفًا مقروءًا للبشر لسبب رمي الاستثناء.

للإشارة إلى وجود خطأ في جزء معيّن من الكود، يجب إنشاء كائن استثناء جديد ثم رميه باستخدام الكلمة المفتاحية `throw`:

```csharp
using System;
static int Square(int number)
{
    if (number >= 46341)
    {
        throw new ArgumentException($"Argument {number} cannot be higher than 46340 as its' square doesn't fit into int type.");
    }
    return number * number;
}
```

عند رمي استثناء، تتولى بيئة التشغيل مهمة البحث عن قطعة من الكود مسؤولة عن معالجة ذلك الاستثناء. وإذا لم يُعثر على معالج مناسب، تعرض بيئة التشغيل رسالة الاستثناء غير المعالَج إضافةً إلى إيقاف تنفيذ البرنامج.

لإنشاء معالج لاستثناء، تستخدم C# عبارة `try-catch`، والتي تتكون من كتلة `try` وواحدة أو أكثر من جمل `catch`. يجب أن تحتوي كتلة `try` على الكود الذي قد يؤدي إلى رمي الاستثناء وأن تحرسه. ويجب أن تحتوي جمل `catch` على الكود الذي يعالج سلوك البرنامج بعد وقوع الخطأ. ومن المهم ملاحظة أن ترتيب الاستثناءات مهم بعد كتلة `try`، لأنه عند إدراج عدة استثناءات، تُنفَّذ أول جملة `catch` مطابقة.

```csharp
try
{
   if (number == 42)
   {
       throw new ArgumentException("The number cannot be equal to 42.", "number");
   }

   if (number < 0)
   {
      throw new ArgumentOutOfRangeException("number", "The number cannot be negative.");
   }

    // Process number ...
}
catch (ArgumentOutOfRangeException e)
{
    Console.WriteLine($"Number is out of range: {e.Message}.");
}
catch (ArgumentException)
{
    Console.WriteLine("Invalid number.");
}
```
