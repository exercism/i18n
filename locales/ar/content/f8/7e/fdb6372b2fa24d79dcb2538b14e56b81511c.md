# نبذة

## الدوال

في Gleam تُعرَّف الدوال باستخدام صيغة `pub fn`.

```gleam
pub fn add(x: Int, y: Int) -> Int {
  x + y
}
```

تأخذ هذه الدالة وسيطين، كلاهما من النوع `Int`، وتُرجع قيمة من النوع `Int`. لا توجد كلمة مفتاحية `return` في Gleam، فقيمة آخر تعبير في الدالة _تُرجع ضمنيًا_ دائمًا.

تحديدات النوع للوسائط ونوع الإرجاع اختيارية، وستتحقق Gleam دائمًا من أنواع الكود بالكامل. عادةً ما يضيف مبرمجو Gleam تحديدات النوع إلى دوالهم من أجل الوضوح، لكن يمكنك حذفها إن أردت.

```gleam
pub fn add(x, y) {
  x + y
}
```

يمكن استدعاء دالة باستخدام صيغة `function_name(argument1, argument2)`.

```gleam
pub fn double(x: Int) -> Int {
  // Call the add function defined above
  add(x, x)
}
```

## المتغيرات

في Gleam تُعرَّف المتغيرات باستخدام صيغة `let name = expression`.

```gleam
pub fn main() {
  let count = 1
}
```

يمكن تعريف المتغيرات مع تحديدات النوع. وكما هو الحال مع وسائط الدالة، فهي اختيارية، غير أن معظم مبرمجي Gleam سيحذفون تحديدات النوع للمتغيرات.

```gleam
pub fn main() {
  let count: Int = 1
}
```

## السلاسل النصية الحرفية

في Gleam تُكتب السلاسل النصية باستخدام علامات الاقتباس المزدوجة.

```gleam
pub fn greeting() {
  "Hello, world!"
}
```

## تعليقات الكود

يمكن استخدام التعليقات لترك ملاحظات للمبرمجين الآخرين الذين يقرؤون الكود المصدري. التعليقات في Gleam أسطر مفردة تسبقها `//`.

```gleam
pub fn main() {
  // This is a comment
  let x = 1
}
```
