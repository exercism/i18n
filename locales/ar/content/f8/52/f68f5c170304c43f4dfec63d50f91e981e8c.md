# مقدمة

JavaScript لغة ديناميكية، تدعم أساليب البرمجة الكائنية والأمرية والتعريفية (مثل البرمجة الوظيفية).

## المتغيرات

توجد عدة طرق أساسية لإسناد القيم إلى الأسماء في JavaScript، إما باستخدام المتغيرات أو الثوابت.
في Exercism، تُكتب المتغيرات دائمًا بنمط [camelCase][wiki-camel-case]، وتُكتب الثوابت بنمط [SCREAMING_SNAKE_CASE][wiki-snake-case].
لا يوجد دليل رسمي يجب اتباعه، ولكل شركة أو مؤسسة دليل أسلوب خاص بها.
_لا تتردد في كتابة المتغيرات بالطريقة التي تناسبك_.
وميزة كتابتها بالطريقة التي أُعدّت بها التمارين هي أنها ستُبرَز بشكل مختلف في واجهة الويب وفي معظم بيئات التطوير المتكاملة.

يمكن تعريف المتغيرات في JavaScript باستخدام الكلمة المفتاحية [`const`][mdn-const] أو [`let`][mdn-let] أو [`var`][mdn-var].

يمكن للمتغير أن يشير إلى قيم مختلفة على مدار عمره عند استخدام `let` أو `var`.
على سبيل المثال، يمكن تعريف `myFirstVariable` وإعادة تعريفه مرات عديدة باستخدام عامل الإسناد `=`:

```javascript
let myFirstVariable = 1;
myFirstVariable = 'Some string';
myFirstVariable = new SomeComplexClass();
```

وعلى عكس `let` و`var`، لا يمكن إسناد قيمة إلا مرة واحدة للمتغيرات المعرّفة بـ `const`.
وهذا ما يُستخدم لتعريف الثوابت في JavaScript.

```javascript
const MY_FIRST_CONSTANT = 10;

// Can not be re-assigned.
MY_FIRST_CONSTANT = 20;
// => TypeError: Assignment to constant variable.
```

## تعريفات الدوال

في JavaScript، تُغَلَّف وحدات الوظائف في _الدوال_، وعادةً ما تُجمَّع الدوال معًا في الملف نفسه إذا كانت تنتمي إلى بعضها.
لهذه الدوال معاملات (حتى تستقبل الوسائط)، ويمكنها أن _تُرجع_ قيمة باستخدام الكلمة المفتاحية `return`.
تُستدعى الدوال باستخدام صيغة `()`.

```javascript
function add(num1, num2) {
  return num1 + num2;
}

add(1, 3);
// => 4
```

في هذا المثال، اسم الدالة هو `add`.
ولها معاملان، `num1` و`num2`.
وهي تُرجع قيمة: ناتج التعبير `num1 + num2`

ثم تُستدعى الدالة `add` باستخدام وسيطين: `1` و`3`.
ونتيجة الدالة، أي القيمة المُرجَعة، هي `4`.

```exercism/note
💡 في JavaScript توجد _طرق_ مختلفة كثيرة لتعريف دالة.
بعض هذه الطرق الأخرى تبدو مختلفة عن استخدام الكلمة المفتاحية `function`.
يحاول المسار تقديمها تدريجيًا، لكن إن كنت تعرفها بالفعل، فلا تتردد في استخدام أي منها.
في معظم الحالات، استخدام إحداها أو الأخرى ليس أفضل ولا أسوأ.
```

## إتاحة الكود لملفات أخرى

لجعل `function` أو ثابت أو متغير متاحًا في _ملفات أخرى_، يجب [تصديره][mdn-export] باستخدام الكلمة المفتاحية `export`.
ويمكن لملف آخر بعد ذلك أن [يستورد][mdn-import] هذه العناصر باستخدام الكلمة المفتاحية `import`.
ويُعرف هذا أيضًا بنظام الوحدات.

ومن الأمثلة الرائعة على ذلك طريقة عمل جميع الاختبارات.
لكل تمرين ملف واحد على الأقل، مثل `lasagna.js`، يحتوي على _التنفيذ_.
يُصدَّر _التنفيذ_ من الملف، مما يجعله متاحًا للاستيراد في ملف آخر.
بالإضافة إلى ذلك، يوجد ملف آخر على الأقل، مثل `lasagna.spec.js`، يحتوي على _الاختبارات_.
يستورد هذا الملف الكيانات العامة (المُصدَّرة بـ `export`) لاختبار التنفيذ:

```javascript
// file.js
export const MY_VALUE = 10;

export function add(num1, num2) {
  return num1 + num2;
}

// file.spec.js
import { MY_VALUE, add } from './file';

add(MY_VALUE, 5);
// => 15
```
