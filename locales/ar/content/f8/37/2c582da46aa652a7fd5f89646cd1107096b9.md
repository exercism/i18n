# مفاهيم Luhn

Luhn هي خوارزمية تحقق تجمع بين التأكيدات النصية والعددية. تفضّل حلول Rust الأساليب الدالية.

## العموميات

### الأنواع الأولية

- `&str` و `char`
  - يجب أن يستوعب الطلاب التمييز بين `char` المفرد و `&str` حتى يستبعدوا أجزاءً من المدخلات المقدَّمة أو يضمّنوها بشكل صحيح
- عدد صحيح
  - فهم الأعداد الصحيحة مهم لإجراء التحقق العددي المطلوب
- قيم منطقية
  - أساسية لتأكيدات الهوية والمقارنات النهائية

### ميزات المكرِّر

- التسلسل
  - من المهم هنا فهم سلاسل المكرِّر لحل المسألة بطريقة مرتّبة.
- `map`، `filter`، turbofish وربما `fold`
  - الجمع بين map و filter يوفّر نمط تصميم أساسي لمشكلات التحقق كهذه. وتتميز حلول `fold` كذلك بمزيد من الإيجاز.
  - يُحتاج إلى turbofish في بعض الحلول لإخبار Rust بنوع القيمة التي تُنشئها من تعبير متسلسل

## مثال الحل 1

[حل](https://exercism.org/tracks/rust/exercises/luhn/solutions/7038c269a4af4f5b95ca35a99c5c3b4d) york

```rust
pub fn is_valid(code: &str) -> bool {
    code.chars()
        .filter(|c| !c.is_ascii_whitespace())
        .rev()
        .try_fold((0, 0), |(num_count, sum), c| {
            c.to_digit(10).map(|x| {
                let double = x * (num_count % 2 + 1);
                let double = if double > 9 { double - 9 } else { double };
                (num_count + 1, sum + double)
            })
        })
        .map_or(false, |(num_count, sum)| num_count >= 2 && sum % 10 == 0)
}
```

## مثال الحل 2

الحل القياسي

```rust
pub fn is_valid(candidate: &str) -> bool {
    if candidate.chars().filter(|c| c.is_ascii_digit()).take(2).count() <= 1
        || candidate.chars().any(|c| !c.is_ascii_digit() && c != ' ')
    {
        return false;
    }

    candidate
        .chars()
        .filter_map(|c| c.to_digit(10))
        .rev()
        .enumerate()
        .map(|(index, digit)| if index % 2 == 0 { digit } else { digit * 2 })
        .map(|digit| if digit > 9 { digit - 9 } else { digit })
        .sum::<u32>()
        % 10
        == 0
}
```
