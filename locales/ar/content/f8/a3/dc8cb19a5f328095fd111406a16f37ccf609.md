# تعليمات خاصة بـ SQLite

* يحتوي العمود **candidates** على قائمة من السلاسل النصية مُرمّزة بصيغة JSON.
  مثال:
  ```json
  ["stone","tones","banana","tons","notes","Seton"]
  ```
* يجب أن يحتوي العمود **result** أيضًا على قائمة من السلاسل النصية مُرمّزة بصيغة JSON.

## مخطط الجدول

```sql
CREATE TABLE anagram (
  subject    TEXT NOT NULL,
  candidates TEXT NOT NULL,     -- json array of strings
  result     TEXT               -- json array of strings
);
```
