# مقدمة

## الوسائط المُسمّاة

أحيانًا عندما تأخذ دالة وسائط كثيرة، قد يصعب تذكّر الترتيب الذي ينبغي تمريرها به. ولتحسين قابلية القراءة، تسمح Gleam بتسمية الوسائط باسم.

لتسمية وسيط، اكتب اسم التسمية قبل اسم الوسيط، مفصولًا بمسافة.

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

عند استدعاء دالة ذات وسائط مُسمّاة، يمكن تمرير الوسائط بأي ترتيب. وكل من هذه الاستدعاءات لـ `replace` متكافئة:

```gleam
replace(in: "🍔🍔🍔", each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

التسميات اختيارية دائمًا. وحتى لو كانت للدالة وسائط مُسمّاة، فيمكن استدعاؤها بدون تسميات.

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```
