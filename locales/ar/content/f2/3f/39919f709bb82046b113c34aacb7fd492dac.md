# نبذة

_السلسلة النصية_ هي نوع البيانات في JavaScript المخصّص لتخزين البيانات النصية.
لا يوجد نوع بيانات منفصل للحرف الواحد.

## إنشاء سلسلة نصية

تنشئ سلسلة نصية [حرفية][literal] بوضع النص بين علامتي اقتباس مفردتين أو مزدوجتين.
في Exercism، تُستخدم علامات الاقتباس المفردة.

<!-- prettier-ignore-start -->
```javascript
'Hello, World!'
"Hello, World!"
```
<!-- prettier-ignore-end -->

بعض الحروف الخاصة في النص تحتاج إلى شرطة مائلة عكسية `\` قبلها، راجع [متتاليات الهروب في MDN][mdn-escape-sequences].

<!-- prettier-ignore-start -->
```javascript
const text = 'I\'m having fun.\nWhat about you?';
console.log(text);
// => I'm having fun.
// => What about you?
```
<!-- prettier-ignore-end -->

إلى جانب علامات الاقتباس المفردة والمزدوجة، يمكنك أيضًا إنشاء سلسلة نصية بوضع النص بين علامتي الاقتباس العكسية.
يتيح لك هذا التركيب تضمين علامات الاقتباس المفردة أو المزدوجة، وحتى الأسطر الجديدة، دون الحاجة إلى تهريبها.
كما يتيح تضمين التعبيرات، راجع [القوالب النصية][mdn-template-strings] لمزيد من التفاصيل.

```javascript
`A multi-line string
with 'single quotes'
and "double quotes"`;
```

## السلاسل النصية كمصفوفات من الحروف

يمكن التعامل مع السلسلة النصية على أنها مصفوفة من الحروف، حيث يحمل الحرف الأول الفهرس `0`.
يمكنك الوصول إلى حرف بعينه في السلسلة النصية باستخدام الأقواس المربعة وفهرس الحرف الذي تريد استرجاعه.
بدلًا من ذلك، هناك أيضًا الطريقة `charAt`.

```javascript
'cat'[1];
// => 'a'

'cat'.charAt(2);
// => 't'
```

يمكنك معرفة عدد الحروف في سلسلة نصية عبر الوصول إلى الخاصية `length`.

```javascript
'cat'.length;
// => 3
```

## دمج السلاسل النصية والطرق

أبسط أسلوب لدمج السلاسل النصية هو استخدام عامل الجمع `+`.

```javascript
'I like' + ' ' + 'cats.';
// => "I like cats."
```

توفّر السلاسل النصية الكثير من الطرق المساعدة، راجع [وثائق MDN حول طرق السلاسل النصية][mdn-string-methods] للحصول على القائمة الكاملة.
تعرض القائمة التالية بعض الأدوات المساعدة الشائعة الاستخدام.

- [`toUpperCase`][mdn-to-upper-case] و[`toLowerCase`][mdn-to-lower-case] - تغيير حالة جميع الحروف
- [`trim`][mdn-trim] - إزالة المسافات البيضاء في البداية والنهاية
- [`includes`][mdn-includes] و[`startsWith`][mdn-starts-with] و[`endsWith`][mdn-ends-with] - تحديد ما إذا كانت سلسلة نصية أخرى جزءًا من السلسلة النصية المعطاة
- [`slice`][mdn-slice] - استخراج مقطع من السلسلة النصية

## السلاسل النصية غير قابلة للتغيير

لن يؤدي تطبيق الطرق المذكورة أعلاه إلى تغيير السلسلة النصية الأصلية أبدًا. بدلًا من ذلك، تُنشأ سلسلة نصية جديدة وتُرجَع.
السلاسل النصية (وأنواع البيانات الأولية الأخرى) غير قابلة للتغيير في JavaScript.
وهذا يعني أيضًا أنك لا تستطيع إسناد حرف مختلف عند فهرس معيّن باستخدام صيغة الأقواس الموضّحة أعلاه (كما تفعل مع المصفوفات).

```javascript
const str = 'cat';
str[1] = 'u'; // fails silently
console.log(str);
// => 'cat'
```
