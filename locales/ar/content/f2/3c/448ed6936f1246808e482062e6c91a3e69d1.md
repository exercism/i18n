# تجاهل

## خيارات إضافية في سطر أوامر `jq`

ستلاحظ خيارات إضافية لـ `jq` في الاختبارات.

```sh
run jq -s -R -c -f minesweeper.jq << 'END_INPUT'
```

ما هي هذه الخيارات؟

- `-s`

  هذا هو وضع "slurp".
  فبدلًا من التعامل مع المدخلات كتدفق من كائنات JSON،
  ستُسحب كل المدخلات إلى مصفوفة.

  ```sh
  $ seq 5 | jq -c '.'
  1
  2
  3
  4
  5
  $ seq 5 | jq -s -c '.'
  [1,2,3,4,5]
  ```

- `-R`

  ربما رأيت الخيار `-r` من قبل، وهو يُخرج السلاسل النصية "الخام" (بدون علامات الاقتباس).
  هذا الخيار هو العكس تمامًا:
  فكل سطر من المدخلات يُعامَل كسلسلة نصية.

  مثالان:

  ```sh
  $ seq 5 | jq -R -c .
  "1"
  "2"
  "3"
  "4"
  "5"

  $ echo 42 | jq '. * 2'      # input is a JSON number
  84
  $ echo 42 | jq -R '. * 2'   # input is a JSON string
  "4242"
  ```

عندما تجمع هذين الخيارين معًا، _لن_ تحصل على مصفوفة من السلاسل النصية، بل ستحصل على المدخلات كاملة في صورة سلسلة نصية واحدة، بما يشمل محارف السطر الجديد في نهاية كل سطر.

```sh
$ seq 5 | jq -s -R -c .
"1\n2\n3\n4\n5\n"
```

التعامل مع هذا جزء من تحدّي هذا التمرين.
