# مقدمة

[`Set`][set-docs] مجموعة غير مرتبة، وعلى عكس `List`، فهي مضمونة بألّا تحتوي على أي قيم مكررة.

يحدد معامل النوع العام للواجهة `Set` نوع العناصر التي تحتوي عليها:

```java
Set<Integer> ints = Set.of(1, 2, 3);
Set<String> strings = Set.of("alpha", "beta", "gamma");
Set<Object> mixed = Set.of(1, false, "foo");
```

لاحظ أن الطريقة `Set.of()` تُنشئ نسخة `Set` [*غير قابلة للتعديل*][unmodifiable-set-docs].
ومحاولة استدعاء طرق مثل `add` و`remove` على هذه النسخة ستؤدي إلى استثناء أثناء التشغيل.

لإنشاء `Set` قابل للتعديل، عليك إنشاء نسخة من صنف يُنفّذ الواجهة `Set`.
والصنف المدمج الأكثر استخدامًا الذي يُنفّذ هذه الواجهة هو الصنف [`HashSet`][hashset-docs].

```java
Set<Integer> ints = new HashSet<>();
```

تمتد الواجهة `Set` من الواجهتين [`Collection`][collection-docs] و[`Iterable`][iterable-docs]، ولذلك تتشارك الكثير من الطرق مع أنواع أخرى من المجموعات.
لكن ثمة فرق ملحوظ عن الواجهة `Collection`، وهو أن طرقًا مثل `add` و`remove` تُرجع قيمة `boolean` (بدلًا من `void`) تُشير إلى ما إذا كان العنصر موجودًا في المجموعة عند استدعاء تلك الطريقة:

```java
Set<Integer> set = new HashSet<>();
set.add(1);
// => true
set.add(2);
// => true
set.add(1);
// => false
set.size();
// => 2
set.contains(1);
// => true
set.contains(3);
// => false
set.remove(3);
// => false
set.remove(2);
// => true
set.size();
// => 1
```
