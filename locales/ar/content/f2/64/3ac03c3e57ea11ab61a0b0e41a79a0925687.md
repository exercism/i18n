# مقدمة

التحويل الصريح وتحويل النوع طريقتان مختلفتان لتغيير تعبير من نوع بيانات إلى نوع بيانات آخر.

يمكن تحويل تعبير إلى نوع آخر باستخدام عامل التحويل `(<type>)`.

```csharp
long l = 1000L;
int i = (int)l;

object o = new Random();
Random r = (Random)o;
```

إذا لم يكن النوعان متوافقين، فسيُطرح استثناء من النوع `InvalidCastException`. وفي حالة الأعداد، يشير هذا إلى أن النوع المستقبِل لا يمكنه تمثيل القيمة المحوَّلة. أما في حالة الأصناف، فيجب أن يكون أحد النوعين مشتقًا من الآخر (وهذا ينطبق أيضًا على البنى `struct` بالمنطق نفسه).

وثمة بديل عن _التحويل الصريح_ هو _تحويل النوع_ باستخدام عامل `is`. ويُستخدم هذا عادةً مع أنواع المراجع والأنواع القابلة للقيمة `null`.

```csharp
object o = new Random();
if (o is Random rand)
{
    int ii = rand.Next();
    // now, do something random
}
```

إذا احتجت إلى تحديد النوع الدقيق لكائن، فقد يكون `is` متسامحًا أكثر من اللازم، لأنه سيُرجع صحيحًا لأي صنف ولأي من الأصناف والواجهات التي يشتق منها هذا الصنف مباشرةً أو بشكل غير مباشر. وفي هذه الحالة يكون الحل هو `typeof` و`Object.GetType()`.

```csharp
object o = new List<int>();

o is ICollection<int> // true
o.GetType() == typeof(ICollection<int>) // false
o is List<int> // true
o.GetType() == typeof(List<int>) // true
```
