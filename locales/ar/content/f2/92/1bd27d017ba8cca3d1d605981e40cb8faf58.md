# نبذة

الجمل الشرطية في C++ مشابهة للجمل الشرطية في اللغات الأخرى.
النوع الأساسي لأي عملية شرطية هو نوع `bool`، الذي يمكن أن تكون قيمته `true` أو `false`.
غالبًا ما تُستخدم الجمل الشرطية كآليات للتحكم في التدفق للتحقق من شروط مختلفة.

يمكن استخدام جملة `if` الشرطية، التي تنفذ الكود الخاص بها إذا كان الشرط الأساسي `true`، على النحو التالي:

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

في الحالات التي تتضمن أكثر من حالة، يمكن ربط العديد من جمل `if` الشرطية معًا باستخدام الجملتين `else if` و `else`.

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

بدءًا من C++17، يمكن أن تتضمن جمل `if` الشرطية أيضًا عبارة تهيئة قصيرة يمكن استخدامها لتهيئة متغير واحد أو أكثر للجملة الشرطية.
على سبيل المثال:

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> ملاحظة: أي متغيرات تُنشأ في التهيئة لا يمكن الوصول إليها بعد نهاية جملة `if` الشرطية.
