# مقدمة

`when` في Kotlin تعبير شرطي للاختيار من بين عدة خيارات.
وهو مشابه لـ `switch` في Java، وأكثر مرونة من تسلسل من `if` ... `else if` ... `else`.

ومثل `if`، يمكن استخدام `when` أيضًا كتعبير يُنتج قيمة.

## مطابقة قيمة

أعطِ `when` قيمة للمطابقة بين الأقواس الهلالية.
يقارن كل فرع تلك القيمة حتى يتحقق تطابق:

```kotlin
val animal = "chicken"
val type = when (animal) {
    "chicken" -> "bird"
    "poodle" -> "dog"
    else -> "unknown"
}
// type => "bird"
```

- يُكتب كل فرع على الصورة `pattern -> result`.
- تُجرَّب الفروع من الأعلى إلى الأسفل حتى يُعثر على تطابق.
  ولا يُنفَّذ إلا الفرع الأول.
- استخدم `else` لأي قيمة غير مذكورة أعلاه (على غرار `else` في نهاية تسلسل `if`).

هذا مشابه لـ[مطابقة الأنماط][pattern-matching].
يمكن أن يكون `pattern` قيمةً للمطابقة، أو يمكنك استخدام `is` للمطابقة حسب النوع:

```kotlin
fun typeText(subject: Any): String {
    return when(subject) {
        is Animal -> "Animal"
        is Fruit -> "Fruit"
        is String -> "Text"
        else -> "Unknown"
    }
}
```

أو استخدام `in` للتحقق من وجوده داخل نطاق أو مجموعة أو سلسلة نصية أو أي شيء آخر لديه طريقة `contains`:

```kotlin
fun describe(number: Int, position: String) {
    // Range
    when(number) {
        in 1..10 -> println("From 1 to 10")
        in 11..20 -> println("From 11 to 20")
    }

    // Collection
    when(number) {
        in listOf(2, 4, 6) -> println("small even")
        in listOf(3, 5, 7) -> println("small odd")
    }

    // String
    when(position) {
        in "center middle" -> println("inner")
        in "left right boundary" -> println("outer")
    }
}
```

~~~exercism/note

على سبيل المثال، استخدامه مع [Regex][kotlin-regex]:

## شروط الحماية

عند مطابقة قيمة، يمكن وضع شروط إضافية في `if` بعد النمط.
وتُسمى هذه الشروط شروط الحماية.

```kotlin
val x = 5
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else -> "other"
}
// description => "x is 5, y is even"
```

بل يمكن استخدام `else if` أيضًا.

```kotlin
val x = 7
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else if y % 2 == 0 -> "y is an even number"
    else -> "other"
}
// description => "y is an even number"
```


## مطابقة الشروط

بدلًا من ذلك، يمكن حذف القيمة ووضع شروط منطقية على كل فرع:

```kotlin
val x = 5
val y = 8
val description = when {
    x % 2 != 0 -> "x is odd"
    y % 2 == 0 -> "y is even"
    else -> "neither condition matched first"
}
// description => "x is odd"
```

ومرة أخرى، تُفحص الفروع من الأعلى إلى الأسفل، ولا يُنفَّذ إلا أول فرع شرطه `true`.

## استخدام `when` كتعبير

عندما يُستخدم `when` من أجل نتيجته (بإسنادها إلى متغير، أو إرجاعها من دالة، وما إلى ذلك)، يجب تغطية كل حالة ممكنة.

- عند المطابقة بقيمة، أضف `else` ما لم تكن كل القيم الممكنة مغطاة بالفعل (على سبيل المثال، كل قيم `Boolean` أو `enum`).
- وعند مطابقة الشروط، يلزم وجود فرع `else`، لأن المترجم لا يستطيع أن يعرف أن شروطك تغطي كل الحالات.

```kotlin
fun label(n: Int): String = when (n) {
    0 -> "zero"
    1 -> "one"
    else -> "other"
}
```
