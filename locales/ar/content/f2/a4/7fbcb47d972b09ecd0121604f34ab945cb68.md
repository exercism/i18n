# ملحق التعليمات

## تلميحات

لإكمال هذا التمرين تحتاج إلى إنشاء نوع البيانات `BST`، مع نسختَي `Eq` و`Show`، وتنفيذ الدوال التالية:

- `bstLeft`
- `bstRight`
- `bstValue`
- `empty`
- `fromList`
- `insert`
- `singleton`
- `toList`

ستجد إعلان بيانات وهميًا وتوقيعات الأنواع جاهزة بالفعل، لكن الأمر متروك لك في تعريف الدوال وإنشاء نوع بيانات ذي معنى، أو `newtype` أو مرادف نوع.
