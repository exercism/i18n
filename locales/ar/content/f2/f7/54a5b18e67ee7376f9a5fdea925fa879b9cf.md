# التعليمات

أنت مراقب طيور شغوف تتابع عدد الطيور التي زارت حديقتك.
عادةً ما تستخدم تدوينًا في دفتر لعدّ الطيور، لكنك حوّلت أعداد الطيور في الأسابيع الماضية إلى صيغة رقمية لتتعامل مع بياناتك بشكل أفضل.

## 1. حدّد العدد الإجمالي للطيور التي أحصيتها حتى الآن

لنبدأ بتحليل البيانات من خلال نظرة عامة.
اكتشف عدد الطيور التي أحصيتها إجمالًا منذ أن بدأت تسجيل بياناتك.

نفّذ دالة `totalBirdCount` تقبل مصفوفة من قيم `Int` تحتوي على عدد الطيور في كل يوم.
يجب أن تُرجع العدد الإجمالي للطيور التي أحصيتها.

```swift
let birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1]
totalBirdCount(birdsPerDay)
// Returns 34
```

## 2. احسب عدد الطيور الزائرة في أسبوع معيّن

الآن بعد أن صارت لديك فكرة عامة عن أعداد الطيور، تريد إجراء تحليل أكثر تفصيلًا.

نفّذ دالة `birdsInWeek` تقبل مصفوفة تحتوي على عدد الطيور في كل يوم ورقم أسبوع.

تُرجع العدد الإجمالي للطيور التي أحصيتها في ذلك الأسبوع تحديدًا.
يمكنك افتراض أن الأسابيع تُسجَّل دائمًا كاملة.

```swift
let birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1]
birdsInWeek(birdsPerDay, weekNumber: 2)
// Returns 12
```

## 3. صحّح خطأً في العدّ

أدركت أنه طوال الوقت الذي كنت تحاول فيه متابعة الطيور، كان هناك طائر يختبئ في زاوية بعيدة من الحديقة.

واكتشفت أن هذا الطائر كان يقضي يومًا من كل يومين في حديقتك.

لا تعرف بالضبط أين كان في الأيام الفاصلة، لكنه بالتأكيد لم يكن في حديقتك.

كما يخبرك حدسك كمراقب طيور أن الطائر كان في حديقتك في أول يوم سجّلته في قائمتك.

بناءً على هذه المعلومة الجديدة، اكتب دالة `fixBirdCountLog` تأخذ مصفوفة بعدد الطيور المحصاة في كل يوم كوسيط، وتُرجع المصفوفة بعد تصحيح خطأ العدّ.

```swift
var birdsPerDay = [2, 5, 0, 7, 4, 1]
fixBirdCountLog(birdsPerDay)
// Returns [3, 5, 1, 7, 5, 1]
```
