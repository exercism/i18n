# مقدمة

يمثل نوع البيانات الجبري (ADT) عددًا ثابتًا من الحالات المسماة.
وكل قيمة من قيم نوع البيانات الجبري تقابل حالة واحدة بالضبط من الحالات المسماة.

يُعرّف نوع البيانات الجبري باستخدام الكلمة المفتاحية `data`، مع فصل الحالات بمحرف الأنبوب (`|`).
إذا لم تكن مرتبطة بأي من الحالات بيانات، فإن نوع البيانات الجبري يشبه ما تسميه اللغات الأخرى عادةً _تعدادًا_ (أو _enum_).

```haskell
data Season
  = Spring
  | Summer
  | Autumn
  | Winter
```

يمكن أن تكون هناك بيانات مرتبطة بكل حالة من حالات نوع البيانات الجبري، ويمكن أن يكون للحالات المختلفة أنواع مختلفة من البيانات.
وعندما ترتبط بالحالة بيانات، يلزم وجود باني.

```haskell
data Number
  = NInt Int      --'NInt' is the constructor for an Int Number.
  | NFloat Float  --'NFloat' is the constructor for an Float Number.
  | Invalid       --'Invalid' does not have data associated to it.
```

يمكن إنشاء قيمة لحالة معينة بالإشارة إلى اسمها (مثل `NInt 22`).
ولأن أسماء الحالات هي مجرد دوال بانية، يمكن تمرير البيانات المرتبطة كوسيط دالة عادي.

تتمتع أنواع البيانات الجبرية _بالتساوي البنيوي_، مما يعني أن قيمتين لنفس الحالة وبنفس البيانات (الاختيارية) متكافئتان.

بينما يمكن استخدام تعبيرات `if/else` للتعامل مع أنواع البيانات الجبرية، فإن الأسلوب الموصى به للتعامل معها هو مطابقة الأنماط باستخدام عبارة _case_:

```haskell
add1 :: Number -> String
add1 number =
    case number of
      NInt    i -> show (i + 1)
      NFloat  f -> show (f + 1.0)
      Invalid   -> error "Invalid input"
```
