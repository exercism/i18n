# مقدمة

في Go، الدوال قيم من الدرجة الأولى.
هذا يعني أنه يمكنك أن تفعل بالدوال نفس الأشياء التي يمكنك فعلها مع بقية القيم: إسناد الدوال إلى المتغيرات، وتمريرها كوسائط إلى دوال أخرى، أو حتى إرجاع دوال من دوال أخرى.

في ما يلي ننشئ دالتين، `engGreeting` و`espGreeting`، ونُسندهما إلى المتغير `greeting`:

```go
import "fmt"

func engGreeting(name string) string {
	return fmt.Sprintf("Hello %s, nice to meet you!", name)
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := engGreeting			// greeting is a variable of type func(string) string
fmt.Println(greeting("Alice"))	// Hello Alice, nice to meet you!

greeting = espGreeting
fmt.Println(greeting("Alice")) 	// ¡Hola Alice, mucho gusto!
```

تتيح لنا قيم الدوال إمكانية تمرير المعاملات إلى الدوال، ليس بالبيانات فحسب، بل بالسلوك أيضًا.
في المثال التالي، نمرّر السلوك إلى دالة `dialog` عبر المعامل `greetingFunc`:

```go
func dialog(name string, greetingFunc func(string) string) {
	fmt.Println(greetingFunc(name))
	fmt.Println("I'm a dialog bot.")
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := espGreeting
dialog("Alice", greeting)
// =>
// ¡Hola Alice, mucho gusto!
// I'm a dialog bot.
```

قيمة متغير غير مُهيّأ من نوع دالة هي `nil`.
لذلك، فإن استدعاء قيمة دالة تساوي `nil` يؤدي إلى `panic`.

```go
var dutchGreeting func(string) string
dutchGreeting("Alice") // panic: call of nil function
```

يمكن مقارنة قيم الدوال بـ `nil`.
وقد يكون هذا مفيدًا لتجنّب حالات `panic` غير الضرورية في البرنامج.

```go
var dutchGreeting func(string) string
if dutchGreeting != nil {
	dutchGreeting("Alice") // safe to call dutchGreeting
}
```

## أنواع الدوال

استخدام قيم الدوال ممكن بفضل أنواع الدوال في Go.
نوع الدالة يحدّد مجموعة كل الدوال التي لها نفس تسلسل أنواع المعاملات ونفس تسلسل أنواع النتائج.
ويمكن تعريف أنواع يُنشئها المستخدم فوق أنواع الدوال.
على سبيل المثال، يمكن تحديث دالة `dialog` من الأمثلة السابقة كما يلي:

```go
type greetingFunc func(string) string

func dialog(name string, f greetingFunc) {
	fmt.Println(f(name))
	fmt.Println("I'm a dialog bot.")
}
```

## الدوال المجهولة

من الأدوات القوية الأخرى المتاحة بفضل دعم الدوال كقيم من الدرجة الأولى: الدوال المجهولة.
تُعرَّف الدوال المجهولة عند موضع استخدامها، دون اسم يتبع الكلمة المفتاحية `func`.
ولهذه الدوال وصول إلى متغيرات الدالة المحيطة.

على سبيل المثال:

```go
func fib() func() int {
	var n1, n2 int

	return func() int {
		if n1 == 0 && n2 == 0 {
			n1 = 1
		} else {
			n1, n2 = n2, n1 + n2
		}
		return n2
	}
}

next := fib()
for i := range N {
  fmt.Printf("F%d\t= %4d\n", i, next())
}
```

يُعرّف استدعاء `fib` المتغيرين `n1` و`n2` ويُرجع دالة مجهولة، وهذه الدالة بدورها تغيّر قيم هذين المتغيرين في كل مرة تُستدعى فيها.
الاستدعاء رقم N للدالة المجهولة يُرجع العدد رقم N من متتالية فيبوناتشي بدءًا من 0. وللدالة المجهولة الداخلية وصول إلى المتغيرين المحليين (`n1` و`n2`) في الدالة المحيطة `fib`.
وهذه طريقة رائعة لجعل قيم الدوال تحتفظ بحالتها بين الاستدعاءات.
نقول إن الدالة المجهولة إغلاق للمتغيرين `n1` و`n2`. وتُستخدم [الإغلاقات][closure] على نطاق واسع في البرمجة، وقد ترى لغات أخرى تدعمها.

[closure]: https://en.wikipedia.org/wiki/Closure_(computer_programming)
