# مقدمة

عند [الاستدعاء الذاتي][exercism-recursion] عبر الأنواع القابلة للتعداد (المصفوفات، وسلاسل البتات، والسلاسل النصية)، غالبًا ما يكون هناك أمران يجب الانتباه إليهما:

- كمية الذاكرة اللازمة لتخزين أثر استدعاءات الدالة الذاتية
- كيفية بناء الحل بكفاءة

للتعامل مع هذين الأمرين، يمكن استخدام _مُراكم_.

المُراكم متغير يُمرَّر إلى جانب البيانات. يُستخدم لتمرير الحالة الراهنة لتنفيذ الدالة، من استدعاء إلى آخر، حتى الوصول إلى _الحالة الأساسية_. وفي الحالة الأساسية، يُستخدم المُراكم لإرجاع القيمة النهائية لاستدعاء الدالة الذاتية.

ينبغي أن يهيّئ المُراكمَ كاتبُ الدالة، لا مستخدمُها. ولتحقيق ذلك، عرّف دالتين: دالة عامة تأخذ البيانات الضرورية فقط كوسائط وتهيّئ المُراكم، ودالة خاصة تأخذ المُراكم أيضًا. وفي Elixir، من الأنماط الشائعة أن تبدأ اسم الدالة الخاصة بـ `do_`.

```elixir
# Count the length of a list without an accumulator
def count([]), do: 0
def count([_head | tail]), do: 1 + count(tail)

# Count the length of a list with an accumulator
def count(list), do: do_count(list, 0)

defp do_count([], count), do: count
defp do_count([_head | tail], count), do: do_count(tail, count + 1)
```

يتيح استخدام المُراكم تحويل الدوال الذاتية إلى دوال _ذاتية ذيلية_. وتكون الدالة ذاتية ذيلية إذا كان _آخر_ ما تنفذه الدالة هو استدعاء لنفسها.
