# تطبيع representer

يطبّق [representer الخاص بـ F#][representer] التطبيعات التالية:

## إزالة التعليقات

تُزال جميع التعليقات.

### قبل

```fsharp
module Fake

(* Block comment
   on multiple lines *)

let message = "Hi" (* Block comment after code *)

// Double-slash comment on single line
let reply = "Yo" // Double-slash comment after code

/// <summary>This function adds two numbers</summary>
/// <param name="x">The first number</param>
/// <param name="y">The second number</param>
/// <returns>The first number added to the second number</param>
let add x y = x + y
```

### بعد

```fsharp
module Fake

let message = "Hi"

let reply = "Yo"

let add x y = x + y
```

## تنسيق الكود

يُنسَّق الكود باستخدام [مكتبة fantomas][fantomas].
وتُنسّق هذه المكتبة الكود وفق دليل أسلوب F#.
تجد القائمة الكاملة للتحويلات التي تطبّقها fantomas [هنا][fantomas-formatting].

### قبل

```fsharp
module Fake

let  add ( birthDate  :  DateTime)  =
    birthDate.Add (    2.0)

type Volume =
| Liter of float
| USPint of float
| ImperialPint of float
```

### بعد

```fsharp
module Fake

let add (birthDate: DateTime) =
    birthDate.Add(2.0)

type Volume =
    | Liter of float
    | USPint of float
    | ImperialPint of float
```

## تطبيع المعرّفات

تُستبدل المعرّفات بقيمة نائبة.

### قبل

```fsharp
module Fake

```
