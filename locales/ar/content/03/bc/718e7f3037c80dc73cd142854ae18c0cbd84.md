# مقدمة

رأينا في مفهوم `Vectors` أن المتجه يمكن استخدامه داخل تعبير شرطي، فينتج عن ذلك متجه منطقي.
وهذا بدوره يمكن استخدامه في دوال مثل `all()` و`any()`.

```R
v <- c(4, 7, 10)
v >= 6
#> [1] FALSE  TRUE  TRUE
all(v > 6)
#> [1] FALSE    # not all elements match this condition
any(v > 6)
#> [1] TRUE     # at least one element matches
```

لكن هذه التقنية أقوى بكثير من ذلك.

## المجموعات الفرعية للمتجهات

يمكن استخراج عناصر محددة من المتجه باستخدام رقم فهرس أو متجه من الفهارس:

```R
v <- 5:10
v
#> [1]  5  6  7  8  9 10
v[3] 
#> [1] 7
v[c(2, 4)]
#> [1] 6 8
```

أو يمكنك استخدام متجه منطقي لتصفية المتجه الأصلي، فيُرجع مجموعة فرعية من العناصر المطابقة لقيمة `TRUE`:

```R
v <- 1:3
bools <- c(FALSE, TRUE, TRUE)
v[bools]
#> [1] 2 3
```

وخطوة صغيرة تفصلنا عن توليد متجه القيم المنطقية بتعبير شرطي:

```R
bools <- v >= 2
bools
#> [1] FALSE  TRUE  TRUE

v[bools]
#> [1] 2 3

# simpler form
v[v >= 2]
#> [1] 2 3
```

## إيجاد الفهارس

تأخذ الدالة `which()` وسيطاً من القيم المنطقية وتُرجع متجهاً من الفهارس التي قيمتها `TRUE`.

```R
v
#> [1] 2 7 9

v[v > 5]  # returns values
#> [1]  7  9

which(v > 5) # returns indices
#> [1] 2 3
```

## التحقق من وجود عنصر

كانت الأقسام السابقة تدور حول إيجاد العناصر المطابقة لمعيار ما.

إذا كنت تحتاج فقط إلى معرفة ما إذا كان المتجه يحتوي على عنصر محدد، فاستخدم المعامل `%in%`.

```R
3 %in% 1:5
#> [1] TRUE
7 %in% 1:5
#> [1] FALSE
```

هذا مكافئ وظيفياً للكود التالي، لكنه أكثر ملاءمة بكثير:

```R
v <- 1:5
length(v[v == 3]) > 0
#> [1] TRUE
```
