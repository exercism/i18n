# التعليمات

تصنع إيلين لعبة على اللاعب فيها أن يحارب كائنات فضائية.
لقد تعلمت للتو البرمجة كائنية التوجه (OOP)، وهي متشوقة للاستفادة مما قد يقدمه استخدام `classes` لبرنامجها.

وإلى سرور إيلين، عرضت عليها المساعدة، وقد أوكلت إليك مهمة برمجة الكائنات الفضائية التي على اللاعب محاربتها.


## 1. إنشاء صنف `Alien`

عرّف صنف `Alien` بمُنشئ يقبل معاملين من النوع `int` هما `x` و`y`، ويضعهما في متغيري العضو `x_coordinate` و`y_coordinate`.
سيبدأ كل كائن فضائي أيضًا بمستوى صحة قدره `3`، لذا يجب تهيئة متغير العضو `health` كذلك.

يجب أن يكون `health` متغير عضو من النوع private.
ولكي تتمكن أجزاء أخرى من البرنامج من قراءة معلومات الصحة، تريد إيلين أن تكون لديها طريقة `get_health()` من النوع `public` تُرجع `int`.

```cpp
Alien alien{2, 0};
alien.x_coordinate;
// => 2
alien.y_coordinate;
// => 0
alien.get_health();
// => 3
```

الآن، يجب أن يكون كل كائن فضائي قادرًا على تتبع موضعه وصحته داخليًا.

## 2. دالة `hit`

تريد إيلين أن يمتلك صنف `class` طريقة `hit` تُنقص صحة كائن فضائي بمقدار `1` عند استدعائها.
بهذه الطريقة، يمكنها ببساطة استدعاء `some_alien_instance.hit()` بدلًا من الاضطرار إلى تغيير صحة الكائن الفضائي يدويًا.
تأكد من أن نقاط الصحة لا تنخفض إلى ما دون الصفر.
يجب أن تُرجع الدالة `true`.
تريد إيلين إدخال الدروع في مرحلة لاحقة، وحينها ستُرجع الدالة `false` إذا كان الدرع مرفوعًا.

```cpp
Alien alien {0, 0};
alien.get_health();
// => 3 (Initial health value)

alien.hit(); // Decrements health by 1 point.
alien.get_health();
// => 2
```

## 3. دالة `is_alive`

أنت تدرك أنه إذا استمرت الصحة في الانخفاض، ففي مرحلة ما ستصل على الأرجح إلى `0`.
سيكون من الجيد إضافة طريقة `is_alive` يمكن لإيلين استدعاؤها بسرعة للتحقق مما إذا كان الكائن الفضائي... حسنًا... حيًّا. 😉
يجب أن تُرجع `some_alien_instance.is_alive()` قيمة منطقية.

```cpp
alien.get_health();
// => 1
alien.is_alive();
// => true
alien.hit();
alien.get_health();
// => 0
alien.is_alive();
// => false
```

## 4. دالة `teleport`

في لعبة إيلين، يمكن للكائنات الفضائية أن تنتقل آنيًا!
ستحتاج إلى كتابة طريقة `teleport` تأخذ قيمتي `x_new` و`y_new`، وتغيّر إحداثيات الكائن الفضائي وفقًا لذلك.
في الوقت الحالي، يجب أن تُرجع الدالة `true`.
تريد إيلين إضافة قنابل تمنع الانتقال الآني في مستويات لاحقة، وحينها ستُرجع الدالة `false` لمحاولات الانتقال الآني الفاشلة.

```cpp
alien.teleport(5, -4);
alien.x_coordinate;
// => 5
alien.y_coordinate;
// => -4
```

## 5. دالة `collision_detection`

إذا كان يمكن إصابة الكائنات الفضائية بشيء ما، فإنها تحتاج إلى القدرة على اكتشاف متى قد يحدث مثل هذا التصادم.
تحتاج إيلين إلى معرفة ما إذا كان كائنان فضائيان يشغلان الإحداثيات نفسها.
تأخذ الدالة `collision_detection()` كائنًا فضائيًا آخر كوسيط وتُرجع `bool`.

```cpp
Alien lrrr {3, 6};
Alien ndnd {-2, 12};
lrrr.collision_detection(ndnd);
// => false
ndnd.teleport(3, 6);
ndnd.collision_detection(lrrr);
// => true
```
