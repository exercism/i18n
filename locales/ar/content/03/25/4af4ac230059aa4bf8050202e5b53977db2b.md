# مقدمة

## الأساسيات

[Lua](https://lua.org) لغة برمجة نصية بسيطة لكنها قوية وفعّالة وخفيفة وقابلة للتضمين. صُمّمت ونُفّذت وتُصان في [PUC-RIO](https://www.puc-rio.br/) في البرازيل منذ عام 1993 على يد فريق روبرتو إيريوزاليمسكي ووالديمار سيليس ولويس هنريكي دي فيغيريدو.

### التعليقات

التعليقات أحادية السطر في Lua تبدأ بـ `--`، أما التعليقات متعددة الأسطر فتبدأ بـ `--[[` وتنتهي بـ `]]`.
```lua
-- This is a single line comment.

--[[This is
a multiline
comment
]]
```

### المتغيرات

هناك ثلاثة أنواع من المتغيرات في Lua: المتغيرات العامة، والمتغيرات المحلية، وحقول الجداول. وللتبسيط، لن نشرح هنا إلا المتغيرات المحلية. جميع المتغيرات عامة افتراضيًا، لذلك علينا أن نُعلن المتغيرات المحلية على هذا النحو باستخدام الكلمة المفتاحية `local`.
```lua
local x
```

يمكن إسناد قيمة إلى متغير باستخدام العامل `=`.
```lua
local x = 1
```

يقتصر نطاق المتغير `local` على الكتلة التي أُعلن فيها. ويمكن أن تكون الكتلة جسم بنية تحكم، أو جسم دالة، أو ملفًا أو سلسلة نصية يُعلن فيه المتغير.
```lua
local x = 1

if x == 1 then
  local x = 2
  print(x) -- prints 2
end

print(x) -- prints 1
```

### الدوال

تُعلن الدالة باستخدام الكلمة المفتاحية `function`، وهي مثل المتغيرات عامة افتراضيًا. يتكون تعريف الدالة من اسم وقائمة معاملات وجسم. وتنتهي الدالة عند الوصول إلى الكلمة المفتاحية `return` وتُرجع جميع القيم المدرجة بعدها. وإذا لم يُحدَّد `return`، فستُرجع الدالة `nil`.

```lua
-- Defining a local function which returns "Hello " followed by 
-- the name which was given as parameter
local function say_hello(name)
  return 'Hello ' .. name
end
```

### الجداول

الجداول هي آلية بناء البيانات الوحيدة في Lua، وهي قوية جدًا. تُستخدم لتمثيل المصفوفات والمجموعات والكائنات والوحدات وغيرها الكثير. وفي جوهره، الجدول في Lua هو مصفوفة ترابطية.
```lua
-- create a table and assign its reference to tbl
local tbl = {}

-- new entry with key 'x' and value 1
tbl['x'] = 1

-- printing the value
print(tbl['x'])  --> 1

-- uninitialized table fields evaluate to nil
print(tbl['y'])  --> nil

-- there is also syntactic sugar - the following is the same as above
tbl.y = 1
print(tbl.y)    --> 1
```

هذه مجرد لمحة صغيرة نحتاجها للقسم التالي. وسنعود إلى هذا الموضوع بالتفصيل لاحقًا.

### الوحدات

الوحدة مجموعة من الكود مخزّنة في ملف مصدري بامتداد `.lua`. وكل ما تصدّره الوحدة يُخزَّن في جدول، ويُرجع هذا الجدول في نهاية الملف. لذا يعمل الجدول أساسًا كنوع من فضاء الأسماء.
```lua
-- say-hello.lua

-- defining the table 'say' which is exported at the end
local say = {}

-- defining the function 'hello' as a table field
-- this is syntax sugar for: say.hello = function() print('Hello!') end
function say.hello()
  print('Hello!')
end

-- returning (exporting) the table 'say'
return say
```

يمكن بعد ذلك تحميل تلك الوحدة في ملف آخر عبر الدالة `require`، التي تُرجع الجدول.
```lua
-- lets_say_hello.lua
local say = require('say-hello')
say.hello() -- prints "Hello!"
```

عندما نرى `say.hello` قد نفكّر في "الدالة `hello` من الوحدة `say`". لكن بمعرفتنا أن `say-hello.lua` تُرجع جدولًا، وبالعودة إلى قسم الجداول، نلاحظ أن التعبير في Lua يعني "فهرسة الجدول `say` باستخدام السلسلة النصية `hello` كمفتاح".

ورغم أن من الممارسات الجيدة أن تُرجع الوحدة جدولًا، فمن الممكن تمامًا إرجاع أي نوع آخر، مثل دالة.

```lua
--- say-bye.lua
local function bye()
  print('Bye!')
end

return bye
```
