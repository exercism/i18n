# المدى

يمثّل [المدى][range] فترة بين قيمتين.
وأكثر الأنواع شيوعًا التي تدعم الأمداء هي `Int` و`Char` و`String`.
ويمكن استخدامها في أمور كثيرة، مثل إنشاء مجموعة بسرعة، وتقطيع السلاسل النصية، والتحقق مما إذا كانت قيمة ما ضمن المدى، والتكرار.
ويُنشأ المدى باستخدام عامل المدى `..` أو `...` (شامل وغير شامل على الترتيب).

```crystal
1..5  # A range containing 1, 2, 3, 4, 5
1...5 # A range containing 1, 2, 3, 4
```

السبب في وجود عاملي مدى هو إنشاء أمداء تشمل قيمة النهاية أو تستبعدها، وهو أمر مفيد عندما تتعامل، مثلًا، مع فهارس تبدأ من الصفر.

يمكن أيضًا إنشاء الأمداء باستخدام مُهيِّئ `Range`.

```crystal
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
عند إنشاء مدى في Crystal باستخدام عاملي المدى `..` أو `...`، وأردت استدعاء طريقة على المدى، فستحتاج إلى وضع المدى بين قوسين هلاليين.
فبدون ذلك ستُستدعى الطريقة على الوسيط الثاني لعامل المدى.

```crystal
(1..5).size # => 5
1..5.size # => Error: undefined method 'size' for Int32
```
~~~~

## الحصول على سلاسل فرعية

عندما تريد تقطيع سلسلة نصية، يمكنك استخدام عامل المدى للحصول على سلسلة فرعية، أي بإنشاء مدى من فهرس البداية وفهرس النهاية للسلسلة الفرعية.

```crystal
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

يمكنك أيضًا استخدام فهارس سالبة للحصول على السلسلة الفرعية من نهاية السلسلة النصية.

```crystal
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## طرق المدى

للمدى مجموعة من الطرق التي يمكن استخدامها للتعامل معه.
فمثلًا، يمكن استخدام هذه الطرق للحصول على مجموع كل القيم في المدى أو التحقق مما إذا كان المدى يتضمن قيمة.

| الطريقة                | الوصف                                                             | المثال                         |
|-------------------------|-------------------------------------------------------------------------|---------------------------------|
| [`sum`][sum]            | تُرجع مجموع كل القيم في المدى                                          | `(1..5).sum # => 15`            |
| [`size`][size]          | تُرجع حجم المدى                                                         | `(1..5).size # => 5`            |
| [`includes?`][indludes] | تُرجع `true` إذا كان المدى يتضمن القيمة المعطاة، وإلا `false` | `(1..5).includes?(3) # => true` |

## الأمداء التي بلا نهاية وبلا بداية

يمكن أن يكون المدى بلا نهاية أو بلا بداية.
فالمدى الذي بلا نهاية أو بلا بداية تكون قيمة بدايته أو نهايته `nil`، لكن يمكن حذف `nil` عند تعريف المدى.

ويكون استخدام الأمداء التي بلا بداية أو بلا نهاية مفيدًا عندما تريد، مثلًا، تقطيع سلسلة نصية من بدايتها أو حتى نهايتها.

```crystal
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
إذا لم يُستخدم المدى الذي بلا نهاية على مجموعة، فقد يسبب تسلسلًا لا نهائيًا، ما لم يُستخدم بحذر.
~~~~

## أمداء `Char`

يمكن استخدام المحارف في الأمداء، وهي تتيح لك الحصول على فترة من المحارف بين محرفين.
فمثلًا، يفيد هذا عندما تريد الحصول على الأبجدية.

```crystal
'a'..'z' # A range containing ['a', 'b', 'c', ..., 'z']
```

## أمداء السلاسل النصية

يمكن أيضًا استخدام السلاسل النصية في الأمداء، مما يتيح لك الحصول على فترة من السلاسل بين سلسلتين.
لكن سلوكه يختلف قليلًا عن سلوك `Char` عند استخدام عدة محارف في مدى من السلاسل النصية.
وقد يصبح سلوكه مربكًا عند إنشاء أمداء أكثر تعقيدًا من السلاسل النصية، فتوخَّ الحذر.

```crystal
("aa".."az") # A range containing ["aa", "ab", "ac", ..., "az"]
```

## كائنات مخصصة في الأمداء

~~~~exercism/advanced
تتيح لك Crystal استخدام كائنات مخصصة في الأمداء.
والشرط لذلك أن يحقق الكائن ما يلي:

- تضمين الوحدة `Comparable`
- الطريقة `succ`
- الطريقة `<=>`

تتيح هذه الطرق للمدى أن يمر على الكائن وأن يقارن الكائنات داخل المدى.

```crystal
class Foo
  include Comparable(Foo)

  getter value

  def initialize(@value : Int32)
  end

  def succ
    Foo.new(value + 1)
  end

  def <=>(other : Foo)
 value <=> other.value
  end
end

Foo.new(1)..Foo.new(5)
# => #<Foo:0x7f3552bebe70 @value=1>, #<Foo:0x7f3552bebe50 @value=2>, #<Foo:0x7f3552bebe40 @value=3>, #<Foo:0x7f3552bebe30 @value=4>, #<Foo:0x7f3552bebe20 @value=5>
```
