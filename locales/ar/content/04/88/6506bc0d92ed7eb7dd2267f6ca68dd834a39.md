# التعليمات

في هذا التمرين، ستُطبّق طريقة لتتبّع أعلى الدرجات لأكثر لعبة شعبية في صالة الألعاب في منطقتك.

## 1. تعريف خريطة جديدة لأعلى الدرجات

لإنشاء خريطة جديدة لأعلى الدرجات، عرّف الدالة `HighScore.new/0` التي لا تأخذ أي وسائط وتُرجع خريطة جديدة فارغة لأعلى الدرجات.

```elixir
HighScore.new()
# => %{}
```

## 2. إضافة لاعبين إلى خريطة أعلى الدرجات

لإضافة لاعب إلى خريطة أعلى الدرجات، عرّف `HighScore.add_player/3`، وهي دالة تأخذ 3 وسائط:

- الوسيط الأول هو خريطة الدرجات.
- الوسيط الثاني هو اسم اللاعب على شكل سلسلة نصية.
- الوسيط الثالث هو الدرجة على شكل عدد صحيح. هذا الوسيط اختياري، فنفّذ الوسيط الثالث بقيمة افتراضية مقدارها 0.

خزّن الدرجة الابتدائية الافتراضية في سمة وحدة. ستحتاج إليها مرة أخرى.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas")
# => %{"Dave Thomas" => 0}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"Dave Thomas" => 0, "José Valim"=> 486_373}
```

## 3. إزالة لاعبين من خريطة الدرجات

لإزالة لاعب من خريطة أعلى الدرجات، عرّف `HighScore.remove_player/2`، التي تأخذ وسيطين:

- الوسيط الأول هو خريطة الدرجات.
- الوسيط الثاني هو اسم اللاعب على شكل سلسلة نصية.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas")
# => %{"Dave Thomas" => 0}
score_map = HighScore.remove_player(score_map, "Dave Thomas")
# => %{}
```

## 4. إعادة ضبط درجة اللاعب

لإعادة ضبط درجة لاعب ما، عرّف `HighScore.reset_score/2`، التي تأخذ وسيطين:

- الوسيط الأول هو خريطة الدرجات.
- الوسيط الثاني هو اسم اللاعب على شكل سلسلة نصية، الذي تريد إعادة ضبط درجته.

ينبغي أن تعمل الدالة أيضًا حتى إذا لم يكن للاعب أي درجة.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"José Valim"=> 486_373}
score_map = HighScore.reset_score(score_map, "José Valim")
# => %{"José Valim"=> 0}
```

## 5. تحديث درجة اللاعب

لتحديث درجة لاعب بإضافة قيمة إلى الدرجة السابقة، عرّف `HighScore.update_score/3`، التي تأخذ 3 وسائط:

- الوسيط الأول هو خريطة الدرجات.
- الوسيط الثاني هو اسم اللاعب على شكل سلسلة نصية، الذي تريد تحديث درجته.
- الوسيط الثالث هو الدرجة التي تريد **إضافتها** إلى أعلى درجة مخزّنة.

ينبغي أن تعمل الدالة أيضًا إذا لم يكن للاعب درجة سابقة، فافترض أن الدرجة السابقة هي 0.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"José Valim"=> 486_373}
score_map = HighScore.update_score(score_map, "José Valim", 5)
# => %{"José Valim"=> 486_378}
```

## 6. الحصول على مصفوفة اللاعبين

للحصول على مصفوفة اللاعبين، عرّف `HighScore.get_players/1`، التي تأخذ وسيطًا واحدًا:

- الوسيط الأول هو خريطة الدرجات.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas", 2_374)
# => %{"Dave Thomas" => 2_374}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"Dave Thomas" => 2_374, "José Valim"=> 486_373}
HighScore.get_players(score_map)
# => ["Dave Thomas", "José Valim"]
```
