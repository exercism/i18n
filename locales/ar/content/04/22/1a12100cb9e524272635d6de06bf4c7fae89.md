# التعليمات

أنت رئيس البحّارة على سفينة شحن ساحلية. قاع السفينة، وهو أدنى مقصورة في البدن، يجمع مياه الصرف، وفي كل نوبة يجب فتح معدات القاع وتشغيلها ثم إعادة ركنها. ومهما حدث في أثناء الضخ، *يجب* أن تنتهي المعدات عائدة إلى حالتها المركونة.

تمنحك الاختبارات `<test-pump>` للحصول على مضخات جديدة. لكل مضخة خانة `opened>>` تقرأ `t` ما دامت مفتوحة، و`f` بعد التخلص منها.

## 1. تصريف القاع

عرّف `drain-bilge` لتحرير مضخة واحدة. استدعاء `drain-bilge` على المضخة نفسها مرتين يجب ألا يسبب ضررًا، فإطار العمل يتولى ذلك عنك.

```factor
<test-pump> dup drain-bilge opened>> .   ! => f
```

## 2. روتين الضخ

عرّف `pump-out` بحيث يأخذ مضخة واقتباسًا، ويدفع المضخة إلى المكدس ليستخدمها الاقتباس، ثم يحرر المضخة بعد ذلك، *حتى لو رمى الاقتباس استثناءً*.

```factor
<test-pump> [ drop ] pump-out   ! pump released
```

## 3. روتين النوبة الكاملة

عرّف `shift-routine` بحيث يأخذ مضختين واقتباسًا. افتح نطاق مدمّر، وسجّل *المضختين* معًا لتحريرهما تحريرًا غير مشروط، ثم استدعِ الاقتباس. تنتهي المضختان محرَّرتين سواء أنهى الاقتباس عمله بشكل طبيعي أو رمى استثناءً.

يستقبل الاقتباس المضختين على المكدس كمُدخلات.

```factor
<test-pump> <test-pump> [ 2drop ] shift-routine
! both pumps released
```

## 4. ضخ محفوف بالمخاطر

أحيانًا تكون المضخة معارة، فلا تريد التخلص منها إلا إذا حدث خطأ ما؛ وإلا فإن النوبة التالية تحتاجها متروكة مفتوحة. عرّف `risky-pump-out` بحيث يأخذ مضخة واقتباسًا، ويسجّل المضخة للتحرير **عند الفشل فقط**، ويستدعي الاقتباس والمضخة على المكدس.

إذا نجح الاقتباس، تبقى المضخة مفتوحة. وإذا رمى الاقتباس استثناءً، تُحرَّر المضخة وينتشر الاستثناء.

```factor
<test-pump> [ drop ] risky-pump-out                ! stays open
<test-pump> [ drop "boom" throw ] risky-pump-out   ! pump released, throws
```

## 5. عنصر قابل للتخلص مخصص: الصمام

أكمل صندوق الأدوات بعنصر قابل للتخلص جديد تمامًا: `valve`. الصف معلن لك:

```factor
TUPLE: valve < disposable is-open ;
```

- عرّف `<valve> ( -- valve )` لإنشاء صمام جديد عبر `new-disposable`، مع ضبط `is-open` على `t`.
- نفّذ `M: valve dispose*` لقلب `is-open` إلى `f`.

```factor
<valve> is-open>> .                ! => t
<valve> dup dispose is-open>> .    ! => f
```
