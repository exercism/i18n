# الأعداد

يخزّن `INT` عددًا صحيحًا. وفي نسخة Sather هذه يشغل 32 بتًا بالضبط، فهو يعدّ من -2147483648 إلى 2147483647.

```sather
   goals : INT is
      return 42;
   end;
```

## الوسائط

يأخذ الإجراء وسائطه بين الأقواس الهلالية، ولكل منها نوع:

```sather
   total(first : INT, second : INT) : INT is
      return first + second;
   end;
```

ويمكن للوسائط التي تشترك في النوع نفسه أن تشترك في التعريف، وهو الأسلوب المعتاد:

```sather
   total(first, second : INT) : INT is
```

## الحساب

| العامل | المعنى |
| --- | --- |
| `+` | الجمع |
| `-` | الطرح، وتغيير الإشارة |
| `*` | الضرب |
| `/` | القسمة مع تجاهل الباقي |
| `%` | باقي تلك القسمة |

لا ينتج عن `/` بين عددين من النوع `INT` كسر أبدًا:

```sather
7 / 2      -- 3
7 % 2      -- 1
```

وإذا أردت كسرًا فأنت بحاجة إلى `FLTD`، الذي سيأتي لاحقًا.

وللضرب والقسمة أولوية أعلى من الجمع والطرح، كما في الحساب العادي. وتُستخدم الأقواس الهلالية للتجميع عند الحاجة إلى نتيجة أخرى:

```sather
2 + 3 * 4        -- 14
(2 + 3) * 4      -- 20
```

## إجراءات مفيدة في `INT`

```sather
7.max(3)     -- 7
7.min(3)     -- 3
(-7).abs     -- 7
7.str        -- "7", the number written as text
```

و`.str` هي الطريقة التي يصبح بها العدد جزءًا من جملة، بعد أن تتعرّف على السلاسل النصية.
