# مقدمة

## عوامل المقارنة

تحتوي R على مجموعة من العوامل تشبه تلك الموجودة في العديد من اللغات الأخرى:

```R
1 == 2 # FALSE
1 != 2 # TRUE
1 < 2 # TRUE
1 > 2 # FALSE
1 <= 2 # TRUE
1 >= 2 # FALSE
```

## التفرع

الصيغة الأساسية للجملة `if-else` هي:

```R
if (x > 10) {
    y <- "big"
} else if (x > 2) {
    y <- "medium"
} else {
    y <- "tiny"
}
```

في هذه الحالة، يجب استخدام الأقواس الهلالية `()` حول القيمة المنطقية والأقواس المعقوفة `{}` حول جسم الجملة. كلاهما مطلوب.

يمكن اختصار جملة `if` البسيطة:

```R
if (x == 0) return("success")
```
