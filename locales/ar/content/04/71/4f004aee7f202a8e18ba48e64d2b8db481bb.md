# مقدمة

## الأنواع المعتمة

الأنواع المعتمة في Gleam هي أنواع مخصصة لا يمكن إلا للوحدة التي تُعرّف النوع إنشاء قيم من ذلك النوع أو مطابقتها بالأنماط. هذا مفيد لإنشاء أنواع يجب استخدامها بطريقة محددة فقط.

تُعرّف الأنواع المعتمة باستخدام الكلمة المفتاحية `opaque`.

```gleam
pub opaque type PositiveInt {
  PositiveInt(inner: Int)
}
```

يُستخدم هذا النوع `PositiveInt` في الحالات التي يُراد فيها عدد صحيح، لكن يجب أن يكون صفرًا أو أكبر. لا يمكن استخدام `Int` العادي في Gleam لأن قيم `Int` يمكن أن تكون سالبة أيضًا.

يمكن للوحدة التي تُعرّف هذا النوع أن تُعرّف دالة للحصول على قيمة العدد الصحيح الداخلية، ودالة لإنشاء النوع `PositiveInt` ستُرجع خطأً إذا لم تكن القيمة موجبة.

```gleam
pub fn from_int(i: Int) -> Result(PositiveInt, String) {
  case i {
    _ if i < 0 -> Error("Value must be positive")
    _ -> Ok(PositiveInt(i))
  }
}

pub fn to_int(i: PositiveInt) -> Int {
  i.inner
}
```

باستخدام API، لا يمكن للوحدات الأخرى إنشاء `PositiveInt` بقيمة سالبة، لذا يمكن لأي دالة تأخذ `PositiveInt` أن تتأكد من أن القيمة موجبة.
