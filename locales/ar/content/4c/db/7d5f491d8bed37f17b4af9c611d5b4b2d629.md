# مقدمة

## المجموعات

المجموعة هي تجميعة من قيم فريدة، لا يمكن تعديلها وليست مرتبة. ويجب أن تكون جميع العناصر في المجموعة من النوع نفسه.

تُعرّف وحدة `gleam/set` النوع `Set` وتوفّر دوال للعمل مع المجموعات.

يمكنك تحويل المصفوفات والمجموعات إلى بعضها بعضًا باستخدام `set.to_list` و`set.from_list`. ترتيب العناصر داخل المجموعة غير مضمون.

```gleam
set.from_list([2, 3, 3, 3, 1, 1, 2])
// -> set.from_list([1, 2, 3])

set.to_list(set.from_list([2, 3, 3, 3, 1, 1, 2]))
// -> [1, 2, 3]
```

يمكنك إنشاء المجموعات وتعبئتها باستخدام `set.new` و`set.insert` و`set.delete`.

```gleam
set.new()
// -> set.from_list([])

let eighty_eight = set.from_list([88])

set.insert(eighty_eight, 88)
// -> set.from_list([88])

set.insert(eighty_eight, 89)
// -> set.from_list([88, 89])

set.delete(eighty_eight, 89)
// -> set.from_list([88])
```

يمكنك الاستعلام عن محتويات المجموعة باستخدام الدالتين `set.contains` و`set.size`.

```gleam
set.contains(eighty_eight, 88)
// -> True

set.size(eighty_eight)
// -> 1
```

يمكن دمج المجموعات باستخدام `set.union` و`set.intersection`.

```gleam
let a = set.from_list([1, 5, 10])
let b = set.from_list([1, 2, 3, 4, 5])

set.union(a, b)
// -> set.from_list([1, 2, 3, 4, 5, 10])

set.intersection(a, b)
// -> set.from_list([1, 5])
```

يمكنك تصفية المجموعات.

```gleam
let is_small = fn(n) { n <= 3 }

set.filter(b, is_small)
// -> set.from_list([1, 2, 3])
```
