# مقدمة

أحيانًا، عندما تمرّ على متتالية، تحتاج إلى *موضع* العنصر إلى جانب العنصر نفسه. عائلة `*-index` في [`sequences`][sequences] تسلّم كليهما إلى كتلة الكود الخاصة بكل عنصر. أما `times` فهي القريبة الشقيقة للتكرار المعدود البسيط، وهي مفيدة عندما تحتاج إلى العدّ فقط، لا إلى متتالية.

## `each-index` و`map-index`: الفهرس داخل كتلة الكود

```
each-index ( seq quot: ( elt index -- )       -- )
map-index  ( seq quot: ( elt index -- newelt ) -- newseq )
```

تستقبل كتلة الكود العنصر الذي يقع أسفل الفهرس، ويأتي `index` في **أعلى** المكدس:

```factor
USING: io kernel math.parser sequences ;

{ "alice" "bob" "carol" } [
    number>string ": " glue print
] each-index
! prints:
! alice: 0
! bob:   1
! carol: 2

{ 10 20 30 } [ + ] map-index .
! => { 10 21 32 }       (index added to each element)
```

تُشغّل `each-index` كتلة الكود من أجل أثرها الجانبي ولا تُرجع شيئًا. أما `map-index` فتجمع نتائج كل عنصر في متتالية جديدة من النوع نفسه الذي عليه المدخل.

## `times`: التكرار المعدود

تُشغّل `times` (في [`math`][math]) كتلة الكود الخاصة بها `n` مرة.

```
times ( n quot: ( -- ) -- )
```

الصيغة المنشورة `( -- )` هي *الحد الأدنى*، ولأن `times` مُعلَّمة بـ `inline`، فإن كتلة كود متوازنة الأثر مثل `( str -- str )` تعمل بلا مشكلة، ويُمرَّر المكدس عبر التكرارات. وهذا يمنحك مراكمًا يعمل بالعدّ دون أي حالة قابلة للتغيير:

```factor
USING: kernel sequences ;

"" 3 [ "clop " append ] times .    ! => "clop clop clop "
```

يرى جسم كل تكرار السلسلة النصية الحالية، ويضيف إليها، ويترك السلسلة النصية الجديدة على المكدس للتكرار التالي. وتنجح الحيلة نفسها مع `each-index` و`map-index` عندما تريد تمرير مراكم عبرها.
