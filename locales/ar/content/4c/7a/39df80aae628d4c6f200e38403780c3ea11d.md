# التعليمات

لقد بدأت للتو العمل في مكتب الاستقبال في صالة تسلق.
يشتري الأعضاء عضويات لعدد من الأشهر، ويسجّلون الدخول والخروج في كل مرة يزورون فيها الصالة.
وقد طلب منك المدير كتابة دالة مساعدة تجيب عن الأسئلة التي يطرحها الأعضاء في أغلب الأحيان.

## 1. حدّد متى تنتهي العضوية

العضوية التي تبدأ في تاريخ معيّن تنتهي في اليوم نفسه من الشهر بعد عدد الأشهر المعطى.
وإذا لم يكن ذلك اليوم موجودًا في شهر الانتهاء، تنتهي العضوية في آخر يوم من ذلك الشهر بدلًا من ذلك.

نفّذ طريقة `FrontDesk.membershipEnd()` التي تأخذ تاريخ بدء العضوية وعدد أشهرها، وتُرجع التاريخ الذي تنتهي فيه:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.membershipEnd(LocalDate.of(2024, 3, 10), 1);
// => LocalDate.of(2024, 4, 10)
frontDesk.membershipEnd(LocalDate.of(2025, 1, 31), 1);
// => LocalDate.of(2025, 2, 28)
```

## 2. اعرض مدة صلاحية العضوية

الصالة تطبع مدة صلاحية العضوية بالسنوات والأشهر والأيام على بطاقة العضوية.

نفّذ طريقة `FrontDesk.membershipLength()` التي تأخذ تاريخ بدء العضوية وتاريخ انتهائها، وتُرجع مدة العضوية على هيئة `Period`:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.membershipLength(LocalDate.of(2023, 3, 10), LocalDate.of(2024, 5, 25));
// => Period.of(1, 2, 15)
```

## 3. احسب الأيام المتبقية في العضوية

كثيرًا ما يسأل الأعضاء عن عدد الأيام المتبقية قبل انتهاء عضويتهم.

نفّذ طريقة `FrontDesk.daysLeft()` التي تأخذ تاريخ اليوم وتاريخ انتهاء العضوية، وتُرجع العدد الإجمالي للأيام من اليوم حتى تاريخ الانتهاء.
عندما يكون تاريخ الانتهاء هو اليوم أو قد مضى بالفعل، فلا توجد أيام متبقية، لذا تُرجع الطريقة `0`:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.daysLeft(LocalDate.of(2024, 1, 15), LocalDate.of(2024, 3, 20));
// => 65
frontDesk.daysLeft(LocalDate.of(2024, 4, 2), LocalDate.of(2024, 3, 20));
// => 0
```

## 4. احسب مدة الزيارة

الصالة مفتوحة على مدار الساعة، وتسجّل البوابة الدوارة تاريخ ووقت تسجيل دخول العضو وخروجه.

نفّذ طريقة `FrontDesk.visitDuration()` التي تأخذ تاريخ ووقت تسجيل الدخول وتسجيل الخروج للزيارة، وتُرجع مدة استمرار الزيارة على هيئة `Duration`:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.visitDuration(LocalDateTime.of(2024, 3, 10, 23, 30), LocalDateTime.of(2024, 3, 11, 1, 15));
// => Duration.ofMinutes(105)
```

## 5. اطبع مدة الزيارة على الإيصال

يُظهر الإيصال مدة الزيارة بالساعات والدقائق، مثل `1h 35m`.
تُكتب الدقائق دائمًا برقمين، وتُهمل أي ثوانٍ، ولا تقتصر الساعات على يوم واحد.

نفّذ طريقة `FrontDesk.formatVisit()` التي تأخذ مدة الزيارة وتُرجعها بهذا التنسيق:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.formatVisit(Duration.ofMinutes(95));
// => "1h 35m"
frontDesk.formatVisit(Duration.ofHours(2).plusMinutes(5));
// => "2h 05m"
frontDesk.formatVisit(Duration.ofHours(26).plusMinutes(10));
// => "26h 10m"
```
