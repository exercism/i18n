# لا تستخدم جملة شرطية متداخلة

جرّب إعادة كتابة الجمل الشرطية لتجنّب التداخل العميق، لأن ذلك قد يؤدي إلى كود يصعب تتبّعه. تأمّل هاتين القطعتين من الكود:

```csharp
void PrintName(Person p)
{
    if (p != null)
    {
        if (p.Name != null)
        {
            if (p.Age >= 21)
            {
                Console.WriteLine(p.Name);
            }
        }
    }
}
```

قارن ذلك بالكود التالي:

```csharp
void PrintName(Person p)
{
  if (p == null || p.Name == null || p.Age < 21)
  {
      return;
  }

  Console.WriteLine(p.Name);
}
```

يتميّز المثال الثاني ببنية محددة جدًا: فكل المسارات التي تتعامل مع الأخطاء تُعالَج داخل كتل مُزاحة للداخل، أما "المسار السعيد" فيبقى دائمًا محاذيًا لأقصى اليسار. وهذا يجعل القراءة سهلة للغاية، إذ يرى القارئ بسرعة ما هو المسار الأكثر شيوعًا والخالي من الأخطاء في الكود.
