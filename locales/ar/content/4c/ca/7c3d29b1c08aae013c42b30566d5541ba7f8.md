# نبذة

[أنواع `cons`][hyper-conses] أحد أنواع البيانات الأساسية في Common Lisp، وتتكوّن من رأس وذيل (يُسمّيان، لسبب [تاريخي][history]، `car` و`cdr`).
لا يوجد أي قيد على أنواع بيانات الرأس والذيل في `cons`.

تُنشأ أنواع `cons` بالدالة [`cons`][hyper-cons] التي تأخذ كائنين وتُقيّم إلى `cons` (ويُطلق عليها أحيانًا اسم خلية `cons`).

يمكن الوصول إلى أجزاء `cons` بالدالتين [`car`][hyper-car] و[`cdr`][hyper-cdr].

## مرجع

```lisp
;; Testing for atoms
(atom 'foo)              ; => T
(atom '(bar baz))        ; => NIL

;; Testing for cons
(consp 'foo)             ; => NIL
(consp '(bar baz))       ; => T

;; First item of a cons
(car '(one two three))   ; => ONE
(first '(one two three)) ; => ONE

;; Rest of a cons
(cdr '(one two three))   ; => (TWO THREE)
(rest '(one two three))  ; => (TWO THREE)
```
