# نبذة

إلى جانب إعلانات الدوال وتعبيرات الدوال، توفّر JavaScript أيضًا صيغة مختصرة جدًا لتعريف دالة.
تُسمّى هذه الدوال _الدوال السهمية_.

في هذا المفهوم، سنركّز على الصيغة المستخدمة لكتابة دالة سهمية.
هناك اختلافات في طريقة عمل الدالة السهمية، مثل ربط `this`، وسنتناولها في مفاهيم أخرى.

إليك مقارنة بين إعلان دالة ودالة سهمية.

```javascript
function addUpTwoNumbers(num1, num2) {
  return num1 + num2;
}

// function keyword removed and => added
const addUpTwoNumbers = (num1, num2) => {
  return num1 + num2;
};
```

في الأعلى، سترى أن صيغة الدالة السهمية:

1. تحذف الكلمة المفتاحية `function`
2. تُعلن المعرّف `addUpTwoNumbers` على أنه `const`
3. تضيف سهمًا عريضًا `=>`

إذا كان جسم الدالة يحتوي على عبارة إرجاع فقط، كما في المثال أعلاه، فيمكن حذف `{}` والكلمة المفتاحية `return`.

<!-- prettier-ignore-start -->
```javascript
const addUpTwoNumbers = (num1, num2) => { return num1 + num2 };

// can be shortened to
const addUpTwoNumbers = (num1, num2) => num1 + num2;
// braces {} and return removed
```
<!-- prettier-ignore-end -->

في الحالة الخاصة التي لا تُرجع فيها الدالة السهمية سوى كائن، لا بد من وضع الأقواس الهلالية حول الكائن حتى يمكن حذف عبارة الإرجاع.

```javascript
// explicit return of object
const addUpTwoNumbers = (num1, num2) => {
  return { num1, num2 };
};

// implicit return of object
const addUpTwoNumbers = (num1, num2) => ({ num1, num2 });
```

يعتمد استخدام الأقواس الهلالية حول المعاملات على عدد المعاملات.

<!-- prettier-ignore-start -->
```javascript
// one parameter does not need parenthesis
const square = num => num * num;

// two or more parameters need to be wrapped in parenthesis
const addUpTwoNumbers = (num1, num2) => num1 + num2;
```
<!-- prettier-ignore-end -->
