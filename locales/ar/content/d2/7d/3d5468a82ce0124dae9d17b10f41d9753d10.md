# مقدمة

## الوحدات

يُنظَّم كود Gleam في وحدات، وكل ملف هو وحدة Gleam واحدة.

حتى الآن كتبنا الدوال باستخدام الصيغة `pub fn`، وهي تعرّف دالة متاحة بشكل عام للوحدات الأخرى. أما الدوال المعرّفة بـ `fn` فهي خاصة بالوحدة التي عُرّفت فيها، ولا يمكن للوحدات الأخرى استخدامها.

```gleam
// This function is public
pub fn add(x, y) {
  x + y
}

// This function is private
fn subtract(x, y) {
  x - y
}
```

للوحدات في Gleam أسماء، ويستند الاسم إلى مسار ملفها داخل مجلد `src` أو `test`.

على سبيل المثال، الوحدة المعرّفة في `src\geometry\rectangle.gleam` (على Windows) أو `src/geometry/rectangle.gleam` (على أنظمة التشغيل الشبيهة بـ UNIX) سيكون اسمها `geometry/rectangle`.

## استيراد الدوال من وحدات أخرى

يتم الوصول إلى الدوال المعرّفة في وحدات أخرى عبر الاستيراد.
عند استيراد وحدة ما، تصبح جميع الدوال التي أتاحتها تلك الوحدة متاحة.
لكن طريقة الوصول إليها تختلف حسب كيفية استيراد الوحدة.

الاستيراد المؤهَّل هو الافتراضي، ويتم الوصول إلى دالة داخل وحدة كهذه (على سبيل المثال الدالة `map` في وحدة `gleam/list`) عبر كتابة اسم الوحدة قبلها (`list.map`).

```gleam
// Import the int module
import gleam/int

pub fn run(x: Int) -> String {
  // Use the to_string function from the int module
  int.to_string(x)
}
```

افتراضيًا، الاسم المستخدم للإشارة إلى الوحدة هو الجزء الأخير من اسم الوحدة، وهو هنا `int`، لكن يمكن تغيير ذلك باستخدام الكلمة المفتاحية `as`.

```gleam
// Import the int module and refer to it as i
import gleam/int as i

pub fn run(x: Int) -> String {
  i.to_string(x)
}
```

الاستيراد غير المؤهَّل يتيح الوصول المباشر إلى الدوال المتاحة داخل تلك الوحدة، دون كتابة اسم الوحدة قبلها.

```gleam
// Import the to_string function from the int module
import gleam/int.{to_string}

pub fn run(x: Int) -> String {
  to_string(x)
}
```

يُفضَّل الاستيراد المؤهَّل لأنه يوضّح للقارئ مصدر الدالة، ولتجنّب تعارض الأسماء.


## المكتبة القياسية

لدى Gleam مكتبة قياسية غنية وموثّقة جيدًا. التوثيق متاح على الإنترنت في [hexdocs.pm/gleam_stdlib][docs]. احفظ هذا الرابط في مكان ما، فستستخدمه كثيرًا!

معظم أنواع البيانات المضمّنة لها وحدة مقابلة تقدّم دوالًا للتعامل مع ذلك النوع، مثل وحدة `gleam/int` للأعداد الصحيحة، ووحدة `gleam/string` للسلاسل النصية، ووحدة `gleam/list` للمصفوفات، وهكذا.

[docs]: https://hexdocs.pm/gleam_stdlib/
