# العامل الثلاثي

يوفر العامل الثلاثي صياغة بديلة لإجراء مقارنة `if..else..` وإرجاع قيمة.

## الصياغة

توفّر PHP جملة شرطية يمكن من خلالها تقييم إجراء بناءً على «صحة» الشرط.

```php
if ($condition) {
  $value = 1;
} else {
  $value = 2
}
```

بدلًا من ذلك، يمكن للعامل الثلاثي تمثيل العملية نفسها:

```php
$value = $condition
  ? 1  // True branch
  : 2; // False branch
```

صياغة المقارنة قصيرة، وتُمثَّل بـ `(condition) ? (evaluate if true) : (evaluate if false);`.

## الفوائد

الفائدة الواضحة لاستخدام العامل الثلاثي هي الإيجاز، فكتابة التعبير الشرطي تصبح قصيرة مقارنةً بجملة `if..else..`، لكن هناك فوائد أخرى عدة أيضًا:

- إنه تعبير يمكن استخدامه داخل تعبير آخر
- يسهّل التقييم المتأخر لكل فرع.

  ```php
  function expensiveCalculation(): int
  {
    // An expensive calculation is performed
    $answerToEverything = 42;
    return $answerToEverything;
  }

  $needExactAnswer = false;
  $estimatedAnswer = 40;
  $answer = $needExactAnswer ? expensiveCalculation() : $estimatedAnswer;
  ```

  في هذا المثال، إذا لم تكن الإجابة الدقيقة مطلوبة، لا يتم استدعاء الحساب المكلف.

## العيوب

للعوامل الثلاثية عدة عيوب، مما يجعل من المهم النظر في استخدامها:

- قد يكون العامل الثلاثي أصعب في القراءة لأنه يعتمد على تفسير الرموز بدلًا من استخدام الكلمات المفتاحية.
- قد يؤدي العامل الثلاثي دون قصد إلى bugs لأن العامل الثلاثي في PHP يترابط من اليسار، على عكس معظم اللغات المعاصرة (مثل C وJava وJavaScript).
- يجب أن يُرجع التعبير المُقيَّم في الفرعين صحيح أو خطأ قيمة.

## أقصر من ذلك

يمكن اختصار صياغة العامل الثلاثي أكثر إلى `(condition) ?: (evaluate if falsey)`.
أحد هذه الاستخدامات هو إمكانية توفير قيمة احتياطية في تعبير:

```php
$fruit = null;
eat($fruit ?: 'apple');
```

يُعرف هذا أيضًا أحيانًا باسم _عامل إلفيس_ (`?:`)
