# مقدمة

## الأعداد الصحيحة

الأعداد الصحيحة هي أعداد كاملة تنتمي إلى المجموعة `{..., -2, -1, 0, 1, 2, ...}`.
تتحدد القيمة العظمى والصغرى للعدد الصحيح وفق النظام الذي يعمل عليه PHP.
وعلى الأنظمة الحديثة عادةً، يكون العدد الصحيح قيمة ذات 64 بت، أي أنه يستطيع تمثيل القيم من `-9_223_372_036_854_775_808` إلى `9_223_372_036_854_775_807` ضمناً.

```php
<?php

$a = 1234;
$a = 1_234_567;
```

يمكنك كتابة قيم الأعداد الصحيحة في أساس غير الأساس 10 باستخدام بادئة الأساس:

```php
<?php

$a = 0123; // octal number (equivalent to 83 decimal)
$a = 0o123; // octal number (as of PHP 8.1.0)
$a = 0x1A; // hexadecimal number (equivalent to 26 decimal)
$a = 0b11111111; // binary number (equivalent to 255 decimal)
```

> مأخوذ من [التوثيق][syntax] الخاص بـ PHP

## الأعداد العائمة

تُستخدم الأعداد العائمة في PHP لتمثيل مجموعة جزئية من الأعداد الحقيقية.
وهي تبدأ برقم واحد أو أكثر تفصل بينها فاصلة عشرية.

```php
<?php

$a = 1.234; 
$b = 1.2e3; 
$c = 7E-10;
$d = 1_234.567; // as of PHP 7.4.0
```

### الأخطاء الشائعة

لا يمكن تمثيل كل الأعداد ولا إجراء كل العمليات الحسابية باستخدام الأعداد العائمة.
واستخدام الأعداد العائمة لتمثيل الدولارات والسنتات قد يؤدي إلى أخطاء في التقريب.

```php
<?php

$result = 0.1 + 0.2; // => 0.30000000000000004
```

## العوامل الحسابية

يوفر PHP عدداً من العوامل لتنفيذ العمليات الحسابية. ويتبع PHP الترتيب الرياضي القياسي للعمليات في عوامله الحسابية. والعوامل التي يوفرها PHP هي:

* الهوية (+)
* النفي (-)
* الجمع (+)
* الطرح (-)
* الضرب (*)
* القسمة (/)
* باقي القسمة (%)
* الرفع إلى قوة (**)

```php
$moles = +'10';
$aLotOfMoles = 6.022 * 10**23 * $moles;
```
