# مقدمة

`Iterator` في Gleam يشبه المصفوفة من حيث إنه مجموعة مرتّبة من القيم، جميعها من النوع نفسه. ويختلف عن المصفوفة في أنه كسول، أي أنه لا يخزّن كل قيمه في الذاكرة دفعة واحدة، بل يحسبها عند الحاجة إليها.

يفيد هذا عند التعامل مع تسلسلات كبيرة جدًا أو حتى لا نهائية الحجم، إذ يتيح لنا التعامل معها حين لا تتوفر لدينا ذاكرة حرة تكفي لتخزينها كلها دفعة واحدة.

تعرّف وحدة `gleam/iterator` النوع `Iterator`، وكذلك الدوال اللازمة للتعامل مع المكرِّرات.

وكثير من دوال المصفوفات لها نظائر للمكرِّرات، مثل `map` و`filter` و`take`. تُرجع هذه الدوال مكرِّرات، لذا فهي لا تنفّذ أي عمل فعلي حتى يُستهلك المكرِّر.

```gleam
let iter = 
  [1, 2, 3, 4, 5, 6]
  |> iterator.from_list
  |> iterator.filter(fn(x) { x > 2 })
  |> iterator.take(2)

// No work has been done yet as the iterator has not been consumed

// Consume the iterator and collect the values into a list
iterator.to_list(iter)
// -> [3, 4]
```

يمكن استخدام دالة `unfold` لإنشاء مكرِّرات من دالة تُستدعى مرارًا لتنتج القيمة التالية في التسلسل.

وهنا تُستخدم دالة `unfold` لإنشاء مكرِّر ينتج متتالية فيبوناتشي:

```gleam 
iterator.unfold(#(0, 1), fn(pair) {
  let x = pair.0 + pair.1
  iterator.Next(element: x, accumulator: #(pair.1, x))
})
|> iterator.take(6)
|> iterator.to_list
// -> [1, 2, 3, 5, 8, 13]
```

التسلسل هنا لا نهائي، لذا تُستخدم دالة `take` لجعله منتهيًا قبل جمع القيم في مصفوفة. وإذا استُدعيت `to_list` على مكرِّر لا نهائي، فسيظل البرنامج يعمل حتى تنفد ذاكرة البرنامج فينهار.
