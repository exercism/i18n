# مقدمة

تُعلن *الكلمة العامة* عن عملية يمكن أن يكون لها تطبيقات مختلفة حسب صنف وسيطها. وتُضاف الطرق باستخدام `M:`.

```factor
USING: kernel math ;

GENERIC: area ( shape -- n )

TUPLE: square side ;
TUPLE: circle radius ;

M: square area side>> dup * ;
M: circle area radius>> dup * 3.14159 * ;
```

```factor
T{ square { side 4 } } area .    ! => 16
T{ circle { radius 2 } } area .  ! => 12.56636
```

تُعلن `GENERIC:` عن الكلمة وأثر المكدس الخاص بها. وتُعرّف `M:` طريقة على صنف معيّن؛ إذ يوجّه Factor الاستدعاء حسب صنف الوسيط الأعلى في المكدس وقت التنفيذ.

يمكنك أن تسأل الكلمة العامة عن الأصناف التي لها طرق، وأن تضيف طرقًا أو تحذفها بعد ذلك. ولا توجد صيغة خاصة للوراثة: فأي صنف `tuple` مؤهل تلقائيًا لتعريف طرق عليه.
