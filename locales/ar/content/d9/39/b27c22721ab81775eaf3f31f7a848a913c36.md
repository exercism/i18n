# التثبيت

تحتاج إلى [Vim](http://www.vim.org) لإنجاز التمارين:

- [macOS](#macos)
- [Ubuntu / Debian](#ubuntu--debian)
- [Windows](#windows)
- [من الشيفرة المصدرية](#source)

## macOS

يأتي نظام التشغيل مزوّدًا بـ Vim افتراضيًا، لكنه نسخة قديمة جدًا بلا أمل.

والأرجح أنك تستخدم إما [MacPorts](https://www.macports.org) أو
[Homebrew](https://brew.sh) لتثبيت البرامج.

Homebrew:

```
$ brew update
$ brew install vim
```

MacPorts:

```
$ sudo port install vim +huge
```

وإن أردت واجهة رسومية، فألقِ نظرة على [MacVim](https://macvim-dev.github.io/macvim)
بدلًا من ذلك.

## Ubuntu / Debian

ثبّت نسخة Vim كاملة مع دعم الواجهة الرسومية (`gvim`):

```
$ sudo apt-get update
$ sudo apt-get install vim-gtk
```

## Windows

باستخدام [Chocolatey](https://chocolatey.org):

```
C:\> choco install vim
```

أو نزّله وثبّته مباشرة من [هنا](http://www.vim.org/download.php#pc).

## من الشيفرة المصدرية

GitHub](https://github.com/vim/vim).
