# مقدمة

المتجه هو مصفوفة أحادية البعد.
وقد تحتوي على عناصر من أنواع مختلفة.

## إنشاء المتجهات

يمكن إنشاء المتجهات عبر الدالة `vector` أو باستخدام صيغة القارئ `#()`

```lisp
(vector 1 t "foo" 'b) ; => #(1 T "foo" B)
#(2 nil "bar" a)      ; => #(2 NIL "bar" A)
```

ولأنها مصفوفات، يمكن إنشاؤها أيضًا باستخدام `make-array`:

```lisp
(make-array 3 :initial-element 'x)        ; => #(X X X)
(make-array 3 :initial-contents '(a b c)) ; => #(A B C)
```

## اختبار المتجه

للتحقق مما إذا كان الكائن متجهًا، استخدم ببساطة الدالة الاختبارية `vectorp`.

## الوصول إلى العناصر

للوصول إلى عناصر المتجه، استخدم `aref`، فالفهارس تبدأ من الصفر:

```lisp
(aref #(1 2 3) 1) ; => 2
(aref #(a b c) 0) ; => A
```
