# مقدمة إلى الجمل الشرطية

## مفهوم الصدق في Bash

لا يملك Bash مفهوم القيم المنطقية.
فهناك السلاسل النصية والأعداد، ومصفوفات من السلاسل النصية أو الأعداد.
فكيف تتعامل الأوامر الشرطية مع الصحيح والخطأ؟

## حالة الخروج

تُنتج الأوامر _حالة خروج_ عند انتهائها.
حالة الخروج عدد صحيح بين 0 و255 ضمنا.
ويعتبر Bash أن حالة خروج تساوي **صفر** تمثل _النجاح_.
وأي حالة خروج أخرى تمثل _الفشل_.

وينطبق هذا على جميع الأوامر، بما فيها الأوامر المدمجة في bash والكلمات المفتاحية والدوال.

## الأمر `if`

الصيغة الأساسية للأمر `if` هي

```bash
if CONDITIONAL_COMMANDS; then TRUE_COMMANDS; else FALSE_COMMANDS; fi
```

يبدأ بـ `if`، وتفصل كلمة `then` بين أوامر الشرط وأوامر «النجاح»، وينتهي بـ `fi`.
وشرط `else` اختياري.

يمكن أن تكون CONDITIONAL_COMMANDS أمرًا واحدًا أو [قائمة أوامر][command-list].

تُنفَّذ CONDITIONAL_COMMANDS، وعندها:

* إذا كانت حالة الخروج صفرًا (نجاح)، تُنفَّذ TRUE_COMMANDS.
* وإذا كانت حالة الخروج غير صفر (فشل)، تُنفَّذ FALSE_COMMANDS إن كانت موجودة.

ويمكن إنشاء فروع متتالية باستخدام `elif`
```bash
if CONDITIONAL_COMMANDS
then TRUE_COMMANDS
elif CONDITIONAL_COMMANDS_2
then TRUE_COMMANDS_2
# more elif branches ...
else FALSE_COMMANDS
fi
```

يجب وجود فاصلة منقوطة أو سطر جديد قبل الكلمات `then` و`elif` و`else` و`fi`.

وللتأكيد: **حالة الخروج** للأوامر الشرطية هي التي تتحكم في مسار التنفيذ.
على سبيل المثال، يُرجع `grep` القيمة 0 عند إيجاد تطابق، و1 عند عدم إيجاده.
ويُخفي الخيار `-q` المخرجات، فلا يُنتج سوى حالة الخروج.

```bash
if grep -q "my pattern" my_file; then echo "the pattern is found in the file"; fi
```

## الأمران `[` و`test`

لا توجد صيغة خاصة حول CONDITIONAL_COMMANDS.
ربما اعتدت رؤية جمل شرطية بهذا الشكل:

```if
if [ "$password" = "secure" ]; then
    echo "Welcome!"
fi
```

`[` ليست صيغة خاصة.
إنه _أمر_ يقيّم التعبير الشرطي ويخرج بحالة نجاح أو فشل.
وكما هو الحال مع جميع الأوامر، فإن المسافة البيضاء **مطلوبة** بينه وبين وسائطه.

`[` هو في الواقع مرادف للأمر `test`.
وهما متطابقان تمامًا، إلا أن الوسيط الأخير لـ `[` _يجب_ أن يكون `]`.

### التعبيرات الشرطية

داخل `[` و`]`، تكتب تعبيرًا شرطيًا.
ومن التعبيرات الشرطية المعتادة:

```bash
[ -f "$filename" ]             # file operations
[ "$string1" = "$string2" ]    # string comparisons
[ "$num1" -eq "$num2" ]        # arithmetic comparisons
```

هناك عمليات أخرى كثيرة متاحة، وهي مُدرجة في قسم [تعبيرات Bash الشرطية][cond-expr] من الدليل.

~~~~exercism/note
في الأمثلة أعلاه، لاحظ أن جميع المتغيرات محاطة بعلامات تنصيص.
الأمران `test` و`[` أمران عاديان، تخضع وسائطهما لتقسيم الكلمات وتوسيع أسماء الملفات مثل أي أمر آخر.

من المهم الإشارة إلى هذا لأن التعبيرات الشرطية تُقيَّم بشكل مختلف حسب _عدد الوسائط_ التي تمررها:

* 0 وسائط: حالة الخروج غير صفر (فشل)
* 1 وسيط: تكون حالة الخروج صفرًا (نجاح) إذا لم يكن الوسيط فارغًا، وغير صفر إذا كان فارغًا.
* 2 وسائط: يجب أن يكون الوسيط الأول عاملًا أحاديًا (مثل `[ -z "$name" ]`)، أو `!` (لنفي حالة اختبار الوسيط الواحد)
* و[المزيد][test].

وقد تحصل على نتائج غير متوقعة إذا نسيت التنصيص:

```bash
str=""

# this prints "empty"
if [ -n "$str" ]; then echo "not empty"; else echo "empty"; fi

# leaving the variable unquoted results in incorrect "not empty" output
if [ -n $str ]; then echo "not empty"; else echo "empty"; fi
```

[test]: https://www.gnu.org/software/bash/manual/bash.html#index-test
~~~~

## الكلمة المفتاحية `[[`

إن [البنية الشرطية `[[...]]`][cond-construct] ليست _أمرًا_، بل هي **كلمة مفتاحية**.
وهذا يعني أنه رغم التعامل معه مثل أي أمر آخر، فإن له قواعد تحليل خاصة.
وما يميز `[[` أن المتغيرات الموسَّعة داخله **لا** تخضع لتقسيم الكلمات أو توسيع أسماء الملفات.
وهذا يعني أن هذا الأمر يتصرف كما تتوقع، حتى بدون تنصيص.

```bash
if [[ -n $str ]]; then echo "not empty"; else echo "empty"; fi
```

يدعم `[[` جميع التعبيرات الشرطية التي يتعامل معها `test` و`[`.
بالإضافة إلى ذلك، يوفر `[[`

* عامل مطابقة التعبيرات النمطية `=~`،
* يعمل `==` و`!=` كعاملي مطابقة نمط glob،
* `&&` و`||` كعوامل منطقية (قاعدة تحليل خاصة)،
* `<` و`>` كعاملي مقارنة سلاسل نصية «مجرّدين» (قاعدة تحليل خاصة: لأنهما رمزا إعادة توجيه، فيجب تهريبهما داخل `[`).

يُرى على نطاق واسع أن هذه الميزات الخاصة تقدم فائدة كبيرة لدرجة أنه ينبغي استخدام `[[` حصرًا.
(على سبيل المثال، [Google Shell Style Guide][goog-test].)

## الأمر `case`

[`case`][case] أمر آخر من أوامر التحكم في مسار التنفيذ.
إنه أشبه بعبارة «switch» في لغات أخرى.

```bash
case WORD in [PATTERN [| PATTERN]...) COMMANDS ;;]... esac
```

تُطابَق WORD مع كل PATTERN.
وعند مطابقة أحدها، تُنفَّذ COMMANDS.

```bash
read -p "Guess the secret word: " word
case "$word" in
    secret) echo "Yes, you guessed it!" ;;
    ??????) echo "That's the right number of letters." ;;
    s*)     echo "You guessed the first letter." ;;
    *)      echo "Not even close! Try again." ;;
esac
```

يجب أن تنتهي كل جملة COMMANDS بفاصلتين منقوطتين **اثنتين**، `;;`.
