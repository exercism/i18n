# التعليمات

صديقك لينوس سائق قطارات يقود قطارات الشحن بين المدن.
وهو بارع جدًا في التعامل مع القطارات، لكنه ليس بارعًا في التعامل مع الخدمات اللوجستية أو الحواسيب.
ويرغب في الاستعانة بمساعدتك البرمجية لتنظيم تفاصيل القطارات وتصحيح الأخطاء في بيانات المسارات.

```exercism/note
للتدريب، استخدم عامل `rest` أو `spread` لحل كل مهمة من المهام التالية.
```

## 1. أنشئ مصفوفة بكل العربات

كان صديقك يتابع معرّف كل عربة (ID)، لكنه لا يعرف أبدًا عدد العربات التي سيتعيّن على النظام معالجتها في أي لحظة.
سيكون من الأسهل بكثير لبقية برنامج اللوجستيات أن تُجمَّع هذه البيانات في `array` موحّد.

نفّذ دالة `getListOfWagons` تقبل عددًا غير محدّد من معرّفات العربات، وهي معرّفات كل عربة.
سيكون كل معرّف عددًا صحيحًا موجبًا.
وعلى الدالة بعد ذلك أن تُرجع المعرّفات المعطاة في `array` واحد.

```javascript
getListOfWagons(1, 7, 12, 3, 14, 8, 5);
// => [1, 7, 12, 3, 14, 8, 5]
```

## 2. انقل أول عنصرين إلى نهاية المصفوفة

في هذه المرحلة، بدأت تتكوّن لديك فكرة عن البيانات وعن كيفية استخدامها في برنامج اللوجستيات.
يخصّص نظام المعرّفات دائمًا للقاطرة المعرّف **1**، بينما تُخصَّص بقية عربات القطار معرّفًا عشوائيًا مختارًا أكبر من **1**.

اضطر صديقك إلى ربط عربتين جديدتين بالقطار، لكنه نسي تحديث النظام!
الآن، يجب نقل أول عربتين في `array` القطار إلى النهاية، وإلا فسيختل ترتيب كل شيء.

سيكون لينوس ممتنًا لك حقًا لأنك صحّحت أخطاءه.

نفّذ دالة `fixListOfWagons` تقبل مصفوفة تحتوي على معرّف كل عربة.
وهي تُرجع، عبر الكلمة المفتاحية `return`، `array` يُنقل فيه أول عنصرين إلى نهاية `array` بحيث تكون القاطرة في المقدمة.

```javascript
eachWagonsID = [2, 5, 1, 7, 4, 12, 6, 3, 13];
fixListOfWagons(eachWagonsID);
// => [1, 7, 4,  12, 6, 3, 13, 2, 5]
```

## 3. أضف القيم المفقودة

أوه. يبدو أن بعض العربات قد ضاعت.

لحسن الحظ، وجد صديقك للتو `array` آخر يبدو أنه يحتوي على معرّفات العربات المفقودة، ويرغب في أن تضيفها إلى `array` معرّفات العربات الرئيسي.
وكل ما يتذكّره هو أن القيم المفقودة يجب أن تُوضع مباشرة بعد القاطرة المحدّدة.

بناءً على هذه المعلومات الجديدة، اكتب دالة تُسمّى `correctListOfWagons` تأخذ مصفوفتين تحتويان على معرّفات كل عربة كوسائط.
يجب إضافة معرّفات العربات الموجودة في `array` الثاني إلى `array` الأول مباشرة بعد القاطرة (ID 1).

```javascript
eachWagonsID = [1, 5, 20, 7, 4, 8];
missingWagons = [3, 17, 6, 15];
correctListOfWagons(eachWagonsID, missingWagons);
// => [1, 3, 17, 6, 15, 5, 20, 7, 4, 8]
```

## 4. وسّع معلومات المسارات

الآن بعد أن أصبحت جميع بيانات العربات صحيحة، يرغب صديقك في أن تحدّث معلومات المسارات في النظام.
أُنشئت معلومات المسارات الأولية على شكل `object`، ويرغب صديقك في أن تحدّثها بالإضافة المقدَّمة.
كل مسار يتطلب معلومات مختلفة قليلًا، لذلك يفضّل صديقك حقًا حلاً عامًا.

نفّذ دالة `extendRouteInformation` تقبل `objects` اثنين.
يحتوي `object` الأول على المدن التي يتنقّل بينها مسار القطار.

ويحتوي `object` الثاني على تفاصيل أخرى للمسار مثل سرعة القطار أو طوله.
وعلى الدالة أن تُرجع `object` موحّدًا يحوي جميع معلومات المسارات.

```exercism/note
يمكن أن يحتوي المتغير `moreRouteInformation` على خصائص مختلفة.
```

```javascript
route = { from: 'Berlin', to: 'Hamburg' };
moreRouteInformation = { length: '100', speed: '50' };
extendRouteInformation(route, moreRouteInformation);
// => {from: "Berlin", to: "Hamburg", length: "100", speed: "50"}
```

## 5. افصل وقت الوصول عن معلومات المسارات

لاحظ صديقك أنه لا يحتاج وقت الوصول ضمن معلومات المسارات.
لذلك يرغب صديقك في أن تفصل وقت الوصول عن معلومات المسارات.

نفّذ دالة `separateTimeOfArrival` تقبل كائنًا يحتوي على معلومات المسارات.
وعلى الدالة أن تُرجع مصفوفة يكون فيها العنصر الأول وقت الوصول، والعنصر الثاني كائنًا يحوي معلومات المسارات دون وقت الوصول.

```javascript
routeInformation = {
  from: 'Berlin',
  to: 'Hamburg',
  length: '100',
  timeOfArrival: '10:10',
};
separateTimeOfArrival(routeInformation);
// => ["10:10", {from: "Berlin", to: "Hamburg", length: "100"}]
```
