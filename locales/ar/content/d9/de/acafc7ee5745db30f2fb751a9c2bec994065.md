# مقدمة

## الثوابت

الثوابت في Gleam طريقة لإعطاء أسماء للقيم. تُعرَّف باستخدام الكلمة المفتاحية `const`.

```gleam
pub const pi: Float = 3.14159

pub fn circle_area(radius: Float) -> Float {
  radius *. radius *. pi
}
```

عند تعريفها باستخدام الكلمة المفتاحية `pub` يمكن الوصول إلى ثوابت الوحدة من وحدات أخرى، وإلا فلا يمكن الوصول إليها إلا من داخل الوحدة التي عُرِّفت فيها.

## الرتب

تحتوي وحدة `gleam/order` في المكتبة القياسية لـ Gleam على النوع `Order`، الذي يُستخدم لمقارنة القيم.

يبدو تعريف `Order` هكذا:

```gleam
pub type Order {
  Gt
  Eq
  Lt
}
```

للنوع ثلاث صيغ، تُستخدم كل واحدة لتمثيل العلاقة بين قيمة وقيمة أخرى:

- `Gt` - القيمة _أكبر من_ القيمة الأخرى.
- `Eq` - القيمة _تساوي_ القيمة الأخرى.
- `Lt` - القيمة _أصغر من_ القيمة الأخرى.

إذا كان يمكن مقارنة نوع بيانات ما من حيث الحجم، فمن الشائع أن تُعرِّف الوحدة دالة `compare` تُرجع قيمة `Order`. على سبيل المثال، تُعرِّف وحدتا `gleam/float` و`gleam/int` دالتي `compare` تعملان على الأعداد العشرية والأعداد الصحيحة على التوالي.

```gleam
int.compare(1, 2)
// -> Lt

int.compare(2, 2)
// -> Eq

float.compare(1.0, 2.0)
// -> Lt
```

عادةً ما تأخذ دوال الترتيب مثل `list.sort` دالة تُرجع قيمة `Order`، مما يتيح للمستدعي تحديد كيفية ترتيب المصفوفة.

```gleam
list.sort([3, 7, 3, 1], by: int.compare)
// -> [1, 3, 3, 7]
```
