# نبذة

## التعبير الشرطي `if`

**التعبير الشرطي** في `jq` هو `if A then B else C end`.

`if-then-else` مُرشِّح مثل جميع الدوال المدمجة في `jq`: فهو يأخذ مُدخلًا وينتج مُخرجًا.

إذا أنتج التعبير `A` قيمة "صحيحة"، فإن مُرشِّح `if` يُقيِّم `B`. وإلا فإنه يُقيِّم `C`. وسيُمرَّر مُدخل مُرشِّح `if` إلى `B` أو `C`.

```jq
42 | if . < 50 then "small" else "big" end      # => "small"
```

```jq
5 | if . % 2 == 0 then . / 2 else . * 4 end     # => 20
```

~~~~exercism/note
جملة `else` **اختيارية**؛ فالعبارتان التاليتان متكافئتان.

```jq
if A then B else . end
if A then B end
```
~~~~

## الجمل الشرطية المتداخلة

يمكن إضافة شروط أخرى باستخدام `elif`.

```jq
42 | if . < 33 then "small"
     elif . < 66 then "medium"
     else "big"
     end
# => "medium"
```

استخدم أكبر عدد تحتاج إليه من جمل `elif`.

## الصحة المنطقية

القيم "الخاطئة" الوحيدة في `jq` هي: `false` و`null`. وكل ما عدا ذلك "صحيح"، حتى العدد صفر والسلسلة النصية الفارغة والمصفوفة الفارغة والكائن الفارغ.

## العوامل المنطقية

يمكن استخدام **العوامل المنطقية** `and` و`or` لبناء استعلامات معقدة.

```jq
42 | if . < 33 or . > 66 then "big or small"
     else "medium"
     end
```

للنفي، استخدم `not`. فهو **مُرشِّح** وليس عاملًا.

```jq
42 | if (. < 33 or . > 66 | not) then "medium"
     else "big or small"
     end
```

## عامل البديل

يتيح لك **عامل البديل** تحديد قيمة "افتراضية" إذا كان التعبير خطأ أو `null`.

```jq
A // B

# This is identical to
if A then A else B end
```

وللتوضيح

```jq
[3, 5, 18] | add / 2       # => 13
[]         | add / 2       # => error: null (null) and number (2) cannot be divided
[]         | add // 0 / 2  # => 0
```

## هل هناك المزيد؟

قد يتوقع المبرمجون القادمون من لغات أخرى تنوعًا أوسع من أوامر الشرط، مثل `cond` و`case` و`switch` و`when` و`unless`، أو عامل ثلاثي، وما إلى ذلك. لكن العوامل المذكورة أعلاه هي كل ما يقدمه `jq`.
