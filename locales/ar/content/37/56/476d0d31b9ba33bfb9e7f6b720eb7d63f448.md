# مقدمة

في البرمجة، من الضروري التعامل مع الأخطاء بسلاسة لضمان ألا تتسبب المواقف غير المتوقعة في تعطل البرنامج أو تصرفه بشكل غير متوقع.
توفّر Cairo آليتين رئيسيتين للتعامل مع الأخطاء:

1. **الأخطاء غير القابلة للاسترداد** باستخدام `panic`، وهي توقف البرنامج فورًا.
2. **الأخطاء القابلة للاسترداد** باستخدام `Result`، وهي تتيح للبرنامج التعامل مع الأخطاء والاستجابة لها.

## الأخطاء غير القابلة للاسترداد باستخدام `panic`

في بعض الأحيان، يواجه البرنامج خطأً بالغ الخطورة بحيث لا يستطيع المتابعة.
تستخدم Cairo دالة `panic` لإيقاف التنفيذ فورًا في مثل هذه الحالات.
وهذا مفيد عندما يستحيل على البرنامج، بسبب خطأ ما مثل محاولة الوصول إلى فهرس خارج الحدود، أن يواصل بطريقة معقولة.
وتقبل دالة `panic` رسالة من نوع `ByteArray` تصف سبب الخطأ.

على سبيل المثال، في Cairo:

```rust
fn main() {
    let data = array![1, 2];
    panic("An unrecoverable error has occurred!");
}
```

يوضّح هذا المثال `panic` قسريًا يوقف البرنامج فورًا مع رسالة.

### ماكرو `assert!`

ماكرو `assert!` أداة مفيدة لفرض شروط محددة في الكود.
إذا كان ناتج تقييم الشرط في `assert!` هو `false`، فسيستدعي البرنامج `panic` برسالة خطأ من نوع `ByteArray`.
ويُستخدم هذا غالبًا للتحقق من الافتراضات أثناء التطوير ولضمان استيفاء القيم لمعايير معينة.

على سبيل المثال:

```rust
fn main() {
    let x = 5;
    assert!(x > 0, "x must be greater than zero");
}
```

إذا لم تكن `x` أكبر من صفر، فسيستدعي البرنامج `panic` برسالة `"x must be greater than zero"`. ماكرو `assert!` مفيد للتحقق من الشروط الثابتة والشروط المسبقة دون كتابة كود لمعالجة الأخطاء يدويًا.

## الأخطاء القابلة للاسترداد باستخدام `Result`

ليست كل الأخطاء بحاجة إلى إيقاف البرنامج.
فبعضها يمكن التعامل معه بسلاسة كي يواصل البرنامج عمله.
يمثّل تعداد `Result` في Cairo هذه الأخطاء القابلة للاسترداد، وله صيغتان:

- `Result::Ok` يشير إلى النجاح.
- `Result::Err` يمثّل خطأ.

وباستخدام `Result`، تستطيع الدالة أن تُرجع إما قيمة نجاح وإما خطأ، ما يتيح للدالة المستدعية أن تقرر ما ستفعله بعد ذلك.

```rust
fn divide(a: u32, b: u32) -> Result<u32, ByteArray> {
    if b == 0 {
        Result::Err("Error: Division by zero")
    } else {
        Result::Ok(a / b)
    }
}
```

في هذا المثال، إذا كانت `b` تساوي صفرًا، فيُرجَع خطأ؛ وإلا، فتُرجَع نتيجة القسمة.
