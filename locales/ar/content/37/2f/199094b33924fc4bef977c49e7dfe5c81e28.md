# التعليمات

مرحبًا أيها العميل Double-Null0111.

مهمتك، إن اخترت قبولها، هي كتابة أداتين تساعدانك على التسلل إلى مقر UMBRA (United Minions Being Really Awful) والحصول على مخططات أحدث خطة فظيعة حقًا لديهم.
ستحتاج إلى ثلاث أدوات لتنفيذ هذه المهمة.

## 1. أنشئ رقم معرّف

لكل تابع معرّف فريد يتغير كل يوم، ويعتمد على عدد الأسرار التي يحتفظ بها وعدد الساعات التي ينامها.
ستحتاج إلى كتابة دالة تأخذ اليوم (على شكل `Int`) وتنشئ دالة لتوليد المعرّف الخاص بذلك اليوم.
تأخذ دالة توليد المعرّف معاملَين اثنين:

1. عدد الأسرار التي يحتفظ بها
2. عدد الساعات التي ينامها التابع

يُحسب المعرّف عبر:

1. ضرب عدد الأسرار التي يحتفظ بها في عدد الساعات التي ينامها
2. إضافة اليوم (ممثلًا بـ `Int`) إلى الناتج

```kotlin
val idGenerator = makeIdGenerator(4)
idGenerator(3, 6)
// => 22

idGenerator(11, 5)
//  => 59
```

## 2. احمِ الخطط السرية المستعادة بكلمة مرور سرية

بمجرد أن تحصل على الخطط السرية، ستحتاج إلى حمايتها بحيث لا يستطيع استعادتها إلا من يعرف كلمة المرور.
للقيام بذلك، ستحتاج إلى تنفيذ الدالة `protectSecret(secret: String, password: String) : (String) -> String`.
ستُرجع هذه الدالة دالة أخرى تأخذ سلاسل نصية محتملة لكلمات المرور كمدخل.
إذا كانت كلمة المرور المُدخلة صحيحة، تُرجع الدالة الجديدة السر المخفي، أما إذا كانت كلمة المرور غير صحيحة، فتُرجع الدالة "Sorry. No hidden secrets here."

```kotlin
val secretFunction = protectSecret("Steal the world's supply of french fries!", "5up3r53cr37")

secretFunction("Open sesame")
// Returns "Sorry. No hidden secrets here."

secretFunction("5up3r53cr37")
// Returns "Steal the world's supply of french fries!"
```

## 3. اعثر على كلمة المرور السرية

تحتوي قاعدة UMBRA على عدد من الغرف يحرسها حارس أمن يسألك عن كلمة المرور السرية.
تعتمد كلمة المرور السرية على رقم الغرفة.
لسوء الحظ، لا نعرف إلا نصف الخوارزمية التي تُستنتج بها كلمة المرور.
يمكن معرفة النصف الآخر بسؤال أحد الأتباع.

نفّذ الدالة `getPassword` التي تأخذ ما يلي وتُرجع كلمة المرور:

1. رقم الغرفة
2. دالة التابع وتُرجع كلمة المرور السرية

يُحصل على كلمة المرور السرية عبر استدعاء دالة التابع بدالة أخرى تمثل الخوارزمية التي نعرفها.
الجزء الخاص بنا من الخوارزمية:

1. تأخذ عددين وتجمعهما معًا
2. تضرب الناتج في معرّف الغرفة

```kotlin
val minionFunction = { yourFunc : (Int, Int) -> Int ->
    "Password=${yourFunc(1, 3)}"
}

getPassword(5, minionFunction)
// Returns "Password=20"
```
