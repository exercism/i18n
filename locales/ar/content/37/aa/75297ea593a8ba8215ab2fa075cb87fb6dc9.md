# التعليمات

مهمتك هي تحديد ما ستقوله وأنت تُهدي الكعكة الإضافية.

إذا كان صديقك يحب الكعك، وكان اسمه Do-yun، فستقول:

```text
One for Do-yun, one for me.
```

إذا كان صديقك لا يحب الكعك، فإنك تعطي الكعكة للشخص التالي في الصف في المخبز.
وبما أنك لا تعرف اسمه، فستقول _you_ بدلًا من ذلك.

```text
One for you, one for me.
```

إليك بعض الأمثلة:

| الاسم   | الحوار                    |
| :----- | :-------------------------- |
| Alice  | One for Alice, one for me.  |
| Bohdan | One for Bohdan, one for me. |
|        | One for you, one for me.    |
| Zaphod | One for Zaphod, one for me. |
