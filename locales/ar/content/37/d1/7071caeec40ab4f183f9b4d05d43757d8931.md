# حول

في Haxe، النوع المجرد هو نوع يكون نوعًا مختلفًا في وقت التشغيل. وهو ميزة وقت الترجمة التي تعرّف أنواعًا "فوق" أنواع ملموسة لتعديل سلوكها أو توسيعه:

```haxe
abstract AbstractInt(Int) {
    inline public function new(i:Int) {
        this = i;
    }
}
```

هنا نعرّف النوع `AbstractInt` باستخدام الكلمة المفتاحية `abstract`. صياغته مشابهة جدًا لصياغة `class`. ومثل الأصناف تمامًا، يمكن للأنواع المجردة أن تمتلك طرقًا. ويمكن أيضًا إنشاؤها واستخدامها تمامًا مثل الأصناف:

```haxe
class Main {
    static public function main() {
        var a = new AbstractInt(12);
        trace(a); // 12
    }
}
```

كما ذكرنا أعلاه، تُعد الأنواع المجردة ميزة من ميزات وقت الترجمة. عند ترجمة المثال أعلاه إلى JavaScript نحصل على ما يلي:

```javascript
var a = 12;
console.log(a)
```

يختفي النوع المجرد `AbstractInt` تمامًا من الناتج. وذلك لأن منشئ `Abstract` [مضمّن][inline]، وسنرى ذلك لاحقًا.

[inline]: https://haxe.org/manual/class-field-inline.html
