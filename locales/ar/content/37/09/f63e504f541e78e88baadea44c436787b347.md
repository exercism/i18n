# السلاسل النصية

تمتلك Crystal نوعًا يُعرف باسم [`String`][strings]، وهو يُستخدم لتمثيل النصوص.
السلاسل النصية في Crystal متتاليات من محارف Unicode.
والسلاسل النصية غير قابلة للتغيير، أي أنه لا يمكن تغييرها بعد إنشائها.
هذا يعني أنه تُنشأ سلسلة نصية جديدة في كل مرة تعدّل فيها سلسلةً نصية؛ وبالتالي لا تتغير السلسلة النصية الأصلية.

لتعريف سلسلة نصية تستخدم علامات التنصيص المزدوجة `"`.

```crystal
"Hello World"
```

## الدمج

لدمج سلسلتين نصيتين، استخدم العامل `+`.
سيُرجع العامل `+` سلسلة نصية جديدة تجمع السلسلتين.

```crystal
hello = "Hello"
hello + " World"
# => "Hello World"
```

## التحويل بين السلاسل النصية والأعداد

تُحوّل الطريقة `to_i` سلسلة نصية إلى عدد صحيح.
وبدلًا من ذلك، يمكن استخدام الطريقة `to_f` لإرجاع عدد عشري.
وإذا تعذّر تحويل السلسلة النصية إلى عدد فسيُرفع `ArgumentError`.

```crystal
"1".to_i
# => 1

"1.0".to_f
# => 1.0

"Hello".to_i
# => ArgumentError: Invalid integer: Hello
```

ويمكن تحويل عدد صحيح أو عدد عشري إلى سلسلة نصية باستخدام الطريقة `to_s`.

```crystal
1.to_s
# => "1"

1.0.to_s
# => "1.0"
```

## الإقحام

الإقحام طريقة ملائمة لدمج السلاسل النصية وتضمين التعبيرات داخلها.
لإقحام قيمة في سلسلة نصية، يمكنك استخدام المحرف `#` متبوعًا بأقواس معقوفة `{}` مع التعبير داخل الأقواس.

```crystal
name = "World"
"Hello #{name}!"
# => "Hello World!"
```

ستحوّل Crystal تلقائيًا نتيجة التعبير إلى سلسلة نصية.

```crystal
"Hello #{1 + 1}!"
# => "Hello 2!"
```

## الحجم

عندما تحتاج إلى معرفة عدد المحارف في سلسلة نصية، يمكنك استخدام الطريقة `size`، التي تُرجع طول السلسلة النصية على شكل عدد صحيح.
حجم السلسلة النصية خاصية مخزّنة فيها، لذا لا يلزم حساب الحجم في كل مرة تستدعي فيها الطريقة، وهذا يجعلها سريعة جدًا.

```crystal
"Hello World".size
# => 11
```

## الفهرسة

الفهرسة تعني الحصول على محرف معيّن من سلسلة نصية.
وللحصول على محرف من `String` يمكنك استخدام صيغة الأقواس المربعة المألوفة.

~~~~exercism/note
`[]` مُنفَّذة كطريقة نسخة في `Bool`، حيث يكون الفهرس هو وسيط الطريقة.
~~~~

يقع أول محرف في سلسلة نصية عند الفهرس 0.

```crystal
"Hello World"[0]
# => 'H'

"Hello World"[6]
# => 'W'
```

للحصول على محرف من نهاية سلسلة نصية، يمكنك أخذ طول السلسلة ناقص واحد للحصول على فهرس المحرف الأخير، وللحصول على المحرف قبل الأخير يمكنك أخذ الطول ناقص اثنين، وهكذا.
وهناك اختصار لذلك، وهو استخدام فهرس سالب ببساطة، حيث يقع المحرف الأخير عند الفهرس -1، والمحرف قبل الأخير عند الفهرس -2، وهكذا.

```crystal
name = "Hello World"
name[name.size - 1]
# => 'd'

name[-1]
# => 'd'
```

### اختبار السلسلة الفرعية

تدعم Crystal التحقق مما إذا كانت سلسلة نصية تحتوي على سلسلة فرعية باستخدام الفهرسة.
صيغة الأقواس نفسها تقوم بذلك، لكن بدلًا من فهرس تُعطى سلسلة فرعية.
وإذا وُجدت السلسلة الفرعية في السلسلة النصية فستُرجَع السلسلة الفرعية، وإلا فسيُرفع `NilAssertionError`.

```crystal
"Hello World"["Hello"]
# => "Hello"

"Hello World"["Goodbye"]
# => NilAssertionError
```

وإذا أردت قيمة منطقية تشير إلى ما إذا كانت السلسلة الفرعية موجودة، فيمكنك استخدام الطريقة `includes?`.

```crystal
"Hello World".includes?("Hello")
# => true

"Hello World".includes?("Goodbye")
# => false
```

## الهروب

بعض المحارف لا يمكن كتابتها في سلسلة نصية مباشرة، بل عليك استخدام تسلسل هروب.
على سبيل المثال، إذا أردت استخدام علامات تنصيص مزدوجة في سلسلة نصية، فعليك تهريب علامات التنصيص المزدوجة.
ويمكنك استخدام المحرف `\` لكتابة تسلسل هروب متبوعًا بالمحرف الذي تريد تهريبه.

هذه هي المحارف الخاصة في Crystal:

| القيمة   | الوصف                         |
| -------- | ----------------------------- |
| `\a`     | تنبيه                         |
| `\b`     | مسافة للخلف                   |
| `\e`     | هروب                          |
| `\f`     | تغذية الصفحة                  |
| `\n`     | تغذية سطر أو سطر جديد         |
| `\r`     | إرجاع المؤشر                  |
| `\t`     | جدولة أفقية                   |
| `\v`     | جدولة رأسية                   |
| `\\`     | شرطة مائلة عكسية              |
| `\'`     | علامة تنصيص مفردة             |
| `\"`     | علامة تنصيص مزدوجة            |
| `\377`   | محرف ASCII ثماني              |
| `\xFF`   | محرف ASCII ست عشري            |
| `\uFFFF` | محرف Unicode ست عشري          |

```crystal
puts "Hello \"World\""
# => Hello "World"

puts "Hello \nWorld"
# => Hello
# => World
```

## السلاسل النصية متعددة الأسطر

لكتابة سلسلة نصية متعددة الأسطر، تستخدم الصيغة نفسها الخاصة بسلسلة من سطر واحد، لكن تنتقل إلى سطر جديد لكل سطر تريده في السلسلة النصية.

```crystal
"Hello
World"
# => "Hello\nWorld"
```

## Unicode

[Unicode][unicode] معيار لترميز النصوص وتمثيلها ومعالجتها في مختلف أنظمة الكتابة.
ويدعم Unicode أكثر من 100,000 محرف، تشمل الحروف وعلامات الترقيم والرموز والرموز التعبيرية.

وبما أن Crystal تستخدم Unicode في السلاسل النصية، فيمكنك مثلًا وضع الرموز التعبيرية في السلاسل النصية.

```crystal
"Hello 🌍"
# => "Hello 🌍"
```

أحيانًا تريد استخدام محرف غير متاح في محررك أو نظامك مثلًا.
في هذه الحالة يمكنك استخدام تسلسل هروب Unicode لكتابة المحرف.

```crystal
"\u{1F310}"
# => "🌐"
```
