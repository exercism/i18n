# مقدمة

لا يوجد في لغة Go مفهوم للقيمة الفارغة أو المنعدمة أو غير المعرّفة لقيم المتغيرات.
المتغيرات المعلَنة دون قيمة ابتدائية صريحة تأخذ افتراضيًا القيمة الصفرية لنوعها.

القيمة الصفرية للأنواع الأولية مثل القيم المنطقية والأنواع العددية والسلاسل النصية هي `false` و`0` و`""` على الترتيب.

المعرّف `nil`، بمعنى الصفر، هو القيمة الصفرية للأنواع الأكثر تعقيدًا مثل المؤشرات والدوال والواجهات والشرائح والقنوات والخرائط.

يوضّح الجدول التالي القيمة الصفرية لأنواع Go.

| النوع     | القيمة الصفرية |
| --------- | -------------- |
| قيمة منطقية | `false`    |
| عددية     | `0`        |
| سلسلة نصية | `""`       |
| مؤشر      | `nil`      |
| دالة      | `nil`      |
| واجهة     | `nil`      |
| شريحة     | `nil`      |
| قناة      | `nil`      |
| خريطة     | `nil`      |

ربما لاحظت أن أنواع البُنى غائبة عن الجدول أعلاه.
وذلك لأن القيمة الصفرية لنوع البنية تعتمد على حقوله.
تُضبط البُنى على قيمتها الصفرية عندما تُضبط جميع حقولها على قيمتها الصفرية.
