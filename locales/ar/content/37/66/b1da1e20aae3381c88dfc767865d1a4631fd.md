# ملحق التعليمات

## تعليمات خاصة بالمسار

من المفروض أن تُرجع الدوال حاصل الضرب، وكذلك إزاحة مصفوفة العوامل وطولها.
تُكتب العوامل ببساطة كأزواج من `i32` في الذاكرة:

```
Return value:
[u32 $product] [u32 $factorsOffset] [u32 $factorsLength]

Memory at $factorsOffset
[u32 firstFactor] [u32 firstCofactor] [u32 secondFactor] [u32 secondCofactor] ...
```

بالنسبة لأكبر حاصل ضرب متناظر مكوّن من رقم واحد، سيبدو الشكل هكذا:

```
Return value
0009 0000 0004

Memory at offset 0
0001 0009 0003 0003
```
