# ملحق التعليمات

## طباعة الشجرة

يتضمّن هذا التمرين بعض طرق الصنف المعرّفة مسبقًا التي تساعد في طباعة الشجرة بتنسيق جميل. غرضها الأساسي هو المساعدة في تصحيح الأخطاء وتقديم مزيد من الوضوح. وإذا نفّذت بقية الصنف بشكل صحيح، فسيطبع لك الشجرة.

```powershell
.Example
$tree = [BinarySearchTree]::new(@(50, 76, 1, 34, 89, 44, 25, 6, 26, 100, 13))
$tree.ToString()

Return:
@"
50
├──L:1
│   └──R:34
│       ├──L:25
│       │   ├──L:6
│       │   │   └──R:13    
│       │   └──R:26        
│       └──R:44
└──R:76
    └──R:89
        └──R:100
"@
```
