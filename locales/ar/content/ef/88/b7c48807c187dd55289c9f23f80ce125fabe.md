# إضافة التعليمات

## تلميحات

لإكمال هذا التمرين، عليك إنشاء نوع البيانات `LinkedList`، وتنفيذ الدوال التالية:

- `datum`
- `fromList`
- `isNil`
- `new`
- `next`
- `nil`
- `reverseLinkedList`
- `toList`

ستجد إعلان بيانات وهميًا وتوقيعات الأنواع موجودة بالفعل، لكن الأمر متروك لك لتعريف الدوال وإنشاء نوع بيانات ذي معنى، أو `newtype`، أو مرادف نوع.
