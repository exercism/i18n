# القيم المنطقية

يحتوي Crystal على نوع يُعرف باسم [`Bool`][bools].
وهو يمثّل القيمتين `true` و `false`.

## العوامل المنطقية

يحتوي Crystal على ثلاثة عوامل منطقية (`!` و `||` و `&&`)، وهي تدمج القيم المنطقية وتكوّن تعبيرات تُنتج قيمًا مختلفة.

### العطف (`&&`)

يُمثَّل [عامل العطف][and] في Crystal بـ `&&`، ويُرجع `true` إذا كانت القيمتان `true`؛ وإلا فإنه يُرجع `false`.
عند استخدام عامل العطف، توضع قيمة منطقية على يمين `&&` وأخرى على يساره.

```crystal
true && true
# => true

true && false
# => false
```

### الفصل (`||`)

يُمثَّل [عامل الفصل][or] في Crystal بـ `||`، ويُرجع `true` إذا كانت **قيمة واحدة على الأقل** من القيم المعطاة هي `true`.
وإذا كانت القيمتان كلتاهما `false`، فإنه يُرجع `false`.
عند استخدام عامل الفصل، ينبغي وضع قيمة منطقية على يمين `||` وأخرى على يساره.

```crystal
true || true
# => true

true || false
# => true

false || false
# => false
```

### النفي (`!`)

يُمثَّل عامل النفي في Crystal بـ `!`، ويُرجع `true` إذا كانت القيمة المنطقية المعطاة `false`، ويُرجع `false` إذا كانت المعطاة `true`.
عند استخدام عامل النفي، توضع القيمة المنطقية بعد العامل (`!`).

```crystal
!true
# => false

!false
# => true
```

## استخدام الأقواس الهلالية (`()`)

عند التعامل مع القيم المنطقية، يمكنك استخدام الأقواس الهلالية لتحديد أي القيم المنطقية تُقيَّم أولًا.
قد تختلف النتيجة حسب طريقة استخدام الأقواس الهلالية.
في Crystal، ما بداخل الأقواس الهلالية يُقيَّم أولًا.

```crystal
true && false && false || true
# => true

true && false && (false || true)
# => false
```

ولأن ما بداخل الأقواس الهلالية يُقيَّم أولًا، فسيُطبَّق عامل النفي على التعبير الموجود داخل الأقواس الهلالية في المثال التالي.

```crystal
!true && false
# => false

!(true && false)
# => true
```

~~~~exercism/note
ينبغي استخدام الأقواس الهلالية فقط عندما تؤثر في النتيجة؛ وإلا فينبغي حذفها.
~~~~

## قيم truthy و falsey

في Crystal، القيم التي تُعتبر "falsey" هي: `false` و `nil` والمؤشرات الفارغة؛ أما **كل ما عداها** فيُعتبر "truthy".
ويمكن استخدام هذه القيم مع العوامل المنطقية المذكورة أعلاه.

```crystal

true && nil
# => false

false && 4
# => false

true || nil
# => true
```

## اصطلاحات تسمية الطرق مع القيم المنطقية

من الشائع في Crystal أن تُسمّى الطريقة التي تُرجع قيمة truthy أو falsey بعلامة استفهام (`?`).
وفي معظم الحالات، ستُرجع هذه الطريقة قيمة منطقية، لكن ليس بالضرورة.
وهذا يعني أنه يمكن استخدام الطريقة في المواضع التي يُتوقَّع فيها وجود قيمة truthy أو falsey، فعلى سبيل المثال، كشرط لجملة شرطية `if`:

```crystal
def exchange(value)
    if value.nil?
        value = 5
    end
    value
end

exchange(10)
# => 10

exchange(nil)
# => 5
```

الطرق التي تنتهي أسماؤها بعلامة استفهام ولا تُرجع قيمة منطقية تُرجع غالبًا `nil` بدلًا من ذلك. وقيمة `nil` _شبيهة بـ `None` أو `null` في لغات أخرى_.
