# مقدمة

## التعابير النمطية

التعابير النمطية (regex) أداة قوية للتعامل مع السلاسل النصية في Elixir. تتبع التعابير النمطية في Elixir مواصفة **PCRE** (**P**erl **C**ompatible **R**egular **E**xpressions). تُجمَّع أنماط السلاسل النصية التي تمثّل معنى التعبير النمطي أولًا، ثم تُستخدم لمطابقة سلسلة نصية كاملة أو جزء منها.

في Elixir، الطريقة الأكثر شيوعًا لإنشاء التعابير النمطية هي استخدام sigil بالصيغة `~r`. توفّر أدوات sigil اختصارات من نوع _السكر النحوي_ للمهام الشائعة في Elixir. ولمطابقة _سلسلة نصية حرفية_، يمكننا استخدام السلسلة نفسها كنمط يتبع sigil.

```elixir
~r/test/
```

يفيد العامل `=~/2` في إجراء مطابقة تعبير نمطي على سلسلة نصية لإرجاع نتيجة من نوع `boolean`.

```elixir
"this is a test" =~ ~r/test/
# => true
```

ملاحظتان حول استخدام sigil:

- يمكن استخدام فواصل مختلفة كثيرة بحسب احتياجاتك بدلًا من `/`
- أنماط السلاسل النصية _مُهرَّبة_ مسبقًا، فعند كتابة النمط كسلسلة نصية دون استخدام تعبير نمطي، ستحتاج إلى _تهريب_ الشرطات المائلة العكسية (`\`)

### أصناف المحارف

تعريف نطاق من المحارف باستخدام الأقواس المربعة `[]` يُنشئ _صنف محارف_. سيطابق هذا أي محرف واحد مع أيٍّ من محارف الصنف. يمكنك أيضًا تحديد نطاق من المحارف مثل `a-z`، بشرط أن تمثّل البداية والنهاية نطاقًا متصلًا من نقاط الترميز.

```elixir
regex = ~r/[a-z][ADKZ][0-9][!?]/
"jZ5!" =~ regex
# => true
"jB5?" =~ regex
# => false
```

تجعل _أصناف المحارف المختصرة_ النمط أكثر إيجازًا. على سبيل المثال:

- `\d` اختصار لـ `[0-9]` (أي رقم)
- `\w` اختصار لـ `[A-Za-z0-9_]` (أي محرف "كلمة")
- `\s` اختصار لـ `[ \t\r\n\f]` (أي محرف مسافة بيضاء)

وعند استخدام _صنف محارف مختصر_ خارج sigil، يجب تهريبه: `"\\d"`

### التناوبات

تستخدم _التناوبات_ الرمز `|` كمحرف خاص للدلالة على مطابقة أحد الأمرين _أو_ الآخر

```elixir
regex = ~r/cat|bat/
"bat" =~ regex
# => true
"cat" =~ regex
# => true
```

### المكمّمات

تسمح _المكمّمات_ بنمط متكرر في التعبير النمطي. وهي تؤثر في المجموعة التي تسبق المكمّم.

- `{N, M}` حيث `N` هو الحد الأدنى لعدد التكرارات، و`M` هو الحد الأقصى
- `{N,}` مطابقة `N` تكرار أو أكثر
  - يمكن أيضًا كتابة `{0,}` على هيئة `*`: مطابقة صفر تكرار أو أكثر
  - يمكن أيضًا كتابة `{1,}` على هيئة `+`: مطابقة تكرار واحد أو أكثر
- `{,N}` مطابقة حتى `N` من التكرارات

### المجموعات

تُستخدم الأقواس الهلالية `()` للدلالة على _المجموعات_ و_الالتقاطات_. وقد تُلتقط المجموعة أيضًا في بعض الحالات لتُرجَع للاستخدام. وفي Elixir، قد تكون هذه مسمّاة أو غير مسمّاة. وتُسمّى الالتقاطات بإضافة `?<name>` بعد القوس الافتتاحي. وتعمل المجموعات كوحدة واحدة، كما يحدث حين تتبعها _المكمّمات_.

```elixir
regex = ~r/(h)at/
Regex.replace(regex, "hat", "\\1op")
# => "hop"

regex = ~r/(?<letter_b>b)/
Regex.scan(regex, "blueberry", capture: :all_names)
# => [["b"], ["b"]]
```

### المراسي

تُستخدم _المراسي_ لربط التعبير النمطي ببداية السلسلة النصية المطلوب مطابقتها أو نهايتها:

- `^` يثبّت عند بداية السلسلة النصية
- `$` يثبّت عند نهاية السلسلة النصية

### التداخل

ولأن `~r` اختصار لـ `"pattern" |> Regex.escape() |> Regex.compile!()`، يمكنك أيضًا استخدام تداخل النصوص لبناء نمط تعبير نمطي ديناميكيًا:

```elixir
anchor = "$"
regex = ~r/end of the line#{anchor}/
"end of the line?" =~ regex
# => false
"end of the line" =~ regex
# => true
```
