# نبذة

كل شيء في Common Lisp هو تعبير.
التعبير إما شيء واحد (يسمى ذرة) أو قائمة من الأشياء (محددة بالأقواس الهلالية: `()`).

## الاقتباس

يمكن اقتباس جميع تعابير S، مثل الرموز:

```lisp
;; This line is evaluated as code
(gimme-foo)  ; => FOO

;; This line is treated as data
'(gimme-foo) ; => (GIMME-FOO)
```

يمنع هذا الاقتباس تقييم تعبير S، ويعامله بدلًا من ذلك كبيانات.
وهذه [إجابة ممتازة على Stack Overflow][so-quoting] تناقش الاقتباس بمزيد من التفصيل.

[so-quoting]: https://stackoverflow.com/questions/134887/when-to-use-or-quote-in-lisp
