# Debug

نظرًا لأن مشغّل الاختبارات الحالي يستخدم [PonyTest](https://stdlib.ponylang.io/pony_test--index/)، فإن الـ actor الرئيسي Main موجود في `test.pony` ولا ينبغي تعديله كجزء من حلّك.

وكما هو متّبع في أفضل الممارسات في تطبيقات Pony، لا نوفّر الوصول إلى `Env` إلا عند الحاجة. وهذا يعني أنك في معظم الحالات تقريبًا لن تستطيع استخدام التنقيح بأسلوب printf عبر `env.out.print()`.

إلا أن Pony يوفّر وحدة [debug](https://stdlib.ponylang.io/debug--index/) تتيح للبرامج التي تُصرَّف بالعلامة `-d` وصولًا خاصًّا إلى STDOUT و STDERR دون الوصول إلى `Env`.

وإذا احتجت إلى التنقيح بأسلوب printf، فعليك استخدام هذه الإمكانية.

مثال على التنقيح:

```pony
use "debug"

actor Main
  new create(env: Env) =>
    MySolution.examplefn("First String", 42)

primitive MySolution
  fun examplefn(arg1: String, arg2: USize) =>
    Debug.out("arg1: " + arg1 + ", arg2: " + arg2.string() + " were provided to MySolution.examplefn()")
```
