# مقدمة

## المقارنات

في C++، يمكنك مقارنة القيم باستخدام عوامل المقارنة.

| المقارنة          | العامل    |
| ------------------| --------- |
| يساوي             | `==`      |
| لا يساوي          | `!=`      |
| أصغر من           | `<`       |
| أصغر من أو يساوي  | `<=`      |
| أكبر من           | `>`       |
| أكبر من أو يساوي  | `>=`      |

نتيجة هذه المقارنات هي دائمًا قيمة منطقية:

```cpp
int a{3};

bool eq1 = a != 4; // true

bool eq2 = a > 5;  // false
```

يتحقق العاملان `==` و`!=` مما إذا كانت قيمة تساوي قيمة أخرى أم لا، على الترتيب.
وإليك بعض الأمثلة الشائعة:

```cpp
bool eq3 = 2 == 3; // false, integer comparison

bool eq4 = 2.1 != 2.2; // true, float comparison

bool eq5 = "hello" == "hello"; // true, string comparison
```

تتحقق العوامل الأخرى مما إذا كانت قيمة أكبر من (`>`) أو أكبر من أو تساوي (`>=`) أو أصغر من (`<`) أو أصغر من أو تساوي (`<=`) قيمة أخرى.
هذا النوع من المقارنة متاح للأعداد والسلاسل النصية.
وعند مقارنة السلاسل النصية، يُتبع الترتيب القاموسي (المعروف أيضًا بالترتيب المعجمي).

```cpp
bool eq6 = 2 > 3; // false, integer comparison

bool eq7 = 1.2 < 1.3; // true, float comparison

bool eq8 = "Hello" < "World"; // true, string comparison
```

## الجمل الشرطية

الجمل الشرطية في C++ تشبه الجمل الشرطية في اللغات الأخرى.
النوع الأساسي لأي عملية شرطية هو النوع `bool`، الذي يمكن أن تكون قيمته `true` أو `false`.
وغالبًا ما تُستخدم الجمل الشرطية كآليات للتحكم في التدفق للتحقق من شروط مختلفة.

يمكن استخدام الجملة الشرطية `if`، التي تنفّذ الكود الخاص بها إذا كان الشرط الأساسي `true`، هكذا:

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

وفي الحالات التي تنطوي على أكثر من حالة واحدة، يمكن ربط العديد من الجمل الشرطية `if` معًا باستخدام الجملتين الشرطيتين `else if` و`else`.

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

منذ C++17، يمكن للجمل الشرطية `if` أن تتضمن أيضًا عبارة تهيئة قصيرة يمكن استخدامها لتهيئة متغير واحد أو أكثر خاص بالجملة الشرطية `if`.
على سبيل المثال:

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> ملاحظة: لا يمكن الوصول إلى أي متغيرات أُنشئت في التهيئة بعد نهاية الجملة الشرطية `if`.
