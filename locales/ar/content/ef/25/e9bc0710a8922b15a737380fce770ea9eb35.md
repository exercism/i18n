# نبذة

يُسمى المعامل `|>` معامل الأنبوب. ويمكن استخدامه لتسلسل استدعاءات الدوال بحيث تُمرَّر القيمة التي أرجعتْها الدالة السابقة إلى استدعاء الدالة التالي.

```gleam
"hello"
|> string.uppercase
|> string.append("?!")
// -> "HELLO?!"
```

الكود أعلاه مكافئ للكود التالي:

```gleam
string.append(string.uppercase("hello"), "?!")
```

سيُمرِّر معامل الأنبوب القيمة إما كوسيط أول في استدعاء الدالة، وإما كوسيط وحيد في استدعاء جديد، بحسب أيّهما يكون نوعه صحيحًا.

```gleam
100
|> function_that_takes_two_arguments(1)

// Is equivalent to
function_that_takes_two_arguments(100, 1)
```

```gleam
100
|> function_that_returns_a_function(1)

// Is equivalent to
function_that_returns_a_function(1)(100)
```

أحيانًا نريد تمرير القيمة إلى موضع آخر، وفي هذه الحالة يمكن استخدام العنصر النائب `_` للإشارة إلى الموضع الذي ينبغي إدراج القيمة فيه.

```gleam
100
|> some_function(1, _, 2)
```
