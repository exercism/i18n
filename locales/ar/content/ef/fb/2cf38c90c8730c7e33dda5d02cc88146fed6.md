# مقدمة

توفّر الاستثناءات في C# طريقة منظّمة وموحّدة وآمنة من حيث الأنواع لمعالجة حالات الخطأ التي تحدث أثناء وقت التشغيل. والمعالجة السليمة للاستثناءات والأخطاء مهمة عند محاولة منع انهيار التطبيق.

في C#، يكون الصنف `System.Exception` هو النوع الأساسي لجميع الاستثناءات. وهو يحتوي على خصائص مهمة مثل `Message`، التي تحتوي على وصف مقروء للسبب الذي من أجله يُطرح الاستثناء.

للإشارة إلى وجود خطأ في جزء معيّن من الكود، يلزم إنشاء كائن استثناء جديد ثم طرحه باستخدام الكلمة المفتاحية `throw`:

```csharp
using System;
static int Square(int number)
{
    if (number >= 46341)
    {
        throw new ArgumentException($"Argument {number} cannot be higher than 46340 as its' square doesn't fit into int type.");
    }
    return number * number;
}
```

عند طرح استثناء، تتولّى بيئة التشغيل مهمة البحث عن جزء من الكود مسؤول عن معالجة ذلك الاستثناء. وإذا لم يُعثر على معالج مناسب، تعرض بيئة التشغيل رسالة الاستثناء غير المُعالَج، إضافة إلى إيقاف تنفيذ البرنامج.

لإنشاء معالج لاستثناء، تستخدم C# العبارة try-catch، التي تتألف من كتلة `try` وبند `catch` واحد أو أكثر. ينبغي أن تحتوي كتلة `try` على الكود الذي قد يؤدي إلى طرح الاستثناء وأن تحرسه. وينبغي أن تحتوي بنود `catch` على الكود الذي يعالج سلوك البرنامج بعد وقوع الخطأ. من المهم ملاحظة أن ترتيب الاستثناءات مهم بعد كتلة `try`، لأنه عند إدراج عدة استثناءات يُنفَّذ أول بند `catch` مطابق.

```csharp
try
{
   if (number == 42)
   {
       throw new ArgumentException("The number cannot be equal to 42.", "number");
   }

   if (number < 0)
   {
      throw new ArgumentOutOfRangeException("number", "The number cannot be negative.");
   }

    // Process number ...
}
catch (ArgumentOutOfRangeException e)
{
    Console.WriteLine($"Number is out of range: {e.Message}.");
}
catch (ArgumentException)
{
    Console.WriteLine("Invalid number.");
}
```
