# مقدمة

توفّر Swift نوعًا مدمجًا يُسمى [`Bool`][bools] لتمثيل قيم الصواب: `true` و `false`.

## العوامل المنطقية

توفّر Swift ثلاثة [عوامل منطقية][logical-operators] (`!` و `&&` و `||`) لدمج التعبيرات المنطقية وتقييمها.

### المعامل المنطقي AND (`&&`)

لا يُرجع معامل [_and_][and] (`&&`) القيمة `true` إلا إذا كان الطرفان `true`.
وإذا كان أحد الطرفين `false`، فإنه يُرجع `false`.
ضع تعبيرًا أو قيمة منطقية على كل جانب من جانبي الرمز `&&`:

```swift
true && true  // true
true && false // false
```

### المعامل المنطقي OR (`||`)

يُرجع معامل [_or_][or] (`||`) القيمة `true` إذا كان **أحد الطرفين على الأقل** `true`.
ولا يُرجع `false` إلا عندما يكون الطرفان `false`.
ضع تعبيرًا أو قيمة منطقية على كل جانب من جانبي الرمز `||`:

```swift
true || true   // true
true || false  // true
false || false // false
```

### المعامل المنطقي NOT (`!`)

يعكس معامل [_not_][not] (`!`) القيمة المنطقية.
فيُرجع `true` إذا كانت القيمة `false`، ويُرجع `false` إذا كانت القيمة `true`.
ضع معامل `!` مباشرةً قبل القيمة أو التعبير:

```swift
!true  // false
!false // true
```

## استخدام الأقواس الهلالية (`()`)

يمكنك استخدام [الأقواس الهلالية][explicit-parentheses] لتجميع التعبيرات والتحكم في ترتيب التقييم.
في Swift، تُقيَّم التعبيرات داخل الأقواس الهلالية أولًا:

```swift
true && false && false || true   // true
true && false && (false || true) // false
```

كما يحدد التجميع بالأقواس الهلالية كيفية تطبيق معامل NOT على التعبيرات المركبة:

```swift
!true && false   // false (evaluates (!true) first, then false && false)
!(true && false) // true  (evaluates (true && false) first to false, then !false)
```

~~~~exercism/note
استخدم الأقواس الهلالية عندما تحتاج إلى توضيح ترتيب التقييم أو جعل الشروط المركبة أسهل في القراءة.
وتجنّب إضافة أقواس هلالية غير ضرورية عندما تكون أولوية التقييم الافتراضية واضحة بالفعل.
~~~~
