# مقدمة

## `Base.@kwdef`

يمكن استخدام الماكرو `Base.@kwdef` لتعريف دوال البناء التي تأخذ وسائط مفتاحية تلقائيًا عند تعريف [بنية][struct].
كما يتيح تعيين قيم افتراضية للحقول.

على سبيل المثال، التعريف التالي

```julia
Base.@kwdef struct HumanStats
    birthyear::Int
    height::Int
    mass::Int
    bmi::Float64 = mass / (0.01 * height)^2
end
```

يعرّف ثلاث دوال بناء دفعة واحدة

```julia-repl
julia> methods(HumanStats)
# 3 methods for type constructor:
[1] HumanStats(; birthyear, height, mass, bmi) [...]
[2] HumanStats(birthyear::Int64, height::Int64, mass::Int64, bmi::Float64) [...]
[3] HumanStats(birthyear, height, mass, bmi) [...]
```

بما في ذلك دالة بناء تعتمد على الوسائط المفتاحية

```julia-repl
julia> HumanStats(
           birthyear = 2002,
           height = 193,
           mass = 83
       )
HumanStats(2002, 193, 83, 22.28247738194314)
```

في حين أن التعريف المعتاد

```julia
struct HumanStats
    birthyear::Int
    height::Int
    mass::Int
    bmi::Float64
end
```

لا يعرّف سوى الاثنتين التاليتين

```julia-repl
julia> methods(HumanStats)
# 2 methods for type constructor:
[1] HumanStats(birthyear::Int64, height::Int64, mass::Int64, bmi::Float64) [...]
[2] HumanStats(birthyear, height, mass, bmi) [...]
```

وسيتطلب تعريف دالة بناء قائمة على الوسائط المفتاحية يدويًا.

### متى نستخدم `Base.@kwdef`؟

تكون دوال البناء القائمة على الوسائط المفتاحية مفيدة بشكل خاص عند إنشاء بنى تأخذ عددًا كبيرًا من الوسائط، خصوصًا عندما لا يرتبط نوع الوسائط أو قيمتها بمعانيها ارتباطًا مباشرًا.

خذ التعريف التالي:

```julia
dirk = BasketballPlayer(1978, 1994, 2019, 213, 111, 42, 1998, [2011], 31560, 11489, 3651)
```

فلا يتضح معنى كل قيمة دون معرفة تعريف النوع.
وحتى إن عرف المرء التعريف، فسيحتاج على الأرجح إلى البحث عن الترتيب مرارًا وتكرارًا.

لكن عند استخدام دالة بناء قائمة على الوسائط المفتاحية، يتضح معناها فورًا:

```julia
dirk = BasketballPlayer(
    birthyear = 1978,
    career_start = 1994,
    career_end = 2019,
    height = 213,
    weight = 111,
    number = 42,
    drafted = 1998,
    championships = [2011],
    points = 31560,
    rebounds = 11489,
    assists = 3651
)
```

~~~~exercism/caution
`Base.@kwdef` غير مُصدَّر ولا موثّق في الدليل، ولذلك فهو ليس جزءًا من [واجهة API العامة لـ Julia][public-api].
وهذا يعني أن واجهته ليست مضمونة الاستقرار من الناحية التقنية، وقد تتغير بين إصدارات Julia الفرعية.

غير أن الماكرو مستخدم على نطاق واسع في المنظومة، ومن غير المرجح أن يُغيَّر بشكل يكسر التوافق.

لمزيد من المعلومات، اطلع على:

- [مسألة Julia رقم 33192 لتصدير `@kwdef`][export-kwdef]
