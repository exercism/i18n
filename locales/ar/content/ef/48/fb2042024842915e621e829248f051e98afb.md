## الأزواج

`Pair` هو بنية بيانات تحتوي على عنصرين بالضبط، ويمكن الوصول إليهما عبر الحقلين `first` و`second`.

يمكن إنشاؤهما باستخدام `x => y`:

```julia-repl
julia> p = 3 => true
3 => true

julia> p.first
3

julia> p.second
true
```

يمكن أن تكون عناصر `Pair` من أنواع مختلفة:

```julia-repl
julia> typeof(p)
Pair{Int64,Bool}
```

لـ `Pair` استخدامان شائعان في Julia: القواميس والاستبدال.

### الاستبدال

تأخذ طرق الاستبدال العديدة `Pair` كوسيط لتوضيح أي عنصر يجري استبداله.
يتيح هذا كتابة كود مثل

```julia-repl
julia> replace!([1, 3, 4, 1], 4 => 0)
4-element Array{Int64,1}:
 1
 3
 0
 1
```

حيث يُستبدل كل `4` في المجموعة بـ `0`، بدلًا من الصياغة الأقل وضوحًا

```julia
replace!([1, 3, 4, 1], 4, 0) # this method doesn't exist
```
