# المقدمة

حتى الآن رأينا أن الوسائط التي تُمرَّر إلى طريقة تُطابَق مع المعاملات المعلنة للطريقة بناءً على موضعها. وهناك أسلوب بديل، لا سيما حين تأخذ دالة عددًا كبيرًا من الوسائط، وهو أن يطابق المستدعي الوسائط بتحديد معرّف المعامل المعلن.

يوضح المثال التالي الصيغة:

```csharp
class Card
{
    static string NewYear(int year, int month, int day)
    {
        return $"Happy {year}-{month}-{day}!";
    }
}

Card.NewYear(month: 1, day: 1, year: 2020);  // => "Happy 2020-1-1!"
```
