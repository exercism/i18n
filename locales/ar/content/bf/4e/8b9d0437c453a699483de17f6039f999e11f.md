# مقدمة

في Python، [`enum`][enum-docs] هو مجموعة من الأسماء المرتبطة بقيم فريدة من نوع `literal`، أو قيم `constant`.

تُعرَّف `Enums` عبر الوراثة من صنف `Enum` أو الاشتقاق منه.
تتوفر أنواع `enum` المدمجة في الوحدة النمطية `enum`، ويمكن استيراد الصنف `Enum` باستخدام `from enum import Enum`.


```python
from enum import Enum

class Color(Enum):
    RED = 1
    GREEN = 2
```

لاحظ أن قيم أعضاء `enum` يمكن أن تكون أي أنواع بيانات مثل `str` و`tuple` و`float` وغيرها.

```python
class Color(Enum):
    RED = 'red'
    GREEN = 'green'
```

عند إسناد القيمة نفسها إلى عضوين في `enum`، يصبح العضو المُسنَد إليه لاحقًا اسمًا مستعارًا للعضو الأول. ولا يُسمح باستخدام الاسم نفسه لعضوين مختلفين في `enum`.

```python
class Color(Enum):
    RED = 1
    GREEN = 2
    ALIAS_OF_RED = 1

Color.ALIAS_OF_RED
#=> <Color.RED: 1>

Color.ALIAS_OF_RED.value
#=> 1
```

يمكن المرور على أعضاء `enum` باستخدام الصيغة المعتادة `for member in`:

```python
for member in Color:
    print((member.name, member.value))
#=> (RED, 1)
#=> (GREEN, 2)
```

يمكن مقارنة أعضاء `Enum` باستخدام [`is` (_عامل الهوية_)][identity-keyword] أو `is not`. كما يعمل `==` أو `!=` (_عاملا المساواة_) بالمثل:

```python
a = Color.RED

a is Color.RED
#=> True

a == Color.RED
#=> True
```

للوصول إلى عضو في `enum` بقيمة معينة، يمكن استخدام `<EnumName>(<value>)`:

```python
g = Color(2)

g is Color.GREEN
#=> True

g
#=> <Color.GREEN: 2>
```
