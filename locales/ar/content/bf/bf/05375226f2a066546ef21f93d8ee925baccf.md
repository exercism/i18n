# مقدمة

المصفوفة [`list`][list] هي مجموعة قابلة للتعديل من العناصر في _تسلسل_.
 ومثل معظم المجموعات (_انظر الأنواع المدمجة [`tuple`][tuple] و[`dict`][dict] و[`set`][set]_)، يمكن للمصفوفات أن تحمل مراجع إلى أي نوع من أنواع البيانات (أو عدة أنواع)، بما في ذلك مصفوفات أخرى.
 ويمكن نسخ المصفوفات كاملة أو جزئيًا عبر [تدوين الشرائح][slice notation] أو باستخدام `<list>.copy()`.
 وكأي [تسلسل][sequence type]، يُشار إلى العناصر داخل `lists` برقم `0-based index` من اليسار، أو برقم `-1-based index` من اليمين.

تدعم المصفوفات كلاً من عمليات التسلسل [الشائعة][common sequence operations] و[القابلة للتعديل][mutable sequence operations]، مثل `min(<list>)`/`max(<list>)` و`<list>.index()` و`<list>.append()` و`<list>.reverse()`.
 ويمكن تكرار العناصر داخل `list` باستخدام التركيب `for item in <list>`.
 ويمكن استخدام `for index, item in enumerate(<list>)` عندما تكون هناك حاجة إلى كل من فهرس العنصر وقيمته.

كما توفر Python أيضًا العديد من [طرق المصفوفات][list-methods] المفيدة للتعامل مع المصفوفات.
 وفيما يلي تغطية لمجموعة مختارة من هذه `list methods`.


لاحظ أنه عند التعامل مع `list` باستخدام `list-method`، **فإنك تُغيّر المصفوفة** التي تم تمريرها.
 وإذا كنت لا ترغب في تعديل `list` الأصلية، فستحتاج على الأقل إلى إنشاء `shallow copy` منها عبر الشرائح أو `<list>.copy()`.


## إضافة العناصر

لإضافة عنصر إلى نهاية مصفوفة موجودة أو إلى "الجانب الأيمن" منها، استخدم `<list>.append(<item>)`:

```python
>>> numbers = [1, 2, 3]
>>> numbers.append(9)

>>> numbers
[1, 2, 3, 9]
```

وبدلًا من _الإلحاق_، تمنحك `<list>.insert()` القدرة على إضافة العنصر إلى _فهرس محدد_ في المصفوفة.
وهي تأخذ معاملَين:

1. `<index>` الذي تريد إدراج العنصر عنده.
2. `<item>` المراد إدراجه.

**ملاحظة**: إذا كان `index` المعطى هو 0، فسيُضاف العنصر إلى بداية `list`، أي "الجانب الأيسر" منها.
 وإذا كان `index` الممرَّر أكبر من `index` الأخير في `list`، فسيُضاف العنصر في الموضع الأخير، وهو ما يعادل استخدام `<list>.append(<item>)`.


```python
>>> numbers = [1, 2, 3]
>>> numbers.insert(0, -2)

>>> numbers
[-2, 1, 2, 3]

>>> numbers.insert(1, 0)

>>> numbers
[-2, 0, 1, 2, 3]
```


يمكن استخدام `<list>.extend(<item>)` لدمج مصفوفة موجودة مع عناصر كائن قابل للتكرار آخر (على سبيل المثال `set` أو `tuple` أو `str` أو `list`).
  يتم _تفكيك_ الكائن القابل للتكرار وتُضاف عناصره بالترتيب (_استخدام `<list>.append(<item>)` في هذه الحالة سيضيف الكائن القابل للتكرار بأكمله كـ**عنصر واحد**_).


```python
>>> numbers = [1, 2, 3]
>>> other_numbers = [5, 6, 7]

>>> numbers.extend(other_numbers)

>>> numbers
[1, 2, 3, 5, 6, 7]

>>> numbers.extend([8, 9])

>>> numbers
[1, 2, 3, 5, 6, 7, 8, 9]

>>> numbers.append([8,9])

>>> numbers
[1, 2, 3, 5, 6, 7, 8, 9, [8, 9]]
```


## إزالة العناصر

لحذف عنصر من مصفوفة، استخدم `<list>.remove(<item>)`، مع تمرير العنصر المراد حذفه كوسيط.
 وستُطلق `<list>.remove(<item>)` خطأ `ValueError` إذا لم يكن العنصر موجودًا في `list`.


```python
>>> numbers = [1, 2, 3]
>>> numbers.remove(2)

>>> numbers
[1, 3]

# Trying to remove a value that is not in the list throws a ValueError
>>> numbers.remove(0)
ValueError: list.remove(x): x not in list
```


وبدلًا من ذلك، سيؤدي استخدام طريقة `<list>.pop(<index>)` إلى حذف العنصر **و**`return`ه لاستخدامه.


تأخذ `<list>.pop(<index>)` معاملًا اختياريًا واحدًا: وهو `index` العنصر المراد حذفه وإرجاعه.
 وإذا لم يُحدَّد وسيط `index` (الاختياري)، فسيُحذف العنصر الأخير من `list` ويُرجَع.
 وإذا كان `index` المحدد أكبر من `index` العنصر الأخير، فسيُرفع `IndexError`.


```python
>>> numbers = [1, 2, 3]

>>> numbers.pop(0)
1

>>> numbers
[2, 3]

>>> numbers.pop()
3

>>> numbers
[2]

>>> numbers.pop(1)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
IndexError: pop index out of range
```

يمكن حذف جميع العناصر من `list` باستخدام `list.clear()`. وهي لا تأخذ أي معاملات.

```python
>>> numbers = [1, 2, 3]
>>> numbers.clear()

>>> numbers
[]
```

## العكس وإعادة الترتيب

ستعكس طريقة `<list>.reverse()` ترتيب العناصر **في مكانها**.


```python
>>> numbers = [1, 2, 3]
>>> numbers.reverse()

>>> numbers
[3, 2, 1]
```


ويمكن إعادة ترتيب المصفوفة _**في مكانها**_ بمساعدة [`<list>.sort()`][sort].
الترتيب الافتراضي للفرز هو ترتيب _تصاعدي_ من اليسار.
وتقدم وثائق Python [نصائح وتقنيات إضافية للترتيب][sorting how to].

~~~~exercism/note
 من 2002 إلى 2022، استخدمت Python خوارزمية تُسمى [`Timsort`][timsort] داخليًا لترتيب المصفوفات، لكنها انتقلت إلى [`Powersort`][powersort] بدءًا من `Python 3.11`.

[powersort]: https://www.wild-inter.net/publications/munro-wild-2018
[timsort]: https://en.wikipedia.org/wiki/Timsort
~~~~


```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]

# The default sort order is *ascending*.
>>> names.sort()

>>> names
["Bruce", "Natasha", "Thor", "Tony"]
```

إذا أردت ترتيبًا _تنازليًا_، فمرّر الوسيط `reverse=True`:

```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]
>>> names.sort(reverse=True)

>>> names
["Tony", "Thor", "Natasha", "Bruce"]
```

وفي الحالات التي لا يُستحسن فيها تعديل المصفوفة الأصلية، يمكن استخدام الدالة المدمجة [`sorted(<iterable>)`][sorted] لإرجاع **نسخة** مرتبة.


```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]

>>> sorted(names)
['Bruce', 'Natasha', 'Thor', 'Tony']
```


## عدد مرات ظهور عنصر في المصفوفة

يمكن حساب عدد مرات ظهور عنصر في مصفوفة بمساعدة `list.count(<item>)`.
 وهي تأخذ `item` المراد عدّه كوسيط لها، وتُرجع العدد الإجمالي لمرات ظهور ذلك العنصر في `list`.


```python
>>> items = [1, 4, 7, 8, 2, 9, 2, 1, 1, 0, 4, 3]

>>> items.count(1)
3
```

## إيجاد فهرس العناصر

ستُرجع `<list>.index(<item>)` رقم `index` الخاص بـ_أول ظهور_ لعنصر يُمرَّر إليها.
 وإذا لم يكن هناك أي ظهور، فسيُرفع `ValueError`.
 وإذا لم تكن بحاجة إلى الموضع الدقيق لعنصر ما، فإن العامل المدمج `in` أكثر كفاءة للتحقق مما إذا كانت المصفوفة تحتوي على قيمة معينة.


تبدأ الفهرسة من الصفر من اليسار، لذا فإن موضع العنصر "الأول" هو `0`.
كما تعمل الفهرسة من اليمين أيضًا، بدءًا من `-1`.


```python
>>> items = [7, 4, 1, 0, 2, 5]

>>> items.index(4)
1

>>> items.index(10)
ValueError: 10 is not in list
```

ويمكن أيضًا تمرير فهرسي `start` و`end` لتضييق البحث على قسم محدد من `list`:

```python
>>> names = ["Tina", "Leo", "Thomas", "Tina", "Emily", "Justin"]

>>> names.index("Tina")
0

>>> names.index("Tina", 2, 5)
3
```
