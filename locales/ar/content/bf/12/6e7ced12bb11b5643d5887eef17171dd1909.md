# التعليمات

بصفتها ساحرة متدربة، تحتاج إيلايس إلى التدرب على بعض الأساسيات. لديها مكدس من البطاقات تريد التعامل معه.

ولتسهيل الأمور قليلًا، تستخدم البطاقات من 1 إلى 10 فقط.

يُمثَّل مكدس البطاقات بواسطة `queue`، حيث يكون أسفل المكدس في مقدمة الطابور، وأعلى المكدس في مؤخرته.

## 1. إدراج بطاقة في أعلى المكدس

نفّذ الدالة `insert_top` التي تُرجع نسخة من المكدس مع إضافة البطاقة الجديدة المزوّدة إلى أعلى المكدس.

```gleam
insert_top(queue.from_list([5, 9, 7, 1]), 8)
// -> queue.from_list([5, 9, 7, 1, 8])
```

## 2. إزالة البطاقة العليا من المكدس

نفّذ الدالة `remove_top_card` التي تُرجع نسخة من المكدس بعد إزالة بطاقته العليا. إذا كان المكدس المعطى فارغًا، فيجب إرجاع المكدس الأصلي دون تغيير.

```gleam
remove_top_card(queue.from_list([3, 2, 6, 4, 8]))
// -> queue.from_list([3, 2, 6, 4])
```

## 3. إدراج بطاقة في أسفل المكدس

نفّذ الدالة `insert_bottom` التي تُرجع نسخة من المكدس مع إضافة البطاقة الجديدة المزوّدة إلى أسفل المكدس.

```gleam
insert_bottom(queue.from_list([5, 9, 7, 1]), 8)
// -> queue.from_list([8, 5, 9, 7, 1])
```

## 4. إزالة بطاقة من أسفل المكدس

نفّذ الدالة `remove_bottom_card` التي تُرجع نسخة من المكدس بعد إزالة بطاقته السفلى. إذا كان المكدس المعطى فارغًا، فيجب إرجاع المكدس الأصلي دون تغيير.

```gleam
remove_bottom_card(queue.from_list([8, 5, 9, 7, 1]))
// -> queue.from_list([5, 9, 7, 1])
```

## 5. التحقق من حجم المكدس

نفّذ الدالة `check_size_of_stack` التي تتحقق مما إذا كان حجم المكدس يساوي قيمة `stack_size` المعطاة أم لا.

```gleam
check_size_of_stack(queue.from_list([3, 2, 6, 4, 8]), 4)
// -> False
```
