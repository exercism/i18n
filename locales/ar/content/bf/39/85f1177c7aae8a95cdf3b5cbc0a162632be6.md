# واجهة سطر الأوامر

## الإعداد

أسهل أسلوب لتثبيت PureScript هو عبر Node.js و NPM.

إذا لم يكن Node.js مثبتًا على حاسوبك، فيمكنك تنزيله من [موقع Node.js][nodejs-website]. وبعد أن يصبح Node.js جاهزًا للعمل، أدخل هذا الأمر في الطرفية لتثبيت مُصرّف PureScript وأداة Spago لإدارة الحزم والبناء.

```shell
npm install -g purescript spago
```

يمكنك العثور على مزيد من المعلومات في [مستودع PureScript][purescript-repository].

## المتطلبات

ثبّت اعتماديات التمرين:

```shell
spago install
spago build
```

## اجعل مجموعة الاختبارات تنجح

نفّذ الاختبارات بالأمر:

```shell
spago test
```

في مجموعات الاختبارات، جرى تخطي جميع الاختبارات باستثناء الأول. وذلك لتشجيعك على حل التمرين خطوة بخطوة.

بعد أن ينجح اختبار واحد، يمكنك تمكين الاختبار التالي بتغيير `xit` إلى `it`.

## إرسال الحل

بعد ألا يبقى أي اختبار متخطى وأن تنجح جميعها، يمكنك إرسال حلك بالأمر:

```shell
exercism submit src/<NAME>.purs
```

## كتابة اختبارات مخصصة

إذا أردت كتابة اختبارات إضافية مخصصة، فأنشئ ملفًا جديدًا باسم `test/Custom.purs`، وأرسله مع حلك إلى جانب الملف الجديد:

```shell
exercism submit src/<NAME>.purs test/Custom.purs
```
