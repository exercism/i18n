# التثبيت

كُتبت حلول هذا المسار بلغة التجميع RISC-V بسعة 32 بت وتعمل عبر المحاكاة، لذا لا حاجة إلى أي عتاد RISC-V.
يأتي كل تمرين مصحوبًا بملف Makefile يبني الاختبارات ويشغّلها.
ولاستخدامه تحتاج إلى ثلاث أدوات:

- [Zig][zig]، وهو يوفّر مُجمِّع RISC-V ومترجم C والرابط من خلال `zig cc`.
- [Make][make]، وهو الذي ينفّذ عملية البناء.
- `qemu-riscv32` من [QEMU][qemu]، وهو الذي يشغّل البرنامج الناتج.

## macOS

شغّل آلة افتراضية تعمل بنظام Linux باستخدام أي حل مناسب للمحاكاة الافتراضية (مثل [Lima][lima])، ثم اتبع أحد أقسام توزيعات Linux أدناه.

## Windows

استخدم [Windows Subsystem for Linux][wsl] ثم اتبع أحد أقسام توزيعات Linux أدناه.
أو أعدّ آلة افتراضية تعمل بنظام Linux بدلًا من ذلك.

## Debian / Ubuntu

ثبّت Make ومحاكيات وضع المستخدم الخاصة بـ QEMU:

```shell
sudo apt install make qemu-user
```

ثم ثبّت Zig 0.15.2 أو إصدارًا أحدث كما هو موضّح في [التنزيل المباشر][zig-install].

## Fedora

ثبّت الأدوات الثلاث جميعها باستخدام:

```shell
sudo dnf install zig make qemu-user
```

## Arch Linux

ثبّت الأدوات الثلاث جميعها باستخدام:

```shell
sudo pacman -S zig make qemu-user
```

## openSUSE Tumbleweed

ثبّت الأدوات الثلاث جميعها باستخدام:

```shell
sudo zypper install zig make qemu-linux-user
```

## التحقق من التثبيت

تأكّد من العثور على الأدوات الثلاث جميعها:

```shell
zig version
make --version
qemu-riscv32 --version
```

ثم نزّل تمرينًا باستخدام واجهة سطر الأوامر الخاصة بـ Exercism وشغّل اختباراته:

```shell
exercism download --track=risc-v --exercise=hello-world
cd ~/exercism/risc-v/hello-world/
make
```
