# مقدمة

هناك نوعان مختلفان من الأعداد في Gleam: الأعداد الصحيحة والأعداد العشرية.

الأعداد الصحيحة هي أعداد بلا كسور.

```gleam
let integer = 3
// -> 3
```

تمتلك Gleam عدة عوامل تعمل مع الأعداد الصحيحة.

```gleam
1 + 1 // -> 2
5 - 1 // -> 4
5 / 2 // -> 2
3 * 3 // -> 9
5 % 2 // -> 1

2 > 1  // -> True
2 < 1  // -> False
2 >= 1 // -> True
2 <= 1 // -> False
```
