# الموارد

* يُعدّ [The Rust Programming Language](https://doc.rust-lang.org/book/) مصدرًا رائعًا للبدء مع Rust وللتعمق أيضًا في ميزات معينة فيه.
* يعرض لك [Rust by Example](https://doc.rust-lang.org/stable/rust-by-example/) أمثلة على أكثر الأشياء شيوعًا التي ستكتبها بلغة Rust.
* يمكنك استخدام [Rust API Documentation](http://doc.rust-lang.org/std/) لاكتشاف طُرق جديدة ومعرفة كيفية عملها.
* يمكنك استخدام [Stack Overflow](http://stackoverflow.com/questions/tagged/rust) للبحث عن مشكلتك ومعرفة ما إذا كان قد تمت الإجابة عنها من قبل. ويمكنك أيضًا طرح الأسئلة والإجابة عنها.
* [Rust User Forum](http://users.rust-lang.org) مخصص للنقاش العام حول Rust.
* [/r/rust](http://www.reddit.com/r/rust/) هو المنتدى الفرعي الرسمي لـ Rust.
* يمكنك استخدام الخادم الرسمي لـ [The Rust Programming Language](https://discord.gg/rust-lang) على [Discord](https://discordapp.com/) للاستفسارات السريعة والنقاشات حول اللغة.
