# مقدمة

عند مطابقة الأنماط على قيمة في Gleam، علينا أن نتأكد من أن الأنماط تطابق كل القيم الممكنة للنوع، وإلا فلن يُترجم الكود.

يجب رفض هذه الدالة لأنها لم تتعامل مع الحالة التي تكون فيها المصفوفة فارغة:

```gleam
pub fn get_first_element_or_crash(items: List(e)) -> e {
  case items {
    [item, ..] -> item
  }
}
```

في معظم الأحيان نريد في برامج Gleam التعامل مع كل الحالات الممكنة، لكن في بعض البرامج مثل النماذج الأولية والسكربتات السريعة قد نريد التركيز على المسار السعيد فقط وعدم كتابة كود للحالات الأخرى. هنا يأتي دور `let assert` في Gleam.

مع تأكيدات `let assert` يمكن للنمط أن يطابق بعض القيم الممكنة للنوع فقط، وإذا لم يطابق النمط قيمة ما فسيتعطل البرنامج. وباستخدام `let assert` يمكننا كتابة الدالة أعلاه هكذا:

```gleam
pub fn get_first_element_or_crash(items: List(e)) -> e {
  let assert [item, ..] = items
  item
}
```

يجب ألا تستخدم مكتبات Gleam تأكيدات `let assert` أبدًا، لأنها قد تُعطّل البرنامج. بدلًا من ذلك، يجب أن تستخدم نوع `Result` وتدع مطوّر التطبيق يقرّر كيفية التعامل مع الأخطاء.
