# التثبيت

## تثبيت .NET

مسار C# مبني على منصة [.NET](https://dotnet.microsoft.com/learn/dotnet/what-is-dotnet)، وهي تعمل على أنظمة Windows وLinux وmacOS.
لبناء مشاريع .NET، يمكنك استخدام واجهة سطر الأوامر الخاصة بـ .NET (CLI).
هذه الـ CLI جزء من .NET SDK، ويمكنك تثبيتها باتباع [تعليمات التثبيت](https://dotnet.microsoft.com/download/dotnet/8.0).
ملاحظة: يتطلب مسار C# الإصدار 9.0 من SDK أو أحدث.

بعد إتمام التثبيت، يمكنك التحقق من نجاح تثبيت CLI بتشغيل هذا الأمر في الطرفية:

```bash
dotnet --version
```

إذا كان الناتج إصدارًا أكبر من أو يساوي `9.0.100`، فقد تم تثبيت .NET SDK بنجاح.

## استخدام بيئة تطوير متكاملة

إذا كنت تريد تجربة تحرير أغنى بالمزايا، فربما تريد استخدام [بيئة تطوير متكاملة](https://en.wikipedia.org/wiki/Integrated_development_environment).
هذه هي أكثر بيئات التطوير المتكاملة شيوعًا التي تدعم بناء مشاريع .NET:

- [Visual Studio 2022](https://www.visualstudio.com/downloads/)
- [Visual Studio Code](https://code.visualstudio.com/download) مع [إضافة C#](https://marketplace.visualstudio.com/items?itemName=ms-dotnettools.csharp)
- [Visual Studio for Mac](https://www.visualstudio.com/vs/visual-studio-mac/)
- [Project Rider](https://www.jetbrains.com/rider/download/)

ملاحظة: بما أن تنسيق مشروع .NET يختلف اختلافًا كبيرًا عن الإصدارات السابقة، فإن بيئات التطوير المتكاملة الأقدم (مثل Visual Studio 2015) غير مدعومة.
