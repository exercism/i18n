# ملحق التعليمات

## ابنِ DSL الخاصة بك

في هذا التمرين، لك مطلق الحرية في تصميم DSL الرسم البياني الذي تحلم به.

ربما تودّ إنشاء DSL تعتمد على مصفوفات من الوسوم والسجلات، هكذا:

```roc
my_graph =
    Graph.new([
        Title("My Graph"),
        Node("a", { color: Green }),
        Node("b", { color: Blue }),
        Edge("a", "b", { style: Dotted }),
    ])
```

أو ربما تفضّل DSL تعتمد على استدعاءات دوال متتالية، هكذا:

```roc
my_graph =
    Graph.new
        .with_title("My Graph")
        .add_node("a", Attr.new.with_color(Green))
        ...
```

أو ربما لديك خطة مختلفة تمامًا؟ امضِ قدمًا! لا تطلب منك الاختبارات سوى إنشاء بعض الرسوم البيانية المحددة، وطريقة بنائها متروكة لك تمامًا.

ومع ذلك، تكون DSL عادة أفضل إذا كانت واضحة وموجزة وغير مفاجئة أكثر من اللازم (فمثلًا، دالة `minus` مخصّصة للطرح، لا لبناء حافة بين عقدتين كما في `node("a") - node("b")`).

ولمضاعفة المتعة، يمكنك اختياريًا أن تحاول تنفيذ دالة `to_dot` تحوّل رسمك البياني إلى صيغة DOT!
