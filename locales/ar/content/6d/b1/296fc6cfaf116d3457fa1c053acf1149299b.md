# مقدمة

مثل كثير من اللغات الأخرى، توفّر لغة C++ _المؤشرات_.
أنت تعرف بالفعل أن _المراجع_ و_المؤشرات_ متشابهة، لكن اعتبرهما مستوى أقرب إلى طريقة عمل حاسوبك من الداخل.
_المؤشرات_ متغيرات تحمل عناوين الكائنات.
تُستخدم للتفاعل المباشر مع الكائنات، مما يتيح تخصيص الذاكرة الديناميكي ومعالجة البيانات بكفاءة في C++.

إذا كنت جديدًا على _المؤشرات_، فقد تبدو غامضة بعض الشيء، لكنها تصبح بسيطة جدًا بمجرد أن تعتاد عليها.

إنها جزء أساسي من C++، لذا خصّص بعض الوقت لفهمها فهمًا حقيقيًا.
النسخة المجرّدة في هذا المفهوم تُسمّى أيضًا _المؤشر غير الذكي_ أو _المؤشر الخام_.
مع C++ الحديثة توجد أيضًا _المؤشرات الذكية_، أما النوع الأساسي فليس ذكيًا على الإطلاق، وعليك أن تتعامل مع كل العمل يدويًا.

قبل الخوض في التفاصيل، يجدر بك أن تفهم استخدام _المؤشرات_.
_المؤشرات_ طريقة لمشاركة عنوان كائن ما مع أجزاء أخرى من برنامجنا، وهذا مفيد لسببين رئيسيين:

1. مثل _المراجع_، تتجنب المؤشرات النسخ وتساعد على تقليل استهلاك برنامجك للموارد.
1. وعلى عكس _المراجع_، يمكن إعادة إسناد المؤشرات إلى كائنات مختلفة.
1. ويمكن للمؤشرات أيضًا أن تشير إلى قيمة فارغة، لتدل على أنها لا تشير حاليًا إلى أي كائن.

## الصياغة العامة

يتضمّن تعريف مؤشر في C++ تحديد نوع البيانات الذي يشير إليه المؤشر، يليه نجمة (`*`) ثم اسم المؤشر.
عند تعريف المؤشرات، لا يتم تهيئتها تلقائيًا.
وبدون إسناد صريح، يحمل المؤشر عادةً قيمة غير محددة، يُشار إليها غالبًا باسم «عنوان عشوائي».
قد تهيّئ بعض المترجمات المؤشرات إلى `nullptr`، لكن هذا السلوك غير مضمون في كل المترجمات، لذا من الضروري ألا تعتمد عليه.
من أفضل الممارسات تهيئة المؤشرات الخام صراحةً والتحقق من أنها ليست فارغة قبل استخدامها، لتجنّب مشكلات محتملة.

```cpp
int* ptr{nullptr}; // Declares a pointer and makes sure it is not invalid
```

لإسناد عنوان متغير إلى مؤشر، تستخدم عامل العنوان (`&`).
أما إلغاء الإشارة إلى مؤشر فيتم باستخدام _عامل الإشارة غير المباشرة_ (`*`).

```cpp
std::string opponent{"Solomon Lane"};
// 'ethan' points to the address of the string opponent
std::string* ethan{&opponent};
// Instead of ethan's, the opponent's name address is given to the passPort
std::string passportName{*ethan};
```

تنبيه: يجب إلغاء الإشارة صراحةً، بينما تعمل _المراجع_ ببساطة كاسم مستعار.

## حساب المؤشرات

يتيح لك _حساب المؤشرات_ إجراء عمليات حسابية على المؤشرات، وهو أمر مفيد بشكل خاص عند التعامل مع المصفوفات.
إضافة عدد صحيح إلى مؤشر تجعله يشير إلى عنصر مختلف.

```cpp
// Stargate Coordinate Code
int gateCode[] = {462, 753, 218, 611, 977};
// 'ptr' points to the first element of 'gateCode'
int* ptr{&gateCode[0]};
// Accesses the third Stargate address through pointer arithmetic
int dialedAddress{*(ptr + 2)};
// Chevron encoded! Dialing Stargate address:
openStarGate(dialedAddress);
```

قد يظهر السلوك غير المعرّف في صورة نتائج غير متوقعة للبرنامج، أو انهيارات، أو حتى ثغرات أمنية.

## الوصول إلى متغيرات الأعضاء

في C++، يُستخدم العامل `->` للوصول إلى أعضاء كائن عبر مؤشر إليه.
إنه اختصار يسهّل الوصول إلى أعضاء الكائنات التي تشير إليها المؤشرات.
على سبيل المثال، إذا كان `ptr` مؤشرًا إلى كائن له متغير عضو `x`، فبدلًا من استخدام `(*ptr).x` يمكنك استخدام `ptr->x` مباشرة.
يعزّز هذا العامل وضوح الكود ويقلّل الإسهاب عند التعامل مع مؤشرات إلى كائنات.

إليك مثالًا موجزًا، باستخدام `struct` اسمها `Superhero` ولها متغير عضو `superpower`.
وتُنشئ الدالة `main` مؤشرًا `dianaPrince` إلى كائن `Superhero` (يمثّل Wonder Woman).
ويُستخدم العامل `->` للوصول إلى متغير العضو `superpower`، بما يعرض «حبل الحقيقة» الشهير لدى Wonder Woman.

```cpp
struct Superhero {
    std::string superpower;
};
Superhero wonder_woman{};
Superhero* dianaPrince = &wonder_woman;
dianaPrince->superpower = "Lasso of Truth";
// Using the -> operator to access member variable superpower:
std::cout << "Wonder Woman, possesses the mighty " << dianaPrince->superpower;
// Memory cleanup:
delete dianaPrince;
```

## المؤشرات مقابل المراجع

تتيح المؤشرات والمراجع كلتاهما وصولًا غير مباشر إلى الكائنات، لكنهما يختلفان في إمكاناتهما واعتبارات الأمان.
توفّر المؤشرات مرونة تغيير الكائن الذي تشير إليه، ويمكن إسنادها قيمة فارغة.
غير أن هذه المرونة تجلب مخاطر، مثل إلغاء الإشارة إلى مؤشرات فارغة أو إنشاء مؤشرات معلّقة.
أما المراجع، فلا يمكن أن تكون فارغة، وترتبط بكائنات صالحة عند إنشائها، وهو ما يجنّبك هذه المخاطر.
ونظرًا لطبيعتها الأكثر أمانًا، يُفضّل استخدام المراجع بدلًا من المؤشرات، إلا إذا كانت الوظائف الإضافية التي توفّرها المؤشرات ضرورية.
