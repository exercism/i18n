# نبذة

صنف `Lambda` هو مجموعة من الطرق الوظيفية تتيح استخدام أسلوب البرمجة الوظيفية مع Haxe. فهو يسمح لنا بالتعامل مع أي `Iterable` كاملة دفعة واحدة. وهذا غالبًا أفضل من كتابة حلقات تكرارية، لأنه أقل عرضة للأخطاء وأسهل في القراءة. وللتيسير، يحتوي صفّا `Array` و`List` على بعض الطرق الشائعة الاستخدام من صنف `Lambda`.

من دوال صنف `Lambda` ما يلي:

- `Lambda.array` و`Lambda.list` تحويل `Iterable` إلى `Array` أو `List`. وتُرجعان دائمًا نسخة جديدة.
- `Lambda.count` حساب عدد العناصر. وإذا كان `Iterable` من نوع `Array` أو `List`، فاستخدام خاصية `length` أسرع.
- `Lambda.has` تحديد ما إذا كان العنصر المحدد موجودًا في `Iterable`.
- `Lambda.indexOf` معرفة فهرس العنصر المحدد.
- `Lambda.find` العثور على أول عنصر يطابق دالة البحث المعطاة.
- `Lambda.concat` دمج كائنين من النوع `Iterable`، وإرجاع `List` جديدة.
- `Lambda.filter` إيجاد العناصر التي تحقق معيارًا معينًا، وإرجاع `List` جديدة.

مثال يوضح بعض الدوال:

```haxe
using Lambda;

class Main {
  static function main() {
    var words = ["boat", "dog", "phone", "cat", "food"];

    var isThreeLetters = function(word) return word.length == 3;

    trace(words.filter(isThreeLetters)); // [dog,cat]
  }
}
```
