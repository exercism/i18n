# البنى

البنى هي أنواع بيانات مخصصة تسمح لك بتسمية وتجميع عدة قيم مرتبطة معًا.
وهي مشابهة للصفوف، لكنها أكثر مرونة وتسمح لك بتسمية كل جزء من البيانات، مما يجعل الكود أوضح.
تتميز البنى في Cairo بالخصائص التالية:

- كل نوع بنية له اسم معين.
- كل عضو في البنية يسمى **حقلًا**.
- كل حقل في البنية له اسم معين.
- يُتتبَّع الظهور على مستوى الحقل: قد يكون كل حقل عامًا أو خاصًا بشكل مستقل.

## تعريف البنى وإنشاء نسخ منها

لتعريف بنية، استخدم الكلمة المفتاحية `struct` متبوعة باسم والأقواس المعقوفة التي تحتوي على الحقول بأسمائها وأنواعها:

```rust
#[derive(Drop)]
struct User {
    active: bool,
    username: ByteArray,
    email: ByteArray,
    sign_in_count: u64,
}
```

لإنشاء نسخة من `struct`، حدِّد اسم `struct` واستخدم الأقواس المعقوفة مع أزواج مفتاح وقيمة للحقول.
لاحظ أنه يمكنك سرد الحقول بأي ترتيب عند إنشاء نسخة:

```rust
let user1 = User {
   active: true, username: "someusername123", email: "someone@example.com", sign_in_count: 1
};

let user2 = User {
    sign_in_count: 1, username: "someusername123", active: true, email: "someone@example.com"
};
```

## التعامل مع نسخة من بنية

استخدم تدوين النقطة للوصول إلى حقول نسخة `struct` أو تعديلها.
لاحظ أنه لتعديل حقل، يجب أن تكون النسخة قابلة للتغيير:

```rust
let mut user1 = User {
    active: true, username: "someusername123", email: "someone@example.com", sign_in_count: 1
};
user1.email = "anotheremail@example.com";
```

كما هو الحال مع أي تعبير، يمكننا إنشاء نسخة جديدة من `struct` كآخر تعبير في جسم الدالة، فتُرجع الدالة تلك النسخة الجديدة ضمنيًا:

```rust
fn build_user(email: ByteArray, username: ByteArray) -> User {
    User {
        email: email,
        username: username,
        active: true,
        sign_in_count: 1,
    }
}
```

## اختصار تهيئة الحقول

في المثال الأخير كان من المنطقي أن تسمي معاملي الدالة `email` و`username` بالأسماء نفسها المستخدمة لحقول `struct`، لكن إعادة ذكرهما عند إسنادهما إلى حقول البنية أمر مضجر بعض الشيء.
لحسن الحظ، توجد صيغة مختصرة ملائمة لتهيئة حقول البنية من متغيرات تحمل الأسماء نفسها:

```rust
fn build_user_short(email: ByteArray, username: ByteArray) -> User {
    User { email, username, active: true, sign_in_count: 1, }
}
```

## إنشاء نسخ من نسخ أخرى باستخدام صيغة تحديث البنية

استخدم صيغة تحديث البنية لإنشاء نسخة جديدة من نسخة موجودة، مع تغيير بعض الحقول وإبقاء البقية كما هي.
يتحقق ذلك باستخدام العامل `..`.

بدون صيغة التحديث:

```rust
let user2 = User {
    active: user1.active,
    username: user1.username,
    email: "another@example.com",
    sign_in_count: user1.sign_in_count,
};
```

مع صيغة التحديث:

```rust
let user2 = User { email: "another@example.com", ..user1 };
```

تنسخ صيغة `..user1` الحقول المتبقية من `user1` إلى `user2`.
لاحظ أن هذا ينقل البيانات من `user1` إلى `user2`، لذا لا يمكن استخدام `user1` بعد ذلك إذا كان يحتوي على أنواع غير قابلة للنسخ.
