# مقدمة

توفّر حزمة [math/rand][mathrand] دعمًا لتوليد أعداد شبه عشوائية.

إليك كيفية توليد عدد صحيح عشوائي بين `0` و`99`:

```go
n := rand.Intn(100) // n is a random int, 0 <= n < 100
```

تُرجع الدالة `rand.Float64` عددًا عشريًا عشوائيًا بين `0.0` و`1.0`:

```go
f := rand.Float64() // f is a random float64, 0.0 <= f < 1.0
```

هناك أيضًا دعم لخلط عناصر مصفوفة (أو بنى بيانات أخرى):

```go
x := []string{"a", "b", "c", "d", "e"}
// shuffling the slice put its elements into a random order
rand.Shuffle(len(x), func(i, j int) {
	x[i], x[j] = x[j], x[i]
})
```

## البذور

متتاليات الأعداد التي تولّدها حزمة `math/rand` ليست عشوائية حقًا.
عند تحديد قيمة "بذرة" معيّنة، تكون النتائج حتمية تمامًا.

في Go 1.20+ تُختار البذرة تلقائيًا بشكل عشوائي، لذا سترى متتالية مختلفة من الأعداد العشوائية في كل مرة تشغّل فيها برنامجك.

في الإصدارات السابقة من Go، كانت البذرة `1` افتراضيًا.
لذا، للحصول على متتاليات مختلفة عند تشغيل البرنامج عدة مرات، كان عليك ضبط بذرة مولّد الأعداد العشوائية يدويًا، مثلًا بالوقت الحالي، قبل جلب أي أعداد عشوائية.

```go
rand.Seed(time.Now().UnixNano())
```

[mathrand]: https://pkg.go.dev/math/rand
