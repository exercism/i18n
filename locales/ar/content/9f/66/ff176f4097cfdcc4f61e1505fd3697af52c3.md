# التعليمات

في هذا التمرين ستقوم بمعالجة أسطر السجل.

كل سطر من أسطر السجل هو سلسلة نصية مُنسّقة كما يلي: `"[<LEVEL>]: <MESSAGE>"`.

هناك ثلاثة مستويات سجل مختلفة:

- `INFO`
- `WARNING`
- `ERROR`

لديك ثلاث مهام، كل مهمة منها ستأخذ سطرًا من سطور السجل وتطلب منك فعل شيء به.

## 1. استخراج الرسالة من سطر السجل

نفّذ الطريقة (_static_) `LogLevels.message()` لتُرجع رسالة سطر السجل:

```java
LogLevels.message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

يجب إزالة أي مسافات بيضاء بادئة أو لاحقة:

```java
LogLevels.message("[WARNING]:  Disk almost full\r\n")
// => "Disk almost full"
```

## 2. الحصول على مستوى السجل من سطر السجل

نفّذ الطريقة (_static_) `LogLevels.logLevel()` لتُرجع مستوى السجل الخاص بسطر السجل، ويجب أن يكون بأحرف صغيرة:

```java
LogLevels.logLevel("[ERROR]: Invalid operation")
// => "error"
```

## 3. إعادة تنسيق سطر السجل

نفّذ الطريقة (_static_) `LogLevels.reformat()` التي تعيد تنسيق سطر السجل، فتضع الرسالة أولًا ثم مستوى السجل بعدها بين الأقواس الهلالية:

```java
LogLevels.reformat("[INFO]: Operation completed")
// => "Operation completed (info)"
```
