# مقدمة

الإدخال والإخراج في Factor مبنيان على *التدفقات*، وهي كائنات تقرأ منها البايتات أو المحارف، أو تكتب فيها. تمنحك مفردات [`io`][io] منظورين للبروتوكول نفسه.

## المنظوران

كلمات **التدفق الصريح** تأخذ التدفق كوسيط، وكلها تبدأ بـ `stream-`:

```
stream-read       ( n stream -- seq/f )
stream-readln     ( stream -- str/f )
stream-write      ( seq stream -- )
stream-flush      ( stream -- )
stream-contents   ( stream -- seq )
stream-lines      ( stream -- seq )
```

كلمات **التدفق المحيط** تقرأ من أي تدفق *مرتبط حاليًا* أو تكتب فيه، وهو المتغير الديناميكي على مستوى البرنامج `input-stream` أو `output-stream`. ولها أسماء قصيرة:

```
read1 read readln write write1 print flush
```

الصيغة المحيطة هي ما يستخدمه معظم الكود اليومي. أما الصيغة الصريحة فهي ما تلجأ إليها عندما تكون لديك تدفق محدد ولا تريد استبدال التدفق المحيط به.

## تدفقات في الذاكرة

في هذا التمرين ستعمل مع تدفقات مبنية على سلاسل نصية من [`io.streams.string`][io.streams.string]:

```
<string-reader>   ( str -- reader )
<string-writer>   ( -- writer )
```

يقرأ `<string-reader>` من سلسلة نصية حرفية كما لو كانت ملفًا، ويجمع `<string-writer>` كل ما يُكتب فيه حتى تتمكن من قراءته لاحقًا. وهما ينفّذان البروتوكول نفسه الذي تنفّذه تدفقات الملفات، لذا تنتقل الدروس مباشرة إلى `<file-reader>` / `<file-writer>`.

## تحديد النطاق باستخدام `with-…`

لربط تدفق صريح كتدفق محيط لإحدى الكتل ثم التخلص منه بعد ذلك، استخدم أحد مُركّبات `with-…`:

```
with-input-stream    ( stream quot -- )
with-output-stream   ( stream quot -- )
with-string-writer   ( quot -- str )
with-file-reader     ( path encoding quot -- )
with-file-writer     ( path encoding quot -- )
```

‏[`with-string-writer`][with-string-writer] هي الصيغة الملائمة لجمع ما تطبعه هذه الكتلة: فهي تنشئ الكاتب، وتشغّل الكتلة مع هذا الكاتب كمخرج محيط، ثم تُرجع السلسلة النصية الملتقطة:

```factor
USING: io io.streams.string ;

[ "captured" print ] with-string-writer .
! => "captured\n"
```

جميع مُركّبات `with-…` هي مُركّبات مُدمِّرة (من العائلة نفسها التي تنتمي إليها `with-disposal` و`with-destructors` في [`boatswains-bilge`][boatswains-bilge])، إذ يُتخلّص من التدفق عند الخروج حتى لو أطلقت الكتلة استثناءً.
