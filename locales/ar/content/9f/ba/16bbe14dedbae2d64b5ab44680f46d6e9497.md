# نبذة

تعتمد مكتبة المتتاليات في Factor اعتمادًا كبيرًا على *الاقتباسات*، وهي كود بين قوسين `[ ]`، من أجل تمرير معاملات إلى التكرار. والشكل واحد دائمًا: مرّر متتالية واقتباسًا، فتُشغّل الكلمة ذات الرتبة الأعلى الاقتباس على كل عنصر.

```factor
{ 1 2 3 4 5 } [ even? ] filter .   ! => { 2 4 }
{ 1 2 3 4 5 } [ even? ] reject .   ! => { 1 3 5 }
{ 1 2 3 4 5 } [ 3 > ] find .s      ! => 3 / 4 (index, element)
{ 1 2 3 4 5 } [ sq ] map .         ! => { 1 4 9 16 25 }
{ 1 2 3 4 5 } [ . ] each           ! prints each element
0 { 1 2 3 4 5 } [ + ] reduce .     ! => 15
```

وهذه القائمة الكاملة للكلمات الشائعة:

| الكلمة         | الشكل                                      |
|--------------|--------------------------------------------|
| `each`       | `( seq quot -- )`                          |
| `map`        | `( seq quot -- newseq )`                   |
| `filter`     | `( seq quot -- newseq )`                   |
| `reject`     | `( seq quot -- newseq )`                   |
| `find`       | `( seq quot -- i/f elt/f )`                |
| `find-last`  | `( seq quot -- i/f elt/f )`                |
| `reduce`     | `( seq init quot -- result )`              |
| `map-sum`    | `( seq quot -- n )`                        |
| `count`      | `( seq quot -- n )`                        |
| `any?`       | `( seq quot -- ? )`                        |
| `all?`       | `( seq quot -- ? )`                        |
| `with`       | `( value seq quot -- seq curry )`          |
| `without`    | `( seq exclude -- newseq )`                |
| `sort`       | `( seq -- sortedseq )`                     |
| `sum`        | `( seq -- n )`                             |
| `minimum`    | `( seq -- elt )`                           |
| `maximum`    | `( seq -- elt )`                           |
| `minimum-by` | `( seq quot -- elt )`                      |
| `maximum-by` | `( seq quot -- elt )`                      |

وعندما تمرّر *كلمتك* اقتباسًا وقت التشغيل إلى أحد هذه المُركِّبات، أعلن عن كلمتك باستخدام `; inline` حتى يتمكّن استدلال الأثر الخاص بالمُركِّب من رؤية شكل الاقتباس عند موضع الاستدعاء. أما الكلمات المبنية من اقتباسات حرفية فقط فلا تحتاج إلى ذلك.

وإلى جانب عمليات المتتاليات الأساسية:

| المفردات              | ما توفّره                                      |
|--------------------|-----------------------------------------------|
| [`sorting`][sorting]          | `sort`, `sort-by`                             |
| [`math.statistics`][math.statistics]  | `cum-sum`, `cum-product`, `cum-min`, `cum-max` |
| [`grouping`][grouping]         | `group`, `clump`, `monotonic-split`           |
| [`sets`][sets]             | `members`, `all-unique?`                      |

والأزواج (`bi`, `tri`) والمُركِّبات متعددة المعاملات (`2map`, `2each`, `zip`) توسّع النمط نفسه عندما يحتاج الاقتباس إلى أكثر من مدخل واحد.
