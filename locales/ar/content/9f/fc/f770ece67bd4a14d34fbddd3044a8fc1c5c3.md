## لمحة تاريخية موجزة

كان التعامل مع المحارف في الحواسيب أبسط بكثير في العقود الماضية، حين افترض المبرمجون أن الإنجليزية هي اللغة المهمة الوحيدة.
إذن: 26 حرفًا بحالتيه العلوية والسفلية، و10 أرقام، وعدة علامات ترقيم، بالإضافة إلى رمز (0x07) لإطلاق جرس، وقد اتسع كل ذلك في 7 بتات: مجموعة محارف [ASCII][wiki-ascii].

بطبيعة الحال، بدأ الناس يسألون: ماذا عن à وä وŁ؟ ثم بدأ آخرون يسألون عن ऄ وஹ وญ، وأراد الشباب رموزًا تعبيرية 😱.
فما العمل؟

ولاختصار القصة الطويلة، اضطر كثير من الأذكياء والصابرين إلى العمل في لجان لسنوات، لوضع تفاصيل مجموعة محارف [Unicode][web-unicode]، وترميزات مثل [UTF-8][wiki-utf-8]، واحتاج قدر كبير من البرمجيات إلى إعادة كتابة _بالغة_ التعقيد.
كما أُدخل عدد كبير من `bug` جديدة.

ولمنع انهيار _كل شيء_، يضمن تصميم Unicode/UTF-8 أن أول 127 رمزًا مطابقة لـ ASCII _(حتى الجرس)_.

## المحارف في Kotlin

تتمتع اللغات المصممة بعد عام 2005 تقريبًا بميزة كبيرة، وهي أن معيار Unicode مستقر إلى حد معقول كان موجودًا بالفعل.

كانت Kotlin (صدرت أول مرة في 2011) قادرة على افتراض أن المستخدمين سيستعملون تنوعًا من اللغات (البشرية)، وأنهم سيحتاجون إلى Unicode للتعبير عنها.

~~~~exercism/advanced
[المحارف][ref-char] في Kotlin هي نقاط ترميز [`codepoints`][wiki-codepoint] بحجم 16 بت (UTF-16)، تمامًا مثل `char` في JVM.
هذا كافٍ للتعبير عن معظم الأبجديات المكتوبة، لكن ليس عن كامل نطاق الرموز التعبيرية.

يستخدم معيار Unicode الكامل ما يصل إلى ست بايتات (48 بت) لكل محرف (ويسمى [`grapheme`][wiki-grapheme]).

تدعم `Strings` في Kotlin هذا المعيار الكامل باستخدام عدة نقاط ترميز لكل محرف عند الحاجة.
على سبيل المثال، سيكون 😱 هو `\uD83D` و`\uDE31`.

لسوء الحظ، لا يملك Java أي دعم مدمج لـ`grapheme`، ولأجل التوافق لا تملكه Kotlin هي الأخرى.

[wiki-codepoint]: https://en.wikipedia.org/wiki/Code_point
[wiki-grapheme]: https://en.wikipedia.org/wiki/Grapheme
[ref-char]: https://kotlinlang.org/docs/characters.html
~~~~


تُكتب المحارف الحرفية بين علامتي اقتباس مفردتين، وهي مميزة عن السلاسل النصية المكتوبة بين علامتي اقتباس مزدوجتين.
قد يكون هذا بديهيًا لمن يأتي من عالم C/C++، لكنه قد يربك مبرمجي Python وJavaScript.

```kotlin
val a = 'a'
a::class.qualifiedName  // => kotlin.Char
a.code  // => 97

val jha = 'झ'  // Devanagari alphabet
jha.code  // => 2333

val heart = '❤'  // heart emoji
heart.code  // => 10084

Char.MAX_VALUE.code // => 65535 (64k, the largest code point allowed)

val not_char = 'abc' // => Too many characters in a character literal.
```

التحويل بين `Char` و`Int` مباشر:

```kotlin
a.code  // => 97
Char(97) // => 'a'
```

يسمح المترجم بـ_بعض_ أشكال الحساب الصحيح على `Char`:

```kotlin
'a' + 5     // => 'f'
'c' - 'a'   // => 2
'c' + 'a'   // => error!

'f' + ('A' - 'a')  // => 'F' (same as 'f'.uppercase()

'f'.dec() // => 'e' (decrement)
'f'.inc() // => 'g' (increment)
```

## بعض الدوال الخاصة بـ `Char`

كما هو الحال دائمًا، هناك [دوال كثيرة][ref-char-lib] أكثر من أن نناقشها هنا، لذا هذه مجرد مختارات.

- بالنسبة إلى الأبجديات المناسبة، غيّر حالة الأحرف باستخدام [`uppercase()`][ref-uppercase] و[`lowercase()`][ref-lowercase].
- واختبر الحالة باستخدام [`isUpperCase()`][ref-isuppercase] و[`isLowerCase()`][ref-islowercase].
- واختبر نوع المحرف باستخدام:
  - [`isLetter()`][ref-isletter]، وتغطي أبجديات كثيرة (فئات Lu وLl وLt وLm وLo في Unicode)
  - [`isDigit()`][ref-isdigit]، في النطاق 0..9 (فئة Nd في Unicode)
  - `isLetterOrDigit()`، وتجمع الاثنتين السابقتين
  - [`isWhitespace()`][ref-iswhitespace]، أي محرف مسافة بيضاء (فئات Cc وZp وZl وZs في Unicode)

```kotlin
'झ'.isLetter()      // => true
'A'.isLowerCase()   // => false
'4'.isDigit()       // => true
'\t'.isWhitespace() // => true  (tab character)
```

كذلك تتيح [التعبيرات النمطية][ref-regex] (التي ستكون موضوع مفهوم لاحق) بحثًا ومعالجةً قويين.

## التحويل بين قائمة المحارف والسلسلة النصية

للتحويل من `String` إلى `List` من `Char`، يمكننا استخدام `toList()`.

وللتحويل من `List` من `Char` إلى `String`، هناك الدالة [`joinToString()`][ref-jointostring]، التي تأخذ فاصلًا (غالبًا السلسلة النصية الفارغة) كوسيط.

```kotlin
val kt = "kotlin".toList()  // => [k, o, t, l, i, n]
kt.joinToString("")   // => "kotlin"
kt.joinToString("_")  // => "k_o_t_l_i_n"
```

لاحظ أن `joinToString()` تعمل على List أو Array.
ولـ_تحويل_ محرف `Char` واحد إلى سلسلة نصية من محرف واحد، استخدم `toString()`.

```kotlin
'a'.toString() // => "a"
```

للتحقق من وجود محرف في `String`، أو في قائمة أو مصفوفة من `Char`، لدينا `in`، الذي يقابل الدالة [`contains()`][ref-contains].

```kotlin
val clist = "kotlin".toList()  // => [k, o, t, l, i, n]
't' in clist     // => true
't' in "kotlin"  // => true
```
