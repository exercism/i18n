# التعليمات

استكمالًا لعملك في مدينة الملاهي، يُطلب منك كتابة بعض الطرق المساعدة لتسهيل التحقق مما إذا كان بإمكان الزائر استخدام إحدى الألعاب.

## 1. تحقق مما إذا كان لدى الزائر تصريح ركوب

نفّذ الطريقة `Attendee#has_pass?` لتُرجع قيمة منطقية (`true`/`false`) بناءً على وجود تصريح الركوب.

```ruby
Attendee.new(100).has_pass?
# => false
```

## 2. تحقق مما إذا كان الزائر يناسب إحدى الألعاب

نفّذ الطريقة `Attendee#fits_ride?` لمعرفة ما إذا كان الزائر يناسب لعبة ما بناءً على طوله.
يُمرَّر الحد الأدنى للطول المطلوب للعبة كوسيط.
يجب أن يكون طول الزائر أكبر من أو يساوي الحد الأدنى للطول المطلوب للعبة.

```ruby
Attendee.new(140).fits_ride?(100)
# => true
```

## 3. تحقق مما إذا كان مسموحًا للزائر بالركوب

نفّذ الطريقة `Attendee#allowed_to_ride?` لمعرفة ما إذا كان مسموحًا للزائر بركوب إحدى الألعاب. يُمرَّر الحد الأدنى للطول المطلوب للعبة كوسيط. يجب أن يكون لدى الزائر تصريح ركوب وأن يناسب اللعبة.

```ruby
attendee = Attendee.new(100)
attendee.issue_pass!(42)
attendee.allowed_to_ride?(120)
# => false
```
