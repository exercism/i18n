# التعليمات

في هذا التمرين ستعمل على منظّم مواعيد لصالون تجميل افتُتح في 15 سبتمبر 2012.

لديك خمس مهام، وكلها ستتعلق بتواريخ المواعيد.

## 1. تحليل تاريخ الموعد

نفّذ الدالة `Schedule` لتحليل تمثيل نصي لتاريخ موعد إلى صيغة `time.Time` المقابلة:

```go
Schedule("7/25/2019 13:45:00")
// => 2019-07-25 13:45:00 +0000 UTC
```

## 2. التحقق مما إذا كان الموعد قد مضى

نفّذ الدالة `HasPassed` التي تأخذ تاريخ موعد وتتحقق مما إذا كان الموعد في الماضي:

```go
HasPassed("July 25, 2019 13:45:00")
// => true
```

## 3. التحقق مما إذا كان الموعد بعد الظهر

نفّذ الدالة `IsAfternoonAppointment` التي تأخذ تاريخ موعد وتتحقق مما إذا كان الموعد بعد الظهر (>= 12:00 و < 18:00):

```go
IsAfternoonAppointment("Thursday, July 25, 2019 13:45:00")
// => true
```

## 4. وصف وقت الموعد وتاريخه

نفّذ الدالة `Description` التي تأخذ تاريخ موعد وتُرجع وصفًا لذلك التاريخ والوقت:

```go
Description("7/25/2019 13:45:00")
// => "You have an appointment on Thursday, July 25, 2019, at 13:45."
```

## 5. إرجاع تاريخ الذكرى السنوية لافتتاح الصالون

نفّذ الدالة `AnniversaryDate` التي تُرجع تاريخ الذكرى السنوية لافتتاح الصالون للسنة الحالية بالتوقيت العالمي UTC.

بافتراض أن السنة الحالية هي 2020:

```go
AnniversaryDate()

// => 2020-09-15 00:00:00 +0000 UTC
```

**ملاحظة:** القيمة المُرجَعة هي `time.Time` ووقت اليوم لا يهم.
