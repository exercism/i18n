# نبذة

Nim لغة عامة الأغراض صمّمها وطوّرها Andreas Rumpf وظهرت أول مرة عام 2008.
صُمّمت لتكون فعّالة ومعبّرة وأنيقة.
Nim لغة ثابتة الأنواع وتُترجَم، لكنها تتيح لك كتابة كود أنيق يعمل بكفاءة.
وتتيح لك Nim استهداف منصات كثيرة بترجمة الكود إلى C أو C++ أو JavaScript أو Objective-C.
تشبه صياغة Nim صياغة Python وتتشارك معها خصائص كثيرة، لكنها تستلهم من عدد من اللغات مثل C و C++ و C# و Lisp و Ada و Go و Oberon وغيرها.

ولأن Nim لغة عامة الأغراض فيمكن استخدامها في مجالات متنوعة، لكنها شغلت مكانة حقيقية في تطوير الألعاب وبرمجة الأنظمة، بما في ذلك الأنظمة المدمجة.

تمنحك Nim قدرًا كبيرًا من الراحة التي تجدها في Python ولغات أخرى، مثل صياغة سهلة القراءة، ونظام لإدارة الحزم لاستخدام مكتبات جديدة في مشاريعك، وتقارير تتبّع ودّية للمستخدم لتصحيح الأخطاء.

تمنحك Nim سرعة C وقابلية نقلها، لكن مع جامع مهملات عالي الأداء وصياغة أنيقة تجعل اللغة في متناول المبتدئين.
وتمنحك Nim أيضًا التحكم، فتتيح لك تغيير جامع المهملات أو إيقافه تمامًا، ليكون أمامك خيار إدارة الذاكرة بنفسك.
وتتوفّر لك مع Nim تشكيلة متنوعة من أنماط البرمجة وطبقات التجريد.
