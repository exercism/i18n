# مقدمة

## الأعداد

تحتوي ABAP على عدة أنواع عددية. في هذا التمرين، ستستخدم اثنين منها:

- `i` للقيم الصحيحة، مثل عدد الأيام.
- `p` للقيم العشرية المعبأة، مثل أجر الساعة أو الخصم.

```abap
DATA billable_days TYPE i VALUE 22.
DATA rate_per_hour TYPE p LENGTH 8 DECIMALS 2 VALUE '89.89'.
```

تحدد الأعداد المعبأة طولها الأقصى وعدد منازلها العشرية.
تُكتب القيم الحرفية العشرية عادةً كقيم نصية، ويحوّلها المترجم إلى النوع العشري الهدف أو يحوّلها أنت باستخدام `CONV`.

```abap
TYPES discount_rate TYPE p LENGTH 8 DECIMALS 6.

DATA discount TYPE discount_rate.
discount = CONV discount_rate( '0.15' ).
```

### التقريب

توفر ABAP دوال عددية مدمجة للتقريب.
دالة `floor` تقرّب للأسفل إلى أقرب عدد صحيح، ودالة `ceil` تقرّب للأعلى إلى أقرب عدد صحيح.

```abap
DATA full_months TYPE i.
full_months = floor( 70 / 22 ).

DATA rounded_cost TYPE i.
rounded_cost = ceil( '14527.2' ).
```

## العوامل الحسابية

تدعم ABAP عوامل حسابية لإجراء العمليات الحسابية على القيم العددية.

```abap
DATA day_rate TYPE p LENGTH 8 DECIMALS 2.
day_rate = rate_per_hour * 8.
```

العوامل الأساسية هي:

- `+` للجمع.
- `-` للطرح.
- `*` للضرب.
- `/` للقسمة.
- `MOD` لباقي قسمة الأعداد الصحيحة.

```abap
DATA remaining_days TYPE i.
remaining_days = num_days MOD 22.
```

تحسب ABAP الضرب والقسمة قبل الجمع والطرح.
ويمكن استخدام الأقواس الهلالية لجعل الترتيب المقصود واضحًا.

```abap
DATA discounted_rate TYPE p LENGTH 8 DECIMALS 2.
discounted_rate = monthly_rate * ( 1 - discount ).
```
