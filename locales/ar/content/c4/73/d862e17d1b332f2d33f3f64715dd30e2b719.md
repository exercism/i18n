# نبذة

حين يتعذّر التحويل الضمني بين الأنواع، يجب عليك استخدام [عامل][cast-operator] التحويل الصريح. وعامل التحويل ليس إلا النوع الهدف بين الأقواس الهلالَين قبل القيمة التي تريد تحويلها:

```csharp

int i = 7;
byte b = (byte)i; // Explicit cast from int to byte
```

قد يكون استخدام التحويل الصريح خطيرًا. والخطأان الأكثر شيوعًا هما:

- التحويل إلى نوع غير متوافق. سيرفع هذا استثناءً أثناء التشغيل.
- التحويل إلى قيمة عددية ليست «واسعة» بما يكفي. وقد يؤدي هذا إلى تعارض في الإشارة، أو إلى رفع استثناء تجاوز في حالة الأعداد الصحيحة.

ملاحظة: يمكن تحويل تعبير من النوع `int` تحويلًا صريحًا إلى `char`. وقد ينتج عن ذلك `char` غير صالح.

[cast-operator]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/operators/type-testing-and-cast#cast-expression
