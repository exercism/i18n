# التعليمات

في هذا التمرين أنت من مشجعي الرياضة الكبار، وقد اكتشفت للتو شغفًا بكرة سلة NBA.
ولأنك جديد على كرة سلة NBA، فأنت تتعمّق في تاريخ NBA، وتتابع الفرق والمدربين وإحصاءات انتصاراتهم وخسائرهم وتقارن بينها.

ولأنه ليس لديك بعد فريق مفضّل، ستطوّر أيضًا خوارزمية لتحديد ما إذا كان ينبغي أن تشجّع فريقًا معيّنًا.
أمامك سبع مهام تساعدك على تطوير خوارزمية _اختيار الفريق الذي تشجّعه_ الخاصة بك.

## 1. عرّف النموذج

عرّف `type alias` بالاسم `Coach` لسجل يحتوي الحقلين التاليين، بالترتيب التالي:

- `name`: اسم المدرب، من النوع `String`.
- `formerPlayer`: يشير إلى ما إذا كان المدرب لاعبًا سابقًا، من النوع `Bool`.

عرّف `type alias` بالاسم `Stats` لسجل يحتوي الحقلين التاليين، بالترتيب التالي:

- `wins`: عدد الانتصارات، من النوع `Int`.
- `losses`: عدد الخسائر، من النوع `Int`.

عرّف `type alias` بالاسم `Team` لسجل يحتوي الحقول الثلاثة التالية، بالترتيب التالي:

- `name`: اسم الفريق، من النوع `String`.
- `coach`: مدرب الفريق، من النوع `Coach`.
- `stats`: إحصاءات الفريق، من النوع `Stats`.

## 2. أنشئ فريقًا

تريد التواصل مع كود طرف ثالث لديه مفهوم الفريق، لكنه ينادي الكود لديك بمعاملات بترتيب مختلف. أضف دالة `createTeam` بالتوقيع التالي `String -> Stats -> Coach -> Team`.

## 3. استبدل المدرب

نظرًا لأن مالكي فرق NBA قليلو الصبر، وجدت أن النتائج السيئة للفريق كثيرًا ما تؤدي إلى استبدال المدرب.
نفّذ دالة `replaceCoach` التي تأخذ المدرب الجديد والفريق كمعاملين، وتُرجع الفريق مع المدرب الجديد:

```elm
let
    coach = { name = "Larry Bird", formerPlayer = True }
    stats = { wins = 58, losses =  24 }
    team = { name = "Indiana Pacers", coach = coach, stats =  stats }
    newCoach = { name = "Isiah Thomas", formerPlayer = True }
in
replaceCoach newCoach team
--> { name = "Indiana Pacers"
--  , coach = { name = "Isiah Thomas", formerPlayer = True }
--  , stats = { wins = 58, losses = 24 } }
```

## 4. تحقّق مما إذا كان ينبغي أن تشجّع فريقًا

في المستقبل، تخطّط لابتكار خوارزمية معقّدة لتحديد ما إذا كان ينبغي أن تشجّع فريقًا أم لا، لكن في المحاولة الأولى قرّرت أن تشجّع أي فريق لديه انتصارات أكثر من الخسائر.

تريد أن تكون هذه الدالة قابلة لإعادة الاستخدام في سياقات أخرى، لذا استخدم سجلًا قابلًا للتوسيع في توقيع النوع لقبول أي سجل يحتوي الحقول ذات الصلة.
ولتبقى الدالة موجزة قدر الإمكان، تريد استخدام مطابقة الأنماط للحصول على `stats` من معامل الدالة.
نفّذ دالة `rootForTeam` التي تأخذ فريقًا وتُرجع `True` إذا كان ينبغي أن تشجّع ذلك الفريق؛ وإلا فتُرجع `False`.

```elm
let
    spursCoach = { name = "Gregg Popovich", formerPlayer =  False }
    spursStats = { wins = 56, losses = 26 }
    spursTeam = { name = "San Antonio Spurs", coach = spursCoach, stats = spursStats }
in
rootForTeam spursTeam
--> True
```
