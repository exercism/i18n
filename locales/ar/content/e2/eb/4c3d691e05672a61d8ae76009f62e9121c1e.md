# مقدمة

## التلاعب بالأنواع

قد يُعرف التلاعب بالأنواع أيضًا باسم إكراه الأنواع.
يحدث التلاعب بالأنواع عندما تُجبر قيمتان من نوعين مختلفين على أن تصيرا من النوع نفسه لتنفيذ عملية.

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15
```

يمكن أن يحدث هذا ضمنيًا (كما في المثال أعلاه)، أو صراحةً عبر تحويل النوع على طريقة `C`:

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

الأنواع المسموح بها في تحويل النوع اليدوي هي: `bool`، `int`، `float`، `string`، `array`، `object`.
وفي الغالب يُستخدم تحويل النوع لتغيير عدد صحيح (`int`) إلى عدد عشري (`float`) أو العكس.
