# ملحق التعليمات

## صيغة الإخراج

تُحدَّد كل جنسية بحرف واحد. (`E` = `Englishman`، `J` = `Japanese`، `N` = `Norwegian`، `S` = `Spaniard`، `U` = `Ukrainian`)

## السجلات

| السجل | الاستخدام | النوع | الوصف |
| -------- | --------- | ------- | ---------------------------- |
| `$v0`    | إخراج    | byte    | جنسية شارِب الماء |
| `$v1`    | إخراج    | byte    | جنسية صاحب الحمار الوحشي |
| `$t0-9`  | مؤقت | any     | لتخزين مؤقت        |
