# نبذة

تتيح [طرق التوسعة][extension-methods] إضافة طرق إلى أنواع موجودة دون إنشاء نوع مشتق جديد، أو إعادة ترجمة الكود، أو تعديل النوع الأصلي بأي شكل آخر.

طرق التوسعة هي طرق ثابتة، إلا أنها تُستدعى كما لو كانت طرق مثيل على النوع الموسَّع. ويتحقق ذلك بوضع الكلمة المفتاحية `this` قبل النوع، ما يشير إلى أن المثيل الذي نضع عليه النقطة `.` يُمرَّر كأول معامل. وبالنسبة إلى كود العميل، لا يوجد فرق ظاهر بين استدعاء طريقة توسعة واستدعاء الطرق المعرَّفة في النوع.

```csharp
namespace MyExtensions
{
    public static int WordCount(this string str)
    {
        return str.Split().Length;
    }
}

"Hello World".WordCount();
// => 2
```

تُضاف طرق التوسعة إلى النطاق على مستوى مساحة الاسم. وهذا يعني أنه إذا كنت في مساحة اسم مختلفة عن المساحة المعرَّفة فيها طريقة التوسعة، فلا بد أن تكون مساحة اسمها ضمن توجيه `using` أولًا؛ فعلى سبيل المثال، إذا أردنا استخدام المثال السابق في الكود الذي نكتبه، فسنحتاج أولًا إلى توجيه `using MyExtensions`. أما إذا كنت في مساحة الاسم نفسها التي عُرِّفت فيها طريقة التوسعة، فيمكنك استخدام طرق التوسعة دون توجيه `using`.

ومن الأمثلة المعروفة على طرق التوسعة عوامل الاستعلام القياسية في [LINQ][linq]، التي تضيف إمكانات الاستعلام إلى أنواع `IEnumerable` الموجودة. ولإضافتها إلى النطاق نحتاج إلى توجيه `using System.Linq;`.
