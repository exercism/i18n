# مقدمة

[البنى][structs-and-classes] (وتُسمّى شائعةً *structs*) هي إحدى اللبنات الأساسية في برامج Swift.
تتيح لك البنى إنشاء أنواع مخصّصة تجمع الخصائص (البيانات) والطرق (السلوك) المترابطة معًا.
بل إن الأنواع القياسية في Swift، ومنها `Int` و`Double` و`Bool` و`String` و`Array` و`Dictionary`، كلها مُنفَّذة كبنى.

## تعريف البنى

عرّف بنية باستخدام الكلمة المفتاحية `struct`، متبوعةً باسم النوع، ثم الأقواس المعقوفة التي تحتوي على تعريفها.
بحسب اصطلاح Swift، تُكتب أسماء البنى بنمط `UpperCamelCase`:

```swift
struct CharacterStats {
    var health = 0.0
    var speed = 0
    var strength = 0
}
```

## إنشاء النسخ

تعريف البنية هو مخطط.
ولإنشاء *نسخة* من بنية، استدعِ مُهيّئها بكتابة اسم النوع متبوعًا بالأقواس الهلالية:

```swift
var someStats = CharacterStats()
```

يُنشئ هذا نسخة معبّأة بقيم الخصائص الافتراضية من التعريف.

كذلك يولّد Swift تلقائيًا **مُهيّئًا عُضويًا** للبنى، يتيح لك تهيئة الخصائص بالاسم:

```swift
let customStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

## الوصول إلى الخصائص وتعديلها

تصل إلى خصائص النسخة وتعدّلها باستخدام *الترميز النقطي*:

```swift
var stats = CharacterStats()

print(stats.health) // Prints 0.0

stats.health = 87.3
print(stats.health) // Prints 87.3
```

لأن البنى أنواع قيم، فإن تعديل خصائص نسخة يستلزم أن تكون النسخة نفسها معلنة بـ `var`.
وإذا كانت النسخة معلنة بـ `let`، أصبحت جميع خصائصها غير قابلة للتغيير.
