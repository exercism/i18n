# ملحق التعليمات

## الكلمات

عرّف توبل `cmplx` بخانتَي `real` و`imaginary`. تأتي دالتا الوصول إلى الخانتين `real>>` و`imaginary>>` تلقائيًا مع تعريف التوبل، وهما ما تستخدمه الاختبارات لقراءة المكوّنات.

- `<cmplx> ( real imag -- cmplx )`: لإنشاء عدد مركّب.
- `>cmplx ( pair -- cmplx )`: لبناء توبل `cmplx` من `{ real imaginary }`.
- `cmplx>pair ( cmplx -- pair )`: لإرجاع `{ real imaginary }`.
- `c+ ( a b -- c )`، `c- ( a b -- c )`، `c* ( a b -- c )`،
  `c/ ( a b -- c )`: عمليات حسابية على عددين مركّبين.
- `c-abs ( a -- |a| )`: القيمة المطلقة (عدد حقيقي).
- `c-conj ( a -- a* )`: المرافق المركّب.
- `c-exp ( z -- e^z )`: الدالة الأسية المركّبة.

لا تعمل الكلمات العامة `MATH:` في Factor (`+` و`-` و`*` و`/`) إلا مع التسلسل الهرمي الرياضي المدمج، لذا يستخدم هذا التمرين أسماء كلمات مخصّصة بدلًا من طرق على تلك الكلمات العامة.

الاختبارات الخاصة بالعمليات الحسابية التي تخلط الأعداد الحقيقية بالأعداد المركّبة مستبعدة، فكل عملية هنا تجري بين قيمتَي `cmplx`.
