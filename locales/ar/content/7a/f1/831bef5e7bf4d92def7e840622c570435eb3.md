# مقدمة

إن المصفوفة `list` في R مجموعة مرتبة من العناصر، وتختلف عن `vectors` في بضعة أوجه:

- يمكن أن تكون العناصر من أنواع مختلفة (مثل خلط `numeric` مع `character`).
- يمكن أن تكون العناصر بُنى معقدة (مثل المتجهات، ومصفوفات أخرى، وما إلى ذلك).
- توجد صيغة مختلفة قليلًا للوصول إلى العناصر.

المقارنات مع لغات أخرى ليست دقيقة.
تشبه المصفوفة `list` في R قاموس Python إلى حدٍّ ما، لكن المصفوفة مرتبة ويمكن الوصول إليها بفهرس رقمي.
وهي تشبه إلى حدٍّ ما البنية `struct` في C، إلا أن المصفوفة يمكن توسيعها بسهولة في وقت التشغيل.

## إنشاء المصفوفات

إعطاء الأسماء (التي يُطلق عليها غالبًا "وسوم") للعناصر أكثر شيوعًا مع المصفوفات منه مع المتجهات:

```R
list(x = 5.3, y = 4.2, color = "blue")
$x
#> [1] 5.3

$y
#> [1] 4.2

$color
#> [1] "blue"
```

لكن الوسوم اختيارية، وحينها ستستخدم R أرقام الفهارس فقط:

```R
list(5.3, 4.2, "blue")
#> [[1]]
#> [1] 5.3

#> [[2]]
#> [1] 4.2

#> [[3]]
#> [1] "blue"
```

## الوصول إلى عناصر المصفوفة

توجد ثلاث أساليب لفعل ذلك، كل منها مفيد في سياق مختلف.

### 1. باستخدام صيغة `$tag`

شائعة جدًا إذا كانت أسماء الوسوم معروفة مسبقًا.

```R
point <- list(x = 5.3, y = 4.2, color = "blue")
point$x
#> [1] 5.3
point$color
#> [1] "blue"
```

### 2. باستخدام صيغة `[[tag]]`

لهذه الصيغة ميزة أن اسم الوسم يمكن اختياره في وقت التشغيل.
لاحظ الأقواس المربعة المزدوجة.

```R
want <- "y"
point[[want]] # same as point$y
#> [1] 4.2
```

### 3. باستخدام فهرس الموضع

تعمل هذه الصيغة سواء كانت للمصفوفة وسوم أم لا.
ومرة أخرى، الأقواس المربعة مزدوجة.

```R
point[[3]] # same as point$color
#> [1] "blue"
```

## إضافة العناصر وحذفها

الأمر بسيط: الإسناد إلى عنصر سيعدّله إن كان موجودًا، أو سيُدرجه إن كان جديدًا.

```R
point$color <- "red"
point$trust <- TRUE
str(point)
#> List of 4
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
#>  $ trust: logi TRUE
```

للحذف، أسنِد `NULL` إلى العنصر غير المرغوب فيه.

```R
point$trust <- NULL
str(point)
#> List of 3
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
```
