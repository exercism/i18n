# الاختبارات

لتشغيل مجموعة الاختبارات:
```bash
tclsh exercise.test
```

## الاختبارات المتخطّاة

حل التمرين يعني جعل جميع اختباراته تنجح. افتراضيًا، لا يُنفَّذ عند تشغيل الاختبارات
إلا اختبار واحد (الأول). وهذا مقصود، فهو يتيح لك التركيز على جعل ذلك الاختبار
الواحد ينجح فقط. وبمجرد أن ينجح، يمكنك تفعيل الاختبار التالي بتعليق أمر
`skip` الذي يسبقه أو بحذفه.

أو، لتشغيل جميع الاختبارات بغض النظر عن حالة «التخطي» الخاصة بها:
```bash
RUN_ALL=1 tclsh exercise.test
```
