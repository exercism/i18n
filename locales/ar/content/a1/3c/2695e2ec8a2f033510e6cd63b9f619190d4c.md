# ملحق التعليمات

## مثال على المُدخلات

```j
  INPUTS=: 2 ; 1 0 0 1 0 1 ; 10
```

هذا يعني أن مُدخلاتك هي:
```
  0{INPUTS NB. is the input base.
  1{INPUTS NB. is the digits.
  2{INPUTS NB. is the output base.
```
## التعامل مع المُدخلات غير الصالحة

إذا كانت أي من قيم المُدخلات غير صالحة، فيجب أن يُرجع `verb` الخاص بك إما `empty` (مثل `0$0` أو `''`).

### أمثلة

- إذا كان _أساس الإدخال_ أصغر من 2:
    ```j
      '' -: rebase 10 ; 0 0 0 0 ; 1
    ```

- إذا كان _أساس الإخراج_ أصغر من 2:
    ```j
      '' -: rebase 1 ; 0 0 0 0 ; _7
    ```

- إذا كانت _الأرقام_ تحتوي على قيم أكبر من أساس الإدخال أو مساوية له:
    ```j
      '' -: rebase 10 ; 1 0 2 0 ; 2
    ```
