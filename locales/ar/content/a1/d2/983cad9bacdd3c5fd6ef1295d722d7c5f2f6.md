# مقدمة

## تعريف المتغيرات

تعريف المتغير يعني إسناد قيمة إلى اسم. في Scala يوجد نوعان من المتغيرات، `val` و `var`.

`val` غير قابل للتغيير، لذا لا يمكن تغيير قيمته بعد الإسناد الأول:

```scala
val numberTen = 10

numberTen = 11
// --> raises a compile error "reassignment to val"
```

أما `var`، فيمكن إعادة إسناده إلى قيمة جديدة من النوع نفسه:

```scala
var someNumber = 10

someNumber = 11
// now someNumber has been reassigned
```

Scala لغة ذات أنواع ثابتة، وهو ما يعني أن لكل شيء نوعًا في وقت التصريف. ويمكن تعريف المتغير إما بتحديد نوعه صراحةً، أو بترك مُصرِّف Scala يستنتج نوعه انطلاقًا من القيمة المُسندة إليه (وهذا ما يُعرف باستنتاج النوع). لذلك فإن تعريفَي المتغيرين التاليين متكافئان:

```scala
val explicitNumber: Int = 10; // Explicitly typed
val implicitNumber = 10; // Implicitly typed
```

بعد تعريفه، لا يمكن أن يتغير نوع المتغير أبدًا.

```scala
var count = 1; // Assigning an initial value of type Int
count = 2;     // Updating to new value is possible, because it is defined as var

count = false;
// --> raises a compile error "type mismatch"
```

## تعريف الطرق داخل الأصناف

Scala لغة _كائنية التوجه_، وتشترط تعريف جميع الطرق داخل _صنف_. وتُستخدم الكلمة المفتاحية `class` لتعريف صنف.

```scala
class Calculator {
  // ...
}
```

داخل الصنف، يمكن تعريف الطرق بدءًا بالكلمة المفتاحية `def` متبوعة باسم. ويمكن أن تحتوي كل طريقة على صفر أو أكثر من المعاملات، تُسرد مفصولة بفواصل داخل الأقواس الهلالية. ويجب تحديد نوع جميع المعاملات صراحةً، فلا يوجد استنتاج للنوع في المعاملات. وبعد قائمة المعاملات يُحدَّد نوع الإرجاع للطريقة، مفصولًا بنقطتين إضافيتين.

ويتبع تعريف الطريقة علامة `=` التي تبدأ جسم الطريقة. في المثال التالي يتكوّن جسم الطريقة من عبارتين محاطتين بأقواس معقوفة.

ستُرجع الطريقة قيمة آخر تعبير، وفي هذه الحالة تُرجع طريقة `add` قيمة المتغير `sum`:

```scala
class Calculator {
  // long form
  def add(x: Int, y: Int): Int = {
    val sum = x + y
    sum
  }
}
```

هناك بعض التحسينات التي يمكن إجراؤها لاختصار هذه الطريقة بهدف تحسين قابليتها للقراءة:

- بما أن المتغير `sum` لا يُستخدَم إلا مرة واحدة لإرجاع القيمة، فيمكن حذفه
- الطرق التي تتكوّن من عبارة واحدة فقط لا تحتاج إلى أقواس معقوفة
- يمكن استنتاج نوع الإرجاع للطريقة تمامًا كما هو الحال في أنواع المتغيرات

وهذا يؤدي إلى الطريقة التالية المكوّنة من سطر واحد وبالوظيفة نفسها:

```scala
class Calculator {
  // shortened form
  def add(x: Int, y: Int) = x + y
}
```

## إنشاء نُسخ من الأصناف واستدعاء الطرق

يتم استدعاء طريقة عبر إنشاء نسخة من صنف أولًا، ثم استدعاء الطريقة على تلك النسخة مع الوسائط:

```scala
val calculator = new Calculator()
val sum = calculator.add(5, 7)
// sum is of type Int with assigned value of 12
```
