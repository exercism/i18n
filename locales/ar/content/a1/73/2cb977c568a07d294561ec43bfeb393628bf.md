# الاختبارات

## تشغيل الاختبارات

نفّذ مواصفات الاختبار بالأمر التالي:

```bash
$ gradle test
```

## تفعيل اختبارات إضافية

بعد أن يجتاز كودك جميع الاختبارات المفعّلة، فعّل اختبارًا آخر بإزالة `@Ignore` الذي يسبق الاختبار التالي الذي يهمّك. افعل ذلك بحذف سطر `@Ignore` أو بتحويله إلى تعليق بإضافة شرطتين مائلتين إلى بداية السطر.

```Groovy
//@Ignore
def 'outputs "Hello, Alice!" when given the name "Alice"'() {
    expect: hello.hello('Alice') == 'Hello, Alice!'
}
```
