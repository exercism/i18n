# الاختبارات

نستخدم [PonyTest](https://stdlib.ponylang.io/pony_test--index/) من المكتبة القياسية لكتابة الاختبارات التي تختبر بها حلّك. ولاختبار حلّك، ترجم كودك وشغّله.

على سبيل المثال، قد تبدو جلستك مع "Hello World" هكذا:

```text
[red@apophenia:~/exercism/pony/hello-world]$ ponyc
Generating
 Reachability
 Selector painting
 Data prototypes
 Data types
 Function prototypes
 Functions
 Descriptors
Optimising
Writing ./hello-world.o
Linking ./hello-world

[red@apophenia:~/exercism/pony/hello-world]$ ./hello-world 
1 test started, 0 complete: hello-world/HelloWorld started
1 test started, 1 complete: hello-world/HelloWorld complete
---- Passed: hello-world/HelloWorld
----
---- 1 test ran.
---- Passed: 1
```
