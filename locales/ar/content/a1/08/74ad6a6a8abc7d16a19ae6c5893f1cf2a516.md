# ملحق التعليمات

استبدل سلسلة رقم الهاتف المقدَّمة.
إذا كان رقم الهاتف غير صالح، فاستبدله بسلسلة نصية فارغة.

## السجلات

| السجل | الاستخدام        | النوع    | الوصف                            |
| -------- | ------------ | ------- | -------------------------------------- |
| `$a0`    | إدخال/إخراج | عنوان | رقم الهاتف كسلسلة نصية منتهية بـ `null` |
| `$t0-9`  | مؤقت    | أي     | يُستخدم للتخزين المؤقت             |
