# مقدمة

الصف حاوية مرتّبة من القيم. ومثل جميع أنواع البيانات في Gleam، فإن الصفوف غير قابلة للتغيير. ويمكن أن يكون كل عنصر من عناصر الصف من نوع مختلف، بل يمكن أن تكون العناصر نفسها صفوفًا أخرى.

يُعرَّف الصف على أنه قيم مفصولة بفواصل بين `#(` و`)`: `#(1, 2.0, "Three")`.

```gleam
#("one", 2)      // Tuple pair (2 values)
#("one", 2, 3.0) // Tuple triplet (3 values)
```

يمكن مقارنة الصفوف التي لها الطول نفسه والأنواع نفسها (وبالترتيب نفسه) للتحقق من تساويها.

```gleam
#(1, 2) == #(1, 2) // Same length, same types, same values, same order
// -> True

#(1, 2) == #(2, 1) // Same length, same types, same values, different order
// -> False

#(1, 2) == #(1, "2") // Same length, different types
// Compile error!

#(1, 2) == #(1, 2, 3) // Different length
// Compile error!
```

هناك ثلاثة أساليب لاستخراج القيم الموجودة داخل الصف:

- الفهرسة.
- مطابقة الأنماط باستخدام `let`.
- مطابقة الأنماط باستخدام `case`.

```gleam
let person = #("Jordan", 170)

// Option 1: Indexing
person.0 // -> "Jordan"
person.1 // -> 170

// Option 2: let
let #(name2, length2) = person
// -> name2 = "Jordan"
// -> length2 = 52

// Option 3: case
case person {
  #(name3, length3) -> {
    name3   // -> "Jordan"
    length3 // -> 170
  }
}
```
