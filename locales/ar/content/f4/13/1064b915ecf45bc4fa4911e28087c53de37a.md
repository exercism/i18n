# مقدمة

*الصف* هو نوع السجل/البنية/الصنف في Factor. ولكل صف مجموعة ثابتة من الخانات المسماة، وتولّد Factor تلقائيًا لها دوال الجلب والإسناد.

```factor
TUPLE: point
    { x initial: 0 }
    { y initial: 0 } ;

T{ point { x 3 } { y 4 } } x>> .   ! => 3
3 4 point boa .                    ! => T{ point { x 3 } { y 4 } }
point new .                        ! => T{ point }
```

‏`boa` (اختصار «by order of arguments»، أي بترتيب الوسائط) يملأ الخانات من المكدس بترتيب الإعلان. أما `new` فيبني نسخة تأخذ فيها كل خانة قيمتها المعلنة في `initial:` (أو `f` إن لم تكن لها قيمة).

دالة الجلب لكل خانة هي `slot>>` ودالة الإسناد هي `>>slot`، ودالة الإسناد *تعدّل* الكائن في مكانه، فاستخدم `clone` أولًا إن احتجت إلى تحديث لا يغيّر الكائن الأصلي:

```factor
T{ point { x 3 } { y 4 } } clone 10 >>x .
! => T{ point { x 10 } { y 4 } }
```

تستخدم القيم الافتراضية للخانات الصيغة `{ name initial: value }`؛ ومن دون `initial:` تكون القيمة الافتراضية `f`.
