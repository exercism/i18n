# التفكيك

التفكيك هو عملية تجزئة عنصر ما إلى مكوّناته الأساسية، وربط كل مكوّن بمتغيّر أصغر.

## تفكيك الصفوف

تفكيك الصفوف بسيط: ما عليك سوى إسناد أسماء متغيرات جديدة إلى كل حقل من حقول الصف:

```rust
let (first, second) = (1, 2);
```

## تفكيك بنى الصفوف

تفكيك بنى الصفوف مطابق لتفكيك الصفوف، لكن مع إضافة اسم البنية:

```rust
struct TupleStruct(&'static str, i32);
let my_tuple_struct = TupleStruct("foo", 123);
let TupleStruct(foo, num) = my_tuple_struct;
```

## تفكيك البنى

تفكيك البنى يشبه تفكيك بنى الصفوف. استخدم أسماء الحقول فحسب:

```rust
struct ArabianNights {
    name: String,
    stories: usize,
}
let teller = ArabianNights { name: "Scheherazade".into(), stories: 1001 };
{
    let ArabianNights { name, stories } = teller;
    println!("{name} told {stories} stories");
}
```

## التفكيك الجزئي

يمكن استخدام العامل `..` لتجاهل بعض الحقول عند التفكيك:

```rust
let ArabianNights { name, .. } = teller;
println!("{name} survived by her wits");
```

## التفكيك الشرطي

تفكيك البنى والصفوف لا يمكن أن يفشل. ومع ذلك، يمكن أيضًا تفكيك التعدادات، باستخدام تراكيب اللغة `if let` و`while let` و`match`.

```rust
if let Some(foo) = foo {
    println!("{foo:?}");
}
```
