# تعلّم Visual Basic

## مواقع الويب

تطورت Visual Basic بشكل كبير على مر السنين، وتشير العديد من الدروس التي تقدمها جهات خارجية إلى أدوات أو ميزات قديمة.
إن [توثيق Visual Basic الرسمي](https://learn.microsoft.com/en-us/dotnet/visual-basic/) هو المكان الأحدث والأكثر موثوقية لبدء رحلتك.

## منظومة .NET

تعمل Visual Basic على وقت تشغيل .NET، وتتشارك الكثير من الوظائف الأساسية مع C# وF#.
لذلك، فإن فهم كيفية عمل .NET سيجعلك مطور VB أقوى.

- [معجم .NET](https://learn.microsoft.com/en-us/dotnet/standard/glossary)
- [نظام الأنواع المشترك (CTS)](https://learn.microsoft.com/en-us/dotnet/standard/base-types/common-type-system)
