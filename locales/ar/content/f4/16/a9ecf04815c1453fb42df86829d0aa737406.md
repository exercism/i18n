# ملحق التعليمات

## صيغة الإخراج

أخرِج سلسلة نصية منتهية بمحرف فارغ، واستخدم فاصلة ومسافة للفصل بين العناصر.

ومن الأمثلة على الإخراج `"491, 914, 142"`.

إذا كانت المدخلات غير صالحة، أخرِج سلسلة نصية فارغة.

## السجلات

| السجل    | الاستخدام        | النوع   | الوصف                          |
| -------- | ---------------- | ------- | ------------------------------ |
| `$a0`    | إدخال            | عنوان   | سلسلة نصية منتهية بمحرف فارغ   |
| `$a1`    | إدخال            | عدد صحيح | طول المقطع                     |
| `$a2`    | إدخال/إخراج      | عنوان   | سلسلة نصية منتهية بمحرف فارغ   |
| `$t0-9`  | مؤقت             | أي      | يُستخدم للتخزين المؤقت          |
