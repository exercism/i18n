# مقدمة

تتشارك المصفوفات الترابطية في Factor، أي جداول التجزئة وما شابهها، في [بروتوكول][assoc-protocol] مشترك من [`assocs`][assocs]. الصيغة الحرفية لجدول التجزئة هي `H{ }`:

```factor
H{ { "coal" 1 } { "wood" 2 } } .

"coal" H{ { "coal" 1 } { "wood" 2 } } at .   ! => 1
"gold" H{ { "coal" 1 } { "wood" 2 } } at .   ! => f
```

العمليات الشائعة:

```
at        ( key assoc -- value/f )
key?      ( key assoc -- ? )
set-at    ( value key assoc -- )
delete-at ( key assoc -- )
inc-at    ( key assoc -- )
change-at ( key assoc quot -- )
keys      ( assoc -- keys )
values    ( assoc -- values )
>alist    ( assoc -- alist )
```

جداول التجزئة *قابلة للتغيير*، فاستخدم `clone` على الصيغة الحرفية `H{ }` قبل تعديلها، حتى لا تصبح الصيغة الحرفية مشتركة بين الاستدعاءات.

[assocs]: https://docs.factorcode.org/content/vocab-assocs.html
[assoc-protocol]: https://docs.factorcode.org/content/article-assocs-protocol.html
