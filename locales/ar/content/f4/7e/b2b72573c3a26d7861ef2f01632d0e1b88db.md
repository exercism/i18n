# التعليمات

لا يصعد أحد إلى الأرجوحة في السيرك قبل أن تنجح فحوصات السلامة.
أنت تدوّن هذه الفحوصات حتى تنطبق القواعد نفسها على الجميع.

تقع المهام الخمس كلها في الصنف `SAFETY_CHECK`.

## 1. هل السجادة جاهزة؟

لا تكون السجادة جاهزة إلا عندما تكون مفروشة ونظيفة في الوقت نفسه.

```sather
SAFETY_CHECK::mat_ready(true, false)
-- => false
```

## 2. هل يوجد شيء للهبوط عليه؟

يجب أن تكون هناك سجادة في الأسفل، أو شبكة في الأسفل. أيّهما يكفي، ووجودهما معًا لا بأس به.

```sather
SAFETY_CHECK::something_below(false, true)
-- => true
```

## 3. من لا يزال يحتاج إلى الإحاطة؟

كل من لم يتلقَّ الإحاطة يحتاج إليها.

```sather
SAFETY_CHECK::needs_briefing(false)
-- => true
```

## 4. هل عمر هذا المؤدّي كافٍ؟

الأرجوحة مخصّصة للمؤدّين من عمر 13 فما فوق.

```sather
SAFETY_CHECK::old_enough(13)
-- => true
```

## 5. لنجمع كل شيء معًا

يُصرَّح للمؤدّي بالأرجوحة عندما يكون عمره كافيًا، ويكون قد تلقّى الإحاطة، وتكون السجادة جاهزة.

```sather
SAFETY_CHECK::cleared(14, true, true, true)
-- => true
```

الوسائط الأربعة هي العمر، وما إذا كان قد تلقّى الإحاطة، وما إذا كانت السجادة مفروشة، وما إذا كانت السجادة نظيفة.
