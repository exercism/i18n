# التعليمات

أنت تعمل على نظام لتبسيط عملية تسجيل الدخول إلى شبكة مؤسستك. وتتعلق المهام بجزء المصادقة. ويستخدم النظام التعرّف على الوجه لإثبات الهوية.

في جميع الحالات، يُضمن أن معامل لون العين غير `null`.

## 1. تأكد من تطابق ملامح الوجه

نفّذ `Authenticator.AreSameFace()` للتحقق من تطابق وجهين.

أضف إجراءات المساواة إلى الصنف `FacialFeatures`.

```csharp
Authenticator.AreSameFace(new FacialFeatures("green", 0.9m), new FacialFeatures("green", 0.9m);
// => true
Authenticator.AreSameFace(new FacialFeatures("blue", 0.9m), new FacialFeatures("green", 0.9m);
// => false
```

## 2. صادق على مدير النظام

رغم اعتراضاتك، يصرّ مدير النظام على أن تكون لديه هوية مدمجة أثناء اختبارات القبول حتى يمكن المصادقة عليه دائمًا.

البريد الإلكتروني لمدير النظام هو admin@exerc.ism. ولديه عينان خضراوان ونثرة بعرض 0.9.

أضف إجراءات المساواة إلى الصنف `Identity`.

نفّذ الطريقة `Authenticator.IsAdmin()` للتحقق من أن الهوية المُمرَّرة تطابق هوية مدير النظام.

```csharp
var authenticator = new Authenticator();
authenticator.IsAdmin(new Identity("admin@exerc.ism", new FacialFeatures("green", 0.9m)));
// => true
authenticator.IsAdmin(new Identity("admin@thecompetition.com", new FacialFeatures("green", 0.9m)));
// => false
```

## 3. سجّل هويات جديدة

نفّذ الطريقة `Authenticator.Register()` التي تخزّن هوية في كائن المصادقة نفسه، بحيث تُرجع الاستدعاءات إلى `IsRegistered()` القيمة `true` لهذه الهوية، وإلا فستُرجع `IsRegistered()` القيمة `false`.

ولكشف المحاولات المكررة لتسجيل هوية، إذا كانت الهوية قد سُجّلت بالفعل فستُرجع `Authenticator.Register()` القيمة `false`، وإلا فستُرجع `true`.

```csharp
var authenticator = new Authenticator();
authenticator.Register(new Identity("tunde@thecompetition.com", new FacialFeatures("blue", 0.9m)));
// => true
authenticator.IsRegistered(new Identity("tunde@thecompetition.com", new FacialFeatures("blue", 0.9m)));
// => true
authenticator.Register(new Identity("tunde@thecompetition.com", new FacialFeatures("blue", 0.9m)));
// => false
```

## 4. امنع المصادقة على الهويات غير الصالحة

نفّذ الطريقة `Authenticator.IsRegistered()` وتأكد من أنها تُرجع `false` عندما لم تُسجَّل أي هويات.

```csharp
var authenticator = new Authenticator();
authenticator.IsRegistered(new Identity("alice@thecompetition.com", new FacialFeatures("blue", 0.8m)));
// => false
```

## 5. أضف تشخيصات لكشف محاولات المصادقة المتعددة

أُبلغ عن bug يتمثل في استدعاء الطريقة `Authenticator.IsRegistered()` عدة مرات متتالية بسرعة للهوية نفسها. وتعتقد أن هناك مشكلة ما من نوع "ارتداد"، حيث يُرسَل السجل نفسه عدة مرات. ومهمتك هي إضافة إجراء تشخيصي `Authenticator.AreSameObject()` لدعم أي اختبار يُجرى. ويقارن الإجراء كائنين ويُرجع `true` إذا كانا المثيل نفسه بالضبط، وإلا فيُرجع `false`.

```csharp
var identityA = new Identity("alice@thecompetition.com", new FacialFeatures("blue", 0.9m));
var identityB = identityA;
Authenticator.AreSameObject(identityA, identityB);
// => true

var identityC = new Identity("alice@thecompetition.com", new FacialFeatures("blue", 0.9m));
var identityD = new Identity("alice@thecompetition.com", new FacialFeatures("blue", 0.9m));
Authenticator.AreSameObject(identityC, identityD);
// => false
```
