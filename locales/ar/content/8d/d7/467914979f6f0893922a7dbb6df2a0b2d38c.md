# نبذة

Haxe لغة ذات أنواع صارمة، لكن يمكن التحايل على نظام الأنواع عند الحاجة. إسناد قيمة إلى اسم يُسمّى تعريف متغير. ويمكن تعريف المتغير إما بتحديد نوعه صراحةً، أو بترك مُصرِّف Haxe يستنتج النوع باستخدام [الكلمة المفتاحية `var`](var). لذلك فإن تعريفي المتغيرين التاليين متكافئان:

```haxe
var explicitVariable:Int = 10; // Explicitly typed
var implicitVariable = 10; // Implicit typed
```

يمكن تحديث المتغير باستخدام العامل `=`:

```haxe
var number = 0; // Initial value
number = 1; // Updated value
```

سيُصدر المصرِّف خطأً عند محاولة إسناد قيمة يختلف نوعها عن نوع المتغير:

```haxe
var number = 1; // Variable number is of integer type
number = "Hello" // Error trying to assign a string to an integer variable
```

في Haxe، يُكتب الكود عادةً داخل _دالة_، تُسمّى أيضًا [_طريقة_](method). ويمكن لهذه الدوال أن تأخذ معاملات (وسائط)، وأن تُرجع قيمًا باستخدام الكلمة المفتاحية `return`. وتُستدعى الدوال باستخدام صيغة `()`. ويجب أن يكون لكل دالة نوع إرجاع.

```haxe
function add(x:Int, y:Int):Int {
  return x + y;
}
```

يُحدَّد النطاق في Haxe بين المحرفين `{` و`}`.

يدعم Haxe نوعين من التعليقات. التعليقات أحادية السطر تسبقها `//`، أما التعليقات متعددة الأسطر فتُوضع بين `/*` و`*/`.
