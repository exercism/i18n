# التعليمات

في هذا التمرين ستلعب بسيارة يتم التحكم فيها عن بُعد، وقد ادّخرت أخيرًا ما يكفي من المال لشرائها.

تبدأ السيارات ببطارية ممتلئة بالكامل (100%). في كل مرة تقود السيارة باستخدام جهاز التحكم عن بُعد، تقطع 20 مترًا وتستهلك واحدًا بالمئة من البطارية. ولا يُعرف لقب السيارة إلا عند إنشائها.

تحتوي السيارة التي يتم التحكم فيها عن بُعد على شاشة LED أنيقة تعرض معلومتين:

- المسافة الإجمالية التي قطعتها، معروضة على النحو التالي: `"<METERS> meters"`.
- شحن البطارية المتبقي، معروض على النحو التالي: `"Battery at <PERCENTAGE>%"`.

إذا كانت البطارية عند 0%، فلن تتمكن من قيادة السيارة بعد الآن، وستعرض شاشة البطارية `"Battery empty"`.

## 1. إنشاء سيارة جديدة تمامًا يتم التحكم فيها عن بُعد

نفّذ الدالة `RemoteControlCar.new/0` بحيث تُرجع `struct` سيارة جديدة تمامًا يتم التحكم فيها عن بُعد:

```elixir
RemoteControlCar.new()
# => %RemoteControlCar{
#      battery_percentage: 100,
#      distance_driven_in_meters: 0,
#      nickname: "none"
#    }
```

اللقب مطلوب في `struct`، فتأكد من تهيئة قيمة له في الدالة `new`، وليس في `struct`.

## 2. إنشاء سيارة جديدة تمامًا يتم التحكم فيها عن بُعد مع لقب

نفّذ الدالة `RemoteControlCar.new/1` بحيث تُرجع `struct` سيارة جديدة تمامًا يتم التحكم فيها عن بُعد مع لقب مُحدَّد:

```elixir
RemoteControlCar.new("Blue")
# => %RemoteControlCar{
#      battery_percentage: 100,
#      distance_driven_in_meters: 0,
#      nickname: "Blue"
#    }
```

## 3. عرض المسافة

نفّذ الدالة `RemoteControlCar.display_distance/1` لإرجاع المسافة كما تُعرض على شاشة LED:

```elixir
car = RemoteControlCar.new()
RemoteControlCar.display_distance(car)
# => "0 meters"
```

تأكد من أن الدالة لا تقبل سوى `struct` من نوع `RemoteControlCar` كوسيط.

## 4. عرض نسبة شحن البطارية

نفّذ الدالة `RemoteControlCar.display_battery/1` لإرجاع نسبة شحن البطارية كما تُعرض على شاشة LED:

```elixir
car = RemoteControlCar.new()
RemoteControlCar.display_battery(car)
# => "Battery at 100%"
```

تأكد من أن الدالة لا تقبل سوى `struct` من نوع `RemoteControlCar` كوسيط. وإذا كانت البطارية عند 0%، فستعرض شاشة البطارية "Battery empty".

## 5. القيادة تغيّر البطارية والمسافة المقطوعة

نفّذ الدالة `RemoteControlCar.drive/1` التي:

- تزيد عدد الأمتار المقطوعة بمقدار 20
- تستهلك 1% من البطارية

```elixir
RemoteControlCar.new("Red")
|> RemoteControlCar.drive()

# => %RemoteControlCar{
#      battery_percentage: 99,
#      distance_driven_in_meters: 20,
#      nickname: "Red"
#    }
```

تأكد من أن الدالة لا تقبل سوى `struct` من نوع `RemoteControlCar` كوسيط.

## 6. مراعاة القيادة ببطارية فارغة

حدّث الدالة `RemoteControlCar.drive/1` بحيث لا تزيد المسافة المقطوعة ولا تنقص نسبة شحن البطارية عندما تكون البطارية فارغة (عند 0%):

```elixir
%RemoteControlCar{
  battery_percentage: 0,
  distance_driven_in_meters: 1980,
  nickname: "Red"
}
|> RemoteControlCar.drive()

# => %RemoteControlCar{
#      battery_percentage: 0,
#      distance_driven_in_meters: 1980,
#      nickname: "Red"
#    }
```
