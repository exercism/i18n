# التعليمات

أنت وأصدقاؤك تحبّون لعب ألعاب تقمّص الأدوار بالقلم والورق، لكنك لاحظت أن جذب أشخاص جدد للانضمام إلى مجموعتك أمر صعب. فهم غالبًا ما يجدون صعوبة في إنشاء الشخصيات، ولا يعرفون من أين يبدأون. ولمساعدتهم، قرّرت كتابة برنامج صغير يرشد اللاعبين الجدد خلال هذه العملية.

## 1. رحّب باللاعب الجديد

نفّذ الدالة `RPG.CharacterSheet.welcome/0`. ينبغي لها أن تطبع رسالة ترحيب، وأن تُرجع `:ok`.

```elixir
RPG.CharacterSheet.welcome()
# > Welcome! Let's fill out your character sheet together.
# => :ok
```

## 2. اطلب اسم الشخصية

نفّذ الدالة `RPG.CharacterSheet.ask_name/0`. ينبغي لها أن تطبع سؤالًا، وتنتظر إجابة، وأن تُرجع الإجابة دون مسافات بيضاء في البداية أو النهاية.

```elixir
RPG.CharacterSheet.ask_name()
# > What is your character's name?
# < Mathilde
# => "Mathilde"
```

## 3. اطلب صنف الشخصية

نفّذ الدالة `RPG.CharacterSheet.ask_class/0`. ينبغي لها أن تطبع سؤالًا، وتنتظر إجابة، وأن تُرجع الإجابة دون مسافات بيضاء في البداية أو النهاية.

```elixir
RPG.CharacterSheet.ask_class()
# > What is your character's class?
# < healer
# => "healer"
```

## 4. اطلب مستوى الشخصية

نفّذ الدالة `RPG.CharacterSheet.ask_level/0`. ينبغي لها أن تطبع سؤالًا، وتنتظر إجابة، وأن تُرجع الإجابة كعدد صحيح.

```elixir
RPG.CharacterSheet.ask_level()
# > What is your character's level?
# < 2
# => 2
```

## 5. اجمع الخطوات السابقة في خطوة واحدة

نفّذ الدالة `RPG.CharacterSheet.run/0`. ينبغي لها أن ترحّب باللاعب الجديد، وتطلب اسم الشخصية وصنفها ومستواها، وأن تُرجع ورقة الشخصية كخريطة. وينبغي لها أيضًا أن تطبع الخريطة مع التسمية "Your character".

```elixir
RPG.CharacterSheet.run()
# > Welcome! Let's fill out your character sheet together.
# > What is your character's name?
# < Mathilde
# > What is your character's class?
# < healer
# > What is your character's level?
# < 2
# > Your character: %{class: "healer", level: 2, name: "Mathilde"}
# => %{class: "healer", level: 2, name: "Mathilde"}
```
