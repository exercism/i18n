# مقدمة

## الأخطاء

تكون الأخطاء مفيدة للإبلاغ عندما يكون هناك خطأ ما أو شيء غير متوقع في برنامج أو في جزء من الكود.

وهي كائنات JavaScript.

الخاصية الرئيسية في هذا الكائن هي `message`:

```javascript
const error = new Error('Oops, something went wrong');

console.log(error.message);
// => "Oops, something went wrong"
```

باستخدام صيغة `throw`، يمكنك إطلاق خطأ.

```javascript
throw new Error('Oops');
```

عند إطلاق خطأ، يتوقف التنفيذ الحالي ويُستأنف في أول كتلة `catch` من مكدس الاستدعاءات.

```javascript
try {
  throw new Error('Oops');
} catch (error) {
  console.log(error.message);
  // => "Oops"
}
```

## الوراثة

الوراثة أسلوب لإنشاء علاقات من نوع الأصل والفرع بين الأصناف.
الصنف الابن (ويُشار إليه أحيانًا باسم _الصنف الفرعي_) يمكنه الوصول إلى السلوك والبيانات التي يعرّفها الصنف الأب (ويُشار إليه أحيانًا باسم _الصنف الأعلى_).

```javascript
class Pet {
  constructor(name) {
    this.name = name;
  }

  introduce() {
    console.log(`This is my pet, ${this.name}.`);
  }
}

class Dog extends Pet {}

const dog = new Dog('Otis');
dog.introduce();
// => This is my pet, Otis.
```

الكلمة المفتاحية `extends` في تعريف الصنف الابن تُنشئ علاقة مع الصنف الأب عبر [سلسلة `prototype`][prototype-chain].

الكائنات التي يُنشئها منشئ الصنف الابن تحتوي على `prototype` الخاص بالصنف الأب ضمن سلسلة `prototype` الخاصة بها، ما يتيح الوصول إلى أي طُرق أو بيانات يعرّفها الصنف الأب.

```javascript
const dog = new Dog('Otis');

Dog.prototype.isPrototypeOf(dog); // => true
Pet.prototype.isPrototypeOf(dog); // => true
Pet.prototype.isPrototypeOf(Dog.prototype); // => true

Pet.prototype.hasOwnProperty('introduce'); // => true
Dog.prototype.hasOwnProperty('introduce'); // => false
dog.hasOwnProperty('introduce'); // => false
```

وكما هو الحال مع أي صنف في JavaScript، يمكن للأصناف الفرعية أن ترث من `Error` لإنشاء أخطاء مخصصة باستخدام الكلمة المفتاحية `extends`.
تتحقق صيغة `instanceof` مما إذا كان الخطأ الذي تم التقاطه نسخة من صنف فرعي معيّن من `Error`.

```javascript
class CustomError extends Error {}

try {
  // ... Code that may throw an error
} catch (error) {
  if (error instanceof CustomError) {
    console.log('The error thrown is an instance of the CustomError');
  }
}
```

[prototype-chain]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Inheritance_and_the_prototype_chain
