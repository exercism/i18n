# نبذة

توفّر Swift نوعًا مدمجًا يُسمّى [`Bool`][bools] لتمثيل القيم المنطقية: `true` و `false`.

## العوامل المنطقية

توفّر Swift ثلاثة [عوامل منطقية][logical-operators] (`!` و `&&` و `||`) لدمج التعبيرات المنطقية وتقييمها.

### العامل المنطقي AND (`&&`)

لا يُرجع العامل [AND][and] (`&&`) القيمة `true` إلا إذا كان كلا الطرفين `true`.
وإذا كان أحد الطرفين `false`، فإنه يُرجع `false`.
ضع تعبيرًا أو قيمة منطقية على كل من جانبي الرمز `&&`:

```swift
true && true  // true
true && false // false
```

### العامل المنطقي OR (`||`)

يُرجع العامل [OR][or] (`||`) القيمة `true` إذا كان **أحد الطرفين على الأقل** `true`.
ويُرجع `false` فقط عندما يكون الطرفان `false`.
ضع تعبيرًا أو قيمة منطقية على كل من جانبي الرمز `||`:

```swift
true || true   // true
true || false  // true
false || false // false
```

### العامل المنطقي NOT (`!`)

يعكس العامل [NOT][not] (`!`) قيمة منطقية.
فهو يُرجع `true` إذا كانت القيمة `false`، و`false` إذا كانت القيمة `true`.
ضع العامل `!` مباشرةً قبل القيمة أو التعبير:

```swift
!true  // false
!false // true
```

## استخدام الأقواس الهلالية (`()`)

يمكنك استخدام [الأقواس الهلالية][explicit-parentheses] لتجميع التعبيرات والتحكم في ترتيب التقييم.
في Swift، تُقيَّم التعبيرات الموجودة داخل الأقواس الهلالية أولًا:

```swift
true && false && false || true   // true
true && false && (false || true) // false
```

كما يحدد التجميع بالأقواس الهلالية كيفية تطبيق العامل NOT على التعبيرات المركبة:

```swift
!true && false   // false (evaluates (!true) first, then false && false)
!(true && false) // true  (evaluates (true && false) first to false, then !false)
```

~~~~exercism/note
استخدم الأقواس الهلالية عندما تحتاج إلى توضيح ترتيب التقييم أو إلى جعل الشروط المعقدة أسهل في القراءة.
وتجنّب إضافة أقواس هلالية غير ضرورية عندما تكون الأسبقية الافتراضية واضحة أصلًا.
~~~~
