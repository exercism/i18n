# التلاعب بالأنواع

قد يُعرف التلاعب بالأنواع أيضًا باسم إكراه الأنواع.
يحدث التلاعب بالأنواع عندما تُكرَه قيمتان من نوعين مختلفين على التحوّل إلى النوع نفسه لإجراء عملية.

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15
```

وقد يحدث هذا ضمنيًا (كما في المثال أعلاه)، أو صراحةً باستخدام صبّ الأنواع على طريقة `C`:

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

الأنواع المسموح بها في صبّ الأنواع اليدوي هي: `bool`، و`int`، و`float`، و`string`، و`array`، و`object`.
وفي الغالب، يُستخدم صبّ الأنواع لتغيير عدد صحيح (`int`) إلى عدد عشري (`float`) أو العكس.
