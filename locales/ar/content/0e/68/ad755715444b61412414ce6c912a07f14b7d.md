# مقدمة

تسمح العوامل الثلاثية بتعريف شروط `if` داخل التعبيرات بدلًا من كتل العبارات. وهذا يعكس أساليب البرمجة الوظيفية، وغالبًا ما يجعل الكود أكثر تعبيرًا وأقل عرضة للأخطاء.

يجمع العامل الثلاثي 3 تعبيرات: شرطًا يتبعه تعبير يُقيَّم ويُرجَع إذا كان الشرط صحيحًا (الجزء `if` الذي يبدأ بـ `?`) وتعبيرًا يُقيَّم ويُرجَع إذا كان الشرط خطأً (الجزء `else` الذي يبدأ بـ `:`).

```csharp
int a = 3, b = 4;
int max = a > b ? a : b;
// => 4
```
