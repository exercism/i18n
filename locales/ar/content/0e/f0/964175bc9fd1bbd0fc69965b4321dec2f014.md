# مقدمة

الخاصية في C# عضو في صنف يتيح الوصول إلى البيانات الموجودة داخل ذلك الصنف.
ويستطيع المستدعون ضبط هذه البيانات أو استرجاعها (`get`). وقد تكون الخصائص منفَّذة تلقائيًا
أو مدعومة بحقل داعم. وتتكوّن الخاصية من مُوصِّل ضبط و/أو مُوصِّل استرجاع.
وفي بعض اللغات الأخرى، تكاد «المُغيّر» تعادل مُوصِّل الضبط، وتكاد «المُوصِّل» تعادل
مُوصِّل الاسترجاع، وإن كانت بنية الصياغة مختلفة تمامًا.

عند ضبط خاصية يمكن التحقق من القيمة المُدخَلة أو تنسيقها
أو معالجتها بأي طريقة أخرى، بل يمكن في الواقع تنفيذ أي عملية برمجية متاحة للكود داخل
الصنف.

وبالمثل، عند استرجاع قيمة خاصية يمكن حساب البيانات أو تنسيقها، ومرة أخرى
يمكن تنفيذ أي عملية برمجية متاحة للصنف.

للخصائص مُعدِّلات وصول (`public` و`private` وغيرها) تمامًا كما لأعضاء الصنف
الآخرين، لكن قد يكون لمُوصِّل الضبط مستوى وصول مستقل عن مُوصِّل الاسترجاع (`get`)
والعكس صحيح. ولا يجب أن تحتوي الخاصية على المُوصِّلَين كليهما، بل يمكن أن يكون لها واحد فقط (إما `get` أو `set`).

تأخذ الصياغة الأساسية للتعبير عن الخصائص شكلين اثنين:

## الخصائص المدعومة بحقل أو بتعبير:

```csharp
private int myField;
public int MyProperty
{
    get { return myField; }
    set { myField = value; }
}
```

## الخصائص المنفَّذة تلقائيًا

```
public int MyProperty { get; private set; } = 42;
```
