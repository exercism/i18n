# مقدمة

مساحات الأسماء طريقة لتجميع الكود المرتبط ببعضه ولتجنب تعارض الأسماء، وهي موجودة عمومًا في كل قاعدة كود إلا أبسطها.

تكون الصيغة كما يلي:

```csharp
namespace MyNameSpace
{
    public class MyClass {}

    public class OtherClass {}
}
```

عند الإشارة إلى الأنواع الموجودة داخل مساحات الأسماء من خارج نطاق مساحة الأسماء، تُكتب مساحة الأسماء قبل اسم النوع متبوعة بنقطة. وبدلًا من ذلك، وهو الأكثر شيوعًا، يمكنك وضع توجيه `using` في أعلى الملف (أو داخل مساحة الأسماء)، ثم يمكن استخدام النوع دون كتابة البادئة. وداخل مساحة الأسماء نفسها، لا حاجة إلى كتابة بادئة قبل أسماء الأنواع.

```csharp
namespace MySpace
{
    public class MyClass {}

    public class Foo
    {
        public void Bar()
        {
            var baz = new MyClass();
        }
    }
}

public class Qux
{
    public void Box()
    {
        var nux = new MySpace.MyClass();
    }
}

namespace OtherSpace
{
    using MySpace;

    public class Tix
    {
        public void Jeg()
        {
            var lor = new MyClass();
        }
    }
}
```

يمكنك إنشاء اسم مستعار لمساحة الأسماء باستخدام الصيغة `using MyAlias = MySpace;`، ثم استخدام الاسم المستعار في أي مكان يمكن فيه استخدام مساحة الأسماء.
