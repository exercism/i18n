# مقدمة

يربط *tuple* عدة قيم مسمّاة معًا في كائن واحد، وهو ما تسميه لغات أخرى سجلًا أو بنيةً أو صنفًا. يمتلك كل صنف tuple مجموعة ثابتة من الخانات المسمّاة، ويولّد Factor تلقائيًا دوال قراءة ودوال كتابة لها.

## تعريف tuple

```factor
TUPLE: point
    { x initial: 0 }
    { y initial: 0 } ;
```

تُصرَّح كل خانة بالصيغة `{ name initial: default-value }`. وبدون بند `initial:` تكون القيمة الافتراضية `f`.

## إنشاء tuple

أبسط مُنشئ هو `new`:

```factor
point new .
! => T{ point }
```

أما `boa` (أي "حسب ترتيب الوسائط") فتملأ الخانات بترتيب التصريح انطلاقًا من مكدّس البيانات:

```factor
3 4 point boa .
! => T{ point { x 3 } { y 4 } }
```

تتيح لك الصيغة الحرفية `T{ class { slot value } … }` إنشاء tuple مع تحديد بعض الخانات فقط، وهي تُطبع بالطريقة نفسها:

```factor
T{ point { x 3 } } .
! => T{ point { x 3 } }
```

وعندما تطابق قيمة إحدى الخانات قيمتها الافتراضية، يحذفها الطابع.

## قراءة خانة

يولّد Factor دالة قراءة `slot>>` لكل خانة. توجد دوال القراءة في [`accessors`][accessors]:

```factor
T{ point { x 3 } { y 4 } } x>> .
! => 3
```

## تحديث خانة

تُكتب دوال الكتابة بالصيغة `>>slot` وهي *تعدّل* tuple في موضعه مباشرةً:

```factor
T{ point { x 3 } { y 4 } } 10 >>x .
! => T{ point { x 10 } { y 4 } }
```

ولكي تترك الأصل كما هو، استخدم `clone` أولًا:

```factor
: shifted ( pt -- pt' )
    clone 10 >>x ;
```

تأخذ `change-slot` اقتباسًا يحوّل القيمة الحالية إلى القيمة الجديدة:

```factor
: shift-x ( pt dx -- pt )
    [ + ] curry change-x ;
```

تُعدّل `change-x` هي أيضًا، لذا استخدم `clone` قبل استدعائها إذا أردت الحفاظ على الأصل.
