# مقدمة

يُستخدم `Map` لتخزين أزواج من **المفتاح** و**القيمة**. تُهيَّأ `Maps` تمامًا مثل مصفوفة، لكنها تستخدم عامل حرفية الخريطة `=>`. ويمكن أيضًا تعريف أنواع المفتاح والقيمة فيها صراحةً، أو يمكن استنتاج الأنواع. يجب أن تكون المفاتيح فريدة، وإلا فسيُطرح خطأ.

```haxe
var map1:Map<Int, String> = [1 => "one", 2 => "two", 3 => "three"];

var map2 = ["one" => 1, "two" => 2, "three" => 3];

var map3 = [1 => "cat", 1 => "dog"]; // Error: Duplicate Key

var map4 = ["h" => "Hello", "b" => "Bye"];
trace(map4["h"]); // Hello
```

يمكن اجتياز `Map` باستخدام حلقة `for`. يمكنك إما اجتياز القيم أو المفاتيح:

```haxe
for (value in map) {
  // ...
}

for (key in map.keys()) {
  // ...
}
```
