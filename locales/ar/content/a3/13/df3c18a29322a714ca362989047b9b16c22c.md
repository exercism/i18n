# الدوال

في JavaScript، الدوال هي _كائنات من الدرجة الأولى_، وهذا يعني أنه يمكن إسنادها إلى متغيرات وخصائص، وتمريرها إلى دوال أخرى، وإرجاعها من الدوال. ويمكن أن تكون لها خصائص وطرق، تمامًا مثل أي _كائن_ آخر.

## الإدخال: تمرير الوسائط

تسمح لك دوال JavaScript بتمرير الوسائط عند استدعائها. تُمرَّر الوسائط دائمًا [بالقيمة](https://dev.to/xpbytes/javascript-ruby-and-c-are-not-call-by-reference-23f7). بعبارة أخرى، إذا أعادت دالة إسناد قيمة إلى معامل داخلها، فلن تتغير القيمة خارج الدالة. لكن هذا لا يعني أنه لا يمكن تعديل الكائنات الممرَّرة.

> [!TIP]
> عند تمرير كائن، تُمرَّر الإشارة إلى هذا الكائن حسب القيمة. هذا يجعل الأمر _يبدو_ وكأن تمرير الكائنات يُعالَج بشكل مختلف، لكن هذا ليس هو الحال.

إليك مثالًا على دالة تأخذ وسيطين وتضربهما:

```javascript
function multiply(a, b) {
  return a * b;
}

multiply(2, 3);
// => 6
```

## الإخراج: القيمة المُرجَعة

يمكن لـ JavaScript إرجاع قيمة واحدة من دالة باستخدام الكلمة المفتاحية `return`، متبوعة بتعبير. وعندما لا تُرجِع الدالة أي قيمة، تكون القيمة المُرجَعة هي `undefined`.

إليك مثالًا على دالة تُرجع قيمة:

```javascript
function multiply(a, b) {
  return a * b;
}

multiply(2, 3);
// => 6
```

## تعريف الدوال

هناك أربعة أنواع من الدوال في JavaScript:

1. الدوال العادية التي يمكنها إرجاع أي شيء وتعمل دائمًا حتى تكتمل؛
2. الدوال غير المتزامنة التي تُرجع دائمًا كائن `Promise`، ويمكن إيقافها مؤقتًا واستئنافها باستخدام العامل `await`؛
3. الدوال المولِّدة: التي تُرجع دائمًا كائن `Generator`، ويمكن إيقافها مؤقتًا واستئنافها باستخدام العامل `yield`؛
4. الدوال المولِّدة غير المتزامنة؛ التي تُرجع دائمًا كائن `AsyncGenerator`، ويمكن إيقافها مؤقتًا واستئنافها باستخدام العامِلَين `yield` و`await` _معًا_.

ولكل نوع من هذه الأنواع الأربعة، هناك ثلاث أساليب لتعريفها:

1. باستخدام إعلان
2. باستخدام تعبير
3. باستخدام الدالة البانية

وأخيرًا، هناك بعض الصياغات الخاصة لتعريف _الدوال السهمية والطرق_.
