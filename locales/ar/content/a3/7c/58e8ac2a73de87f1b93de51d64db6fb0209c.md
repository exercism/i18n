# مقدمة

## السلاسل النصية

السلاسل النصية في Elixir تُحدَّد بعلامات التنصيص المزدوجة، وتُرمَّز بترميز UTF-8:

```elixir
"Hi!"
```

يمكن دمج السلاسل النصية باستخدام العامل `<>/2`:

```elixir
"Welcome to" <> " " <> "New York"
# => "Welcome to New York"
```

السلاسل النصية في Elixir تدعم الإدراج باستخدام الصياغة `#{}`:

```elixir
"6 * 7 = #{6 * 7}"
# => "6 * 7 = 42"
```

لإضافة محرف سطر جديد إلى سلسلة نصية، استخدم رمز الهروب `\n`:

```elixir
"1\n2\n3\n"
```

للتعامل بشكل مريح مع النصوص التي تحتوي على الكثير من الأسطر الجديدة، استخدم بدلًا من ذلك صياغة heredoc بثلاث علامات تنصيص مزدوجة:

```elixir
"""
1
2
3
"""
```

توفر Elixir العديد من الدوال للتعامل مع السلاسل النصية في وحدة `String`.

## عامل الأنبوب

يُسمى العامل `|>` عامل الأنبوب. يمكن استخدامه لتسلسل استدعاءات الدوال معًا بحيث تُمرَّر القيمة التي أرجعها استدعاء الدالة السابق كأول وسيط إلى استدعاء الدالة التالي.

```elixir
"hello"
|> String.upcase()
|> Kernel.<>("?!")

# => "HELLO?!"
```
