# التعليمات

في هذا التمرين، ستُنفّذ قواعد لحساب الراتب الإجمالي لموظف في شهر واحد.
تحتاج شركة International Siderurgy Company (ISC) إلى مساعدة في حساب رواتب الموظفين، مع مراعاة عوامل مختلفة قد تؤثّر على الأجر النهائي.

لديك ثلاث مهام، وعليك استخدام العامل الثلاثي بدلًا من جمل `if`/`else` الشرطية لتنفيذها.

## 1. تحديد مضاعف الراتب

نفّذ طريقة `salaryMultiplier`، التي تُرجع مضاعف الراتب بناءً على عدد الأيام التي تغيّب فيها الموظف عن العمل.
طبّق خصمًا بنسبة 15% إذا تغيّب الموظف خمسة أيام على الأقل.

```java
int daysSkipped = 3;
salaryMultiplier(daysSkipped);
// => 1.0

daysSkipped = 7;
salaryMultiplier(daysSkipped);
// => 0.85
```

## 2. حساب مكافأة المنتجات المباعة

نفّذ طريقتَي `bonusMultiplier` و`bonusForProductsSold`.
تدفع ISC عشرة وحدات نقدية عن كل منتج مباع، وإذا باع الموظف عشرين منتجًا أو أكثر، يتحسّن المضاعف ليصبح ثلاثة عشر.
ينبغي أن تحدّد `bonusMultiplier` أيّ مضاعف يُطبّق، وأن تُرجع `bonusForProductSold` إجمالي المكافأة بالوحدات النقدية.

```java
int productsSold = 21;
bonusMultiplier(productsSold);
// => 13
bonusForProductsSold(productsSold);
// => 273

productsSold = 5;
bonusMultiplier(productsSold);
// => 10
bonusForProductsSold(productsSold);
// => 50
```

## 3. حساب الراتب النهائي للموظف

نفّذ طريقة `finalSalary`.
ينبغي أن تضرب الراتب الأساسي `1000.00` في مضاعف الراتب، وتضيف المكافأة، ثم تُرجع النتيجة.
لكن يجب ألا يتجاوز الراتب `2000.00`.

```java
int daysSkipped = 2;
int productsSold = 3;
finalSalary(daysSkipped, productsSold);
// => 1030.00

productsSold = 90;
finalSalary(daysSkipped, productsSold);
// => 2000.00
```
