# مقدمة

## أنواع `struct`

رأينا أنواع `struct` من قبل؛ وللتذكير، `struct` هي سلسلة من العناصر المسماة تُدعى _الحقول_، ولكل حقل اسم ونوع.
ويجب أن يكون اسم الحقل فريدًا داخل `struct`.
ويمكن مقارنة أنواع `struct` بالصنف في نمط البرمجة الكائنية التوجه.

لإنشاء نوع `struct` جديد، استخدم الكلمتين المفتاحيتين `type` و `struct`، ثم عرّف اسم الحقول وأنواعها صراحةً كما في المثال التالي.

```go
type StructName struct{
    field1 fieldType1
    field2 fieldType2
}
```

## الأنواع غير `struct`

يمكنك أيضًا تعريف أنواع غير `struct` واستخدامها كأسماء بديلة لتعريفات الأنواع المضمّنة.

```go
type Name string
func SayHello(n Name) {
  fmt.Printf("Hello %s\n", n)
}
n := Name("Fred")
SayHello(n)
// Output: Hello Fred
```

يمكنك أيضًا تعريف أنواع غير `struct` تتكوّن من المصفوفات والخرائط.

```go
type Names []string
func SayHello(n Names) {
  for _, name := range n {
    fmt.Printf("Hello %s\n", name)
  }
}
n := Names([]string{"Fred", "Bill"})
SayHello(n)
// Output:
// Hello Fred
// Hello Bill
```
