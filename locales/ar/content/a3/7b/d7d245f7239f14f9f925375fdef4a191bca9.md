# مقدمة

تسمح لك حلقة `for` بالمرور على عناصر مصفوفة وتكرار الكود لكل عنصر:

```haxe
var fruitList = ["apple", "banana", "pear"];

for (fruit in fruitList) {
  trace(fruit);
}

// apple
// banana
// pear
```

في المثال أعلاه، `fruit` هو المتغير الذي يحمل قيمة عنصر واحد من عناصر المصفوفة `fruitList`. ويتحقق المترجم من أن `fruitList` قابلة للمرور عليها، وإلا فسيوقف التنفيذ.

يمكنك المرور على الأعداد باستخدام عامل النطاق. يأخذ هذا العامل قيمتين من النوع `Int` ويُكتب بالشكل `min...max`:

```haxe
for (i in 0...10) {
  trace(i); // from 0 to 9
}
```
