# مقدمة

## الاستيراد

توفّر Swift وظائف غنية في مكتبتها القياسية، لكن يمكنك الوصول إلى مزيد من الميزات باستيراد مكتبات وأُطر عمل خارجية.
قد تأتي هذه الوحدات مباشرةً من مشروع Swift (مثل [Swift Argument Parser][argument-parser])، أو من أُطر عمل منصّات Apple (مثل [Foundation][apple-foundation] و[Network Framework][network-framework])، أو من مكتبات مفتوحة المصدر من أطراف ثالثة (مثل [SwiftyBeaver][swifty-beaver]).

الوحدات الأساسية مثل Foundation، وهي من أكثر المكتبات استخدامًا في Swift، تأتي مضمّنة مع مجموعة أدوات Swift.
أما مكتبات الأطراف الثالثة فيجب إضافتها إلى إعدادات مشروعك (مثلًا باستخدام Swift Package Manager) قبل أن تتمكن من استيرادها.

يتم استيراد الوحدات بكتابة الكلمة المفتاحية `import` متبوعةً باسم الوحدة.
لذا يمكنك استيراد Foundation بإضافة ما يلي إلى برنامجك.

```swift
import Foundation
```

استيراد وحدة يجعل أنواعها وطرقها ودوالها متاحةً لكودك.
على سبيل المثال، يوسّع استيراد Foundation النوع `String` بطرق مساعدة مفيدة مثل `components(separatedBy:)`.

بحسب العُرف، توضع عبارات `import` في أعلى ملف Swift حتى تكون التبعيات ظاهرةً مباشرةً لأي شخص يقرأ الكود.

## فهرسة السلاسل النصية

يمكن الوصول إلى المحارف المفردة في `String` باستخدام أسلوب الفهرسة المستخدم مع المصفوفات.
لكن [الفهارس][string-indices] المستخدمة مع السلاسل النصية _ليست_ أعدادًا صحيحة ولا يمكن التعامل معها مباشرةً.
بدلًا من ذلك يجب حسابها انطلاقًا من فهرس آخر معروف، مثل `startIndex`، الذي يشير إلى موضع أول محرف في سلسلة نصية غير فارغة، وذلك باستخدام الطرق المتاحة في مكتبتي [`String`][string-docs] و[`NSString`][nsstring-docs] (فعند استيراد وحدة `Foundation`، تتمكن السلاسل النصية في Swift من الوصول إلى جميع خصائص NSString وطرقه).

على سبيل المثال، لنأخذ السلسلة النصية التالية:

```swift
let csv = "apple,pear,peach,orange,cherry,lime,goosberry"
```

لا يمكنك كتابة `csv[21]` للحصول على الحرف "g" في "orange"، بل يجب بدلًا من ذلك حساب قيمة من النوع `String.Index` وتمرير ذلك الفهرس.
لاحظ أن هذه الفهارس ليست مخصصة لأن يفهمها البشر بمفردها.
فهي ما يُشار إليه باسم _الفهارس المعتمة_، إذ لا يحتاج البشر إلى معرفة ما بداخلها.

```swift
let index = csv.index(csv.startIndex, offsetBy: 21)
csv[index]
// "g"
print(index)
// prints Index(_rawBits: 1376513)
```

لكن لاحظ أنه إذا لم تكن قيمة الإزاحة فهرسًا صالحًا، أي إذا كانت ستُرجع فهرسًا قبل `startIndex` أو بعد `endIndex`، فستُطلق العملية خطأً يؤدي إلى انهيار البرنامج.
ولمنع هذه المشكلة، يمكنك تحديد فهرس مُقيّد.
تُرجع هذه العملية فهرسًا اختياريًا، وستُرجع nil للفهارس غير الصالحة في غير ذلك.

```swift
let tooFar = csv.index(csv.startIndex, offsetBy: 200)
// error: Execution was interrupted, reason: EXC_BAD_INSTRUCTION (code=EXC_I386_INVOP, subcode=0x0).
let tooFarButSafe = csv.index(csv.startIndex, offsetBy: 200, limitedBy: csv.endIndex)
// nil
```

بالإضافة إلى ذلك، لا يمكن مشاركة الفهارس بين السلاسل النصية.
فمثلًا، استخدام `index` للحرف "g" في "orange" المحسوب أعلاه للفهرسة داخل السلسلة `fam = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶, this is our cat: 🐱!"`، أي `fam[index]`، سيؤدي إلى انهيار برنامجك.

هناك أسباب كثيرة لكل هذا، لكنها جميعًا تعود في الأساس إلى أن "يونيكود معقّد".

وبشكل عام، إذا كنت تحتاج إلى وصول عشوائي إلى المحارف المفردة، فالأرجح أنك تريد استخدام بنية بيانات أخرى، مثل `Array<Character>`.

### بعض الطرق المفيدة

توفّر Swift الطريقتين `first` و`last` للحصول على أول محرف وآخر محرف في السلسلة النصية.
تُرجع هاتان الطريقتان محرفًا اختياريًا، لذا إذا كانت السلسلة النصية فارغة فستُرجعان nil.

```swift
let str = "Hello, world!"
print(str.first) // Prints Optional("H")
print(str.last)  // Prints Optional("!")
```

يمكنك أيضًا استخدام الطريقتين `prefix` و`suffix` للحصول على سلسلة نصية فرعية.
تأخذ هاتان الطريقتان عددًا صحيحًا كوسيط وتُرجعان سلسلة نصية فرعية تحتوي على أول n محرف أو آخر n محرف من السلسلة النصية.

```swift
let str = "Hello, world!"
print(str.prefix(5)) // Prints "Hello"
print(str.suffix(6)) // Prints "world!"
```

## طرق السلاسل النصية

التعامل مع النصوص مهمة شائعة في البرمجة.
وتوفّر Swift، إلى جانب إطار عمل Foundation، العديد من الطرق والخصائص الملائمة لفحص السلاسل النصية وتحويلها ومعالجتها.

## تقسيم السلاسل النصية باستخدام `components(separatedBy:)`

لتقسيم سلسلة نصية إلى مصفوفة من السلاسل النصية الفرعية بناءً على فاصل، استخدم `components(separatedBy:)` (يتطلب استيراد Foundation):

```swift
import Foundation

let sentence = "Hello, world!"
let words = sentence.components(separatedBy: " ")
print(words) // Prints ["Hello,", "world!"]
```

## التحقق من البادئات واللواحق باستخدام `hasPrefix(_:)` و`hasSuffix(_:)`

للتحقق مما إذا كانت سلسلة نصية تبدأ أو تنتهي بتسلسل معيّن من المحارف، استخدم `hasPrefix(_:)` و`hasSuffix(_:)`:

```swift
let greeting = "Hello, world!"
print(greeting.hasPrefix("Hello"))  // Prints true
print(greeting.hasSuffix("world!")) // Prints true
```

## تغيير حالة الأحرف

يمكنك تغيير حالة الأحرف في سلسلة نصية باستخدام هذه الطرق والخصائص القياسية:

- `lowercased()`: تُرجع نسخة من السلسلة النصية بأحرف صغيرة.
- `uppercased()`: تُرجع نسخة من السلسلة النصية بأحرف كبيرة.
- `capitalized`: تُرجع نسخة يكون فيها أول حرف من كل كلمة كبيرًا (من Foundation).

```swift
let greeting = "hello, world!"
print(greeting.lowercased())  // Prints "hello, world!"
print(greeting.uppercased())  // Prints "HELLO, WORLD!"
print(greeting.capitalized)   // Prints "Hello, World!"
```

## استبدال السلاسل النصية الفرعية باستخدام `replacingOccurrences(of:with:)`

لاستبدال كل حالات ظهور سلسلة نصية فرعية مستهدفة بسلسلة أخرى، استخدم `replacingOccurrences(of:with:)` (من Foundation):

```swift
let greeting = "Hello, world!"
let updated = greeting.replacingOccurrences(of: "world", with: "Swift")
print(updated) // Prints "Hello, Swift!"
```

## ضم السلاسل النصية باستخدام `joined(separator:)`

تنتمي الطريقة `joined(separator:)` إلى مجموعات السلاسل النصية، مثل `[String]`.
وهي تضم العناصر معًا في سلسلة نصية واحدة باستخدام فاصل:

```swift
let words = ["Hello", "world"]
let sentence = words.joined(separator: ", ")
print(sentence) // Prints "Hello, world"
```
