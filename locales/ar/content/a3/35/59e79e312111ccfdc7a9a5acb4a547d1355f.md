# التعليمات

في هذا التمرين، ستُنفّذ آليات لعبة تقمّص أدوار.
يُمثَّل شخص اللاعب بالنوع التالي:

```fsharp
type Player = {
    Name: string option
    Level: int
    Health: int
    Mana: int option
}
```

يجب أن يصل اللاعبون في هذه اللعبة إلى المستوى 10 قبل أن يفتحوا مخزون المانا حتى يتمكنوا من البدء في إلقاء التعويذات.
ستعمل على جزأين من الوظائف في هذه اللعبة: آلية الإحياء وآلية إلقاء التعويذات.

## 1. عرّف بنفسك

اكتب محتوى دالة `introduce`.
لاحظ أن حقل `Name` في سجل `Player` من نوع `Option`.
قد يرغب اللاعبون المتخفّون في إخفاء أسمائهم بتركه مضبوطًا على `None`، وسيُعرَّف هؤلاء اللاعبون باسم `"Mighty Magician"`.
وإلا، فاستخدم اسمك فقط لتعريف بنفسك.

```fsharp
introduce { Name = None; Level = 2; Health = 8; Mana = None }
    --> "Mighty Magician"

introduce { Name = Some "Merlin"; Level = 2; Health = 8; Mana = None }
    --> "Merlin"
```

## 2. نفّذ آلية الإحياء

ينبغي أن تتحقق دالة `revive` من أن شخص اللاعب ميت فعلًا (وصلت صحته إلى 0).
وإن كان كذلك، فينبغي أن تُرجع نسخة جديدة من `Player` بصحة 100.
وإلا، إذا لم يكن شخص اللاعب ميتًا، فإن دالة `revive` تُرجع `None`.

وإذا كان مستوى اللاعب 10 أو أكثر، فينبغي أن يُحيا أيضًا بـ 100 مانا.
وإذا كان مستوى اللاعب أقل من 10، فينبغي أن تكون ماناه `None`.
ينبغي أن تحافظ دالة `revive` على مستوى اللاعب.

```fsharp
let deadPlayer = { Name = None; Level = 2; Health = 0; Mana = None }

revive deadPlayer
    --> Some { Name = None; Level = 2; Health = 100; Mana = None }
```

إذا استُدعيت طريقة `revive` على لاعب صحته 1 أو أكثر، فينبغي أن تُرجع الدالة `None`.

```fsharp
let alivePlayer = { Name = None; Level = 2; Health = 42; Mana = None }

revive alivePlayer
    --> None
```

## 3. نفّذ آلية إلقاء التعويذات

تأخذ دالة `castSpell` وسيطين: قيمة من نوع `int` تشير إلى كمية المانا التي تكلّفها التعويذة، وكائنًا من نوع `Player`.
وهي تُرجع اللاعب المُحدَّث، إضافة إلى مقدار الضرر الذي تلحقه التعويذة المُلقاة.
إلقاء التعويذة بنجاح يلحق ضررًا يساوي ضعف تكلفة المانا للتعويذة.
لكن إذا لم يمتلك اللاعب ما يكفي من المانا، فلا يحدث شيء، ويبقى اللاعب دون تغيير، ولا يلحق أي ضرر.
وإذا لم يكن لدى اللاعب مخزون مانا أصلًا، فإن محاولة إلقاء التعويذة يجب أن تخفض صحته بمقدار تكلفة المانا للتعويذة، ولا تلحق أي ضرر.

```fsharp
let wizard = { Name = None; Level = 18; Health = 123; Mana = Some 30 }

let updatedWizard, damage = castSpell 14 wizard

updatedWizard.Mana --> Some 16
damage             --> 28
```
