# نبذة

[السلاسل النصية][getting-started-strings] في Elixir تُحدَّد بعلامات الاقتباس المزدوجة، وتُرمَّز بترميز UTF-8:

```elixir
"Hi!"
```

يمكن دمج السلاسل النصية باستخدام عامل [`<>/2`][kernel-concat]:

```elixir
"Welcome to" <> " " <> "New York"
# => "Welcome to New York"
```

تدعم السلاسل النصية في Elixir [التداخل النصي][string-interpolation] باستخدام صيغة `#{}`:

```elixir
"6 * 7 = #{6 * 7}"
# => "6 * 7 = 42"
```

أي تعبير في Elixir صالح داخل التداخل النصي. إذا أُعطيت سلسلة نصية، تُدرَج السلسلة كما هي. وإذا أُعطيت أي قيمة أخرى، سيحاول Elixir تحويلها إلى سلسلة نصية.

```elixir
"Elixir can convert booleans to strings: #{true}"
# => "Elixir can convert booleans to strings: true"

"And #{["lists", ", ", "too!"]}"
# => "And lists, too!"

"But not functions: #{fn x -> x end}"

# => ** (Protocol.UndefinedError) protocol String.Chars not implemented for #Function<7.126501267/1 in :erl_eval.expr/5> of type Function
#        (elixir 1.10.1) lib/string/chars.ex:3: String.Chars.impl_for!/1
#        (elixir 1.10.1) lib/string/chars.ex:22: String.Chars.to_string/1
```

يوفر Elixir العديد من الدوال للتعامل مع السلاسل النصية في وحدة `String`. إذا لم تكن متأكدًا من كيفية معالجة سلسلة نصية بالطريقة التي تحتاجها، تأكد من تصفح [الدوال المتاحة في وحدة `String`][string-module-functions] وستجد على الأرجح ما تحتاجه.

```elixir
String.downcase("PLEASE NO SHOUTING")
# => "please no shouting"

String.split("hello", "", trim: true)
# => ["h", "e", "l", "l", "o"]

String.replace("Do I enjoy Elixir? Maybe...", "Maybe...", "Definitely!")
# => "Do I enjoy Elixir? Definitely!"

String.at("12345", 2)
# => "3"
```

عند استخدام بعض تلك الدوال، تذكر أن أول محرف في السلسلة النصية فهرسه `0`.

بعض المحارف تحتاج إلى [الهروب][escape-characters] لتُوضع في سلسلة نصية، مثل الأسطر الجديدة، أو علامات الاقتباس المزدوجة، أو المحرف `#`:

```elixir
"\"A\" is the \#1st letter of the alphabet.\n"
```

للتعامل بشكل مريح مع النصوص التي تحتوي على الكثير من الأسطر الجديدة، استخدم [صيغة heredoc ذات علامات الاقتباس الثلاثية المزدوجة][heredoc-syntax] بدلاً من ذلك:

```elixir
"""
1
2
3
"""
```

غالبًا ما ستجد هذه الصيغة مستخدمة لتوثيق الكود:

```elixir
defmodule MyApp.Hello do
  @moduledoc """
  This is the Hello module.
  """

  @doc """
  Says hello to the given `name`.

  Returns `:ok`.

  ## Examples

      iex> MyApp.Hello.world(:john)
      :ok

  """
  def world(name) do
    IO.puts("hello #{name}")
  end
end
```
