# مقدمة

النوع `char` في F# هو قيمة ذات 16 بت لتمثيل أصغر مكونات النص القابلة للعنونة، وهو غير قابل للتغيير افتراضيًا.

يمكن تعريف قيم `char` كقيم حرفية باستخدام علامتي اقتباس مفردتين:

```fsharp
let ch = 'A'
// => val ch: char = 'A'
```

السلاسل النصية هي تسلسل من قيم `char`.

يمكن استرجاع `char` مفرد من سلسلة نصية باستخدام الفهرسة (بدءًا من الصفر):

```fsharp
"Exercism"[4] //  =>  'c'
```

التكرار على سلسلة نصية يُرجع `char` في كل خطوة.

يستخدم المثال التالي دالة عالية الرتبة ودالة مجهولة، لتسهيل الأمر.
ستُغطى هذه لاحقًا بشكل وافٍ في المنهج، لكنها الآن في الأساس أسلوب موجز لكتابة حلقة على الأحرف في سلسلة نصية.

```fsharp
Seq.map (fun c -> c, int c) "F#"  //  =>  [('F', 70); ('#', 35)]
```

كما هو موضح أعلاه، يمكن تحويل `char` إلى قيمة `int` الخاصة به.
وهذا ينطبق أيضًا (في بعض الأحيان على الأقل) على أنظمة كتابة أخرى:

```fsharp
Seq.map (fun c -> c, int c) "東京"  //  =>  [('東', 26481); ('京', 20140)]
```

يُستخدم النوع `Int16` الأساسي عند مقارنة الأحرف:

```fsharp
'A' < 'D'  // =>  true
```

أيضًا، يمكن تحويل `int` إلى `char`:

```fsharp
char 77  // => 'M'
```

تحتوي مكتبة `System.Char` على المجموعة الكاملة من الطرق المتوقعة للغة .NET، مثل التحويل إلى أحرف كبيرة/صغيرة:

```fsharp
'a' |> System.Char.ToUpper  // =>  'A'

'Q' |> System.Char.ToLower  // =>  'q'
```
