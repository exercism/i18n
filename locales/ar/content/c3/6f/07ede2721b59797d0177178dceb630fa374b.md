# التثبيت

## تثبيت واجهة سطر الأوامر Clojure
توفّر Clojure أدوات سطر أوامر يمكن استخدامها لتشغيل `REPL` الخاص بـ Clojure، واستخدام مكتبات Clojure وJava، وتشغيل برامج Clojure.

إذا كنت بحاجة إلى تثبيت Java، فإننا نوصي بـ [Adoptium Temurin 17](https://adoptium.net/).

### Linux
تأكد من تثبيت المتطلبات التالية: `bash` و`curl` و`rlwrap` و`Java`. 
يمكنك تثبيت Clojure بأحد الأسلوبين التاليين:

1. LinuxBrew - يتطلب [Homebrew](https://brew.sh/)

```bash
brew install clojure/tools/clojure
```

2. مثبّت السكربت

```bash
curl -O https://download.clojure.org/install/linux-install-1.11.1.1347.sh
chmod +x linux-install-1.11.1.1347.sh
sudo ./linux-install-1.11.1.1347.sh
```

### Homebrew على Mac OS X
ثبّت أدوات سطر الأوامر باستخدام brew من مستودع tap ‏[clojure/tools](https://github.com/clojure/homebrew-tools):

```bash
brew install clojure/tools/clojure
```

#### Java

أي توزيعة من Java ستفي بالغرض. وإذا لزم الأمر، يمكنك تثبيت Temurin باستخدام brew:

```bash
brew tap homebrew/cask-versions
brew install --cask temurin17
```

### Windows

تحسّن Clojure على Windows تحسّنًا كبيرًا مؤخرًا. كنا نوصي سابقًا باستخدام WSL2، وهو يعمل بشكل ممتاز، لكن أصبح هناك الآن مثبّت PowerShell. لا يزال Clojure على Windows في مرحلة ألفا حاليًا، راجع [clj-on-windows](https://github.com/clojure/tools.deps.alpha/wiki/clj-on-Windows#known-issues) للمشكلات المعروفة.

تأكد من تثبيت Java ومن ضبط متغير البيئة `JAVA_HOME`، ثم نفّذ:

```powershell
iwr -useb download.clojure.org/install/win-install-1.11.1.1165.ps1 | iex
```

يمكنك أيضًا تثبيت Clojure على Windows باستخدام مدير الحزم [Scoop](https://scoop.sh/). لتثبيت Scoop، افتح PowerShell ونفّذ هذين الأمرين، واحدًا تلو الآخر:

 ```sh
 iwr -useb get.scoop.sh | iex
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser -Force
```

لتثبيت Clojure باستخدام Scoop، عليك أولًا إضافة مستودعين مهمّين:

```sh
# if you don't have git version control system installed
# it is required for adding new external buckets to your scoop installer
# you can skip this step otherwise
scoop install git

# add scoop bucket for Java 
scoop bucket add java

# add scoop bucket for clojure build
scoop bucket add scoop-clojure https://github.com/littleli/scoop-clojure
```

الآن أصبحنا جاهزين لتثبيت Java وClojure بتنفيذ الأوامر التالية:

```sh
# install Java runtime and compiler
scoop install adoptopenjdk-lts-hotspot

# install official clojure tools
scoop install clojure

# update to the newest version
scoop update clojure
```

بعد تنفيذ الخطوات السابقة بنجاح، سيكون بإمكانك تشغيل Clojure بالأمر التالي:

```sh
clj
```

## تثبيت Leiningen (اختياري)

رغم أنه لم يعد ضروريًا، ما زلنا ندعم أداة إدارة المشروعات كاملة المزايا [Leiningen](https://leiningen.org/). فهي تقدّم تشكيلة واسعة من المهام المفيدة، مثل الاختبار الميسّر، وعمليات البناء، وواجهة `REPL` محسّنة.

1. نزّل [سكربت lein](https://raw.githubusercontent.com/technomancy/leiningen/stable/bin/lein) أو [lein.bat](https://raw.githubusercontent.com/technomancy/leiningen/stable/bin/lein.bat) (Windows)
2. ضعه في `$PATH` حيث تستطيع صدفة الأوامر العثور عليه (مثل `/usr/local/bin/`)
3. اجعله قابلًا للتنفيذ (`sudo chmod a+x /usr/local/bin/lein`)
4. نفّذ `lein`.
