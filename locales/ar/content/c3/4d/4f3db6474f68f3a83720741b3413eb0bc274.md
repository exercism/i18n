# مقدمة

## الأنواع الجنيسة

**النوع الجنيس** هو صنف أو واجهة جنيسة مُعاملة على أنواع. وهذا يسمح للمترجم بفرض أمان الأنواع على الصنف أو الواجهة.

خذ بعين الاعتبار واجهة `Container` غير الجنيسة التالية:

```java
class Container {
    private Object object;

    public void set(Object object) { this.object = object; }
    public Object get() { return object; }
}
```

ولأنها تقبل أنواعًا من نوع `Object` وتُرجعها، فهي تعمل مع أي نوع غير أولي.
لكن هذا يأتي بتكلفة، إذ قد يستدعي بعض الكود `get` متوقعًا قيمًا من نوع `Integer` بينما يستدعي كود آخر `set` مضيفًا قيمًا من نوع `String`، ما يؤدي إلى استثناء وقت التشغيل.

لل**صنف الجنيس** و**الواجهة الجنيسة** الصيغتان التاليتان:

```java
class ClassName<T1, T2, ..., Tn> { ... }
interface InterfaceName<T1, T2, ..., Tn> { ... }
```

قسم معاملات النوع، المحصور بين الأقواس الزاوية (`<>`)، والذي يأتي بعد اسم الصنف أو الواجهة، يحدد معاملات النوع (وتُسمى أيضًا متغيرات النوع) `T1` و`T2` و... و`Tn`.
ويمكن استخدامها داخل جسم الصنف أو الواجهة للحصول على أمان الأنواع الذي تقدمه الأنواع الجنيسة.

وهذه هي النسخة الجنيسة من `Container`:

```java
class Container<E> {
    private E object;

    public void set(E object) { this.object = object; }
    public E get() { return object; }
}
```

عند إنشائه، علينا الآن أن نصرّح بنوع ما يحمله، وسيفرض المترجم هذا القيد:

```java
// empty <> can infer from context
Container<String> stringContainer = new Container<>();
// compiler knows this is a String, so it is allowed
stringContainer.set("Some string");
// no cast needed, compiler knows it is a String
String result = stringContainer.get();
// this causes a compiler error:
stringContainer.set(42);
```

## القوائم

**القوائم** هي المجموعة المتسلسلة المرتبة في Java.
وعلى خلاف المصفوفات، تستطيع [`List`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/List.html) أن تنمو في الحجم لتستوعب أي عدد من العناصر.
ومن التطبيقات القياسية `ArrayList`، وهي مدعومة بمصفوفة قابلة لتغيير حجمها.
ومن التطبيقات القياسية أيضًا صنف `LinkedList`، وهو مدعوم بقائمة مترابطة مزدوجة.

قد تكون القوائم فارغة أو تحمل أي عدد من العناصر (بما في ذلك العناصر المكررة).
والقوائم هي **واجهة جنيسة** تُحدَّد بنوع لتشير إلى نوع الكائنات التي يمكن أن تحتوي عليها.
على سبيل المثال:

```java
List<String> emptyListOfStrings = List.of();
List<Integer> singleInteger = List.of(1);
List<Boolean> threeBooleans = List.of(true, false, true);
List<Object> listWithMultipleTypes = List.of("hello", 1, true);
```

توفّر القوائم طرقًا مفيدة متنوعة لإضافة عنصر أو إزالته أو جلبه أو التحقق من وجوده:

```java
List<Character> vowels = new ArrayList<>(List.of('a', 'e', 'i', 'o', 'i', 'e', 'a'));
int startingSize = vowels.size(); // 7
vowels.add('u'); // vowels is now ['a', 'e', 'i', 'o', 'i', 'e', 'a', 'u']
char a = vowels.get(0); // 'a'
boolean hadI = vowels.remove('i'); // true and vowels is now ['a', 'e', 'o', 'i', 'e', 'a', 'u']
boolean hasI = vowels.contains('i'); // true (still have one more left)
```
