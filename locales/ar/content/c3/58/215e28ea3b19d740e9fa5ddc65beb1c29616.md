# الاختبارات

## تشغيل الاختبارات

1. احصل على تمرين:

    ```bash
    $ exercism download -track=kotlin --exercise=hello-world
    ```

2. انتقل إلى مجلد التمرين:

    ```bash
    $ cd <path_to_exercise_directory>
    ```

3. شغّل الاختبارات:

    ```bash
    $ ./gradlew test
    ```

في معظم التمارين، يُشغَّل الاختبار الأول فقط افتراضيًا.  
الاختبارات الأخرى معلَّمة بـ `@Ignore` لتخطيها.  
أثناء حلّك لكل اختبار، أزل `@Ignore` من الاختبار التالي لتتقدّم.

هذه ممارسة شائعة في التطوير الموجَّه بالاختبارات (أو TDD للاختصار).
وهي تُستخدم للتأكد من أنك تعمل على مشكلة واحدة في كل مرة.
