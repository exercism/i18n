# عنصر نائب

## نصائح حول `jq`

يدور هذا التمرين حول أخذ كائن إدخال وتحويله إلى كائن جديد.
وقد تساعدك الدالتان المدمجتان التاليتان:

- [`to_entries`][x_entries]
  - تأخذ هذه الدالة كائنًا كمدخل
  - وتُخرج _مصفوفة_، وكل عنصر فيها كائن `{"key": "K", "value": V}`
    - كل `K` هو مفتاح من كائن الإدخال
    - وكل `V` هو القيمة المقابلة لـ `K`.
- [`from_entries`][x_entries]
  - العملية العكسية
  - تأخذ مصفوفة من كائنات `{"key": K, "value": V}` وتبني كائنًا

مثال:

```sh
jq -n '
    {
        "username": "glennj",
        "tracks": ["bash", "awk", "jq"],
        "reputation": 123
    }
    | to_entries
'
```

الناتج:

```json
[
  {
    "key": "username",
    "value": "glennj"
  },
  {
    "key": "tracks",
    "value": ["bash", "awk", "jq"]
  },
  {
    "key": "reputation",
    "value": 123
  }
]
```

[x_entries]: https://jqlang.org/manual/#to_entries-from_entries-with_entries
