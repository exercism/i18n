# مقدمة

تسمح السمة `Flags` بتمثيل القيم المعرَّفة في اتحاد مميز على هيئة مواضع بتات (أي أعلام).
وبصفتها أعلامًا، يمكن دمج هذه القيم، ما يجعل من الممكن تمثيل عدة شروط منطقية في قيمة واحدة.

```fsharp
[<Flags>]
type PhoneFeatures =
| Call = 1
| Text = 2
```

```fsharp
[<Flags>]
type PhoneFeaturesBinary =
| Call = 0b00000001
| Text = 0b00000010
```

يمكن ضبط العلم باستخدام عامل OR البتي (`|||`)؛ ويمكن إلغاء ضبطه باستخدام مزيج من عامل AND البتي (`&&&`) وعامل النفي البتي (`~~~`).
وبينما يمكن التحقق من حالة العلم باستخدام عامل AND البتي، يمكن أيضًا استخدام طريقة `HasFlag()`.

```fsharp
let features = PhoneFeatures.Call

// Set the Text flag
let moreFeatures = features ||| PhoneFeatures.Text

moreFeatures.HasFlag(PhoneFeatures.Call) // => true
moreFeatures.HasFlag(PhoneFeatures.Text) // => true
```
