# مقدمة

صنف `Lambda` هو مجموعة من الطرق الوظيفية لاستخدام أسلوب البرمجة الوظيفية مع Haxe. وهو يتيح لنا العمل على `Iterable` بالكامل دفعة واحدة. وهذا غالبًا أفضل من حلقات التكرار لأنه أقل عرضة للأخطاء وأسهل في القراءة. وللتسهيل، يحتوي كل من الصنفين `Array` و `List` على بعض الطرق الأكثر استخدامًا من صنف `Lambda`.

تتضمن بعض دوال صنف `Lambda` ما يلي:

- `Lambda.array`، `Lambda.list` تحوّلان `Iterable` إلى `Array` أو `List`. وتُرجعان دائمًا نسخة جديدة.
- `Lambda.count` تعدّ عدد العناصر. إذا كان `Iterable` من نوع `Array` أو `List`، فاستخدام خاصية `length` أسرع.
- `Lambda.has` تحدّد ما إذا كان العنصر المحدد موجودًا في `Iterable`.
- `Lambda.indexOf` تجد فهرس العنصر المحدد.
- `Lambda.find` تجد أول عنصر يحقق دالة البحث المعطاة.
- `Lambda.concat` تدمج كائني `Iterable`، وتُرجع `List` جديدة.
- `Lambda.filter` تجد العناصر التي تحقق معيارًا، وتُرجع `List` جديدة.

مثال يوضح بعض الدوال:

```haxe
using Lambda;

class Main {
  static function main() {
    var words = ["boat", "dog", "phone", "cat", "food"];

    var isThreeLetters = function(word) return word.length == 3;

    trace(words.filter(isThreeLetters)); // [dog,cat]
  }
}
```
