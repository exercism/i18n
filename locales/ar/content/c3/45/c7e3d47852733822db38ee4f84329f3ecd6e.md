# مقدمة

في معظم الأحيان يتولى Factor التكرار عبر المُركِّبات مثل `each` و`map` و`count`. لكن في بعض الأحيان يكون أنظف أسلوب لكتابة عملية حسابية هو **الاستدعاء الذاتي**، أي كلمة تستدعي نفسها.

## تعريف كلمة بالاستدعاء الذاتي

يمكن لتعريف `:` أن يستدعي نفسه مباشرة:

```factor
: count-down ( n -- )
    dup 0 = [ drop ] [ dup . 1 - count-down ] if ;

5 count-down
! prints 5 4 3 2 1
```

## التفريع عند الفراغ وعدمه

يُعد `if-empty` (الموجود في [`sequences`][sequences]) الحالة الأساسية الطبيعية للاستدعاء الذاتي:

```
if-empty ( seq emptyquot nonemptyquot -- )
```

```factor
{ 4 0 9 } [ "empty" ] [ "got data" ] if-empty .
! => "got data"
```

يعمل `emptyquot` بعد أن تكون المتتالية (الفارغة) قد استُهلكت بالفعل، بينما يعمل `nonemptyquot` ولا تزال المتتالية على المكدس.

## `cond`: تتابع من فروع مشروطة

عندما يحتوي استدعاؤك الذاتي على أكثر من حالتين، يحافظ `cond` (الموجود في [`combinators`][combinators]) على وضوح الكود:

```factor
: classify ( n -- label )
    {
        { [ dup 0 < ] [ drop "negative" ] }
        { [ dup 0 = ] [ drop "zero"     ] }
        [ drop "positive" ]
    } cond ;
```

## الإشارات الأمامية مع `DEFER:`

يمكن لتعريف `:` أن يستدعي نفسه مباشرة، لكن عندما تستدعي كلمتان *إحداهما الأخرى*، يرى المحلّل الكلمة الأولى قبل أن توجد الثانية. يحجز `DEFER:` اسمًا حتى يمكن تصريف التعريف الأول:

```factor
DEFER: even?

: odd? ( n -- ? ) dup 0 = [ drop f ] [ 1 - even? ] if ;
: even? ( n -- ? ) dup 0 = [ drop t ] [ 1 - odd? ] if ;
```

يكون `DEFER:` مفيدًا أيضًا عندما يكون من الطبيعي قراءة كلمة مساعدة *بعد* الكلمة التي تستخدمها.
