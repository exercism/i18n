# نبذة

النوع `Maybe` هو حل لغة Elm للقيم الاختيارية.
لذلك يظهر في توقيعات أنواع عدد كبير من دوال Elm الأساسية، وفهمه أمر بالغ الأهمية.

## التعريف ومتغير النوع

يُعرَّف النوع `Maybe` كما يلي:

```elm
type Maybe a = Nothing | Just a
```

يُعرف هذا باسم تعريف «النوع المخصص» في مصطلحات Elm.
تُقدَّم الأنواع المخصصة بالتفصيل في مفهوم آخر من هذا المسار، لكننا لن نحتاج إليها لفهم `Maybe` تحديدًا.
يمثل `a` في `Maybe a` و`Just a` متغير نوع، أي أنه يمكن أن يكون أي نوع، مثل `Int` أو `Bool` أو `String`.
وبالتالي، فإن `Maybe String` قيمة تحمل `String` اختياريًا، بينما `Maybe Int` تحمل `Int` اختياريًا.

```elm
name : Maybe String
name = Just "Matthieu"

age : Maybe Int
age = Just 29
```

تعني الشرطة العمودية `|` في تعريف نوع `Maybe` كلمة «أو».
وهي تدل على أن قيمة من هذا النوع إما أن تكون `Nothing` أو أن تكون `Just` شيئًا من النوع `a`.
فلنتخيل أن الشخص لم يملأ الاسم والعمر، فسنحصل على ما يلي.

```elm
name : Maybe String
name = Nothing

age : Maybe Int
age = Nothing
```

## قراءة محتوى قيمة `Maybe`

تتم قراءة محتوى قيمة `Maybe` عبر «مطابقة الأنماط».
تُقدَّم مطابقة الأنماط أيضًا بمزيد من التفصيل في مفهوم آخر، لذا سنركّز هنا فقط على كيفية عمل مطابقة الأنماط مع `Maybe`.

```elm
-- This function returns "Hello, <name>!" if the name was provided.
-- Otherwise, it just says "Hello, World!".
sayHello : Maybe String -> String
sayHello maybeName =
    case maybeName of
        Nothing -> "Hello, World!"
        Just someName -> "Hello, " ++ someName ++ "!"

sayHello (Just "Matthieu")
    --> "Hello, Matthieu!"

sayHello Nothing
    --> "Hello, World!"
```

في كل مرة تستخدم فيها قيمة `Maybe`، سيتحقق مُصرِّف Elm من أن الكود لديك يعالج جميع الاحتمالات، لذا لا يمكنك أبدًا أن تُطابق نمط `Maybe` وتعالج الحالة التي فيها `Just someValue` فقط.
قد يبدو هذا مزعجًا في البداية، لكنه من أعظم نقاط قوة لغة Elm.
سيمنع هذا وقوع مئات الـ bug، ويجعل إعادة الهيكلة الموجَّهة من المُصرِّف تجربة بلا خوف ومُجزية.

## المزيد من الدوال للتعامل مع `Maybe`

توجد أيضًا عدد من الدوال المفيدة في وحدة `Maybe` للتعامل مع أنواع `Maybe`.

```elm
sayHelloAgain : Maybe String -> String
sayHelloAgain name = "Hello, " ++ Maybe.withDefault "World" name ++ "!"

capitalizeName : Maybe String -> Maybe String
capitalizeName name = Maybe.map String.toUpper name

capitalizeName matthieu
    --> Just "MATTHIEU"

capitalizeName anon
    --> Nothing
```
