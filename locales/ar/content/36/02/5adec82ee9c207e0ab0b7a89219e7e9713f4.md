# ملحق التعليمات

## صيغة الإخراج

أخرِج تسلسل الإجراءات كسلسلة نصية منتهية بـ `null`، باستخدام فاصلة ومسافة كفواصل.

## السجلات

| السجل | الاستخدام    | النوع   | الوصف                         |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | إدخال        | عدد صحيح | عدد بين 1 و31                 |
| `$a1`    | إدخال/إخراج  | عنوان   | سلسلة نصية منتهية بـ `null`   |
| `$t0-9`  | مؤقت         | أي      | يُستخدم للتخزين المؤقت        |
