# تعليمات

حوّل عددًا ثلاثيًا، ممثلًا كسلسلة نصية (مثل '102012')، إلى مكافئه العشري باستخدام المبادئ الأساسية.

يجب أن يعتبر البرنامج السلاسل النصية التي تحدد عددًا ثلاثيًا غير صالح بقيمة 0.

تحتوي الأعداد الثلاثية على ثلاثة رموز: 0، 1، و2.

المنزلة الأخيرة في العدد الثلاثي هي منزلة الآحاد. الثانية من الأخير هي منزلة الثلاثات، والثالثة من الأخير هي منزلة التسعات، وهكذا.

```shell
# "102012"
    1       0       2       0       1       2    # the number
1*3^5 + 0*3^4 + 2*3^3 + 0*3^2 + 1*3^1 + 2*3^0    # the value
  243 +     0 +    54 +     0 +     3 +     2 =  302
```

إذا كانت لغتك توفر طريقة في المكتبة القياسية لإجراء التحويل، فتظاهر بأنها غير موجودة وقم بتنفيذها بنفسك.
