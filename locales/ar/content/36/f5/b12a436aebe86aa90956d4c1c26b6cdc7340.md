# ملحق التعليمات

## السجلات

| السجل    | الاستخدام | النوع      | الوصف                                        |
| -------- | --------- | ---------- | -------------------------------------------- |
| `$a0`    | إدخال     | عنوان      | سلسلة نصية ثلاثية المحارف منتهية بـ `null`   |
| `$v0`    | إخراج     | عدد صحيح   | القيمة العشرية للسلسلة النصية المُدخلة       |
| `$t0-9`  | مؤقت      | أي نوع     | تُستخدم للتخزين المؤقت                       |
