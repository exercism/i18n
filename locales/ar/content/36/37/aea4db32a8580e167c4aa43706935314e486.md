# مقدمة

إذا أمكن استنتاج أنواع المعاملات، فإن Swift تسمح أيضًا بحذف أسماء المعاملات والكلمة المفتاحية `in` من تعريف الإغلاق. ويمكن بدلًا من ذلك الإشارة إلى المعاملات باستخدام صيغة اختصار خاصة، حيث يشير `$0` إلى المعامل الأول، ويشير `$1` إلى المعامل الثاني، وهكذا.

```swift
let mean: (Double, Double) -> Double = { $0 + $1 / 2.0 }

["apple", "ball", "carrot"].sorted(by: { $0.count < $1.count })
```
