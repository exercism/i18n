# مقدمة

## الأصناف

البنية الأساسية للبرمجة كائنية التوجه في Java هي _الصنف_، وهو مزيج من البيانات (_الحقول_) والسلوك (_الطرق_).
تُعرف حقول الصنف وطرقه باسم _أعضائه_.

يمكن التحكم في الوصول إلى الأعضاء عبر معدِّلات الوصول، وأكثرها شيوعًا اثنان:

- `public`: يمكن لأي كود الوصول إلى العضو (بلا قيود).
- `private`: لا يمكن الوصول إلى العضو إلا من الكود الموجود في الصنف نفسه.

يمكنك التفكير في الصنف كقالب لإنشاء نسخ منه.
لإنشاء نسخة من صنف (وتُعرف أيضًا بـ_الكائن_)، تُستخدم الكلمة المفتاحية `new`:

```java
class Car {
}

// Create two car instances
Car myCar = new Car();
Car yourCar = new Car();
```

الحقول لها نوع واسم (يُكتب الاسم بأسلوب camelCase) ويمكن تعريفها في أي مكان داخل الصنف (وحسب العُرف تُكتب بأسلوب PascalCase):

```java
class Car {
    // Accessible by anyone
    public int weight;

    // Only accessible by code in this class
    private String color;
}
```

يمكن اختياريًا إسناد قيمة ابتدائية إلى الحقل.
إذا لم يحدد الحقل قيمة ابتدائية، فستُضبط على القيمة الافتراضية لنوعه.
ويمكن الوصول إلى قيم حقول النسخة وتحديثها باستخدام تدوين النقطة.

```java
class Car {
    // Will be set to specified value
    public int weight = 2500;

    // Will be set to default value (0)
    public int year;
}

Car newCar = new Car();
newCar.weight; // => 2500
newCar.year;   // => 0

// Update value of the field
newCar.year = 2018;
```

عادةً ما تُحدَّث الحقول الخاصة كأثر جانبي لاستدعاء طريقة.
وهذه الطرق لا تُرجع عادةً أي قيمة، وفي هذه الحالة ينبغي أن يكون نوع الإرجاع `void`:

```java
class CarImporter {
    private int carsImported;

    public void importCars(int numberOfCars)
    {
        // Update private field from public method
        carsImported = carsImported + numberOfCars;
    }
}
```
