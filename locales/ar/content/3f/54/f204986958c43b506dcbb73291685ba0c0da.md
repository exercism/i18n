# مقدمة

## المعاملات

يناقش هذا التمرين بعض التفاصيل المتعلقة بمعاملات الطريقة واستخدامها في C#.

تنقل المعاملات معلومات من طريقة مستدعية إلى طريقة مستدعاة.

- يمكن تعديل سلوك المعاملات باستخدام معدِّلات مثل `ref` و `out`.

- ينقل المعامل المزوَّد بالمعدِّل `out` قيمةً عائدةً من الطريقة المستدعاة إلى المستدعي. يمكن تمرير المعامل إلى الطريقة المستدعاة دون تهيئته، وفي كل الأحوال يُعامَل داخل الطريقة المستدعاة كما لو أنه لم يكن مُهيَّأً عند الدخول. ويمكن اكتساب فهمٍ لسلوك وقواعد معدِّلات المعاملات على نحو أسهل من خلال الأمثلة (انظر أدناه) ورسائل المترجم.

```csharp
void Foo(out int val)
{
    val = 42;
}
void Bar(int val)
{
    val = 42;
}

int importantValue = 1729;
Foo(out importantValue);
var result = importantValue == 42;
// => true

importantValue = 1729;
Bar(importantValue);
result = importantValue == 1729;
// => true
```

- يجب إسناد قيم إلى معاملات `out` داخل الطريقة المستدعاة.

- يمرِّر المعامل المزوَّد بالمعدِّل `ref` قيمةً إلى الطريقة المستدعاة. وعندما تُرجع الطريقة، سيعثر المستدعي على أي تحديثات أُجريت بواسطة الطريقة المستدعاة في ذلك المعامل.

```csharp
void Foo(ref int val)
{
    val *= 7;
}

int importantValue = 6;
Foo(ref importantValue);
return importantValue;
// => 42
```

- يجب أن تكون معاملات `ref` متغيرات، لأن الطريقة المستدعاة ستعمل مباشرةً على المعامل كما يراه المستدعي.

- المعدِّلان `out` و `ref` مطلوبان في توقيع الطريقة المستدعاة وفي موقع الاستدعاء.
