# التعليمات

أوكلت إليك إدارة المطالبات في شركة Isaacs Asteroid Exploration Co. مهمة تحسين أداء نظام المطالبات بالأراضي.

في كل مرة يصبح كويكب جديد جاهزًا للاستغلال، يُدعى المضاربون إلى تسجيل مطالبتهم بقطعة أرض. تُقسَّم أرض الكويكب إلى قطع أرضية رباعية الأضلاع. ويسجّل المضاربون مطالبتهم بالأرض عبر تحديد أبعادها.

هدفك هو تطوير نظام عالي الأداء للتعامل مع التهافت على الأرض الذي أدى في الماضي إلى تعطّل الموقع.

وحدة القياس هي 100 متر، لكن يمكن تجاهلها في هذه المهام.

## 1. عرّف `Plot`

أكمل تنفيذ بنية `Plot` التي تتكوّن من 4 بنى `Coord` (تستقبلها في المُنشئ الخاص بها).

## 2. يستطيع المضاربون تسجيل مطالبتهم بتحديد قطعة أرض تُعرَّف بأبعادها

نفّذ الطريقة `ClaimsHandler.StakeClaim()` للسماح بتسجيل المطالبة.

نفّذ الطريقة `ClaimsHandler.IsClaimStaked()` لتحديد ما إذا كانت المطالبة قد سُجّلت.

```csharp
var ch = new ClaimsHandler();
ch.StakeClaim(new Plot(new Coord(1,1), new Coord(2,1), new Coord(1,2), new Coord(2,2)));
ch.IsClaimStaked(new Plot(new Coord(1,1), new Coord(2,1), new Coord(1,2), new Coord(2,2)));
// => true
```

## 3. تحقّق مما إذا كانت المطالبة الحالية هي نفسها الأخيرة.

نفّذ الطريقة `ClaimsHandler.IsLastClaim()` لمقارنة المطالبة الحالية بالمطالبة السابقة.

```csharp
var ch = new ClaimsHandler();
ch.StakeClaim(new Plot(new Coord(1,1), new Coord(2,1), new Coord(1,2), new Coord(2,2)));
ch.IsLastClaim(new Plot(new Coord(1,1), new Coord(2,1), new Coord(1,2), new Coord(2,2)));
// => true
```

## 4. اعثر على قطعة الأرض المُطالَب بها ذات الضلع الأطول لأغراض البحث

نفّذ الطريقة `ClaimsHandler.GetClaimWithLongestSide()` لفحص كل المطالبات المسجّلة وإرجاع قطعة الأرض ذات الضلع الأطول. من المضمون أن تكون بيانات الإحداثيات في أي قطعة أرض على هيئة مستطيل متّصل.

```csharp
var ch = new ClaimsHandler();
ch.StakeClaim(new Plot(new Coord(1,1), new Coord(2,1), new Coord(1,2), new Coord(2,2)));
ch.StakeClaim(new Plot(new Coord(10,1), new Coord(20,1), new Coord(10,2), new Coord(20,2)));
ch.GetClaimWithLongestSide();
// => new Plot(new Coord(1,1), new Coord(20,1), new Coord(1,2), new Coord(2,2))
```
