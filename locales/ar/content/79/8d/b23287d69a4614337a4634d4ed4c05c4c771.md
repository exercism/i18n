# تلميحات

## عام

- ربما ترغب في إنشاء لغة خاصة بالمجال قائمة على قوائم من الوسوم والسجلات، مثل هذا:

  ```roc
  my_graph =
      Graph.create([
          Title("My Graph"),
          Node("a", { color: Green }),
          Node("b", { color: Blue }),
          Edge("a", "b", { style: Dotted }),
      ])
  ```

- أو ربما تفضّل لغة خاصة بالمجال قائمة على تسلسل استدعاءات الدوال، مثل هذا:

  ```roc
  my_graph =
      Graph.create()
          .with_title("My Graph")
          .add_node("a", Attr.create().with_color(Green))
          ...
  ```

  أم ربما لديك خطة مختلفة تمامًا؟
  جرّبها!

- مع ذلك، تكون لغة خاصة بالمجال عادةً أفضل إذا كانت واضحة وموجزة وغير مفاجئة كثيرًا (على سبيل المثال، دالة `minus` مخصّصة للطرح، لا لبناء حافة بين عقدتين، كما في `node("a") - node("b")`).
