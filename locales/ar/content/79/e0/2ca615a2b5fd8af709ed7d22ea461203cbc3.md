# نبذة

في Common Lisp، تُمثَّل القيم التي تُعدّ خطأً بالقائمة الفارغة `()` أو بالرمز `nil`.
ويمكن أن تُكتب هذه القيم مقتبسة أو غير مقتبسة.

```lisp
;; Equivalent False Values
()   ; => NIL
nil  ; => NIL
'()  ; => NIL
'nil ; => NIL
```

أما جميع القيم الأخرى في Lisp فتُعدّ صحيحة.
وهناك أيضًا الرمز الثابت الخاص `t` الذي يساوي `t` دائمًا (وبالتالي فهو دائمًا صحيح).

```lisp
;; Some Different True Values
42                        ; => 42
"this statement is false" ; => "this statement is false"
t                         ; => T
't                        ; => T
```
