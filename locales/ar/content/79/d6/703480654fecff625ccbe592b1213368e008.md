# التعليمات

مرحبًا مجددًا، أيها العميل Double-Null0111.

تعود قوى UMBRA إلى التحرك من جديد، وعليك أنت أن تُحبط مخططهم الأخير.
يُبلغنا فرع الاستخبارات لدينا أن هؤلاء الـ Minions يخططون لتفجير قنبلة نتنة في الحفل الراقص للحاكم.

ولأن الـ minions خرقاء جدًا، فإنهم كثيرًا ما يُسلّحون القنابل النتنة بالخطأ في مختبراتهم ومكاتبهم.
ولأنهم ينسون باستمرار كيفية إبطال قنابلهم النتنة، فقد أنشأوا نظامًا يُولّد تعليمات الإبطال التي تسرد الترتيب الذي يجب قطع الأسلاك به انطلاقًا من رقم تعريف القنبلة.

مهمتك هي كتابة الكود الذي سيتيح لك إبطال القنبلة النتنة في الحفل قبل أن تنفجر.

## 1. اكتب إغلاقًا لقلب سلكين

توجد ثلاثة أسلاك مختلفة الألوان على كل قنبلة نتنة.
اكتب إغلاقًا يأخذ صفًا من النوع `(String, String, String)` ويُرجع الصف بعد قلب ترتيب العنصرين الأولين.
أسنِد هذا الإغلاق إلى الاسم `flip`.

من المهم ملاحظة أن النوع يجب أن يكون `ChangeClosure` (أو نوعًا قابلًا للإرسال)، وتعريف النوع موجود في ملف البداية.
وإلا فلن يُترجم الكود.

```swift
flip(("red", "yellow", "blue"))
// Returns ("yellow", "red", "blue")
```

## 2. اكتب إغلاقًا لتدوير الأسلاك

اكتب إغلاقًا يأخذ صفًا من النوع `(String, String, String)` ويُرجع الصف بعد تدوير ترتيب الأسلاك إلى اليسار.
أسنِد هذا الإغلاق إلى الاسم `rotate`.

من المهم ملاحظة أن النوع يجب أن يكون `ChangeClosure` (أو نوعًا قابلًا للإرسال)، وتعريف النوع موجود في ملف البداية.

```swift
rotate(("red", "yellow", "blue"))
// Returns ("yellow", "blue", "red")
```

## 3. نفّذ مولّد خلط الأسلاك

لكي تعرف الترتيب الذي يجب قطع أسلاك القنبلة النتنة به، ستحتاج إلى تنفيذ دالة تُولّد دالة الخلط المناسبة بناءً على رقم تعريف القنبلة النتنة.

نفّذ الدالة:

```swift
makeShuffle(
  flipper: @escaping ((String, String, String)) -> (String, String, String),
  rotator: @escaping ((String, String, String)) -> (String, String, String)
) -> ([UInt8], (String, String, String)) -> (String, String, String)
```

وهي تأخذ كمدخل إغلاقًا يقلب سلكين وإغلاقًا يدوّر الأسلاك الثلاثة، وتُرجع إغلاقًا.
هذا الإغلاق المُرجَع يأخذ رقم تعريف القنبلة النتنة وترتيب الأسلاك الثلاثة، ثم يحسب الترتيب الذي يجب قطع الأسلاك به.
يتكوّن رقم المعرّف من ثمانية بتات، ويحدد كل بت ما إذا كان يجب قلب الأسلاك أو تدويرها.

لكل بت في رقم المعرّف، بدءًا من البت الواقع في أقصى اليمين، ستطبّق إغلاق `flipper` على صف الأسلاك إذا كانت قيمة البت 0، وستطبّق إغلاق `rotator` إذا كانت قيمته 1، ما يمنح الحالة الجديدة للأسلاك.
بعد تطبيق الإغلاقات المناسبة على البتات الثمانية في المعرّف، تكون الحالة النهائية للأسلاك هي الترتيب الذي يجب قطعها به.

```swift
let shuffler = makeShuffle(flipper: flip, rotator: rotate)
// Returns ([UInt8], (String, String, String)) -> (String, String, String)
shuffler([1, 0, 0, 1, 1, 0, 1, 1], ("red", "yellow", "blue"))
// Returns ("red", "blue", "yellow")
```
