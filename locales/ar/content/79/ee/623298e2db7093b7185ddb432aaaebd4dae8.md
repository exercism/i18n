# ملحق التعليمات

## تنسيقات الإخراج

من المتوقع أن تُرجع الدالة `treeFromTraversals` كائنًا بثلاث خصائص:

- `value` قيمة العقدة الحالية
- `left` كائن يحتوي على الابن الأيسر للعقدة
- `right` كائن يحتوي على الابن الأيمن للعقدة

```javascript
{
    value: 'a',
    left: { value: 'i', left: {}, right: {} },
    right: { value: 'x', left: {}, right: {} },
}
```

إذا كانت الشجرة فارغة، فيجب إرجاع كائن فارغ.
