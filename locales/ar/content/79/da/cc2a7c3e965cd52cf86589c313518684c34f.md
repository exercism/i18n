# مقدمة

في C#، تُستخدم القيمة الحرفية `null` للدلالة على غياب قيمة. النوع _القابل لأن يكون `null`_ هو نوع يسمح بقيم `null`.

قبل C# 8.0، كانت الأنواع المرجعية دائمًا قابلة لأن تكون `null`، بينما لم تكن الأنواع القيمية كذلك. ومع ذلك، يمكن جعل نوع القيمة قابلًا لأن يكون `null` بإلحاق علامة استفهام (`?`) به.

```csharp
string nullableReferenceType = "hello";
nullableReferenceType = null; // Valid as type is nullable

int nonNullableValueType = 5;
nonNullableValueType = null; // Compile error as type is not nullable

int? nullableValueType = 5; // Define nullable value type
nullableValueType = null;   // Valid as type is nullable
```

الوصول إلى عضو في متغير قيمته `null` سيُترجم بنجاح، لكنه سيؤدي إلى رمي `NullReferenceException` في وقت التشغيل:

```csharp
string sentence = null;

// Throws NullReferenceException at runtime
sentence.Length;
```

لمواجهة هذا النوع الشائع من الأخطاء، تتيح C# 8 تفعيل ميزة تجعل الأنواع المرجعية غير قابلة لأن تكون `null` افتراضيًا:

```csharp
string nonNullableReferenceType = "book";
nonNullableReferenceType = null; // Compile warning (no error!)

string? nullableReferenceType = "movie";
nullableReferenceType = null; // Valid as type is nullable
```

للتعامل بأمان مع القيم القابلة لأن تكون `null`، ينبغي التحقق مما إذا كانت `null` قبل التعامل معها:

```csharp
string NormalizedName(string? name)
{
    if (name == null)
    {
        return "UNKNOWN";
    }
    else
    {
        // Value is not null at this point, so no compile warning
        // and no runtime NullReferenceException being thrown
        return name.ToUpper();
    }
}

NormalizedName(null); // => "UNKNOWN"
NormalizedName("Elisabeth"); // => "ELISABETH"
```

يتيح العامل `??` إرجاع قيمة افتراضية عندما تكون القيمة `null`:

```csharp
string? name1 = "John";
name1 ?? "Paul"; // => "John"

string? name2 = null;
name2 ?? "George"; // => "George"
```

يتيح العامل `?.` استدعاء الأعضاء بأمان على قيمة قد تكون `null`:

```csharp
string? fruit = "apple";
fruit?.Length; // => 5

string? vegetable = null;
vegetable?.Length; // => null
```
