# مقدمة

## مقارنة الأعداد

في JavaScript يمكن مقارنة الأعداد باستخدام عوامل العلاقة والمساواة التالية.

| المقارنة                | العامل    |
| ---------------------- | --------- |
| أكبر من                | `a > b`   |
| أكبر من أو يساوي       | `a >= b`  |
| أصغر من                | `a < b`   |
| أصغر من أو يساوي       | `a <= b`  |
| يساوي (بشكل صارم)      | `a === b` |
| لا يساوي (بشكل صارم)   | `a !== b` |

نتيجة المقارنة هي دائمًا قيمة منطقية، أي إما `true` أو `false`.

```javascript
1 < 3;
// => true

2 !== 2;
// => false

1 === 1.0;
// => true
// All numbers are floating-points, so this is different syntax for
// the exact same value.
```

## مقارنة السلاسل النصية

في JavaScript، يمكن أيضًا استخدام عوامل المقارنة أعلاه لمقارنة السلاسل النصية.
في هذه الحالة، يُطبَّق ترتيب قاموسي (معجمي).
يمكنك العثور على قائمة بالترتيب الدقيق لجميع المحارف [هنا][utf-16-list].

```javascript
'Apple' > 'Pear';
// => false

'a' < 'above';
// => true

'a' === 'A';
// => false
```

## المساواة الصارمة

قد تتساءل عن علامات يساوي الثلاث عند التحقق من المساواة في JavaScript.
يمثل `===` التحقق من _المساواة الصارمة_، وهذا يعني أنه لا يُجرى أي تحويل للنوع، وأن القيم من أنواع مختلفة تكون دائمًا غير متساوية.

```javascript
'3' === 3;
// => false
// The value on the left has type string, the value on the right has type number.

1 === 1n;
// => false
// The value on the left has type number, the value on the right has type bigint.
```

يُعد استخدام `===` و `!==` الأسلوب الموصى به للتحقق من المساواة في JavaScript.

هناك أيضًا `==` و `!=` وهما يمثلان التحقق من _المساواة غير الصارمة_.
تجنّبه لأنه يطبّق تحويلًا ضمنيًا للنوع قبل إجراء المقارنة.
من الصعب التنبؤ بنتائج هذه الحالات، وأحيانًا لا تكون كما تتوقع.

```javascript
0 == false;
// => true
```
