# التعليمات

في هذا التمرين ستُنظّم سباقات بين أنواع مختلفة من السيارات التي يتم التحكم بها عن بعد.
لكل سيارة خصائصها الخاصة، وهي تسير على العديد من المضامير المختلفة في سباقات على مدار موسم البطولة.

~~~~exercism/note
الدوال في هذا التمرين مُعلَنة في ملف مصدر بلغة C بالتوقيعات المعطاة.
يجب أن يتّبع كود لغة التجميع x86-64 هذه المواصفات.
~~~~

## 1. إنشاء سيارة يتم التحكم بها عن بعد

لقد عرّفت بنية `car_t` لتمثيل سيارة يتم التحكم بها عن بعد:

```c
struct car_t {
    char name[10];
    int16_t speed;
    float battery;
};
```

يتيح لك تعريف دالة `new_car` في لغة التجميع x86-64 إنشاء سيارة يتم التحكم بها عن بعد.
يبدأ الحقل `battery` دائمًا بالقيمة `100.0`.

```c
struct car_t new_car(short speed, const char name[]);
```

## 2. إنشاء مضمار جديد

تُمثَّل المضامير ببنية `track_t`:

```c
struct track_t {
    enum surface_t surface;
    size_t distance;
};
```

يحتفظ `enum surface_t` بالأسطح المختلفة للمضمار:

```c
enum surface_t {
    ASPHALT,
    SAND,
    ICE,
    CLAY
};
```

يتيح لك تعريف دالة `new_track` في لغة التجميع x86-64 إنشاء مضمار جديد.

```c
struct track_t new_track(enum surface_t surface, size_t distance);
```

## 3. إنشاء سباق

يشارك في كل سباق حتى 6 سيارات، وتقطع عددًا محددًا من اللفات على المضمار.
تُمثَّل السباقات ببنية `race_t`:

```c
struct race_t {
    struct track_t track;
    uint8_t num_of_laps;
    struct car_t cars[6];
    uint8_t num_of_running_cars;
};
```

عرّف دالة `new_race` في لغة التجميع x86-64.
في البداية، لا توجد سيارات مؤكَّدة المشاركة في السباق:

```c
struct race_t new_race(struct track_t track, uint8_t num_of_laps);
```

## 4. تأكيد مشاركة سيارة في السباق

عندما يطلب مالك سيارة مشاركتها في سباق، لا تُؤكَّد مشاركتها إلا إذا لم تكن القائمة ممتلئة بالفعل.

عرّف دالة `add_participant` في لغة التجميع x86-64.
إذا كان هناك متسع لمشارك آخر في السباق، تُضاف السيارة إلى القائمة، مع تحديث العدّاد، وتُؤكَّد مشاركتها.
وإلا، فعلى منظّمي السباق إبلاغ مالك السيارة بأنها لا تستطيع المشاركة هذه المرة.

```c
bool add_participant(struct race_t *race, struct car_t car);
```

## 5. إنشاء بطولة

تتابع السباقات المقرَّرة للموسم في بنية `tournament_t`:

```c
struct tournament_t {
    struct race_t races[20];
    size_t num_of_races;
};
```

عرّف دالة `add_race` في لغة التجميع x86، لإضافة سباق إلى مصفوفة البطولة وتحديث عدّادها أيضًا.
يمكنك اعتبار أنه سيكون هناك دائمًا مساحة كافية في مصفوفة `races` للسباق الجديد.

```c
void add_race(struct tournament_t *tournament, struct race_t race);
```
