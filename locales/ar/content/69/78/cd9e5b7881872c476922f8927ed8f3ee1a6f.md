## تثبيت Z3

### تنزيل Python (إن لم يكن مثبتًا لديك بعد)

يمكنك تنزيل أحدث إصدار من Python من [هنا](https://python.org).

* عند التثبيت، تأكد من تحديد المربع الذي يضيف Python إلى `PATH`

### تنزيل Visual Studio (إن لم يكن مثبتًا لديك بعد)

يمكنك تنزيل أحدث إصدار من Visual Studio من [هنا](https://visualstudio.microsoft.com/downloads/?utm_medium=microsoft&utm_source=docs.microsoft.com&utm_campaign=inline+link&utm_content=download+vs2019).

* عند التثبيت، اختر حمل العمل **Python Development**
* حدّد كل مربعات الاختيار الخاصة بحزم تطوير Python الاختيارية على الجانب الأيمن

بعد التثبيت، افتح Visual Studio واضبط تفضيلاتك الأولية.

### تثبيت أوامر Git

تجد تعليمات تثبيت Git [هنا](https://git-scm.com/book/en/v2/Getting-Started-Installing-Git).

* ستحتاج إلى [إضافة Git إلى متغيرات نظامك](https://stackoverflow.com/questions/4492979/git-is-not-recognized-as-an-internal-or-external-command)

### استنساخ Z3

انتقل إلى [مستودع Z3 على Github](https://github.com/Z3Prover/z3) لمشاهدة المشروع.

افتح طرفية على حاسوبك وانتقل إلى المكان الذي تريد استنساخ مستودع Z3 فيه (مثال: `C:\Z3`).

من ذلك الموقع، نفّذ:

```bash
git clone https://github.com/z3Prover/z3.git
```

### بناء Z3 على Windows باستخدام Visual Studio Command Prompt

افتح **Developer Command Prompt for VS 2019** من قائمة ابدأ.

انتقل إلى المجلد الذي استنسخت فيه مستودع Z3 (مثال: `C:\Z3`).

لبناء نسخة 32 بت، نفّذ:

```bash
python scripts/mk_make.py
```

لبناء نسخة 64 بت، نفّذ:

```bash
python scripts/mk_make.py -x
```

ثم نفّذ:

```bash
cd build
pip install z3-solver
```



يفترض أن تكون الآن قادرًا على فتح Visual Studio وتشغيل Z3 مع ارتباط Python الخاص به.


للاختبار، يمكنك تشغيل:
```python
from x3 import *
x = Real('x')
y = Real('y)
s = Solver()
s.add(x + y > 5, x > 1, y > 1)
print(s.check())
print(s.model())
```

يفترض أن ينتج السطران الأخيران `sat` و`[y = 4, x = 2]`.
