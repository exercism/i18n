# مقدمة

## الصفوف

الصف في Elixir بنية بيانات تنظّم البيانات، وتحتوي على عدد ثابت من العناصر من أي نوع، لكن دون أسماء صريحة لكل عنصر. كثيرًا ما تُستخدم الصفوف في Elixir في العمليات كثيفة القراءة من الذاكرة، لأن الوصول للقراءة إلى عنصر ما عملية ذات زمن ثابت. وعادةً لا تُستخدم عندما قد يلزم إضافة العناصر أو حذفها ديناميكيًا، لأن الصف لا يُعدَّل، بل يُنشأ صف جديد يتطلب تخصيص الذاكرة مسبقًا.

عمليًا، تُنشأ الصفوف في Elixir باستخدام الأقواس المعقوفة. ويمكن الوصول إلى عناصر الصف كلٌّ على حدة باستخدام الدالة `elem/2` بفهرسة تبدأ من الصفر:

```elixir
empty_tuple = {}
one_element_tuple = {1}
multiple_element_tuple = {1, :a, "hello"}

elem(multiple_element_tuple, 2)
# => "hello"
```

### الصفوف كمعلومات مجمّعة

كثيرًا ما تُستخدم الصفوف عمليًا لتمثيل معلومات مجمّعة.

```elixir
Float.ratio(0.25)
# => {1, 4} indicating the numerator and denominator of the fraction ¼
```

## مطابقة الأنماط

مطابقة الأنماط هي السائدة في كود Elixir الأصيل والحاسم. قد تتذكر أن `=/2` يُوصف بأنه عامل مطابقة وليس عامل إسناد. وعند استخدام عامل المطابقة، إذا طابق النمط الموجود على اليسار الجانب الأيمن، تُربط أي متغيرات على اليسار، وتُرجَع قيمة الجانب الأيمن. ويُطلَق استثناء `MatchError` إذا لم تحدث مطابقة.

```elixir
2 = 2
# => 2
# Literals can be matched if they are the same

2 = 3
# => ** (MatchError) no match of right hand side value: 3

{_, denominator} = Float.ratio(0.25)
# => {1, 4}
# the variable `denominator` is bound to the value 4
```

تذكّر أن المطابقات تحدث من الجانب الأيمن إلى الجانب الأيسر.

في المثال الأخير، إذا لم نحتج إلى متغير في مطابقة النمط، يمكننا التخلص منه بالإشارة إلى `_`. وأي متغير يبدأ بـ `_` لا يتتبعه وقت التشغيل.

### مطابقة الأنماط في الدوال المسماة

مطابقة الأنماط أداة مفيدة أيضًا عند إنشاء عدة بنود للدالة. ويمكن استخدام مطابقة الأنماط على وسائط الدوال، وهو ما يحدد بند الدالة الذي سيُنفَّذ، بدءًا من أعلى الملف نزولًا حتى أول مطابقة. وقد تُربط المتغيرات في رأس الدالة وتُستخدم في جسم الدالة.

```elixir
defmodule Example do
  def named_function(:a = variable_a) do
    {variable_a, 1}
  end

  def named_function(:b = variable_b) do
    {variable_b, 2}
  end
end

Example.named_function(:a)
# => {:a, 1}

Example.named_function(:b)
# => {:b, 2}

Example.named_function(:c)
# => ** (FunctionClauseError) no function clause matching in Example.named_function/1
```
