# التثبيت

ستحتاج إلى مدير حزم Node ‏(npm) لتثبيت Reason. اتبع التعليمات الموجودة [هنا](https://www.npmjs.com/get-npm)

بعد أن يصبح npm جاهزًا لديك، ثبّت Reason بالأمر التالي:
```
npm install -g bs-platform
```

يتكامل Reason مع عدد من المحررات، انظر [هنا](https://reasonml.github.io/docs/en/editor-plugins.html#officially-supported-editors)

تجد [هنا](https://github.com/reasonml/reason-cli) بعض أدوات سطر الأوامر (ومنها REPL الذي يتيح لك تقييم تعبيرات Reason في صدفة الأوامر)
