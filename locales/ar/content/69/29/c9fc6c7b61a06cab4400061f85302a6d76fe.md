# التعليمات

في هذا التمرين ستتعامل مع أسطر السجل.

كل سطر سجل هو سلسلة نصية مُنسّقة كما يلي: `"[<LEVEL>]: <MESSAGE>"`.

هناك ثلاثة مستويات مختلفة للسجل:

- `INFO`
- `WARNING`
- `ERROR`

لديك ثلاث مهام، كل واحدة منها تأخذ سطر سجل وتطلب منك فعل شيء به.

## 1. استخرج الرسالة من سطر السجل

نفّذ الدالة `message` لتُرجع رسالة سطر السجل:

```gleam
message("[ERROR]: Invalid operation")
// -> "Invalid operation"
```

يجب إزالة أي مسافات بيضاء في البداية أو النهاية:

```gleam
message("[WARNING]:  Disk almost full\r\n")
// -> "Disk almost full"
```

## 2. استخرج مستوى السجل من سطر السجل

نفّذ الدالة `log_level` لتُرجع مستوى السجل الخاص بسطر السجل، ويجب أن يكون بأحرف صغيرة:

```gleam
log_level("[ERROR]: Invalid operation")
// -> "error"
```

## 3. أعد تنسيق سطر السجل

نفّذ الدالة `reformat` التي تعيد تنسيق سطر السجل، فتضع الرسالة أولًا ثم مستوى السجل بعدها بين الأقواس الهلالية:

```gleam
reformat("[INFO]: Operation completed")
// -> "Operation completed (info)"
```
