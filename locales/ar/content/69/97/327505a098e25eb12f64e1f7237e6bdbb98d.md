# التعليمات

في هذا التمرين، ستتعامل مع أسطر من تقرير مسجل.
كل سطر سجل هو سلسلة نصية منسقة كما يلي: `"[<LEVEL>]: <MESSAGE>"`.

هناك ثلاثة مستويات مختلفة للسجل:

- `INFO`
- `WARNING`
- `ERROR`

لديك ثلاث مهام، كل مهمة ستأخذ سطر سجل وتطلب منك فعل شيء به.

## 1. استخرج الرسالة من سطر سجل

طبّق طريقة `log_line::message` لتُرجع رسالة سطر السجل:

```cpp
log_line::message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

## 2. استخرج مستوى السجل من سطر سجل

طبّق طريقة `log_line::log_level` لتُرجع مستوى السجل لسطر السجل، والذي يجب أن يُرجع بأحرف كبيرة:

```cpp
log_line::log_level("[ERROR]: Invalid operation")
// => "ERROR"
```

## 3. أعد تنسيق سطر سجل

طبّق طريقة `log_line::reformat` التي تعيد تنسيق سطر السجل، مع وضع الرسالة أولًا ومستوى السجل بعدها بين الأقواس الهلالية:

```cpp
log_line::reformat("[INFO]: Operation completed")
// => "Operation completed (INFO)"
```
