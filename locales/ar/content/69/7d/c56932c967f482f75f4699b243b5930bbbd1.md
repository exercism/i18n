# التحكم في تدفق التنفيذ

تتحكم تعبيرات `if` والحلقات في تدفق التنفيذ في Cairo من خلال:
`

- **تعبيرات `if`** تنفّذ الكود بشكل شرطي بناءً على ما إذا كان الشرط يُقيَّم إلى `true`.
- **الحلقات** (مثل `loop` و`while` و`for`) تنفّذ الكود بشكل متكرر طالما بقي شرط معيّن صحيحًا، أو حتى يتحقق شرط يوقف التنفيذ.

هذه التركيبات أساسية لتطبيق المنطق والتكرار في Cairo.

## تعبيرات `if`

تتيح لك تعبيرات `if` في Cairo التحكم في تدفق التنفيذ بناءً على منطق شرطي.
وهي تتبع بنية يُنفَّذ فيها الكود بناءً على ما إذا كانت قيمة شرط منطقي تساوي `true` أو `false`.

```rust
fn main() {
    let temperature = 30;

    if temperature > 25 {
        println!("It's hot outside!");
    }
}
```

يوضح هذا المثال كتلة `if` بسيطة في Cairo.
لا تُطبع الرسالة `"It's hot outside!"` إلا إذا كانت قيمة الشرط `temperature > 25` تساوي `true`.
وإذا كان الشرط `false`، فلا يُنفَّذ أي كود، ويواصل البرنامج عمله.

```rust
fn main() {
    let number: u32 = 5;

    if number < 10 {
        println!("The number is less than 10.");
    } else {
        println!("The number is 10 or greater.");
    }
}
```

عند تشغيل هذا الكود ستُطبع الرسالة `"The number is less than 10."` في وحدة التحكم.

### التعامل مع شروط متعددة باستخدام `else if`

يمكنك استخدام شروط متعددة عبر الجمع بين `if` و`else` في تعبير `else if`.

```rust
fn main() {
    let score: u64 = 85;

    if score >= 90 {
        println!("Grade: A");
    } else if score >= 80 {
        println!("Grade: B");
    } else if score >= 70 {
        println!("Grade: C");
    } else {
        println!("Grade: F");
    }
}
```

عند تشغيل هذا الكود ستُطبع الرسالة `"Grade: B"` في وحدة التحكم.

### استخدام `if` داخل عبارة `let`

يمكن استخدام تعبير `if` في Cairo على الجانب الأيمن من عبارة `let` لإسناد النتيجة إلى متغير.

```rust
fn main() {
    let condition: bool = true;
    let number: felt252 = if condition {
        5
    } else {
        6
    };

    if number == 5 {
        println!("condition was true and number is {}", number);
    }
}
```

## الحلقات

تُعدّ الحلقات تركيبًا أساسيًا يسمح بتكرار كتل الكود، بما يتيح تنفيذ المهام بكفاءة وتحكّم.
ويمكن للحلقات أن تمرّ على تسلسل ما، أو أن تنفّذ الكود بشكل متكرر بناءً على شرط.
توفّر Cairo ثلاثة أنواع رئيسية من الحلقات:

- **loop**: حلقة أساسية تعمل إلى ما لا نهاية ما لم تُوقف بشكل صريح باستخدام عبارة `break`.
- **while**: تستمر في التنفيذ طالما بقي شرط محدد `true`.
  وتتوقف عندما يصبح الشرط `false`.
- **for**: تمرّ على العناصر في مجموعة، مثل المصفوفات، وتنفّذ الكود لكل عنصر.

### تكرار الكود باستخدام `loop`

تخبر الكلمة المفتاحية `loop` لغة Cairo بتنفيذ كتلة من الكود مرارًا وتكرارًا إلى ما لا نهاية، أو حتى تطلب منها التوقف صراحةً.

```rust
fn main() {
    loop {
        println!("again!");
    }
}
```

عند تنفيذ هذا الكود ستُطبع الرسالة `"again!"` بلا نهاية في وحدة التحكم، حتى ينفد الغاز من البرنامج أو نوقفه يدويًا.

> ملاحظة: تمنعنا Cairo من تشغيل برنامج فيه حلقات لا نهائية من خلال تضمين مقياس للغاز.
> ومقياس الغاز آلية تحدّ من مقدار الحسابات التي يمكن إجراؤها في البرنامج.
> والغاز وحدة قياس تعبّر عن كلفة تنفيذ تعليمة.
> وعندما ينفد مقياس الغاز، يتوقف البرنامج.

للخروج من الحلقة، ضع الكلمة المفتاحية `break` داخل الحلقة لتخبر البرنامج متى يتوقف عن تنفيذها.

```rust
fn main() {
    let mut i: usize = 0;
    loop {
        if i > 10 {
            break;
        }
        println!("i = {}", i);
        i += 1;
    }
}
```

تخبر الكلمة المفتاحية `continue` البرنامج بالانتقال إلى التكرار التالي في الحلقة وتخطّي بقية الكود في هذا التكرار.

```rust
fn main() {
    let mut i: usize = 0;
    loop {
        if i > 10 {
            break;
        }
        if i == 5 {
            i += 1;
            continue;
        }
        println!("i = {}", i);
        i += 1;
    }
}
```

لن يطبع تنفيذ هذا البرنامج قيمة `i` عندما تساوي `5`.

#### إرجاع القيم من `loop`

يمكنك إرجاع قيمة من `loop` باستخدام الكلمة المفتاحية `break` متبوعة بالقيمة التي تريد إرجاعها.
ويتيح لك ذلك الخروج من `loop` وتمرير نتيجة إلى بقية الكود.

```rust
fn main() {
    let mut counter = 0;

    let result = loop {
        if counter == 10 {
            break counter * 2;
        }
        counter += 1;
    };

    println!("The result is {}", result); // prints "The result is 20"
}
```

### الحلقات الشرطية باستخدام `while`

تشغّل `while` الكود طالما بقي الشرط `true`، وتخرج عندما يصبح الشرط `false`.

```rust
fn main() {
    let mut number = 3;
    while number != 0 {
        println!("{}!", number);
        number -= 1;
    }
    println!("LIFTOFF!!!");
}
```

### المرور على مجموعة باستخدام `for`

تمرّ `for` على كل عنصر في مجموعة، وتنفّذ الكود لكل عنصر.

```rust
fn main() {
    let a = [10, 20, 30, 40, 50].span();
    for element in a {
        println!("the value is: {}", element);
    }
}
```
