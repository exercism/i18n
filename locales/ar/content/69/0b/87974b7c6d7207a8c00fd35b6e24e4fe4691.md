# ملحق التعليمات

## الكلمات

- `<bst> ( data-seq -- tree )`: لبناء شجرة عبر إدراج كل عنصر من `data-seq` بالترتيب.
- `sorted-data ( tree -- seq )`: تُرجع عناصر الشجرة بترتيب تصاعدي (اجتياز داخلي).

## التسلسل الهرمي للصفوف

عقدة في شجرة بحث ثنائية تكون إما *فارغة* أو *تحتوي على بيانات مع شجرتين فرعيتين*. مثّل ذلك بتسلسل هرمي صغير للوراثة:

```factor
TUPLE: bst ;
TUPLE: leaf < bst ;
TUPLE: branch < bst data left right ;
```

`bst` هو الأب المجرد؛ `leaf` هي حالة الشجرة الفارغة؛ `branch` يحمل قيمة وطفلين من نوع `bst` (كل منهما إما `leaf` أو `branch`).

## الترتيب

قارن البيانات باستخدام `before=?` (من `math.order`)، وهي تعمل مع السلاسل النصية والأعداد. تستخدم الاختبارات بيانات نصية مثل `"1"` و`"2"` و`"3"`.
