# مقدمة

مثل الخصائص، التي تخزّن البيانات في البُنى والأصناف الخاصة بك، يمكنك أيضًا تعريف _الطرق_ التي تخزّن الدوال في بنيتك أو صنفك.

تُعرَّف الطرق كما تُعرَّف الدالة العادية، لكن داخل جسم البنية أو الصنف. لاحظ أنه إذا غيّرت دالة قيمة خاصية في بنية، فيجب أن تسبقها الكلمة المفتاحية `mutating`. بالإضافة إلى ذلك، إذا كان يمكن تغيير خاصية بواسطة طريقة، فيجب تعريف تلك الخاصية باستخدام `var` بدلًا من `let`، تمامًا مثل المتغيرات العادية.

```swift
struct CharacterStats {
  var health = 0.0
  var speed = 0
  var strength = 0

  mutating func takeHit(_ damage: Double) {
    health = max(0.0, health - damage)
  }
  func canLift(_ weight: Int) -> Bool {
    weight < strength * 100
  }
}
```

يمكن استدعاء هذه الطرق باستخدام ترميز النقطة، تمامًا مثل الخصائص.

```swift
var stats = CharacterStats(health: 72.8, speed: 19, strength: 6)
stats.canLift(500)
// => true
```
