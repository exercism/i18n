# حول

تناول مفهوم [الأزواج والقواميس][pairs-dicts] أساسيات نوع القاموس في Julia.

ولأن [`Dict`s][dict] نوع مجموعة مهم وكثير الاستخدام، فهناك أيضًا دوال كثيرة للتعامل معها.

## الحصول على المدخلات

أبسط طريقة لاسترجاع مدخل هي عبر المفتاح (كما هو الحال في كثير من اللغات). لكن طلب مفتاح غير موجود يؤدي إلى `KeyError`.

```julia-repl
julia> d = Dict(i => ('a':'c')[i] for i in 1:3)
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'

julia> d[2]
'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)

# missing key
julia> d[4]
ERROR: KeyError: key 4 not found
```

كان بإمكاننا التحقق من وجود المفتاح قبل محاولة استرجاعه (بشيء مثل `haskey(d, 4)` أو `4 ∈ keys(d)`)، لكن قد يكون من المفيد ببساطة الحصول على قيمة افتراضية للمفاتيح المفقودة.

لهذا الغرض لدينا الدالة [`get()`][get] ونسختها المعدِّلة [`get!()`][get-bang]. ويختلف الاثنان في ما إذا كان المفتاح «المفقود» يُضاف إلى `Dict` أم لا.

```julia-repl
julia> get(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)

# get() leaves Dict unchanged
julia> d
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'

julia> get!(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)

# get!() adds new key to Dict
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'
```

رأينا في المفهوم السابق أن `delete!()` تحذف مدخلًا بالمفتاح. ويمكن الجمع بين ذلك واسترجاع القيمة باستخدام الدالة `pop!()`.

```julia-repl
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'

# popped value is returned
julia> pop!(d, 3)
'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)

# Dict is shrunk
julia> d
Dict{Int64, Char} with 3 entries:
  4 => '!'
  2 => 'b'
  1 => 'a'
```

## التكرار

يؤدي التكرار على `Dict` افتراضيًا إلى إنتاج أزواج `key => value`. ويمكن الوصول إلى المكوّنَين بالتسمية المعتادة `.first` و`.second`.

```julia-repl
# d is from the previous example
julia> [(kv.first, kv.second) for kv in d]
3-element Vector{Tuple{Int64, Char}}:
 (4, '!')
 (2, 'b')
 (1, 'a')
```

غالبًا ما نريد استخدام المفاتيح فقط أو القيم فقط، وهذا أمر سهل.

```juliajulia> [k for k in keys(d)]
julia> [k for k in keys(d)]
3-element Vector{Int64}:
 4
 2
 1

julia> [v for v in values(d)]
3-element Vector{Char}:
 '!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
```

## الدمج

قد يكون دمج اثنين من `Dict` مفيدًا، لكن علينا أن نكون واضحين بشأن ما ننوي فعله بالمفاتيح الموجودة في أكثر من مُدخل واحد.

تجمع الدالتان [`merge()`][merge] و[`merge!()`][merge-bang] أي عدد من كائنات `Dict` المُعطاة، من اليسار إلى اليمين.

تُستبدل قيم المفاتيح الموجودة ببساطة، لذا فإن `Dict` الواقع في أقصى اليمين هو الذي «يفوز».

```julia-repl
julia> d3 = Dict("color" => "red", "shape" => "circle")
Dict{String, String} with 2 entries:
  "shape" => "circle"
  "color" => "red"

julia> d4 = Dict("color" => "blue", "coords" => (3, 2))
Dict{String, Any} with 2 entries:
  "color"  => "blue"
  "coords" => (3, 2)

# color from d3 is lost
julia> merge(d3, d4)
Dict{String, Any} with 3 entries:
  "shape"  => "circle"
  "color"  => "blue"
  "coords" => (3, 2)
```

تتيح لنا الدالتان [`mergewith()`][mergewith] و[`mergewith!()`][mergewith-bang] تمرير دالة كوسيط أول، لتحديد كيفية دمج المفاتيح المكرّرة. والجمع مثال بسيط على ذلك.

```julia-repl
julia> d5 = Dict("color" => "red", "area" => 3)
Dict{String, Any} with 2 entries:
  "area"  => 3
  "color" => "red"

julia> d6 = Dict("shape" => "circle", "area" => 5)
Dict{String, Any} with 2 entries:
  "shape" => "circle"
  "area"  => 5

# area values are added, not overwritten
julia> mergewith(+, d5, d6)
Dict{String, Any} with 3 entries:
  "shape" => "circle"
  "area"  => 8
  "color" => "red"
```

يُعدّ ربط متجهين عملية شائعة أخرى عند الدمج. ولهذا تستخدم Julia الدالة [`vcat()`][vcat]، للأسباب الموضحة في مفهوم [`Multi Dimensional Arrays`][multidim].

```julia-repl
julia> d7 = Dict("vals" => [1, 2, 3])
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [1, 2, 3]

julia> d8 = Dict("vals" => [4, 5])
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [4, 5]

julia> mergewith(vcat, d7, d8)
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [1, 2, 3, 4, 5]
```

أما بالنسبة لعدة [`Set`s][sets]، فدالة الدمج المقابلة هي [`union`][union].

لاحظ أن دوال `mergewith` مثال جيد على [الدوال ذات الرتبة الأعلى][hof] وهي تعمل.
