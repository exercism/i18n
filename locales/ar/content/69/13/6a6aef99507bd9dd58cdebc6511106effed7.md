# التعليمات

في هذا التمرين ستكتب بعض الكود لمساعدة Larry the Lisp Alien على تحليل سلاسل السجل وتنسيقها. تأتي هذه السلاسل النصية من أنظمة مختلفة وتحتاج إلى معالجة حتى يمكن عرض رسائلها على شاشة مراقبة مفيدة.

تأتي سلاسل السجل بالشكل `"[<level>]: <message>"`. وتكون قيمة المستوى واحدة من القيم التالية: `info` أو `warn` أو `ohno`.

## 1. استخراج الرسالة

عرّف دالة `log-message` تأخذ سلسلة سجل وتُقيّم إلى الرسالة التي تحتويها.

```lisp
(log-message "[ohno]: whoops!") ; => "whoops!"
```

## 2. تحديد درجة الخطورة

يحدد مستوى سلسلة السجل درجة خطورتها.

- مستوى `info` يعني درجة الخطورة `:everything-ok`
- مستوى `warn` يعني درجة الخطورة `:getting-worried`
- مستوى `ohno` يعني درجة الخطورة `:run-for-cover`

عرّف دالة `log-severity` تأخذ سلسلة سجل وتُقيّم إلى درجة الخطورة الصحيحة.

```lisp
(log-severity "[warn]: might want to get that checked") ; => :getting-worried
```

## 3. التعامل مع تقلّبات الواقع

لسوء الحظ، لا تكون سلاسل السجل منسّقة تنسيقًا صحيحًا دائمًا. وتحديدًا، قد لا يكون مستوى السجل بأحرف صغيرة كلها كما هو موضح أعلاه. عدّل `log-severity` للتعامل مع هذا.

```lisp
(log-severity "[WaRn]: string case system failing") ; => :getting-worried
```

## 4. إعادة تنسيق رسالة السجل وفقًا لدرجة خطورة السجل

تبعًا لدرجة الخطورة، ينبغي تعديل الرسالة بطرق مختلفة:

- درجة الخطورة `:everything-ok` ينبغي أن تتحول رسالتها إلى أحرف صغيرة كلها.
- درجة الخطورة `:getting-worried` ينبغي أن تتحول رسالتها بحيث تبدأ كل كلمة فيها بحرف كبير.
- درجة الخطورة `:run-for-cover` ينبغي أن تتحول رسالتها إلى أحرف كبيرة كلها.

عرّف دالة `log-format` تأخذ رسالة سجل وتُقيّم إلى رسالة منسّقة تنسيقًا صحيحًا.

```lisp
(log-format "[ohno]: whoops!") ; => WHOOPS!
```
