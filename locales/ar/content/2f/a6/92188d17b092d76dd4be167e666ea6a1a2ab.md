# المقدمة

لغة C لغة ذات أنواع ثابتة، وهذا يعني أن لكل شيء نوعًا في وقت الترجمة.
يُسمّى اختيار اسم للمتغير وتحديد نوعه الإعلانَ عن المتغير.

يُعلن عن المتغير بتحديد نوعه صراحةً.
ويجب أن يبدأ اسم المتغير بحرف أو بشرطة سفلية.
ولا يمكن استخدام بعض الأسماء لأنها محجوزة [للكلمات المفتاحية][reserved-keywords] أو [لمعرّفات أخرى][reserved-identifiers].

يتم ضبط قيمة المتغير أو تحديثها عبر إسناد المتغير.
فتحديد القيمة يعرّف ذلك المتغير.
ويُعرف تعريف المتغير أيضًا بالتهيئة.

```c
int foo;      // Declare an integer named var
foo = 10;     // Define the variable

int bar = 15; // Both can also be done in a single statement
```

يمكن إسناد قيمة المتغير وتحديثها باستخدام عامل الإسناد البسيط `=`.
وبمجرد تعريف المتغير، لا يمكن أن يتغير نوعه أبدًا.

```c
int foo = 10; // Assign initial value
foo = 25;     // Update to new value

foo = false;  // Compiler error when assigning value of a different type
```

لغة C لغة إجرائية أمرية.
تُنفَّذ كل العمليات الحسابية ضمن مجموعة من العبارات التي تشكل جزءًا من دالة واحدة أو من عدة دوال.

يمكن أن يكون لكل دالة صفر من المعاملات أو أكثر.
وعند تعريف دالة، يجب تحديد نوع جميع المعاملات وقيمة الإرجاع صراحةً.
وتُرجع الدوال القيم باستخدام الكلمة المفتاحية `return`.
وللدوال فئة تخزين خارجية افتراضيًا، أي أنها تبقى موجودة طوال عمر البرنامج ويمكن أن تكون مرئية خارج الملف.
ولمنع ذلك يمكن إضافة الكلمة المفتاحية `static` لتحديد رؤية داخلية.

```c
static int add(int x, int y) {
  return x + y;
}
```

في المثال أعلاه، لا يمكن استخدام المتغيرين `x` و`y` إلا داخل الدالة، أي أن لهما نطاق الدالة.
والنطاق يعني أن القيمة المرتبطة باسم (لعنصر برمجي) لا يمكن الوصول إليها إلا ضمن "المنطقة" من الكود التي عُرّفت فيها.
ومناطق الكود الرئيسية في لغة C هي:

- الملف
- الدالة
- الكتلة (كما في الحلقات وتراكيب أخرى)

تُستدعى الدوال بتحديد اسم الدالة وتمرير وسائط لكل من معاملات الدالة.

```c
int sum = add(1, 2);
```

تدعم لغة C نوعين من التعليقات.
تسبق التعليقات أحادية السطر علامة `//` (منذ C99)، أما التعليقات متعددة الأسطر فتوضع بين `/*` و`*/`.
