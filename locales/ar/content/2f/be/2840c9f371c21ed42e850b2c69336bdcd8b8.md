# مقدمة

## السلاسل النصية

`string` في C# هو كائن يمثّل نصًا غير قابل للتغيير على هيئة تسلسل من محارف يونيكود (حروف وأرقام وعلامات ترقيم وما إلى ذلك). تُستخدم علامات الاقتباس المزدوجة لتعريف كائن من `string`:

```csharp
string fruit = "Apple";
```

### الطرق

تُعالَج السلاسل النصية عن طريق استدعاء [الطرق المدمجة][docs-string-methods] الخاصة بها.
على سبيل المثال، لإزالة المسافات البيضاء من سلسلة نصية، يمكنك استخدام [الطريقة `Trim`][tutorial-docs.microsoft.com-trim-white-space] هكذا:

```csharp
string name = " Jane "
name.Trim()
// => "Jane"
```

بمجرد إنشاء سلسلة نصية، لا يمكن أن تتغير قيمتها أبدًا.
أي طرق تبدو وكأنها تعدّل سلسلة نصية ستُرجع في الواقع سلسلة نصية جديدة.

### الدمج

يمكن دمج عدة سلاسل نصية (إضافتها) معًا. أسهل أسلوب لتحقيق ذلك هو استخدام عامل `+`.

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

### التنسيق

لأي تنسيق سلاسل نصية أكثر تعقيدًا من الدمج البسيط، يُفضَّل استخدام تداخل السلاسل النصية. لاستخدام التداخل في سلسلة نصية، ضع رمز الدولار (`$`) في بدايتها. ثم يمكنك استخدام الأقواس المعقوفة (`{}`) للوصول إلى أي متغيرات داخل السلسلة النصية.

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
