# ملحق التعليمات

## تنسيق اللوحة

تُمثَّل اللوحة بسلسلة نصية منتهية بمحرف `null`، مع محرف سطر جديد في نهاية كل صف.

ومن الأمثلة على ذلك `"X  \n XO\nOX \n"`

## السجلات

| السجل   | الاستخدام     | النوع   | الوصف                                                                   |
| -------- | ------------ | ------- | ----------------------------------------------------------------------- |
| `$a0`    | إدخال        | عنوان   | سلسلة إدخال نصية منتهية بمحرف `null`                                    |
| `$v0`    | إخراج        | عدد صحيح | حالة اللعبة (`1` = `ongoing`، `2` = `draw`، `3` = `win`، `-1` = `error`) |
| `$t0-9`  | مؤقت         | أي      | لتخزين مؤقت                                                             |
