# نبذة

البنية الأساسية للبرمجة الكائنية في C# هي _الصنف_، وهو مزيج من البيانات ([_الحقول_][fields]) والسلوك ([_الطرق_][methods]). وتُعرف حقول الصنف وطرقه باسم _أعضائه_.

يمكن تقييد الوصول إلى الأعضاء عبر محددات الوصول، وأكثرها شيوعًا اثنان:

- [`public`][public]: يمكن لأي كود الوصول إلى العضو (بلا قيود).
- [`private`][private]: لا يمكن الوصول إلى العضو إلا من الكود الموجود في الصنف نفسه.

من المعتاد تحديد محدد وصول لكل الأعضاء. وإذا لم يُحدَّد أي محدد وصول، فسيُعتمد على `private` افتراضيًا.

تُعرف هذه المجموعة من البيانات والسلوك المرتبطين، مع تقييد الوصول إلى الأعضاء، باسم [التغليف][encapsulation]، وهو أحد المفاهيم الأساسية في البرمجة الكائنية.

وتُعرف مجموعة قيم حقول كائن ما في لحظة معينة باسم [حالة][object-state] الكائن.

يمكنك أن تتخيل الصنف كقالب لإنشاء نسخ منه. ولـ[إنشاء نسخة من صنف][creating-objects] (تُعرف أيضًا باسم _الكائن_)، تُستخدم [الكلمة المفتاحية `new`][new]:

```csharp
class Car
{
}

// Create two car instances
var myCar = new Car();
var yourCar = new Car();
```

[الحقول][fields] لها نوع، ويمكن تعريفها في أي مكان داخل الصنف.
تُعرَّف الحقول العامة بأسلوب [PascalCase][pascal-case]، وتُعرَّف الحقول الخاصة بأسلوب [camelCase][camel-case] مع بادئة شرطة سفلية `_`:

```csharp
class Car
{
    // Accessible by anyone
    public int Weight;

    // Only accessible by code in this class
    private string _color;
}
```

يمكنك اختياريًا إسناد قيمة ابتدائية لحقل ما. وإذا لم يحدد الحقل قيمة ابتدائية، فسيُضبط على [القيمة الافتراضية][default-values] لنوعه. ويمكن الوصول إلى قيم حقول النسخة وتحديثها باستخدام الترميز النقطي.

```csharp
class Car
{
    // Will be set to specified value
    public int Weight = 2500;

    // Will be set to default value (0)
    public int Year;
}

var newCar = new Car();
newCar.Weight; // => 2500
newCar.Year;   // => 0

// Update value of the field
newCar.Year = 2018;
```

عادةً ما تُحدَّث الحقول الخاصة كأثر جانبي لاستدعاء طريقة ما. وهذه الطرق لا تُرجع أي قيمة عادةً، وفي هذه الحالة يجب أن يكون نوع الإرجاع [`void`][void]:

```csharp
class CarImporter
{
    private int _carsImported;

    public void ImportCars(int numberOfCars)
    {
        // Update private field
        _carsImported = _carsImported + numberOfCars;
    }
}
```

لاحظ أنه ليس من المعتاد استخدام حقول عامة في أصناف C#. فإما أن تُستخدم حقول خاصة، أو أنواع أخرى من الأعضاء ستُناقش في تمارين لاحقة.

داخل الصنف، تشير [الكلمة المفتاحية `this`][this] إلى الصنف الحالي. وهذا مفيد بشكل خاص إذا كان لمعامل ما الاسم نفسه الذي لحقل:

```csharp
class CarImporter
{
    private int carsImported;

    public void SetImportedCars(int carsImported)
    {
        // Update private field from public method
        this.carsImported = carsImported;
    }
}
```

يوفّر تركيب الصنف والطريقة أسلوبًا طبيعيًا للحد من ظهور عناصر البرنامج مثل الحقول والطرق، ولتجنّب [مشكلة الحالة العامة][so-global-state-problem] الشهيرة. يجب تأهيل الحقول والطرق العامة وغيرها من الأعضاء باسم الكائن، `object.field` أو `object.method()`، (أو اسم الصنف في حالة العناصر الساكنة) كي يراها الكود خارج الصنف. أما المتغيرات والمعاملات المعرَّفة داخل طريقة ما فلا تُرى إلا داخل تلك الطريقة.

من الأمور التي يجب الحذر منها في هذا الأسلوب أنه إذا تطابق اسم حقل مع اسم متغير أو معامل داخل طريقة، فسيتجاهل الكود داخل الطريقة اسم الحقل، وقد لا يكون هذا ما تريده. وبشكل عام، يُستحسن تجنّب ذلك متى أمكن، رغم أنه نمط شائع في البواني. وإذا كان من المناسب أن يتطابق اسم الحقل مع اسم المتغير، فأهّل اسم الحقل بالكلمة المفتاحية `this` داخل الطريقة.

ويمكن استخدام [محددات الوصول][access-modifiers] هذه لمزيد من الحد من الظهور.
