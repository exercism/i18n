# مقدمة

تذكّر من مفهوم الأساسيات أن برنامج AWK يتكوّن من **أزواج النمط والإجراء**.

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

## ما الذي نعنيه بـ«النمط»؟

«النمط» هو أي تعبير في AWK.
وكون نتيجة التعبير صحيحة هو ما يحدد ما إذا كان الإجراء سيُنفَّذ.

## النمط الفارغ

يمكن حذف النمط.
في هذه الحالة، يُنفَّذ الإجراء لكل سجل.

يمكننا طباعة جميع أسماء المستخدمين في ملف `passwd`.

```sh
awk -F: '{print $1}' /etc/passwd
```

## التعبيرات النمطية

يستطيع AWK مقارنة السلاسل النصية بالتعبيرات النمطية للحصول على قيمة منطقية.

استخدم العامل `~` الخاص بمطابقة التعبيرات النمطية لمطابقة حقل معيّن.
يأخذ هذا العامل سلسلة نصية في طرفه الأيسر، وتعبيرًا نمطيًا في طرفه الأيمن.
أما التعبير النمطي الحرفي فيُحاط بشرطتين مائلتين `/`.

للعثور على المستخدمين في ملف `passwd` الذين يسجّلون الدخول باستخدام `bash`:

```sh
awk -F: '$7 ~ /bash/ {print $1}' /etc/passwd
```

`!~` هو عامل «**عدم** مطابقة» التعبير النمطي.

لمطابقة تعبير نمطي مع السجل الحالي، يمكنك كتابة `$0 ~ /regex/`.
هذا شائع لدرجة وجود صيغة مختصرة: يمكنك حذف `$0` و `~` وكتابة `/regex/` مباشرة.

```sh
awk '/regex/' data.txt
```

~~~~exercism/note
قارن أمر AWK المكوّن من سطر واحد بأمر `grep` المكافئ

```sh
grep 'regex' data.txt
```

يمنحك AWK لغة برمجة كاملة دون التضحية بالإيجاز.
~~~~

سنتعمّق أكثر في صيغة التعبيرات النمطية في GNU AWK في مفهوم لاحق.

## التعبيرات

يمكن استخدام تعبيرات AWK (الحسابية أو المنطقية أو غيرها) كأنماط.

لاستخراج جميع المستخدمين ذوي UID يساوي 1000 أو أكثر:

```sh
awk -F: '$3 >= 1000' /etc/passwd
```

تذكّر أن القيم التي تعتبر خطأ في AWK هي العدد صفر والسلسلة النصية الفارغة، وأن كل الأعداد أو السلاسل النصية الأخرى تعتبر صحيحة.
أي تعبير يُقيَّم إلى عدد أو سلسلة نصية يمكن استخدامه كنمط.

## الدوال

يمكن استخدام أي دالة [مدمجة][builtins] أو [معرّفة من المستخدم][user-defined] في تعبير، وبالتالي في النمط.
مثالان:

```awk
length($1) {print "first field is not empty"}
```
```awk
toupper(substr($1, 1, 1)) ~ /[AEIOU]/ {print "starts with a vowel"}
```

## الأنماط الثابتة

من الصيغ الشائعة في AWK:

```sh
{
    xyz()   # some code that transforms each record
}
1
```

`1` نمط قيمته صحيحة وليس له إجراء مرتبط.
وهذا يعني «اطبع السجل الحالي».
