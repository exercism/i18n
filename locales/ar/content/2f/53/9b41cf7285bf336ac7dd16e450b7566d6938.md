# ملحق التعليمات

## السجلات

| السجل | الاستخدام | النوع | الوصف |
| -------- | --------- | ------- | ------------------------------------------------------ |
| `$a0`    | إدخال     | عنوان | سلسلة نصية مُدخلة منتهية بـ null                           |
| `$v0`    | إخراج     | قيمة منطقية | صلاحية السلسلة النصية المُدخلة (`0` = `false`، `1` = `true`) |
| `$t0-9`  | مؤقت | أي     | تُستخدم للتخزين المؤقت                             |
