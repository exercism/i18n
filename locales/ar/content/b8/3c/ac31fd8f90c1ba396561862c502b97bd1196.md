# مقدمة إلى المصفوفات

في Java، تتيح لك المصفوفات تخزين عدة قيم من النوع نفسه في بنية واحدة.
وعلى خلاف بنى البيانات الأخرى، يكون حجم المصفوفة ثابتًا بمجرد إنشائها.
يمكن إسناد العناصر إلى المصفوفة أو استرجاعها منها باستخدام فهرس.
تستخدم مصفوفات Java فهرسة تبدأ من الصفر: فهرس العنصر الأول هو 0، وفهرس العنصر الثاني هو 1، وهكذا.

إليك الصيغة القياسية لتهيئة مصفوفة:

```java
type[] variableName = new type[size];
```

يمثّل `type` نوع العناصر في المصفوفة، وقد يكون نوعًا أوليًا (مثل `int`) أو صنفًا (مثل `String`).

أما `size` فهو عدد العناصر التي ستضمّها هذه المصفوفة (ولا يمكن تغييره لاحقًا).
بعد إنشاء المصفوفة، تُهيَّأ العناصر إلى قيمها الافتراضية (عادةً `0` أو `false` أو `null`).

```java
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];
```

يمكن أيضًا تعريف المصفوفات باستخدام صيغة مختصرة تتيح لك إنشاء المصفوفة وتحديد قيمها في الوقت نفسه:

```java
// Two equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = { 4, 9, 7 };
```

ولأن المترجم يستطيع الآن معرفة عدد العناصر التي ستحتوي عليها المصفوفة، يمكن حذف الطول.

يمكن إسناد عناصر المصفوفة والوصول إليها باستخدام تدوين الفهرس بين الأقواس المربعة:

```java
// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index and assign to the int element
int secondElement = twoInts[1];
```

الوصول إلى فهرس خارج نطاق الفهارس الصالحة للمصفوفة يُسبّب استثناءً من النوع `IndexOutOfBoundsException`.

يمكن التعامل مع المصفوفات إما باستدعاء طُرق نسخة المصفوفة أو خصائصها، وإما باستخدام الطُرق الساكنة المعرّفة في صنف `Arrays` (والتي تُستخدم عادةً في الكود الذي يعتمد على الأنواع العامة فقط).
تحمل الخاصية `length` طول المصفوفة.
ويمكن الوصول إليها هكذا:

```java
int arrayLength = someArray.length;
```

توفّر Java أيضًا صنفًا مساعدًا مفيدًا هو [`java.util.Arrays`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/Arrays.html)، ويتضمّن كثيرًا من الطُرق المفيدة المتعلقة بالمصفوفات (مثل `Arrays.equals`).

تدعم Java أيضًا [المصفوفات متعددة الأبعاد](https://www.programiz.com/java-programming/multidimensional-array) مثل `int[][] arr = new int[3][4];`، وهي مفيدة جدًا.

كون المصفوفة أيضًا _مجموعة_ يعني أنه، إلى جانب الوصول إلى القيم عبر الفهرس، يمكنك المرور على _كل_ قيمها باستخدام حلقة `for-each`:

```java
char[] vowels = { 'a', 'e', 'i', 'o', 'u' };

for(char vowel: vowels) {
    // Output the vowel
    System.out.print(vowel);
}

// => aeiou
```

وإذا أردت تحكمًا أكبر في القيم التي تمرّ عليها، فيمكنك استخدام حلقة `for`:

```java
char[] vowels = { 'a', 'e', 'i', 'o', 'u' };

for (int i = 0; i < 3; i++) {
    // Output the vowel
    System.out.print(vowels[i]);
}

// => aei
```
