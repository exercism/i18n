# الجمل الشرطية

تحتوي Crystal على ما يُعرف بتعبيرات التحكم، وهي تُستخدم للتحكم في طريقة سير البرنامج، وتأخذ قيمة صحيحة أو خاطئة.
وهناك عوامل يمكن استخدامها لإنشاء قيم صحيحة أو خاطئة، وتُعرف باسم [عوامل المساواة والمقارنة][equality-and-comparison].

هناك تعبيرا تحكم رئيسيان يُستخدمان للتحكم في الكود الذي سيعمل والذي لن يعمل، أي تحديد الفرع الذي سيُنفَّذ.

وهما: تعبير `if` وتعبير `unless`.

## عوامل المقارنة

تُستخدم عوامل المقارنة لمقارنة القيم وإرجاع قيمة `true` أو `false`.
تتطلب هذه العوامل قيمتين من النوع نفسه لتتم المقارنة بينهما.
وإذا لم تكن القيمتان من النوع نفسه، فسيُطلق المصرِّف خطأً.
فيما يلي قائمة بعوامل المقارنة ومثال على الحالة التي تُرجع فيها قيمة `true`:

| العامل | الوصف           | المثال |
| ------ | --------------------- | ------- |
| <      | أصغر من             | 4 < 5   |
| <=     | أصغر من أو يساوي    | 4 <= 4  |
| >      | أكبر من          | 3 > 1   |
| >=     | أكبر من أو يساوي | 2 >= 2  |

## عوامل المساواة

عوامل المساواة مشابهة لعوامل المقارنة، لكنها تُستخدم للتحقق مما إذا كانت قيمتان متساويتين أم لا.

يتحقق العامل `==` مما إذا كانت قيمتان متساويتين، بما في ذلك نوع القيمة.
فإذا كانت القيمتان متطابقتين فسيُرجع `true`، وإلا فسيُرجع `false`.
ويستطيع العامل `==` مقارنة أي نوع من القيم مع أي نوع آخر.
ويعمل العامل `!=` بالأسلوب نفسه، لكنه سيُرجع `true` إذا لم تكن القيمتان متساويتين، و`false` إذا كانتا متساويتين.

## جملة `if` الشرطية

تُستخدم جملة [`if`][if] الشرطية للتحقق مما إذا كان شرط معين صحيحًا أو خاطئًا.
إذا كان الشرط صحيحًا، فسيُنفَّذ الكود الموجود داخل جملة `if`.
وتنتهي جملة `if` بالكلمة المفتاحية `end`.

```crystal
if 1 == 1
  puts "1 is equal to 1"
end
# => 1 is equal to 1

if 1 > 2
  puts "1 is greater than 2"
end
# => no output
```

## جملة `unless` الشرطية

تعمل جملة [`unless`][unless] الشرطية بشكل مشابه جدًا لجملة `if`، لكنها تُنفِّذ الكود الموجود داخل جملة `unless` إذا كان الشرط خاطئًا.

```crystal
unless 1 == 1
  puts "1 is not equal to 1"
end
# => no output

unless 1 > 2
  puts "1 is not greater than 2"
end
# => 1 is not greater than 2
```

## جملة `else` الشرطية

يمكن استخدام جملة `else` مع جملتي `if` و`unless`.
وتُنفَّذ جملة `else` إذا لم يُنفَّذ فرع `if` أو فرع `unless`.

~~~~exercism/warning
حتى وإن كان يمكن استخدام فرع `else` مع `unless,` فمن غير المستحسن فعل ذلك لأنه يضر بقابلية القراءة.
وبدلًا من ذلك، يُوصى باستخدام `if !condition` مع فرع `else`.
~~~~

```crystal
if 1 == 1
  puts "1 is equal to 1"
else
  puts "1 is not equal to 1"
end
# => 1 is equal to 1

unless 1 < 2
  puts "1 is not greater than 2"
else
  puts "1 is greater than 2"
end
# => 1 is greater than 2
```

## الجمل الشرطية المتتالية

يمكن استخدام جملة `elsif` مع جملة `if`.
وتُنفَّذ جملة `elsif` إذا لم يُنفَّذ فرع `if` وكان شرط جملة `elsif` صحيحًا.
ويمكن ربط جمل `elsif` ببعضها، وسيُنفَّذ أول شرط صحيح.
ويمكن أيضًا وجود جملة `else` في نهاية جملة `if`، وستُنفَّذ إذا لم يكن أي من الجمل السابقة صحيحًا.

```crystal
if 1 != 1
  puts "1 is not equal to 1"
elsif 1 > 2
  puts "1 is greater than 2"
else
  puts "1 is not equal to 1 and 1 is not greater than 2"
end
# => 1 is not equal to 1 and 1 is not greater than 2
```

## الأنواع مع الجمل الشرطية

عند الإسناد إلى أنواع مختلفة، سيحمل المتغير النوعين معًا.
وهذا لأن المصرِّف لا يعرف أي فرع سيُنفَّذ.
هذا الإسناد المتعدد، المعروف أيضًا باسم الاتحاد، سيُشرح في مفاهيم لاحقة.
ويمكن ملاحظة ذلك في المثال التالي:

```crystal
if 1 == 1
  a = 1
else
  a = "1"
end

typeof(a) # => Int32 | String
```

## العامل الثلاثي

تمتلك Crystal عاملًا ثلاثيًا، وهو جملة `if`-`else` في سطر واحد: `condition ? expression_if_truthy : expression_if_falsey`

```crystal
1 == 1 ? puts("1 is equal to 1") : puts("1 is not equal to 1")
# => 1 is equal to 1
```
