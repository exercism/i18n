# مقدمة

## صحيح وخطأ

تُمثَّل الحالتان المنطقيتان، صحيح وخطأ، بالرمزين `true` و`false` في Ruby.
ويمكن استخدامهما كقيم حرفية بمفردهما، أو الحصول عليهما كنتيجة لطرق منطقية أو طرق مقارنة.

```ruby
happy = true
sad = false

true && false
# => false

1 < 2
# => true
```

## _الصادق_ و_الكاذب_

عند تقييم الكائنات في الجمل الشرطية `if` أو في سياقات منطقية أخرى، تُقيَّم جميع الكائنات على أنها _صادقة_، **باستثناء** `false` و `nil`.

## التحكم في مسار التنفيذ

تقييمات _الصادق_ و_الكاذب_ مفيدة في سياق التحكم في مسار التنفيذ.
وكما هو الحال في اللغات الإجرائية، توفّر Ruby تركيب `if`...`else`، لكن قد يكون من الأكثر شيوعًا استخدام `if` كعبارة «حارسة» لتعديل تقييم تعبير.

```ruby
def falsey
  nil || false
end

def truthy
  not falsey
end

if truthy
  # this block is evaluated
end

if falsey
  # this block is not evaluated
else
  # this block is evaluated
end

1 + 1 if truthy
# this will evaluate and return 2

2 + 2 if falsey
# the numbers are not added because of the modifier, nil is returned
```

توفّر Ruby الكلمة `unless` لجعل الكود يُقرأ بشكل جيد.
مثال: بدلًا من `eat_desert if not too_full`، يمكننا أيضًا كتابة `eat_desert unless too_full`.

```ruby
3 + 3 unless truthy
# the numbers are not added because of the modifier, nil is returned

4 + 4 unless falsey
# this will evaluate and return 8
```
