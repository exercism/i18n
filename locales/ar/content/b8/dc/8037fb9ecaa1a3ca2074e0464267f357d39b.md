# الأصناف ذات الحالة

```sather
class SCOREBOARD is

   attr home_team, away_team : STR;
   attr home_score, away_score : INT;

   create(home, away : STR) : SAME is
      board ::= new;
      board.home_team := home;
      board.away_team := away;
      return board;
   end;

   home_goal is home_score := home_score + 1; end;

end; -- class SCOREBOARD
```

## attr, readonly attr, private attr

| مكتوب | يُقرأ من الخارج | يُغيَّر من الخارج |
| --- | --- | --- |
| `attr x : INT` | نعم | نعم |
| `readonly attr x : INT` | نعم | لا |
| `private attr x : INT` | لا | لا |

`readonly` هو الخيار الافتراضي الذي ينبغي اللجوء إليه. فهو يتيح لأي شخص رؤية النتيجة، ويشترط أن يمر أي تغيير لها عبر `home_goal`، وهو الموضع الذي تقيم فيه قواعد احتساب النقاط.

## create و new

`new` يُنشئ كائنًا من هذا الصنف تكون كل خصائصه فارغة. ولا يجوز استخدامه إلا داخل الصنف.

`create` هو روتين عادي له اسم متفق عليه: `#C(args)` هو بالضبط `C::create(args)`. ويمكن للصنف أن يضم عدة روتينات منه، تُميَّز بوسائطها، أما الصنف الذي لا يملك أيًّا منها فلا يمكن إنشاؤه بـ `#` ببساطة.

## SAME

`SAME` يشير إلى الصنف المكتوب فيه. وهو في `create` نوع الإرجاع؛ كما يُستخدم في الوسيط، وهو ما يجعل الروتين الموروث يتحدث عن الصنف الوارث بدلًا من الصنف الذي جاء منه.

## روتينات بلا نوع إرجاع

```sather
   home_goal is
      home_score := home_score + 1;
   end;
```

لا وجود لـ `:` ولا لنوع. وروتين كهذا يُستدعى كعبارة، ولا يمكن أن يظهر في تعبير. وهو علامة على أن الهدف من الاستدعاء هو التغيير الذي يُحدثه.

## self

داخل الروتين، `self` هو الكائن الذي استُدعي عليه. ونادرًا ما يُكتب صراحةً، لأن ذكر خاصية أو روتين بمفرده يعني بالفعل أنه يخص `self`. وهو ضروري عندما يلزم تمرير الكائن أو إرجاعه:

```sather
   with_goal : SAME is
      home_score := home_score + 1;
      return self;
   end;
```

`self` و`new` و`void` و`result` و`value` و`out` كلمات حجزتها Sather، ولا يمكن استخدام أيٍّ منها اسمًا خاصًا بك.

## مرجع لا قيمة

يُتوصل إلى الكائن عبر مرجع. وواسمان لنفس لوحة النتائج يريان النتيجة نفسها:

```sather
   a ::= #SCOREBOARD("Vixens", "Magpies");
   b ::= a;         -- not a copy
   b.home_goal;
   a.home_score     -- 1
```

`immutable class`، الذي سنراه لاحقًا، هو السبيل إلى السلوك الآخر.
