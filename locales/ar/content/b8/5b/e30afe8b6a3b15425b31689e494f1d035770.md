# المديات

[المديات][range] تمثّل فترة بين قيمتين.
أكثر الأنواع شيوعًا التي تدعم المديات هي `Int` و`Char` و`String`.
ويمكن استخدامها في أمور كثيرة، مثل إنشاء مجموعة بسرعة، وتقطيع السلاسل النصية، والتحقق مما إذا كانت قيمة ما تقع ضمن المدى، والتكرار.
وتُنشأ باستخدام عامل المدى `..` أو `...` (شامل وغير شامل على الترتيب).

```crystal
1..5  # A range containing 1, 2, 3, 4, 5
1...5 # A range containing 1, 2, 3, 4
```

السبب في وجود عاملي المدى هو إنشاء مديات شاملة أو غير شاملة لقيمة النهاية، وهو ما يفيد عندما تعمل، على سبيل المثال، مع الفهارس التي تبدأ من الصفر.

ويمكن أيضًا إنشاء المديات باستخدام دالة التهيئة `Range`.

```crystal
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
عند إنشاء مدى في Crystal باستخدام عاملي المدى `..` أو `...`، ثم رغبت في استدعاء طريقة على المدى، فستحتاج إلى إحاطة المدى بالأقواس الهلالية.
وذلك لأن الطريقة ستُستدعى، بخلاف ذلك، على الوسيط الثاني لعامل المدى.

```crystal
(1..5).size # => 5
1..5.size # => Error: undefined method 'size' for Int32
```
~~~~

## الحصول على السلاسل الفرعية

عند رغبتك في تقطيع سلسلة نصية، يمكنك استخدام عامل المدى للحصول على سلسلة فرعية.
أي بإنشاء مدى بفهرس البداية وفهرس النهاية للسلسلة الفرعية.

```crystal
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

ويمكنك أيضًا استخدام فهارس سالبة للحصول على السلسلة الفرعية من نهاية السلسلة النصية.

```crystal
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## طرق المدى

للمديات مجموعة من الطرق التي يمكن استخدامها للتعامل معها.
على سبيل المثال، يمكن استخدام هذه الطرق للحصول على مجموع كل القيم في المدى أو للتحقق مما إذا كان المدى يشمل قيمة ما.

| الطريقة                 | الوصف                                                             | المثال                         |
|-------------------------|-------------------------------------------------------------------------|---------------------------------|
| [`sum`][sum]            | تُرجع مجموع كل القيم في المدى                          | `(1..5).sum # => 15`            |
| [`size`][size]          | تُرجع حجم المدى                                           | `(1..5).size # => 5`            |
| [`includes?`][indludes] | تُرجع `true` إذا كان المدى يشمل القيمة المعطاة، وإلا فتُرجع `false` | `(1..5).includes?(3) # => true` |

## المديات اللامنتهية والتي بلا بداية

يمكن أن يكون المدى لامنتهيًا وبلا بداية.
المدى اللامنتهي أو الذي بلا بداية تكون قيمة بدايته أو نهايته مساوية لـ `nil`، لكن يمكن حذف `nil` عند تعريف المدى.

يفيد استخدام المديات التي بلا بداية واللامنتهية عندما تريد، على سبيل المثال، تقطيع سلسلة نصية من البداية أو حتى النهاية.

```crystal
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
قد يسبب المدى اللامنتهي تسلسلًا لا نهائيًا إذا لم يُستخدم بحذر ولم يُطبَّق على مجموعة.
~~~~

## مديات Char

يمكن استخدام الأحرف في المديات، مما يتيح لك الحصول على فترة من الأحرف بين حرفين.
على سبيل المثال، يفيد هذا عندما تريد الحصول على الأبجدية.

```crystal
'a'..'z' # A range containing ['a', 'b', 'c', ..., 'z']
```

## مديات السلاسل النصية

يمكن أيضًا استخدام السلاسل النصية في المديات، مما يتيح الحصول على فترة من السلاسل النصية بين سلسلتين نصيتين.
لكن سلوكها يختلف قليلًا عن سلوك `Char` عند استخدام عدة أحرف في مدى من السلاسل النصية.
وقد يصبح سلوكها مربكًا عند التعامل مع مديات نصية أكثر تعقيدًا، لذا توخَّ الحذر.

```crystal
("aa".."az") # A range containing ["aa", "ab", "ac", ..., "az"]
```
