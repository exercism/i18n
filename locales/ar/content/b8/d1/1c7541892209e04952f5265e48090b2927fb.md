# ملحق التعليمات

## تلميحات

ينبغي لوحدة `Sgf` أن تصدّر وحدة `parseSgf` بالتوقيع التالي:

```haskell
parseSgf :: Text -> Maybe (Tree (Map Text [Text]))
```

قد يفيدك نسخ التعريفات التالية الخاصة بـ`SgfTree` و`SgfNode`:

```haskell
-- | A tree of nodes.
type SgfTree = Tree SgfNode

-- | A node is a property list, each key can only occur once.
-- Keys may have multiple values associated with them.
type SgfNode = Map Text [Text]
```

مكتبة `parsec` جزء من Haskell Platform. استفد منها.
