# مقدمة

## القيم المنطقية في Julia

تُمثَّل قيم صحيح وخطأ بالنوع `Bool`.
وهو يحتوي على قيمتين فقط: `true` و`false`.

```julia-repl
julia> true
true

julia> false
false
```

## العوامل المنطقية

توجد ثلاثة عوامل منطقية في Julia.

`&&` هو العامل المنطقي «و».
ويعطي `true` إذا كان التعبيران على *كلا* جانبي `&&` يساويان `true`.

```julia-repl
julia> true && true
true

julia> true && false
false
```

`||` هو العامل المنطقي «أو».
ويعطي `true` إذا كان التعبير على *أي* من جانبي `||` يساوي `true`.

```julia-repl
julia> true || true
true

julia> false || true
true
```

`!` هو العامل المنطقي «ليس».
وهو يبدّل بين القيمتين `true` و`false`.

```julia-repl
julia> !true
false

julia> !false
true
```

في التعبيرات الأطول والأكثر تعقيدًا، من الأفضل استخدام الأقواس الهلالية لتوضيح ما تقصده.

```julia-repl
julia> (true || false) && (false && true)
false
```
