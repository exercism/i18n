# المقدمة

توفر C#، مثل كثير من اللغات ذات الأنواع الساكنة، عددًا من الأنواع التي تمثل الأعداد الصحيحة، ولكل منها نطاق قيمه الخاص. عند الطرف الأدنى، يمتلك النوع `sbyte` قيمة دنيا مقدارها -128 وقيمة عليا مقدارها 127. وكما في جميع أنواع الأعداد الصحيحة، تتوفر هذه القيم بصيغة `<type>.MinValue` و`<type>.MaxValue`. وعند الطرف الأعلى، يمتلك النوع `long` قيمة دنيا مقدارها -9,223,372,036,854,775,808 وقيمة عليا مقدارها 9,223,372,036,854,775,807. وبينهما يقع النوعان `short` و`int`.

تتحدد النطاقات بعرض التخزين الذي يخصصه النظام للنوع. على سبيل المثال، يستخدم النوع `byte` 8 بتات ويستخدم النوع `long` 64 بتًا.

يقترن كل نوع من الأنواع أعلاه بنظير غير مُشغَّل الإشارة: `sbyte`/`byte`، و`short`/`ushort`، و`int`/`uint`، و`long`/`ulong`. وفي جميع الحالات، يمتد نطاق القيم من 0 إلى ضعف القيمة العليا السالبة للنوع المُشغَّل الإشارة زائد 1.

| النوع  | العرض  | الحد الأدنى                | الحد الأعلى                 |
| ------ | ------ | -------------------------- | --------------------------- |
| sbyte  | 8 بت   | -128                       | +127                        |
| short  | 16 بت  | -32_768                    | +32_767                     |
| int    | 32 بت  | -2_147_483_648             | +2_147_483_647              |
| long   | 64 بت  | -9_223_372_036_854_775_808 | +9_223_372_036_854_775_807  |
| byte   | 8 بت   | 0                          | +255                        |
| ushort | 16 بت  | 0                          | +65_535                     |
| uint   | 32 بت  | 0                          | +4_294_967_295              |
| ulong  | 64 بت  | 0                          | +18_446_744_073_709_551_615 |

يمكن تحويل متغير (أو تعبير) من نوع إلى آخر بسهولة. على سبيل المثال، في عملية إسناد، إذا ضمن نوع القيمة المُسنَدة (`lhs`) أن تقع القيمة داخل نطاق النوع المُسنَد إليه (`rhs`)، فإن الإسناد يكون بسيطًا:

```csharp
uint ui = uint.MaxValue;
ulong ul = ui;    // no problem
```

ومن ناحية أخرى، إذا لم يكن نطاق النوع المُسنَد منه مجموعة فرعية من نطاق قيم النوع المُسنَد إليه، فإن عملية التحويل الصريح `()` تكون مطلوبة حتى لو كانت القيمة نفسها ضمن نطاق النوع المُسنَد إليه:

```csharp
short s = 42;
uint ui = (uint)s;
```
