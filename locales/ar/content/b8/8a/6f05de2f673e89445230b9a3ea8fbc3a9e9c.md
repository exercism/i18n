# نظرة عامة

[المديات][range] تمثل فترة بين قيمتين.
تُستخدم المديات عادةً مع أنواع مثل `Int` و`String` و`Character` للتنقل عبر المتتاليات، أو تقطيع المجموعات، أو التحقق مما إذا كانت قيمة ما تقع ضمن الحدود.

توفر Swift عاملي مدى أساسيين:

- **عامل المدى المغلق (`...`)**: يشمل قيمتي البداية والنهاية (`1...5` يشمل 1 و2 و3 و4 و5).
- **عامل المدى نصف المفتوح (`..<`)**: يشمل قيمة البداية لكنه يستثني قيمة النهاية (`1..<5` يشمل 1 و2 و3 و4).

```swift
let closed = 1...5
let halfOpen = 1..<5
```

~~~~exercism/note
عند استدعاء طريقة مباشرة على مدى حرفي، ضع تعبير المدى بين الأقواس الهلالية حتى يقيّم المترجم المدى أولًا:

```swift
(1...5).contains(3) // Returns true
// 1...5.contains(3) // Error: value of type 'Int' has no member 'contains'
```

## تحويل مدى إلى مصفوفة

يمكنك تحويل مدى من الأعداد إلى `Array` باستخدام المنشئ `Array(_:)`:

```swift
let range = 1...5
let numbers = Array(range)
// numbers is [1, 2, 3, 4, 5]
```

## تقطيع مصفوفة باستخدام المديات

يمكنك استخدام المديات لتقطيع أقسام فرعية من مصفوفة:

```swift
let array = [10, 20, 30, 40, 50]
let slice = array[1...3]
// slice contains [20, 30, 40]
```

## خصائص المديات وطرقها

تشمل العمليات الشائعة على المديات ما يلي:

| العضو                  | الوصف                                                | مثال                              |
| ----------------------- | ---------------------------------------------------------- | ------------------------------------ |
| `count`                 | تُرجع عدد العناصر في المدى                | `(1...5).count` تُرجع `5`          |
| [`contains(_:)`][contains] | تُرجع `true` إذا كان المدى يتضمن القيمة المحددة | `(1...5).contains(3)` تُرجع `true` |

## المديات أحادية الجانب

تدعم Swift أيضًا المديات أحادية الجانب (الجزئية)، حيث تحذف قيمة البداية أو قيمة النهاية:

- `array[2...]`: من الفهرس 2 إلى نهاية المجموعة.
- `array[...2]`: من بداية المجموعة وحتى الفهرس 2 ضمنًا.
- `array[..<2]`: من بداية المجموعة إلى ما قبل الفهرس 2.

## مديات السلاسل النصية والمحارف

يمكن أيضًا إنشاء مديات بين محارف أو سلاسل نصية تتوافق مع `Comparable`:

```swift
let letters = "a"..."z"
print(letters.contains("m")) // Prints true
print(letters.contains("A")) // Prints false
```
