# نبذة

يحتوي Haxe على نوعين من الأعداد: الأعداد الصحيحة والأعداد العشرية:

- `Int`: يمثل عددًا صحيحًا.
- `Float`: يمثل عددًا عشريًا بدقة مزدوجة بطول 64 بت.

```haxe
var integer:Int = 10;
var floating:Float = 5.4;
```

يمكن استخدام كل `Int` في الموضع الذي يُتوقع فيه `Float` (أي أن `Int` **يمكن إسناده إلى** `Float` أو **يتوحد معه**)، أما العكس فغير صحيح: إسناد `Float` إلى `Int` قد يؤدي إلى فقدان الدقة، ولذلك لا يُسمح به ضمنيًا.

## المقارنة

تتساوى الأعداد إذا كانت لها القيمة نفسها.

```haxe
1 == 1; // true

1.2 == 1.2; // true

1 == 1.0; // true

0.2 + 0.1 == 0.3 // false
```
