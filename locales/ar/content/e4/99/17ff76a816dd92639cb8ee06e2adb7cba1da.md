# مقدمة

المصفوفات في Factor هي متتاليات ثابتة الطول: يمكنك تغيير العناصر، لكن ليس الطول. أنت تعرف بالفعل كيف تكتب مصفوفة حرفية (`{ … }`)، وكيف تقتطع جزءًا منها وتجمع عناصرها. يتناول هذا التمرين مجموعة الأدوات الصغيرة التي تحتاجها عندما تبني مصفوفات من قيم موجودة على المكدس، ثم تبحث في محتوياتها أو تعيد ترتيبها.

## البناء من المكدس

`1array` و`2array` و`3array` و`4array` (في [`arrays`][arrays]) تأخذ 1 أو 2 أو 3 أو 4 من القيم من أعلى المكدس وتضمّها معًا:

```
1array ( a       -- { a }       )
2array ( a b     -- { a b }     )
3array ( a b c   -- { a b c }   )
4array ( a b c d -- { a b c d } )
```

```factor
42 1array .                ! => { 42 }
3 4 2array .               ! => { 3 4 }
"x" "y" "z" 3array .       ! => { "x" "y" "z" }
1 2 3 4 4array .           ! => { 1 2 3 4 }
```

## الربط

تأخذ `concat` (في [`sequences`][sequences]) متتالية عناصرها متتاليات أخرى، فتسطّحها مستوى واحدًا. وتفعل `join` الشيء نفسه مع إدراج فاصل بين كل زوج:

```
concat ( seqs     -- seq )
join   ( seqs sep -- seq )
```

```factor
{ { 1 2 } { 3 4 } { 5 } } concat .
! => { 1 2 3 4 5 }

{ "alpha" "beta" "gamma" } ", " join .
! => "alpha, beta, gamma"
```

## العكس

تُرجع `reverse` متتالية جديدة تحتوي على العناصر بترتيب معاكس:

```
reverse ( seq -- newseq )
```

```factor
{ 1 2 3 4 } reverse .   ! => { 4 3 2 1 }
```

## هل هي مصفوفة؟

`array?` (في [`arrays`][arrays]) هو اختبار النوع. تكون قيمته صحيحة لأي قيمة بُنيت بـ `<array>` أو `1array`/`2array`/... أو مصفوفة حرفية `{ … }`، وخطأ لكل ما عدا ذلك (بما في ذلك المتجهات والسلاسل النصية والمتتاليات الأخرى):

```
array? ( obj -- ? )
```

```factor
{ 1 2 3 } array? .         ! => t
"hello" array? .           ! => f
V{ 1 2 3 } array? .        ! => f
```

## البحث

تُرجع `index` موضع أول عنصر يساوي القيمة المدخلة، أو `f` إن لم تكن موجودة. أما `member?` فتكتفي بإرجاع قيمة منطقية. وكلتاهما تأخذ **العنصر أولًا** و**المتتالية ثانيًا**. وتُرجع `members` (في [`sets`][sets]) العناصر *الفريدة* في المتتالية، أي عملية إزالة التكرار، بينما تختبر `all-unique?` (في `sets` أيضًا) ما إذا كانت المتتالية خالية من التكرار أصلًا:

```
index       ( elt seq -- i/f )
member?     ( elt seq -- ? )
members     ( seq     -- uniques )
all-unique? ( seq     -- ? )
```

```factor
"b" { "a" "b" "c" } index .       ! => 1
"z" { "a" "b" "c" } index .       ! => f
"b" { "a" "b" "c" } member? .     ! => t
"z" { "a" "b" "c" } member? .     ! => f
{ 1 2 3 2 1 } members .           ! => { 1 2 3 }
{ 1 2 3 } all-unique? .           ! => t
{ 1 2 1 } all-unique? .           ! => f
```
