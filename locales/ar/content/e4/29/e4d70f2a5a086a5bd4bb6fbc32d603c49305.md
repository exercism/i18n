# مقدمة

## المقارنة

في JavaScript، يمكن مقارنة الأعداد باستخدام عوامل المقارنة والمساواة العلائقية التالية.

| المقارنة | العامل |
| ---------------------- | --------- |
| أكبر من | `a > b` |
| أكبر من أو يساوي | `a >= b` |
| أصغر من | `a < b` |
| أصغر من أو يساوي | `a <= b` |
| يساوي (تمامًا) | `a === b` |
| لا يساوي (تمامًا) | `a !== b` |

نتيجة المقارنة هي دائمًا قيمة منطقية: `true` أو `false`.

```javascript
1 < 3;
// => true

2 !== 2;
// => false

1 === 1.0;
// => true
// All numbers are floating-points, so this is different syntax for
// the exact same value.
```

في JavaScript، يمكن أيضًا استخدام عوامل المقارنة أعلاه لمقارنة السلاسل النصية.
وفي هذه الحالة، يُطبَّق ترتيب معجمي (قاموسي).
يمكنك العثور على قائمة بالترتيب الدقيق لجميع المحارف [هنا][utf-16-list].

```javascript
'Apple' > 'Pear';
// => false

'a' < 'above';
// => true

'a' === 'A';
// => false
```

## الجمل الشرطية

من الطرق الشائعة لتنفيذ منطق شرطي في JavaScript استخدام الجملة الشرطية `if`.
وهي تتكوّن من الكلمة المفتاحية `if`، وشرط محاط بالأقواس الهلالية، وكتلة كود محاطة بالأقواس المعقوفة.
ولن تُنفَّذ كتلة الكود إلا إذا كان ناتج تقييم الشرط هو `true`.

```javascript
if (condition) {
  // code that is executed if "condition" is true
}
```

يمكن استخدامها وحدها أو مع الكلمة المفتاحية `else`.

```javascript
if (condition) {
  // code that is executed if "condition" is true
} else {
  // code that is executed otherwise
}
```

ولتداخل شرط آخر داخل جملة `else`، يمكنك استخدام `else if`.

```javascript
if (condition1) {
  // code that is executed if "condition1" is true
} else if (condition2) {
  // code that is executed if "condition2" is true
  // but "condition1" was false
} else {
  // code that is executed otherwise
}
```
