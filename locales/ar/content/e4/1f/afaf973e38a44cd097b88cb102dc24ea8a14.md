# حلقات `for`

التكرار مفهوم أساسي في البرمجة، فهو يسمح لك بتنفيذ كتلة من الكود عدة مرات.
في Swift، هناك نوعان من الحلقات: [حلقات `for-in`][for-loops] وحلقات `while`.
في هذا الفصل، ستتعلّم حلقات `for-in`.

تسمح لك حلقات `for` بالتكرار عبر تسلسل من القيم، فتأخذ كل عنصر بدوره وتربطه بمتغير تختاره أنت.
وتسمح لك Swift بالتكرار عبر مجموعة متنوعة من التسلسلات، مثل النطاقات والمصفوفات والسلاسل النصية (وأنواع أخرى سنتناولها لاحقًا).
وعندما تُستوفى جميع عناصر التسلسل، تنتهي الحلقة.

تُعرَّف حلقات `for` باستخدام الكلمة المفتاحية `for`، يليها اسم متغير، ثم الكلمة المفتاحية `in`، ثم تسلسل من القيم للتكرار عبره.
المتغير المعطى في حلقة `for-in` غير قابل للتغيير، أي أنه لا يمكنك تغيير قيمته داخل الحلقة.
وإليك مثالًا على حلقة `for-in` تكرّر عبر مصفوفة من الأعداد:

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
  print(number)
}
print("Done with numbers")

// prints:
// 3
// 10
// 7
// 11
// Done with numbers
```

~~~~exercism/note
المتغير `number` مُعرَّف في حلقة `for-in`، وهو متاح فقط ضمن نطاق الحلقة.

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
    number + 1
}
number + 1
// Error: Use of unresolved identifier 'number'
```
~~~~

## التكرار عبر نطاق

يمكنك أيضًا التكرار عبر نطاق من الأعداد باستخدام حلقة `for-in`.
وهذا يسمح لك بتنفيذ كتلة من الكود عددًا محددًا من المرات، فعلى سبيل المثال، النطاق `1...5` سيكرّر عبر الأعداد 1 و2 و3 و4 و5، لذا ستنفَّذ الحلقة 5 مرات.
وأحيانًا قد ترغب في التكرار عبر الفهارس في بنية بيانات مثل مصفوفة، وعندها يمكنك استخدام النطاق `0..<array.count`.

```swift
let numbers = [3, 10, 7, 11]

for i in 0..<numbers.count {
  print(numbers[i])
}

// prints:
// 3
// 10
// 7
// 11
```

## التكرار عبر سلسلة نصية

يمكنك أيضًا التكرار عبر سلسلة نصية باستخدام حلقة `for-in`.
وهذا يسمح لك بالتكرار عبر كل حرف في السلسلة النصية، ولاحظ تحديدًا أن النوع المعطى في الحلقة هو `Character`.

```swift
let message = "Hello!"

for character in message {
  print(character)
}

// prints:
// H
// e
// l
// l
// o
// !
```

## `stride`

توفّر Swift أيضًا دالة `stride` تسمح لك بإنشاء تسلسل عبر نطاق بخطوة محددة.
ويمكن بعدها التكرار عبره باستخدام حلقة `for-in`.
تُعرَّف `stride` على أنها [`stride(from:to:by:)`][stride-to] أو [`stride(from:through:by:)`][stride-through]، فالأولى لا تتضمن الحد الأخير بينما الثانية تتضمنه.

```swift
for i in stride(from: 0, to: 10, by: 2) {
  print(i)
}

// prints:
// 0
// 2
// 4
// 6
// 8
```

لاحظ أن المعامل `to` لا يشمل الحد، لذا ستكرّر الحلقة حتى العدد الذي قبل المعامل `to`، بينما المعامل `through` يشمل الحد، لذا في هذه الحالة سيتضمن العدد `10` أيضًا.

[stride-to]: https://developer.apple.com/documentation/swift/stride(from:to:by:)
[stride-through]: https://developer.apple.com/documentation/swift/stride(from:through:by:)
[for-loops]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
