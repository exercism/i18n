# مقدمة

Kotlin لغة برمجة **ذات أنواع ساكنة** طوّرتها JetBrains. ويعني هذا أن نوع المتغيرات يُحدَّد في وقت التصريف.

## المتغيرات

وكما في لغات البرمجة الأخرى ذات الأنواع الساكنة، ينبغي تحديد نوع كل متغير في وقت التصريف. ويمكنك الاستغناء عن كتابة الأنواع صراحةً حين يستطيع المُصرِّف استنتاجها من السياق.

في Kotlin متغيرات ثابتة (`val`) وأخرى قابلة للتغيير (`var`). لا يمكن تغيير قيمة المتغير الثابت بعد إسناد قيمته الأولية. وفي معظم الأحيان ستستخدم هذا النوع من المتغيرات.

```kotlin
val robotName = "HAL-9000"
userId = "T-1000"  // This will not compile
```

أما قيمة المتغير القابل للتغيير فيمكن تغييرها مرة واحدة أو أكثر:

```kotlin
var index = 12
print(index)  // 12

index = 100
print(index)  // 100
```

الفاصلة المنقوطة في Kotlin اختيارية، باستثناء حالات خاصة قليلة سنتناولها لاحقًا.

## الدوال

تُعرَّف الدوال في Kotlin بالكلمة المفتاحية `fun`، وهي _من الدرجة الأولى_ (وهذا لا علاقة له بالبرمجة كائنية التوجه). ويعني هذا أنه يمكنك تعريفها (وتُسمّى `top-level functions`) مباشرة داخل الملفات (في Java مثلًا لا يمكنك تعريف الطُرق إلا داخل الأصناف، لا داخل الملفات):

```kotlin
// This is content of the Hello.kt file

fun hello() {}
```

يمكن للدوال أن تستقبل وسائط. ولكل وسيط اسم ونوع. وخلافًا للمتغيرات، لا يمكن استنتاج نوع الوسائط. ويمكن للدالة أن تحتوي على صفر أو أكثر من الوسائط:

```kotlin
fun hello() {}

fun hello(name: String) {}

fun hello(name: String, age: Int) {}
```

قد تُرجع دوال Kotlin قيمة وقد لا تُرجع:

```kotlin
fun min(a: Int, b: Int): Int

fun countBonuses(user: User): Bonuses

fun run() {}
```

ولإرجاع قيمة من دالة، تُستخدم الكلمة المفتاحية `return`:

```kotlin
fun getName(): String {
    return "Alice"
}
```

ويمكن أن يكون للدوال معاملات بقيم افتراضية. وتُستخدم هذه القيم إذا حُذفت عند استدعاء الدالة:

```kotlin
fun ping(host: String = "localhost") {
    println("PING --> $host")
}

ping("exercism.io")  // PING --> exercism.io
ping()               // PING --> localhost
```

## التعليقات

استخدم `//` لكتابة تعليق من سطر واحد:

```kotlin
foo() // Everything after `//` will be ignored by compiler

// I will be ignored too
```

أو `/*` و `*/` لكتابة تعليقات متعددة الأسطر:

```kotlin
/*
   This this an example
   for a multiline comment
*/
```
