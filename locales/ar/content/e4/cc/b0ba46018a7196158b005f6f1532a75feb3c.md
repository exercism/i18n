# التعليمات

في هذا التمرين ستكتب كودًا يساعد شركة لافتات على إنشاء رسائل مخصّصة للافتاتها.

## 1. أنشئ لافتة مناسبة

نفّذ الدالة `buildSign(occasion, name)` التي تقبل سلسلة نصية بوصفها المعامل `occasion` وسلسلة نصية تحمل اسم شخص بوصفه المعامل `name`.
سيُضمّن المعاملان في سلسلة نصية قالبية لإخراج الرسالة على اللافتة.

```javascript
buildSign('Birthday', 'Rob');
// => "Happy Birthday Rob!"
```

## 2. أنشئ لافتة عيد ميلاد

نفّذ الدالة `buildBirthdaySign(age)` التي تقبل عمرًا وتحدّد، بناءً على هذا العمر، جزءًا من الرسالة على اللافتة.
إذا كان العمر 50 أو أكثر، ستشير اللافتة إلى المستخدم بصفته _mature_، وإلا فستشير إليه بصفته _young_.
المخرجات المتوقعة بالضبط موضّحة أدناه:

```javascript
buildBirthdaySign(50);
// => "Happy Birthday! What a mature fellow you are."

buildBirthdaySign(45);
// => "Happy Birthday! What a young fellow you are."
```

## 3. أنشئ لافتة تخرّج

نفّذ الدالة `graduationFor(name, year)` التي تأخذ اسمًا بوصفه معاملًا من نوع سلسلة نصية وسنة بوصفها معاملًا من نوع عدد، وتستخدم الإدراج داخل السلسلة النصية لإنشاء عبارة للافتة تفصل بين سطري الرسالة بسطر جديد.

```javascript
graduationFor('Hannah', 2022);
/* => "Congratulations Hannah!
       Class of 2022"
*/
```

## 4. احسب تكلفة اللافتة

نفّذ الدالة `costOf(sign, currency)` التي تأخذ سلسلة نصية تحمل محتوى اللافتة وسلسلة نصية تمثّل العملة.
سعر اللافتة الأساسي هو 20 بالعملة المعطاة. بالإضافة إلى ذلك، يكلّف كل حرف مبلغ 2. (تُحتسب المسافات البيضاء ضمن الحساب.)
تشمل العبارة المُرجَعة تكلفة إنشاء اللافتة، مكتوبةً برقمين بعد الفاصلة العشرية، متبوعةً بالسلسلة النصية للعملة.

```javascript
costOf('Happy Birthday Rob!', 'dollars');
// => "Your sign costs 58.00 dollars."
```
