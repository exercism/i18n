# نبذة

`case` أداة التبديل متعددة المسارات في Factor، وهي تعتمد على المساواة. وهي الأداة المناسبة عندما يعتمد الاختيار على قيمة *واحدة* تساوي أحد بدائل عدة، لا عندما يحتاج كل فرع إلى اختبار مختلف (استخدم `cond` لذلك).

```factor
USING: combinators ;

SYMBOLS: yes no maybe ;

: invert ( ?/maybe -- ?'/maybe )
    {
        { yes [ no ] }
        { no  [ yes ] }
        [ ]            ! default: leave value alone
    } case ;
```

وهناك بعض الأمور التي يجدر إبقاؤها واضحة:

- المساواة هي `=`. وأي شيء يعمل معه `=` يصلح مفتاحًا: الأعداد، والسلاسل النصية، والمحارف، والرموز، وحتى `tuple`.
- الفروع *المطابَقة* ترى المكدس *دون* قيمة الإدخال، أما الفروع *الافتراضية* فتراها ما زالت على القمة.
- وإذا لم يكن في `case` فرع افتراضي ولا بند مطابق، فإنها تُطلق خطأً.

تُترجم `case` إلى جدول قفز حيث أمكن، فهي ليست مجرد سكر نحوي لتتابع من عبارات `if`، بل هي سريعة أيضًا.
