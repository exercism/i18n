# نبذة

JavaScript لغة ديناميكية قائمة على النماذج الأولية. لديها بعض [القيم الأولية][mdn-primitive]، وكل ما عداها يُعتبر كائنًا.

وبينما هي معروفة أكثر بوصفها لغة البرمجة النصية لصفحات الويب، فإن كثيرًا من البيئات غير المتصفحية تستخدمها أيضًا، مثل Node.js. تُطوَّر هذه اللغة بنشاط، ولأنها متعددة الأنماط، فهي تتيح أساليب عديدة للبرمجة. JavaScript لغة ديناميكية تدعم الأنماط الكائنية والأمرية والتعريفية (مثل البرمجة الوظيفية).

## الإسناد وإعادة الإسناد

توجد عدة طرق أساسية لإسناد القيم إلى الأسماء في JavaScript، إما باستخدام المتغيرات أو الثوابت. في Exercism، تُكتب المتغيرات دائمًا بنمط [camelCase][wiki-camel-case]، وتُكتب الثوابت بنمط [SCREAMING_SNAKE_CASE][wiki-snake-case]. لا يوجد دليل رسمي يجب اتباعه، ولكل شركة أو مؤسسة دليل أسلوب خاص بها. _لا تتردد في كتابة المتغيرات بالطريقة التي تحبها_. وميزة كتابتها بالطريقة التي أُعدّت بها التمارين هي أنها ستُبرز بشكل مختلف في واجهة الويب وفي معظم بيئات التطوير المتكاملة.

يمكن تعريف المتغيرات في JavaScript باستخدام الكلمة المفتاحية [`const`][mdn-const] أو [`let`][mdn-let] أو [`var`][mdn-var].

يمكن للمتغير أن يشير إلى قيم مختلفة خلال عمره عند استخدام `let` أو `var`. على سبيل المثال، يمكن تعريف `myFirstVariable` وإعادة تعريفه مرات عديدة باستخدام عامل الإسناد `=`:

```javascript
let myFirstVariable = 1;
myFirstVariable = 'Some string';
myFirstVariable = new SomeComplexClass();
```

وعلى عكس `let` و `var`، لا يمكن إسناد قيمة إلا مرة واحدة للمتغيرات المعرّفة بـ `const`. ويُستخدم هذا لتعريف الثوابت في JavaScript.

```javascript
const MY_FIRST_CONSTANT = 10;

// Can not be re-assigned.
MY_FIRST_CONSTANT = 20;
// => TypeError: Assignment to constant variable.
```

### إسناد الثوابت

تُذكر الكلمة المفتاحية `const` _لكلٍّ_ من المتغيرات والثوابت. ومن المفاهيم الأخرى التي تُذكر كثيرًا مع الثوابت [(عدم) قابلية التغيير][wiki-mutability].

الكلمة المفتاحية `const` تجعل _الارتباط_ غير قابل للتغيير فقط، أي أنه يمكنك إسناد قيمة إلى متغير `const` مرة واحدة فقط. وفي JavaScript، لا تكون إلا [القيم الأولية][mdn-primitive] غير قابلة للتغيير. أما [القيم غير الأولية][mdn-primitive] فيمكن تعديلها مع ذلك.

```javascript
const MY_MUTABLE_VALUE_CONSTANT = { food: 'apple' };

// This is possible
MY_MUTABLE_VALUE_CONSTANT.food = 'pear';

MY_MUTABLE_VALUE_CONSTANT;
// => { food: "pear" }
```

### قيمة الثابت (عدم قابلية التغيير)

كقاعدة عامة، في Exercism وفي كثير من المؤسسات وأدلة الأسلوب الخاصة بالمشاريع، لا تُعدّل القيم التي تبدو بالشكل `const SCREAMING_SNAKE_CASE`. فمن الناحية التقنية، _يمكن_ تغيير هذه القيم، لكن يُنصح بعدم فعل ذلك من أجل الوضوح وضبط التوقعات في Exercism. وعندما _يجب_ فرض ذلك، استخدم [`Object.freeze(value)`][mdn-object-freeze].

```javascript
const MY_VALUE_CONSTANT = Object.freeze({ food: 'apple' });

// This silently fails
MY_VALUE_CONSTANT.food = 'pear';

MY_VALUE_CONSTANT;
// => { food: "apple" }
```

في الواقع العملي، من غير المرجح أن ترى `Object.freeze` في كل مكان في قاعدة الكود، لكن قاعدة عدم تعديل قيمة `SCREAMING_SNAKE_CASE` أبدًا قاعدة جيدة، وكثيرًا ما تُفرض باستخدام تحليل آلي مثل أدوات فحص الكود.

## تعريف الدوال

في JavaScript، تُغلَّف وحدات الوظائف داخل _الدوال_، وعادة ما تُجمع الدوال معًا في الملف نفسه إذا كانت تنتمي إلى بعضها. ويمكن لهذه الدوال أن تأخذ معاملات (وسائط)، وأن _تُرجع_ قيمة باستخدام الكلمة المفتاحية `return`. وتُستدعى الدوال باستخدام صيغة `()`.

```javascript
function add(num1, num2) {
  return num1 + num2;
}

add(1, 3);
// => 4
```

> 💡 توجد في JavaScript _طرق_ مختلفة عديدة لتعريف دالة. وتبدو هذه الطرق الأخرى مختلفة عن استخدام الكلمة المفتاحية `function`. يحاول المسار تقديمها تدريجيًا، لكن إن كنت تعرفها بالفعل، فلا تتردد في استخدام أيٍّ منها. وفي معظم الحالات، لا يكون استخدام إحداها أفضل أو أسوأ من الأخرى.

## التصدير والاستيراد

الكلمتان المفتاحيتان `export` و `import` أداتان قويتان تحوّلان ملف JavaScript عاديًا إلى [وحدة JavaScript][mdn-module]. وإلى جانب السماح للكود بعرض مكوّنات مختارة، مثل الدوال والأصناف والمتغيرات والثوابت، فإنه يتيح أيضًا مجموعة كاملة من الميزات الأخرى، مثل:

- [إعادة تسمية الصادرات والواردات][mdn-renaming-modules]، وهو ما يتيح لك تجنّب تعارض الأسماء،
- [الاستيرادات الديناميكية][mdn-dynamic-imports]، التي تحمّل الكود عند الحاجة،
- [Tree shaking][blog-tree-shaking]، الذي يقلّل حجم الكود النهائي بإزالة الوحدات الخالية من الآثار الجانبية، وحتى محتويات الوحدات _التي لا تُستخدم_،
- تصدير [_الارتباطات الحية_][blog-live-bindings]، وهو ما يتيح لك تصدير قيمة تتغيّر في كل مكان تُستورد فيه إذا تغيّرت القيمة الأصلية.

ومن الأمثلة الملموسة طريقة عمل الاختبارات في مسار JavaScript على Exercism. فكل تمرين له ملف تنفيذ واحد على الأقل، مثل `lasagna.js`، وملف اختبار واحد على الأقل، مثل `lasagna.spec.js`. يستخدم ملف التنفيذ `export` لعرض API العامة، ويستخدم ملف الاختبار `import` للوصول إليها، وهكذا يستطيع اختبار نتائج التنفيذ.

```javascript
// file.js
export const MY_VALUE = 10;

export function add(num1, num2) {
  return num1 + num2;
}

// file.spec.js
import { MY_VALUE, add } from './file';

add(MY_VALUE, 5);
// => 15
```
