# مقدمة

حين تحتاج إلى صف من `n` من القيم يعتمد كل منها على موضعه، تتعاون `<iota>` و `map` في Factor على إنجاز المهمة دون كتابة عدّاد حلقة.

## `<iota>` و `map`

يستقبل `<iota>` (في [`sequences`][sequences]) عددًا صحيحًا غير سالب `n` ويُرجع متتالية *افتراضية* من الأعداد الصحيحة `0, 1, …, n-1`. ثم يمرّ عليها `map` مطبّقًا `quotation` على كل عنصر:

```factor
USING: math sequences ;

5 <iota> [ 2 * ] map .   ! => { 0 2 4 6 8 }
```

يستقبل `quotation` عددًا صحيحًا واحدًا، وهو الفهرس، ويترك على المكدس القيمة الخاصة بذلك الموضع.

## المرور والتكرار حسب العدد

حين لا تحتاج إلا إلى *الآثار الجانبية* لزيارة كل فهرس، لا إلى متتالية جديدة، يمرّر `each-integer` (في [`math`][math]) `quotation` على `0, 1, …, n-1`:

```
each-integer ( n quot: ( i -- ) -- )
```

ويستدعي `replicate` (في [`sequences`][sequences]) `quotation` مرات عددها `n` ويجمع النتائج متجاهلًا الفهرس، وهو مفيد لبناء `n` من القيم المستقلة:

```
replicate ( n quot: ( -- elt ) -- seq )
```

```factor
USING: sequences ;

3 [ { 0 0 } ] replicate .   ! => { { 0 0 } { 0 0 } { 0 0 } }
```

## المديات المحدودة

حين لا يبدأ مدى الفهارس من `0`، أو أردتَه شاملًا الطرفين، توفّر مفردات [`ranges`][ranges] قيمًا حرفية بترميز الأقواس. الأقواس المربعة تشمل نقطة النهاية، والأقواس الهلالية تستبعدها.

```
[a..b]    ! a, a+1, …, b      (inclusive)
[a..b)    ! a, a+1, …, b-1    (half-open at the top)
```

```factor
USING: math ranges sequences ;

3 7 [a..b] [ 2 * ] map .   ! => { 6 8 10 12 14 }
3 7 [a..b) [ 2 * ] map .   ! => { 6 8 10 12 }
```

وفيما يلي بعض الاختصارات الشائعة ذات الوسيط الواحد:

```
[1..b]    ! 1, 2, …, b        (same as 1 b [a..b])
[1..b)    ! 1, 2, …, b-1      (same as 1 b [a..b))
[0..b)    ! 0, 1, …, b-1      (same as 0 b [a..b), and same as `b <iota>`)
```

```factor
6 [1..b] [ sq ] map .      ! => { 1 4 9 16 25 36 }
6 [1..b) [ sq ] map .      ! => { 1 4 9 16 25 }
4 [0..b) [ 1 + ] map .     ! => { 1 2 3 4 }
```

يُعدّ `<iota>` الصيغة الأكثر شيوعًا، أما `[a..b]` وشبيهاتها فهي الأداة المناسبة حين يبدأ المدى من غير `0` أو حين يحتاج إلى حد أعلى شامل.

## الحدود الدنيا المفتوحة والمديات التي قد تكون فارغة

الأقواس المربعة *تشمل* نقطة النهاية، والأقواس الهلالية *تستبعدها*. والحيلة نفسها على اليسار تعطي `(a..b]` و `(a..b)`:

```
(a..b]    ! a+1, …, b              (lower open, upper inclusive)
(a..b)    ! a+1, …, b-1            (both open)
```

يعطي `0 n (a..b]` المدى `{ 1 … n }` حين يكون `n > 0`، والمدى الفارغ `{ }` حين يكون `n = 0`، وهو الشكل الطبيعي حين تريد المرور على «كل عدد صحيح موجب حتى `n` شاملًا لها».

## المديات التنازلية

تعدّ صيغ الأقواس الأربع كلها، وهي `[a..b]` و `[a..b)` و `(a..b]` و `(a..b)`، *تنازليًا* حين يكون `a > b`، لا نحو نتيجة فارغة:

```factor
USING: ranges sequences ;

5 1 [a..b] >array .   ! => { 5 4 3 2 1 }
1 0 [a..b] >array .   ! => { 1 0 }   (not empty!)
```

## بناء سلسلة نصية حسب الموضع

يعطي `map` الشكل الذي يُرجعه `quotation` أيًّا كان. وإذا ترك `quotation` رمز محرف على المكدس، حوّل `>string` (في [`strings`][strings]) النتيجة إلى سلسلة نصية:

```factor
USING: math sequences strings ;

4 <iota> [ 2 * CHAR: A + ] map >string .   ! => "ACEG"
```

يُحلَّل `CHAR: A` إلى العدد الصحيح `65`. ويضاعف `quotation` هنا الفهرس ويضيف إليه ذلك الأساس، فيصيب حرفًا كبيرًا من كل حرفين. وأي حساب تُجريه انطلاقًا من الفهرس هو الذي يحدّد المحرف الذي يستقر في ذلك الموضع.

## الاختيار حسب الموضع

حين يعتمد المحرف على *شرط* يتعلق بالفهرس، فأجرِ الاختيار داخل `quotation`:

```factor
USING: kernel math sequences strings ;

5 <iota> [ 3 < [ CHAR: a ] [ CHAR: b ] if ] map >string .
! => "aaabb"
```

تختبر المواضع الثلاثة الأولى `i 3 <` فتخرج النتيجة `t`، فتحصل على `a`، أما البقية فتحصل على `b`. والشكل نفسه، `[ <test> [ <yes> ] [ <no> ] if ]`، يغطي اختبارات الزوجية باستخدام `even?` / `odd?` (في [`math`][math]) واختبارات «كل موضع يحمل الرقم k» باستخدام `mod` و `zero?`.
