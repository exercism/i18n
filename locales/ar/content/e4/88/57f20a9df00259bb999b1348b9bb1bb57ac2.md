# المقدمة

في Python، يُعدّ [الصف][tuple] مجموعة _غير قابلة للتغيير_ من العناصر في _تسلسل_.
وكمعظم المجموعات، يمكن لـ`tuples` أن تحتوي على أي نوع (أو أنواع متعددة) من البيانات، بما في ذلك `tuples` أخرى.
تدعم الصفوف جميع [عمليات التسلسل الشائعة][common sequence operations]، لكنها **لا** تدعم [عمليات التسلسل القابلة للتغيير][mutable sequence operations].

يمكن تكرار المرور على عناصر الصف باستخدام بنية `for item in <tuple>`.
وإذا احتجت إلى كلٍّ من فهرس العنصر وقيمته، يمكنك استخدام `for index, item in enumerate(<tuple>)`.
وكأي تسلسل، يمكن الوصول إلى عناصر `tuples` عبر _الترميز بالأقواس المربعة_ باستخدام رقم `0-based index` من اليسار أو رقم `-1-based index` من اليمين.
كما يمكن نسخ الصفوف كاملة أو جزئية باستخدام ترميز الشرائح (_`<tuple>[<start>:<stop>:<step>]`_).


## إنشاء الصف

يمكن إنشاء الصفوف بطرق متعددة، إما باستخدام مُنشئ الصنف `tuple(<iterable>)` أو التعريف الحرفي `tuple`.

### استخدام مُنشئ `tuple()` فارغًا أو مع _قابل للتكرار_:

```python
>>> no_elements = tuple()
()

# The constructor *requires* an iterable, so single elements must be passed in a list or another tuple.
>>> one_element = tuple([16])
(16,)
```

السلاسل النصية قابلة للتكرار، لذا فإن استخدام `str` واحدة كوسيط إلى مُنشئ `tuple()` قد يُنتج نتائج مفاجئة:

```python
# String elements (characters) are iterated through and added to the tuple
>>> multiple_elements_string = tuple("Timbuktu")
('T', 'i', 'm', 'b', 'u', 'k', 't', 'u')
```

عندما يكون لديك قابل للتكرار مفرد، تُضاف عناصره واحدًا تلو الآخر:

```python
>>> multiple_elements_list = tuple(["Parrot", "Bird", 334782])
("Parrot", "Bird", 334782)

>>> multiple_elements_set = tuple({2, 3, 5, 7, 11})
(2,3,5,7,11)
```

#### تعريف الصف باعتباره _قيمة حرفية_:

نظرًا لأن مُنشئ `tuple(<iterable>)` لا يقبل سوى _الكائنات القابلة للتكرار_ (أو لا شيء) كوسائط، فمن الأسهل بكثير إنشاء صف من عنصر واحد عبر الأسلوب الحرفي.

```python
>>> no_elements = ()
()

>>> one_element = ("Guava",)
("Guava",)
```

يمكن تضمين بنى بيانات متداخلة كعناصر داخل `tuple`، بما في ذلك `tuples` أخرى:

```python
>>> nested_data_structures = ({"fish": "gold", "monkey": "brown", "parrot" : "grey"}, ("fish", "mammal", "bird"))
({"fish": "gold", "monkey": "brown", "parrot" : "grey"}, ("fish", "mammal", "bird"))

>>> nested_data_structures_1 = (["fish", "gold", "monkey", "brown", "parrot", "grey"], ("fish", "mammal", "bird"))
(["fish", "gold", "monkey", "brown", "parrot", "grey"], ("fish", "mammal", "bird"))
```

## دمج الصفوف

يمكن دمج الصفوف باستخدام عامل الجمع `+`، الذي يفكّ كل `tuple` لإنشاء `tuple` جديد مدمج.

```python
>>> new_via_concatenate = ("George", 5) + ("cat", "Tabby")
("George", 5, "cat", "Tabby")

#likewise, using the multiplication operator * is the equivalent of using + n times
>>> first_group = ("cat", "dog", "elephant")

>>> multiplied_group = first_group * 3
('cat', 'dog', 'elephant', 'cat', 'dog', 'elephant', 'cat', 'dog', 'elephant')
```

## الوصول إلى العناصر داخل الصف

يمكن الوصول إلى العناصر داخل `tuple` عبر _الترميز بالأقواس المربعة_ باستخدام رقم `0-based index` من اليسار أو رقم `-1-based index` من اليمين.

```python
student_info = ("Alyssa", "grade 3", "female", 8 )

#gender is at index 2 or index -2
>>> student_gender = student_info[2]
'female'

>>> student_gender = student_info[-2]
'female'

#name is at index 0 or index -4
>>> student_name = student_info[0]
Alyssa

>>> student_name = student_info[-4]
Alyssa
```

## التكرار على عناصر الصف

يمكن _التكرار على_ العناصر داخل `tuple` في حلقة باستخدام صيغة `for item in <tuple>`.
وإذا احتجت إلى كلٍّ من الفهارس والقيم، يمكنك استخدام `for index, item in enumerate(<tuple>)`.

```python
>>> student_info = ("Alyssa", "grade 3", "female", 8 )
>>> for item in student_info:
...   print(item)

...
Alyssa
grade 3
female
8

>>> for index, item in enumerate(student_info):
...  print("Index is: " + str(index) + ", value is: " + str(item) +".")

...
Index is: 0, value is: Alyssa.
Index is: 1, value is: grade 3.
Index is: 2, value is: female.
Index is: 3, value is: 8.
```

## التحقق من العضوية في الصف

يمكن استخدام عامل `in` للتحقق من العضوية في `tuple`.

```python
>>> multiple_elements_list = tuple(["Parrot", "Bird", 334782])
("Parrot", "Bird", 334782)

>>> "Parrot" in multiple_elements_list
True
```
