# نبذة

الأنواع المخصصة هي الوسيلة التي تُعرَّف بها أنواع البيانات الجديدة في Gleam. ويمكن أن تحتوي على عدة _بدائل_، لكل بديل منها اسمه الخاص.

```gleam
pub type Season {
  Spring
  Summer
  Autumn
  Winter
}
```

يمكن لكل حالة من حالات النوع المخصص أن تحمل بيانات، ويمكن أن تختلف أنواع البيانات بين الحالات المختلفة. وعندما يحمل بديل ما بيانات، فإنه يُسمى _سجلًا_.

```gleam
pub type Number {
  SomeInt(Int)
  SomeFloat(Float)
  Invalid
}
```

يمكن إنشاء قيمة لحالة معينة بالإشارة إلى اسمها إذا لم تكن تحمل بيانات إضافية (`Spring`)، أو باستدعائها كدالة إذا كانت تحملها (`SomeInt(2)`).

```gleam
let spring = Spring
let integer_two = SomeInt(2)
```

تتمتع الأنواع المخصصة بـ_التساوي البنيوي_، شأنها شأن كل شيء في Gleam، وهذا يعني أن قيمتين من البديل نفسه وبالبيانات نفسها متكافئتان.

```gleam
Spring == Spring // -> True
Spring == Autumn // -> False
SomeInt(2) == SomeInt(2) // -> True
SomeInt(2) == SomeFloat(2.0) // -> False
```

يمكن إجراء مطابقة الأنماط على بدائل الأنواع المخصصة باستخدام تعبيرات `case`.

```gleam
import gleam/int
import gleam/float

pub fn describe(flexible_number: Number) -> String {
  case flexible_number {
    SomeFloat(f) -> "Float: " <> float.to_string(f)
    SomeInt(i) -> "Int: " <> int.to_string(i)
    Invalid -> "Neither a float nor an int"
  }
}
```
