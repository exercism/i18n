# ملحق التعليمات

## السجلات

| السجل | الاستخدام    | النوع   | الوصف                         |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | مدخل        | عنوان | سلسلة نصية مدخلة منتهية بمحرف فارغ  |
| `$a1`    | مدخل/مخرج | عنوان | سلسلة نصية ناتجة منتهية بمحرف فارغ |
| `$t0-9`  | مؤقت    | أي نوع | للتخزين المؤقت                 |
