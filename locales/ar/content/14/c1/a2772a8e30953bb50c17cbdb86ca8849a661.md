# التعليمات

Izzy مراقبة طيور شغوفة تحتفظ بسجل لعدد الطيور التي زارت حديقتها في أي يوم.

وقد طلبت منك أن تساعدها في الارتقاء بمراقبتها للطيور إلى مستوى جديد، وأن تنفّذ بعض الأدوات التي ستساعدها على تتبّع البيانات ومعالجتها.

لقد اخترت تخزين البيانات في مصفوفة من الأعداد الصحيحة. العدد الأول في المصفوفة هو عدد الطيور التي زارت حديقتك اليوم، والثاني أمس، وهكذا.

## 1. تحقّق من عدد الطيور التي زارت اليوم

نفّذ دالة `today`. يجب أن تأخذ مصفوفة بأعداد الطيور اليومية وتُرجع عدد اليوم. وإذا كانت المصفوفة فارغة، فعليها أن تُرجع `0`.

```gleam
today([2, 5, 1])
// -> 2
```

## 2. زد عدد اليوم

نفّذ دالة `increment_day_count`. يجب أن تأخذ مصفوفة بأعداد الطيور اليومية وتزيد عدد اليوم بمقدار 1. وإذا كانت المصفوفة فارغة، فعليها أن تُرجع `[1]`.

```gleam
increment_day_count([4, 0, 2])
// -> [5, 0, 2]
```

## 3. تحقّق مما إذا كان هناك يوم بلا طيور زائرة

نفّذ دالة `has_day_without_birds`. يجب أن تأخذ مصفوفة بأعداد الطيور اليومية. وعليها أن تُرجع `True` إذا كان هناك يوم واحد على الأقل لم تزر فيه أي طيور الحديقة، و`False` خلاف ذلك. وإذا كانت المصفوفة فارغة، فهذا يُحتسب على أنه لم تُسجَّل أي طيور _بعد_؛ فعليها أن تُرجع `False`.

```gleam
has_day_without_birds([2, 0, 4])
// -> True

has_day_without_birds([3, 8, 1, 5])
// -> False
```

## 4. احسب العدد الإجمالي للطيور الزائرة

نفّذ دالة `total`. يجب أن تأخذ مصفوفة بأعداد الطيور اليومية وتُرجع العدد الإجمالي للطيور التي زارت حديقتك منذ أن بدأت جمع البيانات.

```gleam
total([4, 0, 9, 0, 5])
// -> 18
```

## 5. احسب عدد الأيام المزدحمة

بعض الأيام أكثر ازدحامًا من غيرها. واليوم المزدحم هو الذي زارت فيه خمسة طيور أو أكثر حديقتك.

نفّذ دالة `busy_days`. يجب أن تأخذ مصفوفة بأعداد الطيور اليومية وتُرجع عدد الأيام المزدحمة.

```gleam
busy_days([4, 5, 0, 0, 6])
// -> 2
```
