# مقدمة

في Haxe، يُعدّ `class` البنية الأساسية للبيانات، فهو يغلّف البيانات (الحقول) والسلوك (الطرق). وتُسمّى الحقول والطرق أيضًا أعضاء الصنف.

يمكن تقييد الوصول إلى الأعضاء باستخدام معدّلات الوصول، وهي:

- `public`: يمكن الوصول إلى العضو من أي مكان.
- `private`: لا يمكن الوصول إلى العضو إلا من الصنف نفسه.

يمكن اعتبار الأصناف قوالب لإنشاء النسخ. ولإنشاء نسخة، استخدم ببساطة الكلمة المفتاحية `new`:

```haxe
class Car {
  public function new() {}
}

var myCar = new Car();
var yourCar = new Car();
```

لتعريف حقل، استخدم معدّل وصول يتبعه اسم المتغير والنوع:

```haxe
class Car {
  public var weight:Int; // Accessable by anyone

  private var color:String; // Accessable only within this class
}
```

يمكنك أيضًا تعيين قيمة ابتدائية عند تعريف حقل. وإذا لم يحدّد الحقل قيمة ابتدائية، فسيأخذ قيمة `null`. ويمكنك الوصول إلى الحقل باستخدام التدوين النقطي:

```haxe
class Car {
  public var weight:Int = 2500; // Weight will be set to 2500
  public var year:Int; // year will be null

  public function new() {}
}

var newCar = new Car();
newCar.weight; // 2500
newCar.year; // null

// Update value of field
newCar.year = 2020;
```
