# التثبيت

يستخدم هذا المسار ReScript 12 ويعتمد على [Node.js][nodejs] الإصدار 22 أو أحدث.
كثير من الأنظمة يأتي Node.js مثبَّتًا عليها مسبقًا، أو ربما ثبّتته سابقًا من أجل مسار آخر.

افتح الطرفية ونفّذ:

```sh
node -v
```

إذا لم يكن Node مثبَّتًا أو ظهر إصدار أقدم، فاتبع [تعليمات تثبيت Node.js الرسمية][nodejs-install] الخاصة بنظامك.

## تثبيت الاعتماديات

كل تمرين في ReScript هو مشروع npm قائم بذاته.
بعد تنزيل تمرين باستخدام [Exercism CLI][exercism-cli]، ثبّت اعتماديات المشروع بما فيها ReScript وستكون جاهزًا للبدء:

```sh
cd /path/to/exercise
npm install
```

## دعم المحررات

يحافظ مشروع ReScript على [قائمة بإضافات المحررات الرسمية والمدعومة من المجتمع][rescript-plugins].
