# مقدمة

## القوائم

القوائم مدمجة في لغة Elixir. وتُعتبر نوعًا أساسيًا، يُشار إليها بالأقواس المربعة. قد تكون القوائم فارغة أو تحتوي على أي عدد من العناصر من أي نوع. على سبيل المثال:

```elixir
empty_list = []
one_item_list = [1]
two_item_list = [1, 2]
multiple_type_list = [1, :pi, 3.14, "four"]
```

تطبّق Elixir القوائم كقائمة مترابطة، حيث تخزّن كل عقدة قيمتين: العنصر الأول وقائمة أخرى تضم كل العناصر المتبقية. يُشار إلى العنصر الأول في القائمة باسم _الرأس_، وتسمى قائمة العناصر المتبقية _الذيل_. يمكننا استخدام هذا التدوين في الكود:

```elixir
# [1] represented in [head | tail] notation
[1 | []]

# [1, 2, 3] represented in [head | tail] notation
[1 | [2 | [3 | []]]]
```

يمكننا استخدام التدوين _`[head | tail]`_ لإضافة عناصر إلى مقدمة القائمة:

```elixir
# Suppose
list = [2, 1]

[3, 2, 1] == [3 | list]
# => true
```

توجد عدة دوال في وحدة `Kernel` للتعامل مع القوائم، بالإضافة إلى وحدة `List` بأكملها.

```elixir
# Check if 1 is a member of the list
1 in [1, 2, 3, 4]
# => true
```
