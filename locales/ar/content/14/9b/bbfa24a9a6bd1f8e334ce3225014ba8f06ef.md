# مقدمة

مخزن السلاسل النصية طريقة فعّالة لبناء سلسلة نصية كبيرة عبر إلحاق عناصر صغيرة ببعضها. وعلى عكس `String`، فإن نسخة `StringBuf` قابلة للتغيير، بمعنى أنه يمكن تمريرها كوسيط إلى دوال تعدّلها بإلحاق قيم إضافية.

```haxe
var a = new StringBuf();
a.add("Hello");
trace(a.toString()); // Hello
a.add("Haxe!");
trace(a.toString()); // HelloHaxe
```
