# نبذة

تمثّل السلسلة النصية بيانات نصية.
في Swift، [`String`][strings-and-characters] مجموعة مرتّبة من قيم `Character`، ويمثّل كل `Character` فيها حرفًا واحدًا من حروف يونيكود.

تُنشئ سلسلة نصية باستخدام نص حرفي، وهو تسلسل من الحروف محاط بعلامتَي اقتباس مزدوجتين (`"`).
أما السلاسل النصية متعددة الأسطر، فاستخدم ثلاث علامات اقتباس مزدوجة (`"""`):

```swift
let hello: String = "Hello, World!"

let poem: String = """
Roses are red,
Violets are blue.
Sugar is sweet,
And so are you.
"""
```

تتصل السلاسل النصية في Swift بسلاسة مع صنف [`NSString`][nsstring-docs] في إطار عمل Foundation، مما يتيح الوصول إلى قدرات واسعة في معالجة النصوص.

## الحروف

يمثّل `Character` عنقودًا رسوميًا ممتدًا واحدًا، وهو حرف يمكن للبشر قراءته ويتكوّن من [قيم يونيكود القياسية][unicode-scalar-values] واحدة أو أكثر.
وقيمة يونيكود القياسية هي نقطة ترميز من 21 بت تقع في النطاق من `U+0000` إلى `U+D7FF` ضمنًا، أو من `U+E000` إلى `U+10FFFF` ضمنًا.

```swift
let aChar: Character = "A"
```

## استنتاج النوع

عند كتابة نص حرفي، يستنتج Swift نوعه تلقائيًا على أنه `String`.
ولتخزين حرف واحد على هيئة `Character`، يجب أن تكتب تحديدًا صريحًا للنوع:

```swift
let aString = "A"        // Inferred as String
let aChar: Character = "A" // Explicitly typed as Character
print(type(of: aString)) // Prints String
print(type(of: aChar))   // Prints Character

// The following code will not compile:
let badChar: Character = "Too many characters"
// Error: Cannot convert value of type 'String' to specified type 'Character'
```

## الدمج

يمكنك ضمّ السلاسل النصية بعضها إلى بعض باستخدام عامل الجمع (`+`):

```swift
print("honey" + "comb")
// Prints "honeycomb"
```

لا يمكنك دمج `Character` مع `String` مباشرةً باستخدام `+` دون تحويل الحرف إلى سلسلة نصية أولًا.
ولكن يمكنك استخدام الطريقة [`append(_:)`][append] لإضافة سلسلة نصية أو حرف مباشرةً إلى سلسلة نصية قابلة للتعديل:

```swift
var greeting = "Hello"
let world = ", world"
let period: Character = "."

greeting.append(world)
print(greeting) // Prints "Hello, world"

greeting.append(period)
print(greeting) // Prints "Hello, world."
```

## إدراج القيم في السلاسل النصية

يتيح لك [إدراج القيم في السلاسل النصية][string-interpolation] بناء سلسلة نصية عبر تضمين ثوابت ومتغيرات وقيم حرفية وتعبيرات داخل نص حرفي.
ضع كل تعبير بين قوسين هلاليين مسبوقَين بخط مائل عكسي (`\(` ... `)`):

```swift
let radius = 5.0
let circle = "The area of a circle with radius \(radius) is \(Double.pi * radius * radius)"
print(circle) // Prints "The area of a circle with radius 5.0 is 78.53981633974483"
```

## خصائص السلاسل النصية والحروف

توفّر السلاسل النصية والحروف عدة خصائص لفحص محتواها.

### خصائص السلاسل النصية

من الخصائص الشائعة للسلاسل النصية:

| الخاصية  | الوصف                                    | المثال                          |
| --------- | ---------------------------------------------- | -------------------------------- |
| `isEmpty` | تُرجع `true` إذا لم تحتوِ السلسلة النصية على أي حرف | `"Hello".isEmpty` تُقيَّم إلى `false` |
| `count`   | تُرجع عدد الحروف في السلسلة النصية | `"Hello".count` تُقيَّم إلى `5`       |

للاطلاع على القائمة الكاملة للخصائص، راجع [توثيق String من Apple][string-docs].

### خصائص الحروف

من الخصائص الشائعة للحروف:

| الخاصية       | الوصف                                   | المثال                              |
| -------------- | --------------------------------------------- | ------------------------------------ |
| `isLowercase`  | تُرجع `true` إذا كان الحرف صغيرًا  | `"a".isLowercase` تُقيَّم إلى `true` |
| `isUppercase`  | تُرجع `true` إذا كان الحرف كبيرًا  | `"A".isUppercase` تُقيَّم إلى `true` |
| `isNumber`     | تُرجع `true` إذا كان الحرف رقمًا    | `"1".isNumber` تُقيَّم إلى `true`    |
| `isWhitespace` | تُرجع `true` إذا كان الحرف مسافة بيضاء | `" ".isWhitespace` تُقيَّم إلى `true`|

للاطلاع على القائمة الكاملة للخصائص، راجع [توثيق Character من Apple][character-docs].

## تحويل الأنواع

يمكنك تحويل أنواع أخرى إلى سلاسل نصية باستخدام البانية `String(_:)`، التي تدعم أنواعًا قياسية مثل `Int` و`Double` و`Character`:

```swift
let charX: Character = "x"
print(String(charX))     // Prints "x"
print(String(110))       // Prints "110"
print(String(Double.pi)) // Prints "3.141592653589793"
```

## الحروف الخاصة

تدعم النصوص الحرفية في Swift عدة [تسلسلات هروب][special-characters] للحروف الخاصة:

| التسلسل   | الوصف                   |
| ---------- | ----------------------------- |
| `\0`       | المحرف الفارغ                |
| `\\`       | خط مائل عكسي                     |
| `\t`       | مسافة جدولة أفقية                |
| `\n`       | تغذية سطر (سطر جديد)           |
| `\r`       | عودة العربة               |
| `\'`       | علامة اقتباس مفردة         |
| `\"`       | علامة اقتباس مزدوجة         |
| `\u{n}`    | قيمة يونيكود قياسية اعتباطية (ست عشرية) |

```swift
let quote: String = "\"Hello\", he said."
print(quote) // Prints "Hello", he said.

let unicode: Character = "\u{1F496}"
print(unicode) // Prints 💖
```
