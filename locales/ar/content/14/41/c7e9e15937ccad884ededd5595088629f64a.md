# التعليمات

عجلة التشفير عبارة عن قرصين، أحدهما داخل الآخر، يدوّران الحروف الأبجدية في حلقة: اضبطها على 3 فيصبح كل حرف هو الحرف الذي يبعد ثلاثة مواضع، ويعود `z` من جديد إلى `a`. يستخدمها المحققون منذ قرون. وأنت الآن تبني واحدة.

المهام الخمس كلها تُكتب داخل الصنف `CIPHER_WHEEL`.

## 1. هل هو حرف؟

```sather
CIPHER_WHEEL::is_letter('m')
-- => true
CIPHER_WHEEL::is_letter('7')
-- => false
```

## 2. اصرخ به

أرجِع الحرف الكبير للمحرف. وأي شيء ليس حرفًا يعود من دون تغيير.

```sather
CIPHER_WHEEL::shout('m')
-- => 'M'
```

## 3. ما هو العدد؟

أرجِع العدد الذي يرمز إلى المحرف.

```sather
CIPHER_WHEEL::code('a')
-- => 97
```

## 4. المحرف الأول

أرجِع المحرف الأول من سلسلة نصية.

```sather
CIPHER_WHEEL::first_character("Marlowe")
-- => 'M'
```

## 5. أدِر العجلة

إذا أُعطيت حرفًا صغيرًا وعددًا من المواضع، فأرجِع الحرف الذي يبعد بهذا العدد من المواضع في الأبجدية. وما بعد `z` يعود إلى `a` من جديد.

```sather
CIPHER_WHEEL::turn('a', 3)
-- => 'd'
CIPHER_WHEEL::turn('z', 1)
-- => 'a'
```

التدوير إلى الخلف يعمل أيضًا، بعدد سالب من المواضع.

```sather
CIPHER_WHEEL::turn('a', -1)
-- => 'z'
```

يمكنك افتراض أن المحرف المُعطى هو حرف صغير.
