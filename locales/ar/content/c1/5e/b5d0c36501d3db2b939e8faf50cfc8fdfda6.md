# مقدمة

في Common Lisp، يُمثَّل الوقت بأربعة أساليب، سنتناول اثنين منها هنا.

- الوقت العالمي هو وقت مطلق، عدد صحيح يمثّل عدد الثواني منذ `1900-01-01T00:00:00Z` (أي منتصف ليل الأول من يناير عام 1900 بالتوقيت العالمي المنسق).
- الوقت المفكوك هو تسلسل من 9 قيم تمثّل معًا وقتًا تقويميًا محددًا: الثواني، والدقائق، والساعة، ويوم الشهر، والشهر، والسنة، ويوم الأسبوع، ومؤشر التوقيت الصيفي، والمنطقة الزمنية.
(نناقشها بالتفصيل أدناه.)

## الوقت العالمي

للحصول على الوقت العالمي الحالي نستخدم `get-universal-time` أو `get-decoded-time`.
تُرجع الأولى عدد الثواني الحالي منذ `1900-01-01T00:00Z`، وتُرجع الثانية البيانات نفسها بصيغة مفكوكة.

## الوقت المفكوك

`decode-universal-time` و`encode-universal-time` هما الدالتان الأساسيتان للتعامل مع الوقت.
تأخذ الأولى وقتًا عالميًا وتُرجع قيمة وقت مفكوكة على هيئة [قيم متعددة][concept-multiple-values]، وتأخذ الثانية قيم الوقت المفكوك كوسائط وتُرجع وقتًا عالميًا.

تأخذ كلتاهما وسيطًا اختياريًا للمنطقة الزمنية.
انظر أدناه لمعرفة صيغة المنطقة الزمنية.

الوقت المفكوك هو مجموعة من القيم:

- *الثواني*: عدد صحيح بين 0 و59
- *الدقائق*: عدد صحيح بين 0 و59
- *الساعة*: عدد صحيح بين 0 و23
- *يوم الشهر*: عدد صحيح بين 1 و31 (الحد الأعلى يعتمد في الواقع على الشهر والسنة، بطبيعة الحال)
- *الشهر*: عدد صحيح بين 1 و12
- *السنة*: عدد صحيح يدل على السنة.
- *يوم الأسبوع*: عدد صحيح بين 0 و6. يعني 0 يوم الاثنين، و1 يوم الثلاثاء، وهكذا... و6 يوم الأحد.
- *مؤشر التوقيت الصيفي*: قيمة صحيح تعني أن التوقيت الصيفي ساري المفعول.
- *المنطقة الزمنية*: عدد من الساعات بين -24 و24 يدل على الفارق عن التوقيت العالمي المنسق.
العدد عدد نسبي ويجب أن يكون من مضاعفات `1/3600`

```lisp
(encode-universal-time 1 2 3 4 5 2000 0) ; => 3166398121
(decode-universal-time 3166398121)       ; => 1
                                         ;    2
                                         ;    3
                                         ;    4
                                         ;    5
                                         ;    2000
                                         ;    3 (Thursday)
                                         ;    NIL
                                         ;    0
(decode-universal-time 2208988800) ; => 0
                                   ;    0
                                   ;    0
                                   ;    1
                                   ;    1
                                   ;    1970
                                   ;    3
                                   ;    NIL
                                   ;    0
```
