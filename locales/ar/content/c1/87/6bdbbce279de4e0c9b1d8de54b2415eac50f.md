# مقدمة

تُحاط السلاسل النصية في Elixir بعلامات اقتباس مزدوجة، وتُرمَّز بترميز UTF-8:

```elixir
"Hi!"
```

يمكن دمج السلاسل النصية باستخدام العامل `<>/2`:

```elixir
"Welcome to" <> " " <> "New York"
# => "Welcome to New York"
```

تدعم السلاسل النصية في Elixir الإقحام باستخدام الصيغة `#{}`:

```elixir
"6 * 7 = #{6 * 7}"
# => "6 * 7 = 42"
```

لإضافة محرف سطر جديد إلى سلسلة نصية، استخدم رمز الهروب `\n`:

```elixir
"1\n2\n3\n"
```

للتعامل بارتياح مع النصوص التي تحتوي على الكثير من أسطر جديدة، استخدم بدلًا من ذلك صيغة heredoc بعلامات الاقتباس الثلاثية:

```elixir
"""
1
2
3
"""
```

توفّر Elixir العديد من الدوال للتعامل مع السلاسل النصية في وحدة `String`.
