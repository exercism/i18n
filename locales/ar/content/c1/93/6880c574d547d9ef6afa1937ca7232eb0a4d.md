# نبذة

[الدالة عالية الرتبة](https://docs.microsoft.com/en-us/dotnet/fsharp/introduction-to-functional-programming/first-class-functions) هي دالة تحقق أحد الأمرين:

- تأخذ دالة كوسيط
- تُرجع دالة

الوسيط الذي هو دالة ليس سوى وسيط عادي، إلا أنه وسيط يمكنك استدعاؤه.

```fsharp
let double = fun x -> x * 2

let apply f x = f x

apply double 3
// => 6
```
