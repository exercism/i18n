# التعليمات

في هذا التمرين ستتعامل مع سطور السجل.

كل سطر سجل هو سلسلة نصية منسّقة كالتالي: `"[<LVL>]: <MESSAGE>"`.

هذه هي مستويات السجل المختلفة:

- `TRC` (trace)
- `DBG` (debug)
- `INF` (info)
- `WRN` (warning)
- `ERR` (error)
- `FTL` (fatal)

لديك ثلاث مهام.

## 1. تحليل مستوى السجل

عرّف تعداد `LogLevel` يحتوي على ستة عناصر تقابل مستويات السجل المذكورة أعلاه.

- `TRACE`
- `DEBUG`
- `INFO`
- `WARNING`
- `ERROR`
- `FATAL`

بعد ذلك، نفّذ الطريقة `LogLine.getLogLevel()` التي تُرجع مستوى السجل المُحلَّل لسطر السجل:

```java
var logLine = new LogLine("[INF]: File deleted");
logLine.getLogLevel();
// => LogLevel.INFO
```

## 2. دعم مستوى سجل غير معروف

لسوء الحظ، تحمل بعض سطور السجل أحيانًا مستوى سجل غير معروف.
للتعامل مع هذه السطور بسلاسة، أضف عنصر `UNKNOWN` إلى تعداد `LogLevel`، والذي ينبغي إرجاعه عند تحليل مستوى سجل غير معروف:

```java
var logLine = new LogLine("[XYZ]: Overly specific, out of context message");
logLine.getLogLevel();
// => LogLevel.UNKNOWN
```

## 3. تحويل سطر السجل إلى صيغة مختصرة

مستوى السجل في سطر السجل مطوّل نوعًا ما.
لتقليل مساحة القرص اللازمة لتخزين سطور السجل، طُوّرت صيغة مختصرة: `"[<ENCODED_LEVEL>]:<MESSAGE>"`.

مستوى السجل المشفَّر هو ربط بسيط بين مستوى السجل وعدد:

- `UNKNOWN` - `0`
- `TRACE` - `1`
- `DEBUG` - `2`
- `INFO` - `4`
- `WARNING` - `5`
- `ERROR` - `6`
- `FATAL` - `42`

نفّذ الطريقة `LogLine.getOutputForShortLog()` التي تستطيع إخراج صيغة سطر السجل المختصرة:

```java
var logLine = new LogLine("[ERR]: Stack Overflow");
logLine.getOutputForShortLog();
// => "6:Stack Overflow"
```
