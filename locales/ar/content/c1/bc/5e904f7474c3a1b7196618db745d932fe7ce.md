# نبذة

## أنواع الدوال

رأينا سابقًا كيف تُعرَّف توقيعات الدوال باستخدام اسم الدالة متبوعًا بقائمة من تسميات المعاملات مفصولة بفواصل مع أنواعها، ثم `->` ونوع القيم التي تُرجعها الدالة.

إذا أزلنا كل الأسماء والتسميات من هذا التوقيع، فسنحصل على [نوع الدالة][function-types].

```swift
func shoppingList(item: String, quantity: Int) -> String {
  "You need to buy \(quantity) \(item)."
}
// shoppingList: (String, Int) -> String

func repeater(_ phrase: String, times: Int) -> String {
  var result = ""
  for _ in 1...times {
    result += phrase
  }
  return result
}
// repeater: (String, Int) -> String

func printString(line: String) {
  print(line)
}
// printString: (String) -> ()
```

لاحظ أن نوعي الدالتين الأولى والثانية متماثلان، `(String, Int) -> String`، رغم أن الدالتين تعملان بطريقة مختلفة تمامًا. فكلتاهما تأخذ `String` و`Int` كمدخل وتُرجع `String`. وكما يظهر من نوع الدالة الثالثة، فرغم أنها لا تبدو مُرجِعة لأي شيء، إلا أنها في الحقيقة تُرجع `()`، وهي القيمة الوحيدة من النوع `Void`. لاحظ أن `()` و`Void` يمكن استخدامهما بالتبادل كاسمين للنوع، لذا يمكن أيضًا كتابة نوع `printString` على الصورة `String) -> Void`.

يمكن استخدام هذه الأنواع بالطريقة نفسها التي تُستخدم بها أي أنواع أخرى في Swift، فمثلًا يمكن استخدامها في تعريف المتغيرات أو الثوابت. ولأن الدوال قيم في Swift، يمكن إسناد الدوال الموجودة أصلًا إلى هذه الثوابت أو المتغيرات:

```swift
var stringAndIntToString: (String, Int) -> String

stringAndIntToString = shoppingList
stringAndIntToString("carrots", 3)
// => "You need to buy 3 carrots."

stringAndIntToString = repeater
stringAndIntToString("carrots", 3)
// => "carrotscarrotscarrots"
```

وكما هو الحال مع المتغيرات والثوابت الأخرى، يجب أن تكون القيمة التي تُسندها من النوع الصحيح:

```swift
stringAndIntToString = printShoppingList
// Error: Cannot assign value of type '(String) -> ()' to type '(String, Int) -> String'
```

## أنواع الدوال كأنواع للمعاملات

بما أن أنواع الدوال يمكن استخدامها في أي موضع يمكن استخدام أنواع أخرى فيه، فيترتب على ذلك [أنه يمكن استخدامها كأنواع للمعاملات][functions-as-parameters] وتمريرها إلى دوال أخرى واستدعاؤها من داخل تلك الدوال.

```swift
func apply3(to str: String, function f: (String, Int) -> String) -> String {
  f(str,3)
}
// apply3: ([String], (String, Int) -> String) -> [String]

apply3(to: "eggs", function: shoppingList)
// => "You need to buy 3 eggs."

apply3(to: "eggs", function: repeater)
// => "eggseggseggs"

func apply(functions fs: [(String, Int) -> String],
           to string: String,
          ) -> [String] {
  var result = [String]()
  for f in fs {
    result.append(f(string, 3))
  }
  return result

}
// apply: ([(String, Int) -> String], String) -> [String]


apply(functions: [shoppingList, repeater], to: "carrots")
// => ["You need to buy 3 carrots.", "carrotscarrotscarrots"]
```

## أنواع الدوال كأنواع للقيم المُرجَعة

وبالمثل، [يمكن استخدام أنواع الدوال كأنواع للقيم المُرجَعة][functions-as-returns] من الدوال. بعبارة أخرى، يمكنك كتابة دوال تُنشئ دوال أخرى وتُرجعها. وعند إنشاء هذه الدوال، يمكن للدالة المُرجَعة أن تستخدم المعاملات الأخرى الممرَّرة إلى الدالة أو المتغيرات المحلية المُنشأة داخل الدالة الأب.

```swift
func makeAdder(base: Int) -> (Int) -> Int {
  func adder(_ i: Int) -> Int {
    base + i
  }
  return adder
}
// makeAdder: (Int) -> (Int) -> Int

let add10 = makeAdder(base: 10)
// add10: (Int) -> Int

let subtract20 = makeAdder(base: -20)
// subtract10: (Int) -> Int

add10(5)
// => 15

subtract20(5)
// => -15
```

## التقاط القيم

كما رأينا مع الدالة `makeAdder(base:)` أعلاه، تستطيع الدوال المتداخلة الوصول إلى معاملات الدوال المحيطة بها ومتغيراتها. بالإضافة إلى ذلك، تستطيع الحفاظ على هذا الوصول إلى هذه القيم بعد انتهاء الدالة الحاوية. تُعرف عملية الحصول على هذا الوصول والحفاظ عليه باسم [_الالتقاط_][capturing-values].

## الدوال عالية الرتبة

الدوال التي تأخذ دوالًا كمعاملات و/أو تُرجع دوالًا تُعرف بالدوال عالية الرتبة. تحتوي Swift على العديد من الدوال عالية الرتبة في مكتباتها المختلفة. على سبيل المثال، الطريقة `sorted(by:)` المتاحة على مجموعات Swift مثل `Array`، والتي تأخذ، بالنسبة إلى مصفوفة عناصرها من النوع `T`، دالة من النوع `(T, T) -> Bool` تُحدد أي القيمتين ينبغي أن تأتي قبل الأخرى في مصفوفة مرتبة، فتُرجع `true` إذا كان ينبغي أن تظهر القيمة اليسرى أولًا و`false` إذا كان ينبغي أن تظهر القيمة اليمنى أولًا.

مثال آخر هو الطريقة `contains(where:)` على المجموعات، والتي تأخذ، بالنسبة إلى مجموعة عناصرها من النوع `T`، دالة من النوع `(T) -> Bool` تُرجع `true` إذا حقق العنصر خاصية ما و`false` خلاف ذلك. بعدها تُرجع `contains(where:)` القيمة `true` إذا حقق أحد عناصر المجموعة هذه الخاصية.

```swift
func longer(_ strA: String, _ strB: String) -> Bool {
  strA.count > strB.count
}
// longer: (String, String) -> Bool

["apple", "ball", "carrot"].sorted(by: longer)
// => ["carrot", "apple", "ball"]

["apple", "ball", "carrot"].sorted(by: >)
// => ["carrot", "ball", "apple"]


func isBig(_ i: Int) -> Bool {
  i > 100
}
// isBig: (Int) -> Bool

func isVowel(_ char: Character) -> Bool {
  switch char.lowercased() {
  case "a", "e", "i", "o", "u": return true
  default: return false
  }
}
// isVowel: (Character) -> Bool

[1, 75, 3, 99].contains(where: isBig)
// => false

"Owl".contains(where: isVowel)
// => true

```
