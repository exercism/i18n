# ملحق التعليمات

## تلميحات

لإكمال هذا التمرين، عليك إنشاء نوع البيانات `CustomSet`، مع نسختَي `Eq` و`Show`، وتنفيذ الدوال التالية:

- `delete`
- `difference`
- `empty`
- `fromList`
- `insert`
- `intersection`
- `isDisjointFrom`
- `isSubsetOf`
- `member`
- `null`
- `size`
- `toList`
- `union`

ستجد إعلان بيانات وهميًا وتوقيعات الأنواع جاهزة بالفعل، لكن الأمر متروك لك لتعريف الدوال وإنشاء نوع بيانات ذي معنى، أو newtype أو مرادف نوع.

إن كنت مهتمًا بكتابة تنفيذ فعّال لكنك لا تعرف تمامًا من أين تبدأ، فأفضل مقدمة أعرفها هي كتاب Chris Okasaki بعنوان "Purely Functional Data Structures"، ويمكنك قراءة نسخة منه هنا:
https://www.cs.cmu.edu/~rwh/theses/okasaki.pdf
