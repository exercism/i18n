# عنصر نائب

## قيم ASCII

يتطلب هذا التمرين تحويل محارف ASCII من قيمتها الرقمية وإليها. وتوفّر [إضافة ordchr][ordchr] في GNU awk هذه الوظيفة. لإضافة الدالتين `ord()` و `chr()`، حمّل إضافة `ordchr` بإضافة توجيه `@load` إلى أعلى ملفك:

```
@load "ordchr"
```

[ordchr]: https://www.gnu.org/software/gawk/manual/gawk.html#Extension-Sample-Ord
