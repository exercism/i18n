# ملحق التعليمات

## حزمة الفرز

يتطلب منك هذا التمرين فرز مصفوفة، لكن هذا غير مدمج في المكتبة القياسية. يمكنك كتابة مكتبة فرز خاصة بك، لكن الخيار الأفضل هو استخدام [حزمة sorts](https://github.com/diku-dk/sorts).

يمكنك استخدام هذه الحزمة في حلّك بتشغيل الأمر التالي في مجلد الحل:

```shell
futhark pkg add github.com/diku-dk/sorts
futhark pkg sync
```

ثم استورد [خوارزميات الفرز التي تريدها](https://github.com/diku-dk/sorts/tree/master/lib/github.com/diku-dk/sorts) عبر:

```futhark
import "lib/github.com/diku-dk/sorts/<sorting algorithm>"
```
