# نبذة

تجمع [الصفوف][tuples] قيمًا متعددة في قيمة مركبة واحدة.
وعلى عكس المصفوفات، لا يلزم أن تشترك القيم داخل الصف في النوع نفسه، كما أن حجم الصف ثابت بمجرد إنشائه.

أنشئ صفًا بوضع قيم مفصولة بفواصل داخل الأقواس الهلالية:

```swift
let order = ("biscuits", 2.99, 3)
```

يمكنك أيضًا تحديد تعليقات النوع صراحةً:

```swift
let order: (String, Double, Int) = ("biscuits", 2.99, 3)
```

لاستخراج العناصر الفردية من صف غير مسمّى، استخدم صيغة الفهرس الذي يبدأ من الصفر (`.0` و`.1` وهكذا):

```swift
let item = order.0     // "biscuits"
let quantity = order.2 // 3
```

## الصفوف المسمّاة

يمكنك إعطاء أسماء لعناصر الصف الفردية عند تعريف الصف:

```swift
let order = (item: "biscuits", price: 2.99, quantity: 3)
```

تسمية العناصر تجعل الكود أكثر وضوحًا وتتيح لك الوصول إلى العناصر باستخدام تدوين النقطة مع تسمياتها:

```swift
let item = order.item         // "biscuits"
let quantity = order.quantity // 3
```

يمكنك أيضًا تضمين أسماء العناصر في تعليق النوع:

```swift
let order: (item: String, price: Double, quantity: Int) = (item: "biscuits", price: 2.99, quantity: 3)
```

## تعديل الصفوف

إذا عُرّف الصف كمتغير (`var`)، يمكنك تحديث عناصره:

```swift
var order = ("biscuits", 2.99, 3)
order.0 = "cookies"
order.1 = 1.99
order.2 = 5

print(order)
// Prints ("cookies", 1.99, 5)
```

## إرجاع قيم متعددة

بينما يمكن لدوال Swift إرجاع قيمة واحدة فقط، فإن إرجاع صف يتيح لك تجميع وإرجاع [قيم متعددة][multiple-return-values] من دالة:

```swift
func divide(_ dividend: Int, by divisor: Int) -> (quotient: Int, remainder: Int) {
    let quotient = dividend / divisor
    let remainder = dividend % divisor
    return (quotient, remainder)
}

let result = divide(14, by: 4)
print("Quotient: \(result.quotient), Remainder: \(result.remainder)")
// Prints "Quotient: 3, Remainder: 2"
```

## تفكيك الصف

يمكنك تفكيك (فك) قيم الصف إلى ثوابت أو متغيرات منفصلة:

```swift
let order = ("biscuits", 2.99, 3)
let (item, price, quantity) = order

print(item) // Prints "biscuits"
```

يعمل تفكيك الصف أيضًا مباشرةً داخل حلقات `for-in`:

```swift
let orders = [("biscuits", 2.99, 3), ("cookies", 1.99, 5)]

for (item, price, quantity) in orders {
    print("Item: \(item), Price: \(price), Quantity: \(quantity)")
}
```
