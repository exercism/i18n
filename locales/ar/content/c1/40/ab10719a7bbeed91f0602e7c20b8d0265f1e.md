# مقدمة

## مطابقة الأنماط

يمكن استخدام تعبير `if/elif/else` لتنفيذ المنطق بشكل شرطي. وتمتلك F# أيضًا أسلوبًا آخر وأقوى لتنفيذ المنطق بشكل شرطي، وهو مطابقة الأنماط. فمع مطابقة الأنماط، يمكن اختبار قيمة مقابل نمط واحد أو أكثر. ومن أمثلة هذه الأنماط _النمط الثابت_، الذي يطابق قيمة مقابل ثابت (مثل `1` أو `"hello"`).

في F#، تُجرى مطابقة الأنماط عبر الكلمة المفتاحية `match`:

```fsharp
let describe number =
    match number with
    | 0 -> "Zero"
    | 1 -> "One"
```

قد يبدو هذا مشابهًا لعبارات `switch` في لغات أخرى، لكن مطابقة الأنماط تتألق عندما تستخدم أنماطًا أخرى أيضًا. ومن هذه الأنماط _نمط المتغير_، الذي يتيح لك التقاط قيمة:

```fsharp
match number with
| 0 -> "Zero"
| i -> sprintf "Non zero: %d" i
```

في بعض الحالات، قد ترغب في إضافة شرط إضافي إلى نمط ما. وهذا ما يُعرف بالحارس (أي جملة الحارس)، ويمكن إضافته باستخدام الكلمة المفتاحية `when`:

```fsharp
match number with
| 0 -> "Zero"
| i when i < 0 -> "Negative number"
```

في المثال أعلاه، ليست كل المدخلات الممكنة لها نمط مطابق. وسيكتشف المترجم ذلك ويُصدر تحذيرًا. وهذا ما يُعرف بالتحقق الشامل. ولحل التحذير، عليك معالجة جميع الحالات. ولهذا، يمكن استخدام _نمط البديل_، وهو نمط يطابق أي قيمة:

```fsharp
match number with
| i when i < 0 -> "Negative number"
| _ -> "Positive number"

// No compiler warning
```

تختبر مطابقة الأنماط قيمة مقابل كل نمط من الأعلى إلى الأسفل، حتى تجد نمطًا مطابقًا وتنفذ المنطق المرتبط بذلك النمط. ترتيب الأنماط مهم!
