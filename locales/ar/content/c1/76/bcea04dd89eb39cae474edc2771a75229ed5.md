# ملحق التعليمات

## التنفيذ

في هذا التمرين ستُطبّق إجراءً مهمته تخصيص السلسلة النصية التي يُرجعها. أما إلغاء تخصيص السلسلة النصية فهي مسؤولية من يستدعي هذا الإجراء.

```odin
// The procedure will be called like that:
converted := convert(3)
// ...
// and eventually the caller will delete the string
delete(converted)
```
