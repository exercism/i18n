# نبذة

## مقدمة

الأنواع العامة ميزة من ميزات اللغة تتيح إعادة استخدام الكود.
على سبيل المثال، لا ينبغي أن يهم نوع العناصر التي تحتفظ بها المصفوفة من أجل حساب طولها.
لهذا السبب تستخدم دالة `length` معامل نوع عام اسمه `a` في توقيع نوعها.

```elm
length : List a -> Int
```

## معاملات الأنواع

عندما يكون نوع ما عامًّا إزاء نوع آخر، نكتب اسم ذلك النوع الآخر بحروف صغيرة، ونسميه معامل نوع.
من الأمثلة الشائعة الأنواع المخصصة `List` و`Maybe` و`Result`.

```elm
-- Maybe is generic over the type a
type Maybe a
    = Nothing
    | Just a

someString : Maybe String
someString = Just "hello"

someInt : Maybe Int
someInt = Just 42
```

من الملاحظات المهمة بشأن أسماء معاملات الأنواع أنها يمكن أن تتكوّن من أكثر من حرف.
القيد الوحيد هو أن تكون أسماء بحروف صغيرة.
لذلك، عندما يكون ذلك مفيدًا، نميل إلى منحها أسماء وصفية.

يمكن أن يكون النوع عامًّا إزاء عدة أنواع أخرى، وبالتالي أن يمتلك عدة معاملات أنواع.
في هذه الحالة، يحصل كل نوع مستقل على اسم مختلف بحروف صغيرة.
كونها مستقلة لا يمنعها من أن تصبح النوع نفسه، بل يتيح لها فقط أن تكون مختلفة.

```elm
-- Result is generic over the types error and value
type Result error value
    = Ok value
    | Err error
```

يمكن أن تمتلك الأسماء المستعارة لأنواع السجلات معاملات أنواع أيضًا، مع أن ذلك أقل شيوعًا.

```elm
-- Event is generic over the type a
type alias Event a =
    { at : Time
    , data : a 
    }
```

> لهذا السبب تعرّف حزمة `Html` النوع `Html msg` بمعامل نوع واحد اسمه `msg`.
> وترشدك معمارية Elm إلى إنشاء نوع مخصص `Msg` يصف كل الرسائل التي يمكن لصفحتك أن تُطلقها.
> ونتيجة لذلك، سيبني كودك واجهات من النوع `Html Msg`، حيث `Msg` هو النوع الملموس الذي عرّفته أنت.
> يخلط المبتدئون أحيانًا بين الأخطاء التي تذكر `Html msg` (بحروف صغيرة) والأخطاء التي تذكر `Html Msg`.
> الآن عرفت الفرق!
> الفرق أن الأول عام إزاء أي نوع `msg`، بينما الثاني خاص بنوعك `Msg`.

## معاملات الأنواع في الدوال

بما أن الأنواع يمكن أن تكون عامة، فكذلك الدوال.
يمكن كتابة دوال تتعامل مع أنواع عامة، مثل `Maybe.withDefault`.

```elm
withDefault : a -> Maybe a -> a
withDefault default maybe =
    case maybe of
      Just value -> value
      Nothing -> default
```

الدوال التي تأخذ دوال أخرى كوسائط تسمى دوال ذات رتبة أعلى، ويمكن أن تكون هذه أيضًا عامة.

```elm
map : (a -> b) -> Maybe a -> Maybe b
map function maybe =
  case maybe of
    Just value ->
      Just (function value)

    Nothing ->
      Nothing
```

يمكن أن تظهر معاملات الأنواع في مدخلات الدالة ومخرجاتها معًا، وعادة ما يسمى العموم الذي تتيحه معاملات الأنواع **تعدد الأشكال المعلمي**.
وهذا على النقيض من تعدد الأشكال العرضي، المعروف أيضًا بالتحميل الزائد للدوال، حيث يمكن استخدام اسم الدالة نفسه في عدة تطبيقات تختلف فيها الأنواع.
ويتناقض هذا أيضًا مع تعدد الأشكال الفرعي، حيث يمكن تعريف الأنواع في هرمية، ويمكن استدعاء الدوال المعرّفة على نوع ما بوسائط من أنواعه الفرعية.
في Elm، الميكانيزم الوحيد المتاح للعموم هو تعدد الأشكال المعلمي.
