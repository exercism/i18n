# التعليمات

في هذا التمرين ستحتاج إلى تنفيذ بعض الدوال للتعامل مع مصفوفة من لغات البرمجة.

## 1. عرّف دالة تُرجع مصفوفة لغات فارغة

عرّف الدالة `new` التي لا تأخذ أي وسائط وتُرجع مصفوفة فارغة.

```haskell
new
-- -> []
```

## 2. عرّف دالة تضيف لغة إلى المصفوفة

عرّف الدالة `add/2` التي تأخذ وسيطين (_مصفوفة لغات_ وسلسلة نصية حرفية تمثل _لغة_).
ويجب أن تُرجع المصفوفة الناتجة بعد إضافة اللغة الجديدة في مقدمة المصفوفة المعطاة.

```haskell
add new "Clojure"
-- -> ["Clojure"]
add ["Clojure"] "Haskell"
-- -> ["Haskell", "Clojure"]
```

## 3. عرّف دالة تحذف لغة من المصفوفة

عرّف الدالة `remove` التي تأخذ وسيطًا واحدًا (_مصفوفة لغات_).
ويجب أن تُرجع المصفوفة دون العنصر الأول. افترض أن المصفوفة ستحتوي دائمًا على عنصر واحد على الأقل.

```haskell
remove ["Haskell", "Clojure", "Erlang"]
-- -> ["Clojure", "Erlang"]
```

## 4. عرّف دالة تُرجع العنصر الأول في المصفوفة

عرّف الدالة `first` التي تأخذ وسيطًا واحدًا (_مصفوفة لغات_).
ويجب أن تُرجع اللغة الأولى في المصفوفة.
افترض أن المصفوفة ستحتوي دائمًا على عنصر واحد على الأقل.

```haskell
first ["Elixir", "Haskell", "Clojure", "Prolog"]
-- -> "Elixir"
```

## 5. عرّف دالة تُرجع عدد اللغات في المصفوفة

عرّف الدالة `count` التي تأخذ وسيطًا واحدًا (_مصفوفة لغات_).
ويجب أن تُرجع عدد اللغات في المصفوفة.

```haskell
count ["Prolog", "Elm"]
-- -> 2
```

## 6. عرّف دالة تحدّد ما إذا كانت المصفوفة تتضمن لغة دالية

عرّف الدالة `isFunctionalList` التي تأخذ وسيطًا واحدًا (_مصفوفة لغات_).
ويجب أن تُرجع قيمة منطقية.
ويجب أن تُرجع `True` إذا كانت _"Haskell"_ إحدى اللغات في المصفوفة.

```haskell
isFunctionalList ["Haskell"]
-- -> True
```
