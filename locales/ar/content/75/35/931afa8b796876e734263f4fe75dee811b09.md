# التعليمات

بالنظر إلى أي قائمتين `A` و`B`، حدّد ما إذا:

- كانت القائمة `A` مساوية للقائمة `B`؛ أو
- كانت القائمة `A` تحتوي القائمة `B` (`A` قائمة فائقة للقائمة `B`)؛ أو
- كانت القائمة `A` محتواة في القائمة `B` (`A` قائمة فرعية للقائمة `B`)؛ أو
- لم يتحقق أي مما سبق، وبالتالي فإن القائمتين `A` و`B` غير متساويتين

وبشكل محدد، القائمة `A` مساوية للقائمة `B` إذا احتوت القائمتان القيم نفسها بالترتيب نفسه. والقائمة `A` قائمة فائقة للقائمة `B` إذا كانت `A` تحتوي تسلسلًا فرعيًا من القيم يساوي `B`. والقائمة `A` قائمة فرعية للقائمة `B` إذا كانت `B` تحتوي تسلسلًا فرعيًا من القيم يساوي `A`.

أمثلة:

- إذا كانت `A = []` و`B = []` (كلتا القائمتين فارغة)، فإن `A` و`B` متساويتان
- إذا كانت `A = [1, 2, 3]` و`B = []`، فإن `A` قائمة فائقة للقائمة `B`
- إذا كانت `A = []` و`B = [1, 2, 3]`، فإن `A` قائمة فرعية للقائمة `B`
- إذا كانت `A = [1, 2, 3]` و`B = [1, 2, 3, 4, 5]`، فإن `A` قائمة فرعية للقائمة `B`
- إذا كانت `A = [3, 4, 5]` و`B = [1, 2, 3, 4, 5]`، فإن `A` قائمة فرعية للقائمة `B`
- إذا كانت `A = [3, 4]` و`B = [1, 2, 3, 4, 5]`، فإن `A` قائمة فرعية للقائمة `B`
- إذا كانت `A = [1, 2, 3]` و`B = [1, 2, 3]`، فإن `A` و`B` متساويتان
- إذا كانت `A = [1, 2, 3, 4, 5]` و`B = [2, 3, 4]`، فإن `A` قائمة فائقة للقائمة `B`
- إذا كانت `A = [1, 2, 4]` و`B = [1, 2, 3, 4, 5]`، فإن `A` و`B` غير متساويتين
- إذا كانت `A = [1, 2, 3]` و`B = [1, 3, 2]`، فإن `A` و`B` غير متساويتين
