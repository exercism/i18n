# تعبيرات `match`

يقيّم تعبير `match` قيمةً وشرطًا، ثم يُرجع تعبيرًا يُقيَّم. وكما في العامل الثلاثي، إذا لم يطابق الشرط، فلا يُقيَّم تعبير الإرجاع. ولمطابقة شرط ما، يُجرى تحقق من الهوية (المساواة الصارمة أو `===`).

```php
<?php
$some_value = 42;

$return_value = match($some_value) {
    0 => 'number is 0',
    1 => 'number is 1',
    default => 'number is something else'
}
```

ولإجراء تحقق من المساواة (`==`)، يمكنك إعادة ترتيب الشرط:

```php
<?php
$some_value = 42;

$return_value = match(true) {
    $some_value < 100 => 'number is less than 100',
    $some_value > 100 => 'number is greater than 100',
    $some_value == 100 => 'number is 100',
}
```

في تعبير `match`، إذا لم يُطابَق أي شرط، فسيُرمى استثناء `UnhandledMatchError`.
