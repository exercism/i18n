# API المدخل

غالبًا ما تكون API المدخل هي الطريقة المثلى للتعامل مع محتويات بنية الخريطة. لكن، على غير المعتاد في Rust، لم تُقنَّن في سمة؛ فهي مجرد مجموعة من الأنواع والطرق المُنفَّذة على أنواع الخرائط في المكتبة القياسية.

في الأساس، توفّر طريقة `map.entry()` `enum`:

```rust
enum Entry {
    Occupied(_),
    Vacant(_),
}
```

تأتي الفائدة من مزيد من الطرق المُنفَّذة على هذا التعداد. على سبيل المثال، إذا أردت الحصول على القيمة لمفتاح معيّن وربما تعديلها، وكان الافتراضي لنوع القيمة مناسبًا، فيمكنك ببساطة القيام بما يلي:

```rust
// `entry` has type `&mut Value` for the value type of the map
let entry = map.entry(key).or_default();
```

في تطبيقات مثل العدّاد، يجعل هذا الأمر الحياة سهلة جدًا:

```rust
let counts: HashMap<_, usize> = HashMap::new();
for item in sequence {
    *counts.entry(item).or_default() += 1;
}
```

إذا لم تكن القيمة الافتراضية للنوع مناسبة لتطبيقك، فيمكنك توفير قيمة افتراضية ثابتة خاصة بك باستخدام `or_insert`، أو حساب واحدة باستخدام `or_insert_with`.

في بعض الحالات، قد ترغب في إجراء عملية حسابية على قيمة موجودة قبل أي إدراج محتمل. في تلك الحالات، تسمح `and_modify` بذلك. ومع ذلك، هذا الاستخدام نادر إلى حد ما. يُستخدم `and_modify` أكثر شيوعًا لتجنب الحاجة إلى إلغاء الإشارة:

```rust
map.entry(key).and_modify(|v| *v += 1).or_default();
```

أحيانًا، قد يكون من المرغوب مطابقة المدخل مباشرة. هذا مسموح به:

```rust
match map.entry(key) {
    Entry::Occupied(occupied) => println!("removed from the map: {:?}", occupied.remove_entry()),
    Entry::Vacant(vacant) => println!("key not present in map: {:?}", vacant.key()),
}
```

لمزيد من المعلومات، راجع [`std::collections::hash_map::Entry`](https://doc.rust-lang.org/std/collections/hash_map/enum.Entry.html) و[`std::collections::btree_map::Entry`](https://doc.rust-lang.org/std/collections/btree_map/enum.Entry.html).
