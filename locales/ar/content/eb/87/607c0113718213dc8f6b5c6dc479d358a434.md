# ملحق التعليمات

## السجلات

| السجل | الاستخدام    | النوع   | الوصف                                        |
| -------- | ------------ | ------- | -------------------------------------------- |
| `$a0`    | إدخال        | عنوان   | سلسلة نصية للاسم منتهية بقيمة null، أو مؤشر null |
| `$a1`    | إدخال/إخراج  | عنوان   | سلسلة نصية للنتيجة منتهية بقيمة null         |
| `$t0-9`  | مؤقت         | أي نوع  | للتخزين المؤقت                               |
