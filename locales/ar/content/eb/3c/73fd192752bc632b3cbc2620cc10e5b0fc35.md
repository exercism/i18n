# مقدمة

عندما تحدد Elixir الدالة التي سيتم استدعاؤها، فإنها تستخدم اسم الوحدة لإجراء بحث. يمكن إجراء البحث ديناميكيًا إذا كان اسم الوحدة مربوطًا بمتغير.

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```

داخليًا، اسم الوحدة هو ذرة. جميع ذرات أسماء الوحدات في Elixir تبدأ تلقائيًا بـ `Elixir.`

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```
