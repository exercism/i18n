# مقدمة

يمثّل Gleam قيمتي صحيح وخطأ بالنوع `Bool`. ولا توجد سوى قيمتين: `True` و`False`. ويمكن ربط هاتين القيمتين بمتغير:

```gleam
let true_variable = True
let false_variable = False
```

يمكن استخدام العوامل `&&` و`||` و`!` للتعامل مع القيم المنطقية:

```gleam
True && True  // -> True
True && False // -> False

False || True  // -> True
False || False // -> False

!False // -> True
!True  // -> False
```

العاملان `&&` و`||` يستخدمان التقييم القصير، أي أن التعبير الواقع على الطرف الأيمن من العامل لا يُقيَّم إلا عند الحاجة.

ولكل عامل أسبقية مختلفة، حيث يُقيَّم `!` قبل `&&` و`||`. ويمكن استخدام الأقواس المعقوفة لتقييم جزء من التعبير قبل بقية الأجزاء:

```gleam
!True && False   // -> False
!{True && False} // -> True
```
