# التعليمات

في هذا التمرين ستكتب بعض الكود لمساعدتك على طهي لازانيا رائعة من كتاب الطبخ المفضل لديك.

لديك أربع مهام، جميعها متعلقة بالوقت المستغرق في طهي اللازانيا.

## 1. عرّف زمن الفرن المتوقع بالدقائق

عرّف الطريقة `Lasagna.expectedMinutesInOven()` التي لا تأخذ أي معاملات وتُرجع عدد الدقائق التي يجب أن تبقى فيها اللازانيا في الفرن. وفقًا لكتاب الطبخ، زمن الفرن المتوقع بالدقائق هو 40:

```scala
val lasagna = new Lasagna()
lasagna.expectedMinutesInOven()
// => 40
```

## 2. احسب زمن الفرن المتبقي بالدقائق

عرّف الطريقة `Lasagna.remainingMinutesInOven()` التي تأخذ كمعامل عدد الدقائق الفعلية التي قضتها اللازانيا في الفرن، وتُرجع عدد الدقائق التي يجب أن تبقى فيها اللازانيا في الفرن، استنادًا إلى زمن الفرن المتوقع بالدقائق من المهمة السابقة.

```scala
val lasagna = new Lasagna()
lasagna.remainingMinutesInOven(30)
// => 10
```

## 3. احسب زمن التحضير بالدقائق

عرّف الطريقة `Lasagna.preparationTimeInMinutes()` التي تأخذ كمعامل عدد الطبقات التي أضفتها إلى اللازانيا، وتُرجع عدد الدقائق التي أمضيتها في تحضير اللازانيا، بافتراض أن تحضير كل طبقة يستغرق منك دقيقتين.

```scala
val lasagna = new Lasagna()
lasagna.preparationTimeInMinutes(2)
// => 4
```

## 4. احسب الزمن المنقضي بالدقائق

عرّف الطريقة `Lasagna.elapsedTimeInMinutes()` التي تأخذ معاملين: المعامل الأول هو عدد الطبقات التي أضفتها إلى اللازانيا، والمعامل الثاني هو عدد الدقائق التي قضتها اللازانيا في الفرن. يجب أن تُرجع الدالة عدد الدقائق التي أمضيتها في طهي اللازانيا، وهو مجموع زمن التحضير بالدقائق، والوقت الذي قضته اللازانيا في الفرن حتى هذه اللحظة.

```scala
var lasagna = new Lasagna()
lasagna.elapsedTimeInMinutes(3, 20)
// => 26
```
