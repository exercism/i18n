# نبذة

يُعبَّر عن معظم التكرار في Factor بالمُركِّبات (`each`، `map`، `reduce`)، لكن للاستدعاء الذاتي الصريح مكانه أيضًا: عندما لا يكون الاستدعاء الذاتي على شكل قائمة، أو عندما تكون الحالة الأساسية غير بديهية، أو عندما تنفّذ مُركِّبًا بنفسك.

```factor
: total ( seq -- sum )
    [ 0 ] [ unclip swap total + ] if-empty ;

: gcd ( a b -- g )
    dup zero? [ drop ] [ tuck mod gcd ] if ;
```

إليك بعض الأمور التي ينبغي معرفتها:

- يمكن لتعريفات `:` العادية أن تستدعي نفسها دون أي صياغة خاصة، ويستنتج المترجم تأثيرات المكدس عبر الاستدعاء الذاتي.
- تتيح لك `loop ( quot -- )` تكرار كتلة كود تُرجع قيمة منطقية، فواصل ما دامت قيمتها صحيحة.
- تُترجم الاستدعاءات الذيلية إلى قفزات، لذا لا تتسبب الكلمات شديدة الاستدعاء الذاتي في فيضان المكدس.

والزوجان `unclip` و`if-empty` هما الشكل القياسي للاستدعاء الذاتي على المتتاليات، أما `cond` فهو الشكل القياسي للتوجيه بين حالات متعددة.
