# ملحق التعليمات

## السجلات

| السجل | الاستخدام | النوع | الوصف |
| -------- | ------------ | ------- | ------------------------------------------- |
| `$a0`    | إدخال        | عدد صحيح | عدد العملات المُدخلة                       |
| `$a1`    | إدخال        | عدد صحيح | الهدف                                      |
| `$a2`    | إدخال/إخراج | عنوان | مصفوفة قابلة للكتابة من كلمات العملات            |
| `$v0`    | إخراج       | عدد صحيح | عدد العملات المُخرَجة، و-1 إذا كان المُدخل غير صالح |
| `$t0-9`  | مؤقت    | أي نوع     | يُستخدم للتخزين المؤقت                  |
