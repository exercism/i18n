# سؤال HTTP بمليار دولار

## بيان المشكلة

طُلب منك إيجاد أعلى `x` ملياردير من حيث الثروة الصافية في مجموعة معطاة من البلدان (عدد البلدان = `N`). ولتنفيذ ذلك، مُنحت صلاحية الوصول إلى API تُرجع تفاصيل المليارديرات حسب البلد.

## القيود

* 1 <= N <= 5
* 1 <= x <= 10

## المثال 1

المدخل

```
Countries: ["United States"]
Limit: 3
```

المخرج

```
["Elon Musk", "Jeff Bezos", "Bill Gates"]
```

## المثال 2

المدخل

```
Countries: ["China", "India"]
Limit: 5
```

المخرج

```
["Mukesh Ambani", "Gautam Adani & family", "Zhong Shanshan", "Zhang Yiming", "Ma Huateng"]
```

## بيئة الاختبار

* تم تزويدك بـ Client ID و Client Secret للاتصال بـ API المليارديرات في `tests/Config.toml`. يمكنك استخدامهما لتهيئة العميل.
* استخدم `bal test` لتشغيل تنفيذك واختباره.

## تلميحات

* يمكن استخدام [العميل](https://lib.ballerina.io/ims/billionairehub/1.0.0/clients/Client) في حزمة `ims/billionairehub` لاستدعاء API جلب المليارديرات حسب البلد. ويمكنك تحديدًا استخدام الطريقة البعيدة `getBillionaires("<country>")`.
* يمكنك أولًا إيجاد أغنى الأشخاص في كل بلد ثم دمجهم لإيجاد أعلى `x`
* ستكون [تعبيرات الاستعلام](https://ballerina.io/learn/by-example/query-expressions/) ملائمة للتصفية والترتيب
