# إضافة التعليمات

## السجلات

| السجل | الاستخدام | النوع | الوصف |
| -------- | ------------ | ------- | ---------------------------------------------- |
| `$a0`    | إدخال        | عنوان | مصفوفة كلمات تحتوي على سعات الدلاء              |
| `$a1`    | إدخال        | عدد صحيح | الدلو الابتدائي (1 أو 2)                        |
| `$a2`    | إدخال        | عدد صحيح | الحجم المستهدف                                  |
| `$a3`    | إدخال/إخراج | عنوان | مصفوفة كلمات تحتوي على محتويات الدلاء النهائية   |
| `$v0`    | إخراج       | عدد صحيح | عدد الإجراءات المطلوبة، و-1 إذا كان ذلك غير ممكن |
| `$t0-9`  | مؤقت        | أي     | تُستخدم للتخزين المؤقت                           |
