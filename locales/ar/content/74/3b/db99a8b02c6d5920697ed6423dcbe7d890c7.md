# PaySwitch - محوّل الرواتب

## نص المسألة

تدفع شركة **Insure Everyone** رواتب موظفيها بعملات أجنبية، ولكن بسبب متطلبات تشريعية يجب تحويل الراتب إلى العملة المحلية. ويقع موظفو الشركة في أنحاء مختلفة من العالم.

يبحث قسم الموارد البشرية في **Insure Everyone** عن مطوّر موهوب لبناء برنامج يحوّل راتب كل موظف إلى عملته المحلية المقابلة. وتعتمد **Insure Everyone** على أسعار صرف يوفّرها API خارجي.

بالاستناد إلى API أسعار الصرف الخارجي، عليك كتابة دالة تأخذ `source currency` و`salary` (بعملة المصدر) و`local currency` الخاصة بالموظف، وتُرجع الراتب بالعملة المحلية.

## القيود

* 500 <= `salary` <= 10000
* `sourceCurrency` و`targetCurrency` هما [رموز العملات وفق ISO (الأبجدية)](https://en.wikipedia.org/wiki/ISO_4217#Active_codes). وقد تحتوي مدخلات الاختبار على رموز عملات غير صالحة.
* ستُقاس دقة سعر الصرف المُرجَع حتى `5` منازل عشرية.

## مثال

### المثال 1

#### المدخلات:
* الراتب: 1000
* عملة المصدر: USD
* العملة الهدف: GBP

#### المخرجات:

بافتراض أن صرف العملات الخارجي أرجع رد أسعار التحويل التالي (مختصر):

```json
{
    "base": "USD",
    "rates": {
        // omitted
        "GBP": 0.73584,
        // omitted
    }
}
```

يجب أن تُرجع الدالة `735.84000`
