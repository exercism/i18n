# فهم الاستدعاء الذاتي في JavaScript

الاستدعاء الذاتي مفهوم قوي في البرمجة، وفكرته أن تستدعي الدالة نفسها.
قد يكون فهمه صعبًا قليلًا في البداية، لكن بمجرد أن تتقن أساسياته يصبح أداة قيّمة لحل المشكلات المعقدة.
سنستكشف الاستدعاء الذاتي في JavaScript من خلال أمثلة سهلة الفهم.

## ما هو الاستدعاء الذاتي؟

يحدث الاستدعاء الذاتي عندما تستدعي الدالة نفسها، بشكل مباشر أو غير مباشر.
وهو يشبه الحلقة، لكنه يقوم على تقسيم المشكلة إلى مشكلات فرعية أصغر وأسهل في التعامل.

### المثال الأول: العد التنازلي

لنبدأ بمثال بسيط: دالة العد التنازلي.

```javascript
function countdown(num) {
  // Base case
  if (num <= 0) {
    console.log('Blastoff!');
    return;
  }

  // Recursive case
  console.log(num);
  countdown(num - 1);
}

// Call the function
countdown(5);
```

في هذا المثال:

- **الحالة الأساسية**: عندما تصبح قيمة `num` أصغر من أو تساوي 0، تطبع الدالة "Blastoff!" وتتوقف عن استدعاء نفسها.
- **الحالة الاستدعائية**: تطبع الدالة القيمة الحالية لـ `num` وتستدعي نفسها باستخدام `num - 1`.

### المثال الثاني: المضروب

الآن، لنلقِ نظرة على مثال كلاسيكي للاستدعاء الذاتي: حساب مضروب عدد.

```javascript
function factorial(n) {
  // Base case
  if (n === 0 || n === 1) {
    return 1;
  }

  // Recursive case
  return n * factorial(n - 1);
}

// Test the function
console.log(factorial(5)); // Output: 120
```

في هذا المثال:

- **الحالة الأساسية**: عندما تكون قيمة `n` تساوي 0 أو 1، تُرجع الدالة 1.
- **الحالة الاستدعائية**: تضرب الدالة `n` في مضروب `n - 1`.

## مفاهيم أساسية

### الحالة الأساسية

ينبغي أن تحتوي كل دالة استدعاء ذاتي على حالة أساسية واحدة على الأقل، وهي شرط تتوقف عنده الدالة عن استدعاء نفسها.
وبدون حالة أساسية، سيستمر الاستدعاء الذاتي بلا نهاية، ما يؤدي إلى تجاوز سعة المكدس.

### الحالة الاستدعائية

تحدد الحالة الاستدعائية كيفية استدعاء الدالة لنفسها بنسخة أصغر أو أبسط من المشكلة.

## مزايا الاستدعاء الذاتي وعيوبه

**المزايا:**

- حل أنيق لبعض المشكلات.
- يحاكي مفهوم الاستقراء الرياضي.

**العيوب:**

- قد يكون أقل كفاءة من الحلول التكرارية.
- قد يؤدي إلى تجاوز سعة المكدس عند التعمق الشديد في الاستدعاء الذاتي.

## الخلاصة

الاستدعاء الذاتي تقنية قيّمة تبسّط المشكلات المعقدة عبر تقسيمها إلى مشكلات فرعية أصغر وأسهل في التعامل.
وفهم الحالات الأساسية والحالات الاستدعائية أمر جوهري لتنفيذ حلول استدعاء ذاتي فعّالة في JavaScript.
