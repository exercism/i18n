# نبذة

تُعرف بنى البيانات التي يمكنها حمل صفر عنصر أو أكثر باسم _المجموعات_. و**المصفوفة** مجموعة لها حجم/طول ثابت ويجب أن تكون كل عناصرها من النوع نفسه. يمكن إسناد العناصر إلى المصفوفة أو استرجاعها منها باستخدام فهرس. ومصفوفات C# تبدأ فهرستها من الصفر، أي أن فهرس العنصر الأول يساوي صفرًا دائمًا:

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true

// Check the length of the array
twoInts.Length == 2; // => true
```

يمكن أيضًا تعريف المصفوفات باستخدام صيغة مختصرة تتيح لك إنشاء المصفوفة وتحديد قيمها في الوقت نفسه. ولأن المترجم يمكنه الآن معرفة عدد العناصر التي ستضمها المصفوفة، يمكن حذف الطول:

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

يمكن التعامل مع المصفوفات إما باستدعاء [الطرق][array-methods] أو [الخصائص][array-properties] الخاصة بنسخة المصفوفة، وإما باستخدام الطرق الثابتة المعرّفة في [الصنف `Array`][array-class].

## المرور على العناصر

المصفوفة أيضًا _مجموعة_، ما يعني أنه يمكنك المرور على _كل_ قيمها باستخدام [حلقة `foreach`][foreach-statement]:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```

ويمكنك استخدام [حلقة `for`][for-statement] للمرور على مصفوفة:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

for (int i = 0; i < vowels.Length; i++)
{
    // Output the vowel
    System.Console.Write(vowels[i]);
}

// => aeiou
```

لكن، عمومًا، تُفضَّل حلقة `foreach` على حلقة `for` للأسباب التالية:

- حلقة `foreach` مضمونة المرور على _كل_ القيم. أما مع حلقة `for`، فمن السهل أن تفوتك بعض العناصر، مثلًا بسبب خطأ بمقدار واحد.
- حلقة `foreach` أكثر _تصريحية_، إذ يوضّح الكود _ما_ تريد فعله، بدلًا من حلقة `for` التي توضّح _كيف_ تريد فعله.
- حلقة `foreach` لا مجال للخطأ فيها، بينما يسهل الوقوع في خطأ بمقدار واحد مع حلقات `for`.
- حلقة `foreach` تعمل مع جميع أنواع المجموعات، بما فيها تلك التي لا تدعم استخدام فهرس للوصول إلى العناصر.

ولضمان أن حلقة `foreach` ستمر على _كل_ القيم، لا يسمح المترجم بتعديل المجموعة داخل حلقة `foreach`:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

لحلقة `for` بعض المزايا على حلقة `foreach`:

- يمكنك البدء أو التوقف عند الفهرس الذي تريده.
- يمكنك استخدام أي شرط إنهاء (منطقي) تريده.
- يمكنك تخطي عناصر بتخصيص طريقة زيادة متغير الحلقة.
- يمكنك معالجة المجموعات من النهاية إلى البداية بالعدّ تنازليًا.
- يمكنك استخدام حلقات `for` في حالات لا تتضمن مجموعات.

مواضيع ذات صلة:

- من المفيد أن تعرف أن C# تدعم [المصفوفات متعددة الأبعاد][multi-dimensional-arrays] مثل `int[,] arr = new int[10, 5]`، وقد تكون مفيدة جدًا.
- واعلم أيضًا أنه يمكنك إنشاء كائنات من النوع [`System.Array`][system-array-object] باستخدام `Array.CreateInstance`. هذه الكائنات قليلة الفائدة، وتُستخدم أساسًا للتوافق مع كود VB.NET. وهي ليست بديلًا قابلًا للتبادل مع المصفوفات القياسية (`T[]`). ويمكن أن يكون حدها الأدنى غير صفر.
