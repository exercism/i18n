# التعليمات

في هذا التمرين، ستطبّق [قواعد لعبة Go](https://matmoore.github.io/learngo/). القواعد نفسها مكتوبة بالفعل، وكل ما عليك هو تطبيقها لتحديث `Game` والتعامل مع أي أخطاء أو انتهاكات للقواعد.

تُمثَّل اللعبة كما يلي:

```elm
type Player
    = Black
    | White


type alias Game =
    { whiteCapturedStones : Int
    , blackCapturedStones : Int
    , player : Player
    , error : String
    }
```

هناك 4 قواعد في اللعبة:

- يمكن لكل نقطة أن تحمل حجرًا واحدًا فقط (`oneStonePerPointRule`)
- يمكن أسر أحجار الخصم! (`captureRule`)
- لا يمكنك وضع حجر في موضع يؤدي إلى أسره لنفسه (`libertyRule`)
- لا يمكنك استخدام النقطة نفسها مرتين (`koRule`)

## 1. طبّق القواعد

اكتب محتوى دالة `applyRules`، التي تأخذ `Game` ابتدائيًا ومجموعة من القواعد، وتُرجع `Game` الجديد بعد تطبيق القواعد.

تتحقق `oneStonePerPointRule` و`libertyRule` و`koRule` جميعها من انتهاكات القواعد، وقد تُرجع خطأً، ولذلك يكون نوع الإرجاع لديها `Result String Game`. إذا فشلت أي من هذه القواعد، فيجب إرجاع اللعبة الأصلية، مع تحديث حقل `error` بالخطأ ذي الصلة.

لا تتحقق `captureRule` من أي انتهاكات، ولذلك لا يمكن أن تفشل (مع أنها تستطيع إرجاع `Game` معدَّل)، ولذلك يكون نوع الإرجاع لديها `Game`.

إذا نجحت جميع القواعد، فيجب الإبقاء على أي تغييرات تطرأ على `Game` من القواعد، ويجب تغيير اللاعب. وقد وُفّرت دالة `changePlayer` للقيام بذلك.

```elm
applyRules : Game -> Rule -> NonValidatingRule -> Rule -> Rule -> Game
applyRules game oneStonePerPointRule captureRule libertyRule koRule =
--> If all rules pass, return a `Game` with all changes from the rules applied, and changePlayer
--> If any rule fails, return the original Game, but with the error field set
```
