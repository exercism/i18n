# مقدمة

في JavaScript، المصفوفة بنية تشبه القائمة، ليس لها طول ثابت، ويمكنها أن تحمل أي نوع من القيم الأولية أو الكائنات، حتى الأنواع المختلطة.

لإنشاء مصفوفة، أضف العناصر بين الأقواس المربعة `[]`.
وللقراءة من المصفوفة، ضع الفهرس بين الأقواس المربعة `[]` بعد المعرّف.
تبدأ فهارس المصفوفة من الصفر.

على سبيل المثال:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[2];
// => 3
```

للحصول على عدد العناصر الموجودة في المصفوفة، استخدم الخاصية `length`:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.length;
// => 4
```

لتغيير عنصر في المصفوفة، تُسند قيمة عند الفهرس:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[0] = 'one';
numbers;
// => ['one', 'two', 3, 'four']
```

## الطرق

يمكن استخدام بعض [الطرق][array_methods] المتاحة على كل كائن Array للإضافة إلى المصفوفة أو الإزالة منها.

### push

> تضيف الطريقة `push()` عنصرًا واحدًا أو أكثر إلى نهاية المصفوفة، وتُرجع الطول الجديد للمصفوفة.[^1]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.push(5); // => 5
numbers;
// => [1, 'two', 3, 'four', 5]
```

### pop

> تحذف الطريقة `pop()` العنصر الأخير من المصفوفة وتُرجع ذلك العنصر.
> وتغيّر هذه الطريقة طول المصفوفة.[^2]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.pop(); // => four
numbers;
// => [1, 'two', 3]
```

### shift

> تحذف الطريقة `shift()` العنصر الأول من المصفوفة وتُرجع العنصر المحذوف.
> وتغيّر هذه الطريقة طول المصفوفة.[^3]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.shift(); // => 1
numbers;
// => ['two', 3, 'four']
```

### unshift

> تضيف الطريقة `unshift()` عنصرًا واحدًا أو أكثر إلى بداية المصفوفة وتُرجع الطول الجديد للمصفوفة.[^4]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.unshift('one'); // => 5
numbers;
// => ['one', 1, 'two', 3, 'four']
```

### splice

> تغيّر الطريقة `splice()` محتويات المصفوفة عبر حذف العناصر الموجودة أو استبدالها و/أو إضافة عناصر جديدة في مكانها. وتُرجع هذه الطريقة مصفوفة تحتوي على العناصر المحذوفة.[^5]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.splice(2, 1, 'one'); // => [3]
numbers;
// => [1, 'two', 'one', 'four']
```
