# مقدمة

## الوحدات

حتى الآن، استخدمت جميع التمارين التي رأيتها أصنافًا. أحيانًا لا نحتاج إلى العبء الإضافي لإنشاء كائن يحمل حالة، لذا نستخدم بدلًا من ذلك `module`.

الوحدة شبيهة جدًا بالصنف، بل إن `Module` هو الصنف الأب لـ `Class` في التسلسل الهرمي للكائنات، والفرق الأساسي أنها تستخدم طرق الأصناف بدلًا من طرق الكائنات. تبدأ طرق الأصناف بـ `self.` وتُستدعى مباشرةً على الوحدة.

على سبيل المثال:

```ruby
module Speaker
  def self.echo(something)
    "#{something} ... #{something}"
  end
end

Speaker.echo("Hello")   #=> "Hello ... Hello"
```

## الحلقات

توجد عدة أساليب لكتابة الحلقات في Ruby، لكن بما أننا نميل عمومًا إلى استخدام التعداد بدلًا من الحلقات، فربما تكون الحلقة الأكثر شيوعًا هي حلقة `while`:

```ruby
counter = 0

while counter < 5
  counter += 1
end
```

يمكنك أيضًا استخدام نظيرتها `until`

```ruby
counter = 0

until counter == 5
  counter += 1
end
```
