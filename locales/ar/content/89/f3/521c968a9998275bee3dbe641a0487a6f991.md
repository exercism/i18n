# عن الجمل الشرطية

## عوامل المقارنة

تتشابه [عوامل المقارنة][operators] مع لغات أخرى كثيرة، مع بعض الإضافات.

أما بالنسبة للمساواة، فالعاملان هما `==` (يساوي) و `!=` (لا يساوي).

```Kotlin
val txt = "abc"
txt == "abc" // => true
txt != "abc" // => false
```

بالإضافة إلى ذلك، يختبر العاملان `===` و `!==` ما يُعرف بـ[«المساواة المرجعية»][referential-equality]: يكون التعبير `a === b` صحيحًا إذا وفقط إذا كان `a` و `b` يشيران إلى الكائن نفسه. وسيبدو هذا أوضح لاحقًا في المنهج.

كما أن عاملي الأكبر والأصغر مألوفان أيضًا.

```Kotlin
1 < 3 // => true
3 > 3 // => false
3 <= 3 // => true
4 >= 3 // => true
```

## التفرع باستخدام `if`

هذه هي الصيغة الكاملة [لتعبير `if`][if-else]:

```Kotlin
if (conditional1) {
//    something...
} else if (conditional2) {
//    something...
} else {
//    something...
}
```

- الأقواس الهلالية `()` حول كل شرط إلزامية.
- يجب أن يُقيَّم الشرط إلى قيمة منطقية `true` أو `false`.
  ولا يوجد في Kotlin مفهوم القيم «الصادقة» و«الكاذبة» الموجود في بعض اللغات.
- الأقواس المعقوفة `{}` اختيارية إذا كان هناك تعبير واحد فقط.
- كل من `else if` و `else` اختياري، ويمكن أن تكون هناك عدة كتل `else if`.

ويمكن أيضًا استخدام تعبير `if` «لاختيار» قيمة:

```Kotlin
val number = 100000
val description = if (number > 100) "number is over 100" else "number is less than 100"
// => description = "number is over 100"
```

## هل هناك بدائل؟

باختيار متعمد، لا تملك Kotlin العامل الثلاثي `? :` الموجود في Java، فالصيغة الموجزة من `if ... else` هي المفضلة:

```Kotlin
val result = if (isOk) goodValue else badValue

return if (isOK) goodValue else badValue
```

وعلى عكس Ruby، تحتاج الصيغة الموجزة `if ... else` *دائمًا* إلى `else`، ولذلك لا يمكن استخدامها كعبارة حارسة:

```kotlin
return 42 if (isOk)
// Syntax error: Unexpected tokens (use ';' to separate expressions on the same line).
// Syntax error: Expecting an expression.

return if (isOk) true
// 'if' must have both main and 'else' branches when used as an expression.
```

لاحظ أن `if` في Kotlin هو [تعبير][expression] يُرجع قيمة، وليس [عبارة][statement] كما في Java.

وسنرى في مفهوم لاحق أن Kotlin تمتلك بنية [`when`][when] قوية، تهدف إلى استبدال التتابعات الطويلة من شروط `else if` بمطابقة الأنماط.
