# السلاسل النصية

السلسلة النصية مجموعة من المحارف تحيط بها علامات الاقتباس. وتُدعم علامات الاقتباس المفردة والمزدوجة معًا.

```php
<?php

$where = "Spain";
$what = 'rain';
```

## توسّع المتغيرات داخل السلاسل النصية

في السلاسل النصية المزدوجة، إذا أُشير إلى متغير وهو داخل النطاق، أُدرجت قيمته في السلسلة النصية.

```php
<?php

$answer = 42;
$expanded = "The answer to life, the universe, and everything is $answer"; 
```

## دعم ترميز المحارف

تاريخيًا، كانت دوال السلاسل النصية في PHP تدعم محارف ASCII فقط، ولم تكن تدعم ترميزات Unicode الحديثة.
كل محرف ASCII يشغل بايت واحدًا، أما محارف Unicode فقد يتراوح طولها بين 1 و4 بايت.
إذا احتجت إلى التعامل مع سلاسل Unicode النصية بأمان، فراجع [النسخ متعددة البايتات][multi-byte-fns] من الدوال القديمة.

```php
<?php

$byte_length = strlen('😃'); // => 4
$string_length = mb_strlen('😃'); // => 1
```

[multi-byte-fns]: https://www.php.net/manual/en/ref.mbstring.php
