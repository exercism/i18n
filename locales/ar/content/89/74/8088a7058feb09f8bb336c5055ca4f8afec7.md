# نبذة

## المصطلحات

لقد استخدمت دوال C++ وكتبتها من قبل في بضعة مفاهيم.
حان الوقت الآن للدخول في التفاصيل التقنية.
يعرض مقتطف الكود التالي أكثر المصطلحات شيوعًا، ليكون مرجعًا سهلًا.
ولأن C++ تتجاهل المسافات البيضاء، فقد غُيِّر التنسيق بحيث يقع كل عنصر في سطر واحد.

```cpp
// Function declaration:
bool                                              // Return type
admin_detected(string user, string password)      // Type signature
;                                                 // Don't forget the ';' for the declaration

// Function definition:
bool                                              // Return type
admin_detected                                    // Function name
(string user, string password)                    // Parameter list
{ return user == "admin" && password == "1234"; } // Function body
```
~~~~exercism/advanced
يعمل التصريح كملاحظة موجّهة إلى المترجم، مفادها أن هناك دالة بهذا الاسم وهذا النوع من الإرجاع وهذه القائمة من المعاملات.
لن يعمل الكود إذا كان التعريف مفقودًا.
التصريحات اختيارية، لكنها ضرورية إذا استخدمت الدالة قبل تعريفها.
ويمكن للتصريحات أن تحل مشكلات مثل المراجع الدائرية، كما يمكن استخدامها للفصل بين الواجهة والتنفيذ.
~~~~

## المحدِّد `const`

أحيانًا تريد أن تتأكد من أن القيم لا يمكن تغييرها بعد تهيئتها.
تستخدم C++ الكلمة المفتاحية `const` كمحدِّد للثوابت.

```cpp
const int number_of_dragon_balls{7};
number_of_dragon_balls--; // compilation error
```

~~~~exercism/note
سترى غالبًا الثوابت مكتوبة بصيغة _UPPER_SNAKE_CASE_.
ويُنصح بقصر هذه الصيغة على الماكرو، إن لم توجد اصطلاحية أخرى.
~~~~

إذا حاولت تغيير متغير ثابت بعد ضبطه، فلن يُترجم الكود الخاص بك.
ويساعدك ذلك على تجنب التغييرات غير المقصودة، كما يفتح للمترجم إمكانات من التحسين.
وبصفتك إنسانًا، يصبح من الأسهل عليك أيضًا أن تفكر في الكود إذا عرفت أن أجزاءً معينة لن تتأثر.

يمكنك أيضًا استخدام `const` كمحدِّد لمعاملات الدالة.

```cpp
string guess_number(const int& secret, const int& guess) {
    if (secret < guess) return "lower.";
    if (secret > guess) return "higher.";
    return "exact!";
}
```

عندما تمرر مرجعًا `const` إلى الدالة، يمكنك أن تتيقن أنه سيُترك دون تغيير.
وسترى غالبًا مراجع `const` لكائنات قد يكون نسخها مكلفًا، مثل السلاسل النصية الطويلة.
وهناك استخدام ثالث لمحدِّد `const`، وهو دوال الأعضاء التي لا تغيّر نسخة الصنف.

```cpp
class Stubborn {
    public:
    Stubborn(string reply) {
        response = reply;
    }
    string answer(const string& question) const {
        if (question.length() == 0) { return "";}
        return response;
    }
    private:
    string response{};
};
```

تستخدم دالة العضو `answer` في الصنف `Stubborn` مرجعًا من النوع `const string&` كمعامل.
وهذا يتجنب عملية نسخ من الكائن الأصلي الذي مُرِّر إلى الدالة.

## التحميل الزائد للدوال

يمكن لعدة دوال أن تحمل الاسم نفسه إذا اختلفت قائمة المعاملات.
ويُسمى ذلك التحميل الزائد للدوال، ويُجرى عادةً عندما تؤدي هذه الدوال مهام متشابهة جدًا.

رأس الدالة دون نوع الإرجاع هو __توقيع النوع__ الخاص بالدالة.
وأي تغيير في توقيع النوع ينتج عنه دالة جديدة.

يحتوي مثال `play_sound` على ست صيغ مختلفة من التحميل الزائد لتغطية سيناريوهات مختلفة:

```cpp
// different argument types:
void play_sound(char note);         // C, D, E, ..., B
void play_sound(string solfege);    // do, re, mi, ..., ti
void play_sound(int jianpu);        // 1, 2, 3, ..., 7

// different number of arguments:
void play_sound(string solfege, double duration);

// different qualifiers:
void play_sound(vector<string>& solfege);
void play_sound(const vector<string>& solfege);
```

~~~~exercism/advanced
يُعرَّف توقيع النوع باسم الدالة وعدد المعاملات وأنواعها ومحدِّداتها (وليس أسماءها).
أما نوع الإرجاع فليس جزءًا من توقيع النوع عن قصد، وستحصل على أخطاء في الترجمة إذا كان لديك دالتان تختلفان في نوع الإرجاع فقط.
وسيشتكي المترجم لأنه لن يكون واضحًا أي الدالتين ينبغي استخدامها.
~~~~

## المعاملات الافتراضية

قد تصبح بعض الدوال طويلة جدًا، وقد تستخدم كثير من استدعاءاتها القيم نفسها لمعظم المعاملات.
ويمكن تجنب التكرار في تلك الاستدعاءات باستخدام المعاملات الافتراضية.

```cpp
void record_new_horse_birth(string name, int weight, string color="brown-ish", string dam="Alruccaba", string sire="Poseidon");

record_new_horse_birth("Urban Sea", 130); // color will be brown, dam "Alruccabam", sire "Poseidon"
record_new_horse_birth("Highclere", 175, "off-white", "Fall Aspen");   // sire will be "Poseidon"
```

ولأن تصريح الدالة يُقرأ غالبًا قبل تعريفها، فهو المكان الأفضل لضبط المعاملات الافتراضية.
وإذا كان لأحد المعاملات قيمة افتراضية في التصريح، وجب أن يكون لجميع المعاملات الواقعة على يمينه قيمة افتراضية كذلك.
وأحيانًا يمكن إعادة هيكلة حالات التحميل الزائد المعقدة لتُصبح دوالًا أقل مع معاملات افتراضية، بما يحسّن قابلية الصيانة.
