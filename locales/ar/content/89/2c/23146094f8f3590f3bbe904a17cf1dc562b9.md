# ملحق التعليمات

## الأمر `apply` في Tcl

قد تبدو حالات الاختبار مربكة.
المطلوب منك تنفيذ ما يلي: 

```tcl
set myList {alpha beta gamma delta}
listOps::filter $myList {{word} {expr {[string length $word] == 4}}
```

لماذا تحتوي تلك الوسيطة الأخيرة على كل هذه الأقواس المعقوفة؟

تذكّر أن الأمر `proc` يُعرَّف كالتالي:

```tcl
proc procName argList body
```

يحتوي Tcl على أمر `apply`:

```tcl
apply func ?arg1 arg2 ...?
```

هذه "func" قائمة من عنصرين `{argList body}`، وهي في جوهرها إجراء مجهول (أو "لامبدا").
يستدعي الأمر `apply` ذلك الإجراء المجهول ويمرّر إليه الوسائط التي يحتاجها.

على سبيل المثال، هذه الأمثلة متكافئة:

```tcl
# using proc
proc myReverse {str} {return [string reverse $str]}
puts [myReverse "Hello, World!"]

# using apply
puts [apply {{str} {string reverse $str}} "Hello, World!"]

# or, store the func in a variable
set func {{str} {string reverse $str}}
puts [apply $func "Hello, World!"]
```

استخدام `apply` يجعل تمرير كتل الكود أسهل.

المراجع: [`apply`](https://tcl.tk/man/tcl8.6/TclCmd/apply.htm)، [`proc`](https://tcl.tk/man/tcl8.6/TclCmd/proc.htm).
