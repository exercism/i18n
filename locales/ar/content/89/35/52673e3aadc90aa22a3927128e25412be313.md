# الإعداد

يستخدم هذا المسار أداتين لتشغيل مجموعة الاختبارات وضمان اتباع أفضل الممارسات:

1. [vader.vim](https://github.com/junegunn/vader.vim)
2. [vint](https://github.com/Kuniwak/vint)

## تشغيل الاختبارات

1. ثبّت [vader.vim](https://github.com/junegunn/vader.vim/#installation).
1. افتح حلّك:
    ```
    $ vim exercise.vim
    ```
1. نفّذ الملف الحالي لجعل دواله العامة متاحة لـ Vim:
    ```
    :source %
    ```
1. شغّل الاختبارات:
    ```
    :Vader exercise.vader
    ```

قد تختلف المسارات.

إذا أردت اختصارًا مريحًا للخطوات السابقة، ضع هذا في ملف vimrc الخاص بك:

```vim
function! s:exercism_tests()
  if expand('%:e') == 'vim'
    let testfile = printf('%s/%s.vader', expand('%:p:h'),
          \ tr(expand('%:p:h:t'), '-', '_'))
    if !filereadable(testfile)
      echoerr 'File does not exist: '. testfile
      return
    endif
    source %
    execute 'Vader' testfile
  else
    let sourcefile = printf('%s/%s.vim', expand('%:p:h'),
          \ tr(expand('%:p:h:t'), '-', '_'))
    if !filereadable(sourcefile)
      echoerr 'File does not exist: '. sourcefile
      return
    endif
    execute 'source' sourcefile
    Vader
  endif
endfunction

autocmd BufRead *.{vader,vim}
      \ command! -buffer Test call s:exercism_tests()
```

بعد ذلك، افتح أي ملف ‎`.vim`‎ أو ‎`.vader`‎ من مجلد تمرين وشغّل الأمر ‎`:Test`‎.

## فحص ملفات Vim

1. ثبّت [vint](https://github.com/Kuniwak/vint#quick-start).
1. افحص جميع ملفات Vim بشكل تعاودي:
    ```
    $ vint .
    ```

لمزيد من المعلومات التفصيلية حول مسار Vim script، راجع
[صفحة المساعدة](https://exercism.org/languages/vimscript).
