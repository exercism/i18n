# مقدمة

كما استكشفنا في مفهوم `Nothingness`، توفر لغة R طرقًا متعددة لتمثيل البيانات الغائبة (`NULL`) أو المجهولة (`NA`) أو غير الصالحة رياضيًا (`NaN`، `Inf`).
وعمومًا، ستحاول R استخدام هذه القيم للإشارة إلى المشكلات في موضعها، ثم المتابعة دون رفع استثناء.

## `stop()`

بعض المشكلات جوهرية أكثر من أن تسمح للبرنامج بالمتابعة.
في هذه الحالة، استخدم `stop(msg)` لإيقاف البرنامج فورًا وإظهار `Error` وطباعة `msg`.

```R
f <- function() {
    stop("I have a problem")
}
f()
#> Error in f() : I have a problem
```

## `stopifnot()`

على غرار `assert` في لغات أخرى، هذه دالة تغليف مريحة لـ `stop()`.
المعاملات هي عدد اعتباطي من الشروط المنطقية المفصولة بفواصل، ولن يتابع البرنامج إلا إذا كانت كلها `TRUE`.

```R
stopifnot(1 < 2) # continues OK
stopifnot(1 < 2, 1 == 2)
#> Error: 1 == 2 is not TRUE
```

## `warning()` و`message()`

هذه استجابات لحالات غير قاتلة، على سبيل المثال:

- للتحذير من مشكلة يستطيع البرنامج التعافي منها جزئيًا على الأقل.
- لإخبار المستخدم بتقدم سير برنامج طويل التشغيل.

```R
w <- function() {
  warning("something strange happened")
  -1
}

w()
#> [1] -1
#> Warning message:
#> In w() : something strange happened

# if warnings are not wanted
suppressWarnings(w())
#> [1] -1
```

قد تكون دالة `suppressWarnings()` مفيدة أحيانًا داخل Exercism، لتجنّب إرباك مشغّل الاختبارات بمخرجات غير مرغوبة.
