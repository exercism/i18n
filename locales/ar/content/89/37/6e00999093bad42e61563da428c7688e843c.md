# نبذة

[الإغلاقات][closures] في Swift هي كتل من الكود مكتفية بذاتها، ويمكن تمرير معاملات إليها لتحفيز حساباتها وإرجاع قيم. كما تلتقط الإغلاقات قيمًا من بيئتها وتستخدمها في حساباتها. ولأنها مكتفية بذاتها، يمكن تمريرها في البرنامج مثل القيم الأخرى أو إسنادها إلى ثوابت ومتغيرات.

قد تبدو الإغلاقات شبيهة كثيرًا بدوال Swift؛ وهي كذلك، ولسبب وجيه. الدوال في Swift هي حالات خاصة من الإغلاقات، وهي مطلوبة أن يكون لها اسم وتُعرَّف باستخدام صياغة مختلفة قليلًا.

بينما الدوال في Swift هي إغلاقات من الناحية التقنية، عندما يشير الناس إلى "الإغلاقات" في Swift، فإنهم يشيرون إلى [تعبيرات الإغلاق][closure-expressions]. تُكتب تعبيرات الإغلاق على هيئة قائمة معاملات يتبعها نوع الإرجاع والكلمة المفتاحية `in` يتبعها جسم الإغلاق، وكل ذلك داخل زوج من الأقواس المعقوفة:

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}
```

هذا يُعرّف تعبير إغلاق من النوع `(Double, Double) -> Double`، ويمكن تنفيذه بطريقة مشابهة لدالة من هذا النوع، بتطبيقه على معاملات من النوع المناسب:

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}(10.0, 15.0)
// returns 12.5
```

بما أنه ليس من المريح كتابة تعبير الإغلاق الكامل في كل مرة يريد المرء تنفيذه، يمكن إسناد الإغلاقات إلى أسماء، مثل أي قيمة أخرى في Swift. ثم يمكن استدعاؤها بتطبيق الاسم على المعاملات:

```swift
let mean = { (a: Double, b: Double) -> Double in
  (a + b) / 2.0
}

mean(13.0, 100.0)
// returns 56.5
```

كما رأينا أعلاه، يمكن للإغلاقات، مثل الدوال العادية، أن تحذف الكلمة المفتاحية `return` إذا كان جسم الإغلاق تعبيرًا واحدًا.

في أغلب الأحيان، تُستخدم الإغلاقات مع الدوال ذات الرتبة الأعلى، إما بتمريرها كمعاملات أو إرجاعها كنتائج:

```swift
[11, 75, 3, 99, 53].contains(where: { (x: Int) -> Bool in x > 100 })
// returns false

["apple", "ball", "carrot"].sorted(by: { (s1: String, s2: String) -> Bool in s1.count < s2.count })
// returns ["ball", "apple", "carrot"]

func makeAdder(base: Int) -> (Int) -> Int {
  { (x: Int) -> Int in base + x }
}
```
