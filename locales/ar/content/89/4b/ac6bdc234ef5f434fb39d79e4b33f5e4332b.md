# نبذة

تحتفظ *المجموعة المنفصلة* (بنية الاتحاد والبحث) بمجموعة من القيم مقسّمة إلى مجموعات غير متداخلة، وتجيب بسرعة عن سؤال واحد: هل تقع هاتان القيمتان في المجموعة نفسها؟ وهي موجودة ضمن مفردات [`disjoint-sets`][disjoint-sets].

لبناء بنية فارغة، نستخدم `<disjoint-set>`. أما القيم، وهي *الذرّات*، فتُضاف عبر `add-atom`، أو دفعة واحدة عبر `add-atoms`، وتبدأ كل ذرّة في مجموعة مستقلة بذاتها:

```
<disjoint-set> ( -- disjoint-set )
add-atom       ( atom disjoint-set -- )
add-atoms      ( seq disjoint-set -- )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ "a" "b" "c" "d" } over add-atoms   ! four singleton groups
```

توحّد `equate` بين المجموعتين اللتين تحتويان على الذرّتين. وعملية التوحيد متعدية: فبمجرد أن تُوحَّد `a` مع `b` و`b` مع `c`، تصبح الذرّات الثلاث في مجموعة واحدة.

```
equate ( atom1 atom2 disjoint-set -- )
```

وتُعرَّف كل مجموعة بعضو واحد معياري، هو *الممثِّل*. ويمكن الحصول على هذا العضو عبر `representative`، وتنتمي ذرّتان إلى المجموعة نفسها بالضبط عندما يكون ممثلاهما متساويين. ويمكنك إجراء هذا الاختبار مباشرة عبر `equiv?`:

```
representative ( atom disjoint-set -- representative )
equiv?         ( atom1 atom2 disjoint-set -- ? )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ "a" "b" "c" "d" } over add-atoms
"a" "b" pick equate
"b" "c" pick equate
"a" "c" pick equiv? .          ! => t   (transitively connected)
"a" "d" pick equiv? .          ! => f
"a" over representative
"c" pick representative = .     ! => t   (same representative)
```

اختيار الذرّة التي تصبح ممثّلًا للمجموعة تفصيل داخلي: فقد تكون أي عضو من أعضاء المجموعة، ويمكن أن يتغيّر مع اندماج المجموعات. لا تعتمد أبدًا على أن ذرّة معيّنة هي الممثّل، بل فقط على أن ذرّتين في المجموعة نفسها متفقتان.

وللحصول على كل ذرّة أُضيفت، استخدم `disjoint-set-members`.

البنية *قابلة للتغيير*: فـ`equate` و`add-atom` تغيّران المجموعة المنفصلة في مكانها بدلًا من إرجاع مجموعة جديدة. ويستخدم التنفيذ الاتحاد حسب الرتبة مع ضغط المسار، لذا فإن تسلسلًا طويلًا من استدعاءات `equate` و`representative` يستغرق وقتًا ثابتًا فعليًا لكل استدعاء.
