# نبذة

في C#، الصف بنية بيانات تنظّم البيانات، وتحمل حقلين أو أكثر من أي نوع.

يُنشأ الصف عادةً بوضع تعبيرين أو أكثر مفصولة بفواصل، داخل زوج من الأقواس الهلالية.

```csharp
string boast = "All you need to know";
bool success = !string.IsNullOrWhiteSpace(boast);
(bool, int, string) tripple = (success, 42, boast);
```

وبوصفه تعبيرًا مثل أي تعبير آخر، يمكن استخدام الصف بطرق متنوعة: في [الإسناد][tuple-assignment]، لتهيئة حقل أو متغير، أو [كقيمة مُرجعة][tuple-return-values] من دالة، أو لتمريره كمعامل. ويمكن اختبار [التساوي][tuple-equality] بين الصفوف. ويوضّح تمرين `pattern-matching-tuples` تساوي الصفوف بشكل كامل، لكن المثال الوارد في الكود أدناه مُقدَّم من باب استكمال الصورة.

نستخرج الحقول باستخدام صيغة النقطة. افتراضيًا يكون الحقل الأول `Item1`، والثاني `Item2`، وهكذا. وتُناقش الأسماء غير الافتراضية أدناه في _التسمية_.

ويمكن استخدام الصف كمعامل عام، مثل `IList<(bool, string)>`.

بالإضافة إلى ذلك، تدعم الصفوف «التفكيك» الذي نتناوله أدناه، ويمكن استخدامها في مطابقة الأنماط التي يُخصَّص لها تمرين لاحق.

```csharp
// initialization
(int, int, int) vertices = (90, 45, 45);

// assignment
vertices = (60, 60, 60);

//  return value
(bool, int) GetSameOrBigger(int num1, int num2)
{
    return (num1 == num2, num1 > num2 ? num1 : num2);
}

// method argument
int Add((int, int) operands)
{
    return operands.Item1 + operands.Item2;
}

// equality testing
var estimateA = (42, 1729);
var estimateB = (2*3*7, 7*13*19);
bool result = estimateA == estimateB;
// => result == true
```

يوضّح هذا [المدخل][tuples] كيفية تعريف الصفوف واستخدامها.

## التسمية

أسماء الحقول مثل `Item1` لا تجعل الكود سهل القراءة. وهناك 3 طرق لتسمية الحقول: أ) في تعريف النوع، أو ب) في التعبير الذي ينشئه، أو ج) بواسطة [مهيّئات إسقاط الصف][tuple-projection-initializers] (غير موضّحة هنا).

```csharp
// name items in declaration
(bool success, string message) results = (true, "well done!");
bool mySuccess = results.success;
string myMessaage = results.message;

// name items in creating expression
var results2 = (success: true, message: "well done!");
bool mySuccess2 = results2.success;
string myMessaage2 = results2.message;
```

لا تحاول المبالغة في التذرّك بآلية التسمية. فهي في الحقيقة مجرّد سكر نحوي. على سبيل المثال، لا يمكنك تغيير أسماء الصف عند إسناد صف آخر إليه.

## التفكيك

أحيانًا يكون من المناسب أخذ صف وإسناد حقوله إلى عدة متغيرات وتهيئتها عند الحاجة. تُسمّى هذه الآلية [التفكيك][tuple-deconstruction]. (ويمكن تطبيقها أيضًا على كائناتك الخاصة. انظر [هنا][udt-deconstruction]).

```csharp
var goodNumbers = (42, 3.142, 1729);
(int ultimateQuestion, var π, var ramanujan) = goodNumbers;
return ultimateQuestion;
// => 42
```

## إسناد الحقول

يمكن إسناد قيمة إلى كل حقل من حقول الصف على حدة. غير أنّ هذا الاستخدام ليس شائعًا، نظرًا لاتجاه C# نحو عدم القابلية للتغيير. فكثيرًا ما تُستخدم الصفوف كما لو كانت غير قابلة للتغيير، وهي بالطبع ليست كذلك.

```csharp
(int, string) tpl;
tpl.Item1 = 1;
tpl.Item2 = "bad";
tpl.Item2 = "even worse";
// => (1, "even worse";
```

## خلفية

لا ينبغي الخلط بين الصفوف التي نتحدث عنها و[`System.Tuple`][system-tuple]، الذي لن تجده على الأرجح إلا في قواعد الكود القديمة.

ويزداد الأمر غموضًا قليلًا عند الحديث عن `System.ValueTuple`. فتقول [الوثائق][system-value-tuple] الخاصة بأحدث نسخة محمّلة من [`System.ValueTuple`][system-value-tuple] إن «أنواع صفوف القيم توفّر التنفيذ الذي يدعم الصفوف في C#». ويقصدون بـ«أنواع صفوف القيم» هنا التحميلات الزائدة العامة لـ `System.ValueTuple`. ويقصدون بـ«الصفوف» الأشياء التي شغلتنا في هذا التمرين. وهم يقولون بذلك إن `System.ValueTuple` تفصيل تنفيذي داخلي من تفاصيل الصفوف. ومن غير المرجّح أن يهمّ ذلك معظم الناس في معظم الأوقات. وللأسف، كثير من الوثائق التي تتحدث عن «الصفوف»، بما فيها وثائق Microsoft نفسها، مكتظّة بإشارات إلى `System.ValueTuple`. ومن الآمن على الأرجح أن تتجاوز هذه الإشارات.

## استخدامات أخرى وقيود

مطابقة الأنماط استخدام مثمر بشكل خاص للصفوف. وهي موضوع يتناوله تمرين لاحق.

وتتيح الصفوف بعض اللمسات الأسلوبية الثانوية الأخرى:

- الإسناد المتعدد (لا سيما في الدوال البانية). مثال: `(this.field1, this.field2) = (arg1, arg2);`
- تبديل القيم أو إعادة تدويرها، مثال: `(a, b) = (b, a);`
- الاستخدام بدلًا من `struct` في مصفوفة
- الاستخدام كمفتاح في قاموس أو كمحتوى مجموعة.
- الاستخدام في LINQ. (يتناول LINQ تمارين لاحقة).

تصف الوثائق الصفوف بأنها آلية خفيفة، وهذا هو مفتاح استخدامها الناجح. فقد يؤدي استخدام صف بدلًا من صنف أو `struct` إلى تكرار ممل لأنواع حقوله وربما أسمائه. وينطبق هذا بشكل خاص عند استخدامه كوسيط لطريقة أو كوسيط عام في المجموعات.

ومن الأفضل استخدام حيل مثل الإسناد المتعدد والتبديل بحكمة.

ولا تُدعم العمليات العلائقية سوى التساوي وعدم التساوي.

لاحظ أن الصفوف أُضيفت إلى اللغة حديثًا نسبيًا (C# 7)، لذا إن أردت استخدامها فتأكد من أن قاعدة الكود لديك تستخدم [الإصدار][language-version] 7 أو أحدث من اللغة.
