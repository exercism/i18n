# تلميحات

## عام

- لا تُستخدم العدسات كثيرًا في Roc لأن صياغة تحديث السجل تغطي معظم حالات الاستخدام بشكل جيد.
  على سبيل المثال، تأمّل هذا السجل المتداخل:

  ```roc
  bob = { hair: { color: Brown, length: Long }, mouth: Smiling, height: 6.0 }
  ```

  لنقصّ شعر بوب الآن:

  ```roc
  new_bob = { ..bob, hair: { ..bob.hair, length: Short } }
  ```

  لا حاجة إلى عدسات!

- ومع ذلك، فرغم أن العدسات نادرة في Roc، فهي شائعة في لغات أخرى مثل Haskell وScala، لذا قد تتساءل كيف يمكن تنفيذها في Roc.
  وهو أيضًا أسلوب جيد للتدرّب على بعض ميزات Roc المتقدمة مثل الأنواع ذات المعاملات، والسجلات التي تحتوي على دوال.
  في الواقع، إليك أسلوب واحد لتمثيل عدسة في Roc:

  ```roc
  Lens(whole, part) := {
      get : whole -> part,
      set : whole, part -> whole,
  }
  ```

  هذا نوع ذو معاملات: يمكن أن يكون كل من `whole` و`part` من أي نوع.
  عادةً ما يكون `whole` سجلًا، بينما يمكن أن يكون `part` من أي نوع حقل.
  يحتوي الحقل `get` على دالة تُرجع `part` محددًا من `whole` المعطى، بينما يحتوي الحقل `set` على دالة تُرجع نسخة من `whole` المعطى، مع استبدال `part` محدد بـ`part` المعطى.

  على سبيل المثال، إليك عدسة لجلب شعر شخص أو ضبطه:

  ```roc
  hair_lens = {
      get: |person| person.hair,
      set: |person, hair| { ..person, hair },
  }
  ```

  يمكننا استخدام هذه العدسة للتركيز على شعر بوب، هكذا:

  ```roc
  bob_hair = bob |> hair_lens.get
  ```

  ويمكننا تغيير شعره هكذا:

  ```roc
  new_hair = { ..bob.hair, length: Short }
  new_bob = bob |> (hair_lens.set)(new_hair)
  ```

- ملاحظة: الأقواس الهلالية حول `hair_lens.set` ضرورية: فبدونها، سيبحث Roc عن دالة باسم `set` في نوع `hair_lens`.

- تصبح العدسات مفيدة بشكل خاص عندما تبدأ في تركيبها معًا، مما يتيح لك جلب الأجزاء المتداخلة بعمق وضبطها.
  يمكن فعل ذلك بتنفيذ دالة كهذه:

  ```roc
  compose : Lens(outer, inner), Lens(inner, part) -> Lens(outer, part)
  ```

  بمجرد تنفيذ هذه الدالة، يمكنك استخدامها لإنشاء عدسة لطول الشعر هكذا:

  ```roc
  length_lens = {
      get: |hair| hair.length,
      set: |hair, length| { ..hair, length },
  }
  hair_length_lens = compose(hair_lens, length_lens)

  ```

  الآن يمكنك قصّ شعر بوب مرة أخرى:

  ```roc
  set_hair_length = hair_length_lens.set
  new_bob = bob |> set_hair_length(Short)
  ```

- قد ترغب أيضًا في تنفيذ دالة تتيح لك تطبيق أي تحويل على جزء متداخل:

  ```roc
  over : Lens(whole, part), whole, (part -> part) -> whole
  ```

  بمجرد تنفيذها، يمكنك استخدام `over` هكذا:

  ```roc
  cut_hair = |current_length| match current_length {
      Long => Short
      Short => Bald
      Bald => Bald
  }
  new_bob = hair_length_lens |> over(bob, cut_hair)
  ```

- نوصي بأن تجتاز الاختبارات أولًا باستخدام صياغة تحديث السجل في Roc، ثم تجرّب استخدام العدسات بدلًا منها.
