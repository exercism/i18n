# ملحق التعليمات

## صيغة الإخراج

أخرِج تسلسل البروتينات على هيئة سلسلة نصية منتهية بـ `null`، مع محرف سطر جديد بعد كل بروتين.

ومن أمثلة الإخراج `"Methionine\nPhenylalanine\nSerine\n"`

إذا كانت المدخلات غير صالحة، أخرِج سلسلة نصية فارغة.

## السجلات

| السجل | الاستخدام     | النوع   | الوصف                          |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | إدخال        | عنوان   | سلسلة نصية مدخلة منتهية بـ `null`  |
| `$a1`    | إدخال/إخراج   | عنوان   | سلسلة نصية مخرجة منتهية بـ `null` |
| `$t0-9`  | مؤقت         | أي      | تُستخدم للتخزين المؤقت          |
