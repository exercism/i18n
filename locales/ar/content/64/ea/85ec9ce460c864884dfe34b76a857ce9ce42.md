# مقدمة

## الكلمة المفتاحية `auto` في C++

في C++، الكلمة المفتاحية `auto` ميزة قوية أُدخلت في C++11، وتُستخدم لتعريف المتغيرات بنوع بيانات مستنتَج.
يستنتج المترجم نوع المتغير بناءً على القيمة التي يُهيأ بها، وهو ما قد يجعل الكود أكثر قابلية للقراءة وأسهل في الصيانة.

## مثال على الاستخدام

لنلقِ نظرة على المثال التالي حيث تُستخدم `auto` لتعريف المتغيرات:

```cpp
auto dragon_population{3};          // dragon_population is deduced as an integer
auto westeros{7.7777};              // westeros is deduced as a double
auto wedding_location{"The Twins"}; // wedding_location is deduced as a const char*, not std::string
```

في كل حالة، يُستنتج نوع المتغير من القيمة التي يُهيأ بها.

## استنتاج النوع

تساعد الكلمة المفتاحية `auto` في كتابة كود أكثر إيجازًا وقابلية للقراءة عبر تقليل الإسهاب في الأنواع الصريحة.

```cpp
const std::vector<std::string> pigeon_pie{"flour", "butter", "pigeon", "salt"};
auto purple_wedding_pie{pigeon_pie};
purple_wedding_pie.emplace_back("the strangler");
```

في هذا المثال، تستنتج `auto` نوع `purple_wedding_pie` على أنه `std::vector<std::string>`، مما يغني عن الحاجة إلى تحديد النوع صراحةً مرة أخرى.

## التوافق

تتوافق الكلمة المفتاحية `auto` مع تراكيب مختلفة في C++، مما يجعلها أداة متعددة الاستخدامات في برمجة C++ الحديثة.

```cpp
auto& element{array[0]};           // reference to an element
const auto object{otherObject};    // const type version of otherObject's type
auto* ptr{&x};                     // pointer to x with the same type as x, but as a pointer.
```

في مفاهيم لاحقة، سنرى غالبًا الكلمة المفتاحية `auto` مع تعبيرات لامبدا، وحلقات `for` المعتمدة على المدى، والمكررات.
