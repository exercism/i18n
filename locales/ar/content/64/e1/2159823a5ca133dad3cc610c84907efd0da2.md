# مقدمة

‏`Complex numbers` ليست معقدة.
إنها تحتاج فقط إلى اسم أقل إثارة للقلق.

إنها مفيدة جدًا، خصوصًا في الهندسة والعلوم، حتى إن R يضم الأعداد المركبة ضمن الأنواع الذرية القياسية إلى جانب integer وdouble وlogical وcharacter وraw.

## الأساسيات

العدد `complex` في R قيمة واحدة.
لكن عند الاستخدام يمكن اعتباره زوجًا من الأعداد.
يُسمّى هذان الجزآن الجزء «الحقيقي» والجزء «التخيلي»، لأسباب تاريخية مؤسفة.
ومرة أخرى، الأفضل أن نركّز على البساطة الكامنة وراءه لا على أسمائه الغريبة.

لإنشاء عدد مركب من عددين حقيقيين، أضف اللاحقة `i` إلى الجزء التخيلي.

```r
2+3i
#> [1] 2+3i

typeof(2+3i)
#> [1] "complex"
```

أما لإنشاء عدد مركب من متغيرات حقيقية، فلن تنجح الصيغة السابقة.
فكتابة `r + imi` تجعل المحلّل يظن أن `imi` اسم متغير (غير موجود).

إما أن تضرب الجزء التخيلي في `1i` أو أن تستخدم الدالة [`complex()`][ref-complex]:

```r
r <- 2
im <- 3

r + im * 1i
#> [1] 2+3i

# must include the `real` and `imaginary` keywords
complex(real = r, imaginary = im)
#> [1] 2+3i
```

قد تتساءل: لماذا `i` وليس `j`؟

يفضّل معظم المهندسين `j`.
ويفضّل معظم العلماء والرياضيين الرمز الرياضي `i` للدلالة على _التخيلي_، لكن هذا الرمز يتعارض مع استخدام `i` بمعنى _التيار_ في الهندسة الكهربائية.

اختار R الحرف `i`، واختارت Python الحرف `j`، وتجنّبت Julia هذا الخلاف باختيار `im`.
فكن حذرًا عند التنقل بين لغات البرمجة في مجالات [العلوم والتكنولوجيا والهندسة والرياضيات][wiki-STEM].

للوصول إلى جزأي العدد المركب كلٌّ على حدة:

```r
z <- 2+3i

Re(z)  # real part
#> [1] 2

Im(z)  # imaginary part
#> [1] 3
```

يمكن أن يكون أي من الجزأين صفرًا، وقد يتحدث الرياضيون حينها عن عدد «حقيقي بالكامل» أو «تخيلي بالكامل».
ومع ذلك، يبقى عددًا مركبًا في R.

```r
1.2 + 0i
#> [1] 1.2+0i

typeof(1.2 + 0i)
#> [1] "complex"

2i
#> [1] 0+2i

typeof(2i)
#> [1] "complex"
```

ربما سمعت أن «`i` (أو `j`) هو الجذر التربيعي للعدد -1».

في الوقت الحالي، كل ما يعنيه هذا أن الجزء التخيلي _بحكم التعريف_ يحقق المساواة التالية:

```r
1i * 1i == -1  # more precisely, 1i * 1i == -1 + 0i
#> [1] TRUE
```

هذه فكرة بسيطة، لكنها تؤدي إلى نتائج مثيرة للاهتمام.

## العمليات الحسابية

معظم العوامل المستخدمة مع الأعداد العشرية والأعداد الصحيحة تعمل أيضًا مع الأعداد المركبة:

```r
z1 = 1.5 + 2i
z2 = 2 + 1.5i

z1 + z2  # addition
#> [1] 3.5+3.5i

z1 * z2  # multiplication
#> [1] 0+6.25i

z1 / z2  # division
#> [1] 0.96+0.28i

z1^2  # exponentiation
#> [1] -1.75+6i

2^z1  # another exponentiation
#> [1] 0.518895+2.780422i
```

## الدوال

معظم الدوال الرياضية تعمل مع المدخلات المركبة.

وهناك عدة دوال، إضافة إلى `Re()` و`Im()`، ذات صلة خاصة بالأعداد المركبة.

- تعكس `Conj()` ببساطة إشارة الجزء التخيلي للعدد المركب (_من + إلى - أو العكس_).
  - وبسبب طريقة عمل ضرب الأعداد المركبة، فإن هذا أكثر فائدة مما قد تظن.
- من المضمون أن تُرجع `abs(<complex number>)` عددًا حقيقيًا بلا جزء تخيلي (وهو «مقدار» العدد)، و`Mod(<complex number>)` مرادف لها.
- وتُرجع `Arg(<complex number>)` زاوية الطور بالراديان.

```r
z1
#> [1] 1.5+2i

abs(z1)
#> [1] 2.5

Mod(z1)  # same as previous
#> [1] 2.5

Conj(z1)  # flip sign
#> [1] 1.5-2i

Arg(z1)
#> [1] 0.9272952
```
