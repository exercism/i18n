# مقدمة

## الوقت

يتعامل .NET مع مفهوم _الوقت_ باستخدام البنية `DateTime`. وهناك إجراءات للتحويل بين التوقيت المحلي والتوقيت العالمي المنسق (UTC). ويمكن إجراء العمليات الحسابية بمساعدة `TimeSpan`.

## المنطقة الزمنية

يوفر الصنف `TimeZoneInfo` إجراءات للتعامل مع الفروق بين المناطق الزمنية. كما يحتوي الصنف `TimeZoneInfo` على طرق تسهّل التعامل مع التوقيت الصيفي.

ويدعم الصنف `CultureInfo` تنسيقات التاريخ والوقت المعتمدة على الإعدادات المحلية.

وللدعم البرمجة عبر الأنظمة الأساسية، يتيح لك الصنف `RuntimeInformation` معرفة نظام التشغيل الذي يعمل عليه الكود: Linux أو Windows أو OSX.
