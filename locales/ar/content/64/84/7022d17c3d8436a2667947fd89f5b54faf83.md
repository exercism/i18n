# الأصناف المجرّدة

عرض السيرك قائمة من الفقرات. فالتلاعب بالكرات والأرجوحة الهوائية والشقلبات أشياء مختلفة من الداخل، لكن من يضع ترتيب العرض لا يحتاج من كل فقرة إلا شيئين: اسمها، والوقت الذي تستغرقه.

**الصنف المجرّد** يصف هذا القدر ولا أكثر.

```sather
abstract class $ACT is
   name : STR;
   minutes : INT;
end; -- abstract class $ACT
```

يبدأ اسمه بـ `$`. وهو يسرد إجراءات بلا أجسام: توقيعات فقط، كل توقيع ينتهي عند الفاصلة المنقوطة. ولا يمكن إنشاء أي شيء منه، فلا وجود لـ `create` ولا لـ `new`.

## المطابقة

الصنف الحقيقي يتعهّد بأن يكون `$ACT` بكتابة اسمه بعد `<`:

```sather
class JUGGLING < $ACT is

   create : SAME is return new; end;

   name : STR is return "Juggling"; end;

   minutes : INT is return 5; end;

end; -- class JUGGLING
```

يُقرأ الرمز `<` بمعنى "هو نوع من". وعلى الصنف أن يوفّر كل إجراء يسرده الصنف المجرّد، بالوسائط نفسها ونوع الإرجاع نفسه. وإغفال أحدها خطأ في التصريف، لا مفاجأة في زمن التشغيل.

ويجوز للصنف أن يضيف ما يشاء غير ذلك. فبإمكان `TRAPEZE` أن يحمل ارتفاعًا لا تملكه أي فقرة أخرى؛ والصنف المجرّد لا يعرف ذلك ولا يهمّه.

## استخدام النوع

`$ACT` نوع، لذا يمكن الإعلان عن أي شيء به:

```sather
   acts : ARRAY{$ACT} := |#JUGGLING, #TRAPEZE(4), #TUMBLING|;
```

تحمل تلك المصفوفة كائنات من ثلاثة أصناف مختلفة في آن واحد، وهو ما لا تستطيع `ARRAY{JUGGLING}` فعله.

## الإرسال

```sather
   loop
      total := total + acts.elt!.minutes;
   end;
```

‏`acts.elt!` كائن من نوع `$ACT`. وأي `minutes` يعمل يُحدَّد عند تنفيذ السطر، بحسب ما يكونه الكائن فعلًا: `JUGGLING::minutes` للتلاعب بالكرات، و`TRAPEZE::minutes` للأرجوحة. ويُسمّى هذا الاختيار **الإرسال**.

الإجراء الذي يجمع لا يسأل أبدًا عن نوع الفقرة التي لديه. وإضافة نوع رابع من الفقرات تعني كتابة صنف جديد واحد دون تغيير أي شيء آخر، وهذا هو سبب اتباع هذه الطريقة أصلًا.
