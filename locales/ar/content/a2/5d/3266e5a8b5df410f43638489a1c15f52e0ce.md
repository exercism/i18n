# الاختبارات

يحتوي كل تمرين على ملف اختبار.
شغّل الاختبارات باستخدام برنامج `bats`.
```bash
bats test-hello-world.bats
```

ستحتاج إلى تثبيت `bats`.
راجع صفحة [الاختبار في مسار Bash][bash] للحصول على تعليمات تثبيت `bats` على نظامك.

### bats مكتوب بلغة bash

ملف bats هو سكربت bash، يتضمّن بعض الدوال الخاصة التي يتعرّف عليها أمر `bats`.
سترى بعض الاختبارات التي تبدو هكذا
```sh
gawk -f some-exercise.awk <<< "some,input,here"
```
صيغة `<<<` هذه هي [سلسلة هنا][here-string] في bash.
فهي ترسل السلسلة النصية على الجانب الأيمن إلى المدخل القياسي للبرنامج على الجانب الأيسر.
وهي ([تقريبًا][so]) مماثلة لـ
```sh
echo "some,input,here" | gawk -f some-exercise.awk
```

## مساعدة حول دوال assert

تستخدم الاختبارات دوال من مكتبة [bats-assert][bats-assert].
يمكن العثور هناك على مساعدة حول مختلف دوال `assert*`.

## الاختبارات المتخطّاة

حلّ التمرين يعني جعل جميع اختباراته تنجح.
افتراضيًا، يُنفَّذ اختبار واحد فقط (الأول) عند تشغيل الاختبارات.
وهذا مقصود، لأنه يتيح لك التركيز على جعل ذلك الاختبار الواحد ينجح فقط.
وبمجرد نجاحه، يمكنك تمكين الاختبار التالي بتعليق أو إزالة

    [[ $BATS_RUN_SKIPPED == true ]] || skip

التعليقات التوضيحية التي تسبق الاختبارات الأخرى.

## تجاوز التخطّي

لتشغيل جميع الاختبارات، بما فيها تلك التي تحمل تعليقات توضيحية `skip`، يمكنك تشغيل:
```bash
BATS_RUN_SKIPPED=true bats test-some-exercise.bats
```

قد يكون من المريح استخدام دالة غلاف لتوفير الكتابة: في `bash` يمكنك فعل ما يلي:
```bash
bats() {
    BATS_RUN_SKIPPED=true command bats *.bats
}
```
ثم شغّل الاختبارات بمجرد:
```bash
bats
```

## مخرجات التنقيح

```exercism/caution
هذا يعمل محليًا مع `bats`، ولكن **ليس** في محرّر Exercism على الإنترنت.
```

عند تشغيل الاختبارات، يجمع `bats` كلاًّ من `stdout` و`stderr` لمقارنتهما بالمخرجات المتوقعة.
إذا طبعت رسائل تنقيح إلى `stdout` أو `stderr`، فستُضمَّن في المخرجات المجموعة وقد تؤدي إلى فشل الاختبار.

لطباعة معلومات التنقيح دون التأثير على نتائج الاختبار، يوفّر `bats` واصف الملف **3** لهذا الغرض.
أي شيء يُطبع إلى الملف `/dev/fd/3` سيظهر أثناء تشغيل الاختبار لكنه لن يُضمَّن في المخرجات المجموعة المستخدمة في التحقق.

مثال:

```awk
BEGIN {
    # This debug message will not interfere with test output comparison
    print "a debug message" > "/dev/fd/3"

    # Normal program output (this is what your tests will see and compare)
    print "Hello, World!"
}
```

مثال على التشغيل:

```none
$ bats test-hello-world.bats
test-hello-world.bats
 ✓ Say Hi!
a debug message

1 test, 0 failures
```

يتيح لك ذلك رؤية مخرجات تنقيح مفيدة دون التأثير على الاختبارات.

قد يؤدي إخفاء التفاصيل في دالة إلى تحسين قابلية القراءة إذا استخدمتها في عدة مواضع في الكود:

```awk
BEGIN {
    debug("starting ...")
}

# do stuff here ...

END {
    debug("... finished")
}

function debug(msg) {print msg > "/dev/fd/3"}
```
