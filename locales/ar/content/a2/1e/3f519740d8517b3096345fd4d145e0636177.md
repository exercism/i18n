# مقدمة

الصفوف طريقة خفيفة لتجميع مجموعة ثابتة من أنواع البيانات المختلفة معًا.
الصف ليس له اسم معيّن؛ فإعطاء اسم لبنية بيانات يحوّله إلى `struct`.
ولا تملك حقول الصف أسماء؛ بل يمكن الوصول إليها عن طريق التفكيك أو حسب موضعها.

## الإنشاء

تُنشأ الصفوف دائمًا باستخدام تعبير صف:

```rust
// pointless but legal
let unit = ();
// single element
let single_element = ("note the comma",);
// two element
let two_element = (123, "elements can be of differing types");
```

يمكن للصفوف أن تحتوي على أي عدد من العناصر.

## الوصول بالتفكيك

يمكن الوصول إلى عناصر الصف عن طريق التفكيك.
وهذا يعني ببساطة إسناد أسماء المتغيرات إلى عناصر الصف الفردية، وهو ما يستهلكه.

```rust
let (elem1, _elem2) = two_element;
assert_eq!(elem1, 123);
```
