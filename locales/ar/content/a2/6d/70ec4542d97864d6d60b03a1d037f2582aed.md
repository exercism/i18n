# مقدمة

## السلاسل النصية

تُشكّل الأحرف والسلاسل النصية الأساس لتمثيل النصوص في Elm.
يمكن التفكير في السلاسل النصية على أنها مصفوفات من الأحرف، ولمعظم دوال `List` ما يقابلها في وحدة `String`.

### الأحرف

يمثّل النوع `Char` حرف يونيكود واحدًا بين علامتي اقتباس مفردتين، مثل `'a'`. 
توفّر وحدة `Char` دوال إخبارية (`Char -> Bool`) لاختبار خصائص الحرف: `isUpper` و`isLower` و`isAlpha` و`isAlphaNum`
كما توفّر الوحدة دوالًا لتحويل الحرف: `toUpper` و`toLower` و`toLocaleUpper` و`toLocaleLower`، إضافة إلى التحويل من قيمته الرقمية في يونيكود (`Int`) وإليها عبر `toCode` و`fromCode`.

### السلاسل النصية

يوفّر النوع `String` تمثيلًا مدمجًا للتعامل مع السلاسل النصية بكفاءة، ويمكنه تمثيل أي تسلسل من أحرف يونيكود، مثل "this is an Elm string."
تُمثَّل السلاسل النصية متعددة الأسطر بثلاث علامات اقتباس مزدوجة، ويمكن أن تحتوي على علامات اقتباس وأسطر جديدة غير مُهرَّبة.
```elm
"""
    This is a multiline string.
All line-breaks and whitespace,
are preserved. 
"""
```

### دوال السلاسل النصية

تحتوي وحدة `String` على جميع الدوال الموجزة في الجدول أدناه.
ومن أكثر الدوال استخدامًا:

تضيف `cons : Char -> String -> String` حرفًا إلى بداية السلسلة النصية.
```elm
cons 'T' "he truth is out there" 
    --> "The truth is out there"
```

تُلحق `(++): String -> String -> String` سلسلتين نصيتين ببعضهما.
```elm
"butter" ++ "fly" 
    --> "butterfly"
```

تقسّم `split : String -> String -> List String` سلسلة نصية إلى مصفوفة من السلاسل النصية عند الفاصل المعطى.
```elm
split ";" "cat;dog;cow" 
    --> ["cat", "dog", "cow"]
```

تدمج `join : String -> List String -> String` مصفوفة من السلاسل النصية معًا باستخدام فاصل معطى.
```elm
join "a" ["H", "w", "ii", "n"] 
    --> "Hawaiian"
```
تستبدل `replace : String -> String -> String -> String` جميع مواضع ورود سلسلة نصية فرعية معطاة.
```elm
replace "Hello" "Goodbye cruel" "Hello world." 
    --> "Goodbye cruel world."
```

تُرجع `length : String -> Int` عدد الأحرف في السلسلة النصية.
```elm 
length "Hello world." 
    --> 12
```

تحاول `toInt : String -> Maybe Int` تحويل سلسلة نصية إلى `Just Int`، وتُرجع `Nothing` للسلاسل النصية غير المنسّقة بشكل صحيح.
```elm
toInt "-42" 
    --> Just -42
```    

تتحقق `contains : String -> String -> Bool` مما إذا كانت السلسلة النصية الثانية تحتوي على الأولى.
```elm
contains "the" "theory" 
    --> True
```

تطبّق `map : (Char -> Char) -> String -> String` دالة معطاة على كل `Char` في السلسلة النصية.
لاحظ أن الدالة المقدَّمة يجب أن تكون تحويلًا من `Char` وإلى `Char`.
```elm
map (\c -> if c == '/' then '.' else c) "a/b/c" 
    --> "a.b.c"
```
