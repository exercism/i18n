# حول

`Enum` وحدة مفيدة جدًا توفّر مجموعة من الخوارزميات للتعامل مع القوابل للتعداد. فهي توفّر:

- الترتيب ([`sort/2`][enum-sort/2]، [`sort_by/2`][enum-sort_by/2])،
- التصفية ([`filter/2`][enum-filter/2])،
- التجميع ([`group_by/3`][enum-group_by/3])،
- العدّ ([`count/2`][enum-count/2])
- البحث ([`find/3`][enum-find/3])،
- إيجاد القيم الصغرى والعظمى ([`min/3`][enum-min/3]، [`max/3`][enum-max/3])،
- الاختزال ([`reduce/3`][enum-reduce/3]، [`reduce_while/3`][enum-reduce_while/3])،

والمزيد غير ذلك! راجع [توثيق وحدة `Enum`][enum-functions] للاطلاع على القائمة الكاملة.

## Enumerable

بشكل عام، _القابل للتعداد_ هو أي بيانات يمكن المرور عليها، أي مجموعة. وفي Elixir، القابل للتعداد هو أي نوع بيانات يطبّق [بروتوكول][exercism-protocols] `Enumerable`. وهذه الأنواع هي:

- [`List`][list]
- [`Map`][map]
- [`Range`][range]
- [`Stream`][stream]
- [`MapSet`][mapset]
- [`Function`][function]
- [`Date.Range`][date-range]
- [`IO.Stream`][io-stream]
- [`File.Stream`][file-stream]

لا تقلق إن لم تكن تعرفها كلها بعد.

يمكن لأي شخص تطبيق بروتوكول `Enumerable` على بنية البيانات المخصصة التي يصنعها بنفسه.

## الاختزال

تتيح لك `Enum.reduce/2` أن _تختزل_ القابل للتعداد بأكمله إلى قيمة واحدة. ولتحقيق ذلك، يُستخدم متغير خاص يُسمى _المراكم_. يحمل المراكم الحالة الوسيطة للاختزال بين تكرار وآخر. وهذا ما يجعلها واحدة من أقوى الدوال للتعامل مع القوابل للتعداد. فكثير من الدوال المتخصصة الأخرى يمكن استبدالها بالدالة الأعم `reduce`. على سبيل المثال...

إيجاد القيمة العظمى:

```elixir
Enum.max([4, 20, 31, 9, 2])
# => 31

Enum.reduce([4, 20, 31, 9, 2], nil, fn x, acc ->
  cond do
    acc == nil -> x
    x > acc -> x
    x <= acc -> acc
  end
end)

# => 31
```

وحتى التحويل (لكنه يتطلب عكس النتيجة بعد ذلك):

```elixir
Enum.map([1, 2, 3, 4, 5], fn x -> x + 10 end)
# => [11, 12, 13, 14, 15]

Enum.reduce([1, 2, 3, 4, 5], [], fn x, acc -> [x + 10 | acc] end)
# => [15, 14, 13, 12, 11]
```

## تحويل الخرائط

- باستخدام [`Map.new/2`][map-new]:
  ```elixir
  %{a: 1, b: 2}
  |> Map.new(fn {key, value} -> {key, value * 10} end)
  ```

- باستخدام [`Enum.into/3`][enum-into]:
  ```elixir
  %{a: 1, b: 2}
  |> Enum.into(%{}, fn {key, value} -> {key, value * 10} end)
  ```

- باستخدام [`Enum.map/2`][enum-map]:
  ```elixir
  %{a: 1, b: 2}
  |> Enum.map(fn {key, value} -> {key, value * 10} end)
  |> Enum.into(%{})
  ```
