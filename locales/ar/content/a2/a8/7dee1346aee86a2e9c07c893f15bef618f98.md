# نبذة

## const

يمكن تطبيق المُعدِّل [`const`][constants] (ويُستحسن تطبيقه عمومًا) على أي حقل تُعرف قيمته وقت الترجمة ولن تتغير خلال مدة عمل البرنامج.

```csharp
private const int num = 1729;
public const string title = "Grand" + " Master";
```

سيرشدك المترجم إلى التعبيرات التي يمكن تقييمها وقت الترجمة. تُسمح العمليات الحسابية البسيطة، كما يُسمح بدمج السلاسل النصية. وهذا يستبعد أي تقييم يتطلب استخدام الكومة أو المكدس، لذا لا تتوفر جميع استدعاءات الطرق والمراجع إلى الأنواع غير الأولية.

ثمة بعض النقاش على الويب حول مزايا الأداء التي يوفّرها `const` مقارنة بالمتغيرات. وفي حالة المقارنة مع حقول النسخة غير المعدّلة بـ `const`، قد يكون هناك توفير ملحوظ في الذاكرة، لكنه تافه بكل تأكيد مقارنة بالمتغيرات الساكنة. ومن المرجح أن ينظر زملاؤك إلى أي اهتمام بأداء المعالج على أنه [تحسين سابق لأوانه][premature-optimization].

ثمة سبب أقوى لاستخدام `const`، وهو أنه يعزز قدرة القائم على الصيانة على الاستدلال بشأن الكود. فمجرد ملاحظة أن حقلًا ما موسوم بـ `const` أو `readonly`، أو أن خاصية ما لا تحتوي على ضابط `set`، يمكّن القائم على الصيانة إلى حد كبير من استبعاده من تحليله. فمن غير المرجح أن يكون مصدرًا للأخطاء. ومن غير المرجح أن يطرح صعوبات في عملية إعادة الهيكلة. ويتناول [هذا التعليق على Stack Overflow][so-consts] هذه النقطة.

يمكن أيضًا تطبيق المُعدِّل `const` على القيم داخل الطرق:

```csharp
public double Area(double r)
{
    const double π = 3.142;
    return System.Math.Pow((π * r), 2);
}
```

قد يكون تحديد قيمة بـ `const` بهذه الطريقة مفيدًا إذا استُخدمت عدة مرات في الطريقة، أو إذا أردت لفت الانتباه إلى معناها. ولا يوجد أي مكسب في الأداء مقارنة باستخدام القيم الحرفية مباشرة في موضعها.

## readonly

يمكن تطبيق المُعدِّل [`readonly`][readonly-fields] (ويُستحسن تطبيقه عمومًا) على أي حقل يتعذّر جعله `const`، على أن تكون قيمته غير متغيرة خلال مدة عمل البرنامج، وأن تُضبط إما بتهيئة في الموضع نفسه أو أثناء إنشاء النسخة (عبر المنشئ أو عبر طريقة يستدعيها المنشئ).

```csharp
private readonly int num;
private readonly System.Random rand = new System.Random();

public MyClass(int num)
{
    this.num = num;
}
```

يُشجَّع استخدام المُعدِّل `readonly` للأسباب نفسها التي تنطبق على `const`. وتساعد ممارسة تقييد الحقول بهذه الطريقة القائمين على الصيانة على الاستدلال بشأن الكود.

لاحظ أن إضافة المُعدِّل `readonly` إلى حقل يمنع تغيير قيمة الحقل فقط. وفي حالة الأنواع المركّبة فإنه لا يحمي حقول ذلك النوع أو خصائصه. وعلى وجه الخصوص، لا يحمي محتويات المصفوفات.

```csharp
private readonly IList list = new List();

public void Foo()
{
    list = new List();  // does not compile

    list.Add("new stuff");  // succeeds at runtime
}
```

لضمان حماية جميع أعضاء نوع مرجعي، يمكن جعل الحقول `readonly` وتعريف خصائص تلقائية دون ضابط `set`.

ينبغي أن تطلع على [المجموعات للقراءة فقط][readonly-collections] في مكتبة الأصناف الأساسية.

وبالنسبة للمصفوفات، فإن أقرب ما يمكنك الوصول إليه من نسخة للقراءة فقط هو طريقة [`Array.AsReadOnly<T>()`][as-read-only].
