# نبذة

PowerShell هي لغة برمجة نصية ديناميكية ومُنمَّطة ضمنيًا (_لكنها تدعم أيضًا [المتغيرات قوية النمط][strong typed]_) من Microsoft، وتركّز في الغالب على أتمتة المهام وإدارة الإعدادات.

تدعم PowerShell البرمجة الأمرية والوظيفية والكائنية التوجه، وحتى البرمجة بنمط خطوط الأنابيب.

بُنيت PowerShell على منصة .NET وصدرت أول مرة عام 2006.
وهي مضمنة افتراضيًا في جميع إصدارات Windows الحديثة، ويمكن تثبيتها أيضًا على Mac و Linux.


## المتغيرات

هناك طريقتان شائعتان لتعريف متغير في PowerShell.

يجب أن تبدأ أسماء المتغيرات في PowerShell بالرمز `$`، وتستخدم عامل الإسناد `=` لربط اسم المتغير بقيمة.

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

يمكنك أيضًا تحديد نوع المتغير صراحةً، إذا أردت فرض أن تكون القيمة من نوع معين.
وستبذل PowerShell قصارى جهدها لتحويل القيمة من نوع إلى آخر إن أمكن.

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```

### الثوابت

الثوابت في PowerShell هي متغيرات لا يمكن **تغييرها** ولا **إزالتها** بعد تعريفها.
وهذا يقودنا إلى الطريقة الثانية لتعريف المتغيرات: استخدام الـ cmdlet المسمّى `New-Variable`.

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
100
```


## الدوال

تُعرَّف الدوال في PowerShell باستخدام الكلمة المفتاحية `function`.
ويمكن أن تحتوي كل دالة على صفر أو أكثر من المعاملات الشكلية بين الأقواس الهلالية `()`، متبوعةً بنطاق الدالة الذي يبدأ بـ `{` وينتهي بـ `}`.

```powershell
function Greeting {
    return "Hello!"
}
```

يمكن للدوال في PowerShell إرجاع القيم صراحةً عبر الكلمة المفتاحية `return`، بعد استدعائها باستخدام الصيغة `FuncName $Arg`.

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

## التعليقات

يبدأ التعليق المفرد في PowerShell بالرمز `#` وينتهي عند نهاية السطر.
أما كتل التعليقات في PowerShell فتبدأ بـ `<#` وتنتهي بـ `#>`.

```powershell
function Main() {
    #This is a comment
    <#
    And this is a comment block
    that can span multiple lines
    #>
}
```
