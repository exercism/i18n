# 소개

Swift의 `guard`문은 이후 처리를 계속하는 데 꼭 필요한 조건이 충족되지 않았을 때 함수에서 일찍 반환하기 위해 사용해요. 예를 들면 다음과 같아요:

```swift
guard myValue >= 0 else { return 0 }
let root = myValue.squareRoot()
```

여기서 `guard`는 `guard` 키워드 뒤에 오는 불리언 표현식이 참으로 평가되는지 확인해요. 참이면 `guard`문 다음에 오는 코드(여기서는 `let root = myValue.squareRoot()`로 처리를 계속해요. 그렇지 않으면 else 절의 코드를 실행해요. `if`문과 달리 `guard`문에는 else 절이 _반드시_ 있어야 하고, if-else의 else 절과 달리 guard의 else 절은 _반드시_ `guard`문의 스코프를 벗어나야 해요. 즉, `return`, `continue`, `break`와 같은 제어 전달문을 사용하거나, 오류를 던지거나 프로그램을 종료해야 해요.
