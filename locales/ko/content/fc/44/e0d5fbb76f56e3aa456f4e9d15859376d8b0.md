# 소개

[Groovy](http://www.groovy-lang.org/)는 Apache 재단의 강력한 동적 언어로, 타입 지정이 선택 사항이며 정적 타입 지정과 정적 컴파일 기능도 갖추고 있어요.

Groovy는 간결하고 배우기 쉬운 문법으로 개발자의 생산성을 높이는 것을 목표로 해요.
스크립팅, 도메인 특화 언어 작성, 런타임과 컴파일 시점 메타프로그래밍, 함수형 프로그래밍을 쉽게 할 수 있게 해줘요.

Java 라이브러리 생태계 전체에 접근할 수 있고, Java 애플리케이션과 매끄럽게 통합돼요.

간단한 스크립팅 언어로 쓸 수도 있고, 복잡한 Java 프레임워크에 추가할 수도 있어요. 
다음과 같은 기술들을 구동하고 있죠: 
* Gradle, 
* Spock, 
* Ratpack, 
* Grails, 
* 그리고 Jenkins의 스크립팅.

그리고 재미있어요.
