# 안내

치즈 클럽을 시작하려고 해요. 이 클럽에서는 머신러닝을 이용해, 치즈를 좋아하는 고객의 이력과 취향을 바탕으로 새로 소개할 치즈를 골라요.

새로 가입하는 회원은 시작에 필요한 기본 데이터를 모으기 위해 먼저 간단한 설문을 작성해야 해요. 그 과정에서 비평에 미묘한 차이가 없는, 극단적인 고객 집단이 있다는 걸 알게 됐어요. 이런 고객 때문에 더 섬세한 알고리즘에 돌이킬 수 없는 편향이 생길 수 있어서, 이들을 처리할 별도의 알고리즘을 따로 만들어 두었어요. 이들의 데이터를 다루기 위한 몇 가지 도우미 함수를 만들어 주세요.

~~~~exercism/note
다음 과제를 푸는 방법은 여러 가지가 있겠지만, 각 과제는 고차 함수를 두 개 넘게 쓰지 않고 풀 수 있어요.
~~~~

## 1. 고객 분류하기

평점 시스템은 별 다섯 개를 기준으로 하고, 정수 `1:5`로만 이루어져 있어요. 극단적인 고객은 `1` 또는 `5` 평점만 주는데, 어떤 고객이 이런 성향을 보이는지 알고 싶어요.

`all_15()`를 구현해 보세요. 이 함수는 평점 벡터를 받아서, 모든 평점이 `1` 또는 `5`이면 `true`를, 그렇지 않으면 false를 반환해요.

```R
all_15(c(2, 3, 4, 4, 1))
#> [1] FALSE

all_15(c(1, 5, 5, 1, 5))
#> [1] TRUE
```

## 2. 고객에게 이름 붙이기

고객 이름(또는 ID)을 평점과 연결해야 해요.

`name_customers()`를 구현해 보세요. 이 함수는 이름 벡터와 평점 리스트를 받아서, 둘을 짝지어 리스트의 리스트로 만들어요.

안쪽 리스트 원소에는 `name`과 `rating`이라는 이름이 붙어야 해요.

```R
names <- c("c1", "c2")
ratings <- list(c(2, 3, 5), c(1, 1, 5))
name_customers(names, ratings)
#> [[1]]
#> [[1]]$name
#> [1] "c1"

#> [[1]]$rating
#> [1] 2 3 5

#> [[2]]
#> [[2]]$name
#> [1] "c2"

#> [[2]]$rating
#> [1] 1 1 5
```

## 3. 극단적인 고객 분리하기

극단적인 고객을 나머지 고객과 분리해야 해요.

`emphatics()`를 구현해 보세요. 이 함수는 고객과 평점을 받아요.

`1` 또는 `5` 별점만 사용하는 고객만 담은 리스트를 반환해요.

```R
# names and ratings as in the task 2 example

emphatics(names, ratings)
#> [[1]]
#> [[1]]$name
#> [1] "c2"

#> [[1]]$rating
#> [1] 1 1 5
```

## 4. 평점을 이진수로 바꾸기

극단적인 고객은 `1`과 `5` 평점만 사용하니까, 이걸 `0`과 `1`로 바꾸면 계산하기가 더 편해요.

`to_binary()`를 구현해 보세요. 이 함수는 극단적인 고객의 평점 벡터를 받아요.

`1`은 `0`으로, `5`는 `1`로 바꾼 이진 평점을 반환해요.

```R
to_binary(c(1, 1, 5, 5, 1))
#> [1] 0 0 1 1 0
```

## 5. 시간에 따른 평균 평점 계산하기

고객의 취향을 더 잘 파악하게 되면서, 극단적인 고객뿐 아니라 모든 고객을 위한 추천을 계속 개선하고 싶어요.

`satisfactions()`를 구현해 보세요. 이 함수는 평점 벡터를 받아요.

지금까지의 누적 평균 평점을 담은 벡터를 반환해요. 결과는 소수점 둘째 자리까지 반올림해요.

행복한 고객을 위해, 이 숫자가 계속 커지기를 바라요!

```R
satisfactions(c(1, 2, 2, 3))
#> [1] 1.00 1.50 1.67 2.00
```
