# 힌트

## 일반

- 함수 매개변수에서 여러 인자를 받아내려면 `...<args>`로 묶어요.
- 나머지와 전개를 사용하려면 `...` 연산자를 사용해요.

## 1. 모든 객차 목록 만들기

- 함수 매개변수에 있는 여러 인자는 [`...<args>`(전개) 문법][spread-syntax] 연산자로 묶을 수 있어요.

## 2. 배열의 처음 두 원소를 끝으로 옮기기

- [구조 분해 할당(`...`)][destructuring-assignment]을 사용하면 여러 매개변수를 풀어낼 수 있어요. 이렇게 하면 `array`의 처음 두 원소를 추출하면서 나머지는 그대로 둘 수 있어요.
- 기존 `array`에 다른 `array`를 넣으려면 `...` 연산자로 `array`를 "전개"할 수 있어요.

## 3. 빠진 값 추가하기

- 나머지 연산자(`...`)와 함께 풀어쓰기를 사용하면 `array`의 첫 번째 원소를 추출하면서 나머지는 그대로 둘 수 있어요.
- 기존 `array`에 다른 `array`를 넣으려면 `...` 연산자로 `array`를 "전개"할 수 있어요.

## 4. 라우팅 정보 확장하기

- 기존 `object`에 다른 `object`를 넣으려면 `...` 연산자로 `object`를 "전개"할 수 있어요.

## 5. 도착 시간과 라우팅 정보 분리하기

- `object`에서 값을 추출하면서 나머지는 그대로 두려면 나머지 연산자(`...`)를 사용할 수 있어요.

[spread-syntax]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Spread_syntax
[destructuring-assignment]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Destructuring_assignment
