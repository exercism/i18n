# 힌트

**기억해 두세요**: 이 연습 문제의 테스트는 입력을 변경하든 하지 않든 상관하지 않지만, 함수 이름을 보면 입력을 변경하지 않아야 한다는 것을 알 수 있어요.
입력을 변경하지 않으면서 소개에 나온 함수를 사용하고 싶다면 `copy()` 함수가 도움이 될 거예요.

## 1. 벡터를 기반으로 재고 만들기

- 시작하기 전에 과제 2를 먼저 살펴보면 도움이 될 거예요.

## 2. 기존 딕셔너리에 벡터의 항목 추가하기

- 가장 간단한 방법은 입력 벡터를 한 번에 항목 하나씩 반복하는 거예요.
- [`haskey(dict, key)`][haskey] 함수가 유용할 거예요.

## 3. 재고에서 항목 개수 줄이기

- 코드는 과제 2와 거의 비슷한데, 부호가 바뀌어요.
- 항목 개수가 0 아래로 내려가지 않도록 조심해요.
- `if...else` 논리로도 되지만, [`max()`][max] 함수를 쓰면 코드를 간결하고 관용적으로 작성할 수 있어요.

## 4. 재고에서 항목 완전히 제거하기

- Julia에는 바로 이 일을 하는 함수가 있어요. 소개를 읽어 봐요.

## 5. 재고의 전체 내용 반환하기

- 개수가 0인 항목은 제거해야 한다는 것을 기억해요.
- 초보자라면 항목을 반복하면서 필요할 때 [`push!()`][push]하는 방법이 가장 쉬울 거예요.
- Python 스타일의 리스트 컴프리헨션을 쓰면 훨씬 간결하고, 끝에 `if` 절을 붙여도 돼요.
- 뒤에 나오는 개념에 대한 지식이 필요하긴 하지만, 함수형 프로그래밍에 익숙한 학습자라면 [`filter()`][filter] 함수를 살펴보고 싶을지도 몰라요.
- 정렬된 배열이 필요하고, [`sort()`][sort]는 기본적으로 쌍의 첫 번째 값을 기준으로 정렬해요.
