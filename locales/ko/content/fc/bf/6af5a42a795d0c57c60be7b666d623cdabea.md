# Char

`Char`는 Crystal에서 32비트 [유니코드][unicode] 코드 포인트를 나타내는 데이터 타입이에요.
이 크기 덕분에 메모리를 효율적으로 사용할 수 있고, 문자열에는 없는 고유한 특성도 가지고 있어요.
작은따옴표(`'`)로 만들며, 안에는 유니코드 코드 포인트 하나만 넣을 수 있어요.

```crystal
'a' # => 'a'
'a'.class # => Char
```

Crystal에서 문자열을 다룰 때 Char를 함께 다루는 일은 아주 흔해요. 문자열 클래스에는 Char를 반환하거나 Char를 인자로 받는 메서드가 꽤 많기 때문이에요.
예를 들어 [`String#[]`][index] 메서드는 Char를 반환하고, [`String#chars`][chars] 메서드는 Char 컬렉션을 반환해요.

## 증가 / 감소

Char는 32비트 유니코드 코드 포인트이기 때문에 증가와 감소를 지원해요. 덕분에 `'a'`가 있을 때 1을 더하면 `'b'`를 얻을 수 있어요.

```crystal
'a' + 5
# => 'f'

'z' - 25
# => 'a'
```

유니코드 표에서 다음 문자를 반환하는 [`Char#succ`][succ] 메서드와, 이전 문자를 반환하는 [`Char#pred`][pred] 메서드도 있어요.

```crystal
'a'.succ
# => 'b'

'z'.pred
# => 'y'
```

## 연결

Char는 32비트 유니코드 코드 포인트 하나만 나타내도록 만들어졌기 때문에 Char 두 개를 서로 연결할 수 없어요. 따라서 Char는 문자열과만 연결할 수 있어요.

```Crystal
'a' + "bc"
# => "abc"

'a' + 'b'
# => error: expected argument #1 to 'Char#+' to be Int or String, not Char
```

## 속성 메서드

Crystal에는 문자가 숫자인지 글자인지, 대문자인지 소문자인지 같은 정보를 알아낼 수 있는 메서드가 몇 가지 있어요.
다음은 그중 일부예요. 전체 목록은 [Char API][char-api]에서 확인할 수 있어요.

| 메서드                           | 설명                                          |
| -------------------------------- | ---------------------------------------------------- |
| [`Char#number?`][number]         | Char가 숫자면 `true`를 반환해요               |
| [`Char#letter?`][letter]         | Char가 글자면 `true`를 반환해요               |
| [`Char#lowercase?`][lowercase]   | Char가 소문자면 `true`를 반환해요              |
| [`Char#uppercase?`][uppercase]   | Char가 대문자면 `true`를 반환해요              |
| [`Char#ascii?`][ascii]           | Char가 ASCII 문자면 `true`를 반환해요     |
| [`Char#whitespace?`][whitespace] | Char가 공백 문자면 `true`를 반환해요 |

## 변환

### 코드 포인트와 Char 사이의 변환

Char는 32비트 유니코드 코드 포인트이기 때문에 Char와 코드 포인트(정수) 사이를 변환할 수 있어요.
[`Char#ord`][ord] 메서드로 Char의 코드 포인트를 얻거나, [`Int#chr`][chr] 메서드로 코드 포인트에 해당하는 Char를 얻을 수 있어요.

```crystal
'a'.ord
# => 97

97.chr
# => 'a'
```

### 타입 사이의 변환

다른 데이터 타입과 마찬가지로 Char에도 타입을 변환하는 메서드가 몇 가지 있어요.
가장 흔히 쓰는 건 Char를 문자열로 변환하는 `Char#to_s` 메서드예요. 그 밖에도 Char를 정수로 변환하는 `Char#to_i` 메서드와 Char를 실수로 변환하는 `Char#to_f` 메서드가 있어요.

```crystal
'a'.to_s
# => "a"

'4'.to_i
# => 4

'a'.to_i
# => Error: Invalid integer: a (ArgumentError)
```
