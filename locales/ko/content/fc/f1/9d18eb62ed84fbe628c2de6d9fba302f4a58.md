# 지침

무용단이 선보이는 모든 루틴은 같은 워밍업을 바탕으로 만들어지고, 그다음부터는 저마다 자기 방식대로 나아가요.

스텁에는 `WARM_UP`이 주어져 있어요. 그 아래에 클래스 세 개를 더 작성해요.

## 1. 재즈 루틴

`JAZZ_ROUTINE`은 `WARM_UP`의 모든 것을 그대로 가져오고, 아무것도 더하지 않아요.

```sather
JAZZ_ROUTINE::counts
-- => 8
JAZZ_ROUTINE::describe
-- => "8 counts"
```

## 2. 탭 루틴

`TAP_ROUTINE`은 `WARM_UP`에서 `counts`을 가져오지만, 자기만의 방식으로 자신을 설명해요. include에서 `describe`를 빼고 새로 작성해요.

```sather
TAP_ROUTINE::counts
-- => 8
TAP_ROUTINE::describe
-- => "Tap: 8 counts"
```

## 3. 피날레

`FINALE`은 `WARM_UP`에서 `counts`을 `warm_up_counts`라는 이름으로 가져오고, `describe`는 빼요. 그다음에는 워밍업의 두 배인 자기만의 `counts`가 있고, 자기만의 `describe`도 있어요.

```sather
FINALE::warm_up_counts
-- => 8
FINALE::counts
-- => 16
FINALE::describe
-- => "Finale: 16 counts"
```

여기서 알 수 있는 점이 하나 있어요: `FINALE::counts`는 `WARM_UP::counts`가 아니고, 둘 다 같은 클래스 안에서 서로 다른 이름으로 쓸 수 있어요.
