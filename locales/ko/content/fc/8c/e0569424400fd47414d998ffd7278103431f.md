# 지침

런 렝스 부호화와 복호화를 구현해요.

런 렝스 부호화(RLE)는 데이터 압축의 간단한 형태로, 연속된 데이터 요소인 런을 하나의 데이터 값과 개수로 대체해요.

예를 들어 원래 53개 문자를 단 13개로 나타낼 수 있어요.

```text
"WWWWWWWWWWWWBWWWWWWWWWWWWBBBWWWWWWWWWWWWWWWWWWWWWWWWB"  ->  "12WB12W3B24WB"
```

RLE를 사용하면 압축된 데이터에서 원래 데이터를 완벽하게 복원할 수 있어요. 그래서 무손실 데이터 압축이에요.

```text
"AABCCCDEEEE"  ->  "2AB3CD4E"  ->  "AABCCCDEEEE"
```

간단히 하기 위해, 부호화되지 않은 문자열에는 알파벳 A부터 Z까지(대문자 또는 소문자)와 공백만 들어 있다고 가정해도 돼요.
이렇게 하면 부호화할 데이터에는 숫자가 전혀 들어 있지 않고, 복호화할 데이터에 있는 숫자는 항상 다음 문자의 개수를 나타내요.
