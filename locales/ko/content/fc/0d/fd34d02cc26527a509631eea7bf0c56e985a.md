# 문자

**문자**는 글자 하나, 숫자 하나, 공백 하나 또는 기호 하나를 말해요. Sather에서
문자 하나를 나타내는 타입은 `CHAR`이고, 문자는 작은따옴표 사이에 적어요.

```sather
   initial : CHAR is
      return 'M';
   end;
```

문자 하나에는 작은따옴표를, 문자열에는 큰따옴표를 써요. `'M'`과 `"M"`은 서로
다른 타입이라 바꿔 쓸 수 없어요.

## 문자열에서 문자 꺼내기

문자열은 문자가 나열된 것이고, 대괄호로 위치를 지정하면 0부터 세어 문자 하나를
꺼낼 수 있어요. 배열과 같은 방식이에요.

```sather
"Marlowe"[0]      -- 'M'
"Marlowe"[3]      -- 'l'
```

## 문자에 대해 물어보기

| 호출 | 답 |
| --- | --- |
| `c.is_alpha` | 글자인가요? |
| `c.is_digit` | `0`–`9` 중 하나인가요? |
| `c.is_upper` | 대문자인가요? |
| `c.is_lower` | 소문자인가요? |

각각 `true`나 `false`로 답해요.

```sather
'M'.is_alpha      -- true
'7'.is_alpha      -- false
'7'.is_digit      -- true
```

## 대소문자 바꾸기

`.upper`는 문자의 대문자를, `.lower`는 소문자를 돌려줘요. 문자이지 않은 것은
그대로 돌아와요.

```sather
'm'.upper         -- 'M'
'M'.lower         -- 'm'
'7'.upper         -- '7'
```

## 숫자로서의 문자

모든 문자에는 숫자가 하나씩 있어요. `.int`로 그 숫자를 얻고, `.char`로 숫자를
다시 문자로 바꿔요.

```sather
'a'.int           -- 97
'b'.int           -- 98
98.char           -- 'b'
```

정확한 숫자가 중요한 경우는 거의 없어요. 중요한 건 `a`부터 `z`까지의 글자가
순서대로 나란히 있다는 점이에요. 그래서 `'c'.int - 'a'.int`는 2가 되는데, 이는
`c`가 알파벳에서 얼마나 떨어져 있는지를 나타내요. 암호 바퀴가 작동하는 원리가
바로 이거예요.
