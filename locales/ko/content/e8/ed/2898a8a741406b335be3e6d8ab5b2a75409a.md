# 소개

Factor의 조건문은 **쿼터테이션** 중에서 하나를 골라요. 쿼터테이션은 대괄호 `[ ... ]`로 묶은 코드 조각을 말해요. `[ ... ]`라고 쓰면 코드를 실행하는 대신 값으로서 스택에 올려요. 그러면 조건문이 어느 쿼터테이션을 실행할지 결정해요. (쿼터테이션은 이후 연습 문제에서 자세히 다뤄요.)

`if`([`kernel`][kernel]에 있어요)는 Factor의 기본 조건문이에요. 불리언 하나와 쿼터테이션 두 개를 받아서, 불리언이 참이면 첫 번째를 실행하고 그렇지 않으면 두 번째를 실행해요.

```
if ( ? then-quot else-quot -- )
```

```factor
: abs ( x -- y ) dup 0 < [ neg ] [ ] if ;
```

`when`은 불리언이 참일 때만 쿼터테이션을 실행하고, `unless`는 거짓일 때만 실행해요. 여러 갈래로 분기할 때는 `cond`([`combinators`][combinators]에 있어요)를 써요.

```factor
USING: combinators ;

: classify ( n -- s )
    {
        { [ dup 0 <  ] [ drop "negative" ] }
        { [ dup 0 =  ] [ drop "zero"     ] }
        [ drop "positive" ]
    } cond ;
```

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
[combinators]: https://docs.factorcode.org/content/vocab-combinators.html
