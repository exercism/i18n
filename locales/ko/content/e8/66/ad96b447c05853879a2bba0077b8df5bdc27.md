# 소개

## Try/Rescue/Else/After

`try..rescue`를 사용하면 오류가 발생했을 때 이를 잡아내는 강력한 구조를 만들 수 있어요. 오류를 잡아내면 함수가 필요할 때 정해진 값을 반환할 수 있어요. `try..rescue` 구조는 우리가 활용할 수 있는 두 가지 추가 기능도 제공해요.

- `else` 블록
  - try 블록이 성공하면, 그 결과가 이 블록과 매치돼요.
- `after` 블록
  - try 블록이 성공하든 예외를 발생시키든, 그 시점에 프로그램이 실행 중이라면 `after` 블록의 코드는 항상 실행돼요.
  - `after` 블록의 결과는 호출한 스코프로 반환되지 않아요.

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```

## 동적 디스패치

Elixir가 호출할 함수를 결정할 때는 모듈의 이름으로 검색을 수행해요. 모듈의 이름이 변수에 바인딩되어 있으면 이 검색을 동적으로 할 수 있어요.

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```

내부적으로 모듈의 이름은 아톰이에요. 모든 Elixir 모듈 아톰에는 자동으로 `Elixir.`가 앞에 붙어요.

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```
