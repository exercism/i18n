# 자세히 알아보기

Rust에서 불리언은 `bool` 타입으로 표현되는데, 이 타입의 값은 `true` 또는 `false`예요.

Rust는 [불리언 부정 연산자][negation operators]를 하나 지원해요: `!` (부정).

Rust는 [비교 연산자][comparison operators] 여섯 개를 지원해요: `==` (같음), `!=` (같지 않음), `>` (큼), `<` (작음), `>=`
(크거나 같음), `<=` (작거나 같음). 이 연산자들은 불리언이 아닌 값들의 관계를 평가해 불리언 값으로 만들어 줘요.

```rust
1 > 0 // true
1 < 0 // false
1 == 0 // false
1 != 0 // true
1 >= 0 // true
1 <= 0 // false
```

다른 몇몇 언어와 달리, Rust에서는 `0`이 `false`가 아니고 0이 아닌 값이 `true`도 아니에요.

Rust는 [논리 이항 연산자][logical binary operators] 세 개를 지원해요: `&` (논리곱), `|` (논리합), `^` (배타적 논리합).

Rust는 [불리언 연산자][lazy boolean operators] 두 개를 지원해요: `||` (또는), `&&` (그리고). 이 둘은 `|`와 `&`와 달리,
왼쪽 피연산자만으로는 식의 결과가 결정되지 않을 때에만 오른쪽 피연산자를 평가해요. 즉, `||`는 왼쪽 피연산자가 `false`로
평가될 때에만 오른쪽 피연산자를 평가하고, `&&`는 왼쪽 피연산자가 `true`로 평가될 때에만 그래요.

```rust
true || false // == true; the right-hand side was not evaluated
true && false // == false
```
