# 학습

Bash는 아주 강력한 유닉스 셸이자 명령 스크립팅 언어지만, 학습 난이도가 꽤 가파른 편이에요.

* Bash의 [man 페이지](https://manpage.me/index.cgi?apropos=0&q=bash&sektion=1&manpath=Debian+7.8.0&arch=default&format=html)는
  잘 쓰인, 정보가 풍부한 문서예요. 다만 내용이 워낙 빽빽해서 읽고 또 읽어야 해요.

* 더 많은 안내와 정보, 예제는 다음에서 찾을 수 있어요.
    * [Greg's Wiki](http://mywiki.wooledge.org/BashGuide),
    * [Bash Hackers Wiki](https://web.archive.org/web/20230323071638/https://wiki.bash-hackers.org/),
    * Stack Overflow의 [bash 태그 정보 페이지](https://stackoverflow.com/tags/bash/info),
    * 그리고 man 페이지를 더 자세히 다룬 [GNU Bash 매뉴얼](http://gnu.org/s/bash/manual)은
      bash 정보의 _바로 그_ 원천이에요.

* [shellcheck.net](https://www.shellcheck.net/)은 셸 스크립트의 오류나 흔한 문제를
  검사하고, 어떻게 고치는 것이 가장 좋은지 알려 주는 웹 인터페이스(일부 배포판에서는
  바이너리도)를 제공해요.
