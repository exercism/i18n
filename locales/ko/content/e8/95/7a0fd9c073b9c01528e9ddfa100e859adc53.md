# 소개

## Agent

`Agent` 모듈은 [프로세스와 _receive-send_ 루프][exercism-processes]를 생성하기 위한 추상화를 제공해요. 여기서부터는 `Agent` 모듈로 시작한 프로세스를 '에이전트 프로세스'라고 부를게요. 에이전트 프로세스는 중앙에서 공유하는 상태를 나타내는 데 쓰일 수 있어요.

에이전트 프로세스를 시작하려면 `Agent`가 제공하는 `start/2` 함수를 사용해요. `start`로 에이전트 프로세스를 시작할 때 넘겨주는 함수는 그 프로세스의 초기 상태를 반환해요.

```elixir
# Start an agent process with an initial value of an empty list
{:ok, agent_pid} = Agent.start(fn -> [] end)
```

`Map`이나 `List`처럼 `Agent`도 에이전트 프로세스를 다루는 다양한 함수를 제공해요.

모델링하는 도메인의 `Agent` 관련 기능은 모두 하나의 모듈로 묶어 캡슐화하는 것이 일반적이에요.

[exercism-processes]: https://exercism.org/tracks/elixir/concepts/processes
