# 나머지

수학에서 **나머지**는 어떤 계산을 하고 난 뒤 "남는" 값이에요.
예를 들어 `5 / 3`의 나머지는 `2`예요.

많은 프로그래밍 언어에서는 나머지를 계산할 때 퍼센트 기호(`%`)를 연산자로 사용해요.
예를 들면:
```javascript
5 % 3 == 2
```

나머지는 정수와 실수 모두에서 계산할 수 있는 경우가 많아요.
예를 들어,
```javascript
5.3 % 3 == 2.3
```

음수를 다룰 때는 결과가 항상 피제수(나누어지는, 왼쪽에 있는 수)와 같은 부호를 가져요.
예를 들어:
```javascript
-5 % 3 == -2
5 % -3 == 2
-5 % -3 == -2
```

일부 언어(예: Python)는 나머지가 아니라 모듈러스를 계산할 때 `%` 연산자를 사용해요.
이런 언어는 음수를 다르게 처리해요.
이에 대해서는 [위키백과](https://en.wikipedia.org/wiki/Modulo)에서 더 알아볼 수 있어요.
