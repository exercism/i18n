# 개요

[`while`문][while-loops]은 조건이 참인 동안 코드를 실행할 수 있게 해 주는 제어 흐름 문이에요. Swift는 `while`문과 `repeat-while`문, 두 가지 while 루프를 제공해요. `while`문은 루프 본문을 실행하기 전에 조건을 평가해요. 조건이 거짓이면 루프 본문은 아예 실행되지 않아요. Swift의 `while`문은 다음과 같은 구조를 가져요.

```swift
while <#condition#> {
  <#code#>
}
```

다음 코드에서 루프는 count가 0보다 큰 동안 실행되고, 그 결과 2, 1, 그리고 "Liftoff!"를 출력해요.

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

[`repeat-while`문][while-loops]은 `while`문과 비슷하지만, 조건을 루프 본문을 실행한 뒤에 평가해요. 그래서 조건이 거짓이더라도 루프 본문은 항상 적어도 한 번은 실행돼요. Swift의 `repeat-while`문은 다음과 같은 구조를 가져요.

```swift
repeat {
  <#code#>
} while <#condition#>
```

다음 코드에서 조건이 거짓이기 때문에 루프는 한 번만 실행돼요. `repeat-while`문이므로 조건을 평가하기 전에 루프 본문이 한 번 실행되는 거예요.

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```

## 옵셔널 바인딩 루프

Swift에서 흔히 볼 수 있는 `while`문의 변형 중 하나는 옵셔널 바인딩 `while`문이에요. 이 루프는 옵셔널 값을 내놓는 어떤 함수를 호출했을 때 `nil`이 아닌 값이 반환되는 동안 계속 반복해요. 그 값은 옵셔널이 아닌 값이 되어 원하는 이름에 바인딩되고, 루프 본문에서 사용할 수 있어요.

```swift
var arr = [1,2]
while let count = arr.popLast() {
  print("\(count)…")
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```
