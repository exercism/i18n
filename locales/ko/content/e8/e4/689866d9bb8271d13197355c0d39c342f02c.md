# 소개

여러 워드가 상태 하나를 공유해야 할 때가 있어요. 그때마다 스택 효과를 거쳐 값을 넘겨줄 필요는 없어요. Factor의 *동적 변수*는 `SYMBOL:`로 선언하는데, 각 워드가 네임스페이스에 저장된 값에 접근할 수 있게 해줘요.

## `SYMBOL:`과 `SYMBOLS:`

`SYMBOL: name`은 변수 하나를 선언해요. `SYMBOLS: a b c ;`는 여러 개를 한 번에 선언해요:

```factor
USING: namespaces ;

SYMBOLS: counter total ;
```

## 설정하기와 가져오기

`set-global`과 `get-global`은 ([`namespaces`][namespaces]에 있어요) 전역 네임스페이스에서 동작해요:

```
set-global    ( value variable -- )
get-global    ( variable -- value )
change-global ( variable quot: ( old -- new ) -- )
```

```factor
0 counter set-global
counter get-global .         ! => 0
counter [ 10 + ] change-global
counter get-global .         ! => 10
```

모듈 수준의 상태를 다룰 때는 `-global`이 붙은 쪽을 쓰면 돼요.

## `with-variable`로 스코프 바인딩하기

동적 변수에는 *스코프*를 쓰는 두 번째 방식도 있어요. `set` / `get` / `change`는 (`-global` 접미사가 없어요) *현재* 동적 스코프를 읽고 써요. 그리고 `with-variable`은 ([`namespaces`][namespaces]에 있어요) 쿼테이션이 실행되는 동안 새로운 스코프를 만들어요:

```
with-variable ( value variable quot -- )
set           ( value variable -- )
get           ( variable -- value )
change        ( variable quot: ( old -- new ) -- )
```

`quot`가 실행되는 동안 변수는 `value`에 바인딩돼요. `quot`가 끝나면 바인딩은 사라져요. 이렇게 하면 바깥에서 호출한 쪽이 값을 "주입"할 수 있고, 안쪽 코드는 모든 스택 시그니처를 거치지 않고도 그 값을 읽을 수 있어요.

```factor
SYMBOL: greeting

"Hello" greeting [
    greeting get .                ! => "Hello"
    "Howdy" greeting set
    greeting get .                ! => "Howdy"
    greeting [ "!" append ] change
    greeting get .                ! => "Howdy!"
] with-variable

greeting get-global .    ! => f   (the scoped binding is gone)
```

이 연습 문제에서는 전역 방식을 사용해요. 그래도 `set`/`get`/`change`가 나란히 짝을 이루는 걸 알아두면 다른 사람의 코드를 읽을 때 도움이 돼요.

## 가변 벡터

동적 변수는 참조를 담고 있으니까, 그 안에 *가변* 컬렉션을 두고 제자리에서 갱신할 수 있어요:

```factor
SYMBOL: history

V{ } clone history set-global
"first event" history get-global push
"second event" history get-global push
history get-global .
! => V{ "first event" "second event" }
```

`V{ … }`는 리터럴 벡터예요. `V{ }` 리터럴은 저장하기 전에 항상 `clone`을 해야 해요. 리터럴은 호출 사이에 공유되거든요.

## `find`: 첫 번째로 일치하는 요소

`find`([`sequences`][sequences]에 있어요)는 조건 함수가 참인 첫 번째 요소와 그 인덱스를 반환해요:

```
find ( seq quot -- index elt/f )
```

아무것도 일치하지 않으면 두 값 모두 `f`예요. `nip`으로 인덱스를 버리고 `unless*`를 쓰는 게 "없을 때 기본값"을 처리하는 표준 조합이에요.

## `reject`: 일치하는 요소 버리기

`reject`(역시 [`sequences`][sequences]에 있어요)는 `filter`의 반대예요. 조건 함수를 통과하지 못하는 요소를 반환해요.
