# 지침

차용증을 추적하는 RESTful API를 구현해요.

룸메이트 네 명은 서로 자주 돈을 빌리는 습관이 있고, 누가 누구에게 얼마나 빚을 졌는지 잘 기억하지 못해요.

이번 과제는 POST 요청으로 차용증을 받고, GET 요청으로 지정된 요약 정보를 제공할 수 있는 간단한 [RESTful API][restful-wikipedia]를 구현하는 거예요.

## API 명세

### 사용자 객체

```json
{
  "name": "Adam",
  "owes": {
    "Bob": 12.0,
    "Chuck": 4.0,
    "Dan": 9.5
  },
  "owed_by": {
    "Bob": 6.5,
    "Dan": 2.75
  },
  "balance": "<(total owed by other users) - (total owed to other users)>"
}
```

### 메서드

| 설명              | HTTP 메서드 | URL    | 페이로드 형식                                                            | 페이로드 없는 응답                   | 페이로드가 있는 응답                                                             |
| ------------------------ | ----------- | ------ | ------------------------------------------------------------------------- | -------------------------------------- | ------------------------------------------------------------------------------- |
| 사용자 정보 목록 | GET         | /users | `{"users":["Adam","Bob"]}`                                                | `{"users":<List of all User objects>}` | `{"users":<List of User objects for <users> (sorted by name)}`                  |
| 사용자 생성              | POST        | /add   | `{"user":<name of new user (unique)>}`                                    | 해당 없음                                    | `<User object for new user>`                                                    |
| 차용증 생성               | POST        | /iou   | `{"lender":<name of lender>,"borrower":<name of borrower>,"amount":5.25}` | 해당 없음                                    | `{"users":<updated User objects for <lender> and <borrower> (sorted by name)>}` |
