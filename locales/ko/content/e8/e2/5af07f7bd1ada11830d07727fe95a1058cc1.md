# 지침

이 연습 문제에서는 프로그래밍 언어 배열을 다루는 함수 몇 개를 구현해야 해요.

## 1. 빈 언어 배열을 반환하는 함수를 정의해요

인자를 받지 않고 빈 배열을 반환하는 `new/0` 함수를 정의해요.

```elixir
LanguageList.new()
# => []
```

## 2. 배열에 언어를 추가하는 함수를 정의해요

인자 2개(*언어 배열*과 *언어*의 문자열 리터럴)를 받는 `add/2` 함수를 정의해요. 주어진 배열의 맨 앞에 새 언어를 추가한 배열을 반환해야 해요.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Clojure")
# => ["Clojure"]
language_list = LanguageList.add(language_list, "Haskell")
# => ["Haskell", "Clojure"]
```

## 3. 배열에서 언어를 제거하는 함수를 정의해요

인자 1개(*언어 배열*)를 받는 `remove/1` 함수를 정의해요. 첫 번째 항목이 없는 배열을 반환해야 해요. 배열에는 항상 항목이 최소한 하나는 있다고 가정해요.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Clojure")
# => ["Clojure"]
language_list = LanguageList.add(language_list, "Haskell")
# => ["Haskell", "Clojure"]
language_list = LanguageList.remove(language_list)
# => ["Clojure"]
```

## 4. 배열의 첫 번째 항목을 반환하는 함수를 정의해요

인자 1개(*언어 배열*)를 받는 `first/1` 함수를 정의해요. 배열의 첫 번째 언어를 반환해야 해요. 배열에는 항상 항목이 최소한 하나는 있다고 가정해요.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elm")
# => ["Elm"]
language_list = LanguageList.add(language_list, "Prolog")
# => ["Prolog", "Elm"]
LanguageList.first(language_list)
# => "Prolog"
```

## 5. 배열에 언어가 몇 개 있는지 반환하는 함수를 정의해요

인자 1개(*언어 배열*)를 받는 `count/1` 함수를 정의해요. 배열에 있는 언어의 개수를 반환해야 해요.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elm")
# => ["Elm"]
language_list = LanguageList.add(language_list, "Prolog")
# => ["Prolog", "Elm"]
LanguageList.count(language_list)
# => 2
```

## 6. 배열에 함수형 언어가 있는지 확인하는 함수를 정의해요

인자 1개(*언어 배열*)를 받는 `functional_list?/1` 함수를 정의해요. 불리언 값을 반환해야 해요. _"Elixir"_가 배열에 있는 언어 중 하나라면 true를 반환해야 해요.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elixir")
# => ["Elixir"]
LanguageList.functional_list?(language_list)
# => true
```
