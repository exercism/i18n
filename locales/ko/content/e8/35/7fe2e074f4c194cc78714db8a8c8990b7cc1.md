# 힌트

## 일반

- [정수(`Int`) 값][numbers]은 하나 이상의 연속된 숫자로 정의할 수 있어요.
- 변수를 사용하면 값에 보기 좋고 읽기 쉬운 이름을 붙일 수 있어요. 코드의 가독성이 코드 줄 수보다 훨씬 중요하다는 점을 기억해요.

## 1. 남은 굽는 시간(분) 계산하기

- 매개변수 하나를 가진 [함수][functions]를 정의해야 해요.
- 매개변수에 [기본값][function-defaults]을 지정해야 해요.
- 메서드에서 정수 값을 명시적으로 반환해야 해요.
- 메서드의 매개변수는 [정수][numbers]예요.
- 값을 빼려면 뺄셈 연산자(`-`)를 사용해야 해요.

## 2. 준비 시간(분) 계산하기

- 매개변수 하나를 가진 [함수][functions]를 정의해야 해요.
- 메서드에서 정수 값을 명시적으로 반환해야 해요.
- 메서드의 매개변수는 [정수][numbers]예요.
- 값을 더하려면 덧셈 연산자(`+`)를 사용해야 해요.

## 3. 경과 시간(분) 계산하기

- 매개변수 두 개를 가진 [함수][functions]를 정의해야 해요.
- 두 번째 매개변수에 [기본값][function-defaults]을 지정해야 해요.
- 메서드에서 정수 값을 명시적으로 반환해야 해요.
- 메서드의 매개변수는 [정수][numbers]예요.
- 값을 더하려면 덧셈 연산자(`+`)를 사용해야 해요.
- 이미 구현된 함수를 호출해야 해요.

[numbers]: https://kotlinlang.org/docs/reference/basic-types.html#numbers
[functions]: https://kotlinlang.org/docs/reference/functions.html#function-declarations
[function-defaults]: https://kotlinlang.org/docs/reference/functions.html#default-arguments
