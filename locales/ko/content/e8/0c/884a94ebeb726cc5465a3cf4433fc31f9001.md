# 소개

## If 조건문

### 논리 연산자

Java는 `&&`(AND), `||`(OR), `!`(NOT) 세 가지 논리 연산자를 지원해요.

### If 문

모든 조건 연산의 바탕이 되는 타입은 `boolean` 타입이고, `true` 또는 `false` 값을 가질 수 있어요. 조건문은 여러 조건을 확인하는 흐름 제어 수단으로 자주 사용돼요. 특정한 경우를 확인하려면 `if` 문을 사용할 수 있는데, 이 문은 조건이 `true`이면 코드를 실행해요. 예를 들면 다음과 같아요.

```java
int val;

if(val == 9) {
    // conditional code
}
```

경우가 하나 이상인 상황에서는 `else if`와 `else` 문을 사용해 여러 `if` 문을 함께 연결할 수 있어요.

```java
if(val == 10) {
    // conditional code
} else if(val == 17) {
    // conditional code
} else {
    // executes when val is different from 10 and 17
}
```

### Switch 문

Java는 선택지가 여러 개인 상황을 위해 `switch` 문도 제공해요.

```java
int val;

// switch statement on variable content
switch(val) {
    case 1:
        // conditional code
        break;
    case 2: case 3: case 4:
        // conditional code
        break;
    default:
        // if all cases fail
        break;
}
```
