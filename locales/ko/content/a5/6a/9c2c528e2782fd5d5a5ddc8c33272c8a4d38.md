# 소개

Factor에서 문자는 정수, 즉 유니코드 코드 포인트예요. 그래서 숫자 비교 연산자 `<`, `>`, `=`만으로도 대소문자를 구분하는 순서를 바로 얻을 수 있어요. [`unicode`][unicode] 보캐뷸러리는 유니코드를 인식하는 술어와 단일 문자 대소문자 변환을 추가해요.

## 문자 술어

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
digit>   ( c -- n )    ! the integer value of a digit char
blank?   ( c -- ? )    ! whitespace
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
CHAR: 7 digit>  .    ! => 7
```

## 대소문자 변환

`ch>upper`과 `ch>lower`는 문자 하나를 뒤집어요. 문자열 수준의 `>upper`과 `>lower`는 이를 문자열의 모든 문자에 적용해요.

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```

`capitalize`는 문자열 전체를 소문자로 만든 다음 첫 문자를 대문자로 바꿔요. 단어 하나에 적용한 타이틀 케이스죠.

```factor
"hELLO" capitalize .   ! => "Hello"
```

## 문자 리터럴

`CHAR: A`는 `A`의 정수 코드 포인트로 파싱돼요. 이름이 있는 문자에는 `space`, `tab`, `\n` 같은 이름을 사용해요.

```factor
CHAR: A .        ! => 65
CHAR: space .    ! => 32
CHAR: \n .       ! => 10
```

## 심볼

어떤 단어가 값 대신 태그를 반환해야 할 때가 있어요. 이를테면 불리언 대신 `yes`/`no`/`maybe`를 반환하는 경우죠. 이럴 때는 각 태그를 *심볼*로 선언해요. 심볼은 호출되면 자기 자신을 푸시하는 단어이고, 두 심볼은 이름이 같을 때만 서로 같다고 비교돼요.

```factor
USING: kernel ;

SYMBOLS: yes no maybe ;

yes .    ! => yes
yes yes = .    ! => t
yes no = .     ! => f
```

심볼 하나를 선언할 때는 `SYMBOL: name`처럼 쓰고, 여러 개를 선언할 때는 `SYMBOLS: a b c ;`처럼 써요.
