# 힌트

## 일반

- 어디서부터 시작할지 고민되나요?
  다음과 같은 것들을 정리해 보면 좋아요:

- 하나의 함수가 모든 일을 처리하고 있어요

- 중복된 로직과 반복되는 작업

- 깊은 중첩

- 알아보기 어려운 이름

- 여기저기 흩어진 형식 규칙

- 설명이 없는 상수

- 불필요한 가변 상태

- 암시적인 enum 폴백

- 서로 관계없는 책임을 맡은 헬퍼 함수

- 오류 대신 빈 문자열을 사용하는 것

- 직접 작성한 날짜 파싱과 형식 지정 (대신 `isodate.Date`를 임포트해서 사용해 봐요)

- 직접 처리하는 유니코드 (대신 `unicode.Grapheme`를 임포트해서 사용해 봐요)

- 눈에 띄는 것부터 골라서 정리해 보고, 테스트가 계속 통과하도록 유지해 봐요!
