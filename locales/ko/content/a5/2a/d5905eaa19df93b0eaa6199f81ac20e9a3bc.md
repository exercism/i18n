# 안내 추가

## 구현

이 연습 문제에서는 순회할 수 있는 연결 리스트 자료 구조를 만들어야 해요.

1. `Count` 속성을 구현해요. 이 속성의 값은 외부에서 바꿀 수 없어야 해요.
2. 리스트의 맨 앞에 값을 추가하는 `Push(T value)` 메서드를 구현해요.
3. 맨 앞에서 값을 제거하고 반환하는 `Pop()` 메서드를 구현해요.
4. 값을 하나만 받거나 반복 가능한 객체를 받아 초기화할 수 있도록 생성자를 추가해요.
5. `IEnumerable<T>` 인터페이스를 구현해요. 더 자세한 내용은 [ienumerable]을 참고해요.
6. `Reverse()` 메서드를 사용할 수 있어야 해요.

[ienumerable]: https://docs.microsoft.com/en-us/dotnet/api/system.collections.generic.ienumerable-1
