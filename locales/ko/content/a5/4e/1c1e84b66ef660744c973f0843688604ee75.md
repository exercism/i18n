# 소개

JavaScript는 객체 지향, 명령형, 선언형(예: 함수형 프로그래밍) 스타일을 지원하는 동적 언어예요.

## (재)할당

JavaScript에서 이름에 값을 할당하는 주된 방법은 몇 가지가 있는데, 변수나 상수를 사용하는 거예요. Exercism에서는 변수를 항상 [camelCase][wiki-camel-case]로 쓰고, 상수는 [SCREAMING_SNAKE_CASE][wiki-snake-case]로 써요. 꼭 따라야 하는 공식 가이드가 있는 것은 아니고, 회사나 조직마다 저마다의 스타일 가이드를 사용해요. _변수는 원하는 방식으로 자유롭게 작성해도 돼요_. 연습 문제에서 준비한 방식대로 변수를 작성하면, 웹 인터페이스와 대부분의 IDE에서 변수가 다르게 강조 표시된다는 장점이 있어요.

JavaScript에서는 [`const`][mdn-const], [`let`][mdn-let], [`var`][mdn-var] 키워드로 변수를 정의할 수 있어요.

`let`이나 `var`를 사용하면, 변수는 존재하는 동안 서로 다른 값을 가리킬 수 있어요. 예를 들어 `myFirstVariable`은 할당 연산자 `=`를 사용해 여러 번 정의하고 다시 정의할 수 있어요:

```javascript
let myFirstVariable = 1;
myFirstVariable = 'Some string';
myFirstVariable = new SomeComplexClass();
```

`let`과 `var`와 달리, `const`로 정의한 변수는 한 번만 할당할 수 있어요. JavaScript에서는 이렇게 상수를 정의해요.

```javascript
const MY_FIRST_CONSTANT = 10;

// Cannot be re-assigned.
MY_FIRST_CONSTANT = 20;
// => TypeError: Assignment to constant variable.
```

> 💡 나중에 나오는 학습 연습 문제에서 _상수_ 할당/바인딩과 _상수_ 값의 차이를 살펴보고 설명해요.

## 함수 선언

JavaScript에서는 기능 단위를 _함수_ 로 묶어요. 보통 서로 관련 있는 함수라면 같은 파일에 모아 둬요. 함수는 매개변수(인자)를 받을 수 있고, `return` 키워드로 값을 _반환_ 할 수 있어요. 함수는 `()` 문법으로 호출해요.

```javascript
function add(num1, num2) {
  return num1 + num2;
}

add(1, 3);
// => 4
```

> 💡 JavaScript에는 함수를 선언하는 _다양한_ 방법이 있어요. 이런 다른 방법들은 `function` 키워드를 사용하는 것과 모양이 달라요. 이 트랙에서는 이런 방법들을 차근차근 소개하려고 해요. 이미 알고 있다면 어떤 방법을 써도 괜찮아요. 대부분의 경우, 어느 한쪽이 더 낫거나 나쁘지는 않아요.

## 다른 파일에 공개하기

`function`, 상수, 변수를 _다른 파일_ 에서 사용할 수 있게 하려면, `export` 키워드로 [내보내기][mdn-export] 해야 해요. 그러면 다른 파일에서 `import` 키워드로 이것들을 [가져올][mdn-import] 수 있어요. 이런 방식을 모듈 시스템이라고도 해요. 좋은 예가 바로 모든 테스트가 동작하는 방식이에요. 각 연습 문제에는 최소한 하나의 파일이 있고, 예를 들어 `lasagna.js`에는 _구현_ 이 들어 있어요. 또한 최소한 하나의 다른 파일이 더 있는데, 예를 들어 `lasagna.spec.js`에는 _테스트_ 가 들어 있어요. 이 파일은 구현을 테스트하기 위해 공개된(즉, 내보낸) 요소를 _가져와요_:

```javascript
// file.js
export const MY_VALUE = 10;

export function add(num1, num2) {
  return num1 + num2;
}

// file.spec.js
import { MY_VALUE, add } from './file';

add(MY_VALUE, 5);
// => 15
```
