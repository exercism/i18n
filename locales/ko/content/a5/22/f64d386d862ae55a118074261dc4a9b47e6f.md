# 테스트

## Exercism GDScript 트랙 테스트 러너 설치

테스트 러너를 사용하려면 [Godot이 제대로 설치되어 있어야 해요][installation].

Exercism용 GDScript 스크립트를 빌드하고 테스트하려면 CLI에서 Godot을 "헤드리스" 모드로 실행해요.
이 설명을 따라가려면 현재 Linux와 bash가 필요해요.

### 1단계: 전체 테스트 러너 인프라 설치

테스트를 준비하려면 [https://github.com/exercism/gdscript-test-runner][gdscript-test-runner] 저장소를 클론한 뒤, 그 내용을 `/opt/test-runner/`로 옮겨요:

```sh
git clone https://github.com/exercism/gdscript-test-runner.git
sudo mkdir -p /opt/
sudo mv gdscript-test-runner/ /opt/test-runner/
```

### 2단계: 연습 문제 하나용 테스트 러너 스크립트 내려받기

`exercism` 도구를 설정해 두었고 GDScript 연습 문제를 하나 이상 내려받았다면, 연습 문제를 보관할 `exercism/gdscript` 폴더가 이미 만들어져 있을 거예요.
이 폴더에 [테스트 러너][test-local-gdscript-solution]를 저장하고 파일에 실행 권한을 주거나, 그냥 링크를 만들어도 돼요:

```sh
cd ~/exercism/gdscript # replace with your exercism/gdscript directory
ln /opt/test-runner/bin/test-local-gdscript-solution.sh
```

## 테스트 실행하기

설치 단계를 마쳤다면, 아무 연습 문제 디렉터리(예: `~/exercism/gdscript/two-fer`)에서 시작해서, (한 단계 위인 `../`에 있는) 스크립트를 실행하면 그 연습 문제에 대한 로컬 풀이를 테스트할 수 있어요:

```sh
../test-local-gdscript-solution.sh
```
