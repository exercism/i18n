# 지시 사항

동네 피자 가게 사장님이 여러 가지 피자의 조리 시간을 계산하는 일을 도와달라고 했어요. 이 연습 문제에서는 이를 계산하는 몇 가지 함수를 작성해 봐요.

세 가지 작업이 있어요.

## 1. 오븐에 남은 시간을 분 단위로 계산하기

피자를 오븐에 몇 분 더 두어야 하는지 세는 `remainingMinutesInOven()` 함수를 정의하고 구현해 봐요.

이 함수는 피자 굽기를 시작한 뒤 지난 시간(분)을 나타내는 **선택적** 매개변수 하나를 받아요(기본값이 있어요). 이 매개변수를 생략하면 피자를 방금 오븐에 넣었고 아직 **0(영)** 분이 지났다고 가정해요.

간단하게 하기 위해 모든 종류의 피자는 오븐에서 정확히 40분이 지나야 완성된다고 가정해요.

```kotlin
remainingMinutesInOven()   // => 40

remainingMinutesInOven(10)   // => 30
```

## 2. 준비 시간을 분 단위로 계산하기

피자를 굽기 전에 반죽을 만들고 밀어 펴고 토핑을 올려야 해요.

오븐에 넣기 전에 피자를 준비하는 데 몇 분이 걸리는지 세는 `preparationTimeInMinutes()` 함수를 정의하고 구현해 봐요.

이 함수는 사용할 토핑 재료 종류의 개수를 나타내는 **필수** 매개변수(`numberOfIngredientTypes`) 하나를 받아요.

반죽을 만들고 미는 데 5분이 걸리고, 토핑 **종류마다** 2분이 걸린다고 가정해요.

```kotlin
preparationTimeInMinutes(0) // => 5

preparationTimeInMinutes(1) // => 7
```

## 3. 경과한 시간을 분 단위로 계산하기

피자를 준비하고 굽고 서빙하는 데 몇 분이 걸리는지 세는 `elapsedCookingTimeInMinutes()` 함수를 정의하고 구현해 봐요. 계산할 때 이전 단계의 함수들을 사용해요.

이 함수는 매개변수 두 개를 받아요. 첫 번째는 **필수**이고 토핑 재료 종류의 개수예요. 두 번째는 **선택적**이고 서빙 시간(분)이에요(제공하지 않으면 0이라고 가정해요).

```kotlin
elapsedCookingTimeInMinutes(1)  // => 47

elapsedCookingTimeInMinutes(2, 3)  // => 52
```
