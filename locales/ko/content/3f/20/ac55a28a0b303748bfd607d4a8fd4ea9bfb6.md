# 소개

## 익명 함수

Elixir에서 함수는 일급 시민으로 취급돼요. 즉,

- 이름 있는 함수와 익명 함수를 변수에 할당할 수 있어요.
- 이름 있는 함수와 익명 함수를 데이터처럼 인자와 반환값으로 주고받을 수 있어요.
- 익명 함수를 동적으로 만들 수 있어요.

익명 함수는 이름 있는 함수와 달리 정적으로 참조할 수 있는 대상이 없어요. 변수에 할당하거나 즉시 호출할 때만 사용할 수 있죠.

익명 함수는 다음과 같은 경우에 사용할 수 있어요.

- 렉시컬 스코프(클로저라고도 해요)를 이용해 데이터를 숨길 때
- 실행 중에 함수를 동적으로 만들 때

익명 함수는 예약어 `fn`으로 시작하고, 인자는 `->` 토큰으로 함수 본문과 구분하며, `end`로 끝나요. 이름 있는 함수와 마찬가지로 함수의 마지막 표현식은 호출한 함수에 _암묵적으로 반환_돼요.

함수 참조를 호출하려면 참조 변수와 인자 목록 사이에 `.`을 써야 해요.

```elixir
function_variable = fn param ->
  param + 1
end

function_variable.(1)
# => 2
```

짧은 축약 표기법을 사용하면 이걸 더 간결하게 만들 수도 있어요.

```elixir
variable = &(&1 + 1)

variable.(1)
# => 2
```

## 비트 조작

Elixir는 _Bitwise 모듈_에 있는 비트를 다루는 여러 함수를 지원해요.

- `band/2`: 비트 AND
- `bsl/2`: 비트 왼쪽 시프트
- `bsr/2`: 비트 오른쪽 시프트
- `bxor/2`: 비트 XOR
- `bor/2`: 비트 OR
- `bnot/1`: 비트 NOT

다음은 비트 연산 함수를 사용하는 예예요.

```elixir
Bitwise.bsl(1, 3)
# => 8
```

모든 비트 연산 함수는 정수에서만 동작해요.

Elixir 1.9 이하 버전을 사용한다면, _Bitwise_ 모듈을 사용하기 위해 모듈 정의 시작 부분에서 `require Bitwise`를 호출해야 해요.
