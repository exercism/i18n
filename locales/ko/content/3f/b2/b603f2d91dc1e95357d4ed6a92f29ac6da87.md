# 안내 추가

## 힌트

이 연습 문제를 완료하려면 *text*를 받아 지정한 크기의 숫자 부분 수열을 반환하는
`slices` 함수를 구현해야 해요:

이 연습 문제를 처음 푼다면, 제시된 시그니처를 그대로 따르는 걸 추천해요:

```haskell
slices :: Int -> String -> [[Int]]
```

나중에 이 문제를 다시 풀어 보면서 다른 데이터 타입과 라이브러리를 가지고 놀아 보는
것도 좋아요:

- *bytestring* 패키지의 `ByteString`
- *containers* 패키지의 `Sequence`
- *text* 패키지의 `Text`
- *vector* 패키지의 `Vector`

테스트 스위트는 의미가 통하는 거의 모든 타입 시그니처를 허용하도록 의도적으로
설계되었으니, 가장 좋다고 생각하는 시그니처를 찾아보세요.
