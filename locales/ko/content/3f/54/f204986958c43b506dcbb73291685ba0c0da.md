# 소개

## 매개변수

이 연습 문제에서는 C#에서 메서드 매개변수의 세부 사항과 그 사용법에 대해 다뤄요.

매개변수는 호출하는 메서드에서 호출되는 메서드로 정보를 전달해요.

- 매개변수의 동작은 `ref`와 `out` 같은 한정자를 사용하여 수정할 수 있어요.

- `out` 한정자가 있는 매개변수는 호출된 메서드에서 호출자로 값을 다시 전달해요. 이 매개변수는 초기화하지 않고 호출된 메서드에 전달할 수 있으며, 어떤 경우든 호출된 메서드 내에서는 진입 시점에 초기화되지 않은 것처럼 취급돼요. 매개변수 한정자에 관한 동작과 규칙은 예제(아래 참조)와 컴파일러 메시지를 통해 가장 쉽게 이해할 수 있어요.

```csharp
void Foo(out int val)
{
    val = 42;
}
void Bar(int val)
{
    val = 42;
}

int importantValue = 1729;
Foo(out importantValue);
var result = importantValue == 42;
// => true

importantValue = 1729;
Bar(importantValue);
result = importantValue == 1729;
// => true
```

- `out` 매개변수는 호출된 메서드 안에서 반드시 할당해야 해요.

- `ref` 한정자가 있는 매개변수는 호출된 메서드로 값을 전달해요. 메서드가 반환되면 호출자는 호출된 메서드가 해당 매개변수에 수행한 모든 업데이트를 확인할 수 있어요.

```csharp
void Foo(ref int val)
{
    val *= 7;
}

int importantValue = 6;
Foo(ref importantValue);
return importantValue;
// => 42
```

- `ref` 매개변수는 변수여야 해요. 호출된 메서드가 호출자가 보는 그대로의 매개변수를 직접 다루기 때문이에요.
- `out`과 `ref` 한정자는 호출된 메서드 시그니처와 호출 지점 모두에서 필요해요.
