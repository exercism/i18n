# 소개

## 숫자

Ruby에서 가장 흔한 숫자 유형 두 가지는 다음과 같아요:

- **정수:** 소수점 뒤에 숫자가 없는 수예요. 예로 `-6`, `0`, `1`, `25`, `976`, `500000` 등이 있어요.
- **실수:** 소수점 뒤에 숫자가 하나 이상 있는 수예요. 예로 `-2.4`, `0.1`, `3.14`, `16.984025`, `1024.0` 등이 있어요.

정수와 실수는 각각 `Integer`와 `Float` 클래스로 구현돼요.

이 클래스들에는 값을 서로 변환해 주는 메서드가 있어요. `Integer`는 정수 단위까지 정확한 반면, `Float`는 소수 단위까지 정밀하게 표현할 수 있어요:
- `Integer#to_f`: 새 실수로 변환해요
- `Float#ceil`: 가장 가까운 정수로 올림해요
- `Float#floor`: 가장 가까운 정수로 내림해요
- `Float#round`: 가장 가까운 정수로 반올림해요
- `Float#to_i`: 가장 가까운 정수로 버림해요

## 조건문

Ruby에는 흐름 제어 표현식이라는 것이 있는데, 프로그램이 실행되는 방식을 제어하는 데 사용되며 truthy 또는 falsey 값을 가져요.
truthy 또는 falsey 값을 만들어 내는 데 사용할 수 있는 연산자도 있는데, 이를 [비교 연산자][comparison-operators]라고 해요.

어떤 코드가 실행되고 어떤 코드가 실행되지 않을지, 즉 어느 분기가 실행될지를 제어하는 주요 제어 표현식이 두 가지 있어요.

그 두 가지는 `if`와 `unless` 표현식이에요.

## 비교 연산자

[비교 연산자][comparison-operators]는 값을 비교하고 `true` 또는 `false` 값을 반환하는 데 사용돼요.
다음 연산자들은 같은 타입의 두 값을 비교해야 해요.
값의 타입이 다르면 컴파일러가 오류를 발생시켜요.
다음은 연산자 목록과, 이들이 `true` 값을 내놓는 예시예요:

| 메서드 | 설명                  | 예시    |
| ------ | --------------------- | ------- |
| <      | 보다 작음             | 4 < 5   |
| <=     | 작거나 같음           | 4 <= 4  |
| >      | 보다 큼               | 3 > 1   |
| >=     | 크거나 같음           | 2 >= 2  |

같음과 같지 않음 연산자는 앞서 언급한 연산자들과 달리 어떤 타입의 값이든 비교하는 데 사용할 수 있어요.
`==` 연산자는 두 값이 같은지 확인하는 데 사용되며, 값의 타입까지 확인해요.
`!=`도 같은 방식으로 동작하지만, 값이 같지 않으면 `true`를, 같으면 `false`를 반환해요.
다음은 같음과 같지 않음 연산자 목록과, 이들이 `true` 값을 내놓는 예시예요:

| 메서드 | 설명         | 예시    |
| ------ | ------------ | ------- |
| ==     | 같음         | 4 == 4  |
| !=     | 같지 않음    | 5 != 4  |

## `if`문

[`if`][if]문은 주어진 조건이 "truthy"인지 "falsey"인지 확인하는 데 사용돼요.
조건이 truthy이면 `if`문 안의 코드가 실행돼요.
`if`문은 `end` 키워드로 끝나요.

```ruby
value = 1
if value == 1
  "1 is equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
end
# => nil
```

## `unless`문

`unless`문은 `if`문과 아주 비슷하게 동작하지만, 조건이 falsey일 때 `unless`문 안의 코드를 실행해요.

```ruby
value = 1
unless value == 1
  "1 is not equal to 1"
end
# => nil

unless value > 2
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## `else`문

`else`문은 `if`문과 함께 사용할 수 있어요.
`else`문은 `if` 분기가 실행되지 않았을 때 실행돼요.

```ruby
value = 1
if value == 1
  "1 is equal to 1"
else
  "1 is not equal to 1"
end
# => "1 is equal to 1"
```

## "연쇄 `if`"문

`elsif`문은 `if`문과 함께 사용할 수 있어요.
`elsif`문은 `if` 분기가 실행되지 않았고 `elsif`문의 조건이 truthy일 때 실행돼요.
`elsif`문은 여러 개를 이어 붙일 수 있고, 처음으로 truthy인 조건이 실행돼요.
`if`문 끝에 `else`문을 둘 수도 있는데, 앞선 문들이 모두 참이 아니었을 때 실행돼요.

```ruby
value = 1
if value != 1
  "1 is not equal to 1"
elsif value > 2
  "1 is greater than 2"
else
  "1 is not equal to 1 and 1 is not greater than 2"
end
# => "1 is not equal to 1 and 1 is not greater than 2"
```
