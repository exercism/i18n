# 소개

Elixir는 동적 타입 언어예요. 즉, 컴파일 시점에 타입 검사를 제공하지 않아요. 그래도 타입 명세는 문서화의 한 형태로 사용할 수 있어요.

`@spec` 모듈 속성을 사용하면 함수 정의 바로 앞에 타입 명세를 추가할 수 있어요. `@spec` 뒤에는 함수 이름과 모든 인자의 타입 목록이 괄호 안에 쉼표로 구분되어 나열돼요. 반환값의 타입은 함수의 인자와 이중 콜론 `::`으로 구분해요.

```elixir
@spec longer_than?(String.t(), non_neg_integer()) :: boolean()
def longer_than?(string, length), do: String.length(string) > length
```

## 타입

가장 일반적으로 사용되는 타입은 다음과 같아요:

- 불리언: `boolean()`
- 문자열: `String.t()`
- 숫자: `integer()`, `non_neg_integer()`, `pos_integer()`, `float()`
- 배열: `list()`
- 모든 타입의 값: `any()`

일부 타입은 매개변수화할 수도 있어요. 예를 들어 `list(integer)`는 정수의 배열이에요.

리터럴 값도 타입으로 사용할 수 있어요.

타입의 합집합은 파이프 `|`를 사용하여 작성할 수 있어요. 예를 들어, `integer() | :error`는 정수 또는 아톰 리터럴 `:error`를 의미해요.

모든 타입의 전체 목록은 [공식 문서의 "Typespecs" 섹션][types]에서 찾을 수 있어요.

## 인자 이름 지정

타입 명세에서 인자에 이름을 붙일 수도 있는데, 이는 같은 타입의 여러 인자를 구별하는 데 유용해요. 인자 이름 뒤에 이중 콜론을 붙여서 인자의 타입 앞에 놓아요.

```elixir
@spec to_hex({hue :: integer, saturation :: integer, lightness :: integer}) :: String.t()
```

## 사용자 정의 타입

타입 명세는 내장 타입에만 국한되지 않아요. `@type` 모듈 속성을 사용하여 사용자 정의 타입을 정의할 수 있어요. 사용자 정의 타입 정의는 타입의 이름으로 시작해서 그 뒤에 이중 콜론을 쓰고 타입 자체를 적어요.

```elixir
@type color :: {hue :: integer, saturation :: integer, lightness :: integer}

@spec to_hex(color()) :: String.t()
```

사용자 정의 타입은 정의된 동일한 모듈에서 사용할 수 있고, 다른 모듈에서도 사용할 수 있어요.

[types]: https://hexdocs.pm/elixir/typespecs.html#types-and-their-syntax
