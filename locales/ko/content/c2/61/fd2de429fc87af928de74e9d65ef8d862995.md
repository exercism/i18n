# 테스트

[테스트 주도 개발의 세 가지 규칙][3-tdd-rules]을 따라 첫 번째 테스트가 컴파일되고 링크되고 통과하도록 만들어 봐요.

포함된 makefile을 사용하면 `test` 태스크로 테스트를 만들고 실행할 수 있어요.

```console
$ make test
```

컴파일러 오류를 해결하고 테스트가 실패하게 만들기 위해 필요한 함수만 만들어요.
그다음 테스트가 통과할 만큼만 코드를 작성해요.
이걸 마치면 다음 테스트로 넘어가요.

테스트를 진행해 나가면서, 가독성과 표현력을 위해 구현을 리팩터링할 시간을 갖고, 그런 다음 다음 테스트로 넘어가요.

직접 저수준 알고리즘이나 기능을 손으로 작성하기보다는 표준 C99 기능을 사용해 봐요.

## 메모리 누수 확인하기

makefile에는 메모리 누수와 배열 범위를 벗어난 접근에 관한 몇 가지 흔한 실수를 확인하는 빌드도 들어 있어요.
이 검사를 실행하려면 명령줄에서 다음을 사용해요:

```console
$ make memcheck
```
