# 트랙

트랙은 Exercism의 언어 "강의"예요.

각 트랙은 서로 다른 (때로는 겹치기도 하는) 자원봉사자 그룹이 관리해요.

트랙은 [개념 연습 문제](/docs/building/product/concept-exercises)와 [연습 문제](/docs/building/product/practice-exercises)로 이루어져 있어요.

각 트랙에는 [테스트 러너](/docs/building/product/test-runners), [리프리젠터](/docs/building/product/representers), [애널라이저](/docs/building/product/analyzers) 같은 언어별 도구가 있어요.
