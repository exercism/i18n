# 소개

Kotlin의 [`string`][ref-string]은 유니코드 문자로 이루어진 시퀀스예요.

[`Immutable`][wiki-immutable]은 문자열에 어떤 연산을 하더라도 새로운 문자열을 반환해야 한다는 뜻이에요. 원래 문자열은 절대 바뀌지 않아요.

[`Unicode`][wiki-unicode] 덕분에 세상 대부분의 문자 체계를 표현할 수 있어요. 다만 C 같은 예전 언어와 달리 문자와 바이트가 1:1로 대응하지는 않아요.

문자열은 보통 큰따옴표 `" "`로 감싸요.

일부 문자는 이스케이프가 필요해요: `\'`, `\\`, 그리고 `\t`(탭)나 `\n`(줄 바꿈) 같은 흔한 비인쇄 문자도 마찬가지예요.

```kotlin
val s = "Escape apostrophe \' and backslash \\."
// Escape apostrophe ' and backslash \.
```

여러 줄 문자열은 큰따옴표 세 개로 감싸고, 아무 텍스트나 담을 수 있어요(이스케이프할 필요가 없어요).

```kotlin
val multi = """I'm a
    multi-line
    string with special characters \ \t """
//I'm a
//    multi-line
//    string with special characters  \ \t 
```

[trimIndent][trimIndent-doc]를 사용하면 각 줄에 공통으로 들어간 들여쓰기를 없앨 수 있어요.
문자열 형식을 다듬을 때 유용해요:

```kotlin
val multi = """
    I'm a
      multi-line
    string""".trimIndent()

//I'm a
//  multi-line
//string
```

또는 [trimMargin][trimMargin-doc]으로 구분 기호를 직접 정할 수 있어요.
그러면 `String`의 각 줄이 구분 기호 다음부터 시작해요.
구분 기호의 기본값은 `|`이고, 매개변수로 다른 구분 기호를 지정할 수도 있어요.
예를 들면 다음과 같아요:

```kotlin
val multi = """
    |I'm a
    |  multi-line
    |string""".trimMargin()

//I'm a
//  multi-line
//string

val multi2 = """
    start>I'm a
    start>  multi-line
    start>string""".trimMargin("start>")

//I'm a
//  multi-line
//string
```

문자열은 `+`로 이어 붙일 수 있지만, 짧고 단순한 경우에만 쓰는 게 좋아요.
다른 방법도 있고, 대개 그쪽이 더 좋아요.

## 문자열 템플릿

다른 언어에서 보간이라고 부르는 기능이에요.

문자열에 `$` 기호 뒤에 식별자가 오거나, 식을 감싼 중괄호(`{expression}`)가 있으면 각각 그 값이나 식의 결과로 치환돼요.

```kotlin
val x = 42
val st = "x is $x, x squared is {x * x}"
// x is 42, x squared is 1764
```

중괄호 `{ }`는 그대로 두면 해석이 모호해질 때 식을 감싸는 데 필요해요.

일반적으로 문자열 템플릿은 `+`를 쓰는 것보다 문자열을 결합하는 더 효율적이고 관용적인 방법이에요.

## 문자열 함수

Kotlin은 문자열을 다루는 [`functions`][ref-string-functions]를 _아주 많이_ 제공해요.

대부분 `String` 클래스의 멤버가 아니라 [`extensions functions`][ref-extensions]이지만, 사용하는 방법에는 거의 영향이 없어요.

~~~~exercism/note
Kotlin의 다소 복잡한 [문서][ref-string-functions] 페이지는 기본 화면에서 확장 함수를 숨겨 두었어요.
`Members & Extensions`를 클릭해 이 섹션을 펼쳐 보세요.

[ref-string-functions]: https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/
~~~~

다음 예제는 사용할 수 있는 기능 중 아주 일부만 보여줘요:

```kotlin
val str = "Hello World!"

str.length              // => 12 (a property, not a function)
str.elementAt(6)        // => W
str.elementAtOrNull(20) // => null (index out of range)
str.substring(6, 11)    // => "World"
str.substringAfter(" ") // => "World!"

str.lowercase()         // => "hello world!"
str.uppercase()         // => "HELLO WORLD!"

str.startsWith("Hel")   // => true
str.endsWith("xyz")     // => false
str.indexOf("0")        // => 4

str.toCharArray()       // => [H, e, l, l, o,  , W, o, r, l, d, !]
"42".toInt() + 1        // => 43  (parsing; see also toFloat)

"Howdy!  ".trim()       // => "Howdy"
```
