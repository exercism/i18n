# 힌트

## 1. 무작위 행성 생성하기

- 입력 벡터에서 표본을 추출하는 것과 비슷해요.
- 중복이 나올 수 있으니 복원 추출로 뽑아요.

## 2. 무작위 우주선 등록 번호 생성하기

- 숫자 부분은 범위에서 표본을 뽑는 거예요.
- 문자열을 만드는 방법은 여러 가지가 있어요. [`sprintf()`][ref-sprintf]나 [`str_glue()`][ref-str_glue]를 쓰는 방법도 있고요.

## 3. 우주선 함대 무작위로 섞기

- 소개에서 섞기에 대해 다뤄요.

## 4. 무작위 스타데이트 생성하기

- 하한과 상한 사이에서 [균등 분포][ref-runif]를 따르는 실숫값이 필요해요.
- 경곗값을 포함하는지 여부 같은 미묘한 차이는 이 문제에서는 무시해도 돼요.
