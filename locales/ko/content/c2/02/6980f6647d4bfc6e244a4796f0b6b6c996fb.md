# 설치

표준 ML 구현체로 *PolyML*을 사용할 거예요.

Windows를 사용하고 있다면 [https://github.com/polyml/polyml/releases](https://github.com/polyml/polyml/releases)에서 설치 프로그램을 내려받을 수 있어요.
Linux/OS X/Free BSD에 대한 일반적인 안내는 [https://github.com/polyml/polyml#readme](https://github.com/polyml/polyml#readme)에서 확인할 수 있어요.

소스에서 직접 설치하고 싶다면 과정은 아주 간단해요:

```sh
$ git clone https://github.com/polyml/polyml.git
$ cd polyml
$ ./configure
```

`$HOME/.local`처럼 원하는 위치에 설치하고 싶다면:

```sh
$ ./configure --prefix=$HOME/.local
```

마지막 단계예요:

```sh
$ make compiler
$ make install
```

제대로 설치되었는지 확인해 봐요:

```sh
$ poly
```

인터프리터가 보이면 준비 완료예요!
그렇지 않다면 `$HOME/.local/bin`(또는 `<you prefix>/bin`)을 `$PATH`에 추가해야 할 거예요.
