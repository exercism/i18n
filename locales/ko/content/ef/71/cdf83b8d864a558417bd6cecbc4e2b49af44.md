# 디버그

현재 테스트 러너는 [PonyTest](https://stdlib.ponylang.io/pony_test--index/)를 사용하기 때문에, Main 액터는 test.pony에 있고 풀이의 일부로 수정해서는 안 돼요.

Pony 애플리케이션의 모범 사례에 따라, 필요하지 않으면 `Env`에 대한 접근을 제공하지 않아요. 그래서 거의 모든 경우에 `env.out.print()`를 사용한 printf 스타일 디버깅은 할 수 없어요.

하지만 Pony에는 [debug](https://stdlib.ponylang.io/debug--index/) 모듈이 있어서, `-d` 플래그로 컴파일한 프로그램은 `Env`에 접근하지 않고도 STDOUT과 STDERR에 특별히 접근할 수 있어요.

printf 스타일 디버깅이 필요하면 이 기능을 사용하면 돼요.

디버그 예시:

```pony
use "debug"

actor Main
  new create(env: Env) =>
    MySolution.examplefn("First String", 42)

primitive MySolution
  fun examplefn(arg1: String, arg2: USize) =>
    Debug.out("arg1: " + arg1 + ", arg2: " + arg2.string() + " were provided to MySolution.examplefn()")
```


같은 코드를 `-d` 플래그를 붙여 컴파일했을 때와 붙이지 않았을 때의 결과예요:
