# 힌트

## 일반

- 문자 [코드 포인트][codepoint]를 다룰 때는 `?`를 사용해요.
- `\s`로 공백을 나타낼 수 있어요.
- 코드를 다룰 때는 [2진 정수 리터럴][integer-literal] 축약 표기법을 사용해요.
- 꼬리 호출 재귀 전략을 사용해 봐요.

## 1. 핵산을 2진 값으로 인코딩하기

- 이 함수는 하나의 정수를 다른 정수로 매핑해야 해요.
- 이 함수에는 재귀가 필요하지 않아요.
- 함수 절을 여러 개 사용하면 문제를 나눠서 더 쉽게 해결할 수 있어요.

## 2. 2진 값을 핵산으로 디코딩하기

- 이 함수는 1번 함수와 반대되는 함수예요.
- 이 함수에는 재귀가 필요하지 않아요.
- 함수 절을 여러 개 사용하면 문제를 나눠서 더 쉽게 해결할 수 있어요.

## 3. DNA charlist 인코딩하기

- charlist에서 코드 포인트를 하나 가져와 비트스트링 결과를 재귀적으로 만들어 내는 꼬리 재귀 함수를 작성해요.
- 꼬리 재귀 함수에는 누산기가 필요해요.
- [charlist][charlist]는 [정수 코드 포인트][codepoint]의 배열이라는 점을 기억해요.
- 내장 [`Kernel` 모듈][kernel] 함수를 사용하면 배열에서 첫 번째 항목과 나머지 항목을 가져올 수 있어요.
- [`[head | tail]`][list] 표기법으로 배열을 패턴 매칭할 수도 있어요.
- 함수 절을 여러 개 사용해서 기본 사례와 재귀 사례를 구분해요.
- `::` 연산자로 비트스트링 세그먼트의 타입을 지정하는 것을 잊지 마세요.

## 4. DNA 비트스트링 디코딩하기

- [bitstring][bitstring]에서 [처음 4비트를 매칭][bitstring-matching]하고 [charlist][charlist] 결과를 재귀적으로 만들어 내는 꼬리 재귀 함수를 작성해요.
- 꼬리 재귀 함수에는 누산기가 필요해요.
- [bitstring 특수 폼][bitstring-form]을 사용하면 비트스트링을 매칭할 수 있다는 점을 기억해요.
- `::` 연산자로 비트스트링 세그먼트의 타입을 지정하는 것을 잊지 마세요.
- 마지막에는 누산기를 뒤집어야 해요. 이를 위해 프라이빗 꼬리 재귀 `reverse` 함수를 작성하고, `decode` 함수의 기본 사례에서 사용해요.
