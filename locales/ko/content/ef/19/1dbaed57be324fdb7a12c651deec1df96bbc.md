# 소개

## 정규 표현식

정규 표현식(regex)은 Elixir에서 문자열을 다룰 때 강력한 도구예요. Elixir의 정규 표현식은 **PCRE** 명세(**P**erl **C**ompatible **R**egular **E**xpressions)를 따라요. 정규 표현식의 의미를 나타내는 문자열 패턴은 먼저 컴파일된 다음, 문자열 전체 또는 일부를 일치시키는 데 사용돼요.

Elixir에서 정규 표현식을 만드는 가장 흔한 방법은 `~r` 시길을 사용하는 거예요. 시길은 Elixir에서 자주 하는 작업을 위한 _문법적 설탕_ 지름길을 제공해요. _문자열 리터럴_을 일치시키려면, 시길 뒤에 문자열 자체를 패턴으로 사용하면 돼요.

```elixir
~r/test/
```

`=~/2` 연산자는 문자열에 정규 표현식 일치를 수행해서 `boolean` 결과를 반환할 때 유용해요.

```elixir
"this is a test" =~ ~r/test/
# => true
```

시길을 사용할 때 알아 둘 점 두 가지가 있어요:

- 필요에 따라 `/` 대신 여러 가지 구분 기호를 사용할 수 있어요
- 문자열 패턴은 이미 _이스케이프_되어 있어요. 정규 표현식을 사용하지 않고 패턴을 문자열로 작성할 때는 백슬래시(`\`)를 _이스케이프_해야 해요

### 문자 클래스

대괄호 `[]`로 문자 범위를 일치시키면 _문자 클래스_가 정의돼요. 이것은 클래스 안의 문자 중 어느 한 문자와 일치해요. `a-z`처럼 문자 범위를 지정할 수도 있는데, 시작과 끝이 연속된 코드 포인트 범위를 나타내야 해요.

```elixir
regex = ~r/[a-z][ADKZ][0-9][!?]/
"jZ5!" =~ regex
# => true
"jB5?" =~ regex
# => false
```

_축약 문자 클래스_는 패턴을 더 간결하게 만들어요. 예를 들어:

- `\d`는 `[0-9]`의 축약형이에요 (모든 숫자)
- `\w`는 `[A-Za-z0-9_]`의 축약형이에요 (모든 '단어' 문자)
- `\s`는 `[ \t\r\n\f]`의 축약형이에요 (모든 공백 문자)

_축약 문자 클래스_를 시길 밖에서 사용할 때는 이스케이프해야 해요: `"\\d"`

### 대안

_대안_은 하나 _또는_ 다른 하나를 일치시킨다는 것을 나타내는 특수 문자로 `|`를 사용해요

```elixir
regex = ~r/cat|bat/
"bat" =~ regex
# => true
"cat" =~ regex
# => true
```

### 수량자

_수량자_는 정규 표현식에서 패턴을 반복할 수 있게 해줘요. 수량자는 바로 앞의 그룹에 영향을 줘요.

- `{N, M}`에서 `N`은 최소 반복 횟수이고, `M`은 최대예요
- `{N,}`은 `N`번 이상 반복을 일치시켜요
  - `{0,}`은 `*`로도 쓸 수 있어요: 0번 이상 반복을 일치시켜요
  - `{1,}`은 `+`로도 쓸 수 있어요: 1번 이상 반복을 일치시켜요
- `{,N}`은 최대 `N`번 반복을 일치시켜요

### 그룹

둥근 괄호 `()`는 _그룹_과 _캡처_를 나타내는 데 사용해요. 경우에 따라 그룹이 사용할 수 있도록 반환되기 위해 _캡처_될 수도 있어요. Elixir에서는 이름을 붙일 수도 있고 붙이지 않을 수도 있어요. 캡처는 여는 괄호 뒤에 `?<name>`을 붙여서 이름을 지정해요. 그룹은 _수량자_가 뒤따를 때처럼 하나의 단위로 동작해요.

```elixir
regex = ~r/(h)at/
Regex.replace(regex, "hat", "\\1op")
# => "hop"

regex = ~r/(?<letter_b>b)/
Regex.scan(regex, "blueberry", capture: :all_names)
# => [["b"], ["b"]]
```

### 앵커

_앵커_는 정규 표현식을 일치시킬 문자열의 시작이나 끝에 고정하는 데 사용해요:

- `^`는 문자열의 시작에 고정해요
- `$`는 문자열의 끝에 고정해요

### 보간

`~r`은 `"pattern" |> Regex.escape() |> Regex.compile!()`의 지름길이기 때문에, 문자열 보간을 사용해서 정규 표현식 패턴을 동적으로 만들 수도 있어요:

```elixir
anchor = "$"
regex = ~r/end of the line#{anchor}/
"end of the line?" =~ regex
# => false
"end of the line" =~ regex
# => true
```
