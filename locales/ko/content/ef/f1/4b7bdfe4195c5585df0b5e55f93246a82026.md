# 자세히 알아보기

Common Lisp에서는 모든 것이 표현식이에요.
표현식은 하나의 대상(원자라고 해요)이거나, 괄호 `()`로 구분된 여러 대상의 배열이에요.

## 인용

모든 S-표현식은 심볼처럼 인용할 수 있어요:

```lisp
;; This line is evaluated as code
(gimme-foo)  ; => FOO

;; This line is treated as data
'(gimme-foo) ; => (GIMME-FOO)
```

이렇게 인용하면 S-표현식이 평가되는 것을 막고, 대신 데이터로 취급해요.
인용에 대해 조금 더 자세히 다룬 훌륭한 [Stack Overflow 답변][so-quoting]이 있어요.
