## 쌍

`Pair`는 정확히 두 개의 원소를 담고 있고, `first`와 `second` 필드로 접근할 수 있는 자료 구조예요.

`x => y`로 만들 수 있어요:

```julia-repl
julia> p = 3 => true
3 => true

julia> p.first
3

julia> p.second
true
```

`Pair`의 두 원소는 서로 다른 타입일 수도 있어요:

```julia-repl
julia> typeof(p)
Pair{Int64,Bool}
```

`Pair`는 Julia에서 주로 두 가지 용도로 쓰여요: 딕셔너리와 치환이에요.

### 치환

치환 메서드 중에는 어떤 원소를 치환하는지 분명히 하기 위해 `Pair`를 인자로 받는 것이 많아요.
그래서 다음과 같은 문법을 쓸 수 있어요.

```julia-repl
julia> replace!([1, 3, 4, 1], 4 => 0)
4-element Array{Int64,1}:
 1
 3
 0
 1
```

이 코드에서는 컬렉션의 각 `4`가 `0`으로 치환돼요. 이렇게 하면 덜 명확한 문법을 쓰지 않아도 돼요.

```julia
replace!([1, 3, 4, 1], 4, 0) # this method doesn't exist
```
