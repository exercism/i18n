# 알아보기

`|>` 연산자는 파이프 연산자라고 해요. 이 연산자를 사용하면 함수 호출을 서로 연결할 수 있어요. 앞선 함수 호출이 반환한 값이 다음 함수 호출로 전달되는 식이에요.

```gleam
"hello"
|> string.uppercase
|> string.append("?!")
// -> "HELLO?!"
```

위 코드는 다음 코드와 같아요:

```gleam
string.append(string.uppercase("hello"), "?!")
```

파이프 연산자는 값을 함수 호출의 첫 번째 인자로 전달하거나, 새로운 호출의 유일한 인자로 전달해요. 둘 중 타입이 올바르게 맞는 쪽을 골라요.

```gleam
100
|> function_that_takes_two_arguments(1)

// Is equivalent to
function_that_takes_two_arguments(100, 1)
```

```gleam
100
|> function_that_returns_a_function(1)

// Is equivalent to
function_that_returns_a_function(1)(100)
```

가끔은 값을 다른 위치에 전달하고 싶을 때가 있어요. 이럴 때는 `_` 플레이스홀더를 사용해서 값이 어디에 들어가야 하는지 나타낼 수 있어요.

```gleam
100
|> some_function(1, _, 2)
```
