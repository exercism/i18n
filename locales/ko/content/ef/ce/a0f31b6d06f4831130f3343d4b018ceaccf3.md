# 불리언

Crystal에는 [`Bool`][bools]이라는 타입이 있어요.
이 타입은 `true`와 `false` 값을 나타내요.

## 논리 연산자

Crystal에는 세 가지 논리 연산자(`!`, `||`, `&&`)가 있어요. 이 연산자들은 불리언을 조합해서 서로 다른 값을 만들어 내는 표현식을 만들어요.

### And(`&&`)

Crystal에서 [_and_ 연산자][and]는 `&&`로 나타내고, 두 값이 모두 `true`이면 `true`를 반환하며 그렇지 않으면 `false`를 반환해요.
_and_ 연산자를 사용할 때는 불리언 하나를 `&&`의 오른쪽에, 다른 하나를 왼쪽에 놓아요.

```crystal
true && true
# => true

true && false
# => false
```

### Or(`||`)

Crystal에서 [_or_ 연산자][or]는 `||`로 나타내고, 주어진 값 중 **적어도 하나**가 `true`이면 `true`를 반환해요. 
두 값이 모두 `false`이면 `false`를 반환해요.
_or_ 연산자를 사용할 때는 불리언 하나를 `||`의 오른쪽에, 다른 하나를 왼쪽에 놓아요.

```crystal
true || true
# => true

true || false
# => true

false || false
# => false
```

### Not(`!`)

Crystal에서 _not_ 연산자는 `!`로 나타내고, 주어진 불리언이 `false`이면 `true`를 반환하며 `true`가 주어지면 `false`를 반환해요.
_not_ 연산자를 사용할 때는 불리언 하나를 연산자(`!`) 뒤에 놓아요.

```crystal
!true
# => false

!false
# => true
```

## 괄호(`()`) 사용하기

불리언을 다룰 때는 괄호를 사용해서 어떤 불리언을 먼저 평가할지 정할 수 있어요.
괄호를 어떻게 사용하느냐에 따라 결과가 달라질 수 있어요.
Crystal에서는 괄호 안에 있는 것이 먼저 평가돼요.

```crystal
true && false && false || true
# => true

true && false && (false || true)
# => false
```

괄호 안에 있는 것이 먼저 평가되기 때문에, 다음 예시에서는 _not_ 연산자가 괄호 안의 표현식에 적용돼요.

```crystal
!true && false
# => false

!(true && false)
# => true
```

~~~~exercism/note
괄호는 결과에 영향을 줄 때만 사용하고, 그렇지 않으면 생략해요.
~~~~

## 참 같은 값과 거짓 같은 값

Crystal에서 "거짓 같은 값"은 `false`, `nil`, 그리고 null 포인터이고, **나머지 모든 것**은 "참 같은 값"이에요.
이 값들은 위에서 설명한 논리 연산자들과 함께 사용할 수 있어요.

```crystal

true && nil
# => false

false && 4
# => false

true || nil
# => true
```

## 불리언과 함께 쓰는 메서드 이름 규칙

Crystal에서는 참 같은 값이나 거짓 같은 값을 반환하는 메서드 이름 끝에 물음표(`?`)를 붙이는 것이 일반적이에요.
대부분의 경우 이런 메서드는 불리언 값을 반환하지만, 꼭 그럴 필요는 없어요.
즉, 이런 메서드는 참 같은 값이나 거짓 같은 값이 필요한 곳, 예를 들어 `if`문의 조건으로 사용할 수 있어요.

```crystal
def exchange(value)
    if value.nil?
        value = 5
    end
    value
end

exchange(10)
# => 10

exchange(nil)
# => 5
```

이름 끝에 물음표가 붙었지만 불리언 값을 반환하지 않는 메서드는 대신 `nil`을 반환하는 경우가 많아요. `nil`은 _다른 언어의 `None`이나 `null`과 비슷해요_.
