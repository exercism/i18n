# 소개

## `Base.@kwdef`

`Base.@kwdef` 매크로를 사용하면 [struct][struct]를 정의할 때 키워드 인자를 받는 생성자를 자동으로 정의할 수 있어요.
필드의 기본값도 설정할 수 있어요.

예를 들어, 다음과 같이 정의하면

```julia
Base.@kwdef struct HumanStats
    birthyear::Int
    height::Int
    mass::Int
    bmi::Float64 = mass / (0.01 * height)^2
end
```

한 번에 세 개의 생성자가 정의돼요

```julia-repl
julia> methods(HumanStats)
# 3 methods for type constructor:
[1] HumanStats(; birthyear, height, mass, bmi) [...]
[2] HumanStats(birthyear::Int64, height::Int64, mass::Int64, bmi::Float64) [...]
[3] HumanStats(birthyear, height, mass, bmi) [...]
```

키워드 인자를 기반으로 하는 생성자도 포함해서요

```julia-repl
julia> HumanStats(
           birthyear = 2002,
           height = 193,
           mass = 83
       )
HumanStats(2002, 193, 83, 22.28247738194314)
```

반면, 표준 정의는

```julia
struct HumanStats
    birthyear::Int
    height::Int
    mass::Int
    bmi::Float64
end
```

다음과 같이 두 개만 정의하고

```julia-repl
julia> methods(HumanStats)
# 2 methods for type constructor:
[1] HumanStats(birthyear::Int64, height::Int64, mass::Int64, bmi::Float64) [...]
[2] HumanStats(birthyear, height, mass, bmi) [...]
```

키워드 기반 생성자는 직접 정의해 줘야 해요.

### `Base.@kwdef`는 언제 사용할까요?

키워드 기반 생성자는 인자가 아주 많은 struct를 만들 때 특히 유용해요. 특히 인자의 타입이나 값만으로는 그 인자가 무엇을 뜻하는지 바로 알기 어려울 때 그렇죠.

다음 정의를 살펴봐요:

```julia
dirk = BasketballPlayer(1978, 1994, 2019, 213, 111, 42, 1998, [2011], 31560, 11489, 3651)
```

타입의 정의를 모르면 각 값이 무엇을 의미하는지 알기 어려워요.
정의를 알고 있더라도 인자의 순서를 매번 다시 찾아봐야 할 거예요.

그런데 키워드 기반 생성자를 사용하면 각 값의 의미가 곧바로 분명해져요:

```julia
dirk = BasketballPlayer(
    birthyear = 1978,
    career_start = 1994,
    career_end = 2019,
    height = 213,
    weight = 111,
    number = 42,
    drafted = 1998,
    championships = [2011],
    points = 31560,
    rebounds = 11489,
    assists = 3651
)
```

~~~~exercism/caution
`Base.@kwdef`는 export되지 않았고 매뉴얼에도 문서화되어 있지 않아요. 따라서 [Julia의 공개 API][public-api]의 일부가 아니에요.
그래서 이 매크로의 인터페이스는 기술적으로 안정성이 보장되지 않고, Julia 마이너 업데이트 사이에 바뀔 수도 있어요.

그렇지만 이 매크로는 생태계 전반에서 널리 쓰이고 있고, 호환성을 깨뜨리는 방식으로 바뀔 가능성은 낮아요.

더 자세한 내용은 다음을 참고해요:

- ["What does `@kwdef` do?"][discourse-kwdef]
- [매뉴얼에 `@kwdef`를 추가하자는 Julia 이슈 #32659][add-kwdef-to-manual]
- [`@kwdef`를 export하자는 Julia 이슈 #33192][export-kwdef]

~~~~
