# 소개

C#의 예외는 런타임에 발생하는 오류 상황을 체계적이고 일관되며 타입 안전한 방식으로 처리할 수 있게 해줘요. 애플리케이션 충돌을 막으려면 예외와 오류를 제대로 처리하는 것이 중요해요.

C#에서 모든 예외의 기본 타입은 `System.Exception` 클래스예요. 이 클래스에는 예외가 던져진 이유를 사람이 읽을 수 있게 설명해 주는 `Message` 같은 중요한 속성이 있어요.

코드의 특정 부분에서 오류가 발생해야 한다는 것을 알리려면, 새로운 예외 객체를 만들고 `throw` 키워드를 사용해 던져야 해요:

```csharp
using System;
static int Square(int number)
{
    if (number >= 46341)
    {
        throw new ArgumentException($"Argument {number} cannot be higher than 46340 as its' square doesn't fit into int type.");
    }
    return number * number;
}
```

예외가 던져지면 런타임은 그 예외를 처리할 책임이 있는 코드를 찾아야 해요. 적절한 처리기를 찾지 못하면, 런타임은 처리되지 않은 예외 메시지를 표시하고 프로그램 실행을 중단해요.

예외를 처리할 처리기를 만들기 위해 C#에서는 try-catch 문을 사용하는데, 이 문은 `try` 블록 하나와 하나 이상의 `catch` 절로 이루어져 있어요. `try` 블록에는 예외가 던져질 수 있는 코드를 넣고 보호해야 해요. `catch` 절에는 오류가 발생한 뒤 프로그램이 어떻게 동작할지 처리하는 코드가 들어가요. `try` 블록 뒤에서는 예외의 순서가 중요하다는 점을 기억하세요. 여러 예외가 나열되면 처음으로 일치하는 `catch` 절이 실행되기 때문이에요.

```csharp
try
{
   if (number == 42)
   {
       throw new ArgumentException("The number cannot be equal to 42.", "number");
   }

   if (number < 0)
   {
      throw new ArgumentOutOfRangeException("number", "The number cannot be negative.");
   }

    // Process number ...
}
catch (ArgumentOutOfRangeException e)
{
    Console.WriteLine($"Number is out of range: {e.Message}.");
}
catch (ArgumentException)
{
    Console.WriteLine("Invalid number.");
}
```
