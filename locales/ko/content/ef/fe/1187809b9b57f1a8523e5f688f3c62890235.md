# 소개

Swift에는 참과 거짓을 나타내는 내장 타입 [`Bool`][bools]이 있어요. 이 타입이 표현하는 값은 `true`와 `false`예요.

## 논리 연산자

Swift는 불리언 식을 조합하고 평가할 수 있도록 세 가지 [논리 연산자][logical-operators] (`!`, `&&`, `||`)를 제공해요.

### 논리 AND (`&&`)

[AND 연산자][and] (`&&`)는 두 피연산자가 모두 `true`일 때만 `true`를 반환해요.
피연산자 중 하나라도 `false`이면 `false`를 반환해요.
`&&` 기호의 양쪽에 식이나 불리언 값을 놓아요:

```swift
true && true  // true
true && false // false
```

### 논리 OR (`||`)

[OR 연산자][or] (`||`)는 피연산자 중 **하나 이상**이 `true`이면 `true`를 반환해요.
두 피연산자가 모두 `false`일 때만 `false`를 반환해요.
`||` 기호의 양쪽에 식이나 불리언 값을 놓아요:

```swift
true || true   // true
true || false  // true
false || false // false
```

### 논리 NOT (`!`)

[NOT 연산자][not] (`!`)는 불리언 값을 뒤집어요.
값이 `false`이면 `true`를 반환하고, 값이 `true`이면 `false`를 반환해요.
값이나 식 바로 앞에 `!` 연산자를 놓아요:

```swift
!true  // false
!false // true
```

## 괄호 사용하기 (`()`)

[괄호][explicit-parentheses]를 사용하면 식을 묶고 평가 순서를 제어할 수 있어요.
Swift에서는 괄호 안의 식이 먼저 평가돼요:

```swift
true && false && false || true   // true
true && false && (false || true) // false
```

괄호로 묶으면 NOT 연산자가 복잡한 식에 어떻게 적용되는지도 정해져요:

```swift
!true && false   // false (evaluates (!true) first, then false && false)
!(true && false) // true  (evaluates (true && false) first to false, then !false)
```

~~~~exercism/note
평가 순서를 분명히 하거나 복잡한 조건을 읽기 쉽게 만들고 싶을 때는 괄호를 사용해요.
기본 우선순위만으로 이미 분명하다면 불필요한 괄호는 넣지 않아요.
~~~~
