# 소개

## 비교

C++에서는 비교 연산자를 사용해 값을 비교할 수 있어요.

| 비교              | 연산자    |
| ------------------| --------- |
| 같음              | `==`      |
| 같지 않음         | `!=`      |
| 작음              | `<`       |
| 작거나 같음       | `<=`      |
| 큼                | `>`       |
| 크거나 같음       | `>=`      |

이런 비교의 결과는 항상 불리언 값이에요.

```cpp
int a{3};

bool eq1 = a != 4; // true

bool eq2 = a > 5;  // false
```

`==` 연산자와 `!=` 연산자는 각각 어떤 값이 다른 값과 같은지, 같지 않은지를 확인해요.
몇 가지 흔한 예를 볼까요?

```cpp
bool eq3 = 2 == 3; // false, integer comparison

bool eq4 = 2.1 != 2.2; // true, float comparison

bool eq5 = "hello" == "hello"; // true, string comparison
```

나머지 연산자는 어떤 값이 다른 값보다 큰지(`>`), 크거나 같은지(`>=`), 작은지(`<`), 작거나 같은지(`<=`)를 확인해요.
이런 비교는 숫자와 문자열에 사용할 수 있어요.
문자열을 비교할 때는 사전 순서(사전식 순서라고도 해요)를 따라요.

```cpp
bool eq6 = 2 > 3; // false, integer comparison

bool eq7 = 1.2 < 1.3; // true, float comparison

bool eq8 = "Hello" < "World"; // true, string comparison
```

## if 문

C++의 조건문은 다른 언어의 조건문과 비슷해요.
모든 조건 연산의 기반 타입은 `bool` 타입이고, `true` 또는 `false` 값을 가질 수 있어요.
조건문은 여러 조건을 확인하기 위한 흐름 제어 수단으로 자주 사용돼요.

`if` 문을 사용하면, 조건이 `true`일 때 코드를 실행할 수 있어요. 예를 들면 이렇게요:

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

경우가 두 개 이상인 상황에서는 `else if`와 `else` 문을 사용해 여러 `if` 문을 이어 붙일 수 있어요.

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

C++17부터는 `if` 문에 짧은 초기화 문을 함께 넣어, `if` 문에서 사용할 하나 이상의 변수를 초기화할 수 있어요.
예를 들면 이렇게요:

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> 참고: 초기화에서 만든 변수는 if 문이 끝난 뒤에는 접근할 수 없어요.
