# 지침 추가

## 트랙별 지침

역사적으로 Elm은 함수형 반응형 프로그래밍을 사용했지만, 이후 Elm 아키텍처를 사용하는 쪽으로 특화되었어요.

Elm 아키텍처를 사용해 웹 앱을 작성한다고 생각하고 이 연습 문제를 풀어봐요.
프로그램의 출력은 다음과 같은 구조의 HTML이어야 해요.

```html
<div>
  <dl>
    <dt>State</dt>
    <dd>Ongoing</dd>
    <dt>Word</dt>
    <dd>______</dd>
    <dt>Remaining failures</dt>
    <dd>5</dd>
  </dl>
</div>
```

여기서 `<dl>`은 설명 목록 요소, `<dt>`는 설명 용어 요소, `<dd>`는 설명 세부 요소이고, 모두 표준 HTML 요소예요.

오류가 있으면 출력은 다음과 같은 구조여야 해요.

```html
<div>
  <p>error message</p>
</div>
```
