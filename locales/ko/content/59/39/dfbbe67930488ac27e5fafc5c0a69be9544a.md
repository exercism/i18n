# 힌트

## 일반

- 구조체 인스턴스는 구조체 이름을 쓰고 그 뒤에 중괄호로 감싼 필드 값을 붙여서 만들어요.
- `@T`를 사용하면 어떤 타입 `T`의 스냅샷을 선언할 수 있어요. 예를 들어 `let i: @u32 = @1;`은 `u32` 값 `1`의 스냅샷인 변수 `i`를 선언해요.
- `*` (desnap) 연산자를 사용하면 스냅샷에서 값을 꺼낼 수 있어요. 예를 들어 `let int = *an_int_snapshot;`처럼요.
- `mut` 키워드를 사용하면 값을 가변으로 선언할 수 있어요. `let mut i = 1;`처럼요.

## 1. 투표 계수기 만들기

- `VoteCounter` 구조체에 대한 포인터, 즉 `@VoteCounter`를 만들어야 해요.
- 구조체 인스턴스를 만들 때 `value` 매개변수를 바로 대입할 수 있어요.

## 2. 계수기에서 투표 수 가져오기

- 스냅샷에 `*` 연산자를 사용해서 desnap하고 그 값을 가져올 수 있어요. 예를 들어 `*my_snapshot`처럼요.

## 3. 계수기의 투표 수 증가시키기

- `@VoteCounter` 스냅샷을 수정하는 대신, 투표 수가 증가된 새로운 `VoteCounter` 인스턴스를 반환해야 해요.
- `*` 연산자로 내부의 투표 계수기 값을 desnap하거나, 이전 과제에서 만든 함수를 호출할 수 있어요.

## 4. 선거 결과 만들기

- `name`과 `vote_counter` 필드를 함수의 인자에 있는 값으로 채운 새로운 `ElectionResult` 구조체나 변수를 만들어요.
- 변수 이름이나 구조체 선언 앞에 `@` 연산자를 붙여서 `VoteCounter` 스냅샷을 만들거나, 이전 과제에서 만든 `new_vote_counter` 함수를 호출할 수 있어요.

## 5. 결과 발표하기

- `ElectionResult`에 대한 스냅샷을 받더라도, 마치 스냅샷이 아닌 것처럼 점 `.` 표기법으로 필드에 접근할 수 있어요!
- 구조체의 `name`과 `vote_counter` 필드에 접근해서 메시지를 만들어요.
- 중첩된 스냅샷을 desnap할 때는 desnap해야 할 스냅샷 수만큼 `*` 연산자를 적용해야 해요.

```rust
let result = @ElectionResult {
    name: "John",
    vote_counter: @VoteCounter { value: 32 },
};

println!("{}", **result.vote_counter.value); 
// => 32
```

## 6. 투표 재검표

- [딕셔너리가 구현된 방식][dictionaries underneath] 때문에, 딕셔너리를 수정하고 읽는 데 모두 가변이어야 한다는 조건이 있어요. 즉, 함수 안에서 딕셔너리에 가한 변경이 함수 밖에서도 보여요.
- `let mut m: Felt252Dict<u32>`에서 키의 값을 증가시키려면 `get`과 `insert` 함수를 함께 사용해야 해요: `m.insert('mykey', m.get('mykey') + 1);`
