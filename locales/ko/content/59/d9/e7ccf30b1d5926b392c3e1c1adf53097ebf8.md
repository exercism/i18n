# 지침

이 연습 문제에서는 "Wizard and Warriors"라는 롤플레잉 게임을 플레이해요. 이 게임에서는 Wizard 또는 Warrior로 플레이할 수 있어요.

Warrior와 Wizard가 입히는 피해 점수를 정하는 규칙은 서로 달라요.

Warrior의 규칙은 다음과 같아요:

- 공격 대상이 취약하지 않으면 6점의 피해를 입혀요
- 공격 대상이 취약하면 10점의 피해를 입혀요

Wizard의 규칙은 다음과 같아요:

- Wizard가 미리 주문을 준비했으면 12점의 피해를 입혀요
- Wizard가 주문을 준비하지 않았으면 3점의 피해를 입혀요

일반적으로 캐릭터는 취약하지 않아요. 하지만 Wizard는 주문을 준비하지 않았다면 _취약해요_.

Warrior와 Wizard 캐릭터를 다루는 여섯 개의 과제가 있어요.

## 1. 캐릭터 설명하기

`Character` 클래스의 `ToString()` 메서드를 재정의해서 `"Character is a <CHARACTER_TYPE>"` 형식으로 캐릭터를 설명하는 문자열을 반환하도록 해요.

```csharp
var warrior = new Warrior();
warrior.ToString();
// => "Character is a Warrior"
```

## 2. 캐릭터가 기본적으로 취약하지 않게 만들기

`Character.Vulnerable()` 메서드가 항상 `false`를 반환하도록 해요.

```csharp
var warrior = new Warrior();
warrior.Vulnerable();
// => false
```

## 3. Wizard가 주문을 준비할 수 있게 하기

`Wizard.PrepareSpell()` 메서드를 구현해서 Wizard가 미리 주문을 준비할 수 있게 해요.

```csharp
var wizard = new Wizard();
wizard.PrepareSpell();
```

## 4. 주문을 준비하지 않았을 때 Wizard가 취약하게 만들기

Wizard가 주문을 준비하지 않았으면 `Vulnerable()` 메서드가 `true`를 반환하고, 그렇지 않으면 `false`를 반환하도록 해요.

```csharp
var wizard = new Wizard();
wizard.Vulnerable();
// => true
```

## 5. Wizard의 피해 점수 계산하기

`Wizard.DamagePoints()` 메서드를 구현해서 입힌 피해 점수를 반환하도록 해요. 주문을 준비했으면 12점, 준비하지 않았으면 3점이에요.

```csharp
var wizard = new Wizard();
var warrior = new Warrior();

wizard.PrepareSpell();
wizard.DamagePoints(warrior);
// => 12
```

## 6. Warrior의 피해 점수 계산하기

`Warrior.DamagePoints()` 메서드를 구현해서 입힌 피해 점수를 반환하도록 해요. 대상이 취약하면 10점, 취약하지 않으면 6점이에요.

```csharp
var warrior = new Warrior();
var wizard = new Wizard();

warrior.DamagePoints(wizard);
// => 10
```
