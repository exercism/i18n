# 루프

```sather
   loop
      ...
   end;
```

Sather에는 `loop`문이 딱 하나뿐이에요. `while`도 `for`도 없어요. 둘 다 `loop`와, 그것을 끝내는 무언가로 이루어져 있어요.

## 변수

```sather
   total ::= 0;          -- declare, with a starting value
   total := total + 5;   -- assign
```

`::=` 연산자는 변수를 선언하면서 주어진 값에서 타입을 가져와요. 값을 넣기 전에 변수가 먼저 있어야 할 때는, 대신 타입을 붙여 선언해요.

```sather
   total : INT;
   total := 0;
```

값 없이 선언한 변수는 `INT`라면 0, `BOOL`이라면 `false`, 문자열이나 객체라면 void로 시작해요.

## 루프 끝내기

| 작성 방법 | 루프가 끝나는 때 |
| --- | --- |
| `until!(q)` | `q`가 참일 때 |
| `while!(q)` | `q`가 거짓일 때 |
| `break!` | 곧바로 |

세 가지 모두 루프 본문 어디에나 쓸 수 있고, 한 루프에서 여러 개를 함께 써도 돼요.

```sather
   loop
      until!(n > last);      -- may run no times at all
      ...
   end;

   loop
      ...
      until!(done);          -- always runs at least once
   end;
```

## 느낌표

`until!`, `while!`, `break!`는 끝에 `!`가 붙어요. 이들은 **이터레이터**라서 그래요. 이터레이터는 루프 안에서만 나타날 수 있고, 루프를 끝낼 수도 있어요. 루프 밖에서 이터레이터를 쓰면 경고가 아니라 오류예요. 뒤에 나오는 연습 문제에서는 라이브러리의 다른 이터레이터들을 사용하고, 나중에는 직접 새로운 이터레이터를 만들어요.

## 무한 루프

끝내는 것이 없는 루프는 영원히 돌아요. 가끔은 정말 그렇게 하고 싶을 때도 있지만, 훨씬 자주는 조건에서 확인하는 값이 한 번도 바뀌지 않는다는 뜻이에요. 프로그램이 멈춰서 응답하지 않으면, 가장 먼저 확인해야 할 것은 루프 안의 무언가가 루프를 멈추는 방향으로 나아가게 하고 있는지예요.
