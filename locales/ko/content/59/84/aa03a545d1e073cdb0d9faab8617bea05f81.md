# 힌트

## 일반

- 지침에 있는 표를 참고하는 걸 잊지 마세요.

## 1. 확장자가 주어지면 예상되는 미디어 타입을 반환해요

- 올바른 미디어 타입을 반환하려면 [패턴 매칭][pattern-matching]을 사용해요.
- [여러 함수 절][mfc]을 사용할 수 있어요.

## 2. 바이너리 파일이 주어지면 예상되는 미디어 타입을 반환해요

- 바이너리 리터럴을 작성할 때 사용할 수 있는 [바이너리 특수 형식][special-forms]을 사용해요.
- 파일 바이너리의 처음 몇 바이트와 일치시키려면 [패턴 매칭][binary-matching]을 사용해요.

## 3. 확장자와 바이너리 파일이 주어지면 파일이 예상되는 타입과 일치하는지 확인해요

- 1번과 2번에서 만든 함수를 재사용해요.
- 각 함수의 반환값을 비교한 다음, 알맞은 값을 반환해요.
  - 조건이 참인지 거짓인지 판단할 때는 [`if` 매크로 조건문][if]을 사용할 수 있어요.
