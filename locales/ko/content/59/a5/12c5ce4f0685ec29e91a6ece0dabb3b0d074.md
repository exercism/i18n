# 소개

[switch 문][switch]을 사용하면 값을 여러 가지 가능한 패턴과 비교할 수 있어요.
`if-else` 문을 여러 개 연결하는 것보다 더 깔끔하고 읽기 쉬운 방법이에요.

`switch` 문은 `switch` 키워드로 시작하고, 바로 뒤에 검사할 값이 와요.
가능한 각 일치는 `case` 키워드로 정의해요.
`default` 키워드는 명시한 경우가 하나도 일치하지 않을 때 실행되는 기본 경우를 정의해요.
`if-else` 체인과 마찬가지로 `switch` 문도 처음 일치하는 경우에 해당하는 코드 블록만 실행해요.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

다음 `if-else` 체인을 살펴봐요:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

이 코드는 `switch` 문을 사용하면 더 명확하게 쓸 수 있어요:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

[switch]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#Switch
