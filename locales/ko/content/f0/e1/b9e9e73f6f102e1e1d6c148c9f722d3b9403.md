# 지침

친구들과 나눠 먹을 쿠키를 구울 준비를 하다 보니, 레시피에 쓰인 계량 단위 몇 가지를 변환해야 한다는 걸 알게 됐어요. 미터법에만 익숙하다 보니, 흔히 쓰는 미국식 베이킹 계량을 밀리리터(mL)로 손쉽게 변환할 방법을 마련해야 해요.

해답을 만들 때 다음 변환표를 사용해요:

| 변환할 단위 | 부피 | 밀리리터(mL) 기준 |
| --------------- | ------ | ------------------- |
| mL              | 1      | 1                   |
| 미국식 컵          | 1      | 240                 |
| 미국식 액량 온스  | 1      | 30                  |
| 미국식 티스푼     | 1      | 5                   |
| 미국식 테이블스푼   | 1      | 15                  |

재능 있는 프로그래머 지망생답게, 나열된 어떤 단위에서 다른 단위로(심지어 같은 단위로도) 변환하기 쉽도록 밀리리터를 중간 단위로 쓰기로 해요.

## 1. 부피 쌍에서 숫자 성분 가져오기

`getVolume` 함수를 구현해요. 부피 쌍 튜플이 주어지면 숫자 성분만 반환해야 해요.

```haskell
getVolume (Cup, 2.0)
-- -> 2.0
```

## 2. 부피 쌍을 밀리리터로 변환하기

`toMilliliter` 함수를 구현해요. 부피 쌍 튜플이 주어지면 변환표를 사용해 부피를 밀리리터로 변환해야 해요.

여러 함수 절과 패턴 매칭을 사용해 각 단위에 대한 함수를 만들어요. 각 단위를 나타내는 데 쓰이는 아톰은 `Cup`, `FluidOunce`, `Teaspoon`, `Tablespoon`, `Milliliter`예요. 변환 결과는 튜플로 감싸서 반환해요.

```haskell
toMilliliter (Cup, 2.5)
-- -> (Milliliter, 600.0)
```

## 3. 밀리리터 부피 쌍을 다른 단위로 변환하기

`fromMilliliter` 함수를 구현해요. 부피 쌍 튜플과 원하는 단위가 주어지면 변환표를 사용해 부피를 원하는 단위로 변환해야 해요.

여러 함수 절과 패턴 매칭을 사용해 각 단위에 대한 함수를 만들어요. 각 단위를 나타내는 데 쓰이는 아톰은 `Cup`, `FluidOunce`, `Teaspoon`, `Tablespoon`, `Milliliter`예요.

```haskell
fromMilliliter (Milliliter, 1320.0) Cup
-- -> (Cup, 5.5)
```

## 4. 어떤 단위에서 어떤 단위로든 변환하기

`convert` 함수를 구현해요. 부피 쌍 튜플과 원하는 단위가 주어지면 주어진 부피를 원하는 단위로 변환해야 해요.

```haskell
convert (Teaspoon, 9.0) Tablespoon
-- -> (Tablespoon, 3.0)
```
