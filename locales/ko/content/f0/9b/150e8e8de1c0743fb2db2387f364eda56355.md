# Debug

```pyret
fun print-forty-two():
  print(42) # 42
end
```

```pyret
fun return-forty-two() block:
  print(42) # 42
  42
end
```

[print][print]는 값을 반환하는 표현식이에요.
Pyret은 바깥 블록이 `block`으로 표시되어 있지 않으면, 주어진 코드 블록 안에 표현식 하나만 허용해요.
두 번째 예제에서는 함수 선언에 `block`을 추가하면 42를 출력하고 나서 반환할 수 있어요.

## 스파이

```pyret
fun do-something():
    x = "foo"
    y = "bar"
    spy "strings": x, y end
    a = 1
    b = 2
    spy "numbers": a, b end
end
do-something();

# Spying "strings" (at <clipped>/example.arr:4:4-4:27)
#  x: "foo"
#  y: "bar"
# Spying "numbers" (at <clipped>/example.arr:7:4-7:27)
#  a: 1
#  b: 2
```

spy 문은 선택적인 레이블과 하나 이상의 변수를 받아 각 변수와 그 값을 알려줘요.
표현식이 아니기 때문에, spy는 바깥 블록이 `block`으로 표시되어 있지 않아도 블록 안에서 사용할 수 있어요.

[print]: https://pyret.org/docs/latest/_global_.html#%28idx._%28gentag._57%29%29
[spy]: https://pyret.org/docs/latest/s_spies.html
