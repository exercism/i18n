# 설명

매개변수의 타입을 추론할 수 있다면, Swift에서는 클로저 정의에서 매개변수 이름과 `in` 키워드를 생략할 수도 있어요. 대신 [특별한 축약 문법][shorthand-argument-names]으로 매개변수를 가리킬 수 있는데, `$0`은 첫 번째 매개변수를, `$1`은 두 번째 매개변수를 가리키고, 그다음도 같은 식이에요.

```swift
let mean: (Double, Double) -> Double = { $0 + $1 / 2.0 }

["apple", "ball", "carrot"].sorted(by: { $0.count < $1.count })
```

이 방식은 클로저를 고차 함수에 넘길 때처럼 간결함이 중요할 때 가장 자주 사용해요.

[shorthand-argument-names]: https://docs.swift.org/swift-book/LanguageGuide/Closures.html#ID100
