# 자세히 알아보기

Elm의 [`List`][lists]는 같은 타입의 값을 0개 이상 담는 불변 컬렉션이에요.
배열은 불변이기 때문에, 한 번 만들어지면 그 값은 절대 바뀌지 않아요.
Elm의 배열에는 _머리_(첫 번째 원소)와 _꼬리_(첫 번째 원소 뒤에 오는 모든 것)가 있어요.
배열의 꼬리도 그 자체로 배열이에요.

배열의 타입 애너테이션은 다음과 같이 정의할 수 있어요.

```elm
List String --> a list of String
List Int --> a list of Int
```

배열은 다음과 같이 정의할 수 있어요.

```elm
empty : List Char
empty = []

singleValue = [ 5 ] --> List Int
singleValueAlternative = List.singleton 5 --> List Int

threeValues = [ "a", "b", "c" ] --> List String
```

배열에 원소를 추가하는 가장 흔한 방법은 `::` (cons) 연산자를 쓰는 거예요.

```elm
twoToFour = [ 2, 3, 4 ]
oneToFour = 1 :: twoToFour --> [1; 2; 3; 4]
```

배열은 `++` 연산자나 `List.append`로 이어 붙일 수 있어요.

```elm
[ 6, 7 ] ++ [ 8, 9 ]           --> [6, 7, 8, 9]
List.append [ 6, 7 ] [ 8, 9 ]  --> [6, 7, 8, 9]
```

배열은 [`List` 모듈][list-module]에 정의된 함수와 연산자로 다뤄요.

```elm
List.length [ 7, 8 ] --> 2
```

배열을 수정하는 것처럼 보이는 함수나 연산자(예를 들어 원소를 추가하는 것)는 사실 새로운 배열을 반환해요.
그래도 보통 성능은 문제가 되지 않아요. 배열의 구현이 불필요한 할당이나 복사를 막아 주기 때문이에요.

배열은 [패턴 매칭][list-destructuring]으로 처리할 수도 있어요.

```elm
describe : List String -> String
describe list =
    case list of
        [] ->
            "Empty list"

        [ "hello" ] ->
            "Singleton list with: hello"

        x :: xs ->
            "Non-empty list with head: " ++ x

describe []                   --> "Empty list"
describe [ "hello" ]          --> "Singleton list with: hello"
describe [ "hello", "world" ] --> "Non-empty list with head: hello"
```
