# 테스트 실행하기

터미널에서 연습 문제의 기본 디렉터리로 이동한 다음, 아래 명령어로 테스트를 실행해요:

```bash
$ mix test
```

그러면 `test` 하위 폴더에 있는 테스트 파일, 즉 이름이 `_test.exs`로 끝나는 파일이 실행돼요.

문서:

* [`mix test` - Elixir의 테스트 실행 도구](https://hexdocs.pm/mix/Mix.Tasks.Test.html)
* [`ExUnit` - Elixir의 단위 테스트 라이브러리](https://hexdocs.pm/ex_unit/ExUnit.html)

## 보류 중인 테스트

실습 문제의 테스트 모음에서는 첫 번째 테스트를 제외한 모든 테스트에 건너뛰기 태그가 붙어 있어요.

테스트 하나를 통과시키면, 해당 `@tag :pending`을 `#` 기호로 주석 처리해서 다음 테스트의 건너뛰기를 해제할 수 있어요.

예를 들어:

```elixir
# @tag :pending
test "shouting" do
  assert Bob.hey("WATCH OUT!") == "Whoa, chill out!"
end
```

모든 테스트를 한 번에 실행하고 싶다면 `mix test` 명령어에 `--include` 플래그를 사용해서 건너뛴 테스트를 모두 포함할 수 있어요:

```bash
$ mix test --include pending
```

또는 `test/test_helper.exs` 파일에서 `ExUnit.configure` 줄을 주석 처리해서 모든 테스트를 활성화할 수 있어요.

```elixir
# ExUnit.configure(exclude: :pending, trace: true)
```

## 유용한 `mix test` 옵션

* `test/<FILE>.exs:LINENUM` - 정의가 `LINENUM`번 줄에 있는 `<FILE>.exs`의 테스트 하나만 실행해요
* `--failed` - 지난번 실행에서 실패한 테스트만 실행해요
* `--max-failures` - 테스트 실패가 이 횟수에 도달하면 테스트 모음 실행을 중단해요
* `--seed 0` - 무작위화를 비활성화해서 한 파일의 테스트가 항상 정의된 순서대로 실행돼요
