# 소개

Factor에서는 `: name ( stack-effect ) body ;` 형태로 새로운 단어를 정의해요. 본문은 단어들의 나열이고, 새로 정의한 단어를 호출하면 이 단어들이 순서대로 실행돼요.

```factor
USING: kernel ;
IN: my-vocab

: shout ( str -- str ) "!" append ;
```

루틴이 커지면 그 루틴을 *factor* 할 수 있고, 또 그래야 해요. 단어들을 묶어 각각 한 가지 일만 맡는 더 작은 이름의 단어로 나누는 거예요. Factor라는 언어의 이름도 여기서 나왔어요.

## 어휘

각 `.factor` 파일은 `IN:`으로 어휘를 선언해요. 한 어휘에 속한 단어는 다른 어휘를 `USING:`에 나열하면 그 어휘의 단어를 호출할 수 있어요.

```factor
! file: my-vocab/helpers/helpers.factor
USING: kernel ;
IN: my-vocab.helpers

: shout-line ( str -- str ) "!" append ;
```

```factor
! file: my-vocab/my-vocab.factor
USING: kernel my-vocab.helpers sequences ;
IN: my-vocab

: announce ( names -- strs )
    [ shout-line ] map ;
```

디렉터리 구조는 점으로 구분된 어휘 이름을 따라요. 어휘 `my-vocab`은 `my-vocab/my-vocab.factor`에 있고, 어휘 `my-vocab.helpers`는 `my-vocab/helpers/helpers.factor`에 있어요. Factor의 로더는 `USING:` 선언을 전이적으로 따라가면서 각 어휘를 필요할 때 불러와요.
