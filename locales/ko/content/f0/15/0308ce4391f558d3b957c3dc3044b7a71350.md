# 개요

## 숫자와 숫자 연산자

**숫자**는 정수이든 아니든 모두 IEEE754 배정밀도 부동소수점 수예요.
`jq`의 구현은 C의 `double` 타입을 사용해요.
그래서 정밀도가 53비트로 제한돼요.

숫자에는 다음과 같은 일반적인 연산자를 사용할 수 있어요:

- 산술: `+`, `-`, `*`, `/`, `%`
- 비교: `==`, `!=`, `<`, `<=`, `>=`, `>`
- 표준 [수학 함수][man-math]

  입력이 하나인 함수는 값을 함수로 파이프해요

  ```sh
  $ jq -n '(1 | atan) * 4'
  3.141592653589793
  ```

  입력이 두 개인 함수는 파이프로 들어온 입력을 무시하고 두 입력을 매개변수로 받아요

  ```sh
  $ jq -n 'pow(2; 10)'
  1024
  ```

  함수 인자를 구분하는 것은 쉼표가 아니라 세미콜론이에요.

~~~~exercism/caution
"정밀도가 53비트로 제한된다"는 게 무슨 뜻일까요?

한번 확인해 봐요:

```sh
$ jq -n 'pow(2;52) as $n | [$n, $n+1]'
[
  4503599627370496,
  4503599627370497
]
```

잘 나와요. 그럼 지수를 올리면 어떻게 될까요?

```sh
$ jq -n 'pow(2;53) as $n | [$n, $n+1]'
[
  9007199254740992,
  9007199254740992
]
```

이 두 수는 같으면 안 되는데 말이죠.
이것이 바로 "정밀도 손실"이에요.
즉, `jq`는 임의로 큰 수를 다룰 수 없어요.

## 조건 표현식

`jq`는 **조건 표현식**에 [`if-then-else` 표현식][if-then-else]을 사용해요.
_표현식_이기 때문에 파이프라인 안에 놓여요.

문법은 `if CONDTITION then TRUE_EXPR else FALSE_EXPR end`예요.

`else` 절은 생략할 수 있어요.

```jq
42 | if . < 33 then "small" else "larger" end
# => "larger"
```

조건을 더 추가하려면 `elif`를 사용해요

```jq
42 | if . < 33 then "small"
     elif . < 67 then "medium"
     else "large"
     end
# => "medium"
```
