# 소개

메서드 매개변수에 기본값을 할당하면 그 매개변수를 선택적으로 만들 수 있어요. 선택적 매개변수를 가진 메서드를 호출할 때, 호출자는 그 매개변수에 값을 넘겨주지 않아도 돼요. 선택적 매개변수에 값을 넘겨주지 않으면 기본값이 사용돼요.

선택적 매개변수는 매개변수 목록의 _맨 끝_에 있어야 해요. 뒤에 선택적이 아닌 매개변수가 올 수는 없어요.

```csharp
class Card
{
    static string NewYear(int year = 2020)
    {
        return $"Happy {year}!";
    }
}

Card.NewYear();     // => "Happy 2020!"
Card.NewYear(1999); // => "Happy 1999!"
```
