# 소개

함수가 인자를 많이 받을 때는 어떤 순서로 전달해야 하는지 기억하기 어려울 때가 있어요. 가독성을 높이기 위해 Gleam에서는 인자에 레이블을 붙일 수 있어요.

인자에 레이블을 붙이려면 인자 이름 앞에 레이블 이름을 쓰고, 그 사이에 공백을 하나 넣어요.

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

레이블이 붙은 인자를 가진 함수를 호출할 때는 인자를 어떤 순서로든 전달할 수 있어요. 다음 `replace` 호출은 모두 같은 의미예요:

```gleam
replace(in: "🍔🍔🍔" each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

레이블은 언제나 선택 사항이에요. 함수에 레이블이 붙은 인자가 있더라도 레이블 없이 호출할 수 있어요.

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```
