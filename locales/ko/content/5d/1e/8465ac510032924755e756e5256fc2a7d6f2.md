# 소개

PHP에서 공변성과 반공변성 개념은 클래스나 인터페이스를 상속할 때 PHP가 이 규칙을 따르도록 강제하기 때문에 중요해요.

공변성은 두 타입 사이의 관계를 유지하지만, 반공변성은 그 관계를 뒤집어요. 간단히 말해, 클래스를 상속하고 함수를 오버라이드할 때 메서드의 매개변수에는 더 구체적인 타입이나 더 포괄적인 타입을 허용할 수 있고, 메서드에서는 더 좁은 타입이나 더 구체적인 타입을 반환할 수 있다는 뜻이에요.

## 예시

다음 클래스를 살펴봐요.

```php
class Calculator 
{
    public function add(int $x, int $y): int 
    {
        return $x + $y;
    }
}
```

클래스를 상속하면 원래 선언된 것보다 더 많은 매개변수 타입을 허용할 수 있지만, 원래 반환 타입 외의 다른 것을 반환할 수는 없어요.

```php
class Floatulator extends Calculator
{
    // This is valid
    public function add(int|float $x, int|float $y): int 
    {
        return (int)($x + $y);
    }
}
```

다음처럼 상속한 클래스는 유효하지 않아요. 추가적인 타입이나 더 넓은 타입을 반환하는 것은 허용되지 않기 때문이에요.

```php
class BrokenCalculator extends Calculator 
{
    // This is invalid and will not compile
    public function add(int|float $x, int|float $y): int|float{
        return $x + $y;
    }
}
```
