# 추가 지침

## 레지스터

| 레지스터 | 용도        | 타입    | 설명                          |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | 입력        | 주소    | null로 끝나는 문구            |
| `$a1`    | 입력/출력   | 주소    | null로 끝나는 결과 문자열     |
| `$t0-9`  | 임시        | 제한 없음 | 임시 저장용                  |
