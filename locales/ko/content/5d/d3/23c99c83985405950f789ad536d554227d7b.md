# 소개

SQL에서는 `SELECT` 문을 사용해 데이터베이스에서 데이터를 가져올 수 있어요.
`SELECT` 문의 결과는 결과 집합이에요.
결과 집합에는 행과 열로 정렬된 값이 담겨 있어요.
각 열은 데이터의 특정 속성을 나타내고, 각 행에는 모든 열에 대한 값이 들어 있어요.

이렇게 생각해 볼 수도 있어요. 열의 집합은 하나의 데이터 구조를 나타내고, 각 열은 그 데이터 구조의 필드를, 각 행은 그 데이터 구조의 인스턴스를 나타낸다고요.

`SELECT` 문으로는 가져오고 싶은 데이터를 지정할 수 있어요.
원한다면 출력 데이터를 변환하거나 필터링하거나, 형태를 바꿀 수도 있어요.

## 기본 구조

기본적인 `SELECT` 문의 구조는 다음과 같아요:

```sql
SELECT <columns>
FROM <source>
WHERE <criteria>;
```

~~~~exercism/note
`FROM`과 `WHERE` 절은 생략할 수 있어요.
예를 들어 `SELECT "Hello, world.";` 같은 문은 완벽하게 유효해요.

줄바꿈도 꼭 필요한 건 아니에요. 어떤 공백이든 `SELECT` 문의 각 절(즉, 각 부분)을 구분하기에 충분해요.
~~~~

`SELECT` 키워드 바로 뒤에는 결과에 포함하고 싶은 열 목록이 와요.
`FROM` 절은 데이터의 원천을 지정하는데, 보통 데이터베이스의 테이블이에요.
`WHERE` 절은 하나 이상의 조건으로 출력 데이터를 필터링해요.

## `WHERE` 절로 데이터 필터링하기

`WHERE` 절을 사용하면 `SELECT` 문으로 가져온 데이터를 필터링할 수 있어요.
예를 들어 Appliances만 원한다면 이렇게 하면 돼요:

```sql
SELECT * FROM inventory
WHERE category = "Appliances";
```

결과:
```
upc           category    supplier        brand      product_name                 weight  stock
------------  ----------  --------------  ---------  ---------------------------  ------  -----
899001234556  Appliances  Culinary Depot  QuickBrew  Single-Serve Coffee Maker    4.2     18   
880012349876  Appliances  Culinary Depot  HeatWave   Compact Toaster Oven         7.5     14   
844110220987  Appliances  Culinary Depot  BlendPro   High-Speed Personal Blender  3.1     16   
```

아니면 weight가 2.0과 6.0 사이인 데이터만 원할 수도 있어요:

```sql
SELECT * FROM inventory
WHERE weight BETWEEN 2.0 AND 6.0;
```

결과:
```
upc           category    supplier        brand      product_name                  weight  stock
------------  ----------  --------------  ---------  ----------------------------  ------  -----
899001234556  Appliances  Culinary Depot  QuickBrew  Single-Serve Coffee Maker     4.2     18   
823450987112  Cookware    KitchenCo       FreshKeep  12-Piece Glass Container Set  6       33   
899998877665  Cookware    KitchenCo       IronCraft  Cast-Iron Grill Pan           5.3     21   
844110220987  Appliances  Culinary Depot  BlendPro   High-Speed Personal Blender   3.1     16   
```
