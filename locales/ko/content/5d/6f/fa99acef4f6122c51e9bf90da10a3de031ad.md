# 테스트 실행하기

## 연습 문제 다운로드하기

[Exercism CLI][cli]를 사용해 작업할 연습 문제를 다운로드해요.

```sh
exercism download --track=dart --exercise=hello-world
```

그다음 연습 문제 디렉터리로 이동해요.

```sh
cd /path/to/exercism/dart/hello-world
```

## 의존성 설치하기

테스트를 실행하기 전에 연습 문제의 의존성을 다운로드해요.

```sh
dart pub get
```

## 테스트 실행하기

```sh
dart test
```

## 테스트 결과 이해하기

`dart test`는 기본적으로 compact 리포터를 사용해서, 통과한 테스트, 건너뛴 테스트, 실패한 테스트의 개수를 한 줄에 계속 보여줘요.

```sh
$ dart test

  Expected: <3>
    Actual: <0>

  package:matcher                    expect
  test/binary_search_test.dart 13:5  main.<fn>


To run this test again: dart test test/binary_search_test.dart -p vm --plain-name 'finds a value in the middle of an array'
```

- `+1`: 테스트 1개 통과

## 테스트 하나씩 풀어가기

대부분의 연습 문제에는 여러 테스트가 있고, 첫 번째를 제외한 나머지는 기본적으로 건너뛰도록 되어 있어요.

```dart
void main() {
  final twoFer = TwoFer();

  group('TwoFer', () {
    test('no name given', () {
      final result = twoFer.statement();
      expect(result, equals('One for you, one for me.'));
    }, skip: false);

    test('a name given', () {
      final result = twoFer.statement('Alice');
      expect(result, equals('One for Alice, one for me.'));
    }, skip: true);

    test('another name given', () {
      final result = twoFer.statement('Bob');
      expect(result, equals('One for Bob, one for me.'));
    }, skip: true);
  });
}
```

테스트를 하나씩 풀어가려면, 각 테스트의 `skip: true`를 `skip: false`로 바꿔 가며 진행해요.
또는 파일을 수정하지 않고 모든 테스트를 한 번에 실행할 수도 있어요.

```sh
dart test --run-skipped
```

제출하면 온라인 테스트 러너가 건너뛴 테스트를 포함한 모든 테스트를 실행해요.

## "Could not find a command named frontend_server.dart.snapshot" 오류 해결하기

이미 풀어서 제출한 연습 문제를 한동안 지나서 다시 볼 때가 있어요.
그 문제를 테스트하다 보면 이런 오류를 만날 수 있어요:

```sh
$ dart test
...
Could not find a command named "/path/to/frontend_server.dart.snapshot".
```

[해결 방법][solution]은 `pubspec.lock` 파일을 삭제하는 거예요.
그다음 dart 명령을 다시 실행해요.

[solution]: https://stackoverflow.com/q/79247335/7552
