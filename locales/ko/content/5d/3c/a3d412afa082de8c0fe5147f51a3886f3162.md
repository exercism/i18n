# 소개

Ruby는 동적인 [객체 지향 언어][object-oriented-programming]예요.
Ruby에서는 모든 것이 [객체][object]예요.

Ruby에서 객체에 이름을 붙이는 방법은 크게 두 가지예요. 변수를 사용하는 방법과 상수를 사용하는 방법이에요.
변수는 항상 [스네이크 케이스][snake-case]로 작성해요.
변수는 생명 주기 동안 서로 다른 객체를 참조할 수 있어요.
예를 들어 `my_first_variable`은 `=` 연산자를 사용해서 여러 번 정의하고 다시 정의할 수 있어요.

```ruby
my_first_variable = 1
my_first_variable = "Some string"
my_first_variable = SomeComplexObject.new
```

반면에 상수는 한 번만 할당하는 것이 원칙이에요.
상수는 반드시 대문자로 시작해야 하고, 보통 단어 사이를 밑줄로 구분해서 모두 대문자로 작성해요.

예를 들어볼까요?

```ruby
MY_FIRST_CONSTANT = 10

# Redefining not allowed
# MY_FIRST_CONSTANT = "Some String"
```

Ruby는 클래스로 구성되어 있어요.
클래스는 `class` 키워드 뒤에 클래스 이름을 붙여서 정의해요.
객체는 보통 `.new` 메서드로 클래스를 인스턴스화해서 만들어요.

예를 들어볼까요?

```ruby
# Define the class
class Calculator
  #...
end

# Create an instance of it and assign it to a variable
my_first_calc = Calculator.new
```

기능 단위는 메서드로 캡슐화돼요. 다른 언어의 _함수_와 비슷해요.
메서드는 선택적으로 위치 인자를 받도록 정의할 수 있고, `:` 문법으로 정의하고 호출하는 키워드 인자를 받도록 정의할 수도 있어요.
메서드는 마지막으로 평가된 문의 결괏값을 암묵적으로 반환하거나, `return` 키워드로 객체를 명시적으로 반환할 수 있어요.
메서드는 `.` 문법으로 호출해요.

```ruby
class Calculator

  # Unnamed params
  def add(num1, num2)
    return num1 + num2 # Explicit return
  end

  # Named params
  def multiply(num1:, num2:)
    num1 * num2 # Implicit return
  end
end

calc = Calculator.new
calc.add(1, 3)
calc.multiply(num1: 2, num2: 5)
```
