# 개요

**워드**(word)는 Factor에서 함수를 부르는 이름이에요. `basics`에서 데이터 스택과 셔플 워드를 만났죠. 이제는 입력값을 가지고 계산을 해내는 자신만의 워드를 정의해 봐요.

```factor
: square ( x -- x*x ) dup * ;
: hello  ( -- )       "Hello, world!" print ;
: max3   ( a b c -- max ) max max ;
```

정의는 `:`로 시작해서 스택 효과를 적고, 본문을 쓴 다음 `;`로 끝내요. `( … -- … )` 안의 이름들은 읽는 사람을 위한 것이고, 컴파일러가 확인하는 것은 입력과 출력의 *개수*예요. 개수가 맞지 않으면 컴파일 시점 오류가 나는데, 이런 종류의 선언이 없는 동적 타입 언어라면 런타임 오류가 되었을 부류의 버그를 컴파일할 때 미리 잡아 주는 셈이죠.

정수 산술 워드인 `+`, `-`, `*`는 `math` 어휘에 들어 있고, 각각 스택 맨 위에서 숫자 두 개를 꺼내 써요. 스택의 맨 위가 오른쪽 피연산자라서 `8 3 -`는 `8 - 3`을 계산해요.

`CONSTANT:`는 고정된 값에 이름을 붙여 줘요. 그 이름을 호출하면 다른 워드와 똑같이 값을 스택에 넣어요. 상수는 파일 맨 위에, 그 상수를 사용하는 워드보다 앞에 두세요.

워드의 본문에서는 이미 스코프 안에 있는 워드라면 무엇이든 호출할 수 있어요. 같은 파일의 앞선 정의, 불러온 어휘에 들어 있는 워드, 그리고 직접 선언한 상수가 모두 여기에 해당해요. 작고 한 가지 일만 하는 워드들을 조합하는 것이 프로그램을 만들어 나가는 일반적인 방식이에요.

관례적으로는 이렇게 해요.

- 워드와 상수 이름은 `lowercase-kebab-case`를 사용해요.
- 프레디킷은 `?`로 끝나고 불리언을 만들어요 (`even?`, `empty?`).
- 입력을 변경하는 워드는 변경하지 않는 버전과 이름을 공유하는 경우가 많고, 둘은 문맥으로만 구분해요.
