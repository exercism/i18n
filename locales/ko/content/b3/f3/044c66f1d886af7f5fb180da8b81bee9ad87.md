# 지침

Markdown 파서를 리팩터링해요.

markdown 연습 문제는 리팩터링 연습 문제예요.
주어진 문자열을 [Markdown 문법][markdown]으로 파싱해서 그 문자열에 해당하는 HTML을 반환하는 코드가 있어요.
이 코드는 알아보기 어렵게 작성되어 있고 따라가기도 힘들지만, 어찌 된 일인지 잘 동작하고 모든 테스트도 통과해요!
도전 과제는 이 코드를 더 읽기 쉽고 유지보수하기 쉽게 다시 작성하는 거예요. 그러면서 모든 테스트가 계속 통과하는지도 확인해야 하죠.

리팩터링하면서 한 일을 주석으로 메모해 두면 리뷰하는 사람이 어떤 작업을 했는지 볼 수 있어서 도움이 되지만, 꼭 필요한 건 아니에요.
가장 중요한 건 코드를 더 낫게 만드는 거예요!

[markdown]: https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax
