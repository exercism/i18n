# 개요

값의 스코프는 프로그램에서 그 값에 접근할 수 있는 위치와 관련이 있어요.

## 스코프의 네 가지 종류: 블록, 함수, 함수 프로토타입, 파일

### 블록 스코프

블록 스코프를 가진 값은 그것이 정의된 블록 안에서만 접근할 수 있어요. 블록에 대해 더 알고 싶다면 [블록 개념](../blocks/introduction.md#Introduction)을 참고해요.

### 함수 스코프

함수 스코프는 `goto`문에 사용되는 레이블에 적용되는 특별한 종류의 스코프예요. 이름이 같은 두 레이블은 함수 안의 서로 다른 블록에 정의되어 있더라도 같은 함수에서 사용할 수 없어요.

### 함수 프로토타입 스코프

함수 프로토타입 스코프는 프로토타입(선언이라고도 하는데, 모든 선언이 프로토타입은 아니라는 점을 기억해요) 안에 이름이 붙은 매개변수에만 적용되는 또 다른 특별한 종류의 스코프예요.
함수 선언에서 매개변수 이름은 보통 생략할 수 있어요.
이름의 스코프는 선언 안에서만 의미가 있어요.
다음 예제에서 `len` 식별자는 정의된 다음 함수 선언의 뒷부분에서 참조돼요.

```c
#include <stdio.h>

// len is defined and then referred to
void my_func(int len, int numbers[len]);

int main() {
    int numbers[2];
    numbers[0] = 1;
    numbers[1] = 2;
    my_func(2, numbers);
}

void my_func(int length, int numbers[length]) {
    // prints numbers should have 2 elements
    printf("numbers should have %d elements", length);
}
```

선언 안에서 같은 변수를 참조할 때는 이름이 서로 맞아야 한다는 점에 주목해요.
만약 `my_func`가 `void my_func(int len, int numbers[length]);`로 선언되었다면, 다음과 비슷한 컴파일 오류가 발생해요.

```
/tmp/scn62kKPEZ.c:4:35: error: 'length' undeclared here (not in a function)
    3 | void my_func(int len, int numbers[length]);
      |                                   ^~~~~~
/tmp/scn62kKPEZ.c: In function 'main':
/tmp/scn62kKPEZ.c:10:16: error: type of formal parameter 2 is incomplete
   10 |     my_func(2, numbers);
```

함수 정의에서는 함수 선언에 사용한 매개변수와 같은 이름을 쓸 필요가 없어요.
위 예제에서는 선언에 `len`을 사용했고 정의에는 `length`를 사용했는데, 이는 `len` 식별자의 스코프가 함수 선언 안에만 있었다는 것을 보여줘요.

### 파일 스코프

파일 스코프를 가진 값은 파일 어디에서나 접근할 수 있어요.
그런 값은 모두 함수 밖에서 정의돼요.
