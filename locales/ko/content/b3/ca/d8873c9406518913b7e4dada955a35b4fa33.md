# 소개

Common Lisp에서도 다른 언어들처럼 배열은 정수 인덱스로 접근하는 원소들의 집합이에요.
원소의 타입은 서로 달라도 돼요.
배열은 다차원일 수 있어요 (단순히 1차원이 아닐 수도 있어요).

## 만들기

`make-array`로 배열을 만들 수 있어요.
옵션이 많지만, 간단한 형태로는 모든 원소를 하나의 값으로 초기화한 N차원 배열을 만들거나, 다른 시퀀스(예: 리스트)의 값으로 배열을 초기화할 수 있어요. 
첫 번째 인자는 각 차원의 크기를 나타내는 리스트예요.

```lisp
(make-array '(4) :initial-element 3)    ; => #(3 3 3 3)
(make-array '(2 2) :initial-element 'x) ; => #2A((X X) (X X))
```

(N차원 배열이 차원 수와 함께 출력되는 방식에 주목해 봐요.)

배열은 출력되는 형식 그대로 사용해서 만들 수도 있어요: 

```lisp
#(x y z)         ; => #(X Y Z)
#2A((1 2) (3 4)) ; => #2A((1 2) (3 4))
```

## 원소 접근하기

벡터의 원소에 접근하려면 `aref`를 사용해요. 인덱스는 0부터 시작해요. 
제공하는 인덱스 개수는 배열의 차원 수와 일치해야 해요.

```lisp
(aref #2A((1 2 3) (3 4 5)) 
       1 0)           ; => 3
(aref #3A(((a b) (c d)) 
           ((e f) (g h)) 
           ((t u) (v w))) 
       2 0 1)         ; => U
(aref #2A((1) (2)) 0) ; => ERROR (because not enough indexes provided)
```
