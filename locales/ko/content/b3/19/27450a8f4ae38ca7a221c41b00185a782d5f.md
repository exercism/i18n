# `for`문

루프는 프로그래밍의 기본 개념으로, 같은 코드 블록을 여러 번 실행할 수 있게 해줘요.
Swift에는 `for-in`문과 `while`문, 두 가지 종류의 루프가 있어요.
이번 장에서는 `for-in`문에 대해 알아봐요.

`for`문을 사용하면 값의 시퀀스를 순회할 수 있어요. 이때 각 원소를 차례로 꺼내 원하는 변수에 담아요.
Swift에서는 범위, 배열, 문자열을 비롯한 다양한 시퀀스를 순회할 수 있어요(더 많은 타입은 나중에 다뤄요).
시퀀스의 모든 원소를 순회하고 나면 루프가 끝나요.

`for`문은 `for` 키워드, 변수 이름, `in` 키워드, 그리고 순회할 값의 시퀀스를 차례로 써서 선언해요.
`for-in`문에서 주어지는 변수는 불변이에요. 즉, 루프 안에서 그 값을 바꿀 수 없어요.
다음은 숫자 배열을 순회하는 `for-in`문의 예시예요:

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
  print(number)
}
print("Done with numbers")

// prints:
// 3
// 10
// 7
// 11
// Done with numbers
```

~~~~exercism/note
`number` 변수는 `for-in`문 안에서 선언되고, 루프의 스코프 안에서만 사용할 수 있어요.

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
    number + 1
}
number + 1
// Error: Use of unresolved identifier 'number'
```
~~~~

## 범위 순회하기

`for-in`문으로 숫자 범위를 순회할 수도 있어요.
이렇게 하면 코드 블록을 정해진 횟수만큼 실행할 수 있어요. 예를 들어 `1...5` 범위는 1, 2, 3, 4, 5를 순회하므로 루프가 5번 실행돼요.
배열 같은 자료 구조에서 인덱스를 순회하고 싶을 때는 `0..<array.count` 범위를 사용하면 돼요.

```swift
let numbers = [3, 10, 7, 11]

for i in 0..<numbers.count {
  print(numbers[i])
}

// prints:
// 3
// 10
// 7
// 11
```

## 문자열 순회하기

`for-in`문으로 문자열을 순회할 수도 있어요.
이렇게 하면 문자열의 각 문자를 순회할 수 있어요. 이때 루프에서 받는 값의 타입이 `Character`라는 점에 특히 주목해요.

```swift
let message = "Hello!"

for character in message {
  print(character)
}

// prints:
// H
// e
// l
// l
// o
// !
```

## stride

Swift는 특정 간격으로 범위를 순회하는 시퀀스를 만들어 주는 `stride` 함수도 제공해요.
이 시퀀스는 `for-in`문으로 순회할 수 있어요.
`stride`는 [`stride(from:to:by:)`][stride-to] 또는 [`stride(from:through:by:)`][stride-through]로 정의되는데, 첫 번째는 끝 값을 포함하지 않고 두 번째는 끝 값을 포함해요.

```swift
for i in stride(from: 0, to: 10, by: 2) {
  print(i)
}

// prints:
// 0
// 2
// 4
// 6
// 8
```

`to` 매개변수는 끝 값을 포함하지 않으므로 루프는 `to` 매개변수 바로 앞 숫자까지 순회해요. 반면 `through` 매개변수는 끝 값을 포함하므로 이 경우에는 `10`도 포함돼요.

[stride-to]: https://developer.apple.com/documentation/swift/stride(from:to:by:)
[stride-through]: https://developer.apple.com/documentation/swift/stride(from:through:by:)
[for-loops]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
