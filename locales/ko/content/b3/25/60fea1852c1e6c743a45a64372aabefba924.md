# 지침

이 연습 문제에서는 좋아하는 요리책에 나오는 근사한 라자냐를 만드는 데 도움이 될 코드를 작성해요.

라자냐를 만드는 데 걸리는 시간과 관련된 다섯 가지 과제가 있어요.

## 1. 예상 오븐 시간을 분 단위로 정의해요

`expectedMinutesInOven` 불변 변수를 정의해요. 이 변수는 라자냐를 오븐에 몇 분 동안 넣어 두어야 하는지를 값으로 가져요. 이 변수는 내보내야 해요. 요리책에 따르면 예상 오븐 시간은 40분이에요:

```nim
nim> expectedMinutesInOven
40 == type int
```

## 2. 남은 오븐 시간을 분 단위로 계산해요

라자냐가 지금까지 오븐에 있던 실제 시간(분)을 매개변수로 받아서, 이전 과제에서 구한 예상 오븐 시간을 기준으로 라자냐가 오븐에 앞으로 몇 분 더 있어야 하는지 반환하는 `remainingMinutesInOven` 프로시저를 구현해요.

```nim
nim> remainingMinutesInOven(30)
10 == type int
```

## 3. 준비 시간을 분 단위로 계산해요

라자냐에 넣은 층 수를 매개변수로 받아서, 라자냐를 준비하는 데 몇 분이 걸렸는지 반환하는 `preparationTimeInMinutes` 프로시저를 구현해요. 각 층을 준비하는 데 2분씩 걸린다고 가정해요.

```nim
nim> preparationTimeInMinutes(2)
4 == type int
```

## 4. 총 작업 시간을 분 단위로 계산해요

매개변수 두 개를 받는 `totalTimeInMinutes` 프로시저를 구현해요. `numberOfLayers` 매개변수는 라자냐에 넣은 층 수이고, `actualMinutesInOven` 매개변수는 라자냐가 오븐에 있던 시간(분)이에요.
이 프로시저는 라자냐 요리에 총 몇 분을 들였는지 반환해야 해요. 이는 준비 시간(분)과 현재까지 라자냐가 오븐에 있던 시간(분)을 더한 값이에요.

```nim
nim> totalTimeInMinutes(3, 20)
26 == type int
```
