# 안내

이 연습 문제에서는 차량 구매를 준비하는 데 도움이 되는 코드를 작성해요.

과제는 세 가지예요. 운전면허가 필요한지 판단하는 것, 두 차량 중에서 하나를 고르는 것, 그리고 중고 차량의 적정 가격을 추정하는 것이에요.

## 1. 운전면허가 필요한지 판단하기

일부 차량은 운전하려면 운전면허가 필요해요.
`car`와 `truck` 종류만 면허가 필요하고, 나머지는 모두 면허 없이 운전할 수 있다고 가정해요.

차량의 종류를 받아서 그 종류의 차량에 면허가 필요한지 여부를 불리언으로 반환하는 `needs_license(kind)` 함수를 구현해요.

```R
needs_license("car");
# => TRUE

needs_license("bike");
# => FALSE
```

## 2. 구매할 두 차량 중 하나 고르기

구매할 수 있는 차량들을 살펴봐요.
두 가지 선택지까지 좁혔지만, 최종 결정을 내리려면 도움이 필요해요.
이를 위해 두 차량을 인자로 받아서, 사전 순서에서 앞서는 쪽을 그대로 결정으로 반환하는 `choose_vehicle(option1, option2)` 함수를 구현해요.

```R
choose_vehicle("Wuling Hongguang", "Toyota Corolla");
# =>  "Toyota Corolla"

choose_vehicle("Volkswagen Beetle", "Volkswagen Golf");
# =>  "Volkswagen Beetle"
```

## 3. 중고 차량의 가격 추정하기

이제 결정을 내렸으니, 대리점에서 공정한 가격을 지불하는지 확인하고 싶어요.
중고 차량 구매에 관심이 있으니, 가격은 차량의 연식에 따라 달라져요.
대략적인 추정치로, 차량이 3년 미만이면 새 차였을 때 원래 가격의 80%라고 가정해요.
10년이 넘으면 50%예요.
차량이 3년 이상이지만 10년을 넘지 않으면 원래 가격의 70%예요.

`calculate_resale_price(original_price, age)` 함수를 구현해요.
원래 가격과 차량의 연식을 인자로 받아서 대리점에서의 예상 가격을 반환해요.

```R
calculate_resale_price(1000, 1);
# => 800

calculate_resale_price(1000, 5);
# => 700

calculate_resale_price(1000, 15);
# => 500
```
