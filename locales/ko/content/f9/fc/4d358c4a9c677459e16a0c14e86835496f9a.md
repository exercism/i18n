# 지시 사항

이 연습 문제에서는 좋아하는 요리책에 나오는 근사한 라자냐를 만드는 데 도움이 되는 코드를 작성해 봐요.

라자냐를 조리하는 데 드는 시간과 관련된 다섯 개의 과제가 있어요.

## 1. 예상 오븐 조리 시간(분) 정의하기

`Lasagna` 클래스에 `expectedCookTime` 함수를 구현해요. 이 함수는 인자를 받지 않고, 라자냐를 오븐에 몇 분 동안 넣어 두어야 하는지 반환해요.
요리책에 따르면 예상 오븐 조리 시간은 40분이에요.

```php
<?php
$timer = new Lasagna();
$timer->expectedCookTime()
// => 40
```

## 2. 남은 오븐 조리 시간(분) 계산하기

`Lasagna` 클래스에 `remainingCookTime` 함수를 구현해요. 이 함수는 라자냐가 지금까지 오븐에 있던 실제 시간(분)을 인자로 받고, 이전 과제에서 구한 예상 오븐 조리 시간을 기준으로 라자냐가 오븐에 몇 분 더 있어야 하는지 반환해요.

```php
<?php
$timer = new Lasagna();
$timer->remainingCookTime(30)
// => 10
```

## 3. 준비 시간(분) 계산하기

`Lasagna` 클래스에 `totalPreparationTime` 함수를 구현해요. 이 함수는 라자냐에 넣은 층의 개수를 인자로 받고, 층 하나를 준비하는 데 2분이 걸린다고 가정했을 때 라자냐를 준비하는 데 몇 분이 걸렸는지 반환해요.

```php
<?php
$timer = new Lasagna();
$timer->totalPreparationTime(3)
// => 6
```

## 4. 총 작업 시간(분) 계산하기

`Lasagna` 클래스에 `totalElapsedTime` 함수를 구현해요. 이 함수는 두 개의 인자를 받아요. 첫 번째 인자는 라자냐에 넣은 층의 개수이고, 두 번째 인자는 라자냐가 오븐에 있던 시간(분)이에요.
이 함수는 라자냐를 조리하는 데 총 몇 분을 들였는지 반환해야 해요. 이는 준비 시간(분)과 그 순간까지 라자냐가 오븐에 있던 시간(분)을 더한 값이에요.

```php
<?php
$timer = new Lasagna();
$timer->totalElapsedTime(3, 20)
// => 26
```

## 5. 라자냐가 완성되었다는 알림 만들기

`Lasagna` 클래스에 `alarm` 함수를 구현해요. 이 함수는 인자를 받지 않고, 라자냐를 먹을 준비가 되었다는 메시지를 반환해요.

```php
<?php
$timer = new Lasagna();
$timer->alarm()
// => "Ding!"
```
