# 소개

[SQLite][sqlite]는 오픈 소스이고 가벼우며, 서버가 필요 없고, 자체 완결형인 [관계형 데이터베이스][relational-database] 관리 시스템이에요.
단순함과 사용하기 쉬움, 설정이 전혀 필요 없다는 점으로 잘 알려져 있어요.
SQLite는 애플리케이션 안에 내장할 수 있어서 앱, 임베디드 시스템, 중소 규모 프로젝트에 이상적인 선택이에요.

[D. Richard Hipp][hipp]이 만들었고, SQLite는 신뢰할 수 있는 트랜잭션을 돕기 위한 [ACID][acid] 속성을 따라요.
최소한의 설치 공간과 효율적인 성능 덕분에 다양한 산업에서 널리 쓰여요.

SQLite는 데이터베이스를 정의하고 다루기 위해 간결한 SQL 기반 문법을 사용해요.
테이블, 인덱스, 쿼리는 표준 SQL 문으로 만들어져서, 개발자가 익숙하고 표현력 있는 방식으로 데이터베이스를 관리할 수 있게 해줘요.
데이터베이스 엔진은 자체 완결형이라 별도의 서버 프로세스가 필요 없어요.
이런 단순함이 강력한 기능과 어우러져, 사용하기 쉽고 효율을 우선하는 프로젝트에 SQLite는 훌륭한 선택이 돼요.

자세한 정보와 문서는 [공식 SQLite 문서][sqlite docs]를 참고해요.
또한 커뮤니티에서는 모든 수준의 사용자를 지원하기 위해 튜토리얼, 자주 묻는 질문 등 다양한 자료를 제공해요.
