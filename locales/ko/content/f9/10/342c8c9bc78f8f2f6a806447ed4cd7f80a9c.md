# 소개

*quotation*은 `[ ]` 괄호 안에 들어 있는 code 조각이에요. 이것은 값이라서 스택에 올리거나, 다른 단어에 넘기거나, 배열에 저장할 수 있어요.

```factor
[ 1 + ] .          ! => [ 1 + ]
5 [ 1 + ] call .   ! => 6
```

대부분의 고차 단어는 두 번째 인자로 quotation을 받아요:

```factor
{ 1 2 3 } [ sq ] map .    ! => { 1 4 9 }
{ 1 2 3 } [ even? ] filter .  ! => { 2 }
```

quotation의 본문은 그냥 평범한 Factor code예요. 다른 곳에서 쓰는 것과 똑같은 연산자와 스택 효과를 사용해요.

데이터로 code를 만들 때, 조각을 이어 붙이거나 토큰을 연산에 대응시킬 때, 그 결과는 시퀀스예요. 이걸 호출할 수 있게 만들려면 `>quotation`에 넘겨 주면 돼요.

```factor
{ [ 1 ] [ 2 + ] [ 3 * ] } concat >quotation call .   ! => 9
```
