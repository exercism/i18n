# 소개

_if/else_문과 마찬가지로, `switch`문도 조건에 따라 코드를 실행해서 프로그램의 흐름을 바꿀 수 있어요.
차이점은 `switch`문은 원시 타입이나 문자열 표현식의 값을 미리 정의된 상수 값과 비교할 수만 있다는 거예요.

`switch`문을 사용할 때 알아두면 유용한 키워드가 몇 가지 있어요.

- `switch`: 이 키워드는 `switch`문의 구조를 선언할 수 있게 해줘요.
  뒤에는 결과를 바꿀 표현식이나 변수가 와요.
- `case`: 이 키워드는 결과가 될 수 있는 여러 경우를 선언할 때 사용해요.
- `break`: `break` 키워드는 원하는 흐름이 끝나는 지점에서 `switch`문의 실행을 멈출 때 아주 유용해요.
  이걸 빠뜨리면 프로그램이 계속 실행되면서 예상치 못한 결과를 낳을 수 있어요.
- `default`: 이름 그대로, 다른 어떤 `case`도 표현식의 결과와 일치하지 않을 때 기본 결과로 사용해요.

가장 단순한 형태에서는 원시 타입이나 문자열 표현식을 검사하고, 그 값을 바탕으로 결정을 내려요.
예를 들면 다음과 같아요.

```java
String direction = getDirection();
switch (direction) {
    case "left":
        goLeft();
        break;
    case "right":
        goRight();
        break;
    default:
        // otherwise
        markTime();
        break;
}
```
