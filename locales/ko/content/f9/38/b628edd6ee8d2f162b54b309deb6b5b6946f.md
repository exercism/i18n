# 힌트

## 1. 피자 가격 계산하기

- 해당 추가 토핑이 없는 피자의 가격에 추가 옵션 하나의 가격을 더한 값을 반환하는 재귀 함수를 만들어요.
- `Maximum call stack size exceeded` 오류가 발생하면, 기본 조건을 빠뜨리지 않았는지 확인해요.
- `Memory Allocation Error`가 발생하면, 토핑이 담긴 입력 배열을 직접 수정하지 않고 복사하고 있지는 않은지 확인해요.

## 2. 주문 총액 계산하기

- `pizzaPrice`를 사용해 배열에 있는 각 피자의 가격을 계산하고, 합계에 더해요.
- `Maximum call stack size exceeded` 오류가 발생하고 테스트가 두 개 이상 실패한다면, 기본 조건을 빠뜨리지 않았는지 확인해요. 테스트가 하나만 실패한다면, 루프를 사용해 구현해 봐요!
- `Memory Allocation Error`가 발생하면, 입력 배열을 직접 수정하지 않고 복사하고 있지는 않은지 확인해요.
