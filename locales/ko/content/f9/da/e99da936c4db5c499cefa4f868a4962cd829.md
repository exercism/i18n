# 소개

이 연습 문제는 [Cargo Shuffle][cargo-shuffle]에서 만난 데이터 스택과 스택 효과 표기법을 바탕으로 해요. 여기서는 불리언 값을 결합하는 워드를 작성해요.

## 셔플 워드

가장 흔한 셔플 워드는 [`kernel`][kernel]에 있어요:

```
dup    ( x -- x x )
dupd   ( x y -- x x y )
drop   ( x -- )
swap   ( x y -- y x )
swapd  ( x y z -- y x z )
over   ( x y -- x y x )
pick   ( x y z -- x y z x )
rot    ( x y z -- y z x )
-rot   ( x y z -- z x y )
rotd   ( w x y z -- w y z x )
spin   ( x y z -- z y x )
nip    ( x y -- y )
tuck   ( x y -- y x y )

2dup   ( x y -- x y x y )
3dup   ( x y z -- x y z x y z )
4dup   ( w x y z -- w x y z w x y z )
2drop  ( x y -- )
3drop  ( x y z -- )
4drop  ( w x y z -- )
2nip   ( x y z -- z )
2swap  ( x y z w -- z w x y )
```

## 불리언

두 불리언 리터럴은 `t`와 `f`예요. `f`는 Factor에서 유일하게 거짓으로 취급되는 값이에요. `0`과 빈 컬렉션을 포함한 나머지 값은 모두 참으로 취급해요.

```factor
t .    ! => t
f .    ! => f
```

## 불리언 워드

`kernel` 보캐블러리에 있는 세 가지 불리언 워드예요:

```
and ( x y -- ? )    ! true when both inputs are truthy
or  ( x y -- ? )    ! true when either input is truthy
not ( x   -- ? )    ! inverts its argument
```

```factor
t t and .    ! => t
t f and .    ! => f
f t or .     ! => t
t not .      ! => f
```

각 출력의 `?`는 '불리언'을 나타내는 스택 효과 관례예요.

아래 과제 중 하나에서는 `swap`이 필요해요.
