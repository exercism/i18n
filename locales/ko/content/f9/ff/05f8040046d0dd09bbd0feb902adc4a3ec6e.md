# 개요

불리언 표현식은 하나 이상의 값에 던지는 질문으로, `true` 또는 `false`로 답할 수 있어요.
참인 표현식은 `1`을 반환하고, 거짓인 표현식은 `0`을 반환해요.
숫자에도 참/거짓 값이 있어요. 0은 `false`이고, 0이 아니면 `true`예요.

예전 C 코드에서는 불리언 값에 `int` 타입을 직접 사용하거나, 프로그래머가 `TRUE`와 `FALSE` 같은 상수를 정의해서 `1`과 `0`을 불리언 표현에 대응시키기도 했어요.

C99 버전에서는 `_Bool` 타입이 추가됐어요.
`stdbool.h` 헤더 파일은 세 가지 새로운 불리언 기호를 정의해요: `bool`, `true`, `false`.
`true`는 `1`에, `false`는 `0`에, `bool`은 `_Bool`에 대응돼요.
이제 프로그래머는 `int`를 직접 쓰거나 불리언 대응을 직접 만들지 않고도, `stdbool.h`를 포함해서 코드에서 불리언 기호를 자동으로 사용할 수 있어요.

## 비교 연산자

C는 여섯 가지 비교 연산자를 지원해요: `==`(같음), `!=`(같지 않음), `>`(큼), `<`(작음), `>=`(크거나 같음), `<=`(작거나 같음).
이 연산자들은 값 사이의 관계를 비교해 불리언 값으로 결과를 내요.

```c
0 == 0 // true. Although 0 is false, 0 equals 0 is true.
0 != 0 // false
1 > 0 // true
1 < 0 // false
1 >= 0 // true
1 <= 0 // false
```

## 불리언 연산자

C는 세 가지 불리언 연산자를 지원해요: `||`(또는), `&&`(그리고), `!`(아님).

`!`는 피연산자 하나와 함께 사용해요.
피연산자의 불리언 값을 뒤집어요.
예를 들어 `0`은 `false`지만, `!0`은 `true`예요.

`||`와 `&&`는 피연산자 두 개와 함께 사용해요.
왼쪽 피연산자만으로는 표현식의 결과가 정해지지 않을 때에만 오른쪽 피연산자를 평가해요.
즉, `||`는 왼쪽 피연산자가 `false`로 평가될 때에만 오른쪽 피연산자를 평가해요.
`&&`는 왼쪽 피연산자가 `true`로 평가될 때에만 오른쪽 피연산자를 평가해요.


## 단락 평가

모든 피연산자를 평가하지 않는 것을 "단락 평가"라고 해요.
단락 평가는 특정 상황을 처리하는 간결하고 강력한 방법이에요.
예를 들어, 포인터가 `NULL`이 아닌지 확인하고(&&), `NULL`이 아니라면 그 포인터를 역참조하는 방식은 흔히 쓰이는 관용구예요. 이렇게 하면 `NULL` 포인터를 역참조하는 일을 피할 수 있어요.
하지만 단락 평가는 bug로 이어지기도 해요.
프로그래머는 `||`나 `&&`의 오른쪽 피연산자가 항상 평가되지는 않는다는 사실을 가끔 잊어버려요.
오른쪽 피연산자가 항상 일어날 것이라고 기대한 부수 효과가 있는 표현식이라면, 왼쪽 피연산자의 불리언 값에 따라 bug가 생겨요.


## 불리언 표현식 반환하기

불리언 표현식의 결과는 그대로 반환할 수 있어요.
예를 들어, 다음 `if`문은

```c
if (count > 0)
    return true;
else
    return false;
end
```

다음처럼 바꿀 수 있어요.

```c
return count > 0;
```
