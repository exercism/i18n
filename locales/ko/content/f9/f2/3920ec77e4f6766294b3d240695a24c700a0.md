Elixir에는 고유한 이름 규칙이 있어요. [가드 절에서 사용할 수 있으면서 불리언을 반환하는 검사](https://hexdocs.pm/elixir/naming-conventions.html#is_-prefix-is_foo)의 이름을 어떻게 짓는지도 여기에 포함돼요:

> 가드 절에서 허용되는 타입 검사와 기타 불리언 검사는 이름 앞에 `is_`를 붙여요.

이런 종류의 검사에는 몇 가지 내장 함수와 매크로, 가드가 포함돼요.

```elixir
# this is the expected name for checks that return booleans and are valid in guard clauses

%{expected}

# this is the current name

%{actual}
```
가드 절에서 사용할 수 없는 불리언을 반환하는 함수와 매크로는 다른 규칙을 따라 이름 뒤에 `?`를 붙여요(`def foo?`, `defmacro foo?`). 이 두 규칙을 섞어 쓰면 안 돼요.
