# 소개

Cairo의 함수를 사용하면 코드를 재사용할 수 있는 단위로 묶을 수 있어서, 프로그램이 더 모듈화되고 이해하기 쉬워져요.
Cairo의 함수는 `fn` 키워드, 그 뒤에 오는 함수 이름, 괄호 안의 매개변수 목록, 그리고 함수가 하는 일을 정의하는 코드 블록으로 이루어져 있어요.

## 함수 매개변수

Cairo에서는 모든 함수 매개변수에 타입을 명시해야 해요.
일부 언어와 달리 Cairo는 타입을 추론하지 않고, 매개변수의 기본값도 없어서 모든 매개변수가 필수예요.

```rust
// Function with no parameters
fn print_hello() {
    // Function body
}

// Function with two parameters
fn print_greeting_name(greeting: ByteArray, name: ByteArray) {
    // Function body
}
```

## 매개변수와 인자

`parameters`와 `arguments`를 구분하는 것은 중요해요:

- **매개변수**는 함수 정의에서 사용하는 변수 이름이에요. 예를 들어 `print_greeting_name` 함수의 `greeting`과 `name`이 있어요.
- **인자**는 함수를 호출할 때 함수에 실제로 전달하는 값이에요.

```rust
// Calling the function with arguments
print_greeting_name(123, 456)
```

## 문과 표현식

함수의 본문은 일련의 문으로 이루어져 있고, 마지막에 표현식이 올 수도 있어요.

- 문은 어떤 동작을 수행하고 값을 반환하지 않는 지시예요.
- 표현식은 평가되어 어떤 값이 돼요.

`let` 키워드로 변수를 만들고 값을 할당하는 것은 문이에요.

```rust
let y = 6;
```

하지만 위 문에서 `6`은 값 `6`으로 평가되는 표현식이에요.

함수를 호출하는 것은 항상 어떤 값으로 평가되므로 표현식이에요. 반환 값을 명시했다면 그 값으로, 그렇지 않으면 '유닛' 타입 `()`으로 평가돼요.

## 반환 값

Cairo 함수는 자신을 호출한 코드에 값을 반환할 수 있어요.
반환 값은 매개변수 뒤에 화살표 `->`로 구분해서 적어요.
Cairo에서 함수의 반환 값은 함수 본문 블록의 마지막 표현식 값과 같아요.
`return` 키워드와 값을 지정하면 함수에서 일찍 반환할 수도 있어요.

```rust
// Function returning the last (and only) expression
fn hello(name: ByteArray) -> ByteArray {
    "Hello " + name
}

// Function returning using the `return` keyword
fn double_if_even(value: u32) -> u32 {
    if value % 2 == 0 {
        return value * 2;
    }
    return value;
}
```

## 함수 호출

Cairo에서 함수를 호출하려면 함수 이름을 쓰고 뒤에 괄호 안에 인자를 넣으면 돼요.

```rust
// Calling a function with no parameters
print_hello()

// Calling a function with one parameter
let greeting = hello("John")

// Calling a function with multiple parameters
print_greeting_name("Howdy", "Joel")
```
