# 지침

이번 연습 문제에서는 좋아하는 요리책에 나오는 근사한 라자냐를 준비하고 요리하는 것과 관련된 코드를 조금 더 작성해 봐요.

과제는 네 개예요.
첫 번째는 요리 자체에 관한 것이고, 나머지 세 개는 완벽한 준비에 관한 거예요.

## 1. 준비 시간 예측하기

다음에 만들 라자냐를 위해, 요리를 즐길 수 있도록 충분한 시간을 확보해 두고 싶어요.
라자냐에 어떤 층을 넣을지는 이미 계획해 두었어요.
이제 그것을 바탕으로 준비에 얼마나 걸릴지 추정하려고 해요.

층 목록을 `[]string`으로, 층당 평균 준비 시간(분)을 `int`로 받는 함수 `PreparationTime`을 구현해요.
이 함수는 층 수를 기준으로 계산한 전체 준비 시간의 추정값을 `int`로 반환해야 해요.
Go에는 함수의 기본값이 없어요.
평균 준비 시간이 `0`(`int`의 기본 초깃값)으로 전달되면 기본값 `2`를 사용해야 해요.

```go
layers := []string{"sauce", "noodles", "sauce", "meat", "mozzarella", "noodles"}
PreparationTime(layers, 3)
// => 18
PreparationTime(layers, 0)
// => 12
```

## 2. 필요한 면과 소스의 양 계산하기

시간을 확보하는 것 외에도, 꿈에 그리던 라자냐를 만들 수 있을 만큼 소스와 면이 충분한지 확인하고 싶어요.
라자냐에 면 층이 하나 있을 때마다 면 50그램이 필요해요.
소스 층이 하나 있을 때마다 소스 0.2리터가 필요해요.

층 목록을 매개변수로 `[]string` 형식으로 받는 함수 `Quantities`를 정의해요.
이 함수는 요리를 만드는 데 필요한 면과 소스의 양을 계산해요.
결과는 `noodles`를 `int`로, `sauce`를 `float64`로 하는 두 개의 값으로 반환해야 해요.

```go
Quantities([]string{"sauce", "noodles", "sauce", "meat", "mozzarella", "noodles"})
// => 100, 0.4
```

## 3. 비밀 재료 추가하기

얼마 전에 친구를 방문해서 그곳에서 라자냐를 먹었어요.
정말 훌륭했고 뭔가 특별한 맛이 났어요.
친구가 재료 목록을 보내 주면서, 목록의 마지막 항목이 그 요리를 그렇게 특별하게 만든 "비밀 재료"라고 알려 줬어요.
이제 그 비밀 재료를 내 레시피에도 넣고 싶어요.

`[]string` 형식의 재료 목록 두 개를 매개변수로 받는 함수 `AddSecretIngredient`를 작성해요.
첫 번째 매개변수는 친구가 보내 준 목록이고, 두 번째는 내 레시피의 재료 목록이에요.
내 재료 목록의 마지막 원소는 항상 `"?"`예요.
이 함수는 그 원소를 친구 목록의 마지막 항목으로 바꿔야 해요.
**참고:** `AddSecretIngredient`는 아무것도 반환하지 않아요. 내 재료 목록을 직접 수정해야 해요.
친구의 재료 목록은 **수정하면 안 돼요**.
또한 `slice`는 함수에 포인터로 전달되기 때문에, `AddSecretIngredient`에 전달된 두 `[]string` 인자를 변경하면 그대로 반영돼요.

```go
friendsList := []string{"noodles", "sauce", "mozzarella", "kampot pepper"}
myList := []string{"noodles", "meat", "sauce", "mozzarella","?"}

AddSecretIngredient(friendsList, myList)
// myList => []string{"noodles", "meat", "sauce", "mozzarella", "kampot pepper"}
```

## 4. 레시피 양 조절하기

요리책에 적힌 양은 두 인분 정도의 라자냐밖에 만들지 못해요.
다음에는 더 많은 사람을 위해 요리하고 싶으니, 인분 수에 따라 필요한 양을 계산하려고 해요.

매개변수 두 개를 받는 함수 `ScaleRecipe`를 구현해요.

- 2인분에 필요한 양을 담은 `float64` 슬라이스예요.
- 만들고 싶은 인분 수예요.

이 함수는 원하는 인분 수에 필요한 양을 담은 `float64` 슬라이스를 반환해야 해요.
다만 원래 레시피는 그대로 두고 싶어요.
즉, 이 함수 안에서 `quantities` 인자는 수정되면 안 돼요.

```go
quantities := []float64{ 1.2, 3.6, 10.5 }
scaledQuantities := ScaleRecipe(quantities, 4)
// => []float64{ 2.4, 7.2, 21 }
```
