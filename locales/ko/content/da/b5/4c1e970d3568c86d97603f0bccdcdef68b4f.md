# Break, Continue

반복하거나 순회하는 제어 구조를 사용할 때, `break`와 `continue` 키워드는 프로그램의 흐름을 제어하는 데 도움을 줘요.
`break` 키워드는 루프 문맥을 빠져나와 바깥 스코프로 이동하면서 루프를 종료해요.
`continue` 키워드는 현재 반복의 나머지 부분을 건너뛰고, 다음 반복이 시작되는 지점에서 루프를 다시 시작해요.
흔하지는 않지만, 키워드에 숫자를 함께 지정해서 문맥을 몇 개나 빠져나갈지, 또는 다음 반복까지 건너뛸지 제어할 수 있어요.

```php
<?php
$i = 1;
while ($i <= 10) {

    if ($i <= 5) {
        i += 1;
        continue;
    }
    break;
}
```

앞의 예제에서는 `continue`가 다섯(5) 번 실행되지만, 여섯 번째(6) 반복에서 `break`가 실행되어 코드가 루프를 빠져나가요.
