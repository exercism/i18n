# 지침

기본 Take-A-Number 기계는 판매가 아주 잘 되고 있었지만, 시중에 나와 있는 다른 모델들에 비해 고급 기능이 부족하다고 불만을 제기하는 사용자들이 있었어요.

제조사는 사용자 피드백을 반영해 더 많은 기능을 갖춘 디럭스 모델을 출시하기로 했고, 여러분은 다시 한번 이 기계의 소프트웨어를 작성하는 일을 맡게 됐어요.

디럭스 모델에 추가된 새로운 기능은 다음과 같아요:
- 현재 대기 중인 번호 추적
- 최소 및 최대 번호 설정. 이를 통해 한 시설의 서로 다른 부서에 고객을 대기시키기 위해 여러 대의 디럭스 Take-A-Number 기계를 사용할 수 있고, 번호 범위로 부서를 구분할 수 있어요.
- 특정 번호가 대기열을 건너뛰어 임산부와 어르신에게 우선 서비스를 제공할 수 있도록 하는 기능
- 실수로 주말 내내 기계를 켜 두어 에너지를 낭비하는 것을 막는 자동 종료

기계의 비즈니스 로직은 동료가 이미 구현해 두었고, `TakeANumberDeluxe.State` 모듈에서 찾을 수 있어요. 이제 여러분의 과제는 이 로직을 `GenServer`로 감싸는 것이에요.

## 1. 기계 시작하기

`TakeANumberDeluxe` 모듈에서 `GenServer` behaviour를 사용해요.

`start_link/1` 함수와 필요한 `GenServer` 콜백을 구현해요.

`start_link/1`에 전달되는 인자는 키워드 리스트예요. 여기에는 `:min_number`와 `:max_number` 키가 들어 있어요. 이 키들의 값은 `TakeANumberDeluxe.State.new/2` 함수에 전달해야 해요.

`TakeANumberDeluxe.State.new/2`가 `{:ok, state}` 튜플을 반환하면, 반환된 상태를 자신의 상태로 사용해 기계가 시작되어야 해요. 대신 `{:error, error}` 튜플을 반환하면, 반환된 오류를 종료 이유로 삼아 기계가 중지되어야 해요.

```elixir
TakeANumberDeluxe.start_link(min_number: 1, max_number: 9)
# => {:ok, #PID<0.174.0>}

TakeANumberDeluxe.start_link(min_number: 9, max_number: 1)
# => {:error, :invalid_configuration}
```

`TakeANumberDeluxe.State.new/2` 함수가 선택적인 세 번째 인자 `auto_shutdown_timeout`도 받는다는 걸 눈치챘을 수도 있어요. 이 인자는 이 연습 문제의 마지막 단계에서 사용할 거예요.

## 2. 기계 상태 보고하기

`report_state/1` 함수와 필요한 `GenServer` 콜백을 구현해요. 기계는 호출자에게 현재 상태를 응답해야 해요.

```elixir
{:ok, machine} = TakeANumberDeluxe.start_link(min_number: 1, max_number: 10)
TakeANumberDeluxe.report_state(machine)
# => %TakeANumberDeluxe.State{
#      max_number: 10,
#      min_number: 1,
#      queue: %TakeANumberDeluxe.Queue{in: [], out: []},
#      auto_shutdown_timeout: :infinity,
#    }
```

## 3. 새 번호 대기열에 넣기

`queue_new_number/1` 함수와 필요한 `GenServer` 콜백을 구현해요.

기계의 현재 상태를 가지고 `TakeANumberDeluxe.State.queue_new_number/1` 함수를 호출해야 해요.

`TakeANumberDeluxe.State.queue_new_number/1`이 `{:ok, new_number, new_state}` 튜플을 반환하면, 기계는 호출자에게 새 번호를 응답하고 새 상태를 자신의 상태로 설정해야 해요. 대신 `{:error, error}` 튜플을 반환하면, 기계는 호출자에게 오류를 응답하고 상태를 변경하지 않아야 해요.

```elixir
{:ok, machine} = TakeANumberDeluxe.start_link(min_number: 1, max_number: 2)
TakeANumberDeluxe.queue_new_number(machine)
# => {:ok, 1}

TakeANumberDeluxe.queue_new_number(machine)
# => {:ok, 2}

TakeANumberDeluxe.queue_new_number(machine)
# => {:error, :all_possible_numbers_are_in_use}
```

## 4. 대기 중인 다음 번호 처리하기

`serve_next_queued_number/2` 함수와 필요한 `GenServer` 콜백을 구현해요.

기계의 현재 상태와 두 번째 선택적 인자 `priority_number`를 가지고 `TakeANumberDeluxe.State.serve_next_queued_number/2` 함수를 호출해야 해요.

`TakeANumberDeluxe.State.serve_next_queued_number/2`가 `{:ok, next_number, new_state}` 튜플을 반환하면, 기계는 호출자에게 다음 번호를 응답하고 새 상태를 자신의 상태로 설정해야 해요. 대신 `{:error, error}` 튜플을 반환하면, 기계는 호출자에게 오류를 응답하고 상태를 변경하지 않아야 해요.

```elixir
{:ok, machine} = TakeANumberDeluxe.start_link(min_number: 1, max_number: 10)
TakeANumberDeluxe.queue_new_number(machine)
# => {:ok, 1}

TakeANumberDeluxe.serve_next_queued_number(machine)
# => {:ok, 1}

TakeANumberDeluxe.serve_next_queued_number(machine)
# => {:error, :empty_queue}
```

## 5. 상태 초기화하기

`reset_state/1` 함수와 필요한 `GenServer` 콜백을 구현해요.

현재 상태의 `min_number`와 `max_number`를 사용해 새 상태를 만들기 위해 `TakeANumberDeluxe.State.new/2` 함수를 호출해야 해요. 기계는 새 상태를 자신의 상태로 설정해야 해요. 호출자에게 응답하지 않아야 해요.

```elixir
{:ok, machine} = TakeANumberDeluxe.start_link(min_number: 1, max_number: 10)

TakeANumberDeluxe.reset_state(machine)
# => :ok
```

## 6. 자동 종료 구현하기

기계 시작 부분을 수정해요. `init_arg`로 전달된 키워드 리스트에서 `:auto_shutdown_timeout` 키의 값을 읽어 `TakeANumberDeluxe.State.new/3`의 세 번째 인자로 전달해야 해요. `:auto_shutdown_timeout`이 주어지지 않았다면 기본값 `:infinity`를 사용해요.

기계 상태 초기화 부분도 수정해서 `auto_shutdown_timeout`을 `TakeANumberDeluxe.State.new/3`에 전달하도록 해요.

구현한 모든 콜백(`init/1`과 모든 `handle_*` 콜백)의 반환값을 수정해 타임아웃을 설정해요. 현재 기계 상태의 `:auto_shutdown_timeout` 키 값을 사용해요. `init/1`의 `{:stop, reason}` 반환값에는 타임아웃을 추가하지 마세요. 타임아웃은 서버가 수신 루프를 시작한 뒤에만 적용돼요.

주어진 타임아웃 안에 다른 메시지를 받지 못하면 기계로 전송되는 `:timeout` 메시지를 처리할 `GenServer` 콜백을 구현해요. 이 콜백은 `:normal`이라는 이유로 프로세스를 종료해야 해요.

예상치 못한 메시지도 무시해서 처리하도록 해요.

```elixir
{:ok, machine} =
  TakeANumberDeluxe.start_link(
    min_number: 1,
    max_number: 10,
    auto_shutdown_timeout: :timer.hours(2)
  )

# after 3 hours...

TakeANumberDeluxe.queue_new_number(machine)
# => ** (exit) exited in: GenServer.call(#PID<0.171.0>, :queue_new_number, 5000)
#        ** (EXIT) no process: the process is not alive or there's no process currently associated with the given name, possibly because its application isn't started
#       (elixir 1.13.0) lib/gen_server.ex:1030: GenServer.call/3
```
