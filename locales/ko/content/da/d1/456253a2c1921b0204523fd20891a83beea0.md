# 지침 부록

## 구현 참고 사항

테스트 스위트는 `keep`과 `discard` 메서드에 [블록 인자][block-argument]로 Function 클래스 인스턴스를 전달해요.
테스트를 통과하려면 코드 안에서 이 함수를 호출해야 해요.
이 방법이 익숙하지 않다면 [Function 클래스 문서][function-class]를 참고해 봐요.

[block-argument]: https://wren.io/functions.html#block-arguments
[function-class]: https://wren.io/modules/core/fn.html
