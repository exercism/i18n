# 개요

Factor의 `<iota>`는 정수 `0, 1, …, n-1`의 *가상* 시퀀스를 만들어요. 이걸 `map`으로 순회하면 각 원소가 자기 위치의 함수가 되는, 표로 정리된 시퀀스를 얻을 수 있어요:

```factor
USING: math sequences ;

5 <iota> [ sq ] map .         ! => { 0 1 4 9 16 }
8 <iota> [ 1 + ] map .        ! => { 1 2 3 4 5 6 7 8 }
```

정수 코드의 시퀀스를 문자열로 바꾸는 데는 두 가지가 있어요:

| 워드      | 역할                                                    |
|-----------|---------------------------------------------------------|
| `CHAR:`   | 파싱 시점에 문자의 코드 포인트를 푸시하는 리터럴        |
| `>string` | 코드 포인트의 시퀀스를 문자열로 변환                    |

이 둘을 함께 쓰면 위치를 인덱스로 삼아 문자 행을 만드는 표준 관용구가 돼요:

```factor
USING: kernel math sequences strings ;

10 <iota> [ 2 mod zero? [ CHAR: O ] [ CHAR: . ] if ] map >string .
! => "O.O.O.O.O."
```

쿼테이션 안에서 `if`(또는 `?`)로 문자를 고르면, 위치마다의 판단이 그것이 의존하는 인덱스 가까이에 머물러요.
