# 소개

상수는 컴파일 시점에 값이 정해지며, 다시 대입할 수 없어요.
상수 하나를 선언할 때는 `const` 키워드를 사용해요.

```go
const greeting = "hello"
```

여러 상수는 하나의 블록에 선언할 수 있어요.
블록 안에서 값을 명시하지 않은 상수는 앞의 표현식을 그대로 반복해요.

```go
const (
    greeting    = "hello"
    buffSize    = 4096
    chunkSize   // 4096
)
```

상수는 보통 패키지 수준에서 선언하지만, 함수 안에서 선언할 수도 있어요.

## 타입이 있는 상수와 타입이 없는 상수

타입을 지정하지 않고 상수를 선언하면 타입이 없는 상수가 돼요.
타입이 없는 상수에는 정해진 타입이 없고, 값에 따라 어떤 타입과 호환되는지가 결정돼요.
기반 값이 호환되는 한, 컴파일러는 상수를 사용할 때마다 필요한 타입으로 변환해요.

```go
const numA = 2

math.Sqrt(numA)  // numA is treated as float64 here
var numB int = numA  // numA is treated as int here
```

타입이 있는 상수는 선언할 때 타입이 고정돼요.

```go
const num int = 2

math.Sqrt(num)  // compile error because a float is expected
```

## 상수가 될 수 있는 것

상수에는 불리언, 숫자, 문자열, 룬만 담을 수 있어요.
값이 컴파일 시점에 정해지기 때문에, 함수 호출의 결과는 상수로 사용할 수 없어요.

```go
const s = math.Sqrt(4)  // compile error because the value isn't known at compile time
```

## Iota

상수 블록 안에서 `iota`는 그 상수가 블록 안에서 몇 번째인지를 나타내요.

```go
const (
    Sunday    = iota // 0
    Monday           // 1
    Tuesday          // 2
    Wednesday        // 3
)
```

첫 번째 이후의 각 상수는 같은 표현식을 물려받고, `iota`는 하나씩 증가해요.

`iota`는 표현식 안에서도 사용할 수 있어요.

```go
const (
    _  = iota             // position 0: value discarded
    KB = 1 << (10 * iota) // position 1: 1 << 10 = 1024
    MB                    // position 2: 1 << 20 = 1048576
    GB                    // position 3: 1 << 30 = 1073741824
)
```
