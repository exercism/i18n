# 참고 자료

## 추천 학습 자료
ClojureScript는 세심하게 설계된 Clojure의 방언이에요. Clojure에 대한 지식(호스트 플랫폼인 JVM이 아니라 언어 자체)은 ClojureScript에서 사용할 수 있어요.

- [ClojureScript API](http://cljs.github.io/api/) 공식 API 문서예요.
- [Clojurescript Cheat-Sheet](https://clojure.org/api/cheatsheet), 공식 치트시트예요.
- [Learn Clojurescript Syntax in 15 minutes](https://github.com/shaunlebron/ClojureScript-Syntax-in-15-minutes) 이 언어의 문법을 가르쳐 주는 GitHub 저장소예요.
