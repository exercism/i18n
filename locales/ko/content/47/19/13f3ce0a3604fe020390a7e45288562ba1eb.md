# 도움말

## Rust 설치

Rust 설치와 학습 자료는 [Exercism 도움말 페이지][help-page]를 참고해요.

## 풀이 제출하기

일반적으로는 풀이를 구현한 모든 파일을 제출하는 게 좋아요(대부분의 경우 `src/lib.rs`예요). 외부 크레이트를 사용하고 있다면 `Cargo.toml` 파일도 함께 제출해 봐요. 그러면 리뷰 과정이 더 빠르고 명확해져요.

## 피드백, 이슈, 풀 리퀘스트

[포럼](https://forum.exercism.org/c/programming/rust/)에 가서 연습 문제에 대한 피드백을 남기거나, 새로운 연습 문제를 만드는 데 돕고 싶다면 글을 작성해 주세요.
Rust 트랙 팀원들이 기꺼이 도와드려요!

GitHub의 [트랙 저장소][github]에는 모든 Rust 연습 문제가 모여 있어요.

Exercism에 대해 더 알고 싶다면 [기여 가이드]를 한번 살펴봐요.

## 불완전한 풀이 제출하기
불완전한 풀이도 제출할 수 있어요. 그러면 다른 사람들이 연습 문제를 어떻게 완성했는지 볼 수 있어요.
