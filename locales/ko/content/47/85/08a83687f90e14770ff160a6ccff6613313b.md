# 튜플

튜플은 정해진 개수의 서로 다른 타입 데이터를 하나로 묶는 가벼운 방법이에요. 튜플에는 특별한 이름이 없어요. 데이터 구조에 이름을 붙이면 그건 `struct`가 돼요. 튜플의 필드에는 이름이 없어요. 필드는 구조 분해를 하거나 위치를 이용해서 접근해요.

## 문법

튜플은 괄호로 둘러싸인 필드 목록이에요:

- `()`는 `unit type`, 즉 [특별한 경우](https://doc.rust-lang.org/std/primitive.unit.html)예요
- **(** _표현식_ **,)** 는 요소가 하나인 튜플 표현식이에요
- **(** _타입_ **,)** 은 요소가 하나인 튜플 타입이에요
- **(** _표현식_ **,** ... **)** 은 일반적인 튜플 표현식이에요
- **(** _타입_ **,** ... **)** 은 일반적인 튜플 타입이에요

### 생성

튜플은 항상 튜플 표현식으로 만들어요:

```rust
// pointless but legal
let unit = ();
// single element
let single_element = ("note the comma",);
// two element
let two_element = (123, "elements can be of differing types");
```

튜플은 원소를 몇 개든 가질 수 있어요.

### 구조 분해로 접근하기

구조 분해를 이용하면 튜플의 원소에 접근할 수 있어요. 이건 튜플의 각 원소에 변수 이름을 붙이고, 그렇게 해서 튜플을 소비한다는 뜻일 뿐이에요.

```rust
let (elem1, _elem2) = two_element;
assert_eq!(elem1, 123);
```

### 위치로 접근하기

숫자로 된 위치 인덱스로도 튜플의 원소에 접근할 수 있어요. 인덱싱은 언제나 그렇듯 0부터 시작해요.

```rust
let notation = single_element.0;
assert_eq!(notation, "note the comma");
```

## 튜플 구조체

앞으로는 튜플 구조체도 다뤄 보게 될 거예요. 일반 구조체처럼 이름이 있는 타입이지만, 일반 구조체와 달리 필드가 익명이에요. 문법은 일반적인 튜플 문법과 아주 비슷해요. 구조 분해와 위치 접근을 둘 다 사용해도 괜찮아요.

```rust
struct TupleStruct(u8, i32);
let my_tuple_struct = TupleStruct(123, -321);
let borrowed_neg = &my_tuple_struct.1;
let TupleStruct(borrowed_byte, _) = &my_tuple_struct;
assert_eq!(borrowed_neg, &-321);
assert_eq!(borrowed_byte, &123);
```

### 필드 가시성

익명 튜플의 모든 필드는 항상 공개예요. 반면 튜플 구조체의 필드는 각각 따로 가시성을 가지며, 일반 구조체의 필드처럼 기본값은 비공개예요. 일반 구조체에서처럼 `pub` 제한자를 붙이면 필드를 공개로 만들 수 있어요.

```rust
// fails due to private fields
mod tuple { pub struct TupleStruct(u8, i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```

```rust
// succeeds: fields are public
mod tuple { pub struct TupleStruct(pub u8, pub i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```
