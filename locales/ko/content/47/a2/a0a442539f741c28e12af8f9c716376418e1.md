# 소개

## 제네릭

### 소개

제네릭은 코드 재사용을 가능하게 하는 언어 기능이에요.
예를 들어, 배열이 어떤 타입을 담고 있든 길이를 계산하는 데에는 영향이 없어야 해요.
그래서 `length` 함수는 타입 시그니처에 제네릭 타입 매개변수 `a`를 사용해요.

```elm
length : List a -> Int
```

### 타입에서의 매개변수

어떤 타입이 다른 타입에 대해 제네릭할 때는, 그 다른 타입에 소문자 이름을 붙이고 이를 타입 매개변수라고 불러요.
대표적인 예로 `List`, `Maybe`, `Result` 같은 커스텀 타입이 있어요.

```elm
-- Maybe is generic over the type a
type Maybe a
    = Nothing
    | Just a

someString : Maybe String
someString = Just "hello"

someInt : Maybe Int
someInt = Just 42
```

타입 매개변수의 이름에 대해 한 가지 중요한 점은, 여러 글자로 이루어질 수 있다는 거예요.
유일한 제약은 소문자 이름이어야 한다는 것뿐이에요.
그래서 도움이 될 때는 설명적인 이름을 붙이는 편이에요.

타입은 여러 다른 타입에 대해 제네릭할 수 있고, 따라서 여러 개의 타입 매개변수를 가질 수 있어요.
이 경우 각각의 독립적인 타입은 서로 다른 소문자 이름을 가져요.
독립적이라는 것이 같은 타입이 되는 걸 막지는 않아요.
다만 서로 달라질 수 있게 해줄 뿐이에요.

```elm
-- Result is generic over the types error and value
type Result error value
    = Ok value
    | Err error
```

레코드 타입 별칭도 타입 매개변수를 가질 수 있어요. 다만 흔한 경우는 아니에요.

```elm
-- Event is generic over the type a
type alias Event a =
    { at : Time
    , data : a 
    }
```

### 함수에서의 타입 매개변수

타입이 제네릭할 수 있으니 함수도 제네릭할 수 있어요.
제네릭 타입을 다루는 함수를 작성할 수도 있는데, `Maybe.withDefault`가 그 예예요.

```elm
withDefault : a -> Maybe a -> a
withDefault default maybe =
    case maybe of
      Just value -> value
      Nothing -> default
```

다른 함수를 매개변수로 받는 함수를 고차 함수라고 부르는데, 이런 함수도 제네릭할 수 있어요.

```elm
map : (a -> b) -> Maybe a -> Maybe b
map function maybe =
  case maybe of
    Just value ->
      Just (function value)

    Nothing ->
      Nothing
```
