# 지침 추가

## 힌트

다음 함수를 구현해야 해요.

```haskell
value :: (Color, Color) -> Int
```

이 함수는 색 두 개만 받아서 저항기의 저항값에 해당하는 숫자를 만들어요.

**보너스 - 속성 테스트:**

이 연습 문제는 [속성 테스트](https://en.wikipedia.org/wiki/Property_testing)를 작성해 볼 좋은 기회예요. 이전에 한 번도 작성해 본 적이 없다면 다음 자료를 참고해 봐요:

1. [School of Haskell](https://www.schoolofhaskell.com/user/pbv/an-introduction-to-quickcheck-testing).
2. [Real world Haskell](http://book.realworldhaskell.org/read/testing-and-quality-assurance.html)

테스트 파일에 QuickCheck 속성 테스트 예시를 하나 넣어 두었어요.

테스트할 수 있는 속성의 예는 다음과 같아요:

- `x`가 `Black`이 아닌 모든 `(x, y)`에 대해 `value (x, y) >= 10`

- `value (x, y)`에 `show`를 호출한 결과는 `value (y, x)`에 `show`를 호출한 결과를 `reverse`한 문자열과 같아요.

- 모든 색은 이름이 서로 달라요. (두 색이 서로 다르면 이름도 서로 달라요.)
