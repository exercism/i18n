# 설치

현재 elm 버전은 0.19.1이에요.
설치 방법은 언어가 발전하면서 계속 바뀌어요.
최신 설치 안내는 [elm 가이드의 설치 안내][elm-install]에서 확인할 수 있어요.

[elm-install]: https://guide.elm-lang.org/install/elm.html

## 추가 도구

**elm-test**

명령줄에서 테스트를 실행할 때 사용하는 도구는 elm-test라고 해요.
현재 elm-test는 Node.js와 npm이 필요해서, 아직 설치하지 않았다면
[먼저 Node.js와 npm을 설치해 두세요][npm-install].
npm을 설치했다면, elm-test는 다음처럼 설치할 수 있어요:

```shell
npm install --global elm-test@latest-0.19.1
```

자세한 내용은 [elm-test의 npm 홈 페이지][elm-test]에서 확인할 수 있어요.

[npm-install]: https://www.npmjs.com/get-npm
[elm-test]: https://www.npmjs.com/package/elm-test

**elm-format**

대부분의 elm 프로그래머는 elm 코드의 서식을 정리할 때 elm-format을 사용해요.
설정이 필요 없는 코드 서식 도구예요.
자동 서식 도구에 익숙하지 않다면 처음에는 조금 답답하게 느껴질 수 있지만,
한번 익숙해지고 나면 그전에는 어떻게 코딩을 했는지 궁금해질 거예요.
elm-format도 npm으로 설치할 수 있어요:

```shell
npm install --global elm-format@latest-0.19.1
```

자세한 내용은 [GitHub의 elm-format 홈 페이지][elm-format]에서 확인할 수 있어요.

[elm-format]: https://github.com/avh4/elm-format

**텍스트 편집기**

Elm 지원은 최소한 [IntelliJ][intellij]에서 잘 동작하고,
[elm language server][els]와 호환되는 VS Code, Sublime Text, Vim 같은 텍스트 편집기에서도 좋아요.

[els]: https://github.com/elm-tooling/elm-language-server
[intellij]: https://github.com/klazuka/intellij-elm

## npm 권한 오류

elm-test나 elm-format을 설치할 때 npm에서 EACCESS 권한 오류가 발생할 수 있어요.
그런 경우에는 npm 웹사이트의 안내를 따라 주세요.
[패키지를 전역으로 설치할 때 발생하는 EACCES 권한 오류 해결하기][eaccess].

[eaccess]: https://docs.npmjs.com/resolving-eacces-permissions-errors-when-installing-packages-globally
