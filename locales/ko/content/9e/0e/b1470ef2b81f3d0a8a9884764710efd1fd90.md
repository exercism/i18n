# 개요

[범위][range]는 하나 또는 여러 개의 연속된 정수를 나타내요. 범위의 특징은 다음과 같아요:

- [`..` 연산자][range-operator]로 만들 수 있고, 오름차순과 내림차순 모두 가능해요.
- 기본 간격은 `1`이지만, [`..//` 연산자][range-operator-with-step]로 바꿀 수 있어요 (Elixir 1.12부터).
- 처음 값과 마지막 값 모두 포함해요.
- [_Enumerable 프로토콜_][enumerable]을 구현해요.
- 내부적으로는 구조체로 표현되지만, `..`로 패턴 매칭할 수 있어요.
- 2진수, 8진수, 16진수, 코드 포인트 표기법으로 쓴 정수와 함께 사용할 수 있어요.
- [`Enum.to_list/1`][enum-to-list]이나 [`Enum.map/2`][enum-map] 같은 함수로 배열로 바꿀 수 있어요.

```elixir
Enum.to_list(9..1)
# => [9, 8, 7, 6, 5, 4, 3, 2, 1]

Enum.map(?A..?F, &<<&1>>)
["A", "B", "C", "D", "E", "F"]
```
