# 지침

Lisp 외계인들은 기념일을 축하하는 걸 좋아해요.
그들에게 중요한 기념일은 바로 기가세컨드예요.
즉, 어떤 사건이 일어난 지 1,000,000,000초가 지난 시점이죠.

## 1. 기가세컨드 기념일 날짜 계산하기

`from`이라는 함수를 작성해요.
이 함수는 `year`, `month`, `day`, `hour`, `min`, `sec` 여섯 개의 매개변수를 받아 기가세컨드 기념일의 날짜와 시간을 계산해요.
이 함수는 입력 매개변수와 같은 순서와 의미를 가진 배열로 날짜를 반환해야 해요.

```
(from 2000 1 1 0 0 0) ; => (2031 9 9 1 46 40)
```
