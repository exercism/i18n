# 지시 사항

Jen은 큰 공장의 분류실에서 일해요.
분류실은 들어오는 모든 것에 라벨을 붙여 분류하는 방식으로 처리해야 해요.
Jen은 숫자로 미리 분류된 것들을 맡고 있고, 분류 작업을 도와줄 프로그램이 필요해요.

대부분의 원시 값에는 단순한 라벨이 붙어야 해요.
숫자의 경우, Jen은 (숫자가 2라면) `"This is the number 2.0"` 같은 문자열을 원해요.
Jen은 정수와 실수에 대해 같은 출력을 원해요.

내용물을 얻으려면 포장을 풀어야 하는 `Box` 인터페이스가 몇 가지 있어요.
`NumberBox`의 경우, (`Number()` 메서드가 3을 반환하면) `"This is a box containing the number 3.0"` 같은 문자열을 원해요.
`FancyNumberBox`의 경우, 타입이 `FancyNumber`일 때만 `"This is a fancy box containing the number 4.0"` 같은 문자열을 원해요.

예상치 못한 것은 무엇이든 `"Return to sender"`라고 해야 Jen이 그것들을 온 곳으로 돌려보낼 수 있어요.

## 1. 간단한 숫자 설명하기

Jen은 숫자가 `"This is the number 2.0"` 같은 문자열을 반환하기를 원해요 (소수점 뒤 한 자리를 포함해서요):

```go
fmt.Println(DescribeNumber(-12.345))
// Output: This is the number -12.3
```

## 2. 숫자 상자 설명하기

Jen은 숫자 상자가 `"This is a box containing the number 2.0"` 같은 문자열을 반환하기를 원해요 (마찬가지로 소수점 뒤 한 자리를 포함해서요):

```go
fmt.Println(DescribeNumberBox(numberBoxContaining{12}))
// Output: This is a box containing the number 12.0
```

## 3. 팬시 숫자 상자에서 숫자를 추출하는 메서드 구현하기

Jen은 `FancyNumberBox`에서 숫자를 추출할 도우미 함수가 필요해요.
`FancyNumberBox`가 `FancyNumber`라면, 값을 추출해서 `string`에서 `int`로 변환해요.
다른 타입의 `FancyNumberBox`는 0을 반환해야 해요.

```go
fmt.Println(ExtractFancyNumber(FancyNumber{"10"}))
// Output: 10
fmt.Println(ExtractFancyNumber(AnotherFancyNumber{"4"}))
// Output: 0
```

## 4. 팬시 숫자 상자 설명하기

`FancyNumberBox`가 `FancyNumber`라면, Jen은 `"This is a fancy box containing the number 4.0"` 같은 문자열을 원해요.
다른 타입의 `FancyNumberBox`는 `"This is a fancy box containing the number 0.0"`라고 해야 해요.

```go
fmt.Println(DescribeFancyNumberBox(FancyNumber{"10"}))
// Output: This is a fancy box containing the number 10.0
fmt.Println(DescribeFancyNumberBox(AnotherFancyNumber{"4"}))
// Output: This is a fancy box containing the number 0.0
```

참고: `ExtractFancyNumber` 함수를 사용해야 해요!

## 5. 이 모든 것을 사용하는 `DescribeAnything` 구현하기

이것은 Jen이 필요로 하는, 어떤 입력이든 받는 핵심 함수예요.
`DescribeAnything`은 전달된 값의 타입에 따라 다른 함수에 위임해야 해요.
더 구체적으로는:

- `int`와 `float64`는 둘 다 `DescribeNumber`에 위임해야 해요
- `NumberBox`는 `DescribeNumberBox`에 위임해야 해요
- `FancyNumberBox`는 `DescribeFancyNumberBox`에 위임해야 해요
- 그 외에는 `"Return to sender"`가 되어야 해요

```go
fmt.Println(DescribeAnything(numberBoxContaining{12.345}))
// Output: This is a box containing the number 12.3
fmt.Println(DescribeAnything("some string"))
// Output: Return to sender
```
