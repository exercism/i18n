# 지침

이 연습 문제에서는 고객에게 배달하는 피자 가게에서 일해요.

세 가지 종류의 피자를 제공해요:

- Margherita: \$7
- Caprese: \$9
- Formaggio: \$10

고객은 약간의 추가 요금을 내고 두 가지 옵션을 더 고를 수도 있어요:

1. 추가 소스: \$1
1. 추가 토핑: \$2

고객이 주문할 때 피자를 한 판이나 두 판만 주문하면 추가 요금이 붙어요:

- 피자 한 판: \$3
- 피자 두 판: \$2

과제는 세 가지이고, 각 과제에서는 피자와 그 가격을 다뤄요.

## 1. 피자 종류와 옵션 정의하기

피자 종류와 피자에 추가할 수 있는 두 가지 옵션을 나타내는 `Pizza` 구별된 공용체를 정의해요:

- `Margherita`
- `Caprese`
- `Formaggio`
- `ExtraSauce`
- `ExtraToppings`

## 2. 피자 가격 계산하기

피자 한 판의 가격을 계산하는 `pizzaPrice` 함수를 구현해요:

```fsharp
pizzaPrice Caprese
// => 9
```

## 3. 주문 가격 계산하기

피자 주문의 가격을 계산하는 `orderPrice` 함수를 구현해요:

```fsharp
orderPrice [Margherita; Formaggio]
// => 19
```
