# 테스트

테스트 러너를 사용하려면 [Godot이 제대로 설치되어 있어야 해요][installation].

## 테스트 실행하기

[테스트 러너][test runner]는 풀이를 불러오고 테스트하는 데 사용해요.
테스트 러너를 실행하려면 먼저 내려받은 다음, `godot`으로 테스트 러너를 실행해요.
앞으로는 `exercism download`를 사용할 때 테스트 러너가 연습 문제와 함께 자동으로 내려받아질 거예요.

```bash
godot --headless -s /path/to/test_runner.gd -- <solution-slug> <path/to/solution>
```
