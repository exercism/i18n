# 소개

`cond` 외에도 Elixir는 조건을 하나만 확인하면 될 때 유용한 매크로 [`if/2`][getting-started-if]를 제공해요.

[`if/2`][kernel-if]는 조건과 두 가지 선택지를 받아요. 조건이 _truthy_면 첫 번째 선택지를, _falsy_면 두 번째 선택지를 반환해요.

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
else
  "No beer for you!"
end

# => "No beer for you!"
```

`if` 표현식을 한 줄로 쓸 수도 있어요. 조건 뒤에 오는 쉼표에 주목해요.

```elixir
if age > 16, do: "beer", else: "no beer"
```

이 문법은 아주 짧은 표현식에는 유용하지만, 표현식이 한 줄에 들어가지 않는다면 피하는 게 좋아요.

## _truthy_와 _falsy_

Elixir에서는 모든 데이터 타입이 불리언 문맥(`if` 표현식 같은)에서 _truthy_ 또는 _falsy_ 값으로 평가돼요. 모든 데이터는 `false`와 `nil`을 **제외하고** _truthy_로 간주해요. 특히 빈 문자열, 정수 `0`, 빈 배열은 Elixir에서 모두 _truthy_로 간주해요.
