# 힌트

## 일반

- 안내서의 타입은 `FMAP{STR,STR}`예요. 이름을 서식지에 대응시키는 맵이고, 둘 다 문자열이에요. 이 타입을 받는 모든 루틴에서 타입을 빠짐없이 다 써 줘요.

## 1. 안내서에 있나요?

- `has_ind`가 답을 바로 알려줘요. 그대로 반환하면 돼요. `if`는 필요 없어요.

## 2. 어디에 사나요?

- 없는 키에 `get`을 써도 아무 불평도 하지 않아요. 빈 문자열을 답하는데, 그 잘못은 전혀 다른 곳에서 터져요. 먼저 `has_ind`에게 물어봐요.
- `if` 하나를 쓰고, 한쪽 분기에는 `get`을, 다른 쪽에는 `"Unknown"`을 둬요.

## 3. 항목 추가하기

- `insert`는 키를 먼저 받고 그다음에 넣을 값을 받아서, 이제부터 사용할 맵을 답해요. 그 답을 반환해요. 그게 이 루틴의 전부예요.
- 이미 목록에 있는 동물은 따로 처리할 게 없어요. `insert`가 대체하니까요.
- 빈 안내서도 마찬가지로 따로 할 일이 없어요. 빈 안내서에 값을 넣는 것이 바로 맵이 시작되는 방식이에요.

## 4. 동물은 몇 마리인가요?

- `.size`예요.

## 5. 어떤 서식지인가요?

- 빈 집합에서 시작해요: `habitats ::= #FSET{STR};`
- `guide.target!`이 서식지들을 하나씩 살펴봐요. 하나씩 넣고, 그때마다 답을 다시 대입해요.
- 중복은 따로 처리할 필요가 없어요. 집합은 값 하나만 남기는데, 답이 배열이 아니라 집합인 이유가 바로 그거예요.
