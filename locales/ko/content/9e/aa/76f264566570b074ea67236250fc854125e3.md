# 도움말

문제가 생겼을 때 도움을 받으려면 다음 자료를 활용할 수 있어요:

- [ClojureScript API](http://cljs.github.io/api/) 공식 API 문서예요.
- [Clojurescript Cheat-Sheet](https://clojure.org/api/cheatsheet)는 공식 치트 시트예요.
- [/r/clojurescript](https://www.reddit.com/r/clojurescript)은 C# 서브레딧이에요.
- [StackOverflow](http://stackoverflow.com/questions/tagged/clojurescript)에서 문제를 검색하고 이미 답변이 있는지 확인할 수 있어요. 질문하고 답변할 수도 있어요.
