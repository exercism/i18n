# 지시사항

여러분 근처의 한 학교에는 아주 활발한 학생회가 있어요.
학생회는 회장이 이끌고 있고, 2년마다 새로운 회장을 뽑는 선거가 열려요.
올해 선거에서는 투표를 집계할 새로운 디지털 시스템이 필요하다는 결정이 내려졌어요.

학교는 이 새로운 시스템을 만드는 데 여러분의 도움이 필요해요.

## 1. 투표 집계기 만들기

새 투표 시스템에 가장 먼저 필요한 것 중 하나는 투표 집계기예요.
이 집계기는 특정 후보가 받은 투표 수를 계속 추적하는 방법이에요.

후보의 초기 투표 수를 받아서, 주어진 초기 투표 수로 초기화된 `VoteCounter` 구조체의 스냅샷을 반환하는 함수 `new_vote_counter`를 만들어요.

```rust
let initial_votes: u32 = 2;
let counter: @VoteCounter = new_vote_counter(initial_votes);
// @VoteCounter {
//     value: 2,
// }
```

## 2. 집계기에서 투표 수 가져오기

이제 새로운 집계기를 만들 수 있게 됐어요!
그런데 이제 보니, 새 시스템에는 집계기에서 투표 수를 가져오는 방법도 필요해요.

집계기(`@VoteCounter`)를 인자로 받아서 집계기의 투표 수를 반환하는 함수 `vote_count`를 만들어요.

```rust
let initial_votes: u32 = 3;
let vote_counter: @VoteCounter = new_vote_counter(initial_votes);

let count = vote_count(vote_counter);
// => 3
```

## 3. 집계기의 투표 수 늘리기

드디어 투표를 집계할 시간이에요!
이제 집계기의 투표 수를 늘리는 방법이 필요해요.

집계기(`@VoteCounter`)와 투표 수를 인자로 받아서, 그 투표 수만큼 집계기를 늘리는 함수 `increment_vote_count`를 만들어요.

```rust
let votes: u32 = 3;
let vote_counter: @VoteCounter = new_vote_counter(initial_votes);
let vote_counter: VoteCounter = increment_vote_count(vote_counter, 2);

let count = vote_count(@vote_counter);
// => 5
```

## 4. 선거 결과 만들기

이제 모든 투표를 집계했으니, 학교 전체에 결과를 발표할 준비를 할 시간이에요.
그런데 그러려면 투표 집계기만으로는 부족하다는 걸 알게 돼요.
투표 수를 특정 후보와 연결하는 방법이 필요해요.

후보의 이름과 그 후보의 투표 수를 받아서 새로운 선거 결과를 반환하는 함수 `new_election_result`를 만들어요.

```rust
let result: ElectionResult = new_election_result("Peter", 3);
// ElectionResult {
//     name: "Peter",
//     votes: @VoteCounter {
//         value: 3,
//     },
// }
```

선거 결과 구조체는 이미 만들어져 있고, 다음과 같이 정의되어 있어요:

```rust
struct ElectionResult {
    name: ByteArray,
    counter: @VoteCounter,
}
```

## 5. 결과 발표하기

이제 학교에 새 회장을 발표할 시간이에요!
회장은 학교에 있는 작은 디지털 게시판에 발표될 거예요.

메시지에는 새 회장의 이름과 그 회장이 받은 투표 수가 `<candidate_name> (<votes>)` 형식으로 표시되어야 해요.
다음은 그런 메시지의 예시예요: `"Peter (51)"`.

`@ElectionResult`를 인자로 받아서, 표시할 메시지를 담은 `ByteArray`를 반환하는 함수 `display_result`를 만들어요.

```rust
let result = ElectionResult {
    name: "John",
    votes: @VoteCounter {
        value: 32,
    },
};

let msg = display_result(@result);
// => "John (32)"
```

## 6. 투표 재검표

최종 결과가 정확한지 확인하기 위해 투표를 다시 세었어요.
재검표 결과, 일부 후보의 투표 수가 하나씩 차이가 나는 것이 발견됐어요.

최종 결과와, 투표 수를 줄여야 할 후보의 이름을 받는 함수 `decrement_votes_of_candidate`를 만들어요.
최종 결과는 `Felt252Dict<u32>` 형태로 주어지며, 키는 후보의 이름이고 값은 그 후보의 총 투표 수예요.

```rust
let mut final_results: Felt252Dict<u32> = Default::default();
final_results.insert('Mary', 10);
final_results.insert('John', 51);

decrement_votes_of_candidate(ref final_results, 'Mary');

let decremented_votes = final_results.get('Mary');
// => 9
```
