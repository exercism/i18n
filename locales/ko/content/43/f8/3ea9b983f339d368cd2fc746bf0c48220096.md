### 동적 함수 호출

awk 함수는 일급 객체가 아니에요. 다른 언어들처럼 이리저리 주고받을 수 없죠.
하지만 변수에 함수의 _이름_(문자열)을 담아 둘 수 있고, `@varname(args)`라는 특별한 표기법으로 그 함수를 호출할 수 있어요.
예를 들어 볼까요?

```awk
function greet(name) {
    print "Hello, " name
}
BEGIN {
    greet("John")       # => "Hello, John"

    f = "greet"
    f("Bill")           # => error
    @f("Bill")          # => "Hello, Bill"
}
```
[간접 함수 호출][indirect]에 이 기능이 설명되어 있어요.
`gawk`의 확장 기능이에요.
