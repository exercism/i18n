# 테스트

8th 실행 파일이 PATH에 있다면, 다음 명령을 입력해요:

```bash
8th -f test.8th
```

8th 실행 파일이 PATH에 없다면, Windows에서는 다음과 같이 입력해요:

```cmd
\path\to\8th -f test.8th
```

Linux나 macOS에서는 다음과 같아요:

```bash
/path/to/8th -f test.8th
```

## REPL에서 테스트하기

test-words.8th를 함께 불러오면서 8th를 시작해요:

```sh
8th -f test-words.8th
```

이렇게 하면 CLI 세션이 시작돼요. 풀이 파일에 코드를 어느 정도 작성했다면, 그 코드를 REPL로 불러올 수 있어요.
예를 들어 "word-count" 연습 문제라면 다음과 같이 입력해요:

```8th
"word-count.8th" f:include
```

테스트는 다음 명령으로 실행할 수 있어요.
```sh
"word-count-tests.8th" f:include
```

또는 그 파일에서 테스트 하나를 복사해서 붙여 넣거나, 직접 입력해도 돼요.

## 건너뛴 테스트

연습 문제를 푼다는 것은 그 문제의 모든 테스트를 통과시킨다는 뜻이에요.
기본적으로 테스트를 실행하면 첫 번째 테스트 하나만 실행돼요.
이건 의도된 동작이에요. 우선 그 테스트 하나를 통과시키는 데만 집중할 수 있거든요.
통과하고 나면 `SKIP-REST-OF-TESTS` 단어를 다음 테스트 뒤로 옮겨서 그 테스트를 활성화할 수 있어요.

## 건너뛰기 무시하기

`SKIP-REST-OF-TESTS` 단어 뒤에 있는 테스트까지 포함해 모든 테스트를 실행하려면, 환경 변수 `RUN_ALL_TESTS`를 `true`로 설정하면 돼요.
테스트를 실행하는 동안에만 이 값을 설정하는 한 가지 방법은 다음과 같아요 (macOS와 Linux):

```bash
RUN_ALL_TESTS=true 8th -f test.8th
```
