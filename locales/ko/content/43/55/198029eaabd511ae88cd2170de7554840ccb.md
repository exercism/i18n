# 안내 추가

## 레지스터

| 레지스터 | 용도      | 타입     | 설명                          |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | 입력         | 주소     | null로 끝나는 이름 문자열     |
| `$a1`    | 입력         | 정수     | 숫자                          |
| `$a2`    | 입력/출력    | 주소     | null로 끝나는 결과 문자열     |
| `$t0-9`  | 임시         | 아무 타입 | 임시 저장용                   |
