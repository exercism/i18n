# 소개

[가변 매개변수][variadic-parameters]를 사용하면 함수가 하나의 매개변수로 지정된 타입의 값을 0개 이상 받을 수 있어요.
가변 매개변수는 매개변수의 타입 표기 뒤에 점 세 개(`...`)를 붙여 정의해요.

함수 본문 안에서 Swift는 이 값들을 지정된 타입의 배열로 사용할 수 있게 해요:

```swift
import Foundation

func geometricMean(_ numbers: Double...) -> Double {
    var total = 1.0
    for number in numbers {
        total *= number
    }
    return pow(total, 1.0 / Double(numbers.count))
}

let result = geometricMean(1, 2, 3, 4, 5)
// result is 2.605171084697352
```

~~~~exercism/note
함수에 가변 매개변수 뒤에 오는 매개변수가 더 있다면, 가변 매개변수 다음에 오는 첫 번째 매개변수는 가변 인자 목록이 어디서 끝나는지 Swift가 알 수 있도록 명시적인 인자 레이블을 **반드시** 가져야 해요.
~~~~
