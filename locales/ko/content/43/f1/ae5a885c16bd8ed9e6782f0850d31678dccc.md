# 안내

이 연습 문제에서는 동네 오락실에서 가장 인기 있는 게임의 최고 점수를 기록하는 방법을 구현해요.

구현해야 할 함수는 7개이고, 모두 최고 점수 데이터를 담은 딕셔너리를 반환하고 조작하는 것과 관련이 있어요.

## 1. 새로운 최고 점수 딕셔너리 정의하기

매개변수를 받지 않고, 키의 타입으로 `String`을, 값의 타입으로 `Int`를 사용하는 새로운 최고 점수 딕셔너리를 반환하는 `newScoreBoard()` 함수를 만들어요.

## 2. 최고 점수 딕셔너리에 플레이어 추가하기

최고 점수 딕셔너리에 플레이어를 추가하려면, 3개의 매개변수를 받는 `addPlayer(_:_:_:)` 함수를 정의해요:

- 첫 번째 매개변수는 점수 딕셔너리예요. in-out 매개변수여야 해요.
- 두 번째 매개변수는 플레이어의 이름을 나타내는 문자열이에요.
- 세 번째 매개변수는 점수를 나타내는 정수예요. 이 매개변수는 선택 사항이므로, 기본값 0으로 구현해요.

```swift
var highScores = newScoreBoard()
addPlayer(&highScores, "Dave Thomas")
// Returns ["Dave Thomas": 0]
addPlayer(&highScores, "José Valim", 486_373)
// Returns ["Dave Thomas": 0, "José Valim": 486_373]
```

## 3. 점수 딕셔너리에서 플레이어 제거하기

최고 점수 딕셔너리에서 플레이어를 제거하려면, 2개의 매개변수를 받는 `removePlayer(_:_:)`를 정의해요:

- 첫 번째 매개변수는 점수 딕셔너리예요. in-out 매개변수여야 해요.
- 두 번째 매개변수는 플레이어의 이름을 나타내는 문자열이에요.

이 함수는 플레이어가 딕셔너리에 있으면 제거하고, 없으면 아무것도 하지 않아요.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373]
removePlayer(&highScores, "Dave Thomas")
// Returns ["José Valim": 486_373]
removePlayer(&highScores, "Rose Fanaras")
// Returns ["José Valim": 486_373]
```

## 4. 플레이어의 점수 초기화하기

플레이어의 점수를 초기화하려면, 2개의 매개변수를 받는 `resetPlayer(_:_:)`를 정의해요:

- 첫 번째 매개변수는 점수 딕셔너리예요. in-out 매개변수여야 해요.
- 두 번째 매개변수는 점수를 초기화하려는 플레이어의 이름을 나타내는 문자열이에요.

이 함수는 플레이어의 점수를 0으로 설정해요. 플레이어가 딕셔너리에 없으면 아무 일도 일어나지 않아요.

```swift
var highScores = ["Dave Thomas": 486_373, "José Valim": 10]
resetScore(&highScores, "Dave Thomas")
// Returns ["Dave Thomas": 0, "José Valim": 10]
```

## 5. 플레이어의 점수 업데이트하기

이전 점수에 더해서 플레이어의 점수를 업데이트하려면, 3개의 매개변수를 받는 `updateScore`를 정의해요:

- 첫 번째 매개변수는 점수 딕셔너리예요. in-out 매개변수여야 해요.
- 두 번째 매개변수는 점수를 업데이트하려는 플레이어의 이름을 나타내는 문자열이에요.
- 세 번째 매개변수는 저장된 최고 점수에 **더하려는** 점수예요.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373]
addPlayer(&highScores, "Freyja Ćirić", 12_771_008)
updateScore(&highScores, "Freyja Ćirić", 73)
// Returns ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_081]
```

## 6. 플레이어 이름순으로 정렬된 점수 목록 가져오기

1개의 매개변수를 받는 `orderByPlayers` 함수를 정의해요:

- 첫 번째 매개변수는 점수 딕셔너리예요.

이 함수는 플레이어와 그들의 최고 점수를 플레이어 이름의 오름차순으로 정렬한 `(String, Int)` 튜플의 배열을 반환해요.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_091]
orderByPlayers(highScores)
// Returns [("Dave Thomas", 0), ("Freyja Ćirić", 12_771_091), ("José Valim", 486_373)]
```

## 7. 플레이어 점수의 내림차순으로 정렬된 플레이어 목록 가져오기

플레이어를 점수의 내림차순으로 정렬한 목록을 가져오려면, 1개의 매개변수를 받는 `orderByScores`를 정의해요:

- 첫 번째 매개변수는 점수 딕셔너리예요.

이 함수는 플레이어와 그들의 최고 점수를 플레이어 점수의 내림차순으로 정렬한 `(String, Int)` 튜플의 배열을 반환해요.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_091]
orderByScores(highScores)
// Returns [("Freyja Ćirić", 12_771_091), ("José Valim", 486_373), ("Dave Thomas", 0)]
```
