# 지침

컬렉션과, 그 컬렉션의 각 원소에 수행할 연산이 주어졌을 때 `accumulate` 연산은 입력 컬렉션의 각 원소에 그 연산을 적용한 결과를 담은 새로운 컬렉션을 반환해요. 이 연산을 구현해봐요.

숫자 컬렉션이 주어졌을 때:

- 1, 2, 3, 4, 5

그리고 다음과 같은 연산이 주어졌을 때:

- 숫자를 제곱하기 (`x => x * x`)

코드는 제곱으로 이루어진 컬렉션을 만들어 낼 수 있어야 해요:

- 1, 4, 9, 16, 25

기대하는 함수 시그니처를 확인하려면 테스트 스위트를 살펴봐요.

## 제한 사항

표준 라이브러리에서 제공하는 collect/map/fmap 같은 기능들은 건드리지 마세요!
대신 다른 기본 도구들을 사용해서 직접 풀어봐요.
