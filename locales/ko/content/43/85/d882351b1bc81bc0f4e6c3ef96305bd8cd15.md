# 소개

확장 메서드를 사용하면 새 파생 타입을 만들거나 다시 컴파일하거나 원래 타입을 다른 방식으로 수정하지 않고도 기존 타입에 메서드를 추가할 수 있어요. 확장 메서드는 정적 메서드로 정의하지만, 호출할 때는 인스턴스 메서드 구문을 사용해요. 첫 번째 매개변수 앞에는 `this` 한정자가 붙는데, 이 매개변수가 메서드가 어떤 타입에서 동작하는지를 지정해요. 그리고 확장 메서드는 네임스페이스 수준에서 스코프에 들어와요.

```csharp
public static int WordCount(this string str)
{
    return str.Split().Length;
}

"Hello World".WordCount();
// => 2
```
