# 힌트

## 1. 새로운 최고 점수판 만들기

- 중괄호로 새로운 객체를 만들어요.
- 키에 공백이 들어갈 수 있도록 키를 문자열로 작성해요.
- 키와 값은 콜론으로 구분해요.

## 2. 점수판에 플레이어 추가하기

- 변수(인자)에 저장된 이름을 키로 추가하려면 대괄호 표기법을 사용해요.
- 할당 연산자(`=`)를 사용해서 새 키에 값을 설정해요.
- 플레이어를 추가한 뒤에는 점수판 매개변수를 반환해요.

## 3. 점수판에서 플레이어 제거하기

- [delete 연산자][mdn-delete]를 사용해요.
- 이전 과제에서 했던 것처럼 대괄호 표기법으로 키를 참조해요.

## 4. 플레이어의 점수 올리기

- 먼저 할당하려는 새 값을 어떻게 표현할지 생각해 봐요.
- 그다음 과제 2에서처럼 할당 연산자를 사용해서 그 새 값을 설정해요.
- 아직 하지 않았다면 [복합 할당 연산자][mdn-shorthand-assignment] `+=`를 활용할 수 있어요.

## 5. 월요일 보너스 점수 적용하기

- `for...in`문을 사용해서 객체의 모든 키를 순회해요.
- 각 키마다 과제 4에서처럼 새 값을 설정해요.
