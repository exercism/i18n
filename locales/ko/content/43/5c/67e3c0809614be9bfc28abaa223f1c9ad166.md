# 설치

## Godot Engine 설치하기

GDScript 트랙은 [Godot Engine][godot-engine]을 기반으로 만들어졌고, Windows, Linux, macOS, Android에서 실행돼요.
지금은 [로컬에서 작업][working-locally]할 때 쓰는 test runner에 Linux가 필요해요.
이 트랙에는 Godot 4.0 이상이 필요해요.

설치를 마친 뒤에는 터미널에서 다음 명령을 실행해 CLI가 제대로 설치됐는지 확인할 수 있어요.

```bash
godot --version
```

## Exercism GDScript 트랙 test runner 설치하기

test runner를 사용하려면 [Godot 설치][installation]가 제대로 되어 있어야 해요.

Exercism에서 GDScript 스크립트를 빌드하고 테스트하려면 CLI에서 Godot을 "headless" 모드로 실행해요.
지금 이 안내는 Linux와 bash가 필요해요.

### 1단계: test runner 전체 인프라 설치하기

테스트를 준비하려면 [https://github.com/exercism/gdscript-test-runner][gdscript-test-runner]를 클론하고, 그 내용을 `/opt/test-runner/`로 옮겨요.

```sh
git clone https://github.com/exercism/gdscript-test-runner.git
sudo mv gdscript-test-runner/ /opt/test-runner/
```

### 2단계: 단일 연습 문제용 test runner 스크립트 내려받기

`exercism` 도구를 설정하고 GDScript 연습 문제를 하나 이상 내려받았다면, 작업 공간 아래에 연습 문제를 담을 `gdscript` 폴더가 만들어져 있을 거예요(`exercism configure`를 실행하면 확인할 수 있어요).
이 폴더에 [test runner][test-local-gdscript-solution]를 저장하고, 그 파일에 실행 권한을 줘요.

## 테스트 실행하기

설치 단계를 마쳤다면, 아무 연습 문제 디렉터리(예: `~/exercism/gdscript/two-fer`)에서 시작해 그 연습 문제에 대한 로컬 풀이를 테스트하도록 스크립트(한 단계 위인 `../`에 있어요)를 실행할 수 있어요.

```sh
../test-local-gdscript-solution.sh
```

## IDE 사용하기

[Visual Studio Code][vscode] 같은 편집기에서 GDScript 문법 강조를 쓰려면 [godot-tools][godot-tools] 같은 확장을 설치하고 debug 서버를 실행해 둬야 해요.
Godot은 자체 편집기에서 프로젝트를 열면 이 debug 서버를 자동으로 시작하고, 그 프로젝트나 Godot 자체를 닫을 때까지 계속 실행해 둬요.
