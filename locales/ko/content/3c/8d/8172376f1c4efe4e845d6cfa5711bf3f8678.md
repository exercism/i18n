# 소개

메서드는 특별한 _리시버_ 인자를 가지는 함수예요.
리시버는 `func` 키워드와 메서드 이름 사이에 있는 별도의 인자 목록으로 나타나요.

```go
func (receiver type) MethodName(parameters) (returnTypes) {
}
```

리시버의 타입이 메서드와 같은 패키지에 정의되어 있을 때만 그 리시버를 가지는 메서드를 정의할 수 있어요.

```go
package person 

type Person struct {
	Name string
}

func (p Person) Greetings() string {
	return fmt.Sprintf("Welcome %s!", p.Name)
}
```

구조체의 메서드는 점 표기법으로 호출할 수 있어요.

```go
p := Person{Name: "Bronson"}
fmt.Println(p.Greetings())
// Output: Welcome Bronson!
```

`Person` 인스턴스 `p`에서 `Greetings()` 메서드를 호출한 방식에 주목해 봐요.
객체 지향 프로그래밍 언어에서 메서드를 호출하는 방식과 똑같아요.

기억해 둬요. 메서드는 리시버 인자를 가진 함수일 뿐이에요.
메서드는 이름 충돌을 피하는 데 도움이 돼요. 메서드는 특정 리시버 타입에 묶여 있기 때문에 서로 다른 타입에 같은 메서드 이름을 쓸 수 있거든요.

```go
import "math"

type rect struct {
	width, height int
}
func (r rect) area() int {
	return r.width * r.height
}

type circle struct {
	radius int
}
func (c circle) area() float64 {
	return math.Pow(float64(c.radius), 2) * math.Pi
}
```

리시버에는 값 리시버와 포인터 리시버, 두 가지 종류가 있어요.

지금까지 살펴본 메서드는 모두 값 리시버를 사용해요. 값 리시버는 메서드에 전달된 값의 복사본을 받아요. 그래서 메서드 안에서 리시버를 수정해도 호출한 쪽에서는 그 변경을 볼 수 없어요.

리시버가 가리키는 값을 수정하려면 포인터 리시버를 사용해 메서드를 선언하면 돼요.
타입 이름 앞에 `*`를 붙이면 돼요.
예를 들어 `rect` 타입이라면 포인터 리시버는 `*rect`로 선언해요.
이런 수정은 메서드를 호출한 쪽에서도 확인할 수 있어요.

```go
type rect struct {
	width, height int
}
func (r *rect) squareIt() {
	r.height = r.width
}

r := rect{width: 10, height: 20}
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 20

r.squareIt()
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 10
```
