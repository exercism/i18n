# 소개

객체는 _인스턴스 변수_를 설정해서 자신만의 상태를 가질 수 있어요. 인스턴스 변수는 변수 이름 앞에 `@`를 붙여서 만들어요.

```ruby
@name = 2
```

객체는 보통 `initialize` 메서드에서 초기 상태를 설정해요. `initialize` 메서드는 클래스에 `new`를 호출할 때 자동으로 호출돼요.

```ruby
class Airplane
  def initialize
    @wings = 2
  end
end
```

`initialize` 메서드는 인자를 받을 수도 있어요. 그래야 각 인스턴스가 원하는 상태로 시작할 수 있어요.

```ruby
class Suitcase
  def initialize(locked)
    @locked = locked
  end
end
```

_인스턴스_ 변수는 외부에서 읽거나 쓸 수 없는 비공개로 여겨요. 인스턴스 변수를 읽고 설정할 때는 _인스턴스_ 메서드를 사용해야 해요.

```ruby
class Suitcase
  #...

  def locked? # Query methods should be named with a trailing `?`
    @locked
  end

  def unlock! # Methods which mutate state should have trailing `!`
    @locked = false
  end
end
```
