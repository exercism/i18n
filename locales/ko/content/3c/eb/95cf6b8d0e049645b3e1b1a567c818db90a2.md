# 힌트

## 1. 주어진 카드의 값 계산하기

- 예전 방식의 [`switch`][ref-switch]가 여기서 잘 어울려요. 호출할 때마다 카드 한 장만 처리하면 되니까요.
- [`case_match`][ref-case_match]를 사용하는 것도 방법이지만, 이 경우에는 문자열을 감싼 따옴표를 생략할 수 없어요.

## 2. 첫 번째 턴의 결정 로직 구현하기

- 이 과제에서는 [`case_when`][ref-case_when]이 도움이 돼요.
- 일련의 조건문을 사용해 base R로도 해결할 수 있지만, 그렇게 하면 훨씬 덜 깔끔해요.

[ref-switch]: https://stat.ethz.ch/R-manual/R-devel/library/base/html/switch.html
[ref-case_match]: https://dplyr.tidyverse.org/reference/case_match.html
[ref-case_when]: https://dplyr.tidyverse.org/reference/case_when.html
