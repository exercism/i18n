# 일급 기밀

## 스토리

비밀 정보원의 도움을 받아 기업 스파이 활동에 맞서고 있어요. 그녀는 자신의 코드를 통해 비밀 메시지를 인코딩해요.

## 작업

학생은 다음 단계를 거쳐 소스 코드에서 메시지를 디코딩하는 함수를 구현해요:

- 소스 코드를 AST로 바꿔요
- 노드 하나를 파싱해요: 노드가 함수 정의라면 함수 이름을 반환해요
- 파싱을 확장해요: 함수가 받는 인자의 개수와 같은 수의 문자만 반환해요
- 메시지를 디코딩해요: 모든 노드를 순회하며 반환된 문자열을 이어 붙여요
