# 소개

## 재귀

재귀 함수는 스스로를 호출하는 함수예요.

재귀 함수에는 적어도 하나의 _기저 사례_와 적어도 하나의 _재귀 사례_가 있어야 해요.

_기저 사례_는 함수를 다시 호출하지 않고 값을 반환해요. _재귀 사례_는 함수를 다시 호출하는데, 언젠가는 기저 사례와 일치하도록 입력을 바꿔서 호출해요.

흔히 각 사례는 각자의 함수 절에 따로 작성해요.

```elixir
# base case
def count([]), do: 0

# recursive case
def count([_head | tail]), do: 1 + count(tail)
```
