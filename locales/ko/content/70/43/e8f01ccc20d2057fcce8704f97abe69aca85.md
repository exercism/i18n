# 테스트

대부분의 테스트는 [result]에 값을 할당하거나 [exit]에 값을 전달해서, 예상한 값을 반환하는지 확인해요.

일부 테스트는 예상한 예외를 [raise]하는지 확인해요.

## 테스트 실행하기

테스트를 실행하려면 `make` 유틸리티가 필요해요.

연습 문제 디렉터리 안에서 콘솔이나 터미널에 다음을 입력해요:

```sh
make
```

연습 문제 풀이 파일을 아예 건드리지 않았다면, 다음과 같은 메시지가 보여요:

```
Please implement your solution.
```

그러니 풀이를 작성하기 전에 이 줄을 지워요.

기본적으로는 첫 번째 테스트만 실행돼요.

```text
TAP version 14
1..10
ok 1 - ...
```

모든 테스트를 실행하려면 다음을 입력해요:

```sh
make test=all
```

```text
TAP version 14
1..10
ok 1 - empty_sentence
ok 2 - perfect_lower_case
ok 3 - only_lower_case
ok 4 - missing_the_letter_x
ok 5 - missing_the_letter_h
ok 6 - with_underscores
ok 7 - with_numbers
ok 8 - missing_letters_replaced_by_numbers
ok 9 - mixed_case_and_punctuation
ok 10 - am_and_AM_are_26_different_characters_but_not_a_pangram
```

모든 테스트가 통과하면 연습 문제를 끝낸 것이고, 풀이를 제출할 수 있어요.

해당 번호를 넘겨서 실행할 테스트 하나를 고를 수도 있어요. 예를 들어:

```sh
make test=2
```

라고 입력하면 두 번째 테스트만 실행돼요.
