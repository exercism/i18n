# 배열

`ARRAY{T}`는 타입 `T`의 값들이 일정하게 늘어선 행이에요.

```sather
   row : ARRAY{STR} := |"Mia", "Ana", "Ben"|;
   sizes : ARRAY{INT} := |3, 1, 2|;
```

## 중괄호

`ARRAY{STR}`는 "`STR`의 배열"이라고 읽어요. 중괄호 안에는 **타입 매개변수**가 들어가요.
`ARRAY`만으로는 타입이 아니에요. 배열은 무언가의 배열이어야 하니까요. Sather
라이브러리의 많은 부분이 이런 식으로 만들어져 있고, 이런 클래스를 직접 작성하는 것은
나중에 다뤄요.

## 위치

```sather
row[0]                 -- the first
row[row.size - 1]      -- the last
row.size               -- how many
```

위치는 `0`부터 `.size - 1`까지예요. 배열은 자신의 크기를 알고 있고, 그 크기는 절대
바뀌지 않아요. `ARRAY`에는 원소를 덧붙이는 기능이 없어요.

## 리터럴 없이 만들기

`#ARRAY{INT}(n)`는 값 `n`개로 이루어진 배열을 만들어요. 각 값은 0이에요.

```sather
   counts ::= #ARRAY{INT}(5);      -- five noughts
   counts[0] := 7;
```

어떤 위치에 값을 할당할 때도 `:=` 왼쪽에 같은 대괄호를 써요.

## 범위를 벗어난 접근

존재하지 않는 위치를 읽거나 쓰는 것은 일반 빌드에서 검사하지 않아요. 도움이 되는
메시지와 함께 프로그램을 멈춰 주지 않고, 메모리에서 바로 다음에 있는 것을 그냥 읽거나
써요. 이런 일을 피하는 두 가지 습관이 있어요. 눈으로 세어 본 숫자 대신 `.size - 1`을
쓰고, 리터럴 대신 `until!(i >= a.size)`로 루프를 끝내는 거예요.

## 출력하기

`.str`은 내용을 중괄호에 담아 보여줘요. 뭔가를 계산해 볼 때 편리해요.

```sather
   #OUT + row.str;      -- {Mia,Ana,Ben}
```
