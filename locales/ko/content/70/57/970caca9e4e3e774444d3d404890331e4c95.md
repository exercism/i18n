# 학습

Odin은 시스템 프로그래밍 언어예요.
C처럼 프로그래머가 메모리를 직접 관리해야 하죠.
그래도 꽤 단순한 언어예요.

Odin을 배우는 데 도움이 되는 자료는 다음과 같아요.

먼저 다음 자료로 언어를 맛볼 수 있어요.

* Odin을 만든 사람이 소개하는 [Odin 소개][video] 영상을 봐요.
* ["Understanding the Odin Programming Language"][book]의 저자가 쓴 [Odin 소개][intro] 글을 읽어 봐요.
* Odin의 개념을 코드로 보여 주는 [데모 파일][demo]을 살펴봐요.

더 깊이 파고들려면:

* [Odin 언어 개요][overview].
* [공식 패키지][packages] 문서.
* ["Understanding the Odin Programming Language"][book] 책 (유료).
* 공식 ["Odin Examples"][examples] 모음.
