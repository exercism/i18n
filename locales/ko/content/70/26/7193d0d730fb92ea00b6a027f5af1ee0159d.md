# 소개

이 강의에서는 _언어_를 **AWK**라고 부르고, AWK 프로그램을 해석하는 _실행 파일_을 **`awk`** 또는 **`gawk`**라고 불러요.

## 패턴과 액션

AWK 프로그램은 **패턴-액션 쌍**으로 이루어져 있어요.

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

**패턴**은 입력과 비교할 정규 표현식 패턴이 될 수 있어요.
참/거짓 값을 만들어 내는 어떤 표현식이든 패턴이 될 수도 있어요.

**액션**은 하나 이상의 AWK 명령이에요.
액션을 감싸는 중괄호는 꼭 필요해요.

패턴의 결과가 _참_이면 그에 해당하는 액션이 실행돼요.

## 레코드와 필드

AWK는 입력을 여러 개의 **레코드**로 나누어 읽어요.
각 레코드는 다시 0개 이상의 **필드**로 쪼개져요.

기본 동작은 다음과 같아요.

- 줄바꿈 문자를 "레코드 구분자"로 사용해 입력을 레코드로 나눠요. 그래서 각 _줄_이 하나의 레코드가 돼요.
- 공백 문자를 "필드 구분자"로 사용해 레코드를 필드로 나눠요. 그래서 각 _단어_가 하나의 필드가 돼요.

## 패턴과 액션 (계속)

패턴은 생략할 수 있는데, 이때 액션은 _모든 입력 레코드_에 대해 실행돼요.

액션도 생략할 수 있어요. 이때 기본 액션은 현재 레코드를 출력하는 거예요.

### 특별한 패턴

자주 사용하는 특별한 패턴이 두 가지 있어요.

- `BEGIN`은 입력을 하나도 읽기 전에 연결된 액션을 실행해요.
- `END`는 모든 입력을 다 읽은 뒤에 연결된 액션을 실행해요.

## 필드 변수

필드는 `$1`, `$2`, `$3` 등으로 가리켜요.

현재 레코드는 `$0`이에요.

그 밖에 자주 쓰이는 내장 변수도 있어요.

### 입력 분석을 제어하는 내장 변수

- `RS`는 입력 레코드 구분자예요.
  앞에서 말했듯이 기본값은 줄바꿈 문자예요.
- `FS`는 입력 필드 구분자예요.

이 변수들은 보통 `BEGIN` 액션 블록에서 설정해요.

### 정보를 전달하는 내장 변수

이 변수들은 프로그램이 실행되는 동안 AWK가 자동으로 설정해요.

- `NF`에는 현재 레코드의 필드 개수가 저장돼요.
  - 마지막 필드의 값을 얻으려면 `$NF`를 사용해요.
- `NR`에는 현재 레코드 번호가 저장돼요.
  - 여러 입력 파일을 처리할 때 `NR`에는 지금까지 처리한 전체 레코드 개수가 들어 있어요.
- `FNR`에는 현재 입력 파일의 현재 레코드 번호가 저장돼요.
  - NR과 FNR의 차이를 보여 주는, 흔히 쓰이는 AWK 관용구가 있어요.
    ```awk
    NR == FNR {action}
    ```
    이는 "누적된 레코드 번호가 현재 파일의 레코드 번호와 같다면"이라는 뜻이에요.
    이 조건은 _첫 번째 입력 파일_의 레코드에서만 참이 될 수 있어요.

## 참과 거짓

AWK는 C와 같은 참/거짓 개념을 사용해요.

- 숫자 `0`은 거짓이에요.
- 그 밖의 다른 숫자는 모두 참이에요.

AWK는 텍스트를 다루는 언어이기 때문에 참/거짓 판단이 문자열에도 적용돼요.

- 빈 문자열 `""`은 거짓이에요.
- 비어 있지 않은 문자열은 참이에요.

## 주석

주석은 `#` 문자로 시작하고 줄의 끝까지 이어져요.

## 예제

유닉스 계열 시스템에서 `/etc/passwd`에는 사용자 정보가 들어 있어요.
각 사용자는 한 줄씩 따로 설명되고, 필드는 콜론으로 구분돼요.

사용자 이름을 나열하려면 다음과 같이 해요.

```sh
awk '
    BEGIN { FS = ":" }
    { print $1 }
' /etc/passwd
```

`{print $1}` 액션에는 패턴이 없기 때문에 모든 레코드에 대해 실행돼요.

로그인 셸로 bash를 사용하는 사용자만 출력하고 싶다면 이렇게 하면 돼요.

```sh
awk '
    BEGIN { FS = ":" }
    $7 == "/bin/bash" { print $1 }
' /etc/passwd
```
