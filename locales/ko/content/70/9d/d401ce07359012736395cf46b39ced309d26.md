# 지침 추가

## 레지스터

| 레지스터 | 용도     | 유형    | 설명                       |
| -------- | --------- | ------- | -------------------------- |
| `$a0`    | 입력      | 주소    | 물건 무게의 배열           |
| `$a1`    | 입력      | 주소    | 물건 가치의 배열           |
| `$a2`    | 입력      | 정수    | 물건의 개수                |
| `$a3`    | 입력      | 정수    | 최대 무게                  |
| `$v0`    | 출력      | 정수    | 최대 가치                  |
| `$t0-9`  | 임시      | 임의    | 임시 저장에 사용           |
