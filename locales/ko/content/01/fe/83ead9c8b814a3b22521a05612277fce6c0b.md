# 함수

함수는 Cairo의 기본 요소예요.

관례적으로 Cairo에서는 함수와 변수 이름에 **스네이크 케이스**를 사용하는데, 단어를 모두 소문자로 쓰고 밑줄로 구분하는 방식이에요.

예시를 하나 볼게요:

```rust
fn another_function() {
    println!("Another function.");
}

fn main() {
    println!("Hello, world!");
    another_function();
}
```

함수는 `fn`으로 정의하는데, `fn` 뒤에 이름을 쓰고, 매개변수가 있다면 괄호를 쓰고, 중괄호로 감싼 본문을 작성해요.

함수는 이름 뒤에 괄호를 붙여 호출할 수 있어요.

함수는 스코프 안에 있기만 하면 순서는 상관없어요.

## 매개변수

함수는 **매개변수**를 받을 수 있는데, 매개변수는 함수 시그니처에 정의된 변수예요.

함수를 호출할 때는 이 매개변수에 전달하는 값인 **인자**를 넘겨줘요.

```rust
fn main() {
    another_function(5);
}

fn another_function(x: felt252) {
    println!("The value of x is: {}", x);
}
```

여기서 `x`는 `felt252` 타입의 매개변수예요.

`5`를 넘겨 호출하면 함수는 "The value of x is: 5"를 출력해요.

매개변수가 여러 개일 때는 쉼표로 구분해요:

```rust
fn main() {
    print_labeled_measurement(5, "h");
}

fn print_labeled_measurement(value: u128, unit_label: ByteArray) {
    println!("The measurement is: {value}{unit_label}");
}
```

이 코드는 `The measurement is: 5h`를 출력해요.

## 문과 표현식

Cairo 함수는 **문**과 **표현식**으로 이루어져 있어요:

- **문**은 동작을 수행하지만 값을 반환하지 않아요.
예를 들어 `let x = 3;`은 문이에요.
- **표현식**은 값으로 평가돼요.
예를 들어 `5 + 6`은 `11`로 평가돼요.

중괄호로 감싼 블록도 표현식이고, 블록의 마지막 값이 반환돼요:

```rust
fn main() {
    let y = {
        let x = 3;
        x + 1
    };
    println!("The value of y is: {}", y);
}
```

여기서 `y`에는 `4`가 할당돼요.

## 반환 값

함수는 `->` 문법으로 반환 타입을 지정해서 값을 반환할 수 있어요.

기본적으로 함수는 마지막 표현식의 값을 반환해요:

```rust
fn five() -> u32 {
    5
}

fn main() {
    let x = five();
    println!("The value of x is: {}", x);
}
```

이 코드는 `The value of x is: 5`를 출력해요.

좀 더 복잡한 경우를 볼까요:

```rust
fn plus_one(x: u32) -> u32 {
    x + 1
}

fn main() {
    let x = plus_one(5);
    println!("The value of x is: {}", x);
}
```

이 코드는 `The value of x is: 6`을 출력해요.

마지막 표현식 끝에 세미콜론을 붙이지 않도록 주의해요. 세미콜론을 붙이면 표현식이 문이 되어서, 함수가 기대한 값 대신 `()` (단위 타입)을 반환하게 돼요.
