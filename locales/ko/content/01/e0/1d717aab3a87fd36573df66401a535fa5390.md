# 추가 지침

## 출력 형식

가사를 null로 종료되는 문자열로 출력해요.

## 레지스터

| 레지스터 | 용도      | 타입   | 설명                        |
| -------- | --------- | ------ | --------------------------- |
| `$a0`    | 입력      | 정수   | 시작 절                     |
| `$a1`    | 입력      | 정수   | 끝 절                       |
| `$a2`    | 입출력    | 주소   | null로 종료되는 출력 문자열 |
| `$t0-9`  | 임시      | 임의   | 임시 저장용                 |
