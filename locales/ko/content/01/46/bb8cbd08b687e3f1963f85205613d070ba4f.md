# 소개

조건문은 조건이 `true`인지 `false`인지에 따라 서로 다른 코드를 실행하는 문이에요.

`if`문은 조건이 `true`일 때만 본문을 실행해요. Go에는 truthy나 falsy라는 개념이 없어서 조건은 반드시 `bool` 타입이어야 해요. `if mySlice { ... }`나 `if 1 { ... }` 같은 표현은 컴파일 오류예요.

```go
func describe(val string) string {
    if val == "val" {
        return "was val"
    }
    return "was not val"
}
```

추가 조건을 확인할 때는 `else if`를 쓰고, 어느 조건도 맞지 않을 때를 대비해서는 `else`를 써요. 조건은 위에서 아래로 평가되고, 조건이 참인 첫 번째 분기만 실행돼요.

```go
number := 0
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

`if`문에는 짧은 초기화 문을 함께 넣을 수도 있어요. 이렇게 선언한 변수는 `if`/`else` 체인 전체 안에서만 스코프를 가져요.

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```
