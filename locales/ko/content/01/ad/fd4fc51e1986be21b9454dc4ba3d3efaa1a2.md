# 실라버스 - 확장

개념 연습 문제를 몇 개 만들고 나면 실라버스를 확장하기가 더 쉬워져요.
이미 바탕으로 삼을 수 있는 개념이 더 많아졌기 때문이에요.

개념 트리를 확장하는 두 가지 주요 방법은 다음과 같아요:

1. 이미 있는 개념을 확장하는 방법 (예: `time` => `timezones`)
2. 이미 소개한 개념에 의존하는 새로운 개념을 도입하는 방법 (예: `classes` => `interfaces`)

다음으로 무엇을 고를지 막막하다면, 트랙에 있는 가장 단순한 연습 문제 중 한두 개를 살펴봐요.
어떤 개념이 쓰였는지 찾아보고, 실라버스에서 아직 다루지 않은 개념을 하나 골라요.

작업 중인 연습 문제가 아직 소개하지 않은 개념을 이해해야만 풀 수 있다는 걸 발견할 수도 있어요.
그럴 때는 그냥 메모해 두고, 학습자가 빠진 개념을 이미 이해하고 있다고 가정한 채로 연습 문제를 끝내요.
연습 문제의 상태는 `wip`로 설정해 두세요.
개념 트리에 빈틈이나 건너뛰는 부분이 있으면 그 언어가 익숙하지 않은 학습자에게 아주 혼란스럽거든요.

다른 트랙들이 실라버스를 어떻게 구성했는지 살펴보는 것도 좋아요.
예를 들어 [Elixir 트랙](https://exercism.org/tracks/elixir/concepts)은 실라버스 진행이 정말 잘 짜여 있어요.
