# Debug

[Debug.log](https://package.elm-lang.org/packages/elm/core/latest/Debug#log)를 사용하면 실패하는 테스트에 메시지를 붙일 수 있어요. 다음과 같이요:

```elm
hoursToSeconds : Int -> Int
hoursToSeconds hours =
    let
        secondsInOneHour =
            Debug.log "secondsInOneHour" (60 * 60)
    in
    hours * secondsInOneHour
```

테스트가 실패하면 붙여 둔 로그가 `secondsInOneHour: 3600`으로 표시돼요.

한 가지 주의할 점이 있어요. 최상위 상수는 테스트가 실행되기 전에 딱 한 번만 평가되기 때문에, 테스트는 그 로그 메시지를 담을 수 없어요. 예를 들어:

```elm
secondsInOneHour : Int
secondsInOneHour =
    Debug.log "secondsInOneHour" (60 * 60)
```

이 코드는 테스트 중에 아무것도 로그로 남기지 않아요. `secondsInOneHour`에 연결된 JavaScript 변수가 이미 3600이라는 값으로 평가된 상태이기 때문이에요.
