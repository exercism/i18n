# 소개

## 문자열

F#에서 `string`은 유니코드 문자(글자, 숫자, 문장 부호 등)의 시퀀스로 이루어진, 변경할 수 없는 텍스트를 나타내는 객체예요. 다음과 같이 정의해요:

```fsharp
let fruit = "Apple"
```

문자열은 문자열의 메서드를 호출하거나 `String` 모듈의 함수를 사용해서 다뤄요. 문자열을 한 번 만들면 그 값은 절대 바뀌지 않아요. 문자열을 수정하는 것처럼 보이는 메서드나 함수도 사실은 새로운 문자열을 반환해요.

문자열은 몇 가지 방법으로 이어 붙이거나 서식을 지정할 수 있어요.
* `+` 연산자로 문자열을 이어 붙일 수 있어요:
```fsharp
let sentence = "Apple" + " is a type of fruit."
```
* 텍스트 서식을 지정할 때는 `sprintf` 함수를 사용할 수 있어요. 서식 텍스트에 자리 표시자를 넣고(`string`에는 `%s`), 값은 인자로 넘겨줘요:
```fsharp
let sentence = sprintf "%s is a type of %s." "Apple" "fruit"
```
