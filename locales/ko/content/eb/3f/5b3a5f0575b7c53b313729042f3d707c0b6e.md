# 소개

Gleam은 참과 거짓 값을 `Bool` 타입으로 표현해요. 값은 `True`와 `False` 두 가지뿐이에요. 이 값들은 변수에 담을 수 있어요:

```gleam
let true_variable = True
let false_variable = False
```

`&&`, `||`, `!` 연산자를 사용하면 불리언 값을 다룰 수 있어요:

```gleam
True && True  // -> True
True && False // -> False

False || True  // -> True
False || False // -> False

!False // -> True
!True  // -> False
```

`&&`와 `||` 연산자는 단축 평가를 사용해요. 즉, 연산자 오른쪽에 있는 표현식은 필요할 때만 평가돼요.

연산자마다 우선순위가 달라요. `!` 연산자는 `&&`나 `||`보다 먼저 평가돼요. 중괄호를 사용하면 표현식의 일부를 다른 부분보다 먼저 평가할 수 있어요:

```gleam
!True && False   // -> False
!{True && False} // -> True
```
