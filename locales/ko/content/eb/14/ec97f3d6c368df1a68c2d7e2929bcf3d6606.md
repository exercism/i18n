# 지침

이번 연습 문제에서는 좋아하는 요리책에서 근사한 라자냐를 만들어 볼 수 있도록 코드를 작성해요.

라자냐를 조리하는 데 드는 시간과 관련된 네 가지 과제가 있어요.

## 1. 오븐에 있어야 할 예상 시간을 분 단위로 정의하기

매개변수를 받지 않고, 라자냐를 오븐에 몇 분 동안 넣어 두어야 하는지를 반환하는 `Lasagna.expectedMinutesInOven()` 메서드를 정의해요. 요리책에 따르면 오븐에 있어야 하는 예상 시간은 40분이에요:

```scala
val lasagna = new Lasagna()
lasagna.expectedMinutesInOven()
// => 40
```

## 2. 오븐에 남은 시간을 분 단위로 계산하기

라자냐가 오븐에 들어 있던 실제 시간(분)을 인자로 받고, 이전 과제에서 구한 예상 오븐 시간을 기준으로 라자냐가 오븐에 앞으로 몇 분 더 있어야 하는지를 반환하는 `Lasagna.remainingMinutesInOven()` 메서드를 정의해요.

```scala
val lasagna = new Lasagna()
lasagna.remainingMinutesInOven(30)
// => 10
```

## 3. 준비 시간을 분 단위로 계산하기

라자냐에 추가한 층의 개수를 인자로 받고, 각 층을 준비하는 데 2분이 걸린다고 가정할 때 라자냐를 준비하는 데 걸린 시간(분)을 반환하는 `Lasagna.preparationTimeInMinutes()` 메서드를 정의해요.

```scala
val lasagna = new Lasagna()
lasagna.preparationTimeInMinutes(2)
// => 4
```

## 4. 경과 시간을 분 단위로 계산하기

`Lasagna.elapsedTimeInMinutes()` 메서드는 두 개의 인자를 받는데, 첫 번째 인자는 라자냐에 추가한 층의 개수이고 두 번째 인자는 라자냐가 오븐에 있던 시간(분)이에요. 이 함수는 라자냐를 조리하는 데 몇 분을 들였는지를 반환해야 해요. 이는 준비 시간(분)과 현재까지 라자냐가 오븐에 있던 시간(분)을 더한 값이에요.

```scala
var lasagna = new Lasagna()
lasagna.elapsedTimeInMinutes(3, 20)
// => 26
```
