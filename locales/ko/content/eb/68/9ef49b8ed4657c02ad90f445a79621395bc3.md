# 개요

Factor에서 대부분의 반복은 컴비네이터(`each`, `map`, `reduce`)로 표현하지만, 명시적 재귀가 여전히 필요할 때도 있어요. 재귀가 리스트 모양이 아닐 때, 기저 조건이 단순하지 않을 때, 또는 컴비네이터를 직접 구현할 때죠.

```factor
: total ( seq -- sum )
    [ 0 ] [ unclip swap total + ] if-empty ;

: gcd ( a b -- g )
    dup zero? [ drop ] [ tuck mod gcd ] if ;
```

몇 가지 알아 둘 점이 있어요.

- 일반 `:` 정의는 별도의 문법 없이 재귀 호출을 할 수 있어요. 컴파일러가 재귀 호출을 가로질러 스택 효과를 추론해요.
- `loop ( quot -- )`는 불리언을 반환하는 쿼테이션을 반복 실행하게 해줘요. 참인 동안 계속 진행하면 돼요.
- 꼬리 호출은 점프로 컴파일되므로, 재귀가 깊은 워드도 스택을 넘치게 하지 않아요.

`unclip` / `if-empty` 조합은 시퀀스 재귀의 표준 형태이고, `cond`는 여러 경우를 나누는 표준 형태예요.
