# 소개

`Complex numbers`는 복잡하지 않아요.
그저 이름만 조금 덜 무섭게 지어 주면 될 뿐이에요.

복소수는 공학과 과학 분야에서 특히나 유용해서, Julia는 정수와 부동소수점 수와 나란히 복소수를 표준 숫자 타입으로 제공해요.

## 기초

Julia에서 `complex` 값은 본질적으로 숫자 한 쌍이에요. 보통은 부동소수점이지만 항상 그런 건 아니에요.
이것들은 안타까운 역사적 이유로 '실수부'와 '허수부'라고 불려요.
다시 말하지만, 이상한 이름보다는 그 바탕에 있는 단순함에 집중하는 게 좋아요.

두 실수로 복소수를 만들려면, 허수부 뒤에 접미사 `im`을 붙이기만 하면 돼요.

```julia-repl
julia> z = 1.2 + 3.4im
1.2 + 3.4im
julia> typeof(z)
ComplexF64 (alias for Complex{Float64})
julia> zi = 1 + 2im
1 + 2im
julia> typeof(zi)
Complex{Int64}
```

이렇게 정수나 부동소수점 타입에 대응하는 여러 `Complex` 타입이 있어요.

실수 변수로 복소수를 만들 때는 위 문법이 통하지 않아요.
`a + bim`이라고 쓰면 파서가 `bim`을 (존재하지도 않는) 변수 이름으로 착각해요.

`b*im`이라고 쓸 수도 있지만, 더 권장되는 방법은 `complex()` 함수를 사용하는 거예요. 이 함수는 곱셈과 덧셈 연산을 거치지 않아요.

```julia-repl
julia> a = 1.2; b = 3.4; complex(a, b)
1.2 + 3.4im
```

복소수의 각 부분에 개별적으로 접근하려면:

```julia-repl
julia> z = 1.2 + 3.4im
1.2 + 3.4im
julia> real(z)
1.2
julia> imag(z)
3.4
```

아니면 한꺼번에:

```julia-repl
julia> reim(z)
(1.2, 3.4)
```

어느 한쪽 부분이 0이 될 수도 있는데, 수학자들은 그런 수를 '완전히 실수' 또는 '완전히 허수'라고 부르기도 해요.
그래도 Julia에서는 여전히 복소수예요.

```julia-repl
julia> zr = 1.2 + 0im
1.2 + 0.0im
julia> typeof(zr)
ComplexF64 (alias for Complex{Float64})
julia> zi = 3.4im
0.0 + 3.4im
julia> typeof(zi)
ComplexF64 (alias for Complex{Float64})
```

'`i`(또는 `j`)는 -1의 제곱근이다'라는 말을 들어 봤을지도 몰라요.

지금으로서는, 허수부가 _정의상_ 다음 등식을 만족한다는 뜻일 뿐이에요:

```julia-repl
julia> 1im * 1im == -1
true
```

단순한 생각이지만, 흥미로운 결과로 이어져요.

## 산술

실수와 정수에 쓰이는 모든 표준 수학 `operators`와 기본 함수는 복소수에도 그대로 통해서요. 몇 가지 예를 들어 볼게요:

```julia-repl
julia> z1 = 1.5 + 2im
1.5 + 2.0im
julia> z2 = 2 + 1.5im
2.0 + 1.5im
julia> z1 + z2  # addition
3.5 + 3.5im
julia> z1 * z2  # multiplication
0.0 + 6.25im
julia> z1 / z2  # division
0.96 + 0.28im
julia> z1^2  # exponentiation
-1.75 + 6.0im
julia> 2^z1  # another exponentiation
0.5188946835878313 + 2.7804223253571183im
```

## 함수

`real()`과 `imag()` 외에도, 복소수와 특히 관련이 깊은 함수가 여러 개 있어요.

- `conj()`는 복소수의 허수부 부호를 그냥 뒤집어요(_+에서 -로, 또는 그 반대로_).
    - 복소수 곱셈이 작동하는 방식 덕분에, 이건 생각보다 훨씬 유용해요.
- `abs(<complex number>)`는 허수부가 없는 실수를 반환하는 게 보장돼요.
- `abs2(<complex number>)`는 `abs(<complex number>)`의 제곱을 반환해요. `abs()`보다 계산이 빠르고, 계산에 딱 필요한 값인 경우가 많아요.
- `angle(<complex number>)`는 위상각을 라디안으로 반환해요.

```julia-repl
julia> z1
1.5 + 2.0im
julia> conj(z1)
1.5 - 2.0im
julia> abs(z1)
2.5
julia> abs2(z1)
6.25
julia> angle(z1)
0.9272952180016122
```

수학을 좋아하는 분들을 위한 부분적인 설명:

- `z1`의 `(real, imag)` 표현은 사실상 복소평면의 데카르트 좌표를 사용해요.
- 같은 복소수를 극좌표를 사용한 `(r, θ)` 표기법으로 나타낼 수도 있어요.
- 여기서 `r`과 `θ`는 각각 `abs(z1)`과 `angle(z1)`으로 주어져요.

몇 가지 상수를 사용한 예를 볼까요:

```julia-repl
julia> euler = exp(1im * π)
-1.0 + 1.2246467991473532e-16im
julia> real(euler)
-1.0
julia> round(imag(euler), digits=15)  # round to 15 decimal places
0.0
```

극 `(r, θ)` 표기법은 워낙 유용해서, 더 효율적으로 구성할 수 있게 도와주는 내장 함수 `cis`(`cos(x) + isin(x)`의 줄임말)와 `cispi`(`cos(πx) + isin(πx)`의 줄임말)가 있어요.

극 표기법의 유용함은 오일러의 우아한 공식 `ℯ^(iθ) = cos(θ) + isin(θ) = x + iy`에 잘 드러나요. 여기서 `|x + iy| = 1`이에요.
`|x + iy| = r`이면, 더 일반적인 극형식 `r * ℯ^(iθ) = r * (cos(θ) + isin(θ)) = x + iy`를 얻어요.
특히 지수 형태는 간결하고 다루기 쉬워요.

```julia-repl
julia> exp(1im * π) ≈ cis(π) ≈ cispi(1)
true
```

위에서 근사 등호를 쓴 이유는 `cis`와 `cispi` 함수가 더 깔끔한 수치 결과를 줄 수 있기 때문이에요. 특히 `cispi`는 π의 임의의 배수(예를 들어 라디안!)를 인자로 다룰 때 그렇죠.

```julia-repl
julia> cis(π)
-1.0 + 0.0im
julia> cispi(1)
-1.0 + 0.0im
julia> θ = π/2;
julia> exp(im*θ)
6.123233995736766e-17 + 1.0im
julia> cis(θ)
6.123233995736766e-17 + 1.0im
julia> cispi(θ / π)  # θ/π == 1/2
0.0 + 1.0im
```

덧붙이자면, 덕분에 복소수는 2D에서 회전과 반지름 방향 변위를 수행할 때 아주 유용해요.

회전의 경우, 복소수 `z = x + iy`를 원점을 중심으로 각도 `θ`만큼 간단한 곱셈 `z * ℯ^(iθ)`으로 회전시킬 수 있어요.
여기서 `x`와 `y`는 그냥 평범한 2D 데카르트 평면 위의 좌표이고, 양의 각도는 *반시계 방향* 회전을, 음의 각도는 *시계 방향* 회전을 만들어요.

마찬가지로 간단하게, 반지름 방향 변위 `Δr`은 극형식의 복소수 크기 `r`에 더해서 만들 수 있어요(예: `z = r * ℯ^(iθ)` -> `z' = (r + Δr) * ℯ^(iθ)`).
각도 부분은 그대로이고 예상한 대로 크기 `r`만 바뀌는 점에 주목해요.
