# 테스트

풀이를 테스트하려면 **테스트 스크립트를 실행하기만 하면 돼요**. Red Console에서 `do` 함수와 테스트 스크립트의 경로를 함께 사용하면 되는데, 이렇게 해요:

```red
do %exercism/red/hello-world/hello-world-test.red
```

또는 시스템 터미널에서 Red 바이너리에 인자로 넣어 실행해도 돼요:

```shell
red exercism/red/hello-world/hello-world-test.red
```

처음에는 테스트 파일의 첫 번째 테스트만 활성화되어 있어요. 이는 연습 문제를 한 번에 하나씩 풀도록 장려하기 위해서예요. 첫 번째 테스트를 통과하면, 테스트 파일 맨 앞에 있는 `test-init` 함수의 두 번째 *인자*를 바꾸고 다시 실행해요. 이 값은 활성화할 테스트의 개수라서, `1`을 `2`로 바꾸면 두 번째 테스트가 활성화돼요. `test-init` 함수의 `\limit` refinement와 두 번째 인자를 없애면 건너뛰는 테스트 없이 모든 테스트를 실행할 수도 있어요.
