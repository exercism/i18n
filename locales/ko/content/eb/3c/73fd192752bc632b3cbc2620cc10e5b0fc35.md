# 소개

Elixir가 호출할 함수를 정할 때는 모듈의 이름으로 조회해요. 모듈의 이름이 변수에 바인딩되어 있으면, 이 조회를 동적으로 할 수 있어요.

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```

내부적으로 모듈의 이름은 아톰이에요. 모든 Elixir 모듈 아톰에는 자동으로 `Elixir.` 접두사가 붙어요.

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```
