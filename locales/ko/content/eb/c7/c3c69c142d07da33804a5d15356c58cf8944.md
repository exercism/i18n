# 지시사항 추가

## 레지스터

| 레지스터 | 용도      | 타입    | 설명                                |
| -------- | --------- | ------- | ----------------------------------- |
| `$a0`    | 입력      | 정수    | 입력 동전의 개수                    |
| `$a1`    | 입력      | 정수    | 목표 금액                           |
| `$a2`    | 입출력    | 주소    | 덮어쓸 수 있는 동전 워드 배열       |
| `$v0`    | 출력      | 정수    | 출력 동전의 개수, 입력이 유효하지 않으면 -1 |
| `$t0-9`  | 임시      | 아무 타입 | 임시 저장에 사용                    |
