# 자세히 알아보기

## 동등성

Elm에서는 [동등 연산자][equality-operator] `(==)`로 두 값이 "같은지" 확인할 수 있어요.
같지 않음을 나타내는 연산자는 `(/=)`예요. 많은 언어처럼 `!=`를 쓰는 게 *아니에요*.

```elm
1 == 2
    --> False

1 /= 2
    --> True
```

비교하는 두 값은 타입이 같아야 해요.
동등 연산자는 리터럴, 튜플, 레코드, 사용자 정의 타입에 모두 쓸 수 있어요.
이 연산자는 구조적 동등성을 확인하는데, 타입 애너테이션이나 메모리상의 위치와 관계없이 내용과 내부 구조가 같으면 같은 값으로 봐요.

```elm
(1, 2) == (2, 1)
    --> False

type alias MyRecord = { myInt : Int, myStrings : List String }
a : MyRecord
a = MyRecord (1 + 1) ["hello world"]

type alias MyOtherRecord = { myInt : Int, myStrings : List String }
myStrings =  (String.join " " ["hello", "world"]) :: []
b : MyOtherRecord
b = { myInt = 2, myStrings = myStrings}

a == b
    --> True
```

함수는 *절대* 비교하면 안 돼요. 함수를 비교하면 프로그램이 런타임에 충돌해요.
이 제약에 대한 더 자세한 내용은 [여기][equality-operator]에서 볼 수 있어요.

## 비교

[비교 연산자][comparison-operators] `(<)`, `(<=)`, `(>)`, `(>=)`와 `min`, `max`, `compare` 함수는 `comparable` 타입에 쓸 수 있어요.
`comparable` 타입은 비교할 수 있는 모든 내장 타입을 묶은 특별한 타입이에요. 숫자, 문자, 문자열, `comparable`한 것들의 배열, `comparable`한 것들의 튜플이 여기에 속해요.
문자는 [유니코드 코드 포인트][unicode-codepoint]를 기준으로 비교해요.

```elm
1 < 1 + 1
    --> True

'x' < 'X'
    --> False

'互' < '🙏'
    --> True
```

문자열, 배열, 튜플처럼 순서가 있는 타입은 [사전순][lexicographic-order]으로 비교해요.
간단히 말해, 순서대로 원소를 하나씩 짝지어 비교하다가 더 작은 원소를 찾거나 한쪽이 끝나면 멈춰요.

```elm
"abc" < "abz"
    --> True

"abc" < "abcd"
    --> True

"abc" < "b"
    --> True

min [1 , 2, 9000] [10]
    --> [1 , 2, 9000]

min (1, "hello") (3, "bye")
    --> (1, "hello")

min (1, ['a', 'b']) (1, ['A', 'B'])
    --> (1, ['A', 'B'])
```

레코드나 사용자 정의 타입처럼 다른 타입의 값은 직접 비교할 수 없어요.

`Set`이나 `Dict`의 키처럼 일부 내장 타입은 내부적으로 정렬 순서에 의존하기 때문에, 담는 내용이 `comparable`해야 해요.
그래서 사용자 정의 타입은 `Set`에 담을 수 없어요. 다만 커뮤니티에서 만든 대안이 있는데, [`AnySet`][any-set], [`AnyDict`][any-dict], [`Sort`][sort] 같은 것들이에요.

`comparable`한 값들의 배열은 `List.sort`로 정렬할 수 있고, `comparable`한 값으로 변환할 수 있는 값들의 배열은 `List.sortBy`로 정렬할 수 있어요.
여러 기준으로 정렬해야 할 때(한 속성으로 정렬하고, 값이 같으면 다른 속성으로 순서를 정할 때)는 튜플이나 배열을 `List.sortBy`와 함께 쓸 수 있어요(다른 [대안][sort-by]들도 있어요). 튜플과 배열도 사전순으로 정렬되니까요.


```elm
List.sort ["hi", "hello", "bye", "goodbye"]
    --> ["bye", "goodbye", "hello", "hi"]

List.sortBy String.length ["hi", "hello", "bye", "goodbye"]
    --> ["hi", "bye", "hello", "goodbye"]

-- sort by length, then alphabetically
List.sortBy (\str -> (String.length str, str)) ["hi", "mum", "hello", "sis", "bye", "dad"]
    --> ["hi", "bye", "dad", "mum", "sis", "hello"]
```

`compare` 함수는 `comparable`한 값 두 개를 받아서 `Order`를 반환해요.
`Order`는 한 번의 연산으로 어떤 값이 다른 값보다 큰지(`GT`), 같은지(`EQ`), 작은지(`LT`)를 알려 주는 타입이에요.

```elm
compare 1 2
    --> LT

compare "" ""
    --> EQ

compare [12] []
    --> GT
```

비교 함수는 어떤 타입에든 직접 만들 수 있어요. 예를 들어 `List.sortWith`로 정렬할 때 쓸 수 있어요:

```elm
type Color = Red | Green | Blue

compareColors : Color -> Color -> Order
compareColors a b =
  case (a, b) of
    (Red, Red) -> EQ
    (Red, _) -> LT
    (_, Red) -> GT
    (Green, Green) -> EQ
    (Green, _) -> LT
    (_, Green) -> GT
    (Blue, Blue) -> EQ

List.sortWith compareColors [Blue, Red, Green, Green, Blue]
    --> [Red, Green, Green, Blue, Blue]
```
