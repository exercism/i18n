# 지침

이 연습 문제에서는 동네 오락실에서 가장 인기 있는 게임의 최고 점수를 기록하는 방법을 구현해요.

## 1. 새로운 최고 점수 맵 정의하기

새로운 최고 점수 맵을 만들려면, 인자를 받지 않고 비어 있는 새로운 최고 점수 맵을 반환하는 `HighScore.new/0` 함수를 정의해요.

```elixir
HighScore.new()
# => %{}
```

## 2. 최고 점수 맵에 플레이어 추가하기

최고 점수 맵에 플레이어를 추가하려면, 3개의 인자를 받는 `HighScore.add_player/3` 함수를 정의해요.

- 첫 번째 인자는 점수 맵이에요.
- 두 번째 인자는 플레이어의 이름으로, 문자열이에요.
- 세 번째 인자는 점수로, 정수예요. 이 인자는 선택 사항이며, 기본값이 0인 세 번째 인자를 구현해요.

기본 초기 점수는 모듈 속성에 저장해요. 나중에 다시 필요해요.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas")
# => %{"Dave Thomas" => 0}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"Dave Thomas" => 0, "José Valim"=> 486_373}
```

## 3. 점수 맵에서 플레이어 제거하기

최고 점수 맵에서 플레이어를 제거하려면, 2개의 인자를 받는 `HighScore.remove_player/2`를 정의해요.

- 첫 번째 인자는 점수 맵이에요.
- 두 번째 인자는 플레이어의 이름으로, 문자열이에요.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas")
# => %{"Dave Thomas" => 0}
score_map = HighScore.remove_player(score_map, "Dave Thomas")
# => %{}
```

## 4. 플레이어의 점수 초기화하기

플레이어의 점수를 초기화하려면, 2개의 인자를 받는 `HighScore.reset_score/2`를 정의해요.

- 첫 번째 인자는 점수 맵이에요.
- 두 번째 인자는 점수를 초기화하려는 플레이어의 이름으로, 문자열이에요.

이 함수는 플레이어가 점수를 가지고 있지 않은 경우에도 동작해야 해요.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"José Valim"=> 486_373}
score_map = HighScore.reset_score(score_map, "José Valim")
# => %{"José Valim"=> 0}
```

## 5. 플레이어의 점수 갱신하기

이전 점수에 더해서 플레이어의 점수를 갱신하려면, 3개의 인자를 받는 `HighScore.update_score/3`를 정의해요.

- 첫 번째 인자는 점수 맵이에요.
- 두 번째 인자는 점수를 갱신하려는 플레이어의 이름으로, 문자열이에요.
- 세 번째 인자는 저장된 최고 점수에 **더할** 점수예요.

이 함수는 플레이어에게 이전 점수가 없는 경우에도 동작해야 해요. 이전 점수가 0이라고 가정해요.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"José Valim"=> 486_373}
score_map = HighScore.update_score(score_map, "José Valim", 5)
# => %{"José Valim"=> 486_378}
```

## 6. 플레이어 목록 가져오기

플레이어 목록을 가져오려면, 1개의 인자를 받는 `HighScore.get_players/1`을 정의해요.

- 첫 번째 인자는 점수 맵이에요.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas", 2_374)
# => %{"Dave Thomas" => 2_374}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"Dave Thomas" => 2_374, "José Valim"=> 486_373}
HighScore.get_players(score_map)
# => ["Dave Thomas", "José Valim"]
```
