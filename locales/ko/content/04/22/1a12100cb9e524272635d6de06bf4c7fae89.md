# Instructions

여러분은 연안 화물선의 갑판장이에요. 빌지, 즉 선체에서 가장 낮은 칸에는 폐수가 모이는데, 근무조가 바뀔 때마다 빌지 장비를 열고, 돌리고, 다시 정리해 둬야 해요. 펌프 도중에 무슨 일이 생기든, 장비는 *반드시* 정리된 상태로 되돌아와야 해요.

테스트는 새 펌프를 얻을 수 있는 `<test-pump>`를 줘요. 펌프에는 `opened>>` 슬롯이 있는데, 열려 있는 동안에는 `t`를, 처분된 뒤에는 `f`를 읽어요.

## 1. 빌지 배수하기

`drain-bilge`를 정의해 펌프 하나를 해제해요. 같은 펌프에 `drain-bilge`를 두 번 호출해도 문제가 없어야 해요. 프레임워크가 알아서 처리해 줘요.

```factor
<test-pump> dup drain-bilge opened>> .   ! => f
```

## 2. 퍼내기 루틴

`pump-out`을 정의해 펌프와 콰테이션을 받고, 콰테이션이 쓸 수 있도록 펌프를 스택에 올린 뒤, 펌프를 해제해요. *콰테이션이 예외를 던지더라도* 마찬가지예요.

```factor
<test-pump> [ drop ] pump-out   ! pump released
```

## 3. 근무조 전체 루틴

`shift-routine`을 정의해 펌프 두 개와 콰테이션을 받아요. 소멸자 스코프를 열고, *두* 펌프를 모두 무조건 해제하도록 등록한 뒤 콰테이션을 호출해요. 콰테이션이 정상적으로 끝나든 예외를 던지든 두 펌프 모두 해제돼요.

콰테이션은 스택에 올라온 두 펌프를 입력으로 받아요.

```factor
<test-pump> <test-pump> [ 2drop ] shift-routine
! both pumps released
```

## 4. 위험한 퍼내기

때로는 펌프를 빌려 쓰는 경우도 있어요. 이런 때는 뭔가 잘못됐을 때만 버리고, 그렇지 않으면 다음 당직자가 쓸 수 있도록 열어 둬야 해요. `risky-pump-out`을 정의해 펌프와 콰테이션을 받고, 펌프를 **실패 시에만** 해제하도록 등록한 뒤, 펌프를 스택에 올린 상태로 콰테이션을 호출해요.

콰테이션이 성공하면 펌프는 열린 채로 남아요. 콰테이션이 예외를 던지면 펌프는 해제되고 예외는 그대로 전파돼요.

```factor
<test-pump> [ drop ] risky-pump-out                ! stays open
<test-pump> [ drop "boom" throw ] risky-pump-out   ! pump released, throws
```

## 5. 직접 만드는 일회용품: 밸브

새로운 일회용품인 `valve`로 도구 모음을 마무리해요. 튜플은 미리 선언되어 있어요.

```factor
TUPLE: valve < disposable is-open ;
```

- `<valve> ( -- valve )`를 정의해 `new-disposable`로 새 밸브를 만들고, `is-open`을 `t`로 설정해요.
- `M: valve dispose*`를 구현해 `is-open`을 `f`로 바꿔요.

```factor
<valve> is-open>> .                ! => t
<valve> dup dispose is-open>> .    ! => f
```
