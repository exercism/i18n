# 무시해 주세요

## 입력

스크립트는 표준 입력(stdin)을 통해 알파메틱 퍼즐을 하나의 문자열로 받아요. 퍼즐 문자열은 `WORD1 + WORD2 + ... == RESULT` 형식을 따라요.

예를 들어:

```text
SEND + MORE == MONEY
```

## 출력

퍼즐에 해답이 있다면, 알파벳 순으로 정렬한 `LETTER=DIGIT` 쌍을 공백으로 구분해 한 줄로 출력해요.

위 예시의 출력은 다음과 같아요:

```text
D=7 E=5 M=1 N=6 O=0 R=8 S=9 Y=2
```

퍼즐에 유효한 해답이 여러 개라면, 그중 아무거나 하나를 출력해도 괜찮아요.

퍼즐에 해답이 없다면, 아무것도 출력하지 않아요(빈 줄).
