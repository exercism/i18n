# 숫자

`INT`는 정수를 담아요. 이 Sather에서 `INT`는 정확히 32비트라서 -2147483648부터 2147483647까지 나타낼 수 있어요.

```sather
   goals : INT is
      return 42;
   end;
```

## 인자

루틴은 괄호 안에 인자를 받는데, 각 인자에는 타입이 있어요.

```sather
   total(first : INT, second : INT) : INT is
      return first + second;
   end;
```

같은 타입을 공유하는 인자는 선언도 함께 쓸 수 있는데, 이게 일반적인 스타일이에요.

```sather
   total(first, second : INT) : INT is
```

## 산술

| 연산자 | 의미 |
| --- | --- |
| `+` | 더하기 |
| `-` | 빼기, 그리고 부호 바꾸기 |
| `*` | 곱하기 |
| `/` | 나누기, 나머지는 버림 |
| `%` | 그 나눗셈의 나머지 |

두 `INT` 사이의 `/`는 절대 분수를 만들지 않아요.

```sather
7 / 2      -- 3
7 % 2      -- 1
```

분수가 필요하면 나중에 나오는 `FLTD`가 필요해요.

곱셈과 나눗셈은 일반적인 산술에서처럼 덧셈과 뺄셈보다 우선순위가 높아요. 다른 결과가 필요하면 괄호로 묶어요.

```sather
2 + 3 * 4        -- 14
(2 + 3) * 4      -- 20
```

## INT에서 유용한 루틴

```sather
7.max(3)     -- 7
7.min(3)     -- 3
(-7).abs     -- 7
7.str        -- "7", the number written as text
```

`.str`은 문자열을 배우고 나면 숫자가 문장의 일부가 되는 방법이에요.
