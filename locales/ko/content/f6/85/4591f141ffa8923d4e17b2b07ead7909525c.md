# 힌트

## 일반

- 파이프라인에서 변수 할당은 표현식이며, 입력으로 받은 값과 똑같은 값을 출력한다는 점을 기억해요.
- 기본값을 지정할 때는 [`//` 대체 연산자][alternative]를 사용해요.

## 1. 오븐에서 예상되는 조리 시간(분) 정의하기

- 예상 시간 값을 담는 변수를 정의해요.
- 그 값을 `"expected_minutes_in_oven"` 키의 출력 객체 값으로 포함해요.
- 객체 생성 단축 문법 `{$foo}`는 `{foo: $foo}`와 같아요

## 2. 오븐에 남은 시간(분) 계산하기

- 계산한 값을 `"remaining_minutes_in_oven"` 키의 출력 객체 값으로 포함해요.
- 숫자의 산술 뺄셈에는 [`-` 연산자][subtraction]를 사용해요.

## 3. 준비 시간(분) 계산하기

- 계산한 값을 `"preparation_time"` 키의 출력 객체 값으로 포함해요.
- 숫자의 산술 곱셈에는 [`*` 연산자][multiplication]를 사용해요.
- 좋은 스타일이라면 층마다 걸리는 시간이라는 "매직 값"에 이름을 붙이기 위해 변수를 사용하는 게 좋아요.

## 4. 총 작업 시간(분) 계산하기

- 계산한 값을 `"total_time"` 키의 출력 객체 값으로 포함해요.
- 숫자의 산술 덧셈에는 [`+` 연산자][addition]를 사용해요.

[subtraction]: https://jqlang.org/manual/#subtraction
[multiplication]: https://jqlang.org/manual/#multiplication-division-modulo
[addition]: https://jqlang.org/manual/#addition
[alternative]: https://jqlang.org/manual/#alternative-operator
