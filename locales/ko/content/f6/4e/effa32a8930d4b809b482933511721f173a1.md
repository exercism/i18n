# 소개

Elm에서 문자와 문자열은 텍스트 표현의 바탕이 돼요.
문자열은 문자의 배열이라고 생각할 수 있고, 대부분의 `List` 함수에는 `String` 모듈에 그에 대응하는 함수가 있어요.

## 문자

`Char` 타입은 `'a'`처럼 작은따옴표로 감싼 유니코드 문자 하나를 나타내요.
`Char` 모듈은 문자의 성질을 검사하는 술어 함수(`Char -> Bool`)를 제공해요: `isUpper`, `isLower`, `isAlpha`, `isAlphaNum`.
이 모듈에는 문자를 변환하는 `toUpper`, `toLower`, `toLocaleUpper`, `toLocaleLower` 함수도 있고, `toCode`와 `fromCode`로 문자를 유니코드 숫자 값(`Int`)으로 바꾸거나 그 값에서 문자로 되돌리는 함수도 있어요.

## 문자열

`String` 타입은 문자열을 효율적으로 다루기 위한 내장 표현을 제공하고, "this is an Elm string."처럼 유니코드 문자의 임의의 나열을 나타낼 수 있어요.
여러 줄 문자열은 큰따옴표 세 개로 나타내며, 이스케이프하지 않은 따옴표와 줄바꿈을 담을 수 있어요.
```elm
"""
    This is a multiline string.
All line-breaks and whitespace,
are preserved. 
"""
```

## 문자열 함수

`String` 모듈에는 아래 표에 정리한 함수가 모두 들어 있어요.
가장 많이 쓰이는 함수 몇 가지는 다음과 같아요:

`cons : Char -> String -> String`는 문자열의 맨 앞에 문자 하나를 추가해요.
```elm
cons 'T' "he truth is out there" 
    --> "The truth is out there"
```

`(++): String -> String -> String`는 두 문자열을 이어 붙여요.
```elm
"butter" ++ "fly" 
    --> "butterfly"
```

`split : String -> String -> List String`는 주어진 구분자를 기준으로 문자열을 문자열의 배열로 나눠요.
```elm
split ";" "cat;dog;cow" 
    --> ["cat", "dog", "cow"]
```

`join : String -> List String -> String`는 문자열의 배열을 주어진 구분자로 이어 붙여요.
```elm
join "a" ["H", "w", "ii", "n"] 
    --> "Hawaiian"
```
`replace : String -> String -> String -> String`는 주어진 부분 문자열이 나타나는 곳을 모두 바꿔요.
```elm
replace "Hello" "Goodbye cruel" "Hello world." 
    --> "Goodbye cruel world."
```

`length : String -> Int`는 문자열에 들어 있는 문자의 개수를 반환해요.
```elm 
length "Hello world." 
    --> 12
```

`toInt : String -> Maybe Int`는 문자열을 `Just Int`로 변환하려고 시도하고, 형식이 올바르지 않은 문자열에는 `Nothing`을 반환해요.
```elm
toInt "-42" 
    --> Just -42
```    

`contains : String -> String -> Bool`는 두 번째 문자열이 첫 번째 문자열을 포함하는지 확인해요.
```elm
contains "the" "theory" 
    --> True
```

`map : (Char -> Char) -> String -> String`는 주어진 함수를 문자열의 모든 `Char`에 적용해요.
이때 주어지는 함수는 `Char`에서 `Char`로 가는 함수여야 해요.
```elm
map (\c -> if c == '/' then '.' else c) "a/b/c" 
    --> "a.b.c"
```
