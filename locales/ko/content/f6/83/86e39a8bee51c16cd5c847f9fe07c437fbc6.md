# 소개

## 숫자

많은 프로그래밍 언어에는 서로 다른 종류의 숫자를 나타내기 위한 전용 숫자 타입이 있지만, JavaScript에는 딱 두 가지밖에 없어요:

- `number`: 배정밀도 64비트 부동소수점 형식(IEEE 754)의 숫자 데이터 타입이에요.
  예를 들어 `-6`, `-2.4`, `0`, `0.1`, `1`, `3.14`, `16.984025`, `25`, `976`, `1024.0`, `500000` 등이 있어요.
- `bigint`: 임의 정밀도 형식으로 _정수_를 나타낼 수 있는 숫자 데이터 타입이에요.
  예를 들어 `-12n`, `0n`, `4n`, `9007199254740991n` 등이 있어요.

임의 정밀도가 필요하거나 아주 큰 숫자를 다뤄야 한다면 `bigint` 타입을 사용해요.
그렇지 않다면 `number` 타입이 더 나은 선택일 거예요.

### 반올림

`Math`라는 내장 전역 객체가 있고, 여기에는 여러 가지 [반올림 함수][ref-math-object-rounding]가 있어요.
예를 들어 소수를 가장 가까운 정수로 내림(`floor`)하거나 올림(`ceil`)할 수 있어요.

```javascript
Math.floor(234.34); // => 234
Math.ceil(234.34); // => 235
```

## 산술 연산자

JavaScript는 숫자에 대한 기본적인 산술 연산을 위해 6가지 연산자를 제공해요.

- `+`: 덧셈 연산자는 숫자의 합을 구할 때 사용해요.
- `-`: 뺄셈 연산자는 두 숫자의 차를 구할 때 사용해요.
- `*`: 곱셈 연산자는 두 숫자의 곱을 구할 때 사용해요.
- `/`: 나눗셈 연산자는 두 숫자를 나눌 때 사용해요.

```javascript
2 - 1.5; //=> 0.5
19 / 2; //=> 9.5
```

- `%`: 나머지 연산자는 나눗셈을 한 나머지를 구할 때 사용해요.

  ```javascript
  40 % 4; // => 0
  -11 % 4; // => -3
  ```

- `**`: 거듭제곱 연산자는 숫자를 거듭제곱할 때 사용해요.

  ```javascript
  4 ** 3; // => 64
  4 ** 1 / 2; // => 2
  ```

### 연산 순서

한 줄에서 여러 연산자를 사용할 때, JavaScript는 [이 우선순위 표][mdn-operator-precedence]에 나온 것처럼 연산 우선순위를 따라요.
우리가 다루는 범위로 간단히 말하자면, JavaScript는 초등학교 수학 시간에 배운 PEDMAS(괄호, 거듭제곱, 나눗셈/곱셈, 덧셈/뺄셈) 규칙을 사용해요.

<!-- prettier-ignore-start -->
```javascript
const result = 3 ** 3 + 9 * 4 / (3 - 1);
// => 3 ** 3 + 9 * 4/2
// => 27 + 9 * 4/2
// => 27 + 18
// => 45
```
<!-- prettier-ignore-end -->

### 단축 대입 연산자

단축 대입 연산자는 변수에 산술 연산을 하고, 그 결과 값을 같은 변수에 대입하는 코드를 더 짧게 쓰는 방법이에요.
예를 들어 두 변수 `x`와 `y`가 있다고 해봐요.
그러면 `x += y`는 `x = x + y`와 같아요.
흔히 `y`라는 변수 대신 숫자와 함께 사용해요.
나머지 5가지 연산도 비슷한 방식으로 할 수 있어요.

```javascript
let x = 5;
x += 25; // x is now 30

let y = 31;
y %= 3; // y is now 1
```
