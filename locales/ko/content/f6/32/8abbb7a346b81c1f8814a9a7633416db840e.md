# 지침 추가

## `Array` 클래스에 메서드 추가하기

이 연습 문제는 Crystal에서 `Array` 클래스에 메서드를 추가하는 데 초점을 맞춰요.
그러려면 `Array(T)`라는 이름의 클래스를 정의해야 해요.
그리고 메서드는 이 클래스 안에 넣어요.

```crystal
class Array(T)
  # your solution here
end
```

`Array` 클래스는 [제네릭][generic] 클래스이고, [인덱싱 가능][indexable]하며 [열거 가능][enumerable]해요.
`Array` 클래스의 소스 코드는 [여기][array]에서 볼 수 있어요.

[generic]: https://crystal-lang.org/docs/syntax_and_semantics/generics.html
[indexable]: https://crystal-lang.org/api/Indexable.html
[enumerable]: https://crystal-lang.org/api/Enumerable.html
