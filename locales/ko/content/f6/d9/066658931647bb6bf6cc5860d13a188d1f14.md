# 지침

이 연습 문제에서 열렬한 스포츠 팬으로서 NBA 농구에 막 빠져들었어요. NBA 농구가 처음이라 NBA 역사를 깊이 파고들면서 팀과 감독, 승패 기록을 정리하고 서로 비교해요.

아직 좋아하는 팀이 없어서, 특정 팀을 응원할지 판단하는 알고리즘도 만들어 볼 거예요.

자신만의 _팀 응원_ 알고리즘을 개발하는 데 도움이 될 일곱 개의 작업이 있어요.

## 1. 모델 정의하기

다음 두 필드를 가진 `Coach` 레코드를 정의해요:

- `Name`: 감독의 이름, 타입은 `string`.
- `FormerPlayer`: 감독이 선수 출신이었는지 나타내요, 타입은 `bool`.

다음 두 필드를 가진 `Stats` 레코드를 정의해요:

- `Wins`: 승리 수, 타입은 `int`.
- `Losses`: 패배 수, 타입은 `int`.

다음 세 필드를 가진 `Team` 레코드를 정의해요:

- `Name`: 팀의 이름, 타입은 `string`.
- `Coach`: 팀의 감독, 타입은 `Coach`.
- `Stats`: 팀의 전적, 타입은 `Stats`.

## 2. 팀의 감독 만들기

감독 이름과 선수 출신 여부를 매개변수로 받아 `Coach` 레코드를 반환하는 `createCoach` 함수를 구현해요:

```fsharp
createCoach "Larry Bird" true
// => { Name = "Larry Bird"; FormerPlayer = true }
```

## 3. 팀의 전적 만들기

승리 수와 패배 수를 매개변수로 받아 `Stats` 레코드를 반환하는 `createStats` 함수를 구현해요:

```fsharp
createStats 58 24
// => { Wins = 58; Losses = 24 }
```

## 4. 팀 만들기

팀 이름, 감독, 전적을 매개변수로 받아 `Team` 레코드를 반환하는 `createTeam` 함수를 구현해요:

```fsharp
let coach = createCoach "Larry Bird" true
let record = createStats 58 24
createTeam "Indiana Pacers" coach record
// => { Name = "Indiana Pacers"
//      Coach = { Name = "Larry Bird"; FormerPlayer = true }
//      Stats = { Wins = 58; Losses = 24 } }
```

## 5. 감독 교체하기

NBA 구단주들은 성격이 급해서, 팀 성적이 나쁘면 감독이 자주 교체된다는 걸 알게 됐어요. 팀과 새 감독을 매개변수로 받아, 새 감독이 반영된 팀을 반환하는 `replaceCoach` 함수를 구현해요:

```fsharp
let coach = createCoach "Larry Bird" true
let record = createStats 58 24
let team = createTeam "Indiana Pacers" coach record

let newCoach = createCoach "Isiah Thomas" true
replaceCoach team newCoach
// => { Name = "Indiana Pacers"
//      Coach = { Name = "Isiah Thomas"; FormerPlayer = true }
//      Stats = { Wins = 58; Losses = 24 } }
```

## 6. 같은 팀인지 확인하기

전적을 파고들다 보면 팀과 그 전적을 목록으로 정리하게 돼요. 가끔 실수해서 목록에 중복된 항목이 생기기도 해요. 두 팀을 받아 같은 팀이면 `true`를, 아니면 `false`를 반환하는 `isSameTeam` 함수를 구현해요:

```fsharp
let pacersCoach = createCoach "Larry Bird" true
let pacersStats = createStats 58 24
let pacersTeam = createTeam "Indiana Pacers" pacersCoach pacersStats

let lakersCoach = createCoach "Del Harris" false
let lakersStats = createStats 61 21
let lakersTeam = createTeam "LA Lakers" lakersCoach lakersStats

isSameTeam pacersTeam lakersTeam
// => false
```

## 7. 응원할 팀인지 확인하기

많은 팀과 경기를 살펴본 끝에 알고리즘을 하나 떠올렸어요. 다음 중 하나라도 참이면 그 팀을 응원해요:

- 감독의 이름이 "Gregg Popovich"일 때
- 감독이 선수 출신일 때
- 팀 이름이 "Chicago Bulls"일 때
- 팀이 60경기 이상 승리했을 때
- 팀의 패배가 승리보다 많을 때

팀을 받아 응원해야 하는 팀이면 `true`를, 아니면 `return`를 반환하는 `rootForTeam` 함수를 구현해요:

```fsharp
let spursCoach = createCoach "Gregg Popovich" false
let spursStats = createStats 56 26
let spursTeam = createTeam "San Antonio Spurs" spursCoach spursStats
rootForTeam spursTeam
// => true
```
