# 힌트

## 1. 고객 분류하기

- 여기서는 `any()`나 `all()` 함수가 도움이 돼요.
- 이 함수들에 쓸 별도의 함수를 정의할 수도 있고, 익명 함수를 바로 사용할 수도 있어요.

## 2. 열성 고객 분리하기

- 딕셔너리를 필터링해야 해요.
- 딕셔너리는 기본적으로 키/값 `Pair`를 순회하는데, 이는 필드(first/second)나 인덱스(1/2)로 접근할 수 있어요.
- `all_15()` 함수를 활용해 봐요.

## 3. 평점을 이진수로 바꾸기

- `1`을 `0`으로, `5`를 `1`로 매핑해야 해요.
- 출력 배열의 모양이 입력 배열의 모양과 같은지 확인해요.

## 4. 평점을 행렬로 만들기

- `mapreduce()`로 할 수 있어요.
- 매핑의 (일부에?) `tobinary()` 함수를 활용해 봐요.
- 각각 열 벡터 입력인지 행 벡터 입력인지에 따라 `hcat()` 또는 `vcat()`으로 벡터들의 벡터를 축소하면 행렬을 얻을 수 있어요.
- 출력을 잘 살펴봐요. 각 평점 벡터가 행렬의 행인가요? 어딘가에서 `transpose()` 함수가 도움이 될 거예요.
