# 지침

학교 연극에서는 모든 배역마다 대역이 있어요. 무대 감독이 그 사람이 누구인지 모르는 채로도, 배역에 필요한 일을 대신 해낼 수 있는 사람이에요.

다섯 개의 과제는 모두 `UNDERSTUDY` 클래스에 작성해요. 처음 두 개는 평범한 루틴이고, 뒤의 과제에서 이 둘을 바인딩해요.

## 1. 대사를 말하는 두 가지 방법

대사를 대문자로 반환하는 `shout`과, 대사를 소문자로 반환하면서 양쪽 끝에 `"..."`를 붙이는 `whisper`를 작성해요.

```sather
UNDERSTUDY::shout("who's there")
-- => "WHO'S THERE"
UNDERSTUDY::whisper("Who's There")
-- => "...who's there..."
```

## 2. 대사 연습하기

`rehearse`는 대사 하나와 그 대사를 말하는 방식을 받아서 결과를 반환해요. 두 번째 인자의 타입은 `ROUT{STR}:STR`이에요.

```sather
UNDERSTUDY::rehearse("who's there", bind(UNDERSTUDY::shout(_)))
-- => "WHO'S THERE"
```

## 3. 장면 전체

`run_scene`은 대사들의 배열과 그 대사들을 말하는 방식을 받아서, 모두 그 방식으로 말한 결과를 `" "`로 이어 붙여 반환해요.

```sather
UNDERSTUDY::run_scene(|"Enter", "Exit"|, bind(UNDERSTUDY::shout(_)))
-- => "ENTER EXIT"
```

장면이 비어 있으면 빈 문자열이에요.

## 4. 말하는 방식 돌려주기

`understudy_for`는 스타일의 이름, 즉 `"shout"`이나 그 밖의 값을 받아서 `ROUT{STR}:STR`을 반환해요. `"shout"`이면 외치는 방식을, 그 밖의 값이면 속삭이는 방식을 돌려줘요.

```sather
part ::= UNDERSTUDY::understudy_for("shout");
part.call("who's there")
-- => "WHO'S THERE"
```

## 5. 인자 고정하기

`repeat`을 작성해요. 이 루틴은 반복할 횟수와 대사를 받아서, 대사를 그 횟수만큼 사이에 아무것도 넣지 않고 이어 붙여 반환해요.

```sather
UNDERSTUDY::repeat(3, "Ha")
-- => "HaHaHa"
```

그다음에는 `doubler`를 작성해요. 이 루틴은 인자를 받지 않고, 주어진 대사를 두 번 반복하는 `ROUT{STR}:STR`을 반환해요. `repeat`에 횟수를 미리 채워서 바인딩하면 돼요.

```sather
UNDERSTUDY::doubler.call("Ha")
-- => "HaHa"
```
