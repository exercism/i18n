# 소개

## 정수형

정적 타입 언어가 대부분 그렇듯 C#도 정수를 표현하는 여러 가지 타입을 제공하며, 타입마다 값의 범위가 달라요. 범위가 가장 작은 쪽부터 보면 `sbyte` 타입은 최솟값이 -128이고 최댓값이 127이에요. 모든 정수 타입과 마찬가지로 이 값들은 `<type>.MinValue`와 `<type>.MaxValue`로 확인할 수 있어요. 반대로 범위가 가장 큰 `long` 타입은 최솟값이 -9,223,372,036,854,775,808이고 최댓값이 9,223,372,036,854,775,807이에요. 그 사이에는 `short`와 `int` 타입이 있어요.

이 범위는 시스템이 타입에 할당하는 저장 크기로 정해져요. 예를 들어 `byte`는 8비트를, `long`은 64비트를 사용해요.

위의 타입들은 각각 부호 없는 타입과 짝을 이뤄요: `sbyte`/`byte`, `short`/`ushort`, `int`/`uint`, `long`/`ulong`. 어느 경우든 값의 범위는 0부터 부호 있는 타입의 음수 최댓값에 2를 곱하고 1을 더한 값까지예요.

| 타입   | 크기   | 최솟값                     | 최댓값                      |
| ------ | ------ | -------------------------- | --------------------------- |
| sbyte  | 8 bit  | -128                       | +127                        |
| short  | 16 bit | -32_768                    | +32_767                     |
| int    | 32 bit | -2_147_483_648             | +2_147_483_647              |
| long   | 64 bit | -9_223_372_036_854_775_808 | +9_223_372_036_854_775_807  |
| byte   | 8 bit  | 0                          | +255                        |
| ushort | 16 bit | 0                          | +65_535                     |
| uint   | 32 bit | 0                          | +4_294_967_295              |
| ulong  | 64 bit | 0                          | +18_446_744_073_709_551_615 |

한 타입의 변수(또는 식)는 다른 타입으로 쉽게 변환할 수 있어요. 예를 들어 대입 연산에서, 대입되는 값의 타입(왼쪽, lhs)이 그 값이 대입되는 타입(오른쪽, rhs)의 범위 안에 확실히 들어간다면 단순한 대입으로 충분해요:

```csharp
uint ui = uint.MaxValue;
ulong ul = ui;    // no problem
```

반대로 대입되는 쪽 타입의 범위가 대입받는 쪽 범위의 부분집합이 아니라면, 특정 값이 그 범위 안에 들어가더라도 `()` 캐스트 연산이 필요해요:

```csharp
short s = 42;
uint ui = (uint)s;
```
