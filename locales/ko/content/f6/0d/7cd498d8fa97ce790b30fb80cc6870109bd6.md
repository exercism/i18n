# 설명

`accumulate` 연산을 구현해 보세요. 이 연산은 컬렉션과, 컬렉션의 각 원소에 수행할 연산을 받아서, 입력 컬렉션의 각 원소에 그 연산을 적용한 결과를 담은 새로운 컬렉션을 반환해요.

다음과 같은 숫자 컬렉션이 주어졌을 때:

- 1, 2, 3, 4, 5

그리고 다음과 같은 동작을 하는 quotation이 주어졌을 때:

- 숫자를 제곱해요 (`[ sq ]`)

코드는 다음과 같은 제곱들의 컬렉션을 만들어 낼 수 있어야 해요:

- 1, 4, 9, 16, 25

## 제한 사항

표준 라이브러리가 제공하는 collect/map/fmap, 뭐라고 부르든 그런 기능에는 손대지 마세요!

대신 다른 기본 도구만 가지고 이 문제는 직접 풀어보세요.
