# 개요

Swift는 표준 라이브러리에서 풍부한 기능을 제공하지만, 외부 라이브러리와 프레임워크를 가져오면 다양한 추가 기능을 사용할 수 있어요.
이런 모듈은 Swift 프로젝트에서 직접 올 수도 있고([Swift Argument Parser][argument-parser]처럼), Apple 플랫폼 프레임워크에서 올 수도 있으며([Foundation][apple-foundation]과 [Network Framework][network-framework]처럼), 서드파티 오픈 소스 라이브러리에서 올 수도 있어요([SwiftyBeaver][swifty-beaver]처럼).

Foundation처럼 Swift에서 가장 널리 쓰이는 라이브러리 중 하나인 핵심 모듈은 Swift 툴체인에 함께 포함되어 있어요.
서드파티 라이브러리는 가져오기 전에 프로젝트 설정에 추가해야 해요(예를 들어 Swift Package Manager를 사용해서요).

모듈을 가져오려면 `import` 키워드를 쓰고 뒤에 모듈 이름을 적어요:

```swift
import Foundation
```

모듈을 가져오면 그 모듈의 타입, 메서드, 함수를 코드에서 사용할 수 있어요.
예를 들어 Foundation을 가져오면 `String`에 `components(separatedBy:)` 같은 유용한 편의 메서드가 추가돼요.

관례적으로 `import`문은 Swift 파일 맨 위에 두어서, 코드를 읽는 사람이 의존성을 바로 확인할 수 있게 해요.

[network-framework]: https://developer.apple.com/documentation/network
[swifty-beaver]: https://github.com/SwiftyBeaver/SwiftyBeaver
