# 소개

R에는 별도의 집합 자료형이 없어요. 대신 벡터에 비슷한 연산을 수행하는 여러 함수를 사용해요.

`%in%` 연산자는 어떤 값이 집합에 속하는지 검사해요.

```R
2 %in% 1:10 # TRUE
12 %in% 1:10 # FALSE
```

관련 함수로는 중복을 제거하는 `unique`, 그리고 두 집합을 대상으로 연산하는 `union()`, `intersect()`, `setdiff()`, `setequal()` 등이 있어요.

```R
> set_1 <- c("a", "b", "c", "b", "a")
> unique(set_1) # deduplicate
[1] "a" "b" "c"

> set_2 <- c('a', "c", "d")
> union(set_1, set_2) # values in either set
[1] "a" "b" "c" "d"

> intersect(set_1, set_2) # values in both sets
[1] "a" "c"

> setdiff(set_1, set_2) # values in set_1 but not set_2
[1] "b"

> setdiff(set_2, set_1) # values in set_2 but not set_1
[1] "d"

setequal(set_1, c("c", "b", "a", "b")) # are elements the same after deduplication?
[1] TRUE
```

각 경우에 `set_1`과 `set_2`는 그대로 유지돼요.
