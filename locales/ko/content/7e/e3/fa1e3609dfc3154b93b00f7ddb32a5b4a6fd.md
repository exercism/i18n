# 안내

마술사 지망생 Elyse는 훈련을 계속해요. 그녀는 마술을 부리기 위해 여러 장의 카드 더미를 받게 될 거예요.
조금 더 쉽게 하기 위해, 그녀는 1부터 10까지의 카드만 사용해요.

이 연습 문제에서는 내장 메서드를 사용해 벡터의 내용을 분석해요.

## 1. 카드가 있는지 확인하기

Elyse는 카드가 더미에 있는지, 즉 더미에 특정 숫자가 들어 있는지 확인하려고 해요.

```R
card = 3;
does_stack_include_card(c(2, 3, 4, 5), card);
# => TRUE
```

## 2. 카드의 위치 찾기

Elyse는 더미에서 카드의 위치(인덱스)를 알고 싶어 해요.
카드가 더미에 없으면 `-1`을 반환해요.

```R
card = 2;
get_card_position(c(9, 7, 3, 2), card);
# => 4
```

## 3. 각 카드가 짝수인지 확인하기

Elyse는 모든 카드가 짝수인지, 즉 더미의 각 숫자가 짝수인지 알고 싶어 해요.

```R
is_each_card_even(c(2, 4, 6, 7));
# => FALSE
```

## 4. 더미에 홀수 값 카드가 있는지 확인하기

Elyse는 더미에 홀수가 있는지 알고 싶어 해요.

```R
does_stack_include_odd_card(c(3, 2, 6, 4, 8));
# => TRUE
```

## 5. 더미에서 첫 번째 홀수 카드 가져오기

Elyse는 홀수인 첫 번째 카드의 값을 알고 싶어 해요.  
더미에 홀수 카드가 없으면 `-1`을 반환해요.

```R
get_first_odd_card(c(4, 2, 8, 7, 9));
# => 7
```

## 6. 짝수인 첫 번째 카드의 위치 알아내기

Elyse는 짝수인 첫 번째 카드의 위치를 알고 싶어 해요.
더미에 짝수 카드가 없으면 `-1`을 반환해요.

```R
get_first_even_card_position(c(5, 2, 3, 1));
# => 2
```
