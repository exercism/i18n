# 소개

Ruby에는 표준 라이브러리(흔히 "stdlib"라고 줄여 불러요)가 함께 제공돼요. 날짜, JSON, 네트워킹 같은 것을 다루기 위한 클래스 모음이죠. 표준 라이브러리에는 code를 더 다루기 쉽게 만들어 주는 유용한 기능도 들어 있어요.

`OpenStruct`는 표준 라이브러리의 일부로, `Hash`로부터 객체를 간단히 만들 수 있게 해줘요. `Hash` 키로 접근할 필요 없이, `OpenStruct`에서는 메서드로 값을 읽고 설정할 수 있어요.

표준 라이브러리든 다른 라이브러리든, 그 클래스를 사용하려면 `require` 메서드로 해당 클래스를 불러와야 해요.

```ruby
require 'ostruct'

attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

여기에 더해, 블록 문법을 사용할 때 단축 표현을 활용할 수 있다는 보너스 장점도 있어요. 블록이 메서드 하나만 호출하는 경우에는, 블록 대신 `&:` 뒤에 메서드 이름을 붙여서 쓸 수 있어요. 예를 들어, 다음 두 줄은 같은 의미예요.

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```
