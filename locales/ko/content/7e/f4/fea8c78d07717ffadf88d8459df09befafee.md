# 안내

부두에서 화물 상자를 다시 정리하는 갑판원이에요. 각 과제는 단어 하나이고, 그 단어의 본문에서는 셔플 단어만 사용해요. 산술 연산은 쓰지 않아요.

## 1. 맨 위 상자 두 개 자리 바꾸기

`swap-crates` 단어를 정의해요. 스택에서 상자 두 개를 꺼내고, 순서를 서로 바꿔서 그대로 남겨요.

```factor
1 2 swap-crates .s
! 2
! 1
```

## 2. 엎질러진 상자 치우기

`clear-spill` 단어를 정의해요. 스택에서 상자 세 개를 꺼내고, 맨 위 상자는 버린 뒤 아래 두 개는 그대로 남겨요.

```factor
1 2 3 clear-spill .s
! 1
! 2
```

## 3. 아래에 있는 상자 복사해 두기

`peek-under` 단어를 정의해요. 스택에서 상자 두 개를 꺼내고, 그 위에 아래쪽 상자의 복사본을 올려서 남겨요.

```factor
1 2 peek-under .s
! 1
! 2
! 1
```

## 4. 갑판 정리하기

`tidy-deck` 단어를 정의해요. 스택에서 상자 세 개를 `x y z` 순서로 꺼내고, `z z y`를 남겨요. 맨 아래 상자는 버린 다음, 맨 위 상자의 복사본 두 개를 가운데 상자 아래에 남겨요.

```factor
1 2 3 tidy-deck .s
! 3
! 3
! 2
```
