# 지침

이 연습 문제에서는 로그 줄을 처리해요.

각 로그 줄은 `"[<LEVEL>]: <MESSAGE>"` 형식의 문자열이에요.

로그 레벨은 `INFO`, `WARNING`, `ERROR` 세 가지예요.

세 가지 작업이 있어요. 각 작업은 스택에서 로그 줄 하나를 꺼내요.

## 1. 로그 줄에서 메시지 가져오기

`message`를 정의해서 로그 줄의 메시지를 반환하게 해요. 앞뒤의
공백은 제거해야 해요.

```factor
"[ERROR]: Invalid operation" message .
! => "Invalid operation"

"[WARNING]:  Disk almost full\r\n" message .
! => "Disk almost full"
```

## 2. 로그 줄에서 로그 레벨 가져오기

`log-level`을 정의해서 로그 줄의 레벨을 소문자로 반환하게 해요.

```factor
"[ERROR]: Invalid operation" log-level .
! => "error"
```

## 3. 로그 줄 형식 바꾸기

`reformat`을 정의해서 메시지를 앞에 두고, 그 뒤 괄호 안에 소문자
로그 레벨을 넣어요.

```factor
"[INFO]: Operation completed" reformat .
! => "Operation completed (info)"
```

----

***참고:*** 이 연습 문제의 모든 문자열은 ASCII예요. 이후 연습 문제에서는
유니코드를 인식하는 문자열 처리를 다뤄요.
