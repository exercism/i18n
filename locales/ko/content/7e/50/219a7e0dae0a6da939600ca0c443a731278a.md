# 지시 사항

지난 7일 동안 정원에 찾아온 새가 몇 마리인지 기록해 온 열렬한 탐조가예요.

앞으로 풀어야 할 과제는 여섯 개이고, 모두 정원에 찾아온 새의 수와 관련된 내용이에요.

## 1. 오늘 몇 마리의 새가 찾아왔는지 확인하기

`today()` 함수를 구현해요. 이 함수는 오늘 정원에 찾아온 새가 몇 마리인지 반환해요. 새의 수는 날짜 순으로 정렬되어 있어요. 첫 번째 원소는 가장 오래된 날의 수이고, 마지막 원소는 오늘의 수예요.

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
today(birds_per_day)
# => 1
```

## 2. 오늘의 수 늘리기

`increment_todays_count()` 함수를 구현해 오늘의 수를 늘려요:

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
increment_todays_count(birds_per_day)
# => c(2, 5, 0, 7, 4, 2)
```

## 3. 새가 찾아오지 않은 날이 있었는지 확인하기

`has_day_without_birds()` 함수를 구현해요. 정원에 새가 한 마리도 찾아오지 않은 날이 있으면 `TRUE`를 반환하고, 그렇지 않으면 `FALSE`를 반환해요:

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
has_day_without_birds(birds_per_day)
# => true
```

## 4. 첫 며칠 동안 찾아온 새의 수 계산하기

`count_for_first_days()` 함수를 구현해요. 이 함수는 이번 주가 시작된 이후 정원에 찾아온 새의 수를 반환하되, 세는 범위는 이번 주 시작부터 지정한 일수까지만으로 제한해요.

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
count_for_first_days(birds_per_day, 4)
# => 14
```

## 5. 바쁜 날의 수 계산하기

어떤 날은 다른 날보다 더 바빠요. 바쁜 날은 정원에 다섯 마리 이상의 새가 찾아온 날이에요.
`busy_days()` 함수를 구현해 바쁜 날의 수를 반환해요:

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
busy_days(birds_per_day)
# => 2
```

## 6. 지난 한 주 동안의 새 방문 누적 합계 계산하기

이번 주에 지금까지 새가 모두 몇 마리 찾아왔는지 궁금해요.
날짜별 누적 합계를 계산해요.

```R
running_total(c(7, 6, 5, 4, 3, 2, 1))
#> [1]  7 13 18 22 25 27 28
```

## 7. 바쁜 정도에 따라 요일 이름 정렬하기

새의 방문이 근처 도로 교통 패턴의 영향을 받아서, 주말과 평일이 서로 다르다고 생각해요.

방문한 새의 수를 기준으로 요일 약어를 _내림차순_으로 정렬해요.

```R
day_names <- c("Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun")
birds_per_day <- c(5, 2, 4, 6, 0, 9, 8)
busy_days_of_week(birds_per_day, day_names)
#> [1] "Sat" "Sun" "Thu" "Mon" "Wed" "Tue" "Fri"
```
