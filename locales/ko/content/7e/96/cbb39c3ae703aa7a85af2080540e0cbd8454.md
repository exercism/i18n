# 소개

## 배열과 벡터

C++은 같은 타입의 원소를 순서대로 저장할 수 있는 여러 가지 컨테이너를 제공해요.
크기가 고정된 컨테이너인 `std::array`가 있고, 동적으로 크기를 조정할 수 있는 `std::vector`도 있어요.

### 생성

배열이나 벡터를 선언할 때는 그 컨테이너가 담을 원소의 타입을 지정해야 해요.
배열은 크기도 필요해요.
다음 예제에서 두 컨테이너 타입의 초기화 방법을 살펴봐요:

```cpp
#include <array>
#include <string>

// std::array<element_type, size> variable_name {list of elements}
std::array<std::string, 3> indie_rock {"yeah", "yeah", "yeah"};
// indie_rock contains the elements "yeah" three times
```

벡터는 보통 더 많은 공간을 필요로 해요.
더 커질 것을 대비해 메모리를 할당하기 때문이에요.
대신 크기를 지정할 필요는 없어요:

```cpp
#include <vector>

// std::vector<element_type> variable_name {list of elements}
std::vector<int> countdown {3, 2, 1};
// countdown contains the elements 3, 2 and 1
```

> 참고: 아직 템플릿 개념의 정확한 동작 원리를 알 필요는 없어요. 템플릿은 커리큘럼 트리에서 더 아래에 자체 개념으로 다뤄요.

### 원소 접근

벡터와 배열은 원소에 접근하는 데 쓰는 함수가 같아요.
멤버 함수 `front`와 `back`을 사용하면 컨테이너의 첫 번째와 마지막 원소를 가져올 수 있어요.
특정 원소에 접근할 때는 `at`과 `[]` 연산자도 사용할 수 있어요.

```cpp
countdown[0];
// => 3
countdown.at(2);
// => 1
countdown[1] = 4;
// countdown now contains 3, 4 and 1
indie_rock.back() = "yeahs";
// indie_rock is now "yeah", "yeah", "yeahs"
```

> 참고: 컨테이너의 범위를 벗어난 위치를 고르면 `[]`는 정의되지 않은 동작을 일으킬 수 있어요.
> `at` 함수는 예외를 발생시키는데, 장기적으로는 이쪽이 더 편할지도 몰라요.

### 벡터 요소 수정

`vector`는 크기가 고정되어 있지 않아서 원소를 추가하거나 제거할 수 있어요.
이를 위한 대표적인 함수 두 가지는 `emplace_back`과 `pop_back`이에요.

```cpp
std::vector<std::string> witches {"Holly", "Alyssa", "Shannen"};
witches.pop_back();
// Shannen is no longer with the witches
witches.emplace_back("Rose");
// Rose has joined the team
```

### 용량

멤버 함수 `empty`로 컨테이너가 비어 있는지 확인할 수 있어요.
원소의 개수를 알고 싶다면 `size`를 사용하면 돼요.
