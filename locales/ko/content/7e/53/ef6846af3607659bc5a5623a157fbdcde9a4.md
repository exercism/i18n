# 삼항 연산자

삼항 연산자는 간단한 `if/else`문을 더 짧게 쓰는 방법이에요.
`if/else`문에 조건이 참일 때 실행되는 갈래와 거짓일 때 실행되는 갈래, 이렇게 두 갈래만 있다면 삼항 연산자로 다시 쓸 수 있어요.

삼항 연산자는 `?`와 `:` 기호를 조합해서 조건을 나눠요:
```ruby
condition ? true_branch : false_branch
```

`?`의 왼쪽에 있는 코드가 조건이고, 오른쪽에는 `:`로 구분된 두 갈래가 들어 있어요.
조건이 _참_이면 `:`의 _왼쪽_ 코드가 실행돼요.
조건이 _거짓_이면 `:`의 _오른쪽_ 코드가 실행돼요.

예를 들어 볼까요:

```ruby
if traffic_light == 'green'
  cross_the_road
else
  wait
end
```

이 코드는 다음과 같이 다시 쓸 수 있어요:

```ruby
traffic_light == 'green' ? cross_the_road : wait
```
