# `jq`의 함수

`jq`에서는 필요한 로직을 캡슐화하기 위해 직접 **사용자 정의 함수**를 정의할 수 있어요.
_함수_는 내장 함수와 똑같이 동작해요. 입력을 받아서 0개, 1개 또는 그 이상의 출력을 내보내요.

## 함수 정의하기

다음 문법으로 `jq` _함수_를 정의할 수 있어요:

```jq
# no arguments
def funcname: expression;

# or with arguments
def funcname(args): expression;
```

- `def` 키워드로 시작하고,
- 함수 본문 앞에 콜론이 오고,
- 본문은 하나의 표현식으로 이루어지고,
- 세미콜론으로 끝나요,
- `jq` 문법의 나머지 부분과 마찬가지로, 가독성을 위해 공백을 마음대로 사용할 수 있어요.

## 함수를 어디에 둘까요

_함수_는 사용하기 전에 정의해야 해요. 다음은 오류예요:

```jq
def A: B(10);
def B(n): n + 1;
A
# => error: B/1 is not defined
```

따라서 _함수_는 `jq` 코드의 맨 위, 즉 "메인" 표현식 앞에 두어야 해요.

### 중첩 함수

_함수_는 중첩할 수 있어요:

```jq
def A:
    def B(n): n + 1;
    B(10)
    ;
A
# => 11
```

여기서 `B` _함수_는 `A`의 본문 안에서만 보여요.

## 스코프

_함수_는 변수와 중첩 함수를 위한 새로운 **스코프**를 만들어요.

## 인자

_함수_의 **인자**는 쉼표가 아니라 _세미콜론_으로 구분해요.
예를 들어, 숫자를 받아서 어떤 숫자를 더하고 어떤 숫자를 곱하는 _함수_는 다음과 같아요:

```jq
def add_mul(adder; multiplier): (. + adder) * multiplier;

10 | add_mul(5; 4)    # => 60
```

```jq
10 | add_mul(5, 4)
```

### 인자는 _표현식_이에요

함수 _인자_는 값이 아니라 필터예요.
이런 점에서 다른 언어에서 콜백이라고 부르는 것처럼 동작해요:

`add_mul` 함수를 예로 들어 볼게요:

```jq
10 | add_mul(. + 5; . - 2)    # => 200
```

여기서 무슨 일이 일어나고 있을까요?

- `adder` 인자는 _표현식_ `. + 5`를 받아요
  - 함수가 `. + adder`를 수행하면 `. + . + 5`가 돼요
  - `. == 10`이므로 25로 평가돼요
- 마찬가지로 `multiplier` 인자는 표현식 `. - 2`예요
  - 8로 평가되고
  - 그러면 결과는 `25 * 8 == 200`이 돼요

### 인자를 값으로 사용하기

때로는 _인자_를 변수로 "구체화"하고 싶을 때가 있어요:

```jq
def my_func(arg):
    arg as $arg
    | other stuff ...
;
```

이를 위한 축약형이 있어요:

```jq
def my_func($arg):
    other stuff ...
;
```

이것은 단지 "문법적 설탕"일 뿐이라는 점에 유의해요. `$`가 없는 `arg`라는 이름도 여전히 _함수_ 안에서 스코프에 있어요.

## 인자 개수

_함수_에는 **인자 개수**가 있어요. 즉 함수가 받는 _인자_의 수예요.

_함수_는 같은 이름을 서로 다른 _인자 개수_로 사용할 수 있어요.
내장 [`range`][man-range] 함수가 이를 보여줘요: `range/1`, `range/2`, `range/3`이 모두 함께 존재해요.

이것은 인자를 통해 상태를 전달하는 재귀 함수를 정의할 때 유용해요.
예를 들어 `map`은 다음과 같이 구현할 _수_ 있어요:

```jq
def my_map($accumulator; func):
    if length == 0
        then $accumulator
        else first as $elem | .[1:] | my_map($accumulator + [$elem | func]; func)
    end
    ;

def my_map(func):
    my_map([]; func)
    ;

[1, 2, 3, 4] | my_map(. * 10)   # => [10, 20, 30, 40]
```

## 재귀

`jq`는 꼬리 호출 최적화를 수행하지만, 인자 개수가 0인 함수에만 해당해요.
