# Hints

## General

- 시작하기 가이드에서 [구조체][getting-started-structs]에 대해 읽어봐요.
- 문서에서 [`defstruct`][docs-defstruct]에 대해 읽어봐요.
- [Elixir Casts - #106: Intro to Structs][elixir-casts]를 시청해 봐요.

## 1. 완전히 새로운 원격 조종 자동차 만들기

- `@enforce_keys` 모듈 속성을 사용하면 필수 값을 지정할 수 있어요. `defstruct`를 호출하기 전에 정의해야 해요.
- `nickname` 필드에는 기본값을 지정하면 안 돼요.
- `new/0` 함수는 `nickname`을 `"none"` 값으로 초기화해야 해요.

## 2. 닉네임이 있는 완전히 새로운 원격 조종 자동차 만들기

- 함수 이름은 그대로 두고 다른 인자를 받으려면 [`multiple-function-clauses`][multiple-fn-clauses]를 사용해요.
- 함수에 [`default-argument`][default-arg]을 사용하는 것도 고려해 봐요.

## 3. 거리 표시하기

- 특정한 타입의 구조체만 받는 함수라면, 반드시 패턴 매칭을 해서 인자를 확인해야 해요.
- 필드 값을 가져오려면 _정적 접근 연산자_를 사용해요.

## 4. 배터리 잔량 표시하기

- 특정한 타입의 구조체만 받는 함수라면, 반드시 패턴 매칭을 해서 인자를 확인해야 해요.
- 필드 값을 가져오려면 _정적 접근 연산자_를 사용해요.

## 5. 주행하면 배터리와 주행 거리가 바뀌어요

- 특정한 타입의 구조체만 받는 함수라면, 반드시 패턴 매칭을 해서 인자를 확인해야 해요.
- 필드 값을 가져오려면 _정적 접근 연산자_를 사용해요.
- 구조체를 업데이트하는 방법은 도입부를 다시 확인해 봐요.

## 6. 배터리가 방전된 상태로 주행하는 경우 처리하기

- 배터리가 방전되어 있으면 구조체를 그대로 반환해야 해요.
