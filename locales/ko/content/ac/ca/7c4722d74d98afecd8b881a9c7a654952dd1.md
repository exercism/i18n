# 소개

무언가를 자기 자신을 이용해 정의할 수 있는 성질을 재귀라고 해요. Gleam에서는 스스로를 호출하는 함수인 재귀 함수에서 재귀를 가장 흔히 만날 수 있어요.

재귀 함수에는 _기저 사례_가 적어도 하나, _재귀 사례_가 적어도 하나 있어야 해요. _기저 사례_는 함수를 다시 호출하지 않고 값을 반환해요. _재귀 사례_는 함수를 다시 호출하는데, 이때 입력을 바꿔서 언젠가는 기저 사례에 맞아떨어지게 만들어요.

```gleam
pub fn factorial(x: Int) -> Int {
  case x {
    // Base case
    1 -> 1

    // Recursive case
    _ -> x * factorial(x - 1)
  }
}
```

Gleam에는 루프를 위한 특별한 문법이 없어서, 모든 루프는 재귀로 처리해요.

```gleam
pub fn list_length(list: List(String)) -> Int {
  case list {
    [] -> 0
    [_, ..rest] -> 1 + list_length(rest)
  }
}
```

Gleam은 재귀 사용자 정의 타입도 지원해요. 재귀 사용자 정의 타입은 변형 중 하나 이상이 담고 있는 데이터에서 자기 자신을 참조해요.

```gleam
pub type RussianDoll {
  Child               // Base case
  Mother(RussianDoll) // Recursive case
}
```
```gleam
let very_big_doll = Mother(Mother(Mother(Child)))
let small_doll = Mother(Child)
```
