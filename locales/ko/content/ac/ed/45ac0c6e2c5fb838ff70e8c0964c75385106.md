# 연습 문제 풀기

Exercism이 학습을 돕는 가장 기본적인 방법은 연습 문제를 푸는 거예요.

Exercism에서 연습 문제를 푸는 방법은 두 가지가 있어요.

1. [웹사이트의 브라우저 편집기에서 온라인으로 풀기](/docs/using/solving-exercises/using-the-online-editor)
2. [내 컴퓨터에서 CLI로 풀기](/docs/using/solving-exercises/working-locally)

## 어떤 방법을 선택해야 할까요?

온라인 편집기를 쓰는 것과 CLI를 쓰는 것에는 각각 장단점이 있어요.

|            | 온라인 편집기                          | CLI                                          |
| ---------- | -------------------------------------- | -------------------------------------------- |
| 설치       | 필요 없어요                            | 필요해요 (예: SDK)                           |
| 편집       | 브라우저                               | 원하는 편집기                                |
| 테스트     | 웹사이트에서 테스트 실행               | 로컬에서 테스트 실행                         |
| 디버깅     | 제한적 지원 (일부 트랙만)              | 완전 지원 (사용 환경에 따라)                 |

일반적으로 온라인 편집기는 새 트랙을 시작할 때 알맞고, CLI를 사용하는 방식은 자신만의 코딩 환경을 쓰고 싶을 때 잘 맞아요.
