# 지침

삼각형이 equilateral, isosceles, scalene 중 어느 것인지 판별해요.

_equilateral_ 삼각형은 세 변의 길이가 모두 같아요.

_isosceles_ 삼각형은 적어도 두 변의 길이가 같아요.
(때로는 정확히 두 변의 길이가 같다고 정의하기도 하지만, 이 연습 문제에서는 적어도 두 변이라고 할게요.)

_scalene_ 삼각형은 모든 변의 길이가 서로 달라요.

## 참고

어떤 도형이 삼각형이 되려면 모든 변의 길이가 0보다 커야 하고, 임의의 두 변의 길이의 합이 나머지 한 변의 길이보다 크거나 같아야 해요.

식을 쓰면 다음과 같아요:

삼각형의 변을 각각 `a`, `b`, `c`라고 해요.
그러면 다음 세 식이 모두 성립해야 해요:

```text
a + b ≥ c
b + c ≥ a
a + c ≥ b
```

[삼각형 부등식][triangle-inequality]을 참고해요.
