# 소개

레퍼런스를 이해하는 것은 Perl을 효과적으로 사용하는 데 있어 기본이 되는 요소예요.
레퍼런스는 스칼라이고, 배열과 해시는 스칼라만 담을 수 있기 때문에, 레퍼런스는 이러한 자료 구조를 중첩하는 데 핵심이에요.

백슬래시 연산자 `\`를 사용하면 기존 변수와 서브루틴에 대한 레퍼런스를 만들 수 있어요.

* `\$scalar`로 스칼라 레퍼런스를 만들어요 (변수뿐 아니라 `\1`처럼 어떤 스칼라든 될 수 있어요).
* `\@array`로 배열 레퍼런스를 만들어요.
* `\%hash`로 해시 레퍼런스를 만들어요.
* `\&sub`로 코드 레퍼런스를 만들어요.

배열, 해시, 서브루틴에 대해서는 익명 레퍼런스라고 하는 것도 만들 수 있어요.

* `['Alice', 'Bob', 'Charlie']`로 익명 배열 레퍼런스를 만들어요.
* `{foo => 'a', bar => 'b', baz => 'c'}`로 익명 해시 레퍼런스를 만들어요.
* `sub { return 1 }`로 익명 코드 레퍼런스를 만들어요.

경고: Perl에서 중괄호는 특정 상황에서 모호할 수 있어요. 기대한 해시 레퍼런스가 나오지 않으면 앞에 플러스를 붙여 모호함을 없애요. 예를 들어 `+{}`처럼요. 더 자세한 내용은 [중괄호][perlrefcurlybrackets]를 참고해요.

화살표 연산자 `->`를 사용하면 레퍼런스에 접근할 수 있어요.

* `$ref->[0]`로 배열 레퍼런스 안의 원소에 접근해요.
* `$ref->{foo}`로 해시 레퍼런스 안의 값에 접근해요.
* `$ref->($arg)`로 코드 레퍼런스를 통해 서브루틴을 호출해요.

다차원 배열이나 중첩된 해시처럼 복잡한 자료 구조 안의 데이터는 첨자를 연결해 접근할 수 있어요. 예를 들어 `$ref->{foo}[0]{bar}`는 `$ref->{foo}->[0]->{bar}`와 같아요.

배열이나 해시 전체를 역참조하고 싶다면, 화살표 연산자 뒤에 각각 `@*` 또는 `%*`를 붙이면 돼요. 예를 들어 `$ref->@*`나 `$ref->%*`처럼요.
`*`를 첨자로 바꾸면 배열이나 해시 레퍼런스의 슬라이스를 얻을 수도 있어요. 예를 들어 `$ref->@[0..2]`나 `$ref->@{'Foo', 'Bar'}`처럼요.
슬라이스에서는 배열 변수와 해시 변수에서와 같은 방식으로 시길이 달라지는 규칙이 적용돼요.

[perlrefcurlybrackets]: https://perldoc.perl.org/perlref#Curly-Brackets
