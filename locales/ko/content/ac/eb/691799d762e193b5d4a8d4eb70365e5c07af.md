# 지침

Bob은 재무 고문으로, 사람들이 지출을 관리하도록 도와줘요.
Bob의 고객들은 분석을 위해 Bob에게 지출 기록을 보내요.
Bob은 이전 기간의 기록을 가지고 있어서 지출의 변화를 볼 수 있어요.
Bob은 달력을 좋아하지 않아서 날짜 대신 *Bob epoch*를 사용해요.
Bob epoch는 Bob의 고객이 활동을 시작한 이후 지나간 일수예요.

이 연습 문제에서는 Bob이 고객의 지출을 관리하고 분석하는 것을 돕는 프로그램을 만들 거예요.

Bob은 `Record`와 `DaysPeriod`를 다뤄요.

`Record`는 지출이 발생한 날, 사용한 금액, 지출의 카테고리를 담고 있는 지출 기록을 나타내요.

```go
// Record represents an expense record.
type Record struct {
	Day         int
	Amount      float64
	Category    string
}
```

`DaysPeriod`는 날짜 범위를 나타내고, `From` 날부터 `To` 날까지의 모든 날을 포함해요.
범위에는 양 끝이 모두 포함돼요.

```go
// DaysPeriod represents a period of days.
type DaysPeriod struct {
	From int
	To   int
}

p := DaysPeriod{From: 1, To: 31}
// p represents all days from the day 1 to the day 31:
//  - days 1, 20, 16 and 31 are examples of days that are included
//    in the range of time specified by p
//  - days 50 and 40 are examples of days that are not included
//    in the range of time specified by p
```

## 1. 일반적인 기록 필터 구현하기

Bob은 매일 많은 기록을 다루지만, 하고 있는 분석에 따라 모든 기록이 흥미로운 것은 아니에요.
Bob이 기록을 기본적으로 필터링할 수 있도록 도와봐요.

함수로 주어진 기준에 따라 기록을 필터링하는 제네릭 `Filter` 함수를 구현해요.
이 필터 함수는 기록 모음과 조건 함수를 받아서, 그 조건을 만족하는 기록만 반환해요.

```go
records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
}

// Day1Records only returns true for records that are from day 1
func Day1Records(r Record) bool {
  return r.Day == 1
}

Filter(records, Day1Records)
// =>
// [
//   {Day: 1, Amount: 15, Category: "groceries"}
// ]
```

## 2. 기간 내의 기록 필터링하기

Bob은 주어진 기간에 속한 기록을 자주 필터링해야 해요.

Bob이 그런 필터를 만들도록 도와줄 `ByDaysPeriod` 함수를 구현해요.
이 함수는 `DaysPeriod`를 받아서, 기록을 받아 그 기록이 인자로 주어진 `DaysPeriod`가 지정한 기간에 속하는지 알려주는 함수를 반환해요.

```go
records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
  {Day: 26, Amount: 300, Category: "university"},
  {Day: 28, Amount: 1300, Category: "rent"},
}

period := DaysPeriod{From: 1, To: 15}

Filter(records, ByDaysPeriod(period))
// =>
// [
//   {Day: 1, Amount: 15, Category: "groceries"},
//   {Day: 11, Amount: 300, Category: "utility-bills"},
//   {Day: 12, Amount: 28, Category: "groceries"},
// ]
```

## 3. 카테고리별로 기록 필터링하기

Bob은 기간으로 기록을 필터링하는 것 외에도 카테고리로 기록을 필터링해야 해요.

Bob이 그런 필터를 만들도록 도와줄 `ByCategory` 함수를 구현해요.
이 함수는 카테고리를 받아서, 기록을 받아 그 기록의 카테고리가 인자로 주어진 카테고리와 같은지 알려주는 함수를 반환해요.

```go
records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
  {Day: 28, Amount: 1300, Category: "rent"},
}

Filter(records, ByCategory("groceries"))
// =>
// [
//   {Day: 1, Amount: 15, Category: "groceries"},
//   {Day: 12, Amount: 28, Category: "groceries"},
// ]
```

## 4. 기간 내 지출 총액 계산하기

Bob은 기간 내 지출의 총액도 알고 싶어 해요.

해당 날짜 기간의 지출 합계를 반환하는 `TotalByPeriod` 함수를 구현해요.

```go
records := []Record{
  {Day: 15, Amount: 16, Category: "entertainment"},
  {Day: 32, Amount: 20, Category: "groceries"},
  {Day: 40, Amount: 30, Category: "entertainment"}
}

p1 := DaysPeriod{From: 1, To: 30}
p2 := DaysPeriod{From: 31, To: 60}

TotalByPeriod(records, p1)
// => 16

TotalByPeriod(records, p2)
// => 50
```

## 5. 기간 내 특정 카테고리 기록의 지출 총액 계산하기

Bob이 고객에게 제공하는 가장 복잡한 보고서를 위해서는, 카테고리와 기간으로 동시에 기록을 필터링해야 해요.
즉, Bob은 주어진 기간에 특정 카테고리에 속한 기록의 지출 총액을 알고 싶어 하는 거예요.

주어진 날짜 기간에 특정 카테고리의 지출 총액을 반환하는 `CategoryExpenses` 함수를 구현해요.
이 함수는 주어진 카테고리가 지출 기록에 아예 없는 경우와, 주어진 기간에 그 카테고리의 지출이 없는 경우를 구분해야 해요.
카테고리가 어떤 기록에도 속하지 않을 때(기간과 상관없이) 함수는 오류를 반환해야 해요.

```go
p1 := DaysPeriod{From: 1, To: 30}
p2 := DaysPeriod{From: 31, To: 60}

records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
  {Day: 26, Amount: 300, Category: "university"},
  {Day: 28, Amount: 1300, Category: "rent"},
}

CategoryExpenses(records, p1, "entertainment")
// => 0, error(unknown category entertainment)

CategoryExpenses(records, p1, "rent")
// => 1300, nil

CategoryExpenses(records, p2, "rent")
// => 0, nil
```
