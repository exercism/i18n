# `_is`와 물음표를 사용하는 defmacro

[comment]: # (매개변수 3개가 필요해요:)
[comment]: # (- actual: 학생이 사용한 잘못된 이름)
[comment]: # (- option1: 함수에 맞는 올바른 이름)
[comment]: # (- option2: 가드에 맞는 올바른 이름)

Elixir에는 고유한 작명 규칙이 있는데, 여기에는 [불리언을 반환하는 함수](https://hexdocs.pm/elixir/naming-conventions.html#trailing-question-mark-foo)의 이름을 짓는 방법과 [불리언을 반환하면서 가드 절에서도 사용할 수 있는 검사](https://hexdocs.pm/elixir/naming-conventions.html#is_-prefix-is_foo)의 이름을 짓는 방법이 포함돼요:

> 불리언을 반환하는 함수는 이름 끝에 물음표를 붙여요.

> 타입 검사와 가드 절에서 허용되는 기타 불리언 검사는 이름 앞에 `is_` 접두사를 붙여요.

매크로는 두 상황 모두에서 사용할 수 있어서 표기법은 경우에 따라 달라요. 하지만 두 작명 규칙을 섞어서는 안 돼요.

```elixir
# this is the expected name of macros that return booleans

%{option1}

# this is the expected name of macros that return booleans and are valid in guard clauses

%{option2}

# this is the current name

%{actual}
```
