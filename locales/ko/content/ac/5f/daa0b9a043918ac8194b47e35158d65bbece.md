# 힌트

## 일반

- `H{ } clone`은 새롭고 변경 가능한 해시테이블을 시작하는 올바른 방법이에요. `H{ }` 리터럴은 호출 사이에 공유될 수 있거든요.
- [`assocs`][assocs]의 `inc-at`은 키의 값에 1을 더해요 (키가 없으면 값 1로 삽입해요).

## 1. 목록에서 인벤토리 만들기

- 각 원소마다 `H{ } clone`과 `inc-at`으로 시작해요. fry 쿼테이션 `'[ _ inc-at ]`는 해시테이블을 캡처하므로 `each`로 넘길 수 있어요.
- 반복을 `[ … ] keep`으로 감싸면 해시테이블이 스택에 남는 값이 돼요.

## 2. 항목 더 추가하기

- 작업 1과 형태는 같아요. 다만 빈 해시테이블이 아니라 입력 인벤토리의 `clone`에서 시작해요.

## 3. 개수 줄이기

- 먼저 `key?`를 사용해요. 인벤토리에 이미 있는 항목만 건드려요.
- `change-at`은 쿼테이션 `( old -- new )`를 받아요. 이걸 `[ 1 - 0 max ]`와 짝지어서 ([`math.order`][math.order]의 `max`를 사용해요) 개수가 절대 음수가 되지 않게 해요.

## 4. 항목 완전히 제거하기

- `delete-at`은 해시테이블을 변경하고 아무것도 반환하지 않아요. 먼저 `clone`한 다음 `delete-at`을 하고, 그 복제본을 스택에 남겨요.

## 5. 사용 가능한 항목 나열하기

- `>alist`는 해시테이블을 쌍의 시퀀스로 변환해요.
- `[ second 0 > ] filter`는 재고가 있는 항목만 남겨요.
- `sort-keys`는 [`sorting`][sorting]에 있으며, alist를 키 기준으로 정렬해요.
