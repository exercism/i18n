# 안내

이 연습 문제에서는 로그 라인을 처리해요.

각 로그 라인은 다음과 같은 형식의 문자열이에요: `"[<LVL>]: <MESSAGE>"`.

로그 레벨은 다음과 같아요:

- `TRC` (추적)
- `DBG` (디버그)
- `INF` (정보)
- `WRN` (경고)
- `ERR` (오류)
- `FTL` (치명적)

필요한 기능을 모두 갖추려면 세 가지 작업을 각각 완료해야 해요.

## 1. LogLevel 열거형 만들기

위의 로그 레벨에 해당하는 여섯 개의 케이스와, 로그 레벨이 없거나 표준이 아닌 경우를 위한 unknown 케이스를 가진 `LogLevel` 열거형을 정의해요.

- `trace`
- `debug`
- `info`
- `warning`
- `error`
- `fatal`
- `unknown`

## 2. 로그 레벨 파싱하기

다음으로, 로그 라인의 로그 레벨을 파싱하는 `LogLevel` 이니셜라이저를 구현해요:

```swift
LogLevel("[INF]: File deleted")
// Returns LogLevel.info
LogLevel("Something went wrong!")
// Returns LogLevel.unknown
```

## 3. 로그 라인을 짧은 형식으로 변환하기

로그 라인의 로그 레벨은 꽤 길어요.
로그 라인을 저장하는 데 필요한 디스크 공간을 줄이기 위해 짧은 형식을 만들었어요: `"<ENCODED_LEVEL>:<MESSAGE>"`.

인코딩된 로그 레벨은 로그 레벨을 숫자로 단순하게 매핑한 것이에요:

- `trace` - `0`
- `debug` - `1`
- `info` - `4`
- `warning` - `5`
- `error` - `6`
- `fatal` - `7`
- `unknown` - `42`

짧아진 로그 라인 형식을 `String`으로 출력하는 `shortFormat(message: String) -> String` 메서드를 구현해요:

```swift
let overflow = LogLevel.error
overflow.shortFormat(message: "Stack overflow")
// Returns "6:Stack overflow"
```
