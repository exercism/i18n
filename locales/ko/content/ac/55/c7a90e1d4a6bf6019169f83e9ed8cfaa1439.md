# 힌트

## 일반

- 기본기를 되새기고 싶다면 [객체 개념][concept-objects]을 다시 살펴봐요.

## 1. 창의 크기를 저장하는 Size 정의하기

- 이번 과제에서는 [프로토타입 문법][mdn-prototype]을 사용해야 한다는 점을 기억해요.
- `Size`라는 이름의 함수를 정의하는 것부터 시작하고, 반드시 [내보내기][mdn-export] 해야 해요.
- 생성자 함수에 전달된 인자는 `this` 객체에 추가해야 해요.
- 기본값은 [기본 매개변수][mdn-default-params]를 사용해 적용할 수 있어요.
- 생성자 함수의 `prototype` 속성을 통해 메서드를 추가할 수 있어요.

## 2. 창의 위치를 저장하는 Position 정의하기

- 이번 과제에서는 [프로토타입 문법][mdn-prototype]을 사용해야 한다는 점을 기억해요.
- `Position`이라는 이름의 함수를 정의하는 것부터 시작하고, 반드시 [내보내기][mdn-export] 해야 해요.
- 생성자 함수에 전달된 인자는 `this` 객체에 추가해야 해요.
- 기본값은 [기본 매개변수][mdn-default-params]를 사용해 적용할 수 있어요.
- 생성자 함수의 `prototype` 속성을 통해 메서드를 추가할 수 있어요.

## 3. ProgramWindow 클래스 정의하기

- 이번 과제에서는 [클래스 문법][mdn-class]을 사용해야 한다는 점을 기억해요.
- 클래스를 반드시 [내보내기][mdn-export] 해야 해요.
- `this` 객체에 필드를 추가해 정의해요.
- 앞선 과제에서 정의한 클래스를 활용해요.
- 생성자 함수가 어떤 인자도 받지 않는지 확인해요.

## 4. 창 크기를 조절하는 메서드 추가하기

- 이번 과제에서는 [클래스 문법][mdn-class]을 사용해야 한다는 점을 기억해요.
  즉, 메서드 정의를 클래스 본문에 바로 추가해요.
- 크기 조절에 사용할 올바른 값을 찾으려면, 먼저 도달하고자 하는 너비를 생각하고 하한(`1`)을 고려해요.
- 그런 다음 화면 크기와 창의 현재 `x` 위치를 고려해 허용되는 최대 너비를 계산해요.
- 이 두 값을 가지고 무엇을 적용할지 결정하고, 높이에도 같은 방식의 논리를 적용해요.
- 변경 사항을 적용하려면 `Size` 객체의 `resize` 메서드를 사용해요.

## 5. 창을 이동하는 메서드 추가하기

- 이번 과제에서는 [클래스 문법][mdn-class]을 사용해야 한다는 점을 기억해요.
  즉, 메서드 정의를 클래스 본문에 바로 추가해요.
- 이동에 사용할 올바른 값을 찾으려면, 먼저 도달하고자 하는 `x` 위치를 생각하고 하한(`0`)을 고려해요.
- 그런 다음 허용되는 최대 `x` 값을 계산해요.
  화면 크기와 창의 현재 너비를 고려해요.
- 이 두 값을 가지고 무엇을 적용할지 결정하고, 높이에도 같은 방식의 논리를 적용해요.
- 변경 사항을 적용하려면 `Position` 객체의 `move` 메서드를 사용해요.

## 6. 프로그램 창 변경하기

- 먼저 `changeWindow` 함수를 정의하고, 반드시 [내보내기][mdn-export] 해야 해요.
- `new` 키워드로 `Size` 클래스의 인스턴스를 만들고 원하는 크기를 인자로 전달해요. (필요한 위치 객체도 마찬가지예요.)
- 과제 4와 5에서 정의한 메서드를 사용해요. 예를 들어, 객체 `obj`의 메서드 `a`는 `obj.a()`로 호출해요.
- 입력으로 받은 `Window` 인스턴스를 반드시 반환해요.
