# 소개

*축약*은 시퀀스의 원소들을 하나의 값으로 결합해요(또는 각 단계의 값을 모은 새로운 시퀀스를 만들어요). Factor에서 범용으로 쓸 수 있는 축약 연산은 `reduce`예요. `math.statistics`에는 누적 합, 누적 곱, 누적 최솟값, 누적 최댓값처럼 누적 연산 모음이 더 있어요. 마지막 결과 하나가 아니라 모든 중간 결과가 필요할 때 쓰면 돼요.

```factor
USING: math math.statistics sequences ;

{ 2 5 1 3 } 0 [ + ] reduce .         ! => 11

{ 2 5 1 3 } cum-sum .                ! => { 2 7 8 11 }
{ 2 5 1 3 } cum-product .            ! => { 2 10 10 30 }
{ 2 5 1 3 } cum-min .                ! => { 2 2 1 1 }
{ 2 5 1 3 } cum-max .                ! => { 2 5 5 5 }
```

[math.statistics]: https://docs.factorcode.org/content/vocab-math.statistics.html
