# 소개

함수를 사용하면 코드를 재사용할 수 있는 하나의 단위로 묶을 수 있어요.
함수는 `func` 키워드, 함수 이름, 그리고 괄호 안에 쉼표로 구분된 0개 이상의 매개변수와 타입으로 이루어져 있어요.

## 함수 매개변수

모든 매개변수는 타입을 명시해야 해요. 매개변수에는 타입 추론이 없어요.
매개변수에는 기본값이 없어서 모든 함수 매개변수가 필수예요.

```go
import "fmt"

// No parameters
func PrintHello() {
    fmt.Println("Hello")
}

// Two parameters
func PrintGreetingName(greeting string, name string) {
  fmt.Println(greeting + " " + name)
}
```

같은 타입의 매개변수는 함께 선언하고 뒤에 타입을 한 번만 적어줄 수 있어요.

```go
import "fmt"

func PrintGreetingName(greeting, name string) {
  fmt.Println(greeting + " " + name)
}
```

## 매개변수와 인자

자주 헷갈리는 두 용어, `parameters`와 `arguments`를 잠깐 짚어볼까요?
함수 매개변수는 함수 시그니처에 정의된 이름이에요. 위의 `PrintGreetingName` 함수에서 `greeting`과 `name`이 바로 매개변수예요.
함수 인자는 함수를 호출할 때 매개변수에 전달되는 실제 값이에요.
예를 들어 아래 예제에서 `"Hello"`와 `"Katrina"`는 `greeting`과 `name` 매개변수에 전달되는 인자예요.

```go
PrintGreetingName("Hello", "Katrina")
```

## 반환 값

함수 매개변수 뒤에는 0개 이상의 반환 값이 오는데, 이것도 타입을 명시해야 해요.
반환 값이 하나면 그냥 쓰고, 여러 개면 괄호로 감싸요.
함수에서 호출한 코드로 값을 반환할 때는 `return` 키워드를 사용해요.
함수 안에는 여러 개의 `return` 문이 있을 수 있어요.
함수는 이 `return` 문 중 하나에 도달하면 곧바로 실행이 끝나요.
함수에서 여러 값을 반환할 때는 쉼표로 구분해요.

```go
func Hello(name string) string {
  return "Hello " + name
}

func HelloAndGoodbye(name string) (string, string) {
  return "Hello " + name, "Goodbye " + name
}
```

## 함수 호출하기

함수를 호출할 때는 함수 이름을 쓰고, 괄호 안에 함수의 각 매개변수에 맞는 인자를 전달해요.

```go
import "fmt"

// No parameters, no return value
func PrintHello() {
    fmt.Println("Hello")
}
// Called like this:
PrintHello()

// One parameter, one return value
func Hello(name string) string {
  return "Hello " + name
}
// Called like this:
greeting := Hello("Dave")

// Multiple parameters, multiple return values
func SumAndMultiply(a, b int) (int, int) {
    return a+b, a*b
}
// Called like this:
aplusb, atimesb := SumAndMultiply(a, b)
```

## 이름 있는 반환 값과 네이키드 리턴

매개변수와 마찬가지로 반환 값에도 이름을 붙일 수 있어요.
이름 있는 반환 값을 사용하면, 인자 없는 `return` 문이 그 값들을 반환해요.
이것을 '네이키드' 리턴이라고 해요.

```go
func SumAndMultiplyThenMinus(a, b, c int) (sum, mult int) {
    sum, mult = a+b, a*b
    sum -= c
    mult -= c
    return
}
```

## 값에 의한 전달과 참조에 의한 전달

값에 의한 전달과 참조에 의한 전달 개념도 짚고 넘어갈 필요가 있어요.

먼저 값에 의한 전달부터 살펴볼까요.
아래 예제에서 변수 `val`을 `MultiplyByTwo` 함수에 전달할 때, 우리는 `val`의 복사본을 전달한 거예요.
그래서 `newVal`은 갱신된 값 `4`를 가지지만, 원래 변수 `val`은 여전히 `2`예요.
내부적으로 Go는 원래 값의 복사본을 만들어서, 이 복사본, 즉 `v`만 함수에 의해 수정돼요.

```go
val := 2
func MultiplyByTwo(v int) int {
    v = v * 2
    return v
}
newVal := MultiplyByTwo(val)
// newval is 4, val is still 2 because only a copy of its value was passed into the function
```

엄밀히 말하면 Go에서는 모든 인자가 값에 의해 전달돼요. 즉, 함수에 전달된 값이나 데이터의 복사본이 만들어져요.
그런데 함수에 전달된 데이터의 복사본을 만들고 싶지 않고 함수 안에서 그 데이터를 바꾸고 싶다면, 인자로 `pointers`를 사용해야 해요. 이것을 참조에 의한 전달이라고 해요.

## 포인터

참조에 의한 전달을 하려면 `pointer`를 사용해요.
함수에 `pointer` 인자를 전달하면, 데이터의 복사본만 다루는 대신 함수에 전달된 원본 데이터를 수정할 수 있어요.

지금은 함수 시그니처에서 타입 앞에 붙은 `*`로 포인터 타입을 알아볼 수 있다는 것만 알아두면 충분해요.

```go
func HandlePointers(x, y *int) {
    // Some logic to handle integer values referenced by pointers x and y
}
```

`pointer` 개념이 헷갈려도 걱정 마세요.
나중에 포인터를 완전히 익힐 수 있도록 돕는 별도의 섹션이 있어요.

## 예외

`slices`와 `maps`는 위에서 말한 규칙의 예외라는 점에 주의해야 해요.
`slice`나 `map`을 함수의 인자로 전달하면, 타입에 명시적인 `*`가 없어도 포인터 타입처럼 다뤄져요.
즉, 슬라이스나 맵을 함수에 전달해서 그 원본 데이터를 수정하면, 그 변경 사항이 원래 슬라이스나 맵에도 반영돼요.
