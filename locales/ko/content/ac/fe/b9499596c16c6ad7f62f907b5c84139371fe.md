# Instructions

건강 모니터링 시스템을 구현하는 작업을 하고 있어요.
그 일환으로, 사용자의 건강 통계를 추적해야 해요.

`impl` 블록에 스텁(stub)으로 만들어 둔 몇 가지 함수와, 다음과 같은 구조체 정의에서 시작해요.

```rust
pub struct User {
    name: String,
    age: u32,
    weight: u32,
}
```

목표는 `impl` 블록에 정의된 `User` `struct`의 스텁 메서드들을 구현하는 거예요.

예를 들어, `new` 메서드는 지정된 이름, 나이, 몸무게 값을 가진 `User` 구조체의 인스턴스를 반환해야 해요.

```rust
let mut bob = User::new("Bob", 32, 72);
// Returns: a User with name "Bob", age 32, and weight 72
```

`weight` 메서드는 `User`의 몸무게를 반환해야 해요.

```rust
bob.weight();
// Returns: 72
```

`set_age` 메서드는 `User`의 나이를 설정해야 해요.

```rust
bob.set_age(33);
// Updates Bob's age to 33; happy birthday Bob!
```

재미있게 해봐요!
