# 지침

정원 곳곳에서 측정한 값으로 친구가 보고서를 만들도록 도와주고 있어요.
안타깝게도, 친구는 데이터를 이상한 형식으로 저장해 두었어요.
각 측정값은 쉼표로 구분된 여러 개의 필드로 이루어져 있어요.
그런데 친구는 두 자리 숫자를 두 개의 열에 나누어 저장했어요.

| 필드 번호 | 의미 |
| --- | --- |
| 1 | ID 번호 |
| 2 | 위치 |
| 3 | 첫 번째 측정값, 십의 자리 |
| 4 | 첫 번째 측정값, 일의 자리 |
| 5 | 두 번째 측정값, 십의 자리 |
| 6 | 두 번째 측정값, 일의 자리 |

`101,house,4,2,5,4`와 같은 입력 행이 있다면
- 첫 번째 측정값은 `42`이고,
- 두 번째 측정값은 `54`예요.

## 과제 1: 보고서 만들기

두 측정값의 평균을 구하고, 각 행의 결과를 다음 형식으로 출력하는 것이 과제예요.

```none
#<id>, <label> = <average>
```

42와 54의 평균은 48이므로, 예시 행의 출력은 다음과 같아요:

```none
#101, house = 48
```
