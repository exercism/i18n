# 지시사항

이 연습 문제에서는 2012년 9월 15일에 문을 연 미용실의 예약 스케줄러를 만들어 봐요.

다섯 개의 과제가 있는데, 모두 예약 날짜와 관련되어 있어요.

## 1. 예약 날짜 파싱하기

예약 날짜의 텍스트 표현을 해당하는 `time.Time` 형식으로 파싱하는 `Schedule` 함수를 구현해요:

```go
Schedule("7/25/2019 13:45:00")
// => 2019-07-25 13:45:00 +0000 UTC
```

## 2. 예약이 이미 지났는지 확인하기

예약 날짜를 받아서 그 예약이 과거에 있었는지 확인하는 `HasPassed` 함수를 구현해요:

```go
HasPassed("July 25, 2019 13:45:00")
// => true
```

## 3. 예약이 오후인지 확인하기

예약 날짜를 받아서 예약이 오후(12:00 이상 18:00 미만)인지 확인하는 `IsAfternoonAppointment` 함수를 구현해요:

```go
IsAfternoonAppointment("Thursday, July 25, 2019 13:45:00")
// => true
```

## 4. 예약의 시간과 날짜 설명하기

예약 날짜를 받아서 그 날짜와 시간에 대한 설명을 반환하는 `Description` 함수를 구현해요:

```go
Description("7/25/2019 13:45:00")
// => "You have an appointment on Thursday, July 25, 2019, at 13:45."
```

## 5. 미용실 개업 기념일 날짜 반환하기

UTC 기준으로 올해 미용실 개업 기념일 날짜를 반환하는 `AnniversaryDate` 함수를 구현해요.

올해가 2020년이라고 가정해요:

```go
AnniversaryDate()

// => 2020-09-15 00:00:00 +0000 UTC
```

**참고:** 반환 값은 `time.Time`이고, 하루 중 시간은 중요하지 않아요.
