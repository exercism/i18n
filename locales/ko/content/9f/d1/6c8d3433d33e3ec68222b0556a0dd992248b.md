# 힌트

## 일반

- 마주치는 열거자에 주의를 기울여요.
- 테스트는 모든 과제를 구현한 뒤에만 실행할 수 있어요.
  테스트 결과를 확인하려면 함수와 클래스의 대략적인 뼈대만 있으면 돼요.
- 테스트에서 사용하는 모든 함수, 클래스, 열거형은 헤더 파일에 선언해야 해요.

## 1. 첫 단서를 찾아봐요

- 클래스와 열거형은 서로 다른 네임스페이스에 있어요.
- `System`에는 `class enum`을 사용해요
- 생성자를 두 개 두거나, 기본 인자를 가진 생성자 하나를 둘 수 있어요.

## 2. 자세한 내용을 찾아봐요

- 첫 번째 `REQUIRE` 줄은 기본 `System`을 확인해요.
- `generation`은 복제된 함선에서 1씩 증가하는 것 같아요.
- `System`은 복제 과정에서도 그대로인 것 같아요.

## 3. 내부 동작을 살펴봐요

- `shoot_buster` 멤버 함수는 내부 카운터에 의존하는 것 같아요.
