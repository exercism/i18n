# 지시 사항

놀이공원에서의 작업을 이어가면서, 이번에는 방문객이 놀이기구를 이용할 수 있는지 확인하는 데 쓸 유틸리티 메서드 몇 개를 작성해 볼 거예요.

## 1. 방문객이 탑승권을 가지고 있는지 확인하기

`Attendee#has_pass?` 메서드를 구현해서 탑승권 보유 여부에 따라 불리언(`true`/`false`) 값을 반환해요.

```ruby
Attendee.new(100).has_pass?
# => false
```

## 2. 방문객이 놀이기구 탑승 기준에 맞는지 확인하기

`Attendee#fits_ride?` 메서드를 구현해서 방문객이 키를 기준으로 놀이기구에 탑승할 수 있는지 확인해요.
놀이기구에서 요구하는 최소 키는 인자로 전달돼요.
방문객의 키는 놀이기구에서 요구하는 최소 키보다 크거나 같아야 해요.

```ruby
Attendee.new(140).fits_ride?(100)
# => true
```

## 3. 방문객이 놀이기구를 탈 수 있는지 확인하기

`Attendee#allowed_to_ride?` 메서드를 구현해서 방문객이 놀이기구를 탈 수 있는지 확인해요. 놀이기구에서 요구하는 최소 키는 인자로 전달돼요. 방문객은 탑승권을 가지고 있어야 하고, 놀이기구 탑승 기준에도 맞아야 해요.

```ruby
attendee = Attendee.new(100)
attendee.issue_pass!(42)
attendee.allowed_to_ride?(120)
# => false
```
