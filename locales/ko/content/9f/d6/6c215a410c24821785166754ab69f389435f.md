# 소개

[F#](https://try.fsharp.org/)은 Microsoft의 .NET 언어 스택에 속하는, 타입이 엄격한 함수형 언어예요.

F#은 데이터 과학 문제에 아주 잘 맞지만, 어떤 문제를 가져오든 거의 모두 우아하게 처리할 수 있어요.

F#은 .NET 런타임 위에서 동작하기 때문에 [nuget.org](https://www.nuget.org/)의 모든 패키지를 비롯해 .NET 생태계 전체를 활용할 수 있어요.

F#에서는 객체 지향 코드도 작성할 수 있어서 기존 .NET 코드와의 통합이 한층 더 쉬워져요.

F#의 홈 페이지는 [fsharp.org](http://fsharp.org/)이고, F#을 잘 소개해 주는 곳으로는 [F# for fun and profit](http://fsharpforfunandprofit.com/) 웹사이트가 있어요.
