# 소개

[math/rand][mathrand] 패키지는 의사 난수를 생성하는 기능을 제공해요.

다음은 `0`과 `99` 사이의 임의의 정수를 생성하는 방법이에요:

```go
n := rand.Intn(100) // n is a random int, 0 <= n < 100
```

`rand.Float64` 함수는 `0.0`과 `1.0` 사이의 임의의 실수를 반환해요:

```go
f := rand.Float64() // f is a random float64, 0.0 <= f < 1.0
```

슬라이스(또는 다른 데이터 구조)를 섞는 기능도 지원해요:

```go
x := []string{"a", "b", "c", "d", "e"}
// shuffling the slice put its elements into a random order
rand.Shuffle(len(x), func(i, j int) {
	x[i], x[j] = x[j], x[i]
})
```

## 시드

`math/rand` 패키지가 생성하는 숫자열은 진정한 난수가 아니에요.
특정 "시드" 값을 주면 결과는 완전히 결정적이에요.

Go 1.20 이상에서는 시드가 자동으로 무작위로 선택되기 때문에, 프로그램을 실행할 때마다 다른 난수열을 보게 돼요.

그 이전 버전의 Go에서는 시드가 기본값으로 `1`이었어요.
따라서 프로그램을 여러 번 실행할 때마다 다른 숫자열을 얻으려면, 난수를 가져오기 전에 현재 시각 같은 값으로 난수 생성기의 시드를 직접 설정해야 했어요.

```go
rand.Seed(time.Now().UnixNano())
```
