# 구조체

구조체는 여러 관련된 값을 하나로 묶고 이름을 붙일 수 있게 해 주는 사용자 정의 데이터 타입이에요.
튜플과 비슷하지만 더 유연하고, 각 데이터에 이름을 붙일 수 있어서 코드가 더 명확해져요.
Cairo의 구조체에는 이런 특징이 있어요:

- 모든 구조체 타입에는 고유한 이름이 있어요.
- 구조체의 각 멤버를 **필드**라고 해요.
- 구조체의 각 필드에는 고유한 이름이 있어요.
- 가시성은 필드 단위로 관리돼요. 각 필드는 서로 독립적으로 공개하거나 비공개로 둘 수 있어요.

## 구조체 정의하고 인스턴스 만들기

구조체를 정의하려면 `struct` 키워드를 쓰고, 그 뒤에 이름과 중괄호를 붙여요. 중괄호 안에는 필드의 이름과 타입을 적어요:

```rust
#[derive(Drop)]
struct User {
    active: bool,
    username: ByteArray,
    email: ByteArray,
    sign_in_count: u64,
}
```

`struct`의 인스턴스를 만들려면 `struct` 이름을 적고, 중괄호 안에 필드의 키-값 쌍을 넣어요.
인스턴스를 만들 때 필드는 순서에 상관없이 나열할 수 있다는 점을 기억해요:

```rust
let user1 = User {
   active: true, username: "someusername123", email: "someone@example.com", sign_in_count: 1
};

let user2 = User {
    sign_in_count: 1, username: "someusername123", active: true, email: "someone@example.com"
};
```

## 구조체 인스턴스 다루기

`struct` 인스턴스의 필드에 접근하거나 값을 바꿀 때는 점 표기법을 사용해요.
필드를 바꾸려면 인스턴스가 가변이어야 한다는 점을 기억해요:

```rust
let mut user1 = User {
    active: true, username: "someusername123", email: "someone@example.com", sign_in_count: 1
};
user1.email = "anotheremail@example.com";
```

다른 표현식과 마찬가지로, 함수 본문의 마지막 표현식으로 `struct`의 새 인스턴스를 만들면 그 인스턴스가 암묵적으로 반환돼요:

```rust
fn build_user(email: ByteArray, username: ByteArray) -> User {
    User {
        email: email,
        username: username,
        active: true,
        sign_in_count: 1,
    }
}
```

## 필드 초기화 축약형

지난 예제에서는 `email`과 `username` 함수 매개변수의 이름을 `struct`의 필드 이름과 똑같이 짓는 게 자연스러웠어요.
하지만 같은 이름을 구조체 필드에 대입할 때 또 반복해서 쓰는 건 조금 번거로워요.
다행히 이름이 같은 변수로 구조체 필드를 초기화하는 편리한 축약형이 있어요:

```rust
fn build_user_short(email: ByteArray, username: ByteArray) -> User {
    User { email, username, active: true, sign_in_count: 1, }
}
```

## 구조체 갱신 문법으로 다른 인스턴스에서 인스턴스 만들기

구조체 갱신 문법을 쓰면 기존 인스턴스에서 새 인스턴스를 만들 수 있어요. 일부 필드만 바꾸고 나머지는 그대로 두는 거예요.
이때 `..` 연산자를 사용해요.

갱신 문법 없이:

```rust
let user2 = User {
    active: user1.active,
    username: user1.username,
    email: "another@example.com",
    sign_in_count: user1.sign_in_count,
};
```

갱신 문법을 쓰면:

```rust
let user2 = User { email: "another@example.com", ..user1 };
```

`..user1` 문법은 나머지 필드를 `user1`에서 `user2`로 복사해요.
이때 데이터는 `user1`에서 `user2`로 이동하기 때문에, 복사할 수 없는 타입이 들어 있다면 그 뒤로는 `user1`을 사용할 수 없어요.
