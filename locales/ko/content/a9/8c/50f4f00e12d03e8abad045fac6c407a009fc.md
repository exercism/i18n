# 개요

루프는 여러 문을 한 묶음으로 묶어 반복해서 실행하는 방법이에요.
문 묶음을 한 번 실행하는 것을 반복이라고 해요.

## `while`문

`while`문은 루프 맨 위의 불리언 표현식이 참인 동안 문 묶음을 실행해요.
불리언 표현식이 거짓이 되면 루프 실행을 멈추고, 루프 다음 줄의 코드로 실행이 넘어가요.

처음부터 불리언 표현식이 거짓으로 평가되면 `while`문은 한 번도 실행되지 않고, 루프 다음 줄의 코드로 실행이 넘어가요.

```c
int main() {
    int i = 0;
    while (i < 5) {
        printf("Number is %i\n", i++);
    }    
    return 0;
}
```

루프를 끝낼 조건이 있어야 해요. 그렇지 않으면 무한 루프가 되어 코드가 더 이상 진행되지 못해요.
위 코드에서 `i`의 `++`를 떼어 내면 무한 루프가 돼요.

## `do`문

`do`문은 불리언 표현식을 루프 맨 아래에서 검사해요.
`do`문은 다음 예시처럼 항상 최소 한 번은 실행돼요.

```c
do {
    printf("Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
} while (answer != 42); 
// Note that a semicolon is needed after the Boolean expression.
```

같은 일을 `while`문으로 하면 더 길어져요.

```c
printf(""Enter the Answer to the Ultimate Question of Life: ");
scanf("%d", &answer);
while (answer != 42) {
    printf(""Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
}
```

## `for`문

루프는 흔히 변수를 갱신하다가 그 변수가 특정 값에 도달하면 끝나요.
`for`문은 괄호 안 한 줄에서 하나 이상의 변수를 초기화하고, 갱신하고, 검사하는 방법이에요.
첫 번째 부분은 변수를 초기화하고, 두 번째 부분은 변수를 검사하고, 세 번째 부분은 변수의 값을 갱신해요.

```c
for (int i = 0; i < 5; i++) {
    printf("Number is %i\n", i);
}
```

`while`문으로 같은 일을 하는 것보다 짧으면서도 여전히 읽기 쉬워요.

`for`문의 초기화 부분과 갱신 부분에서는 쉼표 연산자로 조건 안의 식을 구분해서 변수를 여러 개 다룰 수 있어요.

```c
    int i, j;
    for (i = 0, j = 5; i < 5 && j > 2; i++, j--) {
        printf("i is %i\n", i);
        printf("j is %i\n", j);
    }
    printf("After the loop");
```

이 코드는 이렇게 출력해요

```
i is 0
j is 5
i is 1
j is 4
i is 2
j is 3
After the loop
```

`for`문의 어느 부분도 꼭 채울 필요는 없어요.
검사 식을 비워 두면 참으로 평가되므로, `for`문으로 무한 루프를 이렇게 만들 수도 있어요.

```c
int i = 0;
for (;;) {
    printf("Number is %i\n", i++);
    if (i == 5) break;
}
```

루프 전에 `i`를 초기화하고 루프 안에서 `i`를 증가시킨다는 점에서 `while`문과 비슷해요.
또 `i`는 루프 안에서 검사하고, 루프는 `break`문으로 끝나요.

## `break`문

때로는 루프가 불리언 표현식에서 검사하지 않는 특별한 조건에서 끝나야 할 때도 있어요.
`break`문은 루프를 끝내고, 루프 다음 줄의 코드로 실행이 넘어가요.

```c
int i, j, k;
for (int i = 0, j = 5, k = 3; i < 5 && j > 2; i++, j--) {
    printf("i is %i\n", i);
    printf("j is %i\n", j);
    if (k == 3) break;
}
printf("After the loop");
```

이 코드는 이렇게 출력해요

```
i is 0
j is 5
After the loop
```

## `continue`문

때로는 루프가 현재 반복을 끝내지 않고 다음 반복을 시작해야 할 때도 있어요.
`continue`문은 현재 반복의 실행을 멈추고 다음 반복의 시작 지점부터 실행을 이어가요.

```c
int i, j;
for (int i = 0, j = 4; i < 4 && j > 0; i++, j--) {
    if (i == j) continue;
    printf("i is %i\n", i);
    printf("j is %i\n", j);
}
printf("After the loop");
```

이 코드는 이렇게 출력해요

```
i is 0
j is 4
i is 1
j is 3
i is 3
j is 1
After the loop
```

`i`와 `j`가 둘 다 `2`일 때는 값을 출력하지 않아요.
