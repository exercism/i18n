# 지침 추가

## 프로젝트 구조

Exercism의 Clojure 연습 문제는 [leiningen](http://leiningen.org/)으로 코드를 설정하고 실행하며, [leiningen 표준 디렉터리 구조](https://github.com/technomancy/leiningen/blob/master/doc/TUTORIAL.md#directory-layout)를 사용해요.

`test` 디렉터리 안에 `hello_world_test.clj`라는 테스트 파일이 있어요.
코드는 `src/hello_world.clj`에 작성해요. 테스트가 인식할 수 있도록 `hello-world` 네임스페이스를 사용해야 해요.

## 테스트 실행하기

`lein test` 명령으로 테스트를 실행하고, 모두 통과시켜 봐요:

```
$ lein test

lein test hello-world-test

Ran 3 tests containing 3 assertions.
0 failures, 0 errors.
```

그다음 아래 명령으로 연습 문제를 제출해요:

```
$ exercism submit src/hello_world.clj
```

더 자세한 안내와 학습 자료는 [Exercism의 Clojure 언어 페이지](http://exercism.io/languages/clojure)를 참고해요.
