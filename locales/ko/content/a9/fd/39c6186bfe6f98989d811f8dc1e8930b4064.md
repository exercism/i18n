# 힌트

## 공통

- [구조체와 클래스][structs-and-classes]는 정의 문법이 서로 비슷해요.

## 1. Size 구조체 정의하기

- 변경할 수 있는 프로퍼티는 `var`로 정의해야 해요.
- height와 width 프로퍼티에는 각각 80과 60을 기본값으로 지정해요.
- 구조체의 프로퍼티를 변경하는 메서드에는 `mutating`을 붙여야 해요.

## 2. Position 구조체 정의하기

- 변경할 수 있는 프로퍼티는 `var`로 정의해야 해요.
- x와 y 프로퍼티에는 기본값 0을 지정해요.
- 구조체의 프로퍼티를 변경하는 메서드에는 `mutating`을 붙여야 해요.

## 3. Window 클래스 정의하기

- 구조체는 [멤버와이즈 이니셜라이저][memberwise-initializers]를 사용해 서로 다른 프로퍼티 값으로 초기화할 수 있어요.
- 상수 프로퍼티는 `let`으로 정의해요.
- `contents` 프로퍼티는 값을 가지고 있지 않을 수도 있으므로 옵셔널이어야 해요.
- 클래스에는 빈 이니셜라이저(`init() {}`)를 정의해야 해요.

## 4. 창 크기를 조절하는 메서드 추가하기

- 메서드는 `Size` 타입의 `to` 매개변수를 받아야 해요.
- 점 표기법을 사용하면 `to` 매개변수에서 width와 height를 가져올 수 있어요.

## 5. 창을 옮기는 메서드 추가하기

- 메서드는 `Position` 타입의 `to` 매개변수를 받아야 해요.
- 점 표기법을 사용하면 `to` 매개변수에서 x와 y를 가져올 수 있어요.

## 6. 창의 내용을 설정하는 메서드 추가하기

- Swift에서는 이름은 같지만 매개변수가 다른 메서드를 두 개 만들 수 있어요.
- `title` 프로퍼티를 설정하는, 매개변수 `title`을 가진 메서드를 정의해요.
- `contents` 프로퍼티를 설정하는, 매개변수 `text`를 가진 메서드를 정의해요.
- 창의 title과 contents를 출력하는 display 메서드를 정의해요.

## 7. Window 클래스의 이니셜라이저 만들기

- 클래스에는 매개변수를 받지 않는 이니셜라이저와 매개변수를 받는 이니셜라이저, 이렇게 두 개가 있어야 해요.
- 새 이니셜라이저는 `title`와 `contents` 매개변수를 가져야 하고, 선택적 매개변수인 `size`와 `position`도 받을 수 있어야 해요.
    매개변수를 제공하지 않으면 기본값이 사용돼요.
- 선택적 매개변수는 [기본 매개변수 값][default-parameters-vales]을 사용해 만들 수 있어요.
