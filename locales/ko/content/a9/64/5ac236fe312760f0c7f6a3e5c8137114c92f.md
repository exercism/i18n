# 지시 사항

이번 과제는 영어 텍스트를 Pig Latin으로 번역하는 거예요.
번역은 네 가지 규칙으로 정의되는데, 각 규칙은 단어 맨 앞에 오는 모음과 자음의 패턴을 살펴봐요.
규칙은 단어가 모음과 자음을 어떻게 쓰는지 봐요:

- 모음: `a`, `e`, `i`, `o`, `u` 글자
- 자음: 영어 알파벳의 나머지 21개 글자

## 규칙 1

단어가 모음으로 시작하거나 `"xr"` 또는 `"yt"`로 시작하면, 단어 끝에 `"ay"` 소리를 붙여요.

예를 들면:

- `"apple"` -> `"appleay"` (모음으로 시작해요)
- `"xray"` -> `"xrayay"` (`"xr"`로 시작해요)
- `"yttria"` -> `"yttriaay"` (`"yt"`로 시작해요)

## 규칙 2

단어가 하나 이상의 자음으로 시작하면, 먼저 그 자음들을 단어 끝으로 옮기고, 그다음 단어 끝에 `"ay"` 소리를 붙여요.

예를 들면:

- `"pig"` -> `"igp"` -> `"igpay"` (자음 하나로 시작해요)
- `"chair"` -> `"airch"` -> `"airchay"` (자음 여러 개로 시작해요)
- `"thrush"` -> `"ushthr"` -> `"ushthray"` (자음 여러 개로 시작해요)

## 규칙 3

단어가 자음 0개 이상 뒤에 `"qu"`가 오는 형태로 시작하면, 먼저 그 자음들(있는 경우)과 `"qu"` 부분을 단어 끝으로 옮기고, 그다음 단어 끝에 `"ay"` 소리를 붙여요.

예를 들면:

- `"quick"` -> `"ickqu"` -> `"ickquay"` (`"qu"`로 시작하고 앞에 자음이 없어요)
- `"square"` -> `"aresqu"` -> `"aresquay"` (자음 하나 뒤에 `"qu`"로 시작해요)

## 규칙 4

단어가 하나 이상의 자음 뒤에 `"y"`가 오는 형태로 시작하면, 먼저 `"y"` 앞에 오는 자음들을 단어 끝으로 옮기고, 그다음 단어 끝에 `"ay"` 소리를 붙여요.

몇 가지 예를 들면:

- `"my"` -> `"ym"` -> `"ymay"` (자음 하나 뒤에 `"y"`로 시작해요)
- `"rhythm"` -> `"ythmrh"` -> `"ythmrhay"` (자음 여러 개 뒤에 `"y"`로 시작해요)
