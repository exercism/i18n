# 소개

[구조체와 클래스][structs-and-classes]는 Swift에서 사용자 정의 타입을 만드는 핵심 구성 요소예요.
둘 다 관련 있는 프로퍼티(데이터)와 메서드(동작)를 재사용 가능한 단위로 묶을 수 있게 해줘요.
Swift의 대부분 핵심 타입은 `Int`, `Double`, `String`은 물론 `Array`와 `Dictionary` 같은 컬렉션 타입까지 모두 구조체로 구현되어 있어요.

각 타입에 대한 자세한 설명은 다음을 참고해요:

- [concept:swift/structs]()
- [concept:swift/classes]()

## 구조체와 클래스 중에서 선택하기

구조체와 클래스 모두 사용자 정의 타입을 정의할 수 있게 해주지만, 메모리에서 값이 전달되는 방식은 근본적으로 달라요:

- **구조체는 값 타입이에요**: 구조체를 할당하거나 전달하면 Swift는 그 데이터를 독립적으로 복사해요.
한 복사본을 변경해도 다른 복사본에는 영향을 주지 않아요.
- **클래스는 참조 타입이에요**: 클래스 인스턴스를 할당하거나 전달하면 Swift는 기존 인스턴스에 대한 참조를 공유해요.
한 참조를 통해 변경한 내용은 같은 인스턴스를 가리키는 다른 모든 참조에 즉시 반영돼요.

Swift는 안전성과 예측 가능한 동작을 중시하기 때문에, 대부분의 사용자 정의 타입에는 구조체를 기본으로 권장해요.
값 타입을 사용하면 프로그램의 한 부분에서 데이터를 변경해도 다른 곳에서 예상치 못한 부작용이 생기지 않아요.

일반적으로:

- **구조체를 사용해요**: 좌표, 도형, 기하학적 치수, 형식이 정해진 레코드처럼 독립적인 값을 나타내는 데이터를 모델링할 때.
- **클래스를 사용해요**: UI 컨트롤, 데이터베이스 연결, 파일 핸들처럼 고유한 정체성이나 공유된 수명 주기가 필요한 개체를 모델링할 때.
