# 안내

메리는 TV 시리즈 _Star Trek: The Next Generation_의 열렬한 팬이에요.
친구들과 종이와 펜으로 롤플레잉 게임을 자주 하는데, 게임 속에서 모두 _엔터프라이즈_호의 승무원인 척을 하죠.

메리가 맡은 캐릭터는 피카드 함장이라서, 함장 일지를 써야 해요.
그녀는 게임의 창작적인 부분은 좋아하지만, 그 자리에서 무작위 데이터를 만드는 건 좋아하지 않아요.

함장 일지에 자주 등장하는 데이터를 만들어 주는 무작위 생성기를 만들어서 메리를 도와주세요.

## 1. 무작위 행성 생성하기

_엔터프라이즈_호는 여행 중에 수많은 행성을 만나요.
Star Trek 세계의 행성들은 그 특성에 따라 여러 등급으로 나뉘어요.
예를 들어, 지구는 M급 행성이에요. 가능한 행성 등급은 모두 D, H, J, K, L, M, N, R, T, Y예요.

`random_planet_class` 함수를 구현해 주세요.
이 함수는 필요한 개수만큼의 행성 등급을 무작위로 골라 벡터로 반환해야 해요.
등급이 중복되어도 괜찮고, 긴 벡터에서는 오히려 중복이 필요할 수도 있어요.

```R
random_planet_class(number_needed)
#> "K"
```

### 2. 무작위 우주선 등록 번호 생성하기

우주를 날아다니는 우주선은 엔터프라이즈호(등록 번호 NCC-1701)만이 아니에요!
다른 우주선과 만나면, 메리는 그 우주선의 등록 번호를 일지에 기록해야 해요.

등록 번호는 "NCC-"라는 접두사로 시작하고, 그 뒤에 1000부터 9999까지(양쪽 끝 포함)의 숫자가 와요.

무작위 우주선 등록 번호를 반환하는 `random_ship_registry_number` 함수를 구현해 주세요.

```R
random_ship_registry_number()
#> "NCC-1947"
```

## 3. 우주선 함대 무작위로 섞기

게임의 한 가지 버전에서는 다른 우주선들과 교류해야 해서, 메리에게는 우주선 몇 척을 고를 일이 생겨요.

등장할 수 있는 우주선의 전체 목록이 있지만, 게임마다 그중 몇 척만 필요하고, 그마저도 무작위로 골라야 해요.

고유한 우주선 등록 번호의 벡터를 받아서, 같은 길이의 벡터를 무작위 순서로 반환하는 `shuffle_starships(starships)` 함수를 구현해 주세요.
그러면 메리가 벡터의 앞부분에서 원하는 개수만큼 무작위로 골라 쓰기 쉬워져요.

결과 값은 `starships`에 있는 값을 중복 없이 사용해야 해요.

```R
shuffle_starships(c("NCC-5011", "NCC-1228", "NCC-7039", "NCC-3978", "NCC-1476"))
#> [1] "NCC-1476" "NCC-7039" "NCC-3978" "NCC-5011" "NCC-1228"
```

## 4. 무작위 스타데이트 생성하기

날짜도 없는 일지가 무슨 소용이 있을까요?

스타데이트는 실수예요.
_The Next Generation_의 첫 시즌에 등장하는 _엔터프라이즈_호의 모험은 스타데이트 41000.0과 42000.0 사이에서 펼쳐져요.
"4"는 24세기를, "1"은 첫 번째 시즌을 뜻해요.

41000.0과 42000.0 사이의 실수를 반환하는 `random_stardate` 함수를 구현해 주세요.

```R
random_stardate()
#> 41037.6
```
