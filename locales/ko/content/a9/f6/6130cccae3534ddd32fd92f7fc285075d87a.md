# 소개

Elm은 믿음직한 웹 애플리케이션을 만들기 위한 즐거운 언어예요. 친절한 오류 메시지, 뛰어난 성능, 작은 에셋 크기를 갖췄고, 런타임 예외도 없어요.

Elm에서 아마 가장 유명하고 널리 따라 하는 부분은 The Elm Architecture예요. 웹 애플리케이션의 구조를 잡는 단순한 패턴이고, 모든 Elm 웹 애플리케이션이 이 패턴으로 작성돼요.

핵심 아이디어는 애플리케이션 상태를 담은 `Model`, 모델을 `update`하는 방법, 모델을 `view`하는 방법을 중심으로 코드를 구성한다는 거예요.

`Model`은 애플리케이션의 상태, 즉 애플리케이션에 필요한 모든 데이터를 담고 있어요. 텍스트 상자와 그 텍스트를 뒤집은 결과를 보여 주는 텍스트가 있는 단순한 애플리케이션을 상상해 보면, 모델은 아래와 같아요. 이 예제는 [Elm 가이드][elm-guide-text-fields]에서도 볼 수 있어요.

```elm
type alias Model =
  { text : String
  }
```

`update`는 변화가 생겼을 때(예를 들어 사용자가 버튼을 클릭할 때) `Msg`와 함께 호출되는 함수예요. `Msg`와 현재 `Model`을 받아서 새로운 `Model`을 반환해요.

```elm
type Msg
  = TextChanged String

update : Msg -> Model -> Model
update msg model =
  case msg of
    TextChanged newText ->
      { model | text = newText }
```

`view`는 브라우저에서 사용자에게 보여 줄 HTML을 반환하는 함수예요. 현재 `Model`을 받아서 `Html Msg`를 반환해요. `Html Msg`는 Elm이 HTML을 표현할 때 쓰는 타입이에요.

```elm
view : Model -> Html Msg
view model =
  Html.div []
    [ Html.input
      [ Html.Attributes.placeholder "Text to reverse"
      , Html.Attributes.value model.text
      , Html.Events.onInput TextChanged
      ]
      []
    , Html.div [] [ Html.text (String.reverse model.text) ]
    ]
```
