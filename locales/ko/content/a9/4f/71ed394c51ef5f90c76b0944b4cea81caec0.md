# 소개

`switch()` 함수는 긴 `if` ... `else if` 검사들을 간결하게 대체할 수 있어요.
switch의 대상이 되는 변수는 대개 문자열인데, 그럴 때는 선택자에서 따옴표를 생략할 수 있어요.

```R
star <- function(type) {
  switch(type,
    M = , # will "fall through" if no value given
    K = "red dwarf",
    G = "Earth-like",
    "bigger star" # only correct for O,B,A,F
  )
}

> star("M")
[1] "red dwarf"
```

위 예시의 `M`처럼, 값을 비워 두었을 때만 옵션이 다음으로 넘어간다는 점에 주의해요.
다른 언어들처럼 `break` 문을 넣을 필요는 없어요.

`character` 타입을 대상으로 switch할 때는 여기서처럼 마지막 값이 기본값이 돼요.
정수 타입에서는 기본값을 지정할 수 없어요.

## `dplyr`의 함수들

base R의 `switch`는 꽤 제한적이에요. 단일 입력에 대한 정확한 일치만 처리해요.
1993년 R이 처음 공개되었을 때는 합리적으로 보였지만, 현대적인 사용을 위해서는 개선이 필요해요.

`dplyr` 라이브러리는 `switch`와 관련된 두 가지 추가 함수를 제공해요.

### `recode_values`와 `replace_values` 함수

이 두 함수는 예전 값을 새 값으로 매핑하는, 벡터화된 switch 같은 기능을 제공해요.

둘의 주된 차이는 `recode_values()`는 완전히 새로운 벡터를 만들고, `replace_values()`는 기존 벡터를 부분적으로 갱신할 수 있다는 점이에요.

일치는 여전히 정확하지만, 다음이 달라요:

- 왼쪽의 옵션은 벡터일 수 있고, 원소 중 하나라도 일치하면 입력이 매칭돼요.
- 왼쪽의 옵션과 오른쪽의 결과는 `=` 대신 물결표 `~`로 연결돼요.
- 모든 경우에 기본값을 지정할 수 있어요.

```R
library(dplyr)

x <- c("a", "b", "a", "d", "b", NA, "c", "e", "z")
recode_values(
  x,
  "a" ~ 1,
  "b" ~ 2,
  "c" ~ 3,
  c("d", "e") ~ 4, # either "d' or "e" will match
  NA ~ 0,          # matches missing values
  default = 100   # note the different syntax for the default
)
#> [1]   1   2   1   4   2   0   3   4 100
```

### `case_when` 함수

`case_when`은 `case_match` 문법을 한 단계 더 발전시켜, `~` 왼쪽에 어떤 논리 표현식이든 쓸 수 있게 해줘요.

입력 벡터(아래 예시의 `x`)는 인자로 전달하지 않아요. 그저 이미 정의되어 있기만 하면 돼요.

```R
x <- 1:10
case_when(
  x < 3 ~ "low",
  between(x, 3, 5) ~ "mid",
  between(x, 6, 8) ~ "high",
  .default = "what?"
)
#>  [1] "low"   "low"   "mid"   "mid"   "mid"   "high"  "high"  "high"  "what?" "what?"
```

`between()` 함수도 `dplyr`의 일부예요.
