# 개요

주요 산술 연산자와 비교 연산자는 직접 만든 클래스와 구조체에서 사용할 수 있도록 재정의할 수 있어요. 이를 _연산자 오버로딩_이라고 해요.

이 [문서][operator-overloading]에서는 문법은 물론이고 어떤 연산자를 오버로딩할 수 있고 어떤 것은 할 수 없는지도 자세히 다뤄요.

대부분의 연산자는 다음과 같은 형태예요.

```csharp
static <return type> operaator <operator symbols>(<parameters>);
```

[캐스트 연산자][ud-conversion-operators]는 다음과 같은 형태예요.

```csharp
static (explicit|implicit) operator <cast-to-type>(<cast-from-type> <parameter name>);
```

연산자는 정적 메서드와 같은 방식으로 동작해요.

- 연산자 기호는 메서드 식별자를 대신하며, 매개변수와 반환 타입을 가져요. 매개변수와 반환 타입에 대한 타입 규칙은 직관을 따르므로, 자세한 안내는 컴파일러가 제공해 줄 거예요.
- 이항 연산에서는 첫 번째 매개변수가 연산의 왼쪽 인자를 받아요.
- 연산자의 시그니처는 (이항 연산의 경우) 두 개의 매개변수와 반환 타입으로 이루어지고, 단항 연산자의 경우 하나의 매개변수와 반환 타입으로 이루어져요.
- 이항 연산자의 경우, 매개변수 타입 중 하나는 선언하는 클래스의 타입이어야 해요.
- 타입 변환의 경우, 매개변수나 반환 타입 중 하나는 선언하는 클래스의 타입이어야 해요.
- 증가 및 감소 연산자의 경우, 매개변수와 반환 타입 모두 선언하는 클래스의 타입이어야 해요.

문법 예시:

```csharp
struct Point
{
    decimal x;
    decimal y;

    public static bool operator ==(Point pt, Point ptOther)
    {
        return pt.x == ptOther.x && pt.y == ptOther.y;
    }

    public static bool operator !=(Point pt, Point ptOther)
    {
        return !(pt == ptOther);
    }

    public static Point operator *(Point pt, decimal scale)
    {
        var ptNew = new Point();
        ptNew.x = pt.x * scale;
        ptNew.y = pt.y * scale;
        return ptNew;
    }

    public static implicit operator Point((decimal x, decimal y) xy)
    {
        var pt = new Point();
        pt.x = xy.x;
        pt.y = xy.y;
        return pt;
    }

    public static explicit operator (decimal x, decimal y)(Point pt)
    {
        return (pt.x, pt.y);
    }
}
```

[`Equals()`][equals] 메서드를 구현하고 `==` 연산자에서 호출하면 효과를 보는 경우가 많아요. 마찬가지로 비교를 위해서는 [`IComparable`][icomparable] 인터페이스를 구현할 수 있어요. 두 경우 모두 한 번에 두 마리 토끼를 잡는 셈이에요.

표준 연산자 집합에 포함되지 않은 기호로는 연산자를 만들 수 없다는 점을 기억해 두세요. 문서에서 오버로딩할 수 있다고 명시한 연산에 대해서만 기존 기호를 사용할 수 있어요. 오버로딩할 수 있는 연산자는 [여기][overloadable-operators]에 나와 있어요.

매개변수의 타입이 다를 때는 순서가 중요하다는 점에 유의하세요. 위 예제 코드에서 `pt * 10m`은 올바른 식이지만 `10m * pt`는 컴파일되지 않아요.
