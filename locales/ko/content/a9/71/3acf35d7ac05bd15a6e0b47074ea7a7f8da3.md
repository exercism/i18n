# 소개

Factor에서 문자열은 문자로 이루어진 시퀀스예요. [`sequences`][sequences] 어휘에 있는 대부분의 단어는 문자열에서도 동작해요. [`splitting`][splitting], [`ascii`][ascii] 같은 어휘에 있는 문자열 전용 단어들도 함께 쓸 수 있고요.

## 문자열 리터럴

문자열은 큰따옴표로 감싸서 써요. 일반적인 이스케이프를 지원해요. `\n`, `\t`, `\r`, `\\`, `\"` 같은 것들이에요.

```factor
"hello, world" .                 ! => "hello, world"
"first\nsecond" print            ! prints two lines
```

## 길이와 인덱싱

문자열은 시퀀스이기 때문에 [`sequences`][sequences] 어휘의 `length`와 `nth` 단어가 문자열에서 바로 동작해요.

`length`는 문자의 개수를 반환해요.

```factor
"hello" length .    ! => 5
```

`nth`는 0부터 시작하는 인덱스와 시퀀스를 받아서, 그 위치의 원소를 반환해요. 문자열에서 원소는 *문자*, 즉 코드 포인트(정수)예요. 한 글자짜리 부분 문자열이 아니에요.

```factor
0 "hello" nth .     ! => 104   (CHAR: h)
4 "hello" nth .     ! => 111   (CHAR: o)
```

## 문자에서 다시 문자열로

코드 포인트 하나를 한 글자짜리 문자열로 바꾸려면 [`strings`][strings] 어휘의 `1string ( char -- str )`을 사용해요. `CHAR:`는 리터럴 코드 포인트를 파서 시점에 쓰는 형태예요.

```factor
CHAR: A 1string .                ! => "A"
0 "hello" nth 1string .          ! => "h"
```

## 나누기

[`splitting`][splitting] 어휘는 문자열을 조각으로 잘라요.

`split1`은 구분자가 *처음* 나오는 곳에서 자르고 양쪽을 모두 반환해요.

```
split1 ( seq subseq -- before after )
```

```factor
"foo: bar" ": " split1 .s
! => "foo"
! => "bar"
```

`split`은 구분자 집합에 있는 *모든* 문자를 기준으로 자르기 때문에, 빈 조각이 생길 수도 있어요.

```factor
"[ERROR]: Stack overflow" "[]" split .
! => { "" "ERROR" ": Stack overflow" }
```

`harvest`([`sequences`][sequences]에 있어요)는 빈 조각을 버려요.

```factor
"[ERROR]: Stack overflow" "[]" split harvest .
! => { "ERROR" ": Stack overflow" }
```

## 조각 하나 꺼내기

문자열이 조각들의 배열로 나뉘고 나면, `first`, `second`, `third`, `fourth`([`sequences`][sequences]에 있어요)가 그 위치의 조각을 반환해요.

```factor
"apple,bee,carrot,duck" "," split first .    ! => "apple"
"apple,bee,carrot,duck" "," split second .   ! => "bee"
"apple,bee,carrot,duck" "," split third .    ! => "carrot"
"apple,bee,carrot,duck" "," split fourth .   ! => "duck"
```

앞쪽 조각들을 한 번에 스택에 올리고 싶을 때는 `first2`와 `first3`가 두세 개를 한 단계에 풀어놓아요.

```factor
"apple,bee,carrot,duck" "," split first2 .s
! => "apple"
! => "bee"

"apple,bee,carrot,duck" "," split first3 .s
! => "apple"
! => "bee"
! => "carrot"
```

문자열 자체에 `first`를 쓰면 첫 번째 **문자**, 즉 코드 포인트를 반환해요. 부분 문자열이 아니에요.

```factor
"hello" first .                         ! => 104   (CHAR: h)
```

## 공백 제거

`[ blank? ] trim`([`sequences`][sequences]에 있고, `blank?`는 [`ascii`][ascii] 어휘에 있어요)은 앞뒤의 공백을 없애요.

```factor
"  Disk full \r\n" [ blank? ] trim .
! => "Disk full"
```

## 대소문자 변환

`>lower`와 `>upper`([`ascii`][ascii]에 있어요)는 대소문자를 바꾼 새 문자열을 반환해요.

```factor
"WARNING" >lower .    ! => "warning"
"hello" >upper .      ! => "HELLO"
```

## 이어 붙이기

[`sequences`][sequences]의 단어 두 개가 문자열을 조립해요.

`surround`는 문자열을 접두사와 접미사로 감싸요.

```
surround ( seq pre post -- new-seq )
```

```factor
"warning" "(" ")" surround .    ! => "(warning)"
```

`glue`는 두 문자열 사이에 구분자를 넣어 이어 붙여요.

```
glue ( s1 s2 sep -- s )
```

```factor
"Disk full" "(error)" " " glue .    ! => "Disk full (error)"
```
