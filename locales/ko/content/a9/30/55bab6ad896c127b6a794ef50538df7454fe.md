# 자세히 알아보기

Haxe의 이터레이터는 `for`문으로 값을 순회할 때 사용해요. 이터레이터에는 두 가지 종류가 있어요.

- 값을 순회하는 `Iterator`
- 데이터 타입을 순회할 수 있게 해 주는 `Iterable` 데이터

이 두 개념은 각각 `Iterator<T>`와 `Iterable<T>`로 나타내요.

```haxe
typedef Iterator<T> = {
  function hasNext():Bool;
  function next():T;
}

typedef Iterable<T> = {
  function iterator():Iterator<T>;
}
```

이 타입 중 하나와 통합되는 클래스는 `for`문으로 순회할 수 있어요. 어떤 클래스가 `hasNext`와 `next` 메서드를 정의하면 이터레이터로 간주하고, `iterator` 메서드를 정의하면 이터러블 타입으로 간주해요.

```haxe
class MyStringIterator {
  var str:String;
  var i:Int;

  public function new(str:String) {
    this.str = str;
    i = 0;
  }

  public function hasNext():Bool {
    return i < str.length;
  }

  public function next():String {
    return str.charAt(i++);
  }
}
```

위 예제의 `MyStringIterator` 클래스는 `hasNext`와 `next` 메서드를 모두 구현하므로 이터레이터로 간주돼요. 그래서 `Iterator<String>`과도 호환돼요.

```haxe
class MyArrayWrap<T> {
  var arr:Array<T>;

  public function new(a:Array<T>) {
    this.a = a;
  }

  public function iterator() {
    return a.iterator();
  }
}
```

여기서 `MyArrayWrap` 클래스는 `Iterable<Array<T>>`와 호환되므로 이터러블 데이터 타입으로 간주돼요.
