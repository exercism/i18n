# 자세히 알아보기

Gleam의 `Iterator`는 값들이 순서대로 나열된 모음이라는 점과, 모든 값의 타입이 같다는 점에서 배열과 비슷해요. 배열과 다른 점은 값을 한꺼번에 메모리에 저장하지 않고 필요할 때마다 계산한다는 거예요.

이런 특징은 아주 크거나 심지어 무한한 수열을 다룰 때 유용해요. 값을 전부 한꺼번에 저장할 만큼 메모리가 넉넉하지 않아도 다룰 수 있으니까요.

`gleam/iterator` 모듈은 `Iterator` 타입과 이터레이터를 다루는 함수들을 정의해요.

배열에 있는 함수 중 상당수는 이터레이터에도 있어요. `map`, `filter`, `take` 같은 함수죠. 이런 함수들은 이터레이터를 반환하기 때문에, 이터레이터가 소비되기 전까지는 실제로 아무 일도 하지 않아요.

```gleam
let iter = 
  [1, 2, 3, 4, 5, 6]
  |> iterator.from_list
  |> iterator.filter(fn(x) { x > 2 })
  |> iterator.take(2)

// No work has been done yet as the iterator has not been consumed

// Consume the iterator and collect the values into a list
iterator.to_list(iter)
// -> [3, 4]
```

`unfold` 함수를 사용하면, 반복해서 호출되면서 수열의 다음 값을 만들어 내는 함수로부터 이터레이터를 만들 수 있어요.

다음은 `unfold` 함수로 피보나치 수열을 만들어 내는 이터레이터를 만드는 예예요.

```gleam 
iterator.unfold(#(0, 1), fn(pair) {
  let x = pair.0 + pair.1
  iterator.Next(element: x, accumulator: #(pair.1, x))
})
|> iterator.take(6)
|> iterator.to_list
// -> [1, 2, 3, 5, 8, 13]
```

여기서 다루는 수열은 무한하기 때문에, 값을 배열로 모으기 전에 `take` 함수로 유한하게 만들어 줘요. 무한한 이터레이터에 `to_list`를 호출하면, 메모리가 부족해질 때까지 프로그램이 계속 실행되다가 결국 강제 종료돼요.
