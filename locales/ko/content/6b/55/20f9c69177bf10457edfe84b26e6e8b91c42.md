# 지침

여러분의 팀은 기상 애플리케이션을 만들고 있어요.
팀은 기상 데이터를 나타내는 다양한 타입과 상수로 API를 정의했어요. `meteorology.go` 파일을 참고하세요.

여러분이 할 일은 모든 타입에 알맞은 `String` 메서드를 추가해서 `Stringer` 인터페이스를 구현하도록 만드는 거예요.

## 1. `TemperatureUnit` 타입에 `Stringer` 인터페이스 구현하기

몇 차례 논의 끝에 팀은 온도의 단위를 `Celsius` 또는 `Fahrenheit`로 정했어요.
값은 아래 예시와 같은 형식으로 만들어야 해요.

`TemperatureUnit` 타입에 `String` 메서드를 추가해서 `Stringer` 인터페이스를 구현해 봐요.
이 메서드는 온도 단위가 Celsius이면 `"°C"` 문자열을, Fahrenheit이면 `"°F"` 문자열을 반환해야 해요.

```go
celsiusUnit := Celsius
fahrenheitUnit := Fahrenheit

celsiusUnit.String()
// => °C
fahrenheitUnit.String()
// => °F
fmt.Sprint(celsiusUnit)
// Output: °C
```

## 2. `Temperature` 타입에 `Stringer` 인터페이스 구현하기

온도 값은 정수와 온도 단위로 이루어져 있어요.
이 값들도 아래 예시와 같은 형식으로 만들어야 해요.

그렇게 하려면 `Temperature` 타입에 `String` 메서드를 추가해서 `Stringer` 인터페이스를 구현해요.
이 메서드는 온도의 숫자 값과 온도 단위를 공백으로 구분한 문자열을 반환해야 해요. `<temperature> <unit>`:

```go
celsiusTemp := Temperature{
    degree: 21,
    unit: Celsius,
}
celsiusTemp.String()
// => 21 °C
fmt.Sprint(celsiusTemp)
// Output: 21 °C

fahrenheitTemp := Temperature{
    degree: 75,
    unit: Fahrenheit,
}
fahrenheitTemp.String()
// => 75 °F
fmt.Sprint(fahrenheitTemp)
// Output: 75 °F
```

## 3. `SpeedUnit` 타입에 `Stringer` 인터페이스 구현하기

긴 논의 끝에 팀은 풍속의 단위를 `KmPerHour` 또는 `MilesPerHour`로 정했어요.
값은 아래 예시와 같은 형식으로 만들어야 해요.

그렇게 하려면 `SpeedUnit` 타입에 `String` 메서드를 추가해서 `Stringer` 인터페이스를 구현해요.
이 메서드는 속도 단위가 시속 킬로미터면 `"km/h"` 문자열을, 시속 마일이면 `"mph"` 문자열을 반환해야 해요.

```go
mphUnit := MilesPerHour
mphUnit.String()
// => mph
fmt.Sprint(mphUnit)
// Output: mph

kmhUnit := KmPerHour
kmhUnit.String()
// => km/h
fmt.Sprint(kmhUnit)
// Output: km/h
```

## 4. `Speed` 타입에 `Stringer` 인터페이스 구현하기

풍속 값은 정수와 속도 단위로 이루어져 있어요.
이 값들도 아래 예시와 같은 형식으로 만들어야 해요.

그렇게 하려면 `Speed` 타입에 `String` 메서드를 추가해서 `Stringer` 인터페이스를 구현해요.
이 메서드는 속도의 숫자 값과 속도 단위를 공백으로 구분한 문자열을 반환해야 해요. `<speed> <unit>`:

```go
windSpeedNow := Speed{
    magnitude: 18,
    unit: KmPerHour,
}
windSpeedNow.String()
// => 18 km/h
fmt.Sprintf(windSpeedNow)
// Output: 18 km/h

windSpeedYesterday := Speed{
    magnitude: 22,
    unit: MilesPerHour,
}
windSpeedYesterday.String()
// => 22 mph
fmt.Sprint(windSpeedYesterday)
// Output: 22 mph
```

## 5. `MeteorologyData` 타입에 `Stringer` 인터페이스 구현하기

기상 데이터는 위치, 온도, 풍향, 풍속, 습도를 나타내요.
이 데이터는 아래 예시와 같은 형식으로 만들어야 해요.

그렇게 하려면 `MeteorologyData` 타입에 `String` 메서드를 추가해서 `Stringer` 인터페이스를 구현해요.
이 메서드는 기상 데이터를 다음 형식으로 반환해야 해요.

```text
<location>: <temperature>, Wind <wind_direction> at <wind_speed>, <humidity>% Humidity
```

```go
sfData := MeteorologyData{
    location: "San Francisco",
    temperature: Temperature{
        degree: 57,
        unit: Fahrenheit
    },
    windDirection: "NW",
    windSpeed: Speed{
        magnitude: 19,
        unit: MilesPerHour
    },
    humidity: 60
}

sfData.String()
// => San Francisco: 57 °F, Wind NW at 19 mph, 60% Humidity
fmt.Sprint(sfData)
// Output: San Francisco: 57 °F, Wind NW at 19 mph, 60% Humidity
```
