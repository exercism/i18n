# 지침

_Instruments of Texas_에서 RPN 계산기 작업이 순조롭게 진행되고 있어요. 이제 팀에서는 수식을 문자열로 만들어 _IO_ 리소스에 쓸 수 있기를 원해요.

## 1. 파일 열기

팀은 수식을 어떤 종류의 기기에 쓸지 아직 정하지 못했어요. 그래서 함수에 리소스를 하드코딩하는 대신 주입할 수 있도록 _동적 디스패치_ 방식을 사용하자고 제안해요. 리소스와 파일 이름을 사용해 _IO 기기_를 열도록 `write/3` 함수를 구현해요.

`resource`는 항상 `{:ok, io_device}`를 반환하는 `open/1` 함수를 가진 모듈을 나타내는 아톰이라고 가정해도 돼요.

함수가 성공하면 수식이 담긴 ok 튜플을 반환해요.

```elixir
RPNCalculator.Output.write(resource, "file_to_be_written", "1 4 +")
# {:ok, "1 4 +"}
```

## 2. IO 기기에 쓰기 시도

이제 IO 기기를 열었으니, `IO.write/2`를 사용해 여기에 쓰기를 시도해요.

`write/3` 함수를 확장해 이 동작을 수행해요. 쓰기 시도 중에는 오류가 발생할 수 있으니, 오류를 처리하고 error 튜플을 반환해요.

```elixir
RPNCalculator.Output.write(resource, "bad_file", "1 4 +")
# {:error, "Unable to write to resource"}
```

## 3. IO 기기 닫기

리소스를 사용하는 함수에서 오류가 발생하더라도, 열어 둔 리소스는 항상 해제하려고 노력하는 것이 좋은 습관이에요. `write/3` 함수를 확장해 리소스의 close 함수를 호출하여 _IO 기기_를 닫아요.

`resource`는 항상 _IO 기기_를 받는 `close/1` 함수를 가진 모듈을 나타내는 아톰이라고 가정해도 돼요.
