# 테스트

CLI 도구로 연습 문제를 내려받았다면, 연습 문제 이름을 딴 Futhark 파일과 `test.fut` 파일이 보일 거예요.
이 파일에는 모든 테스트 케이스가 들어 있어요. 여기 있는 테스트는 솔루션을 업로드할 때 테스트 러너가 실행하는 것과 동일해요.
실험해 보고 싶다면 테스트 케이스를 자유롭게 더 추가해도 돼요.
하지만 테스트를 수정해도 온라인 테스트 러너에는 영향을 주지 않아요.

## 로컬 테스트

문제의 테스트를 실행하려면, 연습 문제 디렉터리에서 터미널을 열고 `futhark test test.fut` (또는 `exercism test`) 명령을 실행해요.

## 추가 자료

Futhark로 테스트하는 방법을 더 알아보려면 [`futhark test`][test-command] 문서를 참고하세요.
