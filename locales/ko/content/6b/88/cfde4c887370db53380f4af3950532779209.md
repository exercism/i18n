# 소개

Unison은 `Boolean` 타입으로 참과 거짓 값을 표현해요. 값은 `true`와 `false` 두 가지뿐이에요.

```unison
trueVariable = true
falseVariable = false
```

불리언 표현식은 and, or, not 연산자로 평가할 수 있는데, 각각 `&&`, `||`, `not`으로 나타내요.

```unison
trueVariable = true && true
falseVariable = true && false

trueVariable = false || true
falseVariable = false || false

trueVariable = not false
falseVariable = not true
```
