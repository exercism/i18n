# 개요

## 모듈

Gleam 코드는 모듈로 구성되며, 파일 하나가 하나의 Gleam 모듈이에요.

지금까지는 `pub fn` 문법으로 함수를 작성했어요. 이 문법은 다른 모듈에서도 공개적으로 사용할 수 있는 함수를 정의해요. `fn`으로 정의한 함수는 정의된 모듈 안에서만 쓸 수 있는 비공개 함수라서 다른 모듈에서는 사용할 수 없어요.

```gleam
// This function is public
pub fn add(x, y) {
  x + y
}

// This function is private
fn subtract(x, y) {
  x - y
}
```

Gleam 모듈에는 이름이 있고, 그 이름은 `src`나 `test` 디렉터리 안에서의 파일 경로를 바탕으로 정해져요.

예를 들어 `src\geometry\rectangle.gleam`(Windows)이나 `src/geometry/rectangle.gleam`(UNIX 계열 운영체제)에 정의된 모듈의 이름은 `geometry/rectangle`이에요.

## 다른 모듈에서 함수 임포트하기

다른 모듈에 정의된 함수에 접근하려면 임포트를 사용해요. 어떤 모듈을 임포트하면 그 모듈이 공개한 함수는 모두 사용할 수 있게 돼요. 다만 그 함수에 접근하는 방식은 모듈을 임포트한 방식에 따라 달라져요.

기본은 모듈 이름을 붙여 임포트하는 방식이고, 이렇게 임포트한 모듈의 함수(예를 들어 `gleam/list` 모듈의 `map` 함수)에 접근할 때는 모듈 이름을 앞에 붙여요(`list.map`).

```gleam
// Import the int module
import gleam/int

pub fn run(x: Int) -> String {
  // Use the to_string function from the int module
  int.to_string(x)
}
```

기본적으로 모듈을 가리키는 이름은 모듈 이름의 마지막 부분이고, 여기서는 `int`가 되는데, `as` 키워드를 사용하면 이 이름을 바꿀 수 있어요.

```gleam
// Import the int module and refer to it as i
import gleam/int as i

pub fn run(x: Int) -> String {
  i.to_string(x)
}
```

모듈 이름을 붙이지 않고 임포트하면 그 모듈이 공개한 함수에 접두사 없이 바로 접근할 수 있어요.

```gleam
// Import the to_string function from the int module
import gleam/int.{to_string}

pub fn run(x: Int) -> String {
  to_string(x)
}
```

모듈 이름을 붙여 임포트하면 함수가 어디에서 온 것인지 읽는 사람이 더 쉽게 알 수 있고 이름이 충돌하는 것도 피할 수 있어서, 이 방식을 더 권장해요.
