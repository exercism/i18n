# 지시사항

이 연습 문제에서는 프리랜서가 프로젝트 매니저와 원활하게 소통할 수 있도록, 일당과 월 요율을 빠르게 계산해 주는 몇 가지 유틸리티를 만들어요. 원한다면 주어진 할인율을 적용할 수도 있어요.

먼저 프리랜서와 프로젝트 매니저 사이에 몇 가지 규칙을 정해요:

- 일당은 시간당 요율의 8배예요.
- 한 달은 청구 가능한 날이 22일이에요.

때로는 프리랜서가 일당에 할인을 적용하기도 해요. 예를 들어 가장 단골인 고객이나 비영리 고객에게는 할인을 해줄 수 있어요.

할인은 백분율을 나타내는 소수로 표현해요. 예를 들어 `25.0`은 25%를 뜻해요.

## 1. 시간당 요율이 주어졌을 때 일당 계산하기

시간당 요율이 주어졌을 때 일당을 계산하는 함수를 구현해요:

```haskell
dailyRate 60
-- -> 480.0
```

반환되는 일당은 double이어야 해요.

## 2. 할인된 가격 계산하기

할인을 적용한 가격을 계산하는 함수를 구현해요.

```haskell
applyDiscount 150 10
-- -> 135.0
```

반환되는 값은 항상 double이어야 하며, 어떤 식으로도 반올림하면 안 돼요.

## 3. 시간당 요율과 할인율이 주어졌을 때 월 요율 계산하기

월 요율을 계산하면서 할인을 적용하는 함수를 구현해요:

```haskell
monthlyRate 77 10.5
-- -> 12130
```

반환되는 월 요율은 가장 가까운 정수로 올림(ceiling)해야 해요.

## 4. 예산, 시간당 요율, 할인율이 주어졌을 때 근무 일수 계산하기

예산, 시간당 요율, 할인율을 인자로 받아 그 예산으로 며칠을 일할 수 있는지 계산하는 함수를 구현해요.

```haskell
daysInBudget 20000 80 11.0
-- -> 35.1
```

반환되는 일수는 소수점 첫째 자리까지 내림(floor)해야 해요.
