# 힌트

## 일반

- 인자가 어떻게 만들어지는지는 신경 쓰지 말고, 인자들을 조합해 원하는 결과를 반환하는 것에만 집중해요.

## 1. 팩맨이 유령을 먹을 수 있는지 정의하기

- 함수는 불리언 값을 반환해야 해요.
- 논리 연산자 and([`&&`][logical operators])를 사용해 인자들을 조합해 결과를 만들 수 있어요.

## 2. 팩맨이 점수를 얻는지 정의하기

- 함수는 불리언 값을 반환해야 해요.
- 논리 연산자 or([`||`][logical operators])를 사용해 인자들을 조합해 결과를 만들 수 있어요.

## 3. 팩맨이 지는지 정의하기

- 함수는 불리언 값을 반환해야 해요.
- 불리언 연산자 [`&&`][logical operators]와 [`!`][logical operators]를 사용해 인자들을 조합해 결과를 만들 수 있어요.

## 4. 팩맨이 이기는지 정의하기

- 함수는 불리언 값을 반환해야 해요.
- 불리언 연산자 [`&&`][logical operators]와 [`!`][logical operators]를 사용해, 앞서 구현한 함수 중 하나의 인자와 결과를 조합할 수 있어요.

[logical operators]: https://en.cppreference.com/w/cpp/language/operator_logical
