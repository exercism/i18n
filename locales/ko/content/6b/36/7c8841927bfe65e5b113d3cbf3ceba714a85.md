# 안내 추가

## 힌트

`decode`와 `encode` 함수를 구현해야 해요. 이 함수들은 Affine cipher를 사용해 `String`을 디코딩하고 인코딩해요.
타입이 확실하지 않다면 제공된 시그니처를 사용해도 되지만, 그렇다고 해서 창의성을 제한할 필요는 없어요.

이 연습 문제는 텍스트 데이터를 다뤄요.
역사적인 이유로, Haskell의 `String` 타입은 문자들의 리스트인 `[Char]`와 같은 의미예요.
텍스트 데이터를 더 효율적으로 다루려면 `Text` 타입을 사용할 수 있어요.

이 연습 문제의 선택적 확장으로, 다음과 같이 해볼 수 있어요.

- package.yaml의 의존성 목록에 `- text`를 추가해요.
- `Data.Text`를 [다음과 같은 방식](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c)으로 임포트해요:

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- `Text` 타입을 사용하고(예: `decode :: Text -> Text`) `Data.Text` 콤비네이터를 `T.pack`처럼 참조해요.
- [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html) 문서를 찾아봐요.
- Affine.hs에서 `String`을 모두 `Text`로 바꿔요. 즉:

```haskell
encode :: (Int, Int) -> Text -> Maybe Text
encode key plainText = ...

decode :: (Int, Int) -> Text -> Maybe Text
decode key cipherText = ...
```

이 부분은 전적으로 선택 사항이에요.
