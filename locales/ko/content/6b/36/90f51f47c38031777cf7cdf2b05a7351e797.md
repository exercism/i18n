# 자세히 알아보기

F#에서 불리언은 `bool` 타입으로 표현되며, 값은 `true` 또는 `false` 중 하나예요.

F#은 세 가지 [불리언 연산자][operators]를 지원해요: `not`(NOT), `&&`(AND), `||`(OR)예요. `&&`와 `||` 연산자는 _단축 평가_를 사용하는데, 이는 연산자의 오른쪽 항이 필요할 때만 평가된다는 뜻이에요.

```fsharp
true || false // => true
true && false // => false
```

세 가지 불리언 연산자는 각각 서로 다른 [_연산자 우선순위_][precedence]를 가져요. 그 결과, 이들은 `not`이 먼저, `&&`가 그다음, 마지막으로 `||` 순서로 평가돼요. 이 규칙에서 '벗어나고' 싶다면 불리언 표현식을 괄호(`()`)로 감싸면 돼요. 괄호는 연산자 우선순위가 훨씬 더 높기 때문이에요.

```fsharp
not true && false   // => false
not (true && false) // => true
```

[precedence]: https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/symbol-and-operator-reference/#operator-precedence
