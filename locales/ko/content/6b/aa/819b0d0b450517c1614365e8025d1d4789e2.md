# 소개

Tcl은 "tickle"이라고 발음하며, Tool Command Language의 줄임말로 동적 오픈 소스 프로그래밍 언어예요.

아주 단순하면서도 강력한 언어를 목표로 설계되었어요.
문법 전체가 [단 12개의 규칙][rules]만으로 완전히 설명될 만큼 단순하죠.
그렇지만 완전한 기능을 갖춘 프로그래밍 언어예요.

Tcl은 변수 할당, 프로시저 정의, 제어 흐름까지 모든 것을 *명령어*로 다뤄요.
그래서 셸 스크립팅과 Lisp을 모두 닮았어요.

Tcl은 객체 지향, 명령형, 함수형 스타일을 포함한 여러 프로그래밍 패러다임을 지원해요.
Tcl이 가장 흔히 쓰이는 곳은 C 애플리케이션에 내장되는 스크립트 런타임과, Tk GUI 툴킷을 사용한 GUI 프로토타이핑이에요.

이 Exercism 트랙은 아직 학습 커리큘럼을 구현하지 않았어요.
Tcl 언어를 시작하려면 연습 문제를 풀면서 [Tcl 튜토리얼][tutorial]을 함께 보는 것을 추천해요.
