# 소개

Gleam의 문자열은 큰따옴표로 둘러싸인 변경할 수 없는 텍스트예요. 유니코드 문자를 지원하고, 여러 줄에 걸쳐 작성할 수도 있어요.

```gleam
let greeting = "Hello, Joe! 📞"

let multi_line_string = "one
two
three"
```

문자열은 `<>` 연산자로 이어 붙일 수 있어요:

```gleam
let name = "Mike"
"Hello, " <> name <> "!"
// -> "Hello, Mike!"
```

표준 라이브러리에 있는 [`gleam/string`][stdlib] 모듈은 문자열을 다루는 함수를 제공해요.

문자열은 `case` 표현식에서 매칭할 수 있어요:

```gleam
pub fn on_an_excellent_adventure(name: String) -> Bool {
  case name {
    "Bill" -> True
    "Ted" -> True
    _ -> False
  }
}
```

문자열의 시작 부분을 매칭하고 나머지를 변수에 할당하고 싶다면 `<>` 연산자 패턴을 사용할 수 있어요:

```gleam
pub fn profession(name: String) -> String {
  case name {
    "Dr " <> rest -> rest <> " is a doctor"
    _ -> "I'm not sure what " <> name <> " does"
  }
}
```

[stdlib]: https://hexdocs.pm/gleam_stdlib/gleam/string.html
