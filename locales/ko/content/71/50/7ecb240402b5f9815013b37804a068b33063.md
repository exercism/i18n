# 테스트

## 테스트 실행하기

연습 문제가 있는 디렉터리로 들어가면 하위 디렉터리 두 개가 보여요:

* `Sources/<Exercise>`에는 연습 문제에 대한 풀이가 들어 있어요
* `Tests/<Exercise>Tests`에는 연습 문제를 위해 실행할 테스트가 들어 있어요

올바른 디렉터리(`Sources`와 `Tests`가 들어 있는 디렉터리)에 있다면 `swift test`를 실행해서 해당 연습 문제의 테스트를 실행할 수 있어요:

```bash
$ pwd
/Users/johndoe/Code/exercism/swift/hello-world

$ ls
HELP.md  Package.swift  README.md  Sources  Tests

$ swift test
```

테스트 하나를 통과했다면 `@Test` 구문에서 `.enabled(if: RUNALL)`을 지워서 다음 테스트를 활성화해요. 또는 Linux나 macOS에서 `RUNALL` 환경 변수를 `true`로 설정하면 모든 테스트를 한 번에 실행할 수 있어요:

```bash
$ export RUNALL=true
```

Windows에서 PowerShell을 쓴다면 이렇게 해요:

```powershell
set RUNALL=true
```

## 풀이 제출하기

Exercism에 풀이를 업로드하려면 `Sources`와 `Tests` 디렉터리가 들어 있는 디렉터리에 있어야 해요.

```bash
$ exercism submit 
```
