# 안내

이 연습 문제에서는 롤플레잉 게임의 메커니즘을 구현해요.
플레이어의 캐릭터는 다음과 같은 타입으로 표현해요:

```elm
type alias Player =
    { name : Maybe String
    , level : Int
    , health : Int
    , mana : Maybe Int
    }
```

이 게임의 플레이어는 주문을 시전하려면 먼저 레벨 10에 도달해 마나 풀을 해금해야 해요.
이 게임에서 두 가지 기능, 즉 부활 메커니즘과 주문 시전 메커니즘을 작업해요.

## 1. 자기소개를 해요

`introduce` 함수의 내용을 작성해요.
은신한 플레이어는 이름을 숨기고 있을 수 있으며, 이 경우 `"Mighty Magician"`으로 소개해요.
그렇지 않으면 자기 이름으로 자신을 소개해요.

```elm
introduce { name = Nothing, level = 2, health = 8, mana = Nothing }
    --> "Mighty Magician"

introduce { name = Just "Merlin", level = 2, health = 8, mana = Nothing }
    --> "Merlin"
```

## 2. 부활 메커니즘을 구현해요

`revive` 함수는 플레이어의 캐릭터가 실제로 죽었는지(체력이 0이 되었는지) 확인해야 해요.
죽었다면 체력이 100인 새로운 `Player` 인스턴스를 반환해요.
그렇지 않으면, 즉 플레이어의 캐릭터가 죽지 않았다면 `revive` 함수는 `Nothing`을 반환해요.

플레이어의 레벨이 10 이상이면 마나도 100인 상태로 함께 부활해요.
플레이어의 레벨이 10 미만이면 마나는 `Nothing`이어야 해요.
`revive` 함수는 플레이어의 레벨을 그대로 유지해야 해요.

```elm
deadPlayer = { name = Nothing, level = 2, health = 0, mana = Nothing }

revive deadPlayer
    --> Just { name = Nothing, level = 2, health = 100, mana = Nothing }
```

체력이 1 이상인 플레이어에게 `revive` 메서드를 호출하면 함수는 `Nothing`을 반환해야 해요.

```elm
alivePlayer = { name = Nothing, level = 2, health = 42, mana = Nothing }

revive alivePlayer
    --> Nothing
```

## 3. 주문 시전 메커니즘을 구현해요

`castSpell` 함수는 주문에 드는 마나를 나타내는 `Int`와 `Player`를 인자로 받아요.
갱신된 플레이어와 시전한 주문이 입히는 피해량을 반환해요.
주문 시전에 성공하면 주문의 마나 비용 두 배에 해당하는 피해를 입혀요.
하지만 플레이어의 마나가 부족하면 아무 일도 일어나지 않아요. 플레이어는 변하지 않고 피해도 입지 않아요.
플레이어가 마나 풀조차 없다면, 주문을 시전하려 해도 주문의 마나 비용만큼 체력이 감소하고 피해는 입히지 않아요.

```elm
wizard = { name = Nothing, level = 18, health = 123, mana = Just 30 }

( updatedWizard, damage ) = castSpell 14 wizard

updatedWizard.mana --> Just 16
damage             --> 28
```
