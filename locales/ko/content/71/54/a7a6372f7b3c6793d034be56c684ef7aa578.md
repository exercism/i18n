# 지침

예비 마술사 Elyse는 기초를 좀 연습할 필요가 있어요.
그녀에게는 다루고 싶은 카드 더미가 있어요.

조금 더 쉽게 하기 위해 그녀는 1부터 10까지의 카드만 사용해요.

## 1. 특정 카드로 슬라이스 만들기

카드 연습을 할 때 Elyse는 카드 한 벌에서 가장 좋아하는 세 장, 즉 2, 6, 9로 시작하는 걸 좋아해요.
그 카드들을 그 순서대로 담은 슬라이스를 반환하는 `FavoriteCards` 함수를 작성해요.

```go
cards := FavoriteCards()
fmt.Println(cards)
// Output: [2 6 9]
```

## 2. 스택에서 카드 가져오기

주어진 스택에서 `index` 위치에 있는 카드를 반환해요.

```go
card := GetItem([]int{1, 2, 4, 1}, 2) // card == 4
```

인덱스가 범위를 벗어나면(즉, 음수이거나 스택의 끝을 넘어서면) `-1`을 반환해야 해요:

```go
card := GetItem([]int{1, 2, 4, 1}, 10) // card == -1
```

~~~~exercism/note
Go에서는 관례상 "범위를 벗어난" 값을 반환하는 대신 오류를 반환해요.
여기서는 양의 정수가 기대될 때 "범위를 벗어난" 값이 `-1`이에요.
오류를 반환할 때는 오류와 함께 [`zero value`](https://www.geeksforgeeks.org/zero-value-in-golang/)을 반환하는 것이 관용적이라고 여겨져요.
올바른 반환 값과 함께 오류를 반환하는 방법은 앞으로의 연습 문제에서 다뤄요.
~~~~

## 3. 스택의 카드 교환하기

`index` 위치의 카드를 주어진 새 카드와 교환하고, 조정된 스택을 반환해요.
이때 입력 슬라이스가 수정되는데, 이는 기대되는 동작이에요.

```go
index := 2
newCard := 6
cards := SetItem([]int{1, 2, 4, 1}, index, newCard)
fmt.Println(cards)
// Output: [1 2 6 1]
```

인덱스가 범위를 벗어나면(즉, 음수이거나 스택의 끝을 넘어서면) 새 카드를 스택의 끝에 덧붙여요:

```go
index := -1
newCard := 6
cards := SetItem([]int{1, 2, 4, 1}, index, newCard)
fmt.Println(cards)
// Output: [1 2 4 1 6]
```

## 4. 스택 맨 위에 카드 추가하기

`value` 매개변수에 지정된 카드를 스택 맨 위에 추가해요.

```go
slice := []int{3, 2, 6, 4, 8}
cards := PrependItems(slice, 5, 1)
fmt.Println(cards)
// Output: [5 1 3 2 6 4 8]
```

`value` 매개변수에 인자가 주어지지 않으면 결과는 원래 슬라이스와 같아요.

```go
slice := []int{3, 2, 6, 4, 8}
cards := PrependItems(slice)
fmt.Println(cards)
// Output: [3 2 6 4 8]
```

## 5. 스택에서 카드 제거하기

스택에서 `index` 위치의 카드를 제거하고 스택을 반환해요.
이때 입력 슬라이스가 수정될 수 있는데, 괜찮아요.

```go
cards := RemoveItem([]int{3, 2, 6, 4, 8}, 2)
fmt.Println(cards)
// Output: [3 2 4 8]
```

인덱스가 범위를 벗어나면(즉, 음수이거나 스택의 끝을 넘어서면) 스택을 그대로 두어야 해요:

```go
cards := RemoveItem([]int{3, 2, 6, 4, 8}, 11)
fmt.Println(cards)
// Output: [3 2 6 4 8]
```
