# 지침

이 연습 문제에서는 재고 시스템을 관리해요.

재고는 항목 이름을 기준으로 정리하고, 사용 가능한 항목의 개수를 추적해야 해요.

재고에 항목을 추가하는 것도 처리해야 해요.
주어진 배열에 항목이 나타날 때마다, 재고에서 해당 항목의 수량을 `1`만큼 늘려요.
요청이 있으면 수량을 `1`만큼 줄여서 재고에서 항목을 삭제하는 것도 처리해야 해요.

마지막으로, 주어진 재고의 모든 키-값 쌍을 `tuples`로 이루어진 `list`로 반환하는 함수를 구현해야 해요.


## 1. 배열을 바탕으로 재고 만들기

`create_inventory(<input list>)` 함수를 구현해서 항목들의 입력 배열로부터 "재고"를 만들어요.
각 항목 이름과 그에 해당하는 수량을 짝지은 `dict`를 반환해야 해요.

```python
>>> create_inventory(["coal", "wood", "wood", "diamond", "diamond", "diamond"])
{"coal":1, "wood":2, "diamond":3}
```

## 2. 기존 딕셔너리에 배열의 항목 추가하기

`add_items(<inventory dict>, <item list>)` 함수를 구현해서, 전달받은 재고에 항목 배열을 추가해요:

```python
>>> add_items({"coal":1}, ["wood", "iron", "coal", "wood"])
{"coal":2, "wood":2, "iron":1}
```

## 3. 재고에서 항목 수량 줄이기

`decrement_items(<inventory dict>, <items list>)` 함수를 구현해요. 이 함수는 항목들의 `list`를 받아요.
`list`에 항목이 나타날 때마다, 그 항목의 개수에서 `1`을 빼요:

```python
>>> decrement_items({"coal":3, "diamond":1, "iron":5}, ["diamond", "coal", "iron", "iron"])
{"coal":2, "diamond":0, "iron":3}
```

재고의 항목 개수는 0 아래로 내려가면 안 돼요.
입력 `list`에 항목이 나타난 횟수가 남은 개수보다 많으면, 그 항목의 수량은 0으로 유지돼요.
개수가 0으로 떨어지면, 그 뒤의 차감 요청은 무시해요.

```python
>>> decrement_items({"coal":2, "wood":1, "diamond":2}, ["coal", "coal", "wood", "wood", "diamond"])
{"coal":0, "wood":0, "diamond":1}
```

## 4. 재고에서 항목 완전히 삭제하기

`remove_item(<inventory dict>, <item>)` 함수를 구현해서, 재고에서 항목과 그 개수를 완전히 삭제해요:

```python
>>> remove_item({"coal":2, "wood":1, "diamond":2}, "coal")
{"wood":1, "diamond":2}
```

재고에서 항목을 찾지 못하면, 함수는 원래 재고를 그대로 반환해야 해요.

```python
>>> remove_item({"coal":2, "wood":1, "diamond":2}, "gold")
{"coal":2, "wood":1, "diamond":2}
```

## 5. 재고의 전체 내용 반환하기

`list_inventory(<inventory dict>)` 함수를 구현해요. 이 함수는 재고를 받아서 `(item, quantity)` 튜플들로 이루어진 배열을 반환해요.
이 배열에는 _사용 가능한_ 항목(_수량이 0보다 큰 항목_)만 포함해야 해요:

```python
>>> list_inventory({"coal":7, "wood":11, "diamond":2, "iron":7, "silver":0})
[('coal', 7), ('diamond', 2), ('iron', 7), ('wood', 11)]
```
