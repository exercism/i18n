# 소개

Factor의 시퀀스 단어 대부분은 *새로운* 시퀀스를 반환하고 입력은 그대로 둬요. 하지만 배열과 벡터는 시간에 따라 변하는 상태를 기록하고 싶을 때 **제자리 변경**도 지원해요.

`set-nth`와 `change-nth`는 칸 하나를 제자리에서 바꾸고, 배열과 벡터 어디에나 쓸 수 있어요. `<array>`는 길이가 고정된 변경 가능한 배열을 만들고, `V{ }` 리터럴과 `<vector>`, `push`, `pop`은 벡터에서만 쓸 수 있는 것들이에요. 배열은 길이를 바꿀 수 없으니까요. `clone`은 시퀀스를 복제해서 이후의 변경이 원본에 번지지 않게 해요.

```factor
USING: arrays kernel sequences ;

5 0 <array>                 ! a fresh array { 0 0 0 0 0 }
dup 7 2 swap set-nth        ! { 0 0 7 0 0 } — set position 2 to 7
.

V{ } clone                  ! a fresh, empty vector
"alice" over push           ! V{ "alice" }
"bob" over push             ! V{ "alice" "bob" }
dup pop .                   ! "bob"
.                           ! V{ "alice" }
```

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
