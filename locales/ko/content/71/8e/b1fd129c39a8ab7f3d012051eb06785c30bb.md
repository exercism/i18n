# 안내

주민 협회에서 공동 텃밭 등록을 관리할 간단한 등록 애플리케이션을 만들어 달라고 요청했어요. `Plot` 구조체는 이미 제공되어 있어요.

## 1. 텃밭 열기

`CommunityGarden.start/1` 함수를 구현해요. 이 함수는 _에이전트 프로세스_로 전달할 선택적인 키워드 목록 옵션을 받아요. 텃밭의 초기 상태는 빈 구획 모음을 나타내도록 초기화되어야 해요. 텃밭의 pid와 함께 `:ok` 튜플을 반환해요.

```elixir
{:ok, pid} = CommunityGarden.start()
# => {:ok, #PID<0.112.0>}
```

## 2. 등록 목록 조회하기

`CommunityGarden.list_registrations/1` 함수를 구현해요. 이 함수는 공동 텃밭의 `pid`를 받아요. 저장된 구획 중 등록된 구획의 목록을 반환해요.

```elixir
CommunityGarden.list_registrations(pid)
# => []
```

> 아직 구획을 등록하는 기능을 추가하지 않았으니, 이 목록은 비어 있어야 해요

## 3. 구획을 사람에게 등록하기

`CommunityGarden.register/2` 함수를 구현해요. 이 함수는 공동 텃밭의 `pid`와 구획을 등록할 이름을 받아요. 성공하면 구획의 id와 등록한 사람이 담긴 `Plot` 구조체를 반환해요.

id는 순차적으로 증가하며 고유해야 해요. 에이전트의 상태에 id 카운터를 두면 돼요.

```elixir
CommunityGarden.register(pid, "Emma Balan")
# => %Plot{plot_id: 1, registered_to: "Emma Balan"}
CommunityGarden.list_registrations(pid)
# => [%Plot{plot_id: 1, registered_to: "Emma Balan"}]
```

## 4. 구획 해제하기

`CommunityGarden.release/2` 함수를 구현해요. 이 함수는 해제할 구획의 `pid`와 `id`를 받아요. 성공하면 `:ok`를 반환해요. 구획을 해제해도 id는 재사용하지 않고, 고유 식별자로만 사용해요.

```elixir
CommunityGarden.release(pid, 1)
# => :ok
CommunityGarden.list_registrations(pid)
# => []
```

## 5. 등록된 구획 조회하기

`CommunityGarden.get_registration/2` 함수를 구현해요. 이 함수는 확인할 구획의 `pid`와 `id`를 받아요. 구획이 등록되어 있으면 그 구획을 반환하고, 등록되어 있지 않으면 `:not_found`를 반환해요.

```elixir
CommunityGarden.get_registration(pid, 1)
# => %Plot{plot_id: 1, registered_to: "Emma Balan"}
CommunityGarden.get_registration(pid, 7)
# => {:not_found, "plot is unregistered"}
```
