이벤트를 수집하는 서비스를 작성하는 임무를 맡았어요. 각 이벤트에는 날짜가 함께 있는데, 서비스 엔드포인트로 3가지 서로 다른 형식이 제출되고 있다는 걸 알게 됐어요.

- `"01/01/1970"`
- `"January 1, 1970"`
- `"Thursday, January 1, 1970"`

각 형식 사이에 몇 가지 공통점이 보여서, 조합 가능한 정규 표현식 패턴을 작성하기로 했어요.

## 1. 날짜에서 일, 월, 연도 매칭하기

`day`, `month`, `year`를 구현해서, 실행했을 때 `"01/01/1970"`(`dd/mm/yyyy`)의 숫자 구성 요소와 매칭되는 문자열 패턴을 반환하도록 해요. 일과 월은 `1` 또는 `01`(왼쪽을 0으로 채운 형태)로 나타날 수 있어요.

오류 검사는 걱정하지 않아요. 항상 유효한 숫자 구성 요소가 전달된다고 가정해도 돼요.

```clojure
(day "31")
;;=> "31"
(month "12")
;;=> "12"
(year "1970")
;;=> "1970"
```

## 2. 요일과 월 이름 매칭하기

`day-name`과 `month-name`을 구현해서, 실행했을 때 각각 요일 이름과 월 이름과 매칭되는 문자열 패턴을 반환하도록 해요.

```clojure
(day-name "Tuesday")
;;=> "Tuesday"
(month-name "June")
;;=> "June"
```

## 3. 일, 월, 연도 캡처하기

`capture-day`, `capture-month`, `capture-year`, `capture-day-name`, `capture-month-name`을 구현해서, 각 구성 요소를 이름 `"day"`, `"month"`, `"year"`, `"day-name"`, `"month-name"`에 대응시키는 맵을 반환하도록 해요.

```clojure
(capture-month-name "December")
;;=> {:month-name "December"}
```

## 4. 캡처를 조합해서 전체 날짜 캡처하기

`capture-numeric-date`, `capture-month-name-date`, `capture-day-month-name-date`를 구현해서, 해당 날짜 형식에 맞춰 3번 문제의 구성 요소들을 담은 맵을 반환하도록 해요.

```clojure
(capture-numeric-date "01/01/1970")
;;=> {:day "01", :month "01", :year "1970"}
```
