# 지침

여러 애플리케이션이 많은 로그를 만들어 내는 시스템을 운영하고 있어요. 이 로그들을 모아서 심각도에 따라 레이블을 붙여 주는 작은 프로그램을 작성하려고 해요. 시스템의 모든 애플리케이션은 같은 로그 코드를 사용하지만, 일부 레거시 애플리케이션은 모든 코드를 지원하지는 않아요.

| 로그 코드             | 로그 레이블 | 레거시 앱에서 지원하나요? |
|-----------------------| --------- | ------------------------- |
| 0                     | trace     | 아니요                    |
| 1                     | debug     | 예                        |
| 2                     | info      | 예                        |
| 3                     | warning   | 예                        |
| 4                     | error     | 예                        |
| 5                     | fatal     | 아니요                    |
| 기타 / 지원되지 않음  | unknown   | -                         |

## 1. 로그 레이블 정하기

`LogLevel.to_label/2` 함수를 구현해요. 이 함수는 정수 코드와, 로그가 레거시 앱에서 온 것인지 알려 주는 불리언 플래그를 받아서, 로그 라인의 레이블을 아톰으로 반환해야 해요.

표에 명시되지 않은 로그 코드는 _unknown_ 레이블을 반환해야 해요. 레거시 앱에서 지원되지 않는다고 표에 명시된 로그 코드도, 로그가 레거시 앱에서 왔다면 _unknown_ 레이블을 반환해야 해요.

```elixir
LogLevel.to_label(0, false)
# => :trace

LogLevel.to_label(0, true)
# => :unknown
```

## 2. 알림 보내기

예상치 못한 일이 생기면 누군가는 알림을 받아야 해요.

알림을 누구에게 보내야 하는지 결정하는 `LogLevel.alert_recipient/2` 함수를 구현해요. 이 함수는 정수 코드와, 로그가 레거시 앱에서 온 것인지 알려 주는 불리언 플래그를 받아서, 수신자의 이름을 아톰으로 반환해야 해요.

이전 과제의 `LogLevel.to_label/2` 함수를 사용해요. 로그 레이블이 _error_ 또는 _fatal_이면 _ops_ 팀에 알림을 보내요. 레거시 시스템에서 _unknown_ 레이블이 붙은 로그를 받으면 _dev1_ 팀에 알림을 보내고, 그 밖의 unknown 레이블은 _dev2_ 팀에 보내요. 나머지 로그 레이블은 _false_를 반환해서 무시해도 돼요.

```elixir
LogLevel.alert_recipient(-1, true)
# => :dev1

LogLevel.alert_recipient(0, false)
# => false
```
