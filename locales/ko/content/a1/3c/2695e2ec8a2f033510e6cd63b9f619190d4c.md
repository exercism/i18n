# 지침 추가

## 입력 예시

```j
  INPUTS=: 2 ; 1 0 0 1 0 1 ; 10
```

즉, 입력값은 다음과 같아요.
```
  0{INPUTS NB. is the input base.
  1{INPUTS NB. is the digits.
  2{INPUTS NB. is the output base.
```
## 잘못된 입력 처리

입력값 중 하나라도 유효하지 않다면, 동사는 `empty`(예: `0$0` 또는 `''`)를 반환해야 해요.

### 예시

- _입력 진법_이 2보다 작으면:
    ```j
      '' -: rebase 10 ; 0 0 0 0 ; 1
    ```

- _출력 진법_이 2보다 작으면:
    ```j
      '' -: rebase 1 ; 0 0 0 0 ; _7
    ```

- _숫자_에 입력 진법보다 크거나 같은 값이 들어 있으면:
    ```j
      '' -: rebase 10 ; 1 0 2 0 ; 2
    ```
