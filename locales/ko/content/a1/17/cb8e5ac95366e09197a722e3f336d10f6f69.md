# 지침

고등학교 커플이 SNS에서 사랑을 고백할 수 있도록, 두 사람의 이니셜이 들어간 유니코드 하트를 만들어 줄 거예요:

```
❤ J.  +  M. ❤
```

## 1. 이름 정리하기

스택에서 이름 하나를 꺼내는 `cleanupname`을 정의해요. 모든 `-`를 공백으로 바꾸고, 앞뒤의 공백을 제거해요.

```factor
"Jane-Ann" cleanupname .
! => "Jane Ann"
```

## 2. 이름의 첫 글자 가져오기

이름을 받는 `firstletter`를 정의해요. 이전 과제의 `cleanupname`을 재사용한 다음, 결과의 첫 번째 문자를 가져와서 한 글자짜리 문자열로 반환해요.

```factor
"Jane" firstletter .
! => "J"
```

## 3. 첫 글자를 이니셜로 만들기

이름을 받는 `initial`을 정의해요. 이전 과제의 `firstletter`를 재사용해서 대문자로 바꾸고, 뒤에 `.`을 붙여요.

```factor
"Robert" initial .
! => "R."
```

## 4. 하트 안에 이니셜 넣기

스택에서 이름 두 개를 꺼내는 `couple`을 정의해요. 이전 과제의 `initial`을 각 이름에 적용한 다음, 결과를 조립해요:

```factor
"Blake Miller" "Riley Lewis" couple .
! => "❤ B.  +  R. ❤"
```
