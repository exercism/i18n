# 테스트

풀이를 테스트하는 테스트 코드를 작성할 때는 stdlib의 [PonyTest](https://stdlib.ponylang.io/pony_test--index/)를 사용해요. 풀이를 테스트하려면 먼저 코드를 컴파일한 뒤 실행해요.

예를 들어 "Hello World" 문제를 풀 때의 세션은 다음과 같아요:

```text
[red@apophenia:~/exercism/pony/hello-world]$ ponyc
Generating
 Reachability
 Selector painting
 Data prototypes
 Data types
 Function prototypes
 Functions
 Descriptors
Optimising
Writing ./hello-world.o
Linking ./hello-world

[red@apophenia:~/exercism/pony/hello-world]$ ./hello-world 
1 test started, 0 complete: hello-world/HelloWorld started
1 test started, 1 complete: hello-world/HelloWorld complete
---- Passed: hello-world/HelloWorld
----
---- 1 test ran.
---- Passed: 1
```
