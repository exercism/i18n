# 테스트

## 테스트 실행하기

테스트 명세는 다음 명령으로 실행해요:

```bash
$ gradle test
```

## 테스트 더 활성화하기

코드가 활성화된 테스트를 모두 통과하면, 관심 있는 다음 테스트 앞에 있는 `@Ignore`를 지워서 다른 테스트를 하나 더 활성화해요. `@Ignore` 줄을 삭제하거나, 줄 맨 앞에 슬래시 두 개를 붙여 주석으로 만들면 돼요.

```Groovy
//@Ignore
def 'outputs "Hello, Alice!" when given the name "Alice"'() {
    expect: hello.hello('Alice') == 'Hello, Alice!'
}
```
