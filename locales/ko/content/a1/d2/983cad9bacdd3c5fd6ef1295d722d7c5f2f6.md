# 소개

## 변수 정의하기

변수를 정의한다는 것은 이름에 값을 할당한다는 뜻이에요. Scala에는 두 가지 종류의 변수가 있는데, 바로 val과 var예요.

`val`은 불변이기 때문에, 한 번 할당한 뒤에는 그 값을 더 이상 바꿀 수 없어요:

```scala
val numberTen = 10

numberTen = 11
// --> raises a compile error "reassignment to val"
```

반대로 `var`는 같은 타입의 새로운 값으로 다시 할당할 수 있어요:

```scala
var someNumber = 10

someNumber = 11
// now someNumber has been reassigned
```

Scala는 정적 타입 언어예요. 즉, 모든 것에 컴파일 시점에 타입이 정해져 있어요. 변수는 타입을 직접 명시해서 정의할 수도 있고, 할당된 값을 바탕으로 Scala 컴파일러가 타입을 추론하게 할 수도 있어요(이를 타입 추론이라고 해요). 따라서 다음 두 변수 정의는 서로 같아요:

```scala
val explicitNumber: Int = 10; // Explicitly typed
val implicitNumber = 10; // Implicitly typed
```

한 번 정의된 변수의 타입은 절대 바꿀 수 없어요.

```scala
var count = 1; // Assigning an initial value of type Int
count = 2;     // Updating to new value is possible, because it is defined as var

count = false;
// --> raises a compile error "type mismatch"
```

## 클래스 안에서 메서드 정의하기

Scala는 _객체 지향 언어_이며, 모든 메서드를 _클래스_ 안에 정의해야 해요. 클래스를 정의할 때는 `class` 키워드를 사용해요.

```scala
class Calculator {
  // ...
}
```

클래스 안에서는 `def` 키워드 뒤에 이름을 붙여 메서드를 정의할 수 있어요. 각 메서드는 매개변수를 하나도 가지지 않을 수도 있고, 여러 개 가질 수도 있는데, 매개변수는 괄호 안에 쉼표로 구분해서 나열해요. 모든 매개변수에는 타입을 명시해야 해요. 매개변수에는 타입 추론이 적용되지 않아요. 매개변수 목록 뒤에는 콜론을 하나 더 써서 메서드의 반환 타입을 정의해요.

메서드 정의 뒤에는 `=` 기호가 오고, 그다음부터 메서드 본문이 시작돼요. 다음 예시에서 메서드 본문은 두 개의 문으로 이루어져 있고, 중괄호로 감싸져 있어요.

메서드는 마지막 표현식의 값을 반환해요. 여기서는 `add` 메서드가 `sum` 변수의 값을 반환해요:

```scala
class Calculator {
  // long form
  def add(x: Int, y: Int): Int = {
    val sum = x + y
    sum
  }
}
```

가독성을 높이기 위해 이 메서드를 더 짧게 만들 수 있는 몇 가지 개선점이 있어요:

- `sum` 변수는 값을 반환할 때 한 번만 사용되므로 생략할 수 있어요
- 문이 하나뿐인 메서드에는 중괄호가 필요 없어요
- 메서드의 반환 타입도 변수 타입과 마찬가지로 추론할 수 있어요

그러면 같은 기능을 하는 다음과 같은 한 줄짜리 메서드가 돼요:

```scala
class Calculator {
  // shortened form
  def add(x: Int, y: Int) = x + y
}
```

## 클래스 인스턴스 만들기와 메서드 호출하기

메서드를 호출하려면 먼저 클래스의 인스턴스를 만들고, 그다음 그 인스턴스에서 인자를 넘겨 메서드를 호출해요:

```scala
val calculator = new Calculator()
val sum = calculator.add(5, 7)
// sum is of type Int with assigned value of 12
```

## 주석

Scala는 한 줄 주석과 여러 줄 주석, 두 가지 종류의 주석을 지원해요:

```scala
// this is a single line comment

/*
This comment spans across
multiple lines.
*/
```
