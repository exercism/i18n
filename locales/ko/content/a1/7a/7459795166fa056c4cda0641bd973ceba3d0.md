# 개요

Swift의 `guard` 문은 필요한 조건이 충족되지 않았을 때 함수, 루프, 메서드에서 일찍 빠져나가기 위해 사용해요:

```swift
guard myValue >= 0 else { return 0 }
let root = myValue.squareRoot()
```

위 예시에서 `guard`는 뒤따르는 불리언 표현식을 평가해요.
조건이 `true`이면 `guard` 문 뒤의 코드로 실행이 이어져요.
조건이 `false`이면 `else` 블록 안의 코드가 실행돼요.

`if` 문과는 달라요:

- `guard` 문에는 `else` 절이 **반드시** 있어야 해요.
- `else` 절은 **반드시** 제어를 넘겨 주변 스코프를 벗어나야 해요. 예를 들어 `return`, `continue`, `break`를 사용하거나 오류를 던지는 방법이 있어요.

`guard`는 사전 조건을 깔끔하게 검사할 때 자주 사용해요.
예를 들어 싱크 함수를 살펴봐요. 싱크 함수는 $\text{sinc}(x) = \frac{\sin(x)}{x}$이고, 0으로 나누는 문제를 피하기 위해 $\text{sinc}(0) = 1$로 정의해요:

```swift
func sinc(_ x: Double) -> Double {
    guard x != 0 else { return 1 }
    return sin(x) / x
}

sinc(0)             // returns 1
sinc(Double.pi / 2) // returns 0.6366197723675814
```
