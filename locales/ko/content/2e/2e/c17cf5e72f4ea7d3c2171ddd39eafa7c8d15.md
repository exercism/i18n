# 소개

패턴 매칭은 적극적이고 관용적인 Elixir 코드에서 주를 이뤄요. `=/2`가 대입 연산자가 아니라 매치 연산자라고 설명된다는 점을 기억할지도 몰라요. 매치 연산자를 사용할 때, 왼쪽의 패턴이 오른쪽과 매치되면 왼쪽의 변수들이 바인딩되고 오른쪽의 값이 반환돼요. 매치가 없으면 `MatchError`가 발생해요.

```elixir
2 = 2
# => 2
# Literals can be matched if they are the same

2 = 3
# => ** (MatchError) no match of right hand side value: 3

{_, denominator} = Float.ratio(0.25)
# => {1, 4}
# the variable `denominator` is bound to the value 4
```

매치는 오른쪽에서 왼쪽으로 일어난다는 점을 기억해요.

마지막 예시에서, 패턴 매치에 변수가 필요하지 않다면 `_`를 참조해서 버릴 수 있어요. `_`로 시작하는 변수는 런타임이 추적하지 않아요.

## 이름 있는 함수에서의 패턴 매칭

패턴 매칭은 여러 개의 함수 절을 만들 때도 유용한 도구예요. 패턴 매칭은 함수의 인자에 사용할 수 있고, 그러면 어떤 함수 절을 호출할지가 결정돼요. 파일의 맨 위에서 시작해서 처음 매치되는 곳까지 내려가면서 결정돼요. 변수는 함수 헤드에서 바인딩하고 함수 본문에서 사용할 수 있어요.

```elixir
defmodule Example do
  def named_function(:a = variable_a) do
    {variable_a, 1}
  end

  def named_function(:b = variable_b) do
    {variable_b, 2}
  end
end

Example.named_function(:a)
# => {:a, 1}

Example.named_function(:b)
# => {:b, 2}

Example.named_function(:c)
# => ** (FunctionClauseError) no function clause matching in Example.named_function/1
```
