# 소개

F#에서 이름에 값을 할당하는 것을 _바인딩_이라고 해요. 바인딩은 불변이기 때문에 다른 언어의 상수와 비슷해요. F#은 정적 타입 언어이므로 각 바인딩은 컴파일 타임에 타입을 가져요.

바인딩은 `let` 키워드를 사용해 정의해요. 대부분의 바인딩에서는 타입을 지정하는 것이 선택 사항이에요. F#의 _타입 추론_이 보통 값에 따라 타입을 추론할 수 있기 때문이죠. 바인딩은 이렇게 생겼어요:

```fsharp
// Automatically inferred type
let fingers = 10
```

함수도 일반 바인딩이지만, 하나 이상의 매개변수를 가져요. 함수는 마지막 식을 자동으로 반환해요. 타입 추론은 대부분의 함수에서도 작동하는데, 이는 함수가 어떤 값으로 호출되는지와 어떤 값을 반환하는지 분석하기 때문이에요.

```fsharp
// Automatically inferred types for parameters and return type
let add x y = x + y
```

함수를 호출할 때는 함수의 이름을 쓰고 각 매개변수에 대한 인자를 전달해요.

```fsharp
let five = add 2 3
```

바인딩의 타입을 추론할 수 없으면 컴파일러가 오류를 보고해요. 이 문제를 해결하려면 바인딩에 명시적 타입 주석을 추가해요.

```fsharp
// Explicit type annotation
let fingers: int = 10

// Explicit type annotation (also for parameters)
let add (x: int) (y: int): int = x + y
```

F#의 바인딩은 정의된 _후에만_ 사용할 수 있어요. 바인딩이 정의되기 전에 사용하면 컴파일 오류가 발생해요.

```fsharp
// Compile error as the add binding has not yet been defined
// let seven = add 3 4

let add x y = x + y
```

F#은 스코프를 정의하기 위해 의미 있는 공백을 사용해요. 즉, 스코프는 바인딩을 선언하는 줄을 기준으로 코드를 공백으로 들여쓰기해서 정의해요. 기본 관례는 들여쓰기에 공백 네 칸을 사용하는 거예요:

```fsharp
let toes =
    let left = 5
    let right = 5
    left + right

let multiplyPlusTwo x y =
    let product = x * y
    product + 2

// Trying to access the left, right or product bindings
// here would result in a compile error
```

F#의 바인딩(함수 포함)은 보통 모듈로 구성해요. 모듈은 관련 기능을 묶고 `module` 키워드를 사용해 정의해요. 모듈 정의는 바인딩보다 앞에 와야 해요:

```fsharp
module Calculator

let pi = 3.14

let add x y = x + y
```

F#은 두 가지 종류의 주석을 지원해요. 한 줄 주석은 `//`로 시작하고, 여러 줄 주석은 `(*`와 `*)` 사이에 삽입해요.
