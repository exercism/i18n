# configlet 워크플로

configlet은 [configlet 도구](/docs/building/configlet)를 사용해 트랙의 (설정) 파일이 구문적으로나 의미적으로 올바르게 구성되어 있는지 검사해요.
이때 [`configlet lint`](/docs/building/configlet/lint)를 실행해요.

## 파일 서식 검사 활성화

트랙에서는 [`configlet fmt`](/docs/building/configlet/format)를 사용해 트랙의 여러 설정 파일 서식을 맞출 수 있어요.
이 명령어로 모든 설정 파일의 서식이 올바른지 확인할 수도 있어요.

`configlet` 워크플로는 설정 파일의 서식이 올바른지 검사하는 기능을 지원하지만, 이 기능은 선택 사항이고 기본적으로는 꺼져 있어요.
설정 파일의 서식 검사를 사용하려면 다음 단계를 따라 해요:

1. 다음 내용으로 `.github/org-wide-files-config.toml` 파일을 만들어요

```toml
[configlet]
fmt = true
```

2. 이 파일이 `main`에 병합되면, `configlet.yml` 워크플로를 다음과 같이 수정하는 PR이 자동으로 열려요:

```diff
  jobs:
    configlet:
      uses: exercism/github-actions/.github/workflows/configlet.yml@main
+     with:
+       fmt: true
```

3. 이 PR이 병합되면, `configlet` 워크플로가 트랙 설정 파일의 서식도 검사해요.

## 출처

워크플로는 `.github/workflows/configlet.yml` 파일에 정의되어 있어요.
