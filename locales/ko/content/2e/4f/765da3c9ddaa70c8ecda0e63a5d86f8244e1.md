# 개요

## 숫자 비교하기

`jq`에서는 다음 관계 연산자와 동등 연산자로 숫자를 비교할 수 있어요.

| 비교             | 연산자   |
| ---------------- | -------- |
| ~보다 큼         | `a > b`  |
| ~보다 크거나 같음 | `a >= b` |
| ~보다 작음       | `a < b`  |
| ~보다 작거나 같음 | `a <= b` |
| 같음             | `a == b` |
| 같지 않음        | `a != b` |

비교 결과는 항상 불리언 값이에요. 즉 `true` 또는 `false`예요.

```jq
1 < 3,      # => true
2 != 2,     # => false
1 == 1.0    # => true
            # All numbers are floating-points, so this is different syntax
            # for the exact same value.
```

## 문자열 비교하기

위의 비교 연산자는 문자열을 비교할 때도 사용할 수 있어요.
이때는 사전식(사전 순) 순서가 적용돼요.
정렬 순서는 [유니코드 코드 포인트 값][sort]을 기준으로 해요.

[sort]: https://jqlang.org/manual/#sort-sort_by

```jq
"Apple" > "Pear",   # => false
"a" < "above",      # => true
"a" == "A"          # => false
```

숫자 값을 담고 있는 것처럼 보이지만 문자열 타입인 두 변수를 비교할 때는 주의해야 해요.
사전식 순서 때문에, 그 결과는 숫자 타입의 값을 비교한 것과 같지 않아요.

```jq
10 < 2,     # => false
"10" < "2"  # => true (because "1" comes before "2")
```

## "엄격한" 동등 비교

`jq`의 `==` 연산자는 자바스크립트의 `===`와 비슷해요. 겉보기에는 같아 보여도 타입이 다르면 같지 않다고 판단하는 점에서요.

```jq
"3" == 3    # => false
            # the value on the left has type string,
            # the value on the right has type number.
```

## 배열 비교하기

두 배열은 서로 대응하는 모든 원소가 같으면 같아요.

```jq
[1, 2, 3] == [1, 2, 3]      # => true
[1, 2, 3] == [1, 3, 2]      # => false, different order
[1, 2, 3] == [1, 2, "3"]    # => false, different types
```

## 객체 비교하기

두 객체는 같은 키-값 쌍을 가지면 같아요.

```jq
{name: "Joe", age: 42} == {age: 42, name: "Joe"}                # => true
{name: "Joe", age: 42} == {age: 42, name: "Jane"}               # => false
{name: "Joe", age: 42} == {age: "42", name: "Joe"}              # => false
{name: "Joe", age: 42} == {age: 42, name: "Joe", height: 175}   # => false

# comparisons will drill down as deeply as required
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2]}}}                  # => true
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2, 3]}}}               # => false
```
