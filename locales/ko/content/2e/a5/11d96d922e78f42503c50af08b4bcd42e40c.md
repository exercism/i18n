# 지시 사항

이 연습 문제에서는 Exercism에서 배우고 싶은 프로그래밍 언어 목록을 관리하는 코드를 작성해요.

여섯 개의 과제가 있고, 모두 배열을 다루는 내용이에요.

## 1. 새 배열 만들기

배우고 싶은 언어를 관리하려면 새 배열을 만들어야 해요. 비어 있는 새 배열을 반환하는 `new_list` 함수를 정의해요.

```gleam
new_list()
// -> []
```

## 2. 기존 배열 정의하기

지금은 배우고 싶은 언어가 적힌 종이 한 장이 있어요. Gleam, Go, TypeScript예요. 이 배열을 반환하는 `existing_list` 함수를 정의해요.

```gleam
existing_list()
// -> ["Gleam", "Go", "TypeScript"]
```

## 3. 배열에 새 언어 추가하기

Exercism을 둘러보면서 더 흥미로운 언어를 찾으면, 그 언어를 배열에 추가하고 싶어져요. 배열의 맨 앞에 새 언어를 추가하는 `add_language` 함수를 구현해요.

```gleam
add_language(["OCaml", "Elixir"], "Scheme")
// -> ["Scheme", "OCaml", "Elixir"]
```

## 4. 배열에 있는 언어 개수 세기

언어를 하나씩 세는 건 번거로워요. 배열에 있는 언어의 개수를 세는 `count_languages` 함수를 구현해요.

```gleam
count_languages(["jq", "Elm", "Rust", "Kotlin"])
// -> 4
```

## 5. 배열 순서 뒤집기

어느 순간, 배열이 사실 거꾸로 정렬되어 있다는 걸 깨닫게 돼요! 배열을 뒤집는 `reverse_list` 함수를 구현해요.

```gleam
reverse_list(["Python", "Julia", "Idris", "COBOL"])
// -> ["COBOL", "Idris", "Julia", "Python"]
```

## 6. 배열이 흥미진진한지 확인하기

모든 언어를 사랑하지만, Gleam은 마음속 특별한 자리를 차지하고 있어요. 그래서 다음 조건을 만족하는 언어 배열을 보면 정말 신나요.

- 배열의 첫 번째가 Gleam이에요.
- 배열의 두 번째 항목이 Gleam이고, 배열에 언어가 두 개 또는 세 개 들어 있어요.

언어 배열이 흥미진진한지 확인하는 `exciting_list` 함수를 구현해요.

```gleam
exciting_list(["Lua", "Gleam"])
// -> True
```
