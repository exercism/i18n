# 소개

`readonly` 제한자는 필드의 값이나 참조를 덮어쓰지 못하게 막아 주지만, 참조 형식의 멤버까지 보호해 주지는 않아요.

```csharp
readonly List<int> ints = new List<int>();

void Foo()
{
    ints.Add(1);    // ok
    ints = new List<int>(); // fails to compile
}
```

참조 형식의 모든 멤버를 보호하려면 필드를 `readonly`로 만들고, 자동 속성을 `set` 접근자 없이 정의하면 돼요.

기본 클래스 라이브러리(Base Class Library, BCL)는 컬렉션의 멤버가 수정되는 것을 막아야 할 때 쓸 수 있는 몇 가지 읽기 전용 컬렉션을 제공해요. 이런 컬렉션은 래퍼 형태로 제공돼요.

- `ReadOnlyDictionary<T>`는 `Dictionary<T>`를 읽기 전용으로 노출해요.
- `ReadOnlyCollection<T>`는 `List<T>`를 읽기 전용으로 노출해요.
