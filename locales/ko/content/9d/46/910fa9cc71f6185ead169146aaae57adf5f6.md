# 학습

- [The Zig Programming Language Documentation][documentation]은 Zig가 사용하는 사람들에게 제공하는 모든 언어 기능을 잘 살펴볼 수 있는 개요예요.
- [Awesome Zig][awesome-zig]은 여러 사람이 만든 Zig 프로젝트를 잘 모아 놓은 모음집이에요.
  잘 작성된 Zig 코드를 사용하는 프로젝트들이 들어 있어요.
- [Zighelp][zighelp]은 Zig가 제공하는 언어 기능을 설명해 주는 훌륭한 입문서예요.
- [Ziglings][ziglings]를 적극 추천해요.
  망가진 작은 프로그램을 고치면서 Zig를 배워요.
- [Zig SHOWTIME][zig-showtime]은 Zig 커뮤니티 구성원들이 코드와 아이디어를 공유하는 라이브 방송이에요.

[awesome-zig]: https://github.com/catdevnull/awesome-zig
[documentation]: https://ziglang.org/documentation/master/
[zighelp]: https://zighelp.org/
[zig-showtime]: https://zig.show/
[ziglings]: https://codeberg.org/ziglings/exercises
