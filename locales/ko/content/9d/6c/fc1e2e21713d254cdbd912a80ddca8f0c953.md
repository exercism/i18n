# 소개

[축자 문자열][verbatim-strings]을 사용하면 여러 줄 문자열을 만들 수 있어요. 축자 문자열은 @ 문자로 시작해요. 문자열 보간에도 사용할 수 있어요. 여는 따옴표 앞에 "\$"를 붙이기만 하면 돼요.

```csharp
string str = @"
See no wretched
quotes everywhere
";
```

[verbatim-strings]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/strings/#regular-and-verbatim-string-literals
