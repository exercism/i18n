# 소개

이전 콘셉트에서 Julia의 타입은 계층 구조를 이루고, 맨 위에 `Any`가 있다는 것을 살펴봤어요.

`Number`와 같은 추상 타입은 서브타입을 가질 수 있지만, 그 자체로는 인스턴스화할 수 없어요.
변수의 타입을 추상 타입으로 지정하면, 그 변수의 값은 추상 타입의 서브타입 중 하나로 _제한_돼요.
예를 들어 볼까요?

```julia-repl
julia> x::Number = 3
3
julia> typeof(x)  # one subtype of Number
Int64
julia> x = 4.2
4.2
julia> typeof(x) # another subtype of Number
Float64
julia> x = "fail" # not a number type!
ERROR: MethodError: Cannot `convert` an object of type String to an object of type Number
```

이렇게 하면 어떤 입력이 유효한지 제한하는 데 한 가지 유연성을 얻을 수 있어요.

그런데 변수가 정수와 문자열 값을 모두 받아들이게 하고 싶다면 어떨까요?
이 두 타입은 계층 구조에서 같은 가지에 있지 않아요.

타입을 `Any`로 지정하거나 기본값인 `Any`를 그대로 둘 수도 있지만, 그러면 허용되는 타입을 전혀 제어할 수 없어요.

더 나은 방법으로 `Union{ }` 문법이 있어요. 중괄호 안에 두 개 이상의 타입을 나열하면 돼요.

```julia-repl
julia> y::Union{Integer, String} = 4
4
julia> typeof(y)
Int64
julia> y = "works"
"works"
julia> typeof(y)
String
julia> y = 5.3
ERROR: MethodError: Cannot `convert` an object of type 
  Float64 to an object of type 
  Union{Integer, String}
```

또 다른 예제에서는 같은 타입 유니언을 함수 시그니처에 사용해요:

```julia-repl
julia> IntOrString = Union{Integer, String}
Union{Integer, String}
julia> f(z::IntOrString) = z^3
f (generic function with 1 method)
julia> f(2) # integers are cubed
8
julia> f("ab") # strings are repeated 3 times
"ababab"
```

여기서는 타입에 이름을 붙였는데, 이렇게 하면 편리하게 줄여 쓸 수 있지만 꼭 필요한 것은 아니에요.
`g(z::Union{Integer, String}) = z^3` 함수도 똑같이 동작해요.

함수 시그니처에 대해서는 다중 디스패치 콘셉트에서 훨씬 더 자세히 다룰 거예요.

## `nothing`을 포함하는 유니언

다른 여러 언어에는 값을 담을 수도, 담지 않을 수도 있는 타입이 있고, `Option`, `Nullable`, `Maybe` 같은 이름이 붙어 있어요.

Julia에는 이를 위한 별도의 문법이 없지만, 타입 유니언이 같은 아이디어를 일반화한 것이에요.

`Nothingness` 콘셉트에서 Julia가 `nothing`과 `missing`을 비롯해 값이 없음을 나타내는 여러 방법을 가지고 있다는 것을 살펴봤어요.
이 둘 중 어느 것이든 타입 유니언에 포함할 수 있어요.

예를 들어 연결 리스트를 정의할 때는 다음 노드가 없으면 리스트를 끝내는 방법이 필요해요.
`Nothing`은 단일 값 `nothing`을 가지는 타입이고, 이렇게 `Node`를 정의하면 체인의 끝을 알릴 수 있어요:

```julia-repl
julia> struct Node
           value::Any
           next::Union{Node, Nothing}
       end
```

마찬가지로 `missing`은 특히 벡터 같은 컬렉션에서 값이 없음을 나타내는 자리 표시자로 쓸 수 있어요.
아래 예제는 아주 인위적이지만, 실제 데이터셋에서는 결측값이 흔해요.

```julia-repl
julia> q(x::Real) = x >= 0 ? sqrt(x) : missing  # skip negative values
q (generic function with 1 method)
julia> vals::Vector{Union{Real, Missing}} = q.([4, 3.1, -1, 0])
4-element Vector{Union{Missing, Float64}}:
 2.0
 1.760681686165901
  missing
 0.0
```
