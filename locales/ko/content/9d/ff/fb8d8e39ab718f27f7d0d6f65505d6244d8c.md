# 지침 추가

출력은 [행 우선 순서](https://en.wikipedia.org/wiki/Row-_and_column-major_order)로 배치해야 해요. 첫 번째 행의 단어를 모두 쓰고, 그다음 두 번째 행의 단어를 쓰는 식으로요.

## 레지스터

| 레지스터 | 용도      | 타입    | 설명                              |
| -------- | --------- | ------- | --------------------------------- |
| `$a0`    | 입력      | 정수    | 크기                              |
| `$a1`    | 입력/출력 | 주소    | 행 우선 순서로 된 단어의 행렬     |
| `$v0`    | 출력      | 정수    | 행렬에 있는 단어 수               |
| `$t0-9`  | 임시      | 임의    | 임시 저장용                       |
