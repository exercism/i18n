# 힌트

## 1. 무작위 행성 생성하기

- 컬렉션 타입의 인자를 넘기면 [`rand()`][rand]는 어떻게 동작할까요?

## 2. 무작위 우주선 등록 번호 생성하기

- 정수 범위를 넘기는 [`rand()`][rand]를 생각해 봐요.
- 문자열 [보간][interpolation]을 기억해 봐요.

## 3. 무작위 스타데이트 생성하기

- 인자 없이 호출하면 [`rand()`][rand]는 무엇을 반환할까요?
- 원래 결과의 스케일을 조정하고 값을 이동시키는 방법을 생각해 봐요.

## 4. 반올림된 스타데이트 생성하기

- 소개 부분을 읽고, 부동소수점 범위에 대해 무엇이라고 하는지 살펴봐요.

## 5. 목록에서 무작위 우주선 몇 척 고르기

- 무작위성을 얻으려면 입력 목록을 [섞어야][shuffle] 해요.
- 안전을 위해서는 입력을 그대로 두고 섞은 복사본을 만드는 게 좋아요. (그렇지 않으면 이 함수는 입력을 변경하게 되어 `pick_starships!`라고 불러야 해요.)
- 결과로 나온 벡터에서 필요한 만큼 잘라 내요.

## 5a. 선택 사항: 다른 인자 타입

- [`Random.shuffle()`][shuffle]은 다른 반복 가능한 타입을 어떻게 처리할까요? 문서를 확인하거나 직접 실험해 봐요.
  - REPL, [Pluto.jl][pluto], [Jupyter][jupyter] 모두 이럴 때 유용해요.
- 필요하다면, 임의의 반복 가능한 객체를 벡터로 어떻게 변환할까요?
