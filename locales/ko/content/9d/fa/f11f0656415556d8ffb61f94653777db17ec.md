# 지침

이 연습 문제에서는 자동차 공장의 생산을 분석하는 코드를 작성해요.

## 1. 시간당 생산되는 정상 차량 수 계산하기

자동차는 조립 라인에서 생산돼요.
조립 라인에는 바꿀 수 있는 속도가 있어요.
조립 라인의 속도가 빠를수록 더 많은 자동차가 생산돼요.
하지만 조립 라인의 속도를 바꾸면 성공적으로 생산되는 자동차, 즉 생산 과정에 오류가 없는 자동차의 수도 달라져요.

시간당 생산되는 자동차 수와 성공률을 받아서 시간당 성공적으로 생산되는 자동차 수를 계산하는 함수를 구현해요.
성공률은 `0`에서 `100` 사이의 백분율로 주어져요:

```go
CalculateWorkingCarsPerHour(1547, 90)
// => 1392.3
```

**참고:** 반환 값은 `float64`여야 해요.

## 2. 분당 생산되는 정상 차량 수 계산하기

시간당 생산되는 자동차 수와 성공률을 받아서 분당 성공적으로 생산되는 자동차 수를 계산하는 함수를 구현해요:

```go
CalculateWorkingCarsPerMinute(1105, 90)
// => 16
```

**참고:** 반환 값은 `int`여야 해요.

## 3. 생산 비용 계산하기

각 자동차는 성공 여부와 상관없이 개별적으로 생산하는 데 보통 10,000달러가 들어요.
하지만 조금만 계획을 세우면 자동차 10대를 함께 생산해서 95,000달러에 만들 수 있어요.

예를 들어 자동차 37대는 다음과 같은 방식으로 생산할 수 있어요:
37 = 10대씩 묶음 3개 + 낱개 자동차 7대

따라서 자동차 37대의 비용은 다음과 같아요:
3\*95,000+7\*10,000=355,000

성공 여부와 상관없이 여러 대의 자동차를 생산할 때 드는 비용을 계산하는 `CalculateCost` 함수를 구현해요:

```go
CalculateCost(37)
// => 355000

CalculateCost(21)
// => 200000
```

**참고:** 반환 값은 `uint`여야 해요.
