# 안내

이 연습 문제에서는 동네 오락실에서 가장 인기 있는 게임의 최고 점수를 기록하는 방법을 구현해요.

## 1. 최고 점수 게시판에 플레이어 추가하기

최고 점수 게시판에 플레이어를 추가하려면, 다음 인자들을 받는 두 개의 `add_player!` 메서드를 정의해요:

- 첫 번째 인자는 점수를 담은 딕셔너리예요.
- 두 번째 인자는 플레이어의 이름을 나타내는 문자열이에요.
- 세 번째 인자는 점수를 나타내는 정수예요.
  이 인자는 선택 사항이고, 값이 주어지지 않으면 점수는 0으로 설정돼요.

```julia-repl
julia> scores = Dict{String, Int}()
Dict{String, Int64}()

julia> add_player!(scores, "Liselot", 486373)
Dict{String, Int64} with 1 entry:
  "Liselot" => 486373

julia> add_player!(scores, "Éimhín")
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0
```

## 2. 점수 게시판에서 플레이어 제거하기

최고 점수 게시판에서 플레이어를 제거하려면, 인자 2개를 받는 `remove_player!`를 정의해요:

- 첫 번째 인자는 점수를 담은 딕셔너리예요.
- 두 번째 인자는 플레이어의 이름을 나타내는 문자열이에요.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> remove_player!(scores, "Liselot")
Dict{String, Int64} with 1 entry:
  "Éimhín" => 0
```

## 3. 플레이어의 점수 업데이트하기

이전 점수를 대체해서 플레이어의 점수를 업데이트하려면, 인자 3개를 받는 `update_score!`를 정의해요:

- 첫 번째 인자는 점수를 담은 딕셔너리예요.
- 두 번째 인자는 점수를 업데이트하려는 플레이어의 이름을 나타내는 문자열이에요.
- 세 번째 인자는 저장할 최고 점수로 설정하려는 점수예요.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> update_score!(scores, "Éimhín", 89479) # TODO: Should this return the dict?
89479

julia> scores
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 89479
```

## 4. 플레이어의 점수 초기화하기

플레이어의 점수를 초기화하려면, 인자 2개를 받는 `reset_score!`를 정의해요:

- 첫 번째 인자는 점수를 담은 딕셔너리예요.
- 두 번째 인자는 점수를 초기화하려는 플레이어의 이름을 나타내는 문자열이에요.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> reset_score!(scores, "Liselot") # TODO: Should this return the dict?
0

julia> scores
Dict{String, Int64} with 2 entries:
  "Liselot" => 0
  "Éimhín"  => 0
```

## 5. 플레이어 배열 가져오기

플레이어 배열을 가져오려면, 인자 1개를 받는 `players`를 정의해요:

- 첫 번째 인자는 점수를 담은 딕셔너리예요.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> players(scores)
2-element Vector{String}:
 "Liselot"
 "Éimhín"
```
