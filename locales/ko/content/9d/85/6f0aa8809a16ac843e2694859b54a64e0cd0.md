# 지침

이 연습 문제에서는 간판 회사가 간판에 넣을 맞춤 메시지를 만들 수 있도록 돕는 코드를 작성해요.

## 1. 유용한 문자열 집합 만들기

간판을 만드는 데 사용할 다음 상수 문자열을 정의해요:

- `birthday`: 이 상수는 "Birthday" 값을 가져요.
- `valentine`: 이 상수는 "Valentine's Day" 값을 가져요.
- `anniversary`: 이 상수는 "Anniversary" 값을 가져요.

## 2. 유용한 문자 집합 만들기

간판을 만드는 데 사용할 다음 상수 문자를 정의해요:

- `space`: 이 상수는 " " 값(공백 한 칸)을 가져요.
- `exclamation`: 이 상수는 "!" 값을 가져요.

## 3. 문구를 조합해 메시지 만들기

`buildSign(for:name:)` 함수를 구현해요. 이 함수는 첫 번째 과제에서 정의한 세 문자열 중 하나를 담는 `for` 인자와, 간판을 받을 사람의 이름을 담는 문자열 `name` 인자를 받아요.
간판의 메시지를 만들 때 문자열 연결을 사용하고, 이미 정의한 상수를 다시 사용하는 것도 잊지 마세요.
함수는 간판 메시지를 문자열로 반환해야 해요.

```swift
buildSign(for: birthday, name: "Otto")
// returns "Happy Birthday Otto!"

buildSign(for: anniversary, name: "Valentina")
// returns "Happy Anniversary Valentina!"
```

## 4. 졸업 간판 만들기

`graduationFor(name:year:)` 함수를 구현해요. 이 함수는 간판을 받을 사람의 이름을 담는 문자열 `name` 인자와, 그 사람이 졸업하는 연도를 담는 정수 `year` 인자를 받아요.
간판의 메시지를 만들 때 템플릿 문자열을 사용해요.
함수는 간판 메시지를 문자열로 반환해야 해요.

```swift
graduationFor(name: "Padma", year: 2023)
// returns "Congratulations Padma!\nClass of 2023"
```

## 5. 간판 가격 계산하기

`costOf(sign:)` 함수를 구현해요. 이 함수는 간판의 메시지를 담는 문자열 `sign` 인자를 받아요.
간판의 기본 가격은 해당 통화 기준으로 20이고, 글자마다 2씩 추가돼요. (공백도 계산에 포함돼요.)
함수는 간판의 가격을 정수로 반환해야 해요.

```swift
costOf(sign: "Happy Birthday Grandma!")
// returns 66
```
