# 테스트

Clojurescript REPL을 사용하면 코드를 쉽게 실행하고 즉각적인 피드백을 받을 수 있으며, 테스트를 실행하는 데에도 쓸 수 있어요.

## Leiningen

Clojure CLI로 REPL을 열려면, 연습 문제가 있는 디렉터리로 이동한 뒤 다음을 실행해요:
``` bash
$ clojure -m cljs.main -re node
```

Node가 시스템에 설치되어 있어야 해요.

연습 문제를 풀 준비가 되었고 해답을 담을 파일(예: `bob.cljs`)을 만들었다면, 터미널에서 `$ clojure -A:test`로 테스트를 실행할 수 있어요.

먼저 테스트 네임스페이스를 `require`해요:
``` clojure
=> (require 'bob-test)
nil
;; and the test namespace
=> (require 'cljs.test)
```

`ns`를 테스트 네임스페이스로 바꿔요:
```clojure
=> (ns bob-test)
nil
```

그다음 `bob-test`에 `run-tests`를 호출해요:
``` clojure
=> (cljs.test/run-tests)

Testing bob-test

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
{:test 14, :pass 14, :fail 0, :error 0, :type :summary}
```

Clojure CLI로 연습 문제의 테스트를 실행하려면 다음을 호출하기만 하면 돼요:
``` bash
$ clojure -M:test

Testing bob-tests

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
```
