# 지침 추가

## 귀납적 타입 정의하기

이 연습 문제는 반환 값이 직접 정의해야 하는 [귀납적 타입][inductive] `Classification`이기를 기대해요.

이 타입에는 [BEq][beq] 인스턴스, 즉 불리언 동등성 검사가 가능한 인스턴스와 [Repr][repr] 인스턴스, 즉 이 타입의 값을 표시할 수 있도록 형식을 지정할 수 있는 인스턴스가 있어야 해요.

인스턴스 선언에 대해서는 [이 페이지][instance]를 참고하면 돼요.
Lean은 많은 클래스에 대해 [인스턴스를 자동으로 생성][deriving]할 수 있어요.

## 서브타입

`classify` 함수의 인자는 `Positive`라는 [서브타입][subtype]이에요:

```
def Positive := { x : Nat // x > 0 }
```

서브타입은 특정 타입의 원소 중에서 어떤 술어를 만족하는 원소를 나타내요.
`Positive`는 `0`보다 큰 `Nat`의 원소를 나타내죠.

서브타입의 원소는 기반 타입의 값과, 그 값이 해당 술어를 만족한다는 수학적 의미의 증명이 짝을 이룬 것으로 생각할 수 있어요.

서브타입은 타입 수준에서 불변식을 강제해서, 잘못된 형태의 값이 만들어질 수 없도록 해요.
