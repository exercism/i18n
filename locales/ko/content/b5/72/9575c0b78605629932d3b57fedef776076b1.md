# 안내

이 연습 문제에서는 친구가 개발 중인 비디오 게임에 들어갈 로직을 작성해요. 게임의 주인공은 Annalyn으로, 용감한 소녀에다 무섭도록 충직한 반려견을 키우고 있죠. 그런데 안타깝게도 불행이 닥쳐요. Annalyn의 가장 친한 친구가 숲에서 열매를 찾다가 납치된 거예요. Annalyn은 친구를 찾아 구출하려고 하고, 원한다면 이 여정에 반려견을 데리고 갈 수도 있어요.

Annalyn은 마침내 친구가 갇혀 있는 야영지를 찾아내는데, 납치범이 둘이라는 사실을 알게 돼요. 힘센 기사와 교활한 궁수예요.

플레이어에게는 다음에 무엇을 할지에 대한 몇 가지 선택지가 주어져요. 네 가지 선택지 각각에 대해, 그 선택지를 보여줄지 말지를 게임에 알려 주는 단어를 작성해야 해요.

## 1. '빠른 공격' 옵션을 표시해야 하는지 확인하기

기사가 잠들어 있다면, Annalyn은 기사가 제대로 깨어나 갑옷을 입기 전에 재빨리 야영지로 공격을 가할 수 있어요.

기사가 깨어 있는지를 나타내는 불리언 값을 받는 `can-do-fast-attack`이라는 단어를 구현해요.
'빠른 공격' 행동을 할 수 있으면 `t`를, 그렇지 않으면 `f`를 반환해요:

```factor
t can-do-fast-attack .
! => f
```

## 2. '정찰' 옵션을 표시해야 하는지 확인하기

일행 중 적어도 한 명이 깨어 있으면 몰래 정찰할 수 있어요. 그렇지 않다면 정찰은 시간 낭비일 뿐이에요.

기사, 궁수, 죄수가 각각 깨어 있는지를 나타내는 불리언 값 세 개를 받는 `can-spy`라는 단어를 구현해요.
'정찰' 행동을 할 수 있으면 `t`를, 그렇지 않으면 `f`를 반환해요:

```factor
f t f can-spy .
! => t
```

## 3. '죄수에게 신호 보내기' 옵션을 표시해야 하는지 확인하기

죄수가 깨어 있고 궁수가 잠들어 있으면 새소리를 이용해 죄수에게 신호를 보낼 수 있어요. 궁수가 깨어 있다면 안전하게 신호를 보낼 수 없는데, 궁수도 새소리 신호를 배웠기 때문이에요.

궁수와 죄수가 각각 깨어 있는지를 나타내는 불리언 값 두 개를 받는 `can-signal-prisoner`라는 단어를 구현해요.
'죄수에게 신호 보내기' 행동을 할 수 있으면 `t`를, 그렇지 않으면 `f`를 반환해요:

```factor
f t can-signal-prisoner .
! => t
```

## 4. '죄수 구출' 옵션을 표시해야 하는지 확인하기

Annalyn은 야영지에 몰래 들어가 친구를 구출해 볼 수 있어요. 위험한 일이라 다음 두 가지 방법 중 하나로만 성공할 수 있어요:

- Annalyn이 반려견을 데리고 있다면, 궁수가 잠들어 있을 때 죄수를 구출할 수 있어요.
  기사는 개를 무서워하고, 궁수는 Annalyn과 친구가 도망치기 전에 준비할 시간이 없어요.

- Annalyn이 반려견을 데리고 있지 않다면, Annalyn과 죄수가 아주 조심스럽게 움직여야 해요!
  죄수가 깨어 있고 기사와 궁수가 모두 잠들어 있으면 Annalyn은 죄수를 구출할 수 있어요.
  죄수가 잠들어 있다면 구출할 수 없어요. Annalyn이 갑자기 나타나면 죄수가 놀라서 기사와 궁수를 깨울 테니까요.

불리언 값 네 개를 받는 `can-free-prisoner`라는 단어를 구현해요.
매개변수는 순서대로 궁수가 깨어 있는지, 개가 있는지, 죄수가 깨어 있는지, 기사가 깨어 있는지를 나타내요.
'죄수 구출' 행동을 할 수 있으면 `t`를, 그렇지 않으면 `f`를 반환해요:

```factor
f t t f can-free-prisoner .
! => t      (archer asleep, dog present, prisoner awake, knight asleep)

t t f f can-free-prisoner .
! => f      (archer is awake, so no rescue possible)
```
