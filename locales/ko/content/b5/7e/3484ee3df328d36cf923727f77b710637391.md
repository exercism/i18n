# 힌트

## 일반

- `accessors`는 자동으로 생성되는 `slot>>` 게터, `>>slot` 세터, `change-slot` 갱신자를 제공해요.
- 세터와 `change-slot`은 튜플을 *변경*해요. 비파괴적인 갱신을 원한다면 먼저 `clone`을 해요.

## 1. `player` 튜플 정의하기

- 슬롯 문법은 `TUPLE: …  ;` 안에 `{ name initial: value }`를 쓰는 거예요.
- `initial:` 절이 없는 슬롯은 기본값이 `f`예요.

## 2. 플레이어 소개하기

- `name>>`은 `name` 슬롯을 읽어요.
- [`kernel`][kernel]의 `unless*`는 "`f`일 때 기본값" 관용구예요.

## 3. 쓰러진 플레이어 되살리기

- `health>>`는 슬롯을 읽고, [`math`][math]의 `zero?`는 0인지 검사해요.
- `clone`한 뒤 `100 >>health`와 `100 >>mana`로 새 플레이어를 만들어요.
- "아직 살아 있음"에 해당하는 경우에는 `f`를 반환해요.

## 4. 피해 입기

- `change-health`는 `( old-health -- new-health )` 쿼테이션을 받아요.
- fry 쿼테이션 `'[ _ - 0 max ]`는 ([`math.order`][math.order]의 `max`와 함께) "캡처한 피해를 빼고 0에서 잘라내기"를 해줘요.
- 변경하기 전에 `clone`하는 걸 잊지 말아요.
