# 지시사항

그토록 오래 기다린 날이 마침내 왔어요. 이제 알프스에 있는 아름다운 농장의 자랑스러운 주인이 되었어요.

그래도 아침 일찍 일어나 소에게 먹이를 주는 건 여전히 마음에 들지 않아요.
뛰어난 엔지니어답게, 직접 먹이 공급기 `FEED-M-ALL`을 만들었어요.

프로젝트를 끝내기 위해 마지막으로 필요한 것은, 각 소가 받아야 할 사료의 양을 계산하는 코드예요.
모든 소가 같은 양을 받는 게 중요해요. 다툼이 생기지 않도록 해야 하죠.
소는 아주 예민하거든요.

다행히도 사료 양을 계산하는 모든 공식을 직접 만들어 낼 필요는 없어요.
인터넷에서 찾은 신비한 외부 라이브러리를 사용하면 되거든요.
이 라이브러리는 가장 행복한 소를 만들어 준다고 해요.
이 라이브러리는 다음 인터페이스를 구현하는 클래스를 제공해요.
직접 작성하는 코드에서 이 클래스에 의존하게 될 거예요.

```crystal
class FodderCalculator
  def fodder_amount! : Number 
  end

  def fattening_factor! : Number
  end
end
```

코드를 작성하다 보면, 나중에 농장 일상에서 사용할 때 더 견고하고 디버깅하기 쉽도록 오류 처리를 개선하게 될 거예요.

## 1. 먹이를 똑같이 나누기

먼저, 소 한 마리당 사료의 양을 계산하는 데 필요한 코드를 작성하는 데 집중해요.

`FodderCalculator` 객체와 소의 수(정수)를 인자로 받는 메서드 `TheFarm.divide_food`를 구현해요.
*이 과제에서는 전달받는 소의 수가 항상 0보다 크다고 가정해요.*
이 메서드는 소 한 마리당 먹이의 양을 반환해야 해요.

계산을 하려면 먼저 모든 소를 위한 전체 사료 양을 가져와야 해요.
이는 `fodder_amount!` 메서드를 호출하면서 소의 수를 전달하면 돼요.
또한 이 양에 곱해야 하는 계수가 필요해요.
이 계수는 `fattening_factor!` 메서드를 호출해서 얻어요.
이 두 값과 소의 수를 가지고, 이제 소 한 마리당 먹이의 양을 (`float64`로) 계산할 수 있어요.

호출한 메서드 중 하나가 오류를 반환하면, 실행을 멈추고 `0`을 반환해야 해요.

```crystal
fodder_calculator = FodderCalculator.new(50, 1.5)
TheFarm.divide_food(fodder_calculator, 5)
# => 15.0

fodder_calculator = FodderCalculator.new(50, nil)
TheFarm.divide_food(fodder_calculator, 5)
# => 0
```

## 2. 소의 수 확인하기

위의 첫 번째 과제를 하다 보면, 사용하는 외부 라이브러리가 생각만큼 품질이 좋지 않다는 걸 알게 돼요.
예를 들어, 잘못된 입력을 제대로 처리하지 못하죠.
이 한계를 피하기 위해 직접 작성한 코드에서 입력값을 검사하기로 해요.

위의 `TheFarm.divide_food`와 같은 시그니처를 가진 함수 `TheFarm.validate_input_and_divide_food`를 작성해요.

- 전달받은 소의 수가 0보다 크면, 함수는 `TheFarm.divide_food`를 호출하고 그 결과를 반환해야 해요.
- 소의 수가 0 이하이면, 함수는 `"Number of cows must be greater than 0"`라는 메시지와 함께 오류를 발생시켜야 해요.

```crystal
TheFarm.validate_input_and_divide_food(fodderCalculator, 5)
# => 15

TheFarm.validate_input_and_divide_food(fodderCalculator, -2)
# Error: Number of cows must be greater than 0
```

## 3. 오류 처리 개선하기

소의 수를 전달하기 전에 확인한 건 좋은 선택이었지만, 두루뭉술한 오류 메시지가 마음에 들지 않아요.
`InvalidCowsError`라는 사용자 정의 오류 클래스를 만들어서 더 나아지게 하기로 해요.

이 사용자 정의 오류는 소의 수(`Int32`)와 사용자 정의 메시지(`String`)를 담고 있어야 하고, `Expection` 메서드는 데이터를 다음 형식으로 직렬화해야 해요:
```txt
{number of cows} cows are invalid: {custom message}
```

직접 만든 오류를 갖추었으니, 소의 수를 정수로 받아 오류(또는 nil)를 반환하는 함수 `TheFarm.validate_number_of_cows`를 구현해요.

- 소의 수가 0보다 작으면, 함수는 사용자 정의 메시지가 `"there are no negative cows"`로 설정된 `InvalidCowsError`를 반환해요.
- 소의 수가 0이면, 함수는 사용자 정의 메시지가 `"no cows don't need food"`로 설정된 `InvalidCowsError`를 반환해요.
- 그렇지 않으면, 함수는 검증이 성공했음을 나타내는 `nil`을 반환해요.

```crystal
TheFarm.validate_number_of_cows(5)
# => nil

TheFarm.validate_number_of_cows(-5)
# => InvalidCowsError: -5 cows are invalid: there are no negative cows
```

이 검증 함수를 만드는 힘든 작업을 마치고 나면, 어느새 저녁이 되어 자리에서 일어나 산 너머로 지는 노을을 즐기러 가요.
새 검증 함수를 실제로 코드에 추가하는 일은 다음 날로 미뤄 둬요.
