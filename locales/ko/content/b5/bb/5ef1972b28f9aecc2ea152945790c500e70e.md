# 지침

`classes` 연습 문제에서 시작한 원격 조종 자동차 프로젝트가 잘 진행됐어요(축하해요!). 그리고 최근 여러 후원 계약 덕분에 개선 작업에 쓸 예산도 생겼어요.

예산의 일부는 텔레메트리를 제공하는 데 쓰이고 있어요.

후원사들의 마음을 붙잡아 두기 위해, 자동차가 트랙을 돌 때 후원사 이름을 표시하는 패널이 차에 설치됐어요.

이 멋진 신기술이 도입되면서 자동차의 배터리 수명이 크게 줄었다는 점도 눈치챘을 거예요.

## 1. 원격 조종 자동차가 후원사 이름을 표시하도록 만들기

하나 이상의 후원사 이름을 받아 자동차에 저장하도록 `SetSponsors()`를 구현해요.

`SetSponsors()` 메서드의 인자는 null이 아님이 보장돼요.

선택한 후원사를 표시하도록 `DisplaySponsor()`를 구현해요. 처음 전달된 후원사의 `sponsorNum`은 0이고, 두 번째는 1, 그다음은 이런 식이에요.

```csharp
var car = RemoteControlCar.Buy();
car.SetSponsors("Exercism", "Walker Industries", "Acme Co.");
var sp2 = car.DisplaySponsor(sponsorNum: 1);
// => "Walker Industries"
```

## 2. 자동차의 텔레메트리 데이터 가져오기

`RemoteControlCar.GetTelemetryData()` 메서드를 구현해요.

`GetTelemetryData()`는 배터리 잔량과 미터 단위 주행 거리를 `out` 매개변수를 통해 사용할 수 있게 해야 해요.

`serialNum` 인자가 이전에 받은 값보다 작으면 `GetTelemetryData()`는 `false`를 반환해야 해요. (여러 텔레메트리 노드가 관련된 문제가 있어요.) 이 경우 `serialNum`은 이전 `serialNum` 중 가장 높은 값으로 설정되고, 배터리 잔량과 주행 거리(미터)는 모두 `-1`로 설정돼요. 호출이 성공하면 `serialNum`은 그대로 유지돼요.

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
int serialNum = 4;
car.GetTelemetryData(ref serialNum, out int batteryPercentage, out int distanceDrivenInMeters);
// => true, 4L, 80, 4

serialNum = 1;
car.GetTelemetryData(ref serialNum, out batteryPercentage, out distanceDrivenInMeters);
// => false, 4L, -1, -1
```

## 3. 텔레메트리 시스템이 미터당 배터리 사용량을 가져올 수 있도록 기능 추가하기

`TelemetryClient.GetBatteryUsagePerMeter()` 메서드를 구현해요.

이 메서드는 `RemoteControlCar.GetTelemetryData()`를 호출해요. `GetTelemetryData()`가 `false`를 반환하거나 자동차가 주행하지 않았다면, 이 루틴은 "no data"를 반환해야 해요. `GetTelemetryData()`가 `true`를 반환하면 "usage-per-meter=BATTERY-USAGE-PER-METER" 형식의 메시지를 반환해야 해요. 여기서 계산은 (100 - 현재 배터리 잔량)을 지금까지 주행한 거리(미터)로 나눈 값이에요.

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
var tc = new TelemetryClient(car);
int serialNum = 4;
tc.GetBatteryUsagePerMeter(serialNum);
// => "usage-per-meter=5"

serialNum = 1;
tc.GetBatteryUsagePerMeter(serialNum);
// => "no data"
```
