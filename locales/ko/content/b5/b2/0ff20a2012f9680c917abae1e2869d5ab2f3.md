# 지침

기본적인 배열 연산을 구현해요.

함수형 언어에서는 `length`, `map`, `reduce` 같은 배열 연산이 아주 흔해요. 기존 함수를 사용하지 않고, 일련의 기본적인 배열 연산을 직접 구현해 봐요.

구현할 연산의 정확한 개수와 이름은 기존 이름과의 충돌을 피하기 위해 track마다 다르지만, 일반적으로 구현하게 될 연산은 다음과 같아요:

* `append` (*두 개의 배열이 주어지면, 두 번째 배열의 모든 항목을 첫 번째 배열의 끝에 추가해요*);
* `concatenate` (*여러 개의 배열이 주어지면, 모든 배열의 항목을 하나의 평탄화된 배열로 합쳐요*);
* `filter` (*predicate와 배열이 주어지면, `predicate(item)`이 True인 모든 항목의 배열을 반환해요*);
* `length` (*배열이 주어지면, 그 안에 있는 항목의 총 개수를 반환해요*);
* `map` (*함수와 배열이 주어지면, 모든 항목에 `function(item)`을 적용한 결과의 배열을 반환해요*);
* `foldl` (*함수, 배열, 초기 누산기가 주어지면, 왼쪽에서부터 `function(accumulator, item)`을 사용해 각 항목을 누산기로 폴드(축약)해요*);
* `foldr` (*함수, 배열, 초기 누산기가 주어지면, 오른쪽에서부터 `function(item, accumulator)`을 사용해 각 항목을 누산기로 폴드(축약)해요*);
* `reverse` (*배열이 주어지면, 원래 항목을 모두 담되 순서를 뒤집은 배열을 반환해요*);
