# 지시 사항

학교 연극의 소품 테이블을 맡고 있어요. 소품은 소품 이름과 개수를 짝지은 맵이에요.

세 가지 과제는 모두 `MISSING_PROPS` 클래스에 작성해요.

## 1. 몇 개나 있을까요?

소품이 몇 개 있는지 반환해요. 소품이 테이블에 아예 없다면, `"Unknown prop: "` 뒤에 소품 이름을 붙인 문자열을 발생시켜요.

```sather
MISSING_PROPS::count_of(props, "crown")
-- => 2

MISSING_PROPS::count_of(props, "sword")
-- raises "Unknown prop: sword"
```

어떤 소품이 0개인 것과 그런 소품이 아예 없는 것은 달라요. 0개로 적혀 있는 소품은 이미 알고 있는 소품이고, 그냥 다 떨어졌을 뿐이에요.

## 2. 하나 가져가기

하나를 가져간 뒤에 몇 개가 남았는지 반환해요. 소품이 목록에는 있지만 남은 게 없다면, `"Out of "` 뒤에 소품 이름을 붙여 발생시켜요.

```sather
MISSING_PROPS::take_one(props, "crown")
-- => 1

MISSING_PROPS::take_one(props, "lantern")
-- raises "Out of lantern"
```

테이블에 아예 없는 소품이라면 여전히 `"Unknown prop: ..."` 메시지를 발생시켜야 해요. 그리고 그 메시지를 두 번 쓸 필요는 없어요.

## 3. 결과 알려주기

어떤 일이 있어도 발생시키지 않고 메시지를 반환해요.

```sather
MISSING_PROPS::report(props, "crown")
-- => "Took crown, 1 left"

MISSING_PROPS::report(props, "lantern")
-- => "Out of lantern"

MISSING_PROPS::report(props, "sword")
-- => "Unknown prop: sword"
```

잘 처리되면 메시지는 `"Took "`, 소품 이름, `", "`, 남은 개수, `" left"` 순서로 이어져요. 그렇지 않으면 메시지는 발생시킨 문자열과 똑같아요.
