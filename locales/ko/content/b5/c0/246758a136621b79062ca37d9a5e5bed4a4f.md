# 소개

Common Lisp에서 함수의 인자 목록은 ['lambda list'][lambda-list]라고 해요.
lambda list에는 여러 가지 타입의 인자가 올 수 있어요.
이런 타입들은 모두 `&`로 시작하는 ['lambda list keyword'][lambda-list-keyword]로 지정해요.
가장 흔히 쓰이는 타입은 선택적 인자, 키워드 인자, 나머지 인자예요.
특정 lambda list keyword 뒤에 오는 lambda list의 모든 매개변수는 그 타입이 돼요.
lambda list keyword는 하나의 lambda list에서 한 번만 사용할 수 있어요.

lambda list는 구조 분해나 매크로처럼 나중에 다룰 다른 구문에서도 사용해요.

[lambda-list]: http://www.lispworks.com/documentation/HyperSpec/Body/26_glo_l.htm#lambda_list
[lambda-list-keyword]: http://www.lispworks.com/documentation/HyperSpec/Body/26_glo_l.htm#lambda_list_keyword
