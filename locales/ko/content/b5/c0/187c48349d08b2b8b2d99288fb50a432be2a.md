# 안내

경기의 득점자 목록을 받아, 각 선수가 몇 골을 넣었는지 세는 것이 과제예요.

`PlayerName`은 코드를 더 읽기 쉽게 만들고, 이 `String`의 쓰임을 다른 `String` 사용과 구분하기 위한 `String`의 타입 별칭이에요.

## 1. 득점자 집계하기

먼저 `updateGoalCountForPlayer`를 구현해서 선수의 골 수를 초기화하거나 증가시켜요.
그다음에는 `updateGoalCountForPlayer`를 사용해서 각 선수가 몇 골을 넣었는지 세는 `aggregateScorers` 함수를 구현해요.
이 함수는 `List PlayerName`(골을 넣은 선수들의 이름 목록으로, 중복된 선수 이름이 들어 있을 수 있어요)을 받아, 목록에 있는 모든 선수와 각 선수가 넣은 골 수를 담은 `Dict PlayerName Int`를 반환해요.

```elm
aggregateScorers [ "Betty", "Cedd", "Betty" ]
--> Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ]
```

## 2. 중요하지 않은 선수 제거하기

기준값보다 골을 적게 넣은 선수를 걸러 내는 `removeInsignificantPlayers` 함수를 구현해요.

```elm
removeInsignificantPlayers 2 (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> Dict.fromList [ ( "Betty", 2 ) ]
```

## 3. 선수의 골 수 초기화하기

선수가 넣은 골 수를 0으로 초기화하는 `resetPlayerGoalCount` 함수를 구현해요.

```elm
resetPlayerGoalCount "Cedd" (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 0 ) ]
```

## 4. 한 선수의 골 수 포맷하기

한 선수의 골 수를 문자열로 포맷하는 `formatPlayer` 함수를 구현해요. 딕셔너리에 그 선수가 없으면 골 수가 0이라고 가정해요.

```elm
formatPlayer "Betty" (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> "Betty: 2"
```

## 5. 모든 선수의 골 수 포맷하기

모든 선수의 골 수를 문자열로 포맷하는 `formatPlayers` 함수를 구현해요. 선수들은 이름순으로 정렬되어야 해요.

```elm
formatPlayers (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> "Betty: 2, Cedd: 1"
```

## 6. 경기 합치기

두 경기에서 각 선수가 넣은 총 골 수를 세는 `combineGames` 함수를 구현해요.

```elm
combine Games
  (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
  (Dict.fromList [ ( "Betty", 2 ), ( "Mario", 3 ) ] )
--> Dict.fromList [ ( "Betty", 4 ), ( "Cedd", 1 ), ( "Mario", 3 ) ]
```
