# 개요

Haxe는 타입과 필드의 런타임 리플렉션을 지원해요. 리플렉션을 올바르게 사용하려면 어떤 연산이 지원되고 어떤 연산이 지원되지 않는지 이해해야 해요. 리플렉션은 동적인 특성을 지니기 때문에, 이를 컴파일 타임에 항상 결정할 수는 없어요.

리플렉션 API는 두 개의 클래스로 구성되어 있어요:

- `Reflect`: 익명 구조체에서 가장 잘 동작하는 가벼운 API이며, 클래스 지원은 제한적이에요.
- `Type`: 클래스와 열거형을 다루기 위한 더 견고한 API예요.

사용 가능한 메서드는 [Reflect][reflect]와 [Type][type] API에 자세히 설명되어 있어요.

다음 예제에서는 JavaScript 타깃을 사용해요:

```haxe
class Main {
  public static function main() {
    trace(Type.resolveClass("Main"));
  }
}

// This outputs
// class Test { static main() { console.log("Test.hx:3:",$hxClasses["Test"]); } }
```

[reflect]: https://api.haxe.org/Reflect.html
[type]: https://api.haxe.org/Type.html
