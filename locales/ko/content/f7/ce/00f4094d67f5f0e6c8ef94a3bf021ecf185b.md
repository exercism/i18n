# 지침 추가

## 트랙별 지침

`ComplexNumber` 객체를 위해서는 동등 연산자를 직접 구현해야 해요. 여기서 두 부동소수점 수를 비교하는 문제가 생겨요. [Numerics][swift-numberics] 라이브러리에 있는 `isApproximatelyEqual(to:absoluteTolerance:)` 메서드를 사용하면 도움이 될 거예요. 성능 문제 때문에 `RealModule` 부분에만 접근할 수 있어요. 임포트하려면 파일 맨 위에 `import RealModule`이라고 쓰면 돼요. `0.00001` 정도의 허용 오차면 테스트를 통과하기에 충분해요. 이 라이브러리는 이미 프로젝트에 임포트되어 있으니, 파일에서 임포트하기만 하면 돼요.

두 복소수를 비교하는 메서드를 직접 구현해도 괜찮아요.

[swift-numberics]: https://github.com/apple/swift-numerics
