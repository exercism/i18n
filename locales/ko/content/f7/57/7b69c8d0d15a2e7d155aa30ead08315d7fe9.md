# 지시 사항

온라인 패션 부티크를 운영하고 있어요. 재고의 각 품목은 원소 두 개로 이루어진 배열 `{ name price }`이고, 재고 전체는 품목들의 배열이에요.

가격이 없으면 `f`로 기록해요.

## 1. 재고를 가격순으로 정렬하기

`sort-by-price`를 정의해서, 품목을 가격 오름차순으로 정렬한 새 배열을 반환하도록 해요.

```factor
{ { "Maxi Brown Dress" 65 } { "Red Skirt" 50 } { "Bamboo Socks Cats" 20 } }
sort-by-price .
! => { { "Bamboo Socks Cats" 20 } { "Red Skirt" 50 } { "Maxi Brown Dress" 65 } }
```

## 2. 가격이 없는 품목 찾기

`with-missing-price`를 정의해서, 가격이 `f`인 품목만 담은 배열을 반환하도록 해요.

```factor
{ { "Black T-shirt" 40 } { "Denim Pants" f } { "Orange T-shirt" 40 } }
with-missing-price .
! => { { "Denim Pants" f } }
```

## 3. 비싼 품목 세기

`expensive-items`를 정의해서, 재고와 가격 기준값을 받아, 기준값보다 가격이 큰 품목이 몇 개인지 반환하도록 해요.

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } { "Dress" 80 } }
50 expensive-items .
! => 2

{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } { "Dress" 80 } }
0 expensive-items .
! => 4
```

## 4. 가장 저렴한 품목 찾기

`cheapest-item`을 정의해서, 가격이 가장 낮은 품목을 반환하도록 해요. 가격이 없는(`f`) 품목은 입력에 나타나지 않아요.

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } } cheapest-item .
! => { "Hat" 25 }
```

## 5. 모든 가격의 합 구하기

`total-price`를 정의해서, 모든 가격의 합을 반환하도록 해요. 가격이 없는(`f`) 품목은 입력에 나타나지 않아요.

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } } total-price .
! => 195
```

## 6. 품목을 가격표로 만들기

`format-price-tag`를 정의해서, 품목을 `"name: $price"` 형태의 문자열로 반환하도록 해요. 가격이 없는(`f`) 품목은 여기에 나타나지 않아요.

```factor
{ "Skirt" 50 } format-price-tag .
! => "Skirt: $50"
```
