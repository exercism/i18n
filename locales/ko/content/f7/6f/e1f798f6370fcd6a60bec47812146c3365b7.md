# 테스트

테스트를 실행하려면 다음 단계를 따라 해요:

- 연습 문제 디렉터리로 이동해요 (예: `~/Exercism/hello-world`).
- 터미널에서 `jconsole` 세션을 시작해요 (예: `jconsole` 또는 `ijconsole`을 입력).
- 풀이 파일을 불러와요 (예: `load 'hello-world.ijs'`).
- `load  'general/unittest'`를 입력해 단위 테스트 프레임워크를 불러와요.
- `unittest 'test.ijs'`를 입력해 풀이를 테스트해요.
<br></br>
- 또는 다음과 같이 한 줄로 테스트를 실행할 수도 있어요: `jconsole -js "load 'hello-world.ijs'" "echo unittest 'test.ijs'" "exit 0"`.

## 건너뛴 테스트

처음에는 첫 번째 테스트만 활성화돼요.
연습 문제를 한 단계씩 풀어 나가도록 이끌어 줘요.
각 테스트에는 정의 위에 이름이 _'\_ignore'_로 끝나는 명사가 있어요.
테스트를 실행하려면 그 값을 0으로 바꿔요.

### 예시:

```
    leap_test_02_ignore=: 1 NB. Change this value to 0 to run this test
    test_leap_test_02  =: monad define
    ...                     NB. test definitions
    )
```
