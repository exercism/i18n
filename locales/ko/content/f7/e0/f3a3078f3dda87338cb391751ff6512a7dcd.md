# 안내

학생들의 시험을 채점하는 조교로 일하고 있어요.
결과를 손으로 기록하는 건 점점 지루해지고 실수하기도 쉬워져요.
그래서 반 전체의 결과를 세고 계산하는 함수 몇 개를 만들어서, 일을 조금 더 재미있게 해보기로 해요.

## 1. 점수 반올림

시험 문제에는 "부분 점수"를 줄 수 있지만, 전체 시험 점수는 `int`여야 해요.
그래서 반 점수로 다른 작업을 하기 전에, 먼저 성적을 훑으면서 `float` 점수를 모두 `int`로 바꿔야 해요. 다행히 Python에는 사용할 수 있는 내장 [`round()`][round] 함수가 있어요.

`student_scores`라는 `list`를 매개변수로 받는 `round_scores(student_scores)` 함수를 만들어요.
이 함수는 입력 `list`를 _소비_하고, 모든 점수를 `int`로 변환한 새 배열을 `return`해야 해요.
결과 `list`에서 점수의 순서는 중요하지 않아요.

```python
>>> student_scores = [90.33, 40.5, 55.44, 70.05, 30.55, 25.45, 80.45, 95.3, 38.7, 40.3]
>>> round_scores(student_scores)
...
[40, 39, 95, 80, 25, 31, 70, 55, 40, 90]
```

## 2. 불합격한 학생

시험을 채점하다 보니, 기대만큼 성적이 좋지 않은 학생들이 눈에 띄었어요.
그런데 다른 데 정신이 팔려서, 학생이 _몇 명_인지 정확히 적어 두는 걸 깜빡했어요.

`student_scores`라는 `list`를 매개변수로 받는 `count_failed_students(student_scores)` 함수를 만들어요.
이 함수는 합격 점수를 받지 못한 학생 수를 세고, 그 수를 정수로 반환해야 해요.
시험에서 합격하려면 **40**보다 높은 점수를 받아야 해요.

```python
>>> count_failed_students(student_scores=[90,40,55,70,30,25,80,95,38,40])
5
```

## 3. "최고"

함께 일하는 선생님은 이번 시험에서 "가장 잘한" 학생들을 찾고 싶어 해요.
"가장 잘한"의 기준은 매번 달라지기 때문에, 현재 기준값 **이상**인 점수를 찾아야 해요.

`student_scores`(성적의 `list`)와 `threshold`("최고 점수" 기준)를 매개변수로 받는 `above_threshold(student_scores, threshold)` 함수를 만들어요.
이 함수는 `threshold`보다 크거나 같은(`>=`) 모든 점수의 `list`를 반환해야 해요.

```python
>>> above_threshold(student_scores=[90,40,55,70,30,68,70,75,83,96], threshold=75)
[90,75,83,96]
```

## 4. 알파벳 등급 계산

함께 일하는 선생님은 숫자 점수뿐만 아니라 알파벳 등급도 매기고 싶어 해요.
학생들이 시험에서 100점을 받는 일은 드물기 때문에, "알파벳 등급"의 하한 기준은 최고 점수를 바탕으로 계산하고, 최고 점수와 불합격 기준인 **<= 40** 사이를 균등하게 나눠요.

시험의 "최고" 점수를 인자로 받고, "미국식" 등급 구간 `["D", "C", "B", "A"]` 각각의 하한 점수 `list`를 반환하는 `letter_grades(highest)` 함수를 만들어요.


```python
"""Where the highest score is 100, and failing is <= 40.
       "F" <= 40
 41 <= "D" <= 55
 56 <= "C" <= 70
 71 <= "B" <= 85
 86 <= "A" <= 100
"""

>>> letter_grades(highest=100)
[41, 56, 71, 86]


"""Where the highest score is 88, and failing is <= 40.
       "F" <= 40
 41 <= "D" <= 52
 53 <= "C" <= 64
 65 <= "B" <= 76
 77 <= "A" <= 88
"""

>>> letter_grades(highest=88)
[41, 53, 65, 77]
```

## 5. 이름과 점수 연결하기

내림차순으로 정렬된 시험 점수 배열과, 시험 점수를 기준으로 역시 내림차순으로 정렬된 학생 이름 배열이 있어요.
각 학생 이름을 시험 점수와 짝지어서, 반 전체 순위를 출력하고 싶어요.

`student_scores`와 `student_names`를 매개변수로 받는 `student_ranking(student_scores, student_names)` 함수를 만들어요.
student_names `list`의 각 학생 이름을 student_scores `list`의 점수와 짝지어요.
각 인자 `list`는 가장 높은 점수(를 받은 사람)부터 가장 낮은 점수(를 받은 사람) 순으로 정렬되어 있다고 가정해도 돼요.
이 함수는 `<rank>. <student name>: <student score>` 형식의 문자열 `list`를 반환해야 해요.

```python
>>> student_scores = [100, 99, 90, 84, 66, 53, 47]
>>> student_names =  ['Joci', 'Sara','Kora','Jan','John','Bern', 'Fred']
>>> student_ranking(student_scores, student_names)
...
['1. Joci: 100', '2. Sara: 99', '3. Kora: 90', '4. Jan: 84', '5. John: 66', '6. Bern: 53', '7. Fred: 47']
```

## 6. "완벽한" 점수

시험에서 100점이라는 "완벽한" 점수를 받는 일은 드물지만, 적어도 한 명의 학생이 그것을 달성했는지 아는 건 흥미로워요.

`student_info`를 매개변수로 받는 `perfect_score(student_info)` 함수를 만들어요.
`student_info`는 각 학생의 이름과 점수를 담은 `list`의 `list`예요: `[["Charles", 90], ["Tony", 80]]`.
이 함수는 시험에서 100점을 받은 학생의 _첫 번째_ `[<name>, <score>]` 쌍을 `return`해야 해요.

`student_info`에서 100점이 없으면, 빈 `list` `[]`를 반환해야 해요.

```python
>>> perfect_score(student_info=[["Charles", 90], ["Tony", 80], ["Alex", 100]])
["Alex", 100]

>>> perfect_score(student_info=[["Charles", 90], ["Tony", 80]])
[]
```

[round]: https://docs.python.org/3/library/functions.html#round
