# 소개

## 사용자 정의 타입

Elm의 [사용자 정의 타입][custom-types]은 정해진 개수의 이름 있는 경우를 나타내요. 각 값은 그 이름 있는 경우 중 정확히 하나에 대응해요.

사용자 정의 타입은 `type` 키워드로 정의하고, 필요한 문법도 아주 적어요. Elm 프로그래밍에서 가장 중요한 기법 중 하나로, 코드에서 가능한 값이 실생활에서 유효한 값과 정확히 일치하도록 만드는 데 쓰여요. 덕분에 잘못된 데이터가 끼어들 여지가 없고, [불가능한 상태를 코드로 표현할 수 없게][impossible-states] 만들어요.

```elm
type Season
    = Spring
    | Summer
    | Autumn
    | Winter
```

사용자 정의 타입의 각 경우에는 선택적으로 데이터를 함께 붙일 수 있고, 경우마다 서로 다른 타입의 데이터를 가질 수 있어요. 어떤 경우에도 데이터가 붙어 있지 않다면, 이 판별 합집합은 다른 언어에서 흔히 _열거형_(_enum_)이라고 부르는 것과 비슷해요.

```elm
type FlexibleNumber
    = Integer Int
    | Float Float
    | Invalid
```

특정 경우의 값을 만들 때는 그 이름(`Spring`)을 그대로 쓰면 돼요. 이름이 같은 모듈 안에 정의되어 있거나 `import SeasonModule exposing (Season(..))` 형태의 문법으로 가져왔을 때 그렇게 해요. `import SeasonModule exposing (Season)` 형태로 가져왔다면 완전히 한정된 이름(`Season.Spring`)을 써요.

```elm
integerTwo = Integer 2
invalid = FlexibleNumber.Invalid
```

사용자 정의 타입은 Elm의 모든 것과 마찬가지로 _구조적 동등성_을 가져요. 즉, 같은 경우이고 같은 (선택적) 데이터를 가진 두 값은 서로 같아요.

사용자 정의 타입을 다룰 때 가장 권장되는 방법은 [패턴 매칭][pattern-matching]이에요:

```elm
let describe flexibleNumber =
    case flexibleNumber of
        Integer i ->
            "Integer: " ++ fromInt(i)

        Float f ->
            "Float: " ++ fromFloat(f)

        Invalid   ->
            "Invalid"
```
