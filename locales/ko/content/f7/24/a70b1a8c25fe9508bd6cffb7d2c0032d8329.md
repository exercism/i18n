# 소개

## JavaScript의 정규 표현식

[정규 표현식][mdn-regular-expressions](또는 Regex)은 문자열에서 특정 요소를 찾아 조작할 때 사용할 수 있는 문자들의 나열이에요. 그래서 다음과 같은 일을 할 수 있어요:

- 문자열에서 텍스트를 **검색**하기
- 문자열에서 부분 문자열 **바꾸기**
- 문자열에서 정보 **추출**하기

> 💡 JavaScript의 정규식 문법은 이 언어의 ECMA-262 표준에 포함되어 있어요. 따라서 브라우저별 호환성을 걱정할 필요가 없어요.

## 정규 표현식을 만드는 방법

JavaScript에서 정규 표현식은 주로 `/pattern/modifiers` 형식으로 작성해요.

정규 표현식을 만드는 방법은 두 가지가 있어요:

1. **정규 표현식 리터럴**:

```javascript
const regex = /[a-z]/;
```

2. 생성자 **RegExp**:

```javascript
const regex = new RegExp('[a-z]');
```

두 경우 모두 JavaScript는 정규식으로 객체를 만들어요. 기본적으로는 리터럴을 사용한 불변 패턴을 쓰는 것이 좋아요.

RegExp 생성자는 정규식이 바뀌거나 아직 정규식을 모를 때(예를 들어 사용자 입력처럼) 사용할 수 있어요.

## 🏴‍☠️ 플래그

정규 표현식에는 추가 기능을 쓸 수 있게 해 주는 [`flags`][mdn-flags]라는 선택적 초능력이 있어요.

널리 쓰이는 플래그 몇 가지는 이래요:

- `/g` - 전역 검색
- `/i` - 대소문자 무시
- `/m` - 여러 줄 검색

간단한 예시를 볼까요:

```javascript
const re = /home/gi;
const str = 'Home, sweet home.';
const myArray = str.match(re);
console.log(myArray);

// => ["Home", "home"]
```

`g` 문자를 사용하면 문자열에서 가능한 모든 일치를 찾아낼 수 있어요. 이 기능이 없다면 JavaScript는 첫 번째 `Home` 일치만 추출했을 거예요.

대소문자 무시 플래그 `/i`를 사용하면 패턴을 찾을 때 유연하게 대처할 수 있어요. 이렇게 하면 찾는 대상이 `UPPERCASE`든 `lowercase`든 상관없어요.

`RegExp` 생성자를 사용할 때는 플래그를 추가하는 문법이 달라요.

```javascript
let regex = /[a-z]/gi; // literal notation
let regex = new RegExp('[a-z]', 'gi'); // constructor with string pattern as first argument
let regex = new RegExp(/[a-z]/, 'gi'); // constructor with regular expression literal as first argument (Starting with ECMAScript 6)
```

## 가장 흔히 쓰이는 함수

정규 표현식을 JavaScript의 내장 함수와 함께 사용하면 문자열을 조작하고 문자열에서 데이터를 얻는 강력한 방법을 쓸 수 있어요.

다음은 정규식과 함께 가장 흔히 쓰이는 함수들이에요.

### Test

[`test()`][mdn-regex-test]] 메서드는 정규 표현식과 지정된 문자열 사이의 일치를 검색해요. true 또는 false를 반환해요.

```javascript
const str = 'It is difficult to test if you have a virus';
const result = /virus$/.test(str);

console.log(result);

// => true
```

### Match

[`match()`][mdn-regex-match] 메서드를 사용하면, 찾은 일치가 있는지 없는지에 따라 내용이 달라지는 유용한 배열을 얻어요.

이렇게 하면 어떤 문자열에서든 정보를 **검색**하고 **추출**할 수 있어요. 예를 들어:

```javascript
const funnyQuote =
  'If you see someone crying, ask if it is because of their haircut.';
const regex1 = /someone/;
const regex2 = /happy/;

funnyQuote.match(regex1);
// => ["someone", index: 3, input: "If you see someone crying, ask if it is because of their haircut.", groups: undefined]

funnyQuote.match(regex2);
// => null
```

전역 검색 플래그 `/g`가 있으면, 인덱스나 입력값 같은 유용한 정보와 함께 단 하나의 일치만 얻는 대신, 메서드가 배열에 담긴 모든 일치를 반환해요:

```javascript
const funnyQuote =
  'If you see someone crying, ask if it is because of their haircut.';

const regex3 = /if/gi;

funnyQuote.match(regex3);
// => ["If", "if"];
```

### Replace

JavaScript의 [`replace()`][mdn-regex-replace] 메서드를 사용하면 주어진 문자열에서 값을 검색하고, 원하는 새 값으로 바꿀 수 있어요.

```javascript
string.replace(searchValue, newValue);
```

바꿀 대상을 찾는 패턴은 문자열 하나일 수도 있고, 정규 표현식일 수도 있어요.

```javascript
let string = 'I like dogs!';
let result = string.replace('dogs', 'cats');

let string = 'I would love to travel to Japan';
let result = string.replace(/Japan/g, 'Hawaii');
```

게다가 각 값에 추가적인 변경을 가하기 위해 바꿀 값 자리에 함수를 적용할 수도 있어요.

```javascript
let text = 'Say hello to the chatbot.';
let result = text.replace(/chatbot|hello/gi, function (word) {
  return word.toUpperCase();
});

// => "Say HELLO to the CHATBOT"
```

### Split

JavaScript의 [`split()`][mdn-regex-split] 메서드는 정규 표현식으로 문자열을 다루고 조작하는 또 다른 방법을 보여줘요.

이렇게 하면 패턴을 인식해서 주어진 문자열을 나누기 위해 정규식을 사용하게 돼요. 예를 들어 `str.split(/[,.\s]/)`처럼요. 이 패턴은 `separator`로 사용돼요.

```javascript
const str = 'hello,user.how are.you';

const result = str.split(/[,.\s]/);

console.log(result);
// => ['hello', 'user', 'how', 'are', 'you']
```
