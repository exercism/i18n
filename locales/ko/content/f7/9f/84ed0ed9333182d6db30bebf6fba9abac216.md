# 소개

때로는 여러 워드가 상태 하나를 공유해야 할 때가 있어요. 그때마다 스택 효과를 거쳐 값을 넘겨줄 필요는 없어요. Factor의 *동적 변수*는 `SYMBOL:`로 선언하는데, 네임스페이스에 저장된 값에 모든 워드가 접근할 수 있게 해줘요.

```factor
USING: namespaces ;

SYMBOL: counter

0 counter set-global
counter [ 1 + ] change-global
counter get-global .       ! => 1
```

`set-global`과 `get-global`은 전역 네임스페이스에서 동작해요. `set`과 `get`은 *현재* 동적 스코프에서 동작하며, 프로세스 전체에 적용되는 바인딩 대신 스코프가 제한된 바인딩을 원할 때 보통 `with-variable` 블록 안에서 사용해요.

`SYMBOLS: a b c ;`처럼 쓰면 여러 심볼을 한 번에 선언해요.
