# 소개

[Elixir](https://elixir-lang.org/)는 2012년에 처음 공개되었어요. Erlang의 이미 탄탄한 기능을 확장하면서도, 초보자가 접근하고 읽고 테스트하고 작성하기에는 더 쉬워요.

Elixir의 창시자인 José Valim은 [2012년 컨퍼런스 발표](https://vimeo.com/53221562)에서 애플리케이션이 다음과 같은 특성을 갖도록 이 언어를 어떻게 만들었는지 설명해요.

  1. 분산형
  2. 내결함성
  3. 소프트 실시간
  4. 핫 코드 스왑 (서버를 멈추지 않고 새 코드를 도입할 수 있음)

Elixir는 실제로 [바이트코드](https://en.wikipedia.org/wiki/Bytecode)로 컴파일된 다음 [BEAM Erlang 가상 머신](https://codesync.global/media/robert-virding-co-creator-of-erlang-explains-the-beam/)에서 실행돼요.

Erlang을 호출하는 데는 "변환 비용"이 없어요. 즉, Erlang 코드를 Elixir 코드 바로 옆에서 실행할 수 있어요.

함수형 언어인 만큼 Elixir에서는 모든 것이 표현식이에요.

Elixir는 "일급 문서"를 지원해요. 함수에 주석을 붙일 수 있어서 필요할 때 찾아보기가 더 쉬워요.

정규 표현식도 일급으로 다뤄서, 문자열 안에서 어색하게 이스케이프할 필요가 없어요.

Elixir의 비동기 통신 방식 덕분에 코드는 가벼우면서도 대량의 동시성을 처리할 수 있어요.

프로그래머들은 단일 서버 노드에서 수천 개의 요청과 응답을 *동시에* 처리하기 위해 Elixir를 사용해요.

수많은 API를 빠르게 소비하고 제공해야 하는 마이크로서비스에서도 성공적으로 쓰여 왔어요.

[Phoenix 프레임워크](https://www.phoenixframework.org/)는 웹을 위한 Elixir 애플리케이션 구조를 잡는 데 도움을 줘요.
