# 힌트

## 1. 팩맨이 유령을 먹을 수 있는지 정의하기

* 함수는 불리언 값을 반환해야 해요.
* 논리 연산자 `and`를 사용해 인자들을 조합해 결과를 낼 수 있어요.

## 2. 팩맨이 점수를 얻는지 정의하기

* 함수는 불리언 값을 반환해야 해요.
* 불리언 연산자 `or`를 사용해 인자들을 조합해 결과를 낼 수 있어요.

## 3. 팩맨이 지는지 정의하기

* 함수는 불리언 값을 반환해야 해요.
* 불리언 연산자 `and`와 `not`을 사용해 인자들을 조합해 결과를 낼 수 있어요.

## 4. 팩맨이 이기는지 정의하기

* 함수는 불리언 값을 반환해야 해요.
* 불리언 연산자 `and`와 `not`을 사용해 인자들과 이전에 구현한 함수 중 하나의 결과를 조합할 수 있어요.
