# 소개

C#의 [`enum` 타입](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/builtin-types/enum)은 이름이 붙은 상수들의 고정된 집합(열거형)을 나타내요.

일반적으로 `enum` 멤버는 그 이름 있는 상수 중 정확히 하나만 가리킬 수 있어요. 하지만 때로는 상수 하나 이상을 가리키는 게 유용할 때도 있어요. 이럴 때는 `enum`에 [`Flags` 특성](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute)을 붙이면 돼요.

플래그 enum은 다음과 같이 정의할 수 있어요 (`0b` 이진 정수 표기법을 사용해요):

```csharp
[Flags]
enum PhoneFeatures
{
    Call = 0b00000001,
    Text = 0b00000010
}
```

값이 `0b00000011`인 `PhoneFeatures` 인스턴스는 `Call` 플래그와 `Text` 플래그가 _모두_ 설정되어 있어요.

기본적으로 `enum` 멤버 값에는 `int` 타입이 사용돼요. `enum` 선언에서 타입을 지정하면 다른 정수 타입을 사용할 수 있어요:

```csharp
[Flags]
enum PhoneFeatures : byte
{
    Call = 0b00000001,
    Text = 0b00000010
}
```
