# 개요

Swift의 [클로저][closures]는 독립된 코드 블록으로, 매개변수를 전달해 계산을 실행하고 값을 반환할 수 있어요.
클로저는 또한 주변 환경에서 값을 캡처해서 계산에 사용하기도 해요.
스스로 완결되어 있기 때문에, 다른 값들처럼 프로그램 안에서 여기저기 전달되거나 상수와 변수에 할당될 수 있어요.

클로저는 Swift의 함수와 꽤 비슷하게 들릴 수 있어요. 실제로 비슷하고, 그럴 만한 이유도 있어요.
Swift의 함수는 이름이 있어야 하고 조금 다른 문법으로 정의되는 특별한 클로저예요.

Swift의 함수도 엄밀히 말하면 클로저지만, 사람들이 Swift에서 "클로저"라고 할 때는 보통 [클로저 표현식][closure-expressions]을 가리켜요.
클로저 표현식은 매개변수 목록, 반환 타입, `in` 키워드, 그리고 클로저의 본문 순서로 쓰고, 전체를 중괄호 한 쌍으로 감싸요:

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}
```

이 코드는 `(Double, Double) -> Double` 타입의 클로저 표현식을 정의해요. 그리고 이 타입의 함수와 비슷한 방식으로, 알맞은 타입의 매개변수에 적용해서 실행할 수 있어요:

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}(10.0, 15.0)
// returns 12.5
```

클로저를 실행할 때마다 전체 클로저 표현식을 매번 써 주는 건 그리 편리하지 않아요. 그래서 클로저는 Swift의 다른 값들처럼 이름에 할당할 수 있어요.
그러면 이름에 매개변수를 적용하는 방식으로 호출할 수 있어요:

```swift
let mean = { (a: Double, b: Double) -> Double in
  (a + b) / 2.0
}

mean(13.0, 100.0)
// returns 56.5
```

위에서 봤듯이, 클로저도 일반 함수처럼 본문이 하나의 표현식이면 `return` 키워드를 생략할 수 있어요.

클로저는 주로 고차 함수와 함께 사용되는데, 매개변수로 전달되거나 결과로 반환되기도 해요:

```swift
[11, 75, 3, 99, 53].contains(where: { (x: Int) -> Bool in x > 100 })
// returns false

["apple", "ball", "carrot"].sorted(by: { (s1: String, s2: String) -> Bool in s1.count < s2.count })
// returns ["ball", "apple", "carrot"]

func makeAdder(base: Int) -> (Int) -> Int {
  { (x: Int) -> Int in base + x }
}
```
