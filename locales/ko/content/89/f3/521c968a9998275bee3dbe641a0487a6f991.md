# 조건문에 대해

## 비교 연산자

[비교 연산자][operators]는 다른 많은 언어와 비슷하지만, 몇 가지 확장된 부분이 있어요.

같음을 비교할 때는 `==`(같음)와 `!=`(같지 않음) 연산자를 사용해요.

```Kotlin
val txt = "abc"
txt == "abc" // => true
txt != "abc" // => false
```

또한 `===`와 `!==` 연산자는 ["참조 동등성"][referential-equality]을 확인해요. `a === b`는 `a`와 `b`가 같은 객체를 가리킬 때만 참이에요. 이 내용은 실러버스 뒷부분에서 더 잘 이해될 거예요.

크다/작다를 비교하는 연산자도 일반적인 방식과 같아요.

```Kotlin
1 < 3 // => true
3 > 3 // => false
3 <= 3 // => true
4 >= 3 // => true
```

## `if`로 분기하기

[`if` 표현식][if-else]의 전체 형태는 다음과 같아요.

```Kotlin
if (conditional1) {
//    something...
} else if (conditional2) {
//    something...
} else {
//    something...
}
```

- 각 조건식은 괄호 `()`로 감싸야 해요.
- 조건식은 불리언 `true` 또는 `false`로 평가되어야 해요.
  Kotlin에는 다른 언어에서 볼 수 있는 "truthy"와 "falsy" 개념이 없어요.
- 식이 하나뿐이라면 중괄호 `{}`는 생략할 수 있어요.
- `else if`와 `else`는 모두 선택 사항이고, `else if` 블록은 여러 개를 쓸 수 있어요.

`if` 표현식으로 값을 고를 수도 있어요.

```Kotlin
val number = 100000
val description = if (number > 100) "number is over 100" else "number is less than 100"
// => description = "number is over 100"
```

## 대안은 없을까요?

Kotlin은 Java에 있는 삼항 연산자 `? :`를 의도적으로 _넣지 않았어요_.
대신 간결한 `if ... else` 형태를 선호해요.

```Kotlin
val result = if (isOk) goodValue else badValue

return if (isOK) goodValue else badValue
```

Ruby와 달리, 간결한 `if ... else` 형태는 *항상* `else`가 필요하므로, 조건만 확인하고 빠져나가는 가드 문으로는 쓸 수 없어요.

```kotlin
return 42 if (isOk)
// Syntax error: Unexpected tokens (use ';' to separate expressions on the same line).
// Syntax error: Expecting an expression.

return if (isOk) true
// 'if' must have both main and 'else' branches when used as an expression.
```

Kotlin에서 `if`는 값을 반환하는 [_표현식_][expression]이라는 점에 주목해요.
Java에서처럼 [_문_][statement]이 아니에요.

Kotlin에는 강력한 [`when`][when] 구문이 있어서, 길게 이어지는 `else if` 절을 패턴 매칭으로 대체할 수 있어요. 이 구문은 나중에 배우는 개념에서 살펴봐요.
