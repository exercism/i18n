# 지침 추가

## Tcl `apply` 명령

테스트 케이스가 혼란스러워 보일 수 있어요.
다음을 구현해야 해요: 

```tcl
set myList {alpha beta gamma delta}
listOps::filter $myList {{word} {expr {[string length $word] == 4}}
```

그 마지막 인자에는 왜 이렇게 중괄호가 많을까요?

`proc` 명령이 어떻게 정의되는지 떠올려 봐요:

```tcl
proc procName argList body
```

Tcl에는 `apply` 명령이 있어요:

```tcl
apply func ?arg1 arg2 ...?
```

여기서 "func"는 본질적으로 익명 프로시저(또는 "람다")인 두 원소짜리 리스트 `{argList body}`예요.
`apply` 명령은 그 익명 프로시저를 호출하면서 필요한 인자들을 전달해요.

예를 들어, 다음은 서로 같아요:

```tcl
# using proc
proc myReverse {str} {return [string reverse $str]}
puts [myReverse "Hello, World!"]

# using apply
puts [apply {{str} {string reverse $str}} "Hello, World!"]

# or, store the func in a variable
set func {{str} {string reverse $str}}
puts [apply $func "Hello, World!"]
```

`apply`를 사용하면 코드 블록을 주고받기가 더 간단해져요.

참고: [`apply`](https://tcl.tk/man/tcl8.6/TclCmd/apply.htm), [`proc`](https://tcl.tk/man/tcl8.6/TclCmd/proc.htm).
