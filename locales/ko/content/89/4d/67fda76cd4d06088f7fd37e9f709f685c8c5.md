# 힌트

## 일반

- Roc에서는 레코드 업데이트 문법이 대부분의 사용 사례를 잘 처리해 주기 때문에 렌즈를 많이 쓰지는 않아요.
  예를 들어, 다음과 같은 중첩 레코드가 있다고 해봐요:

  ```roc
  bob = { hair: { color: Brown, length: Long }, mouth: Smiling, height: 6.0 }
  ```

  이제 Bob의 머리를 잘라 볼까요:

  ```roc
  new_bob = { ..bob, hair: { ..bob.hair, length: Short } }
  ```

  렌즈가 필요 없어요!

- 그렇긴 해도 렌즈는 Roc에서는 드물지만 Haskell이나 Scala 같은 다른 언어에서는 흔히 쓰이기 때문에, Roc에서는 렌즈를 어떻게 구현할 수 있을지 궁금할 수 있어요.
  매개변수화된 타입이나 함수를 담은 레코드처럼 Roc의 고급 기능을 연습하기에도 좋은 방법이에요.
  실제로 Roc에서 렌즈를 표현하는 한 가지 방법은 다음과 같아요:

  ```roc
  Lens(whole, part) := {
      get : whole -> part,
      set : whole, part -> whole,
  }
  ```

  이것은 매개변수화된 타입이에요. `whole`과 `part`는 어떤 타입이든 될 수 있어요.
  `whole`은 보통 레코드이고, `part`는 어떤 필드 타입이든 될 수 있어요.
  `get` 필드에는 주어진 `whole`에서 특정 `part`를 반환하는 함수가 들어 있고, `set` 필드에는 주어진 `whole`의 복사본을 반환하되 특정 `part`를 주어진 `part`로 바꾼 함수가 들어 있어요.

  예를 들어, 사람의 머리카락을 가져오거나 설정하는 렌즈는 다음과 같아요:

  ```roc
  hair_lens = {
      get: |person| person.hair,
      set: |person, hair| { ..person, hair },
  }
  ```

  이 렌즈를 사용하면 다음과 같이 Bob의 머리카락에 초점을 맞출 수 있어요:

  ```roc
  bob_hair = bob |> hair_lens.get
  ```

  머리카락을 바꾸는 것도 다음과 같이 할 수 있어요:

  ```roc
  new_hair = { ..bob.hair, length: Short }
  new_bob = bob |> (hair_lens.set)(new_hair)
  ```

- 참고: `hair_lens.set`을 감싼 괄호는 꼭 필요해요. 괄호가 없으면 Roc는 `hair_lens`의 타입에서 `set`이라는 이름의 함수를 찾아요.

- 렌즈는 조합하기 시작하면 특히 유용해져요. 깊이 중첩된 부분도 가져오고 설정할 수 있게 해 주거든요.
  다음과 같은 함수를 구현하면 할 수 있어요:

  ```roc
  compose : Lens(outer, inner), Lens(inner, part) -> Lens(outer, part)
  ```

  이 함수를 구현하고 나면, 다음과 같이 머리카락 길이 렌즈를 만들 수 있어요:

  ```roc
  length_lens = {
      get: |hair| hair.length,
      set: |hair, length| { ..hair, length },
  }
  hair_length_lens = compose(hair_lens, length_lens)

  ```

  이제 Bob의 머리를 한 번 더 잘라 볼 수 있어요:

  ```roc
  set_hair_length = hair_length_lens.set
  new_bob = bob |> set_hair_length(Short)
  ```

- 중첩된 부분에 어떤 변환이든 적용할 수 있는 함수를 구현하고 싶을 수도 있어요:

  ```roc
  over : Lens(whole, part), whole, (part -> part) -> whole
  ```

  구현하고 나면 `over`를 다음과 같이 사용할 수 있어요:

  ```roc
  cut_hair = |current_length| match current_length {
      Long => Short
      Short => Bald
      Bald => Bald
  }
  new_bob = hair_length_lens |> over(bob, cut_hair)
  ```

- 먼저 Roc의 레코드 업데이트 문법으로 테스트를 통과한 다음, 렌즈를 사용해 보는 것을 추천해요.
