# 소개

JavaScript에서 배열은 길이가 고정되지 않은 리스트 형태의 구조로, 원시 값이나 객체를 가리지 않고 담을 수 있으며 타입이 섞여 있어도 됩니다.

배열을 만들려면 대괄호 `[]` 사이에 원소를 넣어요.
배열에서 값을 읽으려면 식별자 뒤에 대괄호 `[]`를 붙이고 그 안에 인덱스를 넣어요.
배열의 인덱스는 0부터 시작해요.

예를 들어 볼까요?

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[2];
// => 3
```

배열에 들어 있는 원소의 개수를 알아내려면 `length` 속성을 사용해요.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.length;
// => 4
```

배열의 원소를 바꾸려면 해당 인덱스에 값을 대입해요.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[0] = 'one';
numbers;
// => ['one', 'two', 3, 'four']
```

## 메서드

모든 Array 객체에서 사용할 수 있는 [메서드][array_methods] 중 일부는 배열에 원소를 추가하거나 제거하는 데 쓸 수 있어요.

### push

> `push()` 메서드는 배열의 끝에 원소를 하나 이상 추가하고, 배열의 새로운 길이를 반환해요.[^1]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.push(5); // => 5
numbers;
// => [1, 'two', 3, 'four', 5]
```

### pop

> `pop()` 메서드는 배열의 마지막 원소를 제거하고 그 원소를 반환해요.
> 이 메서드는 배열의 길이를 바꿔요.[^2]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.pop(); // => four
numbers;
// => [1, 'two', 3]
```

### shift

> `shift()` 메서드는 배열의 첫 번째 원소를 제거하고, 제거한 원소를 반환해요.
> 이 메서드는 배열의 길이를 바꿔요.[^3]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.shift(); // => 1
numbers;
// => ['two', 3, 'four']
```

### unshift

> unshift() 메서드는 배열의 맨 앞에 원소를 하나 이상 추가하고, 배열의 새로운 길이를 반환해요.[^4]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.unshift('one'); // => 5
numbers;
// => ['one', 1, 'two', 3, 'four']
```

### splice

> splice() 메서드는 기존 원소를 제거하거나 교체하고 새로운 원소를 추가하는 방식으로 배열의 내용을 바꿔요. 이 메서드는 삭제된 원소를 담은 배열을 반환해요.[^5]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.splice(2, 1, 'one'); // => [3]
numbers;
// => [1, 'two', 'one', 'four']
```
