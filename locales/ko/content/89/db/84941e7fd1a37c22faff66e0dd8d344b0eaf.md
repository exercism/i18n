# 안내

PHP의 [타입 선언][type-declaration] 문서를 살펴봐요.

## 1. Address 클래스의 타입을 문서화해요

- PHP에서 원시 값에 대한 타입 지정은 이름과 같아요. [타입 소개][type-intro]를 참고해요.

## 2. 빈 값으로 양식을 채울 때 쓸 타입을 문서화해요

- PHP에서 원시 값에 대한 타입 지정은 이름과 같아요. [타입 소개][type-intro]를 참고해요.

## 3. 값을 개별 문자로 나눌 때의 타입을 문서화해요

- PHP에서 원시 값에 대한 타입 지정은 이름과 같아요. [타입 소개][type-intro]를 참고해요.

## 4. 값이 양식에 들어가는지 확인할 때의 타입을 문서화해요

- PHP에서 원시 값에 대한 타입 지정은 이름과 같아요. [타입 소개][type-intro]를 참고해요.

## 5. 양식에서 주소를 포맷팅할 때의 타입을 문서화해요

- PHP에서 클래스의 타입 선언에는 `object`나 특정 클래스 이름을 선언된 타입으로 사용할 수 있어요.
