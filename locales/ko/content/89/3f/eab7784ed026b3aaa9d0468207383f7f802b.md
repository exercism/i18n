# 지침

마술사 지망생 Elyse는 기초를 좀 연습할 필요가 있어요.
Elyse에게는 조작하고 싶은 카드 더미가 하나 있어요.

좀 더 쉽게 하기 위해 Elyse는 1부터 10까지의 카드만 사용해서, 카드 더미를 숫자 벡터로 나타낼 수 있어요.
특정 카드의 위치는 벡터의 인덱스에 해당해요.

## 1. 카드 더미에서 카드 가져오기

카드를 한 장 고르려면, 주어진 카드 더미에서 인덱스 `position`에 있는 카드를 반환해요.

```julia-repl
julia> stack = [1, 2, 4, 1];
julia> position = 3;
julia> get_item(stack, position)
4
```

## 2. 카드 더미의 카드 교체하기

손기술을 좀 부려서 인덱스 `position`에 있는 카드를 주어진 대체 카드와 교환해요.
변경된 카드 더미를 반환해요.

```julia-repl
julia> stack = [1, 2, 4, 1];
julia> position = 3;
julia> replacement_card = 6;
julia> set_item!(stack, position, replacement_card)
[1, 2, 6, 1]
```

## 3. 카드 더미 맨 위에 카드 넣기

카드 더미 맨 위에 새 카드를 넣어서 카드 한 장을 나타나게 해요.
변경된 카드 더미를 반환해요.

```julia-repl
julia> stack = [5, 9, 7, 1];
julia> new_card = 8;
julia> insert_item_at_top!(stack, new_card)
[5, 9, 7, 1, 8]
```

## 4. 카드 더미에서 카드 제거하기

카드 더미에서 주어진 `position`에 있는 카드를 제거해서 카드 한 장을 사라지게 해요.
변경된 카드 더미를 반환해요.

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> position = 3;
julia> remove_item!(stack, position)
[3, 2, 4, 8]
```

## 5. 카드 더미 맨 위의 카드 제거하기

카드 더미 맨 위에 있는 카드를 제거해서 카드 한 장을 사라지게 해요.
변경된 카드 더미를 반환해요.

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> remove_item_from_top!(stack)
[3, 2, 6, 4]
```

## 6. 카드 더미 맨 아래에 카드 넣기

카드 더미 맨 아래에 새 카드를 넣어서 카드 한 장을 나타나게 해요.
변경된 카드 더미를 반환해요.

```julia-repl
julia> stack = [5, 9, 7, 1];
julia> new_card = 8;
julia> insert_item_at_bottom!(stack, new_card)
[8, 5, 9, 7, 1]
```

## 7. 카드 더미 맨 아래의 카드 제거하기

카드 더미 맨 아래에 있는 카드를 제거해서 카드 한 장을 사라지게 해요.
변경된 카드 더미를 반환해요.

```julia-repl
julia> stack = [8, 5, 9, 7, 1];
julia> remove_item_at_bottom!(stack)
[5, 9, 7, 1]
```

## 8. 카드 더미의 크기 확인하기

카드 더미의 크기가 `stack_size`와 같은지 확인해요.

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> stack_size = 4;
julia> check_size_of_stack(stack, stack_size)
false
```
