# 자세히 알아보기

*서로소 집합*(유니온 파인드 구조)은 값들을 서로 겹치지 않는 그룹으로 나눠 관리하면서, 한 가지 질문에 빠르게 답해요. 두 값이 같은 그룹에 있나요? 이 구조는 [`disjoint-sets`][disjoint-sets] vocabulary에 들어 있어요.

`<disjoint-set>`은 빈 구조를 만들어요. 값, 즉 *원소*는 `add-atom`으로 하나씩 추가하거나 `add-atoms`로 한꺼번에 추가해요. 추가된 원소는 각각 자기만의 그룹에서 시작해요.

```
<disjoint-set> ( -- disjoint-set )
add-atom       ( atom disjoint-set -- )
add-atoms      ( seq disjoint-set -- )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ "a" "b" "c" "d" } over add-atoms   ! four singleton groups
```

`equate`는 두 원소가 속한 그룹을 하나로 합쳐요. 합치는 연산은 전이적이에요. `a`를 `b`와 합치고 `b`를 `c`와 합치면, 세 원소가 모두 같은 그룹을 공유하게 돼요.

```
equate ( atom1 atom2 disjoint-set -- )
```

각 그룹은 구성원 중 하나인 *대표 원소*로 식별돼요. `representative`는 그 대표 원소를 돌려주고, 두 원소는 대표 원소가 같을 때 정확히 같은 그룹에 속해요. `equiv?`로 이 비교를 바로 할 수 있어요.

```
representative ( atom disjoint-set -- representative )
equiv?         ( atom1 atom2 disjoint-set -- ? )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ "a" "b" "c" "d" } over add-atoms
"a" "b" pick equate
"b" "c" pick equate
"a" "c" pick equiv? .          ! => t   (transitively connected)
"a" "d" pick equiv? .          ! => f
"a" over representative
"c" pick representative = .     ! => t   (same representative)
```

어떤 원소가 그룹의 대표로 뽑히는지는 내부적인 세부 사항이에요. 그룹의 구성원 중 아무나 대표가 될 수 있고, 그룹이 합쳐지면서 대표가 바뀔 수도 있어요. 특정 원소가 대표일 거라고 기대하면 안 돼요. 같은 그룹에 있는 두 원소가 같은 대표를 가리킨다는 점만 믿으면 돼요.

`disjoint-set-members`는 추가된 모든 원소를 돌려줘요.

이 구조는 *가변*이에요. `equate`와 `add-atom`은 새로운 서로소 집합을 돌려주는 대신 기존 구조를 그 자리에서 바꿔요. 구현은 랭크를 기준으로 합치면서 경로를 압축하는 방식을 써서, `equate`와 `representative`를 오래 연달아 호출해도 각 호출이 사실상 상수 시간에 끝나요.
