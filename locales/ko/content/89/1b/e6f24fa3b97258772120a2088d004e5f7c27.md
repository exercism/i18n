# 테스트

OCaml은 컴파일 언어이기 때문에 테스트를 실행하기 전에 제출한 코드와 테스트 코드를 먼저 컴파일해야 해요.
빌드에는 [`dune`](https://dune.build/)을 사용해요.
각 폴더에는 빌드 방법을 지정하는 dune 파일이 있고, dune에 작업을 위임하는 Makefile도 있어요.

테스트를 컴파일하고 실행하려면 연습 문제 폴더에서 다음을 입력하기만 하면 돼요:

```bash
make
```
