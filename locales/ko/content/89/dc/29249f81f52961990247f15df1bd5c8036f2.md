# 문자열

문자열은 따옴표로 감싼 일련의 문자예요.
작은따옴표와 큰따옴표를 모두 지원해요.

```php
<?php

$where = "Spain";
$what = 'rain';
```

## 문자열 변수 확장

큰따옴표 문자열 안에서 스코프에 있는 변수를 참조하면, 그 값이 문자열에 삽입돼요.

```php
<?php

$answer = 42;
$expanded = "The answer to life, the universe, and everything is $answer"; 
```

## 문자 인코딩 지원

예전에는 PHP의 문자열 함수가 ASCII 문자만 지원했고, 최신 유니코드 인코딩은 지원하지 않았어요.
ASCII 문자는 각각 1바이트인 반면, 유니코드 문자는 길이가 1~4바이트일 수 있어요.
유니코드 문자열을 안전하게 다뤄야 한다면, 기존 함수의 [멀티바이트 버전][multi-byte-fns]을 참고해요.

```php
<?php

$byte_length = strlen('😃'); // => 4
$string_length = mb_strlen('😃'); // => 1
```

[multi-byte-fns]: https://www.php.net/manual/en/ref.mbstring.php
