# 소개

## 모듈

지금까지 봐 온 모든 연습 문제는 클래스를 사용했어요.
때로는 상태를 가진 객체를 만드는 오버헤드가 필요하지 않아서, 대신 `module`을 사용해요.

모듈은 클래스와 아주 비슷해요. 실제로 객체 계층 구조에서 `Module`은 `Class`의 부모예요. 가장 큰 차이는 인스턴스 메서드 대신 클래스 메서드를 사용한다는 점이에요.
클래스 메서드는 `self.`로 시작하고, 모듈에서 직접 호출해요.

예를 들어요:

```ruby
module Speaker
  def self.echo(something)
    "#{something} ... #{something}"
  end
end

Speaker.echo("Hello")   #=> "Hello ... Hello"
```

## 루프

Ruby에서 루프를 작성하는 방법은 여러 가지가 있는데, 일반적으로 반복보다는 열거를 사용하는 편이라 가장 흔히 보게 되는 루프는 아마 `while`문일 거예요:

```ruby
counter = 0

while counter < 5
  counter += 1
end
```

그 형제 격인 `until`문도 사용할 수 있어요:

```ruby
counter = 0

until counter == 5
  counter += 1
end
```
