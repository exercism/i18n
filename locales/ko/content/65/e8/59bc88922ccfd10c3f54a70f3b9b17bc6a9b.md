# 소개

클래스는 F#에서 객체 지향 프로그래밍을 하기 위한 핵심 구성 요소예요.

F#의 클래스는 필드와 메서드로 이루어져 있어요. 클래스의 필드와 메서드를 _멤버_라고 해요.

F#에서 클래스는 `type` 키워드로 정의해요. 메서드는 `member` 키워드로 정의하며, 항상 공개 상태예요. (비공개) 필드를 정의하려면 `let` 바인딩을 사용할 수 있어요.

```fsharp
type Shoe() =
    let size = 8

    member this.Describe() = $"This is a size {size} shoe"
```

클래스는 객체를 만들기 위한 템플릿이에요. 클래스의 인스턴스를 만들려면 클래스 이름을 함수처럼 호출해요. 클래스의 인스턴스를 _객체_라고도 해요.

점 표기법을 사용하면 객체의 멤버에 접근할 수 있어요.

```fsharp
let myShoe = Shoe()
myShoe.Describe()
// => "This is a size 8 shoe"
```
