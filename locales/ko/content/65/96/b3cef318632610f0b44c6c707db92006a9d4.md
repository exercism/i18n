# 소개

`:` 정의는 자기 자신을 직접 호출할 수 있어요. Factor의 컴파일러는 재귀 워드의 스택 효과도 다른 워드들과 똑같이 추론해요. 순수한 재귀에는 특별한 선언이 필요하지 않아요.

```factor
: total ( seq -- sum )
    [ 0 ] [ unclip swap total + ] if-empty ;

{ 4 0 9 0 5 } total .    ! => 18
```

이 두 부분은 각각 재귀의 *기저 사례*(여기서는 빈 시퀀스의 합이 `0`이에요)와 *재귀 단계*(원소 하나를 떼어 내고, 나머지에 대해 재귀 호출하고, 결과를 결합해요)예요.

`if-empty`와 `unclip`은 시퀀스 재귀의 대표적인 짝이에요. `if-empty ( seq emptyquot nonemptyquot -- )`는 시퀀스에 따라 두 쿼테이션 중 하나를 실행해요. `unclip`은 첫 번째 원소를 떼어 내서 재귀 단계가 더 단순한 대상으로 시작할 수 있게 해줘요.
