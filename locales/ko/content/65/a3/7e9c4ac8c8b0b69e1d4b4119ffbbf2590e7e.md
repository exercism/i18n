# 소개

Gleam에서는 `case` 표현식을 사용해 조건부로 코드를 실행할 수 있어요. `case` 표현식에서는 값을 하나 이상의 _패턴_과 비교할 수 있는데, 이런 패턴의 한 예가 값을 리터럴 값(예: `1` 또는 `"hello"`)과 일치시키는 _리터럴 패턴_이에요.

`case` 표현식은 `case` 키워드로 작성해요:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    1 -> "One"
  }
}
```

다른 언어의 `switch` 문과 비슷해 보일 수 있지만, 패턴 매칭은 다른 패턴들도 함께 사용할 때 진가를 발휘해요. 그런 패턴 중 하나가 값을 변수에 대입할 수 있게 해주는 _변수 패턴_이에요. 이 예제에서는 `number`가 `0`이 아니면 변수 `i`에 `number`의 값이 대입돼요:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i -> "Non zero"
  }
}
```

경우에 따라 패턴에 조건을 하나 더 추가하고 싶을 수 있어요. 이를 _가드_(절)라고 하며, `if` 키워드로 추가할 수 있어요:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
  }
}
```

성능상의 이유로 가드에는 기본적인 수학 연산자와 불리언 연산자만 사용할 수 있고, 다른 함수는 가드 안에서 사용할 수 없어요.

위 예제에서는 가능한 모든 입력에 일치하는 패턴이 있는 것은 아니에요. 컴파일러가 이를 감지해 오류를 출력하는데, 이것을 _완전성 검사_라고 해요. 이 경고를 해결하려면 모든 경우를 처리해야 해요. 이때 어떤 값과도 일치하는 _무시 패턴_을 사용할 수 있어요:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
    _ -> "Positive number"
  }
}

// No compiler error
```

case 표현식은 위에서 아래로 각 패턴에 대해 값을 검사하고, 일치하는 패턴을 찾으면 그 패턴에 연결된 로직을 실행해요. 패턴의 순서가 중요해요!
