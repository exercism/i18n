# GitHub으로 기여하기

Exercism 코드베이스에 대한 기여는 [GitHub][github]를 통해 이루어져요.

이름에서 알 수 있듯이, GitHub는 버전 관리 시스템으로 [git][git]을 사용해요. Git이 익숙하지 않다면 [Pro Git][pro-git]이 가장 좋은 온라인 자료예요.

GitHub와 기여 워크플로가 익숙하지 않다면, 시작하는 데 도움이 될 자료들을 소개할게요:

- [GitHub 입문 - 인터랙티브 코스][github-course]
- [GitHub에서 풀 리퀘스트 만드는 방법 - 튜토리얼][pr-tutorial]
- [간단한 GitHub PR 만드는 방법 - anthonywritescode의 영상][anthonywritescode]

## 가이드

기여가 환영받도록 하는 방법은 [좋은 풀 리퀘스트 만들기][great-pr] 가이드에서 더 자세히 확인할 수 있어요.

Exercism만의 풀 리퀘스트 가이드도 여러 개 있어요:

- [좋은 풀 리퀘스트 만들기][how-to-make-a-great-pr]
- [기여자를 위한 풀 리퀘스트 가이드][contributors-pr-guide]
- [메인테이너를 위한 풀 리퀘스트 가이드][maintainers-pr-guide]
- [메인테이너 저장소 권한][maintainers-repo-permissions]
