# 개요

타입 정의는 새로운 이름이 붙은 타입을 만들어요. 이 타입은 기반 타입이 같더라도 다른 모든 타입과 구별돼요.

## 타입 정의하기

타입 정의는 `type` 키워드로 시작하고, 그 뒤에 새 타입의 이름과 기반 타입이 와요:

```go
type File []bool
```

여기서 `File`은 체스판의 세로줄 하나를 가리켜요. 보통 A부터 H까지 이름이 붙죠.
이 세로줄의 각 칸은 그 칸이 점유되었는지 아닌지를 나타내는 불리언 값으로 표현해요.
이제 `File`을 정의했으니 다른 정의 안에서도 사용할 수 있어요:

```go
type Chessboard map[string]File

board := Chessboard{
    "A": File{true, false, true},
    "B": File{false, true, false},
}
```

`Chessboard`는 세로줄 식별자를 `File` 값에 대응시켜요.
각 `File`은 체스의 한 세로줄에 있는 칸들을 나타내는 불리언 슬라이스예요.
이런 타입 정의가 없다면 `board`는 `map[string][]bool`이 되어서, 무엇을 나타내는지 이해하기 어려워져요.

## 정의된 타입은 서로 달라요

`Score`와 `int`는 둘 다 정수 값을 담지만, 서로 변환하려면 명시적 변환이 필요해요:

```go
type Score int

var number int = 42

// var score Score = number is a compile error
var score Score = Score(number)
var converted int = int(score)
```

`42`는 타입이 없는 상수라서 `Score` 변수에 바로 대입할 수 있어요.

정의된 타입은 메서드도 가질 수 있는데, 이 내용은 메서드 개념에서 다뤄요.

## 구조체 타입

구조체 정의도 같은 `type` 키워드를 사용해요:

```go
type Player struct {
    Name  string
    Score Score
}
```

구조체 타입은 구조체 개념에서 다뤄요.

## 타입 별칭

타입 별칭은 새로운 타입을 만드는 대신 기존 타입에 또 다른 이름을 붙여요.
별칭과 원래 타입은 동일하기 때문에, 두 타입의 값은 서로 바꿔 쓸 수 있어요.
별칭은 `type` 키워드, 별칭 이름, 등호(`=`), 그리고 기존 타입을 사용해서 선언해요.

```go
type Square = bool

var isOccupied bool = true
var square Square = isOccupied // no conversion needed
```
