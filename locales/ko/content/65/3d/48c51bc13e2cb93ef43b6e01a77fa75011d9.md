# 학습

Groovy를 시작해 보고 싶거나, 연습 문제를 풀면서 더 배우고 싶나요?

다음 방법으로 Groovy를 사용해 봐요.

* [온라인 인터프리터를 사용하는 브라우저](https://www.jdoodle.com/execute-groovy-online)
* 명령줄에서 `groovyConsole`을 입력해 실행하는 [Groovy Console](http://groovy-lang.org/groovyconsole.html)
* 명령줄에서 `groovysh`를 입력해 실행하는 [Groovy Shell](http://groovy-lang.org/groovyconsole.html)

다음 자료로 Groovy를 빠르게 둘러봐요.

* Tim Rows의 [Groovy Tutorial for Java Developers](https://www.timroes.de/2015/06/27/groovy-tutorial-for-java-developers/)는 Java 개발자가 아니어도 똑같이 좋아요.
* [Learn X in Y minutes, Where X=Groovy ](https://learnxinyminutes.com/docs/groovy/)
* SmartThings의 [Groovy Basics](http://docs.smartthings.com/en/latest/getting-started/groovy-basics.html)
* JDriven의 [online Groovy Koans](http://www.groovy-koans.org/) 몇 개

더 깊이 파고들려면

* [Groovy Documentation](http://www.groovy-lang.org/documentation.html)
* [Groovy In Action](https://www.manning.com/books/groovy-in-action-second-edition), Groovy에 관한 _최고의 책_
* Ken Kousen의 [Making Java Groovy](https://www.manning.com/books/making-java-groovy)
