# 소개

이보다 더 표현력이 뛰어난 프로그래밍 언어를 찾기는 어려울지도 몰라요. [Raku](https://raku.org/)는 현대적인 다중 패러다임 언어예요. Raku는 [절차적](https://docs.raku.org/language/functions), [객체 지향](https://docs.raku.org/language/objects), [함수형 프로그래밍](https://docs.raku.org/language/functions#Functions_are_first-class_objects) 방법론을 제공해요.

[궁금하신가요?](https://raku.org/) [문서](https://docs.raku.org/)나 모듈 [저장소](https://raku.land/)(pypi나 CPAN 같은 곳)에서 더 깊이 알아봐요.

Raku는 무척 [유연한](https://docs.raku.org/language/operators) 언어라서, 시스템 관리자를 위한 짧은 [한 줄 프로그램](https://docs.raku.org/language/create-cli)이든, 데이터베이스 가져오기를 관리하는 스크립트든, [웹사이트 전체](https://cro.services/)를 구현하는 데 필요한 모듈 스택 전체든, 어떤 프로그래밍 스타일에도 [맞춰](https://docs.raku.org/language/glossary#gradual_typing) 줘요.

Raku는 다른 언어들로부터 배워요:

* [역할](https://docs.raku.org/language/typesystem#role), [스레딩](https://docs.raku.org/language/concurrency), [다중 메서드](https://docs.raku.org/language/glossary#Multi-dispatch) 디스패치를 갖춘 제대로 된 객체 시스템으로 Perl의 오랜 매력을 더욱 높여 줘요.
* Java에서 스레딩을 가져와 [몇 안 되는 메서드로 단순화](https://docs.raku.org/language/concurrency)했어요.
* Lisp의 [외부 함수 인터페이스](https://docs.raku.org/language/nativecall)를 사용하면, 라이브러리에 접근하는 일이 코드 한 줄만큼 간단해져요.
* [정규 표현식](https://docs.raku.org/language/regexes)은 이제 훨씬 더 강력해졌어요. 파서 표현 [문법](https://docs.raku.org/language/grammars)이 도입되면서 방대한 파싱 작업도 해낼 수 있게 됐거든요.
* 엄격 검사와 경고는 이제 자동으로 적용돼서, 잠재적인 오류를 상당 부분 없애 줘요.
* ... 그리고 [수학](https://docs.raku.org/language/math)도 척척 해내요: ```1/10 * 3 == 0.3 ``` 좋아하는 언어에서 한번 해봐요!

Raku의 모토:
* "Raku는 쉬운 일은 쉽게 하도록, 그러면서도 어려운 일을 불가능하게 만들지 않도록 설계됐어요."
* "일을 하는 방법은 하나가 아니에요. 이제는 재미를 위해 최적화된 -Ofun까지 더해졌어요."
