# 소개

## 배열

C#에서 원소를 0개 이상 담을 수 있는 자료 구조를 _컬렉션_이라고 해요. **배열**은 크기와 길이가 고정되어 있고, 모든 원소가 같은 타입이어야 하는 컬렉션이에요. 원소는 인덱스를 사용해 배열에 할당하거나 배열에서 가져올 수 있어요. C# 배열은 0부터 시작해요. 즉, 첫 번째 원소의 인덱스는 항상 0이에요.

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true
```

배열은 더 짧은 표기법으로 정의할 수도 있어요. 이 방법을 쓰면 배열을 만들면서 동시에 값을 설정할 수 있어요. 이제 컴파일러가 배열에 원소가 몇 개 들어갈지 알 수 있으므로, 길이는 생략할 수 있어요.

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

배열은 배열 인스턴스의 메서드나 속성을 호출하거나, `Array` 클래스에 정의된 정적 메서드를 사용해 다룰 수 있어요.

## `for`문

`for`문을 사용하면 조건이 충족될 때까지 코드를 반복해서 실행할 수 있어요.

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

`for`문은 네 부분으로 이루어져 있어요:

1. 초기화식: 루프에 들어가기 전에 한 번 실행돼요. 보통 루프 안에서 사용할 변수를 정의할 때 사용해요.
2. 조건식: 각 반복을 시작하기 전에 실행돼요. 이 값이 `true`로 평가되는 동안 루프가 계속 실행돼요.
3. 증감식: 각 반복이 끝난 뒤에 실행돼요. 보통 루프 변수를 수정할 때(흔히 값을 증가시키거나 감소시킬 때) 사용해요.
4. 본문: 각 반복마다 실행되는 코드예요.

## `foreach`문

배열도 _컬렉션_이라는 사실은, 인덱스로 값을 가져오는 것 외에도 `foreach`문을 사용해 배열의 _모든_ 값을 순회할 수 있다는 뜻이에요.

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```
