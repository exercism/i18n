# 지침

여러분은 챗봇을 개발하는 회사에 정규 표현식 전문가로 채용되었어요.

아직 개발의 아주 초기 단계라서, 정규 표현식을 사용해 챗봇이 자연어를 이해하고 생성하는 능력을 높이는 것이 이번 임무예요.

## 유효한 명령인지 확인하기

챗봇은 똑똑할 뿐만 아니라 충실한 비서이기도 해요.

챗봇에게 무언가를 물어보려면, 사용자는 명령의 맨 앞에 “**Chatbot**”이라는 단어를 말해야 해요.

키워드가 대문자든 소문자든 상관없어요. 여기서 중요한 것은 단어의 위치예요.

사용자가 명령을 내리고 있는지 챗봇이 알아볼 수 있도록 돕는 `isValidCommand()` 함수를 구현해요.

```javascript
isValidCommand("Chatbot, play a song from the 80's.";
// => True
isValidCommand("Hey Chatbot, where is the closest pharmacy?";
// => False
isValidCommand("CHATBOT, do you have a solution for this challenge?";
// => True
```

## 암호화된 이모지 제거하기

챗봇은 사람들이 감정을 표현하려고 이모지를 어떻게 사용하는지 이해하는 데 어려움을 겪어요.

챗봇이 사용자 메시지를 받으면, 각 이모지는 “_emoji_” 뒤에 _id_ 번호가 붙은 형태로 표현돼요.

문자열을 받아 메시지 전체에서 이모지 암호화 부분을 모두 제거하는 `removeEmoji()` 메서드를 구현해요.

이모지 텍스트가 들어 있지 않은 줄은 그대로 반환해야 해요.

이모지 문자열만 제거해요. 공백은 조정하려고 하지 마세요.

이 문제에서는 정규 표현식을 만들 때 생성자 문법을 사용해요.

```javascript
removeEmoji("I love playing videogames emoji3465 it's one of my hobbies");
// => "I love playing videogames  it's one of my hobbies"
```

## 유효한 전화번호 확인하기

모바일 앱에서 챗봇 기능을 다운로드하는 상황을 고려해, 사용자는 대화 중에 전화번호를 입력하게 돼요.

문제는 챗봇이 특정 형식의 번호만 읽고 검증할 수 있다는 거예요.

번호가 유효하면(**정규 표현식**이 지정한 문자 시퀀스와 일치하면), 챗봇은 사용자에게 감사하고 번호를 확인하는 메시지로 답해요. 번호가 유효하지 않으면, 함수는 사용자에게 전화번호가 유효하지 않다고 알려줘요.

기대하는 형식은 다음과 같아요: (+##) ###-###-###

```javascript
checkPhoneNumber('(+34) 659-771-594');
// => "Thanks! You can now download me to your phone."
checkPhoneNumber('659-771-594');
// => "Oops, it seems like I can't reach out to 659-771-594"
```

## 웹사이트 링크 가져오기

챗봇은 정말 호기심 많은 소프트웨어예요. 특정 주제에 대해 인터넷에서 검색할 수 있지만, 관련 정보를 찾을 멋진 웹사이트나 URL을 사용자에게 물어보는 것을 좋아해요.

대화 예시:

- **챗봇**: 안녕하세요 username님, 저는 JavaScript로 코딩하는 법을 배우고 싶어요. 배울 수 있는 멋진 웹사이트를 알고 있나요?
- **사용자**: 저는 [exercism.org](http://exercism.org)에서 많이 배웠어요

각 웹사이트의 링크만 담은 배열을 반환할 수 있는 `getURL()` 함수를 구현해요. 모든 URL을 인식하는 정규 표현식을 작성하는 것은 매우 복잡하겠지만, 챗봇은 간단한 URL만 읽으면 돼요. 이 연습 문제에서 URL은 `"."`로 구분된 단어의 나열이에요.

```javascript
getURL(
  'I learned a lot from exercism.org and developer.mozilla.org, but I found ts39.es very boring!',
);
// => ["exercism.org", "developer.mozilla.org", "ts39.es"];
```

## 사용자에게 인사하기

대화한 모든 사람의 데이터를 저장하기 위해, 챗봇은 사용자 프로필에서 **“smith, john”** 형식으로 전체 이름을 가져올 수 있어요.

이렇게 해서 우리 챗봇이 정말 예의 바르고 좋은 인상을 주기를 바라요.

사용자의 전체 이름이 담긴 문자열을 받아 **“Nice to meet you, John Smith”** 문자열을 반환하는 `niceToMeetYou()` 함수를 작성해요.

학습을 위해, 정규 표현식의 **치환 메서드**를 사용해 함수를 구현해요.

```javascript
let str = 'Smith, John';

niceToMeetYou(str);
// => "Nice to meet you, John Smith"
```
