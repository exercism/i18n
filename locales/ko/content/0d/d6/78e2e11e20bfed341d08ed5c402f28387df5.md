# 지시 사항

무대 감독이 리허설 대본을 타자로 쳐 달라고 하는데, 그중 몇 부분은 뭔가를 반복하거나 이어 붙여서 만들어요.

네 가지 작업은 모두 `REHEARSAL_SCRIPT` 클래스에 작성해요.

## 1. 큐 반복하기

큐와 숫자가 주어지면, 사이에 아무것도 없이 그 큐를 그 횟수만큼 반복한 값을 반환해요.

```sather
REHEARSAL_SCRIPT::repeat_cue("Ha", 3)
-- => "HaHaHa"
```

무언가를 0번 반복하면 빈 문자열이 나와요.

## 2. 출연진 이니셜

출연진 명단이 주어지면, 각 이름의 첫 글자를 이어 붙여서 반환해요.

```sather
REHEARSAL_SCRIPT::initials(|"Mia", "Ana", "Ben"|)
-- => "MAB"
```

## 3. 대사에 번호 매기기

장면의 대사가 주어지면, 1부터 번호를 붙여서 각각 한 줄씩 넣어요.

```sather
REHEARSAL_SCRIPT::numbered_lines(|"Enter", "Exit"|)
-- => "1. Enter\n2. Exit"
```

대사와 대사 사이에는 새 줄이 들어가고, 마지막 대사 뒤에는 들어가지 않아요. 대사가 하나도 없는 장면은 빈 문자열이에요.

## 4. 대사 외치기

대사의 모든 글자를 대문자로 바꾼 값을 반환해요.

```sather
REHEARSAL_SCRIPT::shout("quiet please")
-- => "QUIET PLEASE"
```
