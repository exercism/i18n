# 지침

친구들을 위해 쿠키를 구울 준비를 하다가, 레시피에 쓰인 계량 단위 몇 가지를 변환해야 한다는 걸 알게 됐어요.
미터법에만 익숙한 상황이라면, 흔히 쓰이는 미국식 베이킹 계량을 편하게 다루기 위해 밀리리터(mL)로 변환하는 방법을 마련해야 해요.

풀이에는 이 변환표를 사용해요:

| 변환할 단위 | 부피 | 밀리리터(mL) 기준 |
| --------------- | ------ | ------------------- |
| mL              | 1      | 1                   |
| 미국 컵          | 1      | 240                 |
| 미국 액량 온스   | 1      | 30                  |
| 미국 티스푼      | 1      | 5                   |
| 미국 테이블스푼  | 1      | 15                  |

프로그래머로 성장 중인 재능 있는 실력자답게, 나열된 어떤 단위에서든 다른 단위로(심지어 같은 단위로도) 변환하기 쉽도록 밀리리터를 중간 단위로 쓰기로 해요.

## 1. 부피 쌍에서 숫자 성분 가져오기

`KitchenCalculator.get_volume` 메서드를 구현해요.
부피 쌍 튜플이 주어지면 숫자 성분만 반환해야 해요.

```crystal
KitchenCalculator.get_volume({:cup, 2.0})
# => 2.0
```

## 2. 부피 쌍을 밀리리터로 변환하기

`KitchenCalculator.to_milliliter` 메서드를 구현해요.
부피 쌍 튜플이 주어지면 변환표를 사용해 부피를 밀리리터로 변환해야 해요.

```crystal
KitchenCalculator.to_milliliter({:cup, 2.5})
# => {:milliliter, 600.0}
```

## 3. 밀리리터 부피 쌍을 다른 단위로 변환하기

`KitchenCalculator.from_milliliter` 메서드를 구현해요.
부피 쌍 튜플과 원하는 단위가 주어지면, 변환표를 사용해 부피를 원하는 단위로 변환해야 해요.

```crystal
KitchenCalculator.from_milliliter({:milliliter, 1320.0}, :cup)
# => {:cup, 5.5}
```

## 4. 어떤 단위에서든 다른 단위로 변환하기

`KitchenCalculator.convert` 메서드를 구현해요.
부피 쌍 튜플과 원하는 단위가 주어지면, 주어진 부피를 원하는 단위로 변환해야 해요.

```crystal
KitchenCalculator.convert({:teaspoon, 9.0}, :tablespoon)
# => {:tablespoon, 3.0}
```
