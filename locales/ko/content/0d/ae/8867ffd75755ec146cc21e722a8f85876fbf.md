# 지침

양의 정수에 대한 니코마코스(서기 60~120년)의 분류 체계를 바탕으로, 어떤 수가 perfect, abundant, deficient 중 어느 것인지 판별해요.

그리스 수학자 [니코마코스][nicomachus]는 양의 정수에 대한 분류 체계를 고안했어요. 이 체계에서는 각 수가 자신의 [진약수의 합][aliquot-sum]에 따라 **perfect**, **abundant**, **deficient** 중 오직 하나의 범주에 속해요.
진약수의 합은 어떤 수의 약수 중에서 그 수 자신을 제외한 것들의 합으로 정의해요.
예를 들어, 15의 진약수의 합은 (1 + 3 + 5) = 9예요.

- **Perfect**: 진약수의 합 = 그 수
  - 6은 (1 + 2 + 3) = 6이므로 perfect에 해당해요.
  - 28은 (1 + 2 + 4 + 7 + 14) = 28이므로 perfect에 해당해요.
- **Abundant**: 진약수의 합 > 그 수
  - 12는 (1 + 2 + 3 + 4 + 6) = 16이므로 abundant에 해당해요.
  - 24는 (1 + 2 + 3 + 4 + 6 + 8 + 12) = 36이므로 abundant에 해당해요.
- **Deficient**: 진약수의 합 < 그 수
  - 8은 (1 + 2 + 4) = 7이므로 deficient에 해당해요.
  - 소수는 deficient에 해당해요.

주어진 수가 **perfect**인지 판별하는 방법을 구현해요.
사용하는 언어 트랙에 따라, 주어진 수가 **abundant**인지 **deficient**인지 판별하는 방법도 구현해야 할 수도 있어요.
