# 소개

함수는 하나 이상의 인자에 기본값을 선언할 수 있어요. 다음 함수를 살펴봐요:

```elixir
def number(n \\ 13), do: "That's not my favorite"
```

컴파일되면 Elixir는 `number/0`(인자 없음)과 `number/1`(인자 하나)에 대한 함수 정의를 만들어요.

인자 두 개 이상에 기본값이 있으면, 기본값은 누락된 인자를 채우기 위해 왼쪽에서 오른쪽으로 함수에 적용돼요.

함수에 절이 두 개 이상 있으면, 기본 인자는 함수 절보다 앞에 있는 함수 헤더(본문이 없는 함수)에서 정의해야 해요:

```elixir
def number(n \\ 13)
def number(n) when n < 10, do: "Dream bigger!"
def number(n) when n > 100, do: "Not that big..."
```

[kernel-guards]: https://hexdocs.pm/elixir/Kernel.html#guards
