# 불필요한 괄호가 있어요

`||` 연산자로 두 개의 작은 식을 OR할 때, 그중 한 식이 괄호로 감싸여 있으면서 여러 항을 AND로만 묶고 있다면(예: `knightIsAwake || (archerIsAwake && !prisonerIsAwake)`) 괄호를 생략할 수 있어요. `&&`가 `||`보다 우선순위가 높기 때문이에요.

```java
// instead of
knightIsAwake || (archerIsAwake && !prisonerIsAwake);

// use
knightIsAwake || archerIsAwake && !prisonerIsAwake;
```

다만, 복잡한 경우에는 괄호를 쓰는 편이 조건을 더 읽기 쉽고 이해하기 쉽게 만들어 줄 수도 있다는 점을 기억해 두세요.
