# 참고 자료

* Libera Chat의 [#haskell](https://web.libera.chat/?channel=#haskell) IRC 채널은 "Haskell과 함수형 프로그래밍, 그리고 프로그래밍 전반에 대한 학습과 토론을 장려하는" 것을 목표로 해요. IRC 채널에 대한 더 자세한 내용은 [채널의 Haskell 위키 페이지](https://wiki.haskell.org/IRC_channel)에서 확인할 수 있어요.
* [Hoogle](https://www.haskell.org/hoogle/)은 Haskell API 검색 엔진이에요. 함수 이름만 알고 있어도 그 함수가 무슨 일을 하는지 찾아볼 수 있어요. 더 흥미로운 점은 타입 시그니처로도 검색할 수 있다는 거예요: [(a -> b) -> [a] -> [b]](https://www.haskell.org/hoogle/?hoogle=%28a+-%3E+b%29+-%3E+[a]+-%3E+[b]) 타입 시그니처를 가진 함수가 무엇인지 알고 싶다면 Hoogle이 찾아줘요!
* [Stack Overflow](https://stackoverflow.com/questions/tagged/haskell)에서 문제를 검색하고 이미 답변이 있는지 확인할 수 있어요. 질문을 올리거나 답변을 달 수도 있어요.
* [/r/haskell](https://www.reddit.com/r/haskell)은 Haskell 서브레딧이에요.
* [Haskell 커뮤니티 페이지](https://www.haskell.org/community/)에는 Haskell 사용자들이 모여 소통하는 여러 커뮤니티가 링크되어 있어요. 여기서 자신에게 맞는 소통 방식을 고르면 돼요.
