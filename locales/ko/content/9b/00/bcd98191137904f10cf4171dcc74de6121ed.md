# 안내

동네 시 동호회가 새 시즌을 시작해요. 시인들이 동호회에 가입하고, 두 시인이 함께 시를 쓰면 그 둘은 같은 *창작 모임*에 속하게 돼요. 동호회는 누가 누구와 같은 모임에 속하는지 관리하고 싶어 하고, 여러분은 그것을 관리하는 단어들을 작성해 달라는 부탁을 받았어요.

서로소 집합이 딱 맞아요. 각 시인은 원소이고, 창작 모임은 그룹이에요.

## 1. 동호회 열기

`new-club`을 정의해요. 시인들의 시퀀스를 받아서, 모든 시인이 등록된 새로운 서로소 집합을 반환해요. 각 시인은 처음에는 자신만의 창작 모임에 속해 있어요.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
! => a disjoint set holding the three poets
```

## 2. 공동 작업 기록하기

`collaborate`를 정의해요. 두 시인과 동호회를 받아서, 두 시인의 창작 모임을 합치고 동호회를 반환해요. 그래서 공동 작업을 차례로 기록할 수 있어요.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Keats" "Byron" rot collaborate
! => the club, with Keats and Byron now in one circle
```

## 3. 시인의 모임 찾기

`circle-of`를 정의해요. 시인과 동호회를 받아서, 그 시인의 창작 모임의 대표를 반환해요. 같은 모임에 속한 두 시인은 항상 같은 대표를 알려줘요.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Dickinson" swap circle-of
! => "Dickinson"   (still in a circle of their own)
```

## 4. 같은 모임인가요?

`same-circle?`을 정의해요. 두 시인과 동호회를 받아서, 두 시인이 같은 창작 모임에 속하면 `t`를, 그렇지 않으면 `f`를 반환해요. 내장 동등성 검사를 쓰는 대신 시인들의 대표를 비교해요.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Keats" "Byron" rot collaborate
dup [ "Keats" "Byron" ] dip same-circle? .      ! => t
    [ "Keats" "Dickinson" ] dip same-circle? .  ! => f
```
