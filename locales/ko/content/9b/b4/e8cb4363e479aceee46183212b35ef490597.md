# 개요

## 산술 연산자

JavaScript는 숫자에 대한 기본 산술 연산을 수행하는 여섯 가지 연산자를 제공해요.

- `+`: 덧셈 연산자는 숫자의 합을 구할 때 사용해요.

  ```javascript
  1 + 2; // => 3
  2.5 + 3.9; // => 6.5
  ```

- `-`: 뺄셈 연산자는 두 숫자의 차를 구할 때 사용해요.

  ```javascript
  19 - 2; // => 17
  7.4 - 1.2; // => 6.2
  ```

- `*`: 곱셈 연산자는 두 숫자의 곱을 구할 때 사용해요.

  ```javascript
  7 * 5; // => 35
  9.2 * 6.3; // => 57.959999999999994
  ```

- `/`: 나눗셈 연산자는 두 숫자를 나눌 때 사용해요.
  JavaScript의 숫자는 항상 부동소수점 수이기 때문에 정수 나눗셈은 없어요.

  ```javascript
  8 / 2; // => 4
  25 / 3; // => 8.333333333333334
  ```

- `%`: 나머지 연산자는 나눗셈을 한 뒤의 나머지를 구할 때 사용해요.

  ```javascript
  40 % 4; // => 0
  11 % 4; // => 3
  -11 % 4; // => -3
  ```

- `**`: 거듭제곱 연산자는 숫자를 거듭제곱할 때 사용해요.
  [`Math.pow()`][mdn-math-pow]를 사용하는 것과 같아요.

  ```javascript
  4 ** 3; // => 64
  4 ** 1 / 2; // => 2
  ```

## 연산 순서

한 줄에서 여러 연산자를 사용할 때, JavaScript는 [이 우선순위 표][mdn-operator-precedence]에 나와 있는 순서대로 연산을 처리해요.
우리가 초등학교 수학 시간에 배운 PEDMAS(괄호, 지수, 나눗셈/곱셈, 덧셈/뺄셈) 규칙을 사용하는 셈이에요.

<!-- prettier-ignore-start -->
```javascript
const result = 3 ** 3 + 9 * 4 / (3 - 1);
// => 3 ** 3 + 9 * 4/2
// => 27 + 9 * 4/2
// => 27 + 18
// => 45
```
<!-- prettier-ignore-end -->

## 복합 대입 연산자

복합 대입 연산자는 변수에 산술 연산을 한 뒤 그 결과값을 같은 변수에 대입하는 코드를 더 짧게 쓰는 방법이에요.
예를 들어, 두 변수 `x`와 `y`가 있다고 해봐요.
이때 `x += y`는 `x = x + y`와 같아요.
흔히 변수 `y` 대신 숫자를 사용하기도 해요.
나머지 다섯 연산도 같은 방식으로 할 수 있어요.

```javascript
let x = 5;
x += 25; // x is now 30

let y = 31;
y %= 3; // y is now 1
```
