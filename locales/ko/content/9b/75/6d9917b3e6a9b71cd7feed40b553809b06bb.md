# 지침

Markdown 파서를 리팩터링해요.

markdown 연습 문제는 리팩터링 연습 문제예요.
주어진 문자열을 [Markdown 문법][markdown]으로 파싱하고, 그 문자열에 해당하는 HTML을 반환하는 코드가 있어요.
이 코드는 헷갈리게 작성되어 있어서 따라가기 어렵지만, 어찌저찌 잘 동작하고 모든 테스트도 통과해요!
이번 과제는 이 코드를 더 읽기 쉽고 유지보수하기 좋게 다시 작성하면서, 동시에 모든 테스트가 계속 통과하도록 만드는 거예요.

리팩터링하면서 한 일을 주석으로 메모해 두면 리뷰하는 사람이 확인할 수 있어서 좋지만, 꼭 필요한 건 아니에요.
가장 중요한 건 코드를 더 나아지게 만드는 거예요!

[markdown]: https://guides.github.com/features/mastering-markdown/
