# 힌트

## 일반

- 익명 함수를 활용해요.
- 익명 함수는 정의될 당시 스코프에 있는 변수를 참조할 수 있어요.

## 1. 덧셈 함수 만들기

- `secret_add`에 전달된 인자에 익명 함수의 인자를 더하는 익명 함수를 반환해요.

## 2. 뺄셈 함수 만들기

- 익명 함수의 인자에서 `secret_subtract`에 전달된 인자를 빼는 익명 함수를 반환해요.

## 3. 곱셈 함수 만들기

- `secret_multiply`에 전달된 인자에 익명 함수의 인자를 곱하는 익명 함수를 반환해요.

## 4. 나눗셈 함수 만들기

- 익명 함수의 인자를 `secret_divide`에 전달된 인자로 나누는 익명 함수를 반환해요.

## 5. 함수 조합기 만들기

- `secret_combine`에 전달된 각 함수를 사용하는 익명 함수를 반환해요.
