# 소개

Go에는 정수 또는 부동소수점 값을 나타낼 수 있는 기본 숫자 타입이 있어요.

이 개념에서는 두 가지 숫자 타입을 살펴봐요:

- `int`: 예를 들어 `0`, `255`, `2147483647` 등이 있어요.
   크기가 최소 32비트인 부호 있는 정수예요 (값 범위: -2147483648부터 2147483647까지).
   하지만 이는 시스템 아키텍처에 따라 달라져요.
   대부분의 최신 컴퓨터는 64비트이므로 `int`의 크기는 64비트가 돼요 (값 범위: -9223372036854775808부터 9223372036854775807까지).

- `float64`: 예를 들어 `0.0`, `3.14` 등이 있어요.
   64비트 부동소수점 수 전체의 집합을 담고 있어요.

Go는 `+`, `-`, `*`, `/`, `%`라는 표준 산술 연산자를 지원해요 (`%`는 모듈로가 아니라 나머지예요).

Go에서는 서로 다른 타입 사이에 값을 할당하려면 명시적 변환이 필요해요.
예를 들어 `int`를 `float64`로 변환하려면 다음과 같이 하면 돼요:

```go
var x int = 42
f := float64(x)

fmt.Printf("x is of type: %s\n", reflect.TypeOf(x))
// Output: x is of type: int

fmt.Printf("f is of type: %s\n", reflect.TypeOf(f))
// Output: f is of type: float64
```
