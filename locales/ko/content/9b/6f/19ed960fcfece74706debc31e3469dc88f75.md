# 자세히 알아보기

PHP에서는 변수에 괄호 [`()`]를 붙여서 그 변수를 함수처럼 호출할 수 있어요. PHP는 함수를 호출할 때 변수의 값과 이름이 같은 함수를 찾아요.

```php
function foo(): string
{
    return "foo() invoked";
}

$func = 'foo';
$func(); // This calls foo()
```

## 정적 클래스 함수 호출하기

정적 클래스 함수도 같은 방식으로 호출할 수 있어요.

```php
class Rocket
{
    public static function launch()
    {
        return '3, 2, 1, Liftoff!';
    }
}

$func = 'Rocket::launch';
$func(); // This calls Rocket::launch()
```

## 인스턴스 클래스 함수 호출하기

클래스 인스턴스의 함수를 호출하는 것도 가능해요.

```php
class Rocket
{
    public function openDoor()
    {
        return 'Door open.';
    }
}

$rocket = new Rocket();
$func = [$rocket, 'openDoor'];
$func(); // This calls Rocket::openDoor()
```
