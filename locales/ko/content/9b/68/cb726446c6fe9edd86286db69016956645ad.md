## MacOS

먼저 [Homebrew][1]로 Lua와 [Luarocks][2]를 설치해요:

```shell
$ brew install lua luarocks
```

그런 다음 Lua용 [Busted][3] 테스트 프레임워크를 설치해요:

```shell
$ luarocks install --local busted
```

시스템 `$PATH`에 `~/.luarocks/bin`을 추가해요

```shell
export PATH="$HOME/.luarocks/bin:$PATH"
```

이 설정은 임시로만 적용돼요.
`$PATH`에 영구적으로 추가하려면
사용하는 셸에 따라 `.bashrc`, `.zshrc`, `config.fish` 중 하나에 추가해야 해요.

그런 다음 테스트를 실행해요:

```shell
$ busted
```

## Windows 10: WSL

먼저 [PowerShell][8](관리자)로 [WSL(리눅스용 윈도우 하위 시스템)][7]을 활성화해야 해요:

```shell
PS> Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Windows-Subsystem-Linux
```

이 작업에는 재부팅이 필요해요.

다음으로 [Microsoft Store][9]에서 Ubuntu를 설치하거나, **또는** PowerShell로 다운로드한 뒤 설치해요:

```shell
PS> curl.exe -L -o ubuntu1804.appx https://aka.ms/wsl-ubuntu-1804
PS> Add-AppxPackage .\ubuntu1804.appx; rm .\ubuntu1804.appx
PS> ubuntu1804
```

그런 다음 패키지 목록을 업데이트해요:

```shell
PS> wsl
$ sudo apt-get update
```

이제 위의 [Ubuntu 설치 안내](#ubuntu)를 따라 [LuaRocks][2]와 [Busted][3]를 설치할 준비가 됐어요.

설치를 마치면 Windows 명령줄에서 바로 테스트를 실행할 수 있어요:

```cmd
C:\> wsl busted
```

## Windows 10: Docker

### Gitbash 설치하기

이 단계는 선택 사항이에요. Windows 기본 CLI나 다른 CLI를 사용한다면 다음 단계를 조금 수정해야 할 수도 있어요.

다운로드는 [여기][10]에서, 설치 안내는 [여기][11]에서 확인해요.

### Docker 설치하기

[Docker for Windows][12] 설치 안내를 따라 설치해요.
설치를 마치면 다음 명령을 실행해서 제대로 설치됐는지 확인할 수 있어요.

```shell
$ docker --version
```

_Docker를 처음 실행할 때 오류가 발생할 수 있어요._

`cannot enable hyper-v service`

_이런 경우 다음 안내에 따라 [Hyper V를 활성화][13]하면 돼요. 설정을 비활성화한 뒤 컴퓨터를 다시 시작하고, 부팅 후 다시 활성화해야 할 수도 있어요._

### busted 설치하기

Gitbash와 Docker를 설치했다면 busted '컨테이너'를 설치할 수 있어요.

Gitbash에서 다음을 실행해요:

널리 쓰이는 이 Docker 컨테이너를 다음 명령으로 내려받아요:

```shell
$ docker pull imega/busted
```

매번 명령 전체를 입력하지 않아도 되도록 함수를 만들어요.
`.bashrc`에 다음을 추가해요:

```shell
dbusted() { docker run --rm -t -v "/$@":/data imega/busted; }
```

이제 CLI에서 테스트를 실행할 디렉터리로 이동할 수 있어요. 다음을 실행해요:

```shell
$ dbusted $PWD
```

busted 테스트의 출력이 보일 거예요.
