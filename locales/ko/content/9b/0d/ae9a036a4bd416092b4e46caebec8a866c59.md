# 지시 사항

학교 분실물 보관소에서는 모든 것을 상자에 보관하는데, 상자에 들어가는 것은 무엇이든 될 수 있어요. 스웨터일 수도, 여러 개의 물건일 수도, 이름일 수도 있죠.

`LOST_BOX{T}` 클래스를 작성해요. 스텁에는 클래스 헤더가 들어 있어요.

## 1. 물건을 맡아요

`create`는 물건과 그것을 맡긴 사람의 이름을 받아서 상자를 만들어 줘요. 상자는 처음에는 아직 찾아가지 않은 상태로 시작해요.

```sather
box ::= #LOST_BOX{STR}("blue jumper", "Mia");
box.item
-- => "blue jumper"
box.handed_in_by
-- => "Mia"
box.claimed
-- => false
```

## 2. 상자를 찾아가요

`claim`은 상자를 찾아간 상태로 표시해요. 아무것도 반환하지 않아요.

```sather
box.claim;
box.claimed
-- => true
```

## 3. 아직 기다리는 중일까요?

`waiting`은 상자가 아직 찾아가지 않았는지 알려줘요.

```sather
box.waiting
-- => false
```

## 4. 내용물을 바꿔요

`replace`는 새 물건을 받아서 상자에 넣고, 그 전에 있던 물건을 반환해요. 들어가는 물건과 나오는 물건은 둘 다 `T`예요.

```sather
old ::= box.replace("red jumper");
old
-- => "blue jumper"
box.item
-- => "red jumper"
```

## 5. 설명을 적어요

`describe`는 상자에 대한 한 줄을 반환해요. `"blue jumper, handed in by Mia"`처럼요.

물건을 문자열로 만들려면, 클래스는 `T`가 문자열로 변환될 수 있다는 것을 알아야 해요. 매개변수에 제약을 걸어요. 클래스 헤더를 `class LOST_BOX{T < $STR}`로 쓰면 `item.str`을 사용할 수 있어요.

```sather
box.describe
-- => "blue jumper, handed in by Mia"
```
