# 소개

C#에서는 클래스나 구조체의 스코프 안에 타입을 정의할 수 있어요. 이렇게 타입을 감싸는 바깥 타입은 일종의 네임스페이스 역할을 해요. 중첩 타입에 접근할 때는 바깥 타입을 거쳐 점 문법을 사용해요.

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

중첩 타입에도 접근 수준을 지정할 수 있어요.

바깥 타입의 private 멤버는 중첩 타입의 멤버에게는 스코프에 포함되지만, 그 반대는 아니에요.
