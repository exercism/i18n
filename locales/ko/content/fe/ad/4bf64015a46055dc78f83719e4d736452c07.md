# 소개

## Python의 객체 지향 프로그래밍

[함수형][functional], [선언형][declarative], [명령형][imperative] 스타일로 프로그래밍해 왔다면, [객체 지향 프로그래밍][oop](OOP)으로 초점을 옮기는 것이 조금 낯설게 느껴질 수 있어요.
OOP 접근 방식은 문제를 서로 상호작용하고, 상태를 유지하며, 데이터에 작용하는 하나 이상의 `objects`로 모델링하는 것을 생각해 보라고 프로그래머에게 요청해요.
객체는 현실 세계의 개체(_예를 들어 자동차나 고양이_)를 나타낼 수도 있고, 더 추상적인 개념(_예를 들어 정수, 탈것, 포유류_)을 나타낼 수도 있어요.
각 객체는 컴퓨터 메모리에서 고유한 인스턴스가 되고, 전체 모델의 일부를 나타내요.

## 클래스

`Classes`는 새로운 객체 타입의 정의이고, 여기서 새로운 객체 `instances`가 만들어져요.
클래스는 흔히 데이터를, 그 데이터를 다루는 코드나 함수와 함께 묶어요.
이런 의미에서 클래스는 비슷한 타입의 객체를 많이 만들어 사용할 수 있는 _청사진_ 또는 일련의 지침이에요.
복잡한 프로그램은 클래스를 많이 가질 수 있고, 각 클래스는 여러 가지 서로 다른 객체를 만들어요.
클래스로부터 객체를 만드는 과정을 `instantiation`(_또는 클래스의 인스턴스를 만드는 것_)이라고 해요.

Python에서 클래스 정의는 간단해요:

```python
class MyClass:
    # Class body goes here
```

### 클래스 속성

클래스 필드(_달리 `properties`, `attributes`, `data members`, `variables`라고도 해요_)는 클래스 본문에 추가할 수 있어요:

```python
class MyClass:
    number = 5
    string = "Hello!"
```

`MyClass`의 인스턴스(_객체_)는 클래스를 [_호출_][calling]해서 만들고 이름에 묶을 수 있어요(_함수를 호출하는 것과 같은 방식이에요_):

```python
>>> new_object = MyClass()

# Class is instantiated and resulting object is bound to the "new_object" name.
# Note: the object address 'at 0x15adc55b0' will vary by computer.
>>> new_object
<__main__.MyClass at 0x15adc55b0>
```

`Class attributes`는 클래스에서 만들어진 모든 객체(_또는 인스턴스_)가 공유하고, [`dot notation`][dot notation], 즉 객체 이름 뒤에 속성 이름 앞에 놓는 `.`을 통해 접근할 수 있어요:

```python
>>> new_object = MyClass()

# Accessing the class attribute "number" via dot-notation.
>>> new_object.number
5

# Accessing the class attribute "string" via dot-notation.
>>> new_object.string
'Hello!'

# Instantiating an additional object and binding it to the "second_new_object" name.
>>> second_new_object = MyClass()

>>> second_new_object
# Note: the object address "at 0x15ad99970" will vary by computer.
<__main__.MyClass at 0x15ad99970>

# Second_new_object shares the same class attributes as new_object.
>>> new_object.number == second_new_object.number
True
```

클래스 속성은 다른 어떤 메서드보다도 먼저, 클래스 자체의 본문에 정의해요.
클래스 속성은 클래스가 소유하기 때문에, 클래스의 인스턴스들 사이에서 공유될 수 있어요.
이 속성들은 공유되기 때문에, 클래스에서 _직접_ 값에 접근하고 조작할 수 있어요.
클래스 속성의 값을 바꾸면 _**클래스에서 만들어진 모든 객체의**_ 값이 바뀌어요:

```python
>>> obj_one = MyClass()
>>> obj_two = MyClass()

# Accessing a class attribute from an object.
>>> obj_two.number
5

# Accessing the class attribute from the class itself.
>>> MyClass.number
5

# Modifying the value of the "number" class attribute.
>>> MyClass.number = 27

# Modifying the "number" class attribute changes the "number" attribute for all objects.
>>> obj_one.number
27

>>> obj_two.number
27
```

항상 데이터가 동기화된 객체 여러 개를 갖는 것은 그다지 유용하지 않아요.
다행히, 클래스에서 만든 객체는 고유한 `instance attributes`(_또는 인스턴스 속성, 변수, 필드_)로 커스터마이즈할 수 있어요.
이름에서 알 수 있듯이, 인스턴스 속성은 각 객체에 고유하고, 독립적으로 수정할 수 있어요.


## `__init__()`로 객체 생성 커스터마이즈하기

특별한 ["던더 메서드"][dunder](_"double underscore method"의 줄임말_)인 `__init__()`는 클래스 인스턴스를 커스터마이즈하는 데 쓰이고, 객체의 인스턴스 속성이나 프로퍼티를 초기화하는 데 사용할 수 있어요.
인스턴스 속성을 초기화하는 역할 때문에, `__init__()`은 `class constructor` 또는 `initializer`라고도 해요.
`__init__()`는 `self`라는 필수 매개변수 하나를 받는데, 이는 새로 초기화되거나 만들어진 객체를 가리켜요.
그런 다음 인스턴스 속성이나 프로퍼티를 위한 데이터를 `self` 매개변수 뒤에 `__init__()`의 인자로 전달할 수 있어요.

아래에서 `MyClass`는 `location_x`와 `location_y`라는 인스턴스 속성을 가져요.
보다시피, 두 속성은 `__init__()`에 전달된 `location`(_튜플_) 인자의 첫 번째와 두 번째 인덱스에 할당됐어요.
이제 클래스를 인스턴스화해서 객체를 만들면 클래스 인스턴스의 `location_x`와 `location_y` 속성이 초기화돼요:

```python
class MyClass:
    # These are class attributes, variables, or fields.
    number = 5
    string = "Hello!"

    # This is the class "constructor", with a "location" parameter that is a tuple.
    def __init__(self, location):

        # This is an instance or object property, attribute, or variable.
        # Note that we are unpacking the tuple argument into two separate instance variables.
        self.location_x = location[0]
        self.location_y = location[1]

# Create a new object "new_object_one", with object property (1, 2).
>>> new_object_one = MyClass((1, 2))

# Create a second new object "new_object_two" with object property (-8, -9).
>>> new_object_two = MyClass((-8, -9))

# Note that new_object_one.location_x and new_object_two.location_x two different values.
>>> new_object_one.location_x
1

>>> new_object_two.location_x
-8
```

위에서 `MyClass`를 초기화할 때는 인자 하나만 전달하면 된다는 점에 주의해요. Python이 클래스를 호출할 때 `self`를 전달하는 것을 알아서 처리해 줘요.


## 메서드

`method`는 클래스 자체(_[클래스 메서드][class method]라고 하며, 나중 연습 문제에서 다뤄요_)나 클래스의 _인스턴스_(객체)에 묶인 `function`이에요.
객체(인스턴스)를 다루는 메서드는 `self`를 첫 번째 매개변수로 해서 정의해야 해요.
그러고 나서 나머지 매개변수는 "일반" 함수, 즉 묶이지 않은 함수에서처럼 정의하면 돼요:

```python
class MyClass:
    number = 5
    string = "Hello!"

    # Class constructor.
    def __init__(self, location):
        # Instance properties
        self.location_x = location[0]
        self.location_y = location[1]

    # Instance method. Note "self" as first parameter.
    def change_location(self, amount):
        self.location_x += amount
        self.location_y += amount
        return self.location_x, self.location_y
```

속성 접근과 마찬가지로, 메서드 호출은 객체 이름 뒤에, 메서드 이름 앞에 `.`을 놓기만 하면 돼요.
호출된 메서드는 첫 번째 매개변수로 객체의 복사본을 필요로 하지 않아요. Python이 `self`를 자동으로 채워 줘요:

```python
class MyClass:
    number = 5
    string = "Hello!"

    def __init__(self, location):
        self.location_x = location[0]
        self.location_y = location[1]

    def change_location(self, amount):
        self.location_x += amount
        self.location_y += amount
        return self.location_x, self.location_y

# Make a new test_object with location (3,7)
>>> test_object = MyClass((3,7))
>>> (test_object.location_x, test_object.location_y)
(3,7)

# Call change_location to increase location_x and location_y by 7.
>>> test_object.change_location(7)
(10, 14)
```

클래스 속성은 클래스 밖에서 접근하는 것과 같은 방식으로 인스턴스 메서드 안에서 접근할 수 있어요:

```python
class MyClass:
    number = 5
    string = "Hello!"

    def __init__(self, location):
        self.location_x = location[0]
        self.location_y = location[1]

    # Alter instance variable location_x and location_y
    def change_location(self, amount):
        self.location_x += amount
        self.location_y += amount
        return self.location_x, self.location_y

    # Alter class variable number for all instances from within an instance.
    def increment_number(self):
        # Increment the 'number' class variable by 1.
        MyClass.number += 1


>>> test_object_one = MyClass((0,0))
>>> test_object_one.number
5

>>> test_object_two = MyClass((13, -3))
>>> test_object_two.increment_number()
>>> test_object_one.number
6
```

## Pass로 구현 자리 표시하기

이전 개념 연습 문제와 실습 연습 문제 스텁에서, 실제 코드 대신 함수 본문 안에 `pass` 키워드가 사용된 것을 봤을 거예요.
`pass` 키워드는 문법적으로 유효한 자리 표시자예요. 빈 함수나 클래스 정의에 대해 Python이 문법 오류를 던지는 것을 막아 줘요.
본질적으로, 이는 Python 인터프리터에게 '걱정 마세요! 언젠가는 _분명히_ 여기에 코드를 넣을 거예요, 아직 안 했을 뿐이에요.'라고 말하는 방법이에요.

```python
class MyClass:
    number = 5
    string = "Hello!"

    def __init__(self, location):
        self.location_x = location[0]
        self.location_y = location[1]

    # Alter instance variable location_x and location_y
    def change_location(self, amount):
        self.location_x += amount
        self.location_y += amount
        return  self.location_x, self.location_y

    # Alter class variable number for all instances
    def increment_number(self):
        # Increment the 'number' class variable by 1.
        MyClass.number += 1

    # This will compile and run without error, but has no current functionality.
    def pending_functionality(self):
       # Stubbing or placholding the body of this method.
       pass
```
