# 힌트

## 1. 직원의 배지 출력하기

- Base R에서 문자열을 만들려면 [`sprintf`][ref-sprintf] 함수가 유용해요.
- Tidyverse 방식을 쓴다면 `stringr` 라이브러리의 [`str_glue`][ref-str_glue]를 사용할 수 있어요.

## 2. 신입 직원의 배지 출력하기

- [`is.na`][ref-isna]로 분기해요.

## 3. 사장님의 배지 출력하기

- [`is.null`][ref-isnull]로 분기해요.

## 4. ID가 없는 직원의 총급여 계산하기

- [`is.na`][ref-isna]로 [필터링][concept-vector-filtering]한 다음 [`sum`][ref-sum]을 사용할 수 있어요.
- ID가 없는 직원이 아무도 없다면 `salaries[is.na(ids)]`는 무엇일까요? R 콘솔에서 한번 확인해 보면 좋아요. 컴퓨터에 R이 설치되어 있지 않다면 [rdrr.io][web-rdrr] 같은 온라인 콘솔이 도움이 될 거예요.
