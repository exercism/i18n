# 지침

이 연습 문제에서는 좋아하는 요리책을 보고 근사한 라자냐를 만들 수 있도록 코드를 작성해 볼 거예요.

라자냐를 요리하는 데 걸리는 시간과 관련된 네 가지 과제가 있어요.

## 1. 예상 굽기 시간을 상수에 저장하기

`expected-bake-time` 상수를 정의해요. 이 상수는 라자냐를 오븐에 굽는 데 몇 분이 필요한지 반환해야 해요.

요리책에 따르면 라자냐는 오븐에 총 40분 동안 있어야 해요.

```factor
expected-bake-time .
! => 40
```

## 2. 준비 시간을 분 단위로 계산하기

`preparation-time` 워드를 정의해요. 이 워드는 스택에서 라자냐에 추가한 층의 수를 꺼내요. 그리고 각 층을 준비하는 데 2분이 걸린다고 가정할 때, 준비에 걸린 시간(분)을 남겨요.

```factor
4 preparation-time .
! => 8
```

## 3. 남은 오븐 시간을 분 단위로 계산하기

`remaining-time` 워드를 정의해요. 이 워드는 라자냐가 오븐에서 이미 보낸 시간(분)을 꺼내고, 오븐에 앞으로 더 있어야 할 시간(분)을 남겨요.

```factor
25 remaining-time .
! => 15
```

## 4. 총 작업 시간을 분 단위로 계산하기

`total-working-time` 워드를 정의해요. 이 워드는 스택에서 두 개의 인자를 꺼내요. 첫 번째는 라자냐의 층 수이고, 두 번째는 라자냐가 오븐에 이미 있었던 시간(분)이에요. 그런 다음 지금까지 요리한 총 시간, 즉 준비 시간과 오븐에 이미 있던 시간을 더한 값을 남겨요.

```factor
3 20 total-working-time .
! => 26
```
