# 부동소수점 수

PHP에서 부동소수점 수는 실수의 부분집합을 표현하는 데 사용돼요.
하나 이상의 숫자를 소수점 구분 기호로 나눈 형태예요.

```php
<?php

$a = 1.234; 
$b = 1.2e3; 
$c = 7E-10;
$d = 1_234.567; // as of PHP 7.4.0
```

## 흔한 함정

모든 수와 산술 연산을 부동소수점 수로 처리할 수 있는 것은 아니에요.
부동소수점 수로 달러와 센트를 표현하면 반올림 오류가 자주 생겨요.

```php
<?php

$result = 0.1 + 0.2; // => 0.30000000000000004
```
