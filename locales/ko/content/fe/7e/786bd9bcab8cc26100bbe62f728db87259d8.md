# 지침

이 연습 문제에서는 동네 오락실에서 가장 인기 있는 게임의 최고 점수를 기록하는 방법을 만들어요.

구현할 함수가 6개 있고, 대부분 최고 점수를 담고 있는 객체를 다루는 것과 관련되어 있어요.

## 1. 새로운 최고 점수판 만들기

최고 점수판 역할을 하는 객체를 만드는 `create_score_board` 함수를 작성해요.
이 객체의 키는 플레이어의 이름이고, 값은 플레이어의 점수예요.
테스트를 위해 객체에 항목 하나를 바로 넣어야 해요.
이 첫 항목은 플레이어 이름 `"The Best Ever"`와 점수 `1000000`으로 구성되어야 해요.

```jq
create_score_board
# returns an object with one initial entry
```

## 2. 점수판에 플레이어 추가하기

최고 점수판에 플레이어를 추가하려면 `add_player` 함수를 구현해요.
이 함수는 점수판을 입력으로 받고, 플레이어 이름과 플레이어의 점수라는 두 개의 매개변수가 필요해요.
이 함수는 새 플레이어가 추가된 점수판 객체를 출력해요.

```jq
{"José Valim", 486373}
| add_player("Dave Thomas"; 0)
# => {"Dave Thomas": 0, "José Valim": 486373} -- in some order
```

플레이어가 이미 점수판에 있다면, 점수판을 그대로 출력해요.

## 3. 점수판에서 플레이어 제거하기

플레이어가 오락실 규칙을 위반하면, 최고 점수판에서 직접 제거해요.
점수판을 입력으로 받고 제거할 플레이어의 이름을 매개변수 하나로 받는 `remove_player`를 구현해요.
이 함수는 주어진 플레이어의 항목을 점수판에서 제거하고 새 점수판을 출력해야 해요.
플레이어가 애초에 점수판에 없었다면 점수판에 아무 일도 일어나지 않아야 하고, 그대로 반환해야 해요.

```q
{"Dave Thomas": 0} | remove_player("Dave Thomas")
# => {}

{"Dave Thomas": 0} | remove_player("Rose Fanaras")
# => {"Dave Thomas": 0}
```

## 4. 플레이어 점수 올리기

플레이어가 오락실에서 게임을 하나 더 끝내면, 점수판에 있던 이전 점수에 일정량의 점수가 더해져요.
점수판을 입력으로 받고, 플레이어 이름과 더할 점수라는 두 개의 매개변수가 필요한 `update_score`를 구현해요.
이 함수는 업데이트가 끝난 뒤의 점수판을 반환해야 해요.

```jq
{"Freyja Ćirić": 12771000} | update_score("Freyja Ćirić"; 73)
# => {"Freyja Ćirić": 12771073}
```

이 함수는 플레이어가 아직 점수판에 없다면 점수판에 추가해야 해요.

## 5. 월요일 보너스 점수 적용하기

오락실은 월요일에 별도의 점수판을 운영해요.
하루가 끝나면 그 점수판에 있는 각 플레이어는 100점을 추가로 받아요.

`apply_monday_bonus` 함수를 구현해요.
이 함수는 그 점수판에 등록된 각 플레이어에게 보너스 점수를 더해요.

```jq
{
  "Dave Thomas": 44,
  "Freyja Ćirić": 539,
  "José Valim": 265
}
| apply_monday_bonus
# => {"Dave Thomas": 144, "Freyja Ćirić": 639, "José Valim": 365}
```

## 6. 총점 구하기

여러 오락실이 서로 경쟁해서 누가 최고의 플레이어를 가졌는지 겨뤄요.
총점이 가장 높은 오락실이 영예를 차지해요.

`total_score` 함수를 작성해요.
이 함수는 점수판을 입력으로 받고, 모든 플레이어 점수의 합을 출력해요.

```jq
{
  "Dave Thomas": 44,
  "Freyja Ćirić": 539,
  "José Valim": 265
}
| total_score
# => 848
```
