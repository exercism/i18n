# 제네릭 클래스

```sather
class LOST_BOX{T} is
   attr item : T;
   create(thing : T) : SAME is
      box ::= new;
      box.item := thing;
      return box;
   end;
end;
```

## 매개변수란 무엇인가요

`T`는 사용하는 지점에서 제공되는 타입을 나타내요. Sather는 프로그램이 컴파일될 때, 실제로 사용된 각 조합에 대해 별도의 클래스를 만들어요. 그래서:

- `LOST_BOX{STR}`과 `LOST_BOX{INT}`는 서로 관련 없는 타입이에요.
- 런타임 검사도 없고, 박싱도 없고, 변환도 없어요.
- 클래스에 있는 오류는 그것이 사용되는 각 타입마다 나타나요.

이것은 C++ 템플릿이나 Rust 제네릭과 같은 접근 방식이고, 타입이 지워지고 모든 것이 실제로는 객체인 Java 제네릭과는 달라요.

## 제약된 매개변수

제약 없는 `T`는 대입하고, 전달하고, 반환할 수 있어요. 그것 말고는 아무것도 할 수 없는데, 그것에 대해 알려진 정보가 없기 때문이에요. 그것에 대해 루틴을 호출하려면, 그것이 무엇에 부합해야 하는지 명시해야 해요:

```sather
class LOST_BOX{T < $STR} is
   describe : STR is return "a box holding " + item.str; end;
end;
```

`T < $STR`은 `T`가 `$STR`에 부합하도록 요구하고, 그 대신 `item.str`을 호출할 수 있게 해줘요. 제약 없는 `T`가 하지 못하는 일은 무엇이든 제약을 통해 가능하게 할 수 있어요.

제약이 없으면 `item.str`은 컴파일되지 않아요. 그리고 오류 메시지는 그것을 사용한 줄이 아니라 제네릭 클래스 내부의 줄을 가리켜요.

## 제네릭 루틴?

제네릭 루틴은 없어요. 매개변수를 받는 것은 클래스뿐이에요. 여러 타입에 걸쳐 동작해야 하는 루틴은 제네릭 클래스 안에 있거나, `$STR` 같은 추상 타입을 받아요.

## 둘 중에서 선택하기

| | 제네릭 클래스 | 추상 클래스 |
| --- | --- | --- |
| 결정 시점 | 컴파일할 때 | 실행할 때 |
| 담는 것 | 인스턴스화마다 한 가지 타입 | 부합하는 모든 타입 |
| 비용 | 없음 | 디스패치 한 번 |

`ARRAY{$ACT}`는 둘 다 사용해요. 원소 타입에 대해서는 제네릭이고, 그 원소가 무엇이 될 수 있는지에 대해서는 추상적이에요.

타입이 전체적으로 같고 클래스를 사용하는 쪽에서 그것을 알고 있다면 제네릭 클래스를 선택하는 게 좋아요. 여러 타입이 하나의 컬렉션 안에 함께 존재해야 한다면 추상 클래스를 선택하는 게 좋아요.
