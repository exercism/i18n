# 테스트

각 연습 문제에는 테스트 파일이 있어요.
`bats` 프로그램으로 테스트를 실행해요.

```bash
bats test-hello-world.bats
```

`bats`를 설치해야 해요.
시스템에 맞게 `bats`를 설치하는 방법은 [Bash 트랙의 테스트 안내][bash] 페이지를 참고하세요.

### bats는 bash로 구현되어 있어요

bats 파일은 bash 스크립트이고, `bats` 명령이 인식하는 몇 가지 특수 함수가 들어 있어요.
다음과 같은 테스트를 볼 수 있어요.

```sh
jq -f some-exercise.jq <<< "{some,json,here}"
```

그 `<<<` 문법은 bash의 [Here String][here-string]이에요.
오른쪽에 있는 문자열을 왼쪽에 있는 프로그램의 표준 입력으로 보내요.
아래 코드와 ([거의][so]) 같아요.

```sh
echo "{some,json,here}" | jq -f some-exercise.jq
```

## assert 함수 도움말

테스트는 [bats-assert][bats-assert] 라이브러리의 함수를 사용해요.
여러 `assert*` 함수에 대한 도움말은 그곳에서 찾을 수 있어요.

## 건너뛴 테스트

연습 문제를 푼다는 것은 모든 테스트를 통과시킨다는 뜻이에요.
기본적으로 테스트를 실행하면 첫 번째 테스트 하나만 실행돼요.
이는 의도된 것으로, 그 테스트 하나를 통과시키는 데만 집중할 수 있게 해줘요.
일단 통과하면, 다른 테스트 앞에 붙어 있는

    [[ $BATS_RUN_SKIPPED == true ]] || skip

주석을 제거하거나 주석 처리하면 다음 테스트를 활성화할 수 있어요.

## 건너뛰기 무시하기

`skip` 주석이 붙은 테스트를 포함해 모든 테스트를 실행하려면 다음을 실행해요:

```bash
BATS_RUN_SKIPPED=true bats test-some-exercise.bats
```

입력을 줄이려고 래퍼 함수를 쓰면 편리해요. `bash`에서는 이렇게 할 수 있어요:

```bash
bats() {
    BATS_RUN_SKIPPED=true command bats *.bats
}
```

그러면 이렇게만 실행하면 돼요:

```bash
bats
```

## `jq`에서 디버깅하기

`jq`에는 편리한 [`debug`][debug] 필터가 있어요.
연습 문제 풀이를 개발하는 동안 이 필터를 사용하면 현재 jq 파이프라인에 있는 데이터를 살펴볼 수 있어요.
더 자세한 내용은 [디버깅 문서][debugging]를 참고하세요.
