# 안내

이 연습 문제에서는 개발자가 식별자 이름을 정리하는 데 도움이 되는 유틸리티 함수 몇 개를 구현해요.

다섯 개의 과제를 통해 `clean` 함수를 차근차근 완성해 나가요.
올바른 식별자는 0개 이상의 문자와 밑줄로 이루어져 있어요.

`clean` 함수에 빈 문자열을 넘기면 빈 문자열을 반환해야 해요.

## 1. 공백을 밑줄로 바꾸기

`clean1` 함수를 구현해 모든 공백을 밑줄로 바꿔요. 문자열 앞뒤의 공백에도 똑같이 적용돼요.

```elm
clean1 "my   Id"
    --> "my___Id"
```

## 2. 제어 문자를 대문자 문자열 "[CTRL]"로 바꾸기

`clean2` 함수를 구현해 이전 함수가 하는 일을 모두 하면서, 흔히 쓰이는 제어 문자(\n, \t, \r)를 `"[CTRL]"` 문자열로 바꿔요.

```elm
clean2 "my\nId"
    --> "my[CTRL]Id",
```

## 3. 케밥 케이스를 카멜 케이스로 바꾸기

`clean3` 함수를 구현해 이전 함수가 하는 일을 모두 하면서 케밥 케이스를 카멜 케이스로 바꿔요.

```elm
clean3 "à-ḃç"
    --> "àḂç"
```

## 4. 숫자 생략하기

`clean4` 함수를 구현해 이전 함수가 하는 일을 모두 하면서 모든 숫자를 생략해요.

```elm
clean4 "123"
    --> ""
```

## 5. 그리스 소문자 생략하기

마지막으로 `clean` 함수를 구현해 이전 함수가 하는 일을 모두 하면서 'α'부터 'ω'까지의 그리스 문자를 생략해요.

```elm
clean "My Οβιεγτ Finder"
    --> "My_Ο_Finder"
```
