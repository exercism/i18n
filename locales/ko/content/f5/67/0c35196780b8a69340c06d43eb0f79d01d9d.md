# 지침 추가

## 구현

Pyret의 기초 단계 연습 문제 상당수는 `foo(1)` 형태의 [함수 적용 표현식]만으로도 풀 수 있어요. 하지만 이 연습 문제에서는 [점 표현식]으로 함수가 반환하는 값의 데이터 필드와 메서드 필드에 접근할 수 있기를 기대해요. 이때 [객체 표현식]을 사용하면 객체 리터럴의 필드에 접근할 수 있어요. [데이터 선언]은 이와 비슷하지만 데이터 필드와 메서드 필드도 함께 활용하는 더 고급 방법이에요.

[함수 적용 표현식]: https://pyret.org/docs/latest/Expressions.html#%28part._s~3aapp-expr%29
[점 표현식]: https://pyret.org/docs/latest/Expressions.html#%28part._s~3adot-expr%29
[객체 표현식]: https://pyret.org/docs/latest/Expressions.html#%28elem._%28bnf-prod._%28.Pyret._obj-expr%29%29%29
[데이터 선언]: https://pyret.org/docs/latest/s_declarations.html#%28part._s~3adata-decl%29
