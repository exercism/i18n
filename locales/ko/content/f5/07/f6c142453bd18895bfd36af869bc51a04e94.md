# 개요

*힙*은 가장 작은 항목(또는 가장 큰 항목)이 무엇인지 항상 알고 있고, 그것을 빠르게 꺼낼 수 있는 컬렉션이에요. *우선순위 큐*를 구현하는 자연스러운 방법이죠. 힙은 [`heaps`][heaps] 보캐뷸러리에 들어 있어요.

`<min-heap>`은 가장 작은 키가 먼저 나오는 빈 힙을 만들어요. `<max-heap>`은 가장 큰 키가 먼저 나오는 힙을 만들어요. 각 항목은 *키* 아래에 저장되는 *값*이고, 이 키가 Factor가 순서를 정하는 기준이 되는 우선순위예요.

```
<min-heap> ( -- min-heap )
<max-heap> ( -- max-heap )
heap-push  ( value key heap -- )
heap-push-all ( assoc heap -- )
```

```factor
USING: heaps ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
```

힙은 *변경 가능*해요. `heap-push`와 `heap-pop`은 힙을 제자리에서 바꿔요.

```
heap-peek    ( heap -- value key )
heap-pop     ( heap -- value key )
heap-pop-all ( heap -- alist )
heap-empty?  ( heap -- ? )
heap-size    ( heap -- n )
```

`heap-peek`은 맨 앞을 제거하지 않고 읽어요. `heap-pop`은 맨 앞을 제거해서 반환해요. `heap-pop-all`은 힙을 비우면서 우선순위 순서대로 `{ key value }` 쌍의 연관 리스트로 만들어요.

```factor
USING: assocs heaps kernel prettyprint ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
"carol" 9 pick heap-push
dup heap-pop .           ! => 2 "bob"   (removed; value then key)
heap-pop-all values .    ! => { "alice" "carol" }
```

푸시는 `O(log n)`이고 맨 앞을 읽는 것은 `O(1)`이에요. 그래서 "가장 급한 항목을 꺼내고, 그다음 더 넣기"를 반복해도 큐가 커져도 계속 빠른 속도를 유지해요. 구현은 크기를 늘릴 수 있는 배열에 저장되는 이진 힙이에요. 키로는 순서를 정할 수 있는 값이면 무엇이든 쓸 수 있어요(숫자, 문자열 등).
