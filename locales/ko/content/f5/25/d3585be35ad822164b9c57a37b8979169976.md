# 지시 사항

이 연습 문제에서는 [틱택토][tic-tac-toe] 게임의 상태를 판별하는 프로그램을 구현해요.
(_이 게임은 "noughts and crosses" 또는 "Xs and Os"라고도 불려요._)

이 게임은 3×3 격자 위에서 진행돼요.
플레이어는 번갈아 가며 격자에 `X`와 `O`를 놓아요.
한 플레이어가 가로, 세로, 대각선 중 한 줄에 표시 세 개를 나란히 놓아 이기거나, 격자가 전부 채워지면 게임이 끝나요.

이 연습 문제에서는 `X`가 먼저 시작한다고 가정해요.

주어진 게임이 어떤 상태인지 판별하는 것이 여러분이 할 일이에요.

게임 상태는 세 가지가 있을 수 있어요:

- 게임이 아직 진행 중(**ongoing**)이에요.
- 게임이 무승부(**draw**)로 끝났어요.
- 게임이 승리(**win**)로 끝났어요.

주어진 보드가 유효하지 않으면 적절한 오류를 던져요.

보드가 다음 조건에 해당하면 유효하지 않아요:

- 턴이 올바른 순서로 진행될 때 나올 수 없는 보드예요 (`X`가 먼저 시작한다는 걸 기억해요).
- 게임이 이미 끝난 뒤에도 계속 진행된 보드예요.

## 예시

### 진행 중인 게임

```text
   |   |
 X |   |
___|___|___
   |   |
   | X | O
___|___|___
   |   |
 O | X |
   |   |
```

### 무승부

```text
   |   |
 X | O | X
___|___|___
   |   |
 X | X | O
___|___|___
   |   |
 O | X | O
   |   |
```

### 승리

```text
   |   |
 X | X | X
___|___|___
   |   |
   | O | O
___|___|___
   |   |
   |   |
   |   |
```

### 유효하지 않은 경우

#### 잘못된 턴 순서

```text
   |   |
 O | O | X
___|___|___
   |   |
   |   |
___|___|___
   |   |
   |   |
   |   |
```

#### 승리 후 계속 진행한 경우

```text
   |   |
 X | X | X
___|___|___
   |   |
 O | O | O
___|___|___
   |   |
   |   |
   |   |
```
