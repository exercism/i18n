# 소개

Common Lisp에서는 함수가 값을 하나만 반환하는 게 아니라 여러 개의 값을 반환할 수도 있어요.
예를 들어 0을 향해 내림하는 `floor`는 두 개의 값을 반환하는데, 첫 번째는 내림한 값이고 두 번째는 나머지예요.

```lisp
(floor 3.5) ; => 3
            ;    0.5
```
(여러 개의 값이 반환될 때는 출력에서 각각 다른 줄에 보여줄게요.)

## 여러 개의 값 반환하기

함수가 여러 개의 값을 반환하게 하려면 `values` 접근자를 사용해요:

```lisp
(defun three-numbers () (values 1 2 3))
(three-numbers) ; => 1
                ;    2
                ;    3
```

## 여러 개의 값 다루기

첫 번째 값에만 관심이 있다면 특별히 해 줄 일은 없어요. 언어가 알아서 처리해 줘요:

```lisp
(+ (values 1 2 3) (values 10 20 30)) ; => 11
```

하지만 나머지 값에도 접근하고 싶다면 사용해야 하는 함수가 몇 개 있어요.
대표적인 매크로 두 가지가 `multiple-value-list`와 `multiple-value-bind`예요.
이 둘은 여러 개의 값을 반환하는 무언가를 감싸서 그 값들을 모두 붙잡는 데 사용해요.
첫 번째는 모든 값으로 이루어진 배열을 만들어요.
두 번째는 각각의 값에 변수를 묶을 수 있게 해줘요.

```lisp
(multiple-value-list (values 1 2 3))                   ; => (1 2 3)
(multiple-value-bind (a b c) (values 1 2 3) 
   (+ a b c)) ; => 6
```

또 하나의 유용한 함수는 `nth-value`예요
