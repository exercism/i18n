# 지침 추가

## 그리드 형식

그리드는 null로 끝나는 문자열로 표현하며, 각 행의 끝에는 줄 바꿈 문자가 있어요.

## 레지스터

| 레지스터 | 용도       | 타입   | 설명                                                                    |
| -------- | ---------- | ------ | ----------------------------------------------------------------------- |
| `$a0`    | 입력       | 주소   | null로 끝나는 입력 문자열                                                |
| `$a1`    | 입력/출력  | 주소   | null로 끝나는 결과 문자열, 그리드 크기가 유효하지 않으면 비어 있음        |
| `$v0`    | 출력       | 정수   | 그리드 상태 (`0` = `ok`, `-1` = `invalid columns`, `-2` = `invalid rows`) |
| `$t0-9`  | 임시       | 아무 값 | 임시 저장용                                                              |
