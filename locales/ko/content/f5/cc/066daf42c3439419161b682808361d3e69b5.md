# 코드 작성하기

`<exercise_name>.zig` 파일에 코드를 작성해요.
연습 문제 중에는 [상수][constants], [함수][functions], [가져오기][imports], [구조체][structs] 같은 특정 Zig 구문에 대한 시그니처가 미리 작성되어 있는 경우도 있고, [그 밖에도 여러 가지][et-cetera]가 있을 수 있어요!

이렇게 미리 작성된 시그니처는 명확한 출발점을 제공해서 연습 문제를 완료하는 데 도움을 주기 위한 것이에요.
하지만 꼭 이 시그니처에서 시작해야 하는 것은 아니에요.
특히 테스트만 통과한다면 어떤 코드든 완벽하게 괜찮은 해답이니까요.

## 테스트 실행하기

테스트를 실행하려면 다음 명령어만 실행하면 돼요:

```bash
zig test test_exercise_name.zig
```

`exercise_name` 부분은 연습 문제의 이름으로 바꿔 주세요.
위 명령어는 연습 문제의 루트 디렉터리에서 실행해야 해요. 테스트 파일도 같은 위치에 있어야 하거든요.
또한 어떤 연습 문제든 모든 테스트는 기본적으로 활성화되어 있고, 건너뛸 수 있는 테스트는 없어요.

모든 테스트가 이렇게 되어 있기 때문에, 테스트를 하나씩 확인하고 싶다면 통과하지 못한 테스트를 [주석 처리][comments]해야 해요.
테스트를 주석 처리하는 방법은 각 줄을 `//`로 시작하면 될 만큼 간단해요.
반대로 내 해답이 테스트를 통과할 자신이 있다면, 주석을 해제해서 실제로 통과하는지 확인할 수 있어요.
