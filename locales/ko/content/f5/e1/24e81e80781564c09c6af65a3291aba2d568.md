# 지침

서로 다른 두 인터널 테이블의 데이터를 하나의 결과 인터널 테이블로 결합하는 방법을 배워봐요.

여러분의 클래스에는 완전히 다른 두 데이터 집합인 ALPHAS와 NUMS를 담은 두 개의 인터널 테이블이 주어져요.

```abap
TYPES: BEGIN OF alphatab_type,
         cola TYPE string,
         colb TYPE string,
         colc TYPE string,
       END OF alphatab_type.
TYPES: alphas TYPE STANDARD TABLE OF alphatab_type.
TYPES: BEGIN OF numtab_type,
         col1 TYPE string,
         col2 TYPE string,
         col3 TYPE string,
       END OF numtab_type.
TYPES: nums TYPE STANDARD TABLE OF numtab_type.
```

ALPHA 테이블의 데이터는 아래와 같아요.

| COLA | COLB | COLC |
| --- | --- | --- |
| A | B | C | 
| D | E | F |
| G | H | I |

NUMS 테이블의 데이터는 아래와 같아요.

| COL1 | COL2 | COL3 |
| --- | --- | --- |
| 1 | 2 | 3 | 
| 4 | 5 | 6 |
| 7 | 8 | 9 |

여러분의 과제는 인터널 테이블 ALPHAS와 인터널 테이블 NUMS의 각 셀 값을 서로 결합한 레코드로 이루어진 인터널 테이블을 반환하는 거예요. 예를 들어 COMBINED_DATA 인터널 테이블의 첫 번째 행, 첫 번째 열의 값은 "A1"이 되어야 해요.

반환해야 할 테이블은 다음과 같이 정의되어 있어요.

```abap
TYPES: BEGIN OF combined_data_type,
         colx TYPE string,
         coly TYPE string,
         colz TYPE string,
       END OF combined_data_type.
TYPES: combined_data TYPE STANDARD TABLE OF combined_data_type WITH EMPTY KEY.
```
