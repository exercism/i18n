# 소개

Elixir의 [문자열][getting-started-strings]은 큰따옴표로 구분하고, UTF-8로 인코딩해요:

```elixir
"Hi!"
```

문자열은 [`<>/2`][kernel-concat] 연산자로 이어 붙일 수 있어요:

```elixir
"Welcome to" <> " " <> "New York"
# => "Welcome to New York"
```

Elixir의 문자열은 `#{}` 문법으로 [문자열 보간][string-interpolation]을 지원해요:

```elixir
"6 * 7 = #{6 * 7}"
# => "6 * 7 = 42"
```

보간 안에는 어떤 Elixir 표현식이든 쓸 수 있어요. 문자열이 주어지면 그대로 보간돼요. 다른 값이 주어지면 Elixir가 그 값을 문자열로 변환하려고 시도해요.

```elixir
"Elixir can convert booleans to strings: #{true}"
# => "Elixir can convert booleans to strings: true"

"And #{["lists", ", ", "too!"]}"
# => "And lists, too!"

"But not functions: #{fn x -> x end}"

# => ** (Protocol.UndefinedError) protocol String.Chars not implemented for #Function<7.126501267/1 in :erl_eval.expr/5> of type Function
#        (elixir 1.10.1) lib/string/chars.ex:3: String.Chars.impl_for!/1
#        (elixir 1.10.1) lib/string/chars.ex:22: String.Chars.to_string/1
```

Elixir는 `String` 모듈에서 문자열을 다루는 다양한 함수를 제공해요. 문자열을 필요한 방식으로 처리하는 방법이 확실하지 않다면, [`String` 모듈에서 사용할 수 있는 함수][string-module-functions]를 꼭 살펴봐요. 그러면 필요한 것을 거의 다 찾을 수 있을 거예요.

```elixir
String.downcase("PLEASE NO SHOUTING")
# => "please no shouting"

String.split("hello", "", trim: true)
# => ["h", "e", "l", "l", "o"]

String.replace("Do I enjoy Elixir? Maybe...", "Maybe...", "Definitely!")
# => "Do I enjoy Elixir? Definitely!"

String.at("12345", 2)
# => "3"
```

이런 함수를 사용할 때는 문자열의 첫 번째 문자가 인덱스 `0`이라는 점을 기억해요.

어떤 문자는 문자열에 넣으려면 [이스케이프][escape-characters]해야 해요. 예를 들어 줄바꿈, 큰따옴표, `#` 문자 같은 것들이에요:

```elixir
"\"A\" is the \#1st letter of the alphabet.\n"
```

줄바꿈이 많은 텍스트를 편하게 다루려면, 대신 [큰따옴표 세 개를 쓰는 히어독 문법][heredoc-syntax]을 사용해요:

```elixir
"""
1
2
3
"""
```

이 문법은 코드를 문서화할 때 아주 자주 볼 수 있어요:

```elixir
defmodule MyApp.Hello do
  @moduledoc """
  This is the Hello module.
  """

  @doc """
  Says hello to the given `name`.

  Returns `:ok`.

  ## Examples

      iex> MyApp.Hello.world(:john)
      :ok

  """
  def world(name) do
    IO.puts("hello #{name}")
  end
end
```
