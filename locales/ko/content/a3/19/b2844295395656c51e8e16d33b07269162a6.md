# 안내

이 연습 문제에서는 고전 게임 팩맨의 규칙 몇 가지를 Unison 함수로 옮겨야 해요.

옮겨야 할 규칙은 네 가지이고, 모두 게임 상태와 관련되어 있어요.

> 인자가 어떻게 만들어지는지는 걱정하지 말고, 인자들을 조합해 원하는 결과를 반환하는 데만 집중해요.

## 1. 팩맨이 유령을 먹는지 정의해요

`pacmanRules.eatGhost` 함수는 인자 두 개(_팩맨이 파워 펠릿을 활성화했는지_, _팩맨이 유령과 닿아 있는지_)를 받아, 팩맨이 유령을 먹을 수 있는지를 나타내는 불리언 값을 반환해요. 이 함수는 팩맨이 파워 펠릿을 활성화했고 유령과 닿아 있을 때에만 true를 반환해야 해요.

```unison
pacmanRules.eatGhost: Boolean -> Boolean -> Boolean

```

## 2. 팩맨이 점수를 얻는지 정의해요

`pacmanRules.score` 함수는 인자 두 개(_팩맨이 파워 펠릿과 닿아 있는지_, _팩맨이 점과 닿아 있는지_)를 받아, 팩맨이 점수를 얻었는지를 나타내는 불리언 값을 반환해요. 이 함수는 팩맨이 파워 펠릿이나 점과 닿아 있으면 true를 반환해야 해요.

```haskell
pacmanRules.score: Boolean -> Boolean -> Boolean
pacmanRules.score powerPelletActive touchingDot =
  todo "implement score"
```

## 3. 팩맨이 지는지 정의해요

`pacmanRules.lose` 함수는 인자 두 개(_팩맨이 파워 펠릿을 활성화했는지_, _팩맨이 유령과 닿아 있는지_)를 받아, 팩맨이 지는지를 나타내는 불리언 값을 반환해요. 이 함수는 팩맨이 유령과 닿아 있고 파워 펠릿을 활성화하지 않았으면 true를 반환해야 해요.

```unison
pacmanRules.lose : Boolean -> Boolean -> Boolean
pacmanRules.lose powerPelletActive touchingGhost =
  todo "implement lose"
```

## 4. 팩맨이 이기는지 정의해요

`pacmanRules.win` 함수는 인자 세 개(_팩맨이 점을 모두 먹었는지_, _팩맨이 파워 펠릿을 활성화했는지_, _팩맨이 유령과 닿아 있는지_)를 받아, 팩맨이 이기는지를 나타내는 불리언 값을 반환해요. 이 함수는 팩맨이 점을 모두 먹었고 3번에서 정의한 인자에 따라 지지 않았다면 true를 반환해야 해요.

```unison
pacmanRules.win : Boolean -> Boolean -> Boolean -> Boolean
pacmanRules.win eatenAll powerPelletActive touchingGhost
  todo "implement Rules.win"
```
