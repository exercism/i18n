# 소개

## 문자열

Elixir의 문자열은 큰따옴표로 감싸고, UTF-8로 인코딩해요:

```elixir
"Hi!"
```

`<>/2` 연산자로 문자열을 이어 붙일 수 있어요:

```elixir
"Welcome to" <> " " <> "New York"
# => "Welcome to New York"
```

Elixir의 문자열은 `#{}` 문법으로 값을 끼워 넣을 수 있어요:

```elixir
"6 * 7 = #{6 * 7}"
# => "6 * 7 = 42"
```

문자열에 줄바꿈 문자를 넣으려면 `\n` 이스케이프 코드를 사용해요:

```elixir
"1\n2\n3\n"
```

줄바꿈이 많은 텍스트를 편하게 다루려면, 대신 큰따옴표 세 개로 이루어진 히어독 문법을 사용해요:

```elixir
"""
1
2
3
"""
```

Elixir는 `String` 모듈에서 문자열을 다루는 다양한 함수를 제공해요.

## 파이프 연산자

`|>` 연산자를 파이프 연산자라고 해요. 이 연산자를 사용하면 함수 호출을 이어 붙일 수 있는데, 앞 함수 호출이 반환한 값이 다음 함수 호출의 첫 번째 인자로 전달돼요.

```elixir
"hello"
|> String.upcase()
|> Kernel.<>("?!")

# => "HELLO?!"
```
