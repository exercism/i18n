# 2진수, 8진수, 16진수

2진수, 8진수, 16진수(_hex라고도 해요_)는 밑이 서로 다른 [진법][numeral-systems]이에요.
2진수는 밑이 2이고, 8진수는 밑이 8, 16진수는 밑이 16이에요.
Crystal에서 일반적인 정수는 밑이 10이에요.
2진수, 8진수, 16진수는 모두 정수를 나타내는 표현 방식이에요.
즉, 분수나 소수 없이 양수와 음수(_0 포함_)를 표현하고, 정수로 할 수 있는 모든 연산을 지원해요.

## 2진수

[2진수][binary]는 숫자 0과 1만 사용하는 밑이 2인 진법이에요.
컴퓨터의 트랜지스터와 스위치를 흐르는 전류의 0("꺼짐")과 1("켜짐") 상태, 그리고 자기 저장 매체의 양전하와 음전하를 흔히 나타내요.
2진수는 밑이 10인 체계에서 사용하는 모든 정수를 표현할 수 있어요.

밑이 2인 체계의 일부를 보면 다음과 같아요. 다만 이 체계는 128에서 멈추지 않고 무한히 이어져요:

| 128      | 64       | 32       | 16       | 8        | 4        | 2        | 1        |
| -------- | -------- | -------- | -------- | -------- | -------- | -------- | -------- |
| 2 \*\* 7 | 2 \*\* 6 | 2 \*\* 5 | 2 \*\* 4 | 2 \*\* 3 | 2 \*\* 2 | 2 \*\* 1 | 2 \*\* 0 |

그래서 숫자 6을 표현하려면 2진수로는 110이 돼요:

| Place value   | 4   | 2   | 1   |
| ------------- | --- | --- | --- |
| Binary number | 1   | 1   | 0   |

계산은 이렇게 해요: `4 + 2 + 0 = 6`

또 다른 예로 19를 보면 다음과 같아요:

| Place value   | 16  | 8   | 4   | 2   | 1   |
| ------------- | --- | --- | --- | --- | --- |
| Binary number | 1   | 0   | 0   | 1   | 1   |

2진수로는 10011이에요.
계산은 이렇게 해요: `16 + 0 + 0 + 2 + 1 = 19`

## Crystal에서의 2진수

Crystal에서는 `0b` 접두사를 사용해 2진수 리터럴을 표현할 수 있어요.
`0b10011`이라고 쓰면 Crystal은 이를 2진수로 해석해 밑이 10인 수로 변환해요.

```crystal
0b10011
# => 19

typeof(0b10011)
# => Int32
```

`0b` 접두사를 붙인 수에 2진법에 없는 숫자가 있으면 컴파일 오류가 발생해요.

```crystal
0b10211
# => Error: unexpected token: "211"
```

### 2진수 연산

2진수는 정수이므로, 정수로 할 수 있는 모든 연산을 2진수에도 할 수 있어요.

```crystal
0b10011 + 0b10011
# => 38

0b10011 * 0b10011
# => 361

0b10011 / 3
# => 6.333333333333333
```

### 2진수 표현으로 변환하기

Crystal은 2진수 리터럴을 자동으로 `Int32`로 변환해요.
`Int32`를 2진수 표현으로 변환하려면 [`<int>.to_s(base)`][to_s] 메서드에 base 인자를 2로 지정해서 사용해요.
이 메서드는 2진수를 문자열로 표현한 값을 반환해요:

```crystal
19.to_s(2)
# => "10011"
```

2진수를 나타내는 문자열을 정수로 변환하려면 [`<int>.to_i(base)`][to_i] 메서드에 밑(2)을 인자로 넘겨서 사용할 수 있어요:

```crystal
"10011".to_i(2)
# => 19
```

밑을 잘못 지정하거나 (_유효하지 않은 2진수 표현을 지정하면_) `ArgumentError`가 발생해요:

```crystal
"011021".to_i(2)
# => Invalid Int32: "011021" (ArgumentError)
```

### 2진수 관련 메서드

정수에 사용해서 그 수의 2진수 표현에 대한 정보를 얻을 수 있는 메서드들이 있어요.

[`<int>.bit_length`][bit_length]는 수를 표현하는 데 필요한 비트 수를 반환해요:

```crystal
19.bit_length
# => 5
```

[`<int>.bit(index)`][bit]는 오른쪽(_최하위 비트_)부터 세어 주어진 인덱스에 있는 비트를 반환해요:

```crystal
19.bit(0)
# => 1

0b10011.bit(1)
# => 1
```

## 8진수

[8진수][octal]는 밑이 8인 진법이에요.
숫자 0, 1, 2, 3, 4, 5, 6, 7을 사용해요.

Crystal에서는 `0o` 접두사를 사용해 8진수를 표현할 수 있어요.
2진수와 마찬가지로, Crystal은 8진수 표현을 자동으로 `Int32`로 변환해요.

```crystal
0o123
# => 83
```

8진법에 없는 숫자에 `0o`를 붙이면 컴파일 오류가 발생해요.

### 8진수 표현으로 변환하기

2진수와 마찬가지로, [`<int>.to_s(base)`][to_s] 메서드를 사용해 `Int32`를 8진수 표현으로 변환할 수 있어요.
그리고 [`<int>.to_i(base)`][to_s] 메서드를 사용해 8진수 표현을 `Int32`로 변환할 수 있어요.

```crystal
83.to_s(8)
# => "123"

"123".to_i(8)
# => 83
```

2진수와 마찬가지로, 밑을 잘못 지정하면 `ArgumentError`가 발생해요.

## 16진수

[16진수][hexadecimal]는 밑이 16인 진법이에요.
숫자 0 - 9와 문자 A, B, C, D, E, F를 사용해요.
A는 10, B는 11, C는 12, D는 13, E는 14, F는 15예요.

Crystal에서는 `0x` 접두사를 사용해 16진수를 표현할 수 있어요.
2진수와 8진수와 마찬가지로, Crystal은 16진수 리터럴을 자동으로 `Int32`로 변환해요.

```crystal
#=> 0x123
291
```

16진법이 아닌 숫자에 `0x`를 붙이면 컴파일 오류가 발생해요.

### 16진수 표현으로 변환하기

2진수와 마찬가지로, [`<int>.to_s(base)`][to_i] 메서드를 사용해 `Int32`를 16진수 표현으로 변환할 수 있어요.
그리고 [`<int>.to_i(base)`][to_s] 메서드를 사용해 16진수 표현을 `Int32`로 변환할 수 있어요.

```crystal
291.to_s(16)
# => "123"

"123".to_i(16)
# => 291
```

2진수와 8진수와 마찬가지로, 밑을 잘못 지정하면 `ArgumentError`가 발생해요.

## 정밀도

수를 문자열 표현으로 변환할 때, 그 수의 정밀도를 지정할 수 있어요.
정밀도란 수를 표현하는 데 사용하는 숫자의 **최소** 개수를 뜻해요.
수의 자릿수가 정밀도보다 적으면 문자열 표현 앞에 0이 채워져요.
이는 [`<int>.to_s(<base>, precision: <value>)`][to_s] 메서드에 `precision` 인자를 넘겨서 해요.

```crystal
291.to_s(16, precision: 5)
# => "00123"

543.to_s(precision: 2)
# => "543"
```
