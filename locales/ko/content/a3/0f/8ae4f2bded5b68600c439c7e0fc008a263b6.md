# 소개

## 구조체 타입

구조체 타입은 이미 살펴봤어요. 복습하자면 `struct`는 _필드_라고 하는 이름 붙은 요소들의 나열이고, 각 필드는 이름과 타입을 가져요.
필드의 이름은 구조체 안에서 유일해야 해요.
구조체는 객체 지향 프로그래밍 패러다임의 _클래스_에 견줄 수 있어요.

`type`과 `struct` 키워드를 사용해 새로운 구조체를 만들고, 아래 예제처럼 필드의 이름과 타입을 직접 정의해요.

```go
type StructName struct{
    field1 fieldType1
    field2 fieldType2
}
```

## 구조체가 아닌 타입

내장 타입 선언의 별칭으로 쓸 수 있는, 구조체가 아닌 타입도 정의할 수 있어요.

```go
type Name string
func SayHello(n Name) {
  fmt.Printf("Hello %s\n", n)
}
n := Name("Fred")
SayHello(n)
// Output: Hello Fred
```

배열과 맵으로 구성된 구조체가 아닌 타입도 정의할 수 있어요.

```go
type Names []string
func SayHello(n Names) {
  for _, name := range n {
    fmt.Printf("Hello %s\n", name)
  }
}
n := Names([]string{"Fred", "Bill"})
SayHello(n)
// Output:
// Hello Fred
// Hello Bill
```
