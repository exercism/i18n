# 개요

딕셔너리는 다른 언어의 맵이나 연관 배열 같은 것들과 마찬가지로 키/값 쌍을 저장하고, 키를 딕셔너리의 인덱서 속성에 넘기면 값을 바로 가져오거나 바꿀 수 있어요.

키/값 쌍은 딕셔너리에 추가하거나 제거할 수도 있어요. 키, 값, 키/값 쌍을 각각 열거할 수 있어요.

값은 기본형, 구조체 _그리고_ 클래스를 포함해 어떤 C# 타입의 객체든 될 수 있어요.

딕셔너리 객체는 키가 어떤 타입의 객체든 될 수 있게 해줘요. 다만 런타임에 올바르게 동작하게 하려면 키가 [GetHashCode][gethashcode]가 반환하는 적절한 해시코드를 가지고 있어야 해요.

딕셔너리 인스턴스는 여러 스레드에서 안전하게 접근할 수 없어요(스레드 안전하지 않아요). 다중 스레드 상황에서는 [ConcurrentDictionary][concurrent-dictionary]를 사용할 수 있어요.

[HashSet][hashset], [ConcurrentDictionary][concurrent-dictionary], [SortedDictionary][sorted-dictionary]도 참고해 보세요.

딕셔너리에는 비제네릭 버전이 없지만, 라이브러리에는 비제네릭 맵을 지원하는 여러 클래스가 남아 있어요. 비제네릭 IDictionary와 Hashtable을 알아 두면 나중에 마주쳤을 때 알아볼 수 있으니, 주로 그 정도로 알고 있으면 돼요. 오래된 코드베이스를 유지보수할 때 말고는 이것들을 쓸 일이 거의 없어요.

딕셔너리를 [`IDictionary<TKey, TValue>`][idictionary] 인터페이스로 노출해서 접근하고 싶은 경우가 많아요.

[인덱서 속성][indexer-properties]의 특성상 기본형 값은 다음과 같이 제자리에서 수정할 수 있어요:

```csharp
nums["some-number"] = 3;
nums["some-number"]++;
// nums["some-number"] == 4

```
