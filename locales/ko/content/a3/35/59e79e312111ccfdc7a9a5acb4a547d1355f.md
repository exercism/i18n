# 지침

이 연습 문제에서는 롤플레잉 게임의 메커니즘을 구현해요.
플레이어의 캐릭터는 다음 타입으로 표현돼요:

```fsharp
type Player = {
    Name: string option
    Level: int
    Health: int
    Mana: int option
}
```

이 게임의 플레이어는 주문을 시전하려면 먼저 레벨 10에 도달해 마나 풀을 잠금 해제해야 해요.
이 게임에서는 부활 메커니즘과 주문 시전 메커니즘, 이렇게 두 가지 기능을 다뤄요.

## 1. 자기소개하기

`introduce` 함수의 내용을 작성해요.
`Player` 레코드의 `Name` 필드는 `Option` 타입이라는 점에 주의해요.
은신형 플레이어는 이름을 `None`으로 두어 숨기고 싶어 할 수도 있는데, 이런 플레이어는 `"Mighty Magician"`으로 소개돼요.
그렇지 않다면 그냥 자신의 이름으로 소개해요.

```fsharp
introduce { Name = None; Level = 2; Health = 8; Mana = None }
    --> "Mighty Magician"

introduce { Name = Some "Merlin"; Level = 2; Health = 8; Mana = None }
    --> "Merlin"
```

## 2. 부활 메커니즘 구현하기

`revive` 함수는 플레이어의 캐릭터가 실제로 죽었는지, 즉 체력이 0이 되었는지 확인해야 해요.
죽었다면 체력이 100인 새로운 `Player` 인스턴스를 반환해야 해요.
그렇지 않고 플레이어의 캐릭터가 죽지 않았다면 `revive` 함수는 `None`을 반환해요.

플레이어의 레벨이 10 이상이면 마나 100을 가진 상태로 부활해야 해요.
플레이어의 레벨이 10 미만이면 마나는 `None`이어야 해요.
`revive` 함수는 플레이어의 레벨을 그대로 유지해야 해요.

```fsharp
let deadPlayer = { Name = None; Level = 2; Health = 0; Mana = None }

revive deadPlayer
    --> Some { Name = None; Level = 2; Health = 100; Mana = None }
```

체력이 1 이상인 플레이어에 대해 `revive` 메서드를 호출하면 함수는 `None`을 반환해야 해요.

```fsharp
let alivePlayer = { Name = None; Level = 2; Health = 42; Mana = None }

revive alivePlayer
    --> None
```

## 3. 주문 시전 메커니즘 구현하기

`castSpell` 함수는 주문에 드는 마나의 양을 나타내는 `int`와 `Player`를 인자로 받아요.
그리고 갱신된 플레이어와 시전한 주문이 입히는 피해량을 반환해요.
주문 시전에 성공하면 주문의 마나 비용의 두 배에 해당하는 피해를 입혀요.
하지만 플레이어의 마나가 부족하면 아무 일도 일어나지 않고, 플레이어는 그대로이며 피해도 입히지 않아요.
플레이어에게 마나 풀조차 없다면, 주문을 시전하려고 할 때 주문의 마나 비용만큼 체력이 감소해야 하며 피해는 입히지 않아요.

```fsharp
let wizard = { Name = None; Level = 18; Health = 123; Mana = Some 30 }

let updatedWizard, damage = castSpell 14 wizard

updatedWizard.Mana --> Some 16
damage             --> 28
```
