# 안내

지난 7일 동안 정원에 몇 마리의 새가 찾아왔는지 기록하는 열정적인 새 관찰자예요.

정원에 찾아온 새의 수를 다루는 여섯 개의 과제가 있어요.

## 1. 지난주 기록이 어땠는지 확인해요

비교를 위해 지난주 기록을 항상 가까이에 두는데, 그 기록은 0, 2, 5, 3, 7, 8, 4였어요. 지난주 기록을 담은 벡터를 만들어 보세요:

```clojure
last-week
;;=> [0 2 5 3 7 8 4]
```

## 2. 오늘 몇 마리의 새가 찾아왔는지 확인해요

`today` 함수를 구현해서 오늘 정원에 찾아온 새의 수를 반환해 보세요. 새의 수는 날짜 순서대로 정렬되어 있고, 첫 번째 원소는 가장 오래된 날의 수, 마지막 원소는 오늘의 수예요.

```clojure
(def birds-per-day [2 5 0 7 4 1])
(today birds-per-day)
;;=> 1
```

## 3. 오늘의 수를 하나 늘려요

`inc-bird` 함수를 구현해서 오늘의 수를 하나 늘려 보세요:

```clojure
(inc-bird birds-per-day)
;;=> [2 5 0 7 4 2]
```

## 4. 새가 찾아오지 않은 날이 있었는지 확인해요

`day-without-birds?` 조건 판별 함수를 구현해 보세요. 정원에 새가 한 마리도 찾아오지 않은 날이 있었다면 `true`를, 그렇지 않으면 `false`를 반환해요:

```clojure
(day-without-birds? birds-per-day)
;;=> true
```

## 5. 처음 며칠 동안 찾아온 새의 수를 계산해요

`n-days-count` 함수를 구현해 보세요. 이 함수는 주가 시작된 이후 정원에 찾아온 새의 수를 반환하는데, 세는 범위를 주가 시작된 날부터 지정한 일수까지만으로 제한해요.

```clojure
(n-days-count birds-per-day 4)
;;=> 14
```

## 6. 바쁜 날의 수를 계산해요

어떤 날은 다른 날보다 더 바빠요. 바쁜 날은 정원에 다섯 마리 이상의 새가 찾아온 날이에요.
`busy-days` 함수를 구현해서 바쁜 날의 수를 반환해 보세요:

```clojure
(busy-days birds-per-day)
;;=> 2
```

## 7. 홀수 주인지 확인해요

지난 한 해 동안, 어떤 주들은 새가 한 마리 찾아오는 날과 한 마리도 찾아오지 않는 날이 번갈아 나타나는, 똑같은 홀수 패턴을 보인다는 걸 알게 됐어요. `odd-week?` 함수를 구현해서 이번 주의 새 수 패턴이 그 홀수 패턴과 일치하면 `true`를 반환해 보세요:

```clojure
(odd-week? [1 0 1 0 1 0 1])
;;=> true
```
