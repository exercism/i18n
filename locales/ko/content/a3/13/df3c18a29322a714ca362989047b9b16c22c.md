# 함수

JavaScript에서 함수는 _일급 객체_예요. 즉, 함수는 변수와 속성에 할당할 수 있고, 다른 함수에 전달할 수 있으며, 함수에서 반환할 수도 있어요. 다른 _객체_와 마찬가지로 속성과 메서드를 가질 수 있어요.

## 입력: 인자 전달

JavaScript 함수는 호출할 때 인자를 전달할 수 있어요. 인자는 항상 [값으로 전달](https://dev.to/xpbytes/javascript-ruby-and-c-are-not-call-by-reference-23f7)돼요. 다시 말해, 함수 안에서 매개변수에 값을 다시 할당해도 함수 밖의 값은 바뀌지 않아요. 그렇다고 해서 전달된 객체를 변경할 수 없다는 뜻은 아니에요.

> [!TIP]
> 객체를 전달하면 그 객체에 대한 참조가 값으로 전달돼요. 그래서 객체를 전달하는 경우에는 다르게 처리되는 것처럼 _보이지만_, 실제로는 그렇지 않아요.

인자를 두 개 받아서 곱하는 함수의 예시는 다음과 같아요:

```javascript
function multiply(a, b) {
  return a * b;
}

multiply(2, 3);
// => 6
```

## 출력: 반환 값

JavaScript에서는 `return` 키워드 뒤에 표현식을 써서 함수에서 값을 하나 반환할 수 있어요. 함수에서 아무것도 반환하지 않으면 반환되는 값은 `undefined`예요.

값을 반환하는 함수의 예시는 다음과 같아요:

```javascript
function multiply(a, b) {
  return a * b;
}

multiply(2, 3);
// => 6
```

## 함수 정의하기

JavaScript에는 네 가지 종류의 함수가 있어요:

1. 무엇이든 반환할 수 있고 항상 끝까지 실행되는 일반 함수.
2. 항상 `Promise`를 반환하고 `await` 연산자로 일시 중지했다가 다시 실행할 수 있는 비동기 함수.
3. 항상 `Generator` 객체를 반환하고 `yield` 연산자로 일시 중지했다가 다시 실행할 수 있는 제너레이터 함수.
4. 항상 `AsyncGenerator` 객체를 반환하고 `yield`와 `await` 연산자 _둘 다_로 일시 중지했다가 다시 실행할 수 있는 비동기 제너레이터 함수.

이 네 가지 종류는 각각 세 가지 방법으로 정의할 수 있어요:

1. 선언문 사용하기
2. 표현식 사용하기
3. 생성자 사용하기

마지막으로, _화살표 함수와 메서드_를 정의하는 특별한 문법도 있어요.
