# 소개

## 가져오기

Swift는 표준 라이브러리에서 풍부한 기능을 제공하지만, 외부 라이브러리와 프레임워크를 가져오면 훨씬 다양한 기능을 사용할 수 있어요.
이런 모듈은 Swift 프로젝트에서 직접 제공되기도 하고([Swift Argument Parser][argument-parser]처럼), Apple 플랫폼 프레임워크에서 오기도 하며([Foundation][apple-foundation]과 [Network Framework][network-framework]처럼), 서드파티 오픈 소스 라이브러리에서 올 수도 있어요([SwiftyBeaver][swifty-beaver]처럼).

Foundation처럼 Swift에서 가장 널리 쓰이는 라이브러리 중 하나인 핵심 모듈은 Swift 툴체인에 함께 포함되어 있어요.
서드파티 라이브러리는 프로젝트 설정에 추가해야 가져올 수 있어요 (예를 들어 Swift Package Manager를 사용해서요).

모듈을 가져올 때는 `import` 키워드 뒤에 모듈 이름을 써요.
예를 들어 Foundation은 프로그램에 다음을 추가해서 가져올 수 있어요.

```swift
import Foundation
```

모듈을 가져오면 그 모듈의 타입과 메서드, 함수를 코드에서 사용할 수 있어요.
예를 들어 Foundation을 가져오면 `String`에 `components(separatedBy:)` 같은 유용한 유틸리티 메서드가 추가돼요.

관례적으로 `import` 문은 Swift 파일 맨 위에 두어서, 코드를 읽는 사람이 의존성을 바로 확인할 수 있게 해요.

## 문자열 인덱싱

`String`의 개별 문자는 배열에서 쓰는 것과 같은 서브스크립트 방식으로 접근할 수 있어요.
하지만 문자열에 쓰이는 [인덱스][string-indices]는 정수가 아니어서 정수처럼 직접 다룰 수 없어요.
대신 비어 있지 않은 문자열에서 첫 번째 문자의 위치를 가리키는 `startIndex`처럼 이미 알고 있는 다른 인덱스를 기준으로, [`String`][string-docs]과 [`NSString`][nsstring-docs] 라이브러리에서 제공하는 메서드를 사용해 계산해야 해요 (`Foundation` 모듈을 가져오면 Swift의 문자열에서 모든 NSString 속성과 메서드에 접근할 수 있어요).

예를 들어 다음 문자열이 있다고 해봐요.

```swift
let csv = "apple,pear,peach,orange,cherry,lime,goosberry"
```

"orange"의 "g"를 얻으려고 `csv[21]`이라고 쓸 수는 없어요. 대신 `String.Index` 타입의 값을 계산해서 그 인덱스를 넘겨야 해요.
이 인덱스들은 그 자체로 사람이 읽고 쓰도록 만든 값이 아니에요.
사람이 그 안에 무엇이 들어 있는지 알 필요가 없는, 이른바 _불투명 인덱스_예요.

```swift
let index = csv.index(csv.startIndex, offsetBy: 21)
csv[index]
// "g"
print(index)
// prints Index(_rawBits: 1376513)
```

그런데 오프셋이 유효한 인덱스가 아니면, 그러니까 `startIndex`보다 앞이거나 `endIndex`보다 뒤의 인덱스를 가리키면 오류가 발생해서 프로그램이 중단돼요.
이 문제를 막으려면 제한 인덱스를 지정할 수 있어요.
그러면 옵셔널 인덱스가 반환되고, 유효하지 않은 인덱스에는 nil이 반환돼요.

```swift
let tooFar = csv.index(csv.startIndex, offsetBy: 200)
// error: Execution was interrupted, reason: EXC_BAD_INSTRUCTION (code=EXC_I386_INVOP, subcode=0x0).
let tooFarButSafe = csv.index(csv.startIndex, offsetBy: 200, limitedBy: csv.endIndex)
// nil
```

또한 인덱스는 서로 다른 문자열끼리 공유할 수 없어요.
예를 들어 위에서 계산한 "orange"의 "g"에 대한 `index`로 `fam = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶, this is our cat: 🐱!"` 문자열을 인덱싱하면, 즉 `fam[index]`라고 쓰면 프로그램이 중단돼요.

이런 것에는 여러 이유가 있지만, 기본적으로는 모두 "유니코드는 까다롭다"로 귀결돼요.

일반적으로 개별 문자에 임의 접근이 필요하다면 `Array<Character>` 같은 다른 자료 구조를 쓰는 게 좋아요.

### 유용한 메서드 몇 가지

Swift에는 문자열의 첫 문자와 마지막 문자를 가져오는 `first`와 `last` 메서드가 있어요.
이 메서드들은 옵셔널 문자를 반환해서, 문자열이 비어 있으면 nil을 반환해요.

```swift
let str = "Hello, world!"
print(str.first) // Prints Optional("H")
print(str.last)  // Prints Optional("!")
```

`prefix`와 `suffix` 메서드로 문자열의 일부를 얻을 수도 있어요.
이 메서드들은 정수를 인자로 받아서 문자열의 앞이나 뒤 n개 문자를 담은 부분 문자열을 반환해요.

```swift
let str = "Hello, world!"
print(str.prefix(5)) // Prints "Hello"
print(str.suffix(6)) // Prints "world!"
```

## 문자열 메서드

텍스트를 다루는 일은 프로그래밍에서 흔한 작업이에요.
Swift는 Foundation 프레임워크와 함께 문자열을 살펴보고, 변환하고, 조작하는 데 편리한 메서드와 속성을 많이 제공해요.

## `components(separatedBy:)`로 문자열 나누기

구분자를 기준으로 문자열을 부분 문자열의 배열로 나누려면 `components(separatedBy:)`를 사용해요 (Foundation을 가져와야 해요):

```swift
import Foundation

let sentence = "Hello, world!"
let words = sentence.components(separatedBy: " ")
print(words) // Prints ["Hello,", "world!"]
```

## `hasPrefix(_:)`와 `hasSuffix(_:)`로 접두사와 접미사 확인하기

문자열이 특정 문자 시퀀스로 시작하거나 끝나는지 확인하려면 `hasPrefix(_:)`와 `hasSuffix(_:)`를 사용해요:

```swift
let greeting = "Hello, world!"
print(greeting.hasPrefix("Hello"))  // Prints true
print(greeting.hasSuffix("world!")) // Prints true
```

## 대소문자 바꾸기

다음 표준 메서드와 속성으로 문자열의 대소문자를 바꿀 수 있어요:

- `lowercased()`: 문자열의 소문자 복사본을 반환해요.
- `uppercased()`: 문자열의 대문자 복사본을 반환해요.
- `capitalized`: 각 단어의 첫 글자를 대문자로 바꾼 복사본을 반환해요 (Foundation에서 제공해요).

```swift
let greeting = "hello, world!"
print(greeting.lowercased())  // Prints "hello, world!"
print(greeting.uppercased())  // Prints "HELLO, WORLD!"
print(greeting.capitalized)   // Prints "Hello, World!"
```

## `replacingOccurrences(of:with:)`로 부분 문자열 바꾸기

어떤 부분 문자열이 나오는 곳을 모두 다른 문자열로 바꾸려면 `replacingOccurrences(of:with:)`를 사용해요 (Foundation에서 제공해요):

```swift
let greeting = "Hello, world!"
let updated = greeting.replacingOccurrences(of: "world", with: "Swift")
print(updated) // Prints "Hello, Swift!"
```

## `joined(separator:)`로 문자열 합치기

`joined(separator:)` 메서드는 `[String]` 같은 문자열 컬렉션에 속해요.
구분자를 사용해서 원소들을 하나의 문자열로 합쳐요:

```swift
let words = ["Hello", "world"]
let sentence = words.joined(separator: ", ")
print(sentence) // Prints "Hello, world"
```
