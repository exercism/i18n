# 소개

`for`문을 사용하면 배열을 순회하면서 각 원소마다 코드를 반복할 수 있어요:

```haxe
var fruitList = ["apple", "banana", "pear"];

for (fruit in fruitList) {
  trace(fruit);
}

// apple
// banana
// pear
```

위 예시에서 `fruit`는 배열 `fruitList`의 개별 원소 값을 담는 변수예요. 컴파일러는 `fruitList`를 순회할 수 있는지 확인하고, 그렇지 않으면 실행을 중단해요.

범위 연산자를 사용하면 숫자를 순회할 수 있어요. 이 연산자는 두 개의 `Int` 피연산자를 받고 `min...max`로 써요:

```haxe
for (i in 0...10) {
  trace(i); // from 0 to 9
}
```
