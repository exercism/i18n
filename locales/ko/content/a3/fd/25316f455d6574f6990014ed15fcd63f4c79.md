# 소개

Elixir 코드는 BEAM 가상 머신에서 실행돼요. BEAM은 Erlang 런타임 시스템의 일부예요. Erlang에서 영감을 받았고 실행 환경도 공유하기 때문에, Elixir는 Erlang 라이브러리와 뛰어난 상호 운용성을 제공해요. 덕분에 Elixir 개발자는 자신의 Elixir 코드 안에서 Erlang 라이브러리를 사용할 수 있어요. 실제로 Elixir 커뮤니티에서는 이미 Erlang 라이브러리가 제공하는 기능을 Elixir 라이브러리로 직접 작성하는 것을 권장하지 않아요.

그래서 수학 연산이나 타이머 함수 같은 일부 기능은 Elixir에서 Erlang을 통해서만 사용할 수 있어요.

Erlang의 표준 라이브러리는 별다른 설정 없이 Elixir 코드에서 바로 사용할 수 있어요.

Erlang 함수는 Elixir 함수를 호출하는 것과 같은 방식으로 호출할 수 있어요. 다만 작은 차이가 하나 있어요. Erlang 모듈 이름은 `snake_case` 아톰이에요. 예를 들어 `math` 모듈의 Erlang `pi/0` 함수를 호출하려면 이렇게 써요:

```elixir
:math.pi()
# => 3.141592653589793
```

Elixir에 대응하는 함수가 없는, 가장 많이 쓰이는 Erlang 함수는 다음과 같아요:

- `:timer.sleep/1`은 주어진 밀리초만큼 프로세스를 일시 중지해요.
- `:rand.uniform/0`은 `0.0 <= x < 1.0` 범위의 무작위 실수 `x`를 만들어요.
- `:io_lib.format/2`는 C 스타일 문자열 서식 기능을 제공해요(제어 시퀀스를 사용해요). 이 함수를 사용하면 2에서 36 사이의 임의의 진법으로 정수를 출력하거나, 원하는 정밀도로 실수의 서식을 지정할 수 있어요. 참고로 이 함수는 많은 Erlang 함수처럼 charlist를 반환해요.
- `sin/1`, `cos/1`, `log2/1`, `log10/1`, `pow/2` 등 수학 함수를 제공하는 `math` 모듈도 있어요.

Erlang 표준 라이브러리에 대해 더 알아보려면 [STDLIB 레퍼런스 매뉴얼][erl-stdlib-ref]을 살펴봐요.

[erl-stdlib-ref]: https://www.erlang.org/doc/apps/stdlib/index.html
