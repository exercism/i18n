# 소개

지금까지 실행해 본 모든 프로그램은 게임이든, 웹 브라우저든, 휴대폰 앱이든 결국 프로세서가 하나씩 처리하는 작은 명령어의 긴 목록으로 끝나요.
어셈블리어는 바로 그 명령어를 직접 작성하는 방법이에요.
변수나 배열, `for`문 대신 프로세서 자체의 구성 요소, 즉 몇 개 안 되는 레지스터와 메모리 주소, 그리고 한 명령어에서 다른 명령어로 건너뛰는 점프를 다뤄요.

RISC-V(발음은 "리스크 파이브")는 2010년 미국 캘리포니아 대학교 버클리에서 시작된 프로세서 설계예요.
대부분의 프로세서 설계와 달리 RISC-V는 개방형 표준이에요. RISC-V 칩을 만드는 데 비용을 내거나 허락을 구할 필요가 없고, 누구나 명세를 무료로 볼 수 있어요.
RISC-V 칩은 마이크로컨트롤러, 싱글 보드 컴퓨터, 저장 장치 등 여러 곳에서 쓰여요.

RISC-V는 단순함을 목표로 설계돼서 첫 어셈블리어로 좋아요.
명령어가 몇 가지 규칙적인 패턴을 따르고, 32개의 레지스터가 명확하고 일관된 역할을 가져서 대부분의 노트북에 들어 있는 프로세서보다 외울 것이 훨씬 적어요.
그 단순함 덕분에 지금은 많은 대학이 컴퓨터의 동작 원리를 가르칠 때 RISC-V를 사용해요.

작은 예로, 두 수를 더하는 함수를 하나 볼까요?

```riscv
add_numbers:
        add     a0, a0, a1      /* a0 = a0 + a1 */
        ret                     /* return to the caller, with the answer in a0 */
```

이 트랙에서는 32비트 RISC-V 어셈블리를 작성해요.
RISC-V 하드웨어는 전혀 필요 없어요. 프로그램은 RISC-V 프로세서인 척하는 에뮬레이터에서 테스트돼요.
연습 문제는 온라인 편집기에서 풀 수도 있고, 무료 도구를 사용해 자신의 컴퓨터에서 풀 수도 있어요.

어셈블리를 배우는 데는 인내심이 필요하지만, 그만한 가치가 있어요.
루프나 함수 호출이 프로세서 눈에 어떻게 비치는지 한번 알고 나면, 다른 프로그래밍 언어도 조금 더 잘 이해가 돼요.
