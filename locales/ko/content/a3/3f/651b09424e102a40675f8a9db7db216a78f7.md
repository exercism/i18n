# 지침

이 연습 문제에서는 한 달 동안 직원의 총 급여를 계산하는 규칙을 구현해요.
International Siderurgy Company (ISC)는 최종 임금에 영향을 줄 수 있는 여러 요인을 고려해 직원 급여를 계산하는 데 도움이 필요해요.

세 가지 과제가 있고, 이를 구현할 때는 if/else 문 대신 삼항 연산자를 사용해야 해요.

## 1. 급여 배수 구하기

직원이 결근한 날짜 수에 따라 급여 배수를 반환하는 `salaryMultiplier` 메서드를 구현해요.
직원이 5일 이상 결근했다면 15%의 페널티를 적용해요.

```java
int daysSkipped = 3;
salaryMultiplier(daysSkipped);
// => 1.0

daysSkipped = 7;
salaryMultiplier(daysSkipped);
// => 0.85
```

## 2. 판매한 제품에 대한 보너스 계산하기

`bonusMultiplier`와 `bonusForProductsSold` 메서드를 구현해요.
ISC는 판매된 제품 하나당 10 화폐 단위를 지급하고, 직원이 제품을 20개 이상 판매하면 배수가 13으로 올라가요.
`bonusMultiplier`는 어떤 배수를 적용할지 결정하고, `bonusForProductSold`는 화폐 단위로 총 보너스를 반환해요.

```java
int productsSold = 21;
bonusMultiplier(productsSold);
// => 13
bonusForProductsSold(productsSold);
// => 273

productsSold = 5;
bonusMultiplier(productsSold);
// => 10
bonusForProductsSold(productsSold);
// => 50
```

## 3. 직원의 최종 급여 계산하기

`finalSalary` 메서드를 구현해요.
기본급 `1000.00`에 급여 배수를 곱하고, 보너스를 더한 뒤, 그 결과를 반환해야 해요.
다만 급여는 `2000.00`을 넘을 수 없어요.

```java
int daysSkipped = 2;
int productsSold = 3;
finalSalary(daysSkipped, productsSold);
// => 1030.00

productsSold = 90;
finalSalary(daysSkipped, productsSold);
// => 2000.00
```
