# 지침

웰링턴 기상 관측소가 수동 온도 기록 시스템을 새로운 디지털 시스템으로 교체하려고 해요.
기존 시스템에서는 계산을 수동으로 했어요.
새 시스템에서는 이 계산이 자동으로 처리돼요.
계산에는 섭씨에서 화씨로 온도를 변환하는 것과 평균 온도를 구하는 것이 포함돼요.
새 시스템에는 섭씨로 온도 데이터를 기록하는 센서가 있어요.

웰링턴 기상 관측소는 새 시스템 작업을 도와주길 바라고 있어요.

## 1. 섭씨 온도를 켈빈으로 변환하기

기상 관측소 웹사이트에는 연구자를 위한 섹션이 있어요.
연구자들은 켈빈 단위의 온도에 관심이 있어요.

켈빈은 온도를 측정하는 데 사용하는 단위예요.
섭씨와 같은 눈금을 사용하지만 시작점이 달라요.
시작점은 절대 영도로, 0K(켈빈) 또는 -273.15°C(섭씨)예요.

다음은 섭씨와 켈빈 사이의 변환을 보여주는 표예요:

| 섭씨(°C) | 켈빈(K) |
| ----------- | --------- |
| -273.15     | 0         |
| -100        | 173.15    |
| 0           | 273.15    |
| 100         | 373.15    |

기상 관측소는 섭씨 온도를 켈빈으로 변환하는 메서드를 구현해 주길 바라고 있어요.

`Temperature#to_kelvin` 메서드를 구현해요. 이 메서드는 `celsius` 인자를 받아, 주어진 `celsius` 값에 273.15를 더해 켈빈 단위의 온도를 반환해요.

```crystal
Temperature.new.to_kelvin(0)
# => 273.15
```

## 2. 온도 반올림하기

기상 관측소의 온도 센서는 정확해요.
0.0001°C 단위까지 온도를 측정할 수 있어요.
기상 관측소는 온도를 소수점 첫째 자리까지 반올림해서 표시하고 싶어 해요. 대부분의 사용자는 그 정도 정밀도에 관심이 없거든요.

기상 관측소는 온도를 소수점 첫째 자리까지 반올림하는 메서드를 구현해 주길 바라고 있어요.

`Temperature#round` 메서드를 구현해요. 이 메서드는 `celsius` 인자를 받아, 소수점 첫째 자리까지 반올림한 온도를 반환해요.

```crystal
Temperature.new.round(10.1234)
# => 10.1

Temperature.new.round(10.1567)
# => 10.2
```

## 3. 섭씨 온도를 화씨로 변환하기

기상 관측소 웹사이트에는 관광객을 위한 섹션이 있어요.
관광객들은 화씨 단위의 온도에 관심이 있어요.

화씨는 온도 측정 단위예요.
섭씨와는 다른 눈금을 사용해요.
0°C는 32°F이고, 섭씨 1도는 화씨 1.8도와 같아요.

다음은 섭씨와 화씨 사이의 변환을 보여주는 표예요:

| 섭씨(°C) | 화씨(°F) |
| ----------- | -------------- |
| -273.15     | -459.8         |
| -100        | -148           |
| 0           | 32             |
| 100         | 212            |

기상 관측소는 섭씨 온도를 화씨로 변환하는 메서드를 구현해 주길 바라고 있어요.

`Temperature#to_fahrenheit` 메서드를 구현해요. 이 메서드는 `celsius` 인자를 받아, 화씨 단위의 온도를 정수로 반환해요.

```crystal
Temperature.new.to_fahrenheit(10)
# => 50
```

## 4. 부족한 센서 개수 구하기

온도 센서를 설치하던 중, 정비 담당자들은 센서 몇 개가 없는 것을 발견했어요.
각 온도 측정 장치에는 온도 센서 네 개가 필요해요.
정비팀은 보유한 센서의 개수를 세었지만, 몇 개가 부족한지도 알아야 했어요.
정비팀은 온도 측정 장치를 하나 더 완성하는 데 센서를 몇 개 사야 하는지 세는 일을 도와주길 바라고 있어요.

`Temperature#number_missing_sensors` 메서드를 구현해요. 이 메서드는 `number_of_sensors` 인자를 받아, 부족한 센서의 개수를 반환해요.

```crystal
Temperature.new.number_missing_sensors(10)
# => 2
```
