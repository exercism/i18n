# 소개

Go에서는 모든 변수에 값이 있어요.
값을 할당하지 않고 변수를 선언하면, 그 타입의 제로 값이 설정돼요.

`bool`, 숫자 타입, `string`을 비롯한 기본 타입에는 각각 고정된 제로 값이 있어요:

| 타입                   | 제로 값    |
| ---------------------- | ---------- |
| bool                   | `false`    |
| int, int8, int64, etc. | `0`        |
| float32, float64       | `0`        |
| complex64, complex128  | `0+0i`     |
| string                 | `""`       |

포인터, 함수, 인터페이스, 슬라이스, 채널, 맵은 모두 제로 값이 `nil`이에요.

배열과 구조체는 데이터를 참조가 아니라 직접 담고 있기 때문에 절대 `nil`이 되지 않아요.
배열의 각 원소와 구조체의 각 필드는 각자의 타입의 제로 값으로 초기화돼요.
예를 들어 `var a [3]int`는 `[0, 0, 0]`이라는 배열을 만들어요.

## 제로 값 선언하기

선언할 때는 `var`를 사용해요:

```go
var myBool bool   // false
var mySlice []int // nil
```

구조체에는 복합 리터럴 `T{}`를 사용해요:

```go
type Person struct {
    Name string
    Age  int
}

myPerson := Person{} // Person{Name: "", Age: 0}
```
