# 소개

배열은 Factor의 대표적인 고정 길이 시퀀스 타입이고, `{ … }`로 써요. 원소는 바꿀 수 있지만 길이는 바꿀 수 없어요. `arrays`와 `sequences` 보캐뷸러리를 함께 쓰면 스택에서 값을 꺼내는 작은 생성자를 비롯해, 원소를 이어 붙이고 뒤집고 조회하는 일상적인 연산도 쓸 수 있어요.

```factor
USING: arrays sequences ;

42 1array .                ! => { 42 }
"a" "b" "c" 3array .       ! => { "a" "b" "c" }
{ { 1 2 } { 3 4 } } concat .   ! => { 1 2 3 4 }
{ 1 2 3 } reverse .            ! => { 3 2 1 }
```

[arrays]: https://docs.factorcode.org/content/vocab-arrays.html
[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
