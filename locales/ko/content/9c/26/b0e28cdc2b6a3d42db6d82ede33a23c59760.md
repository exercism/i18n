# 지시 사항 추가

Cairo에서 배열을 다루는 일이 다른 프로그래밍 언어에서만큼 간단하지 않은 이유를 이해하려면, Cairo가 불변 메모리 모델을 사용한다는 점을 기억해 두면 도움이 돼요. 불변 메모리 모델이란 메모리 셀에 한 번 값이 쓰이면 다시 덮어쓸 수 없고, 오직 읽기만 할 수 있다는 뜻이에요.

Cairo는 이 특징을 어느 정도 감춰 주기 때문에, 개발자는 변수를 마치 변경할 수 있는 것처럼 선언하고 사용할 수 있어요.

덕분에 코드를 작성하는 일, 특히 `Array` 타입(내부적으로는 "바이트의 배열"인 `ByteArray`도 포함해요)을 사용하는 코드를 작성하는 일은 조금 더 어려워지지만, 신뢰할 수 없는 기계에서도 자신 있게 실행할 수 있는 _증명 가능한_ 프로그램을 작성할 수 있게 해줘요. 그래서 이런 트레이드오프는 충분히 가치가 있어요.
