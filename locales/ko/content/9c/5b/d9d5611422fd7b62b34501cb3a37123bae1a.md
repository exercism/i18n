# 소개

타입 정의는 이름이 붙은 새로운 타입을 만들어요. 이 타입은 기반 타입이 같더라도 다른 모든 타입과 구별되는 별개의 타입이에요.

## 타입 정의

타입 정의는 `type` 키워드로 시작하고, 그 뒤에 새 타입의 이름과 기반 타입이 와요.

```go
type File []bool
```

여기서 `File`은 체스판에서 흔히 A부터 H까지 이름이 붙는 세로줄 하나를 가리켜요.
이 세로줄의 각 칸은 말이 있는지 없는지를 나타내는 불리언 값으로 표현돼요.
이제 `File`을 정의했으니, 다른 정의 안에서도 사용할 수 있어요.

```go
type Chessboard map[string]File

board := Chessboard{
    "A": File{true, false, true},
    "B": File{false, true, false},
}
```

`Chessboard`는 세로줄 식별자를 `File` 값에 대응시켜요.
각 `File`은 체스 세로줄 하나의 칸들을 나타내는 불리언 슬라이스예요.
이런 타입 정의가 없다면 `board`는 `map[string][]bool`이 되어서, 무엇을 나타내는지 이해하기가 더 어려워질 거예요.
