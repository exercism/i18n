# 모듈 문서 사용

[comment]: # (제출한 코드에 모듈의 @moduledoc이 없을 때 발생하는 오류예요)

모듈의 의도를 설명하는 [`@moduledoc`](https://hexdocs.pm/elixir/writing-documentation.html#module-attributes) 속성을 두는 것을 권장해요.

- Elixir에서 문서는 [일급 시민](https://hexdocs.pm/elixir/writing-documentation.html)이에요. Elixir의 문서는 읽고 쓰기 쉽도록 설계되었어요.
- `@moduledoc`, `@doc` 같은 문서 속성 안에서는 Markdown 문법을 지원해요.
