# 힌트

## 일반

- 공식 [시작 가이드][getting-started-recursion]에서 재귀에 대해 읽어봐요.
- [elixirschool.com][elixir-school-recursion]에서 재귀에 대해 읽어봐요.
- 여러 절 함수와 패턴 매칭을 사용해요.
- 문제를 기본 사례와 재귀 사례로 나눠 봐요. 예를 들어, 재귀 방식으로 쿠키 항아리에 쿠키가 몇 개 들어 있는지 세고 싶다고 해봐요. 기본 사례는 빈 항아리예요. 빈 항아리에는 쿠키가 하나도 없어요. 항아리가 비어 있지 않다면, 항아리에 있는 쿠키의 수는 쿠키 하나에 쿠키 하나를 꺼낸 뒤 항아리에 남은 쿠키의 수를 더한 것과 같아요.

## 1. 오늘 몇 마리의 새가 찾아왔는지 확인하기

- 이 과제에는 재귀가 필요하지 않아요.
- 배열의 첫 번째 요소에 접근하는 것은 [패턴 매칭][getting-started-pattern-matching]으로 할 수 있어요.

## 2. 오늘의 개수 늘리기

- 이 과제에는 재귀가 필요하지 않아요.
- 배열의 첫 번째 요소에 접근하는 것은 [패턴 매칭][getting-started-pattern-matching]으로 할 수 있어요.

## 3. 새가 찾아오지 않은 날이 있었는지 확인하기

- 새가 찾아오지 않은 날을 찾을 때까지 재귀를 사용해 배열의 요소를 반복해요.
- 기본 사례는 빈 배열이에요.

## 4. 찾아온 새의 총 개수 계산하기

- 재귀를 사용해 배열의 모든 요소를 반복해요.
- 기본 사례는 빈 배열이에요.

## 5. 바쁜 날의 수 계산하기

- 재귀를 사용해 배열의 모든 요소를 반복해요.
- 기본 사례는 빈 배열이에요.
- 함수는 재귀 사례를 두 개 이상 가질 수 있어요.
- 함수 절 중 하나에 [가드][kernel-equal-or-greater-than]를 사용해요.
