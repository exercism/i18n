# 테스트

연습 문제의 이름이 `${slug}`일 때, 해당 `${slug}_test.sql` 파일이 있는 디렉터리로 이동해요. 여기서 `${slug}`는 연습 문제의 이름이고, 공백 대신 하이픈을 쓰고 모두 소문자로 써요 (예: `Hello World` 연습 문제의 경우 `hello-world_test.sql`).

```bash
sqlite3 -bail < ${slug}_test.sql
```

디버깅할 때는 `SELECT` 문을 사용할 수 있어요.
테스트가 실패하면 출력은 `user_output.md`로 전달되어 웹 에디터에 표시돼요.

자세한 내용은 [SQLite 트랙의 테스트 문서](https://exercism.org/docs/tracks/sqlite/tests)에서 확인할 수 있어요.
