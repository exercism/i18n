# 개요

[`while`문][while-loops]은 특정 조건이 참인 동안 코드를 실행할 수 있게 해 주는 제어 흐름 문이에요.
Swift는 `while`문과 `repeat-while`문, 이렇게 두 가지 종류의 `while`문을 제공해요.
`while`문은 루프 본문이 실행되기 전에 조건을 먼저 평가해요. 조건이 거짓이면 루프 본문은 아예 실행되지 않아요.
Swift의 `while`문은 다음과 같은 구조를 가져요:

```swift
while <#condition#> {
  <#code#>
}
```

여기서 루프는 count가 0보다 큰 동안 실행되고, 그 결과 2, 1, 그리고 "Liftoff!"를 출력해요.

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

[`repeat-while`문][while-loops]은 `while`문과 비슷하지만, 조건을 루프 본문이 실행된 뒤에 평가해요.
즉, 조건이 거짓이더라도 루프 본문은 항상 적어도 한 번은 실행돼요.
Swift의 `repeat-while`문은 다음과 같은 구조를 가져요:

```swift
repeat {
  <#code#>
} while <#condition#>
```

여기서는 조건이 거짓이기 때문에 루프가 한 번만 실행돼요.
`repeat-while`문이므로, 조건이 평가되기 전에 루프 본문이 한 번 실행돼요.

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```
