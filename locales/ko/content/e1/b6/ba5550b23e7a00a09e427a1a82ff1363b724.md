# 소개

## 숫자

Go에는 정수 값이나 실수 값을 나타낼 수 있는 기본 숫자 타입이 있어요.
필요한 값의 크기와 애플리케이션이 실행되는 컴퓨터의 아키텍처(예: 32비트와 64비트)에 따라 타입이 달라요.

이 연습 문제에서는 다음 타입만 다뤄요:

- `int`: 예: `0`, `255`, `2147483647`.
  크기가 최소 32비트인 부호 있는 정수예요 (값 범위: -2147483648부터 2147483647까지).
  하지만 이는 시스템 아키텍처에 따라 달라져요.
  대부분의 최신 컴퓨터는 64비트라서 `int`의 크기는 64비트가 돼요 (값 범위: -9223372036854775808부터 9223372036854775807까지).

- `float64`: 예: `0.0`, `3.14`.
  모든 64비트 부동소수점 수의 집합을 담고 있어요.

- `uint`: 예: `0`, `255`.
  `int`와 크기가 같은 부호 없는 정수예요 (값 범위: 32비트의 경우 0부터 4294967295까지, 64비트의 경우 0부터 18446744073709551615까지)

숫자는 타입 변환을 통해 다른 숫자 타입으로 변환할 수 있어요.

## 산술 연산자

Go는 다양한 표준 산술 연산자를 지원해요:

| 연산자 | 예        |
| -------- | -------------- |
| `+`      | `4 + 6 == 10`  |
| `-`      | `15 - 10 == 5` |
| `*`      | `2 * 3 == 6`   |
| `/`      | `13 / 3 == 4`  |
| `%`      | `13 % 3 == 1`  |

정수 나눗셈에서는 나머지가 버려져요 (예: `5 / 2 == 2`).

Go에는 위 연산자들을 위한 축약 대입이 있어요 (예: `a += 5`는 `a = a + 5`의 축약형이에요).
Go는 증가 및 감소 문 `++`와 `--`도 지원해요 (예: `a++`).

## 타입 간 변환

타입 간 변환은 변환하려는 타입의 이름을 가진 함수를 통해 이뤄져요.
예를 들어:

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
var y float64 = 11.9 // y has type float64
i := int(y) // i has type int (ie. 11)
```

## 서로 다른 타입에서의 산술 연산

많은 언어에서는 서로 다른 타입의 변수에 산술 연산을 할 수 있지만, Go에서는 오류가 발생해요.
예를 들어:

```go
var x int = 42

// this line produces an error
value := float32(2.0) * x // invalid operation: mismatched types float32 and int

// you must convert int type to float32 before performing arithmetic operation
value := float32(2.0) * float32(x)
```
