# 개요

## 일반 문법

`for`문은 어떤 로직을 반복해서 실행할 때 가장 흔히 사용하는 문 중 하나예요.
Go에서 `for`문은 `for` 키워드, 헤더, 그리고 중괄호로 감싼 루프 본문이 담긴 코드 블록으로 이루어져 있어요.
헤더는 세미콜론 `;`으로 구분된 세 가지 구성 요소로 이루어져 있어요. 바로 init, condition, post예요.

```go
for init; condition; post {
  // loop body - code that is executed repeatedly as long as the condition is true
}
```

- **init** 구성 요소는 루프가 시작되기 전에 딱 한 번만 실행되는 코드예요.
- **condition** 구성 요소는 불리언으로 평가되는 표현식이어야 하고, 루프를 언제 멈출지 제어해요.
  이 조건이 참으로 평가되는 동안에는 루프 안의 코드가 실행돼요.
  이 표현식이 거짓으로 평가되는 순간, 루프는 더 이상 반복되지 않아요.
- **post** 구성 요소는 매 반복이 끝날 때 실행되는 코드예요.

**참고:** 다른 언어와 달리 헤더의 세 가지 구성 요소를 감싸는 괄호 `()`가 없어요.
오히려 이런 괄호를 넣으면 컴파일 오류가 발생해요.
반면 루프 본문을 감싸는 중괄호 `{ }`는 항상 필요해요.

## `for`문 예제

init 구성 요소는 보통 카운터 변수를 준비하고, condition은 루프를 계속할지 멈출지 확인하며, post는 보통 매 반복이 끝날 때 카운터를 증가시켜요.

```go
for i := 1; i < 10; i++ {
  fmt.Println(i)
}
```

이 루프는 `1`부터 `9`까지(`9` 포함)의 숫자를 출력해요.
위 예시에서처럼 증가 또는 감소 문을 사용해서 반복 간격을 정하는 경우가 많아요.

## 헤더의 선택적 구성 요소

헤더의 init과 post 구성 요소는 생략할 수 있어요.

```go
var sum = 1
for sum < 1000 {
	sum += sum
}
fmt.Println(sum)
// Output: 1024
```

위처럼 `for`문에서 init과 post 구성 요소를 생략하면 Go에서는 `while`문을 만드는 셈이에요.
Go에는 `while` 키워드가 없어요.
이는 개념은 서로 직교해야 한다는 Go의 원칙을 보여주는 예예요.
`while`문의 동작을 구현할 개념, 즉 `for`문이 이미 있기 때문에 `while`을 추가 개념으로 넣지 않은 거예요.

## Break와 Continue

루프 본문 안에서 `break` 키워드를 사용하면 루프 실행을 완전히 멈출 수 있어요.

```go
for n := 0; n <= 5; n++ {
  if n == 3 {
    break
  }
  fmt.Println(n)
}
// Output:
// 0
// 1
// 2
```

반대로 `continue` 키워드는 현재 반복의 실행만 멈추고 다음 반복으로 넘어가요.

```go
for n := 0; n <= 5; n++ {
  if n%2 == 0 {
    continue
  }
  fmt.Println(n)
}
// Output:
// 1
// 3
// 5
```

## 무한 `for`문

루프 헤더의 condition 부분도 생략할 수 있어요.
실제로 헤더 없이 루프를 쓸 수 있어요.

```go
for {
  // Endless loop...
}
```

이 루프는 프로그램이 종료되거나 본문에 `break`가 있을 때만 끝나요.

## 레이블과 goto

`break`를 사용하면 Go는 가장 안쪽 루프의 실행을 멈춰요.
마찬가지로 `continue`를 사용하면 Go는 가장 안쪽 루프의 다음 반복을 실행해요.

하지만 항상 이게 바람직한 건 아니에요.
레이블을 `break`와 `continue`와 함께 사용하면, 각각 어느 루프에서 빠져나올지 또는 계속할지 정확히 지정할 수 있어요.

이 예시에서는 가장 바깥쪽 루프를 가리키는 `OuterLoop`라는 레이블을 만들어요.
가장 안쪽 루프에서 가장 바깥쪽 루프를 빠져나가고 싶다는 뜻으로, 가장 바깥쪽 루프 레이블의 이름을 붙인 `break`를 사용해요.

```go
OuterLoop:
    for i := 0; i < 10; i++ {
        for j := 0; j < 10; j++ {
            // ...
            break OuterLoop
        }
    }
```

`continue`와 함께 레이블을 사용하는 것도 가능한데, 이 경우 Go는 레이블이 가리키는 루프의 다음 반복을 실행해요.

Go에는 비슷하게 동작하는 `goto` 키워드도 있는데, 이 키워드를 사용하면 코드의 한 지점에서 레이블이 붙은 다른 지점으로 점프할 수 있어요.

**경고:** Go에서 레이블이 붙은 코드로 점프할 수 있긴 하지만, 이 기능을 사용하면 코드를 읽기가 매우 어려워지기 쉬워요.
이런 이유로 레이블 사용은 흔히 권장되지 않아요.
