# 개요

고정된 상수 값 집합이 있을 때는 언제든 [열거형][enumeration types]을 사용할 수 있어요. `enum`을 사용하면 상수 값을 타입 안전하게 다룰 수 있어요. 열거형을 정의할 때는 `enum` 키워드를 사용해요. 열거형 멤버는 열거형 이름과 점(.)을 앞에 붙여 나타내요(예: `Status.Active`).

각 열거형 멤버는 이름과 `int` 값의 조합이에요. 첫 번째 멤버에 명시적인 값이 없으면 그 값은 `0`으로 설정돼요. 열거형 멤버에 값이 명시적으로 정의되어 있지 않으면, 이전 멤버의 값에 `1`을 더한 값이 자동으로 할당돼요.

```csharp
enum Season
{
    Spring,     // Auto set 0
    Summer = 2, // Set the value 2
    Autumn,     // Auto set 3
    Winter = 7  // Set the value 7
}
```

열거형은 매우 선언적이에요. 다음 두 메서드 호출을 비교해 봐요:

```csharp
Users.WithStatus(1)
Users.WithStatus(Status.Active)
```

코드를 읽는 사람 입장에서는 열거형을 사용한 두 번째 버전이 이해하기 더 쉬워요.

## 숫자 형식 열거형

값의 기본 숫자 형식은 `int`지만, 다른 [정수 숫자 형식][integral numeric]을 명시적으로 지정해서 바꿀 수 있어요.

다음 열거형은 값에 `byte` 숫자 형식을 사용해요:

```csharp
enum Priority : byte
{
    Low = 0,
    Medium = 127,
    High = 255
}
```

## 열거형 멤버로 변환하기

불리언 같은 것을 모델링하고 싶을 때는 항상 열거형 사용을 고려해 봐요. 앞서 말한 가독성 이점 외에도, 열거형은 불리언보다 한 가지 장점이 더 있어요. 열거형에는 언제든 새로운 값을 추가할 수 있지만, 불리언 값은 언제나 `true` 또는 `false`일 뿐이에요. 따라서 열거형을 사용하는 편이 앞으로를 대비하는 데 더 유리해요.

```csharp
enum Status
{
    Inactive = 0,
    Active = 1
}

Status active = (Status) 1;
active == Status.Active; // True
```

정수 값을 열거형으로 _캐스팅할 수는_ 있지만, 그 정수 값이 어떤 열거형 값에도 해당하지 않으면 예상치 못한 결과가 나올 수 있다는 점에 유의해요:

```csharp
Status status = (Status) 2;
status == Status.Inactive; // False
status == Status.Active;   // False
```

## 열거형 파싱하기

때로는 [`Enum.Parse`][enum parse]를 사용해서 이름을 기준으로 문자열을 열거형 멤버로 변환하는 것이 유용해요:

```csharp
var input = "Inactive";
Status status = (Status)Enum.Parse(typeof(Status), input);
// Inactive
```

이름이나 값이 열거형에 존재하는지 확인하려면 [`Enum.TryParse`][enum tryparse]나 [`Enum.IsDefined`][enum isdefined]를 사용할 수 있어요. 둘 다 열거형 멤버가 존재하는지를 나타내는 불리언을 반환해요:

```csharp
bool doesExist = Enum.IsDefined(typeof(Status), "Inexistent");
// False
```
