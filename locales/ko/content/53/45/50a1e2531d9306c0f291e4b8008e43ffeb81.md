# 지침 추가

## 레지스터

| 레지스터 | 용도    | 타입 | 설명                                |
| -------- | ------------ | ------- | ----------------------------------- |
| `$a0`    | 입력         | 정수    | 소인수분해할 자연수                  |
| `$a1`    | 입출력       | 주소    | 소인수를 저장할 대상 배열            |
| `$v0`    | 출력         | 정수    | 소인수의 개수                        |
| `$t0-9`  | 임시         | 아무 값 | 임시 저장에 사용                     |
