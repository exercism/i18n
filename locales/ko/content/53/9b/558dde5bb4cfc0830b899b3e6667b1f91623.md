# 힌트

## 1. SELECT 쿼리 생성하기

- 빌더를 생성자나 리터럴로 초기화할 필요가 없다는 점을 기억해요. `var sb strings.Builder`라고 간단히 선언하면 바로 사용할 수 있어요.
- `columns` 슬라이스가 비어 있거나 `nil`인 경우에는 와일드카드 `*` 기호를 덧붙여서 처리해야 해요.
- 여기에서는 메타 문자나 SQL 정리 작업을 처리할 필요도, 그럴 것으로 기대하지도 않아요. `sb.WriteString(col)`로 컬럼 이름을 그대로 덧붙여도 안전해요.

## 2. 일괄 INSERT 문 생성하기

- `for`문 안에서 매번 새로운 `strings.Builder`를 할당하면 성능상의 이점이 사라져요. 대신 반복문이 시작되기 *전에* 빌더를 하나만 선언해요.
- 반복문이 한 번 돌 때마다 시작 부분에서 빌더 인스턴스의 `Reset()` 메서드를 호출해요. 그러면 버퍼가 비워져서, 내부적으로 이미 할당된 메모리 용량은 그대로 유지하면서 새로운 쿼리를 시작할 수 있어요.
- SQL `VALUES` 절의 문자열 값은 작은따옴표 `'`로 명시적으로 감싸야 한다는 점을 잊지 말아요. `WriteByte('\'')`를 사용하면 깔끔하게 추가할 수 있어요.
- SELECT 쿼리에서와 마찬가지로, 컬럼 값 안의 특수 문자를 이스케이프하거나 SQL 인젝션을 막는 일은 걱정하지 않아도 돼요. 입력 문자열은 그대로 사용해도 안전하다고 생각해요.
