# 개요

대부분의 프로그래밍 언어와 마찬가지로 Gleam에도 "부작용"이 있어요. 그래서 함수는 값을 반환할 뿐만 아니라 바깥세상의 상태를 읽고 바꿀 수도 있어요.

Gleam 표준 라이브러리의 `gleam/io` 모듈은 문자열을 콘솔에 출력하는 함수를 제공해요.

```gleam
io.println("Hello, Joe!")
// Hello, Joe!
// -> Nil
```

다른 패키지가 다른 IO 함수를 제공할 수도 있어요. 예를 들어 `simplifile`은 파일을 읽고 쓰는 함수를 제공하는 패키지예요.

```gleam
simplifile.read("favourite-colour.txt")
// -> Ok("Pink\n")
```
