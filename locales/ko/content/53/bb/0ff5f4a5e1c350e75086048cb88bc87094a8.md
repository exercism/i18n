# 소개

## 변수와 할당

R은 동적 타입 언어라서 일반적으로 변수의 타입을 지정할 필요가 없어요. 가장 권장되는 할당 연산자는 `<-`예요.

```R
x <- 42
avogadro <- 6.02e23
mystr <- "Hello, World!"
```

`<-` 대신 `=`를 사용해도 자주 동작하지만 항상 그런 것은 아니고, 좋지 않은 스타일이라 권장하지 않아요.
RStudio에서 작업한다면 키보드 단축키 `Alt-minus`로 입력할 수 있어요.

연산자는 대부분 일반적인 언어와 비슷하지만, `%/%`와 `%%`는 눈여겨봐요:

```R
2 + 3   # 5
2 - 3   # -1
2 * 3   # 6
2 / 3   # 0.6666667
8 %/% 3 # 2 (integer division)
8 %% 3  # 2 (remainder)
2 ^ 3   # 8 (exponential)
```

R에서 `#`는 한 줄 주석을 시작해요.
여러 줄 주석을 위한 별도의 문법은 없어요.

## 함수

함수를 정의하려면 이렇게 해요:

```R
squareit <- function(x) {
    x * x
}
```

함수는 인자를 하나도 받지 않거나 여러 개 받을 수 있고, 인자들은 쉼표로 구분해요.
매개변수가 하나도 없더라도 `function()`에는 괄호 `()`가 필요해요.

함수 인자에는 기본값을 지정할 수 있어요. 다만 기본값이 있는 인자는 기본값이 없는 인자들 뒤에 와야 하고, 기본값을 지정할 때는 `<-`가 아니라 `=`를 사용해요.
별로 쓸모는 없지만 예를 하나 들어볼게요:

```R
squareit <- function(x = 42) {
    x * x
}

squareit()
#> [1] 1764
```

한 줄짜리 함수 본문에는 중괄호 `{ }`가 꼭 필요한 것은 아니지만, 포함하는 것이 좋은 스타일로 여겨져요.

R은 위 예제들처럼 함수의 마지막 값을 자동으로 반환해요.

`return()`을 함수 본문 어디에서든 사용해서 반환값을 명시적으로 지정할 수 있어요.

함수를 호출하는 방법은 다른 여러 언어와 같아요:

```R
squareit(3)
#> [1] 9
```
