# 자세히 알아보기

시퀀스를 순회하다 보면 원소만으로는 부족할 때가 있어요. 위치도 알아야 하죠. Factor의 *인덱스 기반* 반복 워드는 원소별 쿼테이션에 원소와 인덱스를 함께 넘겨주는데, 인덱스가 스택의 맨 위에 와요. `times`는 그와 관련된 워드로, 바탕이 되는 시퀀스 없이 횟수만큼 반복할 때 써요.

```factor
USING: io kernel math.parser sequences ;

! map-index: build a new sequence; quot sees ( elt index )
{ "alice" "bob" "carol" }
[ number>string ": " glue ] map-index .
! => { "alice: 0" "bob: 1" "carol: 2" }

! each-index: for side effect; quot sees ( elt index )
{ "alice" "bob" } [
    number>string ": " glue print
] each-index
! prints alice: 0
! prints bob: 1

! times: run a quotation N times
3 [ "tick " print ] times
```

| 워드         | 스택 효과                                                    |
|--------------|-------------------------------------------------------------|
| `each-index` | `( seq quot: ( elt index -- ) -- )`                         |
| `map-index`  | `( seq quot: ( elt index -- newelt ) -- newseq )`           |
| `times`      | `( n quot: ( -- ) -- )` (아래 참고)                          |

`times`에는 미묘한 점이 하나 있어요. 쿼테이션의 스택 효과는 `( -- )`로 문서화되어 있지만, 이 워드는 `inline`이기 때문에 `( str -- str )`처럼 스택 효과가 균형 잡힌 쿼테이션도 문제없이 동작하고, 반복할 때마다 스택을 이어서 넘겨줘요. 덕분에 가변 상태 없이도 횟수를 세는 누산기를 만들 수 있죠.

```factor
USING: kernel sequences ;

"" 3 [ "clop " append ] times .    ! => "clop clop clop "
```

같은 요령은 `each-index`와 `map-index`에도 통해요. 선언된 원소별 스택 효과는 *최소* 조건일 뿐, 최대 조건이 아니에요.
