# 설치

## Clojure CLI 설치

Clojure는 다음과 같은 명령줄 도구를 제공해요: 대화형 REPL(Read-Eval-Print Loop) 실행, Clojure 프로그램 실행, Clojure 표현식 평가.
연습 문제를 풀 때는 Clojure CLI를 사용하는 것을 권장해요. [Clojure CLI](https://clojure.org/guides/deps_and_cli)를 설치하려면 아래 안내를 참고해요.

### Windows
Windows에서의 설치 방법은 [Clojure CLI 설치](https://clojure.org/guides/getting_started#_installation_on_windows)를 참고해요.

### Linux
대부분의 플랫폼에서의 설치 방법은 [Clojure CLI 설치](https://clojure.org/guides/getting_started#_installation_on_linux)를 참고해요.

### Mac OS X용 Homebrew
Homebrew를 업데이트해요:

``` bash
$ brew update
```

Clojure CLI를 설치해요:
``` bash
$ brew install node clojure/tools/clojure
```

node 환경에는 `Node`가 필요해요.

## 설치 확인

제대로 설치되었는지 확인하려면 `clojure --help`를 실행해요. 모든 것이 잘 되었다면 버전이 표시돼요.

```bash
$ clojure --help
Version: 1.10.1.547
...
```
