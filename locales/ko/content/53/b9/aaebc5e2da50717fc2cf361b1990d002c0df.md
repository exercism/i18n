# 설치

## .NET 10 설치하기

Visual Basic 트랙은 .NET 10을 사용해요.
연습 문제를 로컬에서 빌드하고 테스트하려면 [사용 중인 운영 체제에 맞는 .NET 10 SDK][install-sdk]를 설치해요.
런타임이 아니라 SDK를 설치해야 해요.

## 설치 확인하기

새 터미널을 열고 다음을 실행해요:

```bash
dotnet --version
```

이 명령은 `10.0.0` 이상을 출력해야 해요.

## 편집기 지원

연습 문제를 푸는 데에는 .NET SDK와 기본 기능만 갖춘 텍스트 편집기만 있으면 충분해요.
코드 자동 완성이나 디버깅처럼 더 고급 기능이 필요하다면 다음 편집기 중 하나를 고려해 봐요:

- Windows에서는 [Visual Studio 2026][visual-studio]
- Windows, Linux, macOS에서는 [Visual Studio Code][visual-studio-code]
- Windows, Linux, macOS에서는 [JetBrains Rider][rider]

[install-sdk]: https://learn.microsoft.com/en-us/dotnet/core/install
[rider]: https://www.jetbrains.com/rider/
[visual-studio]: https://visualstudio.microsoft.com/downloads/
[visual-studio-code]: https://code.visualstudio.com/download
