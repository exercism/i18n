# 테스트

풀이를 테스트하려면 다음을 실행하면 돼요:

```bash
make test
```

이 명령은 테스트 파일 `<exercise-name>-test.ys`를 실행해요. 이 파일에는 풀이가 올바르려면 통과해야 하는 모든 테스트가 들어 있어요.
테스트 파일을 자세히 살펴보면 풀이가 정확히 무엇을 해야 하는지 알 수 있어요.

> 참고: `make test`를 처음 실행하면 올바른 버전의 `ys` YAMLScript 인터프리터가 올바른 위치에 설치되어 있는지도 확인해요.

파일을 하나도 바꾸지 않은 상태에서 `make test`를 실행하면 모든 테스트가 실패해요.
이건 정상이며 예상된 동작이에요.
일반적인 연습 문제 개발 과정은 풀이를 조금씩 개선하면서 바꿀 때마다 `make test`를 실행해 모든 테스트가 통과할 때까지 반복하는 거예요.

풀이의 특정 부분에 집중하면서 특정 테스트만 실행하고 싶다면, 그 테스트에 다음 키/값 쌍을 추가하면 돼요:

```yaml
  ONLY: true
```

풀이의 다른 부분을 작업하면서 특정 테스트를 건너뛰고 싶다면, 그 테스트들에 다음 키/값 쌍을 추가하면 돼요:

```yaml
  SKIP: true
```


## 테스트 준비 사항

YAMLScript는 현재 MacOS와 Linux에서 실행돼요.

컴퓨터에 다음과 같은 아주 흔한 명령어들이 설치되어 있어야 해요:

* `bash` - 어떤 셸에서든 테스트를 실행할 수 있지만, `bash`는 반드시 있어야 해요.
* `make` - 테스트를 실행하려면 GNU `make`를 사용해야 해요.
  일부 환경에서는 `make`가 아닌 다른 이름일 수도 있어요.
  아마 `gmake`일 거예요.
* `prove` - 이 프로그램은 일반적인 Perl 설치에 포함되어 있어요.
* `curl` - ys가 아직 설치되어 있지 않다면 설치하는 데 사용해요.

이 프로그램들은 이미 모두 설치되어 있을 가능성이 아주 높아요.
