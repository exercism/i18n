# 로드맵

이 문서에서는 앞으로 몇 달 동안 기여자와 메인테이너가 주로 집중하게 될 주요 주제를 한눈에 살펴봐요.

## 주제 개요

- 기존 개념 연습 문제 개선 ([이슈](https://github.com/exercism/javascript/issues/1415) 참고)
- 개념 연습 문제 추가 (아래 교육 과정 개요 참고)
- 모든 실습 연습 문제의 `prerequisites`와 `practices` 목록 정의 ([이슈](https://github.com/exercism/javascript/issues/960) 참고)
- [테스트 러너](https://github.com/exercism/javascript-test-runner/) 개선
  - 버그 수정
  - 테스트 케이스 밖에서 변수를 정의한 경우의 출력 개선
  - 테스트를 과제와 연결
- 기존의 모든 개념 연습 문제에 [분석기](https://github.com/exercism/javascript-analyzer/) 주석 추가
- 다양한 문서 개선/업데이트/교정 (기여 가이드라인, 개념 연습 문제 구현 방법, docs, exercises/shared, reference 폴더)

## 교육 과정 개요

### 이미 존재하거나 이슈가 만들어진 개념

- `basics`
- `strings` (문자열 메서드 포함)
- `numbers`
- `booleans`
- `conditionals` (if/else)와 `comparison`
- `for-loops`와 `increment-decrement`
- `while-loops`
- `conditionals-switch`
- `objects` (키-값 컬렉션)
- `null-undefined`
- `functions`
- `type-conversion` (truthy/falsy 포함)
- `template-strings`
- `conditionals-ternary`
- `callbacks`
- `arrow-functions`
- `classes`와 `prototypes`
- `inheritance`
- `errors`
- `arrays` (push, pop 등으로 배열 조작 포함)
- `array-loops`
- `array-analysis`
- `array-transformation`
- `array-destructering`
- `rest-and-spread`
- `promises`
- `recursion`
- `closures`
- `sets`
- `randomness`
- `regular-expressions`
- `dates`
- `async-await`
- `type-checking`

### 추후 추가할 수 있는 개념

- `maps` (Sets 연습 문제에 추가할 수 있고, WeakSet/WeakMap은 첫 번째 반복에서 about에 넣을 수 있어요)
- `JSON`
- `math`
- getter/setter, 플래그, 디스크립터
- `proxy`
- `variables` (const/let/var 심화)
- `immutability` (freeze 포함, variables 개념과 합칠 수 있어요)
- `object-helpers` (예: Object.assign)
- 문자와 코드 포인트
- this와 스코프 (call/bind 포함)
- 이터레이터와 "enumerators"
- 제너레이터/yield
- 비동기 제너레이터와 이터레이터
- 비트 연산자
- 모듈, import, export, 동적 import
- 덕 타이핑
- Internationalization API
- `bigint`
- `symbol`
- JSDoc 주석
- 비동기성, 이벤트 루프
- setTimeout/setInterval
- 이벤트
- "모든 것이 객체"인 경우도 있어요 (함수, 배열, 원시값과 객체의 관계, 예: 박싱된 타입)
