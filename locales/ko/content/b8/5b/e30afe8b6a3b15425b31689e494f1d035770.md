# 레인지

[레인지][range]는 두 값 사이의 구간을 나타내요.
레인지를 지원하는 가장 흔한 타입은 `Int`, `Char`, `String`이에요.
레인지는 컬렉션을 빠르게 만들거나, 문자열을 자르거나, 어떤 값이 레인지 안에 있는지 확인하거나, 반복할 때 등 여러 상황에서 쓸 수 있어요.
레인지는 `..` 또는 `...` 레인지 연산자로 만들어요. 각각 끝 값을 포함하는 레인지와 포함하지 않는 레인지예요.

```crystal
1..5  # A range containing 1, 2, 3, 4, 5
1...5 # A range containing 1, 2, 3, 4
```

레인지 연산자가 두 개인 이유는 끝 값을 포함하는 레인지와 포함하지 않는 레인지를 만들기 위해서예요.
이건 예를 들어 0부터 시작하는 인덱스를 다룰 때 유용해요.

레인지는 `Range` 초기화 메서드로도 만들 수 있어요.

```crystal
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
Crystal에서 `..` 또는 `...` 레인지 연산자로 레인지를 만들고 그 레인지에 메서드를 호출하고 싶을 때는, 레인지를 괄호로 감싸야 해요.
그러지 않으면 레인지 연산자의 두 번째 인자에 메서드가 호출되기 때문이에요.

```crystal
(1..5).size # => 5
1..5.size # => Error: undefined method 'size' for Int32
```
~~~~

## 부분 문자열 가져오기

문자열을 자르고 싶을 때 레인지 연산자로 부분 문자열을 얻을 수 있어요.
즉, 부분 문자열의 시작과 끝 인덱스로 레인지를 만드는 거예요.

```crystal
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

음수 인덱스를 쓰면 문자열의 끝에서부터 부분 문자열을 얻을 수도 있어요.

```crystal
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## 레인지 메서드

레인지에는 레인지를 다루는 데 쓸 수 있는 여러 메서드가 있어요.
예를 들어 레인지에 있는 모든 값의 합을 구하거나, 레인지가 어떤 값을 포함하는지 확인할 수 있어요.

| 메서드                  | 설명                                                                    | 예제                            |
|-------------------------|-------------------------------------------------------------------------|---------------------------------|
| [`sum`][sum]            | 레인지에 있는 모든 값의 합을 반환해요                                   | `(1..5).sum # => 15`            |
| [`size`][size]          | 레인지의 크기를 반환해요                                                | `(1..5).size # => 5`            |
| [`includes?`][indludes] | 레인지가 주어진 값을 포함하면 `true`를, 그렇지 않으면 `false`를 반환해요 | `(1..5).includes?(3) # => true` |

## 끝이 없는 레인지와 시작이 없는 레인지

레인지는 끝이 없거나 시작이 없을 수 있어요.
끝이 없거나 시작이 없는 레인지는 시작 값이나 끝 값이 `nil`이지만, 레인지를 정의할 때 `nil`은 생략할 수 있어요.

시작이 없거나 끝이 없는 레인지는 예를 들어 문자열을 처음부터 또는 끝까지 자르고 싶을 때 유용해요.

```crystal
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
컬렉션에 사용하지 않는다면, 끝이 없는 레인지는 조심하지 않을 경우 끝없는 시퀀스를 만들 수 있어요.
~~~~

## `Char` 레인지

`Char`는 레인지에 쓸 수 있어서 두 문자 사이의 문자 구간을 얻을 수 있어요.
예를 들어 알파벳을 얻고 싶을 때 유용해요.

```crystal
'a'..'z' # A range containing ['a', 'b', 'c', ..., 'z']
```

## `String` 레인지

`String`도 레인지에 쓸 수 있어서 두 문자열 사이의 문자열 구간을 얻을 수 있어요.
다만 문자열 레인지에 여러 문자가 쓰이면 동작이 `Char`와는 조금 달라요.
더 복잡한 문자열 레인지를 다룰 때는 동작이 헷갈릴 수 있으니 주의해야 해요.

```crystal
("aa".."az") # A range containing ["aa", "ab", "ac", ..., "az"]
```
