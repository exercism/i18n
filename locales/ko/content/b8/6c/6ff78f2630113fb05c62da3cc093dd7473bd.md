# 개요

많은 프로그램은 현실 세계의 사건을 시뮬레이션하기 위해 (겉보기에) 무작위한 값이 필요해요.

흔히 접하는 예로는 다음과 같은 것들이 있어요.

- 동전 던지기: `"H"` 또는 `"T"`인 무작위 값.
- 주사위 굴리기: 1부터 6까지의 무작위 정수.
- 카드 한 벌 섞기: 카드 목록의 무작위 순서.

컴퓨터로 진정한 무작위 값을 생성하는 것은 [놀랄 만큼 어려운 기술적 과제][web-truly-random]라서, 이런 결과를 "의사 난수"라고 부르는 것을 볼 수 있어요.

***중요***: 이 개념에서는 암호학적으로 안전한 난수를 다루지 *않아요*. 그건 훨씬 더 어려운 과제예요.

하지만 R은 통계 패키지에서 파생되었고 시뮬레이션에 자주 사용되기 때문에, 난수를 생성하는 다양한 방법을 제공해요.
그 결과는 모델링, 시뮬레이션, 게임 등 대부분의 응용 분야에 충분히 좋아요.

재현 가능한 출력을 원한다면 이 문서 끝부분의 시드에 관한 섹션을 참고해요.

## [복원 추출과 비복원 추출][yt-sampling-with-replacement]

주머니에 빨간 공 3개와 초록 공 4개가 들어 있고, 그 주머니에서 공 하나를 무작위로 꺼낸다고 상상해 봐요.
두 번째 공을 꺼내려면 두 가지 방법이 있어요.

1. 첫 번째 공을 주머니에 다시 넣고 잘 흔든 다음 또 하나를 꺼내요.
   그러면 공의 개수는 이전과 같은 7개이고, *빨간 공과 초록 공의 비율도 그대로예요*.
2. 첫 번째 공을 탁자 위에 올려두고 두 번째 공을 꺼내요.
   이제 주머니에는 공이 6개뿐이고, *빨간 공과 초록 공의 비율은 첫 번째 공의 색에 따라 달라져요*.

1번은 복원 추출, 2번은 비복원 추출이며, *두 방법은 서로 다른 결과를 줘요*.

## `sample`로 이산값 다루기

한정된 수의 이산값 중에서 고르려면 [`sample()`][ref-sample]을 복원 추출이나 비복원 추출로 사용할 수 있어요.
정수나 문자열 등에 유용해요.

```R
sample(1:10, 5) # no repeats by default
#> [1] 8 3 4 2 6

sample(1:10, 5, replace = TRUE) # repeats are OK
#> [1] 10 10  7 10  9

languages <- c("Fortran", "R", "Python", "Julia")
sample(languages, 1)
#> [1] "Python"

sample(c("H", "T"), 5, replace = TRUE) # coin flips
#> [1] "T" "T" "H" "H" "H"

sample(c(TRUE, FALSE), 5, replace = TRUE) # alternative coin flips
#> [1] FALSE  TRUE FALSE  TRUE  TRUE
```

샘플링은 데이터 파이프라인에 잘 어울려요.
예를 들어 무작위 영숫자 문자열을 생성하려면:

```R
library(stringr)

c(letters, LETTERS, 0:9) |> sample(50) |> str_flatten()
#> [1] "5tX71jhbM9zUmKrpENBQyGYaZdJPVAx06leSF2s8gcfw3OviIH"
```

또한 샘플링은 벡터와 범위에만 국한되지 않아요.
다른 개념에서 [배열][concept-lists], [행렬][concept-matrices-arrays], [데이터프레임][concept-dataframes] 모두 유효한 입력이 된다는 것을 보게 될 거예요.
*R에서 기대할 수 있는 것처럼요*.

## 섞기

다른 여러 언어에는 시퀀스를 섞는 특별한 함수가 있어요. Python의 `random.shuffle()`, Julia의 `shuffle()`, Matlab의 `randperm()` 등이 그렇죠.

R에는 섞기 함수가 없어요.
*왜일까요?*

그 이유를 이해하려면 [`sample`][ref-sample] 함수를 다시 살펴봐요.

전체 형태는 `sample(x, size, replace = FALSE, prob = NULL)`이며, 여기서 `x`는 (보통) 샘플링할 시퀀스이고 `size`는 선택할 항목의 개수예요.

`replace`는 이미 다뤘는데, 기본값은 비복원 추출이에요.
지금은 `x`의 여러 원소에 서로 다른 가중치를 줄 수 있게 해주는 `prob`은 무시해요.

`size`를 생략하고 `x`만 주면 어떻게 될까요?

```R
x <- letters[1:6]
x
#> [1] "a" "b" "c" "d" "e" "f"
sample(x)
#> [1] "e" "a" "f" "b" "c" "d"
```

전형적인 R 스타일로, 벡터를 넣으면 벡터가 나오는 패턴이고 `size`의 기본값은 `length(x)`예요.

R은 대부분 통계학자들이 만들고 통계학자들을 위해 만들었어요.
그들은 "`x`의 모든 원소를 비복원으로 샘플링한다"는 것이 "`x`를 섞는다"는 말을 더 기술적으로 표현한 것일 뿐이라는 걸 알고 있죠.

*따라서* `sample`이 이미 우리에게 필요한 일을 정확히 해주기 때문에 `shuffle` 함수가 없는 거예요!

## 분포 다루기

위의 예제들은 모든 결과가 똑같이 나올 가능성이 있는 경우를 설명했어요.
예를 들어 `sample(1:100)`은 1부터 100까지의 어떤 정수든 같은 확률로 나와요.

이것을 [`uniform`][web-uniform] 분포라고 해요.

현실의 많은 상황은 이보다 훨씬 복잡해요.
그래서 통계학자들은 "현실 세계"의 결과를 수학적으로 설명하기 위해 다양한 [`distributions`][wiki-probability-distribution]를 만들어 냈어요.

기본 R은 여러분이 들어본 적 있을 법한 것보다 더 많은 분포를 지원하고, 그 외의 분포는 오픈 소스 패키지에서 사용할 수 있어요.

이 문서의 나머지 부분에서는 가장 흔한 분포 몇 가지에 대해서만 설명해요.

## 실수

### 균등 분포

실수의 [균등 분포][wiki-uniform]를 얻으려면 [`runif()`][ref-runif]를 사용해요 ("**r**andom-**unif**orm"을 떠올리고, "run if"로 읽고 싶은 자연스럽지만 *잘못된* 유혹을 물리쳐요).
`min`과 `max`를 모두 지정할 수 있지만 기본값은 각각 0과 1이에요.

```R
runif(5)  # generate 5 values
#> [1] 0.3038506 0.3527959 0.3319309 0.4846354 0.4386279

# generate 5 non-negative values <= 100.0
runif(5, max = 100)
#> [1] 79.70762 51.62232 52.85281 71.08571 63.94380
```

### 정규/가우시안 분포

"종 모양" 곡선이라고도 하며, 측정값의 부정확도를 설명하는 아주 흔한 방법이에요.

예를 들어, 여러분이 일하는 공장에서 똑같아야 할 볼트 10,000개를 막 사 왔다고 해요.
공장 로봇이 이들을 다루도록 설정하려고, 100개의 표본을 달아 보니 평균(또는 [`mean`][ref-mean]) 무게가 4.731g이었어요.
이것이 모든 볼트의 무게가 정확히 4.731g이라는 뜻일 가능성은 극히 낮아요.
아마 값은 4.627에서 4.794g 사이에 걸쳐 있지만 4.731g 주위에 몰려 있을 거예요.

이것이 [`normal distribution`][wiki-normal-distribution] (수학자 카를 프리드리히 가우스를 따라 "가우시안"이라고도 해요)이고, 확률은 평균에서 가장 높고 양쪽으로 대칭적으로 줄어들어요 (그래서 "종 모양"이에요).

소프트웨어에서 이를 시뮬레이션하려면 곡선의 너비를 지정할 방법이 필요해요 (*일반적으로 비싼 볼트는 싼 볼트보다 평균 주위에 더 촘촘하게 몰려 있어요!*).
관례적으로 이는 [`standard deviation`][wiki-standard-deviation]로 나타내요. 값이 작으면 뾰족하고 좁은 곡선, 크면 낮고 넓은 곡선이 돼요.

수학자들은 그리스 문자를 좋아해서, 평균을 나타낼 때 `μ`('뮤'), 표준 편차(또는 `sd`)를 나타낼 때 `σ`('시그마')를 자주 볼 수 있어요.
따라서 "값의 95%가 μ에서 2σ 이내에 있다"거나 "힉스 보손이 5시그마 신뢰도로 검출되었다"는 내용을 읽는다면, 그런 설명은 표준 편차와 관련된 거예요.

<!-- 이 내용에 대해서는 [`Statistics`][statistics] 개념에서 더 다룰 예정이에요. -->

이 분포의 난수를 생성하려면 R에 [`rnorm()`][ref-rnorm] 함수가 있어요.

"random normal"의 줄임말이며, 기본값은 `mean`이 0, `sd`가 1이에요.

```R
rnorm(5)
#> [1]  0.36965357  0.07489948 -0.83827224 -0.83126506 -0.59895825

# Simulating our bolts example
rnorm(5, mean = 4.731, sd = 0.2)
#> [1] 4.564521 4.613237 4.419512 4.772196 4.839102
```

숫자만 보고는 원시 출력이 균등 분포보다 평균에 더 가깝게 몰려 있다는 것을 알아채기 어려워요.
의심된다면 1000개 이상을 생성해서 그래프로 그려 보면 더 분명해져요.
RStudio(또는 비슷한 도구)를 로컬에 설치하지 않은 학습자는 [rdrr.io][web-rdrr]나 [WebR ggplot2 Playground][web-ggplot] 같은 온라인 R 실행기를 사용할 수 있어요.

`hist(rnorm(10000), breaks = 40)` 코드는 가장 세련된 표현은 아니지만 기본적인 패턴을 보여줘요.
난수는 구간별로 나뉘고, 세로축은 각 구간에 속한 결과의 개수예요.

~~~~exercism/advanced
R 분포 함수의 이름은 접두 문자 뒤에 축약된 분포 이름이 붙는 형태예요.

접두 문자는 다음과 같아요.

## 이산 분포

### 이항 분포

동전을 (*속임수 없이*) 던지면 앞면이 나올 확률과 뒷면이 나올 확률이 같아요. 둘 다 확률이 `p = 0.5`예요.

동전을 20번 던지면 앞면은 몇 번 나올까요?
0번일 수도, 20번일 수도 있지만, 통계 교육을 받지 않은 사람도 "*10번쯤*"이라고 짐작할 거예요.

한 번 던졌을 때 앞면이 0번 또는 1번 나올 확률의 비는 `1:1`이에요.

두 번 던지면 앞면이 0, 1, 2번 나올 비는 `1:2:1`, 세 번 던지면 `1:3:3:1`이에요.

이 비를 ["이항 계수"][wiki-binom-coeff]라고 해요.
이 계수들은 [파스칼의 삼각형][wiki-pascal-triangle]을 이루고, R을 비롯한 많은 Exercism 트랙에는 이를 바탕으로 한 [연습 문제][practice-pascal]가 있어요.

대신 특정 결과의 확률을 알고 싶다면 R에 [`dbinom()`][ref-rbinom] 함수가 있어요 ([확률 밀도][wiki-pdf]를 계산해요).
20번 던져서 앞면이 10번 나올 확률은 거의 18%예요.

속임수를 쓸 수도 있으니, 앞면이 나올 확률을 `p = 0.6`으로 높이면 앞면이 10번 나올 확률은 *줄어들어요*:

```R
# Probability of exactly 10 heads in 20 flips, fair coin
dbinom(10, size = 20, prob = 0.5)
#> [1] 0.1761971
```

```R
# Probability of exactly 10 heads in 20 flips, biased coin
dbinom(10, size = 20, prob = 0.6)
#> [1] 0.1171416
```

이제는 20번 던져서 앞면이 10번보다 많이 나올 가능성이 커요.
분명히 우리는 가능한 모든 결과, 즉 [이항 분포][wiki-binomial]에 관심을 가져야 해요.

R은 이항 분포의 난수를 생성하는 [`rbinom()`][ref-rbinom] 함수를 제공해요.
반환할 값의 개수 `n`, 시행 횟수 `size`(동전 던지기 횟수 같은), 단일 사건의 확률 `prob`(한 번 던져서 앞면이 나올 확률 같은)을 알려줘요.

동전 던지기를 시뮬레이션하려면 정규 분포에서처럼 그래픽 출력을 보여줄 수 있는 곳에서 이 코드를 실행해요:

```R
# fair coin
hist(rbinom(n = 10000, size = 20, prob = 0.5))

# biased coin
hist(rbinom(n = 10000, size = 20, prob = 0.6))
```

결과 그래프는 앞면이 가장 많이 나올 횟수가 각각 "약 10번"과 "약 12번"임을 보여줘요.

20번 던진 경우 결과는 히스토그램에서 큰 계단을 이루는 명백한 이산값이지만 "종 모양"에 어느 정도 가까워요.

공정한 동전을 써서 결과가 대칭이 되도록 수백만 번 던지는 시뮬레이션을 하면, 이항 분포는 (*연속적인*) 정규 분포에 점점 더 좋은 근사가 돼요.

### 푸아송 분포

지름 1m가 넘는 운석이 매년 지구에 몇 개나 떨어질까요?

지구 어디에나 (낮은 수준의) 자연 방사선이 존재해요.
[가이거 계수기][wiki-geiger]를 켜면 방사선 입자를 검출하면서 1초에 몇 번의 딸깍 소리를 듣게 될까요?

이런 예들의 특징은 다음과 같아요.

- 사건들은 서로 *독립*이에요.
- 어떤 구간에서 사건이 일어날 확률은 일정하게 유지돼요.
- 이산적인 사건을 세고 있어요.
- 횟수에 *이론적인* 상한은 없어요 (측정에는 실제적인 제약이 있을 수 있지만요).

어떤 구간에서 사건이 0, 1, 2...번 일어날 확률은 [푸아송 분포][wiki-poisson]를 이뤄요.

푸아송 분포의 핵심 매개변수는 선택한 구간에서 사건이 일어나는 [평균][ref-mean] 횟수이고, 보통 그리스 문자 λ('람다')로 나타내요.

지름이 1미터 이상인 지구 충돌 운석의 빈도는 문헌에서 "몇 달에 한 번"으로 설명돼요.

예를 들어 `lambda = 4`로 놓고 [`rpois()`][ref-rpois]로 분포가 어떻게 생겼는지 살펴봐요:

```R
hist(rpois(n = 10000, lambda = 4))
```

이제 히스토그램은 매우 비대칭이고, 충돌 2번에서 봉우리를 이루며 10 이상인 값도 0이 아닌 개수로 나타나는 긴 꼬리를 보여줘요.

## 시드

위에서 설명한 모든 난수 함수는 실행할 때마다 다른 결과를 주는 것을 목표로 해요.
결국 *무작위*니까요!

이 동작은 매번 다른 [난수 시드][wiki-seed]를 생성하는 것에 기반해요.

디버깅을 위해 [`set.seed(n)`][ref-set-seed] 함수를 사용하면 도움이 될 수 있어요. 여기서 `n`은 여러분이 고른 정수예요.
매번 같은 시드를 설정하면 코드는 실행할 때마다 같은 난수 집합을 반환해요.

```R
sample(1:5) #> [1] 5 1 2 4 3
sample(1:5) #> [1] 2 5 4 1 3
sample(1:5) #> [1] 4 2 5 1 3

set.seed(100); sample(1:5) #> [1] 2 3 5 4 1
set.seed(100); sample(1:5) #> [1] 2 3 5 4 1
set.seed(100); sample(1:5) #> [1] 2 3 5 4 1
```

고급 사용자를 위해 `set.seed()`는 사용할 RNG(*난수 생성기*) 유형도 지정할 수 있어요.

아무래도 기본값은 `"Mersenne-Twister"`이니, 바꾸려고 하기 전에 그것이 무엇을 뜻하는지 확실히 이해해요.
이 개념의 저자들은 RNG에 대해 더 이상 드릴 조언이 없어요.

## 다른 패키지

많은 경우 패키지는 특정 분야의 전문 지식도 전제로 해요. 보통 의학이나 사회과학의 한 분야(역학, 심리학, 인류학... *목록이 길어요*)죠.

많은 컴퓨터 과학자는 (*어느 정도 타당한 근거를 가지고*) R이 이상한 언어라고 생각해요.
