# 소개

C#은 많은 정적 타입 언어처럼 정수를 나타내는 여러 형을 제공하며, 각 형에는 고유한 값 범위가 있어요. 범위가 가장 작은 `sbyte` 형의 최솟값은 -128이고 최댓값은 127이에요. 모든 정수형과 마찬가지로 이 값들은 `<type>.MinValue`와 `<type>.MaxValue`로 사용할 수 있어요. 범위가 가장 큰 `long` 형의 최솟값은 -9,223,372,036,854,775,808이고 최댓값은 9,223,372,036,854,775,807이에요. 그 사이에는 `short`와 `int` 형이 있어요.

각 범위는 시스템이 그 형에 할당하는 저장 너비에 따라 결정돼요. 예를 들어 `byte`는 8비트를 사용하고 `long`은 64비트를 사용해요.

위의 각 형에는 부호 없는 대응 형이 있어요: `sbyte`/`byte`, `short`/`ushort`, `int`/`uint`, `long`/`ulong`. 모든 경우에 값의 범위는 0부터 부호 있는 형의 음의 최댓값에 2를 곱하고 1을 더한 값까지예요.

| 형   | 너비  | 최솟값                    | 최댓값                     |
| ------ | ------ | -------------------------- | --------------------------- |
| sbyte  | 8비트  | -128                       | +127                        |
| short  | 16비트 | -32_768                    | +32_767                     |
| int    | 32비트 | -2_147_483_648             | +2_147_483_647              |
| long   | 64비트 | -9_223_372_036_854_775_808 | +9_223_372_036_854_775_807  |
| byte   | 8비트  | 0                          | +255                        |
| ushort | 16비트 | 0                          | +65_535                     |
| uint   | 32비트 | 0                          | +4_294_967_295              |
| ulong  | 64비트 | 0                          | +18_446_744_073_709_551_615 |

한 형의 변수(또는 식)는 다른 형으로 쉽게 변환할 수 있어요. 예를 들어 대입 연산에서, 대입되는 값(lhs)의 형이 그 값이 대입 대상(rhs) 형의 범위 안에 들어옴을 보장한다면 단순한 대입만으로 충분해요:

```csharp
uint ui = uint.MaxValue;
ulong ul = ui;    // no problem
```

반대로 대입하는 쪽 형의 범위가 대입받는 쪽의 값 범위에 포함되지 않는다면, 특정 값이 대입받는 쪽 범위 안에 있더라도 `()` 캐스트 연산이 필요해요:

```csharp
short s = 42;
uint ui = (uint)s;
```
