# 힌트

## 일반

- `n <iota>`는 정수 `0, 1, …, n-1`의 가상 시퀀스를 만들어요.
- `map`은 [`sequences`][sequences]에 있고, 각 원소에 쿼테이션을 실행해서 결과를 모아요.
- `>string`은 [`strings`][strings]에 있고, 문자 코드의 시퀀스를 문자열로 바꿔요.

## 1. 알파벳 깃발

- `CHAR: a`는 정수 `97`로 파싱돼요. 여기에 인덱스 `i`를 더하면 `i`번째 소문자의 코드가 돼요.

## 2. 숫자 세기 깃발

- `mod`는 [`math`][math]에 있고, 정수 나눗셈의 나머지를 반환해요.
- 숫자의 문자 코드는 `CHAR: 0`, `CHAR: 1`, …처럼 연속돼요. 그래서 `CHAR: 0 +`는 `0..9` 범위의 정수를 그에 해당하는 숫자 문자로 바꿔요.

## 3. 줄무늬 깃발

- `even?`은 [`math`][math]에 있고, 짝수 정수에 대해서는 `t`, 그렇지 않으면 `f`예요.
- `map` 쿼테이션 안에서 `if`는 검사 결과에 따라 두 문자 리터럴 중 하나를 골라요.

## 4. 표시 깃발

- `5 mod zero?`는 정확히 `0`, `5`, `10`, … 위치에서 `t`예요.

## 5. 골짜기 깃발

- `-5 5 [a..b)`는 [`ranges`][ranges]에 있고, 반개구간 `-5, -4, …, 4`예요.
- `abs`는 [`math`][math]에 있고, 음의 정수를 그에 대응하는 양수로 바꾸고, 음이 아닌 정수는 그대로 둬요.
