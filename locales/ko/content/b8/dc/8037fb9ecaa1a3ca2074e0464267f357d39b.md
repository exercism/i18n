# 상태를 가진 클래스

```sather
class SCOREBOARD is

   attr home_team, away_team : STR;
   attr home_score, away_score : INT;

   create(home, away : STR) : SAME is
      board ::= new;
      board.home_team := home;
      board.away_team := away;
      return board;
   end;

   home_goal is home_score := home_score + 1; end;

end; -- class SCOREBOARD
```

## attr, readonly attr, private attr

| 작성 | 외부에서 읽기 | 외부에서 변경 |
| --- | --- | --- |
| `attr x : INT` | 가능 | 가능 |
| `readonly attr x : INT` | 가능 | 불가능 |
| `private attr x : INT` | 불가능 | 불가능 |

기본적으로 골라야 할 것은 `readonly`예요. 누구나 점수를 볼 수 있게 하면서,
점수를 바꾸려면 반드시 `home_goal`을 거치도록 해요. 점수에 관한 규칙이 바로
그곳에 있으니까요.

## create와 new

`new`는 이 클래스의 객체를 만들고, 모든 속성은 비어 있어요. `new`는 클래스
안에서만 쓸 수 있어요.

`create`는 이름이 정해져 있는 평범한 루틴이에요. `#C(args)`는 정확히
`C::create(args)`와 같아요. 하나의 클래스가 인자로 구별되는 여러 개의 `create`를
가질 수 있고, `create`가 하나도 없는 클래스는 `#`로 만들 수 없어요.

## SAME

`SAME`은 그것이 쓰인 클래스를 가리켜요. `create`에서는 반환 타입이고, 인자
자리에서도 쓰이며, 상속받은 루틴이 원래 있던 클래스가 아니라 상속받는 클래스를
가리키게 해주는 것이 바로 `SAME`이에요.

## 반환 타입이 없는 루틴

```sather
   home_goal is
      home_score := home_score + 1;
   end;
```

`:`도 없고 타입도 없어요. 이런 루틴은 문으로 호출되고, 표현식에는 나타날 수
없어요. 호출의 목적이 바로 그 루틴이 만들어 내는 변화라는 표시예요.

## self

루틴 안에서 `self`는 그 루틴이 호출된 객체예요. 속성이나 루틴을 그냥 이름만으로
써도 이미 `self`의 것을 뜻하기 때문에, `self`는 좀처럼 쓰지 않아요. 객체를
넘겨주거나 반환해야 할 때 필요해요:

```sather
   with_goal : SAME is
      home_score := home_score + 1;
      return self;
   end;
```

`self`, `new`, `void`, `result`, `value`, `out`은 모두 Sather가 이미 가져간
단어라서, 어느 것도 직접 만든 이름으로 쓸 수 없어요.

## 값이 아니라 참조

객체는 참조를 통해 접근해요. 같은 스코어보드를 가리키는 두 이름은 같은 점수를
봐요:

```sather
   a ::= #SCOREBOARD("Vixens", "Magpies");
   b ::= a;         -- not a copy
   b.home_goal;
   a.home_score     -- 1
```

다른 동작을 얻는 방법은 나중에 다룰 `immutable class`예요.
