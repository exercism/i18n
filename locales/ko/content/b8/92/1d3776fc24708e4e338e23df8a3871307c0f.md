# 소개

## 참과 거짓

참과 거짓이라는 논리 상태는 Ruby에서 `true`와 `false`로 표현해요.
이것들은 그 자체로 리터럴로 쓰이거나, 논리 연산이나 비교 메서드의 결과로 쓰일 수 있어요.

```ruby
happy = true
sad = false

true && false
# => false

1 < 2
# => true
```

## _truthy_와 _falsey_

`if`문이나 다른 불리언 문맥에서 객체를 평가할 때, `nil`과 `false`를 **제외한** 모든 객체는 _truthy_로 평가돼요.

## 제어 흐름

_truthy_와 _falsey_ 평가는 제어 흐름 문맥에서 유용해요.
절차적 언어에서처럼 Ruby에도 `if`...`else` 구문이 있지만, 표현식의 평가를 바꾸기 위해 `if`를 "가드" 문으로 사용하는 편이 더 흔할 수 있어요.

```ruby
def falsey
  nil || false
end

def truthy
  not falsey
end

if truthy
  # this block is evaluated
end

if falsey
  # this block is not evaluated
else
  # this block is evaluated
end

1 + 1 if truthy
# this will evaluate and return 2

2 + 2 if falsey
# the numbers are not added because of the modifier, nil is returned
```

Ruby는 코드가 잘 읽히도록 `unless`를 제공해요.
예를 들어 `eat_desert if not too_full` 대신 `eat_desert unless too_full`이라고 쓸 수도 있어요.

```ruby
3 + 3 unless truthy
# the numbers are not added because of the modifier, nil is returned

4 + 4 unless falsey
# this will evaluate and return 8
```
