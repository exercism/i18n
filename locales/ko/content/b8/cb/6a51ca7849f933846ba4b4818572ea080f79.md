# 지침 추가

## 힌트

이 자료 구조는 [`Rose Tree`](https://en.wikipedia.org/wiki/Rose_tree)라고 생각하면 돼요. 이 자료 구조를 나타내는 `'a tree`라는 데이터 타입이 주어져요.

**참고**

- 이 연습 문제에서 `Empty`는 `null`을 나타내요.
- 중첩된 배열은 `List [...]` 형태로 나타내요.
- 입력 예시는 `List [Elem 1, List [Elem 2, Elem 3, Empty, Elem 4], List [Empty], Elem 5]` 형태로 나타내요.
