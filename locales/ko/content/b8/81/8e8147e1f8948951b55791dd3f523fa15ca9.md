# 소개

## Julia의 불리언

참 또는 거짓 값은 `Bool` 타입으로 표현해요.
`Bool` 타입에는 `true`와 `false` 두 가지 값만 있어요.

```julia-repl
julia> true
true

julia> false
false
```

## 불리언 연산자

Julia에는 세 가지 불리언 연산자가 있어요.

`&&`는 불리언 "and"를 뜻해요.
`&&`의 *양쪽* 표현식이 `true`이면 `true`로 평가돼요.

```julia-repl
julia> true && true
true

julia> true && false
false
```

`||`는 불리언 "or"를 뜻해요.
`||`의 *어느 한쪽* 표현식이 `true`이면 `true`로 평가돼요.

```julia-repl
julia> true || true
true

julia> false || true
true
```

`!`는 불리언 "not"을 뜻해요.
`true`와 `false` 값을 서로 바꿔요.

```julia-repl
julia> !true
false

julia> !false
true
```

더 길고 복잡한 표현식에서는 괄호를 사용해 의도를 분명히 하는 게 좋아요.

```julia-repl
julia> (true || false) && (false && true)
false
```
