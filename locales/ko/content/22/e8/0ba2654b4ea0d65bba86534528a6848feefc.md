# 소개

[Reason](https://reasonml.github.io/)은 JavaScript 프로그래머를 대상으로 한 구문과 툴체인으로, 함수형 언어인 [OCaml](https://ocaml.org/)을 기반으로 해요.

정적 타입 언어라서 JavaScript보다 더 안전할 가능성이 높지만, 강력한 타입 추론 기능이 있어서 타입 주석이 발목을 잡지 않아요.

Exercism 연습 문제는 JS로 바로 컴파일되지만, Reason은 OCaml 툴체인을 통해 네이티브 코드, iOS, Android, 심지어 [마이크로컨트롤러](http://www.algo-prog.info/ocapic/web/index.php?id=ocapic)로도 컴파일할 수 있어요.
