# 소개

파이썬의 `str`은 [유니코드 코드 포인트][unicode code points]로 이루어진 [불변 시퀀스][text sequence]예요.
여기에는 문자, 발음 구별 기호, 위치 제어 문자, 숫자, 통화 기호, 이모지, 문장 부호, 공백과 줄 바꿈 문자 등이 포함될 수 있어요.

문자열은 모든 [공통 시퀀스 연산][common sequence operations]을 지원하고, `for item in <string>`이나 `for index, item in enumerate(<string>)` 문법으로 순회할 수 있어요.

문자열은 `<str> + <other str>`나 `<str>.join(<iterable>)`로 이어 붙이고, `<str>.split(<separator>)`로 나눌 수 있어요.
그 밖에도 다양한 포매팅, 조합, 템플릿 기능을 제공해요.

`str`은 불변이기 때문에 메모리에 있는 `str` 객체의 값은 바뀌지 않아요. 문자열을 수정하는 것처럼 보이는 메서드도 `str`의 새 복사본이나 새 인스턴스를 반환해요.

문자열이 어떤 정보를 담고 있는지 더 깊이 파고들고 싶다면(혹은 _"컴퓨터는 어떻게 0과 1을 글자로 옮기는 걸까요?"_), [이 블로그 글][joel-on-text]이 오래도록 도움이 돼요.
파이썬 문서에는 아주 자세한 [유니코드 HOWTO][unicode how-to]도 있는데, `str`, `bytes`, `re` 모듈에서 파이썬이 유니코드 명세를 어떻게 지원하는지, 로케일과 관련해 고려할 점, 인코딩과 변환에서 흔히 겪는 문제를 다뤄요.
