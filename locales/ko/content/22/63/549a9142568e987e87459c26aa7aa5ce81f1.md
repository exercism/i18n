# 소개

Clojure의 `vector`는 값을 0개 이상 담을 수 있는, 순서가 있고 인덱스로 접근하는 불변 컬렉션이에요. 즉, 한 번 만들어진 `vector`는 수정할 수 없어요. `vector`를 다루는 함수는 새로운 `vector`를 반환하고, 원래 `vector`는 그대로 남아 있어요. `vector`에 담기는 값들은 서로 다른 타입일 수 있어요. `vector`는 다음과 같이 정의해요:

```clojure
(def empty [])
(def single-value [5])
```

원소는 인덱스를 사용해 `vector`에서 꺼낼 수 있어요. Clojure의 `vector`는 0부터 시작해요. 즉, 첫 번째 원소의 인덱스는 항상 0이에요:

```clojure
(def numbers [2 3 5])
;; Read value from vector
(get numbers 2)
;;=> 5
;; Update value in vector
(assoc numbers 2 9)
;;=> [2 3 9]
```

원래 `vector`는 변하지 않아요:

```clojure
numbers
;;=> [2 3 5]
```

갱신된 값을 기억하려면 그 값을 계속 넘겨주거나 var에 담아 둬야 해요:

```clojure
(def updated-numbers
  (assoc numbers 2 9))
(get updated-numbers 2)
;;=> 9
```
