# 힌트

## 1. 이자율 계산하기

- Go 코드에서 기본적으로 정의하는 실수는 `float64`로 취급해요. `InterestRate` 함수의 반환 타입은 `float32`이므로 타입 변환은 따로 할 필요가 없어요.

## 2. 이자 계산하기

- 이자를 계산할 때는 `InterestRate`가 백분율을 반환한다는 점을 기억하면 도움이 돼요.
- 이전 단계에서 정의한 함수(`InterestRate`)를 사용해 이자를 계산할 수 있어요.
- `InterestRate`의 결과를 `float64`로 변환해야 할 수도 있어요.

## 3. 연간 잔액 갱신 계산하기

- 연간 잔액 갱신을 계산할 때는 이전 단계에서 정의한 함수를 사용해요.

## 4. 원하는 잔액에 도달하기까지 걸리는 연수 계산하기

- 연수를 계산하려면 원하는 잔액에 도달할 때까지 [`for`문](https://gobyexample.com/for)을 계속 반복하면 돼요.
- 값을 1씩 증가시키는 특별한 [연산자](https://golang.org/ref/spec#IncDec_statements)도 있어요.
