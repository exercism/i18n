# 지침 부록

이 Roc 연습 문제에서 계좌 연산은 순수해요. 각 업데이트는 새로운 계좌 값을 반환해요. 계좌는 닫힌 상태로 시작하고, 다시 열면 잔액이 초기화되며, 입금과 출금은 양수여야 해요. 잘못된 연산은 오류를 반환해요. 이 연습 문제는 계좌 로직에 집중하며 동시성은 테스트하지 않아요.

Roc에서는 일반적으로 동시성을 플랫폼에 맡기기 때문에, 여기에는 동시성 테스트가 없어요. 동시성 애플리케이션이라면 이런 순수 연산은 각 계좌 업데이트를 원자적으로 적용하는 메커니즘 안에서 실행될 거예요. 예를 들어, 플랫폼이 계좌 명령을 순차적으로 처리할 수도 있고, 데이터베이스 트랜잭션에 의존할 수도 있어요.

`parallel-letter-frequency` 연습 문제도 한번 확인해 보면 좋아요. 이 문제에서는 플랫폼이 Roc 코드에 병렬 컴퓨팅 기본 요소에 접근할 수 있게 해줘요. 실제 병렬성은 여전히 플랫폼이 관리하지만, Roc 코드는 그것에 대해 더 많은 제어권을 부여받아요.
