# 소개

Factor는 *연결형* 언어예요. 모든 워드는 공유 **데이터 스택**에서 입력을 읽고, 결과를 다시 그 위에 쌓아요. 값을 주고받는 다른 방법은 없어요.

리터럴을 쓰면 그 값이 스택 맨 위에 쌓이고, 코드는 왼쪽에서 오른쪽으로 읽어요:

```factor
1 2 3    ! stack (bottom → top): 1 2 3
```

*스택 효과* 선언은 워드가 지키는 계약을 보여줘요:

```factor
: restow ( a b -- b a ) swap ;
```

`( a b -- b a )`는 이 워드가 값을 두 개 꺼내서, 순서를 바꿔 두 개를 남긴다는 뜻이에요. 여기서 이름은 설명에 불과해요. 컴파일러가 검사하는 것은 입력과 출력의 *개수*뿐이고, 스택의 맨 위에 있는 값이 바로 오른쪽 이름이에요.

`kernel`에서 흔히 쓰는 **셔플 워드**는 스택 위쪽을 재배열해요:

```
dup  ( x   -- x x   )
drop ( x   --       )
swap ( x y -- y x   )
over ( x y -- x y x )
nip  ( x y -- y     )
rot  ( x y z -- y z x )
```

워드는 `:`로 시작하고 `;`로 끝나요. 정의의 본문이 선언한 스택 효과와 맞지 않으면 컴파일러가 받아들이지 않아요.
