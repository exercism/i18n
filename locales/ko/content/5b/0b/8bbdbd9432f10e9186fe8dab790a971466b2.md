# 지침

베를린의 새 공항이 로봇 연구소를 위해 개발자들을 채용했고, 여러분은 그곳에서 일을 시작해요.
그곳에는 투박하고 어딘가 사람을 닮은 로봇들이 있는데, 공항에서는 이 로봇으로 고객 서비스를 개선하려고 해요.

첫 번째 업무는, 사람들이 셀프 체크인 카운터에서 여권을 스캔한 뒤 로봇이 그 사람의 모국어로 인사할 수 있게 하는 프로그램을 작성하는 거예요.

로봇은 자기 능력을 자랑스러워해서, 항상 자기가 할 수 있는 언어가 무엇인지 먼저 말하고 그다음에 인사를 해요.
예를 들어 누군가 독일 여권을 스캔하면 로봇은 이렇게 말해요:

```txt
I can speak German: Hallo Dietrich!
```

## 1. 추상적인 인사 기능 만들기

여러분이 직접 각 언어의 코드를 작성하지는 않아요. 그래서 나중에 다른 개발자들이 더 많은 언어를 쉽게 추가할 수 있도록 로봇의 코드를 구조화해야 해요.

먼저 `Greeter` 인터페이스를 두 개의 메서드와 함께 정의해요.

- `LanguageName`은 로봇이 방문객에게 인사할 때 사용할 언어의 이름(`string`)을 반환해요.
- `Greet`은 방문객의 이름(`string`)을 받아서, 특정 언어의 인사말이 담긴 `string`을 반환해요.

다음으로 함수 `SayHello`를 구현해요. 이 함수는 방문객의 이름과 `Greeter` 인터페이스를 구현한 무엇이든 인자로 받아서, 원하는 인사 문자열을 반환해요.
예를 들어, `LanguageName`이 `"German"`을 반환하고 `Greet`이 `"Hallo {name}!"`을 반환하는 독일어 `Greeter` 구현이 있다고 해봐요:

```go
SayHello("Dietrich", germanGreeter)
// => "I can speak German: Hallo Dietrich!"
```

## 2. 이탈리아어 구현하기

이제 이탈리아 여권을 스캔한 사람들에게도 로봇이 작동하도록 만들 차례예요.

그러려면 `Italian` 구조체를 만들고, 이 구조체가 1번 작업에서 만든 `Greeter` 인터페이스를 충족하는 데 필요한 두 메서드를 구현해요.
이탈리아어로는 `"Ciao {name}!"`라고 인사하면 돼요.

## 3. 포르투갈어 구현하기

퇴근하기 전에, 포르투갈어로 인사하는 기능도 마무리해야 해요.

그러려면 `Portuguese` 구조체를 만들고, 여기에서도 이 구조체가 `Greeter` 인터페이스를 충족하는 데 필요한 두 메서드를 구현해요.
포르투갈어로는 `"Olá {name}!"`라고 인사하면 돼요.
