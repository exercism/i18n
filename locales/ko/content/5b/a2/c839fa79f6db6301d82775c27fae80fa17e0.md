# 지침 추가

## 힌트

이 연습 문제에서는 `Planet`이라는
[대수적 데이터 타입](https://learnyouahaskell.github.io/making-our-own-types-and-typeclasses)의
정의를 제공해요.
초 단위로 나이가 주어졌을 때, 어떤 사람이 `Planet`에서 몇 살이 되는지
계산하는 `ageOn` 함수를 구현해야 해요.

타입이 확실하지 않다면 제공된 시그니처를 사용해도 되지만,
거기에 얽매여 창의력을 제한할 필요는 없어요:

```haskell
ageOn :: Planet -> Float -> Float
```
