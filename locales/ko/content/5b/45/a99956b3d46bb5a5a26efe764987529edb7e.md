# 소개

Factor는 [`calendar`][calendar] 보캐블러리로 날짜와 시간을 다뤄요. 특정 시점은 `timestamp`이고, 시간의 폭은 `duration`이에요.

## 날짜 만들기

`<date>`는 [`calendar`][calendar]에 있는 단어로, 주어진 날의 자정을 나타내는 `timestamp`를 만들어요:

```
<date> ( year month day -- timestamp )
```

```factor
USING: calendar ;

1904 11 16 <date> .
! a timestamp at midnight on 1904-11-16
```

`>date<`는 `timestamp`를 다시 각 부분으로 나눠요:

```
>date< ( timestamp -- year month day )
```

```factor
1904 11 16 <date> >date< .   ! => 16   (with 1904 and 11 below it)
```

## 날짜 살펴보기

`day-of-week`는 요일을 정수로 반환해요. 일요일이 `0`이고 토요일이 `6`이에요. `day-names`는 [`calendar.english`][english]에 있는, 그에 대응하는 이름 목록이라서 `day-names nth`로 숫자를 이름으로 바꿀 수 있어요:

```factor
USING: calendar calendar.english sequences ;

2024 1 8 <date> day-of-week .          ! => 1
day-names .   ! { "Sunday" "Monday" ... "Saturday" } — Sunday first
```

`leap-year?`는 연도(또는 `timestamp`)를 받고, `days-in-month`는 `timestamp`가 속한 달의 길이를 반환해요. 윤년도 이미 반영되어 있어요:

```
leap-year?    ( obj -- ? )
days-in-month ( timestamp -- n )
```

```factor
2024 leap-year? .                ! => t
2024 2 1 <date> days-in-month .  ! => 29
```

## 날짜 연산

`days`, `weeks`, `hours` 같은 단어들은 `duration`을 만들고, `time+`는 `timestamp`를 그만큼 옮겨요:

```
days  ( x -- duration )
time+ ( timestamp duration -- timestamp )
```

```factor
2024 2 28 <date> 1 days time+ >date< .
! => 29   (2024-02-29, with 2024 and 2 below it)
```

연산은 월과 연도의 경계를 넘어가도 올바르게 이어져요. 같은 순간을 가리키는 두 `timestamp`는 `=`로 비교하면 같아요.

## 하루 중의 시각

`<timestamp>`는 초 단위까지 갖춘 완전한 timestamp를 만들어요. 마지막 인자는 UTC로부터의 오프셋이고, `instant`(값이 0인 `duration`)를 쓰면 timestamp가 UTC에 머물러요:

```
<timestamp> ( year month day hour minute second gmt-offset -- timestamp )
```

```factor
USING: calendar ;

1969 7 21 2 56 15 instant <timestamp> .
! a timestamp at 02:56:15 on 1969-07-21
```

`>time<`는 `>date<`의 짝으로, timestamp를 시, 분, 초로 나눠요:

```
>time< ( timestamp -- hour minute second )
```

```factor
1969 7 21 2 56 15 instant <timestamp> >time< .   ! => 15   (with 2 and 56 below it)
```

`seconds`와 `minutes`는 `days`, `weeks`, `hours`와 마찬가지로 `duration`을 만들어서, 어느 것이든 `time+`에 넘길 수 있어요:

```
seconds ( x -- duration )
minutes ( x -- duration )
```

timestamp의 각 필드는 접근자 `year>>`, `month>>`, `day>>`, `hour>>`, `minute>>`, `second>>`로 읽어요:

```factor
1969 7 21 2 56 15 instant <timestamp> hour>> .   ! => 2
```
