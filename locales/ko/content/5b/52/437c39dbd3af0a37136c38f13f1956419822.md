# 지침

이 연습 문제에서는 좋아하는 요리책에 나오는 근사한 라자냐를 요리할 수 있도록 도와주는 코드를 작성해 볼 거예요.

라자냐를 요리하는 데 걸리는 시간과 관련된 네 가지 과제가 있어요.

~~~~exercism/note
타입을 지정하지 않는 타입 추론을 사용하거나, 타입을 지정하는 명시적 타이핑을 사용할 수 있어요.
후자를 선택한다면 타입으로 `int`를 사용해요.
~~~~

## 1. 오븐에 있어야 하는 예상 시간(분)을 정의해요

라자냐가 오븐에 몇 분 동안 있어야 하는지 확인하는 `expectedMinutesInOven` 바인딩을 정의해요. 요리책에 따르면 오븐에 있어야 하는 예상 시간은 40분이에요.

```fsharp
expectedMinutesInOven
// => 40
```

## 2. 오븐에 남은 시간(분)을 계산해요

라자냐가 실제로 오븐에 있었던 시간(분)을 매개변수로 받아서, 이전 과제에서 구한 오븐에 있어야 하는 예상 시간(분)을 기준으로 라자냐가 오븐에 앞으로 몇 분 더 있어야 하는지 반환하는 `remainingMinutesInOven` 함수를 정의해요.

```fsharp
remainingMinutesInOven 30
// => 10
```

## 3. 준비 시간(분)을 계산해요

라자냐에 추가한 층 수를 매개변수로 받아서, 각 층을 준비하는 데 2분이 걸린다고 가정했을 때 라자냐를 준비하는 데 몇 분을 썼는지 반환하는 `preparationTimeInMinutes` 함수를 정의해요.

```fsharp
preparationTimeInMinutes 2
// => 4
```

## 4. 경과 시간(분)을 계산해요

`elapsedTimeInMinutes` 함수를 정의해요. 이 함수는 두 개의 매개변수를 받아요. 첫 번째 매개변수는 라자냐에 추가한 층 수이고, 두 번째 매개변수는 라자냐가 오븐에 있었던 시간(분)이에요. 이 함수는 라자냐 요리에 쓴 시간(분)을 반환해야 해요. 이 시간은 준비 시간(분)과 현재까지 라자냐가 오븐에서 보낸 시간(분)을 더한 값이에요.

```fsharp
elapsedTimeInMinutes 3 20
// => 26
```
