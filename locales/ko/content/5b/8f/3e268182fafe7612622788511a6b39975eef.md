# 지시 사항

이 연습 문제에서는 창 기반 컴퓨터 시스템을 시뮬레이션해요.
이동하고 크기를 조절할 수 있는 창을 몇 개 만들어요.
다음 이미지는 아래에서 다룰 값들을 보여줘요.

```text
 ╔════════════════════════════════════════════════════════════╗
 ║                                                            ║
 ║        position::$y,_                                      ║
 ║        position::$x  \                                     ║
 ║                       \<---- size::$width ---->            ║
 ║                 ^      *──────────────────────┐            ║
 ║                 |      │        title         │            ║
 ║                 |      ├──────────────────────┤            ║
 ║                 |      │                      │            ║
 ║          size::$height │                      │            ║
 ║                 |      │       contents       │            ║
 ║                 |      │                      │            ║
 ║                 |      │                      │            ║
 ║                 v      └──────────────────────┘            ║
 ║                                                            ║
 ║                                                            ║
 ╚════════════════════════════════════════════════════════════╝
```

## 1. 프로그램 창의 속성 정의하기

제공된 클래스 뼈대를 사용해 `y`, `x`, `height`, `width` 값에 대한 속성을 정의해요.

```php
<?php

$window = new ProgramWindow();
$window->y; // => null
$window->x; // => null
$window->height; // => null
$window->width; // => null
```

## 2. 프로그램 창의 초기값 정의하기

`ProgramWindow`에 대한 생성자 함수를 정의해요.
인자는 받지 않지만, 생성자가 실행되는 동안 속성의 기본값을 설정해요.
초기 `y`와 `x` 값을 `0`으로 설정해요.
초기 `height`와 `width`는 `600x800` 화면 크기로 설정해요.

```php
<?php

$window = new ProgramWindow();
$window->y; // => 0 
$window->x; // => 0
$window->height; // => 600
$window->width; // => 800
```

## 3. 창 크기를 조절하는 함수 정의하기

`Size.php`에 Size 클래스를 새로 정의해요.
생성자 인자로 `height`와 `width` 속성을 설정해요.
또한 `ProgramWindow`에는 `Size` 객체 인스턴스를 받아 자신의 속성을 갱신하는 resize 함수가 필요해요.

```php
<?php 

$window = new ProgramWindow();
$size = new Size(764, 1080);
$window->resize($size)

$window->height;
// => 764
$window->width;
// => 1080
```

## 4. 창을 이동하는 함수 정의하기

`Position.php`에 Position 클래스를 새로 정의해요.
생성자 인자로 `y`와 `x` 속성을 설정해요.
또한 `ProgramWindow`에는 `Position` 객체 인스턴스를 받아 자신의 속성을 갱신하는 move 함수가 필요해요.

```php
<?php 

$window = new ProgramWindow();
$position = new Position(80, 313);
$window->move($position)

$window->y;
// => 80
$window->x;
// => 313
```
