# 힌트

## 일반

- 공식 가이드에서 [패턴 매칭][pattern-matching]에 대해 읽어봐요.
- [구조 분해][destructuring]에 관한 이 치트시트를 한번 살펴봐요.
- 레코드에 대한 패턴 매칭은 [여기][records-pattern-matching]에서 더 자세히 설명해요.

## 1. 빈 댓글 찾아내기

- 인자가 쌍이라면 함수 인자에 `(a, b)`를 바로 사용할 수 있어요.
- 받았지만 사용하지 않는 값은 와일드카드 `_`로 대체할 수 있어요.
- 문자열이 비어 있는지 확인하려면 [`String` 문서][string-docs]를 확인해요.

## 2. 작성자가 남긴 댓글 수 세기

- 변형이 하나뿐인 사용자 정의 타입 `type Box = Box AB`는 함수 인자에서 `(Box ab)`처럼 바로 구조 분해할 수 있어요.
- 레코드 `{a : A, b : B}`의 필드 `a`는 `{ a }`를 사용해 패턴 매칭할 수 있어요.
- 레코드를 담고 있는 사용자 정의 타입에는 위 두 기법을 동시에 사용할 수 있어요.
- 레코드 `{ ab : (A, B) }`에서 쌍 `ab`를 바로 패턴 매칭할 수는 없어요. 먼저 `{ ab }`를 패턴 매칭한 다음, `let` 바인딩에서 `( a, b) = ab`를 사용해야 해요.
- 리스트에서 조건을 만족하는 원소의 개수를 구하려면 [`List` 함수][list-docs]를 사용해요.
- 익명 함수의 인자에서 쌍을 바로 구조 분해할 수 있어요.

## 3. Dev Team에 배정된 티켓 찾아내기

- 2번 과제에서처럼 함수 인자에서 "박스에 담긴" 레코드의 관련 필드를 매칭할 수 있어요.
- 패턴 매칭을 재귀적으로 사용하면 `Just (Box "42")`처럼 중첩된 값을 매칭할 수 있어요.
- `case`문에서는 와일드카드 `_`로 무엇이든 매칭할 수 있어요. 

## 4. IT 직원에게 티켓 배정하기

- 2번과 3번 과제에서처럼 함수 인자에서 "박스에 담긴" 레코드의 관련 필드를 매칭할 수 있어요.
- 게다가 `as` 키워드를 사용하면 필드를 패턴 매칭하면서 레코드 전체도 함께 바인딩할 수 있어요: `(Box ({ a } as ab))`.
- `case`문으로 사용자 정의 타입의 값을 패턴 매칭할 수 있어요.
- 티켓을 반환하려면 타입 생성자 `Ticket`을 사용해요.
- 레코드를 수정하려면 [레코드 업데이트 문법][record-update]을 사용해요.
