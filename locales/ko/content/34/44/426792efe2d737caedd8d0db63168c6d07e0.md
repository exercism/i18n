# 소개

## Nil

Gleam의 `Nil`은 값이 하나뿐인 타입이고, 그 값의 이름도 `Nil`이에요. 다른 언어의 `void`와 비슷하게, 함수가 반환할 만한 더 적절한 값이 없을 때 사용해요.

```gleam
io.println("Hello, Joe!")
// -> Nil
```

Gleam의 값은 다른 언어에서처럼 "nil이 될 수 있거나" "null을 허용하는" 값이 아니에요. 값의 타입이 `Nil`일 때만 그 값이 `Nil`일 수 있고, 다른 타입의 값은 절대 `Nil`이 될 수 없어요.

## IO

대부분의 프로그래밍 언어처럼 Gleam에도 "부수 효과"가 있어요. 그래서 함수는 값을 반환할 뿐만 아니라 세상의 상태를 읽고 바꿀 수도 있어요.

Gleam 표준 라이브러리의 `gleam/io` 모듈은 문자열을 콘솔에 출력하는 함수를 제공해요.

```gleam
io.println("Hello, Joe!")
// Hello, Joe!
// -> Nil
```

다른 패키지에서 다른 IO 함수를 제공하기도 해요. 예를 들어 `simplifile`은 파일을 읽고 쓰는 함수를 제공하는 패키지예요.

```gleam
simplifile.read("favourite-colour.txt")
// -> Ok("Pink\n")
```
