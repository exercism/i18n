# 소개

Haxe는 오픈 소스 고수준, 강타입, 크로스 플랫폼, 객체 지향 프로그래밍 언어이자 컴파일러로, 하나의 코드베이스에서 여러 컴퓨팅 플랫폼을 위한 애플리케이션과 소스 코드를 만들어 낼 수 있어요.

서로 다른 사용 사례를 지원하는 여러 타깃 언어가 있어요: [지원하는 타깃 언어][supported-target-languages]

[타입][types]에서는 Haxe에 있는 일곱 가지 타입과 이들이 서로 어떻게 어울리는지 소개해요. 타입에 대한 이야기는 [타입 시스템][type-system]에서 이어지는데, 여기서는 통합, 타입 매개변수, 타입 추론 같은 기능을 설명해요.

[클래스 필드][class-fields]는 Haxe 클래스의 구조를 다루는 내용으로, 여러 주제 중에서도 속성, 인라인 필드, 제네릭 함수를 살펴봐요.

[표현식][expressions]에서는 표현식을 사용해 프로그램이 실제로 무언가를 하도록 만드는 방법을 알아봐요.

[언어 기능][language-features]은 패턴 매칭, 문자열 보간, 데드 코드 제거 같은 몇 가지 기능을 자세히 설명하면서 Haxe 언어 레퍼런스를 마무리해요.
