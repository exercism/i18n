# 테스트

## 테스트 실행하기
Haxe 트랙은 테스트 프레임워크인 [Buddy](https://github.com/ciscoheat/buddy)를 사용해요.
다음 명령으로 설치할 수 있어요:

```bash
haxelib install buddy
```

테스트를 실행하려면 다음 명령을 실행해요:

```bash
haxe test.hxml
```

테스트 파일에서 각 describe 블록은 연습 문제 테스트의 한 구역을 표시하고, 각 테스트는 `it` 또는 `xit` 블록이에요.
`it` 블록은 테스트를 실행할 때 실행되지만, `xit` 블록은 보류 중인 테스트예요.
풀이를 제출하면 Exercism 테스트 러너가 모든 `it` 또는 `xit` 블록을 실행해요.
로컬에서 작업할 때는 기본적으로 첫 번째 테스트만 실행돼요.
다른 테스트를 실행하려면 해당하는 `xit` 블록을 `it` 블록으로 바꾸고 `haxe test.hxml`을 다시 실행해요.


또한 일부 연습 문제는 haxelib으로 추가 라이브러리를 설치해야 할 수도 있어요.
그런 경우에는 연습 문제 안내에 설명이 있어요.

## 연습 문제 풀기

연습 문제를 푼다는 것은 그 문제의 모든 테스트를 통과시킨다는 뜻이에요.
시작하는 데 도움이 되도록, 각 연습 문제에는 스텁 구현 파일이 함께 제공돼요.
이 파일을 풀이를 만들어 나가는 출발점으로 삼아도 돼요.
이 파일을 지우거나 바꾸는 게 맞다고 생각되면 얼마든지 그렇게 해도 돼요.
풀이를 완성해 나가면서 한 번에 테스트 하나씩에 집중해 봐요.
