# 힌트

## 일반

- `module`인 `TicketingReservation` 안에 initialize를 제외한 모든 메서드를 정의해야 해요.
- `module`은 `TicketSystem` 클래스 위에 놓여야 해요.

## 1. 티켓 시스템 만들기

- `TicketSystem`이라는 클래스를 만들어요.
- `TicketSystem` 클래스의 [생성자][new-initialize]를 만들어요.
- 생성자에 전달된 첫 번째 인자의 값으로 설정되는 [인스턴스 변수][instance-variable] `@tickets_available`을 만들어요.
- 생성자에 전달된 두 번째 인자의 이름으로 설정되는 [인스턴스 변수][instance-variable] `@stadium`을 만들어요.

## 2. 사용 가능한 티켓 수 구하기

- `TicketSystem` 클래스 위에 `TicketingReservation`이라는 모듈을 만들어요.
- [include][include] 키워드를 사용해 모듈을 클래스에 연결해요.
- 모듈 안에 사용 가능한 티켓 수를 반환하는 `tickets_available`이라는 메서드를 만들어요.

## 3. 티켓 주문하기

- 모듈 안에 `order_ticket?`이라는 메서드를 만들어요.
- [비교 연산자][equality-and-comparison]를 사용해 티켓이 최소 100장 있는지 확인해요.
- 티켓이 최소 100장 있으면 `@tickets_available` [인스턴스 변수][instance-variable]에서 1을 빼요.
- 티켓이 최소 100장 있으면 `true`를 반환하고, 그렇지 않으면 `false`를 반환해요.

## 4. 주문 메시지

- 모듈 안에 `order_message`라는 메서드를 만들어요.
- 이미 정의한 메서드를 사용해 티켓이 충분한지 확인할 수 있어요.
- 메시지를 만들 때는 [문자열 보간][string-interpolation]을 사용할 수 있어요.
