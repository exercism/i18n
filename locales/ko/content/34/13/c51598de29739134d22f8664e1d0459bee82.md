# 지시 사항

이 연습 문제에서는 자동차 공장 조립 라인의 생산량을 분석하는 코드를 작성해요.
조립 라인의 속도는 `0`(꺼짐)부터 `10`(최대)까지 설정할 수 있어요.

가장 낮은 속도인 `1`에서는 시간당 `221`대의 자동차가 생산돼요.
생산량은 속도에 비례해서 늘어나요.
그래서 속도를 `4`로 설정하면 시간당 `4 * 221 = 884`대의 자동차를 생산해야 해요.
하지만 속도가 높아질수록 결함이 있는 자동차가 생산될 가능성도 커지고, 이런 자동차는 폐기해야 해요.

세 가지 작업이 있어요.

## 1. 성공률 계산하기

주어진 속도에서 제품이 오류 없이 만들어질 비율을 계산하는 (_static_) `AssemblyLine.SuccessRate()` 메서드를 구현해요.
다음 표는 속도가 성공률에 어떤 영향을 주는지 보여줘요.

- `0`: 성공률 0%.
- `1`부터 `4`까지: 성공률 100%.
- `5`부터 `8`까지: 성공률 90%.
- `9`: 성공률 80%.
- `10`: 성공률 77%.

```csharp
AssemblyLine.SuccessRate(10)
// => 0.77
```

## 2. 시간당 생산량 계산하기

성공률을 고려해서 조립 라인의 시간당 생산량을 계산하는 (_static_) `AssemblyLine.ProductionRatePerHour()` 메서드를 구현해요.

```csharp
AssemblyLine.ProductionRatePerHour(6)
// => 1193.4
```

반환되는 값은 `double`이라는 점에 주의해요.

## 3. 분당 생산되는 정상 제품 수 계산하기

분당 정상 자동차가 몇 대 생산되는지 계산하는 (_static_) `AssemblyLine.WorkingItemsPerMinute()` 메서드를 구현해요.

```csharp
AssemblyLine.WorkingItemsPerMinute(6)
// => 19
```

반환되는 값은 `int`라는 점에 주의해요.
