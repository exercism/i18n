# Introduction

Java에서 불리언은 `boolean` 타입으로 표현되며, 이 값은 `true` 또는 `false` 중 하나예요.

Java는 세 가지 불리언 연산자를 지원해요:  

- `!` (NOT): 불리언을 부정해요  
- `&&` (AND): 두 불리언을 받아서 둘 다 true일 때 true를 반환해요  
- `||` (OR): 두 불리언 중 하나라도 true이면 true를 반환해요  

## Examples

```java
!true // => false
!false // => true
true && false // => false
true && true // => true
false || false // => false
false || true // => true
```
