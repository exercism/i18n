# 설명

[`IEnumerable<T>`][IEnumerable] 인터페이스를 구현하는 타입을 _열거 가능_ 한 타입이라고 해요.
모든 내장 컬렉션 타입은 이 인터페이스를 구현해요.

열거 가능한 타입은 `foreach`문을 사용해 반복할 수 있어요:

```csharp
var primes = new[] { 2, 3, 5, 7 };
foreach (var prime in primes)
{
    Console.Write(prime);
}
// => 2357
```

`IEnumerable<T>`를 구현하려면 타입은 메서드 하나를 구현해야 해요: `IEnumerator<T> GetEnumerator()`.
앞에서 봤듯이, 열거 가능한 타입은 컬렉션을 실제로 반복하는 일을 `IEnumerator<T>` 타입에 맡겨요.
이 인터페이스에는 구현해야 할 속성 하나와 메서드 세 개가 있어요:

- `public T Current { get; }`: 현재 원소를 가져와요.
- `public bool MoveNext ();`: 다음 원소로 이동해요. 다음 원소로 성공적으로 이동하면 `true`를, 그렇지 않으면(더 이상 원소가 없으면) `false`를 반환해요.
- `public void Reset ();`: 열거자를 초기 상태(첫 번째 원소 이전)로 되돌려요.

[IEnumerable]: https://docs.microsoft.com/en-us/dotnet/api/system.collections.generic.ienumerable-1
