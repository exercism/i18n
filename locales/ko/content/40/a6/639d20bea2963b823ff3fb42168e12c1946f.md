# 지침 추가

## Python 트랙에서 이 연습 문제가 어떻게 구성되어 있는지

이 연습 문제의 테스트는 Matrix [`class`][classes]를 만들 것을 요구해요 (_[concept:python/classes]()도 참고해 보세요_).
이는 [Numpy][numpy-matrix] 같은 서드파티 라이브러리의 Matrix 객체를 _사용하는_ 것과는 달라요. 그런 방식은 지원하지 않아요.
 _걱정하지 않아도 돼요. 생각보다 복잡하지 않아요!_
 `classes`와 데이터 구조에 대한 더 많은 시작점과 자세한 내용은 아래 자료를 살펴봐요:


-   [**클래스 첫 살펴보기**](https://docs.python.org/3/tutorial/classes.html#a-first-look-at-classes) (Python 3 문서)
-   [**Python에서 클래스 정의하기**](https://realpython.com/python3-object-oriented-programming/#how-to-define-a-class-in-python) (Real Python 웹사이트)  
-   [**Python의 데이터 구조**](https://docs.python.org/3/tutorial/datastructures.html) (Python 3 문서)

[numpy-matrix]: https://numpy.org/doc/stable/reference/generated/numpy.matrix.html
