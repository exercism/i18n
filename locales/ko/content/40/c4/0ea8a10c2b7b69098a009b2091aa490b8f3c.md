# 소개

Python의 [비교 연산자][comparisons](_Python 관계 연산자_라고도 해요)는 두 [피연산자][operand]의 _값_을 살펴보고, `comparison` 조건이 충족되는지 여부에 따라 불리언 `True` 또는 `False`를 반환해요.

아래 표는 가장 흔히 쓰이는 Python 비교 연산자를 보여줘요:

| 연산자   | 연산                       | 설명                                                                      |
| -------- | -------------------------- | ------------------------------------------------------------------------- |
| `>`      | "보다 큼"                  | `a > b`는 `a`의 값이 `b`보다 **엄격하게** 클 때 `True`예요                |
| `<`      | "보다 작음"                | `a < b`는 `a`의 값이 `b`보다 **엄격하게** 작을 때 `True`예요              |
| `==`     | "같음"                     | `a == b`는 `a`의 값이 `b`와 **엄격하게** 같을 때 `True`예요               |
| `>=`     | "크거나 같음"              | `a >= b`는 `a > b`이거나 값이 `a == b`일 때 `True`예요                    |
| `<=`     | "작거나 같음"              | `a <= b`는 `a < b`이거나 값이 `a == b`일 때 `True`예요                    |
| `!=`     | "같지 않음"                | `a != b`는 `a == b`가 `False`일 때 `True`예요                             |
| `is`     | "동일성"                   | `a is b`는 `a`와 `b`가 같은 _객체_일 때 **_오직 그럴 때만_** `True`예요    |
| `is not` | "부정 동일성"              | `a is not b`는 `a`와 `b`가 같은 _객체_가 **아닐** 때 **_오직 그럴 때만_** `True`예요 |
| `in`     | "포함 여부 검사"           | `a in b`는 `a`가 `b`의 멤버, 부분집합 또는 원소일 때 `True`예요           |
| `not in` | "부정 포함 여부 검사"      | `a not in b`는 `a`가 `b`의 멤버, 부분집합 또는 원소가 아닐 때 `True`예요  |

이 연산자들은 모두 우선순위가 같아요(_[불리언 연산][boolean operations]보다는 높고, 산술 연산이나 비트 연산보다는 낮아요_).

## 서로 다른 데이터 타입 간의 비교

서로 다른 타입인 객체는(_숫자 타입은 예외로_) 기본적으로 절대 같다고 비교되지 않아요.
`class`의 서로 다른 인스턴스 역시, `class`가 기본 `object` 비교 동작을 커스터마이즈하는 특수 메서드를 정의하지 않는 한, 같다고 비교되지 _**않아요**_.

숫자 타입은 (대부분) 이 타입 일치 규칙의 예외예요.
`integer`는 `float`와 같다고 간주될 **수 있어요**(_[`octal`][octal]이 [`hexadecimal`][hex]과 같을 수 있는 것처럼요_). 단, 두 타입이 비교를 위해 암시적으로 변환될 수 있어야 해요.

다른 숫자 타입([복소수][complex numbers], [십진수][decimal numbers], [분수][rational numbers])의 경우, 비교 연산자는 "말이 되는" 곳에서 정의되어 있지만(_암시적 변환이 결과를 바꾸지 않는 곳_), 기반 객체들이 비교를 위해 정확하게 변환될 수 없다면 `TypeError`를 발생시켜요.

## 객체 동일성 비교

`is`와 `is not` 연산자는 객체의 _값_이 아니라 객체의 [_동일성_][object identity]을 검사해요.
객체의 동일성은 한 번 생성된 뒤에는 절대 변하지 않으며, [`id()`][id function] 함수로 확인할 수 있어요.

`<apple> is <orange>`는 `id(<apple>)` == `id(<orange>)`일 때 **_오직 그럴 때만_** `True`로 평가돼요.
`<apple> is not <orange>`는 그 반대를 반환해요.

## 멤버십 비교

`in`과 `not in` 연산자는 _멤버십_을 검사해요.
`<fish> in <soup>`는 `<fish>`가 `<soup>`의 멤버일 때(_`<fish>`가 `<soup>`의 부분집합이거나 `<soup>`에 포함될 때_) `True`로 평가되고, 그렇지 않으면 `False`로 평가돼요.
`<fish> not in <soup>`는 `<fish> in <soup>`의 부정, 즉 _반대_를 반환해요.

문자열과 bytes 타입의 경우, `<name> in <fullname>`은 `<name>`이 `<fullname>`의 부분 문자열일 때 **_오직 그럴 때만_** `True`예요.
