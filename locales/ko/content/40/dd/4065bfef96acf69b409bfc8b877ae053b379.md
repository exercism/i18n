# 지침

두 명의 바이올리니스트가 듀엣을 연습하고 있어요. 각 파트는 각 마디의 음표 수를 담은 배열이고, 파트의 길이가 항상 같지는 않아요.

네 가지 과제는 모두 `DUET_PRACTICE` 클래스 안에 작성해요.

## 1. 두 사람이 함께 연주하는 마디는 몇 마디일까요?

두 파트 모두 마디가 남아 있는 동안 함께 연주해요.

```sather
DUET_PRACTICE::bars_together(|4, 4, 8, 8|, |4, 4|)
-- => 2
```

## 2. 일치하는 마디는 몇 마디일까요?

두 파트의 음표 수가 같은 마디를 세요. 두 파트 모두에 있는 마디만 일치할 수 있어요.

```sather
DUET_PRACTICE::in_unison(|4, 4, 8|, |4, 2, 8|)
-- => 2
```

## 3. 누가 더 바쁠까요?

첫 번째 파트가 두 번째 파트보다 음표가 더 많은 마디를 세요.

```sather
DUET_PRACTICE::louder_bars(|4, 8, 2|, |4, 2, 8|)
-- => 1
```

## 4. 마디에 가중치를 매겨요

뒤에 있는 마디일수록 더 어려우니까, 마디는 위치만큼 비중 있게 세요. 첫 번째 마디는 한 번, 두 번째 마디는 두 번, 세 번째 마디는 세 번이에요. 각 마디의 음표 수에 마디 번호를 곱한 뒤 모두 더해요.

```sather
DUET_PRACTICE::weighted_total(|4, 4, 8|)
-- => 36
```

이는 1×4 + 2×4 + 3×8이에요. 마디 번호는 0이 아니라 1부터 시작해요.
