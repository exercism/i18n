# 소개

Go를 좋아하는 사람들(_고퍼_라고 불러요)은 Go가 Python이나 Ruby 같은 동적 언어의 표현력과 C나 C++ 같은 컴파일 언어의 성능을 모두 갖췄다고 말해요.

이 언어는 오픈 소스이고, Google의 엔지니어들이 시작했어요.
C 스타일 문법으로 작성되었고, 변수는 정적으로 타입이 지정되며, 가비지 컬렉션으로 메모리를 관리하고, 독립 실행형 실행 파일로 컴파일돼요.

Go는 언어 핵심에 내장된 [동시성 프로그래밍 기능](https://golang.org/doc/effective_go.html#concurrency), 표준 라이브러리의 네트워킹 패키지([예를 들어 웹 서버](https://pkg.go.dev/net/http)), 빠른 컴파일과 실행 속도로 유명해요.
단순하고 미니멀하며 일관된 언어 설계는 즐거운 경험을 선사하고, 풍부하고 세심한 도구들은 [일관된 포매팅](https://pkg.go.dev/cmd/gofmt)과 [문서화](https://pkg.go.dev/golang.org/x/tools/cmd/godoc) 같은 오래된 문제들을 해결해 줘요.

Go의 홈페이지는 [go.dev](https://go.dev/)이고, [tour.go.dev](https://tour.go.dev/)에는 훌륭한 대화형 튜토리얼이 있어요.
