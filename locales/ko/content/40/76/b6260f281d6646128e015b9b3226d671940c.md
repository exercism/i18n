# 테스트

테스트를 실행하기 전에, 설치 단계를 따라 과제 폴더가 제대로 설정되어 있는지 확인해요. 즉, `corepack yarn install`과 Editor SDK 설정이에요.

다음 명령으로 테스트를 실행해요:

```bash
$ corepack yarn test
```

## 건너뛴 테스트

테스트 스위트에서는 첫 번째 테스트를 제외한 나머지가 모두 건너뛰도록 설정되어 있어요.

테스트 하나가 통과되면, `xit`를 `it`로 바꿔서 다음 테스트를 활성화할 수 있어요.
또한 테스트는 `xdescribe`로 그룹화되어 있을 수 있어요.
이를 `describe`로 바꾸면 그룹을 활성화할 수 있어요.
마지막으로, 일부 연습 문제에는 선택적인 테스트 `it.skip`이 있을 수 있어요.
`.skip`을 지우면 그 선택적인 테스트를 실행할 수 있어요.
