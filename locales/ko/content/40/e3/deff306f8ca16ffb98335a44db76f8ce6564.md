# 소개

Factor에서 대부분의 데이터는 *시퀀스*에 담겨 있어요. 배열(`{ … }`), 벡터(`V{ … }`), 문자열은 모두 [`sequences`][sequences]의 동일한 [프로토콜][sequence-protocol]을 공유해요.

```factor
{ 1 2 3 } length .    ! => 3
{ 1 2 3 } first .     ! => 1
{ 1 2 3 } last .      ! => 3
{ 1 2 3 4 5 } 3 head .! => { 1 2 3 }
```

집계 연산인 `sum`, `count`, `any?`, `all?`과 `empty?`, `member?` 같은 술어는 모든 시퀀스 타입에서 똑같이 동작해요. 원본을 변경하지 않고 새로운 시퀀스를 만드는 연산도 있어요: `prefix`, `suffix`, `append`, `unclip`, `unclip-last`.

`>array`, `>vector`, `>string`([`arrays`][arrays]와 해당 보캐뷸러리에 있어요)은 일반적인 연산의 결과로 특정한 구체 타입이 필요할 때 시퀀스 타입 사이를 변환해 줘요.

[arrays]: https://docs.factorcode.org/content/vocab-arrays.html

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
[sequence-protocol]: https://docs.factorcode.org/content/article-sequence-protocol.html
