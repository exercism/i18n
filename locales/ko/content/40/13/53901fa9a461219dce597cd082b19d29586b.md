# 소개

클로저의 모든 표준 데이터 타입은 불변이기 때문에, 클로저는 제어된 변경을 제공하는 *참조 타입*을 제공해요. 그중 가장 단순하고 가장 흔히 쓰이는 것이 아톰이에요.

아톰은 `atom` 함수로 만들어요. 이 함수는 초깃값을 받아요:

```clojure
(def players (atom ()))
```

아톰의 현재 값은 `deref`나 `@` 축약형으로 역참조해요:

```clojure
@players
;;=> ()
```

`players` 아톰의 현재 값은 `swap!`으로 바꿀 수 있어요. `swap!`은 함수를 적용해서 값을 갱신해요:

```clojure
(swap! players conj :player1)
;;=> (:player1)
```

`reset!` 함수는 아톰의 현재 값과 상관없이 값을 교체해요:

```clojure
(reset! players ())
```
