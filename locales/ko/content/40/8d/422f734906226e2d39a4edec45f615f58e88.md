# 힌트

## 1. 기념일 표지판 만들기

- [템플릿 문자열][mdn-template-strings](템플릿 리터럴)을 사용하면 하나 이상의 문자열을 치환하거나 표현식을 삽입할 수 있어요

## 2. 생일 표지판 만들기

- [템플릿 문자열][mdn-template-strings](템플릿 리터럴)을 사용하면 문자열을 치환하고 표현식을 삽입할 수 있어요
- [삼항 연산자][mdn-ternary-operator]는 `if/else`와 비슷하게 조건을 다루는 축약형 표현이에요. 템플릿 문자열 안에서는 더 간결하기 때문에 사용하기가 더 쉬울 수 있어요.

## 3. 졸업 표지판 만들기

- [템플릿 문자열][mdn-template-strings]을 사용하면 문자열을 여러 줄에 걸쳐 작성할 수 있어요.

## 4. 표지판 가격 계산하기

- 문자의 [`length`][mdn-string-length]를 구해요.
- [고정 소수점][mdn-to-fixed] 표기법을 사용해 소수점 이하 두 자리까지만 표시해요.
