# 소개

Euphoria는 기존 언어들에 비해 다음과 같은 장점을 가진 프로그래밍 언어예요:

## Euphoric

놀랄 만큼 단순하고 유연하며 강력한 언어 정의로, 배우고 쓰기 쉬워요.

## 동적

프로그래머가 메모리 덩어리를 할당하고 해제할 걱정 없이 변수가 늘었다 줄었다 해요.
어떤 크기의 객체든 Euphoria 시퀀스(배열)의 원소에 대입할 수 있어요.

## 빠른 속도

Perl이나 Python 같은 기존 인터프리터보다 훨씬 빠른, 최신 고성능 인터프리터예요.

## 컴파일

최적화 기능을 갖춘 Euphoria To C Translator로, 이미 빠른 인터프리터에 비해 보통 2배에서 5배까지 속도를 더 끌어올릴 수 있어요.

## 안전

런타임에 다음과 같은 항목을 폭넓게 검사해요:
 * 범위를 벗어난 첨자,
 * 초기화되지 않은 변수,
 * 라이브러리 루틴에 전달된 잘못된 매개변수 값,
 * 변수에 대입된 잘못된 값, 그리고 그 외에도 많아요.

알 수 없는 기계 예외 같은 건 없어요. 프로그램 실행 중에 문제가 생기면 언제나 그 문제에 대한 설명을 영어로 자세히 확인할 수 있고, 호출 스택 역추적과 모든 변수 값의 덤프도 함께 볼 수 있어요.

프로그램을 빠르고 쉽고 더 철저하게 디버그할 수 있어요.

## 고수준

기반 하드웨어의 특성이 완전히 감춰져 있어요.
프로그램은 워드 길이, 값의 비트 단위 표현, 바이트 순서 같은 걸 신경 쓰지 않아요.

## 디버거

전체 화면 소스 디버거와 실행 프로파일러가 포함되어 있어요.

## 편집기

전체 화면 다중 파일 편집기도 포함되어 있어요.
컬러 모니터에서는 편집기가 Euphoria 프로그램을 여러 색으로 표시해서 주석, 예약어, 내장 함수, 문자열, 괄호 중첩 수준을 눈에 띄게 해줘요.
문을 자동으로 완성해 주는 기능도 선택적으로 켤 수 있는데, 입력 수고를 덜어 주고 구문 오류를 줄여 줘요.
이 편집기는 Euphoria로 작성되었고, 소스 코드는 아무 제한 없이 제공돼요.
마음대로 수정하고 기능을 추가하고 재배포해도 돼요.

## 멀티 플랫폼

Euphoria 프로그램은 Windows, Linux, MacOS, FreeBSD, NetBSD, OpenBSD에서 실행되고, GCC를 지원하는 어떤 플랫폼으로든 쉽게 옮길 수 있어요.

## 독립 실행

프로그램에서 단 하나의 독립 실행 파일을 만들 수 있어요.

## 제네릭

Euphoria의 루틴은 본래부터 제네릭해요.
아래 예제 프로그램은 정수, 실수, 문자열 등 어떤 유형의 데이터든 정렬하는 하나의 루틴을 보여줘요.
Euphoria는 "객체 지향" 언어가 아니지만, 이런 언어들의 장점을 훨씬 단순한 방식으로 많이 누려요.

## 무료

Euphoria는 완전히 무료이고 오픈 소스예요.

Euphoria는 1993년 7월 Rapid Deployment Software(RDS)가 v1.0을 내놓은 이래 많은 발전을 이뤄 왔어요. 지금은 전 세계에 열광적인 사용자들이 있어요.
