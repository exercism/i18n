# 소개

Haxe는 타입을 엄격하게 다루지만, 필요할 때는 타입 시스템을 우회할 수 있어요. 이름에 값을 할당하는 것을 변수를 정의한다고 해요. 변수는 타입을 명시적으로 지정해서 정의할 수도 있고, Haxe 컴파일러가 타입을 추론하도록 할 수도 있어요. 따라서 다음 두 변수 정의는 서로 같아요:

```haxe
var explicitVariable:Int = 10; // Explicitly typed
var implicitVariable = 10; // Implicit typed
```

변수를 갱신할 때는 `=` 연산자를 사용해요:

```haxe
var number = 0; // Initial value
number = 1; // Updated value
```

변수와 타입이 다른 값을 할당하려고 하면 컴파일러가 오류를 발생시켜요:

```haxe
var number = 1; // Variable number is of integer type
number = "Hello" // Error trying to assign a string to an integer variable
```

클래스 안에 있는 함수를 _메서드_라고 해요. 메서드는 매개변수를 하나도 갖지 않거나 여러 개 가질 수 있어요. 모든 매개변수는 타입을 명시해야 해요. 매개변수와 마찬가지로 메서드의 반환 타입도 추론할 수 없고 반드시 타입을 지정해야 해요. 값은 `return` 키워드를 사용해 메서드에서 반환해요:

```haxe
function add(x:Int, y:Int):Int {
  return x + y;
}
```

메서드를 호출할 때는 클래스와 메서드 이름을 지정하고 인자를 전달해요:

```haxe
var sum = add(1, 2) // sum = 3
```

Haxe에서 스코프는 `{`와 `}` 문자 사이로 정의돼요.

Haxe는 두 가지 주석을 지원해요. 한 줄 주석은 `//`로 시작하고, 여러 줄 주석은 `/*`와 `*/` 사이에 넣어요.
