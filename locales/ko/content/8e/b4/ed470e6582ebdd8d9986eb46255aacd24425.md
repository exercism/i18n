# 지침

아래와 같은 ASCII 다이어그램에서 직사각형이 몇 개인지 세어 보세요.

```text
   +--+
  ++  |
+-++--+
|  |  |
+--+--+
```

위 다이어그램에는 다음 6개의 직사각형이 있어요.

```text


+-----+
|     |
+-----+
```

```text
   +--+
   |  |
   |  |
   |  |
   +--+
```

```text
   +--+
   |  |
   +--+


```

```text


   +--+
   |  |
   +--+
```

```text


+--+
|  |
+--+
```

```text

  ++
  ++


```

입력은 항상 올바른 직사각형이라고 가정해도 돼요(즉, 모든 줄의 길이가 첫 줄의 길이와 같아요).
