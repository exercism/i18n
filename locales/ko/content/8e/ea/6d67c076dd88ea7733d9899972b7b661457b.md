# 힌트

## 일반

- 각 문장 끝에 `;`를 잊지 마세요.
- 정수는 `int myInteger = 44;`처럼 정의할 수 있어요.

## 1. 굽는 시간 구하기

- 요리법에 필요한 시간 정보는 안내문에 있어요.
- 함수는 `return 2;`의 형태로 값을 반환할 수 있어요.

## 2. 준비 시간 구하기

- 층의 개수는 해당 매개변수를 사용해 확인할 수 있어요.
- 정수를 정의할 때 계산을 할 수 있어요: `int myInteger = 3 + myOtherInteger;`

## 3. 오븐에 남은 시간 계산하기

- 다른 함수를 호출하고, 반환된 값을 변수처럼 사용할 수 있어요: `return 22 * myOtherCalculation();`

## 4. 라자냐에 든 총 시간 계산하기

- 결과는 준비 시간과 라자냐가 지금까지 오븐에 있던 시간을 합한 값이어야 해요.
