# 지침 추가

## 구현

로봇 이름이 바닥날 수도 있어요. 가능한 모든 로봇 이름이 할당되고 나면 오류를 반환해야 해요.

## 보너스 테스트

`go test`가 통과되면, 테스트 스위트에 `TestCollisions`라는 테스트가 있다는 걸 알게 될 거예요. 이 테스트는 시간이 오래 걸릴 수 있어서 기본적으로 건너뛰도록 되어 있어요.
이 테스트는 로봇에 더 이상 새 이름을 할당할 수 없을 때까지 새로운 로봇을 만들어요.

테스트를 실행하려면 다음 줄을 지워요:

```go
t.Skip("skipping test as it can take a long time to run if solution is sub-optimal.")
```

이 테스트를 통과하려면 로봇의 이름이 이전에 사용된 적이 없도록 하고, 이름을 효율적으로 할당할 수 있도록 해야 해요.
