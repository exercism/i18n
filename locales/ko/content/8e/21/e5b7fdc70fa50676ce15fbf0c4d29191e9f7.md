# 연산자 오버로딩

연산자 오버로딩은 일부 프로그래밍 언어의 기능으로, 덧셈(`+`), 뺄셈(`-`), 곱셈(`*`), 나눗셈(`/`) 같은 표준 연산자를 사용자 정의 타입에서도 동작하도록 재정의할 수 있게 해줘요.

이 기능을 활용하면 사용자 정의 타입에 대한 연산을 기본 타입에 대한 연산과 같은 방식으로 표현할 수 있어서, 코드의 문법이 더 직관적으로 느껴져요.

Cairo에서는 특정 트레이트를 구현하는 방식으로 연산자 오버로딩을 해요.

각 연산자에는 짝을 이루는 트레이트가 있고, 그 연산자를 오버로딩하려면 사용자 정의 타입에 대해 그 트레이트를 구현해야 해요.
그렇지만 연산자 오버로딩은 신중하게 사용해야 해요.

잘못 사용하면 코드를 이해하기 어려워지고 유지보수도 힘들어져요. 예를 들어 오버로딩하는 연산자에 의미론적인 의미가 없을 때가 그렇죠.

두 개의 `Potions`를 합쳐야 하는 예를 살펴봐요.

`Potions`에는 마나와 체력, 두 개의 데이터 필드가 있어요.

두 `Potions`를 합치면 각각의 필드 값을 더해야 해요.

```rust
struct Potion {
    health: felt252,
    mana: felt252,
}

impl PotionAdd of Add<Potion> {
    fn add(lhs: Potion, rhs: Potion) -> Potion {
        Potion { health: lhs.health + rhs.health, mana: lhs.mana + rhs.mana }
    }
}

fn main() {
    let health_potion: Potion = Potion { health: 100, mana: 0 };
    let mana_potion: Potion = Potion { health: 0, mana: 100 };
    let super_potion: Potion = health_potion + mana_potion;
    // Both potions were combined with the `+` operator.
    assert(super_potion.health == 100, '');
    assert(super_potion.mana == 100, '');
}
```

위 코드에서는 `Potion` 타입에 `Add` 트레이트를 구현하고 있어요.

`add` 함수는 `lhs`와 `rhs`, 두 개의 인자를 받아요. 각각 왼쪽과 오른쪽을 뜻하죠.

함수 본문은 새로운 `Potion` 인스턴스를 반환하는데, 그 필드 값은 `lhs`와 `rhs`를 각각 합친 결과예요.

예제에서 보듯이, 연산자를 오버로딩하려면 어떤 구체적인 타입을 오버로딩하는지 명시해야 해요.

오버로딩되는 제네릭 트레이트는 `Add<T>`이고, `Add<Potion>`으로 `Potion` 타입에 대한 구체적인 구현을 정의해요.
