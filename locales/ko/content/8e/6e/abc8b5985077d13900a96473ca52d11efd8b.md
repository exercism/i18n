# 테스트

## Clojure CLI

Exercism의 Clojure 연습 문제는 [cognitect-labs test-runner](https://github.com/cognitect-labs/test-runner)를 실행하기 위한 `:test` 별칭이 있는 `deps.edn` 파일을 함께 제공해요:

``` bash
$ clj -X:test
```

## Leiningen

Leiningen으로도 연습 문제의 테스트를 실행할 수 있어요. 연습 문제 디렉터리에서 다음 명령어를 실행해 보세요:

```bash
lein test
```

## REPL

REPL을 사용해서 연습 문제의 테스트를 실행하려면, 연습 문제 디렉터리에서 다음 명령어를 실행해 보세요:

```bash
$ clj
```

-또는-

```bash
$ lein repl
```

그런 다음 `require`로 연습 문제의 테스트 네임스페이스와 Clojure 테스트 네임스페이스를 불러오세요):

```clojure
;; replace <exercise> with the exercise's name
=> (require '<exercise>-test)
```

그런 다음 `<exercise>-test`에 `run-tests`를 호출하세요:

```clojure
;; replace <exercise> with the exercise's name
=> (clojure.test/run-tests '<exercise>-test)
```
