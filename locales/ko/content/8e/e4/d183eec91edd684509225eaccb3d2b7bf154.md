# 힌트

## 일반

- 공식 [시작 가이드][getting-started-keyword-lists]에서 키워드 리스트에 대해 읽어봐요.
- [elixirschool.com][elixir-school-keyword-lists]에서도 키워드 리스트에 대해 읽어봐요.
- [`Keyword` 모듈 문서][keyword]를 한번 살펴봐요.

## 1. 와인 색상 설명하기

- 표에 주어진 정보를 키워드 리스트로 작성해야 해요.
- 키워드 리스트를 정의하는 방법에 대한 [예시][keyword-examples]를 몇 가지 살펴봐요.

## 2. 특정 색상의 와인 모두 가져오기

- 특정 키에 대한 모든 값의 리스트를 가져오는 [내장 함수][keyword-get-values]가 있어요.

## 3. 특정 연도에 병입된 특정 색상의 와인 모두 가져오기

- 특정 키에 대한 값 하나를 가져오는 [내장 함수][keyword-get]가 있어요.
- 병을 필터링하는 부분을 직접 구현할 필요는 없어요. 이미 구현되어 있는 `filter_by_year/2` 함수를 조건에 따라 사용하기만 하면 돼요.

## 4. 특정 국가에서 병입된 특정 색상의 와인 모두 가져오기

- 특정 키에 대한 값 하나를 가져오는 [내장 함수][keyword-get]가 있어요.
- 병을 필터링하는 부분을 직접 구현할 필요는 없어요. 이미 구현되어 있는 `filter_by_country/2` 함수를 조건에 따라 사용하기만 하면 돼요.
