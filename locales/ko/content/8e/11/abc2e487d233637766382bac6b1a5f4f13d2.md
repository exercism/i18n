# 소개

Swift에는 루프의 일반적인 제어 흐름을 바꾸는 데 쓸 수 있는 문이 몇 가지 있어요.
이런 문을 제어 전달문이라고 해요.
`return`은 이미 봤는데, 이번 개념에서는 `continue`, `break`, 레이블을 비롯한 다른 것들을 소개해요.

## Continue

때로는 루프의 현재 반복에서 나머지 문을 다 실행하지 않고 다음 반복으로 일찍 건너뛰어야 할 때가 있어요.
이럴 때 `continue` 키워드를 사용할 수 있어요.
`continue`가 실행되면 루프는 다음 반복을 실행할 수 있는지 확인하는 검사로 바로 넘어가요. 즉, `while`문과 repeat-while 루프에서는 `while` 조건으로, for-in 루프에서는 시퀀스에 다음 원소가 있는지 확인하는 검사로 넘어가요.

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

## Break

`break`는 루프를 일찍 빠져나올 때 사용해요.
`break`가 실행되면 루프는 즉시 종료되고, 프로그램은 루프 다음에 오는 첫 번째 문부터 계속 실행해요.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

## 레이블

루프가 중첩되어 있을 때에는 `break`나 `continue`를 사용해서, 그것이 쓰인 루프를 감싸고 있는 바깥 루프를 빠져나가거나 다시 시작하고 싶을 때가 있어요.
이럴 때 레이블을 사용하면 빠져나가거나 다시 시작할 루프를 지정할 수 있어요.
루프를 시작하는 `while`, `repeat`, `for` 앞에 이름과 콜론을 붙이면 루프에 레이블을 달 수 있어요.

이렇게 레이블을 사용하면 어떤 효과가 있는지 다음 루프를 살펴봐요.

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```

## Fallthrough

`fallthrough` 키워드는 switch 문에서 다음 case로 흘러가도록 할 때 사용해요.
즉, 다음 case의 조건을 확인하지 않고 그 안의 코드가 실행돼요.
그래서 case가 일치한 뒤 switch 문을 빠져나갈 때 `break` 문이 필요 없는 다른 프로그래밍 언어처럼 switch 문이 동작하게 돼요.
`fallthrough`에 대해서는 [Swift 책][fallthrough]에서 더 자세히 읽을 수 있어요.

```swift
let value = 1
switch value {
case 1:
  print("One")
  fallthrough
case 2:
  print("Two")
}

// prints:
// One
// Two
```

[control-transfer]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#Control-Transfer-Statements
[fallthrough]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#Fallthrough
