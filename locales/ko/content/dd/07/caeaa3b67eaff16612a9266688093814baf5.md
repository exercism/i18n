# 자세히 알아보기

## 소개

제네릭은 코드 재사용을 가능하게 하는 언어 기능이에요.
예를 들어, 배열의 길이를 계산하는 데에는 배열이 어떤 타입을 담고 있는지가 중요하지 않아야 해요.
그래서 `length` 함수는 타입 시그니처에서 제네릭 타입 매개변수 `a`를 사용해요.

```elm
length : List a -> Int
```

## 타입의 매개변수

어떤 타입이 다른 타입에 대해 제네릭할 때, 우리는 그 다른 타입에 소문자 이름을 쓰고, 이를 타입 매개변수라고 불러요.
흔한 예로 `List`, `Maybe`, `Result` 사용자 정의 타입이 있어요.

```elm
-- Maybe is generic over the type a
type Maybe a
    = Nothing
    | Just a

someString : Maybe String
someString = Just "hello"

someInt : Maybe Int
someInt = Just 42
```

타입 매개변수의 이름에 대해 한 가지 중요한 점은, 이름이 여러 글자여도 된다는 거예요.
유일한 제약은 소문자 이름이어야 한다는 것이에요.
그래서 유용할 때는 설명적인 이름을 붙이는 편이에요.

어떤 타입은 여러 다른 타입에 대해 제네릭할 수 있고, 따라서 여러 개의 타입 매개변수를 가질 수 있어요.
이 경우 각각의 독립적인 타입은 서로 다른 소문자 이름을 받아요.
독립적이라는 것이 이들이 같은 타입이 되는 것을 막지는 않아요. 다만 서로 다른 타입이 될 수 있게 해 줄 뿐이에요.

```elm
-- Result is generic over the types error and value
type Result error value
    = Ok value
    | Err error
```

레코드 타입 별칭도 타입 매개변수를 가질 수 있어요. 다만 흔한 편은 아니에요.

```elm
-- Event is generic over the type a
type alias Event a =
    { at : Time
    , data : a 
    }
```

> 이것이 `Html` 패키지가 `msg`라는 하나의 타입 매개변수를 가진 `Html msg` 타입을 정의하는 이유예요.
> Elm 아키텍처는 웹 페이지가 일으킬 수 있는 모든 메시지를 설명하는 사용자 정의 타입 `Msg`를 만들도록 안내해요.
> 그 결과, 여러분의 코드는 `Html Msg` 타입의 뷰를 만들게 되는데, 여기서 `Msg`는 직접 정의한 구체적인 타입이에요.
> 초보자는 `Html msg`(소문자)를 언급하는 오류와 `Html Msg`가 나오는 오류를 헷갈리곤 해요.
> 이제 알겠죠!
> 차이는 첫 번째는 어떤 `msg` 타입에 대해서도 제네릭하고, 두 번째는 여러분의 `Msg` 타입에 한정된다는 것이에요.

## 함수의 타입 매개변수

타입이 제네릭할 수 있으니 함수도 그럴 수 있어요.
`Maybe.withDefault`처럼 제네릭 타입을 다루는 함수를 작성할 수 있어요.

```elm
withDefault : a -> Maybe a -> a
withDefault default maybe =
    case maybe of
      Just value -> value
      Nothing -> default
```

다른 함수를 매개변수로 받는 함수를 고차 함수라고 부르는데, 이런 함수들도 제네릭할 수 있어요.

```elm
map : (a -> b) -> Maybe a -> Maybe b
map function maybe =
  case maybe of
    Just value ->
      Just (function value)

    Nothing ->
      Nothing
```

타입 매개변수는 함수의 입력과 출력 양쪽에 나타날 수 있고, 타입 매개변수로 가능해진 제네릭함은 보통 **매개변수 다형성**이라고 불러요.
이는 함수 오버로딩이라고도 알려진 애드혹 다형성과 대조돼요. 애드혹 다형성에서는 같은 함수 이름을 타입이 다른 여러 구현에 사용할 수 있어요.
또한 이는 타입을 계층 구조로 정의할 수 있고, 어떤 타입에 정의된 함수를 그 하위 타입의 인자로도 호출할 수 있는 서브타입 다형성과도 대조돼요.
Elm에서 제네릭을 가능하게 하는 유일한 메커니즘은 매개변수 다형성이에요.
