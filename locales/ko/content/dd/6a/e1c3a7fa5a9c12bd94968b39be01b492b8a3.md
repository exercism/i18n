# 지침 추가

## 트랙별 지침

"Yacht" 연습 문제에서는 선택한 범주에 따라, Yacht 게임에서 주사위 다섯 개를 한 번 던진 결과의 점수를 계산하는 verb를 만들어요.

이 연습 문제에서 만들 verb는 두 개의 인자를 받아요.

- **왼쪽 인자**: 주사위를 던진 결과에 적용할 점수 범주를 나타내는 문자열이에요.
- **오른쪽 인자**: 굴린 주사위 다섯 개를 나타내는 정수 배열이에요.

verb는 이 입력을 다음과 같이 처리하도록 정의해야 해요.

```j
  category =. 'Full House'
  dice     =. 1 3 3 3 5
  
  category scoreYacht dice
```
