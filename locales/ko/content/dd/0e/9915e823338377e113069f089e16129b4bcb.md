# 안내

이 연습 문제에서는 친구가 개발 중인 새로운 RPG 게임의 퀘스트 로직을 구현해요.
게임의 주인공은 Annalyn이에요. 용맹하고 충직한 반려견과 함께 다니는 용감한 소녀죠.
그런데 안타깝게도 Annalyn의 가장 친한 친구가 숲에서 열매를 찾던 중 납치되는 사고가 벌어져요.
Annalyn은 이 퀘스트에서 원한다면 반려견을 데리고 함께, 친구를 찾아 구출하려고 해요.

친구의 흔적을 한참 따라간 끝에, Annalyn은 친구가 갇혀 있는 야영지를 발견해요.
납치범은 둘이었는데, 힘이 센 기사와 교활한 궁수예요.

납치범들을 찾은 Annalyn은 다음과 같은 행동 중 무엇을 할 수 있을지 고민해요:

- _빠른 공격_: 기사가 잠들어 있을 때 빠른 공격을 할 수 있어요.
  갑옷을 입는 데 시간이 걸리기 때문에, 잠든 기사는 무방비 상태가 되거든요.
- _감시_: 이들 중 적어도 한 명이 깨어 있으면 감시할 수 있어요.
  그렇지 않으면 감시는 시간 낭비예요.
- _죄수에게 신호 보내기_: 죄수가 깨어 있고 궁수가 잠들어 있으면 새소리로 죄수에게 신호를 보낼 수 있어요.
  궁수는 새소리 신호를 훈련받았기 때문에 메시지를 가로챌 수도 있거든요.
- _죄수 구출하기_: Annalyn은 야영지에 몰래 들어가 죄수를 풀어줄 수 있어요.
  위험한 일이라 두 가지 방법 중 하나로만 성공할 수 있어요:
  - Annalyn이 반려견과 함께 있다면, 궁수가 잠들어 있을 때 죄수를 구출할 수 있어요.
    기사는 개를 무서워하고, 궁수는 Annalyn과 죄수가 도망치기 전에 준비할 시간이 없어요.
  - 반려견이 없다면 Annalyn과 죄수는 아주 조심스럽게 움직여야 해요!
    죄수가 깨어 있고 기사와 궁수가 모두 잠들어 있으면 죄수를 구출할 수 있지만, 죄수가 잠들어 있으면 구출할 수 없어요.
    Annalyn이 갑자기 나타나면 죄수가 놀라서 기사와 궁수를 깨워버리거든요.

해야 할 일은 네 가지예요.
숲에서 만난 세 인물의 상태와 Annalyn의 반려견이 함께 있는지 여부에 따라 위 행동들을 할 수 있는지 판단하는 로직을 구현해요.

## 1. 빠른 공격을 할 수 있는지 확인하기

기사가 깨어 있는지를 나타내는 불리언 값을 받는 `CanFastAttack()` 함수를 정의해요.
이 함수는 기사의 상태에 따라 빠른 공격을 할 수 있으면 `true`를 반환하고, 그렇지 않으면 `false`를 반환해요:

```go
var knightIsAwake = true
fmt.Println(CanFastAttack(knightIsAwake))
// Output: false
```

## 2. 무리를 감시할 수 있는지 확인하기

기사, 궁수, 죄수가 각각 깨어 있는지를 나타내는 세 개의 불리언 값을 받는 `CanSpy()` 함수를 정의해요.
이 함수는 세 인물의 상태에 따라 무리를 감시할 수 있으면 `true`를 반환하고, 그렇지 않으면 `false`를 반환해요:

```go
var knightIsAwake = false
var archerIsAwake = true
var prisonerIsAwake = false
fmt.Println(CanSpy(knightIsAwake, archerIsAwake, prisonerIsAwake))
// Output: true
```

## 3. 죄수에게 신호를 보낼 수 있는지 확인하기

궁수와 죄수가 각각 깨어 있는지를 나타내는 두 개의 불리언 값을 받는 `CanSignalPrisoner()` 함수를 정의해요.
이 함수는 두 인물의 상태에 따라 죄수에게 신호를 보낼 수 있으면 `true`를 반환하고, 그렇지 않으면 `false`를 반환해요:

```go
var archerIsAwake = false
var prisonerIsAwake = true
fmt.Println(CanSignalPrisoner(archerIsAwake, prisonerIsAwake))
// Output: true
```

## 4. 죄수를 구출할 수 있는지 확인하기

네 개의 불리언 값을 받는 `CanFreePrisoner()` 함수를 정의해요.
처음 세 매개변수는 기사, 궁수, 죄수가 각각 깨어 있는지를 나타내요.
마지막 매개변수는 Annalyn의 반려견이 함께 있는지를 나타내요.
이 함수는 세 인물의 상태와 Annalyn의 반려견 동반 여부에 따라 죄수를 구출할 수 있으면 `true`를 반환하고, 그렇지 않으면 `false`를 반환해요:

```go
var knightIsAwake = false
var archerIsAwake = true
var prisonerIsAwake = false
var petDogIsPresent = false
fmt.Println(CanFreePrisoner(knightIsAwake, archerIsAwake, prisonerIsAwake, petDogIsPresent))
// Output: false
```
