# Instructions

이 연습 문제에서는 프로그래밍 언어 배열을 다루는 함수 몇 개를 구현해요.

## 1. 빈 언어 배열을 반환하는 함수를 정의해요

인자를 받지 않고 빈 배열을 반환하는 `new` 함수를 정의해요.

```haskell
new
-- -> []
```

## 2. 배열에 언어를 추가하는 함수를 정의해요

`add/2` 함수는 인자 두 개(_언어 배열_과 _언어_를 나타내는 문자열 리터럴)를 받아요.
주어진 배열 맨 앞에 새 언어를 추가한 결과 배열을 반환해야 해요.

```haskell
add new "Clojure"
-- -> ["Clojure"]
add ["Clojure"] "Haskell"
-- -> ["Haskell", "Clojure"]
```

## 3. 배열에서 언어를 제거하는 함수를 정의해요

`remove` 함수는 인자 하나(_언어 배열_)를 받아요.
첫 번째 항목이 빠진 배열을 반환해야 해요. 배열에는 항상 항목이 하나 이상 있다고 가정해요.

```haskell
remove ["Haskell", "Clojure", "Erlang"]
-- -> ["Clojure", "Erlang"]
```

## 4. 배열의 첫 번째 항목을 반환하는 함수를 정의해요

`first` 함수는 인자 하나(_언어 배열_)를 받아요.
배열의 첫 번째 언어를 반환해야 해요.
배열에는 항상 항목이 하나 이상 있다고 가정해요.

```haskell
first ["Elixir", "Haskell", "Clojure", "Prolog"]
-- -> "Elixir"
```

## 5. 배열에 언어가 몇 개 있는지 반환하는 함수를 정의해요

`count` 함수는 인자 하나(_언어 배열_)를 받아요.
배열에 있는 언어의 개수를 반환해야 해요.

```haskell
count ["Prolog", "Elm"]
-- -> 2
```

## 6. 배열에 함수형 언어가 포함되어 있는지 판별하는 함수를 정의해요

`isFunctionalList` 함수는 인자 하나(_언어 배열_)를 받아요.
불리언 값을 반환해야 해요.
_\"Haskell\"_이 배열에 있는 언어 중 하나라면 `True`를 반환해야 해요.

```haskell
isFunctionalList ["Haskell"]
-- -> True
```
