# 힌트

## 1. 자기소개하기

- [`option.unwrap` 함수][unwrap]를 사용하면 옵션에서 값을 가져오거나, 값이 없을 때는 기본값을 가져올 수 있어요.

## 2. 부활 기능 구현하기

- `gleam/option` 모듈의 `Some`과 `None` 생성자를 사용해 옵션 값을 만들 수 있어요.

## 3. 주문 시전 기능 구현하기

- [`int.max` 함수][max]를 사용하면 체력이 0 아래로 내려가지 않도록 할 수 있어요.

[max]: https://hexdocs.pm/gleam_stdlib/gleam/int.html#max
