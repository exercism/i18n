# 레이블 동기화 워크플로

레이블 동기화 워크플로는 저장소의 [GitHub 레이블](https://docs.github.com/en/issues/using-labels-and-milestones-to-track-work/managing-labels)을 `.github/labels.yml` 파일의 내용과 동기화해요.
`.github/labels.yml` 파일이 변경될 때마다 레이블 동기화 워크플로가 저장소의 레이블을 자동으로 업데이트해요.

## 레이블 사용자 지정

`.github/labels.yml`에 정의된 레이블은 두 가지 형태가 있어요:

- 공유 레이블: _모든_ Exercism 저장소에서 사용하는 레이블로, [org-wide-files 저장소](https://github.com/exercism/org-wide-files/blob/main/global-files/.github/labels.yml)에 정의되어 있어요
- 트랙별 레이블: `.appends/.github/labels.yml` 파일에 정의되어 있어요

트랙별 레이블을 추가하려면 `.appends/.github/labels.yml` 파일에 추가해야 해요([이 예시](https://github.com/exercism/python/blob/main/.appends/.github/labels.yml)를 참고해요).
변경 사항을 `main`에 병합하면 `.github/labels.yml` 파일을 변경하는 풀 리퀘스트가 자동으로 열려요.
그 풀 리퀘스트를 병합하면 레이블이 자동으로 업데이트돼요(위 설명을 참고해요).

```exercism/caution
`.github/labels.yml` 파일은 직접 수정하지 마세요. 다음에 레이블을 동기화할 때 변경 사항이 덮어써져요.
```

## 출처

워크플로는 `.github/workflows/sync-labels.yml` 파일에 정의되어 있어요.
