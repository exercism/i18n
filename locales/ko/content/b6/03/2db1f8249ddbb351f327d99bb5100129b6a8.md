# 지침 추가

## 레지스터

| 레지스터 | 용도        | 유형    | 설명                          |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | 입력         | 주소    | null로 끝나는 숫자 문자열     |
| `$a1`    | 입력         | 정수    | 구간                          |
| `$v0`    | 출력         | 정수    | 가장 큰 연속 곱               |
| `$t0-9`  | 임시         | 아무거나 | 임시 저장용                   |
