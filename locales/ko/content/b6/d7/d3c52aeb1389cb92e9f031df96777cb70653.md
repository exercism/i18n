# 힌트

## 일반

- [부동소수점 숫자 형식 소개][docs.microsoft.com-floating_point_numeric_types].

## 1. 이자율 계산하기

- C# 코드에서 정의한 부동소수점 숫자는 기본적으로 `double`로 취급돼요. `float`나 `decimal`처럼 다른 부동소수점 형식을 사용하려면 숫자에 알맞은 [접미사][docs.microsoft.com-real_literals]를 붙여야 해요.

## 2. 이자 계산하기

- 이자를 계산할 때는 `InterestRate`가 백분율을 반환한다는 점에 주목하면 도움이 돼요.

## 3. 연간 잔액 갱신 계산하기

- 연간 잔액 갱신을 계산할 때는 이전 단계에서 정의한 메서드를 사용할 수 있어요.

## 4. 원하는 잔액에 도달하기까지 걸리는 연수 계산하기

- 연수를 계산하려면 원하는 잔액에 도달할 때까지 계속 반복하면 돼요. C#에는 여러 가지 [반복 구문][docs.microsoft.com-loops]이 있어요.
- 값을 1만큼 증가시키는 특별한 [연산자][increment-operator]가 있어요.
