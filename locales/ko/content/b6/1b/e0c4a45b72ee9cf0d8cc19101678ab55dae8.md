# 힌트

## 일반

## 1. `new()` 메서드 구현하기

- `new()` 메서드는 `User` 인스턴스를 만들 때 사용할 인자들을 받아요. 지정한 이름, 나이, 몸무게를 가진 `User` 인스턴스를 반환해야 해요.

- 구조체를 정의하고 인스턴스를 만드는 더 많은 예시는 [여기](https://doc.rust-lang.org/book/ch05-01-defining-structs.html)에서 볼 수 있어요.

## 2. 게터 메서드 구현하기

- `name()`, `age()`, `weight()` 메서드는 게터예요. 다시 말해, 구조체 인스턴스에서 해당 필드를 반환하는 역할을 해요.

- `User` 구조체의 `name` 필드는 `String`인데 `name` 메서드는 `&str`을 반환한다는 점에 주목해요. `&str`과 `String`이 잘 어울리게 하려면 어떻게 해야 할까요?

- Rust에서는 함수나 메서드가 일찍 반환하기를 바라는 게 아니라면 `return`문을 쓸 필요가 없어요. 그 대신 반환하고 싶은 결과에서 세미콜론을 생략하는 _암시적_ 반환을 활용하는 게 더 관용적이에요. 명시적 return을 쓰는 게 _틀린_ 건 아니지만, 가능하면 암시적 반환을 활용하는 게 더 깔끔해요.

```rust
fn foo() -> i32 {
    1
}
```

- 구조체에 메서드를 정의하는 더 많은 예시는 [여기](https://doc.rust-lang.org/book/ch05-03-method-syntax.html)에서 볼 수 있어요.

## 3. 세터 메서드 구현하기

- `set_age()`와 `set_weight()` 메서드는 세터로, 입력 인자로 구조체 인스턴스의 해당 필드를 갱신하는 역할을 해요.

- 이 메서드들의 시그니처가 보여주듯, 세터 메서드는 아무것도 반환하지 않아요.
