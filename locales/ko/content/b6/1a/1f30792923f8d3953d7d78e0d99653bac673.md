# 지침

마을에 새 시 동아리가 문을 열었고, 가입할까 생각 중이에요.
예전에 몇 번 사건이 있었기 때문에, 이 동아리에는 아주 까다로운 출입 규칙이 있어요. 들어가려면 먼저 이 규칙을 익혀야 해요.

시 동아리에는 문이 두 개, 앞문과 뒷문이 있고 둘 다 문지기가 지켜요.
들어가려면 그날의 비밀번호를 알아내야 해요.

비밀번호는 항상 시를 바탕으로 하고, 두 단계로 알아낼 수 있어요.

1. 문지기가 시를 한 줄씩 읊어 주면, 그 줄에서 알맞은 글자로 응답해요.
2. 그러면 문지기가 지금까지 응답한 글자를 한꺼번에 알려 주고, 그 글자를 정해진 형식으로 종이에 적어야 해요.

자세한 과정은 어느 문으로 들어가려는지에 따라 달라요.

## 1. 문장의 첫 글자 가져오기

앞문 비밀번호에 쓸 글자를 정하려면, 문지기가 읊어 주는 시의 줄에서 첫 글자로 응답해야 해요.

시 동아리 회원들은 멋진 비밀번호를 만들기 위해 _머리글자 시_를 즐겨 써요.
머리글자 시란 각 문장의 첫 글자를 모으면 단어가 되는 시를 말해요.
다음은 회원들이 가장 좋아하는 작가 중 한 명인 Michael Lockwood의 예예요.

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

그래서 문지기가 **Stands so high**를 읊으면 **S**라고 응답하고, 문지기가 **Huge hooves too**를 읊으면 **H**라고 응답해요.

시의 한 줄을 인자로 받아 그 줄의 첫 글자를 반환하는 `frontDoorResponse` 함수를 구현해요.

```javascript
frontDoorResponse('Stands so high');
// => "S"
```

## 2. 단어를 알맞게 대문자로 만들기

이제 올바른 글자를 모두 모았으니, 앞문 비밀번호를 얻으려면 단어를 알맞게 대문자로 만들기만 하면 돼요.

문자열(1번 과제에서 찾은 글자들을 합친 것)을 받아 알맞게 대문자로 만든 문자열을 반환하는 `frontDoorPassword` 함수를 구현해요.

```javascript
frontDoorPassword('SHIRE');
// => "Shire"

frontDoorPassword('shire');
// => "Shire"
```

## 3. 문장의 마지막 글자 가져오기

뒷문 비밀번호에 쓸 글자를 정하려면, 문지기가 읊어 주는 시의 줄에서 마지막 글자로 응답해야 해요.

시 동아리 회원들은 정말 영리해요.
앞에서 본 시는 _꼬리글자 시_이기도 한데, 이는 각 문장의 마지막 글자도 단어를 이룬다는 뜻이에요.

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

문지기가 **Stands so high**를 읊으면 **h**라고 응답하고, 문지기가 **Huge hooves too**를 읊으면 **o**라고 응답해요.

문지기는 가끔 줄의 앞이나 뒤에서 (공백의 형태로) 멋을 부리듯 쉬어요.
알맞은 글자를 얻으려면 그런 쉼은 무시해야 해요.

시의 한 줄을 인자로 받아, 공백 문자가 아닌 그 줄의 마지막 글자를 반환하는 `backDoorResponse` 함수를 구현해요.

```javascript
backDoorResponse('Stands so high');
// => "h"

backDoorResponse('Stands so high   ');
// => "h"
```

## 4. 예의를 갖추기

시 동아리에 뒷문으로 들어가려면 각별히 예의를 갖춰야 해요.
그래서 이번에는 비밀번호를 만들 때 단어를 알맞게 대문자로 만들고 끝에 `', please'`를 붙여야 해요.

문자열(3번 과제에서 찾은 글자들을 합친 것)을 받아, 대문자로 만든 비밀번호에 예의를 갖춘 형태를 반환하는 `backDoorPassword` 함수를 구현해요.

```javascript
backDoorPassword('horse');
// => "Horse, please"
```
