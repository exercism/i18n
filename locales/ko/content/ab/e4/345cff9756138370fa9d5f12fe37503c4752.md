# 지침 추가

## 트랙별 지침

조금 색다른 걸 원한다면 `unfold` 함수를 사용한 풀이도 시도해 볼 수 있어요.
아마 `foldLeft/Right`는 이미 익숙할 거예요: 컬렉션 전체를 다른 것(보통 컬렉션이 아닌 것)으로 "매핑"하는 거죠.
`unfold`는 "역" 연산이에요: 뭔가(보통 컬렉션이 아닌 것)를 컬렉션으로 "매핑"하는 거죠.
따라서 `unfold`하는 것은 함수형 프로그래밍(FP) 표준 레퍼토리에 논리적으로 추가되는 것이고, 그 일부이기도 해요.

이 연습 문제는 `unfold`하는 사례로 볼 수 있어요: `Int`를 `String`으로 "매핑"하는 거죠. (`String`은 물론 암시적으로 `Seq[Char]`예요.)

Scala 컬렉션에는 2.13부터 이 기능이 있어요. 예를 들어 [`List.unfold`][list]와 `Iterator.unfold`가 있어요.
시작 상태와, 다음 원소와 다음 상태를 반환하는 함수를 받아요. 멈추려면 `None`을 반환하면 돼요:

```scala
List.unfold(1234)(n => Option.when(n > 0)((n % 10, n / 10)))
// List(4, 3, 2, 1)
```

[list]: https://www.scala-lang.org/api/current/scala/collection/immutable/List$.html
