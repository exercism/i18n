# 소개

JavaScript에서 `Array` 클래스에는 배열을 변환하는 강력한 내장 메서드가 많아요.
이런 메서드를 쓰면 단순한 `for`문이나 좀 더 직접적인 조작을 쓸 때보다 배열을 다른 배열로 바꾸기가 훨씬 쉬워져요.

일부 메서드는 [_순수_][pure-function-definition]해서 원본 배열을 수정하지 않아요.
대신 새로운 배열을 반환해요.
반면 다른 메서드들은 자신이 호출된 배열 자체를 조작하고, 수정된 배열을 반환하지 **않아요**.

배열을 변환할 때 가장 많이 쓰이는 메서드 몇 가지를 아래에서 살펴볼게요.
사용할 수 있는 메서드 전체 목록은 [MDN 문서][array-methods]에서 확인할 수 있어요.

### map (순수)

인자로 전달된 함수에 따라 각 원소를 변환해서 새로운 배열을 만들어요.
이런 콜백 함수는 보통 [화살표 함수][concept-arrow-functions]로 작성해요.

```javascript
let arr = [1, 2, 3, 4];

const newArr = arr.map((value) => value - 1);
console.log(newArr);
// => [0, 1, 2, 3]
console.log(arr);
// => [1, 2, 3, 4]
```

결과로 나오는 배열의 길이는 항상 원본과 같다는 점도 알아두면 좋아요.

### filter (순수)

필터링 함수를 이용해 현재 배열을 걸러서 새로운 배열을 만들어요.
이 함수는 원소를 남겨야 하면 true를, 제거해야 하면 false를 반환해요.

```javascript
let arr = [1, 2, 3, 4];

arr.filter((value) => value % 2 === 0);
// => [2, 4]
```

### reduce (순수)

_누산기_와 현재 배열 원소를 매개변수로 받는 함수를 사용해서 배열을 하나의 값으로 줄여요.
이 함수는 현재 원소를 누산기에 어떻게 합쳐야 하는지 정하고, 다음 반복에서 사용할 누산기를 반환해요.

```javascript
let arr = [1, 2, 3, 4];

// Get the sum of elements
arr.reduce((accumulator, currentValue) => accumulator + currentValue, 0);
// => 10

// Classify the numbers by whether they are odd or not
arr.reduce(
  (accumulator, currentValue) => {
    if (currentValue % 2 === 0) {
      accumulator.even.push(currentValue);
    } else {
      accumulator.odd.push(currentValue);
    }

    return accumulator;
  },
  { even: [], odd: [] },
);
// => { even: [2, 4], odd: [1, 3] }
```

### reverse

배열의 원소 순서를 뒤집어요.

```javascript
const arr = [1, 2, 3, 4];

arr.reverse();
// => [4, 3, 2, 1]
```

이 메서드는 자신이 호출된 배열 자체를 수정해요.

### slice (순수)

시작 인덱스와 끝 인덱스를 받아, 호출된 배열에서 부분 배열을 만들어요.

끝 인덱스에 있는 원소는 포함되지 않아요.
또한 모든 매개변수는 선택 사항이에요.
시작 인덱스의 기본값은 `0`이고, 끝 인덱스의 기본값은 배열의 길이예요.

```javascript
const arr = [1, 2, 3, 4];

arr.slice(1, 2); // [2]
arr.slice(1); // [2, 3, 4]
// You can also use negative numbers, that represent the indexes
// starting from the end of the array
arr.slice(-2); // [3, 4]
```

### splice

배열의 원소를 제거하거나, 교체하거나, 새 원소를 추가해요.

다음과 같은 매개변수를 받아요.

- 배열 수정을 시작할 원소의 인덱스
- 삭제할 원소의 개수
- 배열에 삽입할 원소 (선택 사항)

`splice`는 제거된 원소들을 반환해요.

```javascript
const arr = ['1', '2', '5', '6'];

// Insert an element at index 2
arr.splice(2, 0, '3');
console.log(arr);
// => ['1', '2', '3', '5', '6']

// Remove 2 elements, starting at index 3 and insert 2 elements
const removed = arr.splice(3, 2, '4', '5');
console.log(removed);
// => ['5', '6']
console.log(arr);
// => ['1', '2', '3', '4', '5']

// Remove 1 element at index 1
arr.splice(1, 1);
console.log(arr);
// => ['1', '3', '4', '5']
```

### sort

기본적으로 `sort`는 배열의 원소를 먼저 문자열로 변환한 다음 문자열 비교를 적용해서 정렬해요([개념: 비교][concept-comparison] 참고).
정렬은 _제자리에서_ 일어나기 때문에 원본 배열이 수정돼요.
`sort`는 그렇게 수정된 배열을 반환하기도 하는데, 여기에 다른 메서드를 이어서 호출하고 싶을 때 편리해요.

```javascript
const arr = ['c', 'a', 'z', 'b'];
const result = arr.sort();
console.log(result);
// => ['a', 'b', 'c', 'z']
console.log(arr);
// => ['a', 'b', 'c', 'z']
```

정렬 동작을 원하는 대로 바꾸려면 비교 함수를 인자로 전달할 수 있어요.
비교 함수는 배열의 두 원소를 인자로 받아 호출돼요.
그리고 다음 중 하나를 반환해야 해요.

- 첫 번째 인자가 두 번째보다 앞에 정렬되어야 하면 음수
- 첫 번째 인자가 두 번째보다 뒤에 정렬되어야 하면 양수
- 원소의 순서가 그대로 유지되어야 하면 `0`

예를 들어 숫자를 정렬하려면 다음과 같은 비교 함수를 사용할 수 있어요.

```javascript
const arr = [3, 1, 2, 10];
arr.sort((a, b) => a - b);
// => [1, 2, 3, 10]
// "a - b" is negative when b is greater than a, positive when
// a is greater than b and 0 when they are equal.
```
