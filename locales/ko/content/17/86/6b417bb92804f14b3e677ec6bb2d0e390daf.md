# 소개

대부분의 프로그래밍 언어와 마찬가지로 Gleam에도 "부수 효과"가 있어요. 그래서 함수는 값을 반환할 수 있을 뿐만 아니라 세상의 상태를 읽고 바꿀 수도 있어요.

Gleam 표준 라이브러리의 `gleam/io` 모듈은 문자열을 콘솔에 출력하는 함수를 제공해요.

```gleam
io.println("Hello, Joe!")
// Hello, Joe!
// -> Nil
```

다른 패키지에서는 또 다른 입출력 함수를 제공하기도 해요. 예를 들어 `simplifile`은 파일을 읽고 쓰는 함수를 제공하는 패키지예요.

```gleam
simplifile.read("favourite-colour.txt")
// -> Ok("Pink\n")
```
