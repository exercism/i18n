# 소개

재귀는 함수가 자기 자신을 호출해서 코드를 반복하는 방법이에요.
반복하는 또 다른 방법으로 볼 수도 있어요.
루프와 마찬가지로, 재귀 실행을 언제 멈출지 결정할 때는 불리언 표현식이나 `True`/`False` 검사를 사용해요.
루프와는 _달리_, Python에서 종료 조건이 없는 재귀는 무한히 실행되지 못해요.
각 함수 호출에서 사용되는 값은 Python [인터프리터 스택][what-is-the-call-stack]의 각자의 [프레임][stack-frame]에 놓여요.
함수 호출의 총 개수가 스택이 감당할 수 있는 공간보다 더 많은 공간을 차지하면, 오류가 발생해요.

```python
def print_increment(step, max_value):
    if step > max_value:
        return
    print(f'The step is {step}')
    print_increment(step + 1, max_value)


def main():
    print_increment(1, 2)
    print("After recursion")

if __name__ == "__main__":
    main()

```

이 코드는 이렇게 출력해요.

```
The step is 1
The step is 2
After recursion
```

반복문으로 표현할 때보다 재귀로 표현할 때 더 읽기 쉽거나 이해하기 쉬운 상황도 있어요.
