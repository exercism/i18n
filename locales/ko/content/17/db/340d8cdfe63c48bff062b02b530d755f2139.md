# 개요

Common Lisp는 프로그래머에게 여러 가지 조건문을 제공해요. 이 조건문들은 지원하는 "분기"의 개수에 따라 분류할 수 있어요.

또한 다른 많은 프로그래밍 언어와 달리, Common Lisp에서는 모든 조건문이 문이 아니라 _표현식_이에요. 즉, 모든 Lisp 조건문은 어떤 값으로 평가되고, 구체적인 매개변수 자리에 대신 넣을 수 있어요.

예를 들어 볼까요:

```lisp
;; Doubles x when it's even
(* x (if (evenp x) 2 1))
```

## 단일 분기 조건문

`when`과 `unless`는 각각 주어진 테스트가 참일 때와 거짓일 때에만 코드를 평가하고, 그렇지 않으면 `nil`로 평가돼요.

테스트 표현식 뒤에는 여러 개의 표현식이 올 수 있어요.

```lisp
(when (= 2 2) "All is well")      ; => "All is well"
(unless (= 2 2) "Time to panic!") ; => NIL
```

## 두 개의 분기를 가진 조건문

`if` 조건문은 테스트가 참이면 본문의 첫 번째 표현식을, 거짓이면 두 번째 표현식을 평가해요.

```lisp
(if (= 2 2) 'how-honest 'you-liar) ; => HOW-HONEST
```

then 절과 else 절은 각각 하나의 표현식만 가질 수 있다는 점에 주의해요.

## 여러 개의 분기를 가진 조건문

Lisp의 "슈퍼 조건문"은 `cond`인데, 분기의 개수에 제한이 없어요. 각 분기는 테스트 조건과 본문 표현식을 가지고, 이 둘은 괄호 한 쌍으로 한 번 더 감싸요. 모든 테스트가 거짓으로 평가되면 `nil`이 반환돼요.

```lisp
(cond ((= 0 2) 'nope)
      ((= 1 2) 'try-again)
      ((= 2 2) 'quite-true)
      ((= 3 2) 'too-far)
      (t 'something-else))
; => QUITE-TRUE
```

테스트 표현식 뒤에 오는 표현식의 개수에는 제한이 없다는 점에 주의해요.

하나의 값을 여러 분기와 비교해 보고 싶을 뿐이라면, 더 깔끔한 `case` 표현식을 쓰면 돼요. 어떤 경우에도 일치하지 않으면 `nil`이 반환돼요. `t`와 `otherwise`는 모두 나머지 경우를 처리하는 절로 쓸 수 있어요:

```lisp
(case 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark")
  (otherwise "???"))
; => "???"
```

`cond`와 마찬가지로, 테스트 표현식 뒤에 오는 표현식의 개수에는 제한이 없다는 점에 주의해요.

## 숨은 조건문

Common Lisp의 불리언 연산인 `and`와 `or`는 단축 평가 매크로로, 특정 조건 표현식에서 중복을 줄이는 데 쓸 수 있어요.

`and` 매크로는 거짓인 값을 하나라도 만나면 곧바로 `nil`을 반환하고, 그렇지 않으면 `and`의 마지막 참인 값을 반환해요:

```lisp
(and 42 "Magic" :cool) ; => :COOL
(and () "Magic" :cool) ; => NIL
```

`or` 매크로는 처음 만나는 참인 값을 반환하고, 참인 값이 하나도 없으면 `nil`을 반환해요:

```lisp
(or () 42 nil)  ; => 42
(or () NIL nil) ; => NIL
```

## 이제 지칠 대로 지쳤어요...

앞서 말했듯이, `case` 문의 어떤 분기도 일치하지 않고 `otherwise` 절도 없으면 `nil`이 반환돼요. 그런데 때로는 어떤 분기와도 일치하지 않는 상황을 오류로 처리해야 할 때가 있는데, 바로 이럴 때 **빠짐없는** 일치를 위한 `ecase`가 필요해요.

`case`와 똑같은 방식으로 쓰지만, 일치하는 분기가 없을 때 `nil`을 반환하는 대신 오류를 발생시켜요.

```lisp
(case 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark"))
; => NIL

(ecase 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark"))
; => ERROR: ELDER-BEAST fell through ECASE expression. Wanted one of (CAT BIRD DOG).
```
