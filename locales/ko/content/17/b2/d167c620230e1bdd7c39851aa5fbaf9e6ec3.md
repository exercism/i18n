# 안내

여러분은 해안 경비정에서 신호를 담당하는 신호수예요. 오늘 챙길 가방에는 아침 당직이 시작되기 전에 작은 단어 다섯 개가 준비되어 있어야 해요.

## 1. 값 인용하기

항해 일지는 모든 관측값을 *Factor 소스 형식*으로 기록해요. 파서가 다시 읽어 들이는 것과 똑같은 텍스트예요. 어떤 값이든 그 값의 소스 형식 문자열로 바꾸는 `quote-value`를 정의해요.

```factor
123 quote-value .   ! => "123"
"hi" quote-value .  ! => "\"hi\""
```

## 2. 깃발 테두리 벗겨내기

들어오는 신호 깃발은 양쪽 끝에 표시 문자가 둘러싼 형태로 도착해요. 두 표시 문자 *사이*에 있는 모든 것을 반환하는 `flag-body`를 정의해요. 첫 번째 문자를 버리고, 마지막 문자를 버려요.

복사하지 말고 슬라이스(뷰)를 반환해요.

```factor
"#NS-1024#" flag-body .   ! => "NS-1024"
```

## 3. 깃발 나누기

각 깃발은 짧은 접두사 코드 뒤에 페이로드가 따라붙어 있어요. 깃발과 헤더 길이를 받아서 헤더 슬라이스와 본문 슬라이스를 *둘 다* 반환하는 `split-flag`를 정의해요.

```factor
"NS-1024" 2 split-flag .s
! => "NS"
! => "-1024"
```

## 4. 두 판독값으로 삼각 측량하기

연속된 두 신호 판독값은 세 가지 파생 측정값을 만들어요. 두 값의 *차이* `a - b`, *중간점* `(a + b) / 2`, *비율* `a / b`예요. 각 측정값은 두 판독값을 모두 사용해요.

두 판독값에서 이 세 값을 모두 반환하는 `triangulate`를 정의해요.

```factor
100 50 triangulate .s
! => 50
! => 75
! => 2
```

## 5. 세 판독값 요약하기

연속된 세 판독값은 **합**, **곱**, **최댓값**으로 요약돼요. 각 통계는 세 판독값을 모두 사용해요.

세 값을 모두 반환하는 `triangle-stats`를 정의해요.

```factor
5 3 8 triangle-stats .s
! => 16
! => 120
! => 8
```
