# 소개

Java에서는 `java.util.Random` 클래스의 인스턴스를 사용해 난수를 만들 수 있어요.

## 무작위 정수

`nextInt()` 메서드로 무작위 정수를 만들 수 있어요.
이 메서드는 `Integer.MIN_VALUE`부터 `Integer.MAX_VALUE`까지의 값을 만들어요.

```java
Random random = new Random();

random.nextInt();
// => -1169335537
```

만들어지는 값의 범위를 제한하려면 `nextInt(int)`를 사용해요.
이 메서드는 `0` 이상, 주어진 상한 미만의 값을 만들어요.

예를 들어, 다음 코드는 `0`부터 `9`까지의 난수를 만들어요.

```java
Random random = new Random();

random.nextInt(10);
// => 6
```

그리고 다음 코드는 `10`부터 `19`까지의 난수를 만들어요.

```java
Random random = new Random();

10 + random.nextInt(10);
// => 11
```

## 무작위 실수

`nextDouble()` 메서드로 무작위 실수를 만들 수 있어요.
이 메서드는 `0.0`부터 `1.0`까지의 값을 만들어요.

```java
Random random = new Random();

random.nextDouble();
// => 0.19250004204021398
```

그리고 다음 코드는 `100.0`부터 `200.0`까지의 난수를 만들어요.

```java
Random random = new Random();

100.0 + 100.0 * random.nextDouble();
// => 111.31849856260328
```
