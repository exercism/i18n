# 소개

`switch()` 함수는 길게 이어지는 `if` ... `else if` 검사를 간결하게 대체할 수 있어요.
`switch`로 검사할 변수는 대부분 문자열이고, 이 경우 선택자에서 따옴표를 생략할 수 있어요.

```R
star <- function(type) {
  switch(type,
    M = , # will "fall through" if no value given
    K = "red dwarf",
    G = "Earth-like",
    "bigger star" # only correct for O,B,A,F
  )
}

> star("M")
[1] "red dwarf"
```

값을 비워 둘 때만 다음 옵션으로 넘어간다는 점에 주의해요. 위 예시의 `M`이 그런 경우예요.
다른 몇몇 언어들처럼 `break` 문을 넣을 필요는 없어요.

`character` 타입을 검사할 때는 여기에서처럼 마지막 값이 기본값이 돼요.
정수 타입에서는 기본값을 지정할 수 없어요.

## `dplyr`의 함수들

base R의 `switch`는 꽤 제한적이에요. 단일 입력에 대한 정확한 일치만 처리해요.
1993년 R이 처음 공개됐을 때는 합리적으로 보였지만, 현대적인 사용에는 개선이 필요해요.

~~~~exercism/note
[`Conditionals`][concept-conditionals] 개념에서 언급했듯이, `tidyverse` 패키지 모음은 하위 호환성에 영향을 주지 않으면서 base R의 기능을 보완하고(때로는 대체하도록) 설계됐어요.

`dplyr` 패키지는 코드 맨 위에 `library(dplyr)`(패키지 하나만 쓸 때) 또는 `library(tidyverse)`(모음 전체를 쓸 때)를 추가해서 스코프로 불러올 수 있어요.

[concept-conditionals]: https://exercism.org/tracks/r/concepts/conditionals
~~~~

`dplyr` 라이브러리는 `switch`와 관련된 두 가지 추가 함수를 제공해요.

### `recode_values`와 `replace_values` 함수

이 두 함수는 서로 관련이 있으며, 기존 값을 새 값으로 매핑하는, `switch`와 비슷하지만 벡터화된 기능을 제공해요.

둘의 가장 큰 차이는 `recode_values()`는 완전히 새로운 벡터를 만들고, `replace_values()`는 기존 벡터의 일부만 갱신할 수 있다는 점이에요.

일치는 여전히 정확히 이루어져요. 다만:

- 왼쪽의 옵션은 벡터가 될 수 있고, 어떤 원소든 일치하면 입력이 일치한 것으로 처리돼요.
- 왼쪽의 옵션과 오른쪽의 결과는 `=` 대신 물결표 `~`로 연결해요.
- 모든 경우에 기본값을 지정할 수 있어요.

```R
library(dplyr)

x <- c("a", "b", "a", "d", "b", NA, "c", "e", "z")
recode_values(
  x,
  "a" ~ 1,
  "b" ~ 2,
  "c" ~ 3,
  c("d", "e") ~ 4, # either "d' or "e" will match
  NA ~ 0,          # matches missing values
  default = 100   # note the different syntax for the default
)
#> [1]   1   2   1   4   2   0   3   4 100
```

### `case_when` 함수

`case_when`은 `case_match` 문법을 한 단계 더 발전시켜서, `~` 왼쪽에 어떤 논리 표현식이든 쓸 수 있게 해줘요.

입력 벡터(아래 예시의 `x`)는 인자로 넘기지 않아요. 그저 미리 정의돼 있기만 하면 돼요.

```R
x <- 1:10
case_when(
  x < 3 ~ "low",
  between(x, 3, 5) ~ "mid",
  between(x, 6, 8) ~ "high",
  .default = "what?"
)
#>  [1] "low"   "low"   "mid"   "mid"   "mid"   "high"  "high"  "high"  "what?" "what?"
```

`between()` 함수도 `dplyr`의 일부예요.
