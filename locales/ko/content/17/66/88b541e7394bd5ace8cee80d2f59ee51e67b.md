# 개요

메서드에는 varargs 매개변수를 둘 수 있어요. 그러면 호출하는 쪽에서 일반 매개변수처럼 인자를 0개 이상 지정할 수 있어요. 메서드는 이 인자들을 하나의 배열로 받아요.

매개변수를 varargs 매개변수로 만들려면 매개변수 선언에 [`params` 키워드](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/params)를 추가해요:

```csharp
public static void PrintNumbers(params int[] numbers)
{
    foreach (var number in numbers)
    {
        Console.Write(number)
    }
}

// No values for a varags parameter is allowed
PrintNumbers();

PrintNumbers(1);
// => 1

PrintNumbers(1, 2, 3);
// => 123
```
