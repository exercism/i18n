# SQLite 관련 지침

**list_one**과 **list_two** 열에는 정수 목록이 JSON으로 인코딩되어 들어 있어요.

예시:

```json
[1, 2, 3]
```

## 테이블 스키마

```sql
CREATE TABLE sublist (
    list_one TEXT NOT NULL,     -- json array
    list_two TEXT NOT NULL,     -- json array
    result   TEXT
);
```
