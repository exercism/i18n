# 안내

회사는 사용자 입력으로부터 CSV 레코드를 생성하는 일을 맡게 되었어요.

[RFC 4180](https://tools.ietf.org/html/rfc4180)에 정의된 표준에 따라 CSV 레코드를 만들어 주는 빌더가 필요해요.

공식 명세가 있긴 하지만, 회사가 구현하면 되는 기능은 다음뿐이에요:
- 새 레코드 빌더 만들기
- 레코드에 개별 필드 추가하기
- 기본 이스케이프를 적용해 레코드 직렬화하기

기본 이스케이프란 다음과 같아요:

- 줄 바꿈, 큰따옴표, 쉼표를 포함하는 필드는 큰따옴표로 감싸야 해요.

- 필드를 감싸는 데 큰따옴표를 사용한다면, 필드 안에 나타나는 큰따옴표는 앞에 큰따옴표를 하나 더 붙여 이스케이프해야 해요.


## 1. 새 빌더 만들기

새 빌더를 만들려면 `new` 메서드를 구현해야 해요.

```rust
let mut builder = CsvRecordBuilder::new();
```

## 2. 레코드에 개별 필드 추가하기

레코드 빌더에 필드를 덧붙이려면 `add` 메서드를 구현해야 해요.
`add`는 인자로 불변 문자열 슬라이스인 `&str`을 받아요.

```rust
builder.add("ant");
builder.add("ba\"t");
builder.add("cat");
```


## 3. 기본 이스케이프를 적용해 레코드 직렬화하기

`build` 메서드를 구현해야 해요.
`build`는 빌더를 소비하고 CSV 레코드를 반환해요.
```rust
let record = builder.build();
// Note that from now on we cannot use `builder`
assert_eq!(&record, r#"ant,"ba""t",cat"#);
```
