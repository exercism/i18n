# 개요

코드에 분기가 필요할 때는 [`cond/1`][cond]을 사용할 수 있어요:

```elixir
cond do
  x > 10 -> :this_might_be_the_way
  y < 7 -> :or_that_might_be_the_way
  true -> :this_is_the_default_way
end
```

`cond`는 `true`로 평가되는 첫 번째 경로를 따라가요. 절 중 적어도 하나는 `true`로 평가되어야 하며, 그렇지 않으면 런타임 오류가 발생해요.

`cond` 조건문은 논리적 분기가 세 개 이상이고 각 분기의 조건이 서로 다른 변수를 기반으로 할 때 주로 사용해요. 모든 조건이 같은 변수를 기반으로 한다면 [`case`][case] 조건문이 더 잘 맞아요. 논리적 분기가 두 개뿐이라면 [`if`][if] 조건문을 사용해요.

[cond]: https://hexdocs.pm/elixir/case-cond-and-if.html#cond
[case]: https://hexdocs.pm/elixir/case-cond-and-if.html#case
[if]: https://hexdocs.pm/elixir/case-cond-and-if.html#if
