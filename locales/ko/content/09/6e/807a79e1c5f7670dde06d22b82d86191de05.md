# 콘솔에 출력하지 마세요

콘솔에 출력하는 함수는 제거하세요. 테스트에서 필요로 하지 않고, 코드를 조금 더 읽기 어렵게 만들어요.

보통 이런 문은 코드를 디버그하는 데 도움이 되도록 추가해요. 하지만 코드를 디버그하는 더 좋은 방법은 하나 이상의 단위 테스트를 실행하면서 디버그하는 거예요. 이렇게 하면 특정 테스트 케이스에 집중해서 디버그할 수 있다는 장점도 있어요. 다양한 IDE에서 단위 테스트를 실행하면서 Scala 코드를 디버그하는 방법을 설명하는 링크도 있어요:

- [IntelliJ](https://www.jetbrains.com/help/idea/run-debug-and-test-scala.html)
- [Eclipse](http://scala-ide.org/docs/current-user-doc/features/scaladebugger/index.html)
