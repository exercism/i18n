# 힌트

## 일반

- `plot` 튜플과 `registrations`, `next-id` 심볼, 그리고 `not-found` 심볼은
  이미 연습 문제 파일에 선언되어 있어요.
- 모듈 수준의 상태에는 `set-global`, `get-global`, `change-global`을
  사용해요.

## 1. 정원을 열고 등록 목록을 나열해요

- `V{ } clone`은 `registrations`의 올바른 시작 값이에요
  (리터럴이 호출 사이에 공유되지 않도록 항상 `clone`을 사용해요).
- `1 next-id set-global`은 카운터를 설정해요.
- `list-registrations`에는 `registrations get-global` 하나면 충분해요.

## 2. 밭을 등록해요

- 먼저 `next-id`를 읽고, 그다음 `plot boa`로 `id`와 `name`으로부터
  밭을 만들어요.
- `next-id [ 1 + ] change-global`로 카운터를 1 올려요.
- `push`([`sequences`][sequences]에 있어요)는 벡터에 제자리에서 값을 덧붙여요.
  `registrations get-global`에 딱 맞아요.

## 3. 밭을 해제해요

- `:: release ( id -- )`는 필터 조건자 안에서 `id`를 사용할 수 있게 해요.
- `[ id>> id = ] reject`는 `id` 슬롯이 지역 `id`와 일치하지 *않는* 모든 밭을
  남겨요. `change-global`의 본문으로 사용해요.

## 4. 등록된 밭을 가져와요

- `find`는 `( index elt/f )`를 반환해요. `nip`은 인덱스를 버려요.
- `[ not-found ] unless*`는 아무것도 찾지 못했을 때 그 심볼로 대체해요.

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
