# 소개

## 패키지와 모듈

### 가져오기

모듈은 보통 `use` 키워드로 불러와요.
`use`를 쓰면 모듈을 불러오는 동시에 그 모듈의 `import` 메서드를 호출해서, 내보낸 심볼을 모두 가져와요.

패키지의 `@EXPORT` 배열에 있는 심볼은 기본으로 가져와요.
패키지의 `@EXPORT_OK` 배열에 있는 심볼은 명시적으로 가져와야 해요.

### 내보내기

심볼을 가져오려면 먼저 그 심볼을 내보내야 해요.
[Exporter][Exporter] 모듈은 Perl에 기본으로 포함되어 있고, 내보내기에 가장 편리한 방법 중 하나예요.

모듈을 정의하는 방법:
```perl
package Foo;

use Exporter ('import');
our @EXPORT_OK = ('bar');

sub bar { ... }
```

모듈을 사용하는 방법:
```perl
use Foo ('bar');

bar();
```

### 코어 모듈

[Exporter][Exporter] 외에도 Perl에는 사용할 수 있는 다양한 [코어 모듈][perl-core-modules]이 있어요.
여기에서 만날 수 있는 연습 문제에 유용한 예로는 [List::Util][List::Util], [Time::Piece][Time::Piece], [Math::BigRat][Math::BigRat] 등이 있어요.

### CPAN

코어 모듈 외에도 [CPAN][metacpan]에는 Perl 커뮤니티가 만든 수천 개의 추가 모듈이 있어서 설치해서 쓸 수 있어요.
Perl 트랙은 [cpanfile][test-runner-cpanfile]을 사용해서 Exercism의 Perl 테스트 러너에서 쓸 수 있는 모듈을 설치해요.
