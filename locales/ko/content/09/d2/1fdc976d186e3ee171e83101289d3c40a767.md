# 힌트

## 일반

- 이름이 여러 다른 타입을 가질 수 있게 하려면 [유니언 타입][union-type]을 사용해야 해요.
- 인스턴스 변수를 [`if var.is_a?(Type)`][if-is-a] 제어 표현식에서 사용하려면, 먼저 지역 변수에 할당해야 해요.

## 1. 비밀번호 설정하기

- `PasswordLock`이라는 이름의 클래스를 정의해야 해요.
- `String`, `Int32`, `Float64` 중 하나를 인자로 받는 initialize 메서드를 정의해야 해요.
- 생성자에 전달된 인자로 설정되는 [인스턴스 변수][instance-variable] `@password`를 정의해야 해요.

## 2. 비밀번호 암호화하기

- `encrypt`라는 인스턴스 메서드를 정의해요.
- 이 메서드는 [인스턴스 변수][instance-variable] `@password`가 암호화되도록 수정해야 해요.
- 특정 분기가 변수가 특정 타입일 때만 실행되도록 하려면, 제어 표현식에서 [`is_a?`][is-a] 메서드를 사용해야 해요.

## 3. 비밀번호가 올바른지 확인하기

- 이미 정의된 메서드를 사용해서 주어진 비밀번호 시도 값을 암호화할 수 있어요.
