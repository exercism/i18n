그런데 정리가 조금 엉망이에요. Aazra의 좌표는 Rui의 좌표와 형식도, 정렬 순서도 달라 보여서, 어느 보물이 어느 위치에 해당하는지 알아내려면 두 목록을 번갈아 보면서 계속 확인해야 해요. 이제 막 Gleam을 배우기 시작한 두 사람은 보물찾기 정보를 더 잘 정리할 작은 프로그램(사실은 여러 함수의 모음)을 작성하는 데 도움을 청하러 왔어요.

## 1. 위치 변환하기

장소 위치(예: `#("C", 1)`)를 받아 보물 위치(예: `#(1, "C")`)로 변환하는 `place_location_to_treasure_location` 함수를 구현해요.

```gleam
place_location_to_treasure_location(#("C", 1))
// -> #(1, "C")
```

## 2. 보물 위치와 장소 위치 비교하기

장소 위치(예: `#("C", 1)`)를 받아 보물 위치(예: `#(1, "C")`)와 일치하면 `True`를 반환하는 `treasure_location_matches_place_location` 함수를 구현해요.

```gleam
treasure_location_matches_place_location(#("C", 1), #(1, "C"))
// -> True

treasure_location_matches_place_location(#("C", 1), #(2, "C"))
// -> False
```

## 3. 보물 위치 개수 세기

장소(예: `#("Aqua Lagoon (Island of Mystery)", #("F", 1))`)와 보물 목록을 받아, 그곳에서 찾을 수 있는 보물의 개수를 반환하는 `count_place_treasures` 함수를 구현해요.

```gleam
let place = #("Aqua Lagoon (Island of Mystery)", #("F", 1))

count_place_treasures(place, treasures)
// -> 2
```

## 4. 특별한 장소

보물(예: `#("Amethyst Octopus", #(1, "F"))`), 장소(예: `#("Seaside Cottages", #("C", 1))`), 그리고 원하는 보물(예: `#("Crystal Crab", #(6, "A"))`)을 받아, 다음 조합에 대해 `True`를 반환하는 `special_case_swap_possible` 함수를 구현해요.

- Abandoned Lighthouse에서는 Brass Spyglass를 다른 어떤 보물과도 교환할 수 있어요.
- Stormy Breakwater에서는 Amethyst Octopus를 Crystal Crab 또는 Glass Starfish로 교환할 수 있어요.
- Harbor Managers Office에서는 Vintage Pirate Hat을 Model Ship in Large Bottle 또는 Antique Glass Fishnet Float와 교환할 수 있어요.
