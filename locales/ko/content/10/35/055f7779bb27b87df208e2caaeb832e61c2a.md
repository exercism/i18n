# 지시사항

어떤 박물학자가 칼데라 주변에 사는 용들을 목록으로 정리하고 있어요. 용들은 서로 공통된 특징을 지니고 있어요. 모든 용에게는 이름, 색깔, 나이가 있죠. 하지만 각자만의 뚜렷한 방식으로 특화되어 있어요. 이제 용 클래스로 이루어진 작은 상속 트리와, 어떤 자손이든 나이를 먹이는 단어 하나를 만들 거예요.

## 1. 용 가족

튜플 클래스로 이루어진 상속 트리 전체를 먼저 정의해요(생성자는 뒤따르는 과제에서 만들어요).

- `dragon`: `name`, `color`, `age` 슬롯을 가져요.
- `fire-dragon`: `dragon`의 하위 클래스로, `flame-temp` 슬롯을 추가해요.
- `ice-dragon`: `dragon`의 또 다른 하위 클래스로, `chill-temp` 슬롯을 추가해요.
- `volcano-dragon`: `fire-dragon`의 하위 클래스로, `lava-volume` 슬롯을 추가해요.

그다음 `dragon`에 `<dragon>` 생성자를 만들어 줘요.

```factor
"Falkor" "white" 100 <dragon> name>> .   ! => "Falkor"
```

## 2. 불을 뿜는 용들

`fire-dragon`에 `<fire-dragon>` 생성자를 만들어 줘요.

```factor
"Smaug" "red" 500 1200 <fire-dragon> flame-temp>> .   ! => 1200
"Smaug" "red" 500 1200 <fire-dragon> dragon? .        ! => t
```

## 3. 얼음을 뿜는 용들

`ice-dragon`에 `<ice-dragon>` 생성자를 만들어 줘요.

```factor
"Frosty" "blue" 200 -40 <ice-dragon> chill-temp>> .   ! => -40
"Frosty" "blue" 200 -40 <ice-dragon> fire-dragon? .   ! => f   (siblings)
```

## 4. 화산에 사는 용들

`volcano-dragon`에 `<volcano-dragon>` 생성자를 만들어 줘요.

```factor
"Vesuvius" "red" 1000 1500 99 <volcano-dragon> dragon? .       ! => t
"Vesuvius" "red" 1000 1500 99 <volcano-dragon> fire-dragon? .  ! => t
```

## 5. 어떤 용이든 나이 먹이기

`age-dragon`을 정의해서, 어떤 용(또는 자손)이든 `age` 슬롯을 하나씩 증가시켜요. 반환하는 값은 없어요.

```factor
"Falkor" "white" 100 <dragon> dup age-dragon age>> .   ! => 101
```

같은 단어가 모든 자손에서 동작해야 해요. 공유 접근자가 있는 이유가 바로 그거예요.
