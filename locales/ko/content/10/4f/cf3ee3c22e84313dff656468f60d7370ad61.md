# Case

[Case][case](다른 언어에서는 흔히 switch라고 불러요)는 if-else와 같은 제어 표현의 한 형태예요.
케이스를 사용하면 여러 개의 if-else-if 문을 이어서 쓸 수 있고, 흐름 제어를 하면서도 더 읽기 쉬운 코드를 만들 수 있어요.

케이스는 `case` 키워드와 그 뒤에 오는 선택적 표현식으로 정의돼요.
그다음 각 분기마다 `when` 키워드를 쓰고, 그 뒤에 케이스 표현식과 비교할 표현식을 적어요.
`when` 키워드는 `case` 키워드보다 더 들여쓰면 안 돼요.
`when` 키워드 뒤에는, 케이스 표현식이 `when`에 적은 표현식과 일치할 때 실행할 코드가 와요.
케이스에는 선택적으로 `else` 문을 쓸 수 있고, 이 코드는 어떤 케이스와도 일치하지 않을 때 실행돼요.

케이스 표현식이 평가된 다음, 각 `when` 표현식과 비교돼요.
이때 비교에는 케이스 동등 연산자(`===`)를 사용해요.

```ruby
value = 1
case value
when 1
  "One"
when 2
  "Two"
else
  "Other"
end

# This is the same as:
value = 1
if 1 === value
  "One"
elsif 2 === value
  "Two"
else
  "Other"
end
```

## 케이스 동등 연산자 (`===`)

케이스 동등 연산자(`===`)는 동등 연산자(`==`)와는 조금 달라요.
이 연산자는 오른쪽 값이 왼쪽 값이 나타내는 집합에 속하는지 확인해요.
즉, 두 피연산자를 어느 쪽에 두느냐가 중요해요.
어떻게 동작하는지는 왼쪽 값의 타입에 따라 달라요. 예를 들어 `Range`라면 오른쪽 값이 그 범위에 들어 있는지 확인하고, `Object`라면 오른쪽 값이 `Object`의 인스턴스인지 확인해요.

```ruby
(1..3) == 1  # => false
(1..3) === 1 # => true

String == "foo"  # => false
String === "foo" # => true
```

## 여러 표현식을 사용하는 케이스

케이스에서는 하나의 분기에 여러 표현식을 쉼표로 구분해서 나열할 수 있어요.
나열한 표현식 중 하나라도 일치하면 코드가 실행돼요.
하나의 분기에 여러 가능한 값을 두고 싶을 때 유용해요.

```ruby
case var
when 1, 2
  "One or two"
else
  "Other"
end
```

## 범위를 사용하는 케이스

케이스는 값이 범위 안에 있는지도 확인할 수 있어요.
`when` 표현식에 범위를 쓰면 돼요.

```ruby
case var
when 1..3
  puts "One to three"
else
  puts "Other"
end
```

## 케이스 표현식이 없는 케이스

케이스 표현식이 필요 없을 때는 생략할 수 있어요.
이렇게 하면 각 분기의 표현식을 참인지 여부로 평가해요.
그래서 if-else-if 문처럼 동작해요.

```ruby
case
when 1 == 1
  "One is equal to one"
when 1 > 2
  "One is greater than two"
else
  "Other"
end
```

## 한 줄로 쓰는 when

Ruby에서는 케이스 문을 한 줄로 쓸 수 있어요.
실행할 코드가 한 줄로 간단할 때 유용해요.
한 줄 when 문은 `when <expression> then <statement>` 형태로 써요.
그리고 `else` 문에서 사용할 때는 `else <statement>`로 써요.

```ruby
case var
when 1 then "One"
when 2 then "Two"
else "Other"
end
```

## 타입과 함께 쓰는 케이스

케이스는 타입을 기준으로 일치 여부를 확인할 수도 있어요.
변수의 타입에 따라 다르게 동작하게 하고 싶을 때 유용해요.

```ruby
case var
when Integer
  "Integer"
when String
  "String"
else
  "Other"
end
```
