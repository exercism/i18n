# 소개

재귀 함수는 자기 자신을 호출하는 함수예요.

재귀 함수에는 적어도 하나의 _기저 조건_과 적어도 하나의 _재귀 조건_이 있어야 해요.

_기저 조건_은 함수를 다시 호출하지 않고 값을 반환해요.
_재귀 조건_은 입력을 바꿔서 함수를 다시 호출해요. 그러면 언젠가는 기저 조건에 맞게 돼요.

Elm에서 재귀 함수는 보통 `case` 표현식이나 여러 개의 함수 절을 사용한 패턴 매칭으로 정의해요.

```elm
count : List a -> Int
count list =
    case list of
        [] ->
            0  -- base case

        _ :: tail ->
            1 + count tail  -- recursive case
```

## 재귀로 반복하기

불변성 때문에 Elm에서 루프는 명령형 언어와 다르게 작성해요.
예를 들어, 루프는 보통 이렇게 생겼어요:

```c
for(i = 0; i < array.length; i++) {
  // do something with array[i]
}
```

Elm 같은 함수형 언어에서는 변수를 변경할 수 없어요.
그래서 루프는 재귀로 구현해야 해요.

Elm에서 `for`문에 해당하는 코드는 이렇게 생겼어요:

```elm
loop : List a -> (a -> b) -> List b
loop list f =
    case list of
        [] ->
            []

        head :: tail ->
            f head :: loop tail f
```

실제로 Elm에서 리스트나 다른 자료 구조를 순회할 때는 `List` 모듈의 `List.map`, `List.filter`, `List.foldl` 같은 함수를 사용하는 경우가 가장 많아요.
내부적으로 이런 함수들은 재귀로 구현되어 있어요.
