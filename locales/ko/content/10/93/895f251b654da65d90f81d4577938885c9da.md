# 지시 사항

Ellen은 플레이어가 외계인과 싸워야 하는 게임을 만들고 있어요.
막 객체 지향 프로그래밍(OOP)을 배운 참이라, `classes`를 사용하면 프로그램에 어떤 도움이 될지 기대에 부풀어 있어요.

Ellen은 기뻐하며 여러분에게 도움을 청했고, 여러분은 플레이어가 싸워야 할 외계인을 프로그래밍하는 일을 맡게 되었어요.


## 1. Alien 클래스 만들기

두 매개변수 `<x_coordinate>`, `<y_coordinate>`를 받는 생성자를 가진 Alien 클래스를 정의하고, 이 값들을 `x_coordinate`와 `y_coordinate` 인스턴스 변수에 넣어요.
또한 모든 외계인은 체력 3으로 시작하므로, `health` 변수도 함께 초기화해야 해요.

```python
>>> alien = Alien(2, 0)
>>> alien.x_coordinate
2
>>> alien.y_coordinate
0
>>> alien.health
3
```

이제 각 외계인은 자신의 위치와 체력을 내부적으로 추적할 수 있어야 해요.

## 2. `hit` 메서드

Ellen은 Alien `class`에, 호출되면 외계인 객체의 체력을 1만큼 줄여 주는 `hit` 메서드가 있으면 좋겠다고 해요.
이렇게 하면 외계인의 체력을 직접 바꾸지 않고도 `<alien>.hit()`을 호출하기만 하면 돼요.
`hit()`이 체력을 0까지 낮출지, 0 아래로도 내려가게 할지는 여러분이 정하면 돼요.

```python
>>> alien = Alien(0, 0)

# Initialized health value.
>>> alien.health
3

# Decrements health by 1 point.
>>> alien.hit()
>>> alien.health
2
```

## 3. `is_alive` 메서드

체력이 계속 줄어들다 보면 언젠가는 0이 되거나, _심지어 그보다 더 낮아질 수도_ 있다는 걸 알게 될 거예요.
그럴 때 Ellen이 외계인이... 음... 살아 있는지 빠르게 확인할 수 있도록 `is_alive` 메서드를 추가하면 좋겠어요. 😉
`<alien>.is_alive()`는 불리언을 반환해야 해요.

```python
>>> alien.health
1
>>> alien.is_alive()
True
>>> alien.hit()
>>> alien.health
0
>>> alien.is_alive()
False
```

## 4. `teleport` 메서드

Ellen의 게임에서 외계인은 순간이동 능력을 가지고 있어요!
새로운 `x_coordinate`와 `y_coordinate` 값을 받아 그에 맞게 외계인의 좌표를 바꾸는 `teleport` 메서드를 작성해야 해요.

```python
>>> alien.teleport(5, -4)
>>> alien.x_coordinate
5
>>> alien.y_coordinate
-4
```

## 5. `collision_detection` 메서드

외계인이 무언가에 맞을 수 있다면, 당연히 그런 충돌이 일어났을 때 이를 감지할 수 있어야 해요.
하지만 충돌 감지 알고리즘은 까다로울 수 있고, 아직 어떻게 구현해야 할지 모르죠.
Ellen은 나중에 직접 하겠다고 했지만, 기능을 구현해야 한다는 걸 잊지 않도록 `collision_detection` 메서드를 클래스에 넣어 두고 싶어 해요.
이 메서드는 어떤 종류의 변수(아마도 다른 객체)를 받아야 하지만, 아직 아는 건 그것뿐이에요.
메서드 정의를 클래스에 넣었을 때 호출해도 오류가 나지 않도록 해야 해요:

```python
>>> alien.collision_detection(other_object)
>>>
```

## 6. Alien 개수 세기

Ellen이 새로운 부탁을 가지고 돌아왔어요.
게임이 진행되는 동안 외계인이 몇 개 만들어졌는지 추적하고 싶대요.
점수 시스템과 관련이 있다고 말해요.

예를 들어:

```python
>>> alien_one = Alien(5, 1)
>>> alien_one.total_aliens_created
1
>>> alien_two = Alien(3, 0)
>>> alien_two.total_aliens_created
2
>>> alien_one.total_aliens_created
2
# Accessing the variable from the class directly
>>> Alien.total_aliens_created
2
```

## 7. Alien 배열 만들기

Ellen은 지금까지 해준 게 마음에 쏙 들지만, 부탁이 하나 더 있어요.
`Alien()` 클래스 _바깥에_ 있는 독립적인 함수를 원하는데, 이 함수는 위치들의 배열(`tuples` 형태)을 받아 `Alien()` 객체들의 `list`를 만들어요.

예를 들어:

```python
>>> alien_start_positions = [(4, 7), (-1, 0)]
>>> aliens = new_aliens_collection(alien_start_positions)
...
>>> for alien in aliens:
...     print(alien.x_coordinate, alien.y_coordinate)
(4, 7)
(-1, 0)
```
