# 소개

C#은 정적 타입 언어예요. 즉, 컴파일 시점에 모든 것에 타입이 있어요. 이름에 값을 할당하는 것을 변수를 정의한다고 해요. 변수는 타입을 명시적으로 지정해서 정의할 수도 있고, 할당된 값을 바탕으로 C# 컴파일러가 타입을 추론하도록 해서 정의할 수도 있어요(이를 _타입 추론_이라고 해요). 따라서 다음 두 변수 정의는 서로 같아요:

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

변수의 값을 바꿀 때는 `=` 연산자를 사용해요. 한 번 정의된 변수의 타입은 절대 바뀌지 않아요.

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

C#은 [객체 지향 언어][object-oriented-programming]이고, 모든 함수를 _클래스_ 안에 정의해야 해요. `class` 키워드는 클래스를 정의할 때 사용해요. 객체(또는 _인스턴스_)는 `new` 키워드로 만들어요.

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

클래스 안의 함수를 _메서드_라고 해요. 각 메서드는 매개변수를 0개 이상 가질 수 있어요. 모든 매개변수는 타입을 명시해야 해요. 매개변수에는 타입 추론이 적용되지 않아요. 마찬가지로 반환 타입도 명시해야 해요. 메서드에서 값을 반환할 때는 `return` 키워드를 사용해요. 다른 파일의 코드에서 메서드를 호출할 수 있게 하려면 `public` 접근 제한자를 추가해야 해요.

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

메서드는 인스턴스에서 점(`.`) 문법을 사용해 호출하며, 호출할 메서드 이름을 지정하고 메서드의 각 매개변수에 대한 인자를 전달해요. 인자는 해당 매개변수의 이름을 선택적으로 지정할 수 있어요.

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

C#에서 스코프는 `{`와 `}` 문자 사이에 정의돼요.

C#은 두 가지 종류의 주석을 지원해요. 한 줄 주석은 `//`로 시작하고, 여러 줄 주석은 `/*`와 `*/` 사이에 넣어요.

[object-oriented-programming]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/object-oriented-programming
