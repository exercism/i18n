# 지침 추가

## 출력 형식

단백질 서열을 null로 끝나는 문자열로 출력하고, 각 단백질 뒤에는 줄바꿈 문자를 넣어요.

출력 예시는 `"Methionine\nPhenylalanine\nSerine\n"`예요.

입력이 유효하지 않으면 빈 문자열을 출력해요.

## 레지스터

| 레지스터 | 용도         | 타입    | 설명                          |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | 입력         | 주소    | null로 끝나는 입력 문자열      |
| `$a1`    | 입력/출력    | 주소    | null로 끝나는 출력 문자열      |
| `$t0-9`  | 임시         | 임의    | 임시 저장에 사용               |
