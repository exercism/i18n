# 설명

고전적인 입문 연습 문제예요.
그냥 "Hello, World!"라고 말하면 돼요.

["Hello, World!"][hello-world]는 새로운 언어나 환경에서 프로그래밍을 처음 시작할 때 작성하는 전통적인 첫 프로그램이에요.

목표는 간단해요:

- 주어진 코드를 수정해서 "Hello, World!"라는 문자열을 출력하도록 만들어요.
- 테스트 스위트를 실행해서 성공하는지 확인해요.
- 풀이를 제출하고 웹사이트에서 확인해요.

모든 게 잘 되면, 첫 번째 진짜 연습 문제를 받을 준비가 된 거예요.

[hello-world]: https://en.wikipedia.org/wiki/%22Hello,_world!%22_program
