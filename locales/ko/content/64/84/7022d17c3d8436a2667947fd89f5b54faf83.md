# 추상 클래스

서커스 쇼는 여러 개의 공연으로 이루어진 목록이에요. 저글링, 공중 그네, 텀블링은
속도 다르고 내용도 다른 것들이지만, 공연 순서를 짜는 사람이 각 공연에서 필요한 건
딱 두 가지뿐이에요. 이름과, 걸리는 시간이죠.

**추상 클래스**는 딱 그만큼만 설명해요.

```sather
abstract class $ACT is
   name : STR;
   minutes : INT;
end; -- abstract class $ACT
```

이름은 `$`로 시작해요. 몸통이 없는 루틴들을 나열하죠. 시그니처만 있고, 각 줄은
세미콜론으로 끝나요. 이걸로는 아무것도 만들 수 없어요. `create`도 `new`도 없거든요.

## 적합성

실제 클래스는 `<` 뒤에 `$ACT`를 적어서 자신이 `$ACT`임을 약속해요.

```sather
class JUGGLING < $ACT is

   create : SAME is return new; end;

   name : STR is return "Juggling"; end;

   minutes : INT is return 5; end;

end; -- class JUGGLING
```

`<`는 'is a'라고 읽어요. 이 클래스는 추상 클래스가 나열한 모든 루틴을 같은 인자와
같은 반환 타입으로 제공해야 해요. 하나라도 빠뜨리면 컴파일 오류예요. 실행 중에야
알게 되는 게 아니죠.

클래스는 원하는 대로 다른 것들을 얼마든지 더할 수 있어요. `TRAPEZE`는 다른 어떤
공연에도 없는 높이 값을 가질 수 있죠. 추상 클래스는 그걸 알지도, 신경 쓰지도 않아요.

## 타입 사용하기

`$ACT`는 타입이라서 무엇이든 이걸로 선언할 수 있어요.

```sather
   acts : ARRAY{$ACT} := |#JUGGLING, #TRAPEZE(4), #TUMBLING|;
```

이 배열은 서로 다른 세 클래스의 객체를 한꺼번에 담아요. `ARRAY{JUGGLING}`은 그럴 수
없죠.

## 디스패치

```sather
   loop
      total := total + acts.elt!.minutes;
   end;
```

`acts.elt!`는 `$ACT`예요. 어떤 `minutes`가 실행될지는 그 줄이 실행될 때 객체가 실제로
무엇인지에 따라 정해져요. 저글링이면 `JUGGLING::minutes`, 공중 그네면
`TRAPEZE::minutes`죠. 이렇게 고르는 것을 **디스패치**라고 해요.

더하기를 하는 루틴은 자신이 어떤 종류의 공연을 다루는지 절대 묻지 않아요. 네 번째
종류의 공연을 추가하려면 새 클래스 하나만 쓰면 되고, 다른 건 아무것도 바꿀 필요가
없어요. 이게 바로 이렇게 하는 이유 전부예요.
