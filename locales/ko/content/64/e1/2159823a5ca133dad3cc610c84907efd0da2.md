# 소개

`Complex numbers`는 복잡하지 않아요.
이름만 좀 덜 놀랍게 지으면 될 뿐이에요.

복소수는 특히 공학과 과학에서 아주 유용해서, R은 integer, double, logical, character, raw와 나란히 복소수를 표준 원자형 타입으로 포함하고 있어요.

## 기본

R에서 `complex` 수는 하나의 값이에요.
하지만 실제로 쓸 때는 두 수의 짝으로 생각할 수 있어요.
이 둘은 안타까운 역사적 이유 때문에 각각 "실수부"와 "허수부"라고 불려요.
다시 말하지만, 이상한 이름보다 그 바탕에 있는 단순함에 집중하는 게 좋아요.

두 실수로 복소수를 만들려면 허수부에 접미사 `i`만 붙이면 돼요.

```r
2+3i
#> [1] 2+3i

typeof(2+3i)
#> [1] "complex"
```

실수 변수로 복소수를 만들 때는 위 문법이 통하지 않아요.
`r + imi`라고 쓰면 파서가 `imi`를 (존재하지 않는) 변수 이름으로 착각해요.

허수부에 `1i`를 곱하거나 [`complex()`][ref-complex] 함수를 사용해요:

```r
r <- 2
im <- 3

r + im * 1i
#> [1] 2+3i

# must include the `real` and `imaginary` keywords
complex(real = r, imaginary = im)
#> [1] 2+3i
```

`j`가 아니라 왜 `i`일까요?

대부분의 엔지니어는 `j`를 선호해요.
대부분의 과학자와 수학자는 _허수(imaginary)_를 나타내는 수학 표기 `i`를 선호하지만, 그 표기는 전기공학에서 `i`가 _전류(current)_를 뜻하는 것과 충돌해요.

R은 `i`를, Python은 `j`를 선택했고, Julia는 `im`을 선택해 논란을 피했어요.
[STEM][wiki-STEM] 프로그래밍 언어 사이를 오갈 때는 주의해요.

복소수의 각 부분에 개별적으로 접근하려면:

```r
z <- 2+3i

Re(z)  # real part
#> [1] 2

Im(z)  # imaginary part
#> [1] 3
```

어느 한쪽 부분이 0일 수도 있고, 그러면 수학자들은 그 수를 "완전히 실수" 또는 "완전히 허수"라고 말하기도 해요.
하지만 R에서는 여전히 복소수예요.

```r
1.2 + 0i
#> [1] 1.2+0i

typeof(1.2 + 0i)
#> [1] "complex"

2i
#> [1] 0+2i

typeof(2i)
#> [1] "complex"
```

"`i`(또는 `j`)가 -1의 제곱근이다"라는 말을 들어봤을지도 몰라요.

지금은 허수부가 _정의상_ 다음 등식을 만족한다는 뜻일 뿐이에요:

```r
1i * 1i == -1  # more precisely, 1i * 1i == -1 + 0i
#> [1] TRUE
```

단순한 아이디어지만, 흥미로운 결과로 이어져요.

## 산술

실수와 정수에 쓰는 대부분의 연산자는 복소수에도 그대로 통해서요:

```r
z1 = 1.5 + 2i
z2 = 2 + 1.5i

z1 + z2  # addition
#> [1] 3.5+3.5i

z1 * z2  # multiplication
#> [1] 0+6.25i

z1 / z2  # division
#> [1] 0.96+0.28i

z1^2  # exponentiation
#> [1] -1.75+6i

2^z1  # another exponentiation
#> [1] 0.518895+2.780422i
```

## 함수

대부분의 수학 함수는 복소수 입력에서도 동작해요.

`Re()`와 `Im()` 외에도 복소수와 특히 관련이 깊은 함수가 몇 가지 있어요.

- `Conj()`는 복소수 허수부의 부호를 뒤집기만 해요(_+에서 -로, 또는 그 반대로_).
  - 복소수 곱셈이 동작하는 방식 덕분에, 생각보다 훨씬 유용해요.
- `abs(<complex number>)`는 허수부가 없는 실수(그 수의 "크기")를 반환하는 것이 보장되고, `Mod(<complex number>)`는 같은 뜻이에요.
- `Arg(<complex number>)`는 위상각을 라디안으로 반환해요.

```r
z1
#> [1] 1.5+2i

abs(z1)
#> [1] 2.5

Mod(z1)  # same as previous
#> [1] 2.5

Conj(z1)  # flip sign
#> [1] 1.5-2i

Arg(z1)
#> [1] 0.9272952
```
