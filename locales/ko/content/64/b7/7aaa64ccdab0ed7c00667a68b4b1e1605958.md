# 소개

## 무작위성

Elixir에서는 열거 가능한 자료 구조(예: 배열, 범위)에서 무작위로 원소 하나를 고를 때 `Enum.random`을 사용해요. 이 함수는 원소 하나를 고르는데, 모든 원소가 뽑힐 확률이 같아요.

Elixir에는 무작위 실수를 뽑는 자체 함수가 없어요. 그러려면 Erlang을 직접 사용해야 해요.

## Erlang 라이브러리

Elixir 코드는 BEAM 가상 머신에서 실행돼요. BEAM은 Erlang 런타임 시스템의 일부예요. Erlang에서 영감을 받았고 실행 환경을 공유하기 때문에, Elixir는 Erlang 라이브러리와 뛰어난 상호 운용성을 제공해요. 덕분에 Elixir 개발자는 자신의 Elixir 코드 안에서 Erlang 라이브러리를 사용할 수 있어요. 실제로 Elixir 커뮤니티에서는 이미 Erlang 라이브러리가 제공하는 기능을 위해 Elixir 라이브러리를 작성하는 것을 권장하지 않아요.

그래서 수학 연산이나 타이머 함수 같은 일부 기능은 Elixir에서 Erlang을 통해서만 사용할 수 있어요.

Erlang의 표준 라이브러리는 별도의 추가 작업 없이 우리 Elixir 코드에서 바로 사용할 수 있어요.

Erlang 함수는 Elixir 함수를 호출하는 것과 같은 방식으로 호출할 수 있는데, 작은 차이가 하나 있어요. Erlang 모듈 이름은 `snake_case` 아톰이에요. 예를 들어 `math` 모듈의 Erlang `pi/0` 함수를 호출하려면 이렇게 써요:

```elixir
:math.pi()
# => 3.141592653589793
```

Elixir에 대응하는 함수가 없는, 가장 많이 쓰이는 Erlang 함수는 다음과 같아요:

- `:timer.sleep/1`은 주어진 밀리초만큼 프로세스를 일시 중단해요.
- `:rand.uniform/0`은 `0.0 <= x < 1.0` 범위의 무작위 실수 `x`를 생성해요.
- `:io_lib.format/2`는 C 스타일의 문자열 서식(제어 시퀀스를 사용)을 제공해요. 이 함수를 사용하면 예를 들어 2에서 36 사이의 임의의 진법으로 정수를 출력하거나, 원하는 정밀도로 실수를 서식화할 수 있어요. 이 함수는 많은 Erlang 함수처럼 charlist를 반환한다는 점에 유의해요.
- `sin/1`, `cos/1`, `log2/1`, `log10/1`, `pow/2` 등 수학 함수를 제공하는 `math` 모듈도 있어요.

Erlang의 표준 라이브러리를 살펴보려면 [STDLIB 레퍼런스 매뉴얼][erl-stdlib-ref]을 확인해 봐요.

[erl-stdlib-ref]: https://www.erlang.org/doc/apps/stdlib/index.html
