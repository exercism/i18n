# 힌트

## 일반

- 유효 주소는 [lea][lea] 명령어로 계산할 수 있어요.
- 메모리에서 유효한 상대 주소를 만들려면 `rel`을 사용해야 해요.
- 메모리에서 8바이트 값을 접근할 때 쓰는 접두사는 `qword`예요.

## 1. 지난주 개수가 얼마였는지 확인하기

- 유효 주소는 [lea][lea] 명령어로 계산할 수 있어요.
- 메모리에서 유효한 상대 주소를 만들려면 `rel`을 사용해야 해요.
- 메모리에서 8바이트 값을 접근할 때 쓰는 접두사는 `qword`예요.
- 메모리의 주소에 저장된 내용에 접근하려면 `[]`를 사용해 역참조해야 해요.

## 2. 이번 주의 현재 개수가 얼마인지 확인하기

- 유효 주소는 [lea][lea] 명령어로 계산할 수 있어요.
- 메모리에서 유효한 상대 주소를 만들려면 `rel`을 사용해야 해요.
- 메모리에서 8바이트 값을 접근할 때 쓰는 접두사는 `qword`예요.
- 초기화되지 않은 변수는 _section .bss_에 정의돼요.
- 함수에서 정수 두 개를 반환하려면 `rax`과 `rdx`를 모두 사용해야 해요.

## 3. 각 날짜의 개수 저장하기

- 유효 주소는 [lea][lea] 명령어로 계산할 수 있어요.
- 메모리에서 유효한 상대 주소를 만들려면 `rel`을 사용해야 해요.
- 메모리에서 8바이트 값을 접근할 때 쓰는 접두사는 `qword`예요.
- 메모리에서 1바이트 값을 접근할 때 쓰는 접두사는 `byte`예요.
- 메모리에 접근할 때 더 큰 데이터 크기의 접두사를 사용하면 바이트를 한꺼번에 삽입하거나 가져올 수 있어요.
- [cmp][cmp]로 조건을 확인할 수 있어요.
- [jcc][jcc]로 조건부 분기할 수 있어요.
- [inc][inc]를 사용해 대상 피연산자의 값에 1을 더할 수 있어요.

## 4. 오늘 새가 몇 마리 방문했는지 확인하기

- 유효 주소는 [lea][lea] 명령어로 계산할 수 있어요.
- 메모리에서 유효한 상대 주소를 만들려면 `rel`을 사용해야 해요.
- 메모리에서 8바이트 값을 접근할 때 쓰는 접두사는 `qword`예요.
- 1바이트 정수 값은 `al`에 반환돼요.
- [dec][dec]를 사용해 대상 피연산자의 값에서 1을 뺄 수 있어요.
