# 지침

입력 텍스트가 주어지면, 이를 전치해서 출력해요.

대략 설명하자면, 행렬의 전치는 다음과 같아요:

```text
ABC
DEF
```

전치하면 이렇게 돼요:

```text
AD
BE
CF
```

행은 열이 되고, 열은 행이 돼요. 자세한 내용은 <https://en.wikipedia.org/wiki/Transpose>를 참고해요.

입력의 행 길이가 서로 다르다면, 다음과 같이 처리해요:

- 왼쪽은 공백으로 채워요.
- 오른쪽은 채우지 않아요.

따라서 다음 행렬을 전치하면:

```text
ABC
DE
```

이렇게 돼요:

```text
AD
BE
C
```

그리고 다음을 전치하면:

```text
AB
DEF
```

이렇게 돼요:

```text
AD
BE
 F
```

일반적으로 입력의 모든 문자는 전치된 출력에도 그대로 있어야 해요.
즉, 입력 텍스트의 어떤 열이 맨 아래 행에 공백만 가지고 있다면, 그에 대응하는 출력 행은 맨 오른쪽 열에 그 공백을 포함해야 해요.
