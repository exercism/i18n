# 힌트

## 일반 사항

- 이번 챌린지는 [단일 연결 리스트][singly linked list]를 이용해 [_스택_][Baeldung: The Stack Data Structure]을 만드는 과제예요.
- `lists`, `collections.deque`, `queue.LifoQueue`를 기반으로 한 스택과는 달리, 이번에는 원소를 저장하고 연결할 수 있도록 직접 `Node`와 `LinkedList` [`classes`][classes tutorial]를 만들어야 해요.

![연결 리스트로 구현한 스택을 나타내는 그림이에요. 맨 왼쪽에는 New_Node라는 이름의 점선 테두리 원이 있고, 오른쪽을 향하는 점선 화살표 두 개가 있어요. New_Node에는 "(becomes head) - New_Node - next = node_6"이라고 적혀 있어요. 위쪽 점선 화살표에는 "push"라는 라벨이 붙어 있고 오른쪽 위의 Node_6을 가리켜요. Node_6에는 "(current) head - Node_6 - next = node_5"라고 적혀 있어요. 아래쪽 점선 화살표에는 "pop"이라는 라벨이 붙어 있고 "gets removed on pop()"이라고 적힌 상자를 가리켜요. Node_6에서 오른쪽으로 실선 화살표가 뻗어 Node_5를 가리키고, Node_5에는 "Node_5 - next = node_4"라고 적혀 있어요. Node_5에서 오른쪽으로 실선 화살표가 Node_4를 가리키고, Node_4에는 "Node_4 - next = node_3"이라고 적혀 있어요. 이 패턴이 Node_1까지 이어지고, Node_1에는 "(current) tail - Node_1 - next = None"이라고 적혀 있어요. Node_1에서 오른쪽으로 점선 화살표가 "None"이라고 적힌 노드를 가리켜요.](https://assets.exercism.org/images/tracks/python/simple-linked-list/linked-list.svg)

- 구현 세부 사항을 복습할 때 [Real Python: Linked Lists][Real Python Linked Lists], [Towards Data Science: Demystifying the Linked List][towards data science demystifying the linked list], [ADS Stack in Python][Koder Dojo Coding an ADS Stack in Python]가 도움이 될 수 있어요.
- `LinkedList`는 _생성자_에서 `list` 인자를 받아야 하지만, 노드나 원소를 저장하는 데 `list`를 사용하면 안 돼요.
- `len()`은 대부분의 Python 객체에 있는 내장 함수예요.
_직접 만든 객체_가 `len()`을 지원하려면 특수 메서드 [`__len__`][__len__]을 정의해야 해요.
- Python에서는 대부분의 시퀀스, 컨테이너, 컬렉션 타입 객체가 반복을 지원해요.
_직접 만든_ 객체가 반복이나 재정렬을 지원하려면 특수 메서드 `__iter__`를 정의해야 해요.
[Implementing an iterator for a class][implementing iterators] 문서가 방법을 보여주는 데 도움이 될 거예요.
