# 힌트

## 일반

- [튜플][tuple]은 값을 변경할 수 없고, 크기가 고정되어 있으며, 어떤 데이터 타입이든 담을 수 있는 자료 구조예요.
- 심볼은 유한한 상태를 나타내는 데 사용할 수 있어요. 이 연습 문제에서는 사용하는 단위를 나타내기 위해 `:cup`, `:fluid_ounce`, `:teaspoon`, `:tablespoon`, `:milliliter`를 사용해요.

## 1. 부피 쌍에서 숫자 부분 가져오기

- 부피 쌍의 숫자 부분을 반환하도록 튜플을 인덱싱하는 방법을 생각해 봐요.

## 2. 부피 쌍을 밀리리터로 변환하기

- 제어 흐름 로직을 사용해서 단위에 따라 어떤 로직을 적용할지 결정해요.
- 모든 단위에서 밀리리터로 변환하는 메서드를 구현해요. 밀리리터에서 밀리리터로의 변환도 포함해서요.

## 3. 밀리리터 부피 쌍을 다른 단위로 변환하기

- 제어 흐름 로직을 사용해서 단위에 따라 어떤 로직을 적용할지 결정해요.
- 밀리리터에서 모든 단위로 변환하는 메서드를 구현해요. 밀리리터에서 밀리리터로의 변환도 포함해서요.

## 4. 모든 단위에서 모든 단위로 변환하기

- 이미 만든 메서드를 재사용해서 `KitchenCalculator.convert` 메서드에서 변환을 수행해요.

[tuple]: https://crystal-lang.org/reference/syntax_and_semantics/literals/tuple.html
