# 테스트

## Clojure CLI

Exercism의 Clojure 연습 문제에는 [cognitect-labs test-runner](https://github.com/cognitect-labs/test-runner)를 실행하기 위한 `:test` 별칭이 담긴 `deps.edn` 파일이 함께 제공돼요:

``` bash
$ clj -X:test
```

이 명령은 프로젝트의 `test` 디렉터리에서 `clojure.test`로 정의된 테스트를 모두 찾아 실행해요.

## Leiningen

Leiningen으로 연습 문제의 테스트를 실행하려면 다음 명령을 실행하면 돼요:

``` bash
$ lein test

lein test bob-test

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
```
