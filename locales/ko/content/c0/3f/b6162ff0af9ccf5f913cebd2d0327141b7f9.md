# 지침

이 연습 문제에서는 좋아하는 요리책을 보고 근사한 라자냐를 만드는 데 도움이 될 코드를 작성해요.

라자냐를 만드는 데 걸리는 시간과 관련된 네 가지 과제가 있어요.

## 1. 오븐에 넣어 둘 예상 시간을 분 단위로 정의해요

`expected_minutes_in_oven` 바인딩을 정의해서 라자냐를 오븐에 몇 분 동안 넣어 둬야 하는지 확인해 봐요. 요리책에 따르면 오븐에 넣어 둘 예상 시간은 40분이에요:

```rust
expected_minutes_in_oven()
// Returns: 40
```

## 2. 오븐에 남은 시간을 분 단위로 계산해요

`remaining_minutes_in_oven` 함수를 정의해요. 이 함수는 라자냐가 오븐에 들어가 있던 실제 시간(분)을 매개변수로 받아서, 앞 과제에서 구한 오븐 예상 시간(분)을 기준으로 라자냐가 오븐에 몇 분 더 있어야 하는지 반환해요.

```rust
remaining_minutes_in_oven(30)
// Returns: 10
```

## 3. 준비 시간을 분 단위로 계산해요

`preparation_time_in_minutes` 함수를 정의해요. 이 함수는 라자냐에 추가한 층의 개수를 매개변수로 받아서, 각 층을 준비하는 데 2분씩 걸린다고 가정했을 때 라자냐를 준비하는 데 몇 분을 썼는지 반환해요.

```rust
preparation_time_in_minutes(2)
// Returns: 4
```

## 4. 경과 시간을 분 단위로 계산해요

`elapsed_time_in_minutes` 함수를 정의해요. 이 함수는 두 개의 매개변수를 받아요. 첫 번째 매개변수는 라자냐에 추가한 층의 개수이고, 두 번째 매개변수는 라자냐가 오븐에 들어가 있던 시간(분)이에요. 이 함수는 라자냐 요리에 쓴 시간, 즉 준비 시간(분)과 그 시점까지 라자냐가 오븐에 있던 시간(분)을 더한 값을 반환해야 해요.

```rust
elapsed_time_in_minutes(3, 20)
// Returns: 26
```
