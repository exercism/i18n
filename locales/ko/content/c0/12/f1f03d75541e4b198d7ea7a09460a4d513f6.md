# 자세히 알아보기

[`dlists`][dlists]에 있는 `<dlist>`는 새로운 이중 연결 리스트를 만들어요. 연산들은 [`deques`][deques]에 있고 [덱 프로토콜][deque-protocol]에 따라 디스패치돼요. 그래서 다른 컨테이너, 주로 `<dlist>`도 이 연산들을 구현할 수 있어요.

| 워드            | 동작                              |
|-----------------|-------------------------------------|
| `<dlist>`       | `( -- dlist )`, 새로 만든 빈 덱  |
| `push-front`    | `( elt deque -- )`, 맨 앞에 추가해요 |
| `push-back`     | `( elt deque -- )`, 맨 뒤에 추가해요  |
| `pop-front`     | `( deque -- elt )`, 맨 앞에서 제거해요 |
| `pop-back`      | `( deque -- elt )`, 맨 뒤에서 제거해요  |
| `peek-front`    | `( deque -- elt )`, 맨 앞을 제거하지 않고 읽어요 |
| `peek-back`     | `( deque -- elt )`, 맨 뒤를 제거하지 않고 읽어요  |
| `deque-empty?`  | `( deque -- ? )`, 덱이 비어 있는지 확인해요 |
| `dlist-length`  | `( dlist -- n )`, 원소 개수 |

모든 push/pop 연산은 덱을 제자리에서 변경해요. 덱을 루틴에 넘긴 뒤 다시 읽는 것이 일반적인 패턴이에요.

## 스택과 큐

일반적인 디스패치 패턴은 두 가지예요:

```
LIFO (stack): push-back + pop-back   (or push-front + pop-front)
FIFO (queue): push-back + pop-front  (or push-front + pop-back)
```

LIFO 순서만 있으면 될 때는 `mutation`에 있는 `push`와 `pop`을 가진 벡터가 알맞은 선택이에요. `<dlist>`는 연결 리스트의 오버헤드를 안고 있으니까요. 양쪽 끝에서 O(1)이 필요할 때, 즉 거의 항상 FIFO 큐를 만들 때 `<dlist>`를 선택해요.

## BFS 패턴

너비 우선 탐색은 FIFO의 대표적인 쓰임새예요:

```factor
:: reachable ( start graph -- visited )
    HS{ } clone :> visited
    <dlist>    :> frontier
    start visited adjoin
    start frontier push-back
    [ frontier deque-empty? ] [
        frontier pop-front graph at [
            dup visited in? [ drop ] [
                [ visited adjoin ] [ frontier push-back ] bi
            ] if
        ] each
    ] until
    visited ;
```

덱은 탐색의 경계를 나르고, 해시 셋은 중복 제거를 맡아요. `pop-front`를 `pop-back`으로 바꾸면 같은 형태가 깊이 우선 탐색이 돼요.

## `MEMO:`를 이용한 자동 캐싱

때로는 BFS가 노드마다 호출하는 조회가 비쌀 수 있어요. Factor는 `:`를 대신하면서 입력을 키로 삼아 워드의 결과를 자동으로 캐시하는 [`MEMO:`][memo-decl]를 제공해요:

```factor
USING: memoize ;

MEMO: expensive-neighbours ( node -- nodes )
    ! ... slow computation ...
    ;
```

`MEMO:` 워드는 각 입력을 처음 만날 때 본문을 실행하고, 그 뒤부터는 캐시된 결과를 반환해요. 캐시는 이미지가 살아 있는 동안 계속 남아 있어요. 시간이나 크기를 기준으로 한 제거는 없어요. 입력이 유한하고 다룰 만한 집합에서 오는 순수 함수에 쓰면 좋아요.
