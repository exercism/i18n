# 소개

Cairo는 코어 라이브러리의 일부로, `Felt252Dict<T>` 타입으로 표현되는 딕셔너리를 제공해요.

Cairo에서 딕셔너리의 키 타입은 `felt252`로 제한돼요. 키의 타입을 직접 정의할 수 있는 다른 언어들과는 다른 부분이에요.

딕셔너리를 만들려면 `Default` 트레이트의 `default` 메서드를 사용하면 돼요. 이렇게요:

```rust
let mut foo: Felt252Dict<u32> = Default::default();
```

가장 자주 사용하는 기본 연산은 다음과 같아요:

1. `insert(felt252, T) -> ()` 는 딕셔너리 인스턴스에 값을 쓸 때,
2. `get(felt252) -> T` 는 딕셔너리에서 값을 읽을 때 사용해요.

이 연산들은 이렇게 사용해요:

```rust
let mut foo: Felt252Dict<u32> = Default::default();
// Add a value to the dictionariy
foo.insert('bar', 42);
// Here we update the element of 'bar'
foo.insert('bar', 73);
// To retrieve a dictionary value, you can use
baz = foo.get('bar');
```

딕셔너리에 존재하지 않는 키의 값을 가져오려고 하면, 값 타입의 0 값을 반환해요.

이 때문에 헷갈릴 수 있어요. 특히 값 타입의 기본값(예를 들어 정수라면 0)이 유효한 값일 때는 더 그렇죠.

또한 딕셔너리에서 데이터를 삭제할 방법이 없다는 뜻이기도 해요.

코드에 이 구조를 도입할 때 염두에 둘 점이에요.
