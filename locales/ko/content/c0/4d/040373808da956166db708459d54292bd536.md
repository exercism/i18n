# 소개

`if`문 외에도 조건에 따라 로직을 실행하는 `switch`문이 있어요. 변수 하나를 여러 값과 비교해야 할 때 사용해요. 어떤 변수 x에 대해, Haxe의 `switch`문은 다음과 같은 문법을 사용해요.

```haxe
var a = 2;

switch (a) {
  case 0:
    trace("a is 0");
  case 1:
    trace("a is 1");
  case 2:
    trace("a is 2");
  default:
    trace("a is something else");
}

// a is 2
```

`default` 케이스는 다른 케이스가 하나도 일치하지 않을 때 실행돼요.
