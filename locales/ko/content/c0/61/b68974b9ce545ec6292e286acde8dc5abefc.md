# 소개

struct이나 class의 모든 인스턴스에는 그 인스턴스 자체를 가리키는 `self`라는 암시적인 프로퍼티가 있어요.
`self`는 같은 이름을 가진 인스턴스 프로퍼티와 매개변수를 구분할 때 가장 흔히 사용해요.

```swift
struct Position {
    var x = 0

    mutating func move(x: Int) {
        // Here, 'self.x' refers to the struct's property,
        // while 'x' refers to the parameter passed to the method.
        self.x = x
    }
}
```

Swift 타입에는 대문자로 시작하는 `Self` 키워드도 있어요.
이 키워드는 인스턴스 자체가 아니라 인스턴스의 *타입*을 가리켜요.
