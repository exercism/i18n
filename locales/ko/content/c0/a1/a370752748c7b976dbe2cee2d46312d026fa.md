# 소개

Ceylon은 Java와 C#을 닮은 문법을 가진 범용 프로그래밍 언어예요. 명령형이고, 정적 타입이며, 블록 구조를 갖추고 있고, 객체 지향적이며, 고차 언어예요. 여기서 _정적 타입_이라 함은 코드에 나타나는 타입 애너테이션의 도움을 받아 컴파일러가 광범위한 타입 검사를 수행한다는 뜻이에요. _객체 지향_이라 함은 언어가 사용자 정의 타입을 지원하고, 타입이 이름 붙은 속성과 연산의 집합인 명목적 타입 시스템을 갖추고 있으며, 상속과 서브타입 다형성을 지원한다는 뜻이에요. _고차_라 함은 참조할 수 있는 모든 프로그램 요소, 즉 모든 속성과 모든 연산, 모든 타입이 값이기도 하다는 뜻이에요. _블록 구조_라 함은 언어가 어휘적 스코프와, 선언과 문을 위한 지극히 규칙적인 재귀 문법을 갖추고 있다는 뜻이에요.

Ceylon은 Java 언어와 그 타입 시스템을 개선해서, Java와 C#에 비해 장황함은 줄이고 타입 안전성은 높였어요. Ceylon은 좀 더 함수형에 가깝고 명령형에서는 조금 벗어난 프로그래밍 스타일을 권장하는데, 덕분에 코드를 파악하기도 쉽고 리팩터링하기도 쉬워져요.
