# 소개

파일은 디스크 위에 이름이 붙은 스트림일 뿐이에요. [`io.files`][io.files] 보캐블러리를 쓰면 파일을 다루는 두 가지 방법이 있어요. 한 번의 호출로 파일 전체를 읽거나 쓰는 편리한 워드와, 조금씩 읽고 쓰고 싶을 때 쓰는 스트림 열기예요.

파일을 다루는 모든 워드는 **인코딩**을 받아요. 인코딩은 바이트를 문자로, 다시 문자를 바이트로 바꿔 주는 방식이에요. 텍스트라면 거의 항상 `io.encodings.utf8`의 [`utf8`][utf8]을 써요.

## 파일 전체 읽기

```
file-contents   ( path encoding -- str )
file-lines      ( path encoding -- seq )
```

`file-contents`는 파일 전체를 하나의 문자열로 반환하고, `file-lines`는 줄바꿈을 떼어 낸 각 줄을 배열로 반환해요.

```factor
USING: io.encodings.utf8 io.files prettyprint ;

"sunny\ncloudy\n" "forecast.txt" utf8 set-file-contents

"forecast.txt" utf8 file-contents .
! => "sunny\ncloudy\n"

"forecast.txt" utf8 file-lines .
! => { "sunny" "cloudy" }
```

## 파일 전체 쓰기

```
set-file-contents   ( str path encoding -- )
set-file-lines      ( seq path encoding -- )
```

둘 다 파일의 내용을 **덮어써요**(필요하면 파일을 만들어요). `set-file-contents`는 문자열을 그대로 쓰고, `set-file-lines`는 시퀀스의 각 원소를 각각의 줄에 쓰면서 줄바꿈도 알아서 넣어줘요.

```factor
USING: io.encodings.utf8 io.files prettyprint ;

{ "sunny" "cloudy" } "forecast.txt" utf8 set-file-lines
"forecast.txt" utf8 file-contents .
! => "sunny\ncloudy\n"
```

## 파일에 덧붙이기

이미 있는 내용을 지우지 않고 파일에 덧붙이려면, `with-…` 컴비네이터로 파일을 열고 쿼터션 안에서 현재 스트림에 써요.

```
with-file-appender   ( path encoding quot -- )
with-file-reader     ( path encoding quot -- )
with-file-writer     ( path encoding quot -- )
```

```factor
USING: io io.encodings.utf8 io.files prettyprint ;

"sunny\ncloudy\n" "forecast.txt" utf8 set-file-contents
"forecast.txt" utf8 [ "rainy" print ] with-file-appender
"forecast.txt" utf8 file-contents .
! => "sunny\ncloudy\nrainy\n"
```

모든 `with-…` 컴비네이터가 그렇듯 이것들도 소멸자 스코프예요. 쿼터션이 끝나면 파일 핸들이 닫히고, 도중에 예외가 발생해도 마찬가지예요.
