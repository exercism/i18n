# 지시 사항

암호 바퀴는 원판 두 개를 하나 안에 겹쳐 놓은 것으로, 알파벳을 둥글게 돌려 줘요. 3으로 맞추면 모든 글자가 세 칸 뒤의 글자가 되고, `z`는 다시 `a`로 돌아와요. 탐정들은 수백 년 동안 이걸 써 왔어요. 이제 직접 하나 만들어 볼 거예요.

다섯 개의 과제는 모두 `CIPHER_WHEEL` 클래스 안에 작성해요.

## 1. 글자인가요?

```sather
CIPHER_WHEEL::is_letter('m')
-- => true
CIPHER_WHEEL::is_letter('7')
-- => false
```

## 2. 소리치기

문자의 대문자를 반환해요. 글자가 아닌 것은 그대로 반환해요.

```sather
CIPHER_WHEEL::shout('m')
-- => 'M'
```

## 3. 무슨 숫자일까요?

문자를 나타내는 숫자를 반환해요.

```sather
CIPHER_WHEEL::code('a')
-- => 97
```

## 4. 첫 번째 문자

문자열의 첫 번째 문자를 반환해요.

```sather
CIPHER_WHEEL::first_character("Marlowe")
-- => 'M'
```

## 5. 바퀴를 돌려요

소문자와 칸 수를 받아서, 알파벳에서 그만큼 떨어진 글자를 반환해요. `z`를 넘어가면 다시 `a`로 돌아와요.

```sather
CIPHER_WHEEL::turn('a', 3)
-- => 'd'
CIPHER_WHEEL::turn('z', 1)
-- => 'a'
```

칸 수에 음수를 쓰면 거꾸로 돌리는 것도 돼요.

```sather
CIPHER_WHEEL::turn('a', -1)
-- => 'z'
```

넘겨받는 문자는 소문자라고 가정해도 돼요.
