# 소개

`MACRO:` 선언은 `:`처럼 동작하지만, 본문이 *컴파일 타임*에 실행되고 quotation을 반환해야 해요. 컴파일러는 매크로 호출 자리에 반환된 quotation을 대신 넣어요. 본문이 평범한 Factor 코드이기 때문에, 결과 quotation을 만드는 일은 곧 단어들의 나열을 다루는 것뿐이에요.

```factor
USING: kernel macros sequences ;

MACRO: twice ( quot -- compound )
    dup append ;

: shout-twice ( name -- ) [ " ahoy!" append print ] twice ;
! At compile time, the call site is replaced with
! [ " ahoy!" append print " ahoy!" append print ].
```

매크로의 입력은 *호출 지점의 리터럴*이에요. 리터럴이 아닌 값을 넘기면 컴파일러는 특수화를 거부해요. 매크로 본문은 런타임이 아니라 컴파일 타임에 그 값을 필요로 하기 때문이죠.

가까운 친척으로는 `<< … >>` 파싱 타임 평가 블록이 있어요. 이 블록은 quotation 반환 규칙 없이 컴파일 타임에 임의의 Factor 코드를 실행해요. 둘 다 Factor의 [`macros`][macros] 체계에 속해요.

[macros]: https://docs.factorcode.org/content/vocab-macros.html
