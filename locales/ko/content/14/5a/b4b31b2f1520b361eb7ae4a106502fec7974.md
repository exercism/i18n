# 소개

Haxe에서 `class`는 데이터(필드)와 동작(메서드)을 캡슐화하는 주요 데이터 구조예요. 필드와 메서드는 클래스의 멤버라고도 불러요.

멤버에 대한 접근은 접근 제한자를 사용해 제한할 수 있어요. 접근 제한자는 다음과 같아요:

- `public`: 멤버는 어디에서나 접근할 수 있어요.
- `private`: 멤버는 같은 클래스에서만 접근할 수 있어요.

클래스는 인스턴스를 만들기 위한 템플릿이라고 생각할 수 있어요. 인스턴스를 만들려면 간단히 `new` 키워드를 사용하면 돼요:

```haxe
class Car {
  public function new() {}
}

var myCar = new Car();
var yourCar = new Car();
```

필드를 정의하려면 접근 제한자 뒤에 변수 이름과 타입을 적어요:

```haxe
class Car {
  public var weight:Int; // Accessable by anyone

  private var color:String; // Accessable only within this class
}
```

필드를 정의할 때 초기값을 설정할 수도 있어요. 필드에 초기값을 지정하지 않으면 `null` 값을 가지게 돼요. 점 표기법을 사용해 필드에 접근할 수 있어요:

```haxe
class Car {
  public var weight:Int = 2500; // Weight will be set to 2500
  public var year:Int; // year will be null

  public function new() {}
}

var newCar = new Car();
newCar.weight; // 2500
newCar.year; // null

// Update value of field
newCar.year = 2020;
```
