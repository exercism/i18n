# 힌트

## 일반

- [Python 딕셔너리 튜토리얼][dict-tutorial]부터 시작하면 좋아요.
- [매핑 타입 - 딕셔너리][dict docs]에 관한 Python 문서도 꽤 도움이 돼요.

## 1. 배열을 기반으로 인벤토리 만들기

- 항목 배열을 순회하려면 [`for`문][for-loop]이 필요하고, 그다음 각 항목이 딕셔너리에 없으면 넣고, 딕셔너리 접근자로 항목 개수를 늘려요.
- 항목 개수를 늘리기 전에 값이 설정되어 있는지 확인하려면 [`dict.setdefault`][dict setdefault]를 사용하면 돼요.
- 이 함수는 딕셔너리를 [반환][return-keyword]해야 해요.

## 2. 배열의 항목을 기존 딕셔너리에 추가하기

- 항목 배열을 순회하려면 [`for`문][for-loop]이 필요하고, 그다음 각 항목이 딕셔너리에 아직 없으면 넣고, 딕셔너리 접근자로 항목 개수를 [늘려요][increment].
- 항목 개수를 늘리기 전에 값이 설정되어 있는지 확인하려면 [`dict.setdefault`][dict setdefault]를 사용하면 돼요.
- `create_inventory` 함수는 빈 딕셔너리를 매개변수로 넘겨서 `add_items` 함수를 사용할 수 있어요.
- 이 함수는 딕셔너리를 [반환][return-keyword]해야 해요.

## 3. 인벤토리에서 항목 줄이기

- 항목 배열을 순회하려면 [`for`문][for-loop]이 필요하고, 항목 개수가 `0`이 아니면 현재 항목 개수를 [줄여요][decrement].
- 키가 존재하면 `True`를 반환하는 `key in dict` 검사를 사용해서, 항목 개수를 줄이기 전에 값이 딕셔너리에 있는지 확인할 수 있어요.
- 이 함수는 딕셔너리를 [반환][return-keyword]해야 해요.

## 4. 인벤토리에서 항목 완전히 제거하기

- 항목이 딕셔너리에 있으면 [제거해요][dict-pop].
- 항목이 딕셔너리에 없으면 아무것도 하지 않아요.
- 이 함수는 딕셔너리를 [반환][return-keyword]해야 해요.

## 5. 인벤토리 내용 반환하기

- 인벤토리에서 [`for`문][for-loop]을 사용해야 하고, 항목 개수가 `0`보다 크면 `tuple`을 `list`에 추가해요.
- 항목과 값을 동시에 순회하려면 [`dict.items()`][dict items]를 사용하면 돼요. `items()`는 필요하면 그대로 사용하거나 분해할 수 있는 `tuple`을 반환해요.
- 이 함수는 [tuple][tuples]의 [list][list]를 [반환][return-keyword]해야 해요.
