# 설치

이 트랙은 ReScript 12를 사용하며 [Node.js][nodejs] 22 이상이 필요해요.
많은 시스템에는 이게 이미 설치되어 있거나, 다른 트랙에서 미리 설치해 두었을 수도 있어요.

터미널을 열고 다음을 실행해요:

```sh
node -v
```

Node가 설치되어 있지 않거나 더 오래된 버전이 표시된다면, 사용 중인 플랫폼에 맞는 [공식 Node.js 설치][nodejs-install] 안내를 따라 주세요.

## 의존성 설치

각 ReScript 연습 문제는 독립적인 npm 프로젝트예요.
[Exercism CLI][exercism-cli]로 연습 문제를 내려받은 뒤, ReScript를 포함한 프로젝트 의존성을 설치하면 바로 시작할 수 있어요:

```sh
cd /path/to/exercise
npm install
```

## 에디터 지원
