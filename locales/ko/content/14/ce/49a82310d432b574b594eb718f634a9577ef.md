# 연료 지원

## 문제 설명

ABC Corp의 모든 직원은 연료를 무제한으로 지원받아요. 직원들은 차량에 주유할 때마다 기록을 제출해야 해요. 이 기록들은 같은 CSV 파일에 추가되고, 월말에 한꺼번에 처리돼요.

디지털 운영 팀의 일원으로서 해야 할 일은 이 CSV 파일을 읽고 결과를 다른 CSV 파일에 작성하는 거예요. 출력 파일에는 다음 정보를 담은 항목이 직원마다 하나씩 들어가야 해요:

- 직원 번호
- 주유 횟수
- 총 연료비
- 총 갤런
- 누적 총 주행 마일

`string` 인자 두 개가 주어져요.

1. 입력 CSV 파일 경로
1. 출력 CSV 파일 경로

입력 CSV 파일에는 `n`개의 줄이 있고, 각 줄은 다음과 같은 형식이에요.

| 열 이름      | Ballerina 타입 |
| ----------- | ----------- |
| employee_id      | `int`       |
| odometer_reading   | `int`       |
| gallons   | `decimal` |
| gas_price(USD)  |`decimal`|

출력 파일에는 직원마다 항목이 하나씩 있어야 하고, `employee_id`를 기준으로 오름차순으로 정렬돼요. 각 줄은 다음과 같은 형식이에요:

| 열 이름      | Ballerina 타입 |
| ----------- | ----------- |
| employee_id      | `int`       |
| gas_fill_up_count   | `int`        |
| total_fuel_cost(USD)   | `decimal` |
| total_gallons  |`decimal`|
| total_miles_accrued  |`int`|

## 제약 사항

- 입력 CSV 파일의 줄 수 `n`: 2 <= n <= 1000
- 회사의 직원 수: 97
- 주유 가격은 갤런당 가격이에요
- 누락된 주유 기록은 없어요

## 예제 1

- 입력: `example01_input.csv`

```csv
2312,230,18.561,4.56
2312,500,19.345,4.89
```

- 출력: `example01_output.csv`

```csv
2312,2,179.23521,37.906,270
```
