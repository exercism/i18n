# 소개

## 배열

배열은 Elixir 언어에 내장되어 있어요. 기본 타입으로 취급되며, 대괄호로 나타내요. 배열은 비어 있을 수도 있고, 어떤 타입의 항목이든 원하는 개수만큼 담을 수도 있어요. 예를 들어:

```elixir
empty_list = []
one_item_list = [1]
two_item_list = [1, 2]
multiple_type_list = [1, :pi, 3.14, "four"]
```

Elixir는 배열을 연결 리스트로 구현하는데, 각 노드는 두 개의 값을 저장해요. 첫 번째 항목과, 나머지 항목을 모두 담은 또 다른 배열이에요. 배열의 첫 번째 항목을 _헤드_라고 하고, 나머지 항목으로 이루어진 배열을 _테일_이라고 해요. 이 표기는 코드에서 이렇게 쓸 수 있어요:

```elixir
# [1] represented in [head | tail] notation
[1 | []]

# [1, 2, 3] represented in [head | tail] notation
[1 | [2 | [3 | []]]]
```

_`[head | tail]`_ 표기를 사용하면 배열의 앞에 원소를 추가할 수 있어요:

```elixir
# Suppose
list = [2, 1]

[3, 2, 1] == [3 | list]
# => true
```

`Kernel` 모듈에는 배열을 다루는 함수가 여러 개 있고, `List` 모듈 전체에도 그런 함수가 있어요.

```elixir
# Check if 1 is a member of the list
1 in [1, 2, 3, 4]
# => true
```
