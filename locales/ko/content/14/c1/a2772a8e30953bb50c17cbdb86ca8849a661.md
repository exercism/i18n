# 안내

Izzy는 정원에 하루에 몇 마리의 새가 찾아왔는지 기록하는 열렬한 탐조가예요.

새 관찰을 한 단계 더 끌어올리고, 데이터를 추적하고 처리하는 데 도움이 될 도구 몇 가지를 만들어 달라고 부탁했어요.

데이터는 정수 배열로 저장하기로 했어요. 배열의 첫 번째 숫자는 오늘 정원에 찾아온 새의 수이고, 두 번째는 어제, 그다음은 그 전날의 수예요. 이런 식으로 이어져요.

## 1. 오늘 새가 몇 마리 찾아왔는지 확인해요

`today` 함수를 구현해요. 이 함수는 날짜별 새 개체 수를 담은 배열을 받아서 오늘의 수를 반환해요. 배열이 비어 있으면 `0`을 반환해요.

```gleam
today([2, 5, 1])
// -> 2
```

## 2. 오늘의 수를 1 늘려요

`increment_day_count` 함수를 구현해요. 이 함수는 날짜별 새 개체 수를 담은 배열을 받아서 오늘의 수를 1만큼 늘려요. 배열이 비어 있으면 `[1]`을 반환해요.

```gleam
increment_day_count([4, 0, 2])
// -> [5, 0, 2]
```

## 3. 새가 찾아오지 않은 날이 있었는지 확인해요

`has_day_without_birds` 함수를 구현해요. 이 함수는 날짜별 새 개체 수를 담은 배열을 받아요. 새가 정원에 찾아오지 않은 날이 하나라도 있으면 `True`를, 그렇지 않으면 `False`를 반환해요. 배열이 비어 있으면, 이는 _아직_ 새가 기록되지 않은 것으로 봐요. 이때는 `False`를 반환해요.

```gleam
has_day_without_birds([2, 0, 4])
// -> True

has_day_without_birds([3, 8, 1, 5])
// -> False
```

## 4. 정원에 찾아온 새의 총 개체 수를 계산해요

`total` 함수를 구현해요. 이 함수는 날짜별 새 개체 수를 담은 배열을 받아서, 데이터를 모으기 시작한 이후 정원에 찾아온 새의 총 개체 수를 반환해요.

```gleam
total([4, 0, 9, 0, 5])
// -> 18
```

## 5. 바쁜 날의 수를 계산해요

어떤 날은 다른 날보다 더 바빠요. 바쁜 날이란 정원에 새가 다섯 마리 이상 찾아온 날을 말해요.

`busy_days` 함수를 구현해요. 이 함수는 날짜별 새 개체 수를 담은 배열을 받아서 바쁜 날의 수를 반환해요.

```gleam
busy_days([4, 5, 0, 0, 6])
// -> 2
```
