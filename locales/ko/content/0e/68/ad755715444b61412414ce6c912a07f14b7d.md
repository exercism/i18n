# 소개

삼항 연산자를 사용하면 if 조건을 문 블록이 아니라 표현식 안에서 정의할 수 있어요. 이 방식은 함수형 프로그래밍 접근법과 닮아 있고, 흔히 코드를 더 표현력 있게 만들고 오류가 덜 발생하도록 도와줘요.

삼항 연산자는 세 개의 표현식을 결합해요: 조건 하나, 조건이 참일 때 평가되어 반환되는 표현식(`?`로 시작하는 `if` 부분), 그리고 조건이 거짓일 때 평가되어 반환되는 표현식(`:`로 시작하는 `else` 부분)이에요.

```csharp
int a = 3, b = 4;
int max = a > b ? a : b;
// => 4
```
