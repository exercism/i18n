# 소개

C#의 속성은 클래스 내부의 데이터에 접근할 수 있게 해 주는 클래스의 멤버예요. 호출하는 쪽에서는 이 데이터를 설정하거나 가져올(get) 수 있어요. 속성은 자동 구현 속성일 수도 있고, 백킹 필드를 가질 수도 있어요. 속성은 set 접근자와 get 접근자로 이루어져 있어요. 다른 언어에서는 "뮤테이터"가 set 접근자와 거의 같은 역할을 하고, "접근자"가 get 접근자와 거의 같은 역할을 하는데, 문법의 구성은 완전히 달라요.

속성을 설정할 때는 입력값의 유효성을 검사하거나, 형식을 바꾸거나, 그 밖의 다른 방식으로 가공할 수 있어요. 실제로 클래스의 코드에서 할 수 있는 프로그래밍적 작업이라면 무엇이든 실행할 수 있죠.

마찬가지로 속성을 가져올 때도 데이터를 계산하거나 형식을 바꿀 수 있고, 역시 클래스에서 사용할 수 있는 프로그래밍적 작업이라면 무엇이든 실행할 수 있어요.

속성은 다른 클래스 멤버와 마찬가지로 액세스 한정자(`public`, `private` 등)를 가져요. 다만 set 접근자는 get 접근자와는 별개의 액세스 수준을 가질 수 있고, 그 반대도 마찬가지예요. 속성에 두 접근자가 모두 있어야 하는 것은 아니고, 하나만(get 또는 set) 가질 수도 있어요.

속성을 표현하는 기본 문법은 두 가지 형태가 있어요.

## 필드/식 기반 속성:

```csharp
private int myField;
public int MyProperty
{
    get { return myField; }
    set { myField = value; }
}
```

## 자동 구현 속성

```
public int MyProperty { get; private set; } = 42;
```

초기화는 선택 사항이에요.
