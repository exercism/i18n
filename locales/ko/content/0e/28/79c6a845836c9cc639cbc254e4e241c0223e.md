# 소개

네임스페이스는 관련 있는 코드를 묶고 이름 충돌을 피하는 방법이며, 아주 사소한 코드베이스를 빼고는 거의 모든 코드에 등장해요.

문법은 다음과 같아요:

```csharp
namespace MyNameSpace
{
    public class MyClass {}

    public class OtherClass {}
}
```

네임스페이스에 포함된 타입을 네임스페이스 범위 밖에서 참조할 때는 타입 이름 앞에 점 문법을 붙여요. 또는 더 흔하게는, 파일 맨 위에(또는 네임스페이스 안에) `using` 지시문을 두면 접두사 없이 타입을 사용할 수 있어요. 같은 네임스페이스 안에서는 타입 이름을 한정할 필요가 없어요.

```csharp
namespace MySpace
{
    public class MyClass {}

    public class Foo
    {
        public void Bar()
        {
            var baz = new MyClass();
        }
    }
}

public class Qux
{
    public void Box()
    {
        var nux = new MySpace.MyClass();
    }
}

namespace OtherSpace
{
    using MySpace;

    public class Tix
    {
        public void Jeg()
        {
            var lor = new MyClass();
        }
    }
}
```

`using MyAlias = MySpace;` 문법으로 네임스페이스에 별칭을 붙일 수 있고, 그러면 네임스페이스를 쓸 수 있는 곳 어디든 그 별칭을 사용할 수 있어요.
