# 소개

`str` 클래스는 문자열을 다루고 조합하는 데 쓸 수 있는 [다양한 유용한 메서드][str methods]를 제공해요.
여기에는 검색, 정리, 분할, 변환, 번역을 비롯한 여러 가지 기법이 포함돼요.

문자열은 [유니코드 코드 포인트][unicode code points]의 [시퀀스][text sequence]예요. 개별 "문자", 즉 코드 포인트(_길이가 1인 문자열_)는 왼쪽에서부터 `0-based index` 번호로, 또는 오른쪽에서부터 `-1-based index` 번호로 참조할 수 있어요.
문자열은 [공통 시퀀스 연산][common sequence operations]을 모두 지원해요.

`for item in <str>` 또는 `for index, item in enumerate(<str>)` 구문으로 반복할 수 있어요.
`<str> + <other str>` 또는 `<str>.join(<iterable>)`로 이어 붙일 수도 있어요.

문자열은 _불변_이라서, 메모리에 있는 `str` 객체의 값은 바뀔 수 없어요.
`str`에 작용하는 함수나 메서드(_지금 배우고 있는 것들처럼_)는 원래 `str`을 수정하는 대신 그 `str` 객체의 새로운 `instance`를 반환해요.

다음은 Python 문자열 메서드 중 일부예요.
전체 목록은 Python 문서의 [str 클래스][str methods]를 참고해요.


[`<str>.title()`][str-title]는 문자열을 분석해서 찾은 각 "단어"의 첫 "문자"를 대문자로 만들어요.
Python에서는 이것이 사용된 [언어 코덱][codecs]에 따라, 그리고 해당 언어가 단어와 문자를 표현하는 방식에 따라 크게 달라져요.
언어나 문자 집합에 따라 [로케일][locale] 규칙이 적용될 수도 있어요.


```python
man_in_hat_th = 'ผู้ชายใส่หมวก'
man_in_hat_ru = 'мужчина в шляпе'
man_in_hat_ko = '모자를 쓴 남자'
man_in_hat_en = 'the man in the hat.'

>>> man_in_hat_th.title()
'ผู้ชายใส่หมวก'

>>> man_in_hat_ru.title()
'Мужчина В Шляпе'

>>> man_in_hat_ko.title()
'모자를 쓴 남자'

>> man_in_hat_en.title()
'The Man In The Hat.'
```

[`<str>.endswith(<suffix>)`][str-endswith]는 문자열이 `<suffix>`로 끝나면 `True`를, 그렇지 않으면 `False`를 반환해요.


```python
>>> 'My heart breaks. 💔'.endswith('💔')
True

>>> 'cheerfulness'.endswith('ness')
True

# Punctuation is part of the string, so needs to be included in any endswith match.
>>> 'Do you want to 💃?'.endswith('💃')
False

>> 'The quick brown fox jumped over the lazy dog.'.endswith('dog')
False
```

[`<str>.strip(<chars>)`][str-strip]는 `str`의 앞뒤에 있는 `<chars>`를 제거한 복사본을 반환해요.
`<chars>`에 지정된 코드 포인트는 접두사나 접미사가 아니에요. 코드 포인트의 **모든 조합**이 문자열의 **양쪽 끝**에서부터 제거돼요.
 `<chars>`에 아무것도 지정하지 않으면, 공백 코드 포인트의 모든 조합이 제거돼요.


 ```python
# This will remove "https://", because it can be formed from "/stph:". 
>>> 'https://unicode.org/emoji/'.strip('/stph:')
'unicode.org/emoji'

# Removal of all whitespace from both ends of the str.
>>> '   🐪🐪🐪🌟🐪🐪🐪   '.strip()
'🐪🐪🐪🌟🐪🐪🐪'

>>> justification = 'оправдание'
>>> justification.strip('еина')
'оправд'

# Prefix and suffix in one step.
>>> 'unaddressed'.strip('dnue')
'address'

>>> '  unaddressed  '.strip('dnue ')
'address'
```


[`<str>.replace(<substring>, <replacement substring>)`][str-replace]는 문자열에서 `<substring>`이 나타나는 모든 부분을 `<replacement substring>`으로 바꾼 복사본을 반환해요.

아래에 쓰인 인용구는 [Lewis Carroll][Lewis Carroll]의 [The Hunting of the Snark][The Hunting of the Snark]에서 가져왔어요.

```python
# The Hunting of the Snark, by Lewis Carroll
>>> quote = '''
"Just the place for a Snark!" the Bellman cried,
   As he landed his crew with care;
Supporting each man on the top of the tide
   By a finger entwined in his hair.

"Just the place for a Snark! I have said it twice:
   That alone should encourage the crew.
Just the place for a Snark! I have said it thrice:
   What I tell you three times is true."
'''

>>> quote.replace('Snark', '🐲')
...
'\n"Just the place for a 🐲!" the Bellman cried,\n   As he landed his crew with care;\nSupporting each man on the top of the tide\n   By a finger entwined in his hair.\n\n"Just the place for a 🐲! I have said it twice:\n   That alone should encourage the crew.\nJust the place for a 🐲! I have said it thrice:\n   What I tell you three times is true."\n'

>>> 'bookkeeper'.replace('kk', 'k k')
'book keeper'
```
