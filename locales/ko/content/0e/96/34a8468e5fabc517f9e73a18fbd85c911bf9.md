# 개요

[`for`문][for-statement]을 사용하면 조건이 충족될 때까지 코드를 반복해서 실행할 수 있어요.

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

`for`문은 네 부분으로 이루어져 있어요:

1. 초기화식: 루프에 들어가기 전에 한 번 실행돼요. 보통 루프 안에서 사용할 변수를 정의할 때 써요.
2. 조건식: 각 루프 반복 전에 실행돼요. 이 값이 `true`로 평가되는 동안 루프가 계속 실행돼요.
3. 증감식: 각 루프 반복 후에 실행돼요. 보통 루프 변수를 수정(흔히 증가/감소)할 때 써요.
4. 본문: 각 루프 반복마다 실행되는 코드예요.

## `for`문과 `foreach`문 비교

일반적으로 `for`문보다 [concept:csharp/foreach-loops]() 쪽이 더 선호돼요. 그 이유는 다음과 같아요:

- `foreach`문은 _모든_ 값을 반복하는 것이 보장돼요. 반면 `for`문은, 예를 들어 off-by-one 오류 때문에 원소를 빠뜨리기 쉬워요.
- `foreach`문은 더 _선언적_이에요. 코드가 _무엇_을 원하는지를 알려주는 반면, `for`문은 _어떻게_ 할지를 알려줘요.
- `foreach`문은 실수할 여지가 없지만, `for`문은 off-by-one 오류를 내기 쉬워요.
- `foreach`문은 모든 컬렉션 타입에서 동작해요. 인덱서로 원소에 접근하는 기능을 지원하지 않는 컬렉션까지 포함해서요.

`foreach`문이 _모든_ 값을 반복하도록 보장하기 위해, 컴파일러는 `foreach`문 안에서 컬렉션을 업데이트하는 것을 허용하지 않아요:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

`for`문은 `foreach`문에 비해 몇 가지 장점도 있어요:

- 원하는 인덱스에서 시작하거나 멈출 수 있어요.
- 원하는 (불리언) 종료 조건을 사용할 수 있어요.
- 루프 변수의 증가 방식을 직접 바꿔서 원소를 건너뛸 수 있어요.
- 카운트다운해서 컬렉션을 뒤에서 앞으로 처리할 수 있어요.
- 컬렉션이 등장하지 않는 상황에서도 `for`문을 사용할 수 있어요.
