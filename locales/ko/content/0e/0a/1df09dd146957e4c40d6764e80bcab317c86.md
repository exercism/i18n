# 소개

*튜플*은 이름이 붙은 여러 값을 하나의 객체로 묶어 줘요. 다른 언어에서 레코드, 구조체, 클래스라고 부르는 것이 바로 이거죠. 각 튜플 클래스에는 이름이 붙은 슬롯 집합이 고정되어 있고, Factor가 그 슬롯들의 게터와 세터를 자동으로 만들어 줘요.

## 튜플 정의하기

```factor
TUPLE: point
    { x initial: 0 }
    { y initial: 0 } ;
```

각 슬롯은 `{ name initial: default-value }` 형태로 선언해요. `initial:` 절이 없으면 기본값은 `f`예요.

## 튜플 만들기

가장 간단한 생성자는 `new`예요:

```factor
point new .
! => T{ point }
```

`boa`("인자의 순서대로"라는 뜻)는 데이터 스택에서 슬롯을 선언 순서대로 채워요:

```factor
3 4 point boa .
! => T{ point { x 3 } { y 4 } }
```

리터럴 구문 `T{ class { slot value } … }`을 쓰면 일부 슬롯만 설정한 튜플을 만들 수 있고, 출력할 때도 같은 모양으로 나와요:

```factor
T{ point { x 3 } } .
! => T{ point { x 3 } }
```

슬롯의 값이 기본값과 같으면 프린터는 그 슬롯을 생략해요.

## 슬롯 읽기

Factor는 각 슬롯마다 게터 `slot>>`를 만들어요. 게터는 [`accessors`][accessors]에 있어요:

```factor
T{ point { x 3 } { y 4 } } x>> .
! => 3
```

## 슬롯 갱신하기

세터는 `>>slot` 형태로 쓰고, 튜플을 제자리에서 *변경*해요:

```factor
T{ point { x 3 } { y 4 } } 10 >>x .
! => T{ point { x 10 } { y 4 } }
```

원본을 그대로 두려면 먼저 `clone`을 해요:

```factor
: shifted ( pt -- pt' )
    clone 10 >>x ;
```

`change-slot`은 현재 값을 새 값으로 매핑하는 인용을 받아요:

```factor
: shift-x ( pt dx -- pt )
    [ + ] curry change-x ;
```

`change-x`도 마찬가지로 값을 변경하므로, 원본을 보존하고 싶다면 호출하기 전에 `clone`을 해요.
