# 소개

`Map`은 **키**와 **값**의 쌍을 저장하는 데 사용해요. `Maps`는 배열과 똑같이 초기화하지만, 맵 리터럴 연산자 `=>`를 사용해요. `Maps`는 키-값 타입을 명시적으로 정의할 수도 있고, 타입을 추론할 수도 있어요. 키는 반드시 고유해야 해요. 그렇지 않으면 오류가 발생해요.

```haxe
var map1:Map<Int, String> = [1 => "one", 2 => "two", 3 => "three"];

var map2 = ["one" => 1, "two" => 2, "three" => 3];

var map3 = [1 => "cat", 1 => "dog"]; // Error: Duplicate Key

var map4 = ["h" => "Hello", "b" => "Bye"];
trace(map4["h"]); // Hello
```

`Map`은 `for`문을 사용해 순회할 수 있어요. 값을 순회할 수도 있고 키를 순회할 수도 있어요:

```haxe
for (value in map) {
  // ...
}

for (key in map.keys()) {
  // ...
}
```
