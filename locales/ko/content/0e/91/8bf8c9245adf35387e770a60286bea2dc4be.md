# 자세히 알아보기

실수는 소수점 뒤에 0개 이상의 자릿수가 있는 수예요. 예를 들면 `4.0`, `0.1`, `3.14`, `-6.4`, `16.984025`, `1024.0` 같은 것들이 있어요. Ruby에서는 실수를 [Float][Float] 클래스로 구현해요.

부동소수점 수에 대한 짧은 소개는 [0.30000000000000004.com][0.30000000000000004.com]에서 볼 수 있어요.

[Float Toy 페이지][evanw.github.io-float-toy]에서는 부동소수점 수의 비트가 실제 부동소수점 값으로 어떻게 변환되는지 그림과 함께 친절하게 설명해요.

같은 로직을 반복해서 실행하려면 루프를 사용할 수 있어요. 이 예시에서는 `while`문이 유용한데, 조건이 참 같은 값(즉, `false`나 `nil`이 아닌 값)으로 평가되는 _동안_ 계속 반복하기 때문이에요. Ruby에도 `while`문과 비슷한 루프가 있어요. 바로 `until`문이라고 불러요. 아마 어떤 역할을 하는지 짐작했을 거예요. 불리언 조건이 `true`로 평가될 _때까지_ 계속 반복해요. 어떤 언어에서는 코드를 무한히 실행시키기 위해 `while true` 같은 구문을 사용해요. Ruby에는 그런 목적을 위한 `loop` 루프가 있어요. `loop` 루프는 단일 조건에 의존하지 않지만, `return`이나 `break` 키워드를 사용해 빠져나올 수 있어요.

이전 연습 문제의 `#years_before_desired_balance` 메서드는 방금 언급한 세 가지 루프 중 어느 것을 사용해서도 작성할 수 있었어요.

## `while`

```ruby
def self.years_before_desired_balance(current_balance, desired_balance)
  years = 0
  while current_balance < desired_balance
    current_balance = annual_balance_update(current_balance)
    years += 1
  end
  years
end
```

## `until`

```ruby
def self.years_before_desired_balance(current_balance, desired_balance)
  years = 0
  until current_balance >= desired_balance
    current_balance = annual_balance_update(current_balance)
    years += 1
  end
  years
end
```

## `loop`

```ruby
def self.years_before_desired_balance(current_balance, desired_balance)
  years = 0
  loop do
    current_balance = annual_balance_update(current_balance)
    years += 1
    return years if current_balance >= desired_balance
  end
end
```

아마 눈치챘겠지만, Ruby에는 다른 언어들에 있는 증가 연산자(`i++`)가 없어요. 대신 `i += 1`(`i = i + 1`과 같아요) 같은 표현을 사용할 수 있어요.
