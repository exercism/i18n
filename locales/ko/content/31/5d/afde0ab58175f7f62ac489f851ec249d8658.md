# 개요

[클래스](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/classes)는 F#에서 객체 지향 프로그래밍을 하기 위한 주된 구성 요소예요.

F#의 클래스는 필드와 메서드로 이루어져 있어요. 클래스의 필드와 메서드를 _멤버_라고 불러요.

F#에서 클래스는 `type` 키워드로 정의해요. 메서드는 `member` 키워드로 정의하며, 항상 공개 상태예요. (비공개) 필드를 정의할 때는 `let` 바인딩을 사용할 수 있어요.

```fsharp
type Shoe() =
    let size = 8

    member this.Describe() = $"This is a size {size} shoe"
```

클래스는 객체를 만들기 위한 틀이에요. 클래스의 인스턴스를 만들려면 클래스 이름을 함수처럼 호출해요. 클래스의 인스턴스를 _객체_라고도 불러요.

객체의 멤버는 점 표기법으로 접근할 수 있어요.

```fsharp
let myShoe = Shoe()
myShoe.Describe()
// => "This is a size 8 shoe"
```
