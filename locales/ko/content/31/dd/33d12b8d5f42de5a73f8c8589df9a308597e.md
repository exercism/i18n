# 소개

## 기본

C++ 여정을 시작하기 위해 변수, 함수 호출, 주석부터 살펴봐요.

### 주석

주석에는 한 줄 주석과 여러 줄 주석, 두 가지가 있어요.
같은 줄에서 `//` 뒤에 오는 모든 내용은 컴파일러가 무시해요.
여러 줄 주석은 C 스타일 주석이라고도 해요.
`/*`와 `*/`로 감싸요.
그 사이에 오는 내용도 마찬가지로 무시돼요.

### 변수

C++는 타입이 있는 언어예요.
모든 타입은 컴파일 시점에 알려져야 하고, 보통은 이를 직접 명시해야 해요.
변수의 타입은 바뀌지 않아요.
`years`라는 이름의 정수 변수는 이렇게 선언할 수 있어요:

```cpp
int years;
```

변수는 선언할 때 초기화하는 게 좋아요.
C++는 이를 위한 여러 가지 방식을 제공해요.
중괄호를 쓰는 방식이 현대적인 C++에 더 잘 맞지만, 등호를 쓰는 방식도 아주 흔해요.

```cpp
int tomatoes{80};
int potatoes = 40;
```

~~~~exercism/caution
C++는 초기화하지 않은 변수를 사용하는 것을 허용해요.
변수에 의도적으로 값을 넣기 전까지는 정의되지 않은 상태이고, 무엇이든 담겨 있을 수 있어요.
초기화 전 사용 오류와 정의되지 않은 동작을 피하려면 **항상 초기화**하는 게 좋아요.
정의되지 않은 동작은 이전까지 잘 실행되던 프로그램을 최악의 순간에 충돌시킬 수 있어요.
아무리 강조해도 부족해요: 정의되지 않은 동작은 무슨 수를 써서든 피해야 해요.
~~~~

### 산술 연산

`*`, `+`, `-` 같은 산술 연산자는 `3 * 2`나 `tomatoes + potatoes`처럼 표현식의 일부가 될 수 있어요.

### 변수 업데이트

변수는 타입이 유지되는 한 다시 할당할 수 있어요:

```cpp
tomatoes = tomatoes - 5; // tomatoes is now 75
potatoes = (32 * 2) + 11; // potatoes is now 75 as well
```

### 함수

함수에는 이름, 반환 타입, 그리고 비어 있을 수도 있는 매개변수 목록이 있어요.
항상 47을 반환하는 `always_fortyseven`이라는 함수는 이렇게 생겼어요:

```cpp
int always_fortyseven() {
    return 47;
}
```

다음은 매개변수가 하나인 `vip_fee`예요:

```cpp
int vip_fee(int standard_fee) {
    /*
    vip_fee calculates the vip fee based on the standard_fee.
    */
    int vip_multi{3};
    return standard_fee * vip_multi;
}
```

매개변수가 세 개이고 다른 함수를 호출하는 `total_fee`도 있어요.

```cpp
int total_fee(int vips, int adults, int kids) {
    /*
    total_fee calculates the total price for a group of VIP and adult guests with kids.
    Kids get a flat discount on the standard fee.
    VIP guest fees are calculated by calling vip_fee.
    */
    int standard_fee{30};
    int kids_discount{15};

    int kids_total_fee = kids * (standard_fee - kids_discount);
    int vips_total_fee = vips * vip_fee(standard_fee);
    int adult_total_fee = adults * standard_fee;

    return vips_total_fee + adult_total_fee + kids_total_fee;
}
```

C++의 함수는 다른 몇몇 언어처럼 마지막 문의 값을 반환하지 않아요.
코드가 컴파일되려면 `return` 키워드가 필요해요.

### 공백

공백은 소스 코드의 서식을 맞추는 데 쓰이며, 스페이스, 탭, 줄 바꿈을 포함해요.
컴파일러는 불필요한 공백을 무시하므로, 공백을 이용해 코드 구조를 잡을 수 있어요.
공백을 잘 활용하면 코드의 가독성을 높일 수 있어요.
다양한 서식 표준이 있지만, 모두 관례일 뿐 컴파일러가 강제하는 것은 아니에요.

```cpp
// Formatting makes it easier to find bugs

int eggs_yolks =  3;
int      yeast = 15;

int flour=500;int sugar=200;// compact, but difficult to read
```
