# 비교 연산자

PHP에는 기본으로 제공되는 비교 연산자가 열 개 있어요:

| 이름  | 예시    | 결과                                             |
| ----- | ---------- | -------------------------------------------------- |
| 같음 | `$a == $b` | 타입 변환 후 `$a`가 `$b`와 같으면 true예요. |
| 일치 | `$a === $b` | `$a`가 `$b`와 같고 타입도 같으면 true예요. |
| 같지 않음 | `$a != $b` | 타입 변환 후 `$a`가 `$b`와 같지 않으면 true예요. |
| 같지 않음 | `$a <> $b` | 타입 변환 후 `$a`가 `$b`와 같지 않으면 true예요. |
| 일치하지 않음 | `$a !== $b` | `$a`가 `$b`와 같지 않거나 타입이 다르면 true예요. |
| 보다 작음 | `$a < $b` | `$a`가 `$b`보다 작으면 true예요. |
| 보다 큼 | `$a > $b` | `$a`가 `$b`보다 크면 true예요. |
| 작거나 같음 | `$a <= $b` | `$a`가 `$b`보다 작거나 같으면 true예요. |
| 크거나 같음 | `$a >= $b` | `$a`가 `$b`보다 크거나 같으면 true예요. |
| 스페이스십 | `$a <=> $b` | `$a`를 `$b`와 비교했을 때 `0`보다 작거나, 같거나, 큰 정수를 반환해요. |

PHP는 `equal`과 `identical`을 구분하는 서로 다른 정의를 가지고 있어요.
`identical`을 `strictly equal`이라고 부르기도 해요.

```php
<?php

// Comparisons between integer and numeric string values
1 == "1"; // => true, equal
1 === "1"; // => false, not identical

// Comparisons between integers and floating point values
1 == 1.0; // => true
1 === 1.0; // => false

// Comparisons between object instances
new stdClass() == new stdClass(); // => true, properties are equal
new stdClass() === new stdClass(); // => false, references are not identical
```
