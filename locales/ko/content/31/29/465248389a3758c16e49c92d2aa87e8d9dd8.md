# print 문 사용 피하기

코드에서 `System.out.println()` 같은 문을 제거해 봐요.
연습 문제의 테스트는 값을 출력하는 대신 메서드에서 값을 _반환_할 것을 요구해요.

보통 이런 문은 코드를 debug하는 데 도움이 되라고 추가하는 경우가 많아요.
하지만 더 좋은 방법은 하나 이상의 단위 테스트를 실행하면서 코드를 debug하는 거예요.
이렇게 하면 특정 테스트 케이스에 집중해서 debug할 수 있다는 장점도 있어요.

여기, 여러 IDE에서 단위 테스트를 실행하면서 Java 코드를 debug하는 방법을 설명하는 링크가 있어요:

- [Visual Studio Code에서 Java 테스트 실행하고 debug하기](https://code.visualstudio.com/docs/java/java-testing#_rundebug-test-cases)
- [IntelliJ IDEA에서 테스트 debug하기](https://www.jetbrains.com/help/idea/performing-tests.html#RedebugFailedTests)
