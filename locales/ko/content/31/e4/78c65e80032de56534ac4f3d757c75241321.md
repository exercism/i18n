# 소개

Go에서는 애플리케이션을 패키지로 구성해요.
패키지는 같은 폴더에 있는 소스 파일의 모음이에요.
한 폴더에 있는 모든 소스 파일은 파일 맨 위에 같은 패키지 이름을 써야 해요.
관례적으로 패키지 이름은 패키지가 위치한 폴더와 같게 지어요.

```go
package greeting
```

Go는 프로그램에서 `import` 키워드로 사용할 수 있는 방대한 표준 라이브러리 패키지를 제공해요.
표준 라이브러리 패키지는 이름으로 임포트해요.

```go
package greeting

import "fmt"
```

임포트한 패키지는 패키지 이름을 붙여 사용해요:

```go
world := "World"
fmt.Sprintf("Hello %s", world)
```

Go는 어떤 항목을 다른 패키지의 코드에서 호출할 수 있는지를 그 항목을 어떻게 선언했는지로 결정해요.
함수, 타입, 변수, 상수, 구조체 필드를 외부에서 볼 수 있게 하려면(이것을 _exported_라고 해요) 이름이 대문자로 시작해야 해요.
이것은 `public`이나 `private` 같은 접근 제한자를 사용하는 Java 같은 다른 프로그래밍 언어와 비슷해요.

```go
package greeting

// Hello is a public function (callable from other packages).
func Hello(name string) string {
    return "Hello " + name
}

// hello is a private function (not callable from other packages).
func hello(name string) string {
    return "Hello " + name
}
```
