# 지시 사항

이 연습 문제에서는 로그 줄을 처리해요.

각 로그 줄은 다음과 같은 형식의 문자열이에요: `"[<LEVEL>]: <MESSAGE>"`.

로그 레벨은 세 가지가 있어요:

- `INFO`
- `WARNING`
- `ERROR`

과제는 세 가지이고, 각 과제는 로그 줄 하나를 받아 그걸로 무언가를 해 보라는 내용이에요.

base R의 레거시 함수를 사용해도 되고 `stringr` 라이브러리를 사용해도 돼요. 둘 다 짧으면서도 쓸 만한 해법을 만들어 줘요.

## 1. 로그 줄에서 메시지 가져오기

로그 줄의 메시지를 반환하도록 `message` 함수를 구현해요:

```R
message("[ERROR]: Invalid operation")
#> "Invalid operation"
```

앞이나 뒤에 있는 공백은 제거해야 해요:

```R
message("[WARNING]:  Disk almost full\r\n")
#> "Disk almost full"
```

## 2. 로그 줄에서 로그 레벨 가져오기

로그 줄의 로그 레벨을 소문자로 반환하도록 `log_level` 함수를 구현해요:

```R
log_level("[ERROR]: Invalid operation")
#> "error"
```

## 3. 로그 줄 형식 바꾸기

메시지를 앞에 두고 그 뒤에 로그 레벨을 괄호 안에 넣도록 로그 줄 형식을 바꾸는 `reformat` 함수를 구현해요:

```R
reformat("[INFO]: Operation completed")
#> "Operation completed (info)"
```
