# 힌트

## 일반

- Elm을 만든 사람이 쓴 [재귀][recursion]에 대한 글을 읽어 보세요.
- `case` 표현식과 함께 패턴 매칭을 사용해요.
- 문제를 기본 사례와 재귀 사례로 나눠 봐요. 예를 들어, 재귀적인 방법으로 쿠키 항아리에 쿠키가 몇 개 들어 있는지 세고 싶다고 해봐요. 기본 사례는 빈 항아리예요. 쿠키가 하나도 없죠. 항아리가 비어 있지 않다면, 항아리 안의 쿠키 개수는 쿠키 하나에 쿠키 하나를 꺼낸 뒤 항아리 안에 남은 쿠키 개수를 더한 것과 같아요.

## 1. 오늘 몇 마리의 새가 찾아왔는지 확인하기

- 이 과제에는 재귀가 필요하지 않아요.
- 배열의 첫 번째 원소에 접근하는 것은 `case` 표현식으로 패턴 매칭을 하면 돼요.
- 값을 반환할 때는 결과를 `Just`로 감싸는 것을 잊지 마세요.

## 2. 오늘의 개수 증가시키기

- 이 과제에는 재귀가 필요하지 않아요.
- 배열의 첫 번째 원소에 접근하는 것은 `case` 표현식으로 패턴 매칭을 하면 돼요.
- [`::` 연산자][list-cons]를 사용해서 새 배열을 분해하고 다시 구성해요.

## 3. 새가 찾아오지 않은 날이 있었는지 확인하기

- 새가 찾아오지 않은 날을 찾을 때까지 재귀를 사용해서 배열의 원소들을 반복해요.
- 기본 사례는 빈 배열이거나 새가 없는 날이에요.
- 패턴 매칭을 사용해서 배열에 `0`이 있는지 확인해요.

## 4. 찾아온 새의 총 개수 계산하기

- 재귀를 사용해서 배열의 모든 원소를 반복해요.
- 기본 사례는 빈 배열이에요.
- `+` 연산자를 사용해서 현재 원소를 나머지의 합에 더해요.

## 5. 바쁜 날의 개수 계산하기

- 재귀를 사용해서 배열의 모든 원소를 반복해요.
- 기본 사례는 빈 배열이에요.
- `if` 표현식을 사용해서 현재 날이 바쁜 날인지(새가 5마리 이상인지) 확인해요.
- 바쁜 날을 찾으면 나머지 배열의 바쁜 날 개수에 1을 더해요.
