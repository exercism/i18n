# Instructions

엘레인은 동물과 마법 지팡이가 등장하는 새로운 어린이 게임을 만들고 있어요.
이제 주사위를 굴리고, 무작위로 마법 지팡이 에너지를 만들고, 슬라이스를 섞는 함수를 만들 차례예요.

## 1. 주사위 굴리기

`RollADie` 함수를 구현해요.

1부터 20까지의 숫자가 있는 전통적인 20면체 주사위예요.

```go
d := RollADie() // d will be assigned a random int, 1 <= d <= 20
```

## 2. 마법 지팡이 에너지 생성하기

`GenerateWandEnergy` 함수를 구현해요.
마법 지팡이 에너지는 0.0 이상 12.0 미만의 무작위 실수여야 해요.

```go
f := GenerateWandEnergy()  // f will be assigned a random float64, 0.0 <= f < 12.0
```

## 3. 슬라이스 섞기

게임에는 여덟 종류의 동물이 등장해요:

- ant
- beaver
- cat
- dog
- elephant
- fox
- giraffe
- hedgehog

여덟 종류의 동물을 무작위 순서로 담은 슬라이스를 반환하는 `ShuffleAnimals` 함수를 작성해요.
