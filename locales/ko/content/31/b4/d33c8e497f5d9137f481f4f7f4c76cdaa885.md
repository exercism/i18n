# 소개

## 예외 필터링

`when`은 예외를 걸러낼 때 쓰는 키워드예요. `catch`문 뒤에 오고, 그 시점에 스코프 안에 있는 어떤 값이든 담을 수 있는 불리언 표현식을 받을 수 있어요. 표현식이 true로 평가되면 그 `catch`문에 연결된 블록이 실행되고, 그렇지 않으면 다음 `catch`문이 있는지 검사해요.

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```

## 사용자 정의 예외

사용자 정의 예외는 코드에서 정의한 클래스 중 `System.Exception`에서 파생된 클래스예요. 클래스 상속의 모든 규칙을 따르지만, 그에 더해 컴파일러와 언어 런타임이 이런 클래스를 특별한 방식으로 다뤄서, `exceptions` 연습 문제에서 설명하듯 정상적인 제어 흐름 밖에서도 그 인스턴스를 던지고 잡을 수 있게 해줘요.

사용자 정의 예외는 메시지나 그 밖의 관련 데이터처럼 예외를 잡는 쪽에서 쓸 수 있도록 추가 정보를 담는 데 자주 사용해요.
