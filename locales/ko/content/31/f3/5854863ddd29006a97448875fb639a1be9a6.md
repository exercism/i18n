# 지침

모형 기차를 아주 좋아하는 사람이에요. 그 열정을 세상과 나누고 싶어서 뉴스레터를 시작하기로 했어요. 먼저 이 취미를 함께하는 친구와 지인들에게 뉴스레터 첫 호를 보내는 것부터 시작할 거예요. 그들의 이메일 주소 목록이 담긴 텍스트 파일이 하나 있어요.

## 1. 파일에서 이메일 주소 읽기

`Newsletter.read_emails/1` 함수를 구현해요. 이 함수는 파일 경로를 받아요. 파일은 이메일 주소가 줄바꿈으로 구분되어 있는 텍스트 파일이에요. 함수는 파일에서 읽은 이메일 주소의 배열을 반환해야 해요.

```elixir
Newsletter.read_emails("/home/my_user/documents/model_train_friends_emails.txt")
# => ["rick@example.com", "choochoo42@example.com", "anna@example.com"]
```

## 2. 쓰기용 로그 파일 열기

이메일을 보내는 일은 예측할 수 없는 여러 이유로 실패할 수 있어요. 이메일 주소의 오타나 일시적인 네트워크 문제처럼요. 모든 친구에게 이메일을 다시 보낼 때 중복으로 보내지 않으려면, 이미 이메일을 받은 주소를 기록해 둬야 해요. 그러려면 로그 파일이 필요해요.

`Newsletter.open_log/1` 함수를 구현해요. 이 함수는 파일 경로를 받아 파일을 쓰기 모드로 열고, 파일을 다루는 프로세스의 PID를 반환해요.

```elixir
Newsletter.open_log("/home/my_user/documents/newsletter_issue1_log.txt")
# => #PID<0.145.0>
```

## 3. 보낸 이메일 기록하기

`Newsletter.log_sent_email/2` 함수를 구현해요. 이 함수는 파일을 다루는 프로세스의 PID와 이메일 주소가 담긴 문자열을 받아요. 그리고 이메일 주소를 파일에 쓰고, 그 뒤에 줄바꿈을 붙여요.

```elixir
Newsletter.log_sent_email(pid, "joe@example.com")
# => :ok
```

## 4. 로그 파일 닫기

`Newsletter.close_log/1` 함수를 구현해요. 이 함수는 파일을 다루는 프로세스의 PID를 받아 파일을 닫아요.

```elixir
Newsletter.close_log(pid)
# => :ok
```

## 5. 뉴스레터 보내기

이제 이메일을 보내는 절차의 모든 구성 요소를 갖췄으니, 이들을 하나의 함수로 합쳐야 해요.

`Newsletter.send_newsletter/3` 함수를 구현해요. 이 함수는 이메일 주소가 담긴 파일의 경로, 로그 파일의 경로, 그리고 주어진 이메일 주소로 이메일을 보내는 익명 함수를 받아요. 주어진 파일에서 모든 이메일 주소를 읽고, 각 주소로 이메일 보내기를 시도해요. 이메일을 보내는 익명 함수가 `:ok`를 반환하면, 그 이메일 주소를 로그 파일에 쓰고 그 뒤에 줄바꿈을 붙여요. 이메일을 보내자마자 바로 기록해야 해요. 모든 전송이 끝나면 로그 파일을 닫아요.

```elixir
Newsletter.send_newsletter(
  "model_train_friends_emails.txt",
  "newsletter_issue1_log.txt",
  fn email -> :ok end
)

# => :ok
```
