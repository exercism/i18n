# 설치

## Node.js 설치하기

**Windows 및 OS X 사용자**: [Node.js][node]를 [패키지 관리자를 통해][node-download] 설치해요.

**Linux 사용자**: [Node.js 패키지 관리자][linstall]에서 배포판에 맞는 안내를 찾아 [Node.js][node]를 설치해요.

## `jasmine-node`와 `coffeescript` 설치하기

대부분의 사용자라면 다음 명령어를 실행하는 것만으로 충분해요:

```bash
$ npm install -g jasmine-node coffeescript
```

설정에 따라 `npm` 모듈을 전역으로 설치하려면 최고 관리자 권한이 필요할 수도 있어요. 위에 링크된 공식 설치 프로그램을 사용했다면 그런 경우예요. NPM에서 접근 권한이 없다는 오류가 나온다면 위 명령어에 `sudo`를 붙여요:

```bash
$ sudo npm install -g jasmine-node coffeescript
```

공식 설치 프로그램을 사용했다면 `PATH`가 자동으로 설정되었을 거예요. 하지만 셸이 전역으로 설치한 모듈을 찾지 못하거나 Node.js를 소스에서 빌드했다면, `~/.bash_profile`이나 `~/.zshrc`에 다음을 추가해서 `npm` 실행 파일이 있는 경로를 `PATH`에 넣어요:

```bash
$ export PATH=/usr/local/share/npm/bin:$PATH
```
