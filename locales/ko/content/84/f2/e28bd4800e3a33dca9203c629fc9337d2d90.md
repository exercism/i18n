# 힌트

## 공통 사항

- 각 과제는 하나의 값을 정해진 값들과 비교하는데, 바로 이때 쓰라고 있는 게 `case`예요.
- 모든 `case`에는 `else`가 필요해요. 위쪽 분기들이 완전해 보여도 마찬가지예요.
  `else`가 없으면, 어디에도 해당하지 않는 값이 프로그램을 멈춰요.

## 1. 구역별 요금

- `when` 분기 세 개와 `else` 하나예요. `else`는 구역이 아닌 모든 숫자를 처리해요.
- 구역 0과 알 수 없는 구역은 둘 다 요금이 들지 않지만 서로 다른 경우예요.
  두 분기를 따로 써야 의도가 분명해져요.

## 2. 어떤 승차권일까요?

- `'c'`와 `'s'`는 같은 결과를 내므로 하나의 분기로 함께 써요:
  `when 'c', 's' then`.
- 작은따옴표를 써요. 인자는 `STR`이 아니라 `CHAR`예요.

## 3. 어떤 날일까요?

- 분기가 두 개인데, 하나는 날 두 개를 나열하고 다른 하나는 다섯 개를 나열해요.
- 문자열은 숫자와 마찬가지로 `=`로 비교하므로, `case`에서 그대로 쓸 수 있어요.

## 4. 하루 요금 상한

- 하루를 날의 종류로 바꿔 주는 루틴이 이미 있어요. 그걸 호출한 다음, 그 결과에
  `case`를 써요.
- 그렇게 하면 날 목록을 한 번만 쓰면 돼요. 여기서 다시 반복하는 것이 바로 이
  과제가 잡아내려는 실수예요.
