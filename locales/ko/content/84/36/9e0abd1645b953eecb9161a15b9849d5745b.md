# 기초

## 시작하기

### 변수

[변수][variables]를 선언하려면 `=` 대입 연산자를 사용해요.
Crystal에서 변수 이름은 [snake_case][snake-case] 형식으로 작성해요.

```crystal
number = 1
puts number # => 1

number = 2
puts number # => 2
```

### 상수

[상수][constants]도 같은 `=` 대입 연산자로 선언하지만, SCREAMING_SNAKE_CASE라고 하는 모두 대문자인 이름을 사용해요.

```crystal
NUMBER = 1
puts NUMBER # => 1
```

이미 정의된 상수에 값을 대입하면 컴파일 시점에 오류가 발생해요.

```crystal
NUMBER = 1

NUMBER = 2
# Error: already initialized constant NUMBER
```

### 타입

Crystal은 컴파일 언어예요. 즉 모든 변수와 메서드 인자는 컴파일 시점에 타입이 정해져요.
컴파일러는 변수나 메서드 인자의 타입을 추론할 수 있어요.
하지만 경우에 따라 타입을 직접 지정해야 할 때도 있어요.
타입을 지정해야 하는 경우는 이후 개념에서 설명해요.

### 메서드

[메서드][methods]는 재사용할 수 있도록 명령들을 묶는 방법이에요.
Crystal에서 메서드는 보통 클래스, 모듈, 구조체 안에 정의해요.
하지만 클래스, 모듈, 구조체 밖에 정의할 수도 있어요.
메서드는 `def` 키워드 뒤에 메서드 이름을 써서 선언해요.
Crystal에서 메서드 이름은 snake_case로 작성해요.
메서드에 인자가 없으면 괄호는 생략할 수 있어요.
메서드의 끝은 `end` 키워드로 표시해요.

```crystal
def hello
  puts "Hello World!"
end
```

변수나 메서드 인자의 타입에 존재하지 않는 메서드를 사용하면 컴파일 시점에 오류가 발생해요.

```crystal
number = 1
number + "1"
# Error: no overload matches 'Int32#+' with type String
```

### 인자

메서드는 [인자][arguments]를 가질 수 있어요.
인자는 메서드에 전달되는 데이터예요.
메서드에 인자를 전달하려면 인자의 이름을 지정해야 해요.
Crystal에서 인자 이름은 snake_case로 작성해요.
메서드는 여러 인자를 가질 수 있고, 인자들은 쉼표로 구분해요.

```crystal
def hello(name)
  puts "Hello #{name}!"
end
```

메서드는 여러 인자를 가질 수도 있어요.
이때 인자들은 쉼표로 구분해야 해요.

```crystal
def hello(name, language)
  puts "Hello #{name}! You are learning #{language}."
end
```

### 메서드 호출하기

클래스, 모듈, 구조체에 속한 메서드를 호출할 때는 점 연산자(`.`)를 사용해요.
형식은 `<ClassName>.<method_name>`이에요.
메서드가 클래스, 모듈, 구조체에 속하지 않으면 이름만 써서 호출할 수 있어요.
메서드는 항상 마지막 표현식의 값을 암묵적으로 반환해요.

메서드에 인자가 있으면, 메서드 호출과 정의에서 인자를 지정할 때 다음과 같이 괄호를 사용할 수 있어요: `<method_name>(<argument_1>, <argument_2>, ...)`.
메서드에 인자가 없으면 괄호는 생략해요.

```crystal
def hello(name)
  "Hello #{name}!"
end

hello("Crystal")
# => Hello Crystal!
```

여러 인자를 가진 메서드를 호출할 때는 인자들을 쉼표로 구분해요.
인자는 메서드에 정의된 순서와 같은 순서로 전달해야 해요.

```crystal
def hello_language(name, language)
  "Hello #{name}! You are learning #{language}."
end

hello_language("World", "Crystal")
# => Hello World! You are learning Crystal.
```

인자 개수를 잘못 지정해 메서드를 호출하면 컴파일 시점에 오류가 발생해요.

```crystal
hello_language("Crystal")
# wrong number of arguments for 'hello_language' (given 1, expected 2)
```

### 덧셈, 뺄셈, 곱셈

Crystal에서는 `+` 연산자로 두 수를 더할 수 있어요.
`-` 연산자로 두 수를 뺄 수 있어요.
그리고 `*` 연산자로 두 수를 곱할 수 있어요.

```crystal
1 + 1
# => 2

2 - 1
# => 1

2 * 2
# => 4
```

### 주석

Crystal에서 [주석][comments]은 `#` 문자 뒤에 공백을 하나 쓰고 내용을 적어요.
주석은 코드를 설명하는 데 사용해요.
컴파일러는 주석을 실행하지 않아요.

```crystal
# This is a comment
```
