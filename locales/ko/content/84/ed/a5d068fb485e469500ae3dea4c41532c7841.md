# 지침 추가

## 입력 형식

각 도미노는 1바이트로 저장되는데, 왼쪽 절반은 상위 [nibble]에, 오른쪽 절반은 하위 [nibble]에 들어 있어요. 예를 들어 조각 `[2|1]`, `[2|3]`, `[1|3]`은 바이트 `0x21 0x23 0x13`으로 표현해요.

## 레지스터

| 레지스터 | 용도      | 타입    | 설명                                             |
| -------- | --------- | ------- | ------------------------------------------------ |
| `$a0`    | 입력      | 주소    | 조각 바이트 배열                                 |
| `$a1`    | 입력      | 정수    | 조각의 개수                                      |
| `$v0`    | 출력      | 불리언  | 도미노를 이을 수 있는지 여부 (`0` = `false`, `1` = `true`) |
| `$t0-9`  | 임시      | 임의    | 임시 저장에 사용                                 |


[nibble]: https://en.wikipedia.org/wiki/Nibble
