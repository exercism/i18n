# 지침

이 연습 문제에서는 고등학교 커플이 소셜 미디어에서 사랑을 고백할 수 있도록, 두 사람의 이니셜이 들어간 ASCII 하트를 만들어 볼 거예요.

```
❤ J.  +  M. ❤
```

## 1. 이름 정리하기

`HighSchoolSweetheart.clean_up_name` 메서드를 구현해요.
이름을 받아서 `-` 문자를 모두 제거하고 공백으로 바꿔야 해요.
이름의 앞뒤에 있는 공백도 제거해야 해요.

```crystal
HighSchoolSweetheart.clean_up_name("Jane-Ann")
# => "Jane Ann"
```

## 2. 이름의 첫 글자 가져오기

`HighSchoolSweetheart.first_letter` 메서드를 구현해요.
이름을 받아서 첫 글자를 반환해야 해요.
이전 단계에서 정의한 `HighSchoolSweetheart.clean_up_name`을 다시 사용해야 해요.

```crystal
HighSchoolSweetheart.first_letter("Jane")
# => "J"
```

## 3. 첫 글자를 이니셜 형식으로 만들기

`HighSchoolSweetheart.initial` 메서드를 구현해요.
이름을 받아서 첫 글자를 대문자로 바꾸고 마침표를 붙여 반환해야 해요.
이전 단계에서 정의한 `HighSchoolSweetheart.first_letter`를 다시 사용해야 해요.

```crystal
HighSchoolSweetheart.initial("Robert")
# => "R."
```

## 4. 하트 안에 이니셜 넣기

`HighSchoolSweetheart.pair` 메서드를 구현해요.
이름 두 개를 받아서 양옆에 이모지 하트를 붙인 이니셜을 반환해야 해요.
이전 단계에서 정의한 `HighSchoolSweetheart.initial`을 다시 사용해야 해요.

```crystal
HighSchoolSweetheart.pair("Blake Miller", "Riley Lewis")
# => "❤ B.  +  R. ❤"
```
