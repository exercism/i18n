# 안내

이 연습 문제에서는 프리랜서가 프로젝트 관리자와 소통할 수 있도록, 일일 요금과 월 요금을 빠르게 계산하는 몇 가지 유틸리티를 작성해요. 원한다면 주어진 할인을 적용할 수도 있어요.

먼저 프리랜서와 프로젝트 관리자 사이에 몇 가지 규칙을 정해요:

일일 요금은 시간당 요금의 8배예요.
한 달에는 청구할 수 있는 날이 22일 있어요.
프로젝트 관리자가 월 단위로 청구하기로 선택하면 프리랜서가 할인을 적용할 수 있어요. 이건 관리자가 맞춰야 할 예산이 있을 때 유용하죠.

할인은 백분율을 나타내는 소수로 표현해요. 예를 들어 25.0은 25퍼센트를 뜻해요.

## 1. 시간당 요금이 주어졌을 때 일일 요금 계산하기

시간당 요금이 주어졌을 때 일일 요금을 계산하는 함수를 구현해요:

```gleam
freelancer_rates.daily_rate(60)
# => 480.0
```

반환되는 일일 요금은 실수여야 해요.

## 2. 할인된 가격 계산하기

할인을 적용한 뒤의 가격을 계산하는 함수를 구현해요.

```gleam
freelancer_rates.apply_discount(150, 10)
# => 135.0
```

반환되는 값은 항상 실수여야 하며, 절대 반올림해서는 안 돼요.

## 3. 시간당 요금과 할인이 주어졌을 때 월 요금 계산하기

월 요금을 계산하고 할인을 적용하는 함수를 구현해요:

```gleam
freelancer_rates.monthly_rate(77, 10.5)
# => 12130
```

반환되는 월 요금은 올림(ceiling)해서 가장 가까운 정수로 만들어야 해요.

## 4. 예산, 시간당 요금, 할인이 주어졌을 때 근무일 수 계산하기

예산, 시간당 요금, 할인을 받아서 그 예산으로 며칠을 일할 수 있는지 계산하는 함수를 구현해요.

```gleam
freelancer_rates.days_in_budget(20000, 80, 11.0)
# => 35
```

반환되는 일수는 소수점 한 자리까지 내림(floor)해야 해요.
