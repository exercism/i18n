# 설치

## Mac

Homebrew를 사용해서 `brew install swi-prolog`로 설치해요.
또는 [SWI Prolog 웹사이트](http://www.swi-prolog.org/download/devel)에서 사용하는 기기에 맞는 소스를 다운로드해요.

## Windows

[SWI Prolog 웹사이트](http://www.swi-prolog.org/download/devel)에서 사용하는 기기에 맞는 소스를 다운로드해요.

## Linux

[여기](http://www.swi-prolog.org/build/unix.html)에서 사용하는 배포판에 맞는 안내를 따라 해요.
