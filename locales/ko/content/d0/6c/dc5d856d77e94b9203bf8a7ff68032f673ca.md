# 자리 표시자

## bash로 해결하는 방법

`bash`에는 날짜와 시간 문자열을 **파싱**하는 내장 기능이 없어요.
이 연습 문제에서는 외부 도구를 호출해야 해요.

* GNU `date` 명령의 `-d` 옵션은 [다양한 형식][gnu-date]을 파싱할 수 있어요.
* Mac 사용자는 [BSD `date` 명령][bsd-date]과 그 `-f` 옵션을 참고해요.
* Perl은 널리 사용할 수 있고, [`Time::Piece` 모듈][time-piece]로 타임스탬프를 파싱할 수 있어요.

bash는 외부 도구 없이도 날짜를 **포맷**할 수 있어요.
정수 시간 값(에포크 이후 초)이 주어지면, [`printf`의 `%()T` 포맷터][bash-printf]로 "strftime" 스타일 포맷팅을 적용할 수 있어요.

```bash
epoch=1234567890

printf '%(%Y-%m-%d %H:%M:%S)T\n' "$epoch"
# ==> 2009-02-13 18:31:30

# bash uses the `TZ` environment variable for the timezone.

TZ=Asia/Kolkata printf '%(%Y-%m-%d %H:%M:%S)T\n' "$epoch"
# ==> 2009-02-14 05:01:30
```

[bsd-date]: https://manpage.me/index.cgi?apropos=0&q=date&sektion=0&manpath=FreeBSD+12-CURRENT+and+Ports&arch=default&format=html
[time-piece]: https://perldoc.pl/Time::Piece
