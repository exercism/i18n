## 일반

- [Equality][equality]: 참조 형식과 값 형식의 동등성을 비롯해 C#에서 동등 비교가 어떻게 동작하는지 알아봐요.
- [HashCode][hash-code]: 해시 코드를 만들고 조합하는 방법
- [GetHashCode][get-hash-code]: API 문서

## 1. 얼굴 특징이 일치하는지 확인하기

참조 형식을 값으로 비교하는 방법은 이 [문서][value-equality]에서 자세히 다뤄요.

## 2. 시스템 관리자 인증하기

1번 과제에서 배운 내용을 단순한 재귀 방식으로 적용하기만 하면 되는 경우예요.

## 3. 새로운 신원 등록하기

고유한 값들의 모음을 다루는 가장 성능이 좋고 "자연스러운" 방법은 [해시 세트][hash-set]를 사용하는 거예요. 테스트가 로컬에서는 통과하는데 웹사이트에서는 실패한다면, `Authenticator` 클래스에서 `static` 멤버 대신 인스턴스 멤버를 사용해 봐요.

## 4. 유효하지 않은 신원이 인증되지 않도록 막기

[`HashSet<T>.Contains()`][hash-set-contains] 메서드를 살펴봐요. 테스트가 로컬에서는 통과하는데 웹사이트에서는 실패한다면, `Authenticator` 클래스에서 `static` 멤버 대신 인스턴스 멤버를 사용해 봐요.
