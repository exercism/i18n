# match 표현식

match 표현식은 값을 평가하고 조건에 따라 평가될 표현식을 반환해요.
삼항 연산자와 아주 비슷하게, 조건이 일치하지 않으면 반환 표현식은 평가되지 않아요.
조건을 일치시키기 위해서는 동일성 검사[엄격한 동등성 또는 `===`]를 수행해요.

```php
<?php
$some_value = 42;

$return_value = match($some_value) {
    0 => 'number is 0',
    1 => 'number is 1',
    default => 'number is something else'
}
```

동등성 [`==`] 검사를 하려면 조건을 재배치할 수 있어요:

```php
<?php
$some_value = 42;

$return_value = match(true) {
    $some_value < 100 => 'number is less than 100',
    $some_value > 100 => 'number is greater than 100',
    $some_value == 100 => 'number is 100',
}
```

match 표현식에서 어떤 조건도 일치하지 않으면 `UnhandledMatchError`가 발생해요.
