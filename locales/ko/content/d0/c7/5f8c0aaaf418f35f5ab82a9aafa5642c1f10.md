# 힌트

## 일반

- `cmovcc` 계열 명령어는 즉시값을 받지 않아요.
  사용하기 전에 상수는 레지스터에 먼저 넣어야 해요.
- `setcc` 계열 명령어는 8비트 피연산자에만 동작해요.
  알맞은 값을 설정한 뒤에는 부호 확장이나 제로 확장을 해야 할 때가 많아요.

## 1. 디스플레이가 넘치지 않게 보너스 더하기

- 상한값은 `999999`예요.
  이보다 큰 합은 대신 `999999`가 돼요.
- 비교한 뒤에 `cmovcc`를 쓰면 조건이 성립할 때 값을 다른 값으로 바꿀 수 있어요.
- `cmovcc` 계열 명령어는 즉시값을 받지 않아요.
  사용하기 전에 상수는 레지스터에 먼저 넣어야 해요.

## 2. 두 점수 비교하기

- 비교 한 번 뒤에 `setcc`나 `cmovcc`를 여러 개 붙여서, 같은 플래그든 다른 플래그든 그에 따라 여러 값을 설정하거나 옮길 수 있어요.
- `setcc` 계열 명령어는 8비트 피연산자에만 동작해요.
- 부호 있는 8비트 피연산자는 `movsx`로 64비트까지 부호 확장할 수 있어요.

## 3. 원시 점수 검사하기

- 비교 한 번 뒤에 `setcc`나 `cmovcc`를 여러 개 붙여서, 같은 플래그든 다른 플래그든 그에 따라 여러 값을 설정하거나 옮길 수 있어요.
- 부호 있는 비교의 조건 접미사는 더 작다는 뜻의 `l`과 더 크다는 뜻의 `g`예요.

## 4. 가장 높은 두 점수 추적하기

- 최상위 값이 두 개 있어요.
  새 후보는 둘 모두와 비교해야 해요.
- 비교 한 번 뒤에 `setcc`나 `cmovcc`를 여러 개 붙여서, 같은 플래그든 다른 플래그든 그에 따라 여러 값을 설정하거나 옮길 수 있어요.
- 부호 있는 비교의 조건 접미사는 더 작다는 뜻의 `l`과 더 크다는 뜻의 `g`예요.
