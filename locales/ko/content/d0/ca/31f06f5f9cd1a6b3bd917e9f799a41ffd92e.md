# 지침 추가

## 레지스터

| Register | Usage     | Type    | Description                      |
| -------- | --------- | ------- | -------------------------------- |
| `$a0`    | 입력      | 정수    | 1..64 범위의 칸 번호             |
| `$v0`    | 출력      | 정수    | 출력의 하위 32비트               |
| `$v1`    | 출력      | 정수    | 출력의 상위 32비트               |
| `$t0-9`  | 임시      | 아무 타입 | 임시 저장용                     |
