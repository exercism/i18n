# 지침

여러분이 아는 Erin은 여러 행사를 위해 전단지를 수천 장 인쇄해야 하는데, 도움이 필요해요! Erin은 헤더, 선택적인 날짜, 그리고 아티스트 목록으로 구성된 리플릿의 레이아웃을 만들어 달라고 했어요. 각 아티스트는 _유니코드 아이콘_과 연결돼요. 목표는 멋진 새 리플릿 디자인을 `print`해서 배포하는 것이고, 성공하려면 Python 문자열 포매팅 실력을 모두 발휘해야 해요.

## 1. 헤더를 대문자로 시작하는 클래스 만들기

`capitalize_header` 함수는 이벤트 이름을 받아서, 이벤트 이름의 첫 글자를 대문자로 바꾼 버전을 반환해야 해요.

```python
>>> capitalize_header("fan meetup")
"Fan meetup"
```

## 2. 날짜 형식 지정하기

날짜, 월, 연도가 들어 있는 배열을 받는 새 메서드 `format_date`를 만들어요. 이 메서드는 날짜를 `<month_name> <date>, <year>` 형식으로 표시해요.

```python
>>> convert_date([9, 4, 2020])
>>> leaflet.date
"April 9, 2020"
>>> leaflet.set_date([13, 5, 2030])
>>> leaflet.date
"May 13, 2030"
```

## 3. 유니코드 코드 포인트를 아이콘으로 렌더링하기

`display_icons` 메서드가 호출되면, 전달된 유니코드 코드 포인트 배열이 _아이콘_의 `list`로 렌더링되어 반환돼야 해요.

```python
>>> leaflet.display_icons(['\U00000040', '\U0001D70B'])
['@', '𝜋']
```

## 4. 완성된 리플릿 표시하기

이제 위의 모든 함수를 사용해서 `print_leaflet` 함수에서 하나로 합쳐요. 이 함수는 `event_name`, `icons` 배열, `authors` 배열, `event_date` 배열을 받아요.

포스터는 아래 레이아웃을 따라야 해요.

리플릿은 직사각형 모양의 정해진 레이아웃을 따라요.

- 첫 번째 줄과 마지막 줄에는 별표 스무 개가 들어 있어요. `"*"`
- 각 섹션은 위아래로 빈 줄 하나씩으로 구분돼요.
- 빈 줄에는 맨 앞에 별표 하나, 맨 끝에 별표 하나만 들어 있어요.
- 첫 번째 섹션은 리플릿의 헤더이고, 이 제목은 첫 글자가 대문자예요.
- 두 번째 섹션은 선택적인 날짜이고, 날짜가 전달되지 않으면 이 섹션은 빈 줄이어야 해요.
- 세 번째이자 마지막 섹션은 아티스트 목록이고, 각 아티스트는 해당하는 아이콘과 연결돼 있어요.

```python
********************
*                  *
*    'Concert'     *
*                  *
*  June 22, 2020   *
*                  *
* John         🎸  *
* Benjamin     🎤  *
* Max          🎹  *
*                  *
********************
```
