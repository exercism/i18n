# 개요

`call`은 "이 quotation을 지금 실행하라"는 보편적인 기본 연산이에요. 컴파일러가 quotation을 코드에 그대로 적힌 형태로 볼 수 있으면 스택 효과를 추론할 수 있어요. 하지만 quotation이 변수나 배열, 매개변수에서 온다면 스택 효과를 직접 선언해야 해요.

```factor
: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .   ! => 2
5 3 [ + ] apply-binary .   ! => 8
```

`call( a b -- c )` 선언은 quotation이 실제로 선언한 스택 효과를 가지는지 실행 시점에 검사하는 코드로 컴파일돼요. 효과가 맞지 않으면 스택 상태가 망가지는 대신 분명한 오류가 나요.

quotation을 데이터로 다루는 것, 그러니까 quotation을 스택에 넣고, 배열에 담고, word에서 반환하는 것은 연결형 코드를 아주 간결하게 만들어 주는 요소 중 하나예요. "프로그램"이 그냥 나열일 수도 있고, `each`와 `call`만 있으면 그것을 해석하기에 충분해요.
