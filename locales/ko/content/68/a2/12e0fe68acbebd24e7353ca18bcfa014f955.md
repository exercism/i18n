# 지시 사항

디자인 회사에서는 주로 CSS 변환을 사용해 웹 페이지를 만들어 왔어요. 몇 가지 논의 끝에, 일부 계산을 동적으로 수행하기 위해 Clojure를 사용하기로 했어요. 팀원 중에는 Clojure가 아직 익숙하지 않은 사람도 있어서, `{x, y}` 좌표 쌍을 위한 재사용 가능한 변환을 만들기 위해 함수 클로저를 사용하기로 했어요.

## 1. 좌표 평행 이동하기

`translate2d` 함수를 구현해요. 이 함수는 클로저를 사용해 좌표 쌍을 반복해서 2차원 평행 이동하는 함수를 반환해요.

```clojure
(def move-coordinates-right-2px (translate2d 2 0))
(def result (move-coordinates-right-2px 4 8))
;; result => [6 8]
```

## 2. 좌표 크기 조정하기

`scale2d` 함수를 구현해요. 이 함수는 클로저를 사용해 좌표 쌍을 반복해서 2차원으로 크기 조정하는 함수를 반환해요.

> 이 연습 문제에서는 양수 크기 조정 값만 있다고 가정해요.

```clojure
(def double-scale (scale2d 2 2))
(def result (double-scale 6 -3))
;; result => [12 -6]
```

## 3. 변환 함수 합성하기

두 변환 함수를 결합해 반복 가능한 변환을 수행해요. 이를 보통 _함수 합성_이라고 하는데, 첫 번째 함수 _'f(x)'_ 의 결과가 두 번째 함수 _'g(x)'_ 의 입력으로 사용돼요.

```clojure
(def move-coordinates-right-2px (translate2d 2 0))
(def double-coordinates (scale2d 2 2))
(def composed-transformations 
  (compose-transform move-coordinates-right-2px 
                     double-coordinates))
(def result (composed-transformations 0 1))
;; result => [4 2]
```

## 4. 함수의 결과 저장하기

`memoize-transform` 함수를 구현해요. 이 함수는 _메모이제이션_할 함수를 받아서, 전달받은 함수의 입력을 기억하는 새로운 함수를 반환해요. 그래야 같은 인자로 다시 호출했을 때 마지막 반환 값을 "기억"하고 한 번만 계산해요.

> 메모이제이션은 _동적 계획법_이라고도 하는데, 연산 결과를 기억해 두기 때문에 비용이 큰 연산을 한 번만 수행할 수 있어요.

```clojure
(def triple-scale (scale2d 3 3))
(def memoized-scale (memoize-transform triple-scale))

(memoized-scale 4 3)
;; => [12, 9], this is computed since it hasn't been computed before for the arguments

(memoized-scale 4 3)
;; => [12, 9], this is remembered, since it was computed already
```
