# 소개

Cairo의 이넘을 사용하면 여러 개의 이름 붙은 배리언트 중 하나가 될 수 있는 타입을 정의할 수 있어요.

## 기본

이넘은 '열거'를 뜻하는 enumeration을 줄인 말로, 어떤 데이터가 가질 수 있는 모든 값을 미리 정해진 집합으로 제한해요. `enum`이 가질 수 있는 값들을 배리언트라고 해요:

```rust
#[derive(Drop)]
enum Direction {
    North,
    South,
    East,
    West,
}
```

배리언트를 지정해서 이넘 값을 만들어요:

```rust
let my_direction = Direction::North;
let another_direction = Direction::West;
```

## 패턴 매칭

match를 사용하면 서로 다른 이넘 배리언트를 처리할 수 있어요:

```rust
match my_direction {
    Direction::North => println!("Going north!"),
    Direction::South => println!("Going south!"),
    Direction::East => println!("Going east!"),
    Direction::West => println!("Going west!"),
}
```

match의 각 갈래는 이넘의 배리언트 중 하나를 처리해요.

## 데이터를 담는 이넘

이넘 배리언트는 추가 데이터를 담을 수도 있어요:

```rust
struct Location {
    x: u32,
    y: u32,
}

enum Message {
    Text: ByteArray,
    Number: u32,
    Location: Location,
}
```

패턴 매칭으로 데이터를 꺼내요:

```rust
match msg {
    Message::Text(content) => println!("Text: {}", content),
    Message::Number(val) => println!("Number: {}", val),
    Message::Location(Location { x, y }) => println!("Position: ({}, {})", x, y),
}
```
