# 안내 추가

## 입력/출력 형식

각 단어 집합은 null로 끝나는 문자열로 표현되며, 각 단어 끝에는 줄바꿈 문자가 있어요.

애너그램은 후보 단어에 나열된 순서와 같은 순서로 반환해야 해요.

예를 들어 `"tones\nnotes\nSeton\n"`와 같아요.

## 레지스터

| 레지스터 | 용도        | 형식    | 설명                                                    |
| -------- | ------------ | ------- | -------------------------------------------------------------- |
| `$a0`    | 입력        | 주소 | 줄바꿈이 없는, null로 끝나는 대상 문자열                 |
| `$a1`    | 입력        | 주소 | 각 단어 뒤에 줄바꿈이 있는, null로 끝나는 후보 문자열 |
| `$a2`    | 입력/출력 | 주소 | 각 단어 뒤에 줄바꿈이 있는, null로 끝나는 출력 문자열     |
| `$t0-9`  | 임시        | 임의    | 임시 저장용                                          |
