# 참고 자료

* [The Rust Programming Language](https://doc.rust-lang.org/book/)는 Rust를 시작할 때는 물론, Rust의 특정 기능을 더 깊이 파고들 때도 좋은 자료예요.
* [Rust by Example](https://doc.rust-lang.org/stable/rust-by-example/)에서는 Rust로 작성하게 될 가장 흔한 것들의 예제를 볼 수 있어요.
* [Rust API Documentation](http://doc.rust-lang.org/std/)을 보면 새로운 메서드와 그 동작 방식을 알아볼 수 있어요.
* [Stack Overflow](http://stackoverflow.com/questions/tagged/rust)에서 문제를 검색하고 이미 답변이 있는지 확인할 수 있어요. 질문을 올리고 답변을 달 수도 있어요.
* [Rust User Forum](http://users.rust-lang.org)은 Rust에 관한 일반적인 이야기를 나누는 곳이에요.
* [/r/rust](http://www.reddit.com/r/rust/)는 공식 Rust 서브레딧이에요.
* [Discord](https://discordapp.com/)의 [The Rust Programming Language](https://discord.gg/rust-lang) 공식 서버에서는 언어에 관한 짧은 질문과 대화를 나눌 수 있어요.
