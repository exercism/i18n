# 소개

Gleam에서 값에 대해 패턴 매칭을 할 때는 패턴이 그 타입이 가질 수 있는 모든 값과 일치하는지 확인해야 해요. 그렇지 않으면 코드가 컴파일되지 않아요.

다음 함수는 배열이 비어 있는 경우를 처리하지 않았기 때문에 컴파일이 거부돼요:

```gleam
pub fn get_first_element_or_crash(items: List(e)) -> e {
  case items {
    [item, ..] -> item
  }
}
```

Gleam 프로그램에서는 대부분 모든 경우를 처리하고 싶지만, 프로토타입이나 간단한 스크립트처럼 정상 경로에만 집중하고 다른 경우를 위한 코드는 작성하지 않고 싶을 때도 있어요. 이럴 때 필요한 것이 바로 Gleam의 `let assert`이에요.

let 단언을 사용하면 패턴이 타입이 가질 수 있는 값 중 일부만 일치시킬 수 있고, 패턴이 값과 일치하지 않으면 프로그램이 충돌해요. `let assert`를 사용하면 위 함수를 이렇게 작성할 수 있어요:

```gleam
pub fn get_first_element_or_crash(items: List(e)) -> e {
  let assert [item, ..] = items
  item
}
```

Gleam 라이브러리에서는 프로그램이 충돌할 수 있기 때문에 let 단언을 절대 사용하면 안 돼요. 대신 `Result` 타입을 사용해서, 애플리케이션 개발자가 오류를 어떻게 처리할지 결정하도록 해야 해요.
