# 소개

## IO

`IO` 모듈은 입출력을 다루는 함수를 제공해요.

### 출력

문자열을 표준 출력에 쓰려면 `IO.puts`를 사용해요. `IO.puts`는 항상 문자열 끝에 줄바꿈을 추가해요. 그런 동작을 원하지 않으면 대신 `IO.write`를 사용해요. 두 함수 모두 성공하면 `:ok` 아톰을 반환해요.

```elixir
IO.puts("Hi!")
# > Hi!
# => :ok
```

`IO.puts`는 문자열을 쓰는 데 유용하지만, 그 외에는 그다지 유용하지 않아요. 표준 출력에 어떤 값이든 쓸 수 있게 해주는 디버깅 도구가 필요하면, 대신 `IO.inspect`를 사용해요. `IO.inspect`는 전달받은 값을 그대로 반환하므로 코드의 어느 지점에든 넣을 수 있어요. 또한 `:label` 같은 여러 옵션을 받아서 다른 `IO.inspect` 호출과 구분할 수 있게 해줘요.

### 입력

표준 입력에서 한 줄을 읽으려면 `IO.gets`를 사용해요. `IO.gets`는 인자 하나를 받아요. 그 인자는 입력을 요청하는 프롬프트로 출력되는 문자열이에요. `IO.gets`는 프롬프트 뒤에 줄바꿈을 추가하지 않으니, 필요하면 직접 넣어요.

```elixir
IO.gets("What's your name?\n")
# > What's your name?
# < Mary
# => "Mary\n"
```
