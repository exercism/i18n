# 가시성

클래스를 사용해 코드를 구성할 때, 프로퍼티와 메서드, 상수의 가시성은 적절한 추상화와 책임을 이끌어 내는 데 도움을 줘요.
프로퍼티와 메서드, 상수의 가시성은 선언하는 시점에 `public`, `private`, `protected` 키워드를 사용하는지에 따라 정해져요.
가시성은 항상 클래스 외부에서 프로퍼티, 메서드, 상수를 사용하는 관점을 기준으로 해요.
즉, 프로퍼티를 `public`으로 선언하면 외부 호출에서도 볼 수 있고 사용할 수 있어요.
`private` 프로퍼티와 메서드, 상수는 외부 호출에서 볼 수도, 사용할 수도 없어요.

```php
<?php

class SecretDocument
{
    private $encryption_key;

    public $title;

    public function __construct($encryption_key, $title)
    {
        $this->encryption_key = $encryption_key;
        $this->title = $title;
    }
}

$document = new SecretDocument('secret_password', 'Secret Plans');
$title = $document->title; // => succeeds
$key = $document->encryption_key; // => fails
```

`protected` 프로퍼티와 메서드, 상수는 자기 자신과 (상속을 통해) 자식 클래스에서만 볼 수 있어요.

```php
<?php

class Shape
{
    protected $color = "blue";
}

class Square extends Shape
{
    public function getColor()
    {
        return $this->color;
    }
}

$square = new Square();
$color = $square->getColor(); // => succeeds
```
