# 설치

이 트랙의 풀이는 32비트 RISC-V 어셈블리로 작성되어 에뮬레이션 환경에서 실행돼요. 따라서 RISC-V 하드웨어는 필요하지 않아요.
각 연습 문제에는 테스트를 빌드하고 실행하는 Makefile이 함께 제공돼요.
이걸 사용하려면 세 가지 도구가 필요해요:

- [Zig][zig]: `zig cc`를 통해 RISC-V 어셈블러, C 컴파일러, 링커를 제공해요.
- [Make][make]: 빌드를 실행해요.
- [QEMU][qemu]에서 제공하는 `qemu-riscv32`: 빌드된 프로그램을 실행해요.

## macOS

적절한 가상화 도구(예: [Lima][lima])로 Linux 가상 머신을 실행한 뒤, 아래 Linux 배포판 항목을 따라 해요.

## Windows

[Windows Subsystem for Linux][wsl]를 사용한 뒤 아래 Linux 배포판 항목을 따라 해요.
또는 Linux 가상 머신을 설정해도 돼요.

## Debian / Ubuntu

Make와 QEMU의 사용자 모드 에뮬레이터를 설치해요:

```shell
sudo apt install make qemu-user
```

그다음 [직접 다운로드][zig-install]에 설명된 대로 Zig 0.15.2 이상을 설치해요.

## Fedora

다음 명령으로 세 도구를 모두 설치해요:

```shell
sudo dnf install zig make qemu-user
```

## Arch Linux

다음 명령으로 세 도구를 모두 설치해요:

```shell
sudo pacman -S zig make qemu-user
```

## openSUSE Tumbleweed

다음 명령으로 세 도구를 모두 설치해요:

```shell
sudo zypper install zig make qemu-linux-user
```

## 설치 확인

세 도구가 모두 제대로 인식되는지 확인해요:

```shell
zig version
make --version
qemu-riscv32 --version
```

그다음 Exercism CLI로 연습 문제를 내려받고 테스트를 실행해요:

```shell
exercism download --track=risc-v --exercise=hello-world
cd ~/exercism/risc-v/hello-world/
make
```
