# 학습

## Emacs 시작하기

Emacs를 설치했어요. 이제 뭘 하면 될까요?

먼저 `C-h t`를 눌러 튜토리얼을 시작할 수 있어요. 나쁘지 않은 출발점이에요. 튜토리얼에서는 Emacs에서 편집하고, 검색하고, 이동하는 기본적인 방법을 배울 수 있어요.

Emacs가 완전히 처음이라면, 설정과 패키지가 미리 준비되어 함께 딸려 오는 스타터 키트를 받는 것도 좋아요.

[Emacs Prelude](http://batsov.com/prelude/) 패키지는 합리적인 기본 설정과 패키지를 잘 갖춰 제공해요.

Emacs Prelude를 설치하려면 터미널에서 다음을 실행해요:

```
curl -L https://github.com/bbatsov/prelude/raw/master/utils/installer.sh | sh
```

그리고 자세한 안내는 [설치 가이드](https://prelude.emacsredux.com/en/latest/installation/)를 확인해 봐요.


vim에 익숙하다면 [evil-mode](https://github.com/emacs-evil/evil)로 구동되는 vim 에뮬레이션을 통합한 [Doom Emacs](https://github.com/doomemacs/doomemacs) 스타터 키트에 흥미가 생길지도 몰라요.

Doom Emacs를 설치하려면 터미널에서 다음을 실행해요:

```
git clone --depth 1 https://github.com/doomemacs/doomemacs ~/.emacs.d
~/.emacs.d/bin/doom install
```

그리고 자세한 안내는 [설치 가이드](https://github.com/doomemacs/doomemacs#install)를 확인해 봐요.

## 구문 검사와 린팅 설정하기

[Flycheck](https://www.flycheck.org/en/latest/)로 구문 검사와 린팅을 설정하는 걸 추천해요.

아직 Emacs에 [MELPA](https://melpa.org/) 저장소를 추가하지 않았다면, [init 파일](https://www.flycheck.org/en/latest/glossary.html#term-init-file)에 다음을 추가해요

```elisp
(require 'package)

(add-to-list 'package-archives
             '("MELPA Stable" . "https://stable.melpa.org/packages/") t)
(package-initialize)
(package-refresh-contents)
```

[use-package](https://github.com/jwiegley/use-package) 없이 Flycheck를 설치하고 설정하려면 [init 파일](https://www.flycheck.org/en/latest/glossary.html#term-init-file)에 다음을 추가해요

```elisp
(package-install 'flycheck)
(add-hook 'after-init-hook #'global-flycheck-mode)
```

[use-package](https://github.com/jwiegley/use-package)와 함께 Flycheck를 설치하고 설정하려면 [init 파일](https://www.flycheck.org/en/latest/glossary.html#term-init-file)에 다음을 추가해요

```elisp
(use-package flycheck
  :ensure t
  :init (global-flycheck-mode))
```

더 자세한 정보와 문제 해결 방법은 [Flycheck 문서](https://www.flycheck.org/en/latest/user/troubleshooting.html)를 확인해 봐요.

## Emacs Lisp 배우기

Emacs Lisp에 관한 가장 좋은 문서는... 바로 Emacs에 함께 딸려 와요!
[Emacs Lisp Reference](https://www.gnu.org/software/emacs/manual/elisp.html)를 보려면
`C-h i`를 누르고 Elisp 항목을 찾거나, Help &rarr; More Manuals
&rarr; Emacs Lisp Reference를 선택해요. 일부 배포판에는 이 매뉴얼이 없을 수도 있는데,
그럴 때는 [온라인](https://www.gnu.org/software/emacs/manual/elisp.html)에서 찾을 수 있어요.

Elisp가 완전히 처음이라면, 같은 방법으로 열리는
[Introduction to Emacs Lisp](http://www.emacswiki.org/emacs/EmacsLispIntro)를 읽어 봐요.

## Emacs Lisp 모범 사례와 규칙

Emacs 매뉴얼에는 Emacs Lisp [Coding Conventions](https://www.gnu.org/software/emacs/manual/html_node/elisp/Coding-Conventions.html)에 관한 절이 있어요.
GitHub에서 커뮤니티가 관리하는 [Style Guide](https://github.com/bbatsov/emacs-lisp-style-guide)도 있어요.
