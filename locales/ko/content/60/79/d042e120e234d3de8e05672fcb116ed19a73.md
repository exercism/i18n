# 힌트

## 일반

- `set-nth ( elt n seq -- )`, `change-nth ( i seq quot -- )`,
  `push ( elt seq -- )`, `pop ( seq -- elt )`은 모두 시퀀스 인자를 *변경*하고,
  그 결과를 스택에 남기지 않아요. 변경 자체가 바로 효과예요.

## 1. 새 모자이크

- [`arrays`][arrays]에 있는 `<array>`는 길이와 채울 값을 받아서
  새 배열을 반환해요.

## 2. 타일 놓기

- `set-nth`가 대입을 처리하지만, 기대하는 인자 순서는
  `( elt n seq -- )`이고 입력은 `( row position colour -- )`로 들어와요.
  `kernel`에 있는 `spin ( x y z -- z y x )`는 한 단어로 세 값을
  스택에서 재배열해서 `set-nth`가 원하는 순서로 자리 잡게 해줘요.

## 3. 타일 떼어내기

- "이 위치를 `f`로 설정하기", 작업 2와 같은 모양이지만, 먼저 `f`를
  스택에 push해야 해요.

## 4. 타일 색 다시 칠하기

- `change-nth`는 지정한 위치의 요소에 대해 쿼테이션을 실행하고
  그 결과를 다시 저장해요.

## 5. 스냅샷

- [`kernel`][kernel]에 있는 `clone`은 독립적인 복사본을 반환해요.

## 6. 보관

- `push`는 벡터 끝에 요소를 제자리에서 덧붙여요.

## 7. 반환

- `pop`은 벡터의 마지막 요소를 제거하고 반환해요.
