# 지침

입력 텍스트가 주어지면, 이를 전치해서 출력해요.

대략적으로 말하면, 행렬의 전치는 다음과 같아요:

```text
ABC
DEF
```

는 다음과 같아져요:

```text
AD
BE
CF
```

행은 열이 되고, 열은 행이 돼요.
[transpose][]를 참고해요.

입력의 행 길이가 서로 다르다면, 다음과 같이 처리해요:

- 왼쪽은 공백으로 채워요.
- 오른쪽은 채우지 않아요.

따라서 다음 행렬을 전치하면:

```text
ABC
DE
```

다음과 같아져요:

```text
AD
BE
C
```

그리고 다음을 전치하면:

```text
AB
DEF
```

다음과 같아져요:

```text
AD
BE
 F
```

일반적으로 입력의 모든 문자는 전치된 출력에도 있어야 해요.
즉, 입력 텍스트의 어떤 열에서 맨 아래 행이 공백만으로 이루어져 있다면, 그에 대응하는 출력 행은 오른쪽 끝 열에 그 공백을 담아야 해요.

[transpose]: https://en.wikipedia.org/wiki/Transpose
