# 힌트

## 일반

- 읽기 단어들은 [`io`][io]에 있고, 문자열 스트림 생성자와
  `with-string-writer`는
  [`io.streams.string`][io.streams.string]에 있어요.
- writer를 플러시하는 작업에서는 같은 스트림을 두 번 다뤄야 할 때
  로컬(`::`와 `:>`)을 쓰면 본문을 읽기 좋게 유지할 수 있어요.

## 1. 전부 들어 봐요

- 단어 하나면 돼요: `stream-contents`.

## 2. 메시지 수를 세어요

- `stream-lines`는 스트림을 줄 단위 배열로 나누고,
  `length`는 개수를 반환해요.

## 3. 마지막 호출을 되돌려 보내요

- 위에서처럼 `stream-lines`를 쓰고, 그다음 `last`, 그다음
  `ascii`의 `>upper`를 써요.

## 4. 메시지를 방송해요

- `stream-write`로 메시지를 쓰고, `stream-flush`로 밀어내요.
  writer를 두 번 사용하니 `::` 로컬을 써요:
  `:: broadcast ( message writer -- ) message writer stream-write
  writer stream-flush ;`.

## 5. 쿼테이션의 출력을 캡처해요

- 단어 하나면 돼요: `with-string-writer`. 컴파일러가 쿼테이션
  인자를 꿰뚫어 볼 수 있도록 닫는 `;` 뒤에 `inline`을 붙여요:
  `: capture ( quot -- captured ) with-string-writer ; inline`.
