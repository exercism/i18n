# 힌트

## 일반

- Go의 타입에 대해 더 알아보려면 [Tour of Go: Basic Types][basic types]를 확인해 봐요.
- Go의 타입 변환에 대해 더 알아보려면 [Tour of Go: Type Conversions][type conversions]를 확인해 봐요.

## 1. 시간당 생산되는 정상 자동차 수 계산하기

- 백분율(인자로 전달돼요)은 0에서 100 사이의 숫자예요. 이 백분율을 조금 더 다루기 쉽게 하려면, 먼저 100으로 나눠 봐요.
- 정상적으로 생산된 자동차 수를 구하려면, 100으로 나눈 백분율에 생산된 자동차 수를 곱해요.
- 두 수를 곱할 때는 두 수의 타입이 같아야 해요.
  필요하다면 [타입 변환][type conversions]을 사용해요.

## 2. 분당 생산되는 정상 자동차 수 계산하기

- 먼저 시간당 정상 자동차 생산량을 계산해요.
  이때 이전 단계에서 만든 `CalculateProductionRatePerHour` 함수를 사용할 수 있어요.
- 시간당 자동차 생산량을 알면, 시간당 생산량을 60(한 시간의 분 수)으로 나눠서 분당 생산량을 구할 수 있어요.
- 결과를 `int`로 형변환하는 것을 잊지 마세요.

## 3. 생산 비용 계산하기

- 먼저 자동차 10대씩 몇 묶음이 있는지 계산해요.
  자동차 수를 10으로 나누면 구할 수 있어요.
- 그다음 자동차가 몇 대 남는지 계산해요. ([나머지 연산자][modulo operator]가 이때 유용해요.)
- 비용을 구하려면, 묶음 수에 자동차 10대를 생산하는 비용을 곱하고, 남은 자동차 수에 자동차 한 대를 생산하는 비용을 곱해요.
