# 소개

[C# `Attribute`](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/)는 클래스, 메서드, 열거형, 필드, 속성 또는 [지원되는 다른](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/#attribute-targets) 선언에 메타데이터를 연결하도록 선언을 꾸미는 방법을 제공해요.

선언 앞 줄에 `ClassAttribute`나 `FieldAttribute`를 붙이는 식으로 특성을 적용할 수 있어요:

```csharp
[Class]
class MyClass
{
    [Field]
    int myField;
}
```

이렇게 선언적으로 붙인 메타데이터는 코드에 추가적인 구조화된 정보를 연결할 뿐, 동작 자체를 바꾸지는 않아요. 하지만 코드의 다른 부분에서 이 메타데이터를 이용해 대상의 동작 방식을 바꾸거나, 기능을 추가하거나 변경 또는 제거하거나, 일부 기능을 제한할 수 있어요.

[미리 정의되어 예약된 특성](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/attributes/general#conditional-attribute)도 많이 있어요. 예를 들어 `Flags`, `Obsolete`, `Conditional` 같은 것들이 있는데, 각각의 자세한 내용은 C# 문서에서 찾아볼 수 있어요. [`Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute) 같은 특성의 전체 이름은 관례상 `FlagsAttribute`이지만, 선언에 적용할 때는 _Attribute_ 접미사를 생략할 수 있다는 점을 기억해요.
