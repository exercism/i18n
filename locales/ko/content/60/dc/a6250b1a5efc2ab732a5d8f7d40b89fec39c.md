# 소개

Batch 스크립트는 주로 Windows Command Prompt(cmd.exe)에서 명령을 실행하는 데 사용하는 스크립트 언어예요.
일련의 명령줄 명령을 통해 작업을 자동화하고, 파일을 관리하고, 시스템 환경을 제어할 수 있어요.

Batch 스크립트는 단순하지만, 간단한 파일 작업부터 좀 더 복잡한 자동화 과정까지 폭넓은 작업을 처리할 수 있어요.

Batch 파일은 `.bat` 또는 `.cmd` 확장자를 가지며, Windows 명령 인터프리터가 직접 실행할 수 있어요.

Batch 스크립트의 유연성 덕분에, 일상적인 작업을 자동화하거나 나만의 명령줄 도구를 만들어야 하는 시스템 관리자와 개발자, 고급 사용자에게 강력한 도구가 돼요.
