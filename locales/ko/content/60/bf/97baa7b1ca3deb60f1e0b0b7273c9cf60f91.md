# 지침

국제 자원봉사자들로 구성된 소방대의 일원이에요.
팀이 국제적이다 보니, 지난 몇 번의 출동에서 불타는 건물 내부의 온도를 추정하면서 화씨와 섭씨를 서로 변환하느라 귀중한 시간을 낭비했어요.
시간을 아끼고 사람도 지키기 위해, 국제 팀을 위해 화씨와 섭씨를 자동으로 변환해 주는 프로그램을 만들기로 해요.

## 1. 화씨를 섭씨로 변환하기

`tempToC` 함수를 구현해서 화씨 `Integer` 온도를 소수점 둘째 자리까지 반올림한 섭씨 `Float` 값으로 변환해요.
섭씨 온도는 다음과 같이 정의해요: T(°C) = (T(°F) - 32) / 1.8.

```haskell
> tempToC 32
0.00
```

## 2. 섭씨를 화씨로 변환하기

`tempToF` 함수를 구현해서 섭씨 `Float` 온도를 화씨 값으로 변환해요.
안전을 위해 결과를 **올림**해서 **그다음으로 큰** `Integer`로 만들어요.
화씨 온도는 다음과 같이 정의해요: T(°F) = T(°C) × 1.8 + 32.

```Haskell
> tempToF 4
40
```
