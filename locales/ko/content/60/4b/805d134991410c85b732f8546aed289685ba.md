# 개요

순회란 컬렉션(`Array`, `Hash` 등)을 하나씩 따라가면서 각 객체에 어떤 작업을 하는 것을 말해요.

순회는 Ruby의 핵심 개념이고, 정렬(`sort_by`), 그룹화(`group_by`), 매핑(`map`), 리듀싱(`reduce`) 등 다양한 곳에 쓰여요.
컬렉션을 반복할 때 루프를 쓰기보다 순회를 사용하는 것이 Ruby다운 방식이라, 순회를 가장 자주 보게 될 거예요.

배열의 각 단어를 출력하는 간단한 순회는 다음과 같아요:

```ruby
words = %w[the cat sat on the mat]
words.each do |word|
  puts word
end

# Output:
# the
# cat
# sat
# on
# the
# mat
```

이 예제에서는 `Array#each` 메서드를 호출하고, 매개변수 하나(`word`)를 받아 출력하는 _블록_을 넘겼어요.

Enumerable 메서드는 서로 연결할 수도 있어요.
예를 들어 `each` 뒤에 `.with_index`를 연결하면 객체의 값뿐만 아니라 인덱스도 함께 출력할 수 있어요:

```ruby
words = %w[the cat sat on the mat]
list = words.map.with_index { |word, index| "#{index}. #{word}" }
puts list

# Output:
# 0. the
# 1. cat
# ...
# 5. mat
```

`Hash` 객체를 순회하는 것은 `Array` 객체를 순회하는 것과 똑같아요. 다만 블록이 키와 값, 두 개의 인자를 받는다는 점만 달라요:

```ruby
pet_names = {cat: "bob", horse: "caris", mouse: "arya"}
words.each { |animal, name| ... }

# The two arguments should be put in brackets when chaining
words.each.with_index { |(animal, name), index| ... }
```

위에서 설명한 메서드들은 [`Enumerable` 모듈][enumerable-module]의 일부예요.
이 모듈은 `Array`, `Hash`를 비롯해 순회 기능이 필요한 다른 클래스에도 포함되어 있어요.

[enumerable-module]: https://docs.ruby-lang.org/en/master/Enumerable.html
