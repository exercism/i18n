# 안내

이 연습 문제에서는 프리랜서가 고객과 특정 프로젝트의 가격에 대해 이야기할 수 있도록 돕는 코드를 작성해요. 고객을 위한 비용을 빠르게 계산하는 몇 가지 유틸리티 함수를 만들 거예요.

## 1. 시급으로 일당 계산하기

고객이 프리랜서에게 연락해 요금을 문의해요.
프리랜서는 **_하루에 8시간을 일한다고_** 설명해요.
그런데 프리랜서는 프로젝트의 시급만 알고 있어요.
시급이 주어졌을 때 일당을 추정할 수 있도록 도와줘요.

프리랜서의 시급을 담은 인자 `hourlyRate`를 받는 `dailyRateFrom(hourlyRate:)` 함수를 구현해요.
이 함수는 시급을 기준으로 일당을 반환해야 해요.

```swift
dailyRateFrom(hourlyRate: 60)
// Returns 480.0
```

반환되는 일당은 `Double`이어야 해요.

## 2. 시급과 할인이 주어졌을 때 월당 계산하기

때로는 고객이 프리랜서를 더 오랜 기간 고용하는 데 관심을 보여요.
프리랜서는 고객에게 할인을 제공할 의향이 있지만, 고객이 최소 한 달 이상 고용할 때만 그래요.
한 달에는 총 **_근무일 22일_**이 있어요.
시급과, 정가에 적용하려는 할인율이 주어졌을 때 월당을 계산하도록 도와줘요. 결과는 가장 가까운 정수로 반올림해요.

프리랜서의 시급을 담은 `hourlyRate`와, 프리랜서가 고객에게 제공하려는 할인을 담은 `withDiscount` 인자를 받는 `monthlyRateFrom(hourlyRate:withDiscount:)` 함수를 구현해요.
이 함수는 가장 가까운 정수로 반올림한 월당을 반환해야 해요.

```swift
monthlyRateFrom(hourlyRate: 77, withDiscount: 10.5)
// Returns 12129
```

## 3. 예산, 시급, 할인이 주어졌을 때 근무일 수 계산하기

어느 날, 프로젝트 관리자가 프리랜서에게 고정 예산이 있는 프로젝트를 제안해요.
고정 예산과 프리랜서의 시급이 주어졌을 때, 예산이 모두 소진될 때까지 며칠을 일하게 되는지 계산하도록 도와줘요.
이 경우 프리랜서는 고용 기간과 상관없이 항상 할인을 제공할 의향이 있다는 점을 고려해요.
결과는 _반드시_ 가장 가까운 정수로 **내림**해야 해요.

다음 인자들을 받는 `workdaysIn(budget:hourlyRate:withDiscount:)` 함수를 구현해요:
- `budget`은 프로젝트의 예산을 담고 있어요.
- `hourlyRate`는 프리랜서의 시급을 담고 있어요.
- `withDiscount`는 프리랜서가 고객에게 제공하려는 할인을 담고 있어요.

이 함수는 프리랜서가 프로젝트에서 일하게 될 근무일 수를 내림해서 반환해야 해요.

```swift
workdaysIn(budget: 20000, hourlyRate: 80, withDiscount: 11.0)
// Returns 35.0
```
