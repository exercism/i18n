# 소개

값이 프로그램 밖으로 나가서 네트워크로, 로그 파일로, 소켓을 통해 이동할 때는 반드시 *텍스트*여야 해요. 값을 전송하려고 묶을 때 자주 등장하는 Factor 관용구가 세 가지 있어요. 직렬화기 `unparse`, 복사하지 않고 시퀀스를 들여다보는 slice 변형, 그리고 한 표현 안에서 스택에서 여러 필드를 뽑아낼 수 있게 해 주는 다중 입력 cleave 컴비네이터예요.

```factor
USING: combinators kernel prettyprint sequences strings ;

123 unparse .                          ! => "123"
"NS-1024" 2 head-slice >string .       ! => "NS"
1 2 [ + ] [ - ] 2bi . .
! => -1
! => 3
```

`unparse`는 Factor 파서의 역연산이에요. `dup unparse parse`는 원래 값으로 돌아와요. `head-slice`는 `head`처럼 새 시퀀스를 할당하는 대신 *뷰*(`slice` 객체)를 반환해요. 영역을 잠깐 들여다보기만 하면 될 때 유용하죠. `2bi`, `3bi`, `2tri`, `3tri`는 cleave 계열을 두세 개의 스택 입력으로 확장해요.
