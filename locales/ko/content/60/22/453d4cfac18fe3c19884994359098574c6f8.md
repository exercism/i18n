# 소개

## 비교

Go에서는 다음과 같은 관계 연산자와 동등 연산자로 숫자를 비교할 수 있어요.

| 비교              | 연산자    |
| ------------------| --------- |
| 같음              | `==`      |
| 같지 않음         | `!=`      |
| 작음              | `<`       |
| 작거나 같음       | `<=`      |
| 큼                | `>`       |
| 크거나 같음       | `>=`      |

비교 결과는 항상 불리언 값이에요. 즉 `true` 또는 `false` 중 하나예요.

```go
a := 3

a != 4 // true
a > 5  // false
```

위의 비교 연산자는 문자열을 비교할 때도 사용할 수 있어요.
이때는 사전 순서가 적용돼요.
예를 들어 볼까요?

```Go
	"apple" < "banana"  // true
	"apple" > "banana"  // false
```

## `if`문

Go의 조건문은 다른 언어의 조건문과 비슷해요.
모든 조건 연산의 기반이 되는 타입은 `bool` 타입이고, 이 타입은 `true` 또는 `false` 값을 가질 수 있어요.
조건문은 여러 조건을 확인하는 흐름 제어 수단으로 자주 쓰여요.

특정한 경우를 확인할 때는 `if`문을 사용할 수 있어요. 아래처럼 조건이 `true`이면 `if`문이 코드를 실행해요.

```go
var value string

if value == "val" {
    return "was val"
}
```

확인할 경우가 여러 개인 상황에서는 `else if`문과 `else`문을 사용해 여러 `if`문을 이어 붙일 수 있어요.

```go
var number int
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

`if`문에는 짧은 초기화 문을 함께 넣을 수도 있어요. 이 문으로 `if`문에서 사용할 변수를 하나 이상 초기화할 수 있어요.
예를 들어 볼까요?

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```

> 참고: 초기화 문에서 만든 변수는 if문이 끝난 뒤에는 스코프를 벗어나요.
