# 힌트

## 일반

- [범위][range]에 대한 공식 문서를 읽어 보세요.

## 1. 랭크 범위 정의하기

- 범위를 만드는 [특수 연산자][range-creation-operator]가 있어요.

## 2. 파일 범위 정의하기

- 범위를 만드는 [특수 연산자][range-creation-operator]가 있어요.
- 값을 직접 몰라도 문자 코드 포인트를 쓸 수 있는 [특수 문법][unicode-code-points]이 있어요.

## 3. 랭크 범위를 랭크 배열로 변환하기

- 범위는 `Enumerable` 프로토콜을 구현해요.
- 열거 가능한 자료 구조를 배열로 바꾸는 [내장 함수][enum-to-list]가 있어요.

## 4. 파일 범위를 파일 배열로 변환하기

- 범위는 `Enumerable` 프로토콜을 구현해요.
- 열거 가능한 자료 구조의 요소를 바꾸면서 배열로 변환하는 [내장 함수][enum-map]가 있어요.
- [비트스트링 특수 폼][bitstring-special-form]을 사용하면 코드 포인트를 문자열로 바꿀 수 있어요.
