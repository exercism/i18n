# 테스트

phix 바이너리가 PATH에 있다면 다음 명령을 입력해요:

```bash
p test 
```
이 명령은 테스트 파일(test.exw)을 실행해요.

phix 바이너리가 PATH에 없다면, Windows에서는 이렇게 입력해요

```cmd
\path\to\p.exe test
```

Linux:

```bash
/path/to/p test
```

## 테스트 건너뛰기

연습 문제를 푼다는 것은 그 문제의 모든 테스트를 통과한다는 뜻이에요.
기본적으로 test.exw 파일의 모든 테스트가 실행돼요.
테스트를 건너뛰려면 줄 맨 앞에 대시 두 개(Phix의 표준 주석 표시)를 붙여요.

참고로 테스트는 tests.toml의 include=false 플래그를 따르지 않아요. 오히려 test.exw 작성자가
Exercism 사이트(예: 트랙 통계 수집)를 위해 실제 상황을 반영하도록 그 파일에서 직접 관리할
책임이 있어요. 하지만 트랙 자체에서는 테스트 생성기와 테스트 러너를 비롯해 이런 플래그를 전혀
사용하지 않아요.
