# 지침 추가

## 힌트

`countWords`가 반환하는 값은 키가 `string`이고 값이 `int`인 해시 테이블 타입이면 무엇이든 괜찮아요.

해시 테이블(다른 프로그래밍 언어에서는 "딕셔너리"나 "맵"이라고도 불러요)은 `tables` 모듈에 구현되어 있어요. [documentation]을 참고해요.

예를 들어, `countWords`가 `TableRef[string, int]` 타입을 반환할 수도 있어요.

```nim
proc countWords*(sentence: string): TableRef[string, int] =
  ...
```

[documentation]: https://nim-lang.org/docs/tables.html
