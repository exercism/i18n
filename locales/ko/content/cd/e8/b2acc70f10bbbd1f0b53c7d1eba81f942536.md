# 지침

이 연습 문제에서는 1980년대의 고전 아케이드 게임인 [Pac-Man][Pac-Man]의 몇 가지 규칙을 구현해요.

과제는 모두 여섯 개이고, 그중 네 개는 게임 상태와 관련된 규칙이에요.

> _함수에서 인자가 어떻게 만들어지는지는 신경 쓰지 말고, 인자들을 조합해 원하는 결과를 반환하는 데만 집중해요._


## 0. 파워 상태 정의하기

파워가 실제로 켜져 있음을 나타내는 값을 가진 `PowerOn`이라는 변수를 정의해요.

```powershell
> $PowerOn
True
```

## 1. Pac-Man이 유령을 먹는지 정의하기

`EatGhost` 함수를 정의해요. 이 함수는 두 개의 매개변수(_Pac-Man이 파워 펠릿을 활성화했는지_와 _Pac-Man이 유령에 닿아 있는지_)를 받고, Pac-Man이 유령을 먹을 수 있는지를 나타내는 불리언 값을 반환해요.
이 함수는 Pac-Man이 파워 펠릿을 활성화했고 유령에 닿아 있는 경우에만 `True`를 반환해야 해요.

```powershell
> EatGhost -ActivePower $false -TouchingGhost $true
False
```

## 2. Pac-Man이 점수를 얻는지 정의하기

`Score` 함수를 정의해요. 이 함수는 두 개의 매개변수(_Pac-Man이 파워 펠릿에 닿아 있는지_와 _Pac-Man이 점에 닿아 있는지_)를 받고, Pac-Man이 점수를 얻었는지를 나타내는 불리언 값을 반환해요.
이 함수는 Pac-Man이 파워 펠릿이나 점에 닿아 있으면 `True`를 반환해야 해요.

```powershell
> Score -TouchDot $true -TouchPowerPellet $true
4
```

## 3. Pac-Man이 지는지 정의하기

`Lose` 함수를 정의해요. 이 함수는 두 개의 매개변수(_Pac-Man이 파워 펠릿을 활성화했는지_와 _Pac-Man이 유령에 닿아 있는지_)를 받고, Pac-Man이 지는지를 나타내는 불리언 값을 반환해요.
이 함수는 Pac-Man이 유령에 닿아 있고 파워 펠릿을 활성화하지 않았으면 `True`를 반환해야 해요.

```powershell
> Lose -ActivePower $false -TouchingGhost $true
True
```

## 4. Pac-Man이 이기는지 정의하기

`Win` 함수를 정의해요. 이 함수는 세 개의 매개변수(_Pac-Man이 모든 점을 먹었는지_, _Pac-Man이 파워 펠릿을 활성화했는지_, _Pac-Man이 유령에 닿아 있는지_)를 받고, Pac-Man이 이기는지를 나타내는 불리언 값을 반환해요.
이 함수는 Pac-Man이 모든 점을 먹었고 3번에서 정의한 매개변수를 기준으로 지지 않았으면 `True`를 반환해야 해요.

```powershell
> Win -EatenAllDots $false -ActivePower $true -TouchingGhost $false
False
```

## 5. 승리 조건에 대한 Synopsis 작성하기

마지막 함수로 돌아가서, 게임에서 이기는 방법을 짧게 설명하는 `Synopsis` 섹션을 주석 블록에 추가해요.
설명은 최소 열 글자 이상이어야 해요.

```powershell
function MyFunc($Arg) {
    <#
    .DESCRIPTION
    This is a demonstration of the comment-based help with the description keyword.
    #>
}
```
