## 1. 정규식을 사용하여 카드를 생성하는 데 필요한 정보 추출하기

- `\p{L}`는 모든 언어의 모든 종류의 글자와 일치해요.
- 다음 정규식을 사용하면 정보를 추출할 수 있어요:
  ```julia
  re = r"""»(.*)«                     # title
           \ –\ (.*?)                 # name
           (?:\ \((.*?)\)|)           # optional pronouns
           (?:,\ from\ (.*?)|).       # optional organisation
           \ Start:\ (.*?),\          # start time
           (?:Q&A:\ (.*?),\ |)        # optional Q&A time
           End:\ (.*)                 # end time
        """x
  ```
