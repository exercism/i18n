# 자리 표시자

## 일반

- `rand` [숫자 함수][rand-func]로 난수를 만들 수 있어요.
- `srand` [숫자 함수][srand-func]는 `rand`의 시드를 설정하는 데 유용해요.

## 미로 생성

완벽한 미로를 만드는 데는 어떤 알고리즘을 써도 괜찮아요. [재귀 백트래커][recursive-backtracker]가 좋은 선택이에요.

## 상자 그리기 문자

| 문자 | 이름 | 유니코드 |
|:---------:|:--------------------------------------|:--------|
|     ┌     | 상자 그리기 가는 선, 아래쪽과 오른쪽 |  U+250C |
|     ─     | 상자 그리기 가는 선, 가로 |  U+2500 |
|     ┬     | 상자 그리기 가는 선, 아래쪽과 가로 |  U+252C |
|     ┐     | 상자 그리기 가는 선, 아래쪽과 왼쪽 |  U+2510 |
|     │     | 상자 그리기 가는 선, 세로 |  U+2502 |
|     └     | 상자 그리기 가는 선, 위쪽과 오른쪽 |  U+2514 |
|     ┴     | 상자 그리기 가는 선, 위쪽과 가로 |  U+2534 |
|     ┘     | 상자 그리기 가는 선, 위쪽과 왼쪽 |  U+2518 |
|     ├     | 상자 그리기 가는 선, 세로와 오른쪽 |  U+2520 |
|     ⇨     | 오른쪽을 향한 흰색 화살표 |  U+21E8 |

[srand-func]: https://www.gnu.org/software/gawk/manual/html_node/Numeric-Functions.html#index-srand_0028_0029-function
