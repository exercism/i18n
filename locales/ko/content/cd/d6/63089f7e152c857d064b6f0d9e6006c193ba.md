# 디버깅

테스트가 실패하면, 무엇이 잘못됐는지와 어떤 입력에 대한 것인지를 설명하는 메시지가 표시돼요. "표준 출력"으로 출력된 내용도 함께 표시된다는 점을 활용할 수도 있어요. `println!`을 사용하면 표준 출력에 쓸 수 있어요:

```rust
println!("Debug message");
```

중괄호 `{}`를 사용하면 변수나 표현식의 값을 출력할 수 있어요:

```rust
let secret_number = 4321;
println!("My banking password is {}, which is better than {}.", secret_number, 1200 + 34);
```

모든 타입을 이렇게 출력할 수 있는 건 아니고, 사용자에게 명확하게 보여줄 수 있는 타입만 가능해요. 예를 들어 벡터(배열)는 이렇게 출력할 수 없는데, 벡터를 사용자에게 어떻게 보여줘야 할지 명확하지 않기 때문이에요! 이런 다른 타입들은 `println!` 매크로에 `{:?}`를 사용해서 _디버그 형식_을 쓰라고 알려주면 돼요. 이 표현은 개발자만 보도록 의도된 것이에요. 예를 들면:

```rust
let words = vec!["hello", "world"];
println!("words that are often combined: {:?}", words);
```

편리한 `dbg!` 매크로도 있는데, 큰 표현식을 여러 변수 선언으로 나누지 않고도 그 자리에서 디버깅하는 데 쓸 수 있어요.

다음과 같은 표현식이 있다고 가정해봐요:

```rust
"hello world".split(' ').collect::<Vec<_>>().join("-")
```

이제 `collect` 호출이 무엇을 반환하는지 보고 싶어요. 이렇게 하면 돼요:

```rust
let my_temporary_debug_variable = "hello world".split(' ').collect::<Vec<_>>();
println!("{:?}", my_temporary_debug_variable);
my_temporary_debug_variable.join("-")
```

하지만 이건 너무 번거로워요! 디버깅하자고 멋진 표현식을 다시 쓰고 싶지는 않아요. 자, 무대에 등장시켜 볼까요: `dbg!`

```rust
dbg!(
    "hello world".split(' ').collect::<Vec<_>>()
).join("-")
```

공백은 그저 보기 좋으라고 넣은 것뿐이에요. 어떤 표현식이든 `dbg!()`로 감쌀 수 있고, 그러면 그 값이 (디버그 형식으로) 출력돼요. 그다음에는 `dbg!`가 애초에 없었던 것처럼 그 값을 더 큰 표현식에서 계속 사용할 수 있어요.

즐거운 디버깅 되세요!
