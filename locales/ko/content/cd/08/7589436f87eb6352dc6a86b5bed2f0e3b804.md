# 지시 사항

우리는 모두 생물학적 부모로부터 DNA라는 화학적 설계도를 물려받아요. 이 설계도는 우리 몸이 어떻게 만들어지는지에 영향을 줘요. 알려진 모든 생명체는 DNA에 의존해요!

> 참고: 이 연습 문제를 풀기 위해 뉴클레오타이드나 DNA에 대해 이해할 필요는 없어요.

DNA는 다른 화학 물질들이 길게 이어진 사슬이고, 그중 가장 중요한 것은 아데닌, 사이토신, 구아닌, 티민이라는 네 가지 뉴클레오타이드예요. DNA 사슬 하나에는 이 네 가지 뉴클레오타이드가 수십억 개나 들어 있을 수 있고, 이들이 나타나는 순서가 중요해요!
DNA에서 이 뉴클레오타이드들이 배열된 순서를 "DNA 서열"이라고 해요.

DNA 서열은 이 네 가지 뉴클레오타이드의 순서 있는 모음으로 나타내는데, 흔히 "ATTACG"처럼 문자를 나열한 문자열로 표현해요. 이건 6개의 뉴클레오타이드로 이루어진 DNA 서열이에요.
'A'는 아데닌, 'C'는 사이토신, 'G'는 구아닌, 'T'는 티민을 나타내요.

DNA 서열을 나타내는 문자열이 주어지면, 각 뉴클레오타이드가 몇 개씩 있는지 세어요.
문자열에 A, C, G, T가 아닌 문자가 들어 있으면 유효하지 않은 것이므로 오류를 알려 줘야 해요.

예를 들어:

```
"GATTACA" -> 'A': 3, 'C': 1, 'G': 1, 'T': 2
"INVALID" -> error
```
