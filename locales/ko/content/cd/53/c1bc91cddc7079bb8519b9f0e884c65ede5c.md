# 소개

Kotlin의 `when`은 여러 선택지 중에서 하나를 고르는 조건식이에요.
Java의 `switch`와 비슷하지만, `if` ... `else if` ... `else`를 길게 이어 붙인 것보다 훨씬 유연해요.

`if`처럼 `when`도 값을 만들어 내는 식으로 사용할 수 있어요.

## 값 매칭하기

`when` 뒤 괄호 안에 비교할 값을 넣어요.
각 분기가 그 값을 하나씩 비교하다가 일치하는 분기에서 멈춰요:

```kotlin
val animal = "chicken"
val type = when (animal) {
    "chicken" -> "bird"
    "poodle" -> "dog"
    else -> "unknown"
}
// type => "bird"
```

- 각 분기는 `pattern -> result` 형태로 작성해요.
- 분기는 위에서 아래로 차례대로 확인하고, 일치하는 분기를 찾으면 거기서 멈춰요.
  가장 먼저 일치한 분기만 실행돼요.
- 위에 나열되지 않은 값은 `else`로 처리해요. `if` 문을 이어 붙일 때 마지막에 쓰는 `else`와 비슷해요.

이런 방식은 [패턴 매칭][pattern-matching]과 비슷해요.
`pattern` 자리에는 비교할 값을 그대로 쓸 수도 있고, `is`를 써서 타입으로 비교할 수도 있어요:

```kotlin
fun typeText(subject: Any): String {
    return when(subject) {
        is Animal -> "Animal"
        is Fruit -> "Fruit"
        is String -> "Text"
        else -> "Unknown"
    }
}
```

`in`을 써서 범위, 컬렉션, 문자열 등 `contains` 메서드를 가진 대상에 값이 포함되는지 확인할 수도 있어요:

```kotlin
fun describe(number: Int, position: String) {
    // Range
    when(number) {
        in 1..10 -> println("From 1 to 10")
        in 11..20 -> println("From 11 to 20")
    }

    // Collection
    when(number) {
        in listOf(2, 4, 6) -> println("small even")
        in listOf(3, 5, 7) -> println("small odd")
    }

    // String
    when(position) {
        in "center middle" -> println("inner")
        in "left right boundary" -> println("outer")
    }
}
```

## 가드 조건

값을 비교할 때는 패턴 뒤에 `if`를 붙여 추가 조건을 달 수 있어요.
이런 조건을 가드 조건이라고 해요.

```kotlin
val x = 5
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else -> "other"
}
// description => "x is 5, y is even"
```

`else if`도 사용할 수 있어요.

```kotlin
val x = 7
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else if y % 2 == 0 -> "y is an even number"
    else -> "other"
}
// description => "y is an even number"
```


## 조건 매칭하기

또는 값을 생략하고 각 분기에 불리언 조건을 직접 쓸 수도 있어요:

```kotlin
val x = 5
val y = 8
val description = when {
    x % 2 != 0 -> "x is odd"
    y % 2 == 0 -> "y is even"
    else -> "neither condition matched first"
}
// description => "x is odd"
```

여기서도 분기는 위에서 아래로 확인하고, 조건이 `true`인 첫 번째 분기만 실행돼요.

## `when`을 식으로 사용하기

`when`의 결과 값을 사용할 때(변수에 대입하거나 함수에서 반환하는 등)는 가능한 모든 경우를 다뤄야 해요.

- 값을 비교하는 경우, 가능한 값을 모두 처리한 게 아니라면(예를 들어 `Boolean`이나 `enum`의 모든 값) `else`를 추가해요.
- 조건을 비교하는 경우에는 `else` 분기가 꼭 필요해요. 컴파일러는 조건이 모든 경우를 다룬다는 걸 알 수 없기 때문이에요.

```kotlin
fun label(n: Int): String = when (n) {
    0 -> "zero"
    1 -> "one"
    else -> "other"
}
```
