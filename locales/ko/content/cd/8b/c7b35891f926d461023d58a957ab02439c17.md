# 안내

이 연습 문제에서는 만남 시뮬레이션을 구현해요.
이를 통해 Julia의 핵심 패러다임인 다중 디스패치의 기초를 익힐 수 있어요.

~~~~exercism-important
For this exercise, all function definitions should be a single-line declaration with no if/else logic.
~~~~

일반적으로 만남이란 한 개체 `a`가 다른 개체 `b`를 만나 반응하는 것을 말해요.

```julia
encounter(a, b) = "$(name(a)) meets $(name(b)) and $(meets(a, b))."
```

먼저 고양이와 개가 만나면 무슨 일이 일어나는지 시뮬레이션해 봐요.

## 1. 사용자 정의 타입 정의하기

먼저 추상 타입 `Pet`을 추가해요.

그다음 `Cat`과 `Dog` 타입을 `Pet`의 하위 타입으로 정의해요.
각 타입에는 `name` 필드가 하나씩 있어요.

## 2. 반려동물의 이름 알아내기

반려동물의 이름을 반환하는 `name()` 함수를 구현해요.

```julia-repl
julia> fido = Dog("Fido")
Dog("Fido")

julia> name(fido)
"Fido"
```

## 3. 고양이와 개가 만나면 벌어지는 일 정의하기

다음 만남에 대한 `meets()` 메서드를 구현해요:

- 개 두 마리가 만나면 서로 **sniff** 해요.
- 고양이가 개를 만나면 개에게 **hisses** 해요.
- 개가 고양이를 만나면 고양이를 **chases** 해요.
- 고양이 두 마리가 만나면 **slink** 해요.

```julia-repl
julia> ginger = Cat("Ginger")
Cat("Ginger")

julia> meets(ginger, fido)
"hisses"
```

## 4. 두 개체 사이의 만남 정의하기

이름이 있는 두 개체가 만나면 어떤 일이 일어나는지 알려주도록, `encounter()` 함수를 메서드 하나로 구현해요.

```julia-repl
julia> encounter(ginger, fido)
"Ginger meets Fido and hisses."
```

## 5. 반려동물 사이의 만남에 대한 대체 반응 정의하기

산책하다가 [말](https://www.dw.com/en/horse-takes-daily-stroll-through-frankfurt-without-owner/a-47833431)처럼 다른 반려동물을 만나면 어떻게 될까요?

- 반려동물이 알아보지 못하는 다른 반려동물을 만나면 **is cautious** 해요.

```julia-repl
julia> bella = Horse("Bella")
Horse("Bella")

julia> encounter(fido, bella)
"Fido meets Bella and is cautious."
```

## 6. 반려동물이 모르는 것을 만났을 때의 대체 동작 정의하기

반려동물이 만날 수 있는 대상 중에는 반려동물이 아닌 것도 많아요. 자동차, 사람, 식물, 자연재해, 소행성… 그럼 그때는 어떻게 될까요?

- 반려동물이 한 번도 본 적 없는 것을 만나면 **runs away** 해요.

```julia-repl
julia> colnago = Bicycle("Colnago")
Bicycle("Colnago")

julia> encounter(ginger, colnago)
"Ginger meets Colnago and runs away."
```

## 7. 일반적인 대체 동작 정의하기

우리 시뮬레이션에서는 다른 만남도 얼마든지 일어날 수 있어요.
자동차가 개를 만나기도 하고, 두 전자가 서로 만나 상호작용하기도 하죠…

모든 만남을 미리 다루는 것은 불가능하니, 일반적인 대체 동작을 구현해 볼게요.

- 알지 못하는 두 사물이나 존재가 서로 만나면 **nothing happens** 해요.

```julia-repl
julia> γ1 = Photon("γ1")
Photon("γ1")

julia> γ2 = Photon("γ2")
Photon("γ2")

julia> encounter(γ1, γ2)
"γ1 meets γ2 and nothing happens." 
# This is true, photons just pass through each other.
```
