# 소개

친구 Eliud는 할머니 Tigist에게서 농장을 물려받았어요.
할머니는 발명가였고, 뭔가를 지나치게 복잡하게 만드는 경향이 있었어요.
닭장에는 가져갈 수 있는 모든 달걀의 위치를 나타내는, 부호화된 숫자를 보여 주는 디지털 디스플레이가 있어요.

Eliud는 닭장에 실제로 있는 달걀의 개수를 보여 주는 프로그램을 작성해 달라고 부탁해요.

위치 정보의 부호화는 다음과 같이 계산해요:

1. 달걀이 나올 수 있는 자리들을 살펴보고, 달걀이 있으면 `1`, 빈 자리면 `0`을 적어요.
2. 그 숫자를 이진수에서 십진수로 변환해요.
3. 결과를 디스플레이에 보여 줘요.

예시 1:

```text
Chicken Coop:
 _ _ _ _ _ _ _
|E| |E|E| | |E|

Resulting Binary:
 1 0 1 1 0 0 1

Decimal number on the display:
89

Actual eggs in the coop:
4
```

예시 2:

```text
Chicken Coop:
 _ _ _ _ _ _ _ _
| | | |E| | | | |

Resulting Binary:
 0 0 0 1 0 0 0 0

Decimal number on the display:
16

Actual eggs in the coop:
1
```
