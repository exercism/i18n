# 지시 사항

이 연습 문제에서는 저울을 모델링해요.

## 1. 저울의 초기 상태를 만들어요

저울은 초기화될 때, 판매되는 지역에 따라 다른 공장 출하 설정을 참조해야 해요. 따라서 저울은 정밀도와 미터법 또는 야드파운드법 여부를 가지고 초기화될 수 있어야 해요.

`precision`(`Int32`형)과 `metric`(`Bool`형) 두 인자를 받는 `WeighingMachine#initialize` 메서드를 구현해요. `metric` 인자가 `true`이면 미터법을, 그렇지 않으면 야드파운드법을 사용해야 한다는 뜻이에요. 또한 initialize 메서드는 인스턴스 변수 `@weight`를 `0.0`으로 설정해야 해요.

```crystal
precision = 3
metric = true
vm = WeighingMachine.new(precision, metric)
```

## 2. 저울에 정밀도를 설정할 수 있게 해요

다양한 요구에 맞추기 위해, 각 저울은 정밀도(소수 구분 기호 뒤의 자릿수)로 사용자 정의할 수 있어요.

저울의 정밀도를 반환하는 `WeighingMachine#precision` 게터 메서드를 구현해요.

```crystal
precision = 3
metric = true
vm = WeighingMachine.new(precision, metric)
vm.precision
# => 3
```

## 3. 저울에 무게를 설정할 수 있게 해요

무게를 가져오고 설정할 수 있도록 `WeighingMachine#weight` 프로퍼티를 구현해요:

```crystal
precision = 3
metric = true
wm = WeighingMachine.new(precision, metric)
wm.weight = 60.5
wm.weight
# => 60.5

wm.weigh
# => 60.5
```

## 4. 저울이 미터법과 야드파운드법 단위를 전환할 수 있게 해요

단위를 설정할 수 있도록 `WeighingMachine#metric=` 프로퍼티를 구현해요. 이 프로퍼티는 불리언 값을 받아야 해요.

```crystal
precision = 3
metric = true
wm = WeighingMachine.new(precision, metric)
vm.weight = 60.5
wm.metric = false

vm.weigh
# => 133.377
```
