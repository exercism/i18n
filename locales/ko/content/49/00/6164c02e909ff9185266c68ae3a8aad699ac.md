# 지침

Ozan은 다가오는 로드트립을 위해 플레이리스트를 만들고 있어요. 같은 곡을 두 번 듣고 싶지는 않은데, 플레이리스트가 너무 길어져서 어떤 곡을 이미 추가했는지 기억하기 어려워졌어요.

Ozan의 음악 플레이어 API는 배열만 다룰 줄 알아서, 플레이리스트에 곡을 추가하기 전에 `Array.indexOf()`로 그 곡이 있는지 확인하는 코드를 작성해 보려고 해요. 안타깝게도 이 프로그램은 실행하는 데 시간이 너무 오래 걸려요. Ozan을 도와줘야 해요!

Ozan을 도우러 가보니, 그의 플레이리스트에 _오십만 개_의 곡이 들어 있다는 사실에 깜짝 놀라게 돼요. 어쩌면 플레이리스트를 더 효율적으로 다룰 수 있는 다른 데이터 구조를 알고 있을지도 몰라요.

## 1. 중복된 곡 제거하기

`removeDuplicates` 함수를 구현해요. 이 함수는 플레이리스트를 _매개변수_로 받아서 모든 곡이 중복되지 않는 새로운 플레이리스트를 _반환_해요.

```javascript
const playlist = [
  'Court and Spark - Joni Mitchell',
  'Big Yellow Taxi - Joni Mitchell',
  'Court and Spark - Joni Mitchell',
];

removeDuplicates(playlist);
//=> ['Court and Spark - Joni Mitchell', 'Big Yellow Taxi - Joni Mitchell']
```

## 2. 곡이 이미 추가되었는지 확인하기

`hasTrack` 함수를 구현해요. 이 함수는 플레이리스트와 곡을 _매개변수_로 받아서, 플레이리스트에 그 곡이 있는지를 나타내는 불리언을 _반환_해요.

```javascript
const playlist = [
  'The Fashion Show - Grace Jones',
  'Dr. Funkenstein - Parliament',
];

hasTrack(playlist, 'Dr. Funkenstein - Parliament');
//=> true

hasTrack(playlist, 'Walking in the Rain - Grace Jones');
//=> false
```

## 3. 곡 추가하기

`addTrack` 함수를 구현해요. 이 함수는 플레이리스트와 곡을 _매개변수_로 받아서, 그 곡이 포함된 새로운 플레이리스트를 _반환_해요.

```javascript
const playlist = ['Selma - Bijelo Dugme'];

addTrack(playlist, 'Atomic Dog - George Clinton');
//=> ['Selma - Bijelo Dugme', 'Atomic Dog - George Clinton']

addTrack(playlist, 'Selma - Bijelo Dugme');
//=> ['Selma - Bijelo Dugme', 'Atomic Dog - George Clinton']
```

## 4. 곡 삭제하기

`deleteTrack` 함수를 구현해요. 이 함수는 플레이리스트와 곡을 _매개변수_로 받아서, 그 곡이 포함되지 않은 새로운 플레이리스트를 _반환_해요.

```javascript
const playlist = [
  'The Treasure - Fra Lippo Lippi',
  'After the Fall - Klaus Nomi',
];

deleteTrack(playlist, 'The Treasure - Fra Lippo Lippi');
//=> ['After the Fall - Klaus Nomi']

deleteTrack(playlist, 'I Feel the Magic - Belinda Carlisle');
//=> ['After the Fall - Klaus Nomi']
```

## 5. 고유한 아티스트 나열하기

`listArtists` 함수를 구현해요. 이 함수는 플레이리스트를 _매개변수_로 받아서, 플레이리스트에 있는 고유한 아티스트의 목록을 _반환_해요. 곡 이름은 `<SONG> - <ARTIST>` 형식으로 되어 있다는 점에 주의해요.

```javascript
const playlist = [
  'All Mine - Portishead',
  'Sight to Behold - Devendra Banhart',
  'Sour Times - Portishead',
];

listArtists(playlist);
//=> ['Portishead', 'Devendra Banhart']
```
