# 개요

Factor는 무작위성과 관련된 기능을 `random` 보캐뷸러리 안의 제네릭 워드 하나에 모아요:

```
random ( obj -- elt )
```

이 워드는 인자에 따라 다르게 동작해요:

- **정수** `n`을 주면 `[0, n)` 범위의 무작위 정수를 돌려줘요;
- **시퀀스**를 주면 무작위 원소 하나를 돌려줘요;
- 연관 구조, 해시 집합, `uniform-distribution` 튜플도 지원해요.

이 워드를 바탕으로 만들어진 시퀀스 도우미도 두 가지 있어요:

```factor
USING: random ;

{ 1 2 3 4 5 } randomize .   ! shuffle in place (Fisher–Yates)
{ 1 2 3 4 5 } 3 sample .    ! 3 distinct elements; error if too many
```

`randomize`는 시퀀스를 직접 바꾼 뒤 그 시퀀스를 반환해요. 원래 순서를 유지해야 한다면 먼저 `clone`을 호출해요.

## 무작위성은 어디에서 오나요

`random`은 `random-generator` 다이내믹 변수에 담긴 생성기를 읽어요. 기본값은 시스템 시계를 시드로 삼는 메르센 트위스터라서, 프로세스마다 값이 달라요. 콰테이션이 실행되는 동안에만 다른 생성기를 설치할 수도 있어요:

```
<mersenne-twister> ( seed -- rnd )
with-random        ( rnd quot -- )
```

```factor
USING: random random.mersenne-twister ;

42 <mersenne-twister> [ { 1 2 3 } randomize ] with-random .
! => the same ordering on every run
```

`with-random`은 콰테이션이 실행되는 다이내믹 범위 동안 `random-generator`를 바인딩할 뿐이라서, 이를 감싸는 워드는 `inline`으로 표시해야 콰테이션이 자기 결과를 스택에 남겨 호출한 쪽에서 쓸 수 있어요.

이 밖에도 `random`은 다른 분포를 위한 `random-bits`, `random-unit`, `uniform-random`, `normal-random`을 제공하고, 재현할 필요가 없거나 암호학적으로 안전해야 할 때 쓰는 `system-random-generator`, `secure-random-generator`도 제공해요.
