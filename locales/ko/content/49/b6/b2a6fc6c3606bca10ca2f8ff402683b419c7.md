# 지침

이 연습 문제에서는 친구와 함께 숫자 맞히기 게임을 해요. 규칙은 간단해요. `1`과 `100` 사이에서 숫자 하나를 몰래 고르면, 친구가 어떤 숫자를 골랐는지 맞혀봐요. 친구를 돕기 위해, 추측한 숫자가 고른 숫자(`42`)에 얼마나 가까운지에 따라 다르게 대답해요. 각 대답에 대한 규칙은 다음과 같아요.

- 추측한 숫자가 `42`라면: "Correct"
- 추측한 숫자가 `41`이나 `43`이라면: "So close"
- 추측한 숫자가 `41`보다 작다면: "Too low"
- 추측한 숫자가 `43`보다 크다면: "Too high"

추측에 대한 대답을 구현하는 네 가지 과제가 있어요.

## 1. 정답인 추측에 대답하기

정답인 추측에 대답하도록 `reply` 함수를 구현해요.

```gleam
reply(42)
// -> "Correct"
```

## 2. 가까운 추측에 대답하기

가까운 추측에 대답하도록 `reply` 함수를 수정해요.

```gleam
reply(41)
// -> "So close"
```

## 3. 너무 낮은 추측에 대답하기

너무 낮은 추측에 대답하도록 `reply` 함수를 수정해요.

```gleam
reply(25)
// -> "Too low"
```

## 4. 너무 높은 추측에 대답하기

너무 높은 추측에 대답하도록 `reply` 함수를 수정해요.

```gleam
reply(88)
// -> "Too high"
```
