# 지침

문자열로 표현된 이진수(예: '101010')를 기본 원리부터 십진수로 변환해요.

이진수에서 십진수로의 변환을 직접 구현해요. 이진수 문자열이 입력으로 주어지면, 프로그램은 십진수 결과를 출력해야 해요. 프로그램은 잘못된 입력도 처리해야 해요.

## 참고

- 변환은 직접 구현해요. 변환을 대신 해 주는 다른 기능을 사용하지 마세요.

## 이진법(2진법)에 대하여

십진법은 밑이 10인 수 체계예요.

10진법 표기에서 수 23은 10의 거듭제곱의 선형 조합으로 이해할 수 있어요:

- 가장 오른쪽 자릿수에는 10^0 = 1을 곱해요
- 그다음 자릿수에는 10^1 = 10을 곱해요
- ...
- *n*번째 자릿수에는 10^_(n-1)_을 곱해요.
- 이렇게 나온 값들을 모두 더해요.

그래서: `23 => 2*10^1 + 3*10^0 => 2*10 + 3*1 = 23 base 10`

이진법도 비슷하지만, 10의 거듭제곱 대신 2의 거듭제곱을 사용해요.

그래서: `101 => 1*2^2 + 0*2^1 + 1*2^0 => 1*4 + 0*2 + 1*1 => 4 + 1 => 5 base 10`.
