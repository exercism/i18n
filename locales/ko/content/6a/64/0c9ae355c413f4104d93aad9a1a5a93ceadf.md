# 지침

이 연습 문제에서는 무선 조종 자동차를 가지고 좀 더 많은 작업을 해봐요.

실험용 자동차가 개발되었고, 테스트 트랙은 양산형과 실험용 모델을 모두 다룰 수 있도록 수정해야 해요. 두 종류의 자동차는 이미 만들어졌으니, 테스트 트랙에서 둘 다 처리할 방법을 찾아야 해요.

게다가 양산형 자동차가 성과를 내기 시작했어요. 팀장은 양산형 자동차의 순위를 공개해서 경쟁 분위기를 이어가고 싶어 해요.

## 1. 같은 테스트 트랙에서 자동차를 운전할 수 있게 만들기

`IRemoteControlCar` 인터페이스에 메서드를 추가해서 두 종류의 자동차에 대한 `Drive()` 구현을 노출해 주세요.

```csharp
TestTrack.Race(new ProductionRemoteControlCar());
TestTrack.Race(new ExperimentalRemoteControlCar());
// this should execute without an exception being thrown
```

## 2. 테스트 트랙에서 서로 다른 모델이 이동한 거리를 비교할 수 있게 만들기

`IRemoteControlCar` 인터페이스에 속성을 추가해서 두 종류의 자동차에 대한 `DistanceTravelled` 속성의 구현을 노출해 주세요.

```csharp
var prod = new ProductionRemoteControlCar();
TestTrack.Race(prod);
var exp = new ExperimentalRemoteControlCar();
TestTrack.Race(exp);
prod.DistanceTravelled
// => 10
exp.DistanceTravelled
// => 20
```

## 3. 양산형 자동차의 순위를 매길 수 있게 만들기

`ProductionRemoteControlCar` 클래스에서 `IComparable<T>` 인터페이스를 구현해 주세요. 자동차의 기본 정렬 순서는 승리 수의 오름차순이어야 해요.

전달받은 자동차를 승리 수의 오름차순으로 정렬해서 반환하도록 정적 메서드 `TestTrack.GetRankedCars()`를 구현해 주세요.

```csharp
var prc1 = new ProductionRemoteControlCar();
var prc2 = new ProductionRemoteControlCar();
prc1.NumberOfVictories = 3;
prc2.NumberOfVictories = 2;
var rankings = TestTrack.GetRankedCars(prc1, prc2);
// => rankings[1] == prc1
```
