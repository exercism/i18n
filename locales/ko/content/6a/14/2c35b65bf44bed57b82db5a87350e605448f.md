# Match 기초

`match` 연산자는 값을 여러 패턴과 차례로 비교한 뒤, 어떤 패턴이 일치하는지에 따라 코드를 실행해요.

## 리터럴 일치

가장 기본적인 형태로, `match`는 값을 여러 후보와 비교하고 그중 처음 일치하는 갈래를 골라요. 갈래는 언제나 하나만 선택되고, 제어가 다른 갈래로 넘어가는 일은 없어요. `match`는 값으로 평가될 수 있는 표현식이에요.

```rust
enum TrollNumber {
    One,
    Two,
    Many,
    Lots,
}

fn estimated_value(troll_number: TrollNumber) -> u32 {
    match troll_number {
        TrollNumber::One => 1,
        TrollNumber::Two => 2,
        TrollNumber::Many => 10,
        TrollNumber::Lots => 100,
    }
}
```

## 빠짐없는 검사

패턴 일치는 언제나 빠짐없이 검사해요. 값이 패턴 사이로 빠져나갈 가능성이 조금이라도 있으면 Rust는 프로그램을 컴파일하지 않아요. 이때 도움이 되는 것이 `_`예요. `_`는 무엇이든 일치하는 와일드카드예요.

```rust
fn ordinal(n: u32) -> String {
    let ordinal = match n % 10 {
        1 => "st",
        2 => "nd",
        3 => "rd",
        _ => "th",
    };
    format!("{n}{ordinal}")
}
```

## 제어 흐름으로 사용하기

`match`는 값을 만들어 내는 표현식으로 쓸 수도 있지만, 순전히 제어 흐름을 위해서라면 문으로 쓸 수도 있어요.

```rust
// pretend that we've already filtered the key events relevant to the space bar (we don't want a keylogger)
fn space_timer(&mut self, event: Event) {
    match event {
        Event::KeyDown => self.timer = Some(Instant::now()),
        Event::KeyUp => {
            let duration = Instant::now() - self.timer.take().expect("can't have KeyUp without KeyDown");
            self.durations.push(duration);
        }
        // we don't care about any other events; the empty scope is a no-op
        _ => {}
    }
}
```

## 범위 일치

일치 갈래는 단일 값으로 지정하지 않아도 돼요. 범위로 지정할 수도 있어요.

```rust
fn ascii_type(ch: u8) -> &'static str {
    match ch {
        0..=31 => "non-printable control code",
        32..=126 => "printable character",
        127 => "DEL",
        _ => "extended ASCII; region-specific",
    }
}
```

## 또는 패턴

`|` 토큰을 구분자로 사용하면, 하나의 일치 갈래가 여러 후보 중 하나와 일치하도록 만들 수 있어요.

```rust
fn should_retry(error: std::io::Error) -> bool {
    use std::io::ErrorKind;

    match error.kind() {
        ErrorKind::TimedOut | ErrorKind::Interrupted => true,
        _ => false,
    }
}
```

## 구조적 일치와 바인딩

일치를 통해 특정 갈래 안에서 유효한 바인딩을 만들 수 있어요. 데이터를 담은 배리언트를 가진 열거형을 풀어낼 때 특히 유용해요.

```rust
/// Consume a result and proceed, logging any errors.
trait OrLog {
    fn or_log(self);
}

impl<E: std::fmt::Display> OrLog for Result<(), E> {
    fn or_log(self) {
        match self {
            // discard Ok results
            Ok(()) => {},
            // log errors
            Err(err) => println!("ERROR: {err}"),
        }
    }
}
```

이 주제는 `match-advanced` 개념에서 더 자세히 다뤄요.
