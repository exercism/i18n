# 병렬 문자 빈도의 개념

이 연습 문제는 외부 크레이트의 도움을 받으면 아주 다양한 풀이가 나올 수 있다는 점이 특징이에요. 다룰 분량을 감당할 수 있게 유지하려고, 이 문서에는 가능한 풀이 중 일부만 골라 담았어요. Crossbeam을 사용하는 풀이는 여기 나열된 것과 비슷한 개념 구성을 가지고, Rayon은 그중 일부만 필요로 해요.

- **불변성/명시적 가변성**
- **문자열**
  - `&str` 타입
- **유니코드**
  - 유니코드 메서드와 ASCII 메서드
- **슬라이스**
- **튜플**
- **구조 분해**
- **함수**
  - 고차 함수
  - 클로저

### 병렬성과 관련된 개념

- **채널**
- **`Mutex`와 `RwLock`**
- **퓨처**
- **참조 카운팅**

\*<sub>관련은 있지만 여기서는 합리적인 풀이에 해당하지 않아요</sub>

## 일반 사항

- 문자열: 특히 여기서는 `str`이 항상 관여해요.
- 유니코드: ASCII 메서드와 유니코드 메서드는 성능과 기능 면에서 서로 타협하는 부분이 있어요. 벤치마크가 유니코드 메서드를 쓰고 풀이가 ASCII 메서드를 쓰면 벤치마크 결과가 왜곡돼요.
- 이터레이터: 입력 전체를 순회하거나 입력의 일부 조각을 순회해요.
- 컬렉션: `HashMap`을 순회하면서 `Entry`를 사용해요. 보통 핸들은 `Vec`에 모아요.
- 참조
- 숫자: 특히 `Add` 트레이트
- `for`문: `move` 때문에 이터레이터 안에서는 스레드를 조인할 수 없어요.
- **선택** 가시성: 구현 세부 사항을 비공개로 유지해요
- **선택** 슬라이스: `.chunks()`는 워커 스레드를 위해 입력을 나눌 때 자주 쓰는 메서드예요. 또는 부분 슬라이스를 사용하기도 해요.
- **선택** 고차 함수: `HashMap`들은 이터레이터를 사용하는 고차 함수로 병합할 수 있어요.
- **선택** 타입: 입력을 나누기 위해 정수를 실수로 캐스팅해서 반올림을 적용할 수 있어요
- **선택** 크레이트

## 채널을 사용하거나 사용하지 않는 표준 라이브러리 접근법

- 병렬성 - 하위 주제: 스레드 생성/조인.
- 이터레이터 - 하위 주제: 지연 평가. 같은 이터레이터로 스레드를 생성하고 조인하면 병렬성이 사라져요.
- 라이프타임 - 하위 주제: `'static lifetime`과 명시적인 `move` 시맨틱
- 이터레이터/라이프타임 - 하위 주제: 소비하는 이터레이터. 이터레이터를 사용해서는 스레드를 조인할 수 없어요.
- Option 타입: 스레드나 채널의 결과를 언래핑
- 함수: 특히 스레드를 생성하려면 고차 함수가 필요해요. 클로저도 여기서는 선택지예요.

## 채널을 사용하는 표준 라이브러리 접근법

- 병렬성 - 하위 주제: 채널.
- 튜플: `mpsc::channel()`은 튜플을 반환해요
- 구조 분해: 대입할 때 튜플을 구조 분해할 수 있어요
- 라이프타임: `drop()`

## 공유 변수를 사용하는 다른 접근법

- 참조 카운팅: 참조 카운트되는 컬렉션으로 스레드 간에 집계 데이터를 공유해요.
- **덧붙이는 말**: 병렬성 - 하위 주제: 뮤텍스. 이 연습 문제에는 필요하지도, 유용하지도 않지만 흔히 등장하는 개념이에요. 관련: `RwLock`.

### 채널을 사용한 표준 라이브러리 예제

```rust
use std::collections::HashMap;
use std::thread;
use std::sync::mpsc;

pub fn frequency(input: &[&str], worker_count: usize) -> HashMap<char, usize> {
    let (tx, rx) = mpsc::channel();

    let _handles = input.chunks((input.len() as f64 / worker_count as f64).ceil() as usize)
        .map(|slice| slice.concat())
        .map(|slice| {
            let tx = tx.clone();
            thread::spawn(move || {
                let mut map: HashMap<char, usize> = HashMap::new();
                for chr in slice.chars().filter(|c| c.is_alphabetic()) {
                    if let Some(c) = chr.to_lowercase().next() {
                        (*map.entry(c).or_insert(0)) += 1;
                    };
                }
                tx.send(map).unwrap()
            })
        }).collect::<Vec<_>>();

    drop(tx);

    let mut result: HashMap<char, usize> = HashMap::new();
    for received in rx {
        for (c, count) in received {
            *result.entry(c).or_insert(0) += count;
        }
    }

    result
}
```

### `Arc`를 사용한 크레이트 예제

```rust
use std::collections::HashMap;
use std::iter::FromIterator;
use std::sync::Arc;
use dashmap::DashMap;

pub fn frequency(input: &[&str], worker_count: usize) -> HashMap<char, usize> {
    let map: Arc<DashMap<char, usize>> = Arc::new(DashMap::new());

    let handles = input
        .chunks((input.len() as f64 / worker_count as f64).ceil() as usize)
        .map(|slice| slice.concat())
        .map(|slice| {
            let map = map.clone();
            std::thread::spawn(move || {
                for c in slice.chars().filter(|c|c.is_alphabetic())
                  .flat_map(|c| c.to_lowercase().next()) {
                    *map.entry(c).or_insert(0) += 1;
                }
            })
        }).collect::<Vec<_>>();

    for h in handles {
        h.join().unwrap();
    }

    map.iter().map(|x| (*x.key(), *x.value())).collect()
}
```
