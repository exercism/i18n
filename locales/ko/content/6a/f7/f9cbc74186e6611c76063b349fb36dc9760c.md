# 소개

JavaScript에서 _템플릿 문자열_을 사용하면 문자열 안에 표현식을 넣을 수 있어요. 이를 문자열 보간이라고도 해요.
이 기능은 내장 전역 객체인 [`String`][string-reference]의 기능을 확장한 거예요.

JavaScript에서는 텍스트를 백틱으로 감싸면 템플릿 문자열을 만들 수 있어요.
템플릿 문자열을 쓰면 텍스트에 줄 바꿈이나 다른 특수 문자를 넣을 수 있을 뿐만 아니라, 변수와 다른 표현식도 넣을 수 있어요.

```javascript
const num1 = 1;
const num2 = 2;

`Adding ${num1} and ${num2} gives ${num1 + num2}.`;
// => Adding 1 and 2 gives 3.
```

위 예시에서 백틱(<code>\`\`</code>)은 템플릿 문자열을 나타내는 데 사용해요. `${...}`는 값을 치환할 때 사용하는 자리 표시자예요.
문자열이 아닌 타입은 _암시적_으로 문자열로 변환돼요.
이 주제는 [타입 변환][type-conversion-concept] 개념에서 다뤄요.
템플릿 문자열에는 모든 종류의 표현식을 사용할 수 있어요.

```javascript
const track = 'JavaScript';

`This track on exercism.org is ${track.toUpperCase()}.`;
// => This track on exercism.org is JAVASCRIPT.
```

문자열을 여러 줄로 나눠서 작성하고 싶을 때는 이렇게 해요:

```javascript
`This is an example of using template
strings to accomplish multiple
lines`;

/* => This is an example of using template
     strings to accomplish multiple
     lines
*/
```

템플릿 문자열을 쓰지 않고(즉, 백틱을 쓰지 않고) 일반 문자열 안에 줄 바꿈을 넣고 싶다면, 줄 바꿈 이스케이프 시퀀스 `\n`을 사용하면 돼요:

```javascript
'This is an example of using the newline escape sequence!\nWithout backticks';

/* => This is an example of using the newline escape sequence!
      Without backticks
*/
```

치환 기능을 활용하면, 출력 문자열이 무엇이 되어야 하는지 결정하는 로직을 넣을 수도 있어요.
이런 로직을 처리하는 한 가지 방법은 [삼항 연산자][ternary-operator]를 사용하는 거예요.
이 연산자는 `if/else`와 같은 조건부 기능을 조금 다른 형식으로 제공해요.

템플릿 문자열 문법에 로직을 넣으려면 이렇게 해요:

```javascript
const grade = 95;

`You have ${grade > 90 ? 'passed' : 'failed'} the exam.`;
// => You have passed the exam.
```
