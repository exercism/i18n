# 루프

Rust의 루프를 사용하면 멈추라고 할 때까지, 또는 특정 조건이 충족될 때까지 코드 블록을 반복해서 실행할 수 있어요.

가장 기본적인 형태의 루프는 `loop` 키워드를 사용해요:

```rust
fn main() {
    loop {
        println!("again!");
    }
}
```

위 코드는 무한 루프를 만들어요. 루프를 빠져나오려면 break 키워드를 사용해요:

```rust
fn main() {
    let mut count = 0;
    loop {
        println!("again!");
        count += 1;
        if count > 10 { break; }
    }
}
```

## `for`와 `while`을 사용하는 루프

`loop` 키워드 외에도 `for`와 `while`로 루프를 만들 수 있어요.

`for`문은 컬렉션이나 반복자의 원소를 순회할 때 사용해요.

```rust
fn main() {
    let a = [10, 20, 30, 40, 50];

    for x in a {
        println!("the value is: {x}");
    }
}
```

범위도 반복자이기 때문에 `for`문으로 범위를 순회하면 아주 편리해요:

```rust
fn main() {
    for x in 0..10 {
        println!("the value is: {x}");
    }
}
```

`while`문은 조건이 충족될 때까지 코드를 계속 반복해요. 앞의 예제를 `while`문으로 다시 작성하면 다음과 같아요:

```rust
fn main() {
    let a = [10, 20, 30, 40, 50];
    let mut index = 0;

    while index < 5 {
        println!("the value is: {}", a[index]);

        index += 1;
    }
}
```

루프에 대한 더 자세한 내용은 Rust 책의 [https://doc.rust-lang.org/book/ch03-05-control-flow.html#repetition-with-loops](repetition with loops)를 참고해요.
