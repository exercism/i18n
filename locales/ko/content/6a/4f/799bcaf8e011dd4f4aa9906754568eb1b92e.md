# 힌트

## 일반

- `movdqa`는 메모리 피연산자가 정렬되어 있다고 알려진 경우에만 사용해야 해요. 두 피연산자가 모두 레지스터일 때는 안전하게 사용할 수 있어요.
- `movdqu`는 어떤 정렬 상태에서도 동작해요.
- 메모리 주소는 정수 값으로 전달돼요. 처음 여섯 개의 정수 인자는 각각 `rdi`, `rsi`, `rdx`, `rcx`, `r8`, `r9`를 통해 함수에 전달돼요.

## 1. 두 트랙 섞기

- 16비트 레인을 위한 포화 부호 있는 덧셈은 `paddsw`예요.
- 세 메모리 주소 모두 16바이트로 정렬되어 있으므로, 정렬된 이동 변형인 `movdqa`가 적절해요. 이 주소들은 소스 피연산자로 직접 사용할 수도 있어요 (목적지로는 사용할 수 없어요).

## 2. 블리드 제거

- 16비트 레인의 포화 부호 있는 뺄셈은 `psubsw`예요.
- `track`은 정렬되어 있지만 `result`와 `bleed`는 정렬이 보장되지 않으므로, 정렬되지 않은 이동 변형인 `movdqu`가 필요해요.

## 3. 미터 합치기

- 8비트 레인의 포화 부호 없는 덧셈은 `paddusb`예요.
- 세 메모리 주소 모두 16바이트로 정렬되어 있으므로, 정렬된 이동 변형인 `movdqa`가 적절해요. 이 주소들은 소스 피연산자로 직접 사용할 수도 있어요 (목적지로는 사용할 수 없어요).

## 4. 페이드 적용하기

- 부호 있는 16비트 곱의 상위 16비트를 유지하는 곱셈은 `pmulhw`예요.
- 세 메모리 주소 모두 16바이트로 정렬되어 있으므로 `movdqa`가 적절해요. 이 주소들은 소스 피연산자로 직접 사용할 수도 있어요 (목적지로는 사용할 수 없어요).
- `track`과 `gains`는 모두 부호 있는 값으로 읽히며, 이는 `pmulhw`가 기대하는 방식이에요.
- 피연산자가 두 개인 명령어는 보통 목적지 피연산자를 덮어써요.
- 각 128비트 레지스터는 샘플 8개를 담고, `n`(네 번째 인자)은 항상 0이 아니며 `8`의 배수예요.
- 루프를 사용해 모든 샘플을 처리해야 하며, 반복할 때마다 16바이트(샘플 8개)씩 나아가요.

## 5. 트랙 감쇠하기

- 정수 SIMD에는 패킹된 나눗셈이 없으므로, 패킹된 부동소수점으로 변환한 뒤 나누고, 다시 되돌려 변환해요.
- 샘플은 16비트이므로 부동소수점으로 변환하기 전에 32비트로 확장해야 해요. 16비트 레인에서 32비트 레인으로 부호 있는 확장을 하는 명령어는 `pmovsxwd`예요.
- `pmovsxwd`는 64비트 메모리 피연산자를 받을 수 있어서, 단 한 단계로 샘플 4개를 불러와 확장해요.
- 확장된 정수는 `cvtdq2ps`로 패킹된 부동소수점으로 변환해요.
- 나누는 수는 이미 4개의 복사본으로 제공되는 32비트 정수예요. 부동소수점 나눗셈에 사용하기 전에 패킹된 부동소수점으로 변환해야 해요.
- 패킹된 단정밀도 나눗셈은 `divps`예요.
- 몫은 `cvttps2dq`로 패킹된 32비트 정수로 되돌려 변환하는데, 이 명령어는 항상 0 방향으로 버림해요.
- 각 결과 블록은 32비트 정수 4개이고, `n`(네 번째 인자)은 항상 0이 아니며 `4`의 배수예요.
- 루프를 사용해야 하며, 반복할 때마다 `samples`에서 8바이트(값 4개), `result`에서 16바이트(값 4개)씩 나아가요.
