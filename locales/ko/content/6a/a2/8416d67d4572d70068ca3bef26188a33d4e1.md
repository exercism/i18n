# 지침 추가

## 구현

twobucket 패키지에서 다음 시그니처를 가진 Go 함수 Solve를 구현해요:

```go
func Solve(sizeBucketOne,
	sizeBucketTwo, goalAmount int, startBucket string,
) (goalBucket string, numSteps, otherBucketLevel int, e error)
```

Solve는 네 가지 값을 반환해요: 목표를 이룬 버킷("one" 또는 "two"), 목표량에 도달하기까지의 이동/단계 수, 다른 버킷에 남은 리터, 그리고 오류 값이에요.
유효하지 않은 매개변수가 있거나 해답이 존재하지 않으면 오류를 반환해요.
