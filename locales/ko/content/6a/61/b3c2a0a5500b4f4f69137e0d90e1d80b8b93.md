설치
====

YAMLScript로 프로그램을 작성하려면 YAMLScript 명령줄 인터프리터를 설치해야
해요.
`ys`라는 이름의 바이너리 실행 파일이에요.
현재 다음 환경에서 동작해요.

* Linux / Intel
* Linux / ARM
* MacOS / Intel
* MacOS / ARM

> 참고: Windows 지원은 계획 중이지만 아직 사용할 수 없어요.

릴리스는 [GitHub에서 확인할 수 있어요](
http://github.com/yaml/yamlscript/releases).


## 자동 설치

Exercism YAMLScript 연습 문제를 풀려면 풀이 프로그램을 반복해서 고치면서 모든
테스트가 통과할 때까지 `make test`를 실행하면 돼요.

이게 전부예요!

`make test`를 처음 실행하면 해당 문제에 필요한 특정 버전의 `ys` 인터프리터를
`/path/to/exercism/yamlscript/.local/` 디렉터리에 설치하려고 해요.

해당 버전의 `ys`를 이미 `PATH` 어딘가에 설치해 두었다면, 조용히 `ys`
인터프리터를 올바른 위치로 복사해요.

그렇지 않으면 바이너리 릴리스 설치를 하도록 안내해요. 보통 몇 초면 끝나요.

그마저 실패하면(드물지만 가끔 있어요) 소스에서 자동으로 빌드하도록 안내해요.
몇 분 정도 걸릴 수 있지만 아주 안정적이고 따로 조작할 필요가 없어요.

이 과정은 `make test`를 처음 실행할 때만 겪게 돼요.
같은 버전의 `ys`를 사용하도록 설정된 문제는 모두 동일한 설치를 함께 사용해요.

> 참고: `make test`와는 별개로 `make install-ys` 명령을 사용할 수도 있어요.
> `make test`와 똑같은 설치 과정을 진행하지만, 그 뒤에 테스트는 실행하지
> 않아요.


YAMLScript 설치에 관한 더 자세한 내용은, 특히 Exercism 밖에서 사용할 때를
위한 내용은 [YAMLScript 설치 문서](
https://yamlscript.org/doc/install/)를 참고해요.
