# 테스트 러너 만들기

먼저, 테스트 러너 제작에 관심을 가져주셔서 감사해요!

시작하는 방법은 다음과 같아요:

1. 이미 존재하는 `...-test-runner`가 있는지 [저장소 목록](https://github.com/search?q=org%3Aexercism+test-runner&type=repositories)을 확인해요.
2. [이 디렉터리의 내용](/docs/building/tooling/test-runners)을 살펴보면서 테스트 러너를 만드는 일이 어떤 느낌인지 익혀요.
3. [Exercism 포럼][building-exercism]에 어떤 언어의 테스트 러너를 만들고 싶은지 알려주는 새 주제를 올려요.
4. 테스트 러너 저장소가 만들어지면, [테스트 러너 인터페이스](/docs/building/tooling/test-runners/interface)와 [모범 사례](/docs/building/tooling/best-practices) 문서를 참고하면서 구현을 진행해요.

저희 커뮤니티는 정말 친절하고 서로를 잘 도와주는 곳이라, 이 과정을 진행하는 동안 기꺼이 도움을 줄 거예요!
중간에 막히는 부분이 있으면 [Exercism 포럼][building-exercism]에 새 주제를 올리거나, 필요할 때 [exercism/exercism][exercism-repo]에 이슈를 새로 만들어 주세요 🙂
