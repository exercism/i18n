# 소개

## 정규 표현식

Elixir의 정규 표현식은 Java, JavaScript, Ruby 같은 다른 인기 언어들과 마찬가지로 **PCRE** 명세(**P**erl **C**ompatible **R**egular **E**xpressions)를 따라요.

`Regex` 모듈은 정규 표현식을 다루는 함수들을 제공해요. `String` 모듈의 일부 함수들도 정규 표현식을 인자로 받아요.

~~~~exercism/note
이 연습 문제는 문자 클래스, 수량자, 그룹, 캡처를 포함한 정규 표현식 문법을 이미 알고 있다고 가정해요.

정규 표현식 지식을 되새기고 싶다면 다음 자료 중 하나를 확인해 봐요: [Regular-Expressions.info](https://www.regular-expressions.info), [Rex Egg](https://www.rexegg.com/), [RegexOne](https://regexone.com/), [Regular Expressions 101](https://regex101.com/), [RegExr](https://regexr.com/).
~~~~

### 시길

정규 표현식을 만드는 가장 흔한 방법은 `~r` 시길을 사용하는 것이에요.

```elixir
~r/test/
```

모든 Elixir 시길은 `/`뿐만 아니라 [다양한 종류의 구분자][sigils]를 지원한다는 점에 주의하세요.

### 매칭

`=~/2` 연산자를 사용하면 `boolean` 결과를 반환하는 정규 표현식 매칭을 수행할 수 있어요. 또는 `Regex` 모듈과 `String` 모듈에 있는 `match?/2` 함수를 사용할 수도 있어요.

```elixir
"this is a test" =~ ~r/test/
# => true

String.match?("Alice has 7 apples", ~r/\d{2}/)
# => false
```

### 캡처

단순한 불리언 검사로 충분하지 않다면 `Regex.run/3` 함수를 사용해서 모든 캡처의 배열을 얻어요(매치가 없으면 `nil`을 얻고요). 반환된 배열의 첫 번째 원소는 항상 전체 정규 표현식에 대한 매치이고, 그다음 원소들은 매치된 그룹이에요.

```elixir
Regex.run(~r/(\d) apples/, "Alice has 7 apples")
# => ["7 apples", "7"]
```

### 수정자

정규 표현식의 동작은 특수 플래그를 덧붙여서 바꿀 수 있어요. 시길로 정규 표현식을 만들 때는 두 번째 구분자 뒤에 수정자를 추가해요.

자주 쓰이는 수정자는 다음과 같아요:
- `i` - 대소문자를 구분하지 않고 매칭해요.
- `u` - `\p` 같은 유니코드 전용 패턴을 사용할 수 있게 하고, `\w`, `\s` 같은 문자 클래스도 유니코드를 매칭하도록 해요.

```elixir
"this is a TEST" =~ ~r/test/i
# => true
```
