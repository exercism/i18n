# 소개

재귀는 함수가 자기 자신을 호출해서 함수 안의 코드를 반복하는 방법이에요.
루프를 도는 또 다른 방법이기도 해요. 루프와 마찬가지로, 함수는 언제 끝낼지 알기 위해 불리언 표현식을 검사해야 해요.
루프와는 달리, 끝나지 않는 재귀는 무한히 실행되지는 않아요.
각 함수 호출에서 사용하는 값은 스택에 각자의 프레임으로 놓일 수 있어요.
함수 호출이 차지하는 공간이 스택이 가진 공간보다 많아지면 스택 오버플로 오류가 발생해요.

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return i;
    printf("The number is %i\n", i++);
    printIncrement(i, maxValue);
}

int main() {
    printIncrement(1, 2);
    printf("After recursion");
    return 0;
}
```

그러면 다음과 같이 출력해요.

```
The number is 1
The number is 2
After recursion
```

재귀로 표현하면 루프로 표현할 때보다 더 읽기 쉽거나 더 이해하기 쉬운 상황도 있어요.
