# 지침

이 연습 문제에서는 좋아하는 요리책에 나오는 근사한 라자냐를 만들 수 있도록 코드를 좀 더 작성해 볼 거예요.

라자냐를 조리하는 데 걸리는 시간과 관련된 다섯 가지 과제가 있어요.

## 1. 예상 오븐 시간을 변경할 수 있게 하기

이전 과제에서 정의한 예상 오븐 시간(분)을 기준으로, 라자냐가 오븐에 들어간 후 지난 시간(분)을 매개변수로 받아 라자냐가 오븐에 얼마나 더 있어야 하는지 반환하는 개선된 `remainingMinutesInOven` 함수를 작성하려고 해요.
이전에는 `remainingMinutesInOven` 함수 바깥에 있는 `expectedMinutesInOven`이라는 상수 값에 의존했어요.
그런데 이 방식은 조금 복잡하게 느껴졌고, 예상 오븐 시간을 바꿀 수 없다는 점에서 유연하지도 않았어요.

깔끔하게 정리하기 위해, 라자냐가 오븐에 들어간 후 지난 시간(분)과 기본값이 40인 `expectedMinutesInOven` 매개변수를 받는 `remainingMinutesInOven` 함수를 정의해요.
이 함수는 이전 과제의 예상 오븐 시간(분)을 기준으로 라자냐가 오븐에 얼마나 더 있어야 하는지 반환해야 해요.

```swift
remainingMinutesInOven(elapsedMinutes: 30)
// Returns 10
remainingMinutesInOven(elapsedMinutes: 30, expectedMinutesInOven: 75)
// Returns 45
```

## 2. 층 개수를 다르게 지정할 수 있게 하기

이전에는 라자냐에 추가한 층의 개수를 매개변수로 받아, 각 층을 준비하는 데 2분이 걸린다고 가정했을 때 라자냐를 준비하는 데 몇 분이 걸렸는지 반환하는 `preparationTimeInMinutes` 함수를 작성했었어요.
그런데 이 함수가 마음에 꼭 들지는 않아요. 이 함수를 호출하려면 라자냐의 층 개수를 직접 세어야 하니까요. 그럴 시간이 어디 있겠어요?

좀 더 편하게 하려면, 라자냐의 여러 층을 나열하는 가변 인자 `String` 매개변수 `layers`를 받는 `preparationTimeInMinutes` 함수를 작성해요.
그러면 이 함수가 라자냐의 층 개수를 세어 필요한 준비 시간을 반환해요.

```swift
preparationTimeInMinutes(layers: "sauce", "noodles")
// Returns 4
preparationTimeInMinutes(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns 24
```

## 3. 면과 소스의 양 계산하기

라자냐를 만들기 시작하기 전에, 꿈에 그리던 라자냐를 만들 소스와 면이 충분한지 확인하고 싶어요.
라자냐의 면 층마다 면 3개가 필요해요.
라자냐의 소스 층마다 소스 0.2리터가 필요해요.

라자냐의 여러 층을 나열하는 가변 인자 `String` 매개변수 `layers`를 받는 `quantities` 함수를 정의해요.
그러면 이 함수가 요리를 만드는 데 필요한 면과 소스의 양을 계산해요. 결과는 `(noodles: Int, sauce: Double)` 타입의 튜플로 반환해야 해요.

```swift
quantities(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns (noodles: 9, sauce: 0.8)
quantities(layers: "sauce", "noodles", "sauce", "noodles", "meat", "noodles", "mozzarella")
// Returns (noodles: 9, sauce: 0.4)
```

## 4. 리터를 액량 온스로 제자리에서 변환하기

안타깝게도, 가지고 있는 소스의 부피는 리터가 아니라 액량 온스로 표시되어 있어요.
소스가 충분한지 알 수 있도록, `(noodles: Int, sauce: Double)` in-out 튜플 매개변수를 받아 소스의 양을 액량 온스로 변환하는 `toOz` 함수를 작성해요.
1리터는 33.814 액량 온스라는 점에 유의해요.

```swift
var amount = (noodles: 9, sauce: 0.8)
toOz(&amount)

amount
// Returns (noodles: 9, sauce: 27.0512)
```

## 5. 가장 잘 어울리는 와인 정하기

마지막으로, 라자냐와 함께 어떤 와인을 내야 할지 알고 싶어요.
라자냐에 고기와 소스보다 모차렐라, 리코타, 베샤멜이 더 많으면 화이트 와인을, 그렇지 않으면 레드 와인을 내야 한다고 들었어요.
라자냐의 여러 층을 나열하는 가변 인자 `String` 매개변수 `layers`를 받는 `redWine` 함수를 작성해요.
이 함수는 다섯 개의 중첩 함수를 사용해 라자냐에 있는 모차렐라, 리코타, 베샤멜, 소스, 고기 층의 개수를 구하고, 층 개수를 비교해 레드 와인을 내야 하는지 판단해서, 그렇다면 `true`를, 아니라면 `false`를 반환해요.

```swift
redWine(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns true
redWine(layers: "sauce", "noodles", "béchamel", "meat", "mozzarella", "noodles", "ricotta", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns false
```
