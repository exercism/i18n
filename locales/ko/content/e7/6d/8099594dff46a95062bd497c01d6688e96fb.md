# 소개

## 리터럴 패턴 매칭

`if/else` 식으로도 조건부 로직을 실행할 수 있지만, Haskell에는 조건부 로직을 실행하는 더 강력한 방법이 있어요: 바로 [패턴 매칭][pattern-matching]이에요.
패턴 매칭을 사용하면 값을 하나 이상의 _패턴_과 비교해 볼 수 있어요.
이런 패턴의 한 예가 _상수 패턴_으로, 값을 상수(예: `1` 또는 `"hello"`)와 비교해요.

함수를 정의할 때에는 패턴마다 별도의 함수 본문을 정의할 수 있어요.
이렇게 하면 간결하고 읽기 쉬운 코드를 작성할 수 있죠.
숫자, 문자, 리스트, 튜플 등 모든 데이터 타입에 패턴 매칭을 사용할 수 있어요.

예를 들어, 정수(`Int`)를 받아서 _0_에 _1_만큼 더 가깝게 만드는 간단한 함수는 이렇게 표현할 수 있어요:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero 1 = 0
```

패턴 매칭은 다른 패턴과 함께 사용할 때 진가를 발휘해요. 예를 들어 _변수 패턴_이 있어요:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero n = n - 1
```

위 예시는 _0_이 아닌 모든 입력을 똑같이 처리하기 때문에, 음수에 대해서는 잘못된 결과를 내놓아요.
이 문제는 `|` 기호로 표현하는, _가드_라고 불리는 조건부 패턴을 사용하면 해결할 수 있어요:

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
```

위 예시들에서는 가능한 모든 입력에 대응하는 패턴이 있는 것은 아니에요.
컴파일러가 이를 감지하고 경고를 출력하죠.
이것은 가능한 모든 경로를 처리해서 런타임 오류를 피하도록 도와주는, Haskell의 아주 유용한 기능이에요.
이를 _철저한 검사_라고 해요.
이 경고를 없애려면 모든 경우를 처리해야 해요.
_가드_ 안에서는 남은 모든 패턴을 처리하기 위해 `True`의 문법적 설탕으로 `otherwise` 식을 사용할 수 있어요.

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
    | otherwise = 0
```

패턴 매칭은 값을 위에서 아래로 각 패턴과 비교하면서, 일치하는 패턴을 찾으면 그 패턴에 연결된 로직을 실행해요.
**패턴의 순서가 중요해요!**
