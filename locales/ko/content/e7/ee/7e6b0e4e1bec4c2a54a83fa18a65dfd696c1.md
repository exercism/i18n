# 소개

Julia에서는 주로 세 가지 조건문을 사용해요:

- `if` 표현식
- 삼항 연산자
- 단축 평가

## `if` 표현식

Julia의 `if` 표현식은 다른 언어에서 본 것과 비슷해요:

```julia-repl
julia> function say_if_positive(n)
           if n > 0
               println("n is positive!")
           else
               println("n is not positive!")
           end
       end
say_if_positive (generic function with 1 method)

julia> say_if_positive(10)
n is positive!

julia> say_if_positive(-10)
n is not positive!
```

`if` 뒤의 불리언 표현식이 `true`로 평가되면 첫 번째 코드 블록이 실행되고 두 번째 블록은 건너뛰어요.
`if` 뒤의 불리언 표현식이 `false`로 평가되면 첫 번째 코드 블록은 건너뛰고 두 번째 블록이 실행돼요.
프로그램은 `end` 키워드 다음의 첫 번째 코드 줄부터 계속 실행돼요.

~~~~exercism/note
Julia에서 `end` 키워드는 모든 블록 표현식의 끝을 나타내요.
이 문법은 `if` 표현식이나 함수 정의에만 국한된 것이 아니에요.
~~~~

두 번째 코드 블록이 또 다른 `if` 표현식이 될 상황이라면, `elseif`를 쓰면 블록 안에 `if` 표현식을 중첩하지 않아도 돼요:

```julia-repl
julia> function dessert(fruit)
           if fruit == "apple"
               return "Apple Crumble"
           elseif fruit == "lemon"
               return "Lemon Meringue Pie"
           else
               return "Fruit Salad"
           end
       end
dessert (generic function with 1 method)

julia> dessert("apple")
"Apple Crumble"

julia> dessert("lemon")
"Lemon Meringue Pie"

julia> dessert("peach")
"Fruit Salad"
```

`if` 표현식이 경우 중 하나에 대해서만 코드를 실행하면 된다면 `else` 분기를 쓸 필요가 없어요.

## 삼항 연산자

간단한 `if-else` 문은 삼항 연산자 `a ? b : c`로도 쓸 수 있어요.
`a`가 참이면 `b`를 평가해요.
그렇지 않으면 `c`를 평가해요.

예를 들어 다음 함수는

```julia-repl
julia> function diagnose(heartrate)
           if heartrate > 100
               println("Elevated heart rate.")
           else
               println("Nominal heart rate or dead.")
           end
       end
diagnose (generic function with 1 method)
```

다음과 같이 쓸 수도 있어요.

```julia-repl
julia> diagnose(heartrate) = heartrate > 100 ? println("Elevated heart rate.") : println("Nominal heart rate or dead.")
diagnose (generic function with 1 method)
```

조건에 따라 변수에 다른 값을 할당하고 싶을 때 특히 유용해요.
`x = a ? b : c`는 `a`가 `true`이면 `x`에 `b`를 할당하고, 그렇지 않으면 `x`에 `c`를 할당해요.
예를 들면 다음과 같아요:

```julia-repl
julia> function patient_status(heartrate)
           status = heartrate > 0 ? "alive" : "dead"

           println("The patient is ", status)
       end

julia> patient_status(100)
The patient is alive

julia> patient_status(0)
The patient is dead
```

## 단축 평가

`&&`와 `||` 연산자로 여러 불리언 표현식을 연결하면, Julia는 전체 연결의 값을 결정하는 데 필요한 최소한의 표현식만 평가해요.

예를 들어 `n > 0 && k > 10`이라는 표현식 연결을 생각해 봐요.
`n`이 `5`라면 연결의 첫 부분인 `n > 0`이 `true`이고, 전체 표현식이 `true`인지 판단하려면 두 번째 표현식 `k > 10`을 평가해야 해요.
하지만 `n`이 `-5`라면 첫 번째 표현식이 `false`이기 때문에 연결 전체가 `true`가 **될 수 없어요**.

대신 `n > 0 || k > 10`을 생각해 보면 정반대예요.
`n`이 `5`라면 연결의 첫 부분인 `n > 0`이 `true`이고, 두 번째 표현식과 상관없이 전체 연결이 `true`라는 것을 알 수 있어요.
하지만 `n`이 `-5`라면 두 번째 표현식을 평가해야 해요.

이 동작을 이용하면 아주 짧은 `if` 문을 쓸 수 있어요:

```julia
if a
    b
end
```

는 다음과 같아요.

```julia
a && b
```

`&&`와 `||`로 이루어진 연결에서 마지막 표현식은 불리언 표현식이 아니어도 돼요.
이 기능은 이른 오류 처리나 반환에 자주 쓰이는 걸 볼 수 있어요.
예를 들어 위의 `dessert(fruit)` 함수를 사용하면 다음과 같아요:

```julia-repl
julia> function whats_for_dessert(fruit, allergic_to)
           fruit == allergic_to && return "I can't eat that, guess I'll not have dessert tonight!"

           return dessert(fruit)
       end
whats_for_dinner (generic function with 1 method)

julia> whats_for_dinner("apple", "peach")
"Apple Crumble"

julia> whats_for_dinner("apple", "apple")
"I can't eat that, guess I'll not have dessert tonight!"
```
