# 이름 있는 export 없음

이름이 `%{export.name}`인 [export](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/export)를 찾을 수 없어요. 이게 없으면 테스트가 통과하지 못해요.

이름이 `%{export.name}`인 export가 있는지 확인하고, 그 앞에 `export`를 붙여요:
```javascript
// exporting a "const"
export const %{export.name} = /*...*/

// exporting a named function declaration
export function %{export.name}() { /* ... */ }
```
