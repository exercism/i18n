# 안내

지금 롤플레잉 게임을 구현하고 있어요.
플레이어의 캐릭터는 다음과 같이 표현해요.

```rust
pub struct Player {
    health: u32,
    mana: Option<u32>,
    level: u32,
}
```

이 게임의 플레이어는 레벨 10에 도달해야 마나 풀을 사용할 수 있고, 이 마나 풀로 주문을 시전할 수 있어요.
그 전까지 플레이어의 마나는 `Option::None`이에요.

이 게임에서는 되살리기 기능과 주문 시전 기능, 두 가지를 구현하고 있어요.

`revive` 메서드는 플레이어가 정말로 죽었는지(체력이 0이 되었는지) 확인하고, 죽었다면 체력이 100인 새로운 Player 인스턴스를 반환해야 해요.
`revive` 메서드는 플레이어의 레벨을 그대로 유지해야 해요.
플레이어의 레벨이 10 이상이면 마나 100을 가진 상태로 되살아나요.
플레이어의 레벨이 10 미만이면 마나는 `Option::None`이어야 해요.

```rust
let dead_player = Player { health: 0, mana: Option::None, level: 2 };
dead_player.revive()
// Returns Player { health: 100, mana: Option::None, level: 2 }
```

체력이 1 이상인 플레이어에 대해 `revive` 메서드를 호출하면, 메서드는 `Option::None`을 반환해야 해요.

```rust
let alive_player = Player { health: 1, mana: Option::Some(15), level: 11 };
alive_player.revive()
// Returns Option::None
```

`cast_spell` 메서드는 플레이어에 대한 가변 참조와, 주문에 드는 마나를 나타내는 `mana_cost` 매개변수를 받아요.
시전한 주문이 입히는 피해량을 반환해요.

- 플레이어가 마나 풀을 사용할 수 없다면, 주문을 시전하려고 할 때 주문의 마나 비용만큼 체력이 줄어들어야 해요.
  반환되는 피해량은 0이어야 해요.

  ```rust
  let not_a_wizard_yet = Player { health: 79, mana: Option::None, level: 9 };
  assert_eq!(not_a_wizard_yet.cast_spell(5), 0)
  assert_eq!(not_a_wizard_yet.health, 74);
  assert_eq!(not_a_wizard_yet.mana, Option::None);
  ```

- 플레이어에게 마나 풀이 있지만 마나가 부족하다면, 메서드는 마나 풀에 영향을 주어서는 안 돼요.
반환되는 피해량은 0이어야 해요.

  ```rust
  let low_mana_wizard = Player { health: 93, mana: Option::Some(3), level: 12 };
  assert_eq!(low_mana_wizard.cast_spell(10), 0);
  assert_eq!(low_mana_wizard.health, 93);
  assert_eq!(low_mana_wizard.mana, Option::Some(3));
  ```

- 그 외의 경우에는 주문이 성공적으로 시전돼요.
  `mana_cost`는 플레이어의 마나 풀에서 차감돼요.
  반환되는 피해량은 주문의 마나 비용의 두 배여야 해요.

  ```rust
  let wizard = Player { health: 123, mana: Option::Some(30), level: 18 };
  assert_eq!(wizard.cast_spell(10), 20);
  assert_eq!(wizard.health, 123);
  assert_eq!(wizard.mana, Option::Some(20));
  ```

즐겁게 해봐요!
