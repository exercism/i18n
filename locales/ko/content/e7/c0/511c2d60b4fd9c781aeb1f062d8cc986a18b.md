# Exercism CLI

[Exercism CLI][cli]를 사용하면 학생들이 연습 문제를 내려받고 풀이를 사이트에 제출할 수 있어요. 테스트를 실행하는 트랙별 명령을 실행하는 `exercism test` 명령도 지원해요.

## 새 언어 추가하기

트랙별 테스트 명령은 [설정 파일][test-configurations]에 정의되어 있어요. 그 [설정 파일][test-configurations]에 항목을 추가하면 언어 지원을 넣을 수 있는데, 키는 트랙의 슬러그예요.

### 테스트 명령 플레이스홀더

트랙별 명령에서 사용할 수 있는 플레이스홀더는 세 가지예요:

- `{{test_files}}`: 테스트 파일 목록이에요. 공백으로 구분해요 (연습 문제의 `.meta/config.json` 파일에 있는 `.files.test` 키에서 찾을 수 있어요)
- `{{solution_files}}`: 풀이 파일 목록이에요. 공백으로 구분해요 (연습 문제의 `.meta/config.json` 파일에 있는 `.files.solution` 키에서 찾을 수 있어요)
- `{{slug}}`: 연습 문제의 슬러그예요 (트랙 루트 `config.json` 파일에 있는 연습 문제의 `slug` 키에서 찾을 수 있어요)

Arturo 언어에 대한 지원을 추가한 [예시 풀 리퀘스트][example-pr]가 여기 있어요.
