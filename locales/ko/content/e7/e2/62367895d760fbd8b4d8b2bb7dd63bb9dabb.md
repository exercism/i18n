# 지시 사항

이번 연습 문제에서는 개발자가 식별자 이름을 정리하는 데 도움이 되는 유틸리티 루틴 일부를 구현해요.

4개의 과제를 거치면서 `clean` 루틴을 차근차근 완성해 나가요. 유효한 식별자는 0개 이상의 문자와 밑줄로 이루어져요.

모든 경우에 입력 문자열은 nil이 아님을 보장해요. `clean` 함수에 빈 문자열이 전달되면 빈 문자열을 반환해야 해요.

빈 식별자는 아무런 효과가 없으니, 호출하는 쪽에서는 `clean` 루틴을 빈 식별자로 호출하지 않도록 해요.

## 1. 공백을 밑줄로 바꾸기

`clean` 함수를 구현해서 모든 공백을 밑줄로 바꿔요. 앞뒤에 있는 공백도 마찬가지예요.

```clojure
(clean "my   Id")
;;=> "my___Id"
```

## 2. 제어 문자를 대문자 문자열 "CTRL"로 바꾸기

`clean` 함수를 수정해서 제어 문자를 대문자 문자열 `"CTRL"`로 바꿔요.

```clojure
(clean "my\0Id")
;;=> "myCTRLId"
```

## 3. 케밥 케이스를 카멜 케이스로 변환하기

`clean` 함수를 수정해서 케밥 케이스를 카멜 케이스로 변환해요.

```clojure
(clean "à-ḃç")
;;=> "àḂç"
```

## 4. 그리스 소문자 생략하기

`clean` 함수를 수정해서 'α'부터 'ω'까지의 그리스 문자를 생략해요.

```clojure
(clean "MyΟβιεγτFinder")
;;=> "MyΟFinder"
```
