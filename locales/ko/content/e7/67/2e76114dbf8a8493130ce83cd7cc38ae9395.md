# 소개

많은 프로그램은 실제와 같은 상황을 시뮬레이션하기 위해 (겉보기에) 무작위한 값이 필요해요.

흔하고 익숙한 예로는 다음과 같은 것들이 있어요:

- 동전 던지기: `"H"` 또는 `"T"`인 무작위 값.
- 주사위 굴리기: 1부터 6까지의 무작위 정수.
- 카드 덱 섞기: 카드 목록의 무작위 순서.

컴퓨터로 진정한 무작위 값을 생성하는 것은 [놀랄 만큼 어려운 기술적 과제][web-truly-random]라서, 이런 결과를 "의사 난수(pseudorandom)"라고 부르는 것을 볼 수 있어요.

***중요***: 이 개념에서는 암호학적으로 안전한 난수는 다루지 *않아요*. 그건 훨씬 더 어려운 과제예요.

하지만 R은 통계 패키지에서 파생되었고 시뮬레이션에 자주 사용되기 때문에, 무작위 값을 생성하는 다양한 방법을 제공해요.
그 결과는 모델링, 시뮬레이션, 게임 등 대부분의 응용 분야에 충분히 좋아요.

## [복원 추출과 비복원 추출][yt-sampling-with-replacement]

빨간 공 3개와 초록 공 4개가 든 주머니가 있고, 그 주머니에서 공 하나를 무작위로 꺼낸다고 상상해 봐요.
두 번째 공을 꺼내려면 두 가지 방법이 있어요:

1. 첫 번째 공을 주머니에 다시 넣고 잘 흔든 다음 또 하나를 꺼내요.
   이제 공의 개수는 전과 같은 7개이고, *빨간 공과 초록 공의 비율도 같아요*.
2. 첫 번째 공을 탁자 위에 두고 두 번째 공을 꺼내요.
   이제 주머니에는 공이 6개뿐이고, *빨간 공과 초록 공의 비율은 첫 번째 공의 색에 따라 달라져요*.

1번은 복원 추출이고 2번은 비복원 추출이며, *둘은 서로 다른 결과를 줘요*.

## `sample`로 이산값 다루기

제한된 수의 이산값 중에서 고르려면 `sample()`을 복원 추출 또는 비복원 추출로 사용할 수 있어요.
정수나 문자열 등에 유용해요.

```R
sample(1:10, 5) # no repeats by default
#> [1] 8 3 4 2 6

sample(1:10, 5, replace = TRUE) # repeats are OK
#> [1] 10 10  7 10  9

languages <- c("Fortran", "R", "Python", "Julia")
sample(languages, 1)
#> [1] "Python"

sample(c("H", "T"), 5, replace = TRUE) # coin flips
#> [1] "T" "T" "H" "H" "H"

sample(c(TRUE, FALSE), 5, replace = TRUE) # alternative coin flips
#> [1] FALSE  TRUE FALSE  TRUE  TRUE
```

샘플링은 데이터 파이프라인에 잘 어울려요.
예를 들어 무작위 영숫자 문자열을 생성하려면 다음과 같이 해요:

```R
library(stringr)

c(letters, LETTERS, 0:9) |> sample(50) |> str_flatten()
#> [1] "5tX71jhbM9zUmKrpENBQyGYaZdJPVAx06leSF2s8gcfw3OviIH"
```

## 섞기

다른 여러 언어에는 시퀀스를 섞는 특별한 함수가 있어요.

R에는 shuffle 함수가 없어요.
*왜일까요?*

이유를 이해하려면 `sample` 함수를 다시 살펴봐요.

전체 형태는 `sample(x, size, replace = FALSE, prob = NULL)`이고, 여기서 `x`는 (보통) 샘플링할 시퀀스, `size`는 고를 항목의 수예요.

`replace`는 이미 이야기했는데, 기본값은 비복원 추출이에요.
지금은 `prob`은 잠시 잊어둬요. `prob`을 사용하면 `x`의 여러 원소에 서로 다른 가중치를 줄 수 있어요.

`size`를 생략하고 `x`만 넘기면 어떻게 될까요?

```R
x <- letters[1:6]
x
#> [1] "a" "b" "c" "d" "e" "f"
sample(x)
#> [1] "e" "a" "f" "b" "c" "d"
```

전형적인 R 스타일로, 벡터를 넣으면 벡터가 나오는 패턴이고 `size`의 기본값은 `length(x)`예요.

"`x`의 모든 원소를 비복원 추출로 샘플링하기"는 "`x` 섞기"를 좀 더 기술적으로 말한 것일 뿐이에요.

*그래서* `sample`이 이미 우리에게 필요한 일을 정확히 해 주기 때문에 `shuffle` 함수가 없는 거예요!

## 분포 다루기

위의 예제들은 모든 결과가 똑같이 나올 가능성이 있는 경우를 설명했어요.
예를 들어 `sample(1:100)`은 1부터 100까지 어떤 정수가 나올 가능성도 똑같아요.

이것을 `uniform` 분포라고 해요.

실제 세상의 많은 상황은 이보다 훨씬 복잡해요.
그래서 통계학자들은 "현실 세계"의 결과를 수학적으로 설명하기 위해 다양한 `distributions`를 만들어 냈어요.

## 부동소수점 수

### 균등 분포

똑같은 가중치를 가진 부동소수점 수 분포를 얻으려면 `runif()`를 사용해요 ("**r**andom-**unif**orm"에 집중하고, "run if"로 읽고 싶은 자연스럽지만 *틀린* 충동을 참아요).
`min`과 `max`를 모두 지정할 수 있지만 기본값은 각각 0과 1이에요.

```R
runif(5)  # generate 5 values
#> [1] 0.3038506 0.3527959 0.3319309 0.4846354 0.4386279

# generate 5 non-negative values <= 100.0
runif(5, max = 100)
#> [1] 79.70762 51.62232 52.85281 71.08571 63.94380
```
