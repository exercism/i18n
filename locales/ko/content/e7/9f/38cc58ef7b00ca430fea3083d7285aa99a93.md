# 힌트

## 1. 오븐 예상 시간을 분 단위로 정의하기

- 레시피에 명시된 [`number`][numbers] 값을 담아야 하는 [상수][constants]를 정의해요.
- 상수를 [`export`][export]해요.

## 2. 남은 오븐 시간을 분 단위로 계산하기

- 함수에서 [숫자를 명시적으로 반환][return]해요.
- 값을 빼려면 [뺄셈 수학 연산자][operators]를 사용해요.

## 3. 준비 시간을 분 단위로 계산하기

- 함수에서 [숫자를 명시적으로 반환][return]해요.
- 값을 곱하려면 [곱셈 수학 연산자][operators]를 사용해요.
- 각 층에 걸리는 시간(분)을 담은 추가 상수를 사용해요.

## 4. 총 작업 시간을 분 단위로 계산하기

- 함수에서 [숫자를 명시적으로 반환][return]해요.
- 앞서 구현한 다른 메서드 중 하나를 [호출][invocation]해요.
- 값을 더하려면 [덧셈 수학 연산자][operators]를 사용해요.
