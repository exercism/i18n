# 힌트

`i32`의 너비는 4바이트예요.

"메모리 인스턴스는... 바이트 벡터를 담아요. 벡터의 길이는 항상 WebAssembly 페이지 크기의 배수이고, 페이지 크기는 상수 65536으로 정의돼요."

[WebAssembly 명세: 메모리 인스턴스](https://webassembly.github.io/spec/core/exec/runtime.html#page-size)

"`memory.size` 명령은 메모리의 현재 크기를 반환해요. `memory.grow` 명령은 주어진 델타만큼 메모리를 키우고 이전 크기를 반환하거나, 메모리를 충분히 할당할 수 없으면 -1을 반환해요. 두 명령 모두 페이지 크기 단위로 동작해요."

[WebAssembly 명세: 메모리 명령](https://webassembly.github.io/spec/core/syntax/instructions.html#syntax-instr-memory)
