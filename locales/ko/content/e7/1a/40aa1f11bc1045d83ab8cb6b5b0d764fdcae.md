# 힌트

## 일반

- DFT
    - DFT의 정의에서 곧바로 계산할 수 있어요: `Xₖ = Σ xₙ * ℯ^(-2iπk * n/N)`
    - 복잡도는 `O(n²)`에 고정되어 있지만, 더 효율적으로 수행하는 방법도 있어요.
    - 루프는 일반적으로 행렬 곱셈보다 느려요.

- FFT
    - 서론에서 언급했듯이, FFT는 보통 분할 정복 전략으로 수행해요. 그래서 재귀가 아마 도움이 될 거예요. 하지만 `while`문이 배제되는 것은 아니에요 (오히려 더 효율적일 수도 있어요).
    - 알고리즘의 개요는 다음과 같아요:
        - 입력 벡터의 길이가 1 이하이면 입력 벡터를 반환해요. 그렇지 않으면...
        - 신호를 두 부분으로 나눠요. 짝수 인덱스의 원소는 `Xₑ`, 홀수 인덱스의 원소는 `Xₒ`예요.
        - 두 부분 모두에 FFT를 실행해요.
        - `f(n) = ℯ^(-2iπ * n/N)` 벡터를 만들어요 (`n`은 0부터 N/2-1까지의 값을 가져요).
        - 두 부분 `Xₑ`와 `Xₒ`는 완전한 벡터로 재결합돼요: `[Xₑ + f(n) * Xₒ; Xₑ - f(n) * Xₒ]`. 여기서 덧셈과 곱셈은 원소별로 이루어져요.
