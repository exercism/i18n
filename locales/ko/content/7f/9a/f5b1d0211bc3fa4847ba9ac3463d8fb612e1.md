# 지시 사항

서커스 쇼는 여러 공연이 순서대로 이어지는 구성이에요. 공연마다 속은 완전히
다르지만, 쇼를 구성하는 사람은 각 공연에서 똑같은 두 가지 정보를 필요로 해요.

이번 연습 문제는 한 파일에 여러 클래스를 작성하는 첫 번째 문제예요. 스텁에
추상 클래스가 들어 있으니, 나머지 클래스는 그 아래에 작성해요.

## 1. 세 가지 공연

각각 `$ACT`인 클래스 세 개를 작성해요.

| 클래스 | `name` | `minutes` |
| --- | --- | --- |
| `JUGGLING` | `"Juggling"` | 5 |
| `TUMBLING` | `"Tumbling"` | 3 |
| `TRAPEZE` | `"Trapeze at "` then the height then `"m"` | 8 |

`JUGGLING`과 `TUMBLING`은 인자 없이 만들어요. `TRAPEZE`는 높이를 미터
단위로 받아서 만들어요:

```sather
#JUGGLING
#TRAPEZE(4)
```

따라서 `#TRAPEZE(4).name`은 `"Trapeze at 4m"`예요.

## 2. 쇼

`CIRCUS_ACTS` 클래스에 루틴 세 개를 작성하는데, 각 루틴은 공연 순서를
`ARRAY{$ACT}` 타입으로 받아요.

**`total_minutes`**: 쇼 전체가 걸리는 시간이에요.

```sather
CIRCUS_ACTS::total_minutes(|#JUGGLING, #TUMBLING|)
-- => 8
```

**`billing`**: 공연들의 이름을 `", "` 기호로 이어 붙인 값이에요.

```sather
CIRCUS_ACTS::billing(|#JUGGLING, #TUMBLING|)
-- => "Juggling, Tumbling"
```

**`longest`**: 가장 오래 걸리는 공연의 이름이에요. 두 공연의 시간이 같으면
앞선 공연이 이겨요. 빈 쇼에는 가장 오래 걸리는 공연이 없으니 답은
`""`예요.

```sather
CIRCUS_ACTS::longest(|#JUGGLING, #TUMBLING|)
-- => "Juggling"
```

세 루틴 중 어느 것도 공연이 어떤 종류인지 물어보면 안 돼요.
