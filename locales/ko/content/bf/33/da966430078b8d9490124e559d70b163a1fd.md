# 힌트

## 일반

- 콜백 함수는 호출하는 함수에 인자로 전달되는 함수예요.
- 콜백 함수는 호출하는 함수의 명세를 따라야 해요.

## 1. 성공 메시지로 알리기

- 가져온 API 함수 `notify`를 사용해요.
- `notify`에 객체를 전달해요. 객체에는 `message` 속성이 있어야 해요. 메시지 값이 무엇이어야 할지 생각해 봐요.
- JSDoc 타입 힌트에 유의해요. 함수는 값을 반환하면 안 돼요.

## 2. 오류 메시지로 알리기

- 가져온 API 함수 `notify`를 사용해요.
- `notify`에 다른 객체를 전달해요. `message` 속성이 있어야 해요. 메시지 값은 이전 부분과 달라야 해요.
- 함수 정의 위에 있는 [JSDoc] 주석에 유의해요:
  - 함수는 값을 반환하면 안 돼요.

## 3. 과일을 주문하기

- 이미 가져온 `order` 함수를 사용해요.
- JSDoc 타입 힌트에 유의해요. 함수는 인자 세 개를 받고 값을 반환하면 안 돼요.
- 앞서 만든 콜백을 order 함수의 인자로 재사용해요.

## 4. 작업을 더 간결한 함수로 리팩터링하기

- 이전 과제의 함수를 재사용해요.
- JSDoc 타입 힌트에 유의해요. 함수는 인자 두 개를 받고 값을 반환하면 안 돼요.
- 주문을 넣기 위해 과일 가게에 보낼 요청을 나타내는 객체로 인자들을 합쳐요.
