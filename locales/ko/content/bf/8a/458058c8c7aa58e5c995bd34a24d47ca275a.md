# 소개

지금까지 살펴본 대로, 메서드에 전달한 인자는 위치에 따라 메서드가 선언한 매개변수와 짝을 이뤄요. 다른 방법도 있는데, 특히 메서드가 인자를 많이 받는 경우에는 호출자가 선언된 매개변수의 식별자를 지정해서 인자를 짝지을 수 있어요.

다음은 그 문법을 보여줘요.

```csharp
class Card
{
    static string NewYear(int year, int month, int day)
    {
        return $"Happy {year}-{month}-{day}!";
    }
}

Card.NewYear(month: 1, day: 1, year: 2020);  // => "Happy 2020-1-1!"
```
