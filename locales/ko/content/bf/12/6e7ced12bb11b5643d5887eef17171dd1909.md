# 지시 사항

예비 마술사 Elyse에게는 연습해 볼 기본기 몇 가지가 있어요. Elyse에게는 다루고 싶은 카드 더미가 하나 있어요.

좀 더 쉽게 하려고 1부터 10까지의 카드만 사용해요.

카드 더미는 `queue`로 표현하는데, 더미의 맨 아래는 큐의 앞쪽에, 더미의 맨 위는 큐의 뒤쪽에 있어요.

## 1. 더미 맨 위에 카드 넣기

`insert_top` 함수를 구현해요. 이 함수는 주어진 새 카드를 더미 맨 위에 추가한 복사본을 반환해요.

```gleam
insert_top(queue.from_list([5, 9, 7, 1]), 8)
// -> queue.from_list([5, 9, 7, 1, 8])
```

## 2. 더미 맨 위의 카드 빼기

`remove_top_card` 함수를 구현해요. 이 함수는 맨 위 카드를 뺀 더미의 복사본을 반환해요. 주어진 더미가 비어 있다면 원래 더미를 그대로 반환해야 해요.

```gleam
remove_top_card(queue.from_list([3, 2, 6, 4, 8]))
// -> queue.from_list([3, 2, 6, 4])
```

## 3. 더미 맨 아래에 카드 넣기

`insert_bottom` 함수를 구현해요. 이 함수는 주어진 새 카드를 더미 맨 아래에 추가한 복사본을 반환해요.

```gleam
insert_bottom(queue.from_list([5, 9, 7, 1]), 8)
// -> queue.from_list([8, 5, 9, 7, 1])
```

## 4. 더미 맨 아래의 카드 빼기

`remove_bottom_card` 함수를 구현해요. 이 함수는 맨 아래 카드를 뺀 더미의 복사본을 반환해요. 주어진 더미가 비어 있다면 원래 더미를 그대로 반환해야 해요.

```gleam
remove_bottom_card(queue.from_list([8, 5, 9, 7, 1]))
// -> queue.from_list([5, 9, 7, 1])
```

## 5. 더미의 크기 확인하기

`check_size_of_stack` 함수를 구현해요. 이 함수는 더미의 크기가 주어진 `stack_size` 값과 같은지 확인해요.

```gleam
check_size_of_stack(queue.from_list([3, 2, 6, 4, 8]), 4)
// -> False
```
