# 소개

[`list`][list]는 _순서_를 가진 변경 가능한 항목의 모음이에요. 대부분의 컬렉션(_내장 타입인 [`tuple`][tuple], [`dict`][dict], [`set`][set]을 참고해요_)처럼, 배열은 다른 배열을 포함해 어떤 데이터 타입(또는 여러 타입)에 대한 참조도 담을 수 있어요. 배열은 [슬라이스 표기법][slice notation]을 쓰거나 `<list>.copy()`를 통해 전체 또는 일부를 복사할 수 있어요. 다른 [시퀀스 타입][sequence type]과 마찬가지로, `lists` 안의 원소는 왼쪽에서부터 `0-based index` 번호로, 오른쪽에서부터 `-1-based index` 번호로 참조해요.

배열은 `min(<list>)`/`max(<list>)`, `<list>.index()`, `<list>.append()`, `<list>.reverse()` 같은 [일반 시퀀스 연산][common sequence operations]과 [변경 가능 시퀀스 연산][mutable sequence operations]을 모두 지원해요. `list` 안의 원소는 `for item in <list>` 구문으로 반복할 수 있어요. 원소의 인덱스와 값이 둘 다 필요할 때는 `for index, item in enumerate(<list>)`를 사용할 수 있어요.

Python은 배열을 다룰 때 쓸모 있는 [배열 메서드][list-methods]도 많이 제공해요. 그중 일부 `list methods`는 아래에서 다뤄요.

`list-method`로 `list`를 조작하면 **전달된 배열 객체를 변경한다**는 점에 주의해야 해요. 원본 `list`를 변경하고 싶지 않다면, 슬라이스나 `<list>.copy()`를 통해 최소한 `shallow copy`를 만들어야 해요.

## 항목 추가하기

기존 배열의 끝, 즉 "오른쪽"에 항목을 추가하려면 `<list>.append(<item>)`를 사용해요:

```python
>>> numbers = [1, 2, 3]
>>> numbers.append(9)

>>> numbers
[1, 2, 3, 9]
```

_덧붙이는_ 대신, `<list>.insert()`를 사용하면 배열의 _특정 인덱스_에 항목을 추가할 수 있어요. 매개변수를 두 개 받아요:

1. 항목을 삽입할 `<index>`
2. 삽입할 `<item>`

**참고**: 주어진 `index`가 0이면 항목은 `list`의 맨 앞("왼쪽")에 추가돼요. 지정한 `index`가 `list`의 마지막 `index`보다 크면, 항목은 맨 끝에 추가돼요. `<list>.append(<item>)`를 사용한 것과 같아요.

```python
>>> numbers = [1, 2, 3]
>>> numbers.insert(0, -2)

>>> numbers
[-2, 1, 2, 3]

>>> numbers.insert(1, 0)

>>> numbers
[-2, 0, 1, 2, 3]
```

`<list>.extend(<item>)`는 기존 배열을 다른 이터러블(예를 들어 `set`, `tuple`, `str`, `list`)의 원소와 합치는 데 사용할 수 있어요. 이터러블은 _풀어헤쳐지고_ 원소가 순서대로 덧붙여져요. (이 경우 `<list>.append(<item>)`를 사용하면 이터러블 전체가 **하나의 항목**으로 추가돼요.)

```python
>>> numbers = [1, 2, 3]
>>> other_numbers = [5, 6, 7]

>>> numbers.extend(other_numbers)

>>> numbers
[1, 2, 3, 5, 6, 7]

>>> numbers.extend([8, 9])

>>> numbers
[1, 2, 3, 5, 6, 7, 8, 9]

>>> numbers.append([8,9])

>>> numbers
[1, 2, 3, 5, 6, 7, 8, 9, [8, 9]]
```

## 항목 제거하기

배열에서 항목을 삭제하려면 `<list>.remove(<item>)`를 사용하고, 제거할 항목을 인자로 전달해요. `<list>.remove(<item>)`는 항목이 `list`에 없으면 `ValueError`를 발생시켜요.

```python
>>> numbers = [1, 2, 3]
>>> numbers.remove(2)

>>> numbers
[1, 3]

# Trying to remove a value that is not in the list throws a ValueError
>>> numbers.remove(0)
ValueError: list.remove(x): x not in list
```

또는 `<list>.pop(<index>)` 메서드를 사용하면 원소를 제거**하고** 사용할 수 있게 `return`해요.

`<list>.pop(<index>)`는 선택적 매개변수 하나를 받아요. 제거하고 반환할 항목의 `index`예요. (선택적인) `index` 인자를 지정하지 않으면 `list`의 마지막 원소가 제거되어 반환돼요. 지정한 `index`가 마지막 항목의 `index`보다 크면 `IndexError`가 발생해요.

```python
>>> numbers = [1, 2, 3]

>>> numbers.pop(0)
1

>>> numbers
[2, 3]

>>> numbers.pop()
3

>>> numbers
[2]

>>> numbers.pop(1)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
IndexError: pop index out of range
```

`list.clear()`를 사용하면 `list`의 모든 원소를 제거할 수 있어요. 매개변수를 받지 않아요.

```python
>>> numbers = [1, 2, 3]
>>> numbers.clear()

>>> numbers
[]
```

## 순서 뒤집기와 재정렬

`<list>.reverse()` 메서드는 원소의 순서를 **제자리에서** 뒤집어요.

```python
>>> numbers = [1, 2, 3]
>>> numbers.reverse()

>>> numbers
[3, 2, 1]
```

배열은 [`<list>.sort()`][sort]를 사용해 _**제자리에서**_ 순서를 바꿀 수 있어요. 기본 정렬 순서는 왼쪽에서부터 _오름차순_이에요. Python 문서에서는 [정렬에 관한 추가 팁과 기법][sorting how to]을 제공해요.

~~~~exercism/note
2002년부터 2022년까지 Python은 내부적으로 [`Timsort`][timsort]라는 알고리즘으로 배열을 정렬했지만, `Python 3.11`부터는 [`Powersort`][powersort]로 바꿨어요.

[powersort]: https://www.wild-inter.net/publications/munro-wild-2018
[timsort]: https://en.wikipedia.org/wiki/Timsort
~~~~

```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]

# The default sort order is *ascending*.
>>> names.sort()

>>> names
["Bruce", "Natasha", "Thor", "Tony"]
```

_내림차순_으로 정렬하고 싶다면 `reverse=True` 인자를 전달해요:

```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]
>>> names.sort(reverse=True)

>>> names
["Tony", "Thor", "Natasha", "Bruce"]
```

원본 배열을 변경하고 싶지 않은 경우에는 내장 함수 [`sorted(<iterable>)`][sorted]를 사용해 정렬된 **복사본**을 반환할 수 있어요.

```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]

>>> sorted(names)
['Bruce', 'Natasha', 'Thor', 'Tony']
```

## 배열에서 원소가 나타나는 횟수

배열에서 원소가 나타나는 횟수는 `list.count(<item>)`로 계산할 수 있어요. 셀 `item`을 인자로 받아, 그 원소가 `list`에 나타나는 총 횟수를 반환해요.

```python
>>> items = [1, 4, 7, 8, 2, 9, 2, 1, 1, 0, 4, 3]

>>> items.count(1)
3
```

## 항목의 인덱스 찾기

`<list>.index(<item>)`는 전달한 항목이 _처음 나타나는_ 위치의 `index` 번호를 반환해요. 나타나는 곳이 없으면 `ValueError`가 발생해요. 항목의 정확한 위치가 필요하지 않다면, 내장 `in` 연산자가 배열에 특정 값이 있는지 확인하는 데 더 효율적이에요.

인덱싱은 왼쪽에서부터 0부터 시작하므로, "첫 번째" 항목의 위치는 `0`이에요. 인덱싱은 오른쪽에서도 동작하며 `-1`부터 시작해요.

```python
>>> items = [7, 4, 1, 0, 2, 5]

>>> items.index(4)
1

>>> items.index(10)
ValueError: 10 is not in list
```

`start`와 `end` 인덱스를 제공해 `list`의 특정 구간으로 검색 범위를 좁힐 수도 있어요:

```python
>>> names = ["Tina", "Leo", "Thomas", "Tina", "Emily", "Justin"]

>>> names.index("Tina")
0

>>> names.index("Tina", 2, 5)
3
```
