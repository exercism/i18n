# 안내

이 연습 문제에서는 프리랜서가 프로젝트 매니저와 소통할 수 있도록, 일당과 월 요금을 빠르게 계산해 주는 몇 가지 도구를 만드는 코드를 작성해요. 원한다면 주어진 할인을 적용할 수도 있어요.

먼저 프리랜서와 프로젝트 매니저 사이에 몇 가지 규칙을 정해요:

- 일당은 시급의 8배예요.
- 한 달에는 청구 가능한 날이 22일 있어요.

때로는 프리랜서가 일당에 할인을 적용하기도 해요. 예를 들어 가장 충성도 높은 고객이나 비영리 고객을 위해서요.

할인은 백분율을 나타내는 소수로 표현해요. 예를 들어 `25.0`은 25%예요.

## 1. 시급이 주어졌을 때 일당 계산하기

시급이 주어졌을 때 일당을 계산하는 함수를 구현해요:

```elixir
FreelancerRates.daily_rate(60)
# => 480.0
```

반환되는 일당은 실수여야 해요.

## 2. 할인된 가격 계산하기

할인을 적용한 후의 가격을 계산하는 함수를 구현해요.

```elixir
FreelancerRates.apply_discount(150, 10)
# => 135.0
```

반환되는 값은 항상 실수여야 하며, 어떤 방식으로도 반올림하면 안 돼요.

## 3. 시급과 할인이 주어졌을 때 월 요금 계산하기

월 요금을 계산하고 할인을 적용하는 함수를 구현해요:

```elixir
FreelancerRates.monthly_rate(77, 10.5)
# => 12130
```

반환되는 월 요금은 가장 가까운 정수로 올림해야 해요.

## 4. 예산, 시급, 할인이 주어졌을 때 근무일 수 계산하기

예산, 시급, 할인을 받아서 그 예산으로 며칠을 일할 수 있는지 계산하는 함수를 구현해요.

```elixir
FreelancerRates.days_in_budget(20000, 80, 11.0)
# => 35.1
```

반환되는 일수는 소수점 첫째 자리까지 내림해야 해요.
