# CLI

## 설정

PureScript를 설치하는 가장 간단한 방법은 Node.js와 NPM을 사용하는 거예요.

컴퓨터에 Node.js가 아직 설치되어 있지 않다면 [Node.js 웹사이트][nodejs-website]에서 내려받을 수 있어요. Node.js가 준비되면, 터미널에 다음 명령어를 입력해서 PureScript 컴파일러와 Spago 패키지 관리자 겸 빌드 도구를 설치해요.

```shell
npm install -g purescript spago
```

더 자세한 내용은 [PureScript 저장소][purescript-repository]에서 확인할 수 있어요.

## 요구 사항

연습 문제에 필요한 의존성을 설치해요:

```shell
spago install
spago build
```

## 테스트 통과시키기

다음 명령어로 테스트를 실행해요:

```shell
spago test
```

테스트 스위트에서는 첫 번째 테스트를 제외한 나머지 테스트가 모두 건너뛰도록 되어 있어요. 연습 문제를 한 번에 한 단계씩 풀어 나가도록 하기 위해서예요.

테스트 하나를 통과시키면, `xit`를 `it`로 바꿔서 다음 테스트를 활성화할 수 있어요.

## 풀이 제출하기

건너뛰는 테스트가 하나도 없고 모든 테스트를 통과하면, 다음 명령어로 풀이를 제출할 수 있어요:

```shell
exercism submit src/<NAME>.purs
```

## 사용자 정의 테스트 작성하기

추가로 직접 테스트를 작성하고 싶다면, 새 파일 `test/Custom.purs`를 만들고 풀이와 함께 새 파일도 제출해요:

```shell
exercism submit src/<NAME>.purs test/Custom.purs
```
