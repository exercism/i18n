# 테스트 실행하기

[Exercism 명령줄 클라이언트](https://exercism.io/cli)로 가져온 연습 문제에는 최소 세 개의 파일이 함께 제공돼요: `readme.md` 파일, `.dpr` 파일, `.pas` 파일이에요. `.dpr` 파일은 Delphi 프로젝트 파일이고, `.pas` 파일은 테스트 실행기예요. Delphi 프로젝트는 `.dpr` 파일을 더블 클릭하거나 Delphi 안에서 프로젝트를 열어 불러와요. 테스트를 실행할 풀이 코드가 들어갈 새 `.pas` 파일은 직접 만들어야 해요. 코드를 컴파일하고 실행하는 방법은 `readme.md` 파일을 참고해요.

가장 먼저 작업할 첫 번째 테스트를 제외한 모든 테스트는 무시 상태로 되어 있어요. 계속하려면 작업하려는 테스트의 `[Ignore]` 속성을 주석 처리하기만 하면 돼요.

위 설치 과정에서 아직 설치하지 않았다면 [DUnitX](https://github.com/VSoftTechnologies/DUnitX)가 설치되어 있는지 확인해요.
