# 소개

Elixir는 [비트스트링][exercism-bitstrings]을 다룰 때 봤던 `<<>>` 특수 형식처럼, 바이너리 데이터를 다루기 위한 우아한 문법도 제공해요.

바이너리 타입은 비트스트링 타입을 특수화한 거예요. 비트스트링은 길이가 얼마든 될 수 있지만([비트][wiki-bit] 수에 제한이 없어요), 바이너리는 비트 수가 8로 나누어떨어지는 경우를 말해요. 즉, 바이너리를 다룰 때는 [바이트][wiki-byte](8비트) 단위로 생각하는 경우가 많아요. 바이트 하나는 `0`부터 `255`까지의 정수를 표현할 수 있어요. 바이트 값은 [16진수][wiki-hexadecimal]로 다루는 일이 흔한데, `0x00 - 0xFF`처럼요.

바이너리 리터럴은 비트스트링 특수 형식 `<<>>`로 정의해요. 바이너리 리터럴을 정의할 때는 정수 리터럴과 문자열 리터럴을 사용할 수 있어요. 255보다 큰 정수 값은 오버플로되고, 마지막 8비트만 사용돼요. 기본적으로 값에는 `::binary` 수정자가 적용돼요. `<>/2` 연산자로 바이너리를 이어 붙일 수 있어요.

```elixir
<<255>> == <<0xFF>>
# Overflowing bits are truncated
<<256>> == <<0>>
<<2, 4, 6, 8, 10, 12, 14, 16>> == <<0x02, 0x04, 0x06, 0x08, 0x0A, 0x0C, 0x0E, 0x10>>
```

_널 바이트_는 `<<0>>`의 또 다른 이름이에요.

## 바이너리 데이터에 대한 패턴 매칭

[패턴 매칭][exercism-pattern-matching]은 바이너리에도 확장되어, 리스트에서처럼 바이너리 데이터의 일부에 대해서도 패턴 매칭을 할 수 있어요.

```elixir
# Ignore the first 8 bytes, match and bind the remaining to `body`
<<_::binary-size(8), body::binary>>
```

다른 패턴 매칭과 마찬가지로, 여러 함수 절 중에서 선택할 때 함수 시그니처에서도 이걸 사용할 수 있어요.
