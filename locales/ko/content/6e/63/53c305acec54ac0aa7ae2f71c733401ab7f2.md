# 지침

이 연습 문제에서는 개발자가 식별자 이름을 정리할 수 있도록 돕는 유틸리티 함수 몇 가지를 구현해요.

6개의 과제를 통해 단일 문자를 변환하는 `transform` 함수와 문자열을 변환하는 `clean` 함수를 차근차근 완성해 나가요.

유효한 식별자는 0개 이상의 글자, 밑줄, 하이픈, 물음표, 이모지로 이루어져요.

`clean` 함수에 빈 문자열을 전달하면 빈 문자열이 반환되어야 해요.

## 1. 하이픈을 밑줄로 바꾸기

하이픈을 밑줄로 바꾸도록 `transform` 함수를 구현해요.

```fsharp
transform '-'  // => "_"
```

## 2. 모든 공백 제거하기

모든 공백 문자를 제거해요.
문자열 앞뒤의 공백도 포함돼요.

```fsharp
transform ' '  // => ""
```

## 3. camelCase를 kebab-case로 변환하기

`transform` 함수를 수정해 camelCase를 kebab-case로 변환해요.

```fsharp
transform 'D'  // => "-d"
```

## 4. 숫자인 문자 제외하기

`transform` 함수를 수정해 숫자인 문자는 제외해요.

```fsharp
transform '7'  // => ""
```

## 5. 그리스 소문자를 물음표로 바꾸기

`transform` 함수를 수정해 'α'부터 'ω'까지 범위의 그리스 문자를 바꿔요.

```fsharp
transform 'β' // => "?"
```

## 6. 이 연산들을 결합해 문자열에 적용하기

이 연산들을 문자열 전체에 적용하도록 `clean` 함수를 구현해요.

규칙을 벗어나는 문자는 바뀌지 않고 그대로 남아요.

```fsharp
clean "  a2b Cd-ω😀  " //  => "ab-cd_?😀"
```

## 문자로 문자열 조립하기

이 주제는 나중에 교육 과정에서 자세히 다뤄요.

지금은 [`String.collect`][string-collect]라는 [고차 함수][higher-order-function]가 있다는 점을 알아 두면 도움이 될 거예요. 이 함수는 여러분이 제공한 함수를 사용해 `char` 컬렉션을 문자열로 변환해요.

```fsharp
let transform ch = $"{ch}_"
String.collect transform "abc"  // =>  "a_b_c_"
```
