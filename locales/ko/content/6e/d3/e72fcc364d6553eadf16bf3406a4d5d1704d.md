# 지침 추가

## 예외 메시지

때로는 [예외를 발생시켜야](https://docs.python.org/3/tutorial/errors.html#raising-exceptions) 할 때가 있어요. 이때는 오류의 원인이 무엇인지 알려 주는 **의미 있는 오류 메시지**를 항상 함께 넣어야 해요. 그래야 코드를 더 읽기 쉽게 만들 수 있고 디버깅에도 큰 도움이 돼요. 오류의 원인이 특정 유형이라는 것을 알고 있는 경우에는 [내장 오류 유형](https://docs.python.org/3/library/exceptions.html#base-classes) 중 하나를 발생시켜도 되지만, 그래도 의미 있는 메시지는 꼭 함께 넣어야 해요.

이 연습 문제에서는 `classify()` 함수에 _양의 정수_ 가 아닌 수가 전달되면 [raise 문](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)을 사용해 `ValueError`를 "던져야" 해요. 테스트는 `exception`을 `raise`하고 그에 대한 메시지도 함께 넣어야만 통과해요.

메시지와 함께 `ValueError`를 발생시키려면, 메시지를 `exception` 타입의 인자로 작성해요.

```python
# if a number to be classified is less than 1.
raise ValueError("Classification is only possible for positive integers.")
```
