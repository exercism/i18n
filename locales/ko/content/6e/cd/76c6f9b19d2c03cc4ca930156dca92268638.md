# 소개

조건에 따라 분기하는 코드를 작성하고 싶을 때가 많아요. Elixir에서 이렇게 하는 방법에는 여러 가지가 있지만, 그중 가장 간단한 방법 중 하나는 `cond/1`을 사용하는 것이에요.

가장 기본적인 형태로, `cond`는 하나 이상의 분기 중에서 `true`로 평가되는 첫 번째 경로를 따라가요.

```elixir
cond do
  x > 10 -> :this_might_be_the_way
  y < 7 -> :or_that_might_be_the_way
  true -> :this_is_the_default_way
end
```

`true`로 평가되는 경로가 하나도 없으면 런타임이 오류를 발생시켜요.
