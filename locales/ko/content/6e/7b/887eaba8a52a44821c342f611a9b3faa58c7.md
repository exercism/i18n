# 지시 사항

2차원 좌표 평면 위의 두 점이 주어졌을 때, 이 점들을 이으면 정삼각형이 되는 세 번째 점을 만들어 내는 함수를 구현해요. 처음 두 점이 주어졌을 때 정삼각형을 만드는 "세 번째" 점은 두 가지가 가능하기 때문에, 함수는 두 점을 출력해요. 참고로, 정삼각형은 세 변의 길이가 모두 같은 삼각형이에요.

함수는 각 점의 x, y 좌표를 실수로 지정한 두 개의 Python 튜플을 입력받아요. 예를 들어 (0.0, 0.0)과 (1.0, 1.0)이 입력이 될 수 있어요.

함수는 각 점의 x, y 좌표를 실수로 지정한 두 개의 튜플로 이루어진 튜플을 출력해야 해요. 예를 들어 ((0.0, 0.0), (1.0, 1.0))이 출력이 될 수 있어요.

함수는 Z3 솔버가 만족 가능하지 않은 결과를 내놓으면 Python의 내장 예외인 ArithmeticError를 발생시켜야 해요. 두 입력 점이 같을 때도 ArithmeticError를 발생시켜야 해요.

함수는 전역 매개변수를 설정하기 위해 z3 라이브러리의 "set_option()" 함수를 사용하면 안 돼요. 이는 실수가 기대하는 정밀도(소수점 자릿수)를 갖도록 테스트 케이스 안에서 이루어져요.

Z3 Real 변수의 모델 해석은 AlgebraicNumRef, IntNumRef, RatNumRef 중 하나의 인스턴스이기 때문에, 이 인스턴스를 실수로 변환해 주는 함수를 제공해요.
