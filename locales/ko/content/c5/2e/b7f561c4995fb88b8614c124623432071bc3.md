# 지침

이 연습 문제에서는 반정형 로그 메시지를 만들어요.

## 반정형 메시지 출력하기

몇 가지 스텁 함수와 아래 열거형으로 시작해요.

```rust
#[derive(Drop, Clone, PartialEq, Debug)]
pub enum LogLevel {
    Info,
    Warning,
    Error,
    Debug
}
```

목표는 `"[<LEVEL>]: <MESSAGE>"` 형식으로 로그 메시지를 출력하는 거예요.
각 로그 레벨에 대응하는 함수를 구현해야 해요.

예를 들어, 아래 코드 조각은 `log` 함수의 예상 출력을 보여줘요.

```rust
log(LogLevel::Error, "Stack overflow")
// Returns: "[ERROR]: Stack overflow"
```

그리고 `info`는 이렇게요.

```rust
info("Timezone changed")
// Returns: "[INFO]: Timezone changed"
```

즐겁게 해봐요!
