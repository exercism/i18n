# 소개

## 타입 변환

Go에서는 서로 다른 타입 사이의 변환을 명시적으로 해 줘야 해요.
타입 사이를 변환하는 것(**타입 캐스팅**이라고도 해요)은 변환하려는 타입의 이름을 가진 함수를 통해 해요.
예를 들어 `int`를 `float64`로 변환하려면 다음과 같이 하면 돼요:

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
```

## 기본 타입과 문자열 사이의 변환

기본 타입(`int` 같은)과 `string` 사이를 변환하기 위한 `strconv` 패키지가 있어요.

```go
import "strconv"

var intString string = "42"
var i, err = strconv.Atoi(intString)

var number int = 12
var s string = strconv.Itoa(number)
```

## 타입 단언

Go의 인터페이스는 기반 타입에 대해 모호함을 만들어낼 수 있어요.
타입 단언을 사용하면 `interfaceVariable.(concreteType)`이라는 문법으로 인터페이스 값의 실제 구체 타입 값을 꺼낼 수 있어요.

예를 들어요:

```go
var input any = 12
number := input.(int)
```

참고: 인터페이스 변수가 해당 구체 타입의 값을 가지고 있지 않으면 패닉이 발생해요.

타입 단언의 두 반환 값, 즉 실제 값과 단언이 성공했는지를 알려 주는 불리언 값을 모두 사용하면 인터페이스 값이 특정 구체 타입을 가지고 있는지 확인할 수 있어요.
예를 들어요:

```go
str, ok := input.(string) // no panic if input is not a string
```

`input`이 `string`을 가지고 있다면 `str`이 실제 값이 되고 `ok`는 true가 돼요.
`input`이 `string`을 가지고 있지 않다면 `str`은 `string` 타입의 제로 값(즉, `""`, 빈 문자열)이 되고 `ok`는 false가 돼요.
어느 경우에도 패닉은 발생하지 않아요.

## 타입 스위치

**타입 스위치**는 여러 타입 단언을 연달아 수행할 수 있어요.
문법은 타입 단언(`interfaceVariable.(concreteType)`)과 같지만, `concreteType` 자리에 `type` 키워드가 들어가요.
예를 들어요:

```go
var i any = 12 // try: 12.3, true, int64(12), []int{}, map[string]int{}

switch v := i.(type) {
case int:
    fmt.Printf("the integer %d\n", v)
case string:
    fmt.Printf("the string %s\n", v)
default:
    fmt.Printf("type, %T, not handled explicitly: %#v\n", v, v)
}
```
