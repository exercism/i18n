# 안내

여러분 근처의 한 지역 학교에는 아주 활발한 학생회가 있어요.
학생회는 회장이 이끌고 있으며, 2년마다 새로운 회장을 뽑는 선거가 열려요.

올해 선거에서는 표를 세는 새로운 디지털 시스템이 필요하기로 했어요.
학교는 이 새로운 시스템을 만드는 데 여러분의 도움이 필요해요.

## 1. 득표 카운터 만들기

새 투표 시스템에 가장 먼저 필요한 것 중 하나는 득표 카운터예요.
이 카운터로 특정 후보가 받은 표를 관리할 수 있어요.

후보의 초기 득표 수를 받아, 주어진 초기 득표 수로 초기화된 `int`를 가리키는 포인터를 반환하는 함수 `NewVoteCounter`를 만들어요.

```go
var initialVotes int
initialVotes = 2

var counter *int
counter = NewVoteCounter(initialVotes)
*counter == initialVotes // true
```

## 2. 카운터에서 득표 수 가져오기

이제 새 카운터를 만들 수 있게 됐어요! 그런데 새 시스템에는 카운터에서 득표 수를 가져오는 방법도 필요해요.

카운터(`*int`)를 인자로 받아 카운터의 득표 수를 반환하는 함수 `VoteCount`를 만들어요.
카운터가 `nil`이면 득표 수가 없는 것으로 간주해요:

```go
var votes int
votes = 3

var voteCounter *int
voteCounter = &votes

VoteCount(voteCounter)
// => 3

var nilVoteCounter *int
VoteCount(nilVoteCounter)
// => 0
```

## 3. 카운터의 득표 수 늘리기

드디어 표를 셀 시간이에요! 이제 카운터의 득표 수를 늘리는 방법이 필요해요.

카운터(`*int`)와 득표 수를 인자로 받아, 그만큼 카운터를 증가시키는 함수 `IncrementVoteCount`를 만들어요.
전달되는 포인터는 절대 `nil`이 아니라고 가정해도 돼요.

```go
var votes int
votes = 3

var voteCounter *int
voteCounter = &votes

IncrementVoteCount(voteCounter, 2)

votes == 5          // true
*voteCounter == 5   // true
```

## 4. 선거 결과 만들기

이제 모든 표를 세었으니, 학교 전체에 결과를 발표할 준비를 할 시간이에요.
그런데 득표용 카운터만으로는 부족하다는 걸 알게 돼요.
득표 수를 특정 후보와 연결할 방법이 필요해요.

후보의 이름과 득표 수를 받아 새로운 선거 결과를 반환하는 함수 `NewElectionResult`를 만들어요.

```go
var result *ElectionResult
result = NewElectionResult("Peter", 3)

result.Name == "Peter"  // true
result.Votes == 3       // true
```

선거 결과 struct는 이미 만들어져 있고, 다음과 같이 정의되어 있어요:

```go
type ElectionResult struct {
    // Name of the candidate
    Name    string
    // Votes of votes the candidate had
    Votes   int
}
```

## 5. 결과 발표하기

학교에 새로운 회장을 발표할 시간이에요!
회장은 학교에 있는 작은 디지털 전광판을 통해 발표돼요.
메시지는 새 회장의 이름과 그가 받은 득표 수를 다음 형식으로 보여줘야 해요: `<candidate_name> (<votes>)`.
이런 메시지의 예시는 `"Peter (51)"`예요.

`*ElectionResult`를 인자로 받아 표시할 메시지를 담은 문자열을 반환하는 함수 `DisplayResult`를 만들어요.

```go
var result *ElectionResult
result = &ElectionResult{
    Name: "John",
    Votes: 32,
}

DisplayResult(result)
// => John (32)
```

## 6. 표 다시 세기

최종 결과가 정확한지 확인하기 위해 표를 다시 셌어요.
다시 세는 과정에서 일부 후보의 득표 수가 하나씩 어긋나 있다는 사실이 밝혀졌어요.

최종 결과와 득표 수를 줄여야 할 후보의 이름을 받아, 그 후보의 득표 수를 감소시키는 함수 `DecrementVotesOfCandidate`를 만들어요.
최종 결과는 `map[string]int` 형태로 주어지고, 키는 후보의 이름, 값은 해당 후보의 총 득표 수예요.

```go
var finalResults = map[string]int{
    "Mary":  10,
    "John":  51,
}

DecrementVotesOfCandidate(finalResults, "Mary")

finalResults["Mary"]
// => 9
```
