# 소개

Common Lisp에는 여러 가지 동등성 판별 함수가 있어요.
다른 프로그래밍 언어에는 하나나 둘밖에 없는 경우가 많은데(예를 들어 `==`와 `===`), Common Lisp은 그렇지 않아요.
이 판별 함수들 중에는 특정 타입에만 쓰이는 것도 있고, 타입에 상관없이 쓰이는 것도 있어요.
여기서 다루는 것은 바로 뒤쪽, 그러니까 범용 판별 함수예요.

범용 동등성 판별 함수는 네 가지이고, 무엇을 "같다"고 여기는지에 따라 얼마나 엄격한지가 달라요.
가장 엄격한 것부터 가장 느슨한 것 순서로 `eq`, `eql`, `equal`, `equalp`예요.

몇 가지 세부 사항은 빼고, 간단히 정의하면 다음과 같아요:

- `eq`: 두 객체가 동일하다는 것을 같음으로 정의해요.
  _예:_:

```lisp
(eq 'a 'a)                 ; => T
(eq (list 1 2) (list 1 2)) ; => NIL
```

- `eql`: 같은 타입과 값을 가진 두 수, 또는 같은 두 문자를 같음으로 정의하고, 그 밖의 것은 `eq`인 경우 같다고 봐요.
  _예:_:

```lisp
(eql 1 1)     ; => T
(eql #\a #\a) ; => T
(eql 1 1.0)   ; => NIL
(eql #\a #\A) ; => NIL
```

- `equal`: 두 리스트는 각 원소가 `equal`인 경우 `equal`이고, 두 문자열은 각 원소가 `eql`인 경우 `equal`이고, 두 배열은 `eq`인 경우 `equal`이에요. 그 밖의 모든 것은 `eql`인 경우 `equal`이에요.
  _예:_:

```lisp
(equal (list 1 2) (list 1 2)) ; => T
(equal #(1 2) #(1 2))         ; => NIL
(equal "foo" "foo")           ; => T
```

- `equalp`: 같음이란 다음과 같은 것이라고 정의해요. 문자열과 문자는 대소문자를 구분하지 않고 비교해요. 수는 타입 변환을 어느 정도 거쳐서 비교하고요. 리스트와 배열은 모든 원소가 `equalp`인 경우 `equalp`이고, 구조체는 같은 타입이고 모든 슬롯이 `equalp`인 경우, 해시 테이블은 키와 값이 `equalp`인 경우 `equalp`예요
  _예:_:

```lisp
(equalp "foo" "FoO")                          ; => T
(equalp 3 3.0)                                ; => T
(equalp (make-a-structure :slot1 1 :slot2 2) 
        (make-a-structure :slot1 1 :slot2 2)) ; => T
```
