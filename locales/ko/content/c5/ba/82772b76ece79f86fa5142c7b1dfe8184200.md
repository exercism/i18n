# 개요

Haxe에서 **배열**은 (보통) 같은 타입의 원소들로 이루어진 모음이에요. Haxe에서 배열을 만드는 방법은 세 가지예요. 생성자를 사용하거나 선언 문법을 사용하는 거예요. Haxe에서 배열의 첫 번째 원소의 인덱스는 0이에요:

```haxe
var a = [1, 2, 3];
trace(a); // [1,2,3]

// Here the second element is called by index
trace(a[1]); // 2

// The actual first element's index is 0
trace(a[0]); // 1
```

생성자로 배열을 만들려면, 배열에 포함될 원소들의 타입을 전달해야 해요:

```haxe
var a:Array<Int> = [0, 1, 2, 3];
a[1] = "Hello"; // Error: the array a takes integers only
```

Haxe의 배열 접근은 경계가 없어요. 즉, 예외를 던지지 않는 것이 보장되므로 좀 더 자세히 설명할 필요가 있어요:

- 존재하지 않는 인덱스에 읽기 접근을 하면, 타겟에 따라 달라지는 값이 반환돼요.
- 범위를 벗어난 양수 인덱스로 쓰기 접근을 하면, 마지막으로 정의된 인덱스와 새로 쓴 인덱스 사이의 모든 위치에 `null`(또는 정적 타겟에서 기본 타입의 기본값)이 삽입돼요.
- 음수 인덱스로 쓰기 접근을 하면, 결과가 어떻게 될지는 정해져 있지 않아요.

배열이 여러 타입의 원소를 담게 하고 싶다면, 타입 표시에 `Dynamic` 타입을 추가해요:

```haxe
var a:Array<Dynamic> = [10, "Bob", true]
```

## 반복

배열은 `for`문을 사용해 반복할 수 있어요:

```haxe
var nums = [2, 3, 5];
var sum = 0;
for (num in nums) {
  sum += num;
}
trace(sum); // 10
```
