# 소개

`awk`는 텍스트 처리를 위해 설계된 인터프리터 방식의 프로그래밍 언어로, 주로 데이터 추출과 리포팅 도구로 사용해요.
대부분의 유닉스 계열 운영체제에 기본으로 포함되어 있고, [POSIX 명세][posix]도 있어요.

`awk`의 프로그래밍 패러다임은 "데이터 기반"이라고 할 수 있어요.
`awk` 프로그램은 줄(또는 다른 텍스트 단위)을 읽으면서 _패턴_이 일치하는 부분을 찾아요.
일치하는 부분이 있으면 지정한 _동작_을 수행해요.

`awk` 프로그램은 대략 이런 모양이에요.
```awk
pattern1 {action1}
pattern2 {action2}
...
```

_패턴_은 정규 표현식일 수도 있고, 참/거짓으로 평가되는 다른 식일 수도 있어요.
_패턴_은 생략할 수 있는데, 이 경우에는 텍스트의 각 레코드마다 _동작_을 수행해요.
_동작_도 생략할 수 있는데, 이 경우 기본 동작은 현재 레코드를 출력하는 거예요.

`awk`는 사용자의 도구 상자에 더할 나위 없이 좋은 도구예요.
명령줄에 입력하는 짧은 "한 줄짜리" 프로그램에 특히 강해요.
`awk` 프로그램 하나로 `grep`, `sed`, `tr`, `cut`을 조합한 대부분의 파이프라인을 대신할 수 있어요.

## 구현체

`awk`는 1977년에 Alfred Aho, Peter Weinberger, Brian Kernighan이 만들었어요(세 사람의 성을 따서 언어 이름을 지었죠).
이 구현체는 "old awk"로 알려지게 됐어요.
1985년에는 개선된 버전이 나왔는데, "BWK awk", "new awk", 또는 "the one-true-awk"라고 불려요.
macOS와 일부 \*BSD 배포판에 함께 제공되는 버전이에요.

또 다른 흔한 구현체로 바이트코드 인터프리터를 기반으로 한 `mawk`가 있어요.
`mawk`는 속도가 아주 빨라요.
`mawk`는 많은 리눅스 배포판에서 기본 `/usr/bin/awk`로 제공돼요.

### GNU awk

이 트랙에서는 GNU의 awk 구현체인 `gawk`를 사용해요.
`gawk`가 `mawk`만큼 빠르지는 않을 수 있지만, 기능이 아주 풍부하고 문서도 잘 갖춰져 있으며 편리한 명령줄 옵션도 몇 가지 있어요.

### 셔뱅

플랫폼에 따라 파일 맨 위에 [셔뱅][shebang] 줄을 추가하면 awk 스크립트를 실행할 수 있어요.
대부분의 시스템에서는 다음 두 셔뱅 중 하나면 잘 동작할 거예요.
하지만 모든 시스템에서 통하는 셔뱅은 없기 때문에, 여기서는 셔뱅을 생략하기로 했어요.

```bash
#!/usr/bin/env -S gawk -f
#!/usr/bin/gawk -f
```
