# 소개

Elixir에서는 모듈 속성을 정의할 수 있어요. 이 속성은 함수에서 상수로 사용할 수 있어요.

```elixir
defmodule Example do
  # Defines the attribute as the value 1
  @constant_number 1

  def example_value() do
    # Returns the value 1
    @constant_number
  end
end
```

모듈 상수를 정의할 때 사용되는 속성은 컴파일 시간에 평가될 수 있는 표현식이라면 무엇이든 될 수 있어요. 컴파일 후에는 모듈 속성에 접근할 수 없어요. 왜냐하면 컴파일 중에 확장되기 때문이에요. 이는 C 같은 언어에서 정의된 매크로와 비슷해요.
