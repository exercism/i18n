# 개요

조건문은 조건이 `true`인지 `false`인지에 따라 서로 다른 코드를 실행하는 문이에요.

[`if`문][if_statement]은 조건이 `true`일 때만 본문을 실행해요.
Go에는 참 같은 값이나 거짓 같은 값이라는 개념이 없어서, 조건은 반드시 `bool` 타입이어야 해요.
`if mySlice { ... }`나 `if 1 { ... }` 같은 표현은 컴파일 오류가 돼요.

```go
func describe(val string) string {
    if val == "val" {
        return "was val"
    }
    return "was not val"
}
```

조건을 더 확인하려면 `else if`를 사용하고, 어떤 조건도 맞지 않을 때를 대비해서는 `else`를 사용해요.
조건은 위에서 아래로 평가되고, 조건이 참인 첫 번째 분기만 실행돼요.

```go
number := 0
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

일반적으로 Go는 예외적인 경우에는 일찍 반환하고 `else`를 피하는 방식을 선호해요.

```go
func getVal(connected bool) int {
    if !connected {
        return readLocalVal()
    }

    return readVal()
}
```

`if`문에는 짧은 초기화 문을 함께 쓸 수도 있어요.
보통 함수 호출 직후에 오류를 확인할 때 사용해요:

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```

초기화 문에서 선언한 변수는 `if`/`else` 전체 체인 안에서만 스코프를 가져요.
특히 Go에는 삼항 연산자가 없는데, 이는 코드를 읽기 쉽게 유지하기 위한 의도적인 설계 선택이에요.

더 알아보려면 [Go by Example: If/Else][go_by_example_if]를 참고해요.
