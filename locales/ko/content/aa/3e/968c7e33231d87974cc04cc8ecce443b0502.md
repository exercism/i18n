# 안내 추가

## 레지스터

| Register | Usage     | Type    | Description                                               |
| -------- | --------- | ------- | --------------------------------------------------------- |
| `$a0`    | 입력      | 주소    | null로 끝나는 입력 문자열                                 |
| `$v0`    | 출력      | 불리언  | 입력의 괄호 짝이 맞음 (`0` = `false`, `1` = `true`)       |
| `$t0-9`  | 임시      | 아무 형식 | 임시 저장에 사용                                        |
