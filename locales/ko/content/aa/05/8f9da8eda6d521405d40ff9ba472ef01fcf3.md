# 명령줄에서 테스트하기

테스트는 다음 명령으로 실행해요:

```bash
$ cargo test
```

첫 번째 테스트를 제외한 나머지 테스트는 모두 무시된 상태예요. 첫 번째 테스트를 통과시키고 나면, `tests` 디렉터리에 있는 테스트 소스 파일을 열어서 다음 테스트 위에 붙어 있는 `#[ignore]` 플래그를 지우고 다시 테스트를 통과시켜 봐요. 각각의 테스트는 위에 `#[test]` 플래그가 붙어 있는 함수예요. 모든 테스트를 통과할 때까지 이 과정을 계속해요.

테스트 소스 파일을 수정하지 않고 _무시된_ 테스트만 실행하고 싶다면 다음을 사용해요:

```bash
$ cargo test -- --ignored
```

Rust 1.51 이상을 사용한다면 다음으로 _모든_ 테스트를 실행할 수 있어요:

```bash
$ cargo test -- --include-ignored
```

특정 테스트, 예를 들어 `some_test`를 실행하려면 다음을 사용해요:

```bash
$ cargo test some_test
```

특정 테스트가 무시된 상태라면 다음을 사용해요:

```bash
$ cargo test some_test -- --ignored
```

Rust 테스트에 대해 더 알아보려면 온라인 [테스트 문서][rust-tests]를 참고해요.

[rust-tests]: https://doc.rust-lang.org/book/ch11-02-running-tests.html
