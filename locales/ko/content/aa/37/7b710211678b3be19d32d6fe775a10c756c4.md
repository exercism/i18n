# 지침 추가

## 레지스터

| 레지스터 | 용도     | 자료형  | 설명                                              |
| -------- | --------- | ------- | ------------------------------------------------- |
| `$a0`    | 입력      | 정수    | 시작 숫자                                         |
| `$v0`    | 출력      | 정수    | 예상되는 단계 수, 숫자가 유효하지 않으면 -1       |
| `$t0-9`  | 임시      | 임의    | 임시 저장에 사용                                  |
