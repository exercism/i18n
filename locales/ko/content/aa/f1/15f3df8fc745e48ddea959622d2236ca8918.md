# 개요

ABAP은 숫자 값에 사용하는 일반적인 산술 연산자를 지원해요:

- `+`는 값을 더해요.
- `-`는 값을 빼요.
- `*`는 값을 곱해요.
- `/`는 값을 나눠요.
- `MOD`는 정수 나눗셈의 나머지를 반환해요.

```abap
DATA total TYPE i.
total = 6 + 4 * 2.

DATA remaining_days TYPE i.
remaining_days = 70 MOD 22.
```

곱셈과 나눗셈은 덧셈과 뺄셈보다 먼저 계산돼요. 계산을 명시적으로 묶어야 할 때는 괄호를 사용해요.

```abap
DATA result TYPE i.
result = ( 6 + 4 ) * 2.
```
