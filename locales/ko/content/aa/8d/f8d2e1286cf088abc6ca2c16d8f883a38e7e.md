# 지침 추가

## 레지스터

| 레지스터 | 용도     | 타입    | 설명                                             |
| -------- | --------- | ------- | ------------------------------------------------ |
| `$a0`    | 입력     | 주소 | null로 끝나는 입력 문자열                        |
| `$v0`    | 출력     | 불리언 | 입력이 팬그램인지 여부 (`0` = `false`, `1` = `true`) |
| `$t0-9`  | 임시 | 임의     | 임시 저장에 사용                                 |
