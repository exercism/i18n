# 힌트

## 일반

- 각 과제에서 각 함수는 주어진 인자를 사용해 함수 클로저를 반환해야 해요. 자세한 내용은 Clojure 문서의 [함수 클로저][closures] 부분을 참고해요.

## 1. 좌표 이동하기

- 주어진 인자는 좌표 쌍을 _x_축과 _y_축 방향으로 얼마나 이동할지 알려줘요.

## 2. 좌표 크기 조정하기

- 주어진 인자는 좌표 쌍을 _x_축과 _y_축 방향으로 얼마나 조정할지 알려줘요.

## 3. 변환 함수 합성하기

- 첫 번째 변환의 결과는 벡터지만, 변환 함수는 숫자 인자 두 개를 받아요. 벡터에서 값을 꺼내야 해요.
- 함수가 수행되는 순서가 중요하다는 점을 기억해요.

## 4. 함수의 결과 저장하기

- 이 함수에서는 마지막 변환의 결과만 메모이제이션하면 돼요.
- 마지막 변환의 결과를 돌려주려면, 입력 인자가 같은지 확인해야 해요.
- 인자의 값과 마지막 결과를 저장하려면 [atom][atoms]을 사용할 수 있어요.

[atoms]: https://clojure.org/reference/atoms
[closures]: https://clojure.org/guides/higher_order_functions#_functions_returning_functions_and_closures
