# 힌트

## 일반

- `gleam/string` 모듈에는 유용한 [문자열 함수][stdlib]가 많이 있어요.

## 1. 로그 줄에서 메시지 가져오기

- `<>` 연산자는 패턴 매칭에서 문자열의 시작 부분을 일치시키는 데 사용할 수 있어요.
- `gleam/string` 모듈에는 문자열 양옆의 공백을 제거하는 [함수][trim]가 있어요.

## 2. 로그 줄에서 로그 레벨 가져오기

- `gleam/string` 모듈에는 문자열을 소문자로 바꾸는 [함수][lowercase]가 있어요.

## 3. 로그 줄 형식 바꾸기

- `<>` 연산자를 사용하면 문자열을 서로 이어 붙일 수 있어요.

[trim]: https://hexdocs.pm/gleam_stdlib/gleam/string.html#trim
[lowercase]: https://hexdocs.pm/gleam_stdlib/gleam/string.html#lowercase
