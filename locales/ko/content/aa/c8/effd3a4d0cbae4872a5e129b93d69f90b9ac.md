# 개요

C#에서 불리언은 `bool` 타입으로 표현되고, 이 타입의 값은 `true`나 `false` 둘 중 하나예요.

C#은 네 가지 [불리언 연산자][operators]를 지원해요: `!` (NOT), `&&` (AND), `||` (OR), `^` (XOR). `&&`와 `||` 연산자는 _단축 평가_를 사용해요. 단축 평가란 연산자의 오른쪽 피연산자가 필요할 때만 평가된다는 뜻이에요.

```csharp
true || false // => true
true && false // => false
true ^ false  // => true
true ^ true   // => false
```

세 가지 불리언 연산자는 각각 다른 [_연산자 우선순위_][precedence]를 가져요. 그 결과 `not`이 먼저, `&&`가 두 번째, `^`가 세 번째, 마지막으로 `||` 순서로 평가돼요. 이 규칙에서 '벗어나고' 싶다면 불리언 표현식을 괄호(`()`)로 감싸면 돼요. 괄호는 연산자 우선순위가 훨씬 더 높기 때문이에요.

```csharp
!true && false   // => false
!(true && false) // => true
```
