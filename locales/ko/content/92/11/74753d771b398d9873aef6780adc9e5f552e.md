# 소개

## 집합

[`Set`][set-docs]은 순서가 없는 컬렉션이에요. `List`와는 달리 중복된 값은 담지 않는다는 게 보장되죠.

`Set` 인터페이스의 제네릭 타입 매개변수는 `Set`에 담긴 원소의 타입을 나타내요.

```java
Set<Integer> ints = Set.of(1, 2, 3);
Set<String> strings = Set.of("alpha", "beta", "gamma");
Set<Object> mixed = Set.of(1, false, "foo");
```

참고로 `Set.of()` 메서드는 [_수정할 수 없는_][unmodifiable-set-docs] `Set` 인스턴스를 만들어요. 이 인스턴스에서 `add`나 `remove` 같은 메서드를 호출하면 런타임에 예외가 발생해요.

수정할 수 있는 `Set`을 만들려면 `Set` 인터페이스를 구현한 클래스의 인스턴스를 만들어야 해요. 이 인터페이스를 구현한 내장 클래스 중 가장 많이 쓰이는 것은 [`HashSet`][hashset-docs] 클래스예요.

```java
Set<Integer> ints = new HashSet<>();
```

`Set` 인터페이스는 [`Collection`][collection-docs]과 [`Iterable`][iterable-docs] 인터페이스를 확장하기 때문에 다른 종류의 컬렉션과 많은 메서드를 공유해요. 그런데 `Collection` 인터페이스와 눈에 띄게 다른 점이 하나 있어요. 바로 `add`나 `remove` 같은 메서드가 `void` 대신 `boolean`을 반환한다는 건데, 이 값은 그 메서드를 호출했을 때 해당 항목이 집합에 포함되어 있었는지를 알려줘요.

```java
Set<Integer> set = new HashSet<>();
set.add(1);
// => true
set.add(2);
// => true
set.add(1);
// => false
set.size();
// => 2
set.contains(1);
// => true
set.contains(3);
// => false
set.remove(3);
// => false
set.remove(2);
// => true
set.size();
// => 1
```
