# 지침

이 연습 문제에서는 클래식 게임 Pac-Man의 규칙 몇 가지를 Gleam 함수로 옮겨야 해요.

옮겨야 할 규칙은 네 가지이고, 모두 게임 상태와 관련되어 있어요.

> 인자가 어떻게 만들어지는지는 신경 쓰지 말고, 인자들을 조합해 원하는 결과를 반환하는 데만 집중해요.

## 1. Pac-Man이 유령을 먹는지 정의하기

`eat_ghost` 함수를 정의해요. 이 함수는 두 개의 인자(_Pac-Man이 파워 펠릿을 활성화했는지_와 _Pac-Man이 유령에 닿아 있는지_)를 받아, Pac-Man이 유령을 먹을 수 있는지에 대한 불리언 값을 반환해요. Pac-Man이 파워 펠릿을 활성화한 상태에서 유령에 닿아 있을 때만 `True`를 반환해야 해요.

```gleam
eat_ghost(False, True)
// -> False
```

## 2. Pac-Man이 점수를 얻는지 정의하기

`score` 함수를 정의해요. 이 함수는 두 개의 인자(_Pac-Man이 파워 펠릿에 닿아 있는지_와 _Pac-Man이 점에 닿아 있는지_)를 받아, Pac-Man이 점수를 얻었는지에 대한 불리언 값을 반환해요. Pac-Man이 파워 펠릿이나 점에 닿아 있으면 `True`를 반환해야 해요.

```gleam
score(True, True)
// -> True
```

## 3. Pac-Man이 지는지 정의하기

`lose` 함수를 정의해요. 이 함수는 두 개의 인자(_Pac-Man이 파워 펠릿을 활성화했는지_와 _Pac-Man이 유령에 닿아 있는지_)를 받아, Pac-Man이 지는지에 대한 불리언 값을 반환해요. Pac-Man이 유령에 닿아 있고 파워 펠릿을 활성화하지 않았으면 `True`를 반환해야 해요.

```gleam
lose(False, True)
// -> True
```

## 4. Pac-Man이 이기는지 정의하기

`win` 함수를 정의해요. 이 함수는 세 개의 인자(_Pac-Man이 점을 모두 먹었는지_, _Pac-Man이 파워 펠릿을 활성화했는지_, _Pac-Man이 유령에 닿아 있는지_)를 받아, Pac-Man이 이기는지에 대한 불리언 값을 반환해요. Pac-Man이 점을 모두 먹었고 3번에서 정의한 인자들에 따라 지지 않았으면 `True`를 반환해야 해요.

```gleam
win(False, True, False)
// -> False
```
