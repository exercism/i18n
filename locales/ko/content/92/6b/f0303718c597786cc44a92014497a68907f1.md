# 힌트

## 1. 유효한 명령 확인

- 불리언을 반환하려면 [test][regex-test] 표현식을 사용해요.
- 대소문자 구분 없애기 같은 추가 기능에는 [flags][flags] 인자를 사용할 수 있다는 점을 기억해요.

## 2. 암호화된 이모지 제거

- 모든 이모지가 같은 방식으로 암호화되므로, `emoji` 단어 뒤에 오는 숫자는 `[0-9]`로 검색할 수 있어요.
- `+` 문자는 연속된 항목 하나 이상과 일치해요.
- 각 이모지를 빈 문자열로 바꾸려면 [gsub][regex-gsub] 메서드를 사용해요.

## 3. 유효한 전화번호 확인

- 이 [글][phone-validation]은 전화번호를 검증하는 여러 방법을 아주 잘 설명해요.
- 전화번호가 유효한지 확인하려면 `test` 필터를 사용해요.
- 최종 결과는 `if-then-else` 표현식으로 반환해요.

## 4. 웹사이트 링크 가져오기

- 여기서는 하나 이상의 `.` 점으로 이어진 단어를 찾아요.
- `g` 플래그와 함께 [match][regex-match] 필터를 사용할 수 있어요.
- [scan][regex-scan] 필터가 사용하기 더 쉬울 수도 있어요.

## 5. 사용자에게 인사하기

- [명명된 캡처 그룹][named-capture]을 사용하면 일치한 텍스트를 다시 사용하기 편해요.
- 이름 붙인 그룹을 참조할 때는 [capture][regex-capture] 필터가 좋아요.

## 6. 아주 간단한 CSV 파싱

- 여기서는 구분자를 알고 있으므로 [split][regex-split]을 사용하는 게 좋아요.
- 패턴은 "쉼표 뒤에 공백이 0개 이상 오는 것"이에요.
- **2-arity** `split` 필터를 사용해야 해요. 지정해야 할 플래그는 없어요.
