# 지시 사항

동네에 새로운 시 동아리가 문을 열었고, 가 볼까 생각 중이에요.
예전에 몇 번 사건이 있었던 터라, 이 동아리에는 아주 특별한 출입 규칙이 있어서 들어가기 전에 먼저 익혀 두어야 해요.

시 동아리에는 문이 두 개 있는데, 둘 다 문지기가 지키고 있어요.
들어가려면 그날의 비밀번호를 알아내야 해요.

## 1. 문자열을 개별 줄로 나누기

가장 먼저 할 일은 시를 개별 줄로 나누는 거예요.
문지기가 시를 읊어 주면, 그 시를 줄 단위로 나눠야 해요.

문자열을 받아서 줄 바꿈 문자를 구분자로 사용해 문자열의 배열로 나누는 `splitOnNewlines` 함수를 구현해요.
이 함수는 문자열의 배열을 반환해야 하는데, 각 문자열은 시의 한 줄이에요.

```swift
splitOnNewlines("Hello.\nHow are you?\n\nI'm doing fine.")
// returns ["Hello." ,"How are you?", "", "I'm doing fine"].
```

## 2. 정문

1. 문지기가 시를 읊어요.
2. 시를 개별 줄로 나눠야 해요.
3. 각 줄의 첫 글자를 가져와야 해요.
   - 줄이 비어 있으면 대신 `_`를 사용해요.
4. 글자들을 모아 이어 붙이면 하나의 단어가 돼요.

예를 들어, 그들이 가장 좋아하는 작가 중 한 명인 Michael Lockwood는 다음과 같은 _아크로스틱_ 시를 썼는데, 아크로스틱이란 각 문장의 첫 글자를 모으면 단어가 되는 형식을 말해요:

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

문지기가 시를 읊으면, 시를 개별 줄로 나누고 각 줄의 첫 글자로 답해요. 즉, `["S", "H", "I", "R", "E"]`예요.

그다음 문지기는 답한 글자 배열로 만들어진 단어를 주는데, 그 단어를 첫 글자만 대문자로 바꾼 형태로 만들어야 해요.
마지막으로 반환하는 비밀번호가 `"SHIRE"`면 들어갈 수 있어요.

시를 나타내는 문자열을 받는 `frontDoorPassword` 함수를 구현해요.
이 함수는 문지기에게 말할 비밀번호를 반환해야 해요.

```swift
frontDoorPassword("Stands so high\nHuge hooves too\nImpatiently waits for\nReins and harness\nEager to leave")
// returns "SHIRE"
```

## 3. 뒷문

동아리 안쪽에는 가장 유명한 시인들이 있는데, 꼭 VIP 구역 같아요.
아무나 갈 수 있는 곳이 아니라서, 뒷문 절차는 조금 더 복잡해요.

1. 문지기가 시를 읊어요.
2. 시를 줄 단위로 나눠야 해요.
3. 각 줄의 마지막 글자를 가져와야 해요.
   - 줄 끝에 공백이 남아 있을 때가 있으니, 그 공백을 없애야 해요.
4. 글자들을 모은 다음, 그 글자로 만들어진 단어 끝에 `", please"`를 붙여야 해요.

예를 들어, 앞에서 나온 시는 _텔레스틱_이기도 한데, 텔레스틱이란 각 문장의 마지막 글자를 모으면 단어가 되는 형식을 말해요:

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

문지기가 시를 읊으면, 시를 개별 줄로 나누고 줄 끝의 공백을 없앤 다음, 각 줄의 마지막 글자로 답해요. 즉, `["h", "o", "r", "s", "e"]`예요.

그다음 문지기는 답한 글자 배열로 만들어진 단어를 주는데, 그 단어를 첫 글자만 대문자로 바꾸고 `", please"`를 붙여야 해요.
마지막으로 반환하는 비밀번호가 `"horse, please"`면 들어갈 수 있어요.

시를 나타내는 문자열을 받는 `backDoorPassword` 함수를 구현해요.
이 함수는 문지기에게 말할 비밀번호를 반환해야 해요.

```swift
backDoorPassword("Stands so high\nHuge hooves too\nImpatiently waits for\nReins and harness\nEager to leave")
// returns "horse, please"
```

## 4. 비밀의 방

동아리 안쪽 방에는 또 다른 문이 있는데, 이 문은 최고의 시인들만 들어갈 수 있는 비밀의 방으로 이어져요.

1. 문지기가 시를 읊어요.
2. 시를 줄 단위로 나눠야 해요.
3. i<sup>번째</sup> 줄의 i<sup>번째</sup> 글자를 가져와야 해요.
4. 글자들을 모은 다음, 그 글자로 만들어진 단어 끝에 `"!"`를 붙여야 해요.
5. 그 단어를 모두 대문자로 바꿔야 해요.

예를 들어, 앞에서 나온 시를 살짝 바꾼 버전이 이 패턴에 맞아요:

```text
Stands so high
Huge hooves too
Impatiently waits for
Rider with harness
Eager to leave
```

문지기가 시를 읊으면, 시를 개별 줄로 나누고 줄 끝의 공백을 없앤 다음, 각 줄의 i<sup>번째</sup> 글자로 답해요. 즉, ["S", "u", "p", "e", "r"]예요.

그다음 문지기는 답한 글자 배열로 만들어진 단어를 주는데, 그 단어를 모두 대문자로 바꾸고 `"!"`를 붙여야 해요.
마지막으로 반환하는 비밀번호가 `SUPER!`면 들어갈 수 있어요.

시를 나타내는 문자열을 받는 `secretRoomPassword` 함수를 구현해요.
이 함수는 문지기에게 말할 비밀번호를 반환해야 해요.

```swift
secretRoomPassword("Stands so high\nHuge hooves too\nImpatiently waits for\nRider with harness\nEager to leave")
// returns "SUPER!"
```
