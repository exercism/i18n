# 지침 추가

## 예외 메시지

때로는 [예외를 발생시켜야](https://docs.python.org/3/tutorial/errors.html#raising-exceptions) 할 때도 있어요. 이때는 오류의 원인이 무엇인지 알려 주는 **의미 있는 오류 메시지**를 항상 포함해야 해요. 그러면 코드를 더 읽기 쉽게 만들고, 디버깅에도 큰 도움이 돼요. 오류의 원인이 특정 유형이라고 확실한 상황이라면 [내장 오류 유형](https://docs.python.org/3/library/exceptions.html#base-classes) 중 하나를 골라 발생시켜도 되지만, 그래도 의미 있는 메시지는 포함해야 해요.

이 연습 문제에서는 `preorder`와 `inorder` 인자가 길이나 원소가 서로 맞지 않거나, 원소가 중복되는 경우 [raise 문](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)을 사용해 `ValueError`를 "던져야" 해요. 테스트는 `exception`을 `raise`하고 메시지도 함께 넣을 때만 통과해요.

메시지와 함께 `ValueError`를 발생시키려면, 메시지를 `exception` 타입의 인자로 작성해요:

```python
# if preorder and inorder are not the same length
raise ValueError("traversals must have the same length")

# if preorder and inorder do not share the same elements
raise ValueError("traversals must have the same elements")
    
# if element repeat (are not unique)    
raise ValueError("traversals must contain unique items")
```
