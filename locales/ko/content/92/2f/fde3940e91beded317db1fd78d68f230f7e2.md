# 지시사항

해안 무선 통신소에서 채널 교신을 지켜보고 있어요. 메시지가 전선으로 들어오면 받아 적고, 답장은 다시 내보내요. 작은 단어 다섯 개가 한 근무조의 일을 처리해요.

테스트는 `<string-reader>` 입력(들어오는 통신)을 넘겨주고, 나가는 통신에는 `<string-writer>`를 사용해요. 하지만 여기 나오는 모든 단어는 실제 `<file-reader>`나 소켓에 대해서도 똑같이 동작해요.

## 1. 전부 다 들어요

`hear-out`은 입력 스트림을 끝까지 읽어 하나의 문자열로 만들어요.

```factor
"all quiet on the channel" <string-reader> hear-out .
! => "all quiet on the channel"
```

## 2. 메시지 수를 세요

`count-messages`는 입력 스트림에서 모든 줄을 읽고, 줄이 몇 개였는지 반환하도록 정의해요.

```factor
"alpha\nbravo\ncharlie\n" <string-reader> count-messages .
! => 3
```

## 3. 마지막 교신을 되돌려 보내요

`echo-back`은 모든 줄을 읽고 **마지막 줄을 대문자로** 반환하도록 정의해요. 무선 통신에서 흔히 쓰는, 상대가 한 말을 그대로 되돌려 주는 표준 응답이에요.

```factor
"alpha\nbravo\n" <string-reader> echo-back .
! => "BRAVO"
```

## 4. 메시지를 방송해요

`broadcast`는 주어진 writer에 메시지를 쓰고, 곧바로 나가도록 스트림을 플러시하도록 정의해요. 아무것도 반환하지 않아요.

```factor
[ "mayday" output-stream get broadcast ] with-string-writer .
! => "mayday"
```

## 5. quotation의 출력을 캡처해요

`capture`는 새 string-writer를 그 시점의 출력 스트림으로 삼아 quotation을 실행하고, quotation이 출력한 내용을 그대로 반환하도록 정의해요. quotation은 아무 인자도 받지 않아요. 그냥 평소처럼 그 시점의 출력 스트림에 쓸 뿐이에요.

```factor
[ "test broadcast" print ] capture .
! => "test broadcast\n"
```
