# 불리언 타입

Cairo에서 불리언 타입은 논리 연산과 조건문에 꼭 필요해요. Cairo의 불리언은 크기가 `felt252` 하나라서, 참/거짓 논리의 단순함을 유지하면서도 공간을 효율적으로 사용할 수 있어요.

Cairo에서 불리언 타입은 `bool` 키워드로 나타내요. 이 키워드를 사용하면 언어 안에서 불리언 변수를 선언하고 다룰 수 있어요. 예를 들어, 다음 예제를 살펴봐요:

```rust
fn main() {
    let t = true;
    let f: bool = false; // with explicit type annotation
}
```

이 예제에서는 불리언 변수 두 개를 선언해요. 변수 `t`에는 `true` 값을 할당하고 타입을 암시적으로 불리언으로 지정해요. 반면 변수 `f`에는 `bool` 타입을 명시적으로 붙이고 `false` 값을 할당해요.

한 가지 중요한 점은, Cairo에서 불리언 변수를 선언할 때는 반드시 `true`나 `false` 리터럴을 값으로 사용해야 한다는 거예요. 즉 `0`이나 `1` 같은 정수 리터럴을 `false`나 `true` 대신 사용할 수 없어요. 이 규칙을 엄격하게 지키면 타입 안전성이 보장되고, 스마트 컨트랙트 개발에서 생길 수 있는 논리 오류를 막을 수 있어요.

## Cairo의 불리언 연산자

- `||` (논리 OR): 피연산자 중 적어도 하나가 `true`이면 `true`를 반환해요.
- `&&` (논리 AND): 피연산자 두 개가 모두 `true`이면 `true`를 반환해요.
- `!` (논리 부정): 피연산자의 반대 불리언 값을 반환해요.

## 예제 코드

다음 코드는 Cairo에서 불리언 타입을 사용하는 방법을 보여줘요. 불리언 변수를 선언하고, 불리언 표현식을 할당하고, 어서션으로 불리언 논리가 올바른지 확인하는 모습을 볼 수 있어요:

```rust
fn main() {
    // Declaration of Boolean variables
    let t: bool = true;
    let f: bool = false;

    // Boolean expression evaluation
    let true_expr = 5 == 5; // true
    let false_expr = 7 == 5; // false

    // Using Boolean operators
    let or_expr = t || f; // true || false => true
    let and_expr = t && f; // true && false => false
    let not_expr = !f; // !false => true

    // Assertions to verify the correctness
    assert(t == true_expr, 'this should be true'); // t == true
    assert(f == false_expr, 'this should be false'); // f == false
    assert(or_expr == true, 'this should be true for OR'); // true
    assert(and_expr == false, 'this should be false for AND'); // false
    assert(not_expr == true, 'this should be true for NOT'); // true
}
```
