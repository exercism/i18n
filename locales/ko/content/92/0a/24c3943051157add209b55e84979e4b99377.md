# 지침

이 연습 문제에서는 Cairo의 제어 흐름 구문을 사용해 작은 빵집의 일상 운영을 관리해요.

## 1. 주문 총액 계산하기

페이스트리 종류와 수량을 바탕으로 주문 비용을 계산하는 `calculate_total`을 구현해요:

- 크루아상: 개당 3코인
- 머핀: 개당 2코인
- 쿠키: 개당 1코인

```rust
calculate_total(Pastry::Croissant, 4) // Returns: 12 (4 * 3)
calculate_total(Pastry::Cookie, 10)   // Returns: 10 (10 * 1)
```

## 2. 대량 할인 적용하기

주문 총액을 기준으로 할인을 적용하는 `apply_discount`를 구현해요.
총액에 할인율을 적용한 다음, 가장 가까운 정수 코인으로 내림해요(floor).

- 주문 금액이 20코인 이상: 10% 할인
- 주문 금액이 10코인 이상: 5% 할인
- 주문 금액이 10코인 미만: 할인 없음

```rust
apply_discount(25) // Returns: 22
apply_discount(15) // Returns: 14
apply_discount(8)  // Returns: 8
```

## 3. 베이킹 일정 만들기

하루치 베이킹 계획을 만드는 `baking_schedule`을 구현해요.
빵집은 한 시간에 주문 5개씩 묶음 단위로 구워요:

```rust
baking_schedule(18) // Returns: [5, 5, 5, 3] (3 full batches + 3 remaining)
baking_schedule(10) // Returns: [5, 5] (2 full batches)
baking_schedule(3)  // Returns: [3] (1 partial batch)
```

각 문제를 효율적으로 해결하려면 적절한 제어 흐름 구문(`if`/`else`, `loop`)을 사용해요.
