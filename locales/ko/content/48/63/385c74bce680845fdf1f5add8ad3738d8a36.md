# 로그 라인 파서

## 스토리

이 연습 문제에서는 로그 라인을 처리해요.

각 로그 라인은 다음과 같은 형식의 문자열이에요: `"[<LEVEL>]: <MESSAGE>"`.

로그 레벨은 세 가지가 있어요:

- `INFO`
- `WARNING`
- `ERROR`

## 작업

다음은 로그 라인 파서에 맞는 예시 작업이에요:

- 로그 라인에서 메시지 가져오기
- 로그 라인에서 로그 레벨 가져오기
- 로그 라인을 다른 형식으로 변환하기
