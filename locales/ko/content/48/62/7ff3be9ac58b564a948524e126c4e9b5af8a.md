# 힌트

## 일반

- [`Set` API 문서][set-docs]에는 `Set` 인터페이스에서 사용할 수 있는 메서드 목록이 있어요.

## 1. 컬렉션 시작하기

- [`HashSet` 클래스][hashset-docs]에는 `Collection`을 받는 생성자가 있어요.

## 2. 컬렉션 키우기

- `Set` 인터페이스에 정의된 [`add` 메서드][set-add-docs]의 시그니처를 확인해 봐요.

## 3. 거래 시작하기

- `Set`을 `new HashSet<>()`로 감싸면 복사본을 만들 수 있어요.
- [`Set` 인터페이스][set-docs]에는 다른 `Collection`에 들어 있는 모든 항목을 제거하는 메서드가 있어요.

## 4. 공통 카드 찾기

- `Set`을 `new HashSet<>()`로 감싸면 복사본을 만들 수 있어요.
- [`Set` 인터페이스][set-docs]에는 다른 `Collection`에 들어 있는 모든 항목을 남기는 메서드가 있어요.

## 5. 모든 카드

- `Set`을 `new HashSet<>()`로 감싸면 복사본을 만들 수 있어요.
- [`Set` 인터페이스][set-docs]에는 다른 `Collection`에 들어 있는 모든 항목을 추가하는 메서드가 있어요.
