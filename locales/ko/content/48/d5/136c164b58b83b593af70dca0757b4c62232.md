# 테스트

의존성을 설치해요.

```sh
dart pub get
```

테스트를 실행해요.

```sh
dart test
```

테스트별 출력을 더 자세히 보려면 expanded 리포터를 사용해요.

```sh
dart test -r expanded
```

대부분의 연습 문제에는 테스트가 여러 개 있고, 첫 번째 테스트를 제외한 나머지는 기본적으로 건너뛰어요.
테스트를 한 번에 하나씩 진행하려면, 각 테스트의 `skip: true`를 `skip: false`로 바꿔 가며 해요.

또는 파일을 수정하지 않고 모든 테스트를 한 번에 실행할 수도 있어요.

```sh
dart test --run-skipped
```

제출하면 온라인 테스트 러너가 건너뛴 테스트를 포함해 모든 테스트를 실행해요.
