# 소개

[`Rational numbers`][rational]은 정수 분자를 정수 분모로 나눈 분수예요.

예를 들어, 근삿값인 `Float64` 값 `0.6666...` 대신 `2//3`을 정확한 분수로 저장할 수 있어요.

이 방식의 장점은 [integer overflow][integer-overflow]라는 극단적인 경우를 빼면 유리수가 정확한 값을 그대로 유지하기 때문에, 부동소수점 숫자에서 흔히 피할 수 없는 반올림 오류를 피할 수 있다는 거예요.

더 자세한 내용은 Julia [매뉴얼 페이지][julia-rational]에 있어요.

유리수는 아주 단순한 숫자 타입이고, 기대하는 대로 동작하도록 만들어졌어요.
초기 버전부터 Julia의 표준 타입이었기 때문에, 대부분의 함수가 정수나 부동소수점과 같은 방식으로 유리수를 입력으로 받아요.

## 유리수 만들기

만드는 방법은 두 정수 사이에 `//`를 쓰는 것만큼 간단해요.

```julia-repl
julia> 3//4
3//4

julia> a = 3; b = 4;

julia> a//b
3//4
```

공약수는 자동으로 약분되어 분수가 ["최소 항"][lowest-terms]으로 바뀌어요. 최소 항이란 분수를 정확하게 나타내는 가장 작은 정수들이고, 분모는 음수가 아니에요.

```julia-repl
julia> 5//15
1//3

julia> 5//-15
-1//3
```

무한대 결과는 허용되지만, [`NaN`][NaN]은 허용되지 않아요.

```julia-repl
julia> 1//0
1//0

julia> float(1//0)
Inf

julia> 0//0
ERROR: ArgumentError: invalid rational: zero(Int64)//zero(Int64)
```

## 유리수의 산술 연산

일반적인 [`arithmetic operators`][operators] `+ - * / ^ %`는 다른 숫자 타입과 거의 같은 방식으로 유리수에도 쓸 수 있어요.

정수나 다른 `Rational`을 함께 넣어도 결과는 `Rational`이에요.
식에 `float`을 넣으면 결과도 `float`이 되고, 그에 따라 정밀도가 (손실될 수도) 떨어져요.

`float`이 필요하면 `float()` 함수로 유리수를 변환하면 돼요.
긴 계산 동안 정밀도를 유지하려고 유리수를 쓰다가 마지막에 실수로 변환하는 건 아주 흔한 일이에요.

```julia-repl
julia> 3//4 + 1//3  # addition
13//12

julia> 3//4 * 1//3  # multiplication
1//4

julia> 3//4 / 1//3  # division
9//4

julia> 3//4 ^ 2  # exponentiation
3//16

julia> 3//4 + 5  # rational and int => rational
23//4

julia> 3//4 + 5.3  # rational and float => float
6.05

julia> float(3//4)  # casting
0.75
```

유리수는 [복소수][complex]와도 함께 쓸 수 있어요.
복소수는 [별도의 개념][complex-concept]에서 다뤄요.

## 그 밖의 연산

Julia에서 유리수는 그냥 숫자예요.
컴파일러가 보통 필요한 대로 타입을 변환해 줘요.

다만, 비교는 소수로 유한하게 나타낼 수 있는 분수에 대해서만 예상대로 동작한다는 점을 조심해요.

```julia-repl
julia> 3//4 == 0.75
true

julia> 3//4 < 0.74
false
```

그 외의 경우에는 비교하려면 `Rational`을 `Float`로 변환해야 해요.

```julia-repl
julia> 1//3 == 1/3
false

julia> float(1//3) == 1/3
true
```

수학 함수는 유리수를 입력으로 받지만, 결과는 부동소수점일 수 있어요.

```julia-repl
julia> sqrt(9//16)
0.75
```
