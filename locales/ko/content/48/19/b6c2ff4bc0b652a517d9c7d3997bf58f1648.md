# 지침

Markdown 파서를 리팩터링해요.

markdown 연습 문제는 리팩터링을 위한 연습 문제예요. 주어진 문자열을 [Markdown 문법](https://guides.github.com/features/mastering-markdown/)으로 파싱하고, 그 문자열에 해당하는 HTML을 반환하는 코드가 있어요. 이 코드는 알아보기 어렵게 작성되어 있고 따라가기도 힘들지만, 어찌저찌 잘 동작하고 모든 테스트도 통과하고 있어요! 이번 과제는 이 코드를 다시 작성해서 읽기 쉽고 유지보수하기 쉽게 만들면서, 모든 테스트가 계속 통과하도록 하는 거예요.

리팩터링하면서 무엇을 했는지 주석으로 남겨두면 리뷰하는 사람이 확인하기 좋지만, 꼭 필요한 건 아니에요. 가장 중요한 건 코드를 더 나은 코드로 만드는 거예요!
