# 소개

Elixir에서는 함수가 여러 개의 절을 가질 수 있어서 **개방-폐쇄 원칙**을 실천하기 좋아요. 덕분에 여기저기 흩어진, 하드코딩된 제어 로직 대신 동작을 쉽게 더하거나 뺄 수 있는 함수를 목적에 맞게 작성할 수 있어요.

Elixir는 이렇게 작성할 수 있도록 _여러 함수 절_과 _가드_를 제공해요:

```elixir
def number(n) when n == 7 do
  "Awesome, that's my favorite"
end

def number(_n) do
  "That's not my favorite"
end
```

실행할 때 Elixir는 소스 파일의 위에서 아래로 어떤 함수 절을 호출할지 검사해요.

사용하지 않는 변수에는 이름 앞에 밑줄을 붙여요.
