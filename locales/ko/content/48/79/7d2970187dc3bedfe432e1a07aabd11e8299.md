# 지시사항

이 연습 문제에서는 고등학교 커플이 소셜 미디어에서 사랑을 고백할 수 있도록, 두 사람의 이니셜이 들어간 ASCII 상자를 만들어 줄 거예요:

```
❤-------------------❤
|  J. K.  +  M. B.  |
❤-------------------❤
```

## 1. 이름의 첫 글자 가져오기

`HighSchoolSweetheart.first_letter/1` 함수를 구현해요. 이름을 받아서 첫 글자를 반환해요. 이름에 있는 불필요한 공백은 정리해요.

```elixir
HighSchoolSweetheart.first_letter("Jane")
# => "J"
```

## 2. 첫 글자를 이니셜 형식으로 만들기

`HighSchoolSweetheart.initial/1` 함수를 구현해요. 이름을 받아서 첫 글자를 대문자로 바꾼 뒤 마침표를 붙여 반환해요. 이전 단계에서 정의한 `HighSchoolSweetheart.first_letter/1`을 반드시 재사용해요.

```elixir
HighSchoolSweetheart.initial("Robert")
# => "R."
```

## 3. 전체 이름을 이름과 성으로 나누기

`HighSchoolSweetheart.initials/1` 함수를 구현해요. 공백으로 구분된 이름과 성으로 이루어진 전체 이름을 받아서 이니셜을 반환해요. 이전 단계에서 정의한 `HighSchoolSweetheart.initial/1`을 반드시 재사용해요.

```elixir
HighSchoolSweetheart.initials("Lance Green")
# => "L. G."
```

## 4. 이니셜을 ASCII 상자 안에 넣기

`HighSchoolSweetheart.pair/2` 함수를 구현해요. 전체 이름 두 개를 받아서 이니셜이 들어간 ASCII 상자를 반환해요. 상자를 직접 그릴 필요는 없어요. 코드 주석에 있는 상자를 활용해요. 이전 단계에서 정의한 `HighSchoolSweetheart.initials/1`을 반드시 재사용해요.

```elixir
HighSchoolSweetheart.pair("Blake Miller", "Riley Lewis")
# => """
# ❤-------------------❤
# |  B. M.  +  R. L.  |
# ❤-------------------❤
# """
```
