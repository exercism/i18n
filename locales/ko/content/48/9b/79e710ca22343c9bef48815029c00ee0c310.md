# 소개

## 화살표 함수

함수 선언과 함수 표현식 외에도, JavaScript에는 함수를 정의하는 아주 간결한 문법이 하나 더 있어요.
이런 함수를 _화살표 함수_라고 해요.

다음은 함수 선언과 화살표 함수를 비교한 예시예요.

```javascript
function addUpTwoNumbers(num1, num2) {
  return num1 + num2;
}
// function keyword removed and => added
const addUpTwoNumbers = (num1, num2) => {
  return num1 + num2;
};
```

위 예시처럼 함수 본문에 return문만 있다면, `{}`와 `return` 키워드는 생략할 수 있어요.
매개변수가 하나뿐이라면 괄호 `()`도 생략할 수 있어요.

<!-- prettier-ignore-start -->
```javascript
const addUpTwoNumbers = (num1, num2) => num1 + num2;
const square = num => num * num;
```
<!-- prettier-ignore-end -->

화살표 함수는 함수를 호출할 때 짧은 콜백 함수를 바로 정의하는 데 자주 쓰여요.

<!-- prettier-ignore-start -->
```javascript
applyToSquare(number => number * number);
```
<!-- prettier-ignore-end -->

## 배열 분석

[배열][arrays-concept]에는 배열의 내용을 분석하는 내장 메서드가 있어요.
이런 메서드 대부분은 true나 false를 반환하는 함수를 인자로 받아요.
이런 함수를 [`predicate`][predicate_in_programming]라고 해요.

내장 메서드는 `for`문이나 내장 `forEach` 메서드 _대신_ 사용하도록 만들어졌어요.

`for`문으로 분석한 예시:

```javascript
const numbers = [1, 'two', 3, 'four'];
for (var i = 0; i < numbers.length; i++) {
  if (numbers[i] === 'two') {
    return i;
  }
}
// => 1
```

내장 메서드로 분석한 예시:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.indexOf('two');
// => 1
```

아래에는 배열을 분석할 때 쓸 수 있는 다른 유용한 내장 메서드 몇 가지를 소개해요.
배열 메서드의 전체 목록은 [MDN][mdn-array-methods]을 참고해요.

### `includes`

`includes(value)` 메서드는 배열에 특정 값이 포함되어 있는지 확인해요.
값이 포함되어 있으면 `true`를, 그렇지 않으면 `false`를 반환해요.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.includes(1);
// => true
numbers.includes('one');
// => false
```

### `every`

`every(predicate)` 메서드는 _predicate_ 역할을 하는 함수를 받아요.
배열의 모든 원소를 predicate에 넘겼을 때 `true`를 반환하는지 검사해요.
다시 말해, 모든 원소가 함수 호출에 전달된 테스트를 통과하는지 검사하는 메서드예요.
모든 원소가 predicate 테스트를 통과하면 `true`를, 그렇지 않으면 `false`를 반환해요.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.every((num) => num % 2 !== 0);
// => true
```

### `some`

`some(predicate)` 메서드는 `every` 메서드와 같지만, 배열에서 항목이 최소한 하나라도 _predicate_ 테스트를 통과하면 `true`를 반환해요.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.some((num) => num % 2 !== 0);
// => true
```

### `find`

`find(predicate)` 메서드는 배열에서 `predicate` 테스트를 통과하는 첫 번째 원소의 값을 반환해요.
`some()`이 통과할 때 `true`를 반환한다면, `find()`는 배열에 있는 실제 값을 반환해요.
배열의 어떤 원소도 _predicate_ 테스트를 통과하지 못하면 `undefined`를 반환해요.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.find((num) => num < 5);
// => 1
```

### `findIndex`

`findIndex(predicate)`는 `find()` 메서드와 같지만, _predicate_ 테스트를 통과한 원소의 `value` 대신 (첫 번째) _index_를 반환해요.
어떤 원소도 _predicate_ 테스트를 통과하지 못하면 `-1`을 반환해요.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.findIndex((num) => num > 7);
// => 4
numbers.findIndex((num) => num > 9);
// => -1
```
