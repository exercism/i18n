# 지침

지진계 배열의 처리 스테이션을 관리하고 있어요. 지진계 배열은 지면이 어떻게 움직이는지 기록하는 센서 네트워크예요.

측정값은 값 블록 단위로 들어와요.
일부는 32비트 부동소수점 수로 저장된 지면 변위이고, 다른 일부는 32비트 정수로 저장된 원시 카운트와 상태 워드예요.
스테이션은 블록 전체를 한 번에 처리하면서 각 값에 같은 연산을 적용해요.

여섯 개의 작업이 있고, 각 작업은 메모리에 있는 값 블록을 대상으로 동작해요.
메모리 주소를 통해 피연산자를 받고, 결과 주소를 통해 답을 써요.
이 연습 문제의 모든 메모리 주소는 16바이트로 정렬되어 있어요.

~~~~exercism/note
이 연습 문제의 계산은 스칼라 연산이 아니라 SIMD 비트 연산과 시프트를 사용해 수행해야 해요.
~~~~

## 1. 파형을 정류하기

규모 분석에서는 각 지면 변위의 방향이 아니라 크기만 중요해요.
첫 번째 처리 단계에서는 모든 측정값을 음수가 아닌 값으로 바꿔요.

각 측정값의 절댓값을 계산하는 `rectify_trace` 함수를 구현해요.
블록에는 측정값 4개가 들어 있고, 각각 32비트 부동소수점 수예요.

이 함수는 다음 순서로 인자를 받아요:

- `result`: 정류된 측정값 4개가 기록될 버퍼의 메모리 주소예요.
- `trace`: 기록된 측정값의 메모리 주소이고, 값 4개가 있으며 각각 32비트 부동소수점 수예요.

```c
trace  = {1.5, -2.25, 0.0, -135.75}
result = {1.5,  2.25, 0.0,  135.75}
```

이 함수는 반환 값이 없어요.

## 2. 미세 진동의 스케일 읽기

분석가들은 미세 진동을 2의 거듭제곱으로 등급을 매겨요. `8.0`에 가까운 측정값은 스케일 `3`이고, `0.25`에 가까운 측정값은 스케일 `-2`예요.
그 스케일은 이미 각 부동소수점 수 안에 지수 필드로 저장되어 있어요.

32비트 부동소수점 수는 비트 31에 부호 비트, 비트 30부터 23까지에 8비트 지수, 비트 22부터 0까지에 23비트 소수부가 배치되어 있어요.
저장된 지수는 127만큼 바이어스되어 있어서, 수의 값은 `(-1)^sign * 1.fraction * 2^(exponent - 127)`이에요.

각 측정값의 바이어스를 제거한 지수를 부호 있는 32비트 정수로 추출하는 `reading_scale` 함수를 구현해요.

이 함수는 다음 순서로 인자를 받아요:

- `result`: 스케일 4개가 기록될 버퍼의 메모리 주소이고, 각각 부호 있는 32비트 정수예요.
- `trace`: 정류된 측정값의 메모리 주소이고, 값 4개가 있으며 각각 32비트 부동소수점 수예요.

```c
trace  = {8.0, 0.25, 1.0, 13.5}
result = {  3,   -2,   0,   3}
```

이 함수는 반환 값이 없어요.
모든 측정값은 0이 아닌 정규 부동소수점 수예요.

## 3. 해상도 거칠게 하기

장기 저장을 위해 원시 변위 카운트는 더 거친 해상도로 보관해요. 각 카운트를 2의 거듭제곱으로 나눠요.

변위 카운트에는 부호가 있어요. 지면은 양방향으로 움직일 수 있으니까요.
이들을 올바르게 나누려면 부호를 보존하는 시프트가 필요해요.

각 부호 있는 카운트를 `2^shift`로 나누되 음의 무한대 방향으로 반올림하는 `coarsen_displacements` 함수를 구현해요.

이 함수는 다음 순서로 인자를 받아요:

- `result`: 거칠어진 카운트 4개가 기록될 버퍼의 메모리 주소이고, 각각 부호 있는 32비트 정수예요.
- `counts`: 원시 카운트의 메모리 주소이고, 부호 있는 32비트 정수 4개가 있어요.
- `shift`: 나눌 2의 거듭제곱이고, `0`과 `31` 사이의 64비트 부호 없는 정수예요.

```c
counts = {1024, -1024, 25, -25}
shift  = 3
result = { 128,  -128,  3,  -4}
```

~~~~exercism/note
`movq` 명령어를 사용하면 기반 비트 표현을 바꾸지 않고 범용 레지스터에서 `xmm` 레지스터로 64비트 정수를 복사할 수 있어요.
~~~~

이 함수는 반환 값이 없어요.

## 4. 채널 게이팅하기

각 스테이션은 두 번의 기록 캠페인을 병합한 다음, 하드웨어 보고서가 결함으로 표시한 채널을 꺼요.
각 블록에는 채널 마스크 4개가 들어 있고, 각각 부호 없는 32비트 정수이며, 각 비트가 채널 하나를 나타내요. `1`은 활성화, `0`은 비활성화예요.

두 캠페인 중 하나라도 활성화한 채널을 합친 다음 결함으로 표시된 모든 채널을 지우는 `gate_channels` 함수를 구현해요.

이 함수는 다음 순서로 인자를 받아요:

- `result`: 게이팅된 마스크 4개가 기록될 버퍼의 메모리 주소이고, 각각 부호 없는 32비트 정수예요.
- `enable_a`: 첫 번째 캠페인의 활성화 마스크 메모리 주소이고, 부호 없는 32비트 정수 4개가 있어요.
- `enable_b`: 두 번째 캠페인의 활성화 마스크 메모리 주소이고, 부호 없는 32비트 정수 4개가 있어요.
- `faulty`: 결함 채널 마스크의 메모리 주소이고, 부호 없는 32비트 정수 4개가 있어요.

```c
enable_a = {0b1100, 0b0001, 0b1111, 0b0000}
enable_b = {0b0110, 0b0001, 0b0000, 0b0000}
faulty   = {0b0100, 0b0011, 0b1001, 0b1111}
result   = {0b1010, 0b0000, 0b0110, 0b0000}
```

이 함수는 반환 값이 없어요.

## 5. 보정 비트 토글하기

스테이션은 하루에 한 번 보정 작업을 실행해서, 각 상태 워드에서 선택한 구성 비트 집합을 뒤집고 나머지 비트는 그대로 둬요.
그런데 일부 비트는 하드웨어에 의해 잠겨 있어서, 보정 작업이 무엇을 요청하든 절대 바뀌면 안 돼요.
같은 작업을 두 번 실행하면 원래 구성으로 돌아와요.

각 상태 워드에서 해당 토글 마스크에 설정되어 있고 해당 잠금 마스크에 설정되지 않은 비트만 정확히 뒤집는 `toggle_calibration` 함수를 구현해요.

이 함수는 다음 순서로 인자를 받아요:

- `result`: 갱신된 상태 워드 4개가 기록될 버퍼의 메모리 주소이고, 각각 부호 없는 32비트 정수예요.
- `status`: 현재 상태 워드의 메모리 주소이고, 부호 없는 32비트 정수 4개가 있어요.
- `toggle`: 토글 마스크의 메모리 주소이고, 부호 없는 32비트 정수 4개가 있어요.
- `locked`: 잠금 마스크의 메모리 주소이고, 부호 없는 32비트 정수 4개가 있어요.

```c
status = {0b1100, 0b0001, 0b1111, 0b1010}
toggle = {0b0110, 0b0011, 0b1111, 0b1010}
locked = {0b0010, 0b0001, 0b1100, 0b0000}
result = {0b1000, 0b0011, 0b1100, 0b0000}
```

이 함수는 반환 값이 없어요.

## 6. 파형 증폭하기

배열의 각 채널에는 2의 거듭제곱으로 표현되는 자체 이득 조정값이 있어요. 이득이 `3`이면 채널의 측정값에 `8`을 곱하고, 이득이 `-5`이면 `32`로 나눠요.

스테이션은 곱셈을 한 번도 쓰지 않고 각 부동소수점 수의 지수 필드를 조작해서 이득을 적용해요.

원시 비트만 다루면서 각 측정값에 채널 이득만큼 거듭제곱한 `2`를 곱하는 `amplify_trace` 함수를 구현해요.

이 함수는 다음 순서로 인자를 받아요:

- `result`: 증폭된 측정값 4개가 기록될 버퍼의 메모리 주소예요.
- `trace`: 측정값의 메모리 주소이고, 값 4개가 있으며 각각 32비트 부동소수점 수예요.
- `gains`: 채널별 이득의 메모리 주소이고, 부호 있는 32비트 정수 4개가 있어요.

```c
trace  = {1.5, -2.0, 0.25, 96.0}
gains  = {  2,    1,    3,   -5}
result = {6.0, -4.0,  2.0,  3.0}
```

이 함수는 반환 값이 없어요.
모든 측정값은 0이 아닌 정규 부동소수점 수이고, 증폭된 결과도 모두 정규수예요.
