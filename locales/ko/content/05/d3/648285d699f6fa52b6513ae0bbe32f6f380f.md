# 추가 사항

## GNU awk와 임의 정밀도 연산

기본적으로 `awk`의 숫자는 배정밀도 부동소수점 수로 표현돼요. 이 방식은 53비트의 정밀도를 제공해요(매뉴얼의 [표 16.3][table-16.3] 참고). 아쉽게도 이 정도로는 이 연습 문제를 끝낼 수 없어요(스포일러: 한 테스트는 63비트의 정밀도를 요구해요).

"정밀도 부족"은 이렇게 나타나요:
```sh
$ gawk 'BEGIN {
  n = 2 ^ 54
  if (n == n + 1)
    print "not enough precision"
  else
    print "OK"
}'
```
```none
not enough precision
```

GNU `awk`는 관련 라이브러리가 `awk` 실행 파일에 함께 컴파일되어 있으면 임의 정밀도 수를 사용할 수 있어요. awk 버전을 확인하고 "GNU MPFR"이 있는지 찾아봐요:
```sh
$ gawk --version
GNU Awk 5.0.1, API: 2.0 (GNU MPFR 4.0.2, GNU MP 6.2.0)
...
```

있으면 `-M` 옵션으로 이 기능을 켜요:
```sh
$ gawk -M 'BEGIN {
  n = 2 ^ 54
  if (n == n + 1)
    print "not enough precision"
  else
    print "OK"
}'
```
```none
OK
```

내 `awk`에 `-M`이 없다면 어떻게 할까요? 그럴 때는 `bc`처럼 임의 정밀도 연산을 할 수 있는 외부 프로그램을 불러와야 해요. 이 방법의 예는 [파이프에서 변수로 getline 사용하기][getline-pipe] 섹션을 참고해요.
