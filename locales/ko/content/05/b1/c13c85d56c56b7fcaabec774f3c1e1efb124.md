# 소개

`bit`은 컴퓨팅에서 가장 세분화된 값이에요.
`bit`이라는 단어는 "binary digit"을 줄인 말이에요.
`bit`은 실행 환경에서 두 값 중 하나를 가질 수 있는 객체를 담을 수 있을 만큼 큰 데이터 저장 단위예요.
따라서 `1` 또는 `0` 중 하나의 이진 값을 가져요.
다른 모든 데이터 타입은 여러 개의 `bits`로 이루어져 있어요.
예를 들어 `byte`는 보통 여덟 개의 `bits`로 이루어져 있어요.

## 비트 마스크

비트 마스크는 개별 비트를 설정하는 데 사용되는 값이면 무엇이든 될 수 있어요.
예를 들어, 영어 알파벳에는 스물여섯 개의 글자가 있어요.
부호 없는 32비트 정수처럼 적어도 스물여섯 비트의 값을 가진 값은 각 영어 글자에 대해 `true` 또는 `false` 상태를 설정하는 비트 마스크로 사용할 수 있어요.
필요한 `true` 또는 `false` 상태 집합을 처리할 만큼 충분한 비트를 가진 값이라면 무엇이든 비트 마스크로 쓸 수 있어요.
개별 비트를 설정하고 읽는 일은 비트 연산자를 통해 해요.

## 비트 연산자

`string`에 어떤 글자들이 나타나는지 추적하고 싶다고 해봐요.
예제에서는 영어 알파벳의 스물여섯 글자만 사용할게요.
비트 마스크는 부호 없는 32비트 정수예요.
`0`은 글자가 나타나지 않는다는 뜻이에요.
`1`은 글자가 한 번 이상 나타난다는 뜻이에요.
처음에 비트 마스크의 비트 표현은 32개의 `0s`가 나란히 이어진 형태예요: `00000000000000000000000000000000`.
가장 오른쪽 자리는 `A`를 나타내요.
왼쪽에서 두 번째 자리는 `B`를 나타내고, 그다음도 같은 식이에요.
문자열의 모든 글자를 루프로 처리한다고 해봐요. 그래서 어떤 글자든 설정할 수 있는 한 줄의 코드가 필요해요.

### 비트 왼쪽 시프트 연산자: 비트를 배치하는 방법

`<<`는 왼쪽 시프트를 위한 비트 연산자예요.

글자가 `A`라면 왼쪽으로 시프트할 필요가 없지만, `B`라면 한 자리 왼쪽으로 시프트하고, `C`라면 두 자리 왼쪽으로 시프트하는 식이에요.
`chars`를 `A`나 `B` 같은 글자로 인식할 수 있지만, `char`는 메모리에서 정수 타입으로 구현되기 때문에 `char`로 간단한 산술 연산을 할 수 있어요.
처리 중인 `char`를 나타내는 `letter`라는 변수가 주어졌을 때, `1`을 `letter`와 `A` `char`의 차이만큼 왼쪽으로 시프트하면 필요한 자리 수만큼 왼쪽으로 이동할 수 있어요. 이렇게요: `1 << letter - 'A'`.
`A` - `A`는 `0`이므로, `letter`가 `A`라면 `0`자리 왼쪽으로 시프트해요.
`B` - `A`는 `1`이므로, `letter`가 `B`라면 `1`자리 왼쪽으로 시프트하고, 그다음도 마찬가지예요.

### 비트 포함 OR 연산자: 비트를 설정하는 방법

비트를 _어디에_ 설정할지 알았다면, 이제 `|`인 비트 포함 OR 연산자를 사용해서 실제로 설정할 수 있어요.
`|` 연산자의 결과는 왼쪽이나 오른쪽 피연산자 중 하나라도 비트가 설정된 각 자리에서 `1`이 돼요.
따라서 `0010 | 0001`의 결과는 `0011`이에요.
(이 값이 이진수로는 `11`이지만 십진수로는 `3`이라는 점을 기억해 두는 게 중요해요.)
결과를 값에 대입하려면, `|` 연산자를 대입 연산자와 결합해서 이렇게 비트를 설정할 수 있어요: `|=`.
간단하게 하기 위해 다음 예제에서는 루프를 사용하지 않지만, 비트 마스크에서 `ABA`라는 글자들을 처리하는 방법을 보여줘요.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    // it's important to initialize the mask to 0 so we don't get garbage values
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    mask |= 1 << letter_A_again - 'A';
    // prints 3
    printf("%d", mask);
}
```

`A`를 위해 마스크의 가장 오른쪽 부분을 `0001`로 설정하고, 그다음 `B`를 위해 마스크를 `0011`로 설정해요.
`A`를 한 번 더 설정해도 기존 마스크에는 아무 변화가 없어요.
`A`가 이미 설정되었는지 확인해서 비트를 다시 설정하지 않도록 할 수도 있었어요.

### 비트 AND 연산자: 비트를 읽는 방법

`&`는 비트 AND 연산자예요.
`&` 연산자의 결과는 왼쪽과 오른쪽 피연산자 모두 비트가 설정된 각 자리에서 `1`이 돼요.
따라서 `0011 & 0001`의 결과는 `0001`이에요.
다음 예제에서 실제로 확인할 수 있어요.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    // prints A already set
    if (mask & 1 << letter_A_again - 'A')
        printf("A already set\n");
    else
        mask |= 1 << letter_A_again - 'A';
    printf("%d", mask);
}
```

### 비트 배타적 OR 연산자: 비트를 뒤집는 방법

`^`는 비트 배타적 OR 연산자예요.
_포함_ OR 연산자가 있다면 동작이 다른 _배타적_ OR 연산자도 있다는 뜻이에요.
`^` 연산자의 결과는 왼쪽이나 오른쪽 피연산자 중 _하나만_ 비트가 설정된 각 자리에서 `1`이 돼요.
따라서 `0001 ^ 0011`의 결과는 `0010`이에요.
가장 오른쪽 비트는 설정되지 않는데, _두_ 피연산자 모두 가장 오른쪽 자리에 `1`이 있기 때문이에요.
배타적 OR 연산은 XOR로 표기하기도 해요.
XOR한 값의 결과를 다시 XOR하면 원래 값이 나와요.
이것은 같은 키로 데이터를 암호화하고 복호화하는 아주 간단한 암호화에 사용할 수 있어요.
예를 들어

```c
#include <stdio.h>

int main() {
    char a = 'a';
    char b = 'b';
    char c = 'c';
    // we will use "a" for the "key"
    char first = a ^ 'a';
    char second = b ^ 'a';
    char third = c ^ 'a';
    // prints three "dots" for unprintable characters
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 0 3 2
    printf("%d %d %d\n", first, second, third);
    first = first ^ 'a';
    second = second ^ 'a';
    third = third ^ 'a';
    // prints a b c
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 97 98 99
    printf("%d %d %d\n", first, second, third);
}
```

## 비트 필드

간단한 데이터 타입에 압축된 비트를 위치로 다루는 방법을 살펴봤어요.
`struct`에 압축된 비트는 이름으로 다룰 수 있어요.
이런 데이터 타입을 `bit field`라고 해요.
`bit fields`의 활용 사례로는 ON/OFF 플래그 모음이 필요하고 메모리 사용을 최소화하고 싶을 때가 있어요.

```c
#include <stdio.h>

int main() {

    struct lights {
        unsigned int number_of_lights;
        unsigned int red   : 1;
        unsigned int green : 1;
        unsigned int blue  : 1;
    };
    struct lights lightboard = {3, 0, 0, 0};
     
    //  prints 000
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    lightboard.green = 1;

    //  prints 010
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    // prints 3
    printf("%d\n", lightboard.number_of_lights);
}
```

`unsigned int variable_name : 1;` 문법은 구조체 안에 배치된 `unsigned int` 안에 `1`비트짜리 필드를 만들어요.
`unsigned int` 대신 `signed int`를 사용할 수도 있고, C99 이후 버전에서는 `bool` 타입을 사용할 수도 있어요.
비트 필드를 포함하는 구조체는 위 예제의 `number_of_lights`처럼 다른 데이터 타입의 필드도 포함할 수 있어요.
