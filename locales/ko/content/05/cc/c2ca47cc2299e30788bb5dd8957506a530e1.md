# 테스트

## 대화식으로 테스트하기

연습 문제를 내려받은 디렉터리에서 REPL을 시작해요.

REPL에 테스트 파일을 `(load "exercise-test")`로 불러오면 테스트를 실행할 수 있어요. 이때 "exercise"는 알맞은 이름으로 바꿔 주세요. 그런 다음 `(exercise-test:run-tests)`를 평가하면 모든 테스트가 실행돼요.

코드를 REPL에 직접 작성했다면 `(exercise-test:run-tests)`만 평가하면 돼요.

코드를 연습 문제 Lisp 파일에 작성했다면 `(load "exercise")`로 불러온 다음 `(exercise-test:run-tests)`를 평가해요.

## 명령줄에서 테스트하기

다음 명령줄 명령으로 테스트를 실행할 수 있어요. 이때도 "exercise"를 알맞은 이름으로 두 곳에서 바꿔 주세요.

```sh
ros run --load exercise-test.lisp --eval '(uiop:quit (if (exercise-test:run-tests) 0 1))'
```
