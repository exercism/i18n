# 소개

추상 구문 트리(AST)는 _quoted expression_이라고도 불리며, 코드를 데이터로 표현하는 방법이에요.

AST의 각 노드는 세 개의 요소로 이루어진 튜플이에요.

```elixir
# AST representation of:
# 2 + 3
{:+, [], [2, 3]}
```

첫 번째 요소인 아톰은 연산이에요. 두 번째 요소인 키워드 리스트는 메타데이터예요. 세 번째 요소는 다른 노드들을 포함하는 인자 배열이에요. 정수, 아톰, 문자열 같은 리터럴 값은 세 개의 요소로 이루어진 튜플 대신 AST 안에서 자기 자신으로 표현돼요.

## 코드를 AST로 바꾸기

Elixir 코드를 AST로 바꾸고, AST를 다시 코드로 되돌리는 일은 표준 라이브러리에 포함되어 있어요. AST를 다루는 함수들은 `Code` 모듈(예: 코드가 담긴 문자열을 AST로 바꾸기)과 `Macro` 모듈(예: AST를 순회하거나 문자열로 바꾸기)에서 찾을 수 있어요.

참고로, 표준 라이브러리의 모든 함수는 AST를 가리킬 때 "quoted"라는 이름을 사용해요. (_quoted expression_의 줄임말이에요.)

코드를 AST로 바꾸는 특수 폼은 `quote`라고 해요. 이 폼은 코드 블록을 받아서 그 AST를 반환해요.

```elixir
quote do
  2 + 3 - 1
end

# => {:-, [], [
#      {:+, [], [2, 3]},
#      1
#    ]}
```

## 사용 사례

코드를 AST로 표현하는 능력은 Elixir 메타프로그래밍의 핵심이에요. _매크로_는 Elixir 코드를 만들어 내는 Elixir 코드를 작성하는 방법인데, 출력으로 AST를 반환하는 방식으로 동작해요.

AST의 또 다른 사용 사례는 정적 코드 분석이에요. Exercism 자체 도구인 Analyzer가 그 예인데, 풀이에 댓글을 남기는 작은 봇으로 이미 알고 있을지도 몰라요.
