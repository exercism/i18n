# 지침 추가

## Arturo 문자열에 관한 몇 가지 참고 사항

테스트에서 처음 보는 문법이 나올 수도 있어요. 바로 `{ braces }`로 감싼 여러 줄 문자열이에요.

### 참고 자료

* 언어 레퍼런스의 [`:string` 타입][string].
* Strings 모듈의 [기본 사용법][usage] 문서.

[string]: https://arturo-lang.io/documentation/language/#string
[usage]: https://arturo-lang.io/documentation/library/strings/#basic-usage

### Arturo 문자열 리터럴

Arturo에서 문자열 리터럴을 작성하는 방법은 몇 가지가 있어요:

1. 큰따옴표로 감싼 한 줄 문자열

    ```arturo
    greeting: "Hello, World!"

    print express greeting     ; => "Hello, World!"
    ```

1. 스마트 따옴표 `«`를 사용하는 줄 끝 문자열

    ```arturo
    farewell: « Goodbye, Mars!

    print express farewell     ; => "Goodbye, Mars!"
    ```

   짧은 문자열 목록이 있다면 이 방식이 훨씬 읽기 좋아요:

    ```arturo
    numberWords: [
        « one
        « two
        « three
        « four, and so on
    ]
 
    print express numberWords    ; => ["one" "two" "three" "four, and so on"]
    ```

1. 중괄호로 감싼 여러 줄 문자열이에요.
   "공통" 들여쓰기는 제거돼요.
   앞뒤의 줄 바꿈도 제거돼요.

    ```arturo
    multiline: {
        First line
        Second line
            Third line keeps indentation
        Last line!


    }

    print express first multiline   ; => 'F'
    print express last multiline    ; => '!'
    lines: split.lines multiline
    print size lines                ; => 4
    print express lines\2           ; => "    Third line keeps indentation"
    ```

1. 앞뒤 공백까지 포함해 그대로 보존되는 문자열

    ```arturo
    code: {:
        greet: function [name][
            print ~"Hello, |name|~"

        greet "World""
    :}

    print ">" ++ code ++ "<"
    print express first code
        ; => prints a literal newline character between single quotes
    print express (split.lines code | get 1)
        ; => "    greet: function [name]["
    ```

1. Heredoc 스타일 문자열은 하이픈 3개 이상으로 이루어진 줄 아래에 놓여 파일 끝까지 이어져요.
   Perl의 `__DATA__` 키워드와 같은 역할을 해요.
   이 방식은 모듈에서 유용하게 쓸 수 있어요. 파일 끝에서 문서나 라이선스 문구를 변수에 담아 둘 때 말이에요.

    "mymodule.art"라는 파일에 이렇게 써 두면

    ```arturo
    myLicense:
    ---------
    This text has been placed in the public domain.
    Do with it what you will.
    ```

    그러면

    ```arturo
    import {mymodule}!
    print ~">|myLicense|<"  ; => >This text has been placed in the public domain.
                            ; => Do with it what you will.<
    ```
