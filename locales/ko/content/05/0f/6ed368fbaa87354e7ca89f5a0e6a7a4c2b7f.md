# 소개

클래스는 Swift 프로그램을 이루는 기본 구성 요소예요.
클래스를 사용하면 관련 있는 속성(데이터)과 메서드(함수)를 하나로 묶어 독립적인 기능 단위로 만들 수 있어요.

### 클래스 정의하기

클래스를 정의하려면 `class` 키워드 뒤에 클래스 이름을 쓰고, 클래스 정의를 중괄호로 감싸요:

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id = makeRandomID()
}
```

클래스 본문에는 저장 프로퍼티를 둘 수 있는데, 저장 프로퍼티는 일반 상수(`let`)나 변수(`var`)처럼 정의되고 동작해요.

### 인스턴스

클래스 정의는 설계도와 같아요. 새로운 타입을 정의하고 그 값이 어떤 모습인지 설명하지만, 그 자체로 인스턴스를 만들지는 않아요.

클래스의 *인스턴스*를 만들려면, 클래스 이름 뒤에 괄호를 붙여 이니셜라이저를 호출해요:

```swift
let someCharacter = GameCharacter()
```

이렇게 하면 클래스 정의에 지정된 기본값으로 속성이 초기화된 새로운 인스턴스가 만들어져요.
명시적인 기본값이 없는 옵셔널 프로퍼티(예: `name`)는 Swift가 `nil`로 기본 설정해요.

### 속성에 접근하기

인스턴스의 속성에는 *점 표기법*으로 접근해요. 인스턴스 이름, 점(`.`), 속성 이름을 차례로 써요.
점 표기법은 중첩된 속성에도 똑같이 쓸 수 있어요.

점 표기법으로 값을 읽을 수 있고, 프로퍼티가 가변(`var`)이라면 새로운 값을 할당할 수도 있어요:

```swift
someCharacter.name
// => nil

someCharacter.name = "Luther"
someCharacter.name
// => "Luther"

someCharacter.id = "new id"
// Error: Cannot assign to property: 'id' is a 'let' constant
```

### 메서드

클래스는 속성 외에도 *메서드*를 정의할 수 있는데, 메서드는 클래스와 연결된 함수예요.

메서드는 클래스 본문 안에서 표준 `func` 문법으로 정의해요.
메서드가 프로퍼티를 수정한다면, 그 프로퍼티는 `var`로 선언해야 해요:

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id: String = makeRandomID()

    func takesDamage(_ damage: Double) {
        if damage > 100 {
            active = false
        }
    }

    func sayName() -> String {
        return "My name is \(name ?? "no one"), my class is \(characterClass ?? "undetermined")"
    }
}
```

메서드도 프로퍼티와 마찬가지로 점 표기법으로 인스턴스에서 호출해요:

```swift
var myChar = GameCharacter()
myChar.active = true
myChar.takesDamage(200)
myChar.active
// => false
```

### `self`

클래스의 모든 인스턴스에는 `self`라는 암시적인 프로퍼티가 있는데, 이는 인스턴스 자기 자신을 가리켜요.
프로퍼티나 메서드를 가리킬 때는 종종 생략하지만, 프로퍼티 이름과 메서드 매개변수 이름이 같을 때 둘을 구분하기 위해 `self`를 흔히 사용해요.
