# 힌트

## 1. 새로운 최고 점수판 만들기

- 중괄호를 사용해 새로운 객체를 만들어요.
- 키에 공백이 들어갈 수 있도록 키를 문자열로 작성해요.
- 키와 값은 콜론으로 구분해요.

## 2. 점수판에 플레이어 추가하기

- 변수(인자)에 저장된 이름을 키로 추가하려면 대괄호 표기법을 사용해요.
- 할당 연산자(`=`)를 사용해 새 키에 값을 설정해요.
- 또는 [`+` 연산자][man-plus]를 사용해 들어온 객체를 새 객체와 병합할 수 있어요.
- 객체 키로 쓰이는 표현식은 괄호로 감싸야 한다는 점을 기억해요.

## 3. 점수판에서 플레이어 제거하기

- [del 표현식][man-del]을 사용해요.
- 이전 과제에서 했던 것처럼 대괄호 표기법으로 키를 참조해요.
- `del`의 인자는 단순한 문자열이 아니라 _인덱스 표현식_이라는 점을 기억해요.

## 4. 플레이어의 점수 높이기

- 먼저 할당하려는 새 값을 어떻게 표현할지 생각해요.
- 그런 다음 과제 2에서처럼 할당 연산자를 사용해 그 새 값을 설정해요.
- 아직 사용하지 않았다면 [산술 업데이트 할당 연산자][man-update-assignment] `+=`를 활용할 수 있어요.

## 5. 월요일 보너스 점수 적용하기

- 객체를 순회할 때 `to_entries`/`from_entries` 또는 `with_entries`를 사용하기 좋은 곳이에요.
- 각 키마다 과제 4에서처럼 새 값을 설정해요.

## 6. 총점 구하기

- 객체의 _값_들을 순회하려고 해요. [`map_values`][man-map_values] 또는 [`.[]`][man-brackets]를 사용해 값의 스트림을 출력할 수 있어요.
- `add` 표현식을 사용하면 숫자 목록의 합을 구할 수 있어요.
