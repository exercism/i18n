# 소개

## 타입 선언

PHP의 타입 선언은 함수 인자, 반환값, 클래스 속성에 대해 런타임에 타입 단언을 제공해요.
함수에는 `void` 반환 타입을 추가해서 함수가 아무 값도 반환하지 않는다는 것을 나타낼 수 있어요.
선언된 타입은 함수가 적절한 타입의 응답을 반환하는지 런타임에 단언하는 역할도 해요.

```php
<?php

class Driver
{
    private int $serial_number;

    public function setSerialNumber(int $number): void
    {
        $this->serial_number = $number;
    }

    public function getSerialNumber(): int
    {
        return $this->serial_number; 
    }
}

$driver = new Driver();
$driver->setSerialNumber("Version 1b"); // This will throw a TypeError
```

### 타입 유니언

함수 인자, 반환값, 클래스 속성이 둘 이상의 타입이 될 수 있다면 타입 유니언을 선언할 수 있어요.

```php
<?php

class IdentityCard
{
    private int|null $id = null;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

### mixed 타입

코드를 다루다 보면 타입을 지정할 수 없을 때도 있어요.
PHP 8.0부터는 `mixed`라는 탈출구 타입이 제공돼요.
Mixed 타입은 `object|resource|array|string|float|int|bool|null`의 타입 유니언과 같아요.
