# 안내

이 연습 문제에서는 좋아하는 요리책을 보고 멋진 라자냐를 만들 수 있도록 도와주는 코드를 작성해요.

라자냐를 요리하는 데 걸리는 시간과 관련된 네 개의 과제가 있어요.

## 1. 오븐의 예상 시간(분)을 정의해요

`$expected_minutes_in_oven`이라는 상수를 정의해요.
요리책에 따르면 오븐의 예상 시간(분)은 40분이에요:

```sh
$ jq -n -f lasagna.jq
{
  "expected_minutes_in_oven": 40,
  ...
```

## 2. 남은 오븐 시간(분)을 계산해요

이 값은 라자냐가 오븐에 들어간 실제 시간(분)을 입력으로 받아요. 그리고 이전 과제에서 구한 오븐의 예상 시간(분)을 기준으로, 라자냐가 오븐에 더 있어야 하는 시간(분)을 반환해요.

```sh
$ echo '{"actual_minutes_in_oven": 18}' | jq -f lasagna.jq
{
  "expected_minutes_in_oven": 40,
  "remaining_minutes_in_oven": 22,
  ...
```

## 3. 준비 시간(분)을 계산해요

준비 시간은 라자냐를 오븐에 넣기 전에 준비하는 데 걸리는 시간이에요.
층 하나를 준비하는 데 2분이 걸려요.

```sh
$ echo '{"number_of_layers": 3}' | jq -f lasagna.jq
{
  ...
  "preparation_time": 6,
  ...
```

## 4. 총 작업 시간(분)을 계산해요

라자냐를 요리하는 데 총 몇 분을 일했는지 계산해요.
이것은 준비 시간(분)과 현재까지 라자냐가 오븐에서 보낸 시간(분)의 합이에요.

```sh
$ echo '{"actual_minutes_in_oven": 10, "number_of_layers": 2}' | jq -f lasagna.jq
{
  ...
  "total_time": 14,
  ...
```
