# 설치

- macOS: `brew install futhark` 명령을 실행해요
- linux: `brew install futhark` 명령을 실행해요
- Windows: WSL을 사용하거나 [Windows 전용 안내][windows-specific-instructions]를 따라요

다른 설치 방법은 [공식 설치 안내][instructions]에서 확인할 수 있어요.

[instructions]: https://futhark.readthedocs.io/en/stable/installation.html
[windows-specific-instructions]: https://futhark.readthedocs.io/en/stable/installation.html#windows-installation
