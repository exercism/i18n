# 지침 추가

## 프로젝트 구조

Exercism의 Clojure 연습 문제는 의존성 관리와 테스트에 가장 널리 쓰이는 두 가지 도구인 [leiningen][leiningen]과 [Clojure CLI][clojure-cli]를 지원해요.

`test` 디렉터리 안에 `hello_world_test.clj`라는 테스트 파일이 있어요.
코드는 `src/hello_world.clj`에 작성해요. 테스트가 인식할 수 있도록 `hello-world` 네임스페이스를 사용해야 해요.

### Clojure CLI로 테스트 실행하기

```
$ clj -X:test
```

### Leiningen으로 테스트 실행하기

```
$ lein test

lein test hello-world-test

Ran 3 tests containing 3 assertions.
0 failures, 0 errors.
```

그다음 아래 명령으로 연습 문제를 제출해요:

```
$ exercism submit src/hello_world.clj
```

더 자세한 안내와 학습 자료는 [Exercism의 Clojure 언어 페이지][exercism-clojure]를 참고해요.

[leiningen]: https://leiningen.org
[clojure-cli]: https://clojure.org/guides/deps_and_cli
[exercism-clojure]: https://exercism.org/tracks/clojure
