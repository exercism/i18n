# 소개

컴프리헨션은 Enumerable을 쉽고 선언적으로 변환할 수 있는 기능을 제공해요.

아주 간단한 컴프리헨션을 선언하려면 `for` 키워드 뒤에 생성기를 쓰고, do 블록에서 열거된 값으로 새로운 값을 만들어요.

```elixir
for n <- [0, 1, 2, 3], do: n + 1
# => [1, 2, 3, 4]
```

컴프리헨션에는 필터를 붙일 수도 있어요. 필터를 통과하지 못한 값은 최종 배열에서 제거돼요.

```elixir
for n <- [0, 1, 2, 3], n > 1, do: n + 1
# => [3, 4]
```

여러 줄에 걸쳐 더 복잡한 컴프리헨션을 선언할 수도 있어요.

```elixir
for {atom, number} <- [a: 1, b: 2, c: 3, d: 4],
    rem(number, 2) == 0 do
  atom
end

# => [:b, :d]
```

생성기를 여러 개 사용하면 데카르트 곱을 만들 수 있어요. 즉, 첫 번째 생성기가 만든 각 값이 두 번째 생성기가 만든 각 값과 한 번씩 짝을 이뤄요.

```elixir
for x <- [0, 1],
    y <- [0, 1] do
  {x, y}
end

# => [{0, 0}, {0, 1}, {1, 0}, {1, 1}]
```
