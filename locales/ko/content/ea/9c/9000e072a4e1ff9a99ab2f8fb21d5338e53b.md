# 소개

Python에서 [enum](https://docs.python.org/3/library/enum.html)은 고유한 `literal` 또는 `constant` 값에 묶인 이름들의 집합이에요. enum은 `Enum` 클래스를 상속해서 정의해요. 내장 enum 타입은 `enum` 모듈에서 사용할 수 있고, `Enum` 클래스는 `from enum import Enum`을 사용해서 가져올 수 있어요.

```python
class Color(Enum):
    RED = 1
    GREEN = 2
```

참고로, enum 멤버의 값은 str, tuple, float 등 어떤 데이터 타입이든 될 수 있어요.

```python
class Color(Enum):
    RED = 'red'
    GREEN = 'green'
```

enum에서 두 멤버에 같은 값을 할당하면, 나중에 할당된 멤버는 먼저 할당된 멤버의 별칭이 돼요. enum의 두 멤버에 같은 이름을 사용하는 것은 허용되지 않아요.

```python
class Color(Enum):
    RED = 1
    GREEN = 2
    ALIAS_OF_RED = 1

Color.ALIAS_OF_RED
#=> <Color.RED: 1>

Color.ALIAS_OF_RED.value
#=> 1
```

enum의 멤버를 반복하려면 표준 `for member in` 구문을 사용하면 돼요.

```python
for member in Color:
    print((member.name, member.value))
#=> (RED, 1)
#=> (GREEN, 2)
```

enum 멤버는 [`is` (_동일성 연산자_)](https://www.w3schools.com/python/ref_keyword_is.asp) 또는 `is not`을 사용해서 비교할 수 있어요. `==` 또는 `!=` (_동등성 연산자_)도 마찬가지로 작동해요.

```python
a = Color.RED

a is Color.RED
#=> True

a == Color.RED
#=> True
```

주어진 값에 대한 enum 멤버에 접근하려면 `EnumName(value)`를 사용하면 돼요.

```python
g = Color(2)

g is Color.GREEN
#=> True

g
#=> <Color.GREEN: 2>
```
