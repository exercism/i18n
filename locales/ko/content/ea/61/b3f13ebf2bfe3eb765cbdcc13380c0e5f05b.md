# 추천 학습 자료

## 블로그

- 공식 [.NET 블로그](https://blogs.msdn.microsoft.com/dotnet/)에는 초급부터 전문가 수준까지 다양한 흥미로운 C# 글이 많아요.
- Scott Hanselman의 [블로그](http://www.hanselman.com/blog/)는 C#과 .NET 관련 주제를 폭넓게 다루는, 활발하고 잘 쓰인 블로그예요.
- Eric Lippert의 [Fabulous adventures in coding](https://ericlippert.com/)은 훌륭한 C# 블로그지만, 다루는 주제는 대체로 꽤 고급이에요.
- 잘 알려지지 않은 C# 기능을 다룬 James Michael Hare의 [C#/.NET Little Wonders](https://www.slideshare.net/BlackRabbitCoder/little-wonders-5747749) 슬라이드예요.
- C#에 대한 잘못된 가정을 피하는 방법을 다룬 James Michael Hare의 [C#/.NET Little Pitfalls](https://www.slideshare.net/BlackRabbitCoder/cnet-little-pitfalls) 슬라이드예요.

## 소셜 미디어

- [StackOverflow](http://stackoverflow.com/questions/tagged/c%23)에서 문제를 검색하고 이미 답변이 있는지 확인할 수 있어요. 질문하고 답변할 수도 있어요.
- [/r/csharp](https://www.reddit.com/r/csharp)은 C# 서브레딧이에요.
- [@dotnet](https://twitter.com/DotNet)은 공식 .NET 트위터 계정이에요.
- [Gitter](https://gitter.im/exercism/xcsharp)는 C# Gitter 방이에요. C# 트랙과 관련된 도움을 받고 질문하려면 여기로 가요.

## 동영상

- [On .NET](https://www.youtube.com/watch?v=GpLU0UdcGic&list=PL4Sf58qFxdyQuzB1mH5kln_otKpsIuoCO)에서는 Bertrand Le Roy가 다양한 C#/.NET 관련 주제로 사람들을 인터뷰해요.
- PluralSight에는 훌륭한 [C# 강의](https://www.pluralsight.com/search?q=*&categories=course&roles=software-development%7C&subjects=c%23)가 여러 개 있어요. 단점은 PluralSight가 유료 서비스라는 점인데, [무료 체험](https://www.pluralsight.com/pricing)을 신청할 수 있어요.

## 팟캐스트

- [.NET Rocks](https://www.dotnetrocks.com/)는 내용이 아주 좋은 .NET 팟캐스트예요.
