# 힌트

## 1. 방의 습도 수준 확인하기

- 간단한 if...else 로직이에요.
- 삼항 연산자로도 충분해요.
- 이 작업에서는 `error()` 함수를 사용하고, `throw()`는 사용하지 않아요.
- `@info` 매크로도 필요해요.
- 로그 메시지를 생성하는 방법은 소개에 있는 Logging 섹션에서 확인해요.

## 2. 과열 확인하기

- 확인해야 할 두 가지 고장 조건이 있어요.
- 각 조건이 실패하면 `throw()`가 필요해요.
- 성공한 경우에는 `@info` 매크로가 필요해요.

## 3. 사용자 정의 오류 정의하기

- 사용자 정의 오류를 정의하는 예시는 소개를 참고해요.
- 필드와 사용자 정의 출력 메시지도 가능하지만 필수는 아니에요.

## 4. 기계 모니터링하기

- `humiditycheck` 함수와 `temperaturecheck` 함수를 사용할 수 있지만, 꼭 그래야 하는 것은 아니에요.
- 사용한다면 두 함수가 각각 오류를 던지는지 독립적으로 확인하고, 그에 맞는 로그를 추가할 수 있어야 해요.
- `try...catch` 블록 밖에서 정의한 변수는 필요하면 블록 안에서 갱신할 수 있어요.
- 참고: 한 검사만 실패하든 둘 다 실패하든, 로그를 추가한 뒤에는 `MachineError` 하나만 던지면 돼요.
