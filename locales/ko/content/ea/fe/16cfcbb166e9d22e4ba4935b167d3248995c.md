# 지침

여러분! 그래요, 용감한 리스퍼 바로 여러분이에요! [리스프 외계인 레니][alien]가 여러분의 도움이 필요해요! 레니는 다른 리스프 외계인들과 어울리러 나가고 싶어 하지만, 레니의 부모님은 방이 깨끗해질 때까지는 어디에도 못 간다고 했어요.

문제는 레니가 바닥을 거의 볼 수 없다는 거예요! 레니는 atom과 cons를, symbol과 keyword를, `car`와 `cdr`를 구별하지 못해요!

레니가 이 엉망진창을 정리하도록 도와줄 수 있을까요? [괄호][xkcd]도 잊지 마세요, 꼭 필요할 거예요!

## 1. 레니에게 symbol 다시 알려주기

시작하기 전에, 레니는 symbol과 keyword가 어떻게 생겼는지 다시 떠올려야 해요. 마지막으로 정리한 지도 꽤 오래됐거든요... 두 개의 함수를 정의해서 레니를 도와주세요. `lennys-favorite-food`는 어떤 symbol로 평가되고, `lennys-secret-keyword`는 어떤 keyword로 평가돼요. 예를 들면:

```lisp
(lennys-favorite-food) ; => LASAGNA
```

```lisp
(lennys-secret-keyword) ; => :ALIENS-ARE-REAL
```

원하는 symbol이나 keyword를 아무거나 반환해도 돼요 (라자냐를 별로 안 좋아하거나 외계인의 존재를 믿지 않아도 괜찮아요).

## 2. 레니가 atom과 cons를 구별하도록 돕기

레니가 symbol과 keyword를 다시 익혔으니, 이제 청소할 차례예요! 방에 널려 있는 S-Expression을 정리하려면, 레니는 무엇이 cons이고 무엇이 atom인지 판단하는 데 도움이 필요해요. 두 개의 함수 `is-an-atom-p`와 `is-a-cons-p`를 구현해서 도와줄 수 있어요:

```lisp
(is-an-atom-p 'one-thing)    ; => T
(is-an-atom-p '(two things)) ; => NIL
```

```lisp
(is-a-cons-p 'one-thing)    ; => NIL
(is-a-cons-p '(two things)) ; => T
```

이번 섹션에서는 유용하게 쓸 수 있는 내장 lisp 함수가 여러 개 있어요. 그리고 지금은 `T`를 참, `NIL`을 거짓으로 생각하면 돼요.

## 3. 레니가 cons를 나누도록 돕기

마지막으로, 레니의 cons는 너무 부피가 커서 깔끔하게 정리할 수 없어요. 그래서 더 작은 부분으로 나눠야 해요. cons를 나누는 두 개의 함수(`first-thing`과 `rest-of-it`)를 정의해서 도와줄 수 있을까요?

```lisp
(first-thing '(first second third)) ; => FIRST
(rest-of-it  '(first second third)) ; => (SECOND THIRD)
```

다시 말하지만, Common Lisp의 내장 함수 몇 가지가 여기서 유용할 거예요.
