# 소개

## 조건문

조건문은 결정을 내리는 문으로, 부수 효과를 실행하거나 프로그램의 실행 흐름을 제어할 수 있어요.
조건문에는 `if`, `if/else`, `switch`, `ternary` 문이 있어요.

조건문은 값이나 값들 사이의 관계에 대해 질문할 때 사용해요.
질문은 불리언 결과로 평가되지만, `if`문 자체는 어떤 값이든 반환할 수 있고, 단순히 부수 효과를 실행할 수도 있어요.

## `if`문

가장 단순한 `if`문은 표현식을 평가하고 한 줄을 실행해요.
검사하는 표현식은 항상 괄호 안에 넣어요.

부수 효과를 실행할 수도 있어요.

```c
if (count > 10)
    printf("count is greater than 10");
```

또는 실행 흐름을 바꿀 수도 있어요.


```c
if (count > 10)
    return sum;
```

`if`문이 한 줄 이상을 실행한다면, 그 줄들을 중괄호 안에 넣어야 해요.

```c
if (count > 10) {
    printf("count is greater than 10");
    return sum;
}
```

어떤 코딩 팀은 한 줄일 때도 `if`문에 항상 중괄호를 사용하도록 규칙을 정하기도 해요.


## `if`와 `else`

`if`문은 `else`와 함께 쓸 수 있어요.

```c
if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## `if`와 `else if`


`else`는 또 다른 `if`와 결합해서 이른바 `if-else-if ladder`를 만들 수 있어요.

```c
if (number == 0)
    return "zero";
else if (number < 0)
    return "negative";
else if (number < 10)
    return "single digit";   
else if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## `switch`


때로는 `if-else-if ladder`를 `switch`로 더 잘 표현할 수 있어요.
`if`와 마찬가지로, 검사하는 표현식은 항상 괄호 안에 넣어요.

```c
switch (number) {
    case -1:
        return "negative one";
    case 0:
        return "zero";
    case 1:
        return "positive one";
    case 10:
        return "positive ten";
    case -10:
        return "negative ten";
    default:
        return "don't care";
}
```

`default` 케이스는 검사하는 값이 앞의 어떤 케이스와도 일치하지 않을 때 실행돼요.

`switch` 케이스가 반환하지 않으면, 보통 각 케이스를 끝내기 위해 `break`를 넣어요. 그렇지 않으면 로직이 다음 케이스로 "폴스루"돼요.
때로는 폴스루를 의도적으로 사용하기도 해요.

```c
switch (number) {
    case 0:
        msg = "zero"; break;
    case 1:
        msg = "one"; break;
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

폴스루가 의도치 않게 일어나면 버그예요.

```c
switch (number) {
    case 0:
        msg = "zero"; // bug! fallthrough of 0 will set msg to "one"
    case 1:
        msg = "one"; break; 
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

`switch`는 값의 범위 대신 특정 값과 비교할 때 유용할 수 있어요.
컴파일러가 `if-else-if ladder`로는 할 수 없는 방식으로 `switch`문을 최적화할 수 있기 때문에, `switch`가 더 빠를 수 있어요.
때로는 `switch`가 `if-else-if ladder`보다 더 읽기 좋아 보일 수 있어요.

## 삼항(조건) 연산자

삼항 연산자는 세 부분으로 이루어진 조건문으로, 값을 설정할 때 자주 사용해요.
검사할 표현식은 물음표 앞에 오고, 괄호 안에 넣지 않아도 돼요.
참일 때 반환하는 값은 콜론 앞에, 거짓일 때 반환하는 값은 콜론 뒤에 와요.
값 리터럴이나 변수를 반환할 수 있어요.

```c
int i = j > 5 ? 5: j;
```

삼항 연산자는 구문상의 잡음을 줄이기 위해 중첩할 수 있어요.

```c
// the below could also be 
i = j > 5 ? j :k > 5 ? k: 10;
// but that may not be quite as readable

i = j > 5 ? j
    :k > 5 ? k
    :10;

// which is the same as
if (j > 5) i = j;
else if (k > 5) i = k;
else i = 10;
```
