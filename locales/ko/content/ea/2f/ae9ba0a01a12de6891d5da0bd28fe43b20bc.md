# 안내

이 연습 문제에서는 공장 직원들의 이름 배지를 출력하는 코드를 작성해요.

## 1. 직원의 배지 출력하기

직원에게는 ID, 이름, 부서 이름이 있어요. 직원 배지 라벨은 다음과 같은 형식이에요: `"[id] - name - DEPARTMENT"`.
직원의 배지 라벨을 반환하도록 `Badge.print()` 메서드를 구현해요:

```java
Badge badge = new Badge();
badge.print(734, "Ernest Johnny Payne", "Strategic Communication");
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

라벨에서는 부서 이름을 대문자로 표시해야 해요.

## 2. 새로 입사한 직원의 배지 출력하기

컴퓨터 시스템의 특이한 점 때문에, 새로 입사한 직원은 공장에서 일을 시작할 때 아직 ID가 없는 경우가 가끔 있어요.
배지는 필수이기 때문에, 이들은 ID 접두사가 없는 임시 배지를 받아요. 아직 ID가 없는 새 직원을 지원하도록 `Badge.print()` 메서드를 수정해요:

```java
Badge badge = new Badge();
Badge.print(null, "Jane Johnson", "Procurement");
// => "Jane Johnson - PROCUREMENT"
```

## 3. 사장의 배지 출력하기

공장 사장도 항상 배지를 달아야 해요.
그런데 사장에게는 부서가 없어요. 이 경우 라벨에는 부서 이름 대신 `"OWNER"`가 출력되어야 해요.
사장의 라벨을 출력하도록 `Badge.print()` 메서드를 수정해요:

```java
Badge badge = new Badge();
badge.print(254, "Charlotte Hale", null);
// => "[254] - Charlotte Hale - OWNER"
```

사장이 새로 입사한 직원일 수도 있다는 점에 유의해요:

```java
Badge badge = new Badge();
badge.print(null, "Charlotte Hale", null);
// => "Charlotte Hale - OWNER"
```
