# C# 배우기

## 웹사이트

- [공식 C# 문서](https://docs.microsoft.com/en-us/dotnet/articles/csharp/)에는 [자습서](https://docs.microsoft.com/en-us/dotnet/articles/csharp/tutorials/index)와 [언어 둘러보기](https://docs.microsoft.com/en-us/dotnet/articles/csharp/tour-of-csharp/index)를 비롯해 다양한 주제를 폭넓게 다루는 훌륭한 내용이 담겨 있어요.
- [Learn C#](http://www.learncs.org/)은 브라우저에서 바로 해볼 수 있는 인터랙티브 자습서로, C# 프로그래밍의 핵심 개념을 소개해요.

## 동영상

- [C# 101](https://www.youtube.com/playlist?list=PLdo4fOcmZ0oVxKLQCHpiUWun7vlJJvUiN) 라이브 코딩 데모와 함께 C# 프로그래밍 언어의 개념과 문법을 다뤄요.
- [.NET Core 101](https://www.youtube.com/playlist?list=PLdo4fOcmZ0oWoazjhXQzBKMrFuArxpW80) ".NET이란 무엇인가"에 대한 이모저모와 첫 애플리케이션을 게시하는 방법을 알려줘요.
- [Programming in C# Jump Start](https://channel9.msdn.com/Series/Programming-in-C-Jump-Start)는 C# 프로그래밍을 단계별로 차근차근 소개해 주는 좋은 자료예요.
- [C# Fundamentals for Absolute Beginners](https://mva.microsoft.com/en-US/training-courses/c-fundamentals-for-absolute-beginners-16169?l=Lvld4EQIC_2706218949)는 C#을 익히는 아주 좋은 방법이에요.
- [PluralSight](https://www.pluralsight.com/)에는 [훌륭한](https://www.pluralsight.com/courses/csharp-6-from-scratch) [입문](https://www.pluralsight.com/courses/c-sharp-fundamentals-with-visual-studio-2015) [강의](http://www.pluralsight.com/courses/csharp-best-practices-improving-basics)가 여러 개 있어요. 아쉬운 점은 PluralSight가 유료 서비스라는 건데, [무료 체험](https://www.pluralsight.com/pricing)을 신청할 수는 있어요.
