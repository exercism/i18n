# 힌트

## 일반

- Python 문서의 [문자열 튜토리얼][python-str-doc]에 Python `str` 타입에 대한 개요가 있어요.
- 문자열 메서드 [`str.join()`][str-join]과 [`str.split()`][str-split]은 문자열을 다룰 때 아주 유용해요.
- [시퀀스 타입][common sequence operations]에 대한 Python 문서에는 `strings`, `lists`, `tuples`, `ranges`를 비롯한 모든 시퀀스에 공통된 연산이 정리되어 있어요.

과제에는 네 가지 활동이 있고, 각각 다룰 텍스트나 단어가 있어요.

## 1. 단어에 접두사 붙이기

- 짧은 문자열은 `+` 연산자로 이어 붙일 수 있어요.

## 2. 단어 그룹에 접두사 붙이기

- 믿거나 말거나, 여기서는 [`str.join()`][str-join]만 있으면 돼요. **반복문은 필요하지 않아요**.
- 테스트는 함수에 `list`를 넘겨줄 거예요. 좋은 구분자 문자열을 찾아낼 수 있다면 이 `list`를 바꿀 필요는 없어요.
- 구분자 문자열은 요소 사이에 들어가서 요소들을 하나의 문자열로 "붙여" 준다는 점을 기억해요. 구분자는 공백 _없이_ 삽입되지만, 구분자 안에 공백 문자를 넣을 수는 있어요.
- [`str.split()`][str-split]과 마찬가지로 `str.join()`은 어떤 유니코드 코드 포인트로 이루어졌든 임의 길이의 문자열을 처리할 수 있어요. `str.split()`과는 _달리_, `list`, `tuple`, `set`처럼 임의 길이의 반복 가능한 객체도 처리할 수 있어요.

## 3. 단어에서 접미사 제거하기

- 문자열은 왼쪽(0부터 시작)에서도, 오른쪽(-1부터 시작)에서도 인덱싱하거나 슬라이싱할 수 있어요.
- 임의 길이 문자열의 마지막 코드 포인트를 얻고 싶다면 `[-1]`을 사용할 수 있어요.
- 문자열의 마지막 세 글자는 음수 인덱스로 "잘라낼" 수 있어요. 예: `beautiful'[:-3] == 'beauti`

## 4. 단어 추출하고 변환하기

- [`str.split()`][str-split]을 사용하면 공백을 기준으로 나뉜 문자열의 `list`가 반환돼요.
- `lists`는 시퀀스이고, 인덱싱할 수 있어요.
- [`str.split()`][str-split]은 바로 인덱싱할 수 있어요: `'Exercism rocks!'.split()[0] == 'Exercism'`
- 구두점을 조심해요! 마침표는 슬라이스로 제거할 수 있어요: `'dark.'[:-1] == 'dark'`
