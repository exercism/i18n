# 소개

## 상수

`const` 한정자는 값이 컴파일 시점에 알려져 있고 프로그램의 수명 동안 바뀌지 않는 모든 필드에 적용할 수 있으며, 일반적으로 적용하는 게 좋아요.

```csharp
private const int num = 1729;
public const string title = "Grand" + " Master";
```

`readonly` 한정자는 `const`로 만들 수는 없지만 값이 프로그램의 수명 동안 바뀌지 않고, 인라인 이니셜라이저로 설정되거나 인스턴스화 과정에서(생성자 또는 생성자가 호출한 메서드에 의해) 설정되는 모든 필드에 적용할 수 있으며, 일반적으로 적용하는 게 좋아요.

```csharp
private readonly int num;
private readonly System.Random rand = new System.Random();

public MyClass(int num)
{
    this.num = num;
}
```

## 방어적 복사

보안에 민감한 상황이라면(또는 개발자마다 우선순위와 목표가 다른 큰 코드베이스에서라면 더욱) 메서드의 변경 가능한 매개변수를 그대로 받아 저장하거나, 클래스의 변경 가능한 멤버를 반환 값이나 `out` 매개변수로 노출해서 클래스의 공개 API가 우회되도록 두어서는 안 돼요.

## 읽기 전용 컬렉션

`readonly` 한정자는 필드의 값이나 참조를 덮어쓰지 못하게 막아 주지만, 참조 형식의 멤버는 전혀 보호해 주지 않아요.

```csharp
readonly List<int> ints = new List<int>();

void Foo()
{
    ints.Add(1);    // ok
    ints = new List<int>(); // fails to compile
}
```

참조 형식의 모든 멤버를 보호하려면 필드를 `readonly`로 만들고, `set` 접근자 없이 자동 구현 속성을 정의하면 돼요.

기본 클래스 라이브러리(Base Class Library, BCL)는 컬렉션의 멤버가 갱신되지 않도록 해야 할 때 쓸 수 있는 읽기 전용 버전의 컬렉션 몇 가지를 제공해요. 이들은 래퍼 형태로 제공돼요.

- `ReadOnlyDictionary<T>`는 `Dictionary<T>`를 읽기 전용으로 노출해요.
- `ReadOnlyCollection<T>`는 `List<T>`를 읽기 전용으로 노출해요.
