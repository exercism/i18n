# 패션 부티크

## 스토리

온라인 패션 부티크를 운영하고 있어요. 블랙 프라이데이가 다가오니, 준비가 잘 되어 있는지 확인하려면 재고를 점검해야 해요.

재고의 품목 하나는 맵/딕셔너리로 표현하고, 전체 재고는 그런 맵/딕셔너리들의 리스트/배열이에요.

```elixir
%{
  name: "White Shirt",
  price: 40,
  quantity_by_size: %{s: 3, m: 7, l: 8, xl: 4}
}
```

## 할 일

- 가격순으로 품목 정렬하기
- 가격이 없는 품목 모두 찾기
- 품목의 수량 늘리기
- 품목의 총수량 계산하기
