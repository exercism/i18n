# 개요

`when`은 예외를 필터링할 때 쓰는 키워드예요. catch 문 뒤에 오고, 그 시점에 스코프 안에 있는 어떤 값이든 담을 수 있는 불리언 표현식을 받을 수 있어요. 그 값이 꼭 예외 자체의 멤버일 필요는 없어요. 예외의 타입이 일치하고 표현식이 true로 평가되면 그 `catch` 문에 연결된 블록이 실행돼요. 그렇지 않으면 다음 `catch` 문이 있는 경우에 그 문을 검사해요.

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```

- 이 [예외 필터][exception-filters] 문서에서는 예외를 필터링하는 방법을 보여줘요.

[exception-filters]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/when
