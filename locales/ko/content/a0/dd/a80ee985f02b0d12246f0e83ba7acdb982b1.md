# 지침

정원에 새가 몇 마리 찾아왔는지 기록하는 열렬한 탐조가예요. 보통은 공책에 하나씩 표시를 하면서 새를 세지만, 이 데이터를 더 잘 다뤄 보고 싶어요. 지난 몇 주 동안 공책에 적어 둔 날짜별 새 개수는 이미 디지털로 옮겨 놓았어요.

이제 세어 온 새의 총 마릿수를 구하고, 특정 주의 새 개수를 계산하고, 집계 실수 하나를 바로잡으려고 해요.

## 1. 지금까지 세어 온 새의 총 마릿수 구하기

먼저 데이터를 전체적으로 살펴보는 것부터 시작해 봐요. 기록을 시작한 뒤로 모두 몇 마리의 새를 세었는지 알아내요.

날짜별 새 개수를 담은 유사 배열 객체를 받는 `totalBirdCount` 함수를 구현해요. 이 함수는 세어 온 새의 총 마릿수를 반환해야 해요.

```javascript
birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1];
totalBirdCount(birdsPerDay);
// => 34
```

## 2. 특정 주에 찾아온 새의 수 계산하기

새 개수에 대한 전반적인 감을 잡았으니, 이제 더 세밀한 분석을 해 보고 싶어요.

날짜별 새 개수를 담은 유사 배열 객체와 주 번호를 받는 `birdsInWeek` 함수를 구현해요. 이 함수는 해당 주에 세어 온 새의 총 마릿수를 반환해요. 주는 항상 빠짐없이 기록된다고 가정해도 돼요.

```javascript
birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1];
birdsInWeek(birdsPerDay, 2);
// => 12
```

## 3. 집계 실수 바로잡기

새를 기록하는 내내, 정원 멀리 구석에 새 한 마리가 숨어 있었다는 걸 깨달았어요. 이 새는 이틀에 한 번씩 항상 정원에 머물렀다는 걸 알아냈어요. 그 사이에 어디에 있었는지는 정확히 모르지만, 분명 정원에는 없었어요. 탐조가의 직감은 목록에 기록한 첫날에 이 새가 정원에 있었다고도 말해 줘요.

이 새로운 정보를 바탕으로, 날짜별로 센 새 개수를 담은 유사 배열 객체를 인자로 받는 `fixBirdCountLog` 함수를 작성해요. 이 함수는 주어진 배열을 수정해서 집계 실수를 바로잡아야 해요.

```javascript
birdsPerDay = [2, 5, 0, 7, 4, 1];
fixBirdCountLog(birdsPerDay);
// => [3, 5, 1, 7, 5, 1]
```
