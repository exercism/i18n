# 소개

많은 언어에는 존재하지 않는 값을 나타내기 위해 `null`이나 `none` 같은 방법이 있어요.
R은 (흔히 지저분한) 대량의 데이터를 다루도록 설계되었기 때문에, "없음"을 나타내는 여러 가지 형태를 가지고 있어요.

전체적인 목표는 없거나 의심스러운 값을 만나는 즉시 표시해 두고, 예외를 발생시키지 않고 계속 진행하는 거예요.

## NULL

값이 정말로 존재하지 않으면 `NULL`로 나타내요. 아마 C나 Python이 하는 방식과 가장 가까울 거예요.

```R
v <- c() # zero-length vector
v
#> NULL
is.null(v)
#> [1] TRUE
```

많은 상황에서 `NULL` 값은 그냥 무시돼요:

```R
c(2, 3, NULL, 5)
#> [1] 2 3 5
```

## NA

값은 존재하지만 그것이 무엇인지 모르는 상황에서는 `NA`를 사용해요. 예를 들어 도로를 지나는 차량을 셀 때, 사람 관측자가 병가를 내거나 자동 센서가 고장 날 수 있지만 교통은 계속 흘러가죠.

```R
v <- c(1, 2, NA, 4, 5)
v
#> [1]  1  2 NA 4  5
is.na(v) # test for data gaps
#> [1] FALSE FALSE  TRUE FALSE FALSE
```

따라서 `NA`는 자리 표시자로서, 이 값을 어떻게 처리할지 사람이 결정해야 한다는 것을 알려 줘요.

## NaN

"Not a Number"의 줄임말인 `NaN`은 숫자가 기대되는 상황에서 계산 문제가 있음을 알려 줘요.

```R
n <- c(0, 2, 4)
d <- c(0, 1, 2)
n / d
#> [1] NaN   2   2  # 0/0 is mathematically undefined
is.nan(n / d)
#> [1]  TRUE FALSE FALSE
```

"잘못된" 계산이 이것만 있는 것은 아니에요.
0으로 나누면 분자가 0이 아닌 경우 오류를 발생시키지 않고 `Inf` 또는 `-Inf`를 반환해요.

```R
1 / 0
#> [1] Inf
```

## 빈 벡터

아마 놀랍겠지만, R에는 비어 있는지 확인하는 표준 방법이 없어요.

빈 벡터를 생성하는 것조차 그리 명확하지 않아요.
앞선 섹션에서 인자 없이 `c()`를 호출하면 벡터가 아니라 `NULL`을 반환한다는 것을 봤어요.

```R
is.vector(c())
#> [1] FALSE
```

`logical()`이나 `integer()` 같은 함수는 원하는 길이를 지정하는 인자를 받는데, 이 길이는 0이 될 수 있어요.

```R
z <- logical(0)
is.vector(z)
#> [1] TRUE
length(z)
#> [1] 0
```

[벡터 개념][concept-vectors]에서 설명한 것처럼, 벡터를 생성한 다음 모든 원소를 제거할 수도 있어요.
그러면 적절한 타입의 길이 0인 벡터가 돼요.

```R
v <- 5
v[-1]  # delete the first element
#> numeric(0)
```

[concept-vectors]: https://exercism.org/tracks/r/concepts/vectors
