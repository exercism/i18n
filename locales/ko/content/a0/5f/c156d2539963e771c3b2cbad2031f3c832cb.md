# 소개

## 모듈

모듈은 관련 있는 코드를 묶어 이름 충돌을 피하는 방법이고, 아주 사소한 코드베이스를 빼면 거의 모든 코드에 등장해요.

문법은 다음과 같아요:

```rust
mod my_module {
    pub struct MyStruct {}

    pub struct OtherClass {}
}
```

모듈의 범위 밖에서는 모듈에 들어 있는 타입을 이중 콜론 `::` 문법으로 타입 이름 앞에 붙여서 가리켜요.
또는, 더 흔하게는 파일 맨 위에(또는 모듈 안에) `use` 지시문을 두면 접두사 없이 타입을 사용할 수 있어요.
같은 모듈 안에서는 타입 이름을 한정할 필요가 없어요.

```rust
mod my_module {
    #[derive(Drop)]
    pub struct MyStruct {}

    pub struct Foo {}

    #[generate_trait]
    pub impl FooImpl of FooTrait {
        fn bar() {
            let baz = MyStruct {};
        }
    }
}

#[derive(Drop)]
pub struct Qux {}

#[generate_trait]
impl QuxImpl of QuxTrait {
    fn box() {
        let nux = my_module::MyStruct {};
    }
}

mod other_module {
    use super::my_module::*;

    #[derive(Drop)]
    pub struct Tix {}

    #[generate_trait]
    pub impl TixImpl of TixTrait {
        fn jeg() {
            let lor = MyStruct {};
        }
    }
}
```

`use core::array::ArrayTrait as Arr;` 문법으로 모듈이나 타입에 별칭을 붙일 수 있고, 그러면 모듈이나 타입을 쓸 수 있는 곳 어디에서나 그 별칭을 사용할 수 있어요.
