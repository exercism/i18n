# 지침 부록

## Prolog에서 날짜 다루기

Prolog에 내장된 날짜 지원은 [상당히 기초적인 수준][built-in-dates-support]이에요.
날짜를 다루는 훨씬 더 좋은 방법은 [date_time 패키지][date_time-package]를 사용하는 거예요.

### date_time 패키지 설치하기

설치된 Swipl 버전이 비교적 최신이라면, 다음을 실행해서 패키지를 설치할 수 있어요:

```bash
swipl pack install date_time
```

그래도 안 되면 다음을 실행해 봐요:

```shell
swipl -g 'pack_install(date_time)'
```

~~~~exercism/note
온라인 편집기를 사용하고 있다면, 직접 설치할 필요가 없어요.
~~~~

### date_time 패키지 사용하기

`date_time` 패키지를 사용하려면 풀이 파일 맨 위에 다음 코드를 추가해요:

```prolog
:- use_module(library(date_time)).
```

~~~~exercism/note
팁: [date_time 패키지의 소스][https://www.swi-prolog.org/pack/file_details/date_time/prolog/date_time.pl?show=src]는 문서가 잘 되어 있어서 큰 도움이 될 거예요!
~~~~
