# 개요

**클로저**는 바깥 [렉시컬 스코프][wiki-lexical-scope]에 있는 변수를 함수 안에서 사용할 수 있게 해주는, [Clojure의 프로그래밍 패턴][clojure-guide-closures]이에요. Clojure는 클로저를 자연스럽게 지원하기 때문에, 클로저가 무엇인지도 모른 채 사용하는 경우가 많아요.

```clojure
;; Top-level definitions are global-scope
(def dozen 12)

;; Functions create a new scope.
;; Referencing the outer variable here is a closure.
(fn [n] (* dozen n))
```

## 상태를 저장하고 값을 전달하는 클로저

atom을 사용하면 상태를 어느 정도 보존할 수 있어요:

```clojure
;; This function closure increments the counter's state
;; in the outer lexical context.
;; This way the counter can be shared between many calling contexts.

(def increment
  (let [counter (atom 0)]
    (fn [] (swap! counter inc))))
```

`increment`를 호출할 때마다 카운터가 하나씩 증가해요:

``` clojure
(increment)
;;=> 1
(increment)
;;=> 2
```
