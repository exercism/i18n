`Boolean(...)`에 대한 명시적인 호출을 모두 제거해요.

JavaScript에서는 표현식의 결과를 특정 타입으로 _형 변환_할 필요가 없어요.
예를 들어, 이항 표현식의 결과는 그대로 반환할 수 있고, `boolean`으로 만들기 위해 또 다른 호출을 할 필요도 없어요.

```javascript
// instead of
return Boolean(some_expression);

// ...In JavaScript, in general, values don't need to be explicitly changed
return some_expression;
```
