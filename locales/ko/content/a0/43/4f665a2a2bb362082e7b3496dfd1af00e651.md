# 소개

Haxe에서 **배열**은 (보통) 같은 타입의 원소들로 이루어진 컬렉션이에요. Haxe에서 배열을 만드는 방법은 세 가지예요. 생성자를 쓰거나, 선언 문법을 쓰는 방법이에요. Haxe에서 배열의 첫 번째 원소의 인덱스는 0이에요:

```haxe
var a = [1, 2, 3];
trace(a); // [1,2,3]

// Here the second element is called by index
trace(a[1]); // 2

// The actual first element's index is 0
trace(a[0]); // 1
```

생성자로 배열을 만들려면, 배열에 들어갈 원소들의 타입을 넘겨줘야 해요:

```haxe
var a:Array<Int> = [0, 1, 2, 3];
a[1] = "Hello"; // Error: the array a takes integers only
```

배열에 여러 타입의 원소를 담고 싶다면, 타입 표시에 `Dynamic` 타입을 추가해요:

```haxe
var a:Array<Dynamic> = [10, "Bob", true]
```
