# 소개

C#에는 두 가지 종류의 숫자가 있어요:

- 정수: 소수점 뒤에 자릿수가 없는 숫자(소수 부분이 없는 수)예요. 예를 들면 `-6`, `0`, `1`, `25`, `976`, `500000`이에요.
- 부동소수점 수: 소수점 뒤에 자릿수가 0개 이상인 숫자예요. 예를 들면 `-2.4`, `0.1`, `3.14`, `16.984025`, `1024.0`이에요.

C#에서 가장 흔히 쓰는 숫자 타입 두 가지는 `int`와 `double`이에요. `int`는 32비트 정수이고 `double`은 64비트 부동소수점 수예요.

산술 연산은 표준 산술 연산자로 해요. 숫자는 표준 숫자 비교 연산자와 등호(`==`), 부등호(`!=`) 연산자로 비교할 수 있어요.

C#에는 두 가지 숫자 변환 방식이 있어요:

1. 암시적 변환: 데이터가 손실되지 않고 추가 문법도 필요 없어요.
2. 명시적 변환: 데이터가 손실될 수 있고, _캐스트_ 형태의 추가 문법이 필요해요.

`int`는 `double`보다 정밀도가 낮기 때문에 `int`에서 `double`로 변환하는 것은 안전하고, 따라서 암시적 변환이에요. 하지만 `double`에서 `int`로 변환하면 데이터가 손실될 수 있으므로 명시적 변환이 필요해요.

```csharp
int softCool = 1358938113;
double notLost = 4.8151623;

// implicit cast: no loss of information
double macDebug = softCool;         // 1358938113.0

// explicit cast: possible loss of information 
int somethingLost = (int)notLost;   // 4
```
