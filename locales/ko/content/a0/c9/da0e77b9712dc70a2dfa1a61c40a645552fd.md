# 지시 사항

근처에 "Tech Palace"라는 가전제품 가게가 있어요.
가게 주인은 최근 마케팅 메시지에 사용하고, 손님이 입구에서 멤버십 카드를 스캔할 때 특별한 인사말을 보여 주기 위해 큰 디스플레이를 설치했어요.
이 디스플레이는 작은 LED 조명 여러 개로 이루어져 있고, 여러 줄의 텍스트를 표시할 수 있어요.

가게 주인은 새 디스플레이에 표시할 텍스트를 만드는 코드에 도움이 필요해요.

## 1. 환영 메시지 만들기

<!-- markdownlint-disable-next-line MD038 -->
멤버십 카드를 스캔하는 대부분의 손님에게는, 가게 주인이 디스플레이에 `Welcome to the Tech Palace, `와 그 뒤에 대문자로 된 손님의 이름이 표시되기를 원해요.

손님의 이름을 짧은 문자열(`felt252`) 인자로 받아 원하는 메시지를 `ByteArray`로 반환하는 `welcome_message` 함수를 구현해요.

```rust
welcome_message("Judy")
// => Welcome to the Tech Palace, JUDY
```

## 2. 멋진 테두리 추가하기

가게에서 많이 구매하는 단골 손님을 위해, 주인은 환영 메시지 앞뒤에 별 한 줄을 넣어 환영 디스플레이를 더 멋지게 만들고 싶어해요.
별이 한 줄에 몇 개 들어가야 할지는 아직 정하지 못했기 때문에, 그 값을 설정할 수 있게 하고 싶어해요.

환영 메시지(`ByteArray`)와 줄당 별의 개수(`u32` 타입)를 인자로 받는 `add_border` 함수를 작성해요.
이 함수는 3줄로 이루어진 `ByteArray`를 반환해야 해요. 원하는 개수만큼의 별이 있는 줄, 전달받은 그대로의 환영 메시지, 그리고 별이 있는 또 다른 줄 순서예요.

```rust
add_border("Welcome!", 10)
```

다음과 같은 결과를 반환해야 해요:

```bash
**********
Welcome!
**********
```

## 3. 오래된 마케팅 메시지 정리하기

새 디스플레이를 설치하기 전에, 가게에는 설정을 바꿀 수 없는 고정된 줄만 표시할 수 있는 비슷한 디스플레이가 있었어요.
주인은 오래된 마케팅 메시지 일부를 새 디스플레이에서 다시 사용하고 싶어해요.
그런데 그 데이터에는 이미 별 테두리와 불필요한 공백이 포함되어 있어요.
메시지를 다시 사용할 수 있도록 정리해야 해요.

오래된 마케팅 메시지를 `ByteArray`로 받는 `clean_up_message` 함수를 구현해요.
이 함수는 먼저 텍스트에서 모든 별을 제거한 다음, 남은 텍스트의 앞뒤 공백을 제거해야 해요.
그다음 정리된 메시지를 반환해야 해요.

```rust
let message: ByteArray = "
**************************
*    BUY NOW, SAVE 10%   *
**************************
";

clean_up_message(message)
// => BUY NOW, SAVE 10%
```
