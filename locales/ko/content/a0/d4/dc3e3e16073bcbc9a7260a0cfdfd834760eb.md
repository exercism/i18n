# 지침 추가

## 레지스터

| 레지스터 | 용도      | 타입   | 설명                     |
| -------- | --------- | ------ | ------------------------ |
| `$a0`    | 입력      | 주소   | null로 끝나는 입력 문자열 |
| `$a1`    | 입력      | 정수   | 시프트 키                 |
| `$a2`    | 입출력    | 주소   | null로 끝나는 결과 문자열 |
| `$t0-9`  | 임시      | 아무 값 | 값을 임시로 저장할 때 사용해요 |
