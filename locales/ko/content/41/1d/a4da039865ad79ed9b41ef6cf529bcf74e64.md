# 설치

먼저 [Erlang][1] 설치 페이지의 안내에 따라 Erlang이 설치되어 있는지 확인해요.
[1]: /languages/erlang

## Mac OS X용 Homebrew

Homebrew를 최신 버전으로 업데이트해요:

```bash
$ brew update
```

LFE를 설치해요:

```bash
$ brew install lfe
```

## 소스에서 설치하기

시스템의 "개발자 도구" 또는 "필수 빌드 패키지", `git`, 그리고 Erlang의 `erl`을 설치해요.

예를 들어 우분투 18.04에서는 다음과 같아요:

```bash
$ sudo apt-get install build-essential git erlang erlang-base-hipe
```

그다음에는 다음과 같이 LFE를 내려받아 빌드할 수 있어요:

```bash
$ git clone https://github.com/lfe/lfe.git
$ cd lfe
$ make
$ make install
```

LFE 컴파일이 끝나면 ``lfe`` 실행 파일을 실행해서 REPL(대화형 세션)을 시작할 수 있어요:

```bash
$ ./bin/lfe
```
