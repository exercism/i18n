# 개요

Elixir의 표준 라이브러리는 날짜와 시간을 다루기 위한 네 개의 서로 다른 모듈을 제공하며, 각각 고유한 구조체를 가지고 있어요.

- [`Date` 모듈][date]. `Date` 구조체는 [`~D` 시길][sigil-d]로 만들 수 있어요.
    ```elixir
    ~D[2021-01-01]
    ```

- [`Time` 모듈][time]. `Time` 구조체는 [`~T` 시길][sigil-t]로 만들 수 있어요.
    ```elixir
    ~T[12:00:00]
    ```

- [`NaiveDateTime` 모듈][naivedatetime]은 시간대가 없는 날짜와 시간을 위한 모듈이에요. `NaiveDateTime` 구조체는 [`~N` 시길][sigil-n]로 만들 수 있어요.
    ```elixir
    ~N[2021-01-01 12:00:00]
    ```

- [`DateTime` 모듈][datetime]은 시간대가 있는 날짜와 시간을 위한 모듈이에요. UTC 이외의 시간대에 이 모듈을 사용하려면 외부 의존성인 시간대 데이터베이스가 필요해요. `DateTime` 구조체는 [`~U` 시길][sigil-u]로 나타낼 수 있지만, 대신 `DateTime` 함수를 사용해 만들어야 해요.
    ```elixir
    DateTime.new!(~D[2021-01-01], ~T[12:00:00], "Etc/UTC")
    # => ~U[2021-01-01 12:00:00Z]
    ```

## 비교

날짜나 시간을 서로 비교하려면 해당 모듈에서 `compare` 또는 `diff` 함수를 찾아보세요. `==`, `>`, `<` 같은 비교 연산자가 작동하는 것처럼 _보이지만_, 그 구조체들에 대해서는 올바른 의미론적 비교를 하지 않아요.

```elixir
Date.compare(~D[2020-11-30], ~D[2020-12-01])
# => :lt

Time.diff(~T[13:45:00], ~T[13:46:30])
# => -90
```

## 이동

날짜, 시간, 날짜와 시간은 해당 모듈의 `add/2` 함수를 사용해 앞뒤로 이동할 수 있어요.

```elixir
# add 4 days
Date.add(~D[2021-01-01], 4)
# => ~D[2021-01-05]

# subtract 1 second
Time.add(~T[12:00:00], -1)
# => ~T[11:59:59.000000]

# add 4 days and 30 seconds
NaiveDateTime.add(~N[2021-01-01 12:00:00], 4 * 24 * 60 * 60 + 30)
# => ~N[2021-01-05 12:00:30]
```

## 변환

`NaiveDateTime` 구조체는 [`NaiveDateTime.to_date/1`][naivedatetime-to-date]과 [`NaiveDateTime.to_time/1`][naivedatetime-to-time]을 사용해 `Date` 구조체와 `Time` 구조체로 분해할 수 있어요. 반대의 경우에는 [`NaiveDateTime.new!/2`][naivedatetime-new]로 만들 수 있어요.

```elixir
NaiveDateTime.to_date(~N[2021-01-01 12:00:00])
# => ~D[2021-01-01]

NaiveDateTime.to_time(~N[2021-01-01 12:00:00])
# => ~T[12:00:00]

NaiveDateTime.new!(~D[2021-01-01], ~T[12:00:00])
# => ~N[2021-01-01 12:00:00]
```
