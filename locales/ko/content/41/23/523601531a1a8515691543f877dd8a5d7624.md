# 설치

[NodeJS LTS](https://nodejs.org/en)가 필요해요.

> 💡 이 트랙은 이전 안정 버전은 물론 "current" 버전에서도 잘 동작할 가능성이 커요.
> 하지만 [설계상](https://github.com/nodejs/release#release-schedule), 홀수 버전은 결코 안정되지 않아요.
> 항상 NodeJS의 짝수 버전을 설치해야 해요.

Node.JS `corepack`으로 [Yarn 4+](https://yarnpkg.com/getting-started/install)를 설치해요:

```shell
corepack enable yarn
```

## 설치 확인

방금 설치한 바이너리를 사용하려면 보통 새 터미널을 열어야 해요.

```shell
$ node -v
v20.15.0

$ corepack -v
0.28.1

$ corepack yarn -v
v4.3.1
```

_참고: 버전은 여기 나온 것과 다를 수 있어요._

## 연습 문제 설치

**각 연습 문제**에는 테스트를 실행하기 위한 몇 가지 도구가 필요해요:

각 연습 문제 디렉터리에서 다음 명령을 실행하면 설치할 수 있어요:

```bash
$ corepack yarn install
```

사용하는 에디터에 따라, Plug'n'Play 설치 환경에서 동작하려면 각 연습 문제에 [Editor SDK](https://yarnpkg.com/getting-started/editor-sdks)를 설치해야 해요.
이 글을 작성하는 시점에서 다음이 지원돼요:

- [CoC nvim](https://yarnpkg.com/getting-started/editor-sdks#coc-nvim)
- [Emacs](https://yarnpkg.com/getting-started/editor-sdks#emacs)
- [Neovim Native LSP](https://yarnpkg.com/getting-started/editor-sdks#neovim-native-lsp)
- [VSCode](https://yarnpkg.com/getting-started/editor-sdks#vscode)
