# 개요

Ruby에는 표준 라이브러리(흔히 "stdlib"로 줄여 불러요)가 함께 제공돼요. 날짜, json, 네트워킹 같은 것을 다루기 위한 클래스 모음이에요.
또한 코드를 더 다루기 쉽게 만들어 주는 유용한 기능도 제공해요.

`OpenStruct`는 표준 라이브러리의 일부로, `Hash`로부터 객체를 간단히 만들 수 있게 해줘요.
`Hash` 키로 접근해야 하는 대신, `OpenStruct`에서는 메서드로 값에 접근하고 값을 설정할 수 있어요.

표준 라이브러리나 다른 라이브러리의 클래스를 사용할 때는 `require` 메서드로 그 클래스를 불러와야 해요.

```ruby
require 'ostruct'

attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

여기에는 보너스 같은 장점이 하나 있는데, 블록 문법을 사용할 때 단축 표현을 활용할 수 있다는 점이에요.
블록이 메서드 하나만 호출하는 경우에는, 블록을 `&:`와 메서드 이름으로 바꿀 수 있어요.
예를 들어, 다음 두 줄은 같은 의미예요:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```
