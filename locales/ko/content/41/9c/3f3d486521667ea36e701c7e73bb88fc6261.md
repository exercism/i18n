# 소개

`Complex numbers`는 복잡하지 않아요.
그저 이름이 조금 덜 무서우면 될 뿐이에요.


복소수는 특히 공학과 과학 분야에서 아주 유용해서, Python은 정수([`int`s][ints])와 실수([`float`s][floats])에 더해 [`complex`][complex]도 표준 숫자형으로 넣어 두었어요.


Python에서 `complex` 값은 기본적으로 실수 두 개를 묶은 것이에요:

```python
>>> my_complex = 5.443+6.77j
(5.443+6.77j)
```

이 두 부분을 각각 "실수부"와 "허수부"라고 해요.
"`i`(또는 `j`)는 -1의 제곱근이에요"라는 말을 들어 봤을지도 몰라요.
지금 시점에서는 허수부가 _정의상_ `1j * 1j == -1`이라는 등식을 만족한다는 뜻일 뿐이에요.
단순한 생각이지만, 흥미로운 수학적 결과로 이어져요.

Python에서는 "허수" 부분을 `j`로 표시하고(_수학 교과서에서 보는 `i`가 아니라_), `j`는 반드시 숫자 바로 뒤에 붙여야 해요. 그래야 Python이 `j`를 변수 이름으로 보지 않아요:


```python
>>> j
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
NameError: name 'j' is not defined

>>> 1j
1j

>>> type(1j)
<class 'complex'>
```


복소수를 만드는 방법에는 흔히 두 가지가 있어요.

1) [`complex(real, imag)`][complex] 생성자는 `float` 매개변수 두 개를 받아요:

    ```python
    >>> z1 = complex(1.5, 2.0)
    >>> z1
    (1.5+2j)
    ```

    이 생성자는 문자열 입력을 분석할 수도 있어요.
    다만 문자열에 공백이 들어 있으면 실패한다는 이상한 제약이 있어요.

    ```python
    >>> complex('4+2j')
    (4+2j)
    
    >>> complex('4 + 2j')
    Traceback (most recent call last):
      File "<stdin>", line 1, in <module>
    ValueError: complex() arg is a malformed string
    ```


2) 복소수는 `<real part> + <complex part>j` 리터럴로 나타낼 수 있고, 실수부가 0이면 `<complex part>j`만 써도 돼요:


    ```python
    >>> z2 = 2.0 + 1.5j
    >>> z2
    (2+1.5j)
    ```
    최종 결과는 `complex()` 생성자를 사용한 것과 같아요.


## 산술

실수와 정수에 쓰는 [`operators`][operators] 대부분은 복소수에도 그대로 쓸 수 있어요.

복소수에는 정수 나눗셈이 _**불가능**_해서, `//`와 `%` 연산자, 그리고 `divmod()` 함수는 복소수형에서는 실패해요.

복소수의 곱셈과 나눗셈 규칙을 설명하는 것은 이 개념의 범위를 벗어나요(_그런 연산을 "손으로" 직접 할 일도 그리 많지 않아요_).

복소수를 다루는 [수학][math-complex]이나 [전기공학][engineering-complex] 입문서를 보면 이런 내용을 다루니, 더 깊이 파고들고 싶다면 참고해 봐요.

Python 표준 라이브러리에는 실수를 다루는 유용한 기능이 가득한 [`math`][math-module] 모듈이 있고, 복소수를 다루기 위한 같은 역할의 [`cmath`][cmath] 모듈도 있어요.
