# 힌트

## 일반

- 시작하기 가이드에서 [`alias`와 `import`][getting-started]에 대해 읽어 봐요.
- elixirschool.com에서 [모듈 구성][elixir-school-module-composition]에 대해 읽어 봐요.

## 1. 컴파일 오류 `Race.__struct__/0 is undefined` 고치기

- [`alias`][alias] 특수 폼으로 별칭을 만들 수 있어요.

## 2. 컴파일 오류 `Car.__struct__/0 is undefined` 고치기

- [`alias`][alias] 특수 폼으로 별칭을 만들 수 있어요.
- `alias` 특수 폼은 `:as` 옵션을 받아요.

## 3. 컴파일 오류 `undefined function puts/1` 고치기

- [`import`][import] 특수 폼으로 함수를 가져올 수 있어요.
- [`import`][import] 특수 폼은 `:only` 옵션을 받아요. 이 옵션의 값은 함수 이름을 키로, 함수의 인자 개수를 값으로 하는 키워드 리스트여야 해요.

## 4. 컴파일 오류 `undefined function default_color/0` 고치기

- [`import`][import] 특수 폼으로 함수를 가져올 수 있어요.
- [`import`][import] 특수 폼은 `:except` 옵션을 받아요. 이 옵션의 값은 함수 이름을 키로, 함수의 인자 개수를 값으로 하는 키워드 리스트여야 해요.
