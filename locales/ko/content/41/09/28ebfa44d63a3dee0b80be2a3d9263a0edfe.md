# 소개

Roc은 단순함을 염두에 두고 안정적인 소프트웨어를 만들기 위해 설계된 현대적이고 빠르며 안전한 프로그래밍 언어예요. 성능과 미니멀리즘을 강조하면서, Roc은 함수형 프로그래밍의 세계에 새로운 관점을 가져와 개발자가 더 쉽고 효율적으로 다룰 수 있게 하는 것을 목표로 해요.

## 주요 특징

- **단순함과 안전성**: Roc은 타입 시스템을 통해, 그리고 기본적으로 불변성을 강제함으로써 흔한 프로그래밍 오류를 줄이도록 설계됐어요. 덕분에 코드를 더 예측 가능하고 유지보수하기 쉽게 만들어 줘요.
- **최적화된 성능**: Roc의 컴파일러는 고도로 최적화된 기계어 코드를 생성하도록 만들어져서, 애플리케이션이 빠르고 효율적으로 실행돼요.
- **군더더기 없는 의존성**: Roc은 코드에서뿐 아니라 의존성 관리에서도 단순함을 장려하며, 외부 의존성을 최소한으로 유지하는 것을 목표로 해요.
- **깔끔한 문법**: Roc의 문법은 간결하고 읽기 쉬우며, 현대 함수형 언어에서 영감을 받으면서도 불필요한 복잡함은 덜어냈어요.
- **상호 운용성**: Roc은 다른 언어와 잘 어울리도록 만들어져서, 기존 프로젝트에 더 쉽게 통합할 수 있어요.

자세한 내용은 [roc-lang.org](https://roc-lang.org)에서 확인해요.
