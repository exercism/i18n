# 안내

이 연습 문제에서는 저축 계좌를 다뤄요. 저축 계좌의 잔액은 매년 이자율에 따라 갱신돼요. 은행이 주는 이자율은 계좌에 있는 돈의 양, 즉 잔액에 따라 달라져요.

- 잔액이 `1000` 달러 미만인 0 이상의 경우에는 0.5%.
- 잔액이 `1000` 달러 이상 `5000` 달러 미만인 양수인 경우에는 1.621%.
- 잔액이 `5000` 달러 이상인 양수인 경우에는 2.475%.
- 잔액이 음수인 경우에는 3.213% (이자도 음수가 돼요).

세 가지 과제가 있고, 각 과제에서는 잔액과 이자율을 다뤄요.

## 1. 이자율 계산하기

주어진 잔액을 기준으로 이자율을 계산하는 `SavingsAccount.interest_rate` 메서드를 구현해요.

```ruby
SavingsAccount.interest_rate(200.75)
#=> 0.5
```

반환되는 값은 `Float`의 인스턴스라는 점에 주의해요.

## 2. 연간 잔액 갱신액 계산하기

이자율을 고려해서 연간 잔액 갱신액을 계산하는 `SavingsAccount.annual_balance_update` 메서드를 구현해요.

```ruby
SavingsAccount.annual_balance_update(200.75)
#=> 201.75375
```

반환되는 값은 `Float`의 인스턴스라는 점에 주의해요.

## 3. 목표 잔액에 도달하기까지 걸리는 연수 계산하기

목표 잔액에 도달하는 데 필요한 최소 연수를 계산하는 `SavingsAccount.years_before_desired_balance` 메서드를 구현해요.

```ruby
SavingsAccount.years_before_desired_balance(200.75, 214.88)
#=> 14
```

반환되는 값은 `Integer`의 인스턴스라는 점에 주의해요.
