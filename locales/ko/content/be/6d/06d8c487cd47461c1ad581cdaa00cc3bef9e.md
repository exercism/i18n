# https://www.php.net/manual/en/language.basic-syntax.phptags.php"범위 지정 연산자

범위 지정 연산자(`::`)를 사용하면 클래스를 참조해서 그 클래스의 이름 상수, 정적 프로퍼티, 정적 메서드에 접근할 수 있어요.

```php
class MyClass
{
  public const MY_VALUE = 1;
}

// MyClass::class => "MyClass"
// MyClass::MY_VALUE => 1
```

## 범위 지정 연산자와 함께 `self`와 `static` 사용하기

객체가 자신의 스코프를 참조해야 할 때가 있어요. 이를 위해 `self` 키워드를 사용하면 클래스가 자신의 스코프를 참조할 수 있어요. `self` 키워드를 사용하면 클래스가 자기 이름에서 분리되기 때문에, 시간이 지나도 코드를 유지 관리하기가 더 쉬워져요.

```php
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return self::MY_VALUE;
  }
}

// (new MyClass)->getMyValue() => 1
```

하지만 `self`는 자신이 나타나는 클래스에 어휘적으로 바인딩돼요.

```php
class MyOtherClass extends MyClass
{
  public const MY_VALUE = 99;
}

// (new MyOtherClass)->getMyValue() => 1
```

`MyOtherClass::getMyValue`를 평가해도 여전히 `99`가 아니라 `1`이 나와요. 이 문제를 해결하려면 범위 지정 연산자와 함께 `static` 키워드를 사용해서 참조를 현재의 하위 클래스에 늦게 바인딩해요.

```php
// Update MyClass:
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return static::MY_VALUE;
  }
}
```

## 범위 지정 연산자와 함께 `parent` 사용하기

부모 스코프에서 사용할 수 있는 상수, 프로퍼티, 메서드를 특별히 참조해야 할 때도 있어요.

```php
class MyClass
{
  public function getMaximum(): int
  {
    return 5;
  }
}

class AnotherClass extends MyClass
{
  public function getMaximum(): int
  {
    return parent::getMaximum() * 2;
  }
}

// (new AnotherClass())->getMaximum() => 10
```

객체 지향 프로그래밍에서는 객체를 인스턴스화할 때 부모 생성자를 호출하기 위해 `parent`를 가장 흔히 사용해요.

```php
class ChildClass extends ParentClass
{
  public function __construct(): void
  {
    parent::__construct();
  }
}
```

## 주의할 점

### 상수, 프로퍼티, 메서드의 가시성

범위 지정 연산자도 `public`, `private`, `protected` 가시성 제어자가 정한 규칙을 그대로 따라요.
