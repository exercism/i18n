# 소개

Haxe에서 추상 타입은 실행 시점에는 다른 타입이 되는 타입이에요. 이는 구체적인 타입 "위에" 타입을 정의해서 그 동작을 수정하거나 확장할 수 있게 해주는 컴파일 시점의 기능이에요:

```haxe
abstract AbstractInt(Int) {
    inline public function new(i:Int) {
        this = i;
    }
}
```

여기서는 `abstract` 키워드를 사용해 `AbstractInt` 타입을 선언하고 있어요. 문법은 `class`와 아주 비슷해요. 그리고 클래스와 마찬가지로 추상 타입도 메서드를 가질 수 있어요. 클래스처럼 인스턴스를 만들어 사용할 수도 있어요:

```haxe
class Main {
    static public function main() {
        var a = new AbstractInt(12);
        trace(a); // 12
    }
}
```
