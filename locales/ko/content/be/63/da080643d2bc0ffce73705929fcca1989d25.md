# 자세히 알아보기

`List`는 [`Array`][array]와 아주 비슷해요. 하지만 그냥 지나칠 수 없는 중요한 차이점이 몇 가지 있어요:

1. 리스트는 `[0]`처럼 대괄호를 사용해 인덱싱할 수 없어요.
2. 리스트는 초기화할 수 없어요.
3. 리스트 컴프리헨션은 없어요.
4. 리스트는 원소를 순회하는 동안에도 자유롭게 수정할 수 있어요.

`List`는 `haxe.ds` 패키지에 속해 있어서, 리스트를 사용하려면 항상 이 패키지를 임포트해야 해요:

```haxe
import haxe.ds.List;

class Main {
  static function main() {
    var myList = List<Int>();

    for (i in 0...5) {
      myList.add(i);
    }

    trace(myList); // {0, 1, 2, 3, 4}
  }
}
```

[array]: https://haxe.org/manual/std-Array.html
