# About

`PHP 8.0.0`부터 사용할 수 있는 **유니언 타입 선언**은 값이 단일 타입이 아니라 여러 다른 타입을 가질 수 있도록 해줘요. 유니언 타입 정의는 파이프(`|`)를 사용해 타입을 구분해요.

```php
function add(int|float $a, int|float $b): int|float
{
    return $a + $b;
}
```

## 세부 사항

- `null` 타입은 `?Type` 또는 `Type1|Type2|null`을 사용해 _nullable_ 로 선언할 수 있어요.
- 중복되거나 불필요한 타입을 선언하면 컴파일 시점에 오류가 발생해요.
- `void`는 유니언 타입 선언의 일부로 사용할 수 없어요.
