# 소개

고등학교 때 대수학을 처음 배웠던 기억이 있나요?

보통은 연립방정식이 주어지고, `x`, `y`의 값을 구하라는 문제를 받아요.

```
4x - 3y = -2
2x + 7y = 16
```

방정식 두 개, 미지수 두 개예요. 약간 대입해 보면 `x = 1, y = 2`라는 걸 곧 알 수 있어요.

앞의 예시에서 왼쪽 변을 다시 봐요.
행렬 `[4 -3; 2 7]`에 미지의 벡터 `[x, y]`를 곱해 벡터 `[-2, 16]`을 얻는 것처럼 보여요.

선형대수 표기법으로는 **A** **x** = **b**예요. 행렬에는 대문자, 벡터에는 소문자를 쓰는 일반적인 관례를 따르면요.

## **A x = 0**과 영공간

중요한 특별한 경우는 모든 방정식의 우변이 0일 때예요.

```
4x - 3y = 0
2x + 7y = 0
```

위 예시에서 유일한 해는 `x = y = 0`일 때뿐인데, 보통은 별로 흥미롭지 않아요.

**A x = 0**의 자명하지 않은 해는 **A**의 [행렬식][wiki-determinant]이 0일 때만 존재해요.

```julia-repl
julia> using LinearAlgebra

julia> A = [4 -3; 2 7]
2×2 Matrix{Int64}:
 4  -3
 2   7

julia> det(A)  # not zero!
34.0
```

대신 이런 방정식을 생각해봐요:

```
4x - 3y = 0
8x + 6y = 0
```

두 번째 방정식은 첫 번째 방정식을 두 배 한 것일 뿐이고, 새로운 정보를 더하지 않아요.
`x = 0.75y`인 값이라면 무엇이든 해가 돼요.

이 `(x, y)` 값들은 2차원 공간에서 하나의 직선 위에 놓여요.
해가 무한히 많고, 이것들이 행렬의 [영공간][wiki-nullspace]을 이뤄요.

이 경우 행렬의 행들은 [선형 독립][indep]이 아니고, 행렬의 [랭크][rank]는 행이나 열의 개수보다 작아요.

```julia-repl
julia> A = [4 -3; 8 -6]
2×2 Matrix{Int64}:
 4  -3
 8  -6

julia> det(A)
0.0

julia> size(A)  # total number of rows and columns
(2, 2)

julia> rank(A)  # number of linearly-independent rows (or columns)
1

julia> nullspace(A)
2×1 Matrix{Float64}:
 -0.6
 -0.8

julia> nullspace(A) |> norm  # Julia returns unit vectors when possible
1.0
```

[`nullspace()`][ref-nullspace] 함수는 [단위 벡터][wiki-unit-vec]로 정규화된 한 점을 반환하는데, 이 벡터의 스칼라 배수도 모두 영공간에 속해요.

## **A x = b** 풀기

이제 미지수 1000개에 대한 방정식 1000개가 있다고 해볼까요?
그게 우스워 보인다면, 무선 디지털 트랜스듀서가 이제 저렴하고 다재다능하다는 걸 기억해요(변형률, 풍속, 3축 가속도, 뭐든 측정해요...).
현수교 같은 현대 구조물을 감시하는 데 그런 트랜스듀서 1000개를 쓰는 건 지극히 합리적이에요.
데이터 스트림을 해석하고, 상황이 심각해지면 경보를 보낼 준비가 된 제어 시스템이 필요해요.

다시 **A** **x** = **b**예요. 여기서 **A**(설계에서 나온 값)와 **b**(트랜스듀서가 측정한 값)는 알고 있지만 **x**는 찾아야 해요.

이런 걸 처음 접하는 사람이라면 누구나 처음엔 **A**로 "양변을 나눠서" 우변으로 옮기면 어떨까 하고 생각해요.

사실 **A**에는 역행렬이 있어요(모든 정방행렬이 그런 건 아니고 대부분이 그래요. [행렬식][wiki-determinant]이 0이 아니어야 하거든요). 그래서 계산이 _(느리게!)_ 동작해요.

```julia-repl
julia> A = [4 -3; 2 7]
2×2 Matrix{Int64}:
 4  -3
 2   7

julia> b = [-2, 16]
2-element Vector{Int64}:
 -2
 16

# the inverse matrix
julia> inv(A)
2×2 Matrix{Float64}:
  0.205882   0.0882353
 -0.0588235  0.117647

julia> inv(A) * b
2-element Vector{Float64}:
 0.9999999999999999
 2.0
```

아쉽게도 역행렬 계산은 작은 행렬에서는 느리고, 큰 행렬에서는 아주 더뎌요.
계산하는 동안 다리가 무너진다면, 결코 이상적이지 않겠죠!

다행히 다른 알고리즘은 훨씬 빨라요(이 경우에는 [가우스 소거법][gaussian-elim]이요).

Julia는 (Matlab을 따라) 풀이에 그냥 백슬래시를 사용해요(엄밀히 말하면 "왼쪽 나눗셈"이에요).

```julia-repl
julia> x = A \ b
2-element Vector{Float64}:
 1.0
 2.0
```

사소한 예시지만, 주의해야 할 몇 가지 세부 사항이 있어요.

- 계수는 열에 맞춰 정렬되어야 하니, 빠진 항에는 필요에 따라 0을 넣어요.
- 방정식(따라서 행렬의 행)은 [선형 독립][indep]이어야 해요. 3번째 행이 1번째와 2번째 행의 합일 뿐이라면, 새로운 정보를 더하지 않으므로 문제가 과소결정 상태가 돼요.

[`rank()`][rank] 명령은 선형 독립인 행/열의 개수를 알려주니, 이 값이 미지수의 개수와 같아지도록 하는 게 목표예요.

```julia-repl
julia> rank(A)
2
```

### 직사각 행렬

어릴 적에, 미지수 `N`개를 풀려면 `N`개의 연립방정식이 필요하다고 배웠을 거예요.

수학의 대부분이 그렇듯 현실은 조금 더 미묘해요(앞 절에서 언급한 선형 독립 문제만이 아니에요).

#### 행이 "너무 적을" 때

`N-1`개의 방정식(행렬 `A`의 행)만 있으면 문제는 과소결정이에요.
절망하고 포기해야 할까요?

상황에 따라 달라요!

`N-1`개의 방정식에도 여전히 많은 정보가 담겨 있어요.
기하학적으로 말하면, N차원 공간에서 해를 _점_으로 특정하려면 `N`개가 필요하지만, `N-1`개만으로도 해가 _직선_ 위 어딘가에 있어야 한다는 것은 알 수 있어요.

그러면 해가 무한히 많아지지만, 동시에 해가 _하나도_ 없는 매개변수 공간도 무한히 많아져요.

해가 이루는 직선이, 훌륭한 엔지니어라면 걱정해야 할 매개변수 공간 영역을 지나가나요?
아니면 구조물의 공공 접근을 막아야 할 만한 영역을 지나가나요(_현수교는 강한 측풍을 맞으면 요동칠 수 있거든요_)?
그걸 알아내려면 계산을 좀 더 해볼 가치가 있겠죠!

```julia-repl
julia> A3 = [4 -3 1; 2 2 2; 3 -4 -3]
3×3 Matrix{Int64}:
 4  -3   1
 2   2   2
 3  -4  -3

julia> b3 = [1, 12, -14]
3-element Vector{Int64}:
   1
  12
 -14

# fully-determined solution
julia> A3 \ b3
3-element Vector{Float64}:
 1.0
 2.0
 3.0

# remove row 3 from A3 and B3
julia> A2 = A3[1:2, :]
2×3 Matrix{Int64}:
 4  -3  1
 2   2  2

julia> b2 = b3[1:2]
2-element Vector{Int64}:
  1
 12

# an under-determined solution
julia> z1 = A2 \ b2
3-element Vector{Float64}:
 1.594594594594594
 2.445945945945947
 1.9594594594594592
```

백슬래시 풀이법이 해를 하나 내놔요!
[비공식적으로][underdet] 이것은 노름이 가장 작은 해인 것 같아요(기하학적으로 원점에 가장 가까운).

다른 해들을 구하려면 `A2`의 [`nullspace`][ref-nullspace]가 필요해요.

원래 해에 영공간의 스칼라 배수를 더하면 또 다른 유효한 해가 돼요.

```julia-repl
# get the nummspace of A2
julia> N = nullspace(A2)
3×1 Matrix{Float64}:
 -0.46499055497527725
 -0.3487429162314578
  0.813733471206735

# add a random multiple of the nullspace to the earlier solution
julia> z = z1 + rand() * N
3×1 Matrix{Float64}:
 1.274331860650258
 2.205748895487695
 2.5199192438620472

# our random z is a valid solution, recovering b2 = [1, 12]
julia> A2 * z
2×1 Matrix{Float64}:
  0.9999999999999947
 12.0
```

마찬가지로 `N-2`개의 방정식은 (무한한) 해들을 하나의 평면으로 제한하고, 같은 원리가 적용돼요.

#### 행이 "너무 많을" 때

반대 상황은 미지수보다 방정식이 _더 많은_데도 여전히 선형 독립인 경우예요.

_실제 엔지니어링에서는 이게 지극히 정상이고, 오히려 좋은 일로 여겨져요!_

트랜스듀서의 정밀도에는 한계가 있고, **b** 벡터의 정밀도에도 한계가 있으며, 계산에는 노이즈가 끼어요.
이제 해는 노이즈가 있는 데이터에 대한 [최소제곱][least-squares] 적합이 돼요.

가장 간단한 기법은 행렬의 [`pseudoinverse`][pseudoinv]를 사용하는데, Julia에서는 [`pinv()`][pinv] 함수로 구현되어 있어요.

이는 (비특이) 정방행렬의 역행렬처럼 쓸 수 있는데, 정확한 해 대신 변수들의 최소제곱 추정값을 줘요.

```julia-repl
# create 5-row A and b for 2 variables
julia> A5 = [4 -3; 2 7; -1 2; 1 -1; 3 1]
5×2 Matrix{Int64}:
  4  -3
  2   7
 -1   2
  1  -1
  3   1

julia> rank(A5)
2

# add some random-normal noise to b5
julia> b5n = [-2, 16, 3, -1, 5] + randn(5) * 0.1
5-element Vector{Float64}:
 -1.9337349223581917
 16.024913008059457
  3.0087646177373992
 -0.8675748721176717
  4.914568047308805

# solve to get x ≈ 1, y ≈ 2, using the pseudoinverse
julia> pinv(A5) * b5n
2-element Vector{Float64}:
 1.006117942769543
 1.9962973764508272
```

## 고윳값과 고유벡터

앞 절에서는 우리에게 익숙한 대수와 같은 **A** **x** = **b**의 해를 다뤘어요.

이번 절은 **A** **x** = λ **x**의 해에 대한 것이고, 여기서 λ는 스칼라예요.

이건 선형대수만의 독특한 개념이지만, 기하학적으로 해석할 수 있어요:

_적절한 **x**와 λ 값에 대해, 정방행렬 **A**는 0이 아닌 벡터 **x**의 길이를 λ배로 늘리거나 줄이면서 방향은 바꾸지 않아요(λ가 음수이면 방향이 뒤집히는 것은 예외예요)_.

별로 쓸 데 없어 보이지만, 알고 보면 _터무니없이_ 유용해요!

***용어:*** 유효한 λ 값은 **A**의 _고윳값_이고, 대응하는 **x** 값은 **A**의 _고유벡터_예요.
_아쉽지만 절반쯤에서 다른 언어로 바뀌는 단어를 그냥 받아들여야 해요._

보통 학생들은 2×2 행렬의 고윳값과 고유벡터를 손으로 계산하는 법을 배우지만, 컴퓨터를 쓰는 게 훨씬 쉬워요(그래도 꽤 느리고, 일반적인 경우 `n×n` 행렬에서 `O(n^3)`으로 늘어나요).

```julia-repl
julia> A = rand(-9:9, 2, 2)
2×2 Matrix{Int64}:
 9  5
 3  2

julia> F = eigen(A)
Eigen{Float64, Float64, Matrix{Float64}, Vector{Float64}}
values:
2-element Vector{Float64}:
  0.27984674554472466
 10.720153254455274
vectors:
2×2 Matrix{Float64}:
 -0.497417  0.945605
  0.867511  0.325317

# eigenvalues
julia> F.values
2-element Vector{Float64}:
  0.27984674554472466
 10.720153254455274

# each column is an eigenvector, normalized to a unit vector
julia> F.vectors
2×2 Matrix{Float64}:
 -0.497417  0.945605
  0.867511  0.325317
```

일반적으로 `n×n` 행렬은 `n`개의 고윳값을 가져요. 다만 항상 _서로 다른_ 값인 것은 아니에요.
이것들은 `n`차 다항식([특성 다항식][wiki-char-poly]이라고 해요)의 근이라고 생각하면 되는데, 중복될 수 있고, 실수값 행렬에서도 흔히 복소수예요.

각 고유벡터는 하나의 방향을 나타내고, 스칼라 배수도 모두 유효한 고유벡터예요.
이후 계산의 편의를 위해, Julia는 [노름][wiki-norm]이 1인 단위 벡터를 반환해요.

### 활용

고유벡터가 왜 중요한지 설명하는 건 몇 개의 짧은 문단보다 500쪽짜리 교과서가 맡아야 할 일이에요.
이 주제는 현대 응용수학의 _아주 많은_ 부분에 스며들어 있어요.

큰 틀에서 보면, 고유벡터는 데이터셋에서 "가장 중요한" 축(방향)을 나타내요.
고윳값은 각 축의 "상대적 중요도"를 나타내요(_입력의 정규화에 관한 몇 가지 가정이 전제돼요_).

이것이 실제로 _무엇을_ 뜻하는지는 활용 분야에 따라 달라요.

#### 주성분 분석

전형적인 데이터 과학 문제에서는 100개 이상의 "특징"이 데이터 열로 저장되어 있을 수 있어요.
거의 필연적으로 노이즈, 중복, 원치 않는 상관관계가 있어요.

차원 축소가 필요하고, [PCA][wiki-PCA]는 이 혼돈에 질서를 부여하는 한 가지 방법이에요:

- 데이터의 [공분산 행렬][wiki-cov-matrix]을 계산해요.
- 이제 정방행렬이 생겼으니, 다음으로 고윳값과 고유벡터를 계산해요.
- 고유벡터를 고윳값(더 정확히는 절댓값 `|λ|`)이 큰 순서대로 정렬해요.
- 상위 `k`개의 고유벡터가 바로 `principal components`예요. 여기서 `k`는 원래 특징 개수보다 훨씬 작아요.
- 전체 데이터셋을 이 `k`개의 축에 투영하고, 흥미로운 패턴을 찾기 시작해요.

이런 형태의 PCA는 신약 설계에서 분자 특성을 개선하려는 의학 연구자부터 여론조사 데이터로 유권자 선호를 파악하려는 정치 캠페인 활동가까지, 아주 다양한 집단에서 쓰여 왔어요.
아마 당신에게 뭔가를 팔려는 마케팅 집단도 썼을 거예요. 하지만 어떤 기술이든 좋은 쪽으로도 나쁜 쪽으로도 쓰일 수 있어요.

PCA는 최소 설치의 Julia에는 포함되어 있지 않지만, (Exercism 밖에서는) [MultivariateStats][ref-multistats] 패키지에 필요한 것이 들어 있어요.

#### 이미지 처리

PCA 아이디어를 한 걸음 더 밀고 나가면, 디지털 이미지는 그저 픽셀 값의 행렬이므로 여기에 대해서도 주성분을 계산할 수 있어요.

이건 수십 년 동안 이미지 압축에 쓰여 왔는데, 파일 크기를 줄일 때 무엇을 가장 중요하게 보존해야 하는지 PCA가 알려줘요.

점점 더 PCA는 얼굴 인식 같은 이미지 분류기의 핵심 요소가 되고 있어요.
다음에 공항을 지나갈 때, [빅 브라더][wiki-big-brother]는 그냥 지켜보기만 하는 게 아니라 보고 있는 것을 이해하는 데 선형대수까지 써요!

#### 기계 공학

논란이 덜한 예로, 기계 부품의 주축은 그 부품의 [관성 모멘트 텐서][wiki-I-tensor] ***I***의 고유벡터예요(이름만 조금 다른 행렬이죠).

자동차 바퀴에는 아마 이 텐서 ***I***의 비대각 원소를 0으로 만들기 위해 조정된 균형추가 하나 이상 있을 거예요.
정비사는 분명 그 계산을 피하겠지만(항공기 설계자나 로켓 엔지니어와는 달리), "흔들림"은 텐서의 교차항을 가리키는 일상적인 말일 뿐이에요. 이 경우 교차항은 여정을 덜 편안하게 만들고 베어링의 기계적 마모를 늘려요.
