# 설치

Cairo는 Scarb를 내려받기만 하면 설치할 수 있어요. Scarb는 Cairo 컴파일러와 Cairo 언어 서버를 설치하기 쉬운 하나의 패키지로 묶어 주기 때문에 바로 Cairo 코드를 작성할 수 있어요. Scarb는 Cairo의 패키지 관리자이기도 해요.

사용 중인 플랫폼에 권장되는 설치 안내를 확인하려면 [Cairo 공식 웹사이트](https://www.cairo-lang.org/tutorials/getting-started-with-cairo/)로 가 봐요.

운영체제별 안내는 다음과 같아요:

- Linux/MacOS
    1. [asdf](https://asdf-vm.com/guide/getting-started.html)를 설치해요
    2. [scarb](https://docs.swmansion.com/scarb/download#install-via-asdf)를 설치해요
    3. 새 터미널 세션에서 `scarb --version`으로 설치를 확인해요
- Windows
    1. [scarb](https://docs.swmansion.com/scarb/download#windows)를 설치해요
    2. 새 터미널 세션에서 `scarb --version`으로 설치를 확인해요

툴체인을 설치하는 것만으로는 부족해요! IDE (통합 개발 환경) 지원은 대부분의 개발자가 이제 당연하게 여기는, 생산성을 크게 높여 주는 요소예요.
Visual Studio Code를 사용한다면, 구문 강조와 코드 자동 완성 등 유용한 기능을 제공하는 [Cairo 확장](https://marketplace.visualstudio.com/items?itemName=starkware.cairo1)을 설치하는 걸 추천해요!
