# Elm 문법 기초 2

## 함수 내보내기

함수 내보내기는 첫 번째 개념에서 다뤘어요. 여기서는 간단히 되짚어 볼게요.

Elm의 각 파일은 모듈이고, 다른 모든 코드보다 앞에 `module` 문을 포함해야 해요.

모듈 이름은 파일 이름과 일치해야 해요. 따라서 `Calculator` 모듈은 Calculator.elm 파일에 있어야 하고, `Parser.Utils` 모듈은 Parser/Utils.elm 파일에 있어야 해요.

모듈 안에서 정의한 것은 모두 그 모듈 안에서만 쓸 수 있고, `exposing`에 나열하지 않는 한 모듈 밖에서는 접근할 수 없어요.

```elm
-- Calculator.elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Calculator.elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## 다른 모듈에서 함수 가져오기

다른 모듈에 정의된 함수에 접근하려면 import를 사용해요.
모듈을 가져오면 그 모듈이 노출한 함수는 모두 접근할 수 있게 돼요.
다만 어떻게 접근하는지는 모듈을 어떻게 가져오는지에 따라 달라요.

한정 import가 기본이고, 그런 모듈 안의 함수(예를 들어 `List` 모듈의 `map` 함수)에 접근할 때는 모듈 이름을 앞에 붙여요(`List.map`).

열린 import를 쓰면 그 모듈이 노출한 함수에 접두사 없이 바로 접근할 수 있어요. 내보내기에서 쓴 것과 대칭으로, `exposing` 키워드로 해요. 사용할 수 있는 함수를 전부 노출하거나(`..`), 특정 함수만 노출할 수 있어요(예를 들어 `map`).

다른 모듈에서 타입과 그 생성자를 가져올 수도 있는데, 이건 나중에 다루는 개념이에요.

한정 import는 명확성을 높이고 이름 충돌을 피하기 위해 선호돼요.

```elm
-- qualified imports
import List                            -- List.map, List.foldl
import List as L                       -- L.map, L.foldl

-- open imports
import List exposing (..)              -- map, foldl, concat, ...
import List exposing ( map, foldl )    -- map, foldl, List.concat
```

https://elm-lang.org/docs/syntax#modules

## 타입 애너테이션

타입 애너테이션은 `name : parameter types -> return type` 형태로 정의하고, 매개변수 타입도 `->`로 구분해요.

```elm
add : Int -> Int -> Int
add number1 number2 = number1 + number2
```

괄호를 사용해 함수 매개변수를 정의할 수 있어요(매개변수 자체도 같은 문법으로 정의되므로 괄호가 필요해요).

```elm
-- Transform every character in a string
map : (Char -> Char) -> String -> String
map charMapperFunction string =
    -- ...
```

https://elm-lang.org/docs/syntax#type-annotations

## 숫자

Elm에서 쓸 수 있는 숫자에는 두 가지 타입이 있고, 각각 `Int`와 `Float` 타입으로 정의돼요.
`Int`는 양의 정수와 음의 정수 전체에 대응해요.
`Float`는 실수 전체에 대응하지만, 컴퓨터의 정밀도에 따라 제한돼요.
숫자에 정의된 연산은 보통 둘 중 한 타입에서만 동작하고, 두 타입을 섞지는 못해요.
둘 사이를 변환하는 함수도 있는데, `Int`를 `Float`로 바꾸는 `toFloat`가 있고, `Float`를 `Int`로 바꾸는 `round`, `floor`, `ceiling`, `truncate`는 각각 다른 의미로 동작해요.

https://package.elm-lang.org/packages/elm/core/latest/Basics#Int

## 문자열 연산

코드에서 단어와 문장을 표현하려고 Elm에는 기본 `String` 타입이 있어요.
문자열 리터럴은 `"Hello World!"`처럼 큰따옴표 사이에 써요.
문자열 연결 연산자 `++`와 같음 연산자 `==`를 기본으로 쓸 수 있어요.

```elm
hello : String -> String
hello subject = "Hello " ++ subject

hello "World!" --> "Hello World!"
```

다른 대부분의 문자열 함수는 `String` 모듈에 있고, 이 모듈은 import해야 해요.

https://package.elm-lang.org/packages/elm/core/latest/String
