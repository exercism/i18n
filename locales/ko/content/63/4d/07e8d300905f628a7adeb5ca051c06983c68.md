# 지침

친구가 중요한 비밀이 담긴 메시지를 방금 보냈어요. 다른 사람이 쉽게 읽지 못하게 하려고, 메시지는 일련의 비트 조작을 거쳐 암호화되었어요. 이 메시지를 복호화하는 데 필요한 함수들을 작성해야 해요.

## 1. 비트를 다시 오른쪽으로 되돌리기

메시지를 복호화하는 첫 단계는, 암호화 과정에서 시프트한 비트를 다시 오른쪽으로 시프트해서 원래대로 되돌리는 거예요. 이후 단계에서는 왼쪽에서 0이 채워진다고 가정해요.

32비트 값과 이동량을 받아서, 그 이동량만큼 오른쪽으로 시프트한 값을 0으로 채워 반환하는 `shift-back`을 정의해요.

```factor
0b1001 2 shift-back .
! => 0b0010
```

## 2. 일부 비트를 1로 설정하기

다음으로, 1로 설정해야 하는 비트들이 있어요.

값과 마스크를 받는 `set-bits`를 정의해요. `mask`의 해당 비트가 1인 `value`의 모든 비트는 1로 설정하고, 나머지 비트는 그대로 둬요.

```factor
0b0110 0b0101 set-bits .
! => 0b0111
```

## 3. 특정 비트 뒤집기

암호화하는 동안 일부 비트는 뒤집혀요. 메시지를 복호화하려면 이 비트들을 다시 뒤집어야 해요.

값과 마스크를 받는 `flip-bits`를 정의해요. `mask`의 해당 비트가 1인 `value`의 모든 비트는 뒤집고, 나머지 비트는 그대로 둬요.

```factor
0b1100 0b0101 flip-bits .
! => 0b1001
```

## 4. 특정 비트 지우기

마지막으로, 복호화하면 항상 0이 되는 비트들도 있어요.

값과 마스크를 받는 `clear-bits`를 정의해요. `mask`의 해당 비트가 1인 `value`의 모든 비트는 0으로 지우고, 나머지 비트는 그대로 둬요.

```factor
0b0110 0b0101 clear-bits .
! => 0b0010
```
