# 지시 사항 부록

Roc에서는 렌즈를 그렇게 많이 쓰지는 않아요. 레코드 업데이트 문법이 대부분의 사용 사례를 잘 처리해 주기 때문이에요. 예를 들어, 이런 중첩 레코드를 살펴봐요:

```roc
bob = { hair: { color: Brown, length: Long }, mouth: Smiling, height: 6.0 }
```

이제 Bob의 머리를 잘라볼까요:

```roc
new_bob = { ..bob, hair: { ..bob.hair, length: Short } }
```

렌즈가 필요 없어요! 그렇지만 Roc에서 렌즈가 드문 것일 뿐, Haskell이나 Scala 같은 다른 언어에서는 흔히 쓰이니까, Roc에서는 렌즈를 어떻게 구현할 수 있을지 궁금할 수도 있어요. 매개변수화된 타입이나 함수를 담은 레코드처럼 Roc의 고급 기능을 연습하기에도 좋은 방법이에요. 실제로 Roc에서 렌즈를 표현하는 한 가지 방법은 이래요:

```roc
Lens(whole, part) := {
	get : whole -> part,
	set : whole, part -> whole,
}
```

이것은 매개변수화된 타입이에요. `whole`과 `part`는 어떤 타입이든 될 수 있어요. `whole`은 보통 레코드이고, `part`는 어떤 필드 타입이든 될 수 있어요. `get` 필드에는 주어진 `whole`의 특정 `part`를 반환하는 함수가 들어 있고, `set` 필드에는 주어진 `whole`의 복사본을 반환하는 함수가 들어 있어요. 다만 특정 `part`가 주어진 `part`로 바뀐 상태예요.

예를 들어, 사람의 머리카락을 가져오거나 설정하는 렌즈는 이래요:

```roc
hair_lens = {
	get: |person| person.hair,
	set: |person, hair| { ..person, hair },
}
```

이 렌즈를 써서 Bob의 머리카락에 초점을 맞출 수 있어요. 이렇게요:

```roc
bob_hair = bob |> hair_lens.get
```

머리카락을 바꾸는 건 이렇게 해요:

```roc
new_hair = { ..bob.hair, length: Short }
new_bob = bob |> (hair_lens.set)(new_hair)
```

참고: `hair_lens.set`을 감싼 괄호는 꼭 필요해요. 괄호가 없으면 Roc는 `hair_lens`의 타입 안에서 `set`이라는 이름의 함수를 찾으려고 할 거예요.

렌즈는 서로 합성하기 시작하면 특히 유용해져요. 깊이 중첩된 부분을 가져오고 설정할 수 있게 해주거든요. 이건 다음과 같은 함수를 구현하면 돼요:

```roc
compose : Lens(outer, inner), Lens(inner, part) -> Lens(outer, part)
```

이 함수를 구현하고 나면, 이렇게 머리카락 길이 렌즈를 만드는 데 쓸 수 있어요:

```roc
length_lens = {
	get: |hair| hair.length,
	set: |hair, length| { ..hair, length },
}
hair_length_lens = compose(hair_lens, length_lens)

```

이제 Bob의 머리를 한 번 더 잘라줄 수 있어요:

```roc
set_hair_length = hair_length_lens.set
new_bob = bob |> set_hair_length(Short)
```

중첩된 부분에 어떤 변환이든 적용할 수 있게 해주는 함수를 구현하고 싶을 수도 있어요:

```roc
over : Lens(whole, part), whole, (part -> part) -> whole
```

구현하고 나면 `over`를 이렇게 쓸 수 있어요:

```roc
cut_hair = |current_length| match current_length {
	Long => Short
	Short => Bald
	Bald => Bald
}
new_bob = hair_length_lens |> over(bob, cut_hair)
```

이 연습 문제에서 테스트는 코드가 다음 중첩 레코드의 여러 중첩된 부분을 잘 수정할 수 있는지 확인해요:

```roc
test_person : Person
test_person = {
	name: { forenames: "Jane Joanna", surname: "Doe" },
	birth: {
		born_at: { street: "Longway", house_number: 1024, place: "Springfield", country: "United States" },
		born_on: { year: 1984, month: 4, day: 12 },
	},
	address: { street: "Shortlane", house_number: 2, place: "Fallmeadow", country: "Canada" },
}
```

먼저 Roc의 레코드 업데이트 문법으로 테스트를 통과시켜 보고, 그다음에 렌즈를 써보는 걸 추천해요.
