# 소개

`PHP 8.0.0`부터 사용할 수 있는 **유니언 타입 선언**은 단일 타입이 아니라 여러 다른 타입의 값을 받아들여요. 유니언 타입 정의는 타입을 구분하는 파이프(`|`)를 사용해 만들어요.

```php
function add(int|float $a, int|float $b): int|float
{
    return $a + $b;
}
```

PHP는 엄격 모드에서 전달받은 매개변수가 `float`도 `int`도 아니면 `TypeError`를 발생시켜요. 엄격 모드가 아닐 때에는 전달받은 매개변수를 `float`나 `int`로 강제 변환할 수 없으면 타입 오류가 발생해요.

마찬가지로 함수가 선언된 타입 중 하나를 반환하지 않으면, PHP는 런타임에 `TypeError`를 발생시켜요.
