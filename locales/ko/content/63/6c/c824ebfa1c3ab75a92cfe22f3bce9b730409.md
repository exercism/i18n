# 불리언

어떤 질문에는 답이 두 가지뿐이에요: 예 아니면 아니요. Sather에서 이런 답을 나타내는 타입은 `BOOL`이고, 두 가지 답은 `true`와 `false`로 써요.

```sather
   ready : BOOL is
      return true;
   end;
```

## 비교하기

두 수를 비교하면 `BOOL`이 나와요.

| 연산자 | 묻는 것 |
| --- | --- |
| `=` | 두 값이 같나요? |
| `/=` | 두 값이 다른가요? |
| `<` | 왼쪽이 더 작나요? |
| `<=` | 작거나 같나요? |
| `>` | 왼쪽이 더 크나요? |
| `>=` | 크거나 같나요? |

```sather
   old_enough(age : INT) : BOOL is
      return age >= 13;
   end;
```

`=`는 질문을 던진다는 점에 주의해요. 어떤 것에 값을 *넣는* 것은 `:=`이고, 이건 이미 봤죠. 둘은 서로 달라요.

## 조합하기

세 가지 연산자로 작은 질문들을 모아 더 큰 질문을 만들 수 있어요.

`and`는 **양쪽**이 true일 때 true예요.

```sather
harness_on and rope_checked
```

`or`는 **어느 한쪽**이 true이거나 양쪽 다 true일 때 true예요.

```sather
mat_below or net_below
```

`~`는 답을 뒤집어요: true를 false로, false를 true로 바꿔요.

```sather
~ready       -- true exactly when ready is false
```

`and`와 `or`는 두 답 사이에 놓고, `~`는 답 하나 앞에 놓아요.
