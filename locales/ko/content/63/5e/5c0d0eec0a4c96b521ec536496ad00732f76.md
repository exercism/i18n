# 지침

동물의 이름과 그 동물이 사는 서식지를 연결하는 지도, 즉 야외 도감을 만들고 있어요.

다섯 개의 과제는 모두 `FIELD_GUIDE` 클래스에 들어가요.

## 1. 도감에 있을까요?

```sather
FIELD_GUIDE::is_listed(guide, "emu")
-- => true
```

## 2. 어디에 살까요?

어떤 동물에 대해 기록된 서식지를 반환해요. 도감에 그 동물이 없다면 `"Unknown"`을 반환해요.

```sather
FIELD_GUIDE::habitat_of(guide, "emu")
-- => "grassland"
FIELD_GUIDE::habitat_of(guide, "moa")
-- => "Unknown"
```

## 3. 항목을 추가해요

동물을 하나 더 넣은 도감을 반환해요. 이미 등록된 동물은 서식지가 새 값으로 교체돼요.

```sather
FIELD_GUIDE::add_entry(guide, "wombat", "forest")
-- => the guide, now with wombat in it
```

여기서 반환되는 도감이 바로 그다음부터 사용할 도감이에요. 완전히 빈 도감에 항목을 추가해도 제대로 동작하고, 동물이 하나 들어 있는 도감이 만들어져요.

## 4. 동물은 몇 마리일까요?

```sather
FIELD_GUIDE::entry_count(guide)
-- => 3
```

## 5. 어떤 서식지가 있을까요?

도감에 나오는 서식지의 집합을 반환해요. 여러 동물이 같은 서식지를 공유할 수 있고, 그 서식지는 한 번만 나타나야 해요.

```sather
FIELD_GUIDE::all_habitats(guide)
-- => a set holding "grassland" and "forest"
```
