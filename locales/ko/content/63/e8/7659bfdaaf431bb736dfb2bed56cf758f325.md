# 지침

이 연습 문제에서는 고전 게임 팩맨의 규칙 몇 가지를 Haskell 함수로 옮겨야 해요.

옮겨야 할 규칙은 네 가지이고, 모두 게임 상태와 관련이 있어요.

> 인자가 어떻게 만들어지는지는 신경 쓰지 말고, 인자들을 조합해서 원하는 결과를 반환하는 데만 집중해요.

## 1. 팩맨이 유령을 먹는지 정의하기

`eatsGhost` 함수를 정의해 봐요.
이 함수는 인자 두 개(_팩맨이 파워 펠릿을 활성화했는지_와 _팩맨이 유령에 닿아 있는지_)를 받아서, 팩맨이 유령을 먹을 수 있을 때 `Bool` 값을 반환해요.
이 함수는 팩맨이 파워 펠릿을 활성화한 상태에서 유령에 닿아 있을 때만 `True`를 반환해야 해요.

```haskell
eatsGhost False True
-- -> False
```

## 2. 팩맨이 점수를 얻는지 정의하기

`scores` 함수를 정의해 봐요.
이 함수는 인자 두 개(_팩맨이 파워 펠릿에 닿아 있는지_와 _팩맨이 점에 닿아 있는지_)를 받아서, 팩맨이 점수를 얻었는지에 따라 `Bool` 값을 반환해요.
이 함수는 팩맨이 파워 펠릿이나 점에 닿아 있으면 `True`를 반환해야 해요.

```haskell
scores True True
-- -> True
```

## 3. 팩맨이 지는지 정의하기

`loses` 함수를 정의해 봐요.
이 함수는 인자 두 개(_팩맨이 파워 펠릿을 활성화했는지_와 _팩맨이 유령에 닿아 있는지_)를 받아서, 팩맨이 지는지에 따라 `Bool` 값을 반환해요.
이 함수는 팩맨이 유령에 닿아 있고 파워 펠릿을 활성화하지 않았을 때 `True`를 반환해야 해요.

```haskell
loses False True
-- -> True
```

## 4. 팩맨이 이기는지 정의하기

`wins` 함수를 정의해 봐요.
이 함수는 인자 세 개(_팩맨이 점을 모두 먹었는지_, _팩맨이 파워 펠릿을 활성화했는지_, _팩맨이 유령에 닿아 있는지_)를 받아서, 팩맨이 이기는지에 따라 `Bool` 값을 반환해요.
이 함수는 팩맨이 점을 모두 먹었고, _그리고_ 3번에서 정의한 인자들을 기준으로 봤을 때 지지 않았을 때 `True`를 반환해야 해요.

```haskell
wins False True False
-- -> False
```
