# 지침

이 연습 문제에서는 암호학자를 도와 보안 통신 시스템을 관리하고 검증하는 일을 맡아요.
이 시스템은 모든 산술 연산이 정해진 범위 안에 머물도록 하기 위해 필드 원소, 특히 Cairo의 `felt252` 타입에 크게 의존해요.

## 1. 두 메시지의 합 계산하기

각각 `felt252`로 표현되는 두 개의 암호화된 메시지를 더해 하나의 결합된 메시지를 만들어야 해요.
다만 암호화 때문에, 최댓값 $P - 1$을 초과하는 결과는 모듈로 $P$를 이용해 범위 안으로 되돌려야 해요.

`felt252` 값 두 개를 받아 그 합을 반환하고, 결과가 유효한 범위 안에 머물도록 하는 함수를 구현해요:

```rust
add_messages(3618502788666131213697322783095070105623107215331596699973092056135007822949, 987654321)
// => 123456789
```

> **참고:** 반환 값은 `felt252`여야 해요.

## 2. 두 메시지의 차이 계산하기

때로는 원래 데이터를 되찾기 위해 메시지를 빼야 할 때가 있어요.
뺄셈 결과가 음수이면, 시스템이 자동으로 결과에 $P$를 더해 유효한 `felt252` 값의 범위 안으로 되돌려요.

`felt252` 값 두 개를 받아 그 차를 반환하고, 결과가 유효한 범위 안에 머물도록 하는 함수를 구현해요:

```rust
subtract_messages(123456789, 987654321)
// => 3618502788666131213697322783095070105623107215331596699973092056135007822949
```

> **참고:** 반환 값은 `felt252`여야 해요.

## 3. 두 메시지의 유효한 곱 계산하기

암호화된 데이터의 무결성을 보장하기 위해, 암호 시스템은 두 메시지(`felt252`)를 곱해 그 곱이 유효한 범위 안에 머물도록 하는 경우가 많아요.
결과는 유효한 범위를 벗어나지 않도록 모듈로 $P$로 계산해야 해요.

`felt252` 값 두 개를 받아 그 곱을 반환하고, 결과가 유효한 범위 안에 머물도록 하는 함수를 구현해요:

```rust
multiply_messages(382927772233671078546147897004315551461400594453673204174697055647611, 9449570)
// => 123456789
```

> **참고:** 반환 값은 `felt252`여야 해요.
