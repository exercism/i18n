# 힌트

## 일반

- `locals` 어휘는 `::`와 `[| | ]`를 제공해요.
- 로컬은 스택 코드를 대체하지 않아요. 코드를 더 명확하게 만들어 주는 곳에서 사용해요.

## 1. 조리 상태 확인하기

- [`combinators`][combinators]의 `cond`가 딱 맞는 형태예요. 한 분기는 `dup not`을
  확인하고(타이머가 `f`인지), 다른 분기는 `dup zero?`를 확인하며, 나머지는
  기본 분기가 처리해요. 각 분기는 문자열을 푸시하기 전에 타이머를 `drop`해야
  해요.

## 2. 준비 시간 추정하기

- `:: preparation-time ( layers minutes-per-layer -- total )`에
  `layers length minutes-per-layer *`를 함께 사용해요.

## 3. 필요한 면과 소스 계산하기

- 로컬을 사용하면 `dup` 없이 `layers`를 두 번 참조할 수 있어요. `[ "noodles" = ]`(또는
  `"sauce" =`)라는 조건과 함께 `count`를 사용하면 각 레이어의 개수를 구할 수
  있어요.
- `1/5`는 Factor의 유리수 리터럴이에요.

## 4. 비밀 재료 추가하기

- `last`([`sequences`][sequences]에 있어요)는 마지막 원소를 읽고, `suffix`는 끝에
  하나를 추가해요.

## 5. 레시피 양 조절하기

- 조정 계수는 `portions / 2`예요. 로컬을 사용하면 람다 안에서 `portions`를 참조할
  수 있어요.
- [`assocs`][assocs]의 `assoc-map`은 `( key value -- newkey newvalue )` 쿼테이션을
  받아요. `[| key value | … ]` 안에서 두 값을 반환하면 같은 키를 유지하고 새로운
  값을 만들어요.
