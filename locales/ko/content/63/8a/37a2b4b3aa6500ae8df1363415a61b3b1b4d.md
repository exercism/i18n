# 지시 사항

멜버른의 트램은 구역별로 요금을 매기고, 도심은 무료예요. 지금 승차권 발매기의 요금 규칙을 작성하고 있어요. 모든 요금은 센트 단위예요.

네 가지 과제는 모두 `TRAM_FARES` 클래스에 들어가요.

## 1. 구역 요금

0번 구역은 무료 트램 구역이라 요금이 없어요. 1번 구역은 550, 2번 구역은 370이에요. 그 밖의 숫자는 트램 구역이 아니므로 요금이 없어요.

```sather
TRAM_FARES::zone_fare(1)
-- => 550
TRAM_FARES::zone_fare(7)
-- => 0
```

## 2. 승차권의 종류

승차권에는 문자가 하나 적혀 있어요. `'f'`는 일반 요금이에요. `'c'`와 `'s'`는 모두 할인 요금으로, 하나는 어린이용이고 하나는 학생용이에요. `'x'`는 무료 승차권이에요. 그 밖의 문자는 알 수 없어요.

```sather
TRAM_FARES::ticket_kind('s')
-- => "Concession"
TRAM_FARES::ticket_kind('q')
-- => "Unknown"
```

네 가지 답은 `"Full fare"`, `"Concession"`, `"Free pass"`, `"Unknown"`이에요.

## 3. 요일 유형

`"Sat"`과 `"Sun"`은 주말이에요. `"Mon"`부터 `"Fri"`까지는 평일이에요. 그 밖의 값은 알 수 없어요.

```sather
TRAM_FARES::day_type("Sun")
-- => "Weekend"
```

세 가지 답은 `"Weekend"`, `"Weekday"`, `"Unknown"`이에요.

## 4. 일일 상한

트램을 아무리 많이 타도 그날의 상한을 넘겨 지불하지는 않아요. 평일에는 1100, 주말에는 700이에요. 인식할 수 없는 날에는 상한이 없어요. 즉 0이에요.

```sather
TRAM_FARES::daily_cap("Sat")
-- => 700
```
