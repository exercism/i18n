# 학습

Haskell은 순수 함수형 언어예요. 함수형은 흔히 배우는 [객체 지향 접근 방식](https://en.wikipedia.org/wiki/Object-oriented_programming)과는 근본적으로 다른 패러다임이에요. 그래서 Haskell을 배우는 일은 다른 언어를 하나 더 익히는 것과는 다르게 느껴질 수 있어요.

다행히도 어느 정도 프로그래밍 지식이 있다고 전제하는 자료가 많이 있어요. 예를 들면 다음과 같아요.

  - Haskell 초보자를 위한 주관적인 가이드 ([2019](https://github.com/theindigamer/not-a-blog/blob/master/opinionated-haskell-guide-2019.md), [2018](https://lexi-lambda.github.io/blog/2018/02/10/an-opinionated-guide-to-haskell-in-2018/))
  - 널리 알려진 무료 온라인 책 [Learn You a Haskell For Great Good!](https://learnyouahaskell.github.io/)
  - 글래스고 대학의 [Functional Programming in Haskell](https://www.futurelearn.com/courses/functional-programming-haskell) 강의
  - FP Complete의 [School of Haskell](https://www.schoolofhaskell.com/)
  - [Happy Learn Haskell Tutorial](http://www.happylearnhaskelltutorial.com/)
  - [Haskell for Mac](http://learn.hfm.io/)의 튜토리얼

최근에 나온 Haskell 책으로는 다음과 같은 것들이 있어요.
  - Christopher Allen과 Julie Moronuki의 [Haskell Programming From First Principles](https://haskellbook.com) (이 책은 사전 프로그래밍 지식을 전제하지 않아요)
  - Graham Hutton의 [Programming in Haskell](https://www.cambridge.org/us/academic/subjects/computer-science/programming-languages-and-applied-logic/programming-haskell-2nd-edition?format=PB&isbn=9781316626221)

입문에 관한 더 많은 자료는 [Haskell 위키](https://wiki.haskell.org/Learning_Haskell#Online_tutorials)에서도 찾아볼 수 있어요.
