# 지침

Lucian의 여자친구가 집으로 오는 길인데, Lucian은 아직 기념일 저녁 식사를 만들지 않았어요!

이 연습 문제에서는 Lucian이 가장 좋아하는 요리책을 보고 근사한 라자냐를 만들 수 있도록 코드를 작성해요.

라자냐를 만드는 데 걸리는 시간과 관련된 네 가지 작업이 있어요.

## 1. 오븐 예상 시간(분) 정의하기

매개변수를 받지 않고 라자냐를 오븐에 몇 분 동안 둬야 하는지를 반환하는 `Lasagna.ExpectedMinutesInOven()` 메서드를 정의해요. 요리책에 따르면 오븐에 둬야 하는 예상 시간은 40분이에요:

```csharp
var lasagna = new Lasagna();
lasagna.ExpectedMinutesInOven();
// => 40
```

## 2. 오븐에 남은 시간(분) 계산하기

라자냐가 오븐에 들어가 있었던 실제 시간(분)을 매개변수로 받아서, 이전 작업에서 구한 오븐 예상 시간(분)을 기준으로 라자냐가 오븐에 앞으로 몇 분 더 있어야 하는지를 반환하는 `Lasagna.RemainingMinutesInOven()` 메서드를 정의해요.

```csharp
var lasagna = new Lasagna();
lasagna.RemainingMinutesInOven(30);
// => 10
```

## 3. 준비 시간(분) 계산하기

라자냐에 추가한 층의 개수를 매개변수로 받아서, 층 하나를 준비하는 데 2분이 걸린다고 가정했을 때 라자냐를 준비하는 데 몇 분을 썼는지를 반환하는 `Lasagna.PreparationTimeInMinutes()` 메서드를 정의해요.

```csharp
var lasagna = new Lasagna();
lasagna.PreparationTimeInMinutes(2);
// => 4
```

## 4. 경과 시간(분) 계산하기

두 개의 매개변수를 받는 `Lasagna.ElapsedTimeInMinutes()` 메서드를 정의해요. 첫 번째 매개변수는 라자냐에 추가한 층의 개수이고, 두 번째 매개변수는 라자냐가 오븐에 있었던 시간(분)이에요. 이 메서드는 라자냐를 만드는 데 몇 분을 일했는지를 반환해야 해요. 이 값은 준비 시간(분)과 그 시점까지 라자냐가 오븐에 있었던 시간(분)을 더한 값이에요.

```csharp
var lasagna = new Lasagna();
lasagna.ElapsedTimeInMinutes(3, 20);
// => 26
```
