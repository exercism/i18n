# 소개

## 무작위성

Java에서는 `java.util.Random` 클래스의 인스턴스를 사용해 난수를 생성할 수 있어요.

### 정수 난수

`nextInt()` 메서드를 사용하면 정수 난수를 생성할 수 있어요.
이 메서드는 `Integer.MIN_VALUE`부터 `Integer.MAX_VALUE`까지의 값을 생성해요.

```java
Random random = new Random();

random.nextInt();
// => -1169335537
```

생성되는 값의 범위를 제한하려면 `nextInt(int)`를 사용해요.
이 메서드는 `0`(포함)부터 주어진 상한(미포함)까지의 값을 생성해요.

예를 들어, 다음 코드는 `0`부터 `9`까지의 난수를 생성해요.

```java
Random random = new Random();

random.nextInt(10);
// => 6
```

그리고 다음 코드는 `10`부터 `19`까지의 난수를 생성해요.

```java
Random random = new Random();

10 + random.nextInt(10);
// => 11
```

### 실수 난수

`nextDouble()` 메서드를 사용하면 실수 난수를 생성할 수 있어요.
이 메서드는 `0.0`부터 `1.0`까지의 값을 생성해요.

```java
Random random = new Random();

random.nextDouble();
// => 0.19250004204021398
```

그리고 다음 코드는 `100.0`부터 `200.0`까지의 난수를 생성해요.

```java
Random random = new Random();

100.0 + 100.0 * random.nextDouble();
// => 111.31849856260328
```
