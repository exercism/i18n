# PowerShell

모든 것을 자동화해요!
어떤 운영체제에서든 스크립트를 작성해서 파일, 프로세스, 데이터 센터, 클라우드 서비스를 관리할 수 있어요.
JSON, XML, CSV 같은 구조화된 데이터를 대화식으로 탐색하고, 웹 API와 CIM부터 명령줄 앱까지 모든 관리 인터페이스를 다뤄요.

# PowerShell 소개

오픈 소스 크로스 플랫폼 .NET 스크립팅 언어이자 셸, 구성 관리 프레임워크인 PowerShell은 IT 전문가와 고급 사용자가 거의 모든 것을 제어하고 자동화할 수 있게 도와줘요.

PowerShell은 .NET Framework 위에 만들어졌고, 고전적인 유닉스 파이프 개념을 변형시켜 텍스트나 바이너리 스트림만 전달하는 것에서 나아가 타입 정보(예: 날짜와 시간)를 담은 객체 인스턴스와 구조화된 데이터를 가진 복잡한 상태까지 전달할 수 있게 확장했어요.
전통적인 셸에서는 명령의 출력에서 특정 정보를 추출하려고 텍스트 처리를 사용하지만, PowerShell에서는 속성과 메서드에 접근할 수 있어요(어떤 속성과 메서드를 쓸 수 있는지 알아내려고 객체를 살펴보는 방법도 포함해서요).
CSV 파일을 다루고, JSON을 해시 테이블로 변환하고, XML 문서를 탐색하는 등 다양한 작업을 할 수 있어요. 텍스트 파싱으로는 어렵거나 비현실적이었을 많은 작업을 손쉽게 조합할 수 있죠.

PowerShell은 확장 가능해요.
다른 셸이 확장되는 방식처럼 독립 실행형 명령줄 도구를 통해서만이 아니라, 모듈로 배포되는 스크립트, 함수, cmdlet을 통해서도 확장할 수 있어요. 이런 것들은 PowerShell의 도움말 시스템, 구문 강조 명령줄 편집기, 자동 매개변수 검색, 탭 완성 기능과 완전히 통합돼요.
심지어 파일 시스템의 단순하고 탐색하기 쉬운 속성 + 콘텐츠 구문을 Windows 레지스트리, 인증서 저장소, SQL Server, 심지어 Azure 같은 데이터 저장소로까지 확장할 수도 있어요!

PowerShell에는 다양한 추가 기능이 있어요:

- 파일, 서비스, 프로세스, 심지어 레지스트리, 이벤트 로그, CIM(Common Information Model), 웹 요청 등을 관리하는 것과 같은 일반적인 시스템 관리 작업을 위한 내장 "cmdlet".
- 기존 스크립트 및 명령줄 도구와의 호환성.
- 확장 가능한 인터페이스, 그리고 쉽게 찾을 수 있는 모듈과 명령.
- .NET Framework에 대한 완전한 접근, 그리고 NuGet의 .NET 어셈블리를 통한 확장성.
- 명령 실행의 성공 여부와 소요 시간에 대한 정보를 담은 풍부한 명령 기록.
- 강력한 객체 조작 기능. 객체를 직접 조작하고, 직렬화하고, 심지어 다른 도구나 데이터베이스로 보낼 수도 있어요.

PowerShell 언어와 핵심 개념, 기능에 관한 자세한 문서는 설치 프로그램과 함께 https://docs.microsoft.com/en-us/powershell에서 볼 수 있어요.
