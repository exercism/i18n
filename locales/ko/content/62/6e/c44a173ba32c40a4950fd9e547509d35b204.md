# 지침

이 연습 문제에서는 친구와 숫자 맞히기 게임을 해요. 규칙은 간단해요. `1`과 `100` 사이에서 숫자를 하나 몰래 정하고, 친구가 어떤 숫자를 정했는지 맞히려고 해요. 친구를 돕기 위해, 추측한 숫자가 정한 숫자(`42`)에 얼마나 가까운지에 따라 다르게 대답해요. 대답별 규칙은 다음과 같아요:

- 추측한 숫자가 `42`면: "Correct"
- 추측한 숫자가 `41` 또는 `43`이면: "So close"
- 추측한 숫자가 `41`보다 작으면: "Too low"
- 추측한 숫자가 `43`보다 크면: "Too high"

추측에 대한 대답을 구현하는 네 가지 작업이 있어요.

## 1. 정답을 맞혔을 때 대답하기

정답을 맞혔을 때 대답하도록 `reply` 함수를 구현해요:

```fsharp
reply 42
// => "Correct"
```

## 2. 정답에 가까운 추측에 대답하기

정답에 가까운 추측에도 대답하도록 `reply` 함수를 수정해요:

```fsharp
reply 41
// => "So close"
```

## 3. 너무 낮은 추측에 대답하기

너무 낮은 추측에도 대답하도록 `reply` 함수를 수정해요:

```fsharp
reply 25
// => "Too low"
```

## 4. 너무 높은 추측에 대답하기

너무 높은 추측에도 대답하도록 `reply` 함수를 수정해요:

```fsharp
reply 88
// => "Too high"
```
