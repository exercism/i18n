# 힌트

## 일반

- `throw`는 [`kernel`][kernel]에 있고, `recover`는 [`continuations`][continuations]에 있어요.

## 1. 습도 확인하기

- `>`로 비교한 다음, `[ "humidity too high" throw ] when`을 실행해서 잘못된 경우에만 오류를 발생시켜요.

## 2. 온도 확인하기

- 1번 작업과 같은 형태이고, `500`과 다른 메시지를 사용해요.

## 3. 사용자 정의 오류 정의하기

- `ERROR: machine-error ;`는 클래스*와* 새 인스턴스를 던지는 생성자 워드를 선언해요.

## 4. 기계 모니터링하기

- 각 검사를 `[ check-… ] [ drop machine-error ] recover`로 감싸요. 복구 쿼테이션은 원래 오류를 버리고 새 `machine-error`를 던져서, ‘어느 쪽이 실패해도’라는 의미를 유지하면서 원래 예외의 정체를 숨겨요.
- [`kernel`][kernel]의 `bi*`는 각 입력에 쿼테이션을 하나씩 적용해요.
