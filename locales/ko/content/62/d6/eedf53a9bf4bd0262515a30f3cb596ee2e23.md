# 불리언

`bool` 타입은 불리언의 줄임말로, `true`와 `false` 두 가지 값만 가져요.
코드에서 `true`와 `false` 리터럴 값은 대소문자를 구분하지 않아요.

```php
<?php

$value_is_true = true;
$value_is_false = false;
```

불리언 값은 논리 표현식에서 연산자의 결과로 자주 사용되고, 그다음 제어 구조에서 사용돼요.

## 논리 연산자

논리 연산자에는 여러 가지가 있어요:

- `!$a`: `$a`가 `true`가 아니면 `true`를 반환해요
- `$a && $b`: `$a`와 `$b`가 모두 `true`면 `true`를 반환해요
- `$a || $b`: `$a` 또는 `$b` 중 하나라도 `true`면 `true`를 반환해요

~~~~exercism/caution
`and`와 `or` 연산자도 있는데, 각각 `&&`와 `||`에 대응해요.
`&&`와 `||`와 동작 방식이 같지 않고 예상치 못한 결과를 낼 수 있어서, 사용을 권장하지 않아요.
~~~~
