# 지침

이 연습 문제에서는 개발자가 식별자 이름을 정리할 수 있도록 돕는 유틸리티 루틴의 일부를 구현해요.
다섯 개의 과제를 통해 `Clean` 루틴을 조금씩 완성해 나가요.
유효한 식별자는 0개 이상의 글자와 밑줄로 이루어져요.
어떤 경우든 입력 문자열은 null이 아님을 보장해요.
`Clean` 함수에 빈 문자열이 전달되면 빈 문자열을 반환해야 해요.
다만 빈 식별자는 아무 쓸모가 없으므로, 호출하는 쪽에서는 `Clean` 루틴을 빈 식별자로 호출하지 않도록 해요.

## 1. 공백을 밑줄로 바꾸기

공백을 밑줄로 바꾸도록 (_static_) `Identifier.Clean()` 메서드를 구현해요.
문자열 앞뒤의 공백도 마찬가지예요.

```csharp
Identifier.Clean("my   Id");
// => "my___Id"
```

## 2. 제어 문자를 대문자 문자열 "CTRL"로 바꾸기

제어 문자를 대문자 문자열 `"CTRL"`로 바꾸도록 (_static_) `Identifier.Clean()` 메서드를 수정해요.

```csharp
Identifier.Clean("my\0Id");
// => "myCTRLId",
```

## 3. kebab-case를 camelCase로 변환하기

kebab-case를 camelCase로 변환하도록 (_static_) `Identifier.Clean()` 메서드를 수정해요.

```csharp
Identifier.Clean("à-ḃç");
// => "àḂç"
```

## 4. 글자가 아닌 문자는 생략하기

글자가 아닌 문자는 모두 생략하도록 (_static_) `Identifier.Clean()` 메서드를 수정해요.

```csharp
Identifier.Clean("1😀2😀3😀");
// => ""
```

## 5. 그리스 소문자는 생략하기

'α'부터 'ω'까지 범위에 있는 그리스 문자는 모두 생략하도록 (_static_) `Identifier.Clean()` 메서드를 수정해요.

```csharp
Identifier.Clean("MyΟβιεγτFinder");
// => "MyΟFinder"
```
