# 테스트

## 연습 문제 파일

내려받은 연습 문제에는 솔루션을 빌드하고 테스트하는 데 필요한 다음 파일들이 들어 있어요:

```text
hello-world/
├── HelloWorld.vb       # Your solution
├── HelloWorldTests.vb  # The test suite
├── HelloWorld.vbproj   # Project and build configuration
└── packages.lock.json  # Resolved project dependencies
```

파일 이름은 연습 문제마다 달라요.
이름이 `Tests`로 끝나지 않는 `.vb` 파일에 솔루션을 작성해요.
`Tests.vb`로 끝나는 파일은 xUnit 테스트 스위트이고, 보통은 `Skip` 인자를 지울 때만 수정하면 돼요.
프로젝트 파일이나 잠금 파일은 보통 수정할 필요가 없어요.

## 테스트 실행하기

연습 문제 디렉터리에서 터미널을 열고 다음을 실행해요:

```bash
dotnet test
```

이 명령은 프로젝트의 종속성을 복원하고, 프로젝트를 빌드한 다음, 테스트를 실행해요.
`dotnet watch test`를 사용하면 소스 파일이 바뀔 때마다 테스트를 다시 실행할 수 있어요.

## 건너뛴 테스트

연습 문제는 처음에는 첫 번째 테스트만 활성화되어 있어서, 나머지는 한 단계씩 차근차근 풀 수 있어요.
`Tests.vb`로 끝나는 파일을 열면 테스트를 찾을 수 있어요.
각 테스트는 xUnit `<Fact>` 특성으로 표시된 `Sub` 서브루틴이에요.
`<Fact>` 특성에 `Skip` 인자가 있는 한 그 테스트는 건너뛰어져요:

```vb
<Fact(Skip:="Remove this Skip property to run this test")>
Public Sub Lowercase_words()
    Assert.Equal("ROR", Abbreviate("Ruby on Rails"))
End Sub
```

테스트를 활성화하려면 `Skip` 인자를 지우기만 하면 돼요:

```vb
<Fact>
Public Sub Lowercase_words()
    Assert.Equal("ROR", Abbreviate("Ruby on Rails"))
End Sub
```

새로 활성화한 테스트가 통과하면, 다음으로 건너뛴 테스트에 같은 과정을 반복해요.
모든 테스트가 활성화되어 통과하면 끝이에요.
