# 소개

[WebAssembly](https://webassembly.org/)는 스택 기반 가상 머신을 위한 바이너리 명령어 형식이에요. 모든 주요 브라우저에 탑재된 W3C 표준이며, 스트리밍 컴파일과 JavaScript와의 편리한 상호 운용성을 갖추고 있어요. [대부분의 컴파일 언어](https://github.com/appcypher/awesome-wasm-langs)가 이제 WebAssembly 바이너리를 생성할 수 있어서, JavaScript 이외의 언어도 클라이언트 측에서 실행할 수 있게 되었어요. 또한 [많은 서버 측 런타임](https://github.com/appcypher/awesome-wasm-runtimes)과 클라우드 서비스가 WebAssembly를 실행하는데, 그중 상당수는 새롭게 등장한 [WebAssembly Systems Interface (WASI)](https://wasi.dev/)를 지원해요.

이 트랙은 가상 머신, 명령어 집합 구조, 그리고 핵심 명세가 제공하는 모듈 추상화에 익숙해지기 위해 WebAssembly 텍스트 형식(\*.wat) 파일을 직접 작성하는 데 초점을 맞춰요. WebAssembly의 실제 운영 환경 배포는 대부분 고수준 언어에서 컴파일되지만, 많은 개발자는 무거운 JavaScript 글루 코드로 WebAssembly 가상 머신을 감추는 비교적 무거운 프레임워크에 의존해요. 이런 프레임워크는 시작 시간이 느려지는 몇 메가바이트짜리 큰 바이너리를 만들어 내죠. WebAssembly를 더 깊이 이해하면 더 작은 모듈을 만들 수 있고, 내 모듈이 주변 호스트 환경과 어떻게 상호 작용하는지 완전히 제어할 수 있어요. [손으로 작성한 몇 킬로바이트의 WebAssembly](https://github.com/binji/raw-wasm)로 무엇을 해낼 수 있는지 알면 놀랄지도 몰라요!
