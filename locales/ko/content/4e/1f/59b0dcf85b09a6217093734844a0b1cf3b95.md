# 지시 사항

이번 과제는 Smart Game Format(SGF) 문자열을 파싱해서 게임을 나타내는 트리 자료 구조를 반환하는 거예요.

SGF 문자열은 노드로 이루어진 트리를 나타내요. 트리 전체는 괄호 `()`로 감싸져 있어요.
트리의 각 노드는 세미콜론 `;`으로 시작하고, 그 뒤에 여러 속성이 이어져요.
속성은 대문자 식별자(예: `AB`)와 그 뒤에 대괄호 `[]`로 감싼 하나 이상의 값으로 이루어져요.

예를 들어, `(;FF[4]C[root])`는 루트 노드 하나로 이루어진 트리를 나타내요. 이 노드에는 속성이 두 개 있어요:
- `FF` 속성, 값은 `4`
- `C` 속성, 값은 `root`

**변형(트리와 가지)**
SGF는 트리를 중첩해서 게임의 변형을 표현할 수 있어요. 하나의 트리에는 여러 자식 트리가 있을 수 있고, 이 자식 트리도 괄호로 감싸요.
예를 들어, `(;A[B](;C[D])(;E[F]))`는 `A` 속성을 가진 루트 노드를 나타내고, 이 노드에는 자식 가지가 두 개 있어요:
1. `C` 속성과 `D` 값을 가진 노드
2. `E` 속성과 `F` 값을 가진 노드

**형식과 이스케이프**
대괄호 안의 값에는 이스케이프 문자가 들어갈 수 있어요. 백슬래시 `\` 뒤에 오는 문자는 그 문자 자체를 뜻해요(예: `\]`는 문자 그대로의 `]`로 파싱해야 해요). 또 줄바꿈 앞에 백슬래시가 있으면 줄이 이어진다는 뜻이므로 값에서 제거해야 해요. 그 밖의 줄바꿈은 값에 그대로 남겨야 해요.

**오류 처리**
잘못된 SGF 문자열에 대해서는 오류를 던져야 해요. 다음은 잘못된 SGF의 예시예요:
- 괄호 `()`로 시작하지 않는 트리
- 세미콜론 `;`으로 시작하지 않는 노드
- 대문자로만 이루어지지 않은 속성 식별자
- 대괄호가 빠졌거나 괄호 짝이 맞지 않는 경우

### 데이터 구조

파싱 함수는 트리를 표현한 값을 반환해야 해요. 흔히 각 트리를 두 필드를 가진 객체로 표현해요:
- `properties`: 키가 속성 식별자(문자열)이고 값이 문자열 배열인 객체(또는 Map)예요. 속성 하나에 값이 여러 개일 수 있기 때문이에요.
- `children`: 자식 트리를 담은 배열이에요.


예시:

입력: `(;FF[4]C[root])`
출력: `{
  properties: {
    FF: ['4'],
    C: ['root']
  },
  children: []
}`

입력: `(;A[B](;C[D])(;E[F]))`
출력: `{
  properties: {
    A: ['B']
  },
  children: [
    {
      properties: {
        C: ['D']
      },
      children: []
    },
    {
      properties: {
        E: ['F']
      },
      children: []
    }
  ]
}`
