# 지시 사항

Lisp 외계인 Lilly가 돌아왔어요. 이번에는 요리를 더 많이 하려고 해요! 이번에 만들 요리는 Lisp 외계인 라자냐인데, 인간이 먹는 라자냐와 아주 다르지는 않아요.

Lilly는 라자냐 조리 시간을 맞추는 데 도움이 될 함수 몇 개를 만들어야 해요. 그리고 각 함수가 무엇을 하는지 Lilly가 잊지 않도록, 함수마다 설명도 잘 달아 두어야 해요.

Lilly가 라자냐 조리 시간을 맞출 수 있도록 함수를 작성하는 걸 도와줄래요?

## 1. 오븐에서의 예상 조리 시간(분) 정의하기

매개변수를 받지 않고, 라자냐를 오븐에 몇 분 동안 넣어 두어야 하는지 반환하는 `expected-time-in-oven` 함수를 정의해요. Lisp 외계인의 전통에 따르면(Lilly의 부모님이 요리하시던 것과 똑같이), 오븐에서의 예상 조리 시간은 337분이에요:

```lisp
(expected-time-in-oven) ;; => 337
```

## 2. 오븐에 남은 시간(분) 계산하기

라자냐가 오븐에 들어가 있던 실제 시간(분)을 매개변수로 받아서, 이전 단계에서 구한 오븐 예상 시간을 기준으로 라자냐가 오븐에 몇 분 더 있어야 하는지 반환하는 `remaining-minutes-in-oven` 함수를 정의해요.

```lisp
(remaining-minutes-in-oven 100) ;; => 237
```

## 3. 준비 시간(분) 계산하기

Lilly가 라자냐에 넣은 층 수를 매개변수로 받아서, 각 층을 준비하는 데 19분이 걸린다고 가정했을 때 Lilly가 라자냐를 준비하는 데 몇 분을 썼는지 반환하는 `preparation-time-in-minutes` 함수를 정의해요.

```lisp
(preparation-time-in-minutes 3) ;; => 57
```

## 4. 경과 시간(분) 계산하기

매개변수 두 개를 받는 `elapsed-time-in-minutes` 함수를 정의해요. 첫 번째 매개변수는 Lilly가 라자냐에 넣은 층 수이고, 두 번째 매개변수는 라자냐가 오븐에 들어가 있던 시간(분)이에요. 이 함수는 Lilly가 라자냐 요리에 쓴 시간(분)을 반환해야 하는데, 이는 준비 시간(분)과 현재까지 라자냐가 오븐에 있던 시간(분)을 더한 값이에요.

```lisp
(elapsed-time-in-minutes 3 100) ;; => 157
```
