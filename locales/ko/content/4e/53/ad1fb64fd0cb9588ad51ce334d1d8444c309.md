# 소개

이전 연습 문제에서는 Go에서 주석을 작성하는 두 가지 방법을 살펴봤어요. 바로 `//`가 앞에 붙는 한 줄 주석과 `/*`와 `*/`로 감싸는 여러 줄 주석 블록이에요.

## 문서 주석

Go에서 주석은 코드를 문서화하는 데 중요한 역할을 해요.
`godoc` 명령은 이런 주석을 추출해 Go 패키지에 대한 문서를 만들어요.
문서 주석은 설명하는 대상의 이름으로 시작해서 마침표로 끝나는 완전한 문장이어야 해요.

주석은 패키지 앞에 와야 하고, 익스포트된 식별자, 예를 들어 익스포트된 함수, 메서드, 패키지 변수, 상수, 구조체 앞에도 와야 해요. 이런 것들은 다음 연습 문제에서 더 자세히 배워요.

패키지 수준 변수는 이렇게 생겼어요.

```go
// TemperatureCelsius represents a certain temperature in degrees Celsius.
var TemperatureCelsius float64
```

## 패키지 주석

패키지 주석은 패키지 절(`package x`) 바로 앞에 써야 하고, 이렇게 `Package x ...`로 시작해야 해요.

```go
// Package kelvin provides tools to convert
// temperatures to and from Kelvin.
package kelvin
```

## 함수 주석

함수 주석은 함수 선언 바로 앞에 써야 해요.
함수 이름으로 시작하는 완전한 문장이어야 해요.
예를 들어 함수 `Calculate`의 문서 주석은 `Calculate  ...` 형태여야 해요.
또한 함수가 어떤 인자를 받고, 그 인자로 무엇을 하는지, 반환값이 무엇을 의미하는지 설명해야 하며, 마침표로 끝나야 해요):

```go
// CelsiusFreezingTemp returns an integer value equal to the temperature at which water freezes in degrees Celsius.
func CelsiusFreezingTemp() int {
	return 0
}
```
