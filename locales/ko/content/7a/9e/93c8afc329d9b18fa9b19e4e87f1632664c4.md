# 2진법, 8진법, 16진법

2진법, 8진법, 16진법(_hex라고도 불러요_)은 밑이 서로 다른 [수 체계][numeral-systems]예요.
2진법은 밑이 2이고, 8진법은 밑이 8, 16진법은 밑이 16이에요.
Crystal에서 일반적인 정수는 10진법이에요.
2진법, 8진법, 16진법은 모두 정수를 나타내는 표현 방식이에요.
즉, 분수나 소수 없이 양수와 음수(_0 포함_)를 나타낼 수 있고, 정수로 할 수 있는 모든 연산을 지원해요.

## 2진법

[2진법][binary]은 숫자 0과 1만 사용하는 밑이 2인 수 체계예요.
컴퓨터의 트랜지스터와 스위치를 흐르는 전류의 0("꺼짐")과 1("켜짐") 상태, 그리고 자기 저장 매체의 양전하와 음전하를 나타내는 데 흔히 쓰여요.
2진법은 10진법에서 사용하는 모든 정수를 나타낼 수 있어요.

2진법 체계의 일부를 보면 다음과 같아요. 물론 끝없이 이어지며 128에서 멈추지 않아요:

| 128      | 64       | 32       | 16       | 8        | 4        | 2        | 1        |
| -------- | -------- | -------- | -------- | -------- | -------- | -------- | -------- |
| 2 \*\* 7 | 2 \*\* 6 | 2 \*\* 5 | 2 \*\* 4 | 2 \*\* 3 | 2 \*\* 2 | 2 \*\* 1 | 2 \*\* 0 |

그래서 숫자 6을 나타내려면 2진법으로는 110이 돼요:

| 자릿값 | 4   | 2   | 1   |
| ------ | --- | --- | --- |
| 2진수  | 1   | 1   | 0   |

계산하면 `4 + 2 + 0 = 6`이에요

또 다른 예로, 19를 보면:

| 자릿값 | 16  | 8   | 4   | 2   | 1   |
| ------ | --- | --- | --- | --- | --- |
| 2진수  | 1   | 0   | 0   | 1   | 1   |

2진수는 10011이 돼요
계산하면 `16 + 0 + 0 + 2 + 1 = 19`예요

## Crystal에서의 2진법

Crystal에서는 `0b` 접두사를 사용해 2진수 리터럴을 나타낼 수 있어요.
`0b10011`이라고 쓰면 Crystal은 이를 2진수로 해석해 10진법으로 변환해요.

```crystal
0b10011
# => 19

typeof(0b10011)
# => Int32
```

2진법이 아닌 수에 `0b` 접두사를 붙이면 컴파일 오류가 발생해요.

```crystal
0b10211
# => Error: unexpected token: "211"
```

### 2진수 연산

2진수도 정수이므로, 정수로 할 수 있는 모든 연산을 2진수에도 할 수 있어요.

```crystal
0b10011 + 0b10011
# => 38

0b10011 * 0b10011
# => 361

0b10011 / 3
# => 6.333333333333333
```

### 2진수 표현으로 변환하기

Crystal은 2진수 리터럴을 자동으로 `Int32`로 변환해요.
`Int32`를 2진수 표현으로 변환하려면, base 인자를 2로 설정한 [`<int>.to_s(base)`][to_s] 메서드를 사용해요.
이 메서드는 2진수의 문자열 표현을 반환해요:

```crystal
19.to_s(2)
# => "10011"
```

2진수의 문자열 표현을 정수로 변환하려면, 밑(2)을 인자로 전달해 [`<int>.to_i(base)`][to_i] 메서드를 사용할 수 있어요:

```crystal
"10011".to_i(2)
# => 19
```

잘못된 밑(_또는 유효하지 않은 2진수 표현_)을 주면 `ArgumentError`가 발생해요:

```crystal
"011021".to_i(2)
# => Invalid Int32: "011021" (ArgumentError)
```

### 2진수 메서드

정수에서 2진수 표현에 대한 정보를 얻는 데 사용할 수 있는 메서드들이 있어요.

[`<int>.bit_length`][bit_length]는 수를 나타내는 데 필요한 비트 수를 반환해요:

```crystal
19.bit_length
# => 5
```

[`<int>.bit(index)`][bit]는 오른쪽(_최하위 비트_)부터 세어 주어진 인덱스의 비트를 반환해요:

```crystal
19.bit(0)
# => 1

0b10011.bit(1)
# => 1
```

## 8진법

[8진법][octal]은 밑이 8인 수 체계예요.
숫자 0, 1, 2, 3, 4, 5, 6, 7을 사용해요.

Crystal에서는 `0o` 접두사를 사용해 8진수를 나타낼 수 있어요.
2진법과 마찬가지로, Crystal은 8진수 표현을 자동으로 `Int32`로 변환해요.

```crystal
0o123
# => 83
```

8진법이 아닌 수에 `0o`를 붙이면 컴파일 오류가 발생해요.

### 8진수 표현으로 변환하기

2진법과 마찬가지로, [`<int>.to_s(base)`][to_s] 메서드를 사용해 `Int32`를 8진수 표현으로 변환할 수 있어요.
그리고 [`<int>.to_i(base)`][to_s] 메서드를 사용해 8진수 표현을 `Int32`로 변환할 수 있어요.

```crystal
83.to_s(8)
# => "123"

"123".to_i(8)
# => 83
```

2진법과 마찬가지로, 잘못된 밑을 주면 `ArgumentError`가 발생해요.

## 16진법

[16진법][hexadecimal]은 밑이 16인 수 체계예요.
숫자 0 - 9와 문자 A, B, C, D, E, F를 사용해요.
A는 10, B는 11, C는 12, D는 13, E는 14, F는 15예요.

Crystal에서는 `0x` 접두사를 사용해 16진수를 나타낼 수 있어요.
2진법, 8진법과 마찬가지로, Crystal은 16진수 리터럴을 자동으로 `Int32`로 변환해요.

```crystal
#=> 0x123
291
```

16진법이 아닌 수에 `0x`를 붙이면 컴파일 오류가 발생해요.

### 16진수 표현으로 변환하기

2진법과 마찬가지로, [`<int>.to_s(base)`][to_i] 메서드를 사용해 `Int32`를 16진수 표현으로 변환할 수 있어요.
그리고 [`<int>.to_i(base)`][to_s] 메서드를 사용해 16진수 표현을 `Int32`로 변환할 수 있어요.

```crystal
291.to_s(16)
# => "123"

"123".to_i(16)
# => 291
```

2진법, 8진법과 마찬가지로, 잘못된 밑을 주면 `ArgumentError`가 발생해요.

## 정밀도

수를 문자열 표현으로 변환할 때 숫자의 정밀도를 지정할 수 있어요.
정밀도란 수를 나타내는 데 사용하는 숫자의 **최소** 개수를 뜻해요.
수의 자릿수가 정밀도보다 적으면 문자열 표현 앞에 0이 추가돼요.
이는 `precision` 인자를 [`<int>.to_s(<base>, precision: <value>)`][to_s] 메서드에 전달해서 해요.

```crystal
291.to_s(16, precision: 5)
# => "00123"

543.to_s(precision: 2)
# => "543"
```

## 대문자 변환

수를 문자열 표현으로 변환할 때, 문자열의 문자를 대문자로 바꿀지 지정할 수 있어요.
이는 `upcase` 인자를 [`<int>.to_s(<base>, upcase: <value>)`][to_s] 메서드에 전달해서 해요.

```crystal
255.to_s(16, upcase: true)
# => "FF"

255.to_s(16, upcase: false)
# => "ff"
```
