# 지침

친구 Chandler는 세계 곳곳의 이국적인 나라들을 여행할 계획이에요. 안타깝게도 Chandler는 수학 실력이 좋지 않아요. 그는 여행 중에 환전소에서 바가지를 쓸까 봐 꽤 걱정하고 있어요. 그래서 여러분에게 환율 계산기를 만들어 달라고 해요. 다음은 그가 앱에 원하는 사양이에요.

## 1. 환전 후 가치 추정하기

매개변수 2개를 받는 `exchange_money()` 함수를 만들어요:

1. `budget` : 환전할 예정인 금액.
2. `exchange_rate` : 외화 1단위에 해당하는 자국 통화의 금액.

이 함수는 환전한 통화의 가치를 반환해야 해요.

**참고:** 사용하는 통화가 USD이고 환율 `1.20`으로 USD를 EUR로 환전하려면 `1.20 USD == 1 EUR`예요.

```python
>>> exchange_money(127.5, 1.2)
106.25
```

## 2. 환전 후 남은 금액 계산하기

매개변수 2개를 받는 `get_change()` 함수를 만들어요:

1. `budget` : 환전 전 금액.
2. `exchanging_value` : 환전을 위해 예산에서 *빠지는* 금액.

이 함수는 예산에서 *남는* 금액을 반환해야 해요.

```python
>>> get_change(127.5, 120)
7.5
```

## 3. 지폐의 가치 계산하기

매개변수 2개를 받는 `get_value_of_bills()` 함수를 만들어요:

1. `denomination` : 지폐 한 장의 가치.
2. `number_of_bills` : 지폐의 총 개수.

이 환전소는 정해진 단위의 현금만 취급해요.
받게 되는 총액은 "지폐" 한 장, 즉 1단위의 가치로 나누어떨어져야 하는데, 그러면 소수나 나머지가 남을 수 있어요.
이 함수는 환전소가 돌려주는 지폐의 총 가치(_소수 부분은 제외_)만 반환해야 해요.
안타깝게도 환전소는 그 나머지나 거스름돈을 덤으로 가져가요.

```python
>>> get_value_of_bills(5, 128)
640
```

## 4. 지폐 개수 계산하기

`amount`와 `denomination`을 받는 `get_number_of_bills()` 함수를 만들어요.

이 함수는 주어진 _금액_ 안에서 받을 수 있는 _지폐 개수_를 반환해야 해요.
다시 말해, 시작 금액 안에 _온전한 지폐_가 몇 장 들어가나요?
받을 수 있는 건 _온전한 지폐_뿐이고 지폐의 일부는 받을 수 없으니, 그에 맞게 나눠야 해요.
결국 가장 가까운 정수 지폐, 즉 지폐 단위로 _내림_하는 셈이에요.

```python
>>> get_number_of_bills(127.5, 5)
25
```

## 5. 지폐로 환전한 후 남은 금액 계산하기

`amount`와 `denomination`을 받는 `get_leftover_of_bills()` 함수를 만들어요.

이 함수는 지폐 단위가 정해졌을 때 시작 _금액_에서 돌려받을 수 없는 _남은 금액_을 반환해야 해요.
환전소가 정확히 얼마를 가져가는지 아는 것은 아주 중요해요.

```python
>>> get_leftover_of_bills(127.5, 20)
7.5
```

## 6. 환전 후 가치 계산하기

`budget`, `exchange_rate`, `spread`, `denomination`을 받는 `exchangeable_value()` 함수를 만들어요.

`spread` 매개변수는 환전 수수료로 *떼어 가는 비율*이며, 정수로 표기해요.
이 값은 100으로 나누어 소수로 변환해야 해요.
`1.00 EUR == 1.20 USD`이고 *spread*가 `10`이면 실제 환율은 `1.00 EUR == 1.32 USD`가 돼요. 1.20의 10%는 0.12이고, 이 추가 수수료가 환율에 더해지기 때문이에요.

이 함수는 *환율*에 *spread*를 더해 계산한 뒤, 새 통화의 최댓값을 반환해야 해요.
통화의 *지폐 단위*는 정수이고 더 나눌 수 없다는 점을 기억해요.

**참고:** 반환되는 값은 `int` 타입이어야 해요.

```python
>>> exchangeable_value(127.25, 1.20, 10, 20)
80
>>> exchangeable_value(127.25, 1.20, 10, 5)
95
```
