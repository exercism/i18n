# 힌트

## 일반

- 필요하다면 [객체 개념][concept-class-basics]을 다시 살펴보면서 기초를 되새겨 봐요.
- `x`, `y`, `width`, `height`의 매개변수 순서에 대한 설명을 주의 깊게 읽어봐요. 이들은 헷갈리기 쉬워요.

## 1. ProgramWindow 클래스 정의하기

- 이 과제에서는 [클래스 문법][php-class]을 사용해야 한다는 점을 기억해요.
- 클래스 선언에 [속성][php-properties]을 추가하여 정의해요.

## 2. ProgramWindow 클래스의 생성자 함수 정의하기

- 생성자 함수가 어떤 인자도 받지 않는지 확인해요.
- 각 속성이 예상한 정수 값으로 설정되는지 확인해요.

## 3. 창 크기를 조절하는 메서드 추가하기

- 이 과제에서는 `Size.php` 파일에 새로운 [클래스][php-class]를 사용해야 한다는 점을 기억해요.
  - 관례상 파일에는 보통 하나의 클래스만 포함해요.
- `Size` 생성자는 클래스 [속성][php-properties]의 초깃값에 대한 인자를 받아야 해요.
- `Size`의 인스턴스를 사용해 변경 사항을 적용하도록 `ProgramWindow` 객체의 `resize` 메서드를 만들어요.

## 4. 창을 이동하는 메서드 추가하기

- 이 과제에서는 `Position.php` 파일에 새로운 [클래스][php-class]를 사용해야 한다는 점을 기억해요.
  - 관례상 파일에는 보통 하나의 클래스만 포함해요.
- `Position` 생성자는 클래스 [속성][php-properties]의 초깃값에 대한 인자를 받아야 해요.
- `Position`의 인스턴스를 사용해 변경 사항을 적용하도록 `ProgramWindow` 객체의 `move` 메서드를 만들어요.
