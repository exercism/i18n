# 테스트

테스트 스위트를 실행하려면:
```bash
tclsh exercise.test
```

## 건너뛴 테스트

연습 문제를 푼다는 건 모든 테스트를 통과시키는 거예요. 기본적으로 테스트를 실행하면
첫 번째 테스트 하나만 실행돼요. 이건 의도된 동작이에요. 그 테스트 하나만
통과시키는 데 집중할 수 있거든요. 이 테스트가 통과하면, 그 앞에 있는 `skip` 명령을
주석으로 처리하거나 지워서 다음 테스트를 활성화할 수 있어요.

또는 건너뛴 상태와 상관없이 모든 테스트를 실행하려면:
```bash
RUN_ALL=1 tclsh exercise.test
```
