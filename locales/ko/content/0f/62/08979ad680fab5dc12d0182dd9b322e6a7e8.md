# 지침 추가

## 입력 형식

게임 보드를 나타내는 `board` 매개변수는 문자열 배열 형식이에요.

```javascript
['  B  ', ' B B ', 'B W B', ' W W ', '  W  '];
```

문자열의 각 문자는 하나의 셀을 나타내요.
셀에 들어갈 수 있는 값은 다음과 같아요:

- ` ` 빈 셀에 해당하는 공백 문자
- `B` 검은 플레이어가 소유한 셀
- `W` 흰 플레이어가 소유한 셀

## 출력 형식

`getTerritory` 함수는 두 개의 속성을 가진 객체를 반환해야 해요:

- `owner` 영역의 소유자 (`NONE`, `BLACK`, `WHITE` 중 하나)
- `territory` 영역에 있는 각 셀을 나타내는 좌표 배열이에요.

```javascript
{
    owner: 'BLACK',
    territory: [
        [0, 0],
        [0, 1],
        [1, 0],
    ],
}
```

`getTerritories` 함수는 세 개의 속성을 가진 객체를 반환해야 해요:

- `territoryBlack` `BLACK` 플레이어가 소유한 영역들을 나타내는 좌표 배열
- `territoryWhite` `WHITE` 플레이어가 소유한 영역들을 나타내는 좌표 배열
- `territoryNone` 두 플레이어 중 누구에게도 소유되지 않은 영역들을 나타내는 좌표 배열

```javascript
{
    territoryBlack: [
        [0, 0],
        [0, 1],
    ],
    territoryWhite: [
        [3, 0],
        [3, 1],
    ],
    territoryNone: [],
}
```
