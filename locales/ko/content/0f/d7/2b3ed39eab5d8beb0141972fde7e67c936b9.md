`+` 연산자로 문자열을 이어 붙이는 방법도 유효하지만, 유지보수와 가독성에 문제가 생길 수 있어요.
[str.format()][str.format()] 메서드나 [f-strings][f-strings](_다른 말로 "포맷 문자열 리터럴" 또는 "보간 문자열"이라고도 해요_)를 사용하면 유지보수성을 높이고 문자열 안에서 변수를 바꿔 넣는 부분을 더 명확하게 만들어 주는 방법을 쓸 수 있어요.

블로그 글 [String Formatting in Python][string formatting in python]은 Python의 모든 문자열 포매팅 방법을 이해하는 데 좋은 출발점이 되어 주고, [Newer Python String Format Techniques][newer python string format techniques]에도 `str.format()`과 `f-strings`을 사용할 때 참고할 만한 팁과 요령이 잘 정리되어 있어요.
