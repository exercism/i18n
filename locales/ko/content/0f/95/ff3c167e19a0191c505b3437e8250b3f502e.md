# 개요

예외는 오류 처리의 한 가지 방식이에요.
예상치 못한 일이 생겼을 때 주로 나타나기 때문에 예외라고 불러요.

코드 어디에서든 예외를 "raise"할 수 있어요.
이때 `raise` 메서드를 사용해서 객체를 전달하는데, 보통은 Exception 객체를 전달하지만 기본 문자열을 사용할 수도 있어요.
예를 들어, 연습 문제의 스텁에서 메서드가 아직 구현되지 않았다는 것을 Ruby에 알리기 위해 내장된 `RuntimeError`를 사용하는 것을 볼 수 있어요.
`raise(ExceptionObject, params)`처럼 축약된 문법을 사용할 수도 있어요.
예외 클래스를 생략하면 기본값으로 `RuntimeError`가 사용돼요.

예를 들어:

```ruby
# These are equivalent
raise RuntimeError.new("Please implement this method")
raise RuntimeError, "Please implement this method"
raise "Please implement this method"
```

Ruby가 이걸 만나면 오류를 프로그램의 최상위로 올려보낸 다음 종료해요.

예를 들어, 어떤 수를 0으로 나누려고 하면 다음과 같은 결과를 볼 수 있어요:

```ruby
5/0

#=> Traceback (most recent call last):
#=> ...
#=> ZeroDivisionError (divided by 0)
```

예외는 특별한 처리가 필요한, 정말 예외적인 상황에서 사용해야 한다는 점이 중요해요.
예외를 프로그램의 제어 흐름에 사용해서는 안 돼요. 그건 나쁜 설계로 여겨지고, 성능과 유지보수성을 떨어뜨리는 경우가 많아요.

## 클래스 계층 구조

Ruby에서 예외는 `Exception`이 기본 클래스인 클래스 계층 구조를 따라요.
다음은 Ruby에서 가장 흔하게 쓰이는 내장 예외예요:

```
Exception
  NoMemoryError
  ScriptError
    LoadError
    NotImplementedError
    SyntaxError
  SignalException
    Interrupt
  StandardError
    ArgumentError
    IOError
    EOFError
    IndexError
    LocalJumpError
    NameError
      NoMethodError
    RangeError
      FloatDomainError
    RegexpError
    RuntimeError
    SecurityError
    SystemCallError
    SystemStackError
    ThreadError
    TypeError
    ZeroDivisionError
  SystemExit
```

특정 클래스의 오류를 rescue하면 그 하위 클래스의 오류도 함께 rescue돼요.
그래서 `Exception`을 rescue하는 것이 위험할 수 있어요.
Ruby는 운영체제의 "시그널" 메시지를 처리할 때도 예외를 사용해요. 예를 들어 `ctrl-c` 같은 거요.
즉, `Exception`을 rescue하면 이 시스템 "시그널"까지 함께 잡힌다는 뜻이에요.
그래서 예상치 못한 동작을 막기 위해 "모든 오류"를 잡을 때는 `StandardError`를 rescue하는 것이 일반적인 관행이에요.

## rescue 문법
Ruby는 특별한 처리가 필요한 상황을 위해 확장된 rescue 절도 제공해요:

```ruby
begin
  # ...
rescue CustomError => error
  # This block is run if a CustomError occurs
rescue AnotherCustomError => error
  # This block is run if a AnotherCustomError occurs
else
  # This block is run if no exception occurred at all
ensure
  # This block always run, regardless of whether an exception occurred
end
```

예를 들어 항상 연결을 닫아야 하는 네트워크 IO를 다룰 때 유용해요.

Ruby의 rescue 블록에서는 `retry` 키워드를 사용할 수도 있는데, 이는 begin과 rescue 사이의 모든 것을 다시 실행해요:

```ruby
counter = 0
begin
  counter += 1
  api_request
rescue
  retry if counter <= 3
end
```
