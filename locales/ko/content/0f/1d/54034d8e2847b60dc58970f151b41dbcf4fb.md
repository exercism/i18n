# 문제 설명 추가

## `smallest`와 `largest` 구현에 관한 참고 사항

두 함수 모두 두 개의 키워드 인자를 받아야 해요:
- `max_factor`: int
- `min_factor`: int, default 0

반환 값은 `tuple -- (value, factors)`여야 하는데, 여기서 `value`는 회문 자체이고 `factors`는 회문을 이루는 두 수를 임의의 순서로 담은 `iterable`이에요.


## 예외 메시지

때로는 [예외를 발생시켜야 할](https://docs.python.org/3/tutorial/errors.html#raising-exceptions) 경우가 있어요. 예외를 발생시킬 때는 항상 오류의 원인이 무엇인지 알려 주는 **의미 있는 오류 메시지**를 함께 넣어야 해요. 그러면 코드를 더 읽기 쉽게 만들고 디버깅에 큰 도움이 돼요. 오류 원인이 어떤 유형이라고 확실한 상황이라면 [내장 오류 유형](https://docs.python.org/3/library/exceptions.html#base-classes) 중 하나를 골라 발생시켜도 되지만, 이때도 의미 있는 메시지를 함께 넣어야 해요.

이 연습 문제에서는 `largest()`나 `smallest()` 함수가 올바른 범위에 들지 않는 한 쌍의 수를 받았을 때 [raise 문](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)을 사용해 `ValueError`를 "던져야" 해요. `exception`을 `raise`하고 그와 함께 메시지를 넣어야만 테스트를 통과할 수 있어요.

메시지와 함께 `ValueError`를 발생시키려면, 메시지를 `exception` 타입의 인자로 써요:

```python
# if the max_factor is less than the min_factor
raise ValueError("min must be <= max")
```
