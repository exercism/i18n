# 설치

## 어떤 awk가 있나요?

Exercism AWK 트랙은 GNU의 AWK인 `gawk`를 사용해요.
이미 설치되어 있을 수도 있어요. 확인하려면 다음 명령을 실행해 봐요.
```sh
awk --version
```

결과가 다음과 같다면:

* `GNU Awk 5.1.0 ...`처럼 나온다면
    - GNU awk가 이미 있으니 바로 연습 문제를 진행해도 돼요.

* `awk version 20200816`처럼 나온다면
    - 이건 `nawk`이고, 브라이언 커니핸(Brian Kernighan)의 이름을 딴 BWK awk 또는 "one true awk"라고도 불려요.
    - MacOS와 BSD 시스템에 기본으로 포함되어 있는 버전이에요.
    - 설치 방법은 아래를 참고해요.

* `awk: not an option: --version` 오류가 나온다면
    - 아마 `mawk`일 거예요.
    - `awk -W version`으로 확인할 수 있는데, `mawk 1.3.4 20200120`처럼 나올 수도 있어요.
    - mawk는 아주 좋고 빠른 awk 구현이지만, 이 트랙에서 사용할 gawk만의 기능 중 일부는 없어요.
    - 설치 방법은 아래를 참고해요.

* `awk: unrecognized option: version` 오류가 나오고 그 뒤에 `BusyBox v1.35.0 ...`가 나온다면
    - Alpine Linux를 사용 중일 수 있어요.

* "command not found" 오류가 나온다면
    - PATH가 잘못되었거나 awk가 설치되어 있지 않은 거예요.
    - 설치 방법은 아래를 참고해요.

### Linux

배포판의 패키지 관리자에 따라 달라요. 보통은 다음과 같아요:
```sh
apt install gawk
yum install gawk
apk add gawk
# and so on
```
명령을 실행할 때 `sudo`가 필요할 수도 있어요.

### MacOS

[Homebrew][brew]를 사용하면 편해요. 링크를 따라 설치한 다음 실행해 봐요:
```sh
brew install gawk
```

### Windows

[WSL][wsl]이라면 위의 Linux 안내를 참고해요.
cygwin이라면 `gawk` 패키지를 설치해요.

### 소스에서 컴파일하기

직접 해볼 용기가 있다면, [`gawk` 매뉴얼에 안내가 있어요][build].
