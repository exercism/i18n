# 소개

`jq` 프로그램은 _표현식의 파이프라인_이라는 점을 기억해요.
**변수 할당**은 다음 규칙을 따라요. _변수 할당_은 다음과 같은 형태의 표현식이에요:

```jq
... | expr as $varname | ...
```

## 필터는 입력을 그대로 출력해요

_항등 표현식_ `.`처럼, _변수 할당_의 출력은 입력과 같아요.
변수의 값을 설정하는 것은 부수 효과예요.

다음 예제는 할당 이후의 `.`이 처음 입력과 같다는 것을 보여줘요:

```sh
$ jq -c -n '42 | (. * 2) as $double | [., $double]'
[42,84]
```

## 변수 스코프

변수의 스코프는 "렉시컬"이에요. 즉, 변수는 파이프라인의 나머지 부분에서도 스코프에 남아 있어요.
함수 안에서 정의된 변수는 (함수는 나중에 다뤄요) 그 함수의 지역 변수예요.

## 변수 이름

변수는 `$`로 시작해야 해요.
변수 이름의 나머지 부분은 **식별자**예요. 문자나 밑줄로 시작하고, 그 뒤에 문자, 숫자, 밑줄이 와요.

## 구조 분해 할당

매뉴얼에서는 이렇게 말해요:

> 하나의 `as` 표현식으로 여러 변수를 선언할 수 있는데, 이때 _입력의 구조와 일치하는_ 패턴을 주면 돼요 (이것을 "구조 분해"라고 해요).

예를 들어요:

```jq
[1, 2, 3] as [$a, $b, $c]
| [$a, $b, $c]     # => [1, 2, 3]
```

```jq
{"foo": "bar", "len": [10, 20]} as {foo: $f, len: [$h, $w]}
| [$f, $h, $w]     # => ["bar", 10, 20]
```

변수 이름을 _객체 키_와 일치시키면 더 간단하게 쓸 수 있어요:

```jq
{"x": 4, "y": 7} as {$x, $y}
| [$x, $y]         # => [4, 7]
```

```jq
{"foo": "bar", "len": [10, 20]} as {$foo, $len}
| [$foo, $len]     # => ["bar", [10, 20]]
```

## 상수

위 예제에서 봤듯이, 변수는 상수를 저장할 때 편리해요.
코드에 "매직 넘버"가 나타나는 것보다 상수에 이름을 붙이는 게 더 좋아요.

## 변수가 필요 없는 경우도 많아요

변수를 생략하면 오히려 더 읽기 쉬운 경우가 많아요.

숫자 목록의 평균을 계산하는 경우를 생각해봐요.

```jq
[2, 4, 8, 7]
| add as $sum
| length as $len
| $sum / $len
```

이렇게 쓰는 것과 비교해봐요.

```jq
[2, 4, 8, 7] | add / length
```

이것은 `jq`의 가장 강력한 특징 중 하나를 보여줘요. 필터의 입력은 _모든_ 하위 표현식에 전달돼요.

- 입력 배열 `[2,4,8,7]`이 `add`에 전달돼요 (`add`는 모든 요소에 `+` 연산자를 적용해서 숫자들을 더해요).
- _동시에_, `[2,4,8,7]`은 `length`에도 전달돼요.
- 이 하위 표현식들이 끝나면 그 결과를 나눠서, 입력 배열에 있는 숫자들의 평균값을 반환해요.
