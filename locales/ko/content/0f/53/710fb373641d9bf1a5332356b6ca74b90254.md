# 안내

좋아하는 요리책을 보고 라자냐를 만들 수 있도록 코드를 작성해 볼 거예요.

다섯 개의 작업이 있고, 모두 이 레시피를 만드는 과정과 관련되어 있어요.

## 1. 예상 굽는 시간을 분 단위로 정의하기

라자냐를 오븐에서 몇 분 동안 구워야 하는지 반환하는 `ExpectedBakeTime` 상수를 정의해요.
요리책에 따르면 라자냐는 오븐에 40분 동안 넣어 둬야 해요:

```powershell
> $ExpectedBakeTime
> 40
```

## 2. 남은 굽는 시간을 분 단위로 계산하기

라자냐가 오븐에 들어가 있던 실제 시간(분)을 인자로 받아서, `ExpectedBakeTime`을 기준으로 라자냐를 몇 분 더 구워야 하는지 반환하는 `RemainingTime` 함수를 구현해요.

```powershell
> RemainingTime -Minutes 30
> 10
```

## 3. 준비 시간을 분 단위로 계산하기

라자냐에 추가하려는 층의 개수를 인자로 받아서, 그 층을 만드는 데 몇 분이 걸리는지 반환하는 `PreparationTime` 함수를 구현해요.
각 층을 준비하는 데 2분이 걸린다고 가정해요.

```powershell
> PreparationTime -Layers 2
> 4
```

## 4. 지금까지 걸린 총 조리 시간(준비 + 굽기)을 분 단위로 계산하기

`Layers`(_라자냐에 추가한 층의 개수_)와 `Minutes`(_라자냐가 오븐에서 구워진 시간(분)_)라는 두 개의 매개변수를 가진 `ElapsedTime` 함수를 구현해요.
이 함수는 지금까지 요리한 총 시간(분), 즉 준비 시간과 라자냐가 오븐에서 이미 구워진 시간을 더한 값을 반환해야 해요.

```powershell
> ElapsedTime -Layers 3 -Minutes 20
> 26
```

## 5. 라자냐가 다 됐다는 알림 만들기

인자를 받지 않고, 라자냐를 먹을 준비가 됐다는 메시지를 반환하는 `Notification` 함수를 정의해요.

```powershell
> Notification
> "Lasagna's ready!"
```
