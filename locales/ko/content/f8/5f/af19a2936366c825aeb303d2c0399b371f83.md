# 지침

친구인 리메이는 맛있는 과일 주스를 파는 주스 바를 운영해요.
리메이 가게에 자주 가는 단골인 여러분은 친구를 조금 더 편하게 해 줄 수 있겠다는 생각이 들었어요.
그래서 코딩 실력을 살려 리메이의 일을 돕기로 했죠.

## 1. 주스 하나를 만드는 데 걸리는 시간 구하기

리메이는 손님이 메뉴에서 주문한 주스가 나오기까지 얼마나 기다려야 하는지 미리 알려 주는 걸 좋아해요.
주스를 섞는 데 걸리는 시간이 주스마다 달라서, 정확한 숫자를 기억하기는 어려워요.

| ID  | 음료                 | 시간 |
| --- | -------------------- | ---- |
| 1   | 퓨어 스트로베리 조이 | 1    |
| 2   | 에너자이저           | 3    |
| 3   | 그린 가든            | 3    |
| 4   | 트로피컬 아일랜드    | 4    |
| 5   | 모 아니면 도         | 5    |
| 6   | 필 굿                | 4    |
| 7   | 오늘의 특선          | 7    |
| 8   | 손님의 선택          | 10   |

주스의 ID를 32비트 숫자로 받아서, 그 주스를 만드는 데 걸리는 시간을 역시 32비트 숫자로 반환하는 함수 `time_to_make_juice`를 작성해요.

```c
time_to_make_juice(2);
// => 3
```

## 2. 주문된 모든 주스를 만드는 데 걸리는 시간 구하기

리메이는 주기적으로 재료를 채워 넣어야 해서, 지금 들어온 주문을 모두 준비하는 데 시간이 얼마나 걸릴지 미리 알아야 해요.

친구를 도와주기 위해, 주문한 주스 각각의 ID가 담긴 배열과 배열에 있는 주스의 개수를 받는 함수 `time_to_prepare`를 작성해요.
이 함수는 배열에 있는 모든 음료를 준비하는 데 걸리는 총 시간을 반환해야 해요.

각 ID와 배열에 있는 ID의 개수, 반환값은 모두 32비트 숫자라고 생각하면 돼요.
결과는 항상 32비트 숫자에 들어가요.

```c
time_to_prepare({2, 3, 8}, 3);
// => 16
```

## 3. 라임 웨지 재고 채우기

리메이가 만드는 음료 중 상당수에는 라임 웨지가 들어가요.
재료로 쓰이기도 하고, 장식으로 올라가기도 하죠.
그래서 아침에 근무를 시작할 때면, 하루 동안 쓸 라임 웨지가 담긴 통이 가득 차 있는지 확인해야 해요.

리메이가 잘라야 하는 라임 웨지의 개수, 손에 있는 통라임 재고를 나타내는 배열, 배열에 있는 라임의 개수를 받는 함수 `limes_to_cut`을 구현해요.

배열에서 각 라임은 크기를 나타내는 문자로 표현돼요.
라임의 크기에 따라 리메이가 얻을 수 있는 웨지의 개수가 달라요:

| 크기 | 웨지 |
| ---- | ---- |
| 'S'  | 6    |
| 'M'  | 8    |
| 'L'  | 10   |

~~~~exercism/note
문자는 8비트 숫자이고, 다른 8비트 숫자와 똑같이 사용할 수 있어요:

| 문자 | 값  |
| ---- | --- |
| 'S'  | 83  |
| 'M'  | 77  |
| 'L'  | 76  |

명령어에서도 값과 같으므로 그대로 사용할 수 있어요:

```x86asm
mov dl, 'S'
cmp cl, 'M'
```
~~~~

리메이는 배열에 나온 순서대로, 첫 번째 라임부터 차례로 잘라요.
필요한 웨지의 개수에 도달하거나 라임이 떨어질 때까지 계속 자르죠.

리메이는 라임을 몇 개나 잘라야 하는지 미리 알고 싶어 해요.

필요한 웨지의 개수와 배열에 있는 라임의 개수, 반환값은 모두 32비트 숫자라고 생각하면 돼요.
결과는 항상 32비트 숫자에 들어가요.

```c
limes_to_cut(25, {'S', 'S', 'L', 'M', 'S'}, 5);
// => 4
```

## 4. 근무 마무리하기

리메이는 항상 오후 3시까지 일해요.
그다음에는 직원인 드미트리가 이어받죠.
리메이의 근무가 끝날 때쯤이면 주문은 들어왔지만 아직 만들지 않은 음료가 남아 있는 경우가 많아요.
그러면 드미트리가 남은 주스를 만들어요.

인수인계를 수월하게 하려면, 다음을 받는 함수 `remaining_orders`를 구현해요:

- 리메이의 근무에 남은 시간(분).
- 주문은 들어왔지만 아직 만들지 않은 주스 각각의 ID가 담긴 배열.

이 함수는 리메이가 퇴근하기 전까지 만든 주문의 개수를 반환해야 해요.

근무에 남은 시간은 항상 0보다 커요.
만들어야 할 주스 배열은 절대 비어 있지 않고, 근무는 항상 배열의 끝에 도달하기 전에 끝나요.
또한 주문은 배열에 나온 순서대로 만들어져요.
리메이가 어떤 주스를 섞기 시작하면, 조금 더 일해야 하더라도 그 주스는 항상 끝까지 만들어요.

남은 시간(분)과 배열에 있는 각 ID, 반환값은 모두 32비트 숫자라고 생각하면 돼요.
결과는 항상 32비트 숫자에 들어가요.

```c
remaining_orders(5, {5, 5, 3});
// => 1
```
