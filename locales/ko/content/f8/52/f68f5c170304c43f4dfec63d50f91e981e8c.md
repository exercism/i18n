# 소개

JavaScript는 동적 언어로, 객체 지향, 명령형, 선언형(예: 함수형 프로그래밍) 스타일을 지원해요.

## 변수

JavaScript에서 이름에 값을 할당하는 방법은 크게 몇 가지가 있어요. 변수나 상수를 사용하는 거예요.
Exercism에서는 변수를 항상 [camelCase][wiki-camel-case]로 쓰고, 상수는 [SCREAMING_SNAKE_CASE][wiki-snake-case]로 써요.
따라야 할 공식 가이드는 없고, 회사나 조직마다 다양한 스타일 가이드를 사용해요.
_변수는 원하는 방식으로 자유롭게 작성해도 돼요_.
연습 문제에서 준비한 방식대로 작성하면, 웹 인터페이스와 대부분의 IDE에서 다르게 강조 표시된다는 장점이 있어요.

JavaScript에서 변수는 [`const`][mdn-const], [`let`][mdn-let], [`var`][mdn-var] 키워드로 정의할 수 있어요.

`let`이나 `var`를 사용하면 변수는 생명 주기 동안 여러 값을 참조할 수 있어요.
예를 들어 `myFirstVariable`은 할당 연산자 `=`를 사용해 여러 번 정의하고 다시 정의할 수 있어요:

```javascript
let myFirstVariable = 1;
myFirstVariable = 'Some string';
myFirstVariable = new SomeComplexClass();
```

`let`과 `var`와 달리, `const`로 정의한 변수는 한 번만 할당할 수 있어요.
JavaScript에서는 이 방법으로 상수를 정의해요.

```javascript
const MY_FIRST_CONSTANT = 10;

// Can not be re-assigned.
MY_FIRST_CONSTANT = 20;
// => TypeError: Assignment to constant variable.
```

## 함수 선언

JavaScript에서는 기능 단위를 _함수_로 캡슐화하고, 보통 함께 속한 함수들은 같은 파일에 모아 둬요.
이런 함수는 매개변수를 가지고(그래서 인자를 받을 수 있어요), `return` 키워드로 값을 _반환_할 수 있어요.
함수는 `()` 문법으로 호출해요.

```javascript
function add(num1, num2) {
  return num1 + num2;
}

add(1, 3);
// => 4
```

이 예제에서 함수 이름은 `add`예요.
이 함수는 `num1`과 `num2`, 두 개의 매개변수를 가져요.
그리고 값을 반환해요. 바로 `num1 + num2` 표현식의 결과예요.

그다음 함수 `add`는 두 개의 인자 `1`과 `3`을 사용해 _호출_돼요.
함수의 결과, 즉 반환된 값은 `4`예요.

```exercism/note
💡 JavaScript에서는 함수를 선언하는 방법이 _매우_ 다양해요.
이 중 몇 가지는 `function` 키워드를 사용하는 방식과 달라 보여요.
이 트랙에서는 그것들을 점진적으로 소개하려고 하지만, 이미 알고 있다면 어떤 방법을 써도 괜찮아요.
대부분의 경우 한쪽을 쓰는 게 더 낫거나 나쁘지 않아요.
```

## 다른 파일에 공개하기

`function`, 상수, 변수를 _다른 파일_에서 사용할 수 있게 하려면 `export` 키워드를 사용해 [내보내야][mdn-export] 해요.
그러면 다른 파일에서 `import` 키워드로 이것들을 [가져올][mdn-import] 수 있어요.
이것을 모듈 시스템이라고도 해요.

좋은 예로 모든 테스트가 동작하는 방식을 들 수 있어요.
각 연습 문제에는 최소한 하나의 파일이 있고, 예를 들어 `lasagna.js`에는 _구현_이 들어 있어요.
_구현_은 파일에서 `export`되어, 다른 파일에서 import할 수 있게 돼요.
또한 최소한 하나의 다른 파일, 예를 들어 `lasagna.spec.js`에는 _테스트_가 들어 있어요.
이 파일은 구현을 테스트하기 위해 공개된(즉 `export`된) 요소들을 `import`해요:

```javascript
// file.js
export const MY_VALUE = 10;

export function add(num1, num2) {
  return num1 + num2;
}

// file.spec.js
import { MY_VALUE, add } from './file';

add(MY_VALUE, 5);
// => 15
```
