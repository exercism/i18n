# 소개

이제 C++의 핵심 패러다임 중 하나인 객체 지향 프로그래밍(OOP)을 살펴볼 차례예요.
OOP는 `classes`, 즉 관련된 함수들을 자기 것으로 가진 사용자 정의 데이터 타입을 중심으로 해요.
먼저 기초부터 시작하고, 커리큘럼 트리에서 더 아래쪽에 있는 고급 주제들은 나중에 다뤄요.

## 멤버

`classes`에는 **멤버 변수**와 **멤버 함수**가 있을 수 있어요.
이들은 **멤버 선택** 연산자 `.`로 접근해요.
`classes` 밖의 변수와 마찬가지로, 멤버 변수도 선언할 때 값을 넣어 초기화하는 게 좋아요.
이 값은 이 클래스로 새로 만들어지는 객체의 기본값이 돼요.

## 캡슐화와 정보 은닉

클래스는 멤버에 대한 접근을 제한할 수 있어요.
가장 기본적인 두 가지는 `private`와 `public`이에요.
`private` 멤버는 클래스 밖에서 접근할 수 없어요.
`public` 멤버는 자유롭게 호출할 수 있어요.
모든 멤버는 기본적으로 `private`이고, 클래스 밖에서 쓰려면 명시적으로 표시해야 해요.

## 기본 예제

새 `class`를 정의하는 모습은 다음 예제에서 볼 수 있어요.
정의 끝에 있는 `;`를 눈여겨봐요.

```cpp
class Wizard {
  public:               // from here on all members are accessible publicly
    int cast_spell() {  // defines the public member function cast_spell
      return damage;
    }
    std::string name{}; // defines the public member variable `name`
  private:              // from here on all members are private
    int damage{5};      // defines the private member variable `damage`
};

```

클래스 안에서는 모든 변수에 접근할 수 있어요.
`cast_spell` 함수 안의 `damage`를 봐요.
클래스 밖에서는 `private` 멤버를 읽거나 바꿀 수 없어요:

```cpp
Wizard silverhand{};
// calling the `cast_spell` function is okay, it is public:
silverhand.cast_spell();
// => 5

// name is public and can be changed:
silverhand.name = "Laeral";

// damage is private:
silverhand.damage = 500;
 // => Compilation error
```

## 생성자

생성자를 쓰면 객체를 만들 때 멤버 변수에 값을 넣을 수 있어요.
생성자는 `class`와 이름이 같고 반환 타입이 없어요.
클래스는 생성자를 여러 개 가질 수 있어요.
모든 변수를 항상 설정할 필요가 없을 때 유용해요.

```cpp
class Wizard {
  public:
    Wizard(std::string new_name) {
      name = new_name;
    }
    Wizard(std::string new_name, int new_damage) {
      name = new_name;
      damage = new_damage;
    }
    int cast_spell() {
      return damage;
    }
    std::string name{};
  private:
    int damage{5};
};

Wizard el{"Eleven"};       // deals  5 damage
Wizard vecna{"Vecna", 50}; // deals 50 damage
```

생성자는 다룰 내용이 많고 미묘한 부분도 많아요.
`class`에 `constructor`를 직접 정의하지 않으면, 그럴 때만 컴파일러가 대신 만들어 줘요.
앞의 첫 번째 예제에서 그렇게 됐어요.
_silverhand_ 객체는 기본 생성자를 호출해서 만들어졌고, 인자는 전달되지 않았어요.
모든 변수는 클래스 정의에 적어 둔 값으로 설정돼요.
그 정의에서 값을 주지 않았다면 변수가 초기화되지 않을 수 있고, 그러면 의도하지 않은 결과가 생길 수 있어요.

## 구조체

구조체는 이 언어의 뿌리인 C에서 왔고, C++ 자체만큼이나 오래됐어요.
구조체는 `classes`와 사실상 같은데, 중요한 예외가 하나 있어요.
`class`에서는 모든 것이 기본적으로 `private`이에요.
반면 구조체는 따로 지정하기 전까지 `public`이에요.
관례적으로 `struct` 키워드는 **데이터만 담는 구조체**에 자주 쓰여요.
특정 성질을 보장해야 하는 객체에는 `class` 키워드가 선호돼요.
이런 불변식의 예로, `Wizard` `class`의 `damage`가 음수가 되지 않아야 한다는 것이 있을 수 있어요.
`damage` 변수는 private이고, damage를 바꾸는 함수는 모두 이 불변식이 지켜지도록 해요.
