# 개요

## 함수

Gleam에서 함수는 `pub fn` 문법으로 정의해요.

```gleam
pub fn add(x: Int, y: Int) -> Int {
  x + y
}
```

이 함수는 둘 다 `Int` 타입인 인자 두 개를 받고, `Int` 타입의 값을 반환해요. Gleam에는 `return` 키워드가 없어요. 함수에서 마지막 표현식의 값은 항상 _암묵적으로 반환돼요_.

인자의 타입 애너테이션과 반환 타입은 선택 사항이고, Gleam은 항상 코드의 타입을 완전히 검사해요. 보통 Gleam 프로그래머들은 명확성을 위해 함수에 타입 애너테이션을 붙이지만, 원한다면 생략해도 돼요.

```gleam
pub fn add(x, y) {
  x + y
}
```

함수는 `function_name(argument1, argument2)` 문법으로 호출할 수 있어요.

```gleam
pub fn double(x: Int) -> Int {
  // Call the add function defined above
  add(x, x)
}
```

## 변수

Gleam에서 변수는 `let name = expression` 문법으로 정의해요.

```gleam
pub fn main() {
  let count = 1
}
```

변수는 타입 애너테이션과 함께 선언할 수도 있어요. 함수 인자와 마찬가지로 이는 선택 사항이지만, 대부분의 Gleam 프로그래머들은 변수의 타입 애너테이션은 생략해요.

```gleam
pub fn main() {
  let count: Int = 1
}
```

## 문자열 리터럴

Gleam에서 문자열은 큰따옴표로 작성해요.

```gleam
pub fn greeting() {
  "Hello, world!"
}
```

## 코드 주석

주석은 소스 코드를 읽는 다른 개발자에게 메모를 남길 때 사용할 수 있어요. Gleam의 주석은 `//`로 시작하는 한 줄이에요.

```gleam
pub fn main() {
  // This is a comment
  let x = 1
}
```
