# 소개

## 클래스

클래스는 PHP에서 코드를 구성하는 단위예요.
어떤 대상의 동작이나 어떤 과정의 동작을 나타내는 코드는 하나의 클래스로 묶을 수 있어요.
클래스에 할당된 함수는 관례적으로 `methods`라고 불러요.

```php
<?php

class Door
{
    function lock()
    {
        // ...
    }

    function unlock()
    {
        // ...
    }
}
```

클래스는 `new` 키워드로 인스턴스화하는데, 이때 클래스 인스턴스를 위한 메모리가 할당되고 클래스의 생성자 메서드가 호출돼요.
인스턴스화된 클래스는 변수에 할당할 수 있어요.
클래스 인스턴스의 메서드를 호출하려면 `->` 접근 연산자를 사용할 수 있어요.

```php
<?php

$a_door = new Door();
$a_door->lock();
$a_door->unlock();
```

인스턴스화된 클래스는 특별한 `$this` 변수를 사용해 자기 자신의 인스턴스를 참조할 수 있어요.
클래스는 속성을 가질 수도 있는데, 이 속성은 클래스 객체의 인스턴스에 묶인 변수 역할을 해요.
이 속성은 내부에서도 외부에서도 참조할 수 있어요.

```php
<?php

class Car
{
    public $color;

    function __construct($color)
    {
        $this->color = $color;
    }

    function getColor()
    {
        return $this->color;
    }
}

$a_car = new Car("red");
$a_car->color; // => "red" by accessing the property
$a_car->getColor(); // => "red" by invoking the instance method
```
