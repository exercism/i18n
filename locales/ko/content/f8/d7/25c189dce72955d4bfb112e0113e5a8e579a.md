# 거듭제곱

`pow`나 `sqrt`, `**`를 사용하는 것은 전혀 문제없고, 많은 상황에서 필요할 수도 있어요.
그런데 직교 좌표계에서 거리를 구할 때는 변의 길이가 x와 y인 직각삼각형의 빗변을 반환하는 [`hypot` 메서드][hypot]를 사용할 수 있어요.

```crystal
# Rather than:
Math.sqrt(number ** 2 + another_number ** 2)

# Consider:
Math.hypot(number, another_number)
```

[hypot]: https://crystal-lang.org/api/Math.html#hypot%28value1%2Cvalue2%29-instance-method
