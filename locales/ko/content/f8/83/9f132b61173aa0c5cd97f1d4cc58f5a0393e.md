# 소개

## 레이블 인자

함수가 인자를 많이 받다 보면, 인자를 어떤 순서로 넘겨야 하는지 기억하기 어려울 때가 있어요. 그래서 Gleam에서는 가독성을 높이기 위해 인자에 이름을 붙일 수 있게 해줘요.

인자에 레이블을 붙이려면 인자 이름 앞에 레이블 이름을 쓰고, 둘 사이를 공백으로 구분해요.

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

레이블 인자가 있는 함수를 호출할 때에는 인자를 어떤 순서로 넘겨도 돼요. 다음 `replace` 호출은 모두 같은 의미예요:

```gleam
replace(in: "🍔🍔🍔", each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

레이블은 언제나 선택 사항이에요. 함수에 레이블 인자가 있더라도 레이블 없이 호출할 수 있어요.

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```
