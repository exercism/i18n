# 개요

C#에는 세 가지 부동소수점 타입이 있어요: `double`, `float`, `decimal`이에요. 가장 많이 쓰이는 타입은 `double`이고, `decimal`은 보통 금액 데이터를 다룰 때 사용해요. `double`은 `2.45` 또는 `2.45d`로 쓰고, `float`은 `2.45f`, `decimal`은 `2.45m`으로 써요.

부동소수점 타입마다 [정밀도, 대략적인 범위와 크기][docs-microsoft.com-characteristics-of-the-floating-point-types]가 달라요.

부동소수점 타입 사이의 변환 중에는 [자동(암시적)][docs-microsoft.com-implicit-numeric-conversion]으로 되는 것도 있고, [수동(명시적)][docs-microsoft.com-explicit-numeric-conversion]으로 해야 하는 것도 있어요.

```csharp
decimal account = 125m * (decimal)1.2f;
```

부동소수점 타입의 값을 같은지 비교할 때는 항상 주의해야 해요. 같은 값을 나타내는 것처럼 보여도 실제로는 다른 값일 수 있거든요. 더 자세한 내용은 [이 글][docs.microsoft.com_precision-in-comparisons]을 참고해요.

부동소수점 수에 대한 짧은 소개는 [0.30000000000000004.com][0.30000000000000004.com]에서 볼 수 있어요. [Float Toy 페이지][evanw.github.io-float-toy]에는 부동소수점 수의 비트가 실제 부동소수점 값으로 변환되는 과정이 그림과 함께 친절하게 설명되어 있어요.
