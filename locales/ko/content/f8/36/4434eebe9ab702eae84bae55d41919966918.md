# 지침

예비 마술사 Elyse는 기본기를 좀 연습할 필요가 있어요. 그녀에게는 다루고 싶은 카드 한 벌이 있어요.

조금 더 쉽게 하기 위해 그녀는 1부터 10까지의 카드만 사용해서, 카드 한 벌을 숫자 벡터로 나타낼 수 있어요. 특정 카드의 위치는 벡터의 인덱스에 대응해요.

## 1. 스택에서 카드 가져오기

카드를 고르려면, 주어진 스택에서 인덱스 `position`에 있는 카드를 반환해요.

```R
stack <- c(1, 2, 4, 1)
position <- 3
get_item(stack, position)
# => 4
```

## 2. 스택의 카드 교환하기

손재주를 좀 부려서 인덱스 `position`에 있는 카드를 주어진 대체 카드와 교환해요. 조정된 스택을 반환해요.

```R
stack <- c(1, 2, 4, 1)
position <- 3
replacement_card <- 6
set_item(stack, position, replacement_card)
# => c(1, 2, 6, 1)
```

## 3. 스택 맨 위에 카드 삽입하기

스택 맨 위에 새 카드를 삽입해서 카드 하나가 나타나게 해요. 조정된 스택을 반환해요.

```R
stack <- c(5, 9, 7, 1)
new_card <- 8
insert_item_at_top(stack, new_card)
# => c(5, 9, 7, 1, 8)
```

## 4. 스택에서 카드 제거하기

주어진 `position`에 있는 카드를 스택에서 제거해서 카드 하나를 사라지게 해요. 조정된 스택을 반환해요.

```R
stack <- c(3, 2, 6, 4, 8)
position <- 3
remove_item(stack, position)
# => c(3, 2, 4, 8)
```

## 5. 스택의 크기 확인하기

스택의 크기가 `stack_size`와 같은지 확인해요.

```R
stack <- c(3, 2, 6, 4, 8)
stack_size <- 4
check_size_of_stack(stack, stack_size)
# => FALSE
```

## 6. 스택 맨 위의 카드 제거하기

스택 맨 위에 있는 카드를 제거해서 카드 하나를 사라지게 해요. 조정된 스택을 반환해요.

```R
stack <- c(3, 2, 6, 4, 8)
remove_item_from_top(stack)
# => c(3, 2, 6, 4)
```

## 7. 스택 맨 아래에 카드 삽입하기

스택 맨 아래에 새 카드를 삽입해서 카드 하나가 나타나게 해요. 조정된 스택을 반환해요.

```R
stack <- c(5, 9, 7, 1)
new_card <- 8
insert_item_at_bottom(stack, new_card)
# => c(8, 5, 9, 7, 1)
```

## 8. 스택 맨 아래에서 카드 제거하기

스택 맨 아래에 있는 카드를 제거해서 카드 하나를 사라지게 해요. 조정된 스택을 반환해요.

```R
stack <- c(8, 5, 9, 7, 1)
remove_item_at_bottom(stack)
# => c(5, 9, 7, 1)
```
