# 소개

정규 표현식은 문자열을 _패턴 매칭_하는 매우 다재다능한 방법으로, 그 목적을 위해 설계된 도메인 특화 언어(DSL)를 사용해요.

Julia는 다른 여러 프로그래밍 언어처럼 자체 정규식 라이브러리를 구현하려고 하지 않아요. 대신 널리 쓰이는 [PCRE2][PCRE] 라이브러리를 감싸서, (예를 들어) Gleam과 동일하고 JavaScript와 매우 유사한 정규식 문법을 제공해요.

~~~~exercism/note
이 Julia 실라버스는 이미 기본적인 정규식 문법에 익숙하다고 가정해요.
Julia에 특화된 기능에만 집중할게요.

정규 표현식 지식을 되새길 수 있는 자료 몇 가지를 아래에 정리했어요.
~~~~

- [Regex101][regex101]
- [RegExr][regexr]
- [RexEgg][rexegg]
- [RegexOne][regexone]
- [Regular Expressions Info][regex-info]

Julia의 정규 표현식 인터페이스는 [매뉴얼][regex]에 설명되어 있어요.

Julia에서 정규 표현식은 여는 `"` 앞에 `r`을 붙인 문자열에 불과해요.
기본 기능은 모두 표준 라이브러리에 포함되어 있어요.

사실 [`Strings`][strings] 개념에서 이미 다룬 많은 함수가 `occursin()`처럼 기본적으로 정규식 검색을 위해 설계되었어요.

```julia-repl
julia> re = r"test$"
r"test$"

julia> typeof(re)
Regex

# Does a string end with "test"?
julia> occursin(re, "this is a test")
true

julia> occursin(re, "these are tests")
false
```

수정자 문자는 닫는 따옴표 뒤에 올 수 있는데, 예를 들어 `i`는 대소문자를 구분하지 않는 매칭을 의미해요.

```julia-repl
julia> occursin(r"test", "Testing")
false

julia> occursin(r"test"i, "Testing")
true
```

## 캡처

흔히 우리는 _무엇이_ 매칭되는지 알고 싶어요. 이는 정규식 안의 괄호에 캡처 그룹을 넣고 [`match()`][match] 함수를 사용하면 돼요.

```julia-repl
julia> m = match(r"(\d+g) .* (\d+ml)", "dissolve 25g sugar in 200ml water")
RegexMatch("25g sugar in 200ml", 1="25g", 2="200ml")

julia> m.captures
2-element Vector{Union{Nothing, SubString{String}}}:
 "25g"
 "200ml"

# how many matches?
julia> length(m.captures)
2

# what matched?
julia> m[1], m[2]
("25g", "200ml")

# Starting positions of the matches (character index)
julia> m.offsets
2-element Vector{Int64}:
 10
 23
```

물론 매칭이 실패할 수도 있어요.
그러면 결과는 `RegexMatch` 대신 특수 값 `Nothing`이 되니, 이에 대비해야 해요.

```julia-repl
# failed match
m = match(r"(not here)", "dissolve 25g sugar in 200ml water")

julia> typeof(m)
Nothing

julia> isnothing(m)
true
```

`match`는 기본적으로 문자열의 시작에서 매칭을 시작하지만, 앞의 `n`개 문자를 무시하도록 오프셋 `n`을 지정할 수도 있어요.

```julia-repl
# capture first match
julia> m = match(r"(\wat)", "cat, sat, mat")
RegexMatch("cat", 1="cat")

# ignore first 5 characters, then match
julia> m = match(r"(\wat)", "cat, sat, mat", 5)
RegexMatch("sat", 1="sat")
```

Julia에서 `match()`는 대상 문자열 내에서 _첫 번째_ 매칭만 찾아요. 다른 언어들처럼 전역 수정자는 없어요.

대신 매칭의 반복자를 반환하는 [`eachmatch()`][eachmatch]가 있어요.
이는 지연 평가되므로, 원하는 형식으로 변환해야 할 수도 있어요.

```julia-repl
julia> matches = eachmatch(r"(\wat)", "cat, sat, mat")
Base.RegexMatchIterator{String}(r"(\wat)", "cat, sat, mat", false)

# convert to vector
julia> collect(matches)
3-element Vector{RegexMatch}:
 RegexMatch("cat", 1="cat")
 RegexMatch("sat", 1="sat")
 RegexMatch("mat", 1="mat")

# convert with comprehension
julia> [m.match for m in matches]
3-element Vector{SubString{String}}:
 "cat"
 "sat"
 "mat"

# broadcast an anonymous function
julia> (m -> m.match).(matches)
3-element Vector{SubString{String}}:
 "cat"
 "sat"
 "mat"
```

## 치환

정규식을 사용하는 흔한 이유 중 하나는 매칭된 부분을 다른 문자열로 바꾸는 것이에요.

[`replace()`][replace] 함수는 [`Strings`][strings] 개념에서 문자열 리터럴로 검색하는 방식으로 다뤘어요.
같은 함수로 정규식 매칭의 모든 기능을 활용할 수 있어요.

```julia-repl
julia> replace("some string", r"[aeiou]" => "*")
"s*m* str*ng"

julia> replace("first second", r"(\w+) (?<agroup>\w+)" => s"\g<agroup> \1")
"second first"
```

위의 두 번째 예시는 `s" "` 문자열 안에서 번호가 붙은 캡처 그룹과 이름이 붙은 캡처 그룹을 모두 치환에 사용하는 방법을 보여줘요.

더 자세한 내용은 [매뉴얼][regex]을 참고해요. 이 주제는 대부분의 프로그래머를 끊임없이 문서로 되돌아가게 만드는 주제예요!
