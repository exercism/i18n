# Luhn의 개념

Luhn은 문자와 숫자에 대한 검증을 결합한 유효성 검사 알고리즘이에요. Rust 풀이는 함수형 접근을 선호해요.

## 일반

### 기본 타입

- `&str`과 `char`
  - 주어진 입력의 일부를 올바르게 제외하거나 포함하려면 개별 `char`가 `&str`과 어떻게 다른지 파악해야 해요.
- 정수
  - 필요한 숫자 검증을 하려면 정수를 이해하는 게 중요해요.
- 불리언
  - 동일성 검증과 최종 비교에 꼭 필요해요.

### 이터레이터 기능

- 체이닝
  - 문제를 순서대로 풀려면 여기서는 이터레이터 체이닝을 이해하는 게 중요해요.
- `map`, `filter`, 경우에 따라 turbofish, `fold`
  - `map`과 `filter`를 조합하면 이와 같은 검증 문제를 푸는 기본적인 설계 패턴이 돼요. `fold`를 사용한 풀이는 더 간결하다는 장점도 있어요.
  - 어떤 풀이에서는 체이닝된 표현식에서 만들어지는 타입이 무엇인지 Rust에 알려주기 위해 turbofish가 필요해요.

## 예시 풀이 1

york의 [풀이](https://exercism.org/tracks/rust/exercises/luhn/solutions/7038c269a4af4f5b95ca35a99c5c3b4d)

```rust
pub fn is_valid(code: &str) -> bool {
    code.chars()
        .filter(|c| !c.is_ascii_whitespace())
        .rev()
        .try_fold((0, 0), |(num_count, sum), c| {
            c.to_digit(10).map(|x| {
                let double = x * (num_count % 2 + 1);
                let double = if double > 9 { double - 9 } else { double };
                (num_count + 1, sum + double)
            })
        })
        .map_or(false, |(num_count, sum)| num_count >= 2 && sum % 10 == 0)
}
```

## 예시 풀이 2

표준

```rust
pub fn is_valid(candidate: &str) -> bool {
    if candidate.chars().filter(|c| c.is_ascii_digit()).take(2).count() <= 1
        || candidate.chars().any(|c| !c.is_ascii_digit() && c != ' ')
    {
        return false;
    }

    candidate
        .chars()
        .filter_map(|c| c.to_digit(10))
        .rev()
        .enumerate()
        .map(|(index, digit)| if index % 2 == 0 { digit } else { digit * 2 })
        .map(|digit| if digit > 9 { digit - 9 } else { digit })
        .sum::<u32>()
        % 10
        == 0
}
```
