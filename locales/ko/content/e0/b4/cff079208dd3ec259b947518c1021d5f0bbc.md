# 소개

Java에서 `null` 리터럴은 값이 없음을 나타내는 데 사용해요.

Java의 기본 타입은 모두 기본값을 가지므로 절대 `null`이 될 수 없어요. 관례상 `int`처럼 소문자로 시작해요.

참조 타입은 객체의 메모리 주소를 담고 있으며 `null` 값을 가질 수 있어요. 보통 `String`처럼 대문자로 시작해요.

기본 타입 변수에 `null`을 할당하려 하면 컴파일 오류가 발생해요. 변수는 언제나 할당된 타입의 값을 담고 있기 때문이에요.

```java
//Throws compile time error stating the required type is int, but null was provided
int number = null;
```

참조 변수에 `null`을 할당하면 컴파일 오류가 발생하지 않아요. 참조 변수는 `null`을 허용하기 때문이에요.

```java
//No error will occur as the String variable str is nullable
String str = null;
```
