# 소개

`Bool` 타입은 언어의 기본 구성 요소 중 하나예요.
어떤 것이 참인지 거짓인지를 각각 `True`와 `False` 값으로 나타내요.

불리언은 `&&` "AND" 연산자와 `||` "OR" 연산자로 결합할 수 있고, `not` 함수로 부정할 수 있어요.

불리언은 특정 조건을 만족할 때만 실행되는 분기를 코드에 만들 때도 아주 유용해요.
Elm에서는 `if-then-else` 표현식으로 분기를 만들어요. 다음과 같이요.

```elm
if someCondition || (someOtherCondition && anotherCondition) then
    doSomething
else
    doSomethingElse
```
