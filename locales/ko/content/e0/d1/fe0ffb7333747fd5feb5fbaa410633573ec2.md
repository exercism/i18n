# 힌트

## 일반

- Python 문서의 [제어 흐름 도구][control flow tools]와 Real Python의 [조건문][real python conditionals] 튜토리얼은 시작하기에 좋은 자료예요.
- Python 문서의 [불리언 연산][boolean operations]과 Real Python의 [불리언][python booleans] 튜토리얼은 `bools`를 복습하기에 좋아요.
- Python 문서의 [비교][comparisons]와 [비교 예제][python comparisons examples]는 비교 연산을 복습하기에 좋아요.

## 1. 임계 상태 확인

- 비교 연산자([비교][comparisons review])와 불리언 연산([concept:python/bools]())은 조건문과 함께 조합해서 사용할 수 있어요.
- 조건식은 `True` 또는 `False`로 평가되어야 해요.
- `else`는 모든 조건 검사가 `False`를 반환할 때 실행되는 코드 블록에 사용할 수 있어요.

  ```python
     >>> item = 'blue'
     >>> item_2 = 'green'
     
     >>>  if len(item) >= 3 and len(item_2) < 5:
            print('Both pass the test!')
          elif len(item) >= 3 or len(item_2) < 5:
            print('One passes the test!')
          else:
            print('None pass the test!')
    ...
    One passes the test!
  ```

## 2. 전력 출력 범위 결정

- 비교 연산자는 조건문과 함께 조합해서 사용할 수 있어요.
- `elif`문은 몇 개든 의사 결정 "분기"로 사용할 수 있어요.
- 각 "분기"는 별도의 `return`을 가질 수 있지만, 린팅 도구는 이것을 "좋지 않은 방식"으로 볼 수도 있어요.
- 린터가 불평한다면, 분기의 출력을 공통 변수에 할당한 다음 그 변수를 `return`하는 것을 고려해 봐요.

## 3. 페일 세이프 메커니즘

- 비교 연산자는 조건문과 함께 조합해서 사용할 수 있어요.
- `elif`문은 몇 개든 의사 결정 "분기"로 사용할 수 있어요.
- 각 "분기"는 별도의 `return`을 가질 수 있지만, 린팅 도구는 이것을 "좋지 않은 방식"으로 볼 수도 있어요.
- 린터가 불평한다면, 분기의 출력을 공통 변수에 할당한 다음 그 변수를 `return`하는 것을 고려해 봐요.
