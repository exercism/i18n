# 지침

이 연습 문제에서는 인터넷 포럼에서 사용자 계정의 권한을 확인해요. 이 포럼은 세 가지 권한을 지원해요:

- Read
- Write
- Delete

계정에는 세 가지 유형이 있고, 유형마다 기본 권한이 달라요:

- Guests: 게시물을 읽을 수 있어요.
- Users: 게시물을 읽고 쓸 수 있어요.
- Moderators: 게시물을 읽고 쓰고 삭제할 수 있으며, 모든 권한을 가지고 있어요.

때로는 개별 권한을 수정할 수 있어요. 예를 들어 게스트 계정에 게시물을 쓸 수 있는 권한을 주거나, 계정에서 모든 권한을 취소하면 어떤 권한도 없는 상태가 돼요.

## 1. 계정 유형의 기본 권한 구하기

먼저 세 가지 계정 유형인 `Guest`, `User`, `Moderator`를 나타내는 `AccountType` 열거형을 정의해요.

다음으로 `Permission` 열거형을 정의해요. 이는 `Read`, `Write`, `Delete` 세 가지 권한 유형과 두 가지 추가 유형을 나타내요. `All`은 모든 권한을 가진 경우를, `None`은 권한이 하나도 없는 경우를 나타내요.

그런 다음 특정 계정 유형의 기본 권한을 반환하는 (_정적_) `Permissions.Default()` 메서드를 구현해요:

```csharp
Permissions.Default(AccountType.Guest)
// => Permission.Read
```

## 2. 권한 부여하기

권한을 부여(추가)하는 (_정적_) `Permissions.Grant()` 메서드를 구현해요:

```csharp
Permissions.Grant(current: Permission.None, grant: Permission.Read)
// => Permission.Read
```

## 3. 권한 취소하기

권한을 취소(제거)하는 (_정적_) `Permissions.Revoke()` 메서드를 구현해요:

```csharp
Permissions.Revoke(current: Permission.Read, revoke: Permission.Read)
// => Permission.None
```

## 4. 권한 확인하기

현재 계정의 권한을 받아서 해당 계정이 주어진 권한에 대해 권한이 있는지 확인하는 (_정적_) `Permissions.Check()` 메서드를 구현해요:

```csharp
Permissions.Check(current: Permission.Write, check: Permission.Read)
// => false
```
