# 예제

```riscvasm
.equ FRAME_SIZE, 16

.text
.global is_triple
```

점으로 시작하는 줄은 _지시어_예요. 프로세서를 위한 것이 아니라 어셈블러를 위한 명령이죠.
`.equ`는 숫자 16에 `FRAME_SIZE`라는 이름을 붙여요.
`.text`는 뒤에 오는 내용이 코드라고 알려줘요.
`.global`은 `is_triple` 레이블을 이 파일 밖에서도 볼 수 있게 해서, 다른 코드가 이 함수를 호출할 수 있게 해줘요.
같은 뜻을 가진 `.globl`을 볼 수도 있어요.

```riscvasm
/* bool is_triple(unsigned a, unsigned b, unsigned c); */
is_triple:
```

`is_triple`은 `a² + b² = c²`인지 확인하고, 맞으면 1을, 아니면 0을 반환해요.
예를 들어 `(6, 8, 10)`은 1을 반환하는데, `36 + 64 = 100`이기 때문이에요.
`is_triple` 레이블은 함수가 시작하는 위치를 나타내요.
이 함수는 `a`, `b`, `c`를 각각 `a0`, `a1`, `a2` 레지스터에 담아 호출해요.

```riscvasm
        addi    sp, sp, -FRAME_SIZE
        sw      ra, 12(sp)      /* save the return address */
        sw      a1, 8(sp)       /* save b */
        sw      a2, 4(sp)       /* save c */
```

`ra` 레지스터에는 _반환 주소_가 들어 있어요. 함수가 끝났을 때 돌아갈 호출자 안의 위치죠.
`call`은 매번 `ra`를 덮어쓰기 때문에, 먼저 이 값을 _스택_에 저장해요.
스택은 더 작은 주소 쪽으로, 즉 아래로 자라나므로, 스택 포인터 `sp`에서 16을 빼면 16바이트를 확보할 수 있어요.
(`sp`는 항상 16의 배수여야 해요.)
우리가 호출하는 함수는 `a` 레지스터들을 바꿔도 되기 때문에, `b`와 `c`도 저장해요.

```riscvasm
        call    square          /* a0 = a * a */
        sw      a0, 0(sp)       /* save a * a */
```

`a`는 `square`가 입력을 기대하는 `a0`에 이미 들어 있어요.
`call`은 `ra`를 다음 명령으로 설정하고 `square`로 점프하는데, `square`는 결과를 `a0`에 담아 반환해요.

```riscvasm
        lw      a0, 8(sp)       /* a0 = b */
        call    square          /* a0 = b * b */
        lw      t0, 0(sp)       /* t0 = a * a */
        add     t0, t0, a0      /* t0 = a * a + b * b */
        sw      t0, 0(sp)       /* save a * a + b * b */
```

스택에서 `b`를 다시 불러와 제곱한 뒤 `a * a`에 더해요.

```riscvasm
        lw      a0, 4(sp)       /* a0 = c */
        call    square          /* a0 = c * c */
        lw      t0, 0(sp)       /* t0 = a * a + b * b */
        sub     a0, t0, a0      /* a0 = a * a + b * b - c * c */
        seqz    a0, a0          /* a0 = 1 if that is zero, otherwise 0 */
```

이 차이는 `a² + b² = c²`일 때 정확히 0이 돼요.
`seqz`는 "0이면 1로 설정"이라는 뜻으로, 이 값을 1 또는 0으로 바꿔요.

```riscvasm
        lw      ra, 12(sp)      /* restore the return address */
        addi    sp, sp, FRAME_SIZE
        ret
```

`ra`를 복원하고 스택의 16바이트를 되돌려줘요.
그러면 `ret`이 `ra`에 있는 주소로 점프해서 호출자에게 돌아가요.

```riscvasm
/* unsigned square(unsigned n); */
square:
        mul     a0, a0, a0      /* n * n */
        ret
```

`square`는 다른 함수를 호출하지 않으므로 `ra`가 그대로 유지되고, 저장할 것도 없어요.
`is_triple`만 이 함수를 사용하기 때문에 `.global`로 표시하지 않았어요.
