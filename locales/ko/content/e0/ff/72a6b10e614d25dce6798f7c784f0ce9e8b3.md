# 소개

`for`문을 사용하면 조건이 만족될 때까지 코드를 반복해서 실행할 수 있어요.

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

`for`문은 네 부분으로 이루어져 있어요:

1. 초기화식: 루프에 들어가기 전에 한 번 실행돼요. 보통 루프 안에서 사용할 변수를 정의할 때 사용해요.
2. 조건식: 각 반복이 시작되기 전에 실행돼요. 이 식이 `true`로 평가되는 동안 루프가 계속 실행돼요.
3. 증감식: 각 반복이 끝난 뒤에 실행돼요. 보통 루프 변수를 수정할 때(주로 값을 늘리거나 줄일 때) 사용해요.
4. 본문: 각 반복마다 실행되는 코드예요.
