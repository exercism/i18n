# 괄호에 대한 참고 사항

Tcl은 [아주 단순한 언어](https://tcl.tk/man/tcl8.6/TclCmd/Tcl.htm)지만, 인터프리터가 코드를 해석하는 방식에는 까다로운 예외 상황이 몇 가지 있어요.

## 중괄호

Tcl에서 중괄호는 그저 텍스트 블록을 인용하는 방법일 뿐이에요. 그 텍스트는 코드로 해석될 수도 있고 데이터로 해석될 수도 있어요. 중괄호 안에는 중괄호가 중첩될 수 있지만, 중첩된 중괄호는 짝이 맞아야 해요. Tcl 맨 페이지에는 이렇게 나와 있어요.

> 중괄호는 단어 안에서 중첩돼요. 여는 중괄호가 하나 더 있으면 닫는 중괄호도 하나 더 있어야 해요. (단, 단어 안의 여는 중괄호나 닫는 중괄호가 _백슬래시로 인용되어 있으면_ 짝이 맞는 닫는 중괄호를 찾을 때 세지 않아요.)

여기서 표현이 아주 구체적이에요. 짝이 맞지 않는 여는 중괄호나 닫는 중괄호 문자를 쓰고 싶다면, 반드시 백슬래시로 인용해야 해요. 그러니 이렇게 하면 안 돼요.
```tcl
proc isOpenBrace {char} {
    return [expr {$char eq "{"}]
    # ......................^ will not work
}
```
이렇게 해야 해요.
```tcl
proc isOpenBrace {char} {
    return [expr {$char eq "\{"}]
    # ......................^^ will work
}
```

이 점은 대부분의 언어와 다른 Tcl의 주석 해석 방식 때문에 문제가 될 수 있어요. [Tcl 위키](https://wiki.tcl-lang.org/page/Why+can+I+not+place+unmatched+braces+in+Tcl+comments)에 더 자세한 논의가 있어요.

## 대괄호

마찬가지로, Tcl은 [명령어 치환](https://tcl.tk/man/tcl8.6/TclCmd/Tcl.htm#M11)에 대괄호를 사용하기 때문에, 큰따옴표 문자열 안에서도 여는 대괄호를 이스케이프하는 일에 주의해야 해요.

## 소괄호

[연관 배열 변수](https://tcl.tk/man/tcl8.6/TclCmd/Tcl.htm#M12)를 제외하면, 소괄호는 그냥 평범한 문자예요.
