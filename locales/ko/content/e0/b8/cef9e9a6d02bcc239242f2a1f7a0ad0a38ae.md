# 힌트

## 일반 사항

- 처음 여섯 개의 정수 인자는 `rdi`, `rsi`, `rdx`, `rcx`, `r8`, `r9` 레지스터로 함수에 전달돼요.
- 메모리 주소는 64비트(8바이트) 값이에요.

## 1. 각 물품의 항목 만들기

- 처음 여섯 개의 정수 인자는 `rdi`, `rsi`, `rdx`, `rcx`, `r8`, `r9` 레지스터로 함수에 전달돼요.
- 메모리 주소는 64비트(8바이트) 값이에요.
- 여섯 번째 이후의 모든 정수 인자는 스택으로 전달되며, 첫 번째 인자는 `rsp + 8`에 있어요.
- 추가 인자의 수는 `r9`로 전달되는 카테고리의 수와 같아요.
- 루프를 돌면서 추가 인자를 하나씩 더할 수도 있고, [movsq][movs]와 [rep][rep]을 함께 사용할 수도 있어요.

## 2. 월별 물품 목록을 위한 공간 확보하기

- 처음 여섯 개의 정수 인자는 `rdi`, `rsi`, `rdx`, `rcx`, `r8`, `r9` 레지스터로 함수에 전달돼요.
- 메모리 주소는 64비트(8바이트) 값이에요.
- 할당 함수를 호출한 뒤 배열의 바이트를 지우려면 그 크기를 알아야 해요.
- 외부 함수를 호출하면 그 함수가 _호출자 저장 레지스터_ 의 값을 바꿀 수 있어요.
- [push][push]를 사용하거나 `rsp`를 직접 조작해서 레지스터의 값을 스택에 보존할 수 있어요.
- `push`를 포함해 `rsp`를 변경했다면, 함수가 반환되기 전에 [pop][pop]을 사용하거나 `rsp`를 직접 바꿔서 반드시 원래대로 되돌려야 해요.

## 3. 월별 목록에 물품 추가하기

- 처음 여섯 개의 정수 인자는 `rdi`, `rsi`, `rdx`, `rcx`, `r8`, `r9` 레지스터로 함수에 전달돼요.
- 메모리 주소는 64비트(8바이트) 값이에요.
- 레지스터에 들어가지 않는 값은 스택을 통해 함수에 전달돼요.
- 물품 하나의 항목은 120바이트의 공간을 차지하는데, 이는 레지스터의 최대 크기(8바이트)보다 훨씬 커요.
- 스택으로 전달된 인자는 `rsp + 8`부터 시작하는 주소에서 찾을 수 있어요.
- 루프를 돌면서 목적지 메모리 위치에 값을 더할 수도 있고, [movsb][movs]와 [rep][rep]을 함께 사용할 수도 있어요.

## 4. 물품 출력하기

- 처음 여섯 개의 정수 인자는 `rdi`, `rsi`, `rdx`, `rcx`, `r8`, `r9` 레지스터로 함수에 전달돼요.
- 메모리 주소는 64비트(8바이트) 값이에요.
- 도입 문자열은 선택 사항이라, 대신 `0`을 넘겨서 출력 함수를 호출해도 돼요.
- 도입 문자열을 출력 함수에 넘긴다면, NUL 종료 문자(값 `0`)를 포함해서 최대 50개의 ASCII 문자여야 해요.
- 함수를 호출할 때마다 여섯 번째 이후의 인자를 위한 공간을 스택에 확보해야 해요.
- System V ABI에서는 함수를 호출하기 전에 스택이 16바이트로 정렬되어 있어야 한다고 규정하는데, 이는 특히 외부 함수에서 중요해요.
- 목록에 있는 물품 하나의 항목은 120바이트의 공간을 차지해요.
