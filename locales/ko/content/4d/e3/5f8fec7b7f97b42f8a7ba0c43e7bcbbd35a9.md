# 힌트

## 1. 제목의 첫 글자 가져오기

- 주어진 인덱스에서 `String`의 `Char`를 반환하는 [메서드][index]가 있어요.

## 2. 저자의 이니셜 가져오기

- 이미 구현된 메서드를 사용해서 `String`의 첫 글자를 가져올 수 있어요.
- 값들을 `String`으로 합치려면 [문자열 보간][string-interpolation]을 사용할 수 있어요.

## 3. 글자 복호화하기

- `Char`가 대문자인지 확인하는 [메서드][uppercase]가 있어요.
- `Char`의 코드 포인트를 가져오는 [메서드][ord]가 있어요.

## 4. 텍스트 복호화하기

- [루프][while]를 사용해서 코드를 여러 번 실행할 수 있어요.
