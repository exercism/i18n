# 소개

R은 통계 분야의 오픈 소스 프로그래밍 *공통어*예요.
**R**oss Ihaka와 **R**obert Gentleman이 오클랜드 대학교에서 만들었는데, 두 사람은 통계 계산에 더 잘 맞으면서 컴퓨터 과학자들이 설계한 비슷한 소프트웨어보다 사용하기 쉬운 언어를 원했어요.

R은 프로그래밍 언어일 뿐만 아니라 대화형 데이터 분석 환경이기도 해요.
강력한 메타프로그래밍 기능 덕분에 마법처럼 간결하고 짧은 함수를 만들 수 있어요.
Fortran, C, C++처럼 성능이 뛰어난 프로그래밍 언어와 통합할 수도 있어요.
이런 특징들이 어우러져 [도메인 특화 언어](https://en.wikipedia.org/wiki/Domain-specific_language)를 설계하기에 더없이 좋은 환경을 제공해요.

Ross Ihaka는 R을 두고 "협업의 힘을 제대로 보여 주는 사례"라고 말해요.
R에는 사용자와 개발자로 이루어진 멋진 커뮤니티가 있어요. 이들은 데이터를 가져오고 다루고 시각화하는 방대한(그리고 빠르게 성장하는) [패키지](https://cran.r-project.org/) 모음은 물론, 통계 모델링과 머신러닝을 위한 최신 기법에도 기여하고 있어요.

[r-project.org](https://www.r-project.org/)에서 더 자세히 알아봐요!
