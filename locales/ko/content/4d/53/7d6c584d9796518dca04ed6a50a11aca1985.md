# 설치

## Ubuntu (및 대부분의 Debian 기반 배포판)

코드를 로컬에서 빌드하려면 gcc와 make가 필요해요. 다음 명령으로 설치할 수 있어요.

```shell
sudo apt install gcc make
```

ARM64 하드웨어에서 실행하고 있지 않다면, [QEMU][] 에뮬레이터와 GCC ARM64 크로스 툴체인을 다음 명령으로 설치해요.

```shell
sudo apt install qemu-user libc6-dev-arm64-cross gcc-aarch64-linux-gnu
```

## Windows

[Windows Subsystem for Linux][]를 Debian 기반 배포판과 함께 사용하고, 위의 Ubuntu 안내를 따라 해요.
또는 Linux 가상 머신을 설정해도 돼요.

## macOS

적절한 가상화 솔루션(예: [Lima][])을 사용해 Linux 가상 머신을 실행할 수 있어요.

[QEMU]: https://www.qemu.org/
[Windows Subsystem for Linux]: https://docs.microsoft.com/en-gb/windows/wsl/about
[Lima]: https://lima-vm.io/
