## 1. 예상 굽기 시간(분)을 상수로 정의하기

라자냐를 오븐에서 몇 분 동안 구워야 하는지를 나타내는 `EXPECTED_BAKE_TIME` [상수][constants]를 정의해요.
요리책에 따르면 라자냐는 오븐에서 40분 동안 구워야 해요:

```python
>>> print(EXPECTED_BAKE_TIME)
40
```

## 2. 남은 굽기 시간(분) 계산하기

`bake_time_remaining()` 함수를 완성해요. 이 함수는 라자냐가 오븐에 있던 실제 시간(분)을 인자로 받아서, `EXPECTED_BAKE_TIME` 상수를 기준으로 라자냐가 앞으로 몇 분을 더 구워야 하는지 반환해요.

```python
>>> bake_time_remaining(30)
10
```

## 4. 총 소요 시간(분) 계산하기 (준비 + 굽기)

`elapsed_time_in_minutes()` 함수를 정의해요. 이 함수는 두 개의 매개변수를 인자로 받아요:

- `number_of_layers` (_라자냐에 추가한 층의 수_)

```python
        ...
        
>>> elapsed_time_in_minutes(3, 20)

```
