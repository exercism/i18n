# 안내

친구가 방금 중요한 비밀이 담긴 메시지를 보냈어요.
다른 사람들이 쉽게 읽지 못하게 하려고, 메시지는 일련의 비트 조작을 거쳐 암호화되었어요.
메시지를 복호화할 수 있도록 메서드들을 작성해야 해요.

## 1. 비트를 다시 시프트하기

메시지를 복호화하는 첫 단계는 암호화 과정에서 시프트한 비트를 오른쪽으로 다시 시프트해서 되돌리는 거예요.
복호화 과정의 이후 단계들은 왼쪽에서 0이 채워진다고 가정해요.

값과 시프트할 자릿수를 받아 시프트를 수행하는 `Secrets.shiftBack` 메서드를 구현해요.

```java
Secrets.shiftBack(0b1001, 2);
# => 0b0010
```

## 2. 일부 비트를 1로 설정하기

다음으로, 1로 설정해야 하는 비트들이 있어요.

값과 마스크를 받아 값의 비트를 1로 설정한 결과를 반환하는 `Secrets.setBits` 메서드를 구현해요.
마스크의 비트가 1인 자리에서는 값의 비트도 1로 설정되어야 해요.
나머지 비트는 모두 그대로 유지되어야 해요.

```java
Secrets.setBits(0b0110, 0b0101);
# => 0b0111
```

## 3. 특정 비트 뒤집기

암호화 과정에서 일부 비트가 뒤집혀요.
메시지를 복호화하려면 이 비트들을 다시 뒤집어야 해요.

값과 마스크를 받는 `Secrets.flipBits` 메서드를 구현해요.
마스크는 값에서 어떤 비트를 뒤집을지 알려줘요.
마스크의 비트가 1이면, 값의 해당 비트가 뒤집혀요.
나머지 비트는 모두 그대로 유지돼요.

```java
Secrets.flipBits(0b1100, 0b0101);
# => 0b1001
```

## 4. 특정 비트를 0으로 만들기

마지막으로, 항상 0으로 복호화되는 특정 비트들도 있어요.

값과 마스크를 받는 `Secrets.clearBits` 메서드를 구현해요.
마스크의 비트가 1인 자리에서는 `value`의 비트가 0으로 설정되어야 해요.
나머지 비트는 모두 그대로 유지되어야 해요.

```java
Secrets.clearBits(0b0110, 0b0101);
# => 0b0010
```
