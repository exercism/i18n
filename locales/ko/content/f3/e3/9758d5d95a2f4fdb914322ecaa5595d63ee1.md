# 클래스 정적 키워드

클래스는 PHP에서 코드를 구성하는 단위로, 흔히 어떤 것/서비스/절차의 인스턴스를 나타내요.
`static`과 `self` 키워드를 사용하면, 속성과 메서드가 모든 인스턴스(또는 인스턴스가 하나도 없을 때도)를 기준으로 클래스에 존재할 수 있어요.

```php
<?php

class Book
{
    static $genre = 'Adventure';

    static function getGenre()
    {
        return self::$genre;
    }
}

// Usage
$genre = Book::$genre;
$genre = Book::getGenre();
```

## 제한 사항

정적 클래스 메서드는 자신의 클래스에 있는 다른 정적 클래스 속성이나 클래스 메서드만 호출할 수 있어요.
