# 소개

## 배열

우리가 사용하는 언어의 이름인 Lisp은 _LIST Processing_을 뜻하니까, 이 언어에 항목들의 배열을 다루는 기능이 있겠구나 하고 짐작할 수 있는데, 맞아요!

Common Lisp에는 배열 외에도 다른 자료 구조가 있지만, 배열은 여전히 아주 많이 쓰여요.

Common Lisp에서 배열은 항목들의 시퀀스예요. **cons**라고도 부르는데, 주로 역사적인 이유 때문이에요.
항목들은 꼭 같은 타입일 필요는 없어요.
예를 들어 `1`, `two`, `"III"`로 이루어진 배열을 만들 수 있어요.

### 배열 만들기

다음처럼 인용한 배열을 그냥 입력하면 돼요: `'(1 two "III")`. 그러면 배열이 만들어지고 평가돼요. 평과 결과는 `(1 two "III")`예요.

배열을 만드는 데 쓰이는 주요 함수도 두 가지 있어요: `list`와 `cons`.

`list`는 인자를 0개 이상 받아서, 그 값들로 만들어진 배열로 평가돼요:

```lisp
(list 1 'two "III") ; => (1 two "III")
```

`cons`는 두 항목을 받아서, 첫 번째 항목을 `car`(배열의 머리)로, 두 번째 항목을 `cdr`(나머지 부분)로 하는 배열을 만들어요:

```lisp
(cons 1 2)            ; => (1 . 2) ;; (a list without `nil` as its `cdr` is printed in this way)
(cons 1 nil)          ; => (1)
(cons 1 (cons 2 nil)) ; => (1 2)
```

`car`와 `cdr` 함수를 사용하면 배열의 `car`와 `cdr`에 접근할 수 있어요.

(`first`와 `rest`는 `car`와 `cdr`의 동의어이고, 완전히 똑같이 동작해요.)

### 길이와 임의 접근

배열의 길이는 `length`로 구할 수 있어요.
빈 배열의 길이는 0이에요.

임의의 항목에는 `nth`로 접근할 수 있어요(배열의 인덱스는 0부터 시작해요).

배열의 길이보다 큰 인덱스를 요청해도 오류가 _아니에요_.
대신 `nil`로 평가돼요:

```lisp
(nth 23 '(short list)) ; => nil
```

배열의 앞쪽 항목들에 접근하는 데 쓰이는 여러 도우미 메서드도 있어요: `first`, `second`, `third`부터 `tenth`까지요. 멋지죠?

### 배열 합치기

두 개 이상의 배열은 `append`로 합칠 수 있어요:

```lisp
(append '(a b c) '(1 2 3)) ; => (A B C 1 2 3)
(append '(a b c) '())     ; => (A B C)
```

`append`에 전달하는 인자는 각각 배열이어야 해요.
