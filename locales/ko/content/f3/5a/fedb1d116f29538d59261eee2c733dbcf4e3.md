# 개요

Rust는 단일 문자를 나타내기 위해 [char][char type] 타입을 구현해요. `char` 리터럴은 `'a'`처럼 작은따옴표 안에 넣어요.
각 `char`는 크기가 4바이트이고, 단일 [유니코드 스칼라 값][unicode scalar]을 나타내요.

하지만 [`char`][character type]가 항상 우리가 생각하는 글자인 것은 아니에요. 힌디어처럼 [발음 구별 기호][diacritics]를 사용하는 언어도 있는데,
발음 구별 기호는 붙어 있는 문자를 수정하는 특수 기호예요. Rust에서 발음 구별 기호는 별도의 `char`이지만, 우리가 흔히 글자라고 생각하는 것은
발음 구별 기호와 그것이 수정하는 문자를 합친 것이에요.

문자와 그 발음 구별 기호를 아울러 이르는 말은 [자소 클러스터][grapheme cluster]예요. [unicode-segmentation][unicode-segmentation] 같은
외부 크레이트를 사용하면 자소 클러스터를 처리할 수 있어요.

예제

```rust
pub fn main() {
    let text = "ü"; // a "u" with a diacritic
    let text_vec: Vec<char> = text.chars().collect(); // this gets the chars in "ü"
    println!("{:?}", text_vec.len()); // this prints the number of chars in "ü"
    println!("{:?}", text_vec[0]); // this prints the first char in "ü"
    println!("{:?}", text_vec[1]); // this prints the second char in "ü"
}
```

출력 결과

```rust
2
'u'
'\u{308}'
```

'\u{308}'는 `char` 리터럴을 작성하는 또 다른 방법이에요. `\u`는 유니코드 `char`라는 것을 나타내고, `{308}`은 그 문자
또는 발음 구별 기호의 고유한 유니코드 번호예요.
