# 지침

이 연습 문제에서는 간단한 정수 계산기의 오류 처리를 만들어 봐요.
계산기는 덧셈, 곱셈, 나눗셈 연산을 지원하고, 결과를 형식에 맞춘 문자열로 반환해야 해요.
또한 잘못된 연산과 0으로 나누는 경우를 처리하는 오류 처리도 구현해요.

목표는 다음 형식의 문자열을 반환하는, 제대로 동작하는 계산기를 완성하는 거예요.

```rust
SimpleCalculator::calculate(16, 51, "+"); // => returns "16 + 51 = 67"

SimpleCalculator::calculate(32, 6, "*"); // => returns "32 * 6 = 192"

SimpleCalculator::calculate(512, 4, "/"); // => returns "512 / 4 = 128"
```

## 1. 계산기 연산 구현하기

이 작업의 주 함수는 `SimpleCalculator::calculate`이고, 세 개의 인자를 받아요: 두 개의 정수와 연산을 나타내는 `ByteArray`예요.
다음 연산을 구현해요.

- `+` 기호를 사용하는 **덧셈**
- `*` 기호를 사용하는 **곱셈**
- `/` 기호를 사용하는 **나눗셈**

## 2. 잘못된 연산 처리하기

연산 기호가 `+`, `*`, `/`가 아니면 계산기는 panic을 일으키거나 오류를 반환해야 해요.

- 연산이 빈 문자열이면 `"Operation cannot be an empty string"`라는 `ByteArray` 오류 메시지와 함께 panic해요.
- 그 밖의 잘못된 연산에 대해서는 `Result::Err("Operation is out of range")`를 반환해요.

```rust
SimpleCalculator::calculate(100, 10, "-"); // => returns Result::Err("Operation is out of range")

SimpleCalculator::calculate(8, 2, ""); // => panics with "Operation cannot be an empty string"
```

## 3. 0으로 나눌 때의 오류 처리하기

`0`으로 나누려고 하면, 계산기는 0으로 나누는 것은 허용되지 않는다는 오류 메시지와 함께 panic해야 해요.
반환되는 결과는 `'Division by zero is not allowed'`라는 `felt252` 값이어야 해요.

```rust
SimpleCalculator::calculate(512, 0, "/"); // => panics with 'Division by zero is not allowed'
```
