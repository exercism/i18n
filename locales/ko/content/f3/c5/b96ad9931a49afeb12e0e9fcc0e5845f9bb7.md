# 지침

이번 연습 문제에서는 데이터에 변환을 적용하는 방식으로 동작하는 암호화 장치의 소프트웨어를 작성해요. 더 단순한 함수들을 조합해서 복잡한 함수를 유연하게 만들 수 있는 방법이 필요해요.

각 과제마다, 호출하는 스코프에서 호출할 수 있는 익명 함수를 반환해야 해요.

## 1. 덧셈 함수 만들기

`secret_add`를 구현해요. 인자 하나를 받아서, 그 인자에 `secret_add`에 전달된 값을 더하는 함수를 반환해야 해요.

```gleam
let adder = secret_add(2)
adder(2)
// -> 4
```

## 2. 뺄셈 함수 만들기

`secret_subtract`를 구현해요. 인자 하나를 받아서, 그 인자에서 `secret_subtract`에 전달된 값을 빼는 함수를 반환해야 해요.

```gleam
let subtractor = secret_subtract(2)
subtractor(3)
// -> 1
```

## 3. 곱셈 함수 만들기

`secret_multiply`를 구현해요. 인자 하나를 받아서, 그 인자에 `secret_multiply`에 전달된 값을 곱하는 함수를 반환해야 해요.

```gleam
let multiplier = secret_multiply(7)
multiplier(3)
// -> 21
```

## 4. 나눗셈 함수 만들기

`secret_divide`를 구현해요. 인자 하나를 받아서, 그 인자를 `secret_divide`에 전달된 값으로 나누는 함수를 반환해야 해요.

```gleam
let divider = secret_divide(3)
divider(32)
// -> 10
```

## 5. 두 함수를 조합하는 함수 만들기

`secret_combine`을 구현해요. 인자 하나를 받아서, `secret_combine`에 전달된 두 함수를 순서대로 그 인자에 적용하는 함수를 반환해야 해요.

```gleam
let multiply = secret_multiply(7)
let divide = secret_divide(3)
let combined = secret_combine(multiply, divide)

combined(6)
// -> 14
```
