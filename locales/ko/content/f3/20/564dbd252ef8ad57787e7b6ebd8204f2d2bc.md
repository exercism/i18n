# 지침

이 연습 문제에서는 로그 라인을 처리해요.

각 로그 라인은 다음과 같은 형식의 문자열이에요: "[<LEVEL>]: <MESSAGE>*".

## 1. 로그 라인에서 메시지 가져오기

로그 라인에서 메시지를 반환하도록 `LogLevels.message()` 함수를 구현해요. 이때 앞뒤 공백은 제거해요.

## 2. 로그 라인에서 로그 레벨 가져오기

로그 라인에서 로그 레벨을 소문자로 반환하도록 `LogLevels.logLevel()` 함수를 구현해요.

## 3. 로그 라인 형식 바꾸기

로그 라인과 위치 문자열을 받아서 두 줄로 된 메시지로 형식을 바꾸는 `LogLevels.reformat()` 메서드를 구현해요.
첫 번째 줄은 `<LEVEL>@<LOCATIOON>:` 형식이에요. 여기서:

* `<LEVEL>`은 소문자로 된 로그 레벨이에요 (2. 로그 라인에서 로그 레벨 가져오기에서처럼).
* `<LOCATION>`은 두 번째 매개변수로 주어진 위치예요.

두 번째 줄은 정확히 공백 두 개로 시작하고, 그 뒤에 로그 메시지가 와요 (1. 로그 라인에서 메시지 가져오기에서처럼):

```kotlin
reformat("[TRACE]: Start of function", 2, 8)
// => "trace@208:
  Start of function"
```
