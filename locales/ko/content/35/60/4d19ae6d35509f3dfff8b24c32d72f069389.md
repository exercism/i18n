# 소개

quotation이 주변의 값을 *기억*해야 할 때가 있어요. 다른 언어라면 *클로저*라고 부를 그런 기능인데, Factor에서는 두 가지 도구를 써요. 바로 `curry` 워드와 `'[ ]` *fry* 문법이에요.

## `curry`: 값 하나 캡처하기

`curry`는 [`kernel`][kernel]에 있는 워드로, 값 하나와 quotation을 받아 그 값을 안에 심은 새 quotation을 반환해요:

```
curry ( value quot -- newquot )
```

```factor
3 [ + ] curry .
! => [ 3 + ]

10 3 [ + ] curry call .
! => 13
```

값 두 개를 캡처하려면 `curry`를 두 번 적용해요:

```factor
2 3 [ + + ] curry curry .
! => [ 2 3 + + ]
```

## `compose`: quotation 두 개 이어 붙이기

`compose`는 [`kernel`][kernel]에 있는 워드로, quotation 두 개를 서로 붙여요:

```
compose ( quot1 quot2 -- quot )
```

```factor
[ 1 + ] [ 2 * ] compose .
! => [ 1 + 2 * ]

5 [ 1 + ] [ 2 * ] compose call .
! => 12
```

## Fry quotation: 값 여러 개 캡처하기

캡처할 값이 한두 개를 넘으면 `curry`를 연달아 호출한 코드는 읽기 어려워져요. *Fry*는 `'[ … ]` 안에 `_` 자리 표시자를 하나 이상 두는 방식이에요. 각 `_`는 데이터 스택에서 꺼낸 값으로 차례대로 바뀌어요:

```factor
2 3 '[ _ _ + + ] .
! => [ 2 3 + + ]
```

`curry`와 fry는 모두 클로저가 만들어지는 순간 스택에서 값을 *소비*해요. 위 코드는 스택에 아무것도 남기지 않으며, `[ + + ] curry curry`를 그대로 대신하는 표현이에요.

자리 표시자는 왼쪽에서 오른쪽으로, 스택 값은 아래에서 위로 채워져요. `2 3 '[ _ _ ]`는 `[ 2 3 ]`이지 `[ 3 2 ]`가 아니에요.

Fry는 중첩된 quotation *안쪽*까지 들어가요. 덕분에 캡처한 값을 원하는 자리에 정확히 넣을 수 있어요:

```factor
2 '[ [ _ > ] filter ] { 1 2 3 4 5 } swap call( s -- s ) .
! => { 3 4 5 }
```

`_`가 안쪽 `[ … ]`에 들어 있어도 fry는 그 자리를 채워 줘요.

## 스택 효과를 밝힌 `call`

저장해 둔 quotation을 마침내 실행할 때는 `call`에 그 스택 효과를 함께 적어 줘요. 그러면 컴파일러가 타입을 검사할 수 있어요:

```factor
{ 3 4 5 } [ first2 + ] call( p -- n ) .
! => 7

{ 3 4 5 } [ first ] call( p -- n ) .
! => 3
```

## 벡터 연산

[`math.vectors`][math.vectors] 보캐뷸러리는 길이가 같은 두 시퀀스를 원소 단위로 결합해요. `v+`와 `v*`는 두 시퀀스를 더하거나 곱하고, `vmax`와 `vmin`은 각 성분 중 더 큰 값이나 더 작은 값을 골라요. 모두 2-array를 돌려줘요:

```factor
{ 1 1 } { 3 4 } v+ .    ! => { 4 5 }
{ 2 5 } { 3 -1 } v* .   ! => { 6 -5 }
{ 1 9 } { 4 4 } vmax .  ! => { 4 9 }
{ 1 9 } { 4 4 } vmin .  ! => { 1 4 }
```
