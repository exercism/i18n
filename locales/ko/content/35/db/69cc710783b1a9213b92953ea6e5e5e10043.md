# gofmt를 사용하지 않았어요

풀이에 `gofmt`를 실행해 봐요. Go 코드 형식을 정리하는 데 도움이 돼요.

Go에서 코드 형식은 커뮤니티에서 아주 중요하게 여겨요.
대부분의 IDE는 저장할 때마다 코드 형식을 자동으로 정리하도록 설정할 수 있어요. 예를 들면 다음과 같아요:

- Visual Studio Code는 [훌륭한 Go 지원](https://code.visualstudio.com/docs/languages/go)을 제공해요
- Vim에도 [멋진 Go 확장 기능](https://github.com/fatih/vim-go)이 있어요
- [Jetbrains Goland](https://www.jetbrains.com/go/)는 Go 전용 IDE예요

`gofmt`를 직접 실행하려면:

```bash
# will only show the differences
gofmt -d filename.go

# will apply the changes
gofmt -w filename.go
```

```git
%{gofmt}
```
