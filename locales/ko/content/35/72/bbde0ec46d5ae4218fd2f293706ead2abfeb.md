# 루프

**루프**는 같은 일을 계속 반복해요.

```sather
   loop
      ...
   end;
```

그대로 두면 절대 멈추지 않아요. 그래서 루프 안의 무언가가 루프를 끝내 줘야 해요.

## 개수를 세어 둘 곳

루프에는 거의 항상 진행하면서 바뀌는 값이 필요해요. 그게 바로 **변수**이고, `::=`로 만들 수 있어요.

```sather
   total ::= 0;
```

변수 이름은 `total`이고 `0`에서 시작해요. Sather는 이 `0`을 보고 변수가 `INT`를 담고 있다는 것을 알아내요. 그다음에는 `:=`로 새로운 값을 넣어요.

```sather
   total := total + 5;
```

오른쪽에서 왼쪽으로 읽어 봐요. 지금 `total`에 들어 있는 값을 가져와 5를 더하고, 그 결과를 다시 `total`에 넣는 거예요.

이렇게 만든 변수는 루틴이 끝날 때까지 살아 있어요.

## until!

`until!`은 질문을 하나 받아요. 루프를 한 바퀴 돌 때마다 그 질문을 다시 물어보고, 답이 참이면 그 자리에서 바로 루프가 멈춰요.

```sather
   sum_to(last : INT) : INT is
      total ::= 0;
      n ::= 1;
      loop
         until!(n > last);
         total := total + n;
         n := n + 1;
      end;
      return total;
   end;
```

`n`은 1, 2, 3 ... 하고 세어 나가고, `n`이 처음으로 `last`를 넘어설 때 루프가 끝나요. `n := n + 1`이 없다면 질문의 답이 영원히 바뀌지 않아서 루프가 끝없이 돌아요.

`until!`이 반드시 첫 줄에 있어야 하는 건 아니에요. 질문이 자연스러운 자리에 두면 돼요. 위쪽에 두면 루프가 한 번도 실행되지 않을 수 있고, 아래쪽에 두면 항상 적어도 한 번은 실행돼요.

이름의 일부에 `!`가 들어가요. Sather는 특정한 것들에 이런 표시를 붙여요. 이 표시가 무슨 뜻인지는 나중에 알아봐요.

## break!

`break!`는 질문 없이 루프를 곧바로 끝내요. 멈출 이유가 작업 도중에 생겼을 때 유용해요.

```sather
   loop
      if too_far then break!; end;
      ...
   end;
```

`until!`과 `break!`은 `loop` 안에서만 의미가 있어요. 둘 다 단독으로는 쓸 수 없어요.
