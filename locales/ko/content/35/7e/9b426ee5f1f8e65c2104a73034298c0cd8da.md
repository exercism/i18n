# Babashka 텍스트 편집기 연동

## nREPL

### Emacs: [CIDER](https://cider.mx/)

이 도구가 모든 것의 시작이고, 다른 많은 플러그인이 이 [Orchard](https://metaredux.com/posts/2018/11/09/ciders-orchard-the-heart.html) 생태계를 기반으로 동작해요.

1. 사용하는 플랫폼에 맞는 [Emacs](https://www.gnu.org/software/emacs/download.html)를 설치해요.

2. 이미 만들어진 Emacs 배포판([Prelude](https://prelude.emacsredux.com/), [Spacemacs](https://www.spacemacs.org/), [Doom Emacs](https://github.com/hlissner/doom-emacs) 모두 좋아요)을 골라도 되고, `init.el`에 다음을 추가해도 돼요:

```elisp
(unless (package-installed-p 'cider)
  (package-install 'cider))
  
(add-hook 'clojure-mode-hook #'cider-mode)
```

[CIDER 문서](https://docs.cider.mx/cider/platforms/babashka.html)에서 요약했어요:

프로젝트 디렉터리에서 nREPL 서버를 시작해요:

```bash
$ bb --nrepl-server
```

`C-x C-f`로 아무 Clojure 파일(`.clj`)이나 만들거나 열고, `C-c C-x c j`(cider-connect-clj)로 연결해요.

[CIDER 기본 키 바인딩](https://docs.cider.mx/cider/usage/cider_mode.html#key-reference):

* `cider-load-buffer` - `C-c C-k`
* `cider-eval-last-sexp` - `C-x C-e` 또는 `C-c C-e`
* `cider-eval-defun-at-point` - `C-M-x` 또는 `C-c C-c`

### VSCode: [Calva](https://github.com/BetterThanTomorrow/calva)

1. [VSCode](https://code.visualstudio.com/)를 설치해요.

2. [Calva](https://marketplace.visualstudio.com/items?itemName=betterthantomorrow.calva)를 설치해요.

현재 Calva는 소스 코드가 폴더, 즉 Clojure 프로젝트의 맥락 안에 있다고 이해해요. 프로젝트를 만드는 좋은 방법은 [clj-new](https://github.com/seancorfield/clj-new)를 쓰는 거예요:

```bash
$ clj -A:new lib myorg/bbtest
Generating a project called bbtest based on the 'lib' template.
The lib template is intended for library projects, not applications.
```
3. 프로젝트 디렉터리에서 nREPL 서버를 시작해요:

```bash
$ cd bbtest
bbtest$ bb --nrepl-server 1667
Started nREPL server at localhost:1667
For more info visit https://github.com/borkdude/babashka/blob/master/doc/repl.md#nrepl.
```

VSCode에서 프로젝트 폴더를 열거나(Ctrl+K Ctrl+O), 다른 터미널에서 열어요:

```bash
$ cd bbtest
bbtest$ code .
```

4. VSCode에서 Calva 명령 `Connect to a running REPL`을 실행해요(ctrl+alt+c ctrl+alt+c). 프로젝트 종류를 묻으면 `Generic`을 고르고, `localhost:1667`을 입력해요.

REPL 명령:

* `Load Current File and Dependencies` ctrl+alt+c enter
* `Evaluate Current Form Inline` ctrl+alt+c e
* `Evaluate Current Top Level Form (defun)` ctrl+alt+c space

### IntelliJ: [Cursive](https://cursive-ide.com/)

1. IntelliJ를 [여기](https://www.jetbrains.com/idea/download/index.html)에서 내려받아요.
2. [사용 안내](https://cursive-ide.com/userguide/)를 따라 Cursive를 설치하고 [deps를 설정](https://cursive-ide.com/userguide/deps.html)해요.
3. 더 자세한 내용은 [Cursive: Working with Babashka](https://cursive-ide.com/userguide/babashka.html)를 참고해요.

## Socket REPL

### Atom: [chlorine](https://github.com/mauricioszabo/atom-chlorine)

1. [atom](https://flight-manual.atom.io/getting-started/sections/installing-atom/)을 설치해요.

2. `chlorine` 패키지를 설치해요.

3. 소켓 REPL을 시작해요:

 ```
$ bb --socket-repl 1666
Babashka socket REPL started at localhost:1666
 ```

4. Atom 명령 팔레트(ctrl+shift+p)를 열고 `Connect Clojure Socket REPL` 명령을 `localhost` `1666`으로 실행해요.

5. `Edit` 메뉴 -> `Keymap...`에서 keymap.cson의 키 바인딩을 편집해요:

```
'atom-text-editor[data-grammar="source clojure"]':
  'ctrl-; y':       'chlorine:connect-clojure-socket-repl'
  'ctrl-; e':       'chlorine:disconnect'
  'ctrl-; k':       'chlorine:clear-console'
  'ctrl-shift-enter':       'chlorine:load-file'
  'ctrl-enter':       'chlorine:evaluate-block'
  'shift-enter':       'chlorine:evaluate-top-block'
  'ctrl-; i':       'chlorine:inspect-block'
  'ctrl-; I':       'chlorine:inspect-top-block'
  'ctrl-; s':       'chlorine:evaluate-selection'
  'ctrl-; c':       'chlorine:break-evaluation'
  'ctrl-; S':       'chlorine:source-for-var'
  'ctrl-; d':       'chlorine:doc-for-var'
  'ctrl-; x':       'chlorine:run-tests-in-ns'
  'ctrl-; t':       'chlorine:run-test-for-var'
```

### Emacs: [inf-clojure](https://github.com/clojure-emacs/inf-clojure)

Emacs에서는 `init.el`에 다음을 추가해서 [inf-clojure](https://github.com/clojure-emacs/inf-clojure)를 설치해요:

```
(unless (package-installed-p 'inf-clojure)
  (package-refresh-contents)
  (package-install 'inf-clojure))

(add-hook 'clojure-mode-hook #'inf-clojure-minor-mode)
```

위에서처럼 소켓 REPL을 시작하고, Emacs에서 `M-x inf-clojure-connect`를 실행해요(C-c M-c).

C-c C-e로 폼을 평가해요. inf-clojure-mode(일명 REPL)와 inf-clojure-minor-mode에서 쓸 수 있는 모든 명령 목록은 C-h f RET inf-clojure-mode와 C-h f RET inf-clojure-minor-mode를 실행하거나, 그냥 각 모드의 메뉴를 살펴보면 돼요.

### Vim: [vim-iced](https://github.com/liquidz/vim-iced)

[Neovim appimage](https://github.com/neovim/neovim/releases/download/v0.4.3/nvim.appimage)를 내려받아 `vim`으로 별칭을 지정해요.

* [vim-plug](https://github.com/junegunn/vim-plug)를 설치해요:

```
$ curl -fLo ~/.local/share/nvim/site/autoload/plug.vim --create-dirs \
    https://raw.githubusercontent.com/junegunn/vim-plug/master/plug.vim
```

`~/.config/nvim/init.vim`을 만들어요:

```
call plug#begin('~/.vim/plugged')

Plug 'liuchengxu/vim-clap'
Plug 'guns/vim-sexp',    {'for': 'clojure'}
Plug 'liquidz/vim-iced', {'for': 'clojure'}

call plug#end()

" Enable vim-iced's default key mapping
" This is recommended for newbies
let g:iced_enable_default_key_mappings = v:true
```

Neovim을 열고 `:PlugInstall` 명령을 실행해요.

`iced` 명령을 $PATH에 추가해요:

`$ export PATH=$PATH:~/.vim/plugged/vim-iced/bin`

* 소켓 REPL 서버를 시작하고, 소스 파일을 연 다음 `:IcedConnectSocketRepl 1666`을 실행해요.

기본 REPL 명령(기본 `<Leader>`는 `\`):

- `<Leader>ei` : 안쪽 요소 평가
- `<Leader>ee` : 바깥 리스트 평가
- `<Leader>et` : 바깥 최상위 리스트 평가
