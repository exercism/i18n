# 자세히 알아보기

Factor의 문자는 *정수*, 즉 유니코드 코드 포인트예요. 그래서 `<`, `>`, `=` 같은 평범한 숫자 비교만으로도 대소문자를 구분하는 정렬을 바로 할 수 있어요. [`unicode`][unicode] 보캐뷸러리는 여기에 더해 유니코드를 인식하는 술어와 단일 문자 대소문자 변환을 제공해요.

## 술어

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
digit>   ( c -- n )    ! the integer value of a digit char
blank?   ( c -- ? )    ! whitespace
alpha?   ( c -- ? )    ! letter or decimal digit
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
CHAR: \n blank? .    ! => t
```

## 대소문자 변환

```
ch>upper  ( c -- c' )
ch>lower  ( c -- c' )
ch>title  ( c -- c' )
```

문자열 수준의 `>upper`, `>lower`, `>title`은 이런 변환을 문자열의 모든 문자에 적용해요.

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```
