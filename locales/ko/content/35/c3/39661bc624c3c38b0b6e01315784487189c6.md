# 지침

이 연습 문제에서는 차량 구매를 준비하는 데 도움이 되는 코드를 작성해요.

해야 할 과제는 세 가지예요. 운전면허가 필요한지 판단하기, 두 차량 중에서 고르기, 그리고 중고 차량의 적정 가격을 추정하기예요.

## 1. 운전면허가 필요한지 판단하기

어떤 종류의 차량은 운전하려면 운전면허가 필요해요.
`"car"`와 `"truck"` 종류만 면허가 필요하고, 나머지는 모두 면허 없이 운전할 수 있다고 가정해요.

차량의 종류를 받아서, 그 종류의 차량에 면허가 필요한지를 나타내는 불리언을 반환하는 `needs_license` 함수를 구현해요.

```jq
"car" | needs_license
# => true

"bike" | needs_license
# => false
```

## 2. 구매할 후보 차량 두 대 중에서 고르기

구매 가능한 차량들을 살펴봤어요.
후보를 두 개로 좁혔지만, 최종 결정을 내리려면 도움이 필요해요.
차량 두 대가 담긴 배열을 입력으로 받아서, 사전 순으로 앞서는 쪽을 결정으로 반환하는 `choose_vehicle` 함수를 구현해요.

```jq
["Wuling Hongguang", "Toyota Corolla"] | choose_vehicle
# =>  "Toyota Corolla is clearly the better choice."

["Volkswagen Beetle", "Volkswagen Golf"] | choose_vehicle
# =>  "Volkswagen Beetle is clearly the better choice."
```

## 3. 중고 차량의 가격 추정하기

이제 결정을 내렸으니, 대리점에서 적정한 가격에 사고 싶어요.
중고 차량을 사려고 하니, 가격은 차량의 연식에 따라 달라져요.
대략적으로 추정해 보면, 차량이 3년 미만이면 새 차였을 때의 원래 가격에서 80%라고 가정해요.
10년이 넘으면 50%예요.
차량이 3년 이상이면서 10년 이하이면 원래 가격의 70%예요.

`if`, `elif`, `else`를 사용해 이 로직을 적용하는 `resell_price` 함수를 구현해요.
원래 가격과 차량의 연식이 담긴 객체를 받아서 대리점에서의 추정 가격을 반환해요.

```jq
{"original_price": 1000, "age": 1} | resell_price
# => 800

{"original_price": 1000, "age": 5} | resell_price
# => 700

{"original_price": 1000, "age": 15} | resell_price
# => 500
```
