# 소개

같은 프로젝트 안에서 서로 다른 Elixir 모듈끼리 코드를 공유하려면, 바깥 모듈을 전체 이름으로 참조해야 해요. 그런데 그 이름이 너무 길거나 헷갈린다면 어떻게 할까요?

특별한 형식인 `alias`를 사용하면 바깥 모듈을 참조할 때 쓰는 이름을 줄이거나 바꿀 수 있어요. 인자 없이 사용하면 모듈 이름을 마지막 부분만 남기고 줄여줘요. 예를 들어 `MyApp.Logger.Settings`는 `Settings`가 돼요. 원하는 이름은 `:as` 옵션으로 지정할 수 있어요.

보통 alias는 모듈 정의 맨 앞에 추가해요.

```elixir
defmodule Square do
  alias Integer, as: I

  def area(a), do: I.pow(a, 2)
end
```
