# 소개

[`Basics`][basics] 개념에서는 함수를 정의하는 두 가지 방법을 소개했어요.

가장 일반적인 것은 여러 줄로 쓰는 형태예요.

```julia
function muladd(x, y, z)
    x * y + z
end
```

짧은 정의를 위한 "할당" 형태, 즉 "한 줄" 형태도 있어요.
```julia
muladd(x, y, z) = x * y + z
```

세 번째로, 더 짧은 형태에서는 짧고 한 번만 쓰는 함수를 이름 없이 만들 수 있어요.

```julia-repl
julia> map(x -> 2x, 1:3)
4-element Vector{Int64}:
 2
 4
 6

julia> map((x, y) -> x * y, 1:3, 4:6)
3-element Vector{Int64}:
  4
 10
 18
```

이 경우 `x -> 2x`는 "익명 함수"예요.
다른 언어에서 "람다 함수"라고 부르는 것과 같아요.

인자가 여러 개면 `(x, y) -> x * y`처럼 괄호가 필요하다는 점에 주의해요.

익명 함수는 Julia 코드에서 흔히 쓰여요. 특히 `map()`이나 `filter()` 같은 고차 함수와 결합할 때 자주 보이죠(이 둘은 나중에 나오는 개념에서 더 자세히 다뤄요).

```julia-repl
julia> map(x -> x^4, [1, 2, 3])
3-element Vector{Int64}:
  1
 16
 81
```

## 함수 인자

지금까지 이 과정에서는 인자의 개수가 정확히 정해져 있고, 함수를 호출할 때 그 인자를 모두 올바른 순서로 넘겨야 하는 함수만 살펴봤어요.
그러면 제한적이고 불편하겠죠. 그래서 다른 방법들도 몇 가지 있어요.

### 선택적 인자

많은 언어와 마찬가지로, Julia에서는 함수 정의에서 개별 인자의 기본값을 지정할 수 있어요.

그러면 함수를 호출할 때 그 인자에 값을 넘겨도 되고, 생략하고 기본값을 쓰게 할 수도 있어요.

```julia-repl
julia> f(x, y=10) = x * y
f (generic function with 2 methods)

julia> f(2, 3)
6

julia> f(2)
20
```

기본값이 _없는_ 인자는 기본값이 _있는_ 인자보다 항상 앞에 와야 해요. 따라서 `f(x=2, y)`는 올바르지 않아요.

### 키워드 인자

지금까지 나온 예제는 모두 `positional arguments`를 사용했어요. 함수를 호출할 때 넘기는 값이 함수 정의에 있는 해당 인자의 순서와 일치해야 하죠.

많은 언어와 마찬가지로, Julia는 `keyword arguments`도 지원해요.
함수를 호출할 때는 인자 이름을 반드시 적어야 하지만, 키워드 인자가 여러 개라면 순서는 아무렇게나 정해도 돼요.

Julia의 독특한 점은 함수 정의에서 키워드 인자(있다면) 앞에 세미콜론 `;`을 붙여 위치 인자와 구분해야 한다는 거예요.
함수를 호출할 때 마지막 위치 인자와 첫 키워드 인자 사이에는 `;`나 `,` 중 아무거나 써도 돼요.

```julia-repl
julia> b(x; y) = x + y
b (generic function with 1 method)

julia> b(2, y=3)
5

# keyword is required when calling
julia> b(2, 3)
ERROR: MethodError: no method matching b(::Int64, ::Int64)
The function `b` exists, but no method is defined for this combination of argument types.
```

위치 인자와 똑같이, 기본값을 지정할 수도 있어요.

매개변수와 이름이 같은 변수를 미리 계산해 둔 경우, 함수 호출에서 `myarg=myarg` 같은 문법을 쓰게 되는 일이 흔해요.
이런 상황에서는 축약 문법을 쓸 수 있어요.

```julia-repl
julia> width = 4.0
4.0

julia> height = √ width
2.0

julia> area(; width, height) = width * height
area (generic function with 1 method)

# repetition
julia> area(; width=width, height=height)
8.0

# shorthand form
julia> area(; width, height)
8.0
```

### 스플랫과 슬러프

혹시 궁금했다면, 이 둘은 Julia 문법의 유용한 기능에 붙은 표준 이름이에요.
둘 다 `...` 연산자를 가리켜요.

#### 스플랫

스플랫은 함수를 _호출할_ 때, 컬렉션을 함수가 필요로 하는 개별 값들로 펼치는 데 써요.

설명하는 것보다 보여주는 게 이해하기 쉬울 거예요.

```julia-repl
julia> fxyz(x, y, z) = x * y * z
fxyz (generic function with 1 method)

julia> xyz = [2, 3, 4]
3-element Vector{Int64}:
 2
 3
 4

# Using the vector directly in a function call is invalid
julia> fxyz(xyz)
ERROR: MethodError: no method matching fxyz(::Vector{Int64})
The function `fxyz` exists, but no method is defined for this combination of argument types.

# splatting converts the vector to 3 numbers, used as positional arguments
julia> fxyz(xyz...)
24
```

일부 "함수 호출"은 문법 설탕에 숨어 있어서, 스플랫을 덜 뻔한 방식으로도 쓸 수 있어요.

예를 들어, 다중 할당은 내부적으로 튜플 생성자 함수를 사용해요.

```julia-repl
julia> first, rest... = [1, 2, 3, 4]
4-element Vector{Int64}:
 1
 2
 3
 4

julia> first
1

julia> rest
3-element Vector{Int64}:
 2
 3
 4
```

키워드 인자도 스플랫으로 넘길 수 있는데, 보통 `named tuple`을 써요.
`Dict`도 되지만 키는 심볼이어야 해요(문자열은 안 돼요).

```julia-repl
# function with 3 keyword arguments
julia> fabc(; a, b, c) = a + b + c
fabc (generic function with 1 method)

# named tuple
julia> abc_nt = (a=2, b=3, c=4)
(a = 2, b = 3, c = 4)

# there are no positional arguments, so need to use ; before kw argument
julia> fabc(;abc_nt...)
9

# Dict
julia> abc_dict = Dict(:a=>2, :b=>3, :c=>4)
Dict{Symbol, Int64} with 3 entries:
  :a => 2
  :b => 3
  :c => 4

julia> fabc(;abc_dict...)
9
```

#### 슬러프

슬러프는 함수를 _정의할_ 때, 임의 개수의 개별 값들을 하나의 컬렉션으로 묶는 데 써요.

```julia-repl
julia> f_more(i, j, more...) = i + j + sum(more)
f_more (generic function with 1 method)

julia> f_more(1, 3, 5, 7, 9, 11)
36
```

슬러프된 인자의 이름(여기서는 `more`)은 중요하지 않아요.
이 변수의 타입은 컴파일러가 정하는데, 위치 인자라면 아마 `tuple`이나 비슷한 것이 될 거예요.

키워드 인자도 슬러프할 수 있고, 그러면 `Dict`(또는 비슷한 것)가 돼요.

```julia-repl
julia> f_kwslurp(x, y; switches...) = :mult in keys(switches) ? x * y : x + y
f_kwslurp (generic function with 1 method)

julia> f_kwslurp(5, 6; mult=true)
30

julia> f_kwslurp(5, 6)
11
```

호출할 때는 어떤 키워드 인자든 쓸 수 있어요.
그중 어떤 키워드에 반응하고 어떤 것을 무시할지는 함수 정의가 정해요.
