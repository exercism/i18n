# 삼항 연산자

삼항 연산자는 `if..else..` 비교를 수행하고 값을 반환하는 또 다른 문법을 제공해요.

## 문법

PHP에는 조건이 참으로 취급되는지에 따라 동작을 평가할 수 있는 `if`문이 있어요.

```php
if ($condition) {
  $value = 1;
} else {
  $value = 2
}
```

또는 삼항 연산자로 같은 동작을 나타낼 수도 있어요.

```php
$value = $condition
  ? 1  // True branch
  : 2; // False branch
```

비교 문법은 짧아요. `(condition) ? (evaluate if true) : (evaluate if false);`로 나타내요.
