# 소개

## 배열 컴프리헨션

컴프리헨션은 _Enumerable_을 쉽고 선언적으로 변환하는 기능을 제공해요.

아주 간단한 컴프리헨션을 선언하려면, `for` 키워드 뒤에 _제너레이터_와 열거된 값에서 새로운 값을 만드는 _do 블록_을 사용하면 돼요.

```elixir
for n <- [0, 1, 2, 3], do: n + 1
# => [1, 2, 3, 4]
```

컴프리헨션에는 _필터_를 둘 수도 있어요. 필터를 통과하지 못한 값은 최종 배열에서 제거돼요:

```elixir
for n <- [0, 1, 2, 3], n > 1, do: n + 1
# => [3, 4]
```

여러 줄에 걸쳐 더 복잡한 컴프리헨션을 선언할 수 있어요:

```elixir
for {atom, number} <- [a: 1, b: 2, c: 3, d: 4],
    rem(number, 2) == 0 do
  atom
end

# => [:b, :d]
```

_카테시안 곱_은 여러 제너레이터를 사용해 만들 수 있어요. 즉, 첫 번째 제너레이터가 생성한 각 값은 두 번째 제너레이터가 생성한 각 값과 한 번씩 짝을 이뤄요:

```elixir
for x <- [0, 1],
    y <- [0, 1] do
  {x, y}
end

# => [{0, 0}, {0, 1}, {1, 0}, {1, 1}]
```
