# Instructions

이 연습 문제에서는 고등학교 커플이 소셜 미디어에서 사랑을 고백할 수 있도록 도와봐요.

## 1. 커플의 이름을 하트로 구분해 표시하기

두 이름을 받아 하트로 구분해 표시하는 정적 `HighSchoolSweethearts.DisplaySingleLine()` 메서드를 구현해 보세요.
서식이 적용된 텍스트는 61자 너비여야 하고, 하트는 문자열의 가운데에 있어야 해요.

어떤 이름이든 줄 너비 안에 넉넉히 들어간다고 보장돼요.

```csharp
HighSchoolSweethearts.DisplaySingleLine("Lance Green", "Pat Riley");
// => "                  Lance Green ♡ Pat Riley                    "
```

## 2. 커플의 이니셜을 아스키 아트 하트로 표시하기

두 사람의 이니셜을 플러스 기호로 구분해 표시하는 정적 `HighSchoolSweethearts.DisplayBanner()` 메서드를 구현해요.

```csharp
HighSchoolSweethearts.DisplayBanner("L. G.", "P. R.");
// see the ascii art below
```

## 3. 독일 교환학생들도 로캘을 고려한 서식 덕분에 편안함을 느낄 수 있게 하기

독일에서 온 교환학생들을 위해 교제 시작일과 교제 기간을 보여주는 정적 `HighSchoolSweethearts.DisplayGermanExchangeStudents()` 메서드를 구현해요.

```csharp
HighSchoolSweethearts.DisplayGermanExchangeStudents("Norbert", "Heidi", new DateTime(2019, 1, 22), 1535.22f);
// => "Norbert and Heidi have been dating since 22.01.2019 - that's 1.535,22 hours"
```
