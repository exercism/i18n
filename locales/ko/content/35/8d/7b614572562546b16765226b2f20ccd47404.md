# 타입 명세 사용

[comment]: # (이 경고는 풀이에 타입 명세가 없을 때 나타나요)

함수의 입력과 출력 사이의 계약을 알려주려면 [타입 명세](https://elixir-lang.org/getting-started/typespecs-and-behaviours.html#types-and-specs)(`@spec`)를 작성해요.

- Elixir는 동적 타입 언어라서 타입 검사가 실행 시점에만 일어나요. 타입 명세를 사용하면 [`Dialyxir`](https://hexdocs.pm/dialyxir/readme.html) 같은 린터와 정적 분석 도구(Erlang의 [`Dialyzer`](http://erlang.org/doc/man/dialyzer.html) 기반)가 코드에 의도하지 않은 동작이 있는지 평가할 수 있어요.
- 모든 내장 타입의 [전체 목록](https://hexdocs.pm/elixir/typespecs.html#basic-types)은 [언어 문서](https://hexdocs.pm/elixir/typespecs.html#content)에서 볼 수 있어요.
- 타입은 괄호를 붙이거나 붙이지 않고 명세할 수 있어요: `atom()` vs `atom`
  - Exercism Elixir 스타일은 괄호 없이 명세하는 거예요.

```elixir
# Example 1
@spec add_one(int) :: int
def add_one(n) when is_integer(n) do
  n + 1
end

# Example 2
@spec hello(String.t) :: String.t
def hello(what \\ "world") when is_binary(what) do
  "Hello, #{what}"
end
```
