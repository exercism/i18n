# 소개

이 연습 문제에서는 메서드 매개변수의 몇 가지 세부 사항과 C#에서의 사용법을 다뤄요.

매개변수는 호출하는 메서드에서 호출된 메서드로 정보를 전달해요.

- 매개변수의 동작은 `ref`와 `out` 같은 한정자를 사용해 바꿀 수 있어요.

- `out` 한정자가 붙은 매개변수는 호출된 메서드에서 호출한 쪽으로 값을 다시 전달해요. 이 매개변수는 초기화하지 않고도 호출된 메서드에 전달할 수 있으며, 어느 경우든 호출된 메서드 안에서는 진입 시점에 초기화되지 않은 것처럼 취급돼요. 매개변수 한정자의 동작과 규칙은 예제(아래 참고)와 컴파일러 메시지를 통해 가장 쉽게 이해할 수 있어요.

```csharp
void Foo(out int val)
{
    val = 42;
}
void Bar(int val)
{
    val = 42;
}

int importantValue = 1729;
Foo(out importantValue);
var result = importantValue == 42;
// => true

importantValue = 1729;
Bar(importantValue);
result = importantValue == 1729;
// => true
```

- `out` 매개변수는 호출된 메서드 안에서 반드시 값을 할당해야 해요.

- `ref` 한정자가 붙은 매개변수는 값을 호출된 메서드로 전달해요. 메서드가 반환되면 호출한 쪽은 호출된 메서드가 그 매개변수에 가한 변경 사항을 확인할 수 있어요.

```csharp
void Foo(ref int val)
{
    val *= 7;
}

int importantValue = 6;
Foo(ref importantValue);
return importantValue;
// => 42
```

- `ref` 매개변수는 변수여야 해요. 호출된 메서드가 호출한 쪽에서 보이는 바로 그 매개변수를 직접 다루기 때문이에요.
- `out`과 `ref` 한정자는 호출된 메서드 시그니처와 호출하는 위치 모두에 필요해요.
