# 소개

Factor에서 대부분의 데이터는 *시퀀스*에 있어요. 배열, 벡터, 문자열은 모두 시퀀스이고, [`sequences`][sequences] 보카뷸러리에 있는 공통된 단어 집합을 공유해요.

## 배열 리터럴

리터럴 배열은 `{ }`를 사용하고, 원소 사이에 공백을 넣어요:

```factor
{ 1 2 3 } .          ! => { 1 2 3 }
{ "a" "b" "c" } .    ! => { "a" "b" "c" }
```

배열은 길이가 고정되어 있어서, 원소 개수를 바꾸는 `suffix`나 `remove-nth` 같은 단어는 원래 배열을 늘리는 대신 *새로운* 시퀀스를 반환해요.

## 길이와 인덱싱

```
length   ( seq -- n   )
first    ( seq -- elt )
rest     ( seq -- tailseq )    ! everything but the first element
last     ( seq -- elt )
but-last ( seq -- headseq )    ! everything but the last element
nth      ( n seq -- elt )      ! 0-based
?nth     ( n seq -- elt/f )    ! 0-based; f when out of bounds
```

```factor
{ 10 20 30 } length .       ! => 3
{ 10 20 30 } first .        ! => 10
{ 10 20 30 } rest .         ! => { 20 30 }
{ 10 20 30 } last .         ! => 30
{ 10 20 30 } but-last .     ! => { 10 20 }
1 { 10 20 30 } nth .        ! => 20
```

`?nth`는 범위를 안전하게 처리하는 버전이에요. 길이를 먼저 확인하지 않고도 위치를 조회할 수 있어요.

```factor
1 { 10 20 30 } ?nth .       ! => 20
9 { 10 20 30 } ?nth .       ! => f  (out of bounds, no error)
```

## 슬라이싱

```
head ( seq n -- headseq )    ! first n elements
tail ( seq n -- tailseq )    ! drop first n
```

```factor
{ 1 2 3 4 5 } 3 head .   ! => { 1 2 3 }
{ 1 2 3 4 5 } 3 tail .   ! => { 4 5 }
```

둘 다 `n`이 시퀀스보다 크면 오류를 발생시켜요. `n`이 너무 크면 `index-or-length`가 이를 시퀀스의 길이로 줄여서, 뒤따르는 슬라이스가 끝을 넘어가지 않게 해요:

```
index-or-length ( seq n -- seq n' )
```

```factor
{ 10 20 30 40 50 } 3 index-or-length head .   ! => { 10 20 30 }
{ 10 20 } 3 index-or-length head .            ! => { 10 20 }
```

별표가 붙은 변형인 `head*`와 `tail*`는 끝에서부터 세요. `head*`는 마지막 `n`개를 버리고, `tail*`는 마지막 `n`개를 유지해요:

```
head* ( seq n -- headseq )   ! everything except the last n
tail* ( seq n -- tailseq )   ! the last n elements
```

```factor
{ 1 2 3 4 5 } 2 head* .   ! => { 1 2 3 }
{ 1 2 3 4 5 } 2 tail* .   ! => { 4 5 }
```

두 인덱스 사이의 임의 슬라이스의 경우, `subseq`는 *시작*(포함)과 *끝*(미포함)을 받아요:

```
subseq ( from to seq -- subseq )
```

```factor
1 4 { 10 20 30 40 50 } subseq .   ! => { 20 30 40 }
1 4 "hello" subseq .              ! => "ell"
```

*시작과 길이*가 있을 때는 둘을 더해서 끝을 구해요:

```factor
2 dup 3 + "hello world" subseq .  ! => "llo"
```

(즉, 인덱스 범위 `[2, 5)`로, 위치 2에서 시작하는 세 문자예요.)

반대 질문, 즉 하위 시퀀스가 *어디에* 나타나는지는 `subseq-index`가 답해요. 첫 번째 일치의 시작 인덱스를 반환하고, 없으면 `f`를 반환해요:

```
subseq-index ( seq subseq -- i/f )
```

```factor
"hello world" "o w" subseq-index .   ! => 4
"hello world" "xyz" subseq-index .   ! => f
```

## 패딩

```
pad-head ( seq n elt -- padded )    ! prepend copies of elt
pad-tail ( seq n elt -- padded )    ! append copies of elt
```

둘 다 `seq`의 길이가 적어도 `n`이 될 때까지 확장해요. `seq`가 이미 그만큼 길면 그대로 반환해요.

```factor
{ 2 5 0 } 6 0 pad-tail .   ! => { 2 5 0 0 0 0 }
{ 4 1 } 5 9 pad-head .     ! => { 9 9 9 4 1 }
```

## 같은 단어가 문자열에서도 작동해요

문자열은 문자의 시퀀스이므로, 위의 모든 것이 문자열에서도 작동해요. 결과는 배열 대신 또 다른 문자열일 뿐이에요:

```factor
"hello" length .            ! => 5
"hello" 3 head .             ! => "hel"
"abc" 6 CHAR: . pad-tail .   ! => "abc..."
```

## 집계

`sum`과 `product`는 ([`sequences`][sequences]에 있는) 숫자 시퀀스의 원소를 더하거나 곱해요:

```factor
{ 2 5 0 7 } sum .        ! => 14
{ 2 5 3 7 } product .    ! => 210
```

`count`는 시퀀스에 조건자를 실행하고, 참이 된 원소가 몇 개인지 반환해요:

```
count ( seq quot -- n )
```

```factor
{ 2 5 0 7 4 1 } [ even? ] count .    ! => 3
```

## 전체 시퀀스에 대한 조건자

```
any?   ( seq quot -- ? )
all?   ( seq quot -- ? )
empty? ( seq -- ? )
```

```factor
{ 2 5 0 7 } [ 4 > ] any? .      ! => t
{ 2 5 0 7 } [ 0 > ] all? .      ! => f
```

## 새로운 시퀀스 만들기

`suffix`는 시퀀스 끝에 원소를 추가하고, `prefix`는 앞에 추가해요. `unclip`은 첫 번째 원소를 떼어내고, `unclip-last`는 마지막 원소를 떼어내요:

```
prefix      ( seq elt -- newseq )
suffix      ( seq elt -- newseq )
unclip      ( seq -- rest first )
unclip-last ( seq -- butlast last )
```

```factor
{ 7 9 } 3 prefix .             ! => { 3 7 9 }
{ 7 9 } 3 suffix .             ! => { 7 9 3 }
{ 4 0 9 } unclip .s
! => { 0 9 }
! => 4
```

`unclip-last`와 `suffix`를 조합하면 마지막 원소를 비파괴적으로 업데이트할 수 있어요 (`unclip` + `prefix`는 첫 번째 원소에 대해 같은 일을 해요):

```factor
{ 10 20 30 } unclip-last 2 * suffix .
! => { 10 20 60 }
```

## 시퀀스 타입 간 강제 변환

`>array`, `>vector`, `>string`은 ([`arrays`][arrays] 및 해당 보카뷸러리에 있는) 시퀀스를 특정 구체적 타입으로 강제 변환해요. 어떤 연산이 슬라이스나 일반 시퀀스를 반환했는데 배열(또는 문자열)로 되돌려야 할 때 유용해요.

```factor
{ 1 2 3 } 1 tail >array .   ! => { 2 3 }
"hello" >array .            ! => { 104 101 108 108 111 }
{ 65 66 67 } >string .      ! => "ABC"
```
