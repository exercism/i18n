# 지시 사항

뉴욕의 뷰티 살롱은 Booking Up For Beauty 연습 문제에서 도와드렸던 그 살롱인데, 그동안 잘 운영되어서 많은 손님이 단골이 되었어요.
단골손님은 방문할 때마다 따로 예약하는 대신 "격주 화요일마다", "매달 마지막 금요일"처럼 정해진 규칙으로 예약해요.
사장님이 이런 규칙에 해당하는 날짜와 살롱 자체의 월간 정기 업무 날짜를 계산해 주는 도우미를 만들어 달라고 했어요.

## 1. 단골손님의 정기 예약 날짜 찾기

연도, 월, 몇 번째인지(`1`은 첫 번째, `2`는 두 번째 등)와 요일을 받는 `SalonCalendar.standingAppointment()` 메서드를 구현해요.
이 메서드는 그 달 안에서 해당 요일이 그 순서로 오는 날의 날짜를 반환해요:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.standingAppointment(2024, Month.AUGUST, 2, DayOfWeek.TUESDAY);
// => LocalDate.of(2024, 8, 13)
```

## 2. 단골손님의 월말 예약 날짜 찾기

어떤 단골손님은 자기 요일이 그 달에 마지막으로 오는 날을 더 좋아해요.
연도, 월, 요일을 받아 그 달 안에서 해당 요일이 마지막으로 오는 날의 날짜를 반환하는 `SalonCalendar.lastAppointment()` 메서드를 구현해요:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.lastAppointment(2024, Month.AUGUST, DayOfWeek.FRIDAY);
// => LocalDate.of(2024, 8, 30)
```

## 3. 예약 없이 방문한 손님을 위한 다음 날 찾기

카운터에서 손님이 "다음 토요일"로 예약을 원해요.
문의한 날이 이미 토요일이라면 바로 그날을 뜻해요.
날짜와 요일을 받아, 주어진 날짜 당일 또는 그 이후에 해당 요일이 처음 오는 날짜를 반환하는 `SalonCalendar.nextAvailable()` 메서드를 구현해요:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.nextAvailable(LocalDate.of(2024, 8, 15), DayOfWeek.SATURDAY);
// => LocalDate.of(2024, 8, 17)
calendar.nextAvailable(LocalDate.of(2024, 8, 17), DayOfWeek.SATURDAY);
// => LocalDate.of(2024, 8, 17)
```

## 4. 장부 마감 날짜 찾기

살롱은 매달 마지막 날에 장부를 마감해요.
그런데 주말에는 문을 닫기 때문에, 그 달의 마지막 날이 토요일이나 일요일이면 그 전 금요일에 장부를 마감해요.
연도와 월을 받아 그 달의 장부 마감 날짜를 반환하는 `SalonCalendar.bookkeepingDay()` 메서드를 구현해요:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.bookkeepingDay(2024, Month.SEPTEMBER);
// => LocalDate.of(2024, 9, 30)
calendar.bookkeepingDay(2024, Month.AUGUST);
// => LocalDate.of(2024, 8, 30)
```

## 5. 주말 규칙을 재사용해 급여일 정하기

직원들은 매달 15일에 급여를 받는데, 여기에도 같은 주말 규칙이 적용돼요. 15일이 토요일이나 일요일이면 급여일은 그 전 금요일이에요.
규칙을 두 번 작성하지 말고, 재사용할 수 있는 조정자로 만들어 봐요.

평일은 그대로 두고 토요일이나 일요일을 그 전 금요일로 옮기는 `TemporalAdjuster`를 반환하는 `SalonCalendar.precedingWorkday()` 메서드를 구현해요.
그다음 이 조정자를 사용해서, 연도와 월을 받는 `SalonCalendar.payday()` 메서드를 구현해요:

```java
SalonCalendar calendar = new SalonCalendar();
LocalDate.of(2024, 6, 15).with(calendar.precedingWorkday());
// => LocalDate.of(2024, 6, 14)
calendar.payday(2024, Month.JUNE);
// => LocalDate.of(2024, 6, 14)
calendar.payday(2024, Month.AUGUST);
// => LocalDate.of(2024, 8, 15)
```

`bookkeepingDay()`로 돌아가서 이 조정자를 사용하도록 바꿔도 좋아요.
