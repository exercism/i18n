# 테스트

## 모든 테스트 실행하기

`t/` 디렉터리에 `.t` 확장자를 가진 Perl 스크립트가 있는데, 이 스크립트로 풀이를 테스트해요.
다음 명령으로 테스트를 실행할 수 있어요:

`prove`

연습 문제를 시작하기 전에는 출력이 대략 이렇게 보일 거예요:

```
./t/hello-world.t .. 1/2
# Failed test 'Say Hi!'
# at exercises/hello-world/t/hello-world.t line 15.
# +---------+---------------+
# | GOT     | CHECK         |
# +---------+---------------+
# | <UNDEF> | Hello, World! |
# +---------+---------------+
exercises/hello-world/t/hello-world.t .. Dubious, test returned 1 (wstat 256, 0x100)
Failed 1/2 subtests

Test Summary Report
-------------------
./t/hello-world.t (Wstat: 256 Tests: 2 Failed: 1)
  Failed test:  2
  Non-zero exit status: 1
Files=1, Tests=2,  0 wallclock secs ( 0.03 usr  0.00 sys +  0.18 cusr  0.02 csys =  0.23 CPU)
Result: FAIL
```

`lib/` 디렉터리에 있는 `.pm` 확장자를 가진 모듈을 수정하고, 테스트를 통과하는 풀이를 작성해야 해요.
테스트가 통과되면, 위 명령의 출력은 대략 이렇게 보일 거예요:

```
./t/hello-world.t .. ok
All tests successful.
Files=1, Tests=2,  0 wallclock secs ( 0.02 usr  0.00 sys +  0.07 cusr  0.01 csys =  0.10 CPU)
Result: PASS
```

테스트 파일에서 사용하는 단언에 대한 문서는 [Test2::Manual::Testing::Introduction][test2-manual]에서 찾을 수 있어요.
`Test2`에 대한 더 자세한 설명은 [perldoc][test2]에서 볼 수 있어요.

[test2-manual]: https://metacpan.org/pod/Test2::Manual::Testing::Introduction
[test2]: https://perldoc.perl.org/Test2
