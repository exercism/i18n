# 소개

## 비교 연산자

[비교 연산자][comparison-operators]는 같은 타입의 두 값을 비교하고 `Bool` 값(`true` 또는 `false`)을 반환해요.
서로 다른 타입의 값을 비교하려고 하면 컴파일러가 오류를 발생시켜요.

Swift의 표준 비교 연산자는 다음과 같아요:

| 연산자 | 설명              | 예시         |
| -------- | ------------------------ | --------------- |
| `==`     | 같음                 | `1 == 1` (true) |
| `!=`     | 같지 않음                 | `1 != 2` (true) |
| `<`      | 보다 작음                | `4 < 5`  (true) |
| `<=`     | 보다 작거나 같음    | `4 <= 4` (true) |
| `>`      | 보다 큼                | `3 > 1`  (true) |
| `>=`     | 보다 크거나 같음 | `2 >= 2` (true) |

## `if`문과 `else`문

[조건문][conditional-statement]은 조건이 `true`로 평가되는지 `false`로 평가되는지에 따라 코드를 실행해요.
가장 흔한 조건문은 [`if`문][if]으로, 조건이 `true`일 때만 코드 블록을 실행해요.
`if`문은 `if` 키워드로 시작하고, 그 뒤에 조건과 중괄호로 감싼 코드 블록을 써요:

```swift
let wheelCount = 4
if wheelCount == 4 {
    print("Your vehicle is a car")
}
// Prints "Your vehicle is a car"
```

`if`에 `else` 절을 붙이면 조건이 `false`일 때 다른 코드를 실행할 수 있어요:

```swift
let precipitationInMM = 0.5
if precipitationInMM > 0.5 {
    print("You will need an umbrella")
} else {
    print("You will not need an umbrella")
}
// Prints "You will not need an umbrella"
```

여러 조건을 차례로 검사하려면 `else if`로 문을 이어 붙여요.
`if`문에는 `else` 분기가 꼭 필요하지는 않지만, 어떤 조건에도 맞지 않는 경우를 처리하려면 넣을 수 있어요:

```swift
let favoriteFruit = "Apple"

if favoriteFruit == "Banana" {
    print("Your favorite fruit is a banana")
} else if favoriteFruit == "Orange" {
    print("Your favorite fruit is an orange")
} else if favoriteFruit == "Apple" {
    print("Your favorite fruit is an apple")
} else {
    print("Your favorite fruit is not a banana, orange, or apple")
}
// Prints "Your favorite fruit is an apple"
```

## `if` 표현식

최신 Swift에서는 `if`문을 값을 만들어 내는 표현식으로도 사용할 수 있어요.
각 분기가 값으로 평가되기 때문에 조건에 따라 결과를 쉽게 대입할 수 있어요:

```swift
let cpuBits = 32
let architecture = if cpuBits == 64 {
    "x86_64"
} else {
    "x86_32"
}

print(architecture)
// Prints "x86_32"
```

## 삼항 연산자

[삼항 조건 연산자][ternary-operator]는 `if-else` 표현식을 간결하게 줄여 쓴 형태예요.
조건을 평가하고, 그 조건이 `true`인지 `false`인지에 따라 두 값 중 하나를 반환해요.

이 연산자는 `condition ? trueExpression : falseExpression`처럼 세 부분으로 이루어져 있어요.
`condition`이 `true`로 평가되면 `trueExpression`이 평가되어 반환되고, 그렇지 않으면 `falseExpression`이 평가되어 반환돼요.

삼항 연산자는 간단한 한 줄짜리 선택에 딱 맞아요:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = showFahrenheit ? temperatureInCelsius * 9 / 5 + 32 : temperatureInCelsius
print(temperature)
// Prints 86
```

위 예시는 다음 코드를 간결하게 표현한 것과 같아요:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = if showFahrenheit {
    temperatureInCelsius * 9 / 5 + 32
} else {
    temperatureInCelsius
}
```
