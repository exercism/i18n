# 소개

Common Lisp에서 시간은 세 가지 방식으로 표현해요.

- 유니버설 타임은 절대 시각으로, `1900-01-01T00:00:00Z`(UTC 기준 1900년 1월 1일 자정) 이후 지난 초의 개수를 나타내는 정수예요.
- 디코딩된 시간은 9개 값으로 이루어진 튜플로, 이 값들이 모여 특정 달력 시각을 나타내요: 초, 분, 시, 일, 월, 년, 요일, 서머타임 플래그, 시간대.
(아래에서 자세히 다뤄요.)
- 내부 시간은 구현에서 정의한 '내부 시간 단위'의 개수로 나타낸 양의 정수로, 실행 시간을 측정하는 데 쓸 수 있어요.

## 유니버설 타임

현재 유니버설 타임을 구하려면 `get-universal-time`이나 `get-decoded-time`을 사용해요.
전자는 `1900-01-01T00:00Z` 이후 지난 현재 초를 반환하고, 후자는 같은 데이터를 디코딩된 형식으로 반환해요.

참고로, 이 수는 양의 정수이기 때문에 1900년 이전의 날짜는 인코딩할 수 없어요.

## 디코딩된 시간

`decode-universal-time`과 `encode-universal-time`은 시간을 다루는 기본 함수예요.
전자는 유니버설 타임을 받아 디코딩된 시간 값을 [다중 값][concept-multiple-values]으로 반환하고, 후자는 디코딩된 시간 값들을 인자로 받아 유니버설 타임을 반환해요.

둘 다 선택적인 시간대 인자를 받아요.
시간대의 형식은 아래를 참고해요.

디코딩된 시간은 다음과 같은 값들로 이루어져 있어요.

- *초*: 0에서 59 사이의 정수
- *분*: 0에서 59 사이의 정수
- *시*: 0에서 23 사이의 정수
- *일*: 1에서 31 사이의 정수(물론 상한은 월과 년에 따라 달라져요)
- *월*: 1에서 12 사이의 정수
- *년*: 연도를 나타내는 정수.
- *요일*: 0에서 6 사이의 정수. 0은 월요일, 1은 화요일, ... 6은 일요일을 뜻해요.
- *서머타임 플래그*: 값이 참이면 서머타임이 적용 중이라는 뜻이에요.
- *시간대*: UTC로부터의 오프셋을 나타내는 -24에서 24 사이의 시간 값이에요.
이 값은 유리수이며 `1/3600`의 배수여야 해요.

```lisp
(encode-universal-time 1 2 3 4 5 2000 0) ; => 3166398121
(decode-universal-time 3166398121 0)     ; => 1
                                         ;    2
                                         ;    3
                                         ;    4
                                         ;    5
                                         ;    2000
                                         ;    3 (Thursday)
                                         ;    NIL
                                         ;    0
(decode-universal-time 2208988800 0)     ; => 0
                                         ;    0
                                         ;    0
                                         ;    1
                                         ;    1
                                         ;    1970
                                         ;    3
                                         ;    NIL
                                         ;    0
```

시간대 매개변수를 제공하지 않았을 때 나타나는 흥미로운 동작이 있다는 점을 알아둬요.
자세한 내용은 [`decode-universal-time`][hyperspec-decode-universal-time]과 [`encode-universal-time`][hyperspec-encode-universal-time] 문서를 참고해요.

## 내부 시간

내부 시간은 '내부 시간 단위'의 개수로 나타낸 양의 정수예요. 두 내부 시간의 차이를 이용하면 실행 중에 시간을 측정할 수 있어요.

- `get-internal-real-time`은 현재의 "실제" 시간, 즉 "시계" 시간을 반환해요.
- `get-internal-run-time`은 구현에 크게 의존하며, 예를 들어 페이징이나 가비지 컬렉션에 쓰인 시간을 포함할 수도 있고 아닐 수도 있어요.

변수 `internal-time-units-per-second`에는 현재 실행 중인 Lisp 환경의 초당 '내부 시간 단위' 개수가 담겨 있어요.
