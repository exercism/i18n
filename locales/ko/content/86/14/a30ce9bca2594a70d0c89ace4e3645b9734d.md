# 지침 부록

## 힌트

`Int`와 `String`을 받아 회전 암호로 인코딩하는 `rotate` 함수를 구현해야 해요.
타입이 확실하지 않다면 제공된 시그니처를 사용해도 되지만, 그것이 창의력을 제한하도록 두지는 마세요.

이 연습 문제는 텍스트 데이터를 다뤄요. 역사적인 이유로 Haskell의 `String` 타입은
`[Char]`, 즉 문자의 리스트와 같은 의미예요. 텍스트 데이터를 더 효율적으로 다루려면
`Text` 타입을 사용할 수 있어요.

이 연습 문제의 선택적인 확장으로, 다음과 같은 것도 해볼 수 있어요.

- Haskell의 [문자열 타입](https://haskell-lang.org/tutorial/string-types)에 대해 읽어 봐요.
- package.yaml의 의존성 목록에 `- text`를 추가해요.
- [다음과 같은 방식](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c)으로 `Data.Text`를 임포트해요.

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- `Text` 타입을 예를 들어 `rotate :: Int -> Text -> Text`처럼 사용하고, `Data.Text`의 컴비네이터는 예를 들어 `T.pack`처럼 참조해요.
- [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html) 문서를 찾아봐요.
- RotationalCipher.hs에서 모든 `String`을 `Text`로 바꿔요. 즉:

```haskell
rotate :: Int -> Text -> Text
```

이 부분은 전부 선택 사항이에요.
