# 테스트

다음 명령으로 테스트를 실행해요:

```shell
phpunit test_file.php
```

예를 들어, Hello World 연습 문제의 테스트를 실행하려면 다음과 같이 해요:

```shell
phpunit HelloWorldTest.php
```
