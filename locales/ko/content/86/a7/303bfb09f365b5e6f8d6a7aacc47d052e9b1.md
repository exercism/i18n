# 테스트

테스트를 실행하려면, 연습 문제의 테스트 러너 파일을 어셈블해서 MARS 시뮬레이터 GUI로 실행하거나 명령줄에서 실행해요. 명령줄에서 실행하려면 다음처럼 러너 파일을 먼저 지정하고, 그다음에 구현을 지정해요:

    java -jar /path/to/mars.jar nc runner.mips impl.mips

GUI에서 실행하려면, "runner.mips"의 마지막 줄에 있는 주석을 풀어 구현을 파일 맨 아래에 `include`해요.

테스트 러너는 “success” 메시지와 함께 끝나거나, 실패한 테스트에서 멈추면서 그 테스트가 실패한 입력을 알려주는 메시지를 내요.
