# 지침

이 연습 문제에서는 2012년 9월 15일에 문을 연 뉴욕의 한 미용실에서 사용할 예약 스케줄러를 만들어 봐요.

네 가지 과제가 있고, 모두 예약 날짜와 관련되어 있어요. 날짜와 시간은 다음 세 가지 형식 중 하나를 사용해요:

- `"7/25/2019 13:45:00"`
- `"July 25, 2019 13:45:00"`
- `"Thursday, July 25, 2019 13:45:00"`

테스트는 문화권을 자동으로 `en-US`로 설정해요. 문화권을 직접 설정하거나 지정할 필요는 없어요.

## 1. 예약 날짜 파싱하기

예약 날짜의 텍스트 표현을 그에 해당하는 `DateTime` 형식으로 파싱하는 (_정적_) `Appointment.Schedule()` 메서드를 구현해요:

```csharp
Appointment.Schedule("7/25/2019 13:45:00")
// => new DateTime(2019, 7, 25, 13, 45, 0)
```

## 2. 예약이 이미 지났는지 확인하기

예약 날짜를 받아서 그 예약이 과거에 있었는지 확인하는 (_정적_) `Appointment.HasPassed()` 메서드를 구현해요:

```csharp
Appointment.HasPassed(new DateTime(1999, 12, 31, 9, 0, 0))
// => true
```

## 3. 예약이 오후인지 확인하기

예약 날짜를 받아서 그 예약이 오후인지(12:00 이상, 18:00 미만) 확인하는 (_정적_) `Appointment.IsAfternoonAppointment()` 메서드를 구현해요:

```csharp
Appointment.IsAfternoonAppointment(new DateTime(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. 예약의 시간과 날짜 설명하기

예약 날짜를 받아서 그 날짜와 시간에 대한 설명을 반환하는 (_정적_) `Appointment.Description()` 메서드를 구현해요:

```csharp
Appointment.Description(new DateTime(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on 3/29/2019 3:00:00 PM."
```

## 5. 기념일 날짜 반환하기

올해의 기념일 날짜인 9월 15일을 반환하는 (_정적_) `Appointment.AnniversaryDate()` 메서드를 구현해요:

```csharp
Appointment.AnniversaryDate()
// => new DateTime(2019, 9, 15, 0, 0, 0)
```
