# 힌트

이 연습 문제는 여러 스레드에서 안전하게 접근할 수 있는 가변 상태를 테스트해요. Scala는 가변 상태를 보호하는 여러 가지 방법을 제공해요. Java 동시성에 익숙한 개발자라면, Scala에서 Java의 synchronized 블록 같은 Java 동시성 지원을 활용할 수 있어요.

## 흔한 실수

Scala에서 가변 상태를 얻는 방법에는 두 가지가 있어요. "var"를 사용하거나 가변 객체를 사용하는 거예요. 여기서 흔히 하는 두 가지 실수는 다음과 같아요.
- "var"이면서 동시에 가변 객체인 것을 사용하지 마세요. 하나면 충분하지만, 둘 다 함께 쓰면 안 돼요.
- "var"나 가변 객체를 외부에 노출하지 마세요. 그러니 "private"으로 만들고, 값을 반환하기 전에 가변 객체를 불변으로 바꿔야 해요.
