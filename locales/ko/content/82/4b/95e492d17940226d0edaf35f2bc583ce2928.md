# 안내

이벤트 기획자 Mika는 회사에서 승진을 했고, 새로 맡은 업무의 하나로 이벤트 데이터베이스를 관리하게 되었어요. 그런데 데이터 상당수가 다루기 어려운 방식으로 저장되어 있다는 걸 금방 알아차렸죠. 그래서 Mika와 함께 일회성 스크립트로 데이터를 정리해 보기로 해요.

스크립트는 딱 한 번만 실행할 예정이고 데이터 구조도 확실히 파악하고 있으니, 이럴 때는 Gleam의 _let assertions_을 쓰기 좋은 상황이라고 생각해요.

## 1. 오류 추출하기

지난 이벤트마다 그 이벤트 중에 발생한 문제 목록이 있어요. 이것들은 결과로 저장되어 있지만, 항상 `Error` 배리언트예요.

항상 `Error`일 것으로 예상되는 결과를 받아, 그 안에 담긴 오류 값을 반환하는 `extract_error` 함수를 구현해요.

```gleam
extract_error(Error("Not enough coffee"))
// -> "Not enough coffee"
```

## 2. 팀 접두사 제거하기

팀 이름 앞에는 "Team "이라는 단어가 붙어 있지만, 이건 필요하지 않아요. 팀 이름에서 이 접두사를 제거하는 `remove_team_prefix` 함수를 구현해요.

```gleam
remove_team_prefix("Team Turtle")
// -> "Turtle"
```

## 3. 지역과 팀 나누기

각 이벤트는 팀이 진행하고, 각 팀은 지역에 속해 있어요. 데이터베이스에서는 이 둘이 쉼표로 구분되어 하나의 문자열로 저장되어 있어요.

문자열을 지역과 팀을 각각 담은 두 문자열의 튜플로 나누는 `split_region_and_team` 함수를 구현해요. 팀 이름에서는 "Team " 접두사를 제거해야 해요.

```gleam
split_region_and_team("East,Team Orange")
// -> #("East", "Orange")
```
