# 힌트

## 일반

- `reduce`는 시퀀스를 먼저 받고, 그다음 초깃값을, 마지막으로 쿼테이션을 받아요. 쿼테이션은 `( prev elt -- next )`를 받는데, 누적값이 먼저 오고 그다음에 다음 요소가 와요.
- 누적 함수 계열(`cum-sum`, `cum-product`, `cum-min`, `cum-max`)은 [`math.statistics`][math.statistics]에 있고, 입력과 길이가 같은 시퀀스를 반환해요.

## 1. 요청 대기열 처리하기

- `reduce`의 초깃값은 시작 잔고예요.
- 결합 함수는 누적 잔고에 요청을 더한 다음, `0 max`로 0을 하한으로 잡아서 잔고가 절대 음수가 되지 않게 해요.
- 인자는 `( opening requests )` 형태로 스택에 들어오지만, `reduce`는 `( seq init quot )`를 원해요. `swap` 한 번이면 돼요.

## 2. 누적 잔고

- `cum-sum` 한 단어면 돼요.

## 3. 지금까지의 최소 잔고

- 먼저 누적 잔고를 계산하고, 그 결과에 누적 최솟값을 적용해요. 두 단어를 이어서 쓰면 돼요.

## 4. 목표에 도달할 때까지 반씩 줄이기

- `produce`가 딱 맞는 도구예요. 값을 반복해서 검사하고 한 단계씩 나아가면서 시퀀스를 만들어요.
- `produce`를 거쳐 가는 상태는 누적 값과 목표값 *둘 다*예요. `target`을 아래에 두고 현재 값을 위에 두세요. 술어는 `2dup <`로 둘을 비교하는데, 목표가 누적 값보다 작은지, 즉 아직 목표 위에 있는지를 확인해요.
- 쿼테이션 안에서는 `2 /i`로 현재 값을 2로 나누고, 그 결과를 `dup`해서 누적 상태를 갱신하는 동시에 새 요소로 내보내요.
- `produce`가 끝나면 남은 상태(목표값과 최종 값)를 버려야 해요. `2nip`가 아래쪽 두 값을 걷어내고 생성된 시퀀스만 남겨요.
