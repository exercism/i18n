# 스택으로 사용하는 벡터

스택은 한쪽 끝에서의 접근에 최적화된 선형 자료 구조예요. 적절한 비유는 꽂이에 꽂힌 종이 뭉치예요. 새 종이는 항상 같은 끝에 넣고, 종이는 넣은 순서와 반대 순서로 꺼내요. 먼저 넣은 종이는 가장 나중에 꺼내고, 마지막에 넣은 종이는 가장 먼저 꺼내요.

Rust의 `Vec` 자료 구조는 스택으로 사용하기에 알맞아요. [`push` 메서드](https://doc.rust-lang.org/std/vec/struct.Vec.html#method.push)는 벡터의 끝에 항목을 추가해요. [`pop` 메서드](https://doc.rust-lang.org/std/vec/struct.Vec.html#method.pop)는 벡터에서 마지막 항목을 제거해요. `push`와 `pop` 모두 분할 상환 `O(1)` 시간만 필요해요.

## 예제

이 예제에서는 간단한 [RPN](https://en.wikipedia.org/wiki/Reverse_Polish_notation) 계산기에서 벡터를 스택으로 사용해요. 전체 소스는 [playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2018&gist=b40514e282cb753d0c3272778f92d736)에서 확인할 수 있어요.

```rust
#[derive(Default)]
pub struct RpnCalculator {
    stack: Vec<Value>,
}

impl RpnCalculator {
    pub fn evaluate(&mut self, argument: Argument) -> Result<(), Error> {
        match argument {
            Argument::Value(value) => self.stack.push(value),
            Argument::Operator(operator) => {
                let b = self.stack.pop().ok_or(Error::StackUnderflow)?;
                let a = self.stack.pop().ok_or(Error::StackUnderflow)?;
                let output = operator.execute()(a, b);
                self.stack.push(output);
            }
        }
        Ok(())
    }

    pub fn conclude(self) -> Result<Value, Error> {
        if self.stack.len() == 1 {
            Ok(self.stack[0])
        } else {
            Err(Error::IncompleteCalculation)
        }
    }
}
```
