# 소개

## 메서드 오버로딩

_메서드 오버로딩_은 같은 클래스 안의 여러 메서드가 같은 이름을 가질 수 있게 해줘요. 오버로드된 메서드들은 다음 중 하나로 서로 달라야 해요.

- 매개변수의 개수
- 매개변수의 타입

반환 타입을 기준으로 하는 메서드 오버로딩은 없어요.

컴파일러는 매개변수의 개수와 타입을 바탕으로 어떤 오버로드된 메서드를 호출할지 자동으로 추론해요.

## 명명된 인자

지금까지는 메서드에 전달된 인자가 위치를 기준으로 메서드에 선언된 매개변수와 짝지어진다는 것을 살펴봤어요. 또 다른 방법도 있는데, 특히 루틴이 많은 수의 인자를 받을 때 호출자는 선언된 매개변수의 식별자를 지정해서 인자를 짝지을 수 있어요.

다음은 그 문법을 보여줘요.

```csharp
class Card
{
    static string NewYear(int year, int month, int day)
    {
        return $"Happy {year}-{month}-{day}!";
    }
}

Card.NewYear(month: 1, day: 1, year: 2020);  // => "Happy 2020-1-1!"
```

## 선택적 매개변수

메서드 매개변수에 기본값을 할당하면 그 매개변수를 선택적으로 만들 수 있어요. 선택적 매개변수가 있는 메서드를 호출할 때, 호출자는 그 매개변수에 값을 전달하지 않아도 돼요. 선택적 매개변수에 값을 전달하지 않으면 기본값이 사용돼요.

선택적 매개변수는 _반드시_ 매개변수 목록의 맨 끝에 있어야 해요. 선택적 매개변수 뒤에 선택적이지 않은 매개변수가 올 수는 없어요.

```csharp
class Card
{
    static string NewYear(int year = 2020)
    {
        return $"Happy {year}!";
    }
}

Card.NewYear();     // => "Happy 2020!"
Card.NewYear(1999); // => "Happy 1999!"
```
