# 지침 추가

## 레지스터

| 레지스터 | 용도     | 타입    | 설명                                                   |
| -------- | --------- | ------- | ------------------------------------------------------ |
| `$a0`    | 입력     | 주소    | null로 끝나는 문자열인 첫 번째 색상                    |
| `$a1`    | 입력     | 주소    | null로 끝나는 문자열인 두 번째 색상                    |
| `$a2`    | 입력     | 주소    | null로 끝나는 문자열인 세 번째 색상 (비어 있을 수 있음) |
| `$v0`    | 출력     | 정수    | 저항 값                                                |
| `$t0-9`  | 임시     | 임의    | 임시 저장용                                            |
