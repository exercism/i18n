# 지시 사항

이 연습 문제에서는 여섯 가지 심각도로 나뉜 로그 메시지를 처리해요.

각 로그 줄은 `"[<LVL>]: <MESSAGE>"` 형식의 문자열이에요.

로그 레벨은 다음과 같아요:

| 레벨      | 약어  |
| --------- | ----- |
| `Trace`   | `TRC` |
| `Debug`   | `DBG` |
| `Info`    | `INF` |
| `Warning` | `WRN` |
| `Error`   | `ERR` |
| `Fatal`   | `FTL` |

## 1. 로그 레벨 파싱

위에서 정의한 로그 레벨에 대응하는 여섯 개의 원소를 가진 `LogLevel` 열거형을 정의해요.
그다음, 로그 메시지를 매개변수로 받아 그 레벨에 해당하는 열거형 멤버를 반환하는 `parse_log_level` 함수를 정의해요.

```python
parse_log_level("[INF]: File deleted")
#=> LogLevel.Info
```

## 2. 알 수 없는 로그 레벨 지원

아쉽게도, 가끔 _알 수 없는_ 심각도를 가진 로그 메시지가 나타나요. `parse_log_level` 함수에서 이런 '수수께끼 같은' 로그 메시지를 자연스럽게 처리하려면, 알 수 없는 로그 레벨을 파싱할 때 반환되는 `Unknown` 멤버를 `LogLevel` 열거형에 추가해요:

```python
parse_log_level("[XYZ]: Overly specific, out of context message")
#=> LogLevel.Unknown
```

## 3. 로그 메시지를 짧은 형식으로 변환하기

로그 줄의 로그 레벨은 꽤 길어요. 로그 메시지를 저장하는 데 필요한 디스크 공간을 줄이기 위해 짧은 형식이 정의되어 있어요: `"[<CODE_LEVEL>]:<MESSAGE>"`.

로그 레벨 코드는 다음과 같이 단순하게 매핑돼요:

| 레벨      | 코드 |
| --------- | ---- |
| `Trace`   | `0`  |
| `Debug`   | `1`  |
| `Info`    | `4`  |
| `Warning` | `5`  |
| `Error`   | `6`  |
| `Fatal`   | `7`  |
| `Unknown` | `42` |

두 개의 매개변수를 받는 `convert_to_short_log()` 함수를 정의해요:

1. 로그 레벨: 전송된 로그의 로그 레벨이에요. 예: `LogLevel.Error`.
2. 로그 메시지: `str` 타입의 메시지예요.

```python
convert_to_short_log(LogLevel.Error, "Stack overflow")
# => "6:Stack overflow"
```

## 4. 별칭 만들기

사용자가 `LogLevel.Warning` 대신 `LogLevel.Warn`에 대한 로그를 만든 것 같아요. `LogLevel.Warning`에 대한 `alias`를 만들고, `get_warn_alias` 함수에서 새로운 별칭 멤버를 반환해요.

이 작업은 파일 맨 위에서 이미 정의한 동일한 열거형 클래스 `LogLevel`에서 할 수 있어요. 두 LogLevel은 같은 값 `"WRN"`을 가리켜야 해요.

```python
get_warn_alias()
#=> LogLevel.Warn

get_warn_alias() == LogLevel.Warning
#=> True
```

## 5. 모든 멤버 이름과 값

`get_members()` 함수를 정의해요.

이 함수는 열거형 `LogLevel`의 모든 멤버를 담은 `(name, value)` 튜플의 배열을 반환해야 해요.

```python
get_members()
#=> [('Trace', 'TRC'), ('Debug', 'DBG'), ('Info', 'INF'), ('Warning', 'WRN'),
# ('Error', 'ERR'), ('Fatal', 'FTL'), ('Unknown', 'UKN')]
```
