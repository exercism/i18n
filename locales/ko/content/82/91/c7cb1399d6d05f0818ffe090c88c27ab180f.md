# 자세히 알아보기

[컴프리헨션][for]은 _Enumerable_을 쉽고 선언적인 방식으로 변환할 수 있게 해주는 기능이에요. Elixir에서 열거 가능한 값들을 순회할 때 쓰는 _문법적 설탕_이죠.

[//]: # (elixir-formatter-disable-next-block)

```elixir
for s <- ["a", "b", "hello", "c"], # 1. generator
  String.length(s) == 1,           # 2. filter
  into: "",                        # 3. collectable
  do: String.upcase(s)

# => "ABC"
```

컴프리헨션은 세 부분으로 이루어져 있어요.

1. _생성기_
   - [_Enumerable_][enumerable] 프로토콜을 구현한 구조체에서 열거된 값들이에요.
   - 열거된 값의 구조를 분해하는 패턴 매칭 표현식이에요.
2. _필터_: 새 값을 만들 때 어떤 열거된 값을 사용할지 고르는 불리언 조건이에요.
3. _Collectable_: 새 값을 모으는 데 쓰이는, [_Collectable_][collectable] 프로토콜을 구현한 구조체예요.

컴프리헨션은 한 줄로 쓸 수도 있고 여러 줄로 쓸 수도 있어요. 생성기를 두 개 이상 사용하면, 생성된 값들의 [카테시안 곱][cartesian-product]이 만들어져요. 즉, 첫 번째 생성기에서 만들어진 각 값이 두 번째 생성기에서 만들어진 각 값과 한 번씩 짝을 이뤄요.

```elixir
for n <- [0, 1, 2, 3], do: n + 1
# => [1, 2, 3, 4]

for x <- [0, 1],
    y <- [0, 1] do
  {x, y}
end

# => [{0, 0}, {0, 1}, {1, 0}, {1, 1}]
```

do 블록의 값은 _enumerable_에서 **생성된 값마다** 하나씩 _collectable_에 들어가요.

```elixir
for _ <- [1, 2, 3], do: :a
# => [:a, :a, :a]
```

컴프리헨션에서는 패턴 매칭을 사용할 수 있어요. `<-` 왼쪽에 쓸 수도 있고, 별도의 줄에 쓸 수도 있어요.

```elixir
for {atom, str} <- [a: "string"], do: str
# => ["string"]

for pair <- [a: "string"],
    {atom, str} = pair do
  str
end

# => ["string"]
```
