# 소개

C#에서 원소를 0개 이상 담을 수 있는 자료 구조를 _컬렉션_이라고 해요. **배열**은 크기, 즉 길이가 고정되어 있고 모든 원소가 같은 타입이어야 하는 컬렉션이에요. 원소는 인덱스를 사용해 배열에 할당하거나 배열에서 꺼낼 수 있어요. C#의 배열은 0부터 시작해요. 즉, 첫 번째 원소의 인덱스는 항상 0이에요:

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true
```

배열은 더 짧은 표기법으로 정의할 수도 있어요. 이 표기법을 사용하면 배열을 만들면서 동시에 값을 설정할 수 있어요. 이 경우 컴파일러가 배열에 원소가 몇 개 들어갈지 알 수 있기 때문에 길이를 생략할 수 있어요:

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

배열은 배열 인스턴스의 메서드나 속성을 호출하거나, `Array` 클래스에 정의된 정적 메서드를 사용해서 다룰 수 있어요.
