# 소개

## 스트림

[`Enum` 모듈][exercism-enum]의 모든 함수는 _즉시 실행_ 방식이에요. `Enum` 모듈로 열거 가능한 값에 여러 연산을 수행하면, 각 연산은 중간 결과를 만들어내요.

`Stream` 모듈은 _즉시 실행_ 방식인 `Enum` 모듈을 대신하는 _지연 실행_ 방식이에요. `Enum` 모듈과 같은 함수를 많이 제공하지만, 중간 결과를 만드는 대신 스트림이 `Enum` 모듈의 함수에 전달되고 나서야 실행되는 일련의 계산을 구성해요.

스트림은 _Enumerable_ [프로토콜][exercism-protocols]을 구현하고, 조합할 수 있어요. 스트림을 서로 이어 붙여서 더 복잡한 기능을 만들 수 있어요.

[exercism-enum]: https://exercism.org/tracks/elixir/concepts/enum
[exercism-protocols]: https://exercism.org/tracks/elixir/concepts/protocols
