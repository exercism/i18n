# 지침

임의의 두 배열 `A`와 `B`가 주어졌을 때, 다음 중 어느 것인지 확인해요:

- 배열 `A`가 배열 `B`와 같거나
- 배열 `A`가 배열 `B`를 포함하거나 (`A`는 `B`의 슈퍼리스트예요)
- 배열 `A`가 배열 `B`에 포함되거나 (`A`는 `B`의 서브리스트예요)
- 위 어느 것도 아니어서 배열 `A`와 `B`가 같지 않아요

구체적으로, 두 배열이 같은 순서로 같은 값을 가지고 있으면 배열 `A`는 배열 `B`와 같아요. `A`가 `B`와 값이 같은 연속된 부분 수열을 포함하고 있으면 `A`는 `B`의 슈퍼리스트예요. `B`가 `A`와 값이 같은 연속된 부분 수열을 포함하고 있으면 `A`는 `B`의 서브리스트예요.

예시:

- `A = []`이고 `B = []`인 경우(두 배열 모두 비어 있어요), `A`와 `B`는 같아요
- `A = [1, 2, 3]`이고 `B = []`인 경우, `A`는 `B`의 슈퍼리스트예요
- `A = []`이고 `B = [1, 2, 3]`인 경우, `A`는 `B`의 서브리스트예요
- `A = [1, 2, 3]`이고 `B = [1, 2, 3, 4, 5]`인 경우, `A`는 `B`의 서브리스트예요
- `A = [3, 4, 5]`이고 `B = [1, 2, 3, 4, 5]`인 경우, `A`는 `B`의 서브리스트예요
- `A = [3, 4]`이고 `B = [1, 2, 3, 4, 5]`인 경우, `A`는 `B`의 서브리스트예요
- `A = [1, 2, 3]`이고 `B = [1, 2, 3]`인 경우, `A`와 `B`는 같아요
- `A = [1, 2, 3, 4, 5]`이고 `B = [2, 3, 4]`인 경우, `A`는 `B`의 슈퍼리스트예요
- `A = [1, 2, 4]`이고 `B = [1, 2, 3, 4, 5]`인 경우, `A`와 `B`는 같지 않아요
- `A = [1, 2, 3]`이고 `B = [1, 3, 2]`인 경우, `A`와 `B`는 같지 않아요
