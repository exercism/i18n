# 소개

[C++](https://en.wikipedia.org/wiki/C%2B%2B)(발음은 '씨 플러스 플러스')은 1979년 벨 연구소에서 [Bjarne Stroustrup](https://en.wikipedia.org/wiki/Bjarne_Stroustrup)이 개발하기 시작한 범용 프로그래밍 언어예요. 특히 속도가 중요하거나 저수준 기능에 접근해야 하는 애플리케이션에서 굉장히 인기가 많아요. 고수준과 저수준 언어의 특징을 모두 담고 있어서 중간 단계 언어로 여겨져요.

C++은 [절차적](https://en.wikipedia.org/wiki/Procedural_programming), [객체 지향](https://en.wikipedia.org/wiki/Object-oriented_programming), [함수형](https://en.wikipedia.org/wiki/Functional_programming), [제네릭](https://en.wikipedia.org/wiki/Generic_programming) 프로그래밍을 지원해요. C++ 컴파일러는 Windows, Mac OS, Linux를 비롯해 사실상 모든 플랫폼에서 사용할 수 있어요.

주요 장점:
- **타입 안전성:** 필요한 안전하지 않은 연산을 캡슐화해요
- **리소스 안전성:** 모든 리소스 관리가 메모리 관리인 것은 아니에요
- **성능:** 거의 모든 시스템에는 성능이 중요한 부분이 있어요
- **예측 가능성:** 하드 실시간 및 소프트 실시간 시스템에 필요해요
- **교육 가능성:** 코드의 복잡성은 작업의 복잡성에 비례해야 해요
- **가독성:** 사람과 기계 모두에게 중요해요 ("분석 가능성")
- **하드웨어로의 직접 매핑:** 명령어와 기본 데이터 타입이 하드웨어에 그대로 대응돼요
- **제로 오버헤드 추상화:** 생성자와 소멸자를 가진 클래스, 상속, 제네릭 프로그래밍, 함수형 프로그래밍 기법

C++ 표준은 국제 표준화 기구(ISO)에서 관리하며, 2018년 6월 기준 최신 버전은 C++17이에요(이름이 C++의 17번째 버전을 뜻하는 것이 아니라, 표준이 2017년에 승인되었다는 의미예요).

C++의 가장 큰 장점은 리소스가 매우 제한된 임베디드 프로세서부터 거대한 메인프레임 슈퍼컴퓨터, 그리고 그 사이의 모든 개인용 컴퓨터에 이르기까지 무엇이든 실행된다는 점이에요.
