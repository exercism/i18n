# 소개

패턴 매칭은 값이 주어진 패턴, 어쩌면 깊이 중첩된 패턴과 일치하는지에 따라 분기하는 과정이에요. Haxe에서는 **패턴 매칭**을 `switch` 표현식과 개별 `case` 표현식으로 해요.

다음 데이터 구조를 살펴봐요.

```haxe
enum Tree<T> {
  Leaf(v:T);
  Node(l:Tree<T>, r:Tree<T>);
}
```

- 패턴은 항상 위에서 아래로 일치하는지 검사해요.
- 입력 값과 일치하는 가장 위쪽 패턴의 표현식이 실행돼요.
- `_` 패턴은 무엇이든 일치하므로, `case _:`는 `default:`와 같아요.

## Enum 매칭

Enum은 생성자를 기준으로 자연스럽게 매칭할 수 있어요.

```haxe
var myTree = Node(Leaf("foo"), Node(Leaf("bar"), Leaf("foobar")));

var match = switch (myTree) {
  // Matches any Leaf
  case Leaf(_):
    "0";

  // Matches any Node that has r = Leaf
  case Node(_, Leaf(_)):
    "1";

  // Matches any Node that has
  // r = another Node which has
  // l = Leaf("bar")
  case Node(_, Node(Leaf("bar", _))):
    "2";

  // Matches anything
  case _:
    "3";
}

trace(match); // 2
```
