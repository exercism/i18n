# 지시 사항 추가

## 구현

가정:

1. 출력에서 0은 항상 [] 대신 [0]으로 표현해요.
2. 그 외의 경우에는 출력에 선행 0이 포함되지 않아요.
3. 입력에서는 선행 0을 허용해요.
4. 입력 숫자 시퀀스가 비어 있으면 오류가 아니라 0으로 간주해요.

문제가 되는 경우에는 `Error()` 메서드가 다음 메시지 중 하나를 반환하는 오류를 반환해서 처리해요:

- input base must be >= 2
- output base must be >= 2
- all digits must satisfy 0 <= d < input base
