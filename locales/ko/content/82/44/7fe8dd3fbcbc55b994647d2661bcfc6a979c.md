# 소개

Scala는 작은 스크립트부터 대규모 멀티플랫폼 애플리케이션까지, 규모가 커져도 함께 성장하는 프로그래밍 언어예요.

Scala는 객체 지향 프로그래밍과 함수형 프로그래밍을 하나의 간결한 고수준 언어로 결합해요. Scala의 정적 타입은 복잡한 애플리케이션에서 버그를 피하도록 도와주고, JVM, JavaScript, Native 런타임을 통해 방대한 라이브러리 생태계에 쉽게 접근하면서 고성능 시스템을 만들 수 있게 해줘요.

* 특징
    * JVM 상호 운용성 - Scala는 JVM에서 실행되므로 Java와 Scala 스택을 섞어 매끄럽게 통합할 수 있어요.
    * JS 및 Native 상호 운용성 - [Scala.js](https://www.scala-js.org/)와 [Scala Native](https://github.com/scala-native/scala-native) 덕분에 Scala는 브라우저와 네이티브 기기에서 실행할 수 있어요.
    * 타입 추론 - Scala는 정적 타입 언어예요. 하지만 Scala는 타입 추론을 제공해서 고급 타입 시스템이 주는 부담을 덜어줘요.
    * 객체 지향 - Scala는 모든 값이 객체라는 점에서 순수 객체 지향 언어예요. 객체의 데이터 타입과 동작은 클래스와 트레이트로 표현해요. 클래스 추상화는 서브클래싱과 유연한 믹스인 기반 합성 메커니즘으로 확장되어 다중 상속의 문제를 피할 수 있어요.
    * 함수형 - Scala는 모든 함수가 값이라는 점에서 함수형 언어이기도 해요. Scala는 익명 함수를 정의하는 가벼운 문법을 제공하고, 고차 함수를 지원하며, 함수를 중첩할 수 있고 커링도 지원해요. Scala의 케이스 클래스와 패턴 매칭에 대한 내장 지원은 많은 함수형 프로그래밍 언어에서 사용하는 대수적 타입을 모델링해요. 싱글턴 객체는 클래스의 멤버가 아닌 함수들을 편리하게 묶는 방법을 제공해요.
    * 동시성과 분산 처리 - 컬렉션에 데이터 병렬 연산을 사용하고, 동시성과 분산 처리에는 액터를, 비동기 프로그래밍에는 퓨처를 사용해요.
