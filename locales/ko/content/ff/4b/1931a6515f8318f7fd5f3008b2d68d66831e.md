# 안내

체스 애호가라면 누구나 자신만의 체스 게임을 한번 만들어 보고 싶어 하죠.
온라인에 이미 체스 구현이 많이 있긴 하지만, 직접 만든 것은 세상에 하나뿐일 거예요!

먼저 기물의 기본 이동 시스템을 구현하는 것부터 시작해요.

체스 게임은 가로 8칸, 세로 8칸인 보드에서 진행돼요.
각 칸은 문자 하나와 숫자 하나로 나타내요.

## 1. 랭크와 파일 범위 정의하기

게임은 보드의 랭크를 저장할 수 있어야 해요.
랭크는 보드의 행이고, 1부터 8까지의 숫자로 나타내요.

게임은 보드의 파일도 저장해야 해요.
파일은 보드의 열이고, A부터 H까지의 문자로 구분해요.

랭크와 파일의 범위를 각각 저장하는 `Chess::RANKS`와 `Chess::FILES` 상수를 정의해요.

```ruby
Chess::RANKS
# => 1..8

Chess::FILES
# => 'A'..'H'
```

## 2. 칸이 유효한지 확인하기

게임은 어떤 칸이 유효한지 확인해야 해요.
칸의 랭크와 파일이 각각 랭크와 파일의 범위 안에 있으면 유효한 칸이에요.

랭크를 정수로 담는 `rank` 인자와 파일을 문자로 담는 `file` 인자를 받는 `Chess.valid_square?` 메서드를 정의해요.
이 메서드는 `rank`와 `file`이 랭크와 파일의 범위 안에 있으면 `true`를 반환하고, 그렇지 않으면 `false`를 반환해야 해요.

```ruby
Chess.valid_square?(1, 'A')
# => true
```

## 3. 플레이어의 닉네임 가져오기

게임은 플레이어의 닉네임을 알아내야 해요.
닉네임은 플레이어의 이름에서 앞 2글자, 성에서 뒤 2글자를 따서 만들어요.
닉네임은 모두 대문자로 표기해야 해요.

플레이어의 이름을 문자열로 담는 `first_name` 인자와 플레이어의 성을 문자열로 담는 `last_name` 인자를 받는 `Chess.nickname` 메서드를 정의해요.
이 메서드는 플레이어의 닉네임을 대문자 문자열로 반환해야 해요.

```ruby
Chess.nickname("John", "Doe")
# => "JOOE"
```

## 4. 이동 메시지 만들기

게임은 어떤 플레이어가 어느 칸으로 이동했는지 알려 주는 메시지를 만들어야 해요.
메시지에는 플레이어의 닉네임과 이동한 칸을 사용해요.
또한 칸의 파일과 랭크가 파일과 랭크의 범위 안에 있는지 확인해서 이동이 유효한지도 판단해야 해요.

이동이 유효하면 메시지는 `"{nickname} moved to {square}"`여야 해요.
이동이 유효하지 않으면 메시지는 `"{nickname} attempted to move to {square}, but that is not a valid square"`여야 해요.

플레이어의 이름을 문자열로 담는 `first_name` 인자, 플레이어의 성을 문자열로 담는 `last_name` 인자, 플레이어가 이동한 칸을 문자열로 담는 `square` 인자를 받는 `Chess.move_message` 메서드를 정의해요.
이 메서드는 이동 메시지를 문자열로 반환해야 해요.

```ruby
Chess.move_message("John", "Doe", "A1")
# => "JOOE moved to A1"
```
