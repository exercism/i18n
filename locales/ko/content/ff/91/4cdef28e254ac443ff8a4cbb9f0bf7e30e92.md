# 학습

* [The Rust Programming Language](https://doc.rust-lang.org/book/)는 Rust를 시작하고 Rust의 특정 기능을 더 깊이 파고들기에 좋은 자료예요.
* [Rust by Example](https://doc.rust-lang.org/stable/rust-by-example/)은 Rust에서 가장 흔히 작성하게 될 것들의 예제를 보여줘요.
* [Into_rust()](http://intorust.com/) "Rust를 배우기 위한 스크린캐스트예요."
* [Rustlings](https://github.com/carols10cents/rustlings) "Rust 코드를 읽고 쓰는 데 익숙해지도록 만든 작은 연습 문제예요."
* [Rust User Forum](http://users.rust-lang.org)에서는 모든 수준의 질문에 답해줘요.
