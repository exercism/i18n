# 소개

## Nil

[Nil][nil-dictionary]은 "nothing" 또는 "zero"를 뜻하는 영어 단어예요. Elixir에서 `nil`은 값의 _부재_를 나타내는 특별한 값이에요.

```elixir
# I do not have a favorite color
favorite_color = nil
```

다른 프로그래밍 언어에서는 `null`이나 `none` 값이 비슷한 역할을 하기도 해요.

## If

`cond` 외에도, Elixir는 조건을 하나만 확인하면 될 때 유용한 매크로 [`if/2`][getting-started-if]도 제공해요.

[`if/2`][kernel-if]는 조건과 두 개의 선택지를 받아요. 조건이 _truthy_면 첫 번째 선택지를 반환하고, _falsy_면 두 번째 선택지를 반환해요.

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
else
  "No beer for you!"
end

# => "No beer for you!"
```

`if` 식을 한 줄로 쓸 수도 있어요. 조건 뒤에 오는 쉼표를 확인해 봐요.

```elixir
if age > 16, do: "beer", else: "no beer"
```

이 문법은 아주 짧은 식에는 유용하지만, 식이 한 줄에 들어가지 않는다면 피하는 게 좋아요.

### _Truthy_와 _falsy_

Elixir에서는 모든 데이터 타입이 불리언 문맥(예를 들어 `if` 식)에서 쓰일 때 _truthy_ 또는 _falsy_ 값으로 평가돼요. `false`와 `nil`을 **제외한** 모든 데이터는 _truthy_로 취급해요. 특히 빈 문자열, 정수 `0`, 빈 배열은 Elixir에서 모두 _truthy_로 취급해요.
