# 자세히 알아보기

`Map`은 **키**와 **값**의 쌍을 저장할 때 사용해요. `Map`은 배열과 똑같은 방식으로 초기화하지만, 맵 리터럴 연산자 `=>`를 사용해요. 키-값 타입을 명시적으로 정의할 수도 있고, 타입을 추론하게 할 수도 있어요. 키는 반드시 고유해야 하며, 그렇지 않으면 오류가 발생해요.

```haxe
var map1:Map<Int, String> = [1 => "one", 2 => "two", 3 => "three"];

var map2 = ["one" => 1, "two" => 2, "three" => 3];

var map3 = [1 => "cat", 1 => "dog"]; // Error: Duplicate Key

var map4 = ["h" => "Hello", "b" => "Bye"];
trace(map4["h"]); // Hello
```

`Map`은 `for`문을 사용해 반복할 수 있어요. 값에 대해 반복할 수도 있고, 키에 대해 반복할 수도 있어요.

```haxe
for (value in map) {
  // ...
}

for (key in map.keys()) {
  // ...
}
```

내부적으로 `Map`은 추상 타입이에요. 컴파일 시점에 키 타입에 따라 여러 특수화된 타입 중 하나로 변환돼요.

- `String`: `haxe.ds.StringMap`
- `Int`: `haxe.ds.IntMap`
- `EnumValue`: `haxe.ds.EnumValueMap`
- `{}`: `haxe.ds.ObjectMap`

`Maps` 타입은 런타임에는 존재하지 않으며, 위에 나온 객체 중 하나로 대체돼요.
