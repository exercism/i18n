# 소개

루프에는 기본적으로 두 가지 종류가 있어요:

1. 조건이 만족될 때까지 반복하는 루프예요.
2. 컬렉션의 원소들을 순회하는 루프예요.

두 가지 모두 R에서 가능하지만, 첫 번째가 더 흔할 수 있어요.

## `while`과 `repeat`

반복 횟수를 미리 알 수 없는 열린 문제에는, R은 조건이 있는 `while`문과 조건이 없는 `repeat`문(이는 `while (TRUE)`와 같아요)을 제공해요.

기본 형태는 아주 간단해요:

```R
while (condition) {
  do_something()
}
```

이 경우 프로그램은 `condition`이 더 이상 `TRUE`가 아닐 때까지 루프를 계속 돌아요.

루프를 일찍 빠져나가는 두 가지 방법이 있어요:

- `break`는 루프를 종료시키고, 실행은 루프의 닫는 중괄호 `}` 다음 줄부터 이어져요.
- `return(x)`는 현재 함수의 실행을 멈추고, 반환값 `x`를 호출한 쪽으로 돌려줘요.

이런 방법들을 쓸 수 있으니, `repeat { ... }`로 "무한" 루프를 만들고 루프 본문 안에서 멈출 조건을 찾아 `break`나 `return`을 실행하는 게 더 편할 때도 있어요.

이 세 가지 변형은 서로 같고, 모두 `x == 0.4444...`로 끝나요.

```R
x <- 12
while (x > 1) {
  x <- x / 3
}

x <- 12
while (TRUE) {
  x <- x/3
  if (x <= 1) break
}

x <- 12
# no boolean clause 
repeat { 
  x <- x/3
  if (x <= 1) break
}
```

## 벡터 순회하기

R에서는 이것이 자주 불필요해요.
다른 개념에서 이야기했듯이, 많은 함수가 벡터 전체에 대해 동작해요.

하지만 명시적인 루프가 피할 수 없을 때도 있어요.
특히 다음과 같은 경우예요:

- 루프 본문이 출력이나 파일 입출력 같은 부수 효과를 일으킬 때예요.
- 예측할 수 없는 횟수의 반복 끝에 어떤 기준에 도달할 때까지 루프가 계속될 때예요.

루프 조건은 괄호 안에 있어야 해요.
함수 본문과 마찬가지로, 한 줄짜리 루프 본문에서는 중괄호가 선택 사항이에요(하지만 자주 넣어요).

```R
words <- c("This", "is", "a", "loop")
for (w in words) { print(w) } # the braces are optional here
#> [1] "This"
#> [1] "is"
#> [1] "a"
#> [1] "loop"
```

현재 반복이 어떤 조건을 만족하지 못하면, `next`로 다음 반복으로 바로 건너뛸 수 있어요:

```R
for (n in 1:10) {
    if (is_useless(n)) next
     
    # we decided this iteration could be useful
    do_something_slow(n)
}
```

숫자 인덱스가 필요하면 `seq_along()`을 사용해요.

```R
v <- LETTERS[1:3]
v
#> [1] "A" "B" "C"

for (i in seq_along(v)) { print(sprintf("%s%i", v[i], i)) }
#> [1] "A1"
#> [1] "B2"
#> [1] "C3"
```

`i in 1:length(v)`는 _권장하지 않아요_. `length(v)`가 0일 때 문제를 일으킬 수 있거든요.
범위 `1:0`은 `c(1, 0)`과 같아서, 루프 본문이 실행되고 아마 실패할 거예요.
`seq_along()` 함수는 이 경우를 올바르게 처리하도록 설계됐어요.
