# 알아보기

[Lua](https://lua.org)는 단순하면서도 강력하고 효율적이며 가벼운, 임베딩할 수 있는 스크립팅 언어예요. 1993년부터 브라질의 [PUC-RIO](https://www.puc-rio.br/)에서 Roberto Ierusalimschy, Waldemar Celes, Luiz Henrique de Figueiredo 팀이 설계하고 구현하고 유지 보수하고 있어요.

## 주석

Lua에서 한 줄 주석은 `--`로 시작하고, 여러 줄 주석은 `--[[`로 시작해서 `]]`로 끝나요.
```lua
-- This is a single line comment.

--[[This is
a multiline
comment
]]
```

## 변수

Lua에는 전역 변수, 지역 변수, 테이블 필드, 이렇게 세 가지 종류의 변수가 있어요. 여기서는 간단하게 설명하기 위해 지역 변수만 다뤄요. 기본적으로 모든 변수는 전역 변수라서, 지역 변수로 쓰려면 `local` 키워드를 붙여서 선언해야 해요.
```lua
local x
```

`=` 연산자를 사용하면 변수에 값을 할당할 수 있어요.
```lua
local x = 1
```

`local` 변수의 스코프는 그 변수가 선언된 블록으로 제한돼요. 블록은 제어 구조의 본문일 수도 있고, 함수의 본문일 수도 있고, 변수가 선언된 파일이나 문자열일 수도 있어요.
```lua
local x = 1

if x == 1 then
  local x = 2
  print(x) -- prints 2
end

print(x) -- prints 1
```

## 함수

함수는 `function` 키워드로 선언하고, 변수와 마찬가지로 기본적으로 전역이에요. 함수 정의는 이름, 매개변수 목록, 본문으로 이루어져 있어요. 함수는 `return` 키워드를 만나면 종료되면서 그 뒤에 나열된 모든 값을 반환해요. `return`을 쓰지 않으면 함수는 `nil`을 반환해요.

```lua
-- Defining a local function which returns "Hello " followed by 
-- the name which was given as parameter
local function say_hello(name)
  return 'Hello ' .. name
end
```

## 테이블

테이블은 Lua에서 유일한 데이터 구조화 수단이고, 아주 강력해요. 배열, 집합, 객체, 모듈 등등 다양한 것을 표현하는 데 쓰여요. 본질적으로 Lua의 테이블은 연관 배열이에요.
```lua
-- create a table and assign its reference to tbl
local tbl = {}

-- new entry with key 'x' and value 1
tbl['x'] = 1

-- printing the value
print(tbl['x'])  --> 1

-- uninitialized table fields evaluate to nil
print(tbl['y'])  --> nil

-- there is also syntactic sugar - the following is the same as above
tbl.y = 1
print(tbl.y)    --> 1
```

이건 다음 섹션에 필요한 아주 작은 부분만 살짝 본 거예요. 이 주제는 나중에 자세히 다시 다뤄요.

## 모듈

모듈은 `.lua` 소스 파일에 저장된 코드의 모음이에요. 모듈이 내보내는 모든 것은 테이블에 저장되고, 이 테이블은 파일 끝에서 반환돼요. 그래서 이 테이블은 사실상 일종의 네임스페이스 역할을 해요.
```lua
-- say-hello.lua

-- defining the table 'say' which is exported at the end
local say = {}

-- defining the function 'hello' as a table field
-- this is syntax sugar for: say.hello = function() print('Hello!') end
function say.hello()
  print('Hello!')
end

-- returning (exporting) the table 'say'
return say
```

그러면 그 모듈은 `require` 함수를 통해 다른 파일로 불러올 수 있는데, 이 함수가 테이블을 반환해요.
```lua
-- lets_say_hello.lua
local say = require('say-hello')
say.hello() -- prints "Hello!"
```

`say.hello`를 보면 "모듈 `say`에 있는 함수 `hello`"라고 생각하기 쉬워요. 그런데 `say-hello.lua`가 테이블을 반환한다는 걸 알고 테이블 섹션을 다시 떠올려 보면, Lua에서 이 표현은 "문자열 `hello`를 키로 써서 테이블 `say`를 인덱싱하는 것"을 뜻한다는 걸 알 수 있어요.

모듈이 테이블을 반환하는 게 좋은 관행이긴 하지만, 함수처럼 다른 타입을 반환하는 것도 얼마든지 가능해요.

```lua
--- say-bye.lua
local function bye()
  print('Bye!')
end

return bye
```
