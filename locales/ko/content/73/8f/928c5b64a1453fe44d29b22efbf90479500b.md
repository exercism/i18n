# 지침

이번 과제는 단어의 각 글자에 해당하는 값을 모두 더해 Scrabble 점수를 계산하는 거예요.

각 글자의 값은 다음과 같아요:

| 글자                         | 값  |
| ---------------------------- | --- |
| A, E, I, O, U, L, N, R, S, T | 1   |
| D, G                         | 2   |
| B, C, M, P                   | 3   |
| F, H, V, W, Y                | 4   |
| K                            | 5   |
| J, X                         | 8   |
| Q, Z                         | 10  |

예를 들어, "cabbage"라는 단어는 14점이에요:

- C: 3점
- A: 1점
- B: 3점
- B: 3점
- A: 1점
- G: 2점
- E: 1점
