# 지침

이 연습 문제에서는 좋아하는 요리책을 보며 근사한 라자냐를 만드는 데 도움이 될 코드를 작성해 볼 거예요.

라자냐를 요리하는 데 걸리는 시간과 관련된 다섯 가지 과제가 있어요.

## 1. 오븐에 넣어 둬야 할 예상 시간(분)을 정의해요

인자를 받지 않고 라자냐를 오븐에 몇 분 동안 넣어 둬야 하는지 반환하는 `Lasagna.expected_minutes_in_oven/0` 함수를 정의해요. 요리책에 따르면 오븐에 넣어 둬야 할 시간은 40분이에요:

```elixir
Lasagna.expected_minutes_in_oven()
# => 40
```

## 2. 오븐에 남은 시간(분)을 계산해요

라자냐가 실제로 오븐에 있었던 시간(분)을 인자로 받아서, 이전 과제에서 구한 오븐에 넣어 둬야 할 시간(분)을 기준으로 라자냐가 오븐에 얼마나 더 있어야 하는지 반환하는 `Lasagna.remaining_minutes_in_oven/1` 함수를 정의해요.

```elixir
Lasagna.remaining_minutes_in_oven(30)
# => 10
```

## 3. 준비 시간(분)을 계산해요

라자냐에 추가한 층의 개수를 인자로 받아서, 각 층을 준비하는 데 2분이 걸린다고 가정했을 때 라자냐를 준비하는 데 몇 분을 썼는지 반환하는 `Lasagna.preparation_time_in_minutes/1` 함수를 정의해요.

```elixir
Lasagna.preparation_time_in_minutes(2)
# => 4
```

## 4. 총 작업 시간(분)을 계산해요

인자 두 개를 받는 `Lasagna.total_time_in_minutes/2` 함수를 정의해요. 첫 번째 인자는 라자냐에 추가한 층의 개수이고, 두 번째 인자는 라자냐가 오븐에 있었던 시간(분)이에요. 이 함수는 라자냐를 요리하는 데 총 몇 분을 일했는지 반환해야 하는데, 이는 준비 시간(분)과 현재 라자냐가 오븐에서 보낸 시간(분)을 더한 값이에요.

```elixir
Lasagna.total_time_in_minutes(3, 20)
# => 26
```

## 5. 라자냐가 다 되었다는 알림을 만들어요

인자를 받지 않고 라자냐가 다 익어서 먹을 준비가 되었다는 메시지를 반환하는 `Lasagna.alarm/0` 함수를 정의해요.

```elixir
Lasagna.alarm()
# => "Ding!"
```
