# 테스트

Exercism 웹사이트의 온라인 에디터를 사용해서 연습 문제를 풀 수 있어요.
아니면 연습 문제를 컴퓨터로 다운로드해서 로컬에서 풀고 Exercism에 제출해도 돼요.
이 문서의 나머지 부분에서는 로컬에서 작업하는 방법을 다뤄요.

## Exercism CLI

연습 문제를 다운로드하고 제출하려면 `exercism` 명령줄 도구가 필요해요.
이 도구를 다운로드하고 설정하는 방법은 [exercism CLI 문서][exercism-cli]를 참고하세요.

연습 문제를 다운로드하려면 이렇게 해요:

```bash
exercism download --track 8th --exercise hello-world
```

그다음 연습 문제 디렉터리로 이동해요:

```bash
cd /path/to/your/exercism_workspace/8th/hello-world
```

Windows를 사용한다면 이렇게 해요:

```cmd
cd \path\to\your\exercism_workspace\8th\hello-world
```

`exercism configure` 명령으로 exercism 워크스페이스를 확인할 수 있어요.

## 로컬에서 테스트하기

연습 문제의 테스트를 실행하려면 올바른 연습 문제 디렉터리에 있어야 해요.
그다음 이 명령으로 테스트를 실행해요:

```bash
8th -f test.8th
```

## 건너뛴 테스트

연습 문제를 푼다는 것은 그 문제의 모든 테스트를 통과시키는 것을 의미해요.
기본적으로 테스트를 실행하면 하나의 테스트(첫 번째 테스트)만 실행돼요.
이건 의도된 동작으로, 그 테스트 하나만 통과시키는 데 집중할 수 있게 해줘요.
그 테스트를 통과하면 `SKIP-REST-OF-TESTS` 줄을 아래로 옮겨서 다음 테스트를 활성화할 수 있어요.

### 건너뛰기 무시하기

`SKIP-REST-OF-TESTS` 다음에 있는 테스트를 포함해 모든 테스트를 실행하려면 환경 변수 `RUN_ALL_TESTS`를 `true`로 설정하면 돼요.
테스트를 실행하는 동안에만 이 값을 설정하려면 (macOS와 Linux) 이렇게 해요:

```bash
RUN_ALL_TESTS=true 8th -f test.8th
```

## 해답 제출하기

exercism 도구를 사용해 해답을 Exercism 웹사이트에 업로드하려면 이렇게 해요:

```bash
exercism submit
```

모든 테스트를 통과하지 못했더라도 코드를 업로드할 수 있어요.
막혀서 멘토의 도움이 필요할 때 유용해요.

[exercism-cli]: https://exercism.org/docs/using/solving-exercises/working-locally
