# 자세히 알아보기

[`switch` 식][switch-expressions]은 [concept:csharp/switch-statements]()에서 다룬 [`switch`문][switch-statements]과 비슷하게 동작해요. 입력 조건을 동작이나 값에 대응시키는 일종의 결정 테이블을 지원해요.

`switch` 식의 핵심은 _패턴 일치_예요. 코딩 연습 문제에서는 값을 `const` 패턴과 일치시켰어요. 이 경우 `switch`의 입력은 _범위 식_이며, 이는 const 값과 비교되고, 그 값은 _케이스 가드_에서 사용돼요.

케이스(또는 _`switch` 암_)는 적힌 순서대로 평가되고, 일치하는 항목을 찾으면 곧바로 평가가 중단되면서 해당 값이 반환돼요.

목록의 마지막에 있는 `_` 케이스는 일치 검사가 빠짐없이 이루어지도록 보장하고, 발생할 수 있는 런타임 오류를 피하는 데 유용해요.

```csharp
double xx = 42d;

string interesting = xx switch
{
    0 => "I suppose zero is interesting",
    3.14 when DateTime.Now.Day == 14 && DateTime.Now.Month == 3 => "Mmm pie!",
    3.14 => "π",
    42 => "a bit of a cliché",
    1729 => "only if you are a pure mathematician",
    _ => "not interesting"
};

// => interesting == "a bit of a cliché"
```

패턴이 범위 변수와 일치하고 케이스 가드가 true로 평가되면 `switch`의 "암"이 선택돼요.

`switch` 식은 [타입 패턴][pattern-matching]과 재귀적 일치도 지원해요.
