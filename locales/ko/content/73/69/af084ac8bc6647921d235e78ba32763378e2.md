# 지침

독일 뮌헨에 있는 대기업의 시스템 관리자로 일하고 있어요. 맡은 업무 중 하나는 이메일 계정을 관리하는 거예요.

Mr. Müller에게 이메일을 보낼 수 없다는 불만이 곳곳에서 들려오고 있어요. 알아보니 회사 사람들 대부분이 오래된 이메일 클라이언트를 쓰고 있는데, 그 클라이언트가 ASCII가 아닌 문자 때문에 `müller@firma.de`를 올바른 이메일 주소로 인식하지 못하는 거예요.

사람들에게 애용하는 오래된 이메일 클라이언트를 버리라고 하는 건 이미 진 싸움이에요. 그래서 모든 이메일 계정에 대해 정리한 별칭을 만들기로 해요.

## 1. 소문자를 제외한 모든 문자를 제거해 기존 사용자 이름 정리하기

`sanitize/1` 함수를 구현해요. 사용자 이름을 charlist로 받아서, 소문자를 제외한 모든 문자를 제거한 사용자 이름을 반환해야 해요.

```elixir
Username.sanitize(~c"schmidt1985")
# => ~c"schmidt"
```

## 2. 밑줄 문자 허용하기

`sanitize/1` 함수를 확장해요. 사용자 이름에서 밑줄 문자는 제거하면 안 돼요.

```elixir
Username.sanitize(~c"mark_fischer$$$")
# => ~c"mark_fischer"
```

## 3. 독일어 문자 대체하기

독일어 알파벳에는 ASCII가 아닌 문자가 네 개 있고, 모두 널리 알려진 ASCII 대체 문자가 있어요.

| 독일어 문자 | ASCII 대체 문자 |
| ---------------- | ---------------- |
| ä                | ae               |
| ö                | oe               |
| ü                | ue               |
| ß                | ss               |

`sanitize/1` 함수를 확장해요. 표에 따라 독일어 문자를 대체해야 해요. 모든 사용자 이름은 이미 소문자라고 가정해도 돼요.

```elixir
Username.sanitize(~c"cäcilie_weiß")
# => ~c"caecilie_weiss"
```
