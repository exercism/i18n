# 힌트

## 일반 사항

- `matches?`, `all-matching-subseqs`, `count-matches`, `re-replace`는 모두 [`regexp`][regexp]에 들어 있어요. 각 패턴은 `R/ `와 `/` 사이에 리터럴로 써요.
- 올바른 배지 코드는 대문자 두 개, 하이픈 하나, 숫자 네 개예요: `R/ [A-Z]{2}-\d{4}/`.

## 1. 배지 코드 확인하기

- `matches?`는 문자열 *전체*를 검사해요. "이게 올바른 배지 코드인가?"를 확인할 때 딱 필요한 기능이죠: `R/ [A-Z]{2}-\d{4}/ matches?`.

## 2. 로그 한 줄에서 코드 전부 뽑아내기

- `all-matching-subseqs`는 일치하는 모든 항목을 문자열 시퀀스로 반환해요. 여기에도 똑같은 배지 코드 패턴을 넘겨줘요.

## 3. 코드에 있는 숫자 개수 세기

- `\d`는 숫자 하나와 일치해요. `count-matches`는 패턴이 몇 번 일치하는지 세어줘요: `R/ \d/ count-matches`.

## 4. 비밀번호 가리기

- `\S`는 "공백이 아닌 문자"를 뜻해요. 그래서 `R/ pass=\S+/`는 `pass=`와 그 뒤에 오는 비밀 값까지 함께 일치해요.
- `re-replace`에는 문자열, 패턴, 그리고 바꿔 넣을 텍스트 `"pass=****"`를 넘겨줘요.

[regexp]: https://docs.factorcode.org/content/vocab-regexp.html
