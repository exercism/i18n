# 자세히 알아보기

[배열][list]은 Haskell에서 값의 모음을 담는 기본 데이터 타입이에요.
배열은 _불변_이라서 수정할 수 없어요.
배열을 바꾸는 연산은 모두 새로운 배열을 반환하죠.
Prelude에는 배열을 다룰 수 있게 해 주는 여러 함수가 있어요.

Haskell의 배열은 메모리가 연속된 위치에 놓이는 배열이 아니라 [연결 리스트][linked-list-wiki]로 구현되어 있어요.
그래서 배열에서 원소 하나에 접근하려면 배열의 길이에 비례하는 선형 시간이 걸려요.

배열은 리터럴 형태나 head-tail 표기법(`cons` 연산자 `:`를 사용해요), 또는 두 가지를 섞은 형태로 쓸 수 있어요:

```haskell
-- Literal Form
[]
[1]
[1, 2, 3]

-- Head-tail Notation
[]
-- same as [1]
1 : []
-- same as [1, 2, 3]
1 : (2 : (3 : []))

-- Mixed
-- same as [1, 2, 3]
1 : [2, 3]
```

head-tail 표기법으로 배열에 항목을 덧붙일 수도 있어요.

```haskell
list = [2, 1]

[3, 2, 1] == 3 : list
-- -> True
```

반복하면서 배열에 원소를 덧붙이는 것은 안티 패턴으로 여겨져요.
원소를 덧붙이려면 배열 전체를 훑으면서 끝에 원소를 더해야 해요. 그래서 반복할 때마다 새 원소를 덧붙이면 매번 배열 전체를 훑어야 하죠.

대신 배열을 뒤집은 다음 맨 앞에 원소를 붙이고, 그 결과를 다시 뒤집으면 같은 결과를 얻을 수 있어요. 맨 앞에 붙이는 것은 상수 시간이 걸리는 빠른 연산이에요.

```haskell
-- Appending to the end of a list (potentially slow)
[1, 2, 3] ++ [4] ++ [5] ++ [6]

-- Prepend to the start of a list (faster, due to the nature of linked lists)
6 : (5 : (4 : [3, 2, 1]))
-- then reverse!
```

배열을 다룰 때 자주 쓰는 Prelude 함수도 여러 개 있어요:

- [`head`][head]는 배열의 _head_, 즉 배열의 _첫 번째_ 항목을 반환해요.
- [`tail`][tail]은 배열의 _tail_, 즉 _첫 번째_ 항목을 _뺀_ 나머지 배열을 반환해요.
- [`length`][length]는 배열에 들어 있는 항목의 개수를 반환해요.
- [`elem`][elem]는 항목이 배열의 원소인지를 나타내는 불리언 값을 반환해요.

[`Data.List` 모듈][list]도 있어요.

## 배열 타입

Haskell에서 배열은 **동질적**이에요.
즉, 배열의 모든 원소는 같은 타입이에요.
서로 다른 타입의 원소를 같은 배열에 넣으려 하면 타입 오류가 발생해요.

```haskell
list = [1, "string"]
-- Error: No instance for (Num String) arising from the literal ‘1’
```

배열의 타입 표기는 `[a]`이고, 여기서 a는 배열이 담는 값의 타입이에요. 예를 들어 `String`이나 `Int`가 있어요.

``` haskell
a :: [Int] 
a = [1, 2, 3]
```
