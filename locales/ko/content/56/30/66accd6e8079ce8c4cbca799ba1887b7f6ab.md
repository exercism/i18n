# 지침 추가

## `Print`는 문자열 값을 따옴표로 묶지 않아요

이 연습 문제에서는 숫자 점수를 다뤄요.
#[a: 1]` and `#[a: "1"]`는 서로 같지 않아요:

```arturo
inspect #[a: 1]
; [ :dictionary
;        a  :        1 :integer
; ]

inspect #[a: "1"]
; [ :dictionary
;        a  :        1 :string
; ]
equal? #[a: "1"] #[a: 1]
; false
```

값을 확인할 때 `print`를 쓰는 것은 흔한 디버깅 방법이에요.
하지만 출력 결과에는 문자열을 감싸는 따옴표가 붙지 않아요.
따라서 `"1"` 같은 숫자 문자열은 출력했을 때 정수 `1`과 똑같이 보여요.

```arturo
print #[a: 1]
; [a:1]
print #[a: "1"]
; [a:1]
```
이 연습 문제의 테스트 출력에서는 `:x: equal? [a:1 e:1 i:1 o:1 u:1] [a:1 e:1 i:1 o:1 u:1]` 같은 결과를 볼 수 있어요.
비교되는 두 딕셔너리는 출력했을 때 똑같아 보여요.
하지만 첫 번째 딕셔너리는 숫자 문자열 값을 가지고 있고 두 번째는 정수 값을 가지고 있어서 둘은 같지 않아요.
디버깅할 때는 `inspect`를 사용해서 딕셔너리의 내용을 확인할 수 있어요.

## `Express`는 문자열 값을 따옴표로 묶어요

`express`는 값을 Arturo 코드로 변환하고, 그 코드 표현을 나타내는 문자열을 반환해요.
그 결과에서 문자열 값은 모두 따옴표로 묶여요.
그래서 `express "1"`은 `1`이 아니라 `"1"`을 반환해요.

```arturo
express #[name: "Octavius" age: 22]
; #[name: "Octavius" age: 22 ]
```
```arturo
express #[name: "Octavius" age: "22"]
; #[name: "Octavius" age: "22" ]
```
