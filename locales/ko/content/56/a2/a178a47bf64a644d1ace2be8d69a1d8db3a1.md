# 개요

Haxe에서 예외는 코드를 실행하는 중에 발생하는 오류를 안전하게 처리하는 방법이에요. 모든 예외에는 오류를 설명하는 메시지가 들어 있어야 해요. `throw` 키워드를 사용하면 예외를 _throw_ 할 수 있어요:

```haxe
public function main(num:Int) {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
  // ...
}
```

예외를 던지면, 코드는 오류를 처리하도록 지정된 부분을 찾아요. 그런 부분을 찾지 못하면 오류 메시지를 표시하면서 프로그램 실행도 중단해요.

Haxe에서 예외를 처리하려면 `try-catch` 블록을 사용해요. 이 블록문은 `try` 블록 하나와 `catch` 블록 하나 이상으로 이루어져 있어요. `try` 블록은 코드의 한 부분을 실행하려고 _tries_ 하고, `catch` 블록은 예외가 던져지면 실행이 멈추지 않도록 그것을 _catch_ 하려고 기다려요. `catch` 블록이 예외를 잡으면, 블록 안의 내용도 모두 실행해요:

```haxe
try {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
} catch (e) {
  // All exceptions will be caught here
  trace(e.message); // Argument num cannot be greater than 10
}
```

`catch` 블록 인자의 타입은 생략해야 해요.

예외는 특별한 처리가 필요한 오류처럼, 예외적인 일이 발생했을 때 사용해야 한다는 점이 중요해요. 프로그램의 제어 흐름을 위해 사용해서는 안 되는데, 그런 사용은 나쁜 설계로 여겨지고 성능과 유지보수성에 나쁜 영향을 주는 경우가 많아요.
