# 안내

친구가 방금 중요한 비밀이 담긴 메시지를 보냈어요.
다른 사람이 쉽게 읽지 못하게 하려고, 메시지는 일련의 비트 조작을 거쳐 암호화되었어요.
메시지를 복호화할 수 있도록 함수를 작성해야 해요.

## 1. 비트를 되돌리기

메시지를 복호화하는 첫 단계는, 암호화 과정에서 밀린 비트를 오른쪽으로 다시 밀어 되돌리는 거예요.
복호화 과정의 이후 단계에서는 왼쪽에서 `0`이 채워진다고 가정해요.

이동할 자릿수와 값을 받아 이동을 수행하는 `shiftBack` 함수를 구현해 보세요.

```elm
shiftBack 2 42 --> 10
```

## 2. 비트 설정하기

다음으로, `1`로 설정해야 하는 비트가 있어요.

마스크와 값을 받아, 값의 비트를 `1`로 설정한 결과를 반환하는 `setBits` 함수를 구현해 보세요.
마스크의 비트가 `1`인 자리에서는 값의 비트도 `1`로 설정해야 해요.
나머지 비트는 그대로 유지해요.

```elm
setBits 66 212 --> 64
```

## 3. 특정 비트 뒤집기

암호화 과정에서 일부 비트는 뒤집혀요.
메시지를 복호화하려면 이 비트들을 다시 뒤집어야 해요.

마스크와 값을 받는 `flipBits` 함수를 구현해 보세요.
마스크는 값에서 어떤 비트를 뒤집을지 알려줘요.
마스크의 비트가 `1`이면, 값의 해당 비트를 뒤집어요.
나머지 비트는 그대로 유지해요.

```elm
flipBits 23 157 --> 138
```

## 4. 특정 비트 지우기

항상 0으로 복호화되는 비트도 있어요.

마스크와 값을 받는 `clearBits` 함수를 구현해 보세요.
마스크의 비트가 1인 자리에서는 `value`의 비트를 0으로 설정해야 해요.
나머지 비트는 그대로 유지해요.

```elm
clearBits 2 15 --> 13
```

## 5. 메시지 복호화하기

이제 필요한 함수를 모두 만들었으니, 친구의 메시지를 해독할 수 있어요.
다음 작업을 수행하는 `decrypt` 함수를 구현해 보세요:

1. 친구가 태어난 연도(1996)로 비트를 설정해요
2. 처음 만난 연도(2009)로 결과를 뒤집어요
3. 함께 듣는 수업 수(5)만큼 비트를 되돌려 밀어요
4. 첫 번째와 다섯 번째 비트를 지워요.

```elm
decrypt 380182 --> 11840
```

이전 과제에서 구현한 모든 함수를 사용해 `decrypt`를 구현해 보세요.
