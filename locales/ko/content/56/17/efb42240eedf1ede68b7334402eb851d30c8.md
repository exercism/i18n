# 지침

이 연습 문제에서는 [바둑 게임의 규칙](https://matmoore.github.io/learngo/)을 적용해 봐요. 규칙 자체는 이미 작성되어 있으니, 규칙을 적용해서 게임을 업데이트하고 오류나 규칙 위반을 처리하기만 하면 돼요.

게임은 다음과 같이 표현해요:

```gleam
pub type Player {
  Black
  White
}


pub type Game {
  Game(
    white_captured_stones: Int,
    black_captured_stones: Int,
    player: Player,
    error: String,
  )
}
```

게임에는 네 가지 규칙이 있어요:

- 각 점에는 돌을 하나만 놓을 수 있어요.
- 상대편 돌은 잡을 수 있어요.
- 자신이 잡히게 되는 자리에는 돌을 놓을 수 없어요.
- 같은 점을 두 번 사용할 수 없어요.

## 1. 규칙 적용하기

`apply_rules` 함수의 내용을 작성해요. 이 함수는 초기 `Game`과 규칙 집합을 받아서, 규칙을 모두 적용한 뒤의 새로운 `Game`을 반환해요.

세 가지 규칙은 규칙 위반 여부를 검사하고 오류를 반환할 수도 있어서 반환 타입이 `Result(Game, String)`이에요. 이 규칙 중 하나라도 실패하면 원래 게임을 반환하되, `error` 필드에는 해당 오류를 담아야 해요.

나머지 규칙 하나는 위반 여부를 검사하지 않으므로 실패할 수 없고(변경된 `Game`을 반환할 수는 있어요), 따라서 반환 타입이 `Game`이에요.

모든 규칙이 통과하면 규칙으로 인한 `Game`의 변경 사항은 그대로 유지하고, 플레이어는 변경해야 해요.

```gleam
pub fn apply_rules(
  game: Game,
  rule1: fn(Game) -> Result(Game, String),
  rule2: fn(Game) -> Game,
  rule3: fn(Game) -> Result(Game, String),
  rule4: fn(Game) -> Result(Game, String),
) -> Game {
  // -> If all rules pass, return a `Game` with all changes from the rules applied, and change player
  // -> If any rule fails, return the original Game, but with the error field set
}
```
