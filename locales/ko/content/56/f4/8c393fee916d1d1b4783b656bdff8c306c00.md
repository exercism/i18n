# 지시 사항

이 연습 문제에서는 공장 직원의 명찰을 출력하는 코드를 작성해요. 직원에게는 ID, 이름, 부서 이름이 있어요. 직원 배지 라벨은 다음과 같은 형식이에요: `"[id] - name - DEPARTMENT"`.

## 1. 직원의 배지를 출력하기

`NameBadge.print/3` 함수를 구현해요. 이 함수는 id, 이름, 부서를 인자로 받아요. 부서 이름을 대문자로 표기한 배지 라벨을 반환해요.

```elixir
NameBadge.print(67, "Katherine Williams", "Strategic Communication")
# => "[67] - Katherine Williams - STRATEGIC COMMUNICATION"
```

## 2. 새 직원의 배지를 출력하기

컴퓨터 시스템의 특이한 점 때문에, 새로 입사한 직원은 공장에서 일을 시작할 때 아직 ID가 없는 경우가 가끔 있어요. 배지는 반드시 필요하기 때문에, 이들은 ID 접두사가 없는 임시 배지를 받아요.

`NameBadge.print/3` 함수를 확장해요. id가 없으면, id 없이 배지를 출력해야 해요.

```elixir
NameBadge.print(nil, "Robert Johnson", "Procurement")
# => "Robert Johnson - PROCUREMENT"
```

## 3. 공장주의 배지를 출력하기

공장주조차 항상 배지를 착용해야 해요. 하지만 공장주에게는 부서가 없어요. 이 경우 라벨에는 부서 이름 대신 `"OWNER"`가 출력되어야 해요.

`NameBadge.print/3` 함수를 확장해요. 부서가 없으면, 배지가 회사 공장주의 것이라고 가정해요.

```elixir
NameBadge.print(204, "Rachel Miller", nil)
# => "[204] - Rachel Miller - OWNER"
```

공장주가 새로 입사한 직원일 수도 있다는 점에 유의해요.

```elixir
NameBadge.print(nil, "Rachel Miller", nil)
# => "Rachel Miller - OWNER"
```
