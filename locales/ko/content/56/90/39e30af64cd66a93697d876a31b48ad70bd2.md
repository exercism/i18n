# `testthat` 설치하기

이 트랙의 테스트는 `testthat` 패키지를 사용해요.

패키지를 설치하려면 R을 열고 다음을 실행하기만 하면 돼요:

`install.packages("testthat")`

패키지가 제대로 설치됐는지 확인하려면 다음을 실행해요:

`library(testthat)`

# 테스트 실행하기

각 연습 문제에는 `test_<exercise-name>.R`이라는 이름의 스크립트가 있어요 (예: `test_hello-world.R`).

연습 문제의 테스트를 실행하려면 이 R 스크립트를 실행하면 돼요.

RStudio에서는 테스트 스크립트를 열고 소스 창의 오른쪽 위에 있는 "Source"를 클릭하면 돼요. 그러면 테스트 스크립트 첫 줄의 `source` 명령으로 풀이 코드를 불러온 뒤, 이어지는 `testthat` 테스트 모음을 실행해요.

다만 테스트 스크립트 첫 줄의 `source()` 명령은 풀이 스크립트(`<exercise-name>.R`)가 작업 디렉터리에 있을 때만 제대로 동작해요. 그렇지 않다면 다음 중 하나를 하면 돼요:
- 작업 디렉터리 바꾸기 (예: `setwd('exercism/r/hello-world/')`)
- 테스트 스크립트 첫 줄 수정하기 (예: `source('exercism/r/hello-world/hello-world.R')`)

원한다면 명령줄에서 `Rscript path_to_exercise_directory/test_<exercise-name>.R` 명령으로 테스트를 실행할 수도 있어요 (예: `Rscript hello-world/test_hello-world.R`).

테스트를 실행하는 또 한 가지 편리한 방법은 [testthat의 `auto_test` 함수](https://www.rdocumentation.org/packages/testthat/topics/auto_test)를 사용하는 거예요. Exercism의 코드와 테스트는 같은 폴더에 있으니, `code_path`와 `test_path` 매개변수에 같은 경로를 넣어요. `auto_test()`를 실행하면 연습 문제의 R 코드를 수정하거나 저장할 때마다 해당 연습 문제의 테스트가 자동으로 실행돼요. 이렇게 하면 풀이를 작성하면서 빠르게 반복 작업을 하는 데 도움이 돼요.
