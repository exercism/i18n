# 소개

Common Lisp에서는 컴퓨터가 무시하는 "주석"을 작성할 수 있어요.
한 줄 주석은 세미콜론(`;`) 하나 이상으로 시작하고, 가끔 다음과 같은 코드를 볼 수도 있어요.

```lisp
(code...) ; => value
```

여기서 주석은 그 줄의 코드를 실행한 뒤 Common Lisp이 반환하는 값이 무엇인지 나타내는 데 쓰여요.

한 줄 끝에 붙이는 짧은 주석에는 세미콜론 하나를, 코드 블록 위에 붙이는 조금 더 긴 주석에는 두 개를, 함수 같은 무언가를 설명하는 긴 주석에는 세 개를, 소스 파일 맨 위의 헤더 같은 주석에는 네 개를 쓰는 것이 관례예요.
