# 소개

불리언 표현식은 하나 이상의 값에 대해 던지는 질문이고, `true` 또는 `false`로 답할 수 있어요.
참인 표현식은 `1`을 반환하고, 거짓인 표현식은 `0`을 반환해요.
숫자에도 참/거짓 값이 있어요. 0은 `false`이고, 0이 아닌 값은 `true`예요.

예전 C 코드에서는 불리언 값에 `int` 타입을 직접 사용하거나, 프로그래머가 `TRUE`와 `FALSE` 같은 상수를 정의해서 `1`과 `0`을 불리언 표현으로 대응시키기도 했어요.

C99 버전에서는 `_Bool` 타입이 추가됐어요.
`stdbool.h` 헤더 파일은 `bool`, `true`, `false` 세 가지 새로운 불리언 심볼을 정의해요.
`true`는 `1`에, `false`는 `0`에, `bool`은 `_Bool`에 대응해요.
그래서 이제 프로그래머는 `int`를 직접 사용하거나 불리언 매핑을 직접 만들 필요 없이, `stdbool.h`를 포함하면 코드에서 자동으로 불리언 심볼을 얻을 수 있어요.

## 비교 연산자

C는 여섯 개의 비교 연산자를 지원해요: `==` (같음), `!=` (같지 않음), `>` (큼), `<` (작음), `>=`(크거나 같음), `<=` (작거나 같음).
이 연산자들은 값 사이의 관계를 비교하고, 그 결과를 불리언 값으로 만들어요.

```c
0 == 0 // true. Although 0 is false, 0 equals 0 is true.
0 != 0 // false
1 > 0 // true
1 < 0 // false
1 >= 0 // true
1 <= 0 // false
```

## 불리언 연산자

C는 `||` (또는), `&&` (그리고), `!` (아님) 세 가지 불리언 연산자를 지원해요.

`!`는 피연산자 하나와 함께 사용해요.
피연산자의 불리언 값을 뒤집어요.
예를 들어 `0`은 `false`이지만, `!0`은 `true`예요.

`||`와 `&&`는 피연산자 두 개와 함께 사용해요.
왼쪽 피연산자만으로 표현식의 결과가 결정되지 않을 때만 오른쪽 피연산자를 평가해요.
즉, `||`는 왼쪽 피연산자가 `false`로 평가될 때만 오른쪽 피연산자를 평가해요.
`&&`는 왼쪽 피연산자가 `true`로 평가될 때만 오른쪽 피연산자를 평가해요.
