# 가변 매개변수

Swift의 [_가변 매개변수_][variadic-parameters]를 사용하면 같은 타입의 값을 0개 이상 함수의 매개변수 하나로 전달할 수 있어요. 이는 매개변수의 타입 표기 뒤에 `...` 기호를 붙여 나타내요.

이 값들은 자동으로 하나의 배열로 묶이고, 그 배열의 원소 타입은 가변 매개변수의 타입과 같아요.

```swift
func geometricMean(_ numbers: Double...) -> Double {
  var total = 1.0
  for number in numbers {
      total *= number
  }
  return pow(total, 1.0 / Double(numbers.count))
}

geometricMean(1, 2, 3, 4, 5)
// => 2.605171084697352
```

가변 매개변수를 사용할 때는 Swift에 한 가지 제약이 있어요.
함수 정의에서 가변 매개변수 뒤에 오는 매개변수가 있다면, 가변 매개변수 바로 다음에 오는 매개변수에는 인자 레이블이 _반드시_ 있어야 해요.

[variadic-parameters]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/functions/#Variadic-Parameters
