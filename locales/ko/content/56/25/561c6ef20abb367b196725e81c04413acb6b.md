# 설치

사용 중인 플랫폼에 맞는 권장 설치 안내는 [Rust 공식 웹사이트][the official Rust website]에서 확인해요.

툴체인을 설치하는 것만으로 끝나는 건 아니에요! IDE 지원은 생산성을 크게 높여 주는 요소이고, 이제는 대부분의 개발자가 당연하게 여겨요. Visual Studio Code를 사용한다면 [Rust 지원 문서][vscode]를 확인해 봐요. [clippy로 린팅하기][vscode-linting]도 정말 추천해요!

[the official Rust website]: https://www.rust-lang.org/tools/install
[vscode]: https://code.visualstudio.com/docs/languages/rust
[vscode-linting]: https://code.visualstudio.com/docs/languages/rust#_linting
