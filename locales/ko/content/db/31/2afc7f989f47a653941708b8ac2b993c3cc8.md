# 지침

이 연습 문제에서는 데이터에 변환을 수행하는 방식으로 동작하는 암호화 장치의 소프트웨어를 작성하는 임무를 맡았어요. 더 단순한 함수들을 서로 조합해서 복잡한 함수를 유연하게 만들 수 있는 방법이 필요해요.

각 작업마다, 호출하는 스코프에서 호출할 수 있는 익명 함수를 반환해야 해요.

모든 함수는 정수 인자를 받는다고 가정해요. 정수는 Elixir에서 비트 연산을 수행하기에도 적합해요.

## 1. 덧셈 함수 만들기

`Secrets.secret_add/1`을 구현해요. 인자 하나를 받고, 그 인자에 `secret_add`에 전달한 인자를 더하는 함수를 반환해야 해요.

```elixir
adder = Secrets.secret_add(3)
adder.(2)
# => 5
```

## 2. 뺄셈 함수 만들기

`Secrets.secret_subtract/1`을 구현해요. 인자 하나를 받고, 그 인자에서 `secret_subtract`에 전달한 비밀 값을 빼는 함수를 반환해야 해요.

```elixir
subtractor = Secrets.secret_subtract(2)
subtractor.(3)
# => 1
```

## 3. 곱셈 함수 만들기

`Secrets.secret_multiply/1`을 구현해요. 인자 하나를 받고, 그 인자에 `secret_multiply`에 전달한 비밀 값을 곱하는 함수를 반환해야 해요.

```elixir
multiplier = Secrets.secret_multiply(7)
multiplier.(3)
# => 21
```

## 4. 나눗셈 함수 만들기

`Secrets.secret_divide/1`을 구현해요. 인자 하나를 받고, 그 인자를 `secret_divide`에 전달한 비밀 값으로 나누는 함수를 반환해야 해요.

```elixir
divider = Secrets.secret_divide(3)
divider.(32)
# => 10
```

결과가 다른 함수들이 기대하는 입력과 호환되도록 정수 나눗셈을 사용해요.

## 5. "and" 함수 만들기

`Secrets.secret_and/1`을 구현해요. 인자 하나를 받고, 그 인자와 `secret_and`에 전달한 비밀 값에 비트 _and_ 연산을 수행하는 함수를 반환해야 해요.

```elixir
ander = Secrets.secret_and(1)
ander.(2)
# => 0
```

## 6. "xor" 함수 만들기

`Secrets.secret_xor/1`을 구현해요. 인자 하나를 받고, 그 인자와 `secret_xor`에 전달한 비밀 값에 비트 _xor_ 연산을 수행하는 함수를 반환해야 해요.

```elixir
xorer = Secrets.secret_xor(1)
xorer.(3)
# => 2
```

## 7. 함수 조합기 만들기

`Secrets.secret_combine/2`를 구현해요. 인자 하나를 받고, 그 인자에 `secret_combine`에 전달한 두 함수를 순서대로 적용하는 함수를 반환해야 해요.

```elixir
add_one = Secrets.secret_add(1)
multiply_by_2 = Secrets.secret_multiply(2)
combined = Secrets.secret_combine(add_one, multiply_by_2)

combined.(3)
# => 8
```
