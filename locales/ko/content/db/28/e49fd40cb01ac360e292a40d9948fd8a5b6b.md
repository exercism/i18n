# 소개

## 배열

Cairo 코어 라이브러리는 `Array` 타입을 구현해요.

다른 프로그래밍 언어에서 흔히 볼 수 있는 배열 타입과 비슷하지만, 몇 가지 중요한 차이점이 있어요:

- 원소는 `Array` 타입의 뒤쪽에만 효율적으로 추가할 수 있고, 앞쪽에서만 효율적으로 제거할 수 있어요.
- 배열 인덱스를 사용해 항목을 직접 설정할 수는 없어요.

배열은 `ArrayTrait::new` 함수로도, `array!` 매크로로도 만들 수 있어요:

```rust
let empty: Array<u32> = ArrayTrait::new();
let one_to_four = array![1, 2, 3, 4];
```

`ArrayTrait::append` 함수를 사용하면 배열에 원소를 추가할 수 있어요:

```rust
let mut num_array = array![1, 2, 3, 4];
num_array.append(5);
// -> [1, 2, 3, 4, 5]
```

`ArrayTrait::pop_front` 함수를 사용하면 배열에서 원소를 제거할 수 있어요:

```rust
let mut one_to_four = array![1, 2, 3, 4];

one_to_four.pop_front();
// -> [2, 3, 4]
```

Cairo는 `Array`의 "스냅샷"처럼 동작하는 `Span` 타입도 도입했어요.

모든 `Array`는 `ToSpanTrait::span` 함수로 `Span`으로 변환할 수 있어요:

```rust
let one_to_four = array![1, 2, 3, 4];
let one_to_four_span = one_to_four.span();
// -> [1, 2, 3, 4]
```

배열을 `Span`으로 변환하는 것은 매우 효율적이에요. `Span`은 Cairo가 배열의 일부를 "바라볼" 수 있게 해 주는 자료 구조일 뿐이고, 배열을 어떤 식으로도 수정하지 않거든요.

배열을 `Span`으로 변환하면, `Array`에서 직접 허용되는 것보다 더 많은 연산을 할 수 있어요. 예를 들어 span의 앞쪽에서 항목을 제거하는 것 같은 연산이에요.

```rust
let one_to_four = array![1, 2, 3, 4];
let mut one_to_four_span = one_to_four.span();
one_to_four_span.pop_back();
// -> [2, 3, 4]
```

`pop_back`을 호출하려면 `mut` 키워드로 `one_to_four_span`을 변경 가능하게 만들어야 한다는 점에 유의해요. `pop_back`은 span이 "바라보는" 배열의 구간을 줄여서 span을 변경하거든요.
