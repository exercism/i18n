# 힌트

## 1. 자기소개 하기

`introduce` 함수는 `player.Name`에 담긴 값을 "풀어내야" 해요.
`player.Name`이 `Some`일 때는 "감싸인" 값으로, `None`일 때는 필요한 기본값으로 변환하려면 [`Options.defaultValue` 함수][defaultvalue]를 사용하는 것을 고려해 봐요.

## 2. revive 기능 구현하기

`revive` 함수는 `Some <player>` 또는 `None`을 반환해야 해요. 여기서 `<player>`는 일부 필드가 수정되었을 수 있는 `Player` 레코드예요.

## 3. 주문 시전 기능 구현하기

`Some`과 `None` 두 경우를 모두 처리하려면 다음 예시처럼 match 식을 사용하는 것을 고려해 봐요:

```fsharp
let exists (x: int option) =
    match x with
    | Some n -> true
    | None -> false
```

[defaultvalue]: https://learn.microsoft.com/en-us/dotnet/fsharp/language-reference/options#converting-options-with-default-values
