# 테스트

테스트는 여러 가지 방법으로 실행할 수 있어요.

## Emacs 안에서 대화형으로 실행하기

1. 테스트 파일을 열고 `M-x eval-buffer RET`
2. `M-x ert RET test-name RET`로 개별적으로 대화형 실행
3. `M-x ert RET t RET`로 한 번에 모두 대화형 실행
   참고로, 이 방법은 현재 Emacs에 로드된 모든 테스트를 실행해요!
4. 코드를 수정했다면 테스트하기 전에 항상 `M-x eval-buffer RET`를 다시 실행해요

현재 버퍼의 테스트만 실행하려면 `.emacs`나 `init.el`에 다음을 추가하면 돼요:

```elisp
(defun my-eval-and-run-all-tests-in-buffer ()
  "Deletes all loaded tests from the runtime, evaluates the current buffer and runs all loaded tests with ert."
  (interactive)
  (ert-delete-all-tests)
  (eval-buffer)
  (ert 't))
```

Emacs를 다시 시작한 뒤에는:

1. 테스트 파일을 열어요
2. `M-x my-eval-and-run-all-tests-in-buffer RET`

## 터미널에서 실행하기

터미널에서 배치 모드로 모든 테스트를 실행하려면 `emacs -batch -l ert -l *-test.el -f ert-run-tests-batch-and-exit`를 실행해요

위 명령은 조금 다루기 번거로우니, 원한다면 이렇게 해봐요:

1. `$PATH`(아마도 `~/bin`)에 `ert-run`이라는 파일을 만들어요
2. 파일 내용은 다음과 같아요:
   ```sh
   #!/usr/bin/env sh
   emacs -batch -l ert -l $1 -f ert-run-tests-batch-and-exit
   ```
3. `chmod +x ert-run`으로 파일을 실행 가능하게 만들어요

`ert-run *-test.el`을 호출하기만 하면 배치 모드로 테스트를 실행할 수 있어요.

## 다른 방법

다른 방법은 문서에서 확인할 수 있어요: `C-h i m ert RET`.
