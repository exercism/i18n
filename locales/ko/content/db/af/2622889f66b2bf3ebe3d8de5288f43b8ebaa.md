# 지시 사항

눈이 튀어나올 만큼 높은 일당에 이끌려, 인플레이션이 높기로 유명한 Hyperia로 다시 돌아오게 되었어요.

중앙은행은 미국 달러를 두 번째 통화로 도입하는 방안을 검토하고 있어요. 그래서 모든 회계 시스템을 여러 통화를 다룰 수 있도록 수정해야 해요.

통화 금액 객체를 구현해 달라는 요청을 받았어요.

## 1. 통화 금액을 동등 비교할 수 있게 만들기

`CurrencyAmount` 구조체를 수정해서 동등 비교를 처리할 수 있게 해 주세요. 두 통화 금액 구조체의 통화("USD" 또는 "HD")가 같지 않으면 `ArgumentException` 인스턴스를 던져야 해요.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
CurrencyAmount amountB = new CurrencyAmount(55, "HD");
CurrencyAmount amountC = new CurrencyAmount(55, "USD");
amountA == amountB
// => true
amountA != amountB
// => false
amountA == amountC
// => ArgumentException
amountA != amountC
// => ArgumentException
```

## 2. 통화 금액 비교하기

`CurrencyAmount` 구조체를 수정해서 비교(`>`와 `<`만)를 처리할 수 있게 해 주세요. 두 통화 금액 구조체의 통화("USD" 또는 "HD")가 같지 않으면 `ArgumentException` 인스턴스를 던져야 해요.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
amountA > new CurrencyAmount(50, "HD")
// => true
amountA < new CurrencyAmount(50, "HD")
// => false
amountA > new CurrencyAmount(50, "USD")
// => ArgumentException
```

## 3. 통화 금액 더하고 빼기

`CurrencyAmount` 구조체를 수정해서 덧셈과 뺄셈(`+`와 `-`만)을 처리할 수 있게 해 주세요. 두 통화 금액 구조체의 통화("USD" 또는 "HD")가 같지 않으면 `ArgumentException` 인스턴스를 던져야 해요.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
CurrencyAmount amountB = new CurrencyAmount(100, "HD");
CurrencyAmount amountC = new CurrencyAmount(55, "USD");
amountA + amountB
// => {155, HD}
amountB - amountA
// => {45, HD}
amountA + amountC
// => ArgumentException
```

## 4. 통화 금액 곱하고 나누기

`CurrencyAmount` 구조체를 수정해서 곱셈과 나눗셈(`*`와 `/`만)을 처리할 수 있게 해 주세요.

```csharp
CurrencyAmount amountA = new CurrencyAmount(10, "HD");
amountA * 2m
// => {20, HD}
amountA / 2m
// => {5, HD}
```

## 5. 통화 금액을 double로 변환하기

`CurrencyAmount` 구조체를 수정해서 인스턴스를 `double`로 명시적으로 캐스팅할 수 있게 해 주세요.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55.5m, "HD");
(double)amountA
// => 55.5d
```

## 6. 통화 금액을 decimal로 변환하기

`CurrencyAmount` 구조체를 수정해서 인스턴스를 `decimal`로 암시적으로 변환할 수 있게 해 주세요.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55.5m, "HD");
decimal d = amountA;
// => d == 55.5m
```
