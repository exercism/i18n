# 지시 사항 추가

## 워드

`"ready"` 상태이고 경과 시간과 이전 랩이 없는 새 스톱워치를 반환하는 `stopwatch` 튜플과 생성자 `<stopwatch> ( -- stopwatch )`를 정의해요.

스톱워치를 다루는 다음 워드를 제공해요:

- `state ( stopwatch -- str )` — `"ready"`, `"running"`, `"stopped"` 중 하나예요.
- `current-lap ( stopwatch -- str )` — 현재 랩의 경과 시간을 `"HH:MM:SS"` 문자열로 나타낸 것이에요.
- `total ( stopwatch -- str )` — 현재 랩과 이전 랩 모두의 경과 시간을 합한 것을 `"HH:MM:SS"` 문자열로 나타낸 것이에요.
- `previous-laps ( stopwatch -- seq )` — 이전에 기록된 랩들의 배열로, 각각 `"HH:MM:SS"` 문자열이에요.
- `start ( stopwatch -- )`, `stop ( stopwatch -- )`, `reset ( stopwatch -- )`, `lap ( stopwatch -- )` — 위 표에 나온 네 가지 명령이에요. 허용되지 않는 상태에서 호출하면 오류를 `throw`해야 해요.

시간은 다음과 같이 진행해요:

- `advance-time ( str stopwatch -- )` — `"HH:MM:SS"` 형식의 시간을 현재 랩에 더해요. 이는 스톱워치가 실행 중일 때만 효과가 있어요.
