# 힌트

## 일반

- 시작하기 가이드에서 [오류][getting-started-errors]에 대해 읽어봐요.
- 시작하기 가이드에서 [IO][getting-started-io]에 대해 읽어봐요.

## 1. 파일 열기

- _동적 디스패치_를 사용해 open 함수를 호출해요. 도입부 코드 조각을 다시 살펴봐요.

## 2. 파일에 쓰기 시도

- try-rescue 구문을 활용해요.
- `IO` 모듈에는 IO 장치에 쓸 수 있게 해 주는 [함수][io-write]가 있어요.
- `rescue` 블록을 사용해 오류를 패턴 매칭하고 오류 튜플을 반환할 수 있어요.
- `else` 블록을 사용해 성공한 쓰기의 반환값을 패턴 매칭할 수 있어요.

## 3. 파일 닫기

- `after` 블록을 사용하면 `try` 블록이 성공하든 rescue되든 함수를 실행할 수 있어요.
