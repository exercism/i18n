# 소개

Rust에서 불리언은 `bool` 타입으로 표현돼요. 이 타입의 값은 `true` 또는 `false` 중 하나예요.

Rust는 여섯 개의 비교 연산자를 지원해요: `==` (같음), `!=` (같지 않음), `>` (큼), `<` (작음), `>=` (크거나 같음), `<=` (작거나 같음). 이 연산자들을 사용하면 불리언이 아닌 값들 사이의 관계를 평가해 불리언 값을 얻을 수 있어요.

```rust
1 > 0 // true
1 < 0 // false
1 == 0 // false
1 != 0 // true
1 >= 0 // true
1 <= 0 // false
```

다른 몇몇 언어와 달리, `0`이 `false`인 것도 아니고 0이 아닌 값이 `true`인 것도 아니에요.

Rust는 두 개의 불리언 연산자를 지원해요: `||` (또는), `&&` (그리고). 이 연산자들은 왼쪽 피연산자만으로 식의 결과가 이미 정해지지 않았을 때만 평가돼요. 즉, `||`는 왼쪽 피연산자가 `false`로 평가될 때만 오른쪽 피연산자를 평가하고, `&&`는 왼쪽 피연산자가 `true`로 평가될 때만 오른쪽 피연산자를 평가해요.
