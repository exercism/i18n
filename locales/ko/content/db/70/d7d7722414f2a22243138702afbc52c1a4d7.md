# Instructions

이 연습 문제에서는 킬로그램을 단위로 사용하는 저울을 모델링해요.

여섯 개의 과제가 있고, 각 과제에서는 속성을 하나 이상 구현해야 해요.

## 1. 저울에 정밀도를 설정할 수 있게 하기

다양한 요구를 반영하기 위해, 저울마다 정밀도(소수점 아래 자릿수)를 지정할 수 있어요.
`WeighingMachine` 클래스에, 생성자의 `precision` 인자로 값이 설정되는 get 전용 `Precision` 속성을 구현해요:

```csharp
var wm = new WeighingMachine(precision: 3);

//  => wm.Precision == 3
```

## 2. 저울에 무게를 설정할 수 있게 하기

`WeighingMachine.Weight` 속성을 get과 set이 모두 가능하도록 구현해요:

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = 60.5;

//  => wm.Weight == 60.5
```

## 3. 음수 무게 입력을 거부하기

무게는 당연히 음수가 될 수 없어요.
`WeighingMachine.Weight` 속성에 유효성 검사를 추가해서, 음수 무게를 설정하려고 하면 `ArgumentOutOfRangeException` 예외를 던지게 해요:

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = -10; // Throws an ArgumentOutOfRangeException
```

## 4. 저울에 영점 조정을 적용할 수 있게 하기

영점 조정 값은 어떤 값이든 될 수 있어요(음수이거나, 표시되는 무게를 음수로 만드는 값이어도 괜찮아요).
`WeighingMachine.TareAdjustment` 속성을 영점 조정 값을 설정할 수 있도록 구현해요:

```csharp
var wm = new WeighingMachine(precision: 3);
wm.TareAdjustment = -10.6;

// => wm.TareAdjustment == -10.6
```

## 5. 저울에 기본 영점 조정 값을 설정하기

철저히 테스트해 본 결과, 제조상의 문제로 모든 저울이 무게를 `5`만큼 과대평가하는 경향이 있는 것 같아요.
`WeighingMachine.TareAdjustment` 속성의 기본값을 `5`로 바꿔요.

```csharp
var wm = new WeighingMachine(precision: 3);

// => wm.TareAdjustment == 5.0
```

## 6. 무게를 읽어 올 수 있게 하기

`WeighingMachine.DisplayWeight` 속성을 구현해요. 이 속성은 영점 조정을 적용한 뒤의 무게를, 올바른 정밀도로 맞추고 단위를 붙여서 보여 주는 문자열을 반환해야 해요.
참고로:

``` display-weight = input-weight - tare-adjustment ```

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = 60.567;
wm.TareAdjustment = 10;

// => wm.DisplayWeight == "50.567 kg"
```
