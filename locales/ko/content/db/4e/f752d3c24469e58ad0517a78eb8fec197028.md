# 소개

## 타입 별칭

### 타입 별칭

타입 별칭을 사용하면 Gleam에서 기존 타입에 편리한 이름을 붙일 수 있어요. 그 타입을 직접 쓰기에는 번거로울 때 유용하죠.

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

`pub type`으로 작성하면 별칭을 정의된 모듈 밖에서도 사용할 수 있어요. `pub`을 생략하면 별칭은 비공개가 되어 다른 모듈에서 참조할 수 없어요.

## 딕셔너리

Gleam의 딕셔너리는 정보를 키-값 쌍으로 저장하는 자료 구조예요. 다른 언어에서는 연관 배열, 해시, 딕셔너리 등으로도 알려져 있어요.

딕셔너리에서는 어떤 타입이든 키와 값으로 사용할 수 있어요. 그리고 항목을 조회하거나 반환할 때 순서를 보장하지 않아요.

### 딕셔너리 다루기

딕셔너리는 `gleam/dict` 모듈의 함수로 만들고 다뤄요.

```gleam
// Create an empty dict
let dict1 = dict.new()

// Create a dict with some values
let dict2 = dict.from_list([
  #("name", "Gleam"),
  #("colour", "Pink"),
])

// Add a value to a dict
let dict3 = dict.insert(dict2, "website", "https://gleam.run")

// Get a value from a dict
let name = dict.get(dict3, "name")
// -> Ok("Gleam")
```
