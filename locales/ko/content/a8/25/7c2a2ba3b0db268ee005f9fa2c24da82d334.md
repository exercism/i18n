# 지침

이 연습 문제에서는 프리랜서가 프로젝트 매니저와 소통하는 데 도움이 되는 코드를 작성해요.
여러분이 할 일은 일일 요금과 월 요금을 빠르게 계산하는 몇 가지 유틸리티를 만드는 거예요. 원한다면 주어진 할인율을 적용할 수도 있어요.

먼저 프리랜서와 프로젝트 매니저 사이에 몇 가지 규칙을 정해요:

- 일일 요금은 시간당 요금의 8배예요.
- 한 달에는 청구 가능한 날이 22일 있어요.

때로는 프리랜서가 일일 요금에 할인을 적용해 주기도 해요(예를 들어 가장 충성도 높은 고객이나 비영리 고객에게요).

할인은 백분율을 나타내는 소수로 표현해요. 예를 들어 `25.0`은 25%예요.

~~~~exercism/note
다음은 부동소수점 명령어에 붙는 접미사예요:

| 접미사 | 피연산자 크기 |
|--------|--------------|
| `ss`   | 32비트       |
| `sd`   | 64비트       |

다음은 이 개념에서 언급하는 명령어 중 일부예요:

| 명령어 | 설명 |
|-------------------------|--------------------------------------------------------|
| movss/movsd a, b        | b를 a로 복사해요                                       |
| addss/addsd a, b        | a = a + b                                              |
| subss/subsd a, b        | a = a - b                                              |
| mulss/mulsd a, b        | a = a * b                                              |
| divss/divsd a, b        | a = a / b                                              |
| cvtsi2ss/cvtsi2sd a, b  | 정수 b를 부동소수점 a로 변환해요                       |
| roundss/roundsd a, b, c | 부동소수점 b를 c에 따라 반올림해서 a에 저장해요        |
| cvtss2si/cvtsd2si a, b  | 부동소수점 b를 정수 a로 변환해요                       |
| comiss/comisd a, b      | a와 b를 비교하고, `NaN`이면 예외가 발생해요            |
| ucomiss/ucomisd a, b    | a와 b를 비교하고, `NaN`이면 `PF`를 설정해요            |

다음은 `roundss`와 `roundsd`에서 쓰는 반올림 제어 숫자예요:

| 숫자 | 모드         |
|:-------|:-------------|
| 0      | 반올림       |
| 1      | 내림         |
| 2      | 올림         |
| 3      | 버림         |

## 1. 시간당 요금으로 일일 요금 계산하기

`daily_rate`라는 함수를 구현해서, 매개변수로 주어진 시간당 요금으로 일일 요금을 계산해요.
시간당 요금은 64비트 부동소수점 수예요.
계약에서는 하루를 청구 가능한 8시간으로 정의해요.

```c
daily_rate(60)
// => 480.0
```

반환하는 일일 요금은 64비트 부동소수점 수여야 해요.

## 2. 할인된 가격 계산하기

할인이 적용된 가격을 계산하는 `apply_discount` 함수를 구현해요.
이 함수는 원래 가격과 백분율로 나타낸 할인율, 두 개의 매개변수를 받아요. 둘 다 64비트 부동소수점 수예요.

```c
apply_discount(150.0, 10.0)
// => 135.0
```

반환값은 항상 64비트 부동소수점 수여야 해요.

## 3. 시간당 요금과 할인이 주어졌을 때 월 요금 계산하기

할인이 적용된 월 요금을 계산하는 `monthly_rate` 함수를 구현해요.
이 함수는 시간당 요금과 백분율로 나타낸 할인, 두 개의 매개변수를 받아요. 둘 다 64비트 부동소수점 수예요.

```c
monthly_rate(77.0, 10.5)
// => 12130
```

반환하는 월 요금은 64비트 정수로 올림해야 해요.

## 4. 예산, 시간당 요금, 할인이 주어졌을 때 완전한 근무일 수 계산하기

다음 매개변수를 받는 `days_in_budget` 함수를 구현해요:

1. 64비트 부호 없는 정수인 예산.
2. 64비트 부동소수점 수인 시간당 요금.
3. 64비트 부동소수점 수인 백분율 할인.

이 함수는 예산으로 며칠을 온전히 일할 수 있는지 그 일수를 반환해야 해요.

```c
days_in_budget(20000, 80, 11.0)
// => 35
```

반환하는 일수는 32비트 정수로 내림해야 해요.
