# 지침

지금 큰 인기를 끌게 될 새로운 게임 **Wings Quest**를 개발하는 중이에요.
이 게임에서 플레이어는 이리저리 움직이며 씨앗을 모으는 새예요.
플레이어는 모든 씨앗을 주우면 게임에서 이겨요.
플레이어가 독수리에 닿으면 씨앗을 모두 잃고 게임에서 지게 돼요.
이 규칙에는 예외가 하나 있어요. 플레이어가 파워업을 활성화한 상태라면 다른 새들보다 더 높이 날 수 있어요.

목표는 게임에서 사용될 규칙 몇 가지를 작성하는 거예요.

## 1. 새가 보너스 점수를 받는지 정의하기

게임에서 새는 파워업을 가진 상태로 독수리에 닿으면 보너스 점수를 받아요.

두 개의 인자를 받는 함수 `bonusPoints(powerUpActive:touchingEagle:)`를 정의해요. `powerUpActive`는 새가 활성화된 파워업을 가지고 있는지를 담고, `touchingEagle`은 새가 독수리에 닿아 있는지를 담아요.
이 함수는 새가 파워업을 활성화한 상태이며 독수리에 닿아 있을 때에만 `true`를 반환하고, 그렇지 않으면 `false`를 반환해야 해요.

```Swift
bonusPoints(powerUpActive: false, touchingEagle: true)
// Returns false
```

## 2. 새가 점수를 얻는지 정의하기

게임에서 플레이어는 씨앗이나 파워업을 주우면 점수를 얻어요.

두 개의 인자를 받는 함수 `score(touchingPowerUp:touchingSeed:)`를 정의해요. `touchingPowerUp`은 새가 파워업에 닿아 있는지를 담고, `touchingSeed`는 새가 씨앗에 닿아 있는지를 담아요.
이 함수는 새가 파워업이나 씨앗에 닿아 있으면 `true`를 반환하고, 그렇지 않으면 `false`를 반환해야 해요.

```Swift
score(touchingPowerUp: true, touchingSeed: true)
// Returns true
```

## 3. 새가 지는지 정의하기

두 개의 인자를 받는 함수 `lose(powerUpActive:touchingEagle:)`를 정의해요. `powerUpActive`는 새가 활성화된 파워업을 가지고 있는지를 담고, `touchingEagle`은 새가 독수리에 닿아 있는지를 담아요.
이 함수는 새가 독수리에 닿아 있고 활성화된 파워업이 없으면 `true`를 반환하고, 그렇지 않으면 `false`를 반환해야 해요.

```Swift
lose(powerUpActive: false, touchingEagle: true)
// Returns true
```

## 4. 새가 이기는지 정의하기

다음 인자들을 받는 `win(hasPickedUpAllSeeds:powerUpActive:touchingEagle:)` 함수를 정의해요.

- `hasPickedUpAllSeeds`는 새가 모든 씨앗을 주웠는지 여부를 나타내요.
- `powerUpActive`는 새가 파워업을 활성화했는지 여부를 나타내요.
- `touchingEagle`은 새가 독수리에 닿아 있는지 여부를 나타내요.

이 함수는 새가 모든 씨앗을 모았고 3번에서 정의한 인자들에 따라 지지 않은 경우에 `true`를 반환하고, 그렇지 않으면 `false`를 반환해야 해요.

```Swift
win(hasPickedUpAllSeeds: false, powerUpActive: true, touchingEagle: false)
// Returns false
```
