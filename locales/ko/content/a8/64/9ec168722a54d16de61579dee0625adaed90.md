# 힌트

## 일반

- Elm을 만든 사람이 쓴 [꼬리 호출 제거][tail-call-elimination] 글을 읽어볼 수 있어요
- 꼬리 재귀 함수에서 각 분기의 _마지막_ 연산은 간단한 함수 적용으로 자기 자신을 호출해요
- 꼬리 재귀 도우미 함수를 정의해야 해요

## 1. 팩토리얼

- 꼬리 재귀 도우미 함수를 하나 정의해야 해요
- 0의 팩토리얼은 1이에요
- 재귀를 사용해 `n`을 기저 조건까지 줄이면서 곱을 추적해요

## 2. 이중 팩토리얼

- 꼬리 재귀 도우미 함수를 하나 정의해야 해요
- 0의 이중 팩토리얼은 1이에요
- 1의 이중 팩토리얼은 1이에요
- 재귀를 사용해 `n`을 둘씩 줄여 기저 조건까지 이르게 하면서 곱을 추적해요

## 3. 뉴턴/오일러 수렴 변환

- 꼬리 재귀 도우미 함수를 하나 정의해야 해요
- `factorial`과 `doubleFactorial`을 직접 사용하는 것은 권장하지 않아요. 합을 이루는 항을 만드는 가장 효율적인 방법이 아니거든요
- 도우미 함수에는 원하는 만큼 인자를 넘길 수 있어요
