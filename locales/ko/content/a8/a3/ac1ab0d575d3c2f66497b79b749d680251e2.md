# 소개

`for`문은 어떤 로직을 반복해서 실행할 때 가장 흔히 쓰이는 문 중 하나예요. JavaScript에서 `for`문은 `for` 키워드, 소괄호로 감싼 _헤더_, 그리고 중괄호로 감싼 루프의 _본문_이 들어 있는 코드 블록으로 이루어져 있어요.

```javascript
for (initialization; condition; step) {
  // code that is executed repeatedly as long as the condition is true
}
```

초기화 부분은 보통 카운터 변수를 준비하고, 조건은 루프를 계속할지 멈출지 확인하며, 단계는 반복이 끝날 때마다 카운터를 증가시켜요. 헤더의 각 부분은 세미콜론으로 구분해요.

```javascript
const list = ['a', 'b', 'c'];
for (let i = 0; i < list.length; i++) {
  // code that should be executed for each item list[i]
}
```

단계를 정의할 때는 위 예시처럼 JavaScript의 증가 연산자나 감소 연산자를 쓰는 경우가 많아요. 이 연산자들은 변수 값을 그 자리에서 바꿔요. `++`는 숫자에 1을 더하고, `--`는 숫자에서 1을 빼요.

```javascript
let i = 3;
i++;
// i is now 4

let j = 0;
j--;
// j is now -1
```
