# rescue 없이 풀기

흐름 제어를 위해 예외를 사용하지 마세요.
`rescue`를 사용하지 않고 이 연습 문제를 풀어 봐요.

이름이 `!`로 끝나는 표준 라이브러리 함수(오류를 발생시켜요)를 사용하고 있다면, `!`가 없는 동등한 함수를 찾아봐요(보통 `{:ok, result}`나 `{:error, message}`를 반환해요).

참고: 풀이에서 이 자동 댓글을 보고 있다면, 다른 자동 댓글은 정확하지 않을 수 있어요.
먼저 이 문제를 해결해 봐요!

```elixir
# preferred: for example `case`

case Date.new(1999, 13, 1) do
  {:ok, date} -> date
  {:error, _} -> nil
end

# discouraged: rescuing exceptions

try do
  Date.new!(1999, 13, 1)
rescue
  ArgumentError ->
    nil
end
```
