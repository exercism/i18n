# 힌트

## 일반

- 함수 매개변수에서 여러 인자를 꺼내려면 **배열**에는 `*arguments` 연산자로, 키워드 기반 인자에는 `**keyword_arguments`로 묶어요.
- 묶거나 풀 때는 스플랫 연산자(`*` 또는 `**`)를 사용해요.

## 1. 모든 객차 목록 만들기

- 함수 매개변수의 여러 인자는 `*arguments` 연산자로 묶을 수 있어요.

## 2. 객차 목록 고치기

- 스플랫 연산자(`*`)로 풀면 **배열**의 처음 두 원소를 꺼내면서 나머지는 그대로 둘 수 있어요.
- 기존 **배열**에 다른 **배열**을 추가하려면 스플랫 연산자(`*`)로 **배열**을 "펼쳐서" 넣을 수 있어요.

## 3. 빠진 정차역 추가하기

- 메서드 인자로 `**keyword_arguments`를 사용하면 원하는 만큼 키워드 인자를 전달할 수 있어요.
- 인자로 `**<hash>`를 사용하면 `Hash`를 키워드 인자로 풀어요.
- 키워드 인자를 `{}` 안에 넣을 수도 있는데, 이는 `Hash`를 만드는 또 다른 방법이에요.
- `Hash`에서 값들을 꺼내려면 `Hash#values` 메서드를 사용해요.

## 4. 경로 정보 확장하기

- 인자로 `**{some_hash: value}`를 사용하면 `Hash`를 키워드 인자로 풀어요.
