# 지시 사항 추가

문자열에는 `#reversed`와 `#reverseDo:` 메서드가 있지만, 더 낮은 수준의 문자 반복과 스트림을 사용해서 직접 해결할 수 있을까요?

코드를 살펴보는 데 도움이 되도록, Pharo에는 멋진 코드 찾기 도구가 있어요. Shift-Enter를 눌러 활성화해요.

참고: Exercism의 관례에 따라 풀이의 이름을 ReverseString이라고 지었지만, 더 Smalltalk다운 이름은 StringReverser예요.

## Smalltalk과 문자열

문자열과 관련해서는 주석에 큰따옴표를 쓰고, 문자열에 작은따옴표를 쓰며, 문자에는 특별한 문법을 쓰는 것(예: 문자 “x”는 $x)처럼 처음 읽을 때 헷갈릴 만한, 뻔하지만 중요한 세부 사항이 몇 가지 있어요. 다른 언어에서 쓰는 관례와 다르기 때문이에요.

메모리 전체에서 유일한 문자열을 뜻하는 심볼이라는 개념도 있어요. 즉, 심볼이 만들어질 때(보통 컴파일 시점에) 메모리를 검색해서 똑같은 것이 이미 있는지 확인하고, 원래 있던 것만 사용해요. 그 이유는 메모리를 아끼기 위해서만이 아니라, 심볼을 비교할 때 속도가 크게 빨라지기 때문이에요.

```smalltalk
"this is a comment"
'this is a string'
#'this is a symbol'
#thisIsASymbolToo
```

Smalltalk 프로그램에는 쉼표도 거의 없어요. 쉼표가 문법적인 역할을 하지 않기 때문이에요.
그래서 예를 들어 배열 리터럴에는 쉼표가 없어요. 예를 들면 `#(1 2 3 4 5)` 같아요.
하지만 쉼표 자체가 연산자라서, 두 문자열을 이어 붙일 때는 쉼표를 보게 될 거예요. 예를 들면 `'string1', 'string2'` 처럼요.

마지막으로, 문자열과 문자가 서로 다른 클래스라는 점을 알아두면 좋아요. 문자열은 문자의 모음이에요. 문자열을 반복할 때 문자열을 기대하는 메서드에 문자를 넘겨 버릴 수 있어서 방심하다가 당할 수 있어요. 다음을 봐요...
```smalltalk
(('hello' at: 2) = $e) inspect.
(('hello' at: 2) = 'e') inspect.
```

## Smalltalk과 스트림
스트림은 순차적인 읽기와 쓰기에 유용해요.  인덱스를 증가시킬 필요를 없애서 코드를 더 깔끔하게 만들어 줘요.
스트림은 어떤 컬렉션에서도 동작해요.
```smalltalk
stream := WriteStream on: String new.
stream nextPut: $h ; nextPutAll: 'ell' ; nextPut: $o.
stream contents inspect
```
