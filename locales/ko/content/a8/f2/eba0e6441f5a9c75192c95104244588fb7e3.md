# 소개

Clojure의 `vector`는 0개 이상의 값으로 이루어진 컬렉션이에요. 순차적이고 인덱스가 있으며 변경할 수 없죠. 즉, 한 번 `vector`를 만들면 수정할 수 없어요. `vector`를 다루는 함수는 새로운 `vector`를 반환하고, 원래 `vector`는 그대로 남아 있어요. `vector` 안의 값은 서로 다른 타입일 수 있어요. `vector`는 다음과 같이 정의할 수 있어요:

```clojure
(def empty [])
(def single-value [5])
(def single-value-alternative (vector 5))
(def three-values [1 "a" "b"])
```

`vector`의 원소는 인덱스를 사용해 가져올 수 있어요. Clojure의 `vector`는 0부터 시작해요. 즉, 첫 번째 원소의 인덱스는 항상 0이에요:

```clojure
(def numbers [2 3 5])
;; Read value from vector
(get numbers 2)
;;=> 5
;; Update value in vector
(assoc numbers 2 9)
;;=> [2 3 9]
```

원래 `vector`는 변경되지 않아요:

```clojure
numbers
;;=> [2 3 5]
```

업데이트된 값을 기억해 두려면, 그 값을 계속 넘겨주거나 var에 담아 두어야 해요:

```clojure
(def updated-numbers
  (assoc numbers 2 9))
(get updated-numbers 2)
;;=> 9
```
