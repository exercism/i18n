# Debug

YS에는 솔루션 코드를 디버깅하는 데 유용한 내장 `DBG` 함수가 있어요.
이 함수는 인자를 몇 개든 받아서 stderr로 콘솔에 출력해요.
마지막 인자를 반환하기 때문에 코드에서 인라인으로 사용할 수 있어요.


`.DBG()`의 단축형인 `.>` 인라인 연산자를 사용할 수 있어요.

다음은 예제 코드 파일이에요:

```yaml
# file: program.ys

!YS-v0

defn do-it(nums):
  x =: 5

  DBG: -'my vars' x nums

  nums: .map(\(_ * x)).>
        .reverse().>
        .map(str).>
        .join(' - ')

say: do-it(3 .. 5)
```

`ys`로 이 코드를 실행하면 다음과 같은 출력을 볼 수 있어요:

```txt
>>>
"my vars"
5
(3 4 5)
<<<
>>>(15 20 25)<<<
>>>(25 20 15)<<<
>>>("25" "20" "15")<<<
25 - 20 - 15
```


## 컴파일

문제를 해결하는 또 다른 일반적인 방법은 YS 코드가 컴파일된 Clojure 코드를 살펴보는 거예요.

`ys` 명령줄 인터프리터를 `-c` 플래그로 실행하면 이렇게 할 수 있어요.

위의 `program.ys` 파일이 컴파일되면 다음과 같이 돼요:

```clojure
$ ys -c program.ys
(defn do-it [nums]
 (let [x 5]
  (DBG "my vars" x nums)
  (join
   (DBG
    (+map
     (DBG (reverse (DBG (+map nums (fn [& [_1]] (mul+ _1 x))))))
     str))
   " - ")))
(say (do-it (rng 3 5)))
```

`.>` 연산자가 `DBG` 함수 호출로 컴파일된 것을 분명히 볼 수 있어요.
