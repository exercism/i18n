# 개요

Haxe에서는 _상속_ 을 사용해 클래스 계층을 정의할 수 있어요. 상속을 이용하면 파생 클래스(`Car`)가 부모 클래스(`Vehicle`)의 동작과 데이터를 물려받을 수 있어요.

부모 클래스에서는 다음을 할 수 있어요:

- 재정의할 수 있는 메서드
- 파생 클래스에서 반드시 구현해야 하는 추상 메서드

```haxe
abstract class Vehicle {
  public function new() {}

  // Can be overridden
  public function drive() {
    // ...
  }

  // Must be implemented
  public abstract function getSpeed():Int;
}

class Car extends Vehicle {
  public function new() {
    super(); // Runs the parent class' constructor
  }

  public override function drive() {
    // ...
  }

  public function getSpeed():Int {
    // ...
  }
}
```

부모 클래스에 생성자가 있다면 `super()`로 호출해요:

```haxe
abstract class Vehicle {
  var wheels:Int;

  public function new(wheels:Int) {
    this.wheels = wheels
  }
}

class Car extends Vehicle {
  var color:String;

  public function new(wheels:Int, color:String) {
    super(wheels);
    this.color = color;
  }
}

```
