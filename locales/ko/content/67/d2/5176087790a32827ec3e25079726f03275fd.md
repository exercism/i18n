# 지시 사항

친구 Li Mei는 맛있는 혼합 과일 주스를 파는 주스 바를 운영해요.
여러분은 그 가게에 자주 들르는 단골손님이었는데, 코딩 실력으로 친구의 일을 좀 더 편하게 만들어 줄 수 있다는 걸 깨달았어요.
그래서 코딩 실력을 활용해 Li Mei의 일을 돕기로 했어요.

## 1. 주스 하나를 만드는 데 걸리는 시간 구하기

Li Mei는 손님이 주문한 메뉴의 주스를 얼마나 기다려야 하는지 미리 알려 주는 걸 좋아해요.
주스를 만드는 데 걸리는 시간이 제각각이라 정확한 숫자를 외우기는 어려워요.
`"Pure Strawberry Joy"`는 0.5분, `"Energizer"`와 `"Green Garden"`은 각각 1.5분, `"Tropical Island"`는 3분, `"All or Nothing"`은 5분이 걸려요.
그 밖의 다른 음료(예: 스페셜 오퍼)는 준비 시간이 2.5분이라고 가정하면 돼요.

친구를 돕기 위해, 메뉴에 있는 주스 하나를 인자로 받아 그 음료를 만드는 데 걸리는 분 수를 반환하는 함수 `time_to_mix_juice`를 작성해요.

```R
time_to_mix_juice("Tropical Island")
# => 3

time_to_mix_juice("Berries & Lime")
# => 2.5
```

## 2. 라임 웨지 재고 채우기

Li Mei가 만드는 음료에는 재료로든 장식으로든 라임 웨지가 들어가는 경우가 많아요.
그래서 아침에 근무를 시작할 때는 앞으로의 하루를 위해 라임 웨지 통을 가득 채워 둬야 해요.

Li Mei가 잘라야 할 라임 웨지의 개수와, 손에 있는 통라임 재고를 나타내는 배열을 인자로 받는 함수 `limes_to_cut`을 구현해요.
`"small"` 라임에서는 웨지 6개를, `"medium"` 라임에서는 8개를, `"large"` 라임에서는 10개를 얻을 수 있어요.
Li Mei는 항상 목록에 나온 순서대로, 첫 번째 항목부터 라임을 잘라요.
필요한 웨지 개수에 도달하거나 라임이 다 떨어질 때까지 계속 잘라요.

Li Mei는 라임을 몇 개 잘라야 하는지 미리 알고 싶어 해요.
`limes_to_cut` 함수는 잘라야 할 라임의 개수를 반환해야 해요.

```R
limes_to_cut(25, c("small", "small", "large", "medium", "small"))
# => 4
```

## 3. 대기열에 있는 각 주문을 만드는 데 걸리는 시간 나열하기

Li Mei는 손님들이 기다리고 있는 주문을 만드는 데 얼마나 걸릴지 모니터로 확인하고 싶어 해요.

주문 대기열을 인자로 받아, 각 주문을 만드는 데 걸리는 시간을 stdout에 *출력*하는 `order_times` 함수를 구현해요.

```R
order_times(c("Energizer", "Tropical Island"))
# => 1.5 
# => 3
```

## 4. 근무 마무리하기

Li Mei는 항상 오후 3시까지 일해요.
그다음에는 직원인 Dmitry가 이어받아요.
Li Mei의 근무가 끝날 때쯤이면 주문은 들어왔지만 아직 만들지 않은 음료가 남아 있는 경우가 많아요.
그러면 Dmitry가 남은 주스를 만들어요.

인수인계를 쉽게 하기 위해, Li Mei의 근무에 남은 분 수와 아직 만들지 않은 주문된 주스들의 배열을 인자로 받는 함수 `remaining_orders`를 구현해요.
이 함수는 Li Mei가 근무가 끝나기 전에는 만들기 시작할 수 없는 주문들을 반환해야 해요.

근무에 남은 시간은 항상 0보다 커요.
만들어야 할 주스 배열은 절대 비어 있지 않아요.
또한 주문은 배열에 나온 순서대로 만들어져요.
Li Mei가 어떤 주스를 만들기 시작하면, 조금 더 일해야 하더라도 반드시 그 주스를 끝까지 만들어요.
Dmitry가 처리해야 할 남은 주문이 없다면, 빈 벡터를 반환해야 해요.

```R
remaining_orders(5, c("Energizer", "All or Nothing", "Green Garden"))
# => c("Green Garden")
```
