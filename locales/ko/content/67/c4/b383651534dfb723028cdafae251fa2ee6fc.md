# 지침

ABAP 인터널 테이블의 기초를 배워봐요.

클래스에는 `initial_data`라는 인터널 테이블이 있어요. 이 테이블에는 `GROUP`, `NUMBER`, `DESCRIPTION` 세 개의 열이 있어요.

```abap
TYPES group TYPE c LENGTH 1.
TYPES: BEGIN OF initial_type,
         group       TYPE group,
         number      TYPE i,
         description TYPE string,
       END OF initial_type,
       initial_data TYPE STANDARD TABLE OF initial_type WITH EMPTY KEY.
```

## 1단계

첫 번째 할 일은 `fill_itab` 메서드를 완성해서 다음 값들을 가진 레코드 6개를 이 테이블에 넣는 거예요.

| GROUP | NUMBER | DESCRIPTION |
| --- | ----------- | ----------- |
| A | 10 | Group A-2 |
| B | 5 | Group B |
| A | 6 | Group A-1 |
| C | 22 | Group C-1 |
| A | 13 | Group A-3 |
| C | 500 | Group C-2 |

## 2단계

다음으로 `add_to_itab` 메서드를 구현해서 다음 값을 가진 레코드를 인터널 테이블의 끝에 추가해요.

| GROUP | NUMBER | DESCRIPTION |
| --- | ----------- | ----------- |
| A | 19 | Group A-4 |

## 3단계

이제 `sort_itab` 메서드에서 `GROUP` 열은 알파벳 순서로, `NUMBER` 열은 내림차순으로 인터널 테이블을 정렬해 봐요.

## 4단계

`search_itab` 메서드에서는 정렬된 테이블에서 `NUMBER` 열의 값이 6인 레코드를 검색하고, 그 레코드의 인덱스를 반환해요.
