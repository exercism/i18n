# 테스트

## 모든 테스트 실행

`.rakutest` 확장자를 가진 Raku 스크립트가 있어요. 이 스크립트로 풀이를 테스트해요.
다음 명령어로 테스트를 실행할 수 있어요:

`prove6`

연습 문제를 시작하기 전에는 출력이 대략 다음과 비슷해요:

```
# Failed test 'Say Hi!'
# at t/hello-world.rakutest line 6
# expected: "Hello, World!"
#  matcher: 'infix:<eq>'
#      got: "Goodbye, Mars!"
# You failed 1 test of 1
t/hello-world.rakutest ... Dubious, test returned 1
Failed 1/1 subtests
```

`lib/` 디렉터리에 있는 `.rakumod` 확장자를 가진 모듈을 수정하고, 테스트를 통과하는 풀이를 작성해야 해요.
테스트가 통과되면, 위 명령어의 출력은 대략 다음과 비슷해요:

```
t/hello-world.rakutest ... ok
All tests successful.
```

## 첫 실패 후 중단

`RAKU_TEST_DIE_ON_FAIL` 환경 변수를 설정해 두면, 테스트 실행기는 첫 실패 후에 멈춰요. 예를 들어:

Linux / OS X에서는:

```bash
export RAKU_TEST_DIE_ON_FAIL=1
# now all the follow up runs will stop at the first failure
prove6
# until we do
unset RAKU_TEST_DIE_ON_FAIL
# or you can use it for one run like this:
RAKU_TEST_DIE_ON_FAIL=1 prove6
```

또는 Windows에서는:

```
SET RAKU_TEST_DIE_ON_FAIL=1
REM now all the follow up runs will stop at the first failure
prove6
REM until we do
set RAKU_TEST_DIE_ON_FAIL=
```

더 자세한 내용은
[Raku 문서의 테스트 챕터](https://docs.raku.org/language/testing.html)를 참고해요.

## 문제 해결

```
===SORRY!===
Could not find JSON::Fast
```

Raku 트랙에서 사용하는 모든 모듈은 Rakudo Star에 포함되어 있어요.
테스트를 실행하려 할 때 위와 같은 오류 메시지가 나오면, 최신 Rakudo Star 배포판을 사용하고 있는지 확인하거나, 패키지 관리자로 직접 모듈을 설치해야 해요.
모듈 설치 방법은 [Raku 모듈 문서](https://docs.raku.org/language/modules#Looking_for_and_installing_modules.)를 참고해요.
