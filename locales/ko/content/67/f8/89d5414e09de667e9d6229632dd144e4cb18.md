# 개요

[비트 단위 이진 함수][bitwise-wiki]는 [Bitwise 모듈][bitwise-hexdocs]의 함수를 사용해 정수에 적용할 수 있어요.

- [`band/2`][bitwise-and]: 비트 AND
- [`bsl/2`][bitwise-shift-left]: 비트 왼쪽 시프트
- [`bsr/2`][bitwise-shift-right]: 비트 오른쪽 시프트
- [`bxor/2`][bitwise-xor]: 비트 XOR
- [`bor/2`][bitwise-or]: 비트 OR
- [`bnot/1`][bitwise-not]: 비트 NOT

```elixir
Bitwise.band(0b1110, 0b1001)
# => 8 # 0b1000

Bitwise.bxor(0b1110, 0b1001)
# => 7 # 0b0111
```
