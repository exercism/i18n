# 멘토링에서 Markdown 사용하는 방법

GitHub에서 멘토링 댓글을 작성할 때 Markdown을 사용할 수 있어요.
Markdown을 사용하면 코드 조각을 넣고, 제목이나 굵은 글씨, 기울임꼴, 목록 등을 추가하고, 앞선 문장을 인용할 수 있어요.

Exercism에서는 "Github-flavoured Markdown"의 일부 요소도 지원해요. 구체적으로는 구문 강조, 표, 취소선이에요.

Markdown이나 GitHub의 추가 기능이 익숙하지 않다면, [GitHub의 Markdown 안내서](https://guides.github.com/features/mastering-markdown/)를 읽어보는 걸 추천해요.
