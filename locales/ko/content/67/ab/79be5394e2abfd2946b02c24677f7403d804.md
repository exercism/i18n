# 개요

Elm은 완전한 함수형 언어라서 문이 없고 표현식만 있어요. 함수는 항상 하나의 표현식이에요.

이 덕분에 함수를 작고 단순하게 유지할 수 있는데, 이는 대체로 좋은 일이에요. 하지만 때로는 함수가 어쩔 수 없이 더 복잡해지기도 하죠. 그럴 때는 이런 함수도 우아하게 작성할 수 있는 방법이 필요해요.

바로 이럴 때 `let` 표현식이 등장해요. `let` 표현식은 두 부분으로 이루어져 있어요. 필요한 만큼 정의를 만들 수 있는 `let` 부분과, 그 정의를 사용할 수 있는 하나의 표현식인 `in` 부분이에요.

컴퓨팅 용어로 말하면, `let`은 `in` 안의 표현식에만 국한된 스코프를 만들어요.

`let` 표현식은 몇 가지 상황에서 유용해요:

- 표현식을 단순하게 만들 때
- 중간 표현식의 결과에 이름을 붙일 때
- 표현식이 커졌을 때 더 작은 조각으로 나눌 때

`let` 표현식 안에서는 구조 분해를 포함해 대부분의 작업을 할 수 있지만, 다음은 허용되지 않아요:

- 사용자 정의 타입
- 타입 별칭
- 이름 섀도잉 (이미 스코프에 있는 이름을 다시 정의하거나 재사용할 수 없어요)

## 표현식 단순화하기

이 표현식은 세 수의 세제곱을 더하지만 읽기 어렵고, 수마다 계산이 달라지기 쉬워요.

```elm
(a * a * a) + (b * b * b) + (c * c * c)
```

`let` 표현식 안에 `cube` 함수를 정의하면 계산이 더 단순하고 표현력 있게, 또 더 안전해져요. 이 함수에는 타입 애너테이션을 붙일 수도 있지만, 관용적인 Elm 코드에서는 비교적 드물어요.

```elm
let
  cube x = x * x * x
in
  cube a + cube b + cube c
```

## 중간 표현식의 결과에 이름 붙이기

이 코드는 sideArea와 topArea를 정의해서 계산을 더 단순하고 표현력 있게 만들어요.

```elm
cylinderArea : Float -> Float -> Float
cylinderArea radius height =
    let
        sideArea = 2 * pi * radius * height
        topArea = pi * radius ^2
    in
        sideArea + 2 * topArea
```

## 큰 표현식 나누기

이 코드는 [Game of Life](https://playgameoflife.com/) (프로그래밍 연습 문제에서 흔히 볼 수 있는 예제)를 위한 초기 패턴을 만들어요.

정확히 어떻게 동작하는지 이해하는 건 중요하지 않아요. 다만 `let` 없이 하나의 표현식으로 쓰면 아주 커진다는 점은 분명히 보일 거예요.

```elm
beginWithPattern : Size -> Padding -> Pattern -> GameOfLife
beginWithPattern minimumSize padding pattern =
    let
        size = calculateSize minimumSize padding pattern

        center = Size.center size

        centeredPattern = Pattern.centerAt center pattern

        dimensions = { width = size, height = size }

        deadCells = Matrix.create dimensions Dead
    in
    GameOfLife (bringPatternToLife deadCells centeredPattern)
```
