# 가변성

Cairo는 블록체인에 맞춘 설계를 갖추고 있어서 기본적으로 불변 메모리 모델을 사용해요. 즉, 값이 메모리에 한 번 쓰이면 덮어쓸 수 없고 읽기만 할 수 있어요. 하지만 Cairo는 `mut` 키워드를 사용해 가변 변수를 만들 수 있는 방법을 제공해요. 변수가 가변으로 선언된 상태에서 값을 바꾸면, 새 값은 새로운 메모리 셀에 쓰이고 변수는 그 새 셀을 가리키도록 갱신돼요. 이 방식은 불변성의 이점을 그대로 누리면서도 유연성을 제공해요.

아래 예시에서 `x`는 불변 변수로 선언돼요. `x`의 값을 바꾸려고 하면 컴파일러가 오류를 발생시켜요.

```rust
let x = 5;
x = 2; // Error: cannot assign twice to immutable variable
```

`mut` 키워드를 사용하면 `x`를 가변 변수로 선언할 수 있어요. 그러면 `x`가 선언된 뒤에도 값을 바꿀 수 있어요.

```rust
let mut x = 5;
x = 10;
```

결국 가변성을 사용할지 말지는 스스로 결정할 문제이고, 그 특정 상황에서 무엇이 가장 명확하다고 생각하는지에 달려 있어요.

## 상수

불변 변수와 마찬가지로 상수도 이름에 묶인 값이고 변경할 수 없어요. 다만 상수와 변수 사이에는 몇 가지 차이가 있어요.

- 상수는 `const` 키워드로 선언해요
- 상수에는 `mut`를 사용할 수 없어요
- 값의 타입은 항상 명시적으로 지정해야 해요
- 상수는 전역 스코프에서만 선언할 수 있어요
- 상수에는 상수 표현식만 지정할 수 있고, 런타임에 계산된 값의 결과는 지정할 수 없어요

```rust
struct AnyStruct {
    a: u256,
    b: u32
}

enum AnyEnum {
    A: felt252,
    B: (usize, u256)
}

const ONE_HOUR_IN_SECONDS: u32 = 3600;
const STRUCT_INSTANCE: AnyStruct = AnyStruct { a: 0, b: 1 };
const ENUM_INSTANCE: AnyEnum = AnyEnum::A('any enum');
const BOOL_FIXED_SIZE_ARRAY: [bool; 2] = [true, false];
```

`consteval_int!` 매크로를 사용하면 어떤 계산의 결과를 값으로 갖는 `const` 변수를 만들 수 있어요.

```rust
const ONE_HOUR_IN_SECONDS: u32 = consteval_int!(60 * 60);
```

## 섀도잉

여러 번의 `let` 호출로 이름을 다시 선언해서, 값이 변환되는 과정에서 같은 변수 이름을 재사용하는 것이 가능하고 흔히 자연스러운 방식이에요. 이것을 _섀도잉_이라고 해요. 실제로 두 번째 변수는 첫 번째 변수를 가려서, 자기 자신이 다시 가려지거나 스코프가 끝날 때까지 변수 이름이 쓰이는 모든 곳을 차지해요.

```rust
fn main() {
    let s: ByteArray = "my string";
    let s: ByteArray = s + " and a shadow";
    {
        let s: ByteArray = "a nested shadow";
        println!(s); // emits "a nested shadow"
    }
    println!(s); // emits "my string and a shadow"
}
```

섀도잉을 사용하면 같은 변수 이름을 재사용하면서 변수의 타입까지 바꿀 수 있어요.

```rust
fn main() {
    let x: u64 = 2;
    println!("x is u64, value: {}", x);               // prints "x is u64, value: 2"
    let x: ByteArray = format!("fizz");               // converts x to a ByteArray, type annotation is required
    println!("x is now ByteArray, value: \"{}\"", x); // prints 'x is now ByteArray, value: "fizz"'
}
```
