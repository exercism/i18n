# 지침

이 연습 문제에서는 [Blackjack](https://en.wikipedia.org/wiki/Blackjack) 게임의 첫 턴을 시뮬레이션해요.

두 장의 카드를 받고, 딜러가 공개한 카드 한 장을 볼 수 있어요. 모든 카드는 "ace", "king", "three", "two" 같은 문자열로 표현돼요. 각 카드의 값은 다음과 같아요:

| 카드  | 값 | 카드  | 값 |
| :---: | :---: | :---: | :---: |
|  ace  |  11   | eight |   8   |
|  two  |   2   | nine  |   9   |
| three |   3   |  ten  |  10   |
| four  |   4   | jack  |  10   |
| five  |   5   | queen |  10   |
|  six  |   6   | king  |  10   |
| seven |   7   | other |   0   |

**참고**: 보통 에이스는 1 또는 11의 값을 가질 수 있지만, 여기서는 단순화를 위해 11의 값만 가진다고 가정해요.

두 장의 카드와 딜러의 카드에 따라 게임 첫 턴에 쓸 전략이 있어요. 선택할 수 있는 방법은 다음과 같아요:

    - Stand (S)
    - Hit (H)
    - Split (P)
    - Automatically win (W)

아직 최적은 아니지만, 친구 Alex가 계속 다듬어 온 전략을 따라갈 거예요. 그 전략은 다음과 같아요:

분류: 큰 패

- 에이스 두 장을 가지고 있다면 항상 스플릿해야 해요.
- 블랙잭(두 카드의 합이 21인 경우)이고 딜러가 에이스, 그림 카드, 또는 10을 가지고 있지 않다면 자동으로 이겨요. 딜러가 그중 하나라도 가지고 있다면 스탠드하고, 나머지 카드가 공개되기를 기다려야 해요.

분류: 작은 패

- 카드의 합이 17 이상이면 항상 스탠드해야 해요.
- 카드의 합이 11 이하이면 항상 히트해야 해요.
- 카드의 합이 [12, 16] 범위에 있으면 항상 스탠드해야 해요. 단, 딜러가 7 이상을 가지고 있다면 항상 히트해야 해요.

전체 로직은 이미 구현되어 있어요. 이제 네 가지 작업을 해볼까요:

## 1. 주어진 카드의 점수를 계산해요.

조건문을 사용해, 카드의 이름이 주어졌을 때 그 카드의 숫자 값을 계산하는 함수를 구현해요.

```java
parseCard("ace")
// returns 11
```

## 2. 두 카드가 블랙잭을 이루는지 판별해요.

두 카드가 블랙잭을 이루면 `true`를, 그렇지 않으면 `false`를 반환하는 함수를 구현해요.

```java
isBlackjack("queen", "ace")
// returns true
```

## 3. 20점보다 큰 패 점수에 대한 결정 로직을 구현해요.

카드가 주어졌을 때 결정의 문자열 표현을 반환하는 함수를 구현해요. 이 함수는 `handScore`가 20보다 클 때만 호출돼요. `isBlackJack`과 `dealerScore`, 두 개의 인자를 받아요. 위의 "큰 패" 분류에 있는 항목들을 구현해야 해요.

```java
isBlackJack = true
dealerScore = 7
largeHand(isBlackJack, dealerScore)
// returns "W"
```

## 4. 21점 미만의 패 점수에 대한 결정 로직을 구현해요.

카드가 주어졌을 때 결정의 문자열 표현을 반환하는 함수를 구현해요. 이 함수는 `handScore`가 21보다 작을 때만 호출돼요. `handScore`와 `dealerScore`, 두 개의 인자를 받아요. 위의 "작은 패" 분류에 있는 항목들을 구현해야 해요.

```java
handScore = 15
dealerScore = 12
SmallHand(handScore, dealerScore)
// returns "H"
```
