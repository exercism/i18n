# 힌트

## 1. 성공률 계산하기

- 성공률은 [조건식][conditional-expression]을 통해 구할 수 있어요.

## 2. 초당 생산율 계산하기

- F#에서는 서로 다른 두 숫자 타입(예: `int`와 `float`)에 곱셈을 적용할 수 없어요. 따라서 내장된 [변환 연산자][conversion-operators] 중 하나를 사용해 한쪽 숫자 타입을 다른 타입으로 변환해야 해요.
- 숫자는 내장된 [비교 연산자][comparison-operators]를 사용해 비교할 수 있어요.
- `successRate` 함수를 다시 사용할 수 있을까요?

## 3. 초당 생산되는 정상 제품 수 계산하기

- `float`를 `int`로 변환하는 것은 내장된 [변환 연산자][conversion-operators] 중 하나를 통해 할 수 있어요.
