# Configlet으로 파일 만들기

새로운 접근법, 아티클, 연습 문제를 추가할 때는 아주 구체적인 이름의 파일을 만들어야 해요. 구성 파일도 추가하거나 수정해야 하죠. `create` 명령을 사용하면 [configlet](/docs/building/configlet)이 이 모든 작업을 대신해 줘요.

## 사용법

`create` 명령을 사용하면 새로운 접근법, 아티클, 연습 문제를 추가하는 데 필요한 파일을 만들 수 있고, 구성 파일도 수정할 수 있어요.

```shell
configlet [global-options] create [command-options]

Options for create:
      --approach <slug>           The slug of the approach
      --article <slug>            The slug of the article
      --practice-exercise <slug>  The slug of the practice exercise
      --concept-exercise <slug>   The slug of the concept exercise
  -e, --exercise <slug>           Only operate on this exercise
  -o, --offline                   Do not update the cached 'problem-specifications' data
```

## 연습 문제 만들기

[연습 문제 추가 문서](/docs/building/tracks/practice-exercises/add)에 연습 문제를 추가하는 방법이 자세히 나와 있어요.

## 개념 연습 문제 만들기

개념 연습 문제를 만들려면 슬러그를 지정해야 해요:

```shell
configlet create --concept-exercise bird-watcher
```

이렇게 하면 [개념 연습 문제 문서](/docs/building/tracks/concept-exercises)에 나온 대로 개념 연습 문제에 필요한 파일이 만들어져요.

물론 이건 연습 문제를 만드는 첫 단계일 뿐이에요. 그다음에는 다음 작업을 해야 해요:

- 테스트 파일에 테스트 추가하기
- 예시 구현 추가하기
- 스텁 파일의 내용 정의하기
- `.docs/introduction.md`에 소개 작성하기
- `.docs/instructions.md`에 지침 작성하기
- 연습 문제의 `.meta/config.json` 파일에서:
  - `authors` 키에 연습 문제 작성자의 GitHub 사용자 이름 추가하기
- 트랙의 `config.json` 파일에서:
  - 연습 문제의 난이도 확인하거나 수정하기
  - `concepts` 키에 개념 추가하기
  - `prerequisites` 키에 개념 추가하기

## 접근법 만들기

접근법의 파일을 만들려면 접근법과 해당 연습 문제의 슬러그를 지정해야 해요:

```shell
configlet create --approach recursion --exercise collatz-conjecture
```

이렇게 하면 [접근법 문서](/docs/building/tracks/approaches)에 나온 대로 접근법에 필요한 파일이 만들어져요.

## 아티클 만들기

아티클의 파일을 만들려면 아티클과 해당 연습 문제의 슬러그를 지정해야 해요:

```shell
configlet create --article performance --exercise collatz-conjecture
```

이렇게 하면 [아티클 문서](/docs/building/tracks/articles)에 나온 대로 아티클에 필요한 파일이 만들어져요.
