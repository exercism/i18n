# 지침

마술사가 되려는 Elyse는 기초를 좀 연습할 필요가 있어요.

Elyse에게는 조작하고 싶은 카드 더미가 있어요.

조금 더 쉽게 하려고 1부터 10까지의 카드만 사용해요.

카드 더미는 `Array`로 표현하는데, 더미의 맨 아래가 배열의 앞쪽에, 더미의 맨 위가 배열의 뒤쪽에 와요.

## 1. 더미의 맨 위에 카드를 넣기

`insert_top` 함수를 구현해요. 이 함수는 주어진 새 카드를 더미의 맨 위에 추가한 더미의 복사본을 반환해요.

```rust
let stack = array![5, 9, 7, 1];
insert_top(stack, 8);
// -> [5, 9, 7, 1, 8]
```

## 2. 더미에서 맨 위 카드 빼기

`remove_top_card` 함수를 구현해요. 이 함수는 맨 위 카드를 뺀 더미의 복사본을 반환해요.

주어진 더미가 비어 있으면, 원래 더미를 그대로 반환해야 해요.

```rust
let stack = array![3, 2, 6, 4, 8];
remove_top_card(stack);
// -> [3, 2, 6, 4]
```

## 3. 더미의 맨 아래에 카드를 넣기

`insert_bottom` 함수를 구현해요. 이 함수는 주어진 새 카드를 더미의 맨 아래에 추가한 더미의 복사본을 반환해요.

```rust
let stack = array![5, 9, 7, 1];
insert_bottom(stack, 8);
// -> [8, 5, 9, 7, 1]
```

## 4. 더미의 맨 아래에서 카드 빼기

`remove_bottom_card` 함수를 구현해요. 이 함수는 맨 아래 카드를 뺀 더미의 복사본을 반환해요.

주어진 더미가 비어 있으면, 원래 더미를 그대로 반환해야 해요.

```rust
let stack = array![8, 5, 9, 7, 1];
remove_bottom_card(stack);
// -> [5, 9, 7, 1]
```

## 5. 더미의 크기 확인하기

`check_size_of_stack` 함수를 구현해요. 이 함수는 더미의 크기가 주어진 `stack_size`와 같은지 확인해요.

```rust
let stack = array![3, 2, 6, 4, 8];
check_size_of_stack(stack, 4);
// -> false
```
