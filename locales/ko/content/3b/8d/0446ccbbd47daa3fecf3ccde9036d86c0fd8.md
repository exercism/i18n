# 지침 추가

## 구현

`RestAPI` 클래스의 `get`과 `post` 메서드를 구현해요.

실제 HTTP 서버를 구현할 필요 없이 핸들러 함수만 작성하면 돼요. 저장된 모든 사용자를 담을 메모리 내 객체를 사용해 데이터베이스를 모킹할 수 있어요. `RestAPI` 클래스의 생성자는 이 데이터베이스의 인스턴스를 인자로 받아야 해요(인자가 전달되지 않았다면 기본값도 설정해야 하고요).

이 구현에서는 `GET` 요청의 경우 페이로드가 URL의 일부여야 하며, 예를 들어 `/users?users=Adam,Bob`처럼 쿼리 매개변수로 다뤄야 해요.
