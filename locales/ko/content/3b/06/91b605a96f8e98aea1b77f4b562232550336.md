# `case`문

```sather
   case zone
   when 0 then return 0;
   when 1, 2 then return 550;
   else return 920;
   end;
```

## 어떻게 일치할까요

`case` 뒤의 값은 `=`를 사용해 각 `when` 값과 위에서 아래로 비교돼요. 처음 일치하는 부분만 실행되고, 나머지 `when` 부분은 건너뛴 뒤 `end` 다음부터 실행이 이어져요.

`=`를 지원하는 타입이라면 무엇이든 사용할 수 있어요: `INT`, `CHAR`, `STR`, `BOOL`.

## `else` 절

`else`가 없는 `case`에서 어느 것도 일치하지 않으면 실행 중에 치명적인 오류가 발생해요. 그러니 항상 `else`를 써요. 남은 경우가 정말로 일어나서는 안 되는 상황이라면, `else`를 생략하는 대신 거기서 그 사실을 분명히 알려 주세요:

```sather
   else
      raise "unknown zone: " + zone;
   end;
```

`raise`는 나중에 배워요. 그 전까지는 적절한 기본값을 반환해도 괜찮아요.

## `if`가 더 나은 경우

`case`는 하나의 값을 상수와 비교해요. 그 밖의 경우에는 `if`가 어울려요:

```sather
   -- ranges
   if age < 13 then ... elsif age < 16 then ... end;

   -- more than one value at a time
   if score >= 8 and sings then ... end;
```

범위를 억지로 `case`에 넣으려 하면, 원래의 `if`보다 더 길고 더 나쁜 코드가 나와요.

## 표현식으로서의 `case`

`case`는 표현식이 아니라 문이에요. 그래서 다음은 Sather 코드가 아니에요:

```sather
   -- wrong
   fare := case zone when 1 then 550 else 920 end;
```

각 분기 안에서 반환하거나, 각 분기 안에서 변수에 대입해요.
