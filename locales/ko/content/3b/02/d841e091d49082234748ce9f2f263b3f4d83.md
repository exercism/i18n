# 힌트

## 일반

- 불리언 값을 다룰 때 사용할 수 있는 [불리언 연산자][boolean-operators]가 세 개 있어요.
- 여러 연산자를 하나의 식에 함께 사용할 수 있어요.

## 1. 빠른 공격을 할 수 있는지 확인하기

- 논리 NOT 연산자(`!`)를 식 앞에 붙이면 값이 반전돼요.

## 2. 일행을 감시할 수 있는지 확인하기

- 불리언 연산자는 보통 두 개 이상의 식이 참인지 참이 아닌지를 판단할 때 사용해요.

## 3. 죄수에게 신호를 보낼 수 있는지 확인하기

- 불리언 연산자는 우선순위가 높은 순서대로, 즉 `!`, `&&`, `||` 순서로 실행돼요.
- 일반적으로 의도를 더 분명하게 드러내려면 괄호를 사용하는 것이 좋아요.
- 더 자세한 내용은 [Julia 공식 문서][operator-precedence]의 연산자 우선순위 섹션을 확인해 봐요.

## 4. 'Free Prisoner' 옵션을 표시해야 하는지 확인하기

- 불리언 연산자는 우선순위가 높은 순서대로, 즉 `!`, `&&`, `||` 순서로 실행돼요.
- 일반적으로 의도를 더 분명하게 드러내려면 괄호를 사용하는 것이 좋아요.
