# 지침

다프네는 실험을 실행하고 그 결과를 기록하는 시스템을 만들고 있어요. 코드 일부가 조금 장황하고 반복적이게 되어서, 다프네는 코드를 깔끔하게 정리하는 데 도움이 되도록 `use` 표현식을 몇 개 작성해 달라고 부탁했어요.

## 1. `with_retry` 함수를 정의해요

때로는 실험이 일회성 실수 때문에 실패할 수 있어요. 그래서 실험이 실패하면 다프네는 다시 시도해서 두 번째에는 잘 되는지 확인하고 싶어 해요.

결과를 반환하는 함수를 인자로 받는 `with_retry` 함수를 정의해요.

함수가 `Ok` 값을 반환하면 `with_retry`는 그 값을 반환해야 해요.

함수가 `Error` 값을 반환하면 `with_retry`는 함수를 다시 호출하고 그 호출의 결과를 반환해야 해요.

다프네는 이 함수를 이렇게 사용할 거예요:

```gleam
pub fn main() {
  use <- with_retry
  // Perform the experiment here
}
```

## 2. `record_timing` 함수를 정의해요

다프네는 각 실험이 실행되는 데 걸리는 시간을 기록하기 위해, 실험 전후에 시간 기록 함수를 호출해요.

두 개의 인자를 받는 `record_timing` 함수를 정의해요:
- 인자를 받지 않고 `Nil`을 반환하는 시간 기록 함수.
- 인자를 받지 않고 결과를 반환하는 실험 함수.

`record_timing`은 시간 기록 함수를 호출한 다음, 실험 함수를 호출하고, 다시 시간 기록 함수를 호출한 뒤, 마지막으로 실험 함수의 결과를 반환해야 해요.

다프네는 이 함수를 이렇게 사용할 거예요:

```gleam
pub fn main() {
  use <- record_timing(time_logger)
  // Perform the experiment here
}
```

## 3. `run_experiment` 함수를 정의해요

실험은 세 단계로 이루어져 있어요. 준비, 실행, 기록이에요. 세 단계 모두 결과를 반환하고, 각 단계는 실행되기 위해 이전 단계의 성공적인 결과가 필요해요.

네 개의 인자를 받는 `run_experiment` 함수를 정의해요:
- `String` 타입의 실험 이름.
- 인자를 받지 않고 결과를 반환하는 준비 함수.
- 준비 함수의 `Ok` 값을 인자로 받고 결과를 반환하는 실행 함수.
- 준비 함수와 실행 함수의 `Ok` 값을 인자로 받고 결과를 반환하는 기록 함수.

세 함수가 모두 성공하면 `run_experiment`는 `Ok(#(experiment_name, recording_data))`를 반환해야 해요.

함수 중 하나라도 `Error` 값을 반환하면 `run_experiment`는 그 값을 반환해야 해요.

다프네는 이 함수를 이렇게 사용할 거예요:

```gleam
pub fn main() {
  use setup_data, action_data <- run_experiment("Test 1", setup, action)
  // Record the results here
}
```
