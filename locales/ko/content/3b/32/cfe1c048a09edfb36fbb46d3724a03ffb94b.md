# 소개

## 문자열

`jq`가 JSON과 동일한 데이터 타입을 지원한다는 점을 떠올려 봐요.
JSON은 **문자열**을 이렇게 설명해요:

> 문자열은 0개 이상의 유니코드 문자로 이루어진 나열이며, 큰따옴표로 감싸고 백슬래시 이스케이프를 사용해요.

### 이스케이프 시퀀스

문자열 안에서는 백슬래시 문자를 사용해 "특수" 문자를 넣을 수 있어요:

- `\"` 큰따옴표 문자 그대로
- `\\` 백슬래시 문자 그대로
- 공백 문자 `\n`, `\t`, `\r`, `\f`, `\b`
- 유니코드 문자 `\uAAAA` (`A`는 16진수 숫자)

### 문자열 길이

문자의 개수를 구하려면 `length` 함수를 사용해요.

```sh
$ jq -cn --args  '$ARGS.positional[] | length' "Hello world!" "❄🌡🤧🤒🏥🕰😀"
12
7
```

### 부분 문자열

**슬라이스** 표기법으로 부분 문자열을 추출할 수 있어요.
문법은 `.[i:j]`예요.
반환되는 부분 문자열의 길이는 `j - i`이고, 인덱스 `i`(포함)부터 인덱스 `j`(미포함)까지의 문자를 반환해요.
두 인덱스 모두 음수가 될 수 있고, 이 경우 문자열의 끝에서부터 거꾸로 세요.
두 인덱스 모두 생략할 수 있고, 이 경우 문자열의 시작이나 끝을 가리켜요.
인덱스는 0부터 시작해요.

```jq
"abcdefghij"[3:6]   # => "def"
"abcdefghij"[3:]    # => "defghij"
"abcdefghij"[:-2]   # => "abcdefgh"
```

### 결합

문자열을 이어 붙일 때는 `+`를 사용해요:

```jq
"Hello" + " " + "world!"
# => "Hello world!"
```

문자열 배열이 주어졌을 때는 `add`를 사용해요:

```jq
["Hello", " ", "world!"] | add
# => "Hello world!"
```

### 나누기와 합치기

나누기는 `split/1` 함수나 `/` 연산자를 사용해요:

```jq
"Hello beautiful world!" | split(" ")   # => ["Hello", "beautiful", "world!"]
```

```jq
"Hello beautiful world!" / " "          # => ["Hello", "beautiful", "world!"]
```

`split/1`의 역은 `join/1`이에요.

문자열을 문자 배열로 바꾸는 일은 자주 필요해요.
이를 위한 방법은 두 가지가 있어요:

1. 빈 문자열을 기준으로 나누기

   ```jq
   "Hi friend 😀" / ""   # => ["H","i"," ","f","r","i","e","n","d"," ","😀"]
   ```

1. `explode`로 _코드포인트_ 배열로 만들기

   ```jq
   "Hi friend 😀" | explode   # => [72,105,32,102,114,105,101,110,100,32,128512]
   ```

   `implode`는 `explode`의 역이에요.

### 부분 문자열의 인덱스 찾기

`index/1` 함수를 사용해요. 인덱스는 0부터 시작해요.

```jq
"hello" | index("el")'   # => 1
```

부분 문자열이 문자열 안에 없으면 결과는 `null`이에요.

```jq
"hello" | index("elk")   # => null
```

### 문자열 보간

문자열 안에서 `\(expression)` 시퀀스는 그 표현식의 _결과_를 [문자열에][interpolate] 넣어요:

```jq
"The current datetime is \(now | strflocaltime("%c"))"   # => "The current datetime is Wed Nov 16 17:06:33 2022"
```

### 대소문자 변환

`ascii_downcase`와 `ascii_upcase` 함수를 사용해요.

### 정규 표현식

`jq`는 정규 표현식을 풍부하게 지원해요. 이 내용은 나중 레슨에서 다뤄요.

[interpolate]: https://jqlang.org/manual/#string-interpolation
