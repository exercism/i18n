# 소개

## 루프

루프는 어떤 로직을 반복해서 실행할 때 사용해요.
가장 흔한 두 가지는 `while loop`(반복 횟수가 정해지지 않은 반복)와 `for loop`(정해진 횟수만큼 하는, 즉 계수 반복)예요.
나중에 다른 개념에서 다룰 `for each` 루프도 있어요.

### 일반적인 문법

`for loop`는 헤더와, 루프의 본문을 중괄호로 감싼 코드 블록으로 이루어져 있어요.
헤더는 세미콜론 `;`으로 구분되는 세 가지 요소, 즉 초기문, 조건, 그리고 또 다른 표현식으로 이루어져 있어요.
이 요소들은 각각 비워 둘 수도 있어요.

```cpp
for (init_statement; condition; expression) {
  some_statement;
}
```

- **초기문** 요소는 루프가 시작되기 전에 딱 한 번만 실행되는 코드예요.
- **조건** 요소는 `boolean`으로 평가되는 표현식이어야 하고, 루프를 언제 멈출지 결정해요.
  이 조건이 `true`로 평가되는 동안에는 루프 안의 코드가 실행돼요.
  이 표현식이 `false`로 평가되는 순간, 루프는 더 이상 반복되지 않아요.
- **표현식** 요소는 각 반복이 끝날 때마다 실행되는 코드예요.

`while loop`는 **조건** 검사가 `true`인 동안 본문을 실행해요.
아래 코드는 `for`를 `while loop`로 바꾸는 방법을 보여줘요.

```cpp
init_statement;
while(condition) {
    some_statement;
    expression;
}
```

### 잠시 쉬어가기: 증가와 감소

루프를 다루다 보면 반복 횟수를 세는 카운터 변수에 1을 더하거나 1을 빼야 할 때가 많아요.
너무 흔한 일이라 증가와 감소에는 전용 연산자 `++`와 `--`가 있어요.

이 연산자에는 **전위**형과 **후위**형이 있어요.
전위형은 문에서 사용되기 전에 변수를 바꾸고, 후위형은 사용된 뒤에 바꿔요.
대부분은 전위형을 쓰게 될 거예요.

```cpp
int a{3};
int b{--a};
// b is 2, a is now 2
int c{a++};
// c is 2, a is now 3
```

### `for`문 예제

_초기문_은 보통 카운터 변수를 준비하고, _조건_은 루프를 계속할지 멈출지 판단하며, _증감문_은 보통 매 반복이 끝날 때 카운터를 증가시켜요.

```cpp
int sum{0};
for (int i{1}; i < 10; ++i) {
  sum += i;
}
```

이 루프는 `1`부터 `9`까지(`9` 포함)의 수를 모두 더해요.

### `break`와 `continue`

루프 본문 안에서 `break` 키워드를 사용하면 루프 실행을 완전히 멈출 수 있어요.

```cpp
int sum{2};
while(true) {
    sum *= 2;
    if (sum > 1000)
        break;
}
// sum is now 1024
```

반면에 `continue` 키워드는 현재 반복의 실행만 멈추고 다음 반복을 이어가요.

```cpp
int equal_sum{0};
for (int i{1}; i < 7; ++i) {
  if  (i%2 == 1) {
    continue;
  }
  equal_sum += i;
}
// equal_sum is now 12
```

~~~~exercism/note
`break`와 `continue`를 최소한으로 쓰거나 아예 쓰지 않으면 루프의 논리를 이해하기가 보통 더 쉬워요.
두 키워드 모두 코드의 특정 부분을 건너뛰기 때문에, 흐름을 따라가기가 더 어려워지곤 해요.
~~~~
