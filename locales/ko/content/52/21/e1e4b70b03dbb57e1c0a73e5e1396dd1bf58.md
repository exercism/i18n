# 개요

`Option` 타입은 값이 있을 수도 없을 수도 있는 값을 다루기 위한 F# 언어의 메커니즘이에요.
다른 언어에서 이런 값을 다룰 때 흔히 쓰는 `null` 대신 사용할 수 있는, 타입에 안전한 대안을 제공해요.
많은 F# 표준 라이브러리 함수에서 사용되기 때문에, F# 표준 라이브러리를 제대로 활용하려면 `Option`을 이해하는 게 꼭 필요해요.

## `Option` 타입을 사용하면 좋은 점

* __컴파일 타임 안전성__: 값의 존재 여부를 타입 시스템에서 명시적으로 드러내기 때문에, 컴파일러가 "값이 없음" 경우까지 처리하도록 보장할 수 있어요. 그래서 null로 인해 생길 수 있는 큰 범주의 bug를 미리 막을 수 있어요.

* __런타임 안전성__: F#은 `null` 대신 `None`으로 값이 없음을 나타내기 때문에, `NullReferenceException`이 발생하는 것이 불가능해요.

* __명시적인 처리 강제__: 타입 시스템은 코드가 `Some value`와 `None` 두 경우를 모두 명시적으로 처리하도록 요구하기 때문에, 코드가 더 견고하고 예측 가능해져요.

* __패턴 매칭과의 호환__: `Option`은 F#의 패턴 매칭 관용구와 자연스럽게 어울려서, 값이 있으면 안전하게 꺼내서 처리하고 없으면 다른 동작을 하는 깔끔하고 안전한 방법을 제공해요.

## 사용법

`Option` 타입은 제네릭 타입이에요(바탕이 되는 타입을 하나 가지고 있어요).
`Option` 값은 특정 값을 나타내는 `Some value`이거나, 값이 없음을 나타내는 `None`이에요.

다음 함수는 `Option` 값을 만드는 방법을 보여줘요:

```fsharp
let keepIfPositive (a: int) : int option = if a > 0 then Some a else None
```

~~~~exercism/note
`T option`은 `Option<T>`에 해당하는 후위 표기 문법이에요. 이 두 문법 형식은 서로 바꿔 쓸 수 있어요.
하지만 F# 스타일 가이드에 따르면 Option 타입에는 후위 표기를 사용하는 것이 권장돼요([F# 스타일 가이드의 타입 및 타입 주석 서식 섹션](https://learn.microsoft.com/en-us/dotnet/fsharp/style-guide/formatting#for-types-prefer-prefix-syntax-for-generics-foot-with-some-specific-exceptions)).
~~~~

`Option`의 대표적인 사용 사례는 검색 함수예요.
예를 들어, `List.tryFind` 함수는 항목이 리스트에 있으면 `Some index`를 반환하고(여기서 `index`는 리스트에서 찾는 값의 위치예요), 항목이 리스트에 없으면 `None`을 반환해요.

## Option 값의 내용 읽기

`Option` 값을 읽는 관용적인 방법은 다음 예시처럼 패턴 매칭을 사용하는 거예요:

```fsharp
// Returns "Hello, <name>!" if the name is provided; otherwise returns "Hello, you!"
let sayHello (optionalName: string option): string = 
    match optionalName with
    | Some name -> "Hello, " + name + "!"
    | None -> "Hello, you!"

sayHello (Some "Matthieu")
// --> "Hello, Matthieu!"

sayHello None
// --> "Hello, you!"
```

## 기본값으로 Option 풀어내기

`Option`은 `Option.defaultValue` 함수로 기본값을 지정해서 "풀어낼" 수 있어요(안에 담긴 타입으로 변환하는 거예요).
값이 `None`이 아니도록 보장하고 싶을 때 특히 유용해요.
예를 들어:

```fsharp
Option.defaultValue "" (Some "F#")
// --> "F#"

Option.defaultValue 0 None
// --> 0
```

## `Option` 모듈의 더 많은 함수들

`Option` 모듈에는 리스트, 배열, 시퀀스 및 다른 컬렉션 타입에서 사용할 수 있는 함수에 대응하는 함수들도 있어요. 예를 들어 `Option.map`, `Option.iter`, `Option.forall`, `Option.count` 같은 것들이에요.
이 함수들을 사용하면 `Option`을 요소가 0개 또는 1개인 컬렉션처럼 다룰 수 있어요.
