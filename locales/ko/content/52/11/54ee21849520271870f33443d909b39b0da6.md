# 소개

루프는 어떤 로직을 반복해서 실행할 때 사용해요.
가장 흔한 두 가지는 `while loop`(반복 횟수가 정해지지 않은 경우)와 `for loop`(정해진 횟수, 즉 세어서 반복하는 경우)예요.
나중 개념에서 다룰 `for each` 루프도 있어요.


## 기본 문법

`for loop`는 헤더와, 중괄호로 감싼 루프 본문이 담긴 코드 블록으로 이루어져 있어요.
헤더는 세미콜론 `;`으로 구분되는 세 가지 구성 요소, 즉 init-statement, condition, expression으로 이루어져 있어요.
이들은 각각 비워 둘 수도 있어요.

```cpp
for (init-statement; condition; expression) {
  some_statement;
}
```

- **init** 구성 요소는 루프가 시작되기 전에 딱 한 번만 실행되는 코드예요.
- **condition** 구성 요소는 불리언으로 평가되는 표현식이어야 하고, 루프를 언제 멈출지 결정해요.
이 조건이 true로 평가되는 동안 루프 안의 코드가 실행돼요.
이 표현식이 false로 평가되는 순간, 루프는 더 이상 반복되지 않아요.
- **expression** 구성 요소는 각 반복이 끝날 때 실행되는 코드예요.


`while loop`는 조건 검사가 true인 동안 본문을 실행해요.
아래 코드는 `for`문을 `while`문으로 바꾸는 방법을 보여줘요.

```cpp
init-statement;
while(condition) {
    some_statement;
    expression;
}
```

## 잠깐: 증가와 감소

루프를 다루다 보면 카운터 변수에 1을 더하거나 1을 빼야 할 때가 자주 있어요.
이 일이 워낙 흔해서, 이 연산에는 `++`와 `--`라는 전용 연산자가 있어요.

이 연산자에는 전위 형식과 후위 형식이 있어요.
전위 형식은 문에서 쓰이기 전에 변수를 바꾸고, 후위 형식은 쓰인 뒤에 바꿔요.
대부분의 경우에는 전위 형식을 쓰게 될 거예요.

```cpp
int a{3};
int b{--a};
// b is 2, a is now 2
int c{a++};
// c is 2, a is now 3
```

## `for`문 예제

init 구성 요소는 보통 카운터 변수를 준비하고, condition은 루프를 계속할지 멈출지 검사하며, post 구성 요소는 보통 반복이 끝날 때마다 카운터를 증가시켜요.

```cpp
int sum{0};
for (int i{1}; i < 10; ++i) {
  sum += i;
}
```

이 루프는 `1`부터 `9`까지(`9`도 포함)의 수를 모두 더해요.

## break와 continue

루프 본문 안에서는 `break` 키워드로 루프 실행을 완전히 멈출 수 있어요:

```cpp
int sum{2};
while(true) {
    sum *= 2;
    if (sum > 1000)
        break;
}
// sum is now 1024
```

반대로 `continue` 키워드는 현재 반복의 실행만 멈추고 다음 반복으로 넘어가요:

```cpp
int equal_sum{0};
for (int i{1}; i < 7; ++i) {
  if  (i%2 == 1) {
    continue;
  }
  equal_sum += i;
}
// equal_sum is now 12
```
> 참고: `break`와 `continue`의 사용을 최소화하거나 아예 쓰지 않으면, 루프의 로직을 이해하기가 보통 더 쉬워요.
