# 지시사항

지역 예술 센터에서 자원봉사를 하고 있는데, 정문 위에 긴 세라믹 타일 모자이크가 올라가고 있어요. 디자인팀은 작업을 **줄 단위로** 배치했어요. 각 줄은 타일 색상의 배열이고, 전체 모자이크는 줄들의 배열이에요.

자원봉사자들이 타일을 자르고 붙이고 다시 배치하는 동안, 디자인의 조각들을 만들고, 합치고, 찾아보는 데 쓸 작고 재사용 가능한 단어들을 작성하고 있어요.

## 1. 타일 한 개짜리 줄

`tile-strip`을 정의해서 색상 하나를 받아, 그 색상만 담은 원소 한 개짜리 줄을 반환하게 해요.

```factor
"sky-blue" tile-strip .
! => { "sky-blue" }
```

## 2. 타일 세 개짜리 줄

`row-of-three`를 정의해서 스택에서 색상 세 개를 꺼내, 원소 세 개짜리 줄을 반환하게 해요.

```factor
"red" "white" "blue" row-of-three .
! => { "red" "white" "blue" }
```

## 3. 줄들을 합쳐 평평한 타일 배열로 만들기

디자인팀은 모자이크의 모든 줄에 걸쳐 색상 총합을 확인해야 해요. `combine-rows`를 정의해서 줄들의 배열을 받아, 모든 타일을 순서대로 담은 하나의 배열을 반환하게 해요.

```factor
{ { "red" "white" } { "blue" "red" } } combine-rows .
! => { "red" "white" "blue" "red" }
```

## 4. 줄 뒤집기

대칭 패널을 만들 때는 팀이 줄을 거울처럼 뒤집은 다음, 그 복사본을 반대쪽에 놓아요. `mirror-row`를 정의해서 줄을 역순으로 반환하게 해요.

```factor
{ "red" "white" "blue" } mirror-row .
! => { "blue" "white" "red" }
```

## 5. 이 색상은 줄에서 어디에 있을까요?

`tile-position`을 정의해서 줄과 색상을 받아, 그 색상을 가진 첫 번째 타일의 인덱스(0부터 시작)를 반환하게 해요. 색상이 없으면 `f`를 반환해요.

```factor
{ "red" "white" "blue" } "white" tile-position .
! => 1

{ "red" "white" "blue" } "green" tile-position .
! => f
```

## 6. 이 줄에 그 색상이 들어 있나요?

`has-colour?`를 정의해서 줄과 색상을 받아, 그 색상이 줄 어디에든 나타나면 `t`를, 그렇지 않으면 `f`를 반환하게 해요.

```factor
{ "red" "white" "blue" } "white" has-colour? .
! => t

{ "red" "white" "blue" } "green" has-colour? .
! => f
```
