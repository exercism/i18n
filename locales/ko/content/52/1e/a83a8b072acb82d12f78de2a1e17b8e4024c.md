# 테스트

`exercism test` 또는 `eutest`로 테스트를 실행해요. 기본적으로 모든 테스트가 실행돼요.

## 테스트 건너뛰기

시작하기 좋은 방법은 `t_<exercise>.e`에서 첫 번째 테스트를 제외한 나머지 테스트를 모두 주석 처리하는 거예요.

```euphoria
test_equal("no name given", "One for you, one for me.", two_fer())
-- test_equal("a name given", "One for Alice, one for me.", two_fer("Alice"))
-- test_equal("another name given", "One for Bob, one for me.", two_fer("Bob"))
```

한 번에 하나씩 풀어가면서, 지금 테스트가 통과하면 다음 테스트의 주석을 풀어요. 모든 테스트가 통과하면 연습 문제를 완료한 거예요.
