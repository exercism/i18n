# 지침

Spellbound Steel이라는 카드 게임에서는 warrior, mage, rogue 같은 서로 다른 캐릭터 카드나 fireball, ice storm, lightning bolt 같은 서로 다른 주문 카드로 덱을 구성해요.
게임에는 두 명에서 네 명의 플레이어가 참여하고, 목표는 더 높은 파워 레벨의 카드를 내서 다른 플레이어를 물리치는 거예요.

카드의 파워 레벨을 계산하고 정렬하고 비교하는 다양한 메서드를 만들어 게임에서 우위를 점하고 싶어요.

## 1. 덱에서 카드 찾기

어떤 카드가 덱에 있는지 없는지 확실하지 않아요.
그래서 찾고 있는 종류의 카드가 덱에서 처음 어디에 있는지 알려주는 메서드가 필요해요.
카드가 덱에 없다면 그 사실도 알고 싶어요.

`String` 카드들의 `Array`와 찾을 `String` 카드를 받는 `SpellboundSteel.find_card?` 메서드를 구현해요.
이 메서드는 찾는 카드와 일치하는 덱의 첫 번째 카드의 인덱스를 반환해야 해요.
카드가 덱에 없으면 메서드는 `nil`을 반환해야 해요.

```crystal
cards = ["Warrior", "Mage", "Rogue", "Fireball", "Ice Storm", "Lightning Bolt", "Mage"]
SpellboundSteel.find_card?(cards, "Mage")
# => 1
```

## 2. 모든 글자를 대문자로 만들기

카드를 더 읽기 쉽게 만들기 위해 카드 이름의 모든 글자를 대문자로 바꾸고 싶어요.
그래야 카드를 낼 때 카드 이름을 쉽게 알아볼 수 있어요.

`String` 카드들의 `Array`를 받아 모든 글자를 대문자로 만든 카드를 반환하는 `SpellboundSteel.capitalize_cards` 메서드를 구현해요.

```crystal
cards = ["warrior", "mage", "rogue", "fireball", "ice storm", "lightning bolt"]
SpellboundSteel.capitalize_cards(cards)
# => ["Warrior", "Mage", "Rogue", "Fireball", "Ice Storm", "Lightning Bolt"]
```

## 3. 모든 카드의 파워 레벨 계산하기

게임에서는 모든 카드의 파워 레벨을 계산하는 것이 중요해요.
모든 카드의 파워는 다음 표에서 볼 수 있어요.

| 카드 유형 | 파워 레벨 |
|----------------|-------------|
| Warrior        | 10          |
| Mage           | 20          |
| Rogue          | 30          |
| Fireball       | 15          |
| Ice Storm      | 25          |
| Lightning Bolt | 35          |

`String` 카드들의 `Array`를 받아 모든 카드의 총 파워 레벨을 반환하는 `SpellboundSteel.calculate_power_level` 메서드를 구현해요.

```crystal
cards = ["Warrior", "Mage", "Rogue", "Fireball", "Ice Storm", "Lightning Bolt"]
SpellboundSteel.calculate_power_level(cards)
# => 135
```

## 4. 카드 해독하기

게임에는 저주받은 카드라고 불리는 카드가 있어요.
이 카드는 카드를 낸 플레이어만 해독할 수 있는 숨겨진 카드예요.
카드를 해독하려면 카드 이름에서 두 번째 글자마다 하나씩 제거해야 해요.
그러면 카드의 이름이 나와요.

`String` 카드를 받아 해독된 카드를 반환하는 `SpellboundSteel.decode_card` 메서드를 구현해요.

```crystal
SpellboundSteel.decode_card("Wbalrrrlimoqr")
# => "Warrior"
```
