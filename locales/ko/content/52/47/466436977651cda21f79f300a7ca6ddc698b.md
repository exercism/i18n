## 사용 방법

### 빌드

`npx blueprint build` 또는 `yarn blueprint build`

### 테스트

`npx blueprint test` 또는 `yarn blueprint test`

### 배포하거나 다른 스크립트 실행하기

`npx blueprint run` 또는 `yarn blueprint run`

### 새 컨트랙트 추가하기

`npx blueprint create ContractName` 또는 `yarn blueprint create ContractName`
