# 지침 추가

# 입력

이 연습 문제의 입력은 다음과 같아요:

- `target`: 문자열(예: `'stone'`)이며 _왼쪽 인자_가 돼요.
- `candidates`: 박스로 감싼 문자열의 목록(예: `'stone' ; 'tones' ; 'banana' ; 'tons' ; 'notes' ; 'Seton'`)이며 _오른쪽 인자_가 돼요.

동사는 다음과 같이 호출돼요:

```j
  target     =. 'stone'
  candidates =. 'stone' ; 'tones' ; 'banana' ; 'tons' ; 'notes' ; 'Seton'
  
  subject findAnagrams candidates
```

## 출력

동사는 target의 애너그램인 문자열을 담은 박스의 _목록_을 반환해야 해요. 애너그램이 없으면 결과는 `empty`여야 해요.
