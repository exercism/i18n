# 안내

이 연습 문제에서는 프리랜서가 프로젝트 관리자와 소통할 수 있도록 돕는 코드를 작성해요.
이 과제에서는 일당과 월당을 빠르게 계산하는 몇 가지 유틸리티를 만들어요. 필요에 따라 주어진 할인을 적용할 수도 있어요.

먼저 프리랜서와 프로젝트 관리자 사이에 몇 가지 규칙을 정해요:

- 일당은 시급의 8배예요.
- 한 달은 청구 가능한 날이 22일이에요.

때로는 프리랜서가 일당에 할인을 적용하기도 해요 (가장 충성도 높은 고객이나 비영리 고객을 위해서요).

할인은 백분율을 나타내는 소수로 표현해요. 예를 들어 `25.0`은 25%예요.

## 1. 시급으로 일당 계산하기

매개변수로 시급이 주어졌을 때 일당을 계산하는 `dailyRateFrom` 함수를 구현해요.
계약상 하루는 청구 가능한 8시간이에요.

```swift
dailyRateFrom(hourlyRate: 60)
// Returns 480.0
```

반환되는 일당은 `Double`이어야 해요.

## 2. 시급과 할인이 주어졌을 때 월당 계산하기

할인이 적용된 월당을 계산하는 `monthlyRateFrom` 함수를 구현해요.
이 함수는 시급과 백분율로 나타낸 할인, 두 가지 매개변수를 받아요.


```swift
monthlyRateFrom(hourlyRate: 77, withDiscount: 10.5)
// Returns 12129
```

반환되는 월당은 가장 가까운 정수로 올림해야 해요.

## 3. 예산, 시급, 할인이 주어졌을 때 온전한 근무일 수 계산하기

예산, 시급, 할인을 받아서 그 예산으로 며칠을 온전히 일할 수 있는지 계산하는 `workdaysIn` 함수를 구현해요.

```swift
workdaysIn(budget: 20000, hourlyRate: 80, withDiscount: 11.0)
// Returns 35.0
```
반환되는 일수는 다음 정수로 내림해야 해요.
