# 소개

C#은 객체 지향, 선언형, 함수형, 제네릭, 지연 평가, 통합 쿼리 기능과 타입 추론을 갖춘 다중 패러다임 정적 타입 프로그래밍 언어예요.

**정적 타입**이란 식별자가 컴파일 시점에 정해진 [타입](https://en.wikipedia.org/wiki/Type_system#Static_type_checking)을 가진다는 뜻이에요. Java, C++, Haskell이 그렇죠. Python, Ruby, JavaScript처럼 아무 타입의 데이터나 담을 수 있는 것과는 달라요.

**객체 지향**이란 C#이 단일 상속, 인터페이스, 캡슐화 같은 기능을 갖춘 명령형 [클래스 기반 객체](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/object-oriented-programming)를 제공한다는 뜻이에요.

**선언형**이란 [무엇을 할지](https://stackoverflow.com/questions/1784664/what-is-the-difference-between-declarative-and-imperative-programming)를 프로그래밍하는 것이고, 어떻게 할지(명령형 프로그래밍)와는 반대돼요. 어떻게 할지는 도메인이나 비즈니스 로직에서 눈을 돌리게 만들 수 있는 구현 세부 사항이거든요.

**함수형**이란 [함수가 일급 데이터 타입](https://livebook.manning.com/#!/book/functional-programming-in-c-sharp/chapter-1)이라는 뜻이에요. 함수를 다른 함수에 인자로 넘기거나 다른 함수에서 반환받을 수 있죠.

**제네릭**이란 알고리즘을 [나중에 지정할 타입](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/generics/generic-type-parameters)의 관점에서 작성하고, 필요할 때 매개변수로 주어진 구체적인 타입에 맞춰 인스턴스화한다는 뜻이에요.

**지연 평가**[(지연 실행이라고도 해요)](https://blogs.msdn.microsoft.com/pedram/2007/06/02/lazy-evaluation-in-c/)란 컴파일러가 어떤 항목이 필요해질 때까지 평가를 미룬다는 뜻이에요. 덕분에 무한한 목록을 다루는 것 같은 별난 일도 안전하게 할 수 있어요. 언어는 필요한 마지막 값까지만 목록을 만들어요.

**통합 쿼리**란 [LINQ "Language-Integrated Query"](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/linq/)라는 언어 기능을 말해요. 이 기능을 쓰면 언어 안에서 직접 지연 쿼리를 할 수 있어요. 자기 객체뿐 아니라 XML, JSON, SQL, NoSQL DB, 이벤트 스트림 같은 형식을 통해 외부 데이터 원본도 쿼리할 수 있죠.

**타입 추론**이란 컴파일러가 식별자의 타입을 스스로 알아내는 경우가 많아서 직접 지정하지 않아도 된다는 뜻이에요. Scala와 F#도 이걸 해요.

**문법**은 C, C++, Java 같은 다른 C 스타일 언어와 비슷해요.

**.NET**은 C#이 실행되는 관리되는 환경이에요. 덕분에 [nuget.org](http://www.nuget.org)의 모든 패키지를 포함한 .NET 생태계 전체를 활용할 수 있어요. .NET은 예전에는 Windows 전용이었지만, [.NET Core](https://www.microsoft.com/net/core)와 [Mono](http://www.mono-project.com/)가 나오면서 Mac, Linux, Unix 기반 시스템은 물론 모바일 플랫폼에서도 C#을 쓸 수 있게 됐어요.

C#에는 여러 스레드/프로세서를 쓰는 프로그래밍, 병렬화, 비동기, 관리되는 환경에서의 비관리 코드, 언어 상호 운용성을 더 쉽게 만들어 주는 기능들도 있어요. C#은 Microsoft가 개발하고 유지 관리하며, 공식 [문서](https://docs.microsoft.com/en-us/dotnet/csharp/)도 Microsoft에서 제공해요.
