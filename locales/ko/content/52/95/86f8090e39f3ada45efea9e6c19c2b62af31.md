# 조건문

Ruby에는 흐름 제어 표현식이라고 하는 것이 있어요. 이것은 프로그램이 실행되는 방식을 제어하는 데 사용되며, truthy 또는 falsey 값을 받아요.
truthy 또는 falsey 값을 만드는 데 사용할 수 있는 연산자들이 있는데, 이를 [비교 연산자][comparison-operators]라고 해요.

코드 중 무엇이 실행되고 무엇이 실행되지 않을지를 제어하는 데 사용되는 주요 제어 표현식이 두 가지 있어요.
다시 말해 주어진 분기 중 어느 것이 실행될지를 정하는 거예요.

그 두 가지는 `if`와 `unless` 표현식이에요.

## 비교 연산자

[비교 연산자][comparison-operators]는 값을 비교하고 `true` 또는 `false` 값을 반환하는 데 사용돼요.
다음 연산자들은 같은 타입의 두 값을 비교해야 해요.
값의 타입이 다르면 컴파일러가 오류를 발생시켜요.
다음은 연산자 목록과, 이들이 `true` 값을 내놓는 예시예요:

| 연산자 | 설명      | 예시    |
| ------ | --------------------- | ------- |
| <      | 미만                  | 4 < 5   |
| <=     | 이하                  | 4 <= 4  |
| >      | 초과                  | 3 > 1   |
| >=     | 이상                  | 2 >= 2  |

같음과 같지 않음 연산자는 앞서 언급한 연산자들과 달리 어떤 타입의 값이든 비교할 수 있어요.
`==` 연산자는 두 값이 같은지 확인하는 데 사용되는데, 값의 타입까지 확인해요.
`!=`도 같은 방식으로 동작하지만, 값이 같지 않으면 `true`를, 같으면 `false`를 반환해요.
다음은 같음과 같지 않음 연산자 목록과, 이들이 `true` 값을 내놓는 예시예요:

| 연산자 | 설명         | 예시    |
| ------ | ------------ | ------- |
| ==     | 같음         | 4 == 4  |
| !=     | 같지 않음    | 5 != 4  |

## `if`문

[`if`][if]문은 주어진 조건이 "truthy"인지 "falsey"인지 확인하는 데 사용돼요.
조건이 truthy이면 `if`문 안의 코드가 실행돼요.
`if`문은 `end` 키워드로 끝나요.

```ruby
value = 1
if value == 1
  "1 is equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
end
# => nil
```

## `unless`문

`unless`문은 `if`문과 아주 비슷하게 동작하지만, 조건이 falsey일 때 `unless`문 안의 코드를 실행해요.

```ruby
value = 1
unless value == 1
  "1 is not equal to 1"
end
# => nil

unless value > 2
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## `else`문

`else`문은 `if`문과 함께 사용할 수 있어요.
`if` 분기가 실행되지 않으면 `else`문이 실행돼요.

```ruby
value = 1
if value == 1
  "1 is equal to 1"
else
  "1 is not equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
else
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## "연쇄 if"문

`elsif`문은 `if`문과 함께 사용할 수 있어요.
`if` 분기가 실행되지 않고 `elsif`문의 조건이 truthy이면 `elsif`문이 실행돼요.
`elsif`문은 여러 개를 이어 붙일 수 있고, 처음으로 truthy인 조건이 실행돼요.
`if`문 끝에 `else`문을 둘 수도 있는데, 앞선 문들이 모두 참이 아니면 이 `else`문이 실행돼요.

```ruby
value = 1
if value == 0
  "1 is equal to 0"
elsif value > 2
  "1 is greater than 2"
else
  "1 is not equal to 0 and 1 is not greater than 2"
end
# => "1 is not equal to 0 and 1 is not greater than 2"
```
