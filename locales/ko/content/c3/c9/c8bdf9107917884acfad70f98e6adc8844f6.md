# 소개

Flags 특성을 사용하면 구별된 공용 구조체에 정의된 값을 비트 위치(즉, 플래그)로 표현할 수 있어요.
이런 값들은 플래그이므로 결합할 수 있고, 여러 불리언 조건을 하나의 값으로 표현할 수 있어요.

```fsharp
[<Flags>]
type PhoneFeatures =
| Call = 1
| Text = 2
```

```fsharp
[<Flags>]
type PhoneFeaturesBinary =
| Call = 0b00000001
| Text = 0b00000010
```

플래그를 설정할 때는 비트 OR 연산자(`|||`)를 사용하고, 플래그를 해제할 때는 비트 AND 연산자(`&&&`)와 비트 부정 연산자(`~~~`)를 조합해요.
플래그의 상태를 확인할 때도 비트 AND 연산자를 사용할 수 있지만, `HasFlag()` 메서드를 사용할 수도 있어요.

```fsharp
let features = PhoneFeatures.Call

// Set the Text flag
let moreFeatures = features ||| PhoneFeatures.Text

moreFeatures.HasFlag(PhoneFeatures.Call) // => true
moreFeatures.HasFlag(PhoneFeatures.Text) // => true
```

F# 언어에서 사용할 수 있는 비트 연산자의 전체 목록은 [비트 연산자 요약][bitwise-operators]을 참고해요.

[bitwise-operators]: https://learn.microsoft.com/en-us/dotnet/fsharp/language-reference/symbol-and-operator-reference/bitwise-operators#summary-of-bitwise-operators
