# 지침

한 진법에서 일련의 자릿수로 표현된 수를 다른 진법으로 변환해요.

일반적인 진법 변환을 구현해요. 진법 **a**로 표현된 수가 자릿수의 나열로 주어지면, 그 수를 진법 **b**로 변환해요.

## 참고

- 변환은 직접 구현해 봐요.
  변환을 대신 해 주는 다른 것을 사용하지 마세요.

## [위치 기수법](https://en.wikipedia.org/wiki/Positional_notation)에 대하여

위치 기수법에서는 진법 **b**로 표현된 수를 **b**의 거듭제곱의 선형 조합으로 이해할 수 있어요.

*10진법*에서 수 42는 다음을 의미해요:

(4 * 10^1) + (2 * 10^0)

*2진법*에서 수 101010은 다음을 의미해요:

(1 * 2^5) + (0 * 2^4) + (1 * 2^3) + (0 * 2^2) + (1 * 2^1) + (0 * 2^0)

*3진법*에서 수 1120은 다음을 의미해요:

(1 * 3^3) + (1 * 3^2) + (2 * 3^1) + (0 * 3^0)

감을 잡으셨네요!

*네. 위의 세 수는 정확히 같은 수예요. 축하해요!*
