# 테스트

## 요약
 
- 연습 문제 디렉터리(예: `~/Exercism/hello-world`)로 이동해요.
- 터미널에서 `jconsole` 세션을 시작해요.
- 솔루션 파일을 로드해요(예: `load 'hello-world.ijs'`).
- `load  'general/unittest'`를 입력해 단위 테스트 프레임워크를 로드해요.
- `unittest 'test.ijs'`를 입력해 솔루션을 테스트해요.
<br></br>
- 또는 다음과 같이 한 줄로 테스트를 실행할 수도 있어요: `jconsole -js "load 'hello-world.ijs'" "echo unittest 'test.ijs'" "exit 0"`.

## Jconsole 세션

이 트랙의 테스트는 가능한 한 간단하게 설정하려고 했어요.
예를 들어 `hamming.ijs` 같은 연습 문제를 풀고 있다면, 작업은 이렇게 진행돼요.
`hamming.ijs`를 편집하면서 솔루션을 작성해요.
먼저 다음을 입력해서 대화형으로 조금씩 만들어 나가요.

```j
NB. your j terminal binary may be ijconsole (eg. on Debian)
jconsole 'hamming.ijs' NB. start a J console session with definitions loaded hamming.ijs
```

그런 다음 J 콘솔 안에서 다음을 입력해 다시 로드해요.

```j
load 'hamming.ijs'
```

다음 단계는 단위 테스트 프레임워크를 로드하는 거예요. 다음을 입력해요.

```j
load 'general/unittest'
```

테스트를 실행하려면, 솔루션을 로드한 뒤, 이렇게 입력해요.

```j
unittest 'test.ijs'
```

그리고 결과를 확인해요.

## 명령줄

터미널에서 -js 플래그를 사용하면 한 줄 명령으로 테스트를 실행할 수 있어요:

```j
jconsole  -js "load 'hamming.ijs'" "echo unittest 'test.ijs'" "exit 0"
```
여기서 각 인자는 순차적으로 실행될 명령을 나타내요.
