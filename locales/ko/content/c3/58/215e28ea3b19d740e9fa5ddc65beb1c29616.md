# 테스트

## 테스트 실행하기

1. 연습 문제를 하나 받아요:

    ```bash
    $ exercism download -track=kotlin --exercise=hello-world
    ```

2. 연습 문제 디렉터리로 이동해요:

    ```bash
    $ cd <path_to_exercise_directory>
    ```

3. 테스트를 실행해요:

    ```bash
    $ ./gradlew test
    ```

대부분의 연습 문제에서는 기본적으로 첫 번째 테스트만 실행돼요.  
나머지 테스트에는 건너뛰도록 `@Ignore`가 붙어 있어요.  
테스트를 하나씩 해결할 때마다 다음 테스트에서 `@Ignore`를 지우면 다음 단계로 나아갈 수 있어요.

이건 테스트 주도 개발(줄여서 TDD)에서 흔히 쓰는 방식이에요.
한 번에 문제 하나에만 집중할 수 있도록 이 방식을 써요.
