# 자리 표시자

## `jq` 팁

이 연습 문제는 입력 객체를 받아 새로운 객체로 변환하는 문제예요.
도움이 될 만한 내장 함수 두어 개를 소개할게요:

- [`to_entries`][x_entries]
  - 입력으로 객체를 받아요
  - 결과로 _배열_을 출력해요. 배열의 각 원소는 `{"key": "K", "value": V}` 객체예요
    - 각 `K`는 입력 객체의 키예요
    - 각 `V`는 `K`에 대응하는 값이에요
- [`from_entries`][x_entries]
  - 위와 반대되는 연산이에요
  - `{"key": K, "value": V}` 객체로 이루어진 배열을 받아 객체를 만들어요

예를 들어 볼게요:

```sh
jq -n '
    {
        "username": "glennj",
        "tracks": ["bash", "awk", "jq"],
        "reputation": 123
    }
    | to_entries
'
```

이렇게 출력해요:

```json
[
  {
    "key": "username",
    "value": "glennj"
  },
  {
    "key": "tracks",
    "value": ["bash", "awk", "jq"]
  },
  {
    "key": "reputation",
    "value": 123
  }
]
```

[x_entries]: https://jqlang.org/manual/#to_entries-from_entries-with_entries
