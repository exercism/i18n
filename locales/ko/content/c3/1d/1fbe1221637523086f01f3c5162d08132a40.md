# 소개

Lambda 클래스는 Haxe에서 함수형 스타일 프로그래밍을 할 수 있게 해 주는 함수형 메서드들의 모음이에요. Iterable 전체를 한 번에 다룰 수 있게 해 주죠. 이런 방식은 반복 루틴을 쓰는 것보다 오류가 적고 읽기 쉬워서 더 선호되는 경우가 많아요. 편의를 위해 Array와 List 클래스에는 Lambda 클래스에서 자주 쓰이는 메서드 일부가 들어 있어요.

`Lambda` 클래스의 함수 중 일부는 다음과 같아요:

- `Lambda.array`, `Lambda.list` Iterable을 Array나 List로 변환해요. 항상 새로운 인스턴스를 반환해요.
- `Lambda.count` 원소의 개수를 세요. Iterable이 Array나 List라면 length 속성을 쓰는 게 더 빨라요.
- `Lambda.has` 지정한 원소가 Iterable 안에 있는지 확인해요.
- `Lambda.indexOf` 지정한 원소의 인덱스를 찾아요.
- `Lambda.find` 주어진 검색 함수에 해당하는 첫 번째 원소를 찾아요.
- `Lambda.concat` 두 Iterable을 합쳐서 새로운 List를 반환해요.
- `Lambda.filter` 조건을 만족하는 원소들을 찾아 새로운 List를 반환해요.

몇 가지 함수를 보여 주는 예제예요:

```haxe
using Lambda;

class Main {
  static function main() {
    var words = ["boat", "dog", "phone", "cat", "food"];

    var isThreeLetters = function(word) return word.length == 3;

    trace(words.filter(isThreeLetters)); // [dog,cat]
  }
}
```
