# 소개

F#의 `char` 타입은 텍스트에서 가장 작은 주소 지정 단위를 나타내는 16비트 값이고, 기본적으로 불변이에요.

`char`는 작은따옴표로 리터럴을 정의할 수 있어요:

```fsharp
let ch = 'A'
// => val ch: char = 'A'
```

문자열은 `char`가 나열된 것이에요.

개별 `char`는 0부터 시작하는 인덱스로 문자열에서 꺼낼 수 있어요:

```fsharp
"Exercism"[4] //  =>  'c'
```

문자열을 순회하면 각 단계마다 `char`를 반환해요.

다음 예제는 편의를 위해 고차 함수와 익명 함수를 사용했어요.
이 둘은 나중에 커리큘럼에서 제대로 다루지만, 지금은 문자열의 문자들을 순회하는 루프를 간결하게 쓰는 방법이라고 생각하면 돼요.

```fsharp
Seq.map (fun c -> c, int c) "F#"  //  =>  [('F', 70); ('#', 35)]
```

위에서 보았듯이 `char`는 `int` 값으로 변환할 수 있어요.
이건 다른 문자 체계에서도 (*적어도 어떤 경우에는*) 동작해요:

```fsharp
Seq.map (fun c -> c, int c) "東京"  //  =>  [('東', 26481); ('京', 20140)]
```

문자를 비교할 때는 그 바탕이 되는 Int16이 사용돼요:

```fsharp
'A' < 'D'  // =>  true
```

또한 `int`는 `char`로 변환할 수 있어요:

```fsharp
char 77  // => 'M'
```

`System.Char` 라이브러리에는 .NET 언어에서 기대하는 메서드가 모두 들어 있어요. 대소문자 변환 같은 것들이에요:

```fsharp
'a' |> System.Char.ToUpper  // =>  'A'

'Q' |> System.Char.ToLower  // =>  'q'
```
