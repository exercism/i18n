# 설치

## Clojure CLI 설치
Clojure는 Clojure REPL을 실행하고, Clojure와 Java 라이브러리를 사용하고, Clojure 프로그램을 시작할 수 있는 명령줄 도구를 제공해요.

Java를 설치해야 한다면 [Adoptium Temurin 17](https://adoptium.net/)을 권장해요.

### Linux
다음 의존성이 설치되어 있는지 확인해요: `bash`, `curl`, `rlwrap`, `Java`.
Clojure는 다음 두 가지 방법 중 하나로 설치할 수 있어요:

1. LinuxBrew: [Homebrew](https://brew.sh/)가 필요해요

```bash
brew install clojure/tools/clojure
```

2. 스크립트 설치 프로그램

```bash
curl -O https://download.clojure.org/install/linux-install-1.11.1.1347.sh
chmod +x linux-install-1.11.1.1347.sh
sudo ./linux-install-1.11.1.1347.sh
```

### Mac OS X용 Homebrew
[clojure/tools](https://github.com/clojure/homebrew-tools) tap에서 brew로 명령줄 도구를 설치해요:

```bash
brew install clojure/tools/clojure
```

#### Java

어떤 Java 배포판이든 괜찮아요. 필요하다면 brew로 Temurin을 설치할 수 있어요:

```bash
brew tap homebrew/cask-versions
brew install --cask temurin17
```

### Windows

최근 Windows에서의 Clojure 지원이 많이 좋아졌어요. 예전에는 잘 동작하는 WSL2 사용을 권장했지만, 이제는 PowerShell 설치 프로그램이 있어요. Windows에서의 Clojure는 현재 알파 상태예요. 알려진 문제는 [clj-on-windows](https://github.com/clojure/tools.deps.alpha/wiki/clj-on-Windows#known-issues)에서 확인해요.

Java가 설치되어 있고 `JAVA_HOME` 환경 변수가 설정되어 있는지 확인한 다음 실행해요:

```powershell
iwr -useb download.clojure.org/install/win-install-1.11.1.1165.ps1 | iex
```

Windows에 Clojure를 설치하는 또 다른 방법은 [Scoop](https://scoop.sh/) 패키지 관리자를 사용하는 거예요. scoop을 설치하려면 PowerShell을 열고 다음 두 명령을 차례로 실행해요:

 ```sh
 iwr -useb get.scoop.sh | iex
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser -Force
```

Scoop으로 Clojure를 설치하려면 먼저 중요한 bucket 두 개를 추가해야 해요:

```sh
# if you don't have git version control system installed
# it is required for adding new external buckets to your scoop installer
# you can skip this step otherwise
scoop install git

# add scoop bucket for Java 
scoop bucket add java

# add scoop bucket for clojure build
scoop bucket add scoop-clojure https://github.com/littleli/scoop-clojure
```

이제 다음 명령을 실행해서 Java와 Clojure를 설치할 준비가 되었어요:

```sh
# install Java runtime and compiler
scoop install adoptopenjdk-lts-hotspot

# install official clojure tools
scoop install clojure

# update to the newest version
scoop update clojure
```

위 단계를 성공적으로 실행했다면, 다음 명령으로 Clojure를 실행할 수 있을 거예요:

```sh
clj
```

## Leiningen 설치 (선택 사항)

더 이상 필수는 아니지만, 다양한 기능을 갖춘 프로젝트 관리 도구인 [Leiningen](https://leiningen.org/)을 여전히 지원해요. 편리한 테스트, 빌드, 개선된 REPL 등 여러 가지 유용한 작업을 제공해요.

1. [lein 스크립트](https://raw.githubusercontent.com/technomancy/leiningen/stable/bin/lein) 또는 [lein.bat](https://raw.githubusercontent.com/technomancy/leiningen/stable/bin/lein.bat)(Windows)를 내려받아요
2. 셸이 찾을 수 있는 `$PATH` 위치(예: `/usr/local/bin/`)에 두어요
3. 실행 가능하도록 설정해요 (`sudo chmod a+x /usr/local/bin/lein`)
4. `lein`을 실행해요.
