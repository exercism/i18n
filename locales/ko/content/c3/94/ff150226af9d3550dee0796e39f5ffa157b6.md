# 힌트

## 일반

- 스칼라 불리언 값을 다룰 때 사용하는 [불리언 연산자][boolean-operators]가 세 개 있어요.
- 여러 연산자를 하나의 표현식에 함께 사용할 수 있어요.

## 1. 빠른 공격이 가능한지 확인하기

- 논리 NOT 연산자(`!`)를 표현식 앞에 붙이면 그 값을 부정할 수 있어요.

## 2. 일행을 정찰할 수 있는지 확인하기

- 불리언 연산자는 보통 두 개 이상의 표현식이 `TRUE`인지 아닌지`!`를 판단할 때 사용해요.

## 3. 죄수에게 신호를 보낼 수 있는지 확인하기

- 불리언 연산자는 우선순위가 높은 것부터 낮은 것 순으로 실행돼요: `!`, `&&`, `||`.
- 일반적으로 의도를 더 분명하게 드러내려면 괄호를 사용하는 것이 좋아요.

## 4. 죄수를 구출할 수 있는지 확인하기

- 불리언 연산자는 우선순위가 높은 것부터 낮은 것 순으로 실행돼요: `!`, `&&`, `||`.
- 일반적으로 의도를 더 분명하게 드러내려면 괄호를 사용하는 것이 좋아요.
