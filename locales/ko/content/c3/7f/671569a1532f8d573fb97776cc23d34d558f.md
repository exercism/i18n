# 지침

이 연습 문제에서는 좋아하는 요리책에 나오는 근사한 라자냐를 만들 수 있도록 코드를 작성해요.

라자냐를 만드는 데 걸리는 시간과 관련된 네 가지 작업이 있어요.

## 1. 오븐에서의 예상 시간(분)을 정의해요

`Lasagna` 클래스에 `EXPECTED_MINUTES_IN_OVEN` 상수를 정의해요. 이 상수는 라자냐를 오븐에 몇 분 동안 넣어 둬야 하는지를 저장해요.
요리책에 따르면 오븐에서의 예상 시간은 40분이에요.

```Crystal
Lasagna::EXPECTED_MINUTES_IN_OVEN
# => 40
```

## 2. 남은 오븐 시간(분)을 계산해요

`Lasagna#remaining_minutes_in_oven` 메서드를 정의해요. 이 메서드는 라자냐가 오븐에 있던 실제 시간(분)을 매개변수로 받고, 이전 작업에서 구한 오븐에서의 예상 시간(분)을 기준으로 라자냐가 오븐에 얼마나 더 있어야 하는지를 반환해요.

```Crystal
Lasagna.new.remaining_minutes_in_oven(30)
# => 10
```

## 3. 준비 시간(분)을 계산해요

`Lasagna#preparation_time_in_minutes` 메서드를 정의해요. 이 메서드는 라자냐에 넣은 층의 개수를 매개변수로 받고, 각 층을 준비하는 데 2분이 걸린다고 가정했을 때 준비에 걸린 시간(분)을 반환해요.

```Crystal
Lasagna.new.preparation_time_in_minutes(2)
# => 4
```

## 4. 총 작업 시간(분)을 계산해요

`Lasagna#total_time_in_minutes` 메서드를 정의해요. 이 메서드는 이름이 있는 두 개의 매개변수를 받아요. `number_of_layers` 매개변수는 라자냐에 넣은 층의 개수이고, `actual_minutes_in_oven` 매개변수는 라자냐가 오븐에 있던 시간(분)이에요.
이 메서드는 라자냐를 만드는 데 들인 총 시간(분)을 반환해야 해요. 이는 준비 시간(분)과 그 시점까지 라자냐가 오븐에서 보낸 시간을 더한 값이에요.

```Crystal
number_of_layers = 3
actual_minutes_in_oven = 20
Lasagna.new.total_time_in_minutes(number_of_layers, actual_minutes_in_oven)
# => 26
```
