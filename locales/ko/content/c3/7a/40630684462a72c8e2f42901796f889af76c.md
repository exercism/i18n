# 지침

배워 볼 프로그래밍 언어 목록을 관리하는 코드를 작성해 봐요.
이 목록은 `@LanguageList::Languages`라는 배열에 담겨요.

## 1. @Languages 배열에 언어 추가하기

언어 이름을 인자로 받는 `LanguageList::add_language` 서브루틴을 수정해서, `@LanguageList::Languages` 배열의 끝에 언어를 추가해요.

## 2. @Languages 배열에서 언어 제거하기

`LanguageList::remove_language` 서브루틴을 수정해서 `@LanguageList::Languages` 배열에서 마지막 언어를 제거해요.

## 3. @Languages 배열에서 첫 번째 언어 가져오기

`LanguageList::first_language` 서브루틴을 수정해서 `@LanguageList::Languages` 배열의 첫 번째 언어를 반환해요.

## 4. @Languages 배열에서 마지막 언어 가져오기

`LanguageList::last_language` 서브루틴을 수정해서 `@LanguageList::Languages` 배열의 마지막 언어를 반환해요.

## 5. @Languages 배열에서 언어 슬라이스 가져오기

가져오고 싶은 원소를 나타내는 숫자 목록을 인자로 받는 `LanguageList::get_languages` 서브루틴을 수정해서, `@LanguageList::Languages` 배열의 슬라이스를 반환해요.

## 6. @Languages 배열에 언어가 있는지 확인하기

언어 이름을 인자로 받는 `LanguageList::has_language` 서브루틴을 수정해서, `@LanguageList::Languages` 배열에 해당 언어가 있는지를 나타내는 참 또는 거짓 값을 반환해요.
