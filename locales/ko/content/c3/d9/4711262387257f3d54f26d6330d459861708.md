# 배열

**배열**은 같은 타입의 값 여러 개를 순서대로 담아요.

타입은 `ARRAY{T}`라고 쓰는데, 여기서 `T`는 배열이 담는 값의 타입이에요. 문자열을 담는 배열은 `ARRAY{STR}`, 정수를 담는 배열은 `ARRAY{INT}`예요.

```sather
   row : ARRAY{STR} := |"Mia", "Ana", "Ben"|;
```

두 `|` 기호 사이에 있는 값들이 **배열 리터럴**이에요. 크기는 값이 몇 개인지 보고 Sather가 알아내요.

## 값 꺼내기

대괄호 안에 위치를 적어요.

```sather
row[0]      -- "Mia"
row[1]      -- "Ana"
row[2]      -- "Ben"
```

셈은 1이 아니라 **0**부터 시작해요. 그래서 첫 번째 값은 `0`에 있고, 값이 세 개인 배열의 마지막 값은 `2`에 있어요.

## 몇 개일까요?

`.size`는 배열이 담고 있는 값의 개수예요.

```sather
row.size    -- 3
```

셈이 0부터 시작하기 때문에 마지막 위치는 항상 `.size - 1`이에요.

```sather
row[row.size - 1]     -- "Ben"
```

없는 위치, 예를 들어 `row[3]`이나 `row[-1]`을 요청하는 것은 Sather가 대신 잡아 주지 않는 실수예요. 그러니 값을 눈으로 세기보다 `.size - 1`을 쓰는 게 좋아요.

## 배열 순회하기

배열과 루프는 짝을 이뤄요. 변수를 위치만큼 하나씩 늘려 가면서 그 변수로 각 값에 접근해요.

```sather
   total ::= 0;
   i ::= 0;
   loop
      until!(i >= scores.size);
      total := total + scores[i];
      i := i + 1;
   end;
```
