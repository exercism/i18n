# 지침

한 제조사가 생산할 수 있는 모터에는 두 가지 종류가 있어요. 이제부터 이 모터들을 모터 A와 모터 B라고 부를게요. 두 모터 모두 생산에 필요한 구성 요소가 3가지 있어요. 바로 배선, 드릴링, 조립이에요. 모터마다 각 생산 단계에 필요한 시간이 달라요. 일반적으로 모터 A 한 대에는 배선에 t_a_1시간, 드릴링에 t_a_2시간, 조립에 t_a_3시간이 필요해요. 반면 모터 B 한 대에는 배선에 t_b_1시간, 드릴링에 t_b_2시간, 조립에 t_b_3시간이 필요해요. 각 생산 단계에 할당된 총시간(배선에 t_1시간, 드릴링에 t_2시간, 조립에 t_3시간)과 각 모터 종류의 가격(p_a, p_b)이 주어졌을 때, 이익을 최대화하는 모터 A와 모터 B의 최적 생산량을 계산하는 함수를 구현해 보세요.

함수에는 모두 4개의 입력 매개변수가 있어요. 각각은 다음과 같아요.
1. a_hours: (t_a_1, t_a_2, t_a_3)로 이루어진 3-튜플, 단위는 시간
2. b_hours: (t_b_1, t_b_2, t_b_3)로 이루어진 3-튜플, 단위는 시간
3. total_hours: (t_1, t_2, t_3)로 이루어진 3-튜플, 단위는 시간
4. prices: (p_a, p_b)로 이루어진 2-튜플, 단위는 달러

출력은 (q_a, q_b, profit)으로 이루어진 하나의 3-튜플이어야 해요. 여기서 각각은 다음과 같아요.
1. q_a: 생산할 모터 A의 최적 생산량
2. q_b: 생산할 모터 B의 최적 생산량
3. profit: 이익을 최대화하는 값, 단위는 달러

그 밖에 주의할 점이 있어요.
q_a와 q_b는 실수가 될 수 없어요. 모터를 일부만 생산할 수는 없으니까요.
Z3 모델이 변수에 대해 내놓은 결과는 출력하기 전에 정수로 변환해야 해요. Z3 모델의 결과가 `IntNumRef` 타입이면 `as_long()` 클래스 메서드로 정수로 변환할 수 있어요.
잘못된 입력 때문에 문제를 풀 수 없다면, Python 내장 예외인 `ArithmeticError()`를 발생시켜요.
