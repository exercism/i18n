# 소개

입력과 출력을 처리하는 함수는 `IO` 모듈에서 제공해요.

## 출력

표준 출력에 문자열을 쓰려면 `IO.puts`를 사용해요. `IO.puts`는 문자열 끝에 항상 줄바꿈을 추가해요. 이런 동작을 원하지 않으면 대신 `IO.write`를 사용해요. 두 함수 모두 성공하면 `:ok` 아톰을 반환해요.

```elixir
IO.puts("Hi!")
# > Hi!
# => :ok
```

`IO.puts`는 문자열을 쓰기에는 유용하지만, 그 외의 용도로는 그다지 유용하지 않아요. 어떤 값이든 표준 출력에 쓸 수 있는 디버깅 도구가 필요하다면, 대신 `IO.inspect`를 사용해요. `IO.inspect`는 전달받은 값을 그대로 반환해서, 코드 어디에든 넣을 수 있어요. 또한 `:label` 같은 여러 옵션을 받을 수 있어서, 다른 `IO.inspect` 호출과 구분할 수 있게 해줘요.

## 입력

표준 입력에서 한 줄을 읽으려면 `IO.gets`를 사용해요. `IO.gets`는 인자를 하나 받는데, 입력 프롬프트로 출력할 문자열이에요. `IO.gets`는 프롬프트 뒤에 줄바꿈을 추가하지 않으니, 필요하면 직접 넣어요.

```elixir
IO.gets("What's your name?\n")
# > What's your name?
# < Mary
# => "Mary\n"
```
