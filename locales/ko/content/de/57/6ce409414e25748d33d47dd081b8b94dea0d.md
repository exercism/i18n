# 소개

제네릭을 사용하면 여러 타입에서 동작하는 코드를 중복 없이 작성할 수 있어요.
제네릭 타입은 꺾쇠괄호 `<T>`를 사용해 정의하는데, 여기서 `T`는 임의의 타입을 나타내는 자리 표시자예요.

```rust
fn largest_list<T>(l1: Array<T>, l2: Array<T>) -> Array<T> {
    if l1.len() > l2.len() {
        l1
    } else {
        l2
    }
}
```

Cairo에서는 제네릭 타입이 지원해야 하는 연산을 지정하기 위해 트레이트 바운드가 필요해요.
`+` 문법으로 제약을 추가할 수 있어요:

```rust
fn process_data<T, +Drop<T>, +Copy<T>>(value: T) -> T {
    // Function body
}
```

구조체도 제네릭으로 만들 수 있어요:

```rust
#[derive(Drop)]
struct Container<T> {
    value: T,
}
```

트레이트도 제네릭으로 만들 수 있어서, 여러 타입에서 동작하게 할 수 있어요:

```rust
trait Processor<T> {
    fn process(self: @T) -> ByteArray;
}

impl MyProcessor<T, +Drop<T>> of Processor<T> {
    fn process(self: @T) -> ByteArray {
        "processed"
    }
}
```

함수는 트레이트 바운드가 있는 제네릭 매개변수를 받을 수 있는데, 이렇게 하면 필요한 트레이트를 구현한 모든 타입에서 동작해요:

```rust
fn use_processor<T, +Processor<T>, +Drop<T>>(item: T) -> ByteArray {
    item.process()
}
```
