# 설명

Gleam의 딕셔너리는 정보를 키-값 쌍으로 저장하는 자료 구조예요. 다른 언어에서는 연관 배열이나 해시, 딕셔너리라고 부르기도 해요.

딕셔너리의 키와 값에는 어떤 타입이든 쓸 수 있고, 항목에 접근하거나 반환할 때 순서는 보장하지 않아요.

## 딕셔너리 다루기

딕셔너리는 `gleam/dict` 모듈의 함수로 만들고 다뤄요.

```gleam
// Create an empty dict
let dict1 = dict.new()

// Create a dict with some values
let dict2 = dict.from_list([
  #("name", "Gleam"),
  #("colour", "Pink"),
])

// Add a value to a dict
let dict3 = dict.insert(dict2, "website", "https://gleam.run")

// Get a value from a dict
let name = dict.get(dict3, "name")
// -> Ok("Gleam")
```
