# 개요

`bit`은 컴퓨팅에서 가장 세분화된 값이에요.
`bit`이라는 단어는 "binary digit"을 줄인 말로, "이진 숫자"라는 뜻이에요.
`bit`은 실행 환경에서 두 값 중 하나를 가질 수 있는 객체를 담을 수 있을 만큼 큰 데이터 저장 단위예요.
따라서 `1` 또는 `0`의 이진 값을 가져요.
다른 모든 데이터 타입은 여러 개의 `bits`로 이루어져 있어요.
예를 들어 `byte`는 보통 여덟 개의 `bits`로 이루어져 있어요.

## 비트 값을 쓰는 방법

`Bits`는 2진법 체계를 구성해요.
`2`의 배수는 각각 우리가 십/백/천 등의 자리라고 여기는 곳에 들어가는데, 다만 여기서 "십"은 "이", "백"은 "사", "천"은 "팔"이 되는 셈이에요.
그래서 십진수 `2`는 이진수 `10`, `4`는 `100`, `8`은 `1000`이 돼요.
십진수와 마찬가지로 오른쪽에서 왼쪽으로 갈수록 값이 커져요.
십진수 `5`는 이진수 `101`로 표현된다고 생각할 수 있는데, "일"의 자리에 `1`이, "사"의 자리에 `1`이 있는 거예요.
하지만 이진 리터럴은 C 언어 표준에 포함되어 있지 않아요.
C 언어 표준이 지원하는 이진 값은 `1` 또는 `0` 하나뿐이에요.
일부 비표준 컴파일러 확장(예: gnu 컴파일러)에서는 리터럴 앞에 `0b`를 붙여 이진 리터럴을 _지원하기도_ 해요.

```c
#include <stdio.h>

int main() {
    int binary_five = 0b101;
    printf("%d", binary_five);
    return 0;
}
```

이런 표기법이 모든 컴파일러에서 지원되는 것은 아니며, 서로 다른 컴파일러 사이의 코드 이식성에 장벽이 될 수 있다는 점을 기억하는 게 중요해요.

이진 값을 표현하는 흔한 방법은 16진법 체계인 16진 표기법을 사용하는 거예요.
C 언어의 16진 표기법은 리터럴 앞에 `0x` 또는 `0X`를 붙여요.
십진수 `16`이 십의 자리에 `1`로 표현되듯이, 십진수 `10`은 16진수로 `0xA`, `11`은 `0xB`, `12`는 `0xC`, `13`은 `0xD`, `14`는 `0xE`, `15`는 `0xF`로 표현돼요.
예를 들어 십진수 `42`는 `0x2A`로 쓰는데, `2` 곱하기 `16`(= `32`) 더하기 `10`(= `42`)이에요.

이진수로는 `42`를 `00101010`, 즉 `32` 더하기 `8` 더하기 `2`라고 생각할 수 있어요.
오른쪽에서 두 번째, 네 번째, 여섯 번째 비트가 "설정됐다"고 말하는데, `0` 대신 `1`이라는 뜻이에요.
두 번째 비트는 `2`, 네 번째 비트는 `8`, 여섯 번째 비트는 `32`예요.
이 세 비트를 설정하면 `42`라는 값이 정의돼요.

## 비트 마스크

비트 마스크는 개별 비트를 설정하는 데 사용되는 어떤 값이든 될 수 있어요.
예를 들어 영어 알파벳에는 스물여섯 개의 글자가 있어요.
부호 없는 32비트 정수처럼 적어도 스물여섯 비트를 가진 값은 모든 영어 글자에 대해 `true` 또는 `false` 조건을 설정하는 비트 마스크로 쓸 수 있어요.
필요한 `true` 또는 `false` 조건 집합을 다룰 만큼 비트가 충분한 값이라면 무엇이든 비트 마스크로 쓸 수 있어요.
개별 비트를 설정하고 읽는 일은 비트 연산자를 통해 이뤄져요.

## 비트 연산자

어떤 글자가 `string`에 나타나는지 추적하고 싶다고 해봐요.
이 예제에서는 영어 알파벳의 스물여섯 글자만 사용할게요.
비트 마스크는 부호 없는 32비트 정수로 할게요.
`0`은 그 글자가 나타나지 않음을 나타내요.
`1`은 그 글자가 한 번 이상 나타남을 나타내요.
처음에는 비트 마스크의 비트 표현이 `0s` 32개를 나란히 놓은 `00000000000000000000000000000000`이에요.
가장 오른쪽 자리는 `A`를 위한 거예요.
왼쪽에서 두 번째는 `B`를 위한 것이고, 이런 식이에요.
문자열의 모든 글자를 루프로 처리한다고 해봐요. 그러면 어떤 글자든 설정할 수 있는 한 줄의 코드가 필요해요.

### 비트 왼쪽 시프트 연산자: 비트의 위치를 정하는 방법

`<<`는 왼쪽으로 시프트하는 비트 연산자예요.

글자가 `A`라면 왼쪽으로 시프트할 필요가 없고, `B`라면 한 자리, `C`라면 두 자리 왼쪽으로 시프트하면 돼요. 이런 식이에요.
`chars`를 `A`나 `B` 같은 글자로 인식할 수 있지만, `char`는 메모리에서 정수 타입으로 구현되기 때문에 `char`로 간단한 계산을 할 수 있어요.
처리 중인 `char`를 나타내는 `letter`라는 변수가 있다면, `1`을 `letter`와 `A` `char`의 차이만큼 왼쪽으로 시프트해서 필요한 만큼 왼쪽으로 옮길 수 있어요. 예를 들면 `1 << letter - 'A'`처럼요.
`A` - `A`는 `0`이므로 `letter`가 `A`이면 `0` 자리 왼쪽으로 시프트해요.
`B` - `A`는 `1`이므로 `letter`가 `B`이면 `1` 자리 왼쪽으로 시프트하고, 이런 식이에요.

### 비트 포함 OR 연산자: 비트를 설정하는 방법

비트를 _어디에_ 설정할지 알았다면, `|`인 비트 포함 OR 연산자를 사용해서 실제로 설정할 수 있어요.
`|` 연산자의 결과는 왼쪽 또는 오른쪽 피연산자 중 하나라도 비트가 설정된 각 위치에서 `1`이 돼요.
따라서 `0010 | 0001`의 결과는 `0011`이에요.
(이 값이 이진수로는 `11`이지만 십진수로는 `3`이라는 점을 기억하는 게 중요해요.)
결과를 값에 대입하려면 `|` 연산자를 대입 연산자와 결합해 `|=`처럼 비트를 설정할 수 있어요.
간단하게 하기 위해 다음 예제는 루프를 사용하지 않지만, `ABA`라는 글자들을 비트 마스크에서 처리하는 방법을 보여줘요.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    // it's important to initialize the mask to 0 so we don't get garbage values
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    mask |= 1 << letter_A_again - 'A';
    // prints 3
    printf("%d", mask);
}
```

마스크의 가장 오른쪽 부분을 `A`에 대해 `0001`로 설정하고, 그다음 `B`에 대해 마스크를 `0011`로 설정해요.
또 다른 `A`를 설정해도 기존 마스크에는 변화가 없어요.
`A`가 이미 설정됐는지 확인해서 그 비트를 다시 설정하지 않도록 할 수도 있었어요.

### 비트 AND 연산자: 비트를 읽는 방법

`&`는 비트 AND 연산자예요.
`&` 연산자의 결과는 왼쪽과 오른쪽 피연산자 모두 비트가 설정된 각 위치에서 `1`이 돼요.
따라서 `0011 & 0001`의 결과는 `0001`이에요.
다음 예제에서 이 동작을 직접 볼 수 있어요.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    // prints A already set
    if (mask & 1 << letter_A_again - 'A')
        printf("A already set\n");
    else
        mask |= 1 << letter_A_again - 'A';
    printf("%d", mask);
}
```

### 비트 배타적 OR 연산자: 비트를 뒤집는 방법

`^`는 비트 배타적 OR 연산자예요.
_포함_ OR 연산자가 있다면 동작이 다른 _배타적_ OR 연산자도 있다는 뜻이에요.
`^` 연산자의 결과는 왼쪽 또는 오른쪽 피연산자 중 _오직 하나만_ 비트가 설정된 각 위치에서 `1`이 돼요.
따라서 `0001 ^ 0011`의 결과는 `0010`이에요.
두 피연산자 _모두_ 가장 오른쪽 위치에 `1`이 있기 때문에 가장 오른쪽 비트는 설정되지 않아요.
배타적 OR 연산은 때때로 XOR로 표기해요.
어떤 값을 XOR한 결과를 다시 XOR하면 원래 값이 나와요.
같은 키로 데이터를 암호화하고 복호화하는 아주 간단한 암호화에 이걸 쓸 수 있어요.
예를 들어

```c
#include <stdio.h>

int main() {
    char a = 'a';
    char b = 'b';
    char c = 'c';
    // we will use "a" for the "key"
    char first = a ^ 'a';
    char second = b ^ 'a';
    char third = c ^ 'a';
    // prints three "dots" for unprintable characters
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 0 3 2
    printf("%d %d %d\n", first, second, third);
    first = first ^ 'a';
    second = second ^ 'a';
    third = third ^ 'a';
    // prints a b c
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 97 98 99
    printf("%d %d %d\n", first, second, third);
}
```

### 비트 오른쪽 시프트 연산자: 값을 반으로 줄이는 방법

`>>`는 오른쪽으로 시프트하는 비트 연산자예요.
보통 값의 비트를 오른쪽으로 한 자리 시프트할 때마다 결과는 값을 2로 나눈 값이 돼요.
예를 들어

```c
#include <stdio.h>

int main() {
    int number = 16;
    number >>= 2;
    // prints 4, or 16 / 2 = 8 / 2 = 4
    printf("%d\n", number);
}
```

오른쪽 피연산자의 값이 음수이거나 승격된 왼쪽 피연산자의 너비보다 크거나 같으면 동작이 정의되지 않아요.
이건 왼쪽 시프트 연산자에도 똑같이 적용돼요.
부호 없는 정수 대신 부호 있는 정수를 사용하면 부호 여부도 영향을 줄 수 있어요.
다음 예제는 부호 있는 정수를 왼쪽이나 오른쪽으로 너무 많이 시프트했을 때 한 시스템에서 나타나는 동작을 보여줘요.

```c
#include <stdio.h>

int main() {
    int number = 16;
    number <<= 250;
    // prints 1073741824
    printf("%d\n", number);
    number <<= 1;
    // prints -2147483648
    printf("%d\n", number);
    number <<= 1;
    // prints 0
    printf("%d\n", number);
    // total shifts are now 256, done incrementally
    number <<= 4;
    // prints 0
    printf("%d\n", number);
    number = 16;
    // prints 16 when 256 total shifts done at once
    printf("%d\n", number << 256);
    // prints 0 when bits shifted right far enough
    printf("%d\n", number >> 5);    
    // still prints 0
    printf("%d\n", number >> 255);
    // prints 16 when shifted right far enough to "wrap around"
    printf("%d\n", number >> 256);
}
```

동작이 정의되지 않았기 때문에 시스템에 따라 다른 결과가 나올 수 있어요.
비트를 시프트할 때는 사용하는 데이터 타입의 범위를 이해하는 게 중요해요.

## 비트 필드

단순한 데이터 타입에 압축된 비트를 위치로 어떻게 다룰 수 있는지 살펴봤어요.
`struct`에 압축된 비트는 이름으로 다룰 수 있어요.
이런 데이터 타입을 `bit field`라고 해요.
`bit fields`의 활용 사례는 ON/OFF 플래그 모음이 필요하고 메모리 사용을 최소화하고 싶을 때예요.

```c
#include <stdio.h>

int main() {

    struct lights {
        unsigned int number_of_lights;
        unsigned int red   : 1;
        unsigned int green : 1;
        unsigned int blue  : 1;
    };
    struct lights lightboard = {3, 0, 0, 0};
     
    //  prints 000
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    lightboard.green = 1;

    //  prints 010
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    // prints 3
    printf("%d\n", lightboard.number_of_lights);
}
```

`unsigned int variable_name : 1;` 문법은 struct 안에 배치된 `unsigned int` 안에 `1`비트 크기의 필드를 만들어요.
`unsigned int` 대신 `signed int`를 사용할 수도 있고, C99 이후라면 `bool` 타입을 사용할 수도 있어요.
비트 필드를 포함하는 struct는 위 예제의 `number_of_lights`처럼 다른 데이터 타입의 필드도 포함할 수 있어요.
