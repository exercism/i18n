# 개요

타입을 암시적으로 변환할 수 없을 때는 명시적 형 변환 [연산자][cast-operator]를 사용해야 해요. 형 변환 연산자는 변환하려는 값 앞에 대상 타입을 괄호로 감싸 붙인 것에 지나지 않아요.

```csharp

int i = 7;
byte b = (byte)i; // Explicit cast from int to byte
```

명시적 형 변환은 자칫 위험할 수 있어요. 가장 흔한 오류는 두 가지예요.

- 호환되지 않는 타입으로 형 변환하는 경우. 런타임에 예외가 발생해요.
- 폭이 충분하지 않은 숫자 값으로 형 변환하는 경우. 정수라면 부호 충돌이 생기거나 오버플로 예외가 발생할 수 있어요.

참고: `int` 타입의 식은 `char`로 명시적으로 형 변환할 수 있어요. 그러면 유효하지 않은 `char`가 나올 수 있어요.

[cast-operator]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/operators/type-testing-and-cast#cast-expression
