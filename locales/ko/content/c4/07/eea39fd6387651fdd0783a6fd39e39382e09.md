# 소개

## Map

**Map**은 키와 값을 짝지어 저장하는 자료 구조예요.
다른 프로그래밍 언어의 딕셔너리와 비슷해요.
[Map][map-javadoc] 인터페이스는 맵에서 할 수 있는 연산을 정의해요.

Java에는 여러 가지 Map 구현이 있어요.
[HashMap][hashmap-javadoc]이 흔히 쓰이는 구현이에요.

```java
// Make an instance
Map<String, Integer> fruitPrices = new HashMap<>();
```

[put][map-put-javadoc]으로 맵에 항목을 추가해요.

```java
fruitPrices.put("apple", 100);
fruitPrices.put("pear", 80);
// => { "apple" => 100, "pear" => 80 }
```

각 키에는 값 하나만 연결할 수 있어요.
같은 키로 `put`을 호출하면 그 키의 값이 바뀌어요.

```java
fruitPrices.put("pear", 40);
// => { "apple" => 100, "pear" => 40 }
```

[get][map-get-javadoc]으로 키의 값을 가져와요.

```java
fruitPrices.get("apple"); // => 100
```

[containsKey][map-containskey-javadoc]로 맵에 특정 키가 있는지 확인해요.

```java
fruitPrices.containsKey("apple");  // => true
fruitPrices.containsKey("orange"); // => false
```

[remove][map-remove-javadoc]로 항목을 제거해요.

```java
fruitPrices.put("plum", 90);  // Add plum to map
fruitPrices.remove("plum");   // Removes plum from map
```

[size][map-size-javadoc] 메서드는 항목의 개수를 반환해요.

```java
fruitPrices.size();  // Returns 2
```

[keySet][map-keyset-javadoc]이나 [values][map-values-javadoc] 메서드를 사용하면 Map의 키는 Set으로, 값은 Collection으로 각각 가져올 수 있어요.

```java
fruitPrices.keySet();  // Returns "apple" and "pear" in a set
fruitPrices.values();  // Returns 100 and 80, in a Collection
```
