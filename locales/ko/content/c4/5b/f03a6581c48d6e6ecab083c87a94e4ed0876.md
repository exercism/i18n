# 테스트

테스트는 다음 명령으로 실행해요:

```shell
corepack pnpm test
```

다른 사용자들처럼 코드가 모범 사례와 코딩 스타일을 따르도록 해요. ESLint는 코드를 정적으로 분석해 주는 도구예요.
이런 도구는 JavaScript 코드에서 오타나 사소한 실수를 찾아내는 시간을 아껴 주기도 해요:

```shell
corepack pnpm lint
```

Jest를 "watch" 모드로 실행할 수도 있어요. 이 모드는 코드나 테스트 모듈을 저장할 때마다 테스트를 자동으로 다시 실행해 줘요:

```shell
corepack pnpm watch
```

## 건너뛰기 테스트 이해하기

skip 메서드는 테스트 스위트에 특정 테스트를 실행하지 말라고 지시해요. 이 함수는 `it.skip(name, fn)`, `xit(name, fn)`, `xtest(name, fn)` 같은 별칭으로도 쓸 수 있어요.

- 왜 건너뛸까요?

사용자가 한 번에 하나의 테스트에 집중하고, 풀이를 발전시켜 나가면서 하나씩 활성화할 수 있게 하기 위해서예요.

- 어떻게 활성화할까요?

`xtest`를 `test`로 바꿔요.

```javascript
test('title cased phrases', () => {
  expect(Acronyms.parse('Portable Network Graphics')).toEqual('PNG');
});
```

## 첫 JavaScript 2015 모듈 만들기

보통 이 트랙의 테스트는 구현을 JavaScript 모듈로 임포트해서 불러와요: `import { Bob } from './bob.js';`.
참조한 `bob.js` 파일에서 구현을 export하기만 하면 돼요:

```javascript
export function hey(message) {}
```

모듈에 대한 더 자세한 내용은 [Babel 문서](https://babeljs.io/docs/learn-es2015/#modules)에서 확인할 수 있어요.
시작하기 쉽도록, 디렉터리에 _스켈레톤_ JavaScript 파일이 있어요.
