# 지침

학생들의 이름과 그 학생들이 속한 학년이 주어졌을 때, 학교의 명단을 만들어요.

최종적으로는 다음과 같은 기능을 할 수 있어야 해요:

- 특정 학년의 명단에 학생 이름을 추가하기
  - "2학년에 Jim을 추가해요."
  - "알겠어요."
- 특정 학년에 등록된 모든 학생 목록 가져오기
  - "2학년에는 어떤 학생들이 있나요?"
  - "지금은 Jim밖에 없어요."
- 모든 학년의 모든 학생을 정렬된 목록으로 가져오기. 학년은 1, 2, 3, ... 순으로 정렬되어야 하고, 같은 학년 안의 학생들은 이름을 알파벳순으로 정렬해야 해요.
  - "지금 학교에 등록된 학생은 누구인가요?"
  - "생각해 볼게요. 1학년에 Anna, Barb, Charlie가 있고, 2학년에 Alex, Peter, Zoe가 있고, 5학년에 Jim이 있어요. 그래서 답은 Anna, Barb, Charlie, Alex, Peter, Zoe, Jim이에요."

참고로 우리 학생들은 모두 이름이 하나뿐이에요. (작은 마을이니까 어쩔 수 없죠?)
