# 지침 추가

## 레지스터

| 레지스터 | 용도      | 타입    | 설명                                |
| -------- | --------- | ------- | ----------------------------------- |
| `$a0`    | 입력      | 정수    | 입력 자릿수                         |
| `$a1`    | 입력      | 정수    | 입력 자릿수의 밑                    |
| `$a2`    | 입력      | 정수    | 출력 자릿수의 밑                    |
| `$a3`    | 입력/출력 | 주소    | 덮어쓸 수 있는 자릿수 워드 배열     |
| `$v0`    | 출력      | 정수    | 출력 자릿수, 입력이 유효하지 않으면 -1 |
| `$t0-9`  | 임시      | 임의    | 임시 저장에 사용                    |
