# 소개

## 문자열

Common Lisp에서 문자열은 [문자][concept-characters]의 [벡터][concept-vectors]예요. 큰따옴표로 감싼 문자로 쓰죠. 예를 들어 "Hello World!"처럼요.

`stringp` 술어는 주어진 값이 문자열일 때만 참을 반환해요.

`subseq` 함수를 사용하면 문자열을 부분 문자열로 나눌 수 있어요. 이 함수는 문자열과 시작 인덱스를 받고, 원한다면 끝 인덱스도 받아요. 인덱스는 0부터 시작해요.

```lisp
(subseq "Hello World" 1 5)   ; => "ello"
(subseq "skip to the end" 5) ; => "to the end"
```

두 문자열이 같은지 비교할 때는 `string=`을 사용해요.
대소문자를 구분하지 않으려면 `string-equal`을 쓰면 돼요.

```lisp
(string= "macaroni" "macaroni")      ; => T
(string= "macaroni" "MACARONI")      ; => NIL
(string-equal "macaroni" "MACARONI") ; => T
```

문자열을 전부 대문자로, 전부 소문자로, 또는 각 단어의 첫 글자만 대문자로 바꿀 때는 `string-upcase`, `string-downcase`, `string-capitalize` 함수를 사용해요.

```lisp
(string-upcase "not too loud")                ; => "NOT TOO LOUD"
(string-downcase "YELL IT FROM THE ROOFTOPS") ; => "yell it from the rooftops"
(string-capitalize "practical COMMON LiSP")   ; => "Practical Common Lisp"
```
