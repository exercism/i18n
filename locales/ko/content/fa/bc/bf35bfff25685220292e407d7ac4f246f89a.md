# 추가 지침

이 연습 문제는 비표준 문자열 리터럴과 메타프로그래밍을 실험해 보기 좋은 문제예요.

비표준 문자열 리터럴에 대한 짧은 소개는 이 [블로그 글](https://web.archive.org/web/20170625222109/https://iaindunning.com/blog/julia-unicode.html)에서 볼 수 있어요. 자세한 메타프로그래밍 안내는 [매뉴얼](https://docs.julialang.org/en/v1/manual/metaprogramming/)에 있어요.

아래에 설명한 기능을 추가해서 풀이를 확장할 수 있어요.

보너스 A는 블로그 글에 나온 기초 내용만 알면 돼요. 보너스 B는 Julia의 메타프로그래밍에 대한 훨씬 더 많은 지식을 필요로 해요.

## 보너스 A
문자열에 `ROT13`을 적용하는 문자열 리터럴을 구현해 봐요:
```julia
R13"abcdefghijklmnopqrstuvwxyz" == "nopqrstuvwxyzabcdefghijklm"
```

## 보너스 B
`i = 0, ..., 26`에 대해 문자열을 `i`만큼 이동시키는 문자열 리터럴 `R<i>`를 구현해 봐요:
```julia
R0"Hello, World!" == "Hello, World!"
R4"Testing 1 2 3 testing" == "Xiwxmrk 1 2 3 xiwxmrk"
R13"abcdefghijklmnopqrstuvwxyz" == "nopqrstuvwxyzabcdefghijklm"
```
