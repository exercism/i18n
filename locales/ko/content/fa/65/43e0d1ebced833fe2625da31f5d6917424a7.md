# 메인테이너를 위한 안내

## Fortran 테스트를 만들기 위한 도우미 스크립트: create_fortran_test.py

연습 문제 테스트를 만드는 쉬운 방법은 `bin/create\_fortran\_test.py` 스크립트를 사용하는 거예요.

이 스크립트로 <exercise>\_test.f90 초기 파일을 만들 수 있고, 이 파일을 테스트의 템플릿으로 쓸 수 있어요.
일반적으로 생성된 파일의 'response' 함수를 올바른 함수 호출로 바꿔야 해요.

또 Fortran은 `\n`, `\t` 같은 특수 문자에 문제가 있으니, 이런 문자를 다룰 때는 각별히 주의해요.

### 준비 사항

- 정상 동작하는 CMake와 Fortran 컴파일러
- Python3.x (Python2에서도 동작하게 만들 수는 있지만, 하위 호환성을 맞추는 수고는 하지 않았어요)
- https://github.com/exercism/problem-specifications.git 최신 버전
- git

### 새 테스트를 만드는 작업 흐름

- `exercism/problem-specifications`에서 최신 변경 사항을 가져와요. 예: git clone git@github.com:exercism/problem-specifications.git
- 새 연습 문제를 만들기 위한 새 브랜치를 만들어요. 예: git checkout -b exercise-bob
- 만들고 싶은 예제에 대해 이 스크립트를 실행해요
- `config/CMakeLists.txt`를 연습 문제 디렉터리로 복사해요 (이때 `bin/update-cmake-files`를 사용할 수 있어요)
- 동작하는 연습 문제를 구현해요
- 문제가 될 수 있는 테스트를 고쳐요 (예: exercise/bob의 "Test 20"과 "Test 24" 참고)
- `ctest` 명령이 오류 없이 검증하는지 확인해요
- 작성한 풀이를 .meta/example.f90로 복사하고, 연습 문제 파일(예: bob.f90)에서 실제 구현을 지워요
- .docs와 .meta 디렉터리를 업데이트해요
  - cp ../problem-specifications/exercises/bob/description.md exercises/practice/bob/.docs/instructions.md
    - "# Description"을 "# Instructions"로 바꿔요
  - .meta/tests.toml을 수동으로 채워요 (자동화된 방법이 생길 때까지)
  - .meta/config.json을 수동으로 채워요 (자동화된 방법이 생길 때까지)
    - ../problem-specifications/exercises/bob/metadata.yml을 사용해요
- 변경 사항으로 풀 리퀘스트를 열어요

bob 예제의 경우:

```bash
$ python bin/create_fortran_test.py -j ../problem-specifications/main/exercises/bob/canonical-data.json -t exercises/practice/bob/bob_test.f90
Namespace(json='../problem-specifications/main/exercises/bob/canonical-data.json', target='exercises/practice/bob/bob_test.f90')
Wrote : exercises/practice/bob/bob_test.f90
$ cp config/CMakeLists.txt exercises/practice/bob/.
$ cd exercises/practice/bob
$ touch bob.f90
$ mkdir build
$ cd build
$ cmake ..
$ make
$ ctest -V
```

### `CMakeLists.txt` 변경하기

cmake 파일을 변경할 때는 `config/`에 있는 원본을 업데이트하고, `bin/update-cmake-files`를 사용해 모든 연습 문제 디렉터리에 복사해요.

## 풀이

풀이가 완성되면 그 풀이를 ".meta" 디렉터리에 "example.f90"으로 복사해요.

학생에게 도움이 되도록 함수나 서브루틴의 뼈대 구현을 남겨 두고, 연습 문제 디렉터리에는 연습 문제 이름을 딴 파일을 남기고 싶을 수도 있어요.
