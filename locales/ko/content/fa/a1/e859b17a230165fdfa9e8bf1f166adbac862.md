# 힌트

## 일반

- 모든 과제는 루프 안에서 텍스트를 만들어요. 그래서 각 과제는 `#FSTR`로 시작해서 `.str`로 끝나요.
- 모든 `+`의 결과는 빌더에 다시 대입해요:
  `script := script + ...`.

## 1. 큐 반복하기

- `1.upto!(times)`는 루프를 알맞은 횟수만큼 실행해요. 여기서 나오는 값은 필요 없으니, 한 번도 쓰지 않는 변수에 그대로 넣어도 돼요. 아니면 아무 값도 내놓지 않는 `times.times!`를 써도 돼요.
- 횟수가 아예 없을 때는 특별히 처리할 필요가 없어요. 루프가 그냥 실행되지 않으니까요.

## 2. 출연진 이니셜

- `names.elt!`는 이름을 하나씩 내놓아요. `[0]`은 그 이름의 첫 글자를 가져와요.
- `FSTR`은 `CHAR`를 그대로 받아들여요. 그래서 굳이 문자열로 바꿀 필요가 없어요.

## 3. 줄 번호 매기기

- 지난 연습 문제처럼 루프 하나에 반복자 두 개를 써요. 숫자는 `1.up!`이, 텍스트는 `lines.elt!`가 맡아요.
- 새 줄은 첫 번째 줄을 빼고 모든 줄 *앞에* 들어가요. 숫자를 검사하는 게 가장 쉬운 방법이에요: `if number > 1 then ... end`.
- `FSTR`은 숫자를 그대로 받아들여서 `script + number + ". "`가 변환 없이도 제대로 동작해요.

## 4. 대사 외치기

- `line.elt!`는 문자열을 한 글자씩 훑어요.
- `.upper`는 글자가 아닌 것은 그대로 둬요. 그래서 공백은 특별히 처리할 필요가 없어요.
