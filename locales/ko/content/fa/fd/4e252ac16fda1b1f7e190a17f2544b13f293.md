# 지침

몇몇 "다른" 개발자들이 원격 조종 자동차 프로젝트 [exercise:csharp/remote-control-competition]()를 진행해 왔어요. 코드를 정리하러 불려 왔어요.

## 1. 자동차 자체와 텔레메트리 시스템의 관심사를 분리해요

텔레메트리 메서드와 속성을 분리해 `Telemetry` 속성으로 접근하도록 `RemoteControlCar` 클래스를 리팩터링해요.

```csharp
var car = new RemoteControlCar();
car.Telemetry.Calibrate();
car.Telemetry.SelfTest();
car.Telemetry.ShowSponsor("Walker Industries Inc.");
car.CurrentSponsor
// => "Walker Industries Inc."
car.Telemetry.SetSpeed(100, "cps");
car.GetSpeed()
// => "100 centimeters per second"
```

## 2. 다른 코드가 Telemetry 타입에 너무 많은 의존성을 갖지 않도록 해요

`Telemetry` 인스턴스를 자동차의 스코프 밖에서는 만들 수 없도록 해요.

## 3. 다른 코드가 Speed 구조체에 의존하지 않도록 해요

`RemoteControlCar` 클래스의 스코프 밖에서는 `Speed` 구조체를 사용할 수 없도록 해요.

## 4. 다른 코드가 SpeedUnits 열거형에 의존하지 않도록 해요

`RemoteControlCar` 클래스의 스코프 밖에서는 `SpeedUnits` 열거형을 사용할 수 없도록 해요.
