# 소개

레코드는 서로 다른 타입일 수도 있는 필드들을 하나로 묶은 모음이에요. 레코드를 정의할 때는 `type` 키워드를 사용해요. 레코드의 필드는 `{`와 `}` 사이에 정의하고, 각 필드에는 이름과 타입이 _모두_ 있어야 해요. 레코드를 만들 때는 `{`와 `}` 사이에 필드 이름을 적고 값을 할당해요. 레코드를 만들 때는 모든 필드에 값을 할당해야 해요. 레코드 인스턴스의 필드 값은 점 표기법으로 접근할 수 있어요.

레코드를 정의하거나 만들 때 각 필드는 줄을 나눠 쓰거나, 한 줄에 쓸 때는 세미콜론(`;`)으로 구분해야 해요.

```fsharp
// Define a record
type Address =
    { Street: string
      HouseNumber: int }

// Create a record
let oldAddress: Address =
    { Street = "Main Street"
      HouseNumber = 17 }

// Single-line alternative
type ConciseAddress = { Street: string; HouseNumber: int }
let conciseAddress: ConciseAddress = { Street = "Main Street"; HouseNumber = 17 }
```

레코드는 불변이기 때문에 한 번 만들어진 레코드의 필드 값은 절대 바뀌지 않아요. 레코드의 값을 바꾸고 싶다면 `with` 키워드로 기존 레코드의 복사본을 만들되, 하나 이상의 필드에 새 값을 넣을 수 있어요.

```fsharp
// Copy the old address but change the house number
let newAddress: Address = { oldAddress with HouseNumber = 86 }
newAddress.Street      // => "Main Street"
newAddress.HouseNumber // => 86
```

레코드는 _구조적 동등성_을 가져요. 같은 레코드의 인스턴스 두 개가 값까지 같다면 서로 동등하다는 뜻이에요.

점 표기법으로 레코드의 필드에 접근할 수 있을 뿐만 아니라, 바인딩과 패턴 매칭에서 레코드를 _구조 분해_할 수도 있어요:

```fsharp
let myAddress: Address = { Street = "Broadway"; HouseNumber = 123 }
let { Street = myStreet; HouseNumber = myHouseNumber } = myAddress

match myAddress with
| { HouseNumber = 1 } -> printfn "First house"
| { HouseNumber = houseNumber; Street = street } -> printfn "House number %d on %s" houseNumber street
// => "House number 123 on Broadway
```
