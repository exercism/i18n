# 소개

_"날짜와 시간은 어린아이들에게나 가르치는 거잖아요. 그게 얼마나 어렵겠어요?"_

많은 프로그래머가 그런 실수를 하고, 그 뒤에 겪는 일은 건강과 행복에 좋지 않은 영향을 주곤 해요.

날짜와 시간을 다루는 제법 복잡한 프로그래밍을 하는 사람이라면, 적어도 잠재적인 문제를 이해하고 완화할 준비는 되어 있어야 해요.

이 문서에서는 Julia가 날짜와 시간을 다루는 방식의 개요를 살펴봐요. 더 자세한 내용은 [매뉴얼][Dates]을 참고해야 해요.
설명이 더 명확하다고 느끼는 독자도 있을 [Wikibook][Wikibook]도 있는데, 타입 계층을 보여 주는 유용한 [다이어그램][type-hierarchy]도 함께 담겨 있어요.

## `Dates` 모듈

기본적인 기능 대부분은 `Dates` 모듈에 있어요. 이 모듈은 기본 설치에 포함되어 있지만 표준 라이브러리의 일부는 아니에요.

모듈을 사용하는 방법은 두 가지가 있어요:

1. `import Dates`를 추가하고, 모든 함수 호출 앞에 `Dates.`를 붙여요
2. `using Dates`를 추가하면 전체 모듈이 현재 네임스페이스로 들어와요 (_몇 가지 문제가 있는 이름은 제외하고요_).

```julia-repl
# option 1
julia> import Dates

julia> Dates.now()
2025-06-21T16:02:39.080

julia> now()  # wrong: need to include `Dates.` after an import
ERROR: UndefVarError: `now` not defined in `Main`


# option 2
julia> using Dates

julia> now()  # functions are now in the namespace
2025-06-21T16:03:04.161
```

`Dates` 모듈은 크고 복잡하지만, 크게 네 가지 기능을 제공해요:

- `Dates.Date`: 일, 월, 년을 담고 있지만 하루 중의 시각은 없어요.
- `Dates.Time`: 하루 중의 시각을 담고 있지만 날짜는 없어요.
- `Dates.DateTime`: 날짜와 시간을 함께 담고 있어요.
- `Dates.Period`: 시간/날짜 간격을 다뤄요.

참고로 `DateTime`은 보통 시간대 정보를 포함하지 _않아요_ (Python이라면 이런 것을 "naive" datetime이라고 불러요).
예외는 `now()`인데, 이 함수는 시스템 시계에서 현지 시간을 가져오고, 필요하면 이를 UTC로 변환할 수 있어요.

아마도 가장 자주 필요한 작업은 이런 것들이에요:

- 적절한 입력 형식을 파싱해서 `Dates` 타입을 만들어요.
- `Dates` 타입에서 필요한 숫자 또는 문자열 형식을 얻어요.
- `Date`, `Time`, `DateTime` 값에 오프셋을 적용해요.
- 그런 값 두 개 사이의 간격을 계산해요.
- 현재 날짜(`today()`)와 시간(`now()`)을 가져와요.

~~~~exercism/note
시각적인 방해를 줄이기 위해, 이 문서의 나머지 예제 코드는 대부분 `using Dates`를 사용했다고 가정하고, 함수 호출에 모듈 이름 `Dates.`를 넣지 않아요.
~~~~

### 날짜와 시간 형식

날짜와 시간을 쓰는 방법은 아주 많고, 대개 문화권마다 달라요.
"7/6/23"처럼 숫자만으로 된 날짜는 모호하고 헷갈리며, 다국적 기업에서 값비싼 실수를 많이 불러왔어요 (_글쓴이는 쓰라린 경험을 바탕으로 하는 말이에요_).

국제 표준은 `ISO 8601`에 정의되어 있고, 두 가지 큰 장점이 있어요:

- 파싱이 빠르고 모호하지 않아요.
- 날짜/시간을 일반 텍스트처럼 다뤄 사전순으로 정렬할 수 있어서 정렬이 쉬워요.

앞의 예제에서 `Date.now()`가 `2025-06-21T16:03:04.161`을 반환하는 것을 봤어요.

이 값은 여러 부분으로 이루어져 있어요:

- 날짜 부분은 `YYYY-MM-DD`예요.
- 시간 부분은 `hh:mm:ss`예요.
- 소수점 뒤에는 선택적으로 밀리초(또는 더 작은 단위)가 붙어요.

다른 문자열 형식은 뒤에서 다뤄요.

## 날짜

`Dates.Date`는 비교적 단순한 날짜 전용 타입이고, 시간이나 시간대는 다루지 않아요.

```julia-repl
# constructor with year, month, day arguments
julia> date1 = Date(2025, 06, 23)
2025-06-23

# constructor with ISO 8601 string
julia> date2 = Date("2025-06-23")
2025-06-23

julia> date1 == date2
true

julia> typeof(date1)
Date
```

날짜의 각 부분을 가져오는 접근자 함수가 있는데, 대소문자로 구분되는 쌍으로 이루어져 있어요.

```julia-repl
# lowercase returns an integer
julia> month(date1)
6

julia> typeof(month(date1))
Int64

# Propercase returns a Period type
julia> Month(date1)
6 months

julia> typeof(Month(date1))
Month
```

### 조회 함수

달력을 어느 정도 이해하는 함수가 여러 가지 있어요.
다음 예제는 그중 몇 개만 보여 줘요.

```julia-repl
julia> date1
2025-06-23

julia> dayofweek(date1) # 1 = Monday, 7 = Sunday
1

julia> dayname(date1)
"Monday"

julia> daysinmonth(date1)
30

julia> isleapyear(date1)
false

julia> lastdayofmonth(date1)
2025-06-30
```

## 시간

`Dates.Time`은 기본적인 시간 전용 타입이에요.
날짜는 전혀 다루지 않아서, 자정이 되면 시간이 자동으로 `Time(0, 0, 0)`으로 넘어가요.

전체 생성자 형식은 `Time(hour, min, sec, millisec, microsec)` 또는 이에 해당하는 ISO 8601 형식이에요.

모든 매개변수는 선택 사항이고 기본값은 `0`이에요.

```julia-repl
julia> Time(14, 57, 25, 142)
14:57:25.142

julia> Time("14:57:25.142")
14:57:25.142

julia> Time(14, 57, 25, 142, 32)
14:57:25.142032
```

`Date`와 마찬가지로, 각 부분은 접근자 함수로 가져올 수 있어요:

```julia-repl
julia> minute(t) # => integer
57

julia> Minute(t) # => Period
57 minutes
```

## 날짜와 시간

`Dates.DateTime`은 `Date`와 `Time` 타입의 기능 대부분을 합쳐 놓은 타입이에요.

```julia-repl
julia> dt1 = DateTime(2025, 6, 23, 14, 57, 25, 142)
2025-06-23T14:57:25.142

# date1 and t were defined in previous examples
julia> dt2 = DateTime(date1, t)
2025-06-23T14:57:25.142
```

연, 월, 일 매개변수의 기본값은 `1`이고, 시간 관련 매개변수의 기본값은 모두 `0`이에요.

이 매개변수를 모두 제대로 기억하기는 어려울 수 있어서, 입력할 때는 ISO 형식이 더 나을 수 있어요.

또는 위 예제처럼 `Date`와 `Time`으로 `DateTime`을 만들 수도 있어요.

## 기간

날짜/시간의 각 구성 요소에는 `Year`부터 `Nanosecond`까지 각각의 `Period` 타입이 있고, 이는 시간의 간격을 나타내요.
이 타입들은 산술 연산에 특히 유용해요.

```julia-repl
julia> dt1
2025-06-23T14:57:25.142

julia> Year(21)
21 years

julia> Second(61)
61 seconds

julia> dt1 + Year(21) - Second(61)
2046-06-23T14:56:24.142

julia> Date(2025, 07, 03) - Date(2025, 04, 25)
69 days
```

`Period` 타입을 다룰 때 Julia는 한 달의 길이처럼 달력의 불규칙성을 똑똑하게 처리하려고 하고, 필요하면 반올림해요.

```julia-repl
# February has fewer days than January
julia> Date(2025, 1, 31) + Month(1) 
2025-02-28
```

## 문자열 표현

앞에서 ISO 8601 표준을 언급했는데, Julia가 문자열을 서식화하거나 파싱할 때 쓰는 기본 날짜/시간 표현이 바로 이 표준이에요.

물론 다른 형식도 많이 쓰이고, 대개 문화권에 따라 다르게 쓰여요.
이런 형식을 다루기 위해 Julia에는 `DateFormat` 타입이 있고, 임의로 복잡한 형식 문자열로 만들 수 있어요.

```julia-repl
# dateformat"" string syntax
julia> dtfmt = dateformat"d/m/y"
dateformat"d/m/y"

julia> typeof(dtfmt)
DateFormat{Symbol("d/m/y"), Tuple{Dates.DatePart{'d'}, Dates.Delim{Char, 1}, Dates.DatePart{'m'}, Dates.Delim{Char, 1}, Dates.DatePart{'y'}}}

# DateFormat constructor
julia> DateFormat("d/m/y")
dateformat"d/m/y"
```

위 예제는 아주 단순한데, 유럽에서 흔히 쓰는 일/월/년 형식의 날짜일 뿐이에요.
문법은 두 가지 형태로 보여 줬지만 결과는 같아요.

이렇게 만든 `DateFormat`은 적절한 문자열을 파싱할 때 쓸 수 있어요:

```julia-repl
julia> DateTime("14/7/2023", dtfmt)
2023-07-14T00:00:00
```

`DateFormat`을 만드는 데는 적지 않은 부하가 따르므로, 이 단계를 한 번만 하는 것(여기서 `dtfmt`처럼)이 여러 날짜/시간 문자열을 반복 처리할 때 성능에 도움이 돼요.

형식은 이보다 훨씬 복잡할 수 있으니, 자세한 내용은 [매뉴얼][dateformat]을 봐요.

같은 `DateFormat`을 [`Dates.format()`][format] 함수와 함께 쓰면 날짜/시간을 원하는 문자열 형식으로 출력할 수도 있어요.

아쉽게도 `format`과 네임스페이스 충돌이 있는 것 같아서(적어도 Julia 1.11.5 기준으로), `using Dates`를 한 뒤에도 `Dates.` 접두사를 붙이는 게 가장 좋아요.

```julia-repl
julia> dt1
2025-06-23T14:57:25.142

julia> Dates.format(dt1, dateformat"e, u d")
"Mon, Jun 23"
```

[문서][wiki-format]에 나와 있듯이, `"e, u d"`는 요일과 월의 축약된 텍스트 표현을 만들어 줘요.

텍스트 표현의 기본값은 영어예요.
다른 언어도 추가할 수 있지만, 현재로서는 지원이 그리 좋지 않아요.
