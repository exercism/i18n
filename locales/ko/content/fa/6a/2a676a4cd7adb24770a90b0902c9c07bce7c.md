# 설치

PureScript를 설치하는 가장 간단한 방법은 Node.js와 NPM을 이용하는 거예요.

컴퓨터에 Node.js가 아직 설치되어 있지 않다면, [Node.js 웹사이트](https://nodejs.org/)에서 내려받을 수 있어요. Node.js를 설치하고 나면, 터미널에 다음 명령어를 입력해 PureScript 컴파일러와 Spago 빌드 도구를 설치해요.

    npm install --global purescript spago

더 자세한 내용은 [PureScript 저장소](https://github.com/purescript/purescript/blob/master/INSTALL.md)에서 확인할 수 있어요.
