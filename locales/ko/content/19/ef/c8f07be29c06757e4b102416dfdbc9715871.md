# 안내

이번 연습 문제에서는 로그 라인을 처리해요.

각 로그 라인은 다음과 같은 형식의 문자열이에요: `"[<LEVEL>]: <MESSAGE>"`.

로그 레벨은 세 가지가 있어요:

- `INFO`
- `WARNING`
- `ERROR`

과제가 세 개 있고, 각 과제는 로그 라인을 받아서 무언가를 하도록 요청해요.
이 과제들을 푸는 방법은 다양해요. 위 예시에서 마음에 드는 방법을 골라서 어떻게 풀어낼 수 있을지 한번 해봐요.

## 1. 로그 라인에서 메시지 가져오기

로그 라인의 메시지를 반환하도록 `LogLineParser#message` 메서드를 구현해요:

```ruby
LogLineParser.new('[ERROR]: Invalid operation').message
# => "Invalid operation"
```

앞뒤의 공백은 제거해야 해요:

```ruby
LogLineParser.new("[WARNING]:  Disk almost full\r\n").message
# => "Disk almost full"
```

## 2. 로그 라인에서 로그 레벨 가져오기

로그 라인의 로그 레벨을 반환하도록 `LogLineParser#log_level` 메서드를 구현해요. 로그 레벨은 소문자로 반환해야 해요:

```ruby
LogLineParser.new('[ERROR]: Invalid operation').log_level
# => "error"
```

## 3. 로그 라인 재구성하기

로그 라인을 재구성하도록 `LogLineParser#reformat` 메서드를 구현해요. 메시지를 앞에 두고 그 뒤에 로그 레벨을 괄호 안에 넣어요:

```ruby
LogLineParser.new('[INFO]: Operation completed').reformat
# => "Operation completed (info)"
```
