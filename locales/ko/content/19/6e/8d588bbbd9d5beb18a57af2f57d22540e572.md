# 지침 추가

## 레지스터

| 레지스터  | 용도      | 타입    | 설명                            |
| -------- | --------- | ------- | ------------------------------- |
| `$a0`    | 입력      | 주소    | null로 종료되는 첫 번째 문자열   |
| `$a1`    | 입력      | 주소    | null로 종료되는 두 번째 문자열   |
| `$v0`    | 출력      | 정수    | 해밍 거리                        |
| `$t0-9`  | 임시      | 임의    | 임시 저장용                      |
