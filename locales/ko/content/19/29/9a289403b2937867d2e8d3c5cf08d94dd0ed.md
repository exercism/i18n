# 소개

[Zen of Python][zen-of-python]에는 "Python에서 무언가를 하는 _명확한_ 방법은 하나여야 한다"고 나와 있어요.
Python 3.6부터는 [**리터럴 문자열 보간**][string-interpolation]([**`f-string`s**][f-string])이 문자열을 서식 지정하는 명확하고 선호되는 방법인 경우가 많아요:

```python
>>> adjective = "easy"
>>> f"This is an {adjective} way to format strings!"
'This is an easy way to format strings!'
```

하지만 Python의 긴 역사와 다양한 사용 사례를 생각하면, Python에서 문자열 서식 지정을 하는 다른 일반적인 방법이 **세 가지** 더 있다는 게 그리 놀랍지만은 않아요:

1. [`str.format()`][str-format]은 다재다능하고 매우 강력하며, [`gnu gettext`][gettext]와 대부분의 Python 버전 모두와 호환돼요.
2. 단순함과 안전성, 또는 본격적인 국제화가 필요하다면 [`string.Template()`][string-template]을 사용해 입력을 다뤄야 할 때의 위험을 줄이고 번역 문자열을 감쌀 수 있어요.
3. `%` 연산자는 최신 Python에서도 여전히 동작하지만, 새 코드에서는 일반적으로 더 이상 권장되지 않아요.
  대부분 오래된 코드베이스와의 호환성을 위해 쓰이는 편이에요.
  `%` 서식 지정은 ASCII가 아닌 문자와 유니코드 문자를 표시할 때 문제가 생길 수 있고, 다른 방법보다 오류가 많고 기능은 적어요.
  사용할 생각이라면 자신이 쓰는 Python 배포판의 지원 세부 사항을 확인해 보세요.
