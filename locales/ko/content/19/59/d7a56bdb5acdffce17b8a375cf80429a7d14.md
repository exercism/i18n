# 소개

`const` 한정자는 컴파일 시점에 값이 알려져 있고 프로그램이 실행되는 동안 바뀌지 않는 모든 필드에 적용할 수 있어요(그리고 일반적으로 그래야 해요).

```csharp
private const int num = 1729;
public const string title = "Grand" + " Master";
```

`readonly` 한정자는 `const`로 만들 수 없고, 프로그램이 실행되는 동안 값이 바뀌지 않으며, 인라인 이니셜라이저로 설정되거나 인스턴스화할 때(생성자 또는 생성자가 호출하는 메서드에 의해) 설정되는 모든 필드에 적용할 수 있어요(그리고 일반적으로 그래야 해요).

```csharp
private readonly int num;
private readonly System.Random rand = new System.Random();

public MyClass(int num)
{
    this.num = num;
}
```
