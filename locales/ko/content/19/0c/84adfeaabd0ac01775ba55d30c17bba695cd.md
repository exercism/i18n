# 추가 지침

## 레지스터

| 레지스터 | 용도 | 타입 | 설명                                                       |
| -------- | --------- | ------- | ---------------------------------------------------------- |
| `$a0`    | 입력     | 주소 | 배열 1의 요소                                              |
| `$a1`    | 입력     | 정수 | 배열 1의 크기 (워드 단위)                                  |
| `$a2`    | 입력     | 주소 | 배열 2의 요소                                              |
| `$a3`    | 입력     | 정수 | 배열 2의 크기 (워드 단위)                                  |
| `$v0`    | 출력     | 정수 | `0` = equal, `1` = unequal, `2` = sublist, `3` = superlist |
| `$t0-9`  | 임시 | 임의     | 임시 저장에 사용                                           |
