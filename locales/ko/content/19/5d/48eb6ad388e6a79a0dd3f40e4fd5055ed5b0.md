# 소개

## 널 참조

다른 프로그래밍 언어(C/C++, Python, Java, Ruby, Lisp 등)를 사용해 본 적이 있다면, `null`이나 `nil`을 접해 봤을 가능성이 커요.
이런 언어에서는 `null`이나 `nil`로 특정 변수에 값이 없다는 것을 나타내요.
하지만 이 때문에 `null` 변수를 실수로 사용하는 일이 쉽고도 자주 일어나요.
짐작할 수 있듯이, 존재하지 않는 함수를 호출하거나 없는 값에 접근하려고 하면 온갖 버그와 충돌로 이어질 수 있어요.
`null`을 만든 사람은 심지어 이것을 자신의 ['10억 달러짜리 실수'][billion-dollar-mistake]라고 부르기까지 했어요.

[billion-dollar-mistake]: https://www.infoq.com/presentations/Null-References-The-Billion-Dollar-Mistake-Tony-Hoare/

## `Option` 타입

이런 문제를 피하기 위해, Cairo의 변수는 `Option` 열거형을 사용해서 값이 없다는 것을 안전하게 표현할 수 있어요.
이 열거형에는 두 가지 변형이 있어요. `None`은 Cairo에서 null에 해당하는 값이고, `Some(T)`에서 `T`는 아무 타입의 값이에요.

다음과 같아요:

```rust
enum Option<T> {
    None,
    Some(T),
}
```

`Option`은 널 참조가 일으킬 수 있는 문제를 막아 주는 안전 계층이라고 생각하면 돼요. 그러면서도 널 참조가 가진 개념적 유용성은 그대로 간직해요.

## `Option` 사용하기

변수에 `None`을 설정하는 것은 꽤 간단해요:

```rust
let nothing: Option<u32> = Option::None;  // Variable nothing is set to None
```

하지만 `Option` 타입이 값을 담기를 원한다면, 그 값을 직접 대입할 수는 없어요.
`Option` 타입 변수와, 예를 들어 `i32` 타입 변수는 서로 같지 않아요.
`Some`을 사용해야 해요:

```rust
let wrong_way: Option<i32> = -4; // This will not work

let right_way: Option<i32> = Option::Some(-4); // This will work
let another_right_way = Option::Some(-4); // Compiler infers that this is Option<i32>
```

같은 이유로 다음 코드도 작동하지 않아요:

```rust
let number = 47;
let option_number = Option::Some(15);

let compile_error = number + option_number; // Cannot add an i32 and an Option<i32> - they are of different types
```

`Some`이 담고 있는 값을 꺼내려면, 그 값이 존재하는지 먼저 확인해야 해요:

```rust
let mut some_words = Option::Some("choose something to say"); // some_words set to something

match some_words {
    Option::Some(str) => println!("Here, we will {}", str),
    Option::None => println!("I've got nothing to say"),
} // Prints, "Here, we will choose something to say"

some_words = Option::None; // some_words now set to None

// Exactly the same match block as above
match some_words {
    Option::Some(str) => println!("Here, we will {}", str),
    Option::None => println!("I've got nothing to say"),
} // Prints, "I've got nothing to say"
```

Cairo에는 `Option`에 담긴 값을 확인하고 꺼내는 데 쓸 수 있는 도구가 `match` 말고도 더 있어요. 하지만 이제 `match`는 익숙할 거예요.

Cairo가 널 참조 대신 `Option`을 사용하는 이유를 보여 주는 예라고 생각해요.
핵심은 `Option` 변수가 `Some`인지(그렇다면 그 안에 담긴 값을 꺼내서 사용하면 돼요), 아니면 `None`인지를 **_반드시_ 확인해야 한다**는 거예요.
그렇지 않으면 프로그램이 컴파일되지 않아요. 컴파일러가 `null`로부터 코드를 안전하게 지켜 줘요.
