# 개요

.NET 기본 클래스 라이브러리는 정규식을 처리하기 위한 [`Regex`][regex] 클래스를 제공해요.

C#과 다른 정규식 구현을 비교한 [글][regex-comparison]도 참고해 보세요.

## 캡처 그룹

고려할 점 중 하나는 정규식 패턴의 여러 부분에 일치하는 텍스트 조각을 반환하는 캡처 그룹이에요. 캡처 그룹을 다루는 방식에 익숙해지려면 시간이 좀 걸려요. [문서][capture]를 참고해 보세요.

캡처 그룹 `(?<capture-name>pattern)`에는 다음과 같은 계층 구조가 있다는 점에 유의해야 해요:

- 0개 이상의 매치 집합이 반환돼요(텍스트에서 찾은 매치마다 하나씩).
- 각 매치에는 여러 캡처 그룹이 들어 있어요.
- 각 그룹에는 여러 캡처가 들어 있어요.

또한:

- `Match`는 `Group`에서 파생돼요.
- `Group`은 `Capture`에서 파생돼요.

주의할 점:

- 가장 안전한 방법은 명명된 캡처를 사용하는 거예요.
- 캡처 그룹은 대체로 텍스트에 나타난 순서 그대로 `Groups` 컬렉션에 들어가요.
- `Groups[0]`은 전체 매치와 관련된 것으로 보여요.
- `Groups[<capture name>].Value`가 거의 확실히 관심 있는 값이에요. 개별 캡처는 (`Caputures[0]`를 제외하면) 있더라도 진단 목적을 위한 것으로 보여요.

## 정규식 옵션

[`RegexOptions`][regex-options]에 익숙해져 보세요.

익숙한 `IgnoreCase` 옵션 외에도 `MultiLine`과 `IgnorePatternWhitespace` 옵션이 있어요. `MultiLine`은 여러 줄의 텍스트를 한 번에 처리할 때 유용하고, `IgnorePatternWhitespace`는 축자 문자열, 문자열 보간, 주석과 함께 쓰면 다음 예시처럼 매우 표현력이 좋아요:

```csharp
const string PREAMBLE = "preamble";
const string PWTEXT = "pwtext";
const string PW = "pw";
const string SPACE = "space";
const string POSTAMBLE = "postamble";

var pattern = $@"
    ^
    (?<{PREAMBLE}>.*)          # any text
    (?<{PWTEXT}>password)      # the literal text - password
    (?<{SPACE}>\s+)
    (?<{PW}>\w*)               # the password itself
    (?<{POSTAMBLE}>.*)         # any text
    $
  ";

var rewrittenLine = $"{grps[PREAMBLE].Value}{grps[PWTEXT].Value}{grps[SPACE].Value}{mask}{grps[POSTAMBLE].Value}";
```

또 눈여겨볼 옵션은 [컴파일된][regex-compilation] 정규식을 위한 `RegexOptions.Compiled`예요.
