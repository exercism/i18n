# 지시문

친구 리누스는 도시 사이를 오가는 화물 열차를 운전하는 기관사예요.
열차를 다루는 일에는 놀라울 만큼 능숙하지만, 물류나 컴퓨터를 다루는 일에는 그렇지 않아요.
그래서 열차 정보를 정리하고 경로 데이터의 실수를 바로잡는 일에 여러분의 프로그래밍 도움을 받고 싶어 해요.

~~~~exercism/note
이 연습 문제는 슬라이싱, 인덱싱, 그리고 다양한 `dict` 메서드를 사용하면 쉽게 풀 수 있어요.
하지만 아래 각 과제를 해결할 때는 패킹, 언패킹, 다중 할당을 연습해 보면 좋겠어요.
~~~~

## 1. 모든 화차의 배열 만들기

친구는 각 화차의 식별자(ID)를 계속 기록해 왔지만, 시스템이 어느 시점에 몇 대의 화차를 처리해야 할지 늘 확신이 없어요.
이 데이터를 하나의 `list`로 묶어 두면 나머지 물류 프로그램이 훨씬 수월해져요.

임의의 개수만큼 화차 ID를 받는 함수 `get_list_of_wagons()`를 구현해요.
각 ID는 양의 정수예요.
그런 다음 함수는 주어진 ID들을 하나의 `list`로 `return`해야 해요.

```python
>>> get_list_of_wagons(1, 7, 12, 3, 14, 8, 5)
[1, 7, 12, 3, 14, 8, 5]
```

## 2. 화차 배열 고치기

이쯤에서 데이터와 그것이 물류 프로그램에서 어떻게 쓰이는지 감이 잡히기 시작할 거예요.
ID 시스템은 항상 기관차에 **1**이라는 ID를 부여하고, 열차의 나머지 화차에는 **1**보다 큰 임의의 ID를 부여해요.

친구가 새 화차 두 대를 열차에 연결하고는 시스템을 업데이트하는 걸 잊었어요!
이제 열차 `list`의 처음 두 화차를 끝으로 옮겨야 해요. 그렇지 않으면 모든 순서가 엉망이 돼요.

설상가상으로 친구가 방금 빠진 화차 ID가 들어 있는 듯한 두 번째 `list`를 발견했어요.
새 화차를 옮기고 나면 이 두 번째 `list`의 ID들을 지정된 기관차 바로 뒤에 놓아야 한다는 것만 기억해요.

리누스는 자기 실수를 바로잡고 데이터를 하나로 합쳐 주면 정말 고마워할 거예요.

화차 ID를 담은 두 개의 `lists`를 받는 함수 `fix_list_of_wagons()`를 구현해요.
첫 번째 `list`의 처음 두 항목을 끝으로 옮기고, 두 번째 `list`의 값들을 기관차 ID(**1**) 뒤(_오른쪽_)에 삽입해야 해요.
그런 다음 함수는 수정된 `list`를 `return`해야 해요.

```python
>>> fix_list_of_wagons([2, 5, 1, 7, 4, 12, 6, 3, 13], [3, 17, 6, 15])
[1, 3, 17, 6, 15, 7, 4, 12, 6, 3, 13, 2, 5]
```

## 3. 빠진 정차역 추가하기

이제 모든 화차 데이터가 정확해졌으니, 리누스는 시스템의 경로 정보를 업데이트해 주기를 바라요.
운송 경로를 따라 열차는 화물을 싣거나 내리기 위해 여러 역에 정차할 수 있어요.
여정마다 이런 중간 배송 지점의 수가 다를 수 있어요.
친구는 빠졌거나 추가된 배송 정보를 시스템의 경로 `dict`에 업데이트해 주기를 바라요.

경로 `dict`와 그 뒤에 가변 개수의 키워드 인자를 받는 함수 `add_missing_stops()`를 구현해요.
이 인자들은 하나 이상의 정차역을 담은 `dict` 형태일 수도 있고, 임의의 개수만큼의 `stop_number=city` 키워드 쌍일 수도 있어요.
그런 다음 함수는 추가된 모든 정차역을 순서대로 담은 `key` 하나가 더해진 경로 `dict`를 반환해야 해요.

```python
>>> add_missing_stops({"from": "New York", "to": "Miami"},
                      stop_1="Washington, DC", stop_2="Charlotte", stop_3="Atlanta",
                      stop_4="Jacksonville", stop_5="Orlando")

{"from": "New York", "to": "Miami", "stops": ["Washington, DC", "Charlotte", "Atlanta", "Jacksonville", "Orlando"]}
```

## 4. 경로 정보 확장하기

리누스는 경로 프로그램을 작업하다가 특정 경로에 중요한 세부 정보가 빠져 있다는 것을 알아챘어요.
초기 경로 정보는 `dict`로 만들어져 있고, 친구는 빠진 것이 있으면 그 `dict`를 업데이트해 주기를 바라요.
시스템의 모든 경로는 조금씩 다른 세부 정보를 필요로 하기 때문에, 리누스는 범용적인 해결책을 정말 선호해요.

두 개의 `dicts`를 받는 `extend_route_information()` 함수를 구현해요.
첫 번째 `dict`는 열차 경로가 오가는 출발지와 목적지 도시를 담고 있어요.

두 번째 `dict`는 열차 속도, 길이, 온도 같은 다른 경로 세부 정보를 담고 있어요.
함수는 모든 경로 정보를 하나로 합친 `dict`를 반환해야 해요.

~~~~exercism/note
두 번째 `dict`에는 예시에 나온 것과 다르거나 더 많은 속성이 들어 있을 수 있어요.
~~~~

```python
>>> extend_route_information({"from": "Berlin", "to": "Hamburg"}, {"length": "100", "speed": "50"})
{"from": "Berlin", "to": "Hamburg", "length": "100", "speed": "50"}
```

## 5. 화차 차량기지 바로잡기

리누스는 화차 차량기지를 살펴보다가 화차들이 올바른 순서로 보관되지 않고 있다는 것을 알아챘어요.
각 화차에는 ID 외에도 운반하는 화물의 종류에 대응하는 색상이 있어요.
화차는 차량기지에 격자 형태로 보관되는데, 격자의 각 열에는 같은 색상의 화차가 들어가요.

그런데 물류 시스템에서는 차량기지에 보관할 화차 `lists`의 _행_이 색상별로 묶여 있어요.
하지만 보관 격자가 제대로 작동하려면 각 _행_에 서로 다른 세 가지 색상이 있어야 _열_이 색상별로 정렬돼요.
친구는 화차가 올바르게 보관되도록 차량기지 `lists`를 정리해 주기를 바라요.

세 개의 항목을 담은 `list`를 받는 `fix_wagon_depot()` 함수를 구현해요.
각 `list` 항목은 세 개의 `tuples`를 담은 하위 배열(또는 "행")이에요.
각 `tuple`은 `(<wagon ID>, <wagon color>)` 쌍이에요.

함수는 화차가 올바른 위치로 서로 바뀌도록 세 개의 "행" `lists`를 재정렬한 `list`를 반환해야 해요.

```python
>>> fix_wagon_depot([
                    [(2, "red"), (4, "red"), (8, "red")],
                    [(5, "blue"), (9, "blue"), (13,"blue")],
                    [(3, "orange"), (7, "orange"), (11, "orange")],
                    ])

[
[(2, "red"), (5, "blue"), (3, "orange")],
[(4, "red"), (9, "blue"), (7, "orange")],
[(8, "red"), (13,"blue"), (11, "orange")]
]
```
