# 힌트

## 1. 유용한 문자열 만들기

- [문자열][strings-and-characters]은 큰따옴표(`"`) 사이에 문자를 0개 이상 넣어 리터럴로 정의해요.

## 2. 유용한 문자 만들기

- [문자][strings-and-characters]는 큰따옴표(`"`) 사이에 문자를 정확히 하나 넣어 리터럴로 정의해요.
- 리터럴로 정의한 문자는 컴파일러가 문자열로 해석하지 않도록 `Character` 타입 애너테이션을 명시적으로 붙여야 해요.

## 3. 구절을 조합해 메시지 만들기

- [알맞은 문자열 연산자][string-docs]를 사용하면 문자열을 이어 붙일 수 있어요.
- 문자는 문자열과 이어 붙일 수 없어요. 먼저 문자열로 변환해야 해요.

## 4. 졸업 표지판 만들기

- [문자열 보간][string-interpolation]은 문자열에 넣고 싶은 값의 표현식을 역슬래시 문자가 앞에 오는 괄호 안에 넣어서 해요.

## 5. 표지판 비용 계산하기

- Swift에는 문자열의 문자 수를 반환하는 [문자열 속성][string-count-docs]이 있어요.
