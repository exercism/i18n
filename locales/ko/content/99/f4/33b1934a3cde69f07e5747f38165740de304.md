# 소개

리터럴은 코드에서 직접 사용하는 고정된 값이에요.
실행 중에 계산할 필요가 없어요.
각기 다른 종류의 데이터를 효율적으로 표현하기 위해 다양한 형태로 존재해요.
가장 자주 쓰이는 리터럴은 숫자 리터럴이지만, 날짜, 시간, 문자열 타입을 위한 리터럴 연산자도 있어요.
사용자 정의 리터럴 연산자를 어떻게 사용할 수 있는지는 이후 개념에서 다뤄요.

## 숫자 리터럴

숫자 리터럴에는 10진수, 8진수, 16진수, 2진수 표현이 있어요.
이런 기본 내용은 [숫자 개념][numbers-concept]에서 이미 다뤘어요.

`23`, `0x50f7ba11`, `0xba5eba11` 같은 모든 표현은 컴파일러가 `int`로 이해해요.
일반적인 `int` 타입은 부호가 있고([컴파일러와 시스템에 따라 다르지만][in-depth-integers]), 보통 `-2'147'483'648`부터 `2'147'483'647`까지의 범위를 가져요.
대부분의 경우 이 정도면 충분하고, 특정 타입을 걱정할 필요는 없어요.

어떤 사용 사례는 더 큰 범위나 아주 작은 프로그램 메모리 사용량을 요구해요.
이럴 때는 숫자 리터럴에 특정 정수 타입을 직접 지정해서 명시할 수 있어요.

음수가 필요 없지만 범위를 늘리고 싶을 때는 _부호 없는_ 정수를 위해 `u` 또는 `U` 접미사를 사용해요.
더 큰 범위가 필요하면 long과 long long 타입을 위해 `L` 또는 `LL`을 사용할 수 있어요.

~~~~exercism/caution
소문자 `l`의 사용도 허용되지만, 숫자 `1`과 혼동하기 쉬워서 권장하지 않아요.
~~~~

```cpp
auto net_worth_christian_grey{2'500'000'000U}; // out of range for 32-bit integers
auto net_worth_carlisle_cullen{46'000'000'000LL}; // int and uint are not enough
```

부동소수점 수는 보통 컴파일 중에 `double`로 결정돼요.
이건 좋은 기본값이고, 더 좁은 `float` 타입을 쓰는 경우는 위의 unsigned 예시보다 드물어요.

~~~~exercism/advanced
[C++23 표준][cpp23-literals]은 `f128`이나 `F16` 같은 리터럴로 더 세밀한 제어를 도입했어요.
일부 컴파일러는 자체 리터럴을 허용해요.
GCC는 `d`를 리터럴로 사용하는 것을 허용하지만, 이는 표준에 규정되어 있지 않고 플랫폼 간 호환성을 해칠 수 있어요.

[cpp23-literals]: https://en.cppreference.com/w/cpp/language/floating_literal

~~~~

```cpp
auto light_year_in_m{9.46073e+15f}; // well in the range of float
auto earth_to_edge_comoving_distance_in_nm{4.32355e+32}; // needs double type for magnitude
auto eulers_number{2.718281828459045}; // needs double type for precision
```

## 문자와 문자열 리터럴

다른 개념들에서는 이미 `'}'`나 `'@'`처럼 작은따옴표를 쓴 문자 리터럴을 사용했어요.

C++에서 `char`는 처음 128개의 [아스키 문자 코드][ascii-code]로 제한돼요.
`‰`처럼 확장 아스키 문자를 여러 개 쓰거나 `麗`, `ẞ` 같은 유니코드 문자를 쓰려면 다른 타입이 필요해요.
이전 개념에서는 문자열 리터럴을 _큰따옴표_로 소개했어요: `"一体どういう意味ですか。C++です"`.
이 일본어 문구의 실제 타입은 `const char (&)[46]`, 즉 C 스타일 문자열이에요.

문자열 리터럴의 사용은 기본적으로 활성화되지 않아요.
_string_ 리터럴 `""s`나 _string-view_ 리터럴 `""sv`를 사용하려면 관련 네임스페이스를 사용해서 지정해야 해요:

```cpp
#include <string>
#include <string_view>

using namespace std::literals;

auto green_light{"무궁화 꽃 이 피었 습니다"};
// green_light type is const char (&)[36]
auto umbrella{"달고나"s};
// umbrella type is std::basic_string<char>, the same as std::string
auto il_nam{"보는 것이 하는 것보다 더 재미있을 수가 없지"sv};
// il_nam type is std::basic_string_view<char>
```

_string_view_는 const 문자열에 대한 참조로 볼 수 있어요.

[ascii-code]: https://www.ascii-code.com/
