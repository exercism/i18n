# 지시사항

참고: 이 연습 문제는 `need-for-speed` 연습 문제의 이어지는 내용이에요.

이 연습 문제에서는 여러 종류의 원격 조종 자동차끼리 경주를 진행해요.
각 자동차는 저마다의 속도와 배터리 소모 특성을 가지고 있어요.

자동차는 완충된(100%) 배터리로 시작해요.
리모컨으로 자동차를 운전할 때마다 자동차는 자신의 속도만큼 미터 단위로 이동하고, 남은 배터리 비율은 배터리 소모량만큼 줄어들어요.

자동차의 배터리 잔량이 배터리 소모량보다 낮으면 더 이상 자동차를 운전할 수 없어요.

원격 조종 자동차에는 두 가지 정보를 보여 주는 멋진 LED 디스플레이가 있어요.

- 지금까지 주행한 총 거리, 표시 형식: `"Driven <METERS> meters"`.
- 남은 배터리 잔량, 표시 형식: `"Battery at <PERCENTAGE>%"`.

경주 트랙마다 고유한 거리가 있어요.
자동차는 배터리가 떨어지지 않고 트랙을 완주할 수 있는지 확인하는 방식으로 테스트해요.

## 1. 자동차 운전하기

자동차의 속도에 따라 주행한 미터 수를 갱신하고, 배터리 소모량에 따라 배터리를 줄이는 `Drive` 메서드를 `Car`에 구현하세요:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)
car.Drive()
// car is now Car{speed: 5, batteryDrain: 2, battery: 98, distance: 5}
```

참고: 자동차의 배터리가 0 미만이 되는 상황이라면 자동차를 운전하려고 하면 안 돼요.

## 2. 주행 거리 표시하기

LED 디스플레이에 표시되는 대로 거리를 `string`으로 반환하는 `DisplayDistance` 메서드를 `Car`에 구현하세요:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

fmt.Println(car.DisplayDistance())
// Output: "Driven 0 meters"
```

## 3. 배터리 잔량 표시하기

LED 디스플레이에 표시되는 대로 배터리 비율을 `string`으로 반환하는 `DisplayBattery` 메서드를 `Car`에 구현하세요:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

fmt.Println(car.DisplayBattery())
// Output: "Battery at 100%"
```

## 4. 원격 조종 자동차가 경주를 완주할 수 있는지 확인하기

경주를 완주하려면 자동차가 경주의 거리를 주행할 수 있어야 해요.
즉, 결승선을 통과하기 전에 배터리가 다 닳지 않아야 하죠.
`trackDistance int`를 매개변수로 받아 자동차가 경주를 완주할 수 있으면 `true`를, 그렇지 않으면 `false`를 반환하는 `CanFinish` 메서드를 구현하세요:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

trackDistance := 100

car.CanFinish(trackDistance)
// => true
```
