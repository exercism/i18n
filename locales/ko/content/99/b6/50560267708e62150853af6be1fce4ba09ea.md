# 설치

[공식 릴리스 페이지][official-releases]에서 사용 중인 플랫폼에 맞는 `full` 바이너리를 사용해 주세요.
현재 이 트랙은 Arturo 0.10.0 Arizona Bark 릴리스를 대상으로 해요.

~~~~exercism/caution
Homebrew는 macOS와 Linux 플랫폼에서 소프트웨어를 설치하는 인기 있는 서드파티 방식이에요.
하지만 Arturo용 Homebrew 레시피는 이 트랙과 호환되지 않는 `mini` 빌드를 대상으로 해요.
~~~~

Arturo 설치에 도움이 더 필요하면 [공식 Arturo Discord][discord]를 참고해 주세요.

## Arturo 코드 실행하기

이제 Arturo 코드를 작성할 준비가 된 거예요!
Arturo REPL을 사용하려면 명령줄에서 `arturo`를 실행해요.
Arturo 스크립트를 실행하려면 명령줄에서 `arturo <file>` 명령을 실행해요.

[official-releases]: https://arturo-lang.io/#download
[discord]: https://discord.gg/YdVK2CB
