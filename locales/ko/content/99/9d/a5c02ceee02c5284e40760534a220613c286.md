# 소개

JavaScript는 웹 페이지를 동적으로 만들어 주는 프로그래밍 언어예요. JavaScript는 컴파일이 필요 없는 언어예요. 우리가 작성한 코드를 컴퓨터가 알아듣도록 옮겨 주는 번역기 같은 프로그램을 인터프리터라고 해요. 인터프리터(예를 들어 웹 브라우저)가 코드를 해석해서 컴퓨터가 실행할 수 있는 코드로 바꿔 주죠. 덕분에 어떤 브라우저에서든, _어떤 컴퓨터에서든_ 실행되는 동적 웹사이트를 만들기에 딱 좋아요!

JavaScript는 브라우저에서만 쓰이는 게 아니에요. [Node.js][web-nodejs]나 [Deno][web-deno] 같은 JavaScript 런타임을 사용하면 웹 서버에서 요청을 작성하고, 실행하고, 처리할 수 있어요.
[Electron][web-electron] 같은 다른 프레임워크를 사용하면 Windows, Linux, macOS용 _크로스 플랫폼 애플리케이션_을 JavaScript로 작성할 수 있어요.
모바일 앱 개발도 가능해요. [React Native][web-react-native], [Ionic][web-ionic] 등 여러 도구를 활용하면 되고, 이제 [Expo][web-expo]를 쓰면 Android, iOS, 웹을 한 번에 대상으로 삼을 수 있죠.

ECMAScript는 JavaScript를 정의하는 [표준][web-ecma]이에요.

> "ECMAScript는 세계에서 가장 널리 사용되는 범용 프로그래밍 언어 중 하나로 성장했어요.
> 웹 브라우저에 내장된 언어로 가장 잘 알려져 있지만, 서버와 임베디드 애플리케이션에서도 폭넓게 채택되고 있죠."
> 출처: [ECMA International Language Specification][web-ecma-2019]

2015년 6판(흔히 ES2015 또는 ES6라고 불러요)을 시작으로, 이 표준은 매년 새 판이 발표돼요.
6판은 ES5에 비해 많은 개선을 가져온 중요한 업데이트였어요. 특히 템플릿 문자열, 표현력이 좋은 화살표 함수 문법, 더 깔끔해진 클래스 정의 문법 등이 눈에 띄죠.

하지만 새로운 문법과 기능이 _매년_ JavaScript에 추가되기 때문에, [최신 브라우저][web-compat-browsers]와 [최신 Node.js][web-compat-node]에서도 이런 변경 사항을 완벽하게 지원하지 못하는 경우가 많아요.
그렇다고 해서 사용할 수 없는 건 아니에요.
[Babel][web-babel] 같은 도구는 대부분의 기능에 대해 [트랜스파일][wiki-transpilation]을 제공해서, 마치 미래의 코드를 쓰는 것처럼 _작성_할 수 있게 해줘요.

**참고**: 이 트랙은 Babel과 [@babel/preset-env][web-babel-preset-env] 플러그인을 통해 최신 ECMAScript 문법을 지원해요. 이 플러그인이 업데이트될 때마다 새로운 실험적 기능이 활성화되며, 이는 명세가 발표되는 시점과 맞춰져요.
또한 _로컬 Node.js_ 설치 환경에 자동으로 맞춰져요.
덕분에 어떤 기능이 지원되고 지원되지 않는지 걱정할 필요가 없어요.
