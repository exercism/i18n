# 지침 추가

## 레지스터

| 레지스터 | 용도 | 타입 | 설명 |
| -------- | ------------ | ------- | ---------------------------- |
| `$a0`    | 입력        | 정수 | N, 삼각형 세 변의 길이의 합  |
| `$a1`    | 입력/출력 | 주소 | a 값                     |
| `$a2`    | 입력/출력 | 주소 | b 값                     |
| `$a3`    | 입력/출력 | 주소 | c 값                     |
| `$v0`    | 출력       | 정수 | 삼중항의 개수           |
| `$t0-9`  | 임시        | 임의     | 임시 저장용        |
