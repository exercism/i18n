# Kotlin 설치하기

Exercism CLI와 즐겨 쓰는 텍스트 편집기 외에도, Kotlin으로 Exercism 연습 문제를 풀려면 다음 두 가지가 필요해요.

* **Java Development Kit**(JDK). Kotlin은 Java 바이트코드로 컴파일돼요. 따라서 Java 런타임*과* 개발 도구(특히 Java 컴파일러)를 모두 포함하는 JDK를 설치해야 해요.
* 그리고 **Gradle**은 JVM 기반 프로젝트를 위한 빌드 도구로, Kotlin을 지원해요.

운영 체제를 선택해요:

* [Windows](#h-windows)
* [macOS](#h-macos)
* [Linux](#h-linux)

... 또는 ...
* 패키지 관리자를 사용하고 싶지 않다면 [직접 설치](#h-install-manually)할 수 있어요.

원한다면 [Java IDE](#h-java-ides)를 사용할 수도 있어요.

----

## Windows

관리자 권한 명령 프롬프트를 열어요. (관리자 권한 프롬프트를 여는 방법이 필요하면 [Windows 8 이상에서 관리자 권한 프롬프트 열기](http://www.howtogeek.com/194041/how-to-open-the-command-prompt-as-administrator-in-windows-8.1/)를 참고해요 (또는 [Windows 7](http://www.howtogeek.com/howto/windows-vista/run-a-command-as-administrator-from-the-windows-vista-run-box/)).

1. Chocolatey를 설치하지 않았다면 지금 설치해요:

      ```batchfile
        C:\Windows\system32> @powershell -NoProfile -ExecutionPolicy unrestricted -Command "iex ((new-object net.webclient).DownloadString('https://chocolatey.org/install.ps1'))" && SET PATH=%PATH%;%ALLUSERSPROFILE%\chocolatey\bin
      ```

2.  JDK를 설치해요:

       ```batchfile
        C:\Windows\system32> choco install openjdk11
        ...
        C:\Windows\system32> refreshenv
        ...
       ```

관리자 권한 명령 프롬프트를 닫고 새 명령 프롬프트를 여는 것을 권장해요. Exercism 연습 문제를 풀 때는 관리자 권한이 필요하지 않아요.

이제 Exercism의 Kotlin 트랙을 시작할 준비가 되었어요!

시작하려면 "[테스트 실행하기](https://exercism.org/docs/tracks/kotlin/tests)"를 참고해요.

## macOS

아래는 가장 일반적인 방법인 Homebrew를 사용한 설치 안내예요. 원한다면 [Homebrew 없이 macOS에 설치](#h-installing-on-macos-without-homebrew)할 수도 있어요.

### 설치하기

1. 아직 [Homebrew](http://brew.sh)를 설치하지 않았다면 지금 설치해요:

      ```sh
        $ /usr/bin/ruby -e "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/master/install)"
      ```

2. [Homebrew Cask](https://caskroom.github.io/)를 tap해요. 그러면 JDK 같은 미리 빌드된 바이너리를 설치할 수 있어요.

      ```
        $ brew tap adoptopenjdk/openjdk
      ```

3.  JDK를 설치해요:

       ```
        $ brew install --cask adoptopenjdk11
       ```

이제 Exercism의 Kotlin 트랙을 시작할 준비가 되었어요!

시작하려면 "[테스트 실행하기](https://exercism.org/docs/tracks/kotlin/tests)"를 참고해요.

## Linux

아래는 사용하는 배포판의 패키지 관리자를 이용한 설치 안내예요. 원한다면 [패키지 관리자 없이 Linux에 설치](#h-installing-on-linux-without-a-package-manager)할 수도 있어요.

* [Debian](#h-debian)
* [기타 Linux 배포판](#h-other-linux-distributions)

### Debian

Debian이나 그 파생 배포판(Ubuntu, Linux Mint 등)을 사용한다면 APT를 사용해요:

*(검증된 환경: Ubuntu 14, 16, 18)*

1. JDK를 설치해요:

      ```sh
        $ sudo apt-get update
        $ sudo apt-get install software-properties-common
        $ sudo add-apt-repository ppa:openjdk-r/ppa
        $ sudo apt-get update
        $ sudo apt-get install openjdk-11-jdk
      ```


이제 Exercism의 Kotlin 트랙을 시작할 준비가 되었어요!

시작하려면 "[테스트 실행하기](https://exercism.org/docs/tracks/kotlin/tests)"를 참고해요.

----

### 기타 Linux 배포판

JDK 11을 설치하는 방법은 많지만, 가장 쉬운 방법 중 하나는 SDKMAN을 사용하는 거예요. SDKMAN을 쓰면 OpenJDK 11을 손쉽게 설치할 수 있어요. 다음 단계를 따라 해요:

1. SDKMAN을 설치해요:
    ```sh
    $ curl -s "https://get.sdkman.io" | bash
    ``` 
    (이 방법이 통하지 않으면 https://sdkman.io/install 에 있는 안내를 참고해요 )
1. openjdk11을 설치해요:
    ```
    $ sdk install java 11.0.2-open
    ```

시작하려면 "[테스트 실행하기](https://exercism.org/docs/tracks/kotlin/tests)"를 참고해요.

## Java IDE

사용할 수 있는 Java IDE는 아주 많아요. 가장 인기 있는 세 가지는 다음과 같아요:

* [IntelliJ IDEA](https://www.jetbrains.com/idea/download/) ("Community" 에디션을 내려받아요)
  - Kotlin을 만든 사람들이 만든 IDE라서 Kotlin을 가장 잘 지원해요.
- [Eclipse](https://www.eclipse.org/downloads/)
- [NetBeans](https://netbeans.org/downloads/) ("Java SE" 번들을 내려받아요)

그리고 [다른 IDE](https://en.wikibooks.org/wiki/Java_Programming/Java_IDEs)도 있어요.
