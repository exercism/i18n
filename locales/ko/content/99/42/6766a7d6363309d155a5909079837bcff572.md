# 지침 추가

## 팁

*반환 타입*이 있는 함수는 해당 *타입*의 데이터와 `null`만 반환할 수 있어요.
하지만 함수를 호출한 쪽은 하나의 데이터 타입만 기대하고 있어요.

예:
```dart
String hello(int a){
    if ( a == 0){
        return "a";
    } else {
        return null;
    }
}
```
이 함수가 `null`이나 그 밖의 다른 데이터 타입도 반환할 수 있다는 점을 더 분명히 하려면 `dynamic`을 사용해요.
```dart
dynamic hello(int a){
    if ( a == 0){
        return "a";
    } else {
        return null;
    }
}
