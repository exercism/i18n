# 연습 문제를 로컬에서 풀기

내 컴퓨터에서 연습 문제를 풀면 익숙한 환경에서 모든 코딩을 할 수 있어요.

## CLI 설치하기

내 컴퓨터에서 연습 문제를 풀려면 먼저 [다음 안내](https://exercism.org/cli-walkthrough)에 따라 Exercism CLI(명령줄 인터페이스)를 설치하고 설정해야 해요.

### 설정

CLI가 파일을 제대로 내려받을 수 있도록 사용자 정보를 알려줘야 해요.
토큰은 [설정 페이지](/settings/api_cli)에서 확인할 수 있어요.
그다음 아래 명령으로 CLI를 설정할 수 있어요. `<your-api-token>` 자리에는 설정 페이지에 있는 값을 넣어 주세요:

```
exercism configure --token=<your-api-token>
```

## 연습 문제 내려받기

설치를 마치면 아래 명령으로 CLI를 사용해 연습 문제를 내 컴퓨터로 내려받을 수 있어요. `<exercise-slug>`와 `<track-slug>` 자리에는 알맞은 값을 넣어 주세요:

```
exercism download --exercise=<exercise-slug> --track=<track-slug>
```

연습 문제 페이지에 해당 문제에 맞는 명령이 나와 있으니, 이 명령 구조를 외울 필요는 없어요.

다운로드 명령이 끝나면 연습 문제 파일이 내 컴퓨터에 내려받아져요.

## 연습 문제 풀기

모든 연습 문제의 목표는 모든 테스트를 통과하는 구현을 만드는 것이에요.
이렇게 만든 구현을 _풀이_라고 해요.

이를 돕기 위해 각 연습 문제에는 다음과 같은 파일이 들어 있어요:

- README.md: 무엇을 해야 하는지 설명하는 안내문
- HELP.md: 테스트를 실행하는 방법과 막혔을 때 도움을 받는 방법에 대한 정보
- HINTS.md (선택 사항): 문제를 푸는 데 도움이 되는 힌트
- 테스트 파일: 풀이가 올바른지 검증하는 테스트가 들어 있어요
- 스텁 파일: 구현을 시작할 수 있도록 출발점을 제공해요

트랙에 따라 테스트를 실행하는 데 트랙 도구가 필요로 하는 다른 파일이 있을 수도 있어요.

## 풀이 제출하기

풀이가 모든 테스트를 통과하면 아래 명령으로 풀이를 제출할 수 있어요:

```
exercism submit <implementation_file_paths>
```

이 명령은 풀이를 Exercism 웹사이트에 업로드하고 풀이 페이지의 URL을 출력해요.

다시 말하지만, 연습 문제의 `HELP.md` 파일에 올바른 명령이 나와 있으니 이 명령을 외울 필요는 없어요.

완성되지 않은 풀이도 제출할 수 있는데, 그러면 다음과 같은 일을 할 수 있어요:

- 다른 사람이 이 문제를 어떻게 풀었는지 볼 수 있어요
- 멘토에게 도움을 요청할 수 있어요

## 그 밖의 CLI 기능

### 모든 명령어 보기

사용할 수 있는 모든 명령어 목록을 보려면 help 하위 명령을 실행해요.

```bash
exercism help
```

### 문제 해결

최신 버전을 사용하고 있는지 확인해요.

현재 어떤 버전을 사용 중인지 확인해요:

```bash
exercism version
```

최신 릴리스와 비교해 보고, 사용 중인 버전이 가장 최신이 아니라면 업그레이드해요.

업그레이드한 뒤에는 버전을 다시 확인해요. 버전이 바뀌지 않았다면 업그레이드된 바이너리를 실행하고 있는지 확인해요.

```bash
which exercism
```

그래도 문제가 해결되지 않으면 `troubleshoot` 명령의 출력과 함께 GitHub의 exercism/cli에 이슈를 열어 주세요.

```bash
exercism troubleshoot
```

[이슈 트래커](https://github.com/exercism/exercism/issues)에서 이슈를 열 수 있고, 커뮤니티가 도와드리려고 노력할 거예요. **이슈를 열기 전에 [대화형 안내](https://exercism.org/cli-walkthrough)를 먼저 끝내 주세요.**
