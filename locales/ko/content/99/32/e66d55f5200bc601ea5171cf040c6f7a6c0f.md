# 소개

`Promise` 클래스가 등장하기 전에는 비동기 코드를 다루는 방법이 하나뿐이었어요. 바로 _콜백 패턴_이에요.

콜백은 다른 함수에 인자로 전달되고, 그 함수에서 어떤 작업이 끝나면 호출되는 함수예요. 이런 콜백 함수에서는 첫 번째 매개변수로 오류를 받는 방식이 흔해요 (아래 예제를 봐요).

```javascript
function callback(error, arg2, arg3) {}
```

이게 비동기 코드와 어떻게 관련이 있을까요?

예전부터 콜백은 비동기 작업이 끝난 뒤 프로그램 전체를 막지 않고 어떤 작업을 할 수 있도록 하기 위해 사용됐어요.

```javascript
fetchProduct(productId, function (error, data) {
  if (error) {
    // Handle the error
  } else {
    // Do some work
  }
});
```

위 예제에서 `fetchProduct` 함수는 비동기 함수인데, 두 번째 인자로 콜백을 받아요. 이 콜백은 상품 데이터를 가져온 뒤 무엇을 할지 결정해요.
