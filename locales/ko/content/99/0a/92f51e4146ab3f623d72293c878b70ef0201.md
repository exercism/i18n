# 문자열 보간 사용하기

[comment]: # (이 경고는 풀이에서 문자열 보간을 사용하지 않았을 때 표시돼요)

출력 문자열에 `name` 매개변수를 넣을 때는 [문자열 보간](https://github.com/elixir-lang/elixir/blob/9cac52833e91b5ebac0d322b20e39605d8dafad9/lib/elixir/lib/string.ex#L20)을 사용해요.

- 가능하면 Exercism Elixir 트랙에서는 가독성을 위해 문자열 연결보다 문자열 보간을 사용하는 것을 권장해요.

```elixir
def hello(what) do
  "Hello, #{what}"
end
```

- 문자열 보간 구문에는 [모든 Elixir 표현식](https://github.com/elixir-lang/elixir/blob/9cac52833e91b5ebac0d322b20e39605d8dafad9/lib/elixir/lib/string.ex#L30)을 넣을 수 있어요.

```elixir
def pluralize_apple(n) when n >= 1 do
  "apple#{if n > 1, do: "s"}"
end
```
