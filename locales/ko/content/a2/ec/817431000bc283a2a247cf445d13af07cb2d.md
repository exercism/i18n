# 개요

PowerShell은 Microsoft에서 만든 동적이고 암시적으로 형식이 지정되는 (_동시에 [강력한 형식의][strong typed] 변수도 지원하는_) 스크립팅 언어로, 주로 작업 자동화와 구성 관리에 초점을 맞춰요.

PowerShell은 명령형, 함수형, 객체 지향, 심지어 파이프라인 스타일 프로그래밍까지 지원해요.

PowerShell은 .NET 플랫폼 위에서 만들어졌고 2006년에 처음 출시됐어요.
모든 최신 Windows OS에 기본으로 포함되어 있으며, Mac과 Linux에도 설치할 수 있어요.


## 변수

PowerShell에서 변수를 정의하는 방법은 크게 두 가지가 있어요.

PowerShell의 변수 이름은 `$`로 시작해야 하고, 대입 연산자 `=`를 사용해서 변수 이름에 값을 연결해요.

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

값이 특정 형식이기를 강제하고 싶다면 변수의 형식을 명시적으로 지정할 수도 있어요.
PowerShell은 가능하다면 값을 한 형식에서 다른 형식으로 최선을 다해 변환하려고 해요.

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```

### 상수

PowerShell의 상수는 정의한 뒤에 **변경**할 수도, **제거**할 수도 없는 변수예요.
그래서 변수를 정의하는 두 번째 방법이 등장해요. 바로 `New-Variable` cmdlet을 사용하는 거예요.

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
100
```


## 함수

PowerShell에서 함수는 `function` 키워드로 정의해요.
각 함수는 `()` 괄호 안에 0개 이상의 매개변수를 가질 수 있고, 그 뒤에 `{`로 시작해서 `}`로 끝나는 함수 범위가 이어져요.

```powershell
function Greeting {
    return "Hello!"
}
```

PowerShell의 함수는 `FuncName $Arg` 문법으로 호출한 다음에 `return` 키워드로 값을 명시적으로 반환할 수 있어요.

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

## 주석

PowerShell에서 한 줄 주석은 `#` 기호로 시작하고 그 줄이 끝나면 끝나요.
주석 블록은 `<#` 기호로 시작하고 `#>` 기호로 끝나요.

```powershell
function Main() {
    #This is a comment
    <#
    And this is a comment block
    that can span multiple lines
    #>
}
```
