# 소개

튜플은 임의의 타입의 데이터를 고정된 개수로 묶는 가벼운 방법이에요.
튜플에는 특별한 이름이 없어요. 데이터 구조에 이름을 붙이면 그건 `struct`가 돼요.
튜플의 필드에는 이름이 없어요. 필드는 구조 분해를 하거나 위치를 통해 접근해요.

## 생성

튜플은 항상 튜플 표현식으로 만들어요:

```rust
// pointless but legal
let unit = ();
// single element
let single_element = ("note the comma",);
// two element
let two_element = (123, "elements can be of differing types");
```

튜플은 임의의 개수의 원소를 가질 수 있어요.

## 구조 분해로 접근하기

구조 분해로 튜플의 원소에 접근할 수 있어요.
이것은 튜플의 각 원소에 변수 이름을 붙이는 것을 뜻하며, 그 과정에서 튜플은 소비돼요.

```rust
let (elem1, _elem2) = two_element;
assert_eq!(elem1, 123);
```
