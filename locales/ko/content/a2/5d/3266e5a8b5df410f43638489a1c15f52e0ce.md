# 테스트

연습 문제마다 테스트 파일이 하나씩 들어 있어요.
`bats` 프로그램으로 테스트를 실행해요.
```bash
bats test-hello-world.bats
```

`bats`를 설치해야 해요.
시스템에 맞게 `bats`를 설치하는 방법은 [Bash 트랙의 테스트][bash] 페이지를 참고하세요.

### bats는 bash로 구현되어 있어요

bats 파일은 bash 스크립트예요. `bats` 명령이 인식하는 몇 가지 특별한 함수가 들어 있죠.
이런 테스트도 볼 수 있어요.
```sh
gawk -f some-exercise.awk <<< "some,input,here"
```
`<<<` 문법은 bash의 [Here String][here-string]이에요.
오른쪽의 문자열을 왼쪽 프로그램의 표준 입력으로 보내줘요.
다음 코드와 ([거의][so]) 같아요.
```sh
echo "some,input,here" | gawk -f some-exercise.awk
```

## assert 함수 도움말

테스트는 [bats-assert][bats-assert] 라이브러리의 함수를 사용해요.
여러 `assert*` 함수에 대한 도움말은 그곳에서 찾을 수 있어요.

## 건너뛴 테스트

연습 문제를 푼다는 건 그 문제의 모든 테스트를 통과시킨다는 뜻이에요.
기본적으로 테스트를 실행하면 첫 번째 테스트 하나만 실행돼요.
이건 의도된 동작이에요. 그 테스트 하나를 통과시키는 데만 집중할 수 있거든요.
테스트가 통과하면, 다른 테스트 앞에 붙어 있는

    [[ $BATS_RUN_SKIPPED == true ]] || skip

주석을 주석 처리하거나 지워서 다음 테스트를 활성화할 수 있어요.

## 건너뛰기 무시하기

`skip` 주석이 붙은 테스트를 포함해 모든 테스트를 실행하려면 다음 명령을 실행해요.
```bash
BATS_RUN_SKIPPED=true bats test-some-exercise.bats
```

타이핑을 줄이려면 래퍼 함수를 쓰는 게 편할 수 있어요. `bash`에서는 이렇게 하면 돼요.
```bash
bats() {
    BATS_RUN_SKIPPED=true command bats *.bats
}
```
그러면 이렇게만 입력해서 테스트를 실행할 수 있어요.
```bash
bats
```

## 디버깅 출력

```exercism/caution
이 방법은 로컬에서 `bats`로는 동작하지만, Exercism 온라인 에디터에서는 **동작하지 않아요**.
```

테스트를 실행하면 `bats`는 예상 출력과 비교하기 위해 stdout과 stderr를 모두 캡처해요.
디버그 메시지를 stdout이나 stderr로 출력하면, 그 내용이 캡처된 출력에 포함되어 테스트가 실패할 수 있어요.

테스트 결과에 영향을 주지 않으면서 디버그 정보를 출력하려고, `bats`는 이를 위한 파일 디스크립터 **3**을 제공해요.
`/dev/fd/3` 파일로 출력한 내용은 테스트 실행 중에 표시되지만, 검증에 사용되는 캡처 출력에는 포함되지 않아요.

예시:

```awk
BEGIN {
    # This debug message will not interfere with test output comparison
    print "a debug message" > "/dev/fd/3"

    # Normal program output (this is what your tests will see and compare)
    print "Hello, World!"
}
```

실행 예시:

```none
$ bats test-hello-world.bats
test-hello-world.bats
 ✓ Say Hi!
a debug message

1 test, 0 failures
```

이렇게 하면 테스트에 영향을 주지 않으면서 도움이 되는 디버그 출력을 볼 수 있어요.

코드 여러 곳에서 쓸 때는 세부 내용을 함수로 숨기면 가독성이 좋아질 수 있어요.

```awk
BEGIN {
    debug("starting ...")
}

# do stuff here ...

END {
    debug("... finished")
}

function debug(msg) {print msg > "/dev/fd/3"}
```
