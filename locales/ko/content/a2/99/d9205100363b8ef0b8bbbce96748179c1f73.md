# 테스트

연습 문제 디렉터리에서 다음 명령을 실행하면 테스트를 실행할 수 있어요:

```bash
dub test
```

## 테스트 통과하기

[테스트 주도 개발의 세 가지 규칙](http://butunclebob.com/ArticleS.UncleBob.TheThreeRulesOfTdd)을 따라 첫 번째 테스트가 컴파일되고 링크되고 통과하도록 만들어 봐요. 컴파일 오류를 해결하고 테스트가 실패하도록 만들 만큼만 네임스페이스, 함수, 클래스 등을 선언해 구조를 만들어요. 그다음에는 테스트가 통과할 만큼만 코드를 작성해요. 이렇게 했다면, 다음 줄을 다음 테스트 뒤로 옮겨 다음 테스트의 주석을 해제해요.

```D
static if (all_tests_enabled)
```

이때 아직 선언하거나 정의하지 않은 새로운 구문이 사용되어 컴파일 오류가 발생할 수 있어요. 이 경우에도 테스트가 실패하게 만들 만큼만 컴파일 오류를 최소한으로 고치고, 테스트를 통과할 만큼만 코드를 최소한으로 바꾼 다음, 가독성과 표현력을 위해 구현을 리팩터링하고 다음 테스트로 넘어가요.

직접 저수준 알고리즘이나 기능을 손으로 작성하기보다는 D의 표준 기능을 사용해 봐요.
