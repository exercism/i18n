# 소개

[Pony](http://www.ponylang.org)는 실제로 일을 해내는 데 초점을 맞춘, 객체 지향이고 액터 모델이며 능력 보안을 갖춘 프로그래밍 언어예요.

Pony가 객체 지향인 이유는 Python, Java, C++을 비롯한 여러 언어처럼 클래스와 객체를 가지고 있기 때문이에요. 액터 모델인 이유는 액터를 가지고 있기 때문이에요(Erlang이나 Akka와 비슷해요). 액터는 객체처럼 동작하지만, 코드를 비동기적으로 실행할 수도 있어요. 액터 덕분에 Pony가 멋져요.
Pony가 능력 보안을 갖췄다고 말할 때는 몇 가지를 뜻해요:

- 타입 안전해요. 정말로 타입 안전해요. 수학적 증명까지 있어요.
- 메모리 안전해요. 네, 이건 타입 안전에서 따라오는 것이긴 하지만 그래도 흥미로워요. 댕글링 포인터도 없고, 버퍼 오버런도 없어요. 심지어 이 언어에는 `null`이라는 개념조차 없어요!
- 예외 안전해요. 런타임 예외가 없어요. 모든 예외는 정의된 의미를 가지고 있고, 언제나 처리돼요.
- 데이터 레이스가 없어요. Pony에는 잠금이나 원자적 연산 같은 것이 전혀 없어요. 대신 타입 시스템이 컴파일 시점에 여러분의 동시성 프로그램에 데이터 레이스가 절대 생기지 않도록 보장해요. 그래서 동시성이 아주 높은 코드를 작성해도 절대 틀릴 일이 없어요.
- 교착 상태가 없어요. 이건 쉬워요. Pony에는 잠금이 아예 없으니까요! 그러니 잠금이 교착 상태를 일으킬 수 없어요. 애초에 존재하지 않으니까요.

처음 시작하는 분들은 [튜토리얼](https://tutorial.ponylang.org/)부터 보면 좋아요.
