# Nil

Crystal에는 [`Nil`][nil]이라는 타입이 있는데, 이 타입이 가질 수 있는 값은 `nil` 하나뿐이에요.
값이 없음을 나타낼 때 사용하며, 다른 언어의 `null`이나 `None`과 비슷해요.

`nil` 값은 여러 메서드에서 반환될 수 있는데, 예를 들어 [`String#[]?`][string-index]는 인덱스가 범위를 벗어나면 `nil`을 반환해요.

```crystal
"foo"[10]? # => nil
```

Crystal에는 **널 참조 검사**라는 것이 있는데, 이는 모든 타입이 기본적으로 nil이 될 수 없다는 뜻이에요.
즉, 변수를 명시적으로 `Nil` 타입으로 선언하지 않는 한 그 변수에 `nil`을 할당할 수 없어요.
그 결과 컴파일러가 널 참조를 자동으로 검사해 줘요.

## 거짓 같은 값

`nil` 값을 다루는 방법에는 여러 가지가 있어요.
`nil`은 `false`와 마찬가지로 [거짓 같은 값][truthy-falsey]이에요.
즉, 거짓 같은 값이나 참 같은 값이 필요한 문을 비롯한 여러 위치에서 `nil`은 `false`와 똑같이 취급돼요.

```crystal
if nil
  puts "nil is truthy"
else
  puts "nil is falsey"
end

# => nil is falsey
```

따라서 nil이 될 수 있는 변수의 값이 `nil`이면 참인 분기는 실행되지 않아요.

```crystal
foo = "boo"[2]? # It is possible that foo is nil
if foo
  p foo.class # => Char
end
```

## nil인지 확인하기

Crystal에는 값이 `nil`인지 확인할 수 있는 메서드가 있어요.
[`nil?`][nil?]라고 하며, 모든 객체에서 사용할 수 있어요.

```crystal
foo = "boo"[2]?
if foo.nil?
  puts "foo is nil"
else
  puts "foo is not nil"
end
```

값을 그냥 `if`문에 사용할 때와는 조금 달라요. 앞의 예시에서는 `false`와 `nil`이 모두 거짓으로 취급되지만, 여기서는 `nil`만 거짓으로 취급해요. 값이 `false`였다면 `nil`이 아니었을 테고, 따라서 참이었을 테니까요.

## or 연산자

`nil` 값을 다루는 가장 쉬운 방법은 애초에 값이 `nil`이 되지 않도록 하는 거예요.
or 연산자([`||`][or])는 `Bools`를 다룰 때 자주 사용하지만, 제대로 이해하면 `nil` 값을 다루는 데에도 사용할 수 있어요.
or 연산자는 첫 번째 값이 참인지 확인하고, 그렇지 않으면 두 번째 값을 사용해요.
이를 이용하면 값이 `nil`일 때 거짓으로 취급되어 두 번째 값이 사용되도록 만들 수 있어요.

```crystal
"foo"[10]? || "bar" # => "bar"
```

## not_nil!

~~~~exercism/caution 
이 방법은 최후의 수단으로 여겨야 하며, 값이 `nil`이 아니라고 **확신할** 때만 사용해야 해요.
가능하면 다른 방법을 사용해요.
~~~~

[`not_nil!`][not_nil]은 값이 nil이 아니라고 컴파일러에게 알려 주는 메서드로, 이를 통해 그 값의 타입이 nil이 될 수 없게 만들어요.
값이 nil이면 예외를 발생시켜서 그렇게 해요.

```crystal
foo = "foo"[4]?
foo.not_nil!
# => Error: Nil assertion failed (NilAssertionError)
```
