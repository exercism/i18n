# 지침

이번 연습 문제에서는 그동안 돈을 모아서 드디어 장만한 무선 조종 자동차를 가지고 놀아볼 거예요.

자동차는 배터리가 가득 찬(100%) 상태로 시작해요.
리모컨으로 자동차를 운전할 때마다 20미터를 이동하고 배터리를 1퍼센트 소모해요.
자동차의 별명은 자동차가 만들어지기 전까지는 알 수 없어요.

무선 조종 자동차에는 두 가지 정보를 보여주는 멋진 LED 디스플레이가 있어요:

- 지금까지 이동한 총 거리, 표시 형식: `"<METERS> meters"`.
- 남은 배터리 잔량, 표시 형식: `"Battery at <PERCENTAGE>%"`.

배터리가 0%가 되면 자동차를 더 이상 운전할 수 없고, 배터리 표시에는 `"Battery empty"`가 나타나요.

## 1. 새 무선 조종 자동차 만들기

`new_remote_control_car/0` 함수를 구현해서 새 무선 조종 자동차 객체를 반환해요:

```jq
new_remote_control_car
# => {
#      "battery_percentage": 100,
#      "distance_driven_in_meters": 0,
#      "nickname": null
#    }
```

## 2. 별명이 있는 새 무선 조종 자동차 만들기

`new_remote_control_car/1` 함수를 구현해서 별명을 받은 새 무선 조종 자동차 객체를 반환해요:

```jq
new_remote_control_car("Blue")
# => {
#      "battery_percentage": 100,
#      "distance_driven_in_meters": 0,
#      "nickname": "Blue"
#    }
```

## 3. 거리 표시하기

자동차 객체를 입력으로 받아 LED 디스플레이에 표시되는 거리 문자열을 출력하는 `display_distance/0` 함수를 구현해요:

```jq
new_remote_control_car | display_distance
# => "0 meters"
```

## 4. 배터리 잔량 표시하기

자동차 객체를 입력으로 받아 LED 디스플레이에 표시되는 배터리 잔량 문자열을 출력하는 `display_battery/0` 함수를 구현해요:

```jq
new_remote_control_car | display_battery
# => "Battery at 100%"
```

배터리가 0%가 되면 배터리 표시에는 "Battery empty"가 나타나요.

## 5. 운전하면 배터리와 이동 거리가 바뀌어요

`drive/0` 함수를 구현해요. 이 함수는:

- 자동차 객체를 입력으로 받아요
- 이동한 거리를 20미터 늘려요
- 배터리를 1% 소모해요
- 수정된 자동차 객체를 출력해요

```jq
new_remote_control_car("Red") | drive
# => {
#      "battery_percentage": 99,
#      "distance_driven_in_meters": 20,
#      "nickname": "Red"
#    }
```

## 6. 방전된 배터리로 운전하는 경우 처리하기

배터리가 방전된(0%) 경우에는 이동 거리도 늘리지 않고 배터리 잔량도 줄이지 않도록 `drive/0` 함수를 수정해요:

```jq
{
  battery_percentage: 0,
  distance_driven_in_meters: 2000,
  nickname: "Red"
} | drive
# => {
#      "battery_percentage": 0,
#      "distance_driven_in_meters": 2000,
#      "nickname": "Red"
#    }
```
