# 소개

## Result

`Result` 타입은 Elm 언어에서 오류를 보고하기 위한 해법이자, 오류에서 복구할 수 있게 해 주는 도구예요. `Maybe` 타입과 어느 정도 비슷하지만, 실패할 수 있는 함수가 `Maybe`를 반환하더라도 왜 실패했는지는 전혀 알려주지 않아요. `Result`는 왜 실패했는지에 대한 그런 맥락을 함께 담고 있어요.

`Result` 타입은 다음과 같이 정의돼요:

```elm
type Result error value
  = Ok value
  | Err error
```

이런 것을 Elm 용어로 "사용자 정의 타입" 정의라고 해요.
`OK value`와 `Error error`에서 `error`와 `value`는 타입 변수를 나타내요. 타입 변수는 `Int`, `Bool`, `String`처럼 어떤 타입이든 될 수 있다는 뜻이에요.
따라서 `Result String Int`는 `Int`를 담을 것으로 기대되는 값이고, 오류가 있으면 그 오류는 `String`으로 표현돼요.
`Result`를 다룰 때 유용한 도우미 함수가 많이 들어 있는 [Result 모듈](https://package.elm-lang.org/packages/elm/core/latest/Result)도 있어요.
