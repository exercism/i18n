# 지시 사항

이번 연습 문제에서는 간단한 정수 계산기의 오류 처리를 만들어 봐요.
간단하게 진행할 수 있도록 덧셈, 곱셈, 나눗셈을 계산하는 메서드가 미리 준비되어 있어요.

목표는 제대로 동작하는 계산기를 만드는 거예요. 이 계산기는 인자로 `16`, `51`, `+`를 받으면 `16 + 51 = 67`처럼 문자열을 반환해요.

```java
CalculatorConundrum calculator = new CalculatorConundrum();

calculator.calculate(16, 51, "+");
// => returns "16 + 51 = 67"

calculator.calculate(32, 6, "*");
// => returns "32 * 6 = 192"

calculator.calculate(512, 4, "/");
// => returns "512 / 4 = 128"
```

## 1. 몇 가지 기본 연산을 지원하도록 calculate 메서드 구현하기

이번 작업에서 구현할 핵심 메서드는 `CalculatorConundrum.calculate()` 메서드예요.
이 메서드는 인자 세 개를 받아요.
처음 두 인자 `operand1`, `operand2`는 연산을 적용할 정수예요.
세 번째 인자 `operation`은 문자열 타입이고, 이번 연습 문제에서는 다음 연산들을 구현해야 해요:

- `+` 문자열을 이용한 덧셈
- `*` 문자열을 이용한 곱셈
- `/` 문자열을 이용한 나눗셈

## 2. 잘못된 연산 처리하기

`CalculatorConundrum.calculate()` 메서드를 수정해서 잘못된 연산을 처리해요:

- `operation` 인자가 `null`이면 `Operation cannot be null`이라는 메시지와 함께 `IllegalArgumentException`을 던져야 해요.
- `operation` 인자가 `""`이면 `Operation cannot be empty`이라는 메시지와 함께 `IllegalArgumentException`을 던져야 해요.
- `operation` 인자가 `+`, `*`, `/` 이외의 연산이면 `Operation '{operation}' does not exist`이라는 메시지와 함께 `IllegalOperationException`을 던져야 해요.

```java
calculator.calculate(10, 1, null);
// => throws IllegalArgumentException with message "Operation cannot be null"

calculator.calculate(10, 1, "");
// => throws IllegalArgumentException with message "Operation cannot be empty"

calculator.calculate(10, 1, "-");
// => throws IllegalOperationException with message "Operation '-' does not exist"
```

## 3. 0으로 나눌 때 발생하는 예외 처리하기

Java에서는 0으로 나누려고 하면 `ArithmeticException`이 발생해요.
`CalculatorConundrum.calculate()` 메서드를 수정해서 이 예외를 잡은 뒤, `Division by zero is not allowed`이라는 메시지와 잡은 `ArithmeticException`을 원인으로 하는 `IllegalOperationException`을 던져요.

```java
calculator.calculate(512, 0, "/");
// => throws IllegalOperationException with message "Division by zero is not allowed"
```
