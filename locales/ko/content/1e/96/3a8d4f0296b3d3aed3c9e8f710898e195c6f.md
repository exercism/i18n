# 지시 사항

이 연습 문제에서는 좋아하는 요리책을 보고 근사한 라자냐를 만들 수 있도록 코드를 작성해요.

라자냐를 만드는 데 걸리는 시간과 관련된 세 가지 과제가 있어요.

## 1. 오븐에 둘 예상 시간을 분 단위로 정의해요

라자냐를 오븐에 몇 분 동안 넣어둬야 하는지 확인할 수 있도록 `expectedMinutesInOven` 상수를 정의해요. 요리책에 따르면 오븐에 넣어둘 예상 시간은 40분이에요:

```Haskell
expectedMinutesInOven
    --> 40
```

## 2. 준비 시간을 분 단위로 계산해요

라자냐에 추가한 층 수를 매개변수로 받아서, 라자냐를 준비하는 데 몇 분이 걸렸는지 반환하는 `preparationTimeInMinutes` 함수를 정의해요. 각 층을 준비하는 데 2분이 걸린다고 가정해요.

```Haskell
preparationTimeInMinutes 3
    --> 6
```

## 3. 경과 시간을 분 단위로 계산해요

`elapsedTimeInMinutes` 함수는 두 개의 매개변수를 받아요. 첫 번째 매개변수는 라자냐에 추가한 층 수이고, 두 번째 매개변수는 라자냐가 오븐에 있던 시간(분)이에요. 이 함수는 라자냐 요리에 얼마나 많은 시간을 들였는지 반환해야 하는데, 이는 준비 시간(분)과 그 시점까지 라자냐가 오븐에 있던 시간(분)을 더한 값이에요.

```Haskell
elapsedTimeInMinutes 3 20
    --> 26
```
