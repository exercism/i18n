# 지침 추가

## 레지스터

| 레지스터 | 용도      | 타입    | 설명                          |
| -------- | --------- | ------- | ----------------------------- |
| `$a0`    | 입력      | 주소    | null로 끝나는 입력 문자열     |
| `$a1`    | 입출력    | 주소    | null로 끝나는 출력 문자열     |
| `$t0-9`  | 임시      | 임의    | 임시 저장에 사용              |
