# 지침

Isaac's Asteroid Exploration Co.의 소유권 등록 부서에서 토지 등록 시스템의 성능을 개선해 달라는 요청을 받았어요.

소행성을 개발할 수 있게 될 때마다 투기꾼들은 땅 한 구획에 대한 소유권을 주장할 수 있게 초대돼요.
소행성의 토지는 서로 겹치지 않는 직사각형 구획으로 나뉘어 있어요.
구획마다 크기는 다르지만, 모든 변은 좌표축과 평행해요.
투기꾼들은 좌표를 지정해서 구획 중 하나에 대한 소유권을 주장해요.

목표는 과거에 웹사이트를 마비시켰던 토지 쟁탈전을 처리할 수 있는 성능 좋은 시스템을 만드는 거예요.

측정 단위는 100미터이지만, 이 과제들에서는 무시해도 돼요.

## 1. Point 정의하기

`x`와 `y` 좌표를 담을 `struct`를 정의해요.
이 값들은 그리 크지 않은 음이 아닌 정수이므로 `UInt16` 타입을 사용해요.

```julia-repl
julia> Coord(7, 3)
Coord(0x0007, 0x0003)  # unsigned integers display in hex format by default
```

## 2. Plot 정의하기

모든 구획은 가로변과 세로변을 가진 직사각형이어야 하므로, 서로 마주 보는 두 모서리만 있으면 구획을 정의할 수 있어요.

생성자에서 Coord 구조체 두 개를 받는 `Plot` 구조체를 구현해요.

`Plot`은 `bottom_left`와 `top_right` 필드를 가진 키워드 구조체여야 해요.

```julia-repl
julia> plot = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2))
Plot(Coord(0x000a, 0x0001), Coord(0x0014, 0x0002))

julia> plot.top_right
Coord(0x0014, 0x0002)
```

## 3. 이미 등록된 소유권 주장인지 확인하기

이 소유권 주장에는 경쟁이 붙기 때문에, 주장이 허용되기 전에 등록부에 있는 기존 주장과 대조해 확인해요.

소유권 주장이 이미 등록되었는지 판단하는 `is_claim_staked()` 함수를 구현해요.

```julia-repl
julia> claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));
julia> register = Set{Plot}();
julia> is_claim_staked(claim, register)
false
```

## 4. 투기꾼은 모서리 좌표로 식별되는 구획을 지정해 소유권을 주장할 수 있어요

소유권 주장을 등록할 수 있도록 값을 변경하는 `stake_claim!()` 함수를 구현해요.

같은 주장이 이미 등록되어 있으면 `false`를 반환해요.

새로운 주장이 가능하면 등록부에 추가하고 `true`를 반환해요.

```julia_repl
julia> claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));
julia> register = Set{Plot}();
julia> stake_claim!(claim, register)
true
```

## 5. 구획에서 더 긴 변의 길이 구하기

소유권 주장의 더 긴 변(가로 또는 세로)을 구하는 `get_longest_side()` 함수를 구현해요.

```julia-repl
claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));

julia> get_longest_side(claim)
0x000a
```

## 6. 연구를 위해 가장 긴 변을 가진 소유 구획 찾기

등록된 모든 소유권 주장을 살펴보고 가장 긴 변을 가진 주장을 반환하는 `get_claim_with_longest_side()` 함수를 구현해요.

```julia-repl
julia> plot1 = Plot(bottom_left=Coord(5, 3), top_right=Coord(10, 5));
julia> plot2 = Plot(bottom_left=Coord(0, 0), top_right=Coord(3, 3));
julia> register = Set{Plot}([plot1, plot2]);

julia> get_claim_with_longest_side(register)
Plot(Coord(0x0005, 0x0003), Coord(0x000a, 0x0005))
```

Plot을 `Set`으로 반환해요. 가장 긴 구획이 하나면 원소가 하나, 동점이면 여러 개예요.
