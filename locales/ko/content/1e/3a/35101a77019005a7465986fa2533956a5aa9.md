# 지침 추가

## `.to_string()`에 쓰이는 Rust 트레이트

`Clock` 구조체를 위한 `.to_string()`도 구현해야 해요.
이 메서드는 Clock의 상태를 표시할 때 사용해요.
직접 구현할 수도 있고, [Display 트레이트][display-trait]를 사용할 수도 있어요.

그렇다면 대신 `Clock`에 [Display 트레이트][display-trait]를 구현해 봐요.

트레이트를 사용하면 여러 타입에 공통된 방식으로 기능을 구현할 수 있어요.

더 배워 보고 싶다면 `Clock` 타입에 `String::from`을 어떻게 구현할지 생각해 봐요.
실제로 구현할 필요는 없어요. `Display`와 중복되기도 하고, 대상 타입이 `String`일 때는
대개 `Display`가 더 나은 선택이거든요. 그래도 타입 변환 트레이트 몇 개쯤은 알고 있으면
도움이 돼요.

[display-trait]: https://doc.rust-lang.org/std/fmt/trait.Display.html
