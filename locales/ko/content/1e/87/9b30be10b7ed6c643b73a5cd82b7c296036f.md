# 안내

이 연습 문제에서는 여러 종류의 무선 조종 자동차 사이의 경주를 구성해요. 각 자동차는 고유한 속도와 배터리 소모 특성을 가지고 있어요.

자동차는 완전히 충전된(100%) 배터리로 시작해요. 무선 조종기로 자동차를 조종할 때마다 자동차는 속도만큼 미터를 이동하고, 남은 배터리 비율은 배터리 소모량만큼 줄어들어요.

자동차의 배터리가 배터리 소모 비율보다 낮으면 더 이상 자동차를 조종할 수 없어요.

각 경주 트랙은 고유한 거리를 가지고 있어요. 자동차는 배터리가 다 닳기 전에 트랙을 완주할 수 있는지 확인하는 방식으로 테스트해요.

여섯 개의 과제가 있고, 각 과제에서는 무선 조종 자동차 인스턴스를 다뤄요.

## 1. 무선 조종 자동차 만들기

`RemoteControlCar` 클래스의 생성자를 정의해서 무선 조종 자동차를 만들 수 있게 해요. 생성자는 자동차의 속도(미터)와 배터리 소모 비율을 두 매개변수로 받아요(둘 다 `int` 타입이에요):

```csharp
int speed = 5;
int batteryDrain = 2;
var car = new RemoteControlCar(speed, batteryDrain);
```

## 2. 경주 트랙 만들기

`RaceTrack` 클래스의 생성자를 정의해서 경주 트랙을 만들 수 있게 해요. 생성자는 트랙의 거리(미터)를 유일한 매개변수로 받아요(이 매개변수는 `int` 타입이에요):

```csharp
int distance = 800;
var raceTrack = new RaceTrack(distance);
```

## 3. 자동차 조종하기

자동차의 속도를 기준으로 주행한 미터 수를 갱신하는 `RemoteControlCar.Drive()` 메서드를 구현해요. 또한 자동차가 주행한 미터 수를 반환하는 `RemoteControlCar.DistanceDriven()` 메서드도 구현해요:

```csharp
int speed = 5;
int batteryDrain = 2;
var car = new RemoteControlCar(speed, batteryDrain);
car.Drive();

car.DistanceDriven();
// => 5
```

## 4. 배터리 소모 확인하기

자동차의 배터리 소모량을 기준으로 배터리를 소모시키도록 `RemoteControlCar.Drive()` 메서드를 수정해요. 또한 배터리가 소모되었는지 나타내는 `RemoteControlCar.BatteryDrained()` 메서드도 구현해요:

```csharp
int speed = 5;
int batteryDrain = 2;
var car = new RemoteControlCar(speed, batteryDrain);
car.Drive();

car.BatteryDrained();
// => false
```

## 5. Nitro 무선 조종 자동차 만들기

가장 많이 팔리는 무선 조종 자동차는 Nitro로, 최고 속도가 무려 50미터이고 배터리 소모는 4%예요. 이 유형의 자동차를 반환하는 (정적) `RemoteControlCar.Nitro()` 메서드를 구현해요:

```csharp
var car = RemoteControlCar.Nitro();
car.Drive();
car.DistanceDriven();
// => 50
```
## 6. 무선 조종 자동차가 경주를 완주할 수 있는지 확인하기

경주 트랙을 완주하려면 자동차가 트랙의 거리만큼 주행할 수 있어야 해요. 즉, 결승선을 통과하기 전에 배터리가 다 닳지 않아야 해요. `RemoteControlCar` 인스턴스를 매개변수로 받아 자동차가 경주 트랙을 완주할 수 있으면 `true`를, 그렇지 않으면 `false`를 반환하는 `RaceTrack.TryFinishTrack()` 메서드를 구현해요:

```csharp
int speed = 5;
int batteryDrain = 2;
var car = new RemoteControlCar(speed, batteryDrain);

int distance = 100;
var raceTrack = new RaceTrack(distance);

raceTrack.TryFinishTrack(car);
// => true
```
