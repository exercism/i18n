# 소개

## 오버플로

산술 오버플로는 산술 연산이나 타입 변환 같은 계산의 결과가 값을 받는 타입의 용량보다 큰 값이 될 때 발생해요.

이런 상황에서 `int`와 `long`, 그리고 이들에 대응하는 부호 없는 타입의 표현식은 아무런 오류 없이 값이 반대쪽 끝으로 넘어가요.

정수 연산의 동작은 `checked` 키워드를 사용해 바꿀 수 있어요. `checked` 블록 안에서 오버플로가 발생하면 `OverflowException` 인스턴스가 던져져요.

```csharp
int one = 1;
checked
{
    int expr = int.MaxValue + one;   // OverflowException is thrown
}

// or

int expr2 = checked(int.MaxValue + one);     // OverflowException is thrown
```

`float`와 `double` 타입의 표현식은 무한대라는 특별한 값을 가져요.

`decimal` 타입의 표현식은 `OverflowException` 인스턴스를 던져요.
