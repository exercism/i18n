# 소개

R에는 별도의 [집합][wiki-set] 타입이 없어요. 대신 벡터에서 비슷한 연산을 수행하는 여러 함수를 사용해요.

[`%in%`][ref-match] 연산자는 집합에 포함되는지 검사해요. 이 중위 연산자는 `is.element()` 함수와 같은 역할을 해요.

```R
2 %in% 1:10 # TRUE
12 %in% 1:10 # FALSE
```

관련된 함수는 다음과 같아요:

- 중복을 제거하는 [`unique()`][ref-unique].
- 집합을 합치는 [`union()`][ref-sets] (수학적으로 `A ∪ B`).
- 두 집합에 공통으로 있는 원소를 찾는 [`intersect()`][ref-sets] (`A ∩ B`).
- 한 집합에서 다른 집합을 빼는 [`setdiff()`][ref-sets] (`A - B`).
- 중복과 순서를 무시하고 두 집합이 같은지 검사하는 [`setequal`][ref-sets].

```R
> set_1 <- c("a", "b", "c", "b", "a")
> unique(set_1) # deduplicate
[1] "a" "b" "c"

> set_2 <- c('a', "c", "d")
> union(set_1, set_2) # values in either set
[1] "a" "b" "c" "d"

> intersect(set_1, set_2) # values in both sets
[1] "a" "c"

> setdiff(set_1, set_2) # values in set_1 but not set_2
[1] "b"

> setdiff(set_2, set_1) # values in set_2 but not set_1
[1] "d"

setequal(set_1, c("c", "b", "a", "b")) # are elements the same after deduplication?
[1] TRUE
```

어떤 경우든 함수는 복사본을 반환하고 인자는 바뀌지 않아요.

## 해시 테이블

위에서 설명한 벡터 연산은 base R에 포함되어 있어요. 작은 문제에는 유용하지만, 집합이 커지면 느려져요.

여러 서드파티 패키지가 [해시 테이블][wiki-hash]을 구현해서 어떤 상황에서는 성능을 높여줘요.

예를 들어 [`hashtable`][ref-hashtable] 패키지는 `hashmap`과 `hashset`을 제공하는데, 이들은 확장성이 더 좋아요. 대부분의 외부 패키지와 마찬가지로 Exercism 안에서는 사용할 수 없지만, 실무 문제에서는 살펴볼 만한 가치가 있어요.
