# 자세히 알아보기

Swift에서는 세 가지 주요 루프 구문을 제공해요.

- **`while`문**: 지정한 조건이 `true`인 동안 코드 블록을 반복해요. 조건은 루프 본문을 실행하기 전에 평가해요.
- **`repeat-while`문**: `while`문과 비슷하지만, 루프 본문을 실행한 뒤에 조건을 평가해요. 따라서 본문은 최소한 한 번은 실행되는 것이 보장돼요.
- **`for-in`문**: 시퀀스나 컬렉션(범위, 배열, 문자열 등)의 각 원소마다 코드 블록을 한 번씩 실행해요.
