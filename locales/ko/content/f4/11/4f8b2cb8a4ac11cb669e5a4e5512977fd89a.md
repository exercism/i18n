# 도움말

문제가 생겼을 때 도움을 받을 수 있는 몇 가지 자료를 소개해요:

- [PSF](https://www.python.org)는 Python 다운로드, 문서, 커뮤니티 자료를 제공해요.
- [Python 커뮤니티 포럼](https://discuss.python.org/)에서는 도움, PEP 논의, Python 핵심 커미터 등 여러 가지를 만날 수 있어요.
- [Discord의 Exercism 커뮤니티](https://exercism.org/r/discord)
- [Exercism 커뮤니티 토론 포럼](https://forum.exercsim.org)
- [Discord의 Python 커뮤니티](https://pythondiscord.com/)는 매우 활발하고 도움이 많이 되는 커뮤니티예요.
- [/r/learnpython/](https://www.reddit.com/r/learnpython/)은 Python 학습자를 위해 만들어진 서브레딧이에요.
- [Libera.chat의 #python](https://www.python.org/community/irc/)은 이 언어의 핵심 개발자들이 모여서 작업을 하는 곳이에요.
- [Free Code Camp 커뮤니티 포럼](https://forum.freecodecamp.org/)
- [Pythontutor](http://pythontutor.com/)는 작은 코드 조각을 시각적으로 한 단계씩 따라가 볼 때 좋아요.

그 밖에도 [StackOverflow](http://stackoverflow.com/questions/tagged/python)는 내 문제나 질문에 대한 답이 이미 있는지 검색해 보기 좋은 곳이에요. 없다면 언제든지 [질문](https://stackoverflow.com/help/how-to-ask)을 올리거나 다른 사람의 질문에 [답변](https://stackoverflow.com/help/how-to-answer)할 수 있어요.
