# 지침

안전 점검을 통과하기 전에는 서커스에서 아무도 공중그네에 오르지 않아요.
모두에게 같은 규칙이 적용되도록 점검 사항을 적어 두려고 해요.

다섯 가지 과제는 모두 `SAFETY_CHECK` 클래스에 들어가요.

## 1. 매트가 준비됐나요?

매트는 깔려 있고 깨끗할 때에만 준비된 거예요.

```sather
SAFETY_CHECK::mat_ready(true, false)
-- => false
```

## 2. 착지할 곳이 있나요?

아래에 매트가 있거나, 그물이 있어야 해요. 둘 중 하나만 있어도 되고,
둘 다 있어도 괜찮아요.

```sather
SAFETY_CHECK::something_below(false, true)
-- => true
```

## 3. 누가 아직 브리핑이 필요한가요?

브리핑을 받지 않은 사람은 누구나 브리핑이 필요해요.

```sather
SAFETY_CHECK::needs_briefing(false)
-- => true
```

## 4. 이 공연자는 나이가 충분한가요?

공중그네는 13세 이상인 공연자만 탈 수 있어요.

```sather
SAFETY_CHECK::old_enough(13)
-- => true
```

## 5. 모두 합쳐 봐요

공연자는 나이가 충분하고, 브리핑을 받았고, 매트가 준비됐을 때 공중그네를 탈 수 있어요.

```sather
SAFETY_CHECK::cleared(14, true, true, true)
-- => true
```

네 개의 인자는 나이, 브리핑을 받았는지 여부, 매트가 깔려 있는지 여부,
매트가 깨끗한지 여부예요.
