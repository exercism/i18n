# 지시 사항

이 연습 문제에서는 띠의 값을 외우지 않아도 되도록 도움이 되는 프로그램을 만들어 봐요.
이 프로그램은 입력으로 1개, 4개 또는 5개의 색을 받아 올바른 값을 옴 단위로 출력해요.
색 띠는 다음과 같이 인코딩돼요:

| 색  | 값 |
| ------ | ----- |
| Black  | 0     |
| Brown  | 1     |
| Red    | 2     |
| Orange | 3     |
| Yellow | 4     |
| Green  | 5     |
| Blue   | 6     |
| Violet | 7     |
| Gray   | 8     |
| White  | 9     |

[`Resistor Color Trio`][resistor-color-trio-exercise] 연습 문제에서는 처음 세 개의 색 띠를 해독했어요.
예를 들어 orange-orange-brown은 주값 `330`으로 해독됐어요.
이번 연습 문제에서는 여기에 _허용 오차_를 더해야 해요.
허용 오차는 값이 주값보다 위아래로 벗어날 수 있는 최대량이에요.
예를 들어 마지막 띠가 green이면 최대 허용 오차는 `±0.5%`예요.

허용 오차 띠는 다음 값 중 하나를 가져요:

| 색  | 허용 오차 |
| ------ | --------: |
| Grey   |    ±0.05% |
| Violet |    ±0.10% |
| Blue   |    ±0.25% |
| Green  |    ±0.50% |
| Brown  |    ±1.00% |
| Red    |    ±2.00% |
| Gold   |    ±5.00% |
| Silver |   ±10.00% |

4색 띠 저항은 다음과 같이 구성돼요:

| 띠 1  | 띠 2  | 띠 3     | 띠 4    |
| ------- | ------- | ---------- | --------- |
| 값 1 | 값 2 | 배수 | 허용 오차 |

예시:

- orange-orange-brown-green은 `330`옴이고 허용 오차는 `±0.5%`예요.
- orange-orange-red-grey는 `3300`옴이고 허용 오차는 `±0.05%`예요.

4색 띠 저항과 5색 띠 저항의 차이는 5색 띠 저항에 더 정밀한 값을 나타내는 띠가 하나 더 있다는 점이에요.

| 띠 1  | 띠 2  | 띠 3  | 띠 4     | 띠 5    |
| ------- | ------- | ------- | ---------- | --------- |
| 값 1 | 값 2 | 값 3 | 배수 | 허용 오차 |

예시:

- orange-orange-orange-black-green은 `333`옴이고 허용 오차는 `±0.5%`예요.
- orange-red-orange-blue-violet은 `323 million`옴이고 허용 오차는 `±0.1%`예요.

띠가 하나인 저항도 있어요.
띠가 하나인 저항은 black 색 하나만 가지고 값은 0이에요.

프로그램은 저항 띠 색상으로 이루어진 입력 `list`를 다음 형식의 레이블로 변환해야 해요:

"... ohms ±...%"

따라서 `["orange", "orange", "black", "green"]` 같은 입력 `list`는 다음을 반환해야 해요:

"33 ohms ±0.5%"

수천 옴일 때는 "kiloohms"라고 해요.
1000미터를 "킬로미터", 1000그램을 "킬로그램"이라고 하는 것과 비슷해요.

따라서 `["orange", "orange", "orange", "grey"]` 같은 입력 `list`는 다음을 반환해야 해요:

"33 kiloohms ±0.05%"

수백만 옴일 때는 "megaohms"라고 해요.

따라서 `["orange", "orange", "blue", "red"]` 같은 입력 `list`는 다음을 반환해야 해요:

"33 megaohms ±2%"

[resistor-color-trio-exercise]: https://exercism.org/tracks/python/exercises/resistor-color-trio
