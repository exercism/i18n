# 학습

Cairo는 범용 연산을 위한 증명 가능한 프로그램을 작성할 수 있는 최초의 튜링 완전 언어예요. Rust와 유사한 고수준 언어죠. Rust처럼, 개발자가 효율적이고 안전한 코드를 쉽게 작성할 수 있도록 하는 것을 목표로 해요.

배우는 가장 좋은 방법은 직접 놀고 연습하는 것이라고 생각해요. 자신만의 코딩 프로젝트를 만들거나, 여기 Exercism에 있는 것 같은 작은 연습 문제를 풀면서요!

아래 자료들이 Cairo 여정을 시작하는 데 도움이 될 거예요:

- [Cairo Programming Language](https://www.cairo-lang.org/)는 Cairo 언어를 소개하고, Cairo를 배우고 사용하는 데 관련된 여러 자료를 알려줘요.
- [The Cairo Book](https://book.cairo-lang.org/)은 Cairo를 배우고 Cairo의 특정 기능을 깊이 파고들기에 좋은 자료예요.
- [Cairo Documentation](https://docs.cairo-lang.org/)는 언어의 구성 요소와 의미를 설명해요.
- [Cairo by Example](https://cairo-by-example.com/)은 Cairo로 작성하게 될 가장 흔한 것들의 예제를 보여줘요.
- [Node Guardians](https://nodeguardians.io/campaigns?f=3%3D2)는 "스마트 컨트랙트 개발자를 위한 판타지 테마 학습 플랫폼"이에요.
- [Cairo Community Forum](https://community.cairo-lang.org/)은 모든 수준의 질문에 답해줘요.
