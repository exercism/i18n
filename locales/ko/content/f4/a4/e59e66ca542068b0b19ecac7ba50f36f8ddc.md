# 구조 분해

구조 분해는 항목을 구성 요소로 나누고, 각각을 더 작은 변수에 묶는 과정이에요.

## 튜플 구조 분해

튜플 구조 분해는 간단해요. 튜플의 각 필드에 새 변수 이름을 지정하면 돼요:

```rust
let (first, second) = (1, 2);
```

## 튜플 구조체 구조 분해

튜플 구조체를 구조 분해하는 방법은 튜플과 똑같아요. 다만 구조체 이름을 함께 써요:

```rust
struct TupleStruct(&'static str, i32);
let my_tuple_struct = TupleStruct("foo", 123);
let TupleStruct(foo, num) = my_tuple_struct;
```

## 구조체 구조 분해

구조체를 구조 분해하는 방법은 튜플 구조체와 비슷해요. 필드 이름을 그대로 쓰면 돼요:

```rust
struct ArabianNights {
    name: String,
    stories: usize,
}
let teller = ArabianNights { name: "Scheherazade".into(), stories: 1001 };
{
    let ArabianNights { name, stories } = teller;
    println!("{name} told {stories} stories");
}
```

## 부분 구조 분해

`..` 연산자를 사용하면 구조 분해할 때 일부 필드를 무시할 수 있어요:

```rust
let ArabianNights { name, .. } = teller;
println!("{name} survived by her wits");
```

## 조건부 구조 분해

구조체와 튜플의 구조 분해는 실패하지 않아요. 하지만 `if let`, `while let`, `match` 언어 구문을 사용하면 열거형도 구조 분해할 수 있어요.

```rust
if let Some(foo) = foo {
    println!("{foo:?}");
}
```
