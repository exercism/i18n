# 지침

루시안의 여자친구가 집으로 돌아오는 길인데, 루시안은 기념일 저녁 식사를 아직 준비하지 못했어요!

이 연습 문제에서는 루시안이 가장 좋아하는 요리책을 보고 근사한 라자냐를 만들 수 있도록 돕는 코드를 작성해요.

라자냐를 조리하는 데 걸리는 시간과 관련된 네 가지 과제가 있어요.

## 1. 예상 오븐 조리 시간을 분 단위로 정의하기

인자를 받지 않고, 라자냐를 오븐에 몇 분 동안 넣어 두어야 하는지 반환하는 `ovenTime()` 함수를 정의해요.
요리책에 따르면 예상 오븐 조리 시간은 40분이에요:

```cpp
ovenTime();
// => 40
```

## 2. 남은 오븐 조리 시간을 분 단위로 계산하기

`remainingOvenTime(int actualMinutesInOven)` 함수를 정의해요. 이 함수는 라자냐가 오븐에 있던 실제 분을 인자로 받고, 이전 과제에서 구한 예상 오븐 조리 시간을 기준으로 라자냐가 오븐에 더 남아 있어야 하는 분을 반환해요.

```cpp
remainingOvenTime(30);
// => 10
```

## 3. 준비 시간을 분 단위로 계산하기

`preparationTime(int numberOfLayers)` 함수를 정의해요. 이 함수는 라자냐에 추가한 층의 개수를 인자로 받고, 각 층을 준비하는 데 2분이 걸린다고 가정할 때 라자냐를 준비하는 데 걸린 분을 반환해요.

```cpp
preparationTime(2);
// => 4
```

## 4. 경과 시간을 분 단위로 계산하기

`elapsedTime(int numberOfLayers, int actualMinutesInOven)` 함수를 정의해요. 이 함수는 두 개의 인자를 받아요. 첫 번째 인자는 라자냐에 추가한 층의 개수이고, 두 번째 인자는 라자냐가 오븐에 있던 분이에요. 이 함수는 라자냐를 조리하는 데 작업한 분, 즉 준비 시간과 현재까지 라자냐가 오븐에서 보낸 시간을 더한 값을 반환해야 해요.

```cpp
elapsedTime(3, 20);
// => 26
```
