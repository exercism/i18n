# 개요

블록은 문을 작게 묶은 단위로, 여러 번 실행할 수 있어요.
블록은 클로저나 익명 함수라고 생각할 수 있어요.
블록은 `do...end` 문법(위쪽)이나 `{}`(아래쪽)로 정의해요.
두 스타일은 서로 바꿔 쓸 수 있고, 각각 언제 사용해야 하는지에 대해서는 의견이 갈려요.

## 단축 문법

블록이 메서드 하나만 호출하는 경우에는 블록을 `&:` 뒤에 메서드 이름을 붙인 형태로 바꿀 수 있어요. 예를 들어, 다음 두 줄은 같은 의미예요:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```
