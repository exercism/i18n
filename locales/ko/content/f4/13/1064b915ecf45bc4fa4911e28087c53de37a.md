# 소개

*튜플*(tuple)은 Factor의 레코드/구조체/클래스 타입이에요. 각 튜플 클래스에는 이름이 붙은 슬롯들이 고정된 구성으로 들어 있고, Factor가 그 슬롯들의 게터와 세터를 자동으로 만들어 줘요.

```factor
TUPLE: point
    { x initial: 0 }
    { y initial: 0 } ;

T{ point { x 3 } { y 4 } } x>> .   ! => 3
3 4 point boa .                    ! => T{ point { x 3 } { y 4 } }
point new .                        ! => T{ point }
```

`boa`("by order of arguments", 인자 순서대로라는 뜻)는 스택에서 선언 순서대로 슬롯을 채워요. `new`는 각 슬롯을 선언된 `initial:` 값으로 설정한 인스턴스를 만들어요(값이 없으면 `f`).

각 슬롯의 게터는 `slot>>`, 세터는 `>>slot`이에요. 세터는 값을 *변경*하니까, 원본을 그대로 두는 갱신이 필요하면 먼저 `clone`을 해요.

```factor
T{ point { x 3 } { y 4 } } clone 10 >>x .
! => T{ point { x 10 } { y 4 } }
```

슬롯의 기본값은 `{ name initial: value }`로 지정해요. `initial:`이 없으면 기본값은 `f`예요.
