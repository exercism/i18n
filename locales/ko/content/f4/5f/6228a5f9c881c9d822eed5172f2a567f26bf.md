# 소개

Factor의 연관 배열, 즉 해시 테이블과 그 친구들은 [`assocs`][assocs]에서 제공하는 공통 [프로토콜][assoc-protocol]을 공유해요. 해시 테이블 리터럴은 이렇게 써요:

```factor
H{ { "coal" 1 } { "wood" 2 } } .

"coal" H{ { "coal" 1 } { "wood" 2 } } at .   ! => 1
"gold" H{ { "coal" 1 } { "wood" 2 } } at .   ! => f
```

자주 쓰는 연산:

```
at        ( key assoc -- value/f )
key?      ( key assoc -- ? )
set-at    ( value key assoc -- )
delete-at ( key assoc -- )
inc-at    ( key assoc -- )
change-at ( key assoc quot -- )
keys      ( assoc -- keys )
values    ( assoc -- values )
>alist    ( assoc -- alist )
```

해시 테이블은 *변경 가능*해요. 호출 사이에 리터럴이 공유되지 않도록, 수정하기 전에 `H{ }` 리터럴을 `clone`해요.

[assocs]: https://docs.factorcode.org/content/vocab-assocs.html
[assoc-protocol]: https://docs.factorcode.org/content/article-assocs-protocol.html
