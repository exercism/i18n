# 지침 추가

## 출력 형식

null로 끝나는 문자열을 출력해요. 구분자로는 쉼표와 공백을 사용해요.

출력 예시는 `"491, 914, 142"`예요.

입력이 유효하지 않으면 빈 문자열을 출력해요.

## 레지스터

| 레지스터 | 용도        | 형식    | 설명                           |
| -------- | ----------- | ------- | ------------------------------ |
| `$a0`    | 입력        | 주소    | null로 끝나는 수열 문자열      |
| `$a1`    | 입력        | 정수    | 슬라이스 길이                  |
| `$a2`    | 입출력      | 주소    | null로 끝나는 출력 문자열      |
| `$t0-9`  | 임시        | 임의    | 임시 저장에 사용               |
