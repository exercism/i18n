# Visual Basic 배우기

## 웹사이트

Visual Basic은 지난 여러 해 동안 크게 발전했고, 많은 서드파티 튜토리얼은 오래된 도구나 기능을 다루고 있어요.
[공식 Visual Basic 문서](https://learn.microsoft.com/en-us/dotnet/visual-basic/)가 가장 최신이고 믿을 만한, 여정을 시작할 곳이에요.

## .NET 생태계

Visual Basic은 .NET 런타임에서 실행되고, C#과 F#과 많은 핵심 기능을 공유해요.
따라서 .NET이 어떻게 동작하는지 이해하면 더 실력 있는 VB 개발자가 될 수 있어요.
