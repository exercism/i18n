# 소개

## 맵

엘릭서에서 맵은 정보를 키-값 쌍으로 저장하는 자료 구조예요. 다른 언어에서는 이런 구조를 연관 배열(PHP), 해시(Perl 5, Raku), 딕셔너리(Python)라고 부르기도 해요.

키와 값은 어떤 자료형이든 될 수 있지만, 키가 아톰이면 축약 문법을 쓸 수 있어요. 맵은 항목을 조회하거나 반환할 때 순서를 보장하지 않아요.

### 리터럴 형태

빈 맵은 그냥 `%{}`로 선언해요. 맵 리터럴에 항목을 추가하고 싶다면 두 가지 형태를 쓸 수 있어요:

```elixir
# If the key is an atom:
%{atom_key: 1}

# If the key is a different type:
%{1 => :atom_value}

# You can even mix these if the atom form comes second:
%{"first_form" => :a, atom_form: :b}
```

정해진 표준 형식은 없지만, 키-값 리터럴 쌍을 표현하는 일관된 방식을 고르는 게 좋아요.

### 맵 모듈 함수

엘릭서는 _맵 모듈_에서 맵을 다루는 많은 함수를 제공해요. 일부 _맵 모듈_ 함수는 맵 변환을 돕기 위해 _익명_ 함수를 인자로 넘겨받아요.

## 상수로서의 모듈 속성

엘릭서에서는 함수에서 상수처럼 쓸 수 있는 모듈 속성을 정의할 수 있어요.

```elixir
defmodule Example do
  # Defines the attribute as the value 1
  @constant_number 1

  def example_value() do
    # Returns the value 1
    @constant_number
  end
end
```

모듈 상수를 정의할 때 쓰이는 속성은 컴파일 시점에 평가할 수 있는 어떤 표현식이든 될 수 있어요. 컴파일이 끝나면 모듈 속성에는 접근할 수 없어요. 컴파일 중에 확장되기 때문이에요. C 같은 언어에서 정의된 매크로와 비슷해요.
