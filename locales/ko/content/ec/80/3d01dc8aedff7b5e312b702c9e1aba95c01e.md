# 표현

[Python 리프리젠터][representer]는 학생 풀이를 처리하고 정규화해서 더 "일반적인" 형태로 만들어요:

- 코드는 [Python AST 모듈][python-ast]을 사용해 AST로 변환돼요.
- 최종 AST 트리는 공백이나 들여쓰기가 없는 문자열로 변환되어 `representation.txt`로 출력돼요.
- 문제를 진단할 수 있도록, `representation.out`에는 시작 AST, 편집된 AST, 정규화가 적용된 코드 표현이 담겨요.

- 제거되는 것:
    - 타입 힌트 (_데이터클래스의 타입 힌트도 포함돼요, 아래 정규화를 참고해요_)
    - `print()` 문
    - `if __name__ == __main__` 블록
    -  주석
    -  독스트링

-  대체되는 것:
    - 사용자가 정의한 이름은 자리 표시자로 대체돼요 (_함수 이름, 매개변수, 람다의 변수도 포함돼요_)

- 정규화:
  - 문자열 따옴표 `'`는 `"` (_큰따옴표_)로 바뀌어요. 단, 이스케이프가 필요하면 바뀌지 않고 그대로 남아요.
  - 숫자 리터럴은 밑줄이 모두 제거되고, 과학적 표기법은 실제 값으로 계산돼요:
    - **66_777_888_433** --> 66777888433
    - **1_999_878_473.66** --> 1999878473.66
    - **77_555_998_125.445_779** --> 77555998125.44579
    - **44_573_123.445_312+123_674.889_12j** --> 44573123.445312 + 123674.88912j
    - **1e6** --> 1000000.0 #1000000
    -  **1e2+.23** --> 100.0 + 0.23 #100.23
    - **1e2+1_23e0+4.4e-1** --> 100.0 + 123.0 + 0.44 #223.44
    - **7e6+7e5+5e4+9.98e2+4.45_779e-1** -->7000000.0 + 700000.0 + 50000.0 + 998.0 + 0.445779 #7750998.445779
    - **(7e6+7e5+5e4+9.98e1+4.457_79e-1)+(1e2+1.23e1+4.444_23e-1)*1*j** --> (7000000.0 + 700000.0 + 50000.0 + 99.8 + 0.445779 + (100.0 + 12.3 + 0.444423) * 1j)  #7750100.245779+112.744423j
  - 독스트링을 제거한 뒤 본문이 비어 있는 함수와 클래스는 본문에 `pass`가 할당돼요.
  - 타입 힌트는 있지만 값이 할당되지 않은 데이터 멤버가 있는 데이터클래스는, 그 데이터 멤버에 값으로 `None`이 할당돼요. 자세한 내용은 normalizer.py의 153번째 줄부터 시작하는 독스트링을 참고해요.
