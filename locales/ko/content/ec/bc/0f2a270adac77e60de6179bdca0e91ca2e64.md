# 소개

딕셔너리는 각 원소가 키와 값으로 이루어진 원소들의 모음이에요. 딕셔너리의 메서드에 키를 전달하면 그 키에 해당하는 값이 반환돼요. 다른 언어에서 맵이나 연관 배열이 하는 역할과 같아요.

딕셔너리는 다음과 같이 만들 수 있어요:

```csharp
new Dictionary<int, string>();
// Empty dictionary
```

또는

```csharp
new Dictionary<int, string>
{
    [1] = "One",
    [2] = "Two"
};

// Or

new Dictionary<int, string>
{
    {1, "One"},
    {2, "Two"}
};
// 1 => "One", 2 => "Two"
```

키와 값의 타입도 딕셔너리의 정의에 포함된다는 점에 주의해요.

한번 만들고 나면, 딕셔너리에 내장된 `Add`와 `Remove` 메서드로 항목을 추가하거나 제거할 수 있어요.

딕셔너리에서 값을 가져오거나 수정할 때는 키를 사용해 딕셔너리에 인덱싱해요:

```csharp
var numbers = new Dictionary<int, string>
{
   {1, "One"},
   {2, "Two"}
};

// Set the value of the element with key 2 to "Deux"
numbers[2] = "Deux";

// Get the value of the element with key 2
numbers[2];
// => "Deux"
```

딕셔너리에 값이 존재하는지 확인하려면 다음과 같이 해요:

```csharp
var dict = new Dictionary<string, string>{/*...*/};
dict.ContainsKey("some key that exists");
// => true
```

딕셔너리를 순회하면 키와 값의 쌍을 순회하게 돼요. 딕셔너리에는 키나 값만 순회할 수 있게 해 주는 속성도 있어요.
