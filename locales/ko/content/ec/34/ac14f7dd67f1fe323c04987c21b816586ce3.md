# 개요

C++에서는 비교 연산자를 사용해 값을 비교할 수 있어요.

| 비교              | 연산자    |
| ------------------| --------- |
| 같음              | `==`      |
| 같지 않음         | `!=`      |
| 작음              | `<`       |
| 작거나 같음       | `<=`      |
| 큼                | `>`       |
| 크거나 같음       | `>=`      |

이 비교의 결과는 항상 불리언 값이에요.

```cpp
int a{3};

bool eq1 = a != 4; // true

bool eq2 = a > 5;  // false
```

`==`와 `!=` 연산자는 각각 어떤 값이 다른 값과 같은지, 같지 않은지를 확인해요. 다음은 흔히 쓰이는 예예요.

```cpp
bool eq3 = 2 == 3; // false, integer comparison

bool eq4 = 2.1 != 2.2; // true, float comparison

bool eq5 = "hello" == "hello"; // true, string comparison
```

나머지 연산자들은 한 값이 다른 값보다 큰지(`>`), 크거나 같은지(`>=`), 작은지(`<`), 작거나 같은지(`<=`)를 확인해요. 이런 비교는 숫자와 문자열에 사용할 수 있어요. 문자열을 비교할 때는 사전 순서(사전식 순서라고도 해요)를 따라요.

```cpp
bool eq6 = 2 > 3; // false, integer comparison

bool eq7 = 1.2 < 1.3; // true, float comparison

bool eq8 = "Hello" < "World"; // true, string comparison
```
