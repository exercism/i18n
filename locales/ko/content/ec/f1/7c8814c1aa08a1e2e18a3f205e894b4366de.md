# break와 continue

루프를 돌리거나 반복하는 제어 구조를 사용할 때, `break`와 `continue` 키워드는 프로그램의 흐름을 제어하는 데 도움을 줘요.
`break` 키워드는 루프 문맥을 빠져나와 바깥 스코프로 이동해요. 그래서 루프가 끝나요.
`continue` 키워드는 현재 반복의 나머지를 건너뛰고, 루프 문맥을 다음 반복의 시작 지점에서 다시 시작해요.
흔한 일은 아니지만, 키워드에 숫자를 함께 써서 몇 개의 문맥을 빠져나가거나 다음 반복으로 건너뛸지 제어할 수 있어요.

```php
<?php
$i = 1;
while ($i <= 10) {

    if ($i <= 5) {
        i += 1;
        continue;
    }
    break;
}
```

앞의 예제에서 `continue`는 다섯 번 실행되지만, 여섯 번째 반복에서 `break`가 실행되어 코드가 루프를 빠져나가요.
