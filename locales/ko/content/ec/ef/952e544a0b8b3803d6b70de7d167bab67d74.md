# 추가 지침

## 출력 형식

나이는 연 단위의 100분의 1로 출력해요.

예를 들어 100 × 1,000,000,000 ÷ 31,557,600 ≈ 3,169이므로, 1,000,000,000초를 살아온 사람의 지구 나이는 `3169`(연 단위의 100분의 1)예요.

## 레지스터

| 레지스터 | 용도      | 타입    | 설명                          |
| -------- | --------- | ------- | ----------------------------- |
| `$a0`    | 입력      | 정수    | 행성 (`0` = 수성, `1` = 금성, `2` = 지구, `3` = 화성, `4` = 목성, `5` = 토성, `6` = 천왕성, `7` = 해왕성) |
| `$a1`    | 입력      | 정수    | 초                            |
| `$v0`    | 출력      | 정수    | 연 단위의 100분의 1로 나타낸 나이 |
| `$t0-9`  | 임시      | 임의    | 임시 값 저장에 사용해요       |
