# 소개

## 동등성

Common Lisp에는 서로 다른 동등성 판별 함수가 아주 많아요.
`==`나 `===`처럼 하나 또는 둘만 있는 다른 프로그래밍 언어와는 다른 점이에요.
Common Lisp의 판별 함수 중에는 특정 타입에만 쓰이는 것도 있고, 어떤 타입에도 두루 쓰이는 범용인 것도 있는데, 여기서는 뒤쪽의 범용 판별 함수를 다뤄요.

범용 동등성 판별 함수는 네 가지이고, 무엇을 "동등하다"고 보는지에 따라 얼마나 엄격한지가 달라요.
가장 엄격한 것부터 가장 느슨한 것 순으로 `eq`, `eql`, `equal`, `equalp`예요.

몇 가지 세부 사항은 빼고, 간단히 정의하면 다음과 같아요.

- `eq`: 두 객체가 완전히 동일하다는 것을 동등함으로 정의해요.
  _예를 들어_:

```lisp
(eq 'a 'a)                 ; => T
(eq (list 1 2) (list 1 2)) ; => NIL
```

- `eql`: 같은 타입과 값을 가진 두 수, 또는 서로 같은 두 문자를 동등함으로 정의하고, 그 밖의 것은 `eq`면 동등하다고 봐요.
  _예를 들어_:

```lisp
(eql 1 1)     ; => T
(eql #\a #\a) ; => T
(eql 1 1.0)   ; => NIL
(eql #\a #\A) ; => NIL
```

- `equal`: 두 리스트는 각 원소가 `equal`이면 `equal`이고, 두 문자열은 각 원소가 `eql`이면 `equal`이고, 두 배열은 `eq`면 `equal`이고, 그 밖의 모든 것은 `eql`이면 `equal`이라고 정의해요.
  _예를 들어_:

```lisp
(equal (list 1 2) (list 1 2)) ; => T
(equal #(1 2) #(1 2))         ; => NIL
(equal "foo" "foo")           ; => T
```

- `equalp`: 문자열과 문자는 대소문자를 구분하지 않고 비교하고, 수는 타입 변환을 어느 정도 거쳐서 비교해요. 리스트와 배열은 모든 원소가 `equalp`면 `equalp`이고, 구조체는 같은 타입이고 모든 슬롯이 `equalp`면 `equalp`이고, 해시 테이블은 키와 값이 `equalp`면 `equalp`예요.
  _예를 들어_:

```lisp
(equalp "foo" "FoO")                          ; => T
(equalp 3 3.0)                                ; => T
(equalp (make-a-structure :slot1 1 :slot2 2) 
        (make-a-structure :slot1 1 :slot2 2)) ; => T
```
