# 실수

`INT`에는 정수만 담을 수 있어요. 두 정수를 나누면 나머지는 버려지고요.

```sather
7 / 2        -- 3, not 3.5
```

소수 부분이 중요할 때 쓰는 타입이 `FLTD`예요. 정수 사이의 값도 담을 수 있는 **실수** 타입이에요.

## 실수 작성하기

실수 리터럴은 소수점과 끝에 붙는 `d`로 이루어져요.

```sather
   concert_a : FLTD is
      return 440.0d;
   end;
```

`d`는 생략할 수 없어요. `440.0`만 쓰면 정밀도가 더 낮은 다른 타입이 돼요. `d`를 붙여야 여기서 사용하는 타입이 되어요.

`2.0d`처럼 써야 해요. `2d`는 안 돼요. 소수점도 있어야 하거든요.

## 연산

`+`, `-`, `*`, `/` 모두 사용할 수 있어요. 이제 `/`는 소수 부분까지 그대로 남겨요.

```sather
7.0d / 2.0d      -- 3.5
```

양쪽 모두 `FLTD`여야 해요. Sather는 두 타입을 슬그머니 섞지 않아요. 그래서 `7 / 2.0d`는 뜻밖의 결과가 아니라 오류가 돼요.

## 정수에서 실수로

`.fltd`는 `INT`를 `FLTD`로 바꿔줘요.

```sather
   halve(n : INT) : FLTD is
      return n.fltd / 2.0d;
   end;
```

`halve(7)`은 `3.5`예요. 변환이 어디에서 일어나는지 눈여겨봐요. `(7 / 2).fltd`는 `3.0`이 되어요. 나눗셈에서 이미 0.5를 버렸기 때문이에요. 나눈 **뒤**가 아니라 **전에** 변환해야 해요.

## 얼마나 떨어져 있을까요?

`.abs`는 마이너스 부호를 없애줘요. 두 값이 얼마나 떨어져 있는지, 어느 쪽이 더 큰지는 신경 쓰지 않고 알고 싶을 때 쓰는 방법이에요.

```sather
(440.0d - 442.0d).abs      -- 2.0
```
