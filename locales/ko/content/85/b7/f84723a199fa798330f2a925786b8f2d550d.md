# 지시사항

이 연습 문제에서는 좋아하는 요리책을 보며 근사한 라자냐를 만들 수 있도록 도와주는 코드를 작성해요.
라자냐를 조리하는 데 걸리는 시간과 관련된 네 가지 과제가 있어요.

## 1. 예상 오븐 조리 시간(분)을 정의해요

라자냐를 오븐에 몇 분 동안 두어야 하는지를 저장하는 `expectedMinutesInOven` 상수를 정의해요.
요리책에 따르면 예상 오븐 조리 시간은 40분이에요:

```swift
expectedMinutesInOven
// Returns 40
```

## 2. 남은 오븐 조리 시간(분)을 계산해요

라자냐가 지금까지 오븐에 있던 시간(분)을 담은 `elapsedMinutes` 인자를 받는 `remainingMinutesInOven(elapsedMinutes:)` 함수를 정의해요.
이 함수는 이전 과제에서 구한 예상 오븐 조리 시간을 기준으로, 라자냐가 앞으로 오븐에 몇 분 더 있어야 하는지를 반환해야 해요.

```swift
remainingMinutesInOven(elapsedMinutes: 30)
// Returns 10
```

## 3. 준비 시간(분)을 계산해요

라자냐에 추가한 층 수를 담은 `layers` 인자를 받는 `preparationTimeInMinutes(layers:)` 함수를 정의해요.
이 함수는 각 층을 준비하는 데 2분씩 걸린다고 가정할 때, 라자냐를 준비하는 데 몇 분이 걸렸는지를 반환해야 해요.

```swift
preparationTimeInMinutes(layers: 2)
// Returns 4
```

## 4. 총 작업 시간(분)을 계산해요

`totalTimeInMinutes(layers:elapsedMinutes:)` 함수는 두 개의 인자를 받아요. `layers` 매개변수는 라자냐에 추가한 층 수이고, `elapsedMinutes` 매개변수는 라자냐가 오븐에 있던 시간(분)이에요.
이 함수는 라자냐 조리에 총 몇 분을 들였는지를 반환해야 해요. 이 값은 준비 시간(분)과 현재까지 라자냐가 오븐에 있던 시간(분)을 더한 값이에요.

```swift
totalTimeInMinutes(layers: 3, elapsedMinutes: 20)
// Returns 26
```
