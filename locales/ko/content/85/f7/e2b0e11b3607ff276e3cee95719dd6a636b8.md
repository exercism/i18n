# 테스트

## 테스트 실행하기

테스트를 실행하려면 다음 명령어를 실행해요:

```bash
dotnet test
```

## 연습 문제 풀기

연습 문제를 푼다는 건 모든 테스트를 통과시키는 거예요. 기본적으로 테스트를 실행하면 첫 번째 테스트 하나만 실행돼요. 이건 의도된 동작이에요. 그 한 개의 테스트를 통과시키는 데만 집중할 수 있거든요. 테스트가 통과하면, 테스트의 `[<Fact>]` 또는 `[<Theory>]` 특성에서 `Skip = "Remove this Skip property to run this test"`를 지워서 다음 테스트를 활성화할 수 있어요. 모든 테스트를 활성화했고 구현이 그 테스트를 모두 통과하면, 연습 문제를 푼 거예요!

시작하는 데 도움이 되도록, 각 연습 문제에는 스텁 구현 파일이 함께 있어요. 이 파일을 풀이를 만드는 출발점으로 삼아도 돼요. 이 파일을 지우거나 바꾸는 게 맞다고 생각되면 얼마든지 그렇게 해도 괜찮아요.

## 패키지 사용하기

대부분의 연습 문제는 외부 패키지 없이 풀 수 있어요. 하지만 외부 패키지를 정말 사용하고 싶은 연습 문제라면, 다음 명령어로 프로젝트에 패키지를 추가할 수 있어요:

```bash
dotnet add package [package-name]
```
