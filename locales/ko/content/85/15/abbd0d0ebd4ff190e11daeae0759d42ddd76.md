# 추가 지침

## 레지스터

| 레지스터 | 용도        | 타입    | 설명                            |
| -------- | ------------ | ------- | -------------------------------------- |
| `$a0`    | 입력        | 주소 | 첫 번째 색을 나타내는 null로 끝나는 문자열  |
| `$a1`    | 입력        | 주소 | 두 번째 색을 나타내는 null로 끝나는 문자열 |
| `$a2`    | 입력        | 주소 | 세 번째 색을 나타내는 null로 끝나는 문자열  |
| `$a3`    | 입출력 | 주소 | null로 끝나는 출력 문자열          |
| `$t0-9`  | 임시    | 아무 값     | 임시 저장용             |
