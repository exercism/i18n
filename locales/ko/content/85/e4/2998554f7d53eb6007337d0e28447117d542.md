# 지시 사항

연구소의 보안 데스크를 맡고 있어요. 직원들은 *배지*를 차고 다니는데, 그 코드는 엄격한 형식을 따라요. 출입 기록에는 그런 코드가 평범한 텍스트 속에 섞여 잔뜩 들어 있고, 기록을 공유하려면 먼저 정리해야 해요. 이런 작업에는 정규 표현식이 딱 맞는 도구예요.

유효한 배지 코드는 **대문자 두 개, 대시 하나, 그다음 숫자 네 개**로 이루어져 있어요. 예를 들어 `NS-1024` 같은 코드예요.

## 1. 배지 코드 검사하기

`valid-badge?`를 정의해요. 배지 문자열을 받아서, 문자열 *전체*가 유효한 배지 코드면 `t`를, 아니면 `f`를 반환해요.

```factor
"NS-1024" valid-badge? .   ! => t
"NS-10"   valid-badge? .   ! => f
```

## 2. 로그 줄에서 모든 코드 뽑아내기

`badge-codes`를 정의해요. 출입 기록의 한 줄을 받아서, 그 안에 나타나는 모든 배지 코드를 순서대로 담은 시퀀스를 반환해요.

```factor
"seen NS-1024 then AB-0007 today" badge-codes .
! => { "NS-1024" "AB-0007" }
```

## 3. 코드에 있는 숫자 세기

`digit-count`를 정의해요. 문자열을 받아서 그 안에 숫자가 몇 개 있는지 반환해요.

```factor
"NS-1024" digit-count .   ! => 4
```

## 4. 비밀번호 가리기

기록 줄에는 가끔 비밀번호가 `pass=` 뒤에 비밀값(공백이 아닌 문자가 연속된 부분)이 오는 형태로 적혀 있어요. `redact`를 정의해요. 한 줄을 받아서, 그런 비밀번호를 모두 `pass=****`로 바꾼 줄을 반환해요.

```factor
"user=alice pass=hunter2 ok" redact .
! => "user=alice pass=**** ok"
```
