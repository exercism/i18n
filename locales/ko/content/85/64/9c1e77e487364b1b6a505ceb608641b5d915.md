# 지침

이 연습 문제에서는 프리랜서가 고객과 특정 프로젝트의 가격에 대해 소통할 수 있도록 돕는 코드를 작성해요.
고객의 비용을 빠르게 계산할 수 있는 몇 가지 유틸리티 함수를 작성할 거예요.

```exercism/note
`ratePerHour` 변수와 `dayRate` 함수는 돈과 관련이 있어요.
측정 단위는 단위 시간당 금액이에요. 즉, 각각 시간당 금액과 일당 금액이에요.
```

## 1. 시급으로 일당 계산하기

한 고객이 프리랜서에게 연락해 요금을 문의해요.
프리랜서는 **_하루에 8시간을 일한다고_** 설명해요.
하지만 프리랜서는 프로젝트의 시급만 알고 있어요.
시급을 바탕으로 일당을 추정하도록 도와주세요.

```javascript
dayRate(89);
// => 712
```

일당은 반올림하거나 "고정된" 정밀도로 바꿀 필요가 없어요.

## 2. 고정 예산으로 근무일 수 계산하기

또 다른 날, 한 프로젝트 매니저가 프리랜서에게 고정 예산이 있는 프로젝트를 제안해요.
고정 예산과 프리랜서의 시급이 주어졌을 때, 예산이 모두 소진될 때까지 일하게 될 일수를 계산하도록 도와주세요.
결과는 _반드시_ 가장 가까운 정수로 **내림**해야 해요.

```javascript
daysInBudget(20000, 89);
// => 28
```

## 3. 대규모 프로젝트의 할인 요금 계산하기

프리랜서의 고객들은 여러 달에 걸친 프로젝트를 맡기는 경우가 많아요.
이런 경우 프리랜서는 꽉 찬 한 달마다 할인을 제공하기로 하고, 남은 날은 일당으로 청구해요.
프리랜서는 워라밸이 훌륭해서 달력상 한 달에 22일만 일해요. 그래서 **_모든 달에는 청구 가능한 날이 22일이에요._**
시급, 프로젝트에 포함된 청구 가능한 일수, 월 할인율이 주어졌을 때, 이런 프로젝트의 비용을 추정하도록 도와주세요.
할인율은 항상 숫자로 전달되며, `42%`는 `0.42`가 돼요. 결과는 _반드시_ 가장 가까운 정수로 **올림**해야 해요.

```javascript
priceWithMonthlyDiscount(89, 230, 0.42);
// => 97972
```
