# 설명

charlist는 `~c` 시길을 사용해 만들어요.

```elixir
~c"hello"
```

~~~~exercism/note
Elixir의 예전 버전에서는 charlist를 작은따옴표로 감싼 `'hello'`로 표현했어요.
~~~~

charlist는 정수의 배열이에요. 각 정수는 주어진 문자의 유니코드 값, 즉 코드 포인트를 나타내요.

```elixir
[65, 66, 67]
# => ~c"ABC"
```

## charlist는 _배열_이에요

```elixir
~c"" === []
# => true

is_list(~c"hello")
# => true
```

charlist는 배열이기 때문에 다른 배열과 똑같이 다룰 수 있어요. 재귀와 패턴 매칭을 사용하거나 [`List`][list] 모듈을 사용하면 돼요.

```elixir
[first_letter | _] = ~c"cat"
first_letter
# => 99

List.first(~c"hello")
# => 104
List.pop_at(~c"hello", 0)
# => {104, ~c"ello"}

```

두 배열은 [`++`][kernel-concat-list]를 사용해 이어 붙일 수 있어요.

```elixir
~c"hi" ++ ~c"!"
# => ~c"hi!"
```

첫 번째 배열이 길수록 이어 붙이는 속도가 느려지므로, 길이를 알 수 없는 배열에 요소를 반복해서 추가하는 것은 피해야 해요.

## 출력 가능성

정수 배열이 출력 가능한 문자의 코드 포인트만 담고 있으면 charlist로 표시돼요. `[]` 문법으로 정의했더라도 마찬가지예요.

```elixir
~c"ABC"
# => ~c"ABC"

[65, 66, 67]
# => ~c"ABC"
```

정수 배열이 출력할 수 없는 문자의 코드 포인트를 단 하나라도 담고 있으면 (예: `0-6`, `14-26`, `28-31`) 배열로 표시돼요. `~c""` 문법으로 정의했더라도 마찬가지예요.

```elixir
~c"ABC\0"
# => [65, 66, 67, 0]

[65, 66, 67, 0]
# => [65, 66, 67, 0]
```

출력 가능 여부는 [`List.ascii_printable?`][list-ascii-printable]로 확인할 수 있어요.

```elixir
List.ascii_printable?([65, 66, 67])
# => true
List.ascii_printable?([65, 66, 67, 0])
# => false
```

이 둘은 같은 데이터를 _표시_하는 서로 다른 방식일 뿐이라는 점을 기억해요. 값 자체는 완전히 같아요.

```elixir
~c"ABC" === [65, 66, 67]
# => true
```

[`IO.inspect`][io-inspect]로 배열을 출력할 때 [`:charlists`][inspect-opts] 옵션을 사용하면 배열이 출력되는 방식을 제어할 수 있어요.

```elixir
IO.inspect(~c"ABC", charlists: :as_charlists)
# => prints ~c"ABC"

IO.inspect(~c"ABC", charlists: :as_lists)
# => prints [65, 66, 67]
```

## 코드 포인트

문자 앞에 `?`를 붙이면 그 문자의 코드 포인트를 얻을 수 있어요.

```elixir
?A
# => 65

[?:, ?)]
# => ~c":)"
```

## charlist와 문자열

같은 문자로 이루어진 charlist와 문자열은 서로 같다고 여겨지지 않아요.

```elixir
~c"hello" == "hello"
false
```

charlist의 각 값은 [문자의 유니코드 코드 포인트][unicode-table]이고, 문자열에서는 코드 포인트가 [UTF-8][utf8]로 인코딩돼요.

```elixir
IO.inspect(~c"tschüss", charlists: :as_lists)
# => prints [116, 115, 99, 104, 252, 115, 115]

IO.inspect("tschüss", binaries: :as_binaries)
# => prints <<116, 115, 99, 104, 195, 188, 115, 115>>
```

코드 포인트 `252`인 `ü`가 UTF-8에서 `195`와 `188`로 인코딩되는 것에 주목해요.

**실제로 charlist는 거의 사용되지 않아요**. 주된 용도는 Erlang과 연동하는 것, 특히 바이너리를 인자로 받지 않는 오래된 라이브러리를 사용할 때예요.

Elixir로 작업할 때는 **텍스트를 저장할 때 문자열을 사용해요**. `String` 모듈은 텍스트를 처리하는 다양한 함수를 제공하는데, 이런 함수는 charlist에는 없어요.

charlist는 [`to_string`][kernel-to-string]으로 문자열로 변환할 수 있어요.

```elixir
to_string(~c"hello")
# => "hello"
```
