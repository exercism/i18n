그런데 좀 엉망이에요. Azara의 좌표는 Rui의 좌표와 형식도, 정렬 순서도 달라 보여서, 어떤 보물이 어느 장소에 해당하는지 알아내려면 두 목록을 번갈아 계속 들여다봐야 해요.
Julia를 막 배우기 시작한 두 사람은 탐사 정보를 더 잘 정리할 작은 프로그램(정확히는 함수 몇 개)을 작성하는 데 도움을 받고자 여러분에게 찾아왔어요.

## 1. 좌표 추출하기

Azara의 목록에서 `(treasure, coordinate)` 쌍을 받아 추출한 지도 좌표만 반환하는 `get_cooordinate()` 함수를 구현해요.

```julia-repl
julia> get_cooordinate( ("Scrimshaw Whale's Tooth", "2A") )
"2A"
```

## 2. 좌표 형식 맞추기

"2A" 형식의 좌표를 받아 `('2', 'A')` 형식의 튜플을 반환하는 `convert_coordinate()` 함수를 구현해요.

```julia-repl
julia> convert_coordinate("2A")
('2', 'A')
```

## 3. 좌표 일치 확인하기

`(treasure, coordinate)` 쌍과 `(location, coordinate, quadrant)` 레코드를 받아 각각의 좌표를 비교하는 `compare_records()` 함수를 구현해요.
좌표가 일치하면 **`true`**를, 일치하지 않으면 **`false`**를 반환해요.
정확하게 비교하려면 좌표 형식을 필요에 따라 다시 맞춰요.

```julia-repl
julia> compare_records(("Brass Spyglass", "4B"), ("Seaside Cottages", ('1', 'C'), "blue"))
false

julia> compare_records(("Model Ship in Large Bottle", "8A"), ("Harbor Managers Office", ('8', 'A'), "purple"))
true
```

## 4. 일치하는 레코드 합치기

Azara의 목록에서 `(treasure, coordinate)` 쌍을, Rui의 목록에서 `(location, coordinate, quadrant)` 레코드를 받아, **좌표가 일치하면** `(coordinate, location, quadrant, treasure)`를 반환하는 `create_record()` 함수를 구현해요.

좌표가 _일치하지 않으면_ 빈 튜플을 반환해요.
정확하게 비교하려면 좌표 형식을 필요에 따라 다시 맞춰요.

```julia-repl
julia> create_record(("Brass Spyglass", "4B"), ("Abandoned Lighthouse", ('4', 'B'), "Blue"))
("4B", "Abandoned Lighthouse", "Blue", "Brass Spyglass")

julia> create_record(("Brass Spyglass", "4B"), ("Seaside Cottages", ('1', 'C'), "Blue"))
()
```
