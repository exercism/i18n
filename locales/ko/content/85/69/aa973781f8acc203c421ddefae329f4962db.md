# 소개

## 숫자

Java에는 두 가지 종류의 숫자가 있어요.

- 정수: 소수점 뒤에 숫자가 없는 수(소수 부분이 없는 수)예요.
  예를 들어 `-6`, `0`, `1`, `25`, `976`, `-500000` 등이 있어요.
- 실수: 소수점 뒤에 0개 이상의 숫자가 있는 수예요.
  예를 들어 `-20.4`, `0.1`, `2.72`, `16.984025`, `1024.0` 등이 있어요.

Java에서 가장 흔히 쓰는 숫자 타입은 `int`와 `double`이에요.
`int`는 32비트 정수이고, `double`은 64비트 실수예요.

산술 계산에는 표준 산술 연산자를 사용해요.
숫자는 표준 숫자 비교 연산자(예: `5 > 4`, `4 <= 5`)와 동등(`==`) 및 비동등(`!=`) 연산자로 비교할 수 있어요.

Java에는 두 가지 숫자 변환 방식이 있어요.

1. 암시적 변환: 데이터가 손실되지 않고, 별도의 문법이 필요 없어요.
2. 명시적 변환: 데이터가 손실될 수 있고, _캐스트_ 형태의 별도 문법이 필요해요.

`int`는 `double`보다 정밀도가 낮기 때문에, `int`를 `double`로 변환하는 것은 안전하고 따라서 암시적 변환이에요.
반면 `double`을 `int`로 변환하면 데이터가 손실될 수 있어서 명시적 변환이 필요해요.

## If-Else 문

### _if-then_ 문

Java에서 가장 기본적인 제어 흐름 문은 _if-then_ 문이에요.
이 문은 특정 조건이 `true`일 때만 코드의 일부분을 실행할 때 사용해요.
_if-then_ 문은 `if` 절을 사용해 정의해요.

```java
class Car {
    void drive() {
        // the "if" clause: the car needs to have fuel left to drive
        if (fuel > 0) {
            // the "then" clause: the car drives, consuming fuel
            fuel--;
        }
    }
}
```

위 예제에서 차에 연료가 없으면, `Car.drive` 메서드를 호출해도 아무 일도 일어나지 않아요.

### _if-then-else_ 문

_if-then-else_ 문은 `if` 절의 조건이 `false`로 평가될 때 실행할 다른 경로를 제공해요.
이 대체 실행 경로는 `if` 절 뒤에 오며, `else` 절로 정의해요.

```java
class Car {
    void drive() {
        if (fuel > 0) {
            fuel--;
        } else {
            stop();
        }
    }
}
```

위 예제에서 차에 연료가 없으면, `Car.drive` 메서드를 호출하면 차를 멈추는 다른 메서드를 호출해요.

_if-then-else_ 문은 `else if` 절을 사용해 여러 조건을 지원하기도 해요.

```java
class Car {
    void drive() {
        if (fuel > 5) {
            fuel--;
        } else if (fuel > 0) {
            turnOnFuelLight();
            fuel--;
        } else {
            stop();
        }
    }
}
```

위 예제에서 연료가 `5` 이하일 때 차를 운전하면 차는 계속 달리지만, 연료 경고등이 켜져요.
연료가 `0`이 되면 차는 멈춰요.
