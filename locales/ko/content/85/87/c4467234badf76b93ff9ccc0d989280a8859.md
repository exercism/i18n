# 소개

*disposable*은 OS 자원, 이를테면 열린 파일이나 소켓, 해시 테이블로 구현된 잠금 같은 것을 붙들고 있는 대상이고, 다 쓰고 나면 반드시 해제해야 해요. Factor의 [`destructors`][destructors] vocab은 이런 자원들을 작은 프레임워크로 감싸서, 예외가 스택을 되감는 상황에서도 정리가 이뤄지게 해줘요.

```factor
USING: destructors io.files io.encodings.utf8 ;

"log.txt" utf8 <file-writer> [
    "hello, world" write
] with-disposal
! file is closed even if write throws
```

`with-disposal ( disposable quot -- )`의 경우, 자원과 함께 quotation을 실행하고 빠져나갈 때 자원을 해제해요. 자원이 여러 개라면 `with-destructors`를 써서 스코프를 열고, 각각을 `&dispose`(정상 종료와 오류 시 *모두* 해제) 또는 `|dispose`(오류 시에만 해제)로 등록해요.

클래스는 `disposable`을 확장하고 `dispose*` 제네릭을 구현하는 것으로 이 프레임워크에 참여해요. 프레임워크는 객체마다 `dispose*`를 딱 한 번만 호출해요. 호출하는 쪽에서 쓰는 공개 word는 `dispose`예요.

[destructors]: https://docs.factorcode.org/content/vocab-destructors.html
