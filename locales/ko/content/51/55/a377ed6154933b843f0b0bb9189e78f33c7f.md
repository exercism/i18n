# 소개

루프는 문 묶음을 반복해서 실행하는 방법이에요.
문 묶음을 한 번 실행하는 것을 반복이라고 해요.

## `while`문

`while`문은 루프 위쪽의 불리언 표현식이 참인 동안 문 묶음을 실행해요.
불리언 표현식이 거짓이면 루프는 실행을 멈추고, 실행은 루프 다음 줄의 코드로 넘어가요.

처음부터 불리언 표현식이 거짓으로 평가되면 `while`문은 전혀 실행되지 않고, 실행은 루프 다음 줄의 코드로 넘어가요.

```c
int main() {
    int i = 0;
    while (i < 5) {
        printf("Number is %i\n", i++);
    }    
    return 0;
}
```

루프를 끝내는 조건이 있어야 해요. 그렇지 않으면 무한 루프가 되어 코드의 진행을 막아요.
위 코드에서 `i`에서 `++`를 제거하면 무한 루프가 돼요.

## `do`문

`do`문은 루프 아래쪽에서 불리언 표현식을 검사해요.
`do`문은 항상 적어도 한 번은 실행돼요. 다음 예시처럼요.

```c
do {
    printf("Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
} while (answer != 42); 
// Note that a semicolon is needed after the Boolean expression.
```

`while`문으로 하면 더 장황해져요.

```c
printf(""Enter the Answer to the Ultimate Question of Life: ");
scanf("%d", &answer);
while (answer != 42) {
    printf(""Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
}
```

## `for`문

종종 루프는 변수를 갱신하고, 변수가 특정 값에 도달하면 끝나요.
`for`문은 괄호 안에 한 줄로 하나 이상의 변수를 초기화하고, 갱신하고, 검사하는 방법이에요.
첫 번째 부분은 변수 초기화를 위한 것이고, 두 번째 부분은 변수 검사를 위한 것이며, 세 번째 부분은 변수 값 갱신을 위한 것이에요.

```c
for (int i = 0; i < 5; i++) {
    printf("Number is %i\n", i);
}
```

이것은 `while`문에 해당하는 것보다 덜 장황하면서도 여전히 읽기 쉬워요.
