# 소개

`Agent` 모듈은 [프로세스와 _수신-송신_ 루프][exercism-processes]를 만들어 내기 위한 추상화를 제공해요. 이제부터 `Agent` 모듈로 시작한 프로세스를 _'에이전트 프로세스'_ 라고 불러요. _에이전트 프로세스_ 는 중앙에서 공유되는 상태를 나타내기 위해 선택될 수 있어요.

_에이전트 프로세스_ 를 시작하려면 `Agent`가 `start/2` 함수를 제공해요. _에이전트 프로세스_ 를 `start`할 때 넘겨주는 함수는 프로세스의 초기 상태를 반환해요:

```elixir
# Start an agent process with an initial value of an empty list
{:ok, agent_pid} = Agent.start(fn -> [] end)
```

`Map`이나 `List`처럼, `Agent`도 _에이전트 프로세스_ 를 다루기 위한 많은 함수를 제공해요.

모델링하는 도메인을 위한 모듈에 `Agent` 관련 기능을 모두 모아 캡슐화하는 것이 일반적이에요.

[exercism-processes]: https://exercism.org/tracks/elixir/concepts/processes
