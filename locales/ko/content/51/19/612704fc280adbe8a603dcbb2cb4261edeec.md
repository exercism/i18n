# 개요

Factor의 시퀀스는 *수정*해야 할 때 두 가지 종류로 나뉘어요:

- **배열**(`{ … }`)은 길이가 고정되어 있어요. `set-nth`나 `change-nth`로 각 위치에 *있는* 값을 바꿀 수는 있지만, 길이를 늘리거나 줄일 수는 없어요.
- **벡터**(`V{ … }`)는 길이가 가변적이에요. `push`는 끝에 원소를 추가하고, `pop`은 마지막 원소를 제거해서 반환해요.

```factor
USING: arrays kernel sequences ;

! Fixed-length: build a counter array of zeros, then bump one slot.
3 0 <array>            ! { 0 0 0 }
dup [ 1 + ] 1 rot change-nth
.                      ! { 0 1 0 }

! Variable-length: build a vector of names by pushing.
V{ } clone
"alice" over push
"bob" over push
dup pop drop           ! removes "bob"
.                      ! V{ "alice" }
```

| 단어            | 동작                                           |
|-----------------|------------------------------------------------|
| `<array>`       | `( n elt -- array )`, `elt`를 `n`개 복사한 배열을 만들어요 |
| `<vector>`      | `( n -- vector )`, 용량이 `n`인 빈 벡터를 만들어요 |
| `V{ }`          | 빈 벡터 리터럴이에요                            |
| `set-nth`       | `( elt n seq -- )`, 인덱스 `n`의 원소에 값을 할당해요 |
| `change-nth`    | `( i seq quot -- )`, `i` 위치의 원소에 `quot`를 적용해요 |
| `push`          | `( elt seq -- )`, 벡터 끝에 원소를 덧붙여요     |
| `suffix!`       | `( seq elt -- seq )`, 제자리에서 덧붙이고 벡터를 반환해요 |
| `pop`           | `( seq -- elt )`, 마지막 원소를 제거해서 반환해요 |
| `pop*`          | `( seq -- )`, 마지막 원소를 제거하고 버려요     |
| `clone`         | `( obj -- copy )`, 독립적인 새 복사본을 만들어요 |
| `new-sequence`  | `( n exemplar -- newseq )`, `exemplar`와 같은 클래스의 새 시퀀스를 만들어요 |
| `new-resizable` | `( n exemplar -- newseq )`, 크기를 바꿀 수 있는 새 변형을 만들어요 |

호출자가 넘겨준 시퀀스를 변경하면 그 변경은 호출자에게도 그대로 보여요. 호출자도 같은 객체를 들고 있기 때문이에요. 그게 원하는 게 아니라면, 먼저 `clone`으로 독립적인 복사본을 만들면 돼요.
