# 소개

## Pair

`Pair`는 두 항목을 하나로 묶은 것뿐이에요.
그 두 항목에는 각각 `first`와 `second`라는 그럴듯한 이름이 붙어요.

`=>` 연산자나 `Pair()` 생성자로 만들 수 있어요.

```julia-repl
julia> p1 = "k" => 2
"k" => 2

julia> p2 = Pair("k", 2)
"k" => 2

# Both forms of syntax give the same result
julia> p1 == p2
true

# Each component has its own separate type
julia> dump(p1)
Pair{String, Int64}
  first: String "k"
  second: Int64 2

# Get a component using dot syntax
julia> p1.first
"k"

julia> p1.second
2
```

## Dict

Pair의 `Vector`는 다른 배열과 마찬가지예요. 순서가 있고, 타입이 모두 같으며, 메모리에 연속해서 저장돼요.

```julia-repl
julia> pv = ['a' => 1, 'b' => 2, 'c' => 3]
3-element Vector{Pair{Char, Int64}}:
 'a' => 1
 'b' => 2
 'c' => 3

# Each pair is a single entry
julia> length(pv)
3
```

`Dict`는 겉보기에는 비슷하지만, 항목 수가 많아져도 키로 값을 빠르게 찾을 수 있는 방식으로 저장돼요.

```julia-repl
julia> pd = Dict('a' => 1, 'b' => 2, 'c' => 3)
Dict{Char, Int64} with 3 entries:
  'a' => 1
  'c' => 3
  'b' => 2

julia> pd['b']
2

# Key must exist
julia> pd['d']
ERROR: KeyError: key 'd' not found

# Generators are accepted in the constructor (and note the unordered output)
julia> Dict(x => 1 / x for x in 1:5)
Dict{Int64, Float64} with 5 entries:
  5 => 0.2
  4 => 0.25
  2 => 0.5
  3 => 0.333333
  1 => 1.0
  ```

다른 언어에서는 `Dict`와 아주 비슷한 것을 딕셔너리(Python), 해시(Ruby), 해시맵(Java)이라고 불러요.

Pair는 단독으로 쓰이든 `Vector` 안에 쓰이든, 각 구성 요소의 타입에 제약이 거의 없어요.

`Dict`에서 유효하려면 `Pair`가 `key => value` 쌍이어야 하고, `key`는 "hashable"해야 해요.
무엇보다 중요한 것은 `key`가 _불변_이어야 한다는 점이에요. 그래서 `Char`, `Int`, `String`, `Symbol`, `Tuple`은 모두 괜찮지만 `Vector`는 허용되지 않아요.

### Dict 수정하기

새 키로 항목을 추가하거나, 기존 키로 덮어쓸 수 있어요.

```julia-repl
julia> pd
Dict{Char, Int64} with 3 entries:
  'a' => 1
  'c' => 3
  'b' => 2

# Add
julia> pd['d'] = 4
4

# Overwrite
julia> pd['a'] = 42
42

julia> pd
Dict{Char, Int64} with 4 entries:
  'a' => 42
  'c' => 3
  'd' => 4
  'b' => 2
```

항목을 삭제하려면 `delete!()` 함수를 사용해요. 키가 있으면 Dict를 바꾸고, 없으면 아무 일도 하지 않아요.

```julia-repl
julia> delete!(pd, 'd')
Dict{Char, Int64} with 3 entries:
  'a' => 42
  'c' => 3
  'b' => 2
```

### 키나 값이 있는지 확인하기

여러 가지 방법이 있어요.
키를 확인하려면 `haskey()` 함수를 써요.

```julia-repl
julia> haskey(pd, 'b')
true
```

또는 키나 값 쪽에서 찾을 수도 있어요.

```julia-repl
julia> 'b' in keys(pd)
true

julia> 43 in values(pd)
false

julia> 42 ∈ values(pd)
true
```
