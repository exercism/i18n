# 소개

charlist는 `~c` 시길을 사용해 만들어요.

```elixir
~c"hello"
```

~~~~exercism/note
Elixir의 옛 버전에서는 charlist를 작은따옴표를 써서 `'hello'`와 같이 나타냈어요.
~~~~

문자열과 아주 비슷해 보이지만, 이 두 자료형은 서로 꽤 달라요. charlist는 정수의 배열이에요. 이 정수는 주어진 문자의 유니코드 값을 나타내는데, 이 값을 코드 포인트라고도 불러요.

```elixir
[65, 66, 67]
# => ~c"ABC"
```

문자 앞에 `?` 기호를 붙이면 그 문자의 코드 포인트를 얻을 수 있어요.

```elixir
?A
# => 65

[?:, ?)]
# => ~c":)"
```

charlist는 배열이기 때문에, 다른 배열과 똑같이 재귀와 패턴 매칭을 사용해 다룰 수 있어요.

```elixir
[first_letter | _] = ~c"cat"
first_letter
# => 99
```

`++` 연산자로 두 배열을 이어 붙일 수 있어요.

```elixir
~c"hi" ++ ~c"!"
# => ~c"hi!"
```

첫 번째 배열이 길수록 이어 붙이는 속도가 느려져요. 그러니 길이가 제각각인 배열에 요소를 반복해서 덧붙이는 것은 피해요.
