# 소개

## null 허용성

Java에서 `null` 리터럴은 값이 없음을 나타내는 데 사용해요.

Java의 기본형은 모두 기본값을 가지고 있어서 절대 `null`이 될 수 없어요.
관례적으로 기본형은 소문자로 시작해요. 예를 들어 `int`가 있어요.

참조형은 객체의 메모리 주소를 담고 있으며 `null` 값을 가질 수 있어요.
참조형은 일반적으로 대문자로 시작해요. 예를 들어 `String`이 있어요.

기본형 변수에 `null` 값을 할당하려고 하면 컴파일 오류가 발생해요. 변수는 항상 할당된 타입의 기본형 값을 가지기 때문이에요.

```java
//Throws compile time error stating the required type is int, but null was provided
int number = null;
```

참조형 변수에 `null` 값을 할당해도 컴파일 오류가 발생하지 않아요. 참조형 변수는 null을 허용하기 때문이에요.

```java
//No error will occur as the String variable str is nullable
String str = null;
```
