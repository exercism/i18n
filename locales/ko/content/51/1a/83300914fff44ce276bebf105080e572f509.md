# match 기초

`match` 표현식을 사용하면 하나의 값을 여러 패턴과 손쉽게 비교하고, 일치한 패턴에 따라 코드를 실행할 수 있어요.
리터럴 값, 변수 이름, 와일드카드 등 여러 가지가 패턴을 이루는 요소예요.

```rust
#[derive(Drop)]
enum Color {
    Red,
    Yellow,
    Green,
}

fn print_color_type(color: Color) {
    match color {
        Color::Red => println!("The color is Red"),
        Color::Yellow => println!("The color is Yellow"),
        Color::Green => println!("The color is Green"),
    }
}

fn main() {
    let color = Color::Yellow;
    print_color_type(color); // prints "The color is Yellow"
}
```

여러 줄의 코드를 처리하려면 `match`의 코드 갈래를 중괄호 `{}`로 감싸야 해요:

```rust
fn specified_color(color: Color) -> felt252 {
    let mut response: felt252 = '';

    match color {
        Color::Red => {
            response = 'You passed in Red';
        },
        Color::Yellow => {
            response = 'You passed in Yellow';
        },
        Color::Green => {
            response = 'You passed in Green';
        },
    }

    response
}
```

`match` 표현식에는 패턴과 일치하는 값에 바인딩하는 기능도 있어요.
덕분에 열거형 배리언트에 연관된 값을 추출할 수 있어요.

```rust
#[derive(Drop, Debug)]
enum ColorType {
    Light,
    Dark,
}

#[derive(Drop)]
enum Color {
    Red: ColorType,
    Yellow,
    Green,
}

fn print_color_type(color: Color) {
    match color {
        Color::Red(state) => {
            println!("The color is Red");
            println!("The Color Type is {:?}", state);
        },
        Color::Yellow => println!("The color is Yellow"),
        Color::Green => println!("The color is Green"),
    }
}

fn main() {
    let color = Color::Red(ColorType::Dark);
    print_color_type(color);
}
```

`Color` 열거형의 `Red` 배리언트가 연관된 열거형을 갖도록 확장해 봤어요.
`match` 표현식의 도움을 받아 연관된 값인 `state`를 추출할 수 있어요.
`state`는 코드 갈래 안에서 이후에 사용할 수 있는 변수 이름일 뿐이에요.

## `Option` 열거형 타입 매칭하기

내장된 `Option` 열거형도 `match` 표현식으로 다룰 수 있어요.

`Option<u8>` 매개변수를 받는 함수를 설계해 봐요.
전달받은 매개변수에 값이 있으면 그 값에 1을 더하고, 그렇지 않으면 아무 작업도 하지 않고 `None` 값을 반환해야 해요.

```rust
fn add_one(x: Option<u8>) -> Option<u8> {
    match x {
        Option::Some(val) => Option::Some(val + 1),
        Option::None => Option::None,
    }
}

fn main() {
    let three: Option<u8> = Option::Some(3);
    let four: Option<u8> = add_one(three);
    let none = add_one(Option::None);

    println!("{three:?}"); // prints "Option::Some(3)"
    println!("{four:?}"); // prints "Option::Some(4)"
    println!("{none:?}"); // prints "Option::None(())"
}
```

> 참고: `{:?}`는 `println!` 매크로에 전달된 매개변수의 디버그 형태를 출력할 수 있게 해주는 특별한 서식 문법이에요.
> 자세한 내용은 [The Cairo Book][debugging]에서 확인할 수 있어요.

`match` 제어 흐름을 사용할 때의 한 가지 장점은 모든 경우를 빠짐없이 다룬다는 점이에요. 각 갈래의 패턴은 _모든_ 가능성을 다뤄야 해요.
`None` 경우를 다루지 않은 이전 예제의 버전을 살펴봐요:

```rust
fn add_one(x: Option<u8>) -> Option<u8> {
    match x {
        Option::Some(val) => Option::Some(val + 1),
    }
     // this code does not compile, as we forgot to handle the `None` case
}
```

## `_` 와일드카드를 사용한 포괄 패턴

열거형을 사용할 때, 몇몇 특정 값에 대해서는 특별한 동작을 하고 나머지 모든 값에 대해서는 하나의 기본 동작을 수행하고 싶다면, match 표현식의 마지막 갈래로 `_`를 패턴으로 하는 갈래를 추가하면 돼요.
`_` 패턴은 어떤 값과도 일치하면서 그 값에 바인딩하지는 않는 특별한 패턴이에요.

`is_red` 함수는 매개변수를 받아 색이 `Red`이면 `true`를, 그 밖의 색이면 `false`를 반환해요:

```rust
fn is_red(color: Color) -> bool {
    match color {
        Color::Red => true,
        _ => false,
    }
}
```

## `|` 연산자를 사용한 패턴 매칭

Cairo의 `match` 제어 흐름 구문은 `|` (_or_) 연산자를 사용해 하나의 값을 여러 패턴과 매칭할 수 있어요.
이 덕분에 코드를 더 간결하게 만들 수 있어요.

예를 들어 `Color` 열거형을 사용해, `Red` 또는 `Green` 색에 대해서는 `true`를 반환하고 다른 색에 대해서는 `false`를 반환하는 함수를 작성한다고 해봐요:

```rust
fn is_red_or_green(color: Color) -> bool {
    match color {
        Color::Red | Color::Green => true,
        _ => false,
    }
}
```

## `felt252`와 정수 변수를 사용한 패턴 매칭

`felt252`와 정수 변수를 여러 값 집합과 매칭하는 것도 가능해요.
다만 몇 가지 제약이 있어요.

- 하나의 `felt252`에 들어가는 정수만 지원해요 (즉, `u256`은 지원하지 않아요).
- 0이 첫 번째 갈래여야 해요.
- 각 갈래는 다른 갈래들과 연속된 순차 구간을 이뤄야 해요.

주사위를 던지는 게임을 만들어 봐요.
이 주사위를 던지면 0에서 5 사이의 숫자가 나와요.
0, 1, 2가 나오면 이기고, 3이 나오면 다시 던질 수 있어요.
그 밖의 값이면 져요:

```rust
fn toss(value: u8) {
    match value {
        0 | 1 | 2 => println!("you won!"),
        3 => println!("you can roll again!"),
        _ => println!("you lost...")
    }
}

fn main() {
    toss(2); // prints "you won!".
    toss(3); // prints "you can roll again!".
    toss(5); // prints "you lost...".
}
```

## 튜플 매칭

튜플도 여러 패턴과 매칭할 수 있어요.
이런 패턴은 튜플과 비슷한 방식으로 작성해요.

```rust
#[derive(Drop)]
enum DayType {
    Week,
    Weekend,
    Holiday
}

enum Coin {
    Penny,
    Nickel,
    Dime,
    Quarter,
}

fn vending_machine_accept(c: (DayType, Coin)) -> bool {
    match c {
        (DayType::Week, _) => true, // accepts all coins during week day
        (_, Coin::Dime) | (_, Coin::Quarter) => true, // accepts only Dime or Quarter coin for all specified days
        (_, _) => false, // returns false for other instances
    }
}
```

마지막 match 갈래에서는 어떤 요일과 색 조합을 매칭하든 `(_, _)`를 쓰든 `_` 와일드카드만 쓰든 상관없어요. 기능적으로 같기 때문이에요.
