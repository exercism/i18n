# 지시 사항

이 연습 문제에서는 드디어 돈을 모아서 장만한 무선 조종 자동차를 가지고 놀아볼 거예요.

자동차는 완전히 충전된(100%) 배터리로 시작해요. 리모컨으로 자동차를 조종할 때마다 20미터를 이동하고 배터리가 1퍼센트 줄어들어요.

무선 조종 자동차에는 두 가지 정보를 표시하는 멋진 LED 디스플레이가 있어요:

- 지금까지 주행한 총 거리, 표시 형식: `"Driven <METERS> meters"`.
- 남은 배터리 잔량, 표시 형식: `"Battery at <PERCENTAGE>%"`.

배터리가 0%가 되면 더 이상 자동차를 주행할 수 없고, 배터리 표시에는 `"Battery empty"`가 나타나요.

여섯 개의 작업이 있어요. 각 작업에서는 무선 조종 자동차 인스턴스를 다뤄요.

## 1. 새 무선 조종 자동차 구입하기

새 무선 조종 자동차 인스턴스를 반환하도록 (_static_) `RemoteControlCar.Buy()` 메서드를 구현해요:

```csharp
RemoteControlCar car = RemoteControlCar.Buy();
```

## 2. 주행 거리 표시하기

LED 디스플레이에 표시되는 거리를 반환하도록 `RemoteControlCar.DistanceDisplay()` 메서드를 구현해요:

```csharp
var car = RemoteControlCar.Buy();
car.DistanceDisplay();
// => "Driven 0 meters"
```

## 3. 배터리 잔량 표시하기

LED 디스플레이에 표시되는 배터리 잔량을 반환하도록 `RemoteControlCar.BatteryDisplay()` 메서드를 구현해요:

```csharp
var car = RemoteControlCar.Buy();
car.BatteryDisplay();
// => "Battery at 100%"
```

## 4. 주행할 때 주행 거리 업데이트하기

주행 거리를 업데이트하는 `RemoteControlCar.Drive()` 메서드를 구현해요:

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
car.DistanceDisplay();
// => "Driven 40 meters"
```

## 5. 주행할 때 배터리 잔량 업데이트하기

배터리 잔량을 업데이트하도록 `RemoteControlCar.Drive()` 메서드를 업데이트해요:

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
car.BatteryDisplay();
// => "Battery at 98%"
```

## 6. 배터리가 방전되면 주행하지 못하게 하기

배터리가 방전되었을 때(0%) 주행 거리를 늘리지도 않고 배터리 잔량을 줄이지도 않도록 `RemoteControlCar.Drive()` 메서드를 업데이트해요:

```csharp
var car = RemoteControlCar.Buy();

// Drain the battery
// ...

car.DistanceDisplay();
// => "Driven 2000 meters"

car.BatteryDisplay();
// => "Battery empty"
```
