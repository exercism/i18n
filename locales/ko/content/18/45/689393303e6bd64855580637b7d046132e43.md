# 로컬에서 디버깅하기

[Bats](https://github.com/bats-core/bats-core)로 Bash 트랙 테스트를 실행하면, Bats는 출력 검증을 위해 STDOUT과 STDERR 모두를 캡처해요.

```exercism/caution
로컬에서는 `bats`로 잘 작동하지만, Exercism 온라인 에디터에서는 **작동하지 않아요**.
```

테스트 결과에 영향을 주지 않으면서 디버그 출력을 보고 싶다면, 파일 디스크립터(fd) 3에 써요.

```bash
echo 'debug message' >&3
```

Bats는 테스트를 실행하는 동안 fd 3에 쓰인 출력을 보여주지만, `assert_output` 같은 검증에는 그 출력을 포함하지 않아요.

실행 예시:

```none
$ bats hello_world.bats
hello_world.bats
 ✓ Say Hi!
debug message
1 test, 0 failures
```

이 방법은 로컬에서 테스트를 실행할 때 유용해요.
