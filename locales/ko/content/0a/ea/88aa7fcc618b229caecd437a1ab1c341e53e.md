# 지시 사항

작은 가구 공방에서 견습으로 일하고 있어요. 목수 스승의 태블릿에는 Factor가 돌아가고 있고, 재단 목록을 관리해요. 작업대에 올라오는 모든 판자는 첫 재단을 하기 전에 몇 가지 파생 값으로 치수를 계산해요.

이전 견습생은 코드를 `dup`, `over`, `swap`, `rot`이 우거진 정글처럼 남겨 놨어요. 할 일은 다섯 개의 작은 단어를 *컴비네이터*로 다시 작성하는 거예요.

각 판자는 스택에 원래 길이(cm)만 올라온 상태로 작업 흐름에 들어가요.

## 1. 톱자국 여유 더하기

톱날은 자를 때마다 나무에서 얇은 조각을 떼어 내는데, 이를 *톱자국*이라고 해요. 공방은 이를 감안해 모든 판자에 2%의 여유 길이를 더 잡아요.

`with-kerf`는 길이를 받아서 그 길이에 2%의 톱자국 여유를 더한 값을 반환하도록 정의해요.

```factor
100 with-kerf .
! => 102
```

## 2. 톱자국 여유와 마무리 여유 계산하기

재단이 끝나면 사포질과 대패질 같은 마무리 작업이 이어지는데, 이 과정에서 원래 길이의 5%가 더 없어져요.

`kerf-and-finish`는 *두* 여유를 나란히 반환하도록 정의해요. 톱자국 여유가 아래, 마무리 여유가 위예요.

```factor
100 kerf-and-finish .s
! => 2
! => 5
```

## 3. 재단 카드 만들기

스승이 재단하는 모든 판자에는 작은 카드가 붙어요. 카드에는 원래 길이, 톱자국 여유, 마무리 여유가 이 순서대로 세 개의 숫자로 적혀요.

`cut-card`는 이 세 값을 모두 반환하도록 정의해요.

```factor
100 cut-card .s
! => 100
! => 2
! => 5
```

## 4. 조각 하나의 길이

공방에는 같은 크기로 나눠야 하는 *원목 토막*도 대량으로 들어와요. 원목 토막의 길이에 톱자국 여유를 한 번 더한 다음, 그 결과를 조각 수로 나눠요.

`per-piece`는 원목 토막의 길이와 조각 수를 받아서 조각 하나의 길이를 반환하도록 정의해요. 조각 수는 스택 맨 위에 있어요.

```factor
100 2 per-piece .
! => 51

100 4 per-piece .
! => 25+1/2
```

## 5. 두 원목 토막 비교하기

가끔 스승은 목재 야적장에서 두 원목 토막 중 하나를 고르면서, 두 토막의 톱자국 여유를 한눈에 비교하고 싶어 해요.

`compare-bolts`는 스택에서 길이 두 개를 꺼내서 각각의 톱자국 여유를 같은 순서로 반환하도록 정의해요.

```factor
50 100 compare-bolts .s
! => 1
! => 2
```
