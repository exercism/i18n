# `main` 메서드를 사용하지 마세요

코드에서 `main` 메서드를 제거해 보세요.
연습 문제의 테스트는 해답에 `main` 메서드가 있어야 한다고 요구하지 않아요. 오히려 `main` 메서드가 있으면 코드를 읽기가 조금 더 어려워져요.

보통 `main` 메서드는 코드를 디버깅하는 데 도움이 되라고 추가해요.
하지만 더 좋은 방법은 단위 테스트를 하나 이상 실행하면서 코드를 디버깅하는 거예요.
이렇게 하면 특정 테스트 케이스에 집중해서 디버깅할 수 있다는 장점도 있어요.

다양한 IDE에서 단위 테스트를 실행하면서 Java 코드를 디버깅하는 방법을 설명하는 링크들이에요:

- [Visual Studio Code에서 Java 테스트 실행하고 디버깅하기](https://code.visualstudio.com/docs/java/java-testing#_rundebug-test-cases)
- [IntelliJ IDEA에서 테스트 디버깅하기](https://www.jetbrains.com/help/idea/performing-tests.html#RedebugFailedTests)
