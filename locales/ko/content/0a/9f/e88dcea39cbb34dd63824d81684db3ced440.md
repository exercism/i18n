# 소개

## 기초 1

### 상수와 함수

상수 값은 `name = expression`으로 정의해요.
Elm에서는 정의를 제외한 모든 것이 표현식이거든요.

```elm
five = 5

six = 3 + 3
```

함수는 `name parameters... = expression`으로 정의하고,
매개변수는 공백으로만 구분해요.

```elm
add number1 number2 = number1 + number2
```

함수를 호출하는 것도 표현식이에요.
함수의 이름을 쓰고 각 매개변수에 대응하는 인자를 전달하면 되는데,
함수를 정의할 때처럼 공백으로 구분해요.

```elm
five = add 2 3
```

괄호를 사용하면 표현식의 평가 순서를 지정할 수 있어요.

```elm
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

### 들여쓰기 / 유의미한 공백

Elm은 중괄호, 괄호, 세미콜론 같은 문법적 기호로 코드의 경계를 지정하지 않아요. 대신 공백과 들여쓰기를 사용해요.

- 모듈, import, 최상위 함수 정의는 가장 왼쪽 열에서 시작해야 해요.
- 표현식이 여러 줄로 나뉘면, 그 표현식에 속한 코드는 그 표현식 아래에 최소 한 칸 들여써야 해요.
- 함께 묶이는 표현식의 부분은 같은 수의 공백으로 들여쓰는 게 좋아요.

```elm
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://elmprogramming.com/indentation.html

### 모듈

Elm에서 각 파일은 하나의 모듈이고, 다른 모든 코드보다 앞에 `module`문을 포함해야 해요.
모듈 이름은 파일 이름과 일치해야 하므로, `Calculator` 모듈은 Calculator.elm 파일에 있어야 해요.
모듈 안에서 정의된 것은 무엇이든 그 모듈의 스코프 안에만 머물러서,
`exposing`에 나열하지 않는 한 이 모듈 밖에서는 접근할 수 없어요.

```elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

### 주석

주석은 Elm 파일 안에 있으면서 코드로 해석되지 않는 글을 말해요.
주로 자신과 다른 프로그래머가 읽도록 하기 위한 것이에요.
두 개의 대시를 사용하는, 한 줄 주석을 위한 간단한 문법이 있어요.
여러 줄 주석도 여는 구분자와 닫는 구분자인 `{-`와 `-}` 쌍으로 쓸 수 있어요.

```elm
-- a single line comment
-- another single line comment

{- a multiline comment
   spawning multiple lines
-}
```
