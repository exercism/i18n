# 함수 애너테이션 순서

관례적으로 `@doc` 함수 애너테이션은 `@spec` 함수 애너테이션보다 앞에 와야 하고, `@spec` 함수 애너테이션은 함수 바로 앞에 와야 해요. 함수에 절이 여러 개 있다면 함수 애너테이션은 첫 번째 절 앞에 와야 해요.

예시:

```elixir
@doc """
This function counts the number elements in a list
"""
@spec count(list(any())) :: integer()
def count([]), do: 0
def count([h | t]), do: 1 + count(t)
```
