# 소개

Lua의 불리언 타입에는 전통적인 두 가지 불리언 값인 `true`와 `false`가 있어요. 이 값들은 변수에 할당할 수 있고, 논리 연산자(`and`, `or`, `not`)와 결합하거나 조건 검사(예: 제어 구조)에 사용할 수 있어요.

```lua
local is_true = true
local is_false = false

true and true  --> true
true and false --> false
false or true  --> true
false or false --> false
not false      --> true
not true       --> false

-- prints 0
if is_true == true then
  print(0)
else
  print(1)
end
```

조건 검사와 논리 연산자는 불리언 `false`와 `nil`을 모두 거짓으로, 그 밖의 모든 값을 참으로 취급해요.

```lua
1 and 2          --> 2
nil and 2        --> nil
false and 2      --> false
1 or 2           --> 1
false or 'hello' --> "hello"
nil or false     --> false
```

`and`와 `or`는 모두 *단축 평가*를 사용하는데, 이는 두 번째 피연산자를 필요할 때만 평가한다는 뜻이에요. 모든 연산은 [연산자 우선순위](https://www.lua.org/manual/5.4/manual.html#3.4.8)에 따라 평가되며, `not`은 `and`와 `or`보다 먼저 평가돼요.
