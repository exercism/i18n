# 힌트

## 일반

- `*T`는 타입 `T`를 가리키는 포인터 변수를 선언할 때 사용할 수 있어요. 예를 들어 `var i *int`는 `int`를 가리키는 포인터인 변수 `i`를 선언해요.
- `&` 연산자를 사용하면 변수의 포인터(메모리 주소)를 얻을 수 있어요. 예를 들어 `mypointer := &anIntVariable`과 같아요.
- 포인터에 `*` 연산자를 사용하면 포인터에 저장된 값을 얻을 수 있어요. 예를 들어 `var i int = *aPointerToInt`와 같아요.
  이것을 포인터를 역참조한다고 해요.
- 포인터를 역참조하기 전에 포인터가 `nil`이 아닌지 확인해요.
  `nil` 포인터를 역참조하려고 하면 런타임 오류가 발생해요.
- 포인터가 어떻게 동작하는지 잘 모르겠다면 [Tour of Go: Pointers][go-tour-pointers]나 [Go by Example: Pointers][go-by-example-pointers]를 읽어 봐요.

## 1. 투표 카운터 만들기

- `int`를 가리키는 포인터, 즉 `*int`를 만들어야 해요.
- 변수에 `&` 연산자를 사용하면 그 변수를 가리키는 포인터를 만들 수 있어요. 예를 들어 `&myInt`와 같아요.
- 직접 정의한 새 변수를 가리키는 포인터를 만들 수도 있고, 함수 인자로 받은 변수를 사용할 수도 있어요.

## 2. 카운터에서 투표 수 가져오기

- 포인터에 `*` 연산자를 사용하면 역참조해서 값을 얻을 수 있어요. 예를 들어 `*myPointer`와 같아요.
- `nil` 포인터를 역참조하면 런타임 오류가 발생해요.
  항상 포인터를 역참조하기 전에 `nil`이 아닌지 확인해요.

## 3. 카운터의 투표 수 증가시키기

- 포인터 `var myPointer *int`가 있다면 `*myPointer`에 값을 할당해서 `myPointer`가 가리키는 값을 바꿀 수 있어요.
- 포인터의 현재 값을 얻으려면 `*` 연산자로 역참조하거나, 이전 과제에서 만든 함수를 호출해야 해요.

## 4. 선거 결과 만들기

- `Name`과 `Votes` 필드를 함수의 인자에 있는 값으로 채운 새로운 `ElectionResult` 리터럴이나 변수를 만들어요.
- 변수 이름이나 리터럴 선언 앞에 `&` 연산자를 사용하면 변수나 리터럴로부터 포인터를 만들 수 있어요. 예를 들어 `&myVariable`이나 `&ElectionResult{Name: "John", Votes: 1}`과 같아요.

## 5. 결과 발표하기

- `ElectionResult`의 포인터를 받았더라도, 마치 포인터가 아닌 것처럼 점 `.` 표기법으로 필드에 접근할 수 있어요!
- 구조체의 `Name`과 `Value` 필드에 접근해서 메시지를 만들어요.
- 구조체의 포인터에서 필드에 접근하더라도 역참조를 할 필요가 없어요.
  다음 예시처럼 Go가 포인터를 자동으로 역참조해 줘요:

```go
result := &ElectionResult{
    Name: "John",
    Votes: 32
}

result.Name // "John" - Go will automatically dereference the pointer
            //          and access the 'Name' field of the dereferenced struct 
```

## 6. 투표 재검표

- 맵은 이미 포인터라고 생각할 수 있어요.
  즉, 함수 안에서 맵에 가한 변경은 함수 밖에서도 보여요.
- `var m map[string]int`에서 키의 값을 증가시키려면 몇 가지 방법이 있어요: `m["mykey"] = m["mykey"] + 1`, `m["mykey"] += 1`, `m["mykey"]++`.
