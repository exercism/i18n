# 안내

교외의 크리켓 경기장에서 일하는 관리인은 숫자 계산을 도와줄 사람을 찾고 있어요. 경계를 두르려면 줄이 얼마나 필요한지, 공이 어느 방향으로 얼마나 날아갔는지, 그리고 야수들이 공을 잡기 전까지 공이 얼마나 굴러가는지 말이에요.

모든 거리는 미터 단위이고, 모든 속도는 초속 미터 단위예요. 경기장 위의 위치는 피치 중앙을 기준으로 재요. `x`는 그라운드를 따라 곧장 나아간 미터 수, `y`는 그라운드를 가로지른 미터 수인데, 왼쪽이 양수이고 오른쪽이 음수예요.

## 1. 경계를 두를 줄

경계는 피치 중앙을 둘러싼 원이에요. 반지름을 받아 필요한 줄의 길이를 반환하는 `boundary-length`를 정의해 봐요. 길이는 2 × π × 반지름이에요.

```factor
70.0 boundary-length .
! => 439.822971502571
```

## 2. 피치에서 얼마나 떨어져 있나요?

야수의 `x`와 `y`를 받아 피치 중앙에서 얼마나 떨어져 서 있는지를 반환하는 `distance-from-pitch`를 정의해요. x² + y²의 제곱근이에요.

```factor
30.0 40.0 distance-from-pitch .
! => 50.0
```

## 3. 어느 방향으로 날아갔나요?

공이 떨어진 지점의 `x`와 `y`를 받아 방향을 **도** 단위로 반환하는 `shot-angle`을 정의해요. 0도는 그라운드를 따라 곧장 나아가는 방향, 90도는 왼쪽 정면, -90도는 오른쪽 정면, 180도는 키퍼를 지나 곧장 뒤쪽이에요.

```factor
50.0 50.0 shot-angle .
! => 45.0
```

## 4. 공은 얼마나 멀리 날아갔나요?

`speed`로 맞은 공이 **도** 단위의 `angle` 각도로 솟아오르면, 처음 땅에 떨어지기 전까지 speed² × sin(2 × angle) ÷ 9.8 미터를 날아가요. 속도와 각도를 받아 그 거리를 반환하는 `carry`를 정의해요.

```factor
30.0 45.0 carry .
! => 91.83673469387755
```

## 5. 잔디 위에서 느려지기

아웃필드를 굴러가는 동안 공은 속도를 잃어요. `metres`만큼 굴렀을 때 속도는 speed × e^(−0.02 × metres)가 돼요. 처음 속도와 굴러간 미터 수를 받아 남은 속도를 반환하는 `speed-after`를 정의해요.

```factor
30.0 50.0 speed-after .
! => 11.03638323514327
```

## 6. 언제부터 쫓아갈 가치가 없어지나요?

5번에서 한 것을 거꾸로 뒤집어 봐요. 공이 굴러가기 시작하는 속도와 그보다 느린 `target` 속도를 받아, 목표 속도까지 떨어지는 동안 몇 미터를 굴러가는지 반환하는 `metres-until`을 정의해요. ln(speed ÷ target) ÷ 0.02예요.

```factor
30.0 15.0 metres-until .
! => 34.657359027997266
```
