# 소개

어떤 타입이 _타입 매개변수_를 사용해 모든 타입의 값을 담을 수 있으면, 그 타입은 _제네릭 타입_이에요.

예를 들어, 이 `Box` 타입에는 타입 매개변수 `a`가 있어요(소문자로 써요).

```gleam
pub type Box(a) {
  Box(a)
}
```

`a` 타입 매개변수는 모든 타입을 대신하는 자리 표시자라서, `Box`는 문자열이나 정수, 또는 다른 어떤 타입과도 함께 쓸 수 있어요.

```gleam
Box("Hello, Joe!") // The type is Box(String)

Box(42) // The type is Box(Int)
```

타입 매개변수는 쉼표로 구분해서 여러 개 둘 수 있어요.

```gleam
pub type Pair(a, b) {
  Pair(a, b)
}
```

## 제네릭 함수

타입 매개변수는 함수의 인자에서도 쓸 수 있어요.

이 함수는 `a` 타입의 값을 받아서, `a`를 받고 `b`를 반환하는 함수를 두 번 호출해요.

```gleam
pub fn twice(value: a, f: fn(a) -> b) -> b {
  f(value)
  f(value)
}
```
```gleam
// The type is fn(String, fn(String) -> Nil) -> Nil
twice("Hello, Joe!", io.println)
```
