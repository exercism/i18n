이 연습 문제의 목표는 Password Checker 연습 문제를 개선하는 것이에요.
주어진 비밀번호는 한 번에 여러 규칙을 위반하기 십상이기 때문에, 쓸모 있는 비밀번호 검사기라면 처음 발견한 규칙 하나만 알려 주는 대신 위반한 모든 규칙을 사용자에게 알려 줘야 해요.
개선된 비밀번호 검사기는 주어진 비밀번호가 위반한 규칙을 한 번에 모두 알려 줘야 해요.

이 비밀번호 검사기의 규칙은 이전 Password Checker 연습 문제와 같아요:

- 12자 이상이어야 해요
- 대문자를 최소한 하나 포함해야 해요
- 소문자를 최소한 하나 포함해야 해요
- 숫자를 최소한 하나 포함해야 해요
- !@#$%^&\* 집합에 속하는 기호를 최소한 하나 포함해야 해요

## 1. `PasswordError` 판별 공용체를 수정해 개별 값을 플래그로 다룰 수 있게 하기

이 필수 단계를 마치기 전에는 테스트가 컴파일되지 않는다는 점에 유의해요.

## 2. `checkPassword` 함수 구현하기

`checkPassword` 함수는 주어진 비밀번호가 앞서 말한 규칙들을 지키는지 검사해요.
이 함수는 `Result` 값을 반환해야 하는데, 비밀번호가 모든 규칙을 만족하면 `Ok`를, 하나 이상의 규칙을 위반하면 `Error` 값을 반환해요.
주어진 비밀번호가 여러 규칙을 위반하면, `PasswordError` 값은 위반한 모든 규칙을 나타내야 해요.

```fsharp
checkPassword "abcdefghijk5"
// => Error (PasswordError.MissingUppercaseLetter ||| PasswordError.MissingSymbol)
```

## 3. ``getStatusPhrases` 함수 구현하기

`getStatusPhrases` 함수는 `checkPassword`가 반환한 결과에 담긴 오류 각각에 대응하는, 사람이 읽을 수 있는 문구를 담은 문자열 집합을 반환해요.

```fsharp
getStatusPhrases (Error PasswordError.MissingDigit ||| PasswordError.LessThan12Characters)
// => List ["12 characters"; "digit"]
```
