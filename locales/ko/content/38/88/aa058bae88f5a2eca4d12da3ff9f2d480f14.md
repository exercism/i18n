# 개요

Swift에는 참과 거짓을 나타내는 [`Bool`][bools]이라는 내장 타입이 있어요.
`Bool`이 가질 수 있는 값은 `true`와 `false`예요.

## 논리 연산자

Swift는 불리언 표현식을 조합하고 평가하기 위해 세 가지 [논리 연산자][logical-operators] (`!`, `&&`, `||`)를 제공해요.

### 논리 AND (`&&`)

[_and_ 연산자][and] (`&&`)는 두 피연산자가 모두 `true`일 때만 `true`를 반환해요.
둘 중 하나라도 `false`면 `false`를 반환해요.
`&&` 기호 양쪽에 표현식이나 불리언 값을 놓아요:

```swift
true && true  // true
true && false // false
```

### 논리 OR (`||`)

[_or_ 연산자][or] (`||`)는 피연산자 중 **적어도 하나**가 `true`면 `true`를 반환해요.
두 피연산자가 모두 `false`일 때만 `false`를 반환해요.
`||` 기호 양쪽에 표현식이나 불리언 값을 놓아요:

```swift
true || true   // true
true || false  // true
false || false // false
```

### 논리 NOT (`!`)

[_not_ 연산자][not] (`!`)는 불리언 값을 뒤집어요.
값이 `false`면 `true`를, 값이 `true`면 `false`를 반환해요.
`!` 연산자는 값이나 표현식 바로 앞에 놓아요:

```swift
!true  // false
!false // true
```

## 괄호 사용하기 (`()`)

[괄호][explicit-parentheses]를 사용해 표현식을 묶고 평가 순서를 정할 수 있어요.
Swift에서는 괄호 안의 표현식이 먼저 평가돼요:

```swift
true && false && false || true   // true
true && false && (false || true) // false
```

괄호로 묶으면 NOT 연산자가 복잡한 표현식에 어떻게 적용되는지도 정해져요:

```swift
!true && false   // false (evaluates (!true) first, then false && false)
!(true && false) // true  (evaluates (true && false) first to false, then !false)
```

~~~~exercism/note
평가 순서를 분명히 하거나 복잡한 조건을 읽기 쉽게 만들고 싶을 때는 괄호를 사용해요.
기본 우선순위만으로 충분히 분명한 경우에는 불필요한 괄호를 넣지 않아요.
~~~~
