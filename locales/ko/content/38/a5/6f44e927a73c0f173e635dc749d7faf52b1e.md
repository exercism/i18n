# 소개

## 오류

프로그램이나 코드에 뭔가 잘못되었거나 예상치 못한 일이 있을 때는 오류를 보고하는 게 유용해요.

오류는 JavaScript 객체예요.

이 객체의 주요 속성은 `message`예요.

```javascript
const error = new Error('Oops, something went wrong');

console.log(error.message);
// => "Oops, something went wrong"
```

`throw` 문법을 사용하면 오류를 던질 수 있어요.

```javascript
throw new Error('Oops');
```

오류가 던져지면 현재 실행이 중단되고, 호출 스택의 첫 번째 catch 블록에서 다시 시작해요.

```javascript
try {
  throw new Error('Oops');
} catch (error) {
  console.log(error.message);
  // => "Oops"
}
```

## 상속

상속은 클래스 사이에 부모-자식 관계를 만드는 방법이에요.
자식 클래스(때로는 _서브클래스_라고도 해요)는 부모 클래스(때로는 _슈퍼클래스_라고도 해요)가 정의한 동작과 데이터에 접근할 수 있어요.

```javascript
class Pet {
  constructor(name) {
    this.name = name;
  }

  introduce() {
    console.log(`This is my pet, ${this.name}.`);
  }
}

class Dog extends Pet {}

const dog = new Dog('Otis');
dog.introduce();
// => This is my pet, Otis.
```

자식 클래스 선언에 있는 `extends` 키워드는 [프로토타입 체인][prototype-chain]을 통해 부모 클래스와의 관계를 맺어요.

자식의 생성자로 만들어진 객체는 프로토타입 체인에 부모 클래스의 프로토타입을 가지게 되어, 부모가 정의한 모든 메서드나 데이터에 접근할 수 있어요.

```javascript
const dog = new Dog('Otis');

Dog.prototype.isPrototypeOf(dog); // => true
Pet.prototype.isPrototypeOf(dog); // => true
Pet.prototype.isPrototypeOf(Dog.prototype); // => true

Pet.prototype.hasOwnProperty('introduce'); // => true
Dog.prototype.hasOwnProperty('introduce'); // => false
dog.hasOwnProperty('introduce'); // => false
```

JavaScript의 모든 클래스와 마찬가지로, 서브클래스는 `extends` 키워드를 사용해 `Error`를 상속해서 사용자 정의 오류를 만들 수 있어요.
`instanceof` 문법은 잡은 오류가 `Error`의 특정 서브클래스의 인스턴스인지 확인해요.

```javascript
class CustomError extends Error {}

try {
  // ... Code that may throw an error
} catch (error) {
  if (error instanceof CustomError) {
    console.log('The error thrown is an instance of the CustomError');
  }
}
```

[prototype-chain]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Inheritance_and_the_prototype_chain
