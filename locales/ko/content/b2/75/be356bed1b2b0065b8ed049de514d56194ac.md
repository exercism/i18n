# 추가 지침

## 출력 형식

학생의 식물을 쉼표와 공백으로 구분해, null로 끝나는 문자열로 출력해요.

## 레지스터

| 레지스터 | 용도         | 타입    | 설명                          |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | 입력         | 주소    | 정원 도표                     |
| `$a1`    | 입력         | 주소    | 학생의 이름                   |
| `$a2`    | 입출력       | 주소    | null로 끝나는 출력 문자열     |
| `$t0-9`  | 임시         | 임의    | 임시 값 저장에 사용           |
