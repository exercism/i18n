# 지시사항

공장에서 일하다 보면 직원 배지에 인쇄할 문구를 만들어야 할 때가 있어요. 이 함수를 JavaScript로 구현해 보기로 해요.

배지에는 직원의 `id`와 `name`, 그리고 근무하는 부서가 필요해요.

## 1. 배지 문구 만들기

배지에 인쇄할 문구를 반환하는 `printBadge`라는 함수를 구현해요.

직원의 이름은 항상 주어지지만, 직원의 `id` 번호와 부서 이름은 `null`일 수 있어요. 직원의 `id` 번호는 주어지는 경우 대괄호 안에 넣어요(예: `[20]`).

사장의 배지에는 `id`나 `department`가 없어야 해요.

```javascript
printBadge(20, 'Bob', 'Marketing');
// => '[20] Bob - MARKETING'
```
