# 지침

호텔 레스토랑의 지배인으로 일하고 있어요.
오늘 사용할 수 있는 좌석 수, 예약 수, 그리고 지금 자리를 기다리는 예약 없이 "걸어 들어온" 손님에 따라 식당의 좌석 배치를 관리하는 것이 과제예요.
이 연습 문제에서는 비어 있는 첫 번째 좌석부터 차례대로 배정해요.

이 연습 문제에는 식당 좌석을 관리하는 여섯 가지 과제가 있어요.

## 1. 오늘의 좌석 배치표 만들기

`new_seating_chart(<size=22>)` 함수를 정의해요. 이 함수는 오늘 식당에 마련할 좌석 수를 나타내는 size 인자를 받아요.
`size`를 전달하지 않으면 22석짜리 좌석 배치표를 반환해요.
배정되지 않은 좌석의 값은 손님에게 배정할 수 있음을 나타내는 `None`으로 채워요.

## 2. 예약 손님 배치하기

`arrange_reservations(<guest_names>)` 함수를 정의해요. 이 함수는 손님 이름 목록을 받는 매개변수 하나를 가져요.
이는 오늘 식당에 자리를 예약한 사람들을 나타내요.

이 함수는 기본 크기(22석)의 `dict` 좌석 배치표를 반환하고, 손님들은 예약 명단에 나온 순서대로 좌석에 배정해요.
배정되지 않은 좌석은 모두 `None`으로 설정해요.
손님이 한 명도 없으면 모든 자리가 `None`인 "빈" 좌석 배치표를 반환해요.

```python
>>> arrange_reservations(guests=["Walter", "Frank", "Jenny", "Carol", "Alice", "George"])
...
{1: 'Walter', 2: 'Frank', 3: 'Jenny', 4: 'Carol', 5: 'Alice', 6: 'George', 7: None, 8: None, 9: None, 10: None, 11: None, 12: None, 13: None, 14: None, 15: None, 16: None, 17: None, 18: None, 19: None, 20: None, 21: None, 22: None}
```

## 3. "빈" 좌석 모두 찾기

`find_all_available_seats(<seats>)` 함수를 정의해요. 이 함수는 좌석 배치표 딕셔너리를 받는 매개변수 하나를 받아서, 지금 기다리고 있는 손님이 사용할 수 있는 좌석 번호를 담은 `list`를 반환해요.
좌석이 비어 있으면 딕셔너리에서 값이 `None`이에요. 사용 중인 좌석에는 손님 이름이 들어 있어요.

```python
>>> seats = {1: None, 2: 'Frank', 3: 'Jenny', 4: None, 5: 'Alice', 6: 'George', 7: None, 8: 'Carol', 9: None, 10: None, 11: None, 12: 'Walter'}

>>> find_all_available_seats(seats)
[1,4,7,9,10,11]
```

## 4. 현재 빈 좌석 수

`current_empty_seat_capacity(<seats>)` 함수를 정의해요. 이 함수는 기존 좌석 예약을 담은 `dict`를 매개변수 하나로 받아요.
이 함수는 비어 있는 좌석의 총 개수를 반환해요.

```python
>>> curr_empty_seat_capacity({1: "Occupied", 2: None, 3: "Occupied"})
1

>>> curr_empty_seat_capacity({1: "Occupied", 2: None, 3: None})
2
```

## 5. 기다리게 할까요?

`accommodate_waiting_guests(<seats>, <guests>)` 함수를 정의해요. 이 함수는 매개변수 두 개를 받아요.
첫 번째 매개변수는 좌석 배치표 `dict`예요.
두 번째 매개변수는 예고 없이 "걸어 들어온" 손님들의 `list`예요.
먼저 사용할 수 있는 좌석이 몇 개인지, 지금 예고 없이 온 손님들에게 자리를 줄 수 있는지 알아봐야 해요.

좌석이 충분하지 않으면 좌석 배치표 `dict`를 그대로 반환해요.

좌석이 _있다면_ 손님들을 좌석 배치표에 배정하고, 갱신된 배치표를 반환해요.
**팁:** 앞에서 정의한 함수를 활용하면 계산을 대신해 줄 수 있어요.

```python
# Guests cannot be accommodated.
>>> starting_reservations = {1: 'Carol', 2: 'Alice', 3: 'George', 4: None, 5: None, 6: None, 7: 'Frank', 8: 'Walter'}
>>> accommodate_guests(starting_reservations, ["Mort", "Suze", "Phillip", "Tony"])
...
{1: 'Carol', 2: 'Alice', 3: 'George', 4: None, 5: None, 6: None, 7: 'Frank', 8: 'Walter'}


# Guests can be accommodated.
>>> starting_reservations = {1: None, 2: None, 3: None, 4: 'Carol', 5: 'Alice', 6: 'George', 7: None, 8: None, 9: None, 10: None, 11: None, 12: None, 13: None, 14: None, 15: None, 16: None, 17: None, 18: 'Frank', 19:  'Jenny', 20: None, 21: None, 22: 'Walter'}
>>> accommodate_guests(starting_reservations, ["Mort", "Suze", "Phillip", "Tony"])
...
{1: 'Mort', 2: 'Suze', 3: 'Phillip', 4: 'Carol', 5: 'Alice', 6: 'George', 7: 'Tony', 8: None, 9: None, 10: None, 11: None, 12: None, 13: None, 14: None, 15: None, 16: None, 17: None, 18: 'Frank', 19: 'Jenny', 20: None, 21: None, 22: 'Walter'}
```

## 6. 좌석 비우기

`empty_seats(<seats>, <seat_numbers>)` 함수를 정의해요. 이 함수는 매개변수 두 개를 받아요.
첫 번째 매개변수는 좌석 배치표 딕셔너리예요.
두 번째 매개변수는 비워야 하는, 그러니까 좌석 번호의 값을 `None`으로 바꿔야 하는 좌석 번호 목록이에요.

비울 좌석 값을 갱신한 뒤 좌석 `dict`를 반환해요.

```python
>>> empty_seats(seats={1: "Alice", 2: None, 3: "Bob", 4: "George", 5: "Gloria"}, seat_numbers=[5,3,1])
{1: None, 2: None, 3: None, 4: "George", 5: None}
```
