# 지침

이 연습 문제에서는 전화번호를 분석해요.

구현해야 할 기능은 두 가지예요.

루틴에 전달되는 전화번호는 NNN-NNN-NNNN 형식(예: 212-515-9876)이고 null이 아니라고 보장돼요.

## 1. 전화번호 분석하기

분석 결과로 세 가지 데이터를 반환해야 해요.

1. 번호의 앞 3자리가 뉴욕 지역 코드, 즉 212인지를 나타내는 값
2. 5번째부터 7번째 자리(1부터 세요)에 접두사 코드 555가 있어서 가짜 번호인지를 나타내는 값
3. 번호의 마지막 4자리

전화번호 정보를 만들려면 (정적) 메서드 `PhoneNumber.Analyze()`를 구현해요.

```csharp
PhoneNumber.Analyze("631-555-1234");
// => (false, true, "1234")
```

## 2. 전화번호에 가짜 접두사 코드(555)가 있는지 확인하기

1번 문제에서 만든 전화번호 정보를 사용해 전화번호가 가짜인지 확인하려면 (정적) 메서드 `PhoneNumber.IsFake()`를 구현해요.

```csharp
PhoneNumber.IsFake(PhoneNumbers.Analyze("631-555-1234"));
// => true
```
