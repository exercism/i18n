# 소개

_삼항 연산자_는 간단한 _if/else_ 문을 위한 가볍고 간결한 대안이에요.
주로 반환문에 사용되지만, 반드시 반환문으로만 제한되는 것은 아니에요. 단 한 줄로 결정을 내릴 수 있는데, 표현식이 `true`면 왼쪽 값을, `false`면 오른쪽 값을 반환해요. 예를 들면 다음과 같아요:

```java
boolean expr = 0 != 200;

// Ternary statement
int value = expr ? 22 : 33;
// => 22
```

간단한 _if/else_ 표현식은 대부분 _삼항 연산자_를 사용해 단순하게 만들 수 있어요.
