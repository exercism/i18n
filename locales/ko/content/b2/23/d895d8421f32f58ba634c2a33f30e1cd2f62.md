# 추가 지침

그리드의 각 행은 하나의 워드로 표현해요.

예를 들어,

```
    0 1 0
    1 0 0
    1 1 0
```

이는 다음과 같이 표현해요.

```
0x2
0x4
0x6
```

그리드의 열은 최대 32개예요.

## 레지스터

| 레지스터 | 용도        | 타입    | 설명                        |
| -------- | ----------- | ------- | --------------------------- |
| `$a0`    | 입력        | 정수    | 행의 개수                   |
| `$a1`    | 입력        | 정수    | 열의 개수                   |
| `$a2`    | 입력        | 주소    | 현재 세대의 그리드          |
| `$a3`    | 입력/출력   | 주소    | 다음 세대의 그리드          |
| `$t0-9`  | 임시        | 임의    | 임시 저장에 사용            |
