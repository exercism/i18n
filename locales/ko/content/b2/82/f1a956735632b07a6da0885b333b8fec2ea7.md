# 자세히 알아보기

Swift에서는 정수를 사용해 문자열의 특정 위치에 접근할 수 없어요 (`string[3]`처럼요).
Swift의 문자열은 길이가 가변적인 유니코드 문자로 이루어져 있기 때문에, 어떤 문자를 찾으려면 그 앞에 있는 문자들을 차례대로 거쳐 가야 해요.

특정 위치의 문자에 접근하려면 `String.Index` 타입의 인덱스를 계산해야 해요.
이런 인덱스를 *불투명 인덱스*라고 하는데, 내부 구조가 원시 정수처럼 직접 다뤄지는 것이 아니라 Swift가 관리하기 때문이에요:

```swift
let csv = "apple,pear,peach,orange,cherry,lime,gooseberry"
let index = csv.index(csv.startIndex, offsetBy: 21)
print(csv[index])
// Prints "g"

print(index)
// Prints internal representation: Index(_rawBits: ...)
```
