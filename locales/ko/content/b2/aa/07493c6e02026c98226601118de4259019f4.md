# 안내 추가
## Arturo 전용 안내

대부분의 Arturo 연습 문제와 달리, `src/grep.art`는 테스트 스위트에서 직접 불러오지 않아요.
대신 풀이는 독립 실행형 Arturo 스크립트로 실행되며, 일련의 명령줄 인자를 받아요.
이 명령줄 인자에 접근하려면 `arg`[arg]나 `args`[args]를 사용하면 돼요. 인자에는 0개 이상의 플래그, 검색 패턴, 하나 이상의 파일 이름이 들어 있어요.
이 파일들은 테스트 스위트가 런타임에 만들어서 내용을 채워요.
풀이는 요청한 파일을 읽고, 기대하는 출력을 표준 출력에 써야 해요.

[arg]: https://arturo-lang.io/documentation/library/system/arg
[args]: https://arturo-lang.io/documentation/library/system/args
