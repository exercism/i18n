# 도움말

문제가 생겼을 때 도움을 받을 수 있는 방법은 다음과 같아요:

- [/r/javascript](https://www.reddit.com/r/javascript)는 Javascript 서브레딧이에요.
- [StackOverflow](https://stackoverflow.com/questions/tagged/javascript+exercism)에서 여러분의 문제를 검색하고 이미 답변이 올라와 있는지 확인할 수 있어요. 질문을 올리거나 답변을 달 수도 있어요.
- [Github issue tracker](https://github.com/exercism/javascript/issues)는 exercism에서 Javascript 연습 문제의 개발과 유지 관리를 추적하는 곳이에요. 하지만 위의 링크로도 해결되지 않는다면, 여기에 자유롭게 이슈를 남겨 주세요.
