# 테스트

연습 문제는 모두 모킹과 테스트를 위해 [Pester][pester] 프레임워크를 사용해요.
모든 테스트는 Pester 프레임워크의 표준대로 `[Exercise].tests.ps1`이라는 파일에 들어 있어요.
`[Exercise].ps1`과 `[Exercise].tests.ps1`이 있는 디렉터리, 즉 올바른 디렉터리에 있다면요.
PowerShell에서 다음과 같이 호출하면 테스트를 실행할 수 있어요:

``` PowerShell
Invoke-Pester
```

이 명령은 해당 디렉터리에서 찾을 수 있는 모든 `.tests.ps1` 파일을 실행해요.

PowerShell이 아닌 다른 셸을 사용하고 있다면, 다음과 같이 호출해 테스트를 실행할 수 있어요:

``` PowerShell
pwsh -Command "Invoke-Pester"
```

## Visual Studio Code에서 테스트 실행하기

Visual Studio Code에 [PowerShell 확장][extension]이 설치되어 있는지 확인해야 해요.

Visual Studio Code에서 테스트를 실행하는 방법은 여러 가지가 있어요:

- Debug 메뉴에서 `.Tests.ps1` 스크립트를 실행해요. 단축키는 `F5` 또는 `Shift + F5`를 사용해요.
- 테스트 코드의 `Describe` 키워드 위에 있는 "Run Tests" 링크를 클릭해서 편집기 안에서 실행할 수도 있어요.
- Pester 프레임워크를 실행하는 Task를 구성할 수도 있어요.

[pester]: https://github.com/pester/Pester
[extension]: https://marketplace.visualstudio.com/items?itemName=ms-vscode.PowerShell
