# 소개

## let assert

Gleam에서 값에 대한 패턴 매칭을 할 때에는 패턴이 그 타입의 모든 가능한 값을 처리하도록 해야 해요. 그렇지 않으면 코드가 컴파일되지 않아요.

이 함수는 배열이 비어 있는 경우를 처리하지 않았기 때문에 거부돼요:

```gleam
pub fn get_first_element_or_crash(items: List(e)) -> e {
  case items {
    [item, ..] -> item
  }
}
```

대부분의 Gleam 프로그램에서는 모든 가능한 경우를 처리하고 싶어 해요. 하지만 프로토타입이나 간단한 스크립트처럼 정상 경로에만 집중하고 나머지 경우에 대한 코드는 작성하지 않고 싶을 때도 있어요. 이럴 때 사용하는 것이 바로 Gleam의 `let assert`이에요.

let assert를 사용하면 패턴이 타입의 가능한 값 중 일부만 처리할 수 있어요. 그리고 패턴이 값과 일치하지 않으면 프로그램이 중단돼요. `let assert`를 사용하면 위 함수를 이렇게 작성할 수 있어요:

```gleam
pub fn get_first_element_or_crash(items: List(e)) -> e {
  let assert [item, ..] = items
  item
}
```

Gleam 라이브러리에서는 프로그램을 중단시킬 수 있으므로 let assert를 절대 사용하면 안 돼요. 대신 `Result` 타입을 사용해서 애플리케이션 개발자가 오류를 어떻게 처리할지 결정하도록 해야 해요.
