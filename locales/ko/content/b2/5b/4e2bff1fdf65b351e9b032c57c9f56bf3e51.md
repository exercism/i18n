# 힌트

## 1. 새 방문자 만들기

- 특정 키와 값을 가진 객체를 만드는 방법을 알아보려면 [개념 "객체"][concept-objects]를 다시 살펴봐요.

## 2. 티켓 취소하기

- 할당 연산자 `=`를 사용해서 방문자 객체의 `ticketId` 속성을 `null`로 설정해요.
- 그다음 방문자 객체를 반환해요.

## 3. 티켓 상태 확인하기

- 함수에서 조건에 따라 서로 다른 값을 반환하는 방법을 알아보려면 [개념 "조건문"][concept-conditionals]를 다시 살펴봐요.
- 대괄호 표기법을 사용해서 객체에서 주어진 `ticketId`의 값에 접근해요.
- 일치 연산자 `===`를 사용해서 `null` 또는 `undefined`인지 확인해요.

## 4. 티켓 상태 응답 개선하기

- 이전 과제에서처럼 대괄호 표기법으로 주어진 `ticketId`의 값을 가져와요.
- 이 과제를 해결하는 데는 if문이 필요하지 않아요.
- 대신 [null 병합 연산자][mdn-nullish-coalescing] `??`를 사용해요.

## 5. 이용 약관 버전 확인하기

- 중첩된 값에 접근하는 방법은 [개념 "객체"][concept-objects]를 다시 살펴보고, 버전을 가져오는 표현식을 먼저 적어 보는 것부터 시작해요.
- 그다음 [옵셔널 체이닝][mdn-optional-chaining] 연산자를 사용해서 gtc 객체가 없는 경우를 처리해요.
- 이 과제를 해결하는 데는 if문이 필요하지 않아요.
