# 지침 추가

## 예외 메시지

때로는 [예외를 발생시키는 것](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)이 필요해요. 이때는 항상 오류의 원인이 무엇인지 알려 주는 **의미 있는 오류 메시지**를 함께 넣어야 해요. 그래야 코드를 읽기 쉬워지고 디버깅에 훨씬 도움이 돼요. 오류 원인이 특정 유형이라고 확실한 상황이라면 [내장 오류 유형](https://docs.python.org/3/library/exceptions.html#base-classes) 중 하나를 발생시켜도 되지만, 그때도 의미 있는 메시지는 꼭 포함해야 해요.

이 연습 문제에서는 입력 진법과 출력 진법이 다를 때 `ValueError`를 "던지기" 위해 [raise 문](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)을 사용해야 해요. `exception`을 `raise`하면서 의미 있는 메시지도 함께 넣어야만 테스트를 통과할 수 있어요.

메시지와 함께 `ValueError`를 발생시키려면, 메시지를 `exception` 유형의 인자로 작성해요:

```python
# for input.
raise ValueError("input base must be >= 2")

# another example for input.
raise ValueError("all digits must satisfy 0 <= d < input base")

# or, for output.
raise ValueError("output base must be >= 2")
```
