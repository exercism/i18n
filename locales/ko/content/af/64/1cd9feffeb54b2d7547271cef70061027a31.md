# 힌트

## 일반

- [csharp.net 문자열 튜토리얼][tutorial-csharp.net-strings]에 C# `string`을 소개하는 좋은 내용이 있어요.
- `string` 클래스에는 유용한 [기본 제공 메서드][docs-string-methods]가 많아요.

## 1. 로그 줄에서 메시지 가져오기

- 문자열에서 텍스트를 검색하는 여러 가지 방법을 [이 튜토리얼][tutorial-docs.microsoft.com-search-text-in-string]에서 살펴봐요.
- 공백 제거도 [기본으로 제공][tutorial-docs.microsoft.com-trim-white-space]돼요.

## 2. 로그 줄에서 로그 레벨 가져오기

- `string`의 대소문자를 바꾸는 방법은 [이 튜토리얼][tutorial-docs.microsoft.com-changing-case]에서 살펴봐요.

## 3. 로그 줄 형식 다시 맞추기

- [문자열을 연결][tutorial-docs.microsoft.com-concatenate-strings]하는 방법은 여러 가지가 있지만, 보통은 [문자열 보간][tutorial-csharp.net-string-interpolation]을 선호해요.
