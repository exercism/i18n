# 소개

Gleam의 opaque 타입은 사용자 정의 타입의 한 종류로, 그 타입을 정의한 모듈만이 해당 타입의 값을 만들거나 패턴 매칭할 수 있어요. 특정한 방식으로만 사용해야 하는 타입을 만들 때 유용해요.

opaque 타입은 `opaque` 키워드로 정의해요.

```gleam
pub opaque type PositiveInt {
  PositiveInt(inner: Int)
}
```

이 `PositiveInt` 타입은 정수가 필요하지만 그 값이 0 이상이어야 하는 상황에서 사용해요. 일반적인 Gleam `Int`는 음수가 될 수도 있기 때문에 이런 상황에는 쓸 수 없어요.

이 타입을 정의한 모듈은 내부의 정수 값을 가져오는 함수와, 값이 양수가 아니면 오류를 반환하는 `PositiveInt` 생성 함수를 정의할 수 있어요.

```gleam
pub fn from_int(i: Int) -> Result(PositiveInt, String) {
  case i {
    _ if i < 0 -> Error("Value must be positive")
    _ -> Ok(PositiveInt(i))
  }
}

pub fn to_int(i: PositiveInt) -> Int {
  i.inner
}
```

이런 API 덕분에 다른 모듈은 음수 값으로 `PositiveInt`를 만들 수 없어요. 그래서 `PositiveInt`를 받는 함수는 그 값이 양수임을 확신할 수 있어요.
