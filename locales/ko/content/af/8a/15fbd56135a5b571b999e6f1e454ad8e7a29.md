# 소개

이 연습 문제에서는 Ruby의 기본 구성 요소를 배워요.
다룰 내용이 많지만, 너무 벅차게 느껴져도 걱정하지 마세요. 트랙을 진행하면서 모든 내용을 훨씬 더 깊이 있게 다뤄요.

Ruby를 이해하는 데 핵심적인 점 중 하나는 Ruby가 [객체 지향 언어][object-oriented-programming]라는 것, 그리고 **Ruby에서는 모든 것이 [객체][object]**라는 것이에요. 숫자, 문자열, 배열, 이 모두가 객체예요.

## 변수와 상수

보통 변수나 상수를 사용해 객체에 이름을 붙여 활용해요.

변수는 항상 [스네이크 케이스][snake-case]로 작성해요.
변수는 생명 주기 동안 서로 다른 객체를 참조할 수 있어요.
예를 들어 `my_first_variable`은 `=` 연산자를 사용해 여러 번 정의하고 다시 정의할 수 있어요:

```ruby
my_first_variable = 1
my_first_variable = "Some string"
my_first_variable = SomeComplexObject.new
```

반면 상수는 한 번만 할당하도록 되어 있어요.
상수는 대문자로 시작해야 하고, 보통 단어를 밑줄로 구분해 모두 대문자로 작성해요.
예를 들면 이렇죠:

```ruby
MY_FIRST_CONSTANT = 10

# Redefining not allowed
# MY_FIRST_CONSTANT = "Some String"
```

## 클래스

Ruby는 클래스로 구성되어 있어요.
클래스는 `class` 키워드 뒤에 클래스 이름을 붙여 정의해요.
객체는 보통 `.new` 메서드로 클래스를 인스턴스화해서 만들어요.
예를 들면 이렇죠:

```ruby
# Define the class
class Calculator
  #...
end

# Create an instance of it and assign it to a variable
my_first_calc = Calculator.new
```

## 메서드

기능 단위는 메서드로 캡슐화되어 있어요. 다른 언어의 _함수_와 비슷하죠.

메서드는 위치 인자나 키워드 인자(`:` 문법으로 정의하고 호출해요)로 정의할 수도 있고, 인자가 전혀 없게 정의할 수도 있어요.

메서드는 마지막으로 평가된 문의 결과를 암묵적으로 반환하거나, `return` 키워드로 객체를 명시적으로 반환할 수 있어요.

```ruby
class Calculator

  # Positional arguments
  def add(num1, num2)
    return num1 + num2 # Explicit return
  end

  # Keyword arguments
  def multiply(num1:, num2:)
    num1 * num2 # Implicit return
  end
end
```

메서드는 `.` 문법으로 호출해요:

```ruby
calc = Calculator.new
calc.add(1, 3)
calc.multiply(num1: 2, num2: 5)
```
