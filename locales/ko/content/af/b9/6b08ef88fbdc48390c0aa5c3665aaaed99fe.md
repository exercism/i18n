# 소개

Haxe는 정규 표현식을 기본으로 지원해요. 정규 표현식은 문자열의 형식을 검사하거나, 문자열을 변환하거나, 주어진 텍스트에서 규칙적인 데이터를 추출하는 데 사용할 수 있어요.

정규 표현식을 만들려면 `~/`와 `/` 사이에 입력해요:

```haxe
var r = ~/haxe/i;
```

또 다른 방법으로는 `EReg()` 인스턴스를 사용할 수도 있어요:

```haxe
var r = new EReg("haxe", "i");
```

여기서 `i`는 패턴을 대소문자 구분 없이 만들어 주는 플래그예요. 다른 플래그도 있어요:

- `g`: 전역 치환.
- `m`: 여러 줄 일치

`~/`와 `/` 사이에는 정규 표현식 패턴을 입력해요. 예를 들어, A부터 Z까지의 문자를 포함하는 문자열을 찾고 싶다고 해봐요. 이때 범위 패턴 `[A-Z]`를 사용할 수 있어요. 다양한 표현 패턴이 있어요:

- `.`: 임의의 문자
- `*`: 0회 이상 반복
- `+`: 1회 이상 반복
- `[A-Z0-9]`: 문자 범위
