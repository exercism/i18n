# 소개

[Flower Field][history]는 인기 게임인 지뢰찾기를 따뜻한 시선으로 새롭게 풀어낸 게임이에요.
게임의 목표는 숫자 힌트를 이용해 정원에 있는 모든 꽃을 찾는 거예요. 숫자 힌트는 어떤 칸에 가로, 세로, 대각선으로 바로 인접한 꽃이 몇 개인지 알려줘요.
"Flower Field"는 이탈리아, 독일, 한국, 일본, 대만의 Microsoft Windows 지역 버전에 포함되어 출시됐어요.

[history]: https://web.archive.org/web/20020409051321fw_/http://rcm.usr.dsi.unimi.it/rcmweb/fnm/
