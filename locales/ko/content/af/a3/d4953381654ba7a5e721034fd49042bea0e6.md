# 자리 표시자

## List 연산 구현하기

이 연습 문제의 목표는 List 메서드 중 일부를 직접 구현하는 거예요.
데이터를 담을 때 내부적으로 List 객체를 사용하는 건 자연스러운 일이에요.
List 메서드(`where`, `map` 등)에는 손대지 마세요.

어쩔 수 없이 써야 하는 몇 가지 "원시적" List 연산이 있어요. 예를 들어:

* 슬라이싱: `list[from..to]`
* 추가: `list.add(item)`

## 이터레이터 프로토콜

구현할 List 연산은 모두 다양한 방식으로 순회하는 것에 관한 거예요.
[이터레이터 프로토콜][iter]에 대해 읽어 보세요.
그러면 다음과 같이 할 수 있어요:

```wren
var list = ListOps.new([1, 2, 3, 4])
for (item in list) {
    do_something_with(item)
}
```

[iter]: https://wren.io/control-flow.html#the-iterator-protocol
