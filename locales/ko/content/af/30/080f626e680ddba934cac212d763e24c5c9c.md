# 개요

정규 표현식은 문자 클래스와 수량자를 넘어 텍스트의 *구조*와 *문맥*까지 설명할 수 있어요. 이런 기능들도 같은 [`regexp`][regexp] 어휘에 속하고, `R/ /` 리터럴로 작성해요.

## 그룹화와 선택

괄호 `( )`는 패턴의 일부를 하나로 묶어서, 수량자나 `|`("이것 또는 저것")가 그 그룹 전체에 적용되게 해요. 그룹 뒤에 `?`를 붙이면 그 그룹은 있어도 되고 없어도 돼요.

```factor
USING: regexp ;

"abab"    R/ (ab)+/ matches? .             ! => t
"cat"     R/ cat|dog/ matches? .           ! => t
"$100.50" R/ \$\d+(\.\d{2})?/ matches? .   ! => t
"$100"    R/ \$\d+(\.\d{2})?/ matches? .   ! => t   (group optional)
```

## 앵커

```
^    ! start of the string
$    ! end of the string
\b   ! a word boundary
```

*단어 경계*(`\b`)는 단어 문자(글자, 숫자, 밑줄)가 단어 문자가 아닌 문자와 만나는 지점이에요. 문자열의 양 끝도 여기에 포함돼요. 그래서 `\bcat\b`는 `cat`이 독립적으로 있을 때만 매치돼요.

```factor
USING: regexp ;

"cat nap" R/ \bcat\b/ re-contains? .   ! => t
"scatter" R/ \bcat\b/ re-contains? .   ! => f
```

## 전후방 탐색

*전후방 탐색*은 어떤 지점 바로 앞이나 뒤에 무엇이 있는지 확인해요. 그 문자들을 매치의 일부로 만들지 않고요. 폭이 0이에요.

```
(?=...)    ! lookahead
(?!...)    ! negative lookahead
(?<=...)   ! lookbehind
```

```factor
USING: regexp ;

"spent $100 and $25" R/ (?<=\$)\d+/ all-matching-subseqs .
! => { "100" "25" }

"up 5% then 12%" R/ \d+(?=%)/ all-matching-subseqs .
! => { "5" "12" }
```

## 옵션

닫는 `/` 뒤에 오는 옵션 문자는 패턴 전체를 바꿔요. `i`는 대소문자를 구분하지 않게 해요.

```factor
USING: regexp ;

"REFUND" R/ refund/i matches? .   ! => t
```

## 각 매치 변환하기

`map-matches`는 매치마다 쿼테이션을 실행하고 그 결과를 모아요. `each-match`는 결과는 모으지 않고 부수 효과만을 위해 똑같이 실행해요. 둘 다 쿼테이션에 매치의 `start` 인덱스, `end` 인덱스, 그리고 문자열 전체를 넘겨주기 때문에, `subseq`로 매치된 텍스트를 되찾을 수 있어요.

```
map-matches ( string regexp quot: ( start end string -- obj ) -- seq )
each-match  ( string regexp quot: ( start end string --     ) --     )
```

```factor
USING: math regexp sequences ;

"a1 b22 c333" R/ \d+/ [ subseq length ] map-matches .
! => { 1 2 3 }
```

## Factor가 지원하지 않는 것

Factor의 regexp 엔진에는 **캡처 그룹 추출**이 없어요(그룹 `( )`는 패턴을 구조화할 뿐, 그룹이 매치한 텍스트를 다시 읽어낼 수는 없어요). **역참조**(`\1`)도 없고, **게으른/탐욕적이지 않은** 수량자(`*?`, `+?`)도 없어요. 전후방 탐색이 캡처 그룹을 대신하는 관용적인 방법이에요. 원하는 부분을 주변 문맥으로 알아보면서 매치하는 거예요.
