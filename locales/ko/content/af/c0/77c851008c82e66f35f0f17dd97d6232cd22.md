# 소개

이것은 _큰_ 주제예요!
이 주제에 대해 두꺼운 책 한 권을 쓰는 것도 가능하고, 실제로 그렇게 한 사람들도 여럿 있어요 (예시를 보려면 Amazon에서 "unicode book"을 검색해 봐요).

## 아주 간단한 역사

예전에는 프로그래머들이 영어만이 중요한 언어라고 가정했기 때문에, 컴퓨터에서 문자를 다루는 일은 훨씬 단순했어요.
즉, 알파벳 26글자(대문자와 소문자), 숫자 10개, 몇 개의 문장 부호, 그리고 종을 울리는 코드(0x07)까지 모두 합쳐 7비트에 들어갔어요. 바로 ASCII 문자 집합이에요.

그러자 자연스럽게 à, ä, Ł는 어떻게 하냐는 질문이 나오기 시작했고, 그다음에는 ऄ, ஹ, ญ에 대한 질문이 나왔고, 젊은 사람들은 이모지 😱를 원했어요.
어떻게 해야 했을까요?

간단히 말하면, 똑똑하고 인내심 강한 많은 사람들이 몇 년 동안 위원회에 참여해서 Unicode 문자 집합과 UTF-8 같은 인코딩의 세부 사항을 정리해야 했고, 수많은 소프트웨어가 _아주_ 복잡한 재작성을 거쳐야 했어요.
게다가 새로운 버그도 많이 생겼고요.

_모든 것_이 깨지는 걸 막기 위해, Unicode/UTF-8 설계에서는 처음 127개 코드가 ASCII와 동일하도록 했어요 _(종 소리까지도요)_.

## Julia의 문자

2005년쯤 이후에 설계된 언어들은 이미 어느 정도 안정된 Unicode 표준이 존재했다는 큰 이점을 누릴 수 있었어요.

Julia(2012년 첫 출시)는 문자, 문자열, 변수와 함수 이름, 수학 연산자 등 모든 것이 Unicode일 것이라고 가정할 수 있었어요.

설명서를 인용하자면, "Julia는 일반 ASCII 텍스트를 다루는 일을 간단하고 효율적으로 만들어 주며, Unicode를 다루는 것도 가능한 한 간단하고 효율적이에요."
여기서 "가능한 한"이라는 부분에 주목해 봐요. 이것이 이 문장에서 중요한 부분이에요.

***문자 리터럴은 작은따옴표로 쓰고, 큰따옴표로 쓰는 문자열과는 구별돼요.***

C/C++ 세계에서 온 사람들에게는 당연한 얘기지만, Python과 Javascript 프로그래머에게는 헷갈릴 수 있어요.

```julia-repl
julia> a = 'a'  # Roman alphabet
'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)

julia> typeof(a)
Char

julia> jha = 'झ'  # Devanagari alphabet
'झ': Unicode U+091D (category Lo: Letter, other)

julia> typeof(jha)
Char

julia> '❤'  # heart emoji
'❤': Unicode U+2764 (category So: Symbol, other)
```

예제를 보면 타입이 `Char`라는 것을 알 수 있고, Julia는 문자의 범주에 대한 정보도 더 가지고 있어요.

자세히 보면 이 문자들은 16진수 4자리로 표현할 수 있다는 걸 알 수 있어요.
전체 문자 집합에는 최대 6자리 16진수가 필요해요.

이런 숫자를 "코드 포인트"라고 부르고, 현재 U+0000부터 U+10FFFF까지의 범위를 가져요.
REPL에서는 그대로 표시되지만, 코드 안에서는 `codepoints()`를 사용해서 얻어요.

`Char`와 `Int` 사이의 변환은 간단해요:

```julia-repl
julia> Int('a')
97

julia> Char(97)
'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
```

컴파일러는 `Char`에 대해 _일부_ 형태의 정수 연산을 허용해요:

```julia-repl
julia> 'b' - 'a'  # interval, in alphabetic order
1

julia> 'b' + 'a'
ERROR: MethodError: no method matching +(::Char, ::Char)

julia> 'a' + 5
'f': ASCII/Unicode U+0066 (category Ll: Letter, lowercase)

julia> 'f' + ('A' - 'a')  # same as `uppercase('f')`
'F': ASCII/Unicode U+0046 (category Lu: Letter, uppercase)
```

## 문자를 위한 함수들

많은 문자열 처리 함수는 `Char` 입력에도 동작해요.

- 지원되는 알파벳이라면 `uppercase()`와 `lowercase()`로 대소문자를 바꿀 수 있어요.
- `isuppercase()`와 `islowercase()`로 대소문자 여부를 검사해요.
- 다음과 같이 문자 유형을 검사해요:
  - `isletter()`는 다양한 알파벳을 처리해요
  - `isdigit()`는 엄격하게 0:9만 검사해요
  - `isnumeric()`은 `isdigit`보다 넓어서 ¾와 여러 비유럽 문자 체계에 대해서도 `true`를 반환해요
  - `isxdigit()`는 16진수 숫자를 검사해요
  - `isascii()`는 Unicode 이전 문자인지 검사해요
  - `ispunct()`는 문장 부호를 검사해요
  - `isspace()`는 모든 공백 문자를 검사해요
  - `isprint()`는 출력 가능한 문자를 검사해요 (반대는 `iscntrl()`이에요)

```julia
islowercase('A')  # false
uppercase('γ')  # 'Γ': Unicode U+0393 (category Lu: Letter, uppercase)
ispunct('@')  # true
isdigit('A')  # false
isxdigit('A')  # true
```

## Char 벡터와 String 사이의 변환

String에서 Char 벡터로 가려면 `collect()`를 사용할 수 있어요.

Char 벡터에서 String으로 가려면 `String()` 생성자가 있어요.

```julia-repl
julia> s = "abcde"
"abcde"

julia> cv = collect(s)
5-element Vector{Char}:
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)
 'd': ASCII/Unicode U+0064 (category Ll: Letter, lowercase)
 'e': ASCII/Unicode U+0065 (category Ll: Letter, lowercase)

julia> String(cv)
"abcde"
```

이 방법은 ASCII뿐만 아니라 어떤 문자에도 동작해요.

```julia-repl
julia> collect("❤,😱")
3-element Vector{Char}:
 '❤': Unicode U+2764 (category So: Symbol, other)
 ',': ASCII/Unicode U+002C (category Po: Punctuation, other)
 '😱': Unicode U+1F631 (category So: Symbol, other)
```

`String()` 생성자는 벡터에 동작한다는 점에 주의해요.
`Char` 하나를 1글자 문자열로 _변환_하려면 소문자 `s`를 쓴 `string()` 함수를 사용해요.

```julia-repl
julia> string('a')
"a"
```

## 저장 방식

지금까지 이 문서에서 다룬 내용은 비교적 간단해 보여요. 그럼 정말 걱정할 게 별로 없는 걸까요?

안타깝게도, 그건 너무 낙관적인 생각이에요!

한 가지 복잡한 점은 코드 포인트마다 "최대" 6자리 16진수가 필요하다는 거예요.
그래서 UTF-8로 인코딩했을 때 문자마다 메모리에서 필요한 공간의 크기가 달라요.

1바이트에는 (부호 없는) 255까지의 숫자, 즉 16진수 두 자리까지만 저장할 수 있어요. 그래서 UTF-8은 `Char` 하나를 저장할 때 1에서 4바이트까지, 바이트 수를 가변적으로 사용해요.
이를 "코드 단위"라고 부르고, `ncodeunits()` 함수는 주어진 문자에 필요한 개수를 반환해요.

```julia-repl
julia> codepoint(jha)  # jha 'झ' is defined in an earlier example
0x0000091d

julia> ncodeunits(jha)
3

julia> ncodeunits('a')  # ASCII character
1

julia> ncodeunits('😱')  # emoji
4
```

또한 화면에 표시할 수 있는 모든 것에 고유한 코드 포인트가 있는 건 아니에요.
시각적으로 구별되는 일부 문자는 다른 문자에서 파생된 것으로 간주되어, Unicode는 이를 기본 문자에 수정자를 더한 것으로 취급해요.
