# 지시 사항

이 연습 문제에서는 2012년 9월 15일에 문을 연 뉴욕의 한 미용실을 위한 예약 스케줄러를 만들어요.

다섯 개의 과제가 있고, 모두 예약 날짜와 관련되어 있어요.
시간은 24시간 형식이며 AM/PM은 쓰지 않아요.
시간대 문제를 최대한 단순하게 하기 위해, 모든 시간이 UTC를 사용한다고 가정해요.

## 1. 숫자로만 된 예약 날짜 파싱하기

텍스트로 표현된 예약 날짜를 그에 해당하는 `DateTime` 형식으로 파싱하는 `schedule_appointment()` 함수를 구현해요.

입력은 미국식 월/일/년 순서라는 점에 유의해요.

```julia-repl
julia> schedule_appointment("07/25/2023 13:45:00")
2023-07-25T13:45:00
```

## 2. 예약이 이미 지났는지 확인하기

예약 날짜를 받아서 그 예약이 과거에 있었는지 확인하는 `has_passed()` 함수를 구현해요.

```julia-repl
julia> has_passed(DateTime(1999, 12, 31, 9, 0, 0))
true
```

## 3. 예약이 오후인지 확인하기

예약 날짜를 받아서 그 예약이 오후(12:00 이상 18:00 미만)인지 확인하는 `is_afternoon_appointment()` 함수를 구현해요.

```julia-repl
julia> is_afternoon_appointment(DateTime(2023, 3, 29, 15, 0, 0))
true
```

## 4. 예약의 요일 확인하기

요일을 _숫자로_ 반환하는 `day_of_week()` 함수를 구현해요.
미용실은 일요일에는 문을 닫아요. 따라서 월요일이 1이고 토요일이 6이에요.

```R
# a Friday
day_of_week(make_datetime(2026, 06, 05, 12, 30, 00))
#> [1] 5
```

## 5. 예약 일정 변경하기

고객이 예약 일정을 변경해야 할 때는 다음 주 금요일 같은 시간으로 자동 변경돼요 (한 주 중 가장 한산한 날이기 때문이에요).

원래 예약(월/일/년 순서의 텍스트 문자열)을 받아서 변경된 예약을 반환하는 `reschedule()` 함수를 구현해요.

```R
# a Saturday
reschedule("06/13/2026 12:30:00")
#> [1] "2026-06-19 12:30:00 UTC"
```

원래 예약이 월요일부터 목요일 사이라면 _이번_ 주 금요일로 변경해요.
금요일이나 토요일 예약이라면 _다음_ 주 금요일로 변경해요.
