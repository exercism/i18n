# 소개

Go에서 불리언은 미리 선언된 불리언 타입 `bool`로 표현되며, 값은 `true` 또는 `false` 중 하나예요.
정의된 타입이에요.

```go
var closed bool    // boolean variable 'closed' implicitly initialized with 'false'
speeding := true   // boolean variable 'speeding' initialized with 'true'
hasError := false  // boolean variable 'hasError' initialized with 'false' 
```

Go는 표현식을 불리언 값으로 평가해 `true` 또는 `false`를 반환하는 세 가지 논리 연산자를 지원해요.

| 연산자 | 의미 |
| ----------- | --------------------------------------------- |
| `&&` (논리곱) | 두 명제가 모두 참이면 참이에요. |
| `\|\|` (논리합) | 적어도 하나의 명제가 참이면 참이에요. |
| `!` (논리 부정) | 명제가 거짓일 때만 참이에요. |
