# 설치

시스템에 설치하는 방법은 [시스템/설치][install-link]를 참고해요.

~~~exercism/caution
Java Development Kit(JDK)가 설치되어 있으면 `jconsole` 실행 파일이 같은 이름을 사용하는 Java Console과 충돌할 수 있어요.

가능한 해결 방법은 다음과 같아요:

- J 프로그래밍 언어의 `jconsole` 실행 파일 이름을 고유한 이름(예: `jconsole-jlang`)으로 바꿔요.

- 시스템 환경 변수나 PATH를 조정해서 J 프로그래밍 언어의 `jconsole`이 우선되도록 해요.

- **Linux 사용자**라면 `/usr/` 디렉터리에 `ijconsole`이라는 **심볼릭 링크**를 만들어 주는 bash 스크립트가 `bin/install.sh`에 있어요. 터미널에서 `ijconsole`을 입력해 이 링크를 사용할 수 있어요.
~~~

J를 설치했다면, 터미널에서 J 콘솔을 열고 다음 명령을 입력해 단위 테스트 프레임워크를 설치해요:

```j
  load 'pacman'
  'update' jpkg ''
  'install' jpkg 'general/unittest'
  exit 0
```
