# 개요

Elixir는 공통된 범용 인터페이스를 제공하면서도, Behaviour를 구현하는 각 모듈에 맞는 구체적인 구현을 가능하게 하기 위해 _Behaviour_를 사용해요. 그중 하나가 _Access Behaviour_예요.

_Access Behaviour_는 데이터 구조에서 키 기반 데이터를 가져오기 위한 공통 인터페이스를 제공해요. 맵과 키워드 리스트에 대해 구현되어 있어요.

[`Access`][access] 모듈은 인터페이스에 필요한 콜백을 정의해요. 그러면 [`Map`][map]과 [`Keyword`][keyword] 모듈이 필요한 콜백인 [`fetch/2`][map-fetch], [`get_and_update/3`][map-get-and-update], [`pop/2`][map-pop]를 구현해요.

이 Behaviour를 사용하려면, 바인딩된 변수 뒤에 _대괄호_를 붙이고 키를 사용해서 그 키에 연결된 값을 가져오면 돼요. 맵은 어떤 타입의 키든 지원하지만, 키워드 리스트는 아톰 키만 지원해요.

```elixir
# Atom as key
my_map = %{key: "my value"}
my_map[:key]
# => "my value"

# String as key
another_map = %{"key" => "my value"}
another_map["key"]
# => "my value"
```

데이터 구조에 해당 키가 없으면 `nil`이 반환돼요. 이때는 오류가 발생하지 않기 때문에 의도하지 않은 동작의 원인이 될 수 있어요.

```elixir
my_map = %{key: "my value"}
my_map[:wrong_key][:other_wrong_key]
# => nil
```

`nil` 자체도 Access Behaviour를 구현하고 있어서, 어떤 키에 대해서도 항상 `nil`을 반환한다는 점에 주의해요.

```elixir
nil[:key]
# => nil
```

구조체는 Access Behaviour를 구현하지 않아요.
