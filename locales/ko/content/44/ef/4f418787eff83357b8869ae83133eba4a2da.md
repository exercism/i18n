# 정보

Clojure에서 `vector`는 값이 0개 이상 담긴, 순차적이고 인덱스로 접근할 수 있는 불변 컬렉션이에요. 즉, 한 번 만들어진 벡터는 수정할 수 없어요. 벡터를 다루는 함수는 새로운 벡터를 반환하고, 원래 벡터는 그대로 남아 있어요. 벡터에는 서로 다른 타입의 값을 담을 수 있어요. 벡터는 다음과 같이 정의해요:

```clojure
(def empty [])
(def single-value [5])
(def single-value-alternative (vector 5))
(def three-values [1 "a" "b"])
```

벡터의 원소는 인덱스를 사용해 가져올 수 있어요. Clojure 벡터의 인덱스는 0부터 시작해요. 즉, 첫 번째 원소의 인덱스는 항상 0이에요:

```clojure
(def numbers [2 3 5])
;; Read value from vector
(get numbers 2)
;;=> 5
;; Update value in vector
(assoc numbers 2 9)
;;=> [2 3 9]
```

원래 벡터는 변경되지 않아요:

```clojure
numbers
;;=> [2 3 5]
```

갱신된 값을 기억하려면, 그 값을 계속 전달하거나 var에 담아 둬야 해요:

```clojure
(def updated-numbers
  (assoc numbers 2 9))
(get updated-numbers 2)
;;=> 9
```
