# 학습

SQLite가 처음이고 SQL 문법과 데이터베이스 관리의 기초를 배우고 싶다면, 초보자를 위해 만들어진 훌륭한 자료들이 있어요:

- **YouTube의 SQL 입문**: Danielle Thé가 만든 초보자용 4분 영상 [What is SQL?][sql-youtube]을 확인해 봐요.

- **SQLite 튜토리얼**: [SQLite Tutorials][sqlite-tutorial]는 데이터베이스 생성, 쿼리, 데이터 조작 같은 기본 개념을 다루면서 SQLite를 초보자 친화적으로 소개해요.

- **SQLZoo**: [SQLZoo][sqlzoo]에서 상호작용형 연습 문제와 튜토리얼로 SQL 실력을 키워 봐요. 초보자에게 알맞은 SQLite 관련 내용도 포함돼 있어요.

이 자료들은 SQLite와 SQL 문법을 배우는 데 기본 토대를 마련해 주고, 초보자가 데이터베이스 개념을 이해하고 SQLite 데이터베이스를 직접 다뤄 보는 경험을 쌓도록 도와줘요.

[sqlite-tutorial]: https://www.sqlitetutorial.net/
[sql-youtube]: https://www.youtube.com/watch?v=27axs9dO7AE
[sqlzoo]: https://sqlzoo.net/
