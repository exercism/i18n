# 힌트

## 일반

- [`while`][while-loops]문은 _불확정_(횟수를 세지 않는) 반복에 사용해요.
- [`for`][for-loops]문은 _확정_(횟수를 세는) 반복에 사용해요.
- [`break`와 `continue`][control flow] 키워드는 루프의 동작을 원하는 대로 바꾸는 데 도움이 돼요.
- [`range(<start>, <stop>, <step>)`][range]를 사용하면 루프 카운터로 쓸 수열을 만들 수 있어요.
- 내장 함수 [`enumerate()`][enumerate]는 순회할 수 있는 (`<value>`, `<index>`) 쌍을 반환해요.

다음 내용에도 익숙해지면 과제를 완료하는 데 도움이 돼요:

- [`lists`][list]: 인덱싱, 중첩 리스트, [`<list>.append()`][append and pop], [`<list>.pop()`][append and pop].
- [`str`][str]: `str()` 생성자, `+`로 문자열 이어 붙이기, 선택적으로 [`f-strings`][f-strings].

## 1. 점수 반올림하기

- `While` 루프는 테스트 조건이 `False`로 평가될 때까지 계속 실행돼요.
- `<list>.pop()`은 `list`의 마지막 항목을 제거하고 반환해요.
- 빈 리스트는 `False`로 평가돼요 (Python에서 대부분의 빈 객체는 "Falsy"예요)

## 2. 통과하지 못한 학생

- `for`문으로 객체를 순회할 때는 `loop` 카운터나 `index` 카운터를 선언할 필요가 없어요.
- 결과 카운터는 설정하고 _증가시켜야_ 해요. 루프가 끝나면 통과하지 못한 학생 수를 `return`하고 싶을 거예요.

## 3. "최고" 점수

- `for`문으로 객체를 순회할 때는 `loop` 카운터나 `index` 카운터를 선언할 필요가 없어요.
- 여기서는 "최고" 점수를 추가할 빈 `list`를 준비해 두면 도움이 돼요.
- `<list>.append()`는 결과 `list`에 항목을 추가하는 데 도움이 돼요.

## 4. 알파벳 등급 계산하기

- 이 값들은 _하한선_이에요. "D"의 _하한선_은 **41**점인데, "F"가 **<= 40**이기 때문이에요.
- [`range()`][range]는 "F"에서 "A"로 올라가는 적절한 간격의 수열을 만들 때 도움이 돼요.
- 매개변수 없이 [`round()`][round]를 사용하면 간격을 깔끔하게 반올림해 줘요.
- "최고" 과제에서처럼, `<list>.append()`는 `range()`의 항목을 결과 `list`에 추가할 때 유용해요.

## 5. 이름과 점수 연결하기

- [`enumerate()`][enumerate]가 여기서 도움이 될 수 있어요.
- 두 리스트의 길이가 같고 같은 방식으로 정렬되어 있다면, 한쪽의 `index`로 다른 쪽의 `value`를 가져올 수 있을까요?

## 6. "완벽한" 점수

- 100점을 받은 학생이 있을 수도 있고 없을 수도 있으니, **모든** 점수를 확인하지 않고는 `[]`를 반환할 수 없어요.
- [`control flow`][control flow] 문인 `continue`와 `break`는 원하지 않는 값을 건너뛰는 데 유용할 수 있어요.
