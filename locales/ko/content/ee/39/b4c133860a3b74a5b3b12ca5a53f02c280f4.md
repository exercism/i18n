# 지침

루시안의 여자친구가 집으로 오고 있는데, 루시안은 아직 기념일 저녁 식사를 만들지 않았어요!

이 연습 문제에서는 루시안이 가장 좋아하는 요리책에 나오는 근사한 라자냐를 만들 수 있도록 코드를 작성해요.

라자냐를 요리하는 데 드는 시간과 관련된 네 가지 과제가 있어요.

## 1. 예상 오븐 시간(분) 정의하기

라자냐를 오븐에 몇 분 동안 넣어 두어야 하는지를 나타내는 `EXPECTED_MINUTES_IN_OVEN` 상수를 정의해요. 이 상수는 내보내야 해요. 요리책에 따르면 예상 오븐 시간은 `40`분이에요.

## 2. 남은 오븐 시간(분) 계산하기

`remainingMinutesInOven` 함수를 구현해요. 이 함수는 라자냐가 오븐에 있었던 실제 시간(분)을 _매개변수_로 받아서, 이전 과제의 **예상 오븐 시간(분)** 을 기준으로 라자냐가 오븐에 몇 분 더 있어야 하는지를 _반환_해요.

```javascript
remainingMinutesInOven(30)
// => 10
```

## 3. 준비 시간(분) 계산하기

`preparationTimeInMinutes` 함수를 구현해요. 이 함수는 라자냐에 추가한 층의 개수를 _매개변수_로 받아서, 각 층을 준비하는 데 2분이 걸린다고 가정할 때 라자냐를 준비하는 데 몇 분을 썼는지를 _반환_해요.

```javascript
preparationTimeInMinutes(2)
// => 4
```

## 4. 총 작업 시간(분) 계산하기

`totalTimeInMinutes` 함수를 구현해요. 이 함수는 _매개변수 두 개_를 받는데, `numberOfLayers` 매개변수는 라자냐에 추가한 층의 개수이고, `actualMinutesInOven` 매개변수는 라자냐가 오븐에 있었던 시간(분)이에요. 이 함수는 라자냐 요리에 쓴 총 시간(분), 즉 준비 시간(분)과 현재까지 라자냐가 오븐에 있던 시간(분)의 합을 _반환_해야 해요.

```javascript
totalTimeInMinutes(3, 20)
// => 26
```
