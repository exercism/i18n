# 숫자 타입

Crystal에는 다양한 목적을 위한 여러 가지 숫자 타입이 있어요.
예를 들어, 어떤 타입은 다른 타입보다 빠르지만 표현할 수 있는 값의 범위가 더 좁아요.
반대로 값의 범위는 더 넓지만 느린 타입도 있어요.

Crystal에는 부호 있는 정수 타입과 부호 없는 정수 타입이 모두 있어요.
부호 있는 정수 타입은 양수와 음수를 모두 나타낼 수 있어요.
부호 없는 정수 타입은 양수만 나타낼 수 있어요.

## 부호 있는 정수 타입

다음은 Crystal의 [부호 있는 정수 타입][int]이에요:

| 타입     | 크기 (비트) | 범위                                                                                                        |
| -------- | ----------- | ----------------------------------------------------------------------------------------------------------- |
| `Int8`   | 8           | -128 ~ 127                                                                                                  |
| `Int16`  | 16          | -32_768 ~ 32_767                                                                                            |
| `Int32`  | 32          | -2_147_483_648 ~ 2_147_483_647                                                                              |
| `Int64`  | 64          | -9_223_372_036_854_775_808 ~ 9_223_372_036_854_775_807                                                      |
| `Int128` | 128         | -170_141_183_460_469_231_731_687_303_715_884_105_728 ~ 170_141_183_460_469_231_731_687_303_715_884_105_727 |

작은 타입은 큰 타입보다 메모리를 적게 쓰고 더 빠르지만, 표현할 수 있는 값의 범위가 더 좁아요.

값이 특정 범위 안에 들어온다는 것을 알고 있다면, 메모리를 아끼고 성능을 높이기 위해 가능한 한 가장 작은 타입을 쓰는 게 가장 좋아요.

기본 정수 타입은 `Int32`예요.
특정 타입의 정수를 선언하려면 숫자 뒤에 `<number>_I <bit>` 형태로 접미사를 붙여 타입 이름을 지정할 수 있어요.

```crystal
1_i8.class
# => Int8
```

`to_i<bit>` 메서드로 서로 다른 정수 타입 사이를 변환할 수 있어요.
`to_i` 메서드는 기본 정수 타입인 `Int32`로 변환해요.

```crystal
1_i8.to_i16.class
# => Int16

2_i16.to_i.class
# => Int32
```

## 부호 없는 정수 타입

다음은 Crystal의 [부호 없는 정수][uint] 타입이에요:

`UInt8`, `UInt16`, `UInt32`, `UInt64`, `UInt128`

부호 있는 정수와 부호 없는 정수의 유일한 차이는 부호 없는 정수가 양수만 나타낼 수 있다는 점이에요.
특정 타입의 부호 없는 정수를 선언하려면 숫자 뒤에 `<number>_u<bit>` 형태로 접미사를 붙여 타입 이름을 지정할 수 있어요.
`to_u<bit>` 메서드로 서로 다른 부호 없는 정수 타입 사이를 변환할 수 있어요.
`to_u` 메서드는 기본 부호 없는 정수 타입인 `UInt32`로 변환해요.

```crystal
1_u8.to_u16.class
# => UInt16
```

## 부동소수점 타입

다음은 Crystal의 부동소수점 타입이에요:

| 타입      | 크기 (비트) | 범위                 |
| --------- | ----------- | -------------------- |
| `Float32` | 32          | 1.2E-38 ~ 3.4E+38    |
| `Float64` | 64          | 2.3E-308 ~ 1.7E+308  |

[부동소수점 타입][float]은 두 가지가 있는데, 하나가 다른 하나보다 더 정밀해요.

기본 부동소수점 타입은 `Float64`예요.

`to_f<bit>` 메서드로 서로 다른 부동소수점 타입 사이를 변환할 수 있어요.
`to_f` 메서드는 기본 부동소수점 타입인 `Float64`로 변환해요.

[float]: https://crystal-lang.org/api/latest/Float.html
[int]: https://crystal-lang.org/api/latest/Int.html
[uint]: https://crystal-lang.org/api/latest/UInt32.html
