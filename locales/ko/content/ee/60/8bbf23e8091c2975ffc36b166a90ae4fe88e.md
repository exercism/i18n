# 소개

Elixir는 코드 _비헤이비어_를 사용해서 공통의 범용 인터페이스를 제공하는 한편, 이를 구현하는 각 모듈에는 그 모듈만의 구현을 가능하게 해요. 그런 흔한 예 중 하나가 _Access 비헤이비어_예요.

_Access 비헤이비어_는 키 기반 자료 구조에서 데이터를 가져오기 위한 공통 인터페이스를 제공해요. _Access 비헤이비어_는 맵과 키워드 리스트에 구현되어 있는데, 맵에서 어떻게 쓰이는지 살펴보면서 감을 잡아봐요. _Access 비헤이비어_는 맵이 있을 때 그 뒤에 _대괄호_를 붙이고, 키를 사용해서 그 키에 연결된 값을 가져올 수 있다고 정의해요.

```elixir
# Suppose we have these two maps defined (note the difference in the key type)
my_map = %{key: "my value"}
your_map = %{"key" => "your value"}

# Obtain the value using the Access Behaviour
my_map[:key] == "my value"
your_map[:key] == nil
your_map["key"] == "your value"
```

키가 자료 구조에 없으면 `nil`이 반환돼요. 이때는 오류가 발생하지 않기 때문에, 의도하지 않은 동작의 원인이 될 수 있어요. `nil` 자체도 Access 비헤이비어를 구현하고 있어서 어떤 키에 대해서도 항상 `nil`을 반환한다는 점에 유의해요.
