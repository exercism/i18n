# 소개

[`Vectors`][vectors] 개념에서 "배열은 Julia 언어의 핵심"이라고 했고, 벡터는 1차원 배열이라고 했어요.

그렇다면 Julia가 벡터로 _여러 가지 일_을 하는 다양하고 강력한 방법을 많이 제공하리라고 기대하는 게 당연해요. 그게 정확히 무엇을 뜻하든 간에요.

## 벡터를 입력으로 받는 함수

아주 단순한 함수 몇 개는 벡터를 입력으로 받아 스칼라 값을 반환해요.

```julia
v = [2, 3, 4]
length(v)  # => 3
sum(v)  # => 9
```

## 산술 연산

숫자로 이루어진 벡터가 하나 있고, 각 값에서 0.5를 빼고 싶다고 해봐요.

```julia-repl
julia> v = [1.2, 1.5, 1.7]
3-element Vector{Float64}:
 1.2
 1.5
 1.7

julia> v - 0.5
ERROR: MethodError: no method matching -(::Vector{Float64}, ::Float64)
```

이건 실패해요. 그럼 다른 벡터를 빼면 어떨까요?

```julia-repl
julia> v - [0.5, 0.5, 0.5]
3-element Vector{Float64}:
 0.7
 1.0
 1.2
```

성공하지만, 벡터가 길어질수록 꽤 번거롭고 메모리도 많이 잡아먹어요.

다행히 Julia에는 이 문제를 아주 간단히 해결해 주는 "마법의" 점이 있어요. `v .- 0.5`만 쓰면 돼요.

그 이유는 다음 절에서 설명해요.

## 브로드캐스팅

`v - 0.5`는 실패하는데 `v .- 0.5`는 성공해요. 이 점이 무슨 일을 하는지 이해해야 해요.

점은 두 가지 일을 하는데, 이 둘이 합쳐져서 원하는 결과를 만들어요.

### 1. 원소별 적용

먼저, 중위 연산자 _앞에_ 점을 붙이면 "이 연산을 각 원소에 따로따로 적용하라"는 뜻이에요.

마찬가지로, 함수 이름 _뒤에_ 점을 붙이면 그 함수가 "벡터화"돼요. 스칼라 입력을 위해 작성된 함수라도 마찬가지예요.

```julia-repl
julia> sqrt.([1, 4, 9])
3-element Vector{Float64}:
 1.0
 2.0
 3.0
```

### 2. 싱글턴 확장

앞의 예제에서 길이가 같은 벡터끼리 뺄 수 있다는 걸 봤어요. 다만 `.-`는 원소별 연산이라는 의도를 분명히 드러내는, `-`보다 _더 안전한_ 연산자라는 점을 알아두세요.

```julia-repl
julia> v .- [0.5, 0.5, 0.5]
3-element Vector{Float64}:
 0.7
 1.0
 1.2
```

길이가 다른 벡터라면 어떨까요?

```julia-repl
julia> v .- [0.5, 0.5]
ERROR: DimensionMismatch: arrays could not be broadcast to a common size

julia> v .- [0.5,]
3-element Vector{Float64}:
 0.7
 1.0
 1.2
```

일반적으로 길이가 다르면 오류예요. 다만 한쪽의 길이가 1일 때는 _예외_예요 (엄밀히는 "싱글턴" 차원이죠).

`[0.5,]`나 그냥 `0.5` 같은 싱글턴은 반복을 통해 필요한 길이로 자동으로 확장돼요. 이것이 `broadcasting`의 핵심이에요.

### 제자리 브로드캐스팅

메모리 사용이 걱정된다면, 제자리 연산이 할당을 줄이기 위해 흔히 찾는 방법이에요.

하지만 위 예제의 브로드캐스팅 연산은 원본을 수정하는 대신 새로운 `Vector`를 만들어요.

원본 `Vector`를 제자리에서 수정하려면, 그 수정 작업을 브로드캐스트해야 해요.

```julia-repl
julia> v .= v .+ 1
3-element Vector{Int64}:
 2
 3
 4

julia> v .+= 1  # equivalent operation to above
3-element Vector{Int64}:
 3
 4
 5

julia> v
3-element Vector{Int64}:
 3
 4
 5
```

## 인덱싱

인덱스 번호로 벡터의 원소를 선택하는 방법은 이전 개념에서 다뤘어요.

```julia
a = collect('A':'Z')  # => 26-element Vector{Char}

# index with an integer
a[2]  # => 'B'

# index with a range
 a[12:2:18]  # => ['L', 'N', 'P, 'R']
 
 # index with another vector
 a[ [1, 3, 5] ]  # => ['A', 'C', 'E']
```

### 논리 인덱싱

어떤 논리식(엄밀히는 "술어")을 만족하는 원소를 선택할 수도 있어요. 보통은 브로드캐스팅이 필요해요.

```julia-repl
julia> a[a .< 'D']
3-element Vector{Char}:
 'A': ASCII/Unicode U+0041 (category Lu: Letter, uppercase)
 'B': ASCII/Unicode U+0042 (category Lu: Letter, uppercase)
 'C': ASCII/Unicode U+0043 (category Lu: Letter, uppercase)
```

식이 더 복잡해지면 점이 점점 늘어나요 (하지만 점은 작고 입력하기 쉬워요).

```julia-repl
julia> a[a .< 'D' .|| a .> 'W']
6-element Vector{Char}:
 'A': ASCII/Unicode U+0041 (category Lu: Letter, uppercase)
 'B': ASCII/Unicode U+0042 (category Lu: Letter, uppercase)
 'C': ASCII/Unicode U+0043 (category Lu: Letter, uppercase)
 'X': ASCII/Unicode U+0058 (category Lu: Letter, uppercase)
 'Y': ASCII/Unicode U+0059 (category Lu: Letter, uppercase)
 'Z': ASCII/Unicode U+005A (category Lu: Letter, uppercase)
```

"벡터"는 사실 범위 같은, 순서가 있는 적절한 이터러블이면 무엇이든 될 수 있다는 점을 기억해 두세요.

```julia-repl
julia> n = 3:10
3:10

julia> n[isodd.(n)]
4-element Vector{Int64}:
 3
 5
 7
 9
```
