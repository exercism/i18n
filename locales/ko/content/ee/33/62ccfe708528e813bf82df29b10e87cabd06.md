# 힌트

## 일반

- getter와 setter 메서드를 만들려면 `getter`, `setter`, `property` 매크로를 사용해야 해요.

## 1. 저울의 초기 상태 만들기

- 저울을 초기화하려면 `initialize` 메서드를 사용해요.
- 이 메서드는 `precision`과 `metric`, 두 인자를 받아야 하고, 각각 `Int32`와 `Bool`이어야 해요.
  이 값들은 인스턴스 변수 `@precision`과 `@metric`을 설정하는 데 사용해요.
- 인스턴스 변수 `@weight`는 `0.0`으로 설정해야 해요.

## 2. 저울이 정밀도를 갖도록 하기

- `getter` 매크로를 사용하면 인스턴스 변수의 값을 반환하는 메서드를 정의할 수 있어요.

## 3. 저울의 무게를 설정할 수 있게 하기

- `property` 매크로를 사용하면 인스턴스 변수의 값을 가져오고 설정하는 메서드를 정의할 수 있어요.

## 4. 미터법과 야드파운드법 단위를 전환할 수 있게 하기

- `setter` 매크로를 사용하면 인스턴스 변수의 값을 설정하는 메서드를 정의할 수 있어요.
