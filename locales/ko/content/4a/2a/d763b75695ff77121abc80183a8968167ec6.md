# 지시 사항

여러분은 챗봇을 개발하는 회사에서 정규 표현식 전문가로 일하게 되었어요.

아직 개발이 아주 초기 단계예요.
여러분의 임무는 정규 표현식을 사용해서 챗봇이 자연어를 이해하고 생성하는 능력을 향상시키는 것이에요.

## 1. 유효한 명령 확인하기

챗봇은 똑똑할 뿐만 아니라 충실한 비서이기도 해요.
챗봇에게 무언가를 물어보려면 명령의 맨 앞에 "**Chatbot**"이라는 단어를 말해야 해요.
키워드가 대문자든 소문자든 상관없어요.
중요한 것은 단어의 위치예요.

사용자가 명령을 내리는지 챗봇이 알아볼 수 있도록 `is_valid_command` 함수를 구현해요.

```jq
"Chatbot, play a song from the 80's." | is_valid_command
# => true
"Hey Chatbot, where is the closest pharmacy?" | is_valid_command
# => false
"CHATBOT, do you have a solution for this challenge?" | is_valid_command
# => true
```

## 2. 암호화된 이모지 제거하기

챗봇은 사람들이 감정을 표현하려고 이모지를 어떻게 사용하는지 이해하는 데 어려움을 겪어요.
챗봇이 사용자 메시지를 받으면 각 이모지는 "emoji" 문자열 뒤에 _id 번호_가 붙은 형태로 표현돼요.

문자열을 받아서 메시지 전체에 있는 모든 이모지를 제거하는 `remove_emoji` 메서드를 구현해요.

이모지가 없는 줄은 그대로 반환해야 해요.
이모지 문자열만 제거해요.
공백은 그대로 둬요.

```jq
"I love playing videogames emoji3465 it's one of my hobbies" | remove_emoji
# => "I love playing videogames  it's one of my hobbies"
```

## 3. 유효한 전화번호 확인하기

챗봇과 대화하다 보면 사용자가 전화번호를 알려줄 때가 있어요.
챗봇은 특정 형식의 번호로만 전화를 걸 수 있어요.

`check_phone_number` 함수를 구현해요.

번호가 유효하면 챗봇은 사용자에게 감사하고 번호를 확인해 주는 메시지로 답해요.
번호가 유효하지 않으면 챗봇은 전화번호가 유효하지 않다고 사용자에게 알려줘요.

기대하는 형식은 `(+NN) NNN-NNN-NNN`이고, 여기서 N은 숫자예요.

```jq
"chatbot my phone number is (+34) 659-771-594" | check_phone_number
# => "Thanks! Your phone number is OK."
"chatbot, call me at 659-771-594" | check_phone_number
# => "Oops, it seems like I can't reach out to 659-771-594."
```

## 4. 웹사이트 링크 가져오기

챗봇은 정말 호기심 많은 소프트웨어예요.
특정 주제에 대해 인터넷을 검색할 수 있으면서도, 관련 정보를 찾기 위해 방문할 만한 멋진 웹사이트를 사용자에게 묻는 것을 좋아해요.

대화 예시:

> **챗봇**: 안녕하세요, 저는 JavaScript로 코딩하는 법을 배우고 싶어요. 제가 배울 수 있는 멋진 웹사이트를 아시나요?

> **사용자**: 저는 exercism.org에서 많이 배웠어요. 거기에 좋은 내용이 정말 많아요.

웹사이트 도메인 배열을 반환하는 `get_domains` 함수를 구현해요.

```jq
"I learned a lot from exercism.org and google.com" | get_domains
# => ["exercism.org", "google.com"]
```

## 5. 사용자에게 인사하기

예의 바른 챗봇은 사용자를 이름으로 부르며 말해요.
사용자가 자신을 소개하면 우리 챗봇은 그 이름을 알아내고 다정하게 인사해요.

`nice_to_meet_you` 함수를 작성해요.

입력 문자열에 "My name is Someone."이라는 문장이 포함되어 있으면 이름을 캡처해서 "Nice to meet you, Someone."이라는 문자열을 반환해요.

```jq
"My name is Jean-Luc" | nice_to_meet_you
# => "Nice to meet you, Jean-Luc"
```

## 6. 아주 간단한 CSV 파싱하기

"기능 증식증"에 굴복한 김에, 챗봇에 CSV 파싱 함수를 추가해 볼게요.

문자열을 받아서 파싱된 필드들의 배열을 반환하는 `parse_csv` 함수를 구현해요.
필드 구분자는 "쉼표와 그 뒤에 올 수 있는 공백"이에요.

CSV 형식의 여러 예외적인 경우(예를 들어 필드에 쉼표가 포함된 경우)는 걱정하지 않아요.

```jq
"first, second,third,   fourth" | parse_csv
# => ["first", "second", "third", "fourth"]
```
