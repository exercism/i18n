# 문제 해결 전략


이곳의 첫 번째 글에서 말하듯이, **_문제 해결은 메타 스킬_**이에요.
어떤 문제를 풀 때 가장 어려운 부분은 프로그래밍 언어의 문법이나 구조가 아니라, _무엇을 코딩할지_ 또는 _어디서부터 시작할지_를 알아내는 일인 경우가 많아요.
문제를 코딩할 수 있는 단계로 나누는 전략과 체계를 만드는 것은 꼭 키워볼 만한 **훌륭한** 능력이에요.
아래에는 이런 능력을 키우는 데 도움이 되는, 커뮤니티에서 모은 글과 영상, 책을 소개해요.


- Free Code Camp에는 [프로그래머처럼 생각하기 - 문제 해결 수업][free-code-camp-think-like-a-programmer]이라는 좋은 개요 글이 있어요.
- fast.ai의 창립자인 Jeremy Howard가 [G. Polya의 문제 해결 기법][g-polya-how-to-solve-it-summary]을 잘 정리해 두었어요.
- 1945년에 복잡한 수학 문제를 풀기 위한 지침으로 쓰인 [G. Polya's How To Solve It][g-polya-how-to-solve-it](책 전체)은 오늘날에도 문제 해결 전반에 여전히 _훌륭한_ 조언을 줘요.
- Towards Data Science에 글을 쓰는 Kurtis Pykes는 프로그래머의 문제 해결 능력을 키우는 방법을 다룬 친절한 [문제 해결 실습 튜토리얼][Kurtis Pykes: Hands-on Tutorial - How to Improve Your Problem-Solving Skills as A Programmer]을 제공해요.
- Free Code Camp 글에서 언급된 V. Anton Spraul의 [Think Like a Programmer: An Introduction to Creative Problem Solving][v-anton-spraul-think-like-a-programmer]은 Polya가 수학을 위해 정리한 것과 같은 일반적인 방법을 더 현대적이고 프로그래밍에 초점을 맞춰 다룬 책이에요.
- [Felienne Hermans][felienne-hermans]는 사람들이 코딩이라는 기술을 _어떻게_ 배우는지, 그리고 그것이 일반적인 학습과 어떻게 이어지는지에 더 초점을 맞춰요.
  그녀는 코드를 더 잘 읽고, 코드를 명확하게 생각하고, 더 나은 코드를 쓰고, 더 나은 코드 협업자가 되기 위한 전략을 담은 [The Programmer's Brian][programmers-brain-free-online]을 썼어요.
  - 그녀의 책은 [여기][programmers-brain-manning]에서 종이책으로 주문할 수 있어요.
  - 같은 주제를 다룬 흥미로운 영상도 두 편 있어요: [How to Teach Programming (and other things)?][felienne-hermans-how-to-teach-programming]과 [Programming is Writing is Programming ][felienne-hermans-programming-is-writing-is-programming].
- No Starch Press에서 나온 [Algorithmic Thinking (Daniel Zingaro)][daniel-zingaro-algorithmic-thinking]와 [How to think like a programmer (Paul Vickers)][paul-vickers-how-to-think-like-a-programmer]도 코딩할 때의 문제 해결을 다뤄요.
- [Computational Thinking: A beginner's guide to problem-solving and programming (Karl Beecher)][beecher-computational-thinking]와 [Computational Thinking for the Modern Problem-Solver (Riley and Hunt)][riley-and-hunt-computational-thinking]도 문제를 어떻게 생각하고 코딩으로 풀 수 있게 나눌지에 대한 전략을 제시해요.
- [From Computing to Computational Thinking (Paul S. Wang)][wang-computational-thinking]은 조금 더 일반적이고 학술적이지만, 코딩을 넘어서도 적용할 수 있는 문제 해결 전략과 구조를 알려 주고, 사전 프로그래밍 지식이 없어도 읽을 수 있어요.

이 책들 중 일부는 Association of Computing Machinery(ACM) 라이브러리를 통해서도 읽을 수 있어요.
유료 회원 가입 정보는 [acm(dot)org][association-for-computing-machinery]에서 볼 수 있어요.
