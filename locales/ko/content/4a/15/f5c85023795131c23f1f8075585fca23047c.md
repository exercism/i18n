# 자세히 알아보기

많은 연산자는 [복합 대입][compound-assignment]으로도 사용할 수 있어요. 복합 대입은 `x = op y`를 `x op= y`로 쓸 수 있는 축약 표기예요:

```csharp
var features = PhoneFeatures.Call;
features |= PhoneFeatures.Text;
features &= ~PhoneFeatures.Call;
```
