# 소개

Kotlin에서 함수는 일급 시민이에요.
그래서 함수를 변수에 저장할 수 있고, 인자로 전달할 수 있으며, 다른 함수가 반환할 수도 있어요.
예를 들어, 함수를 `addOne` 변수에 할당하면 다음과 같아요.

```kotlin
val addOne = fun (num : Int) : Int {
    return num + 1
}
```

함수는 또 다른 함수를 반환할 수도 있어요.

```kotlin
fun makeAddOne() : (Int) -> Int {
    return fun(num : Int) : Int {
        return num + 1
    }
}

val addOne = makeAddOne()
```

한 번 할당하고 나면, 마치 또 다른 함수인 것처럼 변수를 통해 그 함수를 호출할 수 있어요.
```kotlin
addOne(3)
// => 4
```

## 함수 타입 선언하기

변수나 매개변수의 타입은 `(parameter types) -> return type` 문법으로 선언할 수 있어요.
예를 들어, 변수를 선언하면 다음과 같아요.

```kotlin
val addOne : (Int) -> Int = fun (num : Int) : Int {
    return num + 1
}
```

함수의 매개변수도 마찬가지예요.

```kotlin
fun perform(operation : (Int) -> Int) {
    operation(3)
}
```

## 람다 표현식

람다 표현식은 함수를 정의하는 더 짧은 방법이에요.
람다 표현식은 `{ parameters -> body }` 형태로 작성해요.
표현식은 본문의 마지막 문에 있는 마지막 값을 반환해요.
예를 들어 볼까요?

```kotlin
// Assigning to a variable
val addOne = { num : Int -> num +  1}

// In a function call
perform({ num : Int -> num + 1 })
```

Kotlin은 정보가 충분하면 타입을 추론할 수 있어요.
예를 들어, 위의 예제는 이렇게 쓸 수도 있어요.

```kotlin
// Assigning to a variable
val addOne : (Int) -> Int = { num -> num + 1 }

// Or ...
val addOne  = { num : Int -> num + 1 }

// Using in a function
perform({ num -> num + 1 })
```

## 매개변수가 하나인 람다에서의 `it`

표현식에 매개변수가 하나뿐이라면, 그 매개변수는 생략할 수 있어요.
그러면 Kotlin이 본문에서 `it`이라는 매개변수를 사용할 수 있게 해줘요.
예를 들어 다음과 같아요.

```kotlin
val addOne : (Int) -> Int = { it +  1 }
```

## 후행 람다 전달하기

함수의 마지막 인자가 람다라면, 람다 표현식은 괄호 _뒤에_ 바로 작성해요.
예를 들어 볼까요?

```kotlin
// Function that takes a function as last argument
fun calculateFrom(from : Int, operation : (Int) -> Int) : Int {
    return operation(from)
}

// Call the calculateFrom function
calculateFrom(2) { it * 3 }
// => 6
```
