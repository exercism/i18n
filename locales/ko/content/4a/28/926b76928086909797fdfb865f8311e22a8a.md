# 힌트

## 일반

- [공식 시작 가이드][getting-started-enum]나 [elixirschool.com][elixir-school-enum]에서 `Enum` 모듈에 대해 읽어봐요.
- [`Enum` 모듈의 함수 목록][enum-functions]을 문서에서 확인해 봐요.

## 1. 가격순으로 상품 정렬하기

- 정렬 함수를 사용해 Enumerable을 정렬하는 [내장 함수][enum-sort-by]가 있어요.

## 2. 가격이 없는 상품 모두 찾기

- Enumerable을 필터링하는 [내장 함수][enum-filter]가 있어요.

## 3. 상품 이름 바꾸기

- Enumerable의 모든 원소를 변환하는 [내장 함수][enum-map]가 있어요.
- 한 문자열의 모든 부분을 다른 문자열로 바꿀 수 있는 [내장 함수][string-replace]도 있어요.

## 4. 상품의 수량 늘리기

- 맵은 Enumerable 프로토콜을 구현해요.
- `Enum` 함수는 맵을 `{key, value}` 튜플의 배열로 변환해요.
- 변환 함수를 사용해 `{key, value}` 튜플의 배열을 다시 맵으로 바꿀 수 있는 서로 다른 함수가 두 개 있어요. [하나는 항상 새로운 맵을 반환하고][map-new], [다른 하나는 Collectable을 직접 고를 수 있어요][enum-into].

## 5. 상품의 총 수량 계산하기

- 맵은 Enumerable 프로토콜을 구현해요.
- `Enum` 함수는 맵을 `{key, value}` 튜플의 배열로 변환해요.
- Enumerable을 하나의 값으로 축약하는 [내장 함수][enum-reduce]가 있어요.
