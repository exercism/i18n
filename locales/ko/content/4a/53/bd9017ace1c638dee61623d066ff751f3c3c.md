# 지시 사항 추가

## 힌트

이 연습 문제의 테스트는 평소 접하는 테스트와 달라요. 보통 테스트는 주어진 입력에 대해 출력이 기대하는 값과 일치하는지 확인해요. 이것을 _값 기반 테스트_라고 해요. 하지만 이 연습 문제는 _속성 기반 테스트_를 사용해요. 속성 기반 테스트에서는 여러 입력에 대해 출력이 특정 속성을 가지는지 확인해요. 속성 기반 테스트와 값 기반 테스트를 구분하는 두 가지 중요한 차이는 다음과 같아요:

1. 속성 기반 테스트는 하나의 입력 값이 아니라 여러 입력 값으로 동작해요.
1. 속성 기반 테스트는 구체적인 값이 아니라 속성을 검증해요.

이 연습 문제에서 테스트는 모두 코드가 만들어야 하는 다이아몬드 모양의 속성을 검증해요. 게다가 모든 테스트는 테스트하는 속성이 모든 유효한 입력 문자('A'부터 'Z'까지)에 대해 성립하는지 확인해요.

속성 기반 테스트를 하기 위해, 이 연습 문제의 테스트는 [FsCheck](https://www.nuget.org/packages/FsCheck)와 [FsCheck.Xunit](https://packages.nuget.org/packages/FsCheck.Xunit/2.2.0) 패키지를 활용해요. FsCheck에 대해 더 알아보려면 프레임워크 문서를 [여기](https://fscheck.github.io/FsCheck/)에서 볼 수 있어요.

속성 기반 테스트에 대해 더 알고 싶다면 [이 글](http://www.erikschierboom.com/2016/02/22/property-based-testing/)을 참고해요.
