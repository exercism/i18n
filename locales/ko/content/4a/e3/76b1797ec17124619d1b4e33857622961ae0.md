# 소개

함수는 기본적으로 외부 연결(external linkage)을 가지며, 프로젝트의 다른 어떤 파일에서든 호출할 수 있어요.
연결에 대해 더 알아보려면 [연결 개념](../linkage/introduction.md#Introduction)을 참고해요.
`static` 함수는 자신이 정의된 소스 파일 안에서만 호출할 수 있어요.

예를 들어

```c
// file scope, internal linkage
// can only be called from within this file
static void some_function()
{
    // code snipped
}

// file scope, external linkage by default
// can be called from any other file in the project
int main()
{
    // code snipped
}
```
