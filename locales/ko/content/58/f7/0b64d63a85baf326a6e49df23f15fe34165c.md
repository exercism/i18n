# 타입 변환

Cairo는 코어 라이브러리의 `Into`와 `TryInto` 트레이트를 통해 타입 변환을 지원해요. 이 트레이트는 내장 타입과 사용자 정의 타입에 모두 자주 쓰여요.

이 트레이트들은 값의 타입을 서로 변환하는 메서드를 정의해요:  

- **`Into`**: 실패할 수 없는, 확실한 변환에 사용해요.  
- **`TryInto`**: 실패할 수 있는 변환에 사용하며, `Option<T>`를 반환해요.

## `Into` 사용하기

`Into`는 대상 타입이 원본 값을 항상 담을 수 있는 변환을 처리해요.

```rust
fn main() {
    let my_u8: u8 = 10;
    let my_felt252: felt252 = my_u8.into(); // Infallible conversion
    let my_u256: u256 = my_felt252.into(); // Conversion to larger types
}
```

## `TryInto` 사용하기

`TryInto`는 변환이 실패할 수 있는 경우에 사용하며, `Option<T>`를 반환해요.

```rust
fn main() {
    let my_u256: u256 = 10;
    let my_felt252: felt252 = my_u256.try_into().unwrap(); // Success
    let my_large_u16: u16 = 2048;
    let my_large_u8: u8 = my_large_u16.try_into().unwrap(); // Panics because value doesn't fit in `u8`
}
```

## 사용자 정의 타입 변환

직접 만든 타입에도 이 트레이트들을 구현할 수 있어요.  

### 예시: `Into`

```rust
#[derive(Drop)]
struct Rectangle {
    width: u64,
    height: u64,
}

#[derive(Drop)]
struct Square {
    side_length: u64,
}

impl SquareIntoRectangle of Into<Square, Rectangle> {
    fn into(self: Square) -> Rectangle {
        Rectangle { width: self.side_length, height: self.side_length }
    }
}
```

### 예시: `TryInto`

```rust
impl RectangleIntoSquare of TryInto<Rectangle, Square> {
    fn try_into(self: Rectangle) -> Option<Square> {
        if self.height == self.width {
            Option::Some(Square { side_length: self.height })
        } else {
            Option::None
        }
    }
}
```

이렇게 하면 Cairo에서 내장 타입과 사용자 정의 타입 모두에 유연하고 타입에 안전한 변환을 제공할 수 있어요.
