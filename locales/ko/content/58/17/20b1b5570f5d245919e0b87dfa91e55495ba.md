# 예상치 못한 필수 매개변수

`${'parameter.name'}` 매개변수는 테스트에서 값과 함께 호출되기도 하고 값 없이 호출되기도 하지만, _선택 사항으로 표시되어 있지 않아서_ 테스트가 통과하지 못해요. TypeScript에서는 매개변수 뒤에 `?`를 붙여 선택 사항임을 명시적으로 나타낼 수 있어요:

```typescript
function(${'parameter.name'}?: ${'parameter.type'}) {
  //
}
```

또는 기본값을 지정하는 방법도 있어요:

```typescript
function(${'parameter.name'}: ${'parameter.type'} = <default>) {
  //
}
```
