# 소개

[D](https://dlang.org)는 C와 비슷한 문법과 정적 타이핑을 가진 시스템 프로그래밍 언어예요. 효율성, 제어력, 모델링 능력을 안전성 및 프로그래머 생산성과 결합해요. 이 언어는 원래 Walter Bright와 Andrei Alexandrescu가 D 버전 2부터 개발했어요.

D는 다양한 언어를 위한 컴파일러를 구현한 수십 년 경험의 집대성이며, 수많은 [독특한 기능](http://dlang.org/overview.html)을 갖추고 있어요:

- 뛰어난 모델링 능력을 위한 고수준 구성 요소
- 고성능 컴파일 언어
- 정적 타이핑
- C++의 진화(실수 없이)
- 운영체제 API와 하드웨어에 직접 인터페이스
- 엄청나게 빠른 컴파일 시간
- 메모리 안전 프로그래밍 허용 (SafeD)
- 유지보수가 쉽고 이해하기 쉬운 코드
- 짧은 학습 곡선 (C와 비슷한 문법, Java 등과 유사)
- C 애플리케이션 바이너리 인터페이스와 호환
- 다중 패러다임 (명령형, 구조적, 객체 지향, 제네릭, 함수형 프로그래밍 순수성, 심지어 어셈블리까지)
- 내장 오류 방지 (계약, 단위 테스트)

[D Language Foundation](https://dlang.org/foundation.html)은 D 언어를 개발하고 발전시키는 데 전념하는 조직이에요.
