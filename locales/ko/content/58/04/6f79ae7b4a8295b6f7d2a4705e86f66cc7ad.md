# 지침

이벤트를 수집하는 서비스를 작성하는 일을 맡았어요. 각 이벤트에는 날짜가 하나씩 연결되어 있는데, 서비스의 엔드포인트로 세 가지 서로 다른 형식이 들어오고 있다는 걸 알아챘어요:

- `"01/01/1970"`
- `"January 1, 1970"`
- `"Thursday, January 1, 1970"`

이들 사이에 몇 가지 공통점이 보이자, 조합 가능한 정규 표현식 패턴을 몇 개 작성하기로 했어요.

## 1. 날짜에서 일, 월, 연도를 일치시켜요

`day/0`, `month/0`, `year/0`를 구현해, 컴파일했을 때 `"01/01/1970"`(`dd/mm/yyyy`)의 숫자 구성 요소와 일치하는 문자열 패턴을 반환하도록 해요. 일과 월은 `1` 또는 `01`처럼 (앞을 0으로 채워) 나타날 수 있어요.

```elixir
"31" =~ DateParser.day() |> Regex.compile!()
# => true
"12" =~ DateParser.month() |> Regex.compile!()
# => true
"1970" =~ DateParser.year() |> Regex.compile!()
# => true
```

## 2. 요일 이름과 월 이름을 일치시켜요

`day_names/0`와 `month_names/0`를 구현해, 컴파일했을 때 각각 이름으로 표기된 요일과 월에 일치하는 문자열 패턴을 반환하도록 해요.

```elixir
"Tuesday" =~ DateParser.day_names() |> Regex.compile!()
# => true
"June" =~ DateParser.month_names() |> Regex.compile!()
# => true
```

## 3. 일, 월, 연도를 캡처해요

`capture_day/0`, `capture_month/0`, `capture_year/0`, `capture_day_name/0`, `capture_month_name/0`를 구현해, 각각의 구성 요소를 `"day"`, `"month"`, `"year"`, `"day_name"`, `"month_name"`이라는 이름으로 캡처하는 문자열 패턴을 반환하도록 해요.

```elixir
DateParser.capture_month_name()
|> Regex.compile!()
|> Regex.named_captures("December")

# => %{"month_name" => "December"}
```

## 4. 캡처를 조합해 전체 날짜를 캡처해요

`capture_numeric_date/0`, `capture_month_name_date()`, `capture_day_month_name_date/0`를 구현해, 3번에서 다룬 구성 요소를 각각의 날짜 형식으로 캡처하는 문자열 패턴을 반환하도록 해요:

- 숫자 날짜 - `"01/01/1970"`
- 월 이름 날짜 - `"January 1, 1970"`
- 요일 + 월 이름 날짜 - `"Thursday, January 1, 1970"`

```elixir
DateParser.capture_numeric_date()
|> Regex.compile!()
|> Regex.named_captures("01/01/1970")

# => %{"day" => "01", "month" => "01", "year" => "1970"}
```

## 5. 캡처 범위를 좁혀 날짜에만 일치시켜요

`match_numeric_date/0`, `match_month_name_date/0`, `match_day_month_name_date/0`를 구현해, 날짜에만 일치하면서 구성 요소도 캡처할 수 있는, 컴파일된 정규 표현식을 반환하도록 해요.

```elixir
"Thursday, January 1, 1970 was the Unix epoch." =~ DateParser.match_day_month_name_date()
# => false
"Thursday, January 1, 1970" =~ DateParser.match_day_month_name_date()
# => true

DateParser.match_day_month_name_date()
|> Regex.named_captures("Thursday, January 1, 1970")

# => %{
#     "day" => "1",
#     "day_name" => "Thursday",
#     "month_name" => "January",
#     "year" => "1970"
#   }
```
