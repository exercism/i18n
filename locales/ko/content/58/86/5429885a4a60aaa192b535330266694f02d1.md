# 소개

## 비교 연산자

R에는 다른 많은 언어와 동일한 연산자 집합이 있어요.

```R
1 == 2 # FALSE
1 != 2 # TRUE
1 < 2 # TRUE
1 > 2 # FALSE
1 <= 2 # TRUE
1 >= 2 # FALSE
```

## 분기

if-else의 기본 형태는 다음과 같아요.

```R
if (x > 10) {
    y <- "big"
} else if (x > 2) {
    y <- "medium"
} else {
    y <- "tiny"
}
```

이 경우 불리언을 감싸는 괄호 `()`와 문을 감싸는 중괄호 `{}`가 모두 필요해요.
단순한 `if` 문은 짧게 줄일 수 있어요.

```R
if (x == 0) return("success")
```
