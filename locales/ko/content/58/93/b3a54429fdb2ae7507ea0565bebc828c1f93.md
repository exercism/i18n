# 자세히 알아보기

[guards][guards]는 [패턴 매칭][exercism-pattern-matching]을 보완하는 기능이에요.
패턴 매칭은 다음 개념에서 다뤄요.
guards를 사용하면 입력값에 따라 함수를 다르게 구현할 수 있어요.
더 복잡한 검사도 가능하고요.

guard 문은 파이프 `|` 뒤에 불리언 표현식이 오고, 등호 `=`와 함수 본문으로 끝나는 형태로 정의해요.
함수 하나에 여러 개의 guard 문을 쓸 수 있어요.
guard 문은 위에서 아래로 평가되고, `True`로 평가되는 첫 번째 문이 실행돼요.
guard 문에는 `otherwise` 문을 함께 쓸 수 있는데, 이는 앞선 guard 문에 해당하지 않는 모든 값을 처리하는 역할을 해요.

```haskell
isEven :: Int -> String
isEven n
    | even n = "n is even"
    | otherwise = "n is odd"
```

함수를 직접 정의해서 guard 문 안에서 사용할 수도 있어요.

```haskell
isEven' :: Int -> Bool
isEven' n = even n

isEven :: Int -> String
isEven n
    | isEven' n = "n is even"
    | otherwise = "n is odd"
```
