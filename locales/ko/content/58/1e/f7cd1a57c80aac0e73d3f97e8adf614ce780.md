# 소개

일반적으로 프로그래밍에서는 바퀴를 새로 발명하고 싶지는 않을 거예요.
많은 표준 알고리즘은 이미 누군가가 대신 만들어 둔 경우가 많아요.

## Includes

다른 파일의 내용을 포함하려면 C++에서는 `include` 지시문을 사용해요.
이 지시문들은 파일 맨 위에 적어요.
컴파일하는 동안, 지시문이 있는 줄은 해당 파일의 내용으로 바뀌어요.
include한 뒤에도 네임스페이스는 원래 파일에 있던 그대로 유지돼요.

## 표준 라이브러리

표준 라이브러리는 많은 일반적인 함수와 알고리즘, 자료 구조를 제공해요.
표준 라이브러리는 `std` 네임스페이스를 사용해요.

한 가지 예로 C 수치 라이브러리인 `cmath`가 있어요.
이 라이브러리는 여러 가지 일반적인 수학 연산을 제공해요.

```cpp
#include <cmath>

int cube_me(int a) {
    // raise `a` to the third power
    return std::pow(a, 3);
}
```

~~~~exercism/note
표준 라이브러리는 큰따옴표 `"` 대신 꺾쇠괄호 `<>`로 포함해요.
두 방식의 차이는 컴파일러가 해당 파일을 찾는 위치에 있어요.
꺾쇠괄호를 쓰는 경우에는 현재 프로젝트에서의 검색을 건너뛰고, 시스템의 include 디렉터리에서 바로 찾기 시작해요.
로컬 파일을 포함하고 싶다면 큰따옴표를 사용해요: `#include "myfile"`
~~~~
