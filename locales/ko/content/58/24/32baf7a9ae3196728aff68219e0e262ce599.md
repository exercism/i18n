# 문자열

`String` 데이터 타입은 UTF-8로 인코딩된 문자가 일렬로 나열된 형태예요. 텍스트 데이터를 저장하는 데 유용해요.

## 문자열 만들기

문자열은 `String::new()`나 `String::from()` 같은 연관 함수로 만들 수 있어요. 많은 타입에는 숫자 같은 값으로부터 문자열을 만들어 주는 `to_string` 메서드가 있어요.

```rust
let my_string = String::from("The answer is");
let answer = 42.to_string();
println!("{my_string} {answer}");
```

### `format!` 매크로

여러 작은 데이터 타입을 조합해 큰 문자열을 만드는 일은 흔하기 때문에, Rust에는 `to_string`을 호출하는 번거로운 과정을 생략해 주는 축약형, 즉 `format!` 매크로가 있어요. 예를 들어 위에서 만든 복합 문자열은 다음과 같이 더 간단하게 만들 수 있어요:

```rust
let the_answer = format!("{} {}.", "The answer is", 42);
assert_eq!("The answer is 42.", the_answer);
```

## 문자열 슬라이스

문자열은 문자열 슬라이스와 밀접한 관계가 있어요. 문자열 슬라이스는 크기가 정해진 메모리 영역을 가리키는 불변 참조로, 그 안에는 UTF-8로 인코딩된 문자가 일렬로 나열되어 있어요. 문자열은 역참조(`&`) 연산자로 빌려 오면 문자열 슬라이스로 강제 변환할 수 있어요. 문자열 슬라이스를 문자열로 바꾸려면 `to_string()` 메서드나 `String::from`을 사용하면 돼요.

Rust 코드에서 문자열 리터럴은 큰따옴표로 감싸요. 이런 문자열 리터럴은 항상 문자열 슬라이스인데, 프로그램 실행 파일 안의 불변 메모리 영역을 가리키기 때문이에요.

```rust
let string = String::from("string");
let slice = "string";
assert_eq!(slice, &string);
```

## 문자열 변경하기

문자열에 문자 하나를 이어 붙이려면 `push` 메서드를 사용해요. 문자열에 문자열 슬라이스를 이어 붙이려면 `push_str` 메서드나 `+` 연산자를 사용해요.

```rust
fn main() {
    // For demonstration purposes, we're not using `format!`
    let s1 = String::from("tic");
    let s2 = String::from("tac");
    let s3 = String::from("toe");

    let s = s1 + "-" + &s2 + "-" + &s3;
    println!("{s}");
}
```

## 문자열의 문자에 접근하기

Rust의 문자열은 UTF-8로 인코딩되기 때문에 각 문자의 크기가 모두 같지는 않아요. 그래서 `String` 데이터 타입은 인덱싱 연산자(`[]`)를 제공하지 않아요. 문자열의 모든 문자 또는 특정 문자에 접근하려면 `chars()` 메서드를 사용할 수 있어요. 이 메서드는 문자열의 각 문자를 순서대로 하나씩 순회해요.

```rust
let alphabet: String = ('a'..='z').collect();
for c in alphabet.chars() {
    println!("{c}");
}
let j = alphabet.chars().nth(9);
println!("{j:?}"); // prints Some('j')
```

## 더 알아보기

String은 여러 메서드와 매크로가 함께 갖춰진 풍부한 데이터 타입이에요. String이 제공하는 모든 메서드와 기능을 보려면 [표준 라이브러리 문서](https://doc.rust-lang.org/std/string/struct.String.html)를 확인해 봐요.
