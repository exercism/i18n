# 작업

작업은 텍스트 교정부터 개념 연습 문제 제작까지, 사람들이 함께 도와주면 좋겠는 GitHub 이슈예요.
작업은 웹사이트에 표시되고, GitHub의 해당 이슈로 연결돼요.
각 작업에는 하나 이상의 속성이 붙는데, 이 속성은 이슈의 레이블에서 채워져요.
그러면 사용자는 속성을 기준으로 작업을 필터링할 수 있어요.

## 태그

이슈가 작업으로 인식되려면 작업 전용 레이블이 하나 이상 붙어 있어야 해요.
덕분에 유지보수자는 일부 이슈만 작업으로 표시되게 할 수 있어요.

각 작업 레이블은 `x:<type>/<value>` 형식으로 정의되며, 다섯 가지 작업 유형을 지원해요.

- `action`
- `knowledge`
- `module`
- `size`
- `type`

### action 태그

`x:action/<value>` 레이블은 기여자가 이슈를 처리할 때 어떤 종류의 작업을 하게 되는지 나타내요.

| 태그                  | 설명                            |
| -------------------- | -------------------------------------- |
| `x:action/create`    | 처음부터 새로 작업하기         |
| `x:action/fix`       | 이슈 수정하기                           |
| `x:action/improve`   | 기존 기능이나 콘텐츠 개선하기 |
| `x:action/proofread` | 텍스트 교정하기                         |
| `x:action/sync`      | 콘텐츠를 최신 버전과 동기화하기   |

### knowledge 태그

`x:knowledge/<value>` 레이블은 기여자에게 얼마나 많은 Exercism 지식이 필요한지 나타내요.

| 태그                        | 설명                                |
| -------------------------- | ------------------------------------------ |
| `x:knowledge/none`         | 기존 Exercism 지식이 필요 없음    |
| `x:knowledge/elementary`   | 약간의 Exercism 지식이 필요함         |
| `x:knowledge/intermediate` | 상당한 Exercism 지식이 필요함 |
| `x:knowledge/advanced`     | 폭넓은 Exercism 지식이 필요함  |

### module 태그

`x:module/<value>` 레이블은 기여자가 Exercism의 어느 부분을 작업하게 될지 나타내요.

| 태그                          | 설명                 |
| ---------------------------- | --------------------------- |
| `x:module/analyzer`          | 애널라이저 작업하기           |
| `x:module/concept`           | 개념 작업하기            |
| `x:module/concept-exercise`  | 개념 연습 문제 작업하기   |
| `x:module/generator`         | 연습 문제 제너레이터 작업하기 |
| `x:module/practice-exercise` | 실습 연습 문제 작업하기  |
| `x:module/representer`       | 리프리젠터 작업하기        |
| `x:module/test-runner`       | 테스트 러너 작업하기        |

### size 태그

`x:size/<value>` 레이블은 기여자에게 예상되는 작업량을 나타내요.

| 태그              | 설명            |
| ---------------- | ---------------------- |
| `x:size/tiny`    | 아주 적은 작업량    |
| `x:size/small`   | 적은 작업량   |
| `x:size/medium`  | 보통 작업량  |
| `x:size/large`   | 많은 작업량   |
| `x:size/massive` | 매우 많은 작업량 |

### type 태그

`x:type/<value>` 레이블은 기여자가 하게 될 작업의 유형을 나타내요.

| 태그              | 설명                                                                                                                                                                                                    |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `x:type/ci`      | 지속적 통합(CI, 예: GitHub Actions 워크플로) 작업하기                                                                                                                                                 |
| `x:type/coding`  | 학생 대상 콘텐츠에 포함되지 않는 코드 작성하기. 보통 프로덕션 도구(예: 테스트 러너), 내부 도구(제너레이터), Exercism이 유지 관리하는 라이브러리와 관련된 작업. |
| `x:type/content` | 콘텐츠(예: 연습 문제, 개념) 작업하기                                                                                                                                                                     |
| `x:type/docker`  | Dockerfile 작업하기                                                                                                                                                                                            |
| `x:type/docs`    | 문서 작업하기                                                                                                                                                                                          |

## 점유된 태그와 점유되지 않은 태그

누군가 이미 작업 중인 작업을 숨기려면, 이슈에 `x:status/claimed` 레이블을 추가하면 돼요.
