# 안내

이 연습 문제에서는 고전 게임 팩맨의 규칙 몇 가지를 구현해요.

구현할 규칙은 네 가지이고, 모두 게임 상태와 관련이 있어요.

## 1. 팩맨이 유령을 먹는지 정의하기

팩맨이 파워 펠릿을 활성화했는지와 팩맨이 유령에 닿아 있는지를 받아서, 팩맨이 유령을 먹을 수 있는지를 나타내는 불리언 값을 반환하는 함수를 구현해요. 이 함수는 팩맨이 파워 펠릿을 활성화한 상태에서 유령에 닿아 있을 때만 `true`를 반환해야 해요.

```lua
rules.eat_ghost(false, true)
-- => false
```

## 2. 팩맨이 점수를 얻는지 정의하기

팩맨이 파워 펠릿에 닿아 있는지와 팩맨이 점에 닿아 있는지를 받아서, 팩맨이 점수를 얻었는지를 나타내는 불리언 값을 반환하는 함수를 구현해요. 이 함수는 팩맨이 파워 펠릿이나 점에 닿아 있으면 `true`를 반환해야 해요.

```lua
rules.score(true, true)
-- => true
```

## 3. 팩맨이 패배하는지 정의하기

팩맨이 파워 펠릿을 활성화했는지와 팩맨이 유령에 닿아 있는지를 받아서, 팩맨이 패배하는지를 나타내는 불리언 값을 반환하는 함수를 구현해요. 이 함수는 팩맨이 유령에 닿아 있고 파워 펠릿을 활성화하지 않았을 때 `true`를 반환해야 해요.

```lua
rules.lose(false, true)
-- => true
```

## 4. 팩맨이 승리하는지 정의하기

팩맨이 점을 모두 먹었는지, 팩맨이 파워 펠릿을 활성화했는지, 팩맨이 유령에 닿아 있는지를 받아서, 팩맨이 승리하는지를 나타내는 불리언 값을 반환하는 함수를 구현해요. 이 함수는 팩맨이 점을 모두 먹었고 3번에서 정의한 인자에 따라 패배하지 않았을 때 `true`를 반환해야 해요.

```lua
rules.win(false, true, false)
-- => false
```
