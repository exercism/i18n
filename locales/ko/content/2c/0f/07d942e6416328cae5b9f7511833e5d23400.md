# 지침

이 연습 문제에서는 Exercism 플랫폼에서 연습할 계획인 프로그래밍 언어 배열을 처리하는 코드를 작성해요.

여섯 가지 작업이 있어요.

## 1. 새 배열 만들기

언어를 추가하려면 먼저 새 배열을 만들어야 해요. 빈 배열을 반환하는 함수를 정의해요.

```clojure
(new-list)
;; => ()
```

## 2. 배열에 새 언어 추가하기

Exercism을 둘러보면서 배우고 싶은 언어를 찾으면, 그 언어를 배열에 추가할 수 있어야 해요. 배열의 맨 앞에 새 언어를 추가하는 함수를 정의해요.

```clojure
(add-language "JavaScript" '("Clojurescript"))
;; => '("JavaScript" "Clojurescript")
```

## 3. 마지막으로 추가한 언어 확인하기

방금 추가한 언어가 무엇인지 빠르게 확인하고 싶을 거예요. 배열에서 첫 번째 언어를 반환하는 함수를 정의해요.

```clojure
(first-language '("Haskell" "Python"))
;; => "Haskell"
```

## 4. 배열에서 첫 번째 언어 제거하기

방금 추가한 언어에 대한 생각이 바뀔 때도 있어요. 배열에서 첫 번째 언어를 제거하는 함수를 정의해요.

```clojure
(remove-language '("Common Lisp" "Racket" "Scheme"))
;; => '("Racket" "Scheme")
```

## 5. 배열에 있는 언어 개수 세기

언어를 하나씩 세는 것은 번거로워요. 배열에 있는 언어의 개수를 세는 함수를 정의해요.

```clojure
(count-languages '("C#" "Racket" "Rust" "Ruby"))
;; => 4
```

## 6. 모두 합쳐 보기

`learning-list` 함수를 정의하고, 그 안에서 위에서 정의한 함수 몇 가지를 사용해요.

- 빈 배열을 만들어요.
- 배열에 새 프로그래밍 언어 2개를 추가해요.

  - "Clojure"
  - "Lisp"

- 한 해 동안 시간이 부족할 수도 있고 Clojure와 꽤 비슷하기도 하니, 배열에서 "Lisp"을 제거해요.
- 배열에 프로그래밍 언어 2개를 더 추가해요.

  - "Java"
  - "JavaScript"

- 언어의 총 개수를 반환해요. 힌트: 3이 되어야 해요.

```clojure
(learning-list)
;; => 3
```
