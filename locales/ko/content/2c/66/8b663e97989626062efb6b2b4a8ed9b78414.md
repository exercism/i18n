# 지침

축구 클럽 웹사이트의 직원들이 경기를 보도할 수 있도록 돕는 시스템을 개발하고 있어요.
데이터는 여러 출처에서 들어오고, 정리된 뒤 하나의 스트림으로 흘러 들어와요.

## 1. 등번호를 기준으로 선수 설명을 출력해요

이 팀은 항상 4-3-3 포메이션으로만 경기하고, 교체를 허용한 1965년 규칙 변경에도 동의한 적이 없어요. 선수단을 늘리는 건 말할 것도 없고요.

선수 설명은 다음과 같아요.

```text
1 -> "goalie"
2 -> "left back"
3 & 4 "center back"
5 -> "right back"
6, 7, & 8 -> "midfielder"
9 -> "left wing"
10 -> "striker"
11 -> "right wing"
```

등번호를 바탕으로 선수 설명을 출력하도록 정적 `FootballMatchReports.onField()` 메서드를 구현해요.

```java
FootballMatchReports.onField(10);
// => "striker"
```

## 2. 등번호가 공식 명단에 속하지 않으면 "invalid"를 출력해요

1-11 범위를 벗어난 등번호가 처리되면 'invalid'를 반환하도록 `FootballMatchReports.onField()` 메서드를 수정해요.

```java
FootballMatchReports.onField(13);
// => "invalid"
```
