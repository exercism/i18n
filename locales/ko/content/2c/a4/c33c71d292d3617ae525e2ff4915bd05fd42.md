# 설치

[미리 컴파일된 Uiua 바이너리][releases]가 있어서 직접 컴파일할 필요는 없어요.
IDE 연동과 폰트를 포함한 최신 설치 방법은 [공식 설치 안내][install-guide]를 참고해요.

```exercism/note
현재 온라인 테스트 러너는 버전 `0.18.1`을 사용해요.
Uiua는 개발이 빠르게 진행되는 만큼 이 버전도 바뀔 수 있으니, 웹사이트에서 본 테스트 결과를 재현할 수 없다면 이 점을 염두에 두세요.
```

원하는 위치에 다운로드했다면, 시스템 PATH에 Uiua를 추가해야 해요.

- **macOS:** Finder에서 `Applications > Utilities > Terminal`을 열어요. 어디서든 Uiua를 실행하려면 `export PATH="/path/to/uiua:$PATH"`를 입력해요.

- **Windows:** 시작 메뉴에서 "Edit Environment Variables"를 열어요. "Path"에 Uiua 폴더를 추가해요.

- **Linux:** 터미널을 열고 `export PATH="/path/to/uiua:$PATH"`를 `~/.bashrc` 또는 `~/.profile`에 추가하면 어디서든 편하게 쓸 수 있어요.
