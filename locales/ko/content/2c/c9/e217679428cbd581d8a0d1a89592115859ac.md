# 개요

코드를 조건에 따라 실행하려면 [`if/elif/else` 표현식][conditional-expression]을 사용해요. `if/elif/else` 표현식에 사용되는 조건은 반드시 `bool` 타입이어야 해요. F#에는 _truthy_ 값이라는 개념이 없어요.

```fsharp
if x = 5 then
    printfn "x equals 5"
elif x > 7 then
    printfn "x is not 5 and greater than 7"
else
    printfn "x is not 5 and not greater than 7"
```

`if/elif/else`는 표현식이기 때문에 이름에 바인딩하거나 함수에서 반환할 수 있어요.

```fsharp
let message =
    if x = 5 then
        "x equals 5"
    elif x > 7 then
        "x is not 5 and greater than 7"
    else
        "x is not 5 and not greater than 7"
```

모든 분기는 같은 타입을 반환해야 해요. 그렇게 하지 않으면 컴파일러 오류가 발생해요.

```fsharp
if x = 5 then
    true
elif x > 7 then
    5.6

// Results in compiler error
```

`else`와 `elif` 분기는 선택 사항이지만, 반환되는 표현식의 타입이 [`unit`][unit-type]일 때만 그래요.

```fsharp
// Valid if expression
if x > 2 then
    printfn "x is greater than two"

// Invalid if expression, results in compiler warning
if x > 2 then
    true
```

`if/else` 표현식은 한 줄에 놓을 수도 있어요. 다만 단순한 `if` 표현식에만 사용해야 해요.

```fsharp
let y = if x > 5 then 10 else 20
```
