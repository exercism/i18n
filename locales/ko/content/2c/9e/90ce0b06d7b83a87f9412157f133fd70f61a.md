# `case`문

하나의 값을 여러 후보 값과 비교할 때, `elsif`를 연달아 쓰면 같은 내용을 계속 반복해서 말하게 돼요:

```sather
   if zone = 0 then
      return 0;
   elsif zone = 1 then
      return 550;
   elsif zone = 2 then
      return 370;
   else
      return 920;
   end;
```

`case`는 그걸 한 번에 말해요:

```sather
   case zone
   when 0 then return 0;
   when 1 then return 550;
   when 2 then return 370;
   else return 920;
   end;
```

비교할 값은 `case` 뒤에 와요. 각 `when`은 그 값과 비교할 값을 하나씩 제시하고, 처음으로 일치하는 것만 실행돼요.

## `when` 하나에 값 여러 개 쓰기

`when`에는 쉼표로 구분해 여러 값을 나열할 수 있어요:

```sather
   case day
   when "Sat", "Sun" then return "Weekend";
   when "Mon", "Tue", "Wed", "Thu", "Fri" then return "Weekday";
   else return "Unknown";
   end;
```

정수, 문자, 문자열, 즉 `=`로 비교할 수 있는 값이라면 뭐든지 이렇게 쓸 수 있어요.

## `else`는 선택 사항이 아니에요

**아무것도 일치하지 않는데 `else`가 없는 `case`는, 그런 상황이 벌어지면 프로그램을 멈춰 버리는 오류예요.**

이건 `if`와 달라요. `if`에서는 `else`를 생략해도 그냥 아무 일도 일어나지 않으니까요. 대부분의 언어와도 달라요. 그쪽에서는 일치하는 `case`가 없어도 조용히 아무것도 하지 않거든요.

그래서 모든 `case`에는 `else`가 필요해요. `when`이 이미 모든 값을 다 다룬다고 확신할 때도 마찬가지예요. 나중에 네 번째 구역이 새로 생겼는데 `case`를 그에 맞게 고치지 않으면, 그 구역을 처음 이용하는 승객에서 프로그램이 멈춰 버려요.

## `when`은 하나만 실행돼요

`when`이 일치하면 그 `then` 뒤의 문이 실행되고 `case`는 거기서 끝나요. 프로그램은 `end` 다음부터 계속 이어져요. 그 아래의 `when`은 아예 쳐다보지 않으니, 다음 것까지 덩달아 실행되지 않게 막는 코드를 따로 쓸 필요가 없어요.
