# 자세히 알아보기

## 불리언

PowerShell에는 참과 거짓 값을 나타내는 [`bool`][booleans] 타입이 있어요.
이 타입에는 `True`와 `False`, 두 가지 값만 있어요.
이 값들은 `$` 접두사를 붙여 변수에 담을 수 있어요:

```powershell
> $TrueVar  = $true
> $FalseVar = $FALSE
#Case senstitivity doesn't matter here
```

`-and`, `-or`, `-not` 같은 [논리 연산자][logical-operators]를 사용하면 불리언 식을 결합하고 평가할 수 있어요.

```powershell
> $TrueVar  = $true -and $true
> $FalseVar = $true -and $false

> $TrueVar  = $true -or $false
> $FalseVar = $false -or $false

> $TrueVar  = -not $false
> $FalseVar = -not $true
```

## 변환과 참/거짓 판정

PowerShell은 어떤 타입이든 암시적으로 불리언으로 취급할 수 있어요.
물론 `[bool]`이라는 불리언 타입 가속기를 사용해 명시적으로 변환할 수도 있어요.

다음은 PowerShell이 다른 타입을 불리언 값으로 변환할 때 따르는 일반적인 규칙이에요:

$false:
- `''`나 `""` 같은 빈 문자열
- `$null` 같은 null 값
- 값이 0인 숫자 타입

$true:
- 비어 있지 않은 문자열
- 그 밖의 컬렉션이 아닌 타입의 인스턴스

```powershell
> [bool] 0
False

> [bool] 0.0
False

> [bool] ""
False

> [bool] "Hello"
True

> [bool] 1234
True
```

컬렉션 타입에서 불리언 값을 변환하는 자세한 규칙은 [여기][collection-conversion]를 읽어 보세요.
