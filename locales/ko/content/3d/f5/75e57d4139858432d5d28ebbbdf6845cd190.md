# 소개

Haxe는 타입과 필드에 대한 런타임 리플렉션을 지원해요. 리플렉션을 올바르게 사용하려면 어떤 종류의 연산이 지원되고 어떤 것이 지원되지 않는지 이해해야 해요. 리플렉션은 본질적으로 동적이기 때문에, 컴파일 시점에 항상 판단할 수 있는 것은 아니에요.

리플렉션 API는 두 개의 클래스로 이루어져 있어요:

- `Reflect`: 익명 구조체에서 가장 잘 동작하는 가벼운 API로, 클래스에 대한 지원은 제한적이에요.
- `Type`: 클래스와 열거형을 다루기 위한 더 견고한 API예요.

다음 예제에서는 JavaScript 타겟을 사용해요:

```haxe
class Main {
  public static function main() {
    trace(Type.resolveClass("Main"));
  }
}

// This outputs
// class Test { static main() { console.log("Test.hx:3:",$hxClasses["Test"]); } }
```
