# 소개


## 불리언

PowerShell에는 참과 거짓 값을 나타내는 [`bool`][booleans] 타입이 있어요.
이 타입에는 `True`와 `False` 두 가지 값만 있어요.
값 앞에 `$` 접두사를 붙이면 변수에 담을 수 있어요:

```powershell
> $TrueVar  = $true
> $FalseVar = $FALSE
#Case senstitivity doesn't matter here
```

`-and`, `-or`, `-not` 같은 [논리 연산자][logical-operators]를 사용하면 불리언 식을 조합하고 평가할 수 있어요.

```powershell
> $TrueVar  = $true -and $true
> $FalseVar = $true -and $false

> $TrueVar  = $true -or $false
> $FalseVar = $false -or $false

> $TrueVar  = -not $false
> $FalseVar = -not $true
```


## 주석 기반 도움말

PowerShell의 [`Comment-based help`][comment-based help]는 주석으로 작성한 함수와 스크립트에 대한 자세한 정보를 제공하는 데 도움이 돼요.
`.SYNOPSIS`, `.EXAMPLE`, `.NOTES`처럼 다루려는 주제를 지정하는 특별한 도움말 주석 키워드를 사용해요.

```powershell
function ExampleFunction($Arg) {
    <#
    .DESCRIPTION
    A detailed description of the function or script. This keyword can be used only once in each topic.

    .PARAMETER Arg
    The description of a parameter, it must be follow with the parameter name.
    #>
}
```

`Get-Help` cmdlet을 사용하면 주석 기반 도움말 정보를 표시할 수 있어요.

```powershell
> Get-Help -Name "ExampleFunction"
```
