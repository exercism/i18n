# 학습

Vim에는 훌륭한 문서가 이미 내장되어 있어요. 이 문서를 열어 보는 방법은 `:help` 명령어예요.

입문 안내를 보고 싶다면 `:h user-manual`을 참고해요.

거의 모든 Vim 설치에는 대화형 튜토리얼도 함께 들어 있어요:

```
$ vimtutor
```

Vim은 수십 년이 지난 지금도 여전히 인기가 많아요. 웹에서 Vim에 관한 자료를 많이 찾을 수 있는데, 어떤 것은 더 좋고 어떤 것은 그렇지 않아요. 좋은 자료는 [여기](https://exercism.org/docs/tracks/vimscript/resources)에 정리되어 있어요.
