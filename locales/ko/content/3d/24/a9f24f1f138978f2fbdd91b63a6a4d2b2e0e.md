# 소개

## 기초

F#에서는 이름에 값을 할당하는 것을 _바인딩_이라고 해요. 바인딩은 변경할 수 없어서 다른 언어의 상수와 비슷해요. F#은 정적 타입 언어라서 각 바인딩은 컴파일 시점에 타입을 가져요.

바인딩은 `let` 키워드로 정의해요. 대부분의 바인딩에서는 타입을 지정하는 것이 선택 사항이에요. 보통 F#의 _타입 추론_이 값을 바탕으로 타입을 알아내 주거든요. 바인딩은 이렇게 생겼어요:

```fsharp
// Automatically inferred type
let fingers = 10
```

함수도 일반적인 바인딩이에요. 다만 하나 이상의 매개변수가 있어요. 함수는 마지막 표현식을 자동으로 반환해요. 타입 추론은 대부분의 함수에서도 동작해요. 함수가 어떤 값들로 호출되는지, 어떤 값을 반환하는지 분석해서요.

```fsharp
// Automatically inferred types for parameters and return type
let add x y = x + y
```

함수를 호출할 때는 이름을 쓰고, 함수의 매개변수마다 인자를 전달해요.

```fsharp
let five = add 2 3
```

바인딩의 타입을 추론할 수 없으면, 컴파일러가 오류를 보고해요. 이 문제를 해결하려면 바인딩에 타입 주석을 명시적으로 추가해요.

```fsharp
// Explicit type annotation
let fingers: int = 10

// Explicit type annotation (also for parameters)
let add (x: int) (y: int): int = x + y
```

F#의 바인딩은 정의된 _뒤에야_ 사용할 수 있어요. 정의되기 전에 바인딩을 사용하면 컴파일 오류가 발생해요.

```fsharp
// Compile error as the add binding has not yet been defined
// let seven = add 3 4

let add x y = x + y
```

F#은 스코프를 정의할 때 의미 있는 공백을 사용해요. 즉, 스코프는 바인딩을 선언한 줄을 기준으로 코드를 공백으로 들여써서 정해져요. 기본 관례는 들여쓰기에 공백 네 칸을 쓰는 거예요:

```fsharp
let toes =
    let left = 5
    let right = 5
    left + right

let multiplyPlusTwo x y =
    let product = x * y
    product + 2

// Trying to access the left, right or product bindings
// here would result in a compile error
```

F#의 바인딩(함수도 포함)은 보통 모듈로 정리해요. 모듈은 관련된 기능을 묶은 단위이고, `module` 키워드로 정의해요. 모듈 정의는 그 안의 바인딩보다 먼저 와야 해요:

```fsharp
module Calculator

let pi = 3.14

let add x y = x + y
```

F#은 두 가지 종류의 주석을 지원해요. 한 줄 주석은 앞에 `//`를 붙이고, 여러 줄 주석은 `(*`와 `*)` 사이에 넣어요.
