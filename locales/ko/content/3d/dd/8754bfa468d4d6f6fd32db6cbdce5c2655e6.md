# 지침

탐정의 수첩은 사건이 진행될수록 채워지고, 수사선이 하나씩 배제되면서 다시 비워져요.

다섯 과제는 모두 `CASE_NOTES` 클래스에 들어가요.

## 1. 사건을 열어요

비어 있는 새 수첩을 반환해요.

```sather
notes ::= CASE_NOTES::new_case;
notes.size
-- => 0
```

## 2. 단서를 적어 둬요

수첩 끝에 단서를 추가해요. 이건 아무것도 반환하지 않아요. 대신 주어진 수첩 자체를 바꿔 놓아요.

```sather
CASE_NOTES::add_clue(notes, "muddy boots");
notes.size
-- => 1
```

## 3. 단서가 몇 개일까요?

```sather
CASE_NOTES::clue_count(notes)
-- => 1
```

## 4. 단서 하나를 배제해요

수첩에서 특정 위치에 있는 단서를 꺼내요. 그 뒤에 있는 단서는 모두 앞으로 당겨져요. 이것도 아무것도 반환하지 않아요.

```sather
CASE_NOTES::rule_out(notes, 0);
```

## 5. 사건을 다시 읽어요

수첩에 있는 모든 단서를 `"; "`로 이어 붙여 반환해요. 빈 수첩은 빈 문자열로 읽혀요.

```sather
CASE_NOTES::summary(notes)
-- => "muddy boots; broken window"
```
