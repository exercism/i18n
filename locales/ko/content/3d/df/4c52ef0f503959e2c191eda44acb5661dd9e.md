# 힌트

## 1. 승인 정의하기

- [이 페이지][define]에서 판별 공용체를 정의하는 방법을 보여줘요.

## 4. 활동 정의하기

- [이 페이지][define]에서 연결된 데이터가 있는 경우와 없는 경우 모두에 대해 판별 공용체를 정의하는 방법을 보여줘요.

## 5. 활동 평가하기

- 활동의 값을 기준으로 로직을 실행하는 가장 좋은 방법은 [패턴 일치][pattern-matching]를 사용하는 거예요.
- 판별 공용체의 케이스(그리고 필요하다면 연결된 데이터까지)를 일치시킬 때 사용하는 패턴이 바로 [식별자 패턴][identifier-patterns]이에요.
- 패턴에 조건을 하나 더 추가하고 싶다면 [가드][guards]를 추가할 수 있어요.
- 한 번에 둘 이상의 값을 처리하고 싶다면 [와일드카드 패턴][wildcard-patterns]을 사용할 수 있어요.
