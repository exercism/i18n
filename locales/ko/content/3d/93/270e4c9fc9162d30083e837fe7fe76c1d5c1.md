# 지침

지난 7일 동안 정원을 찾은 새의 수를 기록하는 열렬한 조류 관찰자예요.

정원을 찾은 새의 수를 다루는 다섯 개의 과제가 있어요.

## 1. 지난주 집계 확인하기

비교를 위해 지난주 집계 사본을 항상 가까이에 보관하는데, 그 값은 0, 2, 5, 3, 7, 8, 4였어요. 지난주 집계를 반환하는 `BirdCount.last_week` 메서드를 구현해요:

```ruby
BirdCount.last_week
# => [0, 2, 5, 3, 7, 8, 4]
```

## 2. 어제 몇 마리의 새가 방문했는지 확인하기

어제 정원을 찾은 새의 수를 반환하는 `BirdCount#yesterday` 메서드를 구현해요. 새 집계는 날짜순으로 정렬되어 있고, 첫 번째 원소는 가장 오래된 날의 집계이고, 마지막 원소는 오늘의 집계예요.

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.yesterday
# => 4
```

## 3. 방문한 새의 총 마릿수 계산하기

정원을 찾은 새의 총 마릿수를 반환하는 `BirdCount#total` 메서드를 구현해요:

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.total
# => 19
```

## 4. 바쁜 날의 수 계산하기

어떤 날은 다른 날보다 더 바빠요. 바쁜 날은 새가 다섯 마리 이상 정원을 찾은 날이에요.
바쁜 날의 수를 반환하는 `BirdCount#busy_days` 메서드를 구현해요:

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.busy_days
# => 2
```

## 5. 새가 방문하지 않은 날이 있었는지 확인하기

정원을 찾은 새가 한 마리도 없는 날이 있었다면 `true`를 반환하고, 그렇지 않으면 `false`를 반환하는 `BirdCount#day_without_birds?` 메서드를 구현해요:

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.day_without_birds?
# => true
```
