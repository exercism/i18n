# 테스트

## clojure.test

Babashka에는 clojure.test가 함께 들어 있어요. 연습 문제를 풀 준비가 되고 해답을 담을 파일(예를 들어 `bob.clj`)을 만들었다면, [여기에 설명된 대로](http://clojure.github.io/clojure/clojure.test-api.html#clojure.test/run-tests) `clojure.test/run-tests`를 사용해 테스트를 실행할 수 있어요.


REPL을 쓰면 코드를 쉽게 실행하고 즉각적인 피드백을 받을 수 있고, 테스트를 실행하는 데에도 쓸 수 있어요. `rlwrap`을 사용하면 위/아래 화살표로 줄을 편집하고 명령 기록을 사용할 수 있어서, `rlwrap` 사용을 권장해요. 연습 문제를 테스트하려면 해당 디렉터리로 이동한 뒤, `src`와 `test` 디렉터리를 클래스패스에 추가해서 소켓 REPL을 열어요:
``` bash
/bob $ rlwrap bb --classpath src:test socket-repl 1666
```

먼저 테스트 네임스페이스를 `require`해요:
``` clojure
=> (require 'bob-test)
nil
```

그다음 `bob-test`에 대해 `run-tests`를 호출해요:
``` clojure
=> (clojure.test/run-tests 'bob-test)

Testing bob-test

Ran 25 tests containing 25 assertions.
0 failures, 0 errors.
{:test 25, :pass 25, :fail 0, :error 0, :type :summary}
```

테스트 실행 스크립트를 만들려면:

``` clojure
#!/usr/bin/env bb

(require '[clojure.test :as t]
         '[babashka.classpath :as cp])

(cp/add-classpath "src:test")                        

(require 'bob-test)                  

(def test-results
  (t/run-tests 'bob-test))           

(def failures-and-errors
  (let [{:keys [:fail :error]} test-results]
    (+ fail error)))                                 

(System/exit failures-and-errors)
```
