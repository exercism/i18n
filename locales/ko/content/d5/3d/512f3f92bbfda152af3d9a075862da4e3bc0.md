# 명령줄에서 테스트하기

다음 명령으로 테스트를 실행해요:

```bash
scarb cairo-test
```

첫 번째 테스트를 제외한 나머지 테스트는 모두 무시되도록 되어 있어요. 첫 번째 테스트를 통과시킨 뒤에는 `tests` 디렉터리에 있는 테스트 소스 파일을 열고, 다음 테스트에서 `#[ignore]` 플래그를 지운 다음 다시 테스트를 통과시켜 봐요. 각각의 테스트는 그 위에 `#[test]` 플래그가 붙은 함수예요. 모든 테스트를 통과할 때까지 계속해 봐요.

테스트 소스 파일을 수정하지 않고 _모든_ 테스트를 실행하고 싶다면 다음을 사용해요:

```bash
scarb cairo-test --include-ignored
```

무시된 테스트인지 여부와 상관없이 특정 테스트를 실행하려면, 예를 들어 `some_test`라면 다음을 사용할 수 있어요:

```bash
scarb cairo-test -f some_test
```

Cairo 테스트에 대해 더 알아보려면 온라인 [테스트 문서][cairo-tests]를 참고해요.

[cairo-tests]: https://book.cairo-lang.org/ch10-01-how-to-write-tests.html
