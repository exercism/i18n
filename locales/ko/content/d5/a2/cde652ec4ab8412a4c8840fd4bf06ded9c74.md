# 지침

한 진법에서 숫자의 나열로 표현된 수를 다른 진법으로 변환해요.

일반적인 진법 변환을 직접 구현해 봐요.
**a**진법의 수가 숫자의 나열로 주어지면, 그 수를 **b**진법으로 변환해요.

## 참고

- 변환은 직접 구현해 봐요.
  변환을 대신 해 주는 다른 것을 사용하지 마세요.

## [위치 기수법][positional-notation]에 대하여

위치 기수법에서는 **b**진법의 수를 **b**의 거듭제곱의 선형 결합으로 이해할 수 있어요.

42라는 수는 *10진법에서* 다음과 같은 뜻이에요:

`(4 * 10^1) + (2 * 10^0)`

101010이라는 수는 *2진법에서* 다음과 같은 뜻이에요:

`(1 * 2^5) + (0 * 2^4) + (1 * 2^3) + (0 * 2^2) + (1 * 2^1) + (0 * 2^0)`

1120이라는 수는 *3진법에서* 다음과 같은 뜻이에요:

`(1 * 3^3) + (1 * 3^2) + (2 * 3^1) + (0 * 3^0)`

이제 감이 잡히죠?

*네. 위의 세 수는 정확히 같은 수예요. 축하해요!*
