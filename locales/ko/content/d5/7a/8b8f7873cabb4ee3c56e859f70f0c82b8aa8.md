# 힌트

## 일반

- [익명 함수][anon-fns]를 활용해 봐요.
- [클로저][closure]를 사용해 바깥 스코프의 변수를 참조해요.

## 1. 덧셈 함수 만들기

- `Secret.secret_add/1`에 전달된 인자에 익명 함수의 인자를 더하는 익명 함수를 반환해요.

## 2. 뺄셈 함수 만들기

- 익명 함수의 인자에서 `Secret.secret_subtract/1`에 전달된 인자를 빼는 익명 함수를 반환해요.

## 3. 곱셈 함수 만들기

- `Secret.secret_multiply/1`에 전달된 인자에 익명 함수의 인자를 곱하는 익명 함수를 반환해요.

## 4. 나눗셈 함수 만들기

- 익명 함수의 인자를 `Secret.secret_divide/1`에 전달된 인자로 나누는 익명 함수를 반환해요.
- [정수 나눗셈][div]을 활용해 봐요.

## 5. "and" 함수 만들기

- 익명 함수에 전달된 인자와 `Secret.secret_and/1`에 전달된 인자를 사용해 [비트 _and_][bitwise-wiki] 연산을 수행하는 익명 함수를 반환해요.
- [Bitwise 모듈][bitwise-hexdocs]의 함수가 도움이 될 거예요.
- Elixir 1.9 이하 버전을 사용한다면, _Bitwise_ 모듈을 사용할 수 있도록 모듈 정의 맨 앞에서 `require Bitwise`를 호출해야 해요.

## 6. "xor" 함수 만들기

- 익명 함수에 전달된 인자와 `Secret.secret_xor/1`에 전달된 인자를 사용해 [비트 _xor_][bitwise-wiki] 연산을 수행하는 익명 함수를 반환해요.
- [Bitwise 모듈][bitwise-hexdocs]의 함수가 도움이 될 거예요.
- Elixir 1.9 이하 버전을 사용한다면, _Bitwise_ 모듈을 사용할 수 있도록 모듈 정의 맨 앞에서 `require Bitwise`를 호출해야 해요.

## 7. 함수 조합기 만들기

- `Secret.secret_combine/2`에 전달된 함수들을 [합성하는][fn-composition] 익명 함수를 반환해요.
- 익명 함수를 호출할 때는 `()` 앞에 `.`을 붙여요.
