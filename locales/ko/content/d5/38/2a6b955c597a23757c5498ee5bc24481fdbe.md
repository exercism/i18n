# 개요

C는 정적 타입 언어예요. 즉, 모든 것에 컴파일 시점에 타입이 정해져 있어요.
[변수][variable]의 이름을 정하고 그 타입을 지정하는 것을 변수 선언이라고 해요.

변수는 타입을 명시적으로 지정해서 선언해요.
변수 이름은 몇 가지 [규칙을 따라야 하는데][name-rules], 예를 들어 글자나 밑줄로 시작해야 해요.
일부 이름은 [키워드][reserved-keywords]나 [다른 식별자][reserved-identifiers]를 위해 예약되어 있어서 사용할 수 없어요.

변수를 설정하거나 갱신하는 것은 변수 할당으로 해요.
값을 설정하는 것이 그 변수를 정의하는 거예요.
변수를 정의하는 것을 초기화라고도 해요.

```c
int foo;      // Declare an integer named var
foo = 10;     // Define the variable

int bar = 15; // Both can also be done in a single statement
```

변수의 값은 [`=` 단순 할당 연산자][assignment-operator]를 사용해서 할당하고 갱신할 수 있어요.
한 번 정의된 변수의 타입은 절대 바뀌지 않아요.

```c
int foo = 10; // Assign initial value
foo = 25;     // Update to new value

foo = false;  // Compiler error when assigning value of a different type
```

C는 [명령형][imperative] [절차적][procedural] 언어예요.
모든 계산은 [함수][function] 하나 또는 여러 함수에 속한 일련의 [문][statements]으로 이루어져요.

각 함수는 [매개변수][parameters]를 0개 이상 가질 수 있어요.
함수를 정의할 때는 모든 매개변수와 반환 값의 타입을 명시적으로 지정해야 해요.
값은 [`return` 키워드][return-keyword]를 사용해서 함수에서 반환해요.
함수는 기본적으로 외부 [기억 부류][storage class]를 가져요. 즉, 프로그램이 실행되는 동안 존재하고 파일 외부에서도 볼 수 있어요.
이를 막으려면 `static` 키워드를 추가해서 내부에서만 보이도록 지정할 수 있어요.

```c
static int add(int x, int y) {
  return x + y;
}
```

위 예제에서 변수 `x`와 `y`는 함수 안에서만 사용할 수 있어요. 즉, 함수 스코프를 가져요.
[스코프][scope]란 이름(프로그램 요소의 이름)과 연결된 값이 그 이름이 정의된 코드 "영역" 안에서만 접근할 수 있다는 개념이에요.
C의 주요 코드 영역은 다음과 같아요:

- 파일
- 함수
- 블록 (루프나 다른 구조 안에서처럼)

함수는 함수 이름을 지정하고 각 매개변수에 맞는 인자를 전달해서 호출해요.

```c
int sum = add(1, 2);
```

C는 두 가지 종류의 [주석][comments]을 지원해요.
한 줄 주석은 `//`로 시작하고(C99부터), 여러 줄 주석은 `/*`로 시작해서 `*/`로 끝나요.
