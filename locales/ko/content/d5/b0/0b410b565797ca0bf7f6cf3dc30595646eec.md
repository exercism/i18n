# 소개

비트 연산을 사용하면 이진수의 개별 자릿수를 조작할 수 있어요.

Elm은 [Bitwise 모듈](https://package.elm-lang.org/packages/elm/core/latest/Bitwise)에서 여러 비트 연산자를 제공해요.

## 기본 연산

숫자의 개별 비트를 조작하는 것을 _마스킹_이라고 해요.
_마스크_는 특정 비트를 정해진 방식으로 설정해 둔 숫자로, `and`, `or`, `xor` 같은 비트 연산자를 사용해 다른 숫자를 조작할 때 써요.

### and

`and`는 두 숫자에서 모두 `1`인 비트만 남겨서 두 숫자를 결합해요.
이 연산은 개별 비트가 설정되어 있는지 확인할 때 유용해요.
예를 들어 어떤 숫자의 4번째 비트가 `1`로 설정되어 있는지 확인하려면, `01000`(십진수로 `8`) 마스크와 `and` 연산을 한 뒤 결과가 0이 아닌지 보면 돼요:

```elm
Bitwise.and 13 8 --> 8
--  13 = 01101
--   8 = 01000
-- and = 01000 = 8
```

### or

`or`는 두 숫자 중 하나 또는 둘 다에서 `1`인 비트를 `1`로 설정해서 두 숫자를 결합해요.
이 연산은 특정 비트를 `1`로 설정할 때 유용해요.
예를 들어 `10101`의 2번째 비트를 `1`로 설정하려면, `00010` 마스크와 `or` 연산을 해요:

```elm
Bitwise.or 21 2 --> 23
-- 21 = 10101
--  2 = 00010
-- or = 10111 = 23
```

### 배타적 논리합 (xor)

`xor`는 한 숫자에서는 `1`이고 다른 숫자에서는 `0`인 비트를 `1`로 설정해서 두 숫자를 결합해요.
이 연산은 비트를 반대 값으로 뒤집을 때 유용해요:

```elm
Bitwise.xor 20 5 --> 17
--  20 = 10100
--   5 = 00101
-- xor = 10001 = 17
```

### 보수

`complement`는 숫자의 각 비트를 반전시켜요(`0`은 `1`이 되고, `1`은 `0`이 돼요).

이 연산을 하면 양수는 음수가 되고 음수는 양수가 돼요.
이진수에서 음수는 가장 왼쪽 자리에 `1`을 두는 방식으로 표현되기 때문이에요.

```elm
Bitwise.complement 21 --> -22
--         21 = 00000000000000000000000000010101
-- complement = 11111111111111111111111111101010 = -22
```

### 비트 시프트

다음 연산자들은 비트를 지정한 자릿수만큼 왼쪽이나 오른쪽으로 옮겨요. 결과적으로 2의 거듭제곱을 곱하거나 나누는 것과 같아요.

`shiftLeftBy`는 비트를 왼쪽으로 옮기고, 오른쪽에서 `0`을 채워 넣어요.
예를 들어 `21`을 왼쪽으로 3자리 옮기려면:

```elm
Bitwise.shiftLeftBy 3 21 --> 168
--  21 = 10101
-- shiftLeftBy 3 = 10101000 = 168
```

이는 `21 * 2^3 = 21 * 2 * 2 * 2 = 168`과 같아요.

`shiftRightBy`: 비트를 오른쪽으로 옮겨요:

```elm
Bitwise.shiftRightBy 2 21 --> 5
--  21 = 10101
-- shiftRightBy 2 = 00101 = 5
```

오른쪽으로 2자리 시프트하는 것은 4로 나누는 정수 나눗셈과 같아요.

참고로 이 함수는 가장 왼쪽 비트에 있는 값을 그대로 복제해요.
그래서 음수는 계속 음수로 남아요:

```elm
Bitwise.shiftRightBy 3 -21 --> -3
--  -21 = 111...101011
-- shiftRightBy 3 = 111...11101 = -3
```

오른쪽으로 시프트하면서 0으로 채우고 싶다면 `shiftRightZfBy`를 사용해요:

```elm
Bitwise.shiftRightZfBy 3 -21 --> 536870909
--  -21 = 111...101011
-- shiftRightZfBy 3 = 00111...11101 = 536870909
```
