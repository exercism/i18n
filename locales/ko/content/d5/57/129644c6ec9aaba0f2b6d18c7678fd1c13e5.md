# 지시사항

이 연습 문제에서는 2012년 9월 15일에 문을 연 뉴욕의 한 미용실을 위한 예약 스케줄러를 만들어요.

예약 날짜와 관련된 네 가지 작업이 있어요. 날짜와 시간은 다음 세 가지 형식 중 하나를 사용해요.

- `"7/25/2019 13:45:00"`
- `"July 25, 2019 13:45:00"`
- `"Thursday, July 25, 2019 13:45:00:00"`

~~~~exercism/caution
테스트는 자동으로 문화권을 `en-US`로 설정해요. 문화권을 직접 설정하거나 지정할 필요는 없어요.
~~~~

## 1. 예약 날짜 파싱하기

예약 날짜의 텍스트 표현을 해당하는 `DateTime` 형식으로 파싱할 수 있는 `schedule` 함수를 구현해요.

```fsharp
schedule "7/25/2019 13:45:00"
// => DateTime(2019, 7, 25, 13, 45, 0)
```

## 2. 예약이 이미 지났는지 확인하기

예약 날짜를 받아서 예약이 과거의 어느 시점이었는지 확인하는 `hasPassed` 함수를 구현해요.

```fsharp
hasPassed (DateTime(1999, 12, 31, 9, 0, 0))
// => true
```

## 3. 예약이 오후인지 확인하기

예약 날짜를 받아서 예약이 오후(12:00 이상, 18:00 미만)인지 확인하는 `isAfternoonAppointment` 함수를 구현해요.

```fsharp
isAfternoonAppointment (DateTime(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. 예약의 시간과 날짜 설명하기

예약 날짜를 받아서 그 날짜와 시간에 대한 설명을 반환하는 `description` 함수를 구현해요.

```fsharp
description (DateTime(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on 3/29/2019 3:00:00 PM."
```

## 5. 기념일 날짜 반환하기

올해의 기념일 날짜인 9월 15일을 반환하는 `anniversaryDate` 함수를 구현해요.

```fsharp
anniversaryDate()
// => DateTime(2019, 9, 15, 0, 0, 0)
```
