# 소개

Common Lisp의 해시 테이블은 연관 데이터를 저장하는 자료 구조예요.
해시 테이블은 키(어떤 객체든 될 수 있어요)를 값(역시 어떤 객체든 될 수 있어요)에 대응시켜요.
다른 언어에서는 이 개념을 맵, 딕셔너리, 해시라고 부르기도 해요.

## 해시 테이블 만들기

해시 테이블은 `make-hash-table` 함수로 만들 수 있어요.

`(make-hash-table) ; => #<HASH-TABLE :TEST EQL :COUNT 0 {10024AD2B3}>`

(해시 테이블이 출력되는 모습은 구현에 따라 다르기 때문에 REPL에서는 다르게 보일 수 있어요.)

## 키로 값 가져오기

해시 테이블에서 키로 값을 가져오려면 `gethash` 함수를 사용해요:

```lisp
*h* ; => #<HASH-TABLE :TEST EQL :COUNT 3 {10024AD2B3}>`
(gethash :foo *h*) ; => :bar
                   ;    T
```

`gethash` 함수는 [다중 값][concept-multiple-values]을 반환하는데, 이건 다른 개념에서 설명할 거예요.

## 값 넣기

해시 테이블에 값을 넣으려면 `gethash`와 함께 `setf`를 이렇게 사용해요:

`(setf (gethash :foo *hash-table*) :bar) : => :bar`

이렇게 하면 해시 테이블 `*hash-table*`에서 키 `:foo`의 값이 `:bar`로 바뀌어요.
그리고 그 값을 반환해요.

`setf`의 사용법은 다른 개념에서 설명할 거예요.
