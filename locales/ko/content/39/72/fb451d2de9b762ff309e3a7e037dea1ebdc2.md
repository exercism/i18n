# 소개

`Enum`은 열거 가능한 값을 다루기 위한 알고리즘 모음을 제공하는 아주 유용한 모듈이에요. 정렬, 필터링, 그룹화, 개수 세기, 검색, 최솟값/최댓값 찾기 등 다양한 기능을 제공해요.

일반적으로 _열거 가능한 값_이란 반복할 수 있는 모든 데이터, 즉 컬렉션이에요. Elixir에서 열거 가능한 값은 `Enumerable` [프로토콜][exercism-protocols]을 구현한 모든 데이터 타입이에요. 그중 가장 흔한 것은 [리스트][exercism-lists]와 [맵][exercism-maps]이에요.

`Enum`의 많은 함수는 인자로 함수를 받아요.

```elixir
Enum.all?([1, 2, 3, 4, 5], fn x -> x > 3 end)
# => false
```

가장 많이 쓰는 `Enum` 함수는 `map`과 `reduce`예요.

## `map/2`

`Enum.map/2`를 사용하면 열거 가능한 값의 모든 원소를 다른 원소로 바꿀 수 있어요. `Enum.map/2`의 두 번째 인자는 원래 원소를 받아 그 대체값을 반환하는 함수예요.

## `reduce/3`

`Enum.reduce/3`를 사용하면 열거 가능한 값 전체를 하나의 값으로 _줄일_ 수 있어요. 그러려면 _누산기_라는 특별한 변수를 사용해요. 누산기는 반복과 반복 사이에서 줄여 나가는 과정의 중간 상태를 담아 둬요.

`Enum.reduce/3`의 두 번째 인자는 누산기의 초깃값이에요. 세 번째 인자는 원소와 누산기를 받아 누산기의 새 값을 반환하는 함수예요.

## 맵 다루기

`Enum` 함수에 맵을 사용하면, 맵은 자동으로 두 개의 원소를 담은 `{key, value}` 튜플의 리스트로 변환돼요.

다시 맵으로 되돌리려면 `Enum.into/2`를 사용해요. `Enum.into/2`는 열거 가능한 값을 콜렉터블, 즉 `Collectable` 프로토콜을 구현한 모든 데이터 구조로 변환하는 함수예요. `Enum.reduce/3`의 반대라고 생각하면 돼요.

`Enum`에는 `Enum.into/3`도 있어요. `Enum.into/3`은 `Enum.into/2`의 변형으로, 열거 가능한 값을 콜렉터블로 변환하는 동안 적용할 변환 함수를 인자로 받아요.

### 맵에 매핑하기

맵에 변환(매핑)을 적용하기 위해 `Enum.into/3`이나 `Enum.map/2`에 `Enum.into/2`를 함께 쓰는 대신, 전용 함수인 `Map.new/2`를 사용할 수도 있어요. `Map.new/2`는 열거 가능한 값과 변환 함수를 받는다는 점에서 `Enum.into/3`과 똑같이 동작하지만, 콜렉터블을 고르게 하는 대신 항상 새로운 맵을 반환해요.
