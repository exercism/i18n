# 숫자

`INT`는 Sather에서 정수를 나타내는 타입이에요: `0`, `7`, `-3`. 정수로 답하는 루틴은 콜론 뒤에 그렇게 밝혀요. 텍스트로 답하는 루틴이 `STR`이라고 밝히는 것과 같은 방식이에요.

```sather
   goals : INT is
      return 42;
   end;
```

루틴은 **인자**를 받을 수 있어요. 인자는 루틴을 호출할 때 넘겨주는 값이에요. 각 인자는 루틴 이름 뒤 괄호 안에서 이름과 타입을 함께 지정해요.

```sather
   total(first : INT, second : INT) : INT is
      return first + second;
   end;
```

두 인자의 타입이 같으면 이름을 함께 붙일 수 있어요.

```sather
   total(first, second : INT) : INT is
```

괄호 안에 값을 넣으면 호출할 수 있어요.

```sather
SCORES::total(3, 4)     -- this is 7
```

산술 연산자는 `+`, `-`, `*`, `/`, `%` 이렇게 다섯 개예요.

`INT` 두 개에 대한 `/`는 **정수 나눗셈**이에요. 분수를 주는 대신 나머지를 버려요.

```sather
7 / 2      -- 3, not 3.5
```

`%`는 그 나눗셈에서 남은 값을 줘요.

```sather
7 % 2      -- 1
```

둘은 함께 동작해요. `7`은 `2`가 `3`번 들어가고 `1`이 남는 수예요.
