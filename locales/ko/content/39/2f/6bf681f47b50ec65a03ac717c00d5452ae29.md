# 소개

## Alias

같은 프로젝트 안에서 서로 다른 Elixir 모듈끼리 코드를 공유하려면, 바깥 모듈을 전체 이름으로 참조해야 해요. 그런데 그 이름이 너무 길거나 헷갈린다면 어떨까요?

특수 형식 `alias`을 사용하면 바깥 모듈을 참조할 때 쓰는 이름을 줄이거나 바꿀 수 있어요. 인자 없이 사용하면 모듈 이름을 마지막 부분만 남기고 줄여요. 예를 들어 `MyApp.Logger.Settings`는 `Settings`가 돼요. 원하는 이름은 `:as` 옵션으로 지정할 수 있어요.

보통 alias는 모듈 정의의 맨 앞에 추가해요.

```elixir
defmodule Square do
  alias Integer, as: I

  def area(a), do: I.pow(a, 2)
end
```

## Import

특수 형식 `import`을 사용하면 모듈 이름을 쓰지 않고도 바깥 모듈의 함수를 사용할 수 있어요.

바깥 모듈 전체를 가져오면 기존 로컬 함수와 충돌이 생길 수 있어요. 이를 피하려면 `:except`와 `:only` 두 가지 옵션을 쓸 수 있어요. 둘 다 키워드 리스트를 받는데, 키는 함수 이름이고 값은 함수의 인자 수예요.

보통 import도 모듈 정의의 맨 앞에 추가해요.

```elixir
defmodule Square do
  import Integer, only: [pow: 2]

  def area(a), do: pow(a, 2)
end
```
