# 지침

넷볼 훈련은 트랙을 도는 것으로 시작해요. 코치는 바퀴마다 거리를 조금씩 늘려요. 첫 바퀴는 100미터, 두 번째는 110미터, 세 번째는 120미터이고, 이렇게 매번 10미터씩 길어져요.

세 가지 과제는 모두 `WARM_UP_LAPS` 클래스에 넣어요.

## 1. 총거리는 얼마일까요?

바퀴 수가 주어지면 총 거리를 계산해요.

```sather
WARM_UP_LAPS::distance_run(3)
-- => 330
```

100 + 110 + 120이에요. 0바퀴면 0미터예요.

## 2. 거리를 채우려면 몇 바퀴가 필요할까요?

미터 단위의 거리가 주어졌을 때, 누적 거리가 그 거리 이상이 되려면 몇 바퀴를 돌아야 할까요?

```sather
WARM_UP_LAPS::laps_to_reach(330)
-- => 3
WARM_UP_LAPS::laps_to_reach(331)
-- => 4
```

0미터라면 바퀴를 전혀 돌 필요가 없어요.

## 3. 처음으로 길어지는 바퀴는 몇 번째일까요?

미터 단위의 거리가 주어졌을 때, *그 자체로* 그 거리보다 긴 첫 번째 바퀴는 몇 번째일까요? 1번 바퀴는 100미터, 2번 바퀴는 110미터이고, 이렇게 이어져요.

```sather
WARM_UP_LAPS::first_long_lap(115)
-- => 3
```

3번 바퀴는 120미터로, 115를 넘는 첫 번째 바퀴예요.
