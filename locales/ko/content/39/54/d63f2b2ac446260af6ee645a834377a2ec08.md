# 개요

PHP에는 `while`을 비롯한 여러 내장 반복 제어 구조가 있어요. `while`문의 기본 형태는 다음과 같아요:

```php
while (expr) {
  // statements
}
```

표현식(_expr_)이 _truthy_ 값으로 평가되는 동안, 루프 안의 문들을 반복 실행해요. 첫 번째 반복 전에 표현식(_expr_)이 false로 평가되면, 문들은 한 번도 실행되지 않아요.

대신 `do-while`문을 사용할 수도 있는데, 이 문은 표현식(_expr_)을 평가하기 전에 루프 안의 문들을 한 번 실행해요.

```php
do {
  // statements
} while (expr);
```
