# 소개

Gleam의 배열은 값이 0개 이상 담긴 불변 컬렉션이에요. 배열 안의 값은 모두 같은 타입이어야 해요. 배열은 불변이기 때문에 한 번 만들어지면 그 값은 절대 바뀌지 않아요. 배열을 수정하는 것처럼 보이는 함수나 연산자(예를 들어 원소를 추가하는 것)는 실제로는 새로운 배열을 반환해요.

배열은 다음과 같이 정의할 수 있어요:

```gleam
let empty = []
let singleValue = [5]
let threeValues = ["a", "b", "c"]
```

배열에 원소를 추가하는 가장 흔한 방법은 스프레드 문법을 쓰는 거예요:

```gleam
let two_to_four = [2, 3, 4]
let one_to_four = [1, ..two_to_four]
// -> [1, 2, 3, 4]
```

Gleam 표준 라이브러리의 [`gleam/list`](https://hexdocs.pm/gleam_stdlib/gleam/list.html) 모듈에는 배열을 다룰 때 유용한 함수가 많이 들어 있어요. 이 모듈은 Gleam 코드에서 아주 흔히 쓰이니 익숙해지면 좋아요.

배열 패턴은 case 식에서 배열을 매칭하고 그 안에 담긴 값을 변수에 할당할 때 사용할 수 있어요:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [] -> "Empty list"
    [x] -> "List with one item: " <> x
    [x, y] -> "List with two items: " <> x <> " and " <> y
    _ -> "List with three or more items"
  }
}
```

정확한 길이의 배열뿐만 아니라, 스프레드 문법으로 최소한 특정 길이 이상인 배열도 매칭할 수 있어요:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [_, _, ..] -> "List with at least two items"
    [_] -> "List with one item"
    [] -> "Empty list"
  }
}
```

스프레드 문법은 배열의 나머지 부분을 변수에 할당할 때도 사용할 수 있어요:

```gleam
pub fn remove_first_item(list: List(String)) -> List(String) {
  case list {
    // Return the list without the first item
    [_, ..rest] -> rest

    // There's no first item to remove, return an empty list
    _ -> []
  }
}
```

case 식은 매칭 대상 타입이 가질 수 있는 모든 값에 대한 패턴을 갖춰야 해요. 그래서 남은 값을 처리할 때는 마지막에 버림 패턴(`_`)을 자주 사용해요.
