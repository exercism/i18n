# 지침

처음 N개의 자연수에 대해, 합의 제곱과 제곱의 합 사이의 차이를 구해요.

처음 열 개의 자연수의 합의 제곱은
(1 + 2 + ... + 10)² = 55² = 3025예요.

처음 열 개의 자연수의 제곱의 합은
1² + 2² + ... + 10² = 385예요.

따라서 처음 열 개의 자연수의 합의 제곱과 처음 열 개의 자연수의 제곱의 합의 차이는 3025 - 385 = 2640이에요.

이 문제를 처음부터 스스로 효율적인 해법으로 찾아낼 필요는 없어요. 자료를 찾아보는 것도 괜찮고, 오히려 권장해요.
문제에 맞는 최선의 알고리즘을 찾는 것은 소프트웨어 엔지니어링에서 중요한 능력이에요.
