# 소개

프로그램이나 코드에 뭔가 잘못되었거나 예상하지 못한 일이 있을 때는 오류로 알려 주는 것이 유용해요.

오류는 JavaScript 객체예요.

이 객체의 주요 속성은 `message`예요:

```javascript
const error = new Error('Oops, something went wrong');

console.log(error.message);
// => "Oops, something went wrong"
```

`throw` 구문을 사용하면 오류를 던질 수 있어요.

```javascript
throw new Error('Oops');
```

`Error`가 던져지면 현재 실행이 중단되고, 호출 스택의 첫 번째 catch 블록에서 이어져요.

```javascript
try {
  throw new Error('Oops');
} catch (error) {
  console.log(error.message);
  // => "Oops"
}
```

JavaScript의 다른 클래스와 마찬가지로, `extends` 키워드를 사용하면 `Error`를 상속받아 사용자 정의 오류를 만들 수 있어요.
`instanceof` 구문은 잡은 오류가 `Error`의 특정 하위 클래스의 인스턴스인지 확인해 줘요.

```javascript
class CustomError extends Error {}

try {
  // ... Code that may throw an error
} catch (error) {
  if (error instanceof CustomError) {
    console.log('The error thrown is an instance of the CustomError');
  }
}
```
