# 튜플

Elm의 튜플은 값 두 개 또는 세 개를 담을 수 있고, 각 값은 어떤 타입이든 가질 수 있어요.
Elm에서 튜플은 주로 단순하고 일시적인 타입에 사용해요.
그래서 튜플은 값이 최대 3개까지이고, 이를 더 장려하기 위해 편의 함수도 값이 2개인 경우에만 제공해요.
더 복잡한 데이터라면 레코드로 바꾸는 게 좋아요.
함수에서 값을 두 개 이상 반환해야 할 때 흔히 사용해요.
튜플의 필드에는 이름이 없고, 구조 분해나 위치를 통해 접근해요.

튜플에 대한 [간결한 소개][tuples-concise]를 읽어볼 수 있어요.
[더 깊이 있는 소개][tuples-in-depth]도 있고, [Tuple 모듈의 API 문서][tuple-core]에는 코드 예제와 자세한 설명이 들어 있어요.

## 선언

튜플의 타입은 괄호로 만들고, 각 원소의 타입은 쉼표로 구분해요.

```elm
type alias IntStringTuple = (Int, String)
```

### 생성

튜플은 괄호로 만들고, 각 원소는 쉼표로 구분해요.

```elm
aTuple : IntStringTuple
aTuple = (123, "elements can be of differing types")
```

`Tuple.pair`를 사용해서 값이 두 개인 튜플을 만들 수도 있어요.

```elm
anotherTuple : (String, String)
anotherTuple = Tuple.pair "this time it's" "two strings"
    --> ("this time it's", "two strings")
```

### 접근

위치로 튜플의 값에 접근하는 함수도 있는데, `Tuple.first`와 `Tuple.second`예요.

```elm
Tuple.first aTuple
    --> 123

Tuple.second aTuple
    --> "elements can be of differing types"
```

튜플은 튜플 패턴 매칭을 사용해 바인딩에서 _구조 분해_할 수 있어요.
구조 분해는 `let` 표현식, 함수 선언, `case` 문에서 할 수 있어요.

```elm
repeatString : (Int, String) -> Bool
repeatString aTuple =
let
    (aNumber, aString) = aTuple
in
    String.repeat aNumber aString

repeatStringAgain : (Int, String) -> Bool
repeatStringAgain (aNumber, aString) = String.repeat aNumber aString
```

`case` 문의 패턴 매칭을 사용하면 값의 내용에 대해서도 매칭할 수 있어요.

```elm
has123 : (Int, String, Bool) -> Bool
has123 aTuple =
    case aTuple of
        (123, _, _) ->
            True
        (_, "123", _) ->
            True
        (_, _, True) ->
            True
        _ ->
            False
```
