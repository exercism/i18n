# 지침

여러분의 친구가 **Gross Store**라는 오래된 도매점을 운영하고 있어요.

가게 이름은 이 가게에서 파는 물건의 수량에서 나왔어요. 수량을 전부 [그로스 단위][gross-unit]로 세기 때문이죠.

친구가 자기 가게를 위한 판매 시점 관리(POS) 시스템을 만들어 달라고 부탁했어요.

**우선 이 시스템의 프로토타입을 만들어 볼 거예요.**

**프로토타입에서는 수량만 기록할 거예요.**

친구가 도움이 되도록 단위 목록을 줬어요:

| 단위               | 값    |
| ------------------ | ----- |
| quarter_of_a_dozen | 3     |
| half_of_a_dozen    | 6     |
| dozen              | 12    |
| small_gross        | 120   |
| gross              | 144   |
| great_gross        | 1728  |

## 1. 프로그램에 측정 단위를 저장해요

단위를 사용하려면 프로그램에 그 단위를 저장해야 해요.

```rust
let units = units();
// Felt252Dictionary with entries like { 'dozen': 12 }
```

## 2. 고객 계산서를 새로 만들어요

고객을 위한 새 (빈) 계산서를 만드는 함수를 구현해야 해요.

```rust
let bill = new_bill();
// Empty Felt252Dictionary
```

## 3. 고객 계산서에 품목을 추가해요

이걸 구현하려면 다음을 해야 해요:

- 주어진 `unit`이 `units` 맵에 없으면 `false`를 반환해요.
- 그렇지 않으면 품목 이름을 키로 삼아 고객 `bill`에 품목을 추가한 다음, `true`를 반환해요.
- 품목이 계산서에 이미 있으면, 주어진 `unit`에 해당하는 값만큼 수량을 늘려요.

```rust
let bill = new_bill();
let units = units();
let ok = add_item(bill, units, 'carrot', 'dozen');
println!(ok);
// Output: true (since dozen is a valid unit)
```

> 반환값의 타입은 `bool`이에요.

## 4. 고객 계산서에서 품목을 제거해요

이걸 구현하려면 다음을 해야 해요:

- 주어진 품목이 계산서에 **없으면** `false`를 반환해요.
수량이 0인 품목은 계산서에 없는 것으로 간주해요.
- 주어진 `unit`이 `units` 맵에 없으면 `false`를 반환해요.
- 새 수량이 0보다 작아지면 `false`를 반환해요.
- 새 수량이 0이면 그 품목은 `bill`에서 제거된 것으로 간주하므로 `true`를 반환해도 돼요.
- 그렇지 않으면 품목의 수량을 줄이고 `true`를 반환해요.

```rust
let bill = new_bill();
let units = units();
let ok = remove_item(bill, units, 'carrot', 'dozen');
println!(ok);
// Output: false (because there are no carrots in the bill)
```

> 반환값의 타입은 `bool`이에요.

## 5. 고객 계산서에 있는 특정 품목의 수량을 반환해요

```rust
let mut bill: Felt252Dict<u32> = Default::default();
bill.insert('carrot', 12);
bill.insert('grapes', 3);
let qty = get_item(bill, 'carrot');
println!(qty);
// Output: 12
```

> 반환값의 타입은 `u32`예요.
