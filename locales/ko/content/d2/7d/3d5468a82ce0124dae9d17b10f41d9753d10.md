# 소개

## 모듈

Gleam 코드는 모듈로 구성되어 있고, 각 파일이 하나의 Gleam 모듈이에요.

지금까지 `pub fn` 문법으로 함수를 작성해 왔어요. 이는 다른 모듈에서도 사용할 수 있는 공개 함수를 정의하죠. `fn`으로 정의한 함수는 해당 모듈 내에서만 비공개이며, 다른 모듈에서는 사용할 수 없어요.

```gleam
// This function is public
pub fn add(x, y) {
  x + y
}

// This function is private
fn subtract(x, y) {
  x - y
}
```

Gleam 모듈에는 이름이 있고, 그 이름은 `src` 또는 `test` 디렉터리 안의 파일 경로를 기반으로 해요.

예를 들어, `src\geometry\rectangle.gleam`(Windows) 또는 `src/geometry/rectangle.gleam`(UNIX 계열 운영체제)에 정의된 모듈의 이름은 `geometry/rectangle`이에요.

## 다른 모듈에서 함수 임포트하기

다른 모듈에 정의된 함수에 접근하려면 임포트를 사용해요.
해당 모듈에서 공개한 모든 함수는 그 모듈을 임포트할 때 사용할 수 있게 돼요.
하지만 어떻게 접근하는지는 모듈을 임포트하는 방식에 따라 달라요.

모듈 이름을 붙인 임포트가 기본이고, 그런 모듈 안의 함수(예를 들어 `gleam/list` 모듈의 `map` 함수)에 접근할 때는 모듈 이름을 앞에 붙여요(`list.map`).

```gleam
// Import the int module
import gleam/int

pub fn run(x: Int) -> String {
  // Use the to_string function from the int module
  int.to_string(x)
}
```

기본적으로 모듈을 가리키는 이름은 모듈 이름의 마지막 부분이에요. 여기서는 `int`죠. 하지만 `as` 키워드를 사용하면 바꿀 수 있어요.

```gleam
// Import the int module and refer to it as i
import gleam/int as i

pub fn run(x: Int) -> String {
  i.to_string(x)
}
```

모듈 이름을 생략한 임포트를 하면 해당 모듈에서 공개한 함수에 접두사 없이 바로 접근할 수 있어요.

```gleam
// Import the to_string function from the int module
import gleam/int.{to_string}

pub fn run(x: Int) -> String {
  to_string(x)
}
```

모듈 이름을 붙인 임포트가 선호되는데, 함수가 어디서 왔는지 독자가 더 명확히 알 수 있고 이름 충돌을 피할 수 있기 때문이에요.


## 표준 라이브러리

Gleam에는 풍부하고 문서화가 잘 된 표준 라이브러리가 있어요. 문서는 [hexdocs.pm/gleam_stdlib][docs]에서 온라인으로 볼 수 있어요. 이 링크를 어딘가에 저장해 두세요. 정말 자주 사용하게 될 거예요!

대부분의 내장 데이터 타입에는 해당 데이터 타입을 다루는 함수를 제공하는 모듈이 있어요. 예를 들어 정수를 위한 `gleam/int` 모듈, 문자열을 위한 `gleam/string` 모듈, 배열을 위한 `gleam/list` 모듈 등이 있죠.

[docs]: https://hexdocs.pm/gleam_stdlib/
