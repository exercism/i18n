# 삼항 연산자

삼항 연산자는 `if..else..` 비교를 수행하고 값을 반환하는 또 다른 문법을 제공해요.

## 문법

PHP는 조건이 참으로 여겨지는지에 따라 동작을 평가할 수 있는 if 문을 제공해요.

```php
if ($condition) {
  $value = 1;
} else {
  $value = 2
}
```

또는 삼항 연산자로 같은 동작을 나타낼 수 있어요.

```php
$value = $condition
  ? 1  // True branch
  : 2; // False branch
```

비교 문법은 짧고, `(condition) ? (evaluate if true) : (evaluate if false);`로 나타내요.

## 장점

삼항 연산자를 쓰는 뚜렷한 장점은 간결함이에요. `if..else..` 문에 비해 조건 표현식을 짧게 쓸 수 있죠. 그런데 다른 장점도 여럿 있어요.

- 식이라서 다른 식 안에서 사용할 수 있어요.
- 각 분기의 지연 평가를 가능하게 해요.

  ```php
  function expensiveCalculation(): int
  {
    // An expensive calculation is performed
    $answerToEverything = 42;
    return $answerToEverything;
  }

  $needExactAnswer = false;
  $estimatedAnswer = 40;
  $answer = $needExactAnswer ? expensiveCalculation() : $estimatedAnswer;
  ```

  이 예시에서 정확한 답이 필요하지 않다면, 비용이 많이 드는 계산은 호출되지 않아요.

## 단점

삼항 연산자에는 몇 가지 단점이 있어서, 사용을 신중히 고려해야 해요.

- 삼항 연산자는 키워드 대신 기호를 해석해야 하므로 읽기가 더 어려울 수 있어요.
- PHP의 삼항 연산자는 대부분의 현대 언어(C, Java, JavaScript 등)와 달리 왼쪽 결합이기 때문에, 의도치 않게 버그로 이어질 수 있어요.
- 참 또는 거짓 분기에서 평가되는 표현식은 값을 반환해야 해요.

## 더 짧게

삼항 문법은 `(condition) ?: (evaluate if falsey)`로 더 줄일 수 있어요.
이런 식으로 표현식에 대체 값을 제공할 수도 있어요.

```php
$fruit = null;
eat($fruit ?: 'apple');
```

이것은 _엘비스 연산자_ (`?:`)라고도 불려요.
