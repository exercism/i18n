# 주방 계산기

## 스토리

이 스토리는 한 언어에서 [튜플][type-tuple]을 살펴볼 수 있도록 도와줘요.

기본 전제는, 주방 재료가 종종 생소한 방식으로 계량되고, 양이나 손에 있는 도구에 따라 서로 다른 변환이 필요하다는 것이에요. 튜플은 측정값의 숫자 부분에 [덕 타이핑][concept-duck-typing]을 제공하는 데 사용해요.

그래서 이 스토리는 실수를 사용한 값의 기본 변환을 다뤄요.

### 변환

| 변환 전            | 변환 후 |
| ------------------ | ------- |
| 1 mL               | 1mL     |
| 1 cup              | 240mL   |
| 1 fluid ounce (US) | 29.57mL |
| 1 teaspoon         | 5 mL    |
| 1 tablespoon       | 15 mL   |

## 과제

이 스토리는 학생들이 다음을 어떻게 사용하는지 익히도록 안내해요:

- 튜플
- 묶인 정보로서의 튜플
- 원소 인덱스로 튜플에서 값 가져오기
- 패턴 매칭으로 튜플에서 값 가져오기
- 새 튜플 만들기
