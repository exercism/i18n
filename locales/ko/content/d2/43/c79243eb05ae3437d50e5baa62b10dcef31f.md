# 힌트

## 일반

- 클로저를 정의하는 문법은 `{ (parameter list) -> ReturnType in bodyOfClosure }` 형태예요

## 1. 두 전선을 뒤집는 클로저 작성하기

- 튜플 분해를 사용하면 튜플의 각 구성 요소에 이름을 붙일 수 있어요

## 2. 전선을 회전시키는 클로저 작성하기

- 튜플 분해를 사용하면 튜플의 각 구성 요소에 이름을 붙일 수 있어요

## 3. 전선 섞기 생성기 구현하기

- 배열을 뒤집을 수 있게 해 주는 [Swift의 메서드][reverse]가 있어요
