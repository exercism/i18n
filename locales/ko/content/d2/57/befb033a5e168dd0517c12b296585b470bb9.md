# 지침

이번 연습 문제에서는 좋아하는 요리책을 보고 근사한 라자냐를 만들 수 있도록 도와주는 코드를 작성해 볼 거예요.

라자냐를 조리하는 데 걸리는 시간과 관련된 다섯 가지 작업이 있어요.

## 1. 오븐에 있어야 하는 예상 시간(분) 정의하기

`expected_minutes_in_oven` 함수를 정의해요. 이 함수는 인자를 받지 않고, 라자냐를 오븐에 몇 분 동안 넣어 두어야 하는지 반환해요. 요리책에 따르면 오븐에 넣어 두어야 하는 예상 시간은 40분이에요.

```gleam
expected_minutes_in_oven()
// -> 40
```

## 2. 남은 오븐 시간(분) 계산하기

`remaining_minutes_in_oven` 함수를 정의해요. 이 함수는 라자냐가 지금까지 오븐에 있던 실제 시간(분)을 인자로 받고, 앞의 작업에서 구한 예상 오븐 시간을 기준으로 라자냐가 오븐에 더 있어야 하는 시간(분)을 반환해요.

```gleam
remaining_minutes_in_oven(30)
// -> 10
```

## 3. 준비 시간(분) 계산하기

`preparation_time_in_minutes` 함수를 정의해요. 이 함수는 라자냐에 넣은 층의 개수를 인자로 받고, 각 층을 준비하는 데 2분이 걸린다고 가정했을 때 라자냐를 준비하는 데 걸린 시간(분)을 반환해요.

```gleam
preparation_time_in_minutes(2)
// -> 4
```

## 4. 총 작업 시간(분) 계산하기

`total_time_in_minutes` 함수를 정의해요. 이 함수는 두 개의 인자를 받아요. 첫 번째 인자는 라자냐에 넣은 층의 개수이고, 두 번째 인자는 라자냐가 오븐에 있던 시간(분)이에요. 이 함수는 라자냐를 조리하는 데 총 몇 분을 일했는지 반환해야 해요. 이 값은 준비 시간(분)과 그 시점까지 라자냐가 오븐에 있던 시간(분)을 더한 값이에요.

```gleam
total_time_in_minutes(3, 10)
// -> 16
```

## 5. 라자냐가 완성되었음을 알리는 알림 만들기

`alarm` 함수를 정의해요. 이 함수는 인자를 받지 않고, 라자냐가 다 되어 먹을 수 있다는 메시지를 반환해요.

```gleam
alarm()
// -> "Ding!"
```
