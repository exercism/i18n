# 힌트

## 일반

- 팬텀 빌더 패턴에 관한 Jeroen Engels의 [훌륭한 강연][phantom-builder-pattern]을 봐요

## 1. 보물 상자를 위한 자리 표시자를 만들어요

- `Chest`는 팬텀 타입을 추가한 단일 배리언트인 `TreasureChest`와 같아도 돼요
- 자리 표시자 `Chest todo`에는 타입 인자가 충분하지 않아요. 팬텀 타입이 빠져 있어요
- 팬텀 타입은 확장할 수 있도록 레코드여야 해요
- 시작 타입은 아무 조건도 없는 `Chest treasure {}`이고, 최종 타입은 모든 검증을 통과한 `Chest treasure { conditions | securePassword : (), uniqueTreasure : () }`예요
- 시작 타입에서 최종 타입으로 넘어가려면 `secureChest`와 `uniqueTreasures`가 각각 `securePassword : ()`와 `uniqueTreasure : ()` 조건을 독립적으로 추가해요

## 2. 안전한 상자를 골라요

- 함수 인자에서 `Chest`를 패턴 매칭할 수 있어요
- [`String.length`][string-length] 함수를 사용해 비밀번호를 검증할 수 있어요
- `securePassword : ()` 조건은 함수 본문이 아니라 타입 시그니처에서 추가돼요
- 조건이 없는 `Chest`를 `Just`에 넣는다고 해서 타입이 바뀌지는 않아요. `Chest` 생성자로 새 값을 만들어야 해요

## 3. 고유한 보물을 골라요

- 사용할 수 있는 `List.unique` 함수는 없으니 직접 만들어야 해요
- 한 가지 방법은 `secureChest`와 비슷한 타입의 도우미 함수와 함께 `List.filterMap`을 사용하는 거예요
- `uniqueTreasure : ()` 조건은 함수 본문이 아니라 타입 시그니처에서 추가돼요
- 조건이 없는 `Chest`를 `Just`에 넣는다고 해서 타입이 바뀌지는 않아요. `Chest` 생성자로 새 값을 만들어야 해요

## 4. 완성된 결과물을 즐겨요

- `makeTreasureChest`는 `TreasureChest` 타입 생성자를 활용해야 해요
