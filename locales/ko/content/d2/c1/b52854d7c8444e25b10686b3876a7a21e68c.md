# 소개

## 정수

정수는 `{..., -2, -1, 0, 1, 2, ...}` 집합에 속하는 수예요.
정수의 최댓값과 최솟값은 PHP가 실행되는 시스템에 따라 결정돼요.
일반적으로 대부분의 현대 시스템에서 정수는 64비트 값이에요. 즉, `-9_223_372_036_854_775_808`부터 `9_223_372_036_854_775_807`까지 포함해 표현할 수 있어요.

```php
<?php

$a = 1234;
$a = 1_234_567;
```

진법 접두사를 사용하면 10진법이 아닌 다른 진법으로 정수 리터럴 값을 작성할 수 있어요:

```php
<?php

$a = 0123; // octal number (equivalent to 83 decimal)
$a = 0o123; // octal number (as of PHP 8.1.0)
$a = 0x1A; // hexadecimal number (equivalent to 26 decimal)
$a = 0b11111111; // binary number (equivalent to 255 decimal)
```

> PHP [문서][syntax]에서 가져왔어요.

## 부동소수점 수

부동소수점 수는 PHP에서 실수의 부분집합을 표현하는 데 사용돼요.
부동소수점 수는 하나 이상의 숫자로 시작하고, 그 숫자들은 소수점 구분 기호로 나뉘어요.

```php
<?php

$a = 1.234; 
$b = 1.2e3; 
$c = 7E-10;
$d = 1_234.567; // as of PHP 7.4.0
```

### 흔히 하는 실수

부동소수점 수로는 모든 수와 산술 연산을 수행할 수 없어요.
달러와 센트를 표현할 때 부동소수점 수를 사용하면 반올림 오류가 발생할 수 있어요.

```php
<?php

$result = 0.1 + 0.2; // => 0.30000000000000004
```

## 산술 연산자

PHP는 산술 연산을 수행하기 위한 여러 연산자를 제공해요. PHP의 산술 연산자는 표준 수학 연산 순서를 따라요. PHP가 제공하는 연산자는 다음과 같아요:

* 항등 (+)
* 부정 (-)
* 덧셈 (+)
* 뺄셈 (-)
* 곱셈 (*)
* 나눗셈 (/)
* 나머지 (%)
* 거듭제곱 (**)

```php
$moles = +'10';
$aLotOfMoles = 6.022 * 10**23 * $moles;
```

[syntax]: https://www.php.net/manual/en/language.types.integer.php#language.types.integer.syntax
