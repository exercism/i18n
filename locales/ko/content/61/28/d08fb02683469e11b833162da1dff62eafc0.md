# 지침

_Instruments of Texas_에서 일하면서, C#으로 작성된 실험적인 계산기 작업을 맡게 됐어요. 곱셈을 시작으로 여러 계산기 기능을 검증할 테스트 하네스를 만들고 있어요. 곱셈의 두 피연산자가 모두 음수일 때 특히 문제가 된다는 걸 알게 될 거예요.

`Calculator` 클래스는 이미 제공되어 있으니 수정하면 안 돼요.

## 1. 사용자 정의 예외 `CalculationException`의 정의를 완성해요

`CalculationException`의 생성자 정의를 완성해요. 이 생성자는 계산기가 던진 예외와, 예외가 발생한 시점에 처리 중이던 피연산자를 저장(래핑)해야 해요.

## 2. 계산기의 오버플로 조건을 처리하고 호출자에게 더 자세한 정보를 제공해요

생성자에 전달된 `Calculator` 인스턴스의 `Calculator.Multiply()` 메서드를 호출하면서 x와 y 정수 값을 전달하는 `CalculatorTestHarness.Multiply()` 메서드를 구현해요. `Calculator.Multiply()` 메서드에서 오버플로가 발생하면 `OverflowException`이 던져져요. 이 예외는 `CalculatorTestHarness.Multiply()` 메서드에서 잡아서 `CalculationException`으로 래핑해야 하고, 전달된 x와 y 값은 예외의 피연산자로 저장해야 해요. 새로 만든 `CalculationException` 객체를 던져야 해요. `Calculator.Multiply()` 메서드가 성공했을 때 반환하는 값은 무시해도 돼요.

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.Multiply(Int32.MaxValue, Int32.MaxValue);
// => throws an instance of CalculationException

var cth2 = new CalculatorTestHarness(new Calculator());
cth2.Multiply(3, 2);
// => silently exits
```

## 3. 유효한 입력에 대한 곱셈 연산을 테스트해요

정수 두 개를 받아 `CalculatorTestHarness.Multiply()` 메서드를 호출하는 `CalculatorTestHarness.TestMultiplication()` 메서드를 구현해요. `"Multiply succeeded"`가 반환돼요.

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.TestMultiplication(6, 7);
// => "Multiply succeeded"
```

## 4. 음수 입력에 대한 곱셈 연산을 테스트해요

`CalculatorTestHarness.TestMultiplication()` 메서드를 수정해서, 정수 인자 두 개가 모두 음수(0보다 작음)이면 `"Multiply failed for negative operands. <INNER_EXCEPTION_MESSAGE>"`가 반환되도록 해요.

`<INNER_EXCEPTION_MESSAGE>` 자리 표시자는 `CalculationException`의 내부 예외 메시지로 바꿔야 해요.

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.TestMultiplication(-2, -Int32.MaxValue);
// => "Multiply failed for negative operands. " + innerException.Message
```

## 5. 양수 입력에 대한 곱셈 연산을 테스트해요

`CalculatorTestHarness.TestMultiplication()` 메서드를 수정해서, 정수 인자 중 적어도 하나가 음수가 아니면 `"Multiply failed for mixed or positive operands. <INNER_EXCEPTION_MESSAGE>"`가 반환되도록 해요.

`<INNER_EXCEPTION_MESSAGE>` 자리 표시자는 `CalculationException`의 내부 예외 메시지로 바꿔야 해요.

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.TestMultiplication(Int32.MaxValue, Int32.MaxValue);
// => "Multiply failed for mixed or positive operands. " + innerException.Message
```
