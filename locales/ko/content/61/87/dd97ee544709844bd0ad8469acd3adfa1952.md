# 힌트

## 일반

- 하루 동안의 새 수는 `birdsPerDay`라는 필드에 저장돼요.
- 하루 동안의 새 수는 정확히 7개의 정수를 담은 배열이에요.

## 1. 지난주 새 수 확인하기

- 지난주 값을 저장하고 있으니, 지난주 값만 반환하면 돼요.

## 2. 오늘 몇 마리의 새가 방문했는지 확인하기

- 새 수는 가장 오래된 날부터 가장 최근 날 순서로 정렬되어 있고, 마지막 원소가 오늘을 나타낸다는 점을 기억해요.
- 마지막 원소에 접근할 때는 (고정된) 인덱스를 쓰거나(0부터 세는 걸 잊지 마요), 배열의 크기로 인덱스를 계산하면 돼요.

## 3. 오늘의 수 증가시키기

- 오늘의 수를 나타내는 원소를 오늘의 수에 1을 더한 값으로 설정해요.

## 4. 방문한 새가 없었던 날이 있었는지 확인하기

- `for`문으로 배열을 순회할 수 있어요.
- 또 다른 방법은 Java Stream API를 사용하는 거예요.

## 5. 처음 며칠 동안 방문한 새의 수 계산하기

- 방문한 새의 수를 담을 변수를 사용할 수 있어요.
- `for`문으로 배열을 순회할 수 있어요.
- 루프 안에서 변수를 갱신할 수 있어요.
- 기억해요: 배열의 인덱스는 `0`부터 시작해요.

## 6. 바쁜 날의 수 계산하기

- 바쁜 날의 수를 담을 변수를 사용할 수 있어요.
- `foreach`문으로 배열을 순회할 수 있어요.
- 루프 안에서 변수를 갱신할 수 있어요.
- 루프 안에서 조건문을 사용할 수 있어요.
