# 소개

_enum 타입_은 변수가 미리 정의된 상수들의 집합에 속하도록 해 주는 특별한 데이터 타입이에요.
변수는 그 타입을 위해 미리 정의된 값 중 하나와 같아야 해요.
흔한 예로는 나침반 방향(`NORTH`, `SOUTH`, `EAST`, `WEST` 값)과 요일이 있어요.

상수이기 때문에 enum 타입 필드의 이름은 대문자로 써요.

## enum 타입 정의하기

Java 프로그래밍 언어에서는 `enum` 키워드를 사용해 enum 타입을 정의해요.
예를 들어 요일 enum 타입은 이렇게 작성해요:

```java
public enum DayOfWeek {
    SUNDAY,
    MONDAY,
    TUESDAY,
    WEDNESDAY,
    THURSDAY,
    FRIDAY,
    SATURDAY
}
```

고정된 상수 집합을 표현해야 할 때는 언제든 enum 타입을 사용하는 게 좋아요.
태양계의 행성처럼 자연스러운 enum 타입도 여기에 해당하고, 컴파일 시점에 가능한 모든 값을 알고 있는 데이터 집합도 해당해요.
예를 들어 메뉴의 선택지나 명령줄 플래그 같은 것들이요.

## enum 타입 사용하기

위에서 정의한 `DayOfWeek` enum을 어떻게 사용하는지 보여 주는 코드예요:

```java
public class Shop {
    public String getOpeningHours(DayOfWeek dayOfWeek) {
        switch (dayOfWeek) {
            case MONDAY:
            case TUESDAY:
            case WEDNESDAY:
            case THURSDAY:
            case FRIDAY:
                return "9am - 5pm";
            case SATURDAY:
                return "10am - 4pm"
            case SUNDAY:
                return "Closed.";
        }
    }
}
```

```java
var shop = new Shop();
shop.getOpeningHours(DayOfWeek.WEDNESDAY);
// => "9am - 5pm"
```

## 메서드와 필드 추가하기

Java 프로그래밍 언어의 enum 타입은 다른 언어의 비슷한 기능보다 훨씬 강력해요.
`enum` 선언은 _클래스_(_enum 타입_이라고 불러요)를 정의해요.
enum 클래스 본문에는 메서드와 다른 필드를 포함할 수 있어요:

```java
public enum Rating {
    GREAT(5),
    GOOD(4),
    OK(3),
    BAD(2),
    TERRIBLE(1);

    private final int numberOfStars;

    Rating(int numberOfStars) {
        this.numberOfStars = numberOfStars;
    }

    public int getNumberOfStars() {
        return this.numberOfStars;
    }
}
```

`Rating` enum 타입의 멤버에서 `getNumberOfStars` 메서드를 호출하면 이렇게 돼요:

```java
Rating.GOOD.getNumberOfStars();
// => 4
```
