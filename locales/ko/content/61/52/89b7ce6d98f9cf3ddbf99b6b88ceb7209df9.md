# 소개

## 특성

[C# `Attribute`](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/)는 선언을 장식해서 클래스, 메서드, 열거형, 필드, 속성 또는 [그 밖에 지원되는](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/#attribute-targets) 선언에 메타데이터를 연결하는 방법을 제공해요.

특성은 선언 바로 위 줄에 `ClassAttribute`와 `FieldAttribute`를 추가하는 방식으로 적용할 수 있어요:

```csharp
[Class]
class MyClass
{
    [Field]
    int myField;
}
```

이런 선언적 메타데이터는 코드에 추가적인 구조화 정보를 연결해 줄 뿐, 코드의 동작 자체를 바꾸지는 않아요. 그런데 코드의 다른 부분에서는 이 메타데이터를 사용해서 대상의 동작 방식을 바꾸거나, 기능을 추가하고 변경하고 제거하거나 일부를 제한해요.

[미리 정의된 예약 특성](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/attributes/general#conditional-attribute)도 많이 있어요. 예를 들어 `Flags`, `Obsolete`, `Conditional`, `Experimental` 같은 것들이에요. 각각은 C# 문서에서 찾아볼 수 있는 고유한 의미를 가지고 있어요. [`Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute) 같은 특성의 전체 이름은 `<Name>Attribute` 형태라는 점을 기억해 두세요(예: `FlagsAttribute`).

## 플래그 열거형

C#의 [`enum` 타입](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/builtin-types/enum)은 이름이 붙은 상수들의 고정된 집합, 즉 열거형을 나타내요.

보통 `enum` 멤버 하나는 이름 붙은 상수 중 정확히 하나만 가리킬 수 있어요. 하지만 여러 상수를 한꺼번에 가리켜야 할 때도 있죠. 그럴 때는 [`Flags` 특성](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute)을 `enum`에 붙이면 돼요.

플래그 열거형은 다음과 같이 정의할 수 있어요(이진 정수 표기법 `0b` 사용):

```csharp
[Flags]
enum PhoneFeatures
{
    Call = 0b00000001,
    Text = 0b00000010
}
```

값이 `0b00000011`인 `PhoneFeatures` 인스턴스는 `Call`과 `Text` 플래그가 둘 다 설정되어 있어요.

기본적으로 열거형 멤버 값에는 `int` 타입이 사용돼요. 열거형 선언에서 타입을 지정하면 다른 정수 타입을 사용할 수 있어요:

```csharp
[Flags]
enum PhoneFeatures : byte
{
    Call = 0b00000001,
    Text = 0b00000010
}
```
