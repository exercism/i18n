# 지침

이 연습 문제에서는 [블랙잭][blackjack] 게임의 첫 턴을 시뮬레이션해요.

## 1. 주어진 카드의 값을 계산해요.

두 장의 카드를 받고, 딜러의 앞면 카드를 볼 수 있어요.
모든 카드는 "ace", "king", "three", "two" 같은 문자열로 표현해요.
각 카드의 값은 다음과 같아요:

| card  | value |  card   | value |
| :---: | :---: | :-----: | :---: |
|  ace  |  11   |  eight  |   8   |
|  two  |   2   |  nine   |   9   |
| three |   3   |   ten   |  10   |
| four  |   4   |  jack   |  10   |
| five  |   5   |  queen  |  10   |
|  six  |   6   |  king   |  10   |
| seven |   7   | _other_ |   0   |

~~~~exercism/note
일반적으로 에이스는 1 또는 11의 값을 가질 수 있지만, 단순하게 하기 위해 여기서는 11의 값만 가진다고 가정해요.
~~~~

카드를 문자열 인자로 받는 `Blackjack.parse_card` 메서드를 구현해요.
이 메서드는 카드의 값을 정수로 반환해야 해요.

```Crystal
Blackjack.parse_card("ace")
# => 11
```

## 2. 값의 범위에 이름을 붙여요.

플레이어의 점수는 값의 범위로 분류해야 해요.
플레이어 점수는 플레이어의 두 카드 값을 더해서 계산해요.
사용하는 범위는 다음과 같아요:

|   range   |  value   |
| :-------: | :------: |
|    low    | [4, 11]  |
|    mid    | [12, 16] |
|   high    | [17, 20] |
| blackjack |   [21]   |

두 장의 카드를 문자열 인자로 받는 `Blackjack.card_range` 메서드를 구현해요.
이 메서드는 두 카드가 속하는 값 범위의 이름을 반환해야 해요.

```Crystal
Blackjack.card_range("ten", "king")
# => "high"
```

## 3. 첫 턴의 결정 로직을 구현해요.

두 장의 카드와 딜러의 카드에 따라 게임 첫 턴의 전략이 있어요. 이때 선택할 수 있는 것은 다음과 같아요:

- 스탠드 (S)
- 히트 (H)
- 스플릿 (P)
- 자동 승리 (W)

아직 최적은 아니지만, 친구 Alex가 개발해 온 전략을 따라요. 그 전략은 다음과 같아요:

- 에이스 한 쌍을 가지고 있으면 항상 스플릿해야 해요.
- 블랙잭(두 카드의 합이 21인 경우)이고 딜러가 에이스, 그림 카드, 또는 10을 가지고 있지 않다면 자동으로 이겨요.
  딜러가 그런 카드 중 하나를 가지고 있다면 스탠드하고, 다른 카드가 공개되기를 기다려야 해요.
- 카드의 합이 [17, 20] 범위에 있으면 항상 스탠드해야 해요.
- 카드의 합이 [12, 16] 범위에 있으면 항상 스탠드해야 해요. 단, 딜러가 7 이상을 가지고 있다면 항상 히트해야 해요.
- 카드의 합이 11 이하이면 항상 히트해야 해요.

세 장의 카드를 문자열 인자로 받는 `Blackjack.first_turn` 메서드를 구현해요.
이 메서드는 해야 할 결정을 문자열로 반환해야 해요.

```Crystal
Blackjack.first_turn("ace", "ace", "two")
# => "P"
```
