# Alias

[특수 폼 `alias`][alias]를 사용하면 외부 모듈을 참조할 때 쓰는 이름을 줄이거나 바꿀 수 있어요. `:as` 옵션으로 원하는 이름을 지정할 수 있어요.

```elixir
defmodule Square do
  alias Integer, as: I

  def area(a), do: I.pow(a, 2)
end
```

인자 없이 사용하면 모듈 이름을 마지막 부분만 남기고 줄여줘요. 예를 들어

```elixir
alias MyApp.Account.User
# is the same as
alias MyApp.Account.User, as: User
```

여러 개의 별칭은 `{}`로 묶을 수 있어요:

```elixir
alias MyApp.Account.{User, EmailValidation}
# is the same as
alias MyApp.Account.User
alias MyApp.Account.EmailValidation
```

보통은 모듈 정의 맨 앞에 별칭을 추가하지만, 어디에든 추가할 수 있어요. 별칭은 렉시컬 스코프를 가지기 때문에, 함수 정의 안에서 추가한 별칭은 다른 함수에서는 사용할 수 없어요.

사용하지 않은 별칭은 컴파일러 경고를 발생시켜요.

[alias]: https://hexdocs.pm/elixir/Kernel.SpecialForms.html#alias/2
