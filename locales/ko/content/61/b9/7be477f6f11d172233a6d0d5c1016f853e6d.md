# Haskell의 내장 숫자 타입

## 숫자

Haskell의 표준 라이브러리인 ***Prelude***에는 대부분의 기본 숫자 타입이 정의되어 있어요. 크기가 고정된 정수(`Int`), 임의 정밀도 정수(`Integer`), 단정밀도 부동소수점(`Float`), 배정밀도 부동소수점(`Double`)이 그렇죠.
유리수나 복소수 같은 다른 숫자 타입은 추가 라이브러리에 정의되어 있어요.

`Integer`는 컴퓨터 메모리가 허용하는 한 아무리 큰 수라도 담을 수 있는 반면, `Int`는 32비트 또는 64비트로 표현할 수 있는 양의 정수와 음의 정수의 집합에 대응해요(최소 -2^29에서 2^29까지는 보장해요).

`Float`는 실수 집합에 대응하지만, 컴퓨터의 정밀도에 따라 한계가 있어요.
숫자에 정의된 연산은 보통 둘 중 한 타입에서만 동작하고, 두 타입 모두에서 동작하지는 않아요.

`Float`와 `Integer` 사이를 변환하는 함수로는 `Int`/`Integer`를 `Float`로 변환하는 `toFloat`, `Float`를 `Int`로 변환하는 `ceiling` 등이 있어요.

## 산술 연산자

Haskell에는 "거듭제곱" 연산자가 세 가지 있고, 각각 동작 방식과 받는 인자 타입이 달라요.

- `**`는 **부동소수점 수** 두 개를 받아 로그를 이용해 거듭제곱을 계산해요.
- `^^`는 **부동소수점 수**를 받아 이를 양수 또는 음수의 **정수** 거듭제곱으로 올려요.
- `^`는 **모든 숫자 타입**을 받아 **양의 정수** 거듭제곱으로 올려요.

정수 타입(`Int` 또는 `Integer`)에서 다른 숫자 타입으로 변환할 때는 `fromIntegral` 함수를 사용해요.
대상 타입은 자동으로 추론돼요.
예를 들어볼까요?

```haskell
n :: Integer
n = 6
x :: Float
x = fromIntegral n      --> x = 6.0

m :: Int
m = 7
y :: Double
y = fromIntegral m      --> y = 7.0
```

정수의 나눗셈은 조금 복잡해요.
정수에 일반적인 `/` 연산자를 사용하면 오류 메시지가 나타나요(다만 `4/3` 같은 표현은 동작하는데, Haskell이 필요할 때 정수 리터럴을 부동소수점으로 알아서 승격시켜 주기 때문이에요).
대신 정수 나눗셈은 이름이 붙은 연산자들을 사용해요.

Haskell에는 연산자와 관련된 멋진 요령이 있어요. 인자를 두 개 받는 함수라면 무엇이든 이름을 백틱으로 감싸서 연산자처럼 사용할 수 있죠.
그래서 다음 두 줄은 완전히 같은 의미예요.

```haskell
 d = 7 `div` 3
 d = div 7 3
```

이를 염두에 두고, 정수 나눗셈 연산자를 살펴봐요.

- `quot`: 두 수의 몫을 반환해요.
  나눗셈 결과를 0 방향으로 버린 값이에요.
- `rem`: 몫을 구하고 남은 나머지를 반환해요.
- `div`: `quot`와 비슷하지만, 음의 무한대 방향으로 내림해요.
- `mod`: 두 수의 모듈러스를 반환해요.
  `rem`과 비슷하지만, `div`가 음수를 반환할 때 규칙이 달라요.

인자를 두 개 받는 함수를 연산자로 바꿀 수 있는 것처럼, 연산자를 괄호로 감싸면 인자를 두 개 받는 함수로 바꿀 수 있어요.
그래서 다음 두 줄은 같은 의미예요.

```haskell
(+) 3 4
3 + 4
```
