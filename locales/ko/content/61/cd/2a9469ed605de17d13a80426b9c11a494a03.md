# 소개

[Nil][nil-dictionary]은 "아무것도 없음" 또는 "0"을 뜻하는 영어 단어예요.
Ruby에서 `nil`은 객체의 _부재_를 나타내는 데 사용해요.
다른 프로그래밍 언어에서는 `null`이나 `none` 값이 비슷한 역할을 하기도 해요.

```ruby
# I do not have a favorite color
favorite_color = nil
```

Ruby에서는 인스턴스 변수를 처음 만나면, 값을 따로 설정하기 전까지 기본값으로 `nil`을 지정해요.

[nil-dictionary]: https://www.merriam-webster.com/dictionary/nil
