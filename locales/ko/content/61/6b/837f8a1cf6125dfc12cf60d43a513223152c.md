# 개요

[구조체와 클래스 멤버의 종류][expression-bodied-members] 중 대부분은(필드가 주된 예외예요) 식 본문 멤버 구문을 사용할 수 있어요. 멤버를 식으로 정의하면 기존의 블록이나 문을 사용할 때보다 더 간결하고 읽기 쉬운 코드를 만들 수 있어요.

```csharp
public int Times3(int input) => input * 3;

public int Interesting => 1729;
```

식 본문 멤버에는 여러 문으로 이루어진 블록을 둘 수 없어요. 하지만 함수형 프로그래밍에 익숙한 사람이라면, 기존 멤버로 할 수 있는 일은 무엇이든 이 방식으로도 할 수 있다는 점을 알아 두세요. 여기서 "식"은 부수 효과를 만들어 내는 할당 연산일 수도 있고, 메서드 호출일 수도 있어요. 즉, 무엇이든 가능하다는 뜻이에요.
