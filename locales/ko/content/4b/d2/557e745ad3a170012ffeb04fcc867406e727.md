# 설치

## Windows 사용자

[Windows Subsystem for Linux][wsl-link]를 설치한 뒤 다음 섹션을 봐요.

## Linux/Mac 사용자

### brew로 설치하기

Chapel을 설치하는 가장 쉬운 방법이에요.
기본적으로 동작하는 설치 환경을 만들어 주고, Exercism 트랙을 진행하기에 적합해요.
더 능숙한 사용자라면 소스 코드에서 Chapel을 직접 빌드하고 싶을 수도 있어요(다음 섹션).

0. 아직 설치하지 않았다면 [brew][brew-link] 패키지 관리자를 설치해요.
1. 먼저 `brew update`를 실행해 brew가 최신 상태인지 확인해요.
2. `brew install chapel`을 실행해 Chapel을 설치해요.
3. `chpl --version`을 실행해 설치가 제대로 됐는지 확인해요.

이렇게 하면 chapel 컴파일러(`chpl`), 테스트를 실행할 때 사용할 패키지 관리자 `mason`, 그리고 문서 생성 도구 `chpldoc`이 설치돼요. `chpldoc`은 Exercism에는 필요 없지만, 언젠가( :) ) Chapel로 자신만의 라이브러리를 개발하고 싶을 때 있으면 좋아요.

### 소스 코드에서 Chapel 빌드하기

더 능숙한 사용자라면 Chapel을 소스 코드에서 직접 빌드하고 싶을 수도 있어요. 그러려면,

1. [사전 준비 사항][prereqs-link]을 설치해요.
2. 최신 Chapel 릴리스의 압축 파일을 [다운로드][download-link]해서 압축을 풀어요.
3. 먼저 Chapel을 설치할 위치를 준비하고 설정해야 해요.
이는 제공되는 `configure` 스크립트를 실행해 할 수 있어요.
간단히

```
./configure
```

를 실행하면 바이너리와 라이브러리, 공유 파일이 `/usr/local/`에 설치돼요. `--prefix` 옵션으로 이 위치를 바꿀 수 있어요.
예를 들어 chapel을 `~/.chapel`에 설치하고 싶다면 이렇게 하면 돼요.

```
./configure --prefix=~/.chapel
```

4. 컴파일러와 도구를 설치하려면 다음을 실행해요.

```
make
make mason
make chpldoc
make install
```

5. `/dir/for/install/bin` 폴더가 `PATH` 변수에 들어 있는지 확인해요.

Chapel을 설치하고 소스 코드에서 작업하는 여러 방법에 대한 더 자세한 내용은 문서의 [Chapel 빌드하기][building-link] 페이지를 참고해요.
