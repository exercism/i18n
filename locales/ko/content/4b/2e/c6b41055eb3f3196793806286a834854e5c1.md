# 커뮤니티 기여 일시 중지

일부 저장소에는 유지 관리자가 아닌 사용자가 올린 이슈나 풀 리퀘스트를 분류하거나 검토할 여력이 없어요.
커뮤니티 솔루션 일시 중지
저장소에서 이 워크플로를 활성화하면, 작성자가 Exercism의 GitHub 조직 구성원이 _아닐_ 경우 새로 열린 이슈나 풀 리퀘스트에 자동으로 댓글을 달아요.
댓글은 사용자에게 먼저 Exercism 포럼에 주제를 올려 보도록 안내해요.

## 워크플로 활성화하기

저장소에 [.github/workflows/pause-community-contributions.yml 파일](https://github.com/exercism/github-actions/blob/b5424c17f661f5529493258a1ad480013351aa9e/.github/workflows/pause-community-contributions.yml)을 추가해요.

## 워크플로 비활성화하기

저장소에서 워크플로 파일을 삭제해요.

## 출처

워크플로는 `.github/workflows/pause-community-contributions.yml` 파일에 정의되어 있어요.
