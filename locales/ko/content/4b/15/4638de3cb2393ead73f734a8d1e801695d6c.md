# 타입 변환 개요

Go는 서로 다른 타입 사이의 변환을 명시적으로 요구해요.
예를 들어, 다음 코드는 컴파일러 오류를 발생시켜요:

```go
var x int = 42
var f float64 = x // compiler error x is an int not a float64
```

타입 사이의 변환은(흔히 **타입 캐스팅**이라고도 해요) 변환하려는 타입의 이름을 가진 함수를 통해 이루어져요.
값 `v`는 `T(v)`를 사용해 타입 `T`로 변환해요.
예를 들어, `int`를 `float64`로 변환하려면 다음과 같이 하면 돼요:

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
```

직접 정의한 타입에도 똑같이 적용돼요:

```go
type Id int
var number int = 121 // number has type int
userId := Id(number) // userId now has type Id
```

## 기본 타입과 문자열 사이의 변환

기본 타입(`int` 등)과 `string` 사이를 변환하기 위한 `strconv` 패키지가 있어요.

```go
import "strconv"

var intString string = "42"
var i, err = strconv.Atoi(intString)

var number int = 12
var s string = strconv.Itoa(number)
```

경고: 표준 캐스팅 방식을 사용하면 이렇게 동작하지 않아요.
예를 들어:

```go
var num int = 65
str := string(num) // str is now "A" not "65"
```

다음은 그 밖의 흔한 변환 메서드예요:

| 메서드      | 용도                        |
| ----------- | --------------------------- |
| ParseBool   | `string`을 `bool`로 변환    |
| FormatBool  | `bool`을 `string`으로 변환  |
| ParseFloat  | `string`을 `float`로 변환   |
| FormatFloat | `float`을 `string`으로 변환 |
| ParseInt    | `string`을 `int`로 변환     |
| FormatInt   | `int`를 `string`으로 변환   |
