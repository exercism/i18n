# 소개

## 참과 거짓

Ruby에서 참과 거짓이라는 논리 상태는 `true`와 `false`로 나타내요.

```ruby
happy = true
sad = false
```

## 동등성과 비교

Ruby에서는 일반적인 동등 비교 기호를 사용해 객체끼리 서로 비교할 수 있어요:

- `==` 연산자로 두 객체가 같은지 확인해요
- `>` 연산자로 왼쪽 객체가 오른쪽 객체보다 **큰지** 확인해요
- `<` 연산자로 왼쪽 객체가 오른쪽 객체보다 **작은지** 확인해요.
- `>=` 또는 `<=` 연산자로 각각 "크거나 같음"과 "작거나 같음"을 검사해요.

일반적인 연산자로 불리언 논리를 사용할 수도 있어요:

- `&&` 또는 `and` 연산자로 `x and y`가 참인지 확인해요
- `||` 또는 `or` 연산자로 `x or y`가 참인지 확인해요.
- `!` 또는 `not` 연산자로 동등 여부를 반전할 수 있어요. 예를 들어 `x != y`는 x와 y가 서로 같지 않다는 뜻이에요.

몇 가지 예시를 볼까요?

```ruby
# Is "true equal to false"? 
true == false # false

# Is "true not equal to false"
true != false # true

# Is 5 greater than 4?
5 > 4 # true

# Is 3 less than or equal to 2?
3 <= 2 # false
```
