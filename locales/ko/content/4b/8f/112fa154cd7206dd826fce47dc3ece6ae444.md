# 알아보기

요소를 0개 이상 담을 수 있는 자료 구조를 _컬렉션_이라고 해요.
Ruby의 **배열**은 객체가 추가된 순서를 유지하는 컬렉션이에요.
배열에는 어떤 객체든 담을 수 있어요.
객체는 인덱스를 사용해 배열에 추가하거나 배열에서 꺼낼 수 있어요.
Ruby 배열의 인덱싱은 0부터 시작해요. 즉, 첫 번째 원소의 인덱스는 항상 0이에요:

```ruby
# Declare an array containing two values
two_ints = [1,2]

# Assign first and second element by index
two_ints[0] = 7
two_ints[1] = 8

# Retrieve the second element by index
two_ints[1] # => 8

# Check the length of the array
two_ints.size # => 2
```

Ruby에서 배열을 만드는 방법은 여러 가지가 있어요:

- 리터럴 생성자 `[]` 사용하기 _(가장 흔해요)_
- `Array.new`를 명시적으로 호출하기
- Kernel `Array()` 메서드를 호출하기

`Array.new` 메서드는 두 개의 선택적 인자를 지원해요: 배열의 초기 크기와 기본 객체예요.

크기와 기본 객체가 주어지면, 배열은 기본 객체의 복사본 `size`개로 채워져요.

```ruby
a = Array.new(2, Hash.new)
# => [{}, {}]
```

모든 배열 원소가 같은 해시를 저장하므로, 그중 하나를 변경하면 모두에 영향을 줘요.

```ruby
a[0]['cat'] = 'feline'
a # => [{"cat"=>"feline"}, {"cat"=>"feline"}]

a[1]['cat'] = 'Felix'
a # => [{"cat"=>"Felix"}, {"cat"=>"Felix"}]
```

여러 개의 복사본이 필요하다면, 배열의 원소를 초기화해야 할 때마다 그 블록의 결과를 사용하는 블록 버전을 사용해야 해요:

```ruby
a = Array.new(2) {Hash.new}
a[0]['cat'] = 'feline'
a # => [{"cat"=>"feline"}, {}]
```

Ruby 배열의 또 다른 특징은 [Enumerable][enumerable-module] 모듈이 믹스인되어 있다는 점이에요. 이 모듈은 배열의 원소를 반복, 검색, 정렬, 필터링하는 등 유용한 메서드를 많이 추가해 줘요.
