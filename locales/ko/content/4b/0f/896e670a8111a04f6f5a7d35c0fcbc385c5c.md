# 추가 지침

## Python 관련 특별 지침

이 연습 문제에는 서드파티 라이브러리가 **필요하지 않아요**. **FRP 라이브러리**에 관한 지침은 무시해 주세요.


## 예외 메시지

때로는 [예외를 발생시켜야](https://docs.python.org/3/tutorial/errors.html#raising-exceptions) 할 때가 있어요. 이럴 때는 오류의 원인이 무엇인지 알려 주는 **의미 있는 오류 메시지**를 항상 포함해야 해요. 그래야 코드를 더 읽기 쉽게 만들고 디버깅에도 큰 도움이 돼요. 오류 원인이 특정 유형일 것이라고 알고 있는 상황이라면 [내장 오류 유형](https://docs.python.org/3/library/exceptions.html#base-classes) 중 하나를 발생시켜도 되지만, 그때도 의미 있는 메시지는 꼭 포함해야 해요.

이 연습 문제에서는 게임이 끝났는데도 플레이어가 계속 플레이하려고 할 때 `ValueError`를 "던지기" 위해 [raise 문](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)을 사용해야 해요. 테스트를 통과하려면 `exception`을 `raise`하고 메시지도 함께 넣어야 해요.

메시지와 함께 `ValueError`를 발생시키려면, `exception` 타입에 인자로 메시지를 써 주세요.

```python
# when player tries to play, but the game is already over.
raise ValueError("The game has already ended.")
```
