# 안내

빈 버퍼를 초기화하고 피보나치 수열의 처음 다섯 숫자, 즉 원소를 나열해 볼 거예요.

피보나치 수열은 다음 원소가 앞의 두 원소를 더한 값이 되는 수열이에요. 수열은 1부터 시작해요. 그래서 처음 두 원소는 1과 1이에요.

## 1. `count`개의 0으로 채워진 버퍼 만들기

`count`개의 0으로 채워진 버퍼를 만드는 함수를 작성해요.

```rust
let my_buffer = create_buffer(5);
// [0, 0, 0, 0, 0]
```

## 2. 피보나치 수열의 처음 다섯 원소 나열하기

피보나치 수열의 처음 다섯 숫자를 반환하는 함수를 작성해요. 처음 다섯 원소는 `1, 1, 2, 3, 5`예요.

```rust
let first_five = fibonacci();
// [1, 1, 2, 3, 5]
```
