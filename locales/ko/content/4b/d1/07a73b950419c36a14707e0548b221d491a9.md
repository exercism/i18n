# 개요

PHP는 산술 연산을 수행하기 위한 여러 연산자를 제공해요. PHP는 산술 연산자에 대해 수학의 표준 연산 순서를 따라요. PHP가 제공하는 연산자는 다음과 같아요:

* 항등 (+)
* 부호 반전 (-)
* 덧셈 (+)
* 뺄셈 (-)
* 곱셈 (*)
* 나눗셈 (/)
* 나머지 (%)
* 거듭제곱 (**)

각 연산자와 그 활용법을 하나씩 살펴봐요:

## 항등 (+)

항등 연산자(+)는 하나의 값에 작용해요(단항 연산자). 변수의 `float` 또는 `int` 값으로 평가돼요.

```php
$value = '42';
$answer = +$value; // 42 (int)
```

## 부호 반전 (-)

부호 반전 연산자는 하나의 값에 작용하고(단항 연산자), 숫자 값의 반대 부호를 반환해요.

```php
$forward = 65;
$reverse = -$forward; // -65
```

## 덧셈 (+)과 뺄셈 (-)

덧셈 연산자는 양쪽의 두 값을 더하고, 뺄셈 연산자는 왼쪽 값에서 오른쪽 값을 빼요.

```php
$apples = 5;
$yourApples = 0;

$apples = $apples - 2; // 3
$yourApples = $yourApples + 2; 2
```

## 나눗셈 (/)

나눗셈 연산자는 왼쪽 값을 오른쪽 값으로 나눈 결과를 줘요. 오른쪽 값이 0이면 `DivisionByZeroError` 오류가 발생해요.

```php
$slicesOfPizza = 8;
$people = 4;
$slicesPerPerson = $slicesOfPizza / $people; // 2
```

## 곱셈 (*)

곱셈 연산자는 왼쪽 값과 오른쪽 값을 곱한 결과를 반환해요.

```php
$tires = 4;
$priceOfTire = 250;
$totalCost = $tires * $priceOfTire; // 1000
```

## 나머지 (%)

나머지 연산자는 왼쪽 값을 오른쪽 값으로 나눴을 때의 나머지를 반환해요. 이 연산자는 어떤 수가 다른 수로 나누어떨어지는지, 값이 짝수인지 홀수인지 등을 판별할 때 아주 유용해요.

```php
$value = 3;
$isOdd = $value % 2;
if ($isOdd === 1) {
    echo 'Yes, it is odd!';
} else {
    echo 'It is even.';
}
```

## 거듭제곱 (**)

거듭제곱 연산자는 왼쪽 값을 오른쪽 값만큼 거듭제곱할 때 사용해요. PHP 5.6 이전에는 같은 일을 하려면 `pow` 함수를 사용해야 했어요.

```php
$sideLength = 13;
$areaOfSquare = $sideLength ** 2; // 169
```

거듭제곱 연산자는 양쪽 모두 정수와 실수를 지원하므로, 제곱근(또는 다른 거듭제곱근)이나 더 복잡한 지수 값을 계산하는 데 사용할 수 있어요.

```php
$squareArea = 144;
$side = $squareArea ** .5; // 12
```

## 연산 순서

PHP는 수학의 표준 연산 순서를 따라요. 즉, 연산을 왼쪽에서 오른쪽으로 수행하는 것이 아니라, 각 연산자에 우선순위가 있어서 그 우선순위에 따라 연산이 처리돼요. 연산 순서는 다음과 같아요:

* 괄호
* 거듭제곱
* 곱셈, 나눗셈
* 덧셈, 뺄셈

곱셈과 나눗셈은 서로 같은 우선순위예요. 마찬가지로 덧셈과 뺄셈도 같은 우선순위예요.

곱셈이 덧셈보다 우선순위가 높기 때문에, 아래 값은 10이 아니라 17이 돼요:

```php
$value = 2 + 3 * 5;
```

PHP는 또한 변수에 연산을 수행한 결과를 다시 그 변수에 대입할 때, 산술 연산자와 대입을 결합한 여러 유용한 대입 연산자를 제공해요. 이는 `Assignment Operators` 개념에서 다뤄요.
