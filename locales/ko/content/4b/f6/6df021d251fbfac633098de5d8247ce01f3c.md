# 가변 매개변수

Swift의 [_가변 매개변수_][variadic-parameters]를 사용하면 같은 타입의 값을 0개 이상 하나의 매개변수로 함수에 전달할 수 있어요.
이는 매개변수의 타입 표기 뒤에 `...`을 붙여 나타내요.

이 값들은 가변 매개변수의 타입과 같은 타입의 원소를 가진 배열로 자동으로 묶여요.

```swift
func geometricMean(_ numbers: Double...) -> Double {
  var total = 1.0
  for number in numbers {
      total *= number
  }
  return pow(total, 1.0 / Double(numbers.count))
}

geometricMean(1, 2, 3, 4, 5)
// Returns 2.605171084697352
```

가변 매개변수를 사용할 때 Swift에는 두 가지 제한이 있어요:

1. Swift에서는 함수가 가변 매개변수를 하나만 가질 수 있어요. 이 제한은 Swift의 향후 릴리스에서 제거하기로 결정되었지만, 현재로서는 아직 그대로 남아 있어요.
2. 함수 정의에서 가변 매개변수 뒤에 오는 매개변수가 있다면, 가변 매개변수 다음에 오는 첫 번째 매개변수는 인자 레이블을 _반드시_ 가져야 해요.

[variadic-parameters]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/functions/#Variadic-Parameters
