# 소개

## Julia의 불리언

참과 거짓 값은 `Bool` 타입으로 나타내요.
`Bool` 타입에는 `true`와 `false`, 두 가지 값만 들어 있어요.

```julia-repl
julia> true
true

julia> false
false
```

## 불리언 연산자

Julia에는 세 가지 불리언 연산자가 있어요.

`&&`는 불리언 "and" 연산자예요.
`&&`의 *양쪽* 표현식이 모두 `true`일 때 `true`로 평가돼요.

```julia-repl
julia> true && true
true

julia> true && false
false
```

`||`는 불리언 "or" 연산자예요.
`||`의 *어느 한쪽* 표현식이 `true`일 때 `true`로 평가돼요.

```julia-repl
julia> true || true
true

julia> false || true
true
```

`!`는 불리언 "not" 연산자예요.
`true`와 `false` 값을 서로 바꿔요.

```julia-repl
julia> !true
false

julia> !false
true
```

표현식이 길고 복잡할수록 괄호를 사용해서 의도를 분명히 밝히는 게 좋아요.

```julia-repl
julia> (true || false) && (false && true)
false
```
