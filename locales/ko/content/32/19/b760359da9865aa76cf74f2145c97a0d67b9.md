# 소개

R의 `list`는 항목을 순서대로 담는 모음이에요. `vectors`와는 몇 가지 면에서 달라요:

- 항목은 서로 다른 타입일 수 있어요(예: `numeric`과 `character`를 섞는 것).
- 항목은 복잡한 구조일 수 있어요(예: 벡터, 다른 배열 등).
- 원소에 접근하는 문법이 조금 달라요.

다른 언어와의 비유는 정확하지 않아요.
R의 `list`는 Python 딕셔너리와 어느 정도 비슷하지만, `list`는 순서가 있고 숫자 인덱스로 접근할 수 있어요.
C의 `struct`와도 어느 정도 비슷하지만, `list`는 실행 중에 쉽게 확장할 수 있어요.

## 배열 만들기

원소에 이름을 붙이는 것(종종 "태그"라고 불러요)은 벡터보다 배열에서 더 흔해요:

```R
list(x = 5.3, y = 4.2, color = "blue")
$x
#> [1] 5.3

$y
#> [1] 4.2

$color
#> [1] "blue"
```

하지만 태그는 선택 사항이고, 그러면 R은 그냥 인덱스 번호를 사용해요:

```R
list(5.3, 4.2, "blue")
#> [[1]]
#> [1] 5.3

#> [[2]]
#> [1] 4.2

#> [[3]]
#> [1] "blue"
```

## 배열 원소에 접근하기

이를 하는 방법에는 세 가지가 있고, 각각 다른 상황에서 유용해요.

### 1. `$tag` 표기법 사용하기

태그 이름을 미리 알고 있다면 아주 흔히 써요.

```R
point <- list(x = 5.3, y = 4.2, color = "blue")
point$x
#> [1] 5.3
point$color
#> [1] "blue"
```

### 2. `[[tag]]` 표기법 사용하기

이 방법은 태그 이름을 실행 중에 정할 수 있다는 장점이 있어요.
대괄호가 두 개라는 점에 주목해요.

```R
want <- "y"
point[[want]] # same as point$y
#> [1] 4.2
```

### 3. 위치 인덱스 사용하기

이 방법은 배열에 태그가 있든 없든 작동해요.
여기서도 대괄호가 두 개예요.

```R
point[[3]] # same as point$color
#> [1] "blue"
```

## 원소 추가 및 삭제

간단해요: 원소에 값을 할당하면, 이미 있으면 수정하고 새로우면 추가해요.

```R
point$color <- "red"
point$trust <- TRUE
str(point)
#> List of 4
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
#>  $ trust: logi TRUE
```

삭제하려면, 원하지 않는 원소에 `NULL`을 할당해요.

```R
point$trust <- NULL
str(point)
#> List of 3
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
```
