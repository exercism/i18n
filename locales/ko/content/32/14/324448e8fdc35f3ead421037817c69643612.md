# 지침

친구들과 게임의 밤을 계획하다가, 일행은 어린 시절 즐겨 하던 게임을 다시 꺼내 놀기로 했어요. 독일 친구가 _Mensch ärgere Dich nicht_(_사람아, 화내지 마_)를 제안했는데, 이 게임은 많은 유럽 국가에서 고전으로 통하며 영어권의 _Ludo_나 북미의 _Parcheesi_와 비슷해요.

게임을 준비하려고 Elixir로 주사위를 굴리는 함수를 구현하기로 했어요.

_Mensch ärgere Dich nicht_에서는 플레이어가 6면체 주사위 하나를 굴려서 다음 이동을 정해요. 운이 좋아서 6이 나오면, 한 번 더 굴리고 이동할 수 있어요.

## 1. 6면체 주사위를 한 번 굴하기

`d6/0` 함수를 구현해요. 이 함수는 호출할 때마다 1과 6 사이의 정수 하나를 무작위로 골라요.

```elixir
MenschAergereDichNicht.d6()
# => 1
MenschAergereDichNicht.d6()
# => 5
```

## 2. 6이 나오는 동안 계속 굴하기

`roll/0` 함수를 구현해요. 이 함수는 주사위를 굴린 결과의 스트림을 반환해야 해요. 주사위 굴리기는 게임 규칙을 따라야 해요. 6이 나오면 다시 굴릴 수 있어요. 그렇지 않으면 굴리기를 멈춰요. 앞 단계에서 정의한 `d6/0` 함수를 사용해요.

```elixir
MenschAergereDichNicht.roll() |> Enum.to_list()
# => [5]
MenschAergereDichNicht.roll() |> Enum.to_list()
# => [6, 3]
```

## 3. 조작된 주사위를 사용할 수 있게 하기

코드를 더 쉽게 테스트할 수 있도록, 조작된 주사위를 사용할 수 있게 해요.

`roll/0` 함수를 확장해요. 이 함수는 선택적 인자, 즉 함수 하나를 받아야 해요. 인자가 전달되면, 그 함수를 사용해서 주사위를 굴려요. 그렇지 않으면 `MenschAergereDichNicht.d6/0`을 대신 사용해요.

```elixir
MenschAergereDichNicht.roll(fn -> 3 end) |> Enum.to_list()
# => [3]
```
