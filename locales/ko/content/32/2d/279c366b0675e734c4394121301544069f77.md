# 소개

때로는 상태를 가진 객체를 만들어야 하는 부담이 필요하지 않을 때도 있어요.
그럴 때는 `module`을 사용할 수 있어요.

모듈은 클래스와 아주 비슷해요. 실제로 객체 계층 구조에서 `Module`은 `Class`의 조상이에요. 가장 큰 차이는 인스턴스 메서드가 아니라 클래스 메서드를 사용한다는 점이에요.
클래스 메서드는 `self.`로 시작하고, 모듈에서 직접 호출해요.

예를 들어:

```ruby
module Speaker
  def self.echo(something)
    "#{something} ... #{something}"
  end
end

Speaker.echo("Hello")   #=> "Hello ... Hello"
```
