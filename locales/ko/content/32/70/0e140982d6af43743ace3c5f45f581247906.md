# 개요

Haskell 함수를 작성할 때 [패턴 매칭][pattern-matching]을 활용할 수 있어요.
패턴 매칭은 데이터 생성자와 매칭하고 그 안의 값에 변수를 바인딩할 수 있게 해주는, Haskell의 아주 강력한 기능이에요.
이름에서 알 수 있듯이 우리가 하는 일은 값을 패턴에 맞춰 보는 것이고, 값이 패턴과 일치하면 그 패턴 안의 값에 변수를 바인딩할 수 있어요.
패턴 매칭은 주로 값 알아보기, 변수 바인딩하기, 값 분해하기라는 개념으로 이루어져 있어요.

~~~~exercism/note
Elixir 같은 언어의 패턴 매칭은 Haskell의 패턴 매칭과 조금 달라요.
예를 들어 Elixir는 하나의 패턴 안에 같은 바인딩 이름을 여러 번 쓸 수 있지만, Haskell은 그렇지 않아요.
~~~~


예를 들어 이런 함수를 봐요:

```haskell
lucky :: Int -> String
lucky 7 = "Lucky number seven!"
lucky x = "Sorry, you're out of luck, pal!"
```

여기 `Int`를 받아 `String`을 반환하는 함수 `lucky`가 있어요.
이 함수에는 두 개의 패턴을 정의했는데, 하나는 숫자 `7`과 일치하고 다른 하나는 그 밖의 어떤 숫자와도 일치해요. 이름은 (Haskell 작명 관례만 따르면) 무엇이든 괜찮지만 여기서는 `x`를 썼어요.
숫자가 `7`이면 함수는 `"Lucky number seven!"`을 반환하고, 그렇지 않으면 `"Sorry, you're out of luck, pal!"`을 반환해요.
여기서 중요한 점은 패턴을 위에서 아래로 검사한다는 거예요. 그래서 패턴의 순서를 바꿨다면 함수는 항상 `"Lucky number seven!"`을 반환했을 거예요.

## 배열 패턴

아주 흔한 패턴 중 하나는 배열을 매칭하는 것, 그러니까 배열의 head와 tail을 취하는 것이에요.
이는 배열이 본질적으로 서로 연결된 구조이기 때문이에요.
다음은 배열의 head와 tail을 반환하는 함수의 예예요:

```haskell
headAndTail :: [Int] -> (Int, [Int])
headAndTail [] = error "Can't call head on an empty list"
headAndTail (x:xs) = (x, xs)
```

여기에는 두 개의 패턴이 있는데, 하나는 빈 배열과 일치하고 다른 하나는 요소가 최소한 하나 있는 배열과 일치해요.
빈 배열인 경우를 처리하는 패턴이 없으면 런타임 오류가 발생하기 때문이에요.
배열이 비어 있지 않다면 배열의 head를 `x`에, tail을 `xs`에 매칭할 수 있어요.
이것은 배열 맨 앞에 요소를 추가할 때 쓰는 `:` (cons) 연산자를 이용해요.
그런데 패턴 매칭에서는 배열을 head와 tail로 분해할 수 있게 해주니, 어떤 의미에서는 반대의 일을 하는 셈이에요.

`xs`는 배열의 tail에 흔히 쓰는 이름으로, 이것이 배열이라는 점을 드러내요. 중첩된 배열을 다룬다면 `xss`를 써서 배열의 배열이라는 점을 드러낼 수 있어요.

## 튜플 패턴

배열과 마찬가지로 튜플도 매칭할 수 있어요.
다음은 튜플을 받아 첫 번째와 두 번째 요소를 반환하는 함수의 예예요:

```haskell
sumTuple :: (Int, Int) -> Int
sumTuple (x, y) = x + y
```

여기서는 요소가 두 개인 튜플과 일치하는 패턴을 썼고, 첫 번째 요소는 `x`에, 두 번째 요소는 `y`에 바인딩돼요.

## 와일드카드 패턴

어떤 변수의 값에는 관심이 없고 그저 패턴에만 일치시키고 싶을 때가 있어요.
이럴 때 와일드카드 패턴을 써요. 밑줄 `_`로 나타내요.

다음은 배열의 첫 번째 요소를 반환하는 함수의 예예요:

```haskell
head' :: [Int] -> Int
head' [] = error "Can't call head on an empty list"
head' (x:_) = x
```

여기서는 배열의 tail이 필요 없다는 뜻으로, 와일드카드 패턴을 써서 무시해요.

## 타입 패턴

타입에 대해서도 매칭할 수 있는데, 이는 해당 타입의 생성자를 사용해서 해요.
튜플에서 그랬던 것처럼 타입에서 값을 꺼낼 수도 있어요.

```haskell
data AccountType = Guest | User String 

greet :: AccountType -> String
greet Guest = "Welcome, guest!"
greet (User name) = "Welcome, " ++ name ++ "!"
```

첫 번째 패턴에서는 `Guest` 생성자와 일치시키고, 두 번째 패턴에서는 `User` 생성자와 일치시키면서 그 안의 값을 `name`에 바인딩해요.
