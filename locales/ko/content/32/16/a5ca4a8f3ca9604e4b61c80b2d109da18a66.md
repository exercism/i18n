# 힌트

## 일반

- 계약은 반환 타입 뒤, `is` 앞에 와요:

  ```sather
     spare_capacity(load : INT) : INT
        pre load >= 0
     is
        ...
     end;
  ```

- 계약 안에서는 인자와 객체의 속성을 사용할 수 있어요. 그래서 `limit`도 쓸 수 있죠.
- 테스트는 `-chk` 없이 빌드되기 때문에, 계약을 잘못 써도 테스트는 실패하지 않아요. 계약은 읽는 사람을 위해 작성해요.

## 1. 하네스 구성하기

- `create`에 `pre kg > 0`을 붙여요.
- 본문은 평소처럼 `new`로 만들고, 속성을 설정한 뒤 반환해요.

## 2. 여유 공간은 얼마나 될까요?

- `and`로 연결한 두 조건이에요: `pre load >= 0 and load <= limit`.
- `post result >= 0`. 이건 `pre`에서 따라 나오는 거라서 말해 둘 가치가 있어요. 답을 믿을 수 있는 근거를 기록해 두는 거죠.

## 3. 얼마나 찼을까요?

- `pre load >= 0` 그리고 `post result >= 0`.
- `load * 100 / limit`, 이 순서대로요. 나눗셈을 먼저 하면 값이 전부 날아가 버려요. `tuning-the-strings`에서도 마찬가지고요.

## 4. 안전할까요?

- `pre`가 전혀 없어요. 어떤 하중이든 물어볼 수 있다는 게 핵심이거든요.
- `post`는 질문을 다시 표현한 거예요: `post result = (load <= limit)`. `=`가 서로 다른 두 가지 의미로 두 번 쓰이기 때문에 괄호를 써요.
