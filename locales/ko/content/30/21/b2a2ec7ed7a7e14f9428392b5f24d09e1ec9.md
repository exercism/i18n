# 지침

이 연습 문제에서는 좋아하는 요리책에 나온 근사한 라자냐를 만들 수 있도록 도와주는 코드를 작성해볼 거예요.

라자냐를 조리하는 데 걸리는 시간과 관련된 세 가지 과제가 있어요.

## 1. 오븐에 있어야 하는 예상 시간을 분 단위로 정의하기

`expectedMinutesInOven` 값을 정의해서 라자냐가 오븐에 몇 분 있어야 하는지 확인해요. 요리책에 따르면, 오븐에 있어야 하는 예상 시간은 40분이에요:

```
> expectedMinutesInOven
  ⧩
  40
```

## 2. 준비 시간을 분 단위로 계산하기

`preparationTimeInMinutes` 함수를 정의해요. 이 함수는 라자냐에 추가한 층 수를 매개변수로 받아요. 각 층을 준비하는 데 2분이 걸린다고 가정했을 때, 라자냐를 준비하는 데 몇 분을 썼는지 반환해요.

```
> preparationTimeInMinutes 3
  ⧩
  6
```

## 3. 경과 시간을 분 단위로 계산하기

`elapsedTimeInMinutes` 함수를 정의해요. 이 함수는 매개변수 두 개를 받아요. 첫 번째 매개변수는 라자냐에 추가한 층 수이고, 두 번째 매개변수는 라자냐가 오븐에 있던 시간(분)이에요. 이 함수는 라자냐 요리에 몇 분을 썼는지 반환해야 해요. 이 값은 준비 시간(분)과 현재 라자냐가 오븐에 있던 시간(분)을 더한 값이에요.

```
> elapsedTimeInMinutes 3 20
  ⧩
  26
```
