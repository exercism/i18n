# 지침 추가

## 지뢰밭 형식

지뢰밭은 null로 끝나는 문자열로 표현되며, 각 행의 끝에는 줄바꿈 문자가 있어요.

예를 들어 `"   \n * \n   \n"`와 같아요.

## 레지스터

| 레지스터 | 용도      | 타입    | 설명                      |
| -------- | --------- | ------- | ------------------------- |
| `$a0`    | 입력      | 주소    | null로 끝나는 입력 문자열 |
| `$a1`    | 입력/출력 | 주소    | null로 끝나는 출력 문자열 |
| `$t0-9`  | 임시      | 아무 타입 | 임시 저장용             |
