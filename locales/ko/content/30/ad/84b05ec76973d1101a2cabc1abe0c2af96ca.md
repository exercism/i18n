# 소개

Elm 같은 순수 함수형 언어에서는 같은 인자로 호출한 함수가 언제나 같은 값을 반환해야 해요.
그래서 타입 시그니처가 `rand : Int`인 함수는 `rand = 4`로만 구현할 수 있는데, 이걸로 무작위 정수를 만들어내기는 어렵겠죠.

그럼 Elm에서는 어떻게 무작위 값을 생성할까요?
문제를 둘로 나눠요. 먼저 `Random.Generator a`로 생성하려는 값을 표현하고, 그다음에 실제로 값을 생성해요.

값을 생성하는 첫 번째 방법은 `initialSeed : Int -> Seed`로 `Random.Seed`를 만들고, 그다음 `step : Generator a -> Seed -> ( a, Seed )`를 사용하는 거예요.
`step`은 값 하나와 새 시드를 반환해요.
이 두 함수는 모두 순수하다는 점을 기억해요. 그래서 같은 인자로 두 번 호출하면 같은 값이 나와요.

값을 생성하는 두 번째 방법은 `generate : (a -> msg) -> Generator a -> Cmd msg`를 사용하는 건데, 이건 Elm 애플리케이션 안에서만 할 수 있어요.
이때 Elm 런타임은 시드를 만들기 위해 `step`뿐만 아니라 외부의 순수하지 않은 자원도 사용할 수 있어요.

이제부터는 생성기에 집중해볼게요.

예제를 보여주기 위해, `initialSeed`와 `step`으로 생성기에서 여러 값을 만들어내는 함수 `generate : Int -> Generator a -> List a`를 정의했다고 가정해볼게요.

`Random` 모듈은 특정 범위 안의 정수와 실수를 생성하는 두 가지 기본 생성기를 제공해요:

```elm
generate 5 (Random.int -5 5)
    --> [0, 3, -5, 5, 0]

generate 3 (Random.float 0 5)
    --> [1.61803, 3.14159, 2.71828]
```

그 값들은 튜플로 묶거나, 값의 배열로 묶을 수 있어요:

```elm
generate 2 (Random.list 3 (Random.int 0 3))
    --> [[0, 3, 3], [1, 3, 2]]

generate 2 (Random.pair (Random.int 0 3) (Random.float 10 10.3))
    --> [(0, 10.23412), (2, 10.17094)]
```

`elm-community/random-extra` 패키지는 문자열, 날짜, 딕셔너리, 배열, 집합 등 다양한 자료 구조를 위한 훨씬 많은 생성기를 제공해요.

`Random.constant`를 사용하면 항상 값 하나만 반환하는 생성기를 만들 수 있어요:

```elm
generate 4 (Random.constant "hello")
    --> ["hello", "hello", "hello", "hello"]
```

`Random.uniform`을 사용하면 주어진 원소들 중에서 같은 확률로 무작위로 하나를 고를 수 있어요:

```elm
generate 5 (Random.uniform Red [Green, Blue])
    --> [Red, Blue, Blue, Green, Red]
```

`Random.uniform`은 고를 값이 적어도 하나는 있도록 인자 두 개(`Red`와 `[Green, Blue]`)를 받아요. 배열 하나만 받으면 비어 있을 수도 있으니까요.

`Random.weighted`로 확률을 조정할 수도 있어요:

```elm
generate 5 (Random.weighted (80, Red) [(15, Green), (5, Blue)])
    --> [Red, Red, Green, Red, Red]
```

값들이 꼭 100이 될 필요는 없어요. 어차피 다시 정규화되거든요.

`Random.map`을 사용하면 생성기 안쪽까지 들어갈 수 있어요:

```elm
generate 3 (Random.int 1 6 |> Random.map (\n -> n * 10))
    --> [30, 60, 10]
```

`Random.map2`부터 `Random.map5`까지 사용해서 생성기를 더 많이 조합할 수도 있어요:

```elm
position =
    Random.map3
      (\x y z -> Position x y z)
      (Random.float -100 100)
      (Random.float -100 100)
      (Random.float -100 100)

generate 1 position
    --> [Position 33.788 -98.321 10.0845]
```

더 복잡한 용도로는 `Random.andThen : (a -> Generator b) -> Generator a -> Generator b`가 있어요. 한 생성기가 만들어낸 값을 이용해 다른 생성기를 만들 수 있죠:

```elm
bool = Random.uniform True [False]

failHalfOfTheTime : Generator a -> Generator (Maybe a)
failHalfOfTheTime generator =
    bool
        |> Random.andThen
            (\boolResult ->
                if boolResult then
                    Random.map Just generator

                else
                    Random.constant Nothing
            )

generate 6 (Random.int 0 1 |> failHalfOfTheTime)
    --> [Nothing, Just 1, Just 0, Nothing, Just 1, Nothing]
```

생성기를 자기 재귀적으로 정의하는 게 유용할 때가 있어요.
그럴 때는 컴파일러가 생성기를 끝없이 펼쳐놓지 않도록 `Random.lazy`를 사용해야 할 수도 있어요.

```elm
type Peano
    = Zero
    | Next Peano


peano : Generator Peano
peano =
    Random.uniform (Random.constant Zero)
        [ Random.map Next (Random.lazy (\_ -> peano))
        ]
        |> Random.andThen identity

generate 12 peano
    --> [Zero, Next(Next(Zero)), Zero, Next(Zero), Zero, Zero, Next(Zero), Zero, Zero, Next(Zero), Next(Next(Next(Zero)))]
```

이 예제는 조금 복잡하니 하나씩 뜯어볼게요.

`Peano`는 양의 정수를 표현하는 타입이에요. `Zero`는 0, `Next(Zero)`는 1, `Next(Next(Zero))`는 2, 이런 식이죠.
`peano`는 무작위 `Peano` 숫자를 만들어 주도록 정의했어요.

먼저 `Random.lazy`는 로직에 뭔가를 더하는 게 아니라는 점을 기억해요. 그저 컴파일러가 `peano`를 `peano` 안에 끝없이 써 넣는 것을 막아줄 뿐이에요.

`Random.uniform`을 사용해 0(50% 확률)과 또 다른 `Peano` 숫자에 1을 더한 값(50% 확률) 중에서 고르고 있어요.
그런데 앞의 예제와 달리, `Random.uniform`은 값(`Zero` 같은)이 아니라 생성기(`Random.constant Zero` 같은) 중에서 고르고 있어요. `peano` 자체를 사용하고 싶기 때문이죠.
이 말은 `Random.uniform`이 `Generator (Generator Peano)` 타입의 값을 반환한다는 뜻인데, 이건 우리에게 필요한 게 아니에요.

생성기를 "평평하게" 만들기 위해, 이걸 `Random.andThen : (a -> Generator b) -> Generator a -> Generator b`로 넘겨요. 여기서 `b`는 `Peano`가 되길 원하죠.
`Generator a`가 `Generator (Generator Peano)`이므로 `a`는 `Generator Peano`여야 하고, 함수 `(a -> Generator b)`는 `(Generator Peano -> Generator Peano)` 타입이어야 해요.
아무것도 바꾸고 싶지 않으니 `identity`가 딱 맞는 선택이에요.

마지막으로, `peano`는 어떤 숫자들을 만들어낼까요?
50%의 확률로 0을 만들거나, 50%의 확률로 자기 자신을 한 번 더 반복한 값에 1을 더한 값을 만들어낸다는 걸 알 수 있어요.
즉, 숫자는 0(50%), 1(25%), 2(12%), 3(6%) 등이 나와요.
`peano`는 얼마든지 큰 숫자를 만들어낼 수 있지만, 확률은 지수적으로 줄어들어요.
