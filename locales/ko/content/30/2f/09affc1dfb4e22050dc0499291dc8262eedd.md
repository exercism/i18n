# 개요

`assocs`는 하나의 데이터 타입이 아니라 [프로토콜][assoc-protocol]이에요. 해시 테이블(`H{ }`), 연관 리스트(`{ key value }` 쌍의 시퀀스), 트리 맵이 모두 이 프로토콜을 구현해요. 그리고 assocs에 있는 대부분의 워드는 이들 사이에서 서로 바꿔 쓸 수 있어요.

```factor
USING: assocs ;

H{ } clone "coal" over inc-at
"coal" over inc-at
"wood" over inc-at      ! => H{ { "coal" 2 } { "wood" 1 } }
```

제공하는 워드의 범위는 넓어요. 정렬된 순회, 매핑, 필터링 등이 모두 있지만, 연습 문제 수준에서는 자주 쓰는 몇 개만 알면 충분해요.

| 워드        | 스택 효과                                     |
|-------------|-----------------------------------------------|
| `at`        | `( key assoc -- value/f )`                    |
| `at*`       | `( key assoc -- value ? )`, f를 값으로 쓸 때와 키가 없을 때를 구분해요 |
| `key?`      | `( key assoc -- ? )`                          |
| `set-at`    | `( value key assoc -- )`, 값을 변경해요        |
| `change-at` | `( key assoc quot -- )`, `quot`는 `( old -- new )`예요 |
| `inc-at`    | `( key assoc -- )`, `+1`을 하고, 키가 없으면 `1`을 넣어요 |
| `delete-at` | `( key assoc -- )`, 값을 변경해요              |
| `>alist`    | `( assoc -- pairs )`                          |

`sort-keys`와 `sort-values`(`sorting`에 있어요)는 연관 리스트를 선택한 필드 기준으로 정렬해요.

[assoc-protocol]: https://docs.factorcode.org/content/article-assocs-protocol.html
