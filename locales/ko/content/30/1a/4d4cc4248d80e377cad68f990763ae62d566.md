# 소개

개체 이니셜라이저는 생성자를 대신하는 방법이에요. 구문은 필드 이름=값 쌍을 쉼표로 구분한 목록이며, 아래에 예시가 있어요:

```csharp
public class Person
{
    public string Name;
    public string Address;
}

var person = new Person{Name="The President", Address = "Élysée Palace"};
```

컬렉션도 같은 방식으로 초기화할 수 있어요. 일반적으로 아래처럼 쉼표로 구분한 목록을 사용해요:

```csharp
IList<Person> people = new List<Person>{ new Person(), new Person{Name="Joe Shmo"}};
```

이 방식(과 구문)은 `IEnumerable`을 구현하고 `Add()` 메서드를 가진 모든 클래스에 사용할 수 있어요.

필드는 순서에 관계없이 나열할 수 있고, 아예 생략할 수도 있어요.

딕셔너리는 다음 구문을 사용해요:

```csharp
IDictionary<int, string> numbers = new Dictionary<int, string>{ [0] = "zero", [1] = "one"...};

// or

IDictionary<int, string> numbers = new Dictionary<int, string>{ {0, "zero" }, {1,  "one"}...};
```

초기화되는 필드는 호출자가 접근할 수 있어야 해요. 보통 `public`이나 `internal`이어야 한다는 뜻이에요.

언어 설계자와 주요 실무자 사이에는 불변성을 장려하는 흐름이 강해서, 이런 방식으로 초기화한 개체의 가변성은 단점으로 여겨져요. 다가올 C# 9 버전에 `init` 절을 도입하자는 제안이 있는데, 이 문제를 해결해 줄지도 몰라요.

- [개체 이니셜라이저][object-initializers] 문서에서는 이니셜라이저를 사용하는 방법을 설명해요.
- [컬렉션 이니셜라이저][collection-initializers] 문서에서는 딕셔너리와 배열 같은 컬렉션에 이니셜라이저를 어떻게 사용할 수 있는지 미리 볼 수 있어요.
