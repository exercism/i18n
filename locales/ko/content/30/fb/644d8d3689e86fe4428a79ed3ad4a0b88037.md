# 테스트

제공된 테스트는 DrRacket에서 실행하거나 명령줄에서 실행할 수 있어요.

DrRacket에서 테스트를 실행하려면, 테스트 파일을 열고 오른쪽 위에 있는 'Run' 버튼을 클릭하면 돼요.

명령줄에서 테스트를 실행하려면, 연습 문제 디렉터리에서 테스트를 실행하면 돼요. 예를 들어, 테스트 스위트의 이름이 `hello-world-test.rkt`라면 다음 명령을 실행할 수 있어요:

```
raco test hello-world-test.rkt
```

그러면 다음과 같이 표시돼요:

```
raco test: (submod "hello-world-test.rkt" test)
2 success(es) 0 failure(s) 0 error(s) 2 test(s) run
0
2 tests passed
```
