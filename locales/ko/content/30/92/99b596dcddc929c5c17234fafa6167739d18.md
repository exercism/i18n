# 지시 사항

이 연습 문제에서는 2012년 9월 15일에 문을 연 뉴욕의 미용실을 위한 예약 스케줄러를 만들어 봐요.

다섯 개의 과제가 있고, 모두 예약 날짜와 관련되어 있어요.
시간은 24시간 형식으로 표기해요(AM/PM은 쓰지 않아요).

## 1. 숫자로만 된 예약 날짜 파싱하기

`schedule_appointment()` 함수를 구현해서 텍스트로 표현된 예약 날짜를 그에 해당하는 `DateTime` 형식으로 파싱해요.

입력은 미국식 월/일/년 순서라는 점에 유의해요.

```julia-repl
julia> schedule_appointment("07/25/2023 13:45:00")
2023-07-25T13:45:00
```

## 2. 예약이 이미 지났는지 확인하기

`has_passed()` 함수를 구현해요. 이 함수는 예약 날짜를 받아서 예약이 과거에 있었는지 확인해요:

```julia-repl
julia> has_passed(DateTime(1999, 12, 31, 9, 0, 0))
true
```

## 3. 예약이 오후인지 확인하기

`is_afternoon_appointment()` 함수를 구현해요. 이 함수는 예약 날짜를 받아서 예약이 오후(12:00 이상, 18:00 미만)인지 확인해요:

```julia-repl
julia> is_afternoon_appointment(DateTime(2023, 3, 29, 15, 0, 0))
true
```

## 4. 예약의 시간과 날짜 설명하기

`description()` 함수를 구현해요. 이 함수는 예약 날짜를 받아서 그 날짜와 시간에 대한 설명을 반환해요:

```julia-repl
julia> describe(DateTime(2023, 3, 29, 15, 0, 0))
"You have an appointment on Wednesday, March 29, 2023 at 15:00"
```

## 5. 기념일 날짜 반환하기

`anniversary_date()` 함수를 구현해요. 이 함수는 올해의 기념일 날짜인 9월 15일을 반환해요:

```julia-repl
julia> anniversary_date()  # run during 2025
2025-09-15
```
