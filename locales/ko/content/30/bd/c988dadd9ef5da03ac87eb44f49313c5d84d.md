# 지침

이번 과제는 랩 타임을 정확하게 기록하는 스톱워치를 만드는 거예요.

스톱워치는 네 가지 명령(start, stop, lap, reset)을 사용해 다음 두 가지를 기록해요.

1. 현재 랩의 기록된 시간
2. 이전에 기록된 랩 타임

사용할 수 있는 명령은 스톱워치가 어떤 상태에 있는지에 따라 달라요.

1. Ready: 초기 상태
2. Running: 시간을 측정하는 중
3. Stopped: 시간을 측정하지 않는 상태

| 명령    | 시작 상태   | 종료 상태 | 동작                                                     |
| ------- | ----------- | --------- | -------------------------------------------------------- |
| Start   | Ready       | Running   | 시간 측정을 시작해요                                     |
| Start   | Stopped     | Running   | 시간 측정을 재개해요                                     |
| Stop    | Running     | Stopped   | 시간 측정을 멈춰요                                       |
| Lap     | Running     | Running   | 현재 랩을 이전 랩에 추가한 다음, 현재 랩을 초기화해요    |
| Reset   | Stopped     | Ready     | 현재 랩을 초기화하고 이전 랩을 모두 지워요               |
