# 지침 추가

## 힌트

이 연습 문제를 완료하려면 볼링 *롤*의 시퀀스를 받아 최종 점수나 알맞은 오류를 반환하는 `score` 함수를 구현해야 해요.

```haskell
score :: [Int] -> Either BowlingError Int

data BowlingError = IncompleteGame
                  | InvalidRoll { rollIndex :: Int, rollValue :: Int }
                  deriving (Eq, Show)
```

이 정의들은 이미 작성되어 있을 거예요. 하지만 함수를 정의하는 건 직접 해야 해요.

테스트 스위트는 롤 번호가 0부터 시작한다고 기대한다는 점을 기억해요.
