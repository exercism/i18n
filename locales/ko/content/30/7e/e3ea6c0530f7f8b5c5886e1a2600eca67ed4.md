## 함수 타입

Swift 함수 시그니처에서 이름과 레이블을 모두 지우면, 함수의 타입만 남아요.

```swift
func shoppingList(item: String, quantity: Int) -> String {
  "You need to buy \(quantity) \(item)."
}
// shoppingList: (String, Int) -> String

func repeater(_ phrase: String, times: Int) -> String {
  var result = ""
  for _ in 1...times {
    result += phrase
  }
  return result
}
// repeater: (String, Int) -> String

func printString(line: String) {
  print(line)
}
// printString: (String) -> ()
```

처음 두 함수의 타입은 `(String, Int) -> String`으로 같은데, 두 시그니처는 서로 다르고 두 함수의 동작 방식도 아주 다르다는 점에 주목해요. 둘 다 `String`과 `Int`를 입력으로 받아 `String`을 반환해요. 그리고 세 번째 함수의 타입에서 볼 수 있듯이, 함수 본문이 아무것도 반환하지 않는 것처럼 보여도 실제로는 `Void` 타입의 유일한 값인 `()`를 암묵적으로 반환해요.

이런 함수 타입은 Swift의 다른 타입과 똑같은 방식으로 쓸 수 있어요. 예를 들어 변수나 상수를 선언할 때 사용할 수 있죠. 그리고 Swift에서 함수는 값이기 때문에, 이미 있는 함수를 이런 상수나 변수에 대입할 수 있어요.

```swift
var stringAndIntToString: (String, Int) -> String

stringAndIntToString = shoppingList
stringAndIntToString("carrots", 3)
// => "You need to buy 3 carrots."
```

다른 변수나 상수와 마찬가지로, 대입하는 값은 올바른 타입이어야 해요.

```swift
stringAndIntToString = printShoppingList
// Error: Cannot assign value of type '(String) -> ()' to type '(String, Int) -> String'
```

### 매개변수 타입으로서의 함수 타입

함수 타입은 다른 타입을 쓸 수 있는 곳이면 어디든 쓸 수 있으므로, 매개변수 타입으로도 쓸 수 있고 다른 함수에 전달해 그 함수 안에서 호출할 수도 있어요.

```swift
func apply3(to str: String, function f: (String, Int) -> String) -> String {
  f(str,3)
}
// apply3: ([String], (String, Int) -> String) -> [String]

apply3(to: "eggs", function: shoppingList)
// => "You need to buy 3 eggs."

apply3(to: "eggs", function: repeater)
// => "eggseggseggs"
```

## 반환 타입으로서의 함수 타입

마찬가지로 함수 타입은 함수의 반환 타입으로도 쓸 수 있어요. 다시 말해 다른 함수를 만들어 반환하는 함수를 작성할 수 있죠. 이런 함수를 만들 때, 반환되는 함수는 부모 함수에 전달된 다른 매개변수나 부모 함수 안에서 만들어진 지역 변수를 사용할 수 있어요.

```swift
func makeAdder(base: Int) -> (Int) -> Int {
  func adder(_ i: Int) -> Int {
    base + i
  }
  return adder
}
// makeAdder: (Int) -> (Int) -> Int

let add10 = makeAdder(base: 10)
// add10: (Int) -> Int

let subtract20 = makeAdder(base: -20)
// subtract10: (Int) -> Int

add10(5)
// => 15

subtract20(5)
// => -15
```
