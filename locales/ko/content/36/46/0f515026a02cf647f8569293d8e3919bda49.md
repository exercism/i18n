# 개요

ABAP에는 여러 가지 숫자 타입이 있어요. 규모가 작은 입문 연습 문제에서는 주로 정수 값에 `i`를, 팩형 십진수 값에 `p`를 사용해요.

값이 일수처럼 반드시 정수여야 할 때는 `i`를 사용해요. 값이 시급처럼 소수 자릿수를 가질 수 있을 때는 실수 타입을 사용해요.

```abap
DATA hours_per_day TYPE i VALUE 8.
DATA rate_per_hour TYPE p LENGTH 8 DECIMALS 2 VALUE '89.89'.

DATA day_rate TYPE p LENGTH 8 DECIMALS 2.
day_rate = hours_per_day * rate_per_hour.
```

팩형 십진수는 고정된 소수 자릿수가 필요할 때 비즈니스 애플리케이션에서 자주 사용해요. ABAP에는 십진 부동소수점 수(`decfloat16` 및 `decfloat34`)와 이진 부동소수점 수(`f`)도 있어요. 이진 부동소수점 수는 과학 계산에 유용할 수 있지만, 많은 십진 소수가 정확히 표현되지 않기 때문에 금액을 다루는 예제의 기본값으로는 적절하지 않아요.
