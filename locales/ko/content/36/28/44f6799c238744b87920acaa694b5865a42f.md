# 힌트

## 1. 중복된 트랙 제거하기

- 배열에서 세트를 만드는 예시는 [MDN 문서][mdn-relation-to-arrays]에서 볼 수 있어요.
- 세트를 반환하기 전에 반드시 배열로 다시 변환해야 해요.
- 스프레드 연산자를 사용하는 방법을 다시 확인하려면 [배열 구조 분해 개념][concept-array-destructuring]을 참고해요.

## 2. 트랙이 이미 추가되었는지 확인하기

- 세트에 원소가 들어 있는지 확인하는 [내장 메서드][mdn-set-has]가 있어요.

## 3. 트랙 추가하기

- 세트에 원소를 추가하는 [내장 메서드][mdn-set-add]가 있어요.
- 원소를 추가하기 전에 `Set.has()`를 직접 호출해서 원소가 있는지 확인하지 마세요. `Set.add()`가 알아서 처리해 줘요!

## 4. 트랙 삭제하기

- 세트에서 원소를 제거하는 [내장 메서드][mdn-set-delete]가 있어요.
- 원소를 삭제하기 전에 `Set.has()`를 직접 호출해서 원소가 있는지 확인하지 마세요. `Set.delete()`가 알아서 처리해 줘요!

## 5. 고유한 아티스트 나열하기

- 세트를 순회하는 방법에는 [몇 가지 방법][mdn-set-iteration]이 있어요.
- 문자열을 여러 개의 부분 문자열로 나누는 [내장 메서드][mdn-string-split]가 있어요.
- 배열을 구조 분해할 때 원소를 건너뛰는 방법을 다시 확인하려면 [배열 구조 분해 개념][concept-array-destructuring]을 참고해요.
