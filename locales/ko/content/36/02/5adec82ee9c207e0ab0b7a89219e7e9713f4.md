# 지침 추가

## 출력 형식

동작 순서를 널 종료 문자열로 출력하고, 구분자로는 쉼표와 공백을 사용해요.

## 레지스터

| 레지스터 | 용도        | 타입    | 설명                   |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | 입력        | 정수 | 1과 31 사이의 숫자       |
| `$a1`    | 입력/출력 | 주소 | 널 종료 출력 문자열 |
| `$t0-9`  | 임시    | 임의     | 임시 저장에 사용    |
