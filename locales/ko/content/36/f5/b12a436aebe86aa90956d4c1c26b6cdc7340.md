# 지침 추가

## 레지스터

| 레지스터 | 용도     | 타입      | 설명                            |
| -------- | -------- | --------- | ------------------------------- |
| `$a0`    | 입력     | 주소      | null로 끝나는 삼진 문자 문자열  |
| `$v0`    | 출력     | 정수      | 입력 문자열의 십진수 값         |
| `$t0-9`  | 임시     | 아무 타입 | 임시 저장에 사용                |
