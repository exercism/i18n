# 개요

`Maybe` 타입은 Elm 언어가 값이 있을 수도, 없을 수도 있는 경우를 다루기 위해 제공하는 해법이에요.
그래서 Elm 핵심 함수 상당수의 타입 시그니처에 등장하니, 이 타입을 이해하는 것이 아주 중요해요.

## 정의와 타입 변수

`Maybe` 타입은 다음과 같이 정의해요.

```elm
type Maybe a = Nothing | Just a
```

이런 형태를 Elm 용어로는 "사용자 정의 타입" 정의라고 불러요.
사용자 정의 타입은 이 트랙의 다른 개념에서 자세히 다루지만, `Maybe`를 이해하는 데는 필요하지 않아요.
`Maybe a`와 `Just a`에 있는 `a`는 타입 변수를 나타내는데, `Int`, `Bool`, `String`처럼 어떤 타입이든 될 수 있다는 뜻이에요.
따라서 `Maybe String`은 `String`을 담을 수도 있는 변수이고, `Maybe Int`는 `Int`를 담을 수도 있는 변수예요.

```elm
name : Maybe String
name = Just "Matthieu"

age : Maybe Int
age = Just 29
```

`Maybe`의 타입 정의에서 세로 막대 `|`는 "또는"을 뜻해요.
즉, 이 타입의 값은 `Nothing`이거나, 타입 `a`인 무언가를 담은 `Just`일 수 있어요.
그러면 그 사람이 이름과 나이를 채우지 않았다고 상상해 봐요. 그때는 다음과 같아요.

```elm
name : Maybe String
name = Nothing

age : Maybe Int
age = Nothing
```

## Maybe 값의 내용 읽기

`Maybe` 값의 내용을 읽는 방법은 "패턴 매칭"이에요.
패턴 매칭도 다른 개념에서 더 자세히 다루니, 여기서는 `Maybe`를 패턴 매칭하는 방법에만 집중해요.

```elm
-- This function returns "Hello, <name>!" if the name was provided.
-- Otherwise, it just says "Hello, World!".
sayHello : Maybe String -> String
sayHello maybeName =
    case maybeName of
        Nothing -> "Hello, World!"
        Just someName -> "Hello, " ++ someName ++ "!"

sayHello (Just "Matthieu")
    --> "Hello, Matthieu!"

sayHello Nothing
    --> "Hello, World!"
```

`Maybe` 값을 사용할 때마다 Elm 컴파일러는 모든 경우를 처리했는지 확인해 줘요.
그래서 `Maybe`를 패턴 매칭하면서 `Just someValue`인 경우만 처리하는 일은 있을 수 없어요.
처음에는 번거롭게 느껴질 수도 있지만, 이는 Elm 언어의 가장 큰 장점 중 하나예요.
이 덕분에 수백 개의 Bug를 막을 수 있고, 컴파일러가 이끄는 리팩터링을 두려움 없이 즐겁게 해낼 수 있어요.

## `Maybe`를 다루는 더 많은 함수

`Maybe` 모듈에는 `Maybe` 타입을 다루는 유용한 함수도 여러 개 있어요.

```elm
sayHelloAgain : Maybe String -> String
sayHelloAgain name = "Hello, " ++ Maybe.withDefault "World" name ++ "!"

capitalizeName : Maybe String -> Maybe String
capitalizeName name = Maybe.map String.toUpper name

capitalizeName matthieu
    --> Just "MATTHIEU"

capitalizeName anon
    --> Nothing
```
