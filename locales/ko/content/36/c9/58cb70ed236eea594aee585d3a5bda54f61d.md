# 소개

## 매핑

매핑이란 시퀀스의 각 원소에 함수를 적용해서 새로운 시퀀스를 만들어 내는 것을 말해요.

`mapcar` 함수를 사용하면 배열에서도 이 작업을 쉽게 할 수 있어요.
인자를 `2`로 곱하는 `double` 함수가 있다고 해봐요.

```lisp
(mapcar #'double '(1 2 3 4)) ; => (2 4 6 8)
```

첫 번째 인자가 호출할 함수라는 점을 눈여겨봐요. `#'`는 함수를 지정하기 위한 특별한 인용 구문이에요.

`double`은 처음에는 첫 번째 원소를 가지고 호출되고, 그다음에는 두 번째 원소를 가지고 호출되는 식이에요.
그 결과들은 하나의 배열로 모이고, 이 배열이 바로 그 표현식이 평가되는 값이에요.

## 필터링

필터링은 원래 시퀀스에서 특정 원소들을 제외한 나머지를 복사해서 새로운 시퀀스를 만드는 과정이에요.
새 시퀀스에 어떤 항목을 포함할지는 술어 함수(불리언 값을 평가하는 함수)로 정할 수도 있고, 특정 객체와의 동등 비교로 정할 수도 있어요.

### 술어로 제거하기

`remove-if`는 술어 함수와 시퀀스를 인자로 받아서, 술어가 거짓으로 평가된 원소들만으로 이루어진 시퀀스를 반환하는 함수예요.
다시 말해, 술어가 참으로 평가되는 시퀀스의 모든 원소를 "제거"해요. 그런데 이 함수는 원래 시퀀스를 수정하지 않는다는 점에 주의해요!
대신 해당 원소들이 빠진 새로운 시퀀스를 반환해요. 만약 모든 값에 대해 술어가 참이었다면 빈 시퀀스가 반환돼요.

```lisp
(remove-if #'evenp '(1 2 3 4 5)) ; => (1 3 5)
(remove-if #'oddp '(1 3 5))      ; => ()
```

### 특정 항목 제거하기

시퀀스에서 특정 항목을 제거하고 싶다면 `remove`를 사용할 수 있어요. `remove`는 제거할 항목과 시퀀스를 인자로 받아요.
제거할 항목과 같지 않은 시퀀스의 모든 값이 반환돼요.
참고: 동등성은 기본적으로 `eql` [일반 동등성 술어][concept-equality]로 검사해요.

```lisp
(remove 1 '(1 2 1 3 1 4)) ; => (2 3 4)
(remove #\l "hello")      ; => "heo"
```
