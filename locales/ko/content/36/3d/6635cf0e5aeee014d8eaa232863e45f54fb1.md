# 지침

이 연습 문제에서는 좋아하는 요리책을 보며 근사한 라자냐를 만들 수 있도록 도와주는 코드를 작성해요.

라자냐를 만드는 데 걸리는 시간과 관련된 네 가지 작업이 있어요.

## 1. 오븐 예상 시간(분) 정의하기

라자냐가 오븐에 있어야 하는 시간(분)을 값으로 하는 `OvenTime` 상수를 정의해요.
요리책에 따르면 예상 오븐 시간은 40분이에요.

```go
OvenTime
// => 40
```
