# 지침

이 연습 문제에서 여러분은 가장 친한 친구들과 "Wizard and Warriors"라는 롤플레잉 게임을 하고 있어요.
게임 마스터는 바로 여러분이에요. 게임 마스터는 플레이어들에게 게임 세계를 생생하게 느낄 수 있게 만들어 주는 역할을 맡은 사람이에요.
이때 중요한 것 중 하나는 플레이어들에게 게임을 설명하는 거예요. 캐릭터의 상태는 어떤지, 방문하는 마을은 어떻게 생겼는지 등등이요.

여러분에게는 플레이어들에게 게임의 여러 부분을 설명하는 다섯 가지 과제가 있어요.

## 1. 캐릭터를 설명해요

각 캐릭터는 클래스, 레벨, 체력을 가지고 있고, 다음과 같이 설명돼요: `"You're a level <LEVEL> <CLASS> with <HIT_POINTS> hit points."`.
`Character`를 유일한 매개변수로 받아 설명을 반환하는 `GameMaster.describe` 메서드를 구현해요.

```java
Character character = new Character();
character.setCharacterClass("Wizard");
character.setLevel(4);
character.setHitPoints(28);

new GameMaster().describe(character);
// => "You're a level 4 Wizard with 28 hit points."
```

## 2. 목적지를 설명해요

각 목적지는 이름과 주민 수를 가지고 있고, 다음과 같이 설명돼요: `"You've arrived at <NAME>, which has <INHABITANTS> inhabitants."`.
`Destination`을 유일한 매개변수로 받아 설명을 반환하는 `GameMaster.describe` 메서드를 구현해요.

```java
Destination destination = new Destination();
destination.setName("Muros");
destination.setInhabitants(732);

new GameMaster().describe(destination);
// => "You've arrived at Muros, which has 732 inhabitants."
```

## 3. 이동 방법을 설명해요

캐릭터는 두 가지 방법 중 하나로 목적지까지 이동할 수 있어요:

- 걷기, 다음과 같이 설명돼요: `"You're traveling to your destination by walking."`
- 말을 타고, 다음과 같이 설명돼요: `"You're traveling to your destination on horseback."`

`TravelMethod`를 유일한 매개변수로 받아 설명을 반환하는 `GameMaster.describe` 메서드를 구현해요.

```java
new GameMaster().describe(TravelMethod.HORSEBACK);
// => "You're traveling to your destination on horseback."
```

## 4. 목적지로 이동하는 캐릭터를 설명해요

캐릭터가 목적지로 이동할 때는 각각의 설명을 조합해서 나타내요: `"<CHARACTER> <TRAVEL_METHOD> <DESTINATION>"`.
`Character`, `Destination`, `TravelMethod`를 매개변수로 받아 설명을 반환하는 `GameMaster.describe` 메서드를 구현해요.

```java
Character character = new Character();
character.setCharacterClass("Wizard");
character.setLevel(4);
character.setHitPoints(28);

Destination destination = new Destination();
destination.setName("Muros");
destination.setInhabitants(732);

new GameMaster().describe(character, destination, TravelMethod.HORSEBACK);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination on horseback. You've arrived at Muros, which has 732 inhabitants."
```

## 5. 이동 방법을 명시하지 않고 목적지로 이동하는 캐릭터를 설명해요

대부분의 경우 캐릭터는 걷기로 목적지까지 이동해요.
편의를 위해 플레이어는 이동 방법을 생략할 수 있고, 이 경우 걷기가 이동 방법으로 간주돼요.
`Character`와 `Destination`을 매개변수로 받아 설명을 반환하는 `GameMaster.describe` 메서드를 구현해요.

```java
Character character = new Character();
character.setCharacterClass("Wizard");
character.setLevel(4);
character.setHitPoints(28);

Destination destination = new Destination();
destination.setName("Muros");
destination.setInhabitants(732);

new GameMaster().describe(character, destination);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination by walking. You've arrived at Muros, which has 732 inhabitants."
```
