# 지침

3진수를 문자열(예: '102012')로 표현한 값을, 기본 원리만 이용해 10진수 값으로 변환해요.

유효하지 않은 3진수를 나타내는 문자열은 값 0으로 간주해요.

3진수는 0, 1, 2 세 가지 기호로 이루어져 있어요.

3진수에서 마지막 자리는 1의 자리예요. 뒤에서 두 번째 자리는 3의 자리, 뒤에서 세 번째 자리는 9의 자리이고, 이런 식으로 이어져요.

```shell
# "102012"
    1       0       2       0       1       2    # the number
1*3^5 + 0*3^4 + 2*3^3 + 0*3^2 + 1*3^1 + 2*3^0    # the value
  243 +     0 +    54 +     0 +     3 +     2 =  302
```

사용하는 언어의 표준 라이브러리에 이 변환을 수행하는 메서드가 있더라도, 그런 건 없는 셈 치고 직접 구현해 봐요.
