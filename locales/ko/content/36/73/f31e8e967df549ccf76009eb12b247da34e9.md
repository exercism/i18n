# 소개

Julia는 대부분의 프로그래밍 언어처럼 다양한 컬렉션 타입을 제공해요.

어떤 컬렉션은 본질적으로 순서가 있어서 `Vectors`와 고차원 `Arrays`처럼 위치로 원소에 접근할 수 있어요.
다른 컬렉션은 순서가 없고(`Sets`, `Dicts`), 원소에 키나 값으로 접근해야 해요.

가장 단순한 경우로, `Ints`로 이루어진 `Vector`가 있고 이걸 오름차순으로 정렬하고 싶다고 해봐요.

```julia-repl
julia> v = [3, 2, 4, 1]
4-element Vector{Int64}:
 3
 2
 4
 1

julia> sort(v)
4-element Vector{Int64}:
 1
 2
 3
 4

# sort descending
julia> sort(v, rev=true)
4-element Vector{Int64}:
 4
 3
 2
 1
```

간단하죠!
`sort()` 함수는 이름만 봐도 알 수 있고, 겉보기에는 정렬된 `Vector`를 반환하는 것처럼 보여요.

_농담이에요!_
커리큘럼에서 이쯤 오면, 우리가 논의해야 할 미묘한 부분이 있다는 걸 (제대로) 짐작하고 있을 거예요.

## 변경하는 함수와 변경하지 않는 함수

`sort(v)`를 실행한 뒤 `v`는 어떻게 됐을까요?

```julia-repl
julia> v
4-element Vector{Int64}:
 3
 2
 4
 1

julia> issorted(v)
false
```

원래 벡터는 그대로예요.
`sort()`는 입력의 _복사본_을 반환하는 ***변경하지 않는*** 함수예요.

이건 많은 상황에서 좋은 설계예요. [순수 함수][wiki-pure-func]라서 동작을 추론하기 쉽고, 병렬이나 분산 코드에서도 마찬가지죠.

반대로, 10억 개의 문자열로 이루어진 배열을 정렬해야 한다고 해봐요.

정렬 자체도 아마 느릴 거예요.
게다가 모든 걸 복사해야 하고(_느려요!_), 그 복사본을 저장할 만큼의 메모리(_수 기가바이트!_)도 할당해야 해요.

이와 아주 비슷한 코드와 비교해봐요:

```julia-repl
# v is as previously

julia> issorted(v)
false

julia> sort!(v)
4-element Vector{Int64}:
 1
 2
 3
 4

julia> v
4-element Vector{Int64}:
 1
 2
 3
 4

julia> issorted(v)
true
```

이제 입력 `Vector`는 복사 없이 제자리에서 정렬되고, 원래 순서는 영영 사라져요.

이 방식은 효율적일 수도 있고, 버그를 만들거나 예상치 못한 부작용을 낳을 수도 있고, 내 코드를 쓰는 다른 사람을 헷갈리게 할 수도 있어요.
_신중하게 선택해요!_

`sort!()`는 "변경하는 함수"예요. 그리고 (_아주 강한_) 관례에 따라, 입력을 변경하는 함수는 이름 끝에 `!`를 붙여 프로그래머에게 경고해요.

## 무엇을 기준으로 정렬할까요?

`Int64` 값을 정렬하는 건 비교적 간단해요. 어린아이도 2가 1보다 크고 3보다 작다는 걸 알아요.

다른 타입은 더 복잡할 수 있지만, 일반적으로 `isless(x, y) == true`이면 `x < y`예요.
Julia는 대부분의 표준 타입에 대해 `isless()` 구현을 제공해요.

예를 들어 유니코드 문자는 이렇게 정렬돼요(유럽 문자 기준으로 대문자가 소문자보다 먼저 와요):

```julia-repl
julia> j = collect("Julia")
5-element Vector{Char}:
 'J': ASCII/Unicode U+004A (category Lu: Letter, uppercase)
 'u': ASCII/Unicode U+0075 (category Ll: Letter, lowercase)
 'l': ASCII/Unicode U+006C (category Ll: Letter, lowercase)
 'i': ASCII/Unicode U+0069 (category Ll: Letter, lowercase)
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)

julia> sort(j)
5-element Vector{Char}:
 'J': ASCII/Unicode U+004A (category Lu: Letter, uppercase)
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
 'i': ASCII/Unicode U+0false069 (category Ll: Letter, lowercase)
 'l': ASCII/Unicode U+006C (category Ll: Letter, lowercase)
 'u': ASCII/Unicode U+0075 (category Ll: Letter, lowercase)
```

정렬하기 전에 각 항목에 임의의 함수를 적용할 수도 있어요. 부호를 무시하는 `abs`나, 대소문자를 구분하지 않고 정렬하는 `uppercase`처럼요:

```julia-repl
julia> nums = [3, -2, -4, 1]
4-element Vector{Int64}:
  3
 -2
 -4
  1

julia> sort(nums)
4-element Vector{Int64}:
 -4
 -2
  1
  3

julia> sort(nums, by=abs)
4-element Vector{Int64}:
  1
 -2
  3
 -4

# j is from "Julia", as previously

julia> sort(j, by=uppercase)
5-element Vector{Char}:
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
 'i': ASCII/Unicode U+0069 (category Ll: Letter, lowercase)
 'J': ASCII/Unicode U+004A (category Lu: Letter, uppercase)
 'l': ASCII/Unicode U+006C (category Ll: Letter, lowercase)
 'u': ASCII/Unicode U+0075 (category Ll: Letter, lowercase)

julia> vecs = [[1, 3], [4, 2], [3, 4], [2, 1]];

julia> sort(vecs)  # by default sorts by the first element of the (2-element) vectors
4-element Vector{Vector{Int64}}:
 [1, 3]
 [2, 1]
 [3, 4]
 [4, 2]

julia> sort(vecs, by=last)
4-element Vector{Vector{Int64}}:
 [2, 1]
 [4, 2]
 [1, 3]
 [3, 4]
```

## 인덱스 배열로 정렬하기

정렬할 원소가 큰 객체라면, 위치 인덱스로 다루는 게 더 쉬울 수 있어요.

```julia-repl
julia> langs = ["Julia", "C++", "Python", "Elixir"]
4-element Vector{String}:
 "Julia"
 "C++"
 "Python"
 "Elixir"

julia> inxs = sortperm(langs)  # => Integers
4-element Vector{Int64}:
 2
 4
 1
 3

julia> langs[inxs]  # sort the entire vector
4-element Vector{String}:
 "C++"
 "Elixir"
 "Julia"
 "Python"

julia> langs[inxs[1:2]]  # slice the indices
2-element Vector{String}:
 "C++"
 "Elixir"
```

`langs`는 Vector이므로 각 인덱스는 [범위][concept-range] `1:length(langs)` 안의 정수예요.
`sortperm()`의 출력은 이 정수들의 [순열][wiki-permutation]이고, 입력 벡터를 정렬한 결과에 대응해요.

## 부분 정렬

프로그램에서 입력 전체를 정렬할 필요가 있나요?
처음 몇 개나 마지막 몇 개 항목에만 관심이 있는 경우에는 [부분 정렬][wiki-partial-sort]을 하는 게 훨씬 빠를 수 있어요.

Julia는 `partialsort()`와 `partialsort!()` 함수를 제공하는데, 지정한 항목이나 항목 범위가 올바르다는 것만 보장하고 나머지 입력에 대해서는 아무것도 보장하지 않아요.

두 번째 인자는 정수일 수도 있고 범위일 수도 있으며, 정렬된 입력에서의 인덱스를 나타내요:

```julia-repl
julia> vsq = [9, 4, 16, 1];  # would be [1, 4, 9, 16] after a full sort

julia> partialsort(vsq, 4)
16

julia> partialsort(vsq, 2:3)
2-element view(::Vector{Int64}, 2:3) with eltype Int64:
 4
 9
```
