# 반복자

반복자는 이름이 `!`로 끝나는 루틴으로, `loop` 안에서만 호출할 수 있어요. 루프를 한 번 돌 때마다 다음 값을 만들어 내고, 값이 떨어지면 루프는 곧바로 끝나요.

```sather
   loop
      total := total + counts.elt!;
   end;
```

Sather에는 `for`문이 없어요. 반복자가 그 자리를 대신하며, Sather가 유명한 바로 그 기능이에요.

## 먼저 알아 두면 좋은 반복자들

| 반복자 | 내놓는 값 |
| --- | --- |
| `a.elt!` | `a`의 각 원소를 순서대로 |
| `a.ind!` | `a`의 각 위치: 0, 1, 2 … |
| `n.upto!(m)` | `n`, `n+1` … `m` |
| `n.downto!(m)` | `n`, `n-1` … `m` |
| `n.times!` | `n`번 실행하고 아무 값도 내놓지 않아요 |
| `n.up!` | `n`, `n+1`, … 끝없이 이어져요 |
| `s.elt!` | 문자열의 각 문자 |

`until!`, `while!`, `break!`도 모두 반복자예요. 그래서 이름이 `!`로 끝나고, 루프 안에서만 동작해요.

## 호출을 어디에 쓸까요

반복자 호출은 표현식이 올 수 있는 곳이라면 어디든 쓸 수 있어요. 조건문 한가운데도 마찬가지예요.

```sather
   loop
      if counts.elt! > 10 then busy := busy + 1; end;
   end;
```

프로그램에서 반복자를 적은 *자리*마다 각자의 위치를 따로 기억해요. 루프 본문 안에 `counts.elt!`를 두 번 쓰면 배열을 서로 독립적인 두 번의 순회가 생기는데, 이런 결과를 원하는 경우는 거의 없어요.

```sather
   loop
      #OUT + counts.elt! + " and " + counts.elt!;   -- two separate walks
   end;
```

그럴 때는 값을 한 번만 받아 변수에 저장해요.

## 루프 끝내기

루프 안의 반복자 중 *하나라도* 값이 떨어지면 루프는 곧바로 끝나요. 모든 반복자가 끝나야 끝나는 게 아니에요. 반복자가 하나뿐이라면 당연해 보여요. 하지만 여러 개라면 누구나 걸리는 규칙이 되고, 다음 연습 문제가 바로 이 이야기예요.

## 어떤 걸 골라야 할까요

값이 필요할 때는 `elt!`을, 위치가 필요할 때는 `ind!`을 써요. `0 .. a.size - 1` 범위를 도는 `upto!`는 둘 다 동시에 필요할 때, 또는 답이 값이 아니라 위치일 때만 꺼내 써요.
