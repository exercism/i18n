# 힌트

## 1. 오븐에서 예상되는 조리 시간을 분 단위로 정의하기

- `$EXPECTED-MINUTES-IN-OVEN` 상수에 올바른 값을 할당해야 해요.

## 2. 남은 오븐 조리 시간을 분 단위로 계산하기

- [중위 `-` 연산자][&infix:<->]를 사용하면 숫자를 서로 뺄 수 있어요.

## 3. 준비 시간을 분 단위로 계산하기

- [중위 `*` 또는 `×` 연산자][&infix:<*>]를 사용하면 숫자를 곱할 수 있어요.

## 4. 총 작업 시간을 분 단위로 계산하기

- 유용할 것 같은 다른 함수를 호출할 수 있어요. 예를 들어 `function($arg)`처럼요.
- [중위 `+` 연산자][&infix:<+>]를 사용하면 숫자를 서로 더할 수 있어요.

## 5. 라자냐가 완성되었다는 알림 만들기

- 텍스트를 작은따옴표 `'foo'` 또는 큰따옴표 `"bar"`로 감싸면 문자열을 만들 수 있어요.
  [인용 구문][quoting]을 참고해요.

[&infix:<*>]: https://docs.raku.org/language/operators#infix_*
[&infix:<->]: https://docs.raku.org/language/operators#infix_-
[quoting]: https://docs.raku.org/language/quoting
