# 지침

전자레인지 패널에서 누른 버튼을 그에 해당하는 타이머 시간으로 변환하는 것이 과제예요.

디지털 전자레인지 타이머는 오른쪽부터 채워져요. 그래서 1, 0, 0을 누르면 전자레인지는 이것을 "1:00", 즉 1분 0초로 읽어요. 132를 누르면 "1:32", 즉 1분 32초로 읽어요. 전자레인지 타이머는 "90"을 누르면 90초, 즉 "1:30"을 의미한다는 것도 알 만큼 똑똑해요.

90초를 그대로 두지 않고, 분과 초로 최대한 간단하게 표현해 주는 "스마트 디스플레이"를 만들고 싶어요.

입력한 버튼을 받아 알맞은 디스플레이 패널 시간으로 변환하는 클래스를 만들어 봐요. 무엇을 입력하든 분과 초로 최대한 간단하게 바꿔 줘야 해요.
