# 테스트

## 테스트 실행

테스트를 실행하려면 다음 명령어를 실행해요:

```bash
bats test-<exercise-slug>.bats
```

### bats는 bash로 구현되어 있어요

bats 파일은 bash 스크립트인데, `bats` 명령어가 인식하는 특별한 함수들이 몇 개 들어 있어요.
다음과 같은 모습의 테스트도 볼 수 있어요:

```bash
sed -E -f <exercise-slug>.sed <<< "$input"
```

이 `<<<` 문법은 bash의 *Here String*이에요.
오른쪽에 있는 문자열을 왼쪽에 있는 프로그램의 표준 입력으로 보내줘요.
다음과 거의 같은 표현이에요:

```bash
echo "$input" | sed -E -f <exercise-slug>.sed
```

## 건너뛴 테스트

연습 문제를 푼다는 것은 그 문제의 모든 테스트를 통과시키는 것을 의미해요.
기본적으로 테스트를 실행하면 하나의 테스트(첫 번째 테스트)만 실행돼요.
이는 의도된 것으로, 그 하나의 테스트를 통과시키는 데만 집중할 수 있게 해줘요.
그 테스트가 통과하면, 다음 테스트들 앞에 붙어 있는

    [[ $BATS_RUN_SKIPPED == true ]] || skip

주석을 삭제하거나 주석 처리해서 다음 테스트를 활성화할 수 있어요.

## 건너뛰기 무시하기

`skip` 주석이 붙은 테스트까지 포함해 모든 테스트를 실행하려면 다음을 실행해요:

```bash
BATS_RUN_SKIPPED=true bats test-<exercise-slug>.bats
```

또는 테스트 파일에서 다음 줄을

```bash
[[ $BATS_RUN_SKIPPED == "true" ]] || skip
```

주석 처리하거나 삭제해도 돼요.
