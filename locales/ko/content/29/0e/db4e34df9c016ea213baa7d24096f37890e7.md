# 힌트

## 일반

- 문제를 기저 사례와 재귀 사례로 나눠 봐요. 예를 들어, 재귀적인 방법으로 쿠키 항아리에 쿠키가 몇 개 있는지 세고 싶다고 해봐요. 기저 사례는 빈 항아리예요. 즉, 쿠키가 하나도 없어요. 항아리가 비어 있지 않다면, 항아리 안의 쿠키 개수는 쿠키 하나에 쿠키 하나를 꺼낸 뒤의 항아리 안 쿠키 개수를 더한 것과 같아요.

## 1. 오늘 몇 마리의 새가 찾아왔는지 확인하기

- 이 과제에는 재귀가 필요하지 않아요.
- 배열의 첫 번째 원소에 접근하는 것은 case 식으로 할 수 있어요.

## 2. 오늘의 개수 증가시키기

- 이 과제에는 재귀가 필요하지 않아요.
- 배열의 첫 번째 원소와 나머지 원소에 접근하는 것은 case 식으로 할 수 있어요.

## 3. 새가 찾아오지 않은 날이 있었는지 확인하기

- 새가 찾아오지 않은 날을 찾을 때까지 재귀로 배열의 원소를 반복해요.
- 기저 사례는 빈 배열이에요.

## 4. 찾아온 새의 총 개수 계산하기

- 재귀로 배열의 모든 원소를 반복해요.
- 기저 사례는 빈 배열이에요.

## 5. 분주한 날의 개수 계산하기

- 재귀로 배열의 모든 원소를 반복해요.
- 기저 사례는 빈 배열이에요.
- case 식의 절 하나에는 가드를 사용해요.
