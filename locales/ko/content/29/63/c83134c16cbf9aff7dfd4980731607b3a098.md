# 소개

다른 언어들처럼 C++도 `switch`문을 제공해요.
`switch`문은 긴 `if ... else if`문을 더 짧게 쓸 수 있는 방법이에요.
`switch`문을 만들려면 먼저 `switch` 키워드를 쓰고 그 뒤에 정수를 붙여요.
그다음에는 `case` 키워드로 각 조건을 하나씩 선언해요.
이전 `case` 조건 중 어느 것도 맞지 않을 때 실행되는 `default` 케이스도 선언할 수 있어요.
각 케이스는 `break`문(또는 `return`문)으로 끝나야 해요.

```cpp
int price{0};
int adults{3};
int kids{2};

switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
        break;
    case 2:
        price = 70;
        break;
    default:
        price = group_size * 30;
}
```

## 폴스루

`switch`문에서 중요한 점 하나는, 코드가 `break`문(또는 `return`문)을 만나 멈출 때까지 계속 실행된다는 거예요.
이 때문에 예상치 못한 동작이 일어날 수 있어요.

```cpp
int adults{1};
int kids{0};
switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
    case 2:
        price = 70;
    default:
        price = group_size * 30;
}
// price will be 30!
```

이렇게 계속 실행되는 기능이 주로 쓰이는 곳은 여러 개의 레이블을 가진 문이에요.
여러 `switch` 결과가 같은 코드 조각으로 이어져 실행되도록 할 수 있어요.
이런 방식으로, 예를 들어 예약 앱에서, 그룹 크기가 2와 3일 때 호출되는 함수를 같게 만들 수 있어요:
```cpp
switch (group_size) {
case 1:
    book_room();
    break;
case 2:
case 3:
    book_apartment(group_size);
    break;
default:
    book_house(group_size);
}
// book_apartment happens when group_size is 2 or 3
```
