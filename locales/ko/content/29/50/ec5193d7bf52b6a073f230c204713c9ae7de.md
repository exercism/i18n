# 바인딩된 루틴

지금까지는 *값*을 주고받기만 했어요. 숫자, 문자열, 객체 같은 것들이요. **바인딩된 루틴**을 쓰면 루틴 자체를 주고받을 수 있어요. 나중에, 그것이 무엇인지도 모르는 코드가 호출할 무언가를 말이에요.

대역 배우가 바로 이 개념이에요. 무대 감독은 그 역할을 연기할 방법을 쥐고 있지만, 누가 연기할지, 무엇을 할지는 몰라요.

## 만드는 법

`bind`는 `_`로 쓴 빈칸이 있는 호출을 받아요:

```sather
   shout(line : STR) : STR is return line.upper; end;

   ...

   part ::= bind(shout(_));
```

이제 `part`는 다른 값과 똑같은 값이에요. 호출은 나중에 일어나요:

```sather
   part.call("who's there")      -- "WHO'S THERE"
```

## 타입

바인딩된 루틴의 타입은 `ROUT`이고, 중괄호 안에 인자 타입을, 콜론 뒤에 반환 타입을 써요:

```sather
   part : ROUT{STR}:STR := bind(shout(_));
```

`ROUT{STR}:STR`은 "`STR`을 받아 `STR`로 답하는 루틴"이라고 읽어요.

| 표기 | 의미 |
| --- | --- |
| `ROUT{STR}:STR` | `STR`을 받고 `STR`로 답함 |
| `ROUT{INT,INT}:BOOL` | `INT` 두 개를 받고 `BOOL`로 답함 |
| `ROUT{STR}` | `STR`을 받고 아무것도 답하지 않음 |
| `ROUT:INT` | 아무것도 받지 않고 `INT`로 답함 |

타입이기 때문에 인자로 넘길 수도 있어요:

```sather
   rehearse(line : STR, part : ROUT{STR}:STR) : STR is
      return part.call(line);
   end;
```

`rehearse`는 `part`가 무엇을 하는지 전혀 몰라요. 바로 그게 핵심이에요. `shout`을 넘겨도 되고, `whisper`를 넘겨도 되고, 그런 모양이기만 하면 무엇이든 넘길 수 있어요.

## 인자 일부만 채우기

모든 인자가 빈칸일 필요는 없어요. 그대로 써 둔 것은 바인딩할 때 고정돼요:

```sather
   repeat(times : INT, line : STR) : STR is ... end;

   twice ::= bind(repeat(2, _));      -- ROUT{STR}:STR
```

`twice`는 `2`가 이미 정해져 있으니 대사만 받아요. 값은 바인딩하는 순간 계산되어 그대로 남기 때문에, 나중에 원래 변수를 바꿔도 아무 차이가 없어요.

이렇게 해서 하나의 일반적인 루틴이 여러 개의 구체적인 루틴이 돼요.

## 객체까지 바인딩하기

객체의 루틴이라면, 객체가 호출의 맨 앞에 오는데, 이걸 고정할 수도 있고 빈칸으로 남길 수도 있어요:

```sather
   bind(board.home_goal)      -- this board's, always
   bind(_.home_goal)          -- whichever board is handed in later
```
