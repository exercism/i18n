# 지시 사항 추가

## 구현

Forth에서 함수는 `words`라고 부르고, 데이터 스택 위에서 동작해요.
각 워드는 매개변수를 스택에서 가져와서 결과를 스택에 반환해요.

Forth 문서에는 워드가 실행되기 전과 실행된 후의 데이터 스택 상태가 항상 다음과 같은 형식으로 적혀 있어요: `( p1 p2 ... pN --- r1 r2 ... rN )`.
`p1`부터 `pN`까지의 값은 호출 전 스택에 있는 워드의 매개변수를 나타내고(스택에는 여기에 표시되지 않은 다른 데이터가 더 있을 수 있어요), `r1`부터 `rN`까지의 값은 호출 후 스택에 있는 워드의 반환 값을 나타내요.
구분자 `---`는 워드가 실행되기 전과 후의 스택 상태를 구분해요.

구현할 워드는 다음과 같이 정의돼요:

- ToS는 Top of Stack의 약자예요
- 스택의 맨 위는 가장 오른쪽 값으로 나타내요

| 워드   | 스택 상태               | 설명                                 |
| ------ | ----------------------- | ------------------------------------ |
| `+`    | `( a b --- sum )`       | `sum = a + b`                        |
| `-`    | `( a b --- diff )`      | `diff = a - b`                       |
| `*`    | `( a b --- prod )`      | `prod = a * b`                       |
| `/`    | `( a b --- quot )`      | `quot = a / b`                       |
| `dup`  | `( a --- a a )`         | ToS에 있는 값을 복제해요             |
| `drop` | `( a --- )`             | ToS에 있는 값을 버려요               |
| `swap` | `( a b --- b a )`       | ToS에 있는 두 값을 서로 바꿔요       |
|`over`  | `( a b c --- a b c b )` | 두 번째 값을 ToS로 복사해요          |

온라인 Forth 인터프리터를 직접 써보고 싶거나 구현할 워드에 대해 더 알아보고 싶다면 [Easy Forth][easy-forth]를 한번 살펴봐요(특히 Adding Some Numbers, Defining Words, Stack Manipulation 섹션을요).
