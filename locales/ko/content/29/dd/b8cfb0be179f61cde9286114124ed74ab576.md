# 지침

이 연습 문제에서는 친구가 개발 중인 새로운 RPG 게임의 퀘스트 로직을 구현해요.
게임의 주인공은 Annalyn으로, 용감한 소녀이자 사납지만 충직한 반려견의 주인이에요.
그런데 안타깝게도, 가장 친한 친구가 숲에서 열매를 찾다가 납치되는 일이 벌어져요.
Annalyn은 이 퀘스트를 떠나 친구를 찾아내고 구출하려고 해요. 원한다면 반려견과 함께 갈 수도 있어요.

친구의 흔적을 한참 따라간 끝에, Annalyn은 친구가 갇혀 있는 야영지를 발견해요.
납치범은 둘이었는데, 하나는 힘센 기사이고 다른 하나는 교활한 궁수예요.

납치범들을 찾은 Annalyn은 다음 행동 중 어떤 것을 할 수 있을지 고민해요.

- _빠른 공격_: **기사**가 **_잠들어 있을_** 때 빠른 공격을 할 수 있어요. 갑옷을 입는 데 시간이 걸려서 기사가 무방비 상태가 되기 때문이에요.
- _정찰_: 무리 중 **적어도 한 명**이 **_깨어 있으면_** 정찰을 할 수 있어요. 그렇지 않으면 정찰은 시간 낭비예요.
- _죄수에게 신호 보내기_: **죄수**가 **_깨어 있고_** **궁수**가 **_잠들어 있으면_** 새소리로 죄수에게 신호를 보낼 수 있어요. 궁수는 새소리 신호를 익혔기 때문에 메시지를 가로챌 수도 있거든요.
- _죄수 구출_: Annalyn은 몰래 야영지에 들어가 죄수를 풀어줄 수 있어요.
  위험한 일이라 두 가지 방법 중 하나로만 성공할 수 있어요.
  - 반려견과 함께 있다면 **궁수**가 **_잠들어 있을_** 때 죄수를 구출할 수 있어요.
    기사는 개를 무서워하고, 궁수는 Annalyn과 죄수가 도망치기 전에 준비할 시간이 없어요.
  - 반려견이 없다면 Annalyn과 죄수는 아주 조심스럽게 움직여야 해요!
    **죄수**가 **_깨어 있고_** **기사**와 **궁수**가 둘 다 **_잠들어 있으면_** 죄수를 풀어줄 수 있지만, **죄수**가 **_잠들어 있으면_** 구출할 수 없어요. Annalyn이 갑자기 나타나면 죄수가 놀라서 기사와 궁수를 깨울 테니까요.

이제 네 가지 과제가 있어요. 숲에서 만난 세 인물의 상태와 Annalyn의 반려견 동반 여부에 따라 위 행동을 할 수 있는지 판단하는 로직을 구현해요.

## 1. '빠른 공격' 행동이 가능한지 확인하기

기사가 깨어 있는지를 나타내는 불리언 값을 받는 `canFastAttack`이라는 함수를 구현해요.
이 함수는 해당 인물의 상태에 따라 '빠른 공격' 행동이 가능하면 `true`를 반환해요.
그렇지 않으면 `false`를 반환해요.

```php
<?php
$is_knight_awake = true;

$infiltration = new AnnalynsInfiltration();
$infiltration->canFastAttack($is_knight_awake);
// => false
```

## 2. '정찰' 행동이 가능한지 확인하기

기사, 궁수, 죄수가 각각 깨어 있는지를 나타내는 세 개의 불리언 값을 받는 `canSpy`라는 함수를 구현해요.
이 함수는 인물들의 상태에 따라 '정찰' 행동이 가능하면 `true`를 반환해요.
그렇지 않으면 `false`를 반환해요.

```php
<?php
$is_knight_awake = false;
$is_archer_awake = true;
$is_prisoner_awake = false;

$infiltration = new AnnalynsInfiltration();
$infiltration->canSpy($is_knight_awake, $is_archer_awake, $is_prisoner_awake);
// => true
```

## 3. '죄수에게 신호 보내기' 행동이 가능한지 확인하기

궁수와 죄수가 각각 깨어 있는지를 나타내는 두 개의 불리언 값을 받는 `canSignal`이라는 함수를 구현해요.
이 함수는 인물들의 상태에 따라 '죄수에게 신호 보내기' 행동이 가능하면 `true`를 반환해요.
그렇지 않으면 `false`를 반환해요.

```php
<?php
$is_archer_awake = false;
$is_prisoner_awake = true;

$infiltration = new AnnalynsInfiltration();
$infiltration->canSignal($is_archer_awake, $is_prisoner_awake);
// => true
```

## 4. '죄수 구출' 행동이 가능한지 확인하기

네 개의 불리언 값을 받는 `canLiberate`라는 함수를 구현해요.
처음 세 매개변수는 기사, 궁수, 죄수가 각각 깨어 있는지를 나타내요.
마지막 매개변수는 Annalyn의 반려견이 함께 있는지를 나타내요.
이 함수는 인물들의 상태와 Annalyn의 반려견 동반 여부에 따라 '죄수 구출' 행동이 가능하면 `true`를 반환해요.
그렇지 않으면 `false`를 반환해요.

```php
<?php
$is_knight_awake = false;
$is_archer_awake = true;
$is_prisoner_awake = false;
$is_dog_present = false;

$infiltration = new AnnalynsInfiltration();
$infiltration->canLiberate(
    $is_knight_awake,
    $is_archer_awake,
    $is_prisoner_awake,
    $is_dog_present
);
// => false
```
