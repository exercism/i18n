# 개요

F# 문자열은 텍스트를 유니코드 문자(글자, 숫자, 문장 부호 등)의 나열로 나타내는 불변 객체예요. `string` 인스턴스를 정의할 때는 큰따옴표를 사용해요:

```fsharp
let fruit = "Apple"
```

문자열을 조작할 때는 문자열의 [메서드][methods]나 [속성][properties] 중 하나를 호출하거나, [`String` 모듈][string-module]에 있는 함수 중 하나를 사용할 수 있어요. 문자열 값은 한 번 정의되면 절대 바뀌지 않기 때문에, 문자열을 조작하는 모든 메서드와 함수는 새로운 문자열을 반환해요.

문자열은 큰따옴표(`"`) 문자로 감싸요. 일부 특수 문자는 백슬래시(`\`) 문자를 사용해 [이스케이프][escaping]해야 해요. 문자열 앞에 앳(`@`) 기호를 붙일 수도 있는데, 이렇게 하면 이스케이프 문자를 무시하는 [축자 문자열][verbatim]이 돼요.

```fsharp
let escaped = "c:\\test.txt"
let verbatim = @"c:\test.txt"
escaped = verbatim
// => true
```

또는 [삼중 따옴표][triple-quoted](`"""`)를 사용해 문자열을 정의할 수 있는데, 이렇게 하면 문자열 안에서 큰따옴표를 이스케이프하지 않고 그대로 쓸 수 있어요.

```fsharp
let tripledQuoted = """<movie title="Se7en" />"""
// => "<movie title="Se7en" />
```

마지막으로, 문자열 연결은 [`+` 연산자][plus-operator]로 할 수 있어요:

```fsharp
let name = "Jane"
"Hello " + name + "!"
// => "Hello Jane!"
```
