# 소개

조건식은 조건이 **true**인지 **false**인지에 따라 코드를 실행할 때 사용해요. 조건식은 다음과 같이 작성해요:

```haxe
if (condition) {
  expressions
};
```

조건의 결과는 `Bool` 타입이에요. 따라서 결과가 `true`이면 표현식이 실행돼요.

때로는 조건이 실제로 `false`일 때 다른 코드를 실행하고 싶을 때도 있어요. 이럴 때 사용하는 것이 `else` 표현식이에요. `else` 표현식은 처음 조건이 `false`일 때 표현식을 실행해요. 그런데 여러 가능성을 확인하고 싶다면 어떻게 해야 할까요? 이때는 `else if (condition)` 구문을 사용해요. 다음은 전체 예시예요:

```haxe
var a = 10;

if (a == 2) {
  trace("a is 2");
} else if (a == 5) {
  trace("a is 5");
} else {
  trace("a is 10");
}

// a is 10
```
