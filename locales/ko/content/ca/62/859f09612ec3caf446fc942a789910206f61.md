# 테스트 실행하기

SWI Prolog은 대화형으로 실행할 수도 있고, 명령줄에서 직접 실행할 수도 있어요.

## 명령줄

다음 명령어를 사용하면 명령줄에서 테스트를 실행할 수 있어요:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)'
```

`<exercise>` 부분은 구현 중인 연습 문제의 이름으로 바꿔 주세요.

## 대화형으로 실행하기

Prolog을 대화형으로 실행하려면 먼저 다음을 실행해요:

```bash
swipl
```

Prolog 콘솔이 시작되면, 구현한 코드를 불러오고 다음 명령으로 테스트를 실행해요:

```
?- ["<exercise>.pl"].
?- ["<exercise>_tests.plt"].
?- run_tests.
```

`<exercise>` 부분은 구현 중인 연습 문제의 이름으로 바꿔 주세요.

### 변경 사항 다시 불러오기

위 파일들을 불러온 뒤에는 다음을 실행해서 변경한 내용을 반영할 수 있어요:

```
?- make.
```

## 건너뛴 테스트

연습 문제를 처음 시작하면 첫 번째 테스트만 실행돼요. 나머지 테스트는 `test` goal에 `condition(pending)`을 추가해서 건너뛰도록 되어 있어요.
첫 번째 테스트가 통과하면, `condition(pending)`의 `pending`을 `true`로 바꿔서 다음 테스트의 건너뛰기를 해제해요.
모든 테스트가 실행되고 통과할 때까지 각 테스트마다 이 과정을 반복해요.

### 명령줄

명령 끝에 `-- --all` 인자를 추가하면 대기 중인 테스트도 함께 실행할 수 있어요:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)' -- --all
```
