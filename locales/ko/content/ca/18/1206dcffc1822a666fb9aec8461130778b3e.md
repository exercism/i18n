# 개요

Haxe는 정규 표현식을 기본으로 지원해요. 정규 표현식은 문자열의 형식을 검사하거나 문자열을 변환하거나, 주어진 텍스트에서 규칙적인 데이터를 추출하는 데 사용할 수 있어요.

정규 표현식을 만들려면 `~/`와 `/` 사이에 입력해요:

```haxe
var r = ~/haxe/i;
```

`EReg()` 인스턴스를 사용하는 방법도 있어요:

```haxe
var r = new EReg("haxe", "i");
```

여기서 `i`는 패턴의 대소문자를 구분하지 않게 만드는 플래그예요. 다른 플래그도 있어요:

- `g`: 전역 치환
- `m`: 여러 줄 일치

`~/`와 `/` 사이에는 정규 표현식 패턴을 입력해요. 예를 들어, A부터 Z까지의 문자를 포함하는 문자열을 찾고 싶다고 해봐요. 이때는 범위 패턴 `[A-Z]`를 사용할 수 있어요. 다양한 표현 패턴이 있어요:

- `.`: 모든 문자
- `*`: 0번 이상 반복
- `+`: 1번 이상 반복
- `[A-Z0-9]`: 문자 범위
