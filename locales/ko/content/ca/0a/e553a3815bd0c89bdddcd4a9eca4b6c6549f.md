# 소개

Go 함수와 메서드는 여러 값을 반환할 수 있어요:

```go
func GetCard() (Card, error) { ... }
```

모든 반환값은 순서대로 할당해야 하고 쉼표로 구분해야 해요:

```go
card, err := GetCard()
```

할당의 각 위치는 변수를 선언해요.
선언된 변수가 하나라도 사용되지 않으면 Go는 컴파일되지 않아요.
빈 식별자 `_`는 변수 이름 대신 사용해서 해당 반환값을 건너뛰어요:

```go
card, _ := GetCard()
```

`error`는 내장 인터페이스예요.
`nil` 오류는 오류가 발생하지 않았다는 뜻이고, nil이 아닌 값은 뭔가 잘못되었다는 뜻이에요.
관례상 실패할 수 있는 함수는 마지막 값으로 `error`를 반환해야 해요.
호출자는 다른 반환값을 사용하기 전에 오류를 확인해야 해요:

```go
card, err := GetCard()
if err != nil {
    return err // do not use card here
}
// safe to use card here
```
