# 지침

놀이공원에서 일하게 되면서, 입장객과 놀이기구를 관리하는 시스템을 설계하라는 명세를 받았어요. 여기서는 공원을 방문하는 사람인 관람객(Attendee)을 모델링하는 일을 맡았어요.

## 1. 새 관람객 만들기

`Attendee` 클래스의 `Attendee#initialize` 메서드를 구현해요. 이 메서드는 키(센티미터 단위)를 인자로 받아 인스턴스 변수에 저장해야 해요.

```ruby
Attendee.new(106)
# => #<Attendee:0x000055c33e6c7e18 @height=106>
```

## 2. 관람객의 키 구하기

`Attendee` 클래스의 `Attendee#height` getter 메서드를 구현해요. 이 메서드는 인스턴스의 키를 반환해야 해요.

```ruby
Attendee.new(106).height
# => 106
```

## 3. 이용권 id는 무엇인가요

모든 관람객이 이용권을 산 것은 아니지만, 이용권을 가지고 있는지 없는지는 알아야 해요. `Attendee` 클래스의 `Attendee#pass_id` getter 메서드를 구현해요. 이 메서드는 인스턴스의 pass_id를 반환하고, 관람객이 이용권을 가지고 있지 않다면 `nil`을 반환해야 해요.

```ruby
Attendee.new(106).pass_id
# => nil
```

## 4. 이용권을 살 수 있게 하기

`Attendee#issue_pass!`를 구현해서 인스턴스의 상태를 바꾸고, pass id 인스턴스 변수를 인자로 설정해요. 이 메서드는 pass id를 반환해야 해요.

```ruby
attendee = Attendee.new(106)
attendee.issue_pass!(42)
attendee.pass_id
# => 42
```

## 5. 이용권 회수하기

일부 손님은 안전하지 않은 행동으로 규칙을 어기기 때문에, 공원은 이용권을 회수할 수 있기를 원해요. `Attendee#revoke_pass!`를 구현해서 인스턴스의 상태를 바꾸고, pass id를 `nil`로 설정해요.

```ruby
attendee = Attendee.new(106)
attendee.issue_pass!(42)
attendee.revoke_pass!
attendee.pass_id
# => nil
```
