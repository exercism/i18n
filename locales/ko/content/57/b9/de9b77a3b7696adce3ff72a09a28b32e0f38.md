# 지침 추가

## 출력 형식

다이아몬드를 null로 끝나는 문자열로 출력하고, 각 행의 끝에 줄바꿈 문자를 붙여요.

출력 예시는 다음과 같아요: `"  A  \n B B \nC   C\n B B \n  A  \n"`

## 레지스터

| 레지스터 | 용도      | 타입   | 설명                      |
| -------- | --------- | ------ | ------------------------- |
| `$a0`    | 입력      | 바이트 | 문자                      |
| `$a1`    | 입력/출력 | 주소   | null로 끝나는 결과 문자열 |
| `$t0-9`  | 임시      | 임의   | 임시 저장용               |
