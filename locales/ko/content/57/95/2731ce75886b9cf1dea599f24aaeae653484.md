# 지침 추가

## 레지스터

| 레지스터 | 용도     | 타입    | 설명                        |
| -------- | --------- | ------- | --------------------------- |
| `$a0`    | 입력      | 주소    | 책 단어 배열                |
| `$a1`    | 입력      | 정수    | 책의 개수                   |
| `$v0`    | 출력      | 정수    | 가격 (센트 단위)            |
| `$t0-9`  | 임시      | 아무 타입 | 임시 저장에 사용            |
