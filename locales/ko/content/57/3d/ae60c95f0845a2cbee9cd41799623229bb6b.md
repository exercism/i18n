# 소개

`GENERIC:` 선언은 인자 중 하나의 *클래스*에 따라 동작이 달라지는 단어를 만들어요. 구체적인 동작은 `M:`으로 정의하는 *메서드*에서 나와요.

```factor
GENERIC: area ( shape -- n )

TUPLE: square side ;
TUPLE: circle radius ;

M: square area
    side>> dup * ;
M: circle area
    radius>> dup * pi * ;
```

`area`가 호출되면 Factor는 스택의 맨 위를 살펴보고, 클래스가 일치하는 가장 구체적인 메서드를 찾아서 실행해요. 로컬을 쓰면 `M::`를 사용할 수 있어요.

```factor
TUPLE: rectangle width height ;

M:: rectangle area ( r -- n )
    r width>> r height>> * ;

T{ rectangle { width 3 } { height 4 } } area .   ! => 12
```

제네릭을 쓰면 나중에 호출하는 코드를 바꾸지 않고도 새로운 표현을 추가할 수 있어요. `area`는 이미 `square`와 `circle`에서 동작했고, `rectangle` 메서드는 `area`가 호출되는 곳이면 어디서든 자동으로 적용돼요.

## 제네릭이 적합한 경우

다음과 같은 경우에 `GENERIC:`를 선택해요.

- 하나의 연산이 입력에 따라 *정말로 다른* 구현을 가질 때.
- 앞으로 추가될 코드가 새로운 타입을 도입할 것으로 예상될 때.
- 타입 시스템이 클래스별 정의를 강제하기를 원할 때.

변화가 몇 가지 레이블을 나열하는 정도라면 `case`가 더 간단해요.

## `INSTANCE:`로 믹스인에 합류하기

*믹스인*은 *열려 있는* 제네릭 클래스예요. 누구나 새로운 클래스를 멤버로 등록할 수 있죠. Factor의 내장 프로토콜(시퀀스, 집합, 스트림 등)은 대부분 믹스인으로 노출되어 있어서, 직접 만든 튜플은 자신을 인스턴스로 선언해서 프로토콜의 기본 메서드에 참여할 수 있어요.

```factor
MIXIN: shape
M: shape area                   ! a default area for any shape
    drop 0 ;

TUPLE: my-shape ;
INSTANCE: my-shape shape         ! my-shape is now a `shape`

T{ my-shape } area .   ! => 0
```

`INSTANCE:`를 쓰면 `M: shape …` 형태의 모든 기본 메서드가 `my-shape`에 대해 자동으로 디스패치되고, `shape`를 요구하는 코드는 모두 `my-shape`를 받아들여요. `M:`은 제네릭에 메서드를 추가할 때 쓰고, `INSTANCE:`는 클래스를 믹스인에 합류시킬 때 써요.

## `TYPED::`로 일반 단어의 입력 검사하기

`GENERIC:`/`M:`은 인자의 클래스에 따라 메서드를 골라요. 때로는 디스패치가 필요 없고, 입력이 특정 클래스임을 요구하는 *하나의* 단어만 있으면 될 때가 있어요. `TYPED::`는 (`typed` 보카블러리에 있는) 각 입력 이름 뒤에 클래스를 적는 `::`예요.

```factor
TYPED:: triple ( n: integer -- m )
    n 3 * ;

14 triple .   ! => 42
```

`n: integer`는 이미 쓰고 있는 로컬에 클래스를 콜론 뒤에 붙여 쓴 형태로 읽혀요. 디스패치는 없어요. 정의 하나에 동작 하나죠. 하지만 이제 각 인자는 자기 클래스에 대해 검사돼요. `"x" triple` 같은 불일치는 조용히 통과되지 않고 거부돼요(*expected input value of type integer but got string*).

출력에도 같은 방식으로 타입을 표시할 수 있어요. `yes?`는 입력과 결과 모두에 타입을 붙여요.

```factor
TYPED:: yes? ( word: string -- answer: boolean )
    word "yes" = ;

"yes" yes? .   ! => t
"no" yes? .    ! => f
```

## 수학 함수와 상수

이 연습 문제는 여기서 처음 보게 될 `math.constants`와 `math.functions`의 몇 가지 단어에도 의존해요.

- `pi`: `math.constants`에 있는 상수 π예요.
- `sin ( x -- y )`, `cos ( x -- y )`: 라디안 단위 각도의 사인과 코사인.
- `e^ ( x -- y )`: `e`를 `x` 제곱한 값이에요. (임의의 밑을 쓰려면 `^`를 사용해요.)

```factor
pi 2 / sin   ! → 1.0
0 cos        ! → 1.0
1 e^         ! → 2.718281828459045
```
