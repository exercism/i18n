# 소개

Rust에서는 [`Iterator`](https://doc.rust-lang.org/stable/std/iter/trait.Iterator.html) 트레이트를 구현하는 모든 타입을 이터레이터로 다룰 수 있어요.
Rust에 내장된 [`collections`](https://doc.rust-lang.org/std/collections/index.html)는 `iter`, `iter_mut`, `into_iter` 메서드를 통해 이터레이터로 변환할 수 있어요.
이터레이터에는 `collect`, `map`, `filter`, `fold`처럼 데이터를 원하는 대로 다룰 수 있는 [강력한 메서드](https://doc.rust-lang.org/stable/std/iter/trait.Iterator.html#provided-methods)가 다양하게 있어요.

```rust
use std::collections::HashMap;

let v = vec![0, 1, 2];

let mut iter = v.iter();

// Call next() to return the next value
assert_eq!(Some(&0), iter.next());
assert_eq!(Some(&1), iter.next());
assert_eq!(Some(&2), iter.next());
// Ahen None once it's over
assert_eq!(None, iter.next());

// Loop over iterators with built-in methods, such as `map` and `collect`
let w: HashMap<_, _> = v.into_iter().map(|x| (x, x + 1)).collect();
println!("{w:?}");
// => {1: 2, 0: 1, 2: 3}
```
