# Java 설치하기

Exercism CLI와 즐겨 쓰는 텍스트 에디터에 더해, Exercism에서 Java 연습 문제를 풀려면 **Java Development Kit**(JDK)가 필요해요. JDK에는 Java 런타임과 개발 도구(가장 중요한 것으로 Java 컴파일러)가 모두 들어 있어요.

요즘에는 다양한 JDK 배포판이 있고, 그중에는 오픈 소스인 것도 있어요. 여기 Exercism에서는 [Eclipse Temurin by Adoptium][adoptium]을 사용하기를 권장해요.

## 지원하는 Java 버전

Exercism의 Java 트랙은 Java 25 LTS와 그 이전 버전을 지원해요.

## Eclipse Temurin 설치하기

Eclipse Temurin을 시스템에 설치하려면 훌륭한 [설치 안내][adoptium-installation-guide]를 한번 살펴봐요. 여기에서 즐겨 쓰는 패키지 관리자로 JDK를 설치하는 방법을 찾을 수 있고, 주요 운영 체제별로 내려받을 수 있는 설치 프로그램 링크도 있어요.

## Java IDE

Java에는 무료 IDE가 많이 있어요. 그중 인기 있는 것들은 다음과 같아요:

- [IntelliJ IDEA Community Edition][intellij-idea]
- [Eclipse][eclipse]
- [Java 확장 기능을 설치한 Visual Studio Code][vscode-java]
