# 소개

`OpenStruct`를 사용하면 `Hash`로 객체를 쉽게 만들 수 있어요.
`Hash` 키로 접근해야 하는 대신, `OpenStruct`에서는 메서드로 값에 접근하고 설정할 수 있어요.


```ruby
attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

이 방식의 또 한 가지 장점은 블록 문법을 사용할 때 단축 표현을 활용할 수 있다는 점이에요.
블록이 메서드 하나만 호출하는 경우에는, 블록을 `&:` 뒤에 메서드 이름을 붙인 형태로 바꿀 수 있어요.
예를 들어, 다음 두 줄은 같은 의미예요:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```

## 표준 라이브러리

지금까지 연습 문제에서 본 모든 클래스는 Ruby의 코어 라이브러리에 속해 있었어요.

OpenStruct는 Ruby의 표준 라이브러리(흔히 "stdlib"라고 줄여 불러요)에 속해요. 날짜, JSON, 네트워킹 같은 것을 다루기 위한 클래스 모음이죠.
코드를 더 다루기 쉽게 만들어 주는 유용한 기능도 제공해요.

코어 라이브러리에 없는 클래스, 예를 들어 다른 파일에 있는 직접 작성한 코드나 stdlib의 클래스, 외부 의존성을 사용할 때는 `require` 메서드로 가져와야 사용할 수 있어요.
예를 들어:

```ruby
require 'ostruct'

person = OpenStruct.new(name: "Jeremy Walker")
# ...
```
