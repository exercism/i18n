# 지시 사항

라몬트는 자기만의 비디오 게임을 만들고 싶어 하는 리스프 외계인이에요. 라몬트가 도움을 요청한 작업 중 하나는 최고 점수 목록을 관리하는 일이에요.

## 1. 최고 점수 테이블 만들기

인자를 전혀 받지 않고 비어 있는 새로운 해시 테이블로 평가되는 함수 `make-high-score-table`을 정의해요:

```lisp
(make-high-score-table) ; => #<HASH-TABLE :TEST EQL :COUNT 0 {1005A90103}>
```

## 2. 테이블에 플레이어 추가하기

테이블에 플레이어를 추가하려면 두 개의 인자를 받는 함수 `add-player`를 정의해요:
- 최고 점수 테이블
- 키워드로 된 플레이어의 이름

플레이어의 초기 점수는 0으로 설정해요.

```lisp
(add-player hash-table :louis) ; => 0
(add-player hash-table :lilly) ; => 0
```

## 3. 플레이어의 점수 설정하기

플레이어의 점수를 설정하려면 세 개의 인자를 받는 함수 `set-score`를 정의해요:
- 최고 점수 테이블
- 키워드로 된 플레이어의 이름
- 정수로 된 플레이어의 점수

```lisp
(set-score hash-table :louis 1234) ; => 1234
```

## 4. 테이블에서 점수 가져오기

테이블에서 플레이어의 점수를 가져오려면 두 개의 인자를 받는 함수 `get-score`를 정의해요:
- 최고 점수 테이블
- 키워드로 된 플레이어의 이름

이 함수는 플레이어에 대해 저장된 점수로 평가되어야 해요.
그 플레이어에 대해 저장된 점수가 없거나, 그 플레이어가 아직 테이블에 없다면 `0`으로 평가해요.

```lisp
(get-score hash-table :louis)                         ; => 1234
(get-score hash-table :lilly)                         ; => 0
(get-score hash-table :not-a-character-in-this-story) ; => 0
```

## 5. 테이블에서 플레이어 제거하기

최고 점수 테이블에서 플레이어를 제거하려면 두 개의 인자를 받는 함수 `remove-player`를 정의해요:
- 최고 점수 테이블
- 키워드로 된 플레이어의 이름

이 함수는 플레이어가 아직 테이블에 추가되지 않은 경우도 문제없이 처리해야 해요.
플레이어를 제거한 뒤에 테이블에서 그 플레이어의 점수를 가져오면 당연히 0이 돼요.

```lisp
(set-score hash-table :louis 1234)           ; => 1234
(remove-player hash-table :louis)            ; => T
(get-score hash-table :louis)                ; => 0

(remove-player hash-table :not-in-the-table) ; => NIL
```
