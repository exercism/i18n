# 지침

이 연습 문제에서는 저축 계좌를 다뤄요.
매년 저축 계좌의 잔액은 이자율에 따라 갱신돼요.
은행이 적용하는 이자율은 계좌에 있는 금액(잔액)에 따라 달라져요:

- 잔액이 `0`달러보다 작으면 3.213%예요(잔액이 더 음수가 돼요).
- 잔액이 `0`달러 이상 `1000`달러 미만이면 0.5%예요.
- 잔액이 `1000`달러 이상 `5000`달러 미만이면 1.621%예요.
- 잔액이 `5000`달러 이상이면 2.475%예요.

네 가지 과제가 있고, 각 과제에서는 잔액과 이자율을 다뤄요.

## 1. 이자율 계산하기

주어진 잔액을 기준으로 이자율을 계산하는 `interest_rate` 함수를 구현해요:

```cpp
interest_rate(200.75);
// => 0.5
```

## 2. 이자 계산하기

주어진 잔액을 기준으로 이자를 계산하는 `yearly_interest` 함수를 구현해요:

```cpp
yearly_interest(200.75):
// => 1.003750
```

## 3. 연간 잔액 갱신값 계산하기

이자율을 고려해 연간 잔액 갱신값을 계산하는 `annual_balance_update` 함수를 구현해요:

```cpp
annual_balance_update(200.75);
// => 201.75375
```

## 4. 목표 잔액에 도달하기까지 걸리는 연수 계산하기

매년 잔액에 이자가 더해진다는 점을 고려해, 목표 잔액에 도달하는 데 필요한 최소 연수를 계산하는 `years_until_desired_balance` 함수를 구현해요.
즉, 1년 후 잔액은 시작 잔액 + 시작 잔액에 대한 이자예요.
2년 후 잔액은 1년 후 잔액 + 1년 후 잔액에 대한 이자예요.
이런 식으로, 해당 연도의 잔액이 목표 잔액 이상이 될 때까지 반복해요.

```cpp
double balance {200.75};
double targetBalance {214.88};
years_until_desired_balance(balance, targetBalance)
// => 14
```

반환되는 값은 `int`라는 점에 유의해요.
