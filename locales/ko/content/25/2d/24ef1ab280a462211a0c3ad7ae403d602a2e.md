# 소개

## 인스턴스 변수

객체는 _인스턴스 변수_를 설정해서 자신만의 상태를 가질 수 있어요.
이 변수들은 객체 안에 존재하고, 보통 내부 상태를 저장하는 데 사용해요.

인스턴스 변수는 항상 `@`로 시작해요.
`@`로 시작하는 변수를 설정해서 새로운 인스턴스 변수를 만들 수 있어요.
예를 들어볼게요:

```ruby
class Repeater
  def hear(something)
    # Save what's been heard into a new instance variable called @heard
    @heard = something
  end

  def repeat
    # Return the value of the instance variable
    @heard
  end
end

repeater = Repeater.new
repeater.hear("Hello, friend!")
print repeater.repeat # Prints "Hello, friend!"
```

객체는 보통 `initialize` 메서드에서 초기 상태를 설정하는데, 이 메서드는 클래스에서 `new`를 호출할 때 자동으로 호출돼요.

```ruby
class Airplane
  def initialize
    @wings = 2
  end

  def wings
    @wings
  end
end

plane = Airplane.new
plane.wings # returns 2
```

`initialize` 메서드는 인자를 받을 수도 있어서, 각 인스턴스가 원하는 상태로 시작할 수 있어요:

```ruby
class Suitcase
  def initialize(locked)
    @locked = locked
  end
end
```

_인스턴스_ 변수는 외부에서 읽거나 쓰지 못하도록 private으로 취급하는 게 좋아요.
대신 값을 가져오고 설정하는 메서드를 정의해요.
예를 들어볼게요:

```ruby
class Suitcase
  def initialize
    @locked = false
  end

  def locked? # Query methods should be named with a trailing `?`
    @locked
  end

  def lock! # Methods which mutate state should have trailing `!`
    @locked = true
  end
end

suitcase = Suitcase.new
suitcase.locked? # false
suitcase.lock!
suitcase.locked? # true
```

## Nil

[Nil][nil-dictionary]은 "아무것도 없음" 또는 "0"을 뜻하는 영어 단어예요.
Ruby에서 `nil`은 객체의 _부재_를 표현할 때 사용해요.
다른 프로그래밍 언어에서는 `null`이나 `none` 값이 비슷한 역할을 하기도 해요.

```ruby
# I do not have a favorite color
favorite_color = nil
```

Ruby는 인스턴스 변수가 처음 등장했을 때, 다른 값이 주어지기 전까지는 기본값으로 `nil`을 줘요.

```ruby
print @favourite_color # prints nil
@favourite_color = "blue"
print @favourite_color # prints "blue"
```
