# 소개

## 배열

PHP의 배열은 순서가 있는 맵이에요.
맵은 키를 값에 연결하는 데이터 구조예요.
배열은 다재다능해서 `C`나 `Java`에서처럼 선형 배열로, 또는 리스트 [vector], 해시 테이블, 딕셔너리, 컬렉션, 스택, 큐로 다룰 수 있어요.

키는 선택 사항이지만, 지정한다면 `int`나 `string`이어야 해요.
키를 제공하지 않으면 PHP는 `0`부터 시작해서 커지는 순서의 정수 키를 기본으로 사용해요.

```php
$no_keys = ["my", "first", "array"];
$integer_keys = [0 => "my", 1 => "first", 2 => "array"];

$no_keys == $integer_keys // => equal returns true
$no_keys === $integer_keys // => strictly equal returns true
```

배열은 모든 타입의 값을 저장할 수 있어요.
값마다 타입이 달라도 괜찮아요.

### 배열 사용하기

배열은 리터럴로 선언하거나(위에서처럼 코드에 직접 작성하는 방식), 함수로 만들어서 다룰 수 있어요.
인덱스 연산자로 값을 접근하고, 할당하고, 추가해요:

```php
$prime_numbers = [2, 3, 5, 6];

$prime_numbers[3] = 7; // replace 6 with 7

$prime_numbers[] = 11; // array now contains [2, 3, 5, 7, 11]
```

## 가변 길이 인자

함수 인자는 개수에 상관없이 여러 인자를 받을 수 있도록 지정할 수 있어요:

```php
<?php

function actOnItems(...$items) {
  // $items is an array containing 0 or more values
  // used to call the function.
}

actOnItems(1, 2, 3, 4); // $items => [1, 2, 3, 4]
```
