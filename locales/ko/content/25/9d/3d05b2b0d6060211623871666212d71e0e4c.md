# 지침

정원에 찾아오는 새가 몇 마리인지 매일 세고 있어요. 데이터는 정수 배열로 저장되는데, **오늘의 수가 맨 앞에** 있어요.

## 1. 오늘의 수

`today`는 스택에서 일별 수 배열을 꺼내 오늘의 수를 반환하고, 배열이 비어 있으면 `f`를 반환하도록 정의해요.

```factor
{ 2 5 1 } today .
! => 2

{ } today .
! => f
```

## 2. 오늘의 수 늘리기

`increment-day-count`는 오늘의 수를 하나 늘린 새로운 배열을 반환하도록 정의해요. 입력이 비어 있으면 `{ 1 }`을 반환해요.

```factor
{ 4 0 2 } increment-day-count .
! => { 5 0 2 }

{ } increment-day-count .
! => { 1 }
```

## 3. 새가 한 마리도 없던 날이 있었나요?

`has-day-without-birds?`는 새가 0마리 기록된 날이 하나라도 있으면 `t`를, 그렇지 않으면 `f`를 반환하도록 정의해요.

`any?`나 다른 고차 시퀀스 단어 대신 **재귀를 사용해요**.

```factor
{ 2 0 4 } has-day-without-birds? .   ! => t
{ 3 8 1 5 } has-day-without-birds? . ! => f
```

## 4. 지금까지 세어 온 새의 총합

`total`은 모든 수의 합을 반환하도록 정의해요.

`sum` 대신 **재귀를 사용해요**.

```factor
{ 4 0 9 0 5 } total .
! => 18
```

## 5. 바쁜 날

바쁜 날은 새가 다섯 마리 이상인 날이에요. `busy-days`는 바쁜 날의 수를 반환하도록 정의해요.

`count` 대신 **재귀를 사용해요**.

```factor
{ 4 5 0 0 6 } busy-days .
! => 2
```
