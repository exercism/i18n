# 테스트 실행하기

테스트를 컴파일하고 실행하려면 연습 문제 디렉터리에서 다음을 실행해요:
```bash
$ ponyc
$ ./exercise-name
```

(`exercise-name`을 연습 문제 디렉터리 이름으로 바꿔 주세요)

컴파일된 바이너리는 Main 액터에서 테스트를 실행하니, 바이너리를 실행해서 테스트가 통과했는지 확인해 봐요. Pony는 컴파일 시점에 모든 코드를 검사하기 때문에, 필요한 코드를 작성하기 전까지는 테스트가 컴파일되지 않을 수도 있어요. 컴파일되지 않는 테스트는 각 줄을 `//`로 시작해서 주석 처리할 수 있어요. 그런 다음 그 테스트를 작업할 준비가 되면 주석을 해제하면 돼요.
