# 자세히 알아보기

[튜플](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples)은 이름은 없지만 순서가 있는 값들을 _불변_으로 묶은 것이에요.
튜플은 다른 튜플을 포함해 어떤 데이터 타입이든 (또는 여러 개를) 담을 수 있어요.

튜플은 `(`와 `)` 사이에 쉼표로 구분한 값들로 정의해요: `(<element_1>, ... , <element_n>)`.

```fsharp
("one", 2) // Tuple pair (2 values)
("one", 2, true) // Tuple triplet (3 values)
```

길이와 타입이 (순서까지) 같은 튜플끼리만 비교할 수 있어요.
튜플은 구조적 동등성을 가져요. 즉, _오직_ 모든 값이 같을 때만 서로 같아요.

```fsharp
(1, 2) = (1, 2) // Same length, same types, same values, same order
// => true

(1, 2) = (2, 1) // Same length, same types, same values, different order
// => false

(1, 2) = (1, "2") // Same length, different types
// compiler error

(1, 2) = (1, 2, 3) // Different length
// compiler error
```

[튜플에서 값을 꺼내는 방법](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples#obtaining-individual-values)에는 세 가지가 있어요:

- `fst`와 `snd` 함수
- 튜플 분해
- 패턴 매칭

```fsharp
let person = ("Jordan", 170)

// Option 1: fst/snd
let name1 = fst person
let length1 = snd person

// Option 2: deconstruction
let (name2, length2) = person

// Option 3: pattern matching
match person with
| name3, length3 -> printf "%s: %d" name3 length3
```

~~~~exercism/note
엄밀히 말하면 `.Item1`, `.Item2`, ... 속성으로 튜플의 값에 접근할 수 있지만, 이는 권장되지 않고 컴파일러 경고가 발생해요.
~~~~

## 튜플의 핵심 포인트

튜플에 대해 알아두면 좋은 핵심은 다음과 같아요:

- 튜플 타입의 특정 인스턴스는 하나의 객체예요. 예를 들어 C#의 요소 두 개짜리 배열과 비슷해요. 함수에 넘길 때도 하나의 매개변수로 취급돼요. 유일한 예외는 여러 매개변수를 받는 F#이 아닌 코드를 호출할 때인데, 이때는 튜플을 넘기면 그 값들이 해당 매개변수 값으로 자동으로 풀려요.
- 튜플 타입에는 명시적인 이름을 붙일 수 없어요. 튜플 타입의 “이름”은 서로 곱해진 타입들의 조합으로 결정돼요.
- 튜플을 정의하는 결정적인 기호는 괄호가 아니라 쉼표예요. 가끔 헷갈릴 수 있지만 괄호 없이도 튜플을 정의할 수 있어요. F#에서 쉼표가 보이면 대개 튜플의 일부예요.
- 튜플은 함수의 인자로도, 함수의 반환 값으로도 쓸 수 있어요.
