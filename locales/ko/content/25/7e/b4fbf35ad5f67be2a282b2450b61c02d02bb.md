# 지침

리습 외계인들이 처음 지구에 왔을 때, 그들은 이루 헤아릴 수 없이 기묘하고 멋진 것들을 만났어요. 그런데 그들이 가장 좋아한 발견 중 하나는 바로 "반려동물"이었어요. 솔직히 말해 봐요, 어떤 외계인이라면 강아지나 새끼 고양이를 보고 감탄하지 않겠어요?

Ludwig는 최근 지구로 휴가를 다녀온 뒤, 자신만의 반려동물을 키우기로 마음먹었어요! 문제가 하나 있다면? 선택지가 너무나 많다는 거예요! 혹시 프로그램을 하나 작성해서, Ludwig가 다음에 맞이할 포근한 친구를 찾고 돌볼 수 있도록 도와줄 수 있을까요?

## 1. 친구 고르기

Ludwig는 반려동물을 키우기로 마음은 굳혔지만, 생각을 정리한 건 거기까지예요. 그렇다면 첫 단계는 어떤 종류의 반려동물을 키울지 정하는 거예요!

Ludwig는 자신의 성격을 잘 보완해 줄 친구를 찾고 싶어 해요. 어떤 성격 특성(키워드)을 받아서, 그 특성을 가진 반려동물의 종류(문자열)를 반환하는 `pal-picker`라는 함수를 Ludwig를 위해 작성해 줄 수 있을까요?

구체적으로는 다음과 같아요:

- `:lazy` -> `"Cat"`
- `:energetic` -> `"Dog"`
- `:quiet` -> `"Fish"`
- `:hungry` -> `"Rabbit"`
- `:talkative` -> `"Bird"`

그 밖의 알 수 없는 성격에 대해서는 함수가 다음 값으로 평가되어야 해요: `"I don't know... A dragon?"`

```lisp
(pal-picker :quiet) ; => "Fish"
```

## 2. 자연 서식지에서

이제 Ludwig에게 새 친구가 생겼으니, 머물 곳도 필요해요! Ludwig가 반려동물에게 맞는 크기의 침대나 수조, 우리를 고를 수 있도록 도와줄 수 있을까요?

여기서 Ludwig에게는 반려동물의 몸무게(킬로그램, 정수)를 바탕으로 알맞은 서식지 크기(키워드)를 고르는 `habitat-fitter`라는 함수가 필요해요.

크기별로 반려동물에게 필요한 서식지는 다음과 같아요:

- 40kg 이상 -> `:massive`
- 20kg에서 39kg까지(포함) -> `:large`
- 10kg에서 19kg까지(포함) -> `:medium`
- 1kg에서 9kg까지(포함) -> `:small`
- 0kg 이하 -> `:just-your-imagination`

```lisp
(habitat-fitter 42) ; => :MASSIVE
```

## 3. 이제 식사할 시간

지구의 모든 반려동물에게 공통된 한 가지는 바로 먹이가 필요하다는 점이에요! 하지만 Ludwig에게 이 개념은 다소 낯설어요. 먹이그릇을 채워 주는 걸 자꾸 잊어버리기 때문이에요.

Ludwig는 그릇을 다시 채워야 할 때를 알려 줄 `feeding-time`이라는 간단한 함수가 있으면 좋겠어요. 이 함수는 배부른 정도(정수, 퍼센트)를 받아서 문자열 형태의 메시지를 반환해요.

먹이 양이 다음과 같다면:

- 20% 초과 -> `"All is well."`
- 20% 이하 -> `"It's feeding time!"`

```lisp
(feeding-time 15) ; => "It's feeding time!"
```

## 4. 행동 수칙

기본적인 것들을 모두 정리했으니, Ludwig는 "쓰다듬기"와 "공 가져오기 놀이" 같은 신나는 활동들을 해 보고 싶어 해요. 그렇다고 해서 모든 반려동물이 이런 활동에 어울리는 건 아니에요.

Ludwig는 반려동물의 종류(문자열)를 받아서, 행동이 어울리지 않으면 아무것도 반환하지 않거나 `"Maybe not with this pet..."` 같은 메시지를 반환하는 `pet`과 `play-fetch` 두 함수를 원해요.

`"Dog"`만 공 가져오기 놀이를 하고, `"Fish"`를 제외한 모든 반려동물은 쓰다듬을 수 있다고 가정해요.

```lisp
(pet "Dog")         ; => NIL
(play-fetch "Fish") ; => "Maybe not with this pet..."
```
