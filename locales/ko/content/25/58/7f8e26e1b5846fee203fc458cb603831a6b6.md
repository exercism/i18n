# 지침

지역 농구팀의 웹사이트를 유지 관리하기 위해 웹 개발팀과 함께 일하고 있어요. 웹 개발팀은 Elixir에 익숙하지 않아서, 빠른 개발을 위해 중첩된 맵에서 데이터를 추출할 수 있는 함수를 부탁했어요.

## 1. 중첩된 맵 구조에서 데이터 추출하기

`extract_from_path/2` 함수를 구현해요. 이 함수는 두 개의 인자를 받아요:

- `data`: 농구팀에 대한 데이터가 담긴 중첩된 맵 구조예요.
- `path`: 마지막 키에 연결된 값을 얻기 위해 마침표로 구분된 키로 이루어진 문자열이에요.

경로 상의 어느 지점에서든 값이나 키가 존재하지 않으면 `nil`을 반환해야 해요

```elixir
data = %{
  "team_mascot" => %{
    "animal" => "bear",
    "actor" => %{
      "first_name" => "Noel"
    }
  }
}

BasketballWebsite.extract_from_path(data, "team_mascot.animal")
# => "bear"
BasketballWebsite.extract_from_path(data, "team_mascot.colors")
# => nil
```

이 함수를 구현할 때는 _Access Behaviour_를 사용해요.

중첩된 맵 데이터 구조를 다룰 때는 `Map`이나 `Kernel` 모듈의 함수를 사용하지 마세요.

## 2. 포함된 함수를 사용해 리팩터링하기

코드를 리뷰하던 동료가 여러분의 구현과 아주 비슷한 일을 하는 `Kernel` 모듈 함수를 알려줘요.

`get_in_path/2`를 이 `Kernel` 모듈 함수를 사용하도록 구현해요.

기대하는 인자는 1번과 같아요.

```elixir
BasketballWebsite.get_in_path(data, "team_mascot.actor.first_name")
# => "Noel"
```
