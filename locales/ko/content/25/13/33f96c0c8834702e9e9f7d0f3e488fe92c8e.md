# 지시사항

이 연습 문제에서는 지역 뉴스 방송국에서 사용할 날씨 리포트를 만들어요.

## 날씨 리포트 만들기

몇 가지 스텁 함수와 다음 enum으로 시작해요:

```rust
#[derive(Drop, Clone, PartialEq, Debug)]
pub enum WeatherCondition {
    Sunny,
    Rainy,
    Cloudy,
    Stormy
}
```

`"Today is <CONDITION> with a temperature of <TEMPERATURE> degrees Celsius."` 형식으로 날씨 리포트를 만들어야 해요.
올바른 날씨 상태를 출력하는 함수를 구현하면 돼요.

예를 들어, 아래 코드는 비 오는 날 `get_weather_report` 함수가 반환해야 하는 결과를 보여줘요.

```rust
get_weather_report(WeatherCondition::Rainy, "25")
// Returns: "Today is RAINY with a temperature of 25 degrees Celsius."
```

맑은 날에는 이렇게 나와요:

```rust
get_weather_report(WeatherCondition::Sunny, "30")
// Returns: "Today is SUNNY with a temperature of 30 degrees Celsius."
```
