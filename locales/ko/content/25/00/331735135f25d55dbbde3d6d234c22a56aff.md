# 소개

C# 문자열에서 가장 기억해야 할 점은, 문자열이 유니코드 문자(글자, 숫자, 문장 부호 등)의 나열을 나타내는 변경할 수 없는 객체라는 거예요. `string` 인스턴스를 정의할 때는 큰따옴표를 사용해요:

```csharp
string fruit = "Apple";
```

문자열을 조작하려면 문자열의 [메서드][methods]나 [속성][properties]을 호출하면 돼요. 문자열 값은 한 번 정의되고 나면 절대 바뀌지 않기 때문에, 문자열을 조작하는 모든 메서드는 새로운 문자열을 반환해요.

문자열은 큰따옴표(`"`) 문자로 구분해요. 일부 특수 문자는 백슬래시(`\`) 문자를 사용해 [이스케이프][escaping]해야 해요. 문자열 앞에 at(`@`) 기호를 붙일 수도 있는데, 이렇게 하면 이스케이프 문자를 무시하는 [축자 문자열][verbatim]이 돼요.

```csharp
string escaped = "c:\\test.txt";
string verbatim = @"c:\test.txt";
escaped == verbatim;
// => true
```

문자열의 일부만 필요하다면 [`Substring()` 메서드][substring]로 그 부분만 추출할 수 있어요:

```csharp
string sentence = "Frank chases the bus.";
string name = sentence.Substring(0, 5);
// => "Frank"
```

[`IndexOf`() 메서드][indexof]를 사용하면 `string` 안에서 `string`이 처음 나타나는 위치를 찾을 수 있고, 지정한 값을 찾지 못하면 `-1`을 반환해요:

```csharp
"continuous-integration".IndexOf("integration")
// => 11

"continuous-integration".IndexOf("deployment")
// => -1
```

마지막으로, [문자열을 연결하는 방법에는 여러 가지][concatenation]가 있어요. 가장 간단한 방법은 [`+` 연산자][plus-operator]를 사용하는 거예요.

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

단순한 연결보다 더 복잡한 문자열 서식이 필요하다면 [문자열 보간][interpolation]을 사용하는 게 좋아요. 문자열에서 보간을 사용하려면 문자열 앞에 달러(`$`) 기호를 붙여요.

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
