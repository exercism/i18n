## 테스트 실행하기

1. PHP 연습 문제 디렉터리의 루트로 이동해요. 이 디렉터리는 `<EXERCISM_WORKSPACE>/php`예요.
   Exercism 워크스페이스를 찾으려면 다음을 실행해요.

   ```shell
   exercism workspace
   ```

2. 아직 [PHPUnit]이 없다면 설치해요.
3. 다음 명령으로 테스트를 실행해요:

   ```shell
   phpunit test_file.php
   ```

   예를 들어 Hello World 연습 문제의 테스트를 실행하려면 이렇게 해요:

   ```shell
   phpunit HelloWorldTest.php
   ```

[PHPUnit]: https://exercism.org/docs/tracks/php/installation#h-via-php-archive-phar
