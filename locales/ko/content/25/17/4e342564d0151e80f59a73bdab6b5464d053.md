# 비트 조작 소개

Java에는 `byte`, `short`, `int`, `long`, `char`의 비트를 조작하는 연산자가 있어요.

## 시프트 연산자

비트를 왼쪽으로 시프트하려면 `<<`를, 오른쪽으로 시프트하려면 `>>`를 사용해요.

```java
// Shift two places to the left
0b0000_1011 << 2;
// # => 0b0010_1100

// Shift two places to the right
0b0000_1011 >> 2;
// # => 0b0000_0010
```

`<<` 연산자는 항상 오른쪽에 0을 넣어요.
반면에 `>>`는 가장 왼쪽 비트와 같은 비트를 넣어요 (수가 음수면 1, 양수면 0).

```java
// Shift 2 places to the right preserves the sign
// This is a negative value, whose binary representation is
// 1000_0000_0000_0000_0000_0000_0010_0110
int value = -0x7FFFFFDA;

// Shift two places to the right, preserving the sign bit
value >> 2;
// # => 1110_0000_0000_0000_0000_0000_0000_1001
```

오른쪽으로 시프트할 때 0을 넣어야 한다면 대신 `>>>`를 사용해요.

```java
// Shift two places to the right, inserting 0s on the left
value >>> 2;
// # => 0010_0000_0000_0000_0000_0000_0000_1001
```

## 비트 연산

### 비트 AND

비트 AND(`&`) 연산자는 두 값을 받아 각 비트마다 AND를 수행해요.
첫 번째 값의 각 비트를 두 번째 값의 같은 위치에 있는 비트와 비교해요.
둘 다 1이면 결과 비트는 1이에요.
그렇지 않으면 결과 비트는 0이에요.

```java
0b0110_0101 & 0b0011_1100;
// # => 0b0010_0100
```

### 비트 OR

비트 OR(`|`) 연산자는 두 값을 받아 각 비트마다 OR를 수행해요.
첫 번째 값의 각 비트를 두 번째 값의 같은 위치에 있는 비트와 비교해요.
둘 중 하나라도 1이면 결과 비트는 1이에요.
그렇지 않으면 0이에요.

```java
0b0110_0101 | 0b0011_1100;
// # => 0b0111_1101
```

### 비트 XOR

비트 XOR 연산자(`^`)는 두 값에 대해 비트 XOR을 수행해요.
비트 AND, 비트 OR 연산자와 마찬가지로, 첫 번째 값의 각 비트를 두 번째 값의 같은 위치에 있는 비트와 비교해요.
둘 중 하나만 1이면 결과 비트는 1이에요.
그렇지 않으면 0이에요.

```java
0b0110_0101 ^ 0b0011_1100;
// # => 0b0101_1001
```

### 비트 NOT(`~`)

마지막으로, 비트 NOT 연산자(`~`)는 각 비트를 뒤집어요.
앞의 연산자들과 달리 이 연산자는 하나의 값에만 작용하는 단항 연산자예요.

```java
~0b0110_0101;
// # => 0b1001_1010
```
