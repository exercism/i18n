# 추가 지침

## 힌트

[이중 연결 리스트](https://en.wikipedia.org/wiki/Doubly_linked_list)는 변경 가능한 자료 구조예요. F#은 함수형 우선 언어라서 보통 불변성을 더 선호하지만, 필요한 곳에서는 변경을 사용할 수 있게 해 주는 언어 기능도 있어요.

- `mutable` 키워드를 `let` 바인딩과 [레코드](https://docs.microsoft.com/en-us/dotnet/articles/fsharp/language-reference/records) 필드 앞에 붙이면, 이들에 새 값을 할당할 수 있어요.

- [클래스](https://fsharpforfunandprofit.com/posts/classes) 속성은 `set` 키워드로 속성 설정자를 지정하면 변경 가능하게 만들 수 있어요.

변경 가능한 바인딩은 `<-`로 다시 할당해야 해요

```fsharp
let mutable x = "initial value"
x <- "new value"
```
