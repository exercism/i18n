# 설명

이 연습 문제에서는 밴드 값을 일일이 외우지 않아도 되도록 도와주는 프로그램을 만들어 볼 거예요.
이 프로그램은 색 1개, 4개 또는 5개를 입력으로 받아 올바른 값을 ohms 단위로 출력해요.
색 밴드는 다음과 같이 인코딩돼요:

| 색          | 값    |
|-------------|-------|
| Black       | 0     |
| Brown       | 1     |
| Red         | 2     |
| Orange      | 3     |
| Yellow      | 4     |
| Green       | 5     |
| Blue        | 6     |
| Violet      | 7     |
| Gray        | 8     |
| White       | 9     |
|-------------|-------|

[`Resistor Color Trio`][resistor-color-trio-exercise]에서는 처음 세 개의 색 밴드를 해독했어요.
예를 들어 orange-orange-brown은 기준값 `330`으로 변환됐죠.
이번 연습 문제에서는 여기에 _허용 오차_까지 더해야 해요.
허용 오차는 값이 기준값보다 위아래로 벗어날 수 있는 최대치예요.
예를 들어 마지막 밴드가 green이면 최대 허용 오차는 `±0.5%`예요.

허용 오차 밴드는 다음 값 중 하나를 가져요:

| 색     | 허용 오차 |
|--------|----------:|
| Grey   | ±0.05%    |
| Violet | ±0.10%    |
| Blue   | ±0.25%    |
| Green  | ±0.50%    |
| Brown  | ±1.00%    |
| Red    | ±2.00%    |
| Gold   | ±5.00%    |
| Silver | ±10.00%   |
|--------|-----------|

4밴드 저항은 이렇게 구성돼요:

| 밴드 1  | 밴드 2  | 밴드 3     | 밴드 4    |
| ------- | ------- | ---------- | --------- |
| 값 1    | 값 2    | 배수       | 허용 오차 |

예시:

- orange-orange-brown-green은 `330` ohms이고 허용 오차는 `±0.5%`예요.
- orange-orange-red-grey는 `3300` ohms이고 허용 오차는 `±0.05%`예요.

4밴드 저항과 5밴드 저항의 차이는 5밴드 저항에는 더 정밀한 값을 나타내는 밴드가 하나 더 있다는 점이에요.

| 밴드 1  | 밴드 2  | 밴드 3  | 밴드 4     | 밴드 5    |
| ------- | ------- | ------- | ---------- | --------- |
| 값 1    | 값 2    | 값 3    | 배수       | 허용 오차 |

예시:

- orange-orange-orange-black-green은 `333` ohms이고 허용 오차는 `±0.5%`예요.
- orange-red-orange-blue-violet은 `323 million` ohms이고 허용 오차는 `±0.1%`예요.

1밴드 저항도 있어요.
1밴드 저항은 값이 0인 black 색만 가져요.

여러분의 프로그램은 저항 밴드 색으로 이루어진 입력 `list`를 다음과 같은 레이블로 변환해야 해요:

"... ohms ±...%"

따라서 `["orange", "orange", "black", "green"]` 같은 입력 `list`는 다음을 반환해야 해요:

"33 ohms ±0.5%"

값이 수천 ohms에 이르면 "kiloohms"라고 해요.
1000미터를 "킬로미터", 1000그램을 "킬로그램"이라고 하는 것과 비슷하죠.

따라서 `["orange", "orange", "orange", "grey"]` 같은 입력 `list`는 다음을 반환해야 해요:

"33 kiloohms ±0.05%"

값이 수백만 ohms에 이르면 "megaohms"라고 해요.

따라서 `["orange", "orange", "blue", "red"]` 같은 입력 `list`는 다음을 반환해야 해요:

"33 megaohms ±2%"
