# 지침

작은 역폴란드 표기법(RPN) 계산기를 만들고 있어요.
계산기의 상태는 Factor 배열로 표현되는 *값의 스택*이고,
*연산*은 그러한 스택을 받아 새로운 스택을 반환하는 quotation이에요.

```factor
{ 3 4 }   ! the calculator's stack: 3 is below 4
[ ... ]   ! an operation that consumes some values and pushes a result
```

## 1. 덧셈 구현하기

스택에서 맨 위의 두 값을 꺼내고, 그 합을 넣은 다음, 새로운 스택을
반환하도록 `add-op`을 정의해요.

```factor
{ 3 4 } add-op .
! => { 7 }

{ 1 2 3 4 } add-op .
! => { 1 2 7 }
```

## 2. 곱셈 구현하기

`multiply-op`도 같은 방식으로, 곱셈을 하도록 정의해요.

```factor
{ 3 4 } multiply-op .
! => { 12 }
```

## 3. 연산 하나 적용하기

데이터 스택에서 스택과 연산(quotation)을 꺼내서, 새로운 계산기
스택을 반환하도록 `apply-op`을 정의해요.

```factor
{ 3 4 } [ add-op ] apply-op .
! => { 7 }
```

## 4. 프로그램 평가하기

시작 스택과 연산들의 배열을 받아서 각 연산을 차례대로 적용하고,
최종 스택을 반환하도록 `evaluate`를 정의해요.

```factor
{ 3 4 5 } { [ add-op ] [ multiply-op ] } evaluate .
! => { 27 }
```

## 5. 이름으로 평가하기

이제 프로그램은 *연산자 이름*(문자열)의 목록이고, 계산기는 이름을
연산에 대응시키는 assoc에서 각 이름을 찾아봐요.

시작 스택, 이름 붙은 연산들의 assoc, 이름들의 배열을 받아서
최종 스택을 반환하도록 `evaluate-named`를 정의해요.

```factor
{ 3 4 5 } H{ { "+" [ add-op ] } { "*" [ multiply-op ] } } { "+" "*" }
evaluate-named .
! => { 27 }
```

## 6. 안전하게 나누기

진짜 계산기는 0으로 나누라는 요청을 받았을 때 조용히 엉터리 값을
내놓아서는 안 돼요. 오류 클래스 `zero-divisor-error`는 이미
정의되어 있어요. `add-op`과 `multiply-op`과 비슷하게 `divide-op`을
구현하되, 스택 맨 위의 제수가 `0`일 때는 새로운 `zero-divisor-error`를
`throw`해요.

```factor
{ 12 4 } divide-op .
! => { 3 }

{ 1 5 6 2 } divide-op .
! => { 1 5 3 }

{ 5 0 } divide-op
! throws zero-divisor-error
```
