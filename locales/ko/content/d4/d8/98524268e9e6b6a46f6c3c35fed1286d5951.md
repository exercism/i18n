# 지침

이미 포화 상태인 시장에서 다른 서비스와 차별화하려는 새로운 택시 서비스에 막 입사했어요. 이를 위해 CEO는 맨해튼에서 초호화 서비스를 제공하기로 했어요. 모든 교차로에 안내원을 두어 승객이 타기 전과 내린 후를 돕는 방식이에요. 이제 이 서비스의 운영을 돕는 코드를 작성해야 해요.

## 1. 간단한 복소수

CEO는 맨해튼의 도로가 주로 격자 모양이라는 점에서, 복소수가 거리 교차로를 나타내는 편리한 방법이라고 결정했어요. 여기서 양수와 음수 실수는 각각 동쪽과 서쪽을, 양수와 음수 허수는 각각 북쪽과 남쪽을 나타내요.

R에서 복소수를 만드는 방식은 좀, 음... 독특하기 때문에, 간단한 복소수 함수를 구현하라는 지시를 받았어요.

정수 `a`와 `b`를 받는 `simplex(a, b)` 함수를 구현해요.
복소수 `a+bi`를 반환해요.

```r
simplex(1, 1)
#> 1+1i

simplex(-3, 4)
#> -3+4i
```

## 2. 운전기사 방향 구하기

고객이 목적지 교차로를 알려주면, 운전기사는 거기까지 가는 방법에 대한 안내를 받아요.
이 안내는 복소수 형태로 주어지는데, 실수부는 북쪽/남쪽으로 몇 블록 가야 하는지를, 허수부는 동쪽/서쪽 거리를 나타내요.
표준 나침반에 맞추기 위해, 프로젝트 매니저는 북쪽을 양의 허수 방향으로, 남쪽을 음의 허수 방향으로 정했어요.
마찬가지로 동쪽은 양의 실수 방향이고, 서쪽은 음의 실수 방향이에요.

출발 교차로 좌표 `start`와 목적지 좌표 `end`를 받는 `driver_directions(start, end)` 함수를 구현해요.
운전기사가 동쪽/서쪽으로, 그리고 북쪽/남쪽으로 몇 블록 가야 하는지를 나타내는 복소수를 반환해요.

```r
driver_directions(0+0i, 7+5i)
#> 7+5i

driver_directions(-2+3i, 4-5i)
#> 6-8i
```

## 3. 맨해튼 거리 구하기

고객은 택시가 이동해야 하는 거리에 대한 요금을 내요.
맨해튼의 도로는 격자 모양이라서, 택시는 이 경로를 따라서만 다닐 수 있어요.
이런 구조 때문에 격자 선을 따라가야만 하는 거리 측정 방식이 생겨요.
이 거리는 지나간 선의 개수나 도착한 교차로의 개수(즉, 출발 교차로는 세지 않아요)를 더해서 구할 수 있어요.
이 측정값을 흔히 맨해튼 거리 또는 L1 노름이라고 불러요.

`start`와 `end` 교차로를 받는 `manhattan(start, end)` 함수를 구현해요.
`start`와 `end` 교차로 사이의 맨해튼 거리를 반환해요.

```r
manhattan(0+0i, 3+4i)
#> 7

manhattan(-2-3i, -1+1i)
#> 5
```

## 4. "까마귀가 날아가는 거리" 구하기

CEO는 이 서비스가 초호화일 뿐만 아니라 친환경적이라고 강조해서 투자 은행들을 설득했어요. 교차로에 있는 안내원들 사이에서 메시지를 나르는 데 훈련된 까마귀를 쓸 거라서요(안내원들은 맞춤형 경험을 위해 승객 정보를 전달해요).
투자 은행가들은 이것이 도대체 왜 환경 친화적인지, 심지어 어떤 CEO가 여가 시간에 까마귀 훈련을 즐기는지 알아보려고 실사를 할 생각을 전혀 하지 않은 것 같아요. 왜냐하면 투자금은 계속 밀려들고 있으니까요.

이 서비스도 이동한 거리에 따라 요금을 받아요.
하지만 까마귀는 날 수 있어서 격자 도로망을 따를 필요가 없고 최단 경로로 갈 수 있어요.
물론 거대한 고층 빌딩이 있으면 얘기가 다를 수 있지만, CEO는 까마귀가 낮은 건물 위를 쉽게 날아갈 수 있는 캔자스주 맨해튼(일명 "작은 사과")에 이 서비스를 넣으려고 해요.
캔자스주 맨해튼에서 이런 서비스에 대한 잠재 수요가 얼마나 될지, 그리고 이 많은 새가 머리 위를 날아다니는 것을 지역 보행자들이 어떻게 느낄지는 나중에 생각할 문제예요.

`start`와 `end` 교차로를 받는 `as_crow_flies(start, end)` 함수를 구현해요.
두 교차로 사이의 까마귀가 날아가는 거리를 반환해요.

```r
as_crow_flies(0+0i, 3+4i)
#> 5
```

## 5. 까마귀 방향 구하기

CEO는 까마귀에게 운전기사와 비슷한 종류의 방향을 따르도록 훈련시켰어요.
하지만 CEO는 남반구를 매우 좋아해서, 프로젝트 매니저가 시스템 나머지 부분에 쓰는 나침반과는 다른 나침반으로 까마귀를 훈련시켰어요.
CEO는 꽤 괴짜인 것 같아요.
CEO의 나침반은 북쪽이 음의 허수 방향이고 남쪽이 양의 허수 방향이에요.
이는 운전기사의 북쪽/남쪽 방향과 반대이고, 동쪽/서쪽은 그대로예요.

`start`와 `end` 교차로를 받는 `crows_directions(start, end)` 함수를 구현해요.
운전기사의 방향과 비슷하지만 북쪽/남쪽이 뒤집힌 복소수를 반환해요.

```r
driver_directions(0+0i, 7+5i)
#> 7-5i

driver_directions(-2+3i, 4-5i)
#> 6+8i
```
