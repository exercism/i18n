# 힌트

## 일반
- 변수의 [타입][types]은 변수에 담긴 값을 기준으로 정해져요: *10*은 `Int`, *'Hello'*는 `String`, *2.0*은 `double`이에요.

## 1. 예상 굽기 시간(분)을 상수로 정의하기

- 상수 변수를 정의하고 정수 값을 할당해야 해요.
- 상수는 [New-Variable cmdlet][new variable]을 통해 정의할 수 있어요.

## 2. 남은 굽기 시간(분) 계산하기

- 매개변수 하나를 받는 [함수][defining functions]를 정의해야 해요.
- 값을 빼려면 [뺄셈 수학 연산자][arithmetic]를 사용해요.
- 이 함수는 [값을 반환][return]해야 해요.

## 3. 준비 시간(분) 계산하기

- 매개변수 하나를 받는 [함수][defining functions]를 정의해야 해요.
- 값을 곱하려면 [곱셈 수학 연산자][arithmetic]를 사용해요.
- 코드에 "매직 넘버"를 쓰는 대신 층마다 걸리는 시간(분)을 나타내는 별도의 _상수_를 정의할 수도 있어요.
- 이 함수는 정수를 [반환][return]해야 해요.

## 4. 총 조리 시간(준비 + 굽기, 분) 계산하기

- 매개변수 두 개를 받는 [함수][defining functions]를 정의해요.
- 앞서 정의한 함수를 _호출_할 수 있어요.
- 값을 더할 때는 [덧셈 수학 연산자][arithmetic]를 사용할 수 있어요.
- 이 함수는 정수를 [반환][return]해야 해요.

## 5. 메모를 추가해 레시피 업데이트하기

- 매개변수 없이 함수를 정의해요.
- 이 함수는 문자열 값을 반환해야 해요.
