# 소개

JavaScript에는 날짜와 시간을 저장하고 관리하는 메서드를 제공하는 내장 객체 `Date`가 있어요.

<!-- prettier-ignore -->
~~~exercism/caution
이 객체는 Java의 `java.util.Date` 클래스를 기반으로 만들어졌는데, 그 클래스는 2010년대 초에 대체되었어요. 하지만 하위 호환성을 위해 JavaScript의 `Date`는 계속 남아 있어요.

Date를 다루는 일이 전반적으로 어렵고, 시간대 처리가 형편없거나 아예 없기 때문에 `moment.js`, `day.js`, `date-fns`, `luxon` 같은 라이브러리가 많이 있어요.
이 중 어느 것도 Exercism에서는 사용할 수 없어요.

직접 만드는 프로젝트에서는 `moment.js`처럼 더 이상 사용하지 않거나 유지보수되지 않는 패키지를 쓰지 말고, `luxon` 같은 더 현대적인 대안이나 아직 널리 보급되지 않은 [Temporal][mdn-temporal]에 의존해요.
이 연습 문제는 JavaScript가 존재하는 한 계속 중요할 `Date`에 초점을 맞춰요.

[mdn-temporal]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Temporal
~~~

## 생성

`Date` 객체는 `Date` 클래스의 인스턴스예요.
생성자 함수에 아무 인자도 전달하지 않고 만들 수 있어요.
이렇게 하면 현재 날짜와 시간을 나타내는 `Date` 객체가 만들어져요:

```javascript
const now = new Date();
// => Thu Apr 14 2022 11:46:08 GMT+0530 (India Standard Time)
// Shows current day, date and time (in your time zone).
```

### **Unix 타임스탬프 (숫자)**

숫자를 전달하면 이는 `timestamp`로 해석돼요.
타임스탬프는 **[UTC][defn-utc]+0 기준 1970년 1월 1일** 이후 지나간 **밀리초** 수를 나타내는 정수예요.

```javascript
const epoch = new Date(0);
// Thu Jan 01 1970 01:00:00 GMT+0100 (Central European Standard Time)

const another = new Date(1749508766627);
// Tue Jun 10 2025 00:39:26 GMT+0200 (Central European Summer Time)
```

`new Date(0)`이 "가장 이른" 날짜 객체를 만들 거라고 기대할 수도 있지만, JavaScript는 날짜를 로컬 시간대로 변환해요. 그래서 [GMT / UTC+0][defn-gmt] 시간대 부근에 있는 사람만 실제로 [Unix epoch][defn-unix-epoch] 값을 얻게 돼요.

### **ISO 8601 타임스탬프 (문자열)**

날짜를 나타내는 문자열 값을 `Date` 생성자에 전달할 수 있어요.
구현에 관계없이 일관되게 동작하는 **유일한** 형식은 국제적으로 인정되고 표준화된 소위 [ISO 8601 타임스탬프 문자열][defn-iso8601]의 [간소화 버전][mdn-date-string-format]이에요.

[UTC][defn-gmt] 기준의 한 시점은 이렇게 생겼어요:

```text
YYYY-MM-DDTHH:mm:ss.mssZ
YYYYMMDDTHHmmss.mssZ
```

여기서 다음 자리에 값이 들어가요:

| 키   | 설명                                          | 기본값 |
| ---- | --------------------------------------------- | ------- |
| YYYY | 4자리로 표현한 역년(달력상의 해)              |         |
| MM   | 2자리로 표현한 월                              | 01      |
| DD   | 2자리로 표현한 일                              | 01      |
| T    | 날짜와 시간을 구분하는 문자 그대로의 T         |         |
| HH   | 24시간제의 시, 2자리                          | 00      |
| mm   | 분, 2자리                                     | 00      |
| ss   | 초, 2자리                                     | 00      |
| mss  | 밀리초, 3자리                                 | 000     |
| Z    | 문자 그대로의 Z, 또는 오프셋 `+/-HH:mm`        |         |

문자 그대로의 `Z`는 UTC를 나타내요(시간대 없음, 일광 절약 시간 없음).

대부분의 구성 요소에 기본값이 있기 때문에, 뒤쪽 부분을 생략해도 괜찮아요:

```text
YYYY-MM-DD
```

시간은 기본값인 00:00:00.000이 돼요.

타임스탬프가 `Z`로 끝나지 않고, `+HH:mm`이나 `-HH:mm`(시간대 오프셋을 나타내는)으로도 끝나지 않는다면, 역사적인 이유로 다음이 적용돼요:

> 시간대 오프셋이 없으면, 날짜만 있는 형식은 UTC 시간으로 해석되고 날짜와 시간이 있는 형식은 로컬 시간으로 해석돼요.
> UTC 시간으로 해석하는 것은 ISO 8601과 일치하지 않았던 역사적인 명세 오류 때문인데, 웹 호환성 때문에 바꿀 수 없었어요.
> [Broken Parser – A Web Reality Issue][ref-broken-parser]를 참고해요.

### **Date 객체**

이미 있는 Date 객체를 생성자 인자로 사용할 수도 있어요.
이렇게 하면 같은 날짜와 시간을 가진 기존 `Date` 객체의 복사본이 만들어져요.

```javascript
const t1 = new Date();
const t2 = new Date(t1);
// Values of t1 and t2 will be the same.
```

### **날짜와 시간 구성 요소 값을 개별적으로 전달하기**

날짜를 나타내는 Date는 숫자 세 개를 전달해서 만들 수 있어요.
날짜와 시간을 나타내는 Date는 숫자 여섯 개를 전달해서 만들 수 있어요.

```javascript
const date1 = new Date(95, 11, 17);
// Creates Date for Dec 17 1995 00:00 if your local timezone is equivalent to UTC.

const date2 = new Date(2013, 12, 5, 13, 24, 0);
// Creates Date for Jan 5 2014 13:24 if your local timezone is equivalent to UTC.
```

두 번째 값은 `month`인데, 1월이 `0`이고 12월이 `11`이에요.

## `Date.parse()`

날짜 파싱 함수 `Date.parse`에 대한 언급이나 참고 자료를 볼 수도 있어요.
이 함수에는 몇 가지 불변(invariant)만 있고 나머지 구현은 명세되어 있지 않아서(따라서 표준도 아니어서) 사용하지 않는 게 좋아요.

## `Date` 구성 요소에 접근하기

날짜 객체에는 날짜의 구성 요소를 반환하는 다양한 메서드가 있어요:

```javascript
getFullYear(); // Get the year (4 digits)
getMonth(); // Get the month, from 0 to 11.
getDate(); // Get the day of month, from 1 to 31.
getHours(); // Get the hour in a 24 clock, from 0 to 23
getMinutes(); // Get the minutes, from 0 to 59
getSeconds(); // Get the seconds, from 0 to 59
getMilliseconds(); // Get the milliseconds, from 0 and 999
getDay(); // Get the day of week, from 0 (Sunday) to 6 (Saturday).
```

각 메서드에는 값을 갱신하는 대응하는 `set` 변형(예: `setFullYear`)이 있어요.
넘치는 값은 다음 구성 요소로 넘어가요:

```javascript
const date = new Date('2025-02-28T12:42:00Z');
// => Fri Feb 28 2025 13:42:00 GMT+0100 (Central European Standard Time)

date.setDate(29);
// there was no February 29th in 2025.

date.getDate();
// => 1

date.toString();
// => Sat Mar 01 2025 13:42:00 GMT+0100 (Central European Standard Time)
```

로컬 시간대를 무시하는 모든 메서드에는 UTC 변형이 있어요.

## 날짜에서 변환하기

Date 객체에는 UNIX 타임스탬프를 밀리초로 반환하는 `getTime()` 메서드가 있어요. 즉, 1970년 1월 1일 UTC 자정 이후 지난 밀리초 수예요.
또한 날짜 객체를 ISO 8601 타임스탬프 문자열로 변환하는 `toISOString()` 메서드도 있어요.

## 날짜 비교하기

크다(`>`), 크거나 같다(`>=`), 작다(`<`), 작거나 같다(`<=`) 연산자는 두 날짜 사이 또는 날짜와 숫자 사이에 바로 사용할 수 있어요.
JavaScript가 날짜를 원시값으로 변환하려고 시도하기 때문에 이렇게 동작해요.
