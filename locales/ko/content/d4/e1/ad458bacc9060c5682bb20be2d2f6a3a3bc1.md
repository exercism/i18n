# 소개

Cairo에서는 연산자 오버로딩을 통해 직접 만든 타입을 다룰 때 `+`, `-`, `==`, `<` 같은 표준 연산자의 동작을 원하는 대로 정의할 수 있어요.

이것은 직접 만든 타입에 특정 트레이트를 구현해서 할 수 있어요.

## 연산자를 위한 핵심 트레이트

### `Add`와 `Sub`

`Add`와 `Sub` 트레이트를 사용하면 타입에서 덧셈(`+`)과 뺄셈(`-`)이 어떻게 동작할지 정의할 수 있어요:

```rust
impl MyTypeAdd of Add<MyType> {
    fn add(lhs: MyType, rhs: MyType) -> MyType {
        // Define addition behavior
    }
}
```

### `PartialEq`

`PartialEq` 트레이트는 타입의 인스턴스끼리 동등 비교(`==`와 `!=`)를 할 수 있게 해줘요.

이것은 보통 `#[derive(PartialEq)]`를 사용해 자동으로 파생시킬 수 있어요.

### `PartialOrd`

`PartialOrd` 트레이트는 타입의 인스턴스끼리 비교 연산(`<`, `>`, `<=`, `>=`)을 할 수 있게 해줘요.

적어도 `lt`(보다 작음) 메서드는 구현해야 해요:

```rust
impl MyTypePartialOrd of PartialOrd<MyType> {
    fn lt(lhs: MyType, rhs: MyType) -> bool {
        // Define "less than" behavior
    }
}
```
