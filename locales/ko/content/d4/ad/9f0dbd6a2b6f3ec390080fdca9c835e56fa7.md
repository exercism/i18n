# 힌트

## 일반

- `<min-heap>`, `heap-push`, `heap-peek`, `heap-pop-all`은 모두 [`heaps`][heaps]에 있고,
  `values`는 [`assocs`][assocs]에 있어요.
- 힙은 각 항목을 *키*와 함께 *값*으로 저장해요. 키가 우선순위예요.
  `heap-push`는 이 둘을 `( value key heap -- )` 형태로 받아요.

## 1. 대기열 열기

- `<min-heap>`은 빈 최소 힙을 만들어요. 키가 가장 작은 항목이 먼저 처리돼요.

## 2. 고객 추가하기

- 고객 이름이 값이고 우선순위가 키예요. 이 순서가 바로 `heap-push`가 원하는
  순서예요.
- `heap-push`는 대기열을 소비해요. 고객을 추가하면서 대기열도 그대로 반환하려면
  `[ heap-push ] keep`을 사용해요.

## 3. 다음은 누구일까요?

- `heap-peek`은 맨 앞 항목의 `value key`를 제거하지 않고 반환해요. 이름만 필요하니
  키는 `drop`해요.

## 4. 모두 응대하기

- `heap-pop-all`은 힙을 비우면서 `{ key value }` 쌍의 연관 리스트로 만들어요. 이미
  우선순위 순서대로 정렬되어 있어요.
- `values`는 값, 즉 이름만 남겨요.

[heaps]: https://docs.factorcode.org/content/vocab-heaps.html
[assocs]: https://docs.factorcode.org/content/vocab-assocs.html
