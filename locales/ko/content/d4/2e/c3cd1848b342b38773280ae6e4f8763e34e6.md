# 지시 사항

*ChronoRealms*의 세계에 오신 것을 환영해요. 강력한 Timekeepers가 시간의 흐름을 다스리는 마법의 땅이에요.

이 세계에서 Timekeepers는 "TimeShard"를 관리해요. TimeShard는 서로 더하고, 빼고, 비교하고, 심지어 값이 같은지 확인할 수도 있는 특별한 단위예요.

이번 임무는 Timekeepers를 도와 이런 TimeShard를 다루는 사용자 정의 연산자를 구현하는 거예요.

Timekeepers는 다음 연산을 지원하는 사용자 정의 struct `TimeShard`를 만들어 달라고 해요.

1. **TimeShard 더하기와 빼기**: Timekeepers는 시간선을 조작하려면 TimeShard를 더하고 뺄 수 있어야 해요.
2. **TimeShard 비교하기**: 두 TimeShard 중 어느 쪽이 더 큰지, 혹은 둘이 같은지 비교해야 할 때도 있어요.
3. **동등성 확인**: Timekeepers는 두 TimeShard의 값이 서로 같은지 확인할 수 있어야 해요.

이번에는 `TimeShard` struct에 다음 트레이트를 구현해 봐요.

1. **덧셈(`Add`)**: 두 `TimeShard` 인스턴스를 서로 더할 수 있게 해요.
2. **뺄셈(`Sub`)**: 한 `TimeShard`에서 다른 `TimeShard`를 뺄 수 있게 해요.
3. **동등성(`PartialEq`)**: Timekeepers가 두 `TimeShard` 인스턴스가 같은지 확인할 수 있게 해요.
4. **비교(`PartialOrd`)**: 두 `TimeShard` 인스턴스 중 어느 쪽이 더 크거나 작은지 비교할 수 있게 해요.

`TimeShard`는 정수 값(`i32`)을 담는 struct로 표현돼요.

Timekeepers의 일을 더 쉽게 만들어 줄 트레이트를 구현해 봐요.

```rust
let shard1 = TimeShard { value: 5 };
let shard2 = TimeShard { value: 3 };

// Adding TimeShards
let sum = shard1 + shard2; // TimeShard { value: 8 }

// Subtracting TimeShards
let difference = shard1 - shard2; // TimeShard { value: 2 }

// Checking equality
let are_equal = shard1 == shard2; // false

// Comparing TimeShards
let is_greater = shard1 > shard2; // true
```
