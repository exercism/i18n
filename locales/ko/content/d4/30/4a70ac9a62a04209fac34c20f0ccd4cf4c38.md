# 지시 사항

독특한 유언 의뢰를 전문으로 처리하는 명망 있는 법률 사무소에서 일하고 있어요.

이 연습 문제에서는 신비로운 금고를 열게 돼요.
유산 집행인으로서, 세 가문이 오랫동안 지켜온 비밀 코드를 모아 계좌 번호와 그에 맞는 코드를 알아낼 거예요.

어느 한 가문이 혼자 금고를 여는 것을 막기 위해, 금고는 각 가문의 지식과 마지막 유언에서 알게 된 비밀 수정자를 결합해야만 열 수 있어요.

금고를 여는 가문들을 돕는 것과 관련된 세 가지 과제가 있어요.

## 1. 가문들 앞에 앉아 서류를 펼쳐요

`estate_executor`라는 이름의 네임스페이스를 정의해요.
다음 과제의 코드는 `estate_executor` 네임스페이스의 본문 안에 정의해야 해요.

```cpp
namespace some_name {
    // The space between the curly brackets
    // is called body of the  namespace.
}
```

## 2. 비밀 계좌 번호를 찾아요

지금이 바로 중요한 순간이에요.
비밀 계좌 번호를 밝혀낼 수 있는 비밀 수정자 키는 오직 한 사람만이 가지고 있어요.

비밀 수정자를 인자로 받아 완성된 계좌 번호를 `int`로 반환하는 `assemble_account_number(int secret_modifier)` 함수를 정의해요.

올바른 번호를 얻으려면 세 가문 각각의 `bank_number_part`를 모두 더해야 해요.

## 3. 마지막 단계: 비밀 코드를 입력해요

유언장의 지시 사항에 따르면, 파란색 조각을 모두 더한 다음 빨간색 조각을 모두 더해야 해요.
결과 코드는 두 합을 곱해서 구해요.

세 가문의 조각을 하나의 `integer`로 결합해 결과 코드를 반환하는 `assemble_code()` 함수를 정의해요.
이 함수는 인자가 없고, 각 가문의 관련 네임스페이스에 담긴 정보에만 의존해요.
