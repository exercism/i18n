# 힌트

## 1. 스택 맨 위에 카드 넣기

- 배열 뒤쪽에 추가하려면 [`ArrayTrait::append` 함수][append]를 사용할 수 있어요.

## 2. 스택 맨 위에서 카드 제거하기

- 배열은 언제든 span으로 변환할 수 있고, 그다음 [`SpanTrait::pop_back` 함수][pop-back]를 사용해 배열 뒤쪽에서 제거할 수 있어요.

## 3. 스택 맨 아래에 카드 넣기

- 배열 앞쪽에 항목을 추가할 방법은 없지만, 한 가지 방법은 항목이 하나뿐인 새 배열을 만들고 [`ArrayTrait::append_span`][append-span]으로 기존 배열을 span으로 추가하는 거예요.

## 4. 스택 맨 아래에서 카드 제거하기

- [`ArrayTrait::pop_front` 함수][pop-front]를 사용해 배열 앞쪽에서 제거할 수 있어요.

## 5. 스택의 크기 확인하기

- [`ArrayTrait::len` 함수][len]을 사용해 배열의 길이를 구할 수 있어요.
