# 지시 사항

팔레르모 항구는 배들이 많이 오가는 분주한 항구예요.
오랫동안 항구에 현재 정박 중인 배들을 관리하는 수동 시스템을 사용해 왔어요.
이 시스템은 오류가 발생하기 쉬워서, 항구 책임자는 이를 전산 시스템으로 교체하기로 했어요.

항구 책임자는 새로운 시스템을 구현하도록 여러분을 고용했어요.
이 시스템은 배의 식별자뿐만 아니라 목적지의 식별자도 처리해야 해요.

## 1. 항구 식별자 만들기

가장 먼저 팔레르모 항구의 식별자를 만들어야 해요.
식별자는 항구 이름의 첫 네 글자를 대문자로 쓴 것이에요.

`Port::IDENTIFIER` 상수를 값이 `:PALE`인 심볼로 정의해요.
    
```ruby
Port::IDENTIFIER 
# => :PALE
```

## 2. 다른 항구의 식별자 가져오기

프로그램은 다른 항구도 처리해야 하므로, 그 항구들의 식별자도 만들어야 해요.
항구에서는 시스템이 자동화되기를 바라고, 항구마다 이름 붙이는 규칙이 다르기 때문에 식별자는 항구 이름에서 생성되어야 해요.
식별자는 항구 이름의 첫 네 글자를 대문자로 쓴 것이에요.

`Port.get_identifier` 메서드는 문자열을 인자로 받아, 그 항구의 식별자를 심볼로 반환하도록 정의해요.

```ruby
Port.get_identifier("Hamburg") 
# => :HAMB
```

## 3. 배가 어느 터미널에 정박해야 하는지 판단하기

항구에는 터미널이 두 개 있고, 시스템은 배가 어느 터미널에 정박해야 하는지 판단해야 해요.
터미널은 배의 식별자로 결정돼요.

식별자는 두 부분으로 이루어져 있어요. 첫 번째 부분은 배가 어떤 화물을 운반하는지 나타내는 대문자 세 글자이고, 그다음은 배의 고유 식별자인 숫자 세 자리예요.

배의 식별자에 담긴 화물이 **OIL** 또는 **GAS**라면, 배는 **A** 터미널에 정박해야 해요.
그렇지 않으면 배는 **B** 터미널에 정박해야 해요.

`Port.get_terminal` 메서드는 배의 식별자인 심볼을 인자로 받도록 정의해요.
이 메서드는 터미널을 심볼로 반환해야 해요.

```ruby
Port.get_terminal(:OIL123)
# => :A
```
