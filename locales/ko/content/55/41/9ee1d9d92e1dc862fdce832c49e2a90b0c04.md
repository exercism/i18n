# 소개

## 중첩 타입

C#의 타입은 클래스나 구조체의 스코프 안에서도 정의할 수 있어요. 이때 감싸고 있는 타입은 일종의 네임스페이스 역할을 해요. 안쪽 타입에 접근할 때는 바깥쪽 타입에 점을 찍는 문법을 사용해요.

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

안쪽 타입에도 접근 수준을 설정할 수 있어요.

바깥쪽 타입의 private 멤버는 안쪽 타입의 멤버에게도 접근할 수 있지만, 그 반대는 안 돼요.
