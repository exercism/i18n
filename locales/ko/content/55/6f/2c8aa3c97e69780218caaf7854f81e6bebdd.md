# 배열

PHP의 배열은 순서가 있는 맵이에요.
맵은 키를 값에 연결하는 자료 구조예요.
배열은 다재다능해서, `C`나 `Java`에서처럼 선형 배열로 다룰 수도 있고, 리스트 [벡터], 해시 테이블, 딕셔너리, 컬렉션, 스택, 큐로도 다룰 수 있어요.

키는 선택 사항이지만, 지정한다면 반드시 `int`나 `string`이어야 해요.
키를 제공하지 않으면 PHP는 `0`부터 시작해 차례로 커지는 정수 키를 기본값으로 사용해요.

```php
$no_keys = ["my", "first", "array"];
$integer_keys = [0 => "my", 1 => "first", 2 => "array"];

$no_keys == $integer_keys // => equal returns true
$no_keys === $integer_keys // => strictly equal returns true
```

배열에는 모든 타입의 값을 저장할 수 있어요.
각 값은 서로 다른 타입일 수 있어요.

```php
$my_arr = [
  1,
  "second",
  new \DateTimeImmutable()
];
```

## 배열 사용하기

배열은 리터럴로 선언하거나(위에서처럼 코드로 직접 작성), 함수로 생성하고 조작할 수 있어요.

```php
$my_empty_arr = [];

// or
$my_empty_arr = array(); // => []

// or
$letters = mb_str_split("Hello"); // => ["H", "e", "l", "l", "o"] 
```

인덱스 연산자를 사용해 값을 접근하고, 할당하고, 추가해요:

```php
$prime_numbers = [2, 3, 5, 6];

$prime_numbers[3] = 7; // replace 6 with 7

$prime_numbers[] = 11; // array now contains [2, 3, 5, 7, 11]
```

foreach를 사용해 배열을 반복해요:

```php
$names = ["Ani", "Jack", "Rami"]

// Iterate just the values
foreach ($names as $name) {
  echo $name;
}

// Iterate keys and values
foreach ($names as $index => $name) {
  echo "$index => $name";
}
```
