# 소개

이것은 _큰_ 주제가 될 수 있어요!
이 주제에 대해서는 긴 책을 한 권 쓸 수도 있고, 실제로 그렇게 한 사람들도 여럿 있어요 (아마존에서 "unicode book"을 검색하면 몇 가지 예를 볼 수 있어요).

## 아주 간단한 역사

옛날에는 컴퓨터에서 문자를 다루는 일이 훨씬 간단했어요. 당시 프로그래머들은 영어가 유일하게 중요한 언어라고 가정했거든요.
그래서 알파벳 26자(대문자와 소문자), 숫자 10개, 몇 가지 문장 부호, 그리고 종을 울리는 코드(0x07)까지 모두 7비트에 들어갔어요. 바로 [ASCII][wiki-ascii] 문자 집합이에요.

당연히 사람들은 à, ä, Ł는 어떡하냐고 묻기 시작했고, 그러다 다른 사람들은 ऄ, ஹ, ญ는 어떡하냐고 물었고, 젊은 사람들은 이모지 😱를 원했어요.
어떻게 해야 할까요?

길게 말할 것 없이, 똑똑하고 인내심 강한 많은 사람들이 수년간 위원회에서 일하며 [유니코드][web-unicode] 문자 집합과 [UTF-8][wiki-utf-8] 같은 인코딩의 세부 사항을 정리해야 했고, 수많은 소프트웨어가 _아주_ 복잡한 재작성 과정을 거쳐야 했어요.
게다가 새로운 버그도 많이 생겼어요.

_모든 것_이 망가지는 걸 막기 위해, 유니코드/UTF-8 설계는 처음 127개 코드가 ASCII와 동일하도록 보장해요 _(종까지도요)_.

## Kotlin의 문자

2005년 즈음 이후에 설계된 언어들은 이미 어느 정도 안정된 유니코드 표준이 존재했다는 큰 이점을 누릴 수 있었어요.

Kotlin(2011년 첫 출시)은 사용자들이 다양한 (사람의) 언어를 사용하고, 그것을 표현하는 데 유니코드가 필요하다는 점을 전제로 삼을 수 있었어요.

문자 리터럴은 작은따옴표로 쓰고, 큰따옴표로 쓰는 문자열과는 구별돼요.
C/C++ 세계에서 온 사람들에게는 아마 당연하겠지만, Python과 JavaScript 프로그래머에게는 헷갈릴 수 있어요.

```kotlin
val a = 'a'
a::class.qualifiedName  // => kotlin.Char
a.code  // => 97

val jha = 'झ'  // Devanagari alphabet
jha.code  // => 2333

val heart = '❤'  // heart emoji
heart.code  // => 10084

Char.MAX_VALUE.code  // => 65535 (64k, the largest code point allowed)
```

`Char`와 `Int` 사이를 변환하는 건 간단해요:

```kotlin
a.code  // => 97  (a.toInt() is deprecated)
Char(97) // => 'a'
```

컴파일러는 `Char`에 대한 _일부_ 정수 연산을 허용해요:

```kotlin
'a' + 5       // => 'f'
'c' - 'a'   // => 2
'c' + 'a'   // => error!

'f' + ('A' - 'a')  // => 'F' (same as 'f'.uppercase()

'f'.dec() // => 'e' (decrement)
'f'.inc() // => 'g' (increment)
```

## `Char`를 위한 몇 가지 함수

늘 그렇듯, 여기서 다 다루기에는 [함수가 너무 많아요][ref-char-lib]. 그래서 몇 가지만 골라볼게요.

- 해당하는 알파벳이라면 [`uppercase()`][ref-uppercase]와 [`lowercase()`][ref-lowercase]로 대소문자를 바꿔요.
- [`isUpperCase()`][ref-isuppercase]와 [`isLowerCase()`][ref-islowercase]로 대소문자를 확인해요.
- 다음과 같은 함수로 문자의 종류를 확인해요:
    - [`isLetter()`][ref-isletter], 다양한 알파벳을 다뤄요
    - [`isDigit()`][ref-isdigit], 0..9 범위예요
    - `isLetterOrDigit()`, 앞의 두 함수를 합친 거예요
    - [`isWhitespace()`][ref-iswhitespace], 모든 공백 문자예요

```kotlin
'झ'.isLetter()      // => true
'A'.isLowerCase()   // => false
'4'.isDigit()       // => true
'\t'.isWhitespace() // => true  (tab character)
```

## Char 리스트와 String 간 변환

String을 Char 리스트로 바꾸려면 `toList()`를 사용하면 돼요.

Char 리스트를 String으로 바꾸려면 [`joinToString()`][ref-jointostring] 함수가 있어요. 이 함수는 구분자(흔히 빈 문자열)를 인자로 받아요.

```kotlin
val kt = "kotlin".toList()  // => [k, o, t, l, i, n]
kt.joinToString("")   // => "kotlin"
kt.joinToString("_")  // => "k_o_t_l_i_n"
```

`joinToString()`은 List나 Array에서 동작한다는 점에 주의해요.
`Char` 하나를 1글자짜리 문자열로 _변환_하려면 `toString()`을 사용해요.

```kotlin
'a'.toString() // => "a"
```

어떤 문자가 `String`이나 `Char` 리스트 또는 배열에 있는지 확인하려면 `in`이 있어요. 이는 [`contains()`][ref-contains] 함수로 이어져요.

```kotlin
val clist = "kotlin".toList()  // => [k, o, t, l, i, n]
't' in clist     // => true
't' in "kotlin"  // => true
```
