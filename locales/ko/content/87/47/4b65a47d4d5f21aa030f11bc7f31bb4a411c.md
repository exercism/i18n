# 힌트

## 1. `GbTree` 외부 타입 정의하기

- 외부 타입은 `pub type TypeName(a, b, c)` 구문으로 정의할 수 있어요.

## 2. `new_gb_tree` 함수 정의하기

- 외부 함수는 `@external(erlang, "module", "function")` 구문으로 정의할 수 있어요.
- 이 함수는 `gb_trees:empty/0`을 사용해야 해요.

## 3. `insert` 함수 정의하기

- `gb_trees:insert/3` 문서를 확인해서 인자의 올바른 순서를 알아봐요.
- 외부 함수는 인자의 순서를 바꾸기 위해 `insert` 함수에서 호출하는 비공개 함수로 만들 수 있어요.
- 이 함수는 `gb_trees:insert/3`을 사용해야 해요.

## 4. `delete` 함수 정의하기

- `gb_trees:delete_any/2` 문서를 확인해서 인자의 올바른 순서를 알아봐요.
- 외부 함수는 인자의 순서를 바꾸기 위해 `delete` 함수에서 호출하는 비공개 함수로 만들 수 있어요.
- 이 함수는 `gb_trees:delete_any/2`를 사용해야 해요.
- `gb_trees:delete/2` 함수는 키를 찾지 못하면 크래시가 발생하므로, 사용하면 안 돼요.
