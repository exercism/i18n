# 문자열에 대하여

Kotlin에서 [`string`][ref-string]은 유니코드 문자의 불변 시퀀스예요.

[`Immutable`][wiki-immutable]은 문자열에 어떤 연산을 하든 새로운 문자열을 반환해야 한다는 뜻이에요. 원래 문자열은 절대 바뀌지 않아요.

[`Unicode`][wiki-unicode]는 세상 대부분의 문자 체계를 표현할 수 있다는 뜻이에요. 다만 C 같은 옛 언어와 달리 문자와 바이트가 1:1로 대응하지는 않아요.
이 내용은 [`Chars`][concept-chars] 개념에서 더 자세히 다뤄요.

문자열은 큰따옴표 `" "`로 감싸요.

일부 문자는 이스케이프가 필요해요. `\\`를 비롯해 `\t`(탭), `\n`(줄바꿈)처럼 흔히 쓰이는 비출력 문자들이 그래요.

```kotlin
val s = "Escape backslash \\."
// Escape backslash \.
```

여러 줄 문자열은 큰따옴표 세 개로 감싸고, 원하는 텍스트를 마음대로 담을 수 있어요(이스케이프할 필요가 없어요).

```kotlin
val multi = """I'm a
    multi-line
    string with special characters \ \t """
//I'm a
//    multi-line
//    string with special characters  \ \t 
```

[trimIndent][trimIndent-doc]를 사용하면 각 줄에 공통으로 붙은 들여쓰기를 없앨 수 있어요.
문자열 형식을 정리할 때 유용하죠.

```kotlin
val multi = """
    I'm a
      multi-line
    string""".trimIndent()

//I'm a
//  multi-line
//string
```

또는 [trimMargin][trimMargin-doc]으로 구분자를 지정할 수 있어요.
그러면 `String`의 각 줄이 구분자 뒤에서 시작해요.
구분자의 기본값은 `|`지만, 매개변수로 다른 구분자를 지정할 수도 있어요.
예를 들어 볼까요?

```kotlin
val multi = """
    |I'm a
    |  multi-line
    |string""".trimMargin()

//I'm a
//  multi-line
//string

val multi2 = """
    start>I'm a
    start>  multi-line
    start>string""".trimMargin("start>")

//I'm a
//  multi-line
//string
```

문자열은 `+`로 이어 붙일 수 있지만, 짧고 단순한 경우에만 쓰는 게 좋아요.
다른, 그리고 대개 더 나은 방법들이 있어요.

## 문자열 템플릿

[`Templates`][ref-templates]는 다른 언어에서 "보간"이라고 부르는 걸 가리켜요.

문자열에 달러 기호 `$` 뒤에 식별자가 오거나, 표현식을 감싼 중괄호(`{expression}`)가 있으면, 그것들은 각각 해당 값이나 표현식의 결과로 바뀌어요.

```kotlin
val x = 42
val st = "x is $x, x squared is {x * x}"
// x is 42, x squared is 1764
```

## 문자열 서식

JVM 플랫폼에서만 `String.format()`을 쓰면 문자열 템플릿보다 더 정밀하게 형식을 지정할 수 있는데, 문법은 (_아주 오래된!_) [`printf`][wiki-printf] 함수와 비슷해요.

```kotlin
String.format("%s %.3f", "π ≈", 3.14159)
//π ≈ 3.142
```

~~~~exercism/advanced
Kotlin은 여러 가지 타깃으로 컴파일할 수 있어요. Java Virtual Machine, JavaScript, Linux, Windows, Android, Apple용 네이티브 바이너리, 그리고 두 가지 WebAssembly 변형이 있어요.

기본적으로 같은 코드를 각 타깃에 쓸 수 있지만, 타깃 플랫폼마다 기능이 다르기 때문에 표준 라이브러리 함수 중 어떤 것이 지원되는지에도 차이가 생겨요.

Exercism은 현재 테스트에 JVM을 사용해요.

## 문자열 함수

Kotlin은 문자열을 다루는 _아주 다양한_ [`functions`][ref-string-functions]를 제공해요.

대부분은 `String` 클래스의 멤버가 아니라 [`extensions functions`][ref-extensions]예요. 다만 이 점이 사용법에 미치는 영향은 거의 없어요.

~~~~exercism/note
Kotlin의 다소 복잡한 [문서][ref-string-functions] 페이지들은 기본 보기에서 확장 함수를 숨겨 둬요.
이 글을 쓰는 시점에 가장 값진 내용은 `Members & Extensions`라는 탭 속에 숨어 있어요.
그 탭을 클릭하면 이 섹션이 펼쳐지면서 `String` 클래스에서 쓸 수 있는 모든 멤버와 확장을 볼 수 있어요.

[ref-string-functions]: https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/
~~~~

다음 예제는 사용할 수 있는 것들 가운데 아주 일부만 보여줘요.

```kotlin
val str = "Hello World!"

str.length              // => 12 (a property, not a function)
str.elementAt(6)        // => W
str.elementAtOrNull(20) // => null (index out of range)
str.substring(6, 11)    // => "World"
str.substringAfter(" ") // => "World!"

str.lowercase()         // => "hello world!"
str.uppercase()         // => "HELLO WORLD!"

str.startsWith("Hel")   // => true
str.endsWith("xyz")     // => false
str.indexOf("0")        // => 4

str.toCharArray()       // => [H, e, l, l, o,  , W, o, r, l, d, !]
"42".toInt() + 1        // => 43  (parsing; see also toFloat)

"Howdy!  ".trim()       // => "Howdy"
```

## 문자열 만들기

때로는 긴 문자열을 단계적으로 만들어야 할 때가 있어요. 예를 들어 루프 안에서요.

문자열을 `+`로 계속 이어 붙이다 보면 금세 우아하지도, 성능이 좋지도 않아요. 불변이기 때문에 복사가 _아주 많이_ 필요하거든요.

Kotlin에는 여러 문자열을 합치는 더 효율적인 방법이 여러 가지 있어요.

- 위에서 설명한 문자열 템플릿.
- [`joinToString()`][ref-jointostring]. [Lists][concept-lists] 개념에서 다뤄요.
- Java의 [`StringBuilder`][ref-stringbuilder]. 그다지 Kotlin다운 방식으로는 여겨지지 않아요.
- Kotlin의 [`buildString()`][ref-buildstring]은 `StringBuilder`를 더 간결하고 Kotlin다운 문법으로 감싼 거예요.
이 함수는 문자열을 만드는 로직을 람다 인자로 받는데, 이건 나중 개념에서 다뤄요.

본질적으로 `StringBuilder`는 편리한 메서드가 많은, 배열과 비슷한 구조예요.
다음은 그중 일부예요.

- [`append()`][ref-sb-append]는 끝에 추가해요.
- [`insert()`][ref-sb-insert]는 지정한 위치에 추가해요.
- [`deleteAt()`][ref-sb-deleteat]과 [`deleteRange()`][ref-sb-deleterange]는 지정한 위치에서 삭제해요.
- `toString()`은 마지막에 일반 문자열로 변환해요. 모든 것을 한 번의 성능 좋은 연산으로 합쳐 주죠.

```kotlin
// Available, not recommended
val sb = StringBuilder()
sb.append("Hello ")
sb.append("World!")
sb.toString()
//Hello World!
```

나중 개념에서 나오는 문법을 쓴 `buildString()` 예제예요.

```kotlin
val countDown = buildString {
    for (i in 5 downTo 1) {
        append(i)
        append("_")
    }
}
// countDown is "5_4_3_2_1_"
```
