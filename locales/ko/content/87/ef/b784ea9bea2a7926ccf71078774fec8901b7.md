# 지침

이 연습 문제에서는 로그 라인을 처리해요.

각 로그 라인은 다음과 같은 형식의 문자열이에요: `"[<LEVEL>]: <MESSAGE>"`.

로그 레벨은 다음 세 가지예요:

- `INFO`
- `WARNING`
- `ERROR`

세 가지 작업이 있어요. 각 작업에서는 로그 라인을 받아 무언가를 처리해야 해요.

## 1. 로그 라인에서 메시지 가져오기

로그 라인의 메시지를 반환하는 (_static_) `LogLine.Message()` 메서드를 구현해요:

```csharp
LogLine.Message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

앞뒤 공백은 제거해야 해요:

```csharp
LogLine.Message("[WARNING]:  Disk almost full\r\n")
// => "Disk almost full"
```

## 2. 로그 라인에서 로그 레벨 가져오기

로그 라인의 로그 레벨을 반환하는 (_static_) `LogLine.LogLevel()` 메서드를 구현해요. 이때 로그 레벨은 소문자로 반환해야 해요:

```csharp
LogLine.LogLevel("[ERROR]: Invalid operation")
// => "error"
```

## 3. 로그 라인 형식 바꾸기

로그 라인의 형식을 바꿔 메시지를 앞에 두고 로그 레벨을 그 뒤에 괄호로 묶는 (_static_) `LogLine.Reformat()` 메서드를 구현해요:

```csharp
LogLine.Reformat("[INFO]: Operation completed")
// => "Operation completed (info)"
```
