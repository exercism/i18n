# 소개

`List`는 `Array`와 아주 비슷해요. 하지만 그냥 지나칠 수 없는 중요한 차이점이 있어요:

1. 리스트는 대괄호, 즉 `[0]`으로 인덱싱할 수 없어요.
2. 리스트는 초기화할 수 없어요.
3. 리스트 컴프리헨션이 없어요.
4. 리스트는 순회하는 동안에도 요소를 자유롭게 수정할 수 있어요.

`List`는 `haxe.ds` 패키지에 속해 있어요. 그래서 리스트를 사용할 때는 항상 패키지를 임포트해야 해요:

```haxe
import haxe.ds.List;

class Main {
  static function main() {
    var myList = List<Int>();

    for (i in 0...5) {
      myList.add(i);
    }

    trace(myList); // {0, 1, 2, 3, 4}
  }
}
```
