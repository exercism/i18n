# 소개

`Integer`는 컴퓨터 메모리가 허용하는 한, 아무리 큰 수라도 저장할 수 있어요. 반면 `Int`는 32비트나 64비트로 표현할 수 있는 양의 정수와 음의 정수를 나타내요(최소 -2^29에서 2^29까지는 보장돼요).

`Float`는 실수의 집합에 대응하고, 컴퓨터의 정밀도에 따라 표현할 수 있는 범위가 제한돼요.
숫자에 대해 정의된 연산은 보통 둘 중 한쪽 타입에서만 동작하고, 두 타입 모두에서 동작하지는 않아요.

`Float`와 `Integer` 사이를 변환하는 함수로는 `Int`/`Integer`를 `Float`로 바꿔 주는 `toFloat`, `Float`를 `Int`로 바꿔 주는 `ceiling` 등이 있어요.

정수 타입(`Int` 또는 `Integer`)에서 다른 숫자 타입으로 변환할 때는 `fromIntegral` 함수를 사용해요.
대상 타입은 자동으로 추론돼요.
예를 들면 다음과 같아요.

```haskell
n :: Integer
n = 6
x :: Float
x = fromIntegral n      --> x = 6.0

m :: Int
m = 7
y :: Double
y = fromIntegral m      --> y = 7.0
```
