# 힌트

## 일반

- 함수는 `list`와 `tuple` 인자에는 `*args` 매개변수를, 딕셔너리나 키워드 기반 인자에는 `**kwargs` 매개변수를 사용해 여러 인자를 한데 묶어 받도록 정의할 수 있어요.
- 값을 묶거나 풀 때는 `*` 또는 `**` 연산자를 사용해요.

## 1. 모든 화차의 배열 만들기

- 함수 매개변수의 여러 인자는 `*args` 연산자로 묶을 수 있어요.

## 2. 화차 배열 고치기

- `*` 연산자로 풀기를 사용하면 `list`의 처음 두 원소를 꺼내면서 나머지는 그대로 둘 수 있어요.
- 기존 `list`에 다른 `list`를 추가할 때는 `*` 연산자로 `list`를 "펼쳐서" 넣을 수 있어요.

## 3. 빠진 정거장 추가하기

- 함수 매개변수로 `**kwargs`를 사용하면 임의의 개수만큼 키워드 인자를 전달할 수 있어요.
- `**<dict>`를 인자로 사용하면 딕셔너리를 키워드 인자로 풀어줘요.
- 키워드 인자는 `{}`나 `dict()`에 담을 수 있어요.
- 딕셔너리에서 값들을 꺼내려면 `<dict>.values()` 메서드를 사용할 수 있어요.

## 4. 노선 정보 확장하기

- `**<dict>`를 인자로 사용하면 딕셔너리를 키워드 인자로 풀어줘요.
- 키워드 인자는 `{}`나 `dict()`에 담을 수 있어요.

## 5. 화차 차량기지 고치기

- `zip(*iterators)`를 사용하면 중첩된 `list`를 전치할 수 있어요.
- zip으로 묶인 이터레이터에서 데이터를 꺼내려면 `for`문을 사용할 수 있어요.
- `*`로 zip된 이터레이터를 풀 수도 있어요.
  `[*content] = zip(iterator_1, iterator_2)`는 `zip()`이 만든 `tuple`을 `list`로 풀어줘요.
