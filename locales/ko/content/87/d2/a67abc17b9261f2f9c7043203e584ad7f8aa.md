# 안내 추가

이 연습 문제를 푸는 방법에는 여러 가지가 있지만, 이 연습 문제는 직접 [ability handler][ability-handler-docs]를 작성하는 연습을 하고 싶은 분들을 위해 만들었어요.

이진 트리 자료 구조를 탐색할 수 있게 해 주는 `Zipper` ability를 작성해 봐요.

`Zipper` ability 자체는 이미 정의되어 있지만, 우리가 지정한 이진 트리 자료 구조를 탐색할 수 있게 해 주는 handler는 직접 구현해야 해요.

다음 이진 트리에서 `Zipper.right`, `Zipper.right`, `Zipper.up`, `Zipper.left`를 차례대로 호출하면 값이 `5`인 노드에 도착해 있어야 해요.

```
     1
   /   \
  2     4
 /     /  \
3     5    7
```

이 연습 문제에서는 왼쪽이나 오른쪽 가지가 없는 이진 트리에서 `left`나 `right`를 호출하면 현재 노드의 값을 반환해도 돼요.
