# 지침

오늘도 앤트워프 조차장은 분주한 밤이에요. 당직 관제사로서, 들어오는 화물차를 출발 열차로 재편성하고, 연결부를 점검하고, 분기점에서 경로를 나누고, 동일한 화물은 청구를 위해 하나로 모아야 해요.

각 *차량*은 무엇을 실었는지 나타내는 문자열이에요:
`"coal"`, `"timber"`, `"crates"` 등.

## 1. 차량을 연결해 열차로 만들어요

`couple`은 차량 배열과 길이 `n`을 받아, 각각 `n`개의 차량으로 이루어진 서로 겹치지 않는 열차를 반환하도록 정의해요. 차량 개수가 똑같이 나누어떨어지지 않으면 마지막 열차는 더 짧을 수 있어요.

```factor
{ "coal" "coal" "coke" "ore" "ore" "timber" "timber" } 3 couple .
! => { { "coal" "coal" "coke" } { "ore" "ore" "timber" } { "timber" } }
```

## 2. 연결부를 살펴봐요

`peek-couplings`는 차량 배열을 받아 인접한 모든 쌍을 반환하도록 정의해요. 그래야 검사관이 각 연결부를 살펴볼 수 있어요.

```factor
{ "coal" "ore" "timber" "crates" } peek-couplings .
! => { { "coal" "ore" } { "ore" "timber" } { "timber" "crates" } }
```

## 3. 분기점에서 차량 열을 나눠요

`split-at-junctions`는 차량 배열과 `junctions` 배열(끊는 지점을 표시하는 차량)을 받아, 분기 차량 사이의 구간을 반환하도록 정의해요. 분기 차량 자체는 결과에 남지 않아요.

```factor
{ "coal" "coal" "switch" "ore" "switch" "timber" }
{ "switch" } split-at-junctions .
! => { { "coal" "coal" } { "ore" } { "timber" } }
```

## 4. 동일한 화물을 하나로 모아요

`coalesce-cargo`는 차량 배열을 받아, 같은 화물을 실은 *연속된* 차량을 하나의 묶음으로 모으도록 정의해요.

```factor
{ "coal" "coal" "ore" "ore" "ore" "timber" "coal" } coalesce-cargo .
! => { { "coal" "coal" } { "ore" "ore" "ore" } { "timber" } { "coal" } }
```
