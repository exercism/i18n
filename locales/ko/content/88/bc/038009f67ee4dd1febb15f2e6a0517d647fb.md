# 정렬

물건을 순서대로 나열하는 일은 워낙 흔해서, 라이브러리가 대신 해줘요.

```sather
   scores : ARRAY{INT} := |3, 1, 2|;
   scores.sort;              -- 1, 2, 3
```

`sort`는 자기 자신을 비교할 줄 아는 것이라면 무엇이든 정렬해요. 숫자와 문자열이 그런데, 둘 다 `is_lt`를 가지고 있기 때문이에요.

## 나만의 기준으로 정렬하기

대부분의 순서는 기본으로 주어지는 순서가 아니에요. 넷볼 리그 순위는 알파벳 순도 아니고 이름 길이 순도 아니에요. 승점 순이고, 승점이 같은 팀끼리는 골 득실차 순이에요. `ARRAY`가 그걸 알아낼 방법은 없어요.

그래서 순서를 직접 넘겨줘요. 바인딩된 루틴(bound routine)으로요.

```sather
   before(a, b : STR) : BOOL is
      return a.size < b.size;
   end;

   ...

   words.insertion_sort_by(bind(before(_, _)));
```

`insertion_sort_by`는 `ROUT{T,T}:BOOL`을 받아요. 정렬할 대상 두 개를 받아서, 첫 번째가 두 번째보다 앞에 와야 하는지를 답하는 루틴이에요. 이 루틴을 필요한 만큼 호출하고, 그 답이 함축하는 순서대로 배열을 배치해요.

`understudy`가 바로 이걸 위한 것이었어요. 라이브러리는 정렬하는 법은 알지만, 내가 생각하는 순서에 대해서는 아무것도 몰라요. 바인딩된 루틴이 둘이 만나는 지점이에요.

## 비교 함수 작성하기

이 루틴은 **첫 번째 인자가 앞에 오면 true**를 답해요.

```sather
   -- shortest first
   return a.size < b.size;

   -- longest first: turn it round
   return a.size > b.size;
```

규칙에 여러 부분이 있다면, 중요한 순서대로 처리해요.

```sather
   higher(a, b : TEAM) : BOOL is
      if a.points /= b.points then
         return a.points > b.points;      -- more points comes first
      end;
      return a.difference > b.difference; -- level: better difference wins
   end;
```

승점이 다르면 첫 번째 `if`가 결판을 내요. 승점이 같을 때만 두 번째 줄이 발언권을 가져요. 동점 처리 규칙을 먼저 썼다면, 승점은 아무 의미가 없었겠죠.

## 정렬은 배열 자체를 바꿔요

`insertion_sort_by`는 배열 자체를 순서대로 정리하고 아무것도 답하지 않아요.

```sather
   teams.insertion_sort_by(bind(higher(_, _)));   -- teams is now sorted
```

원래 순서가 중요하다면, 복사본을 정렬해요.

```sather
   ranked ::= teams.copy;
   ranked.insertion_sort_by(bind(higher(_, _)));
   return ranked;
```
