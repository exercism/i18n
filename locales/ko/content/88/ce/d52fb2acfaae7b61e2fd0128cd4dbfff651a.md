# 소개

때로는 같은 코드를 여러 번 사용해야 할 때가 있어요. 그럴 때는 코드를 함수로 묶어 두면 편리해요. 함수는 보통 하나의 특정한 동작만 수행해요. Rust에서는 함수를 정의할 때 ```fn``` 키워드를 사용해요. 함수에 속한 코드는 항상 중괄호(즉 `{}`) 사이에 들어 있어요. `main`이라는 이름의 함수는 프로그램의 진입점이라서 특별해요. 이 함수에서 다른 함수를 호출할 수 있어요.

```rust
fn say_my_name(name: &str) -> &str {
    name
}
```

함수는 ```say_my_name()```의 ```name: &str```처럼 매개변수를 받을 수도 있어요. 또한 위의 `-> &str`처럼 값을 반환할 수도 있어요.
