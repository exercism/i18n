# 소개

## 정규 표현식

Gleam의 정규 표현식은 Java, JavaScript, Ruby 같은 다른 인기 언어들과 마찬가지로 **PCRE** 명세(**P**erl **C**ompatible **R**egular **E**xpressions)를 따라요.

`gleam_regexp` 패키지의 `gleam/regexp` 모듈은 정규 표현식을 다루는 함수들을 제공해요.

~~~~exercism/note
이 연습 문제는 문자 클래스, 수량자, 그룹, 캡처를 포함한 정규 표현식 문법을 이미 알고 있다고 가정해요.

정규 표현식에 대한 지식을 되새기고 싶다면 다음 자료 중 하나를 확인해 봐요: [Regular-Expressions.info](https://www.regular-expressions.info), [Rex Egg](https://www.rexegg.com/), [RegexOne](https://regexone.com/), [Regular Expressions 101](https://regex101.com/), [RegExr](https://regexr.com/).
~~~~

정규 표현식을 만드는 가장 일반적인 방법은 `regexp.from_string` 함수를 사용하는 거예요.

```gleam
let assert Ok(re) = regexp.from_string("test")
```

정규 표현식 생성 함수는 정규 표현식 문법이 잘못되면 오류를 반환해요. 그래서 여기서는 정규 표현식이 유효한지 확인하기 위해 let-assertion을 사용했어요.

`regexp.check` 함수를 사용하면 정규 표현식이 문자열과 일치하는지 확인할 수 있어요.

```gleam
let assert Ok(re) = regexp.from_string("test")

regexp.check(re, "this is a test")
// -> True

regexp.check(re, "this is too")
// -> False
```


### 캡처

정규 표현식으로 부분 문자열을 캡처하고 싶다면 `regexp.scan` 함수를 사용해 일치 목록을 반환받을 수 있어요.

```gleam
let assert Ok(re) = regexp.from_string("[oi]n a (\\w+)")
regexp.scan(with: re, content: "I am on a boat in a lake.")
// -> [
//   Match(
//     content: "on a boat",
//     submatches: [Some("boat")]
//   ),
//   Match(
//     content: "in a lake",
//     submatches: [Some("lake")]
//   )
// ]
```

### 옵션

정규 표현식의 동작은 `regexp.compile` 함수로 정규 표현식을 만들면서 옵션을 넘겨서 바꿀 수 있어요.

```gleam
let options = regexp.Options(case_insensitive: True, multi_line: False)
let assert Ok(re) = regexp.compile("[A-Z]", with: options)
regexp.check(re, "abc123")
// -> True
```
