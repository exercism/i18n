# 지침

예술가를 꿈꾸는 친구가 프로젝트 아이디어를 들고 찾아왔어요. 친구의 시각적 창의성과 기술적 전문성을 결합해 봐요. 이제 [생성 예술][generative-art]을 시작할 때예요!

제약은 창의성을 돕고 프로젝트 마감도 앞당겨 주기 때문에, 두 사람은 걸작을 단 하나의 도형, 원으로만 제한하기로 했어요. 그런데 원은 아주 많을 거예요. 게다가 움직이기까지 해요! 이름은... 춤추는 점들이에요.

친구는 점들을 위한 새롭고 정교한 움직임을 계속 만들어 내고 싶어 할 테니, 나중에 새로운 애니메이션을 쉽게 정의할 수 있는 구조를 만드는 것부터 시작해요.

## 1. 애니메이션 behaviour 정의하기

각 애니메이션 모듈은 `init/1`과 `handle_frame/3` 두 개의 콜백을 구현해야 해요. 이 둘을 `Animation` 모듈에 정의해요.

`init/1` 콜백을 정의해요. 이 콜백은 `opts` 타입의 인자 하나를 받고, `{:ok, opts}` 튜플이나 `{:error, error}` 튜플을 반환해야 해요. 이 콜백의 구현체는 주어진 옵션이 이 특정 애니메이션 유형에 유효한지 확인해요.

`handle_frame/3` 콜백을 정의해요. 이 콜백은 점, 프레임 번호, 옵션 세 개의 인자를 받아요. 항상 점을 반환해야 해요. 이 콜백의 구현체는 현재 프레임 번호와 애니메이션의 옵션에 따라 점의 속성을 수정해요.

## 2. `init/1` 콜백의 기본 구현 제공하기

`Animation` behaviour는 `use DancingDots.Animation`을 호출해서 다른 모듈에 쉽게 포함할 수 있어야 해요.

그렇게 하려면 `Animation` 모듈에 `__using__` 매크로를 구현해서, 다른 모듈의 behaviour로 `Animation` 모듈을 설정하게 해요. 또한 `init/1` 콜백의 기본 구현도 제공해야 해요. `init/1`의 기본 구현은 주어진 옵션을 그대로 반환해야 해요.

```elixir
defmodule MyCustomAnimation do
  use DancingDots.Animation
end

MyCustomAnimation.init(some_option: true)
# => {:ok, [some_option: true]}
```

## 3. `Flicker` 애니메이션 구현하기

`Animation` behaviour를 사용해서 깜빡이는 애니메이션을 구현해요.

이 애니메이션은 옵션을 받지 않기 때문에 기본 `init/1` 콜백을 사용해야 해요.

단일 프레임을 처리하는 `handle_frame/3` 콜백을 구현해요. 프레임 번호가 4의 배수라면, 함수는 원래 불투명도의 절반을 가진 점을 반환해야 해요. 다른 프레임에서는 점을 그대로 반환해야 해요.

프레임은 `1`부터 세요. `handle_frame/3`에 전달되는 점은 항상 원래 상태의 점이고, 이전 프레임의 상태가 아니에요.

```elixir
dot = %DancingDots.Dot{x: 100, y: 100, radius: 24, opacity: 1}

DancingDots.Flicker.handle_frame(dot, 1, [])
# => %DancingDots.Dot{opacity: 1, radius: 24, x: 100, y: 100}

DancingDots.Flicker.handle_frame(dot, 4, [])
# => %DancingDots.Dot{opacity: 0.5, radius: 24, x: 100, y: 100}
```

## 4. `Zoom` 애니메이션 구현하기

`Animation` behaviour를 사용해서 확대/축소 애니메이션을 구현해요.

이 애니메이션은 옵션을 하나 받아요. 바로 속도예요. 속도는 어떤 숫자든 될 수 있어요. 속도가 음수면, 점은 확대되는 대신 축소돼요.

`init/1` 콜백을 구현해요. 전달된 옵션이 `:velocity` 키를 가진 키워드 리스트인지 검증해야 해요. 속도 값은 숫자여야 해요. 숫자가 아니면, 오류 `"The :velocity option is required, and its value must be a number. Got: #{inspect(velocity)}"`를 반환해요.

`handle_frame/3` 콜백을 구현해요. 현재 프레임 번호에서 1을 뺀 값에 속도를 곱한 만큼 점의 반지름을 늘려서 반환해야 해요.

프레임은 `1`부터 세요. `handle_frame/3`에 전달되는 점은 항상 원래 상태의 점이고, 이전 프레임의 상태가 아니에요.

```elixir
DancingDots.Zoom.init(velocity: nil)
# => {:error, "The :velocity option is required, and its value must be a number. Got: nil"}

dot = %DancingDots.Dot{x: 100, y: 100, radius: 24, opacity: 1}

DancingDots.Zoom.handle_frame(dot, 1, velocity: 10)
# => %DancingDots.Dot{radius: 24, opacity: 1, x: 100, y: 100}

DancingDots.Zoom.handle_frame(dot, 2, velocity: 10)
# => %DancingDots.Dot{radius: 34, opacity: 1, x: 100, y: 100}
```
