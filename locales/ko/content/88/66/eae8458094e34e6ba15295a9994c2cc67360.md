# 소개

[Ballerina](https://ballerina.io/)는 텍스트 문법과 그래픽 문법을 모두 갖춘 컴파일 언어이자 트랜잭션을 지원하는 정적 강타입 프로그래밍 언어예요. Ballerina는 분산 시스템 통합의 핵심 개념을 언어 자체에 담고 있으며, 분산 트랜잭션, 안정적인 메시징, 스트림 처리, 워크플로를 활용한 마이크로서비스를 구현할 수 있도록 타입 안전한 동시성 환경을 제공해요.

Ballerina는 통합을 최대한 단순하게 만들도록 설계된 언어예요. 시퀀스 다이어그램의 상호작용을 중심으로 만들어져서, 분산 트랜잭션, 보상, 서킷 브레이커를 비롯한 일반적인 통합 패턴과 커넥터를 기본으로 지원해요. JSON과 XML을 언어 차원에서 온전히 지원하기 때문에, 네트워크 엔드포인트 전반에 걸쳐 견고한 통합을 간단하고 효과적으로 구축할 수 있어요.
