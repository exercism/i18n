# 숫자

Crystal에는 모든 숫자 타입의 기본이 되는 `Number` 타입이 있어요.
Number 타입 안에는 두 가지 주요 하위 타입이 있어요: [`Int`][int]와 [`Float`][float].

`Int`는 integer의 줄임말로, 정수를 나타내요.
`Int`는 소수점 없이 음수와 양수가 모두 될 수 있어요.

```crystal
1.class
# => Int32

-1.class
# => Int32
```

`Float`는 소수점이 있는 숫자를 나타내요.
`Float`는 음수와 양수가 모두 될 수 있어요.

```crystal
10.5.class
# => Float64
```

## `Int`와 `Float` 사이의 변환

'to_i'와 'to_f' 메서드를 사용하면 `Int`와 `Float` 사이를 변환할 수 있어요.
`Float`에서 `Int`로 변환할 때는 숫자가 내림돼요.

```crystal
1.to_f
# => 1.0

1.0.to_i
# => 1

1.9.to_i
# => 1
```

## 산술 연산자

`Int`와 `Float`에 [기본 산술 연산자][math]를 사용할 수 있어요.
연산자에는 `+`, `-`, `*`, `/`, `%`가 있어요.
이 연산자들을 사용할 때 `Int`와 `Float`를 섞어서 쓸 수 있어요.

### 덧셈, 뺄셈, 곱셈

`+` 연산자는 덧셈에, `-` 연산자는 뺄셈에, `*` 연산자는 곱셈에 사용해요.

| 연산자 | 예시           |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### 나눗셈

나눗셈은 숫자를 나누는 데 사용해요.
`/` 연산자가 나눗셈에 사용돼요.
결과는 항상 Float예요.

```crystal
4 / 2
# => 2.0

4.0 / 2
# => 2.0
```

~~~~exercism/caution
일부 프로그래밍 언어에서는 0으로 나누면 결과가 오류가 돼요.

Crystal에서는 0으로 나누면 결과가 `Infinity` 또는 `-Infinity`예요.
유일한 예외는 0을 0으로 나누는 경우로, 결과는 `NaN`(숫자가 아님)이에요.
`Infinity`와 `NaN`은 `Float` 타입의 특별한 값이에요.

```crystal
1 / 0
# => Infinity

-1 / 0
# => -Infinity

0 / 0
# => NaN
```
~~~~

### 나머지 연산

나머지 연산은 나눗셈의 나머지를 구할 때 사용해요.
`%` 연산자가 나머지 연산에 사용돼요.

```crystal
5 % 2
# => 1

5.0 % 2
# => 1.0

5 % 3
# => 2
```

~~~~exercism/caution
나머지 연산에서 0으로 나누면 DivisionByZeroError가 발생해요.
이건 일반적인 나눗셈과 달라요.

```crystal
1 % 0
# Error: Unhandled exception: Division by 0 (DivisionByZeroError)
```
~~~~

## 반올림

`round` 메서드는 선택적인 인자를 받아요: 반올림할 소수점 자릿수예요.
기본 소수점 자릿수는 0이에요.

```crystal
1.0.round
# => 1

1.5.round
# => 2

1.234.round(2)
# => 1.23
```

## 우선순위와 괄호

Crystal에서는 괄호(`()`)를 사용할 수 있고, 이걸로 표현식을 묶을 수 있어요.
연산 순서를 바꾸고 싶을 때 유용해요.

여러 산술 연산자를 사용할 때 연산 순서는 수학과 같아요. 이걸 [PEMDAS][pemdas]라고도 해요.
괄호(`()`), 지수(`**`), 곱셈(`*`)과 나눗셈(`/`), 그리고 덧셈(`+`)과 뺄셈(`-`) 순서를 따라요.

```crystal
2 + 3 - 4 * 4
# => -11

(2 + 3 - 4) * 4
# => 4
```
