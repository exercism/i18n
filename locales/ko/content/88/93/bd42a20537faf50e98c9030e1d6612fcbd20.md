# Instructions

이 연습 문제에서는 저축 계좌를 다뤄요. 매년 저축 계좌의 잔액은 이자율에 따라 업데이트돼요. 은행에서 제공하는 이자율은 계좌에 있는 금액(잔액)에 따라 달라져요:

- 잔액이 음수일 때 3.213% (음수의 이자가 발생해요).
- 잔액이 양수이면서 `1000`달러 미만일 때 0.5%.
- 잔액이 `1000`달러 이상 `5000`달러 미만일 때 1.621%.
- 잔액이 `5000`달러 이상일 때 2.475%.

매년 정부는 자신의 돈의 일정 비율을 세금 없이 자선 단체에 기부할 수 있게 해줘요. 착한 사람이니까, 연말에 잔액이 양수라면 비과세 비율을 두 배로 하고 가장 가까운 정수 달러로 내림해요. 기부금의 나머지 절반에는 세금을 내도 괜찮아요.

세 가지 작업이 있어요. 각 작업은 잔액과 이자율을 다뤄요.

## 1. 이자율 계산하기

지정된 잔액을 기준으로 이자율을 계산하는 `interestRate` 함수를 구현해 보세요:

```fsharp
interestRate 200.75m
// => 0.5f
```

참고로, 반환되는 값은 `single` 타입이에요.

## 2. 이자 계산하기

지정된 잔액을 기준으로 이자를 계산하는 `interest` 메서드를 구현해 보세요:

```fsharp
interest 200.75m
// => 1.00375m
```

참고로, 반환되는 값은 `decimal` 타입이에요.

## 3. 연간 잔액 업데이트 계산하기

이자율을 고려하여 연간 잔액 업데이트를 계산하는 `annualBalanceUpdate` 함수를 구현해 보세요:

```fsharp
annualBalanceUpdate 200.75m
// => 201.75375m
```

참고로, 반환되는 값은 `decimal` 타입이에요.

## 4. 기부할 금액 계산하기

잔액과 정부가 허용하는 비과세 비율을 기준으로 자선 단체에 기부할 금액을 계산하는 `amountToDonate` 함수를 구현해 보세요:

```fsharp
let balance = 550.5m
let taxFreePercentage = 2.5
amountToDonate balance taxFreePercentage
// => 27
```

참고로, 반환되는 값은 `int` 타입이에요.
