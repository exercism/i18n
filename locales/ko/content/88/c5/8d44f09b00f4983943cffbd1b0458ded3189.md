# 소개

Factor에서 문자는 정수, 곧 유니코드 코드 포인트예요. 그래서 숫자 비교 연산인 `<`, `>`, `=`만으로도 대소문자를 구분하는 순서를 바로 얻을 수 있어요. [`unicode`][unicode] 어휘를 불러오면 유니코드를 인식하는 판별 단어와 한 문자 단위의 대소문자 변환을 쓸 수 있어요.

## 문자 판별 단어

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
blank?   ( c -- ? )    ! whitespace
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
```

## 대소문자 변환

`ch>upper`와 `ch>lower`는 문자 하나를 바꿔요. 문자열 단위의 `>upper`와 `>lower`는 이 변환을 문자열의 모든 문자에 적용해요.

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```
