# 테스트

테스트를 실행하려면 R에 `{testthat}` 패키지가 설치되어 있어야 해요.
연습 문제의 테스트를 실행하려면, 해당 연습 문제 디렉터리에서 `test_<exercise_name>.R` 스크립트를 실행하기만 하면 돼요.

이때 [testthat의 `auto_test` 함수](https://testthat.r-lib.org/reference/auto_test.html)를 사용하면 편리해요. Exercism의 코드와 테스트는 같은 폴더에 있으므로, `code_path`와 `test_path` 매개변수 모두에 이 경로를 사용해요. 명령줄에서는 `Rscript test_<exercise_name>.R`를 실행할 수도 있어요.

더 자세한 내용은 [테스트 페이지](https://exercism.org/docs/tracks/r/tests)를 참고해요.
