# 소개

커스텀 타입의 종류가 데이터를 담고 있으면 레코드라고 하며, 담긴 값은 각각 _필드_에 들어 있어요.

```gleam
pub type Rectangle {
  Rectangle(
    Float, // The first field
    Float, // The second field
  )
}
```

Gleam에서는 가독성을 높이기 위해 필드에 레이블을 붙일 수 있어요.

```gleam
pub type Rectangle {
  Rectangle(
    width: Float,
    height: Float,
  )
}
```

레이블을 사용하면 레코드의 생성자에 인자를 순서에 상관없이 전달할 수 있어요.

```gleam
let a = Rectangle(height: 10.0, width: 20.0)
let b = Rectangle(width: 20.0, height: 10.0)

a == b
// -> True
```

커스텀 타입에 종류가 하나뿐이라면 `.label` 접근자 문법으로 레코드의 필드를 꺼낼 수 있어요.

```gleam
let rect = Rectangle(height: 10.0, width: 20.0)

rect.height // -> 10.0
rect.width  // -> 20.0
```

커스텀 타입에 종류가 하나뿐일 때는 레코드 업데이트 문법을 사용해서 기존 레코드로부터 일부 필드만 새로운 값으로 바꾼 새 레코드를 만들 수 있어요.

```gleam
let rect = Rectangle(height: 10.0, width: 20.0)
let tall_rect = Rectangle(..rect, height: 50.0)

tall_rect.height // -> 50.0
tall_rect.width  // -> 20.0
```

패턴 매칭으로 레코드에서 값을 추출할 때도 레이블을 사용할 수 있어요.

```gleam
pub fn is_tall(rect: Rectangle) {
  case rect {
    Rectangle(height: h, width: _) if h > 20.0 -> True
    _ -> False
  }
}
```

필드 일부만 매칭하고 싶다면 스프레드 연산자 `..`를 사용해서 나머지 필드를 무시할 수 있어요.

```gleam
pub fn is_tall(rect: Rectangle) {
  case rect {
    Rectangle(height: h, ..) if h >. 20.0 -> True
    _ -> False
  }
}
```
