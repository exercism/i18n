# 소개

PHP는 웹 개발에 적합한 서버 사이드 언어예요. 이 약어는 재귀적이에요. _PHP: Hypertext Preprocessor_의 줄임말이거든요.

PHP는 CGI 스크립팅보다 훨씬 다재다능해요. 평범한 HTML에 상호작용을 더하거나 웹 프레임워크를 뒷받침하는 데 자주 쓰이죠.

이 언어는 어떤 운영체제에서든 사용할 수 있어요. PHP는 대부분의 일반적인 웹 서버에서 지원하며, 흔히 인터프리터 모듈을 통해 처리돼요. 이렇게 해서 정적인 웹 코드와 동적인 포함이 결합돼요.

PHP는 웹 서버 프레임워크만이 아니에요. 명령줄 스크립팅(헤드리스 파싱)과 GUI 개발에도 유용해요.

PHP를 배워야 하는 이유는 다음과 같아요.

- 오픈 소스 언어예요.
- 문서와 지원이 잘 갖춰져 있어요.
- 대부분의 일반적인 웹 서버와 호환돼요.
- 익히기 쉽고 금방 시작할 수 있어요.
- 규모를 키우기 쉽고 기능을 확장하기도 쉬워요.
