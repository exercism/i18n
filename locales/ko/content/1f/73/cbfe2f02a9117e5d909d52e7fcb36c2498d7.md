# 개요

`while`과 `until`은 ([`kernel`][kernel]에 있는) 쿼테이션 기반 루프 컴비네이터로, 반복 횟수를 미리 알 수 없을 때 써요.

```
while ( pred: ( -- ? ) body: ( -- ) -- )
until ( pred: ( -- ? ) body: ( -- ) -- )
```

`while`은 `pred`가 참으로 취급되는 값을 남기는 동안 계속 실행하고, `until`은 `pred`가 `f`를 남기는 동안 계속 실행해요. 둘 다 조건자가 뒤집히면 멈추고 값을 반환해요.

```factor
USING: kernel math ;

! Halve down to 1
16 [ dup 1 > ] [ 2 / ] while .   ! => 1

! Double up to 100
1 [ dup 100 >= ] [ 2 * ] until .   ! => 128
```

스택 위를 흐르는 값 하나만으로는 상태를 담기에 충분하지 않을 때가 있어요. 예를 들어 남은 목록, 누적 합계, 카운터가 한꺼번에 필요한 경우처럼요. 이럴 때 가장 깔끔한 방법은 *로컬*에 이름을 붙여 쓰는 거예요. 로컬은 커리큘럼 뒤에서 더 자세히 다뤄요. 지금은 `:: word ( a b -- c )`가 입력값을 이름 있는 로컬로 선언하고, `:> name!`이 본문에서 `value name!`로 값을 바꿀 수 있는 로컬을 추가한다는 것만 알아두면 충분해요.

```factor
USING: kernel locals math sequences ;

! Sum a sequence by hand
:: sum-by-hand ( seq -- total )
    seq :> rest!
    0 :> running!
    [ rest length 0 > ] [
        rest unclip [ rest! ] dip
        running + running!
    ] while
    running ;
```
