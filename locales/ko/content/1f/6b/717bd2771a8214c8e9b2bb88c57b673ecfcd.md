# 안내

루턴의 도서관은 책부터 예술 작품까지 다양한 문학 작품을 소장한 큰 도서관이에요.
도서관에는 문학을 연구하고 컴퓨터 시스템에 책을 등록하는 부서가 있어요.

일부 업무는 자동화를 목표로 하고 있어서, 여러분에게 도움을 요청했어요.
여기에는 도서 등록 양식 자동화부터 암호화된 텍스트 해독까지 다양한 작업이 포함돼요.

## 1. 제목의 첫 글자 가져오기

도서관의 책은 찾기 쉬워야 하므로 제목의 첫 글자를 기준으로 정렬돼요.

도서의 제목을 담은 인자 `title`을 받는 `Library.first_letter` 메서드를 구현해요.
이 메서드는 제목의 첫 글자를 반환해야 해요.

```Crystal
Library.first_letter("Mystery of the Crystal Skull")
# => 'M'
```

## 2. 저자의 이니셜 가져오기

도서관에는 다양한 저자가 쓴 책이 아주 많아요.
저자는 흔히 이니셜로 불리기 때문에, 도서관은 저자의 이름과 성을 입력하면 이니셜을 알려주는 시스템을 요청했어요.
이니셜은 `{first_letter_of_first_name}.{first_letter_of_last_name}` 형식으로 만들어야 해요.

저자의 이름과 성을 담은 두 인자 `first_name`과 `last_name`을 받는 `Library.initials` 메서드를 구현해요.
이 메서드는 저자의 이니셜을 반환해야 해요.

```Crystal
Library.initials("William", "Shakespeare")
# => "W.S"
```

## 3. 글자 복호화하기

일부 문학 작품은 암호화되어 있고, 도서관에는 암호화된 텍스트가 많아요.
도서관은 특별한 암호화 방식에 대응하는 새로운 복호화 시스템을 원해요.

이 암호화는 글자를 알파벳에서 그 앞에 오는 글자로 바꾸는 방식으로 동작해요.
예를 들어 `a`는 `z`가 되고, `b`는 `a`가 되고, `c`는 `b`가 되는 식이에요.

도서관은 대문자와 소문자를 모두 복호화하면서 원래 글자의 대소문자를 그대로 유지하기를 원해요.

복호화할 글자를 담은 인자 `character`를 받는 `Library.decrypt_character` 메서드를 구현해요.
이 메서드는 복호화된 글자를 반환해야 해요.

```Crystal
Library.decrypt_character('a')
# => 'z'
```

## 4. 텍스트 복호화하기

도서관은 알파벳에서 앞 글자를 취하는 이 암호화 방식으로 텍스트 전체를 복호화하는 것도 원해요.

복호화기는 글자만 복호화하고 다른 모든 문자는 그대로 둬야 해요.

복호화할 텍스트를 담은 인자 `text`를 받는 `Library.decrypt_text` 메서드를 구현해요.
이 메서드는 복호화된 텍스트를 반환해야 해요.

```Crystal
Library.decrypt_text("Ifmmp Xpsme!")
# => "Hello World!"
```
