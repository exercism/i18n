# Null

Null은 값이 `null` 하나뿐인 원시 타입이에요.
Null은 아무것도 없음을 나타낼 때 자주 사용돼요.
"falsey"로 취급되지만, `false`나 다른 falsey 값과는 구별돼요.

```php
<?php

is_null(null); // => true
isset(null); // => false

null == true; // => false
null === true; // => false

null == false; // => true
null === false; // => false
```

## null 값 다루기

PHP에서 null 값은 자주 오류의 원인이 돼요. 오류 상태를 대신하거나 아무것도 없음을 나타내기 위해 반환되는 경우가 많거든요.
오류가 생기는 것을 막으려면 값을 다루기 전에 그 값이 null이 아닌지 확인하는, 이른바 "null 검사"가 필요한 경우가 많아요.

null 검사를 반복하면 오류가 생기기 쉬워요. 그래서 PHP는 null 값을 다루기 위한 두 가지 연산자를 제공해요. null 안전 접근 연산자 `?->`와 null 병합 연산자 `??`예요.
