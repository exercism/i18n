# Haskell 문법 기초

## 상수와 함수

Haskell 프로그램은 정의와 표현식으로 이루어져 있어요.

상수 값은 `name = expression`으로 정의해요.

```haskell
five = 5

six = 3 + 3
```

함수는 `name parameters... = expression`으로 정의하는데, 매개변수는 공백으로만 구분해요.

```haskell
add number1 number2 = number1 + number2
```

함수를 호출하는 것도 표현식이에요. 함수 이름을 쓰고 함수의 각 매개변수에 대응하는 인자를 공백으로 구분해 전달하면 돼요. 함수를 정의할 때와 똑같아요.

```haskell
five = add 2 3
```

괄호를 사용하면 표현식의 평가 순서를 지정할 수 있어요.

```haskell
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## 들여쓰기 / 유의미한 공백

Haskell은 공백과 들여쓰기로 코드의 경계를 나타내요.
***어떤 표현식에 속한 코드는 그 표현식의 시작보다 더 안쪽으로 들여써야 해요.***

- 모듈, import, 최상위 함수 정의는 가장 왼쪽 열에서 시작해야 해요.
- 표현식을 여러 줄로 나눈 경우, 그 표현식에 속한 코드는 표현식 아래에 최소한 공백 한 칸으로 들여써야 해요.
- 함께 묶이는 표현식의 부분들은 같은 수의 공백으로 들여써야 해요.

```haskell
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://en.wikibooks.org/wiki/Haskell/Indentation

## 모듈

모듈은 함수를 내보내요.
즉, 모듈이 export 문에 명시한 함수를 사용할 수 있다는 뜻이에요.
모듈은 내부에서만 쓸 함수를 정의할 수도 있어요.
기본적으로 명시적으로 내보내지 않은 함수는 모듈 밖에서 사용할 수 없어요.

모듈 맨 앞에는 모듈 이름을 적어요.
Calculator.hs라는 파일이 있다면 모듈 이름도 Calculator로 지어야 해요.
그다음 내보낼 함수를 적고, 그 뒤부터 함수를 작성하면 돼요.
그래서 이렇게 시작해요.

```haskell
module Calculator ( add ) where
```

https://learnyouahaskell.github.io/modules#making-our-own-modules

## 주석

주석은 Haskell 파일 안에 있으면서 코드로 해석되지 않는 글을 말해요.
주로 자신과 다른 프로그래머가 읽도록 쓰는 거예요.
한 줄 주석에는 간단한 문법이 있는데, 하이픈 두 개를 사용해요.
여러 줄 주석은 여는 구분자 `{-`와 닫는 구분자 `-}` 쌍으로 쓸 수도 있어요.

```haskell
-- a single line comment
-- another single line comment

{- a multiline comment
   spanning multiple lines
-}
```
