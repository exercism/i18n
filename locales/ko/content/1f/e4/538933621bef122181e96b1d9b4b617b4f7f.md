# 소개

## 딕셔너리

딕셔너리는 원소들의 모음이에요. 각 원소는 키와 값으로 이루어져 있고, 딕셔너리의 메서드에 키를 전달하면 그 키에 연결된 값이 반환돼요. 다른 언어에서 맵이나 연관 배열이 하는 역할과 같아요.

딕셔너리는 다음과 같이 만들 수 있어요.

```csharp
new Dictionary<int, string>();
// Empty dictionary
```

또는

```csharp
new Dictionary<int, string>
{
    [1] = "One",
    [2] = "Two"
};

// Or

new Dictionary<int, string>
{
    {1, "One"},
    {2, "Two"}
};
// 1 => "One", 2 => "Two"
```

키와 값의 타입도 딕셔너리 정의의 일부라는 점에 주의해요.

한 번 만들고 나면, 딕셔너리에 내장된 `Add`와 `Remove` 메서드를 사용해 항목을 추가하거나 제거할 수 있어요.

딕셔너리에서 값을 가져오거나 바꿀 때는 키를 사용해 딕셔너리를 인덱싱해요.

```csharp
var numbers = new Dictionary<int, string>
{
   {1, "One"},
   {2, "Two"}
};

// Set the value of the element with key 2 to "Deux"
numbers[2] = "Deux";

// Get the value of the element with key 2
numbers[2];
// => "Deux"
```

딕셔너리에 값이 존재하는지 확인하려면 다음과 같이 해요.

```csharp
var dict = new Dictionary<string, string>{/*...*/};
dict.ContainsKey("some key that exists");
// => true
```

딕셔너리를 열거하면 키/값 쌍을 열거하게 돼요. 딕셔너리에는 키나 값만 열거할 수 있게 해 주는 속성도 있어요.
