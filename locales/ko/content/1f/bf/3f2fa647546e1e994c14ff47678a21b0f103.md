# 지침 추가

## 예외 메시지

때로는 [예외를 발생시켜야](https://docs.python.org/3/tutorial/errors.html#raising-exceptions) 할 때가 있어요. 이럴 때는 오류의 원인이 무엇인지 알려 주는 **의미 있는 오류 메시지**를 항상 함께 넣어야 해요. 그러면 code를 더 읽기 쉽게 만들어 주고 debugging에도 큰 도움이 돼요. 오류의 원인이 특정 유형이라고 알고 있는 상황이라면 [내장 오류 유형](https://docs.python.org/3/library/exceptions.html#base-classes) 중 하나를 골라 발생시켜도 되지만, 그래도 의미 있는 메시지는 꼭 포함해야 해요.

이 연습 문제에서는 주어진 값이 배열 안에서 발견되지 않을 때 [raise 문](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)으로 `ValueError`를 "던져야" 해요. 테스트는 `exception`을 `raise`하면서 메시지도 함께 포함해야만 통과해요.

메시지와 함께 `ValueError`를 발생시키려면, 메시지를 `exception` 유형의 인자로 작성해요.

```python
# example when value is not found in the array.
raise ValueError("value not in array")
```
