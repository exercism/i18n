# 참고 자료

## 첫 Coffee 모듈 만들기

`Bob = require './bob'`로 불러올 수 있는 모듈을 만들려면, 다음 코드를 `bob.coffee`에 작성해요:

```coffeescript
class Bob

module.exports = Bob
```

모듈에 대한 더 자세한 내용은 [Node 문서](http://nodejs.org/api/modules.html#modules_module_exports)에서 확인할 수 있어요.

## Windows에서 Visual Studio 사용하기

유료 버전의 Visual Studio가 있다면, CoffeeScript와 Visual Studio가 지원하는 다른 언어들을 바로 사용할 수 있도록 미리 설정된 Visual Studio 솔루션을 내려받을 수 있어요.

![솔루션 탐색기](https://raw.githubusercontent.com/exercism/coffeescript/main/docs/img/SolutionExplorer.png)

1. 페이지에서 Download Zip 버튼을 클릭해 GitHub에서 [Exercism.io Visual Studio Template](https://github.com/rprouse/Exercism.VisualStudio)을 내려받아요.
2. 템플릿의 압축을 풀어서 연습 문제 디렉터리에 넣어요. 예를 들어 `C:\src\exercises`와 같이요.
2. [Exercism CLI](http://exercism.io/cli)를 설치해요
3. 연습 문제 디렉터리에서 명령 프롬프트를 열어요
4. exercism에 API 키를 추가해요: `exercism configure --key=YOUR_API_KEY`
5. exercism에서 소스 디렉터리를 설정해요: `exercism configure --dir=C:\src\exercises`
6. [첫 연습 문제를 가져와요](http://exercism.io/languages/coffeescript): `exercism fetch coffeescript`
7. Visual Studio에서 Exercism 솔루션을 열어요
8. Exercism.coffeescript 프로젝트를 펼쳐요
9. Solution Explorer에서 **Show All Files**를 클릭해요 (아래 참고)
10. 방금 가져온 연습 문제가 회색으로 표시돼요. 폴더를 마우스 오른쪽 버튼으로 클릭하고 **Include In Project**를 선택해요.
11. 이제 코딩을 시작해요...

![파일 추가](https://raw.githubusercontent.com/exercism/coffeescript/main/docs/img/AddFiles.png)

Visual Studio에서 CoffeeScript로 작업하려면 [Web Essentials](http://vswebessentials.com/) 확장을 설치하는 게 좋아요. JavaScript로 작업할 때도 훨씬 수월해져요.

프로젝트에 있는 배치 파일을 사용하면 Node.js 명령줄에서 단위 테스트를 실행할 수 있어요.

```bash
C:\Src\exercises\coffeescript> test example\bob_test.spec.coffee
.................

Finished in 0.02 seconds
17 tests, 17 assertions, 0 failures, 0 skipped
```

테스트를 실행했는데 아무 출력도 보이지 않는다면, Node.js 명령 프롬프트가 아닐 가능성이 커요.
