# 퍼센트 또는 "구식" 포매팅

이 풀이는 문자열에 `%%-formatting` 또는 [구식 포매팅][old-style formatting]을 사용해요.

`%%-formatting`은 완전히 유효한 방법이지만, 표현이나 가독성 문제를 일으킬 수 있어요.
[str.format()][str.format()] 메서드나 [f-strings][f-strings] (_다른 말로 "형식 문자열 리터럴" 또는 "보간 문자열"이라고도 해요_)를 사용하면 가독성을 높이고 문자열 안의 변수 치환을 더 명확하게 만들어 주는 옵션을 제공할 수 있어요.

블로그 글 [String Formatting in Python][string formatting in python]은 Python의 모든 문자열 포매팅 옵션을 이해하는 데 좋은 출발점이에요. 또한 [Newer Python String Format Techniques][newer python string format techniques]에는 `str.format()` 및 `f-strings` 사용에 도움이 되는 팁과 요령도 있어요.
