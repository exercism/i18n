# 소개

## 아톰

Elixir의 `atom` 타입은 고정된 상수를 나타내요. 아톰의 값은 그저 자기 이름이에요. 덕분에 데이터를 타입에 안전한 방식으로 다룰 수 있죠. 아톰은 다음과 같이 정의할 수 있어요:

```elixir
# All atoms are preceded with a ':' then follow with alphanumeric snake-cased characters
variable = :an_atom
```

_아톰_은 내부적으로 룩업 테이블의 정수로 표현되는데, 이 값은 자동으로 정해져요. 이 내부 값은 바꿀 수 없어요.

## Cond

조건에 따라 분기하는 코드를 작성하고 싶을 때가 많아요. Elixir에서 이걸 하는 방법은 여러 가지지만, 가장 간단한 방법 중 하나는 `cond/1`을 사용하는 거예요.

가장 단순하게 말하면, `cond`는 하나 이상의 분기 중에서 `true`로 평가되는 첫 번째 경로를 따라가요:

```elixir
cond do
  x > 10 -> :this_might_be_the_way
  y < 7 -> :or_that_might_be_the_way
  true -> :this_is_the_default_way
end
```

`true`로 평가되는 경로가 없으면 런타임이 오류를 발생시켜요.
