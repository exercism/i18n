# 안내

이 연습 문제에서는 프로그래밍 언어 배열을 다루는 몇 가지 함수를 구현해요.

## 1. 빈 언어 배열을 반환하는 함수를 정의해요

인자를 받지 않고 빈 배열을 반환하는 `language_list` 함수를 정의해요.

```php
<?php

language_list();
// => []
```

## 2. 여러 개의 언어로 배열을 만드는 함수로 수정해요

`language_list` 함수를 수정해서 언어(문자열)를 가변 인자로 받도록 해요. 그러면 전달받은 언어들이 담긴 배열을 반환해요.

```php
<?php

$language_list = language_list();
// => []
$language_list = language_list("Clojure", "PHP");
// => ["Clojure", "PHP"]
$language_list = language_list("PHP", "Haskell", "Java", "C++", "Rust")
// => ["PHP", "Haskell", "Java", "C++", "Rust"]
```

## 3. 배열에 언어를 추가하는 함수를 정의해요

언어 배열과 새 언어, 이렇게 두 개의 인자를 받는 `add_to_language_list` 함수를 정의해요.

```php
<?php

$language_list = language_list();
// => []
$language_list = add_to_language_list($language_list, "Clojure");
// => ["Clojure"]
```

## 4. 언어 배열에서 항목을 제거하는 함수를 정의해요

언어 배열에서 첫 번째 언어를 제거하는 `prune_language_list` 함수를 정의해요.

```php
<?php

$language_list = language_list("PHP");
// => ["PHP"]
$language_list = prune_language_list($language_list);
// => []
```

## 5. 배열의 첫 번째 항목을 가져오는 함수를 정의해요

인자 하나(언어 배열)를 받는 `current_language` 함수를 정의해요. 이 함수는 배열의 첫 번째 언어를 반환해요. 배열에는 항상 항목이 적어도 하나는 있다고 가정해요.

```php
<?php

$language_list = language_list("PHP", "Prolog");
// => ["PHP", "Prolog"]
$first = current_language($language_list);
// => "PHP"
```

## 6. 배열에 언어가 몇 개 있는지 반환하는 함수를 정의해요

인자 하나(언어 배열)를 받는 `language_list_length` 함수를 정의해요. 이 함수는 배열에 있는 언어의 개수를 반환해요.

```php
<?php

$language_list = language_list("PHP", "Prolog", "Wren");
// => ["PHP", "Prolog", "Wren"]
language_list_length($language_list);
// => 3
```
