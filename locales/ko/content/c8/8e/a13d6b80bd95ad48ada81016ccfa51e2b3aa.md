# 기초

Sather 프로그램은 **루틴**을 담고 있는 **클래스**로 이루어져 있어요.

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

end; -- class GREETER
```

## 클래스

클래스 이름은 대문자로 쓰고, 단어 사이는 밑줄로 이어요: `GREETER`,
`STAGE_DIRECTIONS`. 파일 이름도 보통 여기에 맞춰 소문자로 지어요:
`stage_directions.sa`.

모든 루틴은 클래스 안에 들어 있어요. 클래스 밖에는 코드가 없어요.

## 루틴

결과를 만들어 내는 루틴은 콜론 뒤에 그 결과의 타입을 밝혀요:

```sather
   hello : STR is
      return "Hello!";
   end;
```

`STR`은 텍스트를 나타내는 타입이에요. 인자를 받지 않는 루틴은 괄호 없이
쓰고 호출해요.

루틴은 인자를 받을 수도 있는데, 이름 뒤 괄호 안에 적어요:

```sather
   louder(word : STR) : STR is
      return word;
   end;
```

`return`은 결과를 돌려주고 루틴을 곧바로 멈춰요. 그래서 그 아래에 있는
줄은 건너뛰어요.

## 호출하기

클래스 바깥에서는 클래스 이름을 쓰고, `::`를 붙인 다음, 루틴 이름을
써요:

```sather
GREETER::hello
```

같은 클래스 안에서는 클래스 이름을 생략할 수 있어요. 한 루틴이 다른
루틴을 쓰게 하는 보통의 방법이에요:

```sather
   greeting_again : STR is
      return hello;
   end;
```

## 주석

대시 두 개로 시작하는 주석은 그 줄 끝까지 이어져요.

```sather
   -- Explain why, not what: the code already says what.
   hello : STR is
      return "Hello!";   -- a trailing comment is fine too
   end;
```

관례적으로 클래스는 자기 이름을 밝히는 주석으로 끝나요. 루틴, 루프,
클래스가 모두 `end;`로 닫히기 때문에, 주석이 이 `end;`가 어디에 속하는지
알려 줘요:

```sather
end; -- class GREETER
```

## 세미콜론

문은 세미콜론으로 끝나요. 루틴의 마지막 문 뒤에 오는 세미콜론은
생략해도 되지만, 매번 써 두면 신경 쓸 일이 하나 줄어요.
