# 안내

친구 Li Mei는 맛있는 과일 주스를 섞어 파는 주스 바를 운영해요. 여러분은 Li Mei 가게의 단골손님이고, Factor 코드로 Li Mei의 삶을 조금 더 편하게 만들어 줄 수 있겠다고 생각했어요.

## 1. 주스를 섞는 데 걸리는 시간 구하기

Li Mei는 메뉴에 있는 주스를 주문한 손님에게 얼마나 기다려야 하는지 미리 알려 주는 걸 좋아해요. 주스를 섞는 데 걸리는 시간이 제각각이라 정확한 숫자를 기억하기 어려워해요.

- `"Pure Strawberry Joy"`는 `0.5`분 걸려요.
- `"Energizer"`와 `"Green Garden"`은 각각 `1.5`분 걸려요.
- `"Tropical Island"`는 `3`분 걸려요.
- `"All or Nothing"`은 `5`분 걸려요.
- 그 밖의 다른 음료(예: 특별 메뉴)는 `2.5`분 걸려요.

`time-to-mix-juice`는 스택에서 주스 이름 하나를 꺼내 그 음료를 섞는 데 걸리는 분 수를 반환하도록 정의해요.

```factor
"Tropical Island" time-to-mix-juice .
! => 3

"Berries & Lime" time-to-mix-juice .
! => 2.5
```

## 2. 라임 조각 재고 채우기

Li Mei가 만드는 음료에는 재료로든 장식으로든 라임 조각이 들어가는 경우가 많아요. 그래서 아침에 근무를 시작할 때는 하루 동안 쓸 라임 조각 통이 가득 차 있는지 확인해야 해요.

`wedges-from-lime`은 라임 크기를 받아 그 라임에서 나오는 조각 수를 반환하도록 정의해요. `"small"` 라임에서는 `6`개, `"medium"`에서는 `8`개, `"large"`에서는 `10`개예요.

그다음 `limes-to-cut`은 필요한 조각 수 `needed`와 `limes` 배열(자를 순서대로 나열한 라임 크기)을 받도록 정의해요. 라임을 순서대로 하나씩 자르다가, 조각이 충분해지거나 라임이 떨어지면 곧바로 멈춰요. 잘라야 했던 라임의 개수를 반환해요.

```factor
25 { "small" "small" "large" "medium" "small" } limes-to-cut .
! => 4
```

## 3. 대기 중인 주문별 제조 시간 나열하기

Li Mei는 손님들이 기다리는 주문을 섞는 데 얼마나 걸릴지 파악해 두는 걸 좋아해요.

`order-times`는 주문 배열을 받아 각 주문을 섞는 데 걸리는 시간을 같은 순서로 담은 배열을 반환하도록 정의해요.

```factor
{ "Energizer" "Tropical Island" } order-times .
! => { 1.5 3 }
```

## 4. 근무 마무리하기

Li Mei는 항상 오후 3시까지 일해요. 그다음에는 직원 Dmitry가 이어받아요. Li Mei의 근무가 끝날 때 주문은 들어왔지만 아직 만들지 않은 음료가 남아 있는 경우가 많고, 그러면 Dmitry가 남은 주스를 만들어요.

인수인계를 쉽게 하기 위해 `remaining-orders`는 Li Mei의 근무에 남은 시간(분) `time-left`와 `orders` 배열(주문은 들어왔지만 아직 만들지 않은 주스)을 받도록 정의해요. Dmitry가 이어서 맡아야 할 주문, 즉 Li Mei가 근무가 끝나기 전에 시작할 시간이 없는 주문을 반환해요.

`time-left`는 항상 `0`보다 커요. 주문은 배열에 나온 순서대로 만들어져요. Li Mei는 주스를 한번 시작하면 조금 더 일해야 하더라도 반드시 끝내요. 모든 주문을 시작할 시간이 있다면 빈 배열을 반환해요.

```factor
5 { "Energizer" "All or Nothing" "Green Garden" } remaining-orders .
! => { "Green Garden" }
```
