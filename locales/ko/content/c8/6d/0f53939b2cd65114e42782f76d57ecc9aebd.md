# 지침

Josh는 새로운 롤플레잉 게임을 만들고 있는데, 몇 가지 메커니즘을 구현하는 데 도움이 필요해요.

## 1. 유니온 타입 정의하기

`String`과 `Missing`의 유니온 타입을 `StringOrMissing`이라는 이름으로 정의해요. 이 타입은 뒤에 나오는 코드에서 사용할 수 있어요.
`Int64`와 `Nothing`의 유니온 타입을 `IntOrNothing`이라는 이름으로 정의해요. 이 타입도 뒤에 나오는 코드에서 사용할 수 있어요.

## 2. Player 복합 타입 구현하기

Player 복합 타입은 네 개의 필드를 포함해야 하고, 각 필드에는 타입 애너테이션과 기본값이 있어요:
- `name`은 `StringOrMissing`이고, 기본값은 `missing`이에요.
- `level`은 `Int64`이고, 기본값은 `0`이에요.
- `health`는 `Int64`이고, 기본값은 `100`이에요.
- `mana`는 `IntOrNothing`이고, 기본값은 `nothing`이에요.

```julia-repl
julia> defaultplayer = Player()
Player(missing, 0, 100, nothing)

julia> wealthyplayer = Player(mana=100)
Player(missing, 0, 100, 100)

julia> namedplayer = Player(name="Guilian", level=10)
Player("Guilian", 10, 100, nothing)
```

## 3. 자기소개하기

`introduce` 함수를 구현해요.

은신한 플레이어는 이름을 숨기고 있을 수 있으며, `"Mighty Magician"`으로 소개돼요.
그렇지 않으면 플레이어의 이름을 그대로 사용해 소개해요.

```julia-repl
julia> introduce(Player(level=2, health=8))
"Mighty Magician"

julia> introduce(Player(name="Merlin", level=2, health=8))
"Merlin"
```

## 4. increment 메서드 구현하기

`increment` 도우미 함수에는 두 개의 메서드가 있고, 각각 함수 시그니처가 달라요.
각 메서드의 인자에는 시그니처를 명확히 하기 위한 타입 애너테이션이 필요해요.

이름을 위한 `increment` 메서드는 플레이어의 `name`을 받아요.
- 이름이 `missing`이면 "The Great"라는 칭호를 반환해요.
- 그렇지 않으면 이름 뒤에 " the Great"라는 칭호가 붙어요.

이 `increment` 메서드는 새로운 이름을 반환해요.

```julia-repl
julia> player1 = Player(name="Ogre", level=5, health=49, mana=26)
Player("Ogre", 5, 49, 26)

julia> increment(player1.name)
"Ogre the Great"

julia> player2 = Player(level=32, mana=57)
Player(missing, 32, 100, 57)

julia> increment(player2.name)
"The Great"
```

마나를 위한 `increment` 메서드는 플레이어의 `mana`를 받아요.
- 플레이어의 마나가 `missing`이면 `50`을 반환해요.
- 그렇지 않으면 마나를 `100`만큼 증가시켜요.

이 `increment` 메서드는 갱신된 마나를 반환해요.

```julia-repl
julia> player3 = Player(level=3)
Player(missing, 3, 100, nothing)

julia> increment(player3.mana)
50

julia> player4 = Player("Goblin", level=15, health=49, mana=26)
Player("Goblin", 5, 49, 26)

julia> increment(player4.mana)
126
```

## 5. title 함수 구현하기

게임에서 가장 높은 레벨은 `42`예요.  이 레벨을 달성한 플레이어의 업적을 기리기 위해 이름에 칭호를 붙여요.  `title!` 함수는 플레이어의 이름을 다음과 같이 갱신해요.

- 플레이어의 레벨이 42이면 `increment` 함수를 사용해 이름을 갱신해요.
- 그렇지 않으면 이름은 그대로 유지돼요.

어느 경우든 `title!` 함수는 플레이어의 이름을 반환해요.

```julia-repl
julia> player1 = Player(level=42, health=12)
Player(missing, 42, 12, nothing)

julia> title!(player1)
"The Great"

julia> player1.name
"The Great"

julia> player2 = Player(name="Svengali", level=42, health=36, mana=54)
Player("Svengali", 42, 36, 54)

julia> title!(player2)
"Svengali the Great"

julia> player2.name
"Svengali the Great"

julia> player3 = Player(name="Rasputin", level=21, health=100, mana=54)
Player("Rasputin", 21, 100, 54)

julia> title!(player3)
"Rasputin"

julia> player3.name
"Rasputin"
```

## 6. revive 함수 구현하기

`revive!` 함수는 플레이어의 캐릭터가 실제로 죽었는지(체력이 `0`이 되었는지) 확인해야 해요.

플레이어가 죽었다면:
- 플레이어를 체력 `100`으로 되살려요.
- 플레이어의 마나를 `increment` 함수를 사용해 증가시켜요.

플레이어가 살아 있다면 아무 일도 일어나지 않아요.

`revive!` 함수는 플레이어를 반환해야 해요.

```julia-repl
julia> deadplayer1 = Player(level=2, health=0)
Player(missing, 2, 0, nothing)

julia> revive!(deadplayer1)
Player(missing, 2, 100, 50)

julia> deadplayer2 = Player(level=12, health=0, mana=5)
Player(missing, 12, 0, 5)

julia> revive!(deadplayer2)
Player(missing, 12, 100, 105)

julia> aliveplayer = Player(level=23, health=1)
Player(missing, 23, 1, nothing)

julia> revive!(aliveplayer)
Player(missing, 23, 1, nothing)
```
