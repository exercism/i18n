# 지침

거북이용 이불을 만드는 회사에 보조 생산 엔지니어로 입사했어요.

주문은 하루 종일 고객 이름이나 번호, 그리고 주문 수량의 형태로 들어와요. 이 주문들은 그날의 생산이 시작되기 전 아침에 처리돼요.

그날의 주문이 모두 채워지면 급여는 그대로 받으면서 집에 갈 수 있어요. 그래서 근무 시간을 최대한 줄일 유인이 있죠. 각 주문은 기계 한 대가 처리하기 때문에, 가장 큰 주문을 먼저 일정에 넣으면 작업을 시작하는 데 드는 부담을 작은 주문 쪽으로 넘길 수 있어서 전체 생산 시간이 줄어들어요. 그래서 이런 일정 단축을 돕는 정렬 함수 몇 개를 만들기로 했어요. 그러면 집에 가서 거북이용 스웨터를 뜰 수 있으니까요.

## 1. 수량 정렬!

앞서 말했듯이, 수량 배열은 큰 것부터 작은 것 순으로 정렬해야 해요. 이 배열은 꽤 클 수 있으므로 *제자리에서* 정렬해야 해요. 모든 것을 올바르게 추적하려면 수량에 맞춰 고객 배열도 정렬할 수 있어야 하므로, 수량의 정렬 순열이 필요해요.

`Integer` 수량의 `Vector`를 받는 함수 `sortquantity!(qty)`를 작성해요.
이 함수는 입력 `qty`를 내림차순으로 제자리에서 정렬하고, 이 순서의 정렬 순열을 반환해요.

```julia-repl
julia> qty = [8, 9, 5, 6]
4-element Vector{Int64}:
 8
 9
 5
 6

julia> sortquantity!(qty)
4-element Vector{Int64}:
 2
 1
 4
 3

julia> qty # original vector is sorted in-place
4-element Vector{Int64}:
 9
 8
 6
 5
```

## 2. 고객 정렬

위에서 말했듯이, 고객을 정해진 순서대로 추적해야 해요.

고객 `cust`의 `Vector`와 정렬 순열 `srtperm`의 `Vector`를 받는 함수 `sortcustomer(cust, srtperm)`를 작성해요.
이 함수는 정렬 순열이 정한 순서대로 고객을 담은 새 배열을 반환해요.

```julia-repl
julia> cust = ["a", "b", "c"]
3-element Vector{String}:
 "a"
 "b"
 "c"

julia> sortcustomer(cust, [2, 3, 1])
3-element Vector{String}:
 "b"
 "c"
 "a"

julia> cust # original vector remains unsorted
3-element Vector{String}:
 "a"
 "b"
 "c"
```

## 3. 생산 일정!

이제 이 모든 것을 합쳐서 거북이들을 따뜻하게 지켜줄 수 있어요!
이제 수량과 고객을 제대로 정렬할 수 있지만, 배송을 위해 원래 순서를 되돌릴 수 있어야 해요.
이는 역 정렬 순열로 할 수 있어요.

고객의 `Vector`와 수량의 `Vector`를 받는 함수 `production_schedule!(cust, qty)`를 작성해요.
이 함수는 수량을 내림차순으로 제자리에서 정렬해요.
수량과 같은 순서로 정렬된 고객의 새 `Vector`와, 정렬된 벡터를 원래 순서로 되돌리는 데 쓸 수 있는 *역* 정렬 순열을 반환해요.

```julia-repl
julia> cust, qty = ["a", "b", "c"], [2, 3, 1]
(["a", "b", "c"], [2, 3, 1])

julia> orderedcust, invperm = production_schedule!(cust, qty)
(["b", "a", "c"], [2, 1, 3])

julia> qty # has been sorted in-place
3-element Vector{Int64}:
 3
 2
 1

julia> orderedcust[invperm], qty[invperm] # inverse permutation gives original ordering
(["a", "b", "c"], [2, 3, 1])
```
