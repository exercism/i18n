# 지침 추가

## 나만의 DSL 만들기

이 연습 문제에서는 원하는 대로 그래프 DSL을 마음껏 설계할 수 있어요.

태그와 레코드의 목록을 기반으로 하는 DSL을 만들고 싶을 수도 있어요. 예를 들면 이렇죠:

```roc
my_graph =
    Graph.create([
        Title("My Graph"),
        Node("a", { color: Green }),
        Node("b", { color: Blue }),
        Edge("a", "b", { style: Dotted }),
    ])
```

아니면 함수 호출을 이어 붙인 형태의 DSL이 더 좋을 수도 있어요. 예를 들면 이렇죠:

```roc
my_graph =
    Graph.create()
        .with_title("My Graph")
        .add_node("a", Attr.create().with_color(Green))
        ...
```

어쩌면 아주 다른 계획을 가지고 있을까요? 그렇다면 한번 해봐요! 테스트는 몇 가지 특정한 그래프를 만들기만 요구해요. 어떻게 만들지는 전적으로 자유예요.

그렇긴 해도 DSL은 명확하고 간결하며 너무 놀랍지 않을 때 보통 더 좋아요 (예를 들어 `minus` 함수는 빼기를 위한 것이지, `node("a") - node("b")`처럼 두 노드 사이에 간선을 만드는 용도가 아니에요).

재미를 두 배로 만들고 싶다면, 그래프를 DOT 형식으로 변환하는 `to_dot` 함수를 선택적으로 구현해 볼 수도 있어요!
