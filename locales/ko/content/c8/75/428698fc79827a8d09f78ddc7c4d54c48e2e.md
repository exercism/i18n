# 소개

벡터는 1차원 배열이에요.
서로 다른 타입의 원소를 담을 수도 있어요.

## 벡터 만들기

벡터는 `vector` 함수로 만들거나 `#()` 리더 형식으로도 만들 수 있어요.

```lisp
(vector 1 t "foo" 'b) ; => #(1 t "foo" B)
#(2 nil "bar" a)      ; => #(2 nil "bar" A)
```

## 원소에 접근하기

벡터의 원소에 접근하려면 `aref`를 사용해요. 인덱스는 0부터 시작해요.

```lisp
(aref #(1 2 3) 1) ; => 2
(aref #(a b c) 0) ; => A
```
