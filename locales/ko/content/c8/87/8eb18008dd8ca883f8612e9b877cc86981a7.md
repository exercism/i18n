# 언패킹과 다중 할당

언패킹은 반복을 이용해 `list`, `tuple`, `dict` 같은 컬렉션의 원소를 추출하는 행위를 말해요.
이렇게 언패킹한 값은 같은 문 안에서 변수에 할당할 수 있어요.
이 동작의 아주 흔한 예로는 `for item in list`가 있는데, 여기서 `item`은 반복이 진행되는 동안 `list`의 각 원소 값을 차례대로 가져요.

[다중 할당][multiple assignment]은 하나의 문 안에서 언패킹한 값들에 여러 변수를 할당할 수 있는 기능이에요.
덕분에 코드를 더 간결하고 읽기 쉽게 만들 수 있는데, 할당할 변수들을 쉼표로 구분하면 돼요. 예를 들어 `first, second, third = (1,2,3)` 또는 `for index, item in enumerate(iterable)`처럼요.

특별한 연산자인 `*`와 `**`는 언패킹 상황에서 자주 사용돼요.
`*`는 여러 `list`/`tuple`을 각각 새로운 공통 `list`/`tuple`로 _언패킹_해서 하나의 `list`/`tuple`로 합칠 때 사용할 수 있어요.
`**`는 여러 딕셔너리를 각각 새로운 공통 `dict`로 _언패킹_해서 하나의 딕셔너리로 합칠 때 사용할 수 있어요.

`*` 연산자를 컬렉션 없이 사용하면 여러 값을 하나의 `list`로 _패킹_해요.
이것은 다중 할당에서 개별적으로 할당되지 않은 "나머지" 원소들을 하나의 변수로 묶을 때 자주 사용돼요.

Python에서는 임의의 개수만큼 위치 인자나 키워드 인자를 받는 함수를 사용하거나 정의할 때도 이 언패킹/패킹 동작을 활용하는 경우가 흔해요.
이런 "특별한" 매개변수는 `def some_function(*args, **kwargs)`처럼 정의하고, "특별한" 인자는 `some_function(*some_tuple, **some_dict)`처럼 사용하는 모습을 자주 보게 될 거예요.

~~~~exercism/caution
`*<variable_name>`과 `**<variable_name>`은 `*` 연산자나 `**` 연산자와 혼동하면 안 돼요. 곱셈과 거듭제곱에는 각각 `*` 연산자와 `**` 연산자가 사용되지만, 패킹과 언패킹 연산자로는 `*<variable_name>`과 `**<variable_name>`이 사용돼요.
~~~~
