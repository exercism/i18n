# 개요

F#에서 숫자를 다룰 때 중요한 측면 중 하나는 정수(소수점 뒤에 숫자가 없는 수)와 실수(소수점 뒤에 0개 이상의 숫자가 있는 수)의 구분이에요.

F#에서 가장 흔히 쓰이는 숫자 타입 두 가지는 `int`(32비트 정수)와 `float`(64비트 실수)예요.

```fsharp
let i = 123   // Type is `int`
let d = 54.29 // Type is `float`
```

정수와 실수 모두 `_` 문자를 _자릿수 구분 기호_로 사용할 수 있어요. 큰 숫자를 정의할 때 도움이 돼요:

```fsharp
let largeInt = 1_000_000
// => 1000000

let largeFloat = 9_876_543.21
// => 9876543.21
```

산술 연산은 표준 [산술 연산자][arithmetic-operators](`+`, `-`, `*` 등)를 사용해요. 숫자는 [표준 비교 연산자][comparison-operators](`<`, `>=` 등)와 같음(`=`) 및 다름(`<>`) 연산자를 사용해 비교할 수 있어요.

```fsharp
5 * 6
// => 30

1.2 > 0.8
// => true

2 <> 4
// => true
```

숫자 타입 사이를 변환하려면 내장 [변환 연산자][conversion-operators]를 사용해야 해요. 이 연산자들은 변환하려는 타입의 이름을 따서 지어졌어요.

```fsharp
let floatFromInt = float 2
let intFromFloat = int 3.39
```

타입 사이를 변환할 때는 항상 주의해야 해요. 값이 대상 타입으로 표현될 수 없으면 그 값은 _오버플로_돼요.
