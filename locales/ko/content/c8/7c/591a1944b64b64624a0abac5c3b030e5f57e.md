# 소개

루프에는 기본적으로 두 가지 종류가 있어요:

1. 조건이 만족될 때까지 반복해요.
2. 컬렉션의 원소를 순회해요.

둘 다 Julia에서 가능하지만, 두 번째가 더 흔할 수 있어요.

## `while`문

루프를 몇 번 도는지 미리 알 수 없는 열린 문제에는 Julia의 `while`문을 사용해요.

기본 형태는 아주 간단해요:

```julia
while condition
    do_something()
end
```

이 경우 프로그램은 `condition`이 더 이상 `true`가 아닐 때까지 루프를 계속 돌아요.

루프에서 일찍 빠져나가는 두 가지 방법이 있어요:

- `break`는 루프를 종료하고, 실행은 루프 `end` 다음 줄부터 이어져요.
- `return x`는 현재 함수의 실행을 멈추고, 반환값 `x`를 호출한 곳에 돌려줘요.

이런 방법들을 활용하면 `while true ... end`로 "무한" 루프를 만들어 두고, 루프 본문 안에서 멈춤 조건을 찾아 `break`나 `return`을 실행하는 게 편리할 때가 있어요.

## 컬렉션 순회

가장 간단한 예는 범위를 순회하는 거예요.

10번 무언가를 하고 싶다면:

```julia
for n in 1:10
    do_something(n)
end
```

현재 반복이 어떤 조건을 만족하지 못하면, `continue`로 즉시 다음 반복으로 건너뛸 수 있어요:

```julia
for n in 1:10
    if is_useless(n)
        continue
    end
    
    # we decided this iteration could be useful
    do_something_slow(n)
end
```

더 짧은 형태로는 `if` 블록을 `is_useless(n) && continue`로 대체할 수 있어요.

다른 많은 컬렉션도 순회할 수 있어요: 배열의 원소, 문자열의 문자, 딕셔너리의 키...

지금까지의 예제는 `1:10` 범위를 순회했는데, 여기서는 값이 루프 인덱스이기도 해요.

더 일반적으로는 값뿐 아니라 인덱스가 필요할 수도 있어요.
이럴 때는 `eachindex()` 함수를 사용해요. 예를 들어 `for i in eachindex(my_array) ... end`처럼요.
