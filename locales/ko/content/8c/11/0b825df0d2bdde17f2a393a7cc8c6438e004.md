# 명령과 인자 소개

이 트랙은 bash를 대화형 셸로 사용하는 방법을 다루지 않아요.
bash라는 프로그래밍 언어로 프로그램을 작성하는 법을 배우는 내용이에요.

bash 프로그램, 즉 _스크립트_는 파일에 저장된 일련의 명령이에요.
bash(실행 파일)가 그 파일을 읽고 명령을 순서대로 실행해요.

## 셰뱅

스크립트의 첫 줄은 보통 _인터프리터 지시문_이고, _해시뱅_ 또는 _셰뱅_이라고도 해요:

```bash
#!/usr/bin/env bash
```

운영 체제가 바이너리가 아닌 파일을 실행할 때는 파일의 첫 줄을 읽어요.
그 줄이 `#!`로 시작하면 커널은 그 줄을 보고 어떤 인터프리터가 파일을 실행해야 하는지 결정해요.
`#!`는 파일의 맨 처음에 있어야 하고, 앞에 스페이스나 빈 줄이 있으면 안 돼요.

여기서 `env`는 `PATH`에서 `bash` 실행 파일을 찾아요.
더 간단한 `#!/bin/bash`를 볼 수도 있는데, 이건 인터프리터의 위치를 직접 지정하는 방식이에요. `env` 형태가 이식성이 더 좋아요.

~~~~exercism/note
인터넷에 있는 스크립트나 예시가 인터프리터로 `/bin/sh`를 쓴다고 해서 속지 마세요.
**`sh`는 `bash`가 아니에요!**
Bash는 "sh 호환"이라서 대부분의 `sh` 스크립트를 실행할 수 있지만, 일부 bash 기능은 `sh`에서 깨지거나 예상치 못하게 동작해요.
~~~~

## 주석

`#`로 시작하는 줄은 _주석_이고, bash는 이를 무시해요.
주석은 같은 줄에서 명령 뒤에 올 수도 있어요. `#`부터 그 줄 끝까지는 모두 무시돼요.
주석은 스크립트를 읽는 사람을 위한 것이에요.

## 단어와 인자

Bash는 입력(보통 터미널이나 파일)에서 명령을 읽어요.
읽어 들인 각 줄은 _명령_, 즉 수행해야 할 지시로 취급돼요.
(여러 줄에 걸친 명령처럼 몇 가지 고급 사례가 있는데, 이건 나중에 다뤄요.)

Bash는 각 명령을 공백 문자(스페이스와 탭)로 구분된 **단어**로 나눠요.
첫 번째 단어가 실행할 _명령_의 이름이에요.
나머지 단어는 모두 그 명령의 _인자_(옵션, 파일 이름 등)가 돼요.

명령은 `echo` 같은 bash _빌트인_일 수도 있고, `head`, `awk`, `sed` 같은 _실행 파일_ 프로그램일 수도 있어요.

## `echo` 명령

`echo`는 인자를 스페이스 하나로 구분해서 출력하고, 마지막에 줄바꿈을 붙여요:

```bash
echo flour sugar eggs
```

출력 결과:

```text
flour sugar eggs
```

인자 사이의 공백 양은 중요하지 않아요:

```bash
echo flour       sugar        eggs
```

```text
flour sugar eggs
```

`echo`를 인자 없이 호출하면 빈 줄이 출력돼요.

## 옵션도 그저 인자일 뿐

많은 명령이 동작 방식을 바꾸는 _옵션_을 받아요.
bash 입장에서 옵션은 특별한 게 없어요. 다른 단어와 마찬가지로, 앞뒤 단어와 공백으로 구분되는 단어일 뿐이에요.
인자를 어떻게 해석할지는 명령 자신이 결정해요.
관례상 옵션은 `-`로 시작해요.

`head` 명령은 파일의 처음 몇 줄을 출력해요.
`list.txt`라는 파일이 있다고 해봐요:

```bash
head -n 2 list.txt
```

Bash는 이 줄을 네 개의 단어로 나눠요:

| 단어       | 역할                                         |
| ---------- | -------------------------------------------- |
| `head`     | 실행할 명령                                  |
| `-n`       | `head`에게 _줄_ 단위로 세라고 알려 주는 옵션 |
| `2`        | `-n` 옵션의 값                               |
| `list.txt` | 읽을 파일                                    |

Bash는 마지막 세 단어를 그대로 `head`에 넘겨요.
`-n` 뒤에 숫자가 오고, 남은 단어가 파일이라는 것을 이해하는 건 `head`예요.

단어를 구분하는 것이 공백이기 때문에, 공백을 어디에 두느냐가 중요해요.
`head -n 2`는 `head`에 인자 두 개(`-n`과 `2`)를 주고, `head -n2`는 인자 하나(`-n2`)를 줘요.
많은 명령이 두 형태를 모두 받아들이지만, 그건 명령에 달려 있어요.
Bash는 신경 쓰지 않아요. 그저 줄을 단어로 나눌 뿐이에요.

## 인자에 따옴표 쓰기

[따옴표][Quotes]는 여러 단어를 _하나의 인자_로 묶어요.
따옴표 안의 공백은 그대로 유지되고, 따옴표 문자 자체는 인자의 일부가 아니에요:

```bash
echo "flour       sugar        eggs"
```

```text
flour       sugar        eggs
```

파일 이름처럼 공백이 들어 있는 인자는 따옴표로 묶어요:

```bash
head -n 1 my shopping list.txt     # three files: "my", "shopping", "list.txt"
head -n 1 "my shopping list.txt"   # one file
```

## 스크립트 실행하기

스크립트를 실행하려면 `bash` 명령에 인자로 넘겨요:

```bash
bash myscript
```

이렇게 사용하면 `#!` 줄은 그냥 주석일 뿐이에요.
운영 체제에 그 파일을 어떻게 실행할지 알려 주는 거예요.

또는 스크립트 파일에 실행 권한을 표시하고 다른 프로그램처럼 실행해요:

```bash
chmod +x myscript
./myscript
```

이제 운영 체제가 `#!` 줄을 보고 어떤 인터프리터를 사용할지 결정해요.
