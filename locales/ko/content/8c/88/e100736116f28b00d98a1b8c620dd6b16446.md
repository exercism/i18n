# 지시 사항

Raspberry Pi로 무언가를 만들고 싶다면 아마 _저항_을 사용하게 될 거예요.
이 연습 문제에서는 저항에 대해 두 가지를 알아야 해요:

- 각 저항에는 저항값이 있어요.
- 저항은 작아요. 너무 작아서 실제로 저항값을 저항 위에 인쇄하면 읽기 어려울 정도예요.

이 문제를 해결하기 위해 제조사들은 저항에 색상으로 구분된 띠를 인쇄해서 저항값을 나타내요.
각 띠에는 위치와 숫자 값이 있어요.

저항의 처음 두 띠는 간단한 인코딩 방식을 따라요. 각 색상은 하나의 숫자에 대응해요.

세 번째 띠는 승수예요.

이 연습 문제에서는 띠의 값을 외우지 않아도 되도록 도와주는 프로그램을 만들어 볼 거예요.

저항의 색상 인코딩에 대한 더 많은 정보는 [전자 색 코드 위키백과 문서][e-color-code]에서 찾을 수 있어요.

## 1. 이름을 가진 벡터 정의하기

색상은 다음과 같이 인코딩돼요:

- black: 0
- brown: 1
- red: 2
- orange: 3
- yellow: 4
- green: 5
- blue: 6
- violet: 7
- grey: 8
- white: 9

`resistor_bands`라는 이름을 가진 벡터를 만들어 보세요. 이 벡터는 색상들을 이름으로, 숫자들을 값으로 가져야 해요.

## 2. 띠에 해당하는 값 반환하기

먼저, 어떤 색 띠에 대해서든 단일 값을 찾을 수 있어야 해요.

`band_value(band)`라는 함수를 정의해 보세요. 이 함수는 띠 색상을 나타내는 `string`을 받아요.
함수는 그 색상에 해당하는 값을 반환해요.

```R
band_value("green")
# => [1] 5

band_value("violet")
# => [1] 7
```

## 3. 두 띠에 해당하는 값 반환하기

저항의 처음 두 띠는 합쳐져서 하나의 숫자를 만들어요.
처음 두 띠의 숫자가 각각 `m`과 `n`이면, 이 둘은 합쳐져서 하나의 숫자 `mn`을 만들어요.

`two_band_value(bands)`라는 함수를 정의해 보세요. 이 함수는 두 띠 색상을 나타내는 `string` 여러 개로 이루어진 `vector`를 받아요.
함수는 그 두 색상의 조합에 해당하는 값을 반환해요.

```R
two_band_value(c("yellow", "red"))
# => [1] 42

two_band_value(c("green", "violet"))
# => [1] 57
```

## 4. 세 띠 모두에 해당하는 옴값 반환하기

마지막으로, 처음 두 띠를 세 번째 띠와 함께 사용해서 전체 옴값을 구해야 해요.
그러려면 두 띠 값과 승수를 구해야 해요.
승수는 두 띠 값 뒤에 0이 몇 개 붙는지를 나타낸다고 생각하면 돼요.

`ohms(bands)`라는 함수를 정의해 보세요. 이 함수는 세 띠 색상을 나타내는 `string` 여러 개로 이루어진 `vector`를 받아요.
함수는 세 색상의 조합에 해당하는 옴값을 반환해요.

```R
ohms(c("yellow", "red", "orange"))
# => [1] 42000

ohms(c("green", "violet", "yellow"))
# => [1] 570000
```

[e-color-code]: https://en.wikipedia.org/wiki/Electronic_color_code
