# 배열 메서드

배열은 자주 다루게 되는 자료 구조예요.
그래서 배열을 다루는 데 사용할 수 있는 메서드가 다양하게 있어요.
정렬, 뒤집기, 삽입 등 여러 가지가 포함돼요.

이 메서드 중에는 원본 배열을 수정하는 파괴적인 메서드도 있고, 원본 배열은 그대로 두고 새로운 배열을 반환하는 메서드도 있어요.

다음은 배열을 다룰 때 자주 쓰이는 대표적인 메서드 몇 가지예요.

## insert

배열에 원소를 삽입할 때는 [`insert`][insert] 메서드를 사용할 수 있어요. 이 메서드는 인덱스와 원소를 인자로 받아요.
원소는 지정한 인덱스에 삽입되고, 나머지 원소는 오른쪽으로 밀려요.
인덱스가 범위를 벗어나면 `IndexError`가 발생해요.

```crystal
numbers = [1, 2, 3]
numbers.insert(1, 4)
numbers # => [1, 4, 2, 3]

numbers.insert(5, 5) # => Error: Index out of bounds (IndexError)
```

## delete

배열에서 특정 원소를 삭제하고 싶을 때는 [`delete`][delete] 메서드를 사용할 수 있어요. 이 메서드는 원소를 인자로 받아요.
이 메서드는 삭제한 원소를 반환해요.
배열에 그 원소가 없으면 `nil`을 반환해요.

```crystal
numbers = [1, 2, 3]
numbers.delete(2) # => 2
numbers           # => [1, 3]
```

## first & last

배열의 첫 번째나 마지막 원소를 가져오고 싶을 때는 [`first`][first]와 [`last`][last] 메서드를 사용할 수 있어요.
이 메서드들은 몇 개의 원소를 반환할지 지정하는 선택적 인자를 받아요.
인덱스 `0`이나 `-1`을 사용하거나 범위를 사용하는 것보다 가독성을 높여줄 수 있어요.
배열이 비어 있으면 `Enumerable::EmptyError`가 발생해요.

```crystal
numbers = [1, 2, 3]
numbers.first # => 1
numbers.last  # => 3

numbers.first(2) # => [1, 2]
numbers.last(2)  # => [2, 3]

empty_array = [] of Int32
empty_array.last # => Error: Empty enumerable (Enumerable::EmptyError)
```

## reverse

배열을 뒤집고 싶을 때는 [`reverse`][reverse] 메서드를 사용할 수 있어요. 이 메서드는 원소를 역순으로 담은 새로운 배열을 반환해요.
`reverse`는 새로운 배열을 반환하고 원본 배열은 수정하지 않는다는 점을 기억해 두세요.
원본 배열을 수정하고 싶다면 메서드 이름 끝에 `!`를 붙여요.

```crystal
numbers = [1, 2, 3]
numbers.reverse # => [3, 2, 1]
numbers         # => [1, 2, 3]

numbers.reverse! # => [3, 2, 1]
numbers          # => [3, 2, 1]
```

## Concat(`+`)

append 메서드(`<<`)는 배열에 객체를 추가하고 싶을 때 유용해요.
하지만 두 배열을 합칠 때는 [`+`][concat] 연산자를 사용할 수 있어요. 이 연산자는 두 배열의 원소를 모두 담은 새로운 배열을 반환해요.

```crystal
[1, 2] + [3, 4] # => [1, 2, 3, 4]
```

배열에 다른 배열을 append하면, 그 배열은 하나의 원소로 추가돼요.

```crystal
[1, 2] << [3, 4] # => [1, 2, [3, 4]]
```

## empty?

배열이 비어 있는지 확인하고 싶을 때는 [`empty?`][empty?] 메서드를 사용할 수 있어요. 이 메서드는 배열이 비어 있으면 `true`를, 그렇지 않으면 `false`를 반환해요.
배열의 길이를 `0`과 비교하는 것보다 가독성을 높여줘요.

```crystal
[].empty? # => true
[1, 2, 3].empty? # => false
```

## index

배열에서 원소의 인덱스를 가져오고 싶을 때는 [`index`][index] 메서드를 사용할 수 있어요. 이 메서드는 원소를 인자로 받아요.
배열에 그 원소가 없으면 `nil`을 반환해요.

```crystal
numbers = [1, 2, 3]
numbers.index(2) # => 1
```

## size

배열의 원소 개수를 알고 싶을 때는 [`size`][size] 메서드를 사용할 수 있어요.

```crystal
numbers = [1, 2, 3]
numbers.size # => 3
```

## count

배열에 어떤 원소가 몇 번 나타나는지 세고 싶을 때는 [`count`][count] 메서드를 사용할 수 있어요.

```crystal
fruits = ["apple", "banana", "apple"]
fruits.count("apple")      # => 2
fruits.count("banana")     # => 1
fruits.count("watermelon") # => 0
```

## sort

배열을 정렬하고 싶을 때는 [`sort`][sort] 메서드를 사용할 수 있어요. 이 메서드는 정렬된 원소를 담은 새로운 배열을 반환해요.
`reverse`와 마찬가지로 이 메서드도 새로운 배열을 반환하고 원본 배열은 수정하지 않아요.

```crystal
numbers = [3, 2, 1]
numbers.sort # => [1, 2, 3]
numbers      # => [3, 2, 1]

numbers.sort! # => [1, 2, 3]
numbers       # => [1, 2, 3]
```
