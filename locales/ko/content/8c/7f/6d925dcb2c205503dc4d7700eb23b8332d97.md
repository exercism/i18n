# 소개

[`kernel`][kernel]에 있는 `call`은 quotation을 실행해요. quotation의 스택 효과를 추론할 수 없을 때가 있어요. 보통 quotation이 다른 곳에서 왔기 때문이죠. 그럴 때는 `call`에 스택 효과를 명시적으로 선언해요:

```
call( stack-effect ) ! e.g. call( a b -- c )
```

```factor
3 4 [ + ] call .                 ! => 7
3 4 [ + ] call( a b -- c ) .     ! => 7

: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .         ! => 2
```

quotation은 값이기 때문에 배열은 숫자와 quotation을 섞어 담을 수 있어요. 그래서 "프로그램"도 또 하나의 시퀀스가 돼요:

```factor
{ [ 1 + ] [ 2 * ] } 5 swap [ call( x -- y ) ] each .   ! 5 -> 6 -> 12
```
