# 설치

## R 런타임 설치하기
[CRAN 홈페이지](https://cran.r-project.org/)를 방문해요. 여기에서 Linux, Mac OSX, Windows용 다운로드 링크를 찾을 수 있어요. 사용 중인 운영체제에 맞는 설치 프로그램을 다운로드해서 실행해요.

## RStudio IDE 설치하기 (권장)
RStudio는 R 프로그래밍을 위한 인기 있는 크로스 플랫폼 통합 개발 환경(IDE)이에요. Python, JavaScript, Markdown 같은 다른 언어도 지원해요. RStudio를 사용하면 코드를 작성하고 테스트를 실행하는 일이 훨씬 쉬워져요.

[현재 안정 버전의 RStudio](https://www.rstudio.com/products/rstudio/download/)를 다운로드해서 설치해요. 또는 다음 릴리스의 [미리 보기 버전](https://www.rstudio.com/products/rstudio/download/preview/)을 받을 수도 있어요.

## Visual Studio Code용 R 확장 설치하기 (대안)
Visual Studio Code용 R 확장은 확장된 구문 강조, 코드 완성, 린팅, 서식 지정, R 터미널과의 상호 작용, 데이터와 플롯, 작업 공간 변수, 도움말 페이지 보기, 패키지 관리, R Markdown 문서 작업을 지원해요.

[현재 버전의 R 확장](https://code.visualstudio.com/docs/languages/r)을 다운로드해서 설치해요.

## 테스트를 실행하기 위한 R 패키지 설치
테스트 명세를 실행하는 테스트 러너는 Hadley Wickham의 [`testthat`](https://github.com/hadley/testthat) 라이브러리예요. R 패키지 작성자들이 즐겨 선택하는 라이브러리죠.

이 라이브러리를 설치하려면 RStudio 콘솔(R을 사용하는 곳이라면 어디든)에 다음을 입력해요.

```{R}
install.packages("testthat")
```

Exercism 문제를 풀기 위해 패키지를 _꼭_ 설치해야 하는 경우는 드물지만, 자신의 프로그래밍 스타일에 맞는 [`tidyverse`](https://github.com/tidyverse/tidyverse) 같은 범용 유틸리티 패키지를 가져오고 싶을 수도 있어요. `tidyverse` 같은 패키지를 설치하고 불러오려면:

```{R}
install.packages("tidyverse")
library(tidyverse)
```
