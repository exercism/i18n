# 소개

1000까지의 음이 아닌 정수를 모두 다루고 싶다고 해봐요.
이것들을 배열에 하나하나 직접 입력해야 한다면 말도 안 되겠죠.

이럴 때 쓰는 게 바로 `range` 타입이에요.

```julia-repl
julia> 0:1000
0:1000

julia> typeof(0:1000)
UnitRange{Int64}
```

범위는 아주 흔해요. 입력을 줄여 줄 뿐만 아니라 함수의 반환 타입으로도 쓰여요.

범위는 벡터가 _아니에요_.
범위는 시퀀스를 생성하기 위한 명령의 집합일 뿐이에요 ("지연" 평가, 또는 "이터레이터").

범위를 벡터로 사용해야 한다면 `collect()` 함수로 변환해요.

```julia-repl
julia> collect(0:5)
6-element Vector{Int64}:
 0
 1
 2
 3
 4
 5
```

단계 크기를 지정할 수도 있어요. 이 경우에는 0.3이에요.

```julia-repl
julia>  collect(1.0:0.3:2.0)
4-element Vector{Float64}:
 1.0
 1.3
 1.6
 1.9
```

즉, 문법은 `start:stepsize:stop`이에요.
정수 예시에서 봤듯이, 양 끝 값은 모두 _포함_돼요.
단계 크기가 `stop - start`를 정확히 나누지 못하면, 마지막 원소는 `stop`을 넘지 않도록 해요.

## 문자 범위

숫자가 아닌 시퀀스도 범위에 사용할 수 있어요.
가장 간단한 예는 ASCII 문자예요.

```julia-repl
julia> 'a':'d'
'a':1:'d'

julia> typeof('a':'d')
StepRange{Char, Int64}

julia> collect('a':'d')
4-element Vector{Char}:
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)
 'd': ASCII/Unicode U+0064 (category Ll: Letter, lowercase)
```

`Char` 타입은 다른 개념에서 더 자세히 다뤄요.
지금은 작은따옴표 안의 단일 문자로만 생각해요.

## 범위를 위한 함수와 연산자

범위의 양 끝 값은 `first()`와 `last()`로 확인해요.

```julia
 r = 1:10  # => 1:10
 first(r)  # => 1
 last(r)   # => 10
```

## 벡터 인덱싱 더 알아보기

정수 범위와 벡터는 벡터 인덱싱에 사용할 수 있어요.

```julia
nums = collect(10.0:50.0)
nums[3:2:7]  # gives [12.0, 14.0, 16.0]
nums[ [3, 5, 7] ] # also gives [12.0, 14.0, 16.0]
```
