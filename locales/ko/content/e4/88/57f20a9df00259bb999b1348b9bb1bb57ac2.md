# 소개

Python에서 [튜플][tuple]은 항목을 _순서대로_ 담는 _불변_ 컬렉션이에요.
대부분의 컬렉션처럼 `tuples`는 모든 (또는 여러) 데이터 타입을 담을 수 있어요. 다른 `tuples`도 포함해서요.
튜플은 모든 [일반 시퀀스 연산][common sequence operations]을 지원하지만, [가변 시퀀스 연산][mutable sequence operations]은 **지원하지 않아요**.

튜플의 원소는 `for item in <tuple>` 구문으로 반복할 수 있어요.
원소의 인덱스와 값이 둘 다 필요하면 `for index, item in enumerate(<tuple>)`를 사용할 수 있어요.
다른 시퀀스처럼, `tuples` 안의 원소는 왼쪽에서부터 `0-based index` 숫자를, 또는 오른쪽에서부터 `-1-based index` 숫자를 사용하는 _대괄호 표기법_ 으로 접근할 수 있어요.
튜플은 슬라이스 표기법(_`<tuple>[<start>:<stop>:<step>]`_)을 사용해 전체 또는 일부를 복사할 수도 있어요.


## 튜플 생성

튜플은 `tuple(<iterable>)` 클래스 생성자를 사용하거나 `tuple` 리터럴 선언을 사용하는 등 여러 방법으로 만들 수 있어요.

### `tuple()` 생성자를 비워 두거나 _이터러블_ 과 함께 사용하기:

```python
>>> no_elements = tuple()
()

# The constructor *requires* an iterable, so single elements must be passed in a list or another tuple.
>>> one_element = tuple([16])
(16,)
```

문자열은 이터러블이라서, `tuple()` 생성자의 인자로 `str` 하나를 넘기면 놀라운 결과가 나올 수 있어요:

```python
# String elements (characters) are iterated through and added to the tuple
>>> multiple_elements_string = tuple("Timbuktu")
('T', 'i', 'm', 'b', 'u', 'k', 't', 'u')
```

하나의 이터러블은 원소가 하나씩 추가돼요:

```python
>>> multiple_elements_list = tuple(["Parrot", "Bird", 334782])
("Parrot", "Bird", 334782)

>>> multiple_elements_set = tuple({2, 3, 5, 7, 11})
(2,3,5,7,11)
```

#### 튜플을 _리터럴_ 로 선언하기:

`tuple(<iterable>)` 생성자는 _이터러블_(또는 아무것도)만 인자로 받기 때문에, 리터럴 방식으로 하나짜리 튜플을 만드는 게 훨씬 쉬워요.

```python
>>> no_elements = ()
()

>>> one_element = ("Guava",)
("Guava",)
```

중첩된 자료 구조도 다른 `tuples`를 포함해 `tuple`의 원소로 넣을 수 있어요:

```python
>>> nested_data_structures = ({"fish": "gold", "monkey": "brown", "parrot" : "grey"}, ("fish", "mammal", "bird"))
({"fish": "gold", "monkey": "brown", "parrot" : "grey"}, ("fish", "mammal", "bird"))

>>> nested_data_structures_1 = (["fish", "gold", "monkey", "brown", "parrot", "grey"], ("fish", "mammal", "bird"))
(["fish", "gold", "monkey", "brown", "parrot", "grey"], ("fish", "mammal", "bird"))
```

## 튜플 연결

튜플은 더하기 `+` 연산자로 연결할 수 있는데, 이 연산자는 각 `tuple`을 풀어서 새로운 하나의 `tuple`을 만들어요.

```python
>>> new_via_concatenate = ("George", 5) + ("cat", "Tabby")
("George", 5, "cat", "Tabby")

#likewise, using the multiplication operator * is the equivalent of using + n times
>>> first_group = ("cat", "dog", "elephant")

>>> multiplied_group = first_group * 3
('cat', 'dog', 'elephant', 'cat', 'dog', 'elephant', 'cat', 'dog', 'elephant')
```

## 튜플 안의 원소에 접근하기

`tuple` 안의 원소는 왼쪽에서부터 `0-based index` 숫자를, 또는 오른쪽에서부터 `-1-based index` 숫자를 사용하는 _대괄호 표기법_ 으로 접근할 수 있어요.

```python
student_info = ("Alyssa", "grade 3", "female", 8 )

#gender is at index 2 or index -2
>>> student_gender = student_info[2]
'female'

>>> student_gender = student_info[-2]
'female'

#name is at index 0 or index -4
>>> student_name = student_info[0]
Alyssa

>>> student_name = student_info[-4]
Alyssa
```

## 튜플의 원소 반복하기

`tuple` 안의 원소는 `for item in <tuple>` 구문을 사용해 루프에서 _반복_ 할 수 있어요.
인덱스와 값이 둘 다 필요하면 `for index, item in enumerate(<tuple>)`를 사용할 수 있어요.

```python
>>> student_info = ("Alyssa", "grade 3", "female", 8 )
>>> for item in student_info:
...   print(item)

...
Alyssa
grade 3
female
8

>>> for index, item in enumerate(student_info):
...  print("Index is: " + str(index) + ", value is: " + str(item) +".")

...
Index is: 0, value is: Alyssa.
Index is: 1, value is: grade 3.
Index is: 2, value is: female.
Index is: 3, value is: 8.
```

## 튜플에 값이 들어 있는지 확인하기

`in` 연산자를 사용해 `tuple`에 값이 들어 있는지 확인할 수 있어요.

```python
>>> multiple_elements_list = tuple(["Parrot", "Bird", 334782])
("Parrot", "Bird", 334782)

>>> "Parrot" in multiple_elements_list
True
```
