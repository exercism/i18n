# 소개

## 비교

JavaScript에서는 숫자를 다음과 같은 관계 연산자와 동등 연산자로 비교할 수 있어요.

| 비교             | 연산자  |
| ---------------------- | --------- |
| 보다 큼           | `a > b`   |
| 크거나 같음 | `a >= b`  |
| 보다 작음              | `a < b`   |
| 작거나 같음    | `a <= b`  |
| (엄격) 같음        | `a === b` |
| (엄격) 같지 않음    | `a !== b` |

비교 결과는 항상 `true` 또는 `false`라는 불리언 값이에요.

```javascript
1 < 3;
// => true

2 !== 2;
// => false

1 === 1.0;
// => true
// All numbers are floating-points, so this is different syntax for
// the exact same value.
```

JavaScript에서는 위의 비교 연산자로 문자열을 비교할 수도 있어요.
이 경우에는 사전식 순서가 적용돼요.
모든 문자의 정확한 순서 목록은 [여기][utf-16-list]에서 볼 수 있어요.

```javascript
'Apple' > 'Pear';
// => false

'a' < 'above';
// => true

'a' === 'A';
// => false
```

## 조건문

JavaScript에서 조건에 따라 로직을 실행하는 일반적인 방법은 `if`문이에요.
`if` 키워드, 소괄호로 감싼 조건, 중괄호로 감싼 코드 블록으로 이루어져요.
코드 블록은 조건이 `true`로 평가될 때만 실행돼요.

```javascript
if (condition) {
  // code that is executed if "condition" is true
}
```

단독으로 사용하거나 `else` 키워드와 함께 사용할 수 있어요.

```javascript
if (condition) {
  // code that is executed if "condition" is true
} else {
  // code that is executed otherwise
}
```

`else`문 안에 또 다른 조건을 중첩하려면 `else if`를 사용할 수 있어요.

```javascript
if (condition1) {
  // code that is executed if "condition1" is true
} else if (condition2) {
  // code that is executed if "condition2" is true
  // but "condition1" was false
} else {
  // code that is executed otherwise
}
```
