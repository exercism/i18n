# `for`문

루프는 코드 블록을 여러 번 실행할 수 있게 해 주는 프로그래밍의 기본 개념이에요.
Swift에는 `for-in`문과 `while`문, 두 가지 종류의 루프가 있어요.
이번 장에서는 `for-in`문에 대해 알아봐요.

`for`문을 사용하면 값의 시퀀스를 순회하면서 각 원소를 차례대로 원하는 변수에 담을 수 있어요.
Swift에서는 범위, 배열, 문자열 등 다양한 시퀀스를 순회할 수 있어요(나중에 다룰 더 많은 타입도 마찬가지예요).
시퀀스의 모든 원소를 순회하고 나면 루프가 끝나요.

`for`문은 `for` 키워드와 변수 이름, `in` 키워드, 그리고 순회할 값의 시퀀스를 차례로 써서 선언해요.
`for-in`문에 지정한 변수는 불변이어서, 루프 안에서 값을 바꿀 수 없어요.
다음은 숫자 배열을 순회하는 `for-in`문의 예시예요:

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
  print(number)
}
print("Done with numbers")

// prints:
// 3
// 10
// 7
// 11
// Done with numbers
```

~~~~exercism/note
`number` 변수는 `for-in`문 안에서 선언되고, 루프의 스코프 안에서만 사용할 수 있어요.

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
    number + 1
}
number + 1
// Error: Use of unresolved identifier 'number'
```
~~~~

## 범위 순회하기

`for-in`문으로 숫자 범위를 순회할 수도 있어요.
이렇게 하면 코드 블록을 원하는 횟수만큼 실행할 수 있어요. 예를 들어 범위 `1...5`는 숫자 1, 2, 3, 4, 5를 순회하므로 루프가 5번 실행돼요.
배열 같은 자료 구조의 인덱스를 순회하고 싶을 때는 `0..<array.count` 범위를 사용할 수 있어요.

```swift
let numbers = [3, 10, 7, 11]

for i in 0..<numbers.count {
  print(numbers[i])
}

// prints:
// 3
// 10
// 7
// 11
```

## 문자열 순회하기

`for-in`문으로 문자열을 순회할 수도 있어요.
이렇게 하면 문자열의 각 문자를 하나씩 순회할 수 있는데, 이때 루프에 주어지는 타입이 `Character`라는 점에 주목해요.

```swift
let message = "Hello!"

for character in message {
  print(character)
}

// prints:
// H
// e
// l
// l
// o
// !
```

## stride

Swift는 일정한 간격을 두고 범위를 순회하는 시퀀스를 만들 수 있는 `stride` 함수도 제공해요.
이 시퀀스는 `for-in`문으로 순회할 수 있어요.
`stride`는 [`stride(from:to:by:)`][stride-to] 또는 [`stride(from:through:by:)`][stride-through]로 정의되는데, 앞의 것은 상한을 포함하지 않고 뒤의 것은 상한을 포함해요.

```swift
for i in stride(from: 0, to: 10, by: 2) {
  print(i)
}

// prints:
// 0
// 2
// 4
// 6
// 8
```

`to` 매개변수는 상한을 포함하지 않으므로 `to` 값 바로 앞 숫자까지만 순회하고, `through` 매개변수는 상한을 포함하므로 이 경우에는 `10`까지 포함해요.

[stride-to]: https://developer.apple.com/documentation/swift/stride(from:to:by:)
[stride-through]: https://developer.apple.com/documentation/swift/stride(from:through:by:)
[for-loops]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
