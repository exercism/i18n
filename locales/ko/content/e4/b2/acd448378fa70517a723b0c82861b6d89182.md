# 소개

Kotlin은 JetBrains가 개발한 **정적 타입** 프로그래밍 언어예요. 즉, 변수의 타입이 컴파일 시점에 정해져요.

## 변수

다른 정적 타입 프로그래밍 언어들과 마찬가지로, 각 변수의 타입은 컴파일 시점에 정의되어야 해요. 컴파일러가 문맥에서 타입을 추론할 수 있는 곳에서는 명시적인 타입 선언을 생략할 수 있어요.

Kotlin에는 불변(`val`) 변수와 가변(`var`) 변수가 있어요. 불변 변수의 값은 초깃값이 할당된 뒤에는 바꿀 수 없어요. 대부분의 경우 이 타입의 변수를 사용하게 돼요.

```kotlin
val robotName = "HAL-9000"
userId = "T-1000"  // This will not compile
```

가변 변수의 값은 한 번 이상 바꿀 수 있어요.

```kotlin
var index = 12
print(index)  // 12

index = 100
print(index)  // 100
```

Kotlin에서 세미콜론은 선택 사항이에요. 나중에 다룰 몇 가지 특별한 경우는 예외예요.

## 함수

Kotlin에서 함수는 `fun` 키워드로 정의하며, _일급 시민_이에요 (객체 지향 프로그래밍과는 관련이 없어요). 즉, 함수를 파일에 바로 선언할 수 있어요 (이른바 `top-level functions`). 예를 들어 Java에서는 메서드를 클래스 안에서만 정의할 수 있고 파일에는 정의할 수 없어요.

```kotlin
// This is content of the Hello.kt file

fun hello() {}
```

함수는 인자를 받을 수 있어요. 각 인자에는 이름과 타입이 있어요. 변수와 달리 인자의 타입은 추론할 수 없어요. 함수는 인자를 0개 이상 가질 수 있어요.

```kotlin
fun hello() {}

fun hello(name: String) {}

fun hello(name: String, age: Int) {}
```

Kotlin 함수는 값을 반환할 수도 있고 반환하지 않을 수도 있어요.

```kotlin
fun min(a: Int, b: Int): Int

fun countBonuses(user: User): Bonuses

fun run() {}
```

함수에서 값을 반환하려면 `return` 키워드를 사용해요.

```kotlin
fun getName(): String {
    return "Alice"
}
```

함수는 기본값을 가진 매개변수를 가질 수 있어요. 이 값들은 함수를 호출할 때 생략되면 사용돼요.

```kotlin
fun ping(host: String = "localhost") {
    println("PING --> $host")
}

ping("exercism.io")  // PING --> exercism.io
ping()               // PING --> localhost
```

## 주석

한 줄 주석은 `//`로 정의해요.

```kotlin
foo() // Everything after `//` will be ignored by compiler

// I will be ignored too
```

여러 줄 주석은 `/*`와 `*/`로 정의해요.

```kotlin
/*
   This this an example
   for a multiline comment
*/
```
