# 소개

배열은 Factor의 고정 길이 시퀀스예요. 원소는 바꿀 수 있지만 길이는 바꿀 수 없어요. 리터럴 배열, 즉 `{ … }`를 작성하는 방법과 배열을 슬라이스하고 집계하는 방법은 이미 알고 있어요. 이 연습 문제에서는 스택에 있는 값으로 배열을 만들고 나서 그 내용을 조회하거나 재배치할 때 등장하는 작은 도구 모음을 다뤄요.

## 스택에서 배열 만들기

`1array`, `2array`, `3array`, `4array`([`arrays`][arrays]에 있어요)는 스택 맨 위에서 1개, 2개, 3개, 4개의 값을 꺼내 하나로 묶어요.

```
1array ( a       -- { a }       )
2array ( a b     -- { a b }     )
3array ( a b c   -- { a b c }   )
4array ( a b c d -- { a b c d } )
```

```factor
42 1array .                ! => { 42 }
3 4 2array .               ! => { 3 4 }
"x" "y" "z" 3array .       ! => { "x" "y" "z" }
1 2 3 4 4array .           ! => { 1 2 3 4 }
```

## 이어 붙이기

`concat`([`sequences`][sequences]에 있어요)은 원소 자체가 시퀀스인 시퀀스를 받아서 한 단계 평평하게 펼쳐요. `join`은 각 쌍 사이에 구분자를 넣는다는 점만 다르고 같은 일을 해요.

```
concat ( seqs     -- seq )
join   ( seqs sep -- seq )
```

```factor
{ { 1 2 } { 3 4 } { 5 } } concat .
! => { 1 2 3 4 5 }

{ "alpha" "beta" "gamma" } ", " join .
! => "alpha, beta, gamma"
```

## 뒤집기

`reverse`는 원소를 반대 순서로 배치한 새 시퀀스를 반환해요.

```
reverse ( seq -- newseq )
```

```factor
{ 1 2 3 4 } reverse .   ! => { 4 3 2 1 }
```

## 배열인가요?

`array?`([`arrays`][arrays]에 있어요)는 타입을 판별하는 단어예요. `<array>`, `1array`/`2array`/..., 또는 배열 리터럴 `{ … }`로 만든 모든 값에 대해서는 참이고, 그 밖의 모든 것(벡터, 문자열, 다른 시퀀스 포함)에 대해서는 거짓이에요.

```
array? ( obj -- ? )
```

```factor
{ 1 2 3 } array? .         ! => t
"hello" array? .           ! => f
V{ 1 2 3 } array? .        ! => f
```

## 찾아보기

`index`는 입력 값과 같은 첫 번째 원소의 위치를 반환하고, 없으면 `f`를 반환해요. `member?`는 불리언만 반환해요. 둘 다 **원소를 먼저**, **시퀀스를 나중에** 받아요. `members`([`sets`][sets]에 있어요)는 시퀀스의 *고유한* 원소, 즉 중복을 제거한 결과를 반환하고, `all-unique?`(역시 `sets`에 있어요)는 시퀀스에 이미 중복이 없는지 검사해요.

```
index       ( elt seq -- i/f )
member?     ( elt seq -- ? )
members     ( seq     -- uniques )
all-unique? ( seq     -- ? )
```

```factor
"b" { "a" "b" "c" } index .       ! => 1
"z" { "a" "b" "c" } index .       ! => f
"b" { "a" "b" "c" } member? .     ! => t
"z" { "a" "b" "c" } member? .     ! => f
{ 1 2 3 2 1 } members .           ! => { 1 2 3 }
{ 1 2 3 } all-unique? .           ! => t
{ 1 2 1 } all-unique? .           ! => f
```
