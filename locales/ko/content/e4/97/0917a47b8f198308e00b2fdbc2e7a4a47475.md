# 개요

Haxe에는 정수와 실수, 두 가지 숫자 타입이 있어요.

- `Int`: 정수를 나타내요.
- `Float`: 64비트 배정밀도 부동소수점 수를 나타내요.

```haxe
var integer:Int = 10;
var floating:Float = 5.4;
```

모든 `Int`는 `Float`가 필요한 자리에 쓸 수 있어요. 즉 `Int`는 `Float`에 **할당 가능**하거나 `Float`와 **통합돼요**. 하지만 그 반대는 성립하지 않아요. `Float`를 `Int`에 할당하면 정밀도가 손실될 수 있기 때문에 암시적으로는 허용되지 않아요.

## 비교

숫자는 값이 같으면 같아요.

```haxe
1 == 1; // true

1.2 == 1.2; // true

1 == 1.0; // true

0.2 + 0.1 == 0.3 // false
```
