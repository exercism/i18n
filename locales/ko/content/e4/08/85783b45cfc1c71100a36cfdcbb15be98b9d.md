# 자세히 알아보기

Custom Types는 Gleam에서 새로운 데이터 타입을 정의하는 방법이에요. 여러 개의 _variant_를 가질 수 있으며, 각 variant는 고유한 이름을 가져요.

```gleam
pub type Season {
  Spring
  Summer
  Autumn
  Winter
}
```

Custom type의 각 variant는 데이터를 함께 담을 수도 있고, 그 데이터의 타입은 variant마다 달라요. variant가 데이터를 가지고 있으면 _record_라고 불러요.

```gleam
pub type Number {
  SomeInt(Int)
  SomeFloat(Float)
  Invalid
}
```

특정 variant의 값은 추가 데이터가 없으면 그 이름을 그대로 써서 만들고(`Spring`), 추가 데이터가 있으면 함수처럼 호출해서 만들어요(`SomeInt(2)`).

```gleam
let spring = Spring
let integer_two = SomeInt(2)
```

Custom Types는 Gleam의 모든 값과 마찬가지로 _구조적 동등성_을 가져요. 즉, 같은 variant에 데이터도 같은 두 값은 서로 동등해요.

```gleam
Spring == Spring // -> True
Spring == Autumn // -> False
SomeInt(2) == SomeInt(2) // -> True
SomeInt(2) == SomeFloat(2.0) // -> False
```

Custom type의 variant는 case 표현식으로 패턴 매칭할 수 있어요.

```gleam
import gleam/int
import gleam/float

pub fn describe(flexible_number: Number) -> String {
  case flexible_number {
    SomeFloat(f) -> "Float: " <> float.to_string(f)
    SomeInt(i) -> "Int: " <> int.to_string(i)
    Invalid -> "Neither a float nor an int"
  }
}
```
