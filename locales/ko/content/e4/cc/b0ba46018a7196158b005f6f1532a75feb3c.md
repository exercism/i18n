# 지침

이 연습 문제에서는 표지판 회사가 표지판에 넣을 맞춤 메시지를 만들 수 있도록 코드를 작성해요.

## 1. 기념일 표지판 만들기

`buildSign(occasion, name)` 함수를 구현해요. 이 함수는 `occasion` 매개변수로 문자열을 받고, `name` 매개변수로 누군가의 이름이 담긴 문자열을 받아요.
두 매개변수는 템플릿 문자열에 삽입되어 표지판에 표시할 메시지를 만들어요.

```javascript
buildSign('Birthday', 'Rob');
// => "Happy Birthday Rob!"
```

## 2. 생일 표지판 만들기

`buildBirthdaySign(age)` 함수를 구현해요. 이 함수는 나이를 받아서 나이에 따라 표지판에 표시할 메시지의 일부를 결정해요.
나이가 50 이상이면 표지판에서는 사용자를 _mature_라고 부르고, 그렇지 않으면 _young_이라고 불러요.
정확히 기대되는 출력은 아래와 같아요:

```javascript
buildBirthdaySign(50);
// => "Happy Birthday! What a mature fellow you are."

buildBirthdaySign(45);
// => "Happy Birthday! What a young fellow you are."
```

## 3. 졸업 표지판 만들기

`graduationFor(name, year)` 함수를 구현해요. 이 함수는 이름을 문자열 매개변수로, 연도를 숫자 매개변수로 받고, 문자열 보간을 사용해 표지판에 넣을 문구를 만들어요. 이때 메시지의 두 줄을 줄바꿈으로 구분해요.

```javascript
graduationFor('Hannah', 2022);
/* => "Congratulations Hannah!
       Class of 2022"
*/
```

## 4. 표지판 비용 계산하기

`costOf(sign, currency)` 함수를 구현해요. 이 함수는 표지판에 들어갈 내용이 담긴 문자열과 통화를 나타내는 문자열을 받아요.
표지판의 기본 가격은 주어진 통화로 20이에요. 그리고 글자마다 2씩 추가돼요. (공백도 계산에 포함돼요.)
반환되는 문구에는 표지판을 만드는 비용이 포함되는데, 소수점 이하 두 자리로 표시하고 그 뒤에 통화 문자열을 붙여요.

```javascript
costOf('Happy Birthday Rob!', 'dollars');
// => "Your sign costs 58.00 dollars."
```
