# 개요

`case`는 값이 같은지를 기준으로 여러 갈래로 나뉘는, Factor의 분기 구문이에요. 선택이 *하나의* 값이 여러 후보 중 하나와 같은지에 달려 있을 때 알맞은 도구예요. 갈래마다 서로 다른 검사를 해야 할 때는 어울리지 않아요. 그럴 때는 `cond`를 써요.

```factor
USING: combinators ;

SYMBOLS: yes no maybe ;

: invert ( ?/maybe -- ?'/maybe )
    {
        { yes [ no ] }
        { no  [ yes ] }
        [ ]            ! default: leave value alone
    } case ;
```

몇 가지 짚어 둘 점이 있어요:

- 동등 비교는 `=`로 해요. `=`가 성립하는 값이라면 무엇이든 키가 될 수 있어요. 숫자, 문자열, 문자, 심볼, 심지어 튜플까지요.
- *일치한* 갈래는 입력 값이 *없는* 스택을 봐요. *기본* 갈래는 입력 값이 여전히 맨 위에 있는 스택을 봐요.
- 기본 갈래가 없는데 일치하는 절도 없으면, `case`는 오류를 던져요.

`case`는 가능하면 점프 테이블로 컴파일돼요. 그래서 그저 `if` 연쇄를 위한 편의 문법이 아니라, 속도도 빨라요.
