# 도움말

## 도움이 더 필요하신가요?

- [Exercism 커뮤니티 포럼](https://forum.exercism.org)에 가서 도움을 받고 질문해요 (또는 그냥 수다를 떨어도 좋아요!)
  - 웹 에디터에서 작업하거나, 연습 문제를 로컬로 내려받거나 제출하는 데 문제가 있으면 [Exercism Support](https://forum.exercism.org/c/support/8) 카테고리를 이용해요.
  - jq 관련 주제는 [Programming:jq](https://forum.exercism.org/c/programming/jq/133) 카테고리를 이용해요.
- [Exercism의 Discord 서버](https://exercism.org/r/discord)에서 커뮤니티에 참여해요.
- [StackOverflow](https://stackoverflow.com/questions/tagged/jq)에서 문제를 검색하고 이미 답변이 있는지 확인할 수 있어요.
  질문하고 답변할 수도 있어요.
- [Github 이슈 트래커](https://github.com/exercism/jq/issues)는 Exercism에서 `jq` 연습 문제를 개발하고 유지 관리하는 곳이에요.
  위의 링크 중 어느 것도 도움이 되지 않는다면, 여기에 이슈를 자유롭게 올려도 괜찮아요.
