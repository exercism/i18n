# Instructions

친구 Linus는 도시 사이를 오가며 화물 열차를 운전하는 기관사예요.
열차를 다루는 솜씨는 대단하지만, 물류나 컴퓨터를 다루는 솜씨는 그렇지 않아요.
그래서 열차 정보를 정리하고 경로 데이터의 실수를 바로잡는 일을 여러분의 프로그래밍 실력으로 도와주려고 해요.

~~~~exercism/note
이 연습 문제는 슬라이싱, 인덱싱, 그리고 다양한 `Dict` 메서드를 사용하면 쉽게 풀 수 있어요.
하지만 아래 각 과제를 풀 때는 packing(즉, slurping), unpacking(즉, splatting), 그리고 다중 할당을 연습해 보길 바라요.
~~~~

## 1. 모든 화차를 담은 벡터 만들기

친구는 각 화차 식별자(ID)를 계속 기록해 왔지만, 시스템이 어느 시점에 처리해야 할 화차가 몇 개인지 전혀 알 수 없어요. 이 데이터를 하나의 `Vector`로 묶어 두면 나머지 물류 프로그램이 훨씬 수월해져요.

임의의 개수만큼 화차 ID를 받는 `get_vector_of_wagons(args...)` 함수를 구현해요.
각 ID는 양의 정수예요.
그러면 함수는 주어진 ID들을 하나의 `Vector`로 `return`해야 해요.

```julia-repl
julia> get_vector_of_wagons(1, 7, 12, 3, 14, 8, 5)
7-element Vector{Int64}:
  1
  7
 12
  3
 14
  8
  5
```

## 2. 화차 벡터 고치기

이쯤 되면 데이터와 그것이 물류 프로그램에서 어떻게 쓰이는지 감이 잡히기 시작할 거예요.
ID 시스템은 항상 기관차에 **1**이라는 ID를 부여하고, 열차에 있는 나머지 화차에는 **1**보다 큰 임의의 ID를 부여해요.

친구가 열차에 새 화차 두 개를 연결하고는 시스템을 업데이트하는 걸 잊었어요!
이제 열차 `Vector`의 앞 두 화차를 끝으로 옮겨야 하고, 그렇지 않으면 모든 게 순서가 엉망이 돼요.

설상가상으로, 친구가 방금 누락된 화차 ID가 담긴 것 같은 두 번째 `Vector`를 발견했어요.
기억하는 건 새 화차를 옮기고 나면, 이 두 번째 `Vector`의 ID들을 지정된 기관차 바로 뒤에 놓아야 한다는 것뿐이에요.

Linus는 실수를 고치고 데이터를 하나로 합쳐 주면 정말 고마워할 거예요.

화차 ID를 담은 두 `Vector`를 받는 `fix_vector_of_wagons(each_wagons_id, missing_wagons)` 함수를 구현해요.
이 함수는 첫 번째 `Vector`의 앞 두 항목을 끝으로 옮기고, 두 번째 `Vector`의 값들을 기관차 ID(**1**) 뒤(_오른쪽_)에 삽입해야 해요.
그러면 함수는 수정된 `Vector`를 `return`해야 해요.

```julia-repl
julia> fix_vector_of_wagons([2, 5, 1, 7, 4, 12, 6, 3, 13], [3, 17, 6, 15])
13-element Vector{Int64}:
  1
  3
 17
  6
 15
  7
  4
 12
  6
  3
 13
  2
  5
```

## 3. 누락된 정차역 추가하기

이제 모든 화차 데이터가 정확해졌으니, Linus는 시스템의 경로 정보를 업데이트해 주길 바라요.
한 운송 경로에서 열차는 화물을 싣거나 내리기 위해 여러 다른 역에 정차할 수 있어요.
여정마다 이런 중간 배송 지점의 수는 다를 수 있어요.
친구는 누락되거나 추가된 배송 정보로 시스템의 경로 `Dict`를 업데이트해 주길 바라요.

경로 `Dict`와 그 뒤에 가변 개수의 `stop_number => city` Pair를 받는 `add_missing_stops(route, stops...)` 함수를 구현해요.
그러면 함수는 추가된 모든 정차역을 순서대로 담은 `Vectors`를 `key`로 추가한 경로 `Dict`를 반환해야 해요.

```julia-repl
julia> add_missing_stops(Dict("from" => "New York", "to" => "Miami"), :stop_1 => "Washington, DC", :stop_2 => "Charlotte", :stop_3 => "Atlanta", :stop_4 => "Jacksonville")
Dict{String, Any} with 3 entries:
  "stops" => ["Washington, DC", "Charlotte", "Atlanta", "Jacksonville"]
  "to"    => "Miami"
  "from"  => "New York"
```

## 4. 경로 정보 확장하기

Linus는 경로 프로그램을 작업하다가 특정 경로에 몇 가지 중요한 세부 정보가 빠져 있다는 걸 발견했어요.
초기 경로 정보는 `Dict`로 구성되어 있고, 친구는 빠진 게 있으면 그 `Dict`를 업데이트해 주길 바라요.
시스템의 모든 경로는 조금씩 다른 세부 정보를 필요로 하기 때문에, Linus는 범용적인 해법을 정말 선호해요.

`extend_route_information(route; more_route_information...)`라는 함수를 구현해요.
이 함수는 열차 경로가 잇는 출발지와 도착지 도시를 담은 `Dict`와, 열차 속도, 길이, 온도 같은 경로 세부 정보를 담은 가변 개수의 키워드 인자를 받아요.
함수는 모든 경로 정보를 하나로 합친 `Dict`를 반환해야 해요.

```julia-repl
julia> extend_route_information(Dict("from" => "Berlin", "to" => "Hamburg"); length = "100", speed = "50")
Dict{Any, String} with 4 entries:
  :speed  => "50"
  "to"    => "Hamburg"
  "from"  => "Berlin"
  :length => "100"


julia> extend_route_information(Dict("from" => "Paris", "to" => "London"), length = "15", temperature = "20", timeOfArrival = "10:30")
Dict{Any, String} with 5 entries:
  :temperature   => "20"
  :timeOfArrival => "10:30"
  "to"           => "London"
  "from"         => "Paris"
  :length        => "15"
```
