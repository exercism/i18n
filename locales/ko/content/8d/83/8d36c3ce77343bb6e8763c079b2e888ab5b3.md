# 지시 사항

정원에 어느 날 하루 동안 새가 몇 마리 찾아왔는지 기록하는 열렬한 탐조가예요.

이제 탐조를 한 단계 더 발전시켜서, 데이터를 기록하고 처리하는 데 도움이 될 도구 몇 가지를 직접 만들어 보기로 했어요.

데이터는 정수 배열로 저장하기로 했어요.
배열의 첫 번째 숫자는 오늘 정원에 찾아온 새의 수이고, 두 번째는 어제, 그다음부터는 그 이전 날들의 수예요.

```exercism/note
실제 애플리케이션에서는 해당되는 경우 항상 코어 모듈을 사용해야 하지만, 이 연습 문제에서는 재귀를 배우는 것이 목적이므로 `List` 함수를 하나도 사용하지 마세요.
```

## 1. 오늘 찾아온 새의 수 확인하기

`today` 함수를 구현해요.
이 함수는 날짜별 새 개수를 담은 배열을 받아서 오늘의 개수를 반환해야 해요.
배열이 비어 있으면 `Nothing`을 반환하고, 그렇지 않으면 개수가 `Just`로 감싸져요.

```elm
BirdCount.today [2, 5, 1]
    -- Just 2
```

## 2. 오늘의 개수 증가시키기

`incrementDayCount` 함수를 구현해요.
이 함수는 날짜별 새 개수를 담은 배열을 받아서 오늘의 개수를 1만큼 증가시켜야 해요.
배열이 비어 있으면 `[1]`을 반환해요.

```elm
BirdCount.incrementDayCount [4, 0, 2]
    -- [5, 0, 2]
```

## 3. 새가 찾아오지 않은 날이 있었는지 확인하기

`hasDayWithoutBirds` 함수를 구현해요.
이 함수는 날짜별 새 개수를 담은 배열을 받아요.
정원에 새가 한 마리도 찾아오지 않은 날이 하루라도 있으면 `True`를, 그렇지 않으면 `False`를 반환해야 해요.

```elm
BirdCount.hasDayWithoutBirds [2, 0, 4]
    -- True

BirdCount.hasDayWithoutBirds [3, 8, 1, 5]
    -- False
```

## 4. 찾아온 새의 총 개수 계산하기

`total` 함수를 구현해요.
이 함수는 날짜별 새 개수를 담은 배열을 받아서, 데이터를 수집하기 시작한 이후로 정원에 찾아온 새의 총 개수를 반환해야 해요.

```elm
BirdCount.total [4, 0, 9, 0, 5]
    -- 18
```

## 5. 바쁜 날의 수 계산하기

어떤 날은 다른 날보다 더 바빠요.
바쁜 날이란 정원에 다섯 마리 이상의 새가 찾아온 날이에요.

`busyDays` 함수를 구현해요.
이 함수는 날짜별 새 개수를 담은 배열을 받아서 바쁜 날의 수를 반환해야 해요.

```elm
BirdCount.busyDays [4, 5, 0, 0, 6]
    -- 2
```
