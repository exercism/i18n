# 자세히 알아보기

포인터가 `int`나 다른 기본 자료형을 가리킬 수 있는 것처럼, 함수를 가리키는 포인터도 만들 수 있어요.
함수 포인터를 사용하면 함수를 다른 함수에 전달할 수 있어요.
다른 함수에 매개변수 값으로 전달되는 함수를 일급 함수라고 해요.
하나 이상의 함수를 매개변수로 받거나 함수를 반환하는 함수를 고차 함수라고 해요.

다음 예제에서 `is_even`과 `is_odd`는 일급 함수예요.
고차 함수는 `test_number`예요.

```c
#include <stdio.h>
#include <stdbool.h>

bool is_even (int number) {
    return number & 1 != 1;
}

bool is_odd (int number) {
    return number & 1 == 1;
}

// this function takes any other function which takes a number and returns a bool
void test_number(bool (*func) (int), int number, char *text){
    printf(text, number, func(number)? "true": "false");
}

int main() {
    // prints Testing odd for 3 is true
    test_number(is_odd, 3,"Testing odd for %d is %s\n");
    // prints Testing even for 3 is false
    test_number(is_even, 3,"Testing even for %d is %s\n");
}
```
`test_number`의 첫 번째 인자에 쓰인 `bool (*func) (int)`라는 함수 시그니처는 전달된 함수들의 시그니처와 일치해요.
`is_even`과 `is_odd`는 둘 다 `int` 매개변수를 받고 `bool`을 반환해요.
`(*func)`에서 `func`는 사용할 함수의 이름을 나타내요.
만약 `(*fn)`을 사용했다면, 이렇게 호출했을 거예요: `printf(text, number, fn(number)? "true": "false");`.
함수 포인터 매개변수를 만족시키려면, `test_number`를 호출할 때 기대하는 시그니처를 가진 함수의 이름을 전달해요.
이렇게 해서 함수 이름이 그 함수의 주소를 가리킨다는 것을 알 수 있어요.

잘못된 시그니처로 함수 포인터를 호출하면 정의되지 않은 동작(UB)이 발생해요.
컴파일러에 따라 아예 컴파일되지 않을 수도 있고, 경고가 나오든 나오지 않든 컴파일은 되지만 실행 중에 충돌이 발생할 수도 있어요.
