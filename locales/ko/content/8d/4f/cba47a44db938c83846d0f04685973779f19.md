# 소개

[`Enum` 모듈][exercism-enum]의 모든 함수는 _즉시 실행_돼요. `Enum` 모듈로 열거 가능한 값에 여러 작업을 수행하면, 각 작업은 중간 결과를 만들어요.

`Stream` 모듈은 _즉시 실행_되는 `Enum` 모듈 대신 쓸 수 있는 _지연 실행_ 모듈이에요. `Enum`과 같은 함수를 많이 제공하지만, 중간 결과를 만드는 대신 `Enum` 모듈의 함수에 스트림을 전달한 뒤에야 실행되는 일련의 연산을 구성해요.

스트림은 _Enumerable [프로토콜][exercism-protocols]_을 구현하고, 조합할 수도 있어요. 스트림을 서로 연결하면 더 복잡한 기능을 만들 수 있어요.

[exercism-enum]: https://exercism.org/tracks/elixir/concepts/enum
[exercism-protocols]: https://exercism.org/tracks/elixir/concepts/protocols
