# 소개

Haxe는 강타입 언어이지만, 필요할 때에는 타입 시스템을 우회할 수 있어요. 이름에 값을 할당하는 것을 변수를 정의한다고 해요. 변수는 타입을 직접 명시해서 정의할 수도 있고, [`var` 키워드](var)를 사용해 Haxe 컴파일러가 타입을 추론하도록 해서 정의할 수도 있어요. 따라서 다음 두 변수 정의는 서로 같아요:

```haxe
var explicitVariable:Int = 10; // Explicitly typed
var implicitVariable = 10; // Implicit typed
```

변수를 갱신할 때는 `=` 연산자를 사용해요:

```haxe
var number = 0; // Initial value
number = 1; // Updated value
```

변수와 타입이 다른 값을 할당하려고 하면 컴파일러가 오류를 발생시켜요:

```haxe
var number = 1; // Variable number is of integer type
number = "Hello" // Error trying to assign a string to an integer variable
```

Haxe에서는 보통 코드를 _함수_ 안에 작성해요. 함수는 [_메서드_](method)라고도 불러요. 함수는 매개변수(인자)를 받을 수 있고, `return` 키워드를 사용해 값을 반환해요. 함수는 `()` 구문으로 호출해요. 모든 함수는 반환 타입을 가져야 해요.

```haxe
function add(x:Int, y:Int):Int {
  return x + y;
}
```

Haxe에서 스코프는 `{`와 `}` 문자 사이에 정의돼요.

Haxe는 두 가지 종류의 주석을 지원해요. 한 줄 주석은 `//`로 시작하고, 여러 줄 주석은 `/*`와 `*/` 사이에 넣어요.

[var]: https://haxe.org/manual/expression-var.html
[oop]: https://en.wikipedia.org/wiki/Object-oriented_programming
[method]: https://haxe.org/manual/class-field-method.html
