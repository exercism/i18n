# 소개

집합은 불변이고 순서가 없는, 중복되지 않는 값들의 모음이에요. 집합의 모든 항목은 같은 타입이어야 해요.

`gleam/set` 모듈은 `Set` 타입을 정의하고, 집합을 다루는 함수들을 제공해요.

`set.to_list`와 `set.from_list`를 사용하면 배열과 집합을 서로 변환할 수 있어요. 집합에서 항목의 순서는 보장되지 않아요.

```gleam
set.from_list([2, 3, 3, 3, 1, 1, 2])
// -> set.from_list([1, 2, 3])

set.to_list(set.from_list([2, 3, 3, 3, 1, 1, 2]))
// -> [1, 2, 3]
```

`set.new`, `set.insert`, `set.delete`로 집합을 만들고 항목을 넣거나 지울 수 있어요.

```gleam
set.new()
// -> set.from_list([])

let eighty_eight = set.from_list([88])

set.insert(eighty_eight, 88)
// -> set.from_list([88])

set.insert(eighty_eight, 89)
// -> set.from_list([88, 89])

set.delete(eighty_eight, 88)
// -> set.from_list([])

set.delete(eighty_eight, 89)
// -> set.from_list([88])
```

`set.contains`와 `set.size` 함수로 집합의 내용을 확인할 수 있어요.

```gleam
set.contains(eighty_eight, 88)
// -> True

set.size(eighty_eight)
// -> 1
```

집합은 `set.union`과 `set.intersect`로 합칠 수 있어요.

```gleam
let a = set.from_list([1, 5, 10])
let b = set.from_list([1, 2, 3, 4, 5])

set.union(a, b)
// -> set.from_list([1, 2, 3, 4, 5, 10])

set.intersection(a, b)
// -> set.from_list([1, 5])
```

집합을 필터링할 수도 있어요.

```gleam
let is_small = fn(n) { x <= 3 }

set.filter(b, is_small)
// -> set.from_list([1, 2, 3])
```
