# 기여자

Exercism의 기여자는 Exercism의 언어 트랙과 도구를 함께 만드는 사람들이에요.

**누구나 Exercism 기여자가 될 수 있어요.** 사전 요건이나 지켜야 할 조건 같은 건 없고, 다양한 배경을 가진 사람들을 적극적으로 환영해요.
지금까지 4,000명이 넘는 사람들이 Exercism을 만드는 데 함께했어요!

Exercism을 돕는 방법은 아주 다양해요:

- 연습 문제 작성하기
- 트랙의 개념 개발하기
- 문서 개선하기
- 빠져 있는 도구 만들기 (예: Test Runner나 Code Analyzer)
- Bug 고치기
- 트랙의 콘텐츠 개선하기

...그리고 훨씬 더 많아요.

지금 필요한 모든 작업을 살펴보려면 [기여 섹션](/contributing)을 방문해 봐요.
