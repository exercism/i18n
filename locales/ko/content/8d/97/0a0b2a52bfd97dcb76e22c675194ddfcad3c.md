# 힌트

## 1. 새 거주자 만들기

- 구조체를 만드는 방법을 알아보려면 [구조체 개념](/tracks/go/concepts/structs)을 다시 살펴봐요.

## 2. 거주자 정보 검증하기

- 문자열의 제로 값은 `""`예요.
- 맵의 제로 값은 `nil`이에요.
- 맵에 키가 존재하는지 확인하는 방법을 알아보려면 [맵 개념](/tracks/go/concepts/maps)을 다시 살펴봐요.

## 3. 거주자 정보 삭제하기

- 거주자는 모든 필드가 제로 값으로 설정되면 삭제된 것으로 간주해요.
- Go 타입별 제로 값을 알아보려면 [제로 값 개념](/tracks/go/concepts/zero-values)을 다시 살펴봐요.

## 4. 거주자 수 세기

- 슬라이스를 순회하는 방법을 알아보려면 [range 반복 개념](/tracks/go/concepts/range-iteration)을 다시 살펴봐요.
