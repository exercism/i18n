# 지침

조직 네트워크의 로그인 절차를 간소화하는 시스템을 만들고 있어요. 이번 과제들은 인증 부분을 다뤄요. 이 시스템은 신원을 확인하기 위해 얼굴 인식을 사용해요.

모든 경우에 눈 색깔 매개변수는 null이 아님이 보장돼요.

## 1. 얼굴 특징이 일치하는지 확인하기

두 얼굴이 일치하는지 확인하는 `Authenticator.AreSameFace()`를 구현해요.

`FacialFeatures` 클래스에 동등성 루틴을 추가해요.

```csharp
Authenticator.AreSameFace(new FacialFeatures("green", 0.9m), new FacialFeatures("green", 0.9m);
// => true
Authenticator.AreSameFace(new FacialFeatures("blue", 0.9m), new FacialFeatures("green", 0.9m);
// => false
```

## 2. 시스템 관리자 인증하기

만류에도 불구하고 시스템 관리자는 인수 테스트 중에 항상 인증될 수 있도록 내장된 신원을 갖겠다고 고집해요.

관리자의 이메일은 admin@exerc.ism이에요. 관리자는 눈이 녹색이고 인중 너비는 0.9예요.

`Identity` 클래스에 동등성 루틴을 추가해요.

전달된 신원이 관리자의 신원과 일치하는지 확인하는 `Authenticator.IsAdmin()` 메서드를 구현해요.

```csharp
var authenticator = new Authenticator();
authenticator.IsAdmin(new Identity("admin@exerc.ism", new FacialFeatures("green", 0.9m)));
// => true
authenticator.IsAdmin(new Identity("admin@thecompetition.com", new FacialFeatures("green", 0.9m)));
// => false
```

## 3. 새로운 신원 등록하기

인증기 자체에 신원을 저장해서, 이 신원에 대한 `IsRegistered()` 호출이 `true`를 반환하도록 하는 `Authenticator.Register()` 메서드를 구현해요. 그렇지 않으면 `IsRegistered()`는 `false`를 반환해요.

신원을 중복으로 등록하려는 시도를 감지하기 위해, 이미 등록된 신원이면 `Authenticator.Register()`가 `false`를 반환하고, 그렇지 않으면 `true`를 반환해요.

```csharp
var authenticator = new Authenticator();
authenticator.Register(new Identity("tunde@thecompetition.com", new FacialFeatures("blue", 0.9m)));
// => true
authenticator.IsRegistered(new Identity("tunde@thecompetition.com", new FacialFeatures("blue", 0.9m)));
// => true
authenticator.Register(new Identity("tunde@thecompetition.com", new FacialFeatures("blue", 0.9m)));
// => false
```

## 4. 유효하지 않은 신원이 인증되지 않도록 막기

`Authenticator.IsRegistered()` 메서드를 구현하고, 등록된 신원이 없을 때 false를 반환하도록 해요.

```csharp
var authenticator = new Authenticator();
authenticator.IsRegistered(new Identity("alice@thecompetition.com", new FacialFeatures("blue", 0.8m)));
// => false
```

## 5. 인증 시도의 중복을 감지하는 진단 추가하기

동일한 신원에 대해 `Authenticator.IsRegistered()` 메서드가 연달아 여러 번 호출된다는 버그가 보고됐어요. 똑같은 레코드가 여러 번 제출되는 일종의 "바운스" 문제가 있는 것 같아요. 이번 과제는 진행되는 테스트를 지원하기 위해 진단 루틴 `Authenticator.AreSameObject()`를 추가하는 거예요. 이 루틴은 두 객체를 비교해서 정확히 같은 인스턴스면 `true`를, 그렇지 않으면 `false`를 반환해요.

```csharp
var identityA = new Identity("alice@thecompetition.com", new FacialFeatures("blue", 0.9m));
var identityB = identityA;
Authenticator.AreSameObject(identityA, identityB);
// => true

var identityC = new Identity("alice@thecompetition.com", new FacialFeatures("blue", 0.9m));
var identityD = new Identity("alice@thecompetition.com", new FacialFeatures("blue", 0.9m));
Authenticator.AreSameObject(identityC, identityD);
// => false
```
