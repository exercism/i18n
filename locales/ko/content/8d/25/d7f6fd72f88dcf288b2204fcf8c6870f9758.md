# 지침

이 연습 문제에서는 드디어 돈을 모아서 장만한 무선 조종 자동차를 가지고 놀아볼 거예요.

자동차는 완전히 충전된(100%) 배터리로 시작해요. 리모컨으로 자동차를 운전할 때마다 20미터를 이동하고 배터리를 1퍼센트 소모해요. 자동차의 별명은 자동차를 만들기 전까지는 알 수 없어요.

무선 조종 자동차에는 두 가지 정보를 보여주는 멋진 LED 디스플레이가 있어요:

- 지금까지 이동한 총 거리, `"<METERS> meters"`로 표시돼요.
- 남은 배터리 잔량, `"Battery at <PERCENTAGE>%"`로 표시돼요.

배터리가 0%라면 더 이상 자동차를 운전할 수 없고, 배터리 표시에는 `"Battery empty"`가 나타나요.

## 1. 새 무선 조종 자동차 만들기

새 무선 조종 자동차 구조체를 반환하도록 `RemoteControlCar.new/0` 함수를 구현해요:

```elixir
RemoteControlCar.new()
# => %RemoteControlCar{
#      battery_percentage: 100,
#      distance_driven_in_meters: 0,
#      nickname: "none"
#    }
```

별명은 구조체에 반드시 필요한데, 값은 구조체가 아니라 `new` 함수에서 초기화해야 해요.

## 2. 별명이 있는 새 무선 조종 자동차 만들기

전달받은 별명을 가진 새 무선 조종 자동차 구조체를 반환하도록 `RemoteControlCar.new/1` 함수를 구현해요:

```elixir
RemoteControlCar.new("Blue")
# => %RemoteControlCar{
#      battery_percentage: 100,
#      distance_driven_in_meters: 0,
#      nickname: "Blue"
#    }
```

## 3. 거리 표시하기

LED 디스플레이에 표시되는 대로 거리를 반환하도록 `RemoteControlCar.display_distance/1` 함수를 구현해요:

```elixir
car = RemoteControlCar.new()
RemoteControlCar.display_distance(car)
# => "0 meters"
```

이 함수가 인자로 `RemoteControlCar` 구조체만 받도록 해요.

## 4. 배터리 잔량 표시하기

LED 디스플레이에 표시되는 대로 배터리 잔량을 반환하도록 `RemoteControlCar.display_battery/1` 함수를 구현해요:

```elixir
car = RemoteControlCar.new()
RemoteControlCar.display_battery(car)
# => "Battery at 100%"
```

이 함수가 인자로 `RemoteControlCar` 구조체만 받도록 해요. 배터리가 0%라면 배터리 표시에는 "Battery empty"가 나타나요.

## 5. 운전하면 배터리와 이동 거리가 바뀌어요

다음을 수행하는 `RemoteControlCar.drive/1` 함수를 구현해요:

- 이동한 미터 수를 20만큼 늘려요
- 배터리를 1% 소모해요

```elixir
RemoteControlCar.new("Red")
|> RemoteControlCar.drive()

# => %RemoteControlCar{
#      battery_percentage: 99,
#      distance_driven_in_meters: 20,
#      nickname: "Red"
#    }
```

이 함수가 인자로 `RemoteControlCar` 구조체만 받도록 해요.

## 6. 방전된 배터리로 운전하는 경우 처리하기

배터리가 방전된(0%) 경우에는 이동 거리도 늘리지 않고 배터리 잔량도 줄이지 않도록 `RemoteControlCar.drive/1` 함수를 수정해요:

```elixir
%RemoteControlCar{
  battery_percentage: 0,
  distance_driven_in_meters: 1980,
  nickname: "Red"
}
|> RemoteControlCar.drive()

# => %RemoteControlCar{
#      battery_percentage: 0,
#      distance_driven_in_meters: 1980,
#      nickname: "Red"
#    }
```
