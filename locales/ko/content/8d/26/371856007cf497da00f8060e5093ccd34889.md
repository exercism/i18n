# 지침

여러분과 친구들은 종이와 펜으로 하는 역할 수행 게임을 좋아해요. 그런데 새로운 사람이 모임에 합류하기가 어렵다는 걸 알게 됐어요. 새로 오는 사람들은 캐릭터를 만드는 단계에서 자주 어려움을 겪고, 어디서부터 시작해야 할지 모르거든요. 그래서 새로운 플레이어들을 돕기 위해, 그 과정을 안내해 줄 작은 프로그램을 만들기로 했어요.

## 1. 새로운 플레이어 맞이하기

`RPG.CharacterSheet.welcome/0` 함수를 구현해요. 환영 메시지를 출력하고 `:ok`를 반환해야 해요.

```elixir
RPG.CharacterSheet.welcome()
# > Welcome! Let's fill out your character sheet together.
# => :ok
```

## 2. 캐릭터의 이름 묻기

`RPG.CharacterSheet.ask_name/0` 함수를 구현해요. 질문을 출력하고, 답을 기다린 뒤, 앞뒤 공백을 제거한 답을 반환해야 해요.

```elixir
RPG.CharacterSheet.ask_name()
# > What is your character's name?
# < Mathilde
# => "Mathilde"
```

## 3. 캐릭터의 클래스 묻기

`RPG.CharacterSheet.ask_class/0` 함수를 구현해요. 질문을 출력하고, 답을 기다린 뒤, 앞뒤 공백을 제거한 답을 반환해야 해요.

```elixir
RPG.CharacterSheet.ask_class()
# > What is your character's class?
# < healer
# => "healer"
```

## 4. 캐릭터의 레벨 묻기

`RPG.CharacterSheet.ask_level/0` 함수를 구현해요. 질문을 출력하고, 답을 기다린 뒤, 답을 정수로 반환해야 해요.

```elixir
RPG.CharacterSheet.ask_level()
# > What is your character's level?
# < 2
# => 2
```

## 5. 이전 단계를 하나로 합치기

`RPG.CharacterSheet.run/0` 함수를 구현해요. 새로운 플레이어를 맞이하고, 캐릭터의 이름과 클래스, 레벨을 물은 뒤, 캐릭터 시트를 맵으로 반환해야 해요. 또 "Your character"라는 레이블과 함께 맵을 출력해야 해요.

```elixir
RPG.CharacterSheet.run()
# > Welcome! Let's fill out your character sheet together.
# > What is your character's name?
# < Mathilde
# > What is your character's class?
# < healer
# > What is your character's level?
# < 2
# > Your character: %{class: "healer", level: 2, name: "Mathilde"}
# => %{class: "healer", level: 2, name: "Mathilde"}
```
