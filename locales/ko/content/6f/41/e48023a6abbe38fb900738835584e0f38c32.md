# 설치

## .NET 설치하기

F# 트랙은 Windows, Linux, macOS에서 실행되는 [.NET](https://dotnet.microsoft.com/learn/dotnet/what-is-dotnet) 플랫폼 위에 만들어졌어요. .NET 프로젝트를 빌드하려면 .NET CLI(명령줄 인터페이스)를 사용할 수 있어요. 이 CLI는 .NET SDK에 포함되어 있는데, [설치 안내](https://dotnet.microsoft.com/download)를 따라 설치할 수 있어요. 참고: F# 트랙은 SDK 버전 8.0 이상이 필요해요.

설치를 마친 뒤에는 터미널에서 다음 명령을 실행해 CLI가 제대로 설치되었는지 확인할 수 있어요:

```bash
dotnet --version
```

출력이 `8.0.100` 이상의 버전이면 .NET SDK가 제대로 설치된 거예요.

## IDE 사용하기

더 다양한 편집 기능을 원한다면 IDE를 사용하는 게 좋아요. 다음은 .NET 프로젝트 빌드를 지원하는 가장 인기 있는 IDE예요:

- [Visual Studio 2022](https://www.visualstudio.com/downloads/)
- [Ionide-fsharp 확장](https://marketplace.visualstudio.com/items?itemName=Ionide.Ionide-fsharp)이 있는 [Visual Studio Code](https://code.visualstudio.com/download)
- [Visual Studio for Mac](https://www.visualstudio.com/vs/visual-studio-mac/)
- [Project Rider](https://www.jetbrains.com/rider/download/)

참고: .NET 프로젝트 형식은 이전 버전과 크게 다르기 때문에, 오래된 IDE(예: Visual Studio 2015)는 지원하지 않아요.
