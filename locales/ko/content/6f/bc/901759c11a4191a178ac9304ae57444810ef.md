# 힌트

## 일반

- 함수는 그저 메모리 주소일 뿐이고, 다른 메모리 주소와 똑같이 다룰 수 있어요.
- 메모리 주소는 64비트 정숫값이고, 일반적인 레지스터를 통해 전달되고 반환돼요.
- 레지스터나 메모리에 저장된 함수로 `call`이나 `jmp`를 할 수 있어요.

## 1. 트랜잭션 기억하기

- 함수는 그저 메모리 주소일 뿐이고, 다른 메모리 주소와 똑같이 다룰 수 있어요.
- 메모리 주소는 64비트 정숫값이고, 일반적인 레지스터를 통해 전달되고 반환돼요.
- `remember_transaction`은 함수를 영구적인 메모리 위치에 저장해야 해요.
- `apply_remembered`에서는 저장된 함수에 전달할 인자가 이미 올바른 레지스터(`rdi`)에 들어 있어요.

## 2. 은행의 설명서

- 디스패치 테이블은 그저 배열일 뿐이고, 다른 배열과 똑같이 인덱싱할 수 있어요.
- 디스패치 테이블의 각 항목은 함수이고, 함수는 64비트(8바이트) 정숫값이에요.
- `select_transaction`에서는 트랜잭션에 전달할 인자가 원래 `rdx`에 있고, 함수를 호출하기 전에 `rdi`로 옮겨야 해요.
- 디스패치된 트랜잭션 호출은 꼬리 위치에 있으므로 꼬리 호출(`jmp`)을 사용해도 돼요.

## 3. 월별 명세서 처리하기

- 배열의 각 항목은 함수이고, 함수는 64비트(8바이트) 정숫값이에요.
- 호출자 저장 레지스터는 외부 함수에 의해 값이 덮어써질 수 있으므로, 그런 함수를 호출하기 전에 필요한 값을 저장해야 해요.
  호출자 저장 레지스터는 `rax`, `rcx`, `rdx`, `rdi`, `rsi`, `r8`, `r9`, `r10`, `r11`이에요.
- 피호출자 저장 레지스터(예: `rbx`, `rbp`, `r12`, `r13`, `r14`, `r15`)는 호출된 함수에 의해 값이 바뀌지 않아요.
  하지만 사용하기 전에 원래 값을 저장하고, 반환하기 전에 그 값을 복원해야 해요.
- 외부 함수를 호출하기 전에 스택은 16바이트로 정렬되어 있어야 해요.
  함수에 진입한 시점에서 `rsp`는 16의 배수보다 8만큼 작아요.
- 배열이 비어 있으면 어떤 트랜잭션도 적용되지 않고, 함수는 시작 잔액을 그대로 반환해야 해요.

## 4. 가드와 함께 처리하기

- 배열의 각 항목은 함수이고, 함수는 64비트(8바이트) 정숫값이에요.
- 호출자 저장 레지스터는 외부 함수에 의해 값이 덮어써질 수 있으므로, 그런 함수를 호출하기 전에 필요한 값을 저장해야 해요.
- 피호출자 저장 레지스터(예: `rbx`, `rbp`, `r12`, `r13`, `r14`, `r15`)는 호출된 함수에 의해 값이 바뀌지 않아요.
  하지만 사용하기 전에 원래 값을 저장하고, 반환하기 전에 그 값을 복원해야 해요.
- 외부 함수를 호출하기 전에 스택은 16바이트로 정렬되어 있어야 해요.
  함수에 진입한 시점에서 `rsp`는 16의 배수보다 8만큼 작아요.
- 가드 함수는 각 트랜잭션의 결과를 인자로 받아요.
  이 값은 가드 함수를 호출하기 전에 `rdi`에 있어야 해요.
- 가드 함수는 유효하지 않은 결과에 대해 `0`을 반환하고, 유효한 결과에 대해서는 0이 아닌 값을 반환해요.
  유효한 결과는 현재 잔액과 승인된 트랜잭션 수를 갱신해요.
- 함수는 두 개의 64비트 음이 아닌 정수를 반환해요. 최종 잔액은 `rax`에, 승인된 트랜잭션 수는 `rdx`에 있어야 해요.
