# 참고 자료

[Learning][learning] 자료와 더불어, Odin 여정에 도움이 될 만한 다른 곳들도 소개해요:

* [Odin playground][play]에서 브라우저로 직접 실험해 볼 수 있어요.
* [odin-lang/Odin][gh] GitHub 저장소.
* Odin의 [커뮤니티][community] 링크 (포럼, Discord, Reddit 등).
* Odin을 만든 gingerBill이 쓴 [글][articles].
  언어의 설계 원칙을 엿볼 수 있어요.
* [스타일 가이드][style].
* [Awesome Odin][awesome], Odin 라이브러리와 자료 링크 모음.
* Odin과 게임 개발에서 Odin을 활용하는 방법을 다룬 [영상 시리즈][vids].
  "Understanding Odin" 책의 저자 Karl Zylinski가 만들었어요.
