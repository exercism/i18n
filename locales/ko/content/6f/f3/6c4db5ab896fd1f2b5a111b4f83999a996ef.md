# 소개

## 불리언

Java에서 불리언은 `boolean` 타입으로 표현되며, 값은 `true` 또는 `false`예요.

Java는 세 가지 불리언 연산자를 지원해요:  

- `!` (NOT): 불리언을 부정해요  
- `&&` (AND): 불리언 두 개를 받아서 둘 다 `true`면 `true`를 반환해요
- `||` (OR): 두 불리언 중 하나라도 `true`면 `true`를 반환해요

### 예시

```java
!true // => false
!false // => true
true && false // => false
true && true // => true
false || false // => false
false || true // => true
```
