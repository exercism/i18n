# 소개

[`Set`][set]은 다음과 같은 특징을 가진 항목들의 모음이에요:

- 순서가 없어요.
- 항목은 서로 달라야 해요. 그래서 중복을 추가하려고 해도 아무런 알림 없이 무시돼요.
- 수학의 집합에서 흔히 쓰는 연산을 많이 지원해요.

`Set()` 생성자로 만들 수 있어요. 매개변수로는 어떤 이터레이터든 넣을 수 있어요.

```julia-repl
julia> s1 = Set(1:4)
Set([4, 2, 3, 1])
```

새 원소는 `push!()`로 추가하고(배열과 같아요), `delete!()`로 삭제해요.

```julia-repl
julia> push!(s1, 5)
Set([5, 4, 2, 3, 1])

# Duplicates are ignored
julia> push!(s1, 3)
Set([5, 4, 2, 3, 1])

julia> delete!(s1, 5)
Set([4, 2, 3, 1])

julia> length(s1)  # length counts entries, despite the non-sequential type
4
```

## Set 연산

다른 여러 컬렉션 타입과 마찬가지로, `in` 또는 `∈` 연산자로 항목이 들어 있는지 확인해요 (`∈` 기호는 `\in`을 입력한 뒤 탭을 눌러요).

```julia-repl
julia> 3 ∈ s1
true
```

`Set` 두 개에 대해 다음 연산을 지원해요 (괄호 안은 연산자 기호를 입력하는 단축키예요).

- `union(A, B)` 또는 `A ∪ B` (`\cup`): A 또는 B, 또는 둘 다에 있는 모든 항목이에요.
- `intersect(A, B)` 또는 `A ∩ B` (`\cap`): A와 B 모두에 공통으로 있는 모든 항목이에요.
- `setdiff(A, B)` (기호 없음): A에는 있지만 B에는 없는 항목이에요.
- `symdiff(A, B)` (기호 없음): A 또는 B 중 한쪽에만 있는 항목이에요.
- `issubset(A, B)` 또는 `A ⊆ B` (`\subseteq`) 또는 `B ⊇ A` (`\supseteq`): A의 모든 항목이 B에도 있으면 `true`예요.
- `issetequal(A, B)` (기호 없음): A와 B가 정확히 같은 항목을 담고 있으면 `true`예요.
- `isdisjoint(A, B)` (기호 없음): A와 B에 공통인 항목이 하나도 없으면 `true`예요 (그래서 교집합이 비어 있어요).

```julia-repl
julia> s1 = Set(1:4);
julia> s2 = Set(3:6);
julia> s1 ∪ s2  # union
Set([5, 4, 6, 2, 3, 1])

julia> s1 ∩ s2  # intersect
Set([4, 3])
  
julia> setdiff(s1, s2)
Set([2, 1])

julia> symdiff(s1, s2)
Set([5, 6, 2, 1])
  
julia> s1 ⊇ s2  # issubset
false
```

이 중 상당수는 함수 이름에 `!`를 붙인 변경 버전도 있어요. 전체 함수 목록은 [매뉴얼][set]에서 볼 수 있어요.
