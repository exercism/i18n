# 힌트

## 1. 최고 점수 표 만들기

- 최고 점수 표는 해시 테이블이어야 해요.
- `make-hash-table`로 해시 테이블을 만들 수 있어요.

## 2. 표에 플레이어 추가하기

- 해시 테이블에 키/값 쌍을 추가하려면 `(setf (gethash key table) value)`를 사용해요.

## 3. 플레이어의 점수 설정하기

- 플레이어의 점수를 설정하는 것은 표에 플레이어를 추가하는 것과 거의 같아요.
- 해시 테이블에 키/값 쌍을 추가하려면 `(setf (gethash key table) value)`를 사용해요.

## 4. 표에서 점수 가져오기

- `gethash`를 사용해 해시 테이블에서 키에 해당하는 값을 가져와요.
- `gethash`에는 선택적인 세 번째 인자가 있는데, 키를 찾지 못했을 때 사용할 값이에요.

## 5. 표에서 플레이어 제거하기

- `remhash`를 사용해 표에서 키를 제거해요.
