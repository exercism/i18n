# 지침

그림이 주어지면, 유치원 반의 각 아이가 어떤 식물을 담당하는지 알아내는 것이 과제예요.

이 반에는 아이가 12명 있어요:

- Alice, Bob, Charlie, David, Eve, Fred, Ginny, Harriet, Ileana, Joseph, Kincaid, Larry

네 가지 종류의 씨앗을 심어요:

| 식물   | 그림 표기        |
| ------ | ---------------- |
| Grass  | G                |
| Clover | C                |
| Radish | R                |
| Violet | V                |

각 아이는 각 줄에 두 개씩, 모두 네 개의 컵을 받아요:

```text
[window][window][window]
........................ # each dot represents a cup
........................
```

선생님은 아이들의 이름을 알파벳 순으로 정렬한 뒤, 그 순서대로 컵을 배정해요. 그래서 Alice가 맨 처음이고 Larry가 맨 마지막이에요.

다음은 Alice의 식물을 나타내는 예시 그림이에요:

```text
[window][window][window]
VR......................
RG......................
```

창문에 가장 가까운 첫 번째 줄에는 violet과 radish가 있어요. 두 번째 줄에는 radish와 grass가 있어요.

프로그램에는 창문에 가장 가까운 줄부터 시작해 왼쪽에서 오른쪽 순서로 식물이 주어져요. 이 정보를 바탕으로 각 학생에게 어떤 식물이 속하는지 알아낼 수 있어야 해요.

예를 들어, 정원이 다음과 같다고 하면:

```text
[window][window][window]
VRCGVVRVCGGCCGVRGCVCGCGV
VRCCCGCRRGVCGCRVVCVGCGCV
```

그때 Alice의 식물을 물어보면 다음과 같은 결과를 내놓아야 해요:

- Violets, radishes, violets, radishes

한편 Bob의 식물을 물어보면 이런 결과가 나와요:

- Clover, grass, clover, clover
