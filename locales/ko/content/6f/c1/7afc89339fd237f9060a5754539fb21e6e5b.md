# 설치

## 요구 사항

* 64비트 x86 CPU
* 최신 C 컴파일러
* Make 빌드 도구
* Netwide Assembler (NASM)

이 트랙은 System V AMD64 ABI의 호출 규약만 지원한다는 점에 유의해 주세요. Windows 사용자는 Linux용 Windows 하위 시스템(WSL)을 설치하거나 Linux 가상 머신을 설정해야 해요.

## Linux

시스템의 패키지 관리자를 사용해 필요한 소프트웨어를 설치해요:

* Ubuntu, Debian: `$ sudo apt-get install gcc make nasm`
* Fedora: `$ sudo dnf install gcc make nasm`
* CentOS, RHEL: `$ sudo yum install gcc make nasm`
* Arch Linux: `$ sudo pacman -S gcc make nasm`
* OpenSUSE: `$ sudo zypper install gcc make nasm`

## macOS

Xcode Command Line Tools를 설치해요:

```bash
$ xcode-select --install
```

[Homebrew](http://brew.sh/)로 NASM을 설치해요:

```bash
$ brew install nasm
```

## Windows

WSL을 설치하는 방법은 https://docs.microsoft.com/en-us/windows/wsl/install-win10를 참고해요.
