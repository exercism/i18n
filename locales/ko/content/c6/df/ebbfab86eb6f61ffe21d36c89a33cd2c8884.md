# 소개

Swift는 표준 라이브러리에서 풍부한 기능을 제공하지만, 외부 라이브러리와 프레임워크를 `import`하면 더 많은 기능을 사용할 수 있어요.
이런 모듈은 Swift 프로젝트에서 직접 제공하는 것([Swift Argument Parser][argument-parser] 등)일 수도 있고, Apple 플랫폼 프레임워크([Foundation][apple-foundation]이나 [Network Framework][network-framework] 등)일 수도 있으며, 서드파티 오픈 소스 라이브러리([SwiftyBeaver][swifty-beaver] 등)일 수도 있어요.

Foundation처럼 Swift에서 가장 널리 쓰이는 라이브러리 가운데 하나인 핵심 모듈은 Swift 툴체인에 함께 포함되어 있어요.
서드파티 라이브러리는 프로젝트 설정에 추가해야 가져올 수 있어요(예를 들어 Swift Package Manager를 사용해서요).

모듈을 가져오려면 `import` 키워드를 쓰고 그 뒤에 모듈 이름을 적어요:

```swift
import Foundation
```

모듈을 가져오면 그 모듈의 타입과 메서드, 함수를 코드에서 사용할 수 있어요.
예를 들어 Foundation을 가져오면 `components(separatedBy:)`처럼 유용한 편의 메서드가 `String`에 추가돼요.

관례적으로 `import` 문은 Swift 파일 맨 위에 놓아요. 그래야 코드를 읽는 사람이 의존 관계를 바로 파악할 수 있어요.

[argument-parser]: https://apple.github.io/swift-argument-parser/documentation/argumentparser/
[network-framework]: https://developer.apple.com/documentation/network
[swifty-beaver]: https://github.com/SwiftyBeaver/SwiftyBeaver
[apple-foundation]: https://developer.apple.com/documentation/foundation
