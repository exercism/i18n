# 힌트

## 1. 준비 시간 추정하기

- 벡터의 [`size()`][size-func]를 사용해 레이어 수(레이어 슬라이스의 길이)를 확인해요.

## 2. 필요한 면과 소스의 양 계산하기

- 먼저 면과 소스의 양을 추적할 `amount` 객체를 만들어요.
- [`for`문][for-loop]을 사용해 레이어를 순회해요.
- 반복 중에 `"noodles"` 또는 `"sauce"` 레이어를 만나면, `amount` 객체에 저장된 양을 그에 맞게 늘려요.

## 3. 비법 재료 넣기

- 벡터에서 원소를 가져오는 방법과 벡터의 원소를 바꾸는 방법을 알아보려면 [벡터][concept-vector]를 다시 살펴봐요.
- 벡터 `a`에서 마지막 원소의 인덱스는 `a.size() - 1`이고, `a.back()`을 바로 사용할 수도 있어요.

## 4. 레시피 분량 조절하기

- 먼저 입력 슬라이스와 같은 크기의 새 슬라이스를 만들어요
- [`for`문][for-loop]을 사용해 입력 슬라이스를 순회하면서 출력 슬라이스를 만들어요

## 5. 가족의 비밀 밝혀내기

- 3번 문제에서 작성한 코드를 다시 사용할 수 있어요.
- 이 문제에는 [함수 오버로딩][function overloading]이 필요해요.
