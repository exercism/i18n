# 지침

여러분이 일하는 회사에서 곧 **Smarty 5**라는 새로운 스마트폰을 출시하려고 해요. 이 스마트폰에는 완전히 새로운 카메라 시스템과 새로운 디자인, 그리고 **smartyOS**라는 새로운 운영 체제에서 동작하는 혁신적인 새 프로세서가 들어 있어요.

새 프로세서는 그 어느 때보다 안전한 비밀번호를 처리할 수 있는 성능을 갖추고 있어서, 회사는 이를 활용하기로 했어요. 그래서 회사는 사용자가 비밀번호를 설정하고, 입력한 비밀번호가 올바른지 확인할 수 있는 휴대폰용 비밀번호 잠금 시스템을 구현해 달라고 요청했어요.

~~~~exercism/caution
이 연습 문제에서 다루는 비밀번호 시스템은 안전하지 않으며, 교육 목적으로만 사용해요. 실제 애플리케이션에는 **절대** 사용하면 안 돼요.
~~~~

## 1. 비밀번호 설정하기

이 휴대폰에서는 단순한 숫자 비밀번호부터 더 안전한 영숫자 비밀번호, 심지어 지문을 저장하는 비밀번호까지 여러 가지 유형의 비밀번호를 사용할 수 있어요.

이 비밀번호들은 각각 다른 타입을 사용해요. 숫자 비밀번호는 `Int32`, 영숫자 비밀번호는 `String`, 지문 비밀번호는 `Float64`를 사용해요.

세 가지 유형의 비밀번호 중 하나를 인자로 받아 `@password`라는 인스턴스 변수에 저장하는 초기화 메서드를 가진 `PasswordLock` 클래스를 구현해요.

```crystal
password_lock = PasswordLock.new(1234)
# => #<PasswordLock:0x7f8e1b8c0b80 @password=1234>
```

## 2. 비밀번호 암호화하기

회사는 비밀번호가 평문으로 저장되지 않도록 암호화하기로 했고, 이를 위한 메서드를 구현해 달라고 요청했어요.

비밀번호 유형마다 고유한 암호화 방식이 있어요.

- `Int32` 비밀번호: 비밀번호를 2로 나누고 가장 가까운 정수로 반올림해요.
- `String` 비밀번호: 비밀번호를 뒤집어요.
- `Float64` 비밀번호: 비밀번호에 4를 곱해요.

인자를 받지 않고 `@password` 인스턴스 변수를 암호화된 값으로 수정하는 `encrypt` 인스턴스 메서드를 구현해요.

```crystal
password_lock = PasswordLock.new(1234)
# => #<PasswordLock:0x7f8e1b8c0b80 @password=1234>

password_lock.encrypt
# => #<PasswordLock:0x7f8e1b8c0b80 @password=617>
```

## 3. 비밀번호가 올바른지 확인하기

회사는 주어진 비밀번호가 올바른지 확인하는 메서드도 구현해 달라고 요청했어요.

비밀번호가 틀리면 `nil`을, 올바르면 `"Unlocked"`를 반환하는 메서드를 원해요.

확인할 비밀번호를 인자로 받는 `unlock?` 인스턴스 메서드를 구현해요. 이 메서드는 비밀번호가 틀리면 `nil`을, 올바르면 `"Unlocked"`를 반환해야 해요.

```crystal
password_lock = PasswordLock.new(1234)
password_lock.encrypt
password_lock.unlock?(1234)
# => "Unlocked"
```
