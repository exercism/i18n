# 소개

JavaScript에서 _템플릿 문자열_을 사용하면 문자열 안에 표현식을 넣을 수 있어요. 이를 문자열 보간이라고도 하죠.
이 기능은 내장 [`String`][string-reference] 전역 객체의 기능을 확장한 거예요.

JavaScript에서는 텍스트를 백틱으로 감싸서 템플릿 문자열을 만들 수 있어요.
템플릿 문자열을 쓰면 텍스트에 줄 바꿈이나 다른 특수 문자를 넣을 수 있을 뿐만 아니라, 변수와 다른 표현식도 넣을 수 있어요.

```javascript
const num1 = 1;
const num2 = 2;

`Adding ${num1} and ${num2} gives ${num1 + num2}.`;
// => Adding 1 and 2 gives 3.
```

위 예시에서는 백틱(<code>\`\`</code>)을 사용해 템플릿 문자열을 나타내요. `${...}`는 값을 대신 채워 넣는 자리 표시자예요.
문자열이 아닌 타입은 _암묵적으로_ 문자열로 변환돼요.
이 내용은 [타입 변환][type-conversion-concept] 개념에서 다뤄요.
템플릿 문자열에는 모든 종류의 표현식을 사용할 수 있어요.

```javascript
const track = 'JavaScript';

`This track on exercism.org is ${track.toUpperCase()}.`;
// => This track on exercism.org is JAVASCRIPT.
```

문자열을 여러 줄로 나눠서 써야 할 때도 있어요:

```javascript
`This is an example of using template
strings to accomplish multiple
lines`;
```

이렇게 값을 대신 채워 넣는 기능을 이용하면, 출력 문자열이 무엇이 되어야 할지 결정하는 로직을 넣을 수도 있어요.

그 예로 [삼항 연산자][ternary-operator]를 넣는 방법이 있어요.
이 연산자는 `if/else`문을 짧게 쓴 형태예요.
문법은 `condition ? consequent-expression : alternative-expression`이에요.
조건이 truthy면 콜론 왼쪽의 피연산자가 반환돼요.
그렇지 않으면 삼항 표현식의 결과는 콜론 오른쪽의 피연산자가 돼요.

```javascript
const grade = 95;

`You have ${grade > 90 ? 'passed' : 'failed'} the exam.`;
// => You have passed the exam.
```
