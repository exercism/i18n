# 안내 추가

## 구현 참고 사항

테스트 프로그램은 가변 인자 `New` 함수를 반복해서 적용해 트리를 만들어요.
예를 들어, 다음 문은

```go
tree := New("a",New("b"),New("c",New("d")))
```

다음 트리를 만들어요:

```text
      "a"
       |
    -------
    |     |
   "b"   "c"
          |
         "d"
```

테스트 트리에는 중복된 값이 없다고 가정해도 돼요.

`Value`와 `Children` 메서드는 테스트 프로그램이 트리를 분해할 때 사용해요.

연습 문제에서 흥미로운 부분을 시작하기 전에 기본적인 트리 구성과 분해가 먼저 동작해야 하므로, 처음 세 개의 테스트에서 따로 테스트해요.

---

`FromPov`와 `PathTo` 메서드가 이 연습 문제의 흥미로운 부분이에요.

`FromPov` 메서드는 값으로 트리의 노드를 지정하는 문자열 인자 `from`을 받아요. 값 `from`이 루트에 있는 트리를 반환해야 해요. 원래 트리를 수정해서 그대로 반환해도 되고, 새 트리를 만들어 반환해도 돼요. 새 트리를 반환한다면 원래 트리를 소비하거나 파괴해도 괜찮아요. 물론 원래 트리를 그대로 두면 더 좋아요.

`PathTo` 메서드는 값으로 트리의 두 노드를 지정하는 두 개의 문자열 인자 `from`과 `to`를 받아요. 첫 번째 노드에서 두 번째 노드까지 트리에서 가장 짧은 경로를 반환해야 해요.
