# 소개

## 확장 메서드

확장 메서드는 새로운 파생 타입을 만들거나 다시 컴파일하거나 원래 타입을 수정하지 않고도 기존 타입에 메서드를 추가할 수 있게 해줘요. 확장 메서드는 static 메서드로 정의되지만 인스턴스 메서드 구문을 사용해 호출해요. 첫 번째 매개변수 앞에는 `this` 한정자가 붙고, 메서드가 어떤 타입에서 작동하는지 지정하며, 네임스페이스 수준에서 스코프에 포함돼요.

```csharp
public static int WordCount(this string str)
{
    return str.Split().Length;
}

"Hello World".WordCount();
// => 2
```
