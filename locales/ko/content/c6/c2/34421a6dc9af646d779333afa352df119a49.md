# 문자열 타입

Cairo에는 문자열을 위한 자체 데이터 타입이 없어요.
하지만 문자열 타입을 표현하는 두 가지 방법이 있어요: 단일 `felt252`를 사용하는 짧은 문자열과 `ByteArray`를 사용하는 임의 길이 문자열이에요.

## 짧은 문자열

짧은 문자열은 작은따옴표로 만들며, 문자열을 이루는 각 문자가 [ASCII 표준][ascii-table]에 따라 1바이트에 인코딩돼요.

ASCII 문자열로서 예를 들어 `'abc'`는 다음과 같아요:

- `'a'`는 `0x61`과 같아요
- `'b'`는 `0x62`와 같아요
- `'c'`는 `0x63`과 같아요
- `'abc'`는 `0x616263`과 같아요

`felt252` 데이터 타입은 Cairo에서 짧은 문자열 타입을 담아요.
`felt252`는 251비트를 담기 때문에, 짧은 문자열은 31자로 제한돼요 (31 \* 8 = 248비트이고, 이는 251비트에 들어가는 8의 최대 배수예요).

짧은 문자열 선언의 예:

```rust
    let my_first_char = 'D';
    let my_first_char_in_hex = 0x44;

    let my_first_string = 'Hello world';
    let my_first_string_in_hex = 0x48656C6C6F20776F726C64;
```

### ByteArray

ByteArray 구조체는 Cairo 2.4.0에서 도입됐어요.
ByteArray 문자열은 다음과 같이 큰따옴표로 작성해요:

```rust
    let long_string: ByteArray = "this is a string which has more than 31 characters";
```

기술적으로, 이번 업데이트에서는 31바이트를 담고 felt에 들어가는 `bytes31` 타입도 도입됐어요.
`ByteArray` 구조체는 기본적으로 "온전한 단어"(즉, felt 전체를 채우는 단어)를 담는 `bytes31`의 배열과, "불완전한 단어"를 담는 단일 felt 필드를 사용해 긴 문자열을 표현해요 (그 안의 바이트 수는 별도의 길이 필드에 지정돼요).

```rust
#[derive(Drop, Clone, PartialEq, Serde, Default)]
struct ByteArray {
    data: Array<bytes31>,
    pending_word: felt252,
    pending_word_len: usize,
}
```

[ascii-table]: https://www.asciitable.com/
