# 힌트

## 1. id 번호 생성하기

- 함수는 다른 함수를 반환해야 해요.
- 반환된 함수는 `day` 매개변수에 접근할 수 있어야 해요.

## 2. 복구한 비밀 계획을 비밀 비밀번호로 보호하기

- 반환된 함수에는 매개변수가 하나뿐이에요.
- 문자열은 [동등성][equality]을 사용해 비교할 수 있어요.

## 3. 비밀 비밀번호 찾기

- 미니언의 함수를 호출할 때, 알고리즘에서 우리가 맡은 부분을 수행하는 다른 함수를 인자로 넘겨요.

[equality]: https://kotlinlang.org/docs/equality.html#structural-equality
