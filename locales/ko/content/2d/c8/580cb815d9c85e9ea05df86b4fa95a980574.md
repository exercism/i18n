# 기초 살펴보기

Kotlin은 Java와 완전히 상호 운용되도록 설계된 정적 타입 언어예요.

Java와 구별되는 Kotlin의 특징은 다음과 같아요.

- 더 깔끔하고 간결한 문법을 가지고 있어요.
- 함수형 언어의 여러 기능을 포함하고 있어요.
- null이 될 수 있는 값을 폭넓게 지원해요.

## 변수

Kotlin은 정적 타입 언어이기 때문에, 컴파일 시점에 각 값의 타입을 _알아야_ 해요.

하지만 Kotlin의 [타입 추론][inference]은 매우 강력해서, 타입을 _직접 지정하는_ 것은 대개 선택 사항이에요.

변수를 선언하는 방법에는 두 가지가 있어요.

1. `val`은 불변 변수를 만들고, 이 값을 바꾸려고 하면 컴파일 오류가 발생해요.

```kotlin
val x = 42  // => 42
x = 43      // => 'val' cannot be reasssigned
```

2. `var`은 가변 변수를 만들어요.

```Kotlin
var x = 42  // => 42
x = 43      // => 43
```

불변 변수는 흔한 부류의 버그를 없애 주기 때문에, 가능하면 `val`을 사용하는 것이 권장돼요.

또한 `var`조차 타입을 바꿀 수는 없어요.

```kotlin
var x = 42
x = "foobar" // => Type mismatch: inferred type is String but Int was expected
```

시각적 산만함을 줄이기 위해, 이 강의 자료에서는 타입을 대부분 생략할 거예요.
그래도 최소한 다음의 경우에는 타입을 지정하는 것이 좋아요.

- 공개 API
- 함수 시그니처
- 문서화가 필요한 곳

어떤 회사나 조직은 엄격한 타입 안전성을 요구하며 타입 추론을 허용하지 않고, 또 다른 곳은 "단순한" 타입에만 타입 추론을 제한하거나 아예 타입 추론을 전적으로 받아들이기도 해요.

```kotlin
val x: Int = 42  // => 42
```

일반적으로 변수와 함수의 이름은 `snake_case`가 아니라 `camelCase`로 짓는 것이 좋아요.

## 함수

함수는 `fun` 키워드로 선언해요.
Java와 달리, 함수가 반드시 클래스의 일부일 필요는 없어요.

```Kotlin
fun hello(): String {
    return "Hello, World!"
}

fun add(x: Int, y: Int): Int {
    return x + y
}
```

몇 가지 짚어 둘 점이 있어요.

- 함수 이름 뒤에는 괄호 `()`가 필요해요. 함수가 인자를 받지 않더라도 마찬가지예요.
- 함수의 인자는 타입을 지정해야 해요. 변수와 달리 타입 추론이 없어요.
- 함수의 본문은 중괄호 `{ }`로 감싸요. (아래 내용도 참고해요.)
- 값을 반환할 때는 `return` 키워드가 필요해요.
- 줄 끝의 세미콜론 `;`은 선택 사항이며, 보통은 생략해요.
- 산술 연산자 `+`, `-`, `*`, `/`는 대부분의 주류 언어와 비슷해요.

그런데 아주 단순한 "단일 표현식" 함수라면 축약된 문법을 쓸 수 있어요.

```Kotlin
// return type is usually omitted for single-expression functions
fun add(x: Int, y: Int) = x + y  
```
함수는 기본값을 가진 매개변수를 가질 수 있어요.
이 값들은 함수를 호출할 때 생략하면 대신 사용돼요.

```kotlin
fun ping(host: String = "localhost") {
    println("PING --> $host")
}

ping("exercism.io")  // PING --> exercism.io
ping()               // PING --> localhost
```

Exercism의 함수는 보통 값을 반환해요. (테스트 러너가 구성된 방식 때문이에요.)
Kotlin을 더 폭넓게 활용하려면, 값을 반환하지 않는 함수는 반환 타입과 return 키워드를 생략할 수 있다는 점을 알아 두면 도움이 돼요.

그런 함수는 `Unit` 반환 타입을 가진다고 해요. Java와 여러 다른 언어의 `void`와 같은 거예요.

## 주석

한 줄 주석은 `//`로 시작하고, 그 줄의 나머지는 무시돼요.

여러 줄 주석은 `/*`로 시작해서 `*/`로 끝나요.

```Kotlin
fun hello(): String {
    /*
     * Failing to run this program on a new installation 
     * is considered bad luck
    */
    return "Hello, World!" // the compiler pixies are now happy
}
```

이는 Java와 같아요.
