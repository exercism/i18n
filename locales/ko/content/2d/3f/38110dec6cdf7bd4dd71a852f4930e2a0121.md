# 개요

Swift에는 루프와 switch 문의 실행 흐름을 바꾸는 제어 전달문이 있어요.
Swift에는 `return` 외에도 `continue`, `break`, 루프 레이블, `fallthrough`가 있어요.

## Continue

`continue` 문은 현재 반복 실행을 멈추고 곧바로 다음 반복을 시작하라고 루프에 알려줘요.
`while`문이나 `repeat-while` 루프에서는 조건 검사로 바로 넘어가요.
`for-in` 루프에서는 시퀀스의 다음 원소로 넘어가요.

```swift
var count = 1
while count < 6 {
    count += 1
    if count == 4 {
        continue
    }
    print(count)
}

// Prints:
// 2
// 3
// 5
// 6
```

## Break

`break` 문은 루프나 switch 문 전체를 즉시 빠져나와요.
실행은 루프나 switch 다음에 오는 첫 번째 코드 줄부터 이어져요.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    if !fruit.count.isMultiple(of: 2) {
        break
    }
    print(fruit)
}

// Prints:
// banana
// grapes
```

## 레이블이 붙은 문

루프가 중첩되어 있을 때에는 `break`나 `continue`가 가장 안쪽 루프가 아니라 바깥 루프에 영향을 주기를 원할 수 있어요.
루프 앞에 이름과 콜론(`labelName:`)을 붙이면 루프에 레이블을 달 수 있어요.
그런 다음 그 레이블을 `break`나 `continue`에 넘기면 돼요:

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    print("\n--- \(fruit) ---")
    for letter in fruit {
        guard letter != "n" else {
            break outerLoop
        }
        print(letter)
    }
}

// Prints:
// --- banana ---
// b
// a
```

## Fallthrough

Swift에서 `switch` 문은 기본적으로 다음 case로 흘러가지 않아요. 실행은 일치한 case의 끝에서 자동으로 멈춰요.
패턴을 확인하지 않고 다음 case로 실행을 이어 가고 싶다면 `fallthrough` 키워드를 사용해요:

```swift
let value = 1
switch value {
case 1:
    print("One")
    fallthrough
case 2:
    print("Two")
default:
    break
}

// Prints:
// One
// Two
```
