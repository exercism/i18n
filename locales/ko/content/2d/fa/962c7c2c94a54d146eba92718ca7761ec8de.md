# named export가 없어요

[`export %{export.name}`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/export) 선언을 찾지 못했어요. 이게 없으면 테스트가 통과하지 못해요.

`%{export.name}` 선언이 있는지 확인하고, 그 앞에 `export`를 붙여요:
```javascript
// exporting a "const"
export const %{export.name} = /*...*/

// exporting a named function declaration
export function %{export.name}() { /* ... */ }
```
