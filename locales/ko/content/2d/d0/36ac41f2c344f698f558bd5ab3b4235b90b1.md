# 지침

조류 조사를 돕고 있어요. 매일 누군가 관찰 초소에 앉아서 날아가는 것을 세고, 그날의 집계는 배열로 돌아와요.

다섯 가지 과제는 모두 `BIRD_SURVEY` 클래스에 들어가요.

## 1. 합계

매일의 집계를 모두 더해요.

```sather
BIRD_SURVEY::total_seen(|3, 0, 7|)
-- => 10
```

조사한 날이 하나도 없다면 세는 새는 0마리예요.

## 2. 최고의 날

가장 큰 집계를 반환해요. 날이 하나도 없었다면 답은 0이에요.

```sather
BIRD_SURVEY::busiest_day(|3, 0, 7|)
-- => 7
```

## 3. 바쁜 날들

어떤 수를 넘는 집계가 있었던 날은 며칠일까요?

```sather
BIRD_SURVEY::days_over(|3, 0, 7|, 2)
-- => 2
```

넘는다는 건 정말 넘어야 한다는 뜻이에요. 정확히 2인 집계는 세지 않아요.

## 4. 확인할 관찰 초소

조사 첫날에는 관찰 초소 한 곳을 확인하고, 둘째 날에는 두 곳을 확인하는 식이에요. 그러면 모두 몇 번의 관찰 초소 확인을 하게 될까요?

```sather
BIRD_SURVEY::hides_to_check(4)
-- => 10
```

1 + 2 + 3 + 4를 더한 값이에요.

## 5. 첫 번째 바쁜 날

어떤 수를 넘는 집계가 처음 나온 날은 며칠이었을까요? 날은 배열 위치처럼 0부터 세요. 그렇게 바쁜 날이 없었다면 답은 `-1`이에요.

```sather
BIRD_SURVEY::first_busy_day(|3, 0, 7|, 5)
-- => 2
BIRD_SURVEY::first_busy_day(|3, 0, 7|, 9)
-- => -1
```
