# 지침

저전력 임베디드 시스템을 대상으로 하는 게임을 만들고 있는데, 게임의 다른 부분에서 사용할 여러 편의 함수를 작성해야 해요.

## 1. 나눗셈의 몫과 나머지를 계산해요

몫은 나눗셈의 결과예요.

```rust
fn divmod(dividend: i16, divisor: i16) -> (i16, i16)
```

예시:

```rust
assert_eq!(divmod(10, 3), (3, 1));
```

## 2. 반복자에서 짝수 위치의 항목을 골라요

이 함수는 화면 버퍼 최적화를 가능하게 하는 데 도움이 될 거라고 상사가 장담했어요.

반복자는 [`Iterator` 트레이트](https://doc.rust-lang.org/std/iter/trait.Iterator.html)에 정의된 메서드를 제공하는 항목이에요. 반복자가 제공하는 메서드가 많기 때문에 그 문서도 꽤 방대해요. 가장 관련 있는 특징은 다음과 같아요:

- 반복자는 임의 길이의 항목 스트림이에요
- 값마다 튜플 `(i, val)`을 반환하는 [`enumerate` 메서드](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.enumerate)가 있어요
- 클로저를 사용해 반복자의 원소를 내보낼지 결정하는 [`filter` 메서드](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.filter)가 있어요
- 클로저를 사용해 반복자의 원소를 수정하는 [`map` 메서드](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.map)가 있어요

함수는 어떤 종류의 반복자에서도 동작할 수 있기 때문에, 단순한 항목이 아니라 트레이트 인스턴스라는 것을 나타내기 위해 `impl`을 사용해요. 마찬가지로 `<Item=T>` 문법은 반복자가 만들어 내는 항목의 종류가 무엇이든 상관없다는 뜻일 뿐이에요. 함수는 어떤 반복자에서든 짝수 원소를 만들어 낼 수 있어요.

```rust
fn evens<T>(iter: impl Iterator<Item=T>) -> impl Iterator<Item=T>
```

예시:

```rust
let mut even_ints = evens(0_u8..);
assert_eq!(even_ints.next(), Some(0));
assert_eq!(even_ints.next(), Some(2));
assert_eq!(even_ints.next(), Some(4));
assert_eq!(even_ints.next(), Some(6));
```

```rust
let mut evens_from_odds = evens(1_i16..);
assert_eq!(evens_from_odds.next(), Some(1));
assert_eq!(evens_from_odds.next(), Some(3));
assert_eq!(evens_from_odds.next(), Some(5));
assert_eq!(evens_from_odds.next(), Some(7));
```

## 3. 원점에서 어떤 위치까지의 맨해튼 거리를 계산해요

매핑을 편하게 하기 위해 튜플 구조체 `Position`이 있어요:

```rust
struct Position(i16, i16);
```

`Position`에, 원점(`Position(0, 0)`)에서 해당 위치까지의 [맨해튼 거리](https://en.wikipedia.org/wiki/Taxicab_geometry)를 반환하는 `manhattan` 메서드를 구현해야 해요.

```rust
impl Position {
    fn manhattan(&self) -> i16
}
```

예시:

```rust
assert_eq!(Position(3, 4).manhattan(), 7);
```
