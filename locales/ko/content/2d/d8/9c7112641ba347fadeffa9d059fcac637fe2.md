# 지침 추가

## 구현

자연수의 분류 값을 담기 위한 `type Classification`을 정의해요.
이 타입을 어떻게 표현할지는 자유롭게 정해도 돼요.

다음 이름으로 Classification 상수 세 개를 정의해요.

```text
	ClassificationDeficient
	ClassificationPerfect
	ClassificationAbundant
```

int64 입력을 받아 Classification과 오류 값을 반환하는 Classify라는 함수를 구현해요.

입력이 양의 정수가 아닐 때 반환되는 ErrOnlyPositive라는 오류를 만들어요.
