# 힌트

## 일반

- 이전에 배운 [structs][], [maps][], [methods][] 개념이 여기서 유용해요.


## 1. 참석자 추적

- [type definition][] 개념에서 새로운 타입을 정의하는 방법을 설명해요.
- `make()`를 사용해 새로운 `map` 인스턴스를 만들어요.
- 맵에 값을 추가하려면 `struct{}{}` 문법으로 빈 `struct{}`의 인스턴스를 만들어요.

## 2. 참석자 확인

- 어떤 원소가 맵에 들어 있으면 집합에 그 값이 포함된 거예요.
- [two value assignment][]을 사용하면 맵에 항목이 있는지 확인할 수 있어요.

## 3. 참석자 비교

- 각 집합의 모든 값이 다른 집합에 들어 있으면 두 집합은 같아요.
- `range`를 사용하면 집합의 모든 원소를 확인할 수 있어요.
