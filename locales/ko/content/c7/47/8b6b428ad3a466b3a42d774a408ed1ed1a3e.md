# 소개

[`Set`][set]은 다음과 같은 성질을 가진 원소의 컬렉션이에요.

- 순서가 없어요.
- 원소가 중복될 수 없어서, 중복된 값을 추가하려는 시도는 조용히 무시돼요.
- 수학적 집합에서 흔히 쓰는 연산을 많이 지원해요.

`Set()` 생성자로 만들어요. 이때 매개변수로 아무 이터레이터나 넘길 수 있어요.

```julia-repl
julia> s1 = Set(1:4)
Set{Int64} with 4 elements:
  4
  2
  3
  1
```

새 원소는 `push!()`로 추가하고(배열과 똑같아요), `delete!()`로 제거해요.

```julia-repl
julia> push!(s1, 5)
Set{Int64} with 5 elements:
  5
  4
  2
  3
  1

# Duplicates are ignored
julia> push!(s1, 3)
Set{Int64} with 5 elements:
  5
  4
  2
  3
  1

julia> delete!(s1, 5)
Set{Int64} with 4 elements:
  4
  2
  3
  1

julia> length(s1)  # length counts entries, despite the non-sequential type
4
```

## Set 연산

여러 다른 컬렉션 타입과 마찬가지로, `in` 또는 `∈` 연산자로 포함 여부를 확인해요(기호는 `\in`을 입력한 다음 Tab 키를 눌러요).

```julia-repl
julia> 3 ∈ s1
true
```

두 Set에 대한 다음 연산을 지원해요(연산자 기호 단축키는 괄호 안에 표시했어요).

- `union(A, B)` 또는 `A ∪ B`(`\cup`): A 또는 B, 또는 둘 다에 있는 모든 원소예요.
- `intersect(A, B)` 또는 `A ∩ B`(`\cap`): A와 B 둘 다에 공통으로 있는 모든 원소예요.
- `setdiff(A, B)`(기호 없음): A에는 있지만 B에는 없는 원소예요.
- `symdiff(A, B)`(기호 없음): A 또는 B 한쪽에만 있고 둘 다에는 없는 원소예요.
- `issubset(A, B)` 또는 `A ⊆ B`(`\subseteq`) 또는 `B ⊇ A`(`\supseteq`): A의 모든 원소가 B에도 있으면 `true`예요.
- `issetequal(A, B)`(기호 없음): A와 B가 정확히 같은 원소를 담고 있으면 `true`예요.
- `isdisjoint(A, B)`(기호 없음): A와 B에 공통인 원소가 하나도 없으면 `true`예요(즉, 교집합이 비어 있어요).

```julia-repl
s1 = Set(1:4)
s2 = Set(3:6)

julia> s1 ∪ s2  # union
Set{Int64} with 6 elements:
  5
  4
  6
  2
  3
  1

julia> s1 ∩ s2  # intersect
Set{Int64} with 2 elements:
  4
  3
  
julia> setdiff(s1, s2)
Set{Int64} with 2 elements:
  2
  1

julia> symdiff(s1, s2)
Set{Int64} with 4 elements:
  5
  6
  2
  1
  
julia> s1 ⊇ s2  # issubset
false
```

이 중 상당수에는 함수 이름에 `!`를 붙인, 원본을 직접 바꾸는 버전도 있어요. 전체 함수 목록은 [매뉴얼][set]에서 확인해요.
