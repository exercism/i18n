Code blocks는 Raku에서 아주 폭넓게 사용돼요.
함수에 꼭 필요한 것이기도 하지만, `grep`이나 `map` 같은 도구에서도, `if`, `for`, `while`, `given`문의 블록으로도, 심지어 배열 첨자로도 쓰여요.

## 루틴

Raku에서 `Subs`과 `Methods`는 `Routines`의 한 종류예요.

루틴은 `return` 키워드를 사용해 언제든지 값을 반환하면서 빠져나올 수 있는데, 함수를 만들 때 유용한 도구예요.
`return`을 지정하지 않으면 루틴의 마지막 문이 암묵적인 반환 값이 돼요.

루틴은 코드 블록 앞에 괄호로 둘러싼 `Signature`를 가질 수 있어요.

`Routine`은 `Block`의 하위 클래스예요.

```raku
sub add ($x, $y --> Int) { return $x + $y }
say add(1, 2); # 3
```

메서드는 클래스와 객체에 관한 별도의 개념에서 다뤄요.

## 블록

`Block`은 재사용할 수 있는 코드 객체로, 주로 람다를 만들 때 사용해요.

블록의 마지막 문이 암묵적인 반환 값이에요.

블록은 코드 블록 앞에 `->`를 붙인 `Signature`를 가질 수 있어요.

`Block`은 `Code`의 하위 클래스이고, `Code`는 Raku의 모든 코드 객체에서 가장 위에 있는 기반 클래스예요.

```raku
my $add = -> $x, $y { $x + $y };
say $add(1, 2); # 3
```

## 시그니처

`Signature`는 쉼표로 구분된 0개 이상의 `Parameters`로 이루어져요.

시그니처 끝에는 [반환 타입 화살표][signatures-return-type-arrow] `-->`로 반환 타입을 지정할 수 있어요.

시그니처로 `Block`이 받을 인자를 지정할 수 있어요.

이 개념에서는 시그니처를 단순하게 유지하기 위해, 스칼라 시길이 붙은 변수로 된 위치 매개변수와 반환 타입만 사용해요.
이 내용은 다른 개념에서 더 자세히 다뤄요.

## 멀티 디스패치

Raku에서는 `multi` 키워드를 사용해 이름은 같지만 시그니처가 다른 여러 루틴을 작성할 수 있어요.
이 기능을 [멀티 디스패치][multi-dispatch]라고 해요.
이름으로 루틴을 호출하면 런타임 환경이 알맞은 후보를 찾아 실행해요.

이 내용은 타입에 관한 개념에서 더 자세히 다뤄요.

```raku
multi foo () { say 'No arguments given'}

multi foo ($bar) { say "One argument given: $bar" }
```

## WhateverCode

`Whatever` 별 `*`을 대부분의 연산자와 함께 사용하면 `WhateverCode` 객체가 만들어져요.
이를 통해 더 간단한 문법으로 블록을 만들 수 있어요.

```raku
# These will all give code blocks that increment a single argument by 1:
-> $x { $x  + 1 }; # Explicit signature
      { $^x + 1 }; # Signature via placeholder variable
      { $_  + 1 }; # Topic variable
          * + 1;   # WhateverCode
```
