## 튜플

[튜플][tuple]은 여러 정보를 하나로 묶을 때 흔히 사용해요. 배열과 다른 점은 크기가 고정되어 있고 서로 다른 데이터 타입을 담을 수 있다는 거예요.
튜플은 괄호 `()`로 만들고, 함수에서 여러 값을 반환할 때 자주 사용해요.

```haskell
tuple = (1, "abc", False)
```

예를 들어 2D 공간의 좌표를 저장하고 싶을 때 유용한데, 그러면 그 튜플에는 항상 x 좌표와 y 좌표, 두 개의 원소가 들어 있다는 걸 알 수 있어요.

```haskell
coordinate = (3, 4)
```

### 원소에 접근하기

짧은 튜플을 다룰 때가 많은데, 이때는 `fst`와 `snd` 함수로 원소에 접근할 수 있어요.

```haskell
x = fst coordinate
-- x = 3
y = snd coordinate
-- y = 4
```

## 패턴 매칭

Haskell 함수를 작성할 때는 [패턴 매칭][pattern-match-doc]을 이용한 [단언적 스타일][assertive-style]을 활용할 수 있어요.
패턴 매칭은 Haskell의 아주 강력한 기능으로, 데이터 생성자에 매칭하고 그 안의 값에 변수를 바인딩할 수 있게 해줘요.
이름에서 알 수 있듯이 패턴 매칭은 값을 패턴에 맞춰 보는 것이고, 값이 패턴과 일치하면 패턴 안의 값에 변수를 바인딩할 수 있어요.
패턴 매칭은 주로 값 인식하기, 변수 바인딩하기, 값 분해하기라는 개념으로 이루어져 있어요.

예를 들어 이런 함수를 봐요:

```haskell
lucky :: Int -> String
lucky 7 = "Lucky number seven!"
lucky x = "Sorry, you're out of luck, pal!"
```

여기 `Int`를 받아 `String`을 반환하는 `lucky` 함수가 있어요.
이 함수에는 두 개의 패턴을 정의했는데, 하나는 숫자 `7`과 일치하고 다른 하나는 그 밖의 어떤 숫자와도 일치해요. 이름은 무엇이든 괜찮지만(Haskell 이름 규칙만 따르면 돼요) 여기서는 `x`를 써요.
숫자가 `7`이면 함수는 `"Lucky number seven!"`을 반환하고, 그렇지 않으면 `"Sorry, you're out of luck, pal!"`을 반환해요.
여기서 중요한 점은 패턴이 위에서 아래로 검사된다는 거예요. 그래서 만약 두 패턴의 순서를 바꿨다면 함수는 항상 `"Lucky number seven!"`을 반환했을 거예요.

### 배열 패턴

아주 흔한 패턴 중 하나는 배열을 매칭하는 것인데, 이때는 배열의 head와 tail을 가져와요.
이는 배열이 연결 리스트라는 특성 때문이에요.
다음은 배열의 head와 tail을 반환하는 함수의 예예요:

```haskell
headAndTail :: [Int] -> (Int, [Int])
headAndTail [] = error "Can't call head on an empty list"
headAndTail (x:xs) = (x, xs)
```

여기에는 두 개의 패턴이 있는데, 하나는 빈 배열과 일치하고 다른 하나는 원소가 적어도 하나 있는 배열과 일치해요.
빈 배열일 때를 처리하는 패턴이 없으면 런타임 오류가 발생하기 때문이에요.
배열이 비어 있지 않다면, 배열의 head를 `x`에, tail을 `xs`에 매칭할 수 있어요.
이때 `:` (cons) 연산자를 사용하는데, 이 연산자는 배열 맨 앞에 원소를 추가할 때 써요.
하지만 패턴 매칭에서는 배열을 head와 tail로 분해할 수 있게 해주니, 어떤 면에서는 반대 동작인 셈이에요.

`xs`는 배열의 tail에 흔히 쓰는 이름으로, 이것이 배열임을 강조해요. 중첩된 배열을 다룬다면 `xss`를 써서 배열의 배열이라는 점을 강조할 수 있어요.

### 튜플 패턴

배열과 마찬가지로 튜플도 매칭할 수 있어요.
다음은 튜플을 받아 첫 번째와 두 번째 원소를 반환하는 함수의 예예요:

```haskell
sumTuple :: (Int, Int) -> Int
sumTuple (x, y) = x + y
```

여기서는 원소가 두 개인 튜플과 일치하는 패턴을 사용하는데, 첫 번째 원소는 `x`에, 두 번째 원소는 `y`에 바인딩돼요.

### 와일드카드 패턴

어떤 변수의 값에는 관심이 없고 그냥 패턴만 일치시키고 싶을 때가 있어요.
이때 와일드카드 패턴을 사용하는데, 밑줄 `_`로 나타내요.

다음은 배열의 첫 번째 원소를 반환하는 함수의 예예요:

```haskell
head' :: [Int] -> Int
head' [] = error "Can't call head on an empty list"
head' (x:_) = x
```

여기서는 배열의 tail이 필요 없다는 뜻으로, 와일드카드 패턴을 써서 무시해요.

### 타입 패턴

타입도 매칭할 수 있는데, 이때는 해당 타입의 생성자를 사용해요.
튜플에서 했던 것처럼 타입에서 값을 추출할 수도 있어요.

```haskell
data AccountType = Guest | User String 

greet :: AccountType -> String
greet Guest = "Welcome, guest!"
greet (User name) = "Welcome, " ++ name ++ "!"
```

첫 번째 패턴에서는 `Guest` 생성자와 일치시키고, 두 번째 패턴에서는 `User` 생성자와 일치시키면서 그 안의 값을 `name`에 바인딩해요.
