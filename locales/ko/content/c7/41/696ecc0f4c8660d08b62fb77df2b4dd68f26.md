# 배열

PHP의 배열은 순서가 있는 맵이에요.
맵은 키에 값을 연결해 주는 자료 구조예요.
배열은 활용 범위가 넓어서 `C`나 `Java`에서처럼 선형 배열로, 리스트 [벡터], 해시 테이블, 딕셔너리, 컬렉션, 스택, 큐로 다룰 수 있어요.

키는 생략할 수 있지만, 지정한다면 `int`나 `string`이어야 해요.
키를 지정하지 않으면 PHP는 `0`부터 시작해서 커지는 정수 키를 기본으로 사용해요.

```php
$no_keys = ["my", "first", "array"];
$integer_keys = [0 => "my", 1 => "first", 2 => "array"];

$no_keys == $integer_keys // => equal returns true
$no_keys === $integer_keys // => strictly equal returns true
```

배열에는 모든 타입의 값을 저장할 수 있어요.
값마다 타입이 달라도 괜찮아요.

## 배열 사용하기

배열은 리터럴로 선언하거나(위에서처럼 코드로 직접 작성) 함수로 만들어 조작할 수 있어요.
인덱스 연산자로 값에 접근하고, 할당하고, 추가해요:

```php
$prime_numbers = [2, 3, 5, 6];

$prime_numbers[3] = 7; // replace 6 with 7

$prime_numbers[] = 11; // array now contains [2, 3, 5, 7, 11]
```
