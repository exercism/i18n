# 소개

Java에서 메서드 오버로딩은 매개변수 목록만 다르다면 같은 이름의 메서드를 여러 개 가질 수 있게 해 주는 기능이에요.
컴파일 시점(또는 정적) 다형성과 관련이 있어요.
이 개념은 비슷한 작업을 하면서도 서로 다른 입력을 받는 메서드를 만들 때 꼭 필요해요.

## 메서드를 오버로딩하는 이유

메서드 오버로딩은 프로그램의 가독성을 높여 줘요.
서로 다른 메서드에 같은 이름을 붙이되 매개변수를 다르게 줄 수 있어요.
매개변수의 개수나 매개변수의 타입에 따라 그에 맞는 메서드가 호출돼요.

## 메서드를 오버로딩하는 방법

메서드 오버로딩의 핵심은 메서드의 시그니처예요.
시그니처가 다르면 두 메서드는 서로 다른 메서드로 취급돼요.
메서드를 오버로딩하는 방법에는 두 가지가 있어요.

1. **매개변수의 개수가 다름**: 같은 이름이지만 매개변수의 개수가 다른 메서드를 만들 수 있어요.

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(int x, int y) {
           System.out.println("Show with two ints: " + x + ", " + y);
       }
   }
   ```

2. **매개변수의 타입이 다름**: 같은 이름이고 매개변수의 개수도 같지만 타입이 다른 메서드를 만들 수 있어요.

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(String s) {
           System.out.println("Show with String: " + s);
       }
   }
   ```

## 기억할 점

- 오버로딩된 메서드는 인자 목록을 바꿔야 해요.
- 오버로딩된 메서드는 반환 타입도 바꿀 수 있지만, 반환 타입만 바꾸는 것은 메서드 오버로딩이 되지 않아요.
- 메서드는 같은 클래스 안에서도, 하위 클래스에서도 오버로딩할 수 있어요.

이 개념에서는 Java에서의 메서드 오버로딩에 관한 여러 예제와 세부 사항을 살펴볼 거예요.
