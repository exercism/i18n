# 지시 사항

좋아하는 요리책에 나온 라자냐를 요리할 수 있도록 코드를 작성해 볼 거예요.

요리와 관련된 다섯 가지 과제가 있어요.

## 1. 오븐에 넣어야 할 예상 시간을 분 단위로 정의해요

`$EXPECTED-MINUTES-IN-OVEN` 상수를 라자냐를 오븐에 넣어야 하는 분 수로 설정해요. 요리책에 따르면 예상 오븐 시간은 40분이에요:

```raku
$EXPECTED-MINUTES-IN-OVEN
# => 40
```

## 2. 남은 오븐 시간을 분 단위로 계산해요

`remaining-minutes-in-oven` 서브루틴을 수정해요. 이 서브루틴은 라자냐가 실제로 오븐에 있던 분 수를 인자로 받아서, 이전 과제에서 구한 예상 오븐 시간을 기준으로 라자냐가 오븐에 더 있어야 하는 분 수를 반환해요.

```raku
remaining-minutes-in-oven(30)
# => 10
```

## 3. 준비 시간을 분 단위로 계산해요

`preparation-time-in-minutes` 서브루틴을 수정해요. 이 서브루틴은 라자냐에 추가한 층 수를 인자로 받아서, 각 층을 준비하는 데 2분이 걸린다고 가정했을 때 라자냐를 준비하는 데 걸린 분 수를 반환해요.

```raku
preparation-time-in-minutes(2)
# => 4
```

## 4. 총 작업 시간을 분 단위로 계산해요

`total-time-in-minutes` 서브루틴을 수정해요. 이 서브루틴은 두 개의 인자를 받는데, 첫 번째 인자는 라자냐에 추가한 층 수이고 두 번째 인자는 라자냐가 오븐에 있던 분 수예요.
이 서브루틴은 라자냐를 요리하는 데 총 몇 분을 작업했는지를 반환해야 하는데, 이는 준비 시간과 현재까지 라자냐가 오븐에서 보낸 시간을 더한 값이에요.

```raku
total-time-in-minutes(3, 20)
# => 26
```

## 5. 라자냐가 완성되었다는 알림을 만들어요

`oven-alarm` 서브루틴을 수정해요. 이 서브루틴은 인자를 받지 않고, 라자냐를 먹을 준비가 되었다는 메시지를 반환해요.

```raku
oven-alarm()
# => 'Ding!'
```
