# 개요

Elm처럼 순수 함수형 언어에서는 같은 인자로 호출한 함수가 항상 같은 값을 반환해야 해요.
따라서 `rand : Int`라는 타입 시그니처를 가진 함수는 (`rand = 4`)[xkcd-random]로밖에 구현할 수 없는데, 이는 무작위 정수를 생성하는 데 그리 좋은 징조가 아니에요.

그럼 Elm에서는 어떻게 무작위 값을 생성할까요?
문제를 둘로 나눠 봐요. 먼저 생성하려는 값을 `Random.Generator a`로 기술하고, 그다음 실제로 값을 생성해요.

값을 생성하는 첫 번째 방법은 `initialSeed : Int -> Seed`로 `Random.Seed`를 만드는 거예요.
`Seed`는 정수 하나를 담고 있으면서, 그 정수를 무작위처럼 보이는 방식(이를 의사 난수라고 해요)으로 변환할 줄 아는 불투명 타입이에요.
`Seed`를 하나 만들었다면, 이걸 이용해 `Generator a`로 값을 생성할 수 있어요.
`Generator a`는 시드 안에 있는 정수를 이용해 타입 `a`의 의사 난수 값을 만들고, 정수가 갱신된 새 시드도 함께 만들어 내는 방법을 아는 불투명 타입이에요.

값을 생성하려면 `step : Generator a -> Seed -> ( a, Seed )`를 사용할 수 있는데, 이 함수는 값과 함께 다음 값들을 생성하는 데 쓸 수 있는 새 시드를 반환해요.

이 함수들을 사용해서 제너레이터에서 무작위 값 `n`개를 뽑아내 봐요:

```elm
generate : Int -> Generator a -> List a
generate n generator = generateValuesFromSeed n generator (Random.initialSeed 42)

generateValuesFromSeed : Int -> Generator a -> Seed -> List a
generateValuesFromSeed n generator seed =
    if n <= 0 then
        []
    else
        let ( value, nextSeed ) = Random.step generator seed
        in value :: generateValuesFromSeed (n - 1) generator nextSeed
```

이 함수들은 모두 순수하기 때문에, 같은 인자로 두 번 호출해도 같은 값이 나와요.

```elm
generate 10 (Random.int 1 6)
    --> [4, 5, 3, 3, 5, 1, 2, 4, 6, 6]

generate 10 (Random.int 1 6)
    --> [4, 5, 3, 3, 5, 1, 2, 4, 6, 6]
```

값을 생성하는 두 번째 방법은 `Random.generate : (a -> msg) -> Generator a -> Cmd msg`를 사용하는 건데, 이는 Elm 애플리케이션 안에서만 할 수 있어요.
이 경우 Elm 런타임은 `step`뿐만 아니라 순수하지 않은 외부 자원을 사용해 시드를 생성할 수 있고, 같은 함수를 두 번 호출하면 서로 다른 결과가 나와요.

이제부터는 제너레이터에 집중해 볼게요.

`Random` 모듈은 특정 범위의 정수와 실수를 만드는 두 가지 기본 제너레이터를 제공해요:

```elm
generate 5 (Random.int -5 5)
    --> [0, 3, -5, 5, 0]

generate 3 (Random.float 0 5)
    --> [1.61803, 3.14159, 2.71828]
```

이 값들은 튜플로, 또는 값의 배열로 조합할 수 있어요:

```elm
generate 2 (Random.list 3 (Random.int 0 3))
    --> [[0, 3, 3], [1, 3, 2]]

generate 2 (Random.pair (Random.int 0 3) (Random.float 10 10.3))
    --> [(0, 10.23412), (2, 10.17094)]
```

(`elm-community/random-extra`)[random-extra] 패키지는 문자열, 날짜, 딕셔너리, 배열, 집합 등 다양한 자료 구조를 위한 훨씬 많은 제너레이터를 제공해요.

`Random.constant`를 사용하면 항상 하나의 값만 반환하는 제너레이터를 만들 수 있어요:

```elm
generate 4 (Random.constant "hello")
    --> ["hello", "hello", "hello", "hello"]
```

`Random.uniform`을 사용하면 주어진 원소들 중에서 같은 확률로 무작위로 하나를 고를 수 있어요:

```elm
generate 5 (Random.uniform Red [Green, Blue])
    --> [Red, Blue, Blue, Green, Red]
```

`Random.uniform`은 (`Red`와 `[Green, Blue]`) 두 개의 인자를 받는데, 이는 배열 하나만으로는 비어 있을 수 있기 때문에 고를 값이 최소한 하나는 있음을 보장하기 위해서예요.

`Random.weighted`를 사용하면 확률을 조정할 수도 있어요:

```elm
generate 5 (Random.weighted (80, Red) [(15, Green), (5, Blue)])
    --> [Red, Red, Green, Red, Red]
```

값들의 합이 꼭 100일 필요는 없어요. 어차피 다시 정규화되니까요.

`Random.map`으로 제너레이터 안쪽에 접근할 수 있어요:

```elm
generate 3 (Random.int 1 6 |> Random.map (\n -> n * 10))
    --> [30, 60, 10]
```

`Random.map2`부터 `Random.map5`까지 사용하면 더 많은 제너레이터를 조합할 수 있어요:

```elm
position =
    Random.map3
      (\x y z -> Position x y z)
      (Random.float -100 100)
      (Random.float -100 100)
      (Random.float -100 100)

generate 1 position
    --> [Position 33.788 -98.321 10.0845]
```

더 복잡한 용도로는 `Random.andThen : (a -> Generator b) -> Generator a -> Generator b`가 있는데, 이 함수는 한 제너레이터가 생성한 값을 이용해 다른 제너레이터를 만들 수 있어요:

```elm
bool = Random.uniform True [False]

failHalfOfTheTime : Generator a -> Generator (Maybe a)
failHalfOfTheTime generator =
    bool
        |> Random.andThen
            (\boolResult ->
                if boolResult then
                    Random.map Just generator

                else
                    Random.constant Nothing
            )

generate 6 (Random.int 0 1 |> failHalfOfTheTime)
    --> [Nothing, Just 1, Just 0, Nothing, Just 1, Nothing]
```

제너레이터를 자기 자신을 참조하는 방식으로 정의하는 게 유용할 때도 있어요.
그럴 때는 컴파일러가 제너레이터를 끝없이 펼쳐 놓지 않도록 `Random.lazy`를 사용해야 할 수도 있어요.

```elm
type Peano
    = Zero
    | Next Peano


peano : Generator Peano
peano =
    Random.uniform (Random.constant Zero)
        [ Random.map Next (Random.lazy (\_ -> peano))
        ]
        |> Random.andThen identity

generate 12 peano
    --> [Zero, Next(Next(Zero)), Zero, Next(Zero), Zero, Zero, Next(Zero), Zero, Zero, Next(Zero), Next(Next(Next(Zero)))]
```

이 예제는 조금 복잡하니 하나씩 뜯어볼까요.

`Peano`는 양의 정수를 나타내는 타입이에요. `Zero`는 0, `Next(Zero)`는 1, `Next(Next(Zero))`는 2, 이런 식이에요.
`peano`는 무작위 `Peano` 수를 만들어 주도록 정의해요.

우선 `Random.lazy`는 로직에 아무것도 더하지 않고, 컴파일러가 `peano`를 `peano` 안에 끝없이 써 넣는 것만 막아 준다는 점에 주목해요.

`Random.uniform`으로 0(확률 50%)과 다른 `Peano` 수에 1을 더한 값(확률 50%) 중에서 하나를 골라요.
그런데 앞의 예제와 달리, 여기서는 `peano` 자체를 사용하고 싶기 때문에 `Random.uniform`이 (`Zero` 같은) 값이 아니라 (`Random.constant Zero` 같은) 제너레이터 중에서 고르고 있어요.
즉, `Random.uniform`은 `Generator (Generator Peano)` 타입의 값을 반환하게 되는데, 이건 우리에게 필요한 게 아니에요.

제너레이터를 "평탄화"하기 위해 이걸 `Random.andThen : (a -> Generator b) -> Generator a -> Generator b`로 파이프하는데, 여기서 `b`는 `Peano`가 되기를 원해요.
`Generator a`가 `Generator (Generator Peano)`이므로, `a`는 `Generator Peano`여야 하고, 함수 `(a -> Generator b)`는 `(Generator Peano -> Generator Peano)` 타입이어야 해요.
아무것도 바꾸고 싶지 않으니 `identity`가 딱 맞는 선택이에요.

마지막으로, `peano`는 어떤 수를 만들어 낼까요?
50%의 확률로 0을 만들어 내고, 나머지 50%의 확률로 자기 자신을 한 번 더 반복한 값에 1을 더한 값을 만들어 낸다는 걸 알 수 있어요.
즉, 수는 0(50%의 확률), 1(25%의 확률), 2(12%의 확률), 3(6%의 확률) 등이 나와요.
`peano`는 아주 큰 수도 만들 수 있지만, 확률은 기하급수적으로 줄어들어요.
