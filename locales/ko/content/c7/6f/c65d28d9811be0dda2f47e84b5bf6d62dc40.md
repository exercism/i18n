# 소개

[concept:csharp/resource-cleanup]()에서는 `IDispose` 인터페이스를 사용해서, 어떤 객체가 더 이상 필요하지 않게 되었을 때 그 객체의 리소스나 기타 프로그램 상태를 해제하거나 초기화해야 한다는 것(그리고 가비지 컬렉터에 의존하는 것으로는 이를 해내지 못하거나 필요한 수준의 제어를 제공하지 못한다는 것), 그리고 그런 정리 작업을 하기에 자연스러운 곳이 `IDisposable.Dispose()` 메서드라는 것을 알려줘요.

호출하는 쪽에서 보면, 리소스 수명 관리 전체를 하나의 문으로 모을 수 있게 해 주는 또 다른 구문이 있는데, 바로 `using` 블록이에요.

```csharp
using (var file = new File("my_secrets"))
{
    file.WriteSecret("xxxxxxx");
}
```

위 예제에서는 `using` 블록을 벗어나면 `file`과 관련된 파일 시스템 리소스가 운영 체제로 반환돼요.

이 패턴이 동작하려면 using 문의 변수가 `IDisposable` 인터페이스를 구현하는 참조 형식이어야 하고, `Dispose()` 메서드에서 리소스를 해제하거나 프로그램 상태를 초기화해야 해요.

C# 8에서는 이 패턴이 한층 더 다듬어졌어요. using 문을 블록 맨 앞에 둘 수 있거든요.

```csharp
using var drawingResource = some_provided_or_new_object;
try
{
    drawingResource.DrawSomething();
}
catch (Exception)
{
    throw;
}
```

Java 개발자라면 Java 7에서 도입된 _자동 리소스 관리_ 메커니즘과 비슷하다는 걸 알아차릴지도 몰라요.
