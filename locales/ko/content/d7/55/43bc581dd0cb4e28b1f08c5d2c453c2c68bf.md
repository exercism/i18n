# 애널라이저 태그

애널라이저 태그는 풀이가 _어떻게_ 해결되었는지 식별하는 데 사용해요.

이 태그는 다음과 같은 용도로 사용할 수 있어요:

- 풀이를 접근법에 연결하기
- 풀이를 개념에 연결하기
- 특정 태그가 있는 풀이 검색하기

## 형식

태그는 `<category>:<thing>` 형식으로 되어 있는 문자열이에요.

네 가지 범주를 지원하며, 가장 높은 수준에서 가장 낮은 수준 순으로 나열하면 다음과 같아요:

| Category    | Description                                     | Specificity                              | Examples                              |
| ----------- | ----------------------------------------------- | ---------------------------------------- | ------------------------------------- |
| `paradigm`  | [프로그래밍 패러다임][programming-paradigms]    | 매우 높은 수준이며 트랙에 특화되지 않음  | `imperative`, `functional`            |
| `technique` | 사용 중인 기법                                  | 높은 수준이며 대부분 트랙에 특화되지 않음 | `recursion`, `immutability`           |
| `construct` | 언어 구성 요소                                  | 많은 것이 트랙에 특화되지 않음           | `bitwise-and`, `for-loop`             |
| `uses`      | 타입이나 메서드처럼 언어에 특화된 사용법        | 낮은 수준이며 트랙에 특화됨              | `DateTime.add_seconds`, `IEnumerable` |

태그 예시는 다음과 같아요:

- `paradigm:functional`
- `technique:recursion`
- `construct:bitwise-and`
- `uses:DateTime.add_seconds`

## 자주 사용하는 태그

트랙에서 풀이에 자유롭게 태그를 붙일 수 있지만, 가능하면 아래에 나열한 자주 사용하는 태그를 사용하는 것을 권장해요.
공통된 태그 집합을 사용하면 트랙 간 풀이 연결처럼 멋진 기능을 만들 수 있어요.
