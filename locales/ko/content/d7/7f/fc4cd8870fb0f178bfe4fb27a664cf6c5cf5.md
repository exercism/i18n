# 소개

`LocalDate`나 `LocalDateTime` 같은 클래스는 시간의 _한 지점_을 나타내요.
`java.time` 패키지에는 시간의 _양_을 나타내는 클래스도 두 개 있어요.

- `java.time.Period`는 년, 월, 일로 표현하는 시간의 양이에요. "2개월 5일" 같은 형태죠.
- `java.time.Duration`은 시, 분, 초, 밀리초, 나노초로 표현하는 시간의 양이에요. "1시간 30분"처럼요.

`Period`는 달력을 따르기 때문에 날짜나 날짜-시간과 함께 사용해요.
`Duration`은 정확한 시간을 재기 때문에 시간이나 날짜-시간과 함께 사용하고, 날짜와는 함께 쓰지 않아요.

```exercism/note
다른 `java.time` 클래스들처럼 `Period`와 `Duration`은 불변이에요.
이들을 변경하는 것처럼 보이는 메서드는 대신 _새로운_ 인스턴스를 반환해요.
```

## `Period`

`Period`는 정적 팩토리 메서드 중 하나로 만들어요.

```java
Period.ofDays(10);
// => P10D

Period.ofMonths(3);
// => P3M

Period.of(1, 2, 15);
// => P1Y2M15D
```

`toString()`의 결과는 [ISO-8601][iso-8601-durations] 표기법을 따라요. `P`("period"의 머리글자) 뒤에 년(`Y`), 월(`M`), 일(`D`)의 개수가 이어지는 형식이에요.

`Period`는 날짜에 더하거나 뺄 수 있어요.

```java
LocalDate date = LocalDate.of(2024, 3, 10);

date.plus(Period.ofMonths(2));
// => 2024-05-10

date.minus(Period.ofDays(10));
// => 2024-02-29
```

월마다 길이가 다르기 때문에, 월을 더하면 존재하지 않는 날짜가 될 수도 있어요.
그럴 때는 결과를 그 달의 마지막 유효한 날로 옮겨요.

```java
LocalDate.of(2025, 1, 31).plus(Period.ofMonths(1));
// => 2025-02-28
```

`Period.between()`은 한 날짜(포함)부터 다른 날짜(제외)까지의 기간을 반환해요.

```java
LocalDate start = LocalDate.of(2023, 3, 10);
LocalDate end = LocalDate.of(2024, 5, 25);

Period period = Period.between(start, end);
// => P1Y2M15D

period.getYears();
// => 1
period.getMonths();
// => 2
period.getDays();
// => 15
```

## `ChronoUnit`으로 단위 세기

`Period`는 년, 월, 일을 각각 따로 보관해요.
그래서 `getDays()`는 기간 중 일 _부분_만 반환할 뿐, 총 일수를 반환하지는 않아요.
두 날짜 사이에서 한 단위의 총 개수를 세려면 [`java.time.temporal.ChronoUnit`][chronounit-docs]의 `between()` 메서드를 사용해요.

```java
LocalDate start = LocalDate.of(2024, 1, 15);
LocalDate end = LocalDate.of(2024, 3, 20);

Period.between(start, end);
// => P2M5D

Period.between(start, end).getDays();
// => 5

ChronoUnit.DAYS.between(start, end);
// => 65
```

두 번째 날짜가 첫 번째 날짜보다 이르면 결과는 음수가 돼요.

```java
ChronoUnit.DAYS.between(end, start);
// => -65
```

## `Duration`

`Duration`도 정적 팩토리 메서드로 만들어요.

```java
Duration.ofMinutes(90);
// => PT1H30M

Duration.ofHours(2).plusMinutes(15);
// => PT2H15M
```

ISO-8601 표기법에서 `T`는 날짜 부분과 시간 부분을 구분해요. 그래서 `Duration`은 `PT...` 형태로 표기해요.

`Duration`은 날짜-시간에 더하거나 뺄 수 있어요.

```java
LocalDateTime start = LocalDateTime.of(2024, 3, 10, 22, 30);

start.plus(Duration.ofMinutes(90));
// => 2024-03-11T00:00
```

`Duration.between()`은 두 날짜-시간 사이의 정확한 시간을 반환해요.

```java
LocalDateTime checkIn = LocalDateTime.of(2024, 3, 10, 18, 5);
LocalDateTime checkOut = LocalDateTime.of(2024, 3, 10, 19, 40);

Duration.between(checkIn, checkOut);
// => PT1H35M
```

`Duration`은 `toHours()`, `toMinutes()`, `toSeconds()` 같은 메서드로 하나의 단위로 변환할 수 있어요.
이 메서드들은 그 단위로 환산한 _총량_을 내림해서 반환해요.

```java
Duration duration = Duration.ofMinutes(95);

duration.toHours();
// => 1
duration.toMinutes();
// => 95
```

시계처럼 `Duration`을 각 부분으로 나누고 싶다면, 대신 `toXxxPart()` 메서드를 사용해요.

```java
Duration duration = Duration.ofMinutes(95);

duration.toHoursPart();
// => 1
duration.toMinutesPart();
// => 35
```
