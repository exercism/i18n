# 지침

Sarah는 새로운 롤플레잉 게임을 만들고 있는데, 플레이어 메커니즘을 구현하는 데 도움이 필요해요.

## 1. `player` 튜플 정의하기

네 개의 슬롯과 기본값을 가진 튜플 클래스 `player`를 정의해요.

| 슬롯     | 기본값  |
| -------- | ------- |
| `name`   | `f`     |
| `level`  | `0`     |
| `health` | `100`   |
| `mana`   | `f`     |

한 번 정의하고 나면, 다음과 같이 리터럴로 플레이어를 만들 수 있어요.

```factor
T{ player { name "Merlin" } { level 5 } } .
! => T{ player { name "Merlin" } { level 5 } }
```

## 2. 플레이어 소개하기

플레이어의 이름을 반환하는 `introduce`를 정의해요. 은신 중인 플레이어는 이름을 숨기는데(`name`이 `f`), 이런 플레이어는 `"Mighty Magician"`으로 소개해야 해요.

```factor
T{ player { name "Merlin" } } introduce .
! => "Merlin"

T{ player { health 8 } } introduce .
! => "Mighty Magician"
```

## 3. 쓰러진 플레이어 되살리기

플레이어의 `health`가 `0`일 때만, `health`를 100으로, `mana`를 100으로 설정한 *새로운* 플레이어를 반환하는 `revive`를 정의해요. 플레이어가 아직 살아 있다면 `f`를 반환해요.

```factor
T{ player { name "Merlin" } { health 0 } } revive .
! => T{ player { name "Merlin" } { health 100 } { mana 100 } }

T{ player { health 50 } } revive .
! => f
```

## 4. 피해 입기

주어진 양만큼 `health`가 줄어든 *새로운* 플레이어를 반환하는 `take-damage`를 정의해요. `health`는 `0` 아래로 내려가지 않아요.

```factor
T{ player { health 100 } } 30 take-damage .
! => T{ player { health 70 } }

T{ player { health 5 } } 30 take-damage .
! => T{ player { health 0 } }
```
