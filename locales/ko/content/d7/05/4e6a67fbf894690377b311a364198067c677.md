# 소개

다른 언어의 용어를 빌리자면, JSON **객체**는 "해시", "맵", 또는 "딕셔너리"예요.

JSON은 _객체_를 이렇게 정의해요.

> 객체는 **이름**/**값** 쌍의 순서 없는 집합이에요.
> 객체는 `{` 왼쪽 중괄호로 시작해서 `}` 오른쪽 중괄호로 끝나요.
> 각 _이름_ 뒤에는 `:` 콜론이 오고, _이름/값_ 쌍은 `,` 쉼표로 구분해요.

_이름_은 **반드시 문자열이어야 해요**.
_이름_을 달리 부르면 _키_예요.

_값_은 어떤 JSON 타입이든 될 수 있어요.
아래 예시처럼 같은 객체 안의 서로 다른 _값_이 각기 다른 타입일 수도 있고요.

<!-- prettier-ignore -->
```json
{
  "name": "Jane",
  "age": 42,
  "pets": ["cat", "fish"],
  "address": {"street": "123 Main St", "city": "Springfield"}
}
```

<!-- prettier-ignore-end -->

_마지막_ 키-값 쌍 뒤에는 쉼표가 **있으면 안 돼요**.

## 객체 만들기

이름/값 쌍을 모으려면 중괄호를 사용해요.
이름은 문자열이어야 하지만, 이름이 **식별자와 같은 형태**라면(영숫자와 밑줄로 이루어지고 숫자로 시작하지 않는 경우) 따옴표로 묶을 필요는 없어요.

```jq
{name: "Jane", age: 42}
```

_식별자와 같은 형태_가 아닌 키를 사용해도 괜찮아요.
그냥 따옴표로 묶으면 돼요.

```jq
{"first name": "Jane", "last name": "Lopez", age: 42}
```

이름이 표현식의 결과라면, 그 표현식은 **반드시** 괄호 안에 있어야 해요.

```sh
$ echo "Jane" | jq -Rc '{.: 42}'
# verbose error message ...

$ echo "Jane" | jq -Rc '{(.): 42}'
{"Jane":42}
```

## 인덱싱

값은 **점 표기법**으로 객체에서 가져와요.

```jq
{name: "Jane", age: 42} | .age    # => 42
```

키를 식별자로 참조할 수 없다면 **대괄호 표기법**을 사용해요.

```jq
"name" as $key | {name: "Jane", age: 42} | .$key    # => error
"name" as $key | {name: "Jane", age: 42} | .[$key]  # => "Jane"
```

## 키-값 쌍 추가하거나 바꾸기

객체에 새로운 키-값 쌍을 추가하거나 기존 키의 값을 바꾸려면, 왼쪽에 인덱스 표현식을 두고 `=` 할당 연산자를 사용해요.

```jq
{name: "Jane", age: 42} | .sport = "tennis" | .age = 21
# => {
#      "name": "Jane",
#      "age": 21,
#      "sport": "tennis"
#    }
```

`+` 연산자는 객체를 _병합_해요.

```jq
{Richard: 54} + {Jane: 42}
# => {
#      "Richard": 54,
#      "Jane": 42
#    }
```

## 키 삭제하기

키를 삭제하려면 `del` 함수를 사용해요.
갱신된 객체를 반환해요.

```jq
{name: "Jane", age: 42} | del(.age)   # => {"name": "Jane"}
```

`del`의 매개변수는 객체의 키로 이어지는 **인덱스 표현식**(점 또는 대괄호 표기법을 사용)이에요.
`jq`에서는 이것을 **경로 표현식**이라고 불러요.
문자열을 그냥 넘기는 것으로는 충분하지 않아요.

```jq
{name: "Jane", age: 42} | del(name)        # error: name/0 is not defined
{name: "Jane", age: 42} | del("name")      # error: Invalid path expression with result "name"
{name: "Jane", age: 42} | del(.name)       # OK
{name: "Jane", age: 42} | del(.["name"])   # OK
```

## 키 포함 여부

- 객체에 키가 있는지 확인하려면 `has` 함수를 사용해요.

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ($example | has("name")),    # => true
    ($example | has("sport"))    # => false
  ```

- `in`으로 키가 객체에 있는지 확인해요.

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ("name"  | in($example)),    # => true
    ("sport" | in($example))     # => false
  ```

## 모든 키 나열하기

`keys` 함수로 모든 키의 목록을 출력해요.

```jq
{name: "Jane", age: 42} | keys   # => ["age", "name"]
```

`keys`는 키를 _정렬_한다는 점에 주의해요.
원래 순서대로 키를 가져오려면 `keys_unsorted`를 사용해요.

모든 _값_을 나열하는 그에 상응하는 함수는 없어요.
하지만 `.[]` 필터는 객체의 값들을 _스트림_으로 출력하고, 그 스트림은 `[...]` 배열 생성자로 담을 수 있어요.

```jq
[{first: "Jane", last: "Lopez", status: "awesome!"} | .[]]
# => ["Jane", "Lopez", "awesome!"]
```

## 반복하기

- `map_values(filter)` 함수는 객체의 각 _값_에 필터를 적용해요.

  ```jq
  {first: "Jane", last: "Lopez", status: "awesome!"}
  | map_values(ascii_upcase)
  # => {"first": "JANE", "last": "LOPEZ", "status": "AWESOME!"}
  ```

- 객체를 반복하려면 먼저 키-값 객체의 배열로 변환해야 해요.
  `to_entries` 함수가 그 역할을 해요.

  ```jq
  {name: "Jane", age: 42} | to_entries'
  # => [
  #      {
  #        "key": "name",
  #        "value": "Jane"
  #      },
  #      {
  #        "key": "age",
  #        "value": 42
  #      }
  #    ]
  ```

  이 시점부터는 `map`처럼 배열 반복 함수를 사용할 수 있어요.

- `from_entries` 함수는 그 반대로, 키-값 객체의 배열을 객체로 변환해요.

  ```jq
  [
    {"key":"name", "value":"Jane"},
    {"key":"age", "value":42}
  ] | from_entries                  # =>{"name": "Jane", "age": 42}
  ```

- 객체의 _각_ 키-값 쌍에 필터를 적용하려면 `with_entries(filter)` 함수를 사용해요.

  예를 들어 이름을 나이에 대응시키는 객체가 있다면, 다음과 같이 키와 값을 서로 바꿀 수 있어요.

  ```jq
  {"Jane": 42, "Richard": 54}
  | with_entries({key: (.value | tostring), value: .key})
  ```

  다음과 같이 출력해요.

  ```json
  {
    "42": "Jane",
    "54": "Richard"
  }
  ```

  `with_entries(filter)`는 다음 코드와 같아요.

  ```jq
  to_entries | map(filter) | from_entries
  ```
