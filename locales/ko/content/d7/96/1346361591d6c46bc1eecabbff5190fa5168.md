# 소개

## 함수 내보내기

함수 내보내기는 첫 번째 개념에서 다뤘어요. 여기서 간단히 복습해볼까요.

Elm의 각 파일은 모듈이고, 다른 모든 코드보다 앞에 `module` 문이 있어야 해요.

모듈 이름은 파일 이름과 일치해야 해요. 그래서 `Calculator` 모듈은 Calculator.elm 파일에 있어야 하고, `Parser.Utils` 모듈은 Parser/Utils.elm 파일에 있어야 해요.

모듈 안에서 정의한 것은 무엇이든 그 모듈 안에서만 쓸 수 있고, `exposing`에 나열하지 않는 한 이 모듈 밖에서는 접근할 수 없어요.

```elm
-- Calculator.elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Calculator.elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## 다른 모듈에서 함수 가져오기

다른 모듈에 정의된 함수는 import를 통해 접근해요.
모듈을 import하면 그 모듈이 공개한 함수는 모두 접근할 수 있게 돼요.
하지만 어떻게 접근하는지는 모듈을 import하는 방식에 따라 달라요.

qualified import가 기본이고, 그런 모듈 안의 함수(예를 들어 `List` 모듈의 `map` 함수)에 접근할 때는 모듈 이름을 앞에 붙여요(`List.map`).

open import를 쓰면 그 모듈이 공개한 함수에 접두어 없이 바로 접근할 수 있어요. 내보내기에서 쓴 것과 대칭으로, `exposing` 키워드로 해요. 사용할 수 있는 함수를 전부 공개하거나(`..`), 특정 함수만 공개할 수 있어요(예를 들어 `map`).

다른 모듈에서 타입과 그 생성자도 import할 수 있는데, 이건 나중 개념에서 다뤄요.

명확성을 높이고 이름 충돌을 피하기 위해 qualified import를 권장해요.

```elm
-- qualified imports
import List                            -- List.map, List.foldl
import List as L                       -- L.map, L.foldl

-- open imports
import List exposing (..)              -- map, foldl, concat, ...
import List exposing ( map, foldl )    -- map, foldl, List.concat
```

https://elm-lang.org/docs/syntax#modules

## 타입 애너테이션

타입 애너테이션은 `name : parameter types -> return type` 형태로 정의하고, 매개변수 타입도 `->`로 구분해요.

```elm
add : Int -> Int -> Int
add number1 number2 = number1 + number2
```

괄호를 써서 함수 매개변수를 정의할 수 있어요(매개변수 자체가 같은 문법으로 정의되기 때문에 괄호가 필요해요).

```elm
-- Transform every character in a string
map : (Char -> Char) -> String -> String
map charMapperFunction string =
    -- ...
```

https://elm-lang.org/docs/syntax#type-annotations

## 숫자

Elm에서 쓸 수 있는 숫자는 `Int`와 `Float` 두 가지 타입이 있어요.
`Int`는 양의 정수와 음의 정수의 집합에 해당해요.
`Float`는 실수의 집합에 해당하고, 컴퓨터의 정밀도에 따라 한계가 있어요.
숫자에 정의된 연산은 보통 두 타입 중 하나에서만 동작하고, 둘을 섞어서는 쓸 수 없어요.
둘 사이를 변환하는 함수도 있어요. `toFloat`는 `Int`를 `Float`로 바꾸고, `round`, `floor`, `ceiling`, `truncate`는 각기 다른 방식으로 `Float`를 `Int`로 바꿔요.

https://package.elm-lang.org/packages/elm/core/latest/Basics#Int

## 문자열 연산

코드에서 단어와 문장을 표현하려면 Elm에 내장된 `String` 타입을 써요.
문자열 리터럴은 `"Hello World!"`처럼 큰따옴표 사이에 써요.
문자열 연결 연산자 `++`와 동등 비교 연산자 `==`는 기본으로 제공돼요.

```elm
hello : String -> String
hello subject = "Hello " ++ subject

hello "World!" --> "Hello World!"
```

나머지 문자열 함수는 대부분 `String` 모듈에 있고, 이 모듈은 import해야 해요.

https://package.elm-lang.org/packages/elm/core/latest/String
