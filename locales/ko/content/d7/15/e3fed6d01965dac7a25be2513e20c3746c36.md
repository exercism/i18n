# 설치

Crystal은 Linux, macOS, Windows에서 사용할 수 있어요.

다만 짚고 넘어갈 점이 있어요. Crystal의 Windows 지원은 실험적이에요. 즉, 제대로 동작하지 않는 예외적인 경우가 있을 수 있고, 프로덕션 용도로는 적합하지 않을 수 있어요. 그래도 Exercism과 기본적인 사용에는 네이티브 Windows도 대부분 문제없이 쓸 수 있어요.

Windows 개발에서 미리 보기 버전이 아닌 환경을 원한다면, [WSL(Linux용 Windows 하위 시스템)][wsl] 사용을 권장해요. 이 기능은 Windows 10(1903 이상)과 11에서 제공되는 **무료** 기능으로, 가상 머신 없이 Linux 환경을 실행할 수 있게 해줘요.

Crystal 설치 방법은 [설치 안내][installation guides] 중 하나를 참고해요.

[wsl]: https://learn.microsoft.com/en-us/windows/wsl/install
[installation guides]: https://crystal-lang.org/install/
