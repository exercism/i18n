# 안내 추가

## 힌트

이 연습 문제는 [`Exception`][exception-docs]을 던져야 하는 테스트가 나오는 첫 번째 문제예요. `Exception`은 보통 프로그램이 예상치 못한 입력이나 상태를 만났다는 것을 알리기 위해 던져요.

트랙 전반의 테스트는 던진 예외가 다음과 같은지 확인해요:

1. 지정된 Java 타입의 인스턴스;
2. (선택 사항) 지정된 메시지로 초기화된 것.

[exception-docs]: https://docs.oracle.com/javase/8/docs/api/java/lang/Exception.html
