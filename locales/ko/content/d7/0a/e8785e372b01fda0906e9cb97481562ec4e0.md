# 지침

Blorkemon™️ 카드에 대한 향수가 좀처럼 가라앉지 않네요. 심지어 다시 카드를 모으기 시작했고, 친구들까지 함께 끌어들이고 있어요.

이 연습 문제에서 `Card` 컬렉션은 `Set Card`로 표현돼요. 존재하는 모든 카드를 모으는 것이 목표일 때는 중복된 카드가 중요하지 않기 때문이죠.

## 1. 컬렉션 시작하기

친구들도 Blorkemon™️ 열풍에 빠지게 하고 싶은 마음이 크죠? 가장 좋은 방법은 카드 한 장을 선물해서 친구의 컬렉션을 시작해 주는 거예요.

카드 한 장을 컬렉션으로 바꿔 주는 `newCollection`을 구현해요.

```elm
newCollection "Newthree"
    --> Set.fromList ["Newthree"]
```

## 2. 컬렉션 키우기

컬렉션을 한 번 만들면 컬렉션은 자기만의 생명력을 얻고, 계속 커져야 해요.

`Card`와 컬렉션을 받아서 두 값이 담긴 `Tuple`을 반환하는 `addCard`를 구현해요. 첫 번째는 `Card`가 컬렉션에 이미 있었는지를 나타내는 `Bool`이고, 두 번째는 카드가 추가된 컬렉션이에요.

```elm
addCard "Scientuna" (Set.fromList ["Newthree"])
    --> (False, Set.fromList ["Newthree", "Scientuna"])
```

## 3. 교환 시작하기

친구들이 다시 Blorkemon™️에 푹 빠졌으니, 이제 카드를 교환해서 자기 컬렉션을 키울 수 있어요.

모든 교환이 할 가치가 있는 것도 아니고, 아예 할 수 없는 교환도 있어요.
가지고 있지 않은 카드는 교환할 수 없고, 이미 가지고 있는 카드와 교환해서도 안 돼요.

교환할 두 카드(내 카드와 상대 카드)와 현재 컬렉션을 받는 `tradeCard`를 구현해요.
반환 값은 두 값이 담긴 `Tuple`이에요. 교환이 가능하고 할 가치가 있는지를 나타내는 `Bool`과, 실제로는 불가능하더라도 교환을 했다면 최종적으로 갖게 될 컬렉션이에요.

```elm
tradeCard "Scientuna" "Newthree" (Set.fromList ["Scientuna"])
    --> (True, Set.fromList ["Newthree"])
```

## 4. 같은 카드는 하나씩만

벼룩시장에서 오래된 카드 더미를 발견했어요.
목록을 컬렉션과 비교하려면 카드를 정렬하고 중복을 제거해야 해요.

카드 목록을 정렬해서, 중복이 제거된 정렬된 카드 목록을 반환하는 `removeDuplicates`를 구현해요.

```elm
removeDuplicates ["Newthree", "Newthree", "Newthree", "Scientuna"]
    --> ["Newthree", "Scientuna"]
```

## 5. 상대가 가지고 있지 않은 카드

이제 자기 컬렉션에 뿌듯해할 시간이에요.

내 컬렉션과 다른 컬렉션을 받아서, 다른 컬렉션에 없는 카드의 개수를 반환하는 `extraCards`를 구현해요.

```elm
extraCards (Set.fromList ["Scientuna"]) (Set.fromList ["Newthree", "Scientuna"])
    --> 0
```

## 6. 모두가 가지고 있는 카드

Blorkemon™️에 열광하는 친구들과 모여서 어떤 카드가 가장 흔한지 궁금해해요.

컬렉션 목록을 받아서, 모든 컬렉션이 가지고 있는 카드를 정렬한 목록을 반환하는 `boringCards`를 구현해요.

```elm
boringCards [Set.fromList ["Scientuna"], Set.fromList ["Newthree", "Scientuna"]]
    --> ["Scientuna"]
```

## 7. 모든 카드

나와 친구들이 힘을 합치면 모든 Blorkemon™️ 카드를 가지고 있을까요?

컬렉션 목록을 받아서, 모든 컬렉션에 있는 서로 다른 카드의 총개수를 반환하는 `totalCards`를 구현해요.

```elm
totalCards [Set.fromList ["Scientuna"], Set.fromList ["Newthree", "Scientuna"]]
    --> 2
```

## 8. 반짝이는 카드의 승리

조카가 곧 놀러 온다고 해서, 한번 멋진 모습을 보여주고 싶어요.
아이들은 반짝이는 걸 좋아하잖아요?
Blorkemon™️ 카드도 반짝일 수 있어요!

컬렉션을 받아서 정렬된 카드 목록 두 개가 담긴 `Tuple`을 반환하는 `splitShinyCards`를 구현해요. 하나는 `"Shiny"`로 시작하는 모든 카드, 다른 하나는 나머지 카드예요.

```elm
splitShinyCards (Set.fromList ["Newthree", "Scientuna", "Shiny Scientuna"])
    --> (["Shiny Scientuna"], ["Newthree", "Scientuna"])
```
