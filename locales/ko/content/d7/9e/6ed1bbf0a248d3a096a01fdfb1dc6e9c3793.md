# 지침

이 연습 문제에서는 1980년대를 대표하는 클래식 아케이드 게임인 [Pac-Man][Pac-Man]의 규칙 몇 가지를 구현해야 해요.

게임 상태와 관련된 네 가지 규칙을 구현해요.

> _인자가 어떻게 만들어지는지는 걱정하지 말고, 인자들을 조합해 원하는 결과를 반환하는 데만 집중해요._

## 1. Pac-Man이 유령을 먹는지 정의하기

`eat_ghost()` 함수는 두 개의 매개변수(_Pac-Man이 파워 펠릿을 활성화했는지_ 와 _Pac-Man이 유령에 닿아 있는지_)를 받아서, Pac-Man이 유령을 먹을 수 있는지를 나타내는 불리언 값을 반환해요.
 이 함수는 Pac-Man이 파워 펠릿을 활성화한 상태에서 유령에 닿아 있을 때만 `True`를 반환해야 해요.

```python
>>> eat_ghost(False, True)
...
False
```

## 2. Pac-Man이 점수를 얻는지 정의하기

`score()` 함수는 두 개의 매개변수(_Pac-Man이 파워 펠릿에 닿아 있는지_ 와 _Pac-Man이 점에 닿아 있는지_)를 받아서, Pac-Man이 점수를 얻었는지를 나타내는 불리언 값을 반환해요.
 이 함수는 Pac-Man이 파워 펠릿이나 점에 닿아 있으면 `True`를 반환해야 해요.

```python
>>> score(True, True)
...
True
```

## 3. Pac-Man이 지는지 정의하기

`lose()` 함수는 두 개의 매개변수(_Pac-Man이 파워 펠릿을 활성화했는지_ 와 _Pac-Man이 유령에 닿아 있는지_)를 받아서, Pac-Man이 지는지를 나타내는 불리언 값을 반환해요.
 이 함수는 Pac-Man이 유령에 닿아 있고 파워 펠릿을 활성화하지 않았다면 `True`를 반환해야 해요.

```python
>>> lose(False, True)
...
True
```

## 4. Pac-Man이 이기는지 정의하기

`win()` 함수는 세 개의 매개변수(_Pac-Man이 점을 모두 먹었는지_, _Pac-Man이 파워 펠릿을 활성화했는지_, 그리고 _Pac-Man이 유령에 닿아 있는지_)를 받아서, Pac-Man이 이기는지를 나타내는 불리언 값을 반환해요.
 이 함수는 Pac-Man이 점을 모두 먹었고 3번에서 정의한 규칙에 따라 지지 않았다면 `True`를 반환해야 해요.

```python
>>> win(False, True, False)
...
False
```
