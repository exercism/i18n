# 소개

Cairo의 타입 변환을 사용하면 데이터를 한 타입에서 다른 타입으로 바꿀 수 있어요. 덕분에 유연하고 안전하게 데이터를 다룰 수 있죠.

## 기초

Cairo는 타입 변환을 위한 여러 가지 방법을 제공해요.

### 직접 캐스팅

호환되는 숫자 타입끼리는 직접 캐스팅을 사용할 수 있어요.

```rust
let small_number: u8 = 42;
let big_number: u32 = small_number.into();
```

### `Into` 트레이트

`Into` 트레이트는 한 타입에서 다른 타입으로 변환할 수 있게 해줘요.

```rust
let value: u16 = 100;
let converted: u32 = value.into();
```

### `TryInto` 트레이트

실패할 수도 있는 변환에는 `Option`을 반환하는 `TryInto`를 사용해요.

```rust
let large_value: u32 = 70000;
let small_value: Option<u16> = large_value.try_into();

match small_value {
    Option::Some(v) => println!("Converted: {}", v),
    Option::None => println!("Conversion failed"),
}
```

## 사용자 정의 타입 변환

직접 만든 타입에도 `Into`를 구현할 수 있어요.

```rust
#[derive(Drop)]
struct Celsius {
    value: i32,
}

#[derive(Drop)]
struct Fahrenheit {
    value: i32,
}

impl CelsiusIntoFahrenheit of Into<Celsius, Fahrenheit> {
    fn into(self: Celsius) -> Fahrenheit {
        Fahrenheit { value: (self.value * 9) / 5 + 32 }
    }
}
```

## 안전성 고려 사항

- 변환이 실패할 수 있을 때는 `TryInto`를 사용해요 (예: 큰 타입에서 작은 타입으로)
- 변환이 항상 성공할 때는 `Into`를 사용해요
- `TryInto`가 반환하는 `Option::None`인 경우를 항상 처리해요
- 부호 있는 타입과 부호 없는 타입 사이를 변환할 때는 오버플로와 언더플로를 고려해요
