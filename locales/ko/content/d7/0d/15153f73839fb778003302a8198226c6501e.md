# Python 설치하기

시스템에 Python이 아직 설치되어 있지 않다면, 플랫폼별 자세한 안내는 공식 문서의 [Python Setup and Usage][using python] 섹션에서 찾을 수 있어요.
Real Python에서도 iOS와 Android를 비롯한 여러 플랫폼에서의 설치 방법을 다룬 [유용한 가이드][helpful guide]를 제공해요.

마지막으로, Brett Cannon이 쓴 [A quick-and-dirty guide][quick-and-dirty]와 [Why you should use `python -m pip`][python-m-pip] 두 글에는 Python 설치와 패키지를 관리하는 방법에 관한 아주 유용한 조언이 담겨 있어요.

**MacOS 사용자 참고:** MacOS Monterey(12.3) 이전에는 운영체제에 `Python 2.7`이 미리 설치되어 있었어요.
Exercism이나 대부분의 다른 프로그램에서 `Python 2.7`을 사용하는 것은 지원되지 않아요.
대신 아래에 자세히 설명된 방법 중 하나로 [Python 3][Python-three downloads]을 설치해야 해요.
MacOS Monterey(12.3)부터는 MacOS에 어떤 Python 버전도 미리 설치되어 있지 않아요.

운영체제별로 문서를 바로 볼 수 있는 링크를 모아봤어요:

-  [Windows][windows] 참고로, [installing Python on windows][python-on-windows]라는 Microsoft 문서도 도움이 돼요.
-  [Unix & Linux Systems][unix-and-linux] (_대부분 MacOS에도 적용돼요_)
-  [MacOS][macos]

   또한 Real Python의 [Installing Python][installing-python] 문서나 위에 링크한 Brett Cannon의 글에서 소개하는 방법들도 한번 살펴보는 걸 추천해요.


Exercism의 테스트와 툴링은 현재 `3.10` - `3.13.5` (_테스트_)와 [`Python 3.13.5`][313-new-features] (_툴링_)를 지원해요.
이 지원 범위의 예외는 해당하는 곳에 표시되어 있어요.
대부분의 연습 문제는 `Python 3.6+`는 물론 그보다 이전 버전에서도 작동해요.
하지만 [Active Python Releases][active-python-releases]에 나열되지 않은 버전은 지원을 보장하지 않아요.


현재 지원되는 내용은 [Python 3.13.x documentation][3.13 docs]을 참고해요.
