# 힌트

## 일반

- [정수 값][integers]은 연속된 숫자 하나 이상으로 정의할 수 있어요.

## 1. 오븐 예상 시간을 분 단위로 정의하기

- 인자 없이 [메서드][methods]를 정의해야 해요.
- [정수][integers]를 반환해야 해요.

## 2. 남은 오븐 시간을 분 단위로 계산하기

- 매개변수 하나를 가진 [메서드][methods]를 정의해야 해요.
- 메서드에서 [정수를 명시적으로 반환][return]해야 해요.
- 메서드의 매개변수는 [정수][integers]예요.
- [뺄셈 수학 연산자][operators]를 사용해 값을 뺄 수 있어요.

## 3. 준비 시간을 분 단위로 계산하기

- 매개변수 하나를 가진 [메서드][methods]를 정의해야 해요.
- 메서드에서 [정수를 명시적으로 반환][return]해야 해요.
- 메서드의 매개변수는 [정수][integers]예요.
- [곱셈 수학 연산자][operators]를 사용해 값을 곱할 수 있어요.

## 4. 경과 시간을 분 단위로 계산하기

- 매개변수 두 개를 가진 [메서드][methods]를 정의해야 해요.
- 메서드에서 [정수를 명시적으로 반환][return]해야 해요.
- 메서드의 매개변수는 [정수][integers]예요.
- 앞서 정의한 다른 메서드 중 하나를 [호출][invocation]할 수 있어요.
- [덧셈 수학 연산자][operators]를 사용해 값을 더할 수 있어요.
