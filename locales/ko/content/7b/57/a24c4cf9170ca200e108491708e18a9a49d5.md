# 지시 사항

폐하께서는 [칼마르 연합][kalmar_union]의 수도 코펜하겐에서 만찬을 열어요.
올해 가장 큰 파티이고, 모든 귀족이 초대되었어요.
그런데 폐하를 독살하려는 음모가 있다는 소문이 나라 전역에 퍼지고 있어요.

폐하께서는 왕실의 독 감별사인 여러분에게 음식이나 음료에 독이 들었는지 알아봐 달라고 부탁하셨어요.
폐하께서는 음식으로는 **Mushroom pasties**만 내놓을 예정이지만, 음료는 여러 종류를 준비하고 있어요.

## 1. 음식이 맞는지 확인해요

폐하께서 주문하신 음식이 아니면 독이 들었을 가능성이 높아요.
폐하께서 주문하신 음식이 아니면 버려야 해요.

`food`라는 인자를 받아 음식의 이름을 `String`으로 담는 `check_food?` 메서드를 구현해요.
메서드는 음식이 `Mushroom pasties`이면 그 음식을 반환하고, 그렇지 않으면 `nil`을 반환해야 해요.

```crystal
CastleDinner.check_food?("Mushroom pasties")
# => "Mushroom pasties"

CastleDinner.check_food?("Bread")
# => nil
```

## 2. 음료에 독이 들었는지 확인해요

음료에도 독이 들었을 수 있지만, 그런지 알아내기는 조금 더 어려워요.
이름에 `i`라는 글자가 **없으면** 독이 든 음료예요. 대소문자는 상관없어요.
독이 든 음료는 버려야 해요.

`drink`라는 인자를 받아 음료의 이름을 `String`으로 담는 `check_drink?` 메서드를 구현해요.
메서드는 음료에 독이 들지 않았으면 그 음료를 반환하고, 그렇지 않으면 `nil`을 반환해야 해요.

```crystal
CastleDinner.check_drink?("Apple juice")
# => "Apple juice"

CastleDinner.check_drink?("Tea")
# => nil
```

## 3. 음료를 바꿔요

폐하께서는 손님들이 음식에 독이 들었을까 걱정하게 하고 싶지 않으세요.
따라서 음료에 독이 들었으면 새 음료, 그러니까 **Apple juice**로 바꿔야 해요.

`drink`라는 인자를 받아 음료의 이름을 `String`으로 담는 `replace_drink` 메서드를 구현해요.
메서드는 음료에 독이 들지 않았으면 그 음료를 반환하고, 그렇지 않으면 `"Apple juice"`를 반환해야 해요.

```crystal
CastleDinner.replace_drink("Orange juice")
# => "Orange juice"

CastleDinner.replace_drink("Tea")
# => "Apple juice"
```
