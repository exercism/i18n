# is_를 사용한 def

[comment]: # (매개변수 2개가 필요해요:)
[comment]: # (- expected: 수정된 이름)
[comment]: # (- actual: 학습자가 사용한 잘못된 이름)

Elixir에는 이름을 짓는 고유한 규칙이 있는데, 불리언을 반환하는 [함수](https://hexdocs.pm/elixir/naming-conventions.html#trailing-question-mark-foo)의 이름을 어떻게 지을지도 여기에 포함돼요:

> 불리언을 반환하는 함수는 이름 끝에 물음표를 붙여요.

```elixir
# this is the expected name of functions that return a boolean

%{expected}

# this is the current name

%{actual}
```

가드와, 불리언을 반환하면서 가드에서 쓸 수 있는 일부 내장 함수 및 매크로는 다른 규칙을 따라 이름 앞에 `is_`를 붙여요 (`def is_integer`, `defguard is_foo`, `defmacro is_foo`). 두 규칙을 섞어 쓰면 안 돼요.
