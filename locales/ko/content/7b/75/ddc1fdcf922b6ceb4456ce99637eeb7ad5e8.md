# 튜플

[튜플][tuple]은 불변이며 유한하고 순서가 있는 원소 목록이에요.
튜플은 모든 위치가 고정된 타입을 가져야 해요.
그러면 컴파일러가 각 위치에 어떤 타입이 있는지 알 수 있어요.
튜플에 사용되는 타입은 위치마다 달라도 되지만, 그 타입들은 컴파일 시점에 알려져 있어야 해요.

## 튜플 만들기

튜플 값의 타입을 컴파일 과정에서 해석할 수 있는지에 따라 튜플을 만드는 방법이 달라요.
값이 컴파일 시점에 알려져 있다면 튜플 리터럴 문법으로 튜플을 만들 수 있고, 그렇지 않다면 타입을 명시적으로 선언해야 해요.
또한 값의 타입이 튜플에 지정된 타입과 일치하고, 값의 개수가 지정된 타입의 개수와 일치하는 것도 중요해요.
다음은 튜플 리터럴 문법으로 정의하는 예시예요:

```crystal
tuple = {1, "foo", 'c'} # Tuple(Int32, String, Char)
```

`Tuple` 클래스를 사용해 튜플을 만들 수도 있어요.

```crystal
tuple = Tuple(Int32, String, Char).new(1, "foo", 'c')
```

또는 튜플을 할당할 변수의 타입을 직접 명시할 수도 있어요.

```crystal
tuple : Tuple(Int32, String, Char) = {1, "foo", 'c'}
```

튜플의 타입을 직접 명시하면 특정 위치가 유니언 타입을 갖도록 정의할 수 있어서 유용해요.
즉, 하나의 위치가 여러 타입을 가질 수 있어요.

```crystal
tuple : Tuple(Int32 | String, String, Char) = {1, "foo", 'c'}
```

## 변환

### 배열에서 튜플 만들기

`Tuple` 클래스의 `from` 메서드를 사용해 배열에서 튜플을 만들 수 있어요.
이때는 튜플의 타입을 지정해야 해요.

```crystal
array = [1, "foo", 'c']
tuple = Tuple(Int32, String, Char).from(array)
```

### 배열로 변환

`to_a` 메서드를 사용해 튜플을 배열로 변환할 수 있어요.
결과 배열의 원소 타입은 튜플의 각 필드 타입을 합친 유니언이에요.

```crystal
tuple = {1, "foo", 'c'}
array = tuple.to_a
array # => [1, "foo", 'c']
```

## 원소에 접근하기

배열과 마찬가지로 튜플의 인덱스는 0부터 시작해요. 즉, 첫 번째 원소의 인덱스는 0이에요.
하지만 배열과 달리 각 원소의 타입은 고정되어 있고 컴파일 시점에 알려져 있어요. 따라서 튜플을 인덱싱할 때 원소의 타입은 위치에 따라 정해져요.
튜플의 원소에 접근하려면 `[]` 연산자를 사용하면 돼요.

```crystal
array = [1, "foo", 'c']
array[0]         # => 1
typeof(array[0]) # => Int32 | String | Char

tuple = {1, "foo", 'c'}
tuple[0]         # => 1
typeof(tuple[0]) # => Int32
```

배열에서 원소에 접근할 때와의 또 다른 차이점은, 인덱스를 지정하면 컴파일러가 그 인덱스가 튜플의 범위 안에 있는지 검사한다는 거예요.
즉, 런타임 오류 대신 컴파일 시점 오류가 발생해요.

```crystal
tuple = {1, "foo", 'c'}
tuple[3]
# => Error: index out of bounds for Tuple(Int32, String, Char) (3 not in -3..2)
```

하지만 인덱스가 변수에 저장되어 있다면 컴파일러는 컴파일 시점에 그 인덱스가 튜플의 범위 안에 있는지 검사할 수 없고, 대신 런타임 오류가 발생해요.

## 서브튜플

범위와 함께 `[]` 연산자를 사용하면 튜플의 서브튜플을 얻을 수 있어요.
반환되는 것은 지정한 범위의 원소들로 이루어진 새 튜플이에요.
범위는 컴파일 시점에 주어져야 해요. 그렇지 않으면 컴파일러가 서브튜플에 있는 원소들의 타입을 알 수 없어요.
즉, 범위는 범위 리터럴이어야 하고 변수에 할당되어서는 안 돼요.

```crystal
tuple = {1, "foo", 'c'}
subtuple = tuple[0..1] # Tuple(Int32, String)

i = 0..1
tuple[i]
# Error: Tuple#[](Range) can only be called with range literals known at compile-time
```

## 튜플을 언제 사용할까요

튜플은 값의 타입이 컴파일 시점에 알려져 있는 고정된 개수의 값을 함께 묶고 싶을 때 유용해요.
튜플은 불변이기 때문에 배열보다 메모리를 적게 쓰고 더 빨라요.
또 다른 활용 사례는 메서드에서 여러 값을 반환하는 것이에요.
튜플의 각 위치가 서로 다른 타입을 가질 수 있기 때문에, 값들의 타입이 다를 때 특히 유용해요.

크기가 늘거나 줄어들 수 있거나 자주 수정해야 하는 데이터 구조가 필요할 때는 튜플을 사용하지 않아야 해요.
