# 지침

[암스트롱 수](https://en.wikipedia.org/wiki/Narcissistic_number)는 각 자릿수를 자릿수 개수만큼 거듭제곱한 다음 모두 더한 값이 자기 자신과 같은 수예요.

예를 들어:

- 9는 암스트롱 수예요. 왜냐하면 `9 = 9^1 = 9`이기 때문이에요.
- 10은 암스트롱 수가 *아니에요*. 왜냐하면 `10 != 1^2 + 0^2 = 1`이기 때문이에요.
- 153은 암스트롱 수예요. 왜냐하면 `153 = 1^3 + 5^3 + 3^3 = 1 + 125 + 27 = 153`이기 때문이에요.
- 154는 암스트롱 수가 *아니에요*. 왜냐하면 `154 != 1^3 + 5^3 + 4^3 = 1 + 125 + 64 = 190`이기 때문이에요.
