# 테스트

## 설정

필요한 의존성을 설치하려면 [JavaScript 설치 안내][docs-exercism-javascript]를 따라 해요.

## 요구 사항

연습 문제의 의존성을 설치해요:

```shell
corepack pnpm install
```

`corepack`이 활성화되어 있지 않다고 하면, 다음을 실행해서 활성화할 수 있어요:

```bash
corepack enable pnpm
```

## 테스트 스위트 통과시키기

모든 연습 문제에는 제출하기 전에 풀이를 검증할 수 있도록 테스트 스위트가 함께 제공돼요.
이 테스트는 연습 문제 디렉터리에서 명령 프롬프트를 열고 다음을 실행해서 돌려볼 수 있어요:

```bash
corepack pnpm test
```

일부 테스트 스위트에서는 첫 번째 테스트를 제외한 나머지 테스트가 모두 건너뛰기 처리되어 있어요.

테스트 하나를 통과시키면 `xtest`를 `test`로 바꿔서 다음 테스트를 활성화할 수 있어요.

## 나만의 테스트 작성하기

추가로 직접 테스트를 작성하고 싶다면 새 파일 `custom.spec.js`를 만들어서 풀이와 함께 제출해요:

```shell
exercism submit numbers.js custom.spec.js
```
