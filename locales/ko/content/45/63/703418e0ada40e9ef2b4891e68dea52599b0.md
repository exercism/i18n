# 자세히 알아보기

Elixir에서 열거 가능한 자료 구조(예: 배열, 범위)에서 무작위 원소를 하나 고르려면 [`Enum.random/1`][enum-random]을 사용해요. 이 함수는 원소 하나를 고르며, 모든 원소가 뽑힐 확률이 같아요. 범위에서 무작위 값을 하나 고르는 일은 범위 전체를 순회하지 않고 상수 시간에 실행돼요.

## 무작위 정수와 문자

- 무작위 정수 고르기
  ```elixir
  Enum.random(1..10)
  # => 7
  ```
- 문자열로 무작위 문자 고르기
  ```elixir
  <<Enum.random(?A..?Z)>>
  # => "K"
  ```
- 문자 리스트로 무작위 문자 고르기
  ```elixir
  [Enum.random(?A..?Z)]
  # => ~c"J"
  ```

열거 가능한 자료 구조에서 원소를 둘 이상 고르려면 [`Enum.take_random/2`][enum-take-random]를 사용해요. 열거 가능한 자료 구조를 무작위 순서로 정렬하려면 [`Enum.shuffle/1`][enum-shuffle]을 사용해요.

## 무작위 실수

Elixir에는 무작위 실수를 고르는 자체 함수가 없어요. 그러려면 Erlang의 [`rand`][erl-rand] 모듈을 사용해야 하는데, 이 모듈은 `Enum.random`이 내부적으로 사용하는 모듈이기도 해요.

- 무작위 실수 고르기 (0.0 이상 1.0 미만):

  ```elixir
  :rand.uniform()
  # => 0.275329955448815
  ```

- 무작위 실수 고르기 (`a` 이상 `b` 미만):
  ```elixir
  a = 13
  b = 20
  :rand.uniform() * (b - a) + a
  # => 18.96815556890448
  ```

## 정규 분포

위에서 언급한 모든 함수는 모든 값이 뽑힐 확률이 같은 무작위 값을 골라요. 이를 _균등 분포_라고 해요. `rand` 모듈은 [정규 분포][normal-distribution]를 따르는 무작위 실수를 고르는 [`normal/0`][erl-rand-normal-0]과 [`normal/2`][erl-rand-normal-2] 함수도 제공해요.

## 시드

"무작위" 값은 [_의사_ 난수 생성기][prng]가 만들어 낸다는 점을 이해하는 게 중요해요. 의사 난수 생성기(PRNG)는 _시드_라는 초깃값이 주어지면 무작위처럼 보이지만 전혀 무작위가 아닌 수열을 만들어 내는 알고리즘이에요.

이 사실은 디버깅할 때 유용할 수 있어요. [`:rand.seed/2`][rand-seed-2]로 시드를 재설정하면 Erlang(따라서 Elixir)의 의사 난수 생성기가 같은 수열 값을 만들도록 강제할 수 있어요. 첫 번째 인자는 특정 PRNG 알고리즘이고, 두 번째는 정수 세 개로 이루어진 튜플, 즉 시드예요.

```elixir
:rand.seed(:exsss, {1, 2, 3})
Enum.take_random(100..999, 3)
# => [680, 127, 622]

:rand.seed(:exsss, {1, 2, 3})
Enum.take_random(100..999, 3)
# => [680, 127, 622]
```

## 암호학

`Enum.random`과 Erlang의 `rand` 모듈이 반환하는 무작위 값은 [암호학적으로 안전하지 않아요][cryptographically-secure-rng]. 암호화 키나 비밀번호, 논스를 생성하는 데 사용하면 안 돼요. 이런 용도로는 Erlang의 [`:crypto.strong_rand_bytes/1`][erl-crypto-strong-rand-bytes]을 사용해요.
