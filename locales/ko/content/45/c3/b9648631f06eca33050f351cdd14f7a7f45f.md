# 지침

두 배열이 주어졌을 때, 첫 번째 배열이 두 번째 배열에 포함되는지, 두 번째 배열이 첫 번째 배열에 포함되는지, 두 배열이 서로를 포함하는지, 아니면 어느 것도 아닌지를 판별해요.

구체적으로, 배열 A는 B의 앞에서 원소를 0개 이상 떼어내고 B의 뒤에서 원소를 0개 이상 떼어냈을 때 A와 완전히 같은 배열이 나오면 배열 B의 부분 배열이에요.

예시:

 * A = [1, 2, 3], B = [1, 2, 3, 4, 5]이면 A는 B의 부분 배열이에요
 * A = [3, 4, 5], B = [1, 2, 3, 4, 5]이면 A는 B의 부분 배열이에요
 * A = [3, 4], B = [1, 2, 3, 4, 5]이면 A는 B의 부분 배열이에요
 * A = [1, 2, 3], B = [1, 2, 3]이면 A는 B와 같은 배열이에요
 * A = [1, 2, 3, 4, 5], B = [2, 3, 4]이면 A는 B의 상위 배열이에요
 * A = [1, 2, 4], B = [1, 2, 3, 4, 5]이면 A는 B의 상위 배열도, 부분 배열도, 같은 배열도 아니에요
