# 소개

## 패키지

Go에서는 애플리케이션을 패키지로 구성해요.
패키지는 같은 폴더에 있는 소스 파일들의 모음이에요.
한 폴더에 있는 모든 소스 파일은 파일 맨 위에 같은 패키지 이름을 써야 해요.
관례상 패키지 이름은 패키지가 위치한 폴더와 같게 지어요.

```go
package greeting
```

Go는 다양한 표준 라이브러리 패키지를 제공하는데, `import` 키워드로 프로그램에서 사용할 수 있어요.
표준 라이브러리 패키지는 이름으로 가져와요.

```go
package greeting

import "fmt"
```

가져온 패키지는 패키지 이름으로 접근해요:

```go
world := "World"
fmt.Sprintf("Hello %s", world)
```

Go는 어떤 항목을 다른 패키지의 코드에서 호출할 수 있는지를 그 항목이 어떻게 선언되었는지로 판단해요.
함수, 타입, 변수, 상수, 구조체 필드를 외부에서 볼 수 있게 하려면, 이름이 대문자로 시작해야 해요. 이렇게 외부에 공개하는 것을 _내보내기_라고 해요.

```go
package greeting

// Hello is a public function (callable from other packages).
func Hello(name string) string {
    return "Hello " + name
}

// hello is a private function (not callable from other packages).
func hello(name string) string {
    return "Hello " + name
}
```

## 문자열 포맷팅

Go에는 `fmt`(포맷 패키지)라는 내장 패키지가 있는데, 입력과 출력의 형식을 다루는 다양한 함수를 제공해요.
가장 많이 쓰는 함수는 `Sprintf`로, `%s` 같은 서식 동사를 사용해 값들을 문자열에 끼워 넣고 그 문자열을 반환해요.

```go
import "fmt"

food := "taco"
fmt.Sprintf("Bring me a %s", food)
// Returns: Bring me a taco
```

Go에서는 부동소수점 값을 Sprintf의 서식 동사로 편리하게 포맷할 수 있어요: `%g`(간결한 표현), `%e`(지수), `%f`(지수 없음).
세 동사 모두 필드의 너비와 소수점 위치를 조절할 수 있어요.

```go
import "fmt"

number := 4.3242
fmt.Sprintf("%.2f", number)
// Returns: 4.32
```

사용할 수 있는 서식 동사의 전체 목록은 [포맷 패키지 문서][fmt-docs]에서 확인할 수 있어요.

`fmt`에는 문자열을 다루는 다른 함수들도 있어요. 예를 들어 `Println`은 받은 인자들을 콘솔에 그대로 출력하고, `Printf`는 `Sprintf`와 같은 방식으로 입력을 포맷한 뒤 출력해요.

[fmt-docs]: https://pkg.go.dev/fmt
