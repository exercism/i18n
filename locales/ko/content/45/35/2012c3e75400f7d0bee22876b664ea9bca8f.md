# 타입 선언

PHP는 _동적 타입_ 언어로, 변수에 어떤 타입의 정보든 담을 수 있어요.
PHP에서는 클래스 프로퍼티, 함수 인자, 함수 반환 값에 _선택적_인 강한 타입 선언을 허용해요.
PHP의 강한 타입 선언은 실행 시점에 타입을 검사해요. 하지만 가능하다면 PHP가 스칼라 타입을 선언에 맞게 강제로 변환하려고 시도해요.
이 강제 변환 동작은 파일 맨 위에서 `strict_types` 선언을 사용해 끌 수 있어요.

```php
<?php
declare(strict_types=1);
```

또한 함수가 반환하는 값이 없다는 것을 나타내기 위해 `void` 반환 타입을 지정할 수도 있어요.

```php
<?php
declare(strict_types=1);

class Driver
{
    string $serial_number;

    function setSerialNumber(string $number): void
    {
        $this->serial_number = $number;
    }

    function getSerialNumber(): string
    {
        return $this->serial_number; 
    }
}

$driver = new Driver(); 
$driver->setSerialNumber(1234);
// => This will throw a TypeError with strict_types=1
```

## 타입 유니언

함수 인자나 반환 값, 또는 클래스 프로퍼티가 둘 이상의 타입이 될 수 있다면 타입 유니언을 선언할 수 있어요.

```php
<?php

class IdentityCard
{
    private int|float $id = 0;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

## 혼합 타입

코드를 작성하다 보면 타입을 지정하지 못할 때도 있어요.
PHP 8.0부터는 `mixed`라는 탈출구 타입이 제공돼요.
Mixed는 `object|resource|array|string|float|int|bool|null`의 타입 유니언과 같아요.
