# 소개

Go에서 함수는 일급 값이에요.
즉, 다른 모든 값으로 할 수 있는 것과 똑같은 일을 함수로도 할 수 있어요. 함수를 변수에 할당하고, 다른 함수의 인자로 전달하고, 심지어 다른 함수에서 함수를 반환할 수도 있죠.

아래에서는 `engGreeting`과 `espGreeting` 두 함수를 만들고, 이 함수들을 `greeting` 변수에 할당해요:

```go
import "fmt"

func engGreeting(name string) string {
	return fmt.Sprintf("Hello %s, nice to meet you!", name)
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := engGreeting			// greeting is a variable of type func(string) string
fmt.Println(greeting("Alice"))	// Hello Alice, nice to meet you!

greeting = espGreeting
fmt.Println(greeting("Alice")) 	// ¡Hola Alice, mucho gusto!
```

함수 값을 이용하면 함수를 데이터뿐만 아니라 동작으로도 매개변수화할 수 있어요.
다음 예제에서는 `greetingFunc` 매개변수를 통해 `dialog` 함수에 동작을 전달해요:

```go
func dialog(name string, greetingFunc func(string) string) {
	fmt.Println(greetingFunc(name))
	fmt.Println("I'm a dialog bot.")
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := espGreeting
dialog("Alice", greeting)
// Output:
// ¡Hola Alice, mucho gusto!
// I'm a dialog bot.
```

함수 타입 변수를 초기화하지 않으면 그 값은 `nil`이에요.
따라서 `nil`인 함수 값을 호출하면 패닉이 발생해요.

```go
var dutchGreeting func(string) string
dutchGreeting("Alice") // panic: call of nil function
```

함수 값은 `nil`과 비교할 수 있어요.
이 점은 불필요한 프로그램 패닉을 피하는 데 유용해요.

```go
var dutchGreeting func(string) string
if dutchGreeting != nil {
	dutchGreeting("Alice") // safe to call dutchGreeting
}
```

## 함수 타입

함수 값을 쓸 수 있는 것은 Go의 함수 타입 덕분이에요.
함수 타입은 매개변수 타입의 순서와 결과 타입의 순서가 같은 모든 함수의 집합을 나타내요.
함수 타입을 기반으로 사용자 정의 타입을 선언할 수 있어요.
예를 들어, 앞선 예제의 `dialog` 함수는 다음과 같이 바꿀 수 있어요:

```go
type greetingFunc func(string) string

func dialog(name string, f greetingFunc) {
	fmt.Println(f(name))
	fmt.Println("I'm a dialog bot.")
}
```

## 익명 함수

일급 함수를 지원하기 때문에 쓸 수 있는 또 하나의 강력한 도구가 바로 익명 함수예요.
익명 함수는 사용하는 지점에서 정의하며, `func` 키워드 뒤에 이름이 붙지 않아요.
이런 함수는 자신을 감싸는 함수의 변수에 접근할 수 있어요.

예를 들어:

```go
func fib() func() int {
	var n1, n2 int

	return func() int {
		if n1 == 0 && n2 == 0 {
			n1 = 1
		} else {
			n1, n2 = n2, n1 + n2
		}
		return n2
	}
}

next := fib()
for i := 0; i < N; i++ {
  fmt.Printf("F%d\t= %4d\n", i, next())
}
```

`fib`을 호출하면 변수 `n1`과 `n2`가 선언되고, 이 변수들의 값을 호출할 때마다 바꾸는 익명 함수가 반환돼요.
익명 함수를 N번 호출하면 0부터 시작하는 피보나치 수열의 N번째 수를 반환해요.
익명 내부 함수는 자신을 감싸는 함수 `fib`의 지역 변수(`n1`과 `n2`)에 접근할 수 있어요.
이렇게 하면 함수 값이 호출 사이에도 상태를 유지하게 만들 수 있어요.
이때 익명 함수를 변수 `n1`과 `n2`의 클로저라고 해요.
[클로저][closure]는 프로그래밍에서 널리 쓰이며, 다른 언어에서도 클로저를 지원하는 모습을 볼 수 있어요.

[closure]: https://en.wikipedia.org/wiki/Closure_(computer_programming)
