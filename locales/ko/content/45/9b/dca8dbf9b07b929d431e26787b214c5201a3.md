# 테스트

Factor 트랙은 **Factor 0.101**을 사용해요. 연습 문제마다 `STOP-HERE`와 `TASK:` 파싱 워드, 그리고 테스트 실행기를 정의하는 `exercism-tools` 보캐뷸러리가 함께 들어 있어요. 연습 문제 디렉터리에서 다음을 실행해요:

```
factor -roots=. -run=exercism-tools <exercise>
```

예를 들어 `hello-world` 연습 문제라면 이렇게 해요:

```
factor -roots=. -run=exercism-tools hello-world
```

실행기는 모든 테스트가 통과하면 상태 코드 0으로 종료하고, 테스트가 하나라도 실패하면 진단 출력과 함께 0이 아닌 상태 코드로 종료해요.

## 건너뛴 테스트

연습 문제를 푼다는 것은 그 문제의 모든 테스트를 통과시키는 거예요.
기본적으로 테스트를 실행하면 첫 번째 테스트 하나만 실행돼요.
이건 의도된 동작으로, 그 테스트 하나를 통과시키는 데만 집중할 수 있게 해줘요.

이 동작은 테스트 파일에 있는 `STOP-HERE` 줄이 담당해요. 파싱 시점에 Factor에게 그 아래 내용을 모두 무시하라고 알려주기 때문에, 실행기는 위쪽 테스트만 보게 돼요. 첫 번째 테스트가 통과하면, 두 가지 방법으로 더 많은 테스트를 활성화할 수 있어요:

- **`STOP-HERE` 줄을 삭제하면** 남은 테스트를 한 번에 모두 활성화할 수 있어요.
- **`STOP-HERE` 줄을 더 아래로 옮기면** 테스트를 하나씩, 또는 태스크 하나씩 활성화할 수 있어요. 개념 연습 문제는 테스트를 `TASK:` 표시 아래에 묶어 두는데, 다음 `TASK:` 바로 앞으로 `STOP-HERE`를 옮기는 게 자연스러운 방법이에요.

모든 테스트를 활성화했고 구현이 그 테스트를 모두 통과하면, 연습 문제를 푼 거예요!
