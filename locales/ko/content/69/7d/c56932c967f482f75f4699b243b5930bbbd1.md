# 제어 흐름

`if` 표현식과 루프는 Cairo에서 실행 흐름을 제어해요:
`

- **`if` 표현식**은 조건이 `true`로 평가되는지에 따라 코드를 조건부로 실행해요.
- **루프**는 (`loop`, `while`, `for` 등) 지정된 조건이 참인 동안, 또는 탈출 조건이 충족될 때까지 코드를 반복해서 실행해요.

이런 구조는 Cairo에서 로직과 반복을 구현하는 데 기본이 돼요.

## `if` 표현식

Cairo의 `if` 표현식을 사용하면 조건부 로직에 따라 실행 흐름을 제어할 수 있어요.
`if` 표현식은 불리언 조건이 `true`로 평가되는지 `false`로 평가되는지에 따라 코드가 실행되는 구조를 따라요.

```rust
fn main() {
    let temperature = 30;

    if temperature > 25 {
        println!("It's hot outside!");
    }
}
```

이 예제는 Cairo의 간단한 `if` 블록을 보여줘요.
`temperature > 25`라는 조건이 `true`로 평가될 때만 `"It's hot outside!"`라는 메시지가 출력돼요.
조건이 `false`이면 어떤 코드도 실행되지 않고 프로그램은 계속 진행돼요.

```rust
fn main() {
    let number: u32 = 5;

    if number < 10 {
        println!("The number is less than 10.");
    } else {
        println!("The number is 10 or greater.");
    }
}
```

이 코드를 실행하면 콘솔에 `"The number is less than 10."`이 출력돼요.

### `else if`로 여러 조건 처리하기

`else if` 표현식에서 `if`와 `else`를 조합하면 여러 조건을 다룰 수 있어요.

```rust
fn main() {
    let score: u64 = 85;

    if score >= 90 {
        println!("Grade: A");
    } else if score >= 80 {
        println!("Grade: B");
    } else if score >= 70 {
        println!("Grade: C");
    } else {
        println!("Grade: F");
    }
}
```

이 코드를 실행하면 콘솔에 `"Grade: B"`가 출력돼요.

### `let` 문에서 `if` 사용하기

Cairo의 `if` 표현식은 `let` 문의 오른쪽에 써서 결과를 변수에 할당할 수 있어요.

```rust
fn main() {
    let condition: bool = true;
    let number: felt252 = if condition {
        5
    } else {
        6
    };

    if number == 5 {
        println!("condition was true and number is {}", number);
    }
}
```

## 루프

루프는 코드 블록을 반복할 수 있게 해 주는 기본적인 구조로, 작업을 효율적이고 통제된 방식으로 실행할 수 있게 해요.
루프는 시퀀스를 순회하거나 조건에 따라 코드를 반복 실행할 수 있어요.
Cairo는 세 가지 주요 루프 형태를 제공해요:

- **loop**: `break` 문으로 명시적으로 멈추지 않는 한 끝없이 실행되는 기본 루프예요.
- **while**: 지정된 조건이 `true`인 동안 계속 실행돼요.
  조건이 `false`가 되면 멈춰요.
- **for**: 배열 같은 컬렉션의 요소를 순회하면서 요소마다 코드를 실행해요.

### `loop`로 코드 반복하기

`loop` 키워드는 코드 블록을 영원히, 또는 멈추라고 명시적으로 알릴 때까지 계속해서 반복 실행하라고 Cairo에 알려줘요.

```rust
fn main() {
    loop {
        println!("again!");
    }
}
```

이 코드를 실행하면 프로그램의 가스가 다 떨어지거나 직접 멈출 때까지 콘솔에 `"again!"`이 끝없이 출력돼요.

> 참고: Cairo는 가스 미터를 포함해서 무한 루프가 있는 프로그램이 실행되는 것을 막아요.
> 가스 미터는 프로그램에서 할 수 있는 연산량을 제한하는 장치예요.
> 가스는 명령 하나의 연산 비용을 나타내는 측정 단위예요.
> 가스 미터가 바닥나면 프로그램은 멈춰요.

루프를 빠져나가려면 루프 안에 `break` 키워드를 두어 프로그램이 언제 실행을 멈춰야 하는지 알려줘요.

```rust
fn main() {
    let mut i: usize = 0;
    loop {
        if i > 10 {
            break;
        }
        println!("i = {}", i);
        i += 1;
    }
}
```

`continue` 키워드는 루프의 다음 반복으로 넘어가고 이번 반복에 남은 코드는 건너뛰라고 프로그램에 알려줘요.

```rust
fn main() {
    let mut i: usize = 0;
    loop {
        if i > 10 {
            break;
        }
        if i == 5 {
            i += 1;
            continue;
        }
        println!("i = {}", i);
        i += 1;
    }
}
```

이 프로그램을 실행하면 `i`가 `5`일 때는 `i`의 값이 출력되지 않아요.

#### `loop`에서 값 반환하기

`loop`에서 값을 반환하려면 `break` 키워드 뒤에 반환하려는 값을 붙이면 돼요.
이렇게 하면 `loop`를 빠져나와 결과를 나머지 코드로 넘길 수 있어요.

```rust
fn main() {
    let mut counter = 0;

    let result = loop {
        if counter == 10 {
            break counter * 2;
        }
        counter += 1;
    };

    println!("The result is {}", result); // prints "The result is 20"
}
```

### `while`로 조건부 반복하기

`while`은 조건이 `true`인 동안 코드를 실행하고, 조건이 `false`가 되면 빠져나와요.

```rust
fn main() {
    let mut number = 3;
    while number != 0 {
        println!("{}!", number);
        number -= 1;
    }
    println!("LIFTOFF!!!");
}
```

### `for`로 컬렉션 순회하기

`for`는 컬렉션의 각 항목을 순회하면서 항목마다 코드를 실행해요.

```rust
fn main() {
    let a = [10, 20, 30, 40, 50].span();
    for element in a {
        println!("the value is: {}", element);
    }
}
```
