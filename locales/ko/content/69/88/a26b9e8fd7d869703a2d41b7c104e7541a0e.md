# `for`문 알아보기

[`for`문](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/for.html)은 어떤 조건이 충족될 때까지 문 묶음을 반복해서 실행하는 방법을 제공해요.
루프는 네 부분으로 이루어져 있어요:

```java
for (initialization; test; update) {
    body;
}
```

`initialization`은 루프의 초기 상태를 설정하며, 루프가 시작될 때 딱 한 번 실행돼요.
보통 `test` 식과 `update` 문에서 사용할 변수를 선언하고 값을 할당해요.
예를 들어요:

```java
int i = 1
```

`test` 식은 루프를 끝내야 하는지 검사해요.
true로 평가되면 본문이 실행되고, 이어서 `update` 식이 실행돼요.
false로 평가되면 본문도 `update` 문도 실행되지 않고, 실행은 루프의 닫는 괄호 다음부터 이어져요.
보통 `initialization` 블록에서 할당한 변수를 검사해요.
예를 들어요:

```java
i <= 10
```

루프 본문을 실행한 뒤에는 `update` 식이 실행돼요.
보통 루프 변수를 어떤 값만큼 증가시키거나 감소시켜요.
예를 들어요:

```java
i++
```

처음 네 개의 제곱수를 출력하는 `for`문은 이렇게 생겼어요:

```java
for (int i = 1; i <= 4; i++) {
    System.out.println(i * i);
}

/* =>
1
4
9
16
*/
```

컬렉션의 모든 원소를 순회할 때는 `for-each`문을 쓰는 게 좋지만, `for`문으로도 이렇게 할 수 있어요:

```java
for (int i = 0; i < array.length; i++) {
    System.out.print(array[i]);
}
```

`for`문은 `for-each`문보다 몇 가지 장점이 있어요:

- 원하는 인덱스에서 시작하거나 멈출 수 있어요.
- 원하는 (불리언) 종료 조건을 마음대로 쓸 수 있어요.
- 루프 변수의 증가 방식을 직접 바꿔서 원소를 건너뛸 수 있어요.
- 카운트를 줄여 나가면서 컬렉션을 뒤에서 앞으로 처리할 수 있어요.
- 컬렉션이 필요 없는 상황에서도 `for`문을 쓸 수 있어요.
