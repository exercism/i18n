# 개요

[Pairs and Dicts][pairs-dicts] 개념에서는 Julia의 딕셔너리 타입에 대한 기초를 다뤘어요.

[`Dict`][dict]는 중요하고 자주 쓰이는 컬렉션 타입이라, 이를 다루는 함수도 아주 많아요.

## 항목 가져오기

항목을 가져오는 가장 간단한 방법은 키를 사용하는 거예요(다른 많은 언어에서도 그렇듯이요).
그런데 존재하지 않는 키를 요청하면 `KeyError`가 발생해요.

```julia-repl
julia> d = Dict(i => ('a':'c')[i] for i in 1:3)
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'

julia> d[2]
'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)

# missing key
julia> d[4]
ERROR: KeyError: key 4 not found
```

값을 가져오기 전에 키가 있는지 먼저 확인할 수도 있어요(`haskey(d, 4)`나 `4 ∈ keys(d)` 같은 방법으로요). 하지만 없는 키에 대해서는 그냥 기본값을 받는 게 더 편할 때가 많아요.

이럴 때 쓰는 함수가 [`get()`][get]이고, `Dict`를 직접 바꾸는 변형이 [`get!()`][get-bang]이에요.
이 둘은 없는 키를 `Dict`에 추가하는지 여부가 달라요.

```julia-repl
julia> get(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)

# get() leaves Dict unchanged
julia> d
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'

julia> get!(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)

# get!() adds new key to Dict
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'
```

앞선 개념에서 `delete!()`가 키로 항목을 제거한다는 걸 봤어요.
`pop!()` 함수를 쓰면 여기에 값을 가져오는 것까지 함께 할 수 있어요.

```julia-repl
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'

# popped value is returned
julia> pop!(d, 3)
'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)

# Dict is shrunk
julia> d
Dict{Int64, Char} with 3 entries:
  4 => '!'
  2 => 'b'
  1 => 'a'
```

## 반복

`Dict`를 반복하면 기본적으로 `key => value` 쌍을 내놓아요.
각 요소는 늘 쓰던 `.first`와 `.second` 표기로 접근할 수 있어요.

```julia-repl
# d is from the previous example
julia> [(kv.first, kv.second) for kv in d]
3-element Vector{Tuple{Int64, Char}}:
 (4, '!')
 (2, 'b')
 (1, 'a')
```

키만 쓰고 싶거나 값만 쓰고 싶을 때가 많은데, 이건 간단해요.

```juliajulia> [k for k in keys(d)]
julia> [k for k in keys(d)]
3-element Vector{Int64}:
 4
 2
 1

julia> [v for v in values(d)]
3-element Vector{Char}:
 '!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
```

## 병합

`Dict` 두 개를 합치는 건 유용할 수 있지만, 여러 입력에 같은 키가 있을 때 그 키를 어떻게 할지 분명히 정해야 해요.

[`merge()`][merge]와 [`merge!()`][merge-bang] 함수는 전달받은 `Dict`를 원하는 개수만큼 왼쪽에서 오른쪽 순서로 합쳐요.

이미 있는 키의 값은 그냥 덮어써지기 때문에, 가장 오른쪽에 있는 `Dict`가 "이겨요".

```julia-repl
julia> d3 = Dict("color" => "red", "shape" => "circle")
Dict{String, String} with 2 entries:
  "shape" => "circle"
  "color" => "red"

julia> d4 = Dict("color" => "blue", "coords" => (3, 2))
Dict{String, Any} with 2 entries:
  "color"  => "blue"
  "coords" => (3, 2)

# color from d3 is lost
julia> merge(d3, d4)
Dict{String, Any} with 3 entries:
  "shape"  => "circle"
  "color"  => "blue"
  "coords" => (3, 2)
```

[`mergewith()`][mergewith]와 [`mergewith!()`][mergewith-bang] 함수를 쓰면 첫 번째 인자로 함수를 넘겨서, 중복된 키를 어떻게 병합할지 정할 수 있어요.
덧셈이 간단한 예예요.

```julia-repl
julia> d5 = Dict("color" => "red", "area" => 3)
Dict{String, Any} with 2 entries:
  "area"  => 3
  "color" => "red"

julia> d6 = Dict("shape" => "circle", "area" => 5)
Dict{String, Any} with 2 entries:
  "shape" => "circle"
  "area"  => 5

# area values are added, not overwritten
julia> mergewith(+, d5, d6)
Dict{String, Any} with 3 entries:
  "shape" => "circle"
  "area"  => 8
  "color" => "red"
```

벡터 두 개를 이어 붙이는 것도 병합할 때 자주 쓰는 연산이에요.
이때 Julia는 [`vcat()`][vcat] 함수를 사용하는데, 그 이유는 [`Multi Dimensional Arrays`][multidim] 개념에서 설명해요.

```julia-repl
julia> d7 = Dict("vals" => [1, 2, 3])
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [1, 2, 3]

julia> d8 = Dict("vals" => [4, 5])
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [4, 5]

julia> mergewith(vcat, d7, d8)
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [1, 2, 3, 4, 5]
```

여러 `Set`을 병합할 때는 그에 맞는 [`union`][union] 함수를 사용해요.

`mergewith` 함수들은 [Higher Order Functions][hof]가 실제로 쓰이는 좋은 예라는 점도 눈여겨봐요.
