# 소개

## 네임스페이스

코드를 잘 정리하는 중요한 방법 중 하나는 네임스페이스를 사용하는 거예요.
두 함수의 이름이 충돌할 수 있는데, 이때 두 함수를 서로 다른 네임스페이스에 넣으면 충돌을 해결할 수 있어요.
네임스페이스는 중첩할 수 있어서, 규모가 큰 코드베이스를 구조화하는 데 도움이 돼요.
네임스페이스에 접근할 때는 범위 지정 연산자 `::`를 사용해요.

아래 예제는 서로 다른 두 `foo` 함수를 사용하는 모습을 보여줘요.
각 함수 앞에 자신이 속한 네임스페이스를 붙이면 두 함수를 함께 사용할 수 있어요.

```cpp
namespace my_ns {
    int foo() {
        return 44;
    }
    namespace my_inner_ns {
        int baz() {
            return 90;
        }
    }
}
namespace my_other_ns {
    int foo() {
        return -2;
    }
}

int myresult{my_ns::foo() + my_other_ns::foo() * my_ns::my_inner_ns::baz()};
```
