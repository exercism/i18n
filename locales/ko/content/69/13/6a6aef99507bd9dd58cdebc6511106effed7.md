# 안내

이 연습 문제에서는 Lisp 외계인 Larry를 도와 로그 문자열을 파싱하고 형식을 정리하는 코드를 작성해요. 이 로그 문자열은 여러 시스템에서 들어오는데, 담긴 메시지를 정보를 한눈에 볼 수 있는 모니터링 화면에 표시하려면 가공이 필요해요.

로그 문자열은 `"[<level>]: <message>"` 형태예요. `<level>`은 `info`, `warn`, `ohno` 중 하나예요.

## 1. 메시지 추출하기

로그 문자열을 받아 그 안에 담긴 메시지로 평가되는 함수 `log-message`를 정의해요.

```lisp
(log-message "[ohno]: whoops!") ; => "whoops!"
```

## 2. 심각도 판단하기

로그 문자열의 레벨에 따라 심각도가 정해져요.

- 레벨이 `info`인 경우 심각도는 `:everything-ok`에 해당해요.
- 레벨이 `warn`인 경우 심각도는 `:getting-worried`에 해당해요.
- 레벨이 `ohno`인 경우 심각도는 `:run-for-cover`에 해당해요.

로그 문자열을 받아 올바른 심각도로 평가되는 함수 `log-severity`를 정의해요.

```lisp
(log-severity "[warn]: might want to get that checked") ; => :getting-worried
```

## 3. 현실의 변덕에 대처하기

안타깝게도 로그 문자열이 항상 올바른 형식으로 들어오지는 않아요. 특히 로그 레벨이 위에서 정한 것처럼 전부 소문자가 아닐 수도 있어요. `log-severity`를 고쳐서 이런 경우도 처리해 봐요.

```lisp
(log-severity "[WaRn]: string case system failing") ; => :getting-worried
```

## 4. 로그 심각도에 따라 로그 메시지 형식 바꾸기

심각도에 따라 메시지를 서로 다른 방식으로 바꿔야 해요.

- 심각도가 `:everything-ok`인 경우 메시지를 모두 소문자로 바꿔요.
- 심각도가 `:getting-worried`인 경우 메시지에서 각 단어의 첫 글자를 대문자로 바꿔요.
- 심각도가 `:run-for-cover`인 경우 메시지를 모두 대문자로 바꿔요.

로그 메시지를 받아 올바른 형식의 메시지로 평가되는 함수 `log-format`을 정의해요.

```lisp
(log-format "[ohno]: whoops!") ; => WHOOPS!
```
