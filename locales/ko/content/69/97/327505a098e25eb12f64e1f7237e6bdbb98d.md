# 지침

이 연습 문제에서는 기록된 보고서에서 가져온 줄을 처리해요.
각 로그 줄은 `"[<LEVEL>]: <MESSAGE>"` 형식의 문자열이에요.

로그 레벨은 세 가지가 있어요.

- `INFO`
- `WARNING`
- `ERROR`

과제는 세 개이고, 각 과제에서는 로그 줄을 하나씩 받아 그 줄로 무언가를 해요.

## 1. 로그 줄에서 메시지 가져오기

로그 줄의 메시지를 반환하도록 `log_line::message` 메서드를 구현해요.

```cpp
log_line::message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

## 2. 로그 줄에서 로그 레벨 가져오기

로그 줄의 로그 레벨을 반환하도록 `log_line::log_level` 메서드를 구현해요. 이때 로그 레벨은 대문자로 반환해야 해요.

```cpp
log_line::log_level("[ERROR]: Invalid operation")
// => "ERROR"
```

## 3. 로그 줄 형식 바꾸기

로그 줄의 형식을 바꾸는 `log_line::reformat` 메서드를 구현해요. 메시지를 앞에 두고, 그 뒤에 로그 레벨을 괄호 안에 넣어요.

```cpp
log_line::reformat("[INFO]: Operation completed")
// => "Operation completed (INFO)"
```
