# 소개

struct와 class에 데이터를 저장하는 프로퍼티처럼, struct나 class 안에 함수를 저장하는 _메서드_도 정의할 수 있어요.

메서드도 일반 함수와 똑같은 방식으로 정의하는데, 정의하는 위치만 struct나 class의 본문 안이라는 점이 달라요. struct의 프로퍼티 값을 바꾸는 함수라면 앞에 `mutating` 키워드를 붙여야 한다는 점에 주의해요. 또한 메서드가 값을 바꿀 수 있는 프로퍼티는 일반 변수와 마찬가지로 `let`이 아니라 `var`로 정의해야 해요.

```swift
struct CharacterStats {
  var health = 0.0
  var speed = 0
  var strength = 0

  mutating func takeHit(_ damage: Double) {
    health = max(0.0, health - damage)
  }
  func canLift(_ weight: Int) -> Bool {
    weight < strength * 100
  }
}
```

이 메서드들은 프로퍼티처럼 점 표기법으로 호출할 수 있어요.

```swift
var stats = CharacterStats(health: 72.8, speed: 19, strength: 6)
stats.canLift(500)
// => true
```
