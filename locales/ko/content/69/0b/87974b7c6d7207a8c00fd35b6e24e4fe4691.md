# 지침 추가

## 워드

- `<bst> ( data-seq -- tree )`: `data-seq`의 각 원소를 순서대로 삽입해 트리를 만들어요.
- `sorted-data ( tree -- seq )`: 트리의 원소를 오름차순으로 반환해요(중위 순회).

## 튜플 계층 구조

이진 탐색 트리의 노드는 *비어 있거나*, *값과 두 개의 서브트리를 가지고 있어요*. 이를 작은 상속 계층 구조로 모델링해요:

```factor
TUPLE: bst ;
TUPLE: leaf < bst ;
TUPLE: branch < bst data left right ;
```

`bst`는 추상 부모이고, `leaf`는 빈 트리인 경우이며, `branch`는 값 하나와 두 개의 `bst` 자식을 가져요(각 자식은 그 자체로 `leaf` 또는 `branch`예요).

## 순서 비교

데이터는 `math.order`의 `before=?`로 비교해요. `before=?`는 숫자는 물론 문자열에도 동작해요. 테스트는 `"1"`, `"2"`, `"3"` 같은 문자열 데이터를 사용해요.
