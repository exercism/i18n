# 지침

이 연습 문제에서는 로그 라인을 처리해요.

각 로그 라인은 다음과 같은 형식의 문자열이에요: `"[<LEVEL>]: <MESSAGE>"`.

로그 레벨은 세 가지가 있어요:

- `INFO`
- `WARNING`
- `ERROR`

세 가지 작업이 있는데, 각 작업에서는 로그 라인을 하나 받아 무언가를 해야 해요.

## 1. 로그 라인에서 메시지 가져오기

`message` 함수를 구현해서 로그 라인의 메시지를 반환해요:

```gleam
message("[ERROR]: Invalid operation")
// -> "Invalid operation"
```

앞뒤의 공백은 제거해야 해요:

```gleam
message("[WARNING]:  Disk almost full\r\n")
// -> "Disk almost full"
```

## 2. 로그 라인에서 로그 레벨 가져오기

`log_level` 함수를 구현해서 로그 라인의 로그 레벨을 반환해요. 로그 레벨은 소문자로 반환해요:

```gleam
log_level("[ERROR]: Invalid operation")
// -> "error"
```

## 3. 로그 라인 형식 바꾸기

`reformat` 함수를 구현해서 로그 라인의 형식을 바꿔요. 메시지를 먼저 쓰고, 그 뒤에 로그 레벨을 괄호 안에 넣어요:

```gleam
reformat("[INFO]: Operation completed")
// -> "Operation completed (info)"
```
