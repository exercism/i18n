# 소개

Julia는 대부분의 프로그래밍 작업에 사용할 수 있는 범용 언어예요.
하지만 실제로는 공학과 과학 분야에서 주로 쓰여요.
빠르고 다재다능하며 정교한 수치 계산이 Julia 설계의 중심이에요.

## 정수

정수는 소수점이 없는 "딱 떨어지는" 수예요.

[기초][basics] 개념에서 정수 값을 자료형을 지정하지 않고 변수에 할당할 수 있다는 걸 봤어요.

가독성을 위해 밑줄을 자릿수 구분자로 사용할 수 있어요.
컴파일러는 이 밑줄을 무시해요.

```julia-repl
julia> x = 3
3

julia> typeof(x)
Int64

julia> large_number = 1_234_567_890
1234567890
```


## 부동소수점

부동소수점 수에 소수점이 있고, 소수점 뒤에 소수 부분이 있다는 건 놀랍지 않을 거예요.

```julia-repl
julia> f = 3.45
3.45

julia> typeof(f)
Float64
```

물론 과학적 표기법도 지원해요.

```julia-repl
julia> avogadro = 6.02e23
6.02e23
```

최댓값과 최솟값은 의외일지도 몰라요:

```julia-repl
julia> typemax(Float64)
Inf

julia> typemin(Float64)
-Inf
```

무한대도 유효한 값이에요!

## 산술 연산자

기초 개념에서 이야기했듯이, 산술 연산자는 아이들에게 가르치는 일반적인 산수와 거의 똑같이 동작해요.
거듭제곱에는 `**`가 _아니라_ `^`를 쓴다는 점을 기억해 둬요 (둘 다 다른 언어에서는 흔히 볼 수 있어요).

```julia
2 + 3  # 5 (addition)
2 - 3  # -1 (subtraction)
2 * 3  # 6 (multiplication)
8 / 2  # 4.0 (division)
8 % 3  # 2 (remainder)
2 ^ 3  # 8 (exponentiation)
```

그런데 Julia만의 몇 가지 세부 사항은 짚고 넘어갈 만해요.

### 곱셈

```julia-repl
julia> x = 4.2
4.2

julia> 2 * x
8.4

julia> 2x
8.4

julia> 2.4x
10.08
```

이건 좀 놀라울 수도 있어요.

대부분의 다른 프로그래밍 언어처럼 `*`를 중위 연산자로 쓰는 건 언제나 가능해요.

하지만 Julia는 코드가 최대한 수학 공식처럼 보여야 한다고 믿는 사람들이 설계했어요.

변수 이름은 반드시 문자로 시작해야 하기 때문에, 이름 앞에 숫자(정수든 부동소수점이든)를 붙이면 암시적 곱셈으로 처리돼요.

예를 들어 구의 겉넓이를 구할 때 `4 * pi * r * r` 대신 이렇게 할 수 있어요:

```julia-repl
julia> surface(r) = 4π * r^2
surface (generic function with 1 method)

julia> surface(3)
113.09733552923255
```

π는 내장 상수이지만 (그리스) 문자이기도 해요.
그래서 파서는 `π`와 `r`을 구분하기 위해 명시적인 `*` 하나가 여전히 필요해요.

### 나눗셈

`/`를 중위 연산자로 사용하면 정수를 입력해도 항상 부동소수점 결과가 나와요.

정수 나눗셈에는 더 많은 선택지가 있어요.

```julia-repl
julia> 10 / 3  # floating-point division
3.3333333333333335

julia> div(10, 3)  # integer division
3

julia> 10 ÷ 3  # synonym for div()
3

julia> 10 // 3  # rational number (fraction)
10//3
```

`div()` 함수는 정수 나눗셈을 위한 것으로, 결과는 0 방향으로 버려져요. 양수는 내림, 음수는 올림이에요.

같은 의미로 중위 연산자 `÷`를 쓸 수 있는데, 역시 더 수학처럼 보이게 하려는 거예요.
Julia를 인식하는 편집기를 쓴다면 `\div`를 입력한 뒤 `<Tab>` 키를 누르면 돼요.

`//` 연산자는 이 개념의 범위를 벗어나요.
지금은 `//`의 결과가 "유리수"이고, 대부분의 사람들이 이를 _분수_라고 부른다고만 알아둬요.

## 숫자형 변환

이런 변환은 자주 자동으로 일어나요:

```julia-repl
julia> x = 2 + 3.5
5.5

julia> typeof(x)
Float64
```

`Int64`와 `Float64`를 더했더니 `Float64` 결과가 나왔어요.

사실 덧셈을 하기 전에 정수가 조용히 `Float64`로 변환된 거예요.

**부동소수점에서 정수로**의 변환은 어쩔 수 없이 더 복잡해요.
소수점 뒤에 있는 값은 어떻게 처리하고 싶나요?

- `round()` 함수는 가장 가까운 정수로 변환하는데, 4.5처럼 정확히 중간에 있는 값은 가장 가까운 _짝수_로 반올림해요.
- `floor()`는 내림, `ceil()`은 올림, `trunc()`는 0 방향으로 버림이에요.
- `Int32()`처럼 직접 캐스팅하려고 하면 `InexactError`와 함께 실패해요.

그런데 이 함수들은 기본적으로 원했던 정수형을 반환하지 않아요.
원하는 출력 자료형을 지정할 수 있어요.

```julia-repl
julia> round(4.5)
4.0

julia> ceil(Int, 4.3)
5
```

소수점 뒤 자릿수를 지정해 반올림하는 것도 `digits` 키워드로 가능해요.

```julia-repl
julia> round(π, digits=10)
3.1415926536
```

## 0으로 나누기

오류가 발생한다고 생각하나요?
사실 상황은 그렇게 단순하지 않아요.

예상했겠지만, `÷`나 `//`를 사용한 정수 나눗셈은 오류가 발생해요.

`/`를 사용한 부동소수점 나눗셈은 일반적인 컴퓨터 과학 방식이 아니라, 엔지니어링 방식이라고 할 만한 접근을 취해요:

```julia-repl
julia> 2 / 0
Inf

julia> 0 / 0
NaN
```

앞에서 이야기했듯이, Julia에서 무한대는 유효한 부동소수점 수이고 `Inf`로 나타내요.

분자도 0이면 결과는 수학적으로 정의되지 않아요.
그러면 Julia는 이를 "숫자가 아님"으로 처리하고, `NaN`으로 나타내요.
