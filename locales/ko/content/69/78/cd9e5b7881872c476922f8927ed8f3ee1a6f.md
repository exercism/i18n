## Z3 설치하기

### Python 다운로드 (아직 설치하지 않은 경우)

최신 버전의 Python은 [여기](https://python.org)에서 다운로드할 수 있어요.

* 설치할 때 Python을 PATH에 추가하는 체크박스를 반드시 선택해 주세요

### Visual Studio 다운로드 (아직 설치하지 않은 경우)

최신 버전의 Visual Studio는 [여기](https://visualstudio.microsoft.com/downloads/?utm_medium=microsoft&utm_source=docs.microsoft.com&utm_campaign=inline+link&utm_content=download+vs2019)에서 다운로드할 수 있어요.

* 설치할 때 **Python Development** 워크로드를 선택해 주세요
* 오른쪽에 있는 모든 선택적 Python 개발 패키지 체크박스를 선택해 주세요

설치한 뒤 Visual Studio를 열고 초기 기본 설정을 지정해 주세요.

### Git 명령 설치하기

Git 설치 안내는 [여기](https://git-scm.com/book/en/v2/Getting-Started-Installing-Git)에서 확인할 수 있어요.

* [Git을 시스템 변수에 추가](https://stackoverflow.com/questions/4492979/git-is-not-recognized-as-an-internal-or-external-command)해야 해요

### Z3 클론하기

[Z3 Github 저장소](https://github.com/Z3Prover/z3)로 이동해 프로젝트를 확인해 보세요.

컴퓨터에서 터미널을 열고 Z3 저장소를 클론할 위치로 이동해요 (예: C:\Z3).

그 위치에서 다음을 실행해요:

```bash
git clone https://github.com/z3Prover/z3.git
```

### Visual Studio 명령 프롬프트를 사용해 Windows에서 Z3 빌드하기

시작 메뉴에서 **Developer Command Prompt for VS 2019**를 열어요.

Z3 저장소를 클론한 폴더로 이동해요 (예: C:\Z3).

32비트 빌드의 경우 다음을 실행해요:

```bash
python scripts/mk_make.py
```

64비트 빌드의 경우 다음을 실행해요:

```bash
python scripts/mk_make.py -x
```

그런 다음 실행해요:

```bash
cd build
pip install z3-solver
```



이제 Visual Studio를 열고 Python 바인딩으로 Z3를 실행할 수 있을 거예요.


테스트하려면 다음을 실행해 볼 수 있어요:
```python
from x3 import *
x = Real('x')
y = Real('y)
s = Solver()
s.add(x + y > 5, x > 1, y > 1)
print(s.check())
print(s.model())
```

마지막 두 줄은 `sat`과 `[y = 4, x = 2]`를 출력해야 해요.
