# 설치

Reason을 설치하려면 Node Package Manager(npm)가 필요해요. [여기](https://www.npmjs.com/get-npm)에 있는 안내를 따라 주세요.

npm이 준비되면, 다음 명령으로 Reason을 설치해요.
```
npm install -g bs-platform
```

Reason은 여러 에디터와 연동돼요. [여기](https://reasonml.github.io/docs/en/editor-plugins.html#officially-supported-editors)를 참고해요.

셸에서 Reason 표현식을 평가해 볼 수 있는 REPL을 비롯한 몇 가지 명령줄 도구는 [여기](https://github.com/reasonml/reason-cli)에서 찾을 수 있어요.
