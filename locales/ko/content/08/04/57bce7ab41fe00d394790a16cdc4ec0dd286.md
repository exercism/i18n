# 추가 지침

## 예외 메시지

때로는 [예외를 발생시켜야](https://docs.python.org/3/tutorial/errors.html#raising-exceptions) 할 때가 있어요. 이럴 때는 오류의 원인이 무엇인지 알려 주는 **의미 있는 오류 메시지**를 항상 함께 넣어야 해요. 그래야 코드가 더 읽기 쉬워지고 디버깅에도 큰 도움이 돼요. 오류의 원인이 특정 유형이라고 확실한 상황이라면 [내장 오류 유형](https://docs.python.org/3/library/exceptions.html#base-classes) 중 하나를 발생시켜도 되지만, 그래도 의미 있는 메시지는 꼭 포함해야 해요.

이 연습 문제에서는 입력에 적절한 구분자가 없거나, 대문자가 아니거나, 노드가 있는 트리를 이루지 않거나, 트리를 전혀 이루지 않을 때 [raise 문](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)으로 `ValueError`를 "던지도록" 해야 해요. `exception`을 `raise`하고 그에 대한 메시지도 함께 넣어야만 테스트를 통과할 수 있어요.

메시지와 함께 `ValueError`를 발생시키려면, 메시지를 `exception` 유형의 인자로 작성해요:

```python
# if the tree properties as given do not have proper delimiters.
raise ValueError("properties without delimiter")

# if the tree properties as given are not all in uppercase.
raise ValueError("property must be in uppercase")

# if the input does not form a tree, or is empty.
raise ValueError("tree missing")

# if the input is a tree without any nodes.
raise ValueError("tree with no nodes")
```
