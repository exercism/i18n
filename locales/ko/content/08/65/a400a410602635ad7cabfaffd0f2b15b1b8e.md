# 매크로 연습 문제에 필요한 개념

연습 문제를 푸는 방법은 여러 가지지만, 여기서는 어떤 개념이 쓰이는지 판단하는 주된 기준으로 [표준 예제](https://github.com/exercism/rust/blob/666c366fc0d39d9f6fd8e837facea8afe2153ae2/exercises/macros/example.rs)를 살펴볼게요.

개념 목록이라고 하면 [이 목록](https://github.com/exercism/v3/blob/master/languages/rust/reference/README.md)을 가리켜요.

개념 연습 문제와 실습 연습 문제 모두에서, 사전에 필요한 개념 목록은 가능한 한 작아야 해요. 여기서 목표는 문제를 푸는 모든 방식에서 쓰일 수 있는 개념을 빠짐없이 나열하는 게 아니라, 의욕 있는 학생이라면 그 문제를 풀 수 있을 만한 최소한의 지식을 나열하는 거예요.

참고로 이 연습 문제는 "선언적 매크로 작성"이라는 개념을 다루는 개념 연습 문제가 될 가능성이 아주 높아요.

## 필수 개념

### 기존 개념

- structs
- (불)가변성
- `Hashmap<K, V>`

### 추가해야 할 개념

- 변수 할당 (`fundamentals`의 일부)
- 변수 스코프 / 네임스페이스 (`fundamentals`의 일부)
- 메서드와 연관 함수 (`structs`에 의존)
