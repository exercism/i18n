# 소개

Java의 대표적인 객체 지향 구성 요소는 _클래스_로, 데이터(_필드_)와 동작(_메서드_)을 함께 묶은 것이에요.
클래스의 필드와 메서드를 _멤버_라고 해요.

멤버에 대한 접근은 접근 제어자로 제어할 수 있는데, 가장 흔히 쓰이는 두 가지는 다음과 같아요:

- `public`: 어떤 코드든 이 멤버에 접근할 수 있어요 (제한 없음).
- `private`: 같은 클래스 안의 코드만 이 멤버에 접근할 수 있어요.

클래스는 그 클래스의 인스턴스를 만들기 위한 템플릿이라고 생각하면 돼요.
클래스의 인스턴스(=_객체_라고도 해요)를 만들려면 `new` 키워드를 사용해요:

```java
class Car {
}

// Create two car instances
Car myCar = new Car();
Car yourCar = new Car();
```

필드에는 타입과 이름이 있고(이름은 camelCase로 정의해요), 클래스 안 어디에나 정의할 수 있어요(관례적으로 클래스 이름은 PascalCase로 써요):

```java
class Car {
    // Accessible by anyone
    public int weight;

    // Only accessible by code in this class
    private String color;
}
```

필드에는 초깃값을 선택적으로 지정할 수 있어요.
필드에 초깃값을 지정하지 _않으면_, 그 타입의 기본값으로 설정돼요.
인스턴스의 필드 값은 점 표기법으로 접근하고 갱신할 수 있어요.

```java
class Car {
    // Will be set to specified value
    public int weight = 2500;

    // Will be set to default value (0)
    public int year;
}

Car newCar = new Car();
newCar.weight; // => 2500
newCar.year;   // => 0

// Update value of the field
newCar.year = 2018;
```

`private` 필드는 보통 메서드를 호출하는 부수 효과로 갱신해요.
그런 메서드는 보통 아무 값도 반환하지 않는데, 이때 반환 타입은 `void`로 해야 해요:

```java
class CarImporter {
    private int carsImported;

    public void importCars(int numberOfCars)
    {
        // Update private field from public method
        carsImported = carsImported + numberOfCars;
    }
}
```
