# 설치


## GHCup 설치하기

Haskell 도구를 설치하는 가장 권장되는 방법은 [GHCup][ghcup]을 사용하는 거예요.

GHCup으로 설치된 컴파일러, 프로젝트/패키지 관리자, 언어 서버를 관리할 수 있어요.


## Stack 설치하기

Exercism 연습 문제를 풀려면 Stack만 있으면 돼요.

Stack을 설치하려면 GHCup 설치 명령이나 스크립트를 실행해요.
기본값을 따라가되, Stack도 함께 설치하도록 지정해요.

실수로 Stack 설치를 건너뛰었나요?
걱정 마세요. 나중에 `ghcup install stack`을 실행하면 돼요.

GHCup은 다음을 설치해요

- **컴파일러** (GHC: Glasgow Haskell Compiler)

  엄밀히 말하면 Exercism에는 필요 없지만, 연습 문제 디렉터리 밖에서 [GHCi][ghc-guide-ghci]를 가지고 놀고 싶을 때 유용해요.

- **Cabal**

  프로젝트/패키지 관리자예요.
  Exercism에는 필요 없어요.

- **Stack**

  Exercism에서 사용할 프로젝트/패키지 관리자예요.
  각 프로젝트(연습 문제)마다 알맞은 컴파일러와 라이브러리가 있는지 확인해 줘요.

설치가 성공했는지 확인하려면 다음 명령 중 하나를 실행해요

- `ghcup list`: 도구 버전 목록이 길게 나오고 Stack이 설치됨으로 표시되면 성공이에요
- `stack --version`: `Version 2.7.5, Git revision ...`처럼 나오면 성공이에요


## 알맞은 GHC 버전 설치하기

Stack은 GHC가 필요할 때 자동으로 내려받아 설치해요.
터미널에서 다음 명령을 실행하면 설치를 시작하고 확인할 수 있어요.

```bash
# Note: it only makes sense to run Stack
# inside projects, so navigate into an
# exercise directory first!
exercism download --exercise=hello-world --track=haskell
cd ~/Exercism/haskell/hello-world
stack ghc -- --version
```

다음과 비슷한 결과가 나온다면

```
The Glorious Glasgow Haskell Compilation System, version 8.8.4
```

GHC가 제대로 설치된 거예요.


## Haskell 작업을 위한 에디터 설정하기

Haskell 지원은 Haskell Language Server(HLS)가 제공해요.
언어 지원은 필수는 아니지만, 적극 권장해요.


### Visual Studio Code (권장)

[Visual Studio Code용 Haskell 확장][vscode-haskell]을 설치하기만 하면 돼요.
GHCup을 사용해 HLS를 자동으로 설치하고, 그러면 모든 준비가 끝나요.

**참고:** 새로 내려받은 연습 문제에서는 HLS가 시작하는 데 문제가 생길 수 있어요.
그럴 때는 `stack test`를 실행하고 언어 서버를 다시 시작해요.


### 다른 에디터

[에디터 설정에 관한 HLS 문서][hls-editor-config]를 참고해요.
HLS를 직접 설치해야 할 수도 있어요.
그러려면 `ghcup install hls`를 실행해요.
