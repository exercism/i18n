# 소개

Go에서는 동등 연산자와 순서 연산자를 사용해 값을 비교할 수 있어요.
이 연산자는 6개가 있어요.

| 비교              | 연산자    |
| ------------------| --------- |
| 같음              | `==`      |
| 같지 않음         | `!=`      |
| 작음              | `<`       |
| 작거나 같음       | `<=`      |
| 큼                | `>`       |
| 크거나 같음       | `>=`      |

비교의 결과는 항상 불리언 값이에요.

```go
a := 3

a != 4 // true
a > 5  // false
```

## 동등 연산자

`==`와 `!=`는 동등 연산자예요.
각각 한 값이 다른 값과 같은지, 그렇지 않은지를 확인해요.
Go에서는 대부분의 타입에 동등 연산자를 사용할 수 있어요.
몇 가지 흔한 예를 볼까요?

```go
2 == 3 // false, integer comparison

2.1 != 2.2 // true, float comparison 

"hello" == "hello" // true, string comparison

'a' != 'b' // true, rune/byte comparison
```

## 순서 연산자

순서 연산자는 한 값이 다른 값보다 큰지(`>`), 크거나 같은지(`>=`), 작은지(`<`), 작거나 같은지(`<=`)를 확인해요.
이런 비교는 숫자, 바이트, 룬, 문자열에 사용할 수 있어요.
문자열을 비교할 때는 사전순(사전 편찬 순서라고도 해요)을 따라요.

```go
2 > 3 // false, integer comparison

1.2 < 1.3 // true, float comparison

'a' > 'b' // false, rune/byte comparison

"Hello" < "World" // true, string comparison
```
