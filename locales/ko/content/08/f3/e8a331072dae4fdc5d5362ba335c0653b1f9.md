# 테스트

다음 명령으로 테스트를 실행해요:

```bash
$ wrenc exercise-name.spec.wren
```

예를 들어 `hello-world`라면:

```bash
$ wrenc hello-world.spec.wren
```


## 건너뛰기 테스트 이해하기

`skip` 메서드는 테스트 스위트가 특정 테스트를 실행하지 않도록 지시해요.

- 왜 건너뛰는 걸까요?

사용자가 한 번에 하나의 테스트에 집중하고, 풀이를 발전시켜 나가면서 하나씩
활성화할 수 있도록 하기 위해서예요.

- 어떻게 활성화하나요?

건너뛴 테스트는 다음과 같아요:

```js
// this test will be skipped and not run
skip.test("title cased phrases") {
    Expect.value(Acronyms.parse("Portable Network Graphics")).toEqual("PNG")
}
```

`skip.test`를 `do.test`로 바꾸기만 하면 돼요.

```js
// now the test will be run normally
do.test("title cased phrases") {
    Expect.value(Acronyms.parse("Portable Network Graphics")).toEqual("PNG")
}
```

## 첫 번째 Wren 모듈 만들기

이 트랙의 테스트는 여러분의 구현을 Wren 모듈로 가져와서 로드해요:
`import "./bob" for Bob`. 구현을 내보내기 위한 특별한 문법은 없어요.
클래스 이름을 `Bob`으로 지어서 `for Bob` 가져오기 문과 맞추기만 하면
모든 게 잘 동작할 거예요.

```javascript
class Bob {
  static hey(message) {
    // Your solution to the exercise goes here
  }
}
```

모듈에 대한 더 많은 정보는
[Wren 모듈성 문서][modularity]에서 찾을 수 있어요.
시작하기 쉽도록, 각 연습 문제 디렉터리에는 _뼈대_ Wren 파일이 들어 있어요.

[modularity]: https://wren.io/modularity.html
