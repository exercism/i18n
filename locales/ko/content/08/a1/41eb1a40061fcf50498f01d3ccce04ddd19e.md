# 소개

Cairo의 제어 흐름을 사용하면 조건과 반복에 따라 프로그램의 실행 경로를 제어할 수 있어요.

## 조건부 실행

조건에 따라 코드를 실행하려면 `if` 표현식을 사용해요:

```rust
let number = 42;
if number > 0 {
    println!("Positive number");
} else if number < 0 {
    println!("Negative number");  
} else {
    println!("Zero");
}
```

`if`는 표현식이기 때문에 값을 반환할 수 있어요:

```rust
let result = if condition { 5 } else { 10 };
```

## 루프

코드를 반복하려면 `loop`를 사용해요.
루프는 멈추지 않는 한 계속 실행돼요. 조건이 충족되면 `break`로 루프를 종료해요.

```rust
let mut counter = 0;
loop {
    if counter == 5 {
        break;
    }
    println!("Counter: {}", counter);
    counter += 1;
}
```

루프는 `break`를 사용해 값을 반환할 수 있어요:

```rust
let result = loop {
    counter += 1;
    if counter == 10 {
        break counter * 2; // Returns 20
    }
};
```

다음 반복으로 건너뛰려면 `continue`를 사용해요:

```rust
let mut i = 0;
loop {
    i += 1;
    if i % 2 == 0 {
        continue; // Skip even numbers
    }
    if i > 10 {
        break;
    }
    println!("{}", i); // Only prints odd numbers
}
```
