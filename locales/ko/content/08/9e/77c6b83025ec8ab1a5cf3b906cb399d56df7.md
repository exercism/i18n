# 기초 자세히 알아보기

기초 개념에서는 [Go](https://golang.org)를 정적으로 타입이 지정되는 컴파일 프로그래밍 언어로 소개했어요.
이 언어는 예전 도메인 이름인 golang.org 때문에 흔히 Golang이라고 불리지만, 공식 이름은 Go예요.

기초 개념에서는 패키지, 함수, 변수라는 세 가지 주요 언어 기능을 다뤄요.

## 패키지

Go 애플리케이션은 패키지로 구성돼요.
패키지는 같은 디렉터리에 있는 소스 파일들의 모음이에요.
한 디렉터리에 있는 모든 소스 파일은 같은 패키지 이름을 사용해야 해요.
패키지 이름은 보통 임포트 경로의 마지막 디렉터리 이름으로 정해요.
예를 들어 ["math/rand" 패키지](https://golang.org/src/math/rand/)의 파일들은 `package rand`라는 문으로 시작해요.
패키지를 임포트하면 이름이 대문자로 시작하는 요소(함수, 타입, 변수, 상수)만 사용하거나 접근할 수 있어요.
Go에서 권장하는 이름 짓기 방식은 식별자를 `camelCase`로 짓는 것이고, 패키지 밖에서도 접근할 수 있어야 하는 식별자는 `PascalCase`로 지어요.

```go
package lasagna
```

## 변수

Go는 정적 타입 언어라서, 모든 변수는 컴파일 시점에 [타입이 정해져 있어야 해요](https://en.wikipedia.org/wiki/Type_system).

변수는 타입을 직접 지정해서 정의할 수 있어요:

```go
var explicit int // Explicitly typed
```

초기값을 함께 쓰면 컴파일러가 초기값의 타입에 맞춰 변수의 타입을 정해줘요.

```go
implicit := 10   // Implicitly typed as an int
```

한 번 선언한 변수에는 `=` 연산자로 값을 할당할 수 있어요.
한 번 선언한 변수의 타입은 절대 바꿀 수 없어요.

```go
count := 1 // Assign initial value
count = 2  // Update to new value

count = false // This throws a compiler error due to assigning a non `int` type
```

## 상수

상수는 변수처럼 데이터를 담지만, 프로그램이 실행되는 동안 값이 바뀌지 않아요.

상수는 `const` 키워드로 정의하고, 숫자, 문자, 문자열, 불리언이 될 수 있어요:

```go
const Age = 21 // Defines a numeric constant 'Age' with the value of 21
```

## 함수

Go 함수는 매개변수를 0개 이상 받아요.
매개변수는 타입을 반드시 직접 지정해야 하고, 타입 추론은 없어요.

값은 `return` 키워드로 함수에서 반환해요.

함수는 함수 이름을 쓰고 각 매개변수에 맞는 인자를 넘겨서 호출해요.

참고로 Go는 두 가지 종류의 주석을 지원해요.
한 줄 주석은 `//`로 시작하고, 여러 줄 주석은 `/*`와 `*/` 사이에 넣어요.

```go
package greeting

// Hello is a public function.
func Hello (name string) string {
    return hi(name)
}

// hi is a private function.
func hi (name string) string {
    return "hi " + name
}
```
