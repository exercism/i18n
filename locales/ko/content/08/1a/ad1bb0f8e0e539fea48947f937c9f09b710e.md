# 지침

이 연습 문제에서는 윈도우 기반 컴퓨터 시스템을 시뮬레이션해요.
이동하고 크기를 조절할 수 있으며 내용을 표시하는 창을 만들어 봐요.
다음 그림은 아래에서 다룰 값들을 나타내요.

```
                  <--------------------- screenSize.width --------------------->

       ^          ╔════════════════════════════════════════════════════════════╗
       |          ║                                                            ║
       |          ║          position.x,_                                      ║
       |          ║          position.y  \                                     ║
       |          ║                       \<----- size.width ----->            ║
       |          ║                 ^      *──────────────────────┐            ║
       |          ║                 |      │        title         │            ║
       |          ║                 |      ├──────────────────────┤            ║
screenSize.height ║                 |      │                      │            ║
       |          ║            size.height │                      │            ║
       |          ║                 |      │       contents       │            ║
       |          ║                 |      │                      │            ║
       |          ║                 |      │                      │            ║
       |          ║                 v      └──────────────────────┘            ║
       |          ║                                                            ║
       |          ║                                                            ║
       v          ╚════════════════════════════════════════════════════════════╝
```

## 1. Size 구조체 정의하기

`width`와 `height`라는 두 개의 `Int` 프로퍼티를 가진 `Size`라는 구조체를 정의해요. 각각 창의 현재 너비와 높이를 저장해요.
초기 너비와 높이는 각각 80과 60이어야 해요.
새 너비와 높이 매개변수를 받아 프로퍼티를 새 크기에 맞게 변경하는 `resize(newWidth:newHeight:)` 메서드를 포함해요.

```swift
let size1080x764 = Size(width: 1080, height: 764)
// Returns Size
var size1200x800 = size1080x764
// Returns Size
size1200x800.resize(newWidth: 1200, newHeight: 800)
size1200x800.height
// Returns 800
```

## 2. Position 구조체 정의하기

`x`와 `y`라는 두 개의 `Int` 프로퍼티를 가진 `Position`이라는 구조체를 정의해요. 각각 창의 왼쪽 위 모서리의 현재 가로 위치와 세로 위치를 저장해요.
x와 y의 초기값은 각각 0이어야 해요. 위치 (0, 0)은 화면의 왼쪽 위 모서리이고, 오른쪽으로 갈수록 `x` 값이 커지고 아래로 갈수록 `y` 값이 커져요.

새 x와 y 매개변수를 받아 프로퍼티를 새 위치에 맞게 변경하는 `moveTo(newX:newY:)` 메서드를 포함해요.

```swift
var point = Position(x: 10, y: 20)
// Returns Position
point.moveTo(newX: 100, newY: -100)
point.y
// Returns -100
```

## 3. Window 클래스 정의하기

다음 프로퍼티를 가진 창 클래스를 정의해요:

- `title` : `String`, 초기값은 "New Window"
- `screenSize` : `Size`, `width` = 800이고 `height` = 600인 상수값
- `size` : `Size`, 초기값은 `Size` 구조체의 기본값
- `position` : `Position`, 초기값은 `Position` 구조체의 기본값
- `contents` : `String?`, 초기값은 `nil`

클래스에 대한 빈 이니셜라이저도 정의해야 해요.

```swift
let window = Window()
window.title
// Returns "New Window"
```

## 4. 창 크기를 조절하는 메서드 추가하기

- `resize(to:)` : `(Size) -> ()` - 이 메서드는 `Size` 구조체를 입력으로 받아 창을 지정된 크기로 조절하려고 해요. 하지만 새 크기는 특정 범위를 넘을 수 없어요.
- 허용되는 최소 높이와 너비는 1이에요.
  1보다 작게 요청된 높이나 너비는 1로 잘려요.
- 최대 높이와 너비는 창의 현재 위치에 따라 달라져요. 창의 가장자리는 화면의 가장자리를 넘어갈 수 없어요.
  이 범위보다 큰 값은 가질 수 있는 가장 큰 크기로 잘려요.
  예를 들어 창의 위치가 `x` = 400, `y` = 300이고 `height` = 400, `width` = 300으로 크기 조절을 요청하면, 화면이 `y` 방향으로 요청을 완전히 수용할 만큼 크지 않기 때문에 창은 `height` = 300, `width` = 300으로 조절돼요.

## 5. 창을 이동하는 메서드 추가하기

- `move(to:)` : `(Position) -> ()` - `resize(to:)`와 비슷하지만, 이 메서드는 크기가 아니라 창의 _위치_를 요청된 값으로 조절해요. `resize`와 마찬가지로 새 위치는 특정 한계를 넘을 수 없어요.
- 가장 작은 위치는 `x`와 `y` 모두 0이에요.
- 어느 방향이든 최대 위치는 창의 현재 크기에 따라 달라져요. 창의 가장자리는 화면의 가장자리를 넘어갈 수 없어요.
       이 범위보다 큰 값은 가질 수 있는 가장 큰 값으로 잘려요. 예를 들어 창의 크기가 `x` = 250, `y` = 100이고 `x` = 600, `y` = 200으로 이동을 요청하면, 화면이 `x` 방향으로 요청을 완전히 수용할 만큼 크지 않기 때문에 창은 `x` = 550, `y` = 200으로 이동해요.

## 6. 창 텍스트를 갱신하고 창 정보를 표시하는 메서드 추가하기

- `update(title:)` : `(String) -> ()` - 이 메서드는 `title` 프로퍼티를 전달받은 문자열 값으로 설정해요.
- `update(text:)` : `(String?) -> ()` - 이 메서드는 `contents` 프로퍼티를 전달받은 옵셔널 문자열 값으로 설정해요.
- `display()` : `() -> String` - 이 메서드는 창의 현재 상태를 설명하는 문자열을 반환해요. 예를 들어, 창의 `title`이 "My First Window"이고 위치가 x = 10, y = 100, 크기가 width = 200, height = 150, contents가 "I 😍 my window"라면 `"My First Window\nPosition: (10, 100), Size: (200 x 150)\nI 😍 my window\n"` 문자열을 반환해야 해요. `contents`가 nil이면 마지막 줄은 "[This window intentionally left blank]"여야 해요.

## 7. Window 클래스의 이니셜라이저 만들기

윈도우 시스템에는 사용자 지정 입력으로 창을 만들 수 있도록 하는 이니셜라이저가 있어야 해요.
`Window` 클래스에 **또 다른** 이니셜라이저를 만들어요.
이니셜라이저는 `title`, `contents`, 그리고 두 개의 옵셔널 매개변수 `size`와 `position`을 받아야 해요.
`size`와 `position` 매개변수는 `Size` 구조체와 `Position` 구조체의 기본값으로 기본 설정되어야 해요.

```swift
let window = Window(title: "My First Window", contents: "I 😍 my window")
window.display()
// Returns "My First Window\nPosition: (0, 0), Size: (80 x 60)\nI 😍 my window\n"

let window2 = Window(title: "My Second Window", contents: "I 😍 my window", size: Size(width: 200, height: 150), position: Position(x: 10, y: 100))
window2.display()
// Returns "My Second Window\nPosition: (10, 100), Size: (200 x 150)\nI 😍 my window\n"
```
