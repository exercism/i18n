# 지시 사항

친구가 방금 중요한 비밀을 담은 메시지를 보냈어요.
다른 사람이 쉽게 읽지 못하도록, 이 메시지는 일련의 비트 연산을 거쳐 암호화되었어요.
메시지를 복호화하는 데 필요한 함수를 작성해야 해요.

## 1. 비트를 다시 오른쪽으로 시프트하기

메시지를 복호화하는 첫 단계는 암호화 과정에서 시프트한 비트를 오른쪽으로 다시 시프트해 원래대로 되돌리는 거예요.
이후 복호화 단계에서는 왼쪽에서 0이 삽입된다고 가정해요.

값과 시프트할 칸 수를 받아 시프트를 수행하는 `shiftBack` 함수를 구현해요.

```kotlin
shiftBack(0b1001, 2)
# => 0b0010
```

## 2. 일부 비트를 1로 설정하기

다음으로, 1로 설정해야 하는 비트가 있어요.

값과 마스크를 받아 값의 비트를 1로 설정한 결과를 반환하는 `setBits` 함수를 구현해요.
마스크의 비트가 1인 위치에서는 값의 비트도 1로 설정해야 해요.
나머지 비트는 모두 그대로 유지해요.

```kotlin
setBits(0b0110, 0b0101);
# => 0b0111
```

## 3. 특정 비트를 뒤집기

암호화 과정에서 일부 비트가 뒤집혀요.
메시지를 복호화하려면 이 비트를 다시 뒤집어야 해요.

값과 마스크를 받는 `flipBits` 함수를 구현해요.
마스크는 값에서 어떤 비트를 뒤집을지 나타내요.
마스크의 비트가 1이면 값의 해당 비트를 뒤집어요.
나머지 비트는 모두 그대로 유지해요.

```java
flipBits(0b1100, 0b0101);
# => 0b1001
```

## 4. 특정 비트를 0으로 만들기

마지막으로, 항상 0으로 복호화되는 비트도 있어요.

값과 마스크를 받는 `clearBits` 함수를 구현해요.
마스크의 비트가 1인 위치에서는 `value`의 비트를 0으로 설정해야 해요.
나머지 비트는 모두 그대로 유지해요.

```java
clearBits(0b0110, 0b0101);
# => 0b0010
```
