# 소개

메서드 매개변수는 기본값을 지정해서 선택 사항으로 만들 수 있어요. 매개변수가 선택 사항이면 호출하는 쪽에서 그 매개변수에 인자를 넘기지 않아도 되고, 이때는 기본값이 사용돼요. [선택적 매개변수][optional-arguments]는 매개변수 목록의 맨 끝에 와야 해요. 그 뒤에 선택 사항이 아닌 매개변수가 올 수는 없어요. 메서드에 선택적 매개변수가 여러 개 있다면, [명명된 인자][named-arguments]를 사용해 그중 일부만 지정할 수 있어요.

```csharp
class Card
{
    static string NewYear(int year = 2020, string sender = "me")
    {
        return $"Happy {year} from {sender}!";
    }
}

Card.NewYear();     // => "Happy 2020 from me!"
Card.NewYear(1999); // => "Happy 1999 from me!"
Card.NewYear(sender: "mom"); // => "Happy 2020 from mom!"
```

선택적 매개변수의 값은 다음 중 하나여야 해요:

- 상수 식(예: `"hi"`, `2`, `DayOfWeek.Friday`, `null` 등)
- 값 형식의 `new` 식
- 값 형식의 `default` 식

[named-arguments]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/classes-and-structs/named-and-optional-arguments#named-arguments
