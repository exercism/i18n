# 지침

지난 7일 동안 정원에 새가 몇 마리 찾아왔는지 기록하는 열성적인 새 관찰자예요.

정원을 찾아온 새의 수를 다루는 여섯 가지 과제가 있어요.

## 1. 지난주 기록이 어땠는지 확인하기

비교를 위해 지난주 기록을 항상 가까이에 복사해 두는데, 그 값은 0, 2, 5, 3, 7, 8, 4예요. 지난주 기록을 담은 `lastWeek` 바인딩을 정의해요:

```fsharp
lastWeek
// => [| 0; 2; 5; 3; 7; 8; 4 |]
```

## 2. 어제 새가 몇 마리 찾아왔는지 확인하기

`yesterday` 함수를 구현해서 어제 정원을 찾아온 새의 수를 반환해요. 새 기록은 날짜 순으로 정렬되어 있고, 첫 번째 원소는 가장 오래된 날의 기록, 마지막 원소는 오늘의 기록이에요.

```fsharp
yesterday [| 3; 5; 0; 7; 4; 1 |]
// => 4
```

## 3. 찾아온 새의 총 마릿수 계산하기

`total` 함수를 구현해서 정원을 찾아온 새의 총 마릿수를 반환해요:

```fsharp
total [| 3; 5; 0; 7; 4; 1 |]
// => 20
```

## 4. 새가 한 마리도 찾아오지 않은 날이 있었는지 확인하기

`dayWithoutBirds` 함수를 구현해요. 정원에 새가 한 마리도 찾아오지 않은 날이 있다면 `true`를, 그렇지 않으면 `false`를 반환해요:

```fsharp
dayWithoutBirds [| 3; 5; 0; 7; 4; 1 |]
// => true
```

## 5. 오늘 기록 증가시키기

`incrementTodaysCount` 함수를 구현해서 오늘의 기록을 하나 늘리고 갱신된 기록을 반환해요:

```fsharp
let birdCount = [| 3; 5; 0; 7; 4; 1 |]
incrementTodaysCount birdCount
// => [| 3; 5; 0; 7; 4; 2 |]
```

## 6. 특이한 주인지 확인하기

지난 한 해 동안, 몇몇 주가 다음과 같은 동일한 특이한 패턴을 보인다는 것을 알게 됐어요:
- 주의 짝수 번째 날마다 새가 한 마리도 없었어요
- 주의 짝수 번째 날마다 정확히 새 10마리가 관찰됐어요
- 주의 홀수 번째 날마다 정확히 새 5마리가 관찰됐어요

이번 주의 새 기록 패턴이 이 특이한 패턴 중 하나와 일치하면 `true`를 반환하는 `unusualWeek` 함수를 구현해요:

```fsharp
unusualWeek [| 1; 0; 5; 0; 12; 0; 2 |]
// => true

unusualWeek [| 5; 0; 5; 12; 5; 3; 5|]
// => true
```

(날짜의 홀짝은 0부터가 아니라 1부터 시작해요. 배열의 첫 번째 원소가 홀수 번째 날에 해당해요)
