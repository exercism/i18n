# 개요

## `for`문

`for`문은 코드 블록을 반복해서 실행해요.
첫 줄은 블록이 얼마나 자주 반복되는지를 제어해요:

```go
for init; condition; post {
    // loop body
}
```

- **init** 문은 첫 반복 전에 한 번만 실행돼요. 루프에서 사용할 카운터 변수를 선언하고 초기화하는 경우가 많아요.
- **condition**은 각 반복 전에 평가되는 불리언 표현식이에요. 이 값이 `false`로 평가되면 루프가 멈춰요.
- **post** 문은 각 반복이 끝난 뒤에 실행돼요. 카운터를 갱신하는 데 사용할 수 있어요.

`init; condition; post`는 괄호로 감싸지 않아요.
하지만 루프 본문을 감싸는 중괄호 `{ }`는 항상 필요해요.

이 루프는 `i`를 `1`로 시작해서 현재 `i` 값을 출력하고, 다음 반복을 위해 `i`를 증가시키며, `i`가 `10`에 도달하면 멈춰요:

```go
for i := 1; i < 10; i++ {
    fmt.Println(i)
}
```

## 다른 루프 형태

### 조건만 있는 루프

init과 post 문은 생략할 수 있어요.
조건만 있는 `for`문은 다른 언어의 `while`문과 같은 역할을 해요.
Go에는 `while` 키워드가 없어요.

```go
sum := 1
for sum < 1000 {
    sum += sum
}
fmt.Println(sum)
// Output: 1024
```

### 무한 루프

`for`문은 조건 없이 작성할 수 있어요:

```go
for {
    // loop body
}
```

이 루프는 스스로 종료되지 않아요.
실행은 `break`나 `return`처럼 루프를 명시적으로 빠져나와야 해요.

## 루프 제어

### Break와 Continue

이 루프에서 `break`는 루프를 빠져나와요:

```go
for n := 0; n <= 5; n++ {
    if n == 3 {
        break
    }
    fmt.Println(n)
}
// Output:
// 0
// 1
// 2
```

`continue`는 현재 루프 본문의 나머지를 건너뛰고 다음 반복을 시작해요:

```go
for n := 0; n <= 5; n++ {
    if n % 2 == 0 {
        continue
    }
    fmt.Println(n)
}
// Output:
// 1
// 3
// 5
```

### 레이블이 있는 Break와 Continue

중첩된 루프에서는 레이블이 없는 `break`나 `continue`가 가장 안쪽 루프에 적용돼요.
바깥쪽 루프에 레이블을 붙이려면, 해당 루프 바로 위 줄에 식별자와 콜론을 적어요.
그다음 `break`나 `continue` 뒤에 루프의 레이블을 적으면 동작이 그 레이블이 가리키는 루프로 향해요:

```go
OuterLoop:
for i := 0; i < 10; i++ {
    for j := 0; j < 10; j++ {
        if i + j == 10 {
            break OuterLoop
        }
    }
}
```
