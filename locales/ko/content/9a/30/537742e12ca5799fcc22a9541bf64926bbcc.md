# 지침 추가

## 예약된 메모리

입력 문자열을 위한 버퍼는 선형 메모리의 64-191번 바이트를 사용해요.


## 출력 형식

숫자 계열은 u8 숫자로 이루어진 하나의 연속된 배열로 반환해야 해요. 역직렬화 과정에서 길이에 따라 나뉘어요.

```js
slice("123456", 3) => UInt8Array[1, 2, 3,   2, 3, 4,   3, 4, 5,   4, 5, 6]
// will be split into          [[1, 2, 3], [2, 3, 4], [3, 4, 5], [4, 5, 6]]
```
