# 소개

`Option` 타입은 값이 있을 수도 있고 없을 수도 있는 상황을 다루기 위한 F# 언어의 메커니즘이에요.
다른 언어에서 이런 값을 다룰 때 흔히 쓰는 `null`을 대신할 수 있는, 타입에 안전한 대안을 제공해요.
F# 표준 라이브러리의 여러 함수에서 `Option`을 사용하기 때문에, F# 표준 라이브러리를 효과적으로 활용하려면 `Option`을 이해하는 게 꼭 필요해요.

## 사용법 

`Option` 타입은 제네릭 타입이에요(기반 타입을 가지고 있어요).  
`Option` 값은 특정 값을 나타내는 `Some value`이거나, 값이 없음을 나타내는 `None`이에요.

다음 함수는 `Option` 값을 만드는 방법을 보여줘요:

```fsharp
let keepIfPositive (a: int) : int option = if a > 0 then Some a else None
```

~~~~exercism/note
`T option`은 `Option<T>`에 해당하는 후위 표기 문법이에요. 두 문법 형태는 서로 바꿔 쓸 수 있어요.
하지만 F# 스타일 가이드에 따르면 Option 타입에는 후위 표기를 권장해요([F# 스타일 가이드의 타입 및 타입 주석 서식 지정 섹션](https://learn.microsoft.com/en-us/dotnet/fsharp/style-guide/formatting#for-types-prefer-prefix-syntax-for-generics-foot-with-some-specific-exceptions)을 참고해요). 
~~~~

## `Option` 값의 내용 읽기

`Option` 값을 읽는 관용적인 방법은 다음 예제처럼 패턴 매칭을 사용하는 거예요:

```fsharp
// Returns "Hello, <name>!" if the name is provided; otherwise returns "Hello, you!"
let sayHello (optionalName: string option): string = 
    match optionalName with
    | Some name -> "Hello, " + name + "!"
    | None -> "Hello, you!"

sayHello (Some "Matthieu")
// --> "Hello, Matthieu!"

sayHello None
// --> "Hello, you!"
```

## 기본값으로 Option 풀어내기

`Option`은 `Option.defaultValue` 함수에 기본값을 넘겨서 "풀어낼" 수 있어요(값을 감싸고 있는 타입으로 변환돼요). 
값이 `None`이 아님을 보장하고 싶을 때 특히 유용해요.
예를 들어 볼까요:

```fsharp
Option.defaultValue "" (Some "F#")
// --> "F#"

Option.defaultValue 0 None
// --> 0
```
