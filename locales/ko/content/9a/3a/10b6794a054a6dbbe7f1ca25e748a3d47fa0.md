# 개요

기본적으로 변수는 자신이 정의된 스코프로 제한돼요. 함수나 클래스 바깥의 파일에서 정의하면 파일 스코프로 제한되고, 함수나 클래스 안에서 정의하면 그 함수나 클래스의 스코프로 제한돼요.

```php
<?php

$file_scoped = "I am file scoped";

function example(): void
{
  $function_scoped = "I am function scoped!";
}
```

## 전역 스코프

변수를 할당할 때 `global` 키워드를 앞에 붙이면 전역 스코프를 가진 변수가 만들어져요. 이런 방식은 [강하게 결합된 코드](<https://en.wikipedia.org/wiki/Coupling_(computer_programming)#Disadvantages_of_tight_coupling>)를 만들기 때문에 흔히 권장되지 않아요.

```php
function example(): void
{
  global $hello = "World!";
}

echo $hello; // #=> "World!"
```

## 정적 스코프

변수를 할당하거나 선언할 때 `static` 키워드를 앞에 붙이면 변수의 스코프는 그대로 유지되지만, 값은 실행 스코프 사이에서 보존돼요.

```php
function counter(): int
{
  static $count = 0;
  $count += 1;
  return $count;
}
```

이 예제에서 `$count` 변수는 _함수를 처음 호출할 때만_ 0으로 초기화돼요. 그다음 호출부터는 이전 값이 다음 호출로 이어져요. 그래서 함수를 호출할 때마다 점점 커지는 정수가 반환돼요.
