# 지시 사항

여러분은 태평양 북서부 지역의 날씨 데이터를 분석하는 회사에서 일하는 데이터 분석가예요.
이번에는 다음 컬럼으로 이루어진 `weather_readings` 테이블이 들어 있는 데이터베이스로 작업하게 돼요.

* `date`: 샘플을 수집한 날짜예요.
* `location`: 샘플을 수집한 도시 이름이에요.
* `temperature`: 화씨 기준 온도예요.
* `wind_speed`: 시속 마일 기준 풍속이에요.

다음에 나오는 각 과제에서 해야 할 일은 `SELECT`문을 사용해 지정된 결과 집합을 가져오는 거예요.
이때 결과 집합은 미리 작성된 `CREATE TABLE`문을 통해 과제마다 새 테이블 하나에 저장된다는 점을 기억해 두세요.
지금은 `CREATE TABLE`문은 걱정하지 않아도 돼요. 다른 레슨에서 다룰 내용이거든요.
주어진 과제를 해결하는 데 알맞은 `SELECT`문을 추가하는 데만 집중해요.

## 1. 모든 데이터 가져오기

`weather_readings` 테이블에서 모든 데이터를 가져와요.

## 2. location과 temperature 데이터만 가져오기

`weather_readings` 테이블에서 location 값과 temperature 값만 가져와요.

## 3. 시애틀 데이터만 가져오기

시애틀 지역의 데이터만 가져와요.

## 4. 특정 범위의 풍속 데이터만 가져오기

풍속이 시속 5마일에서 15마일 사이인 데이터만 가져와요.
