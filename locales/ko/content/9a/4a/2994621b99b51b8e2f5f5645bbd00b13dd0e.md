# 지침

가까운 지역 학교에는 아주 활발한 학생회가 있어요.
학생회는 회장이 이끌고 있으며, 2년마다 한 번씩 새 회장을 뽑는 선거를 치러요.

올해 선거에서는 투표를 집계할 새로운 디지털 시스템이 필요하다고 결정했어요. 학교는 이 새로운 시스템을 만드는 데 도움이 필요해요.

## 1. `ElectionResult`에서 투표 수 가져오기

새 시스템에는 카운터에서 투표 수를 가져오는 방법이 필요해요.

선거 결과 구조체는 이미 만들어져 있고, 다음과 같이 정의되어 있어요:

```cpp
struct ElectionResult {
    // Name of the candidate
    std::string name{};
    // Number of votes the candidate has
    int votes{};
};
```

`struct`의 모든 멤버가 public이기 때문에, `ElectionResult` 객체를 초기화하기 위해 `constructor`를 작성할 필요가 없어요.
대신 `initializer list`를 사용할 수 있어요:

```cpp
ElectionResult hamilton{"Alex", 1804};
// => the hamilton object was initialized with the name "Alex" and 1804 votes.
```

`ElectionResult`에 대한 참조를 인자로 받아 `ElectionResult`의 투표 수를 반환하는 함수 `vote_count`를 만들어요.

```cpp
vote_count(hamilton);
// => 1804
```

## 2. `ElectionResult`의 투표 수 증가시키기

드디어 투표를 처리할 시간이에요!
이제 `ElectionResult`의 투표 수를 증가시키는 방법이 필요해요.

`ElectionResult`에 대한 참조와 투표 수를 인자로 받아, 그 투표 수만큼 `ElectionResult`를 증가시키는 `void` 함수 `increment_vote_count`를 만들어요.

```cpp
ElectionResult burr{"Aaron " 1801};

increment_vote_count(burr, 3);

vote_count(burr);
// => 1804
```

## 3. 개표와 회장 선출

학교가 투표를 제출했고, 이제 당선자를 확인할 시간이에요.

최종 집계에 대한 참조를 받아, 새 회장의 `ElectionResult`에 대한 참조를 반환하는 함수 `determine_result`를 만들어요.
이 함수는 당선자의 이름 앞에 "President"를 붙여 이름도 바꿔야 해요.
최종 집계는 참여한 모든 후보의 `ElectionResults`를 담은 `std::vector<ElectionResult>`에 대한 `reference` 형태로 주어져요.

```cpp
ElectionResult sanchez{"Pedro", 471};
ElectionResult wheatley{"Summer", 340};
std::vector<ElectionResult> final_count{sanchez, wheatley};

ElectionResult& winner = determine_result(final_count);

winner.name;
// => "President Pedro"
```

간단하게 하기 위해, 다음과 같다고 가정해도 돼요:
- `vector`에는 요소가 최소한 하나 있어요.
- 1위 동점은 없어요.
