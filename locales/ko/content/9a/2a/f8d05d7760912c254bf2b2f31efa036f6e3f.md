# 지침

체스를 좋아한다면 누구나 자기만의 체스 게임을 한번 만들어 보고 싶어 하죠. 물론 온라인에는 이미 다양한 체스 구현이 넘쳐나지만, 직접 만드는 건 세상에 하나뿐일 거예요!

그렇지만 상상의 나래를 펼치기 전에 기본적인 것부터 챙겨야 해요. 먼저 체스판을 만들어 보는 것부터 시작해요.

체스판의 각 칸은 문자와 숫자 쌍으로 식별해요. 세로 방향으로 놓인 칸 줄은 파일이라고 하고, A부터 H까지 이름을 붙여요. 가로 방향으로 놓인 칸 줄은 랭크라고 하고, 1부터 8까지 번호를 붙여요.

## 1. 랭크 범위 정의하기

`rank_range()` 함수를 구현해요. 1부터 8까지의 정수 범위를 반환해야 해요.

```julia-repl
julia> rank_range()
# output omitted
```

## 2. 파일 범위 정의하기

`file_range()` 함수를 구현해요. 
대문자 A부터 대문자 H까지의 문자 범위를 반환해야 해요.

```julia-repl
julia> file_range()
# output omitted
```

## 3. 랭크 범위를 랭크 벡터로 바꾸기

`ranks()` 함수를 구현해요. 1부터 8까지의 정수 벡터를 반환해야 해요. 
벡터를 직접 손으로 쓰지 말고, `rank_range()` 함수가 반환한 범위에서 만들어요.

```julia-repl
julia> ranks()
[1, 2, 3, 4, 5, 6, 7, 8]
```

## 4. 파일 범위를 파일 벡터로 바꾸기

`files` 함수를 구현해요. 'A'부터 'H'까지의 문자 벡터를 반환해야 해요. 
벡터를 직접 손으로 쓰지 말고, `file_range()` 함수가 반환한 범위에서 만들어요.

```julia-repl
julia> files()
['A', 'B', 'C', 'D', 'E', 'F', 'G', 'H']
```
