# 배열 소개

Bash에는 두 가지 종류의 매개변수가 있어요: "스칼라" 값과 배열이에요.
스칼라 값은 문자열이나 숫자가 될 수 있고, 하나의 "것"을 나타내요.

대부분의 경우 스칼라 값만으로도 데이터를 담기에 충분해요.
하지만 때로는 스칼라 값의 목록을 저장해야 할 때가 있어요.
이럴 때 _배열_을 사용해요.

배열에는 두 가지 종류가 있어요:

* 숫자로 인덱싱된 배열은 정수 키를 문자열 값에 연결해요.
  (다른 언어에서는 이것을 "리스트"나 "시퀀스"라고 부르기도 해요.)
* 연관 배열은 문자열 키를 문자열 값에 연결해요.
  (다른 언어에서는 이것을 "맵"이나 "딕셔너리"라고 부르기도 해요.)

이 문서의 처음 몇 절에서는 숫자로 인덱싱된 배열(이하 간단히 "배열")을 다뤄요.
연관 배열에 대한 자세한 내용은 마지막에 나와요.

~~~~exercism/caution
Bash 배열은 스칼라 값_만_ 저장할 수 있어요.
2차원 배열(배열의 배열)을 만드는 방법은 없어요.
~~~~

## 배열 변수 선언과 초기화

괄호로 묶은 원소 목록(비어 있을 수도 있어요)을 변수에 할당하면 배열을 초기화할 수 있어요.

```bash
myarray=("one" "two" "three")
```

모든 변수 할당에서 그렇듯, 등호 주위에는 공백이 있으면 안 돼요.

원소 사이에 쉼표 구분자는 없고, 공백으로 구분된 문자열 목록이라는 점에 주의해요.

사실 괄호 안의 공백은 전혀 상관없어요.
줄바꿈도 허용되니, 가독성을 높이고 싶은 만큼 자유롭게 써요.

```bash
myarray=(
    "first element"
    "second element"
    "this is the last element"
)
```

이렇게 문자열 목록을 배열 변수에 할당하면 첫 번째 문자열은 인덱스 0에, 다음 문자열은 인덱스 1에, 그다음은 인덱스 2에 저장돼요.

필요한 인덱스를 직접 지정해서 "희소 배열"을 초기화할 수도 있어요.

```bash
raindrops=([3]="Pling" [5]="Plang [7]="Plong")
```

~~~~exercism/note
다시 말하지만, 배열 인덱스는 0부터 시작해요.
다음 코드는 "true"를 출력해요:

```bash
myarray=("one" "two" "three")
[[ "${myarray[0]}" == "one" ]] && echo true || echo false
```
~~~~

`declare` 명령(함수 안에서는 `local`)을 사용해서 변수가 배열을 담을 것이라고 지정할 수 있어요.

```bash
declare -a myarray
```

그냥 (비어 있을 수도 있는) 괄호 목록을 할당해서 변수를 초기화하는 쪽이 더 자연스러워요.

## 배열의 원소에 접근하기

위 노트에서 봤듯이, 배열 원소에 접근하는 문법은 `${myarray[$index]}`예요.
인덱스는 대괄호 안에 써요.
중괄호는 꼭 필요해요.

~~~~exercism/note
숫자로 인덱싱된 배열에서 인덱스는 산술 표현식이에요.
Bash 매뉴얼[에는][arithmetic] 이렇게 나와 있어요:

> 산술 표현식 안에서는 매개변수 확장 문법을 사용하지 않고 이름만으로 셸 변수를 참조할 수도 있어요.

즉 "단순한" 변수 확장에는 `$`가 필요 없다는 뜻이에요.
다음과 같이 원소에 접근하면 조금 더 읽기 쉬워요:

```bash
i=5
echo "${myarray[i]}"
# ..............^
```

[arithmetic]: https://www.gnu.org/software/bash/manual/bash.html#Shell-Arithmetic
~~~~

주어진 인덱스가 배열에 없으면 확장 결과는 빈 문자열이에요.

## 배열에 할당하기

특정 배열 항목에 값을 할당하려면 다음 문법을 사용해요:

```bash
myarray[10]="hello"
```

배열에 값을 _덧붙이려면_ 이어 붙이는 할당 연산자 `+=`와 괄호를 사용해요:

```bash
myarray+=("new element 1" "new element 2")
```

## 배열 순회하기

보통 배열의 _값_을 순회해야 할 때가 많아요.
([반복][looping] 개념에서 본) `for`문을 사용해요:

```bash
myarray=("one" "two" "three")
for value in "${myarray[@]}"; do
    echo "$value"
done
```

배열을 확장하는 특별한 문법 `"${myarray[@]}"`에 주목해요.
이 매개변수 확장 형태는 배열 값을 각각 별개의 단어로 치환해요.
다음 코드와 어느 정도 같은 의미예요:

```bash
for value in "${myarray[0]}" "${myarray[1]}" ... "${myarray[n]}"
```

`"${myarray[@]}"` 형태는 희소 배열에도 쓸 수 있고, 정의된 값만 확장해요.

인덱스가 앰퍼샌드(`@`)인 이 특별한 확장은 큰따옴표 안에서만 특별하게 동작해요.

#### 그 밖의 특별한 매개변수 확장

배열을 순회할 때 필요한 특별한 문법이 몇 가지 더 있어요.
이런 문법은 매뉴얼의 [셸 매개변수 확장][man-expn]에 설명되어 있어요.

배열의 _길이_를 구하려면 이름 앞에 `#`를 붙인 `${#myarray[@]}`를 사용해요.
배열의 "길이"는 배열에 들어 있는 원소의 개수를 뜻해요.

배열의 _인덱스_ 목록을 얻으려면 이름 앞에 `!`를 붙이고 확장을 큰따옴표로 감싼 `"${!myarray[@]}"`를 사용해요.
숫자로 인덱싱된 배열에서는 인덱스가 숫자 순서대로 확장돼요.

### 배열 인덱스로 순회하기

값뿐 아니라 인덱스도 필요할 때가 있어요.
방법은 몇 가지가 있어요.

1. 인덱스가 끊김 없이 이어지는 것을 알고 있을 때는 _산술_ `for`문을 사용할 수 있어요.

   ```bash
   for ((i = 0; i < ${#myarray[@]}; i++)); do
       echo "$i -> ${myarray[i]}"
   done
   ```

   배열 이름 앞에 `#` 문자가 붙은 `${#myarray[@]}` 문법에 주목해요.
   배열은 0부터 시작하는 인덱싱을 사용하므로, 배열의 마지막 인덱스는 배열 길이보다 하나 작아요.

2. 배열이 희소할 때는 다음 형태를 사용할 수 있어요:

   ```bash
   for index in "${!raindrops[@]}"; do
       echo "$index -> ${raindrops[index]}"
   done
   ```

   배열 이름 앞에 `!` 문자가 붙은 `${!myarray[@]}` 문법에 주목해요.

## 배열 살펴보기

배열의 내용을 보고 싶다면 `-p` 옵션과 함께 `declare` 명령을 사용해요:

```bash
a=("the 'first' element"
   second
   third
   'the "last" element')
declare -p a
```

그러면 셸의 표준 인용 형식으로 내용이 출력돼요.

```bash
declare -a a=([0]="the 'first' element" [1]="second" [2]="third" [3]="the \"last\" element")
```

## 연관 배열

다시 말하지만, 연관 배열은 숫자가 아니라 문자열을 인덱스로 사용해요.
위에서 설명한 내용은 연관 배열에도 그대로 적용되지만, 작은 차이가 있어요.
보통은 "인덱스"가 아니라 "키"라는 용어를 사용해요. 연관 배열은 키를 값에 연결하니까요.

### 연관 배열 선언하기

일반 배열과 달리 연관 배열은 **반드시** 선언해야 해요.
`declare`(함수 안에서는 `local`)에 `-A` 옵션을 사용해요:

```bash
declare -A mymap

myfunc() {
    local -A my_local_map
    # ...
}
```

### 연관 배열 초기화하기

키-값 쌍은 괄호 목록 안에 지정해요:

```bash
mymap=([first]=foo [second]=bar [third]=baz)
declare -p mymap
```

그러면 다음과 같이 출력돼요:

```
declare -A mymap=([second]="bar" [first]="foo" [third]="baz")
```

~~~~exercism/note
연관 배열은 **순서가 없다**는 점을 기억해요.
~~~~

선언과 초기화는 한 줄에서 함께 할 수 있어요.

```bash
declare -A mymap=([first]=foo [second]=bar [third]=baz)
```

최근 Bash 버전에서는 `(key value key value ...)` 목록으로 초기화할 수 있어요.

```bash
declare -A mymap=(first foo second bar third baz)
```

### 값에 접근하기

원소에 접근할 때는 앞에서와 같은 문법 `${mymap[$key]}`을 사용해요.

연관 배열의 키는 산술 문맥에서 평가되지 않아요.
일반적인 매개변수 확장 문법을 사용해야 해요.

### 연관 배열에 할당하기

할당에도 앞에서와 같은 문법을 사용해요:

```bash
mymap[$key]="$value"
```

### 순회하기

`for value in "${mymap[@]}"` 루프로 순회할 수 있어요.
하지만 보통은 값과 함께 키도 필요하죠.

위에서 본 `"${!mymap[@]}"` 문법을 사용해요.

```bash
for key in "${!mymap[@]}"; do
    echo "$key -> ${mymap[$key]}"
done
```

그러면 다음과 같이 출력돼요

```
second -> bar
first -> foo
third -> baz
```

다시 강조하자면, 키에는 순서가 없어요.
