# 힌트

## 일반

- 이 연습 문제의 모든 메모리 주소는 16바이트로 정렬되어 있어요. 그래서 정렬된 이동 명령(`movdqa`는 정수용, `movaps`는 실수용)을 사용하는 게 적절해요.
  정렬된 주소는 메모리 소스 피연산자로 직접 사용할 수도 있어요.

## 1. 이미지를 표시 순서로 변환

- 각 4바이트 픽셀 안에서 이 변환은 오프셋 `0`(빨강)의 바이트와 오프셋 `2`(파랑)의 바이트를 서로 바꾸고, 오프셋 `1`(초록)과 `3`(알파)은 그대로 둬요.
  같은 패턴이 네 픽셀 모두에서 반복돼요.
- [셔플][pshufb]을 사용하면 제어 벡터의 인덱스에 따라 바이트 순서를 제자리에서 바꿀 수 있어요.
- 제어 벡터는 메모리에 정의할 수 있어요.
- 블록이 여러 개일 수 있고, 각 블록은 16바이트예요.

## 2. 영역을 한 가지 색으로 채우기

- 색은 하나의 4바이트 픽셀이에요.
  이걸 한 번에 16바이트씩 저장하려면 먼저 `xmm` 레지스터의 네 레인 전체로 [브로드캐스트][pshufd]해야 해요.
- 4바이트 픽셀은 브로드캐스트하기 전에 먼저 `xmm` 레지스터로 [이동][pinsrd]해야 해요.
- 채워진 블록은 모두 동일하니, 채운 레지스터를 한 번 만들어 둔 뒤 재사용하면 돼요.
- 블록이 여러 개일 수 있고, 각 블록은 16바이트예요.

## 3. 두 스캔라인 엮기

- [unpack][unpack] 명령을 사용하면 두 피연산자의 바이트를 서로 교차시킬 수 있어요.
- 두 unpack 명령 모두 각 쌍의 첫 번째 바이트는 목적지 피연산자에서, 두 번째 바이트는 소스 피연산자에서 가져와요.

## 4. 밝게 한 행 패킹하기

- [pack][pack] 명령을 사용하면 레인을 좁히면서 클램핑할 수 있어요.
- pack 명령은 낮은 레인은 목적지 피연산자에서, 높은 레인은 소스 피연산자에서 가져와요.

## 5. 좌표를 x와 y로 나누기

- [부동소수점 셔플][shufps]을 사용하면 두 피연산자에서 레인을 선택하고 재정렬할 수 있어요.
- `x` 좌표는 각 입력의 짝수 레인(`0`과 `2`)에, `y` 좌표는 홀수 레인(`1`과 `3`)에 있어요.
