# 소개

인터페이스는 클래스의 시그니처로 이해할 수 있어요. 클래스의 공개 필드를 설명하기 때문이에요. 클래스는 `implments` 키워드로 `interface`를 _구현_해요.

문법은 클래스와 아주 비슷한데, 메서드가 본문 없이 시그니처로만 나타난다는 점이 달라요:

```haxe
interface Language {
  private var languageName:String;

  public function speak():String;
}

class FrenchSpeaker implements Language {
  var languageName = "French";

  public function speak():String {
    return "Bonjour!";
  }
}
```

인터페이스에서 구현되는 필드는 **반드시** 같은 가시성 제어자를 사용해야 해요. 예를 들어, 인터페이스에서 변수 `a`가 `public`이라면, 이를 구현한 쪽에서도 `public`이어야 해요.
