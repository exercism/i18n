# 테스트

CLI 도구로 연습 문제를 내려받았다면, 연습 문제 이름을 딴 Uiua 파일과 `tests.ua` 파일이 보일 거예요.
이 파일에는 모든 테스트 케이스가 들어 있는데, 해답을 업로드할 때 테스트 러너가 실행하는 테스트와 같아요.
실험해 보고 싶다면 테스트 케이스를 얼마든지 더 추가해도 괜찮아요.
다만, 테스트를 수정해도 온라인 테스트 러너 과정에는 영향을 주지 않아요.

## 로컬에서 테스트하기

연습 문제의 테스트를 실행하려면, 연습 문제 디렉터리에서 터미널을 열고 `uiua test tests.ua` 명령을 실행해요.

예를 들어, 수정하지 않은 `hello-world` 연습 문제의 출력은 다음과 같을 수 있어요:

```bash
$ uiua test tests.ua
Error: Goodbye, Mars!
  at tests.ua:3:1
3 | ⍤⤙≍ "Hello, World!" Hello
    ─
Test failed
```

`Error` 줄은 작성한 코드의 실제 출력을 보여줘요.
줄 번호는 `tests.ua`에서 기대하는 결과가 있는 위치를 알려줘요.
올바른 해답은 다음을 출력해요:

```bash
$ uiua test tests.ua
Test passed
```
