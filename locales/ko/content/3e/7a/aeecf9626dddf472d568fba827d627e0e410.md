# 지침 추가

## 레지스터

| 레지스터 | 용도      | 타입    | 설명                                                                               |
| -------- | --------- | ------- | ---------------------------------------------------------------------------------- |
| `$a0`    | 입력      | 정수    | 변 a                                                                               |
| `$a1`    | 입력      | 정수    | 변 b                                                                               |
| `$a2`    | 입력      | 정수    | 변 c                                                                               |
| `$v0`    | 출력      | 정수    | 삼각형의 종류 (`0` = scalene, `1` = isoceles, `2` = equilateral, `3` = invalid)     |
| `$t0-9`  | 임시      | 아무 값 | 임시 저장에 사용                                                                    |
