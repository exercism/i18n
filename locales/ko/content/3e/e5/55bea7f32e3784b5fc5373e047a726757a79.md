# 지시 사항

동네에 피자 조각 가게가 여러 곳 있는데, 두 가지 피자 구성을 비교해서 어느 가게가 더 큰 조각을 주는지 알려 주는 웹앱을 만들려고 해요.

## 1. 잘못된 입력에는 nil을 반환하는 조각 크기 계산 함수를 작성해요

피자의 지름과 피자 한 판의 조각 수를 받아 조각의 넓이를 반환하는 함수 `sliceSize(diameter: Double?, slices: Int?) -> Double?`를 구현해요.
지름이 음수이거나 조각 수가 1보다 작으면 `nil`을 반환해요. 지름이 음수인 피자는 있을 수 없고, 피자를 1조각보다 적게 자를 방법도 없으니까요.
두 매개변수 중 하나라도 `nil`이면 역시 `nil`을 반환해요.

```swift
sliceSize(diameter: 16, slices: 12)
// Returns 16.75516081914556
sliceSize(diameter: nil, slices: 8)
// Returns nil
```

## 2. 웹 애플리케이션에서 받은 입력을 처리해서 더 큰 조각을 판별해요

웹 애플리케이션은 함수 `biggestSlice(diameterA: String, slicesA: String, diameterB: String, slicesB: String) -> String`에 네 개의 문자열을 전달해요.
첫 번째와 두 번째 문자열은 각각 첫 번째 피자의 지름과 조각 수이고, 세 번째와 네 번째는 각각 두 번째 피자의 지름과 조각 수예요.

`biggestSlice`를 구현할 때는 각 피자의 지름과 조각 수를 각각 `Double`과 `Int`로 변환해 보도록 해요.
두 값을 모두 문자열에서 얻을 수 있으면 앞서 만든 함수로 넓이를 계산해 보고, 그렇지 않으면 그 조각의 넓이는 `nil`이에요.
두 조각의 넓이를 모두 구했으면, 다음 규칙에 따라 두 넓이를 비교해요:

1. A 조각의 넓이가 `Double`이고 B 조각의 넓이가 `nil`이면 "Slice A is bigger"를 반환해요. 그 반대라면 "Slice B is bigger"를 반환해요.
2. 두 넓이가 모두 `Double`이면, 넓이가 더 큰 조각에 따라 "Slice A is bigger" 또는 "Slice B is bigger"를 반환해요.
3. 두 넓이가 모두 `nil`이거나, 둘 다 `Double`이고 서로 같으면 "Neither slice is bigger"를 반환해요.

~~~~exercism/note
입력의 결과로 나온 조각의 넓이가 0이더라도 그 조각은 여전히 유효한 것으로 간주하며, 넓이가 `nil`인 조각보다 큰 것으로 봐요.
~~~~

```swift
biggestSlice(diameterA: "10", slicesA: "6", diameterB: "14", slicesB: "12")
// Returns "Slice A is bigger"
biggestSlice(diameterA: "10", slicesA: "6", diameterB: "12", slicesB: "8")
// Returns "Slice B is bigger"
biggestSlice(diameterA: "Pepperoni", slicesA: "6", diameterB: "Sausage", slicesB: "12")
// Returns "Neither slice is bigger"
```
