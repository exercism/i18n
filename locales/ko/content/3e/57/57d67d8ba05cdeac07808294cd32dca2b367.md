# 소개

**word**는 Factor가 함수를 부르는 이름이에요. `basics`에서 다룬 데이터 스택을 바탕으로, 이번 개념에서는 직접 word를 정의하는 방법을 살펴봐요. 산술 연산을 하고, 고정된 값에 이름을 붙이고, word를 다른 word로 조합하는 거예요.

정의는 `:`로 시작해서 스택 효과를 적고, 본문을 쓴 다음, `;`로 끝내요. 컴파일러는 본문이 선언한 스택 효과와 맞는지 확인해요.

```factor
: square ( x -- x*x ) dup * ;

4 square .    ! => 16
```

정수 산술 word인 `+`, `-`, `*`는 각각 숫자 두 개를 꺼내서 결과를 스택에 넣어요. 이들은 `math` vocabulary에 들어 있어서, 이것들을 사용하는 파일은 `USING:` 줄에 `math`를 적어야 해요. 스택의 맨 위에 있는 값이 오른쪽 피연산자예요.

```factor
2 3 + .    ! => 5
8 3 - .    ! => 5    (8 - 3, not 3 - 8)
2 3 * .    ! => 6
```

`CONSTANT:`는 고정된 값에 이름을 붙여요. 상수 자체도 word예요. 상수를 호출하면 그 값이 스택에 들어가요.

```factor
CONSTANT: pi 3

pi pi * .    ! => 9
```

word의 본문에서는 이미 스코프에 있는 어떤 word든 호출할 수 있어요. 같은 파일에서 앞서 정의한 word도 마찬가지예요.

```factor
: double    ( x -- 2x ) 2 * ;
: quadruple ( x -- 4x ) double double ;

5 quadruple .    ! => 20
```

출력 부분에 붙는 `?`는 불리언을 뜻하는 관례예요. word와 상수 이름은 둘 다 `lowercase-kebab-case`를 사용해요.
