# 지침

마법사 지망생 Elyse는 훈련을 계속해요. Elyse는 마술을 부리기 위해 여러 개의 카드 더미를 받아요.
조금 더 쉽게 하기 위해 Elyse는 1부터 10까지의 카드만 사용해요.

이 연습 문제에서는 내장 메서드를 사용해 배열의 내용을 분석해요.

## 1. 카드의 위치 찾기

Elyse는 카드 더미에서 카드의 위치(인덱스)를 알고 싶어요.

```javascript
const card = 2;
getCardPosition([9, 7, 3, 2], card);
// => 3
```

## 2. 카드가 있는지 확인하기

Elyse는 카드가 더미 안에 있는지, 다시 말해 더미에 특정 `number`가 들어 있는지 알고 싶어요.

```javascript
const card = 3;
doesStackIncludeCard([2, 3, 4, 5], card);
// => true
```

## 3. 각 카드가 짝수인지 확인하기

Elyse는 모든 카드가 짝수인지, 다시 말해 더미의 각 숫자가 짝수 `number`인지 알고 싶어요.

```javascript
isEachCardEven([2, 4, 6, 7]);
// => false
```

## 4. 카드 더미에 홀수 카드가 있는지 확인하기

Elyse는 더미에 홀수가 있는지 알고 싶어요.

```javascript
doesStackIncludeOddCard([3, 2, 6, 4, 8]);
// => true
```

## 5. 카드 더미에서 첫 번째 홀수 카드 가져오기

Elyse는 처음으로 나오는 홀수 카드의 값을 알고 싶어요.

```javascript
getFirstOddCard([4, 2, 8, 7, 9]);
// => 7
```

## 6. 첫 번째 짝수 카드의 위치 확인하기

Elyse는 처음으로 나오는 짝수 카드의 위치를 알고 싶어요.

```javascript
getFirstEvenCardPosition([5, 2, 3, 1]);
// => 1
```
