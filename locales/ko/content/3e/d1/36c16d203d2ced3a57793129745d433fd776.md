# 지시 사항

이번 연습 문제에서는 미용실 예약 스케줄러를 만들어 봐요.

과제는 세 가지이고, 모두 예약 날짜를 다뤄요.

## 1. 예약이 이미 지났는지 확인하기

`appointment_has_passed` 서브루틴을 구현해요. 이 서브루틴은 날짜 문자열을 받아서 예약이 과거에 있었는지 확인해요:

```perl
appointment_has_passed("2019-07-25T13:45:00")
// => true
```

날짜 문자열은 ISO 8601 날짜 및 시간 형식인 `YYYY-mm-ddTHH:MM:SS`로 전달돼요.

비공개 서브루틴 `_parse_datetime`도 구현해야 해요.
몇 가지 모듈을 추천해요:

- [Time::Piece][time-piece]는 Perl의 코어 모듈이에요.
- [DateTime::Tiny][datetime-tiny]는 CPAN에서 사용할 수 있어요.

## 2. 예약이 오후인지 확인하기

`is_afternoon_appointment` 함수를 구현해요. 이 함수는 날짜 문자열을 받아서 예약이 오후(12:00 이상, 18:00 미만)인지 확인해요:

```perl
is_afternoon_appointment("2019-07-25T13:45:00")
// => true
```

## 3. 예약의 시간과 날짜 설명하기

`describe_appointment` 함수를 구현해요. 이 함수는 날짜 문자열을 받아서 그 날짜와 시간에 대한 설명을 반환해요:

```perl
describe_appointment("2019-07-25T13:45:00")
// => "You have an appointment on 07/25/2019 1:45 PM"
```

참고로 시간은 0-12 범위이고, 앞에 0이나 공백이 붙지 않아요.

[time-piece]: https://perldoc.perl.org/Time::Piece
[datetime-tiny]: https://metacpan.org/pod/DateTime::Tiny
