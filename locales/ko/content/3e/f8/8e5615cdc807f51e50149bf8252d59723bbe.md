# 힌트

## 일반

- `double`과 함께 동작하는 일반적인 수학 연산과 변환에 대해 알아보려면 [`cmath` 레퍼런스][cmath-reference]를 살펴봐요.

## 1. 시급이 주어졌을 때 일당 계산하기

- 인자 하나는 `int`이고 다른 하나는 `double`인 기본 산술 연산은 `double`을 반환해요.

## 2. 할인된 가격 계산하기

- 인자 하나는 `int`이고 다른 하나는 `double`인 기본 산술 연산은 `double`을 반환해요.

## 3. 시급과 할인이 주어졌을 때 월급 계산하기

- 올림을 해 주는 [`cmath` 헤더의 함수][cmath-ceil]가 있어요.

## 4. 예산과 시급, 할인이 주어졌을 때 근무일 수 계산하기

- `doubles`을 `int`로 캐스팅하면 소수점 아래 숫자가 잘려요.
