# 지침

이 연습 문제에서는 [바둑 게임의 규칙](https://matmoore.github.io/learngo/)을 적용해 볼 거예요. 규칙 자체는 이미 작성되어 있으니, 규칙을 적용해서 Game을 갱신하고 오류나 규칙 위반을 처리하기만 하면 돼요.

게임은 다음과 같이 표현돼요:

```elm
type Player
    = Black
    | White


type alias Game =
    { whiteCapturedStones : Int
    , blackCapturedStones : Int
    , player : Player
    , error : String
    }
```

게임에는 규칙이 네 가지 있어요:

- 각 점에는 돌을 하나만 놓을 수 있어요 (`oneStonePerPointRule`)
- 상대방의 돌을 잡을 수 있어요! (`captureRule`)
- 스스로 잡히게 되는 자리에는 돌을 놓을 수 없어요 (`libertyRule`)
- 같은 점을 두 번 사용할 수 없어요 (`koRule`)

## 1. 규칙 적용하기

`applyRules` 함수의 내용을 작성해 보세요. 이 함수는 초기 `Game`과 규칙 집합을 받아서, 규칙이 적용된 뒤의 새로운 `Game`을 반환해요.

`oneStonePerPointRule`, `libertyRule`, `koRule`은 모두 규칙 위반을 검사하고 오류를 반환할 수 있어서 반환 타입이 `Result String Game`이에요. 이 규칙 중 하나라도 실패하면 원래 게임을 반환하되, `error` 필드를 해당 오류로 갱신해야 해요.

`captureRule`은 위반을 검사하지 않으므로 실패할 수 없고(변경된 `Game`을 반환할 수는 있어요), 따라서 반환 타입이 `Game`이에요.

모든 규칙을 통과하면 규칙으로 인한 `Game`의 변경 사항을 유지하고 플레이어를 바꿔야 해요. 이때 `changePlayer` 함수가 제공돼요.

```elm
applyRules : Game -> Rule -> NonValidatingRule -> Rule -> Rule -> Game
applyRules game oneStonePerPointRule captureRule libertyRule koRule =
--> If all rules pass, return a `Game` with all changes from the rules applied, and changePlayer
--> If any rule fails, return the original Game, but with the error field set
```
