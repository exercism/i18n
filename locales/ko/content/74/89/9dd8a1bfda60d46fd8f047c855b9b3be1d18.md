# 소개

프로그래밍에서 텍스트를 다루는 일은 흔해요.
Swift는 Foundation 프레임워크와 함께 문자열을 살펴보고, 변환하고, 다룰 수 있는 편리한 메서드와 속성을 많이 제공해요.

## `components(separatedBy:)`로 문자열 나누기

구분자를 기준으로 문자열을 부분 문자열로 이루어진 배열로 나누려면 `components(separatedBy:)`를 사용해요. 이때 Foundation을 import해야 해요.

```swift
import Foundation

let sentence = "Hello, world!"
let words = sentence.components(separatedBy: " ")
print(words) // Prints ["Hello,", "world!"]
```

## `hasPrefix(_:)`와 `hasSuffix(_:)`로 접두사와 접미사 확인하기

문자열이 특정 문자 시퀀스로 시작하거나 끝나는지 확인하려면 `hasPrefix(_:)`와 `hasSuffix(_:)`를 사용해요.

```swift
let greeting = "Hello, world!"
print(greeting.hasPrefix("Hello"))  // Prints true
print(greeting.hasSuffix("world!")) // Prints true
```

## 대소문자 바꾸기

다음 표준 메서드와 속성을 사용하면 문자열의 대소문자를 바꿀 수 있어요.

- `lowercased()`: 문자열의 소문자 복사본을 반환해요.
- `uppercased()`: 문자열의 대문자 복사본을 반환해요.
- `capitalized`: 각 단어의 첫 글자를 대문자로 만든 복사본을 반환해요(Foundation에 있어요).

```swift
let greeting = "hello, world!"
print(greeting.lowercased())  // Prints "hello, world!"
print(greeting.uppercased())  // Prints "HELLO, WORLD!"
print(greeting.capitalized)   // Prints "Hello, World!"
```

## `replacingOccurrences(of:with:)`로 부분 문자열 바꾸기

대상 부분 문자열이 나타나는 곳을 모두 다른 문자열로 바꾸려면 `replacingOccurrences(of:with:)`를 사용해요(Foundation에 있어요).

```swift
let greeting = "Hello, world!"
let updated = greeting.replacingOccurrences(of: "world", with: "Swift")
print(updated) // Prints "Hello, Swift!"
```

## `joined(separator:)`로 문자열 합치기

`joined(separator:)` 메서드는 `[String]`처럼 문자열의 컬렉션에 속해요.
구분자를 사용해 원소들을 하나의 문자열로 합쳐요.

```swift
let words = ["Hello", "world"]
let sentence = words.joined(separator: ", ")
print(sentence) // Prints "Hello, world"
```
