# 지침

이 연습 문제에서는 클래식 게임 Pac-Man의 규칙 몇 가지를 C++ 함수로 구현해야 해요.

옮겨야 할 규칙은 네 가지이고, 모두 게임 상태와 관련되어 있어요.

> 인자가 어떻게 만들어지는지는 걱정할 필요가 없어요. 그냥 인자들을 조합해 원하는 결과를 반환하는 데만 집중해요.

## 1. Pac-Man이 유령을 먹을 수 있는지 정의하기

`can_eat_ghost` 함수는 두 개의 인자(_Pac-Man의 파워 펠릿이 활성화되어 있는지_와 _Pac-Man이 유령에 닿았는지_)를 받아 Pac-Man이 유령을 먹을 수 있는지를 나타내는 불리언 값을 반환해요. 이 함수는 Pac-Man의 파워 펠릿이 활성화되어 있고 유령에 닿았을 때만 true를 반환해야 해요.

```cpp
can_eat_ghost(false, true);
// => false
```

## 2. Pac-Man이 득점하는지 정의하기

`scored` 함수는 두 개의 인자(_Pac-Man이 파워 펠릿에 닿았는지_와 _Pac-Man이 점에 닿았는지_)를 받아 Pac-Man이 득점했는지를 나타내는 불리언 값을 반환해요. 이 함수는 Pac-Man이 파워 펠릿이나 점에 닿았을 때 true를 반환해야 해요.

```cpp
scored(true, true);
// => true
```

## 3. Pac-Man이 지는지 정의하기

`lost` 함수는 두 개의 인자(_Pac-Man의 파워 펠릿이 활성화되어 있는지_와 _Pac-Man이 유령에 닿았는지_)를 받아 Pac-Man이 지는지를 나타내는 불리언 값을 반환해요. 이 함수는 Pac-Man이 유령에 닿았고 파워 펠릿이 활성화되어 있지 않을 때 true를 반환해야 해요.

```cpp
lost(false, true);
// => true
```

## 4. Pac-Man이 이기는지 정의하기

`won` 함수는 세 개의 인자(_Pac-Man이 모든 점을 먹었는지_, _Pac-Man의 파워 펠릿이 활성화되어 있는지_, _Pac-Man이 유령에 닿았는지_)를 받아 Pac-Man이 이기는지를 나타내는 불리언 값을 반환해요. 이 함수는 Pac-Man이 모든 점을 먹었고, 3번에서 정의한 인자들을 기준으로 지지 않았을 때 true를 반환해야 해요.

```cpp
won(false, true, false);
// => false
```
