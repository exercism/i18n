# 지침 추가

## 레지스터

| 레지스터 | 용도        | 타입    | 설명                                    |
| -------- | ------------ | ------- | ---------------------------------------------- |
| `$a0`    | 입력        | 주소 | 버킷 용량을 담은 워드 배열              |
| `$a1`    | 입력        | 정수 | 시작 버킷 (1 또는 2)                          |
| `$a2`    | 입력        | 정수 | 목표 용량                                  |
| `$a3`    | 입력/출력 | 주소 | 최종 버킷 내용을 담은 워드 배열          |
| `$v0`    | 출력       | 정수 | 필요한 동작 수, 불가능하면 -1 |
| `$t0-9`  | 임시    | 임의     | 임시 저장에 사용                     |
