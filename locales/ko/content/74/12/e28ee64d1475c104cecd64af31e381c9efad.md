# `for`문 소개

[`for`문](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/for.html)은 특정 조건이 충족될 때까지 여러 문을 반복 실행할 수 있게 해줘요.
이 루프는 네 부분으로 이루어져 있어요:

```java
for (initialization; test; update) {
    body;
}
```

`initialization`은 루프의 초기 상태를 설정하고, 루프가 시작될 때 정확히 한 번 실행돼요.
일반적으로는 테스트 표현식과 업데이트 문에서 사용할 변수를 선언하고 값을 할당해요.
예를 들어:

```java
int i = 1
```

`test` 표현식은 루프를 끝내야 하는지 검사해요.
`true`로 평가되면 본문과 그다음 업데이트 표현식이 실행돼요.
`false`로 평가되면 본문과 업데이트 문 모두 실행되지 않고, 루프의 닫는 괄호 뒤에서 실행이 이어져요.
일반적으로 초기화 블록에서 할당한 변수를 검사해요.
예를 들어:

```java
i <= 10
```

루프 본문을 실행한 뒤에는 `update` 표현식이 실행돼요.
일반적으로 루프 변수를 어떤 값만큼 증가시키거나 감소시켜요.
예를 들어:

```java
i++
```

`for`문으로 처음 네 개의 제곱을 출력하면 다음과 같아요:

```java
for (int i = 1; i <= 4; i++) {
    System.out.println("square of " + i + " is " + i * i);
}
```

출력 결과는 다음과 같아요:

```text
square of 1 is 1
square of 2 is 4
square of 3 is 9
square of 4 is 16
```

컬렉션의 모든 원소를 반복할 때는 `for-each`문을 쓰는 게 좋지만, 다음과 같이 `for`문으로도 할 수 있어요:

```java
for (int i = 0; i < array.length; i++) {
    System.out.print(array[i]);
}
```

`for`문은 `for-each`문보다 몇 가지 장점이 있어요:

- 원하는 인덱스에서 시작하거나 멈출 수 있어요.
- 원하는 (불리언) 종료 조건을 사용할 수 있어요.
- 루프 변수의 증가 방식을 직접 바꿔 원소를 건너뛸 수 있어요.
- 카운트다운해서 컬렉션을 뒤에서 앞으로 처리할 수 있어요.
- 컬렉션과 관련 없는 상황에서도 `for`문을 사용할 수 있어요.
