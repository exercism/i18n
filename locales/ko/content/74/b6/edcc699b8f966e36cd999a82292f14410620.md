# 지침

여러분은 정원에 찾아온 새가 몇 마리인지 기록하는 열렬한 새 관찰자예요. 보통은 공책에 하나씩 표시하며 새의 수를 세지만, 데이터를 더 잘 다루기 위해 지난 몇 주 동안의 새 개수를 디지털화했어요.

## 1. 지금까지 센 새의 총 개수를 구해요

먼저 전체적인 그림을 보면서 데이터 분석을 시작해 봐요. 기록을 시작한 이후로 총 몇 마리의 새를 셌는지 알아봐요.

하루에 센 새의 수가 담긴 `int` 슬라이스를 받는 `TotalBirdCount` 함수를 구현해요. 이 함수는 센 새의 총 개수를 반환해야 해요.

```go
birdsPerDay := []int{2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1}
TotalBirdCount(birdsPerDay)
// => 34
```

## 2. 특정 주에 찾아온 새의 수를 계산해요

새 개수 데이터에 어느 정도 감이 잡혔으니, 이제 더 세밀하게 분석해 보고 싶어요.

하루에 센 새의 수가 담긴 슬라이스와 주차를 받는 `BirdsInWeek` 함수를 구현해요.

이 함수는 그 주에 센 새의 총 개수를 반환해요. 주는 항상 완전히 기록되어 있다고 가정해도 돼요.

```go
birdsPerDay := []int{2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1}
BirdsInWeek(birdsPerDay, 2)
// => 12
```

## 3. 세는 실수를 바로잡아요

새를 기록하던 내내, 정원 멀리 구석에 숨어 있던 새가 한 마리 있었다는 걸 깨달았어요.

그 새는 이틀에 한 번씩 항상 정원에 머물렀다는 걸 알아냈어요.

그 사이에 그 새가 어디에 있었는지는 정확히 모르지만, 분명히 정원에는 없었어요.

새 관찰자의 직감은 그 새가 목록에서 처음 기록한 날에도 정원에 있었다고 알려줘요.

이 새로운 정보를 바탕으로, 하루에 센 새의 수가 담긴 슬라이스를 인자로 받아 세는 실수를 바로잡은 슬라이스를 반환하는 `FixBirdCountLog` 함수를 작성해요.

```go
birdsPerDay := []int{2, 5, 0, 7, 4, 1}
FixBirdCountLog(birdsPerDay)
// => [3 5 1 7 5 1]
```
