# PaySwitch - 급여 변환기

## 문제 설명

**Insure Everyone**이라는 회사는 직원들에게 외화로 급여를 지급해요. 하지만 법규상의 요구 사항 때문에 급여를 현지 통화로 변환해야 해요. 이 회사의 직원들은 전 세계 곳곳에 있어요.
Insure Everyone의 인사 부서는 각 직원의 급여를 해당 현지 통화로 변환하는 프로그램을 만들 능력 있는 개발자의 도움을 찾고 있어요. Insure Everyone은 외부 API에서 제공하는 환율에 의존해요.

외부 환율 API가 주어졌을 때, `source currency`, `salary`(source currency 기준), 그리고 직원의 `local currency`를 받아 현지 통화로 환산한 급여를 반환하는 함수를 작성해야 해요.

## 제약 사항

* 500 <= `salary` <= 10000
* `sourceCurrency`와 `targetCurrency`는 [ISO 통화 코드(알파벳)](https://en.wikipedia.org/wiki/ISO_4217#Active_codes)예요. 테스트 입력에는 유효하지 않은 통화 코드가 포함될 수 있어요.
* 반환된 환율의 정확도는 소수점 `5`자리까지 측정해요.

## 예시

### 예시 1

#### 입력:
* 급여: 1000
* 원본 통화: USD
* 대상 통화: GBP

#### 출력:

외부 환율 서비스가 다음과 같은 변환 환율 응답(일부 생략)을 반환했다고 가정해요:

```json
{
    "base": "USD",
    "rates": {
        // omitted
        "GBP": 0.73584,
        // omitted
    }
}
```

함수는 `735.84000`을 반환해야 해요

### 예시 2

#### 입력:

* 급여: 1000
* 원본 통화: GBP
* 대상 통화: USD

#### 출력:
