# 개요

원소를 0개 이상 담을 수 있는 자료 구조를 _컬렉션_이라고 해요. **배열**은 크기와 길이가 고정되어 있고 모든 원소가 같은 타입이어야 하는 컬렉션이에요. 원소는 인덱스를 사용해 배열에 할당하거나 배열에서 가져올 수 있어요. C# 배열은 0부터 시작해요. 즉, 첫 번째 원소의 인덱스는 항상 0이에요.

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true

// Check the length of the array
twoInts.Length == 2; // => true
```

배열은 배열을 만들면서 동시에 값을 설정할 수 있는 축약 표기법으로도 정의할 수 있어요. 이제 컴파일러가 배열에 원소가 몇 개 있는지 알 수 있으므로 길이는 생략할 수 있어요.

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

배열은 배열 인스턴스의 [메서드][array-methods]나 [속성][array-properties]을 호출하거나, [`Array` 클래스][array-class]에 정의된 정적 메서드를 사용해서 다룰 수 있어요.

## 반복

배열도 _컬렉션_이에요. 따라서 [`foreach`문][foreach-statement]을 사용해 _모든_ 값에 대해 반복할 수 있어요.

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```

[`for`문][for-statement]을 사용해 배열을 반복할 수도 있어요.

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

for (int i = 0; i < vowels.Length; i++)
{
    // Output the vowel
    System.Console.Write(vowels[i]);
}

// => aeiou
```

하지만 일반적으로는 다음과 같은 이유로 `for`문보다 `foreach`문이 더 좋아요.

- `foreach`문은 _모든_ 값에 대해 반복하는 것이 보장돼요. `for`문에서는 원소를 빠뜨리기 쉬운데, 예를 들어 off-by-one 오류 때문에 그럴 수 있어요.
- `foreach`문은 더 _선언적_이에요. 코드가 _무엇을_ 하려는지를 표현하는 반면, `for`문은 _어떻게_ 하려는지를 표현해요.
- `foreach`문은 실수할 여지가 없지만, `for`문은 off-by-one 오류가 생기기 쉬워요.
- `foreach`문은 인덱서로 원소에 접근하는 것을 지원하지 않는 타입을 포함해, 모든 컬렉션 타입에서 동작해요.

`foreach`문이 _모든_ 값에 대해 반복하도록 보장하기 위해, 컴파일러는 `foreach`문 안에서 컬렉션을 수정하는 것을 허용하지 않아요.

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

`for`문이 `foreach`문보다 나은 점도 몇 가지 있어요.

- 원하는 인덱스에서 시작하거나 멈출 수 있어요.
- 원하는 (불리언) 종료 조건을 사용할 수 있어요.
- 루프 변수의 증가 방식을 원하는 대로 바꿔서 원소를 건너뛸 수 있어요.
- 카운트를 줄여 나가면서 컬렉션을 뒤에서 앞으로 처리할 수 있어요.
- 컬렉션과 관련이 없는 상황에서도 `for`문을 사용할 수 있어요.

관련 주제:

- C#은 `int[,] arr = new int[10, 5]` 같은 [다차원 배열][multi-dimensional-arrays]을 지원하며, 이는 매우 유용할 수 있다는 점을 알아 두면 좋아요.
- `Array.CreateInstance`로 [`System.Array`][system-array-object] 타입의 인스턴스를 만들 수도 있다는 점도 알아 두면 좋아요. 이런 객체는 쓸모가 거의 없고, 주로 VB.NET 코드와 상호 운용할 때 사용해요. 표준 배열(`T[]`)과는 서로 바꿔 쓸 수 없어요. 0이 아닌 하한을 가질 수도 있어요.
