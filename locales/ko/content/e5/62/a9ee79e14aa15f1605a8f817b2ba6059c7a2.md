# 소개

*정규 표현식*(regex)은 어떤 텍스트가 어떤 모양이어야 하는지를 설명하는 작은 패턴이에요. 문자열을 문자 하나하나 직접 확인하는 대신, 원하는 모양을 한 번만 적어 두고 Factor가 맞춰 보게 하는 거예요. Factor의 정규 표현식 도구는 [`regexp`][regexp] 보캐뷸러리에 들어 있어요.

## 패턴 작성하기

Factor에서는 `R/ `와 `/` 사이에 정규 표현식을 적어요:

```factor
R/ cat/      ! the pattern that matches the letters c, a, t
```

패턴 안의 대부분의 문자는 그냥 자기 자신을 뜻해요. `R/ cat/`는 `cat`이라는 텍스트와 일치하죠. 진짜 힘은 *어떤 종류*의 문자를 나타내거나 그런 문자가 *몇 개*인지를 나타내는 몇 가지 특별한 조각에서 나와요.

### 문자 클래스: 집합에서 고른 문자 하나

```
\d        ! any digit, 0–9
\D        ! any NON-digit (the opposite of \d)
\s        ! any space, tab, or newline
\S        ! any NON-space character (the opposite of \s)
\w        ! a "word" character: a letter, a digit, or an underscore
\W        ! any NON-word character (the opposite of \w)
[A-Z]     ! any one capital letter A to Z
[a-z]     ! any one lowercase letter
[0-9]     ! any one digit (same as \d)
.         ! any single character at all
```

클래스는 정확히 문자 *하나*와 일치해요. `[A-Z]`는 `Q`와는 일치하지만 `QQ`와는 일치하지 않아요.

### 수량자: 몇 번

어떤 조각 *뒤에* 이 중 하나를 붙이면 몇 번 반복될 수 있는지를 나타내요:

```
{4}       ! exactly 4 times
{2,5}     ! between 2 and 5 times
+         ! one or more
*         ! zero or more
?         ! zero or one (optional)
```

그래서 `\d{4}`는 숫자 네 개가 연달아 있는 것을, `[A-Z]+`는 대문자가 하나 이상 있는 것을 뜻해요. 이걸 합치면 `R/ [A-Z]+-\d+/`는 "대문자가 하나 이상, 대시 하나, 그다음 숫자가 하나 이상"을 나타내요. `SALE-2024` 같은 텍스트죠. 여기서 `-`는 평범한 문자예요. `[ ]` 밖에서 대시는 그냥 대시와 일치해요. (`[A-Z]`처럼 클래스 안에서는 범위를 나타내고요.)

## 문자열 전체 일치시키기

`matches?`는 "이 문자열 *전체*가 패턴에 들어맞나요?"라는 질문에 답해요. 패턴은 처음부터 끝까지 모든 문자를 설명할 수 있어야 하죠:

```
matches? ( string regexp -- ? )
```

```factor
USING: regexp ;

"SALE-2024"     R/ [A-Z]+-\d+/ matches? .   ! => t
"GET SALE-2024" R/ [A-Z]+-\d+/ matches? .   ! => f   (extra text before)
"SALE-2024 NOW" R/ [A-Z]+-\d+/ matches? .   ! => f   (extra text after)
"sale-2024"     R/ [A-Z]+-\d+/ matches? .   ! => f   (lowercase letters)
```

`"GET SALE-2024"` 안에 `SALE-2024`가 들어 있긴 해도 `matches?`는 여전히 `f`를 말해요. 남는 문자들도 문자열의 일부이고, 패턴에 들어맞지 않으니까요. 패턴이 *어딘가에* 나타나는지만 알고 싶다면 `re-contains?`를 써봐요. `matches?`가 `f`를 반환한 바로 그 자리에서 `t`를 반환해요:

```
re-contains? ( string regexp -- ? )
```

```factor
USING: regexp ;

"GET SALE-2024" R/ [A-Z]+-\d+/ matches? .      ! => f
"GET SALE-2024" R/ [A-Z]+-\d+/ re-contains? .  ! => t
```

## 더 긴 텍스트 안에서 일치 찾기

`re-contains?`는 패턴이 그 안에 있는지 *여부*만 알려줘요. 다음 단어들은 안을 들여다보고 *무엇*이 일치했는지 알려줘요. `all-matching-subseqs`는 패턴이 일치하는 모든 위치를 문자열 시퀀스로 반환하고, `count-matches`는 그 개수만 세요:

```
all-matching-subseqs ( string regexp -- seq )
count-matches        ( string regexp -- n )
```

```factor
USING: regexp ;

"3 cats, 12 dogs, 1 fish" R/ \d+/ all-matching-subseqs .
! => { "3" "12" "1" }            (every run of digits)

"the quick fox" R/ \S+/ all-matching-subseqs .
! => { "the" "quick" "fox" }     (every run of non-space characters)

"id_7!" R/ \w/ count-matches .   ! => 4   (i, d, _ and 7 count; ! does not)
```

## 일치 항목 바꾸기

`re-replace`는 일치하는 모든 부분을 대체 텍스트로 바꾸고 새 문자열을 반환해요:

```
re-replace ( string regexp replacement -- result )
```

```factor
USING: regexp ;

"page 7 of 12" R/ \d+/ "N" re-replace .
! => "page N of N"
```

`regexp` 보캐뷸러리에는 더 알아 둘 만한 단어가 많아요. 자세한 내용은 링크를 따라가 봐요. [`first-match`][first-match](첫 번째 일치만)와 [`re-split`][re-split](패턴이 일치하는 곳마다 문자열을 나눠요)이 있어요.
