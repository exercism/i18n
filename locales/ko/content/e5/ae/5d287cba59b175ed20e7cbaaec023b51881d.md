# 소개

## 일반적인 문법

`for`문은 어떤 로직을 반복해서 실행할 때 가장 흔히 쓰이는 문 중 하나예요.
Go에서는 `for` 키워드, 헤더, 그리고 중괄호로 감싼 루프 본문을 담는 코드 블록으로 이루어져 있어요.
헤더는 세미콜론 `;`으로 구분된 세 가지 요소로 이루어져요. 바로 init, condition, post예요.

```go
for init; condition; post {
  // loop body - code that is executed repeatedly as long as the condition is true
}
```

- **init** 요소는 루프가 시작되기 전에 딱 한 번만 실행되는 코드예요.
- **condition** 요소는 불리언으로 평가되는 표현식이어야 하고, 루프를 언제 멈출지 결정해요.
  루프 안의 코드는 이 조건이 true로 평가되는 동안 실행돼요.
  이 표현식이 false로 평가되는 순간, 루프는 더 이상 반복되지 않아요.
- **post** 요소는 각 반복이 끝날 때 실행되는 코드예요.

**참고:** 다른 언어와 달리, 헤더의 세 요소를 감싸는 괄호 `()`가 없어요.
오히려 이런 괄호를 넣으면 컴파일 오류가 발생해요.
그렇지만 루프 본문을 감싸는 중괄호 `{ }`는 항상 필요해요.

## `for`문 예제

init 요소는 보통 카운터 변수를 준비하고, condition은 루프를 계속할지 멈출지 확인하며, post는 보통 매 반복이 끝날 때 카운터를 증가시켜요.

```go
for i := 1; i < 10; i++ {
  fmt.Println(i)
}
```

이 루프는 `1`부터 `9`까지의 숫자를 출력해요(`9`도 포함해서요).
반복의 간격을 정할 때는 위 예제처럼 증가문이나 감소문을 사용하는 경우가 많아요.
