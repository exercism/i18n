# 힌트

Regex 실력에 아주 자신이 있는 게 아니라면, [Regex101][regex101] 같은 온라인 플레이그라운드에서 문법을 직접 풀어 보면 도움이 돼요.

flavor는 PCRE2로 설정하는 걸 잊지 마세요.

각 정규식을 `const`로 미리 정의해 두는 것도 좋은 스타일이에요 (명확성과 성능에 도움이 돼요).

## 1. 유효한 명령 확인하기

- 문자열의 시작을 나타내는 앵커 문자는 `^`예요.
- 정규식 검색에서는 true/false만 있으면 돼요.
- 정규식 없이도 풀 수 있지만, 개념 연습 문제의 취지에 맞게 풀어 주세요.

## 2. 암호화된 이모지 제거하기

- 간단한 [`replace()`][replace] 한 번이면 돼요.

## 3. 유효한 전화번호 확인하기

- 더 길지만 꽤 반복적인 정규식이 필요해요.
- `n`번 연속으로 나타나는 것은 `{n}` 문법으로 지정할 수 있어요.
- 일치 여부만 true/false로 확인하면 돼요.

## 4. 웹사이트 링크 가져오기

- 점은 `\.`로 이스케이프하는 걸 잊지 마세요.
- 점 앞부분을 [match][match]로 캡처해요.

## 5. 사용자에게 인사하기

- 이름 있는 캡처를 사용하는 `replace()`는 `r"(?<name>...) " => s"\g<name>... "` 형식이에요.
- 마찬가지로 `split()`으로도 풀 수 있지만, 정규식을 연습해 보는 게 유용해요.
