# 테스트

각 예제마다 다음과 같은 일반적인 단계를 거쳐요.

먼저 연습하고 싶은 연습 문제의 디렉터리로 이동해요. 여기서는 `bob`이에요.

```bash
$ cd </path/to/exercism>/lfe/bob
```

다음으로 테스트를 실행해요. `test` make 타깃은 `compile`에 의존하기 때문에, `make test`를 실행하면 소스가 컴파일된 다음 테스트가 실행돼요.


```bash
$ make test
```

축하해요! 실패하는 테스트가 생겼어요!!!

이제 모든 테스트를 통과시키려면 무엇을 해야 하는지 `README.md`를 읽어서 확인해봐요.


테스트가 보고한 첫 번째 오류를 고치고, 테스트를 다시 실행해요.

```bash
$ make test
```

소스 코드에서 실패한 다음 테스트를 고치고 다시 실행하는 과정을 모든 테스트가 통과할 때까지 반복해요.

모든 테스트가 통과하면 `src` 디렉터리의 코드를 마지막으로 한번 훑어보고, 코드가 마음에 드는지 확인한 다음 리뷰를 위해 제출해요.

피드백을 받고, 풀이를 다듬고, 제출하고, 다음 연습 문제를 풀어요. LFE 깨달음을 얻을 때까지 이 과정을 반복해요.
