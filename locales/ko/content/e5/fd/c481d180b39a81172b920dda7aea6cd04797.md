# 지침

이 연습 문제에서는 친구가 개발 중인 새로운 RPG 게임의 퀘스트 로직을 구현해요. 게임의 주인공은 용감한 소녀 Annalyn과, 사납지만 충직한 반려견이에요. 그런데 안타깝게도 Annalyn의 가장 친한 친구가 숲에서 베리를 찾던 중 납치되는 일이 벌어져요. Annalyn은 가장 친한 친구를 찾아 구출하려고 하고, 이 여정에 반려견을 데리고 갈 수도 있어요.

한참 동안 친구의 흔적을 따라간 끝에, Annalyn은 친구가 갇혀 있는 야영지를 발견해요. 납치범은 둘이었어요. 힘센 기사와 교활한 궁수예요.

납치범들을 찾은 Annalyn은 다음 중 어떤 행동을 할 수 있을지 생각해요:

- 빠른 공격: 기사가 잠들어 있을 때 빠른 공격을 할 수 있어요. 갑옷을 입는 데 시간이 걸리기 때문에 기사는 무방비 상태가 돼요.
- 감시: 무리 중 적어도 한 명이 깨어 있으면 감시할 수 있어요. 그렇지 않으면 감시는 시간 낭비예요.
- 죄수에게 신호 보내기: 죄수가 깨어 있고 궁수가 잠들어 있으면 새소리로 죄수에게 신호를 보낼 수 있어요. 궁수는 새소리 신호를 훈련받았기 때문에 메시지를 가로챌 수도 있거든요.
- _죄수 풀어주기_: Annalyn은 야영지에 몰래 들어가 죄수를 풀어줄 수 있어요.
  이것은 위험한 일이라 두 가지 방법 중 하나로만 성공할 수 있어요:
  - Annalyn이 반려견과 함께 있다면 궁수가 잠들어 있을 때 죄수를 구출할 수 있어요.
    기사는 개를 무서워하고, 궁수는 Annalyn과 죄수가 도망치기 전에 준비할 시간이 없어요.
  - Annalyn이 반려견과 함께 있지 않다면 Annalyn과 죄수는 아주 조심스러워야 해요!
    죄수가 깨어 있고 기사와 궁수가 둘 다 잠들어 있으면 죄수를 풀어줄 수 있어요. 하지만 죄수가 잠들어 있으면 구출할 수 없어요. Annalyn이 갑자기 나타나면 죄수가 놀라서 기사와 궁수를 깨울 테니까요.

수행할 과제는 네 가지예요. 숲에서 만난 세 인물의 상태와 Annalyn의 반려견 동반 여부에 따라 위 행동들을 할 수 있는지 판단하는 로직을 구현해요.

## 1. 빠른 공격을 할 수 있는지 확인하기

기사가 깨어 있는지를 나타내는 불리언 값을 받는 `canFastAttack()` 메서드를 구현해요. 이 메서드는 기사의 상태를 기준으로 빠른 공격을 할 수 있으면 `true`를 반환하고, 그렇지 않으면 `false`를 반환해요:

```kotlin
val knightIsAwake = true

canFastAttack(knightIsAwake)
// => false
```

## 2. 무리를 감시할 수 있는지 확인하기

기사, 궁수, 죄수가 각각 깨어 있는지를 나타내는 세 개의 불리언 값을 받는 `canSpy()` 메서드를 구현해요. 이 메서드는 세 인물의 상태를 기준으로 무리를 감시할 수 있으면 `true`를 반환하고, 그렇지 않으면 `false`를 반환해요:

```kotlin
val knightIsAwake = false
val archerIsAwake = true
val prisonerIsAwake = false

canSpy(knightIsAwake, archerIsAwake, prisonerIsAwake)
// => true
```

## 3. 죄수에게 신호를 보낼 수 있는지 확인하기

궁수와 죄수가 각각 깨어 있는지를 나타내는 두 개의 불리언 값을 받는 `canSignalPrisoner()` 메서드를 구현해요. 이 메서드는 두 인물의 상태를 기준으로 죄수에게 신호를 보낼 수 있으면 `true`를 반환하고, 그렇지 않으면 `false`를 반환해요:

```kotlin
val archerIsAwake = false
val prisonerIsAwake = true

canSignalPrisoner(archerIsAwake, prisonerIsAwake)
// => true
```

## 4. 죄수를 풀어줄 수 있는지 확인하기

네 개의 불리언 값을 받는 `canFreePrisoner()` 메서드를 구현해요. 처음 세 매개변수는 기사, 궁수, 죄수가 각각 깨어 있는지를 나타내요. 마지막 매개변수는 Annalyn의 반려견이 함께 있는지를 나타내고요. 이 메서드는 세 인물의 상태와 Annalyn의 반려견 동반 여부를 기준으로 죄수를 풀어줄 수 있으면 `true`를 반환하고, 그렇지 않으면 `false`를 반환해요:

```kotlin
val knightIsAwake = false
val archerIsAwake = true
val prisonerIsAwake = false
val petDogIsPresent = false

canFreePrisoner(knightIsAwake, archerIsAwake, prisonerIsAwake, petDogIsPresent)
// => false
```
