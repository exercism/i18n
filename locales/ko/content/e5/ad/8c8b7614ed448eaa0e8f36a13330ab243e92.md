# 테스트

다음 명령으로 테스트를 실행해요:

```shell
npm run test
```

Jest를 "watch" 모드로 실행할 수도 있는데, 이 모드에서는 코드나 테스트 모듈의 변경 사항을 저장할 때마다 테스트가 자동으로 다시 실행돼요:

```shell
npm run watch
```

## 건너뛴 테스트 이해하기

skip 메서드는 테스트 스위트에 특정 테스트를 실행하지 말라고 지시해요. 이 함수는 `it.skip(name, fn)` 또는 `xit(name, fn)` 또는 `xtest(name, fn)`이라는 별칭으로도 사용할 수 있어요.

- 왜 건너뛰는 걸까요?

사용자가 한 번에 하나의 테스트에 집중하고, 풀이를 발전시켜 나가면서 하나씩 활성화할 수 있게 하기 위해서예요.

- 어떻게 활성화하나요?

`xtest`를 `test`로 바꿔요.

```javascript
test("title cased phrases", () => {
  expect(Acronyms.parse("Portable Network Graphics")).toEqual("PNG");
});
```
