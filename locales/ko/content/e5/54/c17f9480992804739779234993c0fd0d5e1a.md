# Batch 학습

## 웹사이트

- [Official Batch-File Documentation](https://learn.microsoft.com/en-us/previous-versions/windows/it-pro/windows-xp/bb490869(v=technet.10)?redirectedfrom=MSDN)은 예제를 보면서 이 언어를 익히기에 좋은 곳이에요.
- [SS64 Command Documentation](https://ss64.com/nt/)은 Batch 명령에 관한 가장 포괄적인 문서일 거예요. 기초부터 고급 예제까지 담고 있어요.
- [Rob van der Woude's Scripting Pages](https://www.robvanderwoude.com/)는 Batch 스크립팅에 정말 유용한 자료예요. 예제와 설명이 아주 많고, 이 웹사이트에서 가장 흥미로운 점은 정말 독특한 도구들의 코드를 공유하면서 모든 것을 이해하기 쉬운 방식으로 설명한다는 거예요. (처음에는 조금 헷갈릴 수 있지만, 그만한 가치가 있어요)
- [DosTips Forum](https://www.dostips.com/forum/)은 Batch 스크립트에 대해 질문하고 도움을 받을 수 있는 좋은 곳이에요.
- [Batch-Man](https://batch-man.com/)은 유용한 도구와 스크립트를 많이 공유하고, 그것들을 아주 이해하기 쉽게 설명해 줘요. 각 스크립트에는 블로그 형태의 자세한 설명이 있고, GitHub 저장소와 많은 예제, YouTube 영상도 함께 있어요.

## 영상

- [Batch Tutorials by John Hammond](https://www.youtube.com/playlist?list=PL69BE3BF7D0BB69C4)는 초보자가 보기에 잘 설명돼 있어요.
- [Batch-Man](https://www.youtube.com/@batch-man/videos) 채널도 꾸준히 콘텐츠를 만들면서 여러 기법을 보여줘요.
