# 소개

_문자열_은 텍스트 데이터를 저장하기 위한 JavaScript의 데이터 타입이에요.

## 문자열 만들기

문자열은 텍스트를 작은따옴표나 큰따옴표로 감싸서 만들어요.
Exercism에서는 작은따옴표를 사용해요.

<!-- prettier-ignore-start -->
```javascript
'Hello, World!'
"Hello, World!"
```
<!-- prettier-ignore-end -->

## 문자 목록으로서의 문자열

문자열은 문자의 목록으로 볼 수 있고, 첫 번째 문자의 인덱스는 `0`이에요.
대괄호와 가져오고 싶은 문자의 인덱스를 사용해서 문자열의 개별 문자에 접근할 수 있어요.

```javascript
'cat'[1];
// => 'a'
```

`length` 속성에 접근해서 문자열의 문자 수를 알아낼 수 있어요.

```javascript
'cat'.length;
// => 3
```

## 문자열 연결과 메서드

문자열을 연결하는 가장 간단한 방법은 덧셈 연산자 `+`를 사용하는 거예요.

```javascript
'I like' + ' ' + 'cats.';
// => "I like cats."
```

문자열은 다양한 편의 메서드를 제공해요. 전체 목록은 [MDN의 문자열 메서드 문서][mdn-string-methods]를 참고해요.
다음 목록은 자주 사용되는 편의 메서드 일부를 보여줘요.

- [`toUpperCase`][mdn-to-upper-case]와 [`toLowerCase`][mdn-to-lower-case] - 모든 문자의 대소문자를 바꿔요
- [`trim`][mdn-trim] - 앞과 뒤의 공백을 제거해요
- [`includes`][mdn-includes], [`startsWith`][mdn-starts-with], [`endsWith`][mdn-ends-with] - 다른 문자열이 주어진 문자열의 일부인지 판단해요
- [`slice`][mdn-slice] - 문자열의 일부를 추출해요

JavaScript에서 문자열은 변경할 수 없어요. 그래서 위 메서드들처럼 "수정"을 하면 항상 새로운 문자열이 만들어져요.
