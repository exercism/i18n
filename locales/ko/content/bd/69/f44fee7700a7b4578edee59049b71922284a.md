# 지침

이 연습 문제에서는 고등학교 커플이 소셜 미디어에서 사랑을 고백할 수 있도록, 두 사람의 이니셜이 들어간 유니코드 하트를 만들어 줄 거예요:

```
❤ J.  +  M. ❤
```

## 1. 이름 정리하기

`cleanupname` 메서드를 구현해요.
이름을 받아서 `-` 문자를 모두 없애고 공백으로 바꿔요.
이름의 앞뒤에 있는 공백도 제거해요.

```julia-repl
julia> cleanupname("Jane-Ann")
"Jane Ann"
```

## 2. 이름의 첫 글자 가져오기

`firstletter` 메서드를 구현해요.
이름을 받아서 첫 글자를 문자열로 반환해요.
이전 단계에서 정의한 `cleanupname`을 다시 사용하고, 다른 함수들과 조합해 봐요.

```julia-repl
julia> firstletter("Jane")
"J"
```

## 3. 첫 글자를 이니셜로 만들기

`initial` 메서드를 구현해요.
이름을 받아서 첫 글자를 대문자로 만들고 뒤에 마침표를 붙여 반환해요.
이전 단계에서 정의한 `firstletter`를 다시 사용해 봐요.

```julia-repl
initial("Robert")
"R."
```

## 4. 이니셜을 하트 안에 넣기

`couple` 메서드를 구현해요.
이름 두 개를 받아서 양쪽에 하트 이모지를 붙인 이니셜을 반환해요.
이전 단계에서 정의한 `initial`을 다시 사용해 봐요.

```julia-repl
couple("Blake Miller", "Riley Lewis")
"❤ B.  +  R. ❤"
```
