# 지침 추가

## 나만의 DSL 만들기

이 연습 문제에서는 원하는 대로 그래프 DSL을 마음껏 설계할 수 있어요.

테스트는 몇 가지 특정한 그래프를 만들기만 요구해요. 어떻게 만들지는 전적으로 자유예요.

재미를 두 배로 만들고 싶다면, 그래프를 DOT 형식으로 변환하는 `to_dot` 함수를 선택적으로 구현해 볼 수도 있어요!

## 그래프 표현

`Graph.roc`에 DSL을 정의한 다음, 스텁에서 요구하는 그래프를 만들 때 사용해요.
각 `EdgeId`에 있는 두 노드 ID는 알파벳순으로 정렬되어야 해요.

| 정의 | 만들 그래프 |
| --- | --- |
| `empty_graph` | 빈 그래프 |
| `graph_with_one_node` | 노드 하나 |
| `graph_with_one_node_with_attribute` | 속성이 하나 있는 노드 |
| `graph_with_one_edge` | 간선 하나 |
| `graph_with_one_attribute` | 그래프 속성 하나 |
| `graph_with_nodes_edges_and_attributes` | 노드, 간선, 속성 |
| `multiple_edges_on_one_line` | 한 줄에 표현한 여러 간선 |
| `only_1_edge_between_nodes` | 각 노드 쌍 사이에 간선은 하나만 |
