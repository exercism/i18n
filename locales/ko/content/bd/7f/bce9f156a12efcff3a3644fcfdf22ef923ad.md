# CLI

연습 문제 디렉터리에서 명령 프롬프트를 열고 [`stack test` 명령][docs-stack-test]을 실행하면 테스트를 실행할 수 있어요. 코드가 컴파일되면 이 명령이 어떤 테스트가 통과했고 어떤 테스트가 실패했는지 보여줘요. 테스트가 실패하면 통과시키도록 고친 뒤 다시 테스트를 실행해 봐요.

모든 테스트가 통과하면, 연습 문제 디렉터리에서 명령 프롬프트를 열고 [`exercism submit` 명령][docs-exercism-cli]을 실행해서 풀이를 제출할 수 있어요.

[docs-stack-test]: https://docs.haskellstack.org/en/stable/build_command/
[docs-exercism-cli]: https://exercism.io/cli
