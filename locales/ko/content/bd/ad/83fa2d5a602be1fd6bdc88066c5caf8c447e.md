# 소개

## 리소스 수명

[concept:csharp/resource-cleanup]() 개념에서는 `IDispose` 인터페이스를 써서, 어떤 객체가 더 이상 필요하지 않게 되면 그 객체의 리소스나 기타 프로그램 상태를 해제하거나 초기화해야 한다는 것(그리고 가비지 컬렉터에 기대는 것으로는 이걸 해낼 수 없거나 필요한 수준의 제어를 제공하지 못한다는 것)을 알려줘요. 그리고 이런 정리 작업을 하기에 자연스러운 자리는 `IDisposable.Dispose()` 메서드라는 것도 알려주고요.

`using` 블록이라는 또 다른 구문이 있는데, 이걸 쓰면 호출하는 쪽 입장에서 모든 리소스 수명 관리를 문 하나로 모을 수 있어요.

```csharp
using (var file = new File("my_secrets"))
{
    file.WriteSecret("xxxxxxx");
}
```

위 예제에서 `file`과 연결된 파일 시스템 리소스는 `using` 블록을 빠져나갈 때 운영체제로 반환돼요.

이 패턴이 제대로 동작하려면 using 문에 쓰는 변수가 `IDisposable` 인터페이스를 구현한 참조 형식이어야 하고, `Dispose()` 메서드에서 리소스를 해제하거나 프로그램 상태를 초기화해야 해요.

C# 8에서는 이 패턴을 한층 다듬었어요. using 문을 블록 맨 앞에 둘 수 있거든요.

```csharp
using var drawingResource = some_provided_or_new_object;
try
{
    drawingResource.DrawSomething();
}
catch (Exception)
{
    throw;
}
```

Java 개발자라면 Java 7에서 도입된 _자동 리소스 관리_ 메커니즘과 비슷하다는 걸 알아볼 수 있을 거예요.
