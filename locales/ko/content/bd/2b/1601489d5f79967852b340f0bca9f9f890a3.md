# 소개

`Result` 타입을 사용하면 함수가 다음을 모두 나타내는 하나의 값을 반환할 수 있어요:

- 연산이 성공했는지 실패했는지
- 성공했을 때는 연산의 결과 값
- 실패했을 때는 실패한 이유

## 사용법

`Result`는 두 가지 하위 타입을 담는 제네릭 타입이에요:

- 연산이 성공했을 때의 결과 값 타입
- 실패했을 때 실패 이유를 나타내는 타입

`Result` 타입은 [판별된 공용체][discriminated-union]이기도 하고, 다음과 같은 경우를 가질 수 있어요:

- 성공한 결과를 나타내는 `Ok <value>`
- 실패를 나타내는 `Error <reason>`

다음 함수는 `Result` 값을 만드는 방법을 보여줘요:

```fsharp
let validateName (name: string) : Result<string, string> =
    match name with
    | null -> Error "Name not found."
    | "" -> Error "Name is empty."
    | _ -> Ok name
```

이 예제에서 `Ok` 값은 문자열(주어진 이름)이고, `Error` 값도 문자열이에요(사람이 읽을 수 있는 형태의 오류 원인).

## `Result` 값의 내용 읽기

다음 타입 정의와 함수 시그니처를 살펴봐요:

```
type FileOpenError =
| NotFound
| AccessDenied
| FileLocked

let openFile (filename: string) : Result<int, FileOpenError> =
```

`openFile` 함수를 호출하는 코드는 다음 예제처럼 패턴 매칭을 사용해 성공과 실패 경우를 처리할 수 있어요:

```fsharp
match openFile(filename) with
| Ok handle -> doSomethingWithFile(handle)
| Error NotFound -> printfn $"Error: file {filename} was not found."
| Error AccessDenied -> printfn $"Error: you do not have permission to open the file {filename}."
| Error FileLocked -> printfn $"Error: file {filename} is already in use."
```
