# 부동소수점 수

부동소수점 수는 PHP에서 실수의 부분집합을 표현하는 데 사용해요.
숫자 하나 이상으로 시작하고, 소수점 구분 기호로 나뉘어요.

```php
<?php

$a = 1.234; 
$b = 1.2e3; 
$c = 7E-10;
$d = 1_234.567; // as of PHP 7.4.0
```

## 흔히 빠지는 함정

부동소수점 수로는 모든 수와 산술 연산을 수행할 수 있는 게 아니에요.
달러와 센트를 나타내는 데 부동소수점 수를 사용하면 반올림 오류가 생길 수 있어요.

```php
<?php

$result = 0.1 + 0.2; // => 0.30000000000000004
```
