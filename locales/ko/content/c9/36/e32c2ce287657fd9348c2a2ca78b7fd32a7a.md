# 소개

R의 `vector`는 같은 `type`의 값들을 모아 놓은 것이에요: `numeric`, `character` 등. 서로 다른 타입의 입력이 주어지면, R은 이들을 모두 조용히 공통 타입, 보통 `character`로 강제 변환해요. 그러면 예상치 못한 결과가 나올 수 있어요.

```R
v <- c(2, 5.4, "txt")
v
#> [1] "2"   "5.4" "txt"
typeof(v)
#> [1] "character"
```

## 벡터 만들기

값이 모두 준비되어 있다면 `c()`를 사용해요. `c()`는 "concatenate" 또는 "combine"을 줄인 말이에요:

```R
x <- 10
v <- c(4, 7, x)
```

`c()` 함수는 매우 유연해서 다른 벡터와 범위도 입력으로 받을 수 있어요. `c()`는 개수와 종류에 상관없이 입력을 받아 하나의 벡터로 합쳐요.

## 범위, 시퀀스, 반복

연속된 값의 범위(증가 또는 감소)에는 `:` 표기법을 사용할 수 있어요.

```R
v <- 1:5 # equivalent to c(1, 2, 3, 4, 5)
w <- 10:7 # c(10, 9, 8, 7)
```

`seq()` 함수를 사용하면 더 세밀하게 제어할 수 있어요:

```R
# specify step size
seq(2, 11, by = 3) # c(2, 5, 8, 11)

# specify number of values, evenly-spaced
seq(2.5, 4, length.out = 5) # c(2.500, 2.875, 3.250, 3.625, 4.000) 
```

몇몇 범위는 내장 상수로 미리 정의되어 있어요:

```R
letters  # LETTERS is the UPPERCASE equivalent
#> [1] "a" "b" "c" "d" "e" "f" "g" "h" "i" "j" "k" "l" "m" "n" "o" "p" "q" "r" "s" "t" "u" "v" "w" "x" "y" "z"

month.name
#> [1] "January"   "February"  "March"     "April"     "May"       "June"      "July"      "August"   
#> [9] "September" "October"   "November"  "December" 

month.abb
#> [1] "Jan" "Feb" "Mar" "Apr" "May" "Jun" "Jul" "Aug" "Sep" "Oct" "Nov" "Dec"
```

## 산술 연산

연산은 벡터를 따라 자동으로 원소별로 적용돼요. 
다른 언어에서 흔한 루프, 리스트 컴프리헨션, 재귀는 필요하지 않고, (*성능상의 이유로*) 보통 피하는 게 좋아요.

```R
2 + 1:3 # c(3, 4, 5)
2 * 1:3 # c(2, 4, 6)
12 / 1:3 # c(12  6  4)
2 ^ (1:3) # c(2, 4, 8) : exponentiation, precedence order here needs ()
```

두 벡터를 짝지어도 원소별로 연산돼요:

```R
v <- 1:3
w <- 5:7

v + w
#> [1]  6  8 10

v * w
#> [1]  5 12 21

v ^ w
#> [1]    1   64 2187
```

## 벡터 원소에 접근하기

많은 언어에서처럼 대괄호 안에 인덱스를 넣어 사용할 수 있어요:

```R
v <- 4:7
v[2]
#> [1] 5
v[2:4]
#> [1] 5 6 7
```

하지만 주의하세요: ***R은 기본적으로 1부터 시작하는 인덱싱을 사용해요***. 

이 방식은 과학용 언어(Fortran, Matlab, Julia)에서 흔하지만, C와 그 후속 언어들의 0부터 시작하는 인덱싱과는 달라요.

범위는 위 예시에서처럼 사용할 수 있고, 매우 유연한 `c()` 함수에서도 사용할 수 있어요:

```R
v <- c(4, 7, 10)
w <- c(2, v[2:3], 11) # c(2, 7, 10, 11)
```

`vectors`는 (R의 대부분처럼) 변경 가능하게 다룰 수 있어요. 단일 원소나 여러 원소에 값을 쓸 때도 비슷하고 유연한 문법을 사용해요:

```R
v <- 1:10
v[2] <- 42
v[4:6] <- c(11, 12, 13)
v
#> [1]  1 42  3 11 12 13  7  8  9 10
```

## 음수 인덱스

다른 언어에 익숙한 프로그래머라면 `v[-1]`이 벡터의 마지막 원소에 접근하는 방법이라고 추측할 수 있어요.
*틀렸어요!*
그럴 때는 `tail(v, n=1)`을 사용해요.

음수 인덱스는 실제로 원소를 ***제거***하는 방법이고, 더 짧은 벡터를 반환해요:

```R
v <- c(2, 4, 6)
v[-2]
#> [1] 2 6  # second element gone
```

## 벡터 조건식

벡터에 비교 연산을 적용하면 같은 길이의 불리언 벡터를 반환해요.
이는 `all()`이나 `any()` 같은 함수 안에서 매우 편리할 수 있어요:

```R
v <- c(4, 7, 10)
v >= 6
#> [1] FALSE  TRUE  TRUE
all(v > 6)
#> [1] FALSE    # not all elements match this condition
any(v > 6)
#> [1] TRUE     # at least one element matches
```

더 복잡한 논리 표현식에서는 벡터에 작동하는 `&`와 `|` 연산자를 사용하는 것이 중요해요.
두 글자짜리 `&&`와 `||`는 단일 값 비교만을 위한 것이에요.

```R
v %% 2 == 0 & v > 5
#> [1] FALSE FALSE  TRUE
```
