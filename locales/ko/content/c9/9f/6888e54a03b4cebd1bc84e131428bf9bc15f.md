# 연료 변환 JSON

## 문제 설명

ABC Corp의 모든 직원은 연료를 무제한으로 지원받아요. 직원들은 차량에 주유할 때마다 기록을 보내야 해요. 이 기록들은 같은 JSON 파일에 이어서 추가되고, 월말에 처리돼요.

디지털 운영 팀의 일원으로서, 이 JSON 파일을 읽고 그 결과를 다른 JSON 파일에 작성하는 작업을 맡게 돼요. 출력 파일에는 각 직원에 대한 항목이 다음 정보와 함께 포함되어야 해요:

- 직원 번호
- 주유 횟수
- 총 연료비
- 총 갤런 수
- 총 누적 마일

두 개의 `string` 인자가 주어져요.

1. 입력 JSON 파일 경로.
1. 출력 JSON 파일 경로.

입력 JSON 파일에는 JSON 객체의 배열이 들어 있어요. 각 JSON 객체는 다음과 같은 형태예요.


```json
{
    "type": "array",
    "items": {
        "type": "object",
        "properties": {
            "employeeId": {
                "type": "integer"
            },
            "odometerReading": {
                "type": "integer"
            },
            "gallons": {
                "type": "number"
            },
            "gasPrice": {
                "type": "number"
            }
        },
        "required": [
            "employeeId",
            "odometerReading",
            "gallons",
            "gasPrice"
        ]
    }
}
```

```ballerina
// Ballerina record type definition
type FillUpEntry record {|
    int employeeId;
    int odometerReading;
    decimal gallons;
    decimal gasPrice;
|};
```

이제 JSON 입력을 다음 JSON 형식으로 변환하고, 그 내용을 주어진 경로에 작성하는 것이 과제예요. 출력 파일에는 각 직원에 대한 항목이 포함되어야 하며, `employeeId`를 기준으로 오름차순으로 정렬해야 해요.

```json
{
    "type": "array",
    "items": {
        "type": "object",
        "properties": {
            "employeeId": {
                "type": "integer"
            },
            "gasFillUpCount": {
                "type": "integer"
            },
            "totalFuelCost": {
                "type": "number"
            },
            "totalGallons": {
                "type": "number"
            },
            "totalMilesAccrued": {
                "type": "integer"
            }
        },
        "required": [
            "employeeId",
            "gasFillUpCount",
            "totalFuelCost",
            "totalGallons",
            "totalMilesAccrued"
        ]
    }
 }
```

```ballerina
// Ballerina record type definition
type EmployeeFillUpSummary record {|
    int employeeId;
    int gasFillUpCount;
    decimal totalFuelCost;
    decimal totalGallons;
    int totalMilesAccrued;
|};
```

## 제약 조건

- 입력 JSON 파일의 주유 기록 수 `n`: 0 <= n <= 1000
- 회사의 직원 수: 97
- 연료 가격은 갤런당 가격이에요
- 누락된 주유 기록은 없어요

## 힌트

- JSON 파일을 읽고 쓰려면 [`ballerina/io` 모듈](https://lib.ballerina.io/ballerina/io/latest)을 사용해요.
- JSON 값을 애플리케이션에 특화된 타입으로 변환하면 데이터를 타입에 안전한 방식으로 다룰 수 있어요. 자세한 내용은 Ballerina By Examples(BBE)에 있는 [사용자 정의 타입으로 변환하기 예제](https://ballerina.io/learn/by-example/convert-from-json-to-user-defined-type)를 참고해요.

```ballerina
   json jsonPayload = {id: "2", title: "Jeru", artist: "Gerry Mulligan", price: 17.99};

   // Using cloneWithType  
   Album album1 = check jsonPayload.cloneWithType();
   io:println(album1);
 
   // Using fromJsonWithType
   Album album2 = check jsonPayload.fromJsonWithType();
   io:println(album2);
```

- [레코드 구조 분해](https://ballerina.io/learn/by-example/destructure-records-using-query)는 코드의 장황함을 줄이는 데 유용할 수 있어요.

```ballerina
   Album {id, title, artist, price} = album1;
   io:println(id);
   io:println(title);
```

- 표현식이 하나뿐인 함수에는 표현식 본문 함수를 사용해요. 예를 들어 return 문만 있는 함수가 있어요.

```ballerina
   function cfr(int deaths, int cases) returns decimal => <decimal>deaths / <decimal>cases * 100;
```
