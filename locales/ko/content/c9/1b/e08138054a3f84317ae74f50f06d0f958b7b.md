# 테스트

## 테스트 실행하기

테스트를 실행하려면 다음 명령어를 실행해요:

```bash
dotnet test
```

소스 파일이 변경될 때마다 테스트를 자동으로 실행하려면 다음 명령어를 실행해요:

```bash
dotnet watch test
```

## 연습 문제 풀기

연습 문제를 푼다는 것은 모든 테스트를 통과시키는 것을 의미해요. 기본적으로 테스트를 실행하면 하나의 테스트(첫 번째 테스트)만 실행돼요. 이는 의도된 동작으로, 그 하나의 테스트를 통과시키는 데만 집중할 수 있게 해줘요. 통과시키고 나면, 테스트의 `[Fact]` 또는 `[Theory]` 특성에서 `Skip = "Remove this Skip property to run this test"`를 제거해서 다음 테스트를 활성화할 수 있어요. 모든 테스트를 활성화하고 구현이 모든 테스트를 통과하면, 연습 문제를 푼 거예요!

시작하는 데 도움이 되도록 각 연습 문제에는 스텁 구현 파일이 함께 제공돼요. 이 파일을 해결책을 만드는 출발점으로 사용할 수 있어요. 이 파일을 제거하거나 변경하는 것이 옳다고 생각되면 자유롭게 그렇게 해도 돼요.

## 패키지 사용하기

대부분의 연습 문제는 외부 패키지 없이 풀 수 있어요. 하지만 외부 패키지를 사용하고 싶은 연습 문제의 경우, 다음 명령어를 실행해서 프로젝트에 패키지를 추가할 수 있어요:

```bash
dotnet add package [package-name]
```
