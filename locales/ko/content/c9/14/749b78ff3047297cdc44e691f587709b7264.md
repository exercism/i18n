# 추천 학습 자료

ColdFusion(CFML)을 배우러 오신 것을 환영해요! CFML은 동적이고 타입을 느슨하게 다루는 JVM 스크립팅 언어예요. 파일 형식은 두 가지예요. `.cfm` 파일(ColdFusion 마크업)은 순수하게 절차적이고, HTML을 템플릿으로 만들 때 태그 기반 문법을 사용해요. 웹 사이트를 만들 때 뷰로 쓰게 되는 파일이에요:

**index.cfm**

```xml
<cfoutput>
	<html>
		<h1>Welcome to my site, #FirstName# #LastName#!
	</html>
</cfoutput>
```

다른 파일 형식은 `.cfc`(ColdFusion Component)이고, 클래스를 선언하는 방법이에요. 컴포넌트는 비즈니스 로직, 모델, 컨트롤러에 사용해요. 주로 스크립트 문법을 쓰는데, JavaScript와 비슷하게 읽혀요.

**Car.cfc**

```js
component accessors=true {
	property name='make' type='string';
	property name='model' type='string';
	property name='year' type='number';

	function init() {
		return this;
	}
 
}
```
