## 가져오기

모듈은 보통 `use` 키워드로 불러와요. 그러면 모듈을 불러오면서 동시에 모듈의 `import` 메서드를 호출해서, 내보낸 심볼을 모두 가져와요.

기본적으로는 패키지의 `@EXPORT` 배열에 있는 심볼을 가져와요. 패키지의 `@EXPORT_OK` 배열에 있는 심볼은 명시적으로 가져와야 해요.

Perl `v5.37` 이전에는 모듈이 성공적으로 로드되었음을 나타내기 위해 모듈이 참인 값(보통 `1`)으로 끝나야 했어요. [`module_true`][module_true] 기능을 사용하면 이렇게 할 필요가 없어요.

## 내보내기

심볼을 가져오려면 먼저 그 심볼을 내보내야 해요. [Exporter][Exporter] 모듈은 Perl에 함께 포함되어 있고, 내보내기에 가장 편리한 방법 중 하나예요.

모듈을 정의할 때는 이렇게 해요:
```perl
package Foo;

use Exporter ('import');
our @EXPORT_OK = ('bar');

sub bar { ... }
```

모듈을 사용할 때는 이렇게 해요:
```perl
use Foo ('bar');

bar();
```

## 프래그마

프래그마는 Perl의 동작 중 일부 측면에 영향을 주는 모듈이에요.

[`strict`][strict]와 [`warnings`][warnings] 프래그마는 흔히 권장되는데, 각각 안전하지 않은 구문을 제한하고 잠재적인 문제를 알려주기 위해서예요. `strict` 프래그마는 `use v5.12` 이상과 함께 활성화돼요. `warnings` 프래그마는 `use v5.35` 이상과 함께 활성화돼요.

[`feature`][feature] 프래그마를 사용하면 더 새롭고 실험적인 Perl 기능을 켤 수 있어요. `use` 키워드에 특정 Perl 버전을 지정하면, 그 버전의 기능 묶음이 활성화돼요.

## 코어 모듈

[Exporter][Exporter]와 함께, Perl에는 사용할 수 있는 다양한 [core modules][perl-core-modules]가 있어요. 여기서 만나게 될 연습 문제에 유용한 예로는 [List::Util][List::Util], [Time::Piece][Time::Piece], [Math::BigRat][Math::BigRat] 등이 있어요.

코어 모듈 외에도, [CPAN][metacpan]에는 Perl 커뮤니티가 만든 수천 개의 추가 모듈을 설치할 수 있어요. Perl 트랙은 [cpanfile][test-runner-cpanfile]을 사용해서 Exercism의 Perl 테스트 러너와 함께 쓸 수 있는 모듈을 골라 설치해요.
