# 지시 사항

마법사와 전사 게임이라는 주제를 이어서, 이제 어디에나 쓸 수 있는 주사위 굴리기 메서드를 추가할 차례예요. 1부터 18까지의 숫자가 있는 전통적인 18면 주사위예요. 플레이어는 주문 강도도 생성해요.

## 1. _마법사와 전사_ 플레이어가 주사위를 굴릴 수 있게 해요.

`Player` 클래스에 `RollDie()` 메서드를 구현해요.

```csharp
var player = new Player();
player.RollDie();
// => >= 1 <= 18
```

## 2. 플레이어에게는 주문 강도가 필요해요. 주문 강도를 생성하는 방법을 제공해요

플레이어 클래스에 `GenerateSpellStrength()` 메서드를 구현해요. 주문 강도는 0.0 이상 100.0 미만이에요.

주문 강도는 정수가 아닌 실수여야 해요. 그래야 두 상대방의 강도를 비교할 때 동점이 나올 가능성이 줄어들어요.

```csharp
var player = new Player();
player.GenerateSpellStrength();
// => >= 0.0 < 100.0
```
