# 지침 추가

## 레지스터

| 레지스터 | 용도      | 타입    | 설명                          |
| -------- | --------- | ------- | ----------------------------- |
| `$a0`    | 입력      | 주소    | 인수 워드의 배열              |
| `$a1`    | 입력      | 정수    | 인수의 개수                   |
| `$a2`    | 입력      | 정수    | 상한                          |
| `$v0`    | 출력      | 정수    | 상한 이내의 배수의 합         |
| `$t0-9`  | 임시      | 임의    | 임시 저장에 사용              |
