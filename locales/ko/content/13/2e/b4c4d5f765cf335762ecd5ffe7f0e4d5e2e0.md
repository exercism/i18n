# 도움말

## 테스트 실행하기

Factor 트랙은 **Factor 0.101**을 사용해요. [설치하기](https://exercism.org/docs/tracks/factor/installation)를 마친 뒤, 이 연습 문제의 디렉터리에서 다음을 실행해요:

```
factor -roots=. -run=exercism-tools <exercise>
```

예를 들어 `hello-world`라면 이렇게 해요:

```
factor -roots=. -run=exercism-tools hello-world
```

각 연습 문제에는 테스트 실행을 담당하는 작은 `exercism-tools` 보캐뷸러리가 함께 들어 있어요. 러너는 모든 테스트가 통과하면 상태 코드 0으로 끝나고, 테스트가 하나라도 실패하면 0이 아닌 상태 코드와 함께 진단 출력을 내보내요.

### 건너뛴 테스트

기본적으로는 첫 번째 테스트만 실행돼요. 그 원리는 테스트 파일에 있는 `STOP-HERE` 줄이에요. 파싱할 때 이 줄은 Factor의 렉서에게 그 아래에 있는 모든 내용을 무시하라고 알려 주기 때문에, 러너는 위쪽에 있는 테스트만 보게 돼요. 첫 번째 테스트가 통과하면 두 가지 방법으로 더 많은 테스트를 활성화할 수 있어요:

- **`STOP-HERE` 줄을 삭제하면** 남아 있는 테스트를 한 번에 모두 활성화할 수 있어요.
- **`STOP-HERE` 줄을 더 아래로 옮기면** 테스트를 하나씩, 또는 작업 하나씩 활성화할 수 있어요. 개념 연습 문제는 테스트를 `TASK:` 표시 아래에 묶어 두는데, `STOP-HERE`를 다음 `TASK:` 바로 앞으로 옮기는 것이 자연스러운 방법이에요.

모든 테스트가 통과하면 연습 문제를 해결한 거예요.

## 풀이 제출하기

연습 문제 디렉터리에서 실행해요:

```
exercism submit <exercise>/<exercise>.factor
```

예를 들어 이렇게 해요:

```
exercism submit hello-world/hello-world.factor
```

연습 문제의 `.meta/config.json`에 풀이 파일이 여러 개 나열되어 있다면(일부 개념 연습 문제는 풀이를 도우미 하위 보캐뷸러리로 나눠 두기도 해요), 수정한 파일을 모두 `exercism submit`에 넘겨 주세요.

## 미완성 풀이 제출하기

테스트가 실패한 상태여도 풀이를 제출할 수 있어요. 그러면 다른 사람들이 이 연습 문제를 어떻게 풀었는지 볼 수 있고, 지금까지 만든 것에 대해 멘토의 피드백을 요청할 수도 있어요.

## 더 많은 도움 받기

- [Exercism 포럼의 Factor 카테고리](https://forum.exercism.org/c/programming/factor/)는 트랙별 질문과 피드백을 나누기에 가장 좋은 곳이에요.
- [Exercism Discord](https://exercism.org/r/discord)에는 일반적인 도움을 위한 채널과 개별 트랙을 위한 채널이 모두 있어요.
- Factor의 공식 문서는 검색도 잘 되고 내용도 아주 방대해요. 시작하기 좋은 두 지점은 이래요:
  - [Factor 핸드북](https://docs.factorcode.org/content/article-handbook.html)은 레퍼런스 형식으로, 보캐뷸러리별로 정리되어 있어요.
  - [Factor 쿡북](https://docs.factorcode.org/content/article-cookbook.html)은 주제별로 짧고 관용적인 예제를 모아 두었어요.
- Andrea Ferretti의 [Factor 튜토리얼](https://andreaferretti.github.io/factor-tutorial/)은 Factor 언어와 개발 환경을 빠르고 친근하게 소개해 줘요.
