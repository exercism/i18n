# 소개

Gleam은 오류 처리를 위해 예외를 사용하지 않아요. 대신 성공하거나 실패할 수 있는 함수는 제네릭 `Result` 타입을 반환해요.

`Result` 타입은 언어에 내장되어 있어서 직접 정의하거나 임포트할 필요가 없어요. 하지만 직접 정의한다면 다음과 같을 거예요:

```gleam
pub type Result(value, error) {
  Ok(value)
  Error(error)
}
```

`Ok` 변형은 함수가 성공했을 때 반환되고, `Error` 변형은 함수가 실패했을 때 반환돼요.

`Result`는 Gleam에서 아주 흔하기 때문에, Gleam 프로그래머들은 이를 더 쉽게 다루려고 [`gleam/result` 모듈](https://hexdocs.pm/gleam_stdlib/gleam/result.html)을 자주 사용해요.

`result.map` 함수는 결과가 `Ok`일 때 그 안의 값에 함수를 호출하거나, `Error`일 때는 그대로 통과시키는 데 사용할 수 있어요.

```gleam
Ok(1)
|> result.map(fn(x) { x + 1 })
// -> Ok(2)

Error("Oh no!")
|> result.map(fn(x) { x + 1 })
// -> Error("Oh no!")
```

`result.try` 함수도 비슷하지만, 콜백 함수는 결과를 반환해야 해요. 결과를 반환하는 여러 함수를 연결할 때 유용해요.

```gleam
Ok(1)
|> result.try(fn(x) { Ok(x + 1) })
// -> Ok(2)

Ok(1)
|> result.try(fn(x) { Error("Nope!") })
// -> Error("Nope!")
```
