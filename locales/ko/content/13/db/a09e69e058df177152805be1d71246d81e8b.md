# 지침

넷볼 클럽은 매 라운드가 끝난 뒤 순위표를 계산해야 해요.

네 가지 과제는 모두 `NETBALL_LADDER` 클래스 안에 작성해요.

## 1. 순위표 점수

승리하면 4점, 무승부면 2점이에요. 패배하면 점수는 없어요.

```sather
NETBALL_LADDER::ladder_points(3, 1)
-- => 14
```

## 2. 골 득실차

넣은 골에서 실점한 골을 뺀 값이에요. 음수가 될 수도 있어요.

```sather
NETBALL_LADDER::goal_difference(180, 205)
-- => -25
```

## 3. 치른 온전한 쿼터 수

쿼터는 15분이에요. 주어진 분이 온전한 쿼터로 몇 개인지 구해요.

```sather
NETBALL_LADDER::whole_quarters(38)
-- => 2
```

## 4. 현재 쿼터 경과 시간

같은 분이 주어졌을 때, 현재 쿼터에서 얼마나 지났는지 구해요.

```sather
NETBALL_LADDER::minutes_into_quarter(38)
-- => 8
```
