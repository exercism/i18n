# 설치

C 언어 트랙은 시스템에 다음 소프트웨어가 설치되어 있어야 해요:

* 최신 C 컴파일러
* Make 빌드 도구

Apple의 Xcode IDE는 컴파일러와 네이티브 빌드 시스템을 하나의 IDE(통합 개발 환경)로 결합해요.
Linux 환경에서는 보통 컴파일러와 네이티브 빌드 시스템을 각각 별도의 명령줄 도구로 제공해요.

## Linux

Linux 사용자에게는 컴파일러로 gcc 또는 clang이 필요하고, 네이티브 빌드에는 `make`가 필요해요.
Make는 대부분의 유닉스 시스템에 미리 설치되어 있지만, 대개 패키지 관리자를 통해 사용할 수 있어요.
Debian 및 Ubuntu 기반 배포판에서는 필요한 것이 아직 없다면 `sudo apt-get install build-essential`로 모두 설치할 수 있어요.

## MacOS

MacOS 사용자는 [Homebrew][]로 `brew install gcc` 또는 `brew install llvm`을 실행해 gcc나 clang을 설치할 수 있어요.

## Windows

Windows 10 사용자에게는 [Windows Subsystem for Linux][]를 사용하고 위의 linux 안내를 따라갈 것을 권장해요.

이전 버전의 Windows를 사용 중이거나 WSL Bash를 사용할 수 없다면 [MSYS][]나 [mingw-w64][]를 사용할 수 있어요.

[Homebrew]: https://brew.sh
[Windows Subsystem for Linux]: https://docs.microsoft.com/en-gb/windows/wsl/about
[MSYS]: https://www.msys2.org
[mingw-w64]: http://mingw-w64.org
