# 스니펫 추출기

[스니펫 추출기][snippet-extractor]는 학습자의 제출물을 받아 코드에서 "흥미로운" 처음 열 줄을 추출해요.
추출된 스니펫은 웹사이트의 여러 페이지에 표시돼요.

기본적으로는 앞에 있는 빈 줄은 무시하고 처음 열 줄을 표시해요.
이 처음 열 줄에는 주석 같은 것이 포함될 _수도_ 있는데, 이런 것은 보통 스니펫에 표시하기에 적합하지 않아요.

## 스니펫 추출 사용자 지정

각 트랙이 최소한 소스 코드에서 주석을 제거하도록 [스니펫 추출을 사용자 지정][snippet-extractor-customize]하는 것을 권장해요.
스니펫 추출을 사용자 지정하려면 다음이 필요해요:

1. 스니펫 추출을 설정하는 `lib/languages/<track_slug>.txt` 파일을 추가해요.
   이 파일은 [기본 모드][basic-mode] 또는 [확장 모드][extended-mode]를 사용할 수 있어요.
   확장 모드가 더 유연해서 대부분의 트랙이 확장 모드를 사용해요.
2. `tests/<track_slug>/<test_slug>` 디렉터리에 하나 이상의 테스트 케이스를 추가해요.
   각 테스트 디렉터리에는 두 개의 파일이 필요해요:

   1. `tests/<track_slug>/<test_slug>/code.<track_extension>`: 스니펫 추출기를 실행할 대상 코드
   2. `tests/<track_slug>/<test_slug>/expected_snippet.<track_extension>`: 예상 스니펫

[Arturo 언어의 스니펫 추출을 사용자 지정한 이 예시 풀 리퀘스트][example-pr]를 참고하세요.
