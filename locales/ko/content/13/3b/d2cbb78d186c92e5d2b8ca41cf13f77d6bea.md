# 지침

문구를 약어로 바꿔 보세요.

IT를 좋아하는 사람들은 TLA(세 글자 약어)를 정말 좋아해요!

Portable Network Graphics 같은 긴 이름을 약어(PNG)로 바꿔 주는 프로그램을 작성해서 재미있는 전문용어를 만들어 봐요.

구두점은 다음과 같이 처리해요. 하이픈은 (공백처럼) 단어 구분자이고, 나머지 구두점은 모두 입력에서 제거할 수 있어요.

예를 들어:

| Input                     | Output |
| ------------------------- | ------ |
| As Soon As Possible       | ASAP   |
| Liquid-crystal display    | LCD    |
| Thank George It's Friday! | TGIF   |
