# 불리언

하스켈에는 [`Bool`][bools]이라는 타입이 있어요.
`True`와 `False`로 이루어진 열거형이에요.

## 논리 연산자

하스켈에는 세 개의 논리 연산자(`not`, `||`, `&&`)가 있는데, 이들은 불리언을 조합해서 서로 다른 값을 만들어 내는 표현식을 만들어요.

### And 연산자(`&&`)

하스켈에서 [_and_ 연산자][and]는 `&&`로 나타내며, 두 값이 모두 `True`이면 `True`를 반환하고, 그렇지 않으면 `False`를 반환해요.
_and_ 연산자를 사용할 때는 `&&`의 오른쪽에 불리언 하나, 왼쪽에 또 하나를 놓아요.

```haskell
True && True
-- -> True

True && False
-- -> False
```

### Or 연산자(`||`)

하스켈에서 [_or_ 연산자][or]는 `||`로 나타내며, 주어진 값 중 **하나 이상**이 `True`이면 `True`를 반환해요.
두 값이 모두 `False`이면 `False`를 반환해요.
_or_ 연산자를 사용할 때는 `||`의 오른쪽에 불리언 하나, 왼쪽에 또 하나를 놓아요.

```haskell
True || True
-- -> True

True || False
-- -> True

False || False
-- -> False
```

### Not 연산자(`not`)

하스켈에서 _not_ 연산자는 `not`으로 나타내며, 주어진 불리언이 `False`이면 `True`를 반환하고, `True`이면 `False`를 반환해요.
_not_ 연산자를 사용할 때는 연산자(`not`) 뒤에 불리언 하나를 놓아요.

```haskell
not True
-- -> False

not False
-- -> True
```

## 괄호 사용하기(`()`)

불리언을 다룰 때는 괄호를 사용해서 어떤 불리언을 먼저 평가할지 정할 수 있어요.
괄호를 어떻게 사용하느냐에 따라 결과가 달라질 수 있어요.
하스켈에서는 괄호 안에 있는 것이 먼저 평가돼요.

```haskell
True && False && False || True
-- -> True

True && False && (False || True)
-- -> False
```

괄호 안에 있는 것이 먼저 평가되기 때문에, 다음 예시에서는 _not_ 연산자가 괄호 안의 표현식에 적용돼요.

```haskell
not True && False
-- -> False

not (True && False)
-- -> True
```

~~~~exercism/note
괄호는 결과에 영향을 줄 때만 사용하고, 그렇지 않으면 생략해요.
~~~~
