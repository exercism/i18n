# 배열

Cairo에서 배열은 같은 타입의 원소들을 모아 저장할 수 있는 자료 구조예요.
Cairo의 배열은 수정할 수 있는 방법이 제한적이에요.
배열의 끝에만 항목을 추가할 수 있고, 앞에서만 항목을 제거할 수 있어요.
사실 배열은 값을 수정할 수 없는 큐라고 할 수 있어요.

## 배열 생성

배열은 주로 `ArrayTrait` 트레이트를 사용해 만들어요. 다음 네 가지 방법 중 아무거나 써서 `[1, 2]` 원소 배열을 만들 수 있어요:

```rust
// 1. Passing the type to the `ArrayTrait`
let mut arr_type_in_trait = ArrayTrait::<felt252>::new();
arr_type_in_trait.append(1);
arr_type_in_trait.append(2);

// 2. Setting the type on the variable itself
let mut arr_explicit_type: Array<felt252> = ArrayTrait::new();
arr_explicit_type.append(1);
arr_explicit_type.append(2);

// 3. Using the `array!` macro
let mut arr_from_macro: Array<felt252> = array![1, 2]; // assign values in-line

// 4. Allowing the compiler to infer the type from the type of values being assigned to it
let mut arr_implicit_type = ArrayTrait::new(); // compiler "knows" this is a `felt252` array
arr_implicit_type.append(1);
arr_implicit_type.append(2);
```

> 각 `append()` 호출은 배열의 끝에 새로운 숫자를 넣어요.

## 배열 원소 제거하기

Cairo에서 배열의 원소를 제거하는 유일한 방법은 앞에서 제거하는 것이에요.
이 연산은 `pop_front()` 메서드로 수행하는데, 제거된 원소를 담고 있어 unwrap할 수 있는 `Option`을 반환하거나, 배열이 비어 있으면 `Option::None`을 반환해요.

```rust
fn main() {
    let mut a = array![10, 1, 2];
    let first_value = a.pop_front().unwrap(); // `unwrap()` is used to get the value from `Option`
    println!("The first value is {}", first_value); // prints "The first value is 10"
}
```

## 배열의 값에 접근하기

배열 원소에 접근하려면 서로 다른 타입을 반환하는 `get()` 또는 `at()` 배열 메서드를 사용할 수 있어요.
`arr.at(index)`와 같은 역할을 하는 것은 아래 첨자 연산자 `arr[index]`예요.

### get() 메서드 사용하기

`get()` 메서드는 목록에서 번호로 항목을 찾는 것과 비슷해요.
작동 방식은 이래요:

- `arr.get(index)`는 배열의 특정 위치(인덱스)에 있는 항목을 가져올 수 있게 해줘요.
- 주어진 인덱스에 항목이 있으면 `Option::Some(value)`를 반환하고, 인덱스가 범위를 벗어나면 `Option::None`을 반환해요.

이 메서드는 인덱스가 유효하지 않을 수도 있는 상황을 프로그램이 중단되지 않고 처리하고 싶을 때 이상적이에요.

```rust
fn main() {
    let arr: Array<u32> = array![1, 2, 3];

    let index = 1;

    match arr.get(index) {
        Option::Some(value) => { println!("Element at index {}: {}", index, value.unbox()); },
        Option::None => { println!("Index {} is out of bounds!", index); }
    }
}
```

### at() 메서드 사용하기

`at()` 메서드는 박스에 저장된 값을 꺼내는 `unbox()` 연산을 사용해 특정 인덱스에 있는 원소의 스냅샷을 바로 제공해요.
이 메서드의 축약형은 아래 첨자 연산자 `arr[index]`를 쓰는 것이에요.
존재하지 않는 인덱스에 접근하려고 하면(범위를 벗어나면) 프로그램이 오류와 함께 패닉해요.

```rust
fn main() {
    let a: Array<u32> = array![5, 8];

    println!("First: {}", *a.at(0)); // prints "First: 5"
    println!("Second: {}", a[1]); // prints "Second: 8"
    println!("Third: {}", a[2]); // panics with 'Index out of bounds'
}
```

## 크기 관련 메서드

배열의 원소 개수를 알아내려면 `len()` 메서드를 사용해요.
반환 값은 `usize` 타입이에요.

배열이 비어 있는지 확인하고 싶으면 `is_empty()` 메서드를 사용할 수 있는데, 배열이 비어 있으면 `true`를, 그렇지 않으면 `false`를 반환해요.

## `Span`

`Span`은 `Array`의 스냅샷을 나타내는 구조체예요.
원본 배열을 수정하지 않고 배열의 원소에 안전하고 통제된 방식으로 접근할 수 있도록 설계되었어요.
`Span`은 함수 사이로 배열을 전달할 때나 읽기 전용 연산을 할 때 데이터 무결성을 보장하고 빌림 문제를 피하는 데 특히 유용해요.

> `Array`가 제공하는 모든 메서드는 `append()` 메서드를 제외하고 `Span`에서도 사용할 수 있어요.

`Array`의 `Span`을 만들려면 `span()` 메서드를 호출해요:

```rust
let my_array: Array<u32> = array![1, 2, 3];
let my_span: Span<u32> = my_array.span();
```

## 고정 크기 `Array` 타입

고정 크기 배열에서는 값을 대괄호 안에 쉼표로 구분해 나열해요.
배열의 타입은 대괄호 안에 각 원소의 타입, 세미콜론, 그리고 배열의 원소 개수를 써서 표현해요.

```rust
let arr: [u64; 5] = [1, 2, 3, 4, 5];
```

> 참고: 고정 크기 배열만 상수로 사용할 수 있어요

고정 크기 배열의 원소는 배열을 구조 분해하거나, 인덱싱을 지원하는 `Span`으로 변환해서 접근할 수 있어요.

```rust
fn main() {
    let arr = [1, 2, 3, 4, 5]; // implicit `felt252` array type

    // Accessing elements of a fixed-size array by deconstruction
    let [a, b, c, _, _] = arr;
    println!("c: {}", c); // c: 3
    
    // Accessing elements of a fixed-size array by index
    let my_span = arr.span();
    println!("my_span[2]: {}", my_span[2]); // my_span[2]: 3
}
```
