# 힌트

## 일반

- `TUPLE:`와 `boa`는 `kernel`에 인접한 vocab에 선언되어 있어요. 클래스를 선언할 때 특별한 USING은 필요 없고, 접근자 워드는 [`accessors`][accessors]에서 가져와요.

## 1. 기본 클래스

- `TUPLE: dragon name color age ;`는 세 개의 슬롯을 순서대로 가진 클래스를 선언해요. `<dragon>`은 한 줄이에요: `dragon boa`.

## 2. 불을 뿜는 드래곤

- `<` 부모 문법은 부모의 슬롯을 물려받아요: `TUPLE: fire-dragon < dragon flame-temp ;`. `boa` 생성자는 부모 슬롯을 먼저 받아요.

## 3. 얼음을 뿜는 드래곤

- 2번과 같은 모양에 추가 슬롯만 달라요. 형제 서브클래스끼리는 서로 상호작용하지 않아요. `fire-dragon`과 `ice-dragon`은 둘 다 `dragon`을 직접 상속해요.

## 4. 화산에 사는 드래곤

- `dragon`을 직접 상속하지 않고 `fire-dragon`을 상속해요. 그래야 `volcano-dragon`이 `dragon`의 슬롯과 `fire-dragon`의 `flame-temp`를 모두 물려받아요. `boa` 생성자는 name, color, age, flame-temp, lava-volume 다섯 개의 값을 받아요.

## 5. 모든 드래곤의 나이 바꾸기

- `change-age`는 값을 바꾸는 접근자예요. `( tuple quot -- tuple )`는 현재 나이에 쿼테이션을 적용하고 그 결과를 다시 써넣어요. `[ 1 + ] change-age drop`은 나이를 1만큼 늘리고 반환된 튜플을 버려요. 모든 자손이 이 슬롯을 물려받기 때문에, 같은 워드가 각 드래곤에서 똑같이 동작해요.
