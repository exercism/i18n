# 소개

[Range][range]는 두 값 사이의 구간을 나타내요.
Range는 보통 `Int`, `String`, `Character` 같은 타입과 함께 쓰여서 시퀀스를 순회하거나, 컬렉션을 잘라 내거나, 어떤 값이 범위 안에 들어오는지 확인해요.

Swift는 두 가지 주요 범위 연산자를 제공해요:

- **닫힌 범위 연산자(`...`)**: 시작 값과 끝 값을 모두 포함해요(`1...5`는 1, 2, 3, 4, 5를 모두 포함해요).
- **반열린 범위 연산자(`..<`)**: 시작 값은 포함하지만 끝 값은 포함하지 않아요(`1..<5`는 1, 2, 3, 4를 포함해요).

```swift
let closed = 1...5
let halfOpen = 1..<5
```

~~~~exercism/note
범위 리터럴에 메서드를 바로 호출할 때에는 컴파일러가 범위를 먼저 평가하도록 범위 표현식을 괄호로 감싸요:

```swift
(1...5).contains(3) // Returns true
// 1...5.contains(3) // Error: value of type 'Int' has no member 'contains'
```
~~~~

## 범위를 배열로 변환하기

`Array(_:)` 이니셜라이저를 사용하면 숫자 범위를 `Array`로 변환할 수 있어요:

```swift
let range = 1...5
let numbers = Array(range)
// numbers is [1, 2, 3, 4, 5]
```

## 범위로 배열 자르기

범위를 사용하면 배열의 일부분을 잘라낼 수 있어요:

```swift
let array = [10, 20, 30, 40, 50]
let slice = array[1...3]
// slice contains [20, 30, 40]
```

## 범위의 속성과 메서드

범위에서 자주 쓰이는 연산은 다음과 같아요:

| Member                  | Description                                                | Example                              |
| ----------------------- | ---------------------------------------------------------- | ------------------------------------ |
| `count`                 | 범위에 있는 원소의 개수를 반환해요                | `(1...5).count`는 `5`를 반환해요          |
| [`contains(_:)`][contains] | 범위에 지정한 값이 들어 있으면 `true`를 반환해요 | `(1...5).contains(3)`은 `true`를 반환해요 |

## 한쪽 범위

Swift는 시작 값이나 끝 값 중 하나를 생략하는 한쪽(부분) 범위도 지원해요:

- `array[2...]`: 인덱스 2부터 컬렉션의 끝까지예요.
- `array[...2]`: 컬렉션의 시작부터 인덱스 2까지이고, 인덱스 2도 포함해요.
- `array[..<2]`: 컬렉션의 시작부터 인덱스 2 바로 앞까지이고, 인덱스 2는 포함하지 않아요.

## 문자열과 문자 범위

`Comparable`을 준수하는 문자나 문자열 사이에도 범위를 만들 수 있어요:

```swift
let letters = "a"..."z"
print(letters.contains("m")) // Prints true
print(letters.contains("A")) // Prints false
```
