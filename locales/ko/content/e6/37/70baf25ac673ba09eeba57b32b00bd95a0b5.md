# 소개

쿼테이션이 주변에서 값을 *기억*해야 할 때, Factor는 두 가지 도구를 제공해요: [`kernel`][kernel]의 `curry`/`compose`와 [`fry`][fry]의 fry 문법 `'[ … ]`예요.

`curry`는 값 하나를 쿼테이션 앞부분에 미리 넣어 둬요:

```
curry ( value quot -- newquot )
```

```factor
3 [ + ] curry .          ! => [ 3 + ]
10 3 [ + ] curry call .  ! => 13
```

`compose`는 두 쿼테이션을 이어 붙여요:

```factor
[ 1 + ] [ 2 * ] compose .       ! => [ 1 + 2 * ]
5 [ 1 + ] [ 2 * ] compose call . ! => 12
```

한두 개가 넘는 값을 담아야 할 때는 fry가 더 깔끔해요. `_` 자리 표시자마다 스택에서 꺼낸 값이 순서대로 채워져요:

```factor
2 3 '[ _ _ + + ] .    ! => [ 2 3 + + ]
```

fry는 중첩된 쿼테이션 속까지 파고들 수 있어요.

[fry]: https://docs.factorcode.org/content/vocab-fry.html
