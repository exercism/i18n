# 지시 사항

학교 연극 오디션이 끝나서 연출가는 결정 사항을 적어 두어야 해요.

네 가지 과제는 모두 `CASTING_CALL` 클래스 안에서 작성해요.

## 1. 판정

모든 배우는 10점 만점으로 점수를 매겨요. 8점 이상이면 캐스팅되고, 5점에서 7점이면 다시 불러요. 5점 미만이면 감사 인사를 전해요.

```sather
CASTING_CALL::audition_outcome(8)
-- => "Cast"
CASTING_CALL::audition_outcome(6)
-- => "Recalled"
CASTING_CALL::audition_outcome(2)
-- => "Thank you"
```

## 2. 어느 그룹일까요?

13세 미만은 Juniors예요. 13세부터 15세까지는 Middles, 16세 이상은 Seniors예요.

```sather
CASTING_CALL::age_group(13)
-- => "Middles"
```

## 3. 언제 다시 와야 할까요?

Juniors는 4시에, Middles는 5시에, 나머지는 6시에 다시 불러요.

```sather
CASTING_CALL::callback_time("Middles")
-- => "5pm"
```

인자는 그룹의 이름이고, 2번 과제에 나온 철자 그대로 써야 해요.

## 4. 명단에 무엇을 적을까요?

8점 이상이면서 노래를 할 수 있는 사람은 `"Lead"`예요. 8점 이상이지만 노래를 하지 못하면 `"Speaking part"`이고, 그 외에는 모두 `"Chorus"`예요.

```sather
CASTING_CALL::casting_note(9, true)
-- => "Lead"
CASTING_CALL::casting_note(9, false)
-- => "Speaking part"
CASTING_CALL::casting_note(4, true)
-- => "Chorus"
```
