# 소개

## 배열

Elm의 [`List`][lists]는 같은 타입의 값 0개 이상을 담는 불변 컬렉션이에요.

배열은 다음과 같이 정의할 수 있어요:

```elm
empty = []
singleValue = [ 5 ]
threeValues = [ "a", "b", "c" ]
```

배열에 원소를 추가하는 가장 흔한 방법은 `::` (cons) 연산자를 사용하는 거예요:

```elm
twoToFour = [ 2, 3, 4 ]
oneToFour = 1 :: twoToFour --> [ 1, 2, 3, 4 ]
```

배열은 [`List` 모듈][list-module]에 정의된 함수와 연산자로 다루거나 [패턴 매칭][list-destructuring]으로 다뤄요.

```elm
describe : List String -> String
describe list =
    case list of
        [] ->
            "Empty list"

        [ "hello" ] ->
            "Singleton list with: hello"

        x :: xs ->
            "Non-empty list with head: " ++ x

describe []                   --> "Empty list"
describe [ "hello" ]          --> "Singleton list with: hello"
describe [ "hello", "world" ] --> "Non-empty list with head: hello"
```
