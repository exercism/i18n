# 지침

이 연습 문제에서는 친구가 개발 중인 새로운 RPG 게임의 퀘스트 로직을 구현해요.

게임의 주인공은 Annalyn으로, 사납고 충직한 반려견을 기르는 용감한 소녀예요. 그런데 안타깝게도 불행이 닥쳐요. 가장 친한 친구가 숲에서 열매를 찾다가 납치된 거예요.

Annalyn은 가장 친한 친구를 찾아 구출하려고 해요. 원한다면 이 퀘스트에 반려견을 데리고 갈 수도 있어요.

한동안 친구의 흔적을 따라간 끝에, 친구가 갇혀 있는 야영지를 발견해요. 알고 보니 납치범은 두 명이에요: 강력한 기사와 교활한 궁수죠.

납치범들을 찾은 Annalyn은 다음 행동 중 무엇을 할 수 있을지 고민해요:

- _빠른 공격_: 기사가 잠들어 있으면 빠른 공격을 할 수 있어요. 갑옷을 입는 데 시간이 걸려서 기사는 무방비 상태가 되거든요.
- _첩보_: 일행 중 적어도 한 명이 깨어 있으면 첩보를 할 수 있어요. 그렇지 않으면 첩보는 시간 낭비예요.
- _죄수에게 신호 보내기_: 죄수가 깨어 있고 궁수가 잠들어 있으면 새소리로 죄수에게 신호를 보낼 수 있어요. 궁수는 새소리 신호 훈련을 받아서 메시지를 가로챌 수 있기 때문이에요.
- _죄수 구출_: Annalyn은 야영지에 몰래 들어가 죄수를 구출할 수 있어요.
  이것은 위험한 행동이라 두 가지 방법 중 하나로만 성공할 수 있어요:
  - Annalyn이 반려견을 데리고 있으면 궁수가 잠들어 있을 때 죄수를 구출할 수 있어요.
    기사는 개를 무서워하고, 궁수는 Annalyn과 죄수가 도망치기 전에 준비할 시간이 없어요.
  - Annalyn이 개를 데리고 있지 않으면 Annalyn과 죄수는 아주 조심스러워야 해요!
    죄수가 깨어 있고 기사와 궁수가 모두 잠들어 있으면 Annalyn이 죄수를 구출할 수 있지만, 죄수가 잠들어 있으면 구출할 수 없어요: 죄수는 Annalyn이 갑자기 나타난 것에 놀라 기사와 궁수를 깨울 테니까요.

네 가지 과제가 있어요: 숲에서 만난 세 인물의 상태와 Annalyn의 반려견이 함께 있는지 여부에 따라 위 행동들을 할 수 있는지 판단하는 로직을 구현하는 거예요.

## 1. 빠른 공격을 할 수 있는지 확인하기

기사가 깨어 있는지를 나타내는 불리언 값을 받는 `can_fast_attack()` 메서드를 구현해요. 이 메서드는 기사의 상태에 따라 빠른 공격을 할 수 있으면 `TRUE`를 반환하고, 그렇지 않으면 `FALSE`를 반환해요:

```R
knight_is_awake <- TRUE
can_fast_attack(knight_is_awake)
# => FALSE
```

## 2. 일행을 첩보할 수 있는지 확인하기

기사, 궁수, 죄수가 각각 깨어 있는지를 나타내는 세 개의 불리언 값을 받는 `can_spy()` 메서드를 구현해요. 이 메서드는 세 인물의 상태에 따라 일행을 첩보할 수 있으면 `TRUE`를 반환하고, 그렇지 않으면 `FALSE`를 반환해요:

```R
knight_is_awake <- FALSE
archer_is_awake <- TRUE
prisoner_is_awake <- FALSE
can_spy(knight_is_awake, archer_is_awake, prisoner_is_awake)
# => TRUE
```

## 3. 죄수에게 신호를 보낼 수 있는지 확인하기

궁수와 죄수가 각각 깨어 있는지를 나타내는 두 개의 불리언 값을 받는 `can_signal_prisoner()` 메서드를 구현해요. 이 메서드는 두 인물의 상태에 따라 죄수에게 신호를 보낼 수 있으면 `TRUE`를 반환하고, 그렇지 않으면 `FALSE`를 반환해요:

```R
archer_is_awake <- FALSE
prisoner_is_awake <- TRUE
can_signal_prisoner(archer_is_awake, prisoner_is_awake)
# => TRUE
```

## 4. 죄수를 구출할 수 있는지 확인하기

네 개의 불리언 값을 받는 `can_free_prisoner()` 메서드를 구현해요. 처음 세 매개변수는 기사, 궁수, 죄수가 각각 깨어 있는지를 나타내요. 마지막 매개변수는 Annalyn의 반려견이 함께 있는지를 나타내요. 이 메서드는 세 인물의 상태와 Annalyn의 반려견 동반 여부에 따라 죄수를 구출할 수 있으면 `TRUE`를 반환하고, 그렇지 않으면 `FALSE`를 반환해요:

```R
knight_is_awake <- FALSE
archer_is_awake <- TRUE
prisoner_is_awake <- FALSE
pet_dog_is_present <- FALSE
can_free_prisoner(knight_is_awake, archer_is_awake, prisoner_is_awake, pet_dog_is_present)
# => FALSE
```
