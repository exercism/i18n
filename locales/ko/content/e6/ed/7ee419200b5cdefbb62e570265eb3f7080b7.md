# 지시 사항 추가

## 유리수 연산자

산술 함수는 일반적인 함수 호출, 정적 디스패치(즉, 메서드 호출 문법), 연산자를 모두 지원해요:

| 함수 호출 | 메서드 호출 | 연산자 |
| --- | --- | --- |
| `plus(r1, r2)` | `r1.plus(r2)` | `r1 + r2` |
| `minus(r1, r2)` | `r1.minus(r2)` | `r1 - r2` |
| `times(r1, r2)` | `r1.times(r2)` | `r1 * r2` |
| `div_by(r1, r2)` | `r1.div_by(r2)` | `r1 / r2` |

`reduce`를 구현해서 유리수를 기약분수로 약분해 봐요. 예를 들어 `6 / 8`을 `3 / 4`로 만들어요.
