# 소개

Lua(발음은 __루아__, 포르투갈어로 *달*이라는 뜻이에요)는 단순하면서도 강력하고, 가볍고, 빠르고, 이식성이 뛰어나며 임베딩이 가능한 스크립트 언어예요.
[PUC-Rio](https://www.puc-rio.br/)의 [팀](https://www.lua.org/authors.html)이 설계하고 구현하고 유지 관리하며, [LabLua](http://www.lua.inf.puc-rio.br/)에 자리 잡고 있어요.

Lua는 절차적, 객체 지향, 함수형, 데이터 주도 프로그래밍과 데이터 서술을 지원해요.
단순한 절차적 문법에 연관 배열과 확장 가능한 의미론에 기반한 강력한 데이터 서술 구조를 결합했어요.
Lua는 동적 타입 언어이고, 레지스터 기반 가상 머신으로 바이트코드를 해석해 실행하며, 증분 가비지 컬렉션을 통한 자동 메모리 관리를 갖추고 있어서 설정, 스크립팅, 빠른 프로토타이핑에 이상적이에요.

Lua는 임베디드 시스템과 게임을 중심으로 [많은 산업 분야](https://en.wikipedia.org/wiki/Category:Lua_(programming_language)-scriptable_software)에서 사용되어 왔어요.

Lua의 홈페이지는 [Lua.org](https://www.lua.org/)예요.
즐겁게 사용해 봐요!
