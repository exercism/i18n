# 설치

## 빠른 시작

``` shellsession
$ bash <(curl -s https://raw.githubusercontent.com/borkdude/babashka/master/install)
```

기본적으로 `/usr/local/bin`에 설치돼요. 설치 위치를 바꾸려면 디렉터리 이름을 지정해요:

``` shellsession
$ bash <(curl -s https://raw.githubusercontent.com/borkdude/babashka/master/install) /tmp
```

## Brew

Linux와 macOS용 바이너리는 brew를 통해 제공돼요.

설치:

    brew install borkdude/brew/babashka

업그레이드:

    brew upgrade babashka

## Arch (Linux)

`babashka`는 [Arch 사용자 저장소](https://aur.archlinux.org)에서 [사용할 수 있어요](https://aur.archlinux.org/packages/babashka-bin/). [yay](https://github.com/Jguer/yay), [yaourt](https://github.com/archlinuxfr/yaourt), [apacman](https://github.com/oshazard/apacman), [pacaur](https://github.com/rmarquis/pacaur) 같은 좋아하는 [AUR](https://aur.archlinux.org) 도우미로 설치할 수 있어요. 다음은 `yay`를 사용한 예시예요:

    yay -S babashka-bin

## Windows

Windows에서는 [scoop](https://scoop.sh/)과 [scoop-clojure](https://github.com/littleli/scoop-clojure) 버킷으로 설치할 수 있어요.

## 다운로드

[Github](https://github.com/borkdude/babashka/releases)에서 바이너리를 다운로드할 수도 있어요. Linux용으로는 Alpine에서 사용할 수 있는 정적 바이너리가 있어요.

[Docker hub](https://hub.docker.com/r/borkdude/babashka/)에서 이미지를 확인해 봐요.
