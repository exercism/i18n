# 힌트

2D 회전에 복소수를 사용하면 훨씬 깔끔해지고 수치적으로도 더 정확해져요.

## 1. 데카르트 좌표로 복소수 만들기

- 내장 [`complex(x, y)`][complex] 메서드가 `x + im*y`를 대입하는 것보다 더 효율적이에요.
- 복습은 소개를 참고해요.

## 2. 극좌표로 복소수 만들기

- 같은 결과를 얻는 방법이 몇 가지 있어요 (예: `exp`, `cis`, `cispi`).
- 더 자세한 복습은 소개와 안내를 참고해요.

## 3. 2D 벡터 회전 수행하기

- [오일러 공식][euler]이 여기서 큰 도움이 돼요. `euler` 함수를 활용해도 좋아요.
- 복소수의 [실수][real] 부분과 [허수][imaginary] 부분을 가져오는 메서드가 있어요. 둘 다 한 번에 가져올 수도 있고요!

## 4. 반경 방향 변위 수행하기

- `euler` 함수를 쓸 수도 있고, 안 쓸 수도 있어요...
- 내장 [`angle`][angle] 메서드로 복소수에서 편각을 빠르게 구할 수 있어요.
- [`abs`][abs] 메서드로 복소수의 크기를 구할 수 있어요.

## 5. 원하는 노래 찾기

- `rotate`와 `rdisplace` 함수를 조합하기 좋은 기회예요.
