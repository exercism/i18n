# 안내

예비 마술사인 Elyse는 기초를 좀 연습해야 해요.
Elyse에게는 조작하고 싶은 카드 스택이 있어요.

조금 더 쉽게 하기 위해 Elyse는 1부터 10까지의 카드만 사용해서, 카드 스택을 숫자 배열로 나타낼 수 있어요.
특정 카드의 위치는 배열의 인덱스에 대응해요.
즉, 위치 0은 첫 번째 카드, 위치 1은 두 번째 카드를 가리켜요.

~~~~exercism/note
모든 함수는 카드 배열을 수정한 다음, 수정된 배열을 반환해야 해요. 이는 Builder pattern이라고 알려진 흔한 작업 방식으로, 함수들을 멋지게 연결할 수 있게 해줘요.
~~~~

## 1. 스택에서 카드 가져오기

카드를 고르려면, 주어진 스택에서 인덱스 `position`에 있는 카드를 반환해요.

두 개의 인자를 받는 `getCard(at:from:)` 함수를 구현해요. `at`은 스택에서 카드의 위치이고, `from`은 카드 스택이에요.
이 함수는 주어진 스택에서 위치 `index`에 있는 카드를 반환해야 해요.

```swift
let index = 2
getCard(at: index, from: [1, 2, 4, 1])
// returns 4
```

## 2. 스택의 카드 바꾸기

손재주를 좀 부려서, 인덱스 `position`에 있는 카드를 주어진 교체 카드와 바꿔요.

세 개의 인자를 받는 `setCard(at:in:to)` 함수를 구현해요. `at`은 스택에서 카드의 위치, `in`은 카드 스택, `to`는 위치 `index`에 있는 카드를 대체할 새 카드예요.
이 함수는 위치 `index`에 있는 카드가 새 카드로 바뀐 스택의 복사본을 반환해야 해요.
주어진 `index`가 스택에서 유효한 인덱스가 아니면, 원래 스택을 변경 없이 그대로 반환해야 해요.

```swift
let index = 2
let newCard = 6
setCard(at: index, in: [1, 2, 4, 1], to: newCard)
// returns [1, 2, 6, 1]
```

## 3. 스택 맨 위에 카드 넣기

스택 맨 위에 새 카드를 넣어서 카드가 나타나게 해요.

두 개의 인자를 받는 `insert(_:atTopOf:)` 함수를 구현해요. 인자는 삽입할 새 카드와 카드 스택이에요.
이 함수는 주어진 새 카드가 스택 맨 위에 추가된 스택의 복사본을 반환해야 해요.

```swift
let newCard = 8
insert(newCard, atTopOf: [5, 9, 7, 1])
// returns [5, 9, 7, 1, 8]
```

## 4. 스택에서 카드 제거하기

스택에서 주어진 `position`에 있는 카드를 제거해서 카드가 사라지게 해요.

두 개의 인자를 받는 `removeCard(at:from:)` 함수를 구현해요. `at`은 스택에서 카드의 위치이고, `from`은 카드 스택이에요.
이 함수는 위치 `index`에 있는 카드가 제거된 스택의 복사본을 반환해야 해요.
주어진 `index`가 스택에서 유효한 인덱스가 아니면, 원래 스택을 변경 없이 그대로 반환해야 해요.

```swift
let index = 2
removeCard(at: index, from: [3, 2, 6, 4, 8])
// returns [3, 2, 4, 8]
```

## 5. 스택에 카드 넣기

스택의 주어진 `position`에 새 카드를 넣어서 카드가 나타나게 해요.

세 개의 인자를 받는 `insert(_:at:from:)` 함수를 구현해요. 인자는 삽입할 새 카드, 새 카드를 삽입할 위치, 카드 스택이에요.
이 함수는 주어진 새 카드가 주어진 위치에 추가된 스택의 복사본을 반환해야 해요.
주어진 `index`가 스택에서 유효한 인덱스가 아니면, 원래 스택을 변경 없이 그대로 반환해야 해요.

```swift
let newCard = 8
insert(newCard, at: 2, from: [5, 9, 7, 1])
// returns [5, 9, 8, 7, 1]
```

## 6. 스택의 크기 확인하기

스택의 크기가 `stackSize`와 같은지 아닌지 확인해요.

두 개의 인자를 받는 `checkSizeOfStack(_:_:)` 함수를 구현해요. `stack`은 카드 스택이고, `stackSize`는 스택의 크기예요.
이 함수는 스택의 크기가 `stackSize`와 같으면 `true`를, 그렇지 않으면 `false`를 반환해야 해요.

```swift
let stackSize = 4
checkSizeOfStack([3, 2, 6, 4, 8], stackSize)
// returns false
```
