# 소개

루프의 반복 횟수를 미리 알 수 없을 때, 즉 "어떤 조건이 더 이상 참이 아닐 때까지 계속 반복"해야 할 때는 Factor의 [`kernel`][kernel]에 있는 `while` 컴비네이터를 사용해요.

```
while ( pred body -- )
```

`pred`와 `body`는 모두 데이터 스택에서 동작하는 quotation이에요. `while`은 `pred`를 호출해서, 스택 맨 위에 참으로 평가되는 값이 남으면 `body`를 실행하고 이 과정을 반복해요. 그렇지 않으면 멈춰요. 한 반복에서 다음 반복으로 이어지는 상태는 호출 사이의 스택에 그대로 남아 있어요(상태가 둘 이상일 때는 이름이 붙은 로컬을 사용해요).

```factor
USING: kernel math ;

5 [ dup 0 > ] [ dup . 1 - ] while drop
! prints 5 4 3 2 1
```

`until`은 대칭을 이루는 형태예요. 조건이 참으로 평가될 때까지 계속 반복해요.

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
