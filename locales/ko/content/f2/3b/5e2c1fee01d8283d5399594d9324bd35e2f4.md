# 안내

나이가 초 단위로 주어지면, 태양계의 행성에서 그 사람이 몇 살이 되는지 계산해요.

지구의 1년은 365.25 지구일, 즉 31,557,600초예요.
누군가의 나이가 1,000,000,000초라고 하면, 그 사람의 나이는 지구 년으로 31.69살이에요.

다른 행성의 경우에는 지구 년으로 나타낸 공전 주기를 고려해야 해요:

| 행성 | 지구 년으로 나타낸 공전 주기 |
| ------- | ----------------------------- |
| 수성 | 0.2408467                     |
| 금성 | 0.61519726                    |
| 지구 | 1.0                           |
| 화성 | 1.8808158                     |
| 목성 | 11.862615                     |
| 토성 | 29.447498                     |
| 천왕성 | 84.016846                     |
| 해왕성 | 164.79132                     |

~~~~exercism/note
지구가 태양 주위를 한 바퀴 완전히 도는 실제 시간은 365.256일(항성년 1년)에 더 가까워요.
그레고리력은 평균적으로 365.2425일이에요.
완전히 정확하지는 않지만, 이 연습 문제에서는 365.25를 사용해요.
1년을 재는 더 다양한 방법은 [위키백과의 년 문서][year]를 참고해요.

[year]: https://en.wikipedia.org/wiki/Year#Summary
~~~~
