# 지침

이번 연습 문제에서는 게임 진행 방식과 점수 계산 방식 등 [블랙잭][blackjack]의 몇 가지 규칙을 구현해 봐요.

**참고**: 이 연습 문제에서 _`A`_는 에이스를, _`J`_는 잭을, _`Q`_는 퀸을, _`K`_는 킹을 의미해요.
조커는 제외해요.
[표준 프렌치 수트 52장 카드 덱][standard_deck]을 기준으로 하지만, 대부분의 게임에서는 여러 덱을 섞어서 사용해요.

## 1. 카드의 값 계산하기

블랙잭에서는 에이스가 1점인지 11점인지를 각 플레이어가 직접 정해요(_이 부분은 나중에 더 자세히 다뤄요_).
그림 카드(`J`, `Q`, `K`)는 10점으로 계산하고, 나머지 카드는 "핍"(_숫자_) 값만큼의 점수를 가져요.

매개변수 `card`를 가지는 `value_of_card(<card>)` 함수를 정의해요.
이 함수는 전달받은 카드 문자열의 _숫자 값_을 반환해야 해요.
에이스는 여러 값을 가질 수 있으므로(1 **또는** 11), 이 함수에서는 일단 에이스 카드의 값을 1로 고정해요.
나중에 기존 패가 주어졌을 때 에이스 카드의 값을 결정하는 함수를 구현하게 될 거예요.

```python
>>> value_of_card('K')
10

>>> value_of_card('4')
4

>>> value_of_card('A')
1
```

## 2. 어떤 카드의 값이 더 큰지 판별하기

매개변수 `card_one`과 `card_two`를 가지는 `higher_card(<card_one>, <card_two>)` 함수를 정의해요.
점수 계산에서 `J`, `Q`, `K`의 값은 10이에요.
이 함수는 점수 계산에서 어느 카드의 값이 더 큰지 반환해야 해요.
두 카드의 값이 같으면 둘 다 반환해요.
`return`문에서 쉼표를 사용하면 두 카드를 모두 반환할 수 있어요:

```python
# Using a comma in a return creates a Tuple.  Tuples will be covered in a later exercise.
>>> def returning_two_values(value_one, value_two):
        return value_one, value_two

>>> returning_two_values('K', '3')
('K', '3')
```

에이스는 여러 값을 가질 수 있으므로, 이번 과제에서는 `A` 카드의 값을 1로 고정할게요.

```python
>>> higher_card('K', '10')
('K', '10')

>>> higher_card('4', '6')
'6'

>>> higher_card('K', 'A')
'K'
```

## 3. 에이스의 값 계산하기

앞에서 말했듯이, 에이스는 1점 **또는** 11점의 값을 가질 수 있어요.
플레이어는 21점을 _넘지 않으면서_ 최대한 21점에 가까워지려고 해요(21점을 넘는 것을 "버스트"라고 해요).

매개변수 `card_one`과 `card_two`를 가지는 `value_of_ace(<card_one>, <card_two>)` 함수를 정의해요.
이 두 매개변수는 에이스 카드를 받기 _전에_ 이미 패에 있는 두 장의 카드예요.
이 함수는 곧 받을 에이스가 1의 값을 가질지 11의 값을 가질지 결정하고, 그 값을 반환해야 해요.
기억해요: 에이스가 포함된 패의 값은 21을 넘지 _않으면서_ 최대한 높아야 해요.

**힌트**: 이미 패에 에이스가 있다면, 곧 받을 에이스의 값은 1이 돼요.

```python
>>> value_of_ace('6', 'K')
1

>>> value_of_ace('7', '3')
11
```

## 4. "내추럴" 또는 "블랙잭" 패인지 판별하기

플레이어가 처음 두 장으로 에이스(`A`)와 10 카드(10, `K`, `Q`, `J`)를 받으면 21점이 돼요.
이것을 **블랙잭** 패라고 해요.

매개변수 `card_one`과 `card_two`를 가지는 `is_blackjack(<card_one>, <card_two>)` 함수를 정의해요. 이 두 매개변수는 한 쌍의 카드예요.
두 장으로 이루어진 패가 **블랙잭**인지 판별하고, 맞으면 불리언 `True`를, 아니면 `False`를 반환해요.

**참고**: 점수 _계산_은 여러 가지 방법으로 할 수 있어요.
하지만 가능하다면, 패의 값을 _더하는_ 방식 대신 패 **_안에_** 에이스와 10 카드가 있는지(_또는 특정 위치에 있는지_) 확인해 봐요.

```python
>>> is_blackjack('A', 'K')
True

>>> is_blackjack('10', '9')
False
```

## 5. 페어 스플릿

패의 처음 두 카드가 같은 값이면(_예를 들어 6 두 장이나 `Q`와 `K`_), 플레이어는 이 둘을 각각 별개의 패로 나눠서 다룰 수 있어요.
이것을 "페어 스플릿"이라고 해요.

매개변수 `card_one`과 `card_two`를 가지는 `can_split_pairs(<card_one>, <card_two>)` 함수를 정의해요. 이 두 매개변수는 한 쌍의 카드예요.
이 두 장짜리 패를 두 쌍으로 나눌 수 있는지 판별해요.
패를 나눌 수 있으면 불리언 `True`를, 아니면 `False`를 반환해요

```python
>>> can_split_pairs('Q', 'K')
True

>>> can_split_pairs('10', 'A')
False
```

## 6. 더블 다운

처음 받은 두 카드의 합이 9, 10, 11점이면, 플레이어는 원래 베팅한 금액과 같은 금액을 추가로 베팅할 수 있어요.
이것을 "더블 다운"이라고 해요.

매개변수 `card_one`과 `card_two`를 가지는 `can_double_down(<card_one>, <card_two>)` 함수를 정의해요. 이 두 매개변수는 한 쌍의 카드예요.
두 장짜리 패에 "더블 다운"을 할 수 있는지 판별하고, 할 수 있으면 불리언 `True`를, 아니면 `False`를 반환해요.

```python
>>> can_double_down('A', '9')
True

>>> can_double_down('10', '2')
False
```
