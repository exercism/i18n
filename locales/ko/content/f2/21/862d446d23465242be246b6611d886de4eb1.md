# 소개

Kotlin의 `when`은 여러 선택지 중 하나를 고르는 조건식이에요.
Java의 `switch`와 비슷하지만, `if` ... `else if` ... `else`를 연달아 쓰는 것보다 유연해요.

`if`처럼 `when`도 값을 만들어 내는 식으로 사용할 수 있어요.

## 값으로 비교하기

`when` 뒤 괄호 안에 비교할 값을 넣어요.
그러면 각 분기가 그 값을 하나씩 비교하다가 일치하는 것을 찾아요:

```kotlin
val animal = "chicken"
val type = when (animal) {
    "chicken" -> "bird"
    "poodle" -> "dog"
    else -> "unknown"
}
// type => "bird"
```

- 각 분기는 `pattern -> result` 형태로 작성해요.
- 분기는 일치하는 것을 찾을 때까지 위에서 아래로 차례로 확인해요.
  처음 일치한 분기만 실행돼요.
- 위에 나열되지 않은 값은 `else`로 처리해요. (`if` 체인에서 마지막 `else`와 비슷해요.)

이것은 [패턴 매칭][pattern-matching]과 비슷해요.
`pattern` 자리에는 비교할 값을 쓸 수도 있고, `is`를 사용해 타입으로 비교할 수도 있어요:

```kotlin
fun typeText(subject: Any): String {
    return when(subject) {
        is Animal -> "Animal"
        is Fruit -> "Fruit"
        is String -> "Text"
        else -> "Unknown"
    }
}
```

또는 `in`을 사용해 그 값이 범위, 컬렉션, 문자열, 그 밖에 `contains` 메서드가 있는 것에 포함되는지 확인할 수 있어요:

```kotlin
fun describe(number: Int, position: String) {
    // Range
    when(number) {
        in 1..10 -> println("From 1 to 10")
        in 11..20 -> println("From 11 to 20")
    }

    // Collection
    when(number) {
        in listOf(2, 4, 6) -> println("small even")
        in listOf(3, 5, 7) -> println("small odd")
    }

    // String
    when(position) {
        in "center middle" -> println("inner")
        in "left right boundary" -> println("outer")
    }
}
```

~~~exercism/note
`contains` [연산자 확장 함수][kotlin-operator-overloading]를 정의하면 다른 객체에서도 `in`을 사용할 수 있어요.
예를 들어 [Regex][kotlin-regex]와 함께 쓰면 이렇게 해요:

```kotlin
operator fun Regex.contains(text: CharSequence): Boolean = this.matches(text)

fun replace(input: String) {
    return when(input) {
        in Regex("""ani*""") -> println("animal")
        in Regex("""fru.*""") -> println("fruit")
        in Regex("""num.*""") -> println("number")
        else -> println("unknown")
    }
}
```

## 가드 조건

값을 비교할 때는 패턴 뒤에 `if`를 붙여 추가 조건을 둘 수 있어요.
이런 조건을 가드 조건이라고 해요.

```kotlin
val x = 5
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else -> "other"
}
// description => "x is 5, y is even"
```

`else if`도 사용할 수 있어요.

```kotlin
val x = 7
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else if y % 2 == 0 -> "y is an even number"
    else -> "other"
}
// description => "y is an even number"
```


## 조건으로 비교하기

또는 값을 생략하고 각 분기에 불리언 조건을 둘 수도 있어요:

```kotlin
val x = 5
val y = 8
val description = when {
    x % 2 != 0 -> "x is odd"
    y % 2 == 0 -> "y is even"
    else -> "neither condition matched first"
}
// description => "x is odd"
```

여기서도 분기는 위에서 아래로 확인하고, 조건이 `true`인 첫 번째 분기만 실행해요.

## `when`을 식으로 사용하기

`when`의 결과를 사용할 때(변수에 할당하거나 함수에서 반환하는 등)는 가능한 모든 경우를 다뤄야 해요.

- 값을 비교할 때는 가능한 모든 값을 이미 다루고 있지 않은 한 `else`를 추가해요. (예를 들어 `Boolean`이나 `enum`의 모든 값처럼요.)
- 조건으로 비교할 때는 `else` 분기가 꼭 필요해요. 컴파일러는 조건이 모든 경우를 다룬다는 것을 알 수 없기 때문이에요.

```kotlin
fun label(n: Int): String = when (n) {
    0 -> "zero"
    1 -> "one"
    else -> "other"
}
```
