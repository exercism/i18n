# 소개

[`Set`][set-docs]은 `List`와 달리 중복 값을 포함하지 않는다고 보장되는 순서 없는 컬렉션이에요.

`Set` 인터페이스의 제네릭 타입 매개변수는 `Set`에 담긴 원소의 타입을 나타내요:

```java
Set<Integer> ints = Set.of(1, 2, 3);
Set<String> strings = Set.of("alpha", "beta", "gamma");
Set<Object> mixed = Set.of(1, false, "foo");
```

참고로 `Set.of()` 메서드는 [_unmodifiable_][unmodifiable-set-docs] `Set` 인스턴스를 만들어요.
이 인스턴스에서 `add`나 `remove` 같은 메서드를 호출하려고 하면 실행 시점에 예외가 발생해요.

수정할 수 있는 `Set`을 만들려면 `Set` 인터페이스를 구현하는 클래스를 인스턴스화해야 해요.
이 인터페이스를 구현하는 내장 클래스 중 가장 많이 쓰이는 것은 [`HashSet`][hashset-docs] 클래스예요.

```java
Set<Integer> ints = new HashSet<>();
```

`Set` 인터페이스는 [`Collection`][collection-docs]과 [`Iterable`][iterable-docs] 인터페이스를 확장하기 때문에 다른 컬렉션 타입과 많은 메서드를 공유해요.
하지만 `Collection` 인터페이스와 눈에 띄게 다른 점은 `add`나 `remove` 같은 메서드가 `void`가 아니라 `boolean`을 반환한다는 건데, 이 값은 그 메서드가 호출될 당시 해당 항목이 `Set`에 포함되어 있었는지를 나타내요:

```java
Set<Integer> set = new HashSet<>();
set.add(1);
// => true
set.add(2);
// => true
set.add(1);
// => false
set.size();
// => 2
set.contains(1);
// => true
set.contains(3);
// => false
set.remove(3);
// => false
set.remove(2);
// => true
set.size();
// => 1
```
