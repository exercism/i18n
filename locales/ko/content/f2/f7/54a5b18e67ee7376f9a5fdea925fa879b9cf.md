# 안내

여러분은 정원에 찾아온 새가 몇 마리인지 기록하는 열정적인 탐조가예요. 보통은 공책에 하나씩 세어 가며 새를 기록하지만, 데이터를 더 잘 활용하기 위해 지난 몇 주간의 새 개체 수를 디지털화했어요.

## 1. 지금까지 센 새의 총 마릿수 구하기

데이터를 큰 그림에서 살펴보며 분석을 시작해 볼까요?
기록을 시작한 이후로 새를 모두 몇 마리나 세었는지 알아봐요.

하루에 센 새의 수를 담은 `Int` 배열을 받는 `totalBirdCount` 함수를 구현해요.
이 함수는 지금까지 센 새의 총 마릿수를 반환해야 해요.

```swift
let birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1]
totalBirdCount(birdsPerDay)
// Returns 34
```

## 2. 특정 주에 찾아온 새의 수 계산하기

이제 새 개체 수 데이터에 전반적으로 익숙해졌으니, 좀 더 세밀하게 분석해 보고 싶어요.

날짜별 새 개체 수 배열과 주 번호를 받는 `birdsInWeek` 함수를 구현해요.

이 함수는 해당 주에 센 새의 총 마릿수를 반환해요.
주 단위 기록은 항상 완전하게 채워져 있다고 가정해도 돼요.

```swift
let birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1]
birdsInWeek(birdsPerDay, weekNumber: 2)
// Returns 12
```

## 3. 집계 실수 고치기

그동안 새를 기록하는 내내 정원 멀리 구석에 숨어 있던 새가 한 마리 있었다는 걸 알게 됐어요.

이 새는 이틀에 한 번씩 항상 정원에 머물렀다는 걸 알아냈어요.

그 사이에 이 새가 정확히 어디에 있었는지는 모르지만, 정원에 없었던 것만큼은 확실해요.

탐조가의 직감은 이 새가 목록에서 처음 기록한 날에도 정원에 있었다고 알려줘요.

이 새로운 정보를 바탕으로, 날짜별로 센 새의 수를 담은 배열을 인자로 받아 집계 실수를 바로잡은 배열을 반환하는 `fixBirdCountLog` 함수를 작성해요.

```swift
var birdsPerDay = [2, 5, 0, 7, 4, 1]
fixBirdCountLog(birdsPerDay)
// Returns [3, 5, 1, 7, 5, 1]
```
