# 지침 추가

## 제한 사항

Rust의 표준 라이브러리에는 이미
[이진 탐색 함수](https://doc.rust-lang.org/std/primitive.slice.html#method.binary_search)가 있어요.
이 연습 문제에서는 이 함수를 사용하지 말고 다른 기본 도구만 사용해야 해요.

## 보너스 점수를 받으려면

테스트를 통과하고 코드도 깔끔하게 정리했나요? 원한다면 추가로 시도해 볼 만한 것들이 있어요.

- 지금의 find 함수는 아마 숫자 슬라이스에서만 동작할 거예요. 하지만 Rust의 타입 시스템은
  유연해서, 순서를 정할 수 있는 원소를 담은 모든 슬라이스에서 동작하는 find 함수를 만들 수
  있어요.
- 게다가 이 find 함수는 슬라이스뿐만 아니라 Vec이나 Array에서도 동시에 동작하게 만들 수
  있어요.

보너스 테스트를 실행하려면 `#[ignore]` 플래그를 제거하고 `generic` feature를 사용해
테스트를 실행해요. 다음과 같이요:

```bash
$ cargo test --features generic
```
