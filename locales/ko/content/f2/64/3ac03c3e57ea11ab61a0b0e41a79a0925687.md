# 소개

캐스팅과 형 변환은 식을 한 데이터 타입에서 다른 데이터 타입으로 바꾸는 서로 다른 방법이에요.

식은 캐스트 연산자 `(<type>)`를 사용해 다른 타입으로 캐스팅할 수 있어요.

```csharp
long l = 1000L;
int i = (int)l;

object o = new Random();
Random r = (Random)o;
```

타입이 서로 호환되지 않으면 `InvalidCastException`이 발생해요. 숫자의 경우에는 값을 받는 타입이 캐스팅한 값을 표현할 수 없다는 뜻이에요. 클래스의 경우에는 두 타입 중 하나가 다른 하나에서 파생되어야 해요. 구조체에도 당연히 똑같이 적용돼요.

_캐스팅_ 대신 `is` 연산자를 사용하는 _형 변환_이라는 방법도 있어요. 이 방법은 보통 참조 타입과 null 허용 타입에 사용해요.

```csharp
object o = new Random();
if (o is Random rand)
{
    int ii = rand.Next();
    // now, do something random
}
```

객체의 정확한 타입을 알아내야 할 때는 `is`가 조금 너무 관대할 수 있어요. 어떤 클래스에 대해서도, 그리고 그 클래스가 직접 또는 간접적으로 파생된 모든 클래스와 인터페이스에 대해서도 true를 반환하기 때문이에요. 이럴 때는 `typeof`와 `Object.GetType()`이 해결책이에요.

```csharp
object o = new List<int>();

o is ICollection<int> // true
o.GetType() == typeof(ICollection<int>) // false
o is List<int> // true
o.GetType() == typeof(List<int>) // true
```
