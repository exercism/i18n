# 힌트

## 일반

- Erlang 라이브러리 사용법은 [공식 시작 가이드][getting-started-erlang-libraries]에서 살펴볼 수 있어요. 특히 [문자열 서식 지정][getting-started-formatted-text-output] 부분을 읽어봐요.

## 1. 무작위로 행성 생성하기

- 행성 등급을 나타내는 문자 목록이 담긴, 제공된 모듈 속성을 사용해요.
- 목록에서 원소를 무작위로 고르는 [내장 함수][enum-random]가 있어요.

## 2. 무작위로 우주선 등록 번호 생성하기

- 범위에서 원소를 무작위로 고르는 [내장 함수][enum-random]가 있어요.

## 3. 무작위로 스타데이트 생성하기

- 무작위 실수를 반환하는 Elixir 함수는 없어요.
- `0.0 <= x < 1.0`인 무작위 실수 x를 반환하는 [Erlang 내장 함수][erl-rand-uniform]가 있어요.
- `x`가 `0.0 <= x < 1.0` 범위에 속하는데 `a <= x < b`라는 다른 범위의 숫자가 필요하다면, x에 범위의 너비(`b - a`)를 곱하고 범위의 시작(`a`)을 더해서 x의 범위를 옮길 수 있어요. 즉, `x * (b - a) + a`예요.

## 4. 스타데이트 서식 지정하기

- 실수를 주어진 정밀도에 맞춰 한 번에 문자열로 서식 지정할 수 있는 Elixir 함수는 없어요.
- 서식 문자열과 데이터 목록을 받아서 charlist를 반환하는 [Erlang 내장 함수][erl-io-lib-format]가 있어요.
- charlist를 문자열로 바꿔 주는 [내장 함수][to-string]가 있어요.
- 그 함수의 서식 문자열에는 제어 시퀀스가 들어 있어요.
- 제어 시퀀스는 `~`로 시작하고 `~F.P.PadModC` 패턴을 가져요. 여기서 `F`는 출력의 너비, `P`는 정밀도, `Pad`는 채움 문자, `Mod`는 제어 시퀀스 수정자, `C`는 제어 시퀀스의 종류를 나타내요.
- 실수를 원하는 정밀도로 서식 지정하려면 `~.PC` 패턴의 제어 시퀀스로 충분해요.
- 실수에 대한 제어 시퀀스 종류는 `f`예요.
- 정확히 필요한 서식 문자열은 `~.1f`예요.
