# 소개

프로그램에서 사용자 정의 타입을 정의하면 유용할 때가 많아요.

새로운 원시 타입을 만드는 것도 가능하지만, 그럴 일은 거의 없어요.
내장 원시 타입은 임의로 정해진 게 아니라, Julia가 JIT 컴파일에 사용하는 LLVM 컴파일러의 표준 타입과 밀접하게 대응하기 때문이에요.

훨씬 유용한 것은 이름 있는 필드를 가진 복합 타입을 정의할 수 있다는 점이에요.

다른 언어에도 비슷한 것이 있어서 `structs`나 `records`라고 불러요.
그런데 Julia 문서에서는 이것을 `composite types`라고 부르고, (약간 어긋나게도) 언어 문법에서는 `struct` 키워드로 정의해요.

```julia-repl
julia> struct Person
           id
           name::String
           age::Integer
       end

julia> fred = Person(23, "Fred Smith", 46)
Person(23, "Fred Smith", 46)

julia> typeof(fred)
Person

julia> isstructtype(Person)
true

julia> isconcretetype(Person)
true

julia> fred.age
46
```

위 예시에서 몇 가지 짚어 볼 점이 있어요:

- `id`에는 타입을 지정하지 않았기 때문에 컴파일러가 이를 `id::Any`로 해석해요.
  - 실제로는 필드에 구체 타입을 지정해서 컴파일러를 돕는 게 가장 좋아요
- 타입 이름은 생성자로 사용돼서, `Person(id, name, age)`처럼 `Person` 타입의 인스턴스를 만들어요.
- 개별 필드는 네임드 튜플과 마찬가지로 점 표기법으로 접근할 수 있어요.

`Person` 타입의 항목은 불변이어서 수정할 수 없어요.

```julia-repl
julia> fred.age += 1
ERROR: setfield!: immutable struct of type Person cannot be changed
```

가변이 필요하면 정의에 `mutable`을 추가해요.

```julia-repl
julia> mutable struct MutPerson
           name
           age
       end

julia> shaila = MutPerson("Shaila", 23)
MutPerson("Shaila", 23)

julia> shaila.age += 1
24

julia> shaila
MutPerson("Shaila", 24)
```

생성자는 기본적으로 필드가 정의된 순서와 같은 순서로 나타나야 하는데, 타입이 복잡해지면 이것이 불편해져요.

`@kwdef` 매크로를 사용하면 두 가지 새로운 기능이 생겨요:

- 생성자가 위치가 아니라 키워드를 사용해요.
- 필드에 기본값을 줄 수 있고, 생성자에서 생략할 수도 있어요.

```julia-repl
julia> @kwdef struct KwPerson
           name
           age = 42
       end
KwPerson

julia> suki = KwPerson(age=29, name="Suki")
KwPerson("Suki", 29)

julia> qi = KwPerson(name="Qi")
KwPerson("Qi", 42)

# create a Vector{KwPerson}

julia> friends = [suki, qi]
2-element Vector{KwPerson}:
 KwPerson("Suki", 29)
 KwPerson("Qi", 42)
```

## 복합 타입 계층

지금까지는 구체 복합 타입만 만들어 봤어요.
확인해 보면, 모두 `Any`의 서브타입이에요.

서로 관련된 여러 타입을 만들 때는, 그것들을 위한 계층 구조를 정의하는 편이 아마 더 합리적이에요.
이건 아주 쉽게 할 수 있어요.

먼저 추상 타입을 만들어요:

```julia-repl
julia> abstract type AbstractPerson end

julia> supertype(AbstractPerson)
Any
```

다음으로, 관계를 나타내기 위해 타입 정의에 `<:` 연산자를 넣어요.

```julia-repl
julia> struct ConcretePerson <: AbstractPerson
            id
            name::String
            age::Integer
        end

julia> supertype(ConcretePerson)
AbstractPerson

julia> ConcretePerson(15, "Luis", 8)
ConcretePerson(15, "Luis", 8)
```

필요한 만큼 반복하는데, 구체 타입의 서브타이핑은 허용되지 않는다는 점을 기억해요.

더 복잡한 계층 구조가 필요하면, 필요에 따라 추상 서브타입을 만들어요.

```julia-repl
julia> abstract type AdultPerson <: AbstractPerson end

julia> supertype(AdultPerson)
AbstractPerson
```

이런 계층 구조의 가치는 `Multiple Dispatch` 개념에 이르러 함수가 인자 타입을 어떻게 다루는지 보면 더 분명해져요.
