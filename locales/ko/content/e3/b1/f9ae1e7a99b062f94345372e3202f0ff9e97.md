# 지침

근처에 "Tech Palace"라는 가전제품 가게가 있어요.
가게 주인은 최근 마케팅 메시지를 표시하고, 손님이 입구에서 이른바 로열티 카드를 스캔할 때 특별한 인사말을 보여주기 위해 커다란 디스플레이를 설치했어요.
이 디스플레이는 작은 LED 조명 여러 개로 이루어져 있고, 여러 줄의 텍스트를 표시할 수 있어요.

가게 주인은 새 디스플레이에 표시할 텍스트를 생성하는 코드에 대한 도움이 필요해요.

## 1. 환영 메시지 만들기

로열티 카드를 스캔하는 대부분의 손님에게는 디스플레이에 `Welcome to the Tech Palace, ` 뒤에 손님의 이름을 대문자로 표시하고 싶어 해요.

손님의 이름을 받아 원하는 메시지를 문자열로 반환하는 `welcome` 함수를 구현해요.

```julia-repl
julia> welcome("Judy")
"Welcome to the Tech Palace, JUDY"
```

## 2. 멋진 테두리 추가하기

가게에서 많이 구매하는 단골손님을 위해, 주인은 환영 메시지 앞뒤에 별 한 줄을 추가해서 환영 디스플레이를 더 멋지게 만들고 싶어 해요.
별이 각 줄에 몇 개 들어가야 할지는 아직 정하지 못해서, 그 개수를 설정할 수 있게 하고 싶어 해요.

환영 메시지와 줄당 별의 개수를 인자로 받는 `add_border` 함수를 작성해요.
이 함수는 3줄로 이루어진 문자열을 반환해야 해요. 원하는 개수의 별로 이루어진 줄, 전달받은 그대로의 환영 메시지, 그리고 또 다른 별 줄 순서예요.

```julia-repl
julia> add_border("Welcome!", 10)
"**********\nWelcome!\n**********"
```

## 3. 오래된 마케팅 메시지 정리하기

이 새 디스플레이를 설치하기 전에, 가게에는 설정을 바꿀 수 없는 고정된 줄만 표시할 수 있는 비슷한 디스플레이가 있었어요.
주인은 예전 마케팅 메시지 일부를 새 디스플레이에서 다시 사용하고 싶어 해요.
그런데 그 데이터에는 이미 불필요한 공백 문자가 들어 있어요. 이 공백은 여러 디스플레이를 위로 쌓아 올렸을 때 텍스트를 정렬하는 데 사용했던 것이에요.
이 메시지들을 다시 사용할 수 있도록 정리하는 것이 과제예요.

예전 마케팅 메시지를 받는 `clean` 함수를 구현해요.
이 함수는 먼저 텍스트의 앞뒤 공백을 모두 제거한 뒤 반환해야 해요.

```julia-repl
julia> clean("    BUY NOW, SAVE 10%   ")
"BUY NOW, SAVE 10%"
```
