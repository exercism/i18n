# 학습

Exercism은 연습 문제와 피드백을 제공하지만, Common Lisp를 처음 배우는 사람이라면 선뜻 시작하기 어려울 수 있어요.
다음 자료들이 시작하는 데 도움이 될 거예요:

* [A Road to Common Lisp][road-to-cl], 한 사람이 Common Lisp에 이르기까지 걸어온 길과 어떻게 시작하면 좋을지에 대한 생각을 담은 블로그 글
* [Practical Common Lisp][practical-cl], Common Lisp를 배우기 위한 완결된 책으로, 온라인에서 무료로 볼 수 있어요(종이책도 있어요)
* [Common Lisp Cookbook][cl-cookbook]
* [Cliki.net Getting Start Started Page][cliki-getting-started]
* [Wikibooks book of Common Lisp, First steps][wikibooks-cl-first-steps]
  여러 기여자가 함께 만들었어요
* [Awesome Common Lisp Learning][awesome-cl]

이 Exercism Common Lisp 트랙에서 함께 보면 좋은 자료도 있어요: [중요 자료][track-resources].
