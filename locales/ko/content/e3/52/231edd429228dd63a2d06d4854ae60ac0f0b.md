# 설치

## 대상 버전

이 트랙의 테스트에는 `alpine:3.24.1` Docker 이미지를 사용해요. 2026년 9월 기준으로 이 이미지는 `sqlite3 version 3.53.4`를 사용해요.
저희는 이 트랙에서 제공하는 도구가 최신 Ubuntu LTS 릴리스에서도 동작하도록 노력하고 있어요.
더 새로운 버전을 설치한 사용자도 있겠지만, 일부 기능은 저희 테스트 러너에서 동작하지 않을 수 있다는 점을 알아 두세요.
기능은 [SQLite 버전 기록][version-history]에서 비교해 볼 수 있어요.

## Windows

Windows에 SQLite를 설치하려면 다음 단계를 따라 해요:

1. [공식 다운로드 페이지][sqlite-download]에서 미리 컴파일된 Windows 바이너리를 내려받아요.
2. 내려받은 ZIP 파일을 원하는 디렉터리에 압축을 풀어요.
   예를 들어 `C:\Program Files\sqlite3` 같은 곳이에요.
3. `sqlite3.exe`가 들어 있는 디렉터리를 시스템의 PATH 환경 변수에 추가해요.
   이 과정은 Windows 버전마다 조금씩 다르지만, 검색하면 정보를 쉽게 찾을 수 있어요.
   예를 들어 [Windows 11 안내][windows-11-install]와 [Windows 10 안내][windows-10-install]가 있어요.

## macOS

macOS에는 SQLite가 미리 설치되어 있어요.
하지만 더 새로운 버전이 필요하다면 [Homebrew][homebrew]를 사용할 수 있어요:

```bash
brew install sqlite
```

## Ubuntu / Debian

Ubuntu와 Debian 계열 시스템에서는 apt로 SQLite를 설치할 수 있어요:

```bash
sudo apt install sqlite3
```

## CentOS / Fedora / RHEL

CentOS, Fedora, Red Hat 계열 시스템에서는 yum이나 dnf로 SQLite를 설치할 수 있어요:

```bash
sudo yum install sqlite3
# OR
sudo dnf install sqlite3
```

## Arch Linux

Arch Linux에서는 pacman으로 SQLite를 설치할 수 있어요:

```bash
sudo pacman -S sqlite
```

## 다른 설치 방법과 이전 버전
