# 힌트

## 일반

- 전체적인 개요가 필요하면 Python 문서의 [진릿값 검사][stdlib-bools] 부분이 도움이 될 거예요.
- 인자가 _어떻게 만들어지는지는_ 걱정할 필요 없이, 인자들을 조합해서 원하는 결과를 반환하는 데 집중해요.

## 1. 팩맨이 유령을 먹을 수 있는지 정의하기

- [불리언][boolean] [연산자][Boolean-operators]를 사용해서 인자들을 조합하고 결과를 만들 수 있어요.

## 2. 팩맨이 득점하는지 정의하기

- [불리언][boolean] [연산자][Boolean-operators]를 사용해서 인자들을 조합하고 결과를 만들 수 있어요.

## 3. 팩맨이 지는지 정의하기

- [불리언][boolean] [연산자][Boolean-operators]를 사용해서 인자들을 조합하고 결과를 만들 수 있어요.

## 4. 팩맨이 이기는지 정의하기

- [불리언][boolean] [연산자][Boolean-operators]를 사용해서 인자들을 조합하고 결과를 만들 수 있어요.

[Boolean-operators]: https://docs.python.org/3/library/stdtypes.html#boolean-operations-and-or-not
[boolean]: https://docs.python.org/3/library/stdtypes.html#truth
[stdlib-bools]: https://docs.python.org/3/library/stdtypes.html#truth-value-testing
