# 지침

이 연습 문제에서는 자전거와 부품을 파는 온라인 상점인 Betty's Bike Shop을 돕기 위한 코드를 작성해요.
웹사이트에서 자전거와 부품 가격을 올바르게 표시하는 것을 목표로 하는 세 가지 작업이 있어요.

## 1. `pence_to_pounds` 함수 내보내기

동료가 이미 모듈의 뼈대와 미완성 함수 `pence_to_pounds`과 `pounds_to_string`을 작성해 두었어요.
그런데 `pence_to_pounds` 함수를 내보내는 것을 잊어버려서, 지금은 다른 모듈이나 테스트 스위트에서 이 함수를 볼 수 없어요.

`pence_to_pounds` 함수를 내보내세요.

## 2. 펜스를 파운드로 변환하기

현재 가격은 *펜스* 단위의 정수로 저장되어 있어요 (이 자전거 가게는 영국에 있어요).
웹사이트에서는 가격을 *파운드*로 보여주고 싶은데, 1.00파운드는 100펜스예요.
첫 번째 작업은 `Int` 타입의 펜스 금액을 받아 그에 해당하는 파운드를 `Float`로 변환하는 `pence_to_pounds` 함수를 구현하는 거예요.
이 함수에는 타입 애너테이션도 추가해야 해요.

```gleam
pence_to_pounds(106)
// -> 1.06
```

## 3. 웹사이트에 표시할 가격 형식 맞추기

Betty의 자전거는 파운드로 판매되므로, 가격은 "£" 기호와 함께 표시해야 해요.
따라서 두 번째 작업은 파운드 금액을 `Float`로 받아, 앞에 파운드 기호를 붙여 표시한 가격을 `String`으로 반환하는 `pounds_to_string` 함수를 구현하는 거예요.

`gleam/float` 모듈과 `gleam/string` 모듈은 사용하기 전에 임포트해야 해요.

`pounds_to_string`의 타입 애너테이션도 정의해야 해요.

```gleam
pounds_to_string(1.06)
// -> "£1.06"
```
