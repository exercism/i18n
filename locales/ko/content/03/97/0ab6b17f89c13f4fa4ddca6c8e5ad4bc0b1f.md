# 힌트

## 일반

## 1. `new()` 메서드 구현하기

- `new()` 메서드는 `User` 인스턴스를 만들 때 사용할 인자들을 받아요. 지정한 이름, 나이, 몸무게를 가진 `User` 인스턴스를 반환해야 해요.

- 구조체를 정의하고 인스턴스를 만드는 예시는 [구조체 문서][structs]를 참고해요.

## 2. getter 메서드 구현하기

- `name()`, `age()`, `weight()` 메서드는 게터예요. 다시 말해, 구조체 인스턴스에서 해당 필드를 반환하는 역할을 해요.

- Cairo에서는 함수나 메서드를 일찍 반환하고 싶은 게 아니라면 `return` 문을 쓸 필요가 없어요. 그 밖의 경우에는 반환하려는 결과에서 세미콜론을 생략해 _암묵적_ 반환을 활용하는 편이 더 자연스러워요. 명시적 return을 쓰는 게 _틀린_ 것은 아니지만, 가능하면 암묵적 반환을 활용하는 게 더 깔끔해요.

```rust
fn foo() -> i32 {
    1
}
```

- 구조체에 메서드를 정의하는 더 많은 예시는 [메서드 문서][methods]를 참고해요.

## 3. setter 메서드 구현하기

- `set_age()`와 `set_weight()` 메서드는 세터로, 입력 인자로 구조체 인스턴스의 해당 필드를 갱신하는 역할을 해요.

- 이 메서드들의 시그니처가 보여주듯이, 세터 메서드는 아무것도 반환하면 안 돼요.

[structs]: https://book.cairo-lang.org/ch05-01-defining-and-instantiating-structs.html
[methods]: https://book.cairo-lang.org/ch05-03-method-syntax.html
