# 소개

`Vectors` 개념에서 벡터를 조건 표현식에 사용하면 논리형 벡터가 된다는 것을 봤어요.
이 논리형 벡터는 다시 `all()`이나 `any()` 같은 함수에 사용할 수 있어요.

```R
v <- c(4, 7, 10)
v >= 6
#> [1] FALSE  TRUE  TRUE
all(v > 6)
#> [1] FALSE    # not all elements match this condition
any(v > 6)
#> [1] TRUE     # at least one element matches
```

이 기법은 이것보다 훨씬 강력해요.

## 벡터 부분집합

벡터에서 선택한 원소를 인덱스 번호나 인덱스 벡터로 꺼낼 수 있어요:

```R
v <- 5:10
v
#> [1]  5  6  7  8  9 10
v[3] 
#> [1] 7
v[c(2, 4)]
#> [1] 6 8
```

또는 논리형 벡터로 원래 벡터를 걸러서, `TRUE` 값에 해당하는 항목들의 부분집합을 얻을 수도 있어요:

```R
v <- 1:3
bools <- c(FALSE, TRUE, TRUE)
v[bools]
#> [1] 2 3
```

여기서 한 걸음만 더 나아가면 조건 표현식으로 불리언 벡터를 만들 수 있어요:

```R
bools <- v >= 2
bools
#> [1] FALSE  TRUE  TRUE

v[bools]
#> [1] 2 3

# simpler form
v[v >= 2]
#> [1] 2 3
```

## 인덱스 찾기

`which()` 함수는 불리언 인자를 받아서 `TRUE`가 되는 인덱스 벡터를 반환해요.

```R
v
#> [1] 2 7 9

v[v > 5]  # returns values
#> [1]  7  9

which(v > 5) # returns indices
#> [1] 2 3
```

## 항목이 존재하는지 확인하기

앞선 절에서는 어떤 기준에 맞는 항목을 찾는 방법을 살펴봤어요.

벡터에 특정 원소가 들어 있는지만 알고 싶다면 `%in%` 연산자를 사용해요.

```R
3 %in% 1:5
#> [1] TRUE
7 %in% 1:5
#> [1] FALSE
```

이것은 다음 코드와 기능적으로 같지만 훨씬 편리해요:

```R
v <- 1:5
length(v[v == 3]) > 0
#> [1] TRUE
```
