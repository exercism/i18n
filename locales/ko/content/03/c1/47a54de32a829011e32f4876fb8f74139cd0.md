# 범위

[범위][range]는 두 값 사이의 구간을 나타내요.
범위를 지원하는 가장 흔한 타입은 `Int`, `Char`, `String`이에요.
범위는 컬렉션을 빠르게 만들거나, 문자열을 자르거나, 값이 범위에 들어 있는지 확인하거나, 반복하는 등 여러 가지 일에 쓸 수 있어요.
범위는 범위 연산자 `..` 또는 `...`로 만들어요. 각각 끝 값을 포함하는 범위와 포함하지 않는 범위예요.

```crystal
1..5  # A range containing 1, 2, 3, 4, 5
1...5 # A range containing 1, 2, 3, 4
```

범위 연산자가 두 개 있는 이유는 끝 값을 포함하는 범위와 포함하지 않는 범위를 만들기 위해서예요. 이런 구분은 예를 들어 0부터 시작하는 인덱스를 다룰 때 유용해요.

`Range` 이니셜라이저를 사용해서 범위를 만들 수도 있어요.

```crystal
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
Crystal에서 범위 연산자 `..`나 `...`로 범위를 만들고 그 범위에 메서드를 호출하려면, 범위를 괄호로 감싸야 해요.
그렇지 않으면 메서드가 범위 연산자의 두 번째 인자에 호출되기 때문이에요.

```crystal
(1..5).size # => 5
1..5.size # => Error: undefined method 'size' for Int32
```
~~~~

## 부분 문자열 가져오기

문자열을 자르고 싶을 때는 범위 연산자로 부분 문자열을 얻을 수 있어요.
즉, 부분 문자열의 시작과 끝 인덱스로 범위를 만드는 거예요.

```crystal
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

음수 인덱스를 사용하면 문자열의 끝에서부터 부분 문자열을 얻을 수도 있어요.

```crystal
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## 범위 메서드

범위에는 범위를 다룰 때 사용할 수 있는 메서드들이 있어요.
예를 들어, 이 메서드들로 범위에 있는 모든 값의 합을 구하거나 범위가 어떤 값을 포함하는지 확인할 수 있어요.

| 메서드                  | 설명                                                             | 예시                         |
|-------------------------|-------------------------------------------------------------------------|---------------------------------|
| [`sum`][sum]            | 범위에 있는 모든 값의 합을 반환해요                          | `(1..5).sum # => 15`            |
| [`size`][size]          | 범위의 크기를 반환해요                                           | `(1..5).size # => 5`            |
| [`includes?`][indludes] | 범위가 주어진 값을 포함하면 `true`를, 그렇지 않으면 `false`를 반환해요 | `(1..5).includes?(3) # => true` |

## 끝이 없는 범위와 시작이 없는 범위

범위는 끝이 없거나 시작이 없을 수 있어요.
끝이 없거나 시작이 없는 범위는 시작 값이나 끝 값이 `nil`이지만, 범위를 정의할 때 `nil`은 생략할 수 있어요.

시작이 없거나 끝이 없는 범위는 예를 들어 문자열을 처음부터 또는 끝까지 자르고 싶을 때 유용해요.

```crystal
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
끝이 없는 범위를 컬렉션에 사용하지 않으면, 주의하지 않는 한 끝없는 시퀀스가 생길 수 있어요.
~~~~

## Char 범위

문자는 범위에 사용할 수 있고, 두 문자 사이의 문자 구간을 얻을 수 있어요.
예를 들어, 알파벳을 얻고 싶을 때 편리해요.

```crystal
'a'..'z' # A range containing ['a', 'b', 'c', ..., 'z']
```

## 문자열 범위

문자열도 범위에 사용할 수 있어서, 두 문자열 사이의 문자열 구간을 얻을 수 있어요.
하지만 문자열 범위에서 여러 문자가 사용되면 그 동작이 `Char`의 동작과 조금 달라요.
더 복잡한 문자열 범위를 다룰 때는 동작이 헷갈릴 수 있으니 주의해요.

```crystal
("aa".."az") # A range containing ["aa", "ab", "ac", ..., "az"]
```

## 범위에서 사용자 정의 객체 사용하기

~~~~exercism/advanced
Crystal에서는 범위에 사용자 정의 객체를 사용할 수 있어요.
그러려면 객체가 다음을 구현해야 해요:

- `Comparable` 모듈을 포함해야 해요
- `succ` 메서드
- `<=>` 메서드

이 메서드들이 있으면 범위가 객체를 반복하고 범위 안의 객체들을 비교할 수 있어요.

```crystal
class Foo
  include Comparable(Foo)

  getter value

  def initialize(@value : Int32)
  end

  def succ
    Foo.new(value + 1)
  end

  def <=>(other : Foo)
 value <=> other.value
  end
end

Foo.new(1)..Foo.new(5)
# => #<Foo:0x7f3552bebe70 @value=1>, #<Foo:0x7f3552bebe50 @value=2>, #<Foo:0x7f3552bebe40 @value=3>, #<Foo:0x7f3552bebe30 @value=4>, #<Foo:0x7f3552bebe20 @value=5>
```
~~~~
