# 지시 사항

Ellen은 플레이어가 외계인과 싸워야 하는 게임을 만들고 있어요.
막 객체 지향 프로그래밍(OOP)을 배웠고, `classes`를 사용하면 자기 프로그램에 어떤 도움이 될지 몹시 기대하고 있어요.

도움을 주겠다고 나서자 Ellen은 무척 기뻐했고, 플레이어가 맞서야 할 외계인을 프로그래밍하는 일을 맡겼어요.


## 1. `Alien` 클래스 만들기

두 개의 `int` 매개변수 `x`와 `y`를 받는 생성자를 가진 `Alien` 클래스를 정의하고, 이 값들을 `x_coordinate`과 `y_coordinate` 멤버 변수에 넣어요.
또 모든 외계인은 체력 `3`으로 시작하므로, `health` 멤버 변수도 함께 초기화해야 해요.

`health`는 private 멤버 변수여야 해요.
프로그램의 다른 부분에서도 체력 정보를 읽을 수 있도록, Ellen은 `int`를 반환하는 `public` `get_health()` 메서드를 두고 싶어 해요.

```cpp
Alien alien{2, 0};
alien.x_coordinate;
// => 2
alien.y_coordinate;
// => 0
alien.get_health();
// => 3
```

이제 각 외계인은 자신의 위치와 체력을 스스로 추적할 수 있어야 해요.

## 2. `hit` 함수

Ellen은 `class` 클래스에, 호출되면 외계인 객체의 체력을 `1`만큼 줄이는 `hit` 메서드가 있으면 좋겠어요.
그러면 외계인의 체력을 직접 바꾸는 대신 `some_alien_instance.hit()`을 호출하기만 하면 돼요.
체력이 0 아래로 내려가지 않도록 해요.
이 함수는 `true`를 반환해야 해요.
Ellen은 나중에 방어막을 도입할 계획인데, 그때는 방어막이 켜져 있으면 `false`를 보고하게 할 거예요.

```cpp
Alien alien {0, 0};
alien.get_health();
// => 3 (Initial health value)

alien.hit(); // Decrements health by 1 point.
alien.get_health();
// => 2
```

## 3. `is_alive` 함수

체력이 계속 줄어들다 보면 언젠가는 `0`이 될 거라는 걸 알 수 있어요.
Ellen이 외계인이... 음... 살아 있는지 빠르게 확인할 수 있도록 `is_alive` 메서드를 추가하면 좋겠어요. 😉
`some_alien_instance.is_alive()`는 불리언을 반환해야 해요.

```cpp
alien.get_health();
// => 1
alien.is_alive();
// => true
alien.hit();
alien.get_health();
// => 0
alien.is_alive();
// => false
```

## 4. `teleport` 함수

Ellen의 게임에서는 외계인이 순간 이동을 할 수 있어요!
`x_new`와 `y_new` 값을 받아 외계인의 좌표를 그에 맞게 바꾸는 `teleport` 메서드를 작성해야 해요.
우선은 이 함수가 `true`를 반환해야 해요.
Ellen은 나중 레벨에서 순간 이동을 막는 폭탄을 추가할 계획인데, 그때는 순간 이동에 실패하면 `false`를 보고하게 할 거예요.

```cpp
alien.teleport(5, -4);
alien.x_coordinate;
// => 5
alien.y_coordinate;
// => -4
```

## 5. `collision_detection` 함수

외계인이 무언가에 맞을 수 있다면, 그런 충돌이 일어날 수 있는지 감지할 수 있어야 해요.
Ellen은 외계인 두 마리가 같은 좌표에 있는지 알아야 해요.
`collision_detection()` 함수는 다른 외계인 객체를 인자로 받아 `bool`을 반환해요.

```cpp
Alien lrrr {3, 6};
Alien ndnd {-2, 12};
lrrr.collision_detection(ndnd);
// => false
ndnd.teleport(3, 6);
ndnd.collision_detection(lrrr);
// => true
```
