# 안내

다니는 회사는 탄소 발자국을 줄이고 싶어 해요. 그래서 전자 기기를 돌리는 데 드는 전력 사용량과 비용을 계산하는 프로그램을 작성해 달라고 해요.

## 1. 추가 시간 구하기

고용주에게는 여러 전자 기기를 돌리는 데 걸리는 시간을 계산하는 프로그램이 있어요. 현재 이 시간은 시간 단위로 저장돼요. 고용주가 시간을 더해 보니, 시간 길이가 맞지 않는다는 걸 알게 됐어요. 그래서 시간 데이터에 3시간을 추가로 더하기를 원해요. 또 데이터를 "완전한 하루"로 변환하고 나면 "추가" 시간이 몇 시간인지도 알고 싶어 해요 (하루는 24시간이에요). 변환할 시간이 꼭 완전한 하루 단위가 아닐 수도 있어요.

시간 수를 담은 정수를 매개변수로 받는 `get_extra_hours()` 함수를 구현해요. 이 함수는 "추가" 시간을 알맞게 조정한 다음, 전체에서 몇 시간을 빼야 "완전한 하루" 단위의 시간이 되는지를 나타내는 정수를 `return`해야 해요.

```python
>>> get_extra_hours(25)
4
```

## 2. kW 값 구하기

고용주는 여러 전자 기기의 전력 사용량을 kW로 알고 싶어 해요. kW는 킬로와트를 뜻하고, 와트는 전력의 단위예요. 단위 이름에서 킬로는 미터법에서 1000을 뜻하는 접두사예요. 1킬로와트 == 1000와트예요.

와트 수를 담은 정수를 매개변수로 받는 `get_kW_value()` 함수를 구현해요. 이 함수는 와트를 소수점 첫째 자리에서 반올림한 킬로와트로 `return`해야 해요.

```python
>>> get_kW_value(1150)
1.2
```

## 3. kWh 값 구하기

전자 기기를 돌리는 비용을 계산하려면 고용주가 kWh 단위의 전력 사용량을 알아야 해요. kWh는 킬로와트시를 뜻하고, 여기서 시는 시간의 단위예요. 1킬로와트시 == 1시간 동안 사용한 1000와트예요. 1시간은 60분으로, 1분은 60초로 이루어져 있어요. 1시간은 3600초예요. kWh 값을 계산하려면 와트를 kW로 변환한 다음, 그 결과를 3600으로 내림 나눗셈해야 해요.

와트 수를 담은 정수를 매개변수로 받는 `get_kWh_value()` 함수를 구현해요. 이 함수는 킬로와트시를 정수로 `return`해야 해요.

```python
>>> get_kWh_value(5000000)
1
```

## 4. 효율 구하기

전자 기기는 100% 효율적이지 않아요. 그래서 고용주는 전자 기기의 _효율_을 계산해 달라고 해요. 효율을 구하려면 역률(_0과 100 사이의 실수_)을 100으로 나눠야 해요.

역률을 담은 실수를 매개변수로 받는 `get_efficiency()` 함수를 구현해요. 이 함수는 계산된 효율을 실수로 `return`해야 해요.

```python
>>> get_efficiency(80)
0.8
```

## 5. 비용 구하기

고용주는 전자 기기를 돌리는 비용을 알고 싶어 해요. 전자 기기를 돌리는 비용은 사용한 전력에 kWh당 비용을 곱한 값이에요. 사용한 전력은 주어진 전력을 계산된 효율로 나눈 값이에요.

와트 수를 담은 정수, 역률을 담은 실수, kWh당 비용을 담은 실수를 매개변수로 받는 `get_cost(<watts>,<power_factor>,<price>)` 함수를 구현해요. 이 함수는 전자 기기를 돌리는 비용을 실수로 `return`해야 해요.

```python
>>> get_cost(5000000, 80, 0.25)
0.3125
```
