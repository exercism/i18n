# 지시사항

이 연습 문제에서는 국제 전화 코드 딕셔너리를 사용해 국제 전화 코드를 관리하는 코드를 작성해요.

딕셔너리는 키에 정수(전화 코드)를, 값에 문자열(국가 이름)을 사용해요.

`DialingCodes` 정적 클래스와 관련된 9개의 작업이 있어요.

## 1. 새 딕셔너리 만들기

빈 딕셔너리를 반환하는 `DialingCodes.GetEmptyDictionary()` (정적) 메서드를 구현해요.

```csharp
DialingCodes.GetEmptyDictionary();
// => empty dictionary
```

## 2. 미리 채워진 딕셔너리 만들기

코드가 1인 "United States of America", 코드가 55인 "Brazil", 코드가 91인 "India", 이렇게 세 개의 전화 코드를 담고 있는 미리 채워진 딕셔너리가 있어요. 미리 채워진 딕셔너리를 반환하는 `DialingCodes.GetExistingDictionary()` (정적) 메서드를 구현해요.

```csharp
DialingCodes.GetExistingDictionary();
// => 1 => "United States of America", 55 => "Brazil", 91 => "India"
```

## 3. 빈 딕셔너리에 국가 추가하기

딕셔너리를 만들고 전화 코드와 그에 해당하는 국가 이름을 추가하는 `DialingCodes.AddCountryToEmptyDictionary()` (정적) 메서드를 구현해요.

```csharp
DialingCodes.AddCountryToEmptyDictionary(44, "United Kingdom");
// => 44 => "United Kingdom"
```

## 4. 기존 딕셔너리에 국가 추가하기

비어 있지 않은 딕셔너리에 전화 코드와 그에 해당하는 국가 이름을 추가하는 `DialingCodes.AddCountryToExistingDictionary()` (정적) 메서드를 구현해요.

```csharp
DialingCodes.AddCountryToExistingDictionary(DialingCodes.GetExistingDictionary(),
  44, "United Kingdom");
// => 1 => "United States of America", 44 => "United Kingdom", 55 => "Brazil", 91 => "India"
```

## 5. 전화 코드에 해당하는 국가 이름 가져오기

전화 코드를 받아 그에 해당하는 국가 이름을 반환하는 `DialingCodes.GetCountryNameFromDictionary()` (정적) 메서드를 구현해요. 전화 코드가 딕셔너리에 없으면 빈 문자열이 반환돼요.

```csharp
DialingCodes.GetCountryNameFromDictionary(
  DialingCodes.GetExistingDictionary(), 55);
// => "Brazil"

DialingCodes.GetCountryNameFromDictionary(
  DialingCodes.GetExistingDictionary(), 999);
// => string.Empty
```

## 6. 딕셔너리에 국가가 존재하는지 확인하기

전화 코드가 딕셔너리에 존재하는지 확인하는 `DialingCodes.CheckCodeExists()` (정적) 메서드를 구현해요.

```csharp
DialingCodes.CheckCodeExists(DialingCodes.GetExistingDictionary(), 55);
// => true
```

## 7. 국가 이름 업데이트하기

전화 코드를 받아 딕셔너리에서 그에 해당하는 국가 이름을 매개변수로 전달된 국가 이름으로 바꾸는 `DialingCodes.UpdateDictionary()` (정적) 메서드를 구현해요. 전화 코드가 딕셔너리에 없으면 딕셔너리는 바뀌지 않아요.

```csharp
DialingCodes.UpdateDictionary(
  DialingCodes.GetExistingDictionary(), 1, "Les États-Unis");
// => 1 => "Les États-Unis", 55 => "Brazil", 91 => "India"

DialingCodes.UpdateDictionary(
  DialingCodes.GetExistingDictionary(), 999, "Newlands");
// 1 => "United States of America", 55 => "Brazil", 91 => "India"
```

## 8. 딕셔너리에서 국가 제거하기

전화 코드를 받아 딕셔너리에서 해당 레코드(전화 코드 + 국가 이름)를 제거하는 `DialingCodes.RemoveCountryFromDictionary()` (정적) 메서드를 구현해요.

```csharp
DialingCodes.RemoveCountryFromDictionary(
  DialingCodes.GetExistingDictionary(), 91);
// => 1 => "United States of America", 55 => "Brazil"
```

## 9. 이름이 가장 긴 국가 찾기

딕셔너리에 저장된 이름이 가장 긴 국가의 이름을 반환하는 `DialingCodes.FindLongestCountryName()` (정적) 메서드를 구현해요.

```csharp
DialingCodes.FindLongestCountryName(
  DialingCodes.GetExistingDictionary());
// => "United States of America"
```
