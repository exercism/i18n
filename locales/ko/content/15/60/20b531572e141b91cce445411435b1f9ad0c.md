# 소개

열거는 컬렉션(`Array`, `Hash` 등)을 하나씩 거치면서 각 객체에 어떤 작업을 수행하는 것을 말해요.

열거는 Ruby의 핵심 개념으로, 정렬(`sort_by`), 그룹화(`group_by`), 매핑(`map`), 축소(`reduce`) 등 다양한 곳에 쓰여요.
컬렉션을 순회할 때 루프를 사용하는 대신 열거를 사용하는 방식을 가장 자주 보게 될 거예요.

`map`과 `with_index`를 사용하는 간단한 열거는 다음과 같아요:

```ruby
words = %w[the cat sat on the mat]
list = words.map.with_index do |word, index|
  "#{index}. #{word}"
end

puts list

# Output:
# 0. the
# 1. cat
# 2. sat
# 3. on
# 4. the
# 5. mat
```
