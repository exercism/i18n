# 소개

Python에는 세 가지 종류의 내장 숫자 타입이 있어요: 정수([`int`][int]), 실수([`float`][float]), 복소수([`complex`][complex]).
분수([`fractions.Fraction`][fractions])와 십진수([`decimal.Decimal`][decimals])도 표준 라이브러리에서 import해 사용할 수 있어요.

소수점이 없는 16진수([_`hex()`_][hex]), 8진수([_`oct()`_][oct]), 2진수([_`bin()`_][bin])를 포함한 모든 정수도 `ints`로 식별돼요:

```python
# Ints are whole numbers.
>>> 1234
1234
>>> type(1234)
<class 'int'>

>>> -12
-12
```

소수점을 포함하는 숫자(소수 부분이 있든 없든)는 `floats`로 식별돼요:

```python
>>> 3.45
3.45
>>> type(3.45)
<class 'float'>
```

## 산술

Python은 이러한 여러 숫자 타입 간의 산술 연산을 완전히 지원하며, 이항 산술 연산자(`+`, `-`, `*`, `/`, `//`, `%`)와 함께 사용할 때 더 좁은 숫자를 더 넓은 숫자에 맞춰 변환해요.

### 덧셈과 뺄셈

덧셈과 뺄셈 연산자는 일반 수학에서처럼 동작해요.
피연산자 중 하나 이상이 `float`이면 나머지 `int`도 `float`로 변환돼요:

```python
>>> 5 - 3
2
# The int is widened to a float here, and a float is returned.
>>> 3 + 4.0
7.0
```

### 곱셈

덧셈과 뺄셈에서처럼, 곱셈도 더 좁은 숫자를 더 넓은 숫자에 맞춰 변환해요:

```python
>>> 3 * 2
6

>>> 3 * 2.0
6.0
```

### 나눗셈

나눗셈은 결과가 정수라도 항상 `float`을 반환해요:

```python
>>> 6/5
1.2

>>> 6/2
3.0
```

### 내림 나눗셈

`int` 결과가 필요하면 내림 나눗셈을 사용해 결과를 버림할 수 있어요.
내림 나눗셈은 `//` 연산자로 수행해요:

```python
>>> 6//5
1

>>> 6//2
3
```

### 나머지 연산

나머지 연산자(`%`)는 두 피연산자를 나눈 나머지를 반환해요:

```python
# The result of % is zero here, because dividing 8 by 2 leaves no remainder
>>> 8 % 2
0

# The result of % is 2 here, because 3 only goes into 5 once, with 2 leftover
>>> 5 % 3
2
```

5 % 3을 다른 방식으로 살펴보면 이래요:

```python
>>> whole_part = int(5/3)
1

>>> decimal_part = 5/3 - whole_part
0.6666666666666667

>>> whole_remainder = decimal_part * 3
2.0
```

## 반올림

Python은 실수를 지정한 소수 자릿수로 반올림하는 내장 함수 [`round(number, <decimal_places>)`][round]를 제공해요.
소수 자릿수를 지정하지 않으면 가장 가까운 정수로 반올림하고 `int`를 반환해요:

```python
>>> round(3.1415926535, 2)
3.14

>>> round(3.1415926535)
3
```

## 우선순위와 괄호

Python에서는 괄호를 사용해 식을 묶을 수 있어요.
기본 연산 순서를 바꾸고 싶을 때 유용해요.

```python
>>> 2 + 3 * 4
14

>>> (2 + 3) * 4
20
```

Python은 연산자 우선순위에 [PEMDAS][pemdas] 규칙을 따라요.
즉 `()` 안의 계산이 가장 우선이고, 그다음 `**`, 그다음 `*`, `/`, `//`, `%`, `+`, `-` 순서예요:

```python
>>> 2 + 3 - 4 * 4
-11

>>> (2 + 3 - 4) * 4
4

# In the following example, the `**` operator has the highest priority, then `*`, then `+`
# Meaning we first do 4 ** 4, then 3 * 64, then 2 + 192
>>> 2 + 3 * 4 ** 4
770
```

## 정밀도와 표현

Python의 정수는 [임의 정밀도][arbitrary-precision]를 가져요. 즉, 자릿수는 호스트 시스템에서 사용할 수 있는 메모리에 의해서만 제한돼요.

실수는 보통 C의 `double`을 사용해 구현되지만(_소수점 이하 15자리 정밀도_), 표현 방식은 호스트 시스템에 따라 달라요.
복소수는 `real` 부분과 `imaginary` 부분을 가지며, 둘 다 실수로 표현돼요.

여러 프로그래밍 언어에서 실수 연산이 가지는 문제와 한계에 대한 더 자세한 논의는 [0.30000000000000004.com][0.30000000000000004.com]과 [The Python Tutorial][floating point math]을 참고해요.
