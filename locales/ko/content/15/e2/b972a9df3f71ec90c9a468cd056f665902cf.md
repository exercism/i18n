# 배열 메서드

배열은 자주 사용하는 자료 구조예요.
그래서 배열을 다룰 때 사용할 수 있는 메서드가 다양해요.
정렬, 뒤집기, 삽입을 비롯해 여러 가지가 있어요.

이 중 일부 메서드는 파괴적이에요. 다시 말해 원본 배열을 직접 수정해요.
다른 메서드는 비파괴적이에요. 새로운 배열을 반환하고 원본 배열은 수정하지 않아요.

배열을 다룰 때 자주 쓰이는 메서드 몇 가지를 살펴봐요:

## insert

배열에 원소를 삽입할 때는 [`insert`][insert] 메서드를 사용해요. 이 메서드는 인덱스와 원소를 인자로 받아요.
원소는 지정한 인덱스에 삽입되고, 나머지 원소는 오른쪽으로 밀려요.
인덱스가 범위를 벗어나면 `IndexError`가 발생해요.

```crystal
numbers = [1, 2, 3]
numbers.insert(1, 4)
numbers # => [1, 4, 2, 3]

numbers.insert(5, 5) # => Error: Index out of bounds (IndexError)
```

## delete

배열에서 특정 원소를 삭제하고 싶을 때는 [`delete`][delete] 메서드를 사용해요. 이 메서드는 원소를 인자로 받아요.
이 메서드는 제거된 원소를 반환해요.
원소가 배열에 없으면 `nil`을 반환해요.

```crystal
numbers = [1, 2, 3]
numbers.delete(2) # => 2
numbers           # => [1, 3]
```

## first & last

배열의 첫 번째나 마지막 원소를 가져오고 싶을 때는 [`first`][first]와 [`last`][last] 메서드를 사용해요.
이 메서드들은 몇 개의 원소를 반환할지 지정하는 선택적 인자를 받아요.
인덱스 `0`이나 `-1`을 쓰거나 범위를 쓰는 것보다 가독성이 좋아요.
배열이 비어 있으면 `Enumerable::EmptyError`가 발생해요.

```crystal
numbers = [1, 2, 3]
numbers.first # => 1
numbers.last  # => 3

numbers.first(2) # => [1, 2]
numbers.last(2)  # => [2, 3]

empty_array = [] of Int32
empty_array.last # => Error: Empty enumerable (Enumerable::EmptyError)
```

## reverse

배열을 뒤집고 싶을 때는 [`reverse`][reverse] 메서드를 사용해요. 이 메서드는 원소를 역순으로 담은 새 배열을 반환해요.
`reverse`는 새 배열을 반환하고 원본 배열은 수정하지 않는다는 점이 중요해요.
원본 배열을 수정하고 싶다면 메서드 이름 끝에 `!`를 붙여요.

```crystal
numbers = [1, 2, 3]
numbers.reverse # => [3, 2, 1]
numbers         # => [1, 2, 3]

numbers.reverse! # => [3, 2, 1]
numbers          # => [3, 2, 1]
```

## flatten & compact & transpose & uniq

다음 메서드들은 배열을 1차원으로 만들거나, `nil` 원소를 제거하거나, 중복을 제거하거나, 배열의 배열을 전치할 때 유용해요.
`reverse`와 마찬가지로 이 메서드들도 새 배열을 반환하고 원본 배열은 수정하지 않아요.

| 메서드 | 설명 | 예시 |
| ------ | ----------- | ------- |
| [`flatten`][flatten] | 이 배열을 (재귀적으로) 1차원으로 평탄화한 새 배열을 반환해요. 즉, 각 배열 원소마다 그 원소들을 새 배열로 추출해요. | `[[1, 2], [3, 4]].flatten # => [1, 2, 3, 4]` |
| [`compact`][compact] | 모든 nil 원소를 제거한 복사본을 반환해요. | `[1, nil, 2, nil, 3].compact # => [1, 2, 3]` |
| [`transpose`][transpose] | self가 배열의 배열이라고 가정하고 행과 열을 [전치][transpose]해요. | `[[1, 2], [3, 4]].transpose # => [[1, 3], [2, 4]]` |
| [`uniq`][uniq] | self의 중복된 값을 제거한 새 배열을 반환해요. | `[1, 2, 1, 3, 1].uniq # => [1, 2, 3]` |

## Concat(`+`)

덧붙이기 메서드(`<<`)는 배열에 객체를 추가하고 싶을 때 유용해요.
하지만 두 배열을 합칠 때는 [`+`][concat] 연산자를 사용해요. 이 연산자는 두 배열의 원소를 담은 새 배열을 반환해요.

```crystal
[1, 2] + [3, 4] # => [1, 2, 3, 4]
```

배열을 다른 배열에 덧붙이면 그 배열은 하나의 원소로 추가돼요.

```crystal
[1, 2] << [3, 4] # => [1, 2, [3, 4]]
```

## empty?

배열이 비어 있는지 확인할 때는 [`empty?`][empty?] 메서드를 사용해요. 이 메서드는 배열이 비어 있으면 `true`, 아니면 `false`를 반환해요.
배열의 길이를 `0`과 비교하는 것보다 가독성이 좋아요.

```crystal
[].empty? # => true
[1, 2, 3].empty? # => false
```

## index

배열에서 원소의 인덱스를 알고 싶을 때는 [`index`][index] 메서드를 사용해요. 이 메서드는 원소를 인자로 받아요.
원소가 배열에 없으면 `nil`을 반환해요.

```crystal
numbers = [1, 2, 3]
numbers.index(2) # => 1
```

## size

배열의 원소 개수를 알고 싶을 때는 [`size`][size] 메서드를 사용해요.

```crystal
numbers = [1, 2, 3]
numbers.size # => 3
```

## count

배열에 원소가 몇 번 등장하는지 세고 싶을 때는 [`count`][count] 메서드를 사용해요.

```crystal
fruits = ["apple", "banana", "apple"]
fruits.count("apple")      # => 2
fruits.count("banana")     # => 1
fruits.count("watermelon") # => 0
```

## sort

배열을 정렬하고 싶을 때는 [`sort`][sort] 메서드를 사용해요. 이 메서드는 원소를 정렬한 새 배열을 반환해요.
`reverse`와 마찬가지로 이 메서드도 새 배열을 반환하고 원본 배열은 수정하지 않아요.

```crystal
numbers = [3, 2, 1]
numbers.sort # => [1, 2, 3]
numbers      # => [3, 2, 1]

numbers.sort! # => [1, 2, 3]
numbers       # => [1, 2, 3]
```
