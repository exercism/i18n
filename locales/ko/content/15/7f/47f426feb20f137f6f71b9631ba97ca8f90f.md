# 힌트

## 일반

- 인스턴스 변수에 접근하고 정의하려면 `@` 다음에 변수 이름을 써요.

## 1. `TaskHandler` 초기화하기

- `Proc`을 만들려면 `-> (args) { block }` 문법을 사용해요.
- 인스턴스 변수에 `Proc`을 정의할 때는 타입을 명시적으로 지정해야 해요. 변수 이름 뒤에 `: Proc(<arg_type>, <return_type>)`를 붙이면 되고, `-> (arg_1 : <arg_type>) : <return_type> { block }` 문법을 사용해도 돼요.
- `Proc`은 인자가 0보다 크거나 같은지 비교해야 해요.

## 2. 작업 조건 로직 업데이트하기

- 이 메서드는 블록을 인자로 받아 `@task_condition_logic` 인스턴스 변수에 할당해야 해요.

## 3. 다음 작업 실행하기

- `Proc`을 실행하려면 proc의 인자들을 받는 `call` 메서드를 사용해요.
