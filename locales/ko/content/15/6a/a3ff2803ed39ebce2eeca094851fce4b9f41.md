# 소개

[`fractions`][fractions] 모듈을 사용하면 [`rational numbers`][rational]를 만들고 다룰 수 있어요.
유리수는 정수 분자를 정수 분모로 나눈 분수예요.
예를 들어 `2/3`을 근삿값인 `float` 값 `0.6666...` 대신 정확한 분수로 저장할 수 있어요.

`int`, `float`, `complex` 숫자와 달리 분수에는 리터럴 형태가 없어요.
그래도 분수 생성자는 아주 유연해요.

가장 기본적으로, 두 정수를 인자로 받을 수 있어요.
공약수는 자동으로 제거되어 분수가 "기약분수"(_분수를 정확하게 나타내는 가장 작은 정수_)로 변환돼요:

```python
>>> from fractions import Fraction

>>> f1 = Fraction(2, 3) # 2/3
>>> f1
Fraction(2, 3)

>>> f2 = Fraction(6, 9)
>>> f2
Fraction(2, 3)  # automatically simplified

>>> f1 == f2
True
```

분수 생성자는 문자열 표현도 파싱할 수 있어요:

```python
>>> f3 = Fraction('2/3')
>>> f3
Fraction(2, 3)
```

분수는 `float` 매개변수와도 함께 사용할 수 있지만, 십진수 값을 내부적으로 이진수로 표현하는 근사적 특성 때문에 문제가 생길 수 있어요.
이 표현 문제에 대해 더 알아보려면 [0.30000000000000004][0.30000000000000004] 웹사이트와 Python 문서의 [부동 소수점 연산: 문제점과 한계 ][fp-issues]를 참고해요.

분수와 함께 실수를 사용할 때 더 안정적인 결과를 얻으려면 `<fraction>.limit_denominator()` 메서드를 사용해요.


## 분수 연산

일반적인 [`arithmetic operators`][operators] `+ - * / **`는 다른 숫자형과 마찬가지로 분수에서도 동작해요.

정수와 다른 `Fraction`도 식에 넣을 수 있고, 결과는 `Fraction`이 돼요.
식에 `float`를 넣으면 결과가 `float`이 되고, 그에 따라 정밀도가 (어쩌면) 손실될 수 있어요:

```python
>>> Fraction(2, 3) + Fraction(1, 4) # addition
Fraction(11, 12)

>>> Fraction(2, 3) * Fraction(6, 5) # multiply fractions
Fraction(4, 5)

>>> Fraction(2, 3) * 6 / 5 # fraction with integers
Fraction(4, 5)

>>> Fraction(2, 3) * 1.2  # fraction with float -> float
0.7999999999999999

>>> Fraction(2, 3) ** 2  # exponentiation with integer
Fraction(4, 9)
```

여러 표준 Python 숫자 함수도 `int`와 `float` 타입을 다룰 때 기대할 수 있는 결과를 그대로 돌려줘요:

```python
>>> round(Fraction(11, 3))
4

>>> from math import floor, ceil
>>> floor(Fraction(11, 3))
3
>>> ceil(Fraction(11, 3))
4

>>> float(Fraction(11, 3))
3.6666666666666665
```
