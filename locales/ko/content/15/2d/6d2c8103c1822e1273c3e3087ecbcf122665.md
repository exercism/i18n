# Representer 정규화

[JavaScript representer][github-javascript-representer]는 다음과 같은 정규화를 적용해요.

## 주석 제거

모든 주석을 제거해요.
다음 예시들은 모두 같아요.

### 주석이 있는 예시

```javascript
/**
 * Returns the string literal 'hi there' just to say hello
 * @return [String]
 */
function hello(/* nothing*/) {
  // just return it
  return 'hi there';
}
```

### 주석이 없는 예시

```javascript
function hello() {
  return 'hi there';
}
```

## 공백 정규화

코드를 표현할 때 중요한 것은 _순서_이고, 실제 위치는 중요하지 않아요.
그래서 공백을 정규화해요.
다음 예시들은 모두 같아요.

### 들여쓰기가 두 칸인 예시

```javascript
function hello() {
  return 'hello world';
}
```

### 들여쓰기가 네 칸인 예시

```javascript
function hello() {
  return 'hello world';
}
```

### 들여쓰기가 독특한 예시

```javascript
function hello() {
  return 'hello world';
}
```

## 식별자 정규화

식별자는 자리 표시자 값으로 정규화돼요.

### 변경 전

```javascript
const MY_CONSTANT = 42;

function answer(multiplier, addition = 1) {
  return MY_CONSTANT * multiplier + addition;
}
```

### 변경 후

```javascript
const PLACEHOLDER_1 = 42;

function PLACEHOLDER_2(PLACEHOLDER_3, PLACEHOLDER_4 = 1) {
  return PLACEHOLDER_1 * PLACEHOLDER_3 + PLACEHOLDER_4;
}
```
