# 지침

루시안의 여자친구가 집으로 돌아오는 길인데, 루시안은 기념일 저녁 식사를 아직 만들지 않았어요!

이번 연습 문제에서는 루시안이 가장 좋아하는 요리책을 보고 근사한 라자냐를 만들 수 있도록 도와주는 코드를 작성해 볼 거예요.

라자냐를 조리하는 데 걸리는 시간과 관련된 네 가지 과제가 있어요.

## 1. 오븐 예상 시간을 분 단위로 정의하기

라자냐가 오븐에 있어야 하는 시간(분)을 나타내는 `expected_minutes_in_oven` 상수를 정의해요. 요리책에 따르면 예상 오븐 시간은 `40`분이에요.

## 2. 남은 오븐 시간을 분 단위로 계산하기

라자냐가 오븐에 들어가 있던 실제 시간(분)을 _매개변수_로 받아서, 이전 과제의 **예상 오븐 시간(분)**을 기준으로 라자냐가 오븐에 더 남아 있어야 하는 시간(분)을 _반환_하는 `remaining_minutes_in_oven` 메서드를 구현해요.

```abap
remaining_minutes_in_oven( 30 ).
// => 10
```

## 3. 준비 시간을 분 단위로 계산하기

라자냐에 추가한 층의 개수를 _매개변수_로 받아서, 층마다 준비하는 데 2분이 걸린다고 가정할 때 라자냐를 준비하는 데 걸린 시간(분)을 _반환_하는 `preparation_time_in_minutes` 메서드를 구현해요.

```abap
preparation_time_in_minutes( 2 ).
// => 4
```

## 4. 총 작업 시간을 분 단위로 계산하기

`total_time_in_minutes` 메서드를 구현해요. 이 메서드는 _두 개의 매개변수_를 받는데, `numbernumber_of_layers` 매개변수는 라자냐에 추가한 층의 개수이고, `actual_minutes_in_oven` 매개변수는 라자냐가 오븐에 있던 시간(분)이에요. 이 메서드는 라자냐 요리에 총 몇 분을 들였는지 _반환_해야 하는데, 이는 준비 시간(분)과 그 시점까지 라자냐가 오븐에서 보낸 시간(분)을 더한 값이에요.

```abap
total_time_in_minutes( 
  numbernumber_of_layers = 3
  actual_minutes_in_oven = 20 ).
// => 26
```
