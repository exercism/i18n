# Import

[특수 형식 `import`][import]를 사용하면 외부 모듈의 이름을 쓰지 않고도 그 모듈의 함수와 매크로를 사용할 수 있어요.

외부 모듈을 통째로 임포트하면 기존의 지역 함수와 충돌이 생길 수 있어요. 이를 피하려고 `:except`와 `:only`, 두 가지 옵션을 쓸 수 있어요. 둘 다 키워드 리스트를 받는데, 키는 함수 이름이고 값은 그 함수의 인자 개수예요.

```elixir
defmodule Square do
  import Integer, only: [pow: 2]

  def area(a), do: pow(a, 2)
end
```

보통은 모듈 정의 맨 앞에 임포트를 추가하지만, 어디에든 추가할 수 있어요. 임포트에는 렉시컬 스코프가 적용되는데, 이는 함수 정의 안에서 추가한 임포트를 다른 함수에서는 쓸 수 없다는 뜻이에요.

사용하지 않는 임포트는 컴파일러 경고를 발생시켜요.

[import]: https://hexdocs.pm/elixir/Kernel.SpecialForms.html#import/2
