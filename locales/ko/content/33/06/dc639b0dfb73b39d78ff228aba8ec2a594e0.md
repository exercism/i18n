# 개요

F#의 [`list`][lists]는 0개 이상의 값으로 이루어진 불변 컬렉션이에요. 배열의 값은 모두 같은 타입이어야 해요. 배열은 불변이기 때문에, 한 번 생성되면 그 값은 절대 변하지 않아요. F# 배열은 _머리_(첫 번째 요소)와 _꼬리_(첫 번째 요소 이후의 모든 것)를 가져요. 배열의 꼬리는 그 자체로 배열이에요.

배열은 다음과 같이 정의할 수 있어요:

```fsharp
let empty = []
let emptyAlternative = List.empty

let singleValue = [5]
let singleValueAlternative = List.singleton 5

let threeValues = ["a"; "b"; "c"]
```

배열에 요소를 추가하는 가장 일반적인 방법은 `::` (cons) 연산자를 사용하는 거예요:

```fsharp
let twoToFour = [2; 3; 4]
let oneToFour = 1 :: twoToFour
// => [1; 2; 3; 4]
```

배열은 `@` 연산자나 `List.append`를 사용해 덧붙일 수 있어요:

```fsharp
[6; 7] @ [8; 9]           // => [6; 7; 8; 9]
List.append [6; 7] [8; 9] // => [6; 7; 8; 9]
```

배열은 [`List` 모듈][list-module]에 정의된 함수와 연산자로 조작해요. 이러한 함수 중 일부는 `list` 인스턴스의 [속성][list-properties]으로도 사용할 수 있어요:

```fsharp
List.length [7; 8] // => 2
[7; 8].Length      // => 2
```

여기에는 옳고 그른 선택이 없어요. 일반적으로 `List` 모듈의 함수는 타입 추론과 더 잘 어울리는 반면, 속성은 더 간결한 코드를 가능하게 해요.

배열을 수정하는 것처럼 보이는 함수나 연산자(예: 요소 추가)는 실제로는 새로운 배열을 반환해요. 하지만 배열의 구현 방식이 불필요한 할당이나 복사를 방지하기 때문에 성능은 보통 문제가 되지 않아요.

배열은 단일 연결 리스트로 구현되기 때문에, 요소를 앞에 추가하는 것(`::` 연산자 사용)은 매우 빠르지만, 인덱스로 요소에 접근하는 것은 상대적으로 느릴 수 있어요.

배열은 [_list_][list-pattern]와 [_cons_][cons-pattern] 패턴을 통해 패턴 매칭으로 처리할 수도 있어요:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [ 1 ] -> "Singleton list with 1"
    | head::tail -> sprintf "Non-empty list with head: %d" head

describe []        // => "Empty list"
describe [1]       // => "Singleton list with 1"
describe [5; 7; 9] // => "Non-empty with head: 5"
```

패턴 매칭을 할 때 값을 _버릴_ 수도 있어요. 특정 경우에 값이 _필요 없는_ 경우(즉, 값을 _사용하지_ 않을 경우)에는 밑줄(`'_'`)을 사용해 이를 나타낼 수 있어요:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [x] -> "List with one item"
    | [_; y] -> "List with two items (first item ignored)"
    | _ -> "List with many items (all items ignored)"

describe []        // => "Empty list"
describe [1]       // => "List with one item"
describe [5; 7]     // => "List with two items (first item ignored)"
describe [5; 7; 9] // => "List with many items (all items ignored)"
```

단일 `'_'`는 패턴 매칭을 할 때 항상 _마지막_에 와야 해요. 다른 경우와 일치하지 _않는_ 모든 값은 이 경우에 의해 처리될 거예요.
