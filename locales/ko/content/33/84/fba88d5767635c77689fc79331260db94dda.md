# 지침

지역 클럽의 시즌 결승전이에요. 결승선에서 리더보드를 운영하고 있어요. 레이서들이 순서대로 들어오고, 레인에는 라벨이 필요하고, 다음 경기가 시작되기 전에 공식 기록부를 정리해야 해요.

레이서들의 이름은 결승 순서대로 배열로 들어와요. 0번째 이름이 우승자이고, 1번째는 준우승자예요. 이런 식으로 이어져요.

## 1. 배번 배정하기

`assign-bibs`를 정의해요. 레이서 이름 배열을 받아서, 위치가 앞에 오는 `{ position name }` 쌍의 배열을 반환해요.

```factor
{ "Bolt" "Comet" "Spirit" } assign-bibs .
! => { { 0 "Bolt" } { 1 "Comet" } { 2 "Spirit" } }
```

## 2. 레인 라벨

`lane-labels`를 정의해요. 레이서 이름 배열을 받아서 `"Lane 0: Bolt"` 같은 문자열을 반환해요.

```factor
{ "Bolt" "Comet" } lane-labels .
! => { "Lane 0: Bolt" "Lane 1: Comet" }
```

## 3. 레이서 태그 달기

`tag-racers`를 정의해요. 레이서 이름 배열과 태그 문자열을 받아서 `"<tag>/<index>: <name>"` 형식의 라벨을 반환해요. 같은 태그가 모든 라벨에 그대로 들어가요.

```factor
{ "Bolt" "Comet" } "Green" tag-racers .
! => { "Green/0: Bolt" "Green/1: Comet" }
```

## 4. 완주 기록하기

`record-finishes`를 정의해요. 레이서 이름 배열과 기록부(벡터)를 받아요. 각 레이서마다 `"<index>: <name>"` 형식의 문자열을 기록부에 제자리에서 추가해요. 반환하는 값은 없어요.

```factor
V{ } clone   ! a fresh empty ledger
{ "Bolt" "Comet" } over record-finishes
.
! => V{ "0: Bolt" "1: Comet" }
```

## 5. 랩 벨

`lap-bells`를 정의해요. 숫자 `laps`를 받아서 `"ding "`을 `laps`번 반복한 문자열을 반환해요.

```factor
0 lap-bells .   ! => ""
3 lap-bells .   ! => "ding ding ding "
```
