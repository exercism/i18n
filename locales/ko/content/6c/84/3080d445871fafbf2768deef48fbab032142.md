# 지침

이번 과제는 영어 텍스트를 Pig Latin으로 번역하는 것이에요.
번역 규칙은 네 가지로 정의되는데, 모두 단어 맨 앞에 오는 모음과 자음의 패턴을 살펴봐요.
이 규칙들은 각 단어에서 모음과 자음이 어떻게 쓰이는지 살펴봐요:

- 모음: `a`, `e`, `i`, `o`, `u` 글자
- 자음: 영어 알파벳의 나머지 21개 글자

## 규칙 1

단어가 모음으로 시작하거나 `"xr"` 또는 `"yt"`로 시작하면, 단어 끝에 `"ay"` 소리를 붙여요.

예를 들어:

- `"apple"` -> `"appleay"` (모음으로 시작)
- `"xray"` -> `"xrayay"` (`"xr"`로 시작)
- `"yttria"` -> `"yttriaay"` (`"yt"`로 시작)

## 규칙 2

단어가 하나 이상의 자음으로 시작하면, 먼저 그 자음들을 단어 끝으로 옮기고 단어 끝에 `"ay"` 소리를 붙여요.

예를 들어:

- `"pig"` -> `"igp"` -> `"igpay"` (자음 하나로 시작)
- `"chair"` -> `"airch"` -> `"airchay"` (자음 여러 개로 시작)
- `"thrush"` -> `"ushthr"` -> `"ushthray"` (자음 여러 개로 시작)

## 규칙 3

단어가 0개 이상의 자음 뒤에 `"qu"`가 오는 형태로 시작하면, 먼저 그 자음들(있는 경우)과 `"qu"` 부분을 단어 끝으로 옮기고, 단어 끝에 `"ay"` 소리를 붙여요.

예를 들어:

- `"quick"` -> `"ickqu"` -> `"ay"` (`"qu"`로 시작, 앞에 오는 자음 없음)
- `"square"` -> `"aresqu"` -> `"aresquay"` (자음 하나 뒤에 `"qu`"가 오는 형태로 시작)

## 규칙 4

단어가 하나 이상의 자음 뒤에 `"y"`가 오는 형태로 시작하면, 먼저 `"y"` 앞에 오는 자음들을 단어 끝으로 옮기고, 단어 끝에 `"ay"` 소리를 붙여요.

몇 가지 예를 들어보면:

- `"my"` -> `"ym"` -> `"ymay"` (자음 하나 뒤에 `"y"`가 오는 형태로 시작)
- `"rhythm"` -> `"ythmrh"` -> `"ythmrhay"` (자음 여러 개 뒤에 `"y"`가 오는 형태로 시작)
