# 소개

대부분의 프로그래밍 언어에는 여러 종류의 수를 표현하기 위한 전용 숫자 타입이 있지만, JavaScript에는 두 가지밖에 없어요.

- `number`: 배정밀도 64비트 부동소수점 형식(IEEE 754)의 숫자 데이터 타입이에요.
  예를 들면 `-6`, `-2.4`, `0`, `0.1`, `1`, `3.14`, `16.984025`, `25`, `976`, `1024.0`, `500000` 등이 있어요.
- `bigint`: 임의 정밀도 형식으로 _정수_를 표현할 수 있는 숫자 데이터 타입이에요.
  예를 들면 `-12n`, `0n`, `4n`, `9007199254740991n` 등이 있어요.

[임의 정밀도][ref-arbitrary-precision]가 필요하거나 아주 큰 수를 다뤄야 한다면 `bigint` 타입을 사용해요.
그렇지 않다면 `number` 타입이 더 나은 선택일 거예요.

## 반올림

`Math`라는 내장 전역 객체가 있고, 여기에는 다양한 [반올림 함수][ref-math-object-rounding]가 있어요. 예를 들어 실수를 가장 가까운 정수로 내림(`floor`)하거나 올림(`ceil`)할 수 있어요.

```javascript
Math.floor(234.34); // => 234
Math.ceil(234.34); // => 235
```

[ref-math-object-rounding]: https://javascript.info/number#rounding
[ref-arbitrary-precision]: https://en.wikipedia.org/wiki/Arbitrary-precision_arithmetic
