# 지침

DNA 연구실에서 저장 공간을 절약하려고 연구 데이터를 압축하는 여러 방법을 연구해 왔어요. 그러던 중 한 동료가 DNA 데이터를 이진 표현으로 변환하자고 제안해요.

| 핵산    | 코드   |
| ------- | ------ |
| 공백    | `0000` |
| A       | `0001` |
| C       | `0010` |
| G       | `0100` |
| T       | `1000` |

이렇게 하면 필요한 데이터 저장 비용이 절반으로 줄어들 수도 있지만, 그 대신 사람이 읽기는 어려워져요. 이 점을 곱씹어 보다가, 절약 효과를 측정해 보려고 데이터를 인코딩하고 디코딩하는 모듈을 작성하기로 해요.

## 1. 핵산을 이진 값으로 인코딩하기

`encode_nucleotide/1` 함수를 구현해요. 핵산의 코드 포인트를 받아 인코딩된 코드의 정수 값을 반환해요.

```elixir
DNA.encode_nucleotide(?A)
# => 1
# (which is equal to 0b0001)
```

## 2. 이진 값을 핵산으로 디코딩하기

`decode_nucleotide/1` 함수를 구현해요. 인코딩된 코드의 정수 값을 받아 핵산의 코드 포인트를 반환해요.

```elixir
DNA.decode_nucleotide(0b0001)
# => 65
# (which is equal to ?A)
```

## 3. DNA charlist 인코딩하기

`encode/1` 함수를 구현해요. 핵산과 공백을 나타내는 charlist를 받아 인코딩된 데이터의 bitstring을 반환해요.

```elixir
DNA.encode(~c"AC GT")
# => <<18, 4, 8::size(4)>>
```

## 4. DNA bitstring 디코딩하기

`decode/1` 함수를 구현해요. 핵산과 공백을 나타내는 bitstring을 받아 디코딩된 데이터를 charlist로 반환해요.

```elixir
DNA.decode(<<132, 2, 1::size(4)>>)
# => ~c"TG CA"
```
