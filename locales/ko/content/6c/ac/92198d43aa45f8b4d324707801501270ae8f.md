# 지시 사항

이 연습 문제에서는 공장 직원용 배지를 출력하는 코드를 작성해요.

## 1. 직원의 배지를 출력해요

직원에게는 ID, 이름, 부서 이름이 있어요. 직원 배지 라벨은 다음과 같은 형식이에요: `"[id] - name - DEPARTMENT"`. 직원의 배지 라벨을 반환하도록 (_static_) `Badge.Print()` 메서드를 구현해요:

```csharp
Badge.Print(734, "Ernest Johnny Payne", "Strategic Communication");
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

라벨에서는 부서 이름을 대문자로 표시해야 해요.

## 2. 신입 직원의 배지를 출력해요

컴퓨터 시스템의 특이한 점 때문에, 신입 직원은 공장에서 일을 시작할 때 아직 ID가 없는 경우가 가끔 있어요. 배지는 반드시 필요하기 때문에, ID 접두사 없이 임시 배지를 받게 돼요. 아직 ID가 없는 신입 직원을 지원하도록 (_static_) `Badge.Print()` 메서드를 수정해요:

```csharp
Badge.Print(id: null, "Jane Johnson", "Procurement");
// => "Jane Johnson - PROCUREMENT"
```

## 3. 공장주의 배지를 출력해요

공장주조차도 항상 배지를 달고 있어야 해요. 하지만 공장주에게는 부서가 없어요. 이 경우 라벨에는 부서 이름 대신 `"OWNER"`가 출력되어야 해요. 공장주의 라벨을 출력하도록 (_static_) `Badge.Print()` 메서드를 수정해요:

```csharp
Badge.Print(254, "Charlotte Hale", department: null);
// => "[254] - Charlotte Hale - OWNER"
```

공장주가 신입 직원일 수도 있다는 점에 유의해요:

```csharp
Badge.Print(id: null, "Charlotte Hale", department: null);
// => "Charlotte Hale - OWNER"
```
