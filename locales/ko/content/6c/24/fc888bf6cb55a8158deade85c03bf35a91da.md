# 소개

## 구조체와 클래스

구조체와 클래스는 Swift 프로그래밍을 이루는 주요 구성 요소 두 가지예요. 둘 다 관련된 데이터와 함수를 하나의 독립적인 기능 단위로 묶는 방법이고요. 그리고 구조체나 클래스를 정의한다는 건, 이미 다뤄 본 `Int`나 `String` 같은 타입을 사용하듯이, Swift 안에서 사용할 새로운 타입을 정의하는 거예요.

Swift에서 구조체와 클래스는 비슷한 점이 아주 많아요. 그중에서도 둘 다 값을 _프로퍼티_에 저장하고, _메서드_를 통해 기능을 제공할 수 있어요.

각각 추가적인 기능도 제공하지만, 그 부분은 이 연습 문제의 범위를 벗어나요.

### 구조체와 클래스 정의하기

구조체와 클래스는 거의 같은 방식으로 정의해요. 알맞은 키워드로 시작해서 정의하려는 타입의 이름을 쓰고, 그다음 중괄호 사이에 구조체나 클래스의 본문을 작성해요.

본문은 저장 프로퍼티로 구성될 수 있는데, 저장 프로퍼티는 일반 상수나 변수와 똑같이 정의되고 동작해요.

```swift
struct CharacterStats {
  var health = 0.0
  var speed = 0
  var strength = 0
}

class GameCharacter {
  var stats = CharacterStats()
  var characterClass: String?
  var name: String?
  var active = false
  let id = makeRandomID()
}
```

### 인스턴스

위에서 언급했듯이, 구조체나 클래스를 정의하는 건 새로운 _타입_을 정의하는 것일 뿐이에요. 그 타입의 값이 어떤 모습일지에 대한 설계도일 뿐이고, 실제로 작업할 수 있는 그 타입의 값을 만들어 주지는 않아요.

그 타입의 _인스턴스_를 만들려면 타입 이름 뒤에 괄호 두 개를 써야 해요.

```swift
let someStats = CharacterStats()
let someCharacter = GameCharacter()
```

이렇게 하면 정의에서 제공한 기본값으로 프로퍼티가 채워진, 해당 타입의 값이 만들어져요. GameCharacter의 `name` 프로퍼티처럼 옵셔널인 경우에는 값을 제공하지 않으면, 값을 바로 주지 않고 일반 옵셔널 타입을 정의할 때처럼 그 프로퍼티의 기본값이 nil이 돼요.

구조체에서는 Swift가 자동으로 _멤버와이즈 이니셜라이저_라는 것을 제공하는데, 괄호 안에 구조체 프로퍼티의 값을 제공하면 정의의 기본값을 덮어쓸 수 있어요.

```swift
let differentStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

### 프로퍼티 접근하기

구조체와 클래스의 프로퍼티는 _점 표기법_으로 접근할 수 있는데, 값의 이름 뒤에 점(`.`)을 찍고 프로퍼티 이름을 쓰는 방식이에요. 구조체나 클래스의 프로퍼티가 자체적인 프로퍼티를 가지고 있다면, 이 점 표기법으로 중첩된 프로퍼티에도 접근할 수 있어요.

이 표기법은 프로퍼티의 값을 가져올 때도, 허용된다면 값을 바꿀 때도 사용할 수 있어요.

```swift
someStats.health
// => 0
someCharacter.name
// => nil

someStats.health = 87.3
someStats.health
// => 87.3
someCharacter.name = "Luther"
someCharacter.name
// => "Luther"

someCharacter.id  = "new id"
// Error: Cannot assign to property: 'id' is a 'let' constant
```

### 메서드

구조체와 클래스에 데이터를 저장하는 프로퍼티처럼, 구조체나 클래스에 함수를 저장하는 _메서드_도 정의할 수 있어요.

메서드는 일반 함수와 같은 방식으로 정의하는데, 구조체나 클래스의 본문 안에만 정의해요. 구조체에서 함수가 프로퍼티의 값을 바꾼다면, 함수 앞에 `mutating` 키워드를 붙여야 한다는 점에 유의해요. 또한 프로퍼티가 메서드에 의해 바뀔 수 있다면, 그 프로퍼티는 일반 변수처럼 `let` 대신 `var`로 정의해야 해요.

```swift
struct CharacterStats {
  var health = 0.0
  var speed = 0
  var strength = 0

  mutating func takeHit(_ damage: Double) {
    health = max(0.0, health - damage)
  }
  func canLift(_ weight: Int) -> Bool {
    weight < strength * 100
  }
}

class GameCharacter {
  var stats = CharacterStats()
  var characterClass: String?
  var name: String?
  var active = false
  let id: String = makeRandomID()

  func takesDamage(_ damage: Double) {
    stats.takeHit(damage)
    if stats.health <= 0 {
      active = false
    }
  }
  func sayName() -> String {
    return "My name is \(name ?? "no one"), my class is \(characterClass ?? "undetermined")"
  }
  func lift(_ weight: Int) -> String {
    if stats.canLift(weight) {
      return "No problem!"
    } else {
      return "Ooof! No way."
    }
  }
}
```

이 메서드들은 프로퍼티처럼 점 표기법으로 호출할 수 있어요.

```swift
var myChar = GameCharacter()
myChar.stats = CharacterStats(health: 72.8, speed: 19, strength: 6)
myChar.active = true

myChar.lift(750)
// => "Ooof! No way."
myChar.takesDamage(80)
myChar.active
// => false
```

### self

구조체나 클래스의 모든 인스턴스에는 `self`라는 암시적 프로퍼티가 있는데, 이는 인스턴스 자기 자신을 가리켜요.
`self`는 주로 인스턴스 프로퍼티와 이름이 같은 매개변수를 구분할 때 가장 많이 사용해요.

```swift
struct Position {
    var x = 0

    mutating func move(x: Int) {
        // Here, 'self.x' refers to the struct's property,
        // while 'x' refers to the parameter passed to the method.
        self.x = x
    }
}
```

Swift 타입에는 대문자로 시작하는 `Self` 키워드도 있는데, 이는 인스턴스 자체가 아니라 인스턴스의 *타입*을 가리켜요.
