# 소개

## 열거형

C#의 `enum` 타입은 이름이 지정된 상수들의 고정된 집합(열거형)을 나타내요. 이 타입의 주된 목적은 숫자 상수를 타입에 안전한 방식으로 다루게 해 주는 것이에요. 사용할 수 있는 값을 미리 정의된 집합으로 제한해 주죠. 간단한 열거형은 다음과 같이 정의할 수 있어요:

```csharp
enum Season
{
    Spring,
    Summer,
    Autumn,
    Winter
}
```

값을 명시적으로 지정하지 않으면, 열거형 멤버에는 자동으로 1씩 증가하는 정수 값이 할당되는데, 첫 번째 값은 0이에요. 값을 직접 지정하는 것도 가능해요:

```csharp
enum Answer
{
    Maybe = 1,
    Yes = 3,
    No = 5
}
```
