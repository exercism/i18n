# 소개

Cairo에서 배열은 같은 타입의 원소를 구조적인 방식으로 저장하도록 설계된 기본 데이터 구조예요.
다른 프로그래밍 언어의 배열과 비슷하게, 배열의 각 원소는 인덱스로 접근할 수 있어서 효율적으로 가져오고 다룰 수 있어요.

Cairo 배열은 불변 데이터 구조예요.
원소는 배열의 끝에 추가하거나 배열의 앞에서 제거할 수만 있어요.
이런 설계는 데이터 무결성과 안정성을 보장하며, 메모리 관리에 대한 Cairo의 접근 방식과도 맞닿아 있어요.
배열은 `ArrayTrait::new()`로 초기화하고, 원소를 저장하기 위한 타입별 선언을 지원해요.
원소에 접근할 때는 `get()`이나 `at()` 메서드를 사용하거나 첨자 연산자 `arr[index]`를 사용할 수 있어요.
배열의 앞에서 원소를 제거할 때는 `pop_front()` 함수만 사용할 수 있어요.
이런 특징 덕분에 Cairo 배열은 구조화된 데이터를 저장하고 조회하는 작업에 잘 어울려요.
