# 소개

F#에서 조건에 따라 코드를 실행하는 가장 흔한 방법은 `if/elif/else` 표현식을 사용하는 거예요.

```fsharp
if x = 5 then
    printfn "Expression to evaluate when x equals 5"
elif x > 7 then
    printfn "Expression to evaluate when x greater than 7"
else
    printfn "Expression to evaluate in all other cases"
```

`if/elif/else` 표현식에 사용하는 조건은 반드시 `bool` 타입이어야 해요. F#에는 _truthy_ 값이라는 개념이 없어요.
