# 소개

Ruby는 동적 타입 언어이면서 강타입 언어예요.
동적 언어에서는 변수나 객체의 타입이 실행 시점에 결정돼요. 그래서 값이나 타입이 마지막 순간까지, 즉 인터프리터가 코드를 해석하는 순간까지 바뀔 수 있어요.
그럼 강타입이라는 건 무슨 뜻일까요?
변수나 객체의 타입이 한 번 정해지면, Ruby는 그걸로 무엇을 할 수 있는지에 대해 엄격해요. 예를 들어 볼까요?

```ruby
x = '2'
y = x + 'n'
# => '2n'
```

**하지만**

```ruby
x = '2'
y = x + 2
# => TypeError (no implicit conversion of Integer into String)
```

Ruby에서는 모든 것이 객체라는 것을 기억해야 해요.
클래스조차 `Class` 클래스의 인스턴스예요.

예를 들어 볼까요?

```ruby
1.class
# => Integer

Integer.is_a?(Object)
# => true

Class.is_a?(Object)
# => true
```

덕분에 클래스를 이렇게 정의할 수도 있어요.

```ruby
Car = Class.new do
  def run
    'running'
  end
end

Car.new.run
# => 'running'
```

마지막으로, `Integer` 객체가 담는 값은 하나 이상의 (연속된) 숫자로 정의될 수 있고, 그 메서드들은 다양한 [수학 연산자][integers-docs]를 지원한다는 점을 기억해야 해요.

[integers-docs]: https://docs.ruby-lang.org/en/master/Integer.html

~~~~exercism/note
문서에서는 인스턴스 메서드를 `Class#method_name` 같은 문법으로 언급하는 경우가 많고, 클래스나 모듈 수준의 메서드는 `Class::method_name`으로 언급해요.
`::`는 _범위 결정 연산자_라고 부르는데, 여기서는 클래스나 모듈 수준에 있는 상수나 메서드를 가리켜요.
Ruby 문서나 메일링 리스트, 그리고 다른 지원 공간에서 이런 표기를 만나게 될 거예요.
다만 이 글에서는 클래스와 모듈 메서드를 `ClassName.method_name` 또는 `ModuleName.method_name`으로 표기해요.
~~~~
