# 소개

## 참 같은 값과 거짓 같은 값

Common Lisp에서는 `()`를 제외한 모든 값이 "참"이에요. `()`는 "거짓"이에요.
`t`와 `nil`이라는 두 가지 특별한 상수 기호가 있는데, 각각 참과 거짓을 나타내요.

## 조건문

Common Lisp은 여러 가지 조건 표현식을 제공해요. 주요 차이점은 지원하는 분기의 개수예요.

- `when`과 `unless`는 단일 분기를 허용해요:

```lisp
(when (= 2 2) "All is well")      ; => "All is well"
(unless (= 2 2) "Time to panic!") ; => NIL
```

테스트 표현식 뒤의 부분은 하나 이상의 표현식이 될 수 있어요.

- `if`는 고전적인 if-then-else 구조를 제공해요:

```lisp
(if (= 2 2) 'how-honest 'you-liar) ; => HOW-HONEST
```

참고로, then 절과 else 절은 각각 하나의 표현식만 될 수 있어요.

- `cond`는 `if` 표현식을 중첩하지 않고 여러 분기를 가질 수 있는 방법을 제공해요:

```lisp
(cond ((= 0 2) 'nope)
      ((= 1 2) 'try-again)
      ((= 2 2) 'quite-true)
      ((= 3 2) 'too-far)
      (t 'something-else))
; => QUITE-TRUE
```

참고로, 테스트 표현식 뒤에 오는 표현식의 개수에는 제한이 없어요.

- `case`는 고전적인 'switch' 스타일 구조를 제공해요: 하나의 값을 여러 분기와 비교해요:

```lisp
(case 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark")
  (otherwise "???"))
; => "???"
```

참고로, `cond`와 마찬가지로 테스트 표현식 뒤에 오는 표현식의 개수에는 제한이 없어요.
