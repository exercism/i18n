# 지침

이 연습 문제에서는 친구가 개발 중인 새로운 RPG 게임의 퀘스트 로직을 구현해요.
게임의 주인공은 사납고 충직한 반려견을 데리고 다니는 용감한 소녀, Annalyn이에요.
그런데 안타깝게도 Annalyn의 가장 친한 친구가 숲에서 열매를 찾던 중 납치되는 사건이 벌어져요.
Annalyn은 가장 친한 친구를 찾아 구출하려고 하고, 원한다면 이 여정에 반려견을 데리고 갈 수도 있어요.

친구의 흔적을 한참 따라간 끝에, Annalyn은 친구가 갇혀 있는 야영지를 발견해요.
납치범은 둘이에요. 힘센 기사와 교활한 궁수죠.

납치범들을 찾은 Annalyn은 다음 중 어떤 행동을 할 수 있을지 생각해요:

- _빠른 공격_: **기사**가 **_잠들어_** 있을 때 빠른 공격을 할 수 있어요. 갑옷을 입는 데 시간이 걸리기 때문에 기사가 무방비 상태가 되거든요.
- _첩보_: 무리 중 **적어도 한 명**이 **_깨어_** 있으면 첩보를 얻을 수 있어요. 그렇지 않으면 시간 낭비예요.
- _죄수에게 신호 보내기_: **죄수**가 **_깨어_** 있고 **궁수**가 **_잠들어_** 있으면 새소리로 죄수에게 신호를 보낼 수 있어요. 궁수는 새소리 신호를 배웠기 때문에 메시지를 가로챌 수 있거든요.
- _죄수 구출_: Annalyn은 야영지에 몰래 들어가 죄수를 구출할 수 있어요.
  위험한 행동이라 두 가지 방법 중 하나로만 성공할 수 있어요:
  - 반려견을 데리고 있다면 **궁수**가 **_잠들어_** 있을 때 죄수를 구출할 수 있어요.
    기사는 개를 무서워하고, Annalyn과 죄수가 도망칠 때까지 궁수가 준비할 시간은 없거든요.
  - 반려견이 없다면 Annalyn과 죄수는 아주 조심스럽게 움직여야 해요!
    **죄수**가 **_깨어_** 있고 **기사**와 **궁수**가 둘 다 **_잠들어_** 있을 때 죄수를 구출할 수 있어요. 하지만 **죄수**가 **_잠들어_** 있으면 구출할 수 없어요. Annalyn이 갑자기 나타나면 죄수가 놀라서 기사와 궁수를 깨우게 되거든요.

해야 할 일은 네 가지예요. 숲에서 만난 세 인물의 상태와 Annalyn의 반려견 동반 여부에 따라 위 행동들을 할 수 있는지 판단하는 로직을 구현하는 거예요.

## 1. '빠른 공격' 행동이 가능한지 확인하기

기사가 깨어 있는지를 나타내는 불리언 값을 받는 `canExecuteFastAttack`이라는 함수를 구현해요.
이 함수는 그 인물의 상태에 따라 '빠른 공격' 행동이 가능하면 `true`를 반환해요.
그렇지 않으면 `false`를 반환해요:

```javascript
const knightIsAwake = true;
canExecuteFastAttack(knightIsAwake);
// => false
```

## 2. '첩보' 행동이 가능한지 확인하기

기사, 궁수, 죄수가 각각 깨어 있는지를 나타내는 불리언 값 세 개를 받는 `canSpy`라는 함수를 구현해요.
이 함수는 인물들의 상태에 따라 '첩보' 행동이 가능하면 `true`를 반환해요.
그렇지 않으면 `false`를 반환해요:

```javascript
const knightIsAwake = false;
const archerIsAwake = true;
const prisonerIsAwake = false;
canSpy(knightIsAwake, archerIsAwake, prisonerIsAwake);
// => true
```

## 3. '죄수에게 신호 보내기' 행동이 가능한지 확인하기

궁수와 죄수가 각각 깨어 있는지를 나타내는 불리언 값 두 개를 받는 `canSignalPrisoner`라는 함수를 구현해요.
이 함수는 인물들의 상태에 따라 '죄수에게 신호 보내기' 행동이 가능하면 `true`를 반환해요.
그렇지 않으면 `false`를 반환해요:

```javascript
const archerIsAwake = false;
const prisonerIsAwake = true;
canSignalPrisoner(archerIsAwake, prisonerIsAwake);
// => true
```

## 4. '죄수 구출' 행동이 가능한지 확인하기

불리언 값 네 개를 받는 `canFreePrisoner`라는 함수를 구현해요.
처음 세 매개변수는 기사, 궁수, 죄수가 각각 깨어 있는지를 나타내요.
마지막 매개변수는 Annalyn의 반려견이 함께 있는지를 나타내요.
이 함수는 인물들의 상태와 Annalyn의 반려견 동반 여부에 따라 '죄수 구출' 행동이 가능하면 `true`를 반환해요.
그렇지 않으면 `false`를 반환해요:

```javascript
const knightIsAwake = false;
const archerIsAwake = true;
const prisonerIsAwake = false;
const petDogIsPresent = false;
canFreePrisoner(knightIsAwake, archerIsAwake, prisonerIsAwake, petDogIsPresent);
// => false
```
