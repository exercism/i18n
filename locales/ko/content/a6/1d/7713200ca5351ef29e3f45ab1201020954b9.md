# 반복

프로그래밍에서 [반복][iteration]은 코드 블록을 여러 번 실행하는 과정을 말해요.
이는 `while`문이나 `until`문 같은 개념을 사용해서 할 수 있어요.
자기 자신을 호출하는 함수인 재귀를 사용해서 할 수도 있어요.

하지만 대부분은 `Array`, `Range`, `String`처럼 여러 항목으로 이루어진 컬렉션을 반복하고 싶을 때가 많아요.
Crystal의 `Array`와 `Range` 클래스는 모두 [`Enumerable`][enumerable] 모듈을 포함하고 있는데, 이 모듈은 원소를 반복하기 위한 여러 메서드를 제공해요.
반면 `String` 클래스는 문자를 반복하기 위한 자체적인 메서드들을 가지고 있어요.

Crystal에는 다른 언어들에 있는 `for`문이 없어요.
대신 반복에 사용할 수 있는 여러 메서드가 있어요.

## 반복하기

컬렉션을 반복하는 가장 흔한 방법은 [`each`][each] 메서드를 사용하는 것이에요. 이 메서드는 컬렉션의 각 원소를 블록에 넘겨줘요.
`Range`로도 쉽게 할 수 있어요.
1과 3 사이를 반복하고 싶다면 `each` 메서드로 그 범위를 반복하면 돼요.

```crystal
(1..3).each do |n|
  puts n
end

# Output:
# 1
# 2
# 3
```

더 간단하게, 그냥 몇 번 반복하고 싶다면 `Int` 클래스에 있는 [`times`][times] 메서드를 사용할 수 있어요.

```crystal
3.times do |n|
  puts n
end

# Output:
# 0
# 1
# 2
```

## `String` 반복하기

`String`은 문자의 나열이고 `Enumerable` 모듈에 속하지 않아요. 그래서 문자를 반복하기 위한 자체적인 메서드들을 가지고 있어요.
`String`을 반복하는 가장 흔한 방법은 [`each_char`][each_char] 메서드를 사용하는 것이에요. 이 메서드는 `String`의 각 문자를 블록에 넘겨줘요.

~~~~exercism/note
`each_char` 메서드는 블록에 `String` 객체가 아니라 `Char` 객체를 넘겨줘요.
~~~~

```crystal
str = "hello"
str.each_char { |char| puts char }

# Output:
# h
# e
# l
# l
# o
```

`String`을 반복하는 또 다른 방법은 [`each_line`][each_line] 메서드를 사용하는 것이에요.
이 메서드는 주로 파일을 한 줄씩 읽을 때 사용해요.

```crystal
str = "hello\nworld"
str.each_line do |line|
  puts line
end

# Output:
# hello
# world
```

## `Enumerable` 모듈을 포함하는 객체 반복하기

[`Enumerable`][enumerable] 모듈은 컬렉션의 원소를 반복하기 위한 여러 메서드를 제공해요.
`Enumerable` 모듈을 포함하는 컬렉션으로는 `Array`, `Range`, `Hash`, `Set` 등이 있고, 나머지는 이후 개념에서 다뤄요.

`Array`를 반복하는 가장 흔한 방법은 [`each`][each] 메서드를 사용하는 것이에요. 이 메서드는 `Array`의 각 원소를 블록에 넘겨줘요.

```crystal
arr = [5, 2, 3]
arr.each do |element|
  puts element
end

# Output:
# 5
# 2
# 3
```

### Map

[`map`][map] 메서드는 `Array`를 반복하는 또 다른 방법인데, 각 원소에 블록을 적용한 결과를 담은 새 `Array`를 반환해요.
`each` 메서드와 비슷하지만, 변환된 원소를 담은 새 `Array`를 반환해요.
변환은 컬렉션의 각 원소에 함수를 적용하고 싶을 때 아주 유용한데, 흔히 하는 작업이에요.

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  element * 2
end

new_arr
# => [2, 4, 6]
```

`if` 같은 제어 흐름을 사용하면 어떤 원소를 변환할지 걸러낼 수 있어요.

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  if element.odd?
    element * 2
  else
    element
  end
end

new_arr
# => [2, 2, 6]
```

## 축약형

Crystal에는 컬렉션의 각 원소를 반복하면서 메서드를 적용하는 축약 문법이 있어요.
메서드 하나로 변환하기만 하면 되는 간단한 로직을 다룰 때 유용해요.
`&.` 문법 뒤에 메서드 이름을 붙여서 사용해요.

```crystal
arr = [1, 2, 3]
arr.map(&.to_s)
# => ["1", "2", "3"]
```

### 인덱스와 함께

반복하는 원소의 인덱스를 알아야 할 때가 있는데, 그럴 때는 [`each_with_index`][each_with_index] 메서드나 [`map_with_index`][map_with_index] 메서드를 사용할 수 있어요.
이 메서드는 각 원소와 그 인덱스를 블록에 넘겨주고, 시작 인덱스를 지정하는 선택적 인자도 받아요.

```crystal
arr = [1, 2, 3]
arr.each_with_index(4) do |element, index|
  puts "Element: #{element}, Index: #{index}"
end

# Output:
# Element: 1, Index: 4
# Element: 2, Index: 5
# Element: 3, Index: 6
```

`String` 객체에서도 [`each_char_with_index`][each_char_with_index] 메서드를 사용할 수 있다는 점을 기억해 두세요.

### sum

[`sum`][sum] 메서드는 컬렉션에 있는 모든 원소의 합을 반환해요. 원소를 더하기 전에 변환하는 선택적 블록도 받고, 합의 초깃값을 지정하는 선택적 인자도 받아요.

```crystal
arr = [1, 2, 3]
arr.sum
# => 6

arr.sum(2) { |n| n * 2 }
# => 14
```

### reduce

[`reduce`][reduce], 다른 언어에서 fold로 알려진 메서드는 결합 방식과 초깃값을 받아 컬렉션의 모든 원소를 결합해요.
`reduce` 메서드에는 블록에 전달되는 누산기가 있는데, 누산기는 이전 반복의 결과예요.
이는 컬렉션의 모든 원소를 결합하는 재귀적인 과정이 돼요.

```crystal
arr = [1, 2, 3]
arr.reduce(0) do |acc, n|
  acc + n
end
# => 6
```

`reduce`는 `sum`과 비슷해 보일 수 있지만, 누산기의 초깃값과 결합 방식을 지정할 수 있어서 더 유연해요.
`reduce`로 `sum`, `count` 같은 다른 메서드들을 구현할 수 있어요.
