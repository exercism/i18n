# 힌트

## 일반

- [typespecs][typespecs] 공식 문서를 읽어보세요.
- [문서 작성][writing-documentation]에 관한 공식 문서를 읽어보세요.
- [공식 시작하기 가이드][getting-started-module-attributes]에서 모듈 속성을 애노테이션으로 사용하는 방법을 읽어보세요.
- [공식 시작하기 가이드][getting-started-typespecs]에서 typespecs 사용법을 읽어보세요.

## 1. 양식 도구의 목적 문서화하기

- 모듈 속성 `@moduledoc`을 사용해서 모듈의 문서를 작성할 수 있어요.

## 2. 빈 값으로 필드 채우기 문서화하기

- 모듈 속성 `@doc`을 사용하면 함수의 문서를 작성할 수 있어요.
- 모듈 속성 `@spec`을 사용하면 함수의 typespec을 작성할 수 있어요.
- `@doc`과 `@spec` 속성은 해당 속성이 설명하는 함수의 첫 번째 함수 절 바로 앞에 놓아요.
- 사용할 수 있는 모든 타입의 목록은 [typespecs 문서][typespecs-types]를 참고하세요.
- 문자열에 맞는 타입은 [`String` 모듈][string-t]에 정의되어 있어요.

## 3. 값을 대문자 배열로 나누기 문서화하기

- 모듈 속성 `@doc`을 사용하면 함수의 문서를 작성할 수 있어요.
- 모듈 속성 `@spec`을 사용하면 함수의 typespec을 작성할 수 있어요.
- `@doc`과 `@spec` 속성은 해당 속성이 설명하는 함수의 첫 번째 함수 절 바로 앞에 놓아요.
- 사용할 수 있는 모든 타입의 목록은 [typespecs 문서][typespecs-types]를 참고하세요.
- 문자열에 맞는 타입은 [`String` 모듈][string-t]에 정의되어 있어요.
- 배열은 매개변수화된 타입이에요.

## 4. 값이 최대 길이를 가진 필드에 맞는지 확인하기 문서화하기

- 모듈 속성 `@doc`을 사용하면 함수의 문서를 작성할 수 있어요.
- 모듈 속성 `@spec`을 사용하면 함수의 typespec을 작성할 수 있어요.
- `@doc`과 `@spec` 속성은 해당 속성이 설명하는 함수의 첫 번째 함수 절 바로 앞에 놓아요.
- 사용할 수 있는 모든 타입의 목록은 [typespecs 문서][typespecs-types]를 참고하세요.
- 문자열에 맞는 타입은 [`String` 모듈][string-t]에 정의되어 있어요.
- typespec에는 리터럴 값을 사용할 수 있어요.
- 파이프 `|`를 사용해서 타입들의 합집합을 나타낼 수 있어요.

## 5. 다양한 주소 형식 문서화하기

- 모듈 속성 `@type`을 사용해서 사용자 정의 공개 타입을 정의할 수 있어요.
- 타입은 복합적일 수 있어요. 예를 들어 맵 타입을 지정할 때에는 특정 키 아래 값들의 타입도 함께 지정할 수 있어요.
- [타입 연산자 `::`][type-operator]를 사용해서 타입 앞에 변수 이름을 붙일 수도 있어요.
- 사용자 정의 타입을 사용해서 다른 사용자 정의 타입을 정의할 수 있어요.

## 6. 주소 서식 지정 문서화하기

- 모듈 속성 `@doc`을 사용하면 함수의 문서를 작성할 수 있어요.
- 모듈 속성 `@spec`을 사용하면 함수의 typespec을 작성할 수 있어요.
- `@doc`과 `@spec` 속성은 해당 속성이 설명하는 함수의 첫 번째 함수 절 바로 앞에 놓아요.
- 사용할 수 있는 모든 타입의 목록은 [typespecs 문서][typespecs-types]를 참고하세요.
- 문자열에 맞는 타입은 [`String` 모듈][string-t]에 정의되어 있어요.
- typespec에서는 사용자 정의 타입을 사용할 수 있어요.
