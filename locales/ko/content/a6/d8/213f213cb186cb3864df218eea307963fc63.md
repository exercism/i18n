# 소개

Haxe의 프로퍼티는 클래스의 멤버로, 그 클래스 안의 데이터에 접근할 수 있게 해줘요. 호출하는 쪽에서는 이 데이터를 설정하거나 조회할 수 있어요. 프로퍼티는 설정 접근자와 조회 접근자 중 하나, 또는 둘 다로 이루어져요.

프로퍼티도 다른 클래스 멤버와 마찬가지로 접근 제한자(public, private 등)를 가져요. 다만 설정 접근자의 접근 수준은 조회(get) 접근자와 독립적일 수 있고, 그 반대도 마찬가지예요. 프로퍼티에 두 접근자가 모두 있어야 하는 것은 아니고, 하나만 있어도 돼요.

읽기 접근과 쓰기 접근은 다음 예시에서 보듯이 문법에 그대로 드러나요:

```haxe
class Main {
  public var x(default, null):Int;
}
```

`default`와 `null`은 둘 다 특별한 **접근 식별자**예요. 접근 식별자는 필드를 읽을 때(첫 번째 식별자)와 필드에 쓸 때(두 번째 식별자)의 동작을 정해요. 사용할 수 있는 값은 다음과 같아요:

- `default`: 필드가 public이면 일반적인 필드 접근을 허용해요.
- `null`: 필드를 정의한 클래스 안에서만 접근을 허용해요.
- `get/set`: 접근자 메서드(`get_x()`) 호출로 접근이 이루어져요.
- `dynamic`: `get/set`과 같지만 접근자 메서드가 존재하는지 확인할 수 없어요.
- `never`: 어떤 접근도 허용하지 않아요.

전체 예시를 볼까요:

```haxe
class Main {
  public var x(default, set):Int;

  public function set_x(x:Int):Int {
    return this.x = x + 2;
  }

  public function main() {
    trace(x); // null
    x = 2;
    trace(x); // 4
  }
}
```
