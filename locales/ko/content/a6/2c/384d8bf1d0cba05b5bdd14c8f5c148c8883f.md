# 힌트

이 과제들은 모두 `print` 명령이 필요해요:
```awk
{print "something", "something else"}
```

## 1. 사용자 이름 나열하기

* 필드 구분자를 정의할 때는 [`FS` 변수][var-fs]를 사용해요.

## 2. 줄 번호 출력하기

* 줄 번호를 가져오려면 [내장 변수 `NR`][var-nr]을 사용해요.

## 3. 잘못된 홈 디렉터리를 가진 레코드 출력하기

* 홈 디렉터리는 6번째 필드예요.
* 주어진 `startsWith` 함수를 사용해요.
* [불리언 연산자][boolean-ops]를 사용해요: `&&`, `||`, `!`.

## 4. bash를 사용하는 유효한 사용자 수 출력하기

* 로그인 셸은 마지막 필드예요. [`NF` 변수][var-nf]를 사용할 수 있어요.
