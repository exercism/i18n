# 소개

Common Lisp의 심볼은 다른 값을 가리킬 수 있는 특별한 값이에요. _키워드_의 경우에는 자기 자신을 가리키죠.
Lisp가 심볼을 평가하면, 그 심볼은 자신이 가리키는 값으로 바뀌어요:

```lisp
foo  ; => <whatever-foo-points-to>
:foo ; => :FOO
```

참고로, 키워드는 앞에 콜론(`:`)을 붙여 나타내요.

인용은 S-표현식 앞에 `'`를 붙이는 것으로, Lisp에게 그 표현식을 평가하지 말라고 알려줘요.
`defun` 예제에서 `'foo`를 인용함으로써, Lisp가 `FOO`가 가리키는 대상을 찾으려고 시도하다가 (찾지 못하고) 실패하는 대신, `FOO`라는 값 자체를 반환하도록 했어요.
만약 프로그램 어디에서도 `FOO`를 정의하지 않았다면:

```lisp
foo  ; => <ERROR! Lisp doesn't know what foo points to!>
'foo ; => FOO
```

지금은 함수에서 심볼을 반환하는 방법 정도로만 생각해도 돼요. 하지만 인용은 앞으로 나올 개념 연습 문제에서 다시 다루면서 그 의미를 더 자세히 살펴볼 거예요.
