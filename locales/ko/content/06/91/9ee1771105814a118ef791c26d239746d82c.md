# 지침

이 연습 문제에서는 보물을 담아 둘 제네릭(/ 마법의!) TreasureChest를 작성해 볼 거예요.

## 1. TreasureChest 타입 정의하기

두 개의 필드를 가진 `TreasureChest{T}` 매개변수 타입을 정의해요.

- 보물 상자의 비밀번호를 저장하는 `String` 타입의 `password` 필드
- 보물을 저장하는 `T` 타입의 `treasure` 필드. 이 값은 제네릭이라서 보물이 무엇이든 될 수 있어요.

```julia-repl
julia> chest = TreasureChest{String}("password", "gold")
TreasureChest{String}("password", "gold")
```



## 2. get_treasure() 함수 정의하기

이 함수는 두 개의 인자를 받아야 해요.

- `String` (비밀번호를 시도할 때 사용해요)
- `TreasureChest` 타입

이 함수는 전달받은 비밀번호 시도를 `TreasureChest`의 `password`와 비교해야 해요.

- 비밀번호가 일치하면 보물을 반환해요.
- 비밀번호가 일치하지 않으면 `nothing`을 반환해요.

```julia-repl
julia> get_treasure("password", chest)
"gold"

julia> get_treasure("wrong", chest)
# no output

julia> isnothing(get_treasure("wrong", chest))
true
```

## 3. multiply_treasure() 함수 정의하기

이 함수는 두 개의 인자를 받아야 해요.

- 곱할 정수 `n`
- `TreasureChest{T}` 타입

이 함수는 새로운 `TreasureChest{Vector{T}}`를 반환해야 해요. 이때,

- 원래와 같은 비밀번호
- 원래 보물이 `n`번 반복된, 길이가 `n`인 `Vector{T}`로 곱해진 보물

```julia-repl
julia> multiply_treasure(3, chest)
TreasureChest{Vector{String}}("password", ["gold", "gold", "gold"])
```
