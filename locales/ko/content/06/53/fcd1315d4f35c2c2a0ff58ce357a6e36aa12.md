Azara와 Rui는 해적을 테마로 한 보물찾기 대회에 함께 참가한 팀원이에요.

그런데 정리가 좀 엉망이에요.
Azara의 좌표는 Rui의 좌표와 형식도 다르고 정렬 순서도 달라 보여서, 어떤 보물이 어떤 장소에 짝을 이루는지 알아내려면 두 목록을 번갈아 확인해야 해요.
F#을 갓 배우기 시작한 두 사람은 보물찾기 정보를 더 잘 정리할 수 있도록 작은 프로그램(사실은 함수 몇 개예요)을 짜 달라고 도움을 청하러 왔어요.

## 1. 좌표 추출하기

Azara의 목록에서 `(treasure, coordinate)` 쌍을 받아 지도 좌표만 추출해서 반환하는 `getCooordinate()` 함수를 구현해요.

```fsharp
getCoordinate ("Scrimshaw Whale's Tooth", "2A")
// "2A"
```

## 2. 좌표 형식 변환하기

"2A" 형식의 좌표를 받아 `(2, 'A')` 형식의 튜플을 반환하는 `convertCoordinate()` 함수를 구현해요.

```fsharp
convertCoordinate "2A"
// (2, 'A')
```

## 3. 좌표 일치 확인하기

`compareRecords()` 함수를 구현해요.
이 함수는 `(treasure, coordinate)` 쌍과 `(location, coordinate, quadrant)` 레코드를 받아 각각의 좌표를 비교해요.
좌표가 "일치"하면 **`true`**를, 그렇지 않으면 **`false`**를 반환해요.
정확하게 비교하려면 필요에 따라 좌표 형식을 다시 맞춰 줘요.

```fsharp
compareRecords ("Brass Spyglass", "4B") ("Seaside Cottages", (1, 'C'), "blue")
// false

compareRecords ("Model Ship in Large Bottle", "8A") ("Harbor Managers Office", (8, 'A'), "purple")
// true
```

## 4. 일치하는 레코드 합치기

`createrecord()` 함수를 구현해요.
이 함수는 Azara의 목록에서 온 `(treasure, coordinate)` 쌍과 Rui의 목록에서 온 `(location, coordinate, quadrant)` 레코드를 받아, **좌표가 일치하면** `(coordinate, location, quadrant, treasure)`를 반환해요.
좌표가 일치하지 않으면 같은 모양의 튜플을 반환하되 `""`로 채워요.
정확하게 비교하려면 필요에 따라 좌표 형식을 다시 맞춰 줘요.

```fsharp
createRecord ("Brass Spyglass", "4B") ("Abandoned Lighthouse", (4, 'B'), "Blue")
// ("4B", "Abandoned Lighthouse", "Blue", "Brass Spyglass")

createRecord ("Brass Spyglass", "4B") ("Seaside Cottages", (1, 'C'), "Blue")
// ("", "", "", "")
```
