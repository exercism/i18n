# 안내

일반 숫자를 [서수](https://en.wikipedia.org/wiki/Ordinal_numeral)로 변환하는 함수를 작성해요. 0의 경우에는 문자열 "0"을 그대로 반환해요.

서수는 목록에서 어떤 것의 위치를 나타내는 숫자예요. 이 연습 문제에서는 바로 이 맥락에서 서수를 사용하는데, 서수의 이름은 영어 철자로 써요.

서수는 다음과 같아요 (적어도 한 가지 형태로는):

```
1st 2nd 3rd 4th 5th... 9th 10th 11th 12th... 20th 21st 22nd 23rd 24th... etc.
```

따라서 일반 숫자를 입력하면 그에 해당하는 서수가 나와요:

```
1 -> 1st
2 -> 2nd
3 -> 3rd
(and so on...)
```
