# 지침

문득 향수가 밀려오고, 오래된 Blorkemon™️ 카드의 먼지를 털어내고 싶은 강한 충동이 생겨요.
Blorkemon™️ 카드는 훌륭한 옛날식 카드 교환 게임이에요.
각 `Card`에는 Blorkemon™️ 몬스터가 그려져 있고, 공격력 레벨도 함께 있어요. 운이 좋으면 카드가 shiny일 수도 있어요.

## 1. 공격력 비교하기

Blorkemon™️ 카드는 하나같이 다음 카드보다 더 강해 보이지만, 직접 확인해 보는 게 좋아요.

`isMorePowerful` 함수를 구현해요. 첫 번째 인자로 받은 카드가 다른 카드보다 엄격하게 더 강하면 `True`를, 그렇지 않으면 `False`를 반환해야 해요.

```elm
newthree = Card "Newthree" 120 False
scientuna = Card "Scientuna" 6 True

isMorePowerful newthree scientuna
    --> True
```

## 2. 가장 높은 공격력 찾기

손에 Blorkemon™️ 카드가 가득 있으면, 가장 강력한 공격을 준비할 수 있어야 해요.

`maxPower` 함수를 구현해요. 이 함수는 카드 두 장 중 가장 높은 공격력을 반환해요.

```elm
maxPower newthree scientuna
    --> 120
```

## 3. 카드 정렬하기

모든 Blorkemon™️ 카드를 적어도 한 장씩은 가지고 있었던 것 같은데, 마지막으로 확인한 지도 꽤 오래됐어요. Pulpapedia의 공식 목록과 비교하려면 카드를 정렬하는 게 좋겠어요.

`sortByMonsterName` 함수를 구현해요. 이 함수는 `Cards` 목록을 받아 몬스터 이름순으로 정렬한 목록을 반환해야 해요.

```elm
sortByMonsterName [newthree, scientuna]
    --> [Card "Newthree" 120 False, Card "Scientuna" 6 True]
```

## 4. 가장 멋진 카드를 먼저

Blorkemon™️은 세상에서 가장 멋진 존재예요.
그냥 가볍게 하는 말이 아니라, 이를 증명할 과학적인 방법도 있어요.

`sortByCoolness` 함수를 구현해요. 이 함수는 가장 멋진 카드를 앞에 두는 순서로 카드 목록을 정렬해요.
카드의 멋짐은 먼저 shiny 여부로 결정돼요. shiny 카드는 모두 다른 카드보다 훨씬 멋져요.
두 번째 기준은 공격력으로, 높을수록 좋아요.

```elm
sortByCoolness [newthree, scientuna]
    --> [Card "Scientuna" 6 True, Card "Newthree" 120 False]
```

## 5. Shiny Power

shiny는 겉치레만이 아니에요. 공격력이 비슷한 Blorkemon™️끼리 싸우면, shiny 쪽이 항상 이겨요.
이것을 Shiny Power라고 불러요.

`compareShinyPower` 함수를 구현해요. 이 함수는 이 속성을 규칙으로 담아내요.
두 카드의 공격력이 다르면 그 값으로 `Order`가 정해지고, 같으면 shiny 카드가 더 커요.

```elm
compareShinyPower newthree scientuna
    --> GT
```

## 6. 승부에 걸어 보기

Blorkemon™️ 카드 게임에서는 무슨 일이든 일어날 수 있지만, 그래도 더 강한 카드가 이기는 경향이 있어요.

`expectedWinner` 함수를 구현해요. 이 함수는 `compareShinyPower` 순서를 기준으로, 이길 가능성이 가장 높은 몬스터의 이름을 반환해요.
예상 승자의 몬스터 이름을 반환하고, 두 상대의 Shiny Power가 같으면 "too close to call"을 반환해야 해요.

```elm
expectedWinner newthree scientuna
    --> "Newthree"
```
