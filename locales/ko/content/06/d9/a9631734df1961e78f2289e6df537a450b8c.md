# 힌트

## 1. 새로운 최고 점수 딕셔너리 정의하기

- [빈 딕셔너리][empty-dictionary]는 타입 이름 뒤에 빈 괄호 한 쌍을 붙이거나, 타입을 문맥에서 알 수 있다면 빈 딕셔너리 리터럴을 사용해 초기화할 수 있어요.

## 2. 최고 점수 딕셔너리에 플레이어 추가하기

- 딕셔너리에 원소를 추가하려면 변수로 선언해야 해요.
- [딕셔너리 서브스크립트 문법][dictionary-subscripts]을 사용해 딕셔너리에 원소를 추가할 수 있어요.

## 3. 점수 딕셔너리에서 플레이어 제거하기

- 딕셔너리에서 원소를 제거하려면 변수로 선언해야 해요.
- [적절한 메서드][dictionary-docs]를 사용해 딕셔너리에서 원소를 제거할 수 있어요.

## 4. 플레이어의 점수 초기화하기

- 딕셔너리 안의 값을 변경하려면 변수로 선언해야 해요.
- [딕셔너리 서브스크립트 문법][dictionary-subscripts]을 사용해 값을 갱신할 수 있어요.

## 5. 플레이어의 점수 갱신하기

- 딕셔너리 안의 값을 변경하려면 변수로 선언해야 해요.
- [딕셔너리 서브스크립트 문법][dictionary-subscripts]을 사용해 값을 갱신할 수 있어요.

## 6. 플레이어 이름 순으로 정렬된 플레이어 목록 가져오기

- 딕셔너리 원소는 [적절한 메서드][dictionary-docs]를 사용해 정렬할 수 있어요.
- `sorted(by:)` 메서드에 전달할 `((String, Int), (String, Int)) -> Bool` 타입의 정렬 함수를 정의해야 해요.
- 정렬 함수는 왼쪽 키/값 쌍이 정렬된 결과에서 오른쪽 키/값 쌍보다 _앞에_ 와야 하면 `true`를 반환해야 해요.

## 7. 플레이어 점수를 내림차순으로 정렬한 플레이어 목록 가져오기

- 딕셔너리 원소는 [적절한 메서드][dictionary-docs]를 사용해 정렬할 수 있어요.
- `sorted(by:)` 메서드에 전달할 `((String, Int), (String, Int)) -> Bool` 타입의 정렬 함수를 정의해야 해요.
- 정렬 함수는 왼쪽 키/값 쌍이 정렬된 결과에서 오른쪽 키/값 쌍보다 _앞에_ 와야 하면 `true`를 반환해야 해요.
