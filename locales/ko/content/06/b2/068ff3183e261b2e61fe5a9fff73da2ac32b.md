# If, Elseif, Else

`if`, `elseif`, `else`를 사용하는 조건문은 프로그램 제어 흐름의 기본 요소예요.
`if`문은 표현식을 평가하고, 결과가 `true`이면 해당 코드 분기를 실행해요.

```php
<?php

if ($expression) {
    // .. executed if $expression is true
}
```

표현식이 불리언 값이 아니라면, 평가 결과는 그 값이 참으로 취급되는지 아니면 거짓으로 취급되는지를 결정해요.
PHP에서는 다음 값들이 false와 같은 것으로 취급돼요:

- 불리언 `false`
- 정수 `0`
- 실수 `0.0`과 `-0.0`
- 빈 배열 `[]`
- 빈 문자열 `""` 또는 숫자 문자열 `"0"`
- `null`

그 밖의 모든 값은 true로 취급돼요.

## 여러 조건에 대응하기

`if`문 뒤에 `elseif`와 `else`를 사용해 여러 조건을 이어 붙일 수 있어요.

```php
<?php

if ($value === 0) {
    // .. do something
} elseif ($value === 1) {
    // .. do something else
} else {
    // ,, do this if nothing else
}
```

true로 평가되는 조건문은 하나만 실행돼요.
따라서 여러 조건이 true로 평가될 수 있다면, 작성하는 순서가 중요해요.

```php
<?php

if (true) {
    // .. always do something
} elseif (true)
    // .. will never be executed
} else {
    // .. will never be executed
}
```
