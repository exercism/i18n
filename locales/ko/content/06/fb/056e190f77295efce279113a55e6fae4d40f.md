# 지침 추가

## Python 트랙에서 이 연습 문제가 구성된 방식

이 연습 문제의 테스트는 프로그램이 Garden [`class`][classes in python]로 구현되기를 기대해요 (_[concept:python/classes]()도 참고해 봐요_).
Python의 클래스가 익숙하지 않다면, 이 [Real Python 튜토리얼][how-to-make-a-class]이 좋은 추가 출발점이 될 거예요.

`class`에는 `plants`라는 [`method`][methods]를 구현해야 해요. 이 메서드는 학생의 이름을 인자로 받아, 그 학생에게 속한 식물 이름의 `list`를 반환해요.


## 생성자

예시 정원을 만들면 다음과 같아요:

```python
[window][window][window]
VRCGVVRVCGGCCGVRGCVCGCGV
VRCCCGCRRGVCGCRVVCVGCGCV
```

이 코드는 테스트에서 `Garden("VRCGVVRVCGGCCGVRGCVCGCGV\nVRCCCGCRRGVCGCRVVCVGCGCV")`로 표현돼요.

이 표현이 제대로 동작하려면, `class`에 [`__init__()`][init] [특수 메서드][special-methods]를 구현해야 해요.
`__init__()`나 [_생성자_][what-is-a-constructor]가 익숙하지 않다면, Python 문서의 [클래스와 인스턴스 객체][class vs instance objects in python]에 더 자세한 설명이 있어요.


## 기본 매개변수

일부 테스트에서는 학생 `list`가 `__init__()`에 인자로 전달돼요.
이 `list`는 문제 설명에서 제공하는 12명의 학생 명단을 덮어써야 해요.
다음 두 문 모두 `__init__()` 메서드에서 동작해야 해요:


```Python
# Make a garden based on the default 12-student roster.
Garden("VRCGVVRVCGGCCGVRGCVCGCGV\nVRCCCGCRRGVCGCRVVCVGCGCV") 

# Make a garden based on a 2-student roster.
Garden("VRCC\nVCGG", students=["Valorie", "Raven"]) 
```

한 가지 방법은 학생 `list`를 [기본 인자][default argument values]로 만드는 거예요. Python 문서에서는 [함수 정의][function definitions]를 설명하면서 `default parameters`를 자세히 다뤄요.
