# 소개

운에 따라 결과가 달라지는 게임에는 무작위성이 필요해요. Factor의 [`random`][random] 보캐뷸러리는 넘겨받은 대상에 따라 알맞게 동작하는 `random`이라는 범용 워드 하나와, 섞기와 표본 추출을 위한 도우미들, 그리고 테스트를 위해 무작위성을 *재현 가능*하게 만드는 방법을 제공해요.

## 워드에 `inline` 표시하기

이 연습 문제의 몇몇 과제에서는 *쿼테이션*(`[ … ]` 블록)을 인자로 받아 실행하는 워드를 정의해요. 여기에 Factor가 정해 둔 확고한 규칙이 하나 있는데, 바로 **인자로 받은 쿼테이션을 `call`하는 워드는 반드시 `inline`으로 선언해야 한다**는 것이에요. 방법은 닫는 `;` 바로 뒤에 `inline`을 붙여 쓰는 거예요.

`inline`은 컴파일러에게 워드의 본문을 한 번 따로 컴파일하는 대신 각 호출 지점에 그대로 끼워 넣으라고 알려줘요.

- 호출자의 쿼테이션이 그대로 이어져 들어가기 때문에, **쿼테이션이 스택에 남긴 값은 무엇이든 호출자에게 그대로 흘러 돌아가요**. 워드 자체의 스택 효과에는 출력이 하나도 선언되어 있지 않은데도 말이에요.

다음은 `10`을 푸시한 다음 넘겨받은 쿼테이션을 실행하는 작은 워드예요:

```factor
USING: kernel math prettyprint ;

: with-ten ( quot -- ) 10 swap call ; inline
```

이 워드의 스택 효과는 `( quot -- )`인데, 출력을 하나도 선언하지 않아요. 그런데도 효과가 *서로 다른* 두 쿼테이션을 넘겨 호출하면 서로 다른 결과가 나오고, 그 결과는 모두 호출자에게 흘러 돌아와요:

```factor
[ 1 + ] with-ten .        ! => 11   (quotation ( n -- n ): one value back)
[ dup 2 * ] with-ten . .  ! => 20
                          ! => 10   (quotation ( n -- n n ): two values back)
```

## `random`: 원소 하나

[`random`][random]에 있는 `random`은 인자에 따라 동작이 달라지는 범용 워드예요:

```
random ( obj -- elt )
```

- **정수** `n`을 주면 `[0, n)` 범위의 무작위 정수를 반환해요:

```factor
USING: random ;

6 random .    ! 4   (a value from 0 to 5)
```

- **시퀀스**를 주면 무작위 원소를 하나 반환해요:

```factor
{ "rock" "paper" "scissors" } random .    ! "paper"
```

보통 주사위를 굴리려면 범위를 하나 위로 옮기면 돼요. `6`에 대한 `random`은 0부터 5까지를 주니까, `6 random 1 +`는 1부터 6까지를 줘요.

## 여러 값 뽑기

정해진 개수만큼 무작위로 값을 뽑아 모으려면 [`sequences`][sequences]에 있는 `replicate`로 쿼테이션을 반복해요:

```
replicate ( n quot -- seq )
```

```factor
USING: random sequences ;

3 [ 6 random 1 + ] replicate .    ! { 4 1 6 }   (three dice)
```

## `randomize`: 제자리에서 섞기

[`random`][random]에 있는 `randomize`는 원소들을 무작위 순서로 배열한 시퀀스를 반환해요:

```
randomize ( seq -- randomized )
```

```factor
{ 1 2 3 4 5 } randomize .    ! { 3 1 5 2 4 }
```

**제자리에서** 섞고 같은 시퀀스를 반환하니, 원래 순서를 유지해야 한다면 먼저 `clone`을 해요.

## `sample`: 서로 다른 원소 여러 개

[`random`][random]에 있는 `sample`은 시퀀스에서 *서로 다른* 원소를 `n`개 뽑아요. 카드를 나눠 줄 때처럼 같은 카드가 두 번 나오지 않아요:

```
sample ( seq n -- seq' )
```

```factor
{ 10 20 30 40 50 } 3 sample .    ! { 40 10 30 }
```

시퀀스에 들어 있는 것보다 많은 원소를 요청하면 오류가 발생해요.

## 재현 가능한 무작위성

기본적으로 `random`은 시스템 시계로 시드를 정한 전역 생성기에서 값을 뽑기 때문에 실행할 때마다 결과가 달라져요. 테스트를 위해서든, *다시 실행해 볼 수 있는* 게임을 원할 때든, 고정된 **시드**를 가진 생성기를 묶어서 사용해요.

[`random.mersenne-twister`][mt]에 있는 `<mersenne-twister>`는 정수 시드로 생성기를 만들고, [`random`][random]에 있는 `with-random`은 그 생성기를 설치한 상태로 쿼테이션을 실행해요:

```
<mersenne-twister> ( seed -- rnd )
with-random        ( rnd quot -- )
```

```factor
USING: random random.mersenne-twister ;

42 <mersenne-twister> [ 6 random 1 + ] with-random .
! always the same value for seed 42
```

쿼테이션 안의 모든 것, 즉 `random`, `randomize`, `sample`은 시드를 지정한 생성기에서 값을 뽑아요. 그래서 같은 시드는 언제나 같은 결과를 재현해요.

쿼테이션을 인자로 받아 `with-random`으로 실행하는 워드는 [워드에 `inline` 표시하기](#marking-a-word-inline)의 규칙이 적용돼요. `with-random`이 결국 그 쿼테이션을 `call`하기 때문에, 그런 래퍼도 `inline`으로 표시해야 해요.
