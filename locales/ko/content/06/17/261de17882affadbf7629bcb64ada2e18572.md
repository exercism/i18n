# 소개

Swift에서 `String`은 사람이 읽을 수 있는 텍스트를 나타내는 `Character` 값들의 순서 있는 컬렉션이에요. Swift 문자열은 유니코드 문자와 이모지를 완벽하게 지원해요.

문자열 리터럴을 사용해 문자열을 만들어요. 텍스트를 큰따옴표(`"`)로 감싸면 돼요.
특수 문자는 이스케이프 시퀀스를 사용해요. 예를 들어 `\n`은 줄바꿈을 나타내고, `\"`는 문자열 리터럴 안에서 이스케이프된 큰따옴표를 나타내요.

빈 문자열은 사이에 아무 내용도 없는 큰따옴표 한 쌍(`""`)으로 써요.

```swift
let hello = "Hello, World!"
let sausage = "Weißwurst is a tasty sausage."
var family = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶"
var empty = ""
```
