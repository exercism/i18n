# 소개

조건식은 조건이 **true**인지 **false**인지에 따라 코드를 실행할 때 사용해요. 이런 식은 다음과 같이 작성해요:

```haxe
if (condition) {
  expressions
};
```

조건의 결과는 `Bool` 타입이라서, 결과가 `true`일 때 식이 실행돼요.

조건이 실제로 `false`일 때는 다른 코드를 실행하고 싶을 때도 있어요. 바로 이때 `else` 식이 필요해요. `else`는 처음 조건이 `false`일 때 식을 실행해요. 그런데 여러 경우를 확인하고 싶다면 어떻게 할까요? 그럴 때는 `else if (condition)` 식을 사용해요. 다음은 전체 예제예요:

```haxe
var a = 10;

if (a == 2) {
  trace("a is 2");
} else if (a == 5) {
  trace("a is 5");
} else {
  trace("a is 10");
}

// a is 10
```
