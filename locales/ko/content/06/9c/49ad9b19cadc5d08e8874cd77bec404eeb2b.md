# 테스트

자신의 SAP 시스템에서 연습 문제를 구현할 수 있어요. 다음 단계를 따라 해봐요:

1. 시스템의 모든 Exercism 연습 문제를 위한 SAP 패키지를 만들어요 (권장 이름: `$EXERCISM`)
2. 각 연습 문제를 위한 SAP 패키지를 하위 패키지로 만들어요 (권장 이름: `$EXERCISM_<name-of-exercise>`, 예: `$EXERCISM_HELLO-WORLD`)
3. 연습 문제에 해당하는 ABAP 클래스를 만들어요 (예: `ZCL_HELLO_WORLD`)
4. Exercism에서 템플릿 코드를 복사해 클래스에 넣어요
5. 테스트 클래스를 유지보수하고, Exercism의 코드를 테스트 클래스에 복사해요

이제 클래스 구현을 마치고 단위 테스트를 실행해서 작성한 풀이가 제대로 동작하는지 확인할 수 있어요.

참고: 이렇게 패키지를 구성하면 `$EXERCISM` 패키지의 저장소를 만들어 [abapGit](https://abapgit.org)으로 모든 작업을 백업할 수 있어요.

자세한 내용은 [Exercism ABAP 문서](https://exercism.org/docs/tracks/abap)를 참고해요.
