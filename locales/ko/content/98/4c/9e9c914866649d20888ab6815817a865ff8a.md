# 로드맵

이 문서는 기여자와 유지보수자가 앞으로 몇 달 동안 중점적으로 다룰 가능성이 높은 주요 주제를 개괄해요.

## 주제 개요

- 기존 개념 연습 문제를 개선해요
- 개념 연습 문제를 더 만들어요 (아래 실러버스 개요를 참고해요)
- 모든 실습 연습 문제에 `prerequisites`와 `practices` 목록을 정의해요 ([이슈 1396](https://github.com/exercism/go/issues/1396) 참고)
- 남아 있는 [테스트 러너](https://github.com/exercism/go-test-runner/) Bug를 수정해요
- [분석기](https://github.com/exercism/go-analyzer/)를 수정하고 다시 활성화하며(예: [이슈 16](https://github.com/exercism/go-analyzer/issues/16) 참고), 그 밖의 Bug도 수정해요
- [리프리젠터](https://github.com/exercism/go-representer/)를 안정적인 버전으로 잘 완성해 실제로 운영에 올려요
- 연습 문제의 접근법을 개선하거나 추가해요
- 테스트를 [문제 명세](https://github.com/exercism/problem-specifications)와 동기화해요

## 실러버스 개요

### 이미 있는 개념

- `basics`
- `strings`와 `strings-package`
- `numbers`(기초)와 `arithmetic-operators`
- `floating-point-numbers`
- `booleans`
- `comments`
- `conditionals-if`와 `comparison`
- `conditionals-switch`
- `structs`
- `type-definitions`
- `slices`
- `iteration` (`for`문)
- `functions` (반환 값이 여러 개인 경우 포함)
- `maps`
- `range-iteration`
- `runes`
- `pointers`
- `methods`
- `interfaces`
- `errors`
- `zero-values` (nil 포함)
- `type-conversion`
- `type-assertion`
- `constants`
- `string-formatting`
- `packages` (import/export)
- `time`
- `variadic-functions` (`...`를 처음 소개해요)
- `randomness`
- `regular-expressions`
- `stringers`

### 앞으로 추가할 가능성이 있는 개념

- `time-duration`
- `integer-types`
- `panic-recover`
- `error-wrapping` (errors.Is, errors.As)
- `bytes`
- `bitwise-operators`
- `goroutines`
- `waitgroups`
- `mutexes`
- `channels`와 `select`
- `closures`/`anonymous-functions`/`higher-order-functions`
- `JSON`
- `defer`
- `Buffer`, `io.Reader`/`io.Writer`
- `typed-parameters` (제네릭)
- `context`
- 시간 관련 도우미 (ticket, sleep 등)
- `reflection`
- `unsafe`
- `init`
- 함수형 옵션 패턴
- 파일 임베딩

개념 연습 문제의 범위를 벗어날 수도 있는 추가 주제는 다음과 같아요:

- 도구 활용 (go fmt, go vet, go doc 등)
- 테스트와 예제 작성하기
- 벤치마킹
- 프로파일링
- go generate
- 컴파일러 옵션
