# 소개

해시는 Perl의 데이터 타입으로, 문자열 키와 스칼라 값이 짝을 이루는, 순서가 없는 모음을 담아요.

해시 변수는 보통 배열을 대입해서 채워요. 예를 들어 `my %scores = (Alice => 10, Bob => 15, Charlie => 20);` 처럼요.

배열의 요소는 보통 쉼표로 구분하지만, 배열에서 키와 값을 구분할 때는 흔히 "팻 콤마"라고 알려진 `=>`를 쓰는 걸 자주 보게 돼요.
동작은 쉼표와 거의 같지만, 왼쪽에 있는 원소를 문자열로 해석해 준다는 장점이 있어요.

해시는 개별 키에 값을 대입해서 채울 수도 있어요. 예를 들어 `$scores{Alice} = 10;` 처럼요.

해시의 값은 첨자로 키를 지정해 가져올 수 있어요. 예를 들어 `$scores{Bob} # 15` 처럼요.

해시의 키는 중복될 수 없어요.
같은 키가 여러 번 주어지면 마지막으로 준 값만 남아요.

## 함수

해시를 다루는 함수로는 [keys][keys]와 [values][values]가 있어요. 각각 해시의 해당 부분을 배열로 가져와요.
[keys][keys]와 [values][values] 함수가 반환하는 배열은 [grep][grep], [map][map], [sort][sort] 같은 배열 함수나 [for][for] 루프에 유용하게 쓸 수 있어요.

그 밖의 해시 함수로는 키가 해시에 있는지 확인하는 [exists][exists] (값이 `undef`여도 마찬가지예요)와 해시에서 키를 제거하는 [delete][delete]가 있어요.

## 시길의 차이

해시의 값을 가져올 때는 사용한 시길에 따라 결과가 달라져요.
변수 이름 끝에 붙는 첨자 `{}`가 Perl에게 그 이름의 해시에 접근하고 있다는 걸 알려줘요.

```perl
my %names = (Alice => 10, Bob => 15, Charlie => 20);

$names{Alice}; # 10            <- A scalar
@names{Alice}; # (10)          <- A slice (with only one key, this probably isn't what you want. There will be a warning.)
%names{Alice}; # ('Alice', 10) <- A key/index + value slice

$names{'Bob', 'Charlie'}; #                            <- An error (disabled syntax for an ancient feature.)
@names{'Bob', 'Charlie'}; # (15, 20)                   <- A slice
%names{'Bob', 'Charlie'}; # ('Bob', 15, 'Charlie', 20) <- A key/index + value slice
```

가능하기는 하지만, 가독성을 위해 서로 다른 변수 타입이 같은 이름을 공유하지 않는 게 좋아요.
