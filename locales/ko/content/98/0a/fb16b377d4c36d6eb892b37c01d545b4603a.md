# 힌트

## 일반

- [Elm Guide][elm-guide]를 확인해 봐요. 비슷한 주제를 다룬 좋은 예제가 잘 나와 있어요.

## 1. 애플리케이션의 Model과 Msg 타입을 정의하고 init 함수를 작성하기

- `Model`은 애플리케이션의 상태, 즉 애플리케이션에 필요한 모든 데이터를 담아요.
- [레코드][record]여야 해요.
- 이 애플리케이션에는 텍스트 상자의 텍스트를 저장할 `String` 하나만 있으면 돼요. (테스트에서는 이름이 `content`이기를 요구해요.)

- `Msg` 타입은 모델에 특정 변경을 일으키기 위해 `update` 함수에 전달되는 메시지를 정의해요.
- [커스텀 타입][custom-type]이어야 해요.
- 이 애플리케이션에는 모델에 대한 변경이 하나만 필요해요. 텍스트 상자의 텍스트가 바뀔 때 모델을 갱신하는 것이죠.

- `init` 함수는 그냥 알맞은 기본값을 가진 `Model`을 반환하면 돼요. (테스트에서는 빈 문자열을 요구해요.)

## 2. update 함수 작성하기

- 쓸모 있는 애플리케이션이라면 update 함수에서 `case`문으로 `Msg` 매개변수를 패턴 매칭해요.
- `case`문의 각 분기에서는 `Msg` 매개변수에서 필요한 정보를 꺼내고, 갱신된 `Model`을 반환해요.
- `Model`은 레코드여야 하고, 보통 [레코드 업데이트 문법][record-update-syntax]을 사용해요.

## 3. view 함수 작성하기

- `view` 함수는 루트 요소로 `div`를 반환해야 해요.
- 첫 번째 자식은 `input`이어야 하고, 현재 텍스트를 위한 `value` 속성과 `Msg`의 알맞은 변형을 담은 `onInput` 속성/이벤트를 가져야 해요.
- 두 번째 자식은 또 다른 `div`여야 하고, 그 안에 텍스트가 회문인지 아닌지를 알려 주는 `text` 자식을 둬요.

## 4. main 함수 작성하기

- main 함수는 그냥 [`Browser.sandbox`][browser-sandbox]를 호출하면 돼요.
- `Browser.sandbox`는 `init`, `update`, `view` 함수를 담은 [레코드][record] 인자를 필요로 해요.
