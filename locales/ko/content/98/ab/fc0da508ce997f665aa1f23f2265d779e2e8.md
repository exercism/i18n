# 지침 추가

## Except

`guess` 함수의 반환값은 `Except String Result` 타입이에요.

[`Except ε α`][except]는 `ε` 타입의 오류가 발생하거나 `α` 타입의 성공적인 값을 만들어 낼 수 있는 계산을 나타내요.
모나드이기 때문에 이런 계산들을 조합할 수 있어요.

## 반응형 프로그래밍

실용적인 이유로, 이 연습 문제는 반응형 프로그래밍 방식을 요구하지 않아요.
대신 [유한 상태 기계][finite-state-machine]를 구현해 보는 것을 고려해 봐요.
