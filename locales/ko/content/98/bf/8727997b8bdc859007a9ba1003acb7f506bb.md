# 지침

이 연습 문제에서는 차량을 구매할 준비를 돕는 코드를 작성해요.

과제는 세 가지예요. 운전면허가 필요한지 확인하는 과제, 두 차량 중에서 하나를 고르는 과제, 그리고 중고 차량의 적정 가격을 추정하는 과제예요.

## 1. 운전면허가 필요한지 확인하기

차량의 종류에 따라 운전면허가 있어야 운전할 수 있는 경우가 있어요.
`"car"`와 `"truck"` 종류만 면허가 필요하고, 나머지는 면허 없이 운전할 수 있다고 가정해요.

`needsLicense(kind)` 함수를 구현해요. 이 함수는 차량의 종류를 인자로 받아, 그 종류의 차량에 면허가 필요한지 나타내는 불리언 값을 반환해요.

```kotlin
needsLicense("car")
// => true

needsLicense("bike")
// => false

needsLicense("truck")
// => true
```

## 2. 구매할 두 후보 차량 중에서 고르기

구매할 수 있는 차량들을 하나씩 따져 봐요.
선택지를 두 개로 좁혔지만 최종 결정을 내리는 데 도움이 필요해요.
그래서 `chooseVehicle(option1, option2)` 함수를 구현해요. 이 함수는 두 차량을 인자로 받아, [사전순][lexicographical-order]으로 앞서는 차량을 포함한 결정을 반환해요.

```kotlin
chooseVehicle("Wuling Hongguang", "Toyota Corolla")
// => "Toyota Corolla is clearly the better choice."

chooseVehicle("Volkswagen Beetle", "Volkswagen Golf")
// => "Volkswagen Beetle is clearly the better choice."
```

## 3. 중고 차량의 가격 추정치 계산하기

이제 결정을 내렸으니, 딜러십에서 적정한 가격에 사는지 확인하고 싶어요.
중고 차량을 사려고 하니 가격은 차량의 연식에 따라 달라져요.
대략적으로 추정해 보면, 차량이 3년 미만이면 새 차였을 때의 원래 가격에서 80%라고 가정해요.
10년 이상이면 50%예요.
차량이 3년 이상 10년 미만이면 원래 가격의 70%예요.

`if`, `else if`, `else`를 사용해 이 로직을 적용하는 `calculateResellPrice(originalPrice, age)` 함수를 구현해요. (연습하고 싶다면 다른 방법도 있어요.)
이 함수는 원래 가격과 차량의 연식을 인자로 받아, 딜러십에서의 예상 가격을 반환해요.

```kotlin
calculateResellPrice(1000, 1)
// => 800

calculateResellPrice(1000, 5)
// => 700

calculateResellPrice(1000, 15)
// => 500
```

[lexicographical-order]: https://en.wikipedia.org/wiki/Lexicographic_order
