# `while`문과 `until`문

루프는 주어진 조건에 따라 코드를 반복해서 실행할 수 있게 해 주는 제어 구조예요.

## `while`문

`while`문은 주어진 조건에 따라 코드를 반복해서 실행할 수 있게 해 주는 제어 구조예요.
`while`문 안의 코드는 조건이 참으로 평가되는 동안 계속 실행돼요.
`while`문은 반복 횟수를 미리 알 수 없을 때 자주 사용하지만, 루프가 필요한 어떤 상황에서도 사용할 수 있어요.

조건은 루프 안의 코드가 실행되기 전에 평가돼요. 즉, 조건이 거짓이면 루프 안의 코드는 한 번도 실행되지 않아요.

```crystal
i = 0
while i < 3
  puts i
  i += 1
end

# Output:
# 0
# 1
# 2
```

문자열을 순회하고 싶을 때는 문자열의 길이만큼 루프를 돌릴 수 있어요.

```crystal
str = "Hello"
i = 0
while i < str.size
  puts str[i]
  i += 1
end

# Output:
# H
# e
# l
# l
# o
```

## `until`문

`until`문은 `while`문과 똑같이 동작해요. 다만 루프 안의 코드가 조건이 참으로 평가될 때까지 계속 실행된다는 점이 달라요.
`if`와 `unless`의 차이와 같아요.

```crystal
i = 0
until i == 3
  puts i
  i += 1
end
```

### 무한 루프

`while`문에서 흔한 실수는 절대 끝나지 않는 "무한 루프"에 빠지는 거예요.
무한 루프는 조건이 _결코_ 참이나 거짓으로 평가되지 않을 때 생길 수 있어요.
이런 경우는 대개 프로그래머의 실수 때문이에요. 예를 들어 루프 변수를 증가시키는 걸 잊는 경우죠.
하지만 때로는 무한 루프가 프로그램의 로직을 구현하는 가장 명확한 방법이에요.
또는 영원히 반복하는 것이 꼭 필요할 수도 있어요. 예를 들어 HTTP 서버는 들어오는 연결을 기다리고, 연결을 처리한 다음, 다음 연결을 기다려요.

## `break`

`break` 키워드를 사용하면 루프를 일찍 빠져나갈 수 있어요.
특정 조건에서 루프를 일찍 종료하고 싶을 때 편리해요.

```crystal
i = 0
while i <= 3
  puts i
  i += 1
  if i == 2
    break
  end
end

# Output:
# 0
# 1
```

## `next`

`next` 키워드를 사용하면 루프의 다음 반복으로 건너뛸 수 있어요.
루프의 특정 반복을 건너뛰고 싶을 때 편리해요.

```crystal
i = 0
while i <= 3
  i += 1
  if i == 2
    next
  end
  puts i
end

# Output:
# 1
# 3
```

## 반복 중의 타입

반복 중에는 변수의 타입이 달라질 수 있어요.
다음 예제에서 `a`의 타입은 `Int32 | String`이에요. 루프의 첫 부분에서는 `Int32`일 수도 있고 `String`일 수도 있기 때문이죠.
변수 `a`는 루프의 첫 부분에서만 `Int32 | String` 타입을 가져요. 루프가 시작될 때는 `Int32`를 가지고 있고, 두 번째 반복에서는 `String`을 가지니까요.
이렇게 여러 타입을 다루는 시스템은 나중에 자세히 설명할게요.
하지만 루프의 두 번째 부분에서는 `String`만 가진다는 것이 확실하기 때문에, 루프의 두 번째 부분에서 `a`의 타입은 `String`이에요.
런타임에는 `Int32`와 `String`을 동시에 가질 수 없어요.

```crystal
i = 0
a = 4
while i < 3
  p typeof(a)
  # => Int32 | String
  a = "4"
  p typeof(a)
  # => String
  i += 1
end
```
