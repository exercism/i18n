# 지침 추가

## 단어

`custom-set` 튜플을 정의하고, `INSTANCE: custom-set set`으로 `set` 믹스인의 인스턴스라고 선언해요.

- `<custom-set> ( -- set )`, 빈 집합을 만들어요.
- `>custom-set ( seq -- set )`, 시퀀스에서 집합을 만들어요. 중복된 항목은 조용히 버려요.

그다음 `custom-set`을 위해 `members`, `in?`, `adjoin`, `set-like`에 `sets`의 `M:` 메서드를 제공해요. `INSTANCE:` 선언과 이 네 가지 메서드가 준비되면, `sets` 어휘의 `null?`, `union`, `intersect`, `diff`, `subset?`, `set=`, `intersects?`가 모두 프로토콜의 기본 구현을 통해 여러분의 집합에서 그대로 동작해요. 테스트도 바로 이 단어들을 직접 호출해요.

`adjoin ( elt set -- )`은 집합 자체를 변경해요. `elt`가 `set`에 아직 없으면 제자리에서 `set`에 추가해요.
