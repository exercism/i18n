# 지시 사항

이 연습 문제에서는 2012년 9월 15일에 문을 연 뉴욕의 한 미용실을 위한 예약 스케줄러를 만들어 봐요.

## 1. 예약 날짜 파싱하기

예약 날짜를 나타내는 텍스트를 그에 해당하는 `LocalDateTime`으로 파싱하도록 `AppointmentScheduler.schedule()` 메서드를 구현해요.

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.schedule("7/25/2019 13:45:00");
// => LocalDateTime.of(2019, 7, 25, 13, 45, 0)
```

## 2. 예약이 이미 지났는지 확인하기

예약 날짜를 받아서 그 예약이 과거에 있었는지 확인하는 `AppointmentScheduler.hasPassed()` 메서드를 구현해요.

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.hasPassed(LocalDateTime.of(1999, 12, 31, 9, 0, 0));
// => true
```

## 3. 예약이 오후인지 확인하기

예약 날짜를 받아서 그 예약이 오후(12:00 이상, 18:00 미만)인지 확인하는 `AppointmentScheduler.isAfternoonAppointment()` 메서드를 구현해요.

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.isAfternoonAppointment(LocalDateTime.of(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. 예약의 시간과 날짜 설명하기

예약 날짜를 받아서 그 날짜와 시간에 대한 설명을 반환하는 `AppointmentScheduler.getDescription()` 메서드를 구현해요.

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.getDescription(LocalDateTime.of(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on Friday, March 29, 2019, at 3:00 PM."
```

## 5. 기념일 날짜 반환하기

9월 15일인 올해의 기념일 날짜를 반환하는 `AppointmentScheduler.getAnniversaryDate()` 메서드를 구현해요.

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.getAnniversaryDate()
// => LocalDate.of(<current year>, 9, 15)
```
