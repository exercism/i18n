# 지침

Turndit Inc.는 레코드의 트랙 사이를 건너뛸 수 있는 새로운 턴테이블을 만들고 있어요. 그게 왜 좋은 일인지는 아무도 모르지만, 어쨌든 하겠다고 우기니 그냥 하게 두기로 해요. 지금 이 회사는 원할 때 바늘을 레코드의 올바른 위치로 보내는 방법을 알아내는 데 도움이 필요해요.

이 설정에는 두 부분이 있어요.

바늘은 턴테이블 위에 매달려 있고 레코드 위를 좌우 및 앞뒤로 움직일 수 있어요 (인형 뽑기 기계를 떠올려 봐요!).
바늘을 제어하는 기계 장치가 선형으로 움직이기 때문에, 레코드의 중심을 원점으로 하는 좌표 쌍 `(x, y)`로 위치를 추적해요.

또한 바늘이 어디에 있는지, 그리고 이전 곡이나 다음 곡이 어디에서 시작하는지를 추적하는 광학 장치가 있어요.
레코드가 회전하고 있기 때문에, 두 지점 사이의 반지름 방향 차이와 각도 차이를 `(r, θ)`로 추적하는 편이 더 쉬워요. 여기서도 원점은 레코드의 중심이에요.

Turndit은 다른 트랙을 선택했을 때 바늘이 이동할 새로운 `(x', y')` 좌표를 찾는 방법을 알아야 해요.

~~~~exercism/note
이 연산들은 삼각 함수나 회전 행렬로 처리할 수도 있지만, 회전과 반지름 방향 이동에 복소수를 사용하면 더 간단하게 (그리고 더 재미있게!) 처리할 수 있어요. 장담해요!
사실 원한다면, 이 연습 문제의 각 함수는 복소수와 Julia의 내장 메서드/기능을 사용해 대입 형식, 즉 한 줄로 작성할 수 있어요.
~~~~

## 1. 직교 좌표로 복소수 만들기

복소평면의 `x` 좌표와 `y` 좌표를 받아 그에 해당하는 복소수를 반환하는 `z(x, y)` 함수를 구현해요.

```julia-repl
julia> z(1, 1)
1.0 + 1.0im

julia> z(4.5, -7.3)
4.5 - 7.3im
```

## 2. 극좌표로 복소수 만들기

반지름 좌표 `r`, 각도 `θ`(라디안)를 받아 직교 형식의 해당 복소수를 반환하는 `euler(r, θ)` 함수를 구현해요.

```julia-repl
julia> euler(1, π)
-1.0 + 0.0im

julia> euler(3, π/2)
0.0 + 3.0im

julia> euler(2, -π/4)
1.4142135623730951 - 1.414213562373095im  # √2 - √2im
```

## 3. 2D 벡터 회전 수행하기

`x` 좌표, `y` 좌표, 각도 변위 `θ`(라디안)를 받는 `rotate(x, y, θ)` 함수를 구현해요.
이 함수는 원점을 기준으로 점을 주어진 각도 `θ`만큼 회전시키고, 새로운 좌표를 튜플 `(x', y')`로 반환해야 해요.

```julia-repl
julia> rotate(0, 1, π)
(0, -1)

julia> rotate(1, 1, -π/2)
(1, -1)
```
## 4. 반지름 방향 이동 수행하기

`x` 좌표, `y` 좌표, 반지름 방향 변위 `r`을 받는 `rdisplace(x, y, r)` 함수를 구현해요.
이 함수는 x-y 좌표를 반지름을 따라 `r`만큼 이동시키고, 새로운 좌표를 튜플 `(x', y')`로 반환해야 해요.

```julia-repl
julia> rdisplace(0, 1, 1)
(0, 2)

julia> rdisplace(1, 1, √2)
(2, 2)
```
## 5. 원하는 곡 찾기

바늘의 `x`, `y` 좌표와, 바늘에서 원하는 곡의 시작 지점 사이의 변위 `r`, `θ`를 받는 `findsong(x, y, r, θ)` 함수를 구현해요. 바늘의 새로운 좌표를 튜플 `(x', y')`로 반환해야 해요.

```julia-repl
julia> findsong(0, 1, 3, -π/2)
(4, 0)

julia> findsong(√2, √2, 0, 3π/4)
(-2, 0)
```
