# 힌트

## 일반

- `USING:` 줄에 `math.functions`와 `math.constants`를 추가해요.
  3번 문제에는 `math.libm`도 필요해요.
- 테스트는 아주 작은 오차를 허용하니까, 곱하고 나누는 순서는 상관없어요.

## 1. 경계까지 두르는 로프

- 세 가지 값을 곱하는데, 그중 하나가 `pi`예요.

## 2. 피치에서 얼마나 멀리 있을까?

- `[ sq ] bi@`는 스택 맨 위의 두 수를 각각 제곱해요.
- 제곱한 값들을 더한 다음, `sqrt`를 호출해요.

## 3. 어느 쪽으로 갔을까?

- `fatan2`는 가로 방향 거리 `y`를 지면을 따라간 거리 `x` *아래*에 받아요.
  값이 들어오는 순서와는 반대예요. 먼저 `swap`으로 두 값을 바꿔요.
- 결과는 라디안으로 나와요. `rad>deg`로 도 단위로 바꿔요.

## 4. 얼마나 멀리 날아갔을까?

- `sin`은 라디안을 원하는데 `angle`은 도 단위예요. 먼저 `deg>rad`로
  변환한 다음, 두 배로 만들어요.
- `bi*`는 하나의 인용을 `speed`에, 다른 인용을 `angle`에 적용해요:
  `[ sq ] [ ... ] bi*`.

## 5. 잔디 위에서 느려지기

- *e*의 거듭제곱은 `e^`이고, 지수에 대해 호출해요. 먼저
  `-0.02 * metres`를 계산해요.

## 6. 언제부터 쫓을 가치가 없어질까?

- ln은 `log`예요. `speed / target`에 대해 호출한 다음, `0.02`로 나눠요.
