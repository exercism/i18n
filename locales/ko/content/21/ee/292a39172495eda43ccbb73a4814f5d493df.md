# 지시 사항

모험을 좋아하는 연금술사 Astrid는 여러 세계에서 수집한 마법 측정 단위를 표준화하려고 해요.
어떤 세계에서는 음수가 될 수 있는 부호 있는 측정값을 사용하고, 다른 세계에서는 항상 양수인 부호 없는 측정값을 사용해요.
게다가 Astrid는 특정 희귀 재료를 위한 두 가지 사용자 정의 타입을 가지고 있는데, 이 타입들 사이를 쉽게 변환할 방법이 필요해요.

이번 임무는 Astrid가 부호 있는 정수와 부호 없는 정수를 서로 변환하도록 돕고, Cairo의 `Into`와 `TryInto` 트레이트를 사용해 특별한 재료 타입을 위한 사용자 정의 타입 변환을 만드는 거예요.

## 1. 부호 있는 마법 단위와 부호 없는 마법 단위 사이 변환

Astrid가 가진 측정값은 때때로 양수나 음수 값(부호 있는 정수)으로 나타나지만, 특정 작업에서는 값이 항상 양수(부호 없는 정수)가 되도록 해야 해요.

다음을 변환하는 함수를 작성해서 Astrid를 도와주세요:

1. 부호 있는 정수(`i32`)를 부호 없는 정수(`u16`)로.
2. 부호 없는 정수(`u16`)를 부호 있는 정수(`i32`)로.

```rust
let signed_value: i32 = -42;
match convert_signed_to_unsigned(signed_value) {
    Option::Some(v) => println!("Converted to unsigned: {}", v),
    Option::None => println!("Failed to convert: {}", signed_value),
} // prints "Failed to convert: -42"

let unsigned_value: u16 = 42;
let signed_value: i32 = convert_unsigned_to_signed(unsigned_value);
println!("Converted to signed: {}", signed_value); // prints "Converted to signed: 42"
```

## 2. 사용자 정의 재료 타입 변환

Astrid는 두 가지 희귀 재료인 **Essence**와 **Elixir**를 다루는데, 이들은 사용자 정의 타입으로 표현돼요.
**Essence**를 **Elixir**로 변환하고 싶지만, 그 반대 방향은 원하지 않아요.

`Essence`와 `Elixir`라는 두 가지 사용자 정의 타입을 만들고, `Essence`에서 `Elixir`로 변환하는 `Into` 트레이트를 구현해서 Astrid를 도와주세요.

`Essence`를 받아 `.into()`를 사용해 `Elixir`로 변환하는 함수를 작성해요.

```rust
#[derive(Drop)]
struct Essence {
    potency: u16,
}

#[derive(Drop)]
struct Elixir {
    strength: u16,
}

fn convert_essence_to_elixir(essence: Essence) -> Elixir {
    // Convert the Essence to Elixir using the Into trait.
    essence.into()
}

fn main() {
    let essence = Essence { potency: 100 };
    let elixir: Elixir = convert_essence_to_elixir(essence);
    println!("Elixir strength: {}", elixir.strength); // Elixir strength: 100
}
```
