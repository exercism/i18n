# 지침

다시 주방으로 돌아왔어요. 이번에는 [Leah's Luscious Lasagna][lasagna]의 라자냐 레시피를 한층 더 다듬어 볼 거예요. 여기 있는 과제들은 여러 입력을 한꺼번에 다뤄야 하는데, 바로 그럴 때 *로컬*, 즉 Factor의 이름 있는 바인딩이 제 역할을 톡톡히 해요.

## 1. 요리 상태 확인하기

`cooking-status`는 스택에서 타이머 값을 하나 꺼내 상태 문자열을 반환하도록 정의해요.

- `0` → `"Lasagna is done."`
- `f` (타이머를 설정하지 않은 경우) → `"You forgot to set the timer."`
- 그 밖의 숫자 → `"Not done, please wait."`

```factor
12 cooking-status .   ! => "Not done, please wait."
0 cooking-status .    ! => "Lasagna is done."
f cooking-status .    ! => "You forgot to set the timer."
```

## 2. 준비 시간 예측하기

`preparation-time`은 층 이름이 담긴 배열과 층당 평균 분 수를 받아 총 준비 시간을 반환하도록 정의해요.

```factor
{ "sauce" "noodles" "sauce" "meat" "mozzarella" "noodles" } 3 preparation-time .
! => 18
```

## 3. 필요한 면과 소스의 양 계산하기

`quantities`는 층 이름이 담긴 배열을 받아 *두* 개의 값을 반환하도록 정의해요. 필요한 면의 양(면 층 하나당 50g)과 필요한 소스의 양(소스 층 하나당 `1/5`리터)이에요.

```factor
{ "sauce" "noodles" "sauce" "meat" "mozzarella" "noodles" } quantities .s
! => 100
! => 2/5
```

## 4. 비밀 재료 추가하기

친구가 재료 목록을 보내왔는데, *마지막* 항목이 바로 친구의 비밀 재료예요. `add-secret-ingredient`는 친구의 목록과 내 목록을 받아, 비밀 재료를 뒤에 붙인 내 목록을 반환하도록 정의해요.

```factor
{ "noodles" "sauce" "mozzarella" "kampot pepper" }
{ "noodles" "meat" "sauce" "mozzarella" }
add-secret-ingredient .
! => { "noodles" "meat" "sauce" "mozzarella" "kampot pepper" }
```

## 5. 레시피 조정하기

요리책 레시피는 두 인분이 나와요. `scale-recipe`는 레시피(재료 이름에서 양으로 가는 해시테이블)와 목표 인분 수를 받아, 그에 맞게 조정된 새 레시피를 반환하도록 정의해요.

```factor
H{ { "noodles" 200 } { "sauce" 1/2 } { "mozzarella" 1 } { "meat" 100 } }
4 scale-recipe .
! => H{ { "noodles" 400 } { "sauce" 1 } { "mozzarella" 2 } { "meat" 200 } }
```
