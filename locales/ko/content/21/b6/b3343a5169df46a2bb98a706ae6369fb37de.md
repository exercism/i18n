예비 마술사 Elyse는 기본기를 연습해야 해요.
Elyse에게는 다루고 싶은 카드 덱이 있어요.

조금 더 쉽게 하기 위해 Elyse는 1부터 10까지의 카드만 사용해요.

## 1. 덱에서 카드 한 장 가져오기

주어진 덱에서 `idx` 위치에 있는 카드를 반환해요.

```julia-repl
julia> idx = 2;

julia> card([1, 3, 4, 1], idx)
3
```

## 2. 덱의 카드 한 장 교환하기

`idx` 위치에 있는 카드를 주어진 새 카드와 교환하고, 바뀐 덱을 반환해요.
이 함수는 입력 벡터를 직접 변경한다는 점에 유의해요. 원본이 바뀌어도 괜찮아요.

```julia-repl
julia> idx = 2; new_card = 6;

julia> replace_card!([1, 3, 4, 1], idx => new_card)
[1, 6, 4, 1]
```

## 3. 덱 맨 위에 카드 넣기

덱 맨 위에 새 카드를 넣고, 덱을 반환해요.

```julia-repl
julia> new_card = 8;

julia> insert_card_at_top!([1, 3, 4, 1], new_card)
[1, 3, 4, 1, 8]
```

## 4. 덱에서 카드 한 장 제거하기

덱에서 `idx` 위치에 있는 카드를 제거하고, 덱을 반환해요.

```julia-repl
julia> idx = 2;

julia> remove_card!([1, 3, 4, 1], idx)
[1, 4, 1]
```

## 5. 덱 맨 위의 카드 제거하기

덱 맨 위에 있는 카드를 제거하고, 덱을 반환해요.

```julia-repl
julia> remove_card_from_top!([1, 3, 4, 1])
[1, 3, 4]
```

## 6. 덱 맨 아래에 카드 넣기

덱 맨 아래에 새 카드를 넣고, 덱을 반환해요.

```julia-repl
julia> new_card = 8;

julia> insert_card_at_bottom!([1, 3, 4, 1], new_card)
[8, 1, 3, 4, 1]
```

## 7. 덱 맨 아래의 카드 제거하기

덱 맨 아래에 있는 카드를 제거하고, 덱을 반환해요.

```julia-repl
julia> remove_card_at_bottom!([1, 3, 4, 1])
[3, 4, 1]
```

## 8. 덱의 크기 확인하기

덱의 크기가 주어진 `deck_size`와 같은지 아닌지 확인해요.

```julia-repl
julia> deck_size = 4;

julia> check_deck_size([1, 3, 4, 1], deck_size)
true

julia> check_deck_size([1, 3, 4, 1, 5], deck_size)
false
```
