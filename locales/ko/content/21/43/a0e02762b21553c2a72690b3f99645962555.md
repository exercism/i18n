# 소개

Clojure에서 이름에 값을 바인딩하는 것을 _var_라고 해요. 최상위(전역) var는 다른 언어의 상수와 비슷해요.

최상위 var는 `def`로 정의해요:

```clojure
(def fingers 10)

fingers
;;=> 10
```

`defn`을 사용하면 인자를 0개 이상 받는 함수를 정의할 수 있어요. 다음은 두 수를 더하는 함수예요:

```clojure
(defn add [x y]
  (+ x y))
```

이 함수는 `[x y]` 벡터에 담긴 인자 2개를 받고, 그 뒤에 여러 표현식을 담을 수 있는 함수의 *본문*이 와요. 반환값은 항상 본문의 마지막 표현식인 `(+ x y)`를 평가한 결과예요. 이 표현식은 함수 호출을 나타내는 리스트예요. 리스트의 첫 번째 항목은 `+` 함수이고, 그다음 항목인 `x`와 `y`를 인자로 사용해 평가해요.

위에서 정의한 `add` 함수도 같은 방식으로 호출해요:

```clojure
(add 2 3)
;;=> 5
```

Clojure에서 함수와 값은 정의된 _후에야_ 사용할 수 있어요. 즉, 폼은 항상 나타나는 순서대로 평가돼요.

Clojure에서 공백은 서식 외에는 아무런 의미가 없어요.

Clojure의 함수와 var는 네임스페이스로 구성돼요. 네임스페이스는 관련된 기능을 묶어 주고, `ns` 매크로로 정의해요:

```clojure
(ns calculator)

(def pi 3.14)

(defn add [x y]
  (+ x y))
```

Clojure는 두 가지 종류의 주석을 지원해요. 한 줄 주석은 `;`로 시작하고, `comment` 폼은 `(comment`와 `)` 사이의 모든 것이 평가되지 않도록 막는 데 사용해요.
