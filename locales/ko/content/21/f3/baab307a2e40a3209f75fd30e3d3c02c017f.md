# 소개

Gleam은 Erlang 가상 머신(BEAM)에서도, JavaScript 런타임에서도 실행할 수 있어요. 이 런타임을 사용하는 다른 언어도 많고, 그런 언어로 작성한 코드를 Gleam에서 호출할 수 있으면 유용할 때가 많아요.

Gleam의 _외부 함수_ 기능을 사용하면 다른 언어의 함수를 Gleam으로 가져와 런타임 오버헤드 없이 호출할 수 있어요.

Gleam 프로젝트가 Erlang 가상 머신에서 실행되고, Erlang `lists` 모듈의 `reverse` 함수를 호출하고 싶다면, Gleam 함수 선언부에 `@external` 애트리뷰트를 다음과 같이 추가하면 돼요:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

그러면 이 함수를 평범한 Gleam 함수처럼 호출할 수 있어요:

```gleam
let reversed = reverse_list([1, 2, 3])
// -> [3, 2, 1]
```

이 코드를 JavaScript 런타임용으로 컴파일하려고 하면, JavaScript 구현이 없기 때문에 오류 메시지와 함께 실패해요. JavaScript 런타임용 구현을 다음과 같이 따로 지정할 수 있어요:

```gleam
@external(erlang, "lists", "reverse")
@external(javascript, "./my_module.mjs", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

현재 컴파일 대상에 대한 외부 구현이 없을 때 사용할 Gleam 구현을 직접 작성할 수도 있어요:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a) {
  tail_recursive_reverse(x, [])
}

fn tail_recursive_reverse(list, reversed) {
  case list {
    [] -> reversed
    [x, ..xs] -> tail_recursive_reverse(xs, [x, ..reversed])
  }
}
```
