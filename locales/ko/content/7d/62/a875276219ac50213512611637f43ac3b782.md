# 소개

Exercism에서 연습 문제를 하나 풀 때마다 모범 답안을 함께 받게 돼요. Julia 트랙에서는 그런 답안에 보통 [독스트링](https://en.wikipedia.org/wiki/Docstring)이 들어 있어요. 이 연습 문제를 풀고 나면 독스트링이 어떻게 구성되는지, 어떻게 작성하는지, 그리고 REPL에서 독스트링에 어떻게 접근하는지 알게 될 거예요.

~~~~exercism/note
Julia 트랙에서 연습 문제를 푸는 동안에는, 원하지 않는다면 함수에 독스트링을 꼭 작성하지 않아도 돼요.
~~~~

## 문법

Julia 객체, 이를테면 함수나 타입 바로 앞에 오는 문자열은 그 객체를 설명하는 독스트링으로 해석돼요. 예를 들면 다음과 같아요.

```julia
"Tell a joke."
joke() = ...
```

Julia의 독스트링은 [Markdown](https://en.wikipedia.org/wiki/Markdown)으로 서식을 지정해요. 덕분에 독스트링 안에서 들여쓰기, 코드 블록, 굵은 글씨 같은 기능을 쓸 수 있어요.

~~~~exercism/note
지원되는 Markdown 기능 목록은 [Markdown 표준 라이브러리 문서](https://docs.julialang.org/en/v1/stdlib/Markdown/)에서 볼 수 있어요.
~~~~

좀 더 복잡한 독스트링은 이렇게 생겼어요.

````julia
"""
    mean(x, y)

Compute the mean value of `x` and `y`.
"""
mean(x, y) = (x + y) / 2
````

Julia 매뉴얼에는 따라야 할 몇 가지 관례가 있어요.

> - 문서 맨 위에는 항상 함수의 시그니처를 보여 주고, Julia 코드로 출력되도록 네 칸 들여쓰기를 해요.
> - 시그니처를 간략히 적은 블록 뒤에는 함수가 하는 일이나 객체가 나타내는 바를 설명하는 한 줄짜리 문장을 넣어요.
>    필요하다면 빈 줄 하나를 둔 뒤 두 번째 문단에 더 자세한 내용을 적어요.
>    함수를 문서화할 때 한 줄짜리 문장은 3인칭 대신 명령형("Do this", "Return that")을 써요("Returns the length..."처럼 쓰지 않아요).
>    문장은 마침표로 끝내요.
> - 같은 말을 반복하지 않아요.
>    함수 이름은 시그니처에 나오니, 문서를 "The function `mean`..."처럼 시작할 필요가 없어요. 바로 본론으로 들어가요.
> - 코드와 수식은 백틱으로 표시해요.
> - 시작과 끝 `"""` 문자는 각각 별도의 줄에 놓아요.

~~~~exercism/note
위 목록은 Exercism에서 필요하거나 마주칠 수 있는 관례만 다뤄요. 전체 목록은 [Julia 매뉴얼](https://docs.julialang.org/en/v1/manual/documentation/)에서 볼 수 있어요. 더 고급 Julia 개념을 문서화하는 관례는 이후 연습 문제에서 해당 개념과 함께 소개될 거예요.
~~~~

## 독스트링에 접근하기

REPL에서 `?`를 입력한 뒤 함수나 객체의 이름을 입력하면 독스트링을 검색할 수 있어요. 예를 들면 다음과 같아요.

```julia-repl
help?> println
search: println printstyled print sprint isprint

  println([io::IO], xs...)


  Print (using print) xs followed by a newline. If io is not supplied, prints to stdout.

  Examples
  ==========

  julia> println("Hello, world")
  Hello, world

  julia> io = IOBuffer();

  julia> println(io, "Hello, world")

  julia> String(take!(io))
  "Hello, world\n"
```

이 기능은 기본적인 검색으로도 쓸 수 있어요. 예를 들어 함수의 정확한 철자가 기억나지 않을 때 유용해요.

```julia-repl
help?> printline
search:

Couldn't find printline
Perhaps you meant println, pipeline, @inline or print
  No documentation found.

  Binding printline does not exist.
```
