# 개요

`[ ]`로 작성하는 쿼테이션은 Factor에서 익명 함수나 코드 블록에 해당하는 표현이에요. 스택에 넣거나, 저장하거나, 여기저기 전달할 수 있는 일급 값이고, 무언가가 이 쿼테이션을 *호출*할 때만 실행돼요.

```factor
[ 1 + ]              ! a quotation, sitting on the stack
5 [ 1 + ] call .     ! => 6
```

쿼테이션은 단어들의 나열이고, Factor는 어떤 동작을 미뤄 두거나 매개변수로 넘겨야 할 때마다 쿼테이션을 사용해요.

- `if` / `when` / `unless` / `cond`의 분기
- `filter`, `count`, `any?`, `all?`의 조건
- `map`, `each`, `reduce`의 변환
- `times`, `while`, `loop`의 본문

쿼테이션의 스택 효과는 대개 추론할 수 있어요. 추론할 수 없을 때는(보통 쿼테이션을 저장해 두었다가 나중에 `call`할 때) 스택 효과를 직접 명시해요: `call( a b -- c )`.

## 쿼테이션 조합하기

```
compose ( quot1 quot2 -- compound )
curry   ( value quot  -- curried )
```

`compose`는 두 쿼테이션을 앞뒤로 이어 붙여, 첫 번째를 실행한 다음 두 번째를 실행하는 새로운 쿼테이션을 만들어요. `curry`는 고정된 값을 앞에 덧붙여서, 원래 쿼테이션을 호출하기 전에 그 값을 스택에 넣는 쿼테이션을 반환해요. 둘 다 평범한 쿼테이션을 만들어 내므로, `call`하거나 저장하거나 컴비네이터에 전달할 수 있어요.

```factor
USING: kernel math ;

3 [ 2 * ] [ 1 + ] compose call .   ! 3 2 * 1 + => 7
5 [ 1 + ] curry call .             ! 5 1 +     => 6
```
