# 소개

예외는 오류 처리의 한 형태예요.
예상치 못한 상황을 다룰 때 주로 나타나기 때문에 예외라고 불러요.

코드 어디에서든 예외를 `raise`할 수 있어요.
`raise` 메서드를 사용해서 예외를 발생시키는데, 이때 객체를 전달해요. 보통은 Exception 객체를 전달하지만 기본 문자열을 사용할 수도 있어요.
예를 들어, 연습 문제 스텁에서는 메서드가 아직 구현되지 않았다는 것을 Ruby에게 알려주기 위해 내장된 `RuntimeError`를 사용하는 것을 볼 수 있어요.
`raise(ExceptionObject, params)`라는 축약 문법을 사용할 수도 있어요.
예외 클래스를 생략하면 기본적으로 `RuntimeError`가 사용돼요.
예를 들면 다음과 같아요:

```ruby
# These are equivalent
raise RuntimeError.new("Please implement this method")
raise RuntimeError, "Please implement this method"
raise "Please implement this method"
```

Ruby가 이걸 만나면 오류를 프로그램의 최상위로 전달한 다음 종료해요.
예를 들어, 어떤 수를 0으로 나누려고 하면 다음과 같은 것을 볼 수 있어요:
```ruby
5/0

#=> Traceback (most recent call last):
#=> ...
#=> ZeroDivisionError (divided by 0)
```
