# 안내

이 연습 문제에서는 프로그래밍 언어 배열을 다루는 몇 가지 메서드를 구현해요.

## 1. 빈 언어 배열을 반환하는 메서드를 정의해요

인자를 받지 않고 `Array(String)` 타입의 빈 배열을 반환하는 `LanguageList.list` 메서드를 정의해요.

```crystal
LanguageList.list()
# => []
```

## 2. 배열에 언어를 추가하는 메서드를 정의해요

두 개의 인자(_언어 배열_과 _언어_를 나타내는 문자열 리터럴)를 받는 `LanguageList.add` 메서드를 정의해요.
이 메서드는 배열 끝에 새 언어를 추가한 배열을 반환해야 해요.

```crystal
language_list = LanguageList.list()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
```

## 3. 배열에서 언어를 제거하는 메서드를 정의해요

인자 하나(_언어 배열_)를 받는 `LanguageList.remove` 메서드를 정의해요.
이 메서드는 마지막 원소를 제거한 배열을 반환해야 해요.
배열에는 항상 원소가 최소한 하나는 있다고 가정해요.

```crystal
language_list = LanguageList.list()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
language_list = LanguageList.remove(language_list)
# => ["Crystal"]
```

## 4. 배열의 n번째 원소를 반환하는 메서드를 정의해요

두 개의 인자(_언어 배열_과 인덱스)를 받는 `LanguageList.at` 메서드를 정의해요.
이 메서드는 배열에서 n번째 인덱스에 있는 언어를 반환해야 해요.
해당 인덱스에는 항상 언어가 있다고 가정해요.

```crystal
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
LanguageList.at(language_list, 1)
# => "Ruby"
```

## 5. 언어 문자열을 파싱하는 메서드를 정의해요

인자 하나(쉼표로 구분된 언어들의 문자열 리터럴)를 받는 `LanguageList.parse` 메서드를 정의해요.
이 메서드는 언어 배열을 반환해야 해요.

```crystal
LanguageList.parse("Crystal, Ruby")
# => ["Crystal", "Ruby"]
```
