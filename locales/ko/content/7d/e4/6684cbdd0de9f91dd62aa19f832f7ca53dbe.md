# 소개

## 숫자

[매뉴얼][man-types]에서:

> jq는 JSON과 동일한 데이터 타입 집합을 지원해요. 숫자, 문자열, 불리언, 배열, 객체(JSON 용어로는 문자열 키만 가진 해시), 그리고 "null"이에요.

여기서는 **숫자**에 집중해 봐요.

### 숫자와 숫자 연산자

모든 숫자는 정수이든 아니든 IEEE754 배정밀도 부동소수점 수예요.
그래서 정밀도가 53비트로 제한돼요.

숫자에는 일반적인 연산자들을 사용할 수 있어요:

- 산술: `+`, `-`, `*`, `/`, `%`
- 비교: `==`, `!=`, `<`, `<=`, `>=`, `>`
- 표준 [수학 함수][man-math]

  입력이 하나인 함수의 경우, 값을 함수로 파이프해요

  ```sh
  $ jq -n '(1 | atan) * 4'
  3.141592653589793
  ```

  입력이 두 개인 함수의 경우, 함수는 입력을 무시하고 입력값을 매개변수로
  받아요 (매개변수는 세미콜론으로 구분한다는 걸 기억해요)

  ```sh
  $ jq -n 'pow(2; 10)'
  1024
  ```

  세미콜론이 함수 인자의 구분자이고, 쉼표가 아니에요.

### 그 밖의 `jq` 표현식

연습 문제를 풀려면 조건 표현식에 대해 알아야 해요.

#### 조건 표현식

`jq`는 **조건 표현식**에 [`if-then-else` 표현식][if-then-else]을 사용해요.
_표현식_ 이므로 파이프라인에 놓여요.

문법은 다음과 같아요: `if CONDITION then TRUE_EXPR else FALSE_EXPR end`.

`else` 절은 선택 사항이에요.

```jq
42 | if . < 33 then "small" else "larger" end
# => "larger"
```

조건을 더 추가하려면 `elif`를 사용해요

```jq
42 | if . < 33 then "small"
     elif . < 67 then "medium"
     else "large"
     end
# => "medium"
```
