# 지침 추가

## 정원 형식

정원은 널 문자로 끝나는 문자열로 표현돼요. 각 행의 끝에는 줄바꿈 문자가 있어요.

예를 들어 `"   \n * \n   \n"` 같은 형태예요.

## 레지스터

| 레지스터 | 용도     | 타입 | 설명                  |
| -------- | -------- | ---- | --------------------- |
| `$a0`    | 입력     | 주소 | 널 문자로 끝나는 입력 문자열  |
| `$a1`    | 입력/출력 | 주소 | 널 문자로 끝나는 출력 문자열  |
| `$t0-9`  | 임시     | 무관 | 임시 저장용            |
