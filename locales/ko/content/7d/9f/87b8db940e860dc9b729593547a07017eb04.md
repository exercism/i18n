# 일반

- API 문서: [package regexp][package-regexp]
- 정규 표현식 문법: [regexp/syntax][regexp-syntax]
- [regex101.com][regex101] 웹사이트에서 온라인 정규 표현식 테스터를 사용할 수 있어요.
- 정규 표현식은 백틱으로 감싼 [원시 문자열 리터럴][raw-string-literals]로 작성하는 걸 권장해요.

## 1. 깨진 로그 줄 찾아내기

- 함수 [regexp.MatchString][fun-re-match-string]이나 메서드 [MatchString][method-match-string]이 여기서 유용할 수 있어요.
- 정규 표현식에서 `^` 문자는 줄/문자열의 시작과 일치해요.

## 2. 로그 줄 나누기

- 여기서는 [Split][regexp-split] 메서드가 유용할 수 있어요.

## 3. 따옴표로 묶인 텍스트에서 `password`가 포함된 줄 개수 세기

- 정규 표현식 앞에 `(?i)`를 붙이면 대소문자를 구분해서 일치시킬 수 있어요.
  이렇게 하면 `i` 플래그가 설정돼요.
  [이 튜토리얼][yourbasic-i-flag]을 참고해요.

## 4. 로그에서 불필요한 부분 제거하기

- 여기서는 [ReplaceAllString][replace-all-string] 메서드가 유용할 수 있어요.

## 5. 줄에 사용자 이름 표시하기

- 여기서는 [FindStringSubmatch][find-string-submatch] 메서드가 유용할 수 있어요.
