# 소개

## 비교

### 숫자 비교

`jq`에서는 다음과 같은 관계 연산자와 동등 연산자로 숫자를 비교할 수 있어요.

| 비교 | 연산자 |
| ---------------------- | -------- |
| ~보다 큼 | `a > b`  |
| ~보다 크거나 같음 | `a >= b` |
| ~보다 작음 | `a < b`  |
| ~보다 작거나 같음 | `a <= b` |
| 같음 | `a == b` |
| 같지 않음 | `a != b` |

비교 결과는 항상 불리언 값이에요. 즉 `true`나 `false` 중 하나예요.

```jq
1 < 3,      # => true
2 != 2,     # => false
1 == 1.0    # => true
            # All numbers are floating-points, so this is different syntax
            # for the exact same value.
```

### 문자열 비교

위의 비교 연산자로 문자열도 비교할 수 있어요.
이 경우에는 딕셔너리(사전식) 순서가 적용돼요.
정렬 순서는 _유니코드 코드 포인트 값_을 기준으로 해요.

```jq
"Apple" > "Pear",   # => false
"a" < "above",      # => true
"a" == "A"          # => false
```

숫자 값을 담고 있는 것처럼 보이지만 문자열 타입인 두 변수를 비교할 때는 주의해야 해요.
딕셔너리 순서 때문에 그 결과는 숫자 타입 값을 비교한 결과와 같지 않아요.

```jq
10 < 2,     # => false
"10" < "2"  # => true (because "1" comes before "2")
```

### "엄격한" 동등 비교

`jq`의 `==` 연산자는 JavaScript의 `===`와 비슷해요. 겉보기에는 같아 보이지만 타입이 다르면 같지 않다고 판단한다는 점에서요.

```jq
"3" == 3    # => false
            # the value on the left has type string,
            # the value on the right has type number.
```

### 배열 비교

두 배열은 대응하는 모든 원소가 같으면 서로 같아요.

```jq
[1, 2, 3] == [1, 2, 3]      # => true
[1, 2, 3] == [1, 3, 2]      # => false, different order
[1, 2, 3] == [1, 2, "3"]    # => false, different types
```

### 객체 비교

두 객체는 키-값 쌍이 같으면 서로 같아요.

```jq
{name: "Joe", age: 42} == {age: 42, name: "Joe"}                # => true
{name: "Joe", age: 42} == {age: 42, name: "Jane"}               # => false
{name: "Joe", age: 42} == {age: "42", name: "Joe"}              # => false
{name: "Joe", age: 42} == {age: 42, name: "Joe", height: 175}   # => false

# comparisons will drill down as deeply as required
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2]}}}                  # => true
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2, 3]}}}               # => false
```

## 조건문

### if 표현식

`jq`의 **조건 표현식**은 `if A then B else C end`예요.

`if-then-else`는 다른 모든 `jq` 내장 기능과 마찬가지로 필터예요. 입력을 받아 출력을 만들어요.

표현식 `A`가 "truthy" 값을 만들어 내면 `if` 필터는 `B`를 평가해요.
그렇지 않으면 `C`를 평가해요.
`if` 필터의 입력은 `B`나 `C`로 전달돼요.

```jq
42 | if . < 50 then "small" else "big" end      # => "small"
```

```jq
5 | if . % 2 == 0 then . / 2 else . * 4 end     # => 20
```

~~~~exercism/note
`else` 절은 **선택 사항**이에요. 다음 두 문은 서로 동등해요.

```jq
if A then B else . end
if A then B end
```
~~~~

### 중첩된 if 문

`elif`로 조건을 더 추가할 수 있어요.

```jq
42 | if . < 33 then "small"
     elif . < 66 then "medium"
     else "big"
     end
# => "medium"
```

`elif` 절은 필요한 만큼 사용하면 돼요.

### 참 같은 값

`jq`에서 "거짓"인 값은 `false`와 `null`뿐이에요.
나머지는 모두 "참"이에요. 숫자 0과 빈 문자열, 빈 배열, 빈 객체까지도요.

### 불리언 연산자

**불리언 연산자** `and`와 `or`를 사용하면 복잡한 질의를 만들 수 있어요.

```jq
42 | if . < 33 or . > 66 then "big or small"
     else "medium"
     end
```

부정하려면 `not`을 사용해요. 이건 연산자가 아니라 **필터**예요.

```jq
42 | if (. < 33 or . > 66 | not) then "medium"
     else "big or small"
     end
```

### 대체 연산자

**대체 연산자**를 사용하면 표현식이 false나 null일 때 사용할 "기본" 값을 지정할 수 있어요.

```jq
A // B

# This is identical to
if A then A else B end
```

예를 들어 볼까요.

```jq
[3, 5, 18] | add / 2       # => 13
[]         | add / 2       # => error: null (null) and number (2) cannot be divided
[]         | add // 0 / 2  # => 0
```
