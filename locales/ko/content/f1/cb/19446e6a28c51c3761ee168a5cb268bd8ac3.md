# 소개

다른 많은 언어와 달리, JavaScript에는 (의미 있는) 값이 없음을 나타내는 서로 다른 두 가지 요소가 있어요.
바로 `null`과 `undefined`예요.

## Null

원시 값 `null`은 모든 타입의 변수에서 의도적인 "빈 값"으로 사용해요.

```javascript
let name = null;
// name is intentionally set to "empty" because it is not
// available
```

[일치 연산자][mdn-strict-equality] `===`를 사용하면 변수가 null인지 확인할 수 있어요.

```javascript
let name = null;

name === null;
// => true
```

## Undefined

> 값을 할당받지 않은 변수는 `undefined` 타입이에요.[^1]

즉, `null`이 빈 값(그래도 값이기는 해요)을 나타내는 반면, `undefined`는 값이 아예 없음을 나타내요. 🤯

`undefined`는 여러 상황에서 나타나요.

- 변수가 값을 할당받지 않고 선언되면(초기화하지 않으면) `undefined`예요.

  ```js
  let name;
  console.log(name); // => undefined
  ```

- 객체에서 존재하지 않는 키의 값을 가져오려고 하면 `undefined`가 나와요.

  ```js
  let obj = {
    name: 'John',
  };
  console.log(obj.age); // => undefined
  ```

- 함수가 값을 반환하지 않으면 결과는 `undefined`예요.

  ```js
  function printName(name) {
    'My name is ' + name;
  }
  console.log(printName('John')); // => undefined
  ```

- 함수에 인자가 전달되지 않으면, 그 인자에 기본값이 없는 한 `undefined`예요.

  ```js
  function printName(name) {
    return name;
  }
  console.log(printName()); // => undefined
  ```

일치 연산자 `===`를 사용하면 변수가 undefined인지 확인할 수 있어요.

```javascript
let name;

name === undefined;
// => true
```

## 옵셔널 체이닝

객체에서 중첩된 값을 가져오려고 하는데 상위 키가 존재하지 않으면, JavaScript는 오류를 던져요.
이를 쉽게 피하기 위해 2020년에 옵셔널 체이닝이 언어 명세에 추가됐어요.
옵셔널 체이닝 연산자 `?.`를 사용하면, 상위 키가 `null`이나 `undefined`가 아닐 때만 JavaScript가 중첩된 키에 접근하도록 할 수 있어요.
그렇지 않으면 `undefined`가 반환돼요.

```javascript
const obj = {
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
};

obj.address.zipCode;
// => undefined

obj.residence.street;
// => TypeError: Cannot read property 'street' of undefined

obj.residence?.street;
// => undefined
```

## Nullish 병합

변수가 null이거나 undefined일 때(그리고 오직 그때만) 기본값을 적용하고 싶은 상황이 있어요.
이를 위해 2020년에 Nullish 병합 연산자 `??`가 도입됐어요.
왼쪽 피연산자가 `null`이거나 `undefined`일 때만 오른쪽 피연산자를 반환해요.
그렇지 않으면 왼쪽 피연산자가 반환돼요.

```javascript
let amount = null;
amount = amount ?? 1;
// => 1

amount = 0;
amount = amount ?? 1;
// => 0
```
