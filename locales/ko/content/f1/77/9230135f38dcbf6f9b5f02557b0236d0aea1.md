# 힌트

## 1. 한 줄을 말하는 두 가지 방법

- `.upper`와 `.lower`는 문자 하나가 아니라 문자열 전체에 작동해요.
- `whisper`는 소문자로 바꾼 줄의 양끝에 `"..."`를 붙여요.

## 2. 한 줄 연습하기

- 인자 타입은 `ROUT{STR}:STR`라고 써요. 중괄호 안에 인자 타입을 쓰고, 콜론 뒤에 결과를 써요.
- 본문은 한 줄이에요: `return part.call(line);`
- `rehearse`는 `shout`이나 `whisper`를 언급하면 안 돼요. 모르는 것이야말로 바인딩된 루틴을 받는 이유예요.

## 3. 장면 전체

- `rehearsal-script`에서처럼 루프와 `FSTR`을 사용해요.
- 각 줄마다 `part.call(...)`을 호출하고, 첫 번째 줄을 제외한 모든 줄 앞에 `" "`를 붙여요.

## 4. 말하는 방식을 돌려주기

- 반환 타입은 `ROUT{STR}:STR`이에요. 2번 문제의 인자 타입과 똑같아요.
- 클래스 안에서 `bind(shout(_))`를 써요. 자기 클래스에서 호출하는 다른 루틴들처럼 클래스 이름은 필요 없어요.
- `return bind(...)`는 파싱되지 않아요. `bind`는 먼저 대입문의 오른쪽에 와야 해요:

  ```sather
     part : ROUT{STR}:STR;
     if ... then part := bind(shout(_)); else ... end;
     return part;
  ```

- 경우가 두 가지니까 `if`를 쓰거나, `else`가 있는 `case`를 써요.

## 5. 인자 고정하기

- `repeat` 자체는 평범한 루틴이에요. 루프와 `FSTR`, 그리고 `1.upto!(times)`로 이루어져 있어요.
- `doubler`는 숫자를 그대로 쓰고 줄은 빈 자리로 남겨서 바인딩해요: `bind(repeat(2, _))`. 4번 문제에서처럼 변수에 넣고 그것을 반환해요.
- 바인딩된 루틴의 인자가 되는 것은 `_`뿐이에요. 그래서 `bind(repeat(2, _))`의 타입은 `ROUT{INT,STR}:STR`이 아니라 `ROUT{STR}:STR`이에요.
