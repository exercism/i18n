### 소개

Java 트랙의 첫 번째 연습 문제에 오신 것을 환영해요!

이 문서는 이 연습 문제를 푸는 단계별 안내예요.
안내 내용은 Windows, macOS, Linux에서 모두 똑같이 잘 동작할 거예요.

Java 기초에 이미 익숙하더라도 이 안내를 따라가 보면 도움이 될 거예요. 코드를 컴파일하고 테스트할 때 사용하는 도구인 Gradle의 출력을 이해하는 데 도움이 되고, 이 트랙의 모든 연습 문제에 공통된 몇 가지 패턴도 소개해 주거든요.

### 연습 문제 구조

새 Java 연습 문제를 내려받으면 다음과 같은 것들을 받게 돼요:

- __하나 이상의 테스트 파일__ (항상).
이 파일들은 `src/test/java` 디렉터리에 있고, 우리 풀이가 제대로 동작한다고 안심하고 말할 수 있으려면 먼저 통과해야 하는 테스트들을 정의해요.
- __하나 이상의 스타터 파일__ (처음에는).
제공되는 경우, 이 파일들은 `src/main/java` 디렉터리에 있고, 현재 문제를 풀기 위해 필요한 클래스의 뼈대를 정의해요.

### "Hello, World!" 풀기

온라인 에디터를 사용해서 풀이를 작성하고 테스트를 실행할 수도 있지만, 문제를 직접 풀고 로컬에서 테스트를 실행하고 싶다면 아래 링크들을 확인해 봐요:

- [Java 설치하기][Installing Java]
- [로컬에서 작업하기][Working Locally]
- [Java 트랙에서 로컬로 테스트하기][Testing locally on the java track]

### 1단계: 풀이 수정하기

로컬에서 작업하든 온라인 에디터를 사용하든, 다음과 같은 코드를 찾을 수 있을 거예요:

```java
String getGreeting() {
    return "Goodbye, Mars!";
}
```

목표는 주어진 코드를 수정해서 `"Goodbye, Mars!"` 대신 `"Hello, World!"`라는 텍스트를 출력하도록 만드는 거예요.

### 2단계: 테스트 실행하기

코드를 고치고 풀이를 구현했다면, 테스트를 다시 실행해 봐요.
온라인 에디터를 사용하거나 내 컴퓨터에서 로컬로 테스트를 실행할 수 있어요:

- 온라인 에디터에서 테스트를 실행하려면 "Run Tests" 버튼을 클릭해요.
- 로컬에서 테스트를 실행하려면 [Java 트랙에서 테스트하기][Testing locally on the java track]를 확인해 봐요. 테스트가 실패해도 괜찮아요! 오류 메시지가 무엇을 말하는지 확인하고, 코드를 고쳐서 다시 테스트해 봐요. 테스트가 통과하면 다음 단계로 넘어가요.

### 3단계: 첫 번째 풀이 제출하기

동작하는 풀이를 완성하고 함께 살펴봤다면, 이제 exercism.org에 제출할 준비가 된 거예요.
온라인 에디터를 사용하거나 로컬에서 [Exercism CLI][Working Locally]를 사용해 풀이를 제출할 수 있어요:

- 로컬에서 연습 문제를 제출하려면, 아직 설치하지 않았다면 먼저 [exercism CLI 설치하기][Working Locally]를 하고, 그다음 풀이 파일을 제출해요. 예를 들면:

  ```sh
  exercism submit <file location>
  ```

- `<file location>` 자리에는 `Greeter.java` 파일의 상대 경로를 넣어요. 예를 들어 `C:\exercism\java\hello-world`에서 작업하고 있다면 명령은 이렇게 돼요:

  ```sh
  exercism submit .\src\main\java\Greeter.java
  ```

- 온라인 에디터에서 풀이를 제출하고 싶다면, "Submit" 버튼을 클릭하기만 하면 돼요!

로컬에서 풀이를 제출하는 방법을 더 자세히 보려면:

- [로컬에서 제출하기][Working Locally]

### 멘토 되기

Exercism의 핵심은 코딩 연습에 관한 대화예요.
혼자 연습하는 것도 분명히 재미있지만, 다른 사람의 시도와 자신의 시도에 함께 참여해야 피드백을 받을 수 있어요.
그 피드백은 무엇을 잘하고 있고 어디를 더 개선하면 좋을지 짚어 주는 데 도움이 돼요.

어떤 제출물은 자신의 것과 거의 똑같고, 어떤 것은 완전히 달라요.
두 가지를 모두 보는 것은 배울 점도 있고 흥미롭기도 해요.

멘토는 자신이 멘토링하기로 선택한 트랙의 제출된 풀이를 검토해서, 사용자가 최대한 많이 배울 수 있도록 도와요.

멘토링에 대해 더 읽어 보려면 [Exercism 문서][Mentoring]로 가 봐요.

### Exercism에 기여하기

기여자로 뛰어들기 위한 시작점은 [Exercism 기여 가이드][Contributing]에서 찾을 수 있어요.
