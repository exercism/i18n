# 디버깅

디버깅에 도움이 되도록, 모든 콘솔 출력이 캡처되어 테스트 결과 창에 표시된다는 점을 활용할 수 있어요. 값을 `IO.inspect`에 넘기면 어떤 값이든 출력할 수 있어요.

`IO.inspect`는 값을 그대로 반환하기 때문에, 함수 호출 체인 중간의 값들을 살펴볼 때 특히 유용해요.

```elixir
"hello"
|> String.upcase()
|> IO.inspect()
|> String.split("", trim: true)
```

참고로, 보안상의 이유로 각 테스트의 출력은 500자를 넘으면 잘려요.
