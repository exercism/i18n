# 최상위 상수 추출 권장

상수를 최상위 스코프로 추출하는 것을 고려해 보세요:

```javascript
const %{name} = %{value}

// the rest of your code below it
export %{method.signature}
```

`export`된 함수, 클래스, 상수만 외부에서 보이고 접근할 수 있어요.
이런 상수는 다른 코드에 노출되지 않으면서 같은 파일에 함께 둘 수 있어요.
또한 상수를 추출해 두면 같은 상수를 다시 쓸 때 함수 안에서 매번 새로 할당하지 않아도 되므로 메모리를 아낄 수 있어요.
