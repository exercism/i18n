# 지침

옛날 옛적에 사이버스페이스라는 활기찬 도시가 있었어요.
사이버스페이스는 디지털 대도시였고, 매일 수백만 명의 주민이 로그인하고 로그아웃했어요.
이 모든 사용자를 관리하기 위해 사이버스페이스에는 /etc/passwd라는 특별한 파일이 있었어요.

/etc/passwd 파일은 이 도시의 전화번호부와 같았어요.
시스템에 계정을 가진 모든 사용자와, 각 사용자에 대한 몇 가지 중요한 정보가 나열되어 있었어요:

| n   | 필드 |
| --- | --- |
| 1   | 사용자 이름 |
| 2   | 비밀번호 ("x"는 보안을 위해 실제 비밀번호가 다른 곳에 저장되어 있음을 나타내요) |
| 3   | UID, 고유한 숫자 사용자 ID |
| 4   | GID, 고유한 숫자 그룹 ID (일반적으로 UID와 같아요) |
| 5   | 사용자 정보 (일반적으로 사용자의 전체 이름이지만, 다른 정보도 포함될 수 있어요) |
| 6   | 홈 디렉터리 |
| 7   | 로그인 셸 |

각 필드는 콜론 문자로 구분되어 있어요.
다음은 전형적인 항목이에요:

```none
glennj:x:1010:1010:Glenn Jackman:/home/glennj:/usr/local/bin/fish
```

이 파일은 시스템 관리자 팀이 관리했는데, 이들은 새 계정을 만들고, 기존 계정을 갱신하고, 오래된 계정을 삭제하는 일을 맡았어요.
시스템 관리자는 사이버스페이스의 문지기로서, 권한이 있는 사용자만 시스템에 접근할 수 있도록 했어요.

어느 날, 알렉스라는 새 시스템 관리자가 팀에 합류하게 되었어요.
알렉스는 새 일을 맡게 되어 신이 났고, /etc/passwd 파일의 이모저모를 금방 익혔어요.
시스템에 새 사용자를 추가하는 방법, 사용자 정보를 갱신하는 방법, 오래된 사용자를 삭제하는 방법을 배웠어요.

알렉스가 /etc/passwd 파일을 살펴보던 중, 뭔가 이상한 점을 발견했어요.
일부 사용자의 홈 디렉터리는 이상하거나 특이했어요.
어떤 사용자의 홈 디렉터리는 /dev/null로 설정되어 있었고, 또 어떤 사용자의 홈 디렉터리는 존재하지 않는 낯선 경로로 설정되어 있었어요.

알렉스는 이 사용자들이 실제 사람이 아니라 해커가 만들어 둔 가짜 계정이라는 것을 깨달았어요.
해커들은 시스템의 취약점을 악용할 방법을 찾아내서, 사이버스페이스에 접근하려고 이 가짜 계정들을 만들어 둔 것이었어요.

알렉스는 조치를 취해야 한다는 것을 알았어요.
알렉스는 awk를 사용해 /etc/passwd 파일을 분석하고, 모든 가짜 계정을 찾아내는 스크립트를 작성했어요.
그다음 팀원들과 함께 이 계정들을 삭제하고, 애초에 해커들이 이런 계정을 만들 수 있게 했던 취약점을 고쳤어요.

알렉스가 awk를 활용한 덕분에, 팀은 가짜 계정을 찾아내고 삭제해서 사이버스페이스를 모두에게 더 안전한 곳으로 만들 수 있었어요.
시스템 관리자들은 계속해서 /etc/passwd 파일을 관리하며, 파일을 최신 상태로 안전하게 유지하고, 권한이 있는 사용자만 시스템에 접근할 수 있도록 했어요.

이제 알렉스처럼 시스템 관리자가 될 차례예요.

이 연습 문제를 풀기 위해 필요한 추가 AWK 문법이에요.

## 1. 사용자 이름 나열하기

passwd 파일의 각 줄에서 콜론으로 구분된 첫 번째 필드를 출력하는 awk 프로그램을 작성해 보세요.

## 2. 줄 번호 출력하기

입력 파일의 각 레코드에 대한 줄 번호를 출력하는 awk 명령을 작성해 보세요.
줄 번호만 출력하고, 다른 정보는 출력하지 마세요.

## 3. 유효하지 않은 홈 디렉터리를 가진 레코드 출력하기

사이버스페이스에서 "유효한" 홈 디렉터리는 `/home` 또는 `/root`로 시작해요.
홈 디렉터리가 **유효하지 않은** 입력 파일의 레코드를 출력해 보세요.

## 4. bash를 사용하는 유효한 사용자 출력하기

홈 디렉터리가 유효하고 **동시에** 로그인 셸이 `bash`인 레코드를 출력해 보세요.
