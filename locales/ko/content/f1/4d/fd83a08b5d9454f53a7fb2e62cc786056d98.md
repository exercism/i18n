# 힌트

## 일반

- `SYMBOLS:` 줄 하나로 네 가지 기본 방위 기호와 네 가지 상대 방위 기호를 선언해요:
  `SYMBOLS: north east south west ahead starboard behind port ;`
- 각 튜플은 `TUPLE: <class> <slot1> <slot2> ;` 형식으로 선언해요.
- `GENERIC:` 줄은 워드를 선언하고, 각 `M:` 줄은 클래스 하나에 대한
  메서드를 추가해요. 메서드 본문에서 이름 있는 지역 변수를 쓰고 싶다면
  `M::`를 사용해요.

## 1. 기본 방위를 위한 `>cartesian`

- 네 가지 방위 기호에 대한 작은 `case` 하나면 충분해요.
- `{ north [ 0 1 ] }`: 본문은 그저 두 값을 푸시할 뿐이에요. 테스트는
  스택에서 `x`가 `y` 아래에 있기를 기대해요.

## 2. 극좌표를 위한 `>cartesian`

- 도를 라디안으로 변환해요: `bearing pi * 180 /`.
- `sin`과 `cos`는 `math.functions`에 있어요.
- `magnitude * sin(rad)`를 푸시한 다음 `magnitude * cos(rad)`를 푸시해요.

## 3. 상대 방위를 위한 `>cartesian`

- 동적 변수를 선언해요: `SYMBOL: heading`.
- 메서드에서 `heading get`으로 값을 읽어요.
- `case`로 `ahead/starboard/behind/port`를 `0/90/180/270` 오프셋에
  대응시킨 다음, heading을 더해요. 그러고 나면 작업 2와 같은
  극좌표 변환이에요. 헬퍼를 따로 빼내는 것도 고려해 봐요:
  `: deg>cartesian ( magnitude bearing -- x y ) ... ;`.

## 4. `flip`

- `cardinal`에 대한 `change-direction`과 `polar` 또는 `relative`에 대한
  `change-bearing`은 슬롯 하나만 바꾸고 나머지는 그대로 둔 새 튜플을
  만들어요:
  `[ <transformation-quotation> ] change-bearing`.
- `polar`의 회전에는 `[ 180 + 360 mod ] change-bearing`을 사용해요.

## 5. `add-bearings`

- 각 입력에 `>cartesian`을 호출한 다음, x 성분과 y 성분을 각각
  더해요. 지역 변수를 쓰면 읽기 쉬워요:
  ```factor
  :: add-bearings ( a b -- x y )
      a >cartesian :> ay :> ax
      b >cartesian :> by :> bx
      ax bx +
      ay by + ;
  ```
