# 소개

[Java](https://go.java/index.html)는 뛰어난 활용성과 호환성 덕분에 가장 인기 있는 프로그래밍 언어 중 하나예요.
소프트웨어 개발, 모바일 애플리케이션, 대규모 시스템 개발 등에 널리 쓰여요.

Java는 1995년에 탄생했고, [Oracle](https://www.oracle.com/index.html)이 유지 관리하고 있어요.
요즘 나오는 새로운 언어들만큼 젊지는 않지만, Java는 여전히 정말 인기가 많아요.
Java는 빠르고 안전하며 신뢰할 수 있고, 초보자도 배우기 쉬우면서 이식성도 뛰어나도록 설계됐어요.
이런 이식성이 가능한 이유는 Java가 크로스 플랫폼을 지원하는 [자바 가상 머신(Java Virtual Machine, JVM)](https://en.wikipedia.org/wiki/Java_virtual_machine) 위에서 실행되기 때문이에요.
[안드로이드 운영체제](<https://en.wikipedia.org/wiki/Android_(operating_system)>)가 Java 언어 환경에서 동작하기 때문에, 안드로이드 앱도 Java로 개발해요.

Java 커뮤니티는 정말 커요!
예를 들어 GitHub에는 150만 개가 넘는 Java 프로젝트가 있어요.
Java가 [StackOverflow](https://stackoverflow.com/questions/tagged/java)에서 두 번째로 큰 커뮤니티를 가지고 있다는 점도 언급할 만해요!
프로그래밍 언어의 커뮤니티가 클수록 더 많은 도움을 받을 가능성이 높아지기 때문에, 이 점은 중요해요.

Java에는 데이터베이스 연결, 네트워킹, I/O, XML 파싱, 유틸리티 등 다양한 작업에 사용할 수 있는 강력하고 잘 설계된 내장 [API(애플리케이션 프로그래밍 인터페이스)](https://docs.oracle.com/en/java/javase/11/docs/api/index.html)도 있어요.

노트북부터 데이터 센터까지, 게임 콘솔부터 과학용 슈퍼컴퓨터까지, 휴대폰부터 인터넷까지, [Java는 어디에나 있어요](https://en.wikipedia.org/wiki/Write_once,_run_anywhere)!
