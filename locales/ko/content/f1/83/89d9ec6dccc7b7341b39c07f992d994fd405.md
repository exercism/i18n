# 안내

바쁜 은행에서는 기다리는 고객을 도착한 순서가 아니라 *우선순위*에 따라 응대해요. 고객은 번호표를 뽑을 때 우선순위 번호를 받고, 창구 직원은 언제나 가장 낮은 번호를 가진 고객을 다음 순서로 응대해요(`1`이 가장 급해요). 최소 힙은 이런 대기 줄에 딱 맞아요.

## 1. 큐 열기

`new-queue`를 정의해요. 아무것도 받지 않고, 비어 있는 새 우선순위 큐를 반환해요.

```factor
new-queue
! => an empty priority queue
```

## 2. 고객 추가하기

`join-queue`를 정의해요. 고객 이름, 우선순위 번호, 큐를 받아요. 고객을 큐에 추가하고 그 큐를 반환해서, 고객을 차례로 추가할 수 있어요.

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue
! => the queue, now holding alice (5) and bob (2)
```

## 3. 다음은 누구?

`next-name`을 정의해요. 큐를 받아서 다음에 응대해야 할 고객, 즉 가장 낮은 우선순위 번호를 가진 고객의 이름을 반환해요. 단, 그 고객을 큐에서 *꺼내지는* 않아요.

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue next-name .
! => "bob"
```

## 4. 모두 응대하기

`serve-all`을 정의해요. 큐를 받아서 기다리는 모든 고객의 이름을, 응대되는 순서대로 반환해요.

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue
"carol" 9 rot join-queue serve-all .
! => { "bob" "alice" "carol" }
```
