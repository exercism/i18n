# 힌트

## 일반

- 이름으로 이루어진 배열의 타입은 `ARRAY{STR}`이고, 숫자로 이루어진 배열의 타입은 `ARRAY{INT}`예요. 인자와, 4번 문제에서는 답 모두 어느 쪽인지 밝혀야 해요.

## 1. 줄에 몇 명이 있나요?

- `.size`를 쓰는데, 뒤에 괄호를 붙이지 않아요.

## 2. 누가 앞에 서나요?

- 첫 번째 위치는 `0`이에요.

## 3. 누가 맨 뒤에 있나요?

- 세는 것이 0부터 시작하므로, 마지막 위치는 크기보다 하나 작아요.
- `2`라고 그냥 쓰지 말고 `.size`로 계산해요. 테스트는 길이가 서로 다른 여러 줄을 사용해요.

## 4. 시작 대형

- 답은 문자열의 배열이므로, 루틴은 `: ARRAY{STR}`로 선언해요.
- 배열 리터럴을 반환해요. `|` 기호 사이에 세 이름을 넣어요.

## 5. 걸음 수 세기

- 이전 연습 문제에서처럼 누적 합계와 루프를 사용해요.
- 위치를 나타내는 변수를 `0`부터 하나씩 세고, `until!(i >= steps.size)`로 루프를 끝내요.
- 합계를 `0`부터 시작하기 때문에 빈 줄의 답도 별도의 처리 없이 0이 돼요.
