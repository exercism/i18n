# 테스트 실행하기

터미널에서 연습 문제의 기본 디렉터리로 이동한 다음, 다음 명령으로 테스트를 실행해요:

```bash
$ gleam test
```

그러면 `test` 하위 폴더에 있는 테스트 파일, 즉 이름이 `_test.gleam`으로 끝나는 파일이 실행돼요.

## 테스트 함수

테스트는 [커스텀 테스트 프레임워크](https://github.com/exercism/gleam-test-runner/tree/main/runner)를 사용해요.
`test` 디렉터리에 있는 공개 함수 중 이름이 `_test`로 끝나는 함수는 모두 테스트 프레임워크가 테스트로 간주해요.

예를 들어:

```gleam
import bob
import exercism/should

pub fn shouting_test {
  bob.hey("WATCH OUT!")
  |> should.equal("Whoa, chill out!")
}
```
