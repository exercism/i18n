# 힌트

## 1. 세 가지 묘기

- 클래스 헤더는 `<` 뒤에 추상 클래스의 이름을 적어요:
  `class JUGGLING < $ACT is`.
- 각 클래스는 추상 클래스가 선언한 그대로 `name`과 `minutes`를 모두 정의해야 해요.
  하나라도 빠뜨리면 그 루틴의 이름을 알려주는 컴파일 오류가 나요.
- 각 클래스에는 `create`도 필요해요. 없으면 `#JUGGLING`이 호출할 대상이 없어요.
  그중 두 클래스는 `create : SAME is return new; end;` 이게 전부예요.
- `TRAPEZE`는 높이를 담을 속성과, 그것을 받는 `create`가 필요해요.
- `+`는 숫자를 문자열에 이어 붙여요. 그래서 `"Trapeze at " + height + "m"`에는
  따로 변환이 필요 없어요.

## 2. 공연

- 인자 타입은 `ARRAY{$ACT}`예요. 그래야 하나의 배열에 세 종류를 모두 담을 수 있어요.
- `acts.elt!`는 `$ACT`를 돌려줘요. 여기에 `.minutes`를 호출하면 각 클래스에 맞는
  것이 알아서 실행돼요. 이것이 바로 디스패치이고, 이 연습 문제의 핵심이에요.
  검사할 것도 없고 작성할 `typecase`도 없어요.
- `billing`은 루프를 돌며 문자열을 만들어요. 그래서 `FSTR`을 쓰고, `", "`는 첫 번째
  이름을 빼고 모든 이름 앞에 들어가요.
- `longest`는 지금까지 나온 가장 좋은 묘기를 기억해둬요. 가장 좋은 minutes 값을
  `-1`로 시작하면 첫 번째 묘기가 항상 이 값을 넘어서는데, 덕분에 빈 공연도 별도의
  예외 처리 없이 다룰 수 있어요. 이름은 `""` 그대로 남아요.
