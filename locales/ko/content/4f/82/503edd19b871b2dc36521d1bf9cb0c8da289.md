# 소개

Python은 두 가지 반복 구조를 제공해요.
`while`문은 횟수를 정하지 않은 _불확정_ 반복에, `for`문은 횟수가 정해진 _확정_ 반복에 쓰여요.
`break`, `continue`, `else` 키워드를 사용하면 루프의 동작을 원하는 대로 바꿀 수 있어요.
`range(<length of sequence>)` 함수와 `enumerate(<iterable>)` 함수는 반복 횟수를 세고 인덱스를 다룰 때 도움이 돼요.


`while`문은 실행할 반복 횟수를 지정하지 않고, `loop` 표현식 또는 "test"가 `True`로 평가되는 동안 계속 실행돼요.
`loop` 표현식이 `False`로 평가되면 반복이 끝나요.

```python
while expression:
    set_of_statements
```

`for`문은 모든 시퀀스의 값을 차례로 순회하고, 더 이상 반환할 값이 없으면 종료돼요.
`range(<length of sequence>)` 함수는 반복할 자료 구조나 다른 이터러블이 없을 때 `loop` 카운터나 시퀀스를 제공해요.

```python
# Python will keep track of the loop count internally.
for item in sequence:
    set_of_statements
    
# `range()` is used as an explicit loop counter.  
# This will loop 12 times, from index 0 to index 11.
for item in range(12):
    set_of_statements
```
