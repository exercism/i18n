Haxe에서 문자열을 직접 이어 붙일 수도 있지만, Haxe는 더 짧고 편리한 문법을 제공하는 [문자열 보간][string-interpolation]을 지원해요:

```haxe
var x = 42;
//The following two statements are equivalent:

// manual concatenation
trace("the number is " + x);

// using interpolation
trace('the number is $x');
```

위에서 볼 수 있듯이, 보간 문자열은 일반 [문자열][strings]과 달리 작은따옴표(`'`)로 감싸고, 보간을 일으키는 달러 기호(`$`)로 표시된 특수 식별자를 포함할 수 있어요.

`${expr}`를 사용하면 표현식 전체를 넣을 수도 있는데, 여기서 `expr`은 유효한 Haxe 표현식이면 무엇이든 돼요:

```haxe
trace('the next number is ${x + 1}');
```

실제 달러 기호가 필요할 때 보간을 막으려면 `$$`를 사용하면 돼요:

```haxe
trace('the price is $$42'); // outputs: the price is $42
```

마지막으로, 문자열 보간은 컴파일 시점의 기능이라 런타임 성능에는 아무 영향을 주지 않아요. 내부적으로 Haxe 컴파일러는 직접 이어 붙인 것과 같은 코드를 만들어요.

[string-interpolation]: https://haxe.org/manual/lf-string-interpolation.html
[strings]: https://haxe.org/manual/std-String.html
