# 설치

Racket 배포판은 https://download.racket-lang.org에서 내려받을 수 있어요.

다음 운영체제용 설치 프로그램이 제공돼요.

* Windows
* Linux
* macOS

안내 자료는 Racket의 [Getting Started](http://docs.racket-lang.org/getting-started/) 페이지를 참고해요.

[Racket Guide](https://docs.racket-lang.org/guide/intro.html)는 Racket과 상호작용하는 방법을 소개해요.

DrRacket IDE 사용법은 [DrRacket: The Racket Programming Environment](https://docs.racket-lang.org/drracket/index.html)를 참고해요.

Racket 명령줄 도구와 다른 편집기 사용법에 대한 소개는 [Command-Line Tools and Your Editor of Choice](https://docs.racket-lang.org/guide/other-editors.html)를 참고해요.


## Linux 설치 프로그램에 대해
Linux용 빌드는 대부분의 배포판에서 동작할 만큼 범용적이에요. 비교적 오래된 배포판에서도 잘 동작해요.

설치 프로그램 파일을 내려받은 다음, 다음과 같이 실행해요.
```
sh racket-8.10-x86_64-linux-cs.sh
```

관리자 권한이 필요한 위치에 설치하려면 명령 앞에 `sudo`를 붙여야 할 수도 있어요.

**경고: Racket은 배포판의 패키지 관리자를 통해서도 설치할 수 있지만, 최신 Racket 버전보다 오래된 경우가 많아요.**
나중에 그 방법을 선택해도 되지만, 학습자라면 https://download.racket-lang.org에서 받을 수 있는 현재 버전을 그대로 사용하는 편이 훨씬 좋아요.


## macOS 설치 프로그램에 대해

사용 중인 컴퓨터가 M1 또는 M2 시리즈 프로세서를 사용한다면, 내려받기 전에 플랫폼 드롭다운 메뉴에서 **Apple Silicon**을 선택해요.
