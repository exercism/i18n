# 소개

많은 프로그램은 실제 세계의 사건을 흉내 내기 위해 (의사)난수가 필요해요.

흔히 접할 수 있는 예로는 다음과 같은 것들이 있어요.

- 동전 던지기: ('H', 'T') 중 하나를 무작위로 고르기.
- 주사위 굴리기: 1부터 6까지의 무작위 정수.
- 카드 덱 섞기: 카드 목록을 무작위 순서로 재배열하기.
- 3차원 그래픽 시뮬레이션에서 나무와 덤불 만들기.

컴퓨터로 진짜 무작위 값을 만들어 내는 일은 [놀랄 만큼 어려운 기술적 과제][why-randomness-is-hard]예요. 그래서 "의사난수" 생성기도 있어요.

## 난수 생성하기

JavaScript에서는 [`Math.random()`][Math.random] 함수로 의사난수를 만들 수 있어요.
이 함수는 0 이상 1 미만의 의사난수 실수를 반환해요.

_min_ 이상 _max_ 미만의 난수를 얻으려면 다음과 같은 함수를 사용하면 돼요.

```javascript
function getRandomInRange(min, max) {
  return min + Math.random() * (max - min);
}
getRandomInRange(4, 10);
// => 5.72
```

## 무작위 정수 생성하기

무작위 정수를 만들려면 `Math.floor()`나 `Math.ceil()`을 사용해 무작위로 생성된 수를 정수로 바꾸면 돼요.
