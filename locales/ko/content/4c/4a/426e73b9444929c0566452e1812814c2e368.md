# 중첩된 if문을 사용하지 마세요

깊은 중첩을 피하려면 if문을 다시 작성해 보세요. 중첩이 깊어지면 코드를 따라가기가 어려워질 수 있어요. 다음 두 코드를 살펴봐요.

```csharp
void PrintName(Person p)
{
    if (p != null)
    {
        if (p.Name != null)
        {
            if (p.Age >= 21)
            {
                Console.WriteLine(p.Name);
            }
        }
    }
}
```

다음 코드와 비교해 봐요.

```csharp
void PrintName(Person p)
{
  if (p == null || p.Name == null || p.Age < 21)
  {
      return;
  }

  Console.WriteLine(p.Name);
}
```

두 번째 예시는 아주 뚜렷한 구조를 가지고 있어요. 오류를 다루는 경로는 모두 들여쓰기 된 블록 안에서 처리하고, "정상 경로"는 항상 가장 왼쪽에 맞춰져 있어요. 덕분에 코드를 아주 읽기 쉽고, 코드에서 가장 흔하고 오류가 없는 경로가 무엇인지 빠르게 알아볼 수 있어요.
