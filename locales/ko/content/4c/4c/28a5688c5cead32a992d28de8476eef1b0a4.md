# 설치

Zig를 설치하는 방법은 여러 가지가 있고, 언어가 성숙해지면서 그 방법의 수는 꾸준히 늘고 있어요.
다행히 널리 쓰이는 설치 방법은 모두 [Zig 설치 페이지][install-zig]에 정리되어 있어요.

## Zig 버전

Exercism은 Zig 0.17.0(2026-10-01 출시)을 사용해요.

연습 문제가 다른 Zig 버전과 호환될 수도 있지만, 그렇다고 보장할 수는 없어요.
Zig은 아직 버전 1.0에 도달하지 않았고, 호환성을 깨뜨리는 변경이 자주 있어요.

## 추가 도구

### Zig fmt - 잘 정돈된 코드 만들기

연습 문제를 풀 때는 어떤 코드 스타일을 써도 괜찮아요.
하지만 애플리케이션이나 라이브러리를 만드는 것처럼 연습 문제 풀이를 벗어난 작업에서는 코드를 일관성 있고 읽기 쉽게 유지하는 게 좋아요.
특히 여러분의 프로젝트를 도와주려는 사람들이 여러분의 코드를 읽어야 할 때는 이런 원칙이 더욱 중요해요.

이 문제를 해결하기 위해 Zig 컴파일러에는 코드를 편리하게 포맷해 주는 가벼운 [린터][linters]가 내장되어 있어요.
이 코드 포매터는 [Zig 문서][documentation]에서 이미 정한 [스타일 가이드][style-guide]를 따르는 것을 목표로 해요.

Zig에 내장된 포매터의 기능을 보려면 다음 명령을 실행해 봐요:

```bash
zig fmt --help
```

### Zig Zen - 코드를 쓸 때 기억할 규칙

어떤 작업을 할 때, 심지어 코드를 작성할 때도 방향을 잡아 주면 큰 도움이 되곤 해요.
다행히 Zig 컴파일러에는 좋은 Zig 코드를 작성하는 데 담긴 목표 몇 가지를 떠올리게 해 주는 재미있는 명령이 내장되어 있어요.

이 지혜의 말씀을 확인하려면 다음 명령을 사용해 봐요:

```bash
zig zen
```

### Zig 언어 서버 - Zig를 위한 폭넓은 에디터 지원

이 서드파티 소프트웨어는 에디터 자동 완성과 향상된 Zig 코드 탐색 기능을 제공해서 언어를 더 빠르게 익히는 데 도움이 돼요.

최신 안내는 [ZLS 설치 가이드][install-zls]를 참고해요.
