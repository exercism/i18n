# 지침

파티 로봇이 성대한 축제를 위해 깃발 장식을 걸고 있어요. 깃발 장식의 각 줄은 `n`개의 작은 깃발이 가로로 늘어선 행이고, 각 깃발의 문자는 그 깃발이 줄에서 왼쪽부터 `0`을 시작으로 세어 몇 번째 자리에 있는지에 따라 정해져요. 로봇이 아래 패턴을 만들도록 도와줘요.

## 1. 알파벳 깃발 장식

`alphabet-bunting`을 정의해서, 스택에서 음이 아닌 정수 `n`을 꺼내고 알파벳의 처음 `n`개 소문자로 이루어진 문자열을 반환하도록 해요.

```factor
5 alphabet-bunting .
! => "abcde"

0 alphabet-bunting .
! => ""
```

`n`은 최대 `26`이라고 가정해도 돼요.

## 2. 숫자 세기 깃발 장식

`counting-bunting`을 정의해서 `n`을 받아 `n`개의 숫자로 이루어진 문자열을 반환하고, 위치 `i`의 깃발이 `i mod 10`을 나타내도록 해요.

```factor
12 counting-bunting .
! => "012345678901"
```

## 3. 줄무늬 깃발 장식

`stripe-bunting`을 정의해서 두 문자를 번갈아 사용하도록 해요. 짝수 위치에는 `*`, 홀수 위치에는 `-`가 들어가요.

```factor
6 stripe-bunting .
! => "*-*-*-"

1 stripe-bunting .
! => "*"
```

## 4. 표시 깃발 장식

다섯 번째 깃발마다 특별한 표시가 들어가요. `marker-bunting`을 정의해서 `0`, `5`, `10`, … 위치에는 `|`, 나머지 위치에는 `.`가 들어가도록 해요.

```factor
11 marker-bunting .
! => "|....|....|"
```

## 5. 계곡 깃발 장식

로봇은 가운데 고리에 고정되는, 크기가 정해진 깃발 10개짜리 장식을 걸어요. `-5` 위치의 맨 왼쪽 깃발부터 `5` 바로 앞까지 세면서, 각 깃발의 문자는 중심에서 떨어진 거리를 숫자로 쓴 것이에요.

`valley-bunting`을 입력 없이 정의해서 그 고정된 문자열을 반환하도록 해요.

```factor
valley-bunting .
! => "5432101234"
```
