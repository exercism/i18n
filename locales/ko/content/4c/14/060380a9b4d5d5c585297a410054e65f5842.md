# 소개

시퀀스를 순회하다 보면 원소 자체뿐 아니라 그 원소의 *위치*도 함께 필요할 때가 있어요. [`sequences`][sequences]에 있는 `*-index` 계열 단어는 이 둘을 원소마다 실행되는 콰테이션에 함께 넘겨줘요. `times`는 횟수만 세는 단순한 반복을 위한 가까운 사촌이에요. 개수만 필요하고 시퀀스는 필요 없을 때 유용하죠.

## `each-index`와 `map-index`: 콰테이션에 전달되는 인덱스

```
each-index ( seq quot: ( elt index -- )       -- )
map-index  ( seq quot: ( elt index -- newelt ) -- newseq )
```

콰테이션은 인덱스 아래에 있는 원소를 받아요. 즉 `index`가 스택의 **맨 위**에 있어요.

```factor
USING: io kernel math.parser sequences ;

{ "alice" "bob" "carol" } [
    number>string ": " glue print
] each-index
! prints:
! alice: 0
! bob:   1
! carol: 2

{ 10 20 30 } [ + ] map-index .
! => { 10 21 32 }       (index added to each element)
```

`each-index`는 부수 효과를 위해 콰테이션을 실행하고 아무것도 반환하지 않아요. `map-index`는 원소마다의 결과를 모아서 입력과 같은 종류의 새 시퀀스로 만들어요.

## `times`: 횟수를 세는 반복

`times`는 [`math`][math]에 있는 단어로, 콰테이션을 `n`번 실행해요.

```
times ( n quot: ( -- ) -- )
```

공개된 `( -- )` 형태는 *최소* 조건이에요. `times`는 `inline`이라서 `( str -- str )`처럼 스택 효과가 균형을 이루는 콰테이션도 잘 동작하고, 스택은 반복 사이로 이어져요. 덕분에 변경 가능한 상태 없이 횟수를 세는 누산기를 만들 수 있어요.

```factor
USING: kernel sequences ;

"" 3 [ "clop " append ] times .    ! => "clop clop clop "
```

각 반복의 본문은 지금까지 이어져 온 문자열을 보고, 거기에 덧붙인 뒤, 다음 반복을 위해 새 문자열을 스택에 남겨요. 같은 요령은 누산기를 이어 가고 싶을 때 `each-index`와 `map-index`에도 쓸 수 있어요.

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
