# 지시 사항

클라이밍 센터의 프런트 데스크에서 일을 시작한 지 얼마 안 됐어요.
회원들은 몇 달 치 회원권을 구매하고, 방문할 때마다 체크인과 체크아웃을 해요.
매니저는 회원들이 가장 자주 묻는 질문에 답해 주는 도우미를 작성해 달라고 했어요.

## 1. 회원권이 언제 끝나는지 계산하기

회원권은 시작일로부터 주어진 개월 수만큼 지난 뒤, 시작일과 같은 날에 끝나요.
끝나는 달에 그 날이 없으면 그달의 마지막 날에 끝나요.

회원권의 시작일과 개월 수를 받아서 끝나는 날짜를 반환하는 `FrontDesk.membershipEnd()` 메서드를 구현해요:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.membershipEnd(LocalDate.of(2024, 3, 10), 1);
// => LocalDate.of(2024, 4, 10)
frontDesk.membershipEnd(LocalDate.of(2025, 1, 31), 1);
// => LocalDate.of(2025, 2, 28)
```

## 2. 회원권이 얼마나 유지되는지 보여 주기

센터에서는 회원권 카드에 회원권이 얼마나 유지되는지를 년, 월, 일로 표시해요.

회원권의 시작일과 종료일을 받아서 회원권 기간을 `Period`로 반환하는 `FrontDesk.membershipLength()` 메서드를 구현해요:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.membershipLength(LocalDate.of(2023, 3, 10), LocalDate.of(2024, 5, 25));
// => Period.of(1, 2, 15)
```

## 3. 회원권에 남은 일수 세기

회원들은 회원권이 끝나기까지 며칠이 남았는지 자주 물어봐요.

오늘 날짜와 회원권의 종료일을 받아서 오늘부터 종료일까지 남은 총일수를 반환하는 `FrontDesk.daysLeft()` 메서드를 구현해요.
종료일이 오늘이거나 이미 지났다면 남은 날이 없으므로 메서드는 `0`을 반환해요:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.daysLeft(LocalDate.of(2024, 1, 15), LocalDate.of(2024, 3, 20));
// => 65
frontDesk.daysLeft(LocalDate.of(2024, 4, 2), LocalDate.of(2024, 3, 20));
// => 0
```

## 4. 방문 시간 측정하기

센터는 24시간 운영하고, 개찰구는 회원이 체크인하고 체크아웃하는 날짜와 시간을 기록해요.

방문의 체크인 일시와 체크아웃 일시를 받아서 방문이 얼마나 오래 지속됐는지를 `Duration`으로 반환하는 `FrontDesk.visitDuration()` 메서드를 구현해요:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.visitDuration(LocalDateTime.of(2024, 3, 10, 23, 30), LocalDateTime.of(2024, 3, 11, 1, 15));
// => Duration.ofMinutes(105)
```

## 5. 영수증에 방문 시간 출력하기

영수증에는 방문 시간이 `1h 35m`처럼 시와 분으로 표시돼요.
분은 항상 두 자리로 쓰고, 초는 빼고, 시는 하루를 넘어가도 제한이 없어요.

방문 시간을 받아서 이 형식으로 반환하는 `FrontDesk.formatVisit()` 메서드를 구현해요:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.formatVisit(Duration.ofMinutes(95));
// => "1h 35m"
frontDesk.formatVisit(Duration.ofHours(2).plusMinutes(5));
// => "2h 05m"
frontDesk.formatVisit(Duration.ofHours(26).plusMinutes(10));
// => "26h 10m"
```
