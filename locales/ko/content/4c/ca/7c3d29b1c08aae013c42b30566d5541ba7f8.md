# 개요

[콘스][hyper-conses]는 Common Lisp의 기본 데이터 타입이에요. 콘스는 머리와 꼬리로 구성되는데, [역사적 이유][history]로 각각 `car`와 `cdr`라고 불려요. 
콘스의 머리와 꼬리에는 데이터 타입 제한이 없어요.

콘스는 [`cons`][hyper-cons] 함수로 만들어요. 이 함수는 두 객체를 받아 콘스로 평가돼요(때로는 '콘스 셀'이라고도 불려요).

콘스의 각 부분은 [`car`][hyper-car]와 [`cdr`][hyper-cdr] 함수로 접근할 수 있어요.

## 참고

```lisp
;; Testing for atoms
(atom 'foo)              ; => T
(atom '(bar baz))        ; => NIL

;; Testing for cons
(consp 'foo)             ; => NIL
(consp '(bar baz))       ; => T

;; First item of a cons
(car '(one two three))   ; => ONE
(first '(one two three)) ; => ONE

;; Rest of a cons
(cdr '(one two three))   ; => (TWO THREE)
(rest '(one two three))  ; => (TWO THREE)
```
