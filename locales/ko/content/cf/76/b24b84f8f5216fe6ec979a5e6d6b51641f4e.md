# 설치

## PowerShell 언어 트랙 요구 사항

Exercism의 PowerShell 언어 트랙을 사용하려면 시스템에 다음이 설치되어 있어야 해요:

- PowerShell 또는 Windows PowerShell Core
- Pester 테스트 및 모의 프레임워크 모듈 설치

(참고: PowerShell 지원은 중요한 수정 사항으로만 제한돼요. PowerShell Core는 꾸준히 유지 관리되고 크로스 플랫폼 지원도 더 넓어요)

### PowerShell 설치

PowerShell은 Windows 7 SP1 이후의 모든 Windows 운영 체제에 기본으로 설치되어 있어요.

최신 버전의 PowerShell과 모든 플랫폼(Linux, macOS, Windows)용 설치 안내는 [여기][installation]에서 볼 수 있어요.

[PowerShell][source-code]의 소스 코드와 수동 설치 방법도 제공돼요.

### Pester 프레임워크 설치 및 업데이트

[Pester][pester]는 PowerShell 테스트 프레임워크예요.
버전 4.0.9부터 Windows, Linux, MacOS의 PowerShell Core와 호환돼요(몇 가지 제한 사항이 있어요).

Windows 10에는 기본으로 설치되어 있지만, 다음 PowerShell 명령을 실행해 업데이트하는 걸 권장해요:

```PowerShell
Install-Module -Name Pester -Force -SkipPublisherCheck
```

이후 업데이트에는 다음을 실행해요:

```PowerShell
Update-Module -Name Pester
```

필요하다면 더 자세한 설치 안내를 다음에서 볼 수 있어요: [https://github.com/pester/Pester/wiki/Installation-and-Update]()

## IDE 사용하기

더 다양한 기능을 갖춘 편집 환경을 원한다면 IDE를 사용하는 게 좋아요.
다음은 PowerShell 프로젝트 빌드를 지원하는 가장 인기 있는 IDE예요:

### 모든 플랫폼

- [PowerShell ISE(Integrated Scripting Environment)][ise], PowerShell에 포함된 기본 제공 그래픽 IDE예요(Windows 전용).
  PowerShell ISE를 시작하려면 PowerShell 콘솔에 `powershell_ise.exe`를 입력해요.
- [PowerShell 확장][vsc-extension]을 설치한 [Visual Studio Code][vsc].
  Visual Studio Code에서는 테스트를 실행하고 코드를 디버그할 수도 있어요.
- [PowerShell 패키지][sublime-package]를 설치한 [Sublime Text 3][sublime].
