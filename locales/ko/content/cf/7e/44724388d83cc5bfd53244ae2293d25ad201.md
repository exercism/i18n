# 소개

함수를 사용하면 코드를 재사용할 수 있는 하나의 단위로 묶을 수 있어요.
함수는 `func` 키워드, 함수 이름, 그리고 괄호 안에 쉼표로 구분해 나열한 0개 이상의 매개변수와 타입으로 이루어져 있어요.

## 함수 매개변수

모든 매개변수는 타입을 명시해야 해요. 매개변수에는 타입 추론이 없어요.
매개변수에는 기본값이 없기 때문에 모든 함수 매개변수는 필수예요.

```go
import "fmt"

// No parameters
func PrintHello() {
    fmt.Println("Hello")
}

// One parameter
func PrintHelloName(name string) {
  fmt.Println("Hello " + name)
}
```

같은 타입의 매개변수는 하나로 묶어 선언하고, 뒤에 타입을 한 번만 적을 수 있어요.

```go
import "fmt"

func PrintGreetingName(greeting, name string) {
  fmt.Println(greeting + " " + name)
}
```

## 매개변수와 인자

자주 헷갈리는 두 용어, `parameters`와 `arguments`를 잠깐 짚어볼까요.
함수 매개변수는 함수 시그니처에 정의된 이름이에요. 예를 들어 위의 `PrintGreetingName` 함수에서 `greeting`과 `name`이에요.
함수 인자는 함수를 호출할 때 함수 매개변수에 전달되는 구체적인 값이에요.
예를 들어 아래 예제에서 `"Hello"`와 `"Katrina"`는 `greeting`과 `name` 매개변수에 전달된 인자예요.

```go
PrintGreetingName("Hello", "Katrina")
```

## 반환 값

함수 매개변수 뒤에는 0개 이상의 반환 값이 오는데, 이것도 타입을 명시해야 해요.
반환 값이 하나면 그대로 쓰고, 여러 개면 괄호로 감싸요.
값은 `return` 키워드를 사용해 함수에서 호출한 코드로 반환돼요.
하나의 함수에는 여러 개의 `return`문이 있을 수 있어요.
함수의 실행은 이 `return`문 중 하나를 만나는 즉시 끝나요.
함수에서 값을 여러 개 반환할 때는 쉼표로 구분해요.

```go
func Hello(name string) string {
  return "Hello " + name
}

func HelloAndGoodbye(name string) (string, string) {
  return "Hello " + name, "Goodbye " + name
}
```

## 함수 호출

함수를 호출할 때는 함수 이름을 쓰고, 괄호 안에 함수의 각 매개변수에 대한 인자를 전달해요.

```go
import "fmt"

// No parameters, no return value
func PrintHello() {
    fmt.Println("Hello")
}
// Called like this:
PrintHello()

// One parameter, one return value
func Hello(name string) string {
  return "Hello " + name
}
// Called like this:
greeting := Hello("Dave")

// Multiple parameters, multiple return values
func SumAndMultiply(a, b int) (int, int) {
    return a+b, a*b
}
// Called like this:
aplusb, atimesb := SumAndMultiply(a, b)
```

## 이름 있는 반환 값과 네이키드 리턴

매개변수와 마찬가지로 반환 값에도 이름을 붙일 수 있어요.
이름 있는 반환 값을 사용하면, 인자 없이 쓰는 `return`문이 그 값들을 반환해요.
이것을 '네이키드' 리턴이라고 해요.

```go
func SumAndMultiplyThenMinus(a, b, c int) (sum, mult int) {
    sum, mult = a+b, a*b
    sum -= c
    mult -= c
    return
}
```
