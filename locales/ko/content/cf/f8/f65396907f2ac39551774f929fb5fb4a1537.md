# 소개

이 연습 문제에서는 조건에 따라 로직을 실행해야 해요. C#에서 이걸 하는 가장 일반적인 방법은 `if/else`문을 사용하는 거예요:

```csharp
int x = 6;

if (x == 5)
{
    // Execute logic if x equals 5
}
else if (x > 7)
{
    // Execute logic if x greater than 7
}
else
{
    // Execute logic in all other cases
}
```

`if`문의 조건은 `bool` 타입이어야 해요. C#에는 _truthy_ 값이라는 개념이 없어요.
