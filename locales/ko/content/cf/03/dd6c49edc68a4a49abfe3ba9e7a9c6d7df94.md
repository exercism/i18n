# 소개

R의 `vector`는 같은 `mode`의 값들을 모아 놓은 것으로, `numeric`, `character` 등이 있어요. 서로 다른 타입의 입력을 주면 R은 그것들을 조용히 하나의 공통 타입, 보통 character로 변환하는데, 이 때문에 예상치 못한 결과가 나올 수 있어요.

## 벡터 만들기

값이 이미 다 준비되어 있다면 `c()`를 사용해요 ("concatenate" 또는 "combine"의 줄임말이에요):

```R
x <- 10
v <- c(4, 7, x)
```

`c()` 함수는 매우 유연해서, 다른 벡터나 범위를 입력으로 넣을 수도 있어요.
`c()`는 개수와 종류에 상관없이 입력을 받아서 하나의 벡터로 펼쳐 줘요.

## 범위

연속된 값(증가하거나 감소하는)의 범위를 나타내려면 `:` 표기법을 사용할 수 있어요.

```R
v <- 1:5 # equivalent to c(1, 2, 3, 4, 5)
w <- 10:7 # c(10, 9, 8, 7)
```

## 벡터 요소에 접근하기

많은 언어에서 그렇듯, 대괄호 안에 인덱스를 넣어 접근할 수 있어요:

```R
> v <- 4:7
> v[2]
[1] 5
> v[2:4]
[1] 5 6 7
```

그런데 조심해야 해요: ***R은 기본적으로 1부터 시작하는 인덱싱을 사용해요***.

이건 과학용 언어들(Fortran, Matlab, Julia)에서는 흔하지만, C와 그 뒤를 잇는 수많은 언어들의 0부터 시작하는 인덱싱과는 달라요.

범위는 위 예시에서처럼 쓸 수 있고, 굉장히 유연한 `c()` 함수 안에서도 쓸 수 있어요:

```R
v <- c(4, 7, 10)
w <- c(2, v[2:3], 11) # c(2, 7, 10, 11)
```

`vectors`는 (R의 대부분의 것들처럼) 변경 가능한 것으로 다룰 수 있어요. 비슷하게 유연한 문법으로 하나 또는 여러 요소에 값을 써넣을 수 있죠:

```R
> v <- 1:10
> v[2] <- 42
> v[4:6] <- c(11, 12, 13)
> v
 [1]  1 42  3 11 12 13  7  8  9 10
```

## 음수 인덱스

다른 언어에 익숙한 프로그래머라면 `v[-1]`이 벡터의 마지막 요소에 접근하는 방법이라고 짐작할지도 몰라요.
틀렸어요!

음수 인덱스는 사실 요소를 ***제거***해서 더 짧은 벡터를 반환하는 방법이에요:

```R
> v <- c(2, 4, 6)
> v[-2]
[1] 2 6  # second element gone
```
