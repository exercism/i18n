# 문자열 메서드

`String`에는 문자열을 조작할 수 있는 여러 메서드가 있어요.  
이 메서드들은 문자열 자체에서 호출하며, 문자열에 여러 작업을 수행하기 위해 종종 서로 연결해서 사용해요.

다음은 가장 흔히 쓰이는 메서드 일부를 정리한 목록이에요.
전체 메서드 목록은 [`String` API 문서][string-api]를 참고해요.

## String#upcase & String#downcase

[`upcase`][upcase] 메서드는 모든 문자를 대문자로 변환한 새 문자열을 반환해요.

```crystal
"hello".upcase
# => "HELLO"
```

[`downcase`][downcase] 메서드는 모든 문자를 소문자로 변환한 새 문자열을 반환해요.

```crystal
"HELLO".downcase
# => "hello"
```

## String#capitalize & String#camelcase & String#underscore & String#titleize

더 구체적인 대소문자 변환을 해주는 메서드도 여러 개 있어요.
문자열을 특정 형식으로 변환할 때 유용해요.
다음은 가장 흔히 쓰이는 메서드 일부를 정리한 목록이에요.

| 메서드                            | 설명                                                                                                        | 예시                                              |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------- |
| [`String#capitalize`][capitalize] | 첫 글자를 대문자로, 나머지는 소문자로 변환해요                                                   | `"hEllO" # => "Hello"`                               |
| [`String#camelcase`][camel-case]  | 밑줄 표기를 캐멀 케이스로 변환해요                                                                                   | `"eiffel_tower" # => "EiffelTower"`                  |
| `String#camelcase(lower: true)`   | `String#camelcase`와 같지만 첫 글자를 소문자로 남겨둬요                                                 | `"empire_state_building" # => "empireStateBuilding"` |
| [`String#underscore`][underscore] | 모든 문자를 소문자로 변환하고, 소문자와 대문자 사이에 밑줄을 넣어요 | `"PartyInTheUSA" # => "party_in_the_usa"`            |
| [`String#titleize`][titleize]     | 각 단어의 첫 글자를 대문자로, 나머지는 소문자로 변환해요                                                   | `"the great gatsBY" # => "The Great Gatsby"`         |

## String#sub & String#gsub

Crystal에는 문자열의 일부를 바꾸는 메서드가 있어요.
이들은 [`sub`][sub](_substitution_)와 [`gsub`][gsub](_global substitution_)라고 해요.

이 메서드들은 첫 번째 인자로 문자열, char, 정규식을 받을 수 있고, 두 번째 인자로 문자열이나 char를 받아요.
첫 번째 인자는 바꿀 문자열의 일부이고, 두 번째 인자는 대체할 값이에요.
`Char`와 정규식은 뒤의 개념에서 설명해요.

`sub` 메서드는 첫 번째 인자가 처음 나타나는 부분을 두 번째 인자로 바꿔요.

```crystal
"hello".sub("l", "r")
# => "herlo"
```

`gsub` 메서드는 `sub`와 같은 방식으로 동작하지만, 첫 번째 인자가 나타나는 모든 부분을 두 번째 인자로 바꿔요.

```crystal
"hello".gsub("l", "r")
# => "herro"
```

## String#chomp & String#strip

chomp와 strip은 문자열에서 원하지 않는 문자를 제거할 때 사용할 수 있어요.

[`chomp`][chomp] 메서드는 기본적으로 문자열 끝의 `\r`, `\n`, `\r\n` 문자를 제거해요.
인자와 함께 호출하면, 문자열 끝에 그 값이 있을 경우 문자열 끝에서 해당 값을 제거해요.

```crystal
"hello\n".chomp
# => "hello"

"hello".chomp("llo")
# => "he"
```

기본적으로 [`strip`][strip] 메서드는 문자열의 앞과 뒤에 있는 모든 공백을 제거해요.
인자와 함께 호출하면, 문자열의 앞이나 뒤에 그 인자가 있을 경우 제거해요.

```crystal
" hello ".strip
# => "hello"
```

## String#reverse

[`reverse`][reverse] 메서드를 사용해서 문자열을 뒤집을 수 있어요.
이 메서드는 문자를 역순으로 배치한 새 문자열을 반환해요.

```crystal
"hello".reverse
# => "olleh"
```

## String#index

[`index`][index] 메서드는 문자열에서 문자의 인덱스를 찾을 때 사용할 수 있어요.
`index` 메서드는 인자로 `String`, `Char`, 정규식을 받아요.
검색을 시작할 인덱스를 지정하는 선택적 두 번째 인자를 받을 수도 있어요.
`index` 메서드는 인자가 처음 나타나는 위치의 인덱스를 반환해요.

```crystal
"hello".index("l")
# => 2

"hello".index("l", 3)
# => 3
```

## String#delete_at

[`delete_at`][delete_at] 메서드를 사용해서 문자열에서 문자를 제거할 수 있어요.
`delete_at` 메서드는 인자로 인덱스를 받아서, 해당 인덱스의 문자를 제거해요.

```crystal
"hello".delete_at(0)
# => "ello"

"hello".delete_at(3)
# => "helo"
```

## String#insert

[`insert`][insert] 메서드는 특정 인덱스에 문자열을 삽입할 때 사용할 수 있어요.
`insert` 메서드는 첫 번째 인자로 인덱스를, 두 번째 인자로 문자열을 받아요.
`insert` 메서드는 해당 인덱스에 두 번째 인자를 삽입한 새 문자열을 반환해요.

```crystal
"hello".insert(0, "h")
# => "hhello"

"hello".insert(3, "l")
# => "helllo"
```
