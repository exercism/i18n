# 힌트

## 일반

- 공식 Getting Started 가이드에서 [charlists][getting-started-charlists], [유니코드와 코드 포인트][getting-started-code-points], [`case`][getting-started-case]에 대해 읽어봐요.
- elixirschool.com에서 [charlists][elixirschool-charlists]와 [`case`][elixirschool-case]에 대해 읽어봐요.

## 1. 소문자를 제외한 모든 문자를 제거해 기존 사용자 이름을 정리하기

- 재귀를 사용해 charlist를 순회해요.
- 주어진 값을 여러 패턴과 비교할 수 있게 해 주는 [내장 함수][kernel-case]가 있어요.
- 문자의 코드 포인트를 얻기 위한 [특별한 문법][syntax-reference-code-points]이 있어요. 이 문법은 가드에서 사용할 수 있어요.
- charlist는 코드 포인트의 리스트이고, 코드 포인트는 숫자이므로 서로 [비교][kernel-greater-than]할 수 있어요.
- 소문자 라틴 문자는 모두 알파벳 순서로 [연속된 코드 포인트][unicode-character-reference]를 가져요.
- 두 리스트를 연결할 수 있게 해 주는 [내장 함수][kernel-concat-list]가 있어요.

## 2. 밑줄 허용하기

- 문자의 코드 포인트를 얻기 위한 [특별한 문법][syntax-reference-code-points]이 있어요. 이 문법은 가드에서 사용할 수 있고, 구두점 문자에도 적용돼요.
- 두 리스트를 연결할 수 있게 해 주는 [내장 함수][kernel-concat-list]가 있어요.

## 3. 독일어 문자 대체하기

- 문자의 코드 포인트를 얻기 위한 [특별한 문법][syntax-reference-code-points]이 있어요. 이 문법은 가드에서 사용할 수 있고, ASCII가 아닌 문자에도 적용돼요.
- 두 리스트를 연결할 수 있게 해 주는 [내장 함수][kernel-concat-list]가 있어요.
