# 안내

Blorkemon™️ 카드에 대한 향수가 좀처럼 가라앉지 않네요. 다시 카드를 모으기 시작했고, 친구들까지 함께 끌어들이고 있어요.

이 연습 문제에서 카드 컬렉션은 `MapSet`으로 표현해요. 목표가 존재하는 모든 카드를 모으는 것이기 때문에 중복된 카드는 중요하지 않거든요.

## 1. 컬렉션 시작하기

친구들이 Blorkemon™️ 열풍에 함께하길 정말 바라죠. 가장 좋은 방법은 카드 한 장을 선물해서 친구의 컬렉션을 시작해 주는 거예요.

`GottaSnatchEmAll.new_collection`을 구현해요. 이 함수는 카드 한 장을 컬렉션으로 바꿔 줘요.

```elixir
GottaSnatchEmAll.new_collection("Newthree")
# => MapSet.new(["Newthree"])
```

## 2. 컬렉션 키우기

컬렉션을 한 번 만들면 컬렉션은 스스로 자라나기 시작해요.

`GottaSnatchEmAll.add_card`를 구현해요. 카드 한 장과 컬렉션을 받아서 두 값을 담은 튜플을 반환해요. 첫 번째는 카드가 이미 컬렉션에 있었는지 알려 주는 불리언이고, 두 번째는 카드를 추가한 컬렉션이에요.

```elixir
GottaSnatchEmAll.add_card("Scientuna", MapSet.new(["Newthree"]))
# => {false, MapSet.new(["Newthree", "Scientuna"])}
```

## 3. 교환 시작하기

이제 친구들이 다시 Blorkemon™️에 푹 빠졌으니, 카드를 교환하면서 자기 컬렉션을 키울 수 있어요.

모든 교환이 가치 있는 것도 아니고, 아예 할 수 없는 교환도 있어요.
가지고 있지 않은 카드는 교환할 수 없고, 이미 가지고 있는 카드와 교환해서도 안 돼요.

`GottaSnatchEmAll.trade_card`를 구현해요. 교환할 카드 두 장(내 카드와 상대 카드)과 현재 컬렉션을 받아요.
반환값은 두 값을 담은 튜플이에요. 교환이 가능하고 가치가 있는지 알려 주는 불리언과, 교환을 한다면 최종적으로 갖게 될 컬렉션이에요(실제로 교환이 불가능하더라도요).

```elixir
GottaSnatchEmAll.trade_card("Scientuna", "Newthree", MapSet.new(["Scientuna"]))
# => {true, MapSet.new(["Newthree"])}
```

## 4. 같은 카드는 하나씩만

벼룩시장에서 오래된 카드 더미를 발견했어요.
카드를 정렬하고 중복을 제거해서 내 컬렉션과 비교해야 해요.

`GottaSnatchEmAll.remove_duplicates`를 구현해요. 카드 목록을 정렬하고, 정렬된 고유 카드 목록을 반환해요.

```elixir
GottaSnatchEmAll.remove_duplicates(["Newthree", "Newthree", "Newthree", "Scientuna"])
# => ["Newthree", "Scientuna"]
```

## 5. 상대에게 없는 카드

이제 내 컬렉션에 뿌듯해할 시간이에요.

`GottaSnatchEmAll.extra_cards`를 구현해요. 내 컬렉션과 다른 컬렉션을 받아서, 상대 컬렉션에는 없는 카드의 개수를 반환해요.

```elixir
GottaSnatchEmAll.extra_cards(MapSet.new(["Scientuna"]), MapSet.new(["Newthree", "Scientuna"]))
# => 0
```

## 6. 모두가 가진 카드

Blorkemon™️에 열광하는 친구들과 모여서 어떤 카드가 가장 흔한지 궁금해해요.

`GottaSnatchEmAll.boring_cards`를 구현해요. 컬렉션 목록을 받아서, 모든 컬렉션이 가지고 있는 카드를 정렬한 목록을 반환해요.

```elixir
GottaSnatchEmAll.boring_cards([MapSet.new(["Scientuna"]), MapSet.new(["Newthree", "Scientuna"])])
# => ["Scientuna"]
```

## 7. 모든 카드

나와 친구들이 힘을 합치면 모든 Blorkemon™️ 카드를 가지고 있는 걸까요?

`GottaSnatchEmAll.total_cards`를 구현해요. 컬렉션 목록을 받아서, 모든 컬렉션에 있는 서로 다른 카드의 총개수를 반환해요.

```elixir
GottaSnatchEmAll.total_cards([MapSet.new(["Scientuna"]), MapSet.new(["Newthree", "Scientuna"])])
# => 2
```

## 8. 반짝이는 카드로 승리하기

조카가 곧 놀러 온다죠. 한번 멋진 모습을 보여주고 싶어요.
아이들은 반짝이는 걸 좋아하잖아요?
Blorkemon™️ 카드도 반짝일 수 있어요!

`GottaSnatchEmAll.split_shiny_cards`를 구현해요. 컬렉션을 받아서 정렬된 카드 목록 두 개를 담은 튜플을 반환해요. 하나는 `"Shiny"`로 시작하는 카드들이고, 다른 하나는 나머지 카드들이에요.

```elixir
GottaSnatchEmAll.split_shiny_cards(MapSet.new(["Newthree", "Scientuna", "Shiny Scientuna"]))
# => {["Shiny Scientuna"], ["Newthree", "Scientuna"]}
```
