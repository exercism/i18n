# 지시 사항

친구가 비밀 숫자를 맞혀 볼 수 있는 간단한 온라인 게임을 만들고 있어요. 어느 정도 피드백은 주고 싶지만, 추측만으로 정답을 알려 주고 싶지는 않아요. 추측이 비밀 숫자와 어떤 관계인지에 따라 서로 다른 응답을 돌려주는 함수를 만들어야 해요.

| 조건                                                  | 응답           |
| ----------------------------------------------------- | -------------- |
| 추측이 비밀 숫자와 일치할 때                          | "Correct"      |
| 추측이 비밀 숫자보다 하나 크거나 하나 작을 때         | "So close"     |
| 추측이 비밀 숫자보다 클 때                            | "Too high"     |
| 추측이 비밀 숫자보다 작을 때                          | "Too low"      |
| 추측을 하지 않았을 때                                 | "Make a guess" |

모든 추측과 비밀 숫자는 정수예요.

## 1. 추측이 비밀 숫자와 일치할 때 응답 만들기

정수인 두 인자 `secret_number`와 `guess`를 받는 `compare/2` 함수를 구현해요.

```elixir
GuessingGame.compare(5, 5)
# => "Correct"
```

## 2. 추측이 비밀 숫자보다 클 때 응답 만들기

`compare` 함수를 수정해서 비밀 숫자보다 큰 추측에도 응답하도록 해요.

```elixir
GuessingGame.compare(5, 8)
# => "Too high"
```

## 3. 추측이 비밀 숫자보다 작을 때 응답 만들기

`compare` 함수를 수정해서 비밀 숫자보다 작은 추측에도 응답하도록 해요.

```elixir
GuessingGame.compare(5, 2)
# => "Too low"
```

## 4. 추측이 비밀 숫자보다 하나 크거나 하나 작을 때 응답 만들기

`compare` 함수를 수정해서 비밀 숫자에 가까운 추측에도 응답하도록 해요.

```elixir
GuessingGame.compare(5, 6)
# => "So close"
GuessingGame.compare(5, 4)
# => "So close"
```

## 5. 추측이 없을 때 응답 만들기

`compare` 함수를 수정해서 추측이 없을 때도 응답하도록 해요.

```elixir
GuessingGame.compare(5)
# => "Make a guess"

GuessingGame.compare(5, :no_guess)
# => "Make a guess"
```
