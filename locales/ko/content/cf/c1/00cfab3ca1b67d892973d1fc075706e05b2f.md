# 소개

## 여러 절을 가진 함수

Elixir는 함수가 여러 개의 절을 가질 수 있게 해줘서 **개방-폐쇄 원칙**을 실천할 수 있어요. 그래서 길게 늘어지고 하드코딩된 제어 로직을 쓰는 대신, 동작을 쉽게 추가하거나 제거하는 목적에 맞는 함수를 작성할 수 있어요.

Elixir는 _여러 개의 함수 절_과 _가드_를 제공해서 다음과 같이 작성할 수 있어요:

```elixir
def number(n) when n == 7 do
  "Awesome, that's my favorite"
end

def number(_n) do
  "That's not my favorite"
end
```

실행 시점에 Elixir는 소스 파일의 위에서 아래로 어떤 함수 절을 호출할지 검사해요.

사용하지 않는 변수에는 밑줄을 앞에 붙여야 해요.

## 가드

가드는 인자를 가드 함수로 평가한 결과에 따라 Elixir가 함수를 호출하는 것을 막는 데 사용해요. 가드는 `when` 키워드로 시작하고, 그 뒤에 불리언 식이 와요. 가드 함수는 다음과 같은 특별한 함수예요:

- 순수해야 하고, 어떤 전역 상태도 변경하지 않아야 해요.
- 엄격한 `true` 또는 `false` 값을 반환해야 해요.

자주 쓰이는 가드 목록은 [Elixir 문서][kernel-guards]에서 볼 수 있어요. 여기에는 타입 검사, 기본 산술 연산, 비교, 그리고 엄격한 불리언 연산자가 포함돼요.

## 기본 인자

함수는 하나 이상의 인자에 기본값을 선언할 수 있어요. 다음 함수를 살펴봐요:

```elixir
def number(n \\ 13), do: "That's not my favorite"
```

컴파일하면 Elixir는 `number/0`(인자 없음)과 `number/1`(인자 하나)에 대한 함수 정의를 만들어요.

인자가 둘 이상 기본값을 가지면, 기본값은 왼쪽에서 오른쪽 순서로 적용되어 빠진 인자를 채워요.

함수에 절이 둘 이상 있으면, 기본 인자는 함수 절보다 앞에 있는 함수 헤더(본문이 없는 함수)에서 정의해야 해요:

```elixir
def number(n \\ 13)
def number(n) when n < 10, do: "Dream bigger!"
def number(n) when n > 100, do: "Not that big..."
```
