# 소개

오류는 생기기 마련이에요. Elixir에서는 흔히 "let it crash"라고 말하지만, 소프트웨어 계약을 지키기 위해 함수 호출을 복구해 알려진 정상 상태로 되돌려야 할 때도 있어요. 어떤 언어에서는 오류를 제어 흐름의 수단으로 사용하지만, Elixir에서는 이런 패턴을 권장하지 않아요. 오류를 발생시킬 수 있는 함수는 이름만 봐도 알아챌 수 있는 경우가 많아요. 오류를 발생시키는 함수는 이름 끝에 `!`를 붙여요. `{:ok, value}`나 `:error`를 반환하는 함수와는 다른 점이에요. 다음 라이브러리 예제를 살펴봐요:

```elixir
Map.fetch(%{a: 1}, :b)
# => :error
Map.fetch!(%{a: 1}, :b)
# => raises KeyError
```
