# 소개

## 예외

C#의 예외는 런타임 중에 발생하는 오류 상황을 구조적이고 일관되며 형식 안전한 방식으로 처리할 수 있게 해줘요. 애플리케이션이 충돌하지 않도록 하려면 예외와 오류를 적절히 처리하는 것이 중요해요.

C#에서 모든 예외의 기본 형식은 `System.Exception` 클래스예요. 여기에는 예외가 throw된 이유를 사람이 읽을 수 있게 설명하는 `Message` 같은 중요한 속성이 들어 있어요.

코드의 특정 부분에서 오류가 발생해야 함을 나타내려면 `throw` 키워드를 사용해 새 예외 객체를 만들고 throw해야 해요:

```csharp
using System;
static int Square(int number)
{
    if (number >= 46341)
    {
        throw new ArgumentException($"Argument {number} cannot be higher than 46340 as its' square doesn't fit into int type.");
    }
    return number * number;
}
```

예외가 throw되면 런타임은 그 예외 처리를 담당하는 코드 조각을 찾는 역할을 해요. 적절한 처리기를 찾지 못하면 런타임은 프로그램 실행을 중단하고, 처리되지 않은 예외 메시지를 표시해요.

예외에 대한 처리기를 만들기 위해 C#은 `try` 블록과 하나 이상의 `catch` 절로 구성된 try-catch 문을 사용해요. `try` 블록에는 예외가 throw될 수 있는 코드를 포함하고 보호해야 해요. `catch` 절에는 오류가 발생한 뒤 프로그램의 동작을 처리하는 코드가 들어 있어야 해요. `try` 블록 뒤에서는 예외의 순서가 중요하다는 점에 유의해야 해요. 여러 예외가 나열되면 처음 일치하는 `catch` 절이 실행되기 때문이에요.

```csharp
try
{
   if (number == 42)
   {
       throw new ArgumentException("The number cannot be equal to 42.", "number");
   }

   if (number < 0)
   {
      throw new ArgumentOutOfRangeException("number", "The number cannot be negative.");
   }

    // Process number ...
}
catch (ArgumentOutOfRangeException e)
{
    Console.WriteLine($"Number is out of range: {e.Message}.");
}
catch (ArgumentException)
{
    Console.WriteLine("Invalid number.");
}
```
