# 소개

Go에서는 `for`와 인덱스를 사용해 `slice`를 순회할 수도 있고, `range`를 사용할 수도 있어요. `range`를 사용하면 `map`도 순회할 수 있어요.

각 반복은 두 개의 값을 반환해요. 인덱스/키와, 그 인덱스/키에 있는 원소의 복사본이에요.

## 슬라이스 순회

아주 쉬워요. 슬라이스를 순회하면 예상한 순서대로 나와요.

```go
xi := []int{10, 20, 30}
for i, x := range xi {
  fmt.Println(i, x)
}
// outputs:
// 0, 10
// 1, 20
// 2, 30
```

## 맵 순회

맵을 순회할 때는 새로운 문제가 생겨요. 이제 순서가 무작위예요.

```go
hash := map[int]int{9: 10, 99: 20, 999: 30}
for k, v := range hash {
  fmt.Println(k, v)
}
// outputs, for example:
// 99 20
// 999 30
// 9 10
```

~~~~exercism/note
위 출력이 잘못된 것처럼 보일 수 있어요. 맵을 선언할 때 처음 등장한 키/값 쌍인 `9 10`이 마지막이 아니라 가장 먼저 출력될 거라고 생각하기 쉽거든요. 하지만 맵은 본질적으로 순서가 없어요. 처음이나 마지막 키/값 쌍이라는 게 없어요. 그래서 맵의 항목을 순회할 때 방문하는 순서는 무작위이고, 특별한 규칙을 따르지 않아요. 즉, 위와 같은 출력이 나올 수도 있지만 직접 실행해 보면 결과가 다를 수도 있어요. 이에 대해 더 알아보려면 [Go 언어 명세: range 절](https://go.dev/ref/spec#RangeClause)을 참고해요.
~~~~

## 키나 값 생략하기

Go에서는 사용하지 않는 변수가 있으면 빌드할 때 오류가 발생해요. 첫 번째 예시처럼 값만 필요할 때도 있어요.

```go
xi := []int{10, 20, 30}
for i, x := range xi {
  fmt.Println(x)
}
// Go build failed: i declared but not used
```

`i`를 `_`로 바꾸면, 컴파일러에게 그 값을 사용하지 않는다고 알려 줄 수 있어요.

```go
xi := []int{10, 20, 30}
for _, x := range xi {
  fmt.Println(x)
}
// outputs:
// 10
// 20
// 30
```

인덱스만 출력하고 싶다면 `x`를 `_`로 바꾸거나, 선언 자체를 생략하면 돼요.

```go
xi := []int{10, 20, 30}
// for i, _ := range xi {
for i := range xi {
  fmt.Println(i)
}
// outputs:
// 0
// 1
// 2
```

## 타입 정의하기

타입 정의는 새로운 이름의 타입을 만들어요. 이 타입은 같은 기반 타입을 가지고 있더라도 다른 모든 타입과 구별되는 별개의 타입이에요.

```go
type File []bool
```

여기서 `File`은 체스판의 세로줄 하나를 가리켜요. 보통 A부터 H까지 이름이 붙어 있죠. 이 세로줄에 있는 각 칸은 그 칸이 점유되었는지 아닌지를 나타내는 불리언 값으로 표현돼요. 이제 `File`이 정의되었으니 다른 정의 안에서도 사용할 수 있어요.

```go
type Chessboard map[string]File

board := Chessboard{
    "A": File{true, false, true},
    "B": File{false, true, false},
}
```

`Chessboard`는 세로줄 식별자를 `File` 값에 대응시켜요. 각 `File`은 하나의 체스 세로줄에 있는 칸들을 나타내는 불리언 값의 슬라이스예요. 이런 타입 정의가 없다면 `board`는 `map[string][]bool`이 되어서, 무엇을 나타내는지 이해하기가 더 어려워졌을 거예요.
