# 힌트

## 일반

- [비트스트링][bitstring]에 대해서는 시작하기 가이드에서 읽어보세요.
- [비트스트링 특수 형식][bitstring-form] 문서를 살펴보세요.
- [십진수를 이진수로 변환하는 방법][decimal-to-binary-youtube]을 복습해 보세요.
- Elixir는 이진 표기법을 포함해 [정수를 작성하는 여러 가지 방법][integer-literal]을 지원해요.

## 1. 팔레트 비트 크기 계산하기

- 이 작업에서는 비트스트링 데이터 타입을 사용하지 않아요.
- 2의 `n`제곱이 우리가 표현해야 하는 색상 수보다 크거나 같아지는 가장 작은 양수 `n`을 찾아보세요.
- 이를 위해 재귀 함수를 만들어 보세요.
- 시작 비트 크기를 1로 잡아요. 2의 비트 크기 제곱이 색상 수보다 크거나 같다면 비트 크기를 찾은 거예요. 그렇지 않다면 비트 크기에 1을 더하고 다시 확인해요(재귀).
- [거듭제곱 연산자 `**`][power-operator]를 사용해 2를 주어진 거듭제곱으로 올려요.

## 2. 빈 그림 만들기

- [비트스트링 특수 형식][bitstring-form]을 사용해 새로운 비트스트링을 만들어요.

## 3. 테스트 그림 만들기

- [비트스트링 특수 형식][bitstring-form]을 사용해 새로운 비트스트링을 만들어요.
- [타입 연산자][type-operator]를 사용해 각 조각의 비트 크기를 지정해요.

## 4. 그림 앞에 픽셀 추가하기

- [비트스트링 특수 형식][bitstring-form]을 사용하면 기존 비트스트링에 새로운 조각을 덧붙일 수 있어요.
- [타입 연산자][type-operator]를 사용해 새 조각과 기존 비트스트링의 비트 크기를 각각 지정해요.
- 앞서 구현한 `PaintByNumber.palette_bit_size/1` 함수를 사용해 새 조각의 비트 크기를 구해요.
- 특수 타입 `::bitstring`을 사용해 기존 조각의 크기를 알 수 없다고 지정해요.

## 5. 그림에서 첫 번째 픽셀 가져오기

- [비트스트링 특수 형식][bitstring-form]을 사용하면 [비트스트링을 패턴 매칭][bitstring-matching]할 수 있어요.
- 앞서 구현한 `PaintByNumber.palette_bit_size/1` 함수를 사용해 한 픽셀의 비트 크기를 구해요.
- 특수 타입 `::bitstring`을 사용해 나머지 비트스트링의 크기를 알 수 없다고 지정해요.

## 6. 그림에서 첫 번째 픽셀 버리기

- [비트스트링 특수 형식][bitstring-form]을 사용하면 [비트스트링을 패턴 매칭][bitstring-matching]할 수 있어요.
- 앞서 구현한 `PaintByNumber.palette_bit_size/1` 함수를 사용해 한 픽셀의 비트 크기를 구해요.
- 특수 타입 `::bitstring`을 사용해 나머지 비트스트링의 크기를 알 수 없다고 지정해요.

## 7. 두 그림 이어 붙이기

- [비트스트링 특수 형식][bitstring-form]을 사용하면 두 비트스트링을 이어 붙일 수 있어요.
- 특수 타입 `::bitstring`을 사용해 각 비트스트링 조각의 크기를 알 수 없다고 지정해요.
