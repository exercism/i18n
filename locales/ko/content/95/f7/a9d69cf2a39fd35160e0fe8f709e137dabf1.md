# 지침

런 렝스 인코딩과 디코딩을 구현해요.

런 렝스 인코딩(RLE)은 데이터 압축의 간단한 형태로, 연속된 데이터 요소인 런을 단 하나의 데이터 값과 개수로 대체해요.

예를 들어 원래 문자 53개를 단 13개로 표현할 수 있어요.

```text
"WWWWWWWWWWWWBWWWWWWWWWWWWBBBWWWWWWWWWWWWWWWWWWWWWWWWB"  ->  "12WB12W3B24WB"
```

RLE를 사용하면 압축된 데이터로부터 원래 데이터를 완벽하게 복원할 수 있어요. 그래서 무손실 데이터 압축이라고 해요.

```text
"AABCCCDEEEE"  ->  "2AB3CD4E"  ->  "AABCCCDEEEE"
```

간단하게 하기 위해, 인코딩되지 않은 문자열은 알파벳 A부터 Z까지(대문자와 소문자 모두)와 공백 문자만 담고 있다고 가정해도 돼요. 이렇게 하면 인코딩할 데이터에는 숫자가 전혀 들어 있지 않고, 디코딩할 데이터에 있는 숫자는 항상 뒤따르는 문자의 개수를 나타내요.
