# 자세히 알아보기

컬렉션 정의에는 보통 꺾쇠괄호 안에 자리 표시자가 들어가고, 관례적으로 흔히 T를 써요. 이런 컬렉션을 제네릭 타입이라고 해요. 이를 통해 컬렉션을 사용하는 사람이 컬렉션에 어떤 타입의 항목을 저장할지 지정할 수 있어요. 위 예제 코드에서는 문자열 배열을 인스턴스화하고 있어요.

클래스나 함수에 `@:generic` 속성을 붙이면 **제네릭**이 돼요. 그러면 컴파일러가 해당 클래스나 함수를 제네릭으로 인식해요.

```haxe
@:generic
class MyValue<T> {
  public var value:T;

  public function new(value:T) {
    this.value = value;
  }
}

var a = MyValue<String>("Hello");
trace(a.value); // Hello
```
