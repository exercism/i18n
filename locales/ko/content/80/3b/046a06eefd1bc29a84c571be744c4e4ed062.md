# 지침 추가

## 구현 참고 사항

Cipher 인터페이스의 정의는 `cipher.go`에 있어요.

구현은 Cipher 인터페이스를 따라야 해요.

```go
type Cipher interface {
    Encode(string) string
    Decode(string) string
}
```

`Encode`는 문자열에서 A-Za-z가 아닌 모든 값은 무시해요. 이런 값은 출력에 나타나지 않아요.
출력은 소문자로 정규화돼요.

암호를 얻는 데 사용하는 함수는 다음과 같아요:

```go
func NewCaesar() Cipher { }

func NewShift(distance int) Cipher { }

func NewVigenere(key string) Cipher { }
```

`NewShift`의 인자는 1에서 25 또는 -1에서 -25 범위여야 해요.
0은 허용되지 않아요.
인자가 유효하지 않으면 `NewShift`는 nil을 반환해요.

`NewVigenere`의 인자는 소문자 a-z로만 이루어져야 해요.
문자 'a'로만 이루어진 값은 허용되지 않아요.
인자가 유효하지 않으면 `NewVigenere`는 `nil`을 반환해요.
