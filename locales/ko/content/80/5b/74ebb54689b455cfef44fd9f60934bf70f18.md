# 문자

`CHAR`은 문자 하나이고, 작은따옴표 사이에 써요.

```sather
   c : CHAR := 'M';
```

## 특수 문자

어떤 문자는 직접 입력할 수 없어서 백슬래시로 써요.

| 쓰는 모양 | 뜻 |
| --- | --- |
| `'\n'` | 줄 바꿈 |
| `'\t'` | 탭 |
| `'\''` | 작은따옴표 |
| `'\\'` | 백슬래시 |

## 물어보기

```sather
'M'.is_alpha      -- true
'7'.is_digit      -- true
'M'.is_upper      -- true
' '.is_space      -- true
'M'.is_alphanum   -- true, a letter or a digit
```

## 대소문자

`.upper`와 `.lower`는 문자의 대소문자만 바꾸고 나머지는 그대로 둬요. 그래서 확인하지 않은 문자에도 안심하고 적용할 수 있어요.

## 숫자

```sather
'a'.int           -- 97
97.char           -- 'a'
```

`.int`과 `.char`는 정확히 반대예요. 번호 매김에 대해 알아 둘 만한 점은 `'a'`부터 `'z'`까지, `'A'`부터 `'Z'`까지, `'0'`부터 `'9'`까지가 각각 연속된다는 거예요. 그래서 다음과 같아요.

```sather
   c.int - 'a'.int          -- how far c is along the alphabet
   ('a'.int + n).char       -- the letter n places along
   d.int - '0'.int          -- the value of a digit character
```

## 한 바퀴 돌기

암호 바퀴는 `z`를 지나 다시 `a`로 돌아가요. `%` 연산자가 바로 그 일을 해요.

```sather
   ('a'.int + (c.int - 'a'.int + places) % 26).char
```

Sather의 `%` 연산자는 오른쪽 값이 양수일 때 절대 음수를 답하지 않아요. 그래서 바퀴를 앞으로 돌리든 뒤로 돌리든 이 방법이 통해요.

## 문자와 문자열

`STR`은 바이트의 나열이고, `CHAR`은 바이트 하나예요. 영어 텍스트에서는 바이트 하나가 글자 하나라서 `"Marlowe".size`는 7이고 `"Marlowe"[0]`은 `'M'`이에요. 악센트가 있거나 다른 알파벳을 쓰는 텍스트에서는 글자 하나가 여러 바이트를 차지할 수 있어서, 그 둘 중 어느 것도 성립하지 않아요.
