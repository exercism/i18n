# 지시사항

Lisp 외계인 릴리는 요리를 아주 좋아해요. 친구들과 피자 파티를 열고 싶은데, 재료를 최대한 알차게 쓰려면 시작하기 전에 재료가 각각 얼마나 필요한지 정확히 알고 싶어 해요.

이를 위해 릴리는 계획의 일부를 자동화할 프로그램을 대충 만들어 두었지만, 완성하는 데 도움이 필요해요.
릴리가 완벽한 비율의 피자 파티를 열 수 있도록 도와줄래요?

## 1. 반죽 비율

무엇보다도, 모든 훌륭한 피자는 맛있는 반죽에서 시작해요!

릴리는 가장자리 반죽이 두툼한, 얇고 바삭한 피자를 좋아해요.
가운데에 필요한 반죽은 항상 200g이고, 가장자리 20cm마다 반죽 45g이 필요해요.

다행히 릴리는 피자 개수(n)와 지름(d)으로 반죽의 그램 수(g)를 구하는 식을 계산해 두었어요:

`g = n * (((45 * pi * d) / 20) + 200)`

릴리에게는 이런 함수가 필요해요:
* 피자 개수(n)와 지름(d)을 받아서
* 필요한 반죽을 가장 가까운 그램 단위(g)로 반환해요.

예를 들어, 지름 30cm 피자 4판을 만들려면:

```lisp
(dough-calculator 4 30) ; => 1648
```

## 2. 소스 살짝

릴리는 소스를 바를 때 아주 꼼꼼하지만, 피자 크기는 일정하지 않을 수 있어요.

지름(d)을 알아내기 위해, 바른 소스의 양(s)을 변수로 한 다음 식을 사용해요:

`d = square-root of ((40 * s) / (3 * pi))`

릴리에게는 바른 소스의 밀리리터당 피자 지름(d)을 계산하는 함수가 필요해요.

예를 들어, 릴리가 소스 250ml를 사용했다면:

```lisp
(size-from-sauce 250) ; => 32.57
```

## 3. 치즈 좀 주세요

릴리의 행성에서는 모든 치즈가 완벽한 정육면체로 나오고, 크기별로 팔려요.
(뭘 기대했어요? 여긴 외계 행성이니까요...)

다시 한번, 릴리는 한 변의 길이가 l인 치즈 정육면체로 만들 수 있는, 지름 d인 피자의 개수(n)를 구하는 식을 계산했어요:

`n = (2 * (l^3)) / (3* pi * (d^2))`

이런 함수를 만들어 봐요:
* 치즈 정육면체의 한 변의 길이(l)와 피자의 지름(d)을 받아서,
* 만들 수 있는 피자 개수(n)를 내림해서 반환해요.

예를 들어, 25x25x25cm 치즈 정육면체와 지름 30cm 피자가 주어졌다면:

```lisp
(pizzas-per-cube 25 30) ; => 3
```

## 4. 공평한 몫

마지막으로, 릴리는 피자 한 판을 8조각으로 나눠서 친구들에게 똑같이 나눠 주고 싶어 해요.

이런 함수를 만들어 봐요:
* 피자 개수와 친구 수를 받아서
* 피자를 친구들에게 똑같이 나눌 수 있으면 `T`를, 그렇지 않으면 `NIL`을 반환해요.

예를 들어:

```lisp
;; For splitting 3 pizzas between 4 friends
(fair-share-p 3 4) ; => T
;; For splitting 2 pizzas between 3 friends
(fair-share-p 2 3) ; => NIL
```
