# 테스트

연습 문제를 다운로드하려면 터미널을 열고 다음 명령을 실행해요. 예를 들어 `hello-world`는 이렇게요:

```bash
exercism download --track roc --exercise hello-world
```

그다음 연습 문제 디렉터리로 이동해 코드를 수정하면서 문제를 풀어요. 예를 들어:

```bash
cd {your Exercism folder}/roc/hello-world
edit HelloWorld.roc
```

각 연습 문제에는 테스트 스위트가 함께 있어요. `roc test` 명령으로 테스트를 실행할 수 있어요. 예를 들어:

```
roc test hello-world-test.roc
```

연습 문제를 제대로 풀었다면 실패한 테스트가 0개로 표시돼요. 예를 들어:

```
All (5) tests passed in 123.4 ms.
```

하지만 코드에 오류가 있으면 다음과 같이 표시돼요:

```
── EXPECT FAILED in hello-world-test.roc ───────────────────────────────────────

This expectation failed:

6│  expect hello == "Hello, World!"
    ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^


1 failed and 0 passed in 123.4 ms.
```

이 내용이 코드를 고치는 데 도움이 될 거예요. 코드가 제대로 동작하면 `exercism submit` 명령으로 제출할 수 있어요. 자세한 내용은 연습 문제 디렉터리의 `HELP.md`를 참고해요.
