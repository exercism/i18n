# 힌트

## 1. 공백을 밑줄로 바꾸기

- [이 튜토리얼][chars-tutorial]이 도움이 돼요.
- [charAt][char-at] 메서드로 문자열에서 `char`를 가져올 수 있어요.
- 출력 문자열을 만들려면 [`StringBuilder`][string-builder]를 사용해요.
- 공백을 감지하는 메서드는 [Character][chars-docs] 문서에서 확인해요. 정적 메서드라는 점을 기억해요.
- `char` 리터럴은 작은따옴표로 감싸요.

## 2. 케밥 케이스를 카멜 케이스로 바꾸기

- 문자를 대문자로 바꾸는 메서드는 [Character][chars-docs] 문서에서 확인해요. 정적 메서드라는 점을 기억해요.

## 3. 리트스피크를 일반 텍스트로 바꾸기

- 문자가 숫자인지 감지하는 메서드는 [Character][chars-docs] 문서에서 확인해요. 정적 메서드라는 점을 기억해요.

## 4. 글자가 아닌 문자는 빼기

- 문자가 글자인지 감지하는 메서드는 [Character][chars-docs] 문서에서 확인해요. 정적 메서드라는 점을 기억해요.
