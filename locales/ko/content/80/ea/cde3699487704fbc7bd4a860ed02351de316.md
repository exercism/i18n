# 소개

`Rational numbers`는 정수 분자를 정수 분모로 나눈 분수예요.

예를 들어 `2//3`을 근삿값인 `Float64` 값 `0.6666...` 대신 정확한 분수로 저장할 수 있어요.

장점은 (*integer overflow*라는 극단적인 경우만 빼면) 유리수가 정확한 값을 그대로 유지해서, 부동소수점 수에서 흔히 피할 수 없는 반올림 오류를 피할 수 있다는 점이에요.

유리수는 아주 단순한 숫자 타입이고, 기대하는 대로 동작하도록 만들어졌어요.
초기 버전부터 Julia의 표준 타입이었기 때문에, 대부분의 함수가 정수나 실수에서처럼 유리수도 입력으로 받아요.

## 유리수 만들기

만드는 방법은 간단해요. 두 정수 사이에 `//`를 쓰면 돼요.

```julia-repl
julia> 3//4
3//4

julia> a = 3; b = 4;

julia> a//b
3//4
```

공통 인수는 자동으로 제거되어 분수가 "가장 간단한 형태"로 바뀌어요. 즉, 그 분수를 정확히 나타내는 가장 작은 정수들이 되고, 분모는 음수가 아니에요.

```julia-repl
julia> 5//15
1//3

julia> 5//-15
-1//3
```

## 유리수의 계산

일반적인 `arithmetic operators`인 `+ - * / ^ %`는 유리수에서도 다른 숫자 타입과 거의 똑같이 동작해요.

정수와 다른 `Rational`들을 함께 써도 결과는 `Rational`이에요.
식에 `float`을 포함하면 결과도 `float`이 되고, 그에 따라 정밀도가 (어쩌면) 떨어질 수 있어요.

`float`이 필요하면 그냥 `float()` 함수로 유리수를 변환하면 돼요.
긴 계산 동안 정밀도를 유지하려고 유리수를 쓰고, 마지막에 실수로 변환하는 건 아주 흔한 일이에요.

```julia-repl
julia> 3//4 + 1//3  # addition
13//12

julia> 3//4 * 1//3  # multiplication
1//4

julia> 3//4 / 1//3  # division
9//4

julia> 3//4 ^ 2  # exponentiation
3//16

julia> 3//4 + 5  # rational and int => rational
23//4

julia> 3//4 + 5.3  # rational and float => float
6.05

julia> float(3//4)  # casting
0.75
```

## 그 밖의 연산

Julia에서 유리수는 그냥 숫자예요.
컴파일러가 보통 필요에 따라 타입을 변환해 줘요.

다만 비교는 유한 소수로 나타낼 수 있는 분수에서만 기대한 대로 동작하니 주의해요.

```julia-repl
julia> 3//4 == 0.75
true

julia> 3//4 < 0.74
false
```

그 밖의 경우에는 비교하려면 `Rational`을 `Float`로 변환해야 해요.

```julia-repl
julia> 1//3 == 1/3
false

julia> float(1//3) == 1/3
true
```

수학 함수는 유리수를 입력으로 받지만, 부동소수점 결과를 내놓을 수도 있어요.

```julia-repl
julia> sqrt(9//16)
0.75
```
