# 소개

## R의 불리언

참 또는 거짓 값은 `logical` 타입으로 표현해요.
이 타입에는 `TRUE`와 `FALSE` 두 가지 값만 있어요.

```R
TRUE
#> [1] TRUE
FALSE
#> [1] FALSE
typeof(TRUE)
#> [1] "logical"
```

## 불리언 연산자

R에는 다섯 가지 불리언 연산자가 있지만, 이 단계의 교육 과정에서는 세 가지만 관련이 있어요.
나머지 두 개는 벡터를 다룰 때 중요해요. 벡터는 이후 여러 개념에서 다뤄요.

`&&`는 불리언 "and"예요.
`&&`의 *양쪽*에 있는 식이 `TRUE`이면 `TRUE`로 평가돼요.

```R
TRUE && TRUE
#> [1] TRUE
TRUE && FALSE
#> [1] FALSE
```

`||`는 불리언 "or"예요.
`||`의 *어느 한쪽* 식이 `TRUE`이면 `TRUE`로 평가돼요.

```R
TRUE || TRUE
#> [1] TRUE
FALSE || TRUE
#> [1] TRUE
```

`!`는 불리언 "not"이에요.
`TRUE`와 `FALSE` 값을 서로 바꿔요.

```R
!TRUE
#> [1] FALSE
!FALSE
#> [1] TRUE
```

더 길고 복잡한 식에서는 의도를 분명히 하기 위해 괄호를 사용하는 게 좋아요.

```R
(TRUE || FALSE) && (FALSE && TRUE)
#> [1] FALSE
```
