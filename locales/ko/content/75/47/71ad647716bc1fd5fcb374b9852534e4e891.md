# 테스트

각 연습 문제는 단위 테스트를 제공해요.
구현은 직접 작성해요.
각 파일은 테스트를 실행하는 콘솔 실행 파일을 만들어요.
테스트 실행 파일을 실행하면 실패한 테스트마다 메시지를 출력하고, 테스트가 실패하면 0이 아닌 종료 상태를 보고해요.

*참고* 프로젝트를 빌드할 때마다 코드가 테스트 스위트에 대해 테스트돼요.
코드가 하나 이상의 테스트를 통과하지 못하더라도 유효한 D 코드라면 여전히 컴파일돼요.

각 연습 문제를 풀어 나가는 과정은 다음과 같아요:

* `dub test`로 테스트를 실행해요
  * DUB를 설치하지 않기로 했다면, 대신 `dmd source/*.d -de -w -main -unittest`를 사용한 다음, 만들어진 실행 파일을 실행해요.
* 각 단위 테스트마다:
  * 컴파일 오류를 해결해 테스트가 실패하도록 만들어요.
  * 테스트를 통과할 만큼만 구현해요.
  * 가독성을 높이고 중복을 줄이는 등, 구현을 리팩터링해요.
  * 다음 테스트를 활성화해요

*참고:* D는 언어 자체에서 단위 테스트를 지원하기 때문에, 보통 단위 테스트는 구현과 같은 파일에 있어요.
단위 테스트는 main 본문보다 먼저 실행되며, 최종 실행 파일에서는 **-unittest** 컴파일러 스위치를 사용해 활성화돼요.
