# Entry API

Entry API는 맵 구조의 내용을 다룰 때 가장 관용적인 방법인 경우가 많아요. 그런데 Rust에서는 드물게도 이것이 트레이트로 정형화되어 있지 않고, 표준 라이브러리의 맵 타입들에 구현된 일련의 타입과 메서드일 뿐이에요.

기본적으로 `map.entry()` 메서드는 `enum`을 하나 제공해요:

```rust
enum Entry {
    Occupied(_),
    Vacant(_),
}
```

그 유용함은 이 enum에 구현된 여러 메서드에서 나와요. 예를 들어, 특정 키의 값을 가져오면서 값을 바꿀 수도 있고, 그 값 타입의 기본값이 적절하다면, 그냥 이렇게 하면 돼요:

```rust
// `entry` has type `&mut Value` for the value type of the map
let entry = map.entry(key).or_default();
```

카운터 같은 용도라면 이게 아주 편해요:

```rust
let counts: HashMap<_, usize> = HashMap::new();
for item in sequence {
    *counts.entry(item).or_default() += 1;
}
```

타입의 기본값이 여러분의 용도에 맞지 않는다면, `or_insert`로 자신만의 상수 기본값을 지정하거나, `or_insert_with`로 계산할 수 있어요.

어떤 경우에는 삽입이 일어나기 전에 기존 값에 대한 계산을 하고 싶을 수 있어요. 그럴 때 `and_modify`가 이를 가능하게 해줘요. 다만 이런 용도는 다소 드물어요. `and_modify`는 역참조를 피하기 위해 더 흔히 쓰여요:

```rust
map.entry(key).and_modify(|v| *v += 1).or_default();
```

때때로 entry를 직접 match하는 게 좋을 때가 있어요. 이건 허용돼요:

```rust
match map.entry(key) {
    Entry::Occupied(occupied) => println!("removed from the map: {:?}", occupied.remove_entry()),
    Entry::Vacant(vacant) => println!("key not present in map: {:?}", vacant.key()),
}
```

더 자세한 내용은 [`std::collections::hash_map::Entry`](https://doc.rust-lang.org/std/collections/hash_map/enum.Entry.html)와 [`std::collections::btree_map::Entry`](https://doc.rust-lang.org/std/collections/btree_map/enum.Entry.html)를 참고해요.
