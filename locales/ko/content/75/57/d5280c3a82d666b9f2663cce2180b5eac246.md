# 소개

`Option`은 함수의 반환값이 유효한지 확인할 때 사용하는 열거형이에요. 다음과 같이 정의해요:

```haxe
enum Option<T> {
  Some(v:T);
  None;
}
```

`haxe.ds` 패키지에 속해 있어요:

```haxe
import haxe.ds.Option;

class Main {
  static public function main() {
    var result = trySomething();

    switch (result) {
      case None:
        trace("Nothing");
      case Some(s):
        trace("Got: " + s);
    }
  }

  static public function trySomething():Option<String> {
    if (Math.random() > 0.5) {
      return None;
    } else {
      return Some("Success");
    }
  }
}
```
