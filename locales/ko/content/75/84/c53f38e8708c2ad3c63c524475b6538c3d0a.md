# 안내

Conda Airlines는 하루에 10,000편이 넘는 항공편을 운항하는, 프로그래밍 세계에서 가장 큰 항공사예요!

지금은 모든 좌석을 승객에게 일일이 손으로 배정하고 있는데, 이 작업은 자동화가 필요해요.

그래서 승객 좌석 배정을 자동화할 소프트웨어를 만들어 달라고 _여러분_에게 요청했어요.
이 소프트웨어는 메모리 효율이 좋고 성능도 뛰어나야 해요.

## 1. 좌석 문자 생성하기

Conda는 비행기의 좌석 문자를 만들고 싶어 해요.
비행기는 좌석이 여러 행으로 이루어져 있어요.
각 행에는 좌석이 _네 개_ 있어요.
각 행의 좌석 이름은 항상 `A`, `B`, `C`, `D`예요.
행의 첫 번째 좌석은 `A`, 두 번째 좌석은 `B`, 이런 식으로 이름이 붙어요.
`D`까지 가면 다시 `A`부터 시작해요.

생성할 좌석 문자의 개수를 담은 `int`를 인자로 받는 `generate_seat_letters(<number>)` 함수를 구현해요.
그러면 함수는 좌석 문자를 담은 _이터러블_을 반환해야 해요.

```python
>>> letters = generate_seat_letters(4)
>>> next(letters)
"A"
>>> next(letters)
"B"
```

## 2. 좌석 생성하기

Conda Airlines는 비행기에 필요한 만큼의 좌석을 만들어 내는 시스템을 원해요.
각 비행기는 행마다 좌석이 _네 개_ 있어요.
행은 `1`부터 시작해서 숫자가 하나씩 커지는 방식으로 나타내요.
좌석은 `1A`, `1B`, `1C`, `1D`, `2A`, `2B`, `2C`, `2D`, `3A`, `3B`, `3C`, `3D`, ... 순서로 정렬되어야 해요.

예시를 볼까요:

|      x      |  1  |  2  |
| :---------: | :-: | :-: |
|     행      |  5  | 21  |
|  좌석 문자  |  A  |  D  |
|    결과     | 5A  | 21D |

많은 항공사는 승객들의 미신 때문에 13번 _행_을 두지 않아요.
Conda Airlines도 이 관례를 따르니, 13번 _행_의 좌석은 만들지 _않도록_ 해요.

생성할 좌석의 개수를 담은 `int`를 인자로 받는 `generate_seats(<number>)` 함수를 구현해요.
그러면 함수는 만들어진 좌석을 담은 _이터러블_을 반환해야 해요.

```python
>>> seats = generate_seats(10)
>>> next(seats)
"1A"
>>> next(seats)
"1B"
```

## 3. 승객에게 좌석 배정하기

이제 좌석을 생성하는 함수가 있으니, 이 함수로 승객에게 좌석을 배정할 수 있어요.

승객 이름이 담긴 `list`를 인자로 받는 `assign_seats(<passengers>)` 함수를 구현해요.
그러면 함수는 `passenger`를 _키_로, `seat_number`를 _값_으로 갖는 _딕셔너리_를 반환해야 해요.

```python
>>> passengers = ['Jerimiah', 'Eric', 'Bethany', 'Byte', 'SqueekyBoots', 'Bob']

>>> assign_seats(passengers)
{'Jerimiah': '1A', 'Eric': '1B', 'Bethany': '1C', 'Byte': '1D', 'SqueekyBoots': '2A', 'Bob': '2B'}
```

## 4. 티켓 코드

Conda Airlines는 티켓마다 고유한 코드를 부여하고 싶어 해요.
규모가 큰 항공사인 만큼 운항하는 항공편도 아주 많아요.
그래서 같은 좌석 번호를 가진 항공편이 여러 개 있을 수 있어요.
그래서 _12_자 길이의 고유한 티켓 문자열을 만들어 내는 시스템을 원해요.

이 코드는 `assigned_seat`로 시작하고, 그 뒤에 `flight_id`가 와요.
나머지 부분은 `0s`로 채워요.

`seat_numbers`가 담긴 `list`와 항공편 번호가 담긴 `string`을 인자로 받는 `generate_codes(<seat_numbers>, <flight_id>)` 함수를 구현해요.
그러면 함수는 `ticket_number`를 만들어 내는 `generator`를 반환해야 해요.

```python
>>> seat_numbers = ['1A', '17D']
>>> flight_id = 'CO1234'
>>> ticket_ids = generate_codes(seat_numbers, flight_id)

>>> next(ticket_ids)
'1ACO12340000'
>>> next(ticket_ids)
'17DCO1234000'
```
