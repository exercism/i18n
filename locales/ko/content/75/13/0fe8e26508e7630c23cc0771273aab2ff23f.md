# 힌트

## 1. `Coord` 타입 정의하기

- `Coord`는 `struct`로 정의해요.
- 필드는 `x`와 `y`예요.
- 둘 다 `UInt16` 타입이에요.

## 2. `Plot` 타입 정의하기

- `Plot`은 `struct` 키워드로 정의해요.
- 필드는 `bottom_left`와 `top_right`예요.
- 둘 다 `Coord` 타입이에요.

## 3. 점유 신청이 이미 접수되었는지 확인하기

- 점유 신청이 이미 `register`의 원소인가요?
- 필요하다면 [`Sets`][sets]에 대한 내용을 다시 살펴봐요.

## 4. 투기꾼이 모서리 좌표로 식별되는 구획을 지정해 점유 신청하기

- 같은 점유 신청이 이미 접수되어 있다면, 신청이 실패했음을 나타내는 `false`를 반환해요.
- 신청이 허용되면, register에 점유 신청을 추가해요. [`push!()`][push] 함수가 유용할 거예요.
- `stake_claim!()`은 값을 변경하는 함수이기 때문에, `register`의 변경 사항은 호출한 쪽에도 보여요.
- `claim.bottom_left.x`처럼 점 표기법을 연쇄해서 사용할 수 있어요.
- 성공했음을 나타내는 `true`를 반환해요.

## 5. 구획의 더 긴 변의 길이 구하기

- 이 직사각형 구획들의 방향을 기억해요. `top_left`와 `bottom_right` 좌표를 추론할 수 있어요.
- 변의 길이를 계산하는 건 간단한 산수예요.
- [`max()`][max]와 [`maximum()`][maximum]의 차이에 주의해요. `max`는 비교할 인자를 임의의 개수만큼 받고, `maximum`은 반복 가능한 객체 하나를 받아요.

```julia-repl
julia> max(1, 2, 3)
3

julia> v = [1, 2, 3];
julia> maximum(v)
3
```

## 6. 연구 목적으로 가장 긴 변을 가진 점유 신청 구획 찾기

- register는 Set이고, 순서는 없지만 반복할 수 있어요.
  - register를 순서가 있는 형태로 변환하면 편리할 수 있어요. 예를 들어 `collect()`를 사용할 수 있어요.
  - 구획의 가장 긴 변을 계산하는 함수를 이미 작성했으니, 이를 전체 컬렉션에 적용할 수 있어요.
- `max`와 `maximum`의 차이에 대한 설명은 5번 작업을 참고해요.
- 최대 길이를 가진 구획을 하나 이상 찾아요.
- 결과를 `Set{Plot}` 타입으로 반환해요.
