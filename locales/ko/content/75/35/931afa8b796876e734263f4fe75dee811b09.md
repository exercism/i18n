# 지침

두 배열 `A`와 `B`가 주어졌을 때, 다음 중 어느 것인지 판별해요:

- 배열 `A`가 배열 `B`와 같아요 (equal); 또는
- 배열 `A`가 배열 `B`를 포함해요 (`A`는 `B`의 superlist예요); 또는
- 배열 `A`가 배열 `B`에 포함돼요 (`A`는 `B`의 sublist예요); 또는
- 위 어느 것도 참이 아니어서 배열 `A`와 `B`는 서로 달라요 (unequal)

구체적으로, 두 배열이 같은 순서로 같은 값을 가지고 있으면 배열 `A`와 `B`는 같아요 (equal).
`A`가 `B`와 값이 같은 부분 수열을 포함하고 있으면 `A`는 `B`의 superlist예요.
`B`가 `A`와 값이 같은 부분 수열을 포함하고 있으면 `A`는 `B`의 sublist예요.

예시:

- `A = []`이고 `B = []`이면 (두 배열 모두 비어 있어요), `A`와 `B`는 같아요 (equal)
- `A = [1, 2, 3]`이고 `B = []`이면, `A`는 `B`의 superlist예요
- `A = []`이고 `B = [1, 2, 3]`이면, `A`는 `B`의 sublist예요
- `A = [1, 2, 3]`이고 `B = [1, 2, 3, 4, 5]`이면, `A`는 `B`의 sublist예요
- `A = [3, 4, 5]`이고 `B = [1, 2, 3, 4, 5]`이면, `A`는 `B`의 sublist예요
- `A = [3, 4]`이고 `B = [1, 2, 3, 4, 5]`이면, `A`는 `B`의 sublist예요
- `A = [1, 2, 3]`이고 `B = [1, 2, 3]`이면, `A`와 `B`는 같아요 (equal)
- `A = [1, 2, 3, 4, 5]`이고 `B = [2, 3, 4]`이면, `A`는 `B`의 superlist예요
- `A = [1, 2, 4]`이고 `B = [1, 2, 3, 4, 5]`이면, `A`와 `B`는 서로 달라요 (unequal)
- `A = [1, 2, 3]`이고 `B = [1, 3, 2]`이면, `A`와 `B`는 서로 달라요 (unequal)
