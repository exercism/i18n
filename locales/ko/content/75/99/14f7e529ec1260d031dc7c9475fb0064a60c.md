# 학습

[공식 Unison 언어 문서](https://www.unison-lang.org/learn/fundamentals/values-and-functions/terms/)는 학습을 시작하기에 아주 좋은 곳이에요. 함수, 데이터 타입, 대수적 효과처럼 Unison의 기본 개념을 자세히 다뤄요.

명령줄에서 Unison Codebase Manager로 작업하고 있다면, [Exercism 연습 문제를 실행하고 테스트하는 워크플로를 다룬 영상](https://www.youtube.com/watch?v=4UMaaiJnWGY)을 준비해 두었어요.

참고 자료로는 [Unison 언어 레퍼런스](https://www.unison-lang.org/learn/language-reference/top-level-declaration/)에 Unison 기능에 대한 세부 내용이 담겨 있어요. 각 기능은 웹사이트 사이드바에 정리돼 있어요.

[Unison Share](https://share.unison-lang.org/)는 공개 라이브러리와 프로젝트를 위한 Unison의 저장소예요. 한번 익숙해져 두면 좋겠죠. 표준 라이브러리인 [`base`](https://share.unison-lang.org/@unison/code/latest/namespaces/public/base/latest)의 문서에는 유용한 사용법 정보가 담겨 있어요.

👋 막히는 부분이 있으면 언제든 도와드릴게요. [공식 Unison Discord 서버](https://unison-lang.org/discord)의 #beginner-friendly 채널에는 친절한 사람들이 가득해요.
