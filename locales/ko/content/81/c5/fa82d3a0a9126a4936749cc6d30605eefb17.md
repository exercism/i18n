# 지침

마을에 새로운 시 동아리가 문을 열었고, 이제 가입해 볼까 생각 중이에요.
과거에 몇 번 문제가 있었던 탓에, 이 동아리는 들어가기 전에 꼭 익혀야 하는 아주 까다로운 출입 규칙을 두고 있어요.

시 동아리에는 앞문과 뒷문, 두 개의 문이 있고 둘 다 문지기가 지키고 있어요.
들어가려면 그날의 비밀번호를 알아내야 해요.

비밀번호는 항상 시를 바탕으로 하고, 두 단계를 거쳐 만들어져요.

1. 문지기가 시를 한 행씩 읊어 주면, 그 행에서 알맞은 글자로 답해야 해요.
2. 그러면 문지기가 지금까지 답한 글자들을 한꺼번에 알려 주고, 그 글자들을 정해진 형식에 맞춰 종이에 적어야 해요.

과정의 세부 사항은 어느 문으로 들어가려는지에 따라 달라요.

~~~~exercism/note
이 연습 문제의 모든 문자열은 ASCII로 인코딩되고 NUL로 끝나요.
즉, 모든 문자는 ASCII 인코딩을 사용하고, 모든 문자열은 '\0'(값이 `0`인 NUL 문자)이 나오는 지점에서 끝나요.
~~~~

~~~~exercism/note
이 개념에서 언급하는 문자열 명령어는 다음과 같아요:

| 명령어  | 하는 일                                                                                                            |
|--------------|-------------------------------------------------------------------------------------------------------------------|
| `lods`       | `rsi`가 가리키는 메모리 위치에서 값을 읽어 `rax`에 넣어요                                                          |
| `stos`       | `rax`의 값을 `rdi`가 가리키는 메모리 위치에 저장해요                                                                |
| `movs`       | `rsi`가 가리키는 메모리 위치에서 값을 복사해 `rdi`가 가리키는 메모리 위치에 저장해요                                |

이 명령어들에는 모두 연산의 크기를 나타내는 접미사가 붙어야 해요:

| 접미사 | 크기             |
|--------|------------------|
| `b`    | byte             |
| `w`    | word (2 bytes)   |
| `d`    | dword (4 bytes)  |
| `q`    | qword (8 bytes)  |

또한 모든 문자열 명령어는 `rsi`와/또는 `rdi`의 주소를 바꿔요(그 명령어가 사용하는 레지스터에만 해당해요).
기본적으로는 연산의 크기만큼 주소를 증가시켜요.

위의 문자열 명령어에는 `rep` 접두사를 붙일 수 있는데, `rcx`에 해당하는 횟수만큼 그 명령어를 반복해요.
~~~~

## 1. 문장의 첫 글자 가져오기

앞문 비밀번호의 글자들을 알아내려면, 문지기가 읊어 주는 시의 각 행에서 첫 글자로 답해야 해요.

멋진 비밀번호를 만들기 위해, 시 동아리 회원들은 _이합체시_를 즐겨 써요.
이 시는 각 문장의 첫 글자를 모으면 하나의 단어가 돼요.
그들이 가장 좋아하는 작가 중 한 명인 Michael Lockwood의 예시를 볼까요.

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

그래서 문지기가 **Stands so high**를 읊으면 **S**라고 답하고, 문지기가 **Huge hooves too**를 읊으면 **H**라고 답해요.

시의 한 행이 저장된 메모리 주소를 인자로 받아 그 행의 첫 글자를 반환하는 `front_door_response` 함수를 구현해요.
이 글자는 1바이트를 차지하는 ASCII 인코딩 문자로 반환해야 해요.

```c
front_door_response("Stands so high");
// => 'S'
```

## 2. 단어를 대문자로 만들기

이제 올바른 글자들을 모두 모았으니, 앞문 비밀번호를 얻으려면 그 단어를 올바르게 대문자로 만들기만 하면 돼요.

1번 문제에서 찾은 글자들을 합친 문자열이 저장된 메모리 주소를 인자로 받는 `front_door_password` 함수를 구현해요.
이 함수는 입력 문자열을 [제자리에서][in-place] 수정해서 올바르게 대문자로 만들어야 해요.
즉, 올바른 문자열이 입력과 같은 메모리 위치에 저장되어야 해요.

이 함수는 반환값이 없어요.

```c
front_door_password('SHIRE');
// => buffer == "Shire"

front_door_password('shire');
// => buffer == "Shire"
```

## 3. 문장의 마지막 글자 가져오기

뒷문 비밀번호의 글자들을 알아내려면, 문지기가 읊어 주는 시의 각 행에서 마지막 글자로 답해야 해요.

시 동아리 회원들은 정말 영리해요.
앞에서 언급한 시는 _텔레스티크_이기도 한데, 이는 각 문장의 마지막 글자를 모아도 하나의 단어가 된다는 뜻이에요:

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

문지기가 **Stands so high**를 읊으면 **h**라고 답하고, 문지기가 **Huge hooves too**를 읊으면 **o**라고 답해요.

문지기가 시를 읊을 때 문장 부호나 공백 같은 형식적인 쉼을 넣기도 한다는 점에 주의해요.
올바른 글자를 찾아내려면 그런 쉼은 무시해야 해요.

시의 한 행이 저장된 메모리 주소를 인자로 받아 그 행의 마지막 글자를 반환하는 `back_door_response` 함수를 구현해요.
이 글자는 1바이트를 차지하는 ASCII 인코딩 문자로 반환해야 해요.

```c
back_door_response('Stands so high');
// => "h"

back_door_response('Stands ... so high   ');
// => "h"
```

## 4. 예의를 갖추기

뒷문으로 시 동아리에 들어가려면 특히 예의를 갖춰야 해요.
그래서 이번에는 비밀번호를 만들 때 단어를 올바르게 대문자로 만들고 끝에 `", please."`를 붙여야 해요.

다음 순서대로 인자를 받는 `back_door_password` 함수를 구현해요:

1. 결과 문자열이 저장될 버퍼의 메모리 주소.
2. 3번 문제에서 찾은 글자들을 합친 문자열이 저장된 메모리 주소.

이 함수는 대문자로 만든 비밀번호의 정중한 버전을 [버퍼][buffer]에 저장해야 해요.
_버퍼_는 메모리에 값을 저장해 두었다가 서로 다른 함수 사이에서 옮기는 데 사용할 수 있는 배열이에요.

이 함수는 반환값이 없어요.

```c
back_door_password("horse");
// => "Horse, please."
```
