# 안내 추가

## 레지스터

| 레지스터 | 용도        | 타입    | 설명                    |
| -------- | ----------- | ------- | ----------------------- |
| `$a0`    | 입력        | 정수    | 삼각형의 행 수          |
| `$a1`    | 입출력      | 주소    | 워드 배열               |
| `$v0`    | 출력        | 정수    | 출력 워드 수            |
| `$t0-9`  | 임시        | 임의    | 임시 저장용             |
