# 개요

Rust에서 메서드는 구조체(또는 `enum`이나 `trait` 객체)를 위해 정의된 함수예요. 이는 호출 방식도 바꿔요. `frobnicate(foo)` 대신 `foo.frobnicate()`처럼 호출해요.

메서드는 함수와 비슷해요. `fn` 키워드로 선언하고, 이름이 있으며, 매개변수와 반환 값을 가질 수 있어요.

함수와 달리 메서드의 첫 번째 매개변수는 항상 `self`(또는 그 변형)예요. 이는 메서드가 호출되는 구조체의 인스턴스를 나타내요(자세한 내용은 아래에서 다뤄요).

호그와트 기숙사를 위한 `enum`과 마법사의 `age`와 `house`를 나타내는 `struct`를 만들어 볼까요:

```rust
#[derive(Debug)]
enum House {
    Gryffindor,
    Hufflepuff,
    Ravenclaw,
    Slytherin,
}

struct Wizard {
    age: u32,
    house: House,
}
```

## 메서드 정의하기

`Wizard` 구조체에 메서드를 정의하려면 `Wizard`를 위한 `impl`(implementation의 줄임말) 블록을 시작해요.

```rust
impl Wizard { }
```

이 `impl` 블록 안의 모든 것은 `Wizard` 타입과 연관돼요. 구조체는 여러 개의 `impl` 블록을 가질 수 있다는 점을 기억해요.

### `self` 사용하기

메서드는 첫 번째 매개변수로 `Self` 타입의 `self`라는 이름의 매개변수를 반드시 가져야 해요. `Self` 타입은 `impl` 블록이 대상으로 하는 타입의 별칭이에요. 예시에서 `Self`는 `Wizard`를 나타내요.

Rust에서는 편의를 위해 첫 번째 매개변수 자리에 `self`라는 이름만 써서 줄여 쓸 수 있어요. 메서드에서 흔히 쓰이는 `self` 타입은 다음과 같아요:

- `self`: `self: Self`를 줄인 형태예요. `self`만 쓴 시그니처는 인스턴스를 소비해요.
- `&self`: `self: &Self`를 줄인 형태예요. 인스턴스를 불변으로 빌려요.
- `&mut self`: `self: &mut Self`를 줄인 형태예요. 인스턴스를 가변으로 빌려요.

더 고급 코드에서는 `self: Pin<&self>`, `self: Rc<Self>` 같은 시그니처도 볼 수 있어요. 하지만 이는 이번 튜토리얼의 범위를 벗어나요.

### `&self`로 메서드 정의하기

마법사의 기본 정보를 표시하는 `info` 메서드를 구현하려면 `Wizard`를 위한 `impl` 블록 안에 이 메서드를 정의하면 돼요:

```rust
impl Wizard {
    fn info(&self) {
        println!(
            "A wizard of age {} who studies in House {:?} at Hogwarts",
            self.age,
            self.house,
        );
    }
}
```

`info`의 시그니처에서 `&self`로 인스턴스를 불변으로 빌린다는 점에 주목해요. 이렇게 하면 `Wizard` 인스턴스의 `age`와 `house` 필드를 바꾸지 않고 읽을 수 있어요. 빌리는 대신 소비하는 `self`를 사용했다면, 메서드를 호출한 뒤에는 인스턴스에 접근할 수 없게 됐을 거예요.

`info` 메서드를 구현했으니, 이제 마법사의 기본 정보를 출력할 수 있어요:

```rust
let harry = Wizard { age: 11, house: House::Gryffindor };
harry.info();
// => A wizard of age 11 who studies in House Gryffindor at Hogwarts
```

### `&mut self`로 메서드 정의하기

구조체 인스턴스의 필드를 변경하는 메서드를 구현하려면, 메서드 시그니처에서 `&mut self`로 인스턴스를 가변으로 빌려요.

호그와트에서 학생들이 기숙사를 바꿀 수 있도록 새로운 규칙을 만든다고 해봐요. 그러면 `switch_house` 메서드를 다음과 같이 구현할 수 있어요:

```rust
impl Wizard {
    fn switch_house(&mut self, new_house: House) {
        self.house = new_house;
    }
}
```

이제 호그와트에서 공부하는 마법사의 기숙사를 바꿀 수 있어요:

```rust
// Note that the variable must be mutable
let mut cedric = Wizard {age: 14, house: House::Hufflepuff};
cedric.info();
// => A wizard of age 14 who studies in House Hufflepuff at Hogwarts
cedric.switch_house(House::Slytherin);
cedric.info()
// => A wizard of age 14 who studies in House Slytherin at Hogwarts
```

## 여러 개의 'impl' 블록

Rust에서는 각 항목이 여러 개의 `impl` 블록을 가질 수 있어요. 따라서 모든 메서드를 같은 `impl` 블록에 모을 수도 있고, 메서드 그룹별로 여러 개의 `impl` 블록을 둘 수도 있어요. 두 방식 모두 유효한 문법이지만, 일반적인 프로젝트 구성에서는 `impl` 수준의 `where` 바운드 집합마다 하나의 `impl` 블록을 사용해요.

## 연관 함수

`impl` 블록 안에 `self` 매개변수를 포함하지 않는 함수를 정의할 수도 있어요. 이런 함수는 `self` 매개변수가 없기 때문에 메서드가 아니에요. 하지만 여전히 구현 대상 타입과 연관되어 있고, 그 타입의 이름을 붙여 호출해요. 그래서 연관 함수(또는 타입 연관 함수)라고 불러요.

`String::from()` 같은 연관 함수는 이미 봤을 거예요:

```rust
let some_string = String::from("This is an associated function but not a method");
```

생성자는 흔히 연관 함수로 구현해요. `Wizard` 타입과 연관된 `new` 함수를 만들어 볼까요:

```rust
impl Wizard {
    fn new(age: u32, house: House) -> Self {
        Self {
            age,
            house,
        }
    }
}
```

함수에서 반환할 타입을 나타낼 때 `Wizard` 대신 `Self`를 사용할 수 있다는 점을 기억해요. 이렇게 `Self` 타입 별칭을 사용하는 것이 필수는 아니지만, 이름이 복잡하거나 긴 타입의 구현을 단순하게 만들어 줘요. 이제 다음을 실행할 수 있어요:

```rust
let myrtle = Wizard::new(14, House::Ravenclaw);

myrtle.info();
// => A wizard of age 14 who studies in House Ravenclaw at Hogwarts
```
