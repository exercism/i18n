이 연습 문제에서는 좋아하는 요리책을 보고 멋진 라자냐를 만들 수 있도록 도와주는 코드를 작성해요.

라자냐를 조리하는 데 걸리는 시간과 관련된 네 가지 과제가 있어요.

## 1. 오븐에 있어야 할 예상 시간(분) 정의하기

매개변수를 받지 않고, 라자냐가 오븐에 있어야 하는 시간(분)을 반환하는 `expected_minutes_in_oven()` 함수를 정의해요. 요리책에 따르면 오븐에 있어야 할 예상 시간은 60분이에요.

```r
> expected_minutes_in_oven()
[1] 60
```

## 2. 남은 오븐 시간(분) 계산하기

라자냐가 지금까지 오븐에 있던 실제 시간(분)을 매개변수로 받아서, 앞선 과제에서 구한 오븐에 있어야 할 예상 시간(분)을 기준으로 라자냐가 오븐에 더 있어야 하는 시간(분)을 반환하는 `remaining_time_in_minutes` 함수를 정의해요.

```r
> remaining_time_in_minutes(50)
[1] 10
```

## 3. 준비 시간(분) 계산하기

라자냐에 넣은 층 수를 매개변수로 받아서, 각 층을 준비하는 데 2분이 걸린다고 가정했을 때 라자냐를 준비하는 데 걸린 시간(분)을 반환하는 `prep_time_in_minutes()` 함수를 정의해요.

```r
> prep_time_in_minutes(2)
[1] 4
```

## 4. 경과 시간(분) 계산하기

두 개의 인자를 받는 `elapsed_time_in_minutes` 함수를 정의해요. 첫 번째 인자는 라자냐에 넣은 층 수이고, 두 번째 매개변수는 라자냐가 오븐에 있던 시간(분)이에요. 이 함수는 라자냐 요리에 총 몇 분을 들였는지를 반환해야 하는데, 이는 준비 시간(분)과 현재까지 라자냐가 오븐에서 보낸 시간(분)을 더한 값이에요.

```r
> elapsed_time_in_minutes(3, 20)
[1] 26
```
