# 자세히 알아보기

Clojure의 표준 데이터 타입은 모두 불변이기 때문에, Clojure는 통제된 변경을 제공하는 *참조 타입*을 제공해요. 그중 가장 단순하고 가장 널리 쓰이는 것이 Atom이에요.

Atom은 `atom` 함수로 만들어요. 이 함수는 초깃값을 받아요:

```clojure
(def players (atom ()))
```

atom의 현재 값은 `deref`나 축약형 `@`로 역참조해요:

```clojure
@players
;;=> ()
```

`players` atom의 현재 값은 `swap!`으로 바꿀 수 있어요. `swap!`은 함수를 적용해서 값을 갱신해요:

```clojure
(swap! players conj :player1)
;;=> (:player1)
```

`reset!` 함수는 현재 값과는 상관없이 atom의 값을 교체해요:

```clojure
(reset! players ())
```
