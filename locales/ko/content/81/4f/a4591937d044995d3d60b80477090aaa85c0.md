# 소개

## 정수

Elixir에는 정수와 실수, 두 가지 종류의 수가 있어요.

정수는 소수점이 없는 수예요.

```elixir
integer = 3
# => 3
```

## 실수

실수는 소수점 뒤에 한 자리 이상의 숫자가 있는 수예요. 64비트 배정밀도 부동소수점 형식을 사용해요.

```elixir
float = 3.45
# => 3.45
```

### 숫자 다루기

[`Integer`][integer-functions]와 [`Float`][float-functions] 모듈에서는 이런 타입을 다루는 데 유용한 함수를 찾을 수 있어요. 기본 산술 연산자는 [`Kernel`][kernel-arithmetic-operators] 모듈에 정의되어 있어요.

### 변환

정수와 실수는 하나의 산술 식 안에서 함께 섞어 쓸 수 있어요. 식에 실수를 사용하면 결과도 실수가 돼요.

```elixir
2 * 3
# => 6

2 * 3.0
# => 6.0
```

하지만 나눗셈을 할 때는 정수만 사용하더라도 결과가 항상 실수가 돼요.

```elixir
6 / 2
# => 3.0
```

실수를 정수로 변환하려면 [`trunc/1`][trunc-1]로 소수 부분을 버리면 돼요.
