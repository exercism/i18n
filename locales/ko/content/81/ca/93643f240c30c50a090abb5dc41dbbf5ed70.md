# 개요

`Bool` 타입은 언어의 기본 구성 요소 중 하나예요.
어떤 것이 참인지 거짓인지를 각각 `True`와 `False` 값으로 나타내는 것이 목적이에요.
`Bool`이라는 이름은 Boolean을 줄인 말인데, Boolean은 논리적 사고와 관련된 수학의 한 분야로, 조지 불의 연구에서 이름을 따왔어요.

## 불리언 연산자

`Bool` 타입의 값을 다루는 함수 두 개와 연산자 두 개가 있어요.

- `not : Bool -> Bool`
  이 함수는 `True`를 `False`로, `False`를 `True`로 바꿔요.
- `(&&) : Bool -> Bool -> Bool`
  "AND"라고 부르는 이 연산자는 불리언 두 개를 받아서 둘 다 `True`이면 `True`를 반환해요.
  예를 들어 `True && True`는 `True`를 반환하지만 `True && False`는 `False`를 반환해요.
- `(||) : Bool -> Bool -> Bool`
  "OR"라고 부르는 이 연산자는 불리언 두 개를 받아서 둘 중 적어도 하나가 `True`이면 `True`를 반환해요.
  예를 들어 `False || False`는 `False`를 반환하지만 `True || False`는 `True`를 반환해요.
- `xor : Bool -> Bool -> Bool`
  "XOR"라고 부르는 이 함수(연산자가 아니에요)는 불리언 두 개를 받아서, 하나가 `True`이고 다른 하나가 `False`일 때만 `True`를 반환해요.

`&&`와 `||` 연산자는 우선순위가 같지 않아요.
`&&`의 우선순위는 `||`보다 높아요. 곱셈 `*`와 덧셈 `+`의 관계와 같아요.
그래서 `True || False && False`라는 식은 `True || (False && False)`와 같고, `(True || False) && False`와는 달라요.
전자는 `True`를 반환하고 후자는 `False`를 반환해요.

## 조건에 따른 분기

불리언은 특정 조건을 만족할 때만 실행되는 분기를 코드에 만들 때 아주 유용해요.
Elm에서는 `if-then-else` 식으로 이걸 표현하는데, 다음과 같이 써요.

```elm
if someCondition || (someOtherCondition && anotherCondition) then
    doSomething
else
    doSomethingElse
```

`someCondition` 자리에는 `Bool`을 반환하는 어떤 식이든 올 수 있어요.
그 불리언 값이 `True`이면 `doSomething`이 실행돼요.
그렇지 않으면, 즉 `False`이면 `doSomethingElse`가 실행돼요.
다른 프로그래밍 언어들과 달리 `else` 분기는 반드시 있어야 해요.

조건을 이어서 확인해야 한다면 `if-then-else` 식을 그대로 이어 붙이면 돼요.

```elm
if someCondition then
    doSomething
else if someOtherCondition then
    doAnotherThing
else
    doSomethingElse
```
