# 지침

지난 7일 동안 정원에 새가 몇 마리 찾아왔는지 기록하는 열성적인 새 관찰자예요.

정원에 찾아온 새의 수를 다루는 여섯 개의 과제가 있어요.

## 1. 지난주 개수 확인하기

비교를 위해 지난주 개수를 항상 가까이에 적어 두는데, 그 값은 0, 2, 5, 3, 7, 8, 4였어요. 지난주 개수를 반환하는 (_static_) `BirdCount.LastWeek()` 메서드를 구현해요.

```csharp
BirdCount.LastWeek();
// => [0, 2, 5, 3, 7, 8, 4]
```

## 2. 오늘 찾아온 새의 수 확인하기

오늘 정원에 새가 몇 마리 찾아왔는지 반환하는 `BirdCount.Today()` 메서드를 구현해요. 새의 개수는 날짜 순으로 정렬되어 있고, 첫 번째 원소는 가장 오래된 날의 개수, 마지막 원소는 오늘의 개수예요.

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.Today();
// => 1
```

## 3. 오늘 개수 증가시키기

오늘의 개수를 증가시키는 `BirdCount.IncrementTodaysCount()` 메서드를 구현해요.

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.IncrementTodaysCount();
birdCount.Today();
// => 2
```

## 4. 새가 찾아오지 않은 날이 있었는지 확인하기

정원에 새가 한 마리도 찾아오지 않은 날이 있었다면 `true`를, 그렇지 않다면 `false`를 반환하는 `BirdCount.HasDayWithoutBirds()` 메서드를 구현해요.

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.HasDayWithoutBirds();
// => true
```

## 5. 처음 며칠 동안 찾아온 새의 수 계산하기

주가 시작된 때부터 정원에 찾아온 새의 수를 반환하되, 주가 시작된 때부터 지정한 일수까지만 세는 `BirdCount.CountForFirstDays()` 메서드를 구현해요.

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.CountForFirstDays(4);
// => 14
```

## 6. 바쁜 날의 수 계산하기

어떤 날은 다른 날보다 더 바빠요. 바쁜 날이란 새가 다섯 마리 이상 정원에 찾아온 날이에요.
바쁜 날의 수를 반환하는 `BirdCount.BusyDays()` 메서드를 구현해요.

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.BusyDays();
// => 2
```
