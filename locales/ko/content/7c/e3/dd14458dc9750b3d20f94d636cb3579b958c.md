# 자세히 알아보기

정적 확장을 사용하면 기존 타입의 소스를 수정하지 않고도 마치 그 타입을 확장한 것처럼 다룰 수 있어요. 이는 `using`문을 통해 이루어져요. 정적 확장은 타입을 실제로 바꾸지 않으면서 타입에 기능을 더할 수 있게 해 주는 강력한 도구가 될 수 있어요.

```haxe
using Main.IntExtender;

class Main {
  public static function main() {
    trace(2.triple()); // 6
  }
}

class IntExtender {
  public static function triple(i:Int):Int {
    return i * 3;
  }
}
```
