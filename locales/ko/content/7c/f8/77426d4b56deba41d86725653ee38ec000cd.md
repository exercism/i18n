# 농구팀 웹사이트

## 스토리

농구팀을 위한 웹사이트를 만들고 있어요. 이 웹사이트는 많은 데이터를 보여 주는데, 아쉽게도 화면에 표시되는 내용이 자주 바뀌어요. 데이터가 하나의 객체에 저장되어 있어서 작업 자체는 어렵지 않지만, 시간이 많이 들고 지루해요. 그래서 이 작업을 자동화하기로 했어요.

## 과제

웹사이트 자동화라는 스토리에 어울리는 과제의 예시는 다음과 같아요:

- 콘텐츠 팀이 어떤 데이터를 보여 줄지 스스로 선택할 수 있게 하는 것이 목표예요. 콘텐츠 팀은 웹사이트의 콘텐츠 편집기에서 보여 줄 데이터의 경로를 지정하는 방식으로 이 작업을 해요. 여러분의 과제는 객체와, 점 문자로 구분된 경로를 인자로 받는 extract 함수를 만드는 거예요. 그 경로에 있는 값이나 기본값을 반환해요.

## 추가 과제

스토리는 이어질 수 있어요. 예를 들면 다음과 같아요:

- 콘텐츠 팀은 이 새로운 기능에 매우 만족했고, 벌써 새로운 기능을 추가해 달라고 요청했어요. 배열에서 특정 원소의 데이터를 보여 줄 수 있기를 바라요.
