# 개요

## 옵셔널

Swift는 값이 없을 수도 있다는 것을 표현할 수 있도록 [_옵셔널_][optionals]을 사용해요.
옵셔널은 값을 담고 있을 수도 있고, 값이 없음을 나타내는 [`nil`][nil]일 수도 있는 타입이에요.
옵셔널을 사용하려면 먼저 언래핑한 뒤, 값이 실제로 있는지 프로그램이 확인해야 해요.

타입 이름 끝에 `?`를 붙이면 어떤 타입이든 옵셔널로 만들 수 있어요.
그래서 옵셔널 정수는 `Int?` 타입이고, 옵셔널 문자열은 `String?` 타입이에요.
옵셔널 타입의 상수나 변수를 정의하고 값을 할당하는 방법은 비옵셔널 타입의 값과 같아요.

```swift
let x: Int? = 42
var y: String? = "Hello"
y = "Goodbye"
```

옵셔널 타입의 변수에 값이 없다는 것을 나타내려면 특별한 값 `nil`을 할당하면 돼요.
`nil`은 모든 옵셔널 타입에 쓸 수 있지만, 서로 다른 두 옵셔널 타입에 할당된 `nil`은 타입이 같지 않아서 서로 바꿔 쓸 수도, 비교할 수도 없어요.

```swift
let intOpt: Int? = nil
let stringOpt: String? = nil

intOpt = stringOpt
// Compiler error: Cannot assign value of type 'String?' to type 'Int?'

intOpt == stringOpt
// Compiler error: Binary operator '==' cannot be applied to operands of type 'Int?' and 'String?'
```

또 `nil`은 어떤 옵셔널 타입에도 할당할 수 있지만, 비옵셔널 타입에는 (실제로 `nil`을 담고 있지 않더라도) 할당할 수 없다는 점도 기억해 두세요.
그리고 비옵셔널 타입을 기대하는 메서드에는 먼저 언래핑하지 않고 옵셔널 타입을 넘길 수 없어요.

```swift
var x: Int = 42
var y: Int? = 42

y = x
// Works fine
x = y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
x + y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
```

## 옵셔널 사용하기

옵셔널 타입은 기본 타입과 같은 타입이 아니기 때문에, 두 타입을 같은 방식으로 쓸 수는 없어요.
예를 들어 `Int("123") + 1`은 컴파일러 오류 "Value of optional type 'Int?' must be unwrapped to a value of type 'Int'"를 만들어요.
왜냐하면 `Int("123")`의 반환 타입은 `Int`가 아니라 옵셔널 `Int?`이기 때문이에요. 문자열을 정수로 변환할 수 없으면 결과가 `nil`이 되니까요.
변환 결과에서 `Int`에 접근하려면 먼저 언래핑해야 해요.

Swift에서는 보통 `nil`인지 확인하는 [_옵셔널 바인딩_][optional-binding]을 위해 `if-let`과 `guard-let` 구문을 사용해요. 값이 있으면 언래핑한 값을 지정한 이름에 바인딩해서 한 경로로 실행하고, `nil`이면 다른 경로로 실행해요.

```swift
if let safeNum = Int("123") {
	let sum = safeNum + 1
	…
} else {
  // code for the case where nil was found -- may be left out
}
```

`safeNum` 변수는 `Int?`가 아니라 `Int` 타입이라는 점을 기억해 둘 만해요.
아래 예시에서 `num`은 `Int?` 타입이고, `safeNum`은 `Int` 타입이에요.

```swift
let num = Int("123")
if let safeNum = num {
  // num is of type Int
}
```

이 _옵셔널 바인딩_은 값에서 옵셔널 타입을 언래핑해서(또는 "제거해서") 비옵셔널 값처럼 쓸 수 있게 해 주기 때문에 중요해요.
값이 `nil`인지 조건문으로 확인만 하면, 값은 여전히 옵셔널 타입이에요.

```swift
let num = Int("123")
if num != nil {
  // num is of type Int?
}
```

일찍 반환하고 싶은 경우에는 `guard-let` 방식을 쓸 수도 있어요.

```swift
guard let num = Int("123") else { return nil }
let sum = num + 1
…
```

## 옵셔널 비교하기

두 옵셔널의 기본 타입은 표준 비교 연산자로 비교할 수 있지만, 옵셔널 자체는 비교할 수 없다는 점을 기억해 두세요.
옵셔널은 같은지 여부만 확인할 수 있어요.
두 옵셔널은 둘 다 `nil`이거나, 감싸고 있는 값이 각자의 기본 타입에서 같으면 서로 같아요.

하지만 두 옵셔널 값을 직접 비교하는 코드를 작성할 수도 있어요.
아래는 두 옵셔널 값이 모두 nil이 아니고 첫 번째 값이 두 번째 값보다 작을 때만 `true`를 반환하는 `switch`문 예시예요.
이를 위해 nil이 아닌 옵셔널에만 일치하는 _옵셔널 패턴_ `varName?`을 사용해서, 옵셔널 안의 값을 `varName`이라는 이름에 바인딩해요.

```swift
switch (optionalA, optionalB) {
case let (valA?, valB?): return valA < valB
default: return false
}
```
