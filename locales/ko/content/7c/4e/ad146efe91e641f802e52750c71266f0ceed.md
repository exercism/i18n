# 메인테이너를 위한 안내

## 테스트 생성: `bin/generate_tests.py`

테스트 파일은 각 연습 문제의 `.meta/template.j2`에 들어 있는 Jinja 템플릿을 사용해 [exercism/problem-specifications](https://github.com/exercism/problem-specifications)의 표준 데이터에서 생성해요.

```bash
bin/generate_tests.py bob            # regenerate one exercise
bin/generate_tests.py                # regenerate every exercise that has a template
bin/generate_tests.py --no-pull bob  # skip `git pull` of problem-specifications
```

이 스크립트는 configlet 캐시(`~/.cache/exercism/configlet/problem-specifications`, `bin/configlet sync`가 채워요)에서 problem-specifications를 읽거나, `problem-specifications`라는 이름의 상위 디렉터리에서 읽어요.
`.meta/tests.toml`에 포함된 케이스만 생성해요.

Fortran 문자열 리터럴에는 `\n`, `\t` 같은 이스케이프를 넣을 수 없어요.
`escape_quote_whitespace` 템플릿 필터가 이런 문자를 `" // NEWLINE // "`, `" // TAB // "`, `" // CARRIAGE_RETURN // "`로 바꿔 주기 때문에, 템플릿에서 이 상수들을 선언해야 해요 (`exercises/practice/bob/.meta/template.j2` 참고).

### 준비 사항

- 정상 동작하는 CMake와 Fortran 컴파일러
- `jinja2`가 설치된 Python 3.12 이상
- git

### 새 연습 문제를 추가하는 작업 흐름

`bob`을 예로 들어 볼게요.

- 새 브랜치를 만들어요. 예: `git checkout -b exercise-bob`
- `bin/add-exercise bob`을 실행해요 (`jq`와 `curl`이 필요해요). 이 스크립트는 다음을 해요:
  - configlet을 내려받아 `configlet create`를 실행해요. 그러면 연습 문제가 `config.json`에 추가되고, 문서와 메타데이터, `tests.toml`이 problem-specifications에서 동기화돼요
  - `bin/reorder-exercises`로 `config.json`을 정렬해요
  - `exercises/shared/CMakeLists.txt`를 연습 문제 디렉터리로 복사해요
  - 풀이 스텁과 `.meta/example.f90` 스텁, 시작용 `.meta/template.j2`를 작성해요 (`exercises/shared/template.j2`에서 가져와요)

  GitHub 사용자 이름을 물어보는데, `-a <username>`을 넘기면 묻지 않아요. 난이도는 기본값이 1이고, `-d <difficulty>`로 바꿀 수 있어요.

- `.meta/template.j2`를 수정해서 각 케이스가 올바른 함수를 올바른 입력으로 호출하도록 만든 다음, 테스트를 생성해요:

  ```bash
  bin/generate_tests.py bob
  ```

- `.meta/example.f90`에 동작하는 풀이를 작성해요. 학생이 시작할 수 있도록, 학생용 파일(예: `bob.f90`)은 테스트가 호출하는 함수나 서브루틴의 뼈대로 바꿔 놓아요
- 저장소 루트에서 전체 빌드를 실행해 모든 테스트가 통과하는지 확인해요:

  ```bash
  mkdir -p build && cd build
  cmake ..
  cmake --build .
  ctest -V -R bob
  ```

- `bin/reorder-exercises`와 `bin/configlet lint`를 실행해요
- 모든 것이 통과하면 변경 사항으로 풀 리퀘스트를 열어요

### `CMakeLists.txt` 변경하기

cmake 파일을 변경할 때는 `exercises/shared/`에 있는 원본을 업데이트하고, `bin/update-cmake-files`를 사용해 모든 연습 문제 디렉터리에 복사해요.
