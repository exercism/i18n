# 개요

C#은 정적 타입 언어예요. 즉, 컴파일 시점에 모든 것에 타입이 정해져 있어요. [변수][variable]의 이름을 정하는 것을 변수를 정의한다고 해요. 변수를 한 번 정의한 뒤에 값을 설정하거나 바꾸는 것은 변수 할당이라고 해요. 변수는 타입을 명시적으로 지정해서 정의할 수도 있고, [`var` 키워드][var]를 사용해서 할당된 값을 바탕으로 C# 컴파일러가 타입을 추론하게 할 수도 있어요. `var`를 사용하는 것을 _타입 추론_이라고 해요.

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

변수의 값은 [`=` 연산자][assignment]를 사용해서 할당하고 갱신할 수 있어요. 한 번 정의된 변수의 타입은 절대 바뀌지 않아요.

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

C#은 객체 지향 언어라서 모든 [함수][function]를 _클래스_ 안에 정의해야 해요. 클래스는 [`class` 키워드][classes]로 정의해요. 객체(또는 _인스턴스_)는 `new` 키워드로 만들어요.

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

클래스 안에 있는 함수를 _메서드_라고 해요. [메서드][methods]는 매개변수가 없을 수도 있고, 하나 이상 있을 수도 있어요. 모든 매개변수는 타입을 명시적으로 지정해야 하며, 매개변수에는 타입 추론이 적용되지 않아요. 마찬가지로 반환 타입도 명시적으로 지정해야 해요. 메서드에서 값을 반환할 때는 [`return` 키워드][return]를 사용해요. 다른 파일의 코드에서 메서드를 호출할 수 있게 하려면 `public` 접근 한정자를 붙여야 해요.

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

메서드는 인스턴스에서 점(`.`) 문법으로 호출해요. 호출할 메서드의 이름을 쓰고, 메서드의 각 매개변수에 맞는 인자를 전달해요. 인자에는 해당 매개변수의 이름을 선택적으로 지정할 수 있어요.

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

호출하려는 메서드가 자신을 호출하는 메서드와 같은 클래스에 정의되어 있다면 클래스 이름을 생략할 수 있어요.

메서드가 객체의 _상태_를 전혀 사용하지 않는다면, `static` 한정자를 붙여 _정적_ 메서드로 만들 수 있어요. 정적 메서드도 점(`.`) 문법으로 호출하지만, 클래스의 인스턴스가 아니라 클래스 자체에서 호출해요.

클래스에 정적 메서드만 있다면 그 클래스도 `static` 한정자를 붙여 정적으로 만들 수 있어요. 이는 클래스의 의도를 나타내요.

```csharp
static class Calculator
{
    public static int Multiply(int x, int y)
    {
        return x * y;
    }
}

Calculator.Multiply(2, 4); // => 8
```

C#에서 스코프는 `{`와 `}` 문자 사이에 정의돼요.

C#은 두 가지 종류의 [주석][comments]을 지원해요. 한 줄 주석은 `//`로 시작하고, 여러 줄 주석은 `/*`와 `*/` 사이에 넣어요.

정수 값은 하나 이상의 (연속된) 숫자로 정의되고, [기본 수학 연산자][operators]를 지원해요.

변수 이름은 문자나 밑줄로 시작해야 하는 등 [몇 가지 규칙을 따라야 하고][identifier-names], [C# 이름 지정 규칙을 따르는 것이 좋아요][naming-guidelines]. 변수 이름이 예약된 [C# 키워드][csharp-keywords]와 겹치면 `@`를 사용해서 이스케이프해야 해요. 이 표기법은 권장하지 않지만, 예외적인 경우에 마주칠 수 있어요. 예를 들어 `var @this`, `var @class`, `var @var` 같은 식이에요.

C#처럼 C 계열 언어에서 아주 기본이 되는 개념 몇 가지는 사소하지 않은 코드라면 거의 어디에나 자연스럽게 등장해요. 바로 [변경][mutation]과 [스코프][scope]예요. 변경은 프로그램이 실행되는 동안 변수의 값이 바뀔 수 있다는 개념이에요. 스코프는 (프로그램 요소의) 이름에 연결된 값이 그것이 정의된 코드 "영역" 안에서만 접근할 수 있다는 개념이에요. C#에서 주요 코드 영역은 _클래스/구조체_와 _함수_(보통 메서드)지만, 루프나 다른 구조물의 본문도 포함될 수 있어요.
