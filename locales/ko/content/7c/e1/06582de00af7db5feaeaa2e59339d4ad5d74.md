# 소개

`if/else` 표현식으로도 조건부 로직을 실행할 수 있지만, Haskell에는 조건부 로직을 실행하는 더 강력한 방법이 있어요. 바로 [패턴 매칭][pattern-matching]이에요.
패턴 매칭을 사용하면 값을 하나 이상의 _패턴_과 대조해 볼 수 있어요.
이런 패턴의 한 가지 예가 _상수 패턴_인데, 값과 상수(예: `1` 또는 `"hello"`)를 대조해요.

함수를 정의할 때는 패턴마다 별도의 함수 본문을 정의할 수 있어요.
그러면 단순하고 읽기 쉬운 깔끔한 코드가 만들어져요.
숫자, 문자, 배열, 튜플 등 어떤 데이터 타입에든 패턴 매칭을 할 수 있어요.

예를 들어, 정수(`Int`)를 받아서 _0_에 _1_만큼 더 가깝게 만드는 단순한 함수는 이렇게 표현할 수 있어요.

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero 1 = 0
```

패턴 매칭은 다른 패턴들과 함께 사용할 때 진가를 발휘해요. 예를 들어 _변수 패턴_이 있어요.

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero n = n - 1
```

위 예제는 _0_ 이외의 모든 입력을 똑같이 처리하기 때문에, 음수에 대해서는 잘못된 결과를 내놓아요.
이 문제는 _가드_라고 하는 조건부 패턴으로 해결할 수 있는데, `|` 기호로 표현해요.

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
```

위 예제들에서는 모든 가능한 입력에 대응하는 패턴이 있는 게 아니에요.
컴파일러는 이걸 감지하고 경고를 출력해요.
이는 런타임 오류를 피할 수 있도록 가능한 모든 경로가 처리되었는지 확인해 주는, Haskell의 아주 유용한 기능이에요.
이를 _철저한 검사_라고 해요.
경고를 해결하려면 모든 경우를 처리해야 해요.
_가드_ 안에서는 나머지 모든 패턴을 잡아내기 위해 `otherwise` 표현식을 `True`에 대한 문법 설탕처럼 사용할 수 있어요.

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
    | otherwise = 0
```

패턴 매칭은 값을 위에서 아래로 각 패턴과 대조하면서, 일치하는 패턴을 찾으면 그 패턴에 연결된 로직을 실행해요.
**패턴의 순서가 중요해요!**
