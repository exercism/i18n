# 소개

C는 임베디드 컴퓨터부터 고성능 컴퓨팅 클러스터에 이르기까지, 다양한 애플리케이션에 사용되는 범용 프로그래밍 언어예요.

C는 읽기 어려운 어셈블리 언어를 대신할 좋은 대안이라서 저수준 애플리케이션에서 흔히 쓰여요. C는 어셈블리로 컴파일할 수 있어서, 성능은 그대로 유지하면서 가독성을 높이고, 정적 타입 덕분에 어느 정도 안전성까지 챙길 수 있어요!

C는 Bell Labs의 Dennis Ritchie가 만들었고, Unix 운영체제를 다시 구현하는 데 사용됐어요. 지금은 가장 많이 쓰이는 프로그래밍 언어 중 하나로, 대부분의 하드웨어와 플랫폼을 지원하는 컴파일러가 다양하게 있어요. 시작하는 데 도움이 될 자료와 지원도 충분히 많아요!
