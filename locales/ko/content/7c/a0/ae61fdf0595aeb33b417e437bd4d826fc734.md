# 자세히 알아보기

[심볼][symbols]은 값을 가리키는 데 사용할 수 있는, 이름이 붙은 식별자예요.
심볼은 심볼 리터럴로 만들어요. 이름 앞에 `:` 문자를 붙이면 되죠. 예를 들어 `:foo`처럼요.
따옴표로 감싸서 쓸 수도 있는데, 예를 들어 `:"foo"`처럼 쓰면 이름에 공백을 넣을 수 있어요.

```crystal
:foo           # => :foo
:"foo boo"     # => :"foo boo"
:foo == :"foo" # => true
```

심볼은 언어 곳곳에서 쓰여요. namedtuple의 키로 쓰이기도 하고, 메서드와 변수 이름을 나타내는 데 쓰이기도 하죠.

## Crystal의 심볼

Crystal의 심볼은 Ruby와 꽤 달라요.
Crystal에서 심볼은 일종의 상수라서 컴파일 타임에 할당돼요.
즉, 심볼은 동적으로 만들 수 없어요. Ruby에서는 가능하지만요.

Crystal의 심볼은 `Int32`로 표현되기 때문에 매우 효율적이에요.

## 변환

심볼은 문자열로 변환할 수 있지만, 그 반대는 안 돼요.
심볼은 컴파일 타임에 만들어지고 문자열은 런타임에 만들어지기 때문이에요.

```crystal
:foo.to_s # => "foo"
```
