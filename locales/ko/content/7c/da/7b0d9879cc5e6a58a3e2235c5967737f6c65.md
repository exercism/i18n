# 소개

메서드 매개변수에 기본값을 지정하면 그 매개변수를 선택 사항으로 만들 수 있어요. 선택적 매개변수가 있는 메서드를 호출할 때, 호출하는 쪽에서 그 매개변수에 값을 넘길 필요는 없어요. 선택적 매개변수에 값을 넘기지 않으면 기본값이 사용돼요.

선택적 매개변수는 매개변수 목록의 맨 끝에 있어야 해요. 뒤에 선택 사항이 아닌 매개변수가 올 수는 없어요.

```haxe
class Card {
  static function newYear(year = 2021):String {
    return "Happy " + year;
  }
}

Card.newYear(); // Happy 2020
Card.newYear(1990); // Happy 1990
```

변수 이름 앞에 `?` 연산자를 사용하면 선택적 매개변수를 `null`로 설정할 수 있어요.

```haxe
function newYear(?year:Int) {
  if (year != null)
    return "It's " + year;
  return "Year is null";
}

newYear(); // Year is null
```
