# 지침

Lisp 외계인 레슬리는 장을 좀 봐야 해요. 장을 볼 때는 장보기 배열을 만들어 두는 게 아주 중요하죠. 거기에 물건을 넣기도 하고, 빼기도 해야 하니까요.

물론 Lisp 외계인에게 종이와 펜만으로는 부족해요. "List"는 "Lisp"라는 단어의 대부분을 차지하기도 하니까요! 장보기를 관리할 수 있게 도와주는 함수가 분명히 필요하겠죠.

레슬리가 장보기 배열을 잘 관리할 수 있도록 도와줄래요?

## 1. 새 배열 만들기

먼저 레슬리는 빈 배열을 만들어야 해요. `new-list`라는 함수가 딱 맞겠죠.

```lisp
(new-list) ; => ()
```

이런... 레슬리는 이미 생각해 둔 물건이 몇 개 있어서, 세 개의 항목을 받아 (다행히 레슬리는 세 개짜리 배열만 만들어요. 그보다 많지도 적지도 않아요!) 그것들로 새로운 장보기 배열을 만드는 함수가 필요해요. 세 개의 항목을 받아 그것들을 담은 배열을 반환하는 `list-of-things` 함수를 작성해 봐요.

```lisp
(list-of-things 'bread 'milk 'butter) ; => '(bread milk butter)
```

## 2. 배열에 항목 추가하기

가게에 가기 전에 레슬리는 식료품 저장고를 살펴보며 무엇이 필요한지 확인해요. 배열의 맨 앞에 항목을 추가하는 `add-to-list` 함수를 작성해서 도와줘요.

```lisp
(add-to-list 'butter '(bread)) ; => '(butter bread)
```

## 3. 배열에서 다음 항목은 뭘까요?

장을 볼 때 레슬리는 다음에 무엇을 찾아야 할지 알고 싶어 해요. 또 배열에서 두 번째, 세 번째, 심지어 스물세 번째 항목(레슬리의 행운의 숫자예요)까지 미리 훔쳐보는 걸 좋아하죠.

- `first-thing`은 배열의 첫 번째 항목으로 평가돼요
- `second-thing`은 두 번째 항목으로 평가돼요
- `third-thing`은 세 번째 항목으로 평가돼요
- `twenty-third-thing`은 스물세 번째 항목으로 평가돼요

```lisp
(first-thing '(bread butter milk)) ; => 'bread
(second-thing '(bread butter milk)) ; => 'butter
(third-thing '(bread butter milk)) ; => 'milk
```

## 4. 배열에서 항목 하나 제거하기

레슬리는 배열의 첫 번째 항목을 찾아서 선반에서 치우고 싶어 해요. 입력받은 배열에서 첫 번째 항목만 빼고 나머지를 담은 배열로 평가되는 `remove-first-item` 함수를 작성해서 도와줘요.

```lisp
(remove-first-item '(bread butter milk)) ; => '(butter milk)
```

## 5. 작은 배열로 더 큰 배열 만들기

레슬리는 실수로 장보기 배열을 하나가 아니라 두 개나 만들었다는 걸 깨달았어요! 첫 번째 배열의 원소들 뒤에 두 번째 배열의 원소들이 이어지는 배열을 반환하는 `list-append` 함수를 작성해 봐요.

```lisp
(list-append '(bread salt) '(butter milk)) ; => '(bread salt butter milk)
```

## 6. 얼마나 길까요?

레슬리는 이번 장보기가 꽤 오래 걸릴까 봐 걱정되기 시작했어요. 대체 이 배열에는 물건이 몇 개나 들어 있을까요? 배열의 길이를 알려 주는 `just-how-long` 함수를 작성해 봐요.

```lisp
(just-how-long '(bread milk butter salt)) ; => 4
```
