# 자세히 알아보기

[`Rational numbers`][rational]는 정수 분자를 정수 분모로 나눈 분수예요.

예를 들어, `2//3`을 어림값인 `Float64` 값 `0.6666...` 대신 정확한 분수로 저장할 수 있어요.

장점은 ([정수 오버플로][integer-overflow]라는 극단적인 경우를 빼면) 유리수가 정확한 값을 그대로 유지해서, 실수에서 흔히 피할 수 없는 반올림 오류를 피할 수 있다는 점이에요.

더 자세한 내용은 Julia [매뉴얼 페이지][julia-rational]에 있어요.

유리수는 아주 단순한 숫자 타입이고, 기대하는 대로 동작하도록 만들어졌어요.
Julia 초기 버전부터 표준 타입이었기 때문에, 대부분의 함수가 정수나 실수와 마찬가지로 유리수도 입력으로 받아요.

## 유리수 만들기

두 정수 사이에 `//`를 쓰기만 하면 돼요.

```julia-repl
julia> 3//4
3//4

julia> a = 3; b = 4;

julia> a//b
3//4
```

공약수는 자동으로 약분되어, 분수를 ["기약 분수"][lowest-terms]로 만들어요. 기약 분수는 분수를 정확하게 나타내는 가장 작은 정수들이고, 분모는 음수가 아니에요.

```julia-repl
julia> 5//15
1//3

julia> 5//-15
-1//3
```

무한대 결과는 허용되지만, `NaN`은 허용되지 않아요.

```julia-repl
julia> 1//0
1//0

julia> float(1//0)
Inf

julia> 0//0
ERROR: ArgumentError: invalid rational: zero(Int64)//zero(Int64)
```

## 유리수 연산

일반적인 [`arithmetic operators`][operators] `+ - * / ^ %`는 유리수에서도 동작하고, 다른 숫자 타입에서와 본질적으로 같아요.

정수와 다른 `Rational`도 식에 넣을 수 있고, 결과는 `Rational`이 돼요.
식에 `float`을 넣으면 `float` 결과가 나오고, 그에 따라 정밀도가 (손실될 수도) 떨어져요.

`float`이 필요하면, `float()` 함수로 유리수를 변환하면 돼요.
긴 계산 동안 정밀도를 유지하려고 유리수를 쓰고, 마지막에 실수로 변환하는 것은 아주 흔한 방법이에요.

```julia-repl
julia> 3//4 + 1//3  # addition
13//12

julia> 3//4 * 1//3  # multiplication
1//4

julia> 3//4 / 1//3  # division
9//4

julia> 3//4 ^ 2  # exponentiation
3//16

julia> 3//4 + 5  # rational and int => rational
23//4

julia> 3//4 + 5.3  # rational and float => float
6.05

julia> float(3//4)  # casting
0.75
```

유리수는 [복소수][complex]와도 함께 쓸 수 있어요.
복소수는 [별도의 개념][complex-concept]에서 다뤄요.

## 그 밖의 연산

Julia에서 유리수는 그냥 숫자예요.
컴파일러가 보통 필요에 따라 타입을 알아서 변환해 줘요.

다만, 비교는 소수로 정확히 표현되는 분수에 대해서만 동작한다는 점을 조심해요.

```julia-repl
julia> 3//4 == 0.75
true

julia> 3//4 < 0.74
false
```

그 외의 경우에는 비교를 위해 `Rational`을 `Float`로 변환해야 해요.

```julia-repl
julia> 1//3 == 1/3
false

julia> float(1//3) == 1/3
true
```

수학 함수는 유리수를 입력으로 받지만, 결과는 실수로 나올 수 있어요.

```julia-repl
julia> sqrt(9//16)
0.75
```
