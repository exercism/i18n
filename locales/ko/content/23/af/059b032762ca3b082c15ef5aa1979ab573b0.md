# 소개

상속은 객체 지향 프로그래밍(OOP)의 핵심 개념이에요.
IS-A 관계를 나타내죠.
영어에서 쓰이는 것과 같은 의미로, 프로그래밍에서도 부모로부터 기능을 물려받는 것을 뜻해요(프로그래밍에서 기능은 보통 함수와 변수를 말해요).

다음과 같은 `Animal` 클래스를 살펴봐요.

```java
//Creating an Animal class with bark() as a member function.
public class Animal {

    public void bark() {
        System.out.println("This is an animal");
    }

}
```

`Animal`은 부모 클래스예요. 이 클래스가 가진 속성을 일반적인 모든 동물로 확장할 수 있기 때문이죠.

`Lion`이라는 동물이 있고, 그 클래스가 이렇게 생겼다고 생각해 봐요.

```java
//Lion class is a child class of Animal.
public class Lion extends Animal {

    @Override
    public void bark() {
        System.out.println("Lion here!!");
    }

}
```

~~~~exercism/note
`Override` 애너테이션은 하위 클래스의 메서드가 상위 클래스의 메서드를 재정의하고 있음을 나타낼 때 사용해요.
꼭 필요한 것은 아니지만 사용하는 것이 좋은 관행이에요.
~~~~

이제 이렇게 하면,

```java
Animal animal = new Lion(); //creating instance of Animal, of type Lion
animal.bark();
```

참고: `Animal` 클래스를 `Lion`으로 초기화했어요.
출력은 이렇게 나와요.

```java
Lion here!!
```

객체 지향 프로그래밍에서는 상속의 종류가 여러 가지지만, Java는 그중 일부(다중 레벨 상속과 계층적 상속)만 지원해요.
더 자세히 알아보려면 [이 글][java-inheritance]을 읽어 봐요.
