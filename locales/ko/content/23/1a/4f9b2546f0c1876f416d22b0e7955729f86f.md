# 소개

C#에서는 _상속_을 사용해 _클래스_ 계층 구조를 정의할 수 있는데, 상속을 이용하면 파생 클래스(`Car`)가 부모 클래스(`Vehicle`)의 동작과 데이터를 물려받을 수 있어요. 부모 클래스를 지정하지 않으면 그 클래스는 `object` 클래스에서 상속받아요.

부모 클래스는 세 가지 방식으로 파생 클래스에 기능을 제공할 수 있어요.

- 일반 메서드를 정의해요.
- `virtual` 메서드를 정의해요. `virtual` 메서드는 일반 메서드와 비슷하지만 파생 클래스가 _바꿀_ 수 있는 메서드예요.
- `abstract` 메서드를 정의해요. `abstract` 메서드는 구현이 없는 메서드로, 파생 클래스가 _반드시_ 구현해야 해요. `abstract` 메서드가 있는 클래스는 똑같이 `abstract`로 표시해야 해요. 추상 클래스는 인스턴스로 만들 수 없어요.

`protected` 접근 한정자를 사용하면 부모 클래스의 멤버에 파생 클래스에서 접근할 수 있지만, 다른 클래스에서는 접근할 수 없어요.

파생 클래스는 `base` 키워드를 통해 부모 클래스의 멤버에 접근할 수 있어요.

```csharp
// Inherits from the 'object' class
abstract class Vehicle
{
    // Can be overridden
    public virtual void Drive()
    {
    }

    // Must be overridden
    protected abstract int Speed();
}

class Car : Vehicle
{
    public override void Drive()
    {
        // Override virtual method

        // Call parent implementation
        base.Drive();
    }

    protected override int Speed()
    {
        // Implement abstract method
    }
}
```

파생 클래스의 생성자는 자신의 생성자 로직을 실행하기 _전에_ 부모 클래스의 생성자를 자동으로 호출해요. `base` 키워드를 사용하면 부모 클래스의 생성자에 인자를 전달할 수 있어요.

```csharp
abstract class Vehicle
{
    protected Vehicle(int wheels)
    {
        Console.WriteLine("Called first");
    }
}

class Car : Vehicle
{
    public Car() : base(4)
    {
        Console.WriteLine("Called second");
    }
}
```

하나의 기반 클래스에서 둘 이상의 클래스가 파생되면, 이 두 개(또는 그 이상)의 클래스는 흔히 기반 클래스 메서드의 서로 다른 버전을 구현해요. 이를 다형성이라고 하는데, 아주 중요한 원리예요. 예를 들어, 위 예제를 조금 바꾼 아래 코드는 `Vehicle`을 사용하는 코드가 인스턴스화된 탈것의 종류에 따라 동작을 바꿀 수 있는 방법을 보여줘요.

```csharp
abstract class Vehicle
{
   public abstract string GetDescription();
}

class Car : Vehicle
{
   public Car()
   {
   }

   public override string GetDescription()
   {
      return "Runabout";
   }
}

class Rig : Vehicle
{
   public Rig()
   {
   }

   public override string GetDescription()
   {
      return "Big Rig";
   }
}

Vehicle v1 = new Car();
Vehicle v2 = new Rig();

v1.GetDescription();
// => Runabout
v2.GetDescription();
// => Big Rig
```
