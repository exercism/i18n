# 힌트

## 1. 옷 아이템 만들기

- 일부 함수는 컴프리헨션 문법과 함께 사용해서 만들 수 있어요.
- `Dict`가 바로 그런 함수예요. 소개에서 **제너레이터 표현식**을 다시 봐요.
- 인덱스 `i`의 카테고리는 인덱스 `i`의 품질과 짝을 이뤄요 ([eachindex()][index]가 유용할 수 있어요)

## 2. 조합 제안하기

- 컴프리헨션으로 다차원 배열을 만드는 간결한 문법이 있어요.
- 소개에서 **다중 변수, 다차원 출력**을 다시 봐요.
- 반복자(`tops` / `bottoms`)의 순서가 올바른지 확인해요.

## 3. 의상 가격 합산하기

- 두 옷 아이템 각각에서 가격을 가져와서 더해야 해요.
- 출력 배열의 형태가 입력 배열의 형태와 같은지 확인해요.
- 소개에서 **단일 변수**를 다시 봐요.

## 4. 서로 어울리지 않는 의상 걸러내기

- 두 옷 아이템의 `base_color`를 비교해서 같은 `base_color`를 가진 의상은 버려야 해요.
- `Matrix` 입력에서는 출력이 가장 효율적인 순서(즉, 열 우선)가 되도록 해요.
- 소개에서 **단일 변수**를 다시 봐요.

[index]: https://docs.julialang.org/en/v1/base/arrays/#Base.eachindex
