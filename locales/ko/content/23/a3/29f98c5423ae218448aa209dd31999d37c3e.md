# 데이터베이스 결제 감사

## 문제 설명

ABC Corp는 추가 처리를 위해 SQL 데이터베이스의 모든 데이터를 [Ballerina 테이블](https://ballerina.io/learn/by-example/table-syntax/)에 불러오기를 원해요. 그런 다음, 불러온 Ballerina 테이블을 쿼리해서 주어진 금액(예: 3000.00)보다 큰 결제 내역을 가진 직원의 이름을 찾아야 해요.

**1단계:**

다음 컬럼을 가진 Ballerina 테이블을 만들어요.

`payment_id` - 정수

`amount` - 실수

`employee_name` - 문자열

**2단계:**

H2 데이터베이스에 있는 해당 전체 데이터 세트를 불러와서 위에서 만든 Ballerina 테이블을 채워요. 테이블의 기본 키로 `payment_id`를 사용해요.

**3단계**

Ballerina 쿼리 표현식으로 Ballerina 테이블을 쿼리해서 주어진 금액보다 큰 결제 내역을 가진 직원의 이름을 찾아요. 결과는 직원 이름을 기준으로 오름차순으로 정렬해요. 반환하기 전에 결과에서 중복된 이름은 제거해요.

> 참고: 해법을 구현할 때는 Ballerina 테이블을 반드시 사용해야 해요.

## 데이터베이스 정보

이 문제에는 제공된 H2 데이터베이스를 사용해요.

> 샘플 데이터베이스 파일은 `gofigure.mv.db`이고, 데이터베이스 이름은 `gofigure`예요. 이 파일은 `db` 폴더 안에 있어요.

다음 테이블들은 샘플 데이터와 함께 샘플 H2 데이터베이스에 이미 들어 있어요. 컬럼 이름과 데이터 타입은 아래와 같아요.

**테이블 이름**: `Employee`

| **컬럼:**      | 타입 |
| -----------       | ----------- |
| `employee_id`     | 정수, 자동 증가 기본 키       |
| `name`            | 문자열        |
| `city`            | 문자열        |
| `department`      | 문자열        |
| `age`             | 정수        |

**테이블 이름**: `Payment`

| **컬럼:**      | 타입 |
| -----------       | ----------- |
| `payment_id`      | 정수, 자동 증가 기본 키       |
| `date`            | 날짜        |
| `amount`          | 실수        |
| `employee_id`     | 정수        |
| `reason`          | 문자열        |

* 데이터베이스 파일은 `gofigure.mv.db`예요. JDBC URL은 `jdbc:h2:file:/path/to/db/file`로 사용해요.
* 사용자 이름: `root`
* 비밀번호: `root`

## 제약 사항

* 쿼리와 Ballerina 샘플을 검증하려면 `db` 폴더에 제공된 H2 데이터베이스 파일을 사용해요.
* Ballerina.toml에서 H2 데이터베이스 드라이버를 플랫폼 의존성으로 추가하려면 maven dependency params 방식을 사용해요.

## 테스트 환경

* `bal test`로 테스트를 실행할 수 있어요. 그러면 주어진 샘플 DB에 대해 테스트가 실행돼요.

## 힌트

* 데이터베이스를 다루려면 [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc) 모듈을 사용해요.
* JDBC 드라이버를 의존성으로 추가하는 단계는 [사전 준비 사항](https://lib.ballerina.io/ballerinax/java.jdbc/latest) 섹션을 참고해요.
* DB에서 데이터를 쿼리하려면 [query](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-query) 원격 메서드를 사용해요.
* [간단한 쿼리](https://ballerina.io/learn/by-example/mysql-query-operation) 예제를 참고해요.
* [테이블 문법](https://ballerina.io/learn/by-example/table) 예제를 참고해요.
* Ballerina 테이블에서 필요한 데이터를 찾으려면 [테이블 쿼리하기](https://ballerina.io/learn/by-example/querying-tables)를 참고해요.
