# 소개

[배열][arrays-concept]에는 배열의 내용을 분석하는 내장 메서드가 있어요.
이런 메서드 대부분은 true나 false를 반환하는 함수를 인자로 받아요.
이런 함수를 [`predicate`][predicate_in_programming]라고 해요.

이 내장 메서드들은 _`for`문 대신_ 또는 내장 `forEach` 메서드 대신에 사용하도록 만들어졌어요:

`for`문을 사용해 분석하는 예시:

```javascript
const numbers = [1, 'two', 3, 'four'];
for (var i = 0; i < numbers.length; i++) {
  if (numbers[i] === 'two') {
    return i;
  }
}
// => 1
```

내장 메서드를 사용해 분석하는 예시:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.indexOf('two');
// => 1
```

배열을 분석할 때 사용할 수 있는 몇 가지 유용한 내장 메서드를 아래에 소개해요. 전체 배열 메서드 목록은 [MDN][mdn-array-methods]에서 확인해요.

## `includes`

> includes() 메서드는 배열의 항목 중에 특정 값이 포함되어 있는지 확인하고, 그에 따라 true 또는 false를 반환해요. [^1]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.includes(1);
// => true
numbers.includes('one');
// => false
```

## `every`

> every() 메서드는 배열의 모든 요소가 주어진 함수가 구현한 테스트를 통과하는지 검사해요. 불리언 값을 반환해요. [^2]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.every((num) => num % 2 !== 0);
// => true
```

## `some`

> some() 메서드는 배열에서 적어도 하나의 요소가 주어진 함수가 구현한 테스트를 통과하는지 검사해요. [^3]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.some((num) => num % 2 !== 0);
// => true
```

## `find`

> find() 메서드는 주어진 테스트 함수를 만족하는 배열의 첫 번째 요소 값을 반환해요. 만족하는 값이 없으면 undefined를 반환해요. [^4]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.find((num) => num < 5);
// => 1
```

## `findIndex`

> findIndex() 메서드는 주어진 테스트 함수를 만족하는 배열의 첫 번째 요소의 인덱스를 반환해요. 그런 요소가 없으면 -1을 반환해서, 어떤 요소도 테스트를 통과하지 못했음을 나타내요. [^5]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.findIndex((num) => num > 7);
// => 4
numbers.findIndex((num) => num > 9);
// => -1
```
