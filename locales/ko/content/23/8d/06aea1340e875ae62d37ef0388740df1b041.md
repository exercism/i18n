# Odin 소개

[Odin 언어][odin-website]는 C의 실용적이고 현대적인 후속 언어를 목표로 설계된 정적 타입 명령형 언어예요.
Odin을 만든 [GingerBill][gb]은 C 언어의 여러 불편한 점을 대부분 해결하면서도, 하드웨어에 가까운 성능 중심의 경험은 그대로 제공하는 실용적인 언어를 원했어요.

Odin의 원칙은 다음과 같아요:

- 단순함: 일관되고 안전하며 사용자 친화적인 문법.
- 높은 성능: 메모리와 데이터 레이아웃에 대한 명시적인 제어
- 현대적인 시스템을 위한 설계
- 프로그래밍의 즐거움을 되찾기

Odin은 C, Go, Nim, Zig와 같은 범주의 시스템 프로그래밍 언어예요.
Go나 Nim과 달리 Odin은 수동 메모리 관리를 사용해요. 프로그래머가 직접 메모리를 할당한 다음 해제해야 하죠.
Odin의 내장 메커니즘 덕분에 이 과정은 아주 간단해요.

Odin의 컴파일러 제품군은 "배터리 포함"이에요. 상당한 규모의 표준 라이브러리와 OpenGL, SDL, Direct-X, Raylib 같은 게임 및 그래픽 라이브러리를 함께 제공하죠.

기존 시스템 언어보다 더 명확하고 더 편하게 고성능 애플리케이션을 만들고 싶다면, Odin을 배워봐요.
