# 소개

`jq`는 JSON 데이터를 파싱하고 변환하는 도구예요.
`jq`는 JSON 데이터를 위한 `sed` 같은 도구예요. `sed`, `awk`, `grep`을 비롯한 여러 도구로 텍스트를 자유롭게 다루듯이, 같은 편안함으로 구조화된 데이터를 잘라내고 걸러내고 매핑하고 변환할 수 있어요.

`jq`는 동적 타입 함수형 프로그래밍 언어예요.
모든 값은 불변이에요.

`jq` 프로그램은 "필터"들의 파이프라인으로 구성돼요. 각 필터는 항목 하나를 입력으로 받아 동작하고, 변환된 요소를 0개 이상 출력해요.
"필터"는 "표현식"이라고도 불러요.

표현식의 출력은 `|` 연산자를 사용해 다른 표현식으로 전달할 수 있어요.
`expressionA | expressionB`는 `expressionA`를 어떤 입력에 적용한 다음, `expressionA`의 각 출력마다 `expressionB`를 반복해서 실행해요.

표현식의 입력은 `.`으로 명시적으로 가리킬 수 있어요.
입력에 `1`을 더하는 표현식은 이렇게 써요: `. + 1` (`1 + .`라고 써도 돼요).

## `jq`(프로그램)와 `jq`(언어)

`jq`는 다양한 운영체제에 패키지로 설치하거나, 소스에서 직접 빌드할 수 있는 프로그램이에요(소스는 C로 작성돼 있어요).
여러 유용한 [명령줄 옵션][cli-options]이 있고, 속도도 꽤 빨라요.

`jq` 프로그램은 입력 데이터를 원하는 만큼 복잡하게 조작할 수 있도록 _언어_도 구현하고 있어요.

이 Exercism 트랙에서는 이 언어에 집중할 거예요.
`jq` 프로그램의 사용법은 테스트에서 보게 될 거예요.

## JSON

[json.org][json]의 설명이에요:

> JSON(JavaScript Object Notation)은 가벼운 데이터 교환 형식이에요.
> 사람이 읽고 쓰기 쉬워요.
> 기계가 파싱하고 생성하기도 쉬워요.
> JavaScript 프로그래밍 언어 표준 ECMA-262 3판, 1999년 12월을 기반으로 해요.
> JSON은 완전히 언어 독립적인 텍스트 형식이지만, C, C++, C#, Java, JavaScript, Perl, Python 등 C 계열 언어를 쓰는 프로그래머에게 익숙한 관례를 사용해요.
> 이런 특성 덕분에 JSON은 이상적인 데이터 교환 언어예요.

이 트랙은 JSON이 아니라 `jq`에 관한 거예요.
[JSON 문법과 데이터 타입][wiki-json]에는 익숙하다고 가정할게요.
