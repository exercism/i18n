# 개요

[C# `Attribute`][attribute-concept]를 사용하면 선언을 꾸며서 클래스, 메서드, 열거형, 필드, 속성 또는 [그 밖에 지원되는][attribute-targets] 선언에 메타데이터를 연결할 수 있어요.

선언 앞에 대괄호 `[]`로 감싸서 추가하면 선언에 [특성][attribute]을 적용할 수 있어요. 다음 예시에서는 `ClassAttribute`와 `FieldAttribute`를 모두 사용해요:

```csharp
[Class]
public class MyClass
{
    [Field] public int myField;
}
```

선언적 메타데이터는 코드에 추가적인 구조화된 정보를 연결할 뿐, 코드의 동작을 바꾸지는 않아요. 하지만 그 메타데이터는 코드의 다른 부분에서 사용되어 대상의 동작 방식을 바꾸거나, 기능을 추가, 변경, 제거하거나 일부를 제한할 수 있어요.

`Flags`, `Obsolete`, `Conditional`처럼 미리 정의된 특성이 여러 개 있어요. [`Flags` 특성][flags-attribute]의 전체 이름은 `FlagsAttribute`이지만, 특성을 사용할 때는 "Attribute" 접미사를 생략할 수 있어요.

다음 네 가지 미리 정의된 특성은 자주 사용돼요:

- `[Flags]`: System 네임스페이스에 미리 정의되어 있어요. 열거형이 비트 연산과 `Enum.HasFlag()` 메서드를 모두 지원한다는 것을 나타내며, 추가로 `ToString`이 모든 플래그를 표시해요: [예시 보기][flags-example].
- `[Obsolete]`: System 네임스페이스에 미리 정의되어 있어요. 코드가 왜 더 이상 사용되지 않는지에 대한 메시지를 추가할 수 있고, 컴파일러 경고나 오류를 표시하는 데 사용할 수 있어요.
- `[Conditional]`: System.Diagnostics 네임스페이스에 미리 정의되어 있어요. 디버깅(진단) 목적으로 컴파일 시점에 일부 메서드 호출을 제거할 수 있어요.
- `[CallerMemberName]`: System.Runtime.CompilerServices 네임스페이스에 미리 정의되어 있어요. 메서드가 자신을 호출한 쪽에 대한 정보를 얻을 수 있어요.
