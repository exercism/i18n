# 지침

신참 마술사 Elyse는 자신의 덱을 여러 가지 방식으로 분석할 필요가 있어요. 간단하게 하기 위해, Elyse는 값이 1부터 10까지인 카드만 사용해요.

## 1. 덱에 특정한 종류의 카드가 몇 장 있는지 확인하기

Elyse는 자신의 덱에 특정한 종류의 카드가 몇 장 있는지 알고 싶어 해요.

카드 배열(Elyse의 덱)과 세려는 카드의 종류, 이렇게 두 개의 매개변수를 받는 `cardTypeCheck` 함수를 작성해요.

<!--prettier-ignore -->
~~~exercism/note
이 함수는 `forEach`를 사용하고, 덱에 있는 지정된 종류의 카드 개수를 반환해야 해요.
~~~

```javascript
const cardType = 3;
cardTypeCheck([1, 2, 3, 4], cardType);
// => 1
```

## 2. 홀수 또는 짝수 카드가 몇 장인지 확인하기

또 다른 마술을 위해, Elyse는 자신의 덱에 홀수 또는 짝수 카드가 몇 장 있는지 알아야 해요.

카드 배열(Elyse의 덱)과 불리언(true는 '짝수', false는 '홀수'에 해당해요), 이렇게 두 개의 매개변수를 받는 `determineOddEvenCards` 함수를 구현해요.

이 함수는 숫자 하나를 반환해야 해요. 즉, 덱에 있는 홀수 또는 짝수 카드의 개수(두 번째 인자의 값에 따라 달라져요)를 반환해요.

<!--prettier-ignore -->
~~~exercism/note
연습 삼아, 이번에는 함수 구현에 `for...of`문을 사용해 봐요.
~~~

```javascript
determineOddEvenCards([1, 2, 3, 1, 5, 6], true);
// => 2

determineOddEvenCards([1, 2, 3, 1, 5, 6], false);
// => 4
```
