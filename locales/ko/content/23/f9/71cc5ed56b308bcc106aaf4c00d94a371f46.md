# 지침

여러분의 친구가 **Gross Store**라는 오래된 도매점을 운영하고 있어요.
가게 이름은 친구가 파는 물건의 수량에서 나온 건데, 모두 [그로스 단위][gross-unit]로 되어 있거든요.
친구가 가게를 위한 판매 시점 관리(POS) 시스템을 만들어 달라고 부탁했어요.
**우선 그 시스템의 프로토타입부터 만들어 보려고 해요.**
**프로토타입에서는 수량만 기록할 거예요.**
친구가 도움이 되라고 측정 단위 목록을 알려줬어요:

| 단위               | 값    |
| ------------------ | ----- |
| quarter_of_a_dozen | 3     |
| half_of_a_dozen    | 6     |
| dozen              | 12    |
| small_gross        | 120   |
| gross              | 144   |
| great_gross        | 1728  |

## 1. 프로그램에 측정 단위 저장하기

측정 단위를 사용하려면 프로그램에 그 단위를 저장해야 해요.

```go
units := Units()
fmt.Println(units)
// Output: map[...] with entries like ("dozen": 12)
```

## 2. 새 고객 청구서 만들기

고객을 위한 새 (빈) 청구서를 만드는 함수를 구현해야 해요.

```go
bill := NewBill()
fmt.Println(bill)
// Output: map[]
```

## 3. 고객 청구서에 품목 추가하기

이걸 구현하려면 다음을 해야 해요:

- 주어진 `unit`이 `units` 맵에 없으면 `false`를 반환해요.
- 그렇지 않으면 품목 이름을 키로 해서 고객 `bill`에 품목을 추가한 뒤 `true`를 반환해요.
- 품목이 이미 청구서에 있다면, 주어진 `unit`에 해당하는 양만큼 수량을 늘려요.

```go
bill := NewBill()
units := Units()
ok := AddItem(bill, units, "carrot", "dozen")
fmt.Println(ok)
// Output: true (since dozen is a valid unit)
```

> 반환 값의 타입은 `bool`이라는 점에 주의해요.

## 4. 고객 청구서에서 품목 제거하기

이걸 구현하려면 다음을 해야 해요:

- 주어진 품목이 청구서에 **없으면** `false`를 반환해요.
- 주어진 `unit`이 `units` 맵에 없으면 `false`를 반환해요.
- 새 수량이 0보다 작아지면 `false`를 반환해요.
- 새 수량이 0이면 `bill`에서 품목을 완전히 제거한 뒤 `true`를 반환해요.
- 그렇지 않으면 품목의 수량을 줄이고 `true`를 반환해요.

```go
bill := NewBill()
units := Units()
ok := RemoveItem(bill, units, "carrot", "dozen")
fmt.Println(ok)
// Output: false (because there are no carrots in the bill)
```

> 반환 값의 타입은 `bool`이라는 점에 주의해요.

## 5. 고객 청구서에 있는 특정 품목의 수량 반환하기

이걸 구현하려면 다음을 해야 해요:

- `item`이 청구서에 없으면 `0`과 `false`를 반환해요.
- 그렇지 않으면 `bill`에 있는 품목의 수량과 `true`를 반환해요.

```go
bill := map[string]int{"carrot": 12, "grapes": 3}
qty, ok := GetItem(bill, "carrot")
fmt.Println(qty)
// Output: 12
fmt.Println(ok)
// Output: true
```

> 반환 값의 타입은 `int`와 `bool`이라는 점에 주의해요.
