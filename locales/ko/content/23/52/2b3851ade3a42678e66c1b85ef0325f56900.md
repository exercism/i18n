# 읽기 전용 클래스와 프로퍼티

읽기 전용 클래스와 프로퍼티를 사용하면 클래스가 쉽게 접근할 수 있도록 public 프로퍼티를 지정하되, 수정은 할 수 없게 만들 수 있어요.
프로퍼티를 읽기 전용으로 선언하려면 타입 지정 앞에 `readonly`를 붙여야 해요.
프로퍼티에는 값을 한 번만 할당할 수 있고, 값을 다시 할당하거나 수정하려고 하면 오류가 발생해요.

```php
<?php

class Block
{
    public function __construct(
        public readonly int $length;
        public readonly int $width;
    ) {
    }
}
```

읽기 전용 클래스는 이 동작을 바탕으로 해요. 클래스를 `readonly`로 선언하면 각 프로퍼티에 읽기 전용 선언이 그대로 적용돼요.
또한 동적 프로퍼티를 추가하는 것도 막아 줘요.

```php
<?php

readonly class Block
{
    public function __construct(
        public int $length;
        public int $width;
    ) {
    }
}
```
