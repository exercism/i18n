# 반복자

카운터로 배열을 훑으려면, 실제 작업을 하기도 전에 네 줄이나 되는 부수적인 코드를 먼저 써야 해요:

```sather
   i ::= 0;
   loop
      until!(i >= counts.size);
      total := total + counts[i];
      i := i + 1;
   end;
```

카운터도, 끝나는지 확인하는 검사도, 값을 하나씩 늘리는 단계도 숫자를 더하는 일과는 아무 상관이 없어요. **반복자**는 이 세 가지를 모두 대신해 줘요.

```sather
   loop
      total := total + counts.elt!;
   end;
```

`elt!`는 한 바퀴 돌 때마다 원소를 하나씩 넘겨주고, 더 넘겨줄 원소가 없으면 루프를 끝내요. 카운터도 없고, 잘못될 일도 없고, 배열의 끝을 넘어갈 일도 없어요.

## 느낌표

`!`는 반복자라는 표시예요. 이미 세 개를 만났죠. `until!`, `while!`, `break!` 모두 같은 규칙을 따라요: **반복자는 루프 안에서만 호출할 수 있어요.** 루프 밖에서 `counts.elt!`라고 쓰는 건 오류예요.

루프 안에서 호출된 반복자는 한 바퀴 돌 때마다 값을 하나씩 내놓아요. 더 내놓을 값이 없으면, 호출이 본문의 어디에 있든 루프는 곧바로 끝나요.

## 먼저 살펴볼 두 가지

`elt!`는 배열이나 문자열의 원소를 순서대로 내놓아요.

```sather
   loop
      #OUT + names.elt! + "\n";
   end;
```

`upto!`는 숫자를 세요. `1.upto!(5)`는 1, 2, 3, 4, 5를 내놓고 나서 루프를 끝내요.

```sather
   loop
      total := total + 1.upto!(5);
   end;
```

둘 다 이름이 우연히 `!`로 끝나는 평범한 루틴일 뿐이라서, 배열이나 숫자 뒤에 점을 찍어 호출해요.

## 결과를 남겨 두기

루프는 스스로 끝나기 때문에, 루프 안에서 계산한 값은 **바깥**에서 선언한 변수에 담아 둬야 해요. 그렇지 않으면 루프가 끝날 때 함께 사라져 버려요.

```sather
   total ::= 0;             -- outside
   loop
      total := total + counts.elt!;
   end;
   return total;
```
