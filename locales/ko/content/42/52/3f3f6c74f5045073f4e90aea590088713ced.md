# 지침

Chaitana는 아주 인기 있는 테마파크를 운영해요.
아름답게 가꾼 부지 한가운데에는 놀이기구가 단 하나뿐이에요. 바로 The Biggest Roller Coaster in the World(TM)예요.
이 하나뿐인 명소인데도 사람들은 세계 곳곳에서 찾아와 Chaitana의 하이퍼코스터를 타려고 몇 시간씩 줄을 서요.

이 놀이기구에는 두 개의 대기열이 있고, 각각은 `array`로 표현돼요:

1. 일반 대기열
2. 익스프레스 대기열(_패스트트랙이라고도 불러요_) - 돈을 더 내면 우선적으로 탈 수 있는 곳이에요.

공원 손님들을 더 잘 관리할 수 있도록 코드를 작성해 달라는 요청을 받았어요.
손님들(그리고 사장님인 Chaitana!)이 짜증을 내기 전에 다음 함수들을 최대한 빨리 구현해야 해요.

## 1. 대기열에 사람 추가하기

`<express_queue>, <normal_queue>, <ticket_type>, <person_name>` 네 개의 인자를 받아서, 해당 인물의 이름이 추가된 알맞은 대기열을 반환하는 `ColossalCoaster.add_to_queue` 메서드를 정의해요.

1. `<ticket_type>`은 `Int32`이고, 1은 express_queue, 0은 normal_queue를 나타내요.
2. `<person_name>`은 각 대기열에 추가할 사람의 이름이에요 (`String` 타입).

```crystal
express_queue = ["Tony", "Bruce"]
normal_queue = ["RobotGuy", "WW"]
ColossalCoaster.add_to_queue(express_queue, normal_queue, 1, "RichieRich")
# => ["Tony", "Bruce", "RichieRich"]
```

## 2. 내 친구들은 어디에 있을까요?

어떤 사람이 공원에 늦게 도착했는데, 친구들이 기다리고 있는 대기열에 합류하고 싶어 해요.
그런데 친구들이 어디에 서 있는지 전혀 모르고, 전화할 수 있는 신호도 잡히지 않아요.

`queue`와 `friend_name` 두 개의 인자를 받아서, 대기열에서 그 사람 이름이 있는 위치를 반환하는 `ColossalCoaster.find_my_friend` 메서드를 정의해요.

1. `<queue>`는 대기열에 서 있는 사람들의 `array`예요.
2. `<friend_name>`은 그 인덱스, 즉 대기열에서의 위치를 찾아야 하는 친구의 이름이에요.

```crystal
ColossalCoaster.find_my_friend(["Natasha", "Steve", "T'challa", "Wanda", "Rocket"], "Steve")
# => 1
```

## 3. 친구들 사이에 끼어도 될까요?

이제 (위의 2번 문제에서) 친구들을 찾았으니, 늦게 도착한 사람은 친구들이 서 있는 자리에 합류하고 싶어 해요.
`queue`, `friend_name`, `person_name` 세 개의 인자를 받는 `ColossalCoaster.add_with_friends` 메서드를 정의해요.

1. `<queue>`는 대기열에 서 있는 사람들의 `array`예요.
2. `<friend_name>`은 그 사람을 추가할 위치에 서 있는 친구의 이름이에요.
2. `<person_name>`은 해당 인덱스 위치에 추가할 사람의 이름이에요.

늦게 도착한 사람의 이름이 추가된 대기열을 반환해요.

```crystal
ColossalCoaster.add_with_friends(["Natasha", "Steve", "T'challa", "Wanda", "Rocket"], "Steve", "Bucky")
# => ["Natasha", "Bucky", "Steve", "T'challa", "Wanda", "Rocket"]
```

## 4. 대기열의 못된 사람

방금 대기열에서 아주 못된 사람이 밀치고 소리치고 소란을 피우고 있다는 얘기를 들었어요.
그 못된 사람을 나쁜 행동 때문에 쫓아내야 해요!

`queue`와 `person_name` 두 개의 인자를 받는 `ColossalCoaster.remove_from_queue` 메서드를 정의해요.

1. `<queue>`는 대기열에 서 있는 사람들의 `array`예요.
2. `<person_name>`은 쫓아내야 하는 사람의 이름이에요.

못된 사람의 이름이 빠진 대기열을 반환해요.

```crystal
ColossalCoaster.remove_from_queue(["Natasha", "Steve", "Eltran", "Wanda", "Rocket"], "Eltran")
# => ["Natasha", "Steve", "Wanda", "Rocket"]
```

## 5. 대기열 목록 정렬하기

관리 목적으로, 주어진 대기열에 있는 모든 이름을 알파벳 순서로 정리해야 해요.

`queue`(대기열에 서 있는 사람들의 `array`)를 인자 하나로 받는 `ColossalCoaster.sorted_queue` 메서드를 정의해요.
이 메서드는 `array`를 정렬한 복사본을 반환해야 해요.

```crystal
ColossalCoaster.sorted_queue(["Natasha", "Steve", "Eltran", "Natasha", "Rocket"])
# => ['Eltran', 'Natasha', 'Natasha', 'Rocket', 'Steve']
```
