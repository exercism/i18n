# 디버그

테스트가 실패하면 무엇이 잘못되었는지 설명하는 메시지가 표시돼요.
출력을 더 보고 싶다면, 살펴보고 싶은 코드 주위에 `::YYY()` 서브루틴을 사용할 수 있어요.
(`::`는 `main::`의 축약형이에요.)
이 서브루틴은 [XXX][XXX] 모듈의 일부예요.

`say` 함수로 메시지를 간단히 출력할 수도 있어요. 예를 들어 `say 'Hello, World!';`처럼요.

온라인 테스트 러너는 [Test Anything Protocol][TAP]을 사용해요.
TAP의 특성상, 온라인 테스트 러너에서는 `print` 사용을 강력히 권장하지 않아요.
