# 테스트

각 연습 문제에는 단위 테스트와 Make 빌드 레시피가 함께 제공돼요.
구현은 직접 작성해요.

각 테스트 파일은 여러분의 구현과 링크되어, 테스트를 실행하는 콘솔 실행 파일을 만들어요.
테스트 실행 파일을 실행하면 실패한 각 테스트에 대한 메시지가 출력되고, 테스트가 실패하면 0이 아닌 종료 상태를 보고해요.

연습 문제를 풀려면:
* Make로 초기 빌드를 만들어요
* 각 단위 테스트마다:
  * `TEST_IGNORE()` 줄을 삭제해요.
  * 컴파일 오류를 해결해 테스트가 실패하도록 만들어요.
  * 테스트를 통과시킬 만큼만 구현해요.
  * 가독성을 높이고 중복을 줄이는 등, 구현을 리팩터링해요.
