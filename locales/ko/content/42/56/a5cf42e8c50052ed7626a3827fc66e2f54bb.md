# 소개

## 기본 매개변수 값

[기본 매개변수 값][default-parameter-values]은 매개변수 목록에서 매개변수의 타입 애너테이션 뒤에 값을 할당하는 방식으로 함수의 어떤 매개변수에든 지정할 수 있어요. 기본 매개변수 값이 지정되면, 함수를 호출하는 쪽에서 그 매개변수를 생략할 수 있고 대신 기본값이 사용돼요.

```swift
func greeting(name: String = "guest", duration: Int = 2) -> String {
  "Welcome, \(name). Enjoy your \(duration) night stay."
}

greeting(name: "Bobo", duration: 7)
// Returns "Welcome, Bobo. Enjoy your 7 night stay."
greeting(duration: 3)
// Returns "Welcome, guest. Enjoy your 3 night stay."
greeting(name: "Wynona")
// Returns "Welcome, Wynona. Enjoy your 2 night stay."
greeting()
// Returns "Welcome, guest. Enjoy your 2 night stay."
```

## 가변 매개변수

[가변 매개변수][variadic-parameters]를 사용하면 함수가 하나의 매개변수에 대해 지정된 타입의 값을 0개 이상 받을 수 있어요.
가변 매개변수는 매개변수의 타입 애너테이션 뒤에 점 세 개(`...`)를 붙여서 정의해요.

함수 본문 안에서 Swift는 이 값들을 지정된 타입의 배열로 사용할 수 있게 해줘요:

```swift
import Foundation

func geometricMean(_ numbers: Double...) -> Double {
    var total = 1.0
    for number in numbers {
        total *= number
    }
    return pow(total, 1.0 / Double(numbers.count))
}

let result = geometricMean(1, 2, 3, 4, 5)
// result is 2.605171084697352
```

~~~~exercism/note
함수에 가변 매개변수 뒤에 이어지는 매개변수가 더 있으면, 가변 매개변수 다음에 오는 첫 번째 매개변수에는 **반드시** 명시적인 인자 레이블이 있어야 Swift가 가변 인자 목록이 어디에서 끝나는지 알 수 있어요.
~~~~


## in-out 매개변수

함수 본문 안에서 매개변수는 변수가 아니라 상수로 취급돼요. 매개변수의 값을 바꾸려고 하면 컴파일 타임 오류가 발생해요.
함수가 매개변수의 값을 바꾸고 싶다면, 이 변경 가능성을 명시적으로 드러내기 위해 [_in-out 매개변수_][in-out-parameters]를 사용해야 해요.

in-out 매개변수를 사용하려면 프로그래머는 세 가지를 확실히 해야 해요:

1. 함수 정의에서 매개변수의 타입 애너테이션에 있는 `:`와 타입 이름 사이에 `inout` 키워드를 써서 in-out 매개변수를 명시적으로 표시해야 해요.
2. in-out 매개변수에 전달되는 값은 상수가 아니라 변수로 선언해야 해요. 마찬가지로 리터럴일 수도 없어요.
3. 함수를 호출할 때 변수 이름 앞에 `&`를 붙여서 수정할 수 있음을 명시적으로 표시해야 해요.

이렇게 하면 함수는 in-out 매개변수의 내부 복사본을 만들고, 함수 본문에서 지시한 대로 수정한 다음, 함수가 반환될 때 수정된 값을 전달받은 변수에 다시 복사해요.

```swift
func updateVersion(_ record: inout (version: Int, title: String)) {
  record.version += 1
}

var dbRecord = (version: 2, title: "Exercism")
updateVersion(&dbRecord)

// dbRecord is now (3, "Exercism")
```

~~~~exercism/warning
in-out 매개변수와 관련해서 알아 두어야 할 추가 규칙이 몇 가지 있어요.

1. in-out 매개변수가 있는 함수 안에서는 in-out 매개변수로 전달된 변수를 참조할 수 없어요.
2. 같은 변수를 같은 함수의 여러 in-out 매개변수로 전달할 수 없어요.
   예를 들어 `inoutFunc(&mutVar, &mutVar)`는 컴파일러 오류를 발생시켜요.
~~~~

## 중첩 함수

Swift에서는 함수를 [다른 함수 안에서][nested-functions] 정의할 수 있어요.
이런 함수를 **중첩 함수**라고 해요.

중첩 함수는 감싸는 함수를 위해 특정 작업을 수행하면서 바깥 스코프를 어지럽히지 않는, 일종의 비공개 도우미 함수로 흔히 사용해요:

```swift
func makeNumber(_ number: Int) -> Int {
    func double(_ x: Int) -> Int {
        x * 2
    }

    func increment(_ x: Int) -> Int {
        x + 1
    }

    return number.isMultiple(of: 2) ? increment(double(number)) : double(number)
}

print(makeNumber(3)) // Prints 6
print(makeNumber(4)) // Prints 9
```

중첩 함수는 일반 함수처럼 동작하지만, 감싸는 함수의 본문 안에서만 보여요.
