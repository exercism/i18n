# 소개

*제네릭 워드*는 인자의 클래스에 따라 서로 다른 구현을 가질 수 있는 연산을 선언해요. 메서드는 `M:`로 추가해요.

```factor
USING: kernel math ;

GENERIC: area ( shape -- n )

TUPLE: square side ;
TUPLE: circle radius ;

M: square area side>> dup * ;
M: circle area radius>> dup * 3.14159 * ;
```

```factor
T{ square { side 4 } } area .    ! => 16
T{ circle { radius 2 } } area .  ! => 12.56636
```

`GENERIC:`는 워드와 그 스택 효과를 선언해요. `M:`는 특정 클래스에 메서드를 정의해요. Factor는 실행 중에 가장 위에 있는 인자의 클래스를 기준으로 알맞은 메서드를 골라요.

제네릭에게 어떤 클래스에 대한 메서드를 가지고 있는지 물어볼 수 있고, 나중에 메서드를 추가하거나 제거할 수도 있어요. 특별한 상속 문법은 없어요. 어떤 튜플 클래스든 자동으로 메서드를 정의할 수 있는 대상이 돼요.
