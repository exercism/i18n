# 지시 사항

최고의 믹솔로지스트로서, 사람들이 밤에 나가서 즐길 맛있는 음료를 만들어요. 그런데 코드를 조금만 작성하면 일이 훨씬 수월해질 거라고 생각했어요.

## 1. 주문을 만드는 데 걸리는 시간 알아내기

음료마다 준비하는 데 걸리는 시간이 달라요.

- `"beer"`, `"soda"`, `"water"`는 각각 0.5분이 걸려요.
- `"shot"`은 1.0분, `"mixed drink"`는 1.5분이 걸려요.
- `"fancy drink"`는 2.5분이 걸려요.
- `"frozen drink"`는 3.0분이 걸려요.

준비해야 하는 음료를 문자열 배열로 담고 있는 `drinks` 인자를 받는 함수 `timeToPrepare(drinks:)`를 구현해요.
이 함수는 배열에 있는 모든 음료를 준비하는 데 걸리는 총 시간을 반환해야 해요.

```swift
timeToPrepare(drinks: ["beer", "frozen drink", "shot"])
// returns 4.5
```

## 2. 라임 웨지 비축량 채우기

근무를 시작하면 가장 먼저 해야 할 일 중 하나는, 앞으로의 근무를 위해 라임 웨지를 담은 작은 통을 가득 채워 두는 거예요.
라임은 크기에 따라 얻을 수 있는 웨지 수가 달라요. "small" 라임에서는 웨지 6개, "medium" 라임에서는 8개, "large" 라임에서는 10개를 얻을 수 있어요.

웨지가 더 필요하고 아직 손질할 라임이 남아 있는 동안에는 배열에서 첫 번째 라임을 꺼내고, 필요한 웨지 수에서 그 라임으로 얻을 수 있는 웨지 수를 빼요.
더 이상 웨지가 필요하지 않거나 라임이 다 떨어질 때까지 이 과정을 계속해요.

잘라 내야 할 웨지 수를 담은 `needed`와, 손질할 수 있는 라임의 크기를 문자열 배열로 담고 있는 `limes` 인자를 받는 함수 `makeWedges(needed:limes:)`를 구현해요.
이 함수는 손질한 라임의 개수를 반환해야 해요.

```swift
makeWedges(needed: 25, limes: ["small", "small", "large", "medium", "small"])
// returns 4
```

## 3. 근무 마무리하기

축하해요! 긴 근무일도 거의 끝나가고, 곧 집에 가서 새 앱을 만들 수 있어요.
하지만 다음 근무자에게 주문을 인계하고 퇴근하기 전에, 아직 처리해야 할 음료 주문이 줄줄이 남아 있어요.

근무 시간이 남아 있는 동안에는 배열의 첫 번째 주문을 만들고, 그 주문을 배열에서 제거해요.
그런 다음 `timeToPrepare(drinks:)` 함수를 기준으로 그 주문을 준비하는 데 걸린 시간을 남은 근무 시간에서 빼면 돼요.

근무에 남은 시간(분)과 비어 있지 않은 음료 주문 배열을 받는 함수 `finishShift(minutesLeft:remainingOrders:)`를 구현해요.
남은 시간은 항상 0보다 커요.
이 함수는 근무가 끝나기 전까지 처리하지 못한 주문 배열을 반환해야 해요.

```swift
finishShift(minutesLeft: 5, remainingOrders: [["beer", "frozen drink", "shot"], ["fancy drink", "soda"], ["beer", "beer", "water"], ["mixed drink", "frozen drink"]])
// returns [["beer", "beer", "water"], ["mixed drink", "frozen drink"]]
```

## 4. 특정 주문 추적하기

beer와 soda가 신선하게 유지되도록 하려면, 그 주문과 주문이 들어온 시간을 함께 추적해야 해요.

주문과 시간 목록이 주어지면 beer와 soda 각각의 첫 주문과 마지막 주문 시간, 총주문 수를 담은 옵셔널 튜플 한 쌍을 반환하고, 해당 음료 주문이 하나도 없으면 `nil`을 반환하는 함수 `orderTracker(orders: [(drink: String, time: String)]) -> (beer: (first: String, last: String, total: Int)?, soda: (first: String, last: String, total: Int)?)`를 구현해요.
다른 음료는 추적하지 않아도 돼요.

주문한 음료와 주문이 들어온 시간을 각각 담고 있는 튜플들의 배열을 받는 함수 `orderTracker(orders:)`를 구현해요.
이 함수는 beer가 주문된 첫 번째와 마지막 시간, beer 주문의 총개수, soda가 주문된 첫 번째와 마지막 시간, soda 주문의 총개수를 담은 튜플을 반환해야 해요.
반환 형식은 `(beer: (first: String, last: String, total: Int)?, soda: (first: String, last: String, total: Int)?)`이어야 해요.

```swift
let orders = [
    (drink: "beer", time: "10:01"), (drink: "frozen drink", time: "10:02"),
    (drink: "shot", time: "10:05"), (drink: "fancy drink", time: "10:06"),
    (drink: "soda", time: "10:09"), (drink: "beer", time: "10:15"), (drink: "beer", time: "10:22"),
    (drink: "water", time: "10:26"), (drink: "mixed drink", time: "10:28"),
    (drink: "frozen drink", time: "10:33"),
]

orderTracker(orders: orders)

// returns (beer: (first "10:01", last "10:22", total 3), soda: (first "10:09", last "10:09", total 1))
```
