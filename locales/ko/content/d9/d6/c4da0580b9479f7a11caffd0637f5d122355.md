# 힌트

## General

- `unparse`는 [`prettyprint`][prettyprint]에 있고, 슬라이스 변형들은 [`sequences`][sequences]에, 다중 입력 cleave 계열은 [`combinators`][combinators]에 있어요.

## 1. 값 인용하기

- 한 단어: `unparse`.

## 2. 플래그 틀 벗겨내기

- `1 tail-slice`로 앞쪽 마커를 떼어낸 다음, `1 head-slice*`로 뒤쪽 마커를 떼어내요.

## 3. 플래그 나누기

- `head-slice`와 `tail-slice` 모두 스택에 플래그*와* 헤더 길이가 필요해요. 바로 `[ head-slice ] [ tail-slice ] 2bi`예요.

## 4. 두 값으로 삼각측량하기

- 같은 두 값을 받는 서로 다른 세 개의 인용: `[ - ] [ + 2 / ] [ / ] 2tri`.

## 5. 세 값 요약하기

- 각각 세 개의 입력을 받는 인용 세 개: `3tri`. 합을 구하는 인용은 `[ + + ]`, 곱은 `[ * * ]`, 최댓값은 `[ max max ]`예요.
