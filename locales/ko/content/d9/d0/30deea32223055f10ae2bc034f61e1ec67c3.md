# 소개

## 불리언

`Bool` 타입은 언어의 기본 구성 요소 중 하나예요.
어떤 것이 참인지 거짓인지 나타내는 데 사용되며, 각각 `True`와 `False` 값을 가져요.

불리언은 `&&`(AND)와 `||`(OR) 연산자로 결합할 수 있고, `not` 함수로 부정할 수 있어요.

불리언은 특정 조건이 충족될 때만 실행되는 분기를 만들 때도 아주 유용해요.
Elm에서는 `if-then-else` 표현식으로 분기를 만들어요. 다음과 같이 사용해요.

```elm
if someCondition || (someOtherCondition && anotherCondition) then
    doSomething
else
    doSomethingElse
```
