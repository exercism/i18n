# 안내

Lucy는 온라인 스티커 가게를 운영하며, 누구나 좋아하는 프로그래밍 언어를 담은 귀여운 스티커를 팔아요. 전 세계 사람들이 Lucy의 스티커를 사 가는데, 여러 가지 통화를 다루는 일이 쉽지 않아요.

Lucy가 가격을 계산할 때 언제나 올바른 통화를 쓰고 있는지 확신할 수 있도록 도와주는 프로그램을 만들어 봐요.

## 1. `Usd`, `Eur`, `Jpy` 타입 정의하기

이 타입들은 Lucy의 고객이 스티커를 살 때 사용하는 서로 다른 통화를 나타내는 데 쓰여요.

이 타입들은 팬텀 타입으로 사용되며, 생성자가 필요하지 않아요.

## 2. `Money` 타입 정의하기

`Money` 타입은 금액을 나타내는 `Int` 필드와 통화 팬텀 타입 매개변수를 가져야 하고, 불투명 타입이어야 해요.

## 3. `dollar`, `euro`, `yen` 함수 정의하기

`dollar`, `euro`, `yen` 함수는 `Int` 인자를 받아 올바른 통화의 `Money` 값을 반환해요.

## 4. `total` 함수 정의하기

`total` 함수는 `Money` 값들로 이루어진 배열을 받아 그 배열에 담긴 금액의 합계를 반환해요.

```gleam
total([euro(120), euro(200), euro(145)])
// -> euro(465)
```
