# 소개

벡터는 1차원 배열이에요. 벡터에는 서로 다른 타입의 원소를 담을 수 있어요.

## 벡터 만들기

벡터는 `vector` 함수로 만들거나, 리더 형식인 `#()`를 사용해서 만들 수 있어요.

```lisp
(vector 1 t "foo" 'b) ; => #(1 T "foo" B)
#(2 nil "bar" a)      ; => #(2 NIL "bar" A)
```

벡터는 배열이기 때문에 `make-array`로도 만들 수 있어요.

```lisp
(make-array 3 :initial-element 'x)        ; => #(X X X)
(make-array 3 :initial-contents '(a b c)) ; => #(A B C)
```

## 벡터 판별

어떤 객체가 벡터인지 확인하려면 `vectorp` 판별 함수를 사용하면 돼요.

## 원소 접근하기

벡터의 원소에 접근하려면 `aref`를 사용해요. 인덱스는 0부터 시작해요.

```lisp
(aref #(1 2 3) 1) ; => 2
(aref #(a b c) 0) ; => A
```
