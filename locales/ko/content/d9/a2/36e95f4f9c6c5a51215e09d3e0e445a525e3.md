# 소개

Go에서는 `for`와 인덱스를 사용해 `slice`를 순회할 수도 있고, `range`를 사용할 수도 있어요. `range`를 사용하면 `map`도 순회할 수 있어요.

각 반복은 두 개의 값을 반환해요. 인덱스/키와, 그 인덱스/키에 있는 원소의 복사본이에요.

## 슬라이스 순회

아주 쉬워요. 슬라이스를 순회하면 예상한 순서대로 나와요.

```go
xi := []int{10, 20, 30}
for i, x := range xi {
  fmt.Println(i, x)
}
// outputs:
// 0, 10
// 1, 20
// 2, 30
```

## 맵 순회

맵을 순회할 때는 새로운 문제가 생겨요. 이제 순서가 무작위예요.

```go
hash := map[int]int{9: 10, 99: 20, 999: 30}
for k, v := range hash {
  fmt.Println(k, v)
}
// outputs, for example:
// 99 20
// 999 30
// 9 10
```

~~~~exercism/note
위 출력이 잘못된 것처럼 보일 수 있어요. 맵을 선언할 때 처음 등장한 키/값 쌍인 `9 10`이 마지막이 아니라 가장 먼저 출력될 거라고 생각하기 쉽거든요. 하지만 맵은 본질적으로 순서가 없어요. 처음이나 마지막 키/값 쌍이라는 게 없어요. 그래서 맵의 항목을 순회할 때 방문하는 순서는 무작위이고, 특별한 규칙을 따르지 않아요. 즉, 위와 같은 출력이 나올 수도 있지만 직접 실행해 보면 결과가 다를 수도 있어요. 이에 대해 더 알아보려면 [Go 언어 명세: range 절](https://go.dev/ref/spec#RangeClause)을 참고해요.
~~~~

## 키나 값 생략하기

Go에서는 사용하지 않는 변수가 있으면 빌드할 때 오류가 발생해요. 첫 번째 예시처럼 값만 필요할 때도 있어요.

```go
xi := []int{10, 20, 30}
for i, x := range xi {
  fmt.Println(x)
}
// Go build failed: i declared but not used
```

`i`를 `_`로 바꾸면, 컴파일러에게 그 값을 사용하지 않는다고 알려 줄 수 있어요.

```go
xi := []int{10, 20, 30}
for _, x := range xi {
  fmt.Println(x)
}
// outputs:
// 10
// 20
// 30
```

인덱스만 출력하고 싶다면 `x`를 `_`로 바꾸거나, 선언 자체를 생략하면 돼요.

```go
xi := []int{10, 20, 30}
// for i, _ := range xi {
for i := range xi {
  fmt.Println(i)
}
// outputs:
// 0
// 1
// 2
```

## 구조체가 아닌 타입

앞에서 구조체 타입을 정의하는 것을 봤어요. 구조체가 아닌 타입도 정의할 수 있는데, 내장 타입 선언의 별칭으로 사용할 수 있고, 구조체 타입과 같은 방식으로 리시버 함수를 정의해 확장할 수도 있어요.

```go
type Name string
func SayHello(n Name) {
  fmt.Printf("Hello %s\n", n)
}
n := Name("Fred")
SayHello(n)
// Output: Hello Fred
```

배열과 맵으로 구성된 구조체가 아닌 타입도 정의할 수 있어요.

```go
type Names []string
func SayHello(n Names) {
  for _, name := range n {
    fmt.Printf("Hello %s\n", name)
  }
}
n := Names([]string{"Fred", "Bill"})
SayHello(n)
// Output:
// Hello Fred
// Hello Bill
```
