# 설치

연습 문제를 풀려면 [Vim](http://www.vim.org)이 필요해요:

- [macOS](#macos)
- [Ubuntu / Debian](#ubuntu--debian)
- [Windows](#windows)
- [소스](#source)

## macOS

macOS에는 Vim이 기본으로 들어 있지만, 그 버전은 너무 오래돼서 사실상 쓸 수 없어요.

아마 소프트웨어를 설치할 때 [MacPorts](https://www.macports.org)나
[Homebrew](https://brew.sh)를 쓰고 있을 거예요.

Homebrew:

```
$ brew update
$ brew install vim
```

MacPorts:

```
$ sudo port install vim +huge
```

GUI가 필요하다면 대신 [MacVim](https://macvim-dev.github.io/macvim)을 살펴봐요.

## Ubuntu / Debian

GUI를 지원하는 완전한 Vim(`gvim`)을 설치해요:

```
$ sudo apt-get update
$ sudo apt-get install vim-gtk
```

## Windows

[Chocolatey](https://chocolatey.org)를 사용한다면:

```
C:\> choco install vim
```

아니면 [여기](http://www.vim.org/download.php#pc)에서 바로 내려받아 설치해도 돼요.

## 소스
