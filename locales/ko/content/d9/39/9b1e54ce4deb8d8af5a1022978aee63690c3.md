# 소개

## include

다른 파일의 내용을 포함하려면 C++에서는 `include` 지시문을 사용해요.
이 include 지시문들은 파일 맨 위에 적어야 해요.
컴파일하는 동안 지시문이 있는 줄은 해당 파일의 내용으로 바뀌어요.
include 후에도 네임스페이스는 원본 파일에 있던 그대로 유지돼요.

## 표준 라이브러리

표준 라이브러리는 자주 쓰는 함수, 알고리즘, 자료 구조를 많이 제공해요.
표준 라이브러리는 `std` 네임스페이스를 사용해요.

한 예로 C 수치 라이브러리인 `cmath`가 있어요.
이 라이브러리는 여러 가지 수학 연산을 제공해요.

```cpp
#include <cmath>

int cube_me(int a) {
    // raise `a` to the third power
    return std::pow(a, 3);
}
```

~~~~exercism/note
표준 라이브러리는 큰따옴표 `"`가 아니라 꺾쇠괄호 `<>`로 include해요.
차이는 컴파일러가 각 파일을 찾는 위치에 있어요.
꺾쇠괄호를 사용하는 경우 현재 프로젝트에서의 검색은 건너뛰고, 시스템의 include 디렉터리에서 바로 시작해요.
로컬 파일을 include하려면 큰따옴표를 사용해요: `#include "myfile"`
~~~~
