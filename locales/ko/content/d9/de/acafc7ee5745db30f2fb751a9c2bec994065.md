# 소개

## 상수

Gleam의 상수는 값에 이름을 붙이는 방법이에요. `const` 키워드로 정의해요.

```gleam
pub const pi: Float = 3.14159

pub fn circle_area(radius: Float) -> Float {
  radius *. radius *. pi
}
```

`pub` 키워드와 함께 정의하면 모듈 상수를 다른 모듈에서도 가져다 쓸 수 있지만, 그렇지 않으면 정의한 모듈 안에서만 쓸 수 있어요.

## 순서

Gleam 표준 라이브러리의 `gleam/order` 모듈에는 값을 비교할 때 사용하는 `Order` 타입이 들어 있어요.

`Order`의 정의는 이렇게 생겼어요.

```gleam
pub type Order {
  Gt
  Eq
  Lt
}
```

이 타입에는 세 가지 변형이 있고, 각각 어떤 값과 다른 값 사이의 관계를 나타내요.

- `Gt` - 값이 다른 값보다 _큰_ 경우예요.
- `Eq` - 값이 다른 값과 _같은_ 경우예요.
- `Lt` - 값이 다른 값보다 _작은_ 경우예요.

어떤 데이터 타입을 크기로 비교할 수 있다면, 그 모듈에서 `Order` 값을 반환하는 `compare` 함수를 정의하는 경우가 많아요. 예를 들어 `gleam/float`과 `gleam/int`는 각각 실수와 정수를 다루는 `compare` 함수를 정의해요.

```gleam
int.compare(1, 2)
// -> Lt

int.compare(2, 2)
// -> Eq

float.compare(1.0, 2.0)
// -> Lt
```

`list.sort` 같은 정렬 함수는 보통 `Order` 값을 반환하는 함수를 인자로 받아요. 그래서 호출하는 쪽에서 배열을 어떻게 정렬할지 정할 수 있어요.

```gleam
list.sort([3, 7, 3, 1], by: int.compare)
// -> [1, 3, 3, 7]
```
