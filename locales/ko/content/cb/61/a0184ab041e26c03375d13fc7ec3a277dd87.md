# 소개

Python은 [동적이면서도 강한 타입 지정을 사용하는][dynamic typing in python] 프로그래밍 언어예요.
[덕 타이핑][duck typing]과 [점진적 타이핑][gradual typing]을 [타입 힌트][type hints]를 통해 함께 지원해요.
Python은 코드 가독성을 특히 중요하게 여기며, (_Haskell과 마찬가지로_) 함수, 메서드, 클래스 정의를 나타낼 때 [의미 있는 들여쓰기][significant indentation]를 사용해요.

Python은 Guido van Rossum이 만들었고, 1991년에 처음 공개됐어요.

명령형, 선언형(예: 함수형), 객체 지향 프로그래밍 _스타일_을 모두 지원하지만, 내부적으로는 **[Python에서는 모든 것이 객체][everythings an object]**예요.

이 모든 것이 무슨 뜻인지는 Python 트랙의 개념들을 계속 살펴보면서 더 자세히 알아볼게요.

이 첫 번째 개념(`basics`)에서는 Python의 네 가지 주요 기능을 소개해요:
1.  이름 할당(_변수와 상수_),
2.  함수(_`def` 키워드와 `return` 키워드_),
3.  주석,
4.  독스트링.

<br>

## 이름 할당 (변수와 상수)

프로그래머는 할당 `=` 연산자를 사용해 [_이름_][facts-and-myths-about-python-names](_변수_라고도 해요)을 모든 타입의 객체에 연결할 수 있어요: `<name> = <value>`.
이름은 수명 동안 다른 값(다른 객체 타입)으로 다시 할당(또는 다시 바인딩)될 수 있어요:


```python
>>> my_first_variable = 1  # <--my_first_variable bound to an integer object of value one.
>>> my_first_variable = 2  # <--my_first_variable re-assigned to integer value 2.

>>> print(type(my_first_variable))
<class 'int'>

>>> print(my_first_variable)
2

>>> my_first_variable = "Now, I'm a string." # <--You may re-bind a name to a different object type and value.
>>> print(type(my_first_variable))
<class 'str'>

>>> my_first_variable = 'You can call me "str".' # <--Strings can be declared using single or double quote marks.
>>> print(my_first_variable)
You can call me "str".
```


### 상수

상수는 프로그램에서 한 번만 할당하도록 의도된 이름이에요. 물론 Python이 재할당을 막지는 않아요.
`SCREAMING_SNAKE_CASE`를 쓰면 코드를 읽는 사람에게 이 이름은 **다시 할당**하거나 값을 바꾸면 안 된다는 신호를 줘요.
상수는 [모듈][module](파일) 수준에서 정의하는 것이 좋고, 보통 프로그램의 모든 함수와 클래스에서 볼 수 있어요.



## 함수

`def` 키워드로 [함수 정의][function definition]를 시작해요.
각 함수는 `()` 괄호 안에 0개 이상의 형식 [매개변수][parameters]를 가질 수 있고, 그 뒤에 `:` 콜론이 와요.
함수 _본문_의 문은 `def` 다음 줄부터 시작하며 _블록 안에서 들여쓰기_해야 해요.


```python
# The body of this function is indented by 2 spaces & prints the sum of the numbers.
def add_two_numbers(number_one, number_two):
  total = number_one + number_two
  print(total)  

>>> add_two_numbers(3, 4)
7


# Inconsistent indentation in your code blocks will raise an error.
>>> def add_three_numbers_misformatted(number_one, number_two, number_three):
...     result = number_one + number_two + number_three   # This was indented by 4 spaces.
...    print(result)     # <--This was only indented by 3 spaces.
...
...
  File "<stdin>", line 3
    print(result)
    ^
IndentationError: unindent does not match any outer indentation level
```


함수는 [`return`][return] 키워드를 통해 값이나 객체를 _명시적으로_ 반환해요:


```python
# Function definition on first line, explicit return used on final line.
def add_two_numbers(number_one, number_two):
  return number_one + number_two   


# Calling the function in the Python shell returns the sum of the numbers.
>>> add_two_numbers(3, 4)
7

# Assigning the function call to a variable and printing 
# the variable will also return the value.
>>> sum_with_return = add_two_numbers(5, 6)
>>> print(sum_with_return)
11
```


`return` 뒤에 _명시적인_ 표현식이 없는 함수는 [`None`][none] 객체를 _암시적으로_ 반환해요.
`None`의 자세한 내용은 나중 개념에서 다뤄요.
이 연습 문제와 설명에서는 `None`이 아무것도 없는 상태, 즉 null을 나타내는 자리 표시자라고 생각하면 돼요:


```python
# This function will return `None`
def square_a_number(number):
    square = number * number
    return # <-- note that this return is not followed by an expression

# Calling the function in the Python shell appears 
# to not return anything at all.
>>> square_a_number(2)
>>>


# Using print() with the function call shows that 
# the function is actually returning the **None** object.
>>> print(square_a_number(2))
None
```

`return`을 생략한 함수도 [`None`][none] 객체를 _암시적으로_ 반환해요.
즉, 함수에서 `return`을 사용하지 않으면 Python이 대신 `None` 객체를 반환해요.

```python
# This function omits a return keyword altogether.
def add_two_numbers(number_one, number_two):
  result = number_one + number_two

>>> add_two_numbers(5, 7)
>>> print(add_two_numbers(5, 7))
None

# Assigning the function call to a variable and printing 
# the variable will also show None.
>>> sum_without_return = add_two_numbers(5, 6)
>>> print(sum_without_return)
None
```


## 주석

Python에서 [주석][comments]은 문자열의 일부가 아닌 `#`으로 시작해서 줄이 끝날 때 끝나요.
다른 많은 프로그래밍 언어와 달리, Python은 여러 줄 주석 표시를 **지원하지 않아요**.
주석 블록의 각 줄은 `#` 문자로 시작해야 해요.


## 독스트링

함수 본문의 첫 번째 문은 선택적으로 [_독스트링_][docstring]이 될 수 있는데, 이는 함수나 객체의 목적을 간결하게 요약해 줘요.
독스트링은 [Sphinx][sphinx] 같은 자동 문서화 도구가 읽으며, 함수, 메서드, 클래스 이름에 특수 속성 `.__doc__`을 호출하면 반환돼요.
일반적인 독스트링 규칙은 [PEP257][pep257]에 나와 있지만, 정확한 형식은 프로젝트와 팀마다 달라요.
독스트링은 코드 블록과 같은 수준으로 들여쓰기한 삼중 큰따옴표(""")로 선언해요:
