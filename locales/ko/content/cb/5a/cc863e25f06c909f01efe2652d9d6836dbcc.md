# 지시 사항

체스 애호가라면 누구나 자신만의 체스 게임을 만들고 싶어 하죠.
맞아요, 온라인에 이미 체스 구현이 많이 있긴 하지만, 직접 만든 것은 세상에 하나뿐일 거예요!

먼저 체스판을 구현하는 것부터 시작해요.

체스 게임은 가로 8칸, 세로 8칸인 체스판에서 진행돼요.
각 칸은 문자 하나와 숫자 하나로 구분해요.

## 1. 랭크와 파일 범위 정의하기

게임은 체스판의 랭크를 저장해야 해요.
랭크는 체스판의 행이고, 1부터 8까지의 번호가 붙어요.

게임은 체스판의 파일도 저장해야 해요.
파일은 체스판의 열이고, A부터 H까지의 문자로 구분해요.

랭크와 파일의 범위를 각각 저장하는 `ranks`와 `files` 상수를 정의해요.

```swift
ranks
// Returns 1..8

files
// Returns "A".."H"
```

## 2. 칸이 유효한지 확인하기

게임은 칸이 유효한지 확인해야 해요.
칸의 랭크와 파일이 각각 랭크와 파일의 범위 안에 있으면 그 칸은 유효해요.

랭크를 나타내는 `Int`를 담은 `rank` 인자와 파일을 나타내는 `String`을 담은 `file` 인자를 받는 `isValidSquare(rank:file:)` 메서드를 정의해요.
이 메서드는 랭크와 파일이 랭크와 파일의 범위 안에 있으면 `true`를, 그렇지 않으면 `false`를 반환해야 해요.

```swift
isValidSquare(rank: 1, file: "A")
// Returns true
```

## 3. 행 가져오기

게임은 체스판의 모든 칸을 1차원 배열에 저장해요.
칸은 랭크와 파일을 이어 붙인 문자열로 만들어져요. 예를 들어 "1A", "8B", "4G" 등이에요.
어떤 칸의 행을 구하려면 게임은 그 행의 첫 번째 칸의 인덱스를 계산해야 해요.

랭크를 나타내는 `Int`를 담은 `rank` 인자를 받는 `getRow(rank:)` 메서드를 정의해요.
이 메서드는 해당 행의 칸들을 나타내는 문자열 배열을 반환해야 해요.

```swift
let board = ["1A", "1B", "1C", "1D", "1E", "1F", "1G", "1H", "2A", ..., "8H"]
getRow(board, rank: 1)
// Returns ["1A", "1B", "1C", "1D", "1E", "1F", "1G", "1H"]
```
