# 지침 추가

## 직접 배열 연산 구현하기

Rust에는 풍부한 이터레이터 시스템이 있어서, 이터레이터를 사용하면 이 연습 문제를 아주 간단하게 풀 수 있어요.
`map()`, `flatten()`, `filter()`, `count()`, `fold()`, `chain()`, `rev()` 같은 이터레이터 메서드를 사용하지 않고 연습 문제를 풀어 보세요.
`next()`와 `next_back()` 메서드는 여기에 포함되지 않아요.

## 할당 피하기

이 연습 문제는 풀이에 추가적인 메모리 할당을 들이지 않고도 풀 수 있어요.
컬렉션에서 이터레이터를 만드는 대신, 직접 이터레이터 타입을 만들어 볼 수 있는지 확인해 봐요.
