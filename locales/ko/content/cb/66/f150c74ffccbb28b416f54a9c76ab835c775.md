# 지침

이 연습 문제에서는 은행 운영에 사용할 몇 가지 상수를 만들어 봐요.

다섯 개의 과제가 있어요:

## 1. 대출의 고정 금리를 나타내기

5%(5/100) 값을 담을 `FixedInterestRate` 타입 없는 숫자 상수를 만든 다음, 이 값을 반환하는 `GetFixedInterestRate` 함수를 구현해요:

```go
GetFixedInterestRate()
// => 0.05
```

## 2. 1년의 일수를 나타내기

365 값을 담을 `int` 타입의 `DaysPerYear` 상수를 만든 다음, 이 값을 반환하는 `GetDaysPerYear` 함수를 구현해요:

```go
GetDaysPerYear()
// => 365
```

## 3. 1년의 달을 나타내기

블록 안에서 Go의 열거자를 사용해 1년의 달에 해당하는 1부터 12까지의 값을 담는 열두 개의 타입 없는 숫자 상수를 만들어요. 이름은 `Jan`, `Feb`, `Mar` 등으로 짓고, 주어진 달의 값을 반환하는 `GetMonth` 함수를 구현해요:

```go
GetMonth(Jan)
// => 1
```

## 4. 계좌 번호를 나타내기

XF348IJ 값을 담을 `AccountNo` 타입 없는 문자열 상수를 만든 다음, 이 값을 반환하는 `GetAccountNumber` 함수를 구현해요:

```go
GetAccountNumber()
// => "XF348IJ"
```
