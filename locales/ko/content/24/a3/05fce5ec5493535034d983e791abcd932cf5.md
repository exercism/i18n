# 소개

Clojure는 함수형 언어라서 함수가 일급 시민이에요. 즉, 함수를 데이터처럼 다른 함수에 전달하거나 다른 함수가 만들어 낼 수 있다는 뜻이에요. 특히 Clojure에는 기존 함수를 바탕으로 새로운 함수를 만들어 내는 고차 함수가 다양하게 준비되어 있어요. 여기서는 `partial`, `comp`, `memoize`, `juxt`라는 네 가지 중요한 사례를 살펴볼게요. 이렇게 함수를 만들어 내는 함수들은 `map`, `reduce`, `apply`, `complement` 등을 비롯해 기존 함수를 다루는 고차 함수라는 더 넓은 범주에 속해요.

## partial

일반적으로 매개변수 `p1, p2, ..., pN`을 가진 기존 함수 `my-function`이 있을 때, 매개변수 중 일부 `p1, p2, ..., pM`을 상숫값 `v1, v2, ..., vM`으로 고정할 수 있어요. `partial`을 다음과 같이 적용하면 돼요: `(partial my-function v1 v2 ... vM)`.

그 결과로 원래 함수 `my-function`을 `p1=v1, p2=v2, ..., pM=vM`으로 고정해 적용하는 새로운 함수가 만들어져요. 이 새로운 함수는 `partial`을 적용할 때 값을 지정하지 않은 나머지 매개변수 `pM+1, pM+2, ..., pN`을 입력으로 받아요.

```clojure
(def my-new-function 
  (partial my-function v1 v2 ... vM))
(my-new-function xM+1 xM+2 ... xN)
; => equivalent to (my-function v1 v2 ... vM xM+1 xM+2 ... xN)
```

간단한 예로, 무엇을 전달하든 고정된 값인 9만큼 증가시키는 함수 `inc-by-9`를 정의해 볼까요? 이런 함수는 다음과 같이 구현할 수 있어요.

```clojure
(def inc-by-9 (partial + 9))
(inc-by-9 5)
; => 14
```

두 번째 예로, 인사하고 싶은 사람의 이름과 앞뒤에 붙일 문구를 사용하는 함수 `generic-greetings`가 있어요.

```clojure
(defn generic-greetings
  [initial-text final-text name]
  (println (str initial-text name final-text)))
```

여기에 `partial`을 사용하면 항상 특정 인사말을 쓰도록 만들 수 있어요.

```clojure
(def say-hello-and-how-are-you-doing 
  (partial generic-greetings "Hello " ", how are you doing?"))
(say-hello-and-how-are-you-doing "Mary")
; => Hello Mary, how are you doing?
```

## comp

`comp`를 사용하면 원하는 만큼의 함수를 합성한 새로운 함수를 만들 수 있어요. 일반적으로 `N`개의 함수 `f1, f2, ..., fN`을 합성한다는 것은 그 함수들을 순서대로 적용하면서 앞 함수의 출력을 다음 함수에 전달한다는 뜻이에요. 수학 표기법으로는 이렇게 표현해요.

```
f1 (f2 (... fN(x)))
```

Clojure에서는 다음 코드와 같아요.
```clojure
(f1 (f2 (... (fN x))))
```

comp를 사용하면 이 합성을 대신 해 주는 새로운 함수를 만들 수 있어요.

```clojure
(def my-function-composition 
  (comp f1 f2 ... fN))
(my-function-composition x)
; equivalent to
(f1 (f2 (... (fN x))))
```

예를 들어, 여러 숫자의 합을 구한 다음 그 결과에 6을 곱하고 싶다고 해봐요. 그럴 때는 이렇게 하면 돼요.


```clojure
(def six-times-result-sum 
  (comp (partial * 6) +))
(six-times-result-sum 3 2)
; = ((partial * 6) (+ 3 2))
; = (* 6 (+ 3 2))
; = 30
```

## memoize

`memoize`를 사용하면 주어진 입력에 대해 이전에 계산해 둔 결과를 재사용할 수 있어요. 같은 입력이 주어지면 *메모이즈된* 함수는 다시 계산하지 않고도 같은 결과를 반환해요. `clojure` 함수는 기본적으로 *참조 투명성*을 지닌다는 점을 이용한 거예요. 같은 입력에는 항상 같은 출력을 내놓기 때문에 이전 계산을 손쉽게 재사용할 수 있어요.

어떻게 동작하는지 보기 위해, 출력을 내놓기 전에 2초 동안 멈추는 인위적인 예를 들어 볼게요. 그러면 `memoize`를 쓰기 전과 후의 *계산 시간*을 쉽게 비교할 수 있어요.

```clojure
(defn my-time-consuming-fn
    "Original, time-consuming function"
    [x]
    (Thread/sleep 2000)
    (* x 2)
)

; We measure the time it takes for the original function
(time (my-time-consuming-fn 3))
; => "Elapsed time: 2007.785622 msecs"
; => 6

; We define a memoized function
(def my-memoized-fn 
  (memoize my-time-consuming-fn) )

; We call the memoized function and measure its execution time. 
; The first execution actually runs the function, taking
; similar time as the original.
(time (my-memoized-fn 3))
; => "Elapsed time: 2001.364052 msecs"
; => 6

; Subsequent calls reuse the previous computation, taking less
; time. Time is further reduced in additional calls.
(time (my-memoized-fn 3))
; => "Elapsed time: 1.190291 msecs"
; => 6

(time (my-memoized-fn 3))
; => "Elapsed time: 0.043701 msecs"
; => 6

; Changing the input makes the function be executed, so that
; we observe a similar computation time as the original 
(time (my-memoized-fn 4))
; => "Elapsed time: 2000.29306 msecs"
; => 8

; Again, repeating the same input will make the 
; execution be skipped, and the associated output returned
(time (my-memoized-fn 4))
; => "Elapsed time: 0.043701 msecs"
; => 8
```

## juxt

`juxt`는 전달받은 함수들을 왼쪽에서 오른쪽 순서로 적용하는 함수를 만들어 내요. 결과는 각 함수의 결과를 원소로 가지는 벡터예요.

```clojure
((juxt f g h) x) ; => [(f x) (g x) (h x)]
```

간단한 예로, x에 2부터 5까지의 인수를 차례로 곱한 값을 계산하는 함수를 만들어 볼게요.
```clojure
((juxt (partial * 2) (partial * 3) (partial * 4) (partial * 5)) 10) ; => [20 30 40 50]
```
