# 소개

동적 메모리는 프로그래머가 런타임에 메모리를 할당하고 해제할 때 사용하는 라이브러리 함수로 구현돼 있어요.
메모리의 할당과 해제를 프로그래머가 직접 제어하기 때문에, 동적 메모리는 프로그래머가 실수를 하지 않는 만큼만 안전해요.
그래서 동적 메모리는 프로그래밍 bug의 주요 원인 중 하나이고, 해킹 공격의 주요 표적이기도 해요.

## malloc

`malloc`은 동적 메모리를 할당할 때 사용하는, `stdlib.h`에 선언된 함수예요.
할당에 성공하면 할당된 메모리의 첫 번째 바이트 주소를 가리키는 포인터가 반환돼요.
할당에 실패하면 `NULL`이 반환돼요.
`malloc`의 결과가 `NULL`인지 확인하고, 실패했을 때 적절히 처리하는 것이 현명해요.
반환되는 포인터의 타입은 `pointer-to-void`인데, 이는 그 메모리에서 사용할 특정 타입으로 변환할 수 있는 "범용" 포인터라고 대략 생각하면 돼요.
`malloc`에는 매개변수가 하나 있는데, 원하는 메모리의 크기를 바이트 단위로 받아요.
배열을 할당할 때 필요한 전체 크기는 각 원소의 데이터 타입 크기에 원소 개수를 곱한 값이에요.
각 원소의 데이터 타입 크기를 구할 때는 `sizeof` 연산자를 흔히 사용해요.
다음 예제를 보면 알 수 있어요.

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // pointer-to-void from malloc is converted to a pointer-to-int
    int * numbers = malloc(sizeof(int) * count);
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    // printed The size of numbers is 8 bytes (can vary by system)
    printf("The size of numbers is %zu bytes\n", sizeof(numbers));
    numbers[0] = 1;
    numbers[1] = 2;
    numbers[2] = 3;
    // prints The first element of the array is 1
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The second element of the array is 2
    printf("The second element of the array is %d\n", numbers[1]);
    // prints The third element of the array is 3
    printf("The third element of the array is %d\n", numbers[2]);
    free(numbers);
    numbers = NULL;
}
```

`malloc`으로 새로 할당한 메모리는 초기화되지 않고 쓰레기 값이 들어 있을 수 있다는 점을 꼭 기억해야 해요.
`numbers` 포인터에 `sizeof`를 적용한 값은 배열의 원소 개수도, 할당된 전체 메모리 양도 아니에요.
`malloc`이 반환한 포인터의 크기는 그 시스템에서 포인터가 차지하는 크기예요.
예제 code는 64비트 시스템에서 실행했기 때문에 포인터의 크기가 8바이트였어요(바이트당 8비트를 곱하면 64비트예요).
포인터 타입은 pointer-to-void에서 pointer-to-int로 암시적으로 변환됐어요.
다음처럼 명시적으로 변환할 수도 있어요: `int * numbers = (int *) malloc(sizeof(int) * count);`.
값을 읽기 전에 반드시 쓸 것이라면 `malloc`을 사용하는 것이 메모리를 할당하는 효율적인 방법이 될 수 있어요.
하지만 값을 초기화하기 전에 읽을 가능성이 있다면 `malloc`을 사용하는 것은 위험해요.
메모리를 할당하는 더 안전한 방법은 `calloc`을 사용하는 것인데, `calloc`은 새로 할당한 메모리를 0으로 초기화해요.

위 예제들에서는 `free(numbers)`를 사용했다는 점을 기억해 두세요.

## free

`free`는 동적으로 할당된 메모리를 해제할 때 사용하는, `stdlib.h`에 선언된 함수예요.
동적으로 할당된 메모리는 `free`로 해제하기 전까지 메모리에 계속 잡혀 있어요.
일부 운영체제는 프로그램이 끝날 때 동적으로 할당된 메모리를 자동으로 해제해 주기도 하지만, 그것에 의존하지 않는 것이 좋은 관행이에요.
`free`에는 매개변수가 하나 있는데, 동적으로 할당된 메모리를 가리키는 포인터를 받아요.
해제한 뒤에 `NULL`로 설정하지 않은 포인터를 댕글링 포인터라고 해요.
댕글링 포인터는 원래 의도한 메모리가 아닌 다른 메모리를 가리킬 수 있어요.
따라서 댕글링 포인터는 데이터 손상과 임의의 code 대체 및 실행으로 이어질 수 있어요.
할당된 메모리를 가리키는 포인터를 `NULL`로 설정해 정리하지 않으면, 그 포인터를 이용해 프로그램을 해킹할 수 있어요.
포인터를 `free`에 넘긴 뒤에는 `NULL`로 설정하는 것이 좋은 관행이에요.

## calloc

`calloc`은 동적 메모리를 할당하는 것과 새로 할당한 메모리를 0으로 초기화하는 것을 모두 할 때 사용하는, `stdlib.h`에 선언된 함수예요.
할당에 성공하면 할당된 메모리의 첫 번째 바이트 주소를 가리키는 포인터가 반환돼요.
할당에 실패하면 `NULL`이 반환돼요.
`calloc`의 결과가 `NULL`인지 확인하고, 실패했을 때 적절히 처리하는 것이 현명해요.
반환되는 포인터의 타입은 `pointer-to-void`인데, 이는 그 메모리에서 사용할 특정 타입으로 변환할 수 있는 "범용" 포인터라고 대략 생각하면 돼요.
`calloc`에는 매개변수가 두 개 있어요.
첫 번째 매개변수는 지정한 데이터 타입을 몇 개 할당할지를 나타내요.
두 번째 매개변수는 할당할 지정한 데이터 타입의 크기를 나타내요.

다음 예제에서는 `calloc`이 새로 할당한 값을 항상 0으로 만들어 주기 때문에, 모든 `printf` 문이 항상 `0`을 출력해야 해요.

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // allocates the amount of bytes in an int, multiplied by count
    int * numbers = calloc(count, sizeof(int));
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    // prints The first element of the array is 0
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The second element of the array is 0
    printf("The second element of the array is %d\n", numbers[1]);
    // prints The third element of the array is 0
    printf("The third element of the array is %d\n", numbers[2]);
    free(numbers);
    numbers = NULL;
}
```

## realloc

`realloc`은 이미 할당된 메모리를 늘리거나 줄일 때 사용하는, `stdlib.h`에 선언된 함수예요.
재할당에 성공하면 재할당된 메모리의 첫 번째 바이트 주소를 가리키는 포인터가 반환돼요.
재할당에 실패하면 `NULL`이 반환돼요.
`realloc`의 결과가 `NULL`인지 확인하고, 실패했을 때 적절히 처리하는 것이 현명해요.
`realloc`에는 매개변수가 두 개 있어요.
첫 번째 매개변수는 재할당할 기존 메모리를 가리키는 포인터예요.
두 번째 매개변수는 재할당할 메모리의 크기를 바이트 단위로 나타내요.
메모리를 늘리기 전에 설정한 값들은 그대로 유지돼요.
메모리를 늘릴 때 추가되는 메모리는 0으로 초기화되지 않고, 그 값이 무엇이든 될 수 있다는 점을 꼭 기억해야 해요.
또한 메모리를 줄일 때 없어지는 메모리도 초기화되지 않고 값을 그대로 가지고 있을 수 있어요.
다음 예제는 배열을 늘리고 줄이는 방법을 보여줘요.

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // allocates the amount of bytes in an int, multiplied by count
    int * numbers = calloc(count, sizeof(int));
    return numbers;
}

int * my_function_2 (int * ptr , int count) {
    // reallocates the memory to the size of an int multiplied by count
    int * numbers = realloc(ptr, sizeof(int) * count);
    // if realloc fails, exit the program
    if (!numbers) exit(-1);
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    numbers[0] = 1;
    numbers[1] = 2;
    numbers[2] = 3;
    // expand the size of the array
    numbers = my_function_2(numbers, 6);
    // prints The first element of the array is 1
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The sixth element of the array is [whatever is there]
    // the additional memory is not initialized, so it could be
    // 0 or it could be 18728 or anything else
    printf("The sixth element of the array is %d\n", numbers[5]);
    numbers[5] = 6;
    // shrink the size of the array
    numbers = my_function_2(numbers, 3);
    // prints The sixth element of the array is [whatever is there]
    // the removed memory is not initialized, so it could be
    // 6 or it could be 43164 or anything else
    printf("The sixth element of the array is %d\n", numbers[5]);
}
```
