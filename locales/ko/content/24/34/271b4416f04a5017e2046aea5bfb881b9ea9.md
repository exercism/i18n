# 안내

래리는 게임을 만들기 위해 코드를 작성하는 걸 좋아하는 Lisp 외계인이에요.
오늘 래리는 틱택토와 아주 비슷한 게임을 만드는 데 도움이 될 함수 몇 개를 작성하려고 해요.

틱택토처럼 이 게임은 3x3 격자로 된 보드에서 진행해요.

## 1. 처음부터 시작하기

먼저 래리는 빈 보드를 만드는 함수 `make-empty-board`가 필요해요.
보드의 모든 칸은 `NIL`이어야 해요.

```lisp
(make-empty-board) ; => #2A((NIL NIL NIL) (NIL NIL NIL) (NIL NIL NIL))
```

## 2. 기존 보드에서 시작하기

다음으로 래리는 행 목록으로 보드를 만드는 함수가 필요해요.
예를 들면 다음과 같아요:

```lisp
(make-board-from-list '((A B C) (D E F) (G H I))) ; => #2A((A B C) (D E F) (G H I))
```

## 3. 승리 조건

같은 기호가 한 줄에 3개 있는 경우가 있다면 그 플레이어가 이긴 거예요.
래리는 `all-the-same-p`라는 함수가 필요해요. 이 함수는 3개의 항목으로 이루어진 배열을 받아서 모든 항목이 같은 기호이면 `T`로 평가돼요.
(`eq`를 사용하면 두 기호가 같은지 확인할 수 있어요.)

```lisp
(all-the-same-p #(A A A)) ; => T
(all-the-same-p #(A B C)) ; => NIL
```

## 4. 행 단위로

이제 래리는 한 행의 원소를 가져오는 방법이 필요해요.
`row` 함수는 보드와 행 번호를 받아서 그 행에 있는 원소들의 배열을 반환해야 해요.

```lisp
(row #2A((1 2 3) (4 5 6) (7 8 9)) 1) ; => #(4 5 6)
```

## 5. 열 단위로

마지막으로 래리는 한 열의 원소를 가져오는 방법이 필요해요.
`column` 함수는 보드와 열 번호를 받아서 그 열에 있는 원소들의 배열을 반환해야 해요.

```lisp
(column #2A((1 2 3) (4 5 6) (7 8 9)) 1) ; => #(2 5 8)
```
