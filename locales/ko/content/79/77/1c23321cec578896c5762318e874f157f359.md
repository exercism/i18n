# 소개

## 숫자 비교

JavaScript에서는 다음 관계 연산자와 동등 연산자로 숫자를 비교할 수 있어요.

| 비교                   | 연산자    |
| ---------------------- | --------- |
| 크다                   | `a > b`   |
| 크거나 같다            | `a >= b`  |
| 작다                   | `a < b`   |
| 작거나 같다            | `a <= b`  |
| (엄격한) 동등          | `a === b` |
| (엄격한) 동등하지 않음 | `a !== b` |

비교 결과는 항상 불리언 값이라서 `true` 또는 `false`예요.

```javascript
1 < 3;
// => true

2 !== 2;
// => false

1 === 1.0;
// => true
// All numbers are floating-points, so this is different syntax for
// the exact same value.
```

## 문자열 비교

JavaScript에서는 위의 비교 연산자로 문자열도 비교할 수 있어요.
이때는 딕셔너리(사전식) 순서가 적용돼요.
모든 문자의 정확한 순서 목록은 [여기][utf-16-list]에서 볼 수 있어요.

```javascript
'Apple' > 'Pear';
// => false

'a' < 'above';
// => true

'a' === 'A';
// => false
```

## 엄격한 동등

JavaScript에서 같음을 확인할 때 등호를 세 개 쓰는 게 궁금할 수 있어요.
`===`는 _엄격한 동등_을 확인하는 것으로, 타입 변환이 일어나지 않고 타입이 다른 값은 항상 같지 않다는 뜻이에요.

```javascript
'3' === 3;
// => false
// The value on the left has type string, the value on the right has type number.

1 === 1n;
// => false
// The value on the left has type number, the value on the right has type bigint.
```

JavaScript에서 같음을 확인할 때는 `===`와 `!==`를 사용하는 것이 권장돼요.

`==`와 `!=`도 있는데, 이는 _느슨한 동등_을 확인하는 거예요.
비교를 하기 전에 암시적 타입 변환을 적용하기 때문에 피하는 게 좋아요.
이런 경우의 결과는 예측하기 어렵고, 때로는 예상과 다를 수 있어요.

```javascript
0 == false;
// => true
```
