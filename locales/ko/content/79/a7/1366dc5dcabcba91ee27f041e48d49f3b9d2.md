# 지침

이 연습 문제에서는 여러 종류의 무선 조종 자동차가 벌이는 경주를 조직해요.
각 자동차는 저마다의 특성을 가지고 있으며, 토너먼트 시즌 내내 다양한 트랙에서 열리는 경주를 달려요.

~~~~exercism/note
이 연습 문제의 함수들은 제공된 시그니처와 함께 C 소스 파일에 선언되어 있어요.
작성한 x86-64 어셈블리 코드는 그 명세를 따라야 해요.
~~~~

## 1. 무선 조종 자동차 만들기

무선 조종 자동차를 나타내기 위해 `car_t` 구조체를 정의했어요:

```c
struct car_t {
    char name[10];
    int16_t speed;
    float battery;
};
```

x86-64 어셈블리로 `new_car` 함수를 정의해서 무선 조종 자동차를 만들 수 있게 해요.
`battery` 필드는 항상 `100.0` 값으로 시작해요.

```c
struct car_t new_car(short speed, const char name[]);
```

## 2. 새 트랙 만들기

트랙은 `track_t` 구조체로 나타내요:

```c
struct track_t {
    enum surface_t surface;
    size_t distance;
};
```

`enum surface_t`는 트랙의 여러 표면을 구분해요:

```c
enum surface_t {
    ASPHALT,
    SAND,
    ICE,
    CLAY
};
```

x86-64 어셈블리로 `new_track` 함수를 정의해서 새 트랙을 만들 수 있게 해요.

```c
struct track_t new_track(enum surface_t surface, size_t distance);
```

## 3. 경주 이벤트 만들기

각 경주에는 최대 6대의 자동차가 참가해서 트랙을 정해진 횟수만큼 돌아요.
경주는 `race_t` 구조체로 나타내요:

```c
struct race_t {
    struct track_t track;
    uint8_t num_of_laps;
    struct car_t cars[6];
    uint8_t num_of_running_cars;
};
```

x86-64 어셈블리로 `new_race` 함수를 정의해요.
경주가 시작될 때 참가가 확정된 자동차는 없어요:

```c
struct race_t new_race(struct track_t track, uint8_t num_of_laps);
```

## 4. 경주에 자동차 참가 확정하기

자동차 주인이 자기 차의 경주 참가를 요청하면, 목록이 아직 꽉 차지 않았을 때만 참가가 확정돼요.

x86-64 어셈블리로 `add_participant` 함수를 정의해요.
경주에 참가자를 한 명 더 받을 자리가 있으면, 자동차가 목록에 추가되고 카운터가 갱신되면서 참가가 확정돼요.
그렇지 않으면 경주 주최자는 자동차 주인에게 이번에는 참가할 수 없다는 것을 알려야 해요.

```c
bool add_participant(struct race_t *race, struct car_t car);
```

## 5. 토너먼트 만들기

시즌 동안 예정된 경주는 `tournament_t` 구조체로 관리해요:

```c
struct tournament_t {
    struct race_t races[20];
    size_t num_of_races;
};
```

x86-64 어셈블리로 `add_race` 함수를 정의해서 토너먼트의 배열에 경주를 추가하고 카운터도 갱신해요.
`races` 배열에는 새 경주를 넣을 공간이 항상 충분하다고 생각해도 돼요.

```c
void add_race(struct tournament_t *tournament, struct race_t race);
```
