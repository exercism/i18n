# 지시 사항

또 만났네요, Double-Null0111 요원.

UMBRA의 세력이 다시 꿈틀거리고 있고, 그들의 최신 계략을 막아야 해요.
정보부에 따르면, 그 미니언들이 주지사의 무도회에서 악취 폭탄을 터뜨릴 계획이래요.

미니언들은 워낙 덜렁대서 실험실이나 사무실에서 실수로 악취 폭탄을 무장시키곤 해요.
게다가 악취 폭탄을 해체하는 방법을 자꾸 잊어버리기 때문에, 폭탄의 ID 번호로부터 전선을 잘라야 하는 순서를 나열하는 해체 지침을 생성하는 시스템을 만들어 놨어요.

이제 여러분이 할 일은 무도회에 있는 악취 폭탄이 터지기 전에 해체할 수 있게 하는 코드를 작성하는 거예요.

## 1. 전선 두 개를 뒤집는 클로저 작성하기

악취 폭탄에는 각각 색이 다른 전선 세 개가 있어요.
`(String, String, String)` 튜플을 받아서 처음 두 원소의 순서를 뒤집은 튜플을 반환하는 클로저를 작성해요.
이 클로저를 `flip`이라는 이름에 할당해요.

주의할 점은 타입이 `ChangeClosure`(또는 sendable 타입)여야 한다는 거예요. 타입 정의는 스텁 파일에 나와 있어요.
그렇지 않으면 코드가 컴파일되지 않아요.

```swift
flip(("red", "yellow", "blue"))
// Returns ("yellow", "red", "blue")
```

## 2. 전선을 회전시키는 클로저 작성하기

`(String, String, String)` 튜플을 받아서 전선의 순서를 왼쪽으로 회전시킨 튜플을 반환하는 클로저를 작성해요.
이 클로저를 `rotate`라는 이름에 할당해요.

주의할 점은 타입이 `ChangeClosure`(또는 sendable 타입)여야 한다는 거예요. 타입 정의는 스텁 파일에 나와 있어요.

```swift
rotate(("red", "yellow", "blue"))
// Returns ("yellow", "blue", "red")
```

## 3. 전선 셔플 생성기 구현하기

악취 폭탄의 전선을 자를 순서를 알아내려면, 악취 폭탄의 ID 번호를 바탕으로 적절한 셔플 함수를 생성하는 함수를 구현해야 해요.

다음 함수를 구현해요.

```swift
makeShuffle(
  flipper: @escaping ((String, String, String)) -> (String, String, String),
  rotator: @escaping ((String, String, String)) -> (String, String, String)
) -> ([UInt8], (String, String, String)) -> (String, String, String)
```

이 함수는 전선 두 개를 뒤집는 클로저와 전선 세 개를 회전시키는 클로저를 입력으로 받아서 클로저를 반환해요.
반환된 클로저는 악취 폭탄의 ID 번호와 전선 세 개의 순서를 받아서, 전선을 잘라야 하는 순서를 계산해요.
ID 번호는 8개의 비트로 이루어져 있고, 각 비트가 전선을 뒤집을지 회전시킬지를 결정해요.

ID 번호의 각 비트에 대해, 가장 오른쪽 비트부터 시작해서, 비트가 0이면 `flipper` 클로저를 전선 튜플에 적용하고, 1이면 `rotator` 클로저를 적용해서 전선의 새로운 상태를 만들어요.
ID의 여덟 개 비트 모두에 알맞은 클로저를 적용하고 나면, 전선의 최종 상태가 바로 잘라야 하는 순서예요.

```swift
let shuffler = makeShuffle(flipper: flip, rotator: rotate)
// Returns ([UInt8], (String, String, String)) -> (String, String, String)
shuffler([1, 0, 0, 1, 1, 0, 1, 1], ("red", "yellow", "blue"))
// Returns ("red", "blue", "yellow")
```
