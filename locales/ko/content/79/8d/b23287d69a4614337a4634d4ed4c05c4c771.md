# 힌트

## 일반

- 태그와 레코드 목록을 바탕으로 DSL을 만들어 보고 싶을 수도 있어요. 예를 들면 다음과 같아요:

  ```roc
  my_graph =
      Graph.create([
          Title("My Graph"),
          Node("a", { color: Green }),
          Node("b", { color: Blue }),
          Edge("a", "b", { style: Dotted }),
      ])
  ```

- 아니면 함수 호출을 이어 붙인 방식의 DSL을 더 선호할 수도 있어요. 예를 들면 다음과 같아요:

  ```roc
  my_graph =
      Graph.create()
          .with_title("My Graph")
          .add_node("a", Attr.create().with_color(Green))
          ...
  ```

  아니면 완전히 다른 계획이 있나요?
  그렇게 해봐요!

- 그렇긴 해도 DSL은 명확하고 간결하며 예상 밖의 동작이 많지 않을 때 보통 더 좋아요 (예를 들어 `minus` 함수는 빼기를 위한 것이지, `node("a") - node("b")`처럼 두 노드 사이에 간선을 만드는 용도가 아니에요).
