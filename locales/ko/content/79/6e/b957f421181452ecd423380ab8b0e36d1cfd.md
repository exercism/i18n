# 지침

Isaacs Asteroid Exploration Co.의 소유권 신청 부서로부터 토지 소유권 신청 시스템의 성능을 개선해 달라는 임무를 받았어요.

새로운 소행성이 개발 준비를 마칠 때마다 투기꾼들이 땅 한 구획에 대한 소유권을 신청할 수 있어요. 소행성의 땅은 네 변으로 이루어진 구획들로 나뉘어 있어요. 투기꾼들은 구획의 치수를 지정해서 땅을 신청해요.

목표는 과거에 웹사이트가 다운되게 만들었던 신청 폭주를 처리할 수 있는 성능 좋은 시스템을 개발하는 거예요.

측정 단위는 100미터지만, 이 작업들에서는 무시해도 돼요.

## 1. Plot 정의하기

`Plot` 구조체의 구현을 완성해요. 이 구조체는 좌표 구조체 4개로 이루어져 있고, 생성자에서 이들을 받아요.

## 2. 투기꾼이 치수로 식별되는 구획을 지정해 신청할 수 있게 하기

`ClaimsHandler.StakeClaim()` 메서드를 구현해서 신청을 등록할 수 있게 해요.

`ClaimsHandler.IsClaimStaked()` 메서드를 구현해서 신청이 등록되었는지 확인해요.

```csharp
var ch = new ClaimsHandler();
ch.StakeClaim(new Plot(new Coord(1,1), new Coord(2,1), new Coord(1,2), new Coord(2,2)));
ch.IsClaimStaked(new Plot(new Coord(1,1), new Coord(2,1), new Coord(1,2), new Coord(2,2)));
// => true
```

## 3. 현재 신청이 마지막 신청과 같은지 확인하기

`ClaimsHandler.IsLastClaim()` 메서드를 구현해서 현재 신청을 이전 신청과 비교해요.

```csharp
var ch = new ClaimsHandler();
ch.StakeClaim(new Plot(new Coord(1,1), new Coord(2,1), new Coord(1,2), new Coord(2,2)));
ch.IsLastClaim(new Plot(new Coord(1,1), new Coord(2,1), new Coord(1,2), new Coord(2,2)));
// => true
```

## 4. 연구 목적으로 가장 긴 변을 가진 신청된 구획 찾기

`ClaimsHandler.GetClaimWithLongestSide()` 메서드를 구현해서 등록된 모든 신청을 살펴보고 가장 긴 변을 가진 구획을 반환해요. 구획의 좌표 데이터는 항상 연속된 직사각형 모양임이 보장돼요.

```csharp
var ch = new ClaimsHandler();
ch.StakeClaim(new Plot(new Coord(1,1), new Coord(2,1), new Coord(1,2), new Coord(2,2)));
ch.StakeClaim(new Plot(new Coord(10,1), new Coord(20,1), new Coord(10,2), new Coord(20,2)));
ch.GetClaimWithLongestSide();
// => new Plot(new Coord(1,1), new Coord(20,1), new Coord(1,2), new Coord(2,2))
```
