# 개요

`Complex numbers`는 복잡하지 않아요.
이름만 조금 덜 무서우면 좋겠을 뿐이에요.

복소수는 특히 공학과 과학 분야에서 아주 유용해서, R은 정수, 더블, 논리형, 문자형, 원시형과 나란히 복소수를 표준 [원자 타입][ref-atomic]으로 포함하고 있어요.

## 기초

R에서 `complex` 수는 하나의 값이에요.
하지만 실제로 쓸 때는 두 수의 짝으로 생각할 수 있죠.
이 둘은 안타까운 역사적 이유 때문에 각각 "실수부"와 "허수부"라고 불려요.
다시 말하지만, 이상한 이름보다 그 바탕에 있는 단순함에 집중하는 게 좋아요.

두 실수로 복소수를 만들려면, 허수부 뒤에 `i`를 붙이기만 하면 돼요.

```r
2+3i
#> [1] 2+3i

typeof(2+3i)
#> [1] "complex"
```

실수 변수로 복소수를 만들 때는 위 문법이 통하지 않아요.
`r + imi`라고 쓰면 파서가 `imi`를 (존재하지도 않는) 변수 이름이라고 착각해요.

허수부에 `1i`를 곱하거나 [`complex()`][ref-complex] 함수를 쓰면 돼요.

```r
r <- 2
im <- 3

r + im * 1i
#> [1] 2+3i

# must include the `real` and `imaginary` keywords
complex(real = r, imaginary = im)
#> [1] 2+3i
```

왜 `j`가 아니라 `i`일까 하고 궁금할 수도 있어요.

대부분의 엔지니어는 `j`를 선호해요.
대부분의 과학자와 수학자는 _허수_를 뜻하는 수학 표기 `i`를 선호하지만, 전기 공학에서는 `i`가 _전류_를 뜻해서 이 표기와 충돌해요.

R은 `i`를, Python은 `j`를 택했고, Julia는 `im`을 택해서 논란을 비켜갔어요.
[STEM][wiki-STEM] 프로그래밍 언어를 오갈 때는 조심해야 해요.

복소수의 각 부분에 따로 접근하려면:

```r
z <- 2+3i

Re(z)  # real part
#> [1] 2

Im(z)  # imaginary part
#> [1] 3
```

두 부분 중 하나는 0일 수 있고, 그러면 수학자들은 그 수를 "완전히 실수" 또는 "완전히 허수"라고 말하기도 해요.
그래도 R에서는 여전히 복소수예요.

```r
1.2 + 0i
#> [1] 1.2+0i

typeof(1.2 + 0i)
#> [1] "complex"

2i
#> [1] 0+2i

typeof(2i)
#> [1] "complex"
```

"`i`(또는 `j`)는 -1의 제곱근이다"라는 말을 들어 봤을지도 몰라요.

지금로서는, 허수부가 _정의상_ 다음 등식을 만족한다는 뜻일 뿐이에요.

```r
1i * 1i == -1  # more precisely, 1i * 1i == -1 + 0i
#> [1] TRUE
```

단순한 생각이지만, 흥미로운 결과로 이어져요.

## 산술

실수와 정수에 쓰는 [`operators`][ref-operators] 대부분은 복소수에도 그대로 통해요.

```r
z1 = 1.5 + 2i
z2 = 2 + 1.5i

z1 + z2  # addition
#> [1] 3.5+3.5i

z1 * z2  # multiplication
#> [1] 0+6.25i

z1 / z2  # division
#> [1] 0.96+0.28i

z1^2  # exponentiation
#> [1] -1.75+6i

2^z1  # another exponentiation
#> [1] 0.518895+2.780422i
```

복소수의 곱셈과 나눗셈 규칙을 설명하는 것은 이 개념의 범위를 벗어나요(_그리고 이런 연산을 "손으로" 직접 할 일도 그리 많지 않아요_).

복소수를 더 파고들고 싶다면, 복소수에 관한 [수학][web-math-complex] 또는 [전기 공학][web-engineering-complex] 입문 자료에서 이 내용을 다뤄요.

또는 Exercism에는 [`Complex Numbers`][exercise-complex-numbers] 연습 문제가 있어서, 이런 연산들을 처음부터 직접 구현한 복소수 클래스를 만들어 볼 수 있어요.

복소수에서는 정수 나눗셈이 일반적으로 ___불가능___하므로, `%/%`와 `%%` 연산자는 복소수 타입에서 실패해요.

## 함수

대부분의 수학 함수는 복소수 입력에서도 잘 동작해요.

하지만 실수 입력을 주고 복소수 출력을 기대하면 보통은 잘 안 돼요.

```r
sqrt(z1)
#> [1] 1.414214+0.707107i

sqrt(-1)  # fails!
#> Warning in sqrt(-1) : NaNs produced
#> [1] NaN

sqrt(-1 + 0i)  # succeeds with complex input
#> [1] 0+1i

sin(z1)
#> [1] 3.752771+0.256554i
```

`Re()`와 `Im()` 외에도 복소수에 특히 쓸모가 있는 함수가 몇 가지 있어요.
이해가 안 되면 그냥 건너뛰어도 돼요!

- `Conj()`는 복소수 허수부의 부호를 뒤집기만 해요(_+에서 -로, 또는 그 반대로_).
  - 복소수 곱셈이 동작하는 방식 덕분에, 생각보다 훨씬 유용해요.
- `abs(<complex number>)`는 허수부가 없는 실수, 즉 "크기"를 반환하는 것이 보장되고, `Mod(<complex number>)`는 같은 역할을 해요.
- `Arg(<complex number>)`는 위상각을 라디안으로 반환해요.

```r
z1
#> [1] 1.5+2i

abs(z1)
#> [1] 2.5

Mod(z1)  # same as previous
#> [1] 2.5

Conj(z1)  # flip sign
#> [1] 1.5-2i

Arg(z1)
#> [1] 0.9272952
```

수학을 좋아하는 분을 위한 부분적인 설명이에요 _(다시 말하지만, 건너뛰어도 돼요)_:

- `z1`의 `(real, imag)` 표현은 사실상 복소평면 위의 직교 좌표를 사용해요.
- 같은 복소수를 극좌표를 사용하는 `(r, θ)` 표기로 나타낼 수도 있어요.
- 여기서 `r`과 `θ`는 각각 `abs(z1)`과 `Arg(z1)`이에요.

몇 가지 상수를 사용한 예시예요:

```r
 euler <- exp(1i * pi)

euler
#> [1] -1+0i
```

이렇게 자연에서 가장 중요한 상수 세 개인 `e`, `i`(또는 `j`), `pi`로 이루어진 간단한 식이 `-1`이라는 결과를 내요.
어떤 사람들은 이것이 모든 수학에서 가장 아름다운 결과라고 믿어요.
1740년 무렵으로 거슬러 올라가죠.

## 선택 섹션: 복소수 자주 묻는 질문

관심 없으면 이 부분은 건너뛰어도 돼요.

### 이건 뭔가 이상하고 새로운 순수 수학의 한 조각 아닌가요?

16세기에는 정말 이상하고 새로운 것이었어요.

500년이 지난 지금, 대부분의 공학과 자연과학의 중심에 있어요.

### 왜 이런 걸 쓸까요?

복소수는 회전하는 것, 또는 파동 같은 성질을 지닌 것을 설명하는 가장 단순한 방법이에요.
그래서 전기 공학, 오디오 처리, 물리학, 컴퓨터 게임, 내비게이션 등, 몇 가지만 꼽아도 아주 널리 쓰여요.

회전하는 것은 눈으로 볼 수 있죠.
복소수가 세상을 돌게 하지는 않지만, 세상이 도는 결과로 _무슨 일이 일어나는지_ 설명하는 데는 아주 뛰어나요. 큰 태풍의 위성 사진을 한번 보세요.

덜 뻔한 예로, 소리는 파동이고 빛도 파동이며 전파 신호도 파동이에요. 심지어 여러분 나라의 경제도 적어도 일부는 파동과 닮았어요.

이런 파동 처리는 상당 부분 삼각 함수(`sin()`과 `cos()`)로 할 수 있지만, 금방 복잡해져요.

복소 지수는 다루기가 ___훨씬___ 쉬워요.

### 그런데 저는 복소수가 필요 없어요!

동굴에 살면서 먹을 것을 채집해 먹고 있다면 그 말이 맞아요.

어떤 종류의 화면으로든 이 글을 읽고 있다면, 복소수를 활용해 이룬 20세기의 유용한 발전에 완전히 의존하고 있는 거예요.

__반도체 칩__.

- 반도체 칩은 고전 물리학으로는 설명이 안 되고, 양자역학(QM)으로만 설명(그리고 설계)할 수 있어요.
- 양자역학에서는 정의상 모든 것이 복소수 값을 가져요. (_끝까지 내려가면 전부 파형이에요_)

__고속 푸리에 변환(FFT) 알고리즘__.

- FFT는 복소수의 응용이고, 소리 전송, 오디오 처리, 사진, 영상과 관련된 _모든 것_에 들어 있어요.

- MP3와 다른 오디오 형식은 압축에 FFT를 사용해서, 더 많은 오디오를 더 작은 저장 공간에 담을 수 있어요.
- JPEG 압축과 MP4 영상 등, 수많은 이미지와 영상 형식도 압축에 FFT를 사용해요.

- FFT는 휴대폰 기지국이 여러분의 개인 신호를 다른 사람들의 신호와 분리할 수 있게 해 주는 디지털 필터에도 쓰여요.

그러니까 아마 지금도 1초에 수천 번 복소수 계산에 의존하는 기술을 쓰고 있는 셈이에요.
