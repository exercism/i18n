# 개요

Common Lisp에서 거짓 값은 빈 리스트 `()` 또는 기호 `nil`로 나타내요.
이 값들은 인용하거나 인용하지 않을 수 있어요.

```lisp
;; Equivalent False Values
()   ; => NIL
nil  ; => NIL
'()  ; => NIL
'nil ; => NIL
```

Lisp의 다른 모든 값은 참을 나타내요.
항상 `t`와 같고 (따라서 항상 참인) 특별한 상수 기호 `t`도 있어요.

```lisp
;; Some Different True Values
42                        ; => 42
"this statement is false" ; => "this statement is false"
t                         ; => T
't                        ; => T
```
