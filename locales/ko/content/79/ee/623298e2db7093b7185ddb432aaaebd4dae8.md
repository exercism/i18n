# 지침 추가

## 출력 형식

`treeFromTraversals` 함수는 세 개의 프로퍼티를 가진 객체를 반환해야 해요.

- `value` 현재 노드의 값
- `left` 노드의 왼쪽 자식을 담은 객체
- `right` 노드의 오른쪽 자식을 담은 객체

```javascript
{
    value: 'a',
    left: { value: 'i', left: {}, right: {} },
    right: { value: 'x', left: {}, right: {} },
}
```

트리가 비어 있다면 빈 객체를 반환해야 해요.
