# 가시성

클래스로 코드를 구성할 때, 속성과 메서드, 상수의 가시성은 알맞은 추상화와 책임을 이끌어 내는 데 도움이 돼요.
속성과 메서드, 상수의 가시성은 선언할 때 사용하는 `public`, `private`, `protected` 키워드에 따라 정해져요.
가시성은 항상 클래스 외부에서 그 속성, 메서드, 상수를 사용하는 관점을 기준으로 해요.
즉, 어떤 속성을 `public`으로 선언하면 외부 호출에서 관찰하고 사용할 수 있어요.
`private` 속성, 메서드, 상수는 외부 호출에서 관찰하거나 사용할 수 없어요.

```php
<?php

class SecretDocument
{
    private $encryption_key;

    public $title;

    public function __construct($encryption_key, $title)
    {
        $this->encryption_key = $encryption_key;
        $this->title = $title;
    }
}

$document = new SecretDocument('secret_password', 'Secret Plans');
$title = $document->title; // => succeeds
$key = $document->encryption_key; // => fails
```

`protected` 속성, 메서드, 상수는 자기 자신과 (상속을 통한) 자식 클래스에서만 관찰할 수 있어요.

```php
<?php

class Shape
{
    protected $color = "blue";
}

class Square extends Shape
{
    public function getColor()
    {
        return $this->color;
    }
}

$square = new Square();
$color = $square->getColor(); // => succeeds
```
