# 소개

## 비교

Python은 다음과 같은 기본 비교 연산자를 지원해요:

| 연산자   | 연산                       | 설명                                                                      |
| -------- | -------------------------- | ------------------------------------------------------------------------- |
| `>`      | "크다"                     | `a`가 `b`보다 값이 **엄격하게** 크면 `a > b`는 `True`예요                 |
| `<`      | "작다"                     | `a`가 `b`보다 값이 **엄격하게** 작으면 `a < b`는 `True`예요               |
| `==`     | "같다"                     | `a`가 `b`와 값이 **엄격하게** 같으면 `a == b`는 `True`예요                |
| `>=`     | "크거나 같다"              | `a > b`이거나 `a == b`이면 `a >= b`는 `True`예요                          |
| `<=`     | "작거나 같다"              | `a < b`이거나 `a == b`이면 `a <= b`는 `True`예요                          |
| `!=`     | "같지 않다"                | `a == b`가 `False`이면 `a != b`는 `True`예요                              |
| `is`     | "동일성"                   | `a`와 `b`가 같은 _객체_일 때 **_오직 그럴 때만_** `a is b`는 `True`예요   |
| `is not` | "부정된 동일성"            | `a`와 `b`가 같은 _객체_가 **아닐** 때 `a is not b`는 `True`예요           |
| `in`     | "포함 검사"                | `a`가 `b`의 멤버, 부분집합, 또는 원소이면 `a in b`는 `True`예요           |
| `not in` | "부정된 포함 검사"         | `a`가 `b`의 멤버, 부분집합, 또는 원소가 아니면 `a not in b`는 `True`예요  |

이들은 모두 같은 우선순위를 가져요 (_[불리언 연산][boolean operations]보다는 높지만, 산술 연산이나 비트 연산보다는 낮아요_).

## 서로 다른 데이터 타입 간의 비교

서로 다른 타입인 객체는 (_숫자 타입을 제외하고는_) 기본적으로 결코 같다고 비교되지 않아요.
`class`의 동일하지 않은 인스턴스 역시, `class`가 기본 `object` 비교 동작을 바꾸는 특별한 [풍부한 비교][rich comparisons] 메서드를 정의하지 않는 한, 같다고 비교되지 _**않아요**_.
`rich comparisons`를 통한 커스터마이즈는 이어지는 연습 문제에서 다뤄요.
이 주제에 대한 (훨씬) 더 자세한 내용은 Python 문서의 [값 비교][value comparisons]를 참고해요.

숫자 타입은 (대부분) 이 타입 일치 규칙의 예외예요.
비교를 위해 타입이 암시적으로 변환될 수 있다면, `integer`는 `float`와 같다고 간주될 **수 있어요** (_또는 [`octal`][octal]이 [`hexadecimal`][hex]과 같을 수 있어요_).

Python 표준 라이브러리의 다른 숫자 타입들([복소수][complex numbers], [실수][decimal numbers], [분수][rational numbers])의 경우, 비교 연산자는 "말이 되는" 곳(_암시적 변환이 결과를 바꾸지 않는 곳_)에 정의되어 있지만, 기반 객체들이 비교를 위해 정확하게 변환될 수 없으면 `TypeError`를 발생시켜요.
python이 _숫자 변환_에 사용하는 규칙에 대한 더 자세한 내용은 Python 문서의 [산술 변환][arithmetic conversions]을 참고해요.

```python
>>> import fractions

# A string cannot be converted to an int.
>>> 17 == '17'
False

# An int can be converted to float for comparison.
>>> 17 == 17.0
True

# The fraction 6/3 can be converted to the int 2
# The int 2 can be converted to 0b10 in binary.
>>> 6/3 == 0b10
True

# An int can be converted to a complex number with a 0 imaginary part.
>>> 17 == complex(17)
True

# The fraction 2/5 can be converted to the float 0.4
>>> 0.4 == 2/5
True

>>> complex(2/5, 1/2) == complex(0.4, 0.5)
True
```

숫자를 `NaN` (_not a number_) 타입과 순서대로 비교하면 항상 `False`예요.
Python의 `NaN` 정의에서 헷갈리기 쉬운 부작용은 `NaN`이 `NaN`과 결코 같다고 비교되지 않는다는 점이에요.

```python
>>> x = float('NaN')

>>> 3 < x
False

>>> x < 3
False

# NaN never compares equal to NaN
>>> x == x
False
```

## 문자열 비교

숫자와 달리, 문자열(`str`)은 각각의 유니코드 코드 포인트를 사용해 [_사전순으로_][lexographic order] 비교해요 (_`str`의 각 코드 포인트를 내장 함수 [`ord()`][ord]에 넘긴 결과이며, 이 함수는 `int`를 반환해요_).
두 문자열의 모든 코드 포인트가 일치하고 _**같은 순서**_라면, 두 문자열은 같다고 간주돼요.
이 비교는 '쌍별로' 이루어져요. 첫 번째끼리, 두 번째끼리, 이런 식으로요.
Python 3.x에서는 `str`과 `bytes`를 직접 강제 변환하거나 비교할 수 없어요.

```python
>>> 'Python' > 'Rust'
False

>>> 'Python' > 'JavaScript'
True

# Examples with Mandarin.
# hello < goodbye
>>> '你好' < '再见'
True

# ord() of first characters
>>> ord('你'), ord('再')
(20320, 20877)

# ord() of second characters
>>> ord('好'), ord('见')
(22909, 35265)

# And with Korean words.
# Pretty < beautiful.
>>> '예쁜' < '아름다운'
False

>>> ord('예'), ord('아')
(50696, 50500)
```

## 비교 연결

비교 연산자는 _임의로_ 연결할 수 있어요. 즉, 어떤 길이의 어떤 조합으로도 사용할 수 있어요.
표현식의 평가는 `left`에서 `right` 방향으로 일어나요.

예를 들어, `x < y <= z`는 `x < y` `and` `y <= z`와 동일해요. 단, `y`는 **한 번만** 평가돼요.
두 경우 모두, `x < y`가 `False`로 판명되면 `z`는 **전혀** 평가되지 _않아요_.
이를 흔히 `short-circuit evaluation`이라고 해요. 표현식의 진리값이 이미 결정되었다면 평가를 멈춰요.

`Short circuiting`은 다양한 불리언 연산자, 함수, 그리고 Python의 비교 연결에서도 지원돼요.
`C`, `C++`, `C#`, `Java`를 비롯한 많은 다른 프로그래밍 언어와 달리, Python에서 `a < b < c` 같은 연결된 표현식은 관례적인 [수학적 해석][three way boolean comparison]과 우선순위를 가져요.

```python
>>> x = 2
>>> y = 5
>>> z = 10

>>> x < y < z
True

>>> x < y > z
False

>>> x > y < z
False
```

## 객체 동일성 비교

연산자 `is`와 `is not`은 객체 _값_과는 대조적으로 객체 [_동일성_][object identity]을 검사해요.
객체의 동일성은 생성된 후 절대 변하지 않으며, [`id()`][id function] 함수를 사용해 확인할 수 있어요.

`<apple> is <orange>`는 `id(<apple>)` == `id(<orange>)`일 때 _**오직 그럴 때만**_ `True`로 평가돼요.
`<apple> is not <orange>`는 그 반대를 나타내요.

싱글턴이라는 특성 때문에, `None`과 `NotImplemented`는 항상 `is`와 `is not`을 사용해 항목과 비교해야 해요.
이 관례에 대한 더 자세한 내용은 [값 비교][value comparisons none]와 [PEP8][pep8 programming recommendations]에 대한 Python 참조 문서를 참고해요.

```python
>>> my_fav_numbers = [1, 2, 3]

>>> your_fav_numbers = my_fav_numbers

>>> my_fav_numbers is your_fav_numbers
True

# The returned id will differ by system and python version.
>>> id(my_fav_numbers)
4517478208

# your_fav_numbers is only an alias pointing to the original my_fav_numbers object.
# Assigning a new name does not create a new object.
>>> id(your_fav_numbers)
4517478208


>>> my_fav_numbers is not your_fav_numbers
False

>>> my_fav_numbers is not None
True

>>> my_fav_numbers is NotImplemented
False
```

## 멤버십 비교

연산자 `in`과 `not in`은 _멤버십_을 검사해요.
`<fish> in <soup>`는 `<fish>`가 `<soup>`의 멤버일 때 (_`<fish>`가 `<soup>`의 부분집합이거나 `<soup>` 안에 포함될 때_) `True`로 평가되고, 그렇지 않으면 `False`로 평가돼요.
`<fish> not in <soup>`는 `<fish> in <soup>`의 부정, 즉 _반대_를 반환해요.

문자열과 bytes 타입의 경우, `<name> in <fullname>`은 `<name>`이 `<fullname>`의 부분 문자열일 때 _**오직 그럴 때만**_ `True`예요.

```python
# A set of lucky numbers.
>>> lucky_numbers = {11, 22, 33}
>>> 22 in lucky_numbers
True

>>> 44 in lucky_numbers
False

# A dictionary of employee information.
>>> employee = {'name': 'John Doe', 
                'id': 67826, 'age': 33, 
                'title': 'ceo'}

# Checking for the membership of certain keys.
>>> 'age' in employee
True

>>> 33 in employee
False

>>> 'lastname' not in employee
True

# Checking for substring membership
>>> name = 'Super Batman'
>>> 'Bat' in name
True

>>> 'Batwoman' in name
False
```
