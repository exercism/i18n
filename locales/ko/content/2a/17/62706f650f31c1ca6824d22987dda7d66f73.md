# 소개

## Charlist

charlist는 `~c` 시길을 사용해 만들어요.

```elixir
~c"hello"
```

~~~~exercism/note
Elixir의 이전 버전에서는 charlist를 작은따옴표를 사용해 `'hello'`처럼 표현했어요.
~~~~

문자열과 아주 비슷하게 생겼지만, 두 자료형은 서로 꽤 달라요. charlist는 정수로 이루어진 배열이에요. 이 정수들은 주어진 문자의 유니코드 값, 즉 코드 포인트를 나타내요.

```elixir
[65, 66, 67]
# => ~c"ABC"
```

문자 앞에 `?`를 붙이면 그 문자의 코드 포인트를 얻을 수 있어요.

```elixir
?A
# => 65

[?:, ?)]
# => ~c":)"
```

charlist는 배열이기 때문에 재귀와 패턴 매칭을 사용해 다른 배열과 똑같이 다룰 수 있어요.

```elixir
[first_letter | _] = ~c"cat"
first_letter
# => 99
```

`++`를 사용해 두 배열을 연결할 수 있어요.

```elixir
~c"hi" ++ ~c"!"
# => ~c"hi!"
```

첫 번째 배열이 길수록 연결이 느려지므로, 길이가 임의인 배열에 반복해서 덧붙이는 것은 피하는 게 좋아요.

## `case`

`case`는 주어진 값을 여러 패턴과 비교할 수 있게 해주는 제어 흐름 구조예요. `case` 표현식의 절들은 일치하는 것을 찾을 때까지 위에서 아래로 평가돼요.

```elixir
age = 15

case age do
  0 -> ~c"infant"
  age when age < 4 -> ~c"baby"
  age when age < 13 -> ~c"child"
  age when age < 18 -> ~c"teenager"
  _ -> ~c"adult"
end

# => ~c"teenager"
```
