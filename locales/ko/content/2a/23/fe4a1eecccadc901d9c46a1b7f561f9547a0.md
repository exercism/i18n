# 자세히 알아보기

삼항 연산자를 사용하면 `if` 조건을 문 블록이 아니라 표현식 안에서 정의할 수 있어요. 함수형 프로그래밍 방식과도 닮아 있어서, 코드를 더 표현력 있게 만들고 오류가 생길 여지를 줄여 주는 경우가 많아요.

삼항 연산자는 표현식 세 개를 결합해요. 조건 하나와, 조건이 참일 때 평가되어 반환되는 표현식(`?`로 시작하는 `if` 부분), 그리고 조건이 거짓일 때 평가되어 반환되는 표현식(`:`로 시작하는 `else` 부분)이에요.

```haxe
trace(true ? "Haxe" : "Not Haxe"); // Haxe
trace(1 == 2 ? "Something is wrong" : "That's obvious"); // That's obvious
```
