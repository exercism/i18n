# 개요

Lua는 수를 표현하는 방식이 두 가지예요: 64비트 정수와 배정밀도 부동소수점 수예요.

~~~exercism/note
5.3 버전 이전에는 Lua가 모든 수를 배정밀도 부동소수점 형식으로 표현했어요.
~~~

수에는 소수 부분과 소수 지수를 선택적으로 붙일 수 있어요.
```lua
1               --> 1
0.2             --> 0.2
0.3e4           --> 3000.0
4.0e-3          --> 0.004
5.0e+20         --> 5e+20
```

소수점이나 지수가 있는 수는 실수로, 없는 수는 정수로 취급되지만, 둘 다 타입은 'number'예요.
```lua
type(1)         --> number
type(2.0)       --> number
```

실수와 정수를 구분하고 싶다면 `math` 모듈의 `type` 함수를 사용하면 돼요.
```lua
math.type(1)    --> integer
math.type(2.0)  --> float
```

## 비교

값이 같은 정수와 실수는 서로 같다고 비교돼요:
```lua
1 == 1.0        --> true
-2 == -2.0      --> true
0.3e3 == 300    --> true
```

## 산술 연산

Lua는 일반적인 산술 연산자 집합을 지원해요: 덧셈, 뺄셈, 곱셈, 나눗셈, 부호 반전이에요. 이 외에도 내림 나눗셈, 나머지 연산, 거듭제곱을 지원해요.

### 덧셈, 뺄셈, 곱셈, 부호 반전

두 피연산자가 모두 정수이면 연산 결과도 정수예요. 실수일 때도 마찬가지예요.
```lua
1 + 2     --> 3
1.0 + 2.0 --> 3.0
```

피연산자 중 하나가 실수이면 나머지 정수도 실수로 변환되고, 연산 결과는 실수가 돼요.
```lua
1.0 + 2   --> 3.0
```

### 나눗셈

나눗셈은 항상 실수로 연산하고, 결과도 실수로 내놓아요.
```lua
1.0 / 2.0 --> 0.5
2 / 1     --> 2.0
```

0으로 나누면 `inf` 또는 `-inf`가 돼요. 0을 0으로 나누면 `-nan`이 돼요.
```lua
1 / 0     --> inf
-1 / 0    --> -inf
0 / 0     --> -nan
```

### 내림 나눗셈

정수 결과가 필요하면 내림 나눗셈을 사용할 수 있어요. 내림 나눗셈은 항상 몫을 음의 무한대 방향으로 내림해서, 모든 피연산자에 대해 정수 결과를 보장해요.

~~~exercism/note
5.3 버전 이전에는 Lua에 내림 나눗셈을 위한 산술 연산자가 없었어요.
~~~

```lua
3 // 2    --> 1
6 // 2    --> 3
```

내림 나눗셈도 덧셈, 뺄셈, 곱셈, 부호 반전 연산자와 같은 규칙을 따라요. 두 피연산자가 모두 정수이면 연산 결과는 정수이고, 그렇지 않으면 실수예요.

```lua
3.0 // 2   --> 1.0
6.0 // 2.0 --> 3.0
```

내림 나눗셈으로 0을 나누면 Lua는 오류를 발생시켜요.
```lua
3 // 0     --> stdin:1: attempt to divide by zero
```

### 나머지 연산

나머지 연산은 두 피연산자를 나눈 나머지를 구할 때 사용해요.
```lua
8 % 2      --> 0
13 % 9     --> 4
-13 % -9   --> -4
-13 % 9    --> 5
13 % -9    --> -5
0.3 % 0.2  --> 0.1
```

### 거듭제곱

나눗셈과 마찬가지로 거듭제곱도 실수로 연산하고 결과도 실수로 내놓아요.
```lua
10 ^ 2    --> 100.0
```

## 우선순위

모든 연산은 [연산자 우선순위](https://www.lua.org/manual/5.4/manual.html#3.4.8)에 따라 평가돼요. 괄호를 사용하면 표현식의 우선순위를 바꿀 수 있어요.

```lua
1 + 2 * 3   --> 7
(1 + 2) * 3 --> 9
```

## 반올림

`math` 모듈은 세 가지 반올림 함수를 제공해요. `floor`는 음의 무한대 방향으로 "내림", `ceil`은 양의 무한대 방향으로 "올림", `modf`는 0 방향으로 반올림해요.

### `math.floor`

`floor`는 음의 무한대 방향으로 내림해요.
```lua
math.floor(1.3)    --> 1
math.floor(-1.3)   --> -2
```

### `math.ceil`

`ceil`은 양의 무한대 방향으로 올림해요.
```lua
math.ceil(1.3)    --> 2
math.ceil(-1.3)   --> -1
```

### `math.modf`

`modf`는 0 방향으로 반올림해요. 이 함수는 반올림된 값과 함께 수의 소수 부분을 반환하는데, 소수 부분은 항상 실수예요.
```lua
math.modf(1.3)    --> 1    0.3
math.modf(-1.3)   --> -1   -0.3
```

## 변환

정수를 실수로 변환하고 싶다면 `0.0`을 더하면 돼요.
```lua
1 + 0.0         --> 1.0
```

실수를 정수로 변환하고 싶다면 0과 비트 OR 연산을 하거나 `math` 모듈의 `tointeger` 함수를 사용하면 돼요.
```lua
1.0 | 0              --> 1
math.tointeger(1.0)  --> 1
```

수가 정수로 변환될 수 없으면 OR 연산자는 오류를 발생시키고, `tointeger` 함수는 `nil`을 반환해요.
```lua
1.1 | 0              --> stdin:1: number has no integer representation
math.tointeger(1.1)  --> nil
```

## 16진수

다른 많은 프로그래밍 언어와 마찬가지로 Lua는 수 앞에 `0x`를 붙여 16진수를 지원해요. 하지만 대부분의 언어와 달리 Lua는 부동소수점 16진수도 지원해요. 부동소수점 16진수는 소수 부분과 2진 지수를 가질 수 있고, 지수 앞에는 'p' 또는 'P'를 붙여요.
```lua
0xff            --> 255
0x0.2           --> 0.125
0x3p-1          --> 1.5
0xa.bp2         --> 42.75
```
