# 설명 추가

이 연습 문제를 푸는 한 가지 방법은 모듈러 거듭제곱 함수를 직접 구현하는 거예요. 이에 대해 더 알아보려면 [다음 문서](https://en.wikipedia.org/wiki/Modular_exponentiation)를 참고해요.

## 보너스 점수를 원한다면

많은 구현이 모든 입력 범위에서 제대로 동작하지는 않아요. 모든 유효한 입력이 유효한 결과를 내는지 확인하는 데 도움이 되는 추가 선택 테스트가 정의되어 있어요.

보너스 테스트를 실행하려면 `#[ignore]` 플래그를 지우고, 다음과 같이 `big-primes` 기능을 켜서 테스트를 실행해요:

```bash
$ cargo test --features big-primes
```
