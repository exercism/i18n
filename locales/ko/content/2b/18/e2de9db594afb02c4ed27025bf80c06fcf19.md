# 설치

이 연습 문제들을 실행하려면 [CommandBox CLI](https://commandbox.ortusbooks.com/getting-started-guide)와 [Java 8](https://java.com/en/download/)만 설치하면 돼요. CommandBox CLI는 Mac, Linux, Windows를 지원하고, 설치 안내는 여기에서 볼 수 있어요:

[https://commandbox.ortusbooks.com/setup/installation](https://commandbox.ortusbooks.com/setup/installation)

Mac에서 Homebrew를 사용한다면 CommandBox CLI를 설치하는 방법은 다음과 같아요:

```bash
brew install commandbox
```

CLI를 설치하고 나면 REPL을 사용해 볼 수 있어요:

```bash
box repl
```

.cfm 페이지를 직접 실행할 수도 있어요:

```bash
box exec myTest.cfm
```

심지어 하드 드라이브의 어떤 디렉터리에서든 웹 서버를 시작할 수도 있어요:

```bash
box server start
```

CommandBox에는 향상된 탭 완성 기능을 제공하고 더 빠르게 실행되는 대화형 셸이 있어요. 인자 없이 `box` 바이너리를 실행하면 이 셸에 들어갈 수 있어요.

```bash
box
```
