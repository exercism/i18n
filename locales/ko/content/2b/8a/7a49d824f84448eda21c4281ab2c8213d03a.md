# 안내

**복소수**는 `z = a + b * i` 형태로 표현돼요. 여기서:

- `a`는 **실수부**(실수)이고,

- `b`는 **허수부**(역시 실수)이며,

- `i`는 `i^2 = -1`을 만족하는 **허수 단위**예요.

## 복소수의 연산

### 켤레복소수

복소수 `z = a + b * i`의 켤레복소수는 다음과 같아요:

```text
zc = a - b * i
```

### 절댓값

`z`의 절댓값(또는 모듈러스)은 다음과 같이 정의해요:

```text
|z| = sqrt(a^2 + b^2)
```

절댓값의 제곱은 `z`와 그 켤레복소수 `zc`의 곱으로 계산해요:

```text
|z|^2 = z * zc = a^2 + b^2
```

### 덧셈

두 복소수 `z1 = a + b * i`와 `z2 = c + d * i`의 합은 실수부와 허수부를 각각 더해서 구해요:

```text
z1 + z2 = (a + b * i) + (c + d * i)
        = (a + c) + (b + d) * i
```

### 뺄셈

두 복소수의 차는 각각의 실수부와 허수부를 빼서 구해요:

```text
z1 - z2 = (a + b * i) - (c + d * i)
        = (a - c) + (b - d) * i
```

### 곱셈

두 복소수의 곱은 다음과 같이 정의해요:

```text
z1 * z2 = (a + b * i) * (c + d * i)
        = (a * c - b * d) + (b * c + a * d) * i
```

### 역수

0이 아닌 복소수의 역수는 다음과 같아요:

```text
1 / z = 1 / (a + b * i)
      = a / (a^2 + b^2) - b / (a^2 + b^2) * i
```

### 나눗셈

한 복소수를 다른 복소수로 나눈 결과는 다음과 같아요:

```text
z1 / z2 = z1 * (1 / z2)
        = (a + b * i) / (c + d * i)
        = (a * c + b * d) / (c^2 + d^2) + (b * c - a * d) / (c^2 + d^2) * i
```

### 거듭제곱

_e_(자연로그의 밑)를 복소수 지수로 거듭제곱하는 것은 오일러 공식으로 표현할 수 있어요:

```text
e^(a + b * i) = e^a * e^(b * i)
              = e^a * (cos(b) + i * sin(b))
```

## 구현 요구 사항

복소수에 대한 내장 지원을 사용하지 않아야 하므로, 다음 연산을 구현해야 해요:

- 두 복소수의 **덧셈**
- 두 복소수의 **뺄셈**
- 두 복소수의 **곱셈**
- 두 복소수의 **나눗셈**
- 복소수의 **켤레복소수**
- 복소수의 **절댓값**
- _e_(자연로그의 밑)를 복소수로 **거듭제곱**
