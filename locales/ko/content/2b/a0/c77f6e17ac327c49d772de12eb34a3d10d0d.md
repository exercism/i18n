# 지침

이 연습 문제에서는 공장 직원의 이름표를 출력하는 코드를 작성해요.
직원에게는 ID, 이름, 부서 이름이 있어요.
직원 이름표의 라벨은 다음과 같은 형식으로 만들어져요: `"[id] - name - DEPARTMENT"`.

## 1. 직원의 이름표 출력하기

`print_name_badge` 함수를 구현해요. 이 함수는 ID, 이름, 부서를 매개변수로 받아요.
부서 이름을 대문자로 바꾼 이름표 라벨을 반환해요.

```R
print_name_badge(67, "Katherine Williams", "Strategic Communication")
# => "[67] - Katherine Williams - STRATEGIC COMMUNICATION"
```

## 2. 신입 직원의 이름표 출력하기

컴퓨터 시스템의 특이한 점 때문에, 신입 직원은 공장에서 일을 시작할 때 아직 ID가 없는 경우가 가끔 있어요.
이름표는 반드시 필요하기 때문에, ID 접두사가 없는 임시 이름표를 받아요.

`print_name_badge` 함수를 확장해요. ID가 없으면 ID 없이 이름표를 출력해야 해요.

```R
print_name_badge(NA, "Robert Johnson", "Procurement")
# => "Robert Johnson - PROCUREMENT"
```

## 3. 사장의 이름표 출력하기

공장 사장도 항상 이름표를 달고 있어야 해요.
하지만 사장에게는 부서가 없고, 앞으로도 생기지 않아요. 사장은 모든 부서 위에 있으니까요.
이 경우 라벨에는 부서 이름 대신 `"OWNER"`가 출력돼요.

`print_name_badge` 함수를 확장해요. 부서가 `NULL`이면 이름표가 회사 사장의 것이라고 가정해요.

```R
print_name_badge(204, "Rachel Miller", NULL)
# => "[204] - Rachel Miller - OWNER"
```

사장이 신입 직원일 수도 있다는 점에 주의해요.

```R
print_name_badge(NA, "Rachel Miller", NULL)
# => "Rachel Miller - OWNER"
```

## 4. ID가 없는 직원의 급여 합계 계산하기

ID가 얼마나 잘 발급되고 있는지 대략적으로 가늠하기 위해, ID가 없는 직원들의 급여 합계를 보고 싶어요.
값이 크다는 것은 많은 직원이 기다리고 있거나, 문제가 고참 직원들에게도 영향을 주고 있다는 뜻이에요. 둘 다 좋지 않아요.

ID 벡터와 이에 대응하는 급여 벡터를 받아서, 아직 ID가 없는 사람들의 급여 합계를 반환하는 `salaries_no_id` 함수를 구현해요.
두 벡터의 길이는 같아요.

```R
ids <- c(204, NA, 210, 352, NA, 263)
salaries <- c(23, 21, 47, 35, 17, 101) * 1000
salaries_no_id(ids, salaries)
# => 38,000
```

_테스트에 나오지 않는 추가 학습:_ ID가 없는 직원이 하나도 없다면, 합계를 구하는 "빈 벡터"는 무엇일까요?
