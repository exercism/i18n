# 지침

사용자가 서버에 파일을 업로드해 다른 사용자와 공유할 수 있도록 하는 프로젝트를 진행하고 있어요. 업로드한 파일이 [미디어 타입][mimetype]과 일치하는지 확인하는 함수를 작성하는 일을 맡았어요. 자료를 좀 찾아보니, 파일의 처음 몇 바이트는 대개 그 파일 형식만의 고유한 값이라서 일종의 서명 역할을 한다는 걸 알게 됐어요.

다음 표를 참고해요:

| 파일 형식 | 일반적인 확장자 | 미디어 타입                  | 바이너리 '서명'                                  |
| --------- | ---------------- | ---------------------------- | ------------------------------------------------ |
| ELF       | `"exe"`          | `"application/octet-stream"` | `0x7F, 0x45, 0x4C, 0x46`                         |
| BMP       | `"bmp"`          | `"image/bmp"`                | `0x42, 0x4D`                                     |
| PNG       | `"png"`          | `"image/png"`                | `0x89, 0x50, 0x4E, 0x47, 0x0D, 0x0A, 0x1A, 0x0A` |
| JPG       | `"jpg"`          | `"image/jpg"`                | `0xFF, 0xD8, 0xFF`                               |
| GIF       | `"gif"`          | `"image/gif"`                | `0x47, 0x49, 0x46`                               |

## 1. 확장자가 주어졌을 때 예상 미디어 타입 반환하기

`type_from_extension/1` 함수를 구현해요. 이 함수는 파일 확장자(문자열)를 받아서 미디어 타입(문자열)을 반환하고, 확장자가 예상하는 값과 일치하지 않으면 nil을 반환해요.

```elixir
FileSniffer.type_from_extension("exe")
# => "application/octet-stream"

FileSniffer.type_from_extension("txt")
# => nil
```

## 2. 바이너리 파일이 주어졌을 때 예상 미디어 타입 반환하기

`type_from_binary/1` 함수를 구현해요. 이 함수는 파일(바이너리)을 받아서 미디어 타입(문자열)을 반환하고, 파일 서명이 예상하는 값과 일치하지 않으면 nil을 반환해요.

```elixir
file = File.read!("application.exe")
FileSniffer.type_from_binary(file)
# => "application/octet-stream"

file = File.read!("example.txt")
FileSniffer.type_from_binary(file)
# => nil
```

파일을 바이너리로 읽는 부분은 신경 쓰지 않아요. 그건 이미 처리되어 있고, 테스트가 인자로 넘겨준다고 가정해요.

## 3. 확장자와 바이너리 파일이 주어졌을 때 파일이 예상 형식과 일치하는지 확인하기

`verify/2` 함수를 구현해요. 이 함수는 파일(바이너리)과 확장자(문자열)를 받아서 `:ok` 또는 `:error` 튜플을 반환해요.

```elixir
file = File.read!("application.exe")

FileSniffer.verify(file, "exe")
# => {:ok, "application/octet-stream"}

FileSniffer.verify(file, "png")
# => {:error, "Warning, file format and file extension do not match."}
```

[mimetype]: https://en.wikipedia.org/wiki/Media_type
