# 개요

Common Lisp Printer는 데이터를 스트림으로 출력하는 기능이에요. 이 기능에서 자주 쓰이는 함수 중 하나가 `format`이에요.

`format`은 필수 매개변수 두 개를 받아요. 하나는 데이터를 쓸 스트림이고, 다른 하나는 제어 문자열이에요. 제어 문자열의 내용이 나머지 인자들을 어떻게 사용할지 결정해요.

첫 번째 매개변수는 `t`와 `nil`, 두 가지 특별한 값을 가질 수 있어요. `t`는 `*standard-output*`에 바인딩된 스트림을 사용하라는 뜻이고, `nil`은 문자열을 만들어 반환하라는 뜻이에요. 스트림 매개변수가 `nil`이 아닌 한, `format`의 평가 결과는 `nil`이에요.

제어 문자열에는 포맷 지시자가 들어갈 수 있는데, `~` 뒤에 문자가 오는 형태로 나타내요 (문자의 대소문자는 중요하지 않아요). 포맷 지시자는 인자를 소비하는지, 그리고 그 인자를 스트림에 어떻게 출력할지를 정해요.

기본적으로 알아 두면 좋은 포맷 지시자는 다음과 같아요:

* `~A` - _보기 좋게_, "사람이 읽기 좋은" 방식으로 출력해요.
* `~S` - "기계가 읽을 수 있는" 형태가 되도록 _표준_ 방식으로 출력해요.
* `~%` - 줄바꿈을 출력해요
* `~&` - 이미 줄의 시작이 아니라면 줄바꿈을 출력해요.
* `~~` - 물결표를 출력해요.

예시:

```lisp
(format nil "The list is: ~A~%" (list 1 2 3)) ; => "The list is: (1 2 3)
                                                   "
(format nil "(format t ~S)" "hello world")    ; => "(format t \"hello world\""
(format nil "~&fresh~&lines")                 ;=> "fresh
                                                   lines"
(format nil "directives start with a ~~")     ; => "directives start with a ~"
```
