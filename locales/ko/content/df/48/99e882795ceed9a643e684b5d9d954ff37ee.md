# 힌트

## 1. 빠른 공격이 가능한지 확인하기

기사가 깨어 있는지 확인한 뒤, 그 상태를 나타내는 불리언 값을 _뒤집어야_ 해요. 이는 [`not`][not] 함수를 사용하면 돼요.

## 2. 일행을 감시할 수 있는지 확인하기

주어진 조건 중 _하나라도_ `true`이면 함수가 `true`를 반환하게 하고 싶어요. 이는 [`or`][or] 함수를 사용하면 돼요.

## 3. 죄수에게 신호를 보낼 수 있는지 확인하기

주어진 조건이 _모두_ `true`일 때만 `true`를 반환하고 싶어요. 이는 [`and`][and] 함수를 사용하면 돼요.

## 4. 죄수를 풀어줄 수 있는지 확인하기

세 가지 기본 논리 연산자인 [`and`][and], [`or`][or], [`not`][not]을 조합해야 해요.

[not]: https://clojuredocs.org/clojure.core/not
[or]: https://clojuredocs.org/clojure.core/or
[and]: https://clojuredocs.org/clojure.core/and
