# 소개

Elm에서 문자와 문자열은 텍스트를 표현하는 기초가 돼요.
문자열은 문자의 배열이라고 생각할 수 있고, 대부분의 `List` 함수에는 `String` 모듈에 그에 대응하는 함수가 있어요.

## 문자

`Char` 타입은 `'a'`처럼 작은따옴표로 감싼 유니코드 문자 하나를 나타내요. 
`Char` 모듈은 문자의 성질을 검사하는 조건 함수(`Char -> Bool`)인 `isUpper`, `isLower`, `isAlpha`, `isAlphaNum`을 제공해요.
이 모듈은 또 문자를 변환하는 함수 `toUpper`, `toLower`, `toLocaleUpper`, `toLocaleLower`와, `toCode`와 `fromCode`로 유니코드 숫자 값(`Int`)을 오가며 변환하는 함수도 제공해요.

## 문자열

`String` 타입은 효율적인 문자열 조작을 위한 내장 표현을 제공하며, 어떤 유니코드 문자 시퀀스든 나타낼 수 있어요.
문자열은 큰따옴표로 나타내요: `"this is a string"`.
여러 줄 문자열은 큰따옴표 세 개로 나타내며, 이스케이프하지 않은 따옴표와 줄바꿈을 포함할 수 있어요.

```elm 
haiku = 
"""
    Code's strings entwine
    , In binary, thoughts combine
    , Logic's elegant line.
"""
```

## 문자열 조작

`reverse : String -> String`는 문자열을 뒤집어요.
```elm 
reverse "Hello world." 
    --> ".dlrow olleH"
```

`repeat : Int -> String -> String`는 문자열을 n번 반복해요.
```elm 
repeat 2 "Hello world." 
    --> "Hello world.Hello world."
```

`replace : String -> String -> String -> String`는 주어진 부분 문자열이 나타나는 곳을 모두 바꿔요.
```elm
replace "Hello" "Goodbye cruel" "Hello world." 
    --> "Goodbye cruel world."
```

`append : String -> String -> String`는 두 문자열을 이어 붙여요.
`++` 연산자로도 이렇게 할 수 있어요.
```elm
append "butter" "fly" 
    --> "butterfly"
"butter" ++ "fly" 
    --> "butterfly"
```

`concat : List String -> String`는 문자열 배열을 하나의 문자열로 이어 붙여요.
```elm
concat ["never", "the", "less"] 
    --> "nevertheless"
```

`split : String -> String -> List String`는 주어진 구분자를 기준으로 문자열을 문자열 배열로 나눠요.
```elm
split ";" "cat;dog;cow" 
    --> ["cat", "dog", "cow"]
```

`join : String -> List String -> String`는 문자열 배열을 주어진 구분자와 함께 이어 붙여요.
```elm
join "a" ["H", "w", "ii", "n"] 
    --> "Hawaiian"
```

`words : String -> List String`는 공백 덩어리를 기준으로 문자열을 문자열 배열로 나눠요.
```elm
words "How are \t you? \n Good?" 
    --> ["How", "are", "you?", "Good?"]
```

`lines : String -> List String`는 줄바꿈을 기준으로 문자열을 여러 줄로 나눠요.
```elm
lines "How are you?\nGood?" 
    --> ["How are you?", "Good?"]
```

`cons : Char -> String -> String`는 문자열의 맨 앞에 문자를 추가해요.
```elm
cons 'T' "he truth is out there" 
    --> "The truth is out there"
```

`uncons : String -> Maybe ( Char, String )`는 비어 있지 않은 문자열을 머리와 꼬리로 나눠요.
이렇게 하면 배열에서 하듯 문자열에서도 똑같이 패턴 매칭을 할 수 있어요.
빈 문자열은 `Nothing`을 반환해요.
```elm
uncons "abc" 
    --> Just ('a', "bc")
uncons ""
    --> Nothing
```

## 부분 문자열 가져오기

`slice : Int -> Int -> String -> String`는 시작 인덱스와 끝 인덱스가 주어지면 부분 문자열을 가져와요.
음수 인덱스는 배열의 끝에서부터 세요.
```elm
slice 0 6 "snakes on a plane!" 
    --> "snakes"
slice 0 -7 "snakes on a plane!"
    --> "snakes on a"
```

`left : Int -> String -> String`와 `right : Int -> String -> String`는 각각 문자열의 왼쪽 또는 오른쪽에서 n개의 문자를 가져와요.

```elm
left 2 "Mulder" 
    --> "Mu"
right 2 "Scully" 
    --> "ly"
```

`dropLeft : Int -> String -> String`와 `dropRight : Int -> String -> String`는 각각 문자열의 왼쪽 또는 오른쪽에서 n개의 문자를 버려요.
```elm
dropRight 6 "Hello world." 
    --> "Hello"
dropLeft 6 "Hello world." 
    --> "world"
```

## 문자열의 성질 확인하기

`length : String -> Int`는 문자열의 문자 개수를 반환해요.
```elm 
length "Hello world." 
    --> 12
```

`isEmpty : String -> Bool`는 문자열이 비어 있는지 판단해요. 
```elm 
isEmpty "Hello world." 
    --> False
```

`contains : String -> String -> Bool`는 두 번째 문자열이 첫 번째 문자열을 포함하는지 확인해요.
```elm
contains "the" "theory" 
    --> True
contains "THE" "theory" 
    --> False
```

`startsWith : String -> String -> Bool`와 `endsWith : String -> String -> Bool`는 두 번째 문자열이 주어진 부분 문자열로 시작하거나 끝나는지 확인해요.
```elm
startsWith "the" "theory" 
    --> True
endsWith "ory" "theory" 
    --> True
```

`indexes : String -> String -> List Int`는 어떤 문자열에서 부분 문자열이 시작하는 모든 인덱스의 배열을 구해요.
```elm
indexes "ss" "Mississippi"  
    --> [2, 5]
```

## 문자열 변환하기
`toInt : String -> Maybe Int`는 문자열을 `Just Int`로 변환하려고 시도하고, 형식이 잘못된 문자열에는 `Nothing`을 반환해요.
```elm
toInt "-42" 
    --> Just -42
toInt "3.1" 
    --> Nothing
toInt "two" 
    --> Nothing
```

`fromInt : Int -> String`는 정수를 문자열로 변환해요.
```elm
fromInt -42 
    --> "-42"
```

`toFloat : String -> Maybe Float`는 문자열을 실수로 변환하려고 시도하고, 형식이 잘못된 문자열에서는 실패해요.
```elm
toFloat "-42" 
    --> Just -42.0
toFloat "3.1" 
    --> Just 3.1
toFloat "two" 
    --> Nothing
```

`fromFloat : Float -> String`는 실수를 문자열로 변환해요.
```elm
fromFloat 3.9 
    --> "3.9"
```

`toList : String -> List Char`와 `fromList : List Char -> String`는 각각 문자열을 문자 배열로, 문자 배열을 문자열로 변환해요.
```elm 
toList "abc" 
    --> ['a', 'b', 'c']
fromList ['a', 'b', 'c'] 
    --> "abc"
```

`fromChar : Char -> String`는 문자를 문자열로 변환해요.
```elm
fromChar 'a' 
    --> "a"
```

## 문자열 서식 지정하기

`toUpper : String -> String`와 `toLower : String -> String`는 각각 문자열을 모두 대문자 또는 모두 소문자로 변환해요.
대소문자를 구분하지 않는 비교에 유용해요.
```elm
toUpper "skinner" 
    --> "SKINNER"
toLower "X-FILES" 
    --> "x-files"
```

`pad : Int -> Char -> String -> String`는 주어진 `Char`로 문자열 양쪽을 채워 지정한 길이로 만들어요.
```elm
pad 5 ' ' "11"  
    --> "  11 "
```
마찬가지로 `padLeft`와 `padRight`는 문자열의 한쪽을 채워 주어진 길이로 만들어요.

`trim : String -> String`는 문자열 양쪽의 공백을 제거해요.
```elm
trim "  hats  \n" 
    --> "hats"
```
`trimLeft`와 `trimRight`는 문자열의 한쪽 공백을 제거해요.

## 고차 함수

`map : (Char -> Char) -> String -> String`는 주어진 함수로 문자열의 모든 문자를 변환해요.
주어지는 함수는 `Char`에서 `Char`로 가는 매핑이어야 한다는 점에 유의해요.
```elm
map (\c -> if c == '/' then '.' else c) "a/b/c" 
    --> "a.b.c"
```

`filter : (Char -> Bool) -> String -> String`는 검사를 통과한 문자만 남겨요.
```elm
filter isDigit "R2-D2" 
    --> "22"
```

`foldl : (Char -> b -> b) -> b -> String -> b`는 문자열을 왼쪽부터 축약해요.
이 함수는 첫 번째 문자를 첫 번째 매개변수로, 주어진 초기값을 두 번째 매개변수로 해서 적용돼요.
함수의 결과는 주어진 초기값과 같은 타입이어야 하고, 각 문자에 차례대로 적용돼요.
```elm
foldl (\c acc -> Char.toCode c + acc) 0 "the sum of my unicode is " 
    --> 2260
```
`foldr`은 같은 일을 하지만 문자열의 오른쪽부터 시작해요.

`any : (Char -> Bool) -> String -> Bool`는 주어진 조건 함수에 어떤 문자가 `True`를 반환하는지 판단해요.
```elm
any isDigit "R2-D2" 
    --> True
any isDigit "heart" 
    --> False
```
`all : (Char -> Bool) -> String -> Bool`는 문자열의 모든 문자가 주어진 조건 함수에 `True`를 반환하는지 판단해요.
```elm
all isDigit "R2-D2" 
    --> False
all isAlpha "heart" 
    --> True
```
