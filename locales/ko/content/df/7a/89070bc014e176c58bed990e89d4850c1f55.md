# 안내

선생님이에요.
학년 말이 되면 학생마다 숫자로 성적을 매겨 두었어요.
이제 그 성적을 알파벳 등급으로 바꾸고, 각 등급을 받은 학생이 몇 명인지 세어야 해요.

## 1. 숫자 성적을 알파벳 등급으로 바꾸기

`letter_grade` 함수는 숫자 성적을 입력으로 받아서 해당 등급 문자를 출력해요.
다음 범위를 사용해요:

| 등급 |      점수 |
| :----: | ---------: |
|   A    | 90% - 100% |
|   B    |  80% - 89% |
|   C    |  70% - 79% |
|   D    |  60% - 69% |
|   F    |   0% - 59% |

예시:

```jq
75 | letter_grade   # => "C"
```

## 2. 등급별 학생 수 세기

`count_letter_grades` 함수는 학생 이름을 성적에 매핑한 객체를 입력으로 받아요.
출력은 각 등급을 그 등급을 받은 학생 수에 매핑한 객체예요.

예시:

```jq
{"Joe": 78, "Jane": 93, "Richard": 72} | count_letter_grades
# => {"A": 1, "B": 0, "C": 2, "D": 0, "F": 0}
```

이 문제를 푸는 방법은 여러 가지가 있어요.
연습 삼아 `reduce` 필터를 사용해 봐요.
