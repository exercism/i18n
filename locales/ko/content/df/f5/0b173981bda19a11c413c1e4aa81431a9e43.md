# 소개

## 숫자

Python에는 세 가지 종류의 내장 숫자형이 있어요: `ints`, `floats`, `complex`. 하지만 이 연습 문제에서는 `ints`와 `floats`만 다뤄요.

### ints

`ints`는 정수예요. 예를 들어 `1234`, `-10`, `20201278` 같은 숫자예요.

Python의 정수는 [임의 정밀도][arbitrary-precision]를 지원해요. 즉, 자릿수는 호스트 시스템에서 사용할 수 있는 메모리에 의해서만 제한돼요.

### floats

`floats`는 소수점을 포함하는 숫자예요. 예를 들어 `0.0`, `3.14`, `-9.01` 같은 숫자예요.

실수는 보통 Python에서 C의 `double`을 사용해 구현되는데(정밀도는 _소수점 이하 15자리_예요), 표현 방식은 호스트 시스템과 그 밖의 구현 세부 사항에 따라 달라져요. 이 때문에 실수를 다룰 때 예상치 못한 일이 생기기도 하지만, 대부분의 상황에서는 "충분히 괜찮아요".

## 산술

Python은 `ints`와 `floats` 사이의 산술 연산을 완벽하게 지원해요. 이항 산술 연산자(`+`, `-`, `*`, `/`, `//`, `%`)를 사용할 때는 더 좁은 숫자를 더 넓은 숫자에 맞춰 변환해요.

Python은 `ints`가 `floats`보다 좁다고 봐요. 그래서 식에 실수를 사용하면 결과도 실수가 돼요. 하지만 나눗셈을 할 때는 정수만 사용하더라도 결과가 항상 실수가 돼요.

```python
# The int is widened to a float here, and a float type is returned.
>>> 3 + 4.0
7.0
>>> 3 * 4.0
12.0
>>> 3 - 2.0
1.0
# Division always returns a float.
>>> 6 / 2
3.0
>>> 7 / 4
1.75
# Calculating remainders.
>>> 7 % 4
3
>>> 2 % 4
2
>>> 12.75 % 3
0.75
```

정수 결과가 필요하면 `//`를 사용해 결과를 잘라낼 수 있어요.

```python
>>> 6 // 2
3
>>> 7 // 4
1
```

실수를 정수로 변환하려면 `int()`를 사용하면 돼요. 정수를 실수로 변환하려면 `float()`를 사용하면 돼요.

```python
>>> int(6 / 2)
3
>>> float(1 + 2)
3.0
```
