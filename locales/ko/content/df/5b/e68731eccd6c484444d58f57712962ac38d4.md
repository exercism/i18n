# 출시 준비

트랙을 출시할 준비가 되기 전에 다음 작업을 모두 완료했는지 확인해 주세요.

## 트랙 아이콘 요청하기

웹사이트에 사용할 아이콘을 디자인하려면 [exercism/website-icons](https://github.com/exercism/website-icons/issues) 저장소에 새 이슈를 열고 다음 질문에 답해 주세요.

- 언어에 공식 로고가 있나요? 그렇다면
  - 예시 링크를 포함해 주세요
  - 해당 로고 사용에 따른 저작자 표시 요건과 부여되는 권리를 알려주세요
- 언어에 비공식 로고가 있나요? 그렇다면
  - 사람들이 비공식 로고를 어떻게 사용하는지 설명해 주세요
  - 예시 링크를 포함해 주세요
  - 해당 로고의 저작자 표시 요건을 알려주세요

## 트랙 문서 추가하기

다음 트랙 문서를 추가해요.

- `docs/ABOUT.md`: 언어를 간단히 소개하는 문서예요.
- `docs/INSTALLATION.md`: 학습자가 CLI를 사용해 자신의 로컬 시스템에서 트랙을 진행하려면 무엇을 설치해야 하는지 설명해요.
- `docs/LEARNING.md`: 학습 자료 링크를 담고 있어요.
- `docs/RESOURCES.md`: 유용한 자료 링크를 담고 있어요.
- `docs/TESTS.md`: 트랙에서 테스트를 실행하는 것과 관련된 모든 내용을 설명해요.

이 문서들은 학습자가 트랙을 시작하고, 트랙과 그 언어에 대해 알아가는 데 도움이 돼요.
더 자세한 내용은 [문서 안내](/docs/building/tracks/docs)를 참고해요.

## 연습 문제 문서 추가하기

다음 연습 문제 문서를 추가해요.

- `exercises/shared/.docs/help.md`: 도움을 받는 방법에 대한 트랙별 안내를 담고 있어요
- `exercises/shared/.docs/tests.md`: 테스트를 실행하는 방법에 대한 트랙별 안내를 담고 있어요

## 코드 스니펫 추가하기

`docs/SNIPPET.txt` 파일에 코드 스니펫을 추가해요.
이 스니펫은 언어 문법이 어떻게 생겼는지 시각적으로 보여줘요.
더 자세한 내용은 [문서 안내](/docs/building/tracks/docs)를 참고해요.

## 메타데이터 업데이트하기

트랙의 메타데이터는 [config.json 파일](/docs/building/tracks/config-json)에 정의돼 있어요.
다음 속성을 업데이트해야 해요.

- `language`: 트랙의 언어예요(예: `"C#"`). 길이는 255 이하여야 해요
- `slug`: 트랙 언어를 소문자 kebab-case 문자열로 나타낸 값이에요(예: `"csharp"`). 길이는 255 이하여야 해요
- `blurb`: 언어에 대한 짧은 설명이에요. 길이는 400 이하여야 해요
- `online_editor`: 온라인 에디터에서 사용하는 설정을 담은 객체예요.
  - `indent_style`: `"space"` 또는 `"tab"` 중 하나예요
  - `indent_size`: 들여쓰기 크기를 나타내는 정수예요(예: `4`)
  - `highlightjs_language`: Highlight.js에서 사용하는 언어 식별자예요([전체 식별자 목록](https://github.com/highlightjs/highlight.js/blob/main/SUPPORTED_LANGUAGES.md)을 참고해요). Highlight.js가 지원하지 않는 언어라면 이 필드는 생략해도 돼요.
- `key_features`: 언어의 주요 특징을 간결하게 정리한 항목이에요. 더 자세한 내용은 [주요 특징 문서](/docs/building/tracks/config-json#h-key-features)를 참고해요.
- `tags`: 이 트랙에 적용되는 태그를 정의해요. 이 태그 덕분에 웹사이트에서 트랙을 검색할 수 있어요. 자세한 내용과 지원되는 태그 목록은 [태그 문서](/docs/building/tracks/config-json#h-tags)를 참고해요.
