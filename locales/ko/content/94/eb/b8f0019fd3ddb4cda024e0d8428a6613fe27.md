# 힌트

## 일반

- 정수 값은 하나 이상의 연속된 숫자로 정의할 수 있어요.

## 1. 오븐 예상 시간을 분 단위로 정의하기

- [바인딩][bindings]을 정의해야 해요.

## 2. 남은 오븐 시간을 분 단위로 계산하기

- 매개변수 하나를 받는 [함수][functions]를 정의해야 해요.
- 앞서 정의한 바인딩을 이름으로 참조해서 사용할 수 있어요.
- 함수의 마지막 표현식은 함수에서 [자동으로 반환][return-values]돼요. 어떤 값을 반환할지 명시적으로 나타내지 않아도 돼요.
- 값을 빼려면 [뺄셈 수학 연산자][operators]를 사용할 수 있어요.

## 3. 준비 시간을 분 단위로 계산하기

- 매개변수 하나를 받는 [함수][functions]를 정의해야 해요.
- 값을 곱하려면 [곱셈 수학 연산자][operators]를 사용할 수 있어요.

## 4. 경과 시간을 분 단위로 계산하기

- 매개변수 두 개를 받는 [함수][functions]를 정의해야 해요.
- 앞서 정의한 다른 함수 중 하나를 [호출][calling]할 수 있어요.
- 값을 더하려면 [덧셈 수학 연산자][operators]를 사용할 수 있어요.
