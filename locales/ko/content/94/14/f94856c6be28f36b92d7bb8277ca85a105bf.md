# 소개

## `for`문

`for`문은 코드 블록을 반복해요.
첫 줄에서 블록을 몇 번 반복할지 정해요.

```go
for init; condition; post {
    // loop body
}
```

- **init** 문은 첫 번째 반복 전에 한 번 실행돼요. 루프에서 사용할 카운터 변수를 선언하고 초기화하는 경우가 많아요.
- **condition**은 각 반복 전에 평가되는 불리언 표현식이에요. 이 값이 `false`로 평가되면 루프가 멈춰요.
- **post** 문은 각 반복이 끝난 뒤에 실행돼요. 카운터를 갱신할 때 사용할 수 있어요.

`init; condition; post`는 괄호로 감싸면 안 돼요.
그렇지만 루프 본문을 감싸는 중괄호는 항상 필요해요.

이 루프는 `i`를 `1`에서 시작해서, `i`의 현재 값을 출력하고, 다음 반복을 위해 값을 증가시키며, `i`가 `10`이 되면 멈춰요.

```go
for i := 1; i < 10; i++ {
    fmt.Println(i)
}
```
