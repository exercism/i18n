# 데이터베이스 고액 지출

## 문제 설명

ABC Corp는 주어진 금액(예: `3000.00`)보다 큰 결제 내역이 있는 직원의 이름과 부서를 찾아 달라고 해요.

필요한 데이터를 반환하려면 `HighPayment`라는 레코드를 만들어요. 레코드의 정의는 다음과 같아요.

```ballerina
type HighPayment record {
    string name;
    string department;
    decimal amount;
    string reason;
};
```

JDBC 클라이언트의 `query` 연산을 사용해서 데이터베이스에서 필요한 데이터를 가져와요.

> 참고: 결과를 `payment_id` 기준으로 오름차순으로 정렬해요.

## 데이터베이스 정보

이 문제에서는 제공된 H2 데이터베이스를 사용해요.

> 샘플 데이터베이스 파일은 `gofigure.mv.db`이고, 데이터베이스 이름은 `gofigure`예요. `db` 폴더 안에 들어 있어요.

다음 테이블들은 몇 가지 샘플 데이터와 함께 샘플 H2 데이터베이스에 이미 들어 있어요. 열 이름과 데이터 타입은 아래와 같아요.

**테이블 이름** : `Employee`

| **열:**      | 타입 |
| -----------       | ----------- |
| `employee_id`     | 정수, 자동 증가 기본 키       |
| `name`            | 문자열        |
| `city`            | 문자열        |
| `department`      | 문자열        |
| `age`             | 정수        |

**테이블 이름**: `Payment`

| **열:**      | 타입 |
| -----------       | ----------- |
| `payment_id`      | 정수, 자동 증가 기본 키       |
| `date`            | 날짜        |
| `amount`          | 실수        |
| `employee_id`     | 정수        |
| `reason`          | 문자열        |

* 데이터베이스 파일은 `gofigure.mv.db`예요. JDBC URL은 `jdbc:h2:file:/path/to/db/file`로 사용해요.
* 사용자 이름: `root`
* 비밀번호: `root`

## 제약 사항

* 쿼리와 Ballerina 샘플을 검증하려면 `db` 폴더에 제공된 H2 데이터베이스 파일을 사용해요.
* Ballerina.toml에 H2 데이터베이스 드라이버를 플랫폼 의존성으로 추가하려면 Maven 의존성 파라미터 방식을 사용해요.

## 테스트 환경

* `bal test`로 테스트를 실행할 수 있어요. 주어진 샘플 DB를 대상으로 실행돼요.

## 힌트

* 데이터베이스를 다룰 때는 [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc) 모듈을 사용해요.
* JDBC 드라이버를 의존성으로 추가하는 방법은 [사전 준비](https://lib.ballerina.io/ballerinax/java.jdbc/latest) 섹션을 참고해요.
* DB에서 데이터를 조회하려면 [query](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-query) 원격 메서드를 사용해요.
* [간단한 쿼리](https://ballerina.io/learn/by-example/mysql-query-operation) 예제를 참고해요.
* DB에서 데이터에 접근하려면 Ballerina의 [stream](https://ballerina.io/learn/by-example/stream-type) 타입을 사용해요.
* DB에서 필요한 데이터 집합을 찾으려면 SQL 조인을 사용해요.
