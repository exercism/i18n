# 소개

Python의 `str`은 [유니코드 코드 포인트][unicode code points]로 이루어진 [불변 시퀀스][text sequence]예요.
여기에는 문자, 발음 구별 기호, 위치 지정 문자, 숫자, 통화 기호, 이모지, 문장 부호, 다양한 공백, 줄 바꿈 등이 포함될 수 있어요.

문자열은 모든 [공통 시퀀스 연산][common sequence operations]을 구현하며, `for item in <str>` 또는 `for index, item in enumerate(<str>)` 구문으로 반복할 수 있어요.
`<str> + <other str>` 또는 `<str>.join(<iterable>)`로 이어 붙일 수 있고, `<str>.split(<separator>)`로 나눌 수 있으며, 다양한 포맷팅과 조합 옵션을 제공해요.

문자열을 더 다양하게 다루기 위해, Python은 검색, 정리, 변환, 번역을 비롯한 여러 작업을 도와주는 다양한 [문자열 메서드][str-methods]를 제공해요.

`str`은 _불변_이기 때문에 메모리에 있는 `str` 객체의 값은 바뀌지 않아요. 문자열을 수정하는 것처럼 보이는 메서드는 그 `str` 객체의 새 복사본이나 인스턴스를 반환해요.
