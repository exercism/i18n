# 지침

엘레나는 신문 공장의 새 품질 관리자예요.
회사에 막 합류한 그녀는 공장의 여러 공정을 살펴보며 무엇을 개선할 수 있을지 알아보기로 했어요.

기술자들이 품질 검사를 손으로 직접 하는 경우가 많다는 걸 알게 됐어요.

자동화할 좋은 기회가 있다고 본 그녀는, 프리랜서 개발자인 여러분에게 기계 몇 대를 모니터링하는 소프트웨어를 만들어 달라고 부탁해요.

## 1. 방의 습도 수준 모니터링하기

첫 번째 임무는 생산실의 습도 수준을 모니터링하는 소프트웨어를 작성하는 거예요.
회사 소프트웨어에 이미 연결된 센서가 있어서, 방의 습도 백분율을 주기적으로 반환해요.

습도 백분율이 너무 높으면 오류를 발생시키는 함수를 소프트웨어에 구현해야 해요.
함수 이름은 `check_humidity_level`이고, 습도 백분율을 매개변수로 받아야 해요.

백분율이 70%를 넘으면 오류를 내고 중단해야 해요 (메시지는 중요하지 않아요).
그렇지 않으면 "humidity test passed"가 포함된 메시지를 출력하고, 측정값이 정상임을 확인하는 `TRUE`를 반환해요.

```R
check_humidity_level(60)
#> humidity test passed
#> [1] TRUE

check_humidity_level(100)
#> Error in check_humidity_level(100) : pct_humidity <= 70 is not TRUE
```

## 2. 과열 감지하기

엘레나는 첫 번째 과제에 아주 만족해서, 기계 온도 모니터링을 맡아 달라고 부탁해요.
기술자 그렉과 이야기하던 중, 기계 온도가 500°C를 넘으면 기술자들이 과열을 걱정하기 시작한다는 걸 듣게 돼요.

기계에는 내부 온도를 측정하는 센서가 달려 있어요.
이 센서는 아주 민감해서 자주 고장 난다는 점을 알아 두세요.
이럴 때는 기술자들이 센서를 교체해야 해요.

해야 할 일은 온도를 매개변수로 받는 `report_overheating` 함수를 구현해서, 센서가 고장 났거나 기계가 과열되기 시작하면 오류를 발생시키는 거예요.

나중에 오류 종류에 따라 다르게 대응해야 한다는 걸 알고 있으니, 두 가지 오류를 구분할 방법이 필요해요.

- 센서가 고장 나면 온도는 `NULL`이에요.
  이 경우에는 "Sensor Broken"이 문자열에 포함된 오류 메시지를 내고 중단해야 해요.
- 센서가 정상일 때 온도가 600°C를 넘으면, 온도가 포함된 메시지를 내고 중단해야 해요.
- 온도가 500°C를 넘지만 600°C는 넘지 않으면, 온도가 포함된 경고를 출력하고 `FALSE`를 반환해요.
- 그 외의 경우에는 모두 정상이니, `t`가 온도인 메시지 `"temperature check passed: t °C"`를 출력하고 `TRUE`를 반환해요.

```R
report_overheating(NULL)
#> Error in report_overheating(NULL) : Sensor Broken

report_overheating(800)
#> Error in report_overheating(800) : Overheating: 800 C

report_overheating(550)
#> [1] FALSE
#> Warning message:
#> In report_overheating(550) : Risk of overheating: 550 C

report_overheating(450)
#> temperature check passed: 450 °C
#> [1] TRUE
```


## 3. 기계 모니터링하기

이제 기계가 오류를 감지할 수 있고 여러분에게는 사용자 정의 기계 오류가 있으니, 모든 것이 어떻게 동작하는지 보고하는 래퍼 함수를 추가해요.
이 래퍼는 이전 함수들의 로그를 반환하는 것 외에도, 발생하는 실패 유형에 따라 로그를 추가해야 해요.

- 습도와 온도를 확인해요.
- 문제가 있으면 `check_humidity_level()`과 `report_overheating()`가 각자의 로그를 출력하도록 놔둬요.
- 모두 정상이면 "All OK"가 포함된 메시지를 추가해요.

습도와 온도를 인자로 받는 `monitor_the_machine()` 함수를 구현해요.

```R
# Working well
monitor_the_machine(53, 200)
#> humidity test passed
#> temperature check passed: 200 °C
#> All OK!

# High humidity
monitor_the_machine(90, 200)
#> Error in check_humidity_level(pct_humidity) : 
#>   pct_humidity <= 70 is not TRUE

# Faulty sensor
monitor_the_machine(53, NULL)
#> humidity test passed
#> Error in report_overheating(temperature) : Sensor Broken

# Mild overheating
monitor_the_machine(53, 550)
#> humidity test passed
#> Warning message:
#> In report_overheating(temperature) : Risk of overheating: 550 C

# Dangerous overheating: shutdown
monitor_the_machine(53, 650)
#> humidity test passed
#> Error in report_overheating(temperature) : Overheating: 650 C
```
