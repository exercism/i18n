# 지시 사항

여러분은 산타클로스의 물류 부서에서 일하는 엘프예요. 상사에게서 시스템 소프트웨어를 업그레이드하라는 두 가지 작업을 받았어요.

## 1. 장난감 이름 가져오기

시스템은 데이터베이스에서 장난감의 이름을 가져올 수 있어야 해요.
데이터베이스는 `(name: String, quantity: Int)` 타입의 튜플로 이루어져 있어요.

`(name: String, quantity: Int)` 타입의 튜플을 담은 인자를 받는 `getName(_:)` 함수를 구현해요.

```swift
let toy = (name: "Doll", quantity: 10)
getName(toy)
// Returns "Doll"
```

## 2. 데이터베이스에 새 장난감 추가하기

장난감 시장은 변화가 빠르고, 인기 있는 것이 아주 빠르게 바뀌어요.
따라서 새 장난감을 만드는 함수가 필요해요.

장난감의 이름을 담는 인자 `name`과 장난감의 수량을 담는 인자 `amount`를 받는 `createToy(name:amount:)` 함수를 구현해요.

```swift
createToy(name: "Doll", amount: 10)
// Returns (name: "Doll", amount: 10)
```

## 3. 장난감 수량 업데이트하기

산타의 작업장에 있는 엘프들은 끊임없이 장난감을 만들어요. 그래서 산타는 각 장난감의 수량을 계속 파악해야 해요.
이를 위해 시스템은 데이터베이스에 있는 장난감의 수량을 업데이트할 수 있어야 해요.

다음 인자들을 받는 `updateQuantity(_:toy:Amount:)` 함수를 구현해요:
- `(name: String, quantity: Int)` 타입의 튜플 배열을 담는 `toys`.
- 업데이트할 장난감의 이름을 담는 `toy`.
- 장난감의 새 수량을 담는 `amount`.

장난감이 이미 데이터베이스에 있다고 가정해도 되고, 그 부분을 확인할 필요는 없어요.

```swift
let toys = [(name: "Doll", quantity: 10), (name: "Car", quantity: 5), (name: "Train", quantity: 3)]
updateQuantity(toys, toy: "Doll", amount: 15)
// Returns [(name: "Doll", quantity: 15), (name: "Car", quantity: 5), (name: "Train", quantity: 3)]
```

## 4. 장난감에 카테고리 키 추가하기

산타는 데이터베이스에 있는 장난감을 분류하고 싶어 해요.
배달할 때 장난감을 쉽게 찾고, 데이터베이스의 장난감을 정렬할 수 있게 하기 위해서예요.

그런데 시스템을 처음 구현할 때 카테고리 키를 빠뜨렸어요.
이제 시스템은 데이터베이스의 장난감에 카테고리 키를 추가할 수 있어야 해요.

다음 인자들을 받는 `addCategory(_:category:)` 함수를 구현해요:
- `(name: String, quantity: Int)` 타입의 튜플 배열을 담는 `toys`.
- 장난감에 추가할 카테고리 키를 담는 `category`.

장난감이 이미 데이터베이스에 있다고 가정해도 되고, 그 부분을 확인할 필요는 없어요.
장난감에 아직 카테고리 키가 없다고도 가정해도 돼요.

```swift
let toys = [(name: "Car", quantity: 5), (name: "Train", quantity: 3)]
addCategory(toys, category: "Vehicle")
// Returns [(name: "Car", quantity: 5, category: "Vehicle"), (name: "Train", quantity: 3, category: "Vehicle")]
```
