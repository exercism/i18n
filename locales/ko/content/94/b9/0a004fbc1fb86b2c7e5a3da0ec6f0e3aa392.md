# 소개

Cairo에서 불리언은 미리 선언된 불리언 타입 `bool`로 표현되며, 값은 `true` 또는 `false` 중 하나예요.

```rust
let speeding = true;   // Boolean variable 'speeding' set to 'true'
let has_error = false; // Boolean variable 'has_error' set to 'false' 
```

Cairo는 식을 불리언 값으로 평가해 `true` 또는 `false`를 반환하는 세 가지 논리 연산자를 지원해요.

| 연산자    | 의미                                 |
| ----------- | --------------------------------------------- |
| `&&` (and)  | 두 명제가 모두 참이면 참이에요.       |
| `\|\|` (or) | 두 명제 중 적어도 하나가 참이면 참이에요. |
| `!` (not)   | 명제가 거짓일 때만 참이에요.    |
