# 소개

Common lisp에는 여러 가지 조건 표현식이 있는데, 가장 큰 차이는 각 표현식이 지원하는 분기의 수예요.

- `when`과 `unless`는 분기를 하나만 가질 수 있어요:

```lisp
(when (= 2 2) "All is well")      ; => "All is well"
(unless (= 2 2) "Time to panic!") ; => NIL
```

테스트 표현식 뒤에는 표현식을 여러 개 쓸 수 있어요.

- `if`는 고전적인 if-then-else 구조를 제공해요:

```lisp
(if (= 2 2) 'how-honest 'you-liar) ; => HOW-HONEST
```

then 절과 else 절에는 각각 표현식을 하나만 쓸 수 있다는 점에 유의해요.

- `cond`는 `if` 표현식을 중첩하지 않고도 분기를 여러 개 만들 수 있는 방법을 제공해요:

```lisp
(cond ((= 0 2) 'nope)
      ((= 1 2) 'try-again)
      ((= 2 2) 'quite-true)
      ((= 3 2) 'too-far)
      (t 'something-else))
; => QUITE-TRUE
```

테스트 표현식 뒤에는 표현식의 개수에 제한이 없어요.

- `case`는 고전적인 'switch' 스타일 구조를 제공해요. 하나의 값을 여러 분기와 비교해요:

```lisp
(case 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark")
  (otherwise "???"))
; => "???"
```

`cond`와 마찬가지로, 테스트 표현식 뒤에는 표현식의 개수에 제한이 없어요.
