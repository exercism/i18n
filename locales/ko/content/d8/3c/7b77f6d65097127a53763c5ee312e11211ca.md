# 소개

## 주석

Common Lisp에서는 컴퓨터가 무시하는 "주석"을 작성할 수 있어요.
한 줄 주석은 세미콜론(`;`) 한 개 이상으로 시작하고, 가끔 다음과 같은 형태를 볼 수도 있어요:

```lisp
(code...) ; => value
```

여기서 주석은 그 줄의 코드를 실행한 뒤 Common Lisp이 어떤 값을 반환하는지 나타내는 데 쓰여요.

줄 끝에 짧은 주석을 달 때는 세미콜론 한 개, 코드 묶음 위에 더 긴 주석을 달 때는 두 개, 함수 같은 것을 설명하는 긴 주석에는 세 개, 소스 파일 맨 위의 헤더 같은 주석에는 네 개를 쓰는 것이 관례예요.

## 콘스

Common Lisp의 모든 객체는 "원자"(더 이상 나눌 수 없는 단일 값)이거나, 생성 함수 "cons"로 만드는 "콘스"예요.
콘스는 두 부분으로 이루어져 있어요. 첫 번째 요소, 그리고 나머지 요소예요.
역사적인 이유로 이 두 부분에는 `car`와 `cdr`라는 이름이 붙었어요.
이 콘스가 코드로 평가될 때, 첫 번째 요소(`car`)는 호출되는 함수를 나타내고 나머지 요소(`cdr`)는 그 함수의 인자를 나타내요:

```lisp
(<function> <arg1> <arg2> ... <argN>)
; ^ car ^  |        ^ cdr ^
```

## 표현식

Common Lisp 코드는 모두 S-표현식(Symbolic Expression)으로 이루어져 있어요. 줄여서 sexpr라고 불러요. 모든 sexpr은 원자 아니면 콘스예요. S-표현식이 평가되면 어떤 값이 자동으로 반환되고, 그 값이 표현식을 대신해요. 직접 함수를 작성할 때(`defun`을 사용해서)는 `defun` 본문의 마지막 값이 자동으로 반환돼요:

```lisp
;; Defining a new function
(defun gimme-foo () 'foo)
;; Calling the function as an S-Expression
(gimme-foo) ; => FOO
```

## 심볼

Common Lisp에서 심볼은 다른 값을 가리킬 수도 있고, _키워드_의 경우에는 자기 자신을 가리키는 특별한 값이에요.
심볼이 Lisp에 의해 평가되면, 심볼이 가리키는 값으로 바뀌어요:

```lisp
foo  ; => <whatever-foo-points-to>
:foo ; => :FOO
```

키워드는 앞에 콜론(`:`)을 붙여 나타낸다는 점에 주의해요.

인용, 즉 S-표현식 앞에 `'`를 붙이는 것은 Lisp에게 그 표현식을 평가하지 말라고 알려주는 거예요.
`defun` 예제에서 `'foo`를 인용했기 때문에, Lisp이 `FOO`가 가리키는 것을 찾으려고 시도하고 (찾지 못하고) 실패하는 일을 피하고, 대신 `FOO`라는 값 자체를 반환했어요.
우리 프로그램 어디에서도 `FOO`가 정의되지 않았다면:

```lisp
foo  ; => <ERROR! Lisp doesn't know what foo points to!>
'foo ; => FOO
```

지금은 함수에서 심볼을 반환하는 방법 정도로만 여겨도 괜찮아요. 하지만 인용은 나중에 다시 다루고, 앞으로의 개념 연습 문제에서 그 의미를 더 자세히 살펴볼 거예요.
