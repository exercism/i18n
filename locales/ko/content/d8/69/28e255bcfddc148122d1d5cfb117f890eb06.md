# 지시 사항

뉴질랜드에서 트래킹을 하며 나침반으로 방위를 재고 있어요. 방위는 정수 각도이고, 하나의 값이에요. 20도만큼 돌려도 잰 방위가 바뀌지는 않아요. 그저 다른 방위가 나올 뿐이에요.

`immutable class BEARING`을 작성해요. 스텁에는 클래스 헤더와 속성이 들어 있어요.

## 1. 방위 재기

`create`는 각도를 받아 방위를 반환해요. 각도는 0부터 359까지이고, 그 범위를 벗어나면 다시 돌아와요. 370은 10이 되고, -10은 350이 돼요.

```sather
#BEARING(370).degrees
-- => 10
#BEARING(-10).degrees
-- => 350
```

## 2. 돌리기

`turned`는 돌릴 각도를 받아 새로운 방위를 반환해요. 음수를 넘기면 반대 방향으로 돌아가요. 호출한 방위는 바뀌지 않아요.

```sather
#BEARING(350).turned(20).degrees
-- => 10
```

## 3. 비교하기

`is_eq`는 다른 방위를 받아 두 방위가 같은지 반환해요. 이게 있으면 방위에 `=`를 쓸 수 있어요.

```sather
#BEARING(10) = #BEARING(370)
-- => true
```

## 4. 방위점 이름 짓기

`point`는 그 방위와 가장 가까운 방위점을 `"N"`, `"NE"`, `"E"`, `"SE"`, `"S"`, `"SW"`, `"W"`, `"NW"` 중 하나로 반환해요.

각 방위점은 정확한 방위를 중심으로 45도를 차지해요. 북쪽은 337.5부터 0을 지나 22.5까지이고, 북동쪽은 22.5부터 67.5까지이며, 이런 식이에요. 여기서 방위는 정수이므로, 방위 22는 `"N"`이고 23은 `"NE"`예요.

```sather
#BEARING(0).point
-- => "N"
#BEARING(90).point
-- => "E"
#BEARING(225).point
-- => "SW"
```

## 5. 적어 두기

`str`은 각도와 방위점을 `"90 degrees (E)"`처럼 반환해요.

```sather
#BEARING(90).str
-- => "90 degrees (E)"
```
