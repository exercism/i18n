# 안내

이 연습 문제에서는 서로 다른 유형의 전투원들이 맞붙는 롤플레잉 게임을 해요.
게임은 전투원 유형마다 규칙이 달라요.
여기서는 두 가지 유형, 즉 마법사와 전사에 집중해 볼 거예요.

전사의 규칙은 다음과 같아요.

- 전사는 절대 취약하지 않아요.
- 전사는 공격 대상이 취약하지 않다면 `6`의 피해를 입혀요.
- 전사는 공격 대상이 취약하다면 `10`의 피해를 입혀요.

마법사의 규칙은 다음과 같아요.

- 마법사는 미리 주문을 준비할 수 있어요.
- 마법사는 미리 주문을 준비하지 않았다면 취약해요.
- 마법사는 미리 주문을 준비했다면 `12`의 피해를 입혀요.
- 마법사는 미리 주문을 준비하지 않았다면 `3`의 피해를 입혀요.

## 1. Warrior 클래스 만들기

`Warrior`라는 새 클래스를 만들어요.
이 클래스는 기존의 `Fighter` 클래스를 상속받아야 해요.

## 2. Warrior 설명하기

`Warrior` 클래스가 `toString()` 메서드에서 어떤 종류의 전투원인지 설명하도록 수정해요.
이 메서드는 문자열 `"Fighter is a Warrior"`를 반환해야 해요.

```java
Warrior warrior = new Warrior();
warrior.toString();
// => "Fighter is a Warrior"
```

## 3. Warrior를 취약하지 않게 만들기

`Warrior` 클래스의 `isVulnerable()` 메서드가 항상 `false`를 반환하도록 수정해요.

```java
Warrior warrior = new Warrior();
warrior.isVulnerable();
// => false
```

## 4. Warrior의 피해량 계산하기

`Warrior` 클래스의 `getDamagePoints(Fighter)` 메서드가 위 규칙에 따라 Warrior가 입히는 피해를 계산하도록 수정해요.

```java
Warrior warrior = new Warrior();
Wizard wizard = new Wizard();

warrior.getDamagePoints(wizard);
// => 10
```

## 5. Wizard 클래스 만들기

`Wizard`라는 또 다른 새 클래스를 만들어요.
이 클래스도 기존의 `Fighter` 클래스를 상속받아야 해요.

## 6. Wizard 설명하기

`Wizard` 클래스가 `toString()` 메서드에서 어떤 종류의 전투원인지 설명하도록 수정해요.
이 메서드는 문자열 `"Fighter is a Wizard"`를 반환해야 해요.

```java
Wizard wizard = new Wizard();
wizard.toString();
// => "Fighter is a Wizard"
```

## 7. Wizard가 주문을 준비할 수 있게 하고, 주문을 준비하지 않았을 때 취약하게 만들기

`Wizard` 클래스에 `prepareSpell()`이라는 메서드를 추가해요.
이 클래스는 이 메서드가 호출된 시점을 기억하고, 주문을 준비했을 때에만 `isVulnerable()` 메서드가 `false`를 반환하도록 해야 해요.

```java
Wizard wizard = new Wizard();
wizard.prepareSpell();
wizard.isVulnerable();
// => false
```

## 8. Wizard의 피해량 계산하기

`Wizard` 클래스의 `getDamagePoints(Fighter)` 메서드가 위 규칙에 따라 Wizard가 입히는 피해를 계산하도록 수정해요.

```java
Wizard wizard = new Wizard();
Warrior warrior = new Warrior();

wizard.prepareSpell();
wizard.getDamagePoints(warrior);
// => 12
```
