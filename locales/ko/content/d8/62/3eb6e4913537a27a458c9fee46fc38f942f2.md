# 힌트

## 일반

- x86-64에서 메모리 주소는 64비트(8바이트) 숫자예요.
- 메모리에서 유효한 상대 주소를 만들려면 `rel`을 사용해야 해요.

## 1. 색상의 RGB 값 가져오기

- x86-64에서 메모리 주소는 64비트(8바이트) 숫자예요.
- 메모리에서 유효한 상대 주소를 만들려면 `rel`을 사용해야 해요.
- 메모리 주소에 저장된 내용에 접근하려면 `[]`를 사용해 역참조해야 해요.
- 32비트(4바이트) 정수는 `eax`에 반환돼요.

## 2. 기본 색상 더하기

- x86-64에서 메모리 주소는 64비트(8바이트) 숫자예요.
- 메모리에서 유효한 상대 주소를 만들려면 `rel`을 사용해야 해요.
- 초기화된 변수는 _section .data_에 정의해요.
- 변수를 다른 소스 파일에서도 볼 수 있게 하려면 `global`로 선언해야 해요.
- 이미 구현된 `get_color_value` 함수를 재사용할 수 있어요.

## 3. 원색에 대한 상수 정의하기

- x86-64에서 메모리 주소는 64비트(8바이트) 숫자예요.
- 메모리에서 유효한 상대 주소를 만들려면 `rel`을 사용해야 해요.
- 초기화된 상수는 _section .rodata_에 정의해요.
- 상수를 다른 소스 파일에서도 볼 수 있게 하려면 `global`로 선언해야 해요.

## 4. 색상 조합하기

- x86-64에서 메모리 주소는 64비트(8바이트) 숫자예요.
- 메모리에서 유효한 상대 주소를 만들려면 `rel`을 사용해야 해요.
- 메모리 주소에 저장된 내용에 접근하려면 `[]`를 사용해 역참조해야 해요.
- 외부 함수나 데이터는 해당 섹션에서 `extern`으로 선언해야 해요.
- 외부 함수는 사용 중인 일반 레지스터를 수정할 수 있으므로, 호출하기 전에 변수를 메모리에 저장해야 해요.
- `combining_function`은 `rdi`에 기본 색상의 32비트 값(주소가 아님)을, `rsi`에 보조 색상의 32비트 값(주소가 아님)을 받아요.
