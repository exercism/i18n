# 지시 사항

일본인 친구 쿠로코는 전 세계적으로 인기 있는 스트리머예요.
쿠로코의 방송 일정은 꽤 복잡한데, 방송마다 시작 시간이 매일 다른 것처럼 보여요.

쿠로코는 시청자의 현지 시간대에 맞춰 자신의 일정을 보여 줄 작은 앱, 쿠로코의 시계를 만드는 일을 도와달라고 해요.
추가로 원하는 조건이 하나 더 있어요. 바로 일본어와 미국식 영어, 두 가지 언어로 시간을 표시할 수 있어야 한다는 거예요.

## 1. 날짜예요

`showLocalDate : Locale -> Int -> Month -> Int -> String` 함수를 정의해요. 이 함수는 (유효한) 현지 날짜를 표시해요.

`US` 로케일에서는 형식이 `Month/Day/Year`이고, 앞에 0을 붙이지 않아요.

`JP` 로케일에서는 형식이 `Year年Month月Day日`이고, 이때도 앞에 0을 붙이지 않아요.

```elm
showLocalDate US 2025 May 1
    -- "5/1/2025"
showLocalDate JP 2025 May 1
    -- "2025年5月1日"
```

## 2. 시간을 보여줄 차례예요

`showLocalTime : Locale -> Int -> Int -> String` 함수를 정의해요. 이 함수는 (유효한) 현지 시간을 표시해요.

`US` 로케일에서는 시를 12시간 표기로 "PM" 또는 "AM"과 함께 보여 주고, 분은 앞에 0을 붙여서 보여 줘요.

`JP` 로케일에서는 시를 24시간 표기로 "時" 앞에 보여 주고, 분은 앞에 0을 붙이지 않고 "分" 앞에 보여 줘요.

```elm
showLocalTime US 13 8
    -- "1:08 PM"
showLocalTime JP 13 8
    -- "13時8分"
```

## 3. 시간대에 들어가 봐요

`showDateTime : Locale -> Zone -> Posix -> String` 함수를 정의해요. 이 함수는 특정 로케일에서 시간대를 기준으로 날짜와 시간을 표시해요.

`showLocalDate`와 `showLocalTime`을 사용해서 최종 결과를 표시해요.

```elm
showDateTime US Time.utc (Time.millisToPosix 0)
    -- "1/1/1970 12:00 AM"
showDateTime JP Time.utc (Time.millisToPosix 0)
    -- "1970年1月1日0時0分"
```
