# 안내 추가

## 잠깐, 이건 불가능해요!

Roc에서는 내장 함수를 _하나도_ 쓰지 않고 이런 배열 연산을 구현하는 건 사실상 불가능해요. 배열에 원소를 뒤에 붙이거나 앞에 추가할 방법이 필요하기 때문이죠.
다른 언어에서는 Haskell의 `:`나 Python의 `+=` 같은 연산자를 쓸 수 있지만, Roc에서는 [`List` 함수](https://www.roc-lang.org/builtins/main/#Builtin.List)를 사용해야 해요.

그래서 이 연습 문제에서는 `List.append`를 사용해도 돼요. 다른 내장 함수는 사용하지 마세요.

많은 함수형 프로그래밍 언어는 연결 리스트를 기본 컬렉션 타입으로 사용해요.
연결 리스트에서는 원소를 앞에 추가하거나 첫 번째 원소를 꺼내는 게 효율적이라, 그런 언어에서는 `List.prepend`로 이런 연산을 구현하곤 하죠.
하지만 Roc에서 `List`는 배열이에요 (연속된 바이트 덩어리죠).
배열은 연결 리스트와 성질이 달라요. 예를 들어 인덱스로 원소에 빠르게 접근하거나 새 원소를 뒤에 추가할 수 있죠.
그래서 Roc에서는 `List.append`를 자주 쓰고 `List.prepend`는 거의 쓰지 않아요.

## 이름

Roc에서는 일반 안내에 나오는 것과 이름이 조금 달라요:

- `append` 대신 `concat`
- `concatenate` 대신 `join`
- `length` 대신 `len`
- `foldl` 대신 `fold`
- `foldr` 대신 `fold_rev`

하지만 다음 함수 이름은 Roc에서 표준이에요:
- `filter`
- `map`
- `reverse`

## 힌트

이런 식으로 해봐요:

```roc
match list {
    [] => ...
    [first, .. as rest] => ...
}
```

또는

```roc
match list {
    [] => ...
    [.. as rest, last] => ...
}
```
