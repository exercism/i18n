# 지침

이 연습 문제에서는 국제 전화 코드 해시맵을 사용해 국제 전화 코드를 관리하는 코드를 작성해요.

이 맵은 키에는 정수(전화 코드)를, 값에는 문자열(국가 이름)을 사용해요.

전화 코드를 다루는 과제가 11개 있어요.

## 1. 미리 채워진 해시맵 만들기

다음 3개의 전화 코드를 담고 있는 미리 채워진 해시맵이 있어요: 코드가 1인 "United States of America", 코드가 55인 "Brazil", 코드가 91인 "India". 미리 채워진 해시맵을 저장할 `countries` 변수를 정의해요:

```clojure
countries
;;=> {1 "United States of America", 55 "Brazil", 91 "India"}
```

## 2. 맵에 국가 추가하기

1번 과제에서 만든 맵에 전화 코드가 44인 "United Kingdom"을 추가해요:

```clojure
(add-country countries 44 "United Kingdom")
;;=> {1 "United States of America", 44 "United Kingdom", 55 "Brazil", 91 "India"}
```

## 3. 국가 코드에 해당하는 국가 이름 가져오기

전화 코드가 55인 국가의 이름을 가져와요

```clojure
(country-name countries 55)
;;=> "Brazil"
```

## 4. 국가 이름 업데이트하기

"United States of America"의 이름을 "Les États-Unis"로 바꿔요:

```clojure
(update-map countries 1 "Les États-Unis")
;;=> {1 "Les États-Unis", 55 "Brazil", 91 "India"}
```

## 5. 맵에 국가가 있는지 확인하기

1번 과제에서 만든 맵에 Brazil에 대한 기록이 있는지 확인해요

```clojure
(code-exists? countries 55)
;;=> true
```

## 6. 맵에 없는 국가의 이름을 업데이트해 보기

맵에 없는 코드, 예를 들어 999를 가진 국가의 이름을 바꾸려고 해봐요. 맵은 아무것도 바뀌지 않아야 해요:

```clojure
(update-map countries 999, "Newlands")
;;=> {1 "United States of America", 44 "United Kingdom", 55 "Brazil", 91 "India"}
```

## 7. 맵에서 국가 삭제하기

맵에서 India를 삭제해요:

```clojure
(remove-country countries 91)
;;=> {1 "United States of America", 55 "Brazil"}
```

## 8. 이름이 가장 긴 국가 찾기

맵의 값들을 처리해서 이름이 가장 긴 값을 찾아요:

```clojure
(longest-name countries)
;;=> "United States of America"
```
