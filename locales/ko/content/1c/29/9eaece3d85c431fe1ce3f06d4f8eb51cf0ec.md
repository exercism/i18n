# 지침 추가

## 구현

Cairo에서는 부동소수점 수를 기본으로 지원하지 않기 때문에, 소수 값을 정수로 표현해요.

이 방식은 블록체인 개발에서 계산의 정밀도를 유지하는 데 꼭 필요해요.

이 연습 문제에서는 공전 주기를 마이크로초로 변환하여 **고정소수점 연산**을 사용해요.

예를 들어, 수성의 공전 주기인 `0.2408467` 지구년은 `1,000,000`을 곱하면 `240,846,700` 마이크로초가 돼요.

소수점 정밀도를 고려하기 위해, 테스트 케이스에서는 결과 나이가 **소수점 두 자리**를 가지며, 정수로 표현된다고 가정해요.

즉, 나이가 `31.69`년인 경우 코드에서는 `3169`로 저장돼요.

이를 위해 나눗셈을 하기 전에 100을 곱해요.

다음은 예시예요:

```rust
let mercury_orbital_period = 240_846_700; // in microseconds
let age_microseconds = age_seconds * 1_000_000;
// multiplying with 100 to retain 2 decimal places
age_microseconds * 100 / mercury_orbital_period
```

이 방법을 사용하면 필요한 소수점 두 자리 정밀도를 유지하면서 소수 값을 정확하게 정수로 표현할 수 있어요. 이는 테스트를 통과하는 데 꼭 필요해요.
