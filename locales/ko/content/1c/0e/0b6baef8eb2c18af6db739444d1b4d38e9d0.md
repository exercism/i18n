# 소개

[Nil][nil-dictionary]은 "아무것도 없음"이나 "0"을 뜻하는 영어 단어예요. Elixir에서 `nil`은 값이 _없음_을 나타내는 특별한 값이에요.

```elixir
# I do not have a favorite color
favorite_color = nil
```

`nil`은 아톰이지만, 보통 `:nil`이 아니라 `nil`로 써요. 불리언 값인 `true`와 `false`도 아톰이에요.

[//]: # (elixir-formatter-disable-next-block)

```elixir
nil === :nil
# => true

true === :true
# => true
```

변수의 값이 `nil`인지 확인하려면 [`==`][kernel-equal]를 쓰거나, 패턴 매칭을 쓰거나, [`is_nil` 가드][kernel-is-nil]를 쓰면 돼요.

```elixir
def call(phone_number) do
  if phone_number == nil do
    :error
  end
end
```

```elixir
def call(phone_number) when is_nil(phone_number) do
  :error
end
```

```elixir
def call(nil) do
  :error
end
```
