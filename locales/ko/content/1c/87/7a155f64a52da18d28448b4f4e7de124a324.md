# 지침 추가

## 보너스

이 문자열 `uüu`에 함수를 적용해 보고 어떤 일이 일어나는지 확인해 봐요.
이 문자열을 제대로 뒤집는 함수를 작성해 봐요.
힌트: 그래핌 클러스터

보너스 테스트를 실행하려면 마지막 테스트에서 ignore 플래그(`#[ignore]`)를 제거하고, 다음 명령으로 테스트를 실행해요:

```bash
cargo test --features grapheme
```

보너스 과제에는 외부 라이브러리(러스트에서는 `crate`라고 불러요)가 필요해요.
그런 라이브러리를 찾아보기 좋은 곳은 crate의 공식 저장소인 [crates.io](https://crates.io/)예요.
저희 테스트 러너가 지원하는 crate는 일부뿐이라는 점을 기억해 두세요.
전체 목록은 [이 파일](https://github.com/exercism/rust-test-runner/blob/main/local-registry/Cargo.toml)의 `[dependencies]` 섹션에 있어요.

프로젝트에서 외부 crate를 사용하는 방법은 [문서를 확인해 보세요](https://doc.rust-lang.org/cargo/guide/dependencies.html).
