# 소개

F#의 `char` 타입은 텍스트를 이루는 가장 작은 단위를 나타내는 16비트 값이며, 기본적으로 변경할 수 없어요.

`char`는 작은따옴표로 리터럴을 정의할 수 있어요:

```fsharp
let ch = 'A'
// => val ch: char = 'A'
```

문자열은 `char`의 나열이에요.

문자열에서 (0부터 시작하는) 인덱싱으로 개별 `char`를 가져올 수 있어요:

```fsharp
"Exercism"[4] //  =>  'c'
```

문자열을 반복하면 각 단계마다 `char`가 반환돼요.

다음 예제에서는 편의를 위해 고차 함수와 익명 함수를 사용해요.
이 둘은 나중에 교육 과정에서 제대로 다루지만, 지금은 문자열의 문자를 순회하는 코드를 간결하게 작성하는 방법이에요.

```fsharp
Seq.map (fun c -> c, int c) "F#"  //  =>  [('F', 70); ('#', 35)]
```

위에서 보았듯이 `char`는 `int` 값으로 변환할 수 있어요.
다른 문자 체계에서도 (*적어도 때로는*) 동작해요:

```fsharp
Seq.map (fun c -> c, int c) "東京"  //  =>  [('東', 26481); ('京', 20140)]
```

문자를 비교할 때는 내부의 Int16 값이 사용돼요:

```fsharp
'A' < 'D'  // =>  true
```

또한 `int`를 `char`로 변환할 수도 있어요:

```fsharp
char 77  // => 'M'
```

`System.Char` 라이브러리에는 대소문자 변환처럼 .NET 언어에서 기대하는 메서드가 모두 들어 있어요:

```fsharp
'a' |> System.Char.ToUpper  // =>  'A'

'Q' |> System.Char.ToLower  // =>  'q'
```
