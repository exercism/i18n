# 소개

Factor에서는 단어를 그냥 나란히 이어 쓰기만 하면 조합돼요. 어떤 순서로 쓰는지가 곧 어떻게 조합되는지를 결정해요. (프로그래머들은 이것을 *함수 합성*이라고 불러요.) 단어의 몸체도 그 자체로 단어들의 나열이에요. 각 단어는 스택에서 값을 몇 개 꺼내 쓰고, 그 결과를 스택에 올려요. 그러면 다음 단어가 앞 단어가 멈춘 지점부터 이어받아요. 그래서 이렇게 정의하면

```factor
! DOCTEST: SKIP   (cleanupname is hypothetical here — the exercise's job)
: firstletter ( name -- letter ) cleanupname first 1string ;
```

이미 그 자체로 `cleanupname`, `first`, `1string`의 합성이에요.

이 연습 문제에서는 **quotation**도 소개해요. quotation은 값을 저장하듯 담아 두었다가 나중에 실행할 수 있는 코드 조각이에요. 그 자리에서 바로 실행하는 대신에요.

## quotation

quotation은 대괄호로 감싼 코드 조각이에요. 작성한다고 해서 실행되지 않고, 값처럼 스택에 올라가 있어요.

```factor
[ 2 * ] .       ! => [ 2 * ]
```

`call`은 quotation을 실행해요.

```factor
3 [ 2 * ] call .    ! => 6
```

코드를 데이터처럼 넘겨야 할 때 quotation을 써요. 나중에 실행하기 위해서거나, quotation을 입력으로 받는 단어인 *combinator*에 넘기기 위해서예요.

## `compose`

`compose ( quot1 quot2 -- combined )`는 두 quotation을 하나로 붙여요. 쓴 순서대로 실행되도록요.

```factor
[ 2 * ] [ 1 + ] compose .    ! => [ 2 * 1 + ]
```

보통은 `:` ... `;`로 작은 단어를 정의하는 편이 `compose`보다 읽기 좋아요. 그래도 quotation을 즉석에서 만들어야 할 때는 `compose`가 유용해요. 재료가 아직 quotation이 아닐 때는 [`quotations`][quotations]의 `>quotation ( seq -- quot )`이 값과 단어 참조를 나열한 것을 실행 가능한 quotation으로 바꿔 줘요.

```factor
USING: quotations sequences ;

{ [ 1 ] [ 2 + ] [ 3 * ] } concat >quotation call .   ! => 9
```

## 하나의 quotation을 두 입력에 적용하기

`bi@ ( x y quot -- ... )`는 quotation을 `x`에 적용하고, `y`에도 다시 적용해요. 두 결과 모두 스택에 남아요.

```factor
3 4 [ 2 * ] bi@ .s
! => 6
! => 8
```

연습 문제의 `couple` 과제는 이름 두 개를 받아요. `initial`을 각각에 적용하는 자연스러운 방법이 `bi@`예요.

## 몇 가지 문자열 단어

이 연습 문제에는 작은 문자열 단어 몇 개가 필요해요. 세 가지 vocabulary에서 가져와요. [`sequences`][sequences], [`ascii`][ascii], [`strings`][strings]예요.

- `replace ( seq old new -- new-seq )` (`splitting`에 있어요). 부분 문자열을 바꿔요.
- `[ blank? ] trim` (`trim`은 `sequences`에, `blank?`는 `ascii`에 있어요). 앞뒤 공백을 없애요.
- `1string ( char -- str )` (`strings`에 있어요). 문자 하나를 문자열로 감싸요.
- `>upper ( str -- upper )` (`ascii`에 있어요). 문자열을 대문자로 바꿔요.
- `append ( s1 s2 -- s )` (`sequences`에 있어요). 두 문자열을 이어 붙여요.
- `prepend ( s1 s2 -- s )` (`sequences`에 있어요). `s2`를 먼저, 그다음 `s1`을 이어 붙여요 (`append`에서 입력 순서만 바꾼 거예요).
- `glue ( s1 s2 sep -- s )` (`sequences`에 있어요). 두 문자열 사이에 구분자를 두고 이어 붙여요.
- `surround ( seq pre post -- new )` (`sequences`에 있어요). 문자열을 접두사와 접미사로 감싸요.

유니코드 문자는 문자열 안에 `\u{XXXX}` 형태로 쓸 수 있어요. 여기서 `XXXX`는 16진수 코드포인트예요. 이 연습 문제에는 하트 `\u{2764}` (❤)가 나와요.

## 형식화된 출력

`append`/`glue`/`surround`만으로는 표현이 충분하지 않을 때는 [`formatting`][formatting]에 있는 printf 스타일 `sprintf`를 쓰면 돼요.

```
sprintf ( inputs... format-string -- str )
```

`%s`는 문자열을, `%d`는 정수를, `%f`는 실수를 끼워 넣어요. 너비나 정밀도, 패딩 같은 선택적 지정자는 `%`와 타입 문자 사이에 넣어요.

```factor
USING: formatting ;

"Alice" "Bob" "%s & %s" sprintf .   ! => "Alice & Bob"
3.14159 "%.2f" sprintf .             ! => "3.14"
42 "%05d" sprintf .                  ! => "00042"
```

숫자와 문자열 사이를 오갈 때는 [`math.parser`][math.parser]의 `number>string`과 `string>number`를 써요.

```factor
USING: math.parser ;

42 number>string .       ! => "42"
"3.14" string>number .   ! => 3.14
```
