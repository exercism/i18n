# 지침

지난 7일 동안 정원에 몇 마리의 새가 찾아왔는지 기록하는 열렬한 새 관찰자예요.

정원을 찾아온 새의 수를 다루는 다섯 가지 과제가 있어요.

## 1. 지난주 기록 확인하기

새 개수는 JSON 형식으로 저장해요.
"main" 배열은 주별 기록들의 배열을 담고 있어요.
각 주별 기록은 일곱 개의 정수로 이루어진 배열이고, 요일마다 숫자가 하나씩 들어 있어요.
새로운 주는 항상 main 배열의 끝에 추가해요.
지난주 기록을 반환하는 필터를 구현해요.

```sh
$ cat bird-counting-data.json
[
  ...,
  [0, 2, 5, 3, 7, 8, 4],
  [4, 5, 9, 10, 9, 4, 3]
]

$ jq -f bird-count.jq < bird-counting-data.json
{
  "last_week": [0, 2, 5, 3, 7, 8, 4],
  ...
```

## 2. 어제 몇 마리의 새가 찾아왔는지 확인하기

어제 정원에 몇 마리의 새가 찾아왔는지 반환하는 필터를 구현해요.
새 개수는 날짜 순으로 정렬되어 있어요. 첫 번째 원소는 가장 오래된 날의 개수이고, 마지막 원소는 오늘의 개수예요.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "yesterday": 4,
  ...
```

## 3. 찾아온 새의 총 마릿수 계산하기

이번 주에 정원을 찾아온 새의 총 마릿수를 반환하는 필터를 구현해요.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "total": 44,
  ...
```

## 4. 바쁜 날의 수 계산하기

어떤 날은 다른 날보다 더 바빠요.
바쁜 날이란 정원에 다섯 마리 이상의 새가 찾아온 날이에요.
이번 주의 바쁜 날 수를 반환하는 필터를 구현해요.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "busy_days": 4,
  ...
```

## 5. 새가 한 마리도 찾아오지 않은 날이 있었는지 확인하기

이번 주에 정원에 새가 한 마리도 찾아오지 않은 날이 있으면 `true`를 반환하고, 그렇지 않으면 `false`를 반환하는 필터를 구현해요.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "has_day_without_birds": false
}
```
