# 소개

**재귀 함수**는 자기 자신을 호출하는 함수예요.

_재귀 함수_에는 _기저 사례_가 최소한 하나, _재귀 사례_가 최소한 하나 있어야 해요.

**기저 사례**는 함수를 다시 호출하지 않고 값을 반환해요.
**재귀 사례**는 입력을 바꿔서 함수를 다시 호출해요. 그래야 언젠가는 기저 사례에 도달하게 돼요.

다음은 배열의 원소 개수를 세는 예제예요.

```jq
def count:
  if length == 0 then
    0                       # base case
  else
    1 + (.[1:] | count)     # recursive case
  end;

([] | count),           # => 0
([11, 22, 33] | count)  # => 3
```

_재귀 함수_에는 _기저 사례_가 여러 개 있거나 _재귀 사례_가 여러 개 있을 수 있어요.
예를 들어 [피보나치 수열][wiki-fibonacci]은 _기저 사례_가 두 개인 재귀 수열이에요.

```jq
def fibonacci:
  if . == 0 then
    0
  elif . == 1 then
    1
  else
    (. - 1 | fibonacci) + (. - 2 | fibonacci)
  end;

10 | fibonacci          # => 55
```

배열에서 주어진 값 `x`가 몇 번 나오는지 세는 함수에는 _재귀 사례_가 두 개 있어요.

```jq
def count_occurrences(x):
  if length == 0 then
    0
  elif first == x then
    1 + (.[1:] | count_occurrences(x))
  else
    (.[1:] | count_occurrences(x))
  end;

[11, 22, 33, 22, 44] | count_occurrences(22)    # => 2
```

실제로는 배열이나 다른 열거 가능한 데이터 구조를 순회할 때 `map`이나 `reduce` 같은 내장 함수를 쓰는 경우가 가장 많아요.
아니면 `[.[] | select(...)]`처럼 [스트림을 사용][map-implementation]하기도 해요.
내부적으로는 일부 내장 함수가 [재귀를 이용해 구현][walk-implementation]되어 있어요.
