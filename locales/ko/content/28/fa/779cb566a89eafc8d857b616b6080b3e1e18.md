# 소개

Ruby에서 **배열**은 순서가 있고 정수로 인덱싱되는, 모든 객체를 담을 수 있는 컬렉션이에요.
배열의 인덱스는 `0`부터 시작해요.
음수 인덱스는 배열의 끝을 기준으로 세는 것으로 간주해요. 즉, 인덱스 `-1`은 배열의 마지막 원소를 가리키고, `-2`는 배열의 끝에서 두 번째 원소를 가리키는 식이에요.
Ruby 배열은 [Enumerable 모듈][enumerable-module]을 포함하는데, 이 모듈은 여러 순회 및 검색 메서드와 정렬 기능을 더해줘요.

## 배열 만들기

- Ruby의 배열에는 서로 다른 타입의 객체를 담을 수 있어요.

```ruby
array = [1, "two", 3.0] #=> [1, "two", 3.0]
```

## 원소 대입

인덱스를 사용해 원소에 접근하거나 원소를 바꿀 수 있어요.
시작 인덱스와 개수를 지정하면 부분 배열에 접근할 수 있어요.

```ruby
a = ["", "", "", "", ""]

a[4] = "hello"  #=> [nil, nil, nil, nil, "hello"]
a[0, 3] = [ 'a', 'b', 'c' ] #=> ["a", "b", "c", nil, "hello"]
```

- 음수 인덱스는 배열의 끝에서부터 거꾸로 세요.

```ruby
a = ['a', 'b']

a[-1] = "Z"
a #=> ["a", "Z"]
```

## 원소 참조

- 배열의 원소는 #[] 메서드로 가져올 수 있어요.
- 이 메서드는 해당 인덱스의 원소를 반환하거나, 시작 인덱스에서 시작해 length개의 원소로 이어지는 부분 배열을 반환해요.

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[2]    #=> "c"
a[6]    #=> nil
a[1, 2] #=> [ "b", "c" ]
```

- 음수 인덱스는 배열의 끝에서부터 거꾸로 세요 (-1은 마지막 원소예요)

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[-2]    #=> "d"
a[-3, 3] #=> [ "c", "d", "e" ]
```

## 배열에 대한 정보 얻기

배열은 항상 자신의 길이를 추적해요.
배열에 담긴 원소의 개수를 알고 싶다면 length, count, size를 사용해요.

```ruby
browsers = ['Chrome', 'Firefox', 'Safari', 'Opera', 'IE']
browsers.length #=> 5
browsers.count  #=> 5
browsers.size   #=> 5
```

## 배열에 항목 추가하기

`push`나 `<<`를 사용해 배열의 끝에 항목을 추가할 수 있어요.

```ruby
arr = [1, 2, 3, 4]
arr.push(5) #=> [1, 2, 3, 4, 5]
arr << 6    #=> [1, 2, 3, 4, 5, 6]
```

## 배열에서 항목 제거하기

pop 메서드는 배열의 마지막 원소를 제거하고 그 원소를 반환해요.

```ruby
arr = [1, 2, 3, 4, 5, 6]
arr.pop #=> 6
arr     #=> [1, 2, 3, 4, 5]
```
