# 안내 추가

## 예외 메시지

때로는 [예외를 발생시켜야][raising-exceptions] 할 때도 있어요.
이때는 오류의 원인이 무엇인지 알려 주는 **의미 있는 오류 메시지**를 항상 포함해야 해요.
그러면 코드를 더 읽기 쉽게 만들고 디버깅에도 큰 도움이 돼요.
오류 원인이 특정 타입이라고 확실히 아는 상황이라면 [내장 오류 타입][error-base-classes] 중 하나를 골라 발생시켜도 되지만, 그래도 의미 있는 메시지는 꼭 포함해야 해요.


`Tic Tac Toe`의 올바른 게임은 한 플레이어가 이기면 끝나요.
두 플레이어가 모두 승리 상태에 있다면, 이 연습 문제는 [raise 문][raise]을 사용해 풀이에서 `ValueError`를 "던지는" 것을 기대해요.
한 플레이어가 연속으로 두 번 수를 두는 것으로 판정되거나, 두 번째 수를 두도록 배정받았는데 첫 번째 수를 두는 경우에도 코드는 `ValueError`를 던져야 해요.


메시지를 담아 `ValueError`를 발생시키려면, 메시지를 `exception` 타입의 인자로 작성해요:

```python
# Example when player O goes before player X.
raise ValueError("Wrong turn order: O started")

# Example when player X goes twice.
raise ValueError("Wrong turn order: X went twice")

# Example when player X wins AND player O wins.
raise ValueError("Impossible board: game should have ended after the game was won")
```

테스트는 오류 메시지가 정확히 일치하는지 확인하므로, 기대하는 결과를 주의 깊게 읽어 봐요.

[error-base-classes]: https://docs.python.org/3/library/exceptions.html#base-classes
[raise]: https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement
