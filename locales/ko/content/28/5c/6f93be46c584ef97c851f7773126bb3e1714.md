# 힌트

## 일반

- [using 문][using-statement] 문서에서는 `using` 키워드를 언제, 어떻게 사용하는지 설명해요.

## 1. 데이터베이스에 쓰기

- 데이터베이스에 있는 여러 메서드와, 각 메서드를 사용할 때 데이터베이스가 어떤 상태로 바뀌는지 살펴봐요.

## 2. 데이터베이스에 쓰고, 쓰기 작업이 성공했는지 호출자에게 알려 주기

- 이 경우에는 [`exceptions`][try-catch]를 사용해야 해요.
