# 디버깅

많은 언어와 달리 WebAssembly 코드는 콘솔 같은 전역 리소스에 자동으로 접근할 수 없어요. 이런 기능은 대신 임포트로 제공해야 해요.

`console.log` 같은 기능과 몇 가지 편의 기능을 제공하기 위해, Exercism WebAssembly 트랙은 모든 연습 문제에 걸쳐 함수로 이루어진 표준 라이브러리를 제공해요.

이 함수들은 WebAssembly 모듈 맨 위에서 임포트해야 하고, 그런 다음 WebAssembly 코드 안에서 호출할 수 있어요.

`log_mem_*` 함수들은 WebAssembly 모듈의 선형 메모리에 접근할 수 있어야 해요. 기본적으로 이 메모리는 비공개 상태이므로, 접근할 수 있게 하려면 선형 메모리를 내보내기 이름 `mem`으로 내보내야 해요. 방법은 다음과 같아요:

```wasm
(memory (export "mem") 1)
```

# 지역 변수와 전역 변수 로깅

WebAssembly의 각 기본 타입마다 로깅 함수를 제공해요. 이는 전역 변수와 지역 변수를 로깅할 때 유용해요.

## log_i32_s - 32비트 부호 있는 정수를 콘솔에 로깅

```wasm
(module
  (import "console" "log_i32_s" (func $log_i32_s (param i32)))
  (func $main
    ;; logs -1
    (call $log_i32_s (i32.const -1))
  )
)
```

## log_i32_u - 32비트 부호 없는 정수를 콘솔에 로깅

```wasm
(module

  (func $main

```

# 선형 메모리에서 로깅

WebAssembly 선형 메모리는 바이트 단위로 주소를 지정할 수 있는 값의 배열이에요. WebAssembly 프로그램에서 가상 메모리와 같은 역할을 해요

선형 메모리 안의 주소 범위를 특정 타입의 정적 배열로 해석해 주는 로깅 함수를 제공해요. JavaScript의 TypedArray와 비슷하게 동작해요. length 매개변수는 바이트 단위가 아니에요. 해당 함수와 연결된 타입의 연속된 원소 개수로 측정해요.

**이 함수들이 동작하려면, WebAssembly 모듈에서 선형 메모리를 선언하고 이름 있는 내보내기 "mem"으로 내보내야 해요**

```wasm
(memory (export "mem") 1)
```

## log_mem_as_utf8 - UTF8 문자의 시퀀스를 콘솔에 로깅

```wasm
(module
  (import "console" "log_mem_as_utf8" (func $log_mem_as_utf8 (param $byteOffset i32) (param $length i32)))
  (memory (export "mem") 1)
  (data (i32.const 64) "Goodbye, Mars!")
  (func $main
    ;; Logs "Goodbye, Mars!" to console
    (call $log_mem_as_utf8 (i32.const 64) (i32.const 14))
  )
)
```

## log_mem_as_i8 - 부호 있는 8비트 정수 시퀀스를 콘솔에 로깅

```wasm
(module
  (import "console" "log_mem_as_i8" (func $log_mem_as_i8 (param $byteOffset i32) (param $length i32)))
  (memory (export "mem") 1)
  (func $main
    (memory.fill (i32.const 128) (i32.const -42) (i32.const 10))
    ;; Logs an array of 10x -42 to console
    (call $log_mem_as_u8 (i32.const 128) (i32.const 10))
  )
)
```
