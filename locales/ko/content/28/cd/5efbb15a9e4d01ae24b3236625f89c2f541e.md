# 지침

이 연습 문제에서는 좋아하는 요리책에 나오는 근사한 라자냐를 만들 수 있도록 코드를 작성해 볼 거예요.

라자냐를 만드는 데 걸리는 시간과 관련된 네 가지 과제가 있어요.

## 1. 예상 조리 시간을 상수에 저장하기

`expected_bake_time` 상수를 정의해요. 이 상수는 라자냐를 오븐에서 몇 분 동안 구워야 하는지를 나타내요.

요리책에 따르면, 라자냐는 총 60분 동안 오븐에 있어야 해요.

```julia-repl
julia> expected_bake_time
60
```

## 2. 준비 시간을 분 단위로 계산하기

`preparation_time` 함수를 정의해요. 이 함수는 라자냐에 넣은 층의 개수를 인자로 받고, 각 층을 준비하는 데 2분이 걸린다고 가정했을 때 라자냐를 준비하는 데 몇 분이 걸렸는지를 반환해요.

```julia-repl
julia> preparation_time(4)
8
```

## 3. 남은 오븐 조리 시간을 분 단위로 계산하기

`remaining_time` 함수를 정의해요. 이 함수는 라자냐가 지금까지 오븐에 있던 실제 시간(분)을 매개변수로 받고, 라자냐가 오븐에 앞으로 몇 분 더 있어야 하는지를 반환해요.

```julia-repl
julia> remaining_time(50)
10
```

## 4. 총 작업 시간을 분 단위로 계산하기

`total_working_time` 함수를 정의해요. 이 함수는 두 개의 인자를 받는데, 첫 번째 인자는 라자냐에 넣은 층의 개수이고, 두 번째 인자는 라자냐가 오븐에 있던 시간(분)이에요.

이 함수는 라자냐 요리에 총 몇 분을 들였는지를 반환해야 해요. 이는 준비 시간(분)과 현재까지 라자냐가 오븐에 있던 시간(분)을 더한 값이에요.

```julia-repl
julia> total_working_time(3, 20)
26
```
