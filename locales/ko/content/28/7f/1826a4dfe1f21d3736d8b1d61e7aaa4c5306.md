# 개요

Kotlin에서 불리언은 `Boolean` 타입으로 표현해요. 값은 `true` 또는 `false` 중 하나예요.

Kotlin은 세 가지 내장 [불리언 연산자][reference]를 지원해요: `!`(부정, 즉 NOT), `&&`(지연 논리곱, 즉 AND), `||`(지연 논리합, 즉 OR)예요. `&&`와 `||` 연산자는 _단축 평가_를 사용해요. 즉, 연산자의 오른쪽은 필요할 때만 평가돼요.

```kotlin
true || false // => true
true && false // => false
```

세 불리언 연산자는 각각 [_연산자 우선순위_][precedence]가 달라요. 그 결과 `!`가 먼저, `&&`가 그다음, `||`가 마지막으로 평가돼요. 이 규칙에서 '벗어나고' 싶다면 불리언 표현식을 괄호(`()`)로 감싸면 돼요. 괄호는 연산자 우선순위가 훨씬 더 높기 때문이에요.

```kotlin
!true && false   // => false
!(true && false) // => true
```

[reference]: https://kotlinlang.org/docs/reference/basic-types.html#booleans
[precedence]: https://kotlinlang.org/docs/reference/grammar.html#expressions
