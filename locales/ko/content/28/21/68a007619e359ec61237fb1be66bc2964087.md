# 지침 추가

## 예외 메시지

때로는 [예외를 발생시켜야](https://docs.python.org/3/tutorial/errors.html#raising-exceptions) 할 때가 있어요. 이렇게 할 때는 오류의 원인이 무엇인지 알려 주는 **의미 있는 오류 메시지**를 항상 포함해야 해요. 그러면 코드가 더 읽기 쉬워지고 디버깅에 큰 도움이 돼요. 오류 원인이 특정 타입이라는 것을 아는 상황이라면 [내장 오류 타입](https://docs.python.org/3/library/exceptions.html#base-classes) 중 하나를 발생시켜도 되지만, 그때도 의미 있는 메시지를 포함해야 해요.

이 연습 문제에서는 `matrix`가 불규칙할 때 `ValueError`를 "던지기" 위해 [raise 문](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)을 사용해야 해요. 테스트를 통과하려면 `raise`로 `exception`을 발생시키고 메시지도 함께 포함해야 해요.

메시지와 함께 `ValueError`를 발생시키려면, 메시지를 `exception` 타입의 인자로 써 주세요:

```python
# if the matrix is irregular
raise ValueError("irregular matrix")
```
