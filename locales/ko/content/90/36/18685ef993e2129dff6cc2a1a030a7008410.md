# 소개

## 기본

### 변수

Elixir는 동적 타입 언어예요. 변수의 타입은 런타임에만 검사해요. 매치 `=` 연산자를 사용하면 어떤 타입의 값이든 변수 이름에 바인딩할 수 있어요.

```elixir
# Bound an integer value of 1
count = 1
# You may re-bind variables
count = 2

# You may re-bind any type to a variable
count = false

# Strings can be created by enclosing characters within double quotes
message = "Success!"
```

### 모듈

Elixir는 [함수형 프로그래밍 언어][functional-programming]이고, 모든 이름 있는 함수를 _모듈_ 안에 정의해야 해요. 모듈은 `defmodule` 키워드로 정의해요. 모든 모듈은 런타임에 다른 모든 모듈에서 사용할 수 있고, 프로그램의 다른 부분에서 보이게 하려고 _접근 제어자_를 붙일 필요가 없어요. _모듈_은 다른 프로그래밍 언어의 _클래스_와 비슷해요.

```elixir
defmodule Calculator do
  # ...
end
```

### 이름 있는 함수

_이름 있는 함수_는 모듈 안에 정의해야 해요. _공개_ 이름 있는 함수는 `def` 키워드로 정의해요.

각 함수는 인자가 하나도 없을 수도 있고, 여러 개일 수도 있어요. 함수의 마지막 표현식 값은 항상 _암묵적으로 반환_돼요.

```elixir
defmodule Calculator do
  def add(x, y) do
    x + y
  end
end
```

함수를 호출할 때는 모듈과 함수 이름을 쓰고, 각 인자에 넘길 값을 전달해요.

```elixir
sum = Calculator.add(1, 2)
# => 3
```

`def` 대신 `defp` 키워드를 써서 _비공개_ 함수를 정의할 수 있어요. 비공개 함수는 정의한 같은 모듈 안에서만 사용할 수 있어요.

정의된 모듈 안에서 함수를 호출할 때는 모듈 이름을 생략할 수 있어요.

짧은 함수는 한 줄 문법으로 쓸 수도 있어요 (`do` 키워드 앞뒤의 쉼표 `,`와 콜론 `:`에 주목해 봐요).

```elixir
defmodule Calculator do
  def subtract(x, y) do
    private_subtract(x, y)
  end

  defp private_subtract(x, y), do: x - y
end

difference = Calculator.subtract(7, 2)
# => 5

difference = Calculator.private_subtract(7, 2)
# => ** (UndefinedFunctionError) function Calculator.private_subtract/2 is undefined or private
#       Calculator.private_subtract(7, 2)
```

### 함수의 인자 개수

함수를 말할 때 _인자 개수_로 부르는 경우가 많아요. 함수의 _인자 개수_는 그 함수가 받는 인자의 수예요.

```elixir
# add/3 because this function has three arguments, thus an arity of 3
def add(x, y, z) do
  x + y + z
end
```

### 명명 규칙

모듈 이름은 `PascalCase`를 사용해요. 모듈 이름은 대문자 `A-Z`로 시작해야 하고, 문자 `a-zA-Z`, 숫자 `0-9`, 밑줄 `_`을 포함할 수 있어요.

변수와 함수 이름은 `snake_case`를 사용해요. 변수나 함수 이름은 소문자 `a-z`나 밑줄 `_`로 시작해야 하고, 문자 `a-zA-Z`, 숫자 `0-9`, 밑줄 `_`을 포함할 수 있으며, 물음표 `?`나 느낌표 `!`로 끝날 수도 있어요.

### 표준 라이브러리

Elixir에는 아주 풍부하고 문서화가 잘 된 표준 라이브러리가 있어요. 문서는 [hexdocs.pm/elixir][docs]에서 온라인으로 볼 수 있어요. 이 링크는 어딘가에 저장해 두면 좋아요. 정말 자주 쓰게 될 거예요!

대부분의 내장 데이터 타입에는 그 타입을 다루는 함수를 제공하는 대응 모듈이 있어요. 예를 들어 정수에는 `Integer` 모듈, 문자열에는 `String` 모듈, 배열에는 `List` 모듈 등이 있어요.

눈여겨볼 만한 모듈로 `Kernel` 모듈이 있어요. 산술 연산자, 제어 흐름 매크로 등 표준 라이브러리의 나머지가 그 위에 세워지는 기본 기능을 제공해요. `Kernel` 모듈의 함수는 자동으로 임포트되므로, `Kernel.` 접두사 없이 사용할 수 있어요.

### 코드 주석

주석은 소스 코드를 읽는 다른 개발자에게 메모를 남기는 데 쓸 수 있어요. Elixir에서 한 줄 주석은 `#`으로 시작해요.
