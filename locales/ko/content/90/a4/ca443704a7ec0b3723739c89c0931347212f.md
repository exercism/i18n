# 주석에 관한 안내

Go에는 주석을 작성하는 방법에 관한 [훌륭한 지침](https://golang.org/doc/effective_go.html)이 있어요. 문서 주석에 사용할 수 있는 표준 형식이 있는데, 이 형식을 따르면 `godoc` 도구가 자동으로 멋진 문서를 만들어 줘요.

패키지 주석은 `Package`라는 단어로 시작하고, 그 뒤에 패키지 이름을 붙여요. 이렇게요:

```go
// Package cook provides handy conversion methods for units typically used in recipes.
package cook
```

외부에 공개된 함수, 메서드, 상수, 패키지 변수의 경우에는 주석을 이름으로 시작하고 동사구로 이어가요:

```go
// TbsToMl converts tablespoons to milliliters.
func TbsToMl(tbs int) int {
	// ...
}
```

[CodeReviewComments](https://github.com/golang/go/wiki/CodeReviewComments#comment-sentences) 위키에서는 문서 주석이 마침표로 끝나는 완전한 문장이어야 한다고 더 자세히 설명해요.

가독성을 높이는 것 외에도, 이 권장 사항을 따르면 [godoc.org](http://godoc.org), `godoc`, `go doc` 같은 [Go 문서 도구](http://whipperstacker.com/2015/09/30/go-documentation-godoc-godoc-godoc-org-and-go-doc/)에서 코드가 더 좋아 보여요.

공식 스타일 가이드인 [Effective Go](https://golang.org/doc/effective_go.html)에서 문서 주석 부분을 잠시 읽어 보면, 이런 선택의 이유를 알 수 있어요.
