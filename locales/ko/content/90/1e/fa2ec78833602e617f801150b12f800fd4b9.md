# 소개

F#에서 `array`는 길이가 고정된, 0개 이상의 값을 담는 변경 가능한 컬렉션이에요. 즉, 배열을 한 번 만들면 크기는 바꿀 수 없지만 값은 바꿀 수 있어요. 배열의 값은 모두 같은 타입이어야 해요. 배열은 다음과 같이 정의할 수 있어요:

```fsharp
let empty = [| |]
let emptyAlternative = Array.empty

let singleValue = [| 5 |]
let singleValueAlternative = Array.singleton 5

let threeValues = [| "a"; "b"; "c" |]
```

인덱스를 사용해 배열에 원소를 할당하거나 배열에서 원소를 가져올 수 있어요. F# 배열은 0부터 시작하는데, 이는 첫 번째 원소의 인덱스가 항상 0이라는 뜻이에요:

```fsharp
let numbers = [| 2; 3; 5 |]

// Update value in array
numbers[2] <- 9

// Read value from array
numbers[2]
// => 9
```

배열은 `Array` 모듈에 정의된 함수와 연산자로 다루거나, _배열_ 패턴을 사용한 패턴 매칭으로 직접 다룰 수 있어요:

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty"
    | [| 1; 2; three |] -> sprintf "1, 2, %d" three
    | _ -> "Other"

describe [| |]         // => "Empty"
describe [| 1; 2; 4 |] // => "1, 2, 4"
describe [| 5; 7; 9 |] // => "Other"
```

패턴 매칭을 할 때 값을 _버릴_ 수도 있어요. 특정 경우에 값에 관심이 _없다면_(즉, 값을 _사용_할 생각이 아니라면) 밑줄(`'_'`)을 사용해 이를 나타낼 수 있어요:

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty array"
    | [| x |] -> "Array with one item"
    | [| _; y |] -> "Array with two items (first item ignored)"
    | _ -> "Array with many items (all items ignored)"

describe [| |]          // => "Empty array"
describe [| 1 |]        // => "Array with one item"
describe [| 5; 7 |]     // => "Array with two items (first item ignored)"
describe [| 5; 7; 9 |]  // => "Array with many items (all items ignored)"
```

패턴 매칭에서는 `'_'` 하나가 항상 _마지막_에 와야 해요. 다른 어떤 경우와도 _일치하지_ 않는 값은 모두 이 경우가 처리하게 돼요.
