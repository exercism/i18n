# Instructions

ESA(Exercism Space Agency)는 화성의 위성인 [포보스][phobos]로 향하는 새 임무를 한창 계획하고 있어요.
이 임무의 목표는 탐사선을 포보스 표면에 착륙시키고 표면에 관한 데이터를 보내오는 것이에요.
ESA는 탐사선의 항법 컴퓨터를 만드는 데 도움을 요청했어요.
항법 컴퓨터는 메모리가 제한적이라 메모리 사용량을 최대한 낮게 유지해야 해요.
그래서 알맞은 자료형을 사용해야 하죠.

## 1. 항법 상수

항법 컴퓨터는 올바른 계산을 하려면 우주에 있는 여러 물체 사이의 거리를 알아야 하는데, 거리는 km 단위로 측정해요.

다음 상수를 정의해요.

- `NEPTUNE_DISTANCE`: 값은 `4_400_000_000`이고 `Int64`로 저장해야 해요.
- `MARS_DISTANCE`: 값은 `227_940_000`이고 `Int32`로 저장해야 해요.
- `ATMOSPHERE_DISTANCE`: 값은 `10_000`이고 `Int16`으로 저장해야 해요.

## 2. 올바른 면적 분석

항법 컴퓨터는 올바른 계산을 하려면 우주에 있는 여러 물체의 면적을 알아야 해요.
면적은 **절대** 음수가 될 수 없어요.
엔지니어들은 면적이 음수일 때 오버플로 오류가 발생하도록 프로그램을 계획했어요.
하지만 엔지니어들은 부호 있는 정수를 부호 없는 정수로 바꾸는 것을 잊었어요.

그래서 엔지니어들은 부호 있는 정수를 부호 없는 정수로 변환하는 프로그램을 원해요.

`measurement`를 인자로 받아 면적을 32비트 부호 없는 정수로 반환하는 `Navigation#correct_area_analysis` 메서드를 구현해요.

~~~~exercism/note
주어지는 면적은 항상 32비트 부호 없는 정수로 표현할 수 있어요.
~~~~

```crystal
measurement = 52554
measurement.class
# => Int32

Navigation.new.correct_area_analysis(measurement)
# => 52554

Navigation.new.correct_area_analysis(measurement).class
# => UInt32
```

## 3. 속도 계산하기

항법 컴퓨터는 탐사선의 속도를 알아야 해요.
속도는 m/s 단위로 측정해요.

속도를 계산하려면 이동한 거리와 그 거리를 이동하는 데 걸린 시간을 알아야 해요.
그런 다음 거리를 시간으로 나눠요.

속도는 정확하지 않아도 되고 아주 큰 수가 될 일도 없어요.
따라서 `Float32`를 사용할 수 있어요.

`distance`와 `time`을 인자로 받아 속도를 32비트 `Float`로 반환하는 `Navigation#calculate_velocity` 메서드를 구현해요.

```crystal
distance = 52554
time = 2.5

Navigation.new.calculate_velocity(distance, time)
# => 21021.6

Navigation.new.calculate_velocity(distance, time).class
# => Float32
```
