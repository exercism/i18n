# 지침

이 연습 문제의 목표는 두 가지예요:

1. "콜백 패턴"을 사용하는 함수를 `Promise`를 반환하는 함수로 바꿔 주는 `promisify` 함수를 구현해요. 아래 예제를 봐요.

```javascript
function fetchProduct(productId, function(error, data) {
    if (error) {
        // Handle the error
    } else {
        // Make something with your data
    }
})

const fetchProductAsPromise = promisify(fetchProduct);

// Now you got a function `fetchProductAsPromise`
// that returns a promise
fetchProductAsPromise(productId)
    .then((data) => {})
    .catch((error) => {});
```

2. 다음 `Promise` 내장 메서드들을 직접 사용하지 않고 다시 구현해요.

- `all`: 프로미스를 담은 배열을 받아서 _모두_ 이행되면 이행하고, _하나_ 라도 거부되면 거부해요.
- `allSettled`: 프로미스를 담은 배열을 받아서 _모두_ 이행되거나 거부되면 이행해요.
- `race`: 프로미스를 담은 배열을 받아서 _가장 먼저_ 이행되거나 거부된 프로미스의 값으로 이행하거나 거부해요.
- `any`: 프로미스를 담은 배열을 받아서 _하나_ 가 이행되면 이행하고, _모두_ 거부되면 거부해요.
