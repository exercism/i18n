# 힌트

## 1. 인간을 트로이의 세계로 데려오기

- 이 연습 문제의 핵심은 `unique_ptr`과 `shared_ptr`를 사용하는 것이에요. 각 `human` 변수에는 어떤 종류의 스마트 포인터를 써야 할까요?
- `artifacts`는 공유되지 않지만, `powers`는 영향을 받은 사람들을 추적하는 데 필요해요.
- `possession` 포인터는 유일해야 하고, power 포인터들은 공유되어야 해요.

## 2. 트로이에 유물 들여오기

- 스마트 포인터를 만들어 `possession` 변수에 할당해야 해요.
- 함수 밖의 객체를 바꾸려면 _참조_를 사용해요.
- 힌트를 얻으려면 [`std::make_unique`][make_unique]를 찾아봐요.
- 포인터가 가리키는 객체의 타입은 꺾쇠괄호 안에 넣고, 객체를 정의하기 위해 괄호 안에 다시 한 번 넣어요.
- 다음은 전체 예시예요: `variable = std::make_unique<int>(int{23});`

## 3. 아이템을 거래할 수 있게 만들기

- [unique_ptr 참조][unique_ptr]를 살펴보면 알맞은 함수를 찾을 수 있어요.

## 4. 사람들에게 힘 주기

- 스마트 포인터를 만들어 `own_power` 변수에 할당해야 해요.
- 함수 밖의 객체를 바꾸려면 _참조_를 사용해요.
- 힌트를 얻으려면 [`std::make_shared`][make_shared]를 찾아봐요.
- 포인터가 가리키는 객체의 타입은 꺾쇠괄호 안에 넣고, 객체를 정의하기 위해 괄호 안에 다시 한 번 넣어요.
- 다음은 전체 예시예요: `variable = std::make_shared<int>(int{23});`

## 5. 힘 사용하기

- 함수 밖의 객체를 바꾸려면 _참조_를 사용해요.
