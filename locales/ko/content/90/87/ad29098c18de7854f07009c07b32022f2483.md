# 소개

## 삼항 연산자

_삼항 연산자_는 단순한 _if/else_문을 위한 가볍고 간결한 대안이에요.
주로 반환문에서 쓰이지만 거기에만 제한되지는 않고, 결정을 내리는 데 딱 한 줄이면 충분해요.
표현식이 `true`면 왼쪽 값을, `false`면 오른쪽 값을 반환해요. 예를 들면 다음과 같아요:

```java
boolean expr = 0 != 200;

// Ternary statement
int value = expr ? 22 : 33;
// => 22
```

많은 단순한 _if/else_ 표현은 _삼항 연산자_를 사용해 간단하게 줄일 수 있어요.
