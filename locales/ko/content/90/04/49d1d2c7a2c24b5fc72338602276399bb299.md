# 지시 사항

이번 지시 사항에서는 여러분이 가장 좋아하는 요리책을 보면서 라자냐를 만드는 데 도움이 될 코드를 작성해 볼 거예요.

모두 요리를 만드는 것과 관련된 네 가지 과제가 있어요.

## 1. 예상 오븐 시간을 분 단위로 정의해요

라자냐를 오븐에 몇 분 동안 넣어 둬야 하는지를 `lasagna.oven_time` 테이블 필드로 정의해요. 요리책에 따르면 예상 오븐 시간은 40분이에요:

```lua
lasagna.oven_time
-- => 40
```

## 2. 남은 오븐 시간을 분 단위로 계산해요

라자냐가 실제로 오븐에 들어가 있던 시간(분)을 인자로 받아서, 이전 과제에서 구한 예상 오븐 시간을 기준으로 라자냐가 오븐에 얼마나 더 있어야 하는지를 분 단위로 반환하는 `lasagna.remaining_oven_time` 함수를 정의해요.

```lua
lasagna.remaining_oven_time(30)
-- => 10
```

## 3. 준비 시간을 분 단위로 계산해요

라자냐에 추가한 층의 개수를 인자로 받아서, 각 층을 준비하는 데 2분이 걸린다고 가정했을 때 라자냐를 준비하는 데 몇 분이 걸렸는지를 반환하는 `lasagna.preparation_time` 함수를 정의해요.

```lua
lasagna.preparation_time(2)
-- => 4
```

## 4. 지금까지 작업한 시간을 분 단위로 계산해요

`lasagna.elapsed_time` 함수를 정의해요. 이 함수는 두 개의 인자를 받는데, 첫 번째 인자는 라자냐에 추가한 층의 개수이고 두 번째 인자는 라자냐가 오븐에 들어가 있던 시간(분)이에요. 이 함수는 라자냐 요리를 하는 데 지금까지 총 몇 분을 작업했는지를 반환해야 해요. 이는 준비 시간(분)과 현재까지 라자냐가 오븐에서 보낸 시간(분)을 더한 값이에요.

```lua
lasagna.elapsed_time(3, 20)
-- => 26
```
