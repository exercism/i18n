# 소개

Python에서는 [`if`][if statement], `elif` (_'else and if'의 줄임말_), `else`문을 사용해 프로그램의 실행 흐름을 [제어][control flow tools]하고 결정을 내려요.
다른 많은 프로그래밍 언어와 달리, Python 3.9 이하 버전은 공식적인 case-switch 문을 제공하지 않고, 대신 여러 개의 `elif`문으로 비슷한 역할을 해요.

Python 3.10에서는 `pattern matching`이라는 변형된 case-switch 문을 도입했는데, 이는 다른 개념에서 따로 다뤄요.

조건문은 `True` 또는 `False`로 귀결되는 표현식을 사용해요. `bool`을 직접 반환하거나, ["truthy" 또는 "falsy"][truth value testing]로 평가하는 식이죠.


```python
x = 10
y = 5

# The comparison '>' returns the bool 'True',
# so the statement is printed.
if x > y:
    print("x is greater than y")
...
>>> x is greater than y
```

`if`와 함께 쓰이면, 선택적인 `else` 코드 블록은 원래의 `if` 조건이 `False`로 평가될 때 실행돼요:

```python
x = 5
y = 10

# The comparison '>' here returns the bool False,
# so the 'else' block is executed instead of the 'if' block.
if x > y:
    print("x is greater than y")
else:
    print("y is greater than x")
...
>>> y is greater than x
```

`elif`는 여러 번의 평가와 분기를 가능하게 해요.

```python
x = 5
y = 10
z = 20

# The elif statement allows for the checking of more conditions.
if x > y > z:
    print("x is greater than y and z")
elif y > x > z:
    print("y is greater than x and z")
else:
    print("z is greater than x and y")
...
>>> z is greater than x and y
```

[불리언 연산][boolean operations]과 [비교][comparisons]를 조건문과 결합하면 더 복잡한 검사를 할 수 있어요:

```python
>>> def classic_fizzbuzz(number):
...     if number % 3 == 0 and number % 5 == 0:
...         say = 'FizzBuzz!'
...     elif number % 5 == 0:
...         say = 'Buzz!'
...     elif number % 3 == 0:
...         say = 'Fizz!'
...     else:
...         say = str(number)
...     return say

>>> classic_fizzbuzz(15)
'FizzBuzz!'

>>> classic_fizzbuzz(13)
'13'
```
