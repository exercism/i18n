# 소개

## 클래스

C#의 대표적인 객체 지향 구성 요소는 _클래스_예요. 클래스는 데이터(_필드_)와 동작(_메서드_)을 결합한 것으로, 클래스의 필드와 메서드를 _멤버_라고 해요.

멤버에 대한 접근은 접근 제한자로 제한할 수 있는데, 가장 흔히 쓰이는 두 가지는 다음과 같아요.

- `public`: 모든 코드에서 접근할 수 있어요(제한 없음).
- `private`: 같은 클래스 안의 코드에서만 접근할 수 있어요.

클래스를 그 클래스의 인스턴스를 만들기 위한 템플릿이라고 생각하면 돼요. 클래스의 인스턴스(_객체_라고도 해요)를 만들려면 `new` 키워드를 사용해요.

```csharp
class Car
{
}

// Create two car instances
var myCar = new Car();
var yourCar = new Car();
```

필드는 타입을 가지며 클래스 어디에서든 정의할 수 있어요.
public 필드는 PascalCase로, private 필드는 camelCase로 정의하고 앞에 밑줄 `_`을 붙여요.

```csharp
class Car
{
    // Accessible by anyone
    public int Weight;

    // Only accessible by code in this class
    private string _color;
}
```

필드에는 선택적으로 초깃값을 지정할 수 있어요. 초깃값을 지정하지 _않으면_ 해당 타입의 기본값으로 설정돼요. 인스턴스의 필드 값은 점 표기법을 사용해 접근하고 갱신할 수 있어요.

```csharp
class Car
{
    // Will be set to specified value
    public int Weight = 2500;

    // Will be set to default value (0)
    public int Year;
}

var newCar = new Car();
newCar.Weight; // => 2500
newCar.Year;   // => 0

// Update value of the field
newCar.Year = 2018;
```

private 필드는 보통 메서드를 호출하는 부수 효과로 갱신돼요. 이런 메서드는 보통 아무 값도 반환하지 않는데, 이 경우 반환 타입은 `void`여야 해요.

```csharp
class CarImporter
{
    private int _carsImported;

    public void ImportCars(int numberOfCars)
    {
        // Update private field from public method
        _carsImported = _carsImported + numberOfCars;
    }
}
```
