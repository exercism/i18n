# 소개

많은 언어에는 `null`이나 `none`처럼 존재하지 않는 값을 나타내는 방법이 있어요.
R은 대용량의 (흔히 지저분한) 데이터를 다루도록 설계되었기 때문에, 여러 형태의 '없음'을 가지고 있어요.

전체적인 목표는 결측값이나 의심스러운 값을 만날 때마다 표시하고, 예외를 발생시키지 않고 계속 진행하는 거예요.

## NULL

값이 정말로 존재하지 않는 경우에는 `NULL`로 표현해요. 이는 아마도 C나 Python에서 하는 방식에 가장 가까울 거예요.

```R
v <- c() # zero-length vector
v
#> NULL
is.null(v)
#> [1] TRUE
```

많은 상황에서 `NULL` 값은 그냥 무시돼요.

```R
c(2, 3, NULL, 5)
#> [1] 2 3 5
```

## NA

값이 존재하지만 그것이 무엇인지 모르는 상황에서는 `NA`를 사용해요. 예를 들어 도로를 지나는 차량을 셀 때, 사람 관찰자가 병가를 내거나 자동 센서가 고장 날 수 있지만 교통은 계속 흘러가죠.

```R
v <- c(1, 2, NA, 4, 5)
v
#> [1]  1  2 NA 4  5
is.na(v) # test for data gaps
#> [1] FALSE FALSE  TRUE FALSE FALSE
```

따라서 `NA`는 사람에게 이 값을 어떻게 처리할지 결정해야 한다고 알려 주는 자리 표시자예요.

## 빈 벡터

의외로 R에는 비어 있는지 확인하는 표준 방법이 없어요. 다만 일부 서드파티 패키지에서는 `is.empty()` 같은 자체 함수를 구현해 놓기도 해요.

빈 벡터를 만드는 것조차 그리 명확하지는 않아요.
이전 섹션에서 인자 없이 `c()`를 호출하면 벡터가 아니라 `NULL`을 반환한다는 걸 봤어요.

```R
is.vector(c())
#> [1] FALSE
```

`logical()`이나 `integer()` 같은 함수는 원하는 길이를 지정하는 인자를 받는데, 이 길이는 0이 될 수 있어요.

```R
z <- logical(0)
is.vector(z)
#> [1] TRUE
length(z)
#> [1] 0
```

또한 [벡터 개념][concept-vectors]에서 설명한 것처럼, 벡터를 만든 다음 모든 원소를 제거할 수도 있어요.
그러면 적절한 타입의 길이 0인 벡터가 돼요.

```R
v <- 5
v[-1]  # delete the first element
#> numeric(0)
```
