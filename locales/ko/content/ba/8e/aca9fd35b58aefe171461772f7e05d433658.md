# 테스트 실행

특정 연습 문제의 테스트를 실행하려면 해당 폴더로 `cd`한 뒤 다음을 실행해요:

```bash 
box task run TestRunner
# Or start up a test watcher that will rerun when files change
box task run TestRunner --:watcher
```

테스트는 xUnit과 BDD 방식의 테스트를 지원하는 TestBox라는 라이브러리를 활용해요. 모든 테스트 스위트는 클로저로 테스트 스펙을 정의하는 [BDD 스타일](https://testbox.ortusbooks.com/content/primers/bdd/specs.html)로 작성돼요. TestBox 설치에 대해서는 걱정할 필요가 없어요. CLI 테스트 러너가 알아서 처리해 줘요. 처음 실행할 때만 인터넷에 연결되어 있으면 돼요. 자세한 내용은 여기에서 확인할 수 있어요:

[https://testbox.ortusbooks.com](https://testbox.ortusbooks.com)
