# 소개

## format - 기초

Common Lisp에는 Lisp 데이터를 텍스트로 표현하는 모든 함수를 포함하는 The Printer라는 개념이 있어요. 그런 함수 중 하나가 `format`이고, 프로그래머가 원하는 대로 데이터의 형식을 지정할 수 있게 해줘요.

`format`과 Lisp 프린터 전반의 기능은 다루는 범위가 아주 넓은 주제예요. 여기서는 `format` 사용의 기초를 설명할게요.

### format 함수

`format` 함수는 최소 두 개의 인자를 받아요. 출력할 스트림과, 무엇을 어떻게 출력할지 정의하는 제어 문자열이에요.

스트림은 그 자체로 하나의 개념이라 다른 곳에서 설명해요. 지금은 출력이 스트림으로 이루어진다는 것, 그리고 이 인자에 쓸 수 있는 두 가지 특별한 값 `t`와 `nil`이 있다는 것만 알아두면 돼요. `t`는 표준 출력(정확히는 변수 `*standard-output*`이 묶여 있는 스트림)으로 출력하라는 뜻이고, `nil`은 문자열을 만들어 반환하라는 뜻이에요.

`format`은 스트림으로 `nil`을 지정한 뒤의 경우를 빼면 항상 `nil`로 평가돼요. 이건 단순한 문자열 보간이나 문자열 생성을 하는 흔한 방법이에요.

```lisp
(format nil "hello world") ; => "hello world"
(format t "hello world")   ; => NIL (but "hello world" is printed to standard output)
```

### format 지시자

제어 문자열에는 "format 지시자"를 넣을 수 있어요. 지시자는 무엇을 출력할지, `format`에 전달된 다른 매개변수를 어떻게 해석할지에 대한 지침을 `format`에 줘요. 어떤 의미에서 제어 문자열은 `format`이 해석해서 실행하는 프로그램이에요. 모든 지시자는 `~`로 시작하고 그 뒤에 문자가 와요(_예를 들어_ `~A`, `~D`, `~&`). 문자의 대소문자는 상관없어요.

대부분의 format 지시자는 `format`이 받은 인자를 출력에 그대로 끼워 넣어요. 이걸 인자를 "소비한다"고 해요. 어떤 지시자는 인자를 소비하지 않고, 어떤 지시자는 하나보다 많이 소비해요. 심지어 인자 목록 안을 건너뛰거나 인자를 건너뛸 수 있게 해주는 지시자도 있어요.

### 기본 형식 지정

아주 범용적인 format 지시자는 `~A`예요. 데이터를 '사람이 읽을 수 있는' 형태로 출력해요.

```lisp
(format nil "Value = ~a" 10)                ; => "10"
(format nil "hello ~a" "world")             ; => "hello world"
(format nil "The list is: ~A" (list 1 2 3)) ; => "The list is: (1 2 3)"
```

또 다른 유용한 format 지시자는 `~S`예요. 데이터를 '기계가 읽을 수 있는' 형태로 출력해요. 출력된 결과를 Lisp 데이터로 다시 해석하고 싶을 때 아주 유용해요. 많은 경우 `~A`와 똑같아 보이지만, 예를 들어 문자열의 경우 출력에 따옴표가 포함된다는 점에 주목해요(다른 문자열 안에 들어가면 이스케이프돼요). 그래야 그 값을 문자열 매개변수로 다시 읽어들일 수 있어요.

```lisp
(format nil "~s" 10)            ; => "10"
(format nil "~s" "hello world") ; => "\"hello world\""
(format nil "~s" (list 1 2 3))  ; => "(1 2 3)"
```

아주 유용한 지시자가 두 개 더 있어요. `~%`와 `~&`예요. 앞의 것은 줄 바꿈 문자를 출력하고, 뒤의 것은 "새 줄"을 출력해요. 차이는 `~%`는 항상 줄 바꿈을 출력하는 반면, `~&`는 현재 줄의 맨 앞이 아닐 때만 하나를 출력한다는 거예요. 둘 다 인자를 소비하지 않아요.

```lisp
(format nil "~%new~%lines") ; => "
                                  new
                                  lines"

(format nil "~&new~&lines"  ; => "new
                                  lines"
```

마지막으로 `~~`는 리터럴 `~`를 출력하는 단순한 지시자예요.
