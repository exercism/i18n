# 설치

Exercism을 사용하면 브라우저에서 바로 ABAP 코드를 작성하고 테스트할 수 있어요. 추가로 설치할 것은 없어요. 하지만 직접 자신의 시스템에서 코드를 작성하고 테스트하고 싶다면 ABAP 트라이얼 시스템을 구할 수 있어요.

물론, 회사에서 SAP를 운영하고 있을 수도 있어요. ABAP 개발 샌드박스에 접근할 수 있는지, 있다면 어떻게 접근할 수 있는지 IT 부서에 문의해 보세요.

## 어떤 버전을 선택할까요?

현재 지원 중인 최신 ABAP 플랫폼 릴리스를 사용하는 것을 권장해요. 현재 기준으로는 **ABAP 7.5 이상**이에요. 최신 릴리스와 지원 일정에 대한 자세한 내용은 [SAP Developer Center](hhttps://developers.sap.com/tutorials/mission-get-started-with-abap-development-on-premise)에서 확인할 수 있어요.

## 무엇을 설치할까요?

가장 최근의 [ABAP Cloud Developer Trial](https://hub.docker.com/r/sapse/abap-cloud-developer-trial)을 사용하는 것을 권장해요. ABAP 7.58을 기반으로 해요. SAP ABAP 시스템을 Docker 이미지로 설치하거나 SAP Cloud Appliance Library에서 호스팅할 수 있어요. 또한 로컬 운영 체제에 따라 Windows용 또는 Java용 SAP GUI를 설치해야 해요. SAP GUI는 [여기](https://www.sap.com/products/try-sap/trials-downloads.html?search=sap+gui)에서 내려받을 수 있어요.

자세한 내용은 [SAP Community](https://community.sap.com/t5/technology-blog-posts-by-sap/abap-cloud-developer-trial-2023-available-now/ba-p/14057183) 블로그를 참고해요.
