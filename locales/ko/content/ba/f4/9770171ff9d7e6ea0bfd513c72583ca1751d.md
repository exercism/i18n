# 힌트

## 1. 직원의 배지 출력하기

- [문자열 보간][string-interpolation]을 사용하면 배지를 간결하게 만들 수 있어요.
- [문자열을 대문자로 바꾸는 내장 메서드][toupper]가 있어요.

## 2. 신입 직원의 배지 출력하기

- ID를 사용하기 전에 `null`인지 확인해야 해요.
- [이 튜토리얼에서는 null 허용 값 형식을 다루는 방법을 자세히 설명해요][nullable-types-tutorial].

## 3. 사장의 배지 출력하기

- 부서를 사용하기 전에 `null`인지 확인해야 해요.
- [이 튜토리얼에서는 null 허용 참조 형식을 다루는 방법을 자세히 설명해요][nullable-reference-types-tutorial].
- [null 조건부 연산자][null-conditional-operator]를 사용하면 null 허용 값의 멤버를 더 간단하게 호출할 수 있어요.
- [null 병합 연산자][null-coalescing-operator]를 사용하면 null 허용 값이 `null`일 때 다른 값을 더 간단하게 반환할 수 있어요.
