# 지침

여러분은 학교 공연에서 큐를 부르는 역할을 맡았어요. 무대 감독은 누구나 데스크를 운영할 수 있도록 표준 대사를 적어 두고 싶어 해요.

`STAGE_DIRECTIONS` 클래스에서 해야 할 과제가 네 가지 있어요.

## 1. 시작을 알리기

공연을 여는 대사를 반환해요.

```sather
STAGE_DIRECTIONS::opening_line
-- => "The curtain rises."
```

## 2. 막간을 알리기

중간 휴식에 부르는 대사를 반환해요.

```sather
STAGE_DIRECTIONS::interval_line
-- => "Interval. Fifteen minutes."
```

## 3. 끝을 알리기

공연을 닫는 대사를 반환해요.

```sather
STAGE_DIRECTIONS::closing_line
-- => "The curtain falls."
```

## 4. 마지막 큐 부르기

마지막 큐는 공연을 닫는 대사와 같은 대사예요. 텍스트를 두 번 다시 쓰는 대신, 이미 작성한 루틴을 호출해요.

```sather
STAGE_DIRECTIONS::final_cue
-- => "The curtain falls."
```
