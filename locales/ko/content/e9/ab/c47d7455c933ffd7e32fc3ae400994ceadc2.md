# 참고 자료

## 레퍼런스

- [RISC-V 레퍼런스 카드][reference-card]에는 명령어와 의사 명령어, 레지스터가 정리되어 있어요.
- [RISC-V 호출 규약][psabi]은 어떤 레지스터가 함수의 입력과 결과를 담는지, 그리고 함수가 반드시 보존해야 하는 레지스터는 무엇인지 설명해요.
- [RISC-V 명세서][isa-manual]는 모든 명령어가 정확히 무엇을 하는지 설명해요.
- [GNU 어셈블러 매뉴얼][gas-directives]은 `.section`, `.string`, `.word`, `.global` 같은 지시자를 설명해요.

## 도구

- [Compiler Explorer][godbolt]는 C 코드 한 조각을 컴파일러가 어떤 어셈블리로 만드는지 보여줘요.
  링크를 열면 32비트 RISC-V 컴파일러가 설정되어 있어서, 직접 작성한 풀이를 컴파일러가 작성한 코드와 비교해 볼 수 있어요.

## 커뮤니티

- [RISC-V International][riscv-org]은 RISC-V 표준을 관리하는 조직이에요.
- [r/RISCV][reddit]는 RISC-V 칩과 보드, 소프트웨어에 관한 소식을 공유하는 Reddit 커뮤니티예요.
- [Stack Overflow][stack-overflow]에는 RISC-V 어셈블리에 관한 질문과 답변이 있어요.
