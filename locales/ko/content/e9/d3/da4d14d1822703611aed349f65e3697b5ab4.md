# 소개

함수 인자의 기본 내용은 [함수 개념][function concept]을 참고해요.

## 매개변수 이름

[매개변수 이름][parameters]은 변수 이름처럼 문자나 밑줄로 시작해야 하고, 문자, 밑줄, 숫자를 포함할 수 있어요.
매개변수 이름에는 공백이나 구두점이 들어가면 안 돼요.


## 위치 인자

위치 인자는 함수에 전달되는 값으로, 값을 묶어 받는 매개변수와 같은 순서로 전달돼요.
원한다면 매개변수 이름을 사용해 전달할 수도 있어요:


```python
def concat(greeting, name):
    return f"{greeting}{name}"
 
# Passing data to the function by position.
print(concat("Hello, ", "Judy"))
#->  Hello, Judy

# Passing data to the function using the parameter name.
print(concat(name="Sally", greeting="Hello, "))
#-> Hello, Sally
```

concat을 처음 호출할 때는 인자를 위치로 전달해요.
concat을 두 번째로 호출할 때는 인자를 _이름_으로 전달해서, 인자의 위치를 바꿀 수 있어요.

위치 인자는 이름으로 전달한 인자 뒤에 올 수 없다는 점에 유의해요. (_이름으로 전달한 인자를 [키워드 인자][keyword-arguments]라고도 해요. 가변 위치 매개변수나 [**kwargs][kwargs]**과 혼동하면 **안** 돼요._)

다음과 같은 인자 조합은:

```python
>>> print(concat(greeting="Hello, ", "Zed"))
```

이런 오류를 발생시켜요:

```
SyntaxError: positional argument follows keyword argument
```

## 기본 인자 값

매개변수 목록에서 하나 이상의 인자에 대한 [기본값][default arguments]을 지정할 수 있어요.
이렇게 하면 필요할 때 인자를 _더 적게_ 사용해 함수를 호출할 수 있어요.
기본값 대신 새로운 인자를 사용해 함수를 호출하면 기본값을 덮어쓸 수 있어요:


```python
# Note the default arguments for both greeting and name.
def concat(greeting="Hello, ", name="you"):
    return f"{greeting}{name}"
 
# Function call overriding the defaults
print(concat(name="Jerry", greeting="Hello, "))
#-> Hello, Jerry

# Function call without arguments resulting in the defaults being used.
print(concat())
#-> Hello, you
```

## 키워드 인자

키워드 인자는 함수에 인자를 전달할 때 매개변수 이름을 사용해요.
원한다면 위치로 전달할 수도 있어요:


```python
# Note the default arguments for both greeting and name.
def concat(greeting="Hello, ", name="you"):
    return f"{greeting}{name}"

# Function call using parameter names as argument keywords.
print(concat(name="Jerry", greeting="Hello, "))
#-> Hello, Jerry

# Function call with positional data as arguments.
print(concat("Hello, ", "Isaac"))
#-> Hello, Isaac
```
