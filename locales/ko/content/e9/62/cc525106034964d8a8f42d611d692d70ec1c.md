# Ceylon 테스트 실행하기

테스트를 실행하기 전에, 코드를 [`ceylon compile`](https://ceylon-lang.org/documentation/current/reference/tool/ceylon/subcommands/ceylon-compile.html)로 컴파일해야 해요.

테스트는 [`ceylon test`](https://ceylon-lang.org/documentation/reference/tool/ceylon/subcommands/ceylon-test.html) 명령으로 실행해요.

`ceylon test`는 테스트를 실행할 모듈 이름을 필요로 해요.
Ceylon 트랙에서는 각 연습 문제에 단일 모듈만 있어요.

따라서 다음 명령으로 테스트를 실행할 수 있어요:

```bash
ceylon compile && ceylon test $(basename source/*)
```
