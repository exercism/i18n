# 지침

화물선에서 일하는 무선 전신 기사예요. 신호는 잡음이 많은 회선을 타고 들어와요. 배의 기계 소리, 날씨 때문에 생기는 잡음, 이따금 섞여 들어오는 외국어 교신이, 실제로 듣고 있는 모스 신호와 뒤섞여 있죠. 메시지를 잡아내려면 회선을 *테이프* 장치에 통과시켜요. 이 장치는 유효한 모스 기호(`.`, `-`, 그리고 글자 사이를 구분하는 공백)를 빼고 모든 것을 걸러내요.

할 일은 테이프를 사용자 정의 Factor 입력 스트림으로 만드는 거예요.

## 1. 테이프 정의하기

`disposable`을 확장하고, 기반 입력 스트림을 담을 `wire` 슬롯 하나를 가지는 `tape` 튜플을 정의해요.

```factor
TUPLE: tape < disposable wire ;
```

그다음 생성자 `<tape> ( wire -- tape )`를 작성해요. 소멸자 프레임워크가 테이프를 등록하도록 `new`가 아니라 `new-disposable`을 사용하고, 기반 스트림을 `wire` 슬롯에 저장해요.

## 2. input-stream 믹스인 연결하기

`tape`가 `input-stream`임을 선언해요:

```factor
INSTANCE: tape input-stream
```

그러면 프로토콜의 기본 컴비네이터가 해당 클래스로 디스패치돼요.

## 3. 모스 기호 하나 읽기

`M: tape stream-read1 ( tape -- elt/f )`를 구현해요. 기반 스트림에서 `CHAR: .`, `CHAR: -`, `CHAR: \s`(공백) 중 하나를 만날 때까지 바이트를 읽어요. 그 바이트를 반환해요. 스트림이 `f`(스트림 끝)를 반환하면 `f`도 반환해요. 테이프는 거기서 끝이에요.

```factor
"x.y -ab cz" <string-reader> <tape>
[ stream-read1 ] [ stream-read1 ] [ stream-read1 ] tri
! => CHAR: . CHAR: - CHAR: \s
```

## 4. 원소 타입 위임하기

`M: tape stream-element-type ( tape -- type )`를 구현하면서 기반 스트림에 위임해요. 테이프는 읽는 원소의 종류를 바꾸지 않아요.

## 5. 정리하기

`M: tape dispose* ( tape -- )`를 구현해요. 프레임워크는 `dispose`마다 이 메서드를 정확히 한 번 호출해요. 기반 스트림에 dispose를 호출하기만 하면 돼요.

이 다섯 조각이 자리를 잡으면 테이프는 일반 입력 스트림처럼 동작해요. `with-input-stream`, `stream-read`, 그리고 다른 프로토콜 워드가 모두 해당 메서드로 자동으로 디스패치돼요.
