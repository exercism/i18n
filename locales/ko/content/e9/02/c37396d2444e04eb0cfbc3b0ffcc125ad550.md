# 힌트

## 1. `Usd`, `Eur`, `Jpy` 타입 정의하기

- `Usd`, `Eur`, `Jpy` 타입은 `pub type TypeName` 문법을 사용하면 생성자 없이 정의할 수 있어요.

## 2. `Money` 타입 정의하기

- `Money` 타입은 통화를 위한 팬텀 타입 매개변수를 가져야 해요.

## 3. `dollar`, `euro`, `yen` 함수 정의하기

- `dollar`, `euro`, `yen` 함수의 반환 타입 주석은 `Money(currency)`여야 해요. 여기서 `currency`는 `Money` 타입의 적절한 타입 매개변수예요.

## 4. `total` 함수 정의하기

- `total` 함수의 반환 타입 주석은 인자와 같은 타입 매개변수를 사용해야 해요.
