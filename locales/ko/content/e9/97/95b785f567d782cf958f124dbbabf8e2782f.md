# 테스트

제공된 테스트를 실행하려면 Minitest gem이 필요해요. 터미널 창을 열고 다음 명령어를 실행해 minitest를 설치해요:

```
gem install minitest
```


연습 문제 디렉터리에서 다음 명령어로 테스트를 실행해요:

```
ruby <snake-case-exercise>_test.rb
```

`<snake-case-exercise>` 부분을 snake_case 형식의 연습 문제 이름으로 바꿔 주세요.

## 색상 출력

`require 'minitest/pride'`를 사용하거나, 다음 명령어를 실행하면 색이 있는 출력을 볼 수 있어요:

```
ruby -r minitest/pride <snake-case-exercise>_test.rb
```
