# 개요

- [바이너리][binary] 타입은 [비트스트링][bitstring] 타입의 특수한 형태예요.
- 바이너리는 [바이트][wiki-byte]로 이루어져 있어요.
  - 바이트 하나는 8개의 [비트][wiki-bit]예요.
  - 바이트는 `0`부터 `255`까지의 숫자를 나타낼 수 있어요.
  - 바이트를 다룰 때는 [16진수][wiki-hexadecimal] 정숫값을 흔히 사용해요: `0x00`부터 `0xFF`까지예요.
- 바이너리 리터럴은 [`<<>>` 특수 형식][special-form]으로 정의해요.
  - 바이트에 `255`보다 큰 정수를 사용하면, [`::`][type-operator] 연산자로 [사용할 단위와 크기를 지정][bin-size]하지 않는 한 마지막 8비트만 사용해요.
- [`<>/2`][bin-concat]는 비트스트링, 바이너리, 문자열을 이어 붙일 때 쓸 수 있어요.

```elixir
<<255>> == <<0xFF>>
# Overflowing bits are truncated
<<256>> == <<0>>
<<256::size(16)>> == <<1, 0>>

<<"Hello">> == <<72, 101, 108, 108, 111>>
```

_널 바이트_는 `<<0>>`의 또 다른 이름이에요.

## 문자열은 인코딩된 바이너리 데이터예요

- 문자열은 [UTF-8][wiki-utf8] 형식으로 인코딩된 바이너리 데이터예요.
  - 8비트(1바이트) 단위로 인코딩되며, 255개가 넘는 문자를 나타낼 때는 최대 4바이트를 사용해요.
  - [문자열의 길이][string-length]는 [바이트 크기][byte-size]와 같지 않을 수 있어요.

```elixir
# This string has a string length of 5, but is made up of 7 bytes
string = "cześć"
String.length(string) != byte_size(string)

# Even emoji strings are encoded binaries
"👍" == <<240, 159, 145, 141>>
```

## 바이너리 데이터의 패턴 매칭

- 바이너리는 [전체를 패턴 매칭하거나, 특수 형식을 사용해 일부분만][special-form] 매칭할 수 있어요.
  - 패턴 매칭에서 크기가 변할 수 있는 부분은 마지막 부분뿐이에요.

```elixir
# Ignore the first 8 bytes, bind the remaining variable sized binary to `body`
<<_::binary-size(8), body::binary>>
```

문자열에도 똑같이 적용할 수 있어요:

```elixir
# bind the first 5 bytes to `name`,
# match the string literal " the ",
# bind remaining bytes to `species`
<<name::binary-size(5), " the ", species::binary>> = <<"Frank the Walrus">>
{name, species}
# => {"Frank", "Walrus"}
```
