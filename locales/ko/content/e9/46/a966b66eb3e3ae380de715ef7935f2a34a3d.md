# 자세히 알아보기

기본적인 `try .. rescue` 개념은 `else`와 `after` 절을 지원하도록 확장할 수 있어요.

- `else` 블록:
  - try 블록에서 성공한 결과에 대해 패턴 매칭이 일어나는 곳이에요.
- `after` 블록:
  - 프로그램이 실행 중이라면 try 블록이 성공하든 rescue되든 상관없이 함수가 호출되는 곳이에요.
  - `after` 블록의 결과는 호출한 스코프로 반환되지 않아요.

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```
