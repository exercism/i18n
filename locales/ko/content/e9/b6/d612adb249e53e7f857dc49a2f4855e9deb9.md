# 스레드

이 연습 문제는 스레드를 도입해서, 동시 작업에서 은행 계좌가 얼마나 견고한지 시험해 봐요. Tcl 스레드에 관한 읽을거리도 있어요:

* [Tcl 스레딩 모델](https://www.tcl.tk/doc/howto/thread_model.html)
* [Tcl로 제대로 쓰는 스레드…](https://www.activestate.com/blog/threads-done-right-tcl/)
* [멀티스레드 Tcl 스크립트](http://www.beedub.com/book/4th/Threads.pdf),
  _Practical Programming in Tcl and Tk, 4th Ed._의 한 챕터,
copyright 2003 © Brent Welch, Ken Jones
[http://www.beedub.com/book/](http://www.beedub.com/book/)
    * 참고로, 이 챕터에는 "Most binary distributions of Tcl are not thread-enabled"라고 나와 있어요. 이제는 그렇지 않아요. Tcl 배포판은 이제 스레드 지원과 함께 빌드돼요 (참고 [TIP 364](https://core.tcl-lang.org/tips/doc/trunk/tip/364.md))
* Tcl 문서의 [Thread 패키지 명령어](https://tcl.tk/man/tcl8.6/ThreadCmd/contents.htm).

## 설치

일부 Tcl 배포판에는 Tcl의 Thread 패키지가 기본으로 포함되어 있지 않아요. 따로 설치해야 할 수도 있어요.
다음 명령으로 확인해 봐요.
```bash
$ echo 'package require Thread' | tclsh
```
여기서 _아무 출력도_ 나오지 않으면 Thread 패키지가 이미 설치되어 있는 거예요.

필요하면 `apt install tcl-thread`(또는 `dnf install tcl-thread`)를 실행해요.
