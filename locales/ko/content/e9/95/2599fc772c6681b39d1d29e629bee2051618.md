# 소개

Factor가 재사용할 수 있는 변환을 만드는 방법은 클로저예요. 클로저는 자신이 만들어진 환경의 값을 기억하는 쿼테이션이고요. 간단한 경우는 `curry`와 `compose`로 처리하고, 나머지는 fry 쿼테이션이 처리해요.

```factor
3 [ + ] curry .      ! [ 3 + ]
[ 1 + ] [ 2 * ] compose .   ! [ 1 + 2 * ]
2 3 '[ _ _ + + ] .   ! [ 2 3 + + ]
```

| tool      | shape                                | when to reach for it           |
|-----------|--------------------------------------|--------------------------------|
| `curry`   | `value quot -- newquot`              | 값 하나를 캡처할 때            |
| `2curry`  | `v1 v2 quot -- newquot`              | 값 두 개를 모두 앞쪽에 둘 때   |
| `compose` | `quot1 quot2 -- combined`            | 두 쿼테이션을 차례로 이어 붙일 때 |
| `'[ _ ]`  | `… -- newquot`                       | 안쪽 어디에서든 여러 값을 캡처할 때 |

fry는 컴파일 시점에 코드를 다시 써 주는 방식이에요. `'[ _ + ]`는 `[ + ]`에 대한 `curry` 호출로 펼쳐져요. 세부적인 처리는 컴파일러가 알아서 해 주니, 캡처한 값이 들어갈 자리에 밑줄만 써 주면 돼요.
