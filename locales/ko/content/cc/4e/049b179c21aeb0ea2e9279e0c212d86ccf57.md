# 안내

이 연습 문제에서는 예금 계좌를 다뤄요.
매년 예금 계좌의 잔액은 이자율에 따라 갱신돼요.
은행이 제공하는 이자율은 계좌에 있는 금액, 즉 잔액에 따라 달라져요:

- 잔액이 음수일 때 3.213% (잔액이 더 음수가 돼요).
- 잔액이 `1000` 달러 미만의 양수일 때 0.5%.
- 잔액이 `1000` 달러 이상 `5000` 달러 미만의 양수일 때 1.621%.
- 잔액이 `5000` 달러 이상의 양수일 때 2.475%.

네 가지 작업이 있고, 각 작업은 잔액과 이자율을 다뤄요.

## 1. 이자율 계산하기

잔액을 인자로 받는 `SavingsAccount.interest_rate()` 메서드를 구현해요.
이 메서드는 주어진 잔액에 대한 이자율을 반환해야 해요.

```Crystal
SavingsAccount.interest_rate(200.75)
# => 0.5
```

## 2. 이자 계산하기

잔액을 인자로 받는 `SavingsAccount.interest()` 메서드를 구현해요.
이 메서드는 주어진 잔액에 대한 이자를 반환해야 해요.

```Crystal
SavingsAccount.interest(200.75)
# => 1.00375
```

## 3. 연간 잔액 갱신 계산하기

잔액을 인자로 받는 `SavingsAccount.annual_balance_update()` 메서드를 구현해요.
이 메서드는 1년 후의 잔액을 반환해야 해요.

```Crystal
SavingsAccount.annual_balance_update(200.75)
# => 201.75375
```

## 4. 목표 잔액에 도달하기까지 걸리는 연수 계산하기

잔액과 목표 잔액을 인자로 받는 `SavingsAccount.years_before_desired_balance()` 메서드를 구현해요.
이 메서드는 목표 잔액에 도달하는 데 걸리는 연수를 반환해야 해요.

```Crystal
balance = 200.75
target_balance = 214.88
SavingsAccount.years_before_desired_balance(balance, target_balance)
# => 14
```

~~~~exercism/note
원금 잔액에 단리를 적용할 때는 잔액에 이자율을 곱하고, 그 곱이 이자 금액이 돼요.

반면 복리는 이자를 주기적으로 적용하는 방식으로 계산해요.
적용할 때마다 이자 금액을 계산해 원금 잔액에 더하고, 이후 이자 계산은 더 커진 원금 잔액을 대상으로 이루어져요.
~~~~
