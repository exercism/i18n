# 암스트롱 수의 개념

> [암스트롱 수](https://en.wikipedia.org/wiki/Narcissistic_number)는 각 자릿수를 자릿수의 개수만큼 거듭제곱한 뒤 모두 더한 값이 자기 자신과 같은 수예요.

## 예제 풀이

```rust
pub fn is_armstrong_number(num: u32) -> bool {
    let digits = format!("{}", num);
    digits
        .chars()
        .map(|c| c.to_digit(10).unwrap().pow(digits.len() as u32))
        .sum::<u32>()
    == num
}
```

## 개념

- 함수: 풀이를 검증하고 로직을 정의하는 데 꼭 필요해요
- 테스트 스위트: 풀이를 검증하는 데 필요해요
- 정수: 인자와 동일성 단언에 u32를 사용해요
- `&str`: Rust는 타입을 엄격하게 다루기 때문에 수의 길이를 세는 데 필요해요
- `Option<T>`: `char::to_digit`의 실제 값에 접근하는 데 필요해요
- 타입 캐스팅: 산술 연산을 적용하려면 필요해요
- 이터레이터 기능:
  - 단일 표현식 풀이를 가능하게 하는 터보피시
  - `map`과 `sum`으로 표현식을 검증에 필요한 값으로 간편하게 줄일 수 있어요
