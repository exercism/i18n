# 지시사항

최근에 산 무선 조종 자동차가 완전히 새로운 취미가 되었어요. 무선 조종 자동차 경주를 열고 있었죠.

경주 시뮬레이션을 돌릴 수 있는 프로그램을 거의 다 작성했을 때, 고양이가 키보드 위로 뛰어올라 코드 몇 줄을 지워 버렸어요. 이제 프로그램이 더 이상 컴파일되지 않아요...

## 1. 컴파일 오류 `Race.__struct__/0 is undefined` 해결하기

모듈 `NeedForSpeed.Race`를 더 짧은 이름 `Race`로 참조할 수 있도록 별칭을 추가해요.

## 2. 컴파일 오류 `Car.__struct__/0 is undefined` 해결하기

모듈 `NeedForSpeed.RemoteControlCar`를 더 짧은 이름 `Car`로 참조할 수 있도록 별칭을 추가해요.

## 3. 컴파일 오류 `undefined function puts/1` 해결하기

`puts/1` 함수는 `IO` 모듈에 있어요. 모듈을 참조하지 않고도 사용할 수 있도록 임포트해요.

## 4. 컴파일 오류 `undefined function default_color/0` 해결하기

함수 `default_color/0`, `red/0`, `cyan/0`, `green/0`은 모두 `IO.ANSI` 모듈에 있어요. 다른 자동차 색상도 지원할 계획이라서 모듈 전체를 임포트하려고 해요. 그런데 안타깝게도 `IO.ANSI` 모듈의 `color/1` 함수가 직접 정의한 로컬 함수 하나와 충돌해요. 그 함수 하나만 제외하고 `IO.ANSI` 모듈 전체를 임포트해요.
