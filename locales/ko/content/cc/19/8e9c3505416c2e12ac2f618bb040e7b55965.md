# 지침

이번 연습 문제에서는 약속을 관리하기 위한 몇 가지 함수를 다뤄요.
이 시스템은 모든 것을 ISO 8601 형식의 문자열로 저장하지만, 사람들이 달력을 사용하는 방식과는 달라요.
여러 형식 사이를 변환하려면 다양한 함수가 필요해요.

## 1. 약속 만들기

지금으로부터 `n`일 뒤의 현재 시각에 약속을 만들어요.
이 함수는 `n`일을 받아서 지금으로부터 `n`일 뒤의 약속 시각을 반환해요.

```javascript
createAppointment(4, now);
// Given now is Sun Oct 05 2022 23:28:43 GMT+0600 (Bangladesh Standard Time)
// => Sun Oct 09 2022 23:28:43 GMT+0600 (Bangladesh Standard Time)
```

두 번째 매개변수 `now`를 사용하지 않으면, 대신 현재 시각을 사용해야 해요.

## 2. 날짜를 타임스탬프로 변환하기

여러 도구는 국제 표준인 ISO 8601 형식에서만 동작해요.
`getAppointmentTimestamp` 함수를 작성해서 날짜를 받아 그 형식의 문자열을 반환하게 해요.

```javascript
const appointment = new Date(Date.UTC(2010, 6, 16, 12, 42, 0, 0));

getAppointmentTimestamp(appointment);
// => '2010-07-16T12:42:00.000Z'
```

## 3. 약속의 세부 정보 가져오기

타임스탬프는 읽기 어려워요. 약속의 세부 정보를 가져오는 함수가 도움이 될 거예요.
`getAppointmentDetails` 함수는 ISO 8601 형식의 타임스탬프를 받아서 연도, 월, 일, 시, 분을 반환해요.

```javascript
getAppointmentDetails('2022-04-24T08:15:00.000');
// => { year: 2022, month: 3, date: 24, hour: 8, minute: 15 }
```

## 4. 주어진 옵션으로 약속 업데이트하기

이 함수는 첫 번째 인자로 약속 시각을, 두 번째 인자로 몇 가지 옵션을 담은 객체를 받아요.
객체의 옵션에 따라 약속을 업데이트하고, 새로운 약속 날짜를 반환해야 해요.
옵션 객체에는 여러 옵션이 있을 수 있어요.

```javascript
updateAppointment('2022-02-09T09:20:00.000', { month: 6 });
// => { year: 2022, month: 6, date: 9, hour: 10, minute: 20 }
```

## 5. 두 약속 사이의 사용 가능한 시간 구하기

이 함수는 두 약속(타임스탬프)을 인자로 받아요.
두 시각의 차이를 초 단위로 반환해야 해요.

0.5초는 거의 의미가 없으므로, 반환하기 전에 숫자를 반올림해요.

```javascript
timeBetween('2022-12-12T09:20:00.000', '2022-12-18T08:30:00.000');
// => 515400
```

## 6. 약속이 지금 유효한지 확인하기

마지막으로, 약속이 잡히면 시스템은 그것이 유효한지 확인해야 해요.
다시 말해, 약속은 과거가 아니라 미래여야 해요.

`isValid` 함수를 작성해요. 이 함수는 두 개의 인자, 즉 약속 타임스탬프(문자열)와 현재 시각의 타임스탬프(문자열)를 받고, 주어진 현재 시각을 기준으로 약속이 미래라면 `true`를 반환해요.

```javascript
isValid('2022-02-11T23:00:00.000', '2022-02-08T23:00:00.000');
// => true
```
