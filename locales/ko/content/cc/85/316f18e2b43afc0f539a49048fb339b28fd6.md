# 개요

C++에서 불리언은 `bool` 타입으로 표현해요.
`bool`은 `true`거나 `false`예요.

## 논리 연산자

C++는 `!`(NOT), `&&`(AND), `||`(OR) 세 가지 불리언 연산자를 지원해요.
`not`, `and`, `or`라는 대체 표현을 쓸 수도 있어요.

```cpp
true || false // => true
true && false // => false
!true // => false
not false // => true
```

## 우선순위

세 불리언 연산자는 각각 _연산자 우선순위_가 달라요.
그래서 평가 순서는 `!`, `&&`, `||` 순이에요.
순서를 강제로 바꾸고 싶다면 불리언 표현식을 괄호, 즉 `()`로 감싸면 돼요. 괄호의 연산자 우선순위가 훨씬 높거든요.

```cpp
!true && false   // => false
!(true and false) // => true
```

## 변환

숫자가 필요한 자리에 `true`나 `false`를 쓰면 각각 `1`과 `0`으로 변환돼요.
불리언 연산에 숫자를 쓰면 `0`을 제외한 모든 값이 `true`로 취급돼요. 음수도 마찬가지예요.

```cpp
!true && 0.0   // => false
true + true + false // => 2
```
