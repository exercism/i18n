# 지침 부록

## 워드

`game` 튜플과, 롤이 하나도 없는 새 게임을 반환하는 생성자 `<game> ( -- game )`를 정의해요.

게임을 대상으로 동작하는 다음 워드들을 제공해요:

- `roll ( pins game -- )`: `pins`개의 핀이 쓰러졌다는 것을 기록해요. 롤이 유효하지 않으면 오류를 던져요:
  - `"Negative roll is invalid"`: 핀 수가 음수일 때예요.
  - `"Cannot roll after game is over"`: 열 프레임(과 추가 투구)을 모두 마친 뒤예요.
  - `"Pin count exceeds pins on the lane"`: 쓰러진 핀이 서 있는 핀보다 많을 때예요.
- `score ( game -- n )`: 게임의 총점을 반환해요. 게임이 아직 끝나지 않았으면 `"Score cannot be taken until the end of the game"` 오류를 던져요.

`roll`은 `kernel` 어휘의 `roll` 셔플 워드를 가린다는 점에 유의해요. 테스트 스위트는 `FROM: bowling => roll ;`로 구분해요.
