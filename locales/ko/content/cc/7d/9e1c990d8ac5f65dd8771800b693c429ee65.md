# 지침 추가

## 레지스터

| 레지스터 | 용도        | 유형 | 설명                                      |
| -------- | ----------- | ---- | ----------------------------------------- |
| `$a0`    | 입력        | 주소 | null로 끝나는 입력 문자열                 |
| `$a1`    | 입력/출력   | 주소 | 최종 뉴클레오타이드 개수가 담긴 워드 배열 |
| `$t0-9`  | 임시        | 임의 | 임시 저장용                               |
