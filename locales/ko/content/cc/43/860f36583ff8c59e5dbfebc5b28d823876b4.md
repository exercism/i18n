# 소개

## 배열

F#의 `array`는 길이가 고정된, 0개 이상의 값으로 이루어진 변경 가능한 컬렉션이에요. 즉, 배열을 한 번 만들면 크기는 바꿀 수 없지만 값은 바꿀 수 있어요. 배열 안의 값은 모두 같은 타입이어야 해요. 배열은 다음과 같이 정의할 수 있어요:

```fsharp
let empty = [| |]
let emptyAlternative = Array.empty

let singleValue = [| 5 |]
let singleValueAlternative = Array.singleton 5

let threeValues = [| "a"; "b"; "c" |]
```

인덱스를 사용해 배열에 원소를 할당하거나 배열에서 원소를 가져올 수 있어요. F# 배열은 0부터 시작해요. 즉, 첫 번째 원소의 인덱스는 항상 0이에요:

```fsharp
let numbers = [| 2; 3; 5 |]

// Update value in array
numbers[2] <- 9

// Read value from array
numbers[2]
// => 9
```

배열은 `Array` 모듈에 정의된 함수와 연산자로 다루거나, _array_ 패턴을 사용한 패턴 매칭으로 직접 다룰 수 있어요:

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty"
    | [| 1; 2; three |] -> sprintf "1, 2, %d" three
    | _ -> "Other"

describe [| |]         // => "Empty"
describe [| 1; 2; 4 |] // => "1, 2, 4"
describe [| 5; 7; 9 |] // => "Other"
```

패턴 매칭을 할 때 값을 _버릴_ 수도 있어요. 특정 경우에 값에 관심이 없을 때(즉, 값을 _사용_하지 않을 때)는 밑줄(`'_'`)을 사용해 이를 나타낼 수 있어요:

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty array"
    | [| x |] -> "Array with one item"
    | [| _; y |] -> "Array with two items (first item ignored)"
    | _ -> "Array with many items (all items ignored)"

describe [| |]          // => "Empty array"
describe [| 1 |]        // => "Array with one item"
describe [| 5; 7 |]     // => "Array with two items (first item ignored)"
describe [| 5; 7; 9 |]  // => "Array with many items (all items ignored)"
```

패턴 매칭에서 `'_'`는 항상 _마지막_에 와야 해요. 다른 어떤 경우와도 _일치하지 않는_ 값은 모두 이 경우에서 처리돼요.
