# 지침

이 연습 문제에서는 차량 구매를 준비하는 데 도움이 되는 코드를 작성해요.

세 가지 작업이 있어요. 하나는 면허가 필요한지 확인하는 것, 하나는 두 차량 중에서 고르는 것을 돕는 것, 그리고 하나는 중고 차량의 적정 가격을 추정하는 것이에요.

## 1. 운전면허가 필요한지 확인하기

어떤 종류의 차량은 운전하려면 운전면허가 필요해요.
`"car"`와 `"truck"` 종류만 면허가 필요하고, 나머지는 모두 면허 없이 운전할 수 있다고 가정해요.

차량의 종류를 받아서 그 종류의 차량에 면허가 필요한지를 나타내는 불리언을 반환하는 `NeedsLicense(kind)` 함수를 구현해요.

```go
needLicense := NeedsLicense("car")
// => true

needLicense = NeedsLicense("bike")
// => false

needLicense = NeedsLicense("truck")
// => true
```

## 2. 구매할 두 후보 차량 중에서 고르기

구매할 수 있는 차량들을 살펴봐요.
두 가지 선택지로 좁혔지만 최종 결정을 내리는 데 도움이 필요해요.
이를 위해 두 차량을 인자로 받아 사전순으로 앞서는 선택지를 포함한 결정을 반환하는 `ChooseVehicle(option1, option2)` 함수를 구현해요.

```go
vehicle := ChooseVehicle("Wuling Hongguang", "Toyota Corolla")
// => "Toyota Corolla is clearly the better choice."

ChooseVehicle("Volkswagen Beetle", "Volkswagen Golf")
// => "Volkswagen Beetle is clearly the better choice."
```

## 3. 중고 차량 가격 추정치 계산하기

이제 결정을 내렸으니, 판매점에서 공정한 가격에 사는지 확인하고 싶어요.
중고 차량 구매에 관심이 있으니, 가격은 차량의 연식에 따라 달라져요.
대략적으로 추정해 보면, 차량이 3년 미만이면 새 차였을 때의 원래 가격에서 80%가 돼요.
10년 이상이면 50%가 돼요.
차량이 3년 이상 10년 미만이면 원래 가격의 70%가 돼요.

`if`, `else if`, `else`를 사용해서 이 로직을 적용하는 `CalculateResellPrice(originalPrice, age)` 함수를 구현해요. 연습하고 싶다면 다른 방법도 있어요.
이 함수는 원래 가격과 차량의 연식을 인자로 받아 판매점에서의 예상 가격을 반환해요.

```go
CalculateResellPrice(1000, 1)
// => 800

CalculateResellPrice(1000, 5)
// => 700

CalculateResellPrice(1000, 15)
// => 500
```

**참고** 반환 값은 `float64`예요.
