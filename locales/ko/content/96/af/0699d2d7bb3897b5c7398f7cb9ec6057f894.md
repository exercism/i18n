# 개요

요일, 나침반 방향, 컨트롤러의 버튼처럼 정해진 몇 가지 상태 중 하나만 가질 수 있는 데이터를 모델링할 때는, `Int`나 `String` 같은 기본 타입으로는 큰 문제가 있어요.
정수나 문자열을 쓰면 코드가 잘못된 값(예를 들어 상태 코드 `999`나 `"leftt"` 같은 오타)을 끊임없이 검사해야 하고, 사람이 읽을 때 각 숫자가 무엇을 나타내는지 쉽게 알 수 없어요.

Swift는 이 문제를 [_열거형_][enumerations](흔히 *enum*이라고 줄여 불러요)으로 해결해요.
열거형은 서로 관련된 이름 붙은 값들을 하나로 묶는 공통 타입을 정의해요. 컴파일러는 가능한 모든 케이스를 미리 알고 있기 때문에, 컴파일 시점에 코드가 정확하고 빠짐없이 작성되었는지 검사할 수 있어요.
열거형은 메서드, 이니셜라이저, 계산 프로퍼티도 가질 수 있어요.

## 열거형 정의하기

`enum` 키워드 뒤에 타입 이름을 쓰고, 중괄호 안에 케이스들을 나열하면 열거형을 정의할 수 있어요.
Swift 관례상 타입 이름은 `UpperCamelCase`를, 각 케이스는 `lowerCamelCase`를 써요:

```swift
enum NESButton {
    case up
    case down
    case left
    case right
    case a
    case b
    case select
    case start
}
```

여러 케이스를 쉼표로 구분해서 한 줄에 정의할 수도 있어요:

```swift
enum NESButton {
    case up, down, left, right, a, b, select, start
}
```

열거형 케이스를 가리킬 때는 열거형 타입 이름, 점(`.`), 케이스 이름을 써요. 타입을 이미 알고 있거나 컴파일러가 추론할 수 있다면 타입 이름을 생략하고 더 짧은 점 문법을 쓸 수 있어요:

```swift
var lastPressed = NESButton.up

// Swift infers the type, so you can omit the type name:
lastPressed = .down

let konamiCode: [NESButton] = [.up, .up, .down, .down, .left, .right, .left, .right, .b, .a]
```

## 열거형과 `switch`문

열거형은 [`switch`문][enums-and-switches]과 아주 잘 어울려요.
Swift의 `switch`는 모든 경우를 다뤄야 하기 때문에, 컴파일러가 가능한 모든 케이스를 처리하도록 보장해 줘요:

```swift
lastPressed = .left
switch lastPressed {
case .up: print("You pressed the UP button")
case .down: print("You pressed the DOWN button")
case .left: print("You pressed the LEFT button")
case .right: print("You pressed the RIGHT button")
case .a: print("You pressed the A button")
case .b: print("You pressed the B button")
case .select: print("You pressed the SELECT button")
case .start: print("You pressed the START button")
}
// Prints "You pressed the LEFT button"
```

`default` 절 없이 케이스를 하나라도 빠뜨리면 컴파일러가 오류를 알려줘요:

```swift
switch lastPressed {
case .up, .down, .left, .right:
    print("You pressed a direction button.")
}
// Error: Switch must be exhaustive
```

모든 케이스를 명시적으로 나열하는 편이 `default`를 쓰는 것보다 나은 경우가 많아요. 그렇게 해두면 나중에 새 케이스를 추가했을 때, 컴파일러가 그 열거형을 다루는 모든 `switch`문을 고쳐야 한다고 즉시 알려줘요.

## 메서드와 이니셜라이저

열거형은 클래스나 구조체처럼 메서드와 사용자 정의 이니셜라이저를 정의할 수 있어요. 열거형 메서드 안에서 `self`는 현재 케이스 값을 가리켜요:

```swift
enum Coin {
    case heads
    case tails

    init(_ value: Int) {
        if value.isMultiple(of: 2) {
            self = .heads
        } else {
            self = .tails
        }
    }

    func flip() -> Coin {
        switch self {
        case .heads: return .tails
        case .tails: return .heads
        }
    }
}

let tails = Coin(13)     // .tails
let heads = Coin(0)      // .heads
let flipped = heads.flip() // .tails
```

## 원시값

열거형 케이스에는 [_원시값_][raw-values]이라는 기본값을 미리 지정할 수 있어요.
열거형의 모든 원시값은 같은 타입(예: `Int`, `String`, `Character`)이어야 해요:

```swift
enum NESButton: Character {
    case up = "⬆️"
    case down = "⬇️"
    case left = "⬅️"
    case right = "➡️"
    case a = "🅰️"
    case b = "🅱️"
    case select = "✅"
    case start = "🚦"
}

print(NESButton.left.rawValue) // Prints "⬅️"
```

`init(rawValue:)`를 사용하면 원시값으로 열거형을 초기화할 수 있어요. 잘못된 원시값이 들어올 수도 있기 때문에 이 이니셜라이저는 옵셔널을 반환해요:

```swift
let upButton = NESButton(rawValue: "⬆️") // Optional(NESButton.up)
let invalid = NESButton(rawValue: "🙄")  // nil
```

Swift는 `String`과 `Int` 열거형의 원시값을 자동으로 지정할 수 있어요:

- `String` 열거형에서는 각 케이스의 원시값이 기본적으로 케이스 이름이 돼요.
- `Int` 열거형에서는 별도로 지정하지 않으면 원시값이 `0`부터 시작해서 1씩 늘어나요.

```swift
enum Planet: Int {
    case mercury = 1, venus, earth, mars
}

print(Planet.earth.rawValue) // Prints 3
```

## 연관값

열거형 케이스는 각 케이스와 함께 다양한 타입의 값을 저장할 수도 있는데, 이를 [_연관값_][associated-values]이라고 해요:

```swift
enum Suit: Character {
    case diamonds = "♦️", clubs = "♣️", hearts = "♥️", spades = "♠️"
}

enum Card {
    case ace(Suit)
    case king(Suit)
    case queen(Suit)
    case jack(Suit)
    case number(Suit, Int)

    func description() -> String {
        switch self {
        case .ace(let suit): return "A\(suit.rawValue)"
        case .king(let suit): return "K\(suit.rawValue)"
        case .queen(let suit): return "Q\(suit.rawValue)"
        case .jack(let suit): return "J\(suit.rawValue)"
        case let .number(suit, value): return "\(value)\(suit.rawValue)"
        }
    }
}

let aceOfSpades = Card.ace(.spades)
let twoOfHearts = Card.number(.hearts, 2)

print(aceOfSpades.description()) // Prints "A♠️"
print(twoOfHearts.description()) // Prints "2♥️"
```

열거형은 원시값과 연관값 중 하나만 쓸 수 있고, 둘 다 쓸 수는 없어요.

## 재귀 열거형

[재귀 열거형][recursive-enumerations]은 하나 이상의 케이스에 대해 같은 열거형의 또 다른 인스턴스를 연관값으로 가지는 열거형이에요.
재귀를 가능하게 하려면 케이스(또는 열거형 전체)에 `indirect` 키워드를 붙여요:

```swift
enum BinaryTree {
    case leaf(value: Int)
    indirect case node(left: BinaryTree, value: Int, right: BinaryTree)
}

let tree: BinaryTree = .node(
    left: .leaf(value: 1),
    value: 3,
    right: .node(left: .leaf(value: 5), value: 6, right: .leaf(value: 9))
)
```
