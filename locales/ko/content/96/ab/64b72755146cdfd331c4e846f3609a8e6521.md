# 지침

이번 연습 문제에서는 좋아하는 요리책에 나오는 근사한 라자냐를 만들 수 있도록 코드를 작성해요.

라자냐를 조리하는 데 걸리는 시간과 관련된 네 가지 과제가 있어요.

## 1. 오븐에 넣어야 할 예상 시간을 분 단위로 정의하기

`expected-time` 변수를 정의해서 라자냐를 오븐에 몇 분 동안 넣어 두어야 하는지 확인해요. 요리책에 따르면 예상 오븐 시간은 40분이에요.

```clojure
expected-time
;;=> 40
```

## 2. 오븐에 남은 시간을 분 단위로 계산하기

`remaining-time` 함수를 정의해요. 이 함수는 라자냐가 지금까지 오븐에 있던 실제 시간을 분 단위로 인자로 받아서, 앞 과제에서 구한 예상 오븐 시간을 기준으로 라자냐가 오븐에 더 있어야 할 시간이 몇 분인지 반환해요.

```clojure
(remaining-time 30)
;;=> 10
```

## 3. 준비 시간을 분 단위로 계산하기

`prep-time` 함수를 정의해요. 이 함수는 라자냐에 올린 층 수를 인자로 받아서, 각 층을 준비하는 데 2분이 걸린다고 가정했을 때 라자냐를 준비하는 데 몇 분을 썼는지 반환해요.

```clojure
(prep-time 2)
;;=> 4
```

## 4. 총 작업 시간을 분 단위로 계산하기

`total-time` 함수를 정의해요. 이 함수는 두 개의 인자를 받아요. 첫 번째 인자는 라자냐에 올린 층 수이고, 두 번째 인자는 라자냐가 오븐에 있던 시간이 몇 분인지예요. 이 함수는 라자냐를 조리하는 데 총 몇 분을 썼는지, 즉 준비 시간(분)과 현재까지 라자냐가 오븐에서 보낸 시간(분)을 더한 값을 반환해야 해요.

```clojure
(total-time 3 20)
;;=> 26
```
