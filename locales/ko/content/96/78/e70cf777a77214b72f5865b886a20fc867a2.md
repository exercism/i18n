# 소개

Haskell에는 모든 숫자 타입의 기반이 되는 `Num`이라는 타입이 있어요.
Number 타입 안에는 [`Int`][int], [`Integer`][integer], [`Double`][double], [`Float`][float]라는 네 가지 주요 하위 타입이 있어요.

Haskell에는 정수를 나타내는 두 가지 정수 타입이 있어요.
`Int`는 크기가 고정된 정수이고, `Integer`는 임의 정밀도 정수예요.
`Integer`는 컴퓨터 메모리가 허용하는 한, 아무리 큰 수라도 저장할 수 있어요. 반면 `Int`는 32비트나 64비트로 표현할 수 있는 양의 정수와 음의 정수를 나타내요(최소 -2^29에서 2^29 - 1까지는 보장돼요).

음수를 쓸 때는 모호함을 피하기 위해 괄호를 사용해야 해요.

```haskell
1

(-1)
```

`Float`는 실수의 집합에 대응하고, 컴퓨터의 정밀도에 따라 표현할 수 있는 범위가 제한돼요.
숫자에 대해 정의된 연산은 보통 둘 중 한쪽 타입에서만 동작하고, 두 타입 모두에서 동작하지는 않아요.
`Double`은 배정밀도 부동소수점 수예요.

```haskell
10.5
```

## 정수와 실수 사이의 변환

`toFloat` 함수를 사용하면 `Int`나 `Integer`를 `Float`로 변환할 수 있어요.

```haskell
toFloat 1
-- -> 1.0
```

`fromIntegral`도 있는데, 어떤 숫자 타입이든 필요한 타입으로 추론해 변환해 줘요.

```haskell
fromIntegral 1
-- -> 1.0
```

`Float`를 `Int`로 변환하려면 [`round`][round], [`floor`][floor], [`ceiling`][ceiling] 함수를 사용할 수 있어요.
`round` 함수는 가장 가까운 정수로 반올림하고, `floor`는 내림, `ceiling`은 올림해요.

```haskell
round 1.5
-- -> 2

floor 1.5
-- -> 1

ceiling 1.5
-- -> 2
```

## 산술 연산자

숫자 타입에는 [기본 산술 연산자][math]를 사용할 수 있어요.
연산자에는 `+`, `-`, `*`, `/`, `%`가 있어요.
이 연산자들을 사용할 때는 숫자들의 타입이 서로 일치해야 해요.
`fromIntegral` 함수를 사용하면 타입이 일치하도록 변환해 줘요.

### 덧셈, 뺄셈, 곱셈

`+` 연산자는 덧셈에, `-` 연산자는 뺄셈에, `*` 연산자는 곱셈에 사용해요.

| 연산자 | 예시           |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### 나눗셈

나눗셈은 수를 나누는 데 사용해요.
`/` 연산자가 나눗셈에 사용돼요.
결과는 항상 실수예요.

```haskell
4.0 / 2.5
-- -> 1.6

4 / 2
-- -> 2.0
```

~~~~exercism/caution
어떤 프로그래밍 언어에서는 0으로 나누면 오류가 발생해요.

Haskell에서는 0으로 나누면 결과가 `Infinity` 또는 `-Infinity`가 돼요.
유일한 예외는 0을 0으로 나누는 경우로, 결과는 `NaN`(Not a Number)이 돼요.

```haskell
1 / 0
-- -> Infinity

(-1) / 0
-- -> -Infinity

0 / 0
-- -> NaN
```
~~~~

## 정수 나눗셈

정수 나눗셈은 정수를 나눠서 결과의 정수 부분을 구할 때 사용해요.
Haskell에는 정수 나눗셈 함수가 두 가지 있는데, 결과가 음수일 때 반올림하는 방식이 달라요:

- `div`는 음의 무한대 방향으로 내림해요.
- `quot`는 0 방향으로 버림해요.

```haskell
6 `div` 2
-- -> 3

5 `div` 2
-- -> 2

(-5) `div` 2
-- -> -3

5 `quot` 2
-- -> 2

(-5) `quot` 2
-- -> -2
```

~~~~exercism/caution
정수 나눗셈에서 0으로 나누면 예외가 발생해요.
일반 나눗셈과는 달라요.
~~~~

### 나머지

정수 나눗셈의 나머지는 `mod`나 `rem`으로 구할 수 있어요.
두 함수는 둘 중 하나가 음수일 때 결과의 부호가 달라요:

- `mod`는 `div`와 짝을 이루고, 결과의 부호는 제수의 부호와 같아요.
- `rem`은 `quot`와 짝을 이루고, 결과의 부호는 피제수의 부호와 같아요.

```haskell
5 `mod` 3
-- -> 2

(-5) `mod` 3
-- -> 1

5 `mod` (-3)
-- -> -1

5 `rem` 3
-- -> 2

(-5) `rem` 3
-- -> -2

5 `rem` (-3)
-- -> 2
```

0이 아닌 임의의 `x`와 `y`에 대해 다음 법칙이 성립해요:

```haskell
(x `div` y) * y + (x `mod` y) == x
(x `quot` y) * y + (x `rem` y) == x
```

~~~~exercism/note
두 수가 모두 양수이면 `div`와 `quot`는 같은 결과를 내고, `mod`와 `rem`도 마찬가지예요.
이 경우 `quot`와 `rem`이 조금 더 효율적일 수 있어요. `div`와 `mod`는 음수를 처리하는 데 추가 단계가 필요하거든요.
~~~~

~~~~exercism/caution
`mod`나 `rem`을 사용할 때 0으로 나누면 예외가 발생해요.
일반 나눗셈과는 달라요.

```haskell
1 `mod` 0
-- Exception: divide by zero
```
~~~~

## 거듭제곱

Haskell에는 거듭제곱을 하는 연산자가 세 가지 있는데, 동작 방식과 받는 인자 타입이 각각 달라요.

- `**`는 **부동소수점 수** 두 개를 받고, 로그를 이용해 거듭제곱을 계산해요.
- `^^`는 **부동소수점 수**를 받아 **정수**(양수 또는 음수) 거듭제곱을 해요.
- `^`는 **모든 숫자 타입**을 받아 **양의 정수** 거듭제곱을 해요.

```haskell
3.0 ** 2.1
-- -> 10.04510856630514

2.5 ^^ 2
-- -> 6.25

2 ^ 3
-- -> 8
```

## 우선순위와 괄호

Haskell에서는 괄호(`()`)를 사용할 수 있는데, 식을 묶는 데 쓸 수 있어요.
연산 순서를 바꾸고 싶을 때 유용해요.

여러 산술 연산자를 함께 사용할 때 연산 순서는 수학에서와 같고, [PEMDAS][pemdas]라고 불러요.
괄호(`()`), 지수(`**`), 곱셈(`*`)과 나눗셈(`/`), 덧셈(`+`)과 뺄셈(`-`) 순서를 따라요.

```haskell
2 + 3 - 4 * 4
-- -> -11

(2 + 3 - 4) * 4
-- -> 4
```
