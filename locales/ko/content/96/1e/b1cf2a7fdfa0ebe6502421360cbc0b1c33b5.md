# 소개

C#에서 [`null` 리터럴][null-keyword]은 값이 없음을 나타내는 데 사용해요. _nullable_ 타입은 `null` 값을 허용하는 타입이에요.

C# 8.0 이전에는 참조 타입은 항상 nullable이었고 값 타입은 그렇지 않았어요. 하지만 [값 타입은 물음표(`?`)를 붙여 nullable로 만들 수 있어요][nullable-value-types].

```csharp
string nullableReferenceType = "hello";
nullableReferenceType = null; // Valid as type is nullable

int nonNullableValueType = 5;
nonNullableValueType = null; // Compile error as type is not nullable

int? nullableValueType = 5; // Define nullable value type
nullableValueType = null;   // Valid as type is nullable
```

값이 `null`인 변수의 멤버에 접근하면 컴파일은 문제없이 되지만, 런타임에 `NullReferenceException`이 발생해요:

```csharp
string sentence = "What a nice day!";

// Throws NullReferenceException at runtime
sentence.Length;
```

이런 흔한 실수를 막기 위해, C# 8에서는 [기능을 선택][nullable-csharp-8]해서 [참조 타입을 기본적으로 non-nullable로 만들 수 있어요][nullable-reference-types]:

```csharp
string nonNullableReferenceType = "book";
nonNullableReferenceType = null; // Compile warning (no error!)

string? nullableReferenceType = "movie";
nullableReferenceType = null; // Valid as type is nullable
```

[nullable 값으로 안전하게 작업하려면][nullable-types-tutorial], 값이 `null`인지 먼저 확인해야 해요:

```csharp
string NormalizedName(string? name)
{
    if (name == null)
    {
        return "UNKNOWN";
    }
    else
    {
        // Value is not null at this point, so no compile warning
        // and no runtime NullReferenceException being thrown
        return name.ToUpper();
    }
}

NormalizedName(null); // => "UNKNOWN"
NormalizedName("Elisabeth"); // => "ELISABETH"
```

[`??` 연산자][null-coalescing-operator]를 사용하면 값이 `null`일 때 기본값을 반환할 수 있어요:

```csharp
string? name1 = "John";
name1 ?? "Paul"; // => "John"

string? name2 = null;
name2 ?? "George"; // => "George"
```

[`?.` 연산자][null-conditional-operator]를 사용하면 `null`일 수도 있는 값의 멤버를 안전하게 호출할 수 있어요:

```csharp
string? fruit = "apple";
fruit?.Length; // => 5

string? vegetable = null;
vegetable?.Length; // => null
```

컴파일러가 값이 `null`일 수 있다고 생각하지만 확실히 그렇지 않다고 알고 있다면, [`!.` 연산자][null-forgiving-operator]로 경고를 억제할 수 있어요. 다만 이 연산자는 최후의 수단으로만 사용해요.

```csharp
void PrintName(string? name)
{
    // Assume that the IsValid() method only return true
    // when its argument is not null
    if (IsValid(name))
    {
        // No compile warning
        Console.WriteLine(name!.Length);
    }
}
```
