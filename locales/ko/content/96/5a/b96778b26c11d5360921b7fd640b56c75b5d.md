# 안내

갑판장은 갑판에서 매일 당직 브리핑을 해요. 정해진 인사말, 당직 중인 선원들의 이름을 부르는 호명, 그리고 마지막을 알리는 해산 인사로 이어지는 순서예요. 이 연습 문제에서는 이 브리핑을 작고 이름 붙은 줄들로 나누고, 그것들을 조합해 볼 거예요.

이 연습 문제에서는 **두 개의 파일**을 수정해요.

- `bosuns-briefing/helpers/helpers.factor`: 작고 재사용할 수 있는 조각들이에요. 어휘: `bosuns-briefing.helpers`.
- `bosuns-briefing/bosuns-briefing.factor`: 헬퍼들을 조합하는 메인 파일이에요. 어휘: `bosuns-briefing`.

## 1. 인사말

`helpers.factor`에 `greeting`을 정의해서 정해진 시작 문자열 `"All hands, attention!"`을 반환하게 해요.

```factor
greeting .
! => "All hands, attention!"
```

## 2. 선원 줄

`helpers.factor`에 `crew-line`을 정의해서 이름 문자열을 받고, 그 이름 앞에 `"  - "`(공백 두 개, 하이픈, 공백 하나)를 붙여 반환하게 해요.

```factor
"Lopez" crew-line .
! => "  - Lopez"
```

## 3. 마무리

`helpers.factor`에 `closing`을 정의해서 정해진 해산 문자열 `"Carry on."`을 반환하게 해요.

```factor
closing .
! => "Carry on."
```

## 4. 명단

`bosuns-briefing.factor`에 `roster`를 정의해서 선원 이름들의 배열을 받고, 각 이름을 `crew-line`으로 형식화한 뒤 줄바꿈으로 이어 붙인 하나의 여러 줄 문자열을 반환하게 해요.

```factor
{ "Lopez" "Mwangi" } roster .
! => "  - Lopez\n  - Mwangi"

{ } roster .
! => ""
```

## 5. 브리핑

`bosuns-briefing.factor`에 `briefing`을 정의해서 선원 이름들의 배열을 받고, 전체 브리핑을 하나의 문자열로 반환하게 해요. 첫 줄에는 인사말, 그다음 줄들에는 명단, 마지막 줄에는 마무리가 와요. 헬퍼들과 `roster`를 사용해요.

```factor
{ "Lopez" "Mwangi" } briefing .
! => "All hands, attention!\n  - Lopez\n  - Mwangi\nCarry on."

{ } briefing .
! => "All hands, attention!\n\nCarry on."
```
