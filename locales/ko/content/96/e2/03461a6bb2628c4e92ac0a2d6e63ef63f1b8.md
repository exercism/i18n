# 안내 추가

## `Stream` ability 알아보기

`Stream`은 값을 내보내는 데 사용하는 Unison의 ability예요.

함수가 호출되는 동안 부수적인 효과로 값을 내보내야 할 때 `Stream` ability를 사용할 수 있어요. 예를 들어, 다음 함수는 배열의 마지막 값을 반환하지만, 원소를 하나씩 볼 때마다 누적 합계를 내보내요:

```
emitRunningTotal : '{Stream Nat} Nat
emitRunningTotal = 'let
  use Nat +
  List.foldLeft (
    acc a -> let
      runningTotal = acc + a
      Stream.emit runningTotal
      a
    ) 0 [1,2,3,4,5]
```

ability 핸들러를 사용하면, 이 함수가 반환하는 값과 함께 Stream을 List로 만들어 낼 수 있어요:

```
> Stream.toListWithResult! emitRunningTotal
  ⧩
  ([1, 3, 5, 7, 9], 5)
```
