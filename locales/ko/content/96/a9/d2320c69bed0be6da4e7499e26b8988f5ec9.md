# 소개

`Result` 타입은 Elm 언어에서 오류를 보고하기 위한 해결책이자 오류 복구를 가능하게 해주는 요소예요. `Maybe` 타입과 어느 정도 비슷하지만, `Maybe`는 실패할 수 있는 함수가 반환할 수 있을 뿐 왜 실패했는지는 알려주지 않아요. `Result`는 무언가가 왜 실패했는지에 대한 맥락을 담고 있어요.

`Result` 타입은 다음과 같이 정의돼요.

```elm
type Result error value
  = Ok value
  | Err error
```

이런 형태를 Elm 용어로는 "custom type" 정의라고 해요. `OK value`와 `Error error`에 있는 `error`와 `value`는 타입 변수를 나타내는데, `Int`, `Bool`, `String`처럼 어떤 타입이든 될 수 있다는 뜻이에요. 따라서 `Result String Int`는 `Int`를 담을 것으로 예상되는 변수이고, 오류가 있으면 이것은 `String`으로 표현돼요. Result를 위한 유용한 도우미 함수가 많이 담긴 [Result 모듈](https://package.elm-lang.org/packages/elm/core/latest/Result)도 있어요.
