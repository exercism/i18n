# 소개

짧은 워드라면 스택을 이리저리 다루는 방식으로 충분해요. 워드에 입력이 여러 개 있고 그것들을 이름으로 가리켜야 할 때는 Factor가 *locals*를 제공해요. `::`(워드 정의)나 `[| | ]`(인라인 람다)로 도입하는, 이름을 붙인 바인딩이고, 둘 다 [`locals`][locals]에서 와요.

```factor
USING: locals ;

:: hypotenuse ( a b -- c )
    a a *
    b b *
    + sqrt ;
```

쿼테이션 안에서 `[| inputs | body ]`는 이름 있는 입력을 가진 람다예요.

```factor
USING: assocs locals ;

H{ { "a" 1 } { "b" 2 } }
[| key value | key value 10 * ] assoc-map .
! => H{ { "a" 10 } { "b" 20 } }
```

[locals]: https://docs.factorcode.org/content/vocab-locals.html
