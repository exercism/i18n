# 소개

Factor의 오류 시스템은 세 부분으로 이루어져 있어요: [`kernel`][kernel]에 있는 `throw`는 오류를 발생시키고, [`continuations`][continuations]에 있는 `recover`는 그 오류를 잡아내며, `ERROR:`는 튜플 타입의 오류 클래스를 정의해요.

```factor
! "file not found" throw          (raises a string as the error)

[ "boom" throw ] [ drop "caught" ] recover .
! => "caught"
```

`recover ( try recovery -- )`는 *try* 쿼테이션을 실행해요. 오류가 발생하면 그 오류가 푸시되고, *recovery* 쿼테이션이 실행돼요.

`ERROR:`는 클래스와 새로운 인스턴스를 발생시키는 생성자 워드를 *모두* 선언해요:

```factor
! DOCTEST: SKIP
ERROR: not-found path ;

"/missing" not-found
! throws T{ not-found { path "/missing" } }
```

[continuations]: https://docs.factorcode.org/content/vocab-continuations.html
