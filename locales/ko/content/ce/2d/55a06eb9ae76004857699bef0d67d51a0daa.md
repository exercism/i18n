# 가드 사용

[comment]: # (이 오류는 가드를 전혀 사용하지 않은 코드에서 발생해요)

`two_fer/1`이 바이너리가 아닌 입력으로 코드를 실행하지 않도록 하려면 [가드](https://hexdocs.pm/elixir/master/guards.html)를 사용해요.

> elixir에서는 [문자열](https://elixir-lang.org/getting-started/binaries-strings-and-char-lists.html)이 [바이너리 데이터](https://elixir-lang.org/getting-started/binaries-strings-and-char-lists.html)로 취급된다는 점을 기억해 두세요.

```elixir
# Consider this function with a guard:
def hello(what) when is_binary(what) do
  "Hello, #{what}!"
end
```

> 이 가드는 `iex`에서 테스트해 볼 수 있어요.

```shell
iex> hello("world")
"Hello, world!"
iex> hello(123)
** (FunctionClauseError) no function clause matching in hello/1

    The following arguments were given to hello/1:

        # 1
        123
```
