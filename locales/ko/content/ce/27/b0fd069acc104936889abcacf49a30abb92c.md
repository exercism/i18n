# 힌트

## 1. 캐릭터 설명하기

- `Wizard`와 `Warrior` 클래스의 [생성자][constructor-syntax]를 수정해서 각 캐릭터 타입을 [기본 클래스의 생성자][instance-constructors]에 전달해요.
- 캐릭터 타입은 `Character` 클래스의 [필드][fields]로 저장해요.
- `Character` 클래스는 `object` 클래스를 암시적으로 상속받아요. `object` 클래스의 [`ToString()` 메서드는 재정의할 수 있어요][override-tostring].

## 2. 기본적으로 캐릭터가 취약하지 않게 만들기

- `Character` 클래스에 `Vulnerable()` 메서드를 구현해서 항상 `false`를 반환하게 해요.

## 3. `Wizard`가 주문을 준비할 수 있게 만들기

- `Wizard` 클래스에 필드를 추가해서 주문을 준비했는지 저장하고, `PrepareSpell()` 메서드에서 이 값을 갱신해요.
- 주문은 처음에는 준비되지 않은 상태로 시작해야 해요.

## 4. 주문을 준비하지 않았을 때 `Wizard`가 취약해지게 만들기

- `Wizard` 클래스에서 `Vulnerable()` 메서드를 재정의해서, 주문을 준비하지 않았다면 취약해지게 해요.

## 5. `Wizard`의 피해 점수 계산하기

- [조건문][if-else]을 사용해서, 주문 준비 필드의 값을 고려해 피해 점수를 반환해요.

## 6. `Warrior`의 피해 점수 계산하기

- 전달받은 `Character` 인스턴스의 메서드를 호출해 대상이 취약한지 확인할 수 있어요.
- [조건문][if-else]을 사용해서, 대상의 취약 여부를 고려해 피해 점수를 반환해요.
