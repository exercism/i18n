## 우리의 접근 방식

우리는 Rust를 배우는 학생들을 위해 문제 순서를 정해요. 그 독자를 염두에 두고, 새 문제를 추가할 때 두 가지 규칙을 따라요.

- 연습 문제는 새로운 개념을 하나만 소개해야 해요.
- 연습 문제는 Rust 기초에서 고급 Rust 개념으로 나아가야 해요.

### 새로운 개념 하나

어떤 문제를 풀 때 `Result`와 `HashMap`을 모두 사용해야 한다면, 이 개념들 중 최소한 하나는 앞선 문제에서 소개되어야 해요.

트랙에 특정 개념에 의존하는 문제가 여러 개 있다면, 학습을 강화할 수 있도록 그것들을 함께 묶어요.

### Rust 단계별 진행

#### 초반 문제

초반 문제는 여러 프로그래밍 언어에 공통으로 등장하는 Rust 문법과 개념에 집중해야 해요. 조건문, 반복, 고차 함수 같은 것들이요.

#### 중반 문제

트랙 중반의 문제는 덜 흔한 개념을 소개해야 해요. 예를 들어 `Result`와 `Option`, 트레이트 같은 것이요. 아니면 `while let` 같은 문법도요.

트랙 중반부를 지나면서 학생들은 폭넓은 Rust 개념에 익숙해져야 해요.

#### 후반 문제

트랙 후반의 문제는 두 가지 중 하나를 해야 해요.

1. 고급 개념을 소개하기: 라이프타임, 동시성, 안전하지 않은 코드
2. 지금까지 학생들이 쌓은 모든 지식을 종합하는 복잡한 풀이를 요구하기
