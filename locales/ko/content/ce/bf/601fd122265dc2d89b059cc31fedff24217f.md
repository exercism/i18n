# 소개

Haxe에서 `String`은 텍스트를 유니코드 문자(글자, 숫자, 구두점 등)의 나열로 표현하는 객체예요. `String` 인스턴스는 큰따옴표로 정의해요:

```haxe
var fruit:String = "Apple";
```

문자열은 문자열의 메서드를 호출해서 다뤄요. 문자열을 한 번 만들면 그 값은 절대 바뀌지 않아요. 문자열을 수정하는 것처럼 보이는 메서드도 실제로는 새로운 문자열을 반환해요.

여러 문자열을 서로 이어 붙일(더할) 수 있어요. 가장 간단한 방법은 `+` 연산자를 사용하는 거예요.

```haxe
var name:String = "Jane";
trace("Hello " + name + "!");
// => "Hello Jane!"
```

단순히 이어 붙이는 것보다 복잡한 문자열 서식 지정에는 문자열 보간을 쓰는 게 좋아요. 문자열에서 보간을 사용하려면 문자열을 작은따옴표(`'`)로 감싸요. 그다음 달러 기호(`$`)로 보간을 실행할 수 있어요:

```haxe
var name:String = "Jane";
trace('Hello $name!');
// => "Hello Jane!"
```
