# 힌트

## 일반

- Cairo에서는 연산자 오버로딩이 트레이트를 통해 구현된다는 점을 기억해요
- `#[derive(PartialEq)]` 속성은 동등 비교를 자동으로 구현해요
- `PartialOrd`를 구현할 때는 `lt` 메서드만 구현하면 돼요. 나머지 비교 연산자는 여기서 자동으로 파생돼요

## 1. `Add` 구현하기

- `add` 메서드는 두 TimeShard의 `value` 필드를 합쳐야 해요
- TimeShard는 덧셈이 이미 정의된 `i32` 값을 담고 있다는 점을 기억해요

## 2. `Sub` 구현하기

- 덧셈과 비슷하지만, `value` 필드 사이에 뺄셈 연산자를 사용해요
- 뺄셈에서는 피연산자의 순서가 중요해요

## 3. `PartialOrd` 구현하기

- `lt` 메서드는 TimeShard의 `value` 필드를 비교해야 해요
- `lt`를 구현하고 나면 나머지 비교 연산자(`>`, `<=`, `>=`)도 자동으로 동작해요
- `PartialEq`는 이미 파생되어 있으니 직접 구현할 필요가 없다는 점을 기억해요
