# 추가 지침

## Rust에 특화된 연습 문제 참고 사항

이 연습 문제는 다른 언어 버전과 비교했을 때 Rust 버전에서 조금 달라요. 범위를 벗어난 값에 대해 오류를 반환하도록 요구하는 대신, Rust의 강력한 타입 시스템을 사용해 입력을 제한해요. 모듈을 사용하는 사람이 오류를 처리하도록 하는 것보다, 함수가 유효한 입력을 모두 처리하게 만드는 편이 훨씬 쉬워요.

### 확장

u64의 최댓값인 `18_446_744_073_709_551_615`까지 변환할 수 있는 기능을 추가해 봐요.

이때 출력이 어떻게 되어야 하는지 힌트를 얻고 싶다면 마지막 테스트 케이스를 살펴봐요.
