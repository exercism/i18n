# Exercism API

## 설명

대부분의 Exercism 언어 트랙은 연습 문제를 가져오고 제출할 때 `exercism` 명령줄 도구를 사용하는데, 이 도구는 REST API를 통해 `exercism.io`와 통신해요. 반면 Pharo Smalltalk 언어 트랙은 같은 REST API를 사용해서 별도의 중간 도구 없이 Pharo 이미지에 연습 문제를 넣고 빼요. 이 문서는 Pharo Smalltalk 언어 트랙에서 Exercism API를 어떻게 사용하는지를 중심으로 API를 자세히 설명해요. Pharo Smalltalk 도구를 관리하는 메인테이너를 위한 문서예요.

## 헤더

모든 엔드포인트는 요청 헤더를 다음 값으로 설정해야 해요.

```
Authorization: Bearer <token>
```

`<token>` 값은 `https://exercism.io/my/settings`에서 확인할 수 있는 사용자의 CLI 인증 토큰이에요.

## 연습 문제 가져오기

```
Content-Type: application/json
```

`GET api.exercism.io/v1/solutions/latest?exercise_id=<slug>&track_id<language> HTTP/1.1`

위 URL에서 `<slug>`는 연습 문제의 이름(예: `hello-world`)이고, `<language>`는 언어 트랙(예: `pharo-smalltalk`)이에요.

### 응답

#### 200

요청이 성공하면 JSON 페이로드가 담긴 응답을 보내요. JSON 안에는 연습 문제에 대한 정보와 연습 문제 파일을 다운로드할 수 있는 URL이 들어 있어요.

```json
"solution":{
	"id":"<id-string>",
	"url":"https://exercism.io/my/solutions/<id-string>",
	"team":null,
	"user":{
		"handle":"<exercism-user-name>",
		"is_requester":true
		},
		"exercise":{
			"id":"isogram",
			"instructions_url":"https://exercism.io/my/solutions/<id-string>",
			"auto_approve":false,
			"track":{
				"id":"pharo-smalltalk",
				"language":"Pharo"
				}
			},
			"file_download_base_url":"https://api.exercism.io/v1/solutions/<id-string>/files/",
			"files":[
				"IsogramTest.class.st",
				"README.md"
				],
			"iteration":null
		}
	}
```

#### 400

언어 트랙 이름이 모호하거나, 제출한 연습 문제 파일이 변경되지 않았어요.

#### 403

사용자에게 솔루션이 잠금 해제되지 않았거나 언어 트랙에 참여하지 않았어요.

#### 404

언어 트랙이나 연습 문제를 찾을 수 없어요.

## 연습 문제 제출하기

```
Content-Type: application/octet-stream
```

`PATCH api.exercism.io//v1/solutions/<some-kind-of-token-or-hash> HTTP/1.1`

### 응답

#### 201

제출에 성공했어요.

#### 400

제출한 파일이 너무 크거나(1메가바이트 초과), 솔루션이 중복이에요.

#### 403

사용자가 솔루션에 접근할 수 없어요. 솔루션의 사용자 ID와 현재 사용자 ID가 일치하지 않아요.

#### 404

솔루션 ID를 찾을 수 없어요.
