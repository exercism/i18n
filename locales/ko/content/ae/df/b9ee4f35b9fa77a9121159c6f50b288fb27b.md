# 힌트

## 1. 화씨를 섭씨로 변환

- 섭씨 온도는 다음과 같이 정의돼요: T(°C) = (T(°F) - 32) / 1.8
- 화씨 온도는 `Integer`로 주어지고, 섭씨는 `Float`로 반환해야 해요. `fromInteger` 함수가 도움이 될 거예요.

## 2. 섭씨를 화씨로 변환

- 화씨 온도는 다음과 같이 정의돼요: T(°F) = T(°C) × 1.8 + 32
- 섭씨 온도는 `Float`로 주어지고, 가장 가까운 `Integer`로 올림한 화씨를 반환해야 해요. `ceiling` 함수가 도움이 될 거예요.
