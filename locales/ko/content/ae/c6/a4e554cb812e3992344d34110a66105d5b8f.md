# 루프 소개

Bash에는 두 가지 루프 형태가 있어요:

* 항목 목록의 _각 항목마다_ 명령을 반복해요,
* 어떤 조건이 참(또는 거짓)인 _동안_ 명령을 반복해요.

## `for`문

항목 목록을 순회하려면 `for`문을 사용해요.

```bash
for varname in words; do COMMANDS; done
```

`words`는 단어 분리와 파일 이름 확장을 거쳐 펼쳐져요([따옴표 개념][quoting]에서 배운 내용이에요).
각 단어는 차례로 `varname`에 할당되고, COMMANDS가 실행돼요.

`for`문이 언제 유용한지 보여 주는 몇 가지 예제가 있어요.

* 여러 파일에 대해 명령을 실행해요.

    ```bash
    # source all the bash library files in the current directory
    for file in ./*.bash; do
        source "$file"
    done
    ```

* 스크립트나 함수의 매개변수 각각에 대해 명령을 실행해요.

    ```bash
    for arg in "$@"; do
        echo "argument: ${arg}"
    done
    ```

* 어떤 명령의 출력에서 공백으로 구분된 단어마다 명령을 실행해요.

    ```bash
    for i in $(seq 10); do
        echo "${i} squared is $((i * i))"
    done
    ```

    이 방식에 대한 경고는 나중에 살펴볼 거예요.

### 산술 `for`문

Bash에는 산술 루프도 있어요.
다른 프로그래밍 언어를 써 봤다면 꽤 익숙하게 보일 거예요.

```bash
for ((INITIALIZATION; CONDITION; INCREMENT)); do COMMANDS; done
```

Bash에서 이중 괄호는 산술 문맥을 나타내요(Bash 산술에 대해서는 나중 개념에서 더 살펴볼 거예요).
위에서 `seq`를 사용한 예제는 이렇게 쓸 수 있어요.

```bash
for ((i = 1; i <= 10; i++)); do
    echo "${i} squared is $((i * i))"
done
```

### `for`를 쓰지 말아야 할 때

[`for`로 줄을 읽지 마세요][bashfaq1].

자주 보게 되는 안티패턴이 있는데, 바로 `cat`의 출력을 순회하는 것이에요.

```bash
for line in $(cat some.file); do 
    do_something_with "$line"
done
```

이 방법은 두 가지 점에서 잘못됐어요.

1. 명령 치환이 따옴표로 묶여 있지 않아서 단어 분리의 대상이 돼요.
   단어 분리는 기본적으로 줄바꿈만이 아니라 _공백_ 을 기준으로 나눠요.
   이 `for`문은 파일의 줄이 아니라 **단어**를 순회하고 있어요.
2. 명령 치환이 따옴표로 묶여 있지 않아서 파일 이름 확장의 대상이 돼요.
   파일에 있는 모든 단어가 글롭 패턴과 일치하는지 검사돼요.

[따옴표 개념][quoting]에서 배웠듯이, 단어 분리는 `IFS` 변수로 제어할 수 있고 파일 이름 확장은 끌 수 있어요.
하지만 이런 방법은 깨지기 쉬워요.
`for`는 파일의 줄을 순회하는 데 맞는 방법이 아니에요.
파일을 읽는 관용적인 방법은 `while`문을 사용하는 거예요.

## `while`문

어떤 조건이 참인 _동안_ 일련의 명령을 반복하려면 `while`을 사용해요.

```bash
while CONDITION_COMMANDS; do COMMANDS; done
```

`if`와 마찬가지로, CONDITION_COMMANDS에는 특별한 문법이 없어요([조건문 개념][conditionals]에서 배웠어요).
명령 목록의 종료 상태가 "참"인지 "거짓"인지를 결정해요.

## 루프 제어

`break` 명령은 루프 밖으로 빠져나와요.
실행은 루프의 `done` 종결자 다음에 오는 명령부터 다시 이어져요.

`continue` 명령은 루프의 다음 반복으로 건너뛰어요.

## 파일의 줄 읽기

앞에서 말했듯이, 파일을 읽는 관용적인 방법은 `while`문이에요.

```bash
while IFS= read -r line; do
    do_something_with "$line"
done < some.file
```

* 파일의 내용은 `<` 리다이렉션을 통해 루프의 입력으로 들어가요.
* `read` 명령은 입력에서 한 줄 전체를 읽을 수 있으면 "참"을 반환해요.
  입력을 다 소진했거나 마지막 줄이 줄바꿈 없이 끝나면 read는 "거짓"을 반환해요.
  * 마지막 줄이 줄바꿈으로 끝나지 않더라도 파일의 줄을 읽는 _진짜로_ 관용적인 방법은 다음과 같아요.

    ```bash
    while IFS= read -r line || [[ -n "$line" ]]; do ...
    ```

* `-r` 옵션은 `read`가 역슬래시 시퀀스를 치환하지 않도록 해요. 역슬래시는 그냥 평범한 문자예요.
* `IFS=`는 `read` 명령이 실행되는 동안에만 IFS에 빈 문자열을 할당해요.
  이렇게 하면 단어 분리가 일시적으로 꺼져서 입력되는 줄의 앞뒤 공백이 그대로 보존돼요.

## `until`

`until` 구문은 어떤 조건이 **거짓**인 동안 일련의 명령을 반복해요.
조건이 참이 될 _때까지_ 루프가 반복돼요.

```bash
until CONDITION_COMMANDS; do COMMANDS; done
```

`until`은 드물게 사용해요.
더 흔한 것은 "while not" 루프예요.

```bash
while ! CONDITION_COMANDS; do ...
```

## 무한 루프

때로는 영원히 반복하고 싶을 때가 있어요.
그럴 때 쓰는 두 가지 방법이 있어요.

1. 항상 성공 종료 상태를 갖는 조건을 사용하는 `while`문

    ```bash
    while true; do ...
    ```

2. 표현식이 비어 있는 산술 `for`문

    ```bash
    for ((;;)); do ...
    ```

## do-while

do-while 구문이 따로 있는 것은 아니지만, 같은 효과를 낼 수 있어요.

```bash
while true; do
    COMMANDS

    if END_CONDITION; then
        break
    fi
done
```
