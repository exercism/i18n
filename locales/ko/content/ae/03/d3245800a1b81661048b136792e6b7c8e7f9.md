Haxe에서 [불리언][booleans]은 `Bool` 타입으로 표현되며, 값으로는 `true` 또는 `false`를 가질 수 있어요.

Haxe는 세 가지 [불리언 연산자][operators]를 지원해요: `!` (단항 NOT), `&&` (이항 AND), `||` (이항 OR)

복합 불리언 표현식(`&&`와 `||`)은 _단락 평가_를 사용하는데, 표현식은 왼쪽에서 오른쪽으로 평가되지만 필요한 만큼만 평가돼요. 이는 다음과 같은 경우에 중요해요:

```haxe
object != null && object.field == x
```

첫 번째 불리언 검사는 `object`가 `null`이 아닐 때만 `object.field`에 접근하도록 보장해서, 런타임 오류를 막아줘요.

세 불리언 연산자는 서로 다른 [우선순위][precedence]를 가지며, `!` -> `&&` -> `||` 순서로 평가돼요.

표현식을 괄호 `()`로 감싸면 이러한 우선순위 규칙을 무시할 수 있는데, 괄호가 더 높은 우선순위를 가지기 때문이에요.

```haxe
!true && false   // => false
!(true && false) // => true
```
