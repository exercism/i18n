# 소개

Haxe에서 이터레이터는 `for`문을 사용해 값을 순회할 때 써요. 이터레이터에는 두 가지 종류가 있어요.

- 값을 순회하는 `Iterator`
- 데이터 타입을 순회할 수 있게 해 주는 `Iterable` 데이터

이 두 개념은 각각 `Iterator<T>`와 `Iterable<T>`로 표현해요.

```haxe
typedef Iterator<T> = {
  function hasNext():Bool;
  function next():T;
}

typedef Iterable<T> = {
  function iterator():Iterator<T>;
}
```

이 타입들 중 하나와 통합되는 클래스는 `for`문으로 순회할 수 있어요. 클래스가 `hasNext`와 `next` 메서드를 정의하면 이터레이터로 취급하고, `iterator` 메서드를 정의하면 이터러블 타입으로 취급해요.
