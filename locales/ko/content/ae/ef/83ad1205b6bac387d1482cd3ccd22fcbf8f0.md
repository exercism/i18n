# 지침

이 연습 문제에서는 인벤토리 시스템을 관리해요.

인벤토리는 품목 이름을 기준으로 정리되어야 하고, 각 품목의 개수를 추적해야 해요.

인벤토리에 품목을 추가하는 것도 처리해야 해요.
주어진 벡터에 어떤 품목이 나타날 때마다, 인벤토리에서 그 품목의 수량을 `1`만큼 늘려요.
요청이 있으면 수량을 `1`만큼 줄여서 인벤토리에서 품목을 삭제하는 것도 처리해야 해요.

마지막으로, 주어진 인벤토리의 모든 키-값 쌍을 `pair`의 `vector`로 반환하는 함수를 구현해야 해요.

~~~~exercism/note
이 연습 문제의 테스트는 값을 변경하든 하지 않든 상관없이 통과하지만, 함수 이름은 값을 변경하지 않아야 함을 나타내요.
입력을 변경하지 않으면서 소개에서 나온 함수를 사용하고 싶다면, `copy()` 함수가 도움이 될 거예요.
~~~~

## 1. 벡터를 기반으로 인벤토리 만들기

품목으로 이루어진 입력 벡터로부터 "인벤토리"를 만드는 `create_inventory(<input vector>)` 함수를 구현해요.
각 품목 이름과 그에 해당하는 수량을 짝지은 `dict`를 반환해야 해요.

```julia-repl
julia> create_inventory(["coal", "wood", "wood", "diamond", "diamond", "diamond"])
Dict("coal" => 1, "wood" => 2, "diamond" => 3)
```

## 2. 벡터의 품목을 기존 딕셔너리에 추가하기

전달받은 인벤토리에 품목 벡터를 추가하는 `add_items(<inventory dict>, <item vector>)` 함수를 구현해요:

```julia-repl
julia> add_items(Dict("coal" => 1), ["wood", "iron", "coal", "wood"])
Dict("coal" => 2, "wood" => 2, "iron" => 1)
```

## 3. 인벤토리에서 품목 개수 줄이기

품목의 `vector`를 인자로 받는 `decrement_items(<inventory dict>, <items vector>)` 함수를 구현해요.
`vector`에 어떤 품목이 나타날 때마다, 그 품목의 개수에서 `1`을 빼요:

```julia-repl
julia> decrement_items(Dict("coal" => 3, "diamond" => 1, "iron" => 5), ["diamond", "coal", "iron", "iron"])
Dict("coal" => 2, "diamond" => 0, "iron" => 3)
```

인벤토리의 품목 개수는 0 아래로 내려가면 안 돼요.
입력 `vector`에 어떤 품목이 나타나는 횟수가 남아 있는 개수보다 많으면, 그 품목의 수량은 0으로 유지돼야 해요.
개수가 0이 되면, 그 이후의 삭제 요청은 무시해요.

```julia-repl
julia> decrement_items(Dict("coal" => 2, "wood" => 1, "diamond" => 2), ["coal", "coal", "wood", "wood", "diamond"])
Dict("coal" => 0, "wood" => 0, "diamond" => 1)
```

## 4. 인벤토리에서 항목을 완전히 제거하기

인벤토리에서 품목과 그 개수를 완전히 제거하는 `remove_item(<inventory dict>, <item>)` 함수를 구현해요:

```julia-repl
julia> remove_item!(Dict("coal" => 2, "wood" => 1, "diamond" => 2), "coal")
Dict("wood" => 1, "diamond" => 2)
```

인벤토리에 그 품목이 없으면, 함수는 원래 인벤토리를 그대로 반환해야 해요.

```julia-repl
julia> remove_item(Dict("coal" => 2, "wood" => 1, "diamond" => 2), "gold")
Dict("coal" => 2, "wood" => 1, "diamond" => 2)
```

## 5. 인벤토리의 전체 내용 반환하기

인벤토리를 인자로 받아 `(item, quantity)` 쌍의 벡터를 반환하는 `list_inventory(<inventory dict>)` 함수를 구현해요.

벡터에는 _사용 가능한_ 품목(_개수가 0보다 큰_)만 포함되어야 하고, 품목 이름의 알파벳 순서로 정렬되어야 해요:

```julia-repl
julia> list_inventory(Dict("coal" => 7, "wood" => 11, "diamond" => 2, "iron" => 7, "silver" => 0))
["coal" => 7, "diamond" => 2, "iron" => 7, "wood" => 11]
```
