# 소개

[V](https://vlang.io/)는 유지보수하기 쉬운 프로그램을 만들기 위한 간단한 언어예요. 문법은 Go와 비슷하고, 성능은 C만큼 빨라요.

V는 아직 베타 개발 단계지만, 이미 아주 강력해요.

안전 기능이 다양하게 기본으로 들어 있어서, V는 어떤 상황에서도 코드가 잘 실행되도록 도와줘요. 범위 검사, 정의되지 않은 값 없음, 기본적으로 불변 변수, Option/Result 타입과 필수 오류 검사, 그리고 null이 없어요.

V는 V로 작성되었고 1초 이내에 스스로를 컴파일하며, 비용 없이 C 코드를 호출할 수 있어요. 코드 포매팅, 코드 프로파일링, 테스트, 문서 생성 기능도 기본으로 제공해요.

공식 웹사이트는 [vlang.io](https://vlang.io/)이고, 문서는 모두 [이 마크다운 파일](https://github.com/vlang/v/blob/master/doc/docs.md)에 있어요.
