# 소개

C++의 조건문은 다른 언어의 조건문과 비슷해요.
모든 조건 연산의 기반이 되는 타입은 `bool` 타입이고, 이 타입은 `true` 또는 `false` 값을 가질 수 있어요.
조건문은 여러 조건을 확인하는 흐름 제어 수단으로 자주 사용돼요.

아래처럼 조건이 `true`일 때 코드를 실행하는 `if`문을 사용할 수 있어요.

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

경우가 두 개 이상인 상황에서는 `else if`문과 `else`문으로 여러 `if`문을 이어 붙일 수 있어요.

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

C++17부터는 `if`문에 짧은 초기화문을 함께 넣을 수 있는데, 이 초기화문으로 `if`문에서 사용할 변수를 하나 이상 초기화할 수 있어요.
예를 들면 이렇습니다.

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> 참고: 초기화 부분에서 만든 변수는 `if`문이 끝난 뒤에는 접근할 수 없어요.
