# 개요

[메서드 오버로딩][method-overloading]은 Java의 핵심 개념으로, 각 메서드가 서로 다른 매개변수 목록을 가지기만 하면 하나의 클래스가 같은 이름의 메서드를 여러 개 가질 수 있게 해줘요.
이 기능은 Java 객체 지향 프로그래밍의 기본 요소이며, 서로 다른 타입이나 개수의 입력으로 비슷한 연산을 수행할 수 있는 방법을 제공해요.
메서드 오버로딩은 비슷한 기능을 하는 메서드들이 같은 이름을 공유할 수 있게 해줌으로써 코드의 가독성과 구조를 높여줘요.
오버로딩은 메서드 이름과 매개변수 목록을 포함하는 메서드 시그니처에 의해 결정된다는 점이 중요해요.

## 핵심 사항

- **시그니처가 중요해요**: 반환 타입은 메서드 시그니처의 일부가 아니에요. 따라서 메서드의 반환 타입만 바꾸는 것은 오버로딩이 되지 않아요.
- **매개변수의 차이**: 오버로딩된 메서드는 매개변수의 개수나 타입이 달라야 해요.
- **활용**: 오버로딩은 서로 다른 타입의 입력으로 메서드를 더 직관적으로 사용할 수 있게 하는 데 자주 쓰여요.

## 메서드 오버로딩의 예

숫자를 더할 수 있는 `Calculator` 클래스를 생각해봐요.
오버로딩을 사용하면 여러 가지 타입의 덧셈 연산을 만들 수 있어요:

```java
public class Calculator {

    public int add(int a, int b) {
        return a + b;
    }

    public double add(double a, double b) {
        return a + b;
    }

    public int add(int a, int b, int c) {
        return a + b + c;
    }
}
```

## 모범 사례

- **명확성**: 오버로딩된 메서드는 코드를 더 직관적으로 만드는 방식으로 사용해야 해요.
  - 오버로딩된 메서드의 동작은 서로 관련이 있고 일관성이 있어야 해요.
- **모호함 피하기**: 각 오버로딩된 메서드가 명확한 목적을 가지고 있고, 매개변수 목록의 차이가 혼란을 피할 만큼 충분히 분명한지 확인해요.
- **문서화**: 오버로딩된 메서드의 각 버전을 제대로 문서화해요.
  - 명확한 문서는 다른 개발자가 각 메서드 변형의 목적과 사용법을 이해하는 데 도움이 돼요.
- **일관된 반환 타입**: 오버로딩된 메서드에서 반환 타입이 달라질 수 있지만, 혼란을 피하기 위해 가능하면 일관되게 유지하는 것이 일반적으로 좋아요.
- **오버로딩 제한하기**: 메서드 오버로딩을 과도하게 사용하지 않아요.
  - 과도한 오버로딩은 코드를 읽고 유지보수하기 어렵게 만들 수 있어요.

## 마무리

메서드 오버로딩은 Java의 강력한 기능으로, 올바르게 사용하면 코드의 가독성과 유연성을 크게 높일 수 있어요.
메서드가 더 다양한 상황에 맞춰 유연하게 동작할 수 있게 해주어, Java 프로그램을 더 모듈화되고 유지보수하기 쉽게 만들어줘요.
