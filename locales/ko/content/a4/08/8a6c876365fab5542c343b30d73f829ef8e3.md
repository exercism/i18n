# 열거형

열거형은 코드의 가독성과 안전성을 위해 미리 정의된 변형들을 묶어 두는 Cairo의 데이터 타입이에요.
Cairo에서는 `enum` 변형이 서로 다른 데이터 타입(정수, 구조체, 튜플, 다른 열거형 등)을 담도록 선언할 수 있어요.

아래 코드 조각은 열거형을 어떻게 정의할 수 있는지 보여줘요.

```rust
#[derive(Drop)]
enum Direction {
    North,
    East,
    South,
    West,
}
```

위에서 선언한 `Direction` 열거형은 `North`, `East`, `South`, `West`라는 네 가지 변형을 가진 단순한 열거형이에요.
열거형 변형의 이름을 지을 때는 PascalCase를 사용하는 것이 관례예요.
각 변형은 `Direction` 열거형 타입의 서로 다른 값을 나타내요.
이 예제의 열거형에서 각 변형은 연결된 값이 없으며, 다음과 같은 문법으로 인스턴스를 만들 수 있어요.

```rust
let direction = Direction::North;
```

아래는 같은 `Direction` 열거형이지만, 방향의 정확한 각도를 저장하는 값을 가진 변형들로 되어 있어요.

```rust
#[derive(Drop)]
enum Direction {
    North: u128,
    East: u128,
    South: u128,
    West: u128,
}
```

이 예제를 보면 `Direction` 열거형의 각 변형이 `u128` 값을 가진다는 것을 알 수 있어요.
이런 종류의 열거형은 다음과 같이 인스턴스를 만들 수 있어요.

```rust
let direction = Direction::North(10);
```

## 사용자 정의 타입을 사용한 복잡한 열거형 예제

열거형은 서로 다른 데이터 타입들을 조합해 변형으로 선언할 수 있어요.
아래 예제에서 `Action`은 `Quit`, `Direction`, `SendMessage`, `ChangeAvatar`, `ProfileState`를 변형으로 모아 둔 복잡한 열거형이에요.

```rust
#[derive(Drop)]
struct Move {
    up: u32,
    down: u32,
    right: u32,
    left: u32,
}

#[derive(Drop)]
enum UserCommand {
    Login,
    UpdateProfile,
    Logout,
}

#[derive(Drop)]
enum Action {
    Quit, //  variant with no associated value
    Direction: Move, // variant with the `Move` struct associated value
    SendMessage: felt252, // a single felt252 variant
    ChangeAvatarColor: (u8, u8, u8), // variant with the tuple of three associated values
    ProfileState: UserCommand // variant with an enum associated value
}
```

## 열거형을 위한 트레이트 구현

Cairo에서는 트레이트를 정의하고 사용자 정의 열거형에 구현할 수 있어요.
이렇게 하면 열거형과 관련된 메서드와 속성을 정의할 수 있어요.
아래는 `Message` 열거형을 정의하고 이에 대한 `Processing` 트레이트를 구현한 예제예요.

```rust
#[derive(Drop)]
enum Message {
    Quit,
    Echo: felt252,
    Move: (u128, u128),
}

trait Processing {
    fn process(self: Message);
}

impl ProcessingImpl of Processing {
    fn process(self: Message) {
        match self {
            Message::Quit => { println!("quitting") },
            Message::Echo(value) => { println!("echoing {}", value) },
            Message::Move((x, y)) => { println!("moving from {} to {}", x, y) },
        }
    }
}
```

다음은 트레이트를 사용해 `Quit` 메시지를 처리하는 방법이에요.

```rust
let msg: Message = Message::Quit;
msg.process(); // prints "quitting"
```

열거형은 특히 위 트레이트 구현에서처럼 `match` 흐름과 함께 사용할 때 여러 상황에서 유용하게 쓰여요.
`match` 흐름에 대해서는 [The Cairo Book][match]에서 더 자세히 알아볼 수 있어요.

[match]: https://book.cairo-lang.org/ch06-02-the-match-control-flow-construct.html
