# 소개

Clojure에서 이름에 값을 바인딩하는 것을 _var_라고 해요. 최상위(전역) var는 다른 언어의 상수와 비슷하지만, 동적인 개발을 돕기 위해 흔히 다시 정의해요.

최상위 var는 `def`로 정의해요:

```clojure
(def fingers 10)
```

`defn` 매크로를 사용하면 인자를 0개 이상 받는 함수를 정의할 수 있어요. 함수는 항상 본문의 마지막 표현식 결과를 반환해요.

```clojure
(defn add [x y]
  (+ x y))
```

함수를 호출할 때는 이름을 지정하고, 함수의 매개변수마다 인자를 전달해요.

```clojure
(def five (add 2 3))
```

Clojure에서 함수와 값은 정의된 _후에야_ 사용할 수 있어요. 정의되기 전에 사용하면 컴파일 오류가 발생해요.

```clojure
;; Compile error as `add` has not yet been defined
(def seven (add 3 4))

(defn add [x y]
  (+ x y))
```

Clojure에서 공백은 서식 외에는 아무런 의미가 없어요.

Clojure의 함수와 var는 네임스페이스로 구성돼요. 네임스페이스는 관련된 기능을 묶어 주고, `ns` 매크로로 정의해요:

```clojure
(ns calculator)

(def pi 3.14)

(defn add [x y]
  (+ x y))
```

Clojure는 두 가지 종류의 주석을 지원해요. 한 줄 주석은 `;`로 시작하고, `comment` 폼은 `(comment`와 `)` 사이의 모든 것이 평가되지 않도록 막는 데 사용해요.
