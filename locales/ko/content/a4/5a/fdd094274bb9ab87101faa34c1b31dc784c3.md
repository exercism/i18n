# Null

null은 값이 `null` 하나뿐인 원시 값 타입이에요.
null은 흔히 아무것도 없음을 나타내는 데 사용해요.
거짓 같은 값으로 취급되지만, `false`나 다른 거짓 같은 값과는 구별돼요.

```php
<?php

is_null(null); // => true
isset(null); // => false

null == true; // => false
null === true; // => false

null == false; // => true
null === false; // => false
```

## null 값 다루기

PHP에서 null 값은 오류의 흔한 원인이 되곤 해요.
오류 상태를 대신하거나 아무것도 없음을 나타내려고 자주 반환되기 때문이에요.
오류가 생기는 걸 막으려면 보통 값을 다루기 전에 그 값이 null이 아닌지 확인하는, 이른바 "null 검사"가 필요해요.

```php
<?php

$value = null;

$value->doSomething(); // throws an error as a null value is not an object instance.

if (!is_null($value)) {
    $value->doSomething(); // succeeds
}
```

null 검사를 반복하면 실수하기 쉬워요.
그래서 PHP는 null 값을 다루기 위한 두 가지 연산자를 제공해요. null 안전 접근 `?->` 연산자와 null 병합 `??` 연산자예요.

```php
<?php

$value = null;
$result = $value?->doSomething(); // => return null rather than error
$result = $result ?? "default"; // => "default" is assigned to $result
```
