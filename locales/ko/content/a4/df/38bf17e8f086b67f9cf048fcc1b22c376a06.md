# 소개

`import`라는 특별한 형태를 쓰면 모듈 이름을 붙이지 않고도 외부 모듈의 함수를 사용할 수 있어요.

외부 모듈을 통째로 가져오면 이미 있는 지역 함수와 충돌이 생길 수 있어요. 이를 피하려고 `:except`와 `:only` 두 가지 방법을 쓸 수 있어요. 둘 다 키워드 리스트를 받는데, 키는 함수 이름이고 값은 그 함수의 인자 개수예요.

보통 `import`는 모듈 정의 맨 앞에 넣어요.

```elixir
defmodule Square do
  import Integer, only: [pow: 2]

  def area(a), do: pow(a, 2)
end
```
