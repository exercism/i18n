## 타입 별칭

Gleam에서는 타입 별칭을 사용해, 그대로 쓰기에는 번거로운 기존 타입에 편리한 이름을 붙일 수 있어요.

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

`pub type`을 사용하면 별칭을 정의된 모듈 밖에서도 사용할 수 있어요. `pub`을 생략하면 별칭은 비공개가 되어 다른 모듈에서 참조할 수 없어요.
