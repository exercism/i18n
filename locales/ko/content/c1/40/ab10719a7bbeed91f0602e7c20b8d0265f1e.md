# 소개

## 패턴 매칭

`if/elif/else` 식을 사용하면 조건에 따라 로직을 실행할 수 있어요. F#에는 조건에 따라 로직을 실행하는 더 강력한 방법이 하나 더 있어요. 바로 패턴 매칭이에요. 패턴 매칭을 사용하면 값을 하나 이상의 _패턴_과 비교해 볼 수 있어요. 이런 패턴의 한 예가 _상수 패턴_으로, 값을 상수(예: `1` 또는 `"hello"`)와 비교해요.

F#에서는 `match` 키워드로 패턴 매칭을 해요:

```fsharp
let describe number =
    match number with
    | 0 -> "Zero"
    | 1 -> "One"
```

다른 언어의 `switch` 문과 비슷해 보일 수도 있지만, 패턴 매칭은 다른 패턴들도 함께 사용할 때 진가를 발휘해요. 그런 패턴 중 하나가 _변수 패턴_으로, 값을 캡처할 수 있게 해줘요:

```fsharp
match number with
| 0 -> "Zero"
| i -> sprintf "Non zero: %d" i
```

경우에 따라 패턴에 조건을 하나 더 추가하고 싶을 때도 있어요. 이것을 _가드_(절)라고 하며, `when` 키워드로 추가할 수 있어요:

```fsharp
match number with
| 0 -> "Zero"
| i when i < 0 -> "Negative number"
```

위 예시에서는 가능한 모든 입력에 대응하는 패턴이 있는 것은 아니에요. 컴파일러가 이를 감지하고 경고를 출력해요. 이것을 _철저한 검사_라고 해요. 경고를 없애려면 모든 경우를 처리해야 해요. 이때 사용할 수 있는 것이 _와일드카드 패턴_으로, 어떤 값과도 일치하는 패턴이에요:

```fsharp
match number with
| i when i < 0 -> "Negative number"
| _ -> "Positive number"

// No compiler warning
```

패턴 매칭은 값을 위에서 아래로 각 패턴과 비교하면서, 일치하는 패턴을 찾아 그 패턴에 연결된 로직을 실행해요. 패턴의 순서가 중요해요!
