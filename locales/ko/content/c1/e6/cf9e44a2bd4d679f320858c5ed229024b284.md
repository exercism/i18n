# 안내 추가

## 입력 형식

각 입력 목록은 널 종료 문자열로 표현돼요. 각 입력의 끝에는 줄바꿈 문자가 있어요.

예를 들면 `"nail\nshoe\nhorse\nrider\nmessage\nbattle\nkingdom\n"`와 같아요.

## 레지스터

| 레지스터 | 용도      | 타입 | 설명                                                     |
| -------- | --------- | ---- | -------------------------------------------------------- |
| `$a0`    | 입력      | 주소 | 각 입력 뒤에 줄바꿈 문자가 오는 널 종료 입력 문자열       |
| `$a1`    | 입출력    | 주소 | 널 종료 출력 문자열                                      |
| `$t0-9`  | 임시      | 임의 | 임시 저장용                                              |
