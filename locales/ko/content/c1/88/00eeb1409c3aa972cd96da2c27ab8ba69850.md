# 지시사항 추가

## 힌트

이 연습 문제를 완료하려면 `Eq`와 `Show` 인스턴스를 가진 `CustomSet` 데이터 타입을 만들고, 다음 함수들을 구현해야 해요:

- `delete`
- `difference`
- `empty`
- `fromList`
- `insert`
- `intersection`
- `isDisjointFrom`
- `isSubsetOf`
- `member`
- `null`
- `size`
- `toList`
- `union`

더미 데이터 선언과 타입 시그니처는 이미 자리 잡고 있지만, 함수를 정의하고 의미 있는 데이터 타입이나 newtype, 타입 동의어를 만드는 것은 직접 해야 해요.

효율적인 구현을 작성하는 데 관심이 있지만 어디서부터 시작해야 할지 잘 모르겠다면, 제가 아는 가장 좋은 입문서는 Chris Okasaki의 "Purely Functional Data Structures"예요. 이 책의 한 버전은 여기에서 읽을 수 있어요:
https://www.cs.cmu.edu/~rwh/theses/okasaki.pdf
