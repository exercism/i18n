# 개요

## 함수 타입

함수 시그니처는 함수 이름 뒤에 쉼표로 구분된 매개변수 레이블과 그 타입들을 나열하고, 그 뒤에 `->`와 함수가 반환하는 값의 타입을 붙여 정의한다는 것을 앞서 살펴봤어요.

이 시그니처에서 이름과 레이블을 모두 없애면 [함수의 타입][function-types]만 남아요.

```swift
func shoppingList(item: String, quantity: Int) -> String {
  "You need to buy \(quantity) \(item)."
}
// shoppingList: (String, Int) -> String

func repeater(_ phrase: String, times: Int) -> String {
  var result = ""
  for _ in 1...times {
    result += phrase
  }
  return result
}
// repeater: (String, Int) -> String

func printString(line: String) {
  print(line)
}
// printString: (String) -> ()
```

처음 두 함수의 타입이 `(String, Int) -> String`으로 같다는 점을 눈여겨봐요. 두 함수가 하는 일은 아주 다른데도요. 둘 다 `String`과 `Int`를 입력으로 받고 `String`을 반환해요. 그리고 세 번째 함수의 타입에서 볼 수 있듯이, 이 함수는 아무것도 반환하지 않는 것처럼 보여도 실제로는 `Void` 타입의 유일한 값인 `()`를 반환해요. `()`와 `Void`는 타입 이름으로 서로 바꿔 쓸 수 있으므로 `printString`의 타입은 `String) -> Void`로 쓸 수도 있다는 점을 기억해 둬요.

이런 타입은 Swift의 다른 타입과 같은 방식으로 쓸 수 있어요. 예를 들어 변수나 상수를 선언할 때 사용할 수 있죠. 그리고 Swift에서 함수는 값이므로, 이미 있는 함수를 이런 상수나 변수에 대입할 수 있어요:

```swift
var stringAndIntToString: (String, Int) -> String

stringAndIntToString = shoppingList
stringAndIntToString("carrots", 3)
// => "You need to buy 3 carrots."

stringAndIntToString = repeater
stringAndIntToString("carrots", 3)
// => "carrotscarrotscarrots"
```

다른 변수나 상수와 마찬가지로, 여기에 대입하는 값은 올바른 타입이어야 해요:

```swift
stringAndIntToString = printShoppingList
// Error: Cannot assign value of type '(String) -> ()' to type '(String, Int) -> String'
```

## 매개변수 타입으로서의 함수 타입

함수 타입은 다른 타입을 쓸 수 있는 곳이면 어디든 쓸 수 있으므로, [매개변수 타입으로도 쓸 수 있고][functions-as-parameters] 다른 함수에 전달해 그 함수 안에서 호출할 수도 있어요.

```swift
func apply3(to str: String, function f: (String, Int) -> String) -> String {
  f(str,3)
}
// apply3: ([String], (String, Int) -> String) -> [String]

apply3(to: "eggs", function: shoppingList)
// => "You need to buy 3 eggs."

apply3(to: "eggs", function: repeater)
// => "eggseggseggs"

func apply(functions fs: [(String, Int) -> String],
           to string: String,
          ) -> [String] {
  var result = [String]()
  for f in fs {
    result.append(f(string, 3))
  }
  return result

}
// apply: ([(String, Int) -> String], String) -> [String]


apply(functions: [shoppingList, repeater], to: "carrots")
// => ["You need to buy 3 carrots.", "carrotscarrotscarrots"]
```

## 반환 타입으로서의 함수 타입

마찬가지로 [함수 타입은 함수의 반환 타입으로도 쓸 수 있어요][functions-as-returns]. 다시 말해, 다른 함수를 만들어 반환하는 함수를 작성할 수 있죠. 이런 함수를 만들 때 반환되는 함수는, 그 함수에 전달된 다른 매개변수나 바깥 함수 안에서 만들어진 지역 변수를 사용할 수 있어요.

```swift
func makeAdder(base: Int) -> (Int) -> Int {
  func adder(_ i: Int) -> Int {
    base + i
  }
  return adder
}
// makeAdder: (Int) -> (Int) -> Int

let add10 = makeAdder(base: 10)
// add10: (Int) -> Int

let subtract20 = makeAdder(base: -20)
// subtract10: (Int) -> Int

add10(5)
// => 15

subtract20(5)
// => -15
```

## 값 캡처하기

위의 `makeAdder(base:)` 함수에서 봤듯이, 중첩 함수는 자신을 둘러싼 함수의 매개변수와 변수에 접근할 수 있어요. 게다가 둘러싼 함수가 끝난 뒤에도 이 값들에 대한 접근을 유지할 수 있죠. 이렇게 접근 권한을 얻고 유지하는 동작을 [_캡처_][capturing-values]라고 해요.

## 고차 함수

함수를 매개변수로 받거나 함수를 반환하는 함수를 고차 함수라고 해요. Swift는 여러 라이브러리에서 다양한 고차 함수를 제공해요. 예를 들어 `Array` 같은 Swift 컬렉션에서 쓸 수 있는 `sorted(by:)` 메서드는, 원소 타입이 `T`인 배열에 대해 `(T, T) -> Bool` 타입의 함수를 받아요. 이 함수는 정렬된 배열에서 두 값 중 어느 것이 먼저 와야 하는지를 정하는데, 왼쪽 값이 먼저 와야 하면 `true`를, 오른쪽 값이 먼저 와야 하면 `false`를 반환해요.

또 다른 예로 컬렉션의 `contains(where:)` 메서드가 있어요. 원소 타입이 `T`인 컬렉션에 대해 `(T) -> Bool` 타입의 함수를 받는데, 이 함수는 원소가 어떤 조건을 만족하면 `true`를, 그렇지 않으면 `false`를 반환해요. 그러면 `contains(where:)`는 컬렉션의 원소 중 이 조건을 만족하는 것이 있으면 `true`를 반환해요.

```swift
func longer(_ strA: String, _ strB: String) -> Bool {
  strA.count > strB.count
}
// longer: (String, String) -> Bool

["apple", "ball", "carrot"].sorted(by: longer)
// => ["carrot", "apple", "ball"]

["apple", "ball", "carrot"].sorted(by: >)
// => ["carrot", "ball", "apple"]


func isBig(_ i: Int) -> Bool {
  i > 100
}
// isBig: (Int) -> Bool

func isVowel(_ char: Character) -> Bool {
  switch char.lowercased() {
  case "a", "e", "i", "o", "u": return true
  default: return false
  }
}
// isVowel: (Character) -> Bool

[1, 75, 3, 99].contains(where: isBig)
// => false

"Owl".contains(where: isVowel)
// => true

```
