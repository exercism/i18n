# 지침 추가

## 정렬 패키지

이 연습 문제에서는 배열을 정렬해야 하는데, 이 기능은 표준 라이브러리에 내장되어 있지 않아요. 직접 정렬 라이브러리를 작성할 수도 있지만, [sorts 패키지](https://github.com/diku-dk/sorts)를 사용하는 편이 더 좋아요.

솔루션 디렉터리에서 다음 명령을 실행하면 이 패키지를 솔루션에서 사용할 수 있어요:

```shell
futhark pkg add github.com/diku-dk/sorts
futhark pkg sync
```

그런 다음, [원하는 정렬 알고리즘](https://github.com/diku-dk/sorts/tree/master/lib/github.com/diku-dk/sorts)을 다음과 같이 가져와요:

```futhark
import "lib/github.com/diku-dk/sorts/<sorting algorithm>"
```
