# 소개

SGF(Smart Game Format)는 보드 게임의 기보를 저장하는 데 널리 쓰이는 텍스트 기반 파일 형식이에요. 체스, 오셀로, 백개먼 등 여러 게임에 쓸 수 있지만, 바둑에서 가장 널리 알려져 있고 많이 사용돼요.

SGF 파일은 노드의 트리 구조로 되어 있어요. 이런 트리 구조는 기보가 여러 갈래로 나뉠 수 있다는 점에서 특히 유용해요. 즉, 주요 수순은 물론 대안 변화, 분석, 해설까지 모두 같은 파일에 저장할 수 있어요.

트리의 각 노드에는 여러 속성이 들어 있고, 각 속성은 하나 이상의 값을 가져요. 이 속성들은 대국자의 이름과 기력부터 대국 결과, 바둑판 크기, 그리고 바둑판에 놓인 개별 수까지 모든 것을 담아내요.
