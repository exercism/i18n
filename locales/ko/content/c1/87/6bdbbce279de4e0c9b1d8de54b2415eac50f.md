# 소개

Elixir에서 문자열은 큰따옴표로 감싸고, UTF-8로 인코딩해요:

```elixir
"Hi!"
```

문자열은 `<>/2` 연산자로 이어 붙일 수 있어요:

```elixir
"Welcome to" <> " " <> "New York"
# => "Welcome to New York"
```

Elixir의 문자열은 `#{}` 문법으로 보간을 지원해요:

```elixir
"6 * 7 = #{6 * 7}"
# => "6 * 7 = 42"
```

문자열에 줄바꿈 문자를 넣으려면 `\n` 이스케이프 코드를 사용해요:

```elixir
"1\n2\n3\n"
```

줄바꿈이 많은 텍스트를 편하게 다루고 싶다면, 대신 큰따옴표 세 개를 쓰는 히어독 문법을 사용해요:

```elixir
"""
1
2
3
"""
```

Elixir는 `String` 모듈에서 문자열을 다루는 다양한 함수를 제공해요.
