# 소개

판별된 공용체 타입은 이름이 붙은 정해진 수의 케이스를 나타내요. 판별된 공용체의 각 값은 이름이 붙은 케이스 중 정확히 하나에 대응해요.

판별된 공용체는 `type` 키워드로 정의하고, 각 케이스는 파이프(`|`) 문자로 구분해요:

```fsharp
type Season =
    | Spring
    | Summer
    | Autumn
    | Winter
```

판별된 공용체의 각 케이스에는 선택적으로 데이터를 연결할 수 있고, 케이스마다 서로 다른 타입의 데이터를 가질 수 있어요. 어떤 케이스에도 데이터가 연결되어 있지 않다면, 그 판별된 공용체는 다른 언어에서 흔히 _열거형_(_enum_)이라고 부르는 것과 비슷해요.

```fsharp
type Number =
    | Integer of int
    | Float of float
    | Invalid
```

특정 케이스의 값을 만들려면 그 케이스의 이름을 그대로 사용하면 돼요(예: `Success`). 케이스 이름은 그냥 생성자 함수이기 때문에, 연결된 데이터는 일반 함수 인자처럼 넘겨줄 수 있어요. 다른 판별된 공용체에 같은 이름의 케이스가 정의되어 있다면, 전체 이름을 써야 해요(예: `Result.Success`).

```fsharp
let byName = Integer 2
let byFullName = Number.Invalid
```

판별된 공용체는 _구조적 동등성_을 가져요. 이는 같은 케이스이면서 (선택적) 데이터까지 같은 두 값이 서로 같다는 뜻이에요.

`if/elif/else` 식으로도 판별된 공용체를 다룰 수 있지만, 권장하는 방법은 _식별자 패턴_을 사용한 패턴 매칭이에요:

```fsharp
let describe number =
    match number with
    | Integer i -> sprintf "Integer: %d" i
    | Float d  -> sprintf "Float: %f" d
    | Invalid   -> "Invalid"
```
