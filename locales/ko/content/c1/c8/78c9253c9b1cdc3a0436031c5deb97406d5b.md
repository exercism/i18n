# 소개

연결은 코드의 어느 위치에서 식별자에 접근할 수 있는지를 설명해요.
블록 스코프, 함수 스코프, 함수 원형 스코프를 가지는 값은 연결을 가지지 않아요.
즉, 자신의 스코프 밖에서는 접근할 수 없어요.
스코프에 대한 더 자세한 내용은 [스코프 개념](../scope/introduction.md#Introduction)을 참고해요.

## 외부 연결

파일 스코프를 가지는 식별자는 기본적으로 외부 연결을 가져요.
외부 연결을 가지는 식별자는 프로그램의 어떤 파일에서든 호출할 수 있어요.

## 내부 연결

파일 스코프를 가지는 식별자는 `static` 지정자를 사용해서 내부 연결을 가지도록 만들 수 있어요.
내부 연결을 가지는 식별자는 자신의 파일 안에서만 사용할 수 있어요.

예를 들어

```c
int public_count = 0; // file scope, external linkage by default
static int private_count = 0;  // file scope, internal linkage 

// file scope, internal linkage
static void some_function()
{
    // code snipped
}

// file scope, external linkage by default
int main()
{
    // code snipped
}
```

정적 연결을 정적 저장 기간과 혼동하면 안 돼요.
정적 저장 기간에 대한 더 자세한 내용은 [저장 기간 개념](https://github.com/exercism/c/blob/main/concepts/storage-class-specifiers/about.md#static-the-storage-specifier-not-to-be-confused-with-the-static-linkage-type)을 참고해요.
