# 지시사항

이 연습 문제에서는 로그 라인을 처리해요.

각 로그 라인은 다음과 같은 형식의 문자열이에요: `"[<LVL>]: <MESSAGE>"`.

로그 레벨은 다음과 같아요:

- `TRC` (추적)
- `DBG` (디버그)
- `INF` (정보)
- `WRN` (경고)
- `ERR` (오류)
- `FTL` (치명적)

세 가지 작업을 해봐요.

## 1. 로그 레벨 파싱

위 로그 레벨에 대응하는 여섯 개의 원소를 가진 `LogLevel` enum을 정의해요.

- `TRACE`
- `DEBUG`
- `INFO`
- `WARNING`
- `ERROR`
- `FATAL`

다음으로, 로그 라인을 파싱한 로그 레벨을 반환하는 `LogLine.getLogLevel()` 메서드를 구현해요:

```java
var logLine = new LogLine("[INF]: File deleted");
logLine.getLogLevel();
// => LogLevel.INFO
```

## 2. 알 수 없는 로그 레벨 처리

안타깝게도, 때때로 알 수 없는 로그 레벨을 가진 로그 라인이 있어요.
이런 로그 라인을 매끄럽게 처리하려면, `LogLevel` enum에 `UNKNOWN` 원소를 추가해요. 이 원소는 알 수 없는 로그 레벨을 파싱할 때 반환돼요:

```java
var logLine = new LogLine("[XYZ]: Overly specific, out of context message");
logLine.getLogLevel();
// => LogLevel.UNKNOWN
```

## 3. 로그 라인을 짧은 형식으로 변환

로그 라인의 로그 레벨은 꽤 장황해요.
로그 라인을 저장하는 데 필요한 디스크 공간을 줄이기 위해 짧은 형식이 개발됐어요: `"[<ENCODED_LEVEL>]:<MESSAGE>"`.

인코딩된 로그 레벨은 로그 레벨을 숫자로 단순하게 매핑한 것이에요:

- `UNKNOWN` - `0`
- `TRACE` - `1`
- `DEBUG` - `2`
- `INFO` - `4`
- `WARNING` - `5`
- `ERROR` - `6`
- `FATAL` - `42`

축약된 로그 라인 형식을 출력할 수 있는 `LogLine.getOutputForShortLog()` 메서드를 구현해요:

```java
var logLine = new LogLine("[ERR]: Stack Overflow");
logLine.getOutputForShortLog();
// => "6:Stack Overflow"
```
