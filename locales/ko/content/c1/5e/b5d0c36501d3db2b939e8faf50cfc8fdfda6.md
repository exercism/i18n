# 소개

Common Lisp에서 시간은 네 가지 방식으로 표현되는데, 그중 여기서는 두 가지를 다뤄볼게요.

- 유니버설 타임은 절대 시간으로, `1900-01-01T00:00:00Z`(UTC 기준 1900년 1월 1일 자정) 이후 지난 초 수를 나타내는 정수예요.
- 디코딩된 시간은 특정 달력 시각을 함께 나타내는 9개 값의 튜플이에요: 초, 분, 시, 일, 월, 연도, 요일, 서머타임 플래그, 시간대.
(아래에서 자세히 다뤄요.)

## 유니버설 타임

현재 유니버설 타임을 구하려면 `get-universal-time` 또는 `get-decoded-time`을 사용해요.
앞의 함수는 `1900-01-01T00:00Z` 이후 현재까지의 초를 반환하고, 뒤의 함수는 같은 데이터를 디코딩된 형식으로 반환해요.

## 디코딩된 시간

`decode-universal-time`과 `encode-universal-time`은 시간을 다루는 기본 함수예요.
앞의 함수는 유니버설 타임을 받아 [multiple-values][concept-multiple-values]로 디코딩된 시간 값을 반환하고, 뒤의 함수는 디코딩된 시간 값들을 인자로 받아 유니버설 타임을 반환해요.

두 함수 모두 선택적인 시간대 인자를 받아요.
시간대의 형식은 아래를 참고해요.

디코딩된 시간은 다음과 같은 값들로 이루어져 있어요:

- *초*: 0에서 59 사이의 정수
- *분*: 0에서 59 사이의 정수
- *시*: 0에서 23 사이의 정수
- *일*: 1에서 31 사이의 정수 (물론 상한은 월과 연도에 따라 달라져요)
- *월*: 1에서 12 사이의 정수
- *연도*: 연도를 나타내는 정수.
- *요일*: 0에서 6 사이의 정수. 0은 월요일, 1은 화요일 등을 나타내고, 6은 일요일이에요.
- *서머타임 플래그*: 참이면 서머타임이 적용 중임을 나타내는 값.
- *시간대*: UTC로부터의 오프셋을 나타내는 -24에서 24 사이의 시간 수.
이 수는 유리수이며 `1/3600`의 배수여야 해요.

```lisp
(encode-universal-time 1 2 3 4 5 2000 0) ; => 3166398121
(decode-universal-time 3166398121)       ; => 1
                                         ;    2
                                         ;    3
                                         ;    4
                                         ;    5
                                         ;    2000
                                         ;    3 (Thursday)
                                         ;    NIL
                                         ;    0
(decode-universal-time 2208988800) ; => 0
                                   ;    0
                                   ;    0
                                   ;    1
                                   ;    1
                                   ;    1970
                                   ;    3
                                   ;    NIL
                                   ;    0
```
