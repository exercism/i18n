# 소개

## 큐

Gleam 표준 라이브러리는 `gleam/queue` 모듈에서 `Queue` 타입을 구현해요. `List` 타입과 비슷하지만 몇 가지 중요한 차이가 있어요:

- `Queue` 타입에는 큐를 만들거나 패턴 매칭에 사용할 수 있는 리터럴 문법이 없어요.
- `Queue` 타입은 앞과 뒤 양쪽에서 원소를 효율적으로 추가하고 제거할 수 있지만, `List` 타입은 앞에서만 원소를 효율적으로 추가하고 제거할 수 있어요.

대부분의 경우에는 `List` 타입을 쓰는 게 좋지만, 컬렉션의 끝에서 원소를 추가하고 제거해야 할 때는 `Queue` 타입이 좋은 선택이에요.

큐는 `queue.new`와 `queue.from_list` 함수로 만들 수 있어요:

```gleam
let empty = queue.new()
let one_to_four = queue.from_list([1, 2, 3, 4])
```

큐에는 `queue.push_front`와 `queue.push_back` 함수로 원소를 추가할 수 있어요:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
let one_to_five = queue.push_back(one_to_four, 5)
let zero_to_five = queue.push_front(one_to_five, 0)
```

큐에서는 `queue.pop_front`와 `queue.pop_back` 함수로 원소를 제거할 수 있어요:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])

queue.pop_back(one_to_four)
// -> Ok(#(4, queue.from_list([1, 2, 3])))

queue.pop_front(one_to_four)
// -> Ok(#(1, queue.from_list([2, 3, 4])))

queue.pop_front(queue.new())
// -> Error(Nil)
```

큐는 `queue.to_list` 함수로 배열로 변환할 수 있어요:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
queue.to_list(one_to_four)
// -> [1, 2, 3, 4]
```

### 큐의 동등성

큐가 구현된 방식 때문에, 같은 원소를 같은 순서로 가진 두 큐라도 구조적으로 값을 비교하는 `==` 연산자에 따르면 같지 않을 수 있어요. 예를 들어요:

```gleam
let empty = queue.new()
let a = queue.push_front(empty, 1)
let b = queue.push_back(empty, 1)
a == b
// -> False
```

두 큐가 같은지 비교해야 한다면 `queue.is_logically_equal` 함수를 사용할 수 있어요.

```gleam
queue.is_logically_equal(a, b, fn(x, y) { x == y })))
// -> True
```
