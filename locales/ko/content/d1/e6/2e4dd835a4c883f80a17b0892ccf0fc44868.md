# Case

[`case`][case]는 다른 언어에서 흔히 switch라고 부르는, if-else와 같은 제어 표현식의 한 형태예요.
`case`를 사용하면 여러 if-else-if 문을 이어 붙일 수 있고, 코드가 더 읽기 쉬워지며, 강력한 구성도 만들 수 있어요.

`case`는 `case` 키워드 뒤에 선택적인 표현식을 붙여 정의해요.
그다음 각 경우마다 `when` 키워드를 사용하고, 그 뒤에 케이스 표현식과 비교할 표현식을 적어요.
`when` 키워드는 `case` 키워드보다 더 들여쓰지 않아요.
`when` 키워드 뒤에는 케이스 표현식이 when 표현식과 일치할 때 실행할 코드를 적어요.
`case`는 선택적인 `else` 문을 가질 수 있는데, 이 문은 다른 어떤 경우에도 일치하지 않을 때 실행돼요.

케이스 표현식을 평가한 다음, 각 when 표현식과 비교해요.
이 비교에는 [케이스 포섭 연산자(`===`)][case-subsumption]를 사용해요.

```Crystal
case 1
when 1
  puts "One"
when 2
  puts "Two"
else
  puts "Other"
end
# => One

# This is the same as:
tmp = 1
if 1 === tmp
  puts "One"
elsif 2 === tmp
  puts "Two"
else
  puts "Other"
end
```

## 케이스 포섭 연산자(`===`)

케이스 포섭 연산자(`===`)는 동등 연산자(`==`)와 조금 달라요.
이 연산자는 오른쪽 값이 왼쪽 값이 나타내는 집합의 원소인지 확인해요.
즉, 각 피연산자를 어느 쪽에 두는지가 중요해요.
어떻게 동작하는지는 왼쪽 값의 타입에 따라 달라요. 예를 들어 `Range`는 오른쪽 값이 범위 안에 있는지 확인하고, `Object`는 오른쪽 값이 `Object`의 인스턴스인지 확인해요.

```Crystal
(1..3) == 1  # => false
(1..3) === 1 # => true

String == "foo"  # => false
String === "foo" # => true
```

## 여러 표현식을 사용하는 case

각 값을 쉼표로 구분하면 하나의 when에 여러 표현식을 일치시킬 수 있어요.
표현식 중 하나라도 일치하면 코드를 실행해요.
하나의 경우에 가능한 값이 여러 개일 때 유용해요.

```Crystal
case 1
when 1, 2
  puts "One or two"
else
  puts "Other"
end
```

## 범위를 사용하는 case

`case`는 값이 범위 안에 있는지도 확인할 수 있어요.
when 표현식에 범위를 적으면 돼요.

```Crystal
case var
when 1..3
  puts "One to three"
else
  puts "Other"
end
```

## 케이스 표현식이 없는 case

케이스 표현식이 필요 없으면 생략할 수 있어요.
이렇게 하면 각 when 표현식이 참인지 평가하게 돼요.
그래서 if-else-if 문처럼 동작해요.

```Crystal
case
when 1 == 1
  puts "One is equal to one"
when 1 > 2
  puts "One is greater than two"
else
  puts "Other"
end
```

## 한 줄 when

Crystal은 `case` 문을 한 줄로 쓸 수 있어요.
간단한 한 줄짜리 문이 있을 때 사용할 수 있어요.
한 줄로 쓸 때는 `when <expression> then <statement>.` 형태로 적어요.
`else` 문에서 사용할 때는 `else <statement>` 형태로 적어요.

```Crystal
case var
when 1 then puts "One"
when 2 then puts "Two"
else puts "Other"
end
```

## 타입과 함께 사용하는 case

`case`는 타입과도 일치시킬 수 있어요.
이때는 `is_a?` 연산자로 변수의 타입을 확인해요.
예를 들어 유니언 타입에서 각 타입마다 분기를 하나씩 만들 수 있어요.

```Crystal
case var
when Int32
  puts "Int32"
when String
  puts "String"
else
  puts "Other"
end
```

## 암시적 객체

`case`는 암시적 객체를 사용할 수 있어요.
예를 들어 when 표현식을 케이스 표현식에 대한 메서드 호출로 쓸 수 있어요.
메서드가 참 같은 값을 반환하는지 거짓 같은 값을 반환하는지에 따라 일치 여부가 결정돼요.

```Crystal
case 1
when .odd?
  puts "Odd"
when .even?
  puts "Even"
end
```
