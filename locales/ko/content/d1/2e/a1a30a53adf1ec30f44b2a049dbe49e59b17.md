# 소개

많은 언어에는 존재하지 않는 값을 나타내기 위해 `null`이나 `none` 같은 방법이 있어요. Julia는 (흔히 정돈되지 않은) 대량의 데이터를 다루도록 설계되었기 때문에, 없음을 나타내는 여러 가지 형태를 갖고 있어요.

전체적인 목표는 빠졌거나 의심스러운 값을 만나는 즉시 표시하고, 예외를 발생시키지 않으면서 계속 진행하는 것이에요.

## `nothing`

값이 정말로 존재하지 않는다면, 그 값은 `nothing`으로 표현해요. 아마도 C의 `NULL`이나 Python의 `None`에 가장 가까운 방식일 거예요.

```julia-repl
julia> n = nothing

julia> isnothing(n)
true

julia> typeof(n)
Nothing
```

즉 `nothing`은 `Nothing` 타입의 유일한 값이고, 이 값을 검사할 수 있어요.

`nothing`의 흔한 용도 중 하나는 부수 효과(출력, 네트워크 설정 등)만을 목적으로 하는 함수의 반환 (비)값이에요.

## `missing`

이론적으로는 값이 존재하지만 그것이 무엇인지 모르는 상황에서는 `missing`을 사용해요. 예를 들어 도로를 지나는 차량을 셀 때, 사람 관측자가 쉬어야 할 수도 있고 자동 센서가 고장 날 수도 있지만 교통은 계속 흘러가죠.

따라서 `missing`은 자리 표시자로서, 데이터의 이 빈틈을 어떻게 다룰지 결정해야 한다고 사람에게 알려주는 역할을 해요.

```julia-repl
julia> mv = [1, 2, missing]
3-element Vector{Union{Missing, Int64}}:
 1
 2
  missing

julia> typeof(mv)
Vector{Union{Missing, Int64}} (alias for Array{Union{Missing, Int64}, 1})

julia> ismissing.(mv)  # broadcast function, displays as 1 for true, 0 for false
3-element BitVector:
 0
 0
 1
```

다른 언어 중에 이 기능을 기본으로 제공하는 경우는 드물지만, 비슷한 예로 R의 `NA`나 SQL의 `NULL`이 있어요.

`missing` 값이 있으면 표현식은 보통 기본적으로 `missing`을 반환해요. 이런 값을 무시하고 싶다면, `skipmissing()` 함수를 사용해서 의도를 분명히 밝혀요.

```julia-repl
julia> mv = [1, 2, missing]
3-element Vector{Union{Missing, Int64}}:
 1
 2
  missing

julia> sum(mv)  # missing in, missing out
missing

julia> skipmissing(mv)
skipmissing(Union{Missing, Int64}[1, 2, missing])

julia> collect(skipmissing(mv))
2-element Vector{Int64}:
 1
 2

julia> sum(skipmissing(mv))  # functions like sum() can work with iterators
3
```

`skipmissing`은 이터레이터를 만들어 내므로, 벡터가 필요하다면 `collect()`로 감싸요.

때로는 `missing` 값을 어떤 기본값으로 바꾸는 게 유용해요. `@coalesce()` 매크로가 이런 경우에 유용한데, 처음 나오는 missing이 아닌 값을 반환하기 때문이에요 (다른 값이 없으면 `missing`을 반환해요).

```julia-repl
julia> str = ["I", "exist", missing]
3-element Vector{Union{Missing, String}}:
 "I"
 "exist"
 missing

julia> [@coalesce(s, "-") for  s in str]
3-element Vector{String}:
 "I"
 "exist"
 "-"
```

## `NaN`

"Not a Number"의 줄임말인 NaN은 숫자가 있어야 할 상황에서 계산에 문제가 생겼음을 알려줘요.

```julia-repl
julia> v = [0, 1, -1]
3-element Vector{Int64}:
  0
  1
 -1

julia> v / 0
3-element Vector{Float64}:
 NaN
  Inf
 -Inf
 
julia> sum(v / 0)
NaN
```

NaN이 포함된 데이터에 어떤 계산을 해도 결과는 `NaN`이 돼요.

현재 `NaN` 값을 제거하는 특별한 함수는 없지만, 표준 `filter()` 함수로 아주 간단히 처리할 수 있어요. 주어진 조건이 `true`인 값만 결과 배열에 복사돼요.

```julia-repl
julia> filter(!isnan, [1, 2, NaN])
2-element Vector{Float64}:
 1.0
 2.0
```
