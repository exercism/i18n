# 테스트 실행

`sbt`가 설치되어 있으면, 명령줄에서 다음 명령으로 테스트를 실행할 수 있어요:

```bash
$ sbt test
```

`sbt test`를 매번 실행하면 호출할 때마다 `sbt`를 다시 초기화하기 때문에 느려요.

`sbt`는 셸처럼 동작해서, 한 번 시작하면 그 안에서 명령을 실행할 수 있어요.

예를 들어, 소스 파일이 바뀔 때마다 `sbt`로 테스트를 다시 실행할 수 있어요:
```bash
$ sbt
>~ test
```

작업할 수 있도록 첫 번째 테스트를 제외한 모든 테스트는 비활성화되어 있어요.
계속하려면 각 테스트 케이스의 맨 앞에서 `pending` 키워드를 지우기만 하면 돼요.

`sbt`에 대해 더 알아보려면 [여기](https://www.scala-sbt.org/)를 방문해요.


테스트는 다음 IDE에서도 실행할 수 있어요

* [Metals](https://scalameta.org/metals/docs/#running-tests)
* [Scala 플러그인이 있는 IntelliJ IDEA](https://www.jetbrains.com/idea/)
