# PowerShell 배우기

PowerShell을 배우기 시작하기에 좋은 곳은 PowerShell 웹사이트의 [학습 섹션][learning section]에서 학습 자료를 하나 고르는 거예요.
이곳에는 방대한 양의 정보가 있고, 다양한 PowerShell 주제로 가는 링크도 있어요.

PowerShell에는 아주 잘 갖춰진 자체 문서화 도움말 시스템도 있어요.
`Get-Help` cmdlet을 사용하면 PowerShell이 제공하는 많은 기능을 살펴볼 수 있어요.
PowerShell 안에서 다음을 실행해 봐요:

```PowerShell
Get-Help about
```

살펴볼 수 있는 주제가 약 3페이지 분량 나와요.
그 밖에도 아주 유용하게 쓸 수 있는 두 가지 함수가 있어요:

- Get-Command
- Get-Member

이것들이 무슨 일을 하는지 궁금하죠?
그렇다면 물론 `Get-Help Get-Command`와 `Get-Help Get-Member`를 실행해 보면 돼요.

## PowerShell 동사와 명사

PowerShell은 cmdlet 이름을 지을 때 꽤 엄격한 동사-명사 규칙을 따라요.
처음에는 이런 규칙이 경험 많은 프로그래머에게 낯설게 느껴질 수 있어요.
함수 이름은 원하는 대로 지어도 되지만, 표준 동사에 익숙해지고 그것을 받아들이면 PowerShell 코딩이 더 좋아져요.

승인된 모든 동사 목록을 보려면 다음을 실행해요:

```PowerShell
Get-Verb
```
