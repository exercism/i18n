# 소개

문자 클래스와 수량자를 넘어서, 정규 표현식은 *구조*와 *문맥*을 표현할 수 있어요. 이런 기능들도 같은 [`regexp`][regexp] 어휘와 같은 `R/ /` 리터럴을 그대로 사용해요.

둥근 괄호 `( )`는 패턴의 일부를 묶어서, 수량자나 `|` ("이것 또는 저것")가 그룹 전체에 적용되게 해요. 그룹 뒤에 `?`를 붙이면 그 그룹이 선택 사항이 돼요:

```factor
USING: regexp ;

"abab"    R/ (ab)+/ matches? .             ! => t
"$100"    R/ \$\d+(\.\d{2})?/ matches? .   ! => t   (optional group)
```

앵커는 패턴을 특정 위치에 고정해요: `^` (시작), `$` (끝), `\b` (단어 경계).

*전후방 탐색*은 어떤 지점 자체는 소비하지 않고 그 주변을 기준으로 일치시켜요:

```
(?=...)    ! lookahead — ... must follow
(?!...)    ! negative lookahead — ... must not follow
(?<=...)   ! lookbehind — ... must come before
```

```factor
USING: regexp ;

"spent $100 and $25" R/ (?<=\$)\d+/ all-matching-subseqs .
! => { "100" "25" }

"up 5% then 12%" R/ \d+(?=%)/ all-matching-subseqs .
! => { "5" "12" }
```

닫는 `/` 뒤에 오는 옵션 문자는 패턴 전체를 바꿔요. `i`를 붙이면 대소문자를 구분하지 않게 돼요:

```factor
USING: regexp ;

"REFUND" R/ refund/i matches? .   ! => t
```

Factor는 캡처 그룹 대신 전후방 탐색을 사용해요. 캡처 그룹 추출이나 역참조, 게으른 수량자는 지원하지 않아요.
