# 지침 추가

## Arturo 관련 정보

이 연습 문제에서는 해당 행성의 1년 길이를 나타내는 사용자 정의 단위를 가진 [물리량][physical-quantities]을 사용해 나이를 반환해야 해요.
Arturo에서 quantity는 숫자 값과 그에 딸린 [측정 단위][unit-of-measurement]로 이루어져 있어요.

```arturo
length: 10`m
units length ; `m
scalar length ; 10

10`m * 10`m ; 100 m²
```

~~~~exercism/caution
Arturo의 내장 `yr 단위는 31556952초로 변환돼요.
따라서 앞서 지침에서 언급한 초를 기준으로 직접 연 단위를 정의해 사용해야 해요.
~~~~

quantity는 호환되는 다른 단위로 [변환][convert]할 수 있어요.
```arturo
convert 1`m `ft ; 1250/381 ft
convert 100`m2 `ft2 ; 156250000/145161 ft²

property `m  ; length
property `m2 ; area

convert 1`m `m2 ; conversion error results
```

~~~~exercism/note
부동소수점 숫자의 정밀도 한계 때문에 Arturo는 스칼라를 유리수로 저장하기도 해요.
대신 [`to` 함수][to]를 사용하면 그 값을 근사 부동소수점 숫자로 가져올 수 있어요.

```arturo
length: convert 1`m `ft ; 1250/381 ft
to :floating length ; 3.280839895013123
```

[to]: https://arturo-lang.io/documentation/library/types/to/
~~~~

Arturo에서는 quantity에 쓸 자신만의 단위를 [지정][specify]할 수도 있어요.

```arturo
specify 'nauMile 1.151`mi
property `nauMile length
specify 'lea 3.00579`nauMile
property `lea ; length
depth: 20000`lea
convert depth `km ; 111355.7993425152 km
```
