# 소개

## 부동소수점 수

부동소수점 수는 소수점 뒤에 자릿수가 0개 이상 있는 수예요. `-2.4`, `0.1`, `3.14`, `16.984025`, `1024.0` 같은 것이 예예요.

부동소수점 타입마다 소수점 뒤에 저장할 수 있는 자릿수가 달라요. 이 자릿수를 정밀도라고 해요.

C#에는 부동소수점 타입이 세 가지 있어요:

- `float`: 4바이트(정밀도 약 6~9자리). `2.45f`로 써요.
- `double`: 8바이트(정밀도 약 15~17자리). 가장 흔히 쓰이는 타입이에요. `2.45` 또는 `2.45d`로 써요.
- `decimal`: 16바이트(정밀도 28~29자리). 보통 금액 데이터를 다룰 때 사용하는데, 정밀도가 높아서 반올림 오류가 생길 가능성을 줄여 주기 때문이에요. `2.45m`로 써요.

보다시피, 타입마다 저장할 수 있는 자릿수가 달라요. 예를 들어 `float`에 원주율을 저장하려고 하면 소수점 이하 첫 6자리까지만 저장돼요(마지막에 저장된 자리는 반올림돼요).

## `while`문

이 연습 문제에서는 루프를 사용하고 싶을 수 있어요. C#에서 루프를 작성하는 방법은 여러 가지지만, 여기서는 `while`문이 가장 적합해요:

```csharp
int x = 23;

while (x > 10)
{
    // Execute logic if x > 10
    x = x - 2;
}
```

## `do`/`while`문

루프 안의 코드가 항상 최소 한 번은 실행돼야 한다면, `do`/`while`문을 사용할 수 있어요:

```csharp
int x = 23;

do
{
    // Execute body, repeating only if x > 10
    x = x - 2;
} while (x > 10);
```
