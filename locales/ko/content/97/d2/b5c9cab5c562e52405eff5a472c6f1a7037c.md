# 지침

이 연습 문제에서는 여러 종류의 무선 조종 자동차 사이의 경주를 구성해요.
자동차마다 속도와 배터리 소모 특성이 각각 달라요.

자동차는 완전히 충전된(100%) 배터리로 시작해요. 무선 조종기로 자동차를 운전할 때마다 자동차는 자신의 속도에 해당하는 미터만큼 이동하고, 남은 배터리 비율은 배터리 소모량만큼 줄어들어요.

자동차의 배터리가 배터리 소모 비율보다 낮으면 더 이상 자동차를 운전할 수 없어요.

경주 트랙마다 길이가 각각 달라요. 자동차는 배터리가 다 닳기 전에 트랙을 완주할 수 있는지 확인하는 방식으로 시험해요.

## 1. 무선 조종 자동차 만들기

다음 원소를 가진 `car` 배열을 정의해요:

- speed
- battery_drain
- battery
- distance_traveled

자동차의 속도(미터)와 배터리 소모 비율을 두 매개변수로 받아 `car` 배열을 반환하는 `new_car`라는 함수를 정의해서 무선 조종 자동차를 만들 수 있어요.

새 자동차의 배터리는 100%이고 이동 거리는 0이에요.

```R
speed <- 5
battery_drain <- 2
car <- new_car(speed, battery_drain)
str(car)
#> List of 4
#>  $ speed             : num 5
#>  $ battery_drain     : num 2
#>  $ battery           : num 100
#>  $ distance_traveled : num 0
```

## 2. 경주 트랙 만들기

`track_length`라는 하나의 원소만 가진 `track`이라는 또 다른 배열을 정의해요.
트랙의 거리(미터)를 받는 `new_track`이라는 함수를 정의해서 경주 트랙을 만들 수 있어요:

```R
track_length <- 800
track <- new_track(track_length)
str(track)
#> List of 1
#>  $ track_length: num 800
```

## 3. 배터리가 닳았는지 확인하기

배터리가 닳았는지 알려 주는 `battery_drained()` 함수를 구현해요.
한 번 더 이동하기에 배터리가 충분하지 않으면 배터리가 닳은 것으로 간주해요.

```R
speed <- 5;
battery_drain <- 2;
car <- new_car(speed, battery_drain);
car <- drive(car);

battery_drained(car);
#> [1] FALSE
```

## 4. 자동차 운전하기

자동차의 속도에 따라 주행한 미터 수를 갱신하고, 배터리 소모량에 따라 배터리를 줄이는 `drive` 함수를 구현해요.
한 번 더 운전할 만큼 배터리가 남아 있지 않으면 자동차는 움직이지 않아요.

```R
speed <- 5
battery_drain <- 2
car <- new_car(speed, battery_drain)
car <- drive(car)
str(car)
#> List of 4
#>  $ speed             : num 5
#>  $ battery_drain     : num 2
#>  $ battery           : num 98
#>  $ distance_traveled : num 5
```

## 5. 무선 조종 자동차가 경주를 완주할 수 있는지 확인하기

경주를 완주하려면 자동차가 경주 거리만큼 주행할 수 있어야 해요. 이는 결승선을 통과하기 전에 배터리가 다 닳지 않아야 한다는 뜻이에요. 

`car`와 `track`을 매개변수로 받아, 자동차가 경주를 완주할 수 있으면 `TRUE`를, 그렇지 않으면 `FALSE`를 반환하는 `can_finish` 함수를 구현해요.

지금 경주의 출발선에 있고 경주를 위해 자동차의 시동을 건다고 가정해요. 경주를 시작할 때 자동차의 배터리가 반드시 완전히 충전되어 있지는 않을 수 있다는 점을 고려해요.

```R
speed <- 5
battery_drain <- 5
car <- new_car(speed, battery_drain)

name <- "track1"
track_length <- 100
track <- new_track(track_length)

can_finish(car, track)
#> [1] TRUE

# partial battery charge
car$battery <- 50
can_finish(car, track)
#> [1] FALSE
```

## 6. 완전히 충전된 배터리로 트랙을 완주할 수 있는지 저장하기

길이가 각각 다른 여러 트랙을 만들었고, 완전히 충전했을 때 자동차가 그 트랙들을 완주할 수 있는지 저장해야 해요.

자동차, 트랙, 트랙 이름을 받아 원소가 하나 추가된 갱신된 자동차를 반환하는 `store_track` 함수를 구현해요.
이 원소는 트랙의 `name`을 이름으로 하고, 값은 `track_length`와 자동차가 트랙을 완주할 수 있는지를 나타내는 `complete`를 담은 하위 배열이어야 해요.

인자로 전달된 자동차는 완전히 충전되어 있지 않을 수 있으니, 사용하기 전에 배터리와 이동 거리를 반드시 초기화해요.

```R
speed <- 5
battery_drain <- 5
car <- new_car(speed, battery_drain)
car$battery <- 50

name <- "track1"
track_length <- 100
track <- new_track(track_length)

track1 <- store_track(car, track, "Imola")
str(track1)
#> List of 5
#>  $ speed             : num 5
#>  $ battery_drain     : num 5
#>  $ battery           : num 100
#>  $ distance_traveled : num 0
#>  $ Imola             :List of 2
#>   ..$ track_length: num 100
#>   ..$ complete    : logi TRUE
```
