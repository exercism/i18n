# 설치

가장 간단한 경우에는 Red를 설치하지 않아요. 그냥 다운로드하면 바로 사용할 수 있어요.

1. 다운로드 페이지: [https://www.red-lang.org/p/download.html](https://www.red-lang.org/p/download.html) . 파일 이름은 빌드 날짜와 Git 해시로 되어 있어요. 예를 들어 `red-02mar21-6de9b93c5.exe` 같은 식이에요. 백신 프로그램이 Red에서 바이러스를 감지하더라도 겁먹지 마세요. [정상이에요](https://github.com/red/red/wiki/[NOTE]-Anti-virus-false-positives). 다운로드를 허용하고, 백신 옵션에서 Red를 안전한 프로그램으로 표시해 주면 백신이 조용해져요.

1. 원하는 곳에 저장하고 실행해요. [REPL 콘솔](https://en.wikipedia.org/wiki/Read%E2%80%93eval%E2%80%93print_loop)이 열리고, **Red 명령을 입력하기 시작하면** 결과를 바로 볼 수 있어요. 스크립트를 실행하고 싶다면 "[do](https://www.red-by-example.org/#do)" 명령을 사용해요: `do %my-dir/my-script.red` (퍼센트 기호가 중요해요. [Red의 `file!` 데이터 타입](https://github.com/red/docs/blob/master/en/datatypes/file.adoc)을 나타내는 표시예요). GUI 버전을 다운로드했다면 텍스트 콘솔 대신 멋진 창이 열리고, 거기서도 명령을 작성할 수 있어요.

1. 스크립트를 실행하는 또 다른 방법은 콘솔(그래픽이든 텍스트든)을 사용하지 않고, 스크립트 이름을 Red의 인자로 **명령줄에서** 넘기는 거예요. 예를 들어 `red.exe my-dir\my-script.red`처럼요.

1. 다운로드한 파일의 이름을 `red.exe`(Linux/Mac에서는 `red`)로 **바꾸고**, **시스템의 *PATH* 환경 변수에 추가**해 두는 게 좋아요. 그러면 어느 폴더에서든 실행할 수 있고, 다운로드한 자동 빌드 파일의 전체 이름을 기억하지 않아도 돼요. 이렇게 설정해 두면 Red를 업데이트하기도 더 쉬워요.

1. **Linux**에서는 Red에 32비트 버전의 *Curl*이 필요해요(GUI를 사용한다면 *Gtk 3*도요). Arch / Manjaro Linux용 [AUR 패키지](https://aur.archlinux.org/packages/red-nightly-bin)가 있어요.

1. **macOS**를 사용한다면 [32비트 응용 프로그램을 실행할 수 없고](https://support.apple.com/en-us/HT208436), 따라서 Red도 실행할 수 없어요.
