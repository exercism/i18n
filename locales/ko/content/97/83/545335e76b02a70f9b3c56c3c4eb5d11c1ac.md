# 지침

이 연습 문제에서는 차량 구매를 준비하는 데 도움이 되는 코드를 작성해요.

과제는 세 가지예요. 운전면허가 필요한지 판단하는 과제, 두 차량 중에서 선택하도록 돕는 과제, 그리고 중고 차량의 적정 가격을 추정하는 과제예요.

## 1. 운전면허가 필요한지 판단해요

차량 종류에 따라 운전면허가 있어야 운전할 수 있는 경우가 있어요.
`"car"`와 `"truck"` 종류만 면허가 필요하고, 나머지는 면허 없이 운전할 수 있다고 가정해요.

차량 종류를 문자열로 받아, 그 종류의 차량에 면허가 필요한지를 나타내는 불리언을 반환하는 `needs_license(kind)` 함수를 구현해요.

```cpp
needs_license("car")
// => true

needs_license("bike")
// => false

needs_license("truck")
// => true
```

## 2. 구매할 차량 두 대 중에서 선택해요

구매할 수 있는 차량들의 선택지를 검토해요.
두 가지로 좁혔지만 최종 결정을 내리려면 도움이 필요해요.
이를 위해, 차량 두 대를 인자로 받아 사전순으로 앞서는 선택지를 포함한 결정을 반환하는 `choose_vehicle(option1, option2)` 함수를 구현해요.

```cpp
choose_vehicle("Wuling Hongguang", "Toyota Corolla")
// => "Toyota Corolla is clearly the better choice."

choose_vehicle("Volkswagen Beetle", "Volkswagen Golf")
// => "Volkswagen Beetle is clearly the better choice."
```

반환되는 문자열은 "<CHOSEN_VEHICLE> is clearly the better choice." 패턴을 따라야 해요. 여기서 `<CHOSEN_VEHICLE>`은 전달된 인자 중에서 선택한 차량이에요.

## 3. 중고 차량의 가격을 추정해요

이제 결정을 내렸으니, 판매점에서 공정한 가격을 지불하는지 확인하고 싶어요.
중고 차량 구매에 관심이 있으니, 가격은 차량이 얼마나 오래됐는지에 따라 달라져요.
대략적으로 추정해 보면, 차량이 3년 미만이면 새 차였을 때의 원래 가격의 80%라고 가정해요.
10년 이상이면 50%예요.
3년 이상 10년 미만이면 원래 가격의 70%예요.

`if`, `else if`, `else`를 사용해 이 로직을 적용하는 `calculate_resell_price(original_price, age)` 함수를 구현해요 (연습하고 싶다면 다른 방법도 있어요).
이 함수는 차량의 원래 가격과 연식을 인자로 받아 판매점에서의 예상 가격을 반환해요.

```cpp
calculate_resell_price(1000, 1)
// => 800

calculate_resell_price(1000, 5)
// => 700

calculate_resell_price(1000.0, 15)
// => 500
```

> 참고: 반환 값의 타입은 `double`이에요.
