# 힌트

## 일반

`IDisposable`에 관한 문서는 [여기][idisposable]에 있어요

## 2. 데이터베이스에 데이터 쓰기

잘못된 데이터 때문에 예외가 발생했을 때 데이터베이스가 `Closed` 상태로 복원되도록 하려면 [`try`/`catch`][try-catch-finally]가 필요해요.

## 3. 이전에 쓴 데이터를 데이터베이스에 커밋하기

잘못된 데이터 때문에 예외가 발생했을 때 데이터베이스가 `Closed` 상태로 복원되도록 하려면 [`try`/`catch`][try-catch-finally]가 필요해요.
