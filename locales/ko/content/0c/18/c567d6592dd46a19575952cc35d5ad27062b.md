# 지침

Tori는 기후 저널리스트이고, 여러 도시의 날씨에 관한 기사를 쓰고 싶어 해요. 여러 도시의 날씨 데이터를 가지고 있는데, 온도를 기준으로 도시들의 순위를 매기고 싶어 해요. 그런데 어떤 온도는 화씨이고 어떤 온도는 섭씨예요. Tori를 도와 온도를 같은 단위로 변환하고 순위를 매겨 주세요.

## 1. 화씨를 섭씨로 변환하기

화씨 온도를 인자로 받아 섭씨 온도를 반환하는 `fahrenheit_to_celsius` 함수를 정의해요.

화씨를 섭씨로 변환하려면 화씨 값에서 32를 뺀 다음, 그 결과를 1.8로 나눠요.

```gleam
fahrenheit_to_celsius(72.5)
// -> 22.5
```

## 2. 두 온도 비교하기

두 온도를 인자로 받아, 첫 번째 온도가 두 번째 온도보다 작은지, 같은지, 큰지를 나타내는 `Order` 값을 반환하는 `compare_temperature` 함수를 정의해요.

```gleam
compare_temperature(Celsius(30.5), Fahrenheit(82.1))
// -> Gt
```

## 3. 도시를 온도순으로 정렬하기

도시 배열을 인자로 받아, 가장 추운 도시부터 가장 따뜻한 도시 순으로 반환하는 `sort_cities_by_temperature` 함수를 정의해요.

```gleam
sort_cities_by_temperature([
  City(name: "London", temperature: Celsius(30.5)),
  City(name: "Paris", temperature: Fahrenheit(82.1))
])
// -> [
//   City(name: "Paris", temperature: Fahrenheit(82.1)),
//   City(name: "London", temperature: Celsius(30.5)))
// ]
```
