# 지시 사항

독점 영화관을 운영하고 있어요.
영화를 보려면 사람들이 연간 패스를 구매해야 하고, 그러면 영화를 무료로 볼 수 있어요.

영화관에서는 입장 기록을 관리해요.
이 기록을 이용해 이번 달에 연간 패스를 사용한 회원이 누구인지 추적하려고 해요.
고객의 연령대 정보도 알고 싶어요.
이 목표는 집합으로 해결할 수 있다는 걸 알게 될 거예요.

## 집합

집합은 이런 종류의 데이터를 저장하기에 더없이 좋은 데이터 타입이에요.

집합은 서로 구별되는 고유한 값을 특별한 순서 없이 저장하는 데이터 타입이에요.
서로 구별되고 고유하다는 것은, 어떤 원소가 집합에 있거나 없거나 둘 중 하나라는 뜻이에요. 배열과 달리 같은 원소가 집합에 여러 번 들어갈 수는 없어요.
집합에는 보통 순서가 없어요. 집합의 원소를 나열하면, 나오는 순서가 원소를 추가한 순서와 다를 수 있고, 직전에 나열했을 때와도 다를 수 있어요!

집합의 근본적인 특성은 원소 포함 여부 확인, 즉 어떤 원소가 집합에 들어 있는지 확인하는 기능이에요.
원소 포함 여부 확인은 집합을 사용하는 거의 모든 경우에 핵심이에요.

Go는 집합 데이터 타입을 기본으로 제공하지 않아요.
집합 대신 `map[<type>]struct{}`나 `map[<type>]bool`을 사용하는 것이 일반적이에요. 집합과 비슷하게 `map`은 서로 구별되는 고유한 원소를 추가할 수 있고, 원소 포함 여부 확인도 지원해요.

## 1. 참석자 정보를 저장할 공간

참석 여부와 연령대를 추적하려면 집합을 사용하면 돼요.

이름과 나이에 대해 집합을 따로따로 만들 필요는 없어요. 대신 둘 다에 쓸 수 있는 제네릭 집합을 사용하면 돼요.
참석자를 저장하려면 `Set` 타입을 `map[T comparable]struct{}`로 정의해요.
빈 `Set[T]`를 반환하는 `NewSet[T comparable]()` 함수를 작성해요.

```go
names := NewSet[string]()
```

## 2. 참석자 기록하기

이제 참석자 정보를 기록할 준비가 됐어요.

집합에 원소를 추가하는 `Add[T]()` 메서드를 작성해요.

```go
names := NewSet[string]()
names.Add("Alice")
```

## 3. 참석자 확인하기

이제 참석자 집합이 있으니, 특정 회원과 연령대가 참석했는지 확인할 수 있어요.
회원이나 연령대가 `Set`에 들어 있는지 반환하는 `Contains[T](element)` 메서드를 작성해요.

```
names := NewSet[string]()
names.Add("Alice")
names.Contains("Alice")
// => true
names.Contains("Bob")
// => false
```

## 4. 참석자 비교하기

한 달이 더 지나서 연령대에 대한 새로운 `Set`이 생겼어요.
마케팅 매니저는 이번 달 신작 때문에 어떤 연령대가 오는지가 달라졌는지 알고 싶어 해요.
두 집합이 같은 원소를 가지는지 판별하는 `Equals[T](other)` 메서드를 작성해요.

```go
agesOne := NewSet[int]()
names.Add(25)

agesTwo := NewSet[int]()
names.Add(25)

agesOne.Equals(agesTwo)
// => true

agesThree := NewSet[int]()
names.Add(35)

agesOne.Equals(agesThree)
// => false
```
