# 자세히 알아보기

[삼항 조건 연산자][ternary-operator]는 `if-else` 표현식을 간결하게 줄여 놓은 형태예요.
조건을 평가하고, 그 조건이 `true`인지 `false`인지에 따라 두 값 중 하나를 반환해요.

이 연산자는 `condition ? trueExpression : falseExpression`처럼 세 부분으로 이루어져 있어요.
`condition`이 `true`로 평가되면 `trueExpression`을 평가해서 반환하고, 그렇지 않으면 `falseExpression`을 평가해서 반환해요.

삼항 연산자는 간단하게 한 줄로 선택할 때 아주 잘 맞아요.

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = showFahrenheit ? temperatureInCelsius * 9 / 5 + 32 : temperatureInCelsius
print(temperature)
// Prints 86
```

위 예제는 다음 코드를 간결하게 줄인 것과 같아요.

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = if showFahrenheit {
    temperatureInCelsius * 9 / 5 + 32
} else {
    temperatureInCelsius
}
```
