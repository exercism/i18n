# 소개

Go에서 `struct`는 _필드_라고 불리는 이름 있는 요소들의 나열이에요. 각 필드는 이름과 타입을 가지고 있어요.
필드의 이름은 struct 안에서 유일해야 해요.
struct는 객체 지향 프로그래밍 패러다임의 _클래스_와 비교할 수 있어요.

## struct 정의하기

`type`과 `struct` 키워드를 사용해 새로운 struct를 만들고, 필드의 이름과 타입을 직접 정의해요.
예를 들어, 여기에서는 도형의 이름과 크기를 담는 `Shape` struct를 정의해요:

```go
type Shape struct {
    name string
    size int
}
```

struct의 필드 이름은 Go 관례를 따라요. 이름이 소문자로 시작하는 필드는 같은 패키지의 코드에서만 볼 수 있고, 대문자로 시작하는 필드는 다른 패키지에서도 볼 수 있어요.

## struct 인스턴스 만들기

`struct`를 정의했다면, 필드 이름을 사용해 순서에 상관없이 필드를 지정하면서 새로운 인스턴스를 만들어야 해요:

```go
s := Shape {
    name: "Square",
    size: 25,
}
```

인스턴스의 필드를 읽거나 수정하려면 `.` 표기법을 사용해요:

```go
// Update the name and the size
s.name = "Circle"
s.size = 35
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 35
```

초기값이 할당되지 않은 필드는 제로 값을 가져요.
예를 들어:

```go
s := Shape{name: "Circle"}
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 0
```

필드를 _순서대로_ 정의하기만 하면 필드 이름 없이도 `struct` 인스턴스를 만들 수 있어요:

```go
s := Shape {
	"Oval",
	20,
}
```

하지만 이런 문법은 _깨지기 쉬운 코드_로 여겨져요. 필드가 추가될 때, 특히 새 필드의 타입이 다를 때 문제가 생길 수 있기 때문이에요.
다음 예제에서는 `Shape`에 필드를 하나 더 추가해요:

```go
type Shape struct {
	name        string
	description string // new field 'description' added
	size        int
}

s := Shape{
    "Circle",
    20,
}
// Since the second field of the struct is now a string and not an int,
// the compiler will throw an error when compiling the program:
// Output: cannot use 20 (type untyped int) as type string in field value
// Output: too few values in Shape{...}
```

## "New" 함수

때로는 struct 인스턴스를 만드는 데 도움을 주는 함수가 있으면 좋아요.
관례적으로 이런 함수는 보통 `New`라고 부르거나 이름이 `New`로 시작하지만, 그냥 평범한 함수일 뿐이므로 원하는 이름을 아무거나 붙여도 돼요.
다른 언어의 생성자를 떠올리게 할 수도 있지만, Go에서는 그냥 평범한 함수예요.

다음 예제에서는 이런 `New` 함수 중 하나를 사용해 `Shape`의 새 인스턴스를 만들고 도형의 `size`에 기본값을 자동으로 설정해요:

```go
func NewShape(name string) Shape {
	return Shape{
		name: name,
		size: 100, //default-value for size is 100
	}
}

NewShape("Triangle")
// => Shape { name: "Triangle", size: 100 }

```

`New` 함수를 사용하면 다음과 같은 장점이 있어요:

* 주어진 값의 검증
* 기본값 처리
* `New` 함수는 초기화하려는 struct와 같은 패키지에 선언되는 경우가 많아서 struct의 비공개 필드까지 초기화할 수 있어요

이 타입을 더 깊이 파고들고 싶다면 다음 자료를 확인해 봐요: [Go by Example: Structs][go-by-example-structs], [A Tour of Go: Structs][tour-of-go-structs], [Structures in Go (structs)][medium-structures-in-go]

## `new` 내장 함수

struct의 새 인스턴스를 만드는 또 다른 방법은 `new` 내장 함수를 사용하는 거예요:

```go
s := new(Shape) // s will be of type *Shape (pointer to shape)
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name:  size: 0
```

이 예제에서 `new`는 모든 값이 각 타입의 제로 값으로 초기화된 struct `Shape`의 인스턴스를 만들고, 그것을 가리키는 포인터를 반환해요.

~~~~exercism/note
대부분의 경우 `new` 내장 함수로 만든 struct 인스턴스를 보게 되지는 않아요.
struct 리터럴이나 사용자 정의 `New` 함수, 또는 struct를 만드는 데 도움이 되는 패키지에서 제공하는 다른 함수를 항상 우선 사용해요.
struct의 새 인스턴스를 만들 때 `new` 내장 함수는 최후의 수단으로만 사용해요.
~~~~
