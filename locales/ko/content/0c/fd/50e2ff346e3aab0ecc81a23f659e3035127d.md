# 개요

`cond` 외에도 Elixir는 조건을 하나만 확인하면 될 때 유용한 매크로 [`if/2`][getting-started-if]를 제공해요.

[`if/2`][kernel-if]는 조건과 두 개의 옵션을 받아요. 조건이 _truthy_이면 첫 번째 옵션을, 조건이 _falsy_이면 두 번째 옵션을 반환해요.

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
else
  "No beer for you!"
end

# => "No beer for you!"
```

두 번째 옵션을 주지 않으면 `nil`이 반환돼요.

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
end

# => nil
```

`if` 표현식을 한 줄로 쓸 수도 있어요. 조건 뒤에 쉼표가 있다는 점에 주의해요.

```elixir
if age >= 16, do: "beer", else: "no beer"
```

이 문법은 아주 짧은 표현식에는 유용하지만, 표현식이 한 줄에 들어가지 않는다면 피하는 게 좋아요.

## _Truthy_와 _falsy_

Elixir에서는 모든 데이터 타입이 불리언 문맥(예를 들어 `if` 표현식)에서 평가될 때 _truthy_ 또는 _falsy_ 값으로 평가돼요. `false`와 `nil`을 **제외한** 모든 데이터는 _truthy_로 취급해요. 특히 Elixir에서는 빈 문자열, 정수 `0`, 빈 배열이 모두 _truthy_로 취급돼요. 이런 점에서 [Elixir는 Ruby와 비슷하지만 JavaScript, Python, PHP와는 달라요][falsy-various-langs].

```elixir
truthy? = fn x -> if x, do: "truthy", else: "falsy" end

truthy?.(true)
# => "truthy"
truthy?.(0)
# => "truthy"
truthy?.([])
# => "truthy"

truthy?.(false)
# => "falsy"
truthy?.(nil)
# => "falsy"
```

[`&&/2`][kernel-and], [`||/2`][kernel-or], [`!/1`][kernel-not]는 모든 값과 함께 동작하는 _truthy_ 불리언 연산자이고, _엄격한_ 불리언 연산자인 [`and/2`][kernel-boolean-and], [`or/2`][kernel-boolean-or], [`not/1`][kernel-boolean-not]를 보완해요.

```elixir
0 and true
# => ** (BadBooleanError) expected a boolean on left-side of "and", got: 0

0 && true
# => true
```
