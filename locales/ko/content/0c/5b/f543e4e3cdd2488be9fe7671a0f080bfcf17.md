# 소개

ClojureScript는 JavaScript를 대상으로 삼는 Clojure 컴파일러예요. Google Closure 최적화 컴파일러의 고급 컴파일 모드와 호환되는 JavaScript 코드를 생성해요.

## 왜 Clojure일까요?

Clojure는 대화형 개발을 지원하는 동적 범용 프로그래밍 언어예요. 풍부한 불변·영속 데이터 구조를 갖춘 함수형 프로그래밍 언어이기도 해요. Lisp의 방언인 만큼 코드가 곧 데이터라는 철학과 강력한 매크로 시스템을 갖추고 있어요.

## 왜 JavaScript일까요?

브라우저와 웹 기반 애플리케이션이 널리 퍼지면서 JavaScript는 다른 어떤 언어도 따라올 수 없는 독보적인 도달 범위를 얻게 됐어요. 그만큼 중요한 언어라서 JavaScript 엔진에도 활발한 연구와 최적화가 이루어지고 있어요. 덕분에 JavaScript는 JVM처럼 훨씬 더 오래 자리 잡은 플랫폼들과도 성능 면에서 겨룰 수 있게 됐어요.

## 왜 Google Closure일까요?

오늘날 쓰이는 가장 복잡한 클라이언트-서비스 웹 애플리케이션 중 일부를 만들어 온 Google은 Closure 라이브러리와 Closure 컴파일러를 만드는 데 막대한 투자를 해왔어요. 이 둘은 함께 작동해 프로그램 전체 최적화를 가능하게 하고, 라이브러리를 많이 사용할 때도 로드 시간을 최소로 줄여 주는 프로그램을 만들어 내요.

## 기회

ClojureScript는 JavaScript 플랫폼의 도달 범위, Clojure의 유연함과 대화형 개발, Google Closure의 프로그램 전체 최적화를 결합해 웹 프로그래밍을 위한 가장 강력한 언어를 제공해요.
