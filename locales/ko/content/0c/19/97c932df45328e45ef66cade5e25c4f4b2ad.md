Raku는 놀랍도록 풍부하고 유연하며 강력한 프로그래밍 언어예요.
유연하기 때문에 프로그래머는 자신만의 스타일에 맞는 표현력 있는 코드를 작성할 수 있어요.

Raku는 배우고 탐구하고 실험해 볼 깊이가 넘치는 큰 언어예요.
이 강의 계획서는 시작하는 데 필요한 기초를 다루는 것을 목표로 해요.

객체 지향 프로그래밍은 Raku의 핵심이에요.
하지만 Raku가 객체 지향 프로그래밍 방식을 강요하지는 않아요.
객체 지향적인 특성 때문에, 이 강의 계획서에서는 [객체, 클래스, 메서드][object-orientation]를 자주 언급하게 될 거예요.

## Variables

기초에서는 단순하게 유지하기 위해 스칼라 [변수][variables]만 사용할게요.

스칼라 변수는 `$` 시길이 앞에 붙는 [식별자][identifiers]예요.

스칼라 변수에는 거의 무엇이든 담을 수 있고, 기본 타입은 [`Any`][Any]예요.

사용하게 될 대부분의 변수에는 [선언][variable-declarator]이 필요해요.
지금은 [`my`][my]와 [`constant`][constant]만 사용해요.

```raku
my $foo;
constant $BAR;
```

## Subroutines

서브루틴은 [`sub`][sub-declarator] 선언자로 선언해요.

`sub` 선언 뒤에는 선택적인 [식별자][identifiers]가 오고, 그다음에 선택적인 [시그니처][signatures]가 오며, 그다음에 [블록][blocks]이 와요.

서브루틴은 (다른 여러 요소와 마찬가지로) [`is export`][exporting] 트레이트를 추가해 내보낼 수 있어요.

서브루틴은 식별자에 [postcircumfix `( )`][postcircumfix-()] 연산자를 사용해 호출할 수 있어요.

```raku
sub foo ($bar) is export { ... } # Subroutine definition

foo($bar); # Subroutine call
```

## Operators

Raku에는 다양한 [연산자][operators]가 있어요.
기초 개념의 연습 문제에서는 `+`와 `-` 같은 몇 가지 기본적인 수학 연산자를 사용할 거예요.

```raku
say 0.1 + 0.2 - 0.3;
# Raku is not like other languages -> https://0.30000000000000004.com/#raku
```

원한다면 Raku에서 자신만의 연산자를 쉽게 정의할 수 있어요.
대부분의 내장 연산자는 서브루틴으로도 사용할 수 있어요.

## Packages and Modules

Raku에는 여러 가지 유형의 [패키지][package-declarator]가 있어요. 기초에서는 `module`만 사용할 거예요.

파일 전체를 `module`로 선언하려면 모듈 선언 앞에 `unit`을 붙여요.

```raku
unit module Foo;

sub bar () { ... }
```

## Comments

Raku에는 [한 줄][single-line-comments] 주석과 [여러 줄/임베디드][multi-line-comments] 주석이 있어요.

한 줄 주석은 `#`로 시작해서 줄 끝까지 이어져요.

여러 줄/임베디드 주석은 해시 다음에 백틱과 유니코드 열림 문장 부호 문자가 오면서 시작해요.
짝을 이루는 닫는 문자로 끝나요.

```raku
# This is a single-line comment

#`(
    This is a
    multi-line/embedded comment
)
```

## Style Conventions

Raku에서 변수와 서브루틴 [식별자][identifiers]는 `kebab-case` 스타일로 작성해요.
상수는 `ALL-CAPS` 스타일로 작성해요.
패키지 이름은 `PascalCase` 스타일로 작성해요.
