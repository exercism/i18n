# 자세히 알아보기

재귀는 함수가 자기 자신을 호출해서 함수 안의 코드를 반복하는 방법이에요. 루프를 돌리거나 반복하는 또 다른 방법이기도 하죠. 루프와 마찬가지로, 함수는 언제 끝낼지 알기 위해 불리언 표현식을 검사해야 해요. 루프와는 달리, 끝나지 않는 재귀는 무한히 실행되지는 않아요. 각 함수 호출에 사용된 값은 스택에서 각자의 프레임에 저장될 수 있어요. 함수 호출이 차지하는 공간이 스택의 용량보다 커지면 스택 오버플로 오류가 발생해요.

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return i;
    printf("The number is %i\n", i++);
    printIncrement(i, maxValue);
}

int main() {
    printIncrement(1, 2);
    printf("After recursion");
    return 0;
}
```

그러면 다음과 같이 출력돼요.

```
The number is 1
The number is 2
After recursion
```

루프로 표현했을 때보다 재귀로 표현했을 때 더 읽기 쉽거나 추론하기 쉬운 상황도 있어요.


## 꼬리 호출

꼬리 호출은 함수의 마지막 문이 자기 자신만 호출하고 그 외에는 아무것도 하지 않는 경우예요.

꼬리 호출은 재귀의 특별한 형태로, 컴파일러가 컴파일된 코드에서 재귀를 루프로 최적화할 수 있게 해줘요. 이는 두 가지 장점을 모두 가져다줘요. 재귀의 가독성과 루프의 성능이죠. 재귀를 루프로 컴파일하는 것을 `tail call elimination` 또는 `tail call optimization.`이라고 해요.

꼬리 호출이 루프로 컴파일되면, 함수 호출마다 새로운 스택 프레임이 만들어지지 않아요. 처음 호출된 함수의 주소에 갱신된 값이 전달되므로, 스택 공간을 아끼고 성능을 높일 수 있어요.

다음 예제는 함수가 자기 자신을 호출한 결과에 1을 더하기 때문에 꼬리 호출이 아니에요.

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return 1;
    printf("The number is %i\n", i++);
    return 1 + printIncrement(i, maxValue);
}

int main() {
    int j = printIncrement(1, 2);
    printf("j is %i after recursion", j);
    return 0;
}
```

그러면 다음과 같이 출력돼요.

```
The number is 1
The number is 2
j is 3 after recursion
```

꼬리 호출로 리팩터링하려면, `j`를 `printIncrement`의 매개변수로 만들어요.

```c
int printIncrement (int i, int maxValue, int j){
    if (i > maxValue) return j;
    printf("The number is %i\n", i++);
    return printIncrement(i, maxValue, ++j);
}

int main() {
    int j = printIncrement(1, 2, 1);
    printf("j is %i after recursion", j);
    return 0;
}
```

꼬리 호출이 꼬리 호출이 아닌 재귀 호출보다 추론하기 더 쉽다고 느낄 수도 있어요. 하지만 컴파일러는 보통 모든 꼬리 호출이 최적화된다고 보장하지 않아요. 재귀를 사용할 때는 반복이 너무 많아져서 스택이 넘치는 일이 없도록 하는 게 항상 중요해요.
