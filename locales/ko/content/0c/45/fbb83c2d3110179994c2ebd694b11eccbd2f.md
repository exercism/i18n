# 소개

Swift에는 루프와 `switch`문의 실행 흐름을 바꾸는 제어 전달문이 있어요.
`return` 외에도 `continue`, `break`, 루프 레이블, `fallthrough`가 있어요.

## Continue

`continue` 문은 루프가 현재 반복의 실행을 멈추고 곧바로 다음 반복을 시작하도록 해요.
`while` 루프나 `repeat-while` 루프에서는 조건을 확인하는 지점으로 바로 건너뛰고, `for-in` 루프에서는 시퀀스의 다음 원소로 넘어가요.

```swift
var count = 1
while count < 6 {
    count += 1
    if count == 4 {
        continue
    }
    print(count)
}

// Prints:
// 2
// 3
// 5
// 6
```

## Break

`break` 문은 루프나 `switch`문 전체를 즉시 빠져나가요.
실행은 루프나 `switch`문 다음의 첫 번째 코드 줄부터 이어져요.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    if !fruit.count.isMultiple(of: 2) {
        break
    }
    print(fruit)
}

// Prints:
// banana
// grapes
```

## 레이블이 붙은 문

루프가 중첩되어 있을 때는 `break`나 `continue`가 가장 안쪽 루프가 아니라 바깥쪽 루프에 영향을 주길 원할 수 있어요.
루프 앞에 이름과 콜론(`labelName:`)을 붙이면 그 루프에 레이블을 달 수 있어요.
이렇게 붙인 레이블을 `break`나 `continue`에 넘기면 돼요:

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    print("\n--- \(fruit) ---")
    for letter in fruit {
        guard letter != "n" else {
            break outerLoop
        }
        print(letter)
    }
}

// Prints:
// --- banana ---
// b
// a
```
