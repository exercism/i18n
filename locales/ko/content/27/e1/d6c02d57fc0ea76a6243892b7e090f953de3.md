# 소개

F#에서 `string`은 변경할 수 없는 텍스트를 유니코드 문자(글자, 숫자, 구두점 등)의 나열로 표현하는 객체이며, 다음과 같이 정의해요:

```fsharp
let fruit = "Apple"
```

문자열은 문자열의 메서드를 호출하거나 `String` 모듈의 함수를 사용해서 다뤄요. 문자열을 한 번 만들면 그 값은 절대 바뀌지 않아요. 문자열을 수정하는 것처럼 보이는 메서드나 함수는 사실 새로운 문자열을 반환해요.

문자열을 합치거나 형식을 지정하는 방법은 몇 가지가 있어요.
* `+` 연산자로 문자열을 합칠 수 있어요:
```fsharp
let sentence = "Apple" + " is a type of fruit."
```
* `sprintf` 함수로 텍스트 형식을 지정할 수 있어요. 형식 문자열 안에 자리 표시자를 두고(`string`에는 `%s`), 값은 인자로 넘겨줘요:
```fsharp
let sentence = sprintf "%s is a type of %s." "Apple" "fruit"
```
