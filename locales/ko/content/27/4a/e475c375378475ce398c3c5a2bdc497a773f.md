# 소개

Go에서 `map`은 키를 값에 대응시키는 내장 데이터 타입이에요.
다른 프로그래밍 언어에서 `map`을 딕셔너리, 해시 테이블, 키/값 저장소, 연관 배열 같은 개념으로 접해 본 적이 있을 거예요.

문법적으로 `map`은 이렇게 생겼어요:

```go
map[KeyType]ElementType
```

각 키는 고유하다는 점도 중요해요. 같은 키에 값을 두 번 할당하면 그 키의 값이 덮어써져요.

맵을 만들려면 이렇게 하면 돼요:

```go
  // With map literal
  foo := map[string]int{}
```

또는

```go
  // or with make function
  foo := make(map[string]int)
```

다음은 맵으로 할 수 있는 몇 가지 연산이에요

```go
  // Add a value in a map with the `=` operator:
  foo["bar"] = 42
  // Here we update the element of `bar`
  foo["bar"] = 73
  // To retrieve a map value, you can use
  baz := foo["bar"]
  // To delete an item from a map, you can use
  delete(foo, "bar")
```

맵에 없는 키의 값을 가져오려고 하면, 값 타입의 제로 값을 반환해요.
이 때문에 헷갈릴 수 있어요. 특히 `ElementType`의 기본값(예를 들어 int의 0)이 유효한 값일 때는 더 그래요.
맵에 키가 있는지 확인하려면 이렇게 하면 돼요

```go
  value, exists := foo["baz"]
  // If the key "baz" does not exist,
  // value: 0; exists: false
```
