# 소개

Elixir에서 맵은 정보를 키-값 쌍으로 저장하는 데이터 구조예요. 다른 언어에서는 이를 연관 배열(PHP), 해시(Perl 5, Raku), 딕셔너리(Python)라고 부르기도 해요.

키와 값은 어떤 데이터 타입이든 될 수 있지만, 키가 아톰이면 축약 문법을 사용할 수 있어요. 맵은 항목을 조회하거나 반환할 때 그 순서를 보장하지 않아요.

## 리터럴 형태

빈 맵은 `%{}`로 간단히 선언해요. 맵 리터럴에 항목을 추가하고 싶다면 두 가지 형태를 사용할 수 있어요:

```elixir
# If the key is an atom:
%{atom_key: 1}

# If the key is a different type:
%{1 => :atom_value}

# You can even mix these if the atom form comes second:
%{"first_form" => :a, atom_form: :b}
```

정해진 표준 형식은 없지만, 키-값 리터럴 쌍을 표현하는 일관된 방식을 선택해요.

## Map 모듈의 함수

Elixir는 _Map 모듈_에서 맵을 다루는 다양한 함수를 제공해요. 일부 _Map 모듈_ 함수는 맵 변환을 돕기 위해 _익명_ 함수를 인자로 넘겨야 해요.
