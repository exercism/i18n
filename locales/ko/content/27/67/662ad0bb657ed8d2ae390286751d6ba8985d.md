# 소개

어떤 것이 자기 자신을 이용해 정의되는 성질을 재귀라고 해요. F#에서 재귀는 주로 자기 자신을 호출하는 함수인 재귀 함수에서 나타나요.

재귀 함수에는 적어도 하나의 _기저 사례_와 적어도 하나의 _재귀 사례_가 있어야 해요. _기저 사례_는 함수를 다시 호출하지 않고 값을 반환해요. _재귀 사례_는 함수를 다시 호출하는데, 언젠가는 기저 사례에 해당하도록 입력을 바꿔요.

재귀 함수는 일반 함수처럼 정의하지만 `rec` 한정자를 붙여요. 이 한정자가 없으면 함수는 자기 자신을 호출할 수 _없고_, 호출하려고 시도하면 컴파일 오류가 발생해요. 그래서 재귀는 명시적으로 선택해야 해요.

```fsharp
let rec factorial x =
    // Base case
    if x = 1 then
        1
    // Recursive case
    else
        x * factorial (x - 1)
```

F#은 구별된 공용체 타입을 통해서도 재귀 타입을 지원해요. 재귀적 구별된 공용체 타입은 케이스 중 하나 이상이 자신의 데이터에서 구별된 공용체 타입 자체를 참조해요. 재귀 함수와 마찬가지로 재귀 타입에도 기저 사례가 있어야 해요. 재귀 함수와는 달리 재귀 타입은 `rec` 키워드를 사용하지 않아요.

```fsharp
type RussianDoll =
    | Doll                 // Base case
    | Layer of RussianDoll // Recursive case
```
