# 소개

다른 많은 언어와 마찬가지로 Common Lisp에서도 숫자는 몇 가지 타입으로 나뉘어요. 그중 가장 기본적인 두 가지는 다음과 같아요.

## 정수

다른 많은 언어와 마찬가지로 Common Lisp에도 정수가 있어요.
정수는 소수점이 없는 온전한 수예요 (예: `-6`, `0`, `25`, `1234` 등).

Common Lisp은 정수의 크기에 아무런 제한을 두지 않아요.
정수는 얼마든지 커질 수 있어요 (음수라면 얼마든지 작아질 수도 있어요).

일반적으로 온전한 수만 다룬다면 정수를 사용하는 게 좋아요. 정수는 실수처럼 여러 번 계산하면서 정밀도를 잃는 문제가 없기 때문이에요.

## 실수

다른 많은 언어와 마찬가지로 Common Lisp에도 실수가 있어요.
실수는 소수점을 포함하는 분수나 온전한 수예요 (예: `3.14`, `-1.7`, `99.99`, `2048.0`).

## 산술

Common Lisp은 대부분의 연산에 표준 산술 연산자를 사용하지만, 더 익숙한 "중위 표기법" 대신 "전위 표기법"을 사용한다는 점에서는 조금 독특해요.

그림으로 보면 더 명확해요:

```lisp
;; Infix-notation (non-lisp languages)
1 + 2 + 3 + 4 + 5 ; => 15
;; Prefix-notation (lisp languages)
(+ 1 2 3 4 5)     ; => 15
```

전위 표기법은 `2 + 2` 같은 연산을 조금 낯선 `(+ 2 2)` 형태로 바꾸긴 하지만, 한 번에 여러 숫자를 다루기가 훨씬 쉬워요.

### 기본 수학

Common Lisp에는 일반적인 함수가 모두 있어요. 덧셈, 뺄셈, 곱셈, 나눗셈을 위한 `+`, `-`, `*`, `/`가 바로 그것이에요.

나눗셈을 할 때 나머지를 알고 싶을 수 있는데, 그럴 때는 숫자와 제수를 인자로 받는 `mod` (modulo의 줄임말) 함수를 사용해요:

```lisp
(mod 4 2)  ; => 0
(mod 2 4)  ; => 2
(mod 10 3) ; => 1
```

### 숫자 비교하기

마지막으로, `=` (같음), `/=` (같지 않음), `>=` (크거나 같음) 같은 함수로 서로 다른 숫자를 비교하면 유용할 때가 있어요.
이 비교가 참이면 (`(= 1 1)`처럼) `T`를 반환하고, 거짓이면 (`(> 0 1)`처럼) `NIL`을 반환해요.
