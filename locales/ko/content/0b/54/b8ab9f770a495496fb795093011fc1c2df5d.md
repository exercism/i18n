# 무시

## 추가 jq 명령줄 옵션

테스트를 보면 `jq`에 옵션이 몇 가지 더 붙어 있는 걸 알 수 있어요.

```sh
run jq -s -R -c -f flower-field.jq << 'END_INPUT'
```

이 옵션들은 뭘까요?

- `-s`

  이것은 "slurp" 모드예요.
  입력을 JSON 객체의 스트림으로 처리하는 대신,
  입력 전체를 하나의 배열로 모아요.

  ```sh
  $ seq 5 | jq -c '.'
  1
  2
  3
  4
  5
  $ seq 5 | jq -s -c '.'
  [1,2,3,4,5]
  ```

- `-R`

  `-r`은 이미 봤을지도 몰라요. "raw" 문자열(따옴표 없이)을 출력하는 옵션이죠.
  `-R`은 그 반대예요.
  입력의 각 줄을 하나의 문자열로 취급해요.

  두 가지 예를 볼까요?

  ```sh
  $ seq 5 | jq -R -c .
  "1"
  "2"
  "3"
  "4"
  "5"

  $ echo 42 | jq '. * 2'      # input is a JSON number
  84
  $ echo 42 | jq -R '. * 2'   # input is a JSON string
  "4242"
  ```

이 두 옵션을 함께 쓰면, 문자열의 배열이 나오는 게 _아니라_,
각 줄 끝의 줄바꿈까지 포함한 입력 전체가 하나의 문자열로 나와요.

```sh
$ seq 5 | jq -s -R -c .
"1\n2\n3\n4\n5\n"
```

이걸 처리하는 것도 이 연습 문제의 도전 과제 중 하나예요.
