# 지침 추가

## 구현

이 연습 문제에서는 클래스를 인스턴스화하고 인스턴스 메서드 몇 개를 추가하게 돼요. 방법은 [Ruby에서 클래스 작성하기][writing-classes]를 참고해요.

HighScore는 하나 이상의 숫자를 담은 배열을 받는데, 각 숫자는 하나의 '게임 점수'를 나타내요. 배열을 다룰 때는 Array 클래스가 참고가 될 수 있어요. [ruby-docs][ruby-docs-array]를 참고해요.

[ruby-docs-array]: https://docs.ruby-lang.org/en/master/Array.html
[writing-classes]: http://ruby-for-beginners.rubymonstas.org/writing_classes/initializers.html
