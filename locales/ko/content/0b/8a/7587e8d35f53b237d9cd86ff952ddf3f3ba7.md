# 힌트

## 일반

- 연습 문제를 풀다가 막히면 [Go 투어의 인터페이스][interfaces-tour-of-go]를 살펴보면서 예제를 더 확인해 봐요.

## 1. 추상적인 인사 기능 만들기

- 인터페이스를 정의하는 방법을 알아보려면 도입부에서 본 `Counter` 예제를 다시 확인해 봐요.
- Go에서 함수 시그니처를 작성하는 방법을 복습하려면 [함수 개념][concept-functions]을 다시 살펴봐요.
- 추상 타입 `Greeter`는 `string` 같은 일반적인 구체 타입과 같은 방식으로 함수 시그니처에 사용할 수 있어요.
- `SayHello`를 구현하려면 `Greeter` 타입의 인자에서 메서드를 호출해요.
  그런 다음 문자열 포매팅이나 문자열 연결을 사용해 최종 결과를 만들어요.

## 2. 이탈리아어 구현하기

- 구조체 타입을 정의하는 방법을 알아보려면 [구조체 개념][concept-structs]을 다시 살펴봐요.
- 이 과제를 해결하는 데 구조체에는 필드가 전혀 필요하지 않아요.
- 구조체를 정의했다면 여기에 `LanguageName`과 `Greet` 메서드를 추가하고 싶을 거예요.
  타입에 메서드를 추가하는 방법을 알아보려면 [메서드 개념][concept-methods]을 다시 살펴봐요.
