# 지침 부록

## 트랙별 지침

이 연습 문제에서는 `robot`이라는 **로케일**을 정의해야 해요. 이 로케일 안에는 **명사** `position`과 `direction`, 그리고 **동사** `move`가 있어요.

- `robot`의 `create` 동사는 초기 위치와 방향을 박스의 배열로 받아요.
    
    ```j
      r=. (0 0;'north') conew 'robot'
    ```
- `move`는 생성된 **인스턴스**에서 `position`과 `direction`의 값을 갱신해요.
    ```j
      r=. (0,0;'north') conew 'robot'
      
      NB. initial state
      NB. ====================================
      position__r
        0 0
      direction__r
        north
      
      NB. new states after `move` is executed 
      NB. ====================================
      move__r 'LA'
      position__r
        _1 0
      direction__r
        west      
    ```
