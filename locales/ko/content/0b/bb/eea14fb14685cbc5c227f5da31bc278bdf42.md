# main 함수가 있는 경우

테스트에서 필요하지도 않고 코드를 조금 더 읽기 어렵게 만들기 때문에 `Main` 함수는 삭제해요.

보통 `Main` 함수는 코드를 디버깅하는 데 도움을 주려고 추가해요. 하지만 더 좋은 방법은 하나 이상의 단위 테스트를 실행하면서 코드를 디버깅하는 거예요. 이렇게 하면 특정 테스트 케이스에 집중해서 디버깅할 수 있다는 장점도 있어요. 다양한 IDE에서 단위 테스트를 실행하면서 Scala 코드를 디버깅하는 방법을 설명하는 링크예요:

- [IntelliJ](https://www.jetbrains.com/help/idea/run-debug-and-test-scala.html)
- [Eclipse](http://scala-ide.org/docs/current-user-doc/features/scaladebugger/index.html)
