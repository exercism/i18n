# 개요

어떤 함수가 실행하는 _마지막_ 동작이 자기 자신을 호출하는 것이라면, 그 함수는 [꼬리 재귀][recursion-tc] 함수예요.

함수가 호출될 때마다 지역 변수와 인자 등을 담은 _스택 프레임_이 [함수 호출 스택][call-stack] 맨 위에 쌓여요. 함수가 반환하면 그 스택 프레임은 스택에서 제거돼요.

꼬리 재귀 함수는 [꼬리 호출 최적화][tail-call-optimization]를 가능하게 해요. 이 최적화는 이전 함수가 더 이상 스택 프레임을 필요로 하지 않는다는 것이 보장되기 때문에, 다음 함수 호출이 마지막 스택 프레임을 재사용할 수 있도록 해줘요. 이 덕분에 함수 호출 스택이 넘칠까 봐 걱정할 필요가 줄어들어요. 함수 호출 스택이 넘치는 상황이란, 스택에 프레임이 너무 많이 쌓여서 새 프레임을 만들 메모리가 남아 있지 않은 경우를 말해요.

- Elixir에서 꼬리 재귀를 구현하려면 데이터 불변성 규칙 때문에 누산기가 필요한 경우가 많아요.

  - 누산기는 재귀 호출을 따라 전달되면서, 기본 경우에서 최종 결과가 반환될 때까지 재귀 함수의 _지금까지의_ 현재 상태를 유지하는 변수예요.

    ```elixir
    # Count the length of a list without an accumulator
    def count([]), do: 0
    def count([_head | tail]), do: 1 + count(tail)

    # Count the length of a list with an accumulator
    def count(list), do: do_count(list, 0)

    defp do_count([], count), do: count
    defp do_count([_head | tail], count), do: do_count(tail, count + 1)
    ```

- 리스트를 다룰 때는 리스트가 단일 연결 리스트로 구현된다는 점을 기억해요. 앞에 추가하는 연산은 매우 빠르지만, 뒤에 추가하는 연산은 매우 느려요.

  ```elixir
  # Reverse a list with an accumulator
  def reverse(list), do: do_reverse(list, [])

  defp do_reverse([], acc), do: acc

  defp do_reverse([head | tail], acc) do
    do_reverse(tail, [head | acc])
  end
  ```
