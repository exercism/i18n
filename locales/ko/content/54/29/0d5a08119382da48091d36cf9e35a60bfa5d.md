# 소개

## 비교 연산자

비교 연산자는 다른 많은 언어와 비슷해요.

같은지 비교할 때는 `==`(같음)와 `!=`(다름) 연산자를 사용해요.

```Kotlin
val txt = "abc"
txt == "abc" // => true
txt != "abc" // => false
```

크기 비교 연산자도 일반적인 방식과 같아요.

```Kotlin
1 < 3 // => true
3 > 3 // => false
3 <= 3 // => true
4 >= 3 // => true
```

## `if`로 분기하기

다음은 `if` 식의 전체 형태예요:

```Kotlin
if (conditional1) {
//    something...
} else if (conditional2) {
//    something...
} else {
//    something...
}
```

- 각 조건식 앞뒤의 괄호 `()`는 필수예요.
- 조건식은 불리언 `true` 또는 `false`로 평가되어야 해요.
  Kotlin에는 다른 언어에서 볼 수 있는 "truthy"와 "falsy" 개념이 없어요.
- 식이 하나뿐이라면 중괄호 `{}`는 생략할 수 있어요.
- `else if`와 `else`는 모두 선택 사항이고, `else if` 블록은 여러 개일 수 있어요.

`if` 식은 값을 "선택"하는 데에도 사용할 수 있어요:

```Kotlin
val number = 100000
val description = if (number > 100) "number is over 100" else "number is less than 100"
// => description = "number is over 100"
```

## 다른 방법은 없을까요?

의도적인 선택으로, Kotlin에는 Java에 있는 삼항 연산자 `? :`가 _없어요_.
대신 `if ... else`의 간결한 형태를 선호해요:

```Kotlin
return if (isOK) goodValue else badValue
```
