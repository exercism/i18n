# 알아보기

실수는 소수점 뒤에 숫자가 한 자리 이상 있는 수예요.

```gleam
let float = 3.45
// -> 3.45
```

실수에는 고유한 연산자들도 있어요.

```gleam
1.0 +. 1.4 // -> 2.4
5.0 -. 1.5 // -> 3.5
5.0 /. 2.0 // -> 2.5
3.0 *. 3.1 // -> 9.3

2.0 >. 1.0  // -> True
2.0 <. 1.0  // -> False
2.0 >=. 1.0 // -> True
2.0 <=. 1.0 // -> False
```

가독성을 위해 실수에 밑줄을 넣을 수도 있어요.

```gleam
1_000_000.0 // One million
```

실수에는 과학적 표기법을 사용할 수도 있어요.

```gleam
1.01e3 // -> 1010
15.1e-3 // -> 0.0151
```
