# 학습

Pascal 프로그래밍 언어는 오랜 역사를 지니고 있고, 온라인 문서의 상당수도 초보자를 대상으로 해요. 이런 튜토리얼은 대부분 화면에 정보를 출력하거나 사용자 입력을 읽는 콘솔 프로그램을 다뤄요. 예를 들어, 가장 흔한 초보자 튜토리얼 중 하나는 화면에 'Hello World'를 출력하는 프로그램이에요:

```pascal
program HelloWorld;
begin
  writeln('Hello World!');
end.
```

콘솔이나 터미널에서 실행하면 이 프로그램은 화면에 'Hello World'를 출력해요.

Exercism에서는 여러분의 풀이가 올바른지 확인하기 위해 자동화된 테스트를 사용해요. 그래서 **program** 대신 **unit**을 써야 하죠. 가장 큰 차이는 터미널에 뭔가를 출력하는 대신 함수에서 값을 반환해야 한다는 점이에요:

```pascal
writeln('Hello World!');
```

이렇게 바뀌어요:

```pascal
result := 'Hello World!'
```

write/writeln 명령은 정보를 표시하거나, 명령이나 수학 연산 등의 출력을 텍스트로 나타낼 때 여전히 유용해요.
