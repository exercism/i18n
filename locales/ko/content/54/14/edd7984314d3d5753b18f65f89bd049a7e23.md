# 소개

Julia에서 `String`은 UTF-8로 인코딩된 유니코드 문자의 유한한 불변 시퀀스예요.

`String` 리터럴은 큰따옴표로 감싼 문자 시퀀스예요:

```julia-repl
julia> "Christopher"
"Christopher"
```

문자열은 `*` 연산자로 이어 붙일 수 있어요:

```julia-repl
julia> "Christopher" * " " * "Paolini"
"Christopher Paolini"
```

~~~~exercism/advanced
Julia가 문자열 연결에 `+` 대신 `*`를 사용하는 이유가 궁금하다면 [Julia 매뉴얼](https://docs.julialang.org/en/v1/manual/strings/#man-concatenation)을 살펴봐요.
~~~~

일부 특수 문자는 앞에 백슬래시를 붙여 이스케이프해야 해요:

```julia-repl
julia> println("\t or spaces?")
         or spaces?
```

Julia는 기본적으로 문자열을 다루는 유용한 함수를 많이 제공해요:

```julia-repl
julia> lowercase("TEST")
"test"

julia> titlecase("TEST")
"Test"
```
