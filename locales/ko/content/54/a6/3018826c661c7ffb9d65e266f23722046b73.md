# Bash 셸에서의 산술 연산 소개

Bash는 산술 연산을 할 수 있지만 _정수만_ 다룰 수 있어요.
실수 연산이 필요하다면 [awk][awk]나 [bc][bc] 같은 외부 프로그램을 불러와야 해요.

산술 연산자는 매뉴얼의 [Shell Arithmetic][arithmetic]에 (우선순위 순서대로) 나열되어 있어요.

게다가 Bash는 특정한 곳에서만 산술 연산을 수행해요. 이런 곳을 산술 "컨텍스트"라고 불러요.

## 산술 확장

산술 확장은 [명령어 치환][cmd-sub]과 비슷하게 생겼지만, 괄호가 두 개라는 점이 달라요.

```bash
$(( expression ))
```

이 문법은 표현식을 평가한 결과로 확장돼요.
보통 변수에 그 결과를 담을 때 사용해요:

```bash
x=$(( 3 + 4 ))
```

~~~~exercism/note
괄호 안의 공백은 원하는 대로 넣어도 돼요.
스타일과 가독성의 문제예요.

```bash
x=$(( 3 + 4 ))
y=$((5+6))
```

친절한 저자는 산술 표현식이 괄호 안에서 더 잘 보이도록 공백을 넣는 걸 좋아해요.
~~~~

## 산술 조건문

산술 조건문은 맨 앞의 `$` 없이 _이중 괄호_ 안에서 수행돼요:

```bash
(( expression ))
```

이것은 결과로 확장되지 않아요.
대신 _종료 상태_를 만들어요.

* 표현식의 결과가 **0이 아니면** 종료 상태가 0(성공)이에요.
* 표현식의 결과가 **0이면** 종료 상태가 1(실패)이에요.

~~~~exercism/note
`((` 안에서 Bash는 C 언어와 같은 참/거짓 개념을 사용해요. 0은 거짓, 0이 아닌 값은 참이에요.
**이것은 Bash가 종료 상태를 평가하는 방식과 정반대예요!**
~~~~

이 문법은 보통 두 곳에서 사용돼요:

1. [`if`문][conditional-if]이나 [`while`문][looping-while]의 COMMAND 부분으로 쓸 때.

   ```bash
   if (( x == y - 1 )); then ...
   while (( y > 0 )); do ...
   ```

1. 변수의 값을 바꾸는 독립적인 명령어로 쓸 때.

   ```bash
   (( x = x + 1 ))
   echo "new value for x is $x"
   ```

   ~~~~exercism/caution
   이런 식의 산술 연산을 `set -e`와 함께 사용할 때는 주의해야 해요.
   표현식이 0으로 평가되면 종료 상태가 0이 아니게 되어 Bash가 종료돼요.

   ```bash
   x=0
   (( x++ ))
   echo "you will see this"

   set -e
   x=0
   (( x++ ))
   echo "shell exits on the previous line; you won't see this"
   ```

   `++` 연산자에 대한 더 자세한 설명은 [후위 증가와 전위 증가][incr] 글을 참고해요.

   [incr]: https://thisvsthat.io/postincrement-vs-preincrement
   ~~~~


## 산술 컨텍스트를 사용하는 다른 곳

산술 컨텍스트가 되는 다른 곳도 몇 가지 있어요:

* [산술 `for`문][looping-for].

  ```bash
  for (( i = 0; i < 10; i++ )); do
      echo "$i"
  done
  ```

* 숫자로 인덱싱된 배열의 인덱스 부분.

  ```bash
  echo "The next element is ${array[x + 1]}"
  # ................................^^^^^
  ```

  배열에 대해 더 알고 싶다면 [배열][arrays] 개념 문서를 읽어봐요.

* `${var:offset:length}` 확장의 오프셋과 길이 부분.
* [`let` 빌트인 명령어][let].
  * `(( expression ))`가 `let "expresson"`보다 선호된다는 점에 유의해요.
    산술 조건문 구조와 달리 `let` 표현식은 파일 이름 확장과 단어 분할의 영향을 받고, 따옴표로 감싸야 해요.
* 변수에 "정수 속성"이 있을 때의 변수 할당.

  ```bash
  # variable x does not have the integer attribute
  x="3 + 4"
  declare -p x      # => declare -- x="3 + 4"

  # variable y has the integer attribute
  declare -i y
  y="4 + 5"
  declare -p y      # => declare -i y="9"
  ```

  ~~~~exercism/note
  저자의 생각에는 `declare -i`의 쓰임새는 제한적이에요.
  가장 큰 장점은 산술 표현식 문법 없이 "그냥" 산술 연산을 할 수 있다는 점이에요.
  하지만 이 때문에 코드를 읽는 사람이 혼란을 겪을 수 있어요. 예상치 못한 곳에서 산술 표현식이 평가될 수 있거든요.
  ~~~~

## 산술 표현식에서 변수 사용하기

산술 컨텍스트에는 가독성을 높여주는 특징이 하나 있어요.

```bash
height=10
width=20
area=$(( height * width ))
```

산술 표현식에서 변수들에 `$` 달러 기호가 빠져 있다는 걸 눈치챘나요?
Bash에서는 이렇게 해도 돼요.
표현식이 훨씬 읽기 쉬워져요.

매뉴얼에는 이렇게 나와 있어요,

> 표현식 안에서는 매개변수 확장 문법을 사용하지 않고 이름만으로 셸 변수를 참조할 수도 있어요.

배열 요소에도 통해요:

```bash
point1=(10 15)  # these are (x, y) coordinates
point2=(20 7)
distance_squared=$(( (point1[0] - point2[0])**2 + (point1[1] - point2[1])**2 ))
```

하지만 다른 매개변수 표현식은 각자의 특별한 문법을 써야 해요.
예를 들어 문자열 길이를 두 배로 만들려면 이렇게 해요:

```bash
s="hello world"
len=$(( ${#s} * 2 ))
```

위치 매개변수도 마찬가지예요.
처음 두 위치 매개변수가 너비와 높이를 나타낸다면 이렇게 해요:

```bash
area=$(( $1 * $2 ))
```
