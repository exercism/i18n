# 개요

Gleam에서는 `case` 표현식을 사용해 조건에 따라 코드를 실행할 수 있어요. case 표현식을 쓰면 값을 하나 이상의 _패턴_과 비교할 수 있어요. 이런 패턴의 한 가지 예가 _리터럴 패턴_으로, 값을 리터럴 값(예: `1`이나 `"hello"`)과 비교해요.

case 표현식은 `case` 키워드로 작성해요:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    1 -> "One"
  }
}
```

다른 언어의 `switch`문과 비슷해 보일 수도 있지만, 패턴 매칭은 다른 패턴들도 함께 사용할 때 진가를 발휘해요. 그중 하나가 _변수 패턴_으로, 변수에 값을 할당할 수 있게 해줘요. 아래 예시에서는 `number`가 `0`이 아니면 변수 `i`에 `number`의 값이 할당돼요:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i -> "Non zero"
  }
}
```

때로는 패턴에 조건을 하나 더 추가하고 싶을 수도 있어요. 이것을 _가드_(절)라고 하는데, `if` 키워드로 추가할 수 있어요:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
  }
}
```

성능을 위해 가드에는 기본적인 수학 연산자와 불리언 연산자만 쓸 수 있고, 다른 함수는 가드에서 사용할 수 없어요.

위 예시에서는 가능한 모든 입력에 대해 일치하는 패턴이 있는 것은 아니에요. 컴파일러가 이를 감지하고 오류를 출력해요. 이것을 _완전성 검사_라고 해요. 경고를 해결하려면 모든 경우를 처리해야 해요. 이때 사용할 수 있는 것이 _무시 패턴_으로, 어떤 값과도 일치하는 패턴이에요:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
    _ -> "Positive number"
  }
}

// No compiler error
```

case 표현식은 위에서 아래로 각 패턴에 대해 값을 검사하면서, 일치하는 패턴을 찾으면 그 패턴에 연결된 로직을 실행해요. 패턴의 순서가 중요해요!
