# 힌트

## 1. Alien 클래스 만들기

- `object methods`에는 항상 첫 번째 매개변수로 `self`가 전달된다는 걸 기억해요.
- `__init__()`의 _양쪽_에 밑줄 두 개가 있다는 걸 기억해요.
- 인스턴스 변수는 그것을 가진 `class` 인스턴스(_객체_)마다 고유해요.
- 클래스 변수는 `class`의 모든 인스턴스에서 동일해요.

## 2. `hit` 메서드

- `object methods`에는 항상 첫 번째 매개변수로 `self`가 전달된다는 걸 기억해요.
- Alien의 체력이 0 아래로 내려가도록 허용할지, 아니면 내려가지 않도록 할지는 직접 정할 수 있어요.

## 3. `is_alive` 메서드

- `object methods`에는 항상 첫 번째 매개변수로 `self`가 전달된다는 걸 기억해요.
- `hit()`을 어떻게 구현하느냐에 따라 0이 '죽음'을 뜻하는 유일한 조건이 아닐 수도 있어요.

## 4. `teleport` 메서드

- `object methods`에는 항상 첫 번째 매개변수로 `self`가 전달된다는 걸 기억해요.
- 인스턴스 속성은 메서드에서 `self.<attribute> = <new attribute value>`를 사용해 바꿀 수 있어요.

## 5. `collision_detection` 메서드

- `object methods`에는 항상 첫 번째 매개변수로 `self`가 전달된다는 걸 기억해요.
- 이 메서드는 플레이스홀더 같은 걸 쓰기에 아주 좋은 자리 같아요…

## 6. Alien 카운터

- 클래스 속성은 `class`의 모든 인스턴스에서 동일해요.
- 이상적으로는 누군가 _새로운 Alien을 만들 때마다_ 이 카운터가 하나씩 증가하면 좋아요.
- 클래스 속성은 인스턴스 메서드에서 _클래스 이름_을 사용해 바꿀 수 있어요: `Alien.<class attribute name>`.
- `__init__()`은 _새 객체를 초기화_하기 때문에 인스턴스 메서드로 간주돼요.

## 7. 객체 생성

- `tuple`은 _하나의_ 매개변수가 돼요.
- Alien 생성자는 _매개변수 두 개_를 받아요.
- 튜플 _안에_ 있는 것을 풀면 매개변수 두 개가 나와요.
- 이 독립 함수는 `class` 밖에 있어요.
