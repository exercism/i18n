# 소개

ColdFusion(CFML)은 C나 JavaScript와 문법이 비슷한 JVM 스크립트 언어예요.
JIT 컴파일로 바이트 코드를 만들어 JVM 위에서 실행되지만, 동적이고 타입이 느슨해서 개발이 빠르고 쉬워요.
CF는 고전적인 객체 지향(OO)과 함수형 프로그래밍을 모두 지원하는 다중 패러다임 언어예요.

CFML에는 태그 기반 템플릿 언어가 내장되어 있어서 웹 앱에 특히 잘 맞아요.
J2EE 컨테이너에서 실행되고, 여러 라이브러리가 함께 제공되어 패키지를 잔뜩 설치하지 않고도 생산성을 높일 수 있어요.
CFML은 zip 파일, PDF와 Excel 생성, 이메일, FTP, HTTP, S3 파일 시스템, ESAPI 보안 라이브러리, JDBC 드라이버, JSON과 REST API를 기본으로 지원해요.

CFML은 프로젝트에 jar 파일을 넣고 코드에서 Java 객체를 직접 만들기만 하면, 어떤 Java 프로젝트든 활용할 수 있어요.
기본 문법과 기본 데이터 타입에 대해 더 알고 싶다면 이 가이드를 참고해요: [Modern ColdFusion (CFML) in 100 Minutes](https://modern-cfml.ortusbooks.com/)
