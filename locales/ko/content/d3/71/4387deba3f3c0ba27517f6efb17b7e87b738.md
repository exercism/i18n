# 소개

Pyret에는 `true`와 `false`라는 두 가지 서로 다른 불리언 원시값이 있어요.
이 두 값은 어떤 명제나 조건이 참인지 거짓인지를 나타내요.

```pyret
"a" == "a" # true
"a" == "b" # false
```

Pyret은 불리언 값을 결합할 수 있는 `and` 연산자와 `or` 연산자를 제공해요.

and 연산자는 양쪽이 모두 true이면 true를 반환하고, 그 밖의 모든 조합에서는 false를 반환해요.

```pyret
true and true # true
true and false # true
false and true # false
false and false # false
```

or 연산자는 적어도 한쪽이 true이면 true를 반환하고, 양쪽이 모두 false이면 false를 반환해요.

```pyret
true or true # true
true or false # true
false or true # true
false or false # false
```

`not()`은 true를 false로, false를 true로 뒤집는 내장 함수예요.

```pyret
not(true) # false
not(false) # true
```
