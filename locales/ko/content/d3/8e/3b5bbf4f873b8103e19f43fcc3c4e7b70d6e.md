# 지침

문자열로 표현된 삼진수(예: '102012')를 기본 원리를 이용해 십진수로 변환해 보세요.

프로그램은 유효하지 않은 삼진수를 나타내는 문자열을 값 0으로 간주해야 해요.

삼진수는 0, 1, 2 세 가지 기호를 포함해요.

삼진수에서 맨 마지막 자리는 1의 자리예요.
끝에서 두 번째는 3의 자리, 끝에서 세 번째는 9의 자리이고, 이런 식으로 이어져요.

```shell
# "102012"
    1       0       2       0       1       2    # the number
1*3^5 + 0*3^4 + 2*3^3 + 0*3^2 + 1*3^1 + 2*3^0    # the value
  243 +     0 +    54 +     0 +     3 +     2 =  302
```

사용하는 언어의 표준 라이브러리에 변환을 수행하는 메서드가 있다면, 없는 척하고 직접 구현해 보세요.
