# 소개

메서드는 가변 매개변수를 가질 수 있어요. 이 매개변수를 사용하면 호출하는 쪽에서 일반 매개변수처럼 0개 이상의 인자를 지정할 수 있어요. 메서드는 이 인자들을 하나의 배열로 받아요.

매개변수를 가변 매개변수로 만들려면 매개변수 선언에 `params` 키워드를 추가해요:

```csharp
public static void PrintNumbers(params int[] numbers)
{
    foreach (var number in numbers)
    {
        Console.Write(number)
    }
}

// No values for a varags parameter is allowed
PrintNumbers();

PrintNumbers(1);
// => 1

PrintNumbers(1, 2, 3);
// => 123
```
