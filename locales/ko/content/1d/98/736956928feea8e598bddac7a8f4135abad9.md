# 힌트

## 1. 계정 유형의 기본 권한 가져오기

- `None`, `Read`, `Write`, `Delete` 권한 유형의 값을 가진 `Permission` 열거형을 정의해요.
- 열거형 플래그를 사용하면 `Permission` 열거형에 비트 연산을 바로 적용할 수 있어요. [`enum` `Flags` 문서를 참고해요][docs-enum-flags].
- `All` 열거형 멤버는 `Read`, `Write`, `Delete` 열거형 멤버를 조합해서 정의할 수 있어요.
- `Guest`, `User`, `Moderator` 계정 유형의 값을 가진 `AccountType` 열거형을 정의해요.
- 각 계정 유형을 처리하려면 `if`문을 사용할 수도 있지만, [`switch`문][docs.microsoft.com-switch-keyword]이 아주 좋은 대안이에요.
- 플래그를 조합한다는 것은 [비트 연산자][docs.microsoft.com-bitwise-and-shift-operators] 중 하나를 사용해 특정 비트를 `1`로 설정한다는 뜻이에요.

## 2. 권한 부여하기

- 플래그를 조합한다는 것은 [비트 연산자][docs.microsoft.com-bitwise-and-shift-operators] 중 하나를 사용해 특정 비트를 `1`로 설정한다는 뜻이에요.

## 3. 권한 취소하기

- 플래그를 제거한다는 것은 두 [비트 연산자][docs.microsoft.com-bitwise-and-shift-operators]를 조합해서 특정 비트를 `0`으로 설정한다는 뜻이에요.

## 4. 권한 확인하기

- 권한을 확인하려면 [비트 연산자][docs.microsoft.com-bitwise-and-shift-operators] 중 하나를 적용한 결과를 검사하면 돼요.
