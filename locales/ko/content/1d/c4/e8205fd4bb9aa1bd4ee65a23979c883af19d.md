# 개요

Java 문자열에 대해 기억해야 할 핵심은, 문자열이 유니코드 문자(글자, 숫자, 구두점 등)의 나열로 텍스트를 표현하는 불변 객체라는 점이에요.
큰따옴표로 `String` 인스턴스를 정의해요:

```java
String fruit = "Apple";
```

문자열을 다루는 일은 [`String`][string-class] 클래스의 메서드로 할 수 있어요.
문자열 값은 한 번 정의되면 절대 바뀌지 않기 때문에, 모든 문자열 조작 메서드는 새로운 문자열을 반환해요.

문자열은 큰따옴표(`"`) 문자로 감싸서 표현해요.
일부 특수 문자는 백슬래시(`\`) 문자로 이스케이프해야 해요.
Java에서 이스케이프해야 하는 문자는 다음과 같아요:

- `"`
- `\`

```java
String escaped = "c:\\test.txt";
// => c:\test.txt
```

마지막으로, 문자열을 연결하는 방법은 여러 가지가 있어요.
가장 간단한 방법은 `+` 연산자예요:

```java
String name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

단순한 연결보다 복잡한 문자열 서식이 필요할 때는 `String.format` 메서드를 사용하는 편이 좋아요.

```java
String name = "Jane";
String.format("Hello %s!",name);
// => "Hello Jane!"
```

다른 방법도 있어요:

- [`StringBuilder` 클래스][string-builder] 사용하기
- [`String.concat` 메서드][string-concat] 사용하기
