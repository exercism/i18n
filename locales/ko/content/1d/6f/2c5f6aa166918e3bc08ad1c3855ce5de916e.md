# Emacs 설치하기

Emacs Lisp(elisp)는 Emacs의 확장 언어이므로, 먼저 [GNU Emacs](http://www.gnu.org/software/emacs/)를 설치해야 해요.

최신 Emacs를 설치하는 것을 권장하지만, 연습 문제의 기준 구현은 28.1 이상으로 생각하면 돼요.
Emacs가 이미 설치되어 있다면 `M-x emacs-version RET`로 Emacs 버전을 확인할 수 있어요.

## OS X에서
가장 쉬운 방법은 [Emacs For Mac OS X](http://emacsformacosx.com/)를 방문해서 dmg를 내려받는 거예요. 그러면 GNU Emacs가 OS X 앱 패키지로 설치돼요.

Aquamacs(권장하지 않아요)나, 원한다면 [Homebrew](https://formulae.brew.sh/formula/emacs)를 통한 설치 같은 다른 방법도 있어요.

## Linux에서
일부 배포판에는 Emacs가 GNU의 일부이기 때문에 이미 설치되어 있어요.

### Ubuntu
현재 가장 최신 Emacs를 설치하는 권장 방법은 [snap](https://snapcraft.io/emacs)을 이용하는 거예요:

```
sudo snap install emacs --classic
```

snap을 쓰고 싶지 않다면 apt로 Emacs를 설치할 수도 있지만, Ubuntu 저장소에서 제공하는 버전은 자주 구버전이에요.
apt로 더 최신 버전의 Emacs를 설치하고 싶다면 [PPA](https://launchpad.net/ubuntu/+ppas?name_filter=emacs)를 사용하거나 [소스에서 빌드](https://www.emacswiki.org/emacs/BuildingEmacs)해야 해요.

최신 버전 설치에 신경 쓰지 않는다면, 다음 한 줄이면 충분해요.

```
sudo apt-get install emacs
```

### Arch
Arch는 보통 최신 Emacs 버전을 제공하므로, 다음을 실행해요:

```
sudo pacman -S emacs
```

그러면 준비가 끝나요.

### 기타 배포판
사용하는 배포판에서 어떤 버전이 최신인지 확인하고, 패키지 관리자를 사용하거나 필요에 따라 소스에서 빌드해요.

### Windows
Windows에 Emacs를 설치하려면 가장 가까운 [FTP 아카이브 미러](https://ftpmirror.gnu.org/emacs/windows)로 가서 설치 파일(=emacs-XX.X-installer.exe=)을 내려받아 실행해요.
설치 없이 Emacs를 사용하고 싶다면 =emacs-XX.x.zip= 패턴의 파일을 내려받아 압축을 풀고 `bin\runemacs.exe`를 실행하면 돼요.

[MSYS2](https://www.msys2.org/)를 사용한다면 다음으로 64비트 Emacs 빌드를 설치할 수 있어요.

```
pacman -S mingw-w64-x86_64-emacs
```

32비트 빌드는 다음으로 설치해요.

```
pacman -S mingw-w64-i686-emacs
```
