# 개요

## 조건문

조건문은 부수 효과를 실행하거나 프로그램의 실행 흐름을 제어하는, 결정을 내리는 문이에요.
조건문에는 `if`, `if/else`, `switch`, `ternary` 문이 있어요.

조건문은 값이나 값들 사이의 관계에 대해 질문을 던질 때 사용해요.
그 질문은 불리언 답으로 평가되지만, `if`문 자체는 아무 값이나 반환할 수도 있고 단순히 부수 효과만 실행할 수도 있어요.

## `if`문

가장 단순한 `if`문은 표현식을 평가하고 한 줄을 실행해요.
검사하는 표현식은 항상 괄호 안에 넣어요.

부수 효과를 실행할 수도 있고

```c
if (count > 10)
    printf("count is greater than 10");
```

실행 흐름을 바꿀 수도 있어요


```c
if (count > 10)
    return sum;
```

`if`문이 한 줄 넘게 실행한다면, 그 줄들을 중괄호 안에 넣어야 해요.

```c
if (count > 10) {
    printf("count is greater than 10");
    return sum;
}
```

어떤 개발 팀은 한 줄일 때도 `if`문에 항상 중괄호를 쓰도록 규칙을 정하기도 해요.


## `if`와 `else`

`if`문은 `else`와 짝지을 수 있어요.

```c
if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## `if`와 `else if`


`else`는 또 다른 `if`와 짝지어서 `if-else-if ladder`라고 부르는 것을 만들 수 있어요.

```c
if (number == 0)
    return "zero";
else if (number < 0)
    return "negative";
else if (number < 10)
    return "single digit";   
else if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## `switch`


때로는 `if-else-if ladder`를 `switch`로 더 잘 표현할 수 있어요.
`if`와 마찬가지로, 검사하는 표현식은 항상 괄호 안에 넣어요.

```c
switch (number) {
    case -1:
        return "negative one";
    case 0:
        return "zero";
    case 1:
        return "positive one";
    case 10:
        return "positive ten";
    case -10:
        return "negative ten";
    default:
        return "don't care";
}
```

`default` 케이스는 검사하는 값이 앞의 어떤 케이스와도 일치하지 않을 때 실행돼요.

`switch`의 케이스가 반환하지 않는다면 보통 각 케이스를 끝내기 위해 `break`를 넣어요. 그렇지 않으면 로직이 다음 케이스로 "흘러내려가요".
때로는 이렇게 흘러내려가는 동작을 의도적으로 사용하기도 해요.

```c
switch (number) {
    case 0:
        msg = "zero"; break;
    case 1:
        msg = "one"; break;
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

흘러내려가는 일이 의도치 않게 일어나면 그건 버그예요.

```c
switch (number) {
    case 0:
        msg = "zero"; // bug! fallthrough of 0 will set msg to "one"
    case 1:
        msg = "one"; break; 
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

`switch`는 값의 범위가 아니라 특정 값과 비교할 때 유용해요.
컴파일러가 `switch`문을 사다리로는 할 수 없는 방식으로 최적화할 수 있기 때문에 `if-else-if ladder`보다 빠를 수 있어요.
또 `switch`가 사다리보다 더 읽기 좋아 보일 때도 있어요.

## 삼항 연산자(일명 조건 연산자)

삼항 연산자는 값을 정할 때 자주 쓰이는, 세 부분으로 이루어진 조건문이에요.
검사할 표현식은 물음표 앞에 오고, 괄호로 묶지 않아도 돼요.
참일 때 반환할 값은 콜론 앞에, 거짓일 때 반환할 값은 콜론 뒤에 와요.
값 리터럴이나 변수 모두 반환할 수 있어요.

```c
int i = j > 5 ? 5: j;
```

삼항 연산자는 문법적인 잡음을 줄이기 위해 중첩할 수 있어요.

```c
// the below could also be 
i = j > 5 ? j :k > 5 ? k: 10;
// but that may not be quite as readable

i = j > 5 ? j
    :k > 5 ? k
    :10;

// which is the same as
if (j > 5) i = j;
else if (k > 5) i = k;
else i = 10;
```

## 부동소수점 값의 조건 비교

부동소수점 수가 구현된 방식 때문에, 단순한 수학 연산이 반올림 오류를 일으킬 수 있고, 그러면 동등성 검사가 기대한 결과를 반환하지 않을 수 있어요.

```c
    a = 1.345f;
    b = 1.123f;
    c = a + b;
    // c may equal something like 2.4679999352
    if (c == 2.468)
        return "I won the lottery!";
```

`epsilon`이라고 부르는 허용 오차 값을 사용하면, 다른 값과 비교했을 때 여전히 같은 값으로 간주될 수 있는 범위를 정할 수 있어요.
일부 플랫폼에는 float형과 double형의 엡실론을 위한 내장 상수가 있어요.
더 알고 싶다면 사용하는 컴파일러의 문서를 참고해요.
엡실론을 계산하는 일은 복잡할 수 있고, 플랫폼마다, 심지어 개별 기계마다 다를 수도 있어요.
다음은 단순한 비교를 사용하는 예제 프로그램이에요.

```c
#include <stdio.h>
#include <math.h>
#include <stdbool.h>

const double MY_EPSILON = .002;

bool same(double x, double y)
{
    return fabs(x - y) < MY_EPSILON;
}

int main()
{
    // Same should return true if the difference is less than MY_EPSILON
    printf("%s\n", same(1.1, 1.099) ? "true" : "false"); // prints true
    printf("%s\n", same(1.1, 1.098) ? "true" : "false"); // prints false
    return 0;
}
```

`float`이나 `double`을 같은지 비교할 때는 주의해요!
