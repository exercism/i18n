# 이터레이터 조합

루프 하나가 이터레이터를 여러 개 호출할 수도 있어요. 각 이터레이터는 루프가 한 회차 돌 때마다 다음 값을 한 번씩 요청받고, 함께 앞으로 나아가요.

```sather
   loop
      first ::= violin_one.elt!;
      second ::= violin_two.elt!;
      #OUT + first + " against " + second + "\n";
   end;
```

이 코드는 두 배열을 나란히 훑어요. 첫 번째 원소는 첫 번째 원소와, 두 번째 원소는 두 번째 원소와 짝을 이뤄요.

## 모두를 놀라게 하는 규칙

**루프는 이터레이터 중 *첫 번째*가 더 이상 값을 내놓지 못하는 순간 끝나요.**

마지막 이터레이터가 끝날 때가 아니에요. 모든 이터레이터가 끝날 때도 아니고요. 첫 번째예요.

그래서 `violin_one`에 마디가 네 개, `violin_two`에 두 개 들어 있다면 위 루프는 **두 번**만 돌아요. 첫 번째 파트의 세 번째, 네 번째 마디는 아예 쳐다보지도 않아요. 그때쯤이면 두 번째 파트에 내놓을 값이 남아 있지 않으니까요.

보통은 이게 바로 원하는 동작이에요. 짝을 짓는 일은 짝이 남아 있을 때만 의미가 있으니까요. 다만 이 규칙은 직접 겪어서 알아내기보다 미리 알고 있어야 해요.

## 함께 세기

끝나지 않는 이터레이터가 쓸모 있는 건 바로 이 규칙 덕분이에요. `up!`은 끝없이 세어요:

```sather
1.up!        -- 1, 2, 3, 4, ... and never ends
```

`up!` 혼자서는 영원히 도는 루프가 돼요. 끝나는 이터레이터와 짝을 지으면, 어디까지 셀지 정할 필요도 없이 값에 번호를 붙여 줘요:

```sather
   loop
      number ::= 1.up!;
      bar ::= part.elt!;
      #OUT + "Bar " + number + ": " + bar + "\n";
   end;
```

루프를 끝내는 건 `part.elt!`이고, 번호를 대 주는 건 `1.up!`이에요. 둘 다 파트가 얼마나 긴지 알 필요가 없어요.

## 순서는 상관없어요

모든 이터레이터는 회차마다 한 번씩 요청받으니까, 어느 것을 먼저 쓰든 상관없어요. 중요한 건 각 이터레이터가 정확히 한 번씩 요청받는다는 점이에요. 한 회차에 `part.elt!`를 두 번 쓰면 값을 하나가 아니라 두 개나 꺼내 와요.
