# 지침 추가

## 출력 형식

가사를 null로 끝나는 문자열로 출력해요.

## 레지스터

| 레지스터 | 용도      | 타입    | 설명                          |
| -------- | --------- | ------- | ----------------------------- |
| `$a0`    | 입력      | 정수    | 시작할 병의 개수              |
| `$a1`    | 입력      | 정수    | 내려놓을 병의 개수            |
| `$a2`    | 입출력    | 주소    | null로 끝나는 출력 문자열     |
| `$t0-9`  | 임시      | 임의    | 임시 저장용                   |
