# 개요

값을 전송할 수 있게 준비한다는 건 세 가지 일을 동시에 하는 거예요. 값을 직렬화하고, 그중에서 필요한 부분을 골라내고, 복사할 필요가 없을 때는 복사하지 않는 것이죠. 이 세 가지는 Factor의 관용구 세 가지로 모두 해결할 수 있어요.

## `unparse`: 값을 소스로

[`unparse`][unparse]는 `prettyprint`에 들어 있는데, 어떤 값이든 그 값의 소스 형태 텍스트를 반환해요. 파서의 반대 방향이라고 할 수 있죠. `dup unparse parse`처럼 왕복시키면 원래 값이 다시 만들어져요.

```factor
USING: prettyprint ;

{ 1 2 3 } unparse .   ! => "{ 1 2 3 }"
"hi" unparse .        ! => "\"hi\""
123 unparse .         ! => "123"
```

`>string`(문자 시퀀스에만 동작해요)이나 `number>string`(숫자에만 동작해요)과 비교해 봐요. `unparse`는 어디에나 쓸 수 있는 대신 Factor 문법 그대로를 만들어내요(따옴표로 묶인 문자열은 따옴표를 그대로 유지하죠). 그래서 받는 쪽에서 텍스트를 다시 파싱할 때는 알맞은 도구지만, 사람이 읽기 좋은 출력을 만들 때는 알맞지 않아요.

## 슬라이스: 복사가 아니라 뷰

| 단어          | 하는 일                                        |
|---------------|------------------------------------------------|
| `head`        | `( seq n -- newseq )`: 처음 n개를 복사해요      |
| `head-slice`  | `( seq n -- slice )`: 처음 n개의 뷰예요         |
| `tail`        | `( seq n -- newseq )`: 인덱스 n부터 복사해요    |
| `tail-slice`  | `( seq n -- slice )`: 인덱스 n부터의 뷰예요     |
| `head*`       | `( seq n -- newseq )`: 마지막 n개를 뺀 나머지를 복사해요 |
| `head-slice*` | `( seq n -- slice )`: 마지막 n개를 뺀 나머지의 뷰예요 |
| `tail*`       | `( seq n -- newseq )`: 마지막 n개를 복사해요    |
| `tail-slice*` | `( seq n -- slice )`: 마지막 n개의 뷰예요       |

`slice`는 시작 인덱스와 끝 인덱스, 그리고 기반 시퀀스를 담고 있는 튜플이에요. [시퀀스 프로토콜][sequence-protocol]을 구현하고 있어서 어떤 시퀀스 연산이든 이 위에서 동작하죠. 읽기만 하려고 굳이 새로 할당하고 싶지 않을 때는 슬라이스 변형을 쓰고, 기반 시퀀스가 나중에 바뀌더라도 데이터를 그대로 유지해야 할 때는 복사하는 변형을 써요.

## 여러 입력을 다루는 cleave: `2bi`, `3bi`, `2tri`, `3tri`

기본 cleave 단어인 `bi`와 `tri`는 스택 위의 *하나*의 입력에 두세 개의 쿼테이션을 적용해요. `2`가 붙은 변형과 `3`이 붙은 변형은 각 쿼테이션을 *둘* 또는 *셋*의 입력에 적용하죠:

```
bi   ( x       p q   -- )
2bi  ( x y     p q   -- )
3bi  ( x y z   p q   -- )

tri  ( x       p q r -- )
2tri ( x y     p q r -- )
3tri ( x y z   p q r -- )
```

각 쿼테이션은 입력을 *전부* 받아요. 그래서 두 결과가 모두 그 쌍에 의존할 때 `2bi`를 쓰는 거지, 각 입력에 같은 연산을 따로따로 적용하고 싶을 때 쓰는 게 아니에요(그건 `bi@`예요).

```factor
1 2 [ + ] [ * ] 2bi . .       ! => 2  3   (both use 1 and 2)
1 2 3 [ + + ] [ * * ] 3bi . . ! => 6  6
```

각 입력에 *하나*의 쿼테이션을 따로 적용하려면 `bi@`(입력 두 개)나 `tri@`(입력 세 개)를 쓰면 돼요. 같은 계열이지만 모양이 다른 친구들이죠.
