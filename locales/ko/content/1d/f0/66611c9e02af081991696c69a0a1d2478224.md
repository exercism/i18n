# 안내 추가

## 출력

이 연습 문제에서는 주어진 행 수까지 파스칼의 삼각형을 생성하는 verb를 구현해요. verb의 출력은 다음 두 가지 방식 중 하나로 만들 수 있어요:

  1. 박스로 묶인 리스트의 배열이에요. 각 리스트는 파스칼의 삼각형에서 한 행을 나타내요.
  1. 표 형태예요. 숫자는 오른쪽에 맞추고, 왼쪽의 빈 공간은 0으로 채워요.

### 출력 예시

`pascal 3`에 대한 유효한 출력 두 가지는 다음과 같아요:

  - 박스로 묶인 리스트의 배열:
```j
  (1 ; 1 1 ; 1 2 1) -: pascal 3          NB. This test will pass
```
  - 여백을 채운 표:
```j
  (3 3$1 0 0 1 1 0 1 2 1) -: pascal 3   NB. This test also passes
```
