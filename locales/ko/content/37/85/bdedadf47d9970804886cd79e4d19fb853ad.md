# 구문 강조

웹사이트에서 구문 강조는 두 가지로 나뉘어요:

1. _정적_ 코드(코드 조각, 제출물 등)를 강조해요.
   자세한 내용은 [정적 구문 강조 문서](/docs/building/tracks/new/syntax-highlighting/static)를 확인해요.
2. _동적_ 코드(온라인 에디터)를 강조해요.
   자세한 내용은 [동적 구문 강조 문서](/docs/building/tracks/new/syntax-highlighting/dynamic)를 확인해요.

```exercism/note
정적 구문 강조와 동적 구문 강조는 요구 사항이 _아주_ 달라요. 그래서 서로 다른 라이브러리를 사용해요.
```
