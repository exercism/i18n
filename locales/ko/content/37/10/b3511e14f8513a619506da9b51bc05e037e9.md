# 소개

Go에는 변수 값이 비어 있거나 null이거나 undefined라는 개념이 없어요.
명시적인 초깃값 없이 선언한 변수는 해당 타입의 제로 값이 돼요.

불리언, 숫자 타입, 문자열 같은 기본 타입의 제로 값은 각각 `false`, `0`, `""`예요.

0을 의미하는 식별자 `nil`은 포인터, 함수, 인터페이스, 슬라이스, 채널, 맵처럼 더 복잡한 타입의 제로 값이에요.

다음 표는 Go 타입들의 제로 값을 정리한 거예요.

| 타입      | 제로 값    |
| --------- | ---------- |
| 불리언    | `false`    |
| 숫자      | `0`        |
| 문자열    | `""`       |
| 포인터    | `nil`      |
| 함수      | `nil`      |
| 인터페이스 | `nil`      |
| 슬라이스  | `nil`      |
| 채널      | `nil`      |
| 맵        | `nil`      |

위 표에 구조체 타입이 없다는 걸 눈치챘을지도 몰라요.
구조체 타입의 제로 값은 필드에 따라 달라지기 때문이에요.
구조체는 모든 필드가 각각의 제로 값으로 설정될 때 제로 값이 돼요.
