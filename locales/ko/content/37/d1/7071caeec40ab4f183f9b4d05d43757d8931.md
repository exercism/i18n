# 자세히 알아보기

Haxe에서 추상 타입은 런타임에는 다른 타입이 되는 타입이에요. 구체적인 타입 "위에" 타입을 정의해서 그 동작을 수정하거나 확장하는 컴파일 타임 기능이죠:

```haxe
abstract AbstractInt(Int) {
    inline public function new(i:Int) {
        this = i;
    }
}
```

여기서는 `abstract` 키워드로 `AbstractInt` 타입을 선언하고 있어요. 문법은 `class`와 아주 비슷하죠. 그리고 클래스와 마찬가지로 추상 타입도 메서드를 가질 수 있어요. 클래스처럼 인스턴스를 만들어 사용할 수도 있고요:

```haxe
class Main {
    static public function main() {
        var a = new AbstractInt(12);
        trace(a); // 12
    }
}
```

앞서 말했듯이 추상 타입은 컴파일 타임 기능이에요. 위 예제를 JavaScript로 컴파일하면 다음과 같아요:

```javascript
var a = 12;
console.log(a)
```

추상 타입 `AbstractInt`는 출력에서 완전히 사라져요. `Abstract`의 생성자가 [인라인][inline]되기 때문인데, 이건 나중에 살펴볼게요.

[inline]: https://haxe.org/manual/class-field-inline.html
