# 문자열

Crystal에는 텍스트를 나타내는 데 사용하는 [`String`][strings]이라는 타입이 있어요.
Crystal의 문자열은 유니코드 문자의 나열이에요.
문자열은 불변이에요. 즉, 한 번 만들면 바꿀 수 없어요.
따라서 문자열을 수정할 때마다 새로운 문자열이 만들어지고, 원래 문자열은 바뀌지 않아요.

문자열을 정의할 때는 큰따옴표 `"`를 사용해요.

```crystal
"Hello World"
```

## 문자열 연결

두 문자열을 연결할 때는 `+` 연산자를 사용해요.
`+` 연산자는 두 문자열을 합친 새로운 문자열을 반환해요.

```crystal
hello = "Hello"
hello + " World"
# => "Hello World"
```

## 문자열과 숫자 사이의 변환

`to_i` 메서드는 문자열을 정수로 변환해요.
또는 `to_f` 메서드를 사용하면 실수를 반환할 수 있어요.
문자열을 숫자로 변환할 수 없으면 `ArgumentError`가 발생해요.

```crystal
"1".to_i
# => 1

"1.0".to_f
# => 1.0

"Hello".to_i
# => ArgumentError: Invalid integer: Hello
```

정수나 실수는 `to_s` 메서드를 사용해 문자열로 변환할 수 있어요.

```crystal
1.to_s
# => "1"

1.0.to_s
# => "1.0"
```

## 보간

보간은 문자열을 합치고 문자열 안에 표현식을 넣는 편리한 방법이에요.
문자열을 보간할 때는 `#` 문자 뒤에 중괄호 `{}`를 쓰고, 중괄호 안에 표현식을 넣어요.

```crystal
name = "World"
"Hello #{name}!"
# => "Hello World!"
```

Crystal은 표현식의 결과를 자동으로 문자열로 변환해요.

```crystal
"Hello #{1 + 1}!"
# => "Hello 2!"
```

## 크기

문자열에 들어 있는 문자의 개수를 알아야 할 때는 `size` 메서드를 사용할 수 있어요. 이 메서드는 문자열의 길이를 정수로 반환해요.
문자열의 크기는 문자열에 저장된 속성이에요. 그래서 메서드를 호출할 때마다 크기를 계산할 필요가 없어서 아주 빨라요.

```crystal
"Hello World".size
# => 11
```

## 인덱싱

인덱싱은 문자열에서 특정 문자를 가져오고 싶을 때 사용해요.
`String`에서 문자를 가져오려면 익숙한 대괄호 표기법을 사용하면 돼요.

~~~~exercism/note
`[]`는 String의 인스턴스 메서드로 구현되어 있고, 인덱스가 그 메서드의 인자예요.
~~~~

Crystal에서는 문자열의 첫 번째 문자가 인덱스 0에 있어요.

```crystal
"Hello World"[0]
# => 'H'

"Hello World"[6]
# => 'W'
```

문자열의 끝에서부터 문자를 가져오려면 문자열의 길이에서 1을 뺀 값을 마지막 문자의 인덱스로 쓰고, 끝에서 두 번째 문자는 길이에서 2를 뺀 값으로, 이런 식으로 하면 돼요.
이걸 간단하게 하는 방법도 있는데, 바로 음수 인덱스를 사용하는 거예요. 마지막 문자가 인덱스 -1, 끝에서 두 번째 문자가 인덱스 -2, 이런 식이에요.

```crystal
name = "Hello World"
name[name.size - 1]
# => 'd'

name[-1]
# => 'd'
```

### 부분 문자열 확인

Crystal에서는 인덱싱을 사용해 문자열에 부분 문자열이 들어 있는지 확인할 수 있어요.
같은 대괄호 표기법을 쓰지만, 인덱스 대신 부분 문자열을 넣어요.
문자열에서 부분 문자열을 찾으면 그 부분 문자열을 반환하고, 찾지 못하면 `NilAssertionError`가 발생해요.

```crystal
"Hello World"["Hello"]
# => "Hello"

"Hello World"["Goodbye"]
# => NilAssertionError
```

부분 문자열이 있는지 여부를 `Bool` 값으로 알고 싶으면 `includes?` 메서드를 사용하면 돼요.

```crystal
"Hello World".includes?("Hello")
# => true

"Hello World".includes?("Goodbye")
# => false
```

## 이스케이프

어떤 문자는 문자열에 그대로 쓸 수 없어요. 이런 문자는 이스케이프 시퀀스를 사용해야 해요.
예를 들어 문자열에 큰따옴표를 쓰고 싶으면 큰따옴표를 이스케이프해야 해요.
`\` 문자 뒤에 이스케이프하려는 문자를 붙여서 이스케이프 시퀀스를 쓸 수 있어요.

다음은 Crystal의 특수 문자예요:

| 값       | 설명                          |
| -------- | ----------------------------- |
| `\a`     | 경보                          |
| `\b`     | 백스페이스                    |
| `\e`     | 이스케이프                    |
| `\f`     | 폼 피드                       |
| `\n`     | 라인 피드 또는 줄 바꿈        |
| `\r`     | 캐리지 리턴                   |
| `\t`     | 가로 탭                       |
| `\v`     | 세로 탭                       |
| `\\`     | 역슬래시                      |
| `\'`     | 작은따옴표                    |
| `\"`     | 큰따옴표                      |
| `\377`   | 8진수 ASCII 문자              |
| `\xFF`   | 16진수 ASCII 문자             |
| `\uFFFF` | 16진수 유니코드 문자          |

```crystal
puts "Hello \"World\""
# => Hello "World"

puts "Hello \nWorld"
# => Hello
# => World
```

## 여러 줄 문자열

여러 줄 문자열을 쓰려면 한 줄 문자열과 같은 문법을 쓰되, 문자열에 넣고 싶은 줄마다 새 줄을 만들어요.

```crystal
"Hello
World"
# => "Hello\nWorld"
```

## 유니코드

[유니코드][unicode]는 다양한 문자 체계의 텍스트를 인코딩하고 표현하고 처리하기 위한 표준이에요.
유니코드는 문자, 문장 부호, 기호, 이모지를 포함해 10만 개가 넘는 문자를 지원해요.

Crystal은 문자열에 유니코드를 사용하기 때문에, 예를 들어 문자열에 이모지를 넣을 수 있어요.

```crystal
"Hello 🌍"
# => "Hello 🌍"
```

가끔은 편집기나 시스템 등에서 바로 입력할 수 없는 문자를 쓰고 싶을 때가 있어요.
그럴 때는 유니코드 이스케이프 시퀀스를 사용해 그 문자를 쓸 수 있어요.

```crystal
"\u{1F310}"
# => "🌐"
```
