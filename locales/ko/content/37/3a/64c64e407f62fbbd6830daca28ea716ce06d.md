# 개요

## 후행 클로저

Swift는 클로저를 다룰 때 쓸 수 있는 또 하나의 문법 형태를 제공하는데, 이를 [후행 클로저][trailing-closures]라고 해요. 후행 클로저는 함수의 매개변수 목록에서 마지막 매개변수가 함수 타입일 때 나타나요. 이 경우 클로저를 전달한다면, 클로저를 닫는 괄호 _뒤에_ 쓸 수 있고 인자 레이블은 생략해요. 함수에 매개변수가 하나뿐이라면 괄호를 아예 생략할 수도 있다는 점에 유의해요.

```swift
func fetchURL(_ urlString: String,
              uponReceipt handleResult: (String) -> ()
             )  -> () {
  if let url = URL(string: urlString), let htmlString = fetch(url) {
    handleResult(htmlString)
  }
}

fetchURL("https://www.swift.org") { print($0) }
// prints the fetched html string

["apple", "ball", "carrot"].sorted { $0.count < $1.count }
```

## 여러 개의 후행 클로저

이전 버전의 Swift는 후행 클로저를 하나만 사용하는 것만 지원했지만, 5.2.4 버전부터는 여러 개의 후행 클로저를 지원해요.

함수의 매개변수 목록 끝에 클로저가 둘 이상 있다면, 후행 클로저 문법을 사용해 그것들을 모두 괄호 밖으로 옮길 수 있어요. 다만 첫 번째 인자 레이블만 생략되고, 나머지에는 레이블을 붙여야 해요.

```swift
func fetchURL(_ urlString: String,
              uponReceipt handleResult: (String) -> (),
              onFailure handleFailure: () -> ()
             )  -> () {
  if let url = URL(string: urlString), let htmlString = fetch(url) {
    handleResult(htmlString)
  } else {
    handleFailure()
  }
}

fetchURL("https://www.swift.org") {
  print($0)
} onFailure: {
  print("Error: https://www.swift.org could not be fetched")
}
// prints the fetched html string on successful fetch or prints error message on failure
```
