# 지침

안녕하세요, Double-Null0111 요원.

이 임무를 수락하기로 한다면, UMBRA(United Minions Being Really Awful) 본부에 잠입해 그들의 최신 끔찍한 계획서를 빼내는 데 필요한 도구 두 개를 작성해야 해요. 이 임무를 수행하려면 도구 세 개가 필요해요.

## 1. id 번호 생성하기

미니언은 저마다 고유한 식별자를 가지고 있는데, 이 식별자는 매일 바뀌고 미니언이 가진 비밀의 개수와 잠자는 시간에 따라 달라져요.
날짜(`Int`)를 받아서 그날의 식별자 생성 함수를 만드는 함수를 작성해야 해요.
식별자 생성 함수는 두 개의 매개변수를 받아요:

1. 가진 비밀의 개수
2. 미니언이 잠자는 시간

식별자는 다음 순서로 계산해요:

1. 가진 비밀의 개수에 잠자는 시간을 곱해요
2. 그 결과에 날짜(`Int`로 표현)를 더해요

```kotlin
val idGenerator = makeIdGenerator(4)
idGenerator(3, 6)
// => 22

idGenerator(11, 5)
//  => 59
```

## 2. 되찾은 비밀 계획을 비밀번호로 보호하기

비밀 계획을 손에 넣었다면, 비밀번호를 아는 사람만 다시 꺼낼 수 있도록 보호해야 해요.
그러려면 `protectSecret(secret: String, password: String) : (String) -> String` 함수를 구현해야 해요.
이 함수는 비밀번호로 추측되는 문자열을 입력으로 받는 또 다른 함수를 반환해요.
입력한 비밀번호가 맞으면 새 함수는 숨겨 둔 비밀을 반환하지만, 비밀번호가 틀리면 "Sorry. No hidden secrets here."를 반환해요.

```kotlin
val secretFunction = protectSecret("Steal the world's supply of french fries!", "5up3r53cr37")

secretFunction("Open sesame")
// Returns "Sorry. No hidden secrets here."

secretFunction("5up3r53cr37")
// Returns "Steal the world's supply of french fries!"
```

## 3. 비밀번호 찾기

UMBRA 기지에는 여러 방이 있는데, 각 방은 경비원이 지키고 있고 경비원이 비밀번호를 물어봐요.
비밀번호는 방 번호에 따라 달라져요.
안타깝게도 우리는 비밀번호를 계산하는 알고리즘의 절반만 알고 있어요.
나머지 절반은 미니언 한 명에게 물어보면 알 수 있어요.

다음을 입력받아 비밀번호를 반환하는 `getPassword` 함수를 구현해요:

1. 방 번호
2. 미니언의 함수

비밀번호는 우리가 아는 알고리즘을 나타내는 또 다른 함수를 미니언의 함수에 넘겨 호출하면 얻을 수 있어요.
우리가 아는 알고리즘은 다음과 같아요:

1. 두 수를 받아서 더해요
2. 그 결과에 방 번호를 곱해요

```kotlin
val minionFunction = { yourFunc : (Int, Int) -> Int ->
    "Password=${yourFunc(1, 3)}"
}

getPassword(5, minionFunction)
// Returns "Password=20"
```
