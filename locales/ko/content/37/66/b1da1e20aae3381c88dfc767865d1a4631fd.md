# 추가 지침

## 트랙별 지침

함수는 곱과 인수 배열의 오프셋 및 길이를 반환해야 해요.
인수는 그냥 i32 쌍으로 메모리에 기록돼요:

```
Return value:
[u32 $product] [u32 $factorsOffset] [u32 $factorsLength]

Memory at $factorsOffset
[u32 firstFactor] [u32 firstCofactor] [u32 secondFactor] [u32 secondCofactor] ...
```

가장 큰 한 자리 팰린드롬 곱의 경우, 다음과 같아요.

```
Return value
0009 0000 0004

Memory at offset 0
0001 0009 0003 0003
```
