# 자세히 알아보기

[튜플][tuple]은 정보를 묶을 때 흔히 사용해요. 튜플은 크기가 고정되어 있고 서로 다른 데이터 타입을 담을 수 있다는 점에서 배열과 달라요.
튜플은 괄호 `()`를 사용해 만들고, 함수에서 여러 값을 반환할 때도 자주 쓰여요.

```haskell
tuple = (1, "abc", False)
```

예를 들어 2차원 공간의 좌표를 저장하고 싶을 때 유용해요. 이때 튜플에는 항상 x 좌표와 y 좌표, 두 개의 원소가 들어 있다는 것을 알 수 있어요.

```haskell
coordinate = (3, 4)
```

## 원소에 접근하기

짧은 튜플을 다룰 때가 많은데, 이때는 `fst`와 `snd` 함수로 원소에 접근할 수 있어요.

```haskell
x = fst coordinate
-- x = 3
y = snd coordinate
-- y = 4
```

[tuple]: https://hackage.haskell.org/package/base/docs/Data-Tuple.html
