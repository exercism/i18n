# 지침 추가

## 트리 출력하기

이 연습 문제에는 트리를 보기 좋은 형식으로 출력하는 데 도움이 되는 미리 정의된 클래스 메서드가 몇 개 있어요.
주된 목적은 디버깅을 돕고 내용을 더 명확하게 이해하는 것이에요.
클래스의 나머지 부분을 올바르게 구현하면 트리를 알아서 출력해 줄 거예요.

```powershell
.Example
$tree = [BinarySearchTree]::new(@(50, 76, 1, 34, 89, 44, 25, 6, 26, 100, 13))
$tree.ToString()

Return:
@"
50
├──L:1
│   └──R:34
│       ├──L:25
│       │   ├──L:6
│       │   │   └──R:13    
│       │   └──R:26        
│       └──R:44
└──R:76
    └──R:89
        └──R:100
"@
```
