# 소개

프로그래밍에서는 예상치 못한 상황 때문에 프로그램이 중단되거나 예측할 수 없게 동작하지 않도록, 오류를 적절히 처리하는 것이 중요해요.
Cairo는 오류 처리를 위한 두 가지 주요 방법을 제공해요:

1. `panic`을 사용하는 **복구할 수 없는 오류**: 프로그램을 즉시 중단해요.
2. `Result`를 사용하는 **복구 가능한 오류**: 프로그램이 오류를 처리하고 대응할 수 있게 해요.

## `panic`을 사용하는 복구할 수 없는 오류

때로는 프로그램이 더 이상 진행할 수 없을 만큼 심각한 오류를 만나기도 해요.
이런 경우 Cairo는 `panic` 함수로 실행을 즉시 멈춰요.
범위를 벗어난 인덱스에 접근하려는 것처럼, 프로그램이 정상적으로 계속 실행될 수 없는 오류일 때 유용해요.
`panic` 함수는 오류의 원인을 설명하는 `ByteArray` 메시지를 받아요.

예를 들어, Cairo에서는 다음과 같아요:

```rust
fn main() {
    let data = array![1, 2];
    panic("An unrecoverable error has occurred!");
}
```

이 예제는 메시지와 함께 프로그램을 즉시 중단시키는 강제 패닉을 보여줘요.

### `assert!` 매크로

`assert!` 매크로는 코드에서 특정 조건을 강제하는 데 유용한 도구예요.
`assert!`의 조건이 `false`로 평가되면, 프로그램은 `ByteArray` 오류 메시지와 함께 패닉이 발생해요.
이는 개발 중에 가정을 검증하거나 값이 특정 조건을 만족하는지 확인할 때 자주 쓰여요.

예를 들어:

```rust
fn main() {
    let x = 5;
    assert!(x > 0, "x must be greater than zero");
}
```

`x`가 0보다 크지 않으면, 프로그램은 `"x must be greater than zero"` 메시지와 함께 패닉이 발생해요. `assert!`는 오류 처리 코드를 직접 작성하지 않고도 불변식과 사전 조건을 확인할 때 유용해요.

## `Result`를 사용하는 복구 가능한 오류

모든 오류가 프로그램을 멈출 필요는 없어요.
일부 오류는 잘 처리해서 프로그램을 계속 실행할 수 있어요.
Cairo의 `Result` 열거형은 이런 복구 가능한 오류를 나타내며, 두 가지 변형이 있어요:

- `Result::Ok`는 성공을 나타내요.
- `Result::Err`는 오류를 나타내요.

`Result`를 사용하면 함수가 성공 값이나 오류 중 하나를 반환할 수 있어서, 호출한 함수가 다음에 무엇을 할지 결정할 수 있어요.

```rust
fn divide(a: u32, b: u32) -> Result<u32, ByteArray> {
    if b == 0 {
        Result::Err("Error: Division by zero")
    } else {
        Result::Ok(a / b)
    }
}
```

이 예제에서 `b`가 0이면 오류를 반환하고, 그렇지 않으면 나눗셈의 결과를 반환해요.
