# 소개

각 Factor 소스 파일은 `IN:`으로 *어휘*를 선언하고, 사용하는 다른 어휘는 `USING:`으로 가져와요.

```factor
USING: kernel sequences ;
IN: my-vocab

: shout ( str -- str ) "!" append ;
```

디렉터리 구조는 점으로 구분된 어휘 이름을 따라요:

- `my-vocab` 어휘는 `my-vocab/my-vocab.factor`에 있어요.
- `my-vocab.helpers` 어휘는 `my-vocab/helpers/helpers.factor`에 있어요.

Factor의 어휘 로더는 `USING:` 선언을 연쇄적으로 따라가요. 불러온 파일이 다른 어휘를 가져오면 그 어휘도 자동으로 로드돼요.

큰 루틴을 두 어휘로 나누는 경우가 많아요. 작고 재사용할 수 있는 워드로 이루어진 헬퍼 어휘와, 그 워드들을 가져와 결과를 조합하는 메인 어휘로요.
