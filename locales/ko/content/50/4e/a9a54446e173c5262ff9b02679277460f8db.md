# 지시 사항

이 연습 문제에서는 가장 친한 친구들과 "Wizard and Warriors"라는 롤플레잉 게임을 해요. 여러분은 게임 마스터예요. 플레이어들에게 게임 세계를 생생하게 느낄 수 있도록 만들어 주는 사람이죠.

여기서 중요한 것 중 하나는 플레이어들에게 게임을 설명하는 거예요. 캐릭터의 상태는 어떤지, 방문하는 마을은 어떻게 생겼는지 등을 말이죠.

게임의 여러 부분을 플레이어들에게 설명하는 다섯 가지 과제가 있어요.

## 1. 캐릭터 설명하기

각 캐릭터에는 클래스, 레벨, 체력이 있고 다음과 같이 설명돼요: `"You're a level <LEVEL> <CLASS> with <HIT_POINTS> hit points."`. `Character`를 유일한 매개변수로 받아 설명을 반환하는 (정적) `GameMaster.Describe` 메서드를 구현해요.

```csharp
var character = new Character();
character.Class = "Wizard";
character.Level = 4;
character.HitPoints = 28;

GameMaster.Describe(character);
// => "You're a level 4 Wizard with 28 hit points."
```

## 2. 목적지 설명하기

각 목적지에는 이름과 주민 수가 있고 다음과 같이 설명돼요: `"You've arrived at <NAME>, which has <INHABITANTS> inhabitants."`. `Destination`을 유일한 매개변수로 받아 설명을 반환하는 (정적) `GameMaster.Describe` 메서드를 구현해요.

```csharp
var destination = new Destination();
destination.Name = "Muros";
destination.Inhabitants = 732;

GameMaster.Describe(destination);
// => "You've arrived at Muros, which has 732 inhabitants."
```

## 3. 이동 방법 설명하기

캐릭터는 두 가지 방법 중 하나로 목적지까지 이동할 수 있어요:

- 걷기, 다음과 같이 설명돼요: `"You're traveling to your destination by walking."`
- 말을 타고 이동하기, 다음과 같이 설명돼요: `"You're traveling to your destination on horseback."`

`TravelMethod`를 유일한 매개변수로 받아 설명을 반환하는 (정적) `GameMaster.Describe` 메서드를 구현해요.

```csharp
GameMaster.Describe(TravelMethod.Horseback);
// => "You're traveling to your destination on horseback."
```

## 4. 목적지로 이동하는 캐릭터 설명하기

캐릭터가 목적지로 이동할 때는 각각의 설명을 조합해서 다음과 같이 설명해요: `"<CHARACTER> <TRAVEL_METHOD> <DESTINATION>"`. `Character`, `Destination`, `TravelMethod`를 매개변수로 받아 설명을 반환하는 (정적) `GameMaster.Describe` 메서드를 구현해요.

```csharp
var character = new Character();
character.Class = "Wizard";
character.Level = 4;
character.HitPoints = 28;

var destination = new Destination();
destination.Name = "Muros";
destination.Inhabitants = 732;

GameMaster.Describe(character, destination, TravelMethod.Horseback);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination on horseback. You've arrived at Muros, which has 732 inhabitants."
```

## 5. 이동 방법을 지정하지 않고 목적지로 이동하는 캐릭터 설명하기

대부분의 경우, 캐릭터는 걸어서 목적지로 이동해요. 편의를 위해 플레이어는 이동 방법을 생략할 수 있고, 이 경우 걷기가 이동 방법으로 간주돼요. `Character`와 `Destination`을 매개변수로 받아 설명을 반환하는 (정적) `GameMaster.Describe` 메서드를 구현해요.

```csharp
var character = new Character();
character.Class = "Wizard";
character.Level = 4;
character.HitPoints = 28;

var destination = new Destination();
destination.Name = "Muros";
destination.Inhabitants = 732;

GameMaster.Describe(character, destination);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination by walking. You've arrived at Muros, which has 732 inhabitants."
```
