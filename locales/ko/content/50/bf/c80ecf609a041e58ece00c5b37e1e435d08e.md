# 자세히 알아보기

`var` 대신 `final` 키워드로 선언한 변수는 값을 한 번만 할당할 수 있어요.

```haxe
final a = "hello";
var b = "world";
trace(a, b); // hello, world
b = "haxe";
trace(a, b); // hello, haxe

// The following line would cause a compilation error:
// a = "bye";
```

`final`은 배열이나 객체처럼 불변 타입에는 의도한 효과를 내지 않을 수 있다는 점을 기억해 두세요.

```haxe
final a = [0, 1, 2];
trace(a); // [0,1,2]

// this would cause a compilation error:
// a = [0, 1, 2, 3];

// but the following line works:
a.push(3);
trace(a); // [0,1,2,3]
```
