# 내부 링크

Exercism의 Markdown 파서로 렌더링되는 링크는 내부 링크인지 확인하고, 내부 링크라면 툴팁을 붙일 수 있어요.

개념에 대한 툴팁은 이렇게 생겼어요:

<img src="https://raw.githubusercontent.com/exercism/docs/main/.imgs/concept-tooltip.png" height="200">

## 사용법

이런 식으로 링크를 꾸미기 위한 특별한 문법은 따로 없어요.
대신 링크의 href가 다음 두 가지 형식 중 하나를 따르는지 확인해요:

- URL. 예: https://exercism.org/tracks/ruby/concepts/basics
- 절대 경로. 예: /tracks/ruby/concepts/basics

현재는 상대 URL(`./`나 `../`로 시작하는 것들)을 지원하지 않아요. Markdown 파서는 자신이 렌더링하는 문서의 맥락, 렌더링되는 위치의 맥락, git 저장소의 구조를 알지 못하기 때문이에요.

## 대안

일반 링크를 쓰는 대신 위젯을 렌더링할 수도 있어요.
위젯은 보통 문서 끝에서 더 읽어볼 거리나 배우기 좋은 연습 문제를 추천할 때 사용해요.

자세한 내용은 [위젯 문서](/docs/building/markdown/widgets)를 참고해요.
