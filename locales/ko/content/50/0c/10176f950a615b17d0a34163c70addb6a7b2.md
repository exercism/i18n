# 개요

다른 언어들처럼 C++도 `switch`문을 제공해요.
`switch`문은 긴 `if ... else if`문을 더 짧게 쓰는 방법이에요.
`switch`문을 만들려면 먼저 `switch` 키워드를 쓰고 그 뒤에 정수를 적어요.
그다음 각 조건을 `case` 키워드로 선언해요.
이전 `case` 조건 중 어느 것도 맞지 않을 때 실행되는 `default` 케이스도 선언할 수 있어요.
각 케이스는 `break`(또는 `return`)문으로 끝나야 해요.

```cpp
int price{0};
int adults{3};
int kids{2};

switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
        break;
    case 2:
        price = 70;
        break;
    default:
        price = group_size * 30;
}
```

## 폴스루

switch 구조에서 중요한 점은, `break`(또는 `return`)문으로 멈출 때까지 코드가 계속 실행된다는 거예요.
그래서 예상하지 못한 동작이 생길 수 있어요.

```cpp
int adults{1};
int kids{0};
switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
    case 2:
        price = 70;
    default:
        price = group_size * 30;
}
// price will be 30!
```

이렇게 계속 실행되는 기능이 주로 쓰이는 경우는 여러 레이블을 가진 문이에요.
여러 switch 결과가 실행할 같은 코드 조각에 연결될 수 있어요.
이런 식으로, 예를 들어 예약 앱에서 인원이 2명일 때와 3명일 때 호출되는 함수를 같게 만들 수 있어요:
```cpp
switch (group_size) {
case 1:
    book_room();
    break;
case 2:
case 3:
    book_apartment(group_size);
    break;
default:
    book_house(group_size);
}
// book_apartment happens wheng roup_size is 2 or 3
```

~~~~exercism/note
지금까지 봤듯이, C++의 switch문은 다른 언어와 비교하면 매우 제한적이에요.
많은 언어에서는 불리언 표현식을 기준으로, 심지어 정규 표현식을 기준으로도 스위치를 만들 수 있어요.
C++ 버전은 확장된 goto/switch 구조라고 생각하면 돼요.
오직 switch문만 레이블로 점프할 수 있어요.
그 뒤로는 다른 모든 레이블이 무시되고, 코드 블록을 빠져나오려면 `break`문을 써야 해요.
~~~~
