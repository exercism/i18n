# 개요

로컬은 스택 코드를 대체하지 않아요. 스택 코드와 나란히 함께 존재할 뿐이에요. 다음과 같은 경우에 로컬을 꺼내 쓰면 좋아요:

- 같은 입력을 두 번 이상 참조할 때.
- 자연스러운 연산 순서가 스택 순서와 맞지 않을 때.
- 람다에 여러 값을 한꺼번에 넘겨주는 고차 함수 안에 있을 때 (`assoc-map`의 `( key value -- newkey newvalue )`).

```factor
USING: locals ;

! Two references to ratio: stack-shuffled vs. local.
: average  ( a b -- avg ) + 2 / ;
:: average ( a b -- avg ) a b + 2 / ;        ! same effect
```

`[let code :> name code :> name ... body ]`는 quotation이나 listener 안에서 로컬 바인딩을 만들어요. `:>`만으로는 바인딩할 렉시컬 스코프가 없는 곳이니까요:

```factor
[let 5 :> x 10 :> y x y + ] .   ! => 15
```

`:>`의 변경 접미사를 쓰면 로컬을 다시 바인딩할 수 있어요. 명령형처럼 느껴지는 루프에서 유용해요:

```factor
:: collatz ( n -- count )
    n :> current!
    0 :> count!
    [ current 1 = ] [
        current odd?
        [ current 3 * 1 + current! ]
        [ current 2 / current! ] if
        count 1 + count!
    ] until
    count ;
```
