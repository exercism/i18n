# 소개

[`Nothingness`][concept-nothingness] 개념에서 살펴봤듯이, R에는 없는 데이터(`NULL`), 알 수 없는 데이터(`NA`), 수학적으로 유효하지 않은 데이터(`NaN`, `Inf`)를 나타내는 여러 가지 방법이 있어요.
일반적으로 R은 이런 값들을 사용해 문제를 제자리에서 표시하고, 예외를 발생시키지 않고 계속 실행하려고 해요.

## `stop()`

어떤 문제는 너무 근본적이라 프로그램을 계속 실행할 수 없어요. 
이런 경우에는 `stop(msg)`를 사용해 프로그램을 즉시 `Error`와 함께 중단하고 `msg`를 출력해요.

```R
f <- function() {
    stop("I have a problem")
}
f()
#> Error in f() : I have a problem
```

## `stopifnot()`

다른 언어의 `assert`와 비슷하게, 이것은 `stop()`을 편리하게 감싼 함수예요. 
매개변수로는 쉼표로 구분된 임의 개수의 불리언 조건을 받고, 이 조건이 모두 `TRUE`일 때만 프로그램이 계속 실행돼요.

```R
stopifnot(1 < 2) # continues OK
stopifnot(1 < 2, 1 == 2)
#> Error: 1 == 2 is not TRUE
```

## `warning()`과 `message()`

이들은 치명적이지 않은 상황에 대한 응답이에요. 예를 들어:

- 프로그램이 적어도 부분적으로는 복구할 수 있는 문제를 경고할 때.
- 오래 실행되는 프로그램의 진행 상황을 사용자에게 알릴 때.

```R
w <- function() {
  warning("something strange happened")
  -1
}

w()
#> [1] -1
#> Warning message:
#> In w() : something strange happened

# if warnings are not wanted
suppressWarnings(w())
#> [1] -1
```

`suppressWarnings()` 함수는 원치 않는 출력으로 테스트 러너를 혼란스럽게 하지 않도록, Exercism 안에서 가끔 유용하게 쓸 수 있어요.
