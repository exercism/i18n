# 테스트

테스트를 실행하려면 다음 명령을 실행해요:

```bash
make
```

## 건너뛴 테스트

연습 문제를 푼다는 건 그 문제의 모든 테스트를 통과시키는 거예요.
기본적으로 테스트를 실행하면 테스트 하나(첫 번째 테스트)만 실행돼요.
이건 의도된 동작이에요. 한 번에 그 테스트 하나를 통과시키는 데만 집중할 수 있거든요.
그 테스트가 통과하면 `TEST_IGNORE()` 줄을 지워서 다음 테스트를 활성화할 수 있어요.
모든 테스트를 활성화하고 구현이 그 테스트를 모두 통과하면, 연습 문제를 푼 거예요!

## 디버깅

디버깅을 돕기 위해 `debug.mac` 파일에 여러 매크로가 정의되어 있어요.
이 매크로들은 알맞은 크기의 인자를 하나 이상 넘겨서 호출할 수 있어요.
예를 들면 다음과 같아요:

```x86asm
debugf32 xmm0, xmm1 ; prints the value of two 32-bit floating-point numbers
debugd16 ax, cx, dx ; prints the value of three signed 16-bit integers
debugx64 [rax]      ; prints the value of a 64-bit integer in hexadecimal format
debugs rsi          ; prints a NUL-terminated string whose address is stored in `rsi`
debugu8_xmm xmm1    ; prints 16 packed 8-bit unsigned integers
```

이 매크로를 사용하려면 풀이 파일 맨 위에 `debug.mac`을 포함해야 해요:

```x86asm
%include "debug.mac"
```
