# 안내 추가

## 구현

아이템은 `item.lfe`에 정의된 [레코드](https://lfe.gitbooks.io/reference-guide/content/16.html)로 표현해요.
무게를 구하려면 `item-weight`를, 값을 구하려면 `item-value`를 사용해요.

```
;; Create an item with weight=5, value=50
(set item (make-item weight 5 value 50))

;; Get the weight. Returns 5.
(item-weight item)

;; Get the value. Returns 50.
(item-value item)
```
