# 안내 추가

## Callable

PHP에는 [callable](https://www.php.net/manual/en/language.types.callable.php)이라는 개념이 있어요.

여러 가지 형태가 있을 수 있지만, 여기서는 [익명 함수](https://www.php.net/manual/en/functions.anonymous.php)에 집중할게요.

변수에 익명 함수를 만들고, 인자를 넘겨 호출할 수도 있어요:

```php
$double = function ($number) {
    return $number * 2;
};

$double(2); // returns 4
$double(4); // returns 8
```
