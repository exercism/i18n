# 소개

ABAP에는 여러 가지 숫자 타입이 있어요. 이 연습 문제에서는 그중 두 가지를 사용해요:

- `i`는 날짜 수와 같은 정수 값을 나타내는 데 사용해요.
- `p`는 시간당 요금이나 할인율 같은 팩형 십진수 값을 나타내는 데 사용해요.

```abap
DATA billable_days TYPE i VALUE 22.
DATA rate_per_hour TYPE p LENGTH 8 DECIMALS 2 VALUE '89.89'.
```

팩형 숫자는 최대 길이와 소수 자릿수를 정의해요. 십진수 리터럴은 보통 텍스트 값으로 작성하며, 컴파일러가 대상 십진수 타입으로 변환하거나 `CONV`로 변환해요.

```abap
TYPES discount_rate TYPE p LENGTH 8 DECIMALS 6.

DATA discount TYPE discount_rate.
discount = CONV discount_rate( '0.15' ).
```

ABAP은 반올림을 위한 내장 숫자 함수를 제공해요. `floor` 함수는 가장 가까운 정수로 내림하고, `ceil`은 가장 가까운 정수로 올림해요.

```abap
DATA full_months TYPE i.
full_months = floor( 70 / 22 ).

DATA rounded_cost TYPE i.
rounded_cost = ceil( '14527.2' ).
```
