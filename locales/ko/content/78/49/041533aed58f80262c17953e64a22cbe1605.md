# 설치

연습 문제를 풀려면 다음 소프트웨어가 필요해요:

1. [`OPAM`, OCaml 패키지 관리자](https://opam.ocaml.org/)

   운영 체제에 맞게 `OPAM`을 설치하고 설정하는 방법은 [Real World Ocaml, 2nd Ed.: Installation Instructions](https://dev.realworldocaml.org/install.html)를 참고해요.

2. OCaml 컴파일러

   사용할 수 있는 버전 목록은 다음과 같이 확인해요:

   ```bash
   opam switch
   ```

   OCaml 5.1용 switch가 이미 있다면 `opam switch <switch-name>` 명령을 실행해서 불러오거나, 다음을 실행해서 새 switch를 만들어요:

   ```bash
   opam switch create exercism 5.4.0
   ```

   여기서 `exercism`이라는 이름은 선택 사항이지만, switch에 이름을 붙이는 건 좋은 습관이에요.

3. 확장 표준 라이브러리와 테스트 라이브러리 설치

   이 트랙에 필요한 의존성을 설치하려면 다음을 실행해요:

   ```bash
   opam install base core_kernel ounit qcheck
   ```

   일부 연습 문제는 OCaml 표준 라이브러리만 사용하고, 일부는 Jane Street의 확장 라이브러리인 Base와 Core_kernel을 사용해요.
   테스트 라이브러리는 OUnit이고, 일부 연습 문제는 속성 기반 테스트를 위해 QCheck 라이브러리도 사용해요.
   위 명령을 실행하면 이 라이브러리들이 설치돼요.

4. 대화형 셸 설치 및 사용(선택 사항)

   [Setting up and using `utop`](https://dev.realworldocaml.org/install.html) 요약:

   ```bash
   opam install utop
   ```

   홈 디렉터리에 `.ocamlinit`이라는 새 파일을 만들고 다음 줄을 추가해요:

   ```ocaml
   #use "topfind";;
   #require "base";;
   open Base
   ```

5. VS Code에 도구 설치(선택 사항)

   VS Code를 사용한다면:
   - [여기](https://github.com/ocaml/ocaml-lsp)에서 OCaml 언어 서버를 설치해요.
   - [여기](https://marketplace.visualstudio.com/items?itemName=ocamllabs.ocaml-platform)에서 OCaml VS Code 확장을 설치하거나, Ocaml Labs의 `OCaml Platform`을 검색해요.
