# 소개

SystemVerilog는 [하드웨어 기술 언어][HDL](HDL)와 [하드웨어 검증 언어][HVL](HVL)의 하이브리드로, 이를 줄여 HDVL이라고 해요.
즉, 전자 회로의 형태와 동작을 기술하는 동시에 하드웨어 기술 언어로 표현된 전자 회로를 검증해요.
SystemVerilog는 2005년에 [Verilog][Verilog] 언어에 몇 가지 수정을 가한 Verilog의 상위 집합으로 만들어졌고, 2012년에는 [IEEE][IEEE] 1800-2012 표준으로 승격되었어요.
SystemVerilog는 더 동적인 클래스 수준 테스트 벤치를 바탕으로 해요.

제약 기반 랜덤 생성, 단언 기반 검증, 커버리지 기반 검증은 모두 SystemVerilog에서 완전한 검증 환경을 구축하는 데 사용돼요.
이러한 접근 방식은 검증 과정을 크게 향상시켜요.
SystemVerilog에는 [RTL 설계][RTL-Design] 효율을 높이고 설계 과정을 단순화하는, 개선된 하드웨어 모델링 기술도 있어요.

SystemVerilog는 시뮬레이션 도구의 구성 요소예요.
실행하는 데 다른 도구나 GUI, 또는 PLI 같은 인터페이스가 전혀 필요하지 않아요.
새로 필요한 컴파일 명령도 없어요.
그래서 SystemVerilog는 빠르게 도입되고 있고, 설계자들은 사용하기 쉽고 간단하다고 느껴요.
전반적인 성능 또한 이 단일 환경이 주는 장점 중 하나예요.
SystemVerilog에서의 검증은 시뮬레이션 도구에 외부 인터페이스를 필요로 하는 다른 어떤 검증 언어보다 적어도 두 배는 빨라요.
