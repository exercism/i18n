# 소개

많은 프로그램은 실제 세계의 사건을 흉내 내기 위해 (의사)난수 값이 필요해요.

흔히 접할 수 있는 예로는 이런 것들이 있어요.

- 동전 던지기: 'H', 'T' 중에서 하나를 무작위로 고르기
- 주사위 굴리기: 1부터 6까지의 무작위 정수
- 카드 섞기: 카드 목록을 무작위 순서로 재배열하기
- 3차원 그래픽 시뮬레이션에서 나무와 덤불 만들기

컴퓨터로 진짜 난수를 만들어 내는 일은 [놀랄 만큼 어려운 기술적 과제][why-randomness-is-hard]예요. 그래서 "의사난수" 생성기도 있는 거예요.

~~~exercism/advanced
JavaScript의 [언어 명세][spec]는 난수 생성 방식을 강제하지 않아요.
모든 주요 브라우저와 JavaScript 런타임은 PRNG(의사난수 생성기)를 구현해요.
이 숫자들은 암호학적으로 안전하지 않기 때문에, 인증서나 비밀번호를 만들거나 다루는 작업처럼 진짜 난수 또는 최소한 암호학적으로 안전한 난수가 필요한 곳에는 절대 써서는 안 돼요.

JavaScript에서 암호화 작업을 하기 위한 인터페이스를 표준화한 [Web Cryptography][rfc]라는 표준이 있어요.
이 표준은 [브라우저][crypto-web]는 물론 [Node.JS][crypto-node], [Deno][crypto-deno] 같은 런타임에서도 구현되어 있어요.

이 개념은 Web Crypto에 관한 것이 아니고, 의사난수 생성에만 초점을 맞춰요.

[rfc]: https://www.w3.org/TR/webcrypto-2/
[spec]: https://tc39.es/ecma262/multipage/numbers-and-dates.html#sec-math.random
[crypto-web]: https://developer.mozilla.org/en-US/docs/Web/API/Crypto/getRandomValues
[crypto-node]: https://nodejs.org/api/webcrypto.html#cryptogetrandomvaluestypedarray
[crypto-deno]: https://docs.deno.com/api/web/~/Crypto

## 난수 생성하기

JavaScript에서는 [`Math.random()`][Math.random] 함수로 의사난수를 만들 수 있어요.
이 함수는 0 이상 1 미만의 의사난수 실수를 반환해요.

_min_ 이상 _max_ 미만의 난수를 얻으려면 다음과 비슷한 함수를 쓰면 돼요.

```javascript
function getRandomInRange(min, max) {
  return min + Math.random() * (max - min);
}
getRandomInRange(4, 10);
// => 5.72
```

## 난수 정수 생성하기

난수 정수를 만들려면 `Math.floor()`나 `Math.ceil()`로 난수를 정수로 바꾸면 돼요.
