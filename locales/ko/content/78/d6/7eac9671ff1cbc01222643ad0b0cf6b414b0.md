# 도움말

문제가 생겼을 때 도움을 받을 수 있는 몇 가지 방법이 있어요:

- [The Emacs Wiki](http://emacswiki.org/)는 정말 유용해요. 여기서 많은 시간을 보내봐요.
- [The Emacs Editor](http://www.gnu.org/software/emacs/manual/html_node/emacs/index.html)는 GNU Emacs의 공식 매뉴얼이에요.
- IRC - [Libera.Chat](https://libera.chat/)에는 `#emacs`, `#org-mode`를 비롯한 여러 Emacs 패키지 채널이 있고, 도움을 주는 사람들도 많이 있어요. 그리고 emacs에서는 IRC가 `M-x erc`만큼이나 가까이에 있어요.
- Matrix - [Matrix](https://matrix.org/)에는 [emacs](https://matrix.to/#/#emacs:matrix.org), [org-mode](https://matrix.to/#/#org-mode:matrix.org), 그리고 다른 Emacs 패키지들을 위한 방들이 있어요. 사용 가능한 채널을 한눈에 둘러보려면 [Emacs Matrix 스페이스에 참여](https://matrix.to/#/#emacs-space:matrix.org)하면 돼요. Emacs 안에서 Matrix에 참여하려면 [Ement.el](https://github.com/alphapapa/ement.el) 패키지를 사용하면 돼요.
- [StackOverflow](http://stackoverflow.com/questions/tagged/elisp)와 [Emacs StackExchange](https://emacs.stackexchange.com/questions/tagged/elisp)에서 문제를 검색하고 이미 답변이 있는지 확인할 수 있어요. 질문하고 답변을 달 수도 있어요.
