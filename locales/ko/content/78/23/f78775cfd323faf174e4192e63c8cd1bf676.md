# 학습

Tcl은 매우 단순하면서도 강력한 언어를 목표로 설계됐어요. 그래서 [Tcl의 기본 문법][syntax]을 배우는 것은 아주 쉬워요.

직접 따라 해 보는 튜토리얼은 [Learn X in Y minutes: Tcl][X-in-Y]을 참고해요.

더 여러 편으로 이루어진 자세한 튜토리얼은 다음과 같아요:
 - [The Tcl tutorial][tutorial]은 Tcl 8.5 버전을 다뤄요 (현재 안정 버전은 9.1이에요)
 - 객체 지향 프로그래밍 지원은 Tcl 코어에 8.6 버전에서 추가됐어요.
   Magicsplat에는 이를 다루는 자세한 [OO 튜토리얼][oo-tutorial]이 있어요.
