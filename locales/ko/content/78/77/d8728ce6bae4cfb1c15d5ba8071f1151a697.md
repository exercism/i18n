# 지시 사항

이 연습 문제에서는 Exercism에서 배우고 싶은 프로그래밍 언어 배열을 관리하는 코드를 작성해요.

여섯 개의 과제가 있고, 모두 배열을 다루는 내용이에요.

## 1. 새 배열 만들기

배우고 싶은 언어를 계속 관리하려면 새 배열을 만들어야 해요. 비어 있는 새 배열을 담는 `newList` 바인딩을 정의해요.

```fsharp
newList
// => []
```

## 2. 기존 배열 정의하기

지금은 배우고 싶은 언어가 적힌 종이 한 장이 있어요. 바로 F#, Clojure, Haskell이죠. 이 배열을 나타내는 `existingList` 바인딩을 정의해요.

```fsharp
existingList
// => ["F#"; "Clojure"; "Haskell"]
```

## 3. 배열에 새 언어 추가하기

Exercism을 둘러보다가 더 흥미로운 언어를 발견하면 배열에 추가하고 싶어져요. 배열 맨 앞에 새 언어를 추가하는 `addLanguage` 함수를 구현해요.

```fsharp
addLanguage "TypeScript" ["JavaScript"; "CoffeeScript"]
// => ["TypeScript"; "JavaScript"; "CoffeeScript"]
```

## 4. 배열에 있는 언어 세기

언어를 하나씩 세는 건 번거로워요. 배열에 있는 언어의 개수를 세는 `countLanguages` 함수를 구현해요.

```fsharp
countLanguages ["C#"; "Racket"; "Rust"; "Ruby"]
// => 4
```

## 5. 배열 뒤집기

어느 순간, 배열의 순서가 사실 거꾸로 되어 있다는 걸 깨달아요! 배열을 뒤집는 `reverseList` 함수를 구현해요.

```fsharp
reverseList ["Prolog"; "C"; "Idris"; "Assembly"]
// => ["Assembly"; "Idris"; "C"; "Prolog"]
```

## 6. 배열이 흥미진진한지 확인하기

모든 언어를 사랑하지만, F#은 마음속 특별한 자리를 차지하고 있어요. 그래서 다음과 같은 언어 배열이면 정말 신나요:

- 배열의 첫 번째 항목이 F#이에요.
- 배열의 두 번째 항목이 F#이고, 배열에 언어가 두 개 또는 세 개 들어 있어요.

언어 배열이 흥미진진한지 확인하는 `excitingList` 함수를 구현해요:

```fsharp
excitingList ["Nim"; "F#"]
// => true
```
