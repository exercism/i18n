# 소개

## 숫자

C#에는 두 가지 종류의 숫자가 있어요:

- 정수: 소수점 뒤에 숫자가 없는 수예요. 예를 들어 `-6`, `0`, `1`, `25`, `976`, `500000` 등이 있어요.
- 실수: 소수점 뒤에 0개 이상의 숫자가 있는 수예요. 예를 들어 `-2.4`, `0.1`, `3.14`, `16.984025`, `1024.0` 등이 있어요.

C#에서 가장 흔히 쓰이는 숫자 타입은 `int`와 `double`이에요. `int`는 32비트 정수이고, `double`은 64비트 실수예요.

산술 계산은 표준 산술 연산자로 해요. 숫자는 표준 숫자 비교 연산자와 같음(`==`), 다름(`!=`) 연산자로 비교할 수 있어요.

C#에는 두 가지 숫자 변환이 있어요:

1. 암시적 변환: 데이터가 손실되지 않고, 추가 문법도 필요 없어요.
2. 명시적 변환: 데이터가 손실될 수 있고, _캐스트_ 형태의 추가 문법이 필요해요.

`int`는 `double`보다 정밀도가 낮기 때문에, `int`에서 `double`으로 변환하는 것은 안전하고 따라서 암시적 변환이에요. 하지만 `double`에서 `int`로 변환하면 데이터가 손실될 수 있어서 명시적 변환이 필요해요.

```csharp
int softCool = 1358938113;
double notLost = 4.8151623;

// implicit cast: no loss of information
double macDebug = softCool;         // 1358938113.0

// explicit cast: possible loss of information 
int somethingLost = (int)notLost;   // 4
```

## `if` 문

이 연습 문제에서는 조건에 따라 로직을 실행해야 해요. C#에서 이렇게 하는 가장 흔한 방법은 `if/else` 문을 사용하는 거예요:

```csharp
int x = 6;

if (x == 5)
{
    // Execute logic if x equals 5
}
else if (x > 7)
{
    // Execute logic if x greater than 7
}
else
{
    // Execute logic in all other cases
}
```

`if` 문의 조건은 `bool` 타입이어야 해요. C#에는 _truthy_한 값이라는 개념이 없어요.
