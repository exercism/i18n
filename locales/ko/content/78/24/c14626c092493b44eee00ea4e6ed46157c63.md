# 소개

우리가 사용하는 언어의 이름 Lisp은 _LIST Processing_을 줄인 말이에요. 그렇다면 이 언어에 항목들의 배열을 다루는 기능이 있으리라고 짐작할 수 있겠죠. 그리고 그 짐작은 맞아요!

Common Lisp에는 배열 말고도 다른 자료 구조가 있지만, 배열은 여전히 아주 많이 쓰여요.

Common Lisp에서 배열은 항목들이 순서대로 나열된 것이에요. 주로 역사적인 이유로 **cons**라고도 불러요.
항목들이 꼭 같은 타입일 필요는 없어요.
예를 들어 `1`, `two`, `"III"`로 이루어진 배열을 만들 수 있어요.

## 배열 만들기

다음처럼 따옴표를 붙인 배열을 그냥 입력하면 돼요: `'(1 two "III")`. 그러면 배열이 만들어지고 평가돼요(평가 결과는 `(1 two "III")`예요).

배열을 만드는 데 주로 쓰이는 함수가 두 개 있어요: `list`과 `cons`.

`list`는 인자를 0개 이상 받아서, 그 값들로 만든 배열로 평가돼요:

```lisp
(list 1 'two "III") ; => (1 two "III")
```

`cons`는 항목 두 개를 받아서, 첫 번째 항목을 `car`(배열의 머리)로, 두 번째 항목을 `cdr`(배열의 나머지 부분)로 갖는 배열을 만들어요:

```lisp
(cons 1 2)            ; => (1 . 2) ;; (a list without `nil` as its `cdr` is printed in this way)
(cons 1 nil)          ; => (1)
(cons 1 (cons 2 nil)) ; => (1 2)
```

`car`와 `cdr` 함수를 사용하면 배열의 `car`와 `cdr`에 접근할 수 있어요.

(`first`와 `rest`는 `car`와 `cdr`의 동의어이고, 완전히 똑같이 동작해요.)

## 길이와 임의 접근

배열의 길이는 `length`로 구할 수 있어요.
빈 배열의 길이는 0이에요.

임의의 항목에는 `nth`로 접근할 수 있어요(배열의 인덱스는 0부터 시작해요).

배열의 길이보다 큰 인덱스를 요청한다고 해서 오류가 나는 건 _아니에요_. 대신 `nil`로 평가돼요:

```lisp
(nth 23 '(short list)) ; => nil
```

배열의 앞쪽 항목들에 접근할 수 있게 해 주는 도우미 메서드도 여러 개 있어요: `first`, `second`, `third`, 이런 식으로 `tenth`까지요. 멋지죠?

## 배열 합치기

두 개 이상의 배열은 `append`로 합칠 수 있어요: 

```lisp
(append '(a b c) '(1 2 3)) ; => (A B C 1 2 3)
(append '(a b c) '())     ; => (A B C)
```

`append`에 주는 각 인자는 배열이어야 해요.
