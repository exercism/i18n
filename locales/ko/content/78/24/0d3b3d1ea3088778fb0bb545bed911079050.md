# 소개

F#에서 판별 공용체 타입을 사용하는 흔한 방법 중 하나는 고정된 이름의 상수 집합을 나타내는 거예요. 다른 언어에서는 이런 구조를 "enum"이라고 불러요.

보통 이런 판별 공용체에서 각 케이스는 그 이름 있는 상수 중 정확히 하나만 가리킬 수 있어요. 하지만 때로는 상수 하나 이상을 가리키는 게 유용할 때도 있어요. 이럴 때는 판별 공용체에 Flags 특성을 붙이면 돼요.

Flags 특성을 붙인 판별 공용체는 다음과 같이 정의할 수 있어요(이진 정수 표기법 0b를 사용해요):

```fsharp
[<Flags>]
type PhoneFeatures =
| Call = 0b00000001
| Text = 0b00000010
```

`0b00000011` 값을 가진 `PhoneFeatures` 인스턴스는 `Call`과 `Text` 플래그가 모두 설정돼 있어요.
