# 힌트

## 일반

- 불리언 값을 다룰 때 쓸 수 있는 불리언 연산자는 `not`, `&&`, `||` 세 가지예요.
- 여러 연산자를 하나의 표현식 안에서 함께 사용할 수 있어요.

## 1. 팩맨이 유령을 먹을 수 있는지 정의하기

- 함수는 `Bool` 값을 반환해야 해요.
- 불리언 연산자 `&&`를 사용해 인자들을 조합한 결과를 만들 수 있어요.

## 2. 팩맨이 점수를 얻는지 정의하기

- 함수는 `Bool` 값을 반환해야 해요.
- 불리언 연산자 `||`를 사용해 인자들을 조합한 결과를 만들 수 있어요.

## 3. 팩맨이 지는지 정의하기

- 함수는 `Bool` 값을 반환해야 해요.
- 불리언 연산자 `&&`와 `not`을 사용해 인자들을 조합한 결과를 만들 수 있어요.

## 4. 팩맨이 이기는지 정의하기

- 함수는 `Bool` 값을 반환해야 해요.
- 불리언 연산자 `&&`와 `not`을 사용해 인자들과 앞에서 구현한 함수 중 하나의 결과를 조합할 수 있어요.
