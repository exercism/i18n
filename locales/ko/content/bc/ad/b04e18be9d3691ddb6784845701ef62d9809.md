# 연습 문제 잠금 해제

연습 문제의 잠금 해제 방식은 트랙 유형에 따라 달라요.

1. 학습 문제가 없는 트랙: 모든 실습 문제가 처음부터 잠금 해제되어 있어요.
2. 학습 문제가 있는 트랙: 학습 문제를 완료하면 추가 학습 문제와 실습 문제의 잠금이 해제돼요.

## 학습 모드와 실습 모드

더 많은 연습 문제의 잠금을 해제하려면 학습 문제를 완료해야 하는 방식을 학습 모드라고 해요(Exercism 3.0에서 도입됐어요).
학습 문제가 있는 트랙에 참여한 사용자에게는 학습 모드가 기본이에요. 예전 사이트에서 넘어온 사용자에게도 마찬가지예요.
실습 모드는 그 반대로, 모든 연습 문제가 처음부터 잠금 해제되어 있어요.

실습 모드든 학습 모드든 특정 연습 문제에 대해 멘토링을 요청할 수 있다는 점을 기억해 두세요.

### 다시 돌아온 사용자

이전 버전의 Exercism을 사용했던, 다시 돌아온 사용자라면 예전에는 이용할 수 있었던 연습 문제가 이제는 잠겨 있을 수 있어요.
학습 모드에 머물면서 학습 문제를 풀어 다른 연습 문제의 잠금을 해제하는 걸 권장해요(해당 언어에 능숙하다면 문제 하나를 푸는 데 약 5분이면 충분해요). 그 대신 학습 모드에서 실습 모드로 전환할 수도 있어요.

### 모드 전환하기

모드를 전환하려면 참여한 트랙의 트랙 페이지로 가서 오른쪽 상단의 "..." 아이콘을 클릭해요.
그런 다음 현재 모드에 따라 "Disable Learning Mode" 또는 "Enable Learning Mode"를 선택하고, 모드를 전환하겠다고 확인해요.

참고로, 현재 모드가 트랙 목록 페이지에 표시되기까지는 시간이 조금 걸려요.
