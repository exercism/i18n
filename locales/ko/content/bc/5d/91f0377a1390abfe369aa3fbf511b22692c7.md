# 문자열

**문자열**은 텍스트 조각이에요. Sather에서 문자열의 타입은 `STR`이고, 문자열은 큰따옴표 사이에 써요.

```sather
   composer : STR is
      return "Sibelius";
   end;
```

## 문자열 이어 붙이기

`+`는 두 문자열을 끝과 끝으로 이어 붙여요.

```sather
"Jean" + " " + "Sibelius"      -- "Jean Sibelius"
```

사이에 아무것도 넣지 않기 때문에 공백은 따로 챙겨야 해요. 빠뜨리면 `"JeanSibelius"`가 돼요.

## 길이는 얼마나 될까요?

`.size`는 문자열이 담고 있는 문자의 개수예요. 정수이므로 타입은 `INT`예요.

```sather
"Sibelius".size      -- 8
```

`.size` 뒤에는 괄호가 없어요. 인자를 받지 않는 루틴과 같아요.

## 일부분 가져오기

`.head(n)`은 처음 `n`개 문자예요. `.tail(n)`은 마지막 `n`개예요.

```sather
"Sibelius".head(3)   -- "Sib"
"Sibelius".tail(4)   -- "lius"
```

`head`는 앞에서부터 세고, `tail`은 뒤에서부터 세요. 둘 다 원래 문자열은 그대로 두고 새 문자열을 반환해요.
