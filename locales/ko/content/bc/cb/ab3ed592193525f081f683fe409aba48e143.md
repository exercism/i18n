# 소개

switch 식은 값을 여러 패턴 중 하나의 케이스와 일치시킨 뒤, 그에 해당하는 값을 반환하거나 해당 동작을 수행할 수 있어요. 이때 연결은 `=>` 기호로 나타내요. 또한 각 패턴에는 `when` 키워드로 시작하는 선택적 케이스 가드를 붙일 수 있어요. switch의 해당 "암"이 선택되려면 케이스 가드 식이 true로 평가되어야 해요. 케이스는 _switch 암_이라고도 하는데, 코드에 적힌 순서대로 평가돼요. 일치하는 것을 찾는 즉시 처리가 중단되고 해당 값이 반환돼요.

```csharp
double xx = 42d;

string interesting = xx switch
{
    0 => "I suppose zero is interesting",
    3.14 when DateTime.Now.Day == 14 && DateTime.Now.Month == 3 => "Mmm pie!",
    3.14 => "π",
    42 => "a bit of a cliché",
    1729 => "only if you are a pure mathematician",
    _ => "not interesting"
};

// => interesting == "a bit of a cliché"
```
