# 개요

[ABAP][abap]은 SAP가 ABAP 플랫폼의 ABAP 개발 환경을 사용해 비즈니스 애플리케이션을 개발하기 위해 만든 프로그래밍 언어예요.

ABAP은 다음을 지원해요:

- ABAP Objects의 클래스와 인터페이스를 기반으로 하는 객체 지향 프로그래밍 모델
- 함수 모듈과 서브루틴을 기반으로 하는 절차적 프로그래밍 모델

두 모델은 서로 함께 사용할 수 있지만, Exercism에서는 객체 지향 프로그래밍 모델에만 초점을 맞춰요.

더 자세한 내용은 [ABAP 트랙][docs] 문서에서 확인할 수 있어요.
