# 소개

## 익명 함수

Gleam에는 일급 함수가 있어요. 일급 함수란 함수가 일반적인 값이라는 뜻으로, 변수에 할당할 수 있고, 인자로 전달할 수 있으며, 다른 함수에서 반환할 수도 있어요.

모듈에 정의된 이름 있는 함수는 그 이름으로 참조할 수 있어요.

```gleam
pub fn main() {
  // Assign the function to a variable
  let f = add_one
  
  // Invoke the function
  f(1) // -> 2
  f(2) // -> 3
}

fn add_one(x) {
  x + 1
}
```

Gleam에는 익명 함수도 있는데, 익명 함수는 다른 함수 안에서 정의해요.

```gleam
// Define the function
let f = fn(x) { x + 1 }

// Invoke the function
f(1) // -> 2
f(2) // -> 3
```

함수의 타입은 익명 함수와 비슷한 문법으로 써요. `Int`와 `Float`를 받아서 `Int`를 반환하는 함수의 타입은 이렇게 써요:

```gleam
fn(Int, Float) -> Int
```

익명 함수는 정의될 당시 스코프에 있던 변수를 참조할 수 있는데, 그래서 이런 함수를 _클로저_라고 해요.

```gleam
let secret_number = 42

// This function always returns 42
fn() { secret_number }
```

_함수 캡처_ 문법은 하나의 인자를 함수에 전달하는 익명 함수를 만들 때 편리한 축약형이 되어 줘요. 다음 두 표현은 서로 같아요:

```gleam
// Anonymous function syntax
let f = fn(x) { my_function(1, 2, x) }

// Function capture syntax
let f = my_function(1, 2, _)
```
