# 메인테이너 리포지터리 권한

트랙 메인테이너는 해당 트랙의 GitHub 팀 구성원인 사람을 말해요. 트랙 팀의 구성원이 되는 것은 _초대 전용_이에요.

```exercism/note
트랙 메인테이너가 되고 싶다면 [포럼](https://forum.exercism.org/c/exercism/building-exercism/125)에 새 주제를 만들어 주세요.
```

## 유지보수 카테고리

유지보수 카테고리는 다섯 가지예요:

1. `wip-track`
2. `unmaintained`
3. `maintained-solitary`
4. `maintained-autonomous`
5. `maintained`

트랙의 유지보수 카테고리는 세 가지 변수로 결정돼요:

1. 트랙이 활성 상태인지 (즉, 학생이 웹사이트에서 트랙에 참여할 수 있는지)
2. 트랙 메인테이너 수
3. 트랙 메인테이너 중 `cross-track-maintainers` GitHub 팀에도 속한 사람 수

유지보수 카테고리를 정하려면, 다음 표에서 트랙에 처음 해당하는 카테고리를 찾아요:

| 카테고리              | 활성? | 메인테이너 수 | 트랙 간 메인테이너 수 |
| --------------------- | ----- | ------------- | --------------------- |
| wip-track             | 아니요 | 상관없음      | 상관없음              |
| unmaintained          | 예    | 0             | 0                     |
| maintained-autonomous | 예    | > 0           | = 메인테이너 수       |
| maintained-solitary   | 예    | 1             | 0                     |
| maintained            | 예    | > 1           | < 메인테이너 수       |

## 리포지터리 권한

유지보수 카테고리는 트랙의 GitHub 리포지터리 권한을 설정하는 데 사용돼요.

| 카테고리              | PR 필요 | PR 승인 필요 | 트랙 간 팀 리뷰 |
| --------------------- | ------- | ------------ | -------------- |
| wip-track             | 아니요  | 아니요       | 아니요         |
| unmaintained          | 예      | 예           | 예             |
| maintained-solitary   | 예      | 예           | 예             |
| maintained-autonomous | 예      | 아니요       | 아니요         |
| maintained            | 예      | 아니요       | 아니요         |

```exercism/caution
`wip-track` 카테고리는 메인테이너가 `main`에 푸시할 수 있는 유일한 카테고리예요.
```

```exercism/caution
툴링 리포지터리는 _항상_ PR 승인이 필요해요. 내용이 [CODEOWNERS 파일](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-code-owners)로 보호되기 때문이에요.
```
