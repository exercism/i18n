# 개요

Elixir에는 정수와 실수, 두 가지 종류의 수가 있어요.

정수는 소수점이 없는 수예요.

```elixir
integer = 3
# => 3
```

정수를 다룰 때 유용한 함수 몇 가지는 [`Integer`][integer] 모듈에서 찾을 수 있어요.

```elixir
Integer.digits(123)
# => [1, 2, 3]
```

큰 정수는(실수도 마찬가지지만) 보통 세 자리마다 밑줄을 넣어 묶어서 표기해요.

```elixir
1_000_000
# => 1000000
```

Elixir는 [임의 정밀도 연산][arbitrary-precision-arithmetic]을 사용하기 때문에, 수의 최대 크기는 시스템에서 사용할 수 있는 메모리에 의해서만 제한돼요.

Elixir는 [2진수, 8진수, 16진수 정수][integers-in-other-bases]를 입력하기 위한 축약 표기도 지원해요.

```elixir
0b0100
# => 4

0o555
# => 365

0xFF
# => 255
```

## 비교

정수와 실수는 값이 같으면 같은 것으로 볼 수 있어요([`==`][kernel-equal]). 하지만 서로 다른 타입이기 때문에 엄격하게 같을 수는 없어요([`===`][kernel-strictly-equal]).

```elixir
1 == 1.0
# => true

1 === 1.0
# => false
```
