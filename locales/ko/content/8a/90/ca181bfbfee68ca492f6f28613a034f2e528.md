# 추가 안내

어디서부터 시작해야 할지 고민되나요? 정리해볼 만한 것들을 몇 가지 꼽아봤어요:

- 함수 하나가 모든 일을 처리하기
- 중복된 로직과 반복되는 작업
- 깊은 중첩
- 의미를 알기 어려운 이름
- 여기저기 흩어진 형식 규칙
- 설명 없는 상수
- 불필요한 가변 상태
- 암시적인 열거형 폴백
- 관계없는 책임을 가진 헬퍼
- 오류를 대신하는 빈 문자열
- 직접 작성한 날짜 파싱과 포맷팅 (대신 `isodate.Date`를 임포트해서 사용해 봐요)
- 직접 처리하는 유니코드 (대신 `unicode.Grapheme`를 임포트해서 사용해 봐요)

눈에 들어오는 것부터 골라서 고쳐 보고, 테스트는 계속 통과하도록 유지해 봐요!
