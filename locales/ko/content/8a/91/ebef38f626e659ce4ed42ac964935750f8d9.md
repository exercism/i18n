# 소개

이 연습 문제는 [레아의 맛있는 라자냐][lasagna]에서 다룬 정수 연산을 바탕으로 해요. 여기서는 실수를 다루고, 상황에 맞는 나눗셈 단어를 골라 봐요.

## 정수와 실수

Factor는 정수(`1`, `42`, `1_000_000`)와 실수(`1.0`, `3.14`, `6.02e23`)를 구분해요. 하나의 계산에서 정수와 실수를 섞으면 결과는 실수로 나와요:

```factor
2 3 + .      ! => 5
2 3.0 + .    ! => 5.0
```

숫자 안에 밑줄을 넣어 자릿수를 묶을 수도 있어요(`1_000_000`). Factor는 밑줄을 그냥 무시해요.

## 나눗셈 단어

Factor에는 나눗셈 단어가 따로 있어요. 이 단어들은 모두 [`math`][math] 어휘에 들어 있어요.

```
/    ( x y -- x/y )    ! exact: ratio for two integers, float if either is a float
/f   ( x y -- f   )    ! always a float
/i   ( x y -- q   )    ! integer division (truncates toward zero)
mod  ( x y -- r   )    ! remainder
/mod ( x y -- q r )    ! quotient and remainder together
```

```factor
1 2 / .        ! => 1/2     (a proper ratio)
16 3 / .       ! => 5+1/3   (an improper ratio, printed as a mixed numeral)
16 3 /f .      ! => 5.333333333333333
16 3 /i .      ! => 5      (truncated)
16 3 mod .     ! => 1
16 3 /mod .s   ! quotient and remainder in one pass
! => 5
! => 1
16.0 3 / .     ! => 5.333333333333333
```

`/`는 두 정수에 대해 `ratio`(Factor의 정확한 유리수 타입)를 만들고, 둘 중 하나가 실수면 `float`를 만들어요. `/f`는 두 정수라도 항상 실수 결과를 내요. `/i`는 항상 0 방향으로 버려요.

## 확인하기

[`math`][math], [`math.functions`][math.functions], [`math.primes`][math.primes]의 숫자 판별 단어들이에요.

```
zero?    ( x       -- ? )
even?    ( x       -- ? )
odd?     ( x       -- ? )
prime?   ( x       -- ? )
divisor? ( m n     -- ? )    ! true when n divides m
integer? ( x       -- ? )    ! true for ints (fixnum or bignum)
float?   ( x       -- ? )    ! true for floats
number?  ( x       -- ? )    ! true for any numeric kind
```

```factor
0 zero? .            ! => t
0.0 zero? .          ! => t
3 zero? .            ! => f

4 even? .            ! => t
7 even? .            ! => f
7 odd? .             ! => t

7 prime? .           ! => t
9 prime? .           ! => f

15 5 divisor? .      ! => t   (5 divides 15)
15 4 divisor? .      ! => f
```

## 실수를 정수로

[`math.functions`][math.functions] 어휘의 `floor`, `ceiling`, `round`는 모두 실수(`3.0`, `3`이 아니라)를 반환해요. 진짜 정수를 얻으려면 `>integer`를 이어 붙여요:

```factor
3.7 floor >integer .       ! => 3
3.2 ceiling >integer .     ! => 4
```

## 거듭제곱과 절댓값

[`math.functions`][math.functions]에 있는 `sq`, `^`, `abs`는 제곱, 임의의 거듭제곱, 절댓값을 계산해요:

```
sq  ( x   -- x*x )
^   ( x y -- x^y )
abs ( x   -- |x| )
```

```factor
5 sq .          ! => 25
2 10 ^ .        ! => 1024
2 0.5 ^ .       ! => 1.4142135623730951
-7 abs .        ! => 7
3 abs .         ! => 3
```

## 최솟값과 최댓값

`min ( x y -- z )`와 `max ( x y -- z )`([`math.order`][math.order]에 있어요)는 두 수 중 더 작은 값이나 더 큰 값을 반환해요:

```factor
3 7 min .       ! => 3
3 7 max .       ! => 7
```

가장 흔한 용도는 *클램핑*이에요. `max`로 값을 하한에 고정하거나(예를 들어 `0 max`는 값을 음수가 아니게 유지해요), `min`으로 상한에 고정하는 거예요.

## 순서 판별 단어

`math.order`에는 순서를 매길 수 있는 모든 타입, 즉 숫자, 문자열, 문자에서 동작하는 비교 판별 단어 `before?`, `after?`, `before=?`, `after=?`도 있어요:

```
before?  ( obj1 obj2 -- ? )   ! obj1 <  obj2
before=? ( obj1 obj2 -- ? )   ! obj1 <= obj2
after?   ( obj1 obj2 -- ? )   ! obj1 >  obj2
after=?  ( obj1 obj2 -- ? )   ! obj1 >= obj2
```

값이 문자열일 수도 있으면 `<`/`<=` 대신 이걸 사용해요. 산술 연산자는 문자열에 대해서는 동작하지 않아요.
