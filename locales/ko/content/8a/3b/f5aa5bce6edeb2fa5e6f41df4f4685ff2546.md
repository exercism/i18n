# Exercism의 Rust 트랙에서 다루지 않는 것은 무엇인가요?

이 문서는 Rust 언어와 커뮤니티, 생태계가 허용하는 범위 안에서 Exercism의 Rust 트랙이 무엇을 가르칠 수 있고 무엇을 가르칠 수 없는지 설명하기 위한 것이에요.

특정 연습 문제의 _design.md_에서 "Out of scope" 항목으로 다루는 내용은 여기에 다시 적지 않아요. 다만 그 주제가 다른 곳에서는 충분히 눈에 띄지 않는다고 판단될 때는 예외예요.

## 웹 UI의 한계

웹 UI를 사용하는 학생은 웹 인터페이스와 테스트 러너가 허용하는 것 안에서만 작업할 수 있어요. 그래서 웹 UI의 기능은 사실상 Rust 트랙의 바깥 한계가 돼요.

학생이 할 수 있는 일은 다음과 같아요:

- `.rs` 파일 하나 편집하기
- `stdout`으로 출력 받기 (예: `dbg!`에서)

특히 이는 학생이 Cargo.toml을 편집할 수 없다는 뜻이에요. 따라서 외부 크레이트에 의존하는 연습 문제는 필요한 의존성을 모두 Cargo.toml에 미리 포함하고 있어야 해요.

## Exercism이 다루지 않는 것

Exercism은 프로그래밍 언어를 유창하게 다루는 법을 익히는 곳이에요. 소프트웨어 설계나 컴퓨터 과학처럼 더 추상적인 기술을 가르치는 곳이 아니죠. 그래서 Rust 프로그래밍 언어와 특별히 관련이 없는 주제는 Rust 트랙의 범위에 들어가지 않아요.

## 제외되는 주제의 예시

제외되는 주제의 예시는 다음과 같아요:

### Cargo

- Cargo.toml 편집
- CLI 명령, 예를 들어 `new`, `update`, `bench`

### 프레임워크

- Amethyst
- Yew, Iced, Sauron 등

### 상호 운용성

- CFFI
- `asm!`

### 일반적으로:

- 파일 처리
- 네트워킹
