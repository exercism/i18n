# 테스트

각 연습 문제에는 테스트 파일이 하나씩 들어 있어요.
`bats` 프로그램으로 테스트를 실행해요.

```bash
bats hello_world.bats
```

로컬에서 테스트를 실행하면서 디버그 출력을 확인하고 싶다면 [로컬에서 디버깅하기][debugging]를 참고해요.

`bats`를 설치해야 해요.
사용 중인 시스템에 `bats`를 설치하는 방법은 [Bash 트랙의 테스트 안내][tests] 페이지를 참고해요.

[tests]: https://exercism.org/docs/tracks/bash/tests
[debugging]: https://exercism.org/docs/tracks/bash/debugging

## assert 함수 도움말

테스트는 [bats-assert][bats-assert] 라이브러리의 함수를 사용해요.
여러 `assert*` 함수에 대한 도움말은 그곳에서 찾을 수 있어요.

[bats-assert]: https://github.com/bats-core/bats-assert

## 건너뛴 테스트

연습 문제를 풀었다는 건 그 문제의 모든 테스트를 통과했다는 뜻이에요.
기본적으로 테스트를 실행하면 첫 번째 테스트 하나만 실행돼요.
이건 의도된 동작이에요. 그 테스트 하나만 통과시키는 데 집중할 수 있거든요.
그 테스트를 통과하면 다음 어노테이션을 주석 처리하거나 삭제해서 다음 테스트를 활성화할 수 있어요:

```bash
[[ $BATS_RUN_SKIPPED == true ]] || skip
```

## 건너뛰기 무시하기

`skip` 어노테이션이 붙은 테스트를 포함해 모든 테스트를 실행하려면 다음 명령을 실행해요:

```bash
BATS_RUN_SKIPPED=true bats exercise_name.bats
```

타이핑을 줄이려면 래퍼 함수를 만들어 두는 게 편해요:

```bash
bats() {
    BATS_RUN_SKIPPED=true command bats *.bats
}
```

그러면 이렇게만 실행하면 돼요:

```bash
bats
```
