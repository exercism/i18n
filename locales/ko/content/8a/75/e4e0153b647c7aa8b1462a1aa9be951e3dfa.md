# 자세히 알아보기

Factor의 조건문은 모두 분기로 **쿼테이션**을 받아요. 쿼테이션은 대괄호로 감싸서 쓴 코드 `[ ... ]`인데, 곧바로 실행되는 대신 값으로 푸시되고, 조건문이 그것을 선택할 때 실행돼요. (쿼테이션 자체는 뒤에 나오는 연습 문제에서 자세히 다뤄요.)

기본이 되는 세 가지는 `kernel`에 있어요:

```
if      ( ? then-quot else-quot -- )
when    ( ? quot -- )
unless  ( ? quot -- )
```

별표가 붙은 두 가지 변형은, 불리언이 참으로 평가될 때 그 값을 쓸 만한 값으로 취급해요. 흔히 말하는 "값 아니면 `f`" 쌍이죠:

```
if*     ( ? true false -- )    ! truthy: true called WITH value
unless* ( ? false      -- )    ! falsy: false runs and pushes default
```

```factor
: abs   ( x -- y ) dup 0 < [ neg ] [ ] if ;
: shout ( s -- )   dup empty? [ drop ] [ >upper print ] if ;
```

분기가 세 개 이상일 때는 `combinators`에 있는 `cond`를 사용해요. `cond`는 `{ predicate body }` 쌍으로 이루어진 배열을 훑으면서, 가장 먼저 참이 되는 predicate의 body를 실행해요. 관례적인 패턴은 각 predicate에서 `dup`을 써서 입력값이 살아남게 하고, body는 결과를 푸시하기 전에 `drop`으로 그 값을 버리면서 시작해요:

```factor
{
    { [ dup 0 <  ] [ drop "negative" ] }
    { [ dup 0 =  ] [ drop "zero"     ] }
    [ drop "positive" ]
} cond
```

맨 끝에 predicate 없이 놓인 항목이 기본 분기예요.
