# 함수 수준 가드 사용

[comment]: # (이 오류는 풀이에서 가드를 사용하지만, 그 가드가 함수 절에 있지 않을 때 발생해요)

`two_fer/1`이 이진수가 아닌 입력으로 코드를 실행하지 않도록, 함수 절에서 [가드](https://hexdocs.pm/elixir/master/guards.html)를 사용해요.

```elixir
def hello(what) when is_binary(what) do
  "Hello, #{what}!"
end
```

함수가 주어진 절 중 어느 것과도 일치하지 않는 인자와 함께 호출되면 `FunctionClauseError`가 발생해요.

```elixir
hello(123)

# => ** (FunctionClauseError) no function clause matching in hello/1
#
#    The following arguments were given to Foo.hello/1:
#
#    # 1
#    123
```
