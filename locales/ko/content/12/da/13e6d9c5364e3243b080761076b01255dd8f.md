# 튜플 타입

튜플은 Cairo에서 다양하게 활용할 수 있는 효율적인 복합 데이터 타입으로, 서로 다른 타입의 여러 값을 하나로 묶을 수 있게 해줘요.
튜플은 길이가 고정되어 있어서, 한 번 선언하면 크기를 바꿀 수 없어요.

## 튜플 만들기

튜플을 만들려면 괄호 안에 값을 쉼표로 구분해서 나열해요.
튜플의 각 위치에는 정해진 타입이 있고, 이 타입들은 서로 다를 수 있어요.

```rust
fn main() {
    let tup: (u32, u64, bool) = (10, 20, true);
}
```

튜플은 다른 튜플을 포함해 서로 다른 데이터 타입의 값을 여러 개 담을 수 있어요.
예를 들면 다음과 같아요:

```rust
fn main() {
    let nested_tup: ((i32, u64), (u8, bool)) = ((10, 3), (5, false));
}
```

여기서 `nested_tup` 변수는 두 개의 튜플을 담은 튜플이고, 튜플이 다른 튜플을 원소로 담을 수 있다는 것을 보여줘요.

## 튜플 구조 분해

튜플 안의 개별 값에 접근하려면 패턴 매칭으로 튜플을 구조 분해할 수 있어요.
그러면 튜플이 각 구성 요소로 나뉘어요.

```rust
fn main() {
    let tup = (500, 6, true);

    let (x, y, z) = tup;

    println!("x is: {x}"); // prints "x is: 500"
    println!("y is: {y}"); // prints "x is: 6"
    println!("z is: {z}"); // prints "z is: true"
}
```

## 선언과 구조 분해를 동시에

튜플을 선언하면서 동시에 구조 분해할 수도 있어요.

```rust
fn main() {
    let (x, y): (felt252, felt252) = (2, 3);
}
```

## 유닛 타입 `()`

유닛 타입은 Cairo에서 값이 `()` 하나뿐인 특별한 타입이에요.
원소가 없는 튜플로 표현돼요.
유닛 타입의 크기는 항상 0이고, 컴파일된 코드에는 존재하지 않는 것이 보장돼요.

Cairo에서는 모든 표현식이 값을 반환하고, 표현식이 아무것도 반환하지 않을 때는 암묵적으로 `()`를 반환해요.
이는 값을 반환해야 하지만 반환할 만한 값이 없는 함수에 유용할 수 있어요.

## 네임드 튜플 타입 선언

네임드 튜플을 사용하면 튜플에 더 설명적인 타입 별칭을 만들어 코드 가독성을 높일 수 있어요.

```rust
type Point = (u32, u32);

fn main() {
    let point: Point = (10, 8);
    println!("{point:?}"); // prints "(10, 8)"
}
```

이 예제에서 `Point`는 부호 없는 32비트 정수 두 개를 나타내는 네임드 튜플 타입으로, 코드를 더 표현력 있게 만들어줘요.
