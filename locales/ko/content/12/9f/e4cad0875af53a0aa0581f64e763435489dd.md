# 개요

[concept:csharp/enumerables]()에서는 [`foreach`문][foreach-statement]을 사용해 반복할 수 있어요:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```

`foreach`문은 세 부분으로 이루어져 있어요:

1. 선언: 반복되는 값을 담을 변수를 정의해요. 이 변수는 루프 안에서만 사용할 수 있어요.
2. 반복 가능한 객체: 반복할 수 있는 객체예요.
3. 루프 본문.

## `for`문과 `foreach`문의 차이

하지만 일반적으로 `foreach`문이 `for`문보다 선호되는데, 그 이유는 다음과 같아요:

- `foreach`문은 _모든_ 값을 반복하는 것이 보장돼요. `for`문에서는 off-by-one 오류 같은 이유로 원소를 빠뜨리기 쉬워요.
- `foreach`문은 더 _선언적_이에요. 코드가 _무엇을_ 하고 싶은지를 표현하는 반면, `for`문은 _어떻게_ 하고 싶은지를 표현해요.
- `foreach`문은 실수할 여지가 없지만, `for`문은 off-by-one 오류를 내기 쉬워요.
- `foreach`문은 인덱서로 원소에 접근하는 것을 지원하지 않는 컬렉션을 포함해, 모든 컬렉션 타입에서 동작해요.

`foreach`문이 _모든_ 값을 반복하도록 보장하기 위해, 컴파일러는 `foreach`문 안에서 컬렉션을 수정하는 것을 허용하지 않아요:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

`for`문이 `foreach`문보다 나은 점도 몇 가지 있어요:

- 원하는 인덱스에서 시작하거나 멈출 수 있어요.
- 원하는 (불리언) 종료 조건을 사용할 수 있어요.
- 루프 변수의 증가 방식을 바꿔 원소를 건너뛸 수 있어요.
- 카운트다운해서 컬렉션을 뒤에서 앞으로 처리할 수 있어요.
- 컬렉션이 관여하지 않는 상황에서도 `for`문을 사용할 수 있어요.

관련 주제:

- C#은 `int[,] arr = new int[10, 5]` 같은 [다차원 배열][multi-dimensional-arrays]을 지원하고, 이는 매우 유용할 수 있다는 점을 알아두면 좋아요.
- 또한 `Array.CreateInstance`로 [`System.Array`][system-array-object] 타입의 객체를 만들 수 있다는 점도 알아두면 좋아요. 이런 객체는 거의 쓸모가 없고, 주로 VB.NET 코드와의 상호 운용을 위한 것이에요. 표준 배열(`T[]`)과는 서로 바꿔 쓸 수 없어요. 이 객체들은 0이 아닌 하한을 가질 수 있어요.
