# 조건문

**조건문**은 어떤 것이 참인지에 따라 두 가지 행동 중 하나를 선택해요.

```sather
   verdict(score : INT) : STR is
      if score >= 5 then
         return "Recalled";
      else
         return "Thank you";
      end;
   end;
```

읽어 보면, `if`가 있고, 그다음에 `true` 또는 `false`로 답하는 질문이 오고, 그다음에
`then`이 와요. 답이 참이면 `then` 다음 줄이 실행되고, 거짓이면 `else` 다음 줄이
실행돼요. `end;`는 전체를 닫아요.

## 두 가지보다 많은 경우

`elsif`는 또 다른 질문을 추가하는데, 위의 질문들이 모두 거짓일 때만 물어봐요.

```sather
   verdict(score : INT) : STR is
      if score >= 8 then
         return "Cast";
      elsif score >= 5 then
         return "Recalled";
      else
         return "Thank you";
      end;
   end;
```

순서가 중요해요. 점수가 `9`라면 첫 번째 질문에 걸려서 두 번째 질문까지는 가지
않아요. `9 >= 5`도 참인데도 말이에요. 이런 실수는 보통 검사를 잘못된 순서로 쓰기
때문에 생겨요.

철자는 `elsif`예요. `elseif`도, `else if`도 아니에요.

## `else` 생략하기

그런 경우에 할 일이 없으면 `else`를 생략할 수 있어요.

```sather
   if late then
      apologise;
   end;
```

무언가를 반드시 반환해야 하는 루틴은 모든 경로에서 반환해야 하므로, 이 연습
문제에서는 모든 `if`가 `else`를 함께 가져요.
