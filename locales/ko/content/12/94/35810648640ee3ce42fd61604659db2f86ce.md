# 소개

엘릭서의 모든 오류는 _Exception Behaviour_를 구현해요. _Access Behaviour_와 마찬가지로, _Exception Behaviour_는 모듈이 그 비헤이비어의 소프트웨어 계약을 충족하기 위해 구현해야 하는 콜백 함수를 정의해요. 오류를 한 번 정의하고 나면 다음과 같은 속성을 가져요.

- 모듈의 이름이 오류의 이름이 돼요.
- 모듈이 오류 구조체를 정의해요.
- 구조체에는 `:message` 필드가 있어요.
- 모듈을 `raise/1`과 `raise/2`와 함께 사용해서 의도한 오류를 발생시킬 수 있어요.

_Exception Behaviour_는 두 개의 콜백인 `message/1`과 `exception/1`도 지정해요. 구현하지 않으면 기본 구현이 사용돼요. `message/1`은 `raise`와 함께 호출되면 오류 구조체를 읽을 수 있는 메시지로 바꿔줘요. `exception/1`은 `raise/2`와 함께 호출되면 메시지에 추가적인 맥락을 더할 수 있게 해줘요.

## 예외 정의하기

오류 모듈로 예외를 정의하려면 `defexception` 매크로를 사용해요.

```elixir
# Defines a minimal error, with the name `MyError`
defmodule MyError do
  defexception message: "error"
end

# Defines an error with a customized exception/1 function
defmodule MyCustomizedError do
  defexception message: "custom error"

  @impl true
  def exception(value) do
    case value do
      [] ->
        %MyCustomizedError{}

      _ ->
        %MyCustomizedError{message: "Alert: " <> value}
    end
  end
end
```

## 예외 사용하기

정의한 오류는 내장 오류처럼 `raise/1`이나 `raise/2`로 사용할 수 있어요.

- `raise/1`은 모듈 이름으로 특정 오류를 발생시켜요. 인자가 문자열이면 그 문자열을 메시지로 하는 `RuntimeError`를 발생시켜요.
- `raise/2`는 모듈 이름으로 특정 오류를 발생시키고, 속성 인자를 받는데, 이 인자는 알맞은 메시지를 가진 오류를 얻는 데 사용돼요.
