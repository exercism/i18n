# 소개

JSON 문법과 데이터 타입에는 익숙하다고 가정할게요.

jq는 들어오는 JSON 데이터를 _단일 표현식_(_필터들의 파이프라인_으로 작성해요)에 통과시켜서 원하는 대로 변환된 데이터를 얻는 방식으로 동작해요.

<!-- prettier-ignore -->
~~~~exercism/note
`jq` 언어는 `jq` _프로그램_으로 구현돼 있어요.
이 프로그램은 입력을 어떻게 읽어들이고 출력을 어떻게 보여줄지 제어하는 몇 가지 편리한 명령줄 옵션을 제공해요.

아래 예제들에서 만나게 될 옵션은 다음과 같아요:

- `-n` 또는 `--null-input`

    보통 `jq` 프로그램에는 읽을 파일을 주거나, 입력으로 데이터를 보내요.
    `--null-input` 옵션을 사용하면 입력 없이 JSON 데이터를 만들 수 있어요.

- `-c` 또는 `--compact-output`

    `jq`는 기본적으로 출력을 보기 좋게 서식을 갖춰 출력해요.
    데이터가 보기 좋게 정리되어 있으면 사람이 살펴보기에 아주 유용해요.
    하지만 기계에는 그럴 필요가 없어요: `--compact-output` 옵션은 서식용 공백을 없애서 결과 JSON의 크기를 최소화해요.

- `-f filename` 또는 `--from-file filename`

    명령줄에서 주는 대신 `filename`에서 `jq` 프로그램을 읽어요.
    `sed`와 `awk`도 같은 목적으로 `-f` 옵션을 사용해요.
    연습 문제의 테스트 스크립트에서 이 옵션이 쓰이는 걸 보게 될 거예요.

이 수업의 나머지 부분에서는 `jq` _언어_에 집중할게요.
~~~~

## 필터와 파이프

**필터**는 **표현식**이라고도 해요.

_필터_는 입력을 받아 출력을 만들어요.
유닉스 셸에서 작업하는 방식처럼, 파이프 `|`로 _필터_를 이어서 한 _필터_의 출력을 다른 _필터_의 입력으로 연결할 수 있어요.

## 항등 필터: `.`

가장 단순한 _필터_예요.
입력을 그대로 출력으로 넘겨줄 뿐이에요.

```sh
$ echo '[1, 2, 3]' | jq '.'
[
  1,
  2,
  3
]
```

## 배열

**배열**을 다루는 짧은 소개예요.
이 주제는 나중에 더 자세히 다룰게요.

_배열_의 원소에는 대괄호로 접근하고, 인덱스는 0부터 시작해요.

```sh
$ echo '[10, 20, 30]' | jq '.[1]'
20
```

_필터_는 표현식을 `[`와 `]`로 감싸서 _배열_을 만들 수 있어요

- 알려진 원소 목록으로:

  ```sh
  jq -n '[1, 2, 3]'
  ```

- 원소의 스트림을 모으려면: 예를 들어,
  `range`는 숫자의 스트림을 출력하는 함수예요

  ```sh
  $ jq -n 'range(10; 70; 15)'
  10
  25
  40
  55
  ```

  `[]`를 사용하면 표현식의 결과를 배열로 모아요

  ```sh
  $ jq -c -n '[range(10; 70; 15)]'
  [10,25,40,55]
  ```

## 쉼표는 연산자예요

_쉼표_는 _배열_ 원소를 구분하는 문법만이 아니에요.
**쉼표**는 스트림을 이어 붙이는 **연산자**예요.

예를 들어 `[1, 2, 3]`은 세 표현식 `1`, `2`, `3`을 이어 붙인 결과를 모으기 위해 _배열_ 생성자 `[]`를 사용하는 _필터_예요.

위의 `range(10; 70; 15)`에 세미콜론이 들어 있는 게 눈에 띄나요?
_쉼표_가 `jq` 언어에서 특별한 역할을 하기 때문에, 여러 인자를 받는 함수는 인자를 구분할 때 세미콜론을 사용해요.

## 객체

**객체**를 다루는 짧은 소개예요.

많은 프로그래밍 언어와 비슷하게, 점을 사용해서 _객체_의 속성에 접근해요

```sh
$ echo '{"foo": {"bar": "qux"}}' | jq '.foo.bar'
"qux"
```

<!-- prettier-ignore -->
~~~~exercism/note
대괄호는 _객체_에도 사용할 수 있지만, 그럴 때는 문자열 리터럴에 따옴표가 필요해요.
공백이 들어간 키를 다루는 한 가지 방법이에요.

```sh
$ echo '{"foo bar": "qux"}' | jq '.["foo bar"]'
"qux"
```
~~~~

<!-- prettier-ignore-end -->

`{}`와 `key: value` 쌍으로 _객체_를 만들 수 있어요.
"단순한" 문자열인 _키_에는 따옴표가 필요하지 않아요.

```sh
jq -n '{question: (6 * 9), answer: 42}'
```

출력은

```none
{
  "question": 54,
  "answer": 42
}
```

_키_를 _표현식_으로 다루려면 괄호로 감싸야 해요 (다음도 위와 같은 결과를 출력해요).

```sh
echo '[{"key":"question", "value":54}, {"key":"answer", "value":42}]' \
| jq '{(.[0].key): .[0].value, (.[1].key): .[1].value}'
```

## 파이프라인

예를 들어, 다음 내용이 담긴 `file.json`이 있다고 해봐요.

```json
{
  "key1": "value1",
  "key2": [5, 15, 25]
}
```

key2 _배열_의 길이를 계산해봐요:

```sh
$ jq '.key2 | length' file.json
3
```

`.key2` 표현식의 출력을 `length`의 입력으로 _파이프_하고 있어요. 그러면 당연하게도 _배열_의 원소 개수가 출력돼요.

## 필터는 입력을 무시할 수 있어요

이 예제에서는 입력 JSON 데이터가 무시되고 출력에 아무 영향을 주지 않아요:

```sh
$ echo '{"answer": 42}' | jq '6 * 9'
54
```

## 필터는 데이터의 스트림을 출력할 수 있어요

_필터_는 값을 하나 이상 출력할 수 있어요.
예를 들어 `.[]` _필터_는 _배열_의 각 원소를 별도의 값으로 출력해요:

```sh
$ jq -n -c '[1, 2, 3]'
[1,2,3]

$ jq -n -c '[1, 2, 3] | .[]'
1
2
3
```

이런 _필터_를 다른 _필터_로 파이프하면 두 번째 _필터_가 **_각 값마다_** 실행돼요:

```sh
$ jq -n -c '[1, 2, 3] | .[] | . * 2'
2
4
6
```

암시적인 반복과 비슷해요.
이 기법을 이해하고 나면, 아주 강력한 `jq` _필터_도 아주 간결하게 쓸 수 있다는 걸 알게 될 거예요.

## 괄호

**괄호**는 다른 언어에서와 마찬가지로, 연산 순서를 강제하기 위해 하위 표현식을 묶는 데 사용해요.
`jq`에서는 괄호가 필요해지는 상황이 다소 의외로 느껴질 수 있어요.

예를 들어, 원소가 두 개인 _배열_을 만들고 싶다고 해봐요: 9의 제곱근, 그리고 1제곱한 _e_예요.
두 개의 개별 표현식은 `9 | sqrt`와 `1 | exp`예요.
출력이 _배열_ `[3, 2.7...]`이기를 기대해요

```jq
$ jq -n '[ 9|sqrt, 1|exp ]'
[
  20.085536923187668,
  2.718281828459045
]
```

왜 기대한 결과가 나오지 않았을까요? `jq`는 이것을 이렇게 해석해요:

```jq
[ ((9|sqrt), 1) | exp ]
```

`jq`는 두 원소(`3`과 `1`)로 이루어진 스트림을 만들고, 각각이 `exp`에 전달돼요.

`exp`가 숫자를 하나만 입력으로 받도록 해야 해요.
다시 말해, 쉼표보다 파이프가 먼저 평가되도록 강제해야 해요.

```jq
$ jq -n '[ 9|sqrt, (1|exp) ]'
[
  3,
  2.718281828459045
]
```

## 함수와 연산자

깊게 들어가지는 않고(함수는 다른 연습 문제에서 다룰 주제예요), 유용한 내장 함수 몇 가지를 소개할게요:

- `length`

  배열을 입력으로 받으면 배열의 원소 개수를 출력해요.

  ```sh
  $ jq -n '[10, 20, 30, 40] | length'
  4
  ```

- `+`

  이 연산자는 피연산자의 타입에 따라 하는 일이 달라요:
  숫자는 더하고,
  문자열은 이어 붙이고,
  배열은 뒤에 덧붙이고,
  객체는 병합해요.

  ```sh
  $ jq -c -n '
      3 + 4,
      "foo" + "bar",
      ["a", "b"] + ["c"],
      {"m": 10} + {"n": 20}
  '
  7
  "foobar"
  ["a","b","c"]
  {"m":10,"n":20}
  ```

  `add`는 배열을 받아서 모든 원소를 `+`의 규칙으로 더한 값을 반환하는 함수예요.
  `[1, 2, 3] | add`는 `6`을 출력해요.

- `map`

  배열을 입력으로, 필터를 인자로 받아서, 필터를 각 원소에 적용한 배열을 출력해요

  ```sh
  $ jq -c -n '[10, 20, 30, 40] | map(. / 5)'
  [2,4,6,8]
  ```

- `select`

  _어떤_ 입력과 필터를 인자로 받아요:
  - 인자로 주어진 필터를 적용한 결과가 _참_인 값이면, 입력을 그대로 출력해요
  - 그렇지 않으면 _아무것도_ 출력하지 않아요 (`null` 값이 아니라, 정말로 아무 출력도 없어요)

  예를 들어, 숫자들이 주어졌을 때 3으로 나누어 떨어지는 숫자만 선택해요

  ```sh
  $ jq -n 'range(10) | select(. % 3 == 0)'
  0
  3
  6
  9
  ```

  `range`는 숫자의 _스트림_을 출력한다는 걸 기억해요.
  `select`는 각 숫자마다 한 번씩 호출돼요.
  표현식을 "통과하는" 숫자만 출력돼요.

  배열의 원소를 선택해야 할 때가 자주 있어요.
  방법은 몇 가지가 있어요.

  입력이 `["Anne", "Bob", "Cathy", "Dave"]`일 때, 길이가 4인 이름을 선택해봐요.
  - `map`과 `select`를 함께 사용해요

    ```jq
    map(select(length == 4))
    ```

  - 배열을 원소 단위로 펼치고, 그 스트림에 `select`를 적용한 뒤, 결과를 모아요

    ```jq
    [ .[] | select(length == 4) ]
    ```
