# 지침 추가

## 레지스터

| 레지스터 | 용도      | 형식 | 설명                     |
| -------- | --------- | ---- | ------------------------ |
| `$a0`    | 입력      | 정수 | 상한값                   |
| `$a1`    | 입출력    | 주소 | 소수를 담을 대상 배열    |
| `$v0`    | 출력      | 정수 | 소수의 개수              |
| `$t0-9`  | 임시      | 임의 | 임시 저장에 사용         |
