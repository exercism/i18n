# 소개

Perl은 Larry Wall이 만들었고 1987년에 처음 공개된 프로그래밍 언어예요.

## 패키지와 모듈

패키지는 코드의 모음으로, 보통 같은 이름에 `.pm` 확장자를 가진 모듈 파일 안에 들어 있어요.
그다음 그 모듈을 다른 파일로 불러올 수 있는데, 보통 `use` 키워드를 사용해요.

```perl
# Foo.pm
package Foo;

# Accessible with `Foo::bar` when module is used
# or just `bar` if the subroutine is exported.
sub bar () {
    return 1;
}
```

## 변수

변수에는 스칼라(`$foo`), 배열(`@bar`), 해시(`%baz`)가 있어요.
간단하게 설명하기 위해 여기서는 스칼라 변수만 사용할게요.
스칼라 값은 문자열, 숫자, 불리언, 또는 무언가를 가리키는 [레퍼런스][perlreftut]가 될 수 있어요.
값이 없는 상태는 `undef`예요.


`my`와 `our` 키워드는 렉시컬 스코프에 변수를 선언해요. 예를 들면 `my $foo;`처럼요.
`our`를 사용하면 그 변수는 같은 이름의 패키지 변수와도 별칭으로 연결돼요.
변수를 선언하는 다른 방법들도 있지만 여기서는 다루지 않아요.

`=` 연산자로 변수에 값을 할당할 수 있어요. 예를 들어 `$foo = 1;`처럼요. 변수를 선언하면서 동시에 할당할 수도 있는데, 예를 들면 `my $foo = 1;`처럼요.

```perl
package Foo;

sub baz () {
    our $bar = 1; # Sets both $bar and $Foo::bar as 1.
    return $bar;
}

$Foo::bar = 2; # $bar is not accessible here, but $Foo::bar is.

# Both of these will print 1.
say baz;
say $Foo::bar;
```

## 서브루틴

`sub` 키워드는 [서브루틴][perlsub]을 선언해요.
`return` 키워드는 서브루틴을 빠져나오면서 지정한 값들을 반환하고, 아무것도 지정하지 않으면 빈 리스트를 반환해요.
`return`을 지정하지 않으면 반환되는 값은 그 서브루틴이 사용된 컨텍스트(스칼라, 리스트, 보이드)와 마지막 문에 따라 결정돼요.

```perl
sub hello () {
    return 'Hello, World!';
}
```

최근 버전의 Perl에서는 [시그니처][perlsubsig]로 정식 매개변수를 지정할 수 있어요.
매개변수 목록에는 스칼라, 배열, 해시 변수를 넣을 수 있어요.
매개변수 목록이 비어 있으면 그 서브루틴은 인자를 하나도 받지 않는다는 뜻이에요.
예전 버전의 Perl에서는 특수 변수 `@_`에서 인자를 가져와야 했는데, 여기서는 다루지 않아요.

## 주석

Perl의 주석은 문자열의 일부가 아닌 `#`으로 시작해서 줄 끝에서 끝나요.
