# 힌트

## 일반

- [튜플][tuple-module]은 연속된 메모리에 배치되며 어떤 데이터 타입이든 담을 수 있는 자료 구조예요.
- 아톰은 유한한 상태를 나타내는 데 사용할 수 있어요. 이 연습 문제에서는 사용하는 단위를 나타내기 위해 `:cup`, `:fluid_ounce`, `:teaspoon`, `:tablespoon`, `:milliliter`를 사용해요.
- 튜플을 다루기 위해 [`Kernel`][elem]이나 [`Tuple`][tuple-module] 함수를 사용하거나 패턴 매칭을 사용할 수 있어요.

## 1. 부피 쌍에서 숫자 성분 가져오기

- 부피 쌍의 숫자 성분을 반환하려면 [`Kernel` 모듈 함수][elem]를 사용하는 것을 고려해 봐요.

## 2. 부피 쌍을 밀리리터로 변환하기

- 조건부 제어 흐름 로직을 줄이려면 [여러 절을 가진 함수][multi-clause]와 [패턴 매칭][pattern-matching]을 사용해요.
- 밀리리터에서 밀리리터로의 변환을 포함해, 모든 단위에서 밀리리터로 변환하는 함수를 구현해요.

## 3. 밀리리터 부피 쌍을 다른 단위로 변환하기

- 조건부 제어 흐름 로직을 줄이려면 [여러 절을 가진 함수][multi-clause]와 [패턴 매칭][pattern-matching]을 사용해요.
- 밀리리터에서 밀리리터로의 변환을 포함해, 밀리리터에서 모든 단위로 변환하는 함수를 구현해요.

## 4. 어떤 단위에서 어떤 단위로든 변환하기

- 이미 만든 함수를 재사용해서 `convert/2` 함수에서 변환을 수행해요.
