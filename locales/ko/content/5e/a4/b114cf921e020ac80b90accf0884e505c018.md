# Rust 레퍼런스

## 개념

Rust 개념 연습 문제는 기초부터 언어를 능숙하게 다루는 단계까지의 개념을 가르쳐요. 아래에 분류해서 정리했어요.

Exercism의 개념은 학습자에게 실질적으로 도움이 되도록 존재하기에 추상적인 아이디어와는 달라요. 이 문서는 이런 개념이 Rust에서 무엇을 뜻하는지 정의해요. 아래에 시각적인 묶음을 추가한 것은 트랙 관리자가 효과적인 레퍼런스 문서를 만들도록 돕기 위해서예요. 이런 묶음은 교육적인 구분이 _아니에요_. 그러니 가르칠 때 이 묶음을 언급하지 말아 주세요.

체크박스는 각 개념이 연습 문제 매핑 목록에서 아직 가르쳐지는지를 나타내요.

## 개념 연습 문제 매핑

위에 나열한 각 개념마다 정확히 하나의 개념만 가르치고 그 선수 개념만 요구하는 개념 연습 문제를 하나씩 두는 것이 이상적이지만, 그렇게 하는 것이 완전히 실용적이지는 않아요. 예를 들어, 원시 타입에 대한 지식 없이 함수가 무엇인지 가르치는 연습 문제를 설계하기는 어려워요. 마찬가지로, 함수에 대한 지식 없이 테스트 스위트와 함께 원시 타입을 가르치기도 어렵죠.

이 표의 연습 문제들은 언젠가 위에 나열한 모든 개념을 아우르는 DAG를 이뤄야 해요.

| 연습 문제 | 선수 조건 | 가르치는 내용 | 설명 |
| --- | --- | --- | --- |
| `hello-world` | - | 함수, 테스트 스위트 | `&str` 리터럴 `"hello world"`를 반환해요 |
| `compiled-calculator` | `hello-world` | 정수, 변수 할당 | 일련의 수학 연산을 수행하고 결과를 암시적으로 반환해요 |
| `conditionals` | `hello-world` | 조건문 | 3개 분기 `if` / `else if` / `else`로 구성해야 해요; 암시적 반환 |
| `slices` | `hello-world`, `compiled-calculator` | 슬라이스 | 정수 슬라이스인 매개변수에서 슬라이스를 추출해요 |
| `loops` | `slices` | 슬라이스에 대한 기본 반복 | 이터레이터로 표현하기 번거롭도록, 가능하면 조기 반환을 넣어요 |
| `iterator-use` | `slices` | 이터레이터 사용, `collect` |  |
| `integer-sizes` | `compiled-calculator` | `i32`가 아닌 정수, 형 변환 | 여전히 모두 부호 있는 정수예요 |
| `unsigned-ints` | `integer-sizes` | 부호 없는 정수 |  |
| `indexing` | `integer-sizes`, `slices` | 인덱싱, `usize` |  |
| `floats` | `compiled-calculator` | 실수 | 아마 `compiled-calculator` 연습 문제와 같지만 결과가 정수가 아니에요 |
| `bools` | `compiled-calculator` | 불리언, 불리언 연산자 |  |
| `char` | `compiled-calculator` | `char` 데이터 타입 | 와이드 문자 예제를 몇 개 포함해야 해요 |
| `str-use` | `char`, `slices` | `&str` | 참고: 불변이에요! |
| `string-use` | `str-use` | `String` | 참고: 소유권이 있고, 가변적이에요 |
| `format-macro` | `string-use` | `format!` 매크로 |  |
| `str-vs-string` | `str-use`, `string-use` | 결합, 변환, 비용 등 |  |
| `generics-basics` | `integer-sizes`, `floats` | 외부 트레이트를 바운드로 사용하기, 제네릭 기초 | 아마 여전히 compiled-calculator지만 제네릭이에요 |
| `structs` | `string-use`, `unsigned-ints`, `floats` | 데이터를 관리하기 위해 구조체를 만들고 사용하기 | `Person`에는 이름, 키, 보유한 신발 개수가 있어요 |
| `implicit-return` | `compiled-calculator` | 스코프, 표현식, 암시적 반환 |  |
| `explicit-return` | `implicit-return`, `conditionals` | 명시적 `return`문 |  |
| `methods` | `structs`, `explicit-return` | `impl` 블록, 메서드 |  |
| `tuples` | `structs` | 튜플 | 익명 구조체로 가르쳐요; `.0` 문법도 가르쳐요 |
| `tuple-structs` | `tuples`, `structs` | 튜플 구조체 (이름 있는 튜플) |  |
| `basic-enums` | `unsigned-ints` | 기본 열거형 (필드 없음), `match` |  |
| `enums` | `basic-enums`, `tuple-structs` | 열거형 배리언트를 위한 튜플 문법 |  |
| `option` | `enums` | `Option<T>` |  |
| `result` | `enums` | `Result<T, E>` |  |
| `mutability` | `compiled-calculator` | 기본적으로 불변; 명시적 가변성 |  |
| `let-expressions` | `loops`, `option`, `result` | `if let`, `while let` | 구현에 따라 아마 `option`이나 `result` 중 하나에만 의존할 거예요 |
| `vectors` | `slices` | `Vec<T>` |  |
| `hashmaps` | `vectors` | `Hashmap<K, V>` |  |
| `entry-api` | `hashmaps` | Entry API |  |
| `hashsets` | `hashmaps` | `HashSet<K>` |  |
| `btreemaps` | `hashmaps` | `BTreeMap<K, V>` |  |
| `deriving-traits` | `structs` | `PartialEq`, `PartialOrd`, `Debug`, `Display`, `Default` |  |
| `implementing-traits` | `deriving-traits` | 트레이트 직접 구현하기 | 아마 `Iterator`를 구현해요 |
| `collection-conversions` | `vectors`, `hashsets`, `implementing-traits` | `FromIterator`, `IntoIterator` |  |
