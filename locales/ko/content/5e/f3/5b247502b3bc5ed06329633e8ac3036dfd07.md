# 자세히 알아보기

[`switch`문][switch]은 하나의 값을 여러 가지 일치하는 패턴과 비교해요.
여러 개의 `if-else`문을 이어 쓰는 것보다 더 깔끔하고 읽기 쉬운 방법이에요.

`switch`문은 `switch` 키워드로 시작하고, 그 뒤에 검사할 값이 와요.
일치할 수 있는 각 경우는 `case` 키워드로 시작해요.
`default` 키워드는 명시된 어떤 경우와도 일치하지 않을 때 실행되는 기본 경우를 정의해요.
`if-else`문을 이어 쓴 것과 마찬가지로, `switch`문은 처음 일치하는 경우의 코드 블록만 실행해요.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

다음 `if-else`문을 살펴봐요:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

이 코드는 `switch`문을 쓰면 더 명확하게 작성할 수 있어요:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## 값 바인딩과 `where` 절

`switch`문의 각 경우는 일치하는 값을 임시 상수나 변수에 바인딩해서 그 경우의 본문에서 사용할 수 있어요.
또한 각 경우에는 `where` 절을 붙여, 일치 여부를 판단하기 전에 추가 불리언 조건을 검사할 수 있어요:

```swift
let x = 1337
switch sumOfDivisors(of: x) {
case let total where total == x:
    print(total, "is a perfect number")
default:
    print(x, "is not a perfect number")
}
```
