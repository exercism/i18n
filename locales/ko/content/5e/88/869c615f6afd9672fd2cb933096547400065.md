# 지침

정원을 찾아오는 새를 매일 세는 열렬한 탐조가예요. 이 기록은 배열에 저장하는데, 오래된 날이 가장 앞에 와요.

## 1. 오늘의 개수

스택에서 일별 개수 배열을 꺼내 오늘의 개수를 반환하도록 `today`를 정의해요.

```factor
{ 2 5 0 7 4 1 } today .
! => 1
```

## 2. 오늘의 개수 늘리기

오늘의 개수를 하나 늘린 새로운 배열을 반환하도록 `increment-todays-count`를 정의해요. 원래 배열은 그대로 두어야 해요.

```factor
{ 2 5 0 7 4 1 } increment-todays-count .
! => { 2 5 0 7 4 2 }
```

## 3. 새가 한 마리도 없었던 날이 있었나요?

새가 한 마리도 없었던 날이 하루라도 있으면 `t`를, 그렇지 않으면 `f`를 반환하도록 `has-day-without-birds?`를 정의해요.

```factor
{ 2 5 0 7 4 1 } has-day-without-birds? .
! => t

{ 2 5 1 } has-day-without-birds? .
! => f
```

## 4. 처음 며칠의 합 구하기

개수 배열과 숫자 `n`을 받아 처음 `n`개 개수의 합을 반환하도록 `count-for-first-days`를 정의해요.

```factor
{ 2 5 0 7 4 1 } 4 count-for-first-days .
! => 14
```

## 5. 바쁜 날 세기

새가 다섯 마리 이상인 날을 바쁜 날이라고 해요. 배열에서 바쁜 날의 개수를 반환하도록 `busy-days`를 정의해요.

```factor
{ 2 5 0 7 4 1 } busy-days .
! => 2
```

## 6. 빠진 날 채우기

`n`일 동안 매일 관찰하지 않았다면, 뒤쪽에 빠진 날을 `0`으로 채워요. 개수 배열과 목표 길이 `n`을 받아, 길이가 적어도 `n`이고 남는 자리가 `0`인 배열을 반환하도록 `pad-missing-days`를 정의해요. 기존 개수는 그대로 유지해야 하고, 입력이 이미 `n` 이상이면 그대로 반환해요.

```factor
{ 2 5 0 } 7 pad-missing-days .
! => { 2 5 0 0 0 0 0 }

{ 4 1 6 8 } 3 pad-missing-days .
! => { 4 1 6 8 }
```
