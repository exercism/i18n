# 개요

[`fold`][fold]는 [소비하는 반복자 어댑터][consuming iterator adaptor]로, 반복의 각 원소에 함수를 적용해서 결과를 새로운 값으로 누적해요.

`fold`의 각 반복은 두 개의 인자를 받아요. 첫 번째는 누산기의 초깃값이에요. 두 번째는 그 자체로 두 개의 인자, 즉 누산기와 항목을 받는 클로저예요. 클로저의 반환값이 그다음 누산기 값이 돼요. 반복자가 모두 소진되면, 누산기의 최종 값이 반환돼요.

`fold`는 컬렉션을 하나의 값으로 변환하고 싶을 때 사용할 수 있어요. 예를 들어 모든 짝수의 합을 구하고 싶다면

```rust
pub fn main() {
    let even_sum = (1..=10).fold(0, |acc, num| if num % 2 == 0 { acc + num } else { acc });
    println!("{even_sum:?}");
}
```

`30`을 출력해요.

`fold`로 할 수 있는 일은 흔히 다른 함수나 함수들로도 할 수 있어요. 위의 경우라면 `(1..=10)`에 [`filter`][filter]를 적용한 다음 [`sum`][sum]을 하는 편이 더 간결하고 같은 결과를 내요. 이렇게요.

```rust
(0..=10).filter(|n| *n % 2 == 0).sum()
```

`fold`보다 더 흔히 쓰이는 다른 함수로는 [`product`][product]와 [`collect`][collect]가 있어요.

누산기는 숫자 값 외에도 사용할 수 있어요. 예를 들어

```rust
pub fn giant_grunts(initial: char) -> String {
    ["Bee", "Fee", "Gee", "Fi", "Hi", "Fo", "Mo", "Fum", "Tum"].iter().fold(
        String::new(),
        |acc, grunt| if grunt.starts_with(initial) { acc + grunt } else { acc },
    )
}

pub fn main() {
    let song = giant_grunts('F');
    println!("{song:?}");
}
```

`FeeFiFoFum`을 출력해요.
