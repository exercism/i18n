# 소개

`when`은 예외를 필터링할 때 쓰는 키워드예요. `catch`문 뒤에 위치하고, 그 시점에 스코프에 있는 값이라면 무엇이든 담을 수 있는 불리언 표현식을 받을 수 있어요. 표현식이 true로 평가되면 해당 `catch`문에 연결된 블록이 실행되고, 그렇지 않으면 다음 `catch`문이 있다면 그 문을 확인해요.

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```
