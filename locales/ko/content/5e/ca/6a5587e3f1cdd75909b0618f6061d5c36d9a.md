# 테스트 실행하기

운영체제를 선택해요:

- [Windows](#windows)
- [macOS](#macos)
- [Linux](#linux)

## Windows

1. 명령 프롬프트를 열어요.
2. 첫 번째 연습 문제를 내려받아요:

   ```batchfile
   C:\Users\JohnDoe>exercism download --exercise hello-world --track java
   ```

3. 연습 문제 디렉터리로 이동해요:

   ```batchfile
   C:\Users\JohnDoe>cd C:\Users\JohnDoe\exercism\java\hello-world
   ```

4. 테스트를 실행해요:

   ```batchfile
   C:\Users\JohnDoe>gradlew.bat test
   ```

   _(처음에는 테스트가 실패해도 걱정하지 마세요. 모든 연습 문제는 이렇게 시작해요.)_

5. 연습 문제를 풀어요. `instructions.append.md` 가이드를 찾아서 끝까지 따라 해봐요 ([GitHub에서 보기][hello-world-tutorial]).

행운을 빌어요! 즐겁게 해봐요!

## macOS

1. 터미널 창에서 첫 번째 연습 문제를 내려받아요:

   ```sh
   exercism download --exercise hello-world --track java
   ```

2. 연습 문제 디렉터리로 이동해요:

   ```sh
   cd /Users/johndoe/exercism/java/hello-world
   ```

3. 테스트를 실행해요:

   ```sh
   ./gradlew test
   ```

   _(처음에는 테스트가 실패해도 걱정하지 마세요. 모든 연습 문제는 이렇게 시작해요.)_

4. 연습 문제를 풀어요. `instructions.append.md` 가이드를 찾아서 끝까지 따라 해봐요 ([GitHub에서 보기][hello-world-tutorial]).

행운을 빌어요! 즐겁게 해봐요!

## Linux

1. 터미널 창에서 첫 번째 연습 문제를 내려받아요:

   ```sh
   exercism download --exercise hello-world --track java
   ```

2. 연습 문제 디렉터리로 이동해요:

   ```sh
   cd /home/johndoe/exercism/java/hello-world
   ```

3. 테스트를 실행해요:

   ```sh
   ./gradlew test
   ```

   _(처음에는 테스트가 실패해도 걱정하지 마세요. 모든 연습 문제는 이렇게 시작해요.)_

   다음과 같은 오류가 발생하면:

   ```sh
   ./gradlew: Permission denied
   ```

   파일에 실행 권한이 없다는 뜻이에요. 이 문제를 해결하려면 다음을 실행해요:

   ```sh
   chmod +x ./gradlew
   ```

   이제 이전 명령을 실행할 수 있을 거예요.

4. 연습 문제를 풀어요. `instructions.append.md` 가이드를 찾아서 끝까지 따라 해봐요 ([GitHub에서 보기][hello-world-tutorial]).

행운을 빌어요! 즐겁게 해봐요!
