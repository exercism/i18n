# MoonScript 트랙에서 테스트하기

MoonScript 트랙에서의 테스트는 [Lua 트랙에서의 테스트][lua-tests]와 똑같아요.
연습 문제 디렉터리에서 다음을 입력해요:

```console
$ busted
```

## 대기 중인 테스트

이 트랙은 Exercism의 [테스트 주도 개발][tdd] 방법론을 따라요.
완전한 테스트 스위트가 주어지지만, 첫 번째 테스트만 "활성" 상태예요.

테스트를 활성화하려면 테스트의 명령을 `pending`에서 `it`으로 바꿔요.

항상 모든 테스트를 실행하고 싶다면, 명령줄 도구로 한 번에 모두 바꿀 수 있어요.
다음은 perl을 사용한 예시예요(perl은 거의 모든 곳에 설치되어 있어요):

```console
$ perl -i -pe 's/^\s+\Kpending\b/it/' two_fer_spec.moon
```

온라인 편집기에서 작업할 때는 테스트 러너가 모든 테스트를 자동으로 실행해요.

## LuaRocks 사용하기

Lua 자체는 아주 작은 언어예요.
[LuaRocks][luarocks]는 Lua 모듈을 위한 패키지 관리자예요.

풀이에서 어떤 모듈이든 자유롭게 사용할 수 있지만, 온라인 테스트 러너에서 모든 모듈을 쓸 수 있는 건 아니에요.
테스트 러너는 다음을 제공해요:

**`busted` 의존성으로 이미 사용 가능**

* [penlight][penlight-home]
* [dkjson][dkjson-home]

**MoonScript 의존성으로 이미 사용 가능**

* [LPeg][lpeg-home]
* [LuaFileSystem][lfs-home]

**날짜와 시간**

* [date][date-home]
* [lua-tz][lua-tz-home]
* [luatz][luatz-home]
