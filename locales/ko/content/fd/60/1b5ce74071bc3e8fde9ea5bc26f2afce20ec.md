# 지시 사항

시청에서 일한 지도 꽤 됐고, 그동안 양식 작성 같은 일상 업무를 훨씬 빠르게 해 주는 도구들을 만들어 왔어요.

그런데 새 동료가 합류하게 되면서, 도구들이 그만큼 직관적이지는 않을 수도 있겠다는 생각이 들었어요.
사무실에는 이상한 관행이 많아요. 양식을 항상 대문자로 작성한다든지, 필드를 비워 두지 않는다든지 하는 식이죠.

그래서 첫 단계로, 새 동료가 곧바로 뛰어들어 도구를 사용할 수 있도록 PHP 타입 선언을 추가하기로 했어요.

## 1. `Address` 클래스의 타입을 선언해요

`Address` 클래스에 선언된 각 프로퍼티에 프로퍼티 타입 선언을 추가해요.
각 클래스 프로퍼티는 문자열로 선언해야 해요.

## 2. 빈 값으로 양식을 채울 때 쓸 타입을 선언해요

`Form` 클래스의 `blanks` 메서드에 매개변수 타입 선언과 반환 타입 선언을 추가해요.
이 메서드는 정수 길이를 받고, 빈 줄을 나타내는 문자열을 반환해야 해요.

## 3. 값을 각각의 글자로 나눌 때 쓸 타입을 선언해요

`Form` 클래스의 `letters` 메서드에 매개변수 타입 선언과 반환 타입 선언을 추가해요.
이 메서드는 단어를 나타내는 문자열을 받고, 글자 배열을 반환해야 해요.

## 4. 값이 양식에 들어갈 수 있는지 확인할 때 쓸 타입을 선언해요

`Form` 클래스의 `checkLength` 메서드에 매개변수 타입 선언들과 반환 타입 선언을 추가해요.
이 메서드는 단어를 나타내는 문자열과 최대 길이를 나타내는 정수를 받고, true 또는 false 값을 반환해야 해요.

## 5. 양식에서 주소의 형식을 지정할 때 쓸 타입을 선언해요

앞서 수정한 `Address` 클래스를 활용하는 매개변수 타입 선언과 반환 타입 선언을 `Form` 클래스의 `formatAddress` 메서드에 추가해요.
이 메서드는 `Address`를 받고, 형식이 지정된 문자열을 반환해야 해요.
