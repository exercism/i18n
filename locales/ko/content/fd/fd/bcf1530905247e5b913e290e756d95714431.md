# 소개

*힙*은 항상 가장 작은 항목이 무엇인지 알고 있고, 그 항목을 빠르게 꺼낼 수 있는 컬렉션이에요. *우선순위 큐*를 구현하는 자연스러운 방법이죠. 힙은 [`heaps`][heaps] 어휘에 들어 있어요.

`<min-heap>`은 가장 작은 키가 먼저 나오는 빈 힙을 만들어요. `<max-heap>`은 그 반대예요. 각 항목은 *키* 아래에 저장된 *값*이고, 이 키가 우선순위예요.

```
<min-heap> ( -- min-heap )
heap-push  ( value key heap -- )
```

```factor
USING: heaps ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
```

힙은 *변경 가능*해요. `heap-push`는 힙을 제자리에서 바꿔요. `heap-peek`은 맨 앞의 값과 키를 꺼내지 않고 반환하고, `heap-pop`은 꺼내서 반환해요. 그리고 `heap-pop-all`은 힙을 모두 비우면서 우선순위 순서대로 `{ key value }` 쌍으로 이루어진 연관 리스트를 만들어요.

```
heap-peek    ( heap -- value key )
heap-pop     ( heap -- value key )
heap-pop-all ( heap -- alist )
```

```factor
USING: heaps kernel prettyprint ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
dup heap-peek drop .     ! => "bob"
heap-pop-all .           ! => { { 2 "bob" } { 5 "alice" } }
```
