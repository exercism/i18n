# 소개

Swift에는 루프의 정상적인 제어 흐름을 바꾸는 데 사용할 수 있는 문들이 있어요.
이런 문을 제어 전달문이라고 해요.
`return`은 이미 봤고, 이번 개념에서는 `continue`, `break`, 레이블 같은 다른 문들을 알아볼 거예요.
이번 개념에서는 `fallthrough`는 다루지 않지만, [Swift 책][fallthrough]에서 읽어볼 수 있어요.

## Continue

때로는 루프의 현재 반복에서 나머지 문을 다 실행하지 않고 다음 반복으로 일찍 건너뛰어야 할 때가 있어요.
이럴 때 `continue` 키워드를 사용할 수 있어요.
`continue`가 실행되면 루프는 다음 반복을 실행할 수 있는지 확인하는 지점으로 건너뛰어요. 즉, `while` 루프와 repeat-while 루프에서는 `while` 조건으로, for-in 루프에서는 시퀀스에 다음 원소가 있는지 확인하는 부분으로 이동해요.

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

## Break

break는 루프를 일찍 빠져나갈 때 사용해요.
`break`가 실행되면 루프가 즉시 종료되고, 프로그램은 루프 다음의 첫 번째 문부터 계속 실행해요.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

## 레이블

루프가 중첩되어 있을 때는 `break`나 `continue`를 사용해서, 그 문이 속한 루프를 감싸고 있는 바깥쪽 루프를 빠져나가거나 다시 시작하고 싶을 때가 있어요.
이런 경우에는 레이블을 사용해서 빠져나가거나 다시 시작할 루프를 지정할 수 있어요.
루프를 시작하는 `while`, `repeat`, `for` 앞에 이름과 콜론을 붙이면 루프에 레이블을 지정할 수 있어요.

이렇게 레이블을 사용했을 때의 효과를 보려면 다음 루프를 살펴봐요.

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```
