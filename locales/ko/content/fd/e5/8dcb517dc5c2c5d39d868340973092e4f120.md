# 소개

Go에서 상수는 `const` 키워드로 이름에 할당하는, 변하지 않는 단순한 값이에요:

```go
const myWebsite = "Exercism"
```

이런 상수에는 타입이 없지만, 메서드에 전달할 때처럼 타입이 필요한 상황에서는 문법에 따라 기본 타입이 정해져요.
타입을 직접 적어서 타입이 있는 상수를 만들 수도 있어요:

```go
const myWebsite string = "Exercism"
```

Go에는 다른 언어들처럼 열거형이 없지만, 열거 상수를 만들기 위해 미리 선언된 식별자인 `iota`가 있어요.
블록 안에 있는 상수는 암묵적으로 반복돼요:

```go
const (
    a = 9
    b
    c
    d = iota
    e
    f
    g
)
fmt.Print(a, b, c, d, e, f, g)
// Output: 9 9 9 3 4 5 6
```
