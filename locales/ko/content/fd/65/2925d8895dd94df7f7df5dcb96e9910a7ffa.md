# 소개

가장 유용한 시퀀스 워드들은 *quotation*을 입력 중 하나로 받아서 그 연산을 수행해요:

```
each   ( seq quot -- )
map    ( seq quot -- newseq )
filter ( seq quot -- newseq )
reject ( seq quot -- newseq )
count  ( seq quot -- n )
any?   ( seq quot -- ? )
all?   ( seq quot -- ? )
```

```factor
{ 1 2 3 4 5 } [ even? ] filter .   ! => { 2 4 }
{ 1 2 3 4 5 } [ sq ] map .         ! => { 1 4 9 16 25 }
{ 1 2 3 4 5 } [ 2 > ] count .      ! => 3
```

`map-sum`은 (`sequences`에도 있어요) 시퀀스 전체에 quotation을 매핑하고 그 결과를 한 번에 더해요. 같은 패턴이 `sort-by`([`sorting`][sorting]에 있어요)와 `minimum-by`, `maximum-by`(`sequences`에 있어요)에도 쓰여요.

[sorting]: https://docs.factorcode.org/content/vocab-sorting.html
