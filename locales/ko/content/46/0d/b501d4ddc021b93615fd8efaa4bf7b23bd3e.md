# 코드 줄 수 카운터

코드 줄 수(LoC) 카운터는 풀이를 받아서 코드가 몇 줄인지 세어요.

기본적으로는 학생이 제출한 파일의 코드 줄 수만 세어요.
학생이 테스트 파일을 제출했다면, 그 파일은 무시해요.

대부분의 제출물에는 이 방식이 잘 맞지만, 트랙에 따라 추가로 무시해야 할 파일이 있을 수 있어요.
그래서 코드 줄 수 카운터를 [트랙별로 사용자 정의][lines-of-code-counter-customize]할 수 있게 해두었어요.

## 구현

실제로 세는 일은 [tokei][tokei] 라이브러리가 담당해요.
풀 리퀘스트가 빨리 병합되지 않는 경우가 많아서, 자체 [포크][tokei-fork]를 만들었어요.
덕분에 더 빠르게 개선을 반복하고, 원하는 언어에 대한 지원을 추가할 수 있어요.

## 지원하는 언어

[languages.json][languages.json] 파일에서 언어를 찾아보면, 그 언어가 기본으로 지원되는지 확인할 수 있어요.

### 새로운 언어 추가하기

사용하는 언어가 지원되지 **않는다면**, 다음 방법으로 지원을 추가할 수 있어요.

1. [languages.json] 파일에 해당 언어 항목을 추가해요.
   자세한 내용은 [언어 추가 문서][adding-language]를 확인해요.
2. 해당 언어의 줄 수 계산이 올바르게 동작하는지 확인하는 테스트를 추가해요.
   자세한 내용은 [테스트 추가 문서][adding-tests]를 확인해요.

이렇게 변경한 뒤에는 [exercism/tokei 저장소][tokei-fork]에 풀 리퀘스트를 열어요.
Arturo 언어 지원을 추가한 [예시 풀 리퀘스트][example-pr]도 있어요.
