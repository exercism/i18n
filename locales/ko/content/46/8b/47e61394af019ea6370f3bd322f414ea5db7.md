# 힌트

## 1. 처음부터 시작하기

- 배열을 만들려면 `make-array`를 사용해요.
- 배열의 차원은 `make-array`에 목록으로 지정해요.
- 모든 원소를 초깃값으로 설정하려면 `:inital-element` 키워드 매개변수를 사용해요.

## 2. 기존 보드에서 시작하기

- 배열의 초기 내용을 설정하려면 `:initial-contents` 키워드 매개변수를 사용해요.

## 3. 승리 조건

- `aref`를 사용하면 배열에서 셀의 값을 가져올 수 있어요.
- `eq`로 두 심볼이 같은지 확인할 수 있어요.
- `and`로 두 `eq` 표현식을 결합해 세 항목을 비교할 수 있어요.

## 4. 가로줄

- (2차원 배열에서) `aref`의 인자는 "행"과 "열"이에요.

## 5. 세로줄

- (2차원 배열에서) `aref`의 인자는 "행"과 "열"이에요.
