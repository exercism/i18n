# 지시 사항

작은 섬 페리의 운항 시간표를 관리하고 있어요. 출항은 날짜로 기록되는데, 이 날짜를 다루려면 몇 가지 도우미가 필요해요.

## 1. 출항 날짜 기록하기

`make-date`는 연도, 월, 일을 받아 그에 해당하는 타임스탬프를 반환하도록 정의해요.

```factor
2024 7 14 make-date .
! => T{ timestamp { year 2024 } { month 7 } { day 14 } ... }
```

## 2. 요일 이름 구하기

`weekday-name`은 운항 날짜의 타임스탬프를 받아 그 날짜가 무슨 요일인지 그 이름을 반환하도록 정의해요.

```factor
2024 1 8 make-date weekday-name .
! => "Monday"
```

## 3. 윤년

`leap?`는 연도를 받아 윤년인지 여부를 반환하도록 정의해요.

```factor
2024 leap? .   ! => t
2023 leap? .   ! => f
```

## 4. 한 달의 일수

`month-length`는 연도와 월을 받아 그 달의 일수를 반환하도록 정의해요 (2월을 잊지 마세요).

```factor
2024 2 month-length .   ! => 29
2023 2 month-length .   ! => 28
```

## 5. 며칠 뒤

`add-days`는 타임스탬프와 일수를 받아 그만큼 뒤의 타임스탬프를 반환하도록 정의해요.

```factor
2024 2 28 make-date 1 add-days >date< .
! => 29   (2024-02-29)
```
