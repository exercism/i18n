# 소개

## 키워드 배열

키워드 배열은 키-값 데이터 구조예요.

```elixir
[month: "April", year: 2018]
```

키워드 배열은 `{key, value}` [튜플][exercism-tuples]의 배열이고, 같은 형태로 쓸 수도 있지만 더 짧은 문법이 더 널리 쓰여요.

```elixir
[month: "April"] == [{:month, "April"}]
# => true
```

키워드 배열의 키는 반드시 [아톰][exercism-atoms]이어야 하지만, 값은 무엇이든 될 수 있어요. 각 키는 한 번 이상 사용할 수 있어요. 키워드 배열의 키-값 쌍에는 순서가 있어요.

키워드 배열은 배열과 같은 방식으로 다룰 수도 있고, `Keyword` 모듈을 사용할 수도 있어요.
