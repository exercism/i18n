# 힌트

## 1. 오븐 예상 시간을 분 단위로 정의하기

- 레시피에 나온 [정수][integers] 값을 담는 [상수][constants]를 정의해야 해요.
- 상수는 `Lasagna` [클래스][classes] 안에 정의해야 해요.
- 메서드 바깥에 정의해야 해요.

## 2. 남은 오븐 시간을 분 단위로 계산하기

- 지금까지의 실제 시간을 담을 매개변수 하나를 가진 [메서드][methods]를 정의해야 해요.
- 값의 뺄셈에는 수학 연산자(`-`)를 사용할 수 있어요.
- 앞에서 정의한 [상수][constants]를 사용할 수 있어요.

## 3. 준비 시간을 분 단위로 계산하기

- 층의 개수를 담을 매개변수 하나를 가진 [메서드][methods]를 정의해야 해요.
- 값의 곱셈에는 수학 연산자(`*`)를 사용할 수 있어요.

## 4. 총 작업 시간을 분 단위로 계산하기

- 이름이 있는 매개변수 두 개를 가진 [메서드][methods]를 정의해야 해요.
- 앞에서 정의한 다른 메서드 중 하나를 호출할 수 있어요.
- 값의 덧셈에는 수학 연산자(`+`)를 사용할 수 있어요.
