# 소개

Python의 딕셔너리(`dict`)는 [해시 가능한][term-hashable] _키_를 _값_에 연결하는 자료 구조예요. 다른 프로그래밍 언어에서는 크기를 조절할 수 있는 [해시 테이블][hashtable-wikipedia], 해시맵, 또는 [연관 배열][associative-array]로 알려져 있죠. 딕셔너리는 Python에 내장된 유일한 [매핑 타입][mapping-types-dict]이에요.


`Keys`는 해시 가능해야 하고 딕셔너리 전체에서 유일해야 해요.
키의 타입으로는 `numbers`, `str`, 또는 (_불변_ 값들로 이루어진) `tuples`가 올 수 있어요.
`lists`, `dict`s, `set`s처럼 _가변_ 자료 구조는 키가 될 수 없어요.
Python 3.7부터는 `dict`의 키 순서가 항목을 삽입한 순서대로 보장돼요.

`values`는 어떤 자료형이나 구조든 될 수 있어요.
 값은 _얼마든지_ 중첩될 수 있어서, 배열의 배열, 하위 딕셔너리, 그 밖의 사용자 정의 또는 복합 자료 구조를 담을 수도 있어요.

`key`가 주어지면 딕셔너리는 (평균적으로) 상수 시간에 `value`를 가져올 수 있어요(_항목 수와는 무관해요_).
`index` 위치를 모른 채 `list`나 `array` 안에서 값을 찾는 것과 비교하면, `dict`는 메모리를 훨씬 많이 쓰지만 값을 아주 빠르게 가져와요.
딕셔너리는 항목이 많고 자주 접근하고 갱신해야 하는 상황에서 특히 유용해요.


## 딕셔너리 만들기

딕셔너리는 여러 방법으로 만들 수 있어요.
가장 간단한 두 가지는 `dict()`생성자를 사용하는 것과 `dict` _리터럴_을 선언하는 것이에요.

### `dict()` 클래스 생성자

`dict()`(_딕셔너리 클래스의 생성자_)는 `key`, `value` 쌍으로 이루어진 이터러블이나 일련의 `<name>=<value>` _인자_와 함께 사용할 수 있어요:

```python
#Passing a list of key,value tuples.
>>> wombat = dict([('name', 'Wombat'),('speed', 23),('land_animal', True)])
{'name': 'Wombat', 'speed': 23, 'land_animal': True}


#Using key=value arguments.
>>> bear = dict(name="Black Bear", speed=40, land_animal=True)
{'name': 'Black Bear', 'speed': 40, 'land_animal': True}
```

### 딕셔너리 리터럴

`dict`는 중괄호(`{}`)로 `key : value` 쌍을 감싼 _딕셔너리 리터럴_로 직접 입력할 수도 있어요:

```python
>>> whale = {"name": "Blue Whale", "speed": 35, "land_animal": False}
{'name': 'Blue Whale', 'speed': 35, 'land_animal': False}
```

## 딕셔너리의 값에 접근하기

딕셔너리의 항목은 대괄호(`[]`) 안에 _키_를 넣어 접근할 수 있어요.
`dict`에 `key`가 없으면 `KeyError`가 발생해요:

```python
>>> bear["speed"]
40

>>> bear["color"]
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'color'
```

`.get(<key>, <default value>)` 메서드로 항목에 접근하면 `KeyError`를 피할 수 있어요:

```python
>>> bear.get("color", 'not found')
'not found'
```

## 딕셔너리 값 바꾸기와 추가하기

항목의 `value`는 _키_에 할당해서 바꿀 수 있어요:

```python
#Assigning the value "Grizzly Bear" to the name key.
>>> bear["name"] = "Grizzly Bear"
{'name': 'Grizzly Bear', 'speed': 40, 'land_animal': True}

>>> whale["speed"] = 25
{'name': 'Blue Whale', 'speed': 25, 'land_animal': False}
```

새로운 `key`:`value` 쌍도 같은 방식으로 _추가_할 수 있어요:

```python
# Adding a new "color" key with a new "tawney" value.
>>> bear["color"] = 'tawney'
{'name': 'Grizzly Bear', 'speed': 40, 'land_animal': True, 'color': 'tawney'}

>>> whale["blowholes"] = 1
{'name': 'Blue Whale', 'speed': 25, 'land_animal': False, 'blowholes': 1}
```

## 딕셔너리 항목 제거하기 (Pop)

`.pop(<key>)` 메서드로 딕셔너리 항목을 삭제할 수 있어요.
`.pop()`은 (`key`, `value`) 쌍을 제거하고 그 `value`를 반환해요.
`.get()`과 마찬가지로 `.pop(<key>)`는 두 번째 인자(_`dict.pop(<key>, <default value>)`_)를 받을 수 있는데, 이 값은 `key`를 찾지 못했을 때 반환돼요.
이렇게 하면 `KeyError`가 발생하지 않아요:

```python
#Using .pop() removes both the key and value, returning the value.
>>> bear.pop("name")
'Grizzly Bear'


#The "name" key is now removed from the dictionary.
#Attempting .pop() a second time will throw a KeyError.
>>> bear.pop("name")
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'name'


#Using a default argument with .pop() will prevent a KeyError from a missing key.
>>> bear.pop("name", "Unknown")
'Unknown'
```

## 딕셔너리 순회하기(반복하기)

`for item in dict`나 `while item`으로 딕셔너리를 순회하면 기본적으로 _키_만 반복해요.
같은 루프 안에서 _대괄호_를 사용하면 _값_에도 접근할 수 있어요:

```python
>>> for key in bear:
>>>     print((key, bear[key])) #this forms a tuple of (key, value) and prints it.
('name', 'Black Bear')
('speed', 40)
('land_animal', True)
```

`.items()` 메서드를 쓸 수도 있는데, 이 메서드는 (`key`, `value`) 튜플을 자동으로 반환해요:

```python
#dict.items() forms (key, value tuples) that can be unpacked and iterated over.
>>> for key, value in whale.items():
>>>     print(key, ":", value)
name : Blue Whale
speed : 25
land_animal : False
blowholes : 1
```

마찬가지로 `.keys()` 메서드는 `keys`를 반환하고 `.values()` 메서드는 `values`를 반환해요.
