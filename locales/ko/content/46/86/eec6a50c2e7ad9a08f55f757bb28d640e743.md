# 소개

Swift는 세 가지 주요 목표를 바탕으로 설계된, 컴파일되는 다중 패러다임 프로그래밍 언어예요.

- **안전성**: 언어에 내장된 기능이 Code가 프로덕션에서 실행되기 전에 Bug를 잡아내고 막을 수 있도록 도와줘요.
- **속도**: C 기반 언어에 필적하는 최적화된 성능.
- **표현력**: 읽고 쓰기 쉽고 즐거운, 깔끔하고 현대적인 문법.

Apple은 2014년에 iOS와 macOS 개발을 위한 기존 언어였던 Objective-C를 대체할 현대적인 언어로 Swift를 발표했어요.
오늘날 Swift는 오픈 소스이며 Apple 플랫폼, Linux, Windows에서 실행돼요.

## 시작하기

### 변수

[변수][constants-variables]를 정의하면 값을 저장하고 이름을 붙일 수 있어요.
변수를 정의한 뒤에는 그 이름으로 Code 전체에서 그 값을 가리킬 수 있어요.
변수는 _가변_이라서 정의된 뒤에도 값을 바꿀 수 있어요.

`var` 키워드로 변수를 정의해요:

```swift
var variableName = 10
```

Swift는 정적 타입 언어라서 모든 값이 컴파일 시점에 정해진 타입을 가져요.
[타입 주석][type annotations]으로 타입을 직접 선언할 수도 있고, 대입된 값으로부터 Swift 컴파일러가 [타입을 추론][type-inferring]하게 할 수도 있어요:

```swift
var explicitVar: Int = 10 // Explicitly typed
var implicitVar = 10      // Implicitly typed (inferred as Int)
```

할당 연산자(`=`)로 변수의 값을 바꿀 수 있어요:

~~~~exercism/note
변수의 타입은 한 번 선언하면 바꿀 수 없어요.

```swift
variableName = 13 // Allowed: same type (Int)

// Compiler error: cannot assign a different type
variableName = "Hello, world!" // Cannot assign value of type 'String' to type 'Int'
```
~~~~

타입을 지정해서 초깃값 없이 변수를 선언할 수도 있지만, 사용하기 전에 반드시 값을 할당해야 해요:

```swift
var someInt: Int

// This triggers a compiler error:
// print(someInt) // Variable 'someInt' used before being initialized

// Assign a value first
someInt = 169
print(someInt) // Prints 169
```

### 상수

[상수][constants-variables]도 이름과 값을 연결하지만, 할당된 뒤에는 값을 바꿀 수 없어요.
상수는 _불변_이에요.
`let` 키워드로 상수를 정의해요:

```swift
let constantName = 10          // Inferred constant
let explicitConstant: Int = 10 // Explicitly typed constant
```

### 산술 연산자

Swift는 기본적인 계산을 위한 표준 [산술 연산자][arithmetical-operators]를 제공해요:

- 덧셈: `+`
- 뺄셈: `-`
- 곱셈: `*`

```swift
print(1 + 1) // Prints 2
print(2 - 1) // Prints 1
print(2 * 2) // Prints 4
```

### 함수

Swift에서 [함수][functions]는 특정 작업을 수행하는 독립적인 Code 블록이에요.
함수는 입력을 받을 수 있고, 값을 반환할 수 있으며, 값처럼 다른 함수에 전달될 수도 있어요.
`func` 키워드로 함수를 정의해요. 그다음에 함수 이름, 괄호로 감싼 매개변수 목록, 그리고 선택적인 반환 타입을 적어요:

```swift
func functionName(argumentLabel parameterName: ParameterType) -> ReturnType {
    // Function body
}
```

Swift 함수는 [인자 레이블][argument-labels]을 사용해서 Code가 자연스러운 문장처럼 읽히도록 해요:

- **인자 레이블**은 함수를 호출할 때 사용해요.
- **매개변수 이름**은 함수 본문 안에서 값에 접근할 때 사용해요.

이름을 하나만 지정하면 Swift는 그 이름을 인자 레이블과 매개변수 이름으로 모두 사용해요:

```swift
func greet(name: String) {
    print("Hello, \(name)!")
}

greet(name: "Alice")
```

함수를 호출할 때 인자 레이블을 쓰고 싶지 않다면 매개변수 이름 앞에 밑줄(`_`)을 적어요:

```swift
func square(_ number: Int) -> Int {
    return number * number
}

square(5) // Called without an argument label
```

모든 함수 매개변수는 기본적으로 상수(`let`)라서, 함수 본문 안에서 값을 바꿀 수 없어요.

함수에서 값을 반환하려면 `->` 뒤에 반환 타입을 지정하고 `return` 키워드를 사용해요:

```swift
func addTen(to value: Int) -> Int {
    return value + 10
}

addTen(to: 10) // Returns 20
```

함수가 값을 반환하지 않을 때는 반환 타입이 `Void`예요. 이는 빈 튜플 `()`과 같아요.
이런 함수에서는 `-> Void` 반환 타입과 `return` 문을 모두 생략할 수 있어요.

### 주석

Swift는 두 가지 형태의 [주석][comments]을 지원해요:

- **한 줄 주석**은 `//`로 시작해서 줄 끝까지 이어져요.
- **여러 줄 주석**은 `/*`와 `*/` 사이에 넣어요.

```swift
// This is a single-line comment

/* This is a comment
   that spans multiple lines */
```
