# 소개

Common Lisp는 오래된 Lisp 프로그래밍 언어 계열에서 갈라져 나온 언어예요. 애플리케이션 영역에 따라 원하는 접근 방식과 패러다임을 직접 고를 수 있는 다중 패러다임 프로그래밍 언어죠.

Common Lisp는 프로토타이핑이 빠르고, 객체 지향 프로그래밍을 특히 잘 지원해요. 필요에 맞게 언어를 바꿀 수 있는 매크로 시스템도 있고, 실행 중인 애플리케이션을 수정할 수 있는 런타임 환경도 갖추고 있어요.

Common Lisp에 대해 더 알아보려면 [Common Lisp 홈페이지][common-lisp-net]를 살펴봐요.

[common-lisp-net]: https://common-lisp.net/
