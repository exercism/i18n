# 개요

**사용자 정의** 함수는 `function` 키워드로 만들어요. 그 뒤에는 함수 이름과 인자 목록이 이어져야 해요.

```php
function alarm($hour, $minute, $second)
{
    return 'Alarm!';
}
```

함수는 정의되기 전에도 파일에서 호출할 수 있어요. 함수가 자신의 스코프 맨 위로 끌어올려지기 때문이에요.

## 이름 짓기

PHP에서 함수 이름은 다른 이름들과 같은 규칙을 따라요. 밑줄이나 문자로 시작해야 하고, 그 뒤에는 문자, 숫자, 밑줄이 몇 개든 올 수 있어요.
