# Hints

## 객체 지향 프로그래밍

* `reset_names`은 **클래스 메서드**예요.
  MoonScript 언어 가이드의 [클래스 변수][class-vars]를 참고해요.
* 모든 로봇 인스턴스에 걸쳐 어떤 이름이 할당되었는지 같은 상태를 추적해야 해요.
  클래스 변수가 이에 딱 맞아요. 하지만 다른 방법도 통할지 한번 생각해 봐요.

## 성능 힌트

* 모든 로봇에 이름을 할당하는 좋은 방법은 676,000개의 이름을 먼저 전부 생성한 뒤 그 목록을 섞는 거예요.
  그러면 새 로봇은 섞인 목록에서 다음 이름을 그냥 가져가면 돼요.

[class-vars]: https://moonscript.org/reference/#the-language/object-oriented-programming/class-variables
