# 지침

이 연습 문제에서는 고등학교 커플이 소셜 미디어에서 사랑을 고백할 수 있도록, 두 사람의 이니셜이 들어간 ASCII 하트를 만들어요:

```
     ******       ******
   **      **   **      **
 **         ** **         **
**            *            **
**                         **
**     J. K.  +  M. B.     **
 **                       **
   **                   **
     **               **
       **           **
         **       **
           **   **
             ***
              *
```

## 1. 이름의 첫 글자 구하기

`first_letter` 함수를 구현해요. 이름을 받아서 첫 글자를 반환해야 해요. 이름에 있는 불필요한 공백도 정리해 줘야 해요.

```gleam
first_letter("Jane")
// -> "J"
```

## 2. 첫 글자를 이니셜로 만들기

`initial` 함수를 구현해요. 이름을 받아서 첫 글자를 대문자로 바꾸고 마침표를 붙여 반환해야 해요. 이전 단계에서 정의한 `first_letter`를 꼭 다시 사용해요.

```gleam
initial("Robert")
// -> "R."
```

## 3. 전체 이름을 이름과 성으로 나누기

`initials` 함수를 구현해요. 이름과 성이 공백으로 구분된 전체 이름을 받아서 이니셜을 반환해야 해요. 이전 단계에서 정의한 `initial`을 꼭 다시 사용해요.

```gleam
initials("Lance Green")
// -> "L. G."
```

## 4. 이니셜을 하트 안에 넣기

`pair` 함수를 구현해요. 전체 이름 두 개를 받아서 ASCII 하트 안에 들어간 이니셜을 반환해야 해요. 이전 단계에서 정의한 `initials`를 꼭 다시 사용해요.

```gleam
pair("Blake Miller", "Riley Lewis")
// -> "
//      ******       ******
//    **      **   **      **
//  **         ** **         **
// **            *            **
// **                         **
// **     B. M.  +  R. L.     **
//  **                       **
//    **                   **
//      **               **
//        **           **
//          **       **
//            **   **
//              ***
//               *
// "
```
