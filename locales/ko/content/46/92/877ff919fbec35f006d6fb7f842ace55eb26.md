# 지침

지역 예술 센터의 모자이크가 지난달에 설치를 마쳤는데, 이제 까치 마고가 그걸 발견했어요. 대부분의 날에는 근처에 있는 **보물 더미**에서 더 반짝이는 타일로 한두 개를 바꿔 놓거나, 타일 하나를 뽑아 들고 한 시간 동안 사라져요.

이 변화를 하나하나 기록하는 사람은 바로 여러분이에요. 모자이크 자체는 **고정 크기 배열**이에요. 타일 위치마다 칸이 하나씩 있고, 각 칸에는 색을 나타내는 문자열이나 '없음'을 뜻하는 `f`가 들어가요. 까치 마고의 보물 더미는 마고가 훔친 낱개 타일들로 이루어진 **벡터**예요.

## 1. 새 행 펼치기

`fresh-mosaic`는 길이 `n`을 받아서 `n`개의 빈 칸(각각 `f`)으로 이루어진 배열을 반환하도록 정의해요.

```factor
4 fresh-mosaic .
! => { f f f f }
```

## 2. 타일 놓기

`place-tile`는 행 하나와 위치, 색을 받아서, 지정한 위치에 그 색이 들어가도록 행을 제자리에서 수정하도록 정의해요. 반환하는 값은 없어요.

```factor
5 fresh-mosaic   ! { f f f f f }
dup 2 "ruby" place-tile
.
! => { f f "ruby" f f }
```

## 3. 타일 떼어내기

`chip-tile`는 행과 위치를 받아서, 지정한 위치가 다시 `f`가 되도록 행을 제자리에서 수정하도록 정의해요.

```factor
{ "ruby" "lapis" "jade" } 1 chip-tile .
! => { "ruby" f "jade" }
```

## 4. 타일 색 다시 칠하기

`recolour-tile`는 행과 위치, 그리고 인자가 하나인 quotation을 받아서, 그 위치에 있는 타일에 quotation을 적용해 행을 제자리에서 수정하도록 정의해요.

```factor
{ "RUBY" "LAPIS" "JADE" } 1 [ >lower ] recolour-tile .
! => { "RUBY" "lapis" "JADE" }
```

## 5. 마고가 오기 전에 스냅숏 찍기

`snapshot-mosaic`는 행을 받아서, 나중에 원본을 수정해도 영향을 받지 않는 독립적인 복사본을 반환하도록 정의해요.

```factor
{ "ruby" "lapis" "jade" } dup snapshot-mosaic    ! two equal but independent copies
swap 0 "amber" place-tile                        ! mutate the first
.s
! => { "ruby" "lapis" "jade" }                   (the snapshot)
! => { "amber" "lapis" "jade" }                  (the mutated original)
```

## 6. 마고가 타일을 주머니에 넣기

`stash-tile`는 마고의 보물 더미(벡터)와 색을 받아서, 보물 더미에 그 색을 덧붙이도록 정의해요. 반환하는 값은 없어요.

```factor
V{ } clone   ! a fresh empty hoard
dup "ruby"  stash-tile
dup "lapis" stash-tile
.
! => V{ "ruby" "lapis" }
```

## 7. 마고가 타일 되돌려 놓기

`return-tile`는 마고의 보물 더미를 받아서, 가장 최근에 넣어 둔 타일(맨 위에 있는 타일)을 꺼내서 반환하도록 정의해요.

```factor
V{ "ruby" "lapis" "jade" } clone
dup return-tile .
! => "jade"
.
! => V{ "ruby" "lapis" }
```
