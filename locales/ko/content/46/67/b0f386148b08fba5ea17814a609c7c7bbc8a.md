# 안내 추가

## 레지스터

| 레지스터 | 용도 | 자료형 | 설명                                                |
| -------- | --------- | ------- | ---------------------------------------------------------- |
| `$a0`    | 입력     | 정수 | 카테고리: `0` = choice, `1` = ones, `2` = twos, `3` = threes, `4` = fours, `5` = fives, `6` = sixes, `7` = little_straight, `8` = big_straight, `9` = full_house, `10` = four_of_a_kind, `11` = yacht |
| `$a2`    | 입력     | 주소 | 주사위 (워드 배열)                                          |
| `$v0`    | 출력     | 정수 | 계산된 점수                                            |
| `$t0-9`  | 임시 | 임의     | 임시 저장에 사용                                 |
