# Cairo의 모듈과 경로

Cairo는 코드를 구성할 때 **모듈**을 사용해요.

모듈은 프로젝트를 구조화하고 함수, 구조체, 트레이트 같은 항목의 가시성을 제어하는 데 도움을 줘요.

## 모듈 정의하기

모듈은 `mod`로 정의하고 중첩할 수 있어요:

```rust
mod front_of_house {
    pub mod hosting {
        pub fn add_to_waitlist() {}
    }
}
```

함수, 구조체, 트레이트는 **기본적으로 비공개**예요.

`pub`를 사용하면 모듈 밖에서도 접근할 수 있게 만들 수 있어요.

## 경로: 절대 경로와 상대 경로

다른 모듈에 있는 항목을 가리킬 때는 다음을 사용할 수 있어요:

- **절대 경로** (`crate::`로 시작):

  ```rust
  crate::front_of_house::hosting::add_to_waitlist();
  ```

- **상대 경로** (현재 모듈에서 시작):

  ```rust
  front_of_house::hosting::add_to_waitlist();
  ```

  `front_of_house`가 같은 모듈에 있다면 이렇게 쓸 수 있어요.

## `use`로 모듈을 스코프로 가져오기

전체 경로를 반복해서 쓰는 건 불편해요.

`use` 키워드를 쓰면 더 짧게 참조할 수 있어요:

```rust
use crate::front_of_house::hosting;

pub fn eat_at_restaurant() {
    hosting::add_to_waitlist(); // Shorter path
}
```

`use`는 **쓰인 스코프에서만** 적용돼요. 다른 곳에서 필요하다면 다시 써야 해요.

### `use`의 관용적인 사용법

- 함수가 아니라 **모듈**을 스코프로 가져와요:

  ```rust
  use crate::front_of_house::hosting; // ✅
  hosting::add_to_waitlist();
  ```

  다음처럼 쓰는 대신:

  ```rust
  use crate::front_of_house::hosting::add_to_waitlist; // ❌
  add_to_waitlist();
  ```

- **트레이트, 구조체, 열거형**에는 전체 경로를 사용해요:

  ```rust
  use core::num::traits::BitSize;
  ```

### `as`로 별칭 만들기

필요할 때 임포트한 이름을 바꿔요:

```rust
use core::array::ArrayTrait as Arr;

fn main() {
    let mut arr = Arr::new();
    arr.append(1);
}
```

### 여러 항목 임포트하기

여러 개의 `use` 문을 쓰는 대신 임포트를 묶어요:

```rust
use shapes::{Square, Circle, Triangle};
```

## `pub use`로 다시 내보내기

모듈을 다른 구조로 노출하려면 `pub use`를 사용해요:

```rust
pub use crate::front_of_house::hosting;
```

이제 외부 코드는 `restaurant::front_of_house::hosting::add_to_waitlist()` 대신 `restaurant::hosting::add_to_waitlist()`를 사용할 수 있어요.

## Scarb로 외부 패키지 사용하기

의존성을 추가하려면 `Scarb.toml`을 수정해요:

```toml
[dependencies]
alexandria_math = { git = "https://github.com/keep-starknet-strange/alexandria.git" }
```

`scarb add <package>`로 의존성을 추가하고 `scarb rm <package>`로 제거해요.

## 글롭 연산자 (`*`)

모듈에서 모든 것을 임포트하려면:

```rust
use core::num::traits::*;
```

코드를 읽기 어렵게 만들 수 있으니 주의해서 사용해야 해요.
