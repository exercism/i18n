# Bools

Crystal에는 [`Bool`][bools]이라는 타입이 있어요.
이 타입은 `true`와 `false` 값을 나타내요.

## 논리 연산자

Crystal에는 세 개의 논리 연산자(`!`, `||`, `&&`)가 있어요. 이 연산자들은 Bool을 조합해서 서로 다른 값을 만들어 내는 표현식을 만들어요.

### And(`&&`)

Crystal에서 [_and_ 연산자][and]는 `&&`로 나타내며, 두 값이 모두 `true`이면 `true`를 반환하고, 그렇지 않으면 `false`를 반환해요.
_and_ 연산자를 사용할 때는 `&&`의 오른쪽에 Bool 하나를, 왼쪽에 다른 하나를 놓아요.

```crystal
true && true
# => true

true && false
# => false
```

### Or(`||`)

Crystal에서 [_or_ 연산자][or]는 `||`로 나타내며, 주어진 값 중 **적어도 하나**가 `true`이면 `true`를 반환해요.
두 값이 모두 `false`이면 `false`를 반환해요.
_or_ 연산자를 사용할 때는 `||`의 오른쪽에 Bool 하나를, 왼쪽에 다른 하나를 놓아요.

```crystal
true || true
# => true

true || false
# => true

false || false
# => false
```

### Not(`!`)

Crystal에서 _not_ 연산자는 `!`로 나타내며, 주어진 Bool이 `false`이면 `true`를 반환하고, `true`이면 `false`를 반환해요.
_not_ 연산자를 사용할 때는 연산자(`!`) 뒤에 Bool 하나를 놓아요.

```crystal
!true
# => false

!false
# => true
```

## 괄호 사용하기(`()`)

불리언을 다룰 때는 괄호를 사용해서 어떤 Bool을 먼저 평가할지 정할 수 있어요.
괄호를 어떻게 사용하느냐에 따라 결과가 달라질 수 있어요.
Crystal에서는 괄호 안에 있는 것이 먼저 평가돼요.

```crystal
true && false && false || true
# => true

true && false && (false || true)
# => false
```

괄호 안에 있는 것이 먼저 평가되기 때문에, 다음 예제에서는 _not_ 연산자가 괄호 안의 표현식에 적용돼요.

```crystal
!true && false
# => false

!(true && false)
# => true
```

~~~~exercism/note
괄호는 결과에 영향을 줄 때만 사용해야 해요. 그렇지 않으면 생략하는 게 좋아요.
~~~~
