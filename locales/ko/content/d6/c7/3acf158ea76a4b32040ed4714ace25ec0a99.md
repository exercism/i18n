# 추가 지침

## 단어

`linked-list-node` 튜플을 정의해요.

`linked-list` 튜플을 정의하고, 테스트에서 리스트에 대해 `length`를 직접 호출할 수 있도록 `sequences`에 있는 `M: linked-list length` 메서드도 제공해요.

- `<linked-list> ( -- linked-list )`: 빈 리스트를 만들어요.
- `>linked-list ( seq -- linked-list )`: `seq`의 각 원소를 순서대로 새 리스트에 넣어요.
- `linked-list>array ( linked-list -- array )`: 리스트의 맨 위 값부터 차례로 값들을 반환해요.
- `list-push ( linked-list value -- linked-list )`: 값을 맨 위에 넣어요.
- `list-pop ( linked-list -- linked-list value )`: 맨 위의 값을 제거하고 그 값을 반환해요.
- `list-peek ( linked-list -- value )`: 맨 위의 값을 제거하지 않고 반환해요.
- `list-reverse ( linked-list -- linked-list )`: 원소의 순서를 뒤집은 리스트를 반환해요.

리스트가 비어 있으면 `list-pop`과 `list-peek`에서 `list-empty` 오류 클래스를 던져요.
