# 소개

[`function`][function]은 코드를 구획으로 나눠서, 프로그램 안의 한 곳 이상에서 이름으로 호출할 수 있게 해주는 방법이에요.
함수는 특정하고 반복적인 작업을 수행할 때 사용해요.

좀 더 엄밀히 말하면, 함수는 [`function call`][calls] 연산을 적용할 수 있는 모든 Python 객체예요.
함수는 어떤 연산의 결과로 하나 이상의 값을 [`return`][return]하는 데 쓰일 수도 있고, 하나 이상의 [`side effects`][side effects]를 일으키는 데 쓰일 수도 있어요.
함수가 반환값을 지정하지 않아도 `None`은 반환해요.

다음은 부수 효과가 있는 함수의 예예요.

```python
>>> def hello():
...     print("Hello")
...
>>> hello()
Hello

```

위 예제에서는 [`def`][def] 키워드로 함수 정의의 시작을 알려요.
`hello`는 함수의 이름이에요.
빈 괄호는 함수에 아무 값도 전달되지 않는다는 것을 나타내요.
함수의 본문은 `print("Hello")` 문 하나예요.
`print`도 함수예요.
`print` 함수의 괄호 안에 있는 `"Hello"`를 [`argument`][arguments]라고 해요.
`print` 함수는 이 인자를 보고 무엇을 출력할지 알아내요.
함수의 본문이 들여쓰기되어 있다는 점에 주목해요.
들여쓰기는 중요해요. Python이 들여쓰기를 보고 그 코드 블록이 어디서 끝나는지 판단하기 때문이에요.
함수 본문은 프로그램의 끝에서, 또는 들여쓰기가 _되지 않은_ 다음 코드 줄 바로 앞에서 끝나요.
`hello()`는 `return` 값을 지정하지 않으므로, `print()`를 호출하는 부수 효과를 실행한 다음 `None`을 반환해요.
마지막으로, 함수 이름과 괄호를 사용해 함수를 호출해요. 이는 Python 인터프리터에게 이 이름이 _호출 가능한_ 이름이라는 신호를 보내요.

다음은 반환값이 있는 함수의 예예요.

```python
>>> def hello():
...     return "Hello"
... 
print(hello())
Hello

```

이 함수의 본문은 `print`를 _호출_하는 대신 `string` "Hello"를 _반환_하도록 바뀌었어요.
결국 코드는 여전히 `"Hello"`를 출력하지만, 부수 효과는 `hello` 함수가 아니라 _호출하는 코드_에서 일어나요.
`hello` 함수를 호출할 때 괄호를 빼먹으면(예: `print(hello)`), `print`는 다음과 비슷한 것을 출력해요.

```
<function hello at 0x0000026E18E93E20>
```

함수가 인자를 받지 않더라도(_즉, 매개변수가 없더라도), 제대로 _호출_하려면 빈 괄호를 써야 한다는 점이 중요해요.
이 점은 인자 없이 함수를 호출할 때 빈 괄호가 필요 없는 Ruby 같은 언어와 달라요.

함수는 [`parameters`][parameters]를 0개 이상 정의할 수 있어요. 매개변수는 함수가 어떤 인자를 받는지 정의해요.

다음은 인자를 받는 함수의 예예요.

```python
>>> def hello(name):
...     return f"Hello, {name}"
... 
>>> print(hello("Bob"))
Hello, Bob

```

매개변수는 `name`으로 정의되어 있어요.
`"Bob"`은 프로그램이 `hello` 함수에 전달하는 인자예요.
함수는 `string` "Hello, Bob"을 _반환_해요.

`hello`를 인자 없이 호출하면 어떻게 될까요?
프로그램에서 오류가 발생해요.

```python
print(hello())
Traceback (most recent call last):

  Input In in <line: 1>
    print(hello())

TypeError: hello() missing 1 required positional argument: 'name'
```

인자가 없을 때 프로그램이 오류를 내지 않게 하려면(_그러면서 호출하는 코드가 인자를 넘기지 않아도 되게 하려면_), [기본 인자][default arguments]를 정의하면 돼요.
기본 인자는 함수를 호출할 때 인자가 없으면 어떤 값을 사용할지 정의해요.

다음은 기본 인자가 있는 함수의 예예요.

```python
>>> def hello(name="you"):
...     return f"Hello, {name}"
... 
>>> print(hello())
Hello, you

```

`name` 매개변수에는 `"you"`라는 기본 인자가 주어져서, `name` 인자를 넘기지 않으면 프로그램은 `Hello, you`를 출력해요.

함수 인자에 대해 더 알고 싶다면, [함수 인자][function arguments] 개념을 참고해요.
