# 소개

`Time` 모듈은 사람이 읽을 수 있는 날짜와 시간을 표시할 때 사용해요. `Time`으로도 기술적으로는 시간을 다룰 수 있지만, 이 작업에 훨씬 더 잘 맞는 Elm 커뮤니티 패키지들이 있어요. [`justinmimbs/date`][date]나 [`CoderDennis/elm-time-format`][elm-time-format] 같은 것들이죠.

## Posix

시간은 불투명 타입인 `Posix`로 표현하는데, 이 타입은 유닉스 에포크 시간, 즉 1970년 1월 1일 UTC 자정 이후 지난 밀리초 수를 감싸요. `Posix`는 시간대에 따라 달라지지 않는 모호하지 않은 값이라서 시간을 기록하기에 좋은 선택이에요. Elm 애플리케이션에서는 보통 브라우저 같은 외부 소스가 `Posix` 시간을 제공해요.

다음 함수를 사용하면 `Posix`를 밀리초 숫자로, 또는 그 반대로 변환할 수 있어요.

```elm
posixToMillis : Posix -> Int
millisToPosix : Int -> Posix
```

## 시간대

일상에서 우리는 보통 `Posix`를 읽지 않고, 지구상에서의 위치와 그 지역의 일광 절약 시간 규칙에 따라 달라지는 현지 시간을 더 선호해요. Elm에서는 이 정보가 불투명 타입인 `Zone`에 담겨 있고, 보통 브라우저가 이를 제공해요.

항상 사용할 수 있는 특별한 `Zone`도 있어요.

```elm
utc : Zone
```

## 사람이 읽는 시간

`Posix`와 `Zone`만 있으면 어떤 수준으로든 현지 시간을 자세히 표시할 정보가 충분해요. 이를 위해 사용할 수 있는 함수는 다음과 같아요.

```elm
toYear : Zone -> Posix -> Int
toMonth : Zone -> Posix -> Month
toDay : Zone -> Posix -> Int
toWeekday : Zone -> Posix -> Weekday
toHour : Zone -> Posix -> Int
toMinute : Zone -> Posix -> Int
toSecond : Zone -> Posix -> Int
toMillis : Zone -> Posix -> Int
```

`Time`의 사용자 정의 타입이 두 개 더 있다는 것도 눈치챘을 거예요.

```elm
type Month = Jan | Feb | Mar | Apr | May | Jun | Jul | Aug | Sep | Oct | Nov | Dec
type Weekday = Mon | Tue | Wed | Thu | Fri | Sat | Sun
```

이 사용자 정의 타입들을 사람이 읽을 수 있는 값으로 변환하는 일은 사용자에게 맡겨져 있어요.
