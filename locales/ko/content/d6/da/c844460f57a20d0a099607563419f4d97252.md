# 소개

*쿼터테이션*은 `[ ]` 괄호 안에 들어 있는 코드로, 숫자나 문자열처럼 Factor에서는 그 자체로 하나의 값이에요. 변수에 저장할 수도, 배열에 넣을 수도, 다른 워드에 전달할 수도 있고, 나중에 *호출*할 수도 있어요.

## `call`

`call`은 [`kernel`][kernel]에 있는 워드로, 쿼터테이션을 실행해요:

```factor
3 4 [ + ] call .
! => 7
```

Factor가 쿼터테이션의 스택 효과를 추론할 수 없는 상황에서 그 쿼터테이션을 `call`할 때는 스택 효과를 명시적으로 선언해야 해요:

```
call( stack-effect ) ! e.g. call( a b -- c )
```

```factor
: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .
! => 2
```

이렇게 하면 쿼터테이션이 실제로 선언한 효과를 가지는지 확인하는 런타임 검사가 컴파일돼요.

## 시퀀스 안의 쿼터테이션

쿼터테이션은 값이기 때문에, 배열 하나에 숫자와 쿼터테이션을 섞어 담을 수 있어요:

```factor
{ 3 4 [ + ] }
```

그러면 "프로그램"도 그냥 평범한 시퀀스가 되고, `each`는 프로그램을 실행하는 자연스러운 방법이 돼요:

```
each ( seq quot -- )
```

```factor
{ [ 1 + ] [ 2 * ] } 5 swap [ call( x -- y ) ] each .
! 5 -> 6 -> 12
```

## 시퀀스의 끝 잘라내기

`head*`는 마지막 `n`개 원소를 제외한 나머지 전부를 반환하고, `last2`는 마지막 두 개를 반환해요:

```
head* ( seq n -- headseq )
last2 ( seq -- penultimate last )
```

```factor
{ 1 2 3 4 5 } 2 head* .    ! => { 1 2 3 }
{ 1 2 3 4 5 } last2 .s
! => 4
! => 5
```

`suffix`와 함께라면, 맨 위의 두 값을 꺼내고 결과 하나를 푸시하는 스택 연산을 작성하는 데 필요한 모든 것을 갖춘 셈이에요.
