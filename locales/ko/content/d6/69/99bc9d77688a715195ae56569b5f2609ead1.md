# 테스트

테스트를 실행하기 전에, 설치 단계를 따라 과제 폴더가 올바르게 설정되어 있는지 확인해요. 즉, `corepack yarn install`과 Editor SDK 설정이에요.

다음 명령으로 테스트를 실행해요:

```bash
$ corepack yarn test
```

다른 사용자들처럼 코드가 모범 사례를 따르도록, 코드를 정적 분석하는 도구인 eslint를 활용해 봐요.
이런 도구는 코드에서 오타나 사소한 실수를 찾아내는 시간을 아껴줘요:

```bash
$ corepack yarn lint
```

아니면 두 가지를 동시에 실행해도 돼요:

```bash
$ corepack yarn test && corepack yarn lint
```

Exercism의 TypeScript 트랙은 코드 _스타일_을 강제하지 않아요. 그래서 세미콜론을 쓸지, 탭과 스페이스 중 무엇을 쓸지, 그 중간은 무엇인지 자유롭게 선택할 수 있어요.

## 첫 모듈 만들기

보통 이 트랙의 테스트는 구현을 모듈로 불러와서 로드해요: `import Bob from './bob';`.
이게 동작하게 하려면, 테스트가 모듈을 찾는 파일인 `bob.ts`에서 구현을 내보내야 해요:

```typescript
export class Bob {
  public hey(message: string) {
    // Your solution here
  }
}
```

각 연습 문제에 스텁을 제공하고, 거기에 이 `export`를 넣어 두었어요.
