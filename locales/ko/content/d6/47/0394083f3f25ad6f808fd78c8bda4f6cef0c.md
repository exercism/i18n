# 익명 함수와 클로저

PHP에서는 다른 함수 안에서 함수를 선언할 수 있어요. 이런 함수는 이름이 필요 없고, 변수에 할당하거나 함수 매개변수를 받는 다른 함수에 바로 전달할 수도 있어요.

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, function($num) {
        return $num % 2 === 1;
    });
}
```

위에서 정의해서 `array_filter`에 전달한 함수가 익명 함수예요. `array_filter` 함수는 이 익명 함수를 사용해 배열의 어떤 값이 결과에 포함될지 결정해요. 어떤 값에 대해 함수가 `true`를 반환하면, 그 값은 결과 배열에 포함돼요.

익명 함수는 함수 안에서 함수 바깥 스코프에 있는 변수를 참조할 때도 사용할 수 있어요. 이는 함수가 사용하는 변수에 대해 함수의 스코프가 “닫히는” 것을 가리키고, 그래서 “클로저”라는 이름이 붙었어요. 어떤 언어에서는 스코프 안의 모든 변수를 클로저 안에서 자동으로 사용할 수 있어요. PHP에서는 현재 객체를 가리키는 `$this`만 클로저 안에서 자동으로 사용할 수 있고, 나머지 변수는 모두 `use` 키워드로 명시적으로 참조해야 해요.

```php
function makeAdderFunction(int $number) {
    return function(int $x) use($number) {
        return $x + $number;
    }
}

$add5 = makeAdderFunction(5);
echo $add5(4); // echos 9
```

위의 `makeAdderFunction` 함수에서는 전달받은 `$number` 값이 내부에 정의되어 반환되는 익명 함수에 “닫혀” 있어요. 그래서 그 함수가 실행될 때마다 전달받았던 `$number`의 값을 알고 있어요. 이 함수를 다른 숫자로 다시 호출하면 완전히 다른 함수가 반환돼요. 첫 번째 함수 호출이 반환한 값이나 동작이 바뀌지는 않아요. 변수 하나 이상을 닫아야 한다면, 쉼표로 구분해서 `use` 키워드에 추가하면 돼요.

PHP에는 `arrow functions`라는 더 짧은 함수 문법도 있어요. 다만 꽤 단순한 형태여야 해요. 기본 형태는 다음과 같아요.

```php
fn(arguments) => expression
```

이 함수 스타일에서는 `use`를 사용할 필요가 없어요. 부모 스코프의 값을 자동으로 닫아서 캡처해요. 화살표 함수의 표현식은 `return` 키워드를 쓰지 않아도 자동으로 반환돼요. 따라서 위의 `onlyOdds` 함수를 이렇게 다시 쓸 수 있어요.

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, fn($n) => $n % 2 == 1);
}
```

위의 `makeAdderFunction`도 이렇게 다시 쓸 수 있어요.

```php
function makeAdderFunction(int $number) {
    return fn(int $x) => $x + $number;
}
```

**참고:** 함수를 표현식으로 쓸 수 없다면, 더 짧은 화살표 함수 문법을 사용할 수 없어요.

변수는 익명 함수와 클로저에 값으로 전달되고, 그 안에서도 값으로 사용돼요. 즉 함수 안에서 변수의 값을 바꿔도 함수 밖의 변수 값에는 영향을 주지 않아요. 값을 실제로 수정해야 한다면 참조로 전달하면 돼요.

```php
function positiveAverage(array $numbers): float
{
    $total = 0;
    $count = 0;
    return array_walk(
      $numbers,
      function($num) use (&$count, &$total) {
          $total += abs($num);
          $count++;
      }
    );
    return $total / $count;
}
```

위 예시에서 `array_walk`는 배열의 각 원소를 순회하면서 각 값을 호출에 선언된 함수로 넘겨요. `$total`에는 지금까지 더한 값, 즉 각 숫자의 절댓값을 누적해서 저장해요. 숫자가 몇 개였는지도 함께 세요. 두 값 모두 클로저에서 참조로 사용되는데, `use` 부분에서 각 변수 앞에 붙은 `&`가 이를 나타내요. 따라서 `array_walk`가 끝난 뒤에도 변수에 일어난 변경이 그대로 남아 있어서, 함수는 배열에 있는 숫자들의 절댓값 평균을 반환할 수 있어요.

익명 함수와 클로저는 한 가지 상황에서만 필요할 수도 있는 함수를 정의하거나, 함수가 실제로 사용되는 시점과 다른 때에 알게 된 매개변수 집합을 바탕으로 동적인 함수를 반환하는 함수를 정의할 때 편리해요.
