# 지침 추가

## 추가 지침

"isogram"이라는 테이블이 제공돼요.
첫 번째 열인 "phrase"에는 텍스트가 들어 있어요.
이 문구가 아이소그램인지 판단해야 해요.
두 번째 열인 "is_isogram"을 정수 값으로 업데이트해요:

* 문구가 아이소그램이면 1,
* 아이소그램이 아니면 0.

~~~~exercism/note
SQLite 비교 연산은 불리언 값을 0/1 숫자로 반환해요

```sh
$ sqlite3
sqlite> .mode table
sqlite> SELECT 1 < 2 AS "true", 1 > 2 AS "false";
+------+-------+
| true | false |
+------+-------+
| 1    | 0     |
+------+-------+
```
