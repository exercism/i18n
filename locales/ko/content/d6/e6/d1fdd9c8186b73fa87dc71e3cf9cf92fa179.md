# 지침

녹음 스튜디오에 있는 작은 믹싱 콘솔의 디지털 코어를 만들고 있어요.

소리는 샘플의 스트림으로 들어와요.
각 샘플은 한 순간의 스피커 콘 위치를 나타내는 숫자예요.
콘솔은 샘플 블록 전체를 한 번에 처리하면서 각 샘플에 같은 연산을 적용해요.

다섯 개의 작업이 있고, 각 작업은 메모리에 담긴 샘플 블록을 다뤄요.
피연산자는 메모리 주소를 통해 받고, 결과는 결과 주소를 통해 기록해요.

~~~~exercism/note
이 연습 문제의 계산은 스칼라 연산이 아니라 SIMD 명령어를 사용해서 수행해야 해요.
~~~~

## 1. 두 트랙 믹스하기

스튜디오에서는 악기를 서로 다른 트랙에 녹음할 때가 있어요.
같은 스피커로 재생하려면 두 트랙을 하나로 더해야 해요.

`mix_tracks` 함수를 구현해요. 이 함수는 두 트랙을 샘플 단위로 더해요.
각 트랙은 부호 있는 16비트 샘플 8개로 이루어진 블록이에요.
부호 있는 16비트 범위를 넘어서는 합은 값이 반대편으로 돌아가지 않고 클램프되어야 해요.

이 함수는 다음 인자를 이 순서대로 받아요:

- `result`: 믹스된 샘플 8개가 기록될 버퍼의 16바이트 정렬된 메모리 주소예요.
- `track_a`: 부호 있는 16비트 샘플 8개가 담긴 첫 번째 트랙의 16바이트 정렬된 메모리 주소예요.
- `track_b`: 부호 있는 16비트 샘플 8개가 담긴 두 번째 트랙의 16바이트 정렬된 메모리 주소예요.

```c
track_a = {10000, 30000, 20000, -30000, -20000, -100,  100, 0}
track_b = { 5000,  5000, 20000,  -5000, -20000,  100, -100, 0}
result  = {15000, 32767, 32767, -32768, -32768,    0,    0, 0}
```

이 함수는 반환 값이 없어요.

## 2. 블리드 제거하기

마이크 두 개로 동시에 녹음하면, 각 마이크가 다른 쪽 음원의 희미한 사본을 함께 담아요.
이렇게 원치 않게 섞여 들어온 것을 _블리드_라고 해요.
블리드를 측정하고 나면, 트랙을 깨끗하게 하기 위해 그만큼을 다시 빼줘야 해요.

`remove_bleed` 함수를 구현해요. 이 함수는 트랙 블록에서 블리드 블록을 샘플 단위로 빼요.
각 블록은 부호 있는 16비트 샘플 8개이고, 뺄셈은 포화 연산이어야 해요.

이 함수는 다음 인자를 이 순서대로 받아요:

- `result`: 정리된 샘플 8개가 기록되는 메모리 주소예요 (정렬은 보장되지 않아요).
- `track`: 녹음된 트랙의 16바이트 정렬된 메모리 주소로, 부호 있는 16비트 샘플 8개예요.
- `bleed`: 제거할 블리드의 메모리 주소로, 부호 있는 16비트 샘플 8개예요 (정렬은 보장되지 않아요).

```c
track  = {10000, -30000, 5000, 32767, 0,  200, -200, 15000}
bleed  = { 2000,   5000, 5000,    -5, 0,  300,  300,  5000}
result = { 8000, -32768,    0, 32767, 0, -100, -500, 10000}
```

이 함수는 반환 값이 없어요.

## 3. 미터 합치기

각 채널 위에는 레벨 미터가 있어요. 밝기로 그 채널이 얼마나 큰 소리인지 알려주는 작은 막대예요.
전면 패널에는 마스터 미터가 하나 있는데, 두 채널을 합친 만큼 밝게 빛나야 해요.
두 미터 블록을 더해서 이 미터를 구동해요.

밝은 미터는 어두운 값으로 돌아가지 않고 최대 밝기를 유지해요. 그래서 합은 포화 연산이에요.

`combine_meters` 함수를 구현해요. 이 함수는 두 미터 블록을 샘플 단위로 더해요.
이 함수는 다음 인자를 이 순서대로 받아요:

- `result`: 합쳐진 값 16개가 기록될 16바이트 정렬된 메모리 주소예요.
- `meter_a`: 패킹된 부호 없는 8비트 값 16개가 담긴 첫 번째 채널 미터 블록의 16바이트 정렬된 메모리 주소예요.
- `meter_b`: 패킹된 부호 없는 8비트 값 16개가 담긴 두 번째 채널 미터 블록의 16바이트 정렬된 메모리 주소예요.

각 블록은 부호 없는 8비트 값 16개예요.
두 블록을 더하되, 부호 없는 범위로 포화시켜야 해요.

```c
meter_a = {200, 100,  50, 255, 0, 128, 10, 240, 1, 2, 3, 4, 5, 6, 7, 8}
meter_b = {100, 100, 200,   1, 0, 128, 10,  20, 1, 2, 3, 4, 5, 6, 7, 8}
result  = {255, 200, 250, 255, 0, 255, 20, 255, 2, 4, 6, 8, 10, 12, 14, 16}
```

이 함수는 반환 값이 없어요.

## 4. 페이드 적용하기

노래는 갑자기 끊기지 않고 끝에서 서서히 사라져야 해요.
샘플마다 하나씩 있는 _게인 계수_ 블록이 있고, 이 계수는 갈수록 점점 더 조용한 값으로 줄어들어요.

각 계수는 `65536`을 기준으로 표현된 분수예요.
예를 들어 샘플의 값이 `16384`라면, 실제로는 `16384 / 65536`을 나타내고, 이는 `1 / 4`예요.
사용할 수 있는 가장 큰 값인 `32767`은 절반보다 조금 작아요.

`65536`은 `2^16`이므로, 샘플에 계수를 곱하고 곱의 _상위 절반_을 취하면 `sample * gain / 65536`이 나와요.

`apply_fade` 함수를 구현해요. 이 함수는 각 샘플을 계수로 스케일링해요.
이 함수는 다음 인자를 이 순서대로 받아요:

- `result`: 스케일링된 샘플이 모두 기록될 16바이트 정렬된 메모리 주소예요.
- `track`: 부호 있는 16비트 샘플 `n`개가 담긴 트랙의 16바이트 정렬된 메모리 주소예요.
- `gains`: 게인 계수의 16바이트 정렬된 메모리 주소로, 각각 `0`에서 `32767` 범위에 있는 부호 있는 16비트 값 `n`개가 담겨 있어요.
- `n`: 샘플의 개수예요. 항상 0이 아니고 `8`의 배수이며, 64비트 부호 없는 정수예요.

`track`은 부호 있는 16비트 샘플 `n`개를 담는 배열이고, `n`은 절대 0이 아니며 항상 `8`의 배수예요.
각 샘플에 대해 스케일링된 결과는 부호 있는 곱 `sample * gain`의 _상위_ 16비트예요.

```c
track  = {20000, 20000, 20000, 20000, -20000, -20000, -20000, -20000}
gains  = {32767, 24576, 16384,  8192,  32767,  24576,  16384,   8192}
result = { 9999,  7500,  5000,  2500, -10000,  -7500,  -5000,  -2500}
```

~~~~exercism/note
상위 절반을 취하는 것은 음의 무한대 방향으로 반올림해요.
그래서 `20000 * 32767`은 `9999`로 스케일링되고, `-20000 * 32767`은 `-9999`가 아니라 `-10000`으로 스케일링돼요.
~~~~

이 함수는 반환 값이 없어요.

## 5. 트랙 감쇠하기

드러머가 너무 크게 녹음됐어요.
트랙 전체의 크기를 낮추기 위해 모든 샘플을 상수로 나눠요.

`attenuate_track` 함수를 구현해요.
이 함수는 다음 인자를 이 순서대로 받아요:

- `result`: 결과가 32비트 부호 있는 정수로 기록될 16바이트 정렬된 메모리 주소예요.
- `samples`: 부호 있는 16비트 값 `n`개인 샘플의 16바이트 정렬된 메모리 주소예요.
- `divisor`: 나누는 값의 동일한 복사본 4개가 담긴 16바이트 정렬된 메모리 주소로, 32비트 정수예요.
- `n`: 샘플의 개수예요. 항상 0이 아니고 `4`의 배수이며, 64비트 부호 없는 정수예요.

`samples`는 부호 있는 16비트 샘플 `n`개를 담는 배열이고, `n`은 절대 0이 아니며 항상 `4`의 배수예요.

나누는 값은 같은 32비트 정수를 `4`개 복사한 형태로 주어져요. 네 개의 레인을 한 번에 채울 수 있도록 미리 복제된 거예요.

정수 SIMD에는 패킹된 나눗셈이 없어서, 작업은 패킹된 부동소수점으로 수행한 뒤 다시 패킹된 32비트 정수로 변환해서 `result`에 저장해요.
0 방향으로 버림해서 변환하면, 몫 `2.3`은 `2`가 되고 `-2.3`은 `-2`가 돼요.

```c
samples = {300, 150, 90, -120, 100, 50, -50, 7}
divisor = {3, 3, 3, 3}
result  = {100,  50, 30,  -40,  33, 16, -16, 2}
```

이 함수는 반환 값이 없어요.
