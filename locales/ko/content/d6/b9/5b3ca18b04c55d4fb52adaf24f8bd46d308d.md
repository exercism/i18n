# 지시 사항

이 연습 문제에서는 프리랜서가 프로젝트 관리자와 소통할 수 있도록 돕는 코드를 작성해요.
이번 과제는 일당과 월 요금을 빠르게 계산하는 몇 가지 유틸리티를 만드는 거예요. 원한다면 주어진 할인을 적용할 수도 있어요.

먼저 프리랜서와 프로젝트 관리자 사이에 몇 가지 규칙을 정해요.

- 일당은 시급의 8배예요.
- 한 달에는 청구 가능한 날이 22일 있어요.

때로는 프리랜서가 일당에 할인을 적용해 주기도 해요. 예를 들어 가장 충성도가 높은 고객이나 비영리 고객에게요.

할인은 백분율을 나타내는 소수로 표현해요. 예를 들어 `25.0`은 25%를 뜻해요.

## 1. 시급이 주어졌을 때 일당 계산하기

시급을 매개변수로 받아 일당을 계산하는 `daily_rate` 함수를 구현해요.
계약에는 하루에 청구 가능한 시간이 8시간이라고 명시되어 있어요.

```cpp
daily_rate(60)
// => 480.0
```

반환되는 일당은 `double` 타입이어야 해요.

## 2. 할인된 가격 계산하기

할인을 적용한 뒤의 가격을 계산하는 `apply_discount` 함수를 구현해요.
이 함수는 원래 가격과 할인율(퍼센트) 두 가지 매개변수를 받아야 해요.

```cpp
apply_discount(150, 10)
// => 135.0
```

반환되는 값은 항상 `double` 타입이어야 하고, 어떤 방식으로든 반올림하면 안 돼요.

## 3. 시급과 할인이 주어졌을 때 월 요금 계산하기

할인이 적용된 월 요금을 계산하는 `monthly_rate` 함수를 구현해요.
이 함수는 시급과 할인율(퍼센트) 두 가지 매개변수를 가져야 해요.

```cpp
monthly_rate(77, 10.5)
// => 12130
```

반환되는 월 요금은 가장 가까운 정수로 올림(천장 함수)해야 해요.

## 4. 예산, 시급, 할인이 주어졌을 때 완전한 근무일 수 계산하기

예산, 시급, 할인을 받아 그 예산으로 며칠 동안 완전히 일할 수 있는지 계산하는 `days_in_budget` 함수를 구현해요.

```cpp
days_in_budget(20'000, 80, 11.0)
// => 35
```

반환되는 일수는 가장 가까운 정수로 내림(바닥 함수)해야 해요.
