# 소개

문자열은 텍스트 데이터를 나타내요.
Swift에서 [`String`][strings-and-characters]은 `Character` 값이 순서대로 나열된 컬렉션이고, 각 문자는 유니코드 문자를 나타내요.

문자열은 문자열 리터럴로 만들어요. 문자열 리터럴은 큰따옴표(`"`)로 둘러싼 문자의 나열이에요.
여러 줄 문자열에는 큰따옴표 세 개(`"""`)를 사용해요:

```swift
let hello: String = "Hello, World!"

let poem: String = """
Roses are red,
Violets are blue.
Sugar is sweet,
And so are you.
"""
```

Swift의 문자열은 Foundation 프레임워크의 [`NSString`][nsstring-docs] 클래스와 매끄럽게 이어져서, 폭넓은 텍스트 처리 기능을 활용할 수 있어요.

## 문자

`Character`는 하나의 확장 문자소 클러스터를 나타내요. 확장 문자소 클러스터는 하나 이상의 [유니코드 스칼라 값][unicode-scalar-values]으로 이루어진, 사람이 읽을 수 있는 문자예요.
유니코드 스칼라 값은 `U+0000` 이상 `U+D7FF` 이하 또는 `U+E000` 이상 `U+10FFFF` 이하 범위의 21비트 코드 포인트예요.

```swift
let aChar: Character = "A"
```

## 타입 추론

문자열 리터럴을 쓰면, Swift가 자동으로 그 타입을 `String`으로 추론해요.
하나의 문자를 `Character`로 저장하려면 타입을 명시적으로 지정해야 해요:

```swift
let aString = "A"        // Inferred as String
let aChar: Character = "A" // Explicitly typed as Character
print(type(of: aString)) // Prints String
print(type(of: aChar))   // Prints Character

// The following code will not compile:
let badChar: Character = "Too many characters"
// Error: Cannot convert value of type 'String' to specified type 'Character'
```

## 연결

덧셈 연산자(`+`)를 사용해 문자열을 서로 이어 붙일 수 있어요:

```swift
print("honey" + "comb")
// Prints "honeycomb"
```

먼저 문자를 문자열로 변환하지 않으면 `+`로 `Character`를 `String`에 바로 이어 붙일 수는 없어요.
하지만 [`append(_:)`][append] 메서드를 사용하면 문자열이나 문자를 변경 가능한 문자열에 바로 덧붙일 수 있어요:

```swift
var greeting = "Hello"
let world = ", world"
let period: Character = "."

greeting.append(world)
print(greeting) // Prints "Hello, world"

greeting.append(period)
print(greeting) // Prints "Hello, world."
```

## 문자열 보간

[문자열 보간][string-interpolation]을 사용하면 문자열 리터럴 안에 상수, 변수, 리터럴, 표현식을 넣어 문자열을 만들 수 있어요.
각 표현식은 백슬래시가 앞에 오는 괄호(`\(` ... `)`)로 감싸요:

```swift
let radius = 5.0
let circle = "The area of a circle with radius \(radius) is \(Double.pi * radius * radius)"
print(circle) // Prints "The area of a circle with radius 5.0 is 78.53981633974483"
```

## 문자열과 문자의 프로퍼티

문자열과 문자에는 내용을 살펴볼 수 있는 여러 프로퍼티가 있어요.

### 문자열 프로퍼티

자주 쓰이는 문자열 프로퍼티는 다음과 같아요:

| 프로퍼티  | 설명                                           | 예시                             |
| --------- | ---------------------------------------------- | -------------------------------- |
| `isEmpty` | 문자열에 문자가 없으면 `true`를 반환해요       | `"Hello".isEmpty`는 `false`예요  |
| `count`   | 문자열의 문자 개수를 반환해요                  | `"Hello".count`는 `5`예요        |

전체 프로퍼티 목록은 [Apple String 문서][string-docs]를 참고해요.

### 문자 프로퍼티

자주 쓰이는 문자 프로퍼티는 다음과 같아요:

| 프로퍼티       | 설명                                     | 예시                                 |
| -------------- | ---------------------------------------- | ------------------------------------ |
| `isLowercase`  | 문자가 소문자면 `true`를 반환해요        | `"a".isLowercase`는 `true`예요       |
| `isUppercase`  | 문자가 대문자면 `true`를 반환해요        | `"A".isUppercase`는 `true`예요       |
| `isNumber`     | 문자가 숫자면 `true`를 반환해요          | `"1".isNumber`는 `true`예요          |
| `isWhitespace` | 문자가 공백이면 `true`를 반환해요        | `" ".isWhitespace`는 `true`예요      |

전체 프로퍼티 목록은 [Apple Character 문서][character-docs]를 참고해요.

## 타입 변환

`String(_:)` 이니셜라이저를 사용하면 다른 타입을 문자열로 변환할 수 있어요. 이 이니셜라이저는 `Int`, `Double`, `Character` 같은 표준 타입을 지원해요:

```swift
let charX: Character = "x"
print(String(charX))     // Prints "x"
print(String(110))       // Prints "110"
print(String(Double.pi)) // Prints "3.141592653589793"
```

## 특수 문자

Swift 문자열 리터럴은 특수 문자를 위한 여러 [이스케이프 시퀀스][special-characters]를 지원해요:

| 시퀀스     | 설명                          |
| ---------- | ----------------------------- |
| `\0`       | 널 문자                       |
| `\\`       | 백슬래시                      |
| `\t`       | 가로 탭                       |
| `\n`       | 줄 바꿈(개행)                 |
| `\r`       | 캐리지 리턴                   |
| `\'`       | 작은따옴표                    |
| `\"`       | 큰따옴표                      |
| `\u{n}`    | 임의의 유니코드 스칼라(16진수) |

```swift
let quote: String = "\"Hello\", he said."
print(quote) // Prints "Hello", he said.

let unicode: Character = "\u{1F496}"
print(unicode) // Prints 💖
```
