# 소개
C++의 기본 제공 숫자 타입은 정수와 실수로 나눌 수 있어요.
정수는 `0`, `691`, `-2`처럼 소수점이 없는 수예요.
실수는 `6.02214076`, `0.1`, `-1.616`처럼 소수점이 있는 수예요.

## 정수
다음 예제는 서로 다른 네 개의 변수를 선언하고 초기화하는 모습을 보여줘요.

```cpp
int m_morales{9241};              // base 10: 0-9
int a_apaec{0x24CD};              // base 16: 0-9 and A-F
int m_gargan{0b10010000011001};   // base  2: 0-1
int b_reilly{022031};             // base  8: 0-7
                                  // Leading with a 0 not the letter o.
```

`int` 변수에 값을 대입할 때는 리터럴을 사용해 바로 대입할 수 있어요.
리터럴은 `9241`처럼 코드에 직접 적어 넣은 수예요.
표현 방식의 진법에 따라 여러 가지 정수 리터럴이 있어요.
10진수 정수 리터럴이 가장 흔하고, `0`부터 `9`까지의 숫자를 사용해요.
`0x` 같은 특별한 접두사를 붙이면 다른 진법도 사용할 수 있어요.
위 예제는 숫자 `9241`을 네 가지 표현과 접두사로 나타낸 거예요.
모든 변수는 같은 값으로 초기화돼요.

여러 표현 방식에 대한 자세한 내용은 [간단한 튜토리얼][cpp_numerical_bases]을 참고해요.

가독성을 높이려면 작은따옴표로 숫자를 구분할 수 있어요.
`9'241`은 `0b0100'100'0001'1001` 또는 `92'4'1`과 같아요.

## 실수

실수 리터럴에는 두 가지 형태가 있어요.
직관적인 `0.0024` 외에도 과학적 표기법인 `2.4e-3`을 사용할 수 있어요.
가장 흔한 실수형은 `double`이에요.

## 산술 연산

C++은 `+`, `-`, `*`, `/`, `(`, `)`, `%`를 사용해 표현식을 만들 수 있어요.
두 정수 사이의 연산 결과도 정수예요.
`5 / 2`는 `2`를 반환해요.
연산에 포함된 타입 중 하나가 실수형이면 결과도 실수형이 돼요.
`5.0 / 2`와 `5 / 2.0`은 `2.5`를 반환해요.
`%`는 나머지 연산자로, 정수 나눗셈의 나머지를 반환해요. `5%3`은 `2`예요.

## 대입 연산자

대입 연산자는 변수에 리터럴 값을 대입해요.
대입은 항상 오른쪽에서 왼쪽으로 이루어지고, 그 반대는 안 돼요.

```cpp
int length = 5;
int width = 2;
length = width;
```

여기서는 정수 값 `5`가 변수 `length`에 대입돼요.
그다음 정수 값 `2`가 변수 `width`에 대입돼요.
마지막으로 `width`의 값이 변수 `length`로 복사되고, 이전 값 `5`는 사라져요.
또한 대입 연산이 일어나는 순간에만 `width`의 값을 `length`에 대입한다는 점도 기억해요.
따라서 나중에 `width`의 값이 바뀌더라도 `length`의 값에는 영향을 주지 않아요.

대입 연산자는 산술 및 비트 연산자 같은 다른 연산자와 결합할 수 있어요. 이런 연산자를 `compound assignment` 연산자라고 하고, `+=`, `-=`, `*=`, `/=`, `%=`가 있어요.
이 연산자들은 변수의 현재 값에 연산을 수행해서 값을 바꿔요.

```cpp
// we start with 0 people
int people{};
// we need 0 eggs
int eggs{};
// two people joined:
people += 2;
// people is now 2
// let's add 3 eggs per person
eggs += 3 * people;
// eggs is now 6
```

변수 `people`과 `eggs`는 `0`으로 초기화돼요.
그다음 변수 `people`의 기존 값 `0`에 정수 값 `2`를 더하고, 그 결과를 다시 `people`에 대입해요.
이제 `people`은 `2`가 돼요.
그다음 사람마다 계란 `3`개씩 더하는데, 모두 합하면 계란 `6`개가 돼요.
이제 이 `6`을 변수 `eggs`의 기존 값 `0`에 더하고, 그 결과를 다시 `eggs`에 대입해요.
이제 `eggs`는 `6`이 돼요.
같은 의미의 표현식은 `people = people + 2`와 `eggs = eggs + (3 * people)`예요.
