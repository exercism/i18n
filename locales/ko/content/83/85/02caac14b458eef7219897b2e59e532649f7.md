# 소개

함수는 어떤 동작을 수행하는 데 사용되는, 잘 정리된 재사용 가능한 코드 블록이에요.
JavaScript에서 함수를 정의하는 방법은 여러 가지가 있어요.
여기에서는 _함수 선언_과 _함수 표현식_을 살펴볼게요.
[화살표 함수][concept-arrow-functions] 같은 다른 방법은 다른 개념에서 다뤄요.

## 함수 선언

JavaScript에서 함수를 정의하는 표준적인 방법은 _함수 선언_이고, _함수 정의_ 또는 _함수 문_이라고도 해요.

`function` 키워드, 함수 이름, 그리고 괄호 안에 쉼표로 구분해 나열한 매개변수로 이루어져 있어요.
그 뒤에는 중괄호로 감싼 함수 본문(함수가 무엇을 하는지 정의하는 문들의 모음)이 와요.

```javascript
function someName(param1, param2, param3) {
  // ...
}
```

JavaScript에서는 함수 이름을 쓰고, 그 뒤에 인자를 담은 괄호를 붙여서 함수를 호출해요.

```javascript
someName(arg1, arg2, arg3);
```

## 매개변수

함수 본문 안에서 매개변수를 다룰 때는 발생할 수 있는 부수 효과에 주의해야 해요.

- [원시 자료형][mdn-primitives]의 값은 _불변_이에요.
  원래 값은 함수 본문에서 인자에 무슨 일이 일어나든 영향을 받지 않아요.
- 그 밖의 모든 값(객체, 배열, 함수)은 재할당해도 원래 값에 영향을 주지 않아요.
  하지만 그런 인자를 수정하면(예를 들어 객체에 키를 추가하면) 전달된 원래 값도 함께 수정돼요.

JavaScript에서는 함수 선언에 정의된 모든 매개변수가 기본적으로 선택 사항이에요.
매개변수보다 적은 인자를 넘기면 빠진 인자는 함수 안에서 `undefined`가 돼요. [Null과 Undefined][concept-null-undefined]를 참고해요.
많은 경우 `undefined`보다 더 적절한 기본값을 지정하는 게 좋아요.
이는 함수 정의에서 기본 매개변수를 직접 지정해서 할 수 있어요.

```javascript
function someName(param1 = defaultValue1, param2 = defaultValue2) {
  // ...
}
```

## 반환문

`return` 문은 함수 실행을 끝내고 함수 호출자에게 반환할 값을 지정해요. 함수는 여러 개의 `return` 문을 가질 수 있어요.

```javascript
function checkNumber(num) {
  if (num === 0) {
    return 'You passed 0, please provide another number.';
  }

  return 'Thanks for passing such a nice number.';
}
```

값을 `return`하지 않거나 `return` 문이 없는 함수의 결과는 `undefined`예요.
JavaScript에는 암시적인 `return`이 없어요.

```javascript
function nakedReturn(a) {
  a * 2;
  return;
}

nakedReturn(1);
// => undefined

function noReturn(a) {
  a * 2;
}

noReturn(1);
// => undefined
```

JavaScript에서는 정확히 하나의 값만 반환할 수 있어요.
더 많은 정보를 전달하고 싶다면, 먼저 그것을 하나의 개체로 합쳐야 하는데, 보통 [객체][concept-objects]나 [배열][concept-arrays]로 합쳐요.

```javascript
function divide(a, b) {
  return {
    quotient: Math.floor(a / b),
    remainder: a % b,
  };
}
```

## 함수 표현식

함수 선언은 독립적인 문이에요.
하지만 때로는 함수를 다른 표현식의 일부로 정의하는 게 도움이 돼요. 예를 들어 할당에서, 함수 매개변수([콜백][concept-callbacks])로, 또는 [객체][concept-objects]의 값으로요.
이는 함수 표현식으로 할 수 있어요.
문법은 함수 선언과 같은데, 함수 이름을 생략해서 _익명 함수_를 만들 수 있다는 점만 달라요.

```javascript
const someFunction = function (param) {
  // ...
};

someOtherFunction(function (param) {
  // ...
});

const obj = {
  someFunction: function (param) {
    // ...
  },
};
```
