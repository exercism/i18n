# 지침 추가

## 예외 메시지

때로는 [예외를 발생시켜야](https://docs.python.org/3/tutorial/errors.html#raising-exceptions) 할 때가 있어요. 이럴 때는 오류의 원인이 무엇인지 알려 주는 **의미 있는 오류 메시지**를 항상 포함해야 해요. 그러면 코드를 더 읽기 쉽게 만들고 디버깅에도 큰 도움이 돼요. 오류의 원인이 특정 타입일 것이라고 알고 있는 상황이라면 [내장 오류 타입](https://docs.python.org/3/library/exceptions.html#base-classes) 중 하나를 발생시켜도 되지만, 그래도 의미 있는 메시지는 포함해야 해요.

이 연습 문제에서는 `largest_product()` 함수가 잘못된 입력을 받았을 때 [raise 문](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)을 사용해 `ValueError`를 "던져야" 해요. 테스트는 `exception`을 `raise`하고 메시지도 함께 포함해야만 통과해요. `series` 연습 문제에서 작성한 코드를 재사용해도 좋아요!

메시지와 함께 `ValueError`를 발생시키려면, 메시지를 `exception` 타입의 인자로 작성해요:

```python
# span of numbers is longer than number series
raise ValueError("span must not exceed string length")

# span of number is negative
raise ValueError("span must not be negative")

# series includes non-number input
raise ValueError("digits input must only contain digits")
```
