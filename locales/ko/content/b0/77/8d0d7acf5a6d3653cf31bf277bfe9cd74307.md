# Bash 지뢰찾기 연습 문제 힌트

이 연습 문제에는 2차원 배열이 필요한 것처럼 보여요.
Bash는 1차원 인덱스 배열이나 연관 [배열][array]만 제공해요.

다차원 배열은 연관 배열을 사용해 흉내 낼 수 있어요. 인덱스를 쉼표로 구분한 문자열로 인코딩해서 배열 키로 쓰면 돼요.

```bash
# store this matrix:
#   a b
#   c d
declare -A array2d
array2d["0,0"]="a"
array2d["0,1"]="b"
array2d["1,0"]="c"
array2d["1,1"]="d"
```

[array]: https://www.gnu.org/software/bash/manual/bash.html#Arrays
