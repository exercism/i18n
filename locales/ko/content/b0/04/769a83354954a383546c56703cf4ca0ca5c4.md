# 지시 사항

이 연습 문제에서는 간단한 계산기를 위한 오류 처리를 만들어 봐요.

목표는 인자 `16`, `51`, `+`가 주어졌을 때 `16 + 51 = 67` 같은 패턴의 문자열을 반환하는, 제대로 동작하는 계산기를 만드는 거예요.

```ruby
SimpleCalculator.calculate(16, 51, "+")
# => "16 + 51 = 67"
SimpleCalculator.calculate(32, 6, "*")
# => "32 * 6 = 192"
SimpleCalculator.calculate(512, 4, "/")
# => "512 / 4 = 128"
```

## 1. `calculate` 메서드 안에서 오류가 발생할 수 있는 코드를 처리해요

이번 과제에서 구현할 핵심 메서드는 클래스 메서드인 `SimpleCalculator.calculate()`예요.
이 메서드는 세 개의 인자를 받아요.
처음 두 인자는 연산을 수행할 숫자예요.
세 번째 인자는 문자열 타입이고, 이 연습 문제에서는 다음 연산들을 구현해야 해요:

- `+` 문자열을 사용한 덧셈
- `*` 문자열을 사용한 곱셈
- `/` 문자열을 사용한 나눗셈

## 2. 허용되지 않는 연산을 처리해요

알 수 없는 연산 기호에 대해서는 `UnsupportedOperation` 예외를 발생시키도록 `SimpleCalculator.calculate()` 메서드를 수정해요.

```ruby
SimpleCalculator.calculate(1, 2, '-')
# => Raises an UnsupportedOperation
```

~~~~exercism/note
이 연습 문제에서는 특정 스코프에 대한 `UnsupportedOperation` 예외를 정의해야 해요.
~~~~

## 3. 잘못된 인자를 처리해요

잘못된 인자 타입에 대해서는 `ArgumentError` 예외를 발생시키도록 `SimpleCalculator.calculate()` 메서드를 수정해요.

```ruby
SimpleCalculator.calculate(1, '2', '*')
# => Raises an ArgumentError
```

## 4. DivideByZero 예외를 처리해요

`ZeroDivisionError` 예외를 처리하도록 `SimpleCalculator.calculate()`를 수정해요.
처리 코드는 `Division by zero is not allowed.`라는 내용의 문자열을 반환해야 해요.
그 밖의 다른 예외는 `SimpleCalculator.calculate()` 메서드에서 처리하면 안 돼요.

```ruby
SimpleCalculator.calculate(512, 0, "/")
# => returns "Division by zero is not allowed."
```
