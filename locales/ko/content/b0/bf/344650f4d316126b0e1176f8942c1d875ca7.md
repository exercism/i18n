# 힌트

## 일반

- ASCII로 인코딩된 문자열에서는 모든 문자가 메모리에서 1바이트를 차지해요.
- 메모리 위치를 역참조하려면 `[]`를 사용해야 해요.
- 대문자의 ASCII 값은 같은 소문자의 ASCII 값보다 32만큼 작아요.

## 1. 문장의 첫 글자 가져오기

- ASCII로 인코딩된 문자열에서는 모든 문자가 메모리에서 1바이트를 차지해요.
- 메모리 위치를 역참조하려면 `[]`를 사용해야 해요.
- 대문자의 ASCII 값은 같은 소문자의 ASCII 값보다 32만큼 작아요.
- 1바이트 값은 `al`에 반환돼요.

## 2. 단어의 첫 글자를 대문자로 만들기

- ASCII로 인코딩된 문자열에서는 모든 문자가 메모리에서 1바이트를 차지해요.
- 메모리 위치를 역참조하려면 `[]`를 사용해야 해요.
- 대문자의 ASCII 값은 같은 소문자의 ASCII 값보다 32만큼 작아요.
- 대문자화란 _대문자_ 문자 하나 뒤에 _소문자_ 문자들이 이어지는 것을 뜻해요.
- 'a'와 'z' 사이의 값만 소문자이고, 'A'와 'Z' 사이의 값만 대문자예요.
- 그래서 먼저 첫 글자를 추출한 다음, 그 글자가 소문자라면 대문자로 변환해야 해요.
- 그다음에는 문자열의 나머지 부분을 처리해야 해요. 첫 글자 뒤에 오는 모든 문자는 대문자라면 소문자로 변환하고, 그렇지 않으면 그대로 둬요.
- 문자열은 `'\0'`(NUL 문자)을 만나면 끝나요.
- `lodsb`를 사용하면 `rsi`가 가리키는 메모리 위치의 바이트를 `al`에 로드하고, `rsi`를 1만큼 바꿀 수 있어요.
- `stosb`를 사용하면 `al`에 로드된 바이트를 `rdi`가 가리키는 메모리 위치에 저장하고, `rdi`를 1만큼 바꿀 수 있어요.

## 3. 문장의 마지막 글자 가져오기

- ASCII로 인코딩된 문자열에서는 모든 문자가 메모리에서 1바이트를 차지해요.
- 메모리 위치를 역참조하려면 `[]`를 사용해야 해요.
- 대문자의 ASCII 값은 같은 소문자의 ASCII 값보다 32만큼 작아요.
- 마지막 글자를 찾으려면 문자열을 순회해야 해요.
- 'a'와 'z' 사이의 값만 소문자이고, 'A'와 'Z' 사이의 값만 대문자예요.
- 1바이트 값은 `al`에 반환돼요.

## 4. 예의 바르게 만들기

- ASCII로 인코딩된 문자열에서는 모든 문자가 메모리에서 1바이트를 차지해요.
- 메모리 위치를 역참조하려면 `[]`를 사용해야 해요.
- 대문자의 ASCII 값은 같은 소문자의 ASCII 값보다 32만큼 작아요.
- 단어를 대문자로 만들 때는 기존 함수를 재사용해요.
- `movsb`를 사용하면 `rsi`가 가리키는 메모리 주소의 바이트를 `rdi`가 가리키는 메모리 주소로 복사하고, `rsi`와 `rdi`를 모두 1만큼 바꿀 수 있어요.
- _section .rodata_나 _section .data_에 초기화된 문자열을 정의할 수 있어요.
- 상대 주소를 계산하려면 `rel`을 사용해야 해요.
- `arr`이라는 레이블로 선언한 배열에서, 배열을 선언한 바로 뒤에 사용하면 `$ - arr`은 `arr`의 전체 크기를 바이트 단위로 나타내요.
- `rep`를 사용하면 `movsb` 같은 문자열 명령을 `rcx`에 지정한 횟수만큼 반복할 수 있어요.
- 문자열은 종결자로 `'\0'`(NUL 문자)으로 끝나야 해요.
- 백슬래시가 들어간 특수 문자(예: `'\0'`)는 백틱(`` ` ``)으로 정의하거나, 10진수 값(NUL의 경우 `0`)을 사용해 정의해야 한다는 점을 기억해요.
