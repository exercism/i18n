# 최상위 상수로 만들기

`GIGASECOND` 숫자를 상수로 추출하는 것을 고려해 봐요:

```javascript
const %{name} = %{value}

// the rest of your code below it
export const gigasecond = (...)
```

`export`된 함수, 클래스, 상수만 외부에서 보고 접근할 수 있어요. 일반적으로 [매직 넘버](https://en.wikipedia.org/wiki/Magic_number_%%28programming%%29)에 이름을 붙이는 것이 좋고, 이렇게 하면 유지보수성이 좋아져요. 이런 상수들은 다른 코드에 노출되지 않고 같은 파일에 함께 있을 수 있어요.
