# 개요

구조체나 클래스의 인스턴스에는 모두 `self`라는 암시적인 속성이 있어요. `self`는 인스턴스 자기 자신을 가리켜요.
`self`를 가장 흔히 쓰는 경우는 이름이 같은 인스턴스 속성과 매개변수를 구분하기 위해서예요.

```swift
struct Position {
    var x = 0

    mutating func move(x: Int) {
        // Here, 'self.x' refers to the struct's property,
        // while 'x' refers to the parameter passed to the method.
        self.x = x
    }
}
```

Swift 타입에는 대문자로 시작하는 `Self` 키워드도 있어요. 이 키워드는 인스턴스 자체가 아니라 인스턴스의 *타입*을 가리켜요.
