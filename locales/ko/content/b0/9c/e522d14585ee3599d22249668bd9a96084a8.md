# 예상치 못한 스플랫 인자

`...%{splat-arg.name}: %{parameter.type}[]`를 쓰는 대신, `%{splat-arg.name}`이라는 매개변수를 `%{parameter.type}` 타입으로 정의해요.

[나머지 매개변수 / 스플랫 인자](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Functions/rest_parameters)는 함수가 몇 개의 값을 받을지 정하지 않을 때는 아주 유용하지만, 이 경우에는 함수가 몇 개의 값으로 호출될지가 분명히 정해져 있어요.
