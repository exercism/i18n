# 안내

이 연습 문제에서는 차량 구매를 준비하는 데 도움이 되는 코드를 작성해요.

세 가지 작업이 있어요. 하나는 면허가 필요한지 판단하는 것, 하나는 두 차량 중에서 선택하도록 돕는 것, 또 하나는 중고 차량의 적정 가격을 추정하는 것이에요.

## 1. 운전면허가 필요한지 판단하기

어떤 종류의 차량은 운전하려면 운전면허가 필요해요.
`'car'`와 `'truck'` 종류만 면허가 필요하고, 나머지는 모두 면허 없이 운전할 수 있다고 가정해요.

차량 종류를 받아 그 종류에 면허가 필요한지를 나타내는 불리언을 반환하는 `needsLicense(kind)` 함수를 구현해요.

```javascript
needsLicense('car');
// => true

needsLicense('bike');
// => false
```

## 2. 구매할 두 후보 차량 중에서 선택하기

구매할 수 있는 차량들을 하나씩 살펴봐요.
후보를 두 가지로 좁혔지만, 최종 결정을 내리려면 도움이 필요해요.
그러기 위해 두 차량을 인자로 받아, 사전 순으로 앞서는 차량을 포함한 결정을 반환하는 `chooseVehicle(option1, option2)` 함수를 구현해요.

```javascript
chooseVehicle('Wuling Hongguang', 'Toyota Corolla');
// =>  'Toyota Corolla is clearly the better choice.'

chooseVehicle('Volkswagen Beetle', 'Volkswagen Golf');
// =>  'Volkswagen Beetle is clearly the better choice.'
```

## 3. 중고 차량의 예상 가격 계산하기

이제 결정을 내렸으니, 자동차 판매점에서 적정한 가격에 사는지 확인하고 싶어요.
중고 차량을 사려고 하니, 가격은 차량이 얼마나 오래됐는지에 따라 달라져요.
대략적으로 추정해 보면, 차량이 3년 미만이면 새 차였을 때의 원래 가격에서 80%를 받아요.
10년이 넘으면 50%를 받아요.
차량이 3년 이상이지만 10년 이하라면 원래 가격의 70%를 받아요.

`if`, `else if`, `else`를 사용해 이 로직을 적용하는 `calculateResellPrice(originalPrice, age)` 함수를 구현해요(연습하고 싶다면 다른 방법을 써도 돼요).
원래 가격과 차량의 연식을 인자로 받아, 판매점에서의 예상 가격을 반환해요.

```javascript
calculateResellPrice(1000, 1);
// => 800

calculateResellPrice(1000, 5);
// => 700

calculateResellPrice(1000, 15);
// => 500
```
