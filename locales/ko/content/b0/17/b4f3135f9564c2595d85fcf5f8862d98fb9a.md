# 개요

Go에는 정수 또는 실수의 값 집합을 표현할 수 있는 기본 숫자 타입이 있어요.
필요한 값의 크기와 애플리케이션이 실행되는 컴퓨터의 아키텍처(예: 32비트와 64비트)에 따라 타입이 달라져요.

이 개념에서는 두 가지 숫자 타입에 집중해요:

- `int`: 예: `0`, `255`, `2147483647`.
   크기가 최소 32비트인 부호 있는 정수예요 (값 범위: -2147483648부터 2147483647까지).
   하지만 이는 시스템 아키텍처에 따라 달라져요.
   대부분의 최신 컴퓨터는 64비트이므로 `int`의 크기는 64비트가 돼요 (값 범위: -9223372036854775808부터 9223372036854775807까지).

- `float64`: 예: `0.0`, `3.14`.
   64비트 부동소수점 수 전체의 집합을 담고 있어요.

사용할 수 있는 숫자 타입의 전체 목록과 더 자세한 내용은 다음 자료를 참고해요:

- [Go 내장 타입 선언][go-builtins]
- [Digital Ocean - Go에서의 데이터 타입 이해하기][do-understanding-types]
- [Arden Labs - Go의 타입 이해하기][arden-understanding-types]

Go는 `+`, `-`, `*`, `/`, `%`의 표준 산술 연산자를 지원해요 (`%`는 모듈로가 아니라 나머지예요).

Go에서는 서로 다른 타입 간에 값을 할당하려면 명시적 변환이 필요해요.
예를 들어 `int`를 `float64`로 변환하려면 다음과 같이 해야 해요:

```go
var x int = 42
f := float64(x)

fmt.Printf("x is of type: %s\n", reflect.TypeOf(x))
// Output: x is of type: int

fmt.Printf("f is of type: %s\n", reflect.TypeOf(f))
// Output: f is of type: float64
```

타입 변환에 대한 더 자세한 내용은 [A Tour of Go: 타입 변환][type-conversion]을 참고해요.
