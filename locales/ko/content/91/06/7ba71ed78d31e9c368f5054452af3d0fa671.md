# 지시 사항

옛날에 창문에 쇠창살이 달린 이상한 집에 사는 별난 프로그래머가 있었어요.
어느 날 온라인 구인 게시판에서 파티 로봇을 만드는 일자리를 받아들였어요.
그 로봇은 사람들을 맞이하고 자리로 안내해야 했어요.
첫 번째 버전은 몹시 기술적이어서 프로그래머의 인간적 교류 부족을 그대로 드러냈어요.
그중 일부는 다음 버전에도 그대로 들어갔어요.

## 1. 파티에 온 새 손님 맞이하기

주어진 이름으로 환영 메시지를 반환하는 `Welcome` 함수를 구현해요:

```go
Welcome("Christiane")
// => Welcome to my party, Christiane!
```

## 2. 생일이 오늘인 새 손님 맞이하기

주어진 이름과 나이로 생일 메시지를 반환하는 `HappyBirthday` 함수를 구현해요.
안타깝게도 프로그래머는 좀 허세를 부리는 성격이라, 로봇은 모든 손님의 생일을 안다는 걸 보여줘야 해요.

```go
HappyBirthday("Frank", 58)
// => Happy birthday Frank! You are now 58 years old!
```

## 3. 길 안내하기

길 안내를 하는 `AssignTable` 함수를 구현해요.
이 함수는 매개변수 5개를 받아요.

- 맞이할 새 손님의 이름 (`string`)
- 테이블 번호 (`int`)
- 옆자리 사람의 이름 (`string`)
- 테이블이 있는 방향 (`string`)
- 테이블까지의 거리 (`float64`)

정확한 결과 형식은 아래 예시에서 볼 수 있어요.

로봇은 테이블 번호를 세 자리 형식으로 알려줘요.
번호가 세 자리가 안 되면 앞에 0을 채워서 세 자리로 만들어요 (예: 3은 003이 돼요).
로봇은 테이블까지의 거리도 언급해요.
다행히 정밀도는 소수점 한 자리로 제한돼요.

```go
AssignTable("Christiane", 27, "Frank", "on the left", 23.7834298)
// =>
// Welcome to my party, Christiane!
// You have been assigned to table 027. Your table is on the left, exactly 23.8 meters from here.
// You will be sitting next to Frank.
```
