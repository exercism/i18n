# 지침

체스 애호가라면, 자신만의 체스 게임을 만들어 보고 싶을 거예요.
네, 이미 온라인에 체스 구현이 많이 있겠지만, 직접 만든 것은 독특할 거예요!

기물의 기본 이동 체계를 구현하는 것부터 시작해요.

체스 게임은 가로 여덟 칸, 세로 여덟 칸인 보드에서 진행돼요.
각 칸은 문자와 숫자로 구분해요.

## 1. 랭크와 파일 범위 정의하기

게임은 보드의 랭크를 저장해야 해요.
랭크는 보드의 행이며, 1부터 8까지 번호가 매겨져 있어요.

게임은 보드의 파일도 저장해야 해요.
파일은 보드의 열이며, 문자 A부터 H로 구분해요.

각각 랭크와 파일의 범위를 저장하는 `Chess::RANKS`와 `Chess::FILES` 상수를 정의해요.

```crystal
Chess::RANKS
# => 1..8

Chess::FILES
# => 'A'..'H'
```

## 2. 칸이 유효한지 확인하기

게임은 칸이 유효한지 확인해야 해요.
랭크와 파일이 각각 랭크와 파일의 범위 안에 있으면 그 칸은 유효해요.

랭크의 정수를 담는 `rank`와 파일의 문자를 담는 `file` 인자를 받는 `Chess.valid_square?` 메서드를 정의해요.
이 메서드는 랭크와 파일이 랭크와 파일의 범위 안에 있으면 `true`를, 그렇지 않으면 `false`를 반환해야 해요.

```crystal
Chess.valid_square?(1, 'A')
# => true
```

## 3. 플레이어의 닉네임 가져오기

게임은 플레이어의 닉네임을 가져와야 해요.
닉네임은 플레이어의 이름의 처음 두 문자와 성의 마지막 두 문자예요.
닉네임은 대문자로 표기해야 해요.

플레이어의 이름을 담는 `first_name` 문자열과 플레이어의 성을 담는 `last_name` 문자열 인자를 받는 `Chess.nickname` 메서드를 정의해요.
이 메서드는 플레이어의 닉네임을 대문자로 변환한 문자열로 반환해야 해요.

```crystal
Chess.nickname("John", "Doe")
# => "JOOE"
```

## 4. 이동 메시지 만들기

게임은 어떤 플레이어가 어떤 칸으로 이동했는지 알려 주는 이동 메시지를 만들어야 해요.
메시지에는 플레이어의 닉네임과 이동한 칸을 사용해요.
또한 게임은 칸의 파일과 랭크가 파일과 랭크의 범위 안에 있는지 확인해서 이동이 유효한지 판단해야 해요.

이동이 유효하면 메시지는 `"{nickname} moved to {square}"`여야 해요.
이동이 유효하지 않으면 메시지는 `"{nickname} attempted to move to {square}, but that is not a valid square"`여야 해요.

플레이어의 이름을 담는 `first_name` 문자열, 플레이어의 성을 담는 `last_name` 문자열, 플레이어가 이동한 칸을 담는 `square` 문자열을 인자로 받는 `Chess.move_message` 메서드를 정의해요.
이 메서드는 이동 메시지를 문자열로 반환해야 해요.

```crystal
Chess.move_message("John", "Doe", "A1")
# => "JOOE moved to A1"
```
