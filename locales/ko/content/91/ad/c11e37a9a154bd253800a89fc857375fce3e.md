# 개요

`SYMBOL:`은 값을 *담고* 있지 않아요. 그냥 이름일 뿐이에요. 값은 네임스페이스에 살고, 이름은 그 네임스페이스의 키가 돼요.

```factor
USING: namespaces ;

SYMBOL: history

V{ } clone history set-global
"first event" history get-global push
"second event" history get-global push
history get-global .
! => V{ "first event" "second event" }
```

스코프는 두 가지예요.

- **전역** — `set-global`, `get-global`, `change-global`로 쓰고 읽어요. 값은 프로세스가 살아 있는 동안 계속 유지돼요.
- **동적** — `set`, `get`, `change`로 쓰고 읽어요. 바인딩은 `with-variable` 폼이 실행되는 동안만 살아 있어서, 중간에 있는 모든 시그니처를 바꾸지 않고도 바깥 코드가 안쪽 코드에서 보이는 값을 "주입"할 수 있어요.

```factor
"verbose" log-level [
    log-level get .   ! => "verbose"
] with-variable
```

`SYMBOL:`과 `SYMBOLS:`는 보캐뷸러리가 로드될 때 심볼을 선언해서, 여러 파일에서 공유할 수 있는 참조가 되게 해줘요.
