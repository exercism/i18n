# Debug

테스트가 실패하면 무엇이 잘못되었는지, 그리고 어떤 입력에서 그런지 설명하는 메시지가 표시돼요. [콘솔 출력][fmt-println]도 함께 보인다는 점을 활용할 수 있어요. 콘솔에 출력하려면 이렇게 써요:

```go
import "fmt"
fmt.Println("Debug message")
```

[fmt-println]: https://pkg.go.dev/fmt#Println

참고: 브라우저 편집기에서 디버깅할 때 `fmt.Print` 같은 걸 쓰면 출력 뒤에 줄바꿈이 붙지 않아요. 그러면 `go test --json`의 버그를 유발해서 테스트 출력이 엉망이 될 수 있어요.
