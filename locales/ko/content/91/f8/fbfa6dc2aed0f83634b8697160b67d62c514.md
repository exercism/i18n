# 개요

부동소수점 수는 `3.14`, `-1.7`, `99.99`, `2048.0`처럼 소수점을 포함하는 소수나 정수를 말해요.

Common Lisp의 float 타입은 저마다 특성과 정밀도가 다른 여러 하위 타입으로 나뉘어요: short-float, single-float, double-float, long-float.

short-float 하위 타입은 보통 메모리를 가장 적게 차지하고 네 가지 중 정밀도가 가장 낮아요. 메모리 사용량이 걱정되지만 정밀도는 조금 낮아도 괜찮은 상황에 어울려요.

single-float 하위 타입은 메모리 사용량과 정밀도 사이의 균형을 잡아 줘요. 일반적인 부동소수점 계산에 흔히 쓰여요.

double-float 하위 타입은 single-float보다 정밀도가 높아서, 과학 계산이나 수치 시뮬레이션처럼 더 정확한 계산이 필요한 응용 프로그램에 알맞아요.

long-float 하위 타입은 네 가지 중 정밀도가 가장 높지만, 다른 하위 타입보다 메모리를 더 많이 차지할 수 있어요. 아주 정확한 계산이 필요한 특수한 응용 프로그램에 주로 쓰여요.

이런 하위 타입 덕분에 Common Lisp 프로그래머는 자신의 응용 프로그램 요구 사항에 맞춰 알맞은 정밀도와 메모리 사용량을 선택할 수 있어요.

일반적으로 정수만 다룬다면 정수를 쓰는 편이 좋아요. 부동소수점 수는 계산을 거듭할수록 정밀도를 잃지만, 정수는 그런 문제가 없어요.

## 참고

```lisp
;; Rounding to the Nearest Whole Number
(round 3.14)  ; => 3
(round -3.14) ; => -3
(round 2.72)  ; => 3
(round -2.72) ; => -3

;; Rounding Towards Zero
(truncate 3.14)  ; => 3
(truncate -3.14) ; => -3
(truncate 2.72)  ; => 2
(truncate -2.72) ; => -2

;; Rounding Towards Negative Infinity
(floor 3.14)  ; => 3
(floor -3.14) ; => -4
(floor 2.72)  ; => 2
(floor -2.72) ; => -3

;; Rounding Towards Positive Infinity
(ceiling 3.14)  ; => 4
(ceiling -3.14) ; => -3
(ceiling 2.72)  ; => 3
(ceiling -2.72) ; => -2
```
