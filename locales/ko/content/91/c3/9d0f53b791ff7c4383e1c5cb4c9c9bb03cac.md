# 지침

예비 마법사 Elyse는 훈련을 계속해요.
마술을 부리는 데 필요한 여러 개의 카드 덱을 받게 될 거예요.
조금 더 쉽게 하기 위해, Elyse는 1부터 10까지의 카드만 사용해요.
각 카드는 한 장씩만 가지고 있어서, 카드 덱에는 중복되는 카드가 없어요.

이 연습 문제에서는 Julia의 Base 라이브러리에 있는 메서드를 사용해 배열의 내용을 분석해요.

## 1. 카드가 있는지 확인하기

Elyse는 덱에 특정 카드가 있는지 확인하려고 해요. 다시 말해, 덱에 특정 숫자가 들어 있는지 알고 싶은 거예요.

```julia-repl
julia> card = 3;

julia> has_card([2, 3, 4, 5], card)
true
```

## 2. 카드의 위치 찾기

Elyse는 덱에서 카드의 위치(인덱스)를 알고 싶어 해요.
카드가 덱에 없으면 `nothing`을 반환해요.

```julia-repl
julia> card = 2;

julia> find_card([9, 7, 3, 2], card)
4
```

## 3. 모든 카드가 짝수인지 확인하기

Elyse는 모든 카드가 짝수인지 알고 싶어 해요. 다시 말해, 덱에 있는 각 숫자가 짝수인지 확인하는 거예요.

```julia-repl
julia> all_cards_even([2, 4, 6, 7])
false
```

## 4. 덱에 홀수 값 카드가 있는지 확인하기

Elyse는 덱에 홀수인 숫자가 있는지 알고 싶어 해요.

```julia-repl
julia> any_odd_cards([3, 2, 6, 4, 8])
true
```

## 5. 첫 번째 짝수 카드의 위치 찾기

Elyse는 첫 번째 짝수 카드의 위치를 알고 싶어 해요.
덱에 짝수 카드가 없으면 `nothing`을 반환해요.

```julia-repl
julia> first_even_card_idx([5, 2, 3, 1])
2
```

## 6. 덱에서 첫 번째 홀수 카드 가져오기

Elyse는 첫 번째 홀수 카드의 값을 알고 싶어 해요.
덱에 홀수 카드가 없으면 `nothing`을 반환해요.

```julia-repl
julia> first_odd_card([4, 2, 8, 7, 9])
7
```
