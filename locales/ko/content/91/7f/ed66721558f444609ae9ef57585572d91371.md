# 힌트

## 일반

- Elixir의 ['시작하기 가이드'][guide]에는 이름 있는 함수에 대한 좋은 복습 내용이 있어요.

## 1. 추측한 숫자가 정답 숫자와 일치할 때 응답 만들기

- `===/2`로 두 숫자가 같은지 확인하려면 [가드][guard]를 사용할 수 있어요.

## 2. 추측한 숫자가 정답 숫자보다 클 때 응답 만들기

- `>/2`로 추측한 숫자가 정답 숫자보다 큰지 확인하려면 [함수 절][multiple-fn-clauses]과 [가드][guard]를 추가할 수 있어요.

## 3. 추측한 숫자가 정답 숫자보다 작을 때 응답 만들기

- `</2`로 추측한 숫자가 정답 숫자보다 작은지 확인하려면 [함수 절][multiple-fn-clauses]과 [가드][guard]를 추가할 수 있어요.

## 4. 추측한 숫자가 정답 숫자보다 하나 많거나 하나 적을 때 응답 만들기

- 추측한 숫자가 정답 숫자보다 하나 적거나 하나 많은지 확인하려면 [함수 절][multiple-fn-clauses]과 [가드][guard]를 추가할 수 있어요.
- 가드 표현식은 `and/2`나 `or/2`를 사용해 불리언 표현식을 조합할 수 있어요.
- 함수 절의 순서에 주의해야 해요.

## 5. 추측이 없을 때 응답 만들기

- 추측에 [기본 인자][default-arg]를 사용할 수 있어요. 기본값이 반드시 정수일 필요는 없어요.
- 기본 인자를 정의하려면 다른 모든 함수 절보다 앞에 함수 헤더를 사용해요.

[default-arg]: https://hexdocs.pm/elixir/modules-and-functions.html#default-arguments
[guard]: https://hexdocs.pm/elixir/Kernel.html#guards
[guide]: https://hexdocs.pm/elixir/modules-and-functions.html#function-definition
[multiple-fn-clauses]: https://hexdocs.pm/elixir/modules-and-functions.html#function-definition
