# 소개

C#의 `enum` 타입은 이름이 붙은 상수들의 고정된 집합, 즉 열거형을 나타내요. `enum`의 주된 목적은 숫자 상수를 다룰 때 타입 안전한 방법을 제공하는 데 있어요. 사용할 수 있는 값을 미리 정의된 집합으로 제한하죠. 간단한 enum은 다음과 같이 정의할 수 있어요:

```csharp
enum Season
{
    Spring,
    Summer,
    Autumn,
    Winter
}
```

명시적으로 정의하지 않으면 enum 멤버에는 1씩 증가하는 정수 값이 자동으로 할당돼요. 첫 번째 값은 0이에요. 값을 직접 지정할 수도 있어요:

```csharp
enum Answer
{
    Maybe = 1,
    Yes = 3,
    No = 5
}
```
