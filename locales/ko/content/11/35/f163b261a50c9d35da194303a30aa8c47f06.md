# 안내 추가

## 힌트

이 연습 문제를 완료하려면 `Robot` 데이터 타입을 가변 변수로 만들고, `RunState` 데이터 타입도 만들어야 해요. 그리고 다음 함수들도 구현해야 해요:

- `initialState`
- `mkRobot`
- `resetName`
- `robotName`

더미 데이터 선언과 타입 시그니처는 이미 준비되어 있지만, 함수를 정의하고 의미 있는 데이터 타입이나 뉴타입, 또는 타입 동의어를 만드는 일은 직접 해야 해요. 이 연습 문제는 상태를 모델링하기 위해 [`State`](https://en.wikibooks.org/wiki/Haskell/Understanding_monads/State) 모나드를 사용해요. 더 구체적으로는 [`StateT` 모나드 트랜스포머](http://book.realworldhaskell.org/read/monad-transformers.html)를 사용해 `State` 모나드와 `IO` 모나드를 결합해요. 모든 테스트는 `initialState`를 `evalStateT`에 전달하는 상태로 실행해요.
