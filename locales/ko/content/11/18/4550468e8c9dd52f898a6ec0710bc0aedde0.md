# 지침

HTTP 엔드포인트는 타입 검사를 곁들이면 더 좋아요. POST 요청에 레코드 타입을 추가하면 항상 올바른 데이터가 전송되도록 보장할 수 있어요.

## 목표

- 제공된 코드를 수정해요.
- 이 레코드에 두 개의 피연산자와 연산자를 받을 수 있도록 필요한 속성을 추가해요.
- '/calc' 경로에서 POST 요청을 받는 HTTP 리소스 함수를 추가해요.
- 이 함수는 Calculation 레코드 타입을 페이로드로 받고, 일반 JSON 객체를 반환해야 해요.

### 입력

```json
{ "operand1": 4, "operand2": 10.2, "operator": "+" }
```

### 반환값

```json
{ "expression": "4+10.2", "result": 14.2 }
```
