# 지침 추가

복소수의 거듭제곱을 계산하려면 지수 함수와 사인 함수, 코사인 함수가 필요한데, WebAssembly에서는 이 중 어느 것도 사용할 수 없어요. 다행히 [테일러 급수](https://en.wikipedia.org/wiki/Taylor_series)를 사용하면 이 함수들을 계산할 수 있어요. 기대값과 맞추려면 적어도 `1/26!`의 정밀도가 필요해요.

## 지수 함수

```
exp(x) ≃ 1 + x + x ^ 2 / 2! + x ^ 3 / 3! + x ^ 4 / 4! + ... + x ^ n / n!
```

## 사인 함수

```
sin(x) ≃ x - x ^ 3 / 3! + x ^ 5 / 5! - x ^ 7 / 7! + ... - x ^ n / n!
```

## 코사인 함수

```
cos(x) ≃ 1 - x ^ 2 / 2! + x ^ 4 / 4! - x ^ 6 / 6! + ... - x ^ n / n!
```
