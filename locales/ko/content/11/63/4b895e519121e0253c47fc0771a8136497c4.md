# 지시 사항 추가

## 예외 메시지

때로는 [예외를 발생시키기](https://docs.python.org/3/tutorial/errors.html#raising-exceptions) 위해 `raise`를 사용해야 할 때가 있어요. 이렇게 할 때는 오류의 원인이 무엇인지 알려 주는 **의미 있는 오류 메시지**를 항상 포함해야 해요. 그래야 코드를 더 읽기 쉽게 만들고, 디버깅에도 큰 도움이 돼요. 오류의 원인이 특정 유형이라고 확실한 상황이라면 [내장 오류 유형](https://docs.python.org/3/library/exceptions.html#base-classes) 중 하나를 발생시켜도 되지만, 그래도 의미 있는 메시지는 포함해야 해요.

이 연습 문제에서는 점수 계산 규칙이나 경기 규칙을 따르지 않았을 때 [raise 문](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)으로 오류를 "던져야" 해요. 테스트는 `exception`을 `raise`하면서 그와 함께 메시지를 포함해야만 통과돼요.

`ValueError`를 메시지와 함께 발생시키려면, `exception` 유형에 인자로 메시지를 적어요:

```python
# example when a bonus is attempted with an open frame
raise IndexError("cannot throw bonus with an open tenth frame")

# example when fill balls are invalid
raise ValueError("invalid fill balls")
```
