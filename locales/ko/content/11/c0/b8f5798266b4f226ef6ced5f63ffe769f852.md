# 개요

## 배열 순회

`for`문을 사용하면 배열을 순회하면서 각 원소마다 코드를 반복할 수 있어요:

```haxe
var fruitList = ["apple", "banana", "pear"];

for (fruit in fruitList) {
  trace(fruit);
}

// apple
// banana
// pear
```

위 예제에서 `fruit`는 배열 `fruitList`의 개별 원소 값을 담는 변수예요. 컴파일러는 `fruitList`를 순회할 수 있는지 확인하고, 그렇지 않으면 실행을 중단해요.

## 범위 순회

범위 연산자를 사용하면 숫자를 순회할 수 있어요. 이 연산자는 두 개의 `Int` 피연산자를 받고 `min...max`처럼 써요. `min`은 포함되고 `max`는 제외돼요 (`min` <= i AND `max` > i).

```haxe
for (i in 0...10) {
  trace(i); // from 0 to 9
}
```

## 키-값 순회

키-값 쌍으로 이루어진 컬렉션을 순회할 수도 있어요. 문법에서 유일하게 다른 점은, 변수 하나 대신 키 변수 식별자를 쓰고 그 뒤에 `=>`, 다시 값 변수 식별자를 쓴다는 거예요:

```haxe
var map = [1 => 101, 2 => 202, 3 => 303];

for (k => v in map) {
  trace(key, value);
}

// 1, 101
// 2, 202
// 3, 303
```
