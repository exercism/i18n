# 지침

베링 해협을 통과하는 커터함의 당직 장교라고 해봐요. 세 곳의 정보원이
눈에 들어오는 모든 유빙과 곶의 위치를 알려주고 있어요:

- **해도 담당관**은 나침반 방위로 말해요. `north`, `east`, `south`,
  `west`예요. 방위만 알려주고 거리는 없어요.
- **항해사**는 커터함의 마지막 측위 지점을 기준으로 한 *극* 좌표로
  말해요. 해리 단위의 크기와, 북쪽에서 시계 방향으로 잰 도 단위의
  방위예요. (그래서 `0`은 북쪽, `90`은 동쪽, `180`은 남쪽, `270`은
  서쪽이에요.)
- **마스트 위 관측병**은 *상대* 좌표로 말해요. 앞쪽으로의 거리와,
  `ahead`, `starboard`, `behind`, `port` 가운데 하나예요. 상대 방위는
  *배의 현재 침로*를 기준으로 재요. 함장이 매 당직 전에 함교에서 그
  침로를 알려주거든요.

임무는 이 세 가지를 모두 하나의 공통된 데카르트 `(x, y)` 좌표계로
변환해 해도에 그릴 수 있게 하는 거예요. 방위는 도 단위고, `(0, 1)`은
북쪽으로 1해리, `(1, 0)`은 동쪽으로 1해리예요.

## 1. 데이터 모델, 그리고 기본 방위를 위한 데카르트 좌표

먼저 연습 문제 전체가 공유하는 요소들을 배치해요:

- 세 개의 튜플을 정의해요: `cardinal`(슬롯 하나, `direction`), `polar`
  (슬롯 `magnitude`와 `bearing`), `relative`(슬롯 `distance`와
  `bearing`).
- `SYMBOLS:`로 방향 기호를 선언해요: `north`, `east`, `south`, `west`,
  `ahead`, `starboard`, `behind`, `port`.
- `SYMBOL:`로 동적 변수 `heading`을 선언해요(3번 작업에서 사용해요).
- 두 개의 제네릭 워드를 선언해요:
  `GENERIC: >cartesian ( direction -- x y )`와
  `GENERIC: flip ( direction -- direction' )`. 두 워드의 메서드는
  이어지는 작업들에서 추가해요.

그다음 `>cartesian`의 `M: cardinal` 메서드를 추가해요. 이 메서드는
지정한 방향에 대한 단위 벡터를 반환해요.

```factor
T{ cardinal { direction north } } >cartesian . .
! => 1
! => 0
! (top of stack is `y`, just below it is `x`)
```

## 2. 극좌표를 위한 데카르트 좌표

`>cartesian`에 극좌표 형태를 `(x, y)`로 변환하는 `M: polar` 메서드를
추가해요:

```
x = magnitude * sin(bearing-in-radians)
y = magnitude * cos(bearing-in-radians)
```

```factor
T{ polar { magnitude 10 } { bearing 90 } } >cartesian . .
! => 0   (close to zero — the cosine of π/2 isn't exactly 0 in floats)
! => 10
```

## 3. 상대좌표를 위한 데카르트 좌표

`>cartesian`에 `M: relative` 메서드를 추가해요. 까다로운 점은, 상대
방위가 튜플의 일부가 아닌 배의 *현재 침로*를 기준으로 측정된다는
거예요. (1번 작업에서 선언한) `heading` 변수를 `heading get`으로 읽고,
방위 오프셋(`ahead = 0`, `starboard = 90`, `behind = 180`,
`port = 270`)을 더한 뒤 데카르트 좌표를 만들어요. 호출하는 쪽은
`with-variable` 블록 안에서 `heading`을 설정해요.

```factor
0 heading [
    T{ relative { distance 5 } { bearing starboard } } >cartesian
] with-variable . .
! => 0   (heading 0 is north; starboard is east; (5, 0))
! => 5
```

## 4. 뒤집기

(1번 작업에서 선언한) `flip` 제네릭의 메서드들을 추가해 반대 방향을
반환하게 해요.

- `cardinal`: north ↔ south, east ↔ west.
- `polar`: 방위에 180°를 더해요(모듈로 360).
- `relative`: ahead ↔ behind, starboard ↔ port.

```factor
T{ cardinal { direction north } } flip .
! => T{ cardinal { direction south } }

T{ polar { magnitude 10 } { bearing 90 } } flip .
! => T{ polar { magnitude 10 } { bearing 270 } }

T{ relative { distance 5 } { bearing ahead } } flip .
! => T{ relative { distance 5 } { bearing behind } }
```

## 5. 방위 더하기

두 방향을 모두 데카르트 좌표로 변환해 그 합을 반환하는
`add-bearings ( a b -- x y )`를 정의해요. `cardinal`, `polar`,
`relative`를 어떤 조합으로 섞어도 동작해요. 이게 바로 `>cartesian`에
제네릭을 사용한 덕이에요.

```factor
T{ cardinal { direction north } } T{ cardinal { direction east } } add-bearings . .
! => 1
! => 1
```
