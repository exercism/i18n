# 지시사항

회사의 개발자인 Andrew는 최근 데이터베이스 마이그레이션 도구에 쓸 가벼운 SQL 쿼리 생성 유틸리티를 만들었어요.
처음에 만든 단순한 구현은 작은 데이터 집합에서는 아주 잘 동작했어요.
그런데 대규모 프로덕션 마이그레이션을 진행하던 중, 애플리케이션이 메모리를 지나치게 많이 소모하기 시작했고 과부하 상황에서는 제대로 버티지 못했어요.
애플리케이션을 프로파일링한 뒤 Andrew는 루프 안에서의 평범한 문자열 연결 때문에 Go가 메모리를 계속 다시 할당하고 있었다는 사실을 알게 됐어요.
이제 이 유틸리티를 Go의 `strings.Builder`로 리팩터링해, 대용량 텍스트를 처리하면서도 메모리 힙을 무너뜨리지 않고 애플리케이션이 잘 확장되도록 만드는 일만 남았어요.

## 1. SELECT 쿼리 생성

`BuildSelectQuery` 함수를 구현해요.
이 함수는 테이블 이름(`string`)과 컬럼 이름 슬라이스(`[]string`)를 받아요.
세미콜론으로 끝나는 완전한 SQL `SELECT` 문을 반환해야 해요.
컬럼 슬라이스가 비어 있거나 `nil`이면, 모든 컬럼을 선택하는 `*` 와일드카드를 사용하도록 처리해요.

```go
columns := []string{"id", "name", "email"}
BuildSelectQuery("users", columns)
// Function return: "SELECT id, name, email FROM users;"

BuildSelectQuery("orders", nil)
// Function return: "SELECT * FROM orders;"
```

## 2. 배치 INSERT 문 생성

`BuildBatchInserts` 함수를 구현해요.
이 함수는 테이블 이름(`string`)과 데이터베이스의 행을 나타내는 2차원 슬라이스(`[][]ColumnValue`)를 받아요.
행의 각 원소는 특정 컬럼 이름과 그 문자열 값을 연결해요.
이 함수는 개별 `INSERT` SQL 문자열의 슬라이스를 반환해야 해요.
구조화된 슬라이스 형식 덕분에 쿼리 출력 순서를 예측 가능하고 안정적으로 보장할 수 있어요.
입력으로 받은 행 슬라이스가 비어 있으면 빈 문자열 슬라이스를 반환해요.
개별 행이 비어 있으면 그 행은 건너뛰어요.
`VALUES` 절 안의 문자열 값은 작은따옴표 `'`로 감싸야 해요.

```go
rows := [][]ColumnValue{
    {
        {Column: "title", Value: "Book"},
        {Column: "price", Value: "100"},
    },
    {
        {Column: "title", Value: "Magazine"},
        {Column: "price", Value: "15"},
    },
}

BuildBatchInserts("products", rows)
// Function returns string slice: [
//   "INSERT INTO products (title, price) VALUES ('Book', '100');",
//   "INSERT INTO products (title, price) VALUES ('Magazine', '15');"
// ]
```
