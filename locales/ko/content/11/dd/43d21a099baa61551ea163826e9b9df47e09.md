# 지시사항

프라하 블타바 강변에서 작은 기상 관측소를 운영하고 있어요. 근무할 때마다 온도 기록을 텍스트 로그에 적어 두죠. 한 줄에 기록 하나씩이요. 다섯 개의 작은 단어가 한 근무조 분량의 기록 정리를 모두 처리해 줘요.

각 단어에는 로그 파일의 경로가 전달돼요.

## 1. 모든 기록 읽기

`read-readings`는 로그의 모든 기록을 한 줄에 하나씩 담은 문자열 배열로 반환하도록 정의해요.

```factor
"weather.log" read-readings .
! => { "21.5" "19.0" "22.3" }
```

## 2. 가장 최근 기록 찾기

`latest-reading`은 가장 최근 기록, 즉 로그의 마지막 줄을 반환하도록 정의해요.

```factor
"weather.log" latest-reading .
! => "22.3"
```

## 3. 원본 로그 읽기

`log-text`는 로그 파일 전체를 저장된 그대로 하나의 문자열로 반환하도록 정의해요.

```factor
"weather.log" log-text .
! => "21.5\n19.0\n22.3\n"
```

## 4. 기록 남기기

`record-reading`은 새 기록을 로그 끝에 별도의 줄로 추가하고, 앞선 기록은 그대로 두도록 정의해요. 아무것도 반환하지 않아요.

```factor
"23.1" "weather.log" record-reading
"weather.log" log-text .
! => "21.5\n19.0\n22.3\n23.1\n"
```

## 5. 로그 다시 쓰기

`rewrite-log`는 로그 전체를 한 줄에 하나씩 담은 새 기록 배열로 교체하도록 정의해요.

```factor
{ "10.0" "11.0" } "weather.log" rewrite-log
"weather.log" log-text .
! => "10.0\n11.0\n"
```
