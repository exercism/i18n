# 개요

`TUPLE:`는 이름이 붙은 슬롯을 가진 클래스를 선언해요. Factor는 생성자 워드(클래스 이름 뒤에 `new`를 붙여요), `boa`("인자 순서대로") 생성자, 리터럴 문법 `T{ class … }`, 그리고 슬롯별 접근자 워드를 자동으로 만들어 줘요.

```factor
TUPLE: player
    { name initial: f }
    { level initial: 0 }
    { health initial: 100 } ;

player new .                                    ! T{ player }
3 100 "Merlin" player boa .                     ! by-order construction
T{ player { name "Merlin" } { health 50 } } .   ! literal syntax
```

[`accessors`][accessors]의 접근자 시스템은 슬롯마다 네 가지 방식을 제공해요. `name>>`, `>>name`, `change-name`, 그리고 값을 함께 바꾸는 짝인 `[ … ] change-name`이에요. `>>name`과 `change-name`은 튜플을 변경하니, 원본을 그대로 두고 싶다면 먼저 `clone`을 해요.

튜플은 구조적 동등성으로 `=`를 지원하고, 기본값이 아닌 슬롯 값을 함께 보여 주면서 출력해요.

[accessors]: https://docs.factorcode.org/content/vocab-accessors.html
