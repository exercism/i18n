# 지침

완성된 지뢰찾기 보드에 지뢰 개수를 채워 넣어요.

지뢰찾기는 숫자 힌트를 이용해 지뢰를 찾아야 하는 인기 게임이에요. 숫자 힌트는 어떤 칸에 가로, 세로, 대각선으로 바로 맞닿은 지뢰가 몇 개인지 알려줘요.

이 연습 문제에서는 주어진 빈칸에 인접한 지뢰의 개수를 세고, 그 칸을 개수로 바꾸는 코드를 작성해요.

보드는 공백(' ') 문자로 이루어진 직사각형이에요. 지뢰는 별표('\*') 문자로 나타내요.

어떤 칸에 인접한 지뢰가 하나도 없다면, 그 칸은 빈칸으로 남겨 둬요.

## 예시

예를 들어 다음과 같은 5 x 4 보드를 받을 수 있어요. (여기서는 화면에 표시하기 위해 빈칸을 '·' 문자로 나타냈어요.)

```
·*·*·
··*··
··*··
·····
```

그러면 코드가 다음과 같이 바꿔 줘요:

```
1*3*1
13*31
·2*2·
·111·
```
