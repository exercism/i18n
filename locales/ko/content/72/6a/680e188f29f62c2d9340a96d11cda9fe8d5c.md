# 테스트 실행하기

연습 문제의 테스트를 실행하려면, 연습 문제 디렉터리에서 `<exercise>.test` 스크립트를 실행해요:

```bash
tclsh <exercise>.test
```

대부분의 연습 문제에서는 첫 번째 테스트를 제외한 나머지 테스트가 모두 "skipped" 상태가 돼요.
이 덕분에 개발자는 각 테스트를 하나씩 통과하는 데 필요한 만큼만 코드를 작성하는 테스트 주도 개발을 해볼 수 있어요.
skip 명령을 무시하려면, 테스트 모음을 실행하기 전에 `RUN_ALL` 환경 변수를 유효한 Tcl true 값 \[1\]으로 설정해요:

```bash
RUN_ALL=yes tclsh <exercise>.test
```

\[1\]: Tcl의 true/false 값은 C 라이브러리 함수 [Tcl_GetBoolean][bool]의 매뉴얼 페이지에 설명되어 있어요.

[bool]: https://www.tcl-lang.org/man/tcl8.6/TclLib/GetInt.htm
