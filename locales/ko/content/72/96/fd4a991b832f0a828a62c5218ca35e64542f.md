# 개요

## 비교 연산자

[비교 연산자][comparison-operators]는 같은 타입의 두 값을 비교하고 `Bool` 값(`true` 또는 `false`)을 반환해요.
타입이 다른 값을 비교하려고 하면 컴파일러가 오류를 발생시켜요.

Swift의 표준 비교 연산자는 다음과 같아요:

| 연산자 | 설명              | 예시         |
| -------- | ------------------------ | --------------- |
| `==`     | 같음                 | `1 == 1` (true) |
| `!=`     | 같지 않음                 | `1 != 2` (true) |
| `<`      | 작음                | `4 < 5`  (true) |
| `<=`     | 작거나 같음    | `4 <= 4` (true) |
| `>`      | 큼               | `3 > 1`  (true) |
| `>=`     | 크거나 같음 | `2 >= 2` (true) |

## `if`와 `else` 문

[조건문][conditional-statement]은 조건이 `true`로 평가되는지 `false`로 평가되는지에 따라 코드를 실행해요.
가장 흔한 조건문은 [`if`문][if]으로, 조건이 `true`일 때만 코드 블록을 실행해요.
`if`문은 `if` 키워드 뒤에 조건을 쓰고, 중괄호로 감싼 코드 블록을 이어서 작성해요:

```swift
let wheelCount = 4
if wheelCount == 4 {
    print("Your vehicle is a car")
}
// Prints "Your vehicle is a car"
```

`if`에 `else` 절을 붙이면 조건이 `false`일 때 다른 코드를 실행할 수 있어요:

```swift
let precipitationInMM = 0.5
if precipitationInMM > 0.5 {
    print("You will need an umbrella")
} else {
    print("You will not need an umbrella")
}
// Prints "You will not need an umbrella"
```

여러 조건을 차례대로 검사하려면 `else if`로 문을 이어 붙여요.
`if`문에는 `else` 분기가 꼭 필요하지는 않지만, 어떤 조건에도 해당하지 않는 경우를 처리하려면 넣을 수 있어요:

```swift
let favoriteFruit = "Apple"

if favoriteFruit == "Banana" {
    print("Your favorite fruit is a banana")
} else if favoriteFruit == "Orange" {
    print("Your favorite fruit is an orange")
} else if favoriteFruit == "Apple" {
    print("Your favorite fruit is an apple")
} else {
    print("Your favorite fruit is not a banana, orange, or apple")
}
// Prints "Your favorite fruit is an apple"
```

## `if` 표현식

최신 Swift에서는 `if`문을 값을 만들어 내는 표현식으로도 사용할 수 있어요.
각 분기가 값을 가지므로, 조건에 따라 결과를 손쉽게 대입할 수 있어요:

```swift
let cpuBits = 32
let architecture = if cpuBits == 64 {
    "x86_64"
} else {
    "x86_32"
}

print(architecture)
// Prints "x86_32"
```
