# 지침

이 연습 문제에서는 저축 계좌를 다뤄요.
매년 저축 계좌의 잔액은 이자율에 따라 갱신돼요.
은행이 제공하는 이자율은 계좌에 있는 금액, 즉 잔액에 따라 달라져요:

- 잔액이 `0`달러 미만이면 3.213%예요 (잔액이 더 음수가 돼요).
- 잔액이 `0`달러 이상 `1000`달러 미만이면 0.5%예요.
- 잔액이 `1000`달러 이상 `5000`달러 미만이면 1.621%예요.
- 잔액이 `5000`달러 이상이면 2.475%예요.

해야 할 과제는 네 개예요. 각 과제에서는 잔액과 이자율을 다뤄요.

## 1. 이자율 계산하기

주어진 잔액에 대한 이자율을 계산하는 `InterestRate()` 함수를 구현해요:

```go
InterestRate(200.75)
// => 0.5
```

반환되는 값은 `float32` 타입이에요.

## 2. 이자 계산하기

주어진 잔액에 대한 이자를 계산하는 `Interest()` 함수를 구현해요:

```go
Interest(200.75)
// => 1.003750
```

반환되는 값은 `float64` 타입이에요.

## 3. 연간 잔액 업데이트 계산하기

이자율을 고려해서 연간 잔액 업데이트를 계산하는 `AnnualBalanceUpdate()` 함수를 구현해요:

```go
AnnualBalanceUpdate(200.75)
// => 201.75375
```

반환되는 값은 `float64` 타입이에요.

## 4. 원하는 잔액에 도달하기까지 걸리는 연수 계산하기

매년 이자가 잔액에 더해진다는 점을 고려해서, 원하는 잔액에 도달하는 데 필요한 최소 연수를 계산하는 `YearsBeforeDesiredBalance()` 함수를 구현해요.
즉, 1년 후 잔액은 시작 잔액 + 시작 잔액에 대한 이자예요.
2년 후 잔액은 1년 후 잔액 + 1년 후 잔액에 대한 이자예요.
이런 식으로, 해당 연도의 잔액이 목표 잔액 이상이 될 때까지 반복해요.

```go
balance := 200.75
targetBalance := 214.88
YearsBeforeDesiredBalance(balance, targetBalance)
// => 14
```

반환되는 값은 `int` 타입이에요.
