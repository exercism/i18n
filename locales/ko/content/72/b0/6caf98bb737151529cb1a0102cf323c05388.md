# 테스트

CLI로 연습 문제의 테스트를 실행하려면, 연습 문제 디렉터리에서 다음 명령어를 실행해요:

```bash
clojure -M:test
```

## REPL

REPL로 연습 문제의 테스트를 실행하려면, 연습 문제 디렉터리에서 다음 명령어를 실행해요:

```bash
$ clojure -m cljs.main -re node
```

그다음 연습 문제의 테스트 네임스페이스와 Clojure 테스트 네임스페이스를 `require`해요:

```clojure
;; replace <exercise> with the exercise's name
=> (require '<exercise>-test)
nil
;; and the test namespace
=> (require 'cljs.test)
```

ns를 테스트 네임스페이스로 바꿔요:

```clojure
;; replace <exercise> with the exercise's name
=> (ns <exercise>-test)
nil
```

그다음 `run-tests`를 호출해요:

```clojure
=> (cljs.test/run-tests)
```
