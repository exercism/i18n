# 지침

해변 산책로의 오락실에서 운에 따라 승부가 갈리는 게임들을 운영해요. 손님들은 주사위를 굴리고, 인형 뽑기 기계는 상품을 집어 올리고, 카드 테이블에서는 카드를 섞어서 패를 돌려야 해요. 이 모든 게 무작위성 덕분에 돌아가죠. 영업이 끝난 뒤에는 "리플레이" 기능도 필요해요. 시비가 붙은 게임을 같은 시드로 다시 돌려볼 수 있어야 하거든요.

## 1. 주사위를 굴려요

`roll-die`는 면의 수를 받아서 `1`부터 `sides`까지(양 끝 포함)의 값을 반환하도록 정의해요.

```factor
6 roll-die .
! => 4   (some value from 1..6)
```

## 2. 상품을 뽑아요

`pick-prize`는 상품들의 시퀀스를 받아서 그중 하나를 무작위로 반환하도록 정의해요.

```factor
{ "teddy" "goldfish" "keyring" } pick-prize .
! => "goldfish"
```

## 3. 카드를 섞어요

`shuffle-deck`는 덱(시퀀스)을 받아서 카드를 무작위 순서로 재배열한 덱을 반환하도록 정의해요.

```factor
{ 1 2 3 4 5 } shuffle-deck .
! => { 3 1 5 2 4 }
```

## 4. 패를 나눠 줘요

`deal-hand`는 덱과 개수 `n`을 받아서 덱에서 서로 *다른* 카드 `n`장을 반환하도록 정의해요.

```factor
{ 10 20 30 40 50 } 3 deal-hand .
! => { 40 10 30 }
```

## 5. 시드로 다시 실행해요

`play-seeded`는 시드와 쿼테이션을 받아서, 그 정수로 시드를 설정한 생성기로 쿼테이션을 실행하도록 정의해요. 그래야 같은 시드가 항상 같은 결과를 만들어 내거든요. 쿼테이션의 결과는 호출한 쪽으로 반환돼야 해요.

```factor
42 [ 6 roll-die ] play-seeded .
! => the same value every time for seed 42

! Same seed, same game:
99 [ 5 deal-hand ] play-seeded   99 [ 5 deal-hand ] play-seeded   =  .
! => t
```
