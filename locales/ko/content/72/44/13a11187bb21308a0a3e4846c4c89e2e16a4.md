# 소개

Python에서 `None`은 값이 없음을 나타낼 때 자주 사용돼요. `null`(비어 있는) 변수나 객체, 인자를 정의할 때 쓰는 자리 표시자 역할을 하죠.

다른 프로그래밍 언어에서 `NULL`이나 `nil` 타입을 들어봤거나 사용해 봤다면, Python에서의 이 `None` 사용법도 익숙하게 느껴질 거예요. `None`은 아직 값이 없는 변수나 함수 인자를 선언할 때 도움이 돼요. 이런 변수나 인자는 나중에 필요할 때 특정 값으로 다시 할당할 수 있어요.

```python
a = None
print(a)
#=> None
type(a)
#=> <class 'NoneType'>

# Adding a Default Argument with `None`
def add_to_todos(new_task, todo_list=None):
  if todo_list is None:
    todo_list = []
    todo_list.append(new_task)
  return todo_list

```

`None`은 조건식에서 사용하면 `False`로 평가돼요. 그래서 값, 어떤 값이든 그 값의 "존재"나 "부재"를 검사할 때 유용하죠. 이 패턴은 함수나 프로세스가 오류 객체나 메시지를 반환할 수 있을 때 자주 사용돼요.

```python
a = None
if a: #=> a will be evaluated to False when its used in a conditional check.
    print("This will not be printed")
```
