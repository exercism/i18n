# 지침

이 연습 문제에서는 차량 구매를 준비하는 데 도움이 될 코드를 작성해요.

세 가지 과제가 있어요. 하나는 두 차량 중에서 고르는 데 도움이 될지 판단하는 것, 하나는 어떤 운전면허가 필요한지 알아내는 것, 그리고 하나는 중고 차량의 적정 가격을 추정하는 것이에요.

## 1. 주어진 차량의 월 납부금을 감당할 수 있는지 계산하기

동네 자동차 딜러들이 모두 5년 0% 무이자 프로모션을 진행하고 있어서, 이 혜택을 이용하고 싶어요.
하지만 원하는 차의 월 납부금을 감당할 수 있을지 확신이 서지 않아요.

월 납부금은 차량의 총가격을 5년 동안의 개월 수로 나눈 값이에요.

다음 인자를 받는 `canIBuy(vehicle:price:monthlyBudget:)` 함수를 구현해요:
- `vehicle` - 사고 싶은 차량의 이름이에요.
- `price` - 사고 싶은 차량의 가격이에요.
- `monthlyBudget` - 매달 지불할 수 있는 금액이에요.

함수는 다음 조건에 따라 아래 메시지를 반환해야 해요:
- 차량의 월 납부금이 월 예산보다 작거나 같으면, `"Yes! I'm getting a <vehicle>"` 메시지를 반환해요.
- 차량의 월 납부금이 월 예산을 최대 10%까지(포함) 초과하면, `"I'll have to be frugal if I want a <vehicle>"` 메시지를 반환해요.
- 차량의 월 납부금이 월 예산을 10% 넘게 초과하면, `"Darn! No <vehicle> for me"` 메시지를 반환해요.

```swift
canIBuy(vehicle: "1974 Ford Pinto", price: 516.32, monthlyBudget: 100.00)
// returns "Yes! I'm getting a 1974 Ford Pinto"
canIBuy(vehicle: "2011 Bugatti Veyron", price: 2_250_880.00, monthlyBudget: 10000.00)
// returns "Darn! No 2011 Bugatti Veyron for me"
canIBuy(vehicle: "2020 Indian FTR 1200", price: 12_500, monthlyBudget: 200)
// returns "I'll have to be frugal if I want a 2020 Indian FTR 1200"
```

## 2. 필요한 운전면허 종류 알아내기

중고 차량을 사기로 했고, 그 차를 운전하려면 어떤 종류의 운전면허가 필요한지 알아내야 해요.

사고 싶은 차량의 바퀴 수를 담은 `numberOfWheels` 인자를 받는 `licenseType(numberOfWheels:)` 함수를 구현해요.

함수는 다음 조건에 따라 아래 메시지를 반환해야 해요:
- 바퀴 수가 2 또는 3이면, `"You will need a motorcycle license for your vehicle"` 메시지를 반환해요.
- 바퀴 수가 4 또는 6이면, `"You will need an automobile license for your vehicle"` 메시지를 반환해요.
- 바퀴 수가 18이면, `"You will need a commercial trucking license for your vehicle"` 메시지를 반환해요.
- 그 밖의 다른 수라면, `"We do not issue licenses for those types of vehicles"` 메시지를 반환해요.

```swift
licenseType(numberOfWheels: 2)
// returns "You will need a motorcycle license for your vehicle"
licenseType(numberOfWheels: 6)
// returns "You will need an automobile license for your vehicle"
licenseType(numberOfWheels: 18)
// returns "You will need a commercial trucking license for your vehicle"
licenseType(numberOfWheels: 0)
// returns "We do not issue licenses for those types of vehicles"
```

## 3. 중고 차량 가격 추정하기

이제 결정을 내렸으니, 딜러십에서 적정한 가격에 사고 싶어요.
중고 차량을 사려고 하니, 가격은 차량의 연식에 따라 달라져요.
대략적으로 추정해 보면, 차량이 3년 미만이면 새 차였을 때의 원래 가격의 80%라고 가정해요.
10년 이상이면 50%예요.
차량이 3년 이상이면서 10년 이하이면 원래 가격의 70%예요.

`originalPrice`와 `yearsOld` 인자를 받는 `calculateResellPrice(originalPrice:yearsOld:)` 함수를 구현해요. `originalPrice`는 차량의 원래 가격을 담고, `yearsOld`는 차량의 연식을 나타내요.
함수는 차량의 재판매 가격을 반환해야 해요.

```swift
calculateResellPrice(originalPrice: 1000, yearsOld: 1)
// returns 800
calculateResellPrice(originalPrice: 1000, yearsOld: 5)
// returns 700
calculateResellPrice(originalPrice: 1000, yearsOld: 15)
// returns 500
```
