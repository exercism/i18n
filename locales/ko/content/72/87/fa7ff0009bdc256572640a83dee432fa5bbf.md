# 소개

## 꼬리 호출 재귀

리스트, 비트스트링, 문자열처럼 열거 가능한 값들을 [재귀][exercism-recursion]로 순회할 때는 흔히 두 가지가 걱정돼요.

- 재귀 함수 호출의 흔적을 담아 두는 데 메모리가 얼마나 필요한지
- 해답을 효율적으로 만들어 내는 방법

이런 걱정거리를 해결하기 위해 _누산기_를 사용할 수 있어요.

누산기는 데이터와 함께 덧붙여 전달되는 변수예요. 함수 실행의 현재 상태를 호출이 이어질 때마다 다음 호출로 넘겨주는 데 쓰이고, 기저 사례에 도달하면 그 누산기로 재귀 호출의 최종 값을 반환해요.

누산기는 함수를 사용하는 사람이 아니라 함수를 작성하는 사람이 초기화해야 해요. 그러려면 함수를 두 개 선언해요. 필요한 데이터만 인자로 받아서 누산기를 초기화하는 공개 함수 하나와, 누산기도 함께 받는 비공개 함수 하나예요. Elixir에서는 비공개 함수 이름 앞에 `do_`를 붙이는 것이 흔한 패턴이에요.

```elixir
# Count the length of a list without an accumulator
def count([]), do: 0
def count([_head | tail]), do: 1 + count(tail)

# Count the length of a list with an accumulator
def count(list), do: do_count(list, 0)

defp do_count([], count), do: count
defp do_count([_head | tail], count), do: do_count(tail, count + 1)
```

누산기를 사용하면 재귀 함수를 _꼬리 재귀_ 함수로 바꿀 수 있어요. 함수에서 _마지막_으로 실행되는 것이 자기 자신을 호출하는 것이라면, 그 함수는 꼬리 재귀 함수예요.
