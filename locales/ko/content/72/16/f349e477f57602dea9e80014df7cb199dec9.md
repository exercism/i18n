# 설치

## 설치 옵션

최신 Unison 릴리스는 Mac OS X, 64비트 Linux, Windows 사용자라면 누구나 사용할 수 있어요! Unison을 사용해 보고 있다면 Exercism 포럼이나 [Unison Discord](https://unison-lang.org/discord)에서 우리와 이야기를 나눠 봐요. 궁금한 점을 물어보고, 겪는 문제도 알려주세요! 시작할 때 따뜻하고 긍정적인 경험을 하기를 바라요! 😊

Unison은 [homebrew](https://brew.sh/), [Nix](https://github.com/ceedubs/unison-nix/#usage), 또는 패키지 바이너리로 직접 내려받을 수 있어요. 이런 모든 다운로드 방법은 [웹사이트의 설치 안내 페이지](https://www.unison-lang.org/learn/quickstart/#installation-options)에 설명돼 있어요. UCM을 설치했다면 다시 여기로 돌아와요!

### 옵션 1: Homebrew 사용하기

아직 [homebrew를 설치](https://brew.sh/)하지 않았다면 먼저 설치해요.

그런 다음 명령줄에서 다음 명령어를 입력해요:

```
brew tap unisonweb/unison
brew install unison-language
```

이렇게 하면 Unison 코드베이스 관리자 실행 파일인 `ucm`이 설치돼요. 이전 버전에서 업그레이드하는 경우에는 다음만 실행하면 돼요.

```
brew upgrade unison-language.
```

참고: 이때 GitHub 사용자 이름과 비밀번호를 입력하라는 메시지가 나오면 unisonweb/unison을 올바르게 입력했는지 확인해요.

### 옵션 2: Mac과 Linux 사용자를 위한 수동 설치

[Linux와 Mac 수동 설치 링크는 여기](https://www.unison-lang.org/learn/quickstart/#installation-options)에 각각의 Linux 및 Mac 수동 다운로드 섹션 아래에 있어요.

셸에서 다음과 비슷한 명령어를 실행하게 되지만, 가장 최신 바이너리는 위 링크에 있어요:

```
mkdir unisonlanguage
curl -L https://github.com/unisonweb/unison/releases/download/release_VERSION_NAME/ucm-YOUR_PLATFORM.tar.gz --output unisonlanguage/ucm.tar.gz
tar -xzf unisonlanguage/ucm.tar.gz -C unisonlanguage
./unisonlanguage/ucm
```

### 옵션 3: Windows 사용자를 위한 수동 설치

1. 최상의 결과를 위해 기본 터미널 애플리케이션을 "Windows Terminal"로 설정해요. 설정에서 "Terminal"을 검색하거나 [이 안내](https://bit.ly/3IXwdlY)를 따라가요.
2. Git이 이미 설치되어 있는지 확실하지 않다면 Git을 설치해요:
  * winget 사용: `winget install --id Git.Git -e --source winget`
  * Windows 10을 사용 중이고 winget이 없다면 [Microsoft Store](https://www.microsoft.com/en-us/p/app-installer/9nblggh4nns1)에서 설치한 다음 위 명령어를 실행해요.
3. [여기 제공된 링크로 UCM을 다운로드](https://www.unison-lang.org/learn/quickstart/#installation-options)하고 원하는 위치에 압축을 풀어요.
4. `ucm.exe`를 실행해요

## Unison 코드베이스 만들기

`ucm`을 실행해 `$HOME/.unison`에 Unison 코드베이스를 초기화해요. 여기에 Unison이 함수 정의, 타입, 네임스페이스 등을 저장해요. 기본적으로 Unison 코드베이스 관리자("UCM"으로 줄여요)가 `base`라고 하는 표준 라이브러리를 내려받기 시작하는데, 이 라이브러리로 Unison 코드를 작성하게 돼요. 시간이 조금 걸릴 수 있어요! 🕰

## Unison 워크플로

Unison 코드를 작성하고 싶을 때 `ucm` 명령어를 실행해 코드베이스 관리자를 시작해요. 그러면 UCM이 실행된 디렉터리에서 `.u` 확장자를 가진 모든 파일의 변경 사항을 지켜봐요. 예를 들어 `~/exercism/unison/my-exercise/`라는 디렉터리에 있는 `scratch.u`라는 파일에서 함수를 구현하고 있을 수 있어요. 이때 `~/exercism/unison/my-exercise/`로 `cd`한 다음 `ucm`을 실행해야 해요. 그래야 UCM이 `scratch.u` 파일의 변경 사항을 지켜봐요.

`ucm`이 어느 디렉터리에서 파일 변경을 지켜보고 있는지 헷갈린다면, CLI를 시작할 때 나오는 환영 화면에 표시돼요.

```
👀 I'm watching for changes to .u files under /Users/myUser/exercism/unison/my-exercise
```

[더 많은 워크플로 팁은 여기에서 확인해요!](https://exercism.org/docs/tracks/unison/workflow)

## 에디터 지원

`.u` 파일은 아무 텍스트 에디터로나 작성할 수 있어요. Unison은 [LSP를 지원](https://github.com/unisonweb/unison/blob/trunk/docs/language-server.markdown)하므로, 자주 쓰는 IDE에서 마우스를 올리면 타입을 보여주거나 자동 완성 같은 도움을 받을 수 있어요. Unison을 지원하는 인기 에디터 몇 가지를 아래에 소개해요:

### Vim

[vim-plug](https://github.com/junegunn/vim-plug) 사용하기:

1. 아직 [`vim-plug`](https://github.com/junegunn/vim-plug)를 설치하지 않았다면 설치해요.
2. .vimrc에 다음을 추가해요: `Plug 'unisonweb/unison', { 'branch': 'trunk', 'rtp': 'editor-support/vim' }`
3. vim 명령어 `:PlugInstall`을 실행해요.

더 자세한 내용은 vim 안에서 `:help unison`을 실행하거나 [온라인 도움말 문서](https://github.com/unisonweb/unison/blob/trunk/editor-support/vim/doc/unison.txt)를 봐요.

### Atom
콘솔에서 다음을 실행해요:

```
apm install unisonweb/atom-unison
```

### VS Code

1. VS Code 옆면의 활동 표시줄에 있는 확장 아이콘을 클릭하거나 ⇧⌘X를 눌러 확장 보기를 열어요.
2. "unison"을 검색해요
3. [Unison VS Code 확장](https://marketplace.visualstudio.com/items?itemName=unison-lang.unison)을 설치해요

### Emacs
[`unison-mode`](https://github.com/dariooddenino/unison-mode-emacs)를 설치해요.
