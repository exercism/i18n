# 지침 추가

## 힌트

이 연습 문제를 완료하려면 `anagramsFor` 함수를 구현해야 해요. 이 함수는 *단어* 하나와 *단어*들의 묶음을 받아서, 주어진 *단어*의 애너그램인 것들을 반환해요.

애너그램은 후보 단어들에 나열된 순서 그대로 반환해야 해요.


이 연습 문제를 처음 푼다면, 제공된 시그니처를 그대로 사용하는 걸 추천해요:

```haskell
anagramsFor :: String -> [String] -> [String]
```

나중에 이 문제를 다시 풀어보면서 다른 데이터 타입과 라이브러리도 다뤄보면 좋아요:

- *text* 패키지의 `Text`
- *containers* 패키지의 `Sequence`와 `Set`
- *multiset* 패키지의 `MultiSet`

테스트 스위트는 의미가 통하는 거의 모든 타입 시그니처를 허용하도록 의도적으로 설계되었으니, 가장 좋다고 생각하는 시그니처를 찾아보길 권해요.
