# Swift 설치하기

Swift는 macOS, Linux, Windows에서 사용할 수 있어요.
설치 방법은 사용하는 운영 체제에 따라 달라요.
Linux 지원과 관련해 중요한 점은, Swift가 (공식적으로) 다음 배포판에서만 지원된다는 거예요:
- Ubuntu
- Debian
- RedHat
- Fedora
- Amazon Linux

다른 Linux 배포판을 사용하고 있다면, Swift를 직접 설치할 방법을 찾아야 해요.

## Xcode (macOS)

Swift는 Apple의 macOS 및 iOS 개발용 IDE인 Xcode에 포함되어 있어요.
Exercism 트랙에서는 Xcode 16.0 이상이 설치되어 있어야 해요.
Xcode는 [Mac App Store][xcode]에서 무료로 받을 수 있어요.
추가 버전의 Xcode(최신 베타 포함)는 [Apple 개발자 센터][apple-developer-center]에서 받을 수 있어요.

## macOS와 Linux

macOS와 Linux에서는 [swiftly][swiftly]라는 Swift 설치 관리자를 사용할 수 있어요.
시스템에 여러 버전의 Swift를 설치하고 관리할 수 있게 해 주는 명령줄 도구예요.
macOS에서 swiftly를 설치하는 명령은 [여기][swiftly-macos]에서, Linux는 [여기][swiftly-linux]에서 확인할 수 있어요.

macOS의 또 다른 설치 방법으로는 [Homebrew][homebrew]가 있어요.
Linux에서는 공식 [Swift 웹사이트][tarball]의 tarball을 사용해 설치할 수 있어요.

## Windows

Windows에서 Swift를 설치하는 권장 방법은 [WinGet 설치 프로그램][winget-windows]을 사용하는 거예요.
Scoop 패키지 관리자를 사용하거나 직접 수동으로 설치하는 것도 가능해요.
모든 방법은 [Windows용 Swift 설치][swift-windows] 페이지를 참고해요.
