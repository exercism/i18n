# 지침 추가

## 참고 사항

이 연습 문제를 푸는 데 Pharo의 딕셔너리가 도움이 될 거예요.
Pharo에서는 딕셔너리를 만드는 방법이 여러 가지 있는데, `Dictionary new: at:put:`도 있고 `Association`을 사용하는 리터럴 문법도 있어요.
`Association`은 `key -> value`처럼 생겼고, 다음과 같이 딕셔너리로 바꿀 수 있어요: `{ 'key' -> 'value' } asDictionary`.
Smalltalk에서는 모든 중위 연산자가 오른쪽 결합이라는 점, 그리고 위에서 언급한 클래스는 실제로 실행 중인 환경에서 직접 열어볼 수 있다는 점을 기억해 두세요.
