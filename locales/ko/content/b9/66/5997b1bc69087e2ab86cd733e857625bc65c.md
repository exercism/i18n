# 테스트

## 설정

WebAssembly [설정 안내][docs-exercism-wasm]를 따라가면서 필요한 의존성을 설치해요.

## 요구 사항

연습 문제에 필요한 의존성을 설치해요:

```shell
# Using npm
npm install

# Alternatively using yarn
yarn
```

## 테스트 스위트 통과시키기

모든 연습 문제에는 제출하기 전에 풀이를 검증할 수 있도록 테스트 스위트가 함께 제공돼요.
연습 문제 디렉터리에서 명령 프롬프트를 열고 다음을 실행하면 이 테스트들을 실행할 수 있어요:

```bash
# Using npm
npm test

# Alternatively using yarn
yarn test
```

일부 테스트 스위트에서는 첫 번째 테스트를 제외한 모든 테스트가 건너뛰도록 설정되어 있어요.

테스트 하나를 통과시키면 `xtest`를 `test`로 바꿔서 다음 테스트를 활성화할 수 있어요.

## 직접 테스트 작성하기

추가로 직접 테스트를 작성하고 싶다면 새 파일 `custom.spec.js`를 만들고, 그 파일을 풀이와 함께 제출해요:

```shell
exercism submit numbers.wat custom.spec.js
```
