# 소개

Factor는 [`io`][io] 스트림을 통해 읽고 써요. 대부분의 코드는 *주변* 입출력을 다뤄요. `read`, `readln`, `print`, `write` 같은 단어들은 현재 바인딩된 스트림에서 동작하고, 소수의 `with-…` 콤비네이터는 quotation이 실행되는 동안 그 주변 스트림을 바꿔 끼워요.

```factor
USING: io io.streams.string ;

"hello\nworld" <string-reader> [ readln . readln . ] with-input-stream
! prints "hello"
! prints "world"

[ "captured" print ] with-string-writer .
! prints (returns) "captured\n"
```

`<string-reader>`와 `<string-writer>`는 이 연습 문제에서 사용하는 메모리 내 스트림이에요. `<file-reader>`와 `<file-writer>`는 디스크를 대상으로 하는 대응 스트림이고, 인터페이스는 같아요. 범위를 한정한 파일 접근이 필요할 때는 `with-file-reader` / `with-file-writer`와 짝지어 사용해요.

[io]: https://docs.factorcode.org/content/vocab-io.html
