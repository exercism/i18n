# 개요

불리언 값은 어떤 조건이 `true`인지 `false`인지를 나타내요.
Go에서 `bool` 타입은 이 두 값 중 하나만 될 수 있어요.

```go
isDoorLocked := true
hasKey := true
knowsCode := false
```

## 논리 연산자

논리 연산자는 하나 또는 두 개의 불리언 값을 다루고, 불리언 결과를 만들어요.

| 연산자 | 이름 | 동작                                          |
| ------ | ---- | --------------------------------------------- |
| `!`    | NOT  | 불리언 값 하나의 반대를 반환해요              |
| `&&`   | AND  | 양쪽이 모두 `true`일 때만 `true`를 반환해요   |
| `\|\|` | OR   | 어느 한쪽이라도 `true`이면 `true`를 반환해요  |

불리언 값의 반대가 필요할 때는 `!`(NOT)를 사용해요:

```go
!isDoorLocked // false
```

두 조건이 모두 `true`여야 할 때는 `&&`(AND)를 사용해요:

```go
canUnlockDoor := isDoorLocked && hasKey // true
```

적어도 한쪽 조건이 `true`여야 할 때는 `||`(OR)를 사용해요:

```go
canOpenDoor := canUnlockDoor || knowsCode // true
```

논리 연산자는 이 순서대로 평가돼요: 먼저 `!`, 그다음 `&&`, 마지막으로 `||`.
괄호로 코드를 묶으면 어떤 연산이 먼저 일어날지 정할 수 있어요:

```go
!true && false   // false because !true is evaluated first
!(true && false) // true because true && false is evaluated first
```
