# 소개

Common Lisp에서는 대부분의 연산에 표준 산술 연산자를 사용하지만, 익숙한 "중위 표기법"과 달리 "전위 표기법"을 사용한다는 점이 조금 독특해요.

더 시각적으로 보면:

```lisp
;; Infix-notation (non-lisp languages)
1 + 2 + 3 + 4 + 5 ; => 15
;; Prefix-notation (lisp languages)
(+ 1 2 3 4 5)     ; => 15
```

전위 표기법은 `2 + 2` 같은 연산을 다소 낯선 `(+ 2 2)` 형태로 바꾸지만, 한 번에 여러 숫자를 다루기는 훨씬 쉬워요.

## 기본 산술

Common Lisp에는 덧셈, 뺄셈, 곱셈, 나눗셈을 위한 `+`, `-`, `*`, `/` 같은 일반적인 함수가 모두 있어요.

나눗셈을 하다 보면 나머지를 알고 싶을 때가 있는데, 이럴 때는 `mod`(modulo) 함수를 사용해요. 이 함수는 숫자와 나누는 수를 인자로 받아요:

```lisp
(mod 4 2)  ; => 0
(mod 2 4)  ; => 2
(mod 10 3) ; => 1
```

## 숫자 비교

마지막으로, `=`(같음), `/=`(같지 않음), `>=`(크거나 같음) 같은 함수로 서로 다른 숫자를 비교하면 유용할 때가 있어요.
이런 비교가 참이면(예: `(= 1 1)`) `T`를 반환하고, 거짓이면(예: `(> 0 1)`) `NIL`을 반환해요.
