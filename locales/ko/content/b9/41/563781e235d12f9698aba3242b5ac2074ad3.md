# 테스트

## 테스트 실행하기

연습 문제가 있는 디렉터리에 들어가면 두 개의 하위 디렉터리가 보일 거예요:

* `src`에는 연습 문제에 대한 풀이가 들어 있어요
* `spec`에는 연습 문제를 위해 실행할 테스트가 들어 있어요

올바른 디렉터리, 그러니까 `src`와 `spec`이 들어 있는 디렉터리에 있다면 `crystal spec`을 실행해서 해당 연습 문제의 테스트를 돌릴 수 있어요:

```bash
$ pwd
/Users/johndoe/Code/exercism/crystal/hello-world

$ ls
GETTING_STARTED.md README.md          spec               src

$ crystal spec
```

이 명령은 `spec` 디렉터리에 있는 모든 테스트 파일을 실행해요.

각 테스트 파일에서는 첫 번째 테스트를 빼고 나머지가 모두 건너뛰기 처리되어 있어요.

테스트 하나를 통과시키고 나면, `pending`을 `it`으로 바꿔서 다음 테스트의 건너뛰기를 풀 수 있어요.

## Crystal 포맷

풀이를 제출하기 전에 `crystal tool format`을 실행하는 걸 권장해요.

현재 디렉터리에 있는 모든 파일을 포맷하려면 이렇게 해요:

```bash
$ crystal tool format ./
```

파일을 골라서 포맷할 수도 있어요:

```bash
$ crystal tool format ./<path>/<to>/<file>
```

## 풀이 제출하기

풀이를 제출할 때는 `src` 디렉터리에 있는 소스 파일을 꼭 제출해야 해요:

```bash
$ exercism submit src/<exercise>.cr
```
