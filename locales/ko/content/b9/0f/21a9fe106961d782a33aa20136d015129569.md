# 안내 추가

## Python 트랙에서 이 연습 문제가 구성된 방식

이 연습 문제의 테스트는 풀이가 Python에서 RelativeDistance `class`로 구현되기를 기대해요.
Python의 `class`가 익숙하지 않다면, [concept:python/classes]()와 [공식 Python 문서의 `classes`][classes in python]부터 시작하는 게 좋아요.


`RelativeDistance`는 `family_tree`를 사용해 초기화해야 해요 (_자세한 내용은 [`__init__()`][init]을 참고해요_). `family_tree`는 `keys`가 각각의 사람이고 `values`가 그 사람의 자녀를 담은 `list`인 딕셔너리예요.
또한 `person_a`와 `person_b` 사이의 분리 정도를 반환하는 `degree_of_separation` [메서드][methods]도 구현해야 해요. 여기서 `person_a`와 `person_b`는 전달받은 가계도에 있는 사람들이에요.


`RelativeDistance` 클래스의 인스턴스를 만들 때 쓰이는 `__init__` [특수 메서드][special-methods]의 스텁 구현과 `degree_of_separation` 메서드의 스텁이 주어져요.
먼저, `family_tree` 데이터를 나타낼 수 있도록 `self` (_인스턴스_)에 적절한 속성을 추가해 `__init__`을 수정해야 해요.
그런 다음 `degree_of_separation` 메서드에 로직을 추가해 `person_a`와 `person_b` 사이의 분리 정도를 계산하면 돼요.


## 예외 메시지

때로는 [예외를 발생시켜야][raising-exceptions] 하는 경우가 있어요.
이럴 때는 오류의 원인이 무엇인지 알려 주는 **의미 있는 오류 메시지**를 항상 포함해야 해요.
그래야 코드를 더 읽기 쉽게 만들고, 디버깅에도 큰 도움이 돼요.
오류 원인이 특정 타입일 것이라고 알고 있는 상황이라면 [내장 오류 타입][base-error-classes] 중 하나를 발생시켜도 되지만, 그래도 의미 있는 메시지를 포함해야 해요.

이 연습 문제에서는 [`raise` 문][raise-statement]을 사용해 여러 개의 `ValueError`를 "던져야" 해요.
첫 번째 상황에서는 `RelativeDistance.degree_of_separation` 메서드에 전달된 사람 중 하나 또는 둘 다 가계도에 없을 때 `ValueError`를 발생시켜야 해요.

```python
# Example when Person A is not in the tree.
raise ValueError("Person A not in family tree.")
```

두 사람이 모두 가계도에 있다면, 규칙에서 정의한 유효한 연결이 둘 사이에 없을 때 `ValueError`를 발생시켜야 해요.

```python
# Example when there are no valid connections.
raise ValueError("No connection between person A and person B.")
```

테스트는 기대하는 `exception` 타입을 `raise`하면서 그와 함께 기대하는 메시지를 포함할 때만 통과해요.
이 설명이 모든 내용을 담고 있지는 않으니, 테스트와 기대 결과를 꼼꼼히 확인해 봐요.
