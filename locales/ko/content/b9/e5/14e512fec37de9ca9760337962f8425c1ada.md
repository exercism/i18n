그런데 상황이 조금 엉망이에요. Azara의 좌표는 Rui의 좌표와 형식도, 정렬 순서도 다르게 보여서, 어떤 보물이 어떤 위치에 해당하는지 알아내려면 두 목록을 계속 번갈아 봐야 해요.
이제 막 파이썬을 배우기 시작한 두 사람은 탐색 정보를 더 잘 정리할 작은 프로그램(사실은 함수 몇 개)을 짜는 데 도움을 청하러 왔어요.


## 1. 좌표 추출하기

Azara의 목록에 있는 `(treasure, coordinate)` 쌍을 받아 추출한 지도 좌표만 반환하는 `get_coordinate()` 함수를 구현해요.


```python
>>> get_coordinate(('Scrimshawed Whale Tooth', '2A'))
2A
```

## 2. 좌표 형식 맞추기

`"2A"` 형식의 좌표를 받아 `("2", "A")` 형식의 튜플을 반환하는 `convert_coordinate()` 함수를 구현해요.


```python
>>> convert_coordinate("2A")
("2", "A")
```

## 3. 좌표 대조하기

`(treasure, coordinate)` 쌍과 `(location, coordinate, quadrant)` 레코드를 받아 각각의 좌표를 비교하는 `compare_records()` 함수를 구현해요.
좌표가 "일치"하면 **`True`**를 반환하고, 일치하지 않으면 **`False`**를 반환해요.
정확하게 비교하려면 필요에 따라 좌표 형식을 다시 맞춰요.


```python
>>> compare_records(('Brass Spyglass', '4B'), ('Seaside Cottages', ('1', 'C'), 'blue'))
False

>>> compare_records(('Model Ship in Large Bottle', '8A'), ('Harbor Managers Office', ('8', 'A'), 'purple'))
True
```

## 4. 일치하는 레코드 합치기

Azara의 목록에 있는 `(treasure, coordinate)` 쌍과 Rui의 목록에 있는 `(location, coordinate, quadrant)` 레코드를 받아, **좌표가 일치하면** `(treasure, coordinate, location, coordinate, quadrant)`를 반환하는 `create_record()` 함수를 구현해요.
좌표가 _일치하지 않으면_ 문자열 **"not a match"**를 반환해요.
정확하게 비교하려면 필요에 따라 좌표 형식을 다시 맞춰요.


```python
>>> create_record(('Brass Spyglass', '4B'), ('Abandoned Lighthouse', ('4', 'B'), 'Blue'))
('Brass Spyglass', '4B', 'Abandoned Lighthouse', ('4', 'B'), 'Blue')

>>> create_record(('Brass Spyglass', '4B'), ('Seaside Cottages', ('1', 'C'), 'blue'))
"not a match"
```

## 5. "정리"하고 모든 레코드의 보고서 만들기
