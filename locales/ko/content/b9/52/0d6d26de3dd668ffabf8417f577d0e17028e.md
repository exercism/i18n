## 일반

`SimpleLinkedList` 구조체를 `Vec`를 감싸는 래퍼로 구현하지 마세요. 대신 노드를 힙에 할당해요.

다음과 같이 구현할 수 있어요:

```
pub struct SimpleLinkedList<T> {
    head: Option<Box<Node<T>>>,
}
```

`head` 필드는 이 연결 리스트의 첫 번째 요소(Node)를 가리켜요.

이 구현에는 다음과 같은 필드를 가진 `Node` 구조체도 필요해요:

```
struct Node<T> {
    data: T,
    next: Option<Box<Node<T>>>,
}
```

`data`에는 저장된 데이터가 들어 있고, `next`는 다음 노드(있다면)나 None을 가리켜요.

## 왜 `Option<Box<Node<T>>>`이고 `Option<Node<T>>`는 아닐까요?

직접 한번 해봐요. 그러면 다음과 같은 오류가 나와요.

```
| struct Node<T>
| ^^^^^^^^^^^^^^ recursive type has infinite size
...
|     next: Option<Node<T>>,
|     --------------------- recursive without indirection
```

문제는 컴파일 시점에 `next`의 크기를 알고 있어야 한다는 점이에요.
`next`는 재귀적이기 때문에("노드가 노드를 가지고, 그 노드가 또 노드를 가지고..."), 컴파일러는 얼마만큼의 메모리를 할당해야 하는지 알 수 없어요.
반면 [Box](https://doc.rust-lang.org/std/boxed/)는 크기가 정해진 힙 포인터예요.
