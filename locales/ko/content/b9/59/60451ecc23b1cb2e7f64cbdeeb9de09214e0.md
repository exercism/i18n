# 소개

## Period와 Duration

`LocalDate`나 `LocalDateTime` 같은 클래스는 시간의 한 _지점_을 나타내요.
`java.time` 패키지에는 시간의 _양_을 나타내는 클래스도 두 개 있어요.

- `java.time.Period`는 년, 월, 일 단위의 시간 양이에요. 예를 들어 "2개월 5일" 같은 거예요.
- `java.time.Duration`은 시간, 분, 초, 밀리초, 나노초 단위의 시간 양이고, 예를 들어 "1시간 30분" 같은 거예요.

`Period`는 달력을 따르기 때문에 날짜와 날짜시간에 사용해요.
`Duration`은 정확한 시간을 재기 때문에 시각과 날짜시간에는 사용하지만, 날짜에는 사용하지 않아요.

```exercism/note
다른 `java.time` 클래스처럼 `Period`와 `Duration`은 불변이에요.
이들을 바꾸는 것처럼 보이는 메서드도 사실은 _새로운_ 인스턴스를 반환해요.
```

### `Period`

`Period`는 정적 팩토리 메서드 중 하나로 만들어요.

```java
Period.ofDays(10);
// => P10D

Period.ofMonths(3);
// => P3M

Period.of(1, 2, 15);
// => P1Y2M15D
```

`toString()`의 결과는 [ISO-8601][iso-8601-durations] 표기법을 따라요. "period"를 뜻하는 `P` 뒤에 년(`Y`), 월(`M`), 일(`D`)의 개수가 붙는 방식이에요.

날짜에 기간을 더하거나 뺄 수 있어요.

```java
LocalDate date = LocalDate.of(2024, 3, 10);

date.plus(Period.ofMonths(2));
// => 2024-05-10

date.minus(Period.ofDays(10));
// => 2024-02-29
```

달마다 길이가 다르기 때문에, 월을 더하면 존재하지 않는 날짜가 될 수도 있어요.
그럴 때는 그 달의 마지막으로 유효한 날로 결과가 조정돼요.

```java
LocalDate.of(2025, 1, 31).plus(Period.ofMonths(1));
// => 2025-02-28
```

`Period.between()`은 한 날짜(포함)부터 다른 날짜(미포함)까지의 기간을 반환해요.

```java
LocalDate start = LocalDate.of(2023, 3, 10);
LocalDate end = LocalDate.of(2024, 5, 25);

Period period = Period.between(start, end);
// => P1Y2M15D

period.getYears();
// => 1
period.getMonths();
// => 2
period.getDays();
// => 15
```

### `ChronoUnit`으로 단위 세기

`Period`는 년, 월, 일을 각각 따로 저장해요.
그래서 `getDays()`는 기간에서 일 _부분_만 반환할 뿐, 전체 일 수를 반환하지는 않아요.
두 날짜 사이에서 특정 단위의 전체 개수를 세려면 [`java.time.temporal.ChronoUnit`][chronounit-docs]의 `between()` 메서드를 사용해요.

```java
LocalDate start = LocalDate.of(2024, 1, 15);
LocalDate end = LocalDate.of(2024, 3, 20);

Period.between(start, end);
// => P2M5D

Period.between(start, end).getDays();
// => 5

ChronoUnit.DAYS.between(start, end);
// => 65
```

두 번째 날짜가 첫 번째 날짜보다 이르면 결과는 음수가 돼요.

```java
ChronoUnit.DAYS.between(end, start);
// => -65
```

### `Duration`

`Duration`도 정적 팩토리 메서드로 만들어요.

```java
Duration.ofMinutes(90);
// => PT1H30M

Duration.ofHours(2).plusMinutes(15);
// => PT2H15M
```

ISO-8601 표기법에서 `T`는 날짜 부분과 시간 부분을 구분하는 역할을 해요. 그래서 `Duration`은 `PT...` 형태로 표시돼요.

날짜시간에 `Duration`을 더하거나 뺄 수 있어요.

```java
LocalDateTime start = LocalDateTime.of(2024, 3, 10, 22, 30);

start.plus(Duration.ofMinutes(90));
// => 2024-03-11T00:00
```

`Duration.between()`은 두 날짜시간 사이의 정확한 시간 양을 반환해요.

```java
LocalDateTime checkIn = LocalDateTime.of(2024, 3, 10, 18, 5);
LocalDateTime checkOut = LocalDateTime.of(2024, 3, 10, 19, 40);

Duration.between(checkIn, checkOut);
// => PT1H35M
```

`toHours()`, `toMinutes()`, `toSeconds()` 같은 메서드로 `Duration`을 하나의 단위로 바꿀 수 있어요.
이 메서드들은 해당 단위의 _전체_ 양을 버림해서 반환해요.

```java
Duration duration = Duration.ofMinutes(95);

duration.toHours();
// => 1
duration.toMinutes();
// => 95
```

시계처럼 `Duration`을 각 부분으로 나누고 싶다면 `toXxxPart()` 메서드를 사용해요.

```java
Duration duration = Duration.ofMinutes(95);

duration.toHoursPart();
// => 1
duration.toMinutesPart();
// => 35
```
