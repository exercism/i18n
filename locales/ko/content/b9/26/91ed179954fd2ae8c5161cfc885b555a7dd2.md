# 소개

주석을 사용하면 코드가 실행되는 방식에 영향을 주지 않으면서 코드에 메모를 남길 수 있어요.
한 줄 주석은 `//`로 시작하고, 여러 줄 주석은 `/*`와 `*/`로 감싸요:

```go
// This is a single-line comment.

/*
This is a
multiline comment.
*/
```

주석은 어디에 쓰이느냐에 따라 그 역할이 달라요.

## 코드 주석

코드 주석은 무엇을 하는지가 아니라 왜 그렇게 하는지를 설명해요.
코드만 봐서는 어떤 결정을 내린 이유가 분명하지 않을 때 사용해요:

```go
results = results[1:] // skipping the header row
```

## 문서 주석

문서 주석은 선언 바로 앞에 위치하며, 주석과 선언 사이에 빈 줄이 없어요.
[`godoc`][godoc]이 문서 주석을 파싱해 패키지 문서를 만들어요.
문서 주석은 식별자의 이름으로 시작하고 마침표로 끝나는 완전한 문장이어야 해요.

패키지 주석은 패키지 이름으로 시작해요:

```go
// Package kelvin provides tools to convert temperatures to and from Kelvin.
package kelvin
```

함수 주석은 함수 이름으로 시작해요:

```go
// CelsiusFreezingTemp returns an integer value equal to the temperature at which water freezes in degrees Celsius.
func CelsiusFreezingTemp() int {
	return 0
}
```

[godoc]: https://go.dev/blog/godoc
