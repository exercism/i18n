# 문자열

`STR`은 텍스트를 담아요. 문자열은 큰따옴표 사이에 써요.

```sather
   composer : STR is
      return "Sibelius";
   end;
```

`STR`은 한번 만들어지면 절대 바뀌지 않아요. 아래에 나오는 모든 연산은 대상 문자열을 고치는 대신 *새로운* 문자열로 답해요.

## 이어 붙이기

```sather
"Jean" + " " + "Sibelius"      -- "Jean Sibelius"
```

`+`는 숫자를 문자열에 이어 붙일 수도 있는데, 이렇게 해서 숫자가 문장 속으로 들어가요.

```sather
"Opus " + 27           -- "Opus 27"
```

## 길이

```sather
"Sibelius".size        -- 8
"".size                -- 0
```

`.size`는 문자 수를 세고, 결과는 `INT`예요.

## 조각

| 호출 | 결과 |
| --- | --- |
| `"Sibelius".head(3)` | `"Sib"` |
| `"Sibelius".tail(4)` | `"lius"` |

있는 것보다 더 많이 요청하면 실패하는 대신 있는 만큼만 돌려줘요.

## 비교하기

`=`는 두 문자열이 같은 텍스트인지 묻고, `/=`는 서로 다른지 물어요.

```sather
"forte" = "forte"      -- true
"forte" = "Forte"      -- false
```

대소문자가 중요해요. `.upper`와 `.lower`는 한쪽 대소문자로 바꾼 복사본을 주는데, 대소문자를 신경 쓰지 않고 비교할 때 흔히 쓰는 방법이에요.

```sather
"Forte".lower                    -- "forte"
"Forte".lower = "forte".lower    -- true
```

## 크기에 관한 이야기

`STR`은 바이트의 나열이고, `.size`는 바이트 수를 세요. 영어 텍스트에서는 글자 수를 세는 것과 같아요. 하지만 악센트가 붙거나 다른 문자 체계에 속한 텍스트에서는 같지 않아요. 그런 글자는 하나에 한 바이트가 넘게 차지하니까요.
