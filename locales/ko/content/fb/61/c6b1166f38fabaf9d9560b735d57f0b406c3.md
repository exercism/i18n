# Elm 문법 기초 1

## 상수와 함수

Elm 프로그램은 정의와 표현식으로 이루어져 있어요.
Elm에서 모든 것은 정의이거나 표현식이에요.

상수 값은 `name = expression`으로 정의해요.

```elm
five = 5

six = 3 + 3
```

함수는 `name parameters... = expression`으로 정의하고, 매개변수는 공백으로만 구분해요.

```elm
add number1 number2 = number1 + number2
```

함수를 호출하는 것도 표현식이에요. 함수의 이름을 쓰고 함수의 각 매개변수에 인자를 전달하면 되는데,
함수 정의에서처럼 공백으로 구분해요.

```elm
five = add 2 3
```

괄호를 사용해서 표현식의 평가 순서를 지정할 수 있어요.

```elm
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## 들여쓰기 / 유의미한 공백

Elm은 중괄호, 괄호, 세미콜론 같은 문법적 표시를 사용해서 코드의 경계를 지정하지 않아요. 대신 공백과 들여쓰기를 사용해요.

- 모듈, import, 최상위 함수 정의는 가장 왼쪽 열에서 시작해야 해요.
- 표현식이 여러 줄로 나뉘면, 그 표현식에 속한 코드는 표현식 아래에서 최소 한 칸 들여써야 해요.
- 함께 묶이는 표현식의 부분은 같은 수의 공백으로 들여써야 해요.

```elm
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://elmprogramming.com/indentation.html

## 모듈

Elm의 각 파일은 모듈이고, 다른 모든 코드보다 앞에 `module` 문이 있어야 해요.
모듈 이름은 파일 이름과 일치해야 해요. 그래서 `Calculator` 모듈은 Calculator.elm 파일에 있어야 해요.
모듈 안에서 정의된 것은 그 모듈에 비공개로 범위가 정해지고,
`exposing`에 나열되지 않으면 이 모듈 밖에서 접근할 수 없어요.

```elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## 주석

주석은 Elm 파일 안에 있지만 코드로 해석되지 않는 텍스트예요.
주로 자신과 다른 프로그래머가 읽기 위한 것이에요.
두 개의 대시를 기반으로 한 한 줄 주석을 위한 가벼운 문법이 있어요.
여러 줄 주석도 `{-`와 `-}`라는 여는 구분자와 닫는 구분자 쌍으로 가능해요.

```elm
-- a single line comment
-- another single line comment

{- a multiline comment
   spawning multiple lines
-}
```
