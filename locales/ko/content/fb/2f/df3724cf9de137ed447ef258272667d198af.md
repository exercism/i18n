코드베이스의 공개 인터페이스는 신중하게 설계해야 해요. 공개 함수가 하나 늘어날 때마다 장기적인 유지보수 비용이 커지고 리팩터링도 어려워지기 때문이에요.

Exercism의 모든 연습 문제에서 공개 인터페이스는 테스트 스위트가 정의해요. 테스트가 호출하는 함수라면 공개로 두어야 해요. 그 외의 함수는 모두 비공개로 두는 게 좋아요. 이름은 같지만 인자 수가 다른 함수도 마찬가지예요.

```elixir
# you defined the following public function

%{actual}

# make it private like this

%{expected}
```
기본 인자는 함수의 인자 수를 바꾼다는 점을 기억해요.

라이브러리를 작성할 때는 여러 모듈에서 함께 쓰려고 함수를 공개해야 하는 경우가 많아요. 이런 함수를 문서에서 감추려면 함수 정의 앞에 `@doc false` 속성을 붙이고, 모듈 전체를 감추려면 `@moduledoc false` 속성을 붙여요.
