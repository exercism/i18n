# 지침

이 연습 문제에서는 로그 줄을 처리해요.

각 로그 줄은 다음과 같은 형식의 문자열이에요: `"[<LEVEL>]: <MESSAGE>"`.

로그 레벨은 세 가지가 있어요:

- `INFO`
- `WARNING`
- `ERROR`

여기에는 여러 개의 과제가 있어요. 각 과제는 로그 줄 하나를 받아서 그 줄로 무언가를 하도록 해요.

## 1. 특정 부분 문자열 뒤의 문자열을 가져오기

지난달의 로그를 살펴보면, 테스트 메시지는 항상 특정 부분 문자열 뒤에 있다는 걸 알 수 있어요. 조만간 테스트 메시지를 추출해야 할 것 같아서, 그걸 도와줄 도우미 메서드를 만들기로 해요.

(_정적_) `LogAnalysis.SubstringAfter()` 확장 메서드를 구현해요. 이 메서드는 문자열 구분자를 하나 받아서 그 구분자 뒤의 부분 문자열을 반환해요.

```csharp
var log = "[INFO]: File Deleted.";
log.SubstringAfter(": "); // => returns "File Deleted."
```

## 2. 두 부분 문자열 사이의 문자열을 가져오기

자세히 살펴보니, 로그 레벨은 항상 대괄호(`[`와 `]`) 사이에 있네요. 마찬가지로 조만간 로그 레벨을 추출해야 할 것 같아서, 그걸 도와줄 도우미 메서드를 하나 더 만들기로 해요.

(_정적_) `LogAnalysis.SubstringBetween()` 확장 메서드를 구현해요. 이 메서드는 문자열 구분자 두 개를 받아서, 두 구분자 사이에 있는 부분 문자열을 반환해요.

```csharp
var log = "[INFO]: File Deleted.";
log.SubstringBetween("[", "]"); // => returns "INFO"
```

## 3. 로그에서 메시지 파싱하기

(_정적_) `LogAnalysis.Message()` 확장 메서드를 구현해서 로그에 담긴 메시지를 반환해요.

```csharp
var log = "[ERROR]: Missing ; on line 20.";
log.Message(); // => returns "Missing ; on line 20."
```

## 4. 로그에서 로그 레벨 파싱하기

(_정적_) `LogAnalysis.LogLevel()` 확장 메서드를 구현해서 로그의 로그 레벨을 반환해요.

```csharp
var log = "[ERROR]: Missing ; on line 20.";
log.LogLevel(); // => returns "ERROR"
```
