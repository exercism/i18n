# 지시 사항

문득 팬케이크가 먹고 싶어졌어요.
기술에 관심이 많은 현대인답게, 팬케이크 재료 쇼핑 목록을 JSON 형식으로 작성해요.
목록의 구조는 다음과 같아요:

```json
{
  "name": "name of shopping list",
  "ingredients": [ ...list of ingredients... ],
  "optional ingredients": [ ...list of ingredients... ]
}
```

재료는 다음과 같이 JSON 객체로 표현해요:

```json
{
  "item": "flour",
  "amount": {
    "quantity": 2,
    "unit": "cup"
  }
}
```

재료에는 `"substitute"`라는 선택적 속성이 있을 수 있는데, 여기에는 대신 사용할 수 있는 다른 재료의 이름을 담은 문자열이 들어 있어요.

`jq`로 쇼핑 목록을 어떻게 살펴볼 수 있는지 알아봐요.

## 1. 쇼핑 목록 이름 추출하기

쇼핑 목록의 "name" 요소를 출력하는 표현식을 작성해요.

## 2. 필요한 재료가 몇 개인지 세기

"required" 재료만 세요. 선택적 재료는 세지 않아요.

## 3. 설탕은 얼마나 필요할까요?

설탕의 양을 출력하는 표현식을 작성해요.
숫자 부분만 필요해요.

## 4. 대체할 수 있는 재료 매핑하기

일부 재료는 대체할 수 있어요 (재료 X가 없으면 Y를 사용할 수 있어요).
추천 재료를 그 대체 재료에 매핑한 JSON 객체를 출력해요.
매핑에 선택적 재료도 포함해요.
