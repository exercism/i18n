# 소개

Kotlin은 IntelliJ를 만든 회사인 JetBrains가 설계하고 개발했어요. JVM에서 실행되는 언어로, 버전 6 이상( [Android 플랫폼](https://blog.jetbrains.com/kotlin/2017/05/kotlin-on-android-now-official/) 포함)을 대상으로 할 수 있어요. JetBrains는 Java 보일러플레이트 코드를 없애고, 현대적인 함수형 패러다임을 제공하며, 기존 코드베이스와 매끄럽게 양방향으로 상호 운용되는 정적 타입 언어를 쓰고 싶었어요. JVM에는 이미 Groovy나 Scala 같은 다른 언어가 있었지만, 둘 다 그들이 원하던 기준에 맞지 않았기 때문에 Kotlin을 직접 만들었어요.

Kotlin의 문법은 Scala나 Swift와 비슷하지만, C#이나 Groovy 같은 다른 언어에서 가장 뛰어난 기능들을 끌어왔어요. Kotlin은 언어에 어떤 기능을 넣을지 정할 때 개발자에게 유용하다고 검증된 기능만 제공하는 실용적인 접근을 택했어요. 이런 결정과 함께, "더 나은 Java"를 찾는 개발자에게 더 유지보수하기 쉬운 코드와 더 완만한 학습 곡선을 제공하려는 의도로 Scala 기능의 일부만 구현했어요.

JetBrains는 Kotlin을 개발하는 전담 팀을 두고 있으며, 코드베이스는 [Github](https://github.com/JetBrains/kotlin)에서 볼 수 있어요.
