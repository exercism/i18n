# 소개

필터링은 원래 시퀀스에서 특정 원소만 빼고 모두 복사해 새로운 시퀀스를 만드는 과정이에요.
새 시퀀스에 어떤 항목을 포함할지는 술어 함수(불리언 값으로 평가되는 함수)로 정할 수도 있고, 특정 객체와의 동등 비교로 정할 수도 있어요.

## 술어로 제거하기

`remove-if`는 술어 함수와 시퀀스를 인자로 받아, 술어가 거짓으로 평가된 원소만 모은 시퀀스를 반환하는 함수예요.
다시 말해, 술어가 참으로 평가되는 시퀀스의 모든 원소를 "제거"해요. 하지만 이 함수는 원래 시퀀스를 수정하지 않는다는 점에 주의해요! 
대신 해당 원소들이 빠진 새 시퀀스를 반환해요. 모든 값에 대해 술어가 참이었다면 빈 시퀀스가 반환돼요.

```lisp
(remove-if #'evenp '(1 2 3 4 5)) ; => (1 3 5)
(remove-if #'oddp '(1 3 5))      ; => ()
```

## 술어로 원소 유지하기

`remove-if-not`이라는 함수도 있는데, 술어가 참으로 평가되는 원소를 *유지*한다는 점만 빼면 `remove-if`와 똑같아요.

대안으로 `complement`를 사용해 술어를 '반대'로 바꿀 수도 있어요.

```lisp
(remove-if #'evenp '(1 2 3 4 5 6))             ; => (1 3 5)
(remove-if-not #'oddp '(1 2 3 4 5 6))          ; => (1 3 5)
(remove-if (complement #'oddp) '(1 2 3 4 5 6)) ; => (1 3 5)
```

## 특정 항목 제거하기

시퀀스에서 특정 항목을 제거하고 싶다면 `remove`를 사용할 수 있어요. 이 함수는 제거할 항목과 시퀀스를 인자로 받아요.
시퀀스에서 제거할 항목과 같지 않은 모든 값이 반환돼요.

```lisp
(remove 1 '(1 2 1 3 1 4)) ; => (2 3 4)
(remove #\l "hello")      ; => "heo"
```

동등 비교에 사용할 함수는 `:test` [키워드 매개변수][concept-keyword-parameters]로 지정할 수 있어요.

`remove`는 특정 항목과 객체가 같은지 검사하는 술어를 작성해 `remove-if`로 구현할 수도 있다는 점에 주의해요.

## 다양한 옵션

이 함수들은 각각 다른 [키워드 매개변수][concept-keyword-parameters]도 많이 받는데, 이를 이용하면 일부 부분 시퀀스만 대상으로 삼거나 정해진 횟수만큼만 적용하는 등 다양한 활용이 가능해요. 자세한 내용은 [Hyperspec 문서][hyperspec-remove]를 참고해요.


## 파괴적인 옵션

`remove`, `remove-if`, `remove-if-not` 외에도 `delete`, `delete-if`, `delete-if-not`이 있는데, 이들은 전달받은 시퀀스를 수정할 수도 있다는 점만 빼면 같은 효과를 내요.
