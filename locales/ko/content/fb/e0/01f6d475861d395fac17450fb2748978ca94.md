# 소개

Swift에서는 문자열에 정수로 인덱스를 지정할 수 없어요 (`string[3]`처럼요).
Swift의 문자열은 길이가 제각각인 유니코드 문자로 이루어져 있어서, 문자 하나를 찾으려면 앞에 있는 문자들을 차례로 거쳐 가야 해요.

특정 위치의 문자에 접근하려면 `String.Index` 타입의 인덱스를 계산해야 해요.
이런 인덱스를 *불투명 인덱스*라고 부르는데, 내부 구조가 Swift에 의해 관리되고, 정수처럼 직접 다룰 수 없기 때문이에요:

```swift
let csv = "apple,pear,peach,orange,cherry,lime,gooseberry"
let index = csv.index(csv.startIndex, offsetBy: 21)
print(csv[index])
// Prints "g"

print(index)
// Prints internal representation: Index(_rawBits: ...)
```
