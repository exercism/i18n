# 지침

무용단이 줄을 지어 서 있고, 누가 어디에 서는지 기록하고 있어요.

다섯 과제는 모두 `DANCE_FORMATION` 클래스에 작성해요.

## 1. 줄에 몇 명 있나요?

```sather
DANCE_FORMATION::dancer_count(|"Mia", "Ana", "Ben"|)
-- => 3
```

## 2. 누가 선두인가요?

선두는 맨 앞에 서는 사람이에요.

```sather
DANCE_FORMATION::leader(|"Mia", "Ana", "Ben"|)
-- => "Mia"
```

## 3. 누가 맨 뒤에 있나요?

후미는 줄이 아무리 길어도 맨 뒤에 서는 사람이에요.

```sather
DANCE_FORMATION::back_marker(|"Mia", "Ana", "Ben"|)
-- => "Ben"
```

## 4. 시작 대형

무용단은 항상 같은 순서로 시작해요. Mia, Ana, Ben 순서예요. 그 줄을 반환해요.

```sather
DANCE_FORMATION::opening_row
-- => an array holding "Mia", "Ana" and "Ben", in that order
```

이 루틴은 인자를 받지 않아요.

## 5. 스텝 수 세기

댄서마다 해야 할 스텝 수가 있어요. 그 수를 모두 더해요.

```sather
DANCE_FORMATION::total_steps(|8, 16, 8|)
-- => 32
```

줄이 비어 있으면 스텝 수는 0이에요.
