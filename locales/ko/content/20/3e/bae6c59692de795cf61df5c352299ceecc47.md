# 힌트

## 1. 몇 가지 기본 연산을 지원하도록 calculate 메서드를 구현해요

- 서로 다른 연산을 구분하려면 [`switch`문][switch-statement-docs]을 사용해요.

## 2. 잘못된 연산을 처리해요

- `switch`문 안에서는 `null`인지 확인할 수 없어요.
- 나머지 경우는 switch 끝에서 `default` 케이스로 처리해요.

## 3. 0으로 나눌 때 발생하는 예외를 처리해요

- 0으로 나눌 때 발생하는 `ArithmeticException`을 잡으려면 [`try-catch` 블록][exception-handling-docs]을 사용해요.
- `IllegalOperationException` 클래스에는 메시지와 원인을 매개변수로 받는 생성자가 있어요.

[switch-statement-docs]: https://docs.oracle.com/javase/tutorial/java/nutsandbolts/switch.html
[exception-handling-docs]: https://docs.oracle.com/javase/tutorial/essential/exceptions/handling.html
