# 소개

여러 개의 서로 구분되는 값에 따라 분기해야 할 때는, `if`를 연달아 연결하는 것보다 [`combinators`][combinators]에 있는 `case`가 더 깔끔해요.

## `case`

```
case ( obj assoc -- )
```

`case`는 스택 맨 위의 값을 꺼내고, 절들의 *assoc*을 받아요. 각 절은 `{ value [ body ] }` 형태예요. 값이 입력값과 `=`로 같아지는 첫 번째 절이 선택되고, 그 절의 본문은 입력값이 *이미 소비된* 상태에서 실행돼요. 맨 끝에 `[ body ]`만 있는 항목은 기본값인데, 이게 실행될 때는 입력값이 *여전히 스택 위에* 있어요.

```factor
USING: combinators ;

: name-of ( n -- s )
    {
        { 1 [ "one" ] }
        { 2 [ "two" ] }
        [ drop "many" ]
    } case ;
```

동등성은 `=`를 기준으로 판단해요. 그래서 `=`로 같다고 비교되는 것은 무엇이든 키로 쓸 수 있어요. 숫자, 문자열, 심볼 모두 그래요.

## 조건부 분기를 위한 `cond`

선택이 동등성이 아니라 *술어*에 달려 있을 때(예를 들어 `x > 11`), `cond`가 딱 맞는 도구예요. `cond`는 [Cars, Assemble!][cars-assemble]에서 만났어요.

## 심볼

`SYMBOL:`은 자기 자신을 스택에 올리는 단어를 선언해요. 스스로 평가되는 태그 값이죠. `SYMBOLS:`는 한 번에 여러 개를 선언해요:

```factor
SYMBOLS: yes no maybe ;
```

이제 `yes`는 `=`로 비교할 수 있는 값이고, case 키로 쓸 수 있어요:

```factor
: invert ( ? -- ?' )
    { { yes [ no ] } { no [ yes ] } [ ] } case ;
```
