# 테스트

## Clojure CLI

Exercism의 Clojure 연습 문제는 [cognitect-labs test-runner](https://github.com/cognitect-labs/test-runner)를 실행하기 위한 `:test` 별칭이 있는 `deps.edn` 파일을 함께 제공해요:

``` bash
clj -X:test
```

## Leiningen

Leiningen으로도 연습 문제의 테스트를 실행할 수 있어요. 연습 문제 디렉터리에서 다음 명령어를 실행해 보세요:

```bash
lein test
```
