# 분해와 다중 할당

분해는 `Array`나 `Hash`와 같은 컬렉션의 원소를 추출하는 행위를 말해요.
분해된 값은 같은 문 안에서 변수에 할당할 수 있어요.

[다중 할당][multiple assignment]은 하나의 문 안에서 여러 변수에 분해된 값을 할당하는 기능이에요.
이렇게 하면 코드가 더 간결하고 읽기 쉬워지며, 할당할 변수들을 쉼표로 구분해서 `first, second, third = [1, 2, 3]`처럼 작성해요.

스플랫 연산자(`*`)와 더블 스플랫 연산자(`**`)는 분해 상황에서 자주 사용돼요.
스플랫 연산자(`*`)는 여러 **배열**을 하나의 **배열**로 결합할 수 있는데, 각 배열을 새로운 공통 **배열**로 _분해_함으로써 가능해요.
더블 스플랫 연산자(`**`)는 여러 **해시**를 하나의 **해시**로 결합할 수 있는데, 각 해시를 새로운 공통 **해시**로 _분해_함으로써 가능해요.
이는 위치 인자로 받는 여러 값과 구분하기 위해 사용되는 문법으로, 임의의/여러 키워드 인자를 받는 경우에 사용해요.

스플랫 연산자(`*`)가 컬렉션 없이 사용되면, 여러 값을 하나의 **배열**로 _묶어요_(또는 구성해요).
이는 다중 할당에서 개별 할당이 없는 모든 "나머지" 원소들을 하나의 변수로 묶을 때 자주 사용돼요.

Ruby에서는 임의의 개수의 위치 인자나 키워드 인자를 받는 메서드를 사용하거나 정의할 때 이러한 분해/구성 동작을 사용하는 것이 일반적이에요.
이러한 인자는 `def some_method(*args, **kwargs)`와 같이 정의되고, `some_method(*some_array, **some_hash)`와 같이 사용되는 것을 자주 볼 수 있어요.

~~~~exercism/caution
`*<variable_name>`과 `**<variable_name>`는 `*`와 `**`와 혼동하면 안 돼요.
`*`와 `**`는 각각 곱셈과 거듭제곱에 사용되는 반면, `*<variable_name>`과 `**<variable_name>`는 구성 및 분해 연산자로 사용돼요.
~~~~
