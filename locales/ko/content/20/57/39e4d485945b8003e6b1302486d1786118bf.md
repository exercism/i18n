# 자세히 알아보기

[`sequences`][sequences] 보카뷸러리는 배열(`{ … }`), 벡터(`V{ … }`), 문자열, 범위, 슬라이스가 모두 구현하는 하나의 [프로토콜][sequence-protocol]을 정의해요. 하나로 할 수 있는 일은 다른 것으로도 모두 할 수 있어요.

| 단어        | 효과                            |
|-------------|-----------------------------------|
| `length`    | `( seq -- n )`                    |
| `first`     | `( seq -- elt )`                  |
| `second`    | `( seq -- elt )`                  |
| `third`     | `( seq -- elt )`                  |
| `fourth`    | `( seq -- elt )`                  |
| `last`      | `( seq -- elt )`                  |
| `rest`      | `( seq -- tailseq )`              |
| `but-last`  | `( seq -- headseq )`              |
| `nth`       | `( n seq -- elt )` (0부터 시작)      |
| `head`      | `( seq n -- headseq )`            |
| `head*`     | `( seq n -- headseq )` (마지막 n개를 제외한 전부) |
| `tail`      | `( seq n -- tailseq )`            |
| `tail*`     | `( seq n -- tailseq )` (마지막 n개)   |
| `subseq`    | `( from to seq -- newseq )`       |
| `remove-nth`| `( n seq -- newseq )`             |
| `pad-head`  | `( seq n elt -- padded )`         |
| `pad-tail`  | `( seq n elt -- padded )`         |
| `prefix`    | `( seq elt -- newseq )`           |
| `suffix`    | `( seq elt -- newseq )`           |
| `unclip`    | `( seq -- rest first )`           |
| `unclip-last` | `( seq -- butlast last )`       |
| `empty?`    | `( seq -- ? )`                    |
| `if-empty`  | `( seq emptyquot nonemptyquot -- … )` |
| `member?`   | `( elt seq -- ? )`                |
| `reverse`   | `( seq -- newseq )`               |
| `index`     | `( elt seq -- i/f )`              |
| `index-or-length` | `( elt seq -- i )` (없으면 길이) |
| `count`     | `( seq quot -- n )`               |
| `concat`    | `( seqs -- seq )`                 |
| `sum`       | `( seq -- n )`                    |
| `product`   | `( seq -- n )`                    |
| `find`      | `( seq quot -- i/f elt/f )`       |
| `find-last` | `( seq quot -- i/f elt/f )`       |
| `produce`   | `( pred quot -- seq )`            |

배열은 길이가 고정되어 있어서 `prefix`/`suffix`/`append`/`prepend` 연산은 모두 원본을 키우는 대신 새로운 시퀀스를 반환해요. 벡터는 크기를 바꿀 수 있어요. `push`와 `pop`은 제자리에서 동작하지만, 새 복사본을 원한다면 `clone`이 올바른 출발점이에요.

## 변환

`>array`, `>string`, `>vector`는 (각각 해당 보카뷸러리에 있는) 어떤 시퀀스든 이름에 해당하는 구체적인 타입으로 변환해요. 호출하는 쪽에서 특정 표현을 원하거나, 슬라이스 같은 지연 시퀀스를 실제 값으로 만들고 싶을 때 사용해요.

```factor
USING: arrays sequences strings vectors ;

V{ 1 2 3 } >array  .   ! => { 1 2 3 }
{ 65 66 67 } >string . ! => "ABC"
"abc" >vector .        ! => V{ CHAR: a CHAR: b CHAR: c }
```
