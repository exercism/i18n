# 소개

Elixir는 `true`와 `false` 값을 불리언 타입으로 표현해요. 값은 `true`와 `false` 두 개뿐이에요. 이 값들은 변수에 담을 수 있어요:

```elixir
true_variable = true
false_variable = false
```

`and/2`, `or/2`, `not/1` 연산자를 사용하면 엄격한 불리언 표현식을 평가할 수 있어요.

```elixir
true_variable = true and true
false_variable = true and false

true_variable = false or true
false_variable = false or false

true_variable = not false
false_variable = not true
```

불리언 값을 반환하는 함수를 작성할 때는 함수 이름 끝에 `?`를 붙이는 것이 관례예요. 불리언 값을 저장하는 변수에도 같은 관례를 적용할 수 있어요.

```elixir
def either_true?(a?, b?) do
  a? or b?
end
```
