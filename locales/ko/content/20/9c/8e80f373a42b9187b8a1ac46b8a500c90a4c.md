# 지침

이 연습 문제에서는 로그 항목을 처리해요.

각 로그 줄은 다음과 같은 형식의 문자열이에요: `"[<LEVEL>]: <MESSAGE>"`.

로그 레벨은 세 가지가 있어요:

- `INFO`
- `WARNING`
- `ERROR`

세 가지 과제가 있는데, 각 과제는 로그 줄을 주고 그것으로 무언가를 해 보라고 해요. 이 과제를 푸는 방법은 아주 많아요. 위의 예제에서 좋아하는 기법을 골라서 무엇을 만들 수 있는지 확인해 봐요.

## 1. 로그 줄에서 메시지 가져오기

`message` 함수를 구현해서 로그 줄의 메시지를 반환하게 해요:

```jq
"[ERROR]: Invalid operation" | message
# => "Invalid operation"
```

앞뒤의 공백은 제거해야 해요:

```jq
"[WARNING]:  Disk almost full\r\n" | message
# => "Disk almost full"
```

## 2. 로그 줄에서 로그 레벨 가져오기

`log_level` 함수를 구현해서 로그 줄의 로그 레벨을 반환하게 해요. 이때 소문자로 반환해야 해요:

```ruby
"[ERROR]: Invalid operation" | log_level
# => "error"
```

## 3. 로그 줄 형식 바꾸기

`reformat` 함수를 구현해서 로그 줄의 형식을 바꿔요. 메시지를 먼저 놓고 그 뒤 괄호 안에 로그 레벨을 넣어요:

```ruby
"[INFO]: Operation completed" | reformat
# => "Operation completed (info)"
```
