# 힌트

## 일반

- `MACRO:`는 [`macros`][macros]에 있어요. 구성 요소들은 `kernel`(`dup`, `curry`),
  `sequences`(`append`, `concat`, `<repetition>`, `map`), `quotations`(`>quotation`)에
  들어 있어요.
- 매크로 본문은 스택에 **인용 하나**를 남겨야 해요. 본문이 코드의 배열을 만들어 낸다면,
  마지막에 `>quotation`을 붙여요.
- 생각을 확인하려면, 리스너에서 리터럴에 본문의 단어들을 실행해 보고 돌아오는 인용을
  살펴봐요. 그 인용은 과제의 "compiles to" 줄에 있는 코드가 곧바로 이어진 형태여야 해요.

## 1. 두 번 반복하기

- `[ A ]`를 받아서 `[ A A ]`를 원해요. 복사한 다음 이어 붙여요: `dup append`.

## 2. N번 반복

- `[ A ] n`을 받아서 `n`개의 복사본을 이어 붙이고 싶어요.
- `<repetition>`이 복사본을 만들어 주지만, 효과는
  `( length elt -- repetition )`예요. 개수가 맨 위에 있어야 하니 `swap`을 먼저 해요.
- 그다음 펼쳐서 변환해요: `swap <repetition> concat >quotation`.

  ```factor
  ! stack: [ 1 + ] 3
  swap <repetition>     ! 3 copies of [ 1 + ]
  concat >quotation     ! => [ 1 + 1 + 1 + ]
  ```

## 3. 여러 개 조합하기

- 인용들의 배열은 이미 받았으니, 하나로 펼치기만 하면 돼요. `concat >quotation`이 본문의
  전부예요.

## 4. 펼쳐 놓은 반복

시퀀스와 인용, 예를 들어 `{ 10 20 30 } [ + ]`를 받아서 `[ 10 + 20 + 30 + ]`를 원해요.
세 단계로 만들어 봐요.

**원소 하나.** 인용 안에 원소를 미리 넣어 두는 일이 바로 `curry`가 하는 일이에요:

```factor
10 [ + ] curry .   ! => [ 10 + ]
```

**원소마다.** 그걸 시퀀스에 `map`하고 싶지만, `map`은 매핑 인용에 입력을 하나만 넘겨줘요.
바로 원소죠. 그런데 매번 `[ + ]`도 곁에 있어야 해요. 그래서 `[ + ]`를 매핑 인용 안에 먼저
넣어 둬요. 여기서도 `curry`를 써요:

```factor
! stack: { 10 20 30 } [ + ]
[ curry ] curry    ! => { 10 20 30 } [ [ + ] curry ]
map                ! runs  10 [ + ] curry,  20 [ + ] curry, …
                   ! => { [ 10 + ] [ 20 + ] [ 30 + ] }
```

`[ curry ] curry`는 "작은 인용 `[ curry ]`를 푸시한 다음, 그 안에 `[ + ]`를 curry한다"는
뜻이고, 결과는 `[ [ + ] curry ]`예요. 그걸 원소 `e`에 대해 매핑하면 `e [ + ] curry`가
실행되는데, 이건 `[ e + ]`예요.

**합치기.** 마무리는 다른 과제들과 같아요:

```factor
concat >quotation  ! => [ 10 + 20 + 30 + ]
```

- 본문 전체: `[ curry ] curry map concat >quotation`.
