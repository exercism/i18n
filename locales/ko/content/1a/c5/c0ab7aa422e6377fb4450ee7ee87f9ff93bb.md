# 소개

## 배경

문자열은 따옴표 사이에 있는 텍스트예요.
현재 지원되는 모든 R 버전은 문자열을 UTF-8로 인코딩하므로, 세상 대부분의 언어를 지원할 수 있어요.

```R
mystring <- "some text"
mystring
#> [1] "some text"
typeof(mystring)
#> [1] "character"
```

아쉽게도, 다른 언어에 익숙한 프로그래머에게는 이 용어가 혼란스러울 수 있어요.

`type`이 `character`이긴 하지만, R은 한 글자(다른 여러 언어에서는 `char`라고 부르지만 R에서는 _아니에요_)와 긴 문자열을 구분하지 않아요.
둘 다 하나의 항목이고, 작은따옴표 `' '`나 큰따옴표 `" "` 중 어느 것을 써도 돼요.

스타일 가이드는 문자열 안에 큰따옴표를 이스케이프 없이 쓰고 싶을 때를 빼고는 큰따옴표를 사용할 것을 권장해요.

```R
str2 <- 'String with "quotes"'  # convenience format
str2
#> [1] "String with \"quotes\""    # standard format
```

따라서 `character vector`는 문자열의 벡터이고, 각 문자열이 하나의 원소예요.

```R
s <- c("some", "strings")
s
#> [1] "some"    "strings"
length(s)
#> [1] 2
length(s[1])  # the number of vector elements, not the string length
#> [1] 1

nchar(s[1])  # the number of characters in the string "some"
#> [1] 4
```

위 예시에서 `length(s[1])`은 `length("some")`과 같아요. 즉 _문자열의 길이_가 아니라 _벡터 원소의 개수_예요.

개별 문자열을 다루는 것도 물론 가능해요. 위 예시의 `nchar()`처럼요. 다만 아래에서 다룰 특별한 함수들이 필요해요.

### 문자열 함수

베이스 R에서도 대부분의 작업이 _가능_하지만, 많은 프로그래머는 문자열 조작 지원이 다소 제한적이고 혼란스럽다고 느껴요.

다행히 훨씬 직관적이고 유연하며 일관성 있는 `tidyverse` 패키지들이 있어요.

### 베이스 R

예전 스타일의 문자열 함수를 사용하는 레거시 코드가 여전히 많아요.
Exercism의 커뮤니티 풀이 대부분이 그렇죠.

또한 작은 작업에는 큰 라이브러리를 불러오는 대신 내장 함수를 쓰는 게 유용할 수 있어요.
R 트랙 유지보수자들은 연습 문제를 검증하기 위해 모범 풀이를 작성할 때 이 방식을 주로 사용해요.

따라서 예전 방식에 대한 지식도 여전히 알아 둘 가치가 있어요.

#### `nchar`

문자열의 문자 개수를 반환해요.

```R
nchar("string")
#> [1] 6

nchar("Hrōðgār") # a person in Beowulf, written in Old English
#> [1] 7
```

"문자"가 무엇을 의미하는지에 대한 (_복잡한!_) 주제는 이 범위를 벗어나요.
위 예시에서 몇 가지만 짚어볼게요:

- 내부적으로 C로 구현되었지만, R의 문자열은 `\0`로 끝나지 않아요 (그랬다면 길이에 1이 더해졌을 거예요).
- 여러 바이트로 이루어진 유니코드 문자는 예상하거나 바라는 대로 처리돼요. "Hrōðgār"는 7개의 문자("룬" 또는 "코드 포인트"라고도 해요)를 가지지만, 저장에는 10바이트가 필요해요.

#### `paste`와 `paste0`

임의 개수의 문자열을 하나의 문자열로 합쳐요.

`paste`에는 선택적으로 구분자를 지정할 수 있어요. 기본값은 공백이에요.

`paste0(v)`는 `paste(v, sep = "")`와 같아요.

```R
paste("bits", "of", "a", "string")
#> [1] "bits of a string"
paste0("bits", "of", "a", "string")
#> [1] "bitsofastring"
```

#### `sprintf`

문자열 조합을 더 세밀하게 제어하기 위해, R은 C에서 `sprintf` 함수를 가져왔어요 (그리고 이후의 여러 언어도 마찬가지예요: 위키백과에는 약 30개가 [나열되어 있어요][wiki-printf-ports]).

```R
r <- 5.3
pi <- 3.14159
sprintf("A circle of radius %.1f has area %.2f", r, pi * r^2)
#> [1] "A circle of radius 5.3 has area 88.25"
```

#### `trimws`

앞과 뒤의 공백은 `trimws()`로 제거할 수 있어요:

```R
s <- "    messy string   "
trimws(s)
#> [1] "messy string"
```

양쪽 끝을 모두 다듬지 않으려면 `which = "left"` (또는 "right") 매개변수를 사용해요.

#### `substr`

하나의 문자열에 작용하며 두 개의 (양끝을 포함하는) 한계 사이의 부분 문자열을 반환해요.

```R
substr("Exercism", 5, 7)
#> [1] "cis"
```

#### `strsplit`

문자열을 구분자 문자열에 따라 R 리스트로 나눠요.
구분자는 필수예요 (기본값이 없어요). 하지만 빈 문자열도 될 수 있어요.

```R
strsplit("R, Python, Julia", ", ")
[[1]]
#> [1] "R"      "Python" "Julia" 

strsplit("Exercism", "")
[[1]]
#> [1] "E" "x" "e" "r" "c" "i" "s" "m"
```

리스트는 별도의 [개념][concept-lists]에서 다뤄요.
아직 교육 과정의 그 부분에 도달하지 않았다면, 지금은 `unlist()` 함수가 (이 경우) 리스트를 벡터로 변환한다는 것만 알아 두세요.

```R
unlist(strsplit("Exercism", ""))
#> [1] "E" "x" "e" "r" "c" "i" "s" "m"
```

### Tidyverse

너그럽게 보면, 예전 스타일의 문자열 함수가 R이 제공하는 최선은 아니라고 말할 수 있어요 (_덜 너그러운 관점도 있어요_).

상황을 개선하기 위해 `stringr` 라이브러리는 2009년부터 개발되어 왔고, 이제 Tidyverse 모음의 핵심 부분이에요.

`library(stringr)` 또는 `library(tidyverse)`로 네임스페이스에 불러와요.

몇 가지 주요 특징은 다음과 같아요:

- 모든 함수 이름에 `str_` 접두사가 붙어 목적을 분명히 하려고 해요.
- 인자의 순서는 일관성을 유지하려고 하며, 입력 데이터가 첫 번째 인자예요.
- 입력은 하나의 문자열부터 복잡한 데이터 구조까지 다양할 수 있어요. 함수는 상황에 맞게 적응해 가장 합리적인 일을 하려고 해요.

모든 Tidyverse 패키지처럼, `stringr`에도 좋은 문서가 있으며, 보통 패키지 작성자가 썼어요.

- [참고 웹사이트][ref-stringr]
- [치트시트][cheat-stringr]
- "R for Data Science"의 [한 챕터][book-strings]

#### 잠깐 다른 이야기: 파이프 빠른 입문

함수를 연결하는 파이프 `|>`의 사용은 교육 과정의 다른 부분에서 더 자세히 다뤄요.

지금은 다음을 알아 두면 유용해요:

- 파이프 왼쪽의 결과는 오른쪽 함수의 첫 번째 인자가 돼요 (여기서 "오른쪽"은 선택적인 줄 바꿈은 무시해요).
- 나머지 인자는 함수 호출에 포함할 수 있어요.
- R에서는 _이름_이 아니라 함수 _호출_로 파이프해야 하므로 괄호가 항상 필요해요 (_다른 언어와 다른 점이에요_).

아래 예시는 그 문법을 보여줘요.
개별 함수는 나중에 다뤄요.

```R
library(stringr)

"Monday-25-February" |> 
  str_split("-") |>     
  unlist() |>               # [1] "Monday"   "25"       "February"
  str_sub(1, 3) |>          # [1] "Mon" "25"  "Feb"
  str_to_upper() |>         # [1] "MON" "25"  "FEB"
  str_flatten(collapse = ", ")
#> [1] "MON, 25, FEB"
```

#### 길이 다루기

`str_length`는 코드 포인트를 세요 (`nchars`와 비슷해요).

`str_trim()`과 `str_squish()`를 포함한 여러 다른 함수가 공백을 다뤄요.
이는 데이터 과학 프로젝트를 시작할 때 흔히 중요한 정리 작업이에요.

```R
# The first 3 kernels in JuPyteR notebooks:
str_length(c("Julia", "Python", "R"))           #> [1] 1 6 5
#> [1] 5 6 1
str_pad(c("Julia", "Python", "R"), 8, "right")  # add spaces if necessary
#> [1] "Julia   " "Python  " "R       "

str_trim("Julia    Python    R    ")   # remove leading & trailing whitespace
#> [1] "Julia    Python    R"
str_squish("Julia   Python  R    ")  # trim, collapse multiple spaces 
#> [1] "Julia Python R"
```

#### 문자열 부분 추출

`str_sub(string, start, end)` 함수는 `start`부터 `end`까지 (양끝 포함)의 부분 문자열을 반환하고, `str_sub_all()`은 여러 문자열에 작용할 수 있어요.

유연성이 아주 많아요.
`start`와 `end`는 각각 첫 번째와 마지막 문자를 기본값으로 해요.
인덱스의 벡터가 될 수도 있어요.
반가운 점은, 벡터 인덱싱과 달리 음수 값은 파이썬처럼 문자열 끝에서부터 거꾸로 세요.

```R
s <- "abcdefgh"
str_sub(s, 2, 4)
#> [1] "bcd"
str_sub(s, 5)
#> [1] "efgh"
str_sub(s, -3, -2)
#> [1] "fg"
str_sub(s, c(1, 4), c(2, 5))
#> [1] "ab" "de"
str_sub(s, c(1, 4, 6), c(2, 5, -1))
#> [1] "ab"  "de"  "fgh"

s |> str_sub(2, 4) # these functions are designed for pipes
#> [1] "bcd"
```

#### 문자열 합치기

`str_flatten`은 문자 벡터를 하나의 문자열로 변환해요.
`collapse` 인자는 각 원소 사이에 삽입되고 기본값은 `""`예요.

```R
c("R", "Julia", "Python") |> str_flatten()
#> [1] "RJuliaPython"
c("R", "Julia", "Python") |> str_flatten(collapse = " - ")
#> [1] "R - Julia - Python"
```

`str_c`는 여러 문자 벡터를 하나의 문자 벡터로 변환하며, 필요에 따라 재활용해요.

```R
str_c(LETTERS[1:8], 1:8, sep = ":")
#> [1] "A:1" "B:2" "C:3" "D:4" "E:5" "F:6" "G:7" "H:8"
```

`str_glue`는 R에 간단한 문자열 보간을 가져와요.
중괄호 `{ }` 안의 표현식이 해석되고 그 텍스트 표현으로 대체돼요.

```R
r <- 5.3
pi <- 3.14159
str_glue("A circle of radius {r} has area {pi * r^2}")
A circle of radius 5.3 has area 88.2472631
```

#### 문자열 나누기

R의 아주 흔한 용도는 지저분한 데이터를 분석을 위해 일관된 형식으로 다듬는 거예요.
이를 돕기 위해 텍스트를 부분 문자열로 나누는 여러 방법이 있어요.
대부분은 지금 범위를 벗어나요.

`str_split_1`은 가장 단순해서, 하나의 문자열을 지정된 패턴(기본 패턴은 없어요)에서 나눠 조각의 벡터로 변환해요.

```R
s <- "R Julia Python"
str_split_1(s, " ")
#> [1] "R"      "Julia"  "Python"
```

#### 문자열 변형하기

일부 언어(주로 유럽 언어)는 대문자와 소문자를 구분해요.
이를 지역에 맞는 방식으로 상호 변환하는 `stringr` 함수들이 있어요:

- `str_to_lower()`
- `str_to_upper()`
- `str_to_title()` : 각 단어의 첫 글자를 대문자로
- `str_to_sentence()` : 문장의 첫 글자를 대문자로

```R
str_to_upper("elixir")    # defaults to locale = "en"
#> [1] "ELIXIR"
str_to_upper("ελληνικά")  # infers Greek
#> [1] "ΕΛΛΗΝΙΚΆ"

str_to_title("the cat sat on the mat")
#> [1] "The Cat Sat On The Mat"
str_to_sentence("the cat sat on the mat")
#> [1] "The cat sat on the mat"
```

패턴 매칭에 기반한 부분 문자열 교체에는 `str_replace()`가 패턴의 첫 번째 발생을 바꾸고, `str_replace_all()`이 모든 발생을 바꿔요.

문자 인덱싱에 기반한 부분 문자열 교체에는 str_sub()의 할당 형태가 있어요.

```R
 s <- "abcde"
str_sub(s, 3, 4) <- "yz"
s
#> [1] "abyze"
```
