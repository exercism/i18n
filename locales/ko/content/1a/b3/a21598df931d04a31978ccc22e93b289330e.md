# 테스트

  ## 간단히 살펴보기

  1. `<myFileName>.u` 파일에서 변경 사항을 만들어요
  2. `<myFileName>.u` 파일을 저장해요
  3. 파일이 타입 검사를 통과하면 `add` 또는 `update` UCM 명령을 실행해요
    * 파일이 타입 검사를 통과하지 못하면, 컴파일될 때까지 `<myFileName>.u` 파일의 코드를 수정해요. 변경한 뒤에는 함수를 `update`하는 것도 잊지 마세요!
  4. UCM CLI에서 `load <myFileName>.test.u` 명령을 실행해 테스트를 스코프로 불러오고 실행해요

  ## 자세히 살펴보기

  명령줄에서 Exercism 연습 문제를 풀고 있다면, 대부분 주어진 연습 문제의 이름을 딴 디렉터리에서 해답을 구현하게 될 거예요. 예를 들어 연습 문제가 `hello-world`라면, `~/exercism/unison/hello-world`로 `cd`한 뒤 명령줄에서 `ucm`을 열어요. `hello.u` 파일에서 구현을 수정하고, 구현이 만족스러우면 Unison 코드베이스 관리자 CLI(UCM)에서 `add` 또는 `update` 명령을 입력해 파일에 있는 작업을 코드베이스에 추가해요.

  각 연습 문제의 테스트가 담긴 파일에는 `.test.u`가 붙어요. UCM에서 `load` 명령을 사용해 테스트를 스코프로 불러오고 실행하면 돼요. `load` 명령은 파일 경로를 인자로 받아요. hello world 연습 문제라면 이렇게 해볼 수 있어요:

  ```
  .> load hello.test.u
  ```

  UCM에서 스코프로 불러온 용어들에 대한 메시지와, 더 중요하게는 테스트 실행 결과를 볼 수 있을 거예요:

  ```

    ⍟ These new definitions are ok to `add`:

      hello.test : Test.Test
      tests      : [Result]

  Now evaluating any watch expressions (lines starting with
  `>`)... Ctrl+C cancels.


    6 | test> tests = runAll [hello.test]

    🚫 FAILED
  ```

  테스트가 처음에는 통과하지 못했다고 해봐요. 다시 `myExercise.u` 파일을 편집하러 돌아가서, 저장한 뒤에는 `update`할 수 있어요

  ```
  I found and typechecked these definitions in ~/Exercism/unison/hello-world/hello.u. If you do an
  `add` or `update`, here's how your codebase would change:

    ⍟ These names already exist. You can `update` them to your new definition:

      hello : Text

  .> update

  ⍟ I've updated these names to your new definition:

    hello : Text
  ```

  이제 테스트를 다시 불러와서 뭐가 달라졌는지 확인해볼까요!

  ```
  .> load hello.test.u
    Now evaluating any watch expressions (lines starting with `>`)... Ctrl+C cancels.


    6 | test> tests = runAll [hello.test]

    ✅ Passed : Passed 1 tests.
  ```
