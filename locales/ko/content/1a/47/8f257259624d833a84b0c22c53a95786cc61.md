# 개요

Factor의 [`calendar`][calendar] 보캐뷸러리는 두 개의 튜플을 중심으로 구성돼 있어요:

- `timestamp`: 특정 시점(`year`, `month`, `day`, `hour`, `minute`, `second`, 그리고 GMT 오프셋)이에요.
- `duration`: 일정한 시간의 폭(같은 필드를 양으로 사용해요)이에요.

## 타임스탬프

`<date>`는 자정을 나타내는 타임스탬프를 만들고, `>date<`는 그것을 다시 나눠요:

```
<date> ( year month day -- timestamp )
>date< ( timestamp -- year month day )
```

```factor
USING: calendar ;

2024 7 14 <date> >date< .   ! => 14   (2024 and 7 below it)
```

자주 쓰는 질의:

```factor
USING: calendar calendar.english sequences ;

2024 1 8 <date> day-of-week .          ! => 1   (0 = Sunday .. 6 = Saturday)
2024 1 8 <date> day-of-week day-names nth .   ! => "Monday"
2024 leap-year? .                      ! => t
2024 2 1 <date> days-in-month .        ! => 29
```

`day-names`(그리고 `month-names`)는 [`calendar.english`][english]에 있어요.

## duration과 연산

`days`, `weeks`, `hours`, `minutes` 같은 워드들은 `duration`을 만들고, `time+` / `time-`는 타임스탬프를 그만큼 이동시켜요:

```
days  ( x -- duration )
time+ ( timestamp duration -- timestamp )
```

```factor
2024 2 28 <date> 1 days time+ >date< .   ! => 29   (2024-02-29)
```

연산은 월과 연의 경계를 넘어 이어지고, 같은 순간을 가리키는 두 타임스탬프는 `=`로 비교하면 서로 같아요.

이 밖에도 `calendar`는 하루 중의 시각(`set-time`, `+hour`), 시간대 변환(`>gmt`, `>local-time`), 현재 시각(`now`), 그리고 `calendar.format`을 통한 파싱과 포매팅을 제공해요.
