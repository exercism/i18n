# 디버깅

디버깅에 도움이 되도록, 모든 콘솔 출력이 캡처되어 테스트 결과 창에 표시된다는 점을 활용할 수 있어요.
`@show`에 값을 넘겨서 어떤 값이든 출력할 수 있어요.

`@show`는 표현식과 그 결과를 보여주면서, 그 결과를 반환해요.

```julia
@show uppercase("hello") # HELLO will be shown as debug output
```

```julia-repl
julia> function f(a, b)
           @show a b
           return (@show a^b) / 1000
       end
f (generic function with 1 method)

julia> f(3, 5)
a = 3
b = 5
a ^ b = 243
0.243
```

[`println`](https://docs.julialang.org/en/v1/base/io-network/#Base.println)이나 [`stdout`](https://en.wikipedia.org/wiki/Standard_streams#Standard_output_(stdout))에 출력을 쓰는 다른 어떤 메서드를 사용할 수도 있어요.
