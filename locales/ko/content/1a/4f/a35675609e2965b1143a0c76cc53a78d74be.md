# 소개
## `switch`문

[`switch`문][switch]을 사용하면 하나의 값을 여러 가지 가능한 값과 비교할 수 있어요.
여러 개의 `else-if`문을 사용하는 것보다 더 간결한 코드를 작성할 수 있게 해줘요.
`switch`문은 `switch` 키워드로 시작하고, 그 뒤에 비교할 값이 와요.
그다음 `case` 키워드 뒤에 비교 대상이 될 값을 적어 각 경우를 정의할 수 있어요.
`default` 키워드는 어떤 `case`와도 일치하지 않을 때 기본 경우를 정의하는 데 사용해요.
`else-if`문과 마찬가지로, `switch`문은 가장 먼저 일치하는 `case`와 연결된 코드 블록만 실행해요.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

다음 예시를 살펴봐요:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

이 코드는 다음과 같이 다시 쓸 수 있어요:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## `while`문

[`while`문][while-loops]은 특정 조건이 참인 동안 코드를 실행할 수 있게 해 주는 제어 흐름 문이에요.
Swift는 두 가지 종류의 `while`문을 제공해요: `while`문과 `repeat-while`문이에요.
`while`문은 루프 본문이 실행되기 전에 조건을 먼저 평가해요. 조건이 거짓이면 루프 본문은 아예 실행되지 않아요.
Swift의 `while`문은 다음과 같은 구조를 가져요:

```swift
while <#condition#> {
  <#code#>
}
```

여기서 루프는 count가 0보다 큰 동안 실행되며, 그에 따라 숫자 2, 1과 "Liftoff!"가 출력돼요.

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

[`repeat-while`문][while-loops]은 `while`문과 비슷하지만, 루프 본문이 실행된 뒤에 조건을 평가해요.
즉, 조건이 거짓이더라도 루프 본문은 항상 적어도 한 번은 실행돼요.
Swift의 `repeat-while`문은 다음과 같은 구조를 가져요:

```swift
repeat {
  <#code#>
} while <#condition#>
```

여기서는 조건이 거짓이기 때문에 루프가 한 번만 실행돼요.
`repeat-while`문이기 때문에 루프 본문은 조건이 평가되기 전에 한 번 실행돼요.

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```

## 제어 전달

Swift에는 루프의 일반적인 제어 흐름을 바꾸는 데 사용할 수 있는 문들이 있어요.
이런 것들을 제어 전달문이라고 해요.
`return`은 이미 봤고, 이번 개념에서는 `continue`, `break`, 레이블 같은 다른 것들을 소개해요.
이번 개념에서는 `fallthrough`는 다루지 않지만, [Swift 책][fallthrough]에서 읽어볼 수 있어요.

### `continue`

때로는 루프의 현재 반복에서 나머지 문을 모두 실행하지 않고, 다음 반복으로 일찍 건너뛰어야 할 때가 있어요.
이때 `continue` 키워드를 사용할 수 있어요.
`continue`가 실행되면 루프는 다음 반복을 실행할 수 있는지 확인하는 지점으로 넘어가요. 즉, `while`문과 `repeat-while`문에서는 `while` 부분이고, `for-in`문에서는 시퀀스에 다음 요소가 있는지 확인하는 부분이에요.

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

### `break`

`break`는 루프를 일찍 빠져나가는 데 사용해요.
`break`가 실행되면 루프는 즉시 종료되고, 프로그램은 루프 다음의 첫 번째 문부터 계속 실행해요.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

### 레이블

루프가 중첩되어 있을 때에는, `break`나 `continue`가 사용된 루프를 감싸는 바깥쪽 루프를 종료하거나 다시 시작하기 위해 `break`나 `continue`를 사용하고 싶을 때가 있어요.
이런 경우 레이블을 사용해 종료하거나 다시 시작할 루프를 지정할 수 있어요.
루프를 시작하는 `while`, `repeat`, `for` 앞에 이름과 콜론을 붙이면 루프에 레이블을 달 수 있어요.

이렇게 레이블을 사용했을 때의 효과를 보려면 다음 루프를 살펴봐요.

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```
