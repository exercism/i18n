## 2. 임의의 반복자에서 짝수 항목을 반환하는 반복자 어댑터 `evens`를 작성해요

- 제안된 메서드들을 그대로 연결하기만 하면 잘 동작해요.
- 숫자 `n`은 `n % 2 == 0`이면 짝수예요.
- 클로저는 문법을 줄여 쓴 함수예요. 인자 이름을 `|` 기호 두 개 사이에 쓰고, 그 뒤에 표현식이 와요.
  일반 함수와 달리 각 인자의 타입을 항상 명시할 필요는 없고, 이름만 써도 돼요.
  예를 들어, 홀수의 제곱을 만들어 내는 반복자는 이렇게 만들 수 있어요: `(0..).map(|n| 2 * n + 1).map(|n| n * n)`.

## 3. `Position` 튜플 구조체에 `manhattan` 메서드를 구현해요

- 메서드 문법은 걱정하지 마세요. `impl Position` 블록 안의 `todo` 부분만 바꾸면 알아서 잘 동작해요.
- `Position` 안의 값 중에는 음수가 있을 수 있지만, 거리는 절대 음수가 될 수 없다는 점을 기억해요.
- 절댓값 계산은 언젠가 Cairo에서 기본으로 지원될 예정이에요. 그때까지는 사용할 수 있는 헬퍼 트레이트를 준비해 두었어요.
