# 소개

## 정수

Gleam에는 정수와 실수, 두 가지 종류의 숫자가 있어요.

정수는 소수점이 없는 수예요.

```gleam
let integer = 3
// -> 3
```

Gleam에는 정수를 다루는 여러 연산자가 있어요.

```gleam
1 + 1 // -> 2
5 - 1 // -> 4
5 / 2 // -> 2
3 * 3 // -> 9
5 % 2 // -> 1

2 > 1  // -> True
2 < 1  // -> False
2 >= 1 // -> True
2 <= 1 // -> False
```

## 실수

실수는 소수점 뒤에 숫자가 하나 이상 있는 수예요.

```gleam
let float = 3.45
// -> 3.45
```

실수에도 전용 연산자가 있어요.

```gleam
1.0 +. 1.4 // -> 2.4
5.0 -. 1.5 // -> 3.5
5.0 /. 2.0 // -> 2.5
3.0 *. 3.1 // -> 9.3

2.0 >. 1.0  // -> True
2.0 <. 1.0  // -> False
2.0 >=. 1.0 // -> True
2.0 <=. 1.0 // -> False
```

## 모듈

### 모듈

Gleam 코드는 모듈로 구성되어 있고, 파일 하나가 하나의 Gleam 모듈이에요.

지금까지는 `pub fn` 문법으로 함수를 작성했는데, 이렇게 정의한 함수는 다른 모듈에서도 공개적으로 사용할 수 있어요. `fn`으로 정의한 함수는 정의된 모듈 안에서만 쓸 수 있는 비공개 함수라서 다른 모듈에서는 사용할 수 없어요.

```gleam
// This function is public
pub fn add(x, y) {
  x + y
}

// This function is private
fn subtract(x, y) {
  x - y
}
```

Gleam 모듈에는 이름이 있고, 그 이름은 `src`나 `test` 디렉터리 안에서의 파일 경로를 바탕으로 정해져요.

예를 들어 `src\geometry\rectangle.gleam`(Windows)이나 `src/geometry/rectangle.gleam`(UNIX 계열 운영체제)에 정의된 모듈의 이름은 `geometry/rectangle`이에요.

### 다른 모듈에서 함수 임포트하기

다른 모듈에 정의된 함수에 접근할 때는 임포트를 사용해요. 모듈을 임포트하면 그 모듈이 공개한 모든 함수를 사용할 수 있게 되는데, 함수에 접근하는 방식은 모듈을 어떻게 임포트하느냐에 따라 달라져요.

모듈 이름을 앞에 붙이는 임포트가 기본 방식이에요. 이렇게 임포트한 모듈 안의 함수(예를 들어 `gleam/list` 모듈의 `map` 함수)는 모듈 이름을 앞에 붙여 접근해요(`list.map`).

```gleam
// Import the int module
import gleam/int

pub fn run(x: Int) -> String {
  // Use the to_string function from the int module
  int.to_string(x)
}
```

기본적으로 모듈을 가리키는 데 쓰는 이름은 모듈 이름의 마지막 부분이고, 여기서는 `int`인데, `as` 키워드를 쓰면 이 이름을 바꿀 수 있어요.

```gleam
// Import the int module and refer to it as i
import gleam/int as i

pub fn run(x: Int) -> String {
  i.to_string(x)
}
```

이름을 붙이지 않는 임포트를 하면 그 모듈이 공개한 함수에 접두사 없이 바로 접근할 수 있어요.

```gleam
// Import the to_string function from the int module
import gleam/int.{to_string}

pub fn run(x: Int) -> String {
  to_string(x)
}
```

모듈 이름을 붙이는 임포트가 더 선호되는데, 함수가 어디에서 왔는지 읽는 사람이 더 명확히 알 수 있고 이름 충돌도 피할 수 있기 때문이에요.


### 표준 라이브러리

Gleam에는 풍부하고 문서가 잘 갖춰진 표준 라이브러리가 있어요. 문서는 [hexdocs.pm/gleam_stdlib][docs]에서 온라인으로 볼 수 있어요. 이 링크를 어딘가에 저장해 두세요. 정말 자주 쓰게 될 거예요!

대부분의 내장 데이터 타입에는 그 타입을 다루는 함수를 제공하는 모듈이 함께 있어요. 예를 들어 정수를 위한 `gleam/int` 모듈, 문자열을 위한 `gleam/string` 모듈, 배열을 위한 `gleam/list` 모듈 등이 있어요.

[docs]: https://hexdocs.pm/gleam_stdlib/
