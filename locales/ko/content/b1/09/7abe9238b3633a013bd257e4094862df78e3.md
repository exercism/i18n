# 안내

Alizé는 온라인 패션 부티크를 운영해요. 곧 큰 연례 세일이 다가오는데, 재고를 파악하는 데 도움이 될 기능을 몇 가지 만들고 싶어 해요.

재고에 있는 아이템 하나는 사용자 정의 타입으로 표현해요.

```gleam
Item(
  name: "White Shirt",
  price: 40,
  quantity: 6,
)
```

## 1. 아이템들의 이름 배열을 반환해요

`item_names` 함수를 구현해요. 이 함수는 아이템들의 이터레이터를 받아서, 아이템들의 이름으로 이루어진 이터레이터를 같은 순서로 반환해요.

```gleam
[
  Item(price: 65, name: "Maxi Brown Dress", quantity: 8),
  Item(price: 50, name: "Red Short Skirt", quantity: 0),
  Item(price: 29, name: "Black Short Skirt", quantity: 4),
  Item(price: 20, name: "Bamboo Socks Cats", quantity: 7),
]
|> iterator.from_list
|> item_names
|> iterator.to_list

// -> ["Maxi Brown Dress", "Red Short Skirt", "Black Short Skirt", "Bamboo Socks Cats"]
```

## 2. 저렴한 아이템을 반환해요

`cheap` 함수를 구현해요. 이 함수는 아이템들의 이터레이터를 받아서, 가격이 30 미만인 아이템들의 이터레이터를 반환해요.

```gleam
[
  Item(price: 65, name: "Maxi Brown Dress", quantity: 8),
  Item(price: 50, name: "Red Short Skirt", quantity: 0),
  Item(price: 29, name: "Black Short Skirt", quantity: 4),
  Item(price: 20, name: "Bamboo Socks Cats", quantity: 7),
]
|> iterator.from_list
|> cheap
|> iterator.to_list

// -> [
//   Item(price: 29, name: "Black Short Skirt", quantity: 4),
//   Item(price: 20, name: "Bamboo Socks Cats", quantity: 7),
// ]
```

## 3. 재고가 없는 아이템을 반환해요

`out_of_stock` 함수를 구현해요. 이 함수는 재고가 없는 아이템들을 반환해요.

```gleam
[
  Item(price: 65, name: "Maxi Brown Dress", quantity: 8),
  Item(price: 50, name: "Red Short Skirt", quantity: 0),
  Item(price: 29, name: "Black Short Skirt", quantity: 4),
  Item(price: 20, name: "Bamboo Socks Cats", quantity: 7),
]
|> iterator.from_list
|> out_of_stock
|> iterator.to_list

// -> [
//   Item(price: 50, name: "Red Short Skirt", quantity: 0),
// ]
```

## 4. 전체 재고를 반환해요

`total_stock` 함수를 구현해요. 이 함수는 창고에 있는 아이템의 총 개수를 계산해요:

```gleam
[
  Item(price: 65, name: "Maxi Brown Dress", quantity: 8),
  Item(price: 50, name: "Red Short Skirt", quantity: 0),
  Item(price: 29, name: "Black Short Skirt", quantity: 4),
  Item(price: 20, name: "Bamboo Socks Cats", quantity: 7),
]
|> iterator.from_list
|> total_stock

// -> 19
```
