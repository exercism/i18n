# 힌트

## 일반

- 읽기와 쓰기에 쓰이는 워드는 모두 [`io.files`][io.files]에 있고, 이들이 공통으로 받는 `utf8` 인코딩은 [`io.encodings.utf8`][utf8]에서 와요.

## 1. 모든 관측값 읽기

- `file-lines`는 줄바꿈 문자가 제거된 줄들의 배열을 반환해요.

## 2. 가장 최근 관측값 찾기

- `file-lines`로 줄을 읽고, 그다음 `last`(`sequences`에 있어요)로 마지막 줄을 가져와요.

## 3. 원본 로그 읽기

- `file-contents`는 줄바꿈까지 포함해 파일 전체를 하나의 문자열로 반환해요.

## 4. 관측값 기록하기

- 파일을 추가 모드로 열고, 쿼테이션 안에서 관측값을 `print`해요: `with-file-appender ( path encoding quot -- )`. 관측값은 쿼테이션 안에서 쓰이고 경로는 그보다 먼저 소비되므로, `::` 로컬 변수를 쓰면 본문을 읽기 쉽게 유지할 수 있어요: `:: record-reading ( reading path -- ) path utf8 [ reading print ] with-file-appender ;`.

## 5. 로그 다시 쓰기

- `set-file-lines`는 시퀀스의 각 원소를 각각 한 줄에 쓰면서 줄바꿈 문자를 알아서 넣어 줘요.
