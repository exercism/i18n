# 소개

바이너리 데이터를 다루는 일은 어떤 언어에서나 중요한 개념이에요. Elixir는 바이너리 데이터를 작성하고, 매칭하고, 구성할 수 있는 우아한 문법을 제공해요.

Elixir에서는 바이너리 데이터를 비트 문자열 타입이라고 불러요. 바이너리 데이터 _타입_은(일반적인 바이너리 데이터와 혼동하면 안 돼요) 비트 문자열의 한 가지 특정한 형태인데, 나중에 나오는 연습 문제에서 다뤄요.

비트 문자열 리터럴은 `<<>>`이라는 비트 문자열 특수 형식을 사용해서 정의해요. 비트 문자열 리터럴을 정의할 때는 여러 세그먼트로 나눠서 정의하는데, 각 세그먼트는 값과 타입을 가지고 둘은 `::` 연산자로 구분해요. 타입은 값을 인코딩하는 데 몇 비트가 쓰일지 지정해요. 타입은 아예 생략할 수도 있는데, 그러면 기본값으로 8비트 정수가 돼요.

```elixir
# This defines a bitstring with three segments of a single bit each
<<0::1, 1::1, 0::1>>
```

타입을 `::1`이라고 쓰는 것은 `::size(1)`이라고 쓰는 것의 축약형이에요. 비트 크기가 변수에서 온다면 더 긴 문법을 써야 해요.

## 바이너리

바이너리 정수 리터럴을 작성할 때는 리터럴 앞에 `0b`를 붙여서 2진 표기법으로 바로 쓸 수 있어요. 참고로 이런 리터럴은 테스트 결과로 출력되거나 iex에서 볼 때 어차피 10진수로 표시돼요.

```elixir
<<0b1011::4>> == <<11::4>>
# => true
```

## 잘라내기

세그먼트의 값이 그 세그먼트 타입이 감당할 수 있는 범위를 넘어서면, 값은 왼쪽에서부터 잘려 나가요.

```elixir
<<0b1011::3>> == <<0b0011::3>>
# => true
```

## 앞에 추가하기와 뒤에 추가하기

특수 형식을 사용하면 기존 비트 문자열의 앞에도, 뒤에도 값을 추가할 수 있어요. 크기를 모르는 비트 문자열이라면 기존 비트 문자열에 `::bitstring` 타입을 써야 해요.

```elixir
value = <<0b110::3, 0b001::3>>
new_value = <<0b011::3, value::bitstring, 0b000::3>>
# => <<120, 8::size(4)>>
```

## 이어 붙이기

특수 형식을 사용하면 변수에 담긴 비트 문자열끼리 이어 붙일 수 있어요. 크기를 모르는 비트 문자열 두 개를 이어 붙일 때는 `::bitstring` 타입을 써야 해요.

```elixir
first = <<0b110::3>>
second = <<0b001::3>>
concatenated = <<first::bitstring, second::bitstring>>
# => <<49::size(6)>>
```

## 패턴 매칭

패턴 매칭으로 특수 형식에서 값을 꺼낼 수도 있어요. 값을 가져오려는 각 조각이 몇 비트인지 알아야 하는데, 예외가 하나 있어요. `::bitstring` 타입은 크기를 모르는 비트 문자열에 패턴 매칭할 때 쓸 수 있지만, 마지막 조각에만 사용할 수 있어요.

```elixir
<<value::4, rest::bitstring>> = <<0b01101001::8>>
value == 0b0110
# => true
```

## 비트 문자열 살펴보기

~~~~exercism/note
비트 문자열은 (테스트 러너나 iex에서) 만들어질 때 사용한 형식과는 다른 형식으로 출력될 수 있어요. 비트 문자열을 배울 때 이런 점이 자주 혼란을 일으켜요.
~~~~

기본적으로 비트 문자열은 8비트(1바이트) 조각 단위로 표시되는데, 다른 크기의 조각으로 만들었더라도 마찬가지예요.

```elixir
<<2011::11>>
# => <<251, 3::size(3)>>
```

출력 가능한 UTF-8 인코딩 문자열을 나타내는 비트 문자열을 만들면, 문자열로 표시돼요.

```elixir
<<>>
# => ""

<<65, 66, 67>>
# => "ABC"
```
