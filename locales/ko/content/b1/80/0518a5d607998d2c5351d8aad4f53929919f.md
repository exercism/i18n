# 지침

Lisp 외계인 릴리는 도와주신 덕분에 라자냐를 정말 많이 만들었어요. 고마운 마음을 담아 남은 라자냐를 나눠 주고 싶어 해요. 그런데 그전에, 함께 만든 함수 중 하나에 대해 전하고 싶은 이야기가 있대요.

이 연습 문제에서는 릴리의 라자냐 요리를 돕고, 남은 라자냐를 함께 나누는 일도 돕기 위해 함수를 몇 개 더 작성해요.

과제는 여섯 개예요. 세 개는 기존 라자냐 요리 함수를 개선하는 것이고, 나머지 세 개는 남은 라자냐를 나누는 것에 관한 거예요.

## 1. `preparation-time-in-minutes` 함수를 더 쓰기 편하게 만들기

릴리는 `preparation-time-in-minutes` 함수를 쓰려면 호출하기 전에 겹을 전부 세어야 해서 조금 불편했다고 해요. 그래서 겹을 몇 개든 인자로 받아서, 겹이 몇 개였는지에 따라 준비 시간을 계산하는 함수 버전을 만들어 줄 수 있겠느냐고 물어봐요. 참고로, 겹 하나를 준비하는 데는 19분이 걸려요.

```lisp
(preparation-time 'sauce 'cheese 'right-handed-macaroni 'cheese 'sauce
                  'left-handed-macaroni 'sauce 'sauce 'cheese 'cheese)
                  ;; => 190 (because there are 10 layers.)
```

## 2. 예상 오븐 조리 시간을 바꿀 수 있게 하기

릴리의 부모님은 늘 라자냐를 337분 동안 조리했지만, 릴리도 다른 Lisp 외계인들은 라자냐를 더 길거나 더 짧은 시간 동안 조리하는 걸 좋아한다는 점은 인정해요.

그래서 `remaining-minutes-in-oven`이 `expected-minutes-in-oven`을 쓰는 대신, 시간이 더 길어야 하는지, 아주 길어야 하는지, 더 짧아야 하는지, 아주 짧아야 하는지를 정하는 _선택적_ 매개변수를 받을 수 있으면 좋겠어요. 더 길거나 더 짧다는 건 기본 시간 337에서 100을 더하거나 뺀다는 뜻이에요. 아주 길거나 아주 짧다는 건 200을 더하거나 빼는 거고요. 매개변수를 주지 않거나 인자가 'normal'이면 기본값 337을 반환해야 해요.

```lisp
(remaining-minutes-in-oven)             ;; => 337
(remaining-minutes-in-oven :normal)     ;; => 337
(remaining-minutes-in-oven :shorter)    ;; => 237
(remaining-minutes-in-oven :very-short) ;; => 137
(remaining-minutes-in-oven :longer)     ;; => 437
(remaining-minutes-in-oven :very-long)  ;; => 537
```

## 3. 릴리가 떠올린 또 다른 선호 조리법

그 변경을 막 마쳤을 때, 릴리가 _아주 짧은_ 조리 시간을 좋아하는 Lisp 외계인들도 있다는 걸 떠올려요. 사실상 날것으로 먹고 싶어 하는 거예요. 그래서 이제 함수는 `NIL`이 인자로 들어오면 0을, 그 외에는 이전 과제와 같은 값을 반환해야 해요.

```lisp
(remaining-minutes-in-oven)     ;; => 337
(remaining-minutes-in-oven nil) ;; => 0
```

## 4. 남은 라자냐 나누기

라자냐 요리 함수를 개선하는 걸 도와줬더니 이제 _라자냐가 아주 많아요_! 릴리는 그동안의 도움에 보답하려고 남은 라자냐를 나누고 싶어 해요. 여기서는 매개변수 세 개를 받는 함수를 작성해야 해요. 남은 라자냐의 총량, 릴리가 찬장에서 찾은 남은 라자냐 용기의 개수, 그리고 여러분 몫으로 똑같이 찾은 용기의 개수예요.

남은 라자냐 용기를 찾는 데 걸리는 시간이 저마다 다를 수 있고, 남은 라자냐의 정확한 양은 릴리와 함께 각자 찬장을 뒤지는 동안에 정해질 수 있기 때문에, 두 사람은 함수가 인자를 어떤 순서로든 받아야 한다는 데 의견을 모았어요. 그래야 숫자가 하나씩 정해질 때마다 적어 둘 수 있거든요. 세 숫자가 모두 모이면 함수 호출의 괄호를 닫고 그대로 실행하면 돼요.

이 함수는 남고 남은 라자냐의 양, 즉 남은 라자냐의 무게와 릴리와 여러분이 찾은 용기의 총 개수 사이의 차이를 반환해야 해요.

```lisp
(split-leftovers :weight 20 :human 10 :alien 5) ;; => 5
(split-leftovers :weight 20 :alien 10 :human 2) ;; => 8
(split-leftovers :alien 12 :weight 20 :human 4) ;; => 4
```

## 5. 가정하기

각자의 찬장을 몇 번씩 오가며 뒤진 끝에, 두 사람은 지정되지 않았다면 여러분이나 릴리가 용기를, 이를테면 10개쯤 가지고 있다고 함수가 그냥 _가정_해 주면 좋겠다는 데 의견을 모았어요.

```lisp
(split-leftovers :weight 20 :human 5) ;; => 5
(split-leftovers :weight 20 :alien 5) ;; => 5
(split-leftovers :weight 20)          ;; => 0
```

## 6. 남은 라자냐의 기본 양

더 나아가 함수가 남은 라자냐가 용기에 다 들어갈 만큼 충분하다고 _가정_할 수도 있어요. 그래서 무게가 주어지지 않으면 함수는 `:just-split-it`을 반환해야 해요. _하지만_ 무게가 주어졌는데 그 값이 `nil`이면 `:looks-like-someone-was-hungry`를 반환해야 하고요.

```lisp
(split-leftovers :human 5 :alien 5) ;; => :JUST-SPLIT-IT
(split-leftovers :weight NIL :human 5 :alien 5) ;; => :LOOKS-LIKE-SOMEONE-WAS-HUNGRY
```
