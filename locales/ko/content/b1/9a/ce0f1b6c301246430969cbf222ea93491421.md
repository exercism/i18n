# 개요

Haxe의 [문자열][strings]은 텍스트를 유니코드 문자(글자, 숫자, 문장 부호 등)의 나열로 나타내는 불변 객체예요. `string` 인스턴스를 정의할 때는 큰따옴표를 사용해요:

```haxe
var fruit:String = "Apple";
```

문자열을 조작하려면 [메서드나 프로퍼티][string-api] 중 하나를 호출하면 돼요. 문자열 값은 한 번 정의되면 절대 바뀌지 않기 때문에, 모든 문자열 조작 메서드는 새로운 문자열을 반환해요.

문자열은 큰따옴표(`"`) 문자로 감싸요. 일부 특수 문자는 백슬래시(`\`) 문자를 사용해 [이스케이프][escaping]해야 해요. 또한 Haxe의 문자열은 여러 줄에 걸쳐 쓸 수 있어서 긴 문자열 리터럴을 쉽게 만들 수 있어요:

```haxe
var escaped:String = "c:\\test.txt";
var multiline:String = "
- apple
- pear
- banana";
```

문자열을 연결하는 가장 간단한 방법은 [`+` 연산자][plus-operator]를 사용하는 거예요.

```haxe
var name:String = "Jane";
trace("Hello " + name + "!");
// => "Hello Jane!"
```

더 복잡한 문자열 서식이 필요할 때는 [문자열 보간][interpolation]이 더 좋아요. 문자열을 작은따옴표(`'`)로 감싸고 달러 기호(`$`)로 변수 보간을 시작하면 돼요. `${expr}`를 사용하면 표현식 전체를 평가할 수도 있는데, 여기서 `expr`은 유효한 Haxe 표현식이면 무엇이든 돼요:

```haxe
var name:String = "Jane";
trace('Hello $name!');
// => "Hello Jane!"
trace('HELLO ${name.toUpperCase()}!');
// => "HELLO JANE!"
```
