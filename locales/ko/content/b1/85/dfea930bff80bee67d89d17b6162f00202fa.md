# Instructions append

## 레지스터

| 레지스터 | 용도     | 타입    | 설명                                       |
| -------- | --------- | ------- | ------------------------------------------- |
| `$a0`    | 입력      | 주소    | 널 문자로 끝나는 16진수 문자 문자열         |
| `$v0`    | 출력      | 정수    | 입력 문자열의 10진수 값                     |
| `$t0-9`  | 임시      | 아무 값 | 임시 값을 저장하는 데 사용                  |
