# 제네릭 클래스

`ARRAY{STR}`, `FMAP{STR,INT}`, `FSET{STR}` 같은 것들은 초반부터 사용해 왔어요. 중괄호 안에는 항상 타입이 들어 있었죠. 이제는 클래스가 자기만의 중괄호를 갖도록 작성해 봐요.

## 문제

분실물 보관소에는 물건 하나를 담아 두고, 누가 맡겼는지도 기억하는 상자가 필요해요. 점퍼를 담는 상자는 이렇게 생겼어요.

```sather
class JUMPER_BOX is
   attr item : JUMPER;
   ...
end;
```

그리고 물병을 위해서도 같은 클래스를 또 쓰고, 휴대폰을 위해서도 또 써요. 한 단어만 다른 세 개의 복사본이죠.

## 타입 매개변수

```sather
class LOST_BOX{T} is

   attr item : T;

   create(thing : T) : SAME is
      box ::= new;
      box.item := thing;
      return box;
   end;

end; -- class LOST_BOX{T}
```

클래스 이름 뒤에 붙은 `{T}`가 바로 **타입 매개변수**예요. `T`는 타입이 아니에요. 클래스를 사용할 때 넘겨주는 타입을 대신하는 자리 표시자일 뿐이죠. 클래스 안에서는 `T`를 다른 타입 이름과 똑같이 사용해요.

## 사용해 보기

타입은 중괄호 안에 넣어서 넘겨줘요.

```sather
   jumper ::= #LOST_BOX{STR}("blue jumper");
   count ::= #LOST_BOX{INT}(3);

   jumper.item      -- "blue jumper", a STR
   count.item       -- 3, an INT
```

`LOST_BOX{STR}`과 `LOST_BOX{INT}`는 서로 다른 두 타입이에요. 한쪽이 필요한 자리에 다른 쪽을 넣으면 컴파일러가 잡아내는 오류가 나요. 마치 두 클래스를 손으로 직접 써 놓은 것과 똑같죠. 실제로 그렇게 동작해요. Sather는 실제로 사용된 타입마다 이 패턴으로부터 별도의 클래스를 만들어 내거든요.

그래서 실행 시점에는 비용이 전혀 들지 않고, 타입 정보도 잃지 않아요. `jumper.item`은 정말로 `STR`이지, 검사하거나 변환해야 하는 무언가가 아니에요.

## 매개변수가 여러 개일 때

클래스는 쉼표로 구분된 여러 개의 매개변수를 받을 수 있어요. 이미 알고 있는 예가 바로 `FMAP{K,T}`예요.

```sather
class LABELLED{L,T} is
   attr label : L;
   attr item : T;
   ...
end;
```

## 이름 짓기

관례적으로 대문자 한 글자를 써요. `T`는 사물을, `K`는 키를, `E`는 원소를 나타내죠. 라이브러리에서도 이 이름들을 곳곳에서 사용해요.
