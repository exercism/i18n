# 지침

이 연습 문제에서는 자동차 공장의 조립 라인을 분석하는 코드를 작성해요.

## 1. 한 시간에 생산되는 정상 차량 수 계산하기

시간당 생산되는 자동차 수와 성공률을 입력받아, 한 시간에 성공적으로 만들어진 자동차 수를 계산하는 함수를 구현해요. 성공률은 `0`부터 `100`까지의 백분율로 주어져요:

```lua
cars.calculate_working_cars_per_hour(1547, 90)
--> => 1392.3
```

**참고:** 반환값은 실수여야 해요.

## 2. 1분에 생산되는 정상 차량 수 계산하기

시간당 생산되는 자동차 수와 성공률을 입력받아, 1분마다 성공적으로 생산되는 자동차 수를 계산하는 함수를 구현해요:

```lua
cars.calculate_working_cars_per_minute(1105, 90)
-- => 16
```

**참고:** 반환값은 정수여야 해요.

## 3. 생산 비용 계산하기

각 자동차는 성공 여부와 관계없이 개별적으로 생산할 때 보통 $10.000이 들어요. 하지만 조금만 계획을 세우면 자동차 10대를 $95.000에 함께 생산할 수 있어요. 예를 들어 자동차 37대는 다음과 같이 생산할 수 있어요:
37 = 3 x 10대 묶음 + 7대 개별 차량

그래서 자동차 37대의 비용은 다음과 같아요:
3 \* 95,.000 + 7 \* 10.000 = 355.000

성공 여부와 관계없이 여러 대의 자동차를 생산하는 비용을 계산하는 함수를 구현해요:

```lua
cars.calculate_cost(37)
-- => 355000

cars.calculate_cost(21)
-- => 200000
```

**참고:** 반환값은 정수여야 해요.
