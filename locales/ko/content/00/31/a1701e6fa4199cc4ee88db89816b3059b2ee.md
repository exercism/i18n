# 소개

Go에서 `string`은 변경할 수 없는 바이트의 나열이에요. 이 바이트가 꼭 문자를 나타내야 하는 것은 아니에요.

문자열 리터럴은 큰따옴표 사이에 정의해요:

```go
const name = "Jane"
```

문자열은 `+` 연산자로 연결할 수 있어요:

```go
"Jane" + " " + "Austen"
// => "Jane Austen"
```

일부 특수 문자는 앞에 백슬래시를 붙여 이스케이프해야 해요. 예를 들어 문자열에서 탭은 `\t`, 줄 바꿈은 `\n`으로 나타내요.

```go
"How is the weather today?\nIt's sunny"  
// =>
// How is the weather today?
// It's sunny
```

`strings` 패키지에는 문자열을 다루는 유용한 함수가 많이 들어 있어요.
문자열 함수에 대해 더 알고 싶다면 [strings 패키지 문서](https://pkg.go.dev/strings)를 확인해 봐요.
다음은 몇 가지 예시예요:

```go
import "strings"

// strings.ToLower returns the string given as argument with all its characters lowercased
strings.ToLower("MaKEmeLoweRCase")
// => "makemelowercase"

// strings.Repeat returns a string with a substring given as argument repeated many times
strings.Repeat("Go", 3)
// => "GoGoGo"
```
