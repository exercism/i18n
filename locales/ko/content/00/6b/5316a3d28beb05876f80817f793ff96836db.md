# 개요

Elixir에서는 함수를 동적으로 디스패치할 수 있어요.

모든 모듈 이름은 아톰이에요. Elixir 모듈 이름에는 컴파일할 때 자동으로 `Elixir.` 접두사가 붙어요.

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```

Elixir에서는 모듈 이름으로 조회를 수행해서 런타임에 호출할 함수를 찾아낼 수 있어요. 모듈 이름이 변수에 바인딩되어 있다면 그 조회를 동적으로 할 수 있어요.

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```
