# 소개

*정규 표현식*(regex)은 어떤 텍스트가 어떤 모습이어야 하는지를 설명하는 작은 패턴이에요. Factor의 정규식 도구는 [`regexp`][regexp] 보카불러리에 있고, 패턴은 `R/ `와 `/` 사이에 작성해요.

패턴에 있는 대부분의 문자는 자기 자신을 의미해요. 몇 가지 특별한 조각은 문자의 *종류*를, 또는 *몇 개*를 기대하는지를 나타내요:

```
\d        ! any digit 0–9
\s        ! any whitespace; \S means any non-whitespace
[A-Z]     ! any one capital letter
.         ! any single character

{4}       ! exactly 4 times       +   ! one or more
{2,5}     ! 2 to 5 times          *   ! zero or more
?         ! optional (0 or 1)
```

따라서 `R/ [A-Z]{2}-\d{4}/`는 "대문자 두 개, 하이픈 하나, 숫자 네 개"를 의미해요.

`matches?`는 *전체* 문자열이 패턴에 맞는지 검사해요:

```
matches? ( string regexp -- ? )
```

```factor
USING: regexp ;

"NS-1024" R/ [A-Z]{2}-\d{4}/ matches? .   ! => t
"NS-10"   R/ [A-Z]{2}-\d{4}/ matches? .   ! => f
```

다른 워드들은 문자열 *내부*를 살펴봐요: `all-matching-subseqs`는 일치하는 것을 모두 반환하고, `count-matches`는 그 개수를 세고, `re-contains?`는 일치하는 것이 있는지 알려주고, `re-replace`는 각 일치를 새 텍스트로 바꿔요:

```
all-matching-subseqs ( string regexp -- seq )
count-matches        ( string regexp -- n )
re-contains?         ( string regexp -- ? )
re-replace           ( string regexp replacement -- result )
```

```factor
USING: regexp ;

"seen NS-1024 then AB-0007" R/ [A-Z]{2}-\d{4}/ all-matching-subseqs .
! => { "NS-1024" "AB-0007" }

"user=alice pass=hunter2" R/ pass=\S+/ "pass=****" re-replace .
! => "user=alice pass=****"
```
