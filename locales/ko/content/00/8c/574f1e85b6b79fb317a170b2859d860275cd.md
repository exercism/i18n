# 기초

Sather 프로그램은 **클래스**로 이루어져 있어요. 클래스는 루틴을 담는, 이름이 붙은 상자예요. **루틴**은 결과를 만들어 내는, 이름이 붙은 작업 단위예요.

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

end; -- class GREETER
```

위에서부터 하나씩 읽어 봐요.

- `class GREETER is`는 상자를 열고 이름을 붙여요. 클래스 이름은 대문자로 써요.
- `hello : STR is`는 `hello`라는 루틴을 시작해요. 이 루틴은 `STR`, 즉 *문자열*이라고
  부르는 텍스트 한 조각을 만들어 내요. `: STR`은 어떤 종류의 결과가 돌아오는지에 대한
  약속이에요.
- `return "Hello!";`는 결과를 돌려줘요. 텍스트는 큰따옴표 사이에 써요.
- `end;`는 루틴을 닫고, 두 번째 `end;`는 클래스를 닫아요.

한 줄에서 `--` 뒤에 오는 내용은 모두 **주석**이에요. Sather는 주석을 무시해요. 주석은
사람을 위해 있는 거예요.

```sather
-- This line is for the reader, not the computer.
```

다른 곳에서 루틴을 사용하려면 클래스 이름, 콜론 두 개, 루틴 이름을 쓰면 돼요.

```sather
GREETER::hello        -- this is "Hello!"
```

같은 클래스 안에서는 클래스 이름을 생략할 수 있어요.

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

   greeting_again : STR is
      return hello;      -- calls the routine just above
   end;

end; -- class GREETER
```

인자가 없는 루틴은 괄호 없이 호출해요. `hello()`가 아니라 `hello`예요.
