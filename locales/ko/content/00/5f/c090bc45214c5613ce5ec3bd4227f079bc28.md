# 지침

_Instruments of Texas_에서 일하던 중, Elixir로 작성된 실험적인 역폴란드 표기법 [RPN] 계산기 작업을 맡게 됐어요. 팀에는 몇몇 연산이 오류를 일으켜 프로세스를 중단시키는 문제가 있어요. 그래서 관용적인 Elixir 코드로 오류를 더 깔끔하게 처리할 수 있도록 연산 함수를 감싸는 함수를 작성하는 일을 맡았어요.

## 1. 팀에 경고하기

스택만 인자로 넘겨 연산 함수를 호출하도록 `calculate!/2` 함수를 구현해요. 연산 함수는 다른 곳에 정의되어 있지만, 성공적으로 끝나거나 오류를 발생시킬 수 있다는 건 알고 있어요.

```elixir
stack = []
operation = fn _ -> :ok end
RPNCalculator.calculate!(stack, operation)
# => :ok

stack = []
operation = fn _ -> raise ArgumentError, "An error occurred" end
RPNCalculator.calculate!(stack, operation)
# => ** (ArgumentError) An error occurred
```

> 함수 이름이 `!`로 끝나는 것은 그 함수가 오류를 발생시킬 수 있다는 걸 프로그래머에게 알려주는 신호예요

## 2. 오류 감싸기

좀 더 조사해 보니 많은 함수가 성공과 실패를 나타내기 위해 아톰과 튜플을 사용한다는 걸 알게 됐어요. 이 전략을 사용해 `calculate/2`를 구현해요.

```elixir
stack = []
operation = fn _ -> "operation completed" end
RPNCalculator.calculate(stack, operation)
# => {:ok, "operation completed"}

stack = []
operation = fn _ -> raise ArgumentError, "An error occurred" end
RPNCalculator.calculate(stack, operation)
# => :error
```

## 3. 메시지 전달하기

일부 오류에는 시스템이 올바르게 동작하는 데 동료들이 꼭 알아야 하는 중요한 정보가 담겨 있어요. 오류 메시지를 전달하도록 `calculate_verbose/2`를 구현해요. 오류는 `:message` 필드를 가진 구조체예요.

```elixir
stack = []
operation = fn _ -> "operation completed" end
RPNCalculator.calculate_verbose(stack, operation)
# => {:ok, "operation completed"}

stack = []
operation = fn _ -> raise ArgumentError, "An error occurred" end
RPNCalculator.calculate_verbose(stack, operation)
# => {:error, "An error occurred"}
```
