# 소개

튜플은 정해진 개수의, 서로 다른 타입일 수도 있는 데이터를 하나로 묶는 가벼운 방법이에요. 튜플에는 따로
이름이 없어요. 데이터 구조에 이름을 붙이면 그건 `struct`가 돼요. 튜플의 필드에도 이름이 없어요.
필드는 구조 분해를 하거나 위치를 통해 접근해요.

## 문법

### 생성

튜플은 항상 튜플 표현식으로 만들어요:

```rust
// pointless but legal
let unit = ();
// single element
let single_element = ("note the comma",);
// two element
let two_element = (123, "elements can be of differing types");
```

튜플은 원소를 원하는 만큼 가질 수 있어요.

### 구조 분해로 접근

구조 분해를 통해서도 튜플의 원소에 접근할 수 있어요. 구조 분해란 튜플의 각 원소에 변수
이름을 붙이는 것을 말하고, 이 과정에서 튜플은 소비돼요.

```rust
let (elem1, _elem2) = two_element;
assert_eq!(elem1, 123);
```

### 위치로 접근

숫자로 된 위치 인덱스로도 튜플의 원소에 접근할 수 있어요. 인덱스는 언제나처럼
0부터 시작해요.

```rust
let notation = single_element.0;
assert_eq!(notation, "note the comma");
```

## 튜플 구조체

앞으로 튜플 구조체도 다루게 될 거예요. 일반 구조체와 마찬가지로 튜플 구조체도 이름이 있는
타입이에요. 다만 일반 구조체와 달리 필드가 익명이에요. 문법은 일반적인 튜플 문법과 아주
비슷해요. 구조 분해와 위치 접근을 모두 사용할 수 있어요.

```rust
struct TupleStruct(u8, i32);
let my_tuple_struct = TupleStruct(123, -321);
let neg = my_tuple_struct.1;
let TupleStruct(byte, _) = my_tuple_struct;
assert_eq!(neg, -321);
assert_eq!(byte, 123);
```

### 필드 가시성

익명 튜플의 모든 필드는 항상 공개예요. 하지만 튜플 구조체의 필드는 각각 가시성을 가지고,
그 기본값은 일반 구조체의 필드와 마찬가지로 비공개예요. 일반 구조체에서처럼 `pub` 제한자를
붙여 필드를 공개로 만들 수 있어요.

```rust
// fails due to private fields
mod tuple { pub struct TupleStruct(u8, i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```

```rust
// succeeds: fields are public
mod tuple { pub struct TupleStruct(pub u8, pub i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```
