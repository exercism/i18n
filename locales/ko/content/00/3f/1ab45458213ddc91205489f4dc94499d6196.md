# 소개

`Tuple`은 `Vector`(1차원 `array`)와 여러 면에서 꽤 비슷해요.
하지만 몇 가지 중요한 차이점이 있어요.

- 튜플은 대괄호 `[ ]` 대신 소괄호 `( )`를 사용해요. 단, 의미가 명확한 경우에는 소괄호를 생략할 수 있어요.
- 튜플은 모든 원소가 같은 타입일 필요가 없어요. 각 원소의 타입이 개별적으로 저장돼요.
- 튜플은 불변이에요.

불변성은 컴파일러가 더 많은 최적화를 할 수 있게 해주고, 튜플을 벡터보다 더 성능 좋게 만들어요. 그래서 변경이 필요하지 않은 경우에는 튜플을 선호하는 게 좋아요.

```julia-repl
julia> t = (3, 5.2, "xyz")
(3, 5.2, "xyz")

# Non-homogeneous:
julia> dump(t)
Tuple{Int64, Float64, String}
  1: Int64 3
  2: Float64 5.2
  3: String "xyz"

julia> t[2]
5.2

# Immutable:
julia> t[2] = 7.3
ERROR: MethodError: no method matching setindex!(::Tuple{Int64, Float64, String})
```

`Tuple()` 생성자도 있어요. 이 생성자는 반복 가능한 모든 컬렉션을 튜플로 바꿔줘요.
유용하게도, 이 생성자는 문자열을 반복 가능한 문자 컬렉션으로 취급해요.

```julia-repl
julia> Tuple("Julia")
('J', 'u', 'l', 'i', 'a')
```

모든 튜플에서 인덱스로 원소에 접근하거나 원소를 순회할 수 있어요.

숫자로만 이루어진 튜플은 배열과 마찬가지로 `sum()` 같은 수학 함수에도 사용할 수 있어요.

## 언패킹

튜플은 다중 할당을 사용해 각각의 원소로 풀어낼 수 있어요.
필요하지 않은 원소에는 더미 변수 `_`를 사용해요.

```julia-repl
julia> tup = (1, "Julia", true)
(1, "Julia", true)

julia> num, name, _ = tup
(1, "Julia", true)

julia> uppercase(name), 2num
("JULIA", 2)
```

Python 프로그래머라면 이 다중 할당 문법이 아주 익숙할 거예요.

## 이름 있는 튜플

`Tuple`에는 값만 들어 있어요.
`NamedTuple`은 각 값에 이름을 짝지어 줘요.

그런 다음 각 필드에 "점" 표기법으로 접근할 수 있어요:

```jullia-repl
julia> nt = (a = 1, b = 7.3)
(a = 1, b = 7.3)

julia> dump(nt)
@NamedTuple{a::Int64, b::Float64}
  a: Int64 1
  b: Float64 7.3

julia> nt.b
7.3
```

이름은 내부적으로 `Symbol`(불변 타입이며, 이름 앞에 콜론 `:`이 붙어요)로 저장돼요. 그래서 다른 문법도 사용할 수 있어요:

```julia-repl
julia> nt[:b]
7.3
```

이름(또는 "키")이나 값을 따로 얻는 것도 쉬워요:

```julia-repl
julia> nt
(a = 1, b = 7.3)

julia> keys(nt)
(:a, :b)

julia> values(nt)
(1, 7.3)
```

참고로, 이름 있는 튜플을 순회하면 _값_만 나오고 _이름_은 무시돼요.

튜플은 (이름이 있든 없든) 구조화된 데이터를 함수에 전달하고 함수에서 받아오는 아주 흔한 방법이에요.
이런 경우 불변성은 데이터 안전성을 제공하고 컴파일러가 더 적극적으로 최적화할 수 있게 해주기 때문에 좋아요.
