# 지시 사항

서커스의 모든 하네스에는 킬로그램 단위의 하중 등급이 있고, 숫자를 확인하기 전까지는 아무도 올라가지 않아요.

`SAFETY_HARNESS` 클래스에는 다음이 필요해요. 스텁에 클래스와 그 속성이 들어 있으니, 나머지를 채워 넣어요. 아래의 각 루틴에는 계약이 있고, 어떤 계약인지는 힌트에 나와 있어요.

## 1. 하네스를 설치해요

`create`는 하네스가 견딜 수 있는 하중을 받아서 하네스를 돌려줘요. 등급이 0 이하라면 하네스라고 할 수 없으니, 그게 바로 `pre`예요.

```sather
harness ::= #SAFETY_HARNESS(120);
harness.limit
-- => 120
```

## 2. 여유는 얼마나 될까요?

`spare_capacity`는 하네스에 걸린 하중을 받아서, 얼마나 더 감당할 수 있는지 반환해요. 하중은 음수일 수 없고, 한계를 넘을 수도 없어요. 둘 다 `pre`예요. 답은 절대 음수가 아니고, 이건 `post`예요.

```sather
harness.spare_capacity(40)
-- => 80
```

## 3. 얼마나 찼을까요?

`percent_used`는 하중을 받아서 한계에 대한 백분율로 반환해요. 소수점 아래는 버려요. 하중은 음수일 수 없고, 답도 절대 음수가 아니에요.

```sather
harness.percent_used(60)
-- => 50
```

## 4. 안전할까요?

`is_safe`는 하중을 받아서 한계 안에 들어오는지 답해요. 어떤 하중이든, 엉뚱한 값이라도 물어볼 수 있으니 하중에는 `pre`가 없어요. 대신, 하중이 한계 안에 있을 때 정확히 참이 된다는 `post`를 작성해요.

```sather
harness.is_safe(200)
-- => false
```
