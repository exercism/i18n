# 소개

때로는 시퀀스를 원소 하나하나가 아니라 *조각*의 연속으로 봐야 할 때가 있어요. 이럴 때 [`grouping`][grouping], [`splitting`][splitting], [`splitting.monotonic`][splitting.monotonic] 보캐뷸러리가 그렇게 하는 네 가지 방법을 알려줘요.

## `group`: 크기가 *n*인 겹치지 않는 덩어리

```
group ( seq n -- groups )
```

```factor
USING: grouping ;

{ 1 2 3 4 5 6 7 } 3 group .
! => { { 1 2 3 } { 4 5 6 } { 7 } }
```

시퀀스 길이가 *n*의 배수가 아니면 마지막 덩어리는 *n*보다 짧아요.

## `clump`: 크기가 *n*인 겹치는 슬라이딩 윈도우

```
clump ( seq n -- clumps )
```

```factor
USING: grouping ;

{ 1 2 3 4 5 } 2 clump .
! => { { 1 2 } { 2 3 } { 3 4 } { 4 5 } }
```

시퀀스가 *n*보다 짧으면 결과는 비어 있어요.

## `split-when`: 술어가 참이 되는 곳마다 나누기

```
split-when ( seq quot: ( elt -- ? ) -- pieces )
```

```factor
USING: splitting ;

{ 1 2 0 3 4 0 5 } [ zero? ] split-when .
! => { { 1 2 } { 3 4 } { 5 } }
```

각 원소마다 술어가 한 번씩 호출돼요. 술어가 참을 반환하는 원소가 *분리 지점*이 되고, 그 원소는 결과에 남지 않아요.

## `monotonic-split`: 인접한 쌍 검사가 실패하는 곳마다 연속 구간 나누기

```
monotonic-split ( seq quot: ( a b -- ? ) -- pieces )
```

```factor
USING: splitting.monotonic ;

{ 1 1 2 2 2 3 } [ = ] monotonic-split .
! => { { 1 1 } { 2 2 2 } { 3 } }
```

술어는 *인접한 쌍*에 대해 실행돼요. 술어가 참을 반환하는 동안에는 연속 구간이 이어지고, `f`를 반환하면 새로운 조각이 시작돼요. `[ = ]`를 쓰면 값이 같은 원소가 이어지는 구간이, `[ <= ]`를 쓰면 값이 감소하지 않는 구간이 나오는 식이에요.

## 언제 무엇을 쓸까요?

- **`group`/`clump`**: 원하는 *크기*를 알고 있을 때예요.
- **`split-when`**: *분리 원소*가 어떤 모습인지 알고 있을 때예요.
- **`monotonic-split`**: 두 인접한 원소가 *여전히 함께 속한다*고 판단하게 만드는 기준을 알고 있을 때예요.
