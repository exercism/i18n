# 소개

Common Lisp에는 Lisp 데이터의 텍스트 표현을 작성하기 위한 모든 함수를 아우르는 The Printer라는 개념이 있어요. 그런 함수 중 하나가 `format`인데, 프로그래머가 원하는 대로 데이터를 형식화할 수 있게 해줘요.

`format`의 기능과 일반적인 Lisp 프린터는 다룰 범위가 아주 넓은 주제예요. 여기서는 `format` 사용의 기초를 설명할게요.

## FORMAT 함수

`format` 함수는 적어도 두 개의 인자를 받아요. 출력할 대상인 스트림과, 무엇을 어떻게 출력할지 정의하는 제어 문자열이에요.

스트림은 그 자체로 하나의 개념이라 다른 곳에서 설명해요. 하지만 지금은 출력이 스트림으로 이루어진다는 것과, 이 인자에 쓸 수 있는 두 개의 특별한 값 `t`와 `nil`이 있다는 것만 알면 돼요. `t`는 표준 출력(실제로는 변수 `*standard-output*`이 묶여 있는 스트림)에 출력한다는 뜻이고, `nil`은 문자열을 만들어서 반환한다는 뜻이에요.

`format`은 스트림으로 `nil`을 지정한 뒤의 경우를 빼면 항상 `nil`로 평가된다는 점에 유의해요. 이 뒤의 방식은 단순한 문자열 보간이나 문자열 생성을 하는 흔한 방법이에요.

```lisp
(format nil "hello world") ; => "hello world"
(format t "hello world")   ; => NIL (but "hello world" is printed to standard output)
```

## 형식 지시자

제어 문자열에는 "형식 지시자"가 들어갈 수 있는데, 이것은 무엇을 출력할지, `format`에 전달된 다른 인자들을 어떻게 해석할지에 대한 지시를 `format`에 전해줘요. 어떤 의미에서 제어 문자열은 `format`이 해석하고 실행하는 프로그램이에요. 모든 지시자는 `~`로 시작하고 그 뒤에 문자 하나가 와요(예: `~A`, `~D`, `~&`). 문자의 대소문자는 상관없어요.

대부분의 형식 지시자는 `format`에 전달된 인자를 출력에 끼워 넣기만 해요. 이런 것을 인자를 "소비한다"고 해요. 어떤 지시자는 인자를 소비하지 않고, 어떤 것은 하나 이상을 소비해요. 어떤 지시자는 인자 목록 안을 자유롭게 뛰어다니거나 인자를 건너뛸 수도 있게 해줘요.

## 기본 형식화

아주 범용적인 형식 지시자가 `~A`예요. 이 지시자는 데이터를 '사람이 읽을 수 있는' 형태로 출력해요.

```lisp
(format nil "Value = ~a" 10)                ; => "10"
(format nil "hello ~a" "world")             ; => "hello world"
(format nil "The list is: ~A" (list 1 2 3)) ; => "The list is: (1 2 3)"
```

또 하나의 유용한 형식 지시자는 `~S`예요. 이 지시자는 데이터를 '기계가 읽을 수 있는' 형태로 출력해요. 만들어진 출력을 Lisp 데이터로 다시 해석하고 싶을 때 아주 유용해요. 많은 경우 `~A`와 똑같아 보이지만, 예를 들어 문자열의 경우에는 출력에 따옴표가 포함된다는 점에 유의해요(다른 문자열 안에 들어갈 때는 이스케이프돼요). 그래야 그 값을 문자열 인자로 다시 읽어 들일 수 있어요.

```lisp
(format nil "~s" 10)            ; => "10"
(format nil "~s" "hello world") ; => "\"hello world\""
(format nil "~s" (list 1 2 3))  ; => "(1 2 3)"
```

아주 유용한 지시자가 두 개 더 있는데, `~%`와 `~&`예요. 앞의 것은 줄 바꿈 문자를 출력하고, 뒤의 것은 "새 줄"을 출력해요. 둘의 차이는 `~%`는 항상 줄 바꿈을 출력하는 반면, `~&`는 현재 줄의 시작 부분이 아닐 때만 줄 바꿈을 출력한다는 거예요. 둘 다 인자를 소비하지 않아요.

```lisp
(format nil "~%new~%lines") ; => "
                                  new
                                  lines"

(format nil "~&new~&lines"  ; => "new
                                  lines"
```

마지막으로 `~~`는 리터럴 `~`를 출력하는 단순한 지시자예요.
