# 테스트

테스트 러너를 사용하려면 [Godot이 제대로 설치되어 있어야 해요][installation].

## 테스트 실행하기

[테스트 러너][test runner]는 풀이를 불러오고 테스트하는 데 사용해요.
테스트 러너를 실행하려면 먼저 내려받은 다음, `godot`으로 테스트 러너를 실행해요.
앞으로는 `exercism download`를 사용할 때 테스트 러너가 연습 문제와 함께 자동으로 내려받아질 거예요.

### 테스트 러너 내려받기

다음 셸 명령을 사용하면 테스트 러너를 내려받을 수 있어요.

```bash
exercism download --track gdscript --exercise hello-world
cd "$(exercism workspace)/gdscript"
curl --remote-name https://raw.githubusercontent.com/exercism/gdscript-test-runner/refs/heads/main/bin/test_runner.gd
```

### 테스트 러너 실행하기

테스트 러너는 헤드리스 모드(IDE 없이)에서 `godot`으로 실행해요.
`-s` 또는 `--script` 옵션을 붙이면 Godot이 테스트 러너 스크립트를 실행해요.
테스트 러너는 슬러그와 풀이 디렉터리 경로, 이렇게 두 개의 인자를 받아요.

```bash
godot --headless -s to/test_runner.gd -- <solution-slug> <path/to/solution>
```

예를 들어,

```bash
godot --headless -s "$(exercism workspace)/gdscript/test_runner.gd" -- hello-world "$(exercism workspace)/gdscript/hello-world
```
