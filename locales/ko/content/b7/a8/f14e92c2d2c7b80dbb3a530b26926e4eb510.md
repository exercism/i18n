# 출력

Cairo에서 출력을 사용하면 메시지와 값을 콘솔에 표시할 수 있어서, 프로그램을 디버그하거나 실행 중에 정보를 전달하기가 더 쉬워져요.

출력 시스템은 다재다능하면서도 간단해서, 다양한 타입의 데이터를 서식에 맞춰 출력할 수 있는 도구를 제공해요.

## 출력 기본

Cairo는 텍스트를 콘솔에 출력하는 두 가지 주요 매크로를 제공해요:

- **`println!`**: 출력을 새 줄에 표시해요.
- **`print!`**: 새 줄을 추가하지 않고 출력을 같은 줄에 표시해요.

두 매크로 모두 `ByteArray`를 주요 인자로 받는데, 이 인자는 단순한 문자열일 수도 있고 값을 위한 자리 표시자가 포함된 서식 문자열일 수도 있어요.

```rust
// Printing a simple message
println!("Hello, Cairo!");

// Printing with values
let x = 10;
let y = 20;
println!("Values: x = {}, y = {}", x, y);
```

위 예시에서는:

- `{}` 자리 표시자가 `x`와 `y`의 값으로 바뀌어요.
- `println!`은 출력이 새 줄로 끝나게 해요.

## 문자열 서식 지정

때로는 서식 문자열을 만들되 바로 출력하지는 않아야 할 때가 있어요.

`format!` 매크로를 사용하면 이렇게 할 수 있어요.

`println!`과 비슷하게 동작하지만, 콘솔에 출력을 보내는 대신 `ByteArray`를 반환해요.

```rust
let s1: ByteArray = "tic";
let s2: ByteArray = "tac";
let s3: ByteArray = "toe";

// Create a formatted string
let result = format!("{s1}-{s2}-{s3}");

println!("{}", result); // Output: tic-tac-toe
```

이 예시에서는:

- `format!`은 `s1`, `s2`, `s3`를 하나의 문자열로 합치면서, 각각을 대시(`-`)로 구분해요.
- 이렇게 만들어진 문자열은 나중에 다시 사용하거나 출력할 수 있어요.

## 사용자 정의 데이터 타입 출력

기본적으로 Cairo는 정수와 문자열 같은 기본 타입만 출력할 수 있어요.

구조체처럼 사용자 정의 타입을 출력하려고 하면, 그 타입이 `Display`나 `Debug` 트레이트를 구현하지 않는 한 오류가 발생해요.

### 사용자 정의 서식을 위한 `Display` 활용

`Display` 트레이트를 사용하면 사용자 정의 타입을 어떻게 출력할지 정의할 수 있어요.

예시를 볼까요:

```rust
use core::fmt::{Display, Formatter, Error};

struct Point {
    x: u8,
    y: u8,
}

impl PointDisplay of Display<Point> {
    fn fmt(self: @Point, ref f: Formatter) -> Result<(), Error> {
        write!(f, "Point({}, {})", *self.x, *self.y)
    }
}

let p = Point { x: 3, y: 4 };
println!("{}", p); // Output: Point(3, 4)
```

이 예시에서는:

- `fmt` 함수는 `Point` 구조체가 출력 가능한 문자열로 어떻게 변환될지 정의해요.
- `write!` 매크로는 서식 문자열을 `Formatter`에 덧붙여요.

### `Debug`로 디버깅하기

디버깅을 위해 Cairo는 `Debug` 트레이트를 제공해요.

대부분의 타입에서 이를 자동으로 파생할 수 있어서, 구조체의 내부 정보를 빠르고 쉽게 출력할 수 있어요.

```rust
#[derive(Debug)]
struct Point {
    x: u8,
    y: u8,
}

let p = Point { x: 3, y: 4 };
println!("{:?}", p); // Output: Point { x: 3, y: 4 }
```

이 예시에서는:

- `#[derive(Debug)]`는 `Debug` 트레이트에 대한 구현을 자동으로 생성해요.
- `{:?}` 자리 표시자는 `println!`에게 서식 지정에 `Debug` 트레이트를 사용하라고 알려줘요.

## 16진수로 출력하기

Cairo에서는 `{:x}` 자리 표시자를 사용해 정수를 16진수 형식으로 출력할 수 있어요.

```rust
let value: u32 = 255;
println!("{:x}", value); // Output: ff
```

이는 저수준 데이터 표현을 다룰 때 특히 유용해요.
