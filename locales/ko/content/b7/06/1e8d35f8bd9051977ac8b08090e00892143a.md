# 게터와 세터

게터와 세터는 객체 속성의 값을 읽고 쓸 수 있게 해 주는 메서드예요.
Crystal에는 매크로가 있어서 속성의 게터와 세터를 쉽게 정의할 수 있어요.
매크로는 컴파일 시점에 코드를 생성하는 방법인데, 이 내용은 나중에 매크로 개념에서 다뤄요.

Ruby에서는 이런 메서드를 `attr_reader`, `attr_writer`, `attr_accessor` 메서드로 정의하는데, 겉보기에는 Crystal의 구현과 아주 비슷해요.
Crystal은 이들을 `getter`, `setter`, `property` 매크로로 정의했어요.

## 게터

게터는 인스턴스 변수의 값을 반환하는 메서드를 정의하는 매크로예요.
그래서 메서드 안에서 인스턴스 변수에 접근할 때(initialize는 빼고) 더 이상 변수 앞에 `@`를 쓰지 않아도 되고, 대신 게터 매크로가 정의해 둔 메서드를 호출하면 돼요.

게터 매크로는 인스턴스 변수 여러 개를 쉼표로 구분해서 받을 수 있어요.

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name
    @name
  end

  def age
    @age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  getter name, :age
end
```

보시는 것처럼 게터를 사용하면 작성하는 코드의 양이 줄고 읽기도 더 쉬워져요.
또한 Crystal은 게터 매크로의 인자로 변수 이름과 심볼을 모두 받을 수 있다는 점이 Ruby와 달라요.
심볼은 나중에 심볼 개념에서 다뤄요.

## 세터

세터는 인스턴스 변수의 값을 설정하는 메서드를 정의하는 매크로예요.
이 매크로는 그렇게 자주 쓰이지 않고, 보통은 `property` 매크로를 대신 사용해요.
만들어지는 메서드는 `name_of_method=` 같은 모양인데, 이 `=` 덕분에 속성을 설정할 수 있게 돼요.

이 메서드 정의는 메서드가 받는 인자가 `=` 기호 뒤에 온다는 점에서 조금 특별해요.
Crystal의 다른 여러 특별한 메서드도 이 문법을 사용하는데, `+` 메서드가 그렇죠.

게터 매크로와 마찬가지로, 세터를 정의한 뒤에 인스턴스 변수의 값을 바꾸고 싶으면 세터 매크로가 정의해 둔 메서드를 호출하면 돼요.

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name=(name : String)
    @name = name
  end

  def age=(age : Int32)
    @age = age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  setter name, :age
end
```

## 프로퍼티

프로퍼티는 인스턴스 변수에 대한 게터와 세터를 모두 정의하는 매크로예요.

```crystal
class Person
  @name : String
  @age : Int32

  property name, :age
end
```
