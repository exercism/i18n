# 소개

Haxe에서 예외는 코드를 실행하는 중에 발생하는 오류를 안전하게 처리하는 방법이에요. 모든 예외에는 오류를 설명하는 메시지가 담겨 있어야 해요. `throw` 키워드를 사용하면 예외를 _던질_ 수 있어요:

```haxe
public function main(num:Int) {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
  // ...
}
```

예외가 던져지면, 코드는 그 오류를 처리하도록 지정된 부분을 찾아요. 찾지 못하면 오류 메시지를 표시하면서 프로그램 실행도 중단해요.

Haxe에서 예외를 처리하려면 `try-catch` 블록을 사용해요. 이 블록 문은 하나의 `try` 블록과 하나 이상의 `catch` 블록으로 이루어져 있어요. `try` 블록은 코드를 실행해 _보고_, `catch` 블록은 예외가 던져질 경우를 대비해 기다리다가 그것을 _잡아서_ 실행이 멈추지 않게 해요. `catch` 블록이 예외를 잡으면 블록 안의 모든 것도 실행해요:

```haxe
try {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
} catch (e) {
  // All exceptions will be caught here
  trace(e.message); // Argument num cannot be greater than 10
}
```

`catch` 블록 인자의 타입은 생략해야 해요.
