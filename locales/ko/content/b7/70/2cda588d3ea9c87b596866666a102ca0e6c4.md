# 숫자 타입

Crystal에는 다양한 목적을 위한 여러 숫자 타입이 있어요.
예를 들어, 어떤 타입은 더 빠르지만 표현할 수 있는 값의 범위가 다른 타입보다 작아요.
어떤 타입은 표현할 수 있는 값의 범위가 더 넓지만 더 느려요.

Crystal에는 부호 있는 정수 타입과 부호 없는 정수 타입이 모두 있어요.
부호 있는 정수 타입은 양수나 음수를 가질 수 있어요.
부호 없는 정수 타입은 양수만 가질 수 있어요.

## 부호 있는 정수 타입

다음은 Crystal의 [부호 있는 정수 타입][int]이에요:

| Type     | Size (bits) | Range                                                                                                       |
| -------- | ----------- | ----------------------------------------------------------------------------------------------------------- |
| `Int8`   | 8           | -128 to 127                                                                                                 |
| `Int16`  | 16          | -32_768 to 32_767                                                                                           |
| `Int32`  | 32          | -2_147_483_648 to 2_147_483_647                                                                             |
| `Int64`  | 64          | -9_223_372_036_854_775_808 to 9_223_372_036_854_775_807                                                     |
| `Int128` | 128         | -170_141_183_460_469_231_731_687_303_715_884_105_728 to 170_141_183_460_469_231_731_687_303_715_884_105_727 |

작은 타입은 큰 타입보다 메모리를 적게 쓰고 더 빠르지만, 표현할 수 있는 값의 범위는 더 작아요.

값이 특정 범위 안에 들어온다는 것을 알고 있다면, 메모리를 아끼고 성능을 높이기 위해 가능한 한 가장 작은 타입을 사용하는 게 가장 좋아요.

기본 정수 타입은 `Int32`예요.
특정 타입의 정수를 선언하려면 `<number>_I <bit>`를 덧붙여서 타입 이름을 접미사로 쓰면 돼요.

```crystal
1_i8.class
# => Int8
```

`to_i<bit>` 메서드를 사용하면 서로 다른 정수 타입 사이를 변환할 수 있어요.
`to_i` 메서드는 기본 정수 타입인 `Int32`로 변환해요.

```crystal
1_i8.to_i16.class
# => Int16

2_i16.to_i.class
# => Int32
```

## 부호 없는 정수 타입

다음은 Crystal의 [부호 없는 정수][uint] 타입이에요:

`UInt8`, `UInt16`, `UInt32`, `UInt64`, `UInt128`

부호 있는 정수와 부호 없는 정수의 유일한 차이는 부호 없는 정수가 양수만 가질 수 있다는 점이에요.
특정 타입의 부호 없는 정수를 선언하려면 `<number>_u<bit>`를 덧붙여서 타입 이름을 접미사로 쓰면 돼요.
`to_u<bit>` 메서드를 사용하면 서로 다른 부호 없는 정수 타입 사이를 변환할 수 있어요.
`to_u` 메서드는 기본 부호 없는 정수 타입인 `UInt32`로 변환해요.

```crystal
1_u8.to_u16.class
# => UInt16
```

## 부동 소수점 타입

다음은 Crystal의 부동 소수점 타입이에요:

| Type      | Size (bits) | Range                |
| --------- | ----------- | -------------------- |
| `Float32` | 32          | 1.2E-38 to 3.4E+38   |
| `Float64` | 64          | 2.3E-308 to 1.7E+308 |

서로 다른 [부동 소수점 타입][float]이 두 가지 있는데, 하나가 다른 하나보다 더 정밀해요.

기본 부동 소수점 타입은 `Float64`예요.

`to_f<bit>` 메서드를 사용하면 서로 다른 부동 소수점 타입 사이를 변환할 수 있어요.
`to_f` 메서드는 기본 부동 소수점 타입인 `Float64`로 변환해요.

## 연산 후의 타입

두 숫자 사이에서 연산을 실행하면, 결과는 정밀도가 가장 높은 숫자의 타입이 돼요.
부동 소수점은 정수보다 더 정밀하고, 정수는 부호 없는 정수보다 더 정확해요.
그다음으로 `Float64`가 Float32보다 더 정밀해요. 이런 식이에요.

```crystal
(1_u8 + 2_u64).class
# => UInt64

(1_u8 + 2_i64).class
# => Int64

(1_u8 + 2.0_f64).class
# => Float64
```

## 더 깊이 알아보기: 부호 없는 정수 vs 부호 있는 정수

~~~~exercism/advanced
내부적으로 부호 없는 정수와 부호 있는 정수를 구분하는 차이는, 부호 있는 정수는 첫 번째 비트를 부호를 저장하는 데 사용한다는 점이에요.
이 부호는 양수 또는 음수를 나타내요.
부호 없는 정수에서는 첫 번째 비트를 값을 저장하는 데 사용해요.
그래서 부호 있는 32비트 정수의 최댓값은 2^31 - 1이에요.
부호 없는 32비트 정수의 최댓값은 2^32 - 1이에요.

부호에 대해 더 알아보고 싶다면 [Wikipedia](https://en.wikipedia.org/wiki/Signedness)에서 더 읽어볼 수 있어요.
~~~~
