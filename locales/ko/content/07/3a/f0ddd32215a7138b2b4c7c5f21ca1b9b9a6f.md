# 자세히 알아보기

루프에는 기본적으로 두 가지 종류가 있어요:

1. 조건이 만족될 때까지 반복해요.
2. 컬렉션에 있는 원소들을 하나씩 순회해요.

두 방법 모두 [R에서 가능해요][web-loops]. 다만 첫 번째가 더 흔할 수 있어요.

## `while`과 `repeat`

루프를 몇 번 돌지 미리 알 수 없는 열린 문제에서는, R에 조건이 있는 [`while`][ref-control]문과 조건이 없는 [`repeat`][ref-control]문이 있어요(`while (TRUE)`와 같아요).

기본 형태는 꽤 단순해요:

```R
while (condition) {
  do_something()
}
```

이 경우 프로그램은 `condition`이 더 이상 `TRUE`가 아닐 때까지 루프를 계속 돌아요.

루프를 일찍 빠져나가는 방법이 두 가지 있어요:

- `break`를 만나면 루프를 빠져나가고, 실행은 루프의 닫는 중괄호 `}` 다음 줄부터 이어져요.
- `return(x)`는 현재 함수의 실행을 멈추고, 반환값 `x`를 호출한 곳으로 돌려줘요.

이런 방법을 쓸 수 있으니, `repeat { ... }`로 "무한" 루프를 만들어 두고 루프 본문 안에서 멈출 조건을 찾아 `break`나 `return`을 실행하는 게 편리할 때도 있어요.

이 세 가지 방식은 결과가 같고, 모두 `x == 0.4444...`로 끝나요.

```R
x <- 12
while (x > 1) {
  x <- x / 3
}

x <- 12
while (TRUE) {
  x <- x/3
  if (x <= 1) break
}

x <- 12
# no boolean clause 
repeat { 
  x <- x/3
  if (x <= 1) break
}
```

## 벡터(또는 다른 컬렉션) 순회하기

R에서는 이것이 필요 없는 경우가 많아요.
다른 개념에서 이야기했듯이, 많은 함수가 벡터 전체를 대상으로 동작해요.

하지만 명시적인 루프가 불가피할 때도 있어요.
특히 다음과 같은 경우예요:

- 루프 본문이 출력이나 파일 입출력 같은 부수 효과를 일으킬 때.
- 얼마나 반복될지 예측할 수 없는 가운데, 어떤 기준에 도달할 때까지 반복이 계속될 때.

루프 조건은 괄호 안에 있어야 해요.
함수 본문과 마찬가지로, 한 줄짜리 루프 본문에서는 중괄호를 생략할 수 있어요(보통은 넣지만요).

```R
words <- c("This", "is", "a", "loop")
for (w in words) { print(w) } # the braces are optional here
#> [1] "This"
#> [1] "is"
#> [1] "a"
#> [1] "loop"
```

현재 반복이 어떤 조건을 만족하지 않으면, `next`로 곧바로 다음 반복으로 건너뛸 수 있어요:

```R
for (n in 1:5) {
  if (n %% 2 == 0) next
  print(n)
}
#> [1] 1
#> [1] 3
#> [1] 5
```

숫자 인덱스가 필요하면 [`seq_along()`][ref-seq_along]을 사용해요.

```R
v <- LETTERS[1:3]
v
#> [1] "A" "B" "C"

for (i in seq_along(v)) { print(sprintf("%s%i", v[i], i)) }
#> [1] "A1"
#> [1] "B2"
#> [1] "C3"
```

`i in 1:length(v)`는 _권장하지 않아요_. `length(v)`가 0일 때 문제를 일으킬 수 있기 때문이에요.
`1:0` 범위는 `c(1, 0)`과 같아서 루프 본문이 실행되고, 아마 실패할 거예요.
`seq_along()` 함수는 이런 경우를 제대로 처리하도록 만들어졌어요.
