# 자세히 알아보기

`Complex numbers`는 복잡하지 않아요.
그저 조금 덜 놀라운 이름만 있으면 될 뿐이에요.

복소수는 특히 공학과 과학에서 아주 유용해서, Julia에서는 정수와 실수와 나란히 표준 숫자 타입으로 [복소수][complex]를 제공해요.

## 기초

Julia의 `complex` 값은 본질적으로 숫자 두 개의 짝이에요. 보통은 실수지만 항상 그런 것은 아니에요.
이 둘은 안타까운 역사적 이유로 "실수부"와 "허수부"라고 불려요.
여기서도 이상한 이름보다 그 바탕에 있는 단순함에 집중하는 게 좋아요.

두 실수로 복소수를 만들려면 허수부에 접미사 `im`을 붙이기만 하면 돼요.

```julia-repl
julia> z = 1.2 + 3.4im
1.2 + 3.4im

julia> typeof(z)
ComplexF64 (alias for Complex{Float64})

julia> zi = 1 + 2im
1 + 2im

julia> typeof(zi)
Complex{Int64}
```

이렇게 정수나 실수 타입에 대응하는 여러 가지 `Complex` 타입이 있어요.

실수 변수로 복소수를 만들 때는 위 문법이 통하지 않아요.
`a + bim`이라고 쓰면 파서가 `bim`을 (존재하지 않는) 변수 이름으로 착각해요.

`b*im`이라고 쓸 수도 있지만, 더 권장되는 방법은 `complex()` 함수를 사용하는 거예요.

```julia-repl
julia> a = 1.2; b = 3.4; complex(a, b)
1.2 + 3.4im
```

`i`나 `j`가 아니라 왜 `im`일까, 하고 궁금할 수도 있어요.

대부분의 엔지니어는 `j`로 만족해요.
대부분의 과학자와 수학자는 _허수_를 뜻하는 수학 표기 `i`를 선호하지만, 그 표기는 전기 공학에서 `i`를 _전류_라는 뜻으로 쓰는 것과 충돌해요.

[설명서][complex]에는 "수학자의 i나 엔지니어의 j는 인덱스 변수 이름으로 너무 흔히 쓰이기 때문에 이 전역 상수에 사용하는 것은 배제되었다"라고 나와 있어요.

기분 좋은 우연히도, 덕분에 엔지니어와 나머지 모든 사람 사이의 긴 논쟁도 피할 수 있었어요.
이게 결정에 영향을 주었는지는 스스로 판단해 봐요.

복소수의 각 부분에 개별적으로 접근하려면 이렇게 해요.

```julia-repl
julia> z = 1.2 + 3.4im
1.2 + 3.4im

julia> real(z)
1.2

julia> imag(z)
3.4
```

어느 한쪽 부분이 0일 수도 있고, 그러면 수학자들은 그 수가 "완전히 실수" 또는 "완전히 허수"라고 말하기도 해요.
그래도 Julia에서는 여전히 복소수예요.

```julia-repl
julia> zr = 1.2 + 0im
1.2 + 0.0im

julia> typeof(zr)
ComplexF64 (alias for Complex{Float64})

julia> zi = 3.4im
0.0 + 3.4im

julia> typeof(zi)
ComplexF64 (alias for Complex{Float64})
```

`i`(또는 `j`)가 -1의 제곱근이라는 말을 들어 봤을지도 몰라요.

지금로선, 이 말은 허수부가 _정의상_ 다음 등식을 만족한다는 뜻일 뿐이에요.

```julia-repl
julia> 1im * 1im == -1
true
```

단순한 생각이지만, 흥미로운 결과로 이어져요.

## 연산

실수와 정수에 쓰는 모든 표준 수학 `operators`와 기본 함수는 복소수에도 그대로 동작해요. 몇 가지 예를 들어 볼게요.

```julia-repl
julia> z1 = 1.5 + 2im
1.5 + 2.0im

julia> z2 = 2 + 1.5im
2.0 + 1.5im

julia> z1 + z2  # addition
3.5 + 3.5im

julia> z1 * z2  # multiplication
0.0 + 6.25im

julia> z1 / z2  # division
0.96 + 0.28im

julia> z1^2  # exponentiation
-1.75 + 6.0im

julia> 2^z1  # another exponentiation
0.5188946835878313 + 2.7804223253571183im
```

복소수의 곱셈과 나눗셈 규칙을 설명하는 것은 이 개념의 범위를 벗어나요. (_그리고 그런 연산을 "손으로" 직접 할 일도 그리 많지 않을 거예요._)

복소수에 관한 [수학적][math-complex] 또는 [전기 공학적][engineering-complex] 입문 자료라면 이 내용을 다루니, 더 깊이 파고들고 싶다면 찾아보세요.

또는 Exercism에는 `Complex Numbers` 연습 문제가 있는데, 여기서 이런 연산을 갖춘 복소수 클래스를 처음부터 직접 구현해 볼 수 있어요.

복소수에서는 (대부분) 정수 나눗셈이 ___불가능___ 해요. 그래서 복소수 타입에서는 `//`, `÷`, `%` 연산자가 실패해요.
예외적으로 복소수 _정수_에 `//`를 쓰면 복소 유리수를 얻을 수 있지만, 자주 쓸 일은 아마 없을 거예요.

## 함수

대부분의 수학 함수는 복소수 입력에서도 동작해요.

하지만 실수 입력을 주고 복소수 출력을 기대하면 보통은 잘 동작하지 않아요.
이는 성능 최적화 때문인데, 다중 디스패치 개념을 살펴보면 더 이해가 잘 될 거예요.

```julia-repl
julia> sin(1.5 + 2.0im)
3.752771340479298 + 0.25655395609048176im

julia> sqrt(-1)
ERROR: DomainError with -1.0:
sqrt was called with a negative real argument but will only return a complex result if called with a complex argument. Try sqrt(Complex(x)).

julia> sqrt(-1 + 0im)
0.0 + 1.0im
```

`real()`과 `imag()` 외에도 복소수와 특히 관련이 깊은 함수가 몇 가지 있어요.
이해가 안 된다면 그냥 건너뛰어도 돼요!

- `conj()`는 복소수 허수부의 부호를 뒤집기만 해요(_+에서 -로, 또는 그 반대로_).
    - 복소수 곱셈이 동작하는 방식 때문에, 생각보다 유용해요.
- `abs(<complex number>)`는 허수부가 없는 실수를 반환한다는 것이 보장돼요.
- `abs2(<complex number>)`는 `abs(<complex number>)`의 제곱을 반환해요. `abs()`보다 계산이 빠르고, 계산에 딱 필요한 값인 경우도 많아요.
- `angle(<complex number>)`는 위상각을 라디안으로 반환해요.

```julia-repl
julia> z1
1.5 + 2.0im

julia> conj(z1)
1.5 - 2.0im

julia> abs(z1)
2.5

julia> abs2(z1)
6.25

julia> angle(z1)
0.9272952180016122
```
수학을 좋아하는 분을 위한 부분적인 설명이에요. _(다시 말하지만, 건너뛰어도 돼요.)_

- `z1`의 `(real, imag)` 표현은 사실상 복소평면의 직교 좌표를 사용하는 거예요.
- 같은 복소수를 극좌표를 써서 `(r, θ)` 표기로 나타낼 수도 있어요.
- 여기서 `r`과 `θ`는 각각 `abs(z1)`과 `angle(z1)`로 주어져요.

몇 가지 상수를 사용한 예제예요.

```julia-repl
julia> euler = exp(1im * π)
-1.0 + 1.2246467991473532e-16im

julia> real(euler)
-1.0

julia> round(imag(euler), digits=15)  # round to 15 decimal places
0.0
```

그래서 자연에서 가장 중요한 상수 세 개인 `e`, `i`(또는 `j`), `pi`로 이루어진 간단한 식이 `-1`이라는 결과를 내요.
어떤 사람들은 이 결과를 수학 전체에서 가장 아름다운 결과라고 여겨요.
1740년 무렵까지 거슬러 올라가죠.

극좌표 `(r, θ)` 표기는 너무 유용해서, 이를 더 효율적으로 구성하도록 도와주는 내장 함수 `cis`(`cos(x) + isin(x)`의 줄임말)와 `cispi`(`cos(πx) + isin(πx)`의 줄임말)가 있어요.

극좌표 표기의 유용함은 오일러의 우아한 공식 `ℯ^(iθ) = cos(θ) + isin(θ) = x + iy`에 나타나요. 여기서 `|x + iy| = 1`이에요.
`|x + iy| = r`이면, 더 일반적인 극형식 `r * ℯ^(iθ) = r * (cos(θ) + isin(θ)) = x + iy`를 얻어요.
특히 지수 형태는 간결하고 다루기 쉽다는 점에 주목해요.

```julia-repl
julia> exp(1im * π) ≈ cis(π) ≈ cispi(1)
true
```

위에서 근사적으로 같다고 한 것은 [`cis`][cis]와 [`cispi`][cispi] 함수가 더 깔끔한 수치 결과를 줄 수 있기 때문이에요. 특히 `cispi`는 π의 임의의 배수(예를 들어 라디안!)를 인자로 다룰 때 그렇죠.

```julia-repl
julia> cis(π)
-1.0 + 0.0im

julia> cispi(1)
-1.0 + 0.0im

julia> θ = π/2;
julia> exp(im*θ)
6.123233995736766e-17 + 1.0im

julia> cis(θ)
6.123233995736766e-17 + 1.0im

julia> cispi(θ / π)  # θ/π == 1/2
0.0 + 1.0im
```

덧붙이자면, 덕분에 복소수는 2D에서 회전과 반지름 방향 이동을 할 때 아주 유용해요.

회전의 경우, 복소수 `z = x + iy`는 간단한 곱셈 `z * ℯ^(iθ)`으로 원점을 중심으로 각도 `θ`만큼 회전할 수 있어요.
여기서 `x`와 `y`는 실수 2D 직교 평면의 평범한 좌표일 뿐이고, 양의 각도는 *반시계 방향* 회전, 음의 각도는 *시계 방향* 회전을 만들어요.

마찬가지로 간단하게, 극형식에서 복소수의 크기 `r`에 `Δr`을 더하면 반지름 방향 이동을 만들 수 있어요(예: `z = r * ℯ^(iθ)` -> `z' = (r + Δr) * ℯ^(iθ)`).
각도 부분은 그대로이고 기대한 대로 크기 `r`만 바뀌는 점을 눈여겨봐요.

## 선택 사항: 복소수 자주 묻는 질문

관심이 없다면 이 부분은 건너뛰어도 돼요.

### 순수 수학의 이상하고 새로운 무언가인가요?

16세기에는 이상하고 새로웠어요.

500년이 지난 지금은 대부분의 공학과 물리 과학의 중심에 있어요.

### 도대체 왜 쓰는 걸까요?

복소수는 회전하는 것, 또는 파동 같은 성질을 가진 것을 설명하는 가장 간단한 방법이에요.
그래서 전기 공학, 오디오 처리, 물리학, 컴퓨터 게임, 내비게이션 등 여러 분야에서 널리 쓰여요. 몇 가지만 꼽자면 그렇죠.

회전하는 것은 눈으로 볼 수 있어요.
복소수가 세상을 돌아가게 만들지는 몰라도, 세상이 돌아가면서 _무슨 일이 일어나는지_ 설명하는 데는 아주 뛰어나요. 큰 폭풍을 찍은 위성 사진을 한번 보세요.

덜 뻔한 예로, 소리는 파동 같고, 빛도 파동 같고, 전파 신호도 파동 같아요.
심지어 여러분이 사는 나라의 경제도 적어도 일부는 파동 같아요.

이런 파동 처리는 상당 부분 삼각 함수(`sin()`과 `cos()`)로 할 수 있지만, 금방 지저분해져요.

복소 지수는 다루기가 ___훨씬___ 쉬워요.

### 그런데 복소수는 필요 없는데요!

동굴에 살면서 먹을 것을 채집해 구한다면 그 말이 맞아요.

어떤 종류의 화면이든 화면으로 이 글을 읽고 있다면, 복소수를 활용해 이루어진 20세기의 유용한 발전에 완전히 의존하고 있는 셈이에요.

1. __반도체 칩__.
    - 고전 물리학으로는 전혀 설명되지 않고, 양자역학(QM)으로만 설명(그리고 설계)할 수 있어요.
    - 양자역학에서는 정의상 모든 것이 복소수 값을 가져요. (_끝까지 내려가면 결국 파형이에요_)

2. __고속 푸리에 변환 알고리즘__.
    - FFT는 복소수의 응용이고, 소리 전송, 오디오 처리, 사진, 영상과 관련된 _모든 것_에 들어 있어요.

    - MP3를 비롯한 여러 오디오 형식은 압축에 FFT를 사용해서, 더 작은 저장 공간에 더 많은 오디오를 담을 수 있어요.
    - JPEG 압축과 MP4 영상 등 수많은 이미지와 영상 형식도 압축에 FFT를 써요.

    - FFT는 휴대폰 기지국이 여러분의 통화 신호를 다른 사람들의 신호와 분리하도록 해 주는 디지털 필터에도 쓰여요.

그러니 아마 매초 수천 번씩 복소수 계산에 기대는 기술을 쓰고 있는 셈이에요.
