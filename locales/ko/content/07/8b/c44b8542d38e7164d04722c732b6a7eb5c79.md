# 연습 문제 테스트

연습 문제의 풀이를 만들고 로컬에서 테스트하려면 아래 단계를 따라 해봐요.

## 연습 문제 다운로드하기

Command Prompt를 열고, 다운로드할 연습 문제의 이름과 함께 아래 명령을 실행해요.

```sh
exercism download --track ballerina --exercise <exercise-name>
```

## 풀이 작성하기

1. 아래 명령을 실행해 방금 다운로드한 연습 문제의 디렉터리로 이동해요.

     >**팁:** 아래 명령에 나오는 디렉터리 위치는 사용하는 운영체제와 설정한 Exercism 워크스페이스에 따라 달라요. `exercism configure` 명령을 실행하면 워크스페이스 위치를 확인할 수 있어요.

     ```sh
     cd ~/exercism/ballerina/hello-world/
     ```

2. 제공된 안내를 따라 연습 문제의 풀이를 작성해요.

## 풀이 테스트하기

Ballerina 연습 문제 중에는 테스트가 하나뿐인 것도 있고, 여러 개인 것도 있어요. 테스트는 연습 문제의 루트 디렉터리 안에 있는 `/tests` 디렉터리의 각 테스트 파일에서 찾을 수 있어요.

### 테스트가 하나인 연습 문제 테스트하기

아래 명령으로 연습 문제의 테스트를 실행해요.

기본적으로 첫 번째 테스트만 활성화되어 있어요. 이는 의도된 동작으로, 그 테스트 하나만 통과시키는 데 집중할 수 있게 해줘요.

```sh
bal test
```

### 테스트가 여러 개인 연습 문제 테스트하기

테스트가 여러 개인 연습 문제를 테스트하려면 아래 단계를 따라 해봐요.

1. 첫 번째 테스트가 통과하면, `@test:Config` 애너테이션의 `enable: false` 속성을 지워 다음 테스트를 활성화해요.

     ```ballerina
     @test:Config {
       enable: false
     }
     function nextTestCase() {
     }
     ``` 

2. 아래 명령으로 활성화한 테스트를 실행해요.

   ```sh
     bal test
   ```

3. 위 두 단계를 반복해 나머지 테스트를 활성화해요.

모든 테스트를 활성화하고 작성한 풀이가 각 테스트를 통과하도록 만들면 연습 문제를 성공적으로 완료한 거예요.
