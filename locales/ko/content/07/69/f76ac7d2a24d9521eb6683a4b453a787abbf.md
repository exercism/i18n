# 좋은 지원 요청을 작성하는 방법

Exercism에서 도움이 필요하신가요?
좋은 지원 요청을 작성하는 방법을 익히고, 커뮤니티가 기꺼이 도와주도록 만들어서 좋은 답변을 받을 가능성을 높여봐요.

몇 가지 중요한 팁을 알려드릴게요.

## 이미지 대신 코드 블록을 사용해요

직접 작성한 코드든 설명이든, 코드를 공유하고 싶을 때는 이미지 대신 코드 블록을 사용해요.

개발자에게는 이미지를 확대해서 들여다보는 것보다 코드를 읽는 게 훨씬 빨라요.
게다가 많은 사용자가 화면 낭독기를 쓰는데, 이런 프로그램은 이미지를 읽어 주지 못해요.
그러니 좋은 커뮤니티 구성원이 되고, 자원봉사자들의 도움을 받고, 프로처럼 보이고 싶다면 코드를 이미지가 아니라 텍스트로 공유해요!

예를 들어, 이렇게 입력할 수 있어요:

````
```
for number in range(10):
  total += number;
```
````

그러면 이렇게 렌더링돼요:

```
for number in range(10):
  total += number;
```

코드 블록 시작 부분에 언어를 적으면 문법 강조까지 적용할 수 있어요:

````
```python
for number in range(10):
  total += number;
```
````

이렇게 바뀌어요:

```python
for number in range(10):
  total += number;
```
