# 힌트

## 일반

- 불변 클래스에는 `new`가 없어요. `create`는 이미 존재하는 그 클래스의 변수에서
  시작해요:

  ```sather
     create(d : INT) : SAME is
        b : SAME;
        return b.degrees(...);
     end;
  ```

- `b.degrees(x)`는 `b`를 바꾸지 않아요. 새로운 방위를 반환하기 때문에, 반환할 값도
  바로 이것이에요.

## 1. 방위 구하기

- `%`는 수를 범위 안으로 가져와요. 하지만 `-10 % 360`이 `350`이 되는 것은
  Sather의 `%`가 오른쪽 피연산자가 양수일 때 절대 음수를 반환하지 않기 때문이에요.
  그래서 `d % 360`만으로 충분해요.

## 2. 회전하기

- 각도에 회전량을 더하고, 그 합으로 새로운 방위를 만들어요:
  `#BEARING(degrees + by)`.
- `create`가 이미 답을 범위 안으로 되돌려 주기 때문에, north를 넘어가는 회전은
  따로 처리할 게 없어요.

## 3. 비교하기

- 한 줄이면 돼요: 두 `degrees`를 비교해요.
- 인자의 타입은 `SAME`이고, 속성은 평소처럼 읽어요: `other.degrees`.

## 4. 방위점에 이름 붙이기

- 요령은 나누기 전에 한 구간의 절반만큼 먼저 옮겨서, 각 방위점의 *중심*을 기준으로
  재도록 하는 거예요: `((degrees + 22) / 45) % 8`은 north에 0, north-east에 1,
  그런 식으로 값을 줘요.
- 그다음 그 수에 대해 `case`를 쓰면서 여덟 개의 이름을 붙여요. 그리고 `else`도
  필요한데, 여덟 갈래가 모든 가능한 값을 다 덮는 경우에도 `case`에는 항상
  있어야 해요.

## 5. 적어 두기

- `+`는 조각들을 이어 붙여요. 하지만 무엇인가를 더할 수 있는 건 문자열뿐이에요.
  여기서는 수가 먼저 오기 때문에, 이어 붙이기를 시작하려면 `degrees.str`이
  필요해요. `"a" + 1`은 괜찮지만 `1 + "a"`는 컴파일되지 않아요.
- 이름을 다시 계산하지 말고 `point`를 호출해요.
