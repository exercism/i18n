# 지시 사항

주어진 도미노 세 개를 올바른 도미노 사슬이 되도록 배열할 수 있는지 판별해요. 올바른 사슬이란 한 조각의 한쪽 면에 있는 점이 인접한 조각의 맞닿은 면에 있는 점과 같고, 이웃이 없는 면(첫 번째 조각과 마지막 조각의 바깥쪽 면)에 있는 점끼리도 서로 같은 경우예요. 일부 테스트 케이스에서는 사슬 해답에 중복된 조각을 사용할 수 있어요. 올바른 도미노 사슬을 만들 수 있으면 `True`를, 그렇지 않으면 `False`를 반환해요. 

```text
For example, given: [(2,1),(2,3),(1,3)]
    True

For example, given: [(1,2),(4,1),(2,3)]
    False
```
