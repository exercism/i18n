# 소개

하드웨어 수준까지 내려가 보면, [트랜지스터는 켜지거나 꺼지는 두 가지 상태만 가질 수 있어요][how-transistors-work]. 이 두 상태는 전통적으로 `1`과 `0`으로 나타내죠.
이것을 [`binary digits`][binary-digits]라고 하며, 줄여서 [`bits`][bits]라고 해요.
`bits`와 `binary`에 대한 이해는 저수준 언어로 작업하는 시스템 프로그래머에게 특히 중요해요.
하지만 컴퓨팅 역사의 대부분 동안 프로그래밍의 우선순위는 이 이진적 현실을 _추상화_ 하는 점점 더 정교한 방법을 찾는 것이었어요.


Python(그리고 다른 많은 [고급 프로그래밍 언어][high-level-language])에서는 `int`, `float`, `string`을 비롯해 오디오와 비디오 형식에 이르기까지, 정의된 _타입_ 들을 다뤄요.
Python 내부에서는 (_결국에는_) 모든 상위 수준 데이터를 비트로 변환하는 일을 처리해요.


그럼에도 불구하고, [비트 연산자][python-bitwise-operators]와 [비트 연산][python-bitwise-operations]을 사용하면 Python처럼 고급 언어에서도 속도와 메모리 효율에서 상당한 이점을 얻을 수 있을 때가 있어요.
