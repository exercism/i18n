# 설치

## tclsh 설치하기

필요한 도구는 TCL 인터프리터인 `tclsh` 하나뿐이에요.

Windows에서는 [Magicsplat의 Tcl 설치 프로그램][magicsplat]에서 Tcl을 받는 것이 가장 좋아요.

MacOS와 유닉스 계열 운영체제에는 `tclsh`가 이미 설치되어 있을 거예요.
보통 설치된 버전은 8.6.*무언가*일 거예요.
현재 안정 버전인 9.0을 설치하려면:
 - MacOS에서는 [Homebrew][brew]를 사용해요.
 - Linux에서는 패키지 관리자를 확인해 봐요.
 - 또는 [소스를 내려받아][download] [직접 빌드해요][build].

Exercism 웹 인터페이스로 연습 문제를 풀 때 사용하는 테스트 러너는 (2023년 2월 기준) Tcl 버전 8.7a4를 사용해요.

## 대화형 tclsh 셸 사용하기

코드를 작성하면서 명령을 시험해 보려고 대화형 [`tclsh`][tclsh] 세션을 실행하는 일은 흔해요.
하지만 tclsh는 명령줄 편집이나 명령 기록 기능이 없는 아주 기본적인 REPL 인터프리터만 제공해요.
더 나은 환경을 원한다면 readline 기능을 추가해 주는 `rlwrap`이라는 프로그램이 있어요:

```bash
rlwrap tclsh
```

rlwrap을 설치하려면:
 - MacOS에서는 [Homebrew][brew]를 사용해요.
 - Linux에서는 패키지 관리자를 확인해 봐요.
 - 또는 [소스를 내려받아][rlwrap-download] [직접 빌드해요][rlwrap-build].

너무 편리해서 항상 쓰고 싶어질 거예요. ~/.bashrc에 다음을 추가해 봐요.

```bash
command -v rlwrap && alias tclsh='rlwrap tclsh'
```

## 어떤 버전을 사용할까요?

현재 안정 버전은 9.0이에요.
위에서 언급했듯이 버전 8.6은 아직도 널리 사용되고 있어요.

다음 명령을 실행하면 설치된 `tclsh`의 버전을 확인할 수 있어요:

```bash
echo 'puts [info patchlevel]' | tclsh
```
