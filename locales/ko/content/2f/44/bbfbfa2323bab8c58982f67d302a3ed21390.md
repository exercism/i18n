# golint를 통과하지 못했어요

코드에서 흔히 생기는 문제와 스타일 문제를 살펴봐 주는 [`golint`](https://github.com/golang/lint)라는 훌륭한 도구가 있어요.
풀이에 `golint`를 실행해 봐요. 예를 들어 `golint two_fer.go`처럼요. 그러면 유용한 제안을 몇 가지 해줄 거예요.

코드를 항상 `golint`로 확인하는 게 좋아요.
실제 서비스용 Go 소프트웨어를 작성할 때는 코드가 `golint`를 통과하지 못하면 자동으로 실패하는 빌드 파이프라인이 많아요.

코드 린터에게서 훨씬 많은 피드백을 받고 싶다면, 여러 린터를 명령 하나로 실행할 수 있게 해 주는 [golangci-lint](https://github.com/golangci/golangci-lint) 프로젝트가 있어요.
프로젝트 설정 파일로 프로젝트에 맞게 동작을 조정할 수 있어요.

```
> golint
%{golint}
```
