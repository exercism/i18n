# 소개

가장 친한 친구가 직소 퍼즐을 모으기 시작했고, 수집한 퍼즐의 자세한 목록을 만들고 싶어 해요. 전체 조각 수, 행과 열의 개수, 테두리 조각과 안쪽 조각의 개수, 가로세로 비율, 퍼즐 형식 같은 정보를 기록하려고요.
두 사람의 힘을 합쳐도 조각이 천 개나 되는 직소 퍼즐 하나를 맞추는 데 몇 시간이 걸려요. 게다가 그다음에는 행과 열을 세고 나머지 숫자들을 직접 계산해야 하죠.
조각이 수천 개에 달하는 더 큰 퍼즐들은 이제 꽤 막막해 보여요.
"분명 더 나은 방법이 있을 거예요!" 하고 외치며, 문제를 해결하려고 컴퓨터 앞에 앉아요.
