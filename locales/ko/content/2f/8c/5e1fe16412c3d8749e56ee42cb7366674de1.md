# 지침 추가

## Zipper 타입과 연산

`Zipper`를 사용하면 각 노드가 정수를 담는 이진 `Tree`를 순회하고 갱신할 수 있어요.

- `Tree.to_zipper`: 트리의 루트 노드에 초점을 맞춘 zipper를 만들어요.
- `to_tree`: zipper에서 트리를 꺼내요.
- `value`: 초점이 맞춰진 노드의 값을 가져와요.
- `left`와 `right`: 초점을 현재 노드의 왼쪽 또는 오른쪽 자식으로 옮기고, 새로운 zipper를 반환해요.
- `up`: 초점을 부모로 옮기고, 새로운 zipper를 반환해요.
- `set_value`: 초점이 맞춰진 노드의 값을 설정하고, 새로운 zipper를 반환해요.
- `set_left`와 `set_right`: 왼쪽 또는 오른쪽 자식을 교체하고, 새로운 zipper를 반환해요.
- `remove_left`와 `remove_right`: 왼쪽 또는 오른쪽 자식을 제거하고, 새로운 zipper를 반환해요.
