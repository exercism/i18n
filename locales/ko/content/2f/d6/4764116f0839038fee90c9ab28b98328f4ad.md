## 선택적 인자

```julia-repl
julia> f(a, b=1) = a + b
f (generic function with 2 methods)
```

다음과 동일해요.

```julia-repl
julia> f(a, b) = a + b
f (generic function with 1 method)

julia> f(a) = f(a, 1)
f (generic function with 2 methods)
```

REPL의 응답을 보면 첫 번째 정의가 메서드 두 개를 한 번에 정의한다는 걸 알 수 있어요.
