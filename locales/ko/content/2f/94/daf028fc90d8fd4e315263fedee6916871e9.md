# 지침 추가

## 보드 형식

보드는 null로 끝나는 문자열로 표현되며, 각 행의 끝에는 줄바꿈 문자가 있어요.

예를 들어 `"X  \n XO\nOX \n"` 같은 문자열이에요.

## 레지스터

| 레지스터 | 용도        | 타입    | 설명                                                             |
| -------- | ------------ | ------- | ----------------------------------------------------------------------- |
| `$a0`    | 입력        | 주소 | null로 끝나는 입력 문자열                                            |
| `$v0`    | 출력       | 정수 | 게임 상태 (`1` = `ongoing`, `2` = `draw`, `3` = `win`, `-1` = `error`) |
| `$t0-9`  | 임시    | 임의     | 임시 저장용                                                   |
