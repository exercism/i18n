# 소개

키워드 리스트는 키-값 데이터 구조예요.

```elixir
[month: "April", year: 2018]
```

키워드 리스트는 `{key, value}` [튜플][exercism-tuples]의 리스트이고, 같은 내용을 길게 풀어서 쓸 수도 있지만 더 짧은 문법이 훨씬 널리 쓰여요.

```elixir
[month: "April"] == [{:month, "April"}]
# => true
```

키워드 리스트의 키는 반드시 [아톰][exercism-atoms]이어야 하지만, 값은 무엇이든 될 수 있어요. 각 키를 여러 번 사용할 수도 있고, 키워드 리스트의 키-값 쌍에는 순서가 있어요.

키워드 리스트는 리스트를 다룰 때와 같은 방식으로 다룰 수도 있고, `Keyword` 모듈을 사용할 수도 있어요.

[exercism-tuples]: https://exercism.org/tracks/elixir/concepts/tuples
[exercism-atoms]: https://exercism.org/tracks/elixir/concepts/atoms
