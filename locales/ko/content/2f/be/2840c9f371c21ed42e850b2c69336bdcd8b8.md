# 소개

## 문자열

C#에서 `string`은 변경할 수 없는 텍스트를 유니코드 문자(글자, 숫자, 문장 부호 등)의 나열로 나타내는 객체예요. `string` 인스턴스는 큰따옴표로 정의해요.

```csharp
string fruit = "Apple";
```

### 메서드

문자열은 문자열의 [내장 메서드][docs-string-methods]를 호출해서 다뤄요.
예를 들어 문자열에서 공백을 없애려면 다음과 같이 [Trim 메서드][tutorial-docs.microsoft.com-trim-white-space]를 사용할 수 있어요.

```csharp
string name = " Jane "
name.Trim()
// => "Jane"
```

문자열은 한 번 만들어지면 그 값을 절대 바꿀 수 없어요.
문자열을 수정하는 것처럼 보이는 메서드도 실제로는 새로운 문자열을 반환해요.

### 연결

여러 문자열을 서로 연결(더하기)할 수 있어요. 가장 간단한 방법은 `+` 연산자를 사용하는 거예요.

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

### 서식 지정

단순한 연결보다 복잡한 문자열 서식에는 문자열 보간을 사용하는 게 좋아요. 문자열에서 보간을 사용하려면 문자열 앞에 달러(`$`) 기호를 붙여요. 그런 다음 중괄호(`{}`)를 사용해 문자열 안의 변수에 접근할 수 있어요.

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
