# 자세히 알아보기

- Pony는 정적 타입 언어예요. 이 말은 프로그램에서 다루는 데이터의 타입을 미리 *반드시* 정의해야 한다는 뜻이에요. 변수 `x`가 정수라고 Pony에게 알려주면, 거기에 문자열을 할당할 수 없어요.
- Pony의 타입 시스템이 Pony의 여러 보장을 가능하게 해줘요.
  - 프로그램이 컴파일되면 크래시하지 않아요.
  - 처리되지 않은 예외가 생기는 일은 없어요.
  - `null`이라는 건 존재하지 않아요. 그래서 프로그램이 `null`을 역참조하려고 하는 일도 없어요.
  - 데이터 레이스가 생기는 일도 없어요.
  - 데드락이 생기는 일도 없어요.
  - 코드는 항상 capabilities 보안이 보장돼요. 이는 공급망 공격으로부터의 보호를 뜻해요.
- Pony는 타입을 캐스팅하는 걸 허용하지 않아요. 모든 타입 변경은 새 타입의 인스턴스를 만드는 함수를 통해서만 일어나야 해요.
- Pony의 타입 시스템은 대부분의 다른 언어와 달라요. 그래서 작은 단위로 나눠서 살펴볼게요.

## 프리미티브

- 프리미티브는 Pony에서 코드를 구성하는 가장 단순한 형태예요.
  - 함수를 담는 컨테이너나 네임스페이스라고 생각하면 돼요.
  - 필드는 없어요 (필드가 필요하면 클래스를 써요).
  - `primitive` 키워드로 정의해요.

## 함수

- 함수는 `fun` 키워드로 정의해요.
  - 함수는 `primitive` (또는 `class`나 `actor`) 안에 있어야 해요. 하지만 그것들은 나중에 다뤄요.
  - 함수는 인자를 받을 수도, 반환 값을 가질 수도 있어요. 타입은 반드시 지정해야 해요.
  - 반환 타입을 정의했다면, 함수는 *반드시* 그 타입의 값을 반환해야 해요. Pony에는 Null이라는 개념이 없어요.

```pony
primitive Greeter
  // A Function that takes a String, and returns a different String
  fun hello(name: String): String =>
    "Hello " + name + "!"
```

## 주석

주석은 메모나 알림을 남기거나, 소스 코드에서 코드를 잠시 제거하는 데 사용할 수 있어요. 위에서 이미 봤듯이, 한 줄 주석은 `//`를 사용해요. 여러 줄 주석은 C 스타일의 `/*`와 `*/`를 사용해요.

## 변수

- 변수는 항상 소문자로 시작해요.
  - 변수는 `var`로 선언해요. (`let`과 `embed`는 나중에 다뤄요.)
  - Pony가 변수 타입을 알아낼 수 있으면 알아서 정해줘요.
  - 변수의 타입은 컴파일 시점에 검사되고, 절대 바뀌지 않아요.
  - Pony를 처음 시작할 때는 타입을 명시하는 걸 추천해요.

```pony
var name: "Bob"
var bettername: String = "Bobby"
```
