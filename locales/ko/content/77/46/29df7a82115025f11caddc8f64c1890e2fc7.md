# 소개

[ReScript][rescript-lang]로 작성하고, JavaScript로 배포해요.
OCaml의 견고한 타입 시스템과 BuckleScript, ReasonML의 현대적인 후속을 바탕으로, ReScript는 JavaScript 생태계 안에서 빠짐없는 패턴 매칭과 컴파일 타임 보장을 제공해요.
일급 React 지원 덕분에 ReScript는, 타입을 덧붙인 JavaScript가 아닌 진정한 타입 안전성을 원하는 개발자에게 TypeScript를 대신할 만한 매력적인 대안이 돼요.
`any`도 없고, 예상치 못한 `undefined`도 없어요.

[rescript-lang]: https://rescript-lang.org
