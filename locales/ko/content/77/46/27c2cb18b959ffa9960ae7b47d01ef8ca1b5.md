# 힌트

## 일반

- 테스트 앱에서는 [`roc-random` 패키지](https://github.com/kili-ilo/roc-random)를 `random`이라는 별칭으로 사용할 수 있어요.
  스텁은 `random.Random`을 임포트해요.

- `Random.Generator(a)`는 `a` 타입의 값을 만들어 내는 방법을 나타내요.

- `Random.list`로 여러 번 뽑은 값을 하나로 묶고, `Random.map`으로 그 결과를 변환해요.

- `Random.step(state, generator)`는 `{ value, state }`를 반환해요. 시뮬레이션한 그룹 사이에서 갱신된 상태를 계속 넘겨서 같은 표본을 반복하지 않도록 해요.
