# 지침 추가

## IO 처리 과정

다른 연습 문제와 달리 `grep`은 "외부 세계"와 상호작용해야 해요. 파일을 읽고, 시스템 오류를 처리하고, `stdout`에 출력하는 일이죠.

Lean에서는 보통 [IO][io] 모나드 안에서 시스템과 상호작용해요. 이 모나드는 대부분의 다른 함수들의 순수한 상태에 영향을 주지 않으면서, 부작용이 통제된 환경 안에서 일어나도록 해줘요.

## 인자 읽기

Lean에서는 파일을 스크립트로 실행할 수 있어요. `lean --run`으로 독립 실행형 스크립트로 바로 실행하거나, `lake`를 이용해서 실행할 수 있죠.

Lean 프로젝트에는 진입점이 하나 있는데, `main`이라는 함수예요. 이 함수는 전달된 모든 인자를 담은 `List String`을 받아요. 이 연습 문제에서는 `Grep.lean`을 실행 파일처럼 실행하는 것을 흉내 내기 위해, 같은 방식으로 인자를 전달해요.

## 파일 읽기

Lean은 `IO.FS` 모나드 안에서 파일을 다루는 [함수][files]를 제공해요. 예를 들어 `IO.FS.readFile`을 사용하면 주어진 경로에 있는 파일의 내용을 `String`으로 읽을 수 있어요.

## 출력 쓰기

이 연습 문제에서는 값을 반환하는 대신, 결과를 표준 출력이나 표준 오류에 써야 해요. Lean에는 이를 위한 [함수][console]가 있어요.

## 시스템 오류 처리

`Except`의 오류와 달리, `IO` 예외는 실제 런타임 예외예요. `try`/`catch`를 사용해서 처리할 수 있어요:

```
try
    /- 
        code that may possibly raise an exception 
    -/
catch msg =>
    /-
        code that is executed only if an exception was thrown
    -/
```
