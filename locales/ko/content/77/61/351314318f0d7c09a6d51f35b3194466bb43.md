# 지침

이 연습 문제에서는 여동생이 학교에 낼 글을 다듬는 일을 도와줘요. 선생님은 올바른 문장 부호와 문법, 그리고 훌륭한 단어 선택을 기대해요.

문자열을 다듬고 수정하는 네 가지 작업이 있어요.

## 1. 글 제목의 첫 글자를 대문자로 만들기

좋은 글에는 제대로 된 형식의 제목이 필요해요.
`capitalize_title(<title>)` 함수를 구현해요. 이 함수는 제목 `str`을 매개변수로 받아 각 단어의 첫 글자를 대문자로 만들어요.
이 함수는 제목 형식의 `str`을 반환해야 해요.


```python
>>> capitalize_title("my hobbies")
"My Hobbies"
```

## 2. 각 문장이 마침표로 끝나는지 확인하기

글의 문장 부호가 완벽한지 확인하고 싶어요.
`check_sentence_ending()` 함수를 구현해요. 이 함수는 `sentence`를 매개변수로 받아요. `bool`을 반환해야 해요.


```python
>>> check_sentence_ending("I like to hike, bake, and read.")
True
```

## 3. 불필요한 공백 정리하기

글이 전문적으로 보이게 하려면 불필요한 공백을 없애야 해요.
`clean_up_spacing()` 함수를 구현해요. 이 함수는 `sentence`를 매개변수로 받아요.
이 함수는 문장의 앞과 뒤에 있는 여분의 공백을 제거하고, 다듬어진 새로운 문장 `str`을 반환해야 해요.


```python
>>> clean_up_spacing(" I like to go on hikes with my dog.  ")
"I like to go on hikes with my dog."
```

## 4. 단어를 동의어로 바꾸기

글을 _더욱 좋게_ 만들려면 일부 형용사를 동의어로 바꿀 수 있어요.
`replace_word_choice()` 함수를 작성해요. 이 함수는 `sentence`, `old_word`, `new_word`를 매개변수로 받아요.
이 함수는 `old_word`를 모두 `new_word`로 바꾸고, 수정된 문장이 담긴 새로운 `str`을 반환해야 해요.


```python
>>> replace_word_choice("I bake good cakes.", "good", "amazing")
"I bake amazing cakes."
```
