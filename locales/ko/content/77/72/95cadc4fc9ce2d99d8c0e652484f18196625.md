# 지시 사항

친구 Chandler는 세계 곳곳의 이국적인 나라들을 여행할 계획이에요. 그런데 안타깝게도 Chandler는 수학을 잘하지 못해요. Chandler는 여행 중에 환전소에서 사기를 당할까 봐 꽤 걱정하고 있어요. 그래서 환전 계산기를 하나 만들어 달라고 해요.

## 1. 환전 후 가치 추정하기

`budget`과 `exchange-rate`를 매개변수로 받아 환전한 통화의 가치를 반환하는 `exchange-money`를 정의해요.

**참고:** 기준 통화가 USD이고, 환율이 `1.20`일 때 USD를 EUR로 환전한다면, `1.20 USD == 1 EUR`예요.

```factor
127.5 1.2 exchange-money .
! => 106.25
```

## 2. 환전 후 남은 금액 계산하기

`budget`(환전 전)과 `exchanging-value`(환전하려고 예산에서 떼어낸 금액)을 매개변수로 받는 `get-change`를 정의해요. 그리고 남은 금액을 반환해요.

```factor
127.5 120 get-change .
! => 7.5
```

## 3. 지폐 가치 계산하기

지폐 한 장의 가치인 `denomination`과 `number-of-bills`를 매개변수로 받는 `value-of-bills`를 정의해요. 그리고 지폐의 총 가치를 반환해요.

```factor
5 128 value-of-bills .
! => 640
```

## 4. 지폐 개수 계산하기

`amount`와 `denomination`을 매개변수로 받는 `number-of-bills`를 정의해요. 주어진 `denomination`의 *온전한 지폐*가 그 금액에 몇 장 들어가는지 반환해요. 내림해요. 소수 단위의 지폐는 존재하지 않아요.

```factor
127.5 5 number-of-bills .
! => 25
```

## 5. 지폐로 환전한 후 남은 금액 계산하기

`amount`와 `denomination`을 매개변수로 받는 `leftover-of-bills`를 정의해요. 온전한 지폐로 돌려줄 수 없는 나머지 금액을 반환해요.

```factor
127.5 20 leftover-of-bills .
! => 7.5
```

## 6. 환전 후 가치 계산하기

`denomination`, `budget`, `spread`, `exchange-rate`를 매개변수로 받는 `exchangeable-value`를 정의해요.

`spread`는 환전 수수료로 떼는 *백분율*이고, 정수로 적어요. 이 값은 분수로 바꿔서 환율에 더해야 해요. `1.00 EUR == 1.20 USD`이고 spread가 `10`이라면, 총 환율은 `1.00 EUR == 1.32 USD`예요(1.20의 10%는 0.12이고, 이걸 1.20에 더해요).

환율에 spread를 더한 값을 적용한 뒤 얻을 수 있는 새 통화의 최댓값을, 주어진 `denomination`의 온전한 지폐 단위로 내림해서 반환해요. 반환되는 값은 정수예요.

```factor
20 127.25 10 1.20 exchangeable-value .
! => 80

5 127.25 10 1.20 exchangeable-value .
! => 95
```

## 7. 안전한 잔돈

`get-change`와 비슷하지만, Chandler가 실수로 예산보다 큰 환전 금액을 입력했다면 음수 대신 `0`을 반환해요. `budget`과 `exchanging-value`를 매개변수로 받는 `safe-change`를 정의해요.

```factor
127.5 120 safe-change .
! => 7.5

50 100 safe-change .
! => 0
```

## 8. 예산으로 상한 정하기

Chandler는 기념품을 사려고 값을 깎고 있어요. `budget`과 `price`를 매개변수로 받아 둘 중 더 작은 값, 즉 실제로 낼 수 있는 최대 금액을 반환하는 `cap-spend`를 정의해요.

```factor
100 30 cap-spend .
! => 30

20 30 cap-spend .
! => 20
```
