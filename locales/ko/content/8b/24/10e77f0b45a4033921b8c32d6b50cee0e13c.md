# 소개

## 이터레이터

Gleam의 `Iterator`는 순서가 있는 값의 모음이라는 점에서 배열과 비슷해요. 모든 값이 같은 타입이어야 하죠. 배열과 다른 점은 지연 방식이라는 거예요. 즉, 모든 값을 한꺼번에 메모리에 저장하지 않고 필요할 때 계산해요.

이 방식은 매우 크거나 심지어 무한한 시퀀스를 다룰 때 유용해요. 모든 값을 한꺼번에 저장할 만큼 메모리가 충분하지 않아도 다룰 수 있게 해주거든요.

`gleam/iterator` 모듈은 `Iterator` 타입과 함께 이터레이터를 다루는 함수들을 정의해요.

배열을 위한 많은 함수들이 이터레이터에도 있어요. `map`, `filter`, `take` 같은 함수들이죠. 이 함수들은 이터레이터를 반환하기 때문에, 이터레이터가 소비되기 전까지는 실제로 아무 작업도 하지 않아요.

```gleam
let iter = 
  [1, 2, 3, 4, 5, 6]
  |> iterator.from_list
  |> iterator.filter(fn(x) { x > 2 })
  |> iterator.take(2)

// No work has been done yet as the iterator has not been consumed

// Consume the iterator and collect the values into a list
iterator.to_list(iter)
// -> [3, 4]
```

`unfold` 함수를 사용하면 시퀀스의 다음 값을 만들기 위해 반복적으로 호출되는 함수로부터 이터레이터를 만들 수 있어요.

다음은 `unfold` 함수로 피보나치 수열을 생성하는 이터레이터를 만드는 예예요:

```gleam 
iterator.unfold(#(0, 1), fn(pair) {
  let x = pair.0 + pair.1
  iterator.Next(element: x, accumulator: #(pair.1, x))
})
|> iterator.take(6)
|> iterator.to_list
// -> [1, 2, 3, 5, 8, 13]
```

여기서 시퀀스는 무한하기 때문에, 값을 배열로 모으기 전에 `take` 함수를 사용해 유한하게 만들어요. 무한한 이터레이터에 `to_list`를 호출하면, 프로그램이 메모리가 부족해질 때까지 실행되다가 충돌해요.
