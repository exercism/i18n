# 소개

## 열거형

_열거형_은 변수가 미리 정의된 상수 중 하나의 값을 가지도록 해주는 특별한 자료형이에요.
변수의 값은 그 열거형에 대해 미리 정의된 값 중 하나여야 해요.
흔한 예로는 나침반 방향(`NORTH`, `SOUTH`, `EAST`, `WEST` 값)과 요일이 있어요.

상수이기 때문에 열거형 필드의 이름은 대문자로 써요.

### 열거형 정의하기

Java 프로그래밍 언어에서는 `enum` 키워드를 사용해 열거형을 정의해요.
예를 들어, 요일 열거형은 다음과 같이 정의해요:

```java
public enum DayOfWeek {
    SUNDAY,
    MONDAY,
    TUESDAY,
    WEDNESDAY,
    THURSDAY,
    FRIDAY,
    SATURDAY
}
```

고정된 상수 집합을 표현해야 할 때는 언제든 열거형을 사용하는 게 좋아요.
여기에는 태양계의 행성처럼 자연스럽게 열거형이 되는 것들과, 컴파일 시점에 가능한 모든 값을 알고 있는 데이터 집합(예를 들어 메뉴의 선택지, 명령줄 플래그 등)이 포함돼요.

### 열거형 사용하기

위에서 정의한 `DayOfWeek` 열거형을 사용하는 방법을 보여주는 코드예요:

```java
public class Shop {
    public String getOpeningHours(DayOfWeek dayOfWeek) {
        switch (dayOfWeek) {
            case MONDAY:
            case TUESDAY:
            case WEDNESDAY:
            case THURSDAY:
            case FRIDAY:
                return "9am - 5pm";
            case SATURDAY:
                return "10am - 4pm"
            case SUNDAY:
                return "Closed.";
        }
    }
}
```

```java
var shop = new Shop();
shop.getOpeningHours(DayOfWeek.WEDNESDAY);
// => "9am - 5pm"
```

### 메서드와 필드 추가하기

Java 프로그래밍 언어의 열거형은 다른 언어의 열거형보다 훨씬 강력해요.
`enum` 선언은 하나의 _클래스_를 정의해요. 이 클래스를 _열거형_이라고 불러요.
열거형 클래스의 본문에는 메서드나 다른 필드를 포함할 수 있어요:

```java
public enum Rating {
    GREAT(5),
    GOOD(4),
    OK(3),
    BAD(2),
    TERRIBLE(1);

    private final int numberOfStars;

    Rating(int numberOfStars) {
        this.numberOfStars = numberOfStars;
    }

    public int getNumberOfStars() {
        return this.numberOfStars;
    }
}
```

`Rating` 열거형의 멤버에서 `getNumberOfStars` 메서드를 호출하면:

```java
Rating.GOOD.getNumberOfStars();
// => 4
```
