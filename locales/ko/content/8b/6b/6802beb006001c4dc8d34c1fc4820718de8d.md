# 지침

이번 과제는 비밀번호 검사기를 만드는 거예요.
비밀번호 검사기는 사용자가 제안한 비밀번호가, 해당 리소스에 대한 접근을 관리하는 조직이 정한 일련의 요구 사항을 충족하는지 검증해요.

이 연습 문제에서 비밀번호 요구 사항은 다음과 같아요.
* 12자 이상이어야 해요
* 대문자가 적어도 하나 있어야 해요
* 소문자가 적어도 하나 있어야 해요
* 숫자가 적어도 하나 있어야 해요
* `!@#$%^&*` 집합에 속하는 기호가 적어도 하나 있어야 해요

풀이에서는 `Result`를 사용해 성공 또는 실패 상태를 담아야 해요.
성공한 경우, `Result`는 검증된 비밀번호를 문자열로 담아야 해요.
실패한 경우, `Result`는 위반한 규칙을 담아야 해요.

~~~~exercism/note
이 연습 문제의 비밀번호 검사기는 아주 단순해요. 규칙이 하나 위반된 경우에만 그 사실을 알려줘요.
다음 연습 문제에서는 여러 규칙이 동시에 위반된 경우도 알려줄 수 있는, 좀 더 현실적인 비밀번호 검사기를 살펴봐요.
~~~~

## 1. `checkPassword` 함수 구현하기

`checkPassword` 함수는 주어진 비밀번호가 앞에서 설명한 규칙을 충족하는지 검사해요. 실패하면, 결과 값 안에 `PasswordRule` 값 중 하나를 담아서 어떤 규칙을 위반했는지 알려줘요.

```fsharp
checkPassword "abcdefghij5#"
// => Error MissingUppercaseLetter
```

## 2. ``getStatusMessage` 함수 구현하기

`getStatusMessage` 함수는 `checkPassword`가 반환한 결과의 의미를 사람이 읽을 수 있는 메시지로 담은 문자열을 반환해요.

```fsharp
getStatusMessage (Error MissingDigit)
// => "Error: does not have at least one digit"
```
