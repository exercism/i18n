# 힌트

## 일반

- [`Map` API 문서][map-docs]에는 `Map` 인터페이스에서 사용할 수 있는 메서드 목록이 있어요.

## 1. 코드를 맵으로 반환하기

- 클래스 메서드에서 사용할 수 있도록 [적절한 방식][declaring-members]으로 `Map`을 정의해야 해요.

## 2. 딕셔너리에 항목 추가하기

- 맵에는 키의 값을 추가하고 갱신하는 [메서드][map-put-docs]가 있어요.

## 3. 지역 번호의 국가 조회하기

- 맵에는 키의 값을 가져오는 [메서드][map-get-docs]가 있어요.

## 4. 중복을 허용하지 않기

- 맵에 [키][map-contains-key-docs]나 [값][map-contains-value-docs]이 있는지 확인하는 방법이 있어요.

## 5. 국가의 지역 번호 찾기

- 맵의 항목들을 반복해서 살펴볼 수 있는 컬렉션을 가져오는 [방법][map-entry-set-docs]이 있어요. 이 컬렉션을 이용하면 키와 값의 쌍을 하나씩 확인할 수 있어요.

## 6. 국가의 지역 번호 업데이트하기

- 국가의 이전 지역 번호가 맵에 그대로 남아 있다는 점을 잊지 마세요.
- 맵에서 항목을 제거하는 [메서드][map-remove-docs]가 있어요.
