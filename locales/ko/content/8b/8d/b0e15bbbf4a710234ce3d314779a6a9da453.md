# 지시 사항

번호표 발권기를 위한 임베디드 시스템을 작성하고 있어요. 아주 단순한 모델이에요. 이 기계는 연속된 번호를 내주고, 마지막으로 내준 번호가 무엇이었는지 알려줄 수 있어요.

## 1. 기계 시작하기

`start/0` 함수를 구현해요. 이 함수는 새 프로세스를 생성하고 그 프로세스의 PID를 반환해야 해요. 새 프로세스는 아직 아무것도 하지 않아도 돼요.

```elixir
TakeANumber.start()
# => #PID<0.138.0>
```

이 코드를 실행할 때마다 PID는 다를 수 있어요.

## 2. 기계 상태 보고하기

새로 생성된 프로세스가 초기 상태 `0`으로 메시지를 받을 준비를 하도록, 즉 _receive_ 루프를 시작하도록 기계를 수정해요. 이 프로세스는 `{:report_state, sender_pid}` 메시지를 받을 수 있어야 해요. 그런 메시지에 대한 응답으로 자신의 현재 상태(마지막으로 내준 번호)를 `sender_pid`에게 보내고, 그런 다음 다시 메시지를 기다려요.

```elixir
machine_pid = TakeANumber.start()

# a client sending a message to the machine
send(machine_pid, {:report_state, self()})

# a client receiving a message from the machine
receive do
  msg -> msg
end

# => 0
```

## 3. 번호 내주기

`{:take_a_number, sender_pid}` 메시지를 받을 수 있도록 기계를 수정해요. 상태를 1만큼 증가시키고, 새로운 상태를 `sender_pid`에게 보낸 다음, 다시 메시지를 기다려요.

```elixir
machine_pid = TakeANumber.start()

# a client sending a message to the machine
send(machine_pid, {:take_a_number, self()})

# a client receiving a message from the machine
receive do
  msg -> msg
end

# => 1
```

## 4. 기계 멈추기

`:stop` 메시지를 받을 수 있도록 기계를 수정해요. 그러면 더 이상 메시지를 기다리지 않아요.

## 5. 예상치 못한 메시지 무시하기

예상치 못한 메시지를 받았을 때, 그 메시지를 무시하고 계속해서 다음 메시지를 기다리도록 기계를 수정해요.
