# Debug

테스트가 실패하면 무엇이 잘못됐는지와 어떤 입력 때문인지 설명하는 메시지가 표시돼요. 또한 어떤 [콘솔 출력][programiz.com-basic-input-output]이든 함께 표시된다는 점을 활용할 수 있어요. 콘솔에 쓰려면 다음을 사용해요:

```csharp
Console.WriteLine("Debug message");
```
