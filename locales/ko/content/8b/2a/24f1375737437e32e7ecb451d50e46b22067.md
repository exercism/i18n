# 소개

필터링은 원래 시퀀스에서 몇몇 원소를 제외한 나머지를 복사해 새로운 시퀀스를 만드는 과정이에요.
새 시퀀스에 어떤 항목을 포함할지는 술어 함수(불리언 값으로 평가되는 함수)로 정할 수도 있고, 특정 객체와의 동등성 비교로 정할 수도 있어요.

## 술어로 제거하기

`remove-if`는 술어 함수와 시퀀스를 인자로 받아서, 술어가 거짓으로 평가된 원소들만으로 이루어진 시퀀스를 반환하는 함수예요.
다시 말해, 술어가 참으로 평가되는 원소는 모두 "제거"되는 거예요. 그렇지만 이 함수는 원래 시퀀스를 변경하지 않는다는 점에 주의해요!
대신 해당 원소들이 빠진 새로운 시퀀스를 반환해요. 술어가 모든 값에 대해 참이었다면 빈 시퀀스를 반환해요.

```lisp
(remove-if #'evenp '(1 2 3 4 5)) ; => (1 3 5)
(remove-if #'oddp '(1 3 5))      ; => ()
```

## 특정 항목 제거하기

시퀀스에서 특정 항목을 제거하고 싶다면 `remove`를 사용하면 돼요. 이 함수는 제거할 항목과 시퀀스를 인자로 받아요.
제거할 항목과 같지 않은 시퀀스의 모든 값이 반환돼요.
참고: 같은지 여부는 기본적으로 `eql` [제네릭 동등성 술어][concept-equality]로 확인해요.

```lisp
(remove 1 '(1 2 1 3 1 4)) ; => (2 3 4)
(remove #\l "hello")      ; => "heo"
```
