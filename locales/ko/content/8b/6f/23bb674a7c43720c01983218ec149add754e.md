# 소개

## 외부 함수

Gleam은 Erlang 가상 머신(BEAM)에서 실행할 수도 있고, JavaScript 런타임에서 실행할 수도 있어요. 이 런타임들을 사용하는 다른 언어도 아주 많고, 이런 언어로 작성된 코드를 Gleam에서 호출할 수 있으면 유용한 경우가 많아요.

Gleam의 _외부 함수_ 기능을 사용하면 다른 언어의 함수를 Gleam으로 가져와서 런타임 오버헤드 없이 호출할 수 있어요.

Gleam 프로젝트가 Erlang 가상 머신에서 실행되고, Erlang `lists` 모듈의 `reverse` 함수를 호출하고 싶다면, Gleam 함수 헤드에 `@external` 속성을 다음과 같이 추가하면 돼요:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

그러면 이 함수를 평범한 Gleam 함수처럼 호출할 수 있어요:

```gleam
let reversed = reverse_list([1, 2, 3])
// -> [3, 2, 1]
```

이 코드를 JavaScript 런타임용으로 컴파일하려고 하면, JavaScript 구현이 없기 때문에 오류 메시지와 함께 실패해요. 다음과 같이 JavaScript 런타임용 구현을 따로 지정할 수 있어요:

```gleam
@external(erlang, "lists", "reverse")
@external(javascript, "./my_module.mjs", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

현재 컴파일 대상에 대한 외부 구현이 없을 때 사용할 Gleam 구현을 작성할 수도 있어요:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a) {
  tail_recursive_reverse(x, [])
}

fn tail_recursive_reverse(list, reversed) {
  case list {
    [] -> reversed
    [x, ..xs] -> tail_recursive_reverse(xs, [x, ..reversed])
  }
}
```

## 외부 타입

외부 타입을 사용하면 Erlang이나 JavaScript처럼 다른 언어에서 정의된 데이터 타입을 가리킬 수 있어요.

외부 타입을 정의하려면 타입을 선언하되 생성자는 하나도 제공하지 않으면 돼요. 그러면 다른 타입과 똑같은 방식으로 사용할 수 있어요.

```gleam
pub type OrderedDictionary(element)
```
