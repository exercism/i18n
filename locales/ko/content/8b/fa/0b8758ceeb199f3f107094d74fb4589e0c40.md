# 표현

[Java representer][github-java-representer]는 다음과 같은 정규화를 적용해요:

- 모든 주석을 제거해요
- 모든 import 선언을 제거해요
- 식별자를 플레이스홀더 값으로 정규화해요

위 정규화를 적용한 다음에는 코드 서식에 남은 차이를 없애기 위해, 그렇게 만들어진 표현을 [Google Java Style][google-java-style]에 맞춰 서식해요.

## 제출하기 전에

다음 사항을 확인해 봐요:

- analyzer가 이미 준 피드백을 중복해서 주지 않았는지 확인해요.
- 제출 대화 상자의 "examples" 탭을 확인하고, 그 피드백이 모든 탭에 맞는지 살펴봐요.
- 공백이나 주석을 언급하지 않았는지 확인해요.
- 풀이에 나오는 그대로의 함수 이름이나 변수 이름을 언급하지 않고, 제공된 매핑을 사용하거나 이름을 아예 쓰지 않았는지 확인해요.
  연습 문제 테스트에서 사용하는 식별자만 안전하게 언급할 수 있는데, 이런 식별자는 누구에게나 항상 같기 때문이에요.

[github-java-representer]: https://github.com/exercism/java-representer
