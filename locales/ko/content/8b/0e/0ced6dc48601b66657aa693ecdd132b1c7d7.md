# 지침

지금 호평을 받는 신작 게임 **Crystal Hunter**를 개발하고 있어요.
게임 속에서 이리저리 돌아다니며 크리스탈을 모으는 캐릭터가 돼요.
플레이어는 크리스탈을 모두 주우면 이겨요.
플레이어가 도적과 접촉하면 크리스탈을 전부 잃고 게임에서도 지게 돼요.
이 규칙에는 예외가 있어요. 플레이어가 활성화된 파워업을 가지고 있으면 도적에게 보이지 않게 돼요.

목표는 게임에서 사용할 규칙 몇 가지를 작성하는 거예요.

## 1. 캐릭터가 보너스 점수를 받는지 정의하기

게임에서 캐릭터는 파워업을 가진 상태로 도적과 접촉하면 보너스 점수를 받아요.

`Rules#bonus_points?` 메서드를 정의해요. 이 메서드는 두 개의 인자(_캐릭터가 활성화된 파워업을 가지고 있는지_와 _캐릭터가 도적과 접촉하고 있는지_)를 받아서, 캐릭터가 보너스 점수를 받을지 여부를 알려 주는 불리언 값을 반환해요.
이 메서드는 캐릭터가 활성화된 파워업을 가지고 있으면서 도적과 접촉하고 있을 때만 `true`를 반환하고, 그렇지 않으면 `false`를 반환해야 해요.

```Crystal
Rules.new.bonus_points?(false, true)
# => false
```

## 2. 캐릭터가 점수를 얻는지 정의하기

플레이어는 게임에서 크리스탈이나 파워업을 주우면 점수를 얻어요.

`Rules#score?` 메서드를 정의해요. 이 메서드는 두 개의 인자(_캐릭터가 파워업과 접촉하고 있는지_와 _캐릭터가 크리스탈과 접촉하고 있는지_)를 받아서, 캐릭터가 점수를 얻었는지 여부를 나타내는 불리언 값을 반환해요.
이 메서드는 캐릭터가 파워업이나 크리스탈과 접촉하면 `true`를 반환하고, 그렇지 않으면 `false`를 반환해야 해요.

```crystal
Rules.new.score?(true, true)
# => true
```

## 3. 캐릭터가 지는지 정의하기

`Rules#lose?` 메서드를 정의해요. 이 메서드는 두 개의 인자(_캐릭터가 활성화된 파워업을 가지고 있는지_와 _캐릭터가 도적과 접촉하고 있는지_)를 받아서, 캐릭터가 지는지 여부를 나타내는 불리언 값을 반환해요.
이 메서드는 캐릭터가 도적과 접촉하고 있으면서 활성화된 파워업이 없으면 `true`를 반환하고, 그렇지 않으면 `false`를 반환해야 해요.

```crystal
Rules.new.lose?(false, true)
# => true
```

## 4. 캐릭터가 이기는지 정의하기

`Rules#win?` 메서드를 정의해요. 이 메서드는 세 개의 인자(_캐릭터가 모든 크리스탈을 주웠는지_, _캐릭터가 활성화된 파워업을 가지고 있는지_, _캐릭터가 도적과 접촉하고 있는지_)를 받아서, 캐릭터가 이기는지 여부를 나타내는 불리언 값을 반환해요.
이 메서드는 캐릭터가 모든 크리스탈을 모았고 3번에서 정의한 인자를 기준으로 지지 않았다면 `true`를 반환하고, 그렇지 않으면 `false`를 반환해야 해요.

```crystal
Rules.new.win?(false, true, false)
# => false
```
