# 소개

Gleam에는 두 가지 종류의 숫자가 있어요. 바로 정수와 실수예요.

정수는 소수점이 없는 수예요.

```gleam
let integer = 3
// -> 3
```

정수에는 밑줄을 넣어 더 알아보기 쉽게 만들 수도 있어요.

```gleam
1_000_000 // One million
```

Gleam에는 정수와 함께 사용하는 여러 연산자가 있어요.

```gleam
1 + 1 // -> 2
5 - 1 // -> 4
5 / 2 // -> 2
3 * 3 // -> 9
5 % 2 // -> 1

2 > 1  // -> True
2 < 1  // -> False
2 >= 1 // -> True
2 <= 1 // -> False
```
