# 테스트

웹사이트 테스트 실행기로 [pytest][pytest: Getting Started Guide]를 사용해요.
Python 트랙의 테스트를 로컬에서 실행하려면 개발 머신에 `pytest`를 설치해야 해요.
다음 `pytest` 플러그인도 함께 설치하는 게 좋아요:

- [pytest-cache][pytest-cache]
- [pytest-subtests][pytest-subtests]

더 자세한 내용은 웹사이트의 [Python 테스트 가이드][Python track tests page]에서 확인할 수 있어요.


### 테스트 실행하기

포함된 테스트를 실행하려면 터미널에서 `cd`를 사용해 연습 문제가 저장된 폴더로 이동해요 (아래의 `<exercise-folder-location>`을 자신의 경로로 바꿔 주세요).
테스트 파일은 보통 `_test.py`로 끝나며, 해답을 업로드했을 때 웹사이트에서 실행되는 것과 같은 테스트예요.

Linux/MacOS
```bash
$ cd <path/to/exercise-folder-location>
```

Windows
```powershell
PS C:\Users\foobar> cd <path\to\exercise-folder-location>
```

<br>

다음으로 터미널에서 `pytest` 명령을 실행해요. 이때 `<exercise_test.py>`는 테스트 파일 이름으로 바꿔 주세요:

Linux/MacOS
```bash
$ python3 -m pytest -o markers=task <exercise_test.py>
==================== 7 passed in 0.08s ====================
```

Windows
```powershell
PS C:\Users\foobar> py -m pytest -o markers=task <exercise_test.py>
==================== 7 passed in 0.08s ====================
```


### 자주 쓰는 옵션
- `-o` : 기본 `pytest.ini`를 덮어써요 (_마커 경고를 피하려고 사용할 수 있어요_)
- `-v` : 자세한 출력을 켜요.
- `-x` : 처음 실패한 지점에서 테스트 실행을 멈춰요.
- `--ff` : 다른 테스트 케이스를 실행하기 전에 이전 테스트에서 실패한 것부터 실행해요.

그 밖의 옵션은 `python3 -m pytest -h` 또는 `py -m pytest -h`로 확인해요.


### 경고 해결하기

`pytest`를 실행할 때 `pytest -o markers=task`를 사용하지 않으면, 새로운 문법을 사용하는 테스트에서 `PytestUnknownMarkWarning`이 나타날 수 있어요:

```bash
PytestUnknownMarkWarning: Unknown pytest.mark.task - is this a typo?  You can register custom marks to avoid this warning - for details, see https://docs.pytest.org/en/stable/mark.html
```

테스트를 실행할 때마다 `pytest -o markers=task`를 입력하기 번거롭다면 `pytest.ini` 설정 파일을 사용할 수 있어요.
Python 트랙 디렉터리 최상위에서 내려받을 수 있는 파일을 만들어 두었어요: [pytest.ini][pytest.ini].

다음 내용으로 직접 `pytest.ini` 파일을 만들어도 돼요:

```ini
[pytest]
markers =
    task: A concept exercise task.
```

Python 트랙 연습 문제의 _루트_ 또는 _작업_ 디렉터리에 `pytest.ini` 파일을 두면 마커가 등록되고 경고가 멈춰요.
pytest 마커에 대한 더 자세한 내용은 [테스트 함수에 마커 달기][pytest: marking test functions with attributes]와 [사용자 정의 마커 사용하기][pytest: working with custom markers]에 대한 `pytest` 문서에서 확인할 수 있어요.

pytest 설정을 사용자 정의하는 방법은 [설정 파일 형식][pytest: configuration file formats]에 대한 `pytest` 문서에서 확인할 수 있어요.
