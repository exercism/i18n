# SQLite 관련 지침

**result** 열에는 JSON으로 인코딩된 객체가 들어가야 하며, 각 단어가 키이고 개수가 정수예요.

예를 들어, 위 문장을 살펴봐요: `"That's the password: 'PASSWORD 123'!", cried the Special Agent.\nSo I fled.`
이 입력의 **result**는 다음과 같아야 해요:

```json
{"123":1,"agent":1,"cried":1,"fled":1,"i":1,"password":2,"so":1,"special":1,"that's":1,"the":2}
```

## 테이블 스키마

```sql
CREATE TABLE "word-count" (
    sentence TEXT NOT NULL,
    result   TEXT               -- json object
);
```
