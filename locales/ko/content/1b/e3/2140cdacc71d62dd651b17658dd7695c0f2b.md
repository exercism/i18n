# 조건문

Crystal에는 제어 표현식이라는 것이 있어요. 제어 표현식은 프로그램이 실행되는 방식을 제어하는 데 사용되며, truthy 또는 falsey 값을 가져요.
truthy 또는 falsey 값을 만드는 데 사용할 수 있는 연산자도 있는데, 이를 [동등 및 비교 연산자][equality-and-comparison]라고 해요.

어떤 코드가 실행되고 어떤 코드가 실행되지 않을지, 다시 말해 어느 분기가 실행될지를 제어하는 데 사용되는 주요 제어 표현식은 두 가지예요.
바로 `if`와 `unless` 표현식이에요.

## 비교 연산자

비교 연산자는 값을 비교해서 `true` 또는 `false` 값을 반환해요.
이 연산자로 값을 비교하려면 두 값의 타입이 같아야 해요.
값의 타입이 다르면 컴파일러가 오류를 던져요.
다음은 비교 연산자 목록과, 각 연산자가 `true` 값을 내놓는 예시예요:

| 메서드 | 설명           | 예시 |
| ------ | --------------------- | ------- |
| <      | 미만             | 4 < 5   |
| <=     | 이하    | 4 <= 4  |
| >      | 초과          | 3 > 1   |
| >=     | 이상 | 2 >= 2  |

## 동등 연산자

동등 연산자는 비교 연산자와 비슷하지만, 두 값이 같은지 아닌지를 확인하는 데 사용해요.

`==` 연산자는 값의 타입을 포함해서 두 값이 같은지 확인해요.
값이 같으면 `true`를 반환하고, 그렇지 않으면 `false`를 반환해요.
`==` 연산자는 어떤 타입의 값이든 다른 타입의 값과 비교할 수 있어요.
`!=`도 같은 방식으로 동작하지만, 값이 다르면 `true`를, 값이 같으면 `false`를 반환해요.

## 우주선 연산자

우주선 연산자는 독특한 비교 연산자로, 이름은 생김새에서 따왔어요.
truthy나 falsey 값이 아니라 숫자를 반환한다는 점이 독특해요.
`<=>`로 쓰고 두 값을 비교할 때 사용해요.
왼쪽 값이 오른쪽 값보다 크면 `1`을, 왼쪽 값이 오른쪽 값보다 작으면 `-1`을, 두 값이 같으면 `0`을 반환해요.

```crystal
1 <=> 2 # => -1
2 <=> 2 # => 0
3 <=> 2 # => 1
```

## if문

[`if`][if]문은 주어진 조건이 truthy인지 falsey인지 확인할 때 사용해요.
조건이 truthy면 if문 안의 코드가 실행돼요.
`if`문은 `end` 키워드로 끝나요.

```crystal
if 1 == 1
  puts "1 is equal to 1"
end
# => 1 is equal to 1

if 1 > 2
  puts "1 is greater than 2"
end
# => no output
```

## unless문

[`unless`][unless]문은 `if`문과 아주 비슷하게 동작하지만, 조건이 falsey일 때 `unless`문 안의 코드를 실행해요.

```crystal
unless 1 == 1
  puts "1 is not equal to 1"
end
# => no output

unless 1 > 2
  puts "1 is not greater than 2"
end
# => 1 is not greater than 2
```

## else문

`else`문은 `if`문과 `unless`문과 함께 사용할 수 있어요.
`else`문은 `if` 분기나 `unless` 분기가 실행되지 않았을 때 실행돼요.

~~~~exercism/warning
`else` 분기를 `unless,`와 함께 사용할 수 있기는 하지만, 가독성을 해치기 때문에 권장하지 않아요.
대신 `if !condition`에 else 분기를 붙여 쓰는 걸 권장해요.
~~~~

```crystal
if 1 == 1
  puts "1 is equal to 1"
else
  puts "1 is not equal to 1"
end
# => 1 is equal to 1

unless 1 < 2
  puts "1 is not greater than 2"
else
  puts "1 is greater than 2"
end
# => 1 is greater than 2
```

## "연쇄 if"문

`elsif`문은 if문과 함께 사용할 수 있어요.
`elsif`문은 if 분기가 실행되지 않았고 `elsif`문의 조건이 truthy일 때 실행돼요.
`elsif`문은 여러 개를 이어 붙일 수 있고, 처음으로 truthy인 조건이 실행돼요.
if문 끝에 else문을 둘 수도 있는데, 앞의 문들이 모두 참이 아니었을 때 실행돼요.

```crystal
if 1 != 1
  puts "1 is not equal to 1"
elsif 1 > 2
  puts "1 is greater than 2"
else
  puts "1 is not equal to 1 and 1 is not greater than 2"
end
# => 1 is not equal to 1 and 1 is not greater than 2
```

## 삼항 연산자

Crystal에는 한 줄짜리 if-else문인 삼항 연산자가 있어요: `condition ? expression_if_truthy : expression_if_falsey`

```crystal
1 == 1 ? puts("1 is equal to 1") : puts("1 is not equal to 1")
# => 1 is equal to 1
```

## 접미사로 쓰는 if와 unless

if문과 unless문은 [접미사][if-as-suffix]로도 쓸 수 있는데, 조건이 참일 때 코드 한 줄을 실행하고 싶을 때 유용해요.
실행하려는 코드 뒤에 if문이나 unless문을 붙이면 돼요.

```crystal
puts "1 is equal to 1" if 1 == 1
# => 1 is equal to 1

puts "1 is not equal to 1" unless 1 == 1
# => no output
```

## 조건문과 타입

서로 다른 타입이 대입되면 변수는 두 타입을 모두 가지게 돼요.
컴파일러가 어느 분기가 실행될지 알 수 없기 때문이에요.
유니온이라고도 하는 이 다중 대입은 뒤의 개념에서 설명해요.
다음 예시에서 확인할 수 있어요:

```crystal
if 1 == 1
  a = 1
else
  a = "1"
end

typeof(a) # => Int32 | String
```
