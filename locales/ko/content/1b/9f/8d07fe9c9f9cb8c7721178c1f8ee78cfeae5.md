# 지침 추가

## Enum에 대하여

`Enum` 문을 사용하면 강력한 형식의 레이블 집합을 만들 수 있어요.
이 열거형은 코드에서 철자를 해석하거나 확인할 필요 없이 그대로 사용할 수 있어요.

열거형은 내부적으로 0부터 시작하는 정수로 표현돼요.
기본적으로 PowerShell은 목록의 첫 번째 레이블에 0을 할당하고, 나머지 레이블에는 연속된 정수를 할당해요.

예시:
```pwsh
Enum Fruits {
    APPLE       #default internal value 0
    ORANGE      #default internal value 1
    MANGO       #default internal value 2
}

$myFavFruit = [Fruits]::APPLE
Write-host $myFavFruit => APPLE
``````

PowerShell의 Enum에 대해 더 알아보려면 [Enum 모듈](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.core/about/about_enum)을 확인해 봐요.
