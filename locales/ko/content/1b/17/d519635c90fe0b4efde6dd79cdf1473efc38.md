# 지침

이 연습 문제에서는 차량을 구매할 준비를 돕는 프로그램을 작성해요.

해야 할 일은 두 가지예요. 운전면허가 필요한지 판단하기, 그리고 중고 차량의 적정 가격을 추정하기예요.

## 1. 운전면허가 필요한지 판단하기

어떤 종류의 차량은 운전하려면 운전면허가 필요해요.
`car` 또는 `truck`이 포함된 차량만 면허가 필요하다고 가정해요. 그 밖의 차량은 면허 없이 운전할 수 있어요.

첫 번째 필드가 `needs_license`일 때 일치하는 `pattern {action}` 쌍을 구현해요.
두 번째 필드에서 차량 종류를 가져오고, 그 종류의 차량에 면허가 필요하면 "true"를 출력해요.
면허가 필요 없다면 아무것도 출력하지 않아도 돼요.

```sh
echo "needs_license,dumptruck" | gawk -f vehicle-purchase.awk
# => true

echo "needs_license,bike" | gawk -f vehicle-purchase.awk
# => (empty output)
```

## 2. 중고 차량의 가격 추정하기

이제 결정을 내렸으니, 딜러십에서 적정한 가격에 사는지 확인하고 싶어요.
중고 차량을 사려고 하니, 가격은 차량이 얼마나 오래됐는지에 따라 달라져요.
대략적으로 추정해 보면, 차량이 3년 미만이면 새 차였을 때의 원래 가격에서 80%라고 가정해요.
10년이 넘으면 50%예요.
차량이 3년 이상이면서 10년 이하이면 원래 가격의 70%예요.

첫 번째 필드가 `resell_price`일 때 일치하는 `pattern {action}` 쌍을 구현해요.
두 번째 필드에서 차량의 원래 가격을, 세 번째 필드에서 연식을 가져와요.
action은 추정 가격을 출력해야 해요.

```sh
echo "resell_price,1000,1" | gawk -f vehicle-purchase.awk
# => 800

echo "resell_price,1000,5" | gawk -f vehicle-purchase.awk
# => 700

echo "resell_price,1000,15" | gawk -f vehicle-purchase.awk
# => 500
```
