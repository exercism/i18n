# 클래스

클래스는 [객체 지향 프로그래밍][object-oriented-programming]의 핵심 개념이에요.
[Crystal에서는 모든 것이 객체][everything-is-an-object]이고, 모든 객체에는 타입이 있으며, 객체는 몇몇 메서드에 응답할 수 있어요.
클래스는 객체를 만들기 위한 설계도로, 변수 같은 상태의 초깃값과 메서드 같은 동작의 구현을 제공해요.
객체는 모든 인스턴스 변수와 상태를 담고 있는 클래스의 인스턴스예요.

## 클래스 정의

클래스는 `class` 키워드를 사용해 정의하고, 그 뒤에 `UpperCamelCase`로 작성한 클래스 이름을 붙여요.

```crystal
class Account
end
```

## 인스턴스 만들기

[클래스의 인스턴스를 만들려면][new-initialize] `new` 메서드를 사용해 클래스 이름을 호출해요.

```crystal
class Account
end

account = Account.new
```

위 예시에서 `account` 변수는 `Account` 클래스의 인스턴스예요.

인스턴스를 만들 때, `initialize`라는 특별한 메서드가 생성자 역할을 해요.
이 메서드는 인스턴스가 만들어질 때 호출돼요.
생성자를 사용하면 인스턴스의 초기 상태를 설정할 수 있어요.
`initialize` 메서드는 인자를 받을 수 있고, 이 인자는 인스턴스를 만들 때 전달돼요.

```crystal
class Account
  def initialize(number)
    5 + number # => 9
  end
end

Account.new(4)
```

~~~~exercism/note
`initialize` 메서드는 값을 직접 반환할 수 없어요. 대신 `new`가 새로 만들어진 인스턴스를 반환해요.

```crystal
class Account
  def initialize(number)
    5 + number
  end
end

Account.new(4)
# => #<Account:0x7f5dc33dcea0>
```
~~~~

## 인스턴스 메서드

인스턴스 메서드는 클래스의 인스턴스에서 사용할 수 있는 메서드로, 그 인스턴스에서 호출할 수 있어요.
인스턴스 메서드는 `def` 키워드를 사용해 정의하고, 그 뒤에 메서드 이름을 붙여요.
인스턴스 메서드는 클래스 정의 안에 정의해요.

```crystal
class Account
  def balance
    100
  end
end

account = Account.new
account.balance # => 100
```

## 인스턴스 변수

[인스턴스 변수][instance-variable]는 인스턴스의 모든 메서드에서 사용할 수 있는 변수예요.
인스턴스 변수에 접근하려면 인스턴스 메서드를 정의해야 해요.
인스턴스 변수는 `initialize` 메서드에서 초기화할 수 있어요.
인스턴스 변수는 `@` 접두사를 사용해 정의해요.

```crystal
class Account
  def initialize
    @balance = 100
  end

  def balance
    @balance
  end
end

account = Account.new
account.balance
# => 100
```

인스턴스 변수는 클래스 정의 안에서도 정의할 수 있어요.

```crystal
class Account
  @age = 0
end
```

### 초기화가 있는 인스턴스 변수

인스턴스 변수는 `initialize` 메서드에 전달된 인자로 초기화할 수 있어요.
Crystal은 초기화할 때 사용하는 인자의 타입을 추론할 수 없기 때문에, 타입을 명시해야 해요.
이에 대해 더 읽고 싶다면 [타입 추론][type-inference]을 읽어봐요.
변수의 타입을 명시하려면 `:` 기호를 사용하고, 그 뒤에 타입을 붙여요.
예를 들어 `Int32` 타입의 `balance`라는 인스턴스 변수를 만들고 싶다면 `@balance : Int32`처럼 작성해요.
또는 `Bool` 타입의 `raining`이라는 인스턴스 변수를 만들고 싶다면 `@raining : Bool`처럼 작성해요.

이를 구현하는 방법은 몇 가지가 있어요. 예를 들어 다음 예시처럼 `initialize` 메서드에서 인자를 타입과 함께 선언한 다음, 인스턴스 변수에 그 인자를 할당하는 방법이 있어요.

```crystal
class Account
  def initialize(balance : Int32)
    @balance = balance
  end

  def balance
    @balance
  end
end

account = Account.new(1)
account_2 = Account.new(5)

account.balance
# => 1

account_2.balance
# => 5
```

또 다른 방법은 다음 예시처럼 클래스 정의에서 `@<variable> : <Type>` 형태로 인스턴스 변수의 타입을 선언하는 것이에요.

```crystal
class Weather

  @raining : Bool

  def initialize(raining)
    @raining = raining
  end

  def raining
    @raining
  end
end

weather = Weather.new(true)
weather.raining
# => true
```

### 인스턴스 변수를 초기화하는 축약형

`initialize` 메서드의 인자에서 인스턴스 변수를 초기화하는 축약형이 있는데, 같은 `@<variable> : <Type>` 문법을 사용해요.
이 축약형은 인자에 인스턴스 변수를 할당하는 것과 인스턴스 변수의 타입을 선언하는 것을 한 번에 해줘요.

```crystal
class Account
  def initialize(@balance : Int32)
  end
end
```

## 인스턴스 변수 수정하기

메서드는 인스턴스 변수를 수정할 수 있어요.
이런 메서드는 클래스의 인스턴스에서 호출할 수 있어요.
메서드가 인스턴스 변수를 수정하면, 그 변경은 메서드를 호출한 클래스 인스턴스에만 적용돼요.

```crystal
class Account
  def initialize(balance : Int32)
    @balance = balance
  end

  def withdraw(amount)
    @balance -= amount
  end

  def balance
    @balance
  end
end

account = Account.new(10)
account_2 = Account.new(10)
account.balance
# => 10

account_2.balance
# => 10

account.withdraw(5)
account.balance
# => 5

account_2.balance
# => 10
```

## 클래스 메서드

[클래스 메서드][class-methods]는 클래스에 대해 정의되는 메서드로, 인스턴스에 대해서는 정의되지 않아요.
클래스 메서드를 사용하면 인스턴스의 상태에 의존하지 않는 메서드를 만들 수 있어요.
클래스 메서드는 `def` 키워드를 사용해 정의하고, 그 뒤에 `self.<method name>`을 붙여요.
`self`는 self가 호출되는 네임스페이스에 대한 참조예요.
여기서는 `Account` 클래스를 가리켜요.
`Account.`라고 쓴 것과 같지만, `self.`를 쓰는 것이 권장돼요.

```crystal
class Account
  def self.balance
    100
  end
end

Account.balance
# => 100
```
