# 기여자를 위한 도구

학생에게는 [INSTALLATION.md](INSTALLATION.md)에 나오는 도구만 있으면 돼요.
기여자에게는 도구가 몇 가지 더 필요한데, 트랙의 스크립트에서 이것들을 사용하기 때문이에요:

- `git`: 저장소를 클론하고 풀 리퀘스트를 열 때 사용해요.
- `jq`: `bin/verify-exercises`와 `bin/add-practice-exercise`에서 사용해요.
- `curl`: `bin/fetch-configlet`에서 사용해요.
- Python 3.11 이상: 테스트 생성기에 필요해요.
- `clang-format`: 테스트 생성기가 작성한 파일에 실행해요.
- `pre-commit`: 커밋하기 전에 저장소의 검사를 실행해요.

각자 사용하는 배포판에 맞는 명령으로 설치한 다음, "저장소 설정하기"에 나오는 단계를 따라 해요.

## Debian / Ubuntu

```shell
sudo apt install git jq curl clang-format pre-commit
```

## Fedora

```shell
sudo dnf install git jq curl pre-commit clang-tools-extra diffutils
```

## Arch Linux

```shell
sudo pacman -S git jq curl pre-commit clang diffutils
```

## openSUSE Tumbleweed

```shell
sudo zypper install git jq curl python3-pre-commit clang-tools diffutils
```

## 저장소 설정하기

저장소 루트에서 실행해요:

```shell
bin/fetch-configlet
bin/configlet info
pre-commit install
pre-commit run --all-files
```
