# 테스트

현재 사용하는 운영체제를 선택해요:

* [Windows](##windows)
* [macOS](##macos)
* [Linux](##linux)

# 테스트 실행하기

## Windows

1. 명령 프롬프트를 열어요.

2. 첫 번째 연습 문제를 내려받아요:

    ```batchfile
     C:\Users\USERNAME> exercism download --exercise hello-world --track cobol
    ```

3. 연습 문제 폴더로 이동해요:

    ```batchfile
     C:\Users\USERNAME> cd C:\Users\USERNAME\exercism\cobol\hello-world
    ```
   
4. 테스트를 실행해요:

    ```batchfile
     C:\Users\USERNAME\exercism\cobol\hello-world> test.ps1
    ```
    *(처음 실행했을 때 테스트가 실패해도 걱정하지 마세요. 모든 연습 문제는 이렇게 시작해요.)*

5. 연습 문제를 풀어요. 
    `instructions.md`를 읽고 연습 문제를 푸는 방법을 확인해요 ([GitHub에서 보기](https://github.com/exercism/cobol/blob/main/exercises/practice/hello-world/.docs/instructions.md)).


행운을 빌어요! 즐겁게 해보고 COBOL 트랙에 오신 것을 환영해요!

----

## macOS

1. 터미널 창을 열어요.

2. 첫 번째 연습 문제를 내려받아요:

    ```
     $ exercism download --exercise hello-world --track cobol
    ```

3. 연습 문제 폴더로 이동해요:

    ```
     $ cd /Users/USERNAME/exercism/cobol/hello-world
    ```

4. 테스트를 실행해요:

    ```
     $ bash test.sh
    ```
    *(처음 실행했을 때 테스트가 실패해도 걱정하지 마세요. 모든 연습 문제는 이렇게 시작해요.)*

    힌트: `basename`이 없다는 메시지가 나오면, [brew](https://brew.sh/)로 coreutils를 설치할 수 있어요. (`brew install coreutils`)

5. 연습 문제를 풀어요. 

    `instructions.md`를 읽고 연습 문제를 푸는 방법을 확인해요 ([GitHub에서 보기](https://github.com/exercism/cobol/blob/main/exercises/practice/hello-world/.docs/instructions.md)).


행운을 빌어요! 즐겁게 해보고 COBOL 트랙에 오신 것을 환영해요!
