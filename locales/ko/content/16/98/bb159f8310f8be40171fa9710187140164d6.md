# 지침

친구 요하네스는 DIY(직접 만들기) 하드웨어를 정말 좋아해요.
요하네스는 방금 주스 메이커를 만들었고, 무척 신나 있어요.
요하네스의 목표는 매일 아침 신선한 주스를 만드는 거예요.

요하네스 주스 메이커에는 근사한 기능이 많아요.
예를 들어, 컵에 주스가 얼마나 들어 있는지 알려 주는 내장 측정 시스템이 있어요.
기계가 얼마나 오래 작동했는지 알려 주는 타이머도 있어요.

요하네스는 프로그래밍을 잘하지는 못하지만, 기계를 제어할 프로그램을 만들고 싶어 해요.
그래서 여러분에게 도움을 청했어요.

## 1. 디버그 표시등

기계에는 디버그 표시등이 있는데, 간단한 장치예요. 기계에 전원이 들어오면 디버그 표시등이 켜져요.
프로그램은 디버그 표시등이 켜져 있을 때만 실행돼요.

이 메서드는 `JuiceMaker`라는 클래스의 클래스 메서드여야 해요.

`true`를 반환하는 클래스 메서드 `JuiceMaker.debug_light_on?`을 정의해요.

```crystal
JuiceMaker.debug_light_on?
#=> true
```

## 2. 기계 초기화

기계에 전원이 들어오면 `JuiceMaker`라는 클래스의 인스턴스를 만들어야 해요.
기계에는 초기화된 상태가 있어야 해요.
초기화된 상태는 다음 정보를 담고 있어야 해요:

1. 기계가 작동 중인지 여부. 기계를 켰을 때 이 값은 항상 `false`여야 해요.
2. 컵에 들어 있는 주스의 양. 이것은 컵에 있는 주스의 양을 측정하는 센서가 될 거예요.

컵에 들어 있는 주스의 양을 매개변수로 받는 초기화된 상태를 정의하고, 초기화된 상태를 만들어요.
초기화된 상태에는 `false`로 설정되는 인스턴스 변수 `@running`과, 클래스가 초기화될 때 주어진 인자에 따라 값이 정해지는 인스턴스 변수 `@fluid`가 있어야 해요.

```crystal
JuiceMaker.new(5)
#=> #<JuiceMaker:0x10f0b8 @running=false, @fluid=5>
```

## 3. 기계 켜기

기계는 켜고 끌 수 있어요.
기계를 켜는 메서드를 정의해야 해요.
기계를 켜면 작동 상태가 `true`로 설정돼야 해요.

기계를 켜는 `JuiceMaker#start` 메서드를 정의해요.

```crystal
juice_maker = JuiceMaker.new(5)
juice_maker.start

juice_maker
#=> #<JuiceMaker:0x10f0b8 @running=true, @fluid=5>
```

## 4. 기계의 상태

기계는 자신의 상태를 알려 줄 수 있어야 해요.
기계가 작동 중이면 `true`를, 작동 중이 아니면 `false`를 반환해야 해요.

기계의 상태를 반환하는 `JuiceMaker#running?` 메서드를 정의해요.

```crystal
juice_maker = JuiceMaker.new(5)
juice_maker.start

juice_maker.running?
#=> true
```

## 5. 주스 추가하기

기계는 컵에 주스를 더할 수 있어요.
기계는 컵에 주스가 얼마나 더해졌는지 알 수 있어요.
기계는 주스가 더해진 뒤 컵에 주스가 얼마나 들어 있는지 알기 위해 도움이 필요해요.

더해진 주스의 양을 매개변수로 받아 컵에 들어 있는 주스의 양을 갱신하는 `JuiceMaker#add_fluid` 메서드를 정의해요.

```crystal
juice_maker = JuiceMaker.new(5)
juice_maker.add_fluid(5)

juice_maker
#=> #<JuiceMaker:0x10f0b8 @running=false, @fluid=10>
```

## 6. 기계 끄기

기계는 켜고 끌 수 있어요.
기계를 끄는 메서드를 정의해야 해요.
이 메서드는 기계가 작동 중일 때만 호출돼요.
기계를 끄면 작동 상태가 `false`로 설정돼야 해요.
기계는 전원이 꺼진 뒤 컵에 주스가 얼마나 들어 있는지 알아내는 데도 도움이 필요해요.
기계는 1분에 주스 다섯 단위를 사용해요.

기계가 작동한 분 수를 매개변수로 받아 기계가 꺼진 뒤 컵에 들어 있는 주스의 양을 반환하는 `JuiceMaker#stop` 메서드를 정의해요.

```crystal
juice_maker = JuiceMaker.new(5)

juice_maker.start
juice_maker
#=> <JuiceMaker:0x10f0b8 @running=true, @fluid=5>

juice_maker.stop(1)
#=> #<JuiceMaker:0x10f0b8 @running=false, @fluid=0>
```
