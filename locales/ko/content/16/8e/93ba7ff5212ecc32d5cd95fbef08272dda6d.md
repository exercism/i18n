# 힌트

## 일반


- [튜플][tuples]은 어떤 데이터 타입이든 담을 수 있는 불변 [시퀀스 타입][sequence types]이에요.
- 튜플은 [반복 가능한 객체][iterable]예요. 인덱스와 값이 모두 필요하면 [`enumerate()`][enumerate]를 사용해요.
- 튜플의 원소는 [대괄호 표기법][bracket notation]으로 접근할 수 있어요. 왼쪽부터 0을 기준으로 하는 인덱스를 사용하거나, 오른쪽에서 -1을 사용해요. 튜플을 다룰 때는 다른 [공통 시퀀스 연산][common sequence operations]도 사용할 수 있어요.

## 1. 좌표 추출하기

- 기억하세요: 튜플은 _대괄호_를 사용해 _인덱스_로 접근할 수 있어요. 인덱스는 왼쪽부터 0에서 시작해요.

## 2. 좌표 형식 지정하기

- 튜플에 대한 자세한 내용은 [`class tuple`][class tuple]을 확인해 봐요.
- 문자열에 대한 자세한 내용은 [`class str`][class str]을 확인해 봐요.

## 3. 좌표 일치시키기

- 여기서 [멤버십 검사][testing membership]에는 어떤 메서드를 사용할 수 있을까요?
- 튜플에 대한 자세한 내용은 [`class tuple`][class tuple]을 확인해 봐요.
- `convert_coordinate()` 함수를 다시 사용할 수 있을까요?

## 4. 일치하는 레코드 결합하기

- 튜플은 모든 [공통 시퀀스 연산][common sequence operations]을 지원한다는 걸 기억하세요.
- 여기서 `compare_records()` 함수를 다시 사용할 수 있을까요?

## 5. "정리"하고 모든 레코드에 대한 보고서 만들기

- 기억하세요: 튜플은 _불변_이지만, 내용은 _대괄호 표기법_을 사용해 _인덱스_로 접근할 수 있어요.
- 튜플은 _모호한_ 경우가 아니면 괄호를 사용할 필요가 없어요.
- Python에는 문자열을 포맷하는 방법이 여러 가지 있어요. [`str.format()`][str.format]과 [`f-strings`][f-strings]가 아주 흔한 두 가지예요.
- Python의 [`format specification mini-language`][format specification mini-language]를 통해 여러 가지 텍스트 서식 옵션을 사용할 수 있어요.
