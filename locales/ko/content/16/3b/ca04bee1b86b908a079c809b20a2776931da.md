이 임무를 수락하기로 했다면, UMBRA(United Minions Being Really Awful) 본부에 잠입해서 그들의 최신 정말 끔찍한 계획에 대한 설계도를 빼내는 데 필요한 두 가지 도구를 만들게 될 거예요.

## 1. 회수한 비밀 계획을 비밀번호로 보호하기

비밀 계획을 손에 넣었다면, 비밀번호를 아는 사람만이 그 계획을 다시 꺼낼 수 있도록 보호해야 해요.

이를 위해 `protectSecret(_ secret: String, withPassword password: String) -> (String) -> String` 함수를 구현해야 해요.
이 함수는 비밀번호로 추정되는 문자열을 입력으로 받는 또 다른 함수를 반환해요.
입력한 비밀번호가 맞으면 새 함수는 숨겨진 비밀을 반환하지만, 비밀번호가 틀리면 "Sorry. No hidden secrets here."를 반환해요.

```swift
let secretFunction = protectSecret("Steal the world's supply of french fries!", withPassword: "5up3r53cr37")

secretFunction("Open sesame")
// Returns "Sorry. No hidden secrets here."

secretFunction("5up3r53cr37")
// Returns "Steal the world's supply of french fries!"
```

## 2. 금고를 열 조합 생성하기

UMBRA는 모든 금고 조합을 금고가 위치한 방의 번호를 바탕으로 만든다는 사실을 알아냈어요.
금고 조합은 방 번호에 특별한 함수를 반복해서 적용해 생성해요.
즉, 조합의 첫 번째 숫자는 방 번호에 함수를 적용한 결과이고, 두 번째 숫자는 첫 번째 숫자에 함수를 적용한 결과이며, 세 번째 숫자는 두 번째 숫자에 함수를 적용한 결과예요.

그런데 UMBRA는 조합을 생성하는 데 쓰는 함수를 수시로 바꾸기 때문에, 도구가 조합을 생성하려면 방 번호와 그에 맞는 함수를 둘 다 받아야 해요.

필요한 조합을 생성하려면 `generateCombination(forRoom room: Int, usingFunction f: (Int) -> Int) -> (Int, Int, Int)` 함수를 구현해요.

```swift
func makeCombo(_ x: Int) -> Int {
  (x * 13) % 256
}

generateCombination(forRoom: 227, usingFunction: makeCombo)
// Returns (135, 219, 31)
```
