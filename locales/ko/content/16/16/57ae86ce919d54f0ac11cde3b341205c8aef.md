# 지침 추가

## Node 프로세스

다른 연습 문제와 달리, `grep.js`는 테스트 파일 `grep.spec.js` 안에서 _불러오지_ 않아요. 대신, 마치 실행 파일인 것처럼 사용돼요. 이를 위해 `grep.js` 파일에는 셔뱅과, 이것이 무엇을 하는지 설명하는 주석이 설정되어 있어요.

```javascript
#!/usr/bin/env node

// The above line is a shebang. On Unix-like operating systems, or environments,
// this will allow the script to be run by node, and thus turn this JavaScript
// file into an executable. In other words, to execute this file, you may run
// the following from your terminal:
//
// ./grep.js args
//
// If you do not have a Unix-like operating system or environment, for example
// Windows without WSL, you can use the following inside a window terminal,
// such as cmd.exe:
//
// node grep.js args
//
// Read more about shebangs here: https://en.wikipedia.org/wiki/Shebang_(Unix)
```

테스트는 새로운 node _프로세스_를 시작해서 `grep.js`를 실행해요.

## 인자 읽기

_프로세스_가 시작될 때 넘겨받은 인자를 가져오려면 `process.argv`를 사용해요.

## 파일 읽기

`readLines` 함수가 제공돼요. 사용하기 위해 파일 경로를 변환할 필요는 없어요. `readlines` 함수는 현재 작업 디렉터리를 기준으로 경로를 _해석_하는데, `grep.js` 프로세스의 경우 이 디렉터리는 연습 문제 디렉터리로 설정돼 있어요.

## 출력 쓰기

출력을 쓰려면 다음을 사용해요.

- `console.log`는 표준 출력 스트림에 쓰고,
- `console.error`는 표준 오류 스트림에 써요.

테스트는 표준 오류 스트림에 아무것도 쓰이지 않으면 실행이 성공(resolved)한 것으로 보고, 표준 오류 스트림에 무언가 쓰이면 성공하지 못한(rejected) 것으로 봐요.
