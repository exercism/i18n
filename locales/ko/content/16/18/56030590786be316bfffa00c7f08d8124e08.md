# 지침 추가

## 워드

`destructors`에 있는 `disposable`을 확장하고, 기반 스트림을 `bytes`와 `ops` 정수 카운터와 함께 저장하는 래퍼 튜플 두 개를 정의해요.

- 슬롯 `stream`, `bytes`, `ops`를 가진 `metered-input < disposable`.
- 슬롯 `stream`, `bytes`, `ops`를 가진 `metered-output < disposable`.

래퍼가 소멸자 프레임워크에 등록되도록, 각 튜플은 `new`가 아니라 `new-disposable`로 생성해요.

- `<metered-input> ( stream -- m )`: 입력 스트림을 감싸요.
- `<metered-output> ( stream -- m )`: 출력 스트림을 감싸요.

각 튜플을 알맞은 스트림 믹스인의 인스턴스로 선언해요:

```
INSTANCE: metered-input  input-stream
INSTANCE: metered-output output-stream
```

그다음 카운터를 갱신하면서 기반 스트림에 위임하는 `M:` 메서드를 제공해요.

- `metered-input`의 경우: [`stream-read1`][stream-read1], [`stream-read-unsafe`][stream-read-unsafe], [`stream-element-type`][stream-element-type](위임), [`dispose*`][dispose*].
- `metered-output`의 경우: [`stream-write1`][stream-write1], [`stream-write`][stream-write], [`stream-flush`][stream-flush](위임), [`dispose*`][dispose*].

성공한 읽기나 쓰기는 전송된 바이트 수를 `bytes>>`에 더하고 `ops>>`를 1만큼 늘려요. 파일 끝에 도달한 읽기도 op 하나로 세지만 전송하는 바이트는 0이에요. `dispose*`는 기반 스트림으로 그대로 전달해요.
