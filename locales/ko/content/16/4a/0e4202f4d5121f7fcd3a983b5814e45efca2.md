# 소개

많은 프로그램은 현실 세계의 사건을 시뮬레이션하기 위해 (_겉보기에_) 무작위한 값이 필요해요.

자주 접하는 익숙한 예로는 다음과 같은 것들이 있어요:
- 동전 던지기: `('Heads', 'Tails')`에서 무작위로 값을 하나 고르는 것
- 주사위 굴리기: 1부터 6까지의 무작위 정수
- 카드 한 벌 섞기: 카드 목록을 무작위 순서로 배열하는 것
- 3차원 그래픽 시뮬레이션에서 나무와 덤불을 만들어 내는 것

컴퓨터로 _진짜_ 무작위 값을 만들어 내는 것은 [놀랄 만큼 어려운 기술적 과제][truly-random]라서, 이런 결과를 "의사 난수"라고 부르는 걸 볼 수도 있어요.

실제로는 Python 표준 라이브러리의 [`random`][random] 모듈처럼 잘 설계된 라이브러리가 빠르고 유연하며, 모델링, 시뮬레이션, 게임을 비롯한 대부분의 응용 분야에 충분히 쓸 만한 결과를 내줘요.

이 짧은 소개에서는 이 모듈에서 가장 많이 쓰이는 네 가지 함수를 살펴볼게요.
도구와 선택지가 다양하니, [`random`][random] 문서 전체를 한번 살펴보길 권해요.


~~~~exercism/caution

`random` 모듈은 보안이나 암호 응용 프로그램에 __절대__ 사용하면 안 돼요!!

대신 Python은 [`secrets`][secrets] 모듈을 제공해요.
이 모듈은 암호 보안에 맞게 특별히 최적화되어 있어요.
secrets 모듈을 만들게 된 배경과 기존의 문제점 일부는 [PEP 506][PEP 506]에서 확인할 수 있어요.

`random` 모듈의 도구를 사용하려면 먼저 모듈을 가져와야 해요:

```python
>>> import random

# Choose random integer from a range
>>> random.randrange(1000)
360

>>> random.randrange(-1, 500)
228

>>> random.randrange(-10, 11, 2)
-8

# Choose random integer between two values (inclusive)
>>> random.randint(5, 25)
22

```

모듈 이름을 매번 입력하지 않으려면, 특정 함수를 이름으로 바로 가져올 수 있어요:

```python
>>> from random import choice, choices

# Using choice() to pick Heads or Tails 10 times
>>> tosses = []
... for side in range(10):
...    tosses.append(choice(['H', 'T']))    

>>> print(tosses)
['H', 'H', 'H', 'H', 'H', 'H', 'H', 'T', 'T', 'H']


# Using choices() to pick Heads or Tails 8 times
>>> picks = []
... picks.extend(choices(['H', 'T'], k=8))
... print(picks)
['T', 'H', 'H', 'T', 'H', 'H', 'T', 'T']
```



## `randrange()`와 `randint()`

위의 첫 번째 예제에서 보았듯이, `randrange()` 함수에는 세 가지 형태가 있어요:

1. `randrange(stop)`은 `0 <= n < stop`을 만족하는 정수 `n`을 줘요
2. `randrange(start, stop)`은 `start <= n < stop`을 만족하는 정수 `n`을 줘요
3. `randrange(start, stop, step)`은 `start <= n < stop`이고
    `n`이 `start, start + step, start + 2*step...` 수열에 속하는 정수 `n`을 줘요

가장 흔한 경우인 `step == 1`일 때는 `randint(a, b)`가 더 편리하고 읽기 쉬울 수 있어요.
`randint()`가 낼 수 있는 결과에는 위쪽 경곗값도 _포함_되므로, `randint(a, b)`는 `randrange(a, b+1)`을 쓰는 것과 같아요.



## `choice()`와 `choices()`

이 두 함수는 어떤 [시퀀스][sequence-types]나 다른 컨테이너에서 시작한다고 가정해요.
보통은 `list`이고, 몇 가지 제약은 있지만 `tuple`이나 `set`일 수도 있어요 (_`tuple`은 변경할 수 없고, `set`은 순서가 없어요_).

`choice()` 함수는 주어진 시퀀스에서 무작위로 고른 원소 하나를 반환하고, `choices()`는 주어진 시퀀스에서 무작위로 고른 원소를 지정한 개수(`k`)만큼 반환해요.
위에 나온 예제에서는 앞면과 뒷면이 나올 확률이 같은 공정한 동전을 가정했지만, 가중치를 지정할 수도 있어요.

예를 들어, 주머니에 빨간 공 10개와 초록 공 15개가 들어 있고 그중 하나를 무작위로 꺼내고 싶다면:


```python
>>> random.choices(['red', 'green'], [10, 15])
['red']
```
