# 소개

Gleam 표준 라이브러리의 `gleam/order` 모듈에는 값을 비교할 때 사용하는 `Order` 타입이 들어 있어요.

`Order`의 정의는 다음과 같아요:

```gleam
pub type Order {
  Gt
  Eq
  Lt
}
```

이 타입에는 세 가지 종류가 있는데, 각각은 한 값과 다른 값 사이의 관계를 나타내는 데 사용돼요:

- `Gt` - 값이 다른 값보다 _더 큰_ 경우예요.
- `Eq` - 값이 다른 값과 _같은_ 경우예요.
- `Lt` - 값이 다른 값보다 _더 작은_ 경우예요.

데이터 타입을 크기로 비교할 수 있다면, 보통 그 모듈에서 `Order` 값을 반환하는 `compare` 함수를 정의해요. 예를 들어, `gleam/float`와 `gleam/int`는 각각 실수와 정수에 대해 동작하는 `compare` 함수를 정의해요.

```gleam
int.compare(1, 2)
// -> Lt

int.compare(2, 2)
// -> Eq

float.compare(1.0, 2.0)
// -> Lt
```

`list.sort` 같은 정렬 함수는 보통 `Order` 값을 반환하는 함수를 받아서, 호출하는 쪽에서 배열을 어떻게 정렬할지 정의할 수 있게 해줘요.

```gleam
list.sort([3, 7, 3, 1], by: int.compare)
// -> [1, 3, 3, 7]
```
