# 힌트

## 일반

- 정수 값은 하나 이상의 연속된 숫자로 정의할 수 있어요.

## 1. 예상 오븐 시간을 분 단위로 정의하기

- [메서드][methods]를 인자 없이 정의해야 해요.
- 정수 값을 반환해야 해요 ([built-in types] 참고).

## 2. 남은 오븐 시간을 분 단위로 계산하기

- 매개변수가 하나인 [메서드][methods]를 정의해야 해요.
- 메서드의 매개변수는 정수예요.
- 정수 값을 반환해야 해요 ([built-in types] 참고).
- `-` 연산자를 사용해 값을 뺄 수 있어요.

## 3. 준비 시간을 분 단위로 계산하기

- 매개변수가 하나인 [메서드][methods]를 정의해야 해요.
- 메서드의 매개변수는 정수예요.
- 정수 값을 반환해야 해요 ([built-in types] 참고).
- `*` 연산자를 사용해 값을 곱할 수 있어요.

## 4. 경과 시간을 분 단위로 계산하기

- 매개변수가 두 개인 [메서드][methods]를 정의해야 해요.
- 메서드의 매개변수는 모두 정수 타입이에요.
- 정수 값을 반환해야 해요 ([built-in types] 참고).
- 앞서 정의한 다른 메서드 중 하나를 [호출][invocation]할 수 있어요.
- `+` 연산자를 사용해 값을 더할 수 있어요.

[methods]: https://docs.scala-lang.org/overviews/scala-book/methods-first-look.html
[built-in types]: https://docs.scala-lang.org/overviews/scala-book/built-in-types.html
[invocation]: https://docs.scala-lang.org/style/method-invocation.html
