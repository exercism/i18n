# 소개

Common Lisp에서 문자열은 [문자][concept-characters]의 [벡터][concept-vectors]예요. 문자열은 큰따옴표로 감싼 문자로 작성해요 (_예:_ "Hello World!").

`stringp` 프레디킷은 주어진 값이 문자열일 때에만 참을 반환해요.

`subseq` 함수를 사용하면 문자열을 부분 문자열로 나눌 수 있어요. 이 함수는 문자열과 시작 인덱스를 인자로 받고, 끝 인덱스는 선택적으로 받아요. 인덱스는 0부터 시작해요.

```lisp
(subseq "Hello World" 1 5)   ; => "ello"
(subseq "skip to the end" 5) ; => "to the end"
```

`string=`로 두 문자열이 같은지 비교할 수 있어요. 문자의 대소문자를 구분하지 않으려면 `string-equal`을 사용해요.

```lisp
(string= "macaroni" "macaroni")      ; => T
(string= "macaroni" "MACARONI")      ; => NIL
(string-equal "macaroni" "MACARONI") ; => T
```

문자열을 대문자로 바꾸거나, 소문자로 바꾸거나, 첫 글자를 대문자로 만드는 작업은 `string-upcase` `string-downcase` `string-capitalize`로 할 수 있어요.

```lisp
(string-upcase "not too loud")                ; => "NOT TOO LOUD"
(string-downcase "YELL IT FROM THE ROOFTOPS") ; => "yell it from the rooftops"
(string-capitalize "practical COMMON LiSP")   ; => "Practical Common Lisp"
```
