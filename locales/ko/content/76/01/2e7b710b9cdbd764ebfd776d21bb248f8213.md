# 지시 사항

체스 애호가라면 누구나 자기만의 체스 게임을 만들어 보고 싶어 해요. 물론 온라인에는 이미 수많은 체스 구현이 있겠지만, 직접 만든 것은 세상에 하나뿐일 거예요!

체스판의 각 칸은 글자와 숫자 한 쌍으로 나타내요.

- 가로 방향으로 놓인 칸 줄은 랭크라고 부르고, 1부터 8까지 번호가 붙어요.
- 세로 방향으로 놓인 칸 줄은 파일이라고 부르고, A부터 H까지 이름이 붙어요.

```text
   A B C D E F G H
 8 # _ _ _ # _ _ # 8
 7 _ _ _ _ _ _ _ _ 7
 6 _ _ _ _ # _ _ # 6
 5 _ # _ _ _ _ _ # 5
 4 _ _ _ _ _ _ # # 4
 3 # _ # _ _ _ _ # 3
 2 _ _ _ _ _ _ _ # 2
 1 # _ _ _ _ _ _ # 1
   A B C D E F G H
```

## 1. 체스판과 파일이 주어지면 점유된 칸의 개수 세기

`CountInFile(board Chessboard, file string) int` 함수를 구현해요.
맵을 순회하면서 점유된 칸의 총 개수를 세요.
정수를 반환해요.
주어진 파일이 맵에서 발견되지 않으면 0(`0`)을 반환해요.

```go
CountInFile(board, "A")
// => 3
```

## 2. 체스판과 랭크가 주어지면 점유된 칸의 개수 세기

`CountInRank(board Chessboard, rank int) int` 함수를 구현해요.
주어진 랭크를 순회하면서 점유된 칸의 총 개수를 세요.
정수를 반환해요.
주어진 랭크가 유효하지 않으면(`1`부터 `8` 사이가 아니면) 0(`0`)을 반환해요.

```go
CountInRank(board, 2)
// => 1
```

## 3. 주어진 체스판에 칸이 몇 개 있는지 세기

`CountAll(board Chessboard) int` 함수를 구현해요.
체스판에 칸이 몇 개 있는지 세어 정수를 반환해요.
칸의 내용은 확인할 필요가 없으니, `index`와 `value`를 모두 생략하는 range를 사용해 보세요.

```go
CountAll(board)
// => 64
```

## 4. 주어진 체스판에서 점유된 칸의 개수 세기

`CountOccupied(board Chessboard) int` 함수를 구현해요.
체스판에서 점유된 칸의 개수를 세요.
정수를 반환해요.

```go
CountOccupied(board)
// => 15
```
