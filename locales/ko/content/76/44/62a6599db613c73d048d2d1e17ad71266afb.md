# About

`reduce`는 Factor의 범용 폴드예요. 시퀀스를 따라 걸어가면서, 누산기를 이항 quotation에 계속 넘겨요. 이 quotation은 실행 중인 누산기와 다음 원소를 받아서 새로운 누산기를 만들어 내죠.

```
reduce ( seq init quot: ( prev elt -- next ) -- result )
```

```factor
USING: math sequences ;

{ 1 2 3 4 } 0 [ + ] reduce .         ! => 10
{ 1 2 3 4 } 1 [ * ] reduce .         ! => 24
```

초기값을 직접 지정하면 `sum`이나 `product`로는 표현할 수 없는 폴드도 `reduce`로 표현할 수 있어요. 예를 들어, 모든 원소가 밀렸을 때 쓸 기본값을 두고 시퀀스에서 가장 큰 값을 구할 수 있죠.

```factor
USING: math.order ;

{ 3 1 -4 5 -2 } 0 [ max ] reduce .   ! => 5
{ -3 -1 -4 }    0 [ max ] reduce .   ! => 0
```

초기값 `0`이 비교에 참여하기 때문에, 전부 음수인 시퀀스도 가장 작은 값이 아니라 `0`을 만들어 내요.

## `produce`: 언폴드

`reduce`와 짝을 이루는 반대 개념이 [`sequences`][sequences]에 있는 `produce`예요. `reduce`가 시퀀스를 *소비*한다면, `produce`는 시퀀스를 *만들어 내죠*. 조건을 검사하는 quotation이 현재 상태를 살펴보고, 참으로 평가되는 동안 본문 quotation이 다음 원소를 만들어 내요.

```
produce ( pred quot -- seq )
```

`reduce`와 `produce`는 함께 쓰면 Factor의 폴드/언폴드 짝을 이뤄요.

## 누적 축약

[`math.statistics`][math.statistics]의 누적 축약 계열은 입력과 길이가 같은 시퀀스를 반환해요. 각 원소는 자기 위치까지의 접두사 전체를 축약한 값이죠.

| word          | 누적 연산 |
|---------------|-------------------|
| `cum-sum`     | 누적 합계      |
| `cum-product` | 누적 곱    |
| `cum-min`     | 누적 최솟값    |
| `cum-max`     | 누적 최댓값    |

```factor
USING: math.statistics ;

{ 3 1 4 1 5 9 2 6 } cum-sum .         ! => { 3 4 8 9 14 23 25 31 }
{ 3 1 4 1 5 9 2 6 } cum-min .         ! => { 3 1 1 1 1 1 1 1 }
{ 3 1 4 1 5 9 2 6 } cum-max .         ! => { 3 3 4 4 5 9 9 9 }
```

누적 축약은 어떤 값이 시퀀스를 따라 *어떻게* 변해 왔는지, 최종값만이 아니라 그 과정을 살펴보고 싶을 때 유용해요. 이어 붙여 쓰기에도 좋아요. 한 누적 축약의 출력도 그 자체로 시퀀스라서, 다음 축약에 그대로 넣을 수 있거든요.
