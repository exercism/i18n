# 반환

Crystal에서는 메서드의 마지막 표현식이 그 값을 반환해요.
그런데 때로는 마지막 표현식에 이르기 전에 값을 반환해야 할 때가 있어요.
이럴 때 사용하는 것이 `return` 키워드인데, 이 키워드는 뒤따르는 표현식의 값을 반환해요.
`return` 키워드 뒤에 작성한 코드는 실행되지 않아요.

```crystal
def speed_limit(road_number)
    if road_number == 1
        return 50
        puts "This will not be executed"
    elsif road_number == 2
        return 80
        puts "This will not be executed"
    end
    100
end

p speed_limit(1) # => 50
p speed_limit(2) # => 80
p speed_limit(3) # => 100
```

~~~~exercism/note
메서드의 마지막 표현식이 반환해야 할 값일 때는 `return` 키워드를 생략해야 해요.
~~~~
