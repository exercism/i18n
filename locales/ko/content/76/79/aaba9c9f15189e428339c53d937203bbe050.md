# 소개

JavaScript는 동적 언어로, 객체 지향, 명령형, 선언형(예: 함수형 프로그래밍) 스타일을 지원해요.

## (재)할당

JavaScript에서 이름에 값을 할당하는 기본적인 방법은 몇 가지가 있는데, 변수나 상수를 사용하는 거예요. Exercism에서는 변수를 항상 [camelCase][wiki-camel-case]로 쓰고, 상수는 [SCREAMING_SNAKE_CASE][wiki-snake-case]로 써요. 꼭 따라야 하는 공식 가이드가 있는 것도 아니고, 회사나 조직마다 스타일 가이드가 다 달라요. _변수는 원하는 방식으로 자유롭게 작성해도 돼요_. 연습 문제에서 준비한 방식대로 변수를 작성하면, 웹 인터페이스와 대부분의 IDE에서 다르게 강조 표시된다는 장점이 있어요.

JavaScript에서 변수는 [`const`][mdn-const], [`let`][mdn-let], [`var`][mdn-var] 키워드로 정의할 수 있어요.

`let`이나 `var`를 사용하면 변수는 생명 주기 동안 여러 값을 참조할 수 있어요. 예를 들어 `myFirstVariable`은 할당 연산자 `=`를 사용해 여러 번 정의하고 재정의할 수 있어요:

```javascript
let myFirstVariable = 1
myFirstVariable = 'Some string'
myFirstVariable = new SomeComplexClass()
```

`let`과 `var`와 달리, `const`로 정의한 변수는 한 번만 할당할 수 있어요. JavaScript에서 상수를 정의할 때 이걸 사용해요.

```javascript
const MY_FIRST_CONSTANT = 10

// Can not be re-assigned.
MY_FIRST_CONSTANT = 20
// => TypeError: Assignment to constant variable.
```

> 💡 이후 개념 연습 문제에서 _상수_ 할당/바인딩과 _상수_ 값의 차이를 살펴보고 설명해요.

## 함수 선언

JavaScript에서는 기능 단위를 _함수_로 캡슐화하는데, 보통 서로 관련 있는 함수라면 같은 파일에 모아 둬요. 이 함수들은 매개변수(인자)를 받을 수 있고, `return` 키워드로 값을 _반환_할 수 있어요. 함수는 `()` 문법으로 호출해요.

```javascript
function add(num1, num2) {
  return num1 + num2
}

add(1, 3)
// => 4
```

> 💡 JavaScript에서는 함수를 선언하는 방법이 _아주_ 다양해요. 이런 다른 방법들은 `function` 키워드를 쓰는 것과는 다르게 생겼어요. 이 트랙에서는 이걸 점진적으로 소개하려고 하지만, 이미 알고 있다면 아무 방법이나 자유롭게 써도 돼요. 대부분의 경우 어느 쪽을 쓰든 더 낫거나 나쁘지는 않아요.

## 다른 파일에 노출하기

`function`, 상수, 변수를 _다른 파일_에서 사용할 수 있게 하려면 `export` 키워드로 [내보내야][mdn-export] 해요. 그러면 다른 파일에서 `import` 키워드로 이것들을 [불러올][mdn-import] 수 있어요. 이것을 모듈 시스템이라고도 해요. 좋은 예가 모든 테스트가 동작하는 방식이에요. 각 연습 문제에는 최소한 하나의 파일, 예를 들어 _구현_을 담고 있는 `lasagna.js`가 있어요. 그리고 _테스트_를 담고 있는 또 다른 파일, 예를 들어 `lasagna.spec.js`도 최소한 하나 있어요. 이 파일은 구현을 테스트하기 위해 공개된(즉, 내보낸) 요소들을 _불러와요_:

```javascript
// file.js
export const MY_VALUE = 10

export function add(num1, num2) {
  return num1 + num2
}

// file.spec.js
import { MY_VALUE, add } from './file'

add(MY_VALUE, 5)
// => 15
```
