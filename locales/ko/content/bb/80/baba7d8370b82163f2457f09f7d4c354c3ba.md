# 소개

## chars

Java의 `char` 원시 타입은 단일 문자를 16비트로 표현한 것이에요.
여러 `char`가 모여 `"word"` 같은 문자열을 이룰 수 있고, 각 `char`를 따로 다룰 수도 있어요.
`char` 리터럴은 작은따옴표로 감싸요 (예: `'A'`).

```java
char lowerA = 'a';
char upperB = 'B';
```

## `String`에서 `char` 가져오기

`String.toCharArray` 메서드는 문자열의 `char`들을 배열로 반환해요.
배열에서 언급했듯이, `for`문을 사용해 배열을 순회할 수 있어요.

```java
String text = "Hello";
char[] asArray = text.toCharArray();

for (char ch: asArray) {
    System.out.println(ch);
}

// Outputs:
// H
// e
// l
// l
// o
```

## Character 클래스

`char`를 검사하고 조작하는 내장 라이브러리 메서드가 많이 있어요.
이런 메서드들은 `java.lang.Character` 클래스의 정적 메서드로 찾을 수 있어요.
몇 가지 예를 살펴볼까요:

```java
Character.isWhitespace(' ');    // true
Character.isWhitespace('#');    // false

Character.isLetter('a');        // true
Character.isLetter('3');        // false

Character.isDigit('6');         // true
Character.isDigit('?');         // false
```

## `String`에 `char` 추가하기

`+` 연산자를 사용해 `String`에 `char`를 추가할 수 있어요.

```java
'a' + " banana"     // => "a banana"
"banana " + 'a'     // => "banana a"
```

~~~~exercism/caution
`+`로 두 `char`를 이어 붙여 `String`을 만들지 _않도록_ 조심해요!
이렇게 두 `char`를 더하면 `String`이 _아니라_ `int`가 나와요!
예를 들어:

```java
'b' + 'c';
// => 197 (not the String "bc")
```

이는 Java가 `char`를 `int`로 승격시키기 때문이에요 ([Java Language Specification][jls-main]의 [4.2 Primitive Types and Values ][jls-primitives] 참고).

[jls-main]: https://docs.oracle.com/javase/specs/jls/se21/html/
[jls-primitives]: https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.2
~~~~

하지만 추가할 문자가 많을 때는 대신 `StringBuilder`를 사용하는 편이 더 효율적일 수 있어요:

```java
StringBuilder builder = new StringBuilder();
builder.append('a');
builder.append('b');
builder.append('c');

String builtString = builder.toString();
// => abc
```
