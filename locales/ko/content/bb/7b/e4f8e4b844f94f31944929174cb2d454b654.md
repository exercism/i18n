# 자세히 알아보기

흔히 쓰는 수학 함수는 [`math.functions`][math.functions]에 있고, 상수는 [`math.constants`][math.constants]에, 실수만 다루는 워드 몇 개는 [`math.libm`][math.libm]에 있어요. 각 워드는 스택에서 입력을 받아요.

```factor
USING: kernel math math.constants math.functions math.libm prettyprint ;

9 sqrt .            ! => 3.0
1.0 1.0 fatan2 .    ! => 0.7853981633974483
```

## 상수

| 워드 | 값 |
| --- | --- |
| `pi` | π, 3.14159… |
| `e` | *e*, 2.71828… |

## 제곱근과 거듭제곱

| 워드 | 스택 효과 | 반환값 |
| --- | --- | --- |
| `sqrt` | `( x -- y )` | `x`의 제곱근 |
| `sq` | `( x -- y )` | `x * x` |
| `^` | `( x y -- z )` | `x`의 `y`제곱. `y`는 정수가 아니어도 돼요 |

## 삼각함수

| 워드 | 스택 효과 | 반환값 |
| --- | --- | --- |
| `sin` `cos` `tan` | `( x -- y )` | 라디안 단위 각도 `x`에 대한 값 |
| `asin` `acos` `atan` | `( x -- y )` | 사인, 코사인, 탄젠트가 `x`인 각도(라디안) |
| `fatan2` | `( y x -- z )` | 양의 `x` 방향에서 점 (`x`, `y`)까지의 각도(라디안) |
| `deg>rad` | `( x -- y )` | 도를 라디안으로 변환 |
| `rad>deg` | `( x -- y )` | 라디안을 도로 변환 |

모든 각도는 **라디안** 단위예요. 한 바퀴는 360이 아니라 2π예요. 경계에서 단위를 바꾸고, 그 사이에서는 라디안으로 계산해요.

방향을 구할 때는 `atan`보다 `fatan2`(`math.libm`에 있어요)가 낫아요. `1 1 / atan`은 (1, 1)과 (−1, −1)을 구분하지 못해요. 둘 다 나누면 `1`이 되니까요. 게다가 `x`가 0이면 실패해요. `fatan2`는 두 부호를 모두 살펴서 −π에서 π 사이 어디든 답을 내요:

```factor
1 1 / atan rad>deg .          ! => 45.0
-1 -1 / atan rad>deg .        ! => 45.0
-1.0 -1.0 fatan2 rad>deg .    ! => -135.0
```

## 지수와 로그

| 워드 | 스택 효과 | 반환값 |
| --- | --- | --- |
| `e^` | `( x -- y )` | *e*의 `x`제곱 |
| `log` | `( x -- y )` | 자연로그. `x`가 되려면 *e*를 몇 제곱해야 하는지 |
| `10^` | `( x -- y )` | 10의 `x`제곱 |
| `log10` | `( x -- y )` | 밑이 10인 로그 |
| `log2` | `( x -- y )` | 밑이 2인 로그 |

`e^`와 `log`는 서로를 되돌려요. `10^`와 `log10`도 마찬가지예요.

매 단계마다 같은 비율로 줄어드는 것은 `start * e^(-rate * t)`를 따라요. `start`에서 `level`까지 떨어지는 데 걸리는 시간은 `log(start / level) / rate`예요.

## 실수인 답이 없을 때

이 워드들은 이상한 입력이 들어와도 오류를 내지 않아요. 음수의 제곱근이나 로그는 **복소수** 결과를 내는데, 이때는 보통 숫자 대신 `C{ ... }`가 둘러싼 형태로 출력돼요:

```factor
-1 sqrt .     ! => C{ 0.0 1.0 }
-1.0 log .    ! => C{ 0.0 3.141592653589793 }
0.0 log .     ! => -1/0.
```

`-1/0.`은 음의 무한대예요. 잘못된 인자가 들어올 수 있다면 호출하기 전에 확인해요. 계산 세 단계를 지나서야 발견한 복소수나 무한대는 원인을 추적하기 어려워요.

## 반올림도 여기서는 근사값이에요

이 워드들은 정확한 값이 아니라 가장 가까운 실수를 반환해요. 그러니 결과를 비교할 때는 `=` 대신 `~ ( x y epsilon -- ? )`로 오차 범위를 두고 비교해요:

```factor
pi 6 / sin .             ! => 0.49999999999999994
pi 6 / sin 0.5 = .       ! => f
pi 6 / sin 0.5 1e-9 ~ .  ! => t
```
