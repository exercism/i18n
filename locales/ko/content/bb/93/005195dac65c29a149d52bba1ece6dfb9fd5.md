# 상태를 가진 클래스

지금까지 나온 클래스는 모두 루틴을 담은 상자였어요. 각 루틴은 인자를 받아 답을 계산한 뒤 모든 것을 잊어버렸죠.

그런데 클래스는 무언가를 **기억**할 수도 있어요. 점수판은 그래야 하죠. 점수는 경기가 시작된 뒤의 모든 득점에 따라 달라지니까요.

## 속성

`attr`은 클래스가 무언가를 기억하게 해줘요.

```sather
class SCOREBOARD is

   attr home_score : INT;
   attr away_score : INT;

end; -- class SCOREBOARD
```

`attr` 하나는 값을 읽는 루틴과 값을 바꾸는 루틴, 이렇게 두 개가 되어요.

```sather
   board.home_score            -- read it
   board.home_score := 4;      -- change it
```

같은 타입의 속성은 인자처럼 선언을 함께 쓸 수 있어요.

```sather
   attr home_score, away_score : INT;
```

## 객체

속성을 가진 클래스는 **객체**를 만드는 틀이에요. 객체마다 속성의 사본을 따로 가지기 때문에, 점수판 두 개는 각각의 점수를 따로 기억해요.

`new`는 객체를 만들어요. `new`는 `create`라는 루틴 안에 들어가는데, 이 루틴이 객체를 채운 뒤 돌려줘요.

```sather
   create(home, away : STR) : SAME is
      board ::= new;
      board.home_team := home;
      board.away_team := away;
      return board;
   end;
```

`SAME`은 "이 클래스"를 뜻해요. 그 자리에 `SCOREBOARD`라고 써도 같은 의미지만, 클래스 이름이 바뀌어도 `SAME`은 계속 동작해요.

## 하나 만들어 보기

`#`은 `create`를 호출해요.

```sather
   board ::= #SCOREBOARD("Vixens", "Magpies");
```

`rehearsal-script` 이후로 `#`을 계속 써 왔어요. `#FSTR`도 바로 이거예요.

## 객체를 바꾸는 루틴

클래스 안에서는 객체를 앞에 두지 않고 속성의 이름만으로 사용해요. 그 속성은 루틴이 호출된 객체를 가리켜요.

```sather
   home_goal is
      home_score := home_score + 1;
   end;
```

`home_goal`은 반환 타입을 선언하지 않아요. 아무것도 반환하지 않고 대신 객체를 바꾸기 때문이에요. 문으로 호출해요.

```sather
   board.home_goal;
```

## 속성은 비어 있는 상태로 시작해요

아무도 값을 지정하지 않은 속성은 `INT`라면 0, `BOOL`이라면 `false`, 문자열이나 객체라면 void를 담고 있어요. 그래서 새로 만든 점수판은 아무것도 알려주지 않아도 0 대 0으로 표시돼요.
