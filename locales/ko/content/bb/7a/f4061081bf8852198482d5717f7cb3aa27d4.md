# 지시 사항

디자인 팀은 레이아웃 작업 중 일부를 CSS 변환에서 Factor로 옮기고 있어요. 나머지 팀원들이 만족할 수 있도록, 2차원 점을 받아 2차원 점을 반환하는 작고 재사용 가능한 변환을 쿼테이션으로 만들어 봐요.

점은 요소 두 개로 이루어진 배열 `{ x y }`예요.

## 1. 좌표 이동하기

`translate-2d`를 정의해서 스택에서 두 값 `dx`와 `dy`를 꺼내고, 점을 `(dx, dy)`만큼 이동시키는 쿼테이션을 반환해요.

```factor
{ 4 8 } 2 0 translate-2d call( p -- p' ) .
! => { 6 8 }
```

## 2. 좌표 크기 조정하기

`scale-2d`도 같은 방식으로 정의해서, 점의 크기를 `(sx, sy)`만큼 조정하는 쿼테이션을 반환해요.

```factor
{ 6 -3 } 2 2 scale-2d call( p -- p' ) .
! => { 12 -6 }
```

## 3. 두 변환 합성하기

`compose-transformations`를 정의해서 두 변환 쿼테이션 `f`와 `g`를 받고, `f`를 먼저 적용한 다음 `g`를 적용하는 하나의 쿼테이션을 반환해요.

```factor
{ 0 1 } 2 0 translate-2d 2 2 scale-2d compose-transformations
call( p -- p' ) .
! => { 4 2 }
```

## 4. 변환 적용하기

`apply-transformation`을 정의해서 스택에서 점과 변환 쿼테이션을 꺼내고, 변환된 점을 반환해요.

```factor
{ 4 8 } 2 0 translate-2d apply-transformation .
! => { 6 8 }
```

## 5. 여러 점을 한 번에 변환하기

`transform-points`를 정의해서 점들의 배열과 변환 쿼테이션을 받고, 변환된 점들의 배열을 반환해요.

```factor
{ { 0 0 } { 1 1 } { 2 2 } } 1 0 translate-2d transform-points .
! => { { 1 0 } { 2 1 } { 3 2 } }
```
