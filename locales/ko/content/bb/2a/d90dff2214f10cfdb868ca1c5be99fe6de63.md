# 정보

C# 타입은 클래스나 구조체의 스코프 안에서 정의할 수 있어요. 바깥쪽 타입은 일종의 네임스페이스 역할을 해요. 타입에 접근할 때는 바깥쪽 타입을 거쳐 점 표기법으로 접근해요.

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

## 접근 수준

접근 수준은 내부 타입에도 적용할 수 있어요. 예를 들어 클래스가 `private`이면 바깥쪽 타입의 스코프 밖에서는 보이지 않고, 물론 스코프 밖에서는 인스턴스도 보이거나 사용할 수 없어요.

바깥쪽 클래스의 private 멤버는 내부 클래스의 모든 멤버가 접근할 수 있지만, 바깥쪽 클래스의 멤버는 내부 클래스의 private이 아닌 멤버에만 접근할 수 있어요. 바깥쪽 클래스의 멤버에 접근하려면 내부 클래스에 바깥쪽 클래스의 인스턴스를 넘겨줘야 해요.

다음 예제에서 확인할 수 있어요:

```csharp
class Outer
{
    public class InnerImpl
    {
        private Outer outer;

        public int Interesting = 42;

        public InnerImpl(Outer outer, int interesting)
        {
            this.outer = outer;
            Interesting = interesting;
        }

    }

    public InnerImpl Inner;
    public Outer()
    {
        Inner = new InnerImpl(this, 42);
    }
}

var outer = new Outer();
outer.Inner.Interesting
// => 42
var inner = new Outer.InnerImpl(outer, 1729);
outer.Inner.Interesting
// => 1729
```

## 독립적인 인스턴스화 방지

인스턴스화할 수 있는 타입이 바깥쪽 타입 밖에서 만들어지지 않게 하는 패턴이 있어요. public 인터페이스는 노출하되, 구현 클래스는 private으로 유지해요.

```csharp
class Outer
{
    public interface IInner
    {
        void DoSomething();
    }

    private class InnerImpl : IInner
    {
        private Outer outer;
        public InnerImpl(Outer outer)
        {
            this.outer = outer;
        }
        public void DoSomething()
        {
            outer.DoSomethingElse();
        }
    }

    public IInner Inner;

    public Outer()
    {
        Inner = new InnerImpl(this);
    }
    private void DoSomethingElse()
    {
    }
}

var outer = new Outer();
outer.Inner.DoSomething();

// NOT var inner = new Outer.Inner(outer);
```

## Java 개발자를 위한 참고

C#의 중첩 클래스는 Java의 static 중첩 클래스와 내부 클래스의 중간쯤이에요. C#에서는 바깥쪽 클래스의 private 멤버가 중첩 클래스의 멤버에서 접근할 수 있지만, 중첩 클래스를 인스턴스화하고 바깥쪽 클래스의 인스턴스에 연결하는 특별한 문법은 없어요. 위 예제에서 보여 준 패턴을 조금씩 변형해서 사용해야 해요.

C#에도 static 중첩 클래스가 있지만, 이들은 단순히 static 동작을 하는 포함된 클래스일 뿐이에요.
