# 자세히 알아보기

부동소수점 수는 소수점 뒤에 0개 이상의 자릿수를 가진 수예요. 예를 들면 `-2.4`, `0.1`, `3.14`, `16.984025`, `1024.0` 같은 것들이에요.

F#에는 세 가지 부동소수점 타입이 있어요:

- `single`: 4바이트(정밀도 약 6~9 자릿수). `2.45f` 또는 `2.45F`로 써요. `float32` 타입을 별칭으로 사용할 수 있어요.
- `float`: 8바이트(정밀도 약 15~17 자릿수). 가장 흔히 쓰는 타입이에요. `2.45`로 쓰거나, 지수 표기법으로 `2.3E+32` 또는 `2.3e+32`처럼 써요. `double` 타입을 별칭으로 사용할 수 있어요.
- `decimal`: 16바이트(정밀도 28~29 자릿수). 보통 금액 데이터를 다룰 때 사용해요. 정밀도가 높아 반올림 오류가 적기 때문이에요. `2.45m` 또는 `2.45M`로 써요.

부동소수점 타입마다 [정밀도, 대략적인 범위와 크기][floating-point-types]가 달라요. 정밀도는 소수점 뒤에 몇 자릿수까지 저장할 수 있는지를 나타내요. 따라서 PI를 `single`에 저장하려고 하면 처음 6~9 자릿수만 저장되고, 마지막 자릿수는 반올림돼요.

서로 다른 부동소수점 타입 사이의 변환은 [변환 연산자][conversion-operators]로 해요:

```fsharp
let floatFromSingle = float 2.45f
```

부동소수점 타입의 값이 같은지 비교할 때는 항상 주의해야 해요. 같아 보이는 값이 실제로는 다를 수 있거든요. 자세한 내용은 [이 글][precision-in-comparisons]을 참고해요(코드 예제는 C#으로 되어 있어요).

부동소수점 수에 대한 짧은 소개는 [0.30000000000000004.com][0.30000000000000004.com]에서 볼 수 있어요. [Float Toy 페이지][evanw.github.io-float-toy]에는 부동소수점 수의 비트가 실제 부동소수점 값으로 어떻게 변환되는지 그림과 함께 잘 설명되어 있어요.
