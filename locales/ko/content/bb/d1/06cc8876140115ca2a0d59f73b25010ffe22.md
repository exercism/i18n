# 지시 사항

이 연습 문제에서는 좋아하는 요리책에 나오는 근사한 라자냐를 만들 수 있도록 도와주는 코드를 작성해 볼 거예요.

라자냐를 조리하는 데 걸리는 시간과 관련된 네 가지 과제가 있어요.

## 1. 오븐 예상 시간을 분 단위로 정의하기

라자냐가 오븐에 있어야 할 시간(분)을 반환하는 `Lasagna::EXPECTED_MINUTES_IN_OVEN` 상수를 정의해요. 요리책에 따르면 오븐 예상 시간은 40분이에요:

```ruby
Lasagna::EXPECTED_MINUTES_IN_OVEN
# => 40
```

## 2. 남은 오븐 시간을 분 단위로 계산하기

라자냐가 지금까지 오븐에 있었던 실제 시간(분)을 매개변수로 받아서, 앞 과제에서 구한 오븐 예상 시간을 기준으로 라자냐가 오븐에 더 있어야 할 시간(분)을 반환하는 `Lasagna#remaining_minutes_in_oven` 메서드를 정의해요.

```ruby
lasagna = Lasagna.new
lasagna.remaining_minutes_in_oven(30)
# => 10
```

## 3. 준비 시간을 분 단위로 계산하기

라자냐에 넣은 층의 개수를 매개변수로 받아서, 각 층을 준비하는 데 2분이 걸린다고 가정했을 때 라자냐를 준비하는 데 걸린 시간(분)을 반환하는 `Lasagna#preparation_time_in_minutes` 메서드를 정의해요.

```ruby
lasagna = Lasagna.new
lasagna.preparation_time_in_minutes(2)
# => 4
```

## 4. 총 작업 시간을 분 단위로 계산하기

이름이 있는 매개변수 두 개를 받는 `Lasagna#total_time_in_minutes` 메서드를 정의해요. `number_of_layers` 매개변수는 라자냐에 넣은 층의 개수이고, `actual_minutes_in_oven` 매개변수는 라자냐가 오븐에 있었던 시간(분)이에요. 이 함수는 라자냐를 조리하는 데 총 몇 분을 들였는지를 반환해야 하는데, 이는 준비 시간(분)과 현재까지 라자냐가 오븐에서 보낸 시간(분)을 더한 값이에요.

```ruby
lasagna = Lasagna.new
lasagna.total_time_in_minutes(number_of_layers: 3, actual_minutes_in_oven: 20)
# => 26
```
