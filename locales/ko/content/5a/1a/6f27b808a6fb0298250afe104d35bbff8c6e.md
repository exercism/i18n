# ABAP 트랙 클론하기

## 사전 요구 사항

1. ABAP 시스템 릴리스 7.4 이상
2. abapGit v1.115.0 이상
3. ABAP 패키지, 프로그램, 클래스를 구현할 수 있는 권한

## abapGit 설치하기

모든 연습 문제가 포함된 ABAP 트랙은 abapGit 저장소로 구현되어 있어요. 트랙을 자신의 시스템으로 클론하려면 먼저 abapGit을 설치해야 해요.

1. [https://github.com/abapGit/abapGit](https://github.com/abapGit/abapGit)으로 이동해요
2. `zabapgit_standalone.prog.abap` 파일을 내려받아요
3. 자신의 시스템에 `zabapgit_standalone` 프로그램을 만들어요
4. `zabapgit_standalone.prog.abap`의 소스를 `zabapgit_standalone` 프로그램에 업로드해요
5. 프로그램을 활성화해요

## Exercism ABAP 트랙 설치하기

### 온라인 저장소

시스템이 인터넷에 연결되어 있고 GitHub.com에 접속할 수 있다면 이 방법을 사용해요 (권장 방식).

1. abapGit을 실행해요

![abapGit 온라인 저장소](https://github.com/exercism/abap/blob/main/docs/clone_01.png?raw=true)

2. "Repository Overview"에서 "New Online"을 선택해요
3. 다음 값을 입력해요
- URL: `https://github.com/exercism/abap`
- Package: `$exer`
- Display Name: `Exercism - ABAP Track`

참고: 패키지 이름이 `$exercism`처럼 너무 길면 저장소를 가져오려 할 때 오류가 발생해요. 위에서처럼 이름을 짧게 유지해요.

![abapGit 온라인 저장소](https://github.com/exercism/abap/blob/main/docs/clone_02.png?raw=true)

4. "Create Online Repository"를 선택해요. 그러면 상태가 "A"인 오브젝트 목록이 보여요:

![abapGit 온라인 저장소](https://github.com/exercism/abap/blob/main/docs/clone_03.png?raw=true)

5. "Pull"을 선택해 모든 오브젝트를 시스템으로 클론해요. 완료되면 모든 오브젝트의 상태가 비어 있는 것을 볼 수 있어요

![abapGit 온라인 저장소](https://github.com/exercism/abap/blob/main/docs/clone_04.png?raw=true)

### 오프라인 저장소

시스템이 인터넷에 연결되어 있지 *않은* 경우 이 방법을 사용해요.

1. [https://github.com/exercism/abap](https://github.com/exercism/abap)으로 이동해요
2. 저장소 ZIP 파일을 내려받아요

![abapGit 오프라인 저장소](https://github.com/exercism/abap/blob/main/docs/clone_10.png?raw=true)

3. abapGit을 실행해요
4. "Repository Overview"에서 "New Offline"을 선택해요
5. 다음 값을 입력해요
- Repository Name: `Exercism - ABAP Track`
- Package: `$exer`

![abapGit 오프라인 저장소](https://github.com/exercism/abap/blob/main/docs/clone_11.png?raw=true)

6. "Create Offline Repository"를 선택해요

![abapGit 오프라인 저장소](https://github.com/exercism/abap/blob/main/docs/clone_12.png?raw=true)

7. "Import ZIP"을 선택하고 내려받은 ZIP 파일을 골라요. 그러면 상태가 "A"인 오브젝트 목록이 보여요:

![abapGit 오프라인 저장소](https://github.com/exercism/abap/blob/main/docs/clone_13.png?raw=true)

8. "Pull ZIP"을 선택해 모든 오브젝트를 시스템으로 클론해요. 완료되면 모든 오브젝트의 상태가 비어 있는 것을 볼 수 있어요

![abapGit 오프라인 저장소](https://github.com/exercism/abap/blob/main/docs/clone_14.png?raw=true)

## Exercism ABAP 트랙 제거하기

다음 방법으로 시스템에서 모든 오브젝트를 제거할 수 있어요:

1. abapGit을 실행해요
2. `Execism - ABAP Track` 저장소로 이동해요
3. "Advanced > Uninstall"을 선택해요
4. 모든 오브젝트와 저장소를 삭제할지 확인해요

## 문제 해결

- 연결에 문제가 있다면 [SSL Setup](https://docs.abapgit.org/user-guide/setup/ssl-setup.html)을 확인해요
- `Package $EXERCISM_DIFFERENCE-OF-SQUARES exceeds ABAP 30-characters name limit` 오류가 발생하면 `$exer`처럼 더 짧은 패키지 이름을 사용해요.
- ABAP 시스템으로 풀한 뒤 일부 파일에 차이점이 표시될 수 있어요. 파일 끝 문자나 바이트 순서 표시와 관련된 차이는 무시해도 돼요.
