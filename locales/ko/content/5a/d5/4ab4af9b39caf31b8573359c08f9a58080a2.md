# 지침

이번 과제는 완벽한 테이블 자리 배치를 찾는 거예요. 그러려면 _사실_(항상 참인 것)과 _규칙_(조건이 맞을 때만 참인 것)을 선언하면 돼요.

## 1. 수다스러운 사람 나열하기

수다스러운 사람을 나타내는 `chatty` 사실을 정의해요. `chatty` 사실은 인자를 하나 받는데, 바로 수다스러운 사람의 소문자 이름이에요.

```prolog
chatty(gustavo).
true.
```

## 2. 누가 누구를 좋아하는지 나열하기

누가 누구를 좋아하는지 나타내는 `likes` 사실을 정의해요. `likes` 사실은 인자를 두 개 받아요:

1. 다른 사람을 좋아하는 사람의 소문자 이름
2. 좋아하는 대상이 되는 사람의 소문자 이름

```prolog
likes(esteban, malena).
true.
```

## 3. 서로 좋아하는 사람은 좋은 짝이 돼요

두 사람이 서로를 좋아하면 `pairing` 규칙이 참이 되도록 정의해요. 이 규칙은 인자를 두 개 받아요:

1. 첫 번째 사람의 소문자 이름
2. 두 번째 사람의 소문자 이름

```prolog
pairing(malena, esteban).
true.
```

## 4. 수다스러운 사람은 누구와도 짝이 돼요

짝을 이루는 두 사람 중 (적어도) 한 명이 수다스러우면 `pairing` 규칙이 참이 되도록 정의해요.

```prolog
pairing(valeria, jaime).
true.
```

## 5. 자리 배치 확인하기

다섯 쌍이 모두 좋은 짝이면 `seating` 규칙이 참이 되도록 정의해요.

pairing 규칙은 인자를 다섯 개 받아요:

1. 첫 번째 사람의 소문자 이름
2. 두 번째 사람의 소문자 이름
3. 세 번째 사람의 소문자 이름
4. 네 번째 사람의 소문자 이름
5. 다섯 번째 사람의 소문자 이름

방금 정의한 사실과 규칙을 사용해서 자리 배치를 확인해요.

```prolog
seating(esteban, jaime, gustavo, malena, valeria).
false.
```
