# 자세히 알아보기

함수는 하나 이상의 인자에 대해 [기본값][default-arguments]을 선언할 수 있어요.

```elixir
def number(n \\ 13), do: "That's not my favorite"
```

- 위 예제를 컴파일하면 Elixir는 `number/0`(인자 없음)과 `number/1`(인자 하나)에 대한 함수 정의를 만들어요.
- 두 개 이상의 인자에 기본값이 있으면, 빠진 인자를 채우기 위해 그 기본값들이 왼쪽에서 오른쪽 순서로 함수에 적용돼요.
- 함수에 여러 개의 절이 있으면, 기본값을 위해 [함수 헤더][function-header]를 작성해야 해요.
- 어떤 표현식이든 기본값이 될 수 있어요.
- 익명 함수는 기본 인자를 가질 수 없어요.

```elixir
def guess(number \\ 5)
def guess(number) when number != 5, do: false
def guess(number) when number == 5, do: true

guess()
# => true
```
