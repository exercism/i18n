# 소개

Elixir는 _Bitwise 모듈_에서 비트를 다루는 많은 함수를 지원해요.

- `band/2`: 비트 단위 AND
- `bsl/2`: 비트 단위 왼쪽 시프트
- `bsr/2`: 비트 단위 오른쪽 시프트
- `bxor/2`: 비트 단위 XOR
- `bor/2`: 비트 단위 OR
- `bnot/1`: 비트 단위 NOT

다음은 비트 단위 함수를 사용하는 예시예요:

```elixir
Bitwise.bsl(1, 3)
# => 8
```

모든 비트 단위 함수는 정수에서만 동작해요.

Elixir 1.9 이하 버전을 사용한다면, _Bitwise_ 모듈을 사용하기 위해 모듈 정의 시작 부분에서 `require Bitwise`를 호출해야 해요.
