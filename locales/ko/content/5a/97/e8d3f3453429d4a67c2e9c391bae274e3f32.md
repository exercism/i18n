# SQLite 관련 지침

* **digits** 열에는 정수로 이루어진 JSON 인코딩 목록이 들어 있어요.
  예시:
  ```json
  [1,0,1,0,1,0]
  ```
* **result** 열에는 JSON 인코딩 데이터가 들어가야 해요. digits를 정수로 담은 객체이거나, 오류에 대한 설명이에요.
  예시:
  ```json
  {"digits":[1,0,1,0,1,0]}
  ```
  또는
  ```json
  {"error":"some error description"}
  ```

## Table Schema

```sql
CREATE TABLE IF NOT EXISTS "all-your-base" (
  input_base  INTEGER NOT NULL,
  digits      TEXT    NOT NULL, -- json array
  output_base INTEGER NOT NULL,
  result      TEXT              -- json object
);
```
