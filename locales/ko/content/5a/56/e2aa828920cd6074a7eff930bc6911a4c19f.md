# 지침

Mary는 TV 시리즈 _Star Trek: The Next Generation_의 열렬한 팬이에요. 그녀는 친구들과 함께 _Starship Enterprise_의 승무원인 척하는 펜 앤 페이퍼 롤플레잉 게임을 자주 해요. Mary의 캐릭터는 Picard 함장이라서 함장 일지를 적어야 해요. 그녀는 게임의 창작적인 부분은 좋아하지만, 즉석에서 무작위 데이터를 만드는 것은 좋아하지 않아요.

함장 일지에 자주 등장하는 데이터를 위한 무작위 생성기를 만들어서 Mary를 도와줘요.

## 1. 무작위 행성을 만들어요

_Starship Enterprise_는 여행 중에 수많은 행성을 만나요. Star Trek 세계관의 행성은 특성에 따라 여러 등급으로 나뉘어요. 예를 들어, 지구는 M등급 행성이에요. 가능한 모든 행성 등급은 D, H, J, K, L, M, N, R, T, Y예요.

`random_planet_class/0` 함수를 구현해요. 이 함수는 행성 등급 중 하나를 무작위로 반환해야 해요.

```elixir
CaptainsLog.random_planet_class()
# => "K"
```

## 2. 무작위 우주선 등록 번호를 만들어요

Enterprise(등록 번호 NCC-1701)만 우주를 날아다니는 게 아니에요! 다른 우주선과 만나면, Mary는 그 우주선의 등록 번호를 기록해야 해요.

등록 번호는 "NCC-" 접두사로 시작하고, 그다음에 1000부터 9999까지(포함)의 숫자가 와요.

무작위 우주선 등록 번호를 반환하는 `random_ship_registry_number/0` 함수를 구현해요.

```elixir
CaptainsLog.random_ship_registry_number()
# => "NCC-1947"
```

## 3. 무작위 스타데이트를 만들어요

날짜도 없는 일지가 무슨 소용이 있을까요?

스타데이트는 실수예요. _The Next Generation_의 첫 번째 시즌에 나오는 _Starship Enterprise_의 모험은 스타데이트 41000.0과 42000.0 사이에서 펼쳐져요. "4"는 24세기를, "1"은 첫 번째 시즌을 나타내요.

41000.0(포함)과 42000.0(미포함) 사이의 실수를 반환하는 `random_stardate/0` 함수를 구현해요.

구현에는 Erlang 함수를 사용해야 해요.

```elixir
CaptainsLog.random_stardate()
# => 41458.15721310934
```

## 4. 스타데이트 형식을 지정해요

함장 일지에서는 보통 스타데이트를 소수점 한 자리로 반올림해요.

실수를 받아서 소수점 한 자리로 반올림한 수를 문자열로 반환하는 `format_stardate/1` 함수를 구현해요.

구현에는 Erlang 함수를 사용해야 해요.

```elixir
CaptainsLog.format_stardate(41458.15721310934)
# => "41458.2"
```
