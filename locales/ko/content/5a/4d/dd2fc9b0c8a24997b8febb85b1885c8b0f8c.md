# 소개

블록은 여러 문과 선언을 하나의 구문 단위로 묶은 것이에요.
블록은 흔히 중괄호 안에 정의되지만, 항상 그런 것은 아니에요.
블록은 함수 안에, 또 다른 블록 안에 중첩될 수 있어요.

함수는 블록과 비슷하게 동작해요.
함수 안에서 정의된 변수의 식별자는 함수 밖에서 볼 수 없어요. 마찬가지로 블록 안에서 정의된 변수의 식별자는 블록 밖에서 볼 수 없어요.
두 함수에 있는 두 변수는 이름이 같아도 돼요. 두 함수는 서로의 내부를 볼 수 없기 때문이에요. 마찬가지로 두 블록에 있는 두 변수도 이름이 같아도 되는데, 두 블록이 서로의 내부를 볼 수 없기 때문이에요.
그렇지만 함수와 블록이 완전히 같은 것은 아니에요.
함수는 다른 함수 안에 중첩될 수 없지만, 블록은 다른 블록 안에 중첩될 수 있어요.

다음 예제에서 `number`는 `main` 함수 안에서 정의돼요.
`flag`는 `main` 함수 안에 중첩된 `if` 블록 안에서 정의돼요.
블록 안에서 정의된 변수는 그 블록 안에서만 유효해요.
따라서 이 코드를 컴파일하려고 하면 컴파일 오류가 발생해요.

```c
#include <stdio.h>

int main() {

  int number = 1;

  if (number == 1) {
      int flag = 1;
      printf("%d", flag);
  }

  // this line generates a compilation error
  // error: 'flag' undeclared (first use in this function)
  printf("%d", flag);
    
}
```

`flag`는 함수 앞부분에서 _실제로_ 사용되기 때문에 이 오류 메시지가 헷갈릴 수 있어요.
하지만 `flag`는 함수 안쪽 블록에서 정의돼요.
안쪽 블록은 바깥 함수에 있는 `number` 변수를 "볼" 수 있지만, 바깥 함수는 안쪽 블록에서 정의된 `flag` 변수를 "볼" 수 없어요.
실행이 블록을 벗어나면 `flag` 변수는 자동으로 소멸되고, 더 이상 프로그램에서 사용할 수 없어요.
`main` 함수는 마지막 `printf` 문에서야 `flag` 식별자를 처음 보게 돼요.
마지막 `printf` 문을 지우면 프로그램은 컴파일에 성공하고, 실행하면 `1`을 출력해요.
`flag` 변수는 첫 번째 `printf` 문이 있는 블록 안에서는 유효하기 때문이에요.

`C99`부터는 한 줄짜리 `if`, `for`, `while`, `do` 문도 블록으로 취급해요.
다음 예제에서 `i`는 중괄호 안에 정의되지 않았지만, `for` 문이 정의하는 블록 안에만 존재하고 바깥의 `main` 함수에서는 보이지 않아요.

```c
#include <stdio.h>

int main() {

    for (int i = 0, j = 11; i < j; i+=2)
        printf("%d", i);

    // this line generates a compilation error
    // error: 'i' undeclared (first use in this function)
    printf("%d", i);
    
}
```

마지막 `printf` 문을 지우면 프로그램은 컴파일에 성공하고, 실행하면 `0 2 4 6 8 10 `을 출력해요.
Go나 Rust 같은 몇몇 언어는 한 줄짜리 조건문과 반복문도 하나의 블록을 이룬다고 분명히 정해 두고 있어요.
이런 언어들은 한 줄짜리 문이라도 반드시 중괄호로 감싸도록 요구해요.
