# Char

`Char`는 Crystal에서 32비트 [유니코드][unicode] 코드 포인트를 나타내는 데이터 타입이에요.
크기가 32비트라서 메모리 효율이 좋고, 문자열에는 없는 특별한 성질을 가지고 있어요.
작은따옴표(`'`)로 만들며, 안에는 유니코드 코드 포인트 하나만 넣을 수 있어요.

```crystal
'a' # => 'a'
'a'.class # => Char
```

Crystal에서 문자열을 다룰 때 Char를 함께 다루는 일은 흔한데, String 클래스의 꽤 많은 메서드가 Char를 반환하거나 Char를 인자로 받기 때문이에요.
예를 들어 [`String#[]`][index] 메서드는 Char를 반환하고, [`String#chars`][chars] 메서드는 Char의 컬렉션을 반환해요.

## 증가와 감소

Char는 32비트 유니코드 코드 포인트라서 증가와 감소를 지원해요. 그래서 `'a'`가 있을 때 1을 더하면 `'b'`를 얻을 수 있어요.

```crystal
'a' + 5
# => 'f'

'z' - 25
# => 'a'
```

유니코드 표에서 다음 문자를 반환하는 [`Char#succ`][succ] 메서드와, 이전 문자를 반환하는 [`Char#pred`][pred] 메서드도 있어요.

```crystal
'a'.succ
# => 'b'

'z'.pred
# => 'y'
```

## 연결

Char는 32비트 유니코드 코드 포인트 하나만 나타내도록 만들어졌기 때문에, Char 두 개를 연결할 수는 없어요.
따라서 Char는 문자열하고만 연결할 수 있어요.

```Crystal
'a' + "bc"
# => "abc"

'a' + 'b'
# => error: expected argument #1 to 'Char#+' to be Int or String, not Char
```

## 속성 메서드

Crystal에는 문자가 숫자인지, 글자인지, 대문자인지 소문자인지 같은 정보를 알아낼 수 있는 메서드가 몇 가지 있어요.
다음은 그중 일부를 정리한 목록이고, 전체 목록은 [Char API][char-api]에서 확인할 수 있어요:

| 메서드                          | 설명                                                 |
| -------------------------------- | ---------------------------------------------------- |
| [`Char#number?`][number]         | `Char`가 숫자면 `true`를 반환해요                    |
| [`Char#letter?`][letter]         | `Char`가 글자면 `true`를 반환해요                    |
| [`Char#lowercase?`][lowercase]   | `Char`가 소문자면 `true`를 반환해요                  |
| [`Char#uppercase?`][uppercase]   | `Char`가 대문자면 `true`를 반환해요                  |
| [`Char#ascii?`][ascii]           | `Char`가 ASCII 문자면 `true`를 반환해요              |
| [`Char#whitespace?`][whitespace] | `Char`가 공백 문자면 `true`를 반환해요               |

## 변환

### 코드 포인트와 Char 사이의 변환

Char는 32비트 유니코드 코드 포인트라서, Char와 코드 포인트(정수) 사이를 변환할 수 있어요.
이때 [`Char#ord`][ord] 메서드는 Char의 코드 포인트를 반환하고, [`Int#chr`][chr] 메서드는 코드 포인트의 Char를 반환해요.

```crystal
'a'.ord
# => 97

97.chr
# => 'a'
```

### 타입 사이의 변환

다른 데이터 타입과 마찬가지로, Char에도 타입을 변환하는 메서드가 몇 가지 있어요.
가장 흔히 쓰는 건 Char를 문자열로 변환하는 `Char#to_s` 메서드예요. 그 밖에도 Char를 정수로 변환하는 `Char#to_i` 메서드와 Char를 실수로 변환하는 `Char#to_f` 메서드가 있어요.

```crystal
'a'.to_s
# => "a"

'4'.to_i
# => 4

'a'.to_i
# => Error: Invalid integer: a (ArgumentError)
```

## 이스케이프

문자열과 마찬가지로, 직접 쓸 수 없는 문자들이 있어요. 이런 문자를 쓰려면 이스케이프해야 해요.
`\` 문자를 사용해서 이스케이프 시퀀스를 쓰고, 그 뒤에 이스케이프하려는 문자를 붙이면 돼요.

다음은 Crystal의 특수 문자예요:

| 값       | 설명                          |
| -------- | ----------------------------- |
| `\a`     | 경고음                        |
| `\b`     | 백스페이스                    |
| `\e`     | 이스케이프                    |
| `\f`     | 폼 피드                       |
| `\n`     | 줄 바꿈 또는 뉴라인           |
| `\r`     | 캐리지 리턴                   |
| `\t`     | 가로 탭                       |
| `\v`     | 세로 탭                       |
| `\\`     | 백슬래시                      |
| `\'`     | 작은따옴표                    |
| `\"`     | 큰따옴표                      |
| `\377`   | 8진수 ASCII 문자              |
| `\xFF`   | 16진수 ASCII 문자             |
| `\uFFFF` | 16진수 유니코드 문자          |
