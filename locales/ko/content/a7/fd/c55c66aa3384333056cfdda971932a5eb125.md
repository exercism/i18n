# 힌트

## 일반

- [`combinators`][combinators]에 있는 `case`는 같은 값을 매칭할 때 알맞은 도구이고, `cond`는 가드가 있는 조건을 판단할 때 알맞은 도구예요.
- 기호(`yes`, `no`, `maybe`, `korean`, …)는 연습 문제 파일의 `SYMBOLS:`에서 이미 선언되어 있어요.

## 1. 요리 평가하기

- `korean`과 `turkish`를 각각의 승인 값에 매핑하는, 두 절로 이루어진 `case`예요.

## 2. 영화 장르 평가하기

- `romance`를 매칭하고 나머지는 `[ drop no ]` 기본값으로 처리해요. 기본 분기는 원래 값이 스택 맨 위에 그대로 남아 있다는 걸 기억해요. 결과를 푸시하기 전에 drop 해요.

## 3. 산책 평가하기

- `cond`(역시 `combinators`에 있어요)를 사용해요. 각 가드는 `[ dup N > ]`예요. 본문에서는 승인 값을 푸시하기 전에 킬로미터를 `drop`해야 해요.

## 4. 활동 평가하기

- 활동은 `{ tag value }`예요. `first2`로 둘 다 스택에 푸시한 다음, `swap`으로 태그가 맨 위에 오게 해요. 그게 바로 `case`가 매칭하는 대상이에요.
- `board-game`과 `chill` 분기는 (`f`) 값이 스택에 남아 있는 상태를 봐요. 승인 값을 푸시하기 전에 `drop`해요.
- `movie`, `restaurant`, `walk` 분기는 해당 값이 스택에 남아 있는 상태를 봐요. 그래서 2번, 1번, 3번 과제에서 만든 워드를 바로 호출할 수 있어요.
