# 표현

[representer][representer]는 다음과 같은 정규화를 적용해요:

- 모든 주석과 문서를 제거해요
- 모듈과 함수의 import를 정렬해요
- `mix format`으로 코드 서식을 정리해요
- 식별자를 자리 표시자 값으로 정규화해요
- 맵과 구조체의 키를 정렬해요
