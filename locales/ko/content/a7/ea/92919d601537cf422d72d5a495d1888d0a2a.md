# 지침

이 연습 문제에서는 로그 라인을 처리해요.

각 로그 라인은 다음과 같은 형식의 문자열이에요: `"[<LEVEL>]: <MESSAGE>"`.

로그 레벨은 세 가지가 있어요:

- `INFO`
- `WARNING`
- `ERROR`

세 가지 작업이 있는데, 각 작업은 로그 라인 하나를 받아서 그걸로 무언가를 해보라고 해요.

## 1. 로그 라인에서 메시지 가져오기

`message` 함수를 구현해서 로그 라인의 메시지를 반환하게 해요:

```fsharp
message "[ERROR]: Invalid operation"
// => "Invalid operation"
```

앞뒤의 공백은 제거해야 해요:

```fsharp
message "[WARNING]:  Disk almost full\r\n"
// => "Disk almost full"
```

## 2. 로그 라인에서 로그 레벨 가져오기

`logLevel` 함수를 구현해서 로그 라인의 로그 레벨을 반환하게 해요. 로그 레벨은 소문자로 반환해야 해요:

```fsharp
logLevel "[ERROR]: Invalid operation"
// => "error"
```

## 3. 로그 라인 다시 포맷하기

로그 라인의 형식을 다시 만드는 `reformat` 함수를 구현해요. 메시지를 먼저 쓰고 그 뒤 괄호 안에 로그 레벨을 넣어요:

```fsharp
reformat "[INFO]: Operation completed"
// => "Operation completed (info)"
```
