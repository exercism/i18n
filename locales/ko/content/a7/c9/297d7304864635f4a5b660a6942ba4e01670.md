# 타입 변환 소개

Go에서는 서로 다른 타입 사이의 변환을 명시적으로 해줘야 해요.
타입을 변환하는 것(흔히 **타입 캐스팅**이라고도 해요)은 변환하려는 타입의 이름을 가진 함수를 통해 이루어져요.
예를 들어 `int`를 `float64`로 변환하려면 다음과 같이 하면 돼요:

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
```

## 기본 타입과 문자열 사이의 변환

기본 타입(예: `int`)과 `string` 사이를 변환하기 위한 `strconv` 패키지가 있어요.

```go
import "strconv"

var intString string = "42"
var i, err = strconv.Atoi(intString)

var number int = 12
var s string = strconv.Itoa(number)
```
