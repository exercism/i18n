# 지시 사항

Lisp 외계인 Lucy는 숫자를 좋아해요. 그중 몇몇은 "멋지다"고 생각하기도 하죠.

Lucy는 숫자를 더 멋지게 만드는 함수를 작성하는 걸 도와달라고 해요.

Lucy가 어떤 숫자를 멋지다고 생각하는지는 바뀔 수 있어서, 함수는 유연해야 해요.

## 1. 멋지게 만들기

숫자 배열을 더 멋진 숫자 배열로 만들려면, 숫자에 적용할 함수와 숫자 배열을 받는 `make-magnificent-maybe` 함수를 작성해야 해요.
이 함수는 (주어진 함수에 따라) 더 멋진 숫자들의 배열로 평가되어야 해요.

```lisp
(make-magnificent-maybe #'square '(1 2 3)) ; => (1 4 9)
(make-magnificent-maybe #'1+ '(1 2 3))     ; => (2 3 4)
```

## 2. 최고만 남기기

숫자를 (바라건대) 더 멋지게 만들고 나면, Lucy는 정말 멋진 숫자만 보고 싶어 해요.

1은 *절대* 멋지지 않다는 걸 분명히 알고 있으니, 1은 그냥 제거해야 해요.

그런데 그 외에도 Lucy는 가끔 마음을 바꾸기 때문에, 어떤 숫자가 멋진지 아닌지 알려 주는 함수를 다시 줄 거예요.

함수와 숫자 배열을 받아, 가장 멋진 숫자만 (즉, `1`이 아니고 주어진 함수가 참으로 평가하는 숫자도 아닌 숫자만) 반환하는 `only-the-best` 함수를 작성해야 해요.

```lisp
(only-the-best #'evenp '(1 2 3 4 5)) ; => (3 5)
(only-the-best #'oddp '(1 3 5))    ; => ()
```
