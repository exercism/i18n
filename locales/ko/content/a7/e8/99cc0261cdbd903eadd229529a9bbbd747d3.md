# 소개

## 상속

상속은 객체 지향 프로그래밍(OOP)의 핵심 개념이에요.
상속은 IS-A 관계를 나타내요.
프로그래밍에서도 영어에서와 똑같은 의미로, 부모로부터 기능을 물려받는 것을 말해요(프로그래밍에서 기능은 보통 함수와 변수예요).

아래와 같은 `Animal` 클래스를 생각해봐요.

```java
//Creating an Animal class with bark() as a member function.
public class Animal {

    public void bark() {
        System.out.println("This is an animal");
    }

}
```

`Animal`은 부모 클래스예요. 이 클래스가 가진 속성을 모든 동물에게 일반적으로 확장할 수 있기 때문이에요.

`Lion`이라는 동물이 있고, 다음과 같은 클래스를 가진다고 생각해봐요.

```java
//Lion class is a child class of Animal.
public class Lion extends Animal {

    @Override
    public void bark() {
        System.out.println("Lion here!!");
    }

}
```

~~~~exercism/note
`Override` 애너테이션은 하위 클래스의 메서드가 상위 클래스의 메서드를 재정의한다는 것을 나타낼 때 사용해요.
꼭 필요한 것은 아니지만 사용하는 것이 좋은 관행이에요.
~~~~

이제 다음을 실행하면,

```java
Animal animal = new Lion(); //creating instance of Animal, of type Lion
animal.bark();
```

참고: `Animal` 클래스를 `Lion`으로 초기화하는 거예요.
출력은 다음과 같아요.

```java
Lion here!!
```

객체 지향 프로그래밍에는 여러 가지 상속 유형이 있지만, Java는 그중 일부만 지원해요(다중 레벨과 계층적 상속).
더 자세히 알아보려면 [이 글][java-inheritance]을 읽어봐요.
