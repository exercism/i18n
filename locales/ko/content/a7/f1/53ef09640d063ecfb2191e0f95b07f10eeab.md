# 힌트

## 1. 승인 정의하기

- [커스텀 타입][custom-types] 문서에서 새로운 커스텀 타입을 정의하는 방법을 살펴봐요.

## 4. 활동 정의하기

- [커스텀 타입][custom-types] 문서에서 연관 데이터를 가진 새로운 커스텀 타입을 정의하는 방법을 살펴봐요.

## 5. 활동 평가하기

- 활동의 값을 바탕으로 로직을 실행하는 가장 좋은 방법은 [패턴 매칭][pattern-matching]을 사용하는 거예요.

[custom-types]: https://guide.elm-lang.org/types/custom_types.html
