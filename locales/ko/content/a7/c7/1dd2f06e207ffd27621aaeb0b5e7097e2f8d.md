# 지침 추가

## Roc에서의 은행 계좌

Roc 코드에서는 보통 비즈니스 로직에 집중하고, 동시성과 공유 상태는 플랫폼이 처리해요. 그래서 이 연습 문제에서는 동시성을 걱정할 필요 없이 `BankAccount.roc`에 계좌 연산만 구현하면 돼요. 계좌는 닫힌 상태로 시작하고, 다시 열면 잔액이 초기화되며, 입금과 출금 금액은 양수여야 해요.

## 서버 데모 (선택 사항)

함께 제공되는 `bank-account-demo.roc`는 구현한 코드를 작은 웹 서비스에서 어떻게 활용할 수 있는지 보여줘요. 편집기에서 읽어볼 수는 있지만, 테스트와는 별개이고 풀이의 일부도 아니에요.

데모를 실행하려면 먼저 컴퓨터에 [Roc을 설치](https://www.roc-lang.org/install/)하고 [Exercism CLI](https://exercism.org/cli-walkthrough)를 설치한 다음, 터미널에서 다음 명령을 실행해요:

```sh
exercism download --exercise=bank-account --track=roc
```

그다음 `BankAccount.roc`을 구현하고, 다음 명령으로 테스트해 봐요. CLI가 출력한 다운로드 위치가 아래 경로와 다르면 그에 맞게 바꿔 주세요:

```sh
cd ~/Exercism/roc/bank-account
roc test bank-account-test.roc
```

모든 테스트를 통과하면 다음 명령으로 데모 서버를 시작할 수 있어요:

```sh
roc bank-account-demo.roc
```

이 서버는 [basic-webserver 플랫폼](https://github.com/roc-lang/basic-webserver)과 플랫폼에 내장된 SQLite 지원을 사용해요. Roc은 처음 실행할 때 플랫폼을 내려받아요. 별도의 데이터베이스 서버는 필요하지 않아요. 서버는 `http://127.0.0.1:8000`에서 요청을 기다리고, 현재 디렉터리에 `bank-account-demo.db`를 만들어요. 다른 데이터베이스 파일을 쓰고 싶다면 `DB_PATH`를 설정해요. 서버를 멈추려면 Ctrl-C를 눌러요. 데이터는 서버를 다시 시작해도 그대로 남아 있어요.

다른 터미널에서 `curl`로 이 웹 서비스를 호출할 수 있어요. Windows에서는 PowerShell의 `curl` 별칭을 피하려면 항상 `curl.exe`를 사용해요. 예를 들어 123번 계좌를 열고 50을 입금하고 10을 출금한 뒤 잔액을 확인하는 방법은 다음과 같아요:

```sh
curl -X POST http://127.0.0.1:8000/accounts/123/open
curl -X POST http://127.0.0.1:8000/accounts/123/deposit/50
curl -X POST http://127.0.0.1:8000/accounts/123/withdraw/10
curl http://127.0.0.1:8000/accounts/123/balance
```

잔액은 `40`이에요. 계좌 ID와 금액은 부호 없는 정수여야 해요. 갱신에 성공하면 `OK`를 반환하고, 실패하면 계좌 구현에서 만든 오류를 반환해요. 123번 계좌를 닫으려면 이렇게 해요:

```sh
curl -X POST http://127.0.0.1:8000/accounts/123/close
```

Linux/macOS에서 동시 요청을 시험해 보고 싶다면 새로운 계좌 ID를 쓰고, 클라이언트 여덟 개에서 입금 요청 100건을 보내 봐요:

```sh
curl -X POST http://127.0.0.1:8000/accounts/456/open
seq 100 | xargs -P 8 -I '{}' curl --fail --silent --show-error -X POST http://127.0.0.1:8000/accounts/456/deposit/1
curl http://127.0.0.1:8000/accounts/456/balance
```

Windows에서는 병렬 예제를 실행할 때 [PowerShell 7+](https://learn.microsoft.com/powershell/scripting/install/installing-powershell-on-windows)를 사용해요:

```powershell
curl.exe -X POST http://127.0.0.1:8000/accounts/456/open
1..100 | ForEach-Object -Parallel { curl.exe --fail --silent --show-error -X POST http://127.0.0.1:8000/accounts/456/deposit/1 } -ThrottleLimit 8
curl.exe http://127.0.0.1:8000/accounts/456/balance
```

입금은 모두 성공해야 하고, 잔액은 `100`이어야 해요.

## 데모가 동시성을 처리하는 방법

각 요청은 계좌를 읽고, 작성한 Roc 함수를 호출한 뒤, 그 결과를 SQLite `Immediate` 트랜잭션 안에서 저장해요. 실패한 연산은 계좌를 바꾸지 않은 채 롤백돼요. SQLite는 한 번에 하나의 쓰기만 허용하기 때문에 동시 요청이 서로의 갱신을 덮어쓰지 못해요. 서로 다른 계좌의 경우에도 마찬가지예요.

참고: 이 연습 문제는 `U64`를 사용하지만, 데모는 잔액을 SQLite 정수로 저장하므로 `I64` 최댓값(`9223372036854775807`)을 넘는 갱신은 거부해요.

독립적인 계산을 병렬로 실행하는 예제를 보고 싶다면 [parallel-letter-frequency 연습 문제](https://exercism.org/tracks/roc/exercises/parallel-letter-frequency)를 풀어 봐요.
