# 개요

JavaScript에는 증가 연산자와 감소 연산자가 있어요.
이 둘은 변수를 제자리에서 수정해요.
`++`는 숫자에 1을 더하고, `--`는 숫자에서 1을 빼요.

```javascript
let i = 3;
i++;
// i is now 4

let j = 0;
j--;
// j is now -1
```

위 예시는 후위 증가/감소 연산자를 보여줘요.
이 경우 연산자는 변수 뒤에 놓이고, 식의 반환 값은 증가/감소 _이전_의 변수 값이에요.

```javascript
let a = 3;
let b = a++;
// a = 4
// b = 3
```

연산자가 변수 앞에 놓이는 전위 형태도 있어요.
이때 반환 값은 증가/감소 _이후_의 변수 값이에요.

```javascript
let a = 3;
let b = ++a;
// a = 4
// b = 4
```
