# 리눅스 해커를 위한 설치 (고급 리눅스 사용자 전용)

여기에 가장 좋은 안내를 담으려고 아직 작업 중이에요. 그런데 많은 리눅스 개발자가 무엇을 설치하고 어디에 두어야 하는지에 대해 아주 까다롭게 따진다는 걸 알고 있고, 또 고맙게 생각해요.

_그래도 표준 설치를 따르고 싶다면, 그냥 돌아가서 [일반 설치 안내](https://exercism.io/tracks/pharo-smalltalk/installation)를 따라가요._

다음 안내는 아직 한참 작업 중이고 ArchLinux를 기준으로 하지만, 여러분의 배포판에도 적용될 수 있어요. 적용되지 않는다면 개선 방안을 찾을 수 있게 도와주세요. 어쩌면 Pharo 업스트림에도 요청할 수 있어요. _참고: 이 안내가 안정적으로 동작하는지는 아직 확실하지 않아요. 그래서 개선에 도움을 주시면 감사하겠어요._

- 원하는 위치에 Pharo VM을 설치해요. AUR이나 그에 준하는 곳에 pharo 7이 올라와 있다면 그걸 써도 되고, 아니면 다음에서 내려받아요: [https://files.pharo.org/vm/pharo-spur64/linux/] (그리고 stable-timer VM을 골라요)
- 다음으로 Pharo.image 파일을 풀어서 Exercism 디렉터리에 넣어야 해요. 이 파일은 [https://files.pharo.org/image/70/] 에서 받을 수 있고, 가장 최근 64비트 zip 파일을 고르면 돼요.
- 이제 VM과 Image가 제대로 동작하는지 확인하려고 간단한 명령줄 테스트를 해봐요: `pharo Pharo.image eval "100 factorial"`. 문제가 없다면 답이 나올 거예요.
- 이제 OSX 섹션에 설명된 "load script"를 해봐요. `libgit2`를 언급하는 오류가 날 수도 있는데, 그렇다면 `libgit2`도 설치하고 다시 해봐요. `libcurl-gnutls`를 설치하면 도움이 된다는 얘기도 있어요 (아직 확인되진 않았어요).
- 일부 libgit2 오류의 경우, 개발 중인 pharo에서 백포트할 수도 있는 내부 loadModule 변경이 있다는 보고도 있었어요. 이 경우에는 `LGitLibrary` 클래스의 `unixModuleName` 메서드를 다음과 같이 바꿔야 해요:
  1. `pharo-ui Pharo.image`를 입력해 headfull Pharo를 실행해요
  1. Ctrl-Space를 눌러 `unixModuleName`을 입력해요
  1. `LGitLibrary >> unixModuleName` 항목을 선택하고 엔터를 눌러요
  1. 열린 브라우저에서 `unixModuleName`의 메서드 소스를 다음으로 바꾸고(복사해서 붙여 넣어요), 저장(ctrl-s)한 다음, 마지막으로 저장하고 pharo를 종료해요.
```
LGitLibrary >> unixModuleName
	| pluginDir |
	pluginDir := Smalltalk vm binary parent.
	#('libgit2.so' 'libgit2.so.0')
		detect: [ :each | (pluginDir / each) exists ] 
		ifFound: [ :libName | ^ (pluginDir / libName) fullName ].

	self error: 'Module not found.' 
 ```

이제 앞서 말한 OSX exercism "load script"를 다시 해봐요. 모든 게 제대로 동작한다면 화면을 가로질러 로딩 진행 막대가 깜빡이고, 곧 System Browser 창이 나타날 거예요. 그렇지 않다면 Pharo Discord에 들러주세요 (위에서 안내한 대로요).

이제 돌아가서 나머지 [시작하기 안내](https://exercism.io/tracks/pharo-smalltalk/installation)를 따라가면 돼요.
