# 비트 알아보기

이진 숫자는 결국 CPU나 RAM의 트랜지스터, 그리고 각 트랜지스터가 "켜짐"인지 "꺼짐"인지에 그대로 대응해요.

흔히 "비트 조작"이라고 부르는 저수준 조작은 시스템 언어에서 특히 중요해요.

Kotlin 같은 상위 레벨 언어는 보통 이런 세부 사항 대부분을 추상화해요. 하지만 기본적인 범위의 비트 단위 연산은 [사용할 수 있어요][ref-bitwise].

~~~~exercism/note
사람이 읽을 수 있는 이진 출력을 보려면, 아래 예제 거의 모두를 [`Integer.toBinaryString()`][web-binstring] 함수로 감싸거나 `toString(radix = 2)`로 변환해야 해요.
 
이건 시각적으로 산만해서, 이 함수가 나오는 부분은 대부분 지웠고, 결과는 `0b` 표기법으로 나타냈어요.

## 비트 시프트 연산

`Int`나 `Long` 타입은 부호가 있든 없든 1과 0으로 이루어진 문자열로 표현할 수 있고, 비트의 나열로 다룰 수 있어요.

의외일 수도 있는데, `Byte`나 `Short` 타입은 Kotlin의 대부분의 비트 연산과 호환되지 않아요. 아래 예제는 모두 32비트 정수(`Int` 또는 `UInt`)를 사용해요.

```kotlin
val ns = 0b111  // 7 decimal
Integer.toBinaryString(ns)  // => "111"
```

비트 시프트는 모든 비트를 지정한 수만큼 왼쪽이나 오른쪽으로 옮겨요. 한쪽 끝에서 비트가 빠져나가고, 다른 쪽 끝은 0이나 1로 채워져요.

- `shl`로 하는 왼쪽 시프트: 0으로 채워요.
- `shr`나 `ushr`로 하는 오른쪽 시프트: 양수에서는 0으로 채워요(음수는 뒤의 절에서 살펴봐요).

```kotlin
val ns = 0b111  // 7 decimal
ns shl 1  // => 0b1110, decimal 14
ns shr 1  // => 0b11, decimal 3
ns ushr 1  // => 0b11

val nu: UInt = 0b111u  // 7 unsigned
nu shr 1  //  => 0b11
```

왼쪽 시프트는 할 때마다 값을 두 배로 만들고, 오른쪽 시프트는 값을 절반으로 만들어요(잘림이 있을 수 있어요). 이는 십진수 표현에서 더 분명하게 드러나요:

```kotlin
3 shl 2  // => 12
24 shr 3 // => 3
```

이런 비트 시프트는 "제대로 된" 산술 연산보다 훨씬 빨라서, 저수준 코딩에서 아주 인기 있는 기법이에요.

### 음의 정수 시프트

_음의 정수_에서는 조금 더 조심해야 해요.

음수 값은 [2의 보수][wiki-2complement] 형태로 저장되는데, 이는 가장 왼쪽 비트가 1이라는 뜻이에요. 왼쪽 시프트는 문제가 없지만, 오른쪽으로 시프트할 때 가장 왼쪽 비트는 어떻게 채울까요?

```kotlin
val ns = -0b111  // => 0b11111111111111111111111111111001

// shift left: simple
ns shl 1  // => 0b11111111111111111111111111110010, decimal -14

// shift right: preserves sign bit
ns shr 1  // => 0b11111111111111111111111111111100, decimal -4

// unsigned shift right: left-pads with zeros
ns ushr 1 // => 0b01111111111111111111111111111100, decimal 2147483644
```

[`shr`][ref-shr] 연산자는 [산술 시프트][wiki-arithmetic]를 수행해서 부호 비트를 보존해요.

[`ushr`][ref-ushr] 연산자는 [논리 시프트][wiki-logical]를 수행해서, 마치 부호 없는 수인 것처럼 0으로 채워요.

## 비트 논리 연산

[불리언 개념][concept-booleans]에서 `&&`(and), `||`(or), `!`(not) 연산자가 불리언 값과 함께 쓰인다는 걸 살펴봤어요.

두 정수의 비트를 비교하는 `and`, `or`, `xor`([배타적 논리합][wiki-xor]) 연산자와, 모든 비트를 뒤집는 `inv`(반전) 함수도 있어요.

```kotlin
0b1011 and 0b0010 //  bit is 1 in both numbers
// => 0b0010

0b1011 or 0b0010 // bit is 1 in at least one number
// => 0b1011

0b1011 xor 0b0010 // bit is 1 in exactly one number, not both
// => 0b1001

0b1011.inv() // flip all bits (in a 32-bit signed Int)
// => 0b11111111111111111111111111110100
```
