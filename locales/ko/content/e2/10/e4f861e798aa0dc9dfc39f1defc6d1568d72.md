# 소개

[구조체][structs-and-classes](흔히 *struct*라고 불러요)는 Swift 프로그램을 이루는 주요 구성 요소 중 하나예요.
구조체를 사용하면 서로 관련된 속성(데이터)과 메서드(동작)를 하나로 묶은 사용자 정의 타입을 만들 수 있어요.
실제로 `Int`, `Double`, `Bool`, `String`, `Array`, `Dictionary`를 비롯한 Swift의 표준 타입은 모두 구조체로 구현되어 있어요.

## 구조체 정의하기

`struct` 키워드 뒤에 타입 이름을 쓰고, 중괄호 안에 정의를 넣어 구조체를 정의해요.
Swift 관례에 따라 구조체 이름은 `UpperCamelCase`를 사용해요.

```swift
struct CharacterStats {
    var health = 0.0
    var speed = 0
    var strength = 0
}
```

## 인스턴스 만들기

구조체 정의는 설계도예요.
구조체의 *인스턴스*를 만들려면 타입 이름 뒤에 괄호를 붙여 이니셜라이저를 호출해요.

```swift
var someStats = CharacterStats()
```

이렇게 하면 정의에 있는 기본 속성 값으로 채워진 인스턴스가 만들어져요.

Swift는 구조체를 위해 **멤버별 이니셜라이저**도 자동으로 만들어 주는데, 이를 이용하면 속성을 이름으로 지정해 초기화할 수 있어요.

```swift
let customStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

## 속성에 접근하고 수정하기

*점 표기법*을 사용해 인스턴스의 속성에 접근하고 수정해요.

```swift
var stats = CharacterStats()

print(stats.health) // Prints 0.0

stats.health = 87.3
print(stats.health) // Prints 87.3
```

구조체는 값 타입이기 때문에 인스턴스의 속성을 수정하려면 인스턴스 자체가 `var`로 선언되어 있어야 해요.
인스턴스가 `let`으로 선언되면 모든 속성을 변경할 수 없어요.
