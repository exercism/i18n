# 지침 추가

## 워드

`real`과 `imaginary` 슬롯을 가진 `cmplx` 튜플을 정의해요. 슬롯 접근자인 `real>>`과 `imaginary>>`는 튜플을 정의하면 자동으로 생기고, 테스트가 구성 요소를 읽을 때 사용해요.

- `<cmplx> ( real imag -- cmplx )`는 복소수를 만들어요.
- `>cmplx ( pair -- cmplx )`는 `{ real imaginary }`로 `cmplx`를 만들어요.
- `cmplx>pair ( cmplx -- pair )`는 `{ real imaginary }`를 반환해요.
- `c+ ( a b -- c )`, `c- ( a b -- c )`, `c* ( a b -- c )`, `c/ ( a b -- c )`는 두 복소수에 대한 산술 연산이에요.
- `c-abs ( a -- |a| )`는 절댓값(실수)을 구해요.
- `c-conj ( a -- a* )`는 켤레복소수를 구해요.
- `c-exp ( z -- e^z )`는 복소 지수 함수예요.

Factor의 `MATH:` 제네릭(`+`, `-`, `*`, `/`)은 내장된 수학 계층에서만 디스패치돼요. 그래서 이 연습 문제에서는 그 제네릭에 메서드를 정의하는 대신 전용 워드 이름을 사용해요. 실수와 복소수를 섞은 산술에 대한 테스트는 제외되어 있어요. 여기 있는 모든 연산은 두 `cmplx` 값 사이에서 이루어져요.
