# 이벤트 수집

## 스토리

이 스토리에는 이벤트를 수집해야 하는 프로그램이 하나 있는데, 메시지가 세 가지 서로 다른 날짜 형식을 사용하고 있어요.

- `"01/01/1970"`
- `"January 1, 1970"`
- `"Thursday, January 1, 1970"`

할 일은 각 형식을 매칭하고 캡처하는 정규식을 작성하는 거예요.

다루는 내용은 다음과 같아요.

- 리터럴 문자 매칭
- 수량자
- 선택
- 문자 클래스
- 앵커

## 작업

- 작은 구성 요소를 매칭하는 패턴 만들기
- 앞의 내용을 바탕으로 작은 구성 요소를 캡처하는 패턴 만들기
- 앞의 내용을 바탕으로 주어진 날짜 형식에서 캡처하는 패턴 만들기
- 앞의 내용을 바탕으로 해당 날짜 형식만 매칭하고 캡처하는 정규식 만들기
