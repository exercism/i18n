# 힌트

## 일반

- Go의 슬라이스는 0부터 시작해요.
  슬라이스의 첫 번째 인덱스는 `0`이에요.
- 내장 [`append`][append-builtin] 함수는 [`variadic`][variadic-gobyexample] 함수예요.
- 점 세 개 표기법을 사용하면 한 슬라이스의 원소를 다른 슬라이스에 이어 붙일 수 있어요:

```go
a := []int{1, 3}
b := []int{4, 2, 6}
c := append(a, b...)
fmt.Println(c)
// Output: [1 3 4 2 6]
```

## 1. 특정 카드로 슬라이스 만들기

- 데이터가 미리 채워진 슬라이스를 만들려면 슬라이스 리터럴 표기법 `s := []T{x1, x2, ..., xn}`을 사용해요.

## 2. 스택에서 카드 꺼내기

- 슬라이스의 `n`번째 항목을 가져오려면 [인덱스를 사용][go-slices]해요.
- 슬라이스에 항목이 있는지 확인하려면 조건문을 사용해 인덱스를 [슬라이스의 길이][len-builtin]와 비교해요.

## 3. 스택의 카드 교환하기

- 슬라이스의 `n`번째 항목을 설정하려면 [인덱스를 사용][go-slices]하고 새 값을 할당해요.
- 슬라이스 끝에 새 항목을 추가하려면 `append` 함수를 사용해요.

## 4. 스택 맨 위에 카드 추가하기

- 슬라이스 앞에 항목을 추가하려면 원래 슬라이스의 원소를 `value` 인자 슬라이스에 이어 붙이면 돼요.

## 5. 스택에서 카드 제거하기

- 슬라이스에서 항목을 제거하려면 `index` 뒤의 부분을 index 앞의 부분에 이어 붙이면 돼요.
