# 지침

이 연습 문제에서 여러분은 열렬한 스포츠 팬이고, 방금 NBA 농구에 푹 빠졌어요.
NBA 농구가 처음이라 NBA 역사를 깊이 파고들면서 팀과 코치, 그리고 그들의 전적을 하나하나 정리하고 서로 비교하고 있어요.

아직 좋아하는 팀이 없어서, 특정 팀을 응원할지 판단하는 알고리즘도 만들게 됐어요.
여러분만의 _응원할 팀을 고르는_ 알고리즘을 개발하는 데 도움이 될 일곱 개의 과제가 있어요.

## 1. 모델 정의하기

다음 두 필드를 이 순서대로 가지는 레코드에 대한 `Coach` 타입 별칭을 정의해요.

- `name`: 코치의 이름 (타입: `String`)
- `formerPlayer`: 코치가 이전에 선수였는지 여부 (타입: `Bool`)

다음 두 필드를 이 순서대로 가지는 레코드에 대한 `Stats` 타입 별칭을 정의해요.

- `wins`: 승리 수 (타입: `Int`)
- `losses`: 패배 수 (타입: `Int`)

다음 세 필드를 이 순서대로 가지는 레코드에 대한 `Team` 타입 별칭을 정의해요.

- `name`: 팀의 이름 (타입: `String`)
- `coach`: 팀의 코치 (타입: `Coach`)
- `stats`: 팀의 전적 (타입: `Stats`)

## 2. 팀 만들기

어떤 서드파티 코드와 연동해야 하는데, 그 코드에는 팀이라는 개념이 있지만 매개변수를 다른 순서로 넘겨 호출해요.
다음 시그니처를 가진 `createTeam` 함수를 추가해요: `String -> Stats -> Coach -> Team`.

## 3. 코치 교체하기

NBA 구단주들은 성질이 급해서, 팀 성적이 나쁘면 코치가 자주 교체된다는 걸 알게 됐어요.
새 코치와 팀을 매개변수로 받아서, 새 코치가 들어간 팀을 반환하는 `replaceCoach` 함수를 구현해요.

```elm
let
    coach = { name = "Larry Bird", formerPlayer = True }
    stats = { wins = 58, losses =  24 }
    team = { name = "Indiana Pacers", coach = coach, stats =  stats }
    newCoach = { name = "Isiah Thomas", formerPlayer = True }
in
replaceCoach newCoach team
--> { name = "Indiana Pacers"
--  , coach = { name = "Isiah Thomas", formerPlayer = True }
--  , stats = { wins = 58, losses = 24 } }
```

## 4. 팀을 응원해야 하는지 확인하기

나중에는 팀을 응원할지 말지 결정하는 복잡한 알고리즘을 만들 계획이지만, 첫 시도에서는 승리가 패배보다 많은 팀은 모두 응원하기로 했어요.

이 함수를 다른 상황에서도 재사용하고 싶으니, 타입 시그니처에 확장 가능한 레코드를 사용해서 관련 필드만 있으면 어떤 레코드든 받을 수 있게 해요.
함수를 최대한 간결하게 유지하려면, 패턴 매칭으로 함수 매개변수에서 `stats`를 꺼내면 좋아요.
팀을 받아서 그 팀을 응원해야 하면 `True`를, 그렇지 않으면 `False`를 반환하는 `rootForTeam` 함수를 구현해요.

```elm
let
    spursCoach = { name = "Gregg Popovich", formerPlayer =  False }
    spursStats = { wins = 56, losses = 26 }
    spursTeam = { name = "San Antonio Spurs", coach = spursCoach, stats = spursStats }
in
rootForTeam spursTeam
--> True
```
