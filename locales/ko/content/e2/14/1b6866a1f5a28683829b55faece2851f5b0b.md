# 해설

해시는 Perl의 데이터 타입으로, 문자열 키와 스칼라 값이 짝을 이룬 순서 없는 모음을 담고 있어요.

해시 변수는 보통 배열을 대입해서 채워요. 예를 들어 `my %scores = (Alice => 10, Bob => 15, Charlie => 20);` 처럼요.

배열의 요소는 보통 쉼표로 구분하지만, 배열에서 키와 값을 구분할 때는 흔히 "팻 콤마"라고 부르는 `=>`를 쓰는 걸 자주 보게 돼요. 동작은 쉼표와 거의 같지만, 왼쪽에 있는 요소를 문자열로 해석해 준다는 장점이 있어요.

해시는 개별 키에 값을 대입해서 채울 수도 있어요. 예를 들어 `$scores{Alice} = 10;` 처럼요.

해시의 값은 첨자로 키를 지정해서 가져올 수 있어요. 예를 들어 `$scores{Bob} # 15` 처럼요.

해시의 키는 중복되지 않아요. 같은 키가 여러 번 나오면 마지막으로 준 값만 남아요.

## 함수

해시를 다루는 함수로는 [keys][keys]와 [values][values]가 있어요. 각각 해시의 키와 값을 배열로 가져올 때 써요.

[keys][keys]와 [values][values] 함수가 반환하는 배열은 [grep][grep], [map][map], [sort][sort]처럼 배열을 다루는 함수나 [for][for]문에서 유용하게 쓸 수 있어요.

그 밖의 해시 함수로는 해시에 키가 있는지 확인하는 [exists][exists](값이 `undef`인 경우에도요)와, 해시에서 키를 제거하는 [delete][delete]가 있어요.

## 시길의 차이

해시의 값을 가져올 때는 어떤 시길을 쓰느냐에 따라 결과가 달라져요. 변수 이름 끝에 붙는 `{}` 첨자가 바로 그 이름의 해시에 접근하고 있다는 걸 Perl에 알려주거든요.

```perl
my %names = (Alice => 10, Bob => 15, Charlie => 20);

$names{Alice}; # 10            <- A scalar
@names{Alice}; # (10)          <- A slice (with only one key, this probably isn't what you want. There will be a warning.)
%names{Alice}; # ('Alice', 10) <- A key/index + value slice

$names{'Bob', 'Charlie'}; #                            <- An error (disabled syntax for an ancient feature.)
@names{'Bob', 'Charlie'}; # (15, 20)                   <- A slice
%names{'Bob', 'Charlie'}; # ('Bob', 15, 'Charlie', 20) <- A key/index + value slice
```

허용되긴 하지만, 가독성을 위해서라면 서로 다른 변수 타입이 같은 이름을 공유하지 않는 게 좋아요.
