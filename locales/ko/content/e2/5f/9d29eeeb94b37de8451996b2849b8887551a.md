# 디버깅

테스트를 실행할 때마다 Red 스크립트의 모든 출력이 콘솔에 표시돼요. 원하는 것은 무엇이든 `print`로 출력할 수 있어요. 예를 들어 값에 이름을 붙여서 이렇게요:

```red
print ["x =" x]
```

`probe` 함수도 아주 유용해요. `probe`는 평가될 때 입력을 평가하고, 결과를 타입이 드러나는 방식으로 출력한 다음, 그 값을 반환해요. 그래서 대부분의 경우 "투명"하게 동작하고, 표현식 안에 끼워 넣을 수 있어요:

```red
x: 10
y: probe x + 5
```

가끔은 `type?`라는 함수(네, 이름에 정말 물음표가 들어 있어요!)가 값의 타입을 확인할 때 유용해요:

```red
print ["x type:" type? x]
```

더 고급 디버깅 기법도 [Red 위키에 정리되어 있어요](https://github.com/red/red/wiki/%5BDOC%5D-Debugging).
