# 소개

## 타입 저글링

타입 저글링은 타입 강제 변환이라고도 해요.
타입 저글링은 서로 다른 타입의 두 값이 연산을 수행하기 위해 같은 타입으로 강제 변환되는 것을 말해요.

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15
```

이 변환은 암시적으로 일어날 수도 있고(위 예제를 봐요), `C` 스타일의 타입 캐스팅으로 명시적으로 할 수도 있어요.

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

직접 타입 캐스팅을 할 때 사용할 수 있는 타입은 `bool`, `int`, `float`, `string`, `array`, `object`예요.
가장 흔하게는 정수(`int`)를 실수(`float`)로 바꾸거나 그 반대로 바꿀 때 타입 캐스팅을 사용해요.
