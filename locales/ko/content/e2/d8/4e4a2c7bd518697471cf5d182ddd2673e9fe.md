# 지침 추가

## 출력 형식

각 국적은 한 글자로 표기해요. (`E` = `Englishman`, `J` = `Japanese`, `N` = `Norwegian`, `S` = `Spaniard`, `U` = `Ukrainian`)

## 레지스터

| 레지스터 | 용도     | 타입    | 설명                  |
| -------- | --------- | ------- | ---------------------------- |
| `$v0`    | 출력      | 바이트  | 물을 마시는 사람의 국적 |
| `$v1`    | 출력      | 바이트  | 얼룩말을 키우는 사람의 국적 |
| `$t0-9`  | 임시      | 임의    | 임시 저장용           |
