# 소개

`try..rescue`를 사용하면 오류가 발생했을 때 이를 잡아내는 강력한 구조를 만들 수 있어요. 오류를 잡아내면 함수가 필요한 시점에 정해진 값을 반환할 수 있어요. `try..rescue` 구조는 우리가 활용할 수 있는 두 가지 추가 기능도 제공해요:

- `else` 블록
  - try 블록이 성공하면, 그 결과가 이 블록과 매칭돼요.
- `after` 블록
  - try 블록이 성공하든 예외를 발생시키든, 프로그램이 그 시점에 실행 중이라면 `after` 블록의 코드는 항상 실행돼요.
  - `after` 블록의 결과는 호출한 스코프로 반환되지 않아요.

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```
