## 지침

Mickey와 Minerva를 위한 완벽한 미로를 만들어야 해요. 해답이 하나뿐이고 고립된 구역이 없는 미로 말이죠.
알아 두어야 할 것은 다음과 같아요:

- 미로는 직사각형 모양이고, 시작과 끝 지점에 입구가 있어요.
- 미로에는 방과 통로가 있고, 이들은 직각으로 교차해요.
- 프로그램은 행과 열, 두 개의 매개변수를 받아야 해요. 미로의 크기는 5칸에서 100칸 사이여야 해요.
- 너비가 `x`열이고 높이가 `y`행인 미로는 너비가 `2x + 1`글자, 높이가 `2y + 1`글자여야 해요.
- 시드를 제공하지 않으면 무작위 미로를 만들어요. 같은 시드를 여러 번 제공하면 매번 같은 미로가 나와야 해요.
- 벽을 그릴 때는 [상자 그리기 문자][Box-drawing]를 사용하고, 왼쪽 입구와 오른쪽 출구에는 화살표 기호(⇨)를 사용해요.

이제 모험을 좋아하는 이 생쥐들을 위해 완벽한 미로를 만들 시간이에요!

### 예시

1. 5x5칸(또는 11x11글자) 크기의 작은 정사각형 미로
```text
	┌───────┬─┐
	│       │ │
	│ ┌─┬── │ │
	│ │ │   │ ⇨
	│ │ │ ──┤ │
	⇨ │ │   │ │
	┌─┤ └── │ │
	│ │     │ │
	│ │ ────┘ │
	│         │
	└─────────┘
```
2. 6x18칸 크기의 직사각형 미로
```text
	┌───────────┬─────────┬───────────┬─┐
	│           │         │           │ │
	│ ┌───────┐ │ ┌─┐ ──┐ └───┐ ┌───┐ │ │
	│ │       │ │ │ │   │     │ │   │   ⇨
	│ └─┐ ┌─┐ │ │ │ ├── ├───┐ │ │ ──┼── │
	│   │ │ │   │   │   │   │ │ │   │   │
	└── │ │ ├───┴───┤ ┌─┘ ┌─┘ │ ├── │ ──┤
	⇨   │   │       │ │   │   │ │   │   │
	┌─┬─┴─┐ └─┐ ┌─┐ │ └─┐ │ ┌─┘ │ ──┴─┐ │
	│ │   │   │ │ │ │   │   │   │     │ │
	│ │ │ └── │ │ │ └── │ ──┘ ┌─┘ ──┐ │ │
	│   │       │       │     │     │   │
	└───┴───────┴───────┴─────┴─────┴───┘
```
