# 범위 지정 연산자

범위 지정 연산자(`::`)를 사용하면 클래스를 참조해서 이름 상수, 정적 프로퍼티, 정적 메서드에 접근할 수 있어요.

```php
class MyClass
{
  public const MY_VALUE = 1;
}

// MyClass::class => "MyClass"
// MyClass::MY_VALUE => 1
```

## 범위 지정 연산자와 함께 `self`와 `static` 사용하기

객체가 자신의 스코프를 참조해야 할 때가 있어요. 이를 위해 `self` 키워드를 사용하면 클래스가 자신의 스코프를 참조할 수 있어요. `self` 키워드를 사용하면 클래스를 클래스 이름으로부터 분리할 수 있어요. 덕분에 시간이 지나도 코드를 유지 관리하기가 더 쉬워져요.

```php
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return self::MY_VALUE;
  }
}

// (new MyClass)->getMyValue() => 1
```

범위 지정 연산자와 함께 `static` 키워드를 사용하면 현재 하위 클래스에 대한 참조를 "지연 바인딩"할 수 있어요.

```php
// Update MyClass:
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return static::MY_VALUE;
  }
}
```

## 범위 지정 연산자와 함께 `parent` 사용하기

`parent` 키워드는 부모 클래스의 상수, 프로퍼티, 메서드를 참조할 때 사용해요. 보통 객체가 인스턴스화될 때 부모 생성자를 호출하는 데 사용해요.

```php
class ChildClass extends ParentClass
{
  public function __construct(): void
  {
    parent::__construct();
  }
}
```

## 주의 사항

### 상수, 프로퍼티, 메서드의 가시성

범위 지정 연산자도 `public`, `private`, `protected` 가시성 제어자가 정한 규칙을 그대로 따라요.
