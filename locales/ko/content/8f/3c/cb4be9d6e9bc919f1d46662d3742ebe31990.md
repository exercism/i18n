# 지침

밸런타인데이예요. 파트너에게 몇 가지 활동 아이디어가 있는데, 각각을 `yes`, `no`, `maybe` 중 하나로 평가해 달라고 해요.

활동은 원소 두 개로 이루어진 배열 `{ tag value }`로 나타내요. 여기서 `tag`는 `board-game`, `chill`, `movie`, `restaurant`, `walk` 중 하나예요.

| 활동                       | 형태                        |
| ------------------------- | --------------------------- |
| 보드 게임 하기              | `{ board-game f }`          |
| 느긋하게 쉬기               | `{ chill f }`               |
| `genre` 장르의 영화 보기     | `{ movie genre }`           |
| `cuisine` 음식점에서 식사하기 | `{ restaurant cuisine }`    |
| `km`킬로미터 걷기            | `{ walk km }`               |

장르는 `crime`, `horror`, `romance`, `thriller` 중 하나예요. 음식 종류는 `korean` 또는 `turkish`예요.

## 1. 음식 종류 평가하기

`rate-restaurant`를 정의해서 스택에서 음식 종류를 하나 꺼내고, 그에 대한 평가를 반환해요.

- `korean` → `yes`
- `turkish` → `maybe`

```factor
korean rate-restaurant .   ! => yes
turkish rate-restaurant .  ! => maybe
```

## 2. 영화 장르 평가하기

`rate-movie`를 정의해서 장르를 받고 다음을 반환해요.

- `romance` → `yes`
- 그 외 → `no`

```factor
romance rate-movie .   ! => yes
horror rate-movie .    ! => no
```

## 3. 걷기 평가하기

`rate-walk`를 정의해서 걸은 킬로미터 수를 받고 다음을 반환해요.

- `11` 초과 → `yes`
- `6` 초과 `11` 이하 → `maybe`
- 그 외 → `no`

```factor
12 rate-walk .   ! => yes
8 rate-walk .    ! => maybe
3 rate-walk .    ! => no
```

## 4. 활동 평가하기

`rate-activity`를 정의해서 스택에서 `{ tag value }` 형태의 활동을 꺼내고, 그에 대한 평가를 반환해요. 위에서 만든 헬퍼 함수를 재사용해요.

- `board-game`, `chill` → 항상 `no`
- `movie` → `rate-movie`에 맡겨요
- `restaurant` → `rate-restaurant`에 맡겨요
- `walk` → `rate-walk`에 맡겨요

```factor
{ restaurant turkish } rate-activity .   ! => maybe
{ movie horror } rate-activity .         ! => no
{ walk 12 } rate-activity .              ! => yes
{ board-game f } rate-activity .         ! => no
```

## 5. 승인 집계하기

`approval-counts`를 정의해서 활동 목록을 받고, 각 활동이 어떻게 평가되었는지 개수를 세어 원소 세 개로 이루어진 배열 `{ yes-count maybe-count no-count }`로 반환해요.

```factor
{ { restaurant korean } { restaurant turkish } { walk 3 } { movie romance } }
approval-counts .
! => { 2 1 1 }
```
