# 데이터베이스 직원 등록

## 문제 설명

ABC Corp은 직원들에게 지급한 모든 소액 현금 결제 정보를 데이터베이스에서 관리하려고 해요. ABC Corp의 재무 부서가 이 작업을 구현하는 일을 돕고 있어요. ABC Corp이 사업을 확장하면서, 신규 채용으로 인해 시스템에 새 직원을 추가하는 일이 자주 생겨요.

해야 할 일은 제공된 신규 직원 정보를 데이터베이스의 `Employee` 테이블에 추가하고, 자동 생성된 `employee_id` 컬럼의 값을 찾기 위해 데이터베이스에 별도의 쿼리를 보내지 않고도 그 값을 반환하는 것이에요. 실행 중 오류가 발생하면 `-1`을 반환해야 해요.

## 데이터베이스 정보

이 문제에서는 제공된 H2 데이터베이스를 사용해요.

> 샘플 데이터베이스 파일은 `gofigure.mv.db`이고, 데이터베이스 이름은 `gofigure`예요. `db` 폴더 안에 들어 있어요.

다음 테이블들은 샘플 데이터와 함께 샘플 H2 데이터베이스에 이미 들어 있어요. 컬럼 이름과 데이터 타입은 아래와 같아요.

**테이블 이름** : `Employee`

| **컬럼:**      | 타입 |
| -----------       | ----------- |
| `employee_id`     | 정수, 자동 증가 기본 키       |
| `name`            | 문자열        |
| `city`            | 문자열        |
| `department`      | 문자열        |
| `age`             | 정수        |

**테이블 이름**: `Payment`

| **컬럼:**      | 타입 |
| -----------       | ----------- |
| `payment_id`      | 정수, 자동 증가 기본 키       |
| `date`            | 날짜        |
| `amount`          | 실수        |
| `employee_id`     | 정수        |
| `reason`          | 문자열        |

* 데이터베이스 파일은 `gofigure.mv.db`예요. JDBC URL은 `jdbc:h2:file:/path/to/db/file` 형식으로 사용해요.
* 사용자 이름: `root`
* 비밀번호: `root`

## 제약 사항

* 쿼리와 Ballerina 샘플을 검증하려면 `db` 폴더에 제공된 H2 데이터베이스 파일을 사용해요
* Ballerina.toml에 H2 데이터베이스 드라이버를 플랫폼 의존성으로 추가하려면 maven dependency params 방식을 사용해요
* 자동 생성된 id를 찾기 위해 데이터베이스에 별도의 쿼리를 보내지 마세요


## 테스트 환경

* `bal test`로 테스트를 실행할 수 있고, 주어진 샘플 DB에 대해 테스트가 실행돼요.

## 예제

### 예제 1

**입력** : dbFilePath: `"./db/gofigure"`, name : `“John Doe”`, city: `“Omaha”`, department : `“Sales”`, age: `24`

**출력** : `4`

### 예제 2

**입력** : dbFilePath: `"./db/invalidDB"`, name : `“John"`, city: `"Colombo"`, department : `"HR"`, age: `25`

**출력** : `-1`

## 힌트

* 데이터베이스 작업에는 [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc) 모듈을 사용해요
* JDBC 드라이버를 의존성으로 추가하는 방법은 [사전 요구 사항](https://lib.ballerina.io/ballerinax/java.jdbc/latest) 섹션을 참고해요
* 데이터를 삽입하려면 [execute](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-execute) 원격 메서드를 사용해요
* [DML과 DDL 작업](https://ballerina.io/learn/by-example/mysql-execute-operation/) 예제를 참고해요
