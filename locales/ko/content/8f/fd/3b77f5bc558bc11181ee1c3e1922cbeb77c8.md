# 소개

다른 많은 언어에서 그렇듯이, Ruby에서도 예외는 예상치 못한 상황에 대처하는 방법을 제공해요. 프로그램이 중단되지 않도록 하려면 예외를 제대로 처리하는 것이 중요해요.

예외가 발생하면, 직접 발생시킨 것이든 Ruby 인터프리터가 발생시킨 것이든, 프로그램은 정상적인 실행을 멈추고 결국 오류 메시지와 함께 종료돼요.

```ruby
raise ArgumentError.new("Something went wrong!")
=> Traceback (most recent call last):
.
.
ArgumentError (Something went wrong!)
```

```ruby
1/0
=> Traceback (most recent call last):
.
.
ZeroDivisionError (divided by 0)
```

이렇게 종료되는 과정을 막고 싶다면 예외에 반응해야 해요. 이것을 예외를 "구조한다"고 해요.

```ruby
begin
  # ...any code that raises an exception
rescue
  puts 'Got an exception'
end
```

이 프로그램은 중단되지 않고 "Got an exception"을 출력해요. 종료하는 대신 Ruby는 rescue 블록의 코드를 실행하고, 그 코드가 메시지를 출력해요.

Ruby의 모든 것과 마찬가지로 예외도 객체이고, 보통 예외에 대한 데이터를 담고 있어요. 다음은 예외 객체를 얻는 방법이에요.

```ruby
begin
  # ...any code that raises an exception
rescue => e
  puts "Exception class: #{ e.class.name }"
  puts "Exception Message:#{e.message}"
end
```

Ruby에서는 직접 예외를 발생시킬 수도 있어요. 예를 들면 이렇게요.

```ruby
begin
  raise ArgumentError.new("Invalid argument")
rescue ArgumentError => e
  puts e.message
end
```

앞에서 본 예외는 Ruby에 내장된 예외 중 하나지만, 직접 사용자 정의 예외를 정의하고 발생시킬 수도 있어요.

```ruby
class CustomError < StandardError
end

raise CustomError.new("Something went wrong")
```
