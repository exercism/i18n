# 설치

다른 많은 언어와 달리, Pyret은 언어를 전역으로 설치할 필요가 없어요.
대신 Pyret 개발자들은 컴파일러를 [npm 패키지][pyret-npm]로 사용할 수 있게 만들어 두었어요.
연습 문제마다 `npm`을 사용해 Pyret을 설치하게 되며, 자세한 내용은 [테스트][tests] 페이지에서 확인할 수 있어요.

JavaScript 런타임 환경인 Node.js를 설치해야 해요.
[Node.js 다운로드][download] 페이지에서 패키지 관리자로 `npm`을 선택해야 해요.

~~~~exercism/note
현재 pyret-npm 패키지는 Linux와 MacOS에서만 호환돼요.
Windows 사용자는 WSL이나 가상 머신을 사용해 pyret-npm을 설치해야 해요.
~~~~

[pyret-npm]: https://www.npmjs.com/package/pyret-npm
[tests]: ./tests
