# 안내 추가

## 테스트

테스트는 몇몇 연산을 동시에 실행해요.
Account에 수행하는 연산은 계좌를 일관된 상태로 유지해야 해요.
예를 들어, 여러 고루틴이 동시에 입금하고 출금할 수 있는데, 두 번의 출금이 동시에 일어나더라도 잔액이 음수가 되어서는 안 돼요.

로컬에서 작업할 때 코드가 동시성을 제대로 처리하고 데이터 레이스를 일으키지 않는지 확인하려면 `-race` 플래그를 켜고 테스트를 실행해요.

```bash
cd exercism/project/directory/go/bank-account
go test -race
```
