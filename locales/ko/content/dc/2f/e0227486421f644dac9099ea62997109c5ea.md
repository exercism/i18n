# 소개

JSON은 **배열**을 다음과 같이 정의해요:

> 배열은 값들을 순서대로 모은 것이에요.
> 배열은 `[` 왼쪽 대괄호로 시작하고 `]` 오른쪽 대괄호로 끝나요.
> 값들은 `,` 쉼표로 구분해요.

배열에는 _어떤 종류_의 JSON 값이든 0개 이상 담을 수 있어요.
배열의 원소가 모두 같은 타입일 필요는 없어요.

## 배열 만들기

대괄호를 사용해 원소들을 배열로 모을 수 있어요.

```jq
[1, 2, 3]
```

_스트림_의 원소들은 대괄호로 감싸서 배열로 담을 수 있어요.

```jq
range(5)     # => a stream of 5 numbers
[range(5)]   # => the array [0, 1, 2, 3, 4]
```

## 크기

`length` 함수는 배열의 원소 개수를 반환해요.

## 인덱싱과 슬라이싱

배열의 인덱스는 0부터 시작해요.

대괄호 표현식으로 배열에서 원소를 가져올 수 있어요:
`.[2]`는 세 번째 원소를 가져와요.

음수 인덱스는 배열의 끝에서부터 거꾸로 세요:
`.[-1]`은 마지막 원소를 가져오고, `.[-2]`는 뒤에서 두 번째예요.

**슬라이스**는 배열의 일부 구간이에요.
`.[10:15]`는 인덱스 10부터 시작해 원소 5개를 반환해요. 끝 인덱스는 _포함되지 않아요_.

몇 가지 편리한 함수도 있어요:

- `first`는 첫 번째 원소를 가져와요.
- `last`는 마지막 원소를 가져와요.
- `nth(n)`은 인덱스 `n`에 있는 원소를 가져와요.

## 반복하기

`jq`는 자주 쓰이는 반복 기능을 위해 다양한 함수를 제공해요:

- `map(expr)`은 `expr`을 각 원소에 차례로 적용한 새로운 배열을 반환해요.

  ```jq
  [1, 2, 3] | map(. * 10)    # => [10, 20, 30]

  ```

- `select(expr)`는 `expr`을 _단일 값_에 적용하는 함수예요.
  표현식의 결과가 참이면 그 값을 반환하고,
  거짓이면 _아무것도_ 반환하지 않아요. `null`이 아니라 정말로 아무것도요.

  이것을 배열에 적용하려면 `map`과 함께 사용해요.

  ```jq
  [range(10)] | map(select(. % 2 == 0))    # => [0, 2, 4, 6, 8]
  ```

  또는 `select`를 _스트림_에 적용하고 그 결과를 모을 수도 있어요.

  ```jq
  [range(10) | select(. % 2 == 0)]    # => [0, 2, 4, 6, 8]
  ```

- `any(condition)`와 `all(condition)`은 배열의 원소 중 조건을 통과하는 것이 있는지, 또는 모두 통과하는지를 불리언 값으로 반환해요.

  ```jq
  [1, 2, 3, 4] | any(. > 4)    # false
  [1, 2, 3, 4] | any(. >= 4)   # true

  [1, 2, 3, 4] | all(. >= 4)   # false
  [1, 2, 3, 4] | all(. <= 4)   # true
  ```
