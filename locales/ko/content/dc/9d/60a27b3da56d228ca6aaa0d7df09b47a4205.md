# 개요

함수가 많은 인자를 받을 때는 어떤 순서로 전달해야 하는지 기억하기 어려울 때가 있어요. 읽기 쉽도록 Gleam에서는 인자에 레이블을 붙일 수 있어요.

인자에 레이블을 붙이려면 인자 이름 앞에 레이블 이름을 적고, 둘을 공백으로 구분해요.

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

레이블이 있는 인자를 가진 함수를 호출할 때는 인자를 어떤 순서로든 전달할 수 있어요. 다음 `replace` 호출은 모두 같은 의미예요.

```gleam
replace(in: "🍔🍔🍔" each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

레이블은 언제나 선택 사항이에요. 함수에 레이블이 있는 인자가 있더라도 레이블 없이 호출할 수 있어요.

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```

레이블이 있는 인자를 가진 함수를 정의할 때는 첫 번째 레이블 인자 뒤에 오는 모든 인자에도 레이블을 붙여야 해요.

```gleam
// This function is valid
pub fn valid(
  x: Int,
  label1 y: Int,
  label2 z: Int
) -> Int {
  // ...
}

// This function is invalid
pub invalid(
  x: Int,
  label1 y: Int,
  z: Int
) -> Int {
  // ...
}
```
