## 2. 임의의 이터레이터에서 짝수 항목을 반환하는 이터레이터 어댑터 `evens`를 작성해요

- 제안된 메서드들을 그냥 이어 붙이기만 하면 다 잘 풀릴 거예요.
- 숫자 `n`은 `n % 2 == 0`이면 짝수예요.
- 클로저는 문법을 줄여 놓은 함수예요. 인자 이름은 `|` 기호 두 개 사이에 넣고, 그 뒤에 표현식이 와요. 일반 함수와 달리 각 인자의 타입을 항상 명시할 필요는 없고 이름만 적으면 돼요. 예를 들어, 홀수의 제곱으로 이루어진 이터레이터는 이렇게 만들 수 있어요: `(0..).map(|n| 2 * n + 1).map(|n| n * n)`.
