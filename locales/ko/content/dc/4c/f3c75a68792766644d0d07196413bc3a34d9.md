# 소개

위키백과에서는 `switch` 문을 "변수나 식의 값이 프로그램의 제어 흐름을 바꿀 수 있도록 하는 선택 제어 메커니즘의 한 종류"라고 설명해요.

이 메커니즘에는 `switch`, `case`, `break`, `default`라는 키워드가 쓰여요.

가장 단순한 형태에서는 기본형이나 문자열 식을 검사하고, 그 값을 바탕으로 결정을 내려요. 예를 들어 볼까요:

```csharp
string direction = GetDirection();
switch (direction)
{
    case "left":
        GoLeft();
        break;
    case "right":
        GoRight();
        break;
    default:
        MarkTime();
        break;
}
```

가장 정교한 형태에서는 다운캐스팅(`case <Type> <variable>:`)과 가드(`when`)를 도입해요.

```csharp
Animal animal = GetAnimal();

switch (animal)
{
    case Dog canine:
    case Coyote canine:
        canine.Bark();
        break;
    case Cat cat when cat.HasOnly8Lives():
        cat.IsCareful();
        cat.Meow();
        break;
    case Cat cat:
        cat.Meow();
        break;
}
```
