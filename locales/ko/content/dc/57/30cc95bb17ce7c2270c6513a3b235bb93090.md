# 소개

## 제네릭 형식

컬렉션 정의에는 보통 꺾쇠괄호 안에 자리 표시자가 들어가며, 관례상 흔히 `T`를 사용해요. 이런 컬렉션을 제네릭 형식이라고 해요. 이렇게 하면 컬렉션 사용자가 컬렉션에 어떤 형식의 항목을 저장할지 지정할 수 있어요. 아래 예제 코드에서는 문자열 배열을 인스턴스화하고 있어요.

## 배열

C#의 배열은 기본 값이나 구조체 또는 클래스의 인스턴스를 모아 놓은 컬렉션이에요. 이들은 기본 클래스 라이브러리에서 `List<T>`로 구현되어 있어요. 여기서 `T`는 배열에 들어 있는 항목의 형식이에요. API는 배열을 만들고 조작하기 위한 다양한 메서드를 제공해요.

항목은 배열에 추가하거나 배열에서 제거할 수 있어요. 필요에 따라 크기가 커지거나 작아져요.

```csharp
var listOfStrings = new List<string>();
```
