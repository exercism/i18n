# 자세히 알아보기

[`switch`문][switch]을 사용하면 하나의 값을 여러 값과 비교할 수 있어요.
여러 개의 `else-if`문을 사용하는 것보다 더 간결하게 코드를 작성할 수 있죠.
`switch`문은 `switch` 키워드로 시작하고, 그 뒤에 비교할 값이 와요.
그다음 `case` 키워드로 각 경우를 정의하는데, `case` 뒤에는 비교 대상이 되는 값을 적어요.
어떤 경우에도 해당하지 않으면 `default` 키워드로 기본 경우를 정의해요.
`else-if`문과 마찬가지로 `switch`문은 처음 일치하는 경우의 코드 블록만 실행해요.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

다음 예시를 살펴봐요:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

이 코드는 다음과 같이 쓸 수도 있어요:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## 바인딩과 `where`문

`switch`문에서 비교하는 값은 이름에 바인딩할 수 있고, 그 이름은 해당 경우의 본문에서 사용할 수 있어요.
이 이름들은 `where` 절에서도 쓸 수 있는데, `where` 절은 해당 경우가 일치하려면 `true`로 평가되어야 하는 추가 불리언 표현식이에요.

```swift
let x = 1337
switch sumOfDivisors(of: x) {
case let total where total == x:
  print(total, "is a perfect number")
default:
  print(x, "is not a perfect number")
}
```
