# 소개

## 숫자

Lua는 숫자를 두 가지 방식으로 표현해요: 64비트 정수와 배정밀도 부동소수점 수예요. 일반적인 산술 연산자를 지원하는데, 덧셈, 뺄셈, 곱셈, 나눗셈, 부호 반전이 여기에 속해요. 그 밖에도 내림 나눗셈, 나머지 연산, 거듭제곱을 지원해요.

| 연산자 | 예시                |
| ------ | ------------------- |
| `+`    | `1 + 2 --> 3`       |
| `-`    | `2 - 1 --> 1`       |
| `*`    | `2 * 2 --> 4`       |
| `/`    | `4 / 2 --> 2.0`     |
| `//`   | `11 // 3 --> 3`     |
| `%`    | `11 % 3 --> 2`      |
| `^`    | `10 ^ 2 --> 100.0`  |
| `-`    | `-(2 * 2) --> -4`   |
