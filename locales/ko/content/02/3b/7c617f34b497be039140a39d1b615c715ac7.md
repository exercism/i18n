# 소개

[TypeScript](https://www.typescriptlang.org/)(TS)는 JavaScript(JS)의 상위 집합이에요. Microsoft에서 JS로 대규모 애플리케이션을 개발하면서 겪은 어려움에 대한 해답으로 만들어졌죠. 규모가 큰 JS 프로젝트에서는 내가 만든 객체에 어떤 속성이 있는지, 내 함수가 어떤 인자를 받는지(그리고 그 인자가 어떤 타입이어야 하는지)를 파악하기가 어려워질 수 있어요. 마찬가지로 JS 코드를 똑똑하게 분석할 방법이 없기 때문에, `npm` 같은 패키지를 가져다 쓸 때는 어떤 메서드를 쓸 수 있고 어떤 인자를 넘겨야 하는지 알려면 문서를 계속 최신으로 유지해야 했어요. TS는 이런 문제를 해결해 줘요. 현재 Github에서 호스팅되는 오픈 소스 프로젝트예요. 모든 브라우저는 물론 Node를 위한 도구도 지원하고, 어떤 호스트에서든, 어떤 OS에서든 쓸 수 있어요. TS는 읽기 쉽고 표준을 따르는 JavaScript로 컴파일돼요.

TS는 JS에 유연한 타입 시스템을 더해 주고, 인터페이스(사용자 정의 타입)와 클래스 같은 일부 ECMAScript 기능의 문법도 바꿔 줘요. 타입은 선택 사항이고 유연해요. 예를 들어 어떤 인자가 문자열 또는 숫자라고 지정할 수 있죠. 타입 덕분에 대부분의 코드 편집기에서 제공하는 도구를 활용할 수 있어요. 코드 자동 완성과 메서드 감지 같은 기능이 내 코드에도, 내가 사용하는 패키지에도 적용되어 개발 경험이 좋아지죠. 앞으로 다가올 많은 ECMAScript 기능(예: async/await)도 지원해요. TS는 객체 지향 스타일로도, 함수형 스타일로도 작성할 수 있어요. 기존의 모든 JS 패키지와 호환돼요. TS는 깔끔하고 읽기 쉬운 JS로 트랜스파일돼요.

[플레이그라운드](https://www.typescriptlang.org/play)에서 직접 해보고, [TypeScript 블로그](https://devblogs.microsoft.com/typescript/)와 [트위터 계정](https://twitter.com/typescript)을 통해 최신 소식을 받아봐요.
