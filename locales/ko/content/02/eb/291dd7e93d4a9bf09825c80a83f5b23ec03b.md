# 윤년의 개념

저는 첫 번째 예시 풀이를 더 선호해요. 간결함이 제가 지금까지 본 Rust의 관용적인 스타일을 따르기 때문이에요. 또 정규 풀이에서 추가된 클로저 개념을 피할 수 있어요.

## 추출된 개념

### 일반

- 불리언 논리
  - 불리언
- 표현식
  - Rust 함수는 표현식을 암묵적으로 반환해요
- 산술
  - 나머지 연산

### 타입

- 부호 없는 정수 - `u64`
- 불리언 - `bool`

## 예시 연습 문제 1

["desi-belokonska"](https://exercism.org/tracks/rust/exercises/leap/solutions/01d024321b6a491690321844aedf8b09)의 풀이

```rust
pub fn is_leap_year(year: u64) -> bool {
  year % 400 == 0 || year % 4 == 0 && year % 100 != 0
}
```

## 예시 연습 문제 2

[정규 풀이](https://github.com/exercism/rust/blob/master/exercises/leap/example.rs)

```rust
pub fn is_leap_year(year: u64) -> bool {
    let has_factor = |n| year % n == 0;
    has_factor(4) && (!has_factor(100) || has_factor(400))
}
```
