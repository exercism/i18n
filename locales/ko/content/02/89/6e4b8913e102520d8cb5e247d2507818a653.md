# 힌트

## 1. 모든 객차를 담은 벡터 만들기

- `Vector`에 `push!`를 하는 고전적인 for/while 루프도 작동해요.
- 또는 [`collect()`][collect] 함수를 쓰면 더 간결할 수 있어요.
- 벡터 생성자 안에서 스플래팅을 사용하는 방법도 있어요:

```julia-repl
julia> input = (1, 5, 9)
(1, 5, 9)

julia> [input...]
3-element Vector{Int64}:
 1
 5
 9
```

## 2. 객차 벡터 고치기

- 앞쪽 객차들과 기관차를 나머지에서 분리해 두면, 올바른 순서로 다시 조립할 수 있어요.
- 스플래팅을 사용한 다중 할당이 도움이 될 수 있어요 (소개를 참고해요).

## 3. 빠진 정차역 추가하기

- 이 함수는 입력을 변경하지 않는다는 걸 잊지 마세요! 새로운 `Dict`를 만들어요.
- 정차역 번호는 필요 없고 이름만 필요하므로, 각 쌍을 분리해야 해요.
- 이름 벡터를 만드는 방법은 여러 가지가 있어요:
  -  `Vector`에 `push!()`를 사용하는 for/while 루프
  -  배열 [컴프리헨션][comprehensions]
  -  벡터에 함수를 [`map()`][map]하기
  -  [익명][anonymous] 함수의 [브로드캐스팅][broadcasting]도 가능해요:

 ```julia-repl
julia> (x -> x^4).([1, 2, 3]) == [1, 16, 81]
true
 ```

## 4. 경로 정보 확장하기

- 슬러핑한 뒤에 `more_route_information`은 `Pairs()` 컬렉션이에요.
- [`merge()`][merge] 함수는 두 개 이상의 `Dict`를 합치지만, `Pairs()` 컬렉션도 받아들여요.
  `Pairs()` 컬렉션을 `Dict`로 명시적으로 변환할 수도 있지만, 그럴 필요는 없어요.
