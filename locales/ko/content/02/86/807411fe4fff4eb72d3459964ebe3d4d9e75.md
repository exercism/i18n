# 소개

`while`문을 사용하면 특정 조건이 만족되는 동안 코드를 반복해서 실행할 수 있어요.
`while` 키워드 뒤에 소괄호로 감싼 조건을 쓰고, 중괄호로 감싼 루프의 _본문_을 담은 코드 블록을 이어서 써요.

```javascript
while (condition) {
  // code that is executed repeatedly as long as the condition is true
}
```

JavaScript에는 `do-while`문도 있어요.
여기서는 루프 본문을 실행한 뒤에 조건을 확인해요.
조건이 본문에 있는 코드의 결과에 따라 달라질 때 유용해요.

```javascript
do {
  // The code here will always be executed once and then
  // repeatedly while the condition is true.
} while (condition);
```

루프 본문 안에서 `break` 키워드를 사용하면 루프 실행을 완전히 멈출 수 있어요.
이와 달리 `continue` 키워드는 현재 반복의 실행만 멈추고 다음 반복으로 넘어가요.
`continue`를 사용하면 루프 본문의 많은 부분을 `if`문으로 감싸지 않아도 되는 경우가 많아요.

```javascript
let i = 0;

while (i < 100) {
  i = i + 2;

  if (i % 3 === 0) {
    continue;
  }

  // The code here will only be executed when i was not divisible
  // by 3 in the check above.
}
```
