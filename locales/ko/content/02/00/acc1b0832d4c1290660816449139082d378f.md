# 소개

Elixir에서 튜플은 데이터를 정리하는 자료 구조예요. 어떤 타입의 항목이든 정해진 개수만큼 담을 수 있지만, 각 원소에 이름이 따로 붙지는 않아요. 튜플은 원소를 읽는 접근이 상수 시간 연산이기 때문에, 메모리 읽기가 많은 연산에 자주 쓰여요. 반면 원소를 동적으로 추가하거나 제거해야 할 때는 보통 쓰지 않아요. 기존 튜플을 수정하는 대신 새 튜플을 만들어야 하고, 그러려면 메모리를 미리 할당해야 하기 때문이에요.

실제로 Elixir에서 튜플은 중괄호를 사용해 만들어요. 튜플의 원소는 `elem/2` 함수를 사용해 0부터 시작하는 인덱스로 각각 접근할 수 있어요.

```elixir
empty_tuple = {}
one_element_tuple = {1}
multiple_element_tuple = {1, :a, "hello"}

elem(multiple_element_tuple, 2)
# => "hello"
```

## 정보를 묶는 튜플

튜플은 실제로 여러 정보를 묶어 나타낼 때 자주 사용해요.

```elixir
Float.ratio(0.25)
# => {1, 4} indicating the numerator and denominator of the fraction ¼
```
