# 데이터베이스 결제 배치

## 문제 설명

`Payment` 테이블에 결제 데이터 배치를 삽입해야 해요. 이 과제에서는 주어진 입력 JSON 파일에서 결제 데이터를 읽고, JDBC Client의 `batchExecute` 연산을 사용해 결제 데이터를 `Payment` 테이블에 삽입해야 해요. 예제 입력 파일은 `payments.json`으로 주어져요.

입력 JSON 파일의 내용은 다음 JSON 스키마를 기반으로 해요.

```json
{
  "type": "array",
  "items": [
    {
      "type": "object",
      "properties": {
        "employee_id": {
          "type": "integer"
        },
        "amount": {
          "type": "number"
        },
        "reason": {
          "type": "string"
        },
        "date": {
          "type": "string"
        }
      },
      "required": [
        "employee_id",
        "amount",
        "reason",
        "date"
      ]
    }
  ]
}

```

데이터베이스에 추가 쿼리를 실행하지 않고도, 배치로 삽입된 결제 데이터의 자동 생성된 결제 ID를 출력으로 반환해야 해요.

`payments.json` 파일에 주어진 `employee_id`는 유효하며 이미 `Employee` 테이블에 들어 있다고 가정해도 돼요.

## 데이터베이스 세부 정보

이 문제에서는 제공된 H2 데이터베이스를 사용해요.

> 예제 데이터베이스 파일은 `gofigure.mv.db`이고, 데이터베이스 이름은 `gofigure`예요. `db` 폴더 안에 들어 있어요.

다음 테이블들은 예제 데이터와 함께 샘플 H2 데이터베이스에 이미 들어 있어요. 컬럼 이름과 데이터 타입은 다음과 같아요.

**테이블 이름** : `Employee`

| **컬럼:**      | 타입 |
| -----------       | ----------- |
| `employee_id`     | 정수, 자동 증가 기본 키       |
| `name`            | 문자열        |
| `city`            | 문자열        |
| `department`      | 문자열        |
| `age`             | 정수       |

**테이블 이름**: `Payment`

| **컬럼:**      | 타입 |
| -----------       | ----------- |
| `payment_id`      | 정수, 자동 증가 기본 키       |
| `date`            | 날짜        |
| `amount`          | 실수        |
| `employee_id`     | 정수        |
| `reason`          | 문자열        |

* 데이터베이스 파일은 `gofigure.mv.db`예요. JDBC URL은 `jdbc:h2:file:/path/to/db/file`로 사용해요.
* 사용자 이름: `root`
* 비밀번호: `root`

## 제약 사항

* 쿼리와 Ballerina 예제를 검증하려면 `db` 폴더에 제공된 H2 데이터베이스 파일을 사용해요
* Ballerina.toml에 H2 데이터베이스 드라이버를 플랫폼 의존성으로 추가하려면 maven dependency params 방식을 사용해요
* 데이터베이스에 추가 쿼리를 실행하지 않고 자동 생성된 결제 ID를 찾아야 해요.

## 테스트 환경

* `bal test`로 테스트를 실행할 수 있고, 주어진 예제 DB에 대해 테스트가 실행돼요.

## 예제

### 예제 1

**입력:** dbFilePath: `"/path/to/file/gofigure"`, paymentFilePath: `"/path/to/file/payments.json"`

예제 `payments.json` 파일 데이터:

```json
[{
        "employee_id": 4,
        "amount": 12500.50,
        "reason": "Fuel for the month January",
        "date": "2022-02-03"
    },
    {
        "employee_id": 1,
        "amount": 10500.50,
        "reason": "Medical Expenses for the month January",
        "date": "2022-02-04"
    },
    {
        "employee_id": 4,
        "amount": 500.50,
        "reason": "Fuel for the month February",
        "date": "2022-03-03"
    }
]

```

**출력:** `[1,2,3]`

## 힌트

* 데이터베이스를 다루려면 [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc) 모듈을 사용해요
* JDBC 드라이버를 의존성으로 추가하는 방법은 [사전 요구 사항](https://lib.ballerina.io/ballerinax/java.jdbc/latest) 섹션을 참고해요
* JSON 입력 파일을 읽으려면 [io:fileReadJson](https://lib.ballerina.io/ballerina/io/latest/functions#fileReadJson)을 사용해요
* 타입에 안전한 방식으로 데이터를 다루려면 JSON 값을 애플리케이션에 맞는 타입으로 변환해요. [사용자 정의 타입으로 변환하기](https://ballerina.io/learn/by-example/convert-from-json-to-user-defined-type/) 예제를 참고해요
* 데이터베이스를 다루려면 [sql:ParameterizedQuery](https://lib.ballerina.io/ballerina/sql/latest#ParameterizedQuery)와 [batchExecute](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-batchExecute) remote 메서드를 사용해요
* [배치 실행](https://ballerina.io/learn/by-example/mysql-batch-execute-operation/) 예제를 참고해요
