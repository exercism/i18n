# 소개

Python에서 제너레이터는 [제너레이터 이터레이터][generator-iterator]라고 부르는 특별한 종류의 [이터레이터][iterator]를 반환하는 _호출 가능한 함수_ 또는 표현식이에요.
`Generator-iterators`는 [지연 평가][lazy iterator] 방식으로 동작해요. `values`를 메모리에 저장하지 않고, 필요할 때 값을 _생성_해요.

제너레이터 함수는 다른 함수와 똑같이 생겼지만, 하나 이상의 [yield 표현식][yield expression]을 포함해요.
각 `yield`는 코드 실행을 일시 중단하고, 현재 실행 상태(_지역 변수와 try 문을 모두 포함한_)를 저장해요.
제너레이터 함수가 실행을 재개하면, 중단됐던 지점의 상태를 그대로 이어받아요. 반면 일반 함수는 호출할 때마다 초기화돼요.

[iterator]: https://docs.python.org/3.11/glossary.html#term-iterator
[yield expression]: https://docs.python.org/3.11/reference/expressions.html#yield-expressions
