# 소개

Unison은 정적 타입을 사용하는 함수형 프로그래밍 언어로, 프로그래머가 코드와 상호작용하는 방식을 바꾸는 것을 목표로 해요. 그리고 무엇보다 재미있죠.

Unison은 달라요. 💖

많은 프로그래밍 언어와 달리, Unison 코드베이스는 변경 가능한 텍스트 파일 모음으로 저장되지 않아요. 대신 *각 Unison 정의는 자신의 구문 트리 해시로 식별돼요.* 다시 말해, Unison 코드는 콘텐츠 주소 지정 방식이에요.

이 변화는 광범위한 영향을 미쳐요. 분산 프로그래밍을 단순하게 만들고, 빌드와 의존성 충돌을 없애며, 구조적인 리팩터링을 지원하고, 코드를 다룰 때 더 나은 도구를 쓸 수 있게 해줘요.

[Unison 프로그래밍 언어의 핵심 아이디어](https://www.unison-lang.org/learn/the-big-idea/)에 대해 더 읽어보거나, [간단한 언어 투어](https://www.unison-lang.org/learn/tour/)를 살펴보면서 자세한 내용을 확인해요.
