# 소개

C++에서 불리언은 `bool` 타입으로 표현해요.
`bool`은 `true` 또는 `false` 중 하나예요.

## 논리 연산자

C++는 `!`(NOT), `&&`(AND), `||`(OR) 세 가지 불리언 연산자를 지원해요.
`not`, `and`, `or`라는 대체 표현을 써도 돼요.

```cpp
true || false // => true
true && false // => false
!true // => false
not false // => true
```

## 우선순위

세 가지 불리언 연산자는 각각 _연산자 우선순위_가 달라요.
그래서 `!`, `&&`, `||` 순서로 평가돼요.
다른 순서로 평가하고 싶다면 불리언 표현식을 괄호(즉, `()`)로 감싸면 돼요. 괄호는 연산자 우선순위가 더 높기 때문이에요.

```cpp
!true && false   // => false
!(true and false) // => true
```

## 변환

숫자가 필요한 자리에 `true`나 `false`를 쓰면 각각 `1`과 `0`으로 변환돼요.
불리언 연산에 숫자를 쓰면 `0`을 제외한 모든 값이 `true`로 취급돼요. 음수도 마찬가지예요.

```cpp
!true && 0.0   // => false
true + true + false // => 2
```
