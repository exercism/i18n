# 소개

## 사용자 정의 타입

사용자 정의 타입은 Gleam에서 새로운 데이터 타입을 정의하는 방법이에요. 여러 개의 _변형_을 가질 수 있고, 각 변형에는 고유한 이름이 붙어요.

```gleam
pub type Season {
  Spring
  Summer
  Autumn
  Winter
}
```

사용자 정의 타입의 각 케이스는 선택적으로 데이터를 담을 수 있고, 케이스마다 담을 수 있는 데이터의 타입이 달라도 돼요. 변형이 데이터를 담고 있는 경우를 _레코드_라고 해요.

```gleam
pub type Number {
  SomeInt(Int)
  SomeFloat(Float)
  Invalid
}
```

특정 케이스의 값은 추가 데이터가 없으면 이름을 그대로 써서 만들고 (`Spring`), 데이터가 있으면 함수처럼 호출해서 만들어요 (`SomeInt(2)`).

```gleam
let spring = Spring
let integerTwo = SomeInt(2)
```

사용자 정의 타입은 Gleam의 모든 값과 마찬가지로 _구조적 동등성_을 가져요. 즉, 변형이 같고 데이터도 같은 두 값은 서로 같아요.

```gleam
Spring == Spring // -> True
Spring == Autumn // -> False
SomeInt(2) == SomeInt(2) // -> True
SomeInt(2) == SomeFloat(2.0) // -> False
```

사용자 정의 타입의 변형은 `case` 식으로 패턴 매칭할 수 있어요.

```gleam
import gleam/int
import gleam/float

pub fn describe(flexible_number: Number) -> String {
  case flexible_number {
    SomeFloat(f) -> "Float: " <> float.to_string(f)
    SomeInt(i) -> "Int: " <> int.to_string(i)
    Invalid -> "Neither a float nor an int"
  }
}
```
