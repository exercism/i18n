# 소개

[`Basics`][basics] 개념에서는 함수를 정의하는 두 가지 방법을 소개했어요.

가장 일반적인 방법은 여러 줄로 작성하는 형태예요:

```julia
function muladd(x, y, z)
    x * y + z
end
```

짧은 정의에는 "할당" 또는 "한 줄" 형태를 써요:
```julia
muladd(x, y, z) = x * y + z
```

세 번째로, 더 짧은 형태에서는 한 번만 쓰는 짧은 함수를 이름 없이 만들 수 있어요:

```julia-repl
julia> map(x -> 2x, 1:3)
4-element Vector{Int64}:
 2
 4
 6

julia> map((x, y) -> x * y, 1:3, 4:6)
3-element Vector{Int64}:
  4
 10
 18
```

이때 `x -> 2x`는 "익명 함수"예요.
다른 언어에서 "람다 함수"라고 부르는 것과 같아요.

인자가 여러 개일 때는 `(x, y) -> x * y`처럼 괄호가 필요하다는 점에 주의해요.

익명 함수는 Julia 코드에서 흔히 볼 수 있어요. 특히 `map()`이나 `filter()` 같은 고차 함수와 함께 쓸 때 자주 쓰여요.

## 함수 인자

지금까지는 인자의 개수가 정해져 있고, 함수를 호출할 때 그 인자를 모두 올바른 순서로 넘겨야 하는 함수만 살펴봤어요.
그렇게만 하면 제약도 많고 불편하겠죠. 그래서 다른 방법들도 여러 가지 있어요.

### 선택적 인자

많은 언어와 마찬가지로, Julia에서는 함수를 정의할 때 인자마다 기본값을 지정할 수 있어요.

그러면 함수를 호출할 때 그 인자에 값을 넘겨도 되고, 생략해서 기본값을 쓰게 해도 돼요.

```julia-repl
julia> f(x, y=10) = x * y
f (generic function with 2 methods)

julia> f(2, 3)
6

julia> f(2)
20
```

기본값이 _없는_ 인자는 기본값이 _있는_ 인자보다 앞에 와야 해요. 그래서 `f(x=2, y)`는 잘못된 정의예요.

### 키워드 인자

지금까지 나온 예제는 모두 `positional arguments`를 사용해요. 이 방식에서는 함수를 호출할 때 넘긴 값의 순서가 함수 정의에 있는 해당 인자의 순서와 일치해야 해요.

많은 언어와 마찬가지로 Julia도 `keyword arguments`를 지원해요.
함수를 호출할 때 인자 이름을 반드시 지정해야 하지만, 키워드 인자는 여러 개를 순서와 상관없이 지정할 수 있어요.

Julia의 독특한 점은 함수 정의에서 키워드 인자(있는 경우) 앞에 세미콜론 `;`을 붙여 위치 인자와 구분해야 한다는 거예요.
함수를 호출할 때는 마지막 위치 인자와 첫 번째 키워드 인자 사이에 `;`나 `,` 중 아무거나 써도 돼요.

```julia-repl
julia> b(x; y) = x + y
b (generic function with 1 method)

julia> b(2, y=3)
5

# keyword is required when calling
julia> b(2, 3)
ERROR: MethodError: no method matching b(::Int64, ::Int64)
The function `b` exists, but no method is defined for this combination of argument types.
```

기본값은 위치 인자와 똑같이 선택적으로 지정할 수 있어요.

매개변수와 이름이 같은 변수를 미리 계산해 둔 경우, 함수를 호출할 때 `myarg=myarg` 같은 문법을 쓰게 되는 일이 흔해요.
이럴 때는 축약 문법을 쓸 수 있어요:

```julia-repl
julia> width = 4.0
4.0

julia> height = √ width
2.0

julia> area(; width, height) = width * height
area (generic function with 1 method)

# repetition
julia> area(; width=width, height=height)
8.0

# shorthand form
julia> area(; width, height)
8.0
```

### Splat과 slurp

혹시 궁금했을지 몰라서 말해 두면, 이 둘은 Julia 문법의 유용한 기능을 가리키는 표준 이름이에요.
둘 다 `...` 연산자를 가리켜요.

#### Splat

Splat은 함수를 _호출할_ 때 컬렉션을 펼쳐서 함수가 요구하는 개별 값으로 만들어 주는 데 써요.

말로 설명하는 것보다 예로 보여 주는 편이 더 쉬울 거예요:

```julia-repl
julia> fxyz(x, y, z) = x * y * z
fxyz (generic function with 1 method)

julia> xyz = [2, 3, 4]
3-element Vector{Int64}:
 2
 3
 4

# Using the vector directly in a function call is invalid
julia> fxyz(xyz)
ERROR: MethodError: no method matching fxyz(::Vector{Int64})
The function `fxyz` exists, but no method is defined for this combination of argument types.

# splatting converts the vector to 3 numbers, used as positional arguments
julia> fxyz(xyz...)
24
```

"함수 호출" 가운데는 문법 설탕에 가려져 있는 것도 있어서, splat을 눈에 잘 띄지 않는 방식으로 쓸 수도 있어요.

예를 들어 다중 할당은 내부적으로 튜플 생성자 함수를 사용해요:

```julia-repl
julia> first, rest... = [1, 2, 3, 4]
4-element Vector{Int64}:
 1
 2
 3
 4

julia> first
1

julia> rest
3-element Vector{Int64}:
 2
 3
 4
```

키워드 인자도 splat으로 넘길 수 있는데, 보통 `named tuple`을 써요.
`Dict`를 써도 되지만, 키는 심볼이어야 해요(문자열은 안 돼요).

```julia-repl
# function with 3 keyword arguments
julia> fabc(; a, b, c) = a + b + c
fabc (generic function with 1 method)

# named tuple
julia> abc_nt = (a=2, b=3, c=4)
(a = 2, b = 3, c = 4)

# there are no positional arguments, so need to use ; before kw argument
julia> fabc(;abc_nt...)
9

# Dict
julia> abc_dict = Dict(:a=>2, :b=>3, :c=>4)
Dict{Symbol, Int64} with 3 entries:
  :a => 2
  :b => 3
  :c => 4

julia> fabc(;abc_dict...)
9
```

#### Slurp

Slurp은 함수를 _정의할_ 때 개별 값을 원하는 만큼 하나의 컬렉션으로 묶는 데 써요.

```julia-repl
julia> f_more(i, j, more...) = i + j + sum(more)
f_more (generic function with 1 method)

julia> f_more(1, 3, 5, 7, 9, 11)
36
```

slurp하는 인자의 이름(여기서는 `more`)은 아무래도 상관없어요.
이 변수의 타입은 컴파일러가 정하지만, 위치 인자라면 보통 `tuple`이나 그와 비슷한 타입이에요.

키워드 인자도 slurp할 수 있고, 그러면 `Dict`(또는 비슷한 것)가 돼요.

```julia-repl
julia> f_kwslurp(x, y; switches...) = :mult in keys(switches) ? x * y : x + y
f_kwslurp (generic function with 1 method)

julia> f_kwslurp(5, 6; mult=true)
30

julia> f_kwslurp(5, 6)
11
```

호출할 때는 어떤 키워드 인자든 쓸 수 있어요.
어떤 키워드에 반응하고 어떤 키워드를 무시할지는 함수 정의가 정해요.
