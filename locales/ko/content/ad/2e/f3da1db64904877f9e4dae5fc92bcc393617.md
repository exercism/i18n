# 소개

## 수학 함수

제곱근, 각도, 성장 곡선은 `+`, `-`, `*`, `/`만으로는 계산하기 어려워요. `math.functions` 어휘에는 이런 계산을 대신 해 주는 워드들이 들어 있고, `math.constants`에는 π가 있어요. 다른 모든 워드와 마찬가지로, 각 워드는 스택에서 입력을 가져가고 답은 스택에 남겨 둬요.

## 제곱근

```
sqrt ( x -- y )
```

```factor
USING: kernel math math.constants math.functions math.libm prettyprint ;

9 sqrt .     ! => 3.0
2 sqrt .     ! => 1.4142135623730951
```

길이 5미터인 사다리를 벽에서 3미터 떨어진 곳에 세우면, 벽을 따라 4미터 높이까지 닿아요:

```factor
5 sq 3 sq - sqrt .   ! => 4.0
```

## 파이

`pi`(`math.constants`에 있어요)는 원의 지름이 원둘레를 따라 몇 번 들어가는지를 나타내는 수인 π를 스택에 넣어요:

```factor
: wheel-edge ( diameter -- edge ) pi * ;

2 wheel-edge .   ! => 6.283185307179586
```

## 각도는 라디안으로

```
sin ( x -- y )
cos ( x -- y )
tan ( x -- y )
```

`sin`, `cos`, `tan`은 각도를 받지만, 도 단위가 아니에요. 이들은 **라디안**을 쓰는데, 라디안에서는 반 바퀴가 180이 아니라 π예요. 도 단위 값을 그대로 넘겨도 오류가 나지는 않아요. 다만 조용히 틀린 답을 내놓을 뿐이죠.

`deg>rad`는 도를 라디안으로 바꾸고, `rad>deg`는 반대로 되돌려요. π를 곱하고 180으로 나누는 것, 또는 그 반대와 같아요:

```
deg>rad ( x -- y )
rad>deg ( x -- y )
```

```factor
30 deg>rad .       ! => 0.5235987755982988
30 pi * 180 / .    ! => 0.5235987755982988
pi rad>deg .       ! => 180.0
```

`sin`을 호출하기 전에 도를 라디안으로 바꿔요:

```factor
: ramp-rise ( length degrees -- rise ) deg>rad sin * ;

10 30 ramp-rise .   ! => 4.999999999999999
```

길이 10미터인 경사로가 30도로 놓여 있으면 5미터 올라가요. 수학 함수는 정확한 값이 아니라 가장 가까운 실수를 돌려주기 때문에 답이 `4.999999999999999`로 출력돼요. 변환을 빼먹으면 `30 sin`은 30을 라디안(거의 다섯 바퀴)으로 해석해서, 경사로가 `-9.88`미터 “올라가는” 결과가 나와요.

## 각도 구하기

`fatan2`는 반대 방향으로 동작해요. 얼마나 위로 갔는지와 얼마나 옆으로 갔는지를 주면 각도를 라디안으로 알려줘요. `math.libm`에 들어 있어요. 스택에는 *위로* 간 거리를 먼저 넣고, 그다음 *옆으로* 간 거리를 넣어요:

```
fatan2 ( y x -- radians )
```

```factor
1.0 1.0 fatan2 .              ! => 0.7853981633974483
1.0 1.0 fatan2 rad>deg .      ! => 45.0
-1.0 -1.0 fatan2 rad>deg .    ! => -135.0
0.0 -1.0 fatan2 rad>deg .     ! => 180.0
```

각도는 양의 *옆* 방향을 기준으로 재요. `fatan2`는 두 거리의 부호를 모두 살펴보기 때문에 −180도에서 180도 사이 어디든 답할 수 있어요.

## 10의 거듭제곱: 10^와 log10

`10^`는 10을 거듭제곱해요:

```factor
5 10^ .     ! => 100000
2 10^ .     ! => 100
0.5 10^ .   ! => 3.1622776601683795
```

`log10`은 반대로 되돌아가요. “10을 몇 제곱하면 이 수가 될까?”라는 질문에 답하는 거예요. 그 답이 바로 그 수의 **로그**예요:

```factor
100000 log10 .   ! => 5.0
100 log10 .      ! => 2.0
1 log10 .        ! => 0.0
0.001 log10 .    ! => -3.0
```

## e^와 log

`e^`와 `log`도 같은 짝인데, 10 대신 *e*(약 2.718)를 써요. `e^`는 *e*를 거듭제곱하고, `log`는 “*e*를 몇 제곱하면 이 수가 될까?”에 답해요.

```
e^  ( x -- y )
log ( x -- y )
```

수학자들은 매 단계마다 같은 비율로 커지거나 작아지는 것에는 *e*를 써요. 이자를 버는 돈이 한 예이고, 식어 가는 차 한 잔도 또 다른 예예요:

```factor
! 80 degrees hotter than the room, the gap shrinking by 5% a minute
: tea-gap ( minutes -- gap ) -0.05 * e^ 80 * ;

0 tea-gap .    ! => 80.0
10 tea-gap .   ! => 48.52245277701067
```

`log`는 `e^`를 되돌려요. 그러면 반대 방향의 질문에 답할 수 있어요. 온도 차가 40도까지 줄어드는 데 몇 분이 걸릴까요?

```factor
80 40 / log 0.05 / .   ! => 13.862943611198904
```
