# 소개

각 값이 자신의 인덱스에 따라 결정되는 `n`개의 값으로 이루어진 시퀀스가 필요할 때, Factor는 `<iota>`(정수 `0, 1, …, n-1`로 이루어진 가상 시퀀스)와 `map`을 제공해요:

```factor
USING: math sequences ;

5 <iota> [ 2 * ] map .   ! => { 0 2 4 6 8 }
```

`<iota>`는 정수 `0, 1, …, n-1`로 이루어진 가상 시퀀스예요. `map`은 그 값들을 순서대로 훑으면서 각각에 쿼테이션을 적용해요.

각 위치의 결과가 문자 코드라면, `>string`이 그 결과를 문자열로 바꿔줘요. 이는 인덱스에 따라 내린 결정으로 문자들을 한 줄로 이어 붙이는 자연스러운 방법이에요:

```factor
USING: strings ;

5 <iota> [ CHAR: a + ] map >string .   ! => "abcde"
```

[strings]: https://docs.factorcode.org/content/article-strings.html
