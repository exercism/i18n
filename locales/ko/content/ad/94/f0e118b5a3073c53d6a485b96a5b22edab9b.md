# 안내 추가

## 정수의 최댓값

[Vim 문서][number]에 따르면:

> 64비트 숫자를 사용한다고 가정하면(v:numbersize 참고) 부호 없는 숫자는 0x7fffffffffffffff 또는 9223372036854775807로 잘려요.

다시 말해, Vim script는 `2^63` 이상의 수를 정수로 표현할 수 없어요.

이 연습 문제의 일부 테스트는 64비트 정수를 필요로 하는데, 이는 Vim script의 정수 크기 제한을 넘어서요.
이런 제한 때문에 계산 결과는 답을 Integer로 표현하는 대신, 정수 값을 나타내는 문자열과 비교해 테스트해요.
언어가 직접 허용하는 범위보다 큰 수를 피해서 풀 수 있을까요?
