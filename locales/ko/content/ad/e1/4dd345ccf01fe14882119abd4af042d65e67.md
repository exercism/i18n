# 테스트 실행하기

사용하는 운영체제를 선택해요:

- [Windows](#windows)
- [macOS](#macos)
- [Linux](#linux)

## Windows

1. Command Prompt을 열어요.
2. 첫 번째 연습 문제를 가져와요:

   ```batchfile
   C:\Users\JohnDoe>exercism download --exercise hello-world --track java
   ```

3. exercism 폴더로 이동해요:

   ```batchfile
   C:\Users\JohnDoe>cd C:\Users\JohnDoe\exercism\java\hello-world
   ```

4. 테스트를 실행해요:

   ```batchfile
   C:\Users\JohnDoe>gradlew.bat test
   ```

   _(처음에는 테스트가 실패해도 걱정하지 마세요. 모든 연습 문제는 이렇게 시작해요.)_

5. 연습 문제를 풀어요. `instructions.append.md` 가이드를 찾아서 따라 해봐요 ([GitHub에서 보기](https://github.com/exercism/java/blob/main/exercises/practice/hello-world/.docs/instructions.append.md#tutorial)).

행운을 빌어요! 즐겁게 해봐요!
