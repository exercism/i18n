# 사전 준비 사항

D 언어 트랙을 하려면 시스템에 다음 소프트웨어가 설치되어 있어야 해요:

* D 버전 2 컴파일러
* (선택 사항이지만 권장해요) DUB

## 사전 준비: D 버전 2 컴파일러

D 언어 웹사이트인 [dlang.org](https://dlang.org)에서 참조 컴파일러인 DMD(Digital Mars D)의 최신 컴파일러 버전을 여러 플랫폼용으로 내려받아 설치할 수 있어요.
자세한 내용은 [공식 다운로드 페이지](https://dlang.org/download.html)를 참고해요.
Windows에서는 [Chocolatey를 사용하는 방법](https://chocolatey.org/packages/dmd)도 있어요.
Intel 기반 Mac에서는 [Homebrew를 사용하는 방법](https://formulae.brew.sh/formula/dmd)도 있어요.

### 다른 컴파일러
자체 백엔드를 사용하는 DMD 참조 컴파일러 외에도, dlang.org 다운로드 섹션에서 받을 수 있는 컴파일러가 두 가지 더 있어요:

* GCC 백엔드를 사용하는 [GDC](http://gdcproject.org/downloads)
* LLVM 백엔드 기반의 [LDC](https://github.com/ldc-developers/ldc#installation)

GDC와 LDC가 항상 최신 DMD 프런트엔드 버전을 따라가지는 않지만, 더 나은 최적화 수준을 제공하고 ARM 같은 다른 플랫폼도 지원해요.

위키에서 [더 자세한 정보](https://wiki.dlang.org/Compilers)를 참고해요.

### IDE 지원

여러 IDE에서도 D 언어를 지원해요. 예를 들어 Visual Studio용 [VisualD](http://rainers.github.io/visuald/visuald/StartPage.html)와 IntelliJ CLion용 [D 플러그인](https://plugins.jetbrains.com/plugin/7727?pr=clion)이 있어요.
위키에서 [더 자세한 정보](https://wiki.dlang.org/IDEs)를 참고해요.

### 사전 준비: DUB

[DUB](https://github.com/dlang/dub)은 D용 빌드 관리자예요.

테스트 실행 과정을 간소화해 주기 때문에 DUB을 권장하지만, 설치할 수 없거나 설치하고 싶지 않다면 DUB 없이 실행하는 것도 가능해요.

#### Windows

[DUB 웹사이트의 다운로드 페이지](https://code.dlang.org/download)에서 Windows 설치 프로그램을 받을 수 있어요.

#### MacOS

* [DUB 웹사이트의 다운로드 페이지](https://code.dlang.org/download)에서 macOS용 바이너리를 받을 수 있어요.
* Intel 기반과 Apple Silicon 기반 Mac 모두를 위해 [Homebrew 패키지](https://formulae.brew.sh/formula/dub)도 제공돼요:

#### Linux

* [DUB 웹사이트의 다운로드 페이지](https://code.dlang.org/download)에서 Linux용 바이너리를 받을 수 있어요.
* 여러 배포판용 패키지도 제공돼요:
    * [ArchLinux](https://www.archlinux.org/packages/community/x86_64/dub/)
    * [Debian/Ubuntu](http://d-apt.sourceforge.net/)
    * [Gentoo](https://github.com/gentoo/dlang/tree/master/dev-util/dub)
    * [OpenSUSE](http://software.opensuse.org/download.html?project=devel%3Alanguages%3AD&package=dub)
