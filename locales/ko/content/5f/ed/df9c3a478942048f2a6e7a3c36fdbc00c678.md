# 자세히 알아보기

[삼항 연산자][ternary-operators]를 사용하면 if 조건을 문 블록이 아니라 식 안에서 정의할 수 있어요. 이는 함수형 프로그래밍의 접근 방식과 닿아 있고, 코드를 더 표현력 있게 만들면서 오류가 덜 발생하게 해 주는 경우가 많아요.

삼항 연산자는 세 개의 식을 결합해요. 조건이 먼저 오고, 그다음에는 조건이 참일 때 평가되어 반환되는 식(`?`로 시작하는 `if` 부분)이, 마지막에는 조건이 거짓일 때 평가되어 반환되는 식(`:`로 시작하는 `else` 부분)이 와요.

```csharp
int a = 3, b = 4;
int max = a > b ? a : b;
// => 4
```

[ternary-operators]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/operators/conditional-operator
