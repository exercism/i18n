# 설치

## Linux

GNU 셸인 Bash는 모든 GNU/Linux 시스템에서 찾을 수 있어요.
BSD와 다른 UNIX 계열 운영체제에서는 사용자가 직접 설치해야 할 가능성이 커요.
BSD, AIX, 또는 bash가 기본으로 포함되지 않은 Linux를 사용한다면, 기본 패키지가 아닌 패키지의 설치에 관해서는 사용 중인 운영체제의 자료를 참고해요.

원하는 그래픽 인터페이스에서 "Terminal"이라는 이름의 애플리케이션을 찾아봐요. "Administrative/System Tools" 섹션 아래에 있을 거예요.

사용할 수 있는 Bash의 버전을 확인하려면, 명령줄이나 터미널에서 다음을 실행해요:

    echo $BASH_VERSION

셸이 `bash`라면 다음과 비슷한 내용이 나올 거예요:

    4.4.19(1)-release

그 밖에 따로 할 일은 없어요. 지금 사용하는 셸이 bash이므로, 이 시점에 bash는 이미 설치되어 있고 PATH에도 들어 있을 거예요.

셸이 bash가 아니더라도, 굳이 바꿀 이유는 없어요.
bash 셸이 아니어도 bash 스크립트를 작성하고 실행할 수 있어요.

설치된 bash의 버전을 확인하려면 다음을 실행해요:

```plain
bash --version
```

그러면 다음과 비슷한 내용이 나와요:

```
GNU bash, version 4.4.19(1)-release (x86_64-pc-linux-gnu)
Copyright (C) 2016 Free Software Foundation, Inc.
License GPLv3+: GNU GPL version 3 or later <http://gnu.org/licenses/gpl.html>

This is free software; you are free to change and redistribute it.
There is NO WARRANTY, to the extent permitted by law.
```

그렇지 않다면 bash가 설치되어 있지 않을 수 있어요.
사용하는 배포판의 패키지 관리자로 설치해요.

## Windows

Windows 10에서는 [WSL](https://docs.microsoft.com/en-us/windows/wsl/about)을 설치할 수 있어요.
WSL을 설치하면 Windows에서 네이티브로 실행되는 완전한(정확히는 GUI 구성 요소를 제외한) Linux 배포판이 설치돼요.

또는 다음을 설치할 수 있어요:

* [Cygwin](https://cygwin.com/)
* [git for windows](https://gitforwindows.org/)
* [MinGW](http://mingw.org/)
* [가상 머신](https://docs.microsoft.com/en-us/virtualization/hyper-v-on-windows/about/)에 설치한 완전한 Linux 배포판

## MacOS

Apple OSX에서는:

* Finder를 열고,
* Applications 폴더를 열고,
* Utilities 폴더를 열고,
* 마지막으로 `Terminal` 애플리케이션을 열어요.

MacOS에 설치된 bash 버전은 3.2로 아주 오래됐어요.
이유는 (i) 최신 bash 버전이 GPLv3 라이선스를 따르고, (ii) Apple이 그 라이선스 조건을 강제로 따르기를 원하지 않기 때문이에요.
게다가 Apple은 bash가 MacOS에서 사라질 것이라고 예고했어요. 최근 기본 로그인 셸이 [bash에서 zsh로 변경](https://support.apple.com/en-us/HT208050)됐어요.

Mac에서 최신 bash를 설치하려면:

1. [Homebrew](https://brew.sh)를 설치해요.
1. 터미널에서 다음을 입력해요: `brew install bash`

그러면 최신 bash가 (제 기억으로는) `/usr/local/bin/bash`에 설치돼요. 시스템의 기본 bash를 덮어쓰지 않기 위해서예요. 다른 도구들이 /bin/bash에 의존할 수 있거든요.

`bash`를 입력했을 때 Homebrew bash가 실행되게 하려면, ~/.bash_profile(또는 ~/.profile) 파일을 편집해서 PATH에서 /usr/local/bin을 /bin보다 *앞에* 두면 돼요:

    PATH=/usr/local/bin:$PATH
