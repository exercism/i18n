# 소개

## 레코드

레코드는 함께 묶이는 필드들의 모음이고, 필드는 서로 다른 타입일 수 있어요. 레코드를 정의하려면 `type` 키워드를 사용해요. 레코드의 필드는 `{`와 `}` 문자 사이에 정의하고, 각 필드에는 _이름과 타입_이 있어요. 레코드를 만들려면 `{`와 `}` 문자 사이에 필드 이름을 적고 값을 할당해요. 레코드를 만들 때는 모든 필드에 값을 할당해야 해요. 레코드 인스턴스의 필드 값은 점 표기법으로 접근할 수 있어요.

레코드를 정의하거나 만들 때, 각 필드는 한 줄에 하나씩 두거나, 한 줄에 쓸 때는 세미콜론(`;`)으로 구분해야 해요.

```fsharp
// Define a record
type Address =
    { Street: string
      HouseNumber: int }

// Create a record
let oldAddress: Address =
    { Street = "Main Street"
      HouseNumber = 17 }

// Single-line alternative
type ConciseAddress = { Street: string; HouseNumber: int }
let conciseAddress: ConciseAddress = { Street = "Main Street"; HouseNumber = 17 }
```

레코드는 불변이기 때문에, 한 번 만들어진 레코드의 필드 값은 절대 바뀌지 않아요. 레코드의 값을 바꾸고 싶다면, `with` 키워드로 기존 레코드의 복사본을 만들 수 있는데, 하나 이상의 필드에 새로운 값을 지정할 수 있어요.

```fsharp
// Copy the old address but change the house number
let newAddress: Address = { oldAddress with HouseNumber = 86 }
newAddress.Street      // => "Main Street"
newAddress.HouseNumber // => 86
```

레코드는 _구조적 동등성_을 가져요. 즉, 같은 레코드의 두 인스턴스가 동일한 값을 가지면 서로 동등해요.

점 표기법으로 레코드의 필드에 접근할 수 있는 것 외에도, 레코드는 바인딩과 패턴 매칭에서 _분해_할 수 있어요:

```fsharp
let myAddress: Address = { Street = "Broadway"; HouseNumber = 123 }
let { Street = myStreet; HouseNumber = myHouseNumber } = myAddress

match myAddress with
| { HouseNumber = 1 } -> printfn "First house"
| { HouseNumber = houseNumber; Street = street } -> printfn "House number %d on %s" houseNumber street
// => "House number 123 on Broadway
```
