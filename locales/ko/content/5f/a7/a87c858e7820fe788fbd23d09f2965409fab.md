# 테스트

## 코드 작성하기

`src/lib.cairo`에 코드를 작성해요.
연습 문제에는 `src/lib.cairo`에 스텁 파일이 함께 있어서, 앞으로 작성해야 할 코드의 시그니처를 보여줘요.

대부분의 연습 문제에서는 모든 코드를 `src/lib.cairo` 파일에 작성하는 게 가장 좋아요.
해답을 여러 파일로 나누고 싶다면, The Cairo Book의 [모듈 챕터][chapter-modules]를 참고하세요.

[chapter-modules]: https://book.cairo-lang.org/ch07-02-defining-modules-to-control-scope.html

## 테스트 실행하기

테스트를 실행하려면 먼저 작업 디렉터리를 테스트하려는 연습 문제의 디렉터리로 옮겨야 해요:

```bash
cd path/to/exercise
```

그다음 다음 명령어를 실행해요:

```bash
scarb cairo-test
```

기본적으로 첫 번째 테스트만 활성화되어 있어요.
다음 테스트를 통과할 준비가 되면, 다음 테스트에서 ignore 플래그(`#[ignore]`)를 지워요.

무시된 테스트를 포함해 모든 테스트를 실행하려면, 모든 테스트에서 `ignore` 플래그를 지우거나, 그냥 다음을 실행하면 돼요:

```bash
scarb cairo-test --include-ignored
```

테스트를 통과할 수 있을 만큼만 최소한의 코드를 작성해도 괜찮아요.
테스트 실패가 다음에 무엇을 작성해야 하는지 알려줄 거예요.

Cairo는 컴파일 시점에 모든 코드를 검사하기 때문에, 필요한 코드를 작성하기 전까지는 테스트가 컴파일되지 않을 수도 있어요.
`ignore`된 테스트도 컴파일 시점에 검사돼요.
컴파일되지 않는 테스트는 각 줄을 `//`로 시작해서 [주석 처리][comments]할 수 있어요.
그런 다음 그 테스트를 작업할 준비가 되면 주석을 다시 풀면 돼요.
Cairo에는 `panic!()`라는 특별한 매크로도 있는데, 아직 완성하지 않은 코드 경로에 이걸 사용해서 프로그램이 컴파일되도록 만들 수 있어요.

[comments]: https://book.cairo-lang.org/ch02-04-comments.html
