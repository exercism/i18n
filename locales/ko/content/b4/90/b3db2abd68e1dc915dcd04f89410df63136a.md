# 소개

## 속성

C#의 속성은 클래스의 멤버로, 클래스 내부의 데이터에 접근할 수 있게 해줘요.
호출하는 쪽에서는 그 데이터를 설정하거나 가져올(get) 수 있어요. 속성은 자동 구현 속성일 수도 있고, 백킹 필드를 가질 수도 있어요. 속성은 set 접근자와 get 접근자 중 하나 또는 둘 다로 구성돼요.
다른 언어에서는 "mutator"가 대략 set 접근자에, "accessor"가 대략 get 접근자에 해당하기도 하지만, 문법의 구성 자체는 완전히 달라요.

속성을 설정할 때에는 입력값을 검증하거나, 형식을 다듬거나, 그 밖의 방식으로 조작할 수 있고, 실제로 클래스 안의 코드에서 접근할 수 있는 프로그래밍적 작업이라면 무엇이든 실행할 수 있어요.

마찬가지로 속성을 가져올 때에도 데이터를 계산하거나 형식을 다듬을 수 있고, 이때도 클래스에서 사용할 수 있는 프로그래밍적 작업이라면 무엇이든 실행할 수 있어요.

속성은 다른 클래스 멤버와 마찬가지로 접근 제한자(`public`, `private` 등)를 가져요. 다만 set 접근자는 get 접근자와 독립적인 접근 수준을 가질 수 있고, 그 반대도 마찬가지예요. 속성이 두 접근자를 모두 가질 필요는 없고, 하나만 가질 수도 있어요(get 또는 set 중 하나).

속성을 표현하는 기본 문법은 두 가지 형태가 있어요.

### 필드/식 기반 속성:

```csharp
private int myField;
public int MyProperty
{
    get { return myField; }
    set { myField = value; }
}
```

### 자동 구현 속성

```
public int MyProperty { get; private set; } = 42;
```

초기화는 선택 사항이에요.
