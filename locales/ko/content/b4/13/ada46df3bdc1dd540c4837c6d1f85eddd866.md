# 소개

AWK는 아주 작은 언어이고 기본 데이터 타입도 몇 개 없어요.
이번 단원에서는 숫자와 문자열을 살펴봐요.

## 숫자

AWK에서 숫자는 배정밀도 부동소수점 수로 구현돼요.
정수, 실수, 더블 사이에는 아무 구분이 없어요.

AWK는 8진수 상수(`0`으로 시작해요)와 16진수 상수(`0x` 또는 `0X`로 시작해요)를 알아봐요.

### 숫자 연산

[표준 산술 연산자][ops-arith] `+`, `-`, `*`, `/`, `%`를 사용할 수 있어요.
거듭제곱 연산자는 `^`예요(POSIX에서 규정한 형태예요). `**`도 사용할 수 있어요.
삼각 함수, 난수 생성, 그리고 수를 _x_와 0 사이의 가장 가까운 정수로 잘라 주는 `int(x)` 등 [내장 숫자 함수][funcs-numeric]도 있어요.

비트 _연산자_는 없어요.
gawk는 이 연산자들을 함수로 구현해요.
인자는 음수가 아닌 수여야 해요.

| 함수                | 연산                                           |
| ------------------- | ---------------------------------------------- |
| `and(a, b [, ...])` | 인자들의 비트 AND                              |
| `or(a, b [, ...])`  | 인자들의 비트 OR                               |
| `xor(a, b [, ...])` | 인자들의 비트 XOR                              |
| `lshift(v, count)`  | _v_의 값을 _count_ 비트만큼 왼쪽으로 시프트한 값  |
| `rshift(v, count)`  | _v_의 값을 _count_ 비트만큼 오른쪽으로 시프트한 값 |
| `compl(v, count)`   | _v_의 비트 보수                                |

## 문자열

AWK의 문자열은 문자의 나열이에요.
문자열 상수는 큰따옴표로 지정해요.

~~~~exercism/caution
GNU awk는 문자열에 유니코드 문자를 허용하지만, 다른 awk 구현은 허용하지 않을 수 있어요.
`gawk`와 또 다른 인기 있는 AWK 구현인 `mawk`를 비교해 보면:

```sh
$ echo "Hi friend 😀!" | gawk '{print length($3)}'
2
$ echo "Hi friend 😀!" | mawk '{print length($3)}'
5
```
~~~~

### 문자열 연산

문자열 연산은 하나뿐이에요: 연결이에요.
연결에는 특별한 연산자가 없어요.
그냥 두 문자열을 나란히 두면 연결돼요:

```awk
BEGIN {
    hw = "Hello" "World"
    print hw
}
# => HelloWorld
```

~~~~exercism/note
`print`는 함수가 아니라 **문**이에요.
`print`는 괄호가 필요 없어요.
~~~~

AWK에는 [문자열 조작 함수][funcs-string]가 아주 많아요.
트랙을 진행하면서 이 함수들을 자세히 배우게 될 거예요.

## 숫자와 문자열 사이의 변환

숫자와 문자열 사이를 변환하는 명시적인 연산자는 없어요.
AWK가 프로그램의 문맥에 따라 암묵적으로 변환해요.
덕분에 입력 필드 값을 다루기가 아주 간단해요. AWK는 대체로 원하는 대로 동작해요.

* `print x + y`는 `+` 숫자 연산 덕분에 `x`와 `y` 변수의 값을 숫자로 변환해요.
* `print x y`는 연결 연산 덕분에 `x`와 `y` 변수의 값을 문자열로 변환해요.

명시적으로 하고 싶다면, `0 + x`는 _x_의 숫자 표현을, `"" x`는 _x_의 문자열 표현을 돌려줘요.

### 문자열에서 숫자로

AWK가 문자열을 숫자로 변환하는 방식은 헷갈릴 수 있어요.
간단히 생각하면, AWK는 문자열의 시작부터 "숫자 문자"를 읽고, "숫자가 아닌" 문자를 만나면 멈춰요.
몇 가지 예를 들면:

* `"2.5"`는 숫자 `2.5`로 변환돼요.
* `"1e3"`는 숫자 `1000`으로 변환돼요(과학적 표기법).
* `"456abc"`는 숫자 `456`으로 변환돼요(`a`는 "숫자"가 아니므로 거기서 변환이 멈춰요).
* `"abc789"`는 숫자 `0`으로 변환돼요(문자열의 **시작**에는 숫자가 없어요).

자세한 내용은 [매뉴얼][str-to-num]에 있어요.

## 변수의 타입 확인

[`typeof(var)` 함수][func-typeof]는 타입을 문자열로 반환해요.

```awk
BEGIN {
    x = "42"
    print x, typeof(x)
    x = x + 1           # type conversion
    print x, typeof(x)
}
```
출력은 다음과 같아요
```none
42 string
43 number
```
