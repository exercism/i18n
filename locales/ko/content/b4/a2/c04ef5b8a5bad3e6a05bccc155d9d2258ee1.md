# 지침

배의 사무장이 되어 식료품 저장고의 재고를 관리해요. 인벤토리는 해시 테이블이고, 각 키는 품목 이름, 값은 재고 수량이에요.

## 1. 목록에서 인벤토리 만들기

`create-inventory`를 정의해요. 품목 이름의 시퀀스를 받아, 각각의 고유한 이름을 그 개수와 짝지은 해시 테이블을 반환해요.

```factor
{ "coal" "wood" "wood" "diamond" "diamond" "diamond" } create-inventory .
! => H{ { "coal" 1 } { "wood" 2 } { "diamond" 3 } }
```

## 2. 품목 더 추가하기

`add-items`를 정의해요. 인벤토리와 품목의 시퀀스를 받아, 나열된 각 품목마다 개수가 증가한 새로운 인벤토리를 반환해요. 원래 인벤토리는 수정되면 안 돼요.

```factor
H{ { "coal" 1 } } { "wood" "iron" "coal" "wood" } add-items .
! => H{ { "coal" 2 } { "wood" 2 } { "iron" 1 } }
```

## 3. 개수 줄이기

`decrement-items`를 정의해요. 인벤토리와 품목의 시퀀스를 받아, 나열된 각 품목마다 개수가 하나씩 줄어든 새로운 인벤토리를 반환해요. 개수는 절대 0 아래로 내려가면 안 되고, 인벤토리에 없는 품목은 제외해야 해요(음수 항목은 넣지 않아요).

```factor
H{ { "coal" 3 } { "diamond" 1 } { "iron" 5 } }
{ "diamond" "coal" "iron" "iron" } decrement-items .
! => H{ { "coal" 2 } { "diamond" 0 } { "iron" 3 } }
```

## 4. 품목 완전히 제거하기

`remove-item`을 정의해요. 인벤토리와 품목 하나를 받아, 그 품목이 제거된 새로운 인벤토리를 반환해요. 품목이 들어 있지 않으면 변경되지 않은 복사본을 반환해요.

```factor
H{ { "coal" 2 } { "wood" 1 } { "diamond" 2 } } "coal" remove-item .
! => H{ { "wood" 1 } { "diamond" 2 } }
```

## 5. 사용 가능한 품목 나열하기

`list-inventory`를 정의해요. 인벤토리를 받아, 수량이 0보다 큰 품목만 담은 `{ name quantity }` 쌍의 배열을 이름을 기준으로 알파벳순으로 정렬해 반환해요.

```factor
H{ { "coal" 7 } { "wood" 11 } { "diamond" 2 } { "iron" 7 } { "silver" 0 } }
list-inventory .
! => { { "coal" 7 } { "diamond" 2 } { "iron" 7 } { "wood" 11 } }
```
