## 변수

변수는 값이나 컨테이너를 가리키는 이름이에요.
변수 이름은 [sigils][sigils]라는 특수 문자로 시작할 수도 있고, 그런 문자 없이 바로 식별자로 시작할 수도 있어요.
sigil 뒤에는 [twigils][twigils]이 올 수도 있어요.

sigil이 붙은 변수마다 담는 자료 구조의 종류가 달라요.

```raku
my $scalar; # Assigned value will be stored as-is
my @array;  # Assigned value will be coerced into an array
my %hash;   # Assigned value will be coerced into a hash
my &code;   # Assigned value must be a code object
```

자주 보게 되는 twigil은 `^`와 `:`인데, 이 둘은 코드 블록 시그니처를 줄여 주는 역할을 해요.
`^`는 위치 매개변수에 쓰고, `:`는 이름 있는 매개변수에 써요.

```raku
{ $^a + $^b }; #`[same as] ->  $a,  $b { $a + $b }; # Called with (1, 2)
{ $:a + $:b }; #`[same as] -> :$a, :$b { $a + $b }; # Called with (a => 1, b => 2)
```

## 컨테이너

컨테이너가 있기 때문에 변수를 수정할 수 있어요.

`constant`로 선언한 변수와 sigil이 없는 변수(식별자 앞에 `\`를 붙여 선언해요)에는 컨테이너가 없고, 대신 값을 직접 가리켜요.

```raku
my $foo = 1;
$foo = 2;

constant $bar = 3;
my \baz = 4;

# The following will fail
$bar = 5;
baz  = 6;
```

## 타입

변수는 타입 제약을 붙여 선언할 수 있어요.
타입 제약에는 강제 변환도 지정할 수 있는데, 원하는 타입에 인자로 허용할 타입을 넘기면 돼요.

```raku
my Bool   $foo = True; # Booleans only.
my Bool() $bar = 0;    # Accepts type `Any`. Coerced to False.

my Str(Bool(Int)) $baz;
$baz = 1;   # "True"
$baz = "1"; # "1"
```

타입 제약을 활용하면 멀티 디스패치 루틴을 쓸 수 있어요.

```raku
multi foo (Int $bar) { say 'Type of arg to $bar is Int!' }
multi foo (Str $bar) { say 'Type of arg to $bar is Str!' }
```

Raku에서 타입은 그냥 또 다른 종류의 객체예요.
`class`, `role`, `enum`을 선언하는 것은 자신만의 타입 객체를 만드는 방법이에요.
예를 들어, 내장 타입 `Bool`은 enum으로 만들어졌어요: `enum Bool <False True>`.

`subset` 키워드로 다른 타입을 바탕으로 간단한 타입 제약을 만들 수도 있어요.
`where` 절을 사용하면 이 새로운 타입을 더 제한할 수 있어요.
`where` 절은 시그니처에서도 사용할 수 있어요.

```raku
subset PositiveInt of Int where * > 0;

sub is-even (PositiveInt $n where  %% 2) { say "$n is even!" }
```
