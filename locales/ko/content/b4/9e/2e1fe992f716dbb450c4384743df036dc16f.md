# 추가 지침

## 레지스터

| 레지스터 | 용도      | 타입    | 설명                                                                                  |
| -------- | --------- | ------- | ------------------------------------------------------------------------------------- |
| `$a0`    | 입력      | 정수    | 숫자                                                                                  |
| `$v0`    | 출력      | 정수    | 분류 (`1` = `perfect`, `2` = `abundant`, `3` = `deficient`, `-1` = `error`)           |
| `$t0-9`  | 임시      | 임의    | 임시 저장에 사용                                                                      |
