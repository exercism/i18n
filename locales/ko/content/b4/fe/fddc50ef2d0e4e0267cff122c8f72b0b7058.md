# 지침 추가

## 힌트

`label`과 `ohms` 함수를 구현해야 해요. `label`에는 제공된 시그니처를 사용해도 되지만, 그 시그니처가 창의성을 제한하도록 두지는 마세요.

이 연습 문제는 텍스트 데이터를 다뤄요. 역사적인 이유로 Haskell의 `String` 타입은 문자들의 리스트인 `[Char]`와 같은 의미예요. 텍스트 데이터를 더 효율적으로 다루려면 `Text` 타입을 사용할 수 있어요.

이 연습 문제의 선택적 확장으로, 다음과 같은 것들을 할 수 있어요.

- Haskell의 [문자열 타입](https://haskell-lang.org/tutorial/string-types)에 대해 읽어봐요.
- package.yaml의 의존성 목록에 `- text`를 추가해요.
- `Data.Text`를 [다음과 같은 방식](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c)으로 임포트해요.

    ```haskell
    import qualified Data.Text as T
    import           Data.Text (Text)
    ```

- 이제 예를 들어 `label :: Resistor -> Text`처럼 작성할 수 있고, `Data.Text` 컴비네이터를 예를 들어 `T.pack`처럼 참조할 수 있어요.
- [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html) 문서를 찾아봐요.

이 부분은 전적으로 선택 사항이에요.
