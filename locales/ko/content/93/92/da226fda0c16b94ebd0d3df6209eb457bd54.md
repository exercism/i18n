# 자세히 알아보기

C#의 리스트는 기본 형식의 값이나 구조체, 클래스의 인스턴스를 담는 컬렉션이에요. 기본 클래스 라이브러리에서는 [`List<T>`][lists-docs]로 구현되어 있고, 여기서 `T`는 리스트에 담기는 항목의 타입이에요. 이 API는 리스트를 만들고 조작하는 다양한 메서드를 제공해요.

```csharp
var listOfStrings = new List<string>();
var listOfIntegers = new List<int>();
var listOfRandoms = new List<Random>();
var listOfBigIntegers = new List<BigInteger>();
```

컬렉션 정의에는 보통 꺾쇠괄호 안에 자리 표시자가 들어가고, 관례적으로 `T`를 자주 써요. 이렇게 하면 컬렉션을 사용하는 쪽에서 어떤 타입의 항목을 컬렉션에 저장할지 지정할 수 있어요.

[concept:csharp/arrays]()와 달리 리스트는 크기를 동적으로 조정할 수 있어요.

## LINQ

`List<T>`의 기본 제공 API는 `ConvertAll`, `FindAll`, `Foreach` 같은 매핑과 필터를 포함해 풍부하고, [반복 구문][for-each]도 아주 명확해요. 이 API에 꼭 익숙해져야 하는 건 맞지만, LINQ(Language Integrated Query)는 많은 작업에 활용할 수 있고, 훨씬 강력하며 널리 사용돼요. 게다가 라이브러리 컬렉션과 서드파티 컬렉션, 직접 만든 클래스 전반에 걸쳐 일관된 인터페이스를 제공한다는 장점도 있어요.
