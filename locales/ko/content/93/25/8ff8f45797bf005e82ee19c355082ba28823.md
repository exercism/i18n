# 개요

[`grouping`][grouping]과 [`splitting`][splitting]에 있는 네 개의 워드만 알면 "시퀀스를 조각으로 자르는" 거의 모든 작업을 해결할 수 있어요:

```factor
USING: grouping kernel sequences splitting splitting.monotonic ;

! Disjoint chunks of N elements
{ 1 2 3 4 5 6 7 } 3 group .
! => { { 1 2 3 } { 4 5 6 } { 7 } }

! Overlapping sliding window of N elements
{ 1 2 3 4 5 } 2 clump .
! => { { 1 2 } { 2 3 } { 3 4 } { 4 5 } }

! Split wherever a predicate fires on an element
{ 1 2 0 3 4 0 5 } [ zero? ] split-when .
! => { { 1 2 } { 3 4 } { 5 } }

! Group runs where adjacent elements are "the same" by some test
{ 1 1 2 2 2 3 } [ = ] monotonic-split .
! => { { 1 1 } { 2 2 2 } { 3 } }
```

| 워드              | 효과                                                                    |
|-------------------|-------------------------------------------------------------------------|
| `group`           | `( seq n -- groups )`, 서로 겹치지 않게 *n*개씩 나눈 덩어리             |
| `clump`           | `( seq n -- clumps )`, *n*개씩 겹쳐 가며 만든 윈도우                    |
| `split-when`      | `( seq quot: ( elt -- ? ) -- pieces )`, quot이 참이면 나눠요            |
| `monotonic-split` | `( seq quot: ( a b -- ? ) -- pieces )`, *이웃한* 두 원소에 대한 quot이 `f`면 나눠요 |

도움이 되는 머릿속 모형이 있어요:

- **`group` / `clump`**는 크기를 봐요. *n* 매개변수가 각 윈도우가 얼마나 큰지를 정해요.
- **`split-when`**은 *원소 하나하나*를 봐요. 각 원소가 "나눌 지점"인지는 조건이 판단해요.
- **`monotonic-split`**은 *쌍*을 봐요. 이웃한 두 원소가 여전히 같은 묶음에 속하는지는 조건이 판단해요.
