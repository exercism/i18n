# 힌트

## 일반

- [`combinators`][combinators]의 `cond`는 속도를 성공률로 매핑하는 가장 깔끔한 방법이에요.
- 산술 관련 단어들은 [`math`][math]에 있고, 실수를 정수로 바꿔 주는 도우미인 `floor`와 `>integer`는 각각 [`math.functions`][math.functions]와 `math`에 있어요.

## 1. 라인이 가동 중인지 보고하기

- `zero?`는 ([`math`][math]) 속도가 `0`인지 검사해요.
- `if`는 불리언 하나와 두 개의 인용, 즉 `[ "stopped" ] [ "running" ]`을 받아서 조건에 맞는 쪽을 실행해요. 여기서는 속도가 테스트에 소비되므로 어느 인용에도 `drop`이 필요하지 않아요.

## 2. 성공률 계산하기

- `cond` 절은 `{ [ predicate ] [ body ] }` 형태예요. 각 조건은 속도를 검사하지만 스택은 원래 모습 그대로 남겨 둬야 해요 (`dup` … `<test>`가 그렇게 해요). 본문은 보통 `drop`으로 시작해요.
- 순서가 중요해요: `4 <=`보다 `zero?`를 먼저 검사해야 해요. `0 4 <=`는 `t`이기 때문이에요.
- 속도 `10`에 대한 기본값으로, 조건이 없는 마지막 항목을 사용해요.

## 3. 시간당 생산량 계산하기

- 파일 위쪽에 `base-speed`를 `CONSTANT:`로 정의해요 (`lasagna`의 `expected-bake-time`과 똑같이요).
- `base-speed * speed * success-rate`를 계산해요. 한 가지 방법은 `kernel`의 `bi`를 사용하는 거예요. `bi`는 같은 입력에 두 개의 인용을 실행하고 두 결과를 모두 스택에 남겨요.

## 4. 분당 생산되는 합격품 수 계산하기

- 시간당 생산량을 60으로 나눠요.
- `floor`로 소수 부분을 버리고, `>integer`로 실수 결과를 정수로 변환해요.
