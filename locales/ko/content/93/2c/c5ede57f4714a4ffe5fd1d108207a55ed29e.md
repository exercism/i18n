# 소개

`null` 값은 값이 _없음_ 을 나타낼 때 사용해요. **null을 허용하는** 타입은 변수가 `null` 값을 가질 수 있는 타입이에요. 어떤 타입이든 null을 허용하도록 만들려면 `Null<T>`로 감싸요:

```haxe
var a:Int = null; // Error
var b:Null<Int> = null; // Allowed
```

값이 현재 `null`인지 확인하려면 `if` 표현식을 사용하면 돼요:

```haxe
var a:Null<Int> = 10;

if (a != null) {
  trace("a is not null"); // a is not null
}
```
