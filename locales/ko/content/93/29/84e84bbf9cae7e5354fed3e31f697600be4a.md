# 소개

## 배열

F#의 `list`는 0개 이상의 값을 담는 불변 컬렉션이에요. 배열의 값은 모두 같은 타입이어야 해요. 배열은 불변이기 때문에 한 번 만들어지면 그 값은 절대 바뀌지 않아요. 배열을 수정하는 것처럼 보이는 함수나 연산자(예: 원소 추가)는 실제로는 새로운 배열을 반환해요.

배열은 다음과 같이 정의할 수 있어요:

```fsharp
let empty = []
let singleValue = [5]
let threeValues = ["a"; "b"; "c"]
```

배열에 원소를 추가하는 가장 일반적인 방법은 `::` (cons) 연산자를 사용하는 거예요:

```fsharp
let twoToFour = [2; 3; 4]
let oneToFour = 1 :: twoToFour
// => [1; 2; 3; 4]
```

F# 배열에는 _head_(첫 번째 원소)와 _tail_(첫 번째 원소 뒤에 오는 모든 것)이 있어요. 배열의 tail은 그 자체가 배열이에요.

배열은 `List` 모듈에 정의된 함수와 연산자로 다루거나, _list_ 및 _cons_ 패턴을 사용한 패턴 매칭으로 직접 다룰 수 있어요:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | head::tail -> sprintf "Non-empty list with head: %d" head

describe []        // => "Empty list"
describe [1]       // => "Non-empty with head: 1"
describe [5; 7; 9] // => "Non-empty with head: 5"
```

패턴 매칭을 할 때 값을 _버릴_ 수도 있어요. 특정 경우에 값에 _관심이 없을_ 때(즉, 값을 _사용하지_ 않을 때)는 밑줄(`'_'`)을 사용해 이를 나타낼 수 있어요:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [x] -> "List with one item"
    | [_; y] -> "List with two items (first item ignored)"
    | _ -> "List with many items (all items ignored)"

describe []        // => "Empty list"
describe [1]       // => "List with one item"
describe [5; 7]     // => "List with two items (first item ignored)"
describe [5; 7; 9] // => "List with many items (all items ignored)"
```

`'_'` 하나는 패턴 매칭에서 항상 _마지막_에 와야 해요. 다른 경우와 _일치하지 않는_ 모든 값은 이 경우가 처리해요.
