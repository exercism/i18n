# 타입 저글링

타입 저글링은 타입 강제 변환이라고도 해요.
타입 저글링은 서로 다른 타입의 값 두 개를 같은 타입으로 강제 변환해서 연산을 수행하는 것을 말해요.

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15 // int
```

표현식이 평가될 때, 문자열 값은 `*` 연산자가 기대하는 타입에 맞춰 암시적으로 `int`로 변환돼요.
어떤 타입으로 강제 변환할지는 연산의 규칙에 따라 PHP가 결정하는데, 이 규칙은 연산마다 크게 달라요.

타입 강제 변환은 함수나 메서드를 호출할 때도 일어나요.

```php
strlen(12321);
# => 5
```

## 형 변환

암시적 강제 변환에 의존하는 대신, `C` 스타일 형 변환을 사용해서 값을 특정 타입으로 명시적으로 평가되도록 강제할 수 있어요.

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

이렇게 하면 괄호 `(...)` 안에 지정한 타입으로 값이 변환돼요.
모든 원시 타입을 대상 타입으로 사용할 수 있어요: `bool`, `int`, `float`, `string`, `array`, `object`.

## 일시적인 변환일 뿐

타입 저글링이나 형 변환은 변수에 저장된 값의 타입을 **바꾸지 않아요**.
연산에 들어가는 입력만 변환될 뿐이에요.

```php
$apples_per_basket = "3" // string
5 * $apples_per_basket
# $apples_per_basket => "3" // string

$my_number = (int) $apples_per_basket // cast string to int
# $apples_per_basket => "3" // string
```

## 정보의 손실

값이 다른 타입으로 강제 변환될 때, 그 과정에서 정보가 손실될 수 있어요.

```php
$exact_distance = 15.5
$rough_distance = (int) $exact_distance
// => 15

$is_distant = (bool) $exact_distance
// => true

$erroneous_distance = (float) $is_distant
// => 1.0
```

명시적이든 암시적이든 형 변환에 의존하면, 규모가 큰 시스템에서는 오류가 발생할 수 있어요.

## `array`와 `object`로의 명시적 형 변환

값은 `array`와 `object` 타입으로도 변환할 수 있어요.
배열이나 객체가 아닌 값을 `array`로 변환하면, 값이 배열의 항목 하나로 들어가요.

```php
$day_of_the_week = 'Monday';
(array) $day_of_the_week
// => array(1) {
//      [0]=>
//        string(6) "Monday"
//    }
```

`object`로 변환하면, 값은 `scalar`라는 이름의 public 프로퍼티에 설정돼요.

```php
$car = "Honda"
(object) $car
// => object(stdClass)#1 (1) {
//      ["scalar"]=>
//        string(5) "Honda"
//    }
```

> `stdClass`는 PHP에 내장된 익명 클래스의 타입이에요.
