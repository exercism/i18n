# 나머지 연산

Crystal에서 나머지를 비교하는 것 자체는 전혀 문제없지만, 나눗셈의 나머지를 더 읽기 좋게 비교하는 방법은 [`divisible_by?`][divisible_by] 메서드를 사용하는 거예요.
예를 들어 볼까요?

```crystal
# Rather than:
number %% 2 == 0

# Consider:
number.divisible_by?(2)
```

[divisible_by]: https://crystal-lang.org/api/latest/Int.html#divisible_by%%3F%%28num%%29%%3ABool-instance-method
