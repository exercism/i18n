# 소개

구조체는 [맵][exercism-maps]을 기반으로 만들어진 확장 기능으로, 컴파일 시점 검사와 기본값을 제공해요. 구조체의 이름은 정의된 모듈의 이름을 따라요. 구조체를 정의하려면 `defstruct`를 사용해요. 이 구문은 보통 모듈 정의 바로 뒤에 와요. `defstruct`는 아톰의 리스트(`nil` 기본값)나 키워드 리스트(지정한 기본값)를 받아요. 기본값이 없는 필드는 기본값이 있는 필드보다 먼저 와야 해요.

```elixir
defmodule Plane do
  defstruct [:engine, wings: 2]
end

plane = %Plane{}
# => %Plane{engine: nil, wings: 2}
```

## 필드 접근과 갱신

구조체는 맵을 기반으로 만들어졌기 때문에, 대부분의 맵 함수를 사용해 값을 가져오고 다룰 수 있어요. 구조체에는 _Access Behaviour_가 **구현되어 있지 않아요**. 대신 구조체의 필드에 접근할 때는 _정적 접근 연산자_ `.`를 사용하는 것이 좋아요.

- 필드 값 가져오기/조회하기:

  ```elixir
  plane = %Plane{}
  plane.engine
  # => nil
  Map.fetch(plane, :wings)
  # => {:ok, 2}
  ```

- 필드 값 갱신하기

  ```elixir
  plane = %Plane{}
  %{plane | wings: 4}
  # => %Plane{engine: nil, wings: 4}
  ```

## 패턴 매칭

구조체는 구조체 이름을 넣거나 넣지 않고 패턴 매칭에 사용할 수 있어요.

```elixir
plane = %Plane{}
%Plane{wings: wings} = plane
%{wings: wings} = plane
```

패턴에 구조체 이름을 넣으면 왼쪽과 오른쪽이 같은 타입의 구조체인지 확인할 수 있어요.

```elixir
defmodule Helicopter do
  defstruct [:engine, rotors: 1]
end

%Plane{} = %Helicopter{}
# => (MatchError) no match of right hand side value: %Helicopter{engine: nil, rotors: 1}
```

## 필드 값 초기화 강제하기

`@enforce_keys` 모듈 속성에 필드 키의 리스트를 지정하면 구조체가 만들어질 때 값이 초기화되도록 강제할 수 있어요. 리스트에 없는 키의 값은 위의 예시에서 보았듯이 `nil`이 돼요. 강제된 키가 초기화되지 않으면 오류가 발생해요.

```elixir
defmodule User do
  @enforce_keys [:username]
  defstruct [:username]
end

%User{}
# => (ArgumentError) the following keys must also be given when building struct User: [:username]
```
