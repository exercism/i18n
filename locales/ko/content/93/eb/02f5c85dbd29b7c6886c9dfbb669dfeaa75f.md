# 지침 추가

## 구현

코드를 실행하다 보면 예상치 못한 문제를 처리해야 할 때가 있어요.
Dart에서는 이런 상황을 처리할 때 예외를 사용할 수 있어요.

Dart에서 예외를 던지려면 `throw` 키워드 뒤에 발생시키려는 예외의 인스턴스를 붙여요.
예를 들어 `throw Exception()`은 기본 Exception 타입의 인스턴스를 던져요.

이 연습 문제에서는 `InvalidNucleotideException`이라는 사용자 정의 예외를 정의해야 해요.
이 예외는 잘못된 뉴클레오타이드를 만났을 때 던져야 해요.
테스트 스위트는 `InvalidNucleotideException`의 인스턴스가 전달되는지만 확인하므로, 올바르게 던지기만 하면 원하는 대로 자유롭게 구현할 수 있어요.

Dart의 예외에 대해 더 알고 싶다면 [예외 문서](https://dart.dev/language/error-handling)를 참고해요.
사용자 정의 예외는 [Exception 인터페이스를 구현](https://dart.dev/language#interfaces-and-abstract-classes)해서 만들 수 있어요.
