# 테스트

Exercism 프로젝트 디렉터리 안에 있는 Odin 연습 문제는 연습 문제 디렉터리로 이동한 뒤 `odin test .`를 실행하면 돌려볼 수 있어요.

```sh
cd "$(exercism workspace)"/odin/leap
odin test .
```

## 언어 검사 활성화하기

테스트하는 동안 Odin은 코드를 "vet"할 수 있어요. 사용하지 않는 임포트나 변수 같은 것을 찾아내죠.

테스트는 다음과 같이 실행해요.

```sh
odin test . -vet
```

검사를 더 많이 하려면 `-strict-style` 옵션을 추가해요.

## 테스트 주도 개발(TDD)

`odin test`는 `@(test)` 속성을 가진 각 프로시저를 실행해요.

테스트 스위트를 보면 각 테스트 프로시저가 이 속성을 가지고 있는 걸 알 수 있어요.
즉, 테스트를 실행하면 모든 테스트 프로시저가 실행돼요.

Exercism은 일반적으로 [테스트 주도 개발][tdd]을 권장해요. 그 방법은 다음과 같아요.

- 처음에는 첫 번째를 제외한 모든 테스트가 건너뛰도록 설정되어 있어요.
- 첫 번째 테스트를 통과할 만큼만 코드를 작성해요.
- 그다음 다음 테스트를 활성화하고, 그것을 통과할 만큼만 코드를 작성해요.
- 코드가 모든 테스트를 통과할 때까지 반복해요.

유지보수하는 사람들(메인테이너)은 테스트의 일부만 실행하는 우아한 프로그래밍 방식을 찾지 못했어요.
테스트 파일이 다루기 어려울 정도로 너무 커져 버렸거든요.
TDD로 개발하려면 테스트 파일을 편집해서 아직 실행할 준비가 안 된 테스트를 주석 처리하고, 풀이를 작성하면서 하나씩 주석을 해제하면 돼요.
