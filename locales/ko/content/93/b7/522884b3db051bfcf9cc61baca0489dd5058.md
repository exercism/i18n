# 지침

배울 프로그래밍 언어 배열을 관리하는 코드를 작성해 볼 거예요.

## 1. 배열에 언어 추가하기

언어 배열과 언어 이름을 매개변수로 받는 `add-language` 서브루틴을 수정해서, 새 언어가 끝에 추가된 배열을 반환하도록 해요.

## 2. 배열에서 언어 제거하기

`remove-language` 서브루틴을 수정해서 주어진 배열에서 마지막 언어를 제거해요.

## 3. 배열에서 첫 번째 언어 가져오기

`first-language` 서브루틴을 수정해서 주어진 배열의 첫 번째 언어를 반환하도록 해요.

## 4. 배열에서 마지막 언어 가져오기

`last-language` 서브루틴을 수정해서 주어진 배열의 마지막 언어를 반환하도록 해요.

## 5. 배열에서 언어 일부 가져오기

언어 배열과 원하는 원소에 해당하는 숫자 배열을 받는 `get-languages` 서브루틴을 수정해서, 주어진 배열의 일부를 반환하도록 해요.

## 6. 배열에 언어가 있는지 확인하기

언어 배열과 언어 이름을 매개변수로 받는 `has-language` 서브루틴을 수정해서, 주어진 배열에 그 언어가 존재하는지를 나타내는 `True` 또는 `False`를 반환하도록 해요.
