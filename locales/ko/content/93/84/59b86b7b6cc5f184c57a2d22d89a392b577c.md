# 타입 어서션 소개

Go에서 인터페이스는 실제 타입이 무엇인지 모호하게 만들 수 있어요.
타입 어서션을 사용하면 `interfaceVariable.(concreteType)` 문법으로 인터페이스 값이 담고 있는 구체적인 값을 꺼낼 수 있어요.

예를 들어 볼까요:

```go
var input interface{} = 12
number := input.(int)
```

참고: 인터페이스 변수가 구체적인 타입의 값을 담고 있지 않으면 패닉이 발생해요.

타입 어서션의 두 반환 값을 모두 활용하면 인터페이스 값이 특정 구체적인 타입의 값을 담고 있는지 확인할 수 있어요. 하나는 실제 값이고, 다른 하나는 어서션이 성공했는지 알려 주는 불리언 값이에요.
예를 들어 볼까요:

```go
str, ok := input.(string) // no panic if input is not a string
```

`input`이 `string`을 담고 있으면 `str`은 실제 값이 되고 `ok`는 true가 돼요.
`input`이 `string`을 담고 있지 않으면 `str`은 `string` 타입의 제로 값(즉, `""`, 빈 문자열)이 되고 `ok`는 false가 돼요.
어느 경우에도 패닉은 발생하지 않아요.

## 타입 스위치

**타입 스위치**는 여러 타입 어서션을 연달아 수행할 수 있어요.
문법은 타입 어서션(`interfaceVariable.(concreteType)`)과 같지만, `concreteType` 자리에 `type` 키워드가 들어가요.
다음은 예시예요:

```go
var i interface{} = 12 // try: 12.3, true, int64(12), []int{}, map[string]int{}

switch v := i.(type) {
case int:
    fmt.Printf("the integer %d\n", v)
case string:
    fmt.Printf("the string %q\n", v)
default:
    fmt.Printf("type, %T, not handled explicitly: %#v\n", v, v)
}
```
