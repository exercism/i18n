# 개요

C#에서 메모리를 할당할 때 중요한 점은 메모리 할당이 _자동으로_ 이루어진다는 거예요. 메모리를 직접 할당할 필요가 없어요. 더 이상 사용하지 않는 메모리까지 자동으로 해제되도록 하기 위해, C#은 [가비지 컬렉터][docs.microsoft.com_garbage-collection-fundamentals]를 사용해요.

C#으로 작업할 때 사용되는 메모리에는 두 가지 종류가 있어요:

- 스택
- 힙

스택은 수명이 짧고 사용할 수 있는 공간이 제한적이에요. 스택에 허용된 최대 메모리 양을 초과하면 `StackOverflowException`이 발생해요. 각 스레드는 자신만의 스택을 가져요. 메서드가 반환되면 스택은 자동으로 되감기므로, 가비지 컬렉터가 관여할 필요가 없어요. 즉, 스택에서 메모리를 할당하거나 해제하는 것은 매우 빨라요.

힙은 수명이 길고 사용할 수 있는 메모리가 많아요. 객체가 할당되면 메모리 할당자가 힙에서 사용 가능한 메모리를 찾아 할당해요. 힙은 스레드 간에 공유되며 데이터를 공유하는 데 사용할 수 있어요. 이따금 가비지 컬렉터가 실행을 중단하고("GC 일시 정지") 더 이상 사용되지 않는 객체가 있는지 확인해요. 그런 객체가 있으면 해당 객체의 메모리가 해제되고, 그 메모리는 나중에 다시 할당할 수 있게 돼요.

## 무엇이 어디로 갈까요?

원칙적으로 값 형식은 스택에, 참조 형식은 힙에 할당돼요. 여기에는 몇 가지 예외가 있는데, 예를 들어 값 형식이 참조 형식의 일부인 경우(예: `int` 필드를 가진 클래스)가 그래요.
