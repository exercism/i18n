# 소개

Z3는 방정식이나 수식이 만족 가능한지, 다시 말해 해가 존재할 수 있는지 판단하는 데 사용하는 SMT(만족성 모듈로 이론) 언어예요.

Z3는 주로 소프트웨어 검증, 제약 조건 해결, 기하학 문제, 보안, 그리고 빠른 수학 계산이 도움이 되는 여러 응용 분야에서 쓰여요.

Z3는 Microsoft Research의 RiSE(Research in Software Engineering) 그룹에서 만들었고, 2015년부터 오픈 소스 언어가 되었어요. Z3의 오픈 소스 Github 저장소는 https://github.com/Z3Prover/z3에서 볼 수 있어요.
