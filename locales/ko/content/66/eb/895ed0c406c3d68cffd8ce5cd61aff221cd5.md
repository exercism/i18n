# 지침

친구가 사진 편집 소프트웨어에 돈을 쓰는 것에 지쳐서 직접 만들어 보기로 했어요.
친구는 새 소프트웨어의 이름을 Foto Fusionist라고 짓기로 했어요.

Foto Fusionist는 다양한 일을 할 수 있는 사진 편집 소프트웨어지만, 지금까지는 그중 몇 가지 기능만 구현한 상태예요.
그래도 친구는 진행 상황에 아주 만족하며, 몇 가지 기능을 더 구현해 달라고 부탁했어요.

## 1. 이진 표현을 정수로 변환하기

첫 번째 기능으로, 친구는 숫자의 이진 표현을 정수로 변환할 수 있기를 원해요.
소프트웨어가 색상 채널의 이진 표현을 읽어서 정수로 변환할 수 있어야 하기 때문에 필요한 기능이에요.

`String` 타입의 `binary` 인자를 받는 `FotoFusionist.binary_to_int` 메서드를 구현하세요.
메서드는 이진수의 정수 표현을 반환해야 해요.

```crystal
FotoFusionist.binary_to_int("10011")
# => 19
```

## 2. 정수에서 최하위 비트 구하기

친구가 원하는 두 번째 기능은 정수에서 [최하위 비트][least-significant-bit]를 구하는 거예요.
최하위 비트는 가장 오른쪽에 있는 비트예요.
값이 가장 작기 때문에 최하위 비트라고 불러요.

최하위 비트는 색상 채널을 표현하는 데 사용되는 비트 수를 줄여서 이미지를 최적화할 수 있는지 판단할 때 필요해요.

`Int32` 타입의 `number` 인자를 받는 `FotoFusionist.least_significant_bit` 메서드를 구현하세요.
메서드는 숫자의 최하위 비트를 반환해야 해요.

```crystal
FotoFusionist.least_significant_bit(0b10011)
# => 1

FotoFusionist.least_significant_bit(0b10010)
# => 0
```

## 3. 색상 채널에서 16진수 값 구하기

친구가 원하는 세 번째 기능은 색상 채널에서 16진수 값을 구하는 거예요.
16진수 값은 색상 채널을 16진수 표현으로 변환하는 데 필요하고, 그 16진수 표현은 두 자리로 이루어져야 해요.

`Int32` 타입의 `number` 인자를 받는 `FotoFusionist.hex_value` 메서드를 구현하세요.
메서드는 숫자의 16진수 값을 `String`으로 반환해야 해요.

```crystal
FotoFusionist.hex_value(19)
# => "13"
```

## 4. RGB에서 16진수 값 구하기

친구가 원하는 네 번째 기능은 RGB 색상에서 16진수 값을 구하는 거예요.
사용자가 색상을 하나의 문자열 표현으로 얻을 수 있게 하려면 이 기능이 필요해요.
RGB 색상은 빨강, 초록, 파랑 세 개의 색상 채널로 표현되는 색상이에요.
각 색상 채널은 0과 255 사이의 숫자로 표현돼요.

RGB 색상의 16진수 값은 색상을 16진수로 나타낸 문자열이며, 빨강 색상 채널이 먼저, 그다음 초록 색상 채널, 마지막으로 파랑 색상 채널이 와요.

`Int32` 타입의 `red`, `green`, `blue` 세 인자를 받는 `FotoFusionist.hex_value_from_rgb` 메서드를 구현하세요.
메서드는 RGB 색상의 16진수 값을 `String`으로 반환해야 해요.

```crystal
FotoFusionist.hex_value_from_rgb(255, 0, 0)
# => "ff0000"
```

[least-significant-bit]: https://en.wikipedia.org/wiki/Least_significant_bit
