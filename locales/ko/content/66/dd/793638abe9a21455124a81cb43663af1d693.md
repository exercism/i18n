# 소개

Objective-C는 C 위에 얹힌 얇은 계층이고, C의 "엄격한 상위 집합"이에요. 즉, 어떤 C 프로그램이든 Objective-C 컴파일러로 컴파일할 수 있고, Objective-C 클래스 안에 C 언어 코드를 자유롭게 넣을 수도 있어요.
Objective-C는 객체 문법을 Smalltalk에서 가져왔어요.
객체 지향이 아닌 연산(원시 변수, 전처리, 표현식, 함수 선언, 함수 호출 등)의 문법은 모두 C와 같고, 객체 지향 기능의 문법은 Smalltalk 스타일 메시징을 구현한 것이에요.

언어와 그 역사에 대한 더 많은 정보는 [여기](https://en.wikipedia.org/wiki/Objective-C)에서 찾을 수 있어요.
