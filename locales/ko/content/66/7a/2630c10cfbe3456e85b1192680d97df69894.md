# 소개

## 기초

이러한 주제에 대해 더 자세히 알아보려면 [개념 페이지][exercism-concept]를 확인해요.

### 일반적인 문법

PHP 여는 태그 `<?php`는 PHP 코드의 시작을 나타내요.
모든 문은 명령을 구분하기 위해 `;`로 끝나야 해요.

```php
<?php

$message = "Success!"; // Statement correctly ends with `;`
$message = "I fail." // PHP Parse error: syntax error, [...]
```

읽기 쉽도록, 모든 코드 예제에서는 PHP 여는 태그 `<?php`를 생략해요.

### 주석

한 줄 주석은 `//`로 시작해요.

```php
// Single line comment
```

### 값과 변수

할당 `=` 연산자를 사용하면 변수에 값을 할당할 수 있어요.
변수 이름은 달러 `$` 기호로 시작해야 하며, [이름 규칙][exercism-concept-naming-conventions]을 따라야 해요.

```php
$count = 1; // Assign value of 1

// Strings can be created by enclosing the characters
// within single `'` quotes or double `"` quotes.
$message = "Success!";
```

### 함수와 메서드

값과 변수는 함수에 전달할 수 있어요.
함수의 인자는 전달받은 값을 담는 새로운 변수가 돼요.
함수는 `return` 키워드를 사용해 어떤 값이든 반환할 수 있어요.

```php
function window_height($height)
{
    return $height + 10;
}

window_height(100);
// => 110
```

클래스와 그 인스턴스 안에 있는 함수는 메서드라고 해요.
메서드를 호출할 때는 이름 앞에 인스턴스와 `->`를 붙여요.
메서드는 현재 인스턴스를 가리키는 특별한 변수 `$this`에 접근할 수 있어요.

```php
<?php

class Calculator {
    public function sub($x, $y)
    {
        return $this->add($x, -$y); // Calls the method add() of the current instance
    }

    public function add($x, $y)
    {
        return $x + $y;
    }
}

$calculator = new Calculator(); // Creates a new instance of Calculator class
$calculator->sub(3, 1); // Calls the method sub() of the instance stored in $calculator
// => 2
```
