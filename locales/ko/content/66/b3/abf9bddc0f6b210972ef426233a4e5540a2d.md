# 지침

예비 마술사 Elyse는 몇 가지 기본기를 연습하려고 해요. Elyse에게는 다루고 싶은 카드 덱이 하나 있어요.

조금 더 쉽게 하기 위해 1부터 10까지의 카드만 사용해요.

## 1. 덱에서 카드 가져오기

주어진 덱에서 `index` 위치에 있는 카드를 반환하는 `getCard` 함수를 구현해요. 인덱스가 덱에 없으면 Nothing을 반환해요.

```elm
getCard 2 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Just 4
getCard 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Nothing
```

## 2. 덱의 카드 바꾸기

`index` 위치의 카드를 주어진 새 카드로 바꾼 덱을 반환하는 `setCard` 함수를 구현해요.
`index`가 덱에 없으면 원래 덱을 반환해요.

```elm
setCard 2 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Array.fromList [ 1, 2, 6, 1 ]
setCard 6 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Array.fromList [ 1, 2, 4, 1 ]
```

## 3. 덱에 카드 추가하기

새 카드를 추가한 덱을 반환하는 `addCard` 함수를 구현해요.

```elm
addCard 8 ( Array.fromList [ 5, 9, 7, 1 ] )
    --> Array.fromList [ 5, 9, 7, 1, 8 ]
```

## 4. 덱에서 카드 제거하기

`index` 위치의 카드를 제거한 덱을 반환하는 `removeCard` 함수를 구현해요.
주어진 `index`가 덱에서 유효한 인덱스가 아니면 원래 덱을 반환해요.

```elm
removeCard 2 ( Array.fromList [ 3, 2, 6, 4, 8 ] )
    --> Array.fromList [ 3, 2, 4, 8 ]
removeCard 2 ( Array.fromList [ 3, 2 ] )
    --> Array.fromList [ 3, 2 ]
```

## 5. 덱에 있는 짝수 카드의 개수 세기

덱에 있는 짝수 카드의 개수를 세는 `evenCardCount` 함수를 구현해요.

```elm
evenCardCount (Array.fromList [ 3, 8, 4, 5, 1, 6, 10 ] )
    --> 4
```
