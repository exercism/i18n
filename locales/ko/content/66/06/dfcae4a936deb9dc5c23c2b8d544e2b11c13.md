# 튜플

[튜플][tuple]은 원소를 순서대로 나열한 유한한 목록이며, 값을 변경할 수 없어요.
튜플은 모든 위치의 타입이 고정되어 있어야 해요.
따라서 컴파일러는 각 위치에 어떤 타입이 있는지 알고 있어요.
튜플에서 각 위치마다 서로 다른 타입을 사용할 수 있지만, 그 타입들은 컴파일 시점에 반드시 알려져 있어야 해요.

## 튜플 만들기

튜플에 담는 값들의 타입을 컴파일 과정에서 해석할 수 있는지에 따라 튜플을 만드는 방법이 달라져요.
값이 컴파일 시점에 알려져 있다면 튜플 리터럴 문법으로 튜플을 만들 수 있고, 그렇지 않다면 타입을 직접 선언해야 해요.
또한 값들의 타입이 튜플에 지정한 타입과 일치해야 하고, 값의 개수도 지정한 타입의 개수와 같아야 해요.
다음은 튜플 리터럴 문법으로 정의하는 예시예요:

```crystal
tuple = {1, "foo", 'c'} # Tuple(Int32, String, Char)
```

`Tuple` 클래스를 사용해 튜플을 만들 수도 있어요.

```crystal
tuple = Tuple(Int32, String, Char).new(1, "foo", 'c')
```

또는 튜플을 담을 변수의 타입을 직접 지정할 수도 있어요.

```crystal
tuple : Tuple(Int32, String, Char) = {1, "foo", 'c'}
```

튜플의 타입을 직접 지정하면 특정 위치가 유니언 타입을 가지도록 정의할 수 있어서 유용해요.
즉, 하나의 위치가 여러 타입을 가질 수 있다는 뜻이에요.

```crystal
tuple : Tuple(Int32 | String, String, Char) = {1, "foo", 'c'}
```

## 변환

### 배열에서 튜플 만들기

`Tuple` 클래스의 `from` 메서드를 사용하면 배열에서 튜플을 만들 수 있어요.
이때는 튜플의 타입을 지정해야 해요.

```crystal
array = [1, "foo", 'c']
tuple = Tuple(Int32, String, Char).from(array)
```

### 배열로 변환하기

`to_a` 메서드를 사용하면 튜플을 배열로 변환할 수 있어요.
이렇게 만들어진 배열의 원소 타입은 튜플 각 필드 타입의 유니언이에요.

```crystal
tuple = {1, "foo", 'c'}
array = tuple.to_a
array # => [1, "foo", 'c']
```

### 튜플 타입 정의 축약형

튜플 타입을 직접 정의하는 축약형이 있어요.
바로 튜플 리터럴 안에 타입을 적는 방식이에요.

```crystal
tuple : {Int32, String, Char} = {1, "foo", 'c'}
```

## 원소에 접근하기

배열과 마찬가지로 튜플의 인덱스는 0부터 시작해요. 즉, 첫 번째 원소의 인덱스는 0이에요.
하지만 배열과 달리 튜플은 각 원소의 타입이 고정되어 있고 컴파일 시점에 알려져 있어요. 그래서 튜플을 인덱싱하면 원소의 타입은 그 위치에 따라 정해져요.
튜플의 원소에 접근하려면 `[]` 연산자를 사용하면 돼요.

```crystal
array = [1, "foo", 'c']
array[0]         # => 1
typeof(array[0]) # => Int32 | String | Char

tuple = {1, "foo", 'c'}
tuple[0]         # => 1
typeof(tuple[0]) # => Int32
```

배열에서 원소에 접근할 때와 다른 점은, 인덱스를 지정하면 컴파일러가 그 인덱스가 튜플의 범위 안에 있는지 확인한다는 거예요.
즉, 런타임 오류 대신 컴파일 시점에 오류가 발생해요.

```crystal
tuple = {1, "foo", 'c'}
tuple[3]
# => Error: index out of bounds for Tuple(Int32, String, Char) (3 not in -3..2)
```

하지만 인덱스가 변수에 저장되어 있으면 컴파일러가 컴파일 시점에 그 인덱스가 튜플의 범위 안에 있는지 확인할 수 없어요. 대신 런타임 오류가 발생해요.

## 부분 튜플

범위를 사용해 `[]` 연산자를 호출하면 튜플의 부분 튜플을 얻을 수 있어요.
지정한 범위에 해당하는 원소들로 이루어진 새로운 튜플이 반환돼요.
범위는 컴파일 시점에 주어져야 해요. 그렇지 않으면 컴파일러가 부분 튜플에 있는 원소들의 타입을 알 수 없어요.
즉, 범위는 리터럴이어야 하고 변수에 할당된 값이면 안 돼요.

```crystal
tuple = {1, "foo", 'c'}
subtuple = tuple[0..1] # Tuple(Int32, String)

i = 0..1
tuple[i]
# Error: Tuple#[](Range) can only be called with range literals known at compile-time
```

## 튜플은 언제 사용할까요

튜플은 값의 타입이 컴파일 시점에 알려져 있는 값들을 정해진 개수만큼 묶고 싶을 때 유용해요.
튜플은 값을 변경할 수 없기 때문에 배열보다 메모리를 적게 사용하고 더 빨라요.
또 다른 활용 사례로, 메서드에서 여러 값을 반환할 때도 쓸 수 있어요.
튜플의 각 위치가 서로 다른 타입을 가질 수 있기 때문에, 값들의 타입이 다를 때 특히 유용해요.

크기가 늘어나거나 줄어들 수 있는, 또는 자주 수정해야 하는 자료 구조가 필요할 때는 튜플을 사용하면 안 돼요.
