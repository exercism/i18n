# 지시 사항

넷볼 경기에서 점수판을 운영하고 있어요. 지금까지와는 달리, 점수판은 지금까지 일어난 일을 기억해야 해요.

`SCOREBOARD` 클래스에는 다음이 필요해요. 스텁에는 클래스와 두 개의 속성 선언이 들어 있어요. 나머지를 추가해 봐요.

## 1. 점수판 준비하기

`create`는 홈 팀의 이름과 원정 팀의 이름을 받아서, 두 점수가 모두 0인 점수판을 돌려줘요.

```sather
board ::= #SCOREBOARD("Vixens", "Magpies");
board.home_score
-- => 0
```

## 2. 골 넣기

`home_goal`은 홈 점수에 1을 더하고, `away_goal`은 원정 점수에 1을 더해요. 둘 다 아무것도 반환하지 않아요.

```sather
board.home_goal;
board.home_score
-- => 1
```

## 3. 점수판 읽기

`summary`는 점수판을 기록하듯이 반환해요: 홈 팀, 홈 팀의 점수, 하이픈, 원정 팀의 점수, 그다음 원정 팀 순서로요.

```sather
board.summary
-- => "Vixens 1 - 0 Magpies"
```

공백은 표시된 그대로이고, 하이픈은 `-` 하나예요.

## 4. 누가 이기고 있을까요?

`leader`는 앞서고 있는 팀의 이름을 반환하고, 점수가 같으면 `"Draw"`를 반환해요.

```sather
board.leader
-- => "Vixens"
```

## 5. 얼마나 앞서 있을까요?

`margin`은 두 팀을 가르는 골 수를 반환해요. 누가 앞서 있든 절대 음수가 아니에요.

```sather
board.margin
-- => 1
```
