# 지침

복소수는 `a + b * i` 형태의 수예요. 여기서 `a`와 `b`는 실수이고 `i`는 `i^2 = -1`을 만족해요.

`a`를 실수부, `b`를 `z`의 허수부라고 해요.
`a + b * i`의 켤레복소수는 `a - b * i`예요.
복소수 `z = a + b * i`의 절댓값은 실수 `|z| = sqrt(a^2 + b^2)`예요. 절댓값의 제곱 `|z|^2`은 `z`에 그 켤레복소수를 곱한 결과예요.

두 복소수의 합과 차는 각각의 실수부와 허수부를 따로 더하거나 빼서 구해요:
`(a + i * b) + (c + i * d) = (a + c) + (b + d) * i`,
`(a + i * b) - (c + i * d) = (a - c) + (b - d) * i`.

곱셈 결과는 정의에 따라 다음과 같아요.
`(a + i * b) * (c + i * d) = (a * c - b * d) + (b * c + a * d) * i`.

0이 아닌 복소수의 역수는 다음과 같아요.
`1 / (a + i * b) = a/(a^2 + b^2) - b/(a^2 + b^2) * i`.

복소수 `a + i * b`를 다른 복소수 `c + i * d`로 나누면 다음과 같아요:
`(a + i * b) / (c + i * d) = (a * c + b * d)/(c^2 + d^2) + (b * c - a * d)/(c^2 + d^2) * i`.

e를 복소수 지수로 거듭제곱한 값은 `e^(a + i * b) = e^a * e^(i * b)`로 나타낼 수 있어요. 이때 마지막 항은 오일러 공식 `e^(i * b) = cos(b) + i * sin(b)`로 주어져요.

 - 주어진 복소수의 켤레복소수, 절댓값, 지수.
