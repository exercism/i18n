# 설치

이 트랙은 Wren의 로컬 런타임을 제공하기 위해 처음부터 끝까지 [Wren Console][wren-console]에 의존해요. 즉, 컴퓨터에서 Wren을 실행하는 모든 과정은 [Wren Console][wren-console]을 사용한다고 가정해요. 공식 Wren <abbr title="명령줄 인터페이스">CLI</abbr>와 혼동하지 마세요. 완벽한 세상이라면 그 런타임을 사용할 수 있겠지만, 현재는 [여러](https://github.com/wren-lang/wren-cli/pull/74) [가지](https://github.com/wren-lang/wren/pull/1006) [서로 다른](https://github.com/wren-lang/wren-cli/issues/108) [문제](https://github.com/wren-lang/wren-cli/pull/105)가 있어서 Exercism으로 Wren을 배우기에는 최선의 선택이 아니에요.

Wren Console은 Wren CLI에서 갈라져 나온 것으로, 이런 문제들을 해결하고 학습 경험을 더 매끄럽게 만들어 주는 기능들을 더했어요. 걱정 마세요. 여기서 배우는 Wren 언어 지식과 개념은 앞으로 Wren을 어디에서 사용하든 그대로 적용돼요.

## 설치 개요

- `git` 명령을 쓰려면 Git을 설치해요
- `wrenc` 명령을 쓰려면 [Wren Console][wren-console]을 설치해요

### Git 설치

`git` 바이너리가 설치되어 있고 PATH에 있어야 해요. Wren Package가 패키지(연습 문제를 테스트할 때 필요한 테스트 모음 등)를 설치하는 방식이 바로 이거예요.

- **Windows** - 공식 [Git 다운로드](https://git-scm.com/download/win) 페이지부터 시작하는 게 좋아요.
- **Linux** - 즐겨 쓰는 패키지 관리자가 도와줄 거예요.
- **Mac** - 최근의 모든 Mac OS 버전에는 `git`이 기본으로 포함되어 있어요.

`git --version`으로 Git이 설치되어 있는지 확인할 수 있어요:

```
$ git --version
git version 2.31.1
```

정확한 버전이 똑같지 않아도 걱정 마세요. 보통 그렇게까지 중요한 건 아니에요.


### Wren Console 설치

#### Windows

가장 먼저 GitHub에서 [최신 릴리스][releases]를 내려받는 게 좋아요. 그다음 압축을 풀고 `wrenc` 실행 파일을 PATH에 복사해요.

Visual Studio를 사용해 [소스에서 빌드][build-from-source]할 수도 있어요.

#### Linux

GitHub에서 [최신 릴리스][releases]를 내려받거나 [소스에서 빌드][build-from-source]할 수 있어요.

```sh
wget -c https://github.com/joshgoebel/wren-console/releases/download/v0.3.1/wren-console-v0.3.1-linux.tar.gz
tar xzf wren-console-v0.3.1-linux.tar.gz
```

그리고 `PATH`에서 사용할 수 있는지 확인해요.

```sh
cp bin/wrenc /usr/local/bin/
```


#### Mac

가장 쉬운 설치 방법은 Exercism의 [Homebrew][homebrew] 탭과 포뮬러를 사용하는 거예요:

```
brew tap exercism/wren
brew install wren-console
```

또는 GitHub에서 [최신 릴리스][releases]를 내려받아 Linux 안내에 나온 대로 직접 설치할 수도 있어요. 이런 것에 익숙하다면 소스에서 빌드하는 것도 꽤 간단해요.

### 설치 테스트하기

바이너리를 제대로 설치했다고 생각되면, 모든 것이 잘 동작하는지 테스트해 보는 게 좋아요.

1. _터미널_을 열어요 (`Terminal`, `cmd`, `Powershell`, `bash`, ...)
2. `wrenc -v`를 실행해요

`wrenc`와 Wren 버전이 모두 나열되어야 해요:

```
wrenc v0.3.1 (wren v0.4.0)
```

**참고**: _새_ 터미널 창을 여는 것이 중요해요. 이미 열려 있는 터미널 창은 설치가 끝난 뒤에도 갱신되지 않았을 수 있어요. 즉, 열려 있는 터미널은 새 프로그램이 설치된 것을 모를 수 있어요.

> _**도움말**_: `'wrenc' is not recognised`
>
> `wrenc`를 PATH에 넣지 않은 것 같아요... MacOS와 Linux에서는 `~/.bash_profile`이나 `~/.zshrc`에 다음을 추가해서 PATH를 바꿀 수 있어요:
>
> ```bash
> export PATH=/path/to/your/wrenc/:$PATH
> ```
> **이 내용이 다 맞는지는 잘 모르겠어요.**
> Windows에서는 시작 메뉴를 열고 "environment variables"을 검색해요. `PATH` 항목을 편집해서 여기에 `wrenc` 바이너리 경로를 _추가_해야 해요. 보통 `C:\Program Files\nodejs`에 있어요. `File Explorer`로 여기를 열어 보면 `node.exe`, `npm.bat`, `npx.bat`을 찾을 수 있어요.
>
> 열려 있는 터미널을 모두 닫고 새로 하나 열어요.

## 연습 문제 요구 사항

운영체제에 맞는 `exercism` CLI를 내려받으려면 [이 안내][cli-walkthrough]를 따라 해 봐요.

CLI 설정이 모두 끝나면 첫 번째 연습 문제인 `hello-world`를 내려받아요:

```bash
$ exercism download --exercise=hello-world --track=wren
```

그다음 각 연습 문제에서 테스트를 실행하려면 몇 가지 Wren 패키지가 필요해요. 연습 문제 디렉터리 안에서 다음 명령을 실행하면 설치할 수 있어요:

```bash
$ wrenc package.wren install
```
