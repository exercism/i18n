# 지시 사항

바이올린은 기준음에 맞춰 귀로 조율해요. 현마다 음높이가 아주 멀리 떨어져 있고, 관련된 숫자도 정수가 아니에요.

다섯 가지 과제는 모두 `TUNING_THE_STRINGS` 클래스에 들어가요.

## 1. 한 옥타브 올리기

한 옥타브 높은 음은 주파수가 두 배예요.

```sather
TUNING_THE_STRINGS::octave_up(440.0d)
-- => 880.0d
```

## 2. 한 옥타브 내리기

한 옥타브 낮으면 절반이에요.

```sather
TUNING_THE_STRINGS::octave_down(440.0d)
-- => 220.0d
```

## 3. 중간 지점

두 주파수가 주어지면, 정확히 그 중간에 있는 주파수를 반환해요.

```sather
TUNING_THE_STRINGS::midpoint(440.0d, 442.0d)
-- => 441.0d
```

## 4. 얼마나 어긋났을까요?

두 음이 가깝지만 같지 않으면, 두 주파수가 차이 나는 사이클마다 1초에 한 번씩 맥놀이가 들려요. 두 주파수가 얼마나 떨어져 있는지 반환해요. 어느 음이 더 높든, 답은 절대 음수가 아니에요.

```sather
TUNING_THE_STRINGS::beats_per_second(441.5d, 440.0d)
-- => 1.5d
```

## 5. 연습 시간 나누기

몇 분의 시간과 몇 명의 연주자가 주어지면, 각자 몇 분씩 가질까요? 분과 연주자 수는 정수지만, 답은 정수가 아닐 수도 있어요.

```sather
TUNING_THE_STRINGS::minutes_each(45, 2)
-- => 22.5d
```
