# 소개

메서드는 특별한 _리시버_ 인자를 가진 함수예요.
리시버는 `func` 키워드와 메서드 이름 사이에 있는 별도의 인자 목록에 나타나요.

```go
func (receiver type) MethodName(parameters) (returnTypes) {

}
```

리시버의 타입이 메서드와 같은 패키지에 정의되어 있어야만 메서드를 정의할 수 있어요.

```go
type Person struct {
    Name string
}

func (p Person) Greetings() string {
	return fmt.Sprintf("Welcome %s!", p.Name)
}

s := Person{Name: "Bronson"}
fmt.Println(s.Greetings())
// Output: Welcome Bronson!
```

리시버에는 값 리시버와 포인터 리시버, 두 가지 종류가 있어요.

값 리시버를 사용하는 메서드는 전달받은 값의 복사본을 가지고 동작해요. 즉, 메서드 안에서 리시버를 수정해도 호출자에게는 보이지 않아요.

리시버가 가리키는 값을 수정하려면 포인터 리시버를 사용해 메서드를 선언할 수 있어요.
타입 이름 앞에 `*`를 붙이면 되는데, 예를 들어 `rect` 타입이라면 포인터 리시버는 `*rect`로 선언해요.
이런 수정은 메서드 호출자에게도 보여요.

```go
type rect struct {
	width, height int
}
func (r *rect) squareIt() {
	r.height = r.width
}

r := rect{width: 10, height: 20}
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 20

r.squareIt()
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 10

```
