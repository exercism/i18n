# 힌트

## 1. 준비 시간을 추정해요

- [`len()` 내장 함수][len-builtin]를 사용해서 레이어 개수(레이어 슬라이스의 길이)를 구해요.

## 2. 필요한 면과 소스의 양을 계산해요

- 먼저 면과 소스의 양을 추적할 변수 두 개를 만들어요.
- `for`문으로 레이어를 순회해요.
- 반복문에서 `'noodles'`나 `'sauce'` 레이어를 만나면, 각각의 변수에 저장된 양을 그에 맞게 늘려요.

## 3. 비밀 재료를 추가해요

- [슬라이스][concept-slices]를 다시 살펴보면서 슬라이스에서 원소를 가져오는 방법과 슬라이스의 원소를 바꾸는 방법을 알아봐요.
- 슬라이스 `a`에서 마지막 원소의 인덱스는 `len(a) - 1`이에요.

## 4. 레시피의 분량을 조절해요

- 먼저 입력 슬라이스와 같은 크기의 새 슬라이스를 만들어요
- [`for`문][for-loop]을 사용해서 입력 슬라이스를 순회하고 출력 슬라이스를 만들어요

[len-builtin]: https://pkg.go.dev/builtin#len
