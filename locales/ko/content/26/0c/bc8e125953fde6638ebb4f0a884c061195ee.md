# MoonScript 소개

MoonScript는 속도와 임베드 가능성으로 잘 알려진 인기 스크립팅 언어 [Lua][lua]를 더 간결하고 "친근하게" 다듬은 대안으로, [Leaf Corcoran][leafo]이 만들었어요. 흔히 "Lua를 위한 CoffeeScript"라고 불리는 MoonScript의 설계 철학은 가독성과 사용 편의성에 중심을 두고 있고, Lua의 핵심 강점은 그대로 지키면서 장황함을 줄이는 것을 목표로 해요. 이를 위해 자체 코드를 표준 Lua로 직접 트랜스파일하는데, 덕분에 Lua 인터프리터를 지원하는 플랫폼이라면 어디서든 실행할 수 있어요.

MoonScript의 주된 역할은 결국 Lua로 실행되는 코드를 더 우아하고 개발자 친화적인 문법으로 작성하게 해 주는 거예요. 클래스, 리스트 컴프리헨션, 테이블 조작을 위한 더 직관적인 문법처럼 Lua에 원래 없던 기능을 도입하죠. Lua로 컴파일되기 때문에 기존 Lua 라이브러리와 프레임워크의 방대한 생태계를 수정 없이 그대로 활용할 수 있어요. 즉, 현대적이고 표현력 있는 문법과 잘 자리 잡은 언어의 성능 및 이식성을 모두 얻는 셈이에요.

Lua 전처리기라는 성격 때문에 MoonScript는 Lua 자체가 쓰이는 여러 분야에서 똑같이 자리를 잡았어요. 특히 게임 개발에서 인기가 많고, LÖVE 2D나 Defold처럼 Lua로 스크립팅하는 게임 엔진 안에서 많이 쓰여요. 간결한 문법 덕분에 게임 로직을 더 빠르게 개발하고 더 쉽게 유지보수할 수 있죠. 게임 외에도 Lapis(MoonScript의 저자가 만든 프레임워크예요)나 OpenResty 같은 프레임워크와 함께 웹 개발에 쓰이고, 범용 스크립팅과 애플리케이션 개발에도 활용돼요.

MoonScript에 대해 더 알아보려면 공식 웹사이트인 [moonscript.org][moon]가 가장 좋은 출발점이에요. 커뮤니티는 주류 언어들보다 작지만 [GitHub][github]나 [Discord][discord] 같은 플랫폼에서 활발하게 활동하고 있어요. Lua에 익숙한 사람이라면 MoonScript의 문법이 직관적이고 배우기 쉽게 설계되어 있어서 전환이 대체로 매끄러워요.
