# 개요

Swift의 [클로저][closures]는 독립적인 코드 블록으로, 매개변수를 전달해 연산을 실행하고 값을 반환할 수 있어요.
클로저는 주변 환경의 값도 캡처해서 연산에 사용해요.
독립적이기 때문에 다른 값들처럼 프로그램 안에서 이리저리 전달되거나 상수와 변수에 할당될 수 있어요.

클로저는 Swift의 함수와 아주 비슷하게 들릴 텐데, 실제로 그렇고 그럴 만한 이유도 있어요.
Swift의 함수는 이름이 있어야 하고 조금 다른 문법으로 정의되는 특별한 형태의 클로저예요.

Swift의 함수도 엄밀히 말하면 클로저지만, 사람들이 Swift에서 "클로저"라고 할 때는 보통 [클로저 표현식][closure-expressions]을 가리켜요.
클로저 표현식은 매개변수 목록, 반환 타입, 그리고 `in` 키워드와 클로저 본문이 차례로 나오고, 전체가 중괄호 한 쌍으로 감싸인 형태로 작성해요:

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}
```

이 코드는 `(Double, Double) -> Double` 타입의 클로저 표현식을 정의해요.
이 타입의 함수와 비슷한 방식으로, 알맞은 타입의 매개변수에 적용해서 실행할 수 있어요:

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}(10.0, 15.0)
// returns 12.5
```

클로저를 실행할 때마다 전체 클로저 표현식을 매번 다 써 주는 건 그리 편하지 않아서, 클로저는 Swift의 다른 값들처럼 이름에 할당할 수 있어요.
그러면 그 이름에 매개변수를 적용해서 호출할 수 있어요:

```swift
let mean = { (a: Double, b: Double) -> Double in
  (a + b) / 2.0
}

mean(13.0, 100.0)
// returns 56.5
```

위에서 볼 수 있듯이, 클로저도 일반 함수처럼 본문이 하나의 표현식이면 `return` 키워드를 생략할 수 있어요.

클로저는 대개 고차 함수와 함께 사용하는데, 매개변수로 전달되거나 결과로 반환돼요:

```swift
[11, 75, 3, 99, 53].contains(where: { (x: Int) -> Bool in x > 100 })
// returns false

["apple", "ball", "carrot"].sorted(by: { (s1: String, s2: String) -> Bool in s1.count < s2.count })
// returns ["ball", "apple", "carrot"]

func makeAdder(base: Int) -> (Int) -> Int {
  { (x: Int) -> Int in base + x }
}
```

## 클로저 타입 추론하기

반환 타입이나 매개변수 타입을 [문맥에서 추론할 수 있을 때][inferring-closure-types]는 클로저 표현식에서 생략할 수 있어요.
또한 매개변수 타입을 생략할 수 있다면, 매개변수 이름을 감싸는 괄호도 생략할 수 있어요:

```swift
let mean: (Double, Double) -> Double = { a, b in a + b / 2.0 }

func makeAdder(base: Int) -> (Int) -> Int {
  { x in base + x }
}

["apple", "ball", "carrot"].sorted(by: { s1, s2 in s1.count < s2.count })
```

- 첫 번째 예제에서는 상수 `mean`에 붙은 타입 주석에서 타입을 추론할 수 있어요.
- 두 번째 예제에서는 컴파일러가 `makeAdder`의 정의로부터 `base`가 Int이고 반환되는 함수가 `(Int) -> Int` 타입이어야 한다는 걸 알아요. 거기서부터 `x`가 `Int`라면 클로저의 타입이 `(Int) -> Int`가 된다는 걸 확인할 수 있고, 따라서 클로저에서 타입 표기를 생략할 수 있는데, 클로저가 가질 수 있는 유일하게 유효한 표기가 `(Int) -> Int`이기 때문이에요.
- 세 번째 예제도 비슷하지만, 컴파일러가 메서드와 함께 사용되는 배열에서 타입 정보 일부를 가져와야 해요. 컴파일러는 `sorted(by:)` 메서드가, 정렬 대상 컬렉션의 원소와 같은 타입의 매개변수 두 개를 갖고 `Bool`을 반환하는 클로저를 매개변수로 받는다는 걸 알아요. 그래서 클로저의 반환 타입이 `Bool`이어야 한다는 걸 추론할 수 있어요. 그리고 이 메서드가 문자열 배열과 함께 사용되므로, 매개변수 `s1`과 `s2`의 타입이 둘 다 `String`이어야 한다는 것도 판단할 수 있어요.

## 클로저의 제약

위에서 언급했듯이 Swift에서 함수와 클로저는 아주 비슷하지만, 몇 가지 중요한 차이가 있어요:

- 클로저는 외부 인자 레이블을 사용할 수 없어요. 외부 인자 레이블을 정의할 방법이 없고, 클로저를 호출할 때 매개변수 이름을 사용하려고 하면 오류가 발생해요:

```swift
let add5 = { x in x + 5 }
add5(x: 10)
// Error: Extraneous argument label 'x:' in call
```

- 클로저의 매개변수에는 기본 매개변수 값을 지정할 수 없어요.
- 클로저의 매개변수는 가변 매개변수가 될 수 있지만, 이름과 타입 주석이 있어야 해요.
