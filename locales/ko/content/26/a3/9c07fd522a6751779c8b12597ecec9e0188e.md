# 안내

직업을 가진 거의 모든 사람이 그렇듯, Lisp 외계인 Layla도 때때로 다른 사람들에게 정보를 알리기 위해 보고서를 만들어야 할 때가 있어요. Layla는 이 보고서에 쓸 데이터의 서식을 맞추는 일을 도와줄 수 있겠냐고 물어요.

## 1. 분기별 값 서식 지정하기

Layla에게 가장 먼저 필요한 것은 `format-quarter-value`라는 함수예요. 이 함수는 두 개의 매개변수, 즉 달력 분기와 값을 받아서 보고서에 맞게 서식을 지정해요. 결과는 문자열로 평가되어야 해요.

```lisp
(format-quarter-value "last" 3.14) ; => "The value last quarter: 3.14"
(format-quarter-value "this" 0) ; => "The value this quarter: 0"
```

## 2. 두 분기 보고서

Layla는 `format-quarter-value` 함수에 고맙다고 하면서, *다음*에 필요한 함수에서 아주 유용하게 쓰일 거라고 말해요.

다음 보고서는 두 분기의 분기 이름과 값을 두 줄로 보여줘야 해요.

또한 출력은 첫 번째 인자로 주어지는 스트림으로 보내야 해요.

예를 들어 `(format-two-quarters t "last" 3.14 "this" 0)`는 표준 출력에 다음과 같이 출력해요:

```

The value last quarter: 3.14
The value this quarter: 0

```

앞뒤의 빈 줄에 유의해요.

## 3. 사람이 읽을 수 있는 형식과 Lisp 외계인이 읽을 수 있는 형식

Layla는 Lisp 외계인들이 값을 Lisp 데이터로 읽을 수 있는 방식으로 보는 걸 좋아한다는 점을 말해 주는 걸 잊었어요. 그래서 Lisp 데이터로 읽을 수 있는 새 함수가 필요해요 (이번에도 지정된 스트림으로요):

```lisp
(format-two-quarters-for-reading nil "last" 3.14 "this" 0) ; =>

"(\"The value last quarter: 3.14\" \"The value this quarter: 0\")"
```
