# 개요

메서드 매개변수에 기본값을 지정하면 해당 매개변수를 선택적으로 만들 수 있어요. 선택적 매개변수가 있는 메서드를 호출할 때, 호출자는 그 매개변수에 값을 전달하지 않아도 돼요. 선택적 매개변수에 값을 전달하지 않으면 기본값이 사용돼요.

선택적 매개변수는 매개변수 목록의 끝에 있어야 해요. 선택적 매개변수 뒤에 필수 매개변수가 올 수 없어요.

```haxe
class Card {
  static function newYear(year = 2021):String {
    return "Happy " + year;
  }
}

Card.newYear(); // Happy 2020
Card.newYear(1990); // Happy 1990
```

선택적 매개변수는 변수 이름 앞에 `?` 연산자를 사용해 `null`로 설정할 수 있어요:

```haxe
function newYear(?year:Int) {
  if (year != null)
    return "It's " + year;
  return "Year is null";
}

newYear(); // Year is null
```
