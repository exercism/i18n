# 개요

Gleam에서 값에 대해 패턴 매칭을 할 때는, 패턴이 그 타입이 가질 수 있는 모든 값을 처리하도록 해야 해요. 그렇지 않으면 코드가 컴파일되지 않아요.

다음 함수는 배열이 비어 있는 경우를 처리하지 않았으므로 거부돼요:

```gleam
pub fn get_first_element_or_crash(items: List(e)) -> e {
  case items {
    [item, ..] -> item
  }
}
```

대부분의 Gleam 프로그램에서는 가능한 모든 경우를 처리하고 싶어 해요. 하지만 프로토타입이나 간단한 스크립트처럼 일부 프로그램에서는 정상 경로에만 집중하고 나머지 경우에 대한 코드는 작성하지 않고 싶을 때가 있어요. 이럴 때 필요한 것이 바로 Gleam의 `let assert`이에요.

let 어서션을 사용하면 패턴이 타입이 가질 수 있는 값 중 일부만 일치해도 되고, 값이 패턴과 일치하지 않으면 프로그램이 멈춰요. `let assert`를 사용하면 위 함수를 이렇게 작성할 수 있어요:

```gleam
pub fn get_first_element_or_crash(items: List(e)) -> e {
  let assert [item, ..] = items
  item
}
```

Gleam 라이브러리에서는 프로그램이 멈출 수 있기 때문에 let 어서션을 절대 사용하면 안 돼요. 대신 `Result` 타입을 사용하고, 오류 처리는 애플리케이션 개발자가 결정하도록 해야 해요.
