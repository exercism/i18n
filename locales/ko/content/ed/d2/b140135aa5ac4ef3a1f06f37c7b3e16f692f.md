# 개요

[switch 문][switch]을 사용하면 값을 여러 가지 가능한 값과 비교할 수 있어요.
`else-if` 문을 여러 개 사용하는 것보다 더 간결한 코드를 작성할 수 있죠.
switch 문은 `switch` 키워드로 시작하고, 바로 뒤에 비교할 값이 와요.
그다음에는 `case` 키워드 뒤에 비교 대상 값을 적어 각 경우를 정의할 수 있어요.
`default` 키워드는 일치하는 경우가 하나도 없을 때 사용할 기본 경우를 정의해요.
`else-if` 문과 마찬가지로 `switch` 문도 처음 일치하는 경우에 해당하는 코드 블록만 실행해요.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

다음 예시를 살펴봐요:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

이 코드는 대신 이렇게 쓸 수도 있어요:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```
