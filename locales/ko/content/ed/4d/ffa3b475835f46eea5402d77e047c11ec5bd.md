# 지침

현악 그룹이 연주회를 열게 됐는데, 프로그램을 쓸 사람이 필요해요.

다섯 과제는 모두 `PROGRAMME_NOTES` 클래스에서 해결해요.

## 1. 곡과 작곡가의 이름 적기

곡을 먼저 쓰고, 그다음 ` by `를 쓰고, 마지막으로 작곡가를 써요.

```sather
PROGRAMME_NOTES::full_title("Nocturne", "Chopin")
-- => "Nocturne by Chopin"
```

## 2. 줄의 길이 재기

인쇄기는 줄이 얼마나 긴지 알아야 해요.

```sather
PROGRAMME_NOTES::title_length("Nocturne")
-- => 8
```

## 3. 앞부분의 몇 글자

제목과 숫자가 주어지면, 앞에서부터 그 숫자만큼의 글자를 반환해요.

```sather
PROGRAMME_NOTES::opening_letters("Nocturne", 3)
-- => "Noc"
```

## 4. 뒷부분의 몇 글자

같은 방식으로, 이번에는 끝에서부터 세어요.

```sather
PROGRAMME_NOTES::closing_letters("Nocturne", 4)
-- => "urne"
```

## 5. 긴 제목 줄이기

들어가지 않는 제목은 앞의 여섯 글자만 남기고 잘라낸 뒤, 마침표 세 개를 붙여요.

```sather
PROGRAMME_NOTES::short_title("Nocturne in E flat")
-- => "Noctur..."
```
