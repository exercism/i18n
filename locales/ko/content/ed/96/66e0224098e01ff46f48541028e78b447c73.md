# 소개

[Clojure](http://clojure.org)는 Java Virtual Machine (JVM)을 대상으로 하는 동적 프로그래밍 언어예요. 범용 언어로 설계된 Clojure는 스크립트 언어의 친근함과 멀티스레드 프로그래밍을 위한 견고한 기반을 함께 갖추고 있어요.

Clojure는 주로 함수형 프로그래밍 언어이며, 불변이면서 영속적인 [자료 구조](http://clojure.org/data_structures)를 풍부하게 제공해요.

Clojure는 오픈 소스이며, 언어에 기여하는 방법은 [여기에서 확인할 수 있어요](http://clojure.org/contributing).

Clojure를 만든 Rich Hickey는 함수형 프로그래밍을 위한 현대적인 Lisp을 원했어요. 이미 자리 잡은 Java 플랫폼과 공생하고, 동시성을 염두에 두고 설계된 Lisp 말이에요. 그렇게 Clojure가 탄생했어요.

Clojure의 목표를 잘 보여 주는 두 개의 인용구를 살펴봐요.

* _좋은 설계는 거창한 계획을 세우는 일이 아니라, 하나씩 분해해서 들여다보는 일이에요._
* _프로그래밍은 타이핑하는 일이 아니라... 생각하는 일이에요._
