# 지침

숲속에 산책로를 표시하는 중이에요. 거리와 관찰 기록은 모두 시퀀스로 주어져요. 그래서 둘 다 이터레이터예요.

네 가지 모두 `BUSH_WALK` 클래스에 들어가요. 전부 이터레이터라서 이름이 모두 `!`로 끝나요.

## 1. 이정표

`markers!`는 미터 단위의 간격과 개수를 받아서, 시작점에서 각 이정표까지의 거리를 내놓아요.

```sather
loop
   #OUT + BUSH_WALK::markers!(100, 3) + " ";
end;
-- 100 200 300
```

개수가 0이면 아무것도 내놓지 않아요.

## 2. 산책로가 끝날 때까지

`until_end!`는 산책로를 따라 관찰한 기록을 받아서, `"end"`라는 값을 만나면 멈추고 하나씩 내놓아요. `"end"` 자체는 내놓지 않아요.

```sather
loop
   #OUT + BUSH_WALK::until_end!(|"gum", "wattle", "end", "banksia"|) + " ";
end;
-- gum wattle
```

`"end"`라는 값이 없으면 전부 내놓아요.

## 3. 새만

`birds!`는 관찰 기록을 받아서, 대문자로 시작하는 것만 내놓아요. 이 조사에서는 새를 그렇게 적거든요.

```sather
loop
   #OUT + BUSH_WALK::birds!(|"gum", "Emu", "wattle", "Galah"|) + " ";
end;
-- Emu Galah
```

## 4. 번호 매기기

`numbered!`는 관찰 기록을 받아서, 1부터 세어 각 항목 앞에 위치를 붙여 내놓아요.

```sather
loop
   #OUT + BUSH_WALK::numbered!(|"gum", "Emu"|) + " ";
end;
-- 1. gum 2. Emu
```
