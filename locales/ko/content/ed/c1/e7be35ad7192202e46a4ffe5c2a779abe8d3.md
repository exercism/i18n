# 소개

모든 Common Lisp 코드는 S-Expression(Symbolic Expression)으로 이루어져 있어요. 줄여서 sexpr이라고 불러요. 모든 sexpr은 atom이거나 cons예요. S-Expression이 평가되면, 그 표현식을 대신하는 어떤 값이 자동으로 반환돼요. `defun`을 사용해 직접 함수를 작성할 때는, `defun` 본문의 마지막 값이 자동으로 반환돼요:

```lisp
;; Defining a new function
(defun gimme-foo () 'foo)
;; Calling the function as an S-Expression
(gimme-foo) ; => FOO
```
