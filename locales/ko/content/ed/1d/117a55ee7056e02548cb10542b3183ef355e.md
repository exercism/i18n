# 소개

Elixir에서 함수는 일급 시민으로 취급돼요. 이는 다음과 같은 뜻이에요:

- 이름 있는 함수와 익명 함수를 변수에 할당할 수 있어요.
- 이름 있는 함수와 익명 함수를 데이터처럼 인자와 반환값으로 주고받을 수 있어요.
- 익명 함수를 동적으로 만들 수 있어요.

익명 함수는 이름 있는 함수와 달리 고정된 참조가 없어요. 변수에 할당하거나 즉시 호출할 때만 사용할 수 있어요.

익명 함수는 다음과 같은 경우에 사용해요:

- 렉시컬 스코프(클로저라고도 해요)를 사용해 데이터를 감출 때.
- 런타임에 함수를 동적으로 만들 때.

익명 함수는 예약어 `fn`으로 시작하고, 매개변수는 `->` 토큰으로 함수 본문과 구분하며, `end`로 끝나요. 이름 있는 함수와 마찬가지로, 함수의 마지막 표현식은 호출한 함수에 _암묵적으로 반환_돼요.

함수 참조를 호출하려면 참조 변수와 인자 목록 사이에 `.`을 사용해야 해요:

```elixir
function_variable = fn param ->
  param + 1
end

function_variable.(1)
# => 2
```

축약 캡처 표기법을 사용하면 훨씬 더 간결하게 만들 수도 있어요:

```elixir
variable = &(&1 + 1)

variable.(1)
# => 2
```
