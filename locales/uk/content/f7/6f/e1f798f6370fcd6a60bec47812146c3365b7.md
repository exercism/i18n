# Тести

Щоб запустити тести, виконайте такі кроки:

- Перейдіть до каталогу вправи (наприклад, `~/Exercism/hello-world`).
- Запустіть сеанс `jconsole` (наприклад, набравши `jconsole` або `ijconsole`) у терміналі.
- Завантажте файл зі своїм рішенням (наприклад, `load 'hello-world.ijs'`)
- Завантажте framework для модульних тестів, набравши `load  'general/unittest'`
- Перевірте своє рішення, набравши `unittest 'test.ijs'`.
<br></br>
- Або можна запустити тести одним рядком ось так: `jconsole -js "load 'hello-world.ijs'" "echo unittest 'test.ijs'" "exit 0"`.

## Пропущені тести

Спочатку буде увімкнено лише початковий тест.
Підхід заохочує нас розвʼязувати вправу крок за кроком.
Кожен тест містить іменник над своїм визначенням, назва якого закінчується на _'\_ignore'_.
Щоб запустити тест, змініть його значення на 0.

### Приклад:

```
    leap_test_02_ignore=: 1 NB. Change this value to 0 to run this test
    test_leap_test_02  =: monad define
    ...                     NB. test definitions
    )
```
