# Вступ

Go надає вбудований пакет `fmt` (пакет форматування), який пропонує різноманітні функції для роботи з форматом вхідних і вихідних даних.
Найуживаніша функція - `Sprintf`: вона використовує _дієслова_ на кшталт `%s`, щоб підставити значення в рядок тексту (англ. string), і повертає цей рядок.

```go
import "fmt"

food := "taco"
fmt.Sprintf("Bring me a %s", food)
// Returns: Bring me a taco
```

У Go числа з плаваючою комою зручно форматувати дієсловами `Sprintf`: `%g` (компактне подання), `%e` (з експонентою) або `%f` (без експоненти).
Усі три дієслова дають змогу керувати шириною поля та точністю числа.

```go
import "fmt"

number := 4.3242
fmt.Sprintf("%.2f", number)
// Returns: 4.32
```

Повний список доступних дієслів можна знайти в [документації пакета форматування][fmt-docs].

`fmt` містить й інші функції для роботи з рядками тексту, зокрема `Println`, яка просто виводить отримані аргументи в консоль, і `Printf`, яка форматує вхідні дані так само, як `Sprintf`, а вже потім виводить їх.

[fmt-docs]: https://pkg.go.dev/fmt
