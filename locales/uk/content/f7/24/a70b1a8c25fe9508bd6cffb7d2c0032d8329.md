# Вступ

## Регулярні вирази в JavaScript

[Регулярний вираз][mdn-regular-expressions] (або regex) - це послідовність символів, за допомогою якої ми можемо знаходити й опрацьовувати певні елементи в рядках тексту (англ. string). Отже, ми можемо:

- **Шукати** текст у рядку
- **Замінювати** підрядки в рядку
- **Видобувати** інформацію з рядка

> 💡 Реалізація регулярних виразів у JavaScript є частиною стандарту ECMA-262 для цієї мови. Це означає, що нам не потрібно хвилюватися про сумісність із конкретним браузером.

## Як створювати регулярні вирази

У JavaScript регулярний вираз здебільшого записують у форматі `/pattern/modifiers`.

Є два способи створити регулярний вираз:

1. **Літерал регулярного виразу**:

```javascript
const regex = /[a-z]/;
```

2. Конструктор **RegExp**:

```javascript
const regex = new RegExp('[a-z]');
```

В обох випадках JavaScript створює з регулярного виразу обʼєкт. Радимо використовувати незмінні шаблони, а за типовий варіант брати літеральний запис.

Конструктор RegExp стане в пригоді тоді, коли регулярний вираз змінюється або коли ми ще не знаємо його наперед (наприклад, коли він залежить від введених даних).

## 🏴‍☠️ Прапорці

У регулярних виразів є необовʼязкові суперсили, які називають [`flags`][mdn-flags] і які дають додаткові можливості.

Ось деякі з найуживаніших:

- `/g` - глобальний пошук
- `/i` - нечутливість до регістру
- `/m` - багаторядковий пошук

Ось простий приклад:

```javascript
const re = /home/gi;
const str = 'Home, sweet home.';
const myArray = str.match(re);
console.log(myArray);

// => ["Home", "home"]
```

Символ `g` дозволяє знайти всі можливі збіги в рядку тексту. Без цієї можливості JavaScript видобув би лише перший збіг `Home`.

Прапорець нечутливості до регістру `/i` робить нас гнучкішими, коли ми шукаємо закономірність. Завдяки йому неважливо, у якому регістрі те, що ми шукаємо: `UPPERCASE` чи `lowercase`.

Коли ми використовуємо конструктор `RegExp`, синтаксис додавання прапорців інший.

```javascript
let regex = /[a-z]/gi; // literal notation
let regex = new RegExp('[a-z]', 'gi'); // constructor with string pattern as first argument
let regex = new RegExp(/[a-z]/, 'gi'); // constructor with regular expression literal as first argument (Starting with ECMAScript 6)
```

## Найпоширеніші функції

Коли ми поєднуємо регулярні вирази з вбудованими функціями JavaScript, ми отримуємо потужні способи опрацьовувати рядки тексту й діставати з них дані.

Ось кілька найпоширеніших функцій, які використовують разом із регулярними виразами.

### Test

Метод [test()][mdn-regex-test]] виконує пошук збігу між регулярним виразом і заданим рядком тексту. Повертає правду або неправду.

```javascript
const str = 'It is difficult to test if you have a virus';
const result = /virus$/.test(str);

console.log(result);

// => true
```

### Match

За допомогою методу [match()][mdn-regex-match] ми отримуємо корисний масив, вміст якого залежить від того, чи були знайдені збіги.

Так ми можемо і **шукати**, і **видобувати** інформацію з будь-якого рядка тексту. Наприклад:

```javascript
const funnyQuote =
  'If you see someone crying, ask if it is because of their haircut.';
const regex1 = /someone/;
const regex2 = /happy/;

funnyQuote.match(regex1);
// => ["someone", index: 3, input: "If you see someone crying, ask if it is because of their haircut.", groups: undefined]

funnyQuote.match(regex2);
// => null
```

Коли присутній прапорець глобального пошуку `/g`, метод повертає не єдиний збіг разом із корисною інформацією, як-от індекс чи вхідні дані, а всі знайдені входження у вигляді масиву:

```javascript
const funnyQuote =
  'If you see someone crying, ask if it is because of their haircut.';

const regex3 = /if/gi;

funnyQuote.match(regex3);
// => ["If", "if"];
```

### Replace

Метод [replace()][mdn-regex-replace] у JavaScript дає змогу знайти значення в заданому рядку тексту й замінити його на потрібне нове значення.

```javascript
string.replace(searchValue, newValue);
```

Те, що ми шукаємо для заміни, може бути як окремим рядком тексту, так і регулярним виразом.

```javascript
let string = 'I like dogs!';
let result = string.replace('dogs', 'cats');

let string = 'I would love to travel to Japan';
let result = string.replace(/Japan/g, 'Hawaii');
```

Крім того, на місце заміни ми можемо передати функцію, щоб додатково змінити кожне значення.

```javascript
let text = 'Say hello to the chatbot.';
let result = text.replace(/chatbot|hello/gi, function (word) {
  return word.toUpperCase();
});

// => "Say HELLO to the CHATBOT"
```

### Split

Метод [split()][mdn-regex-split] у JavaScript - це інший спосіб використовувати регулярні вирази для роботи з рядками тексту.

Так ми використовуємо регулярні вирази, щоб розділити заданий рядок тексту за розпізнаною закономірністю, наприклад `str.split(/[,.\s]/)`. Ця закономірність буде виступати в ролі `separator`.

```javascript
const str = 'hello,user.how are.you';

const result = str.split(/[,.\s]/);

console.log(result);
// => ['hello', 'user', 'how', 'are', 'you']
```
