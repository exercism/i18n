# Інструкції

Ми працюємо асистентом викладача й перевіряємо студентські екзамени.
Вручну відстежувати результати стає і нудно, і легко припуститися помилки.
Ми вирішуємо трохи урізноманітнити це й створити кілька функцій, щоб рахувати та обчислювати результати для класу.

## 1. Округлення оцінок

Хоча за окремі питання екзамену можна давати «частковий бал», підсумкові оцінки за екзамен мають бути `int`.
Тож перш ніж робити будь-що інше з оцінками класу, потрібно перебрати всі бали й перетворити будь-які оцінки `float` на `int`. На щастя, у Python є вбудована функція [`round()`][round], яку можна використати.

Створіть функцію `round_scores(student_scores)`, яка приймає `list` оцінок `student_scores`.
Ця функція має _спожити_ вхідний `list` і `return` новий список, у якому всі оцінки перетворено на `int`.
Порядок оцінок у отриманому `list` не важливий.

```python
>>> student_scores = [90.33, 40.5, 55.44, 70.05, 30.55, 25.45, 80.45, 95.3, 38.7, 40.3]
>>> round_scores(student_scores)
...
[40, 39, 95, 80, 25, 31, 70, 55, 40, 90]
```

## 2. Студенти, які не склали

Перевіряючи екзамен, ми помітили, що деякі студенти впоралися гірше, ніж сподівалися.
Але ми відволіклися й забули записати, _скільки саме_ студентів.

Створіть функцію `count_failed_students(student_scores)`, яка приймає `list` оцінок `student_scores`.
Ця функція має порахувати кількість студентів, які не мають прохідного балу, і повернути цю кількість як ціле число.
Щоб отримати прохідний бал на екзамені, студентові потрібна оцінка, більша за **40**.

```python
>>> count_failed_students(student_scores=[90,40,55,70,30,25,80,95,38,40])
5
```

## 3. «Найкращі»

Викладач, якому ми допомагаємо, хоче знайти групу студентів, які показали «найкращий» результат на цьому екзамені.
Те, що вважається «найкращим», постійно змінюється, тож потрібно знайти оцінки студентів, які є **більшими або рівними** поточному порогу.

Створіть функцію `above_threshold(student_scores, threshold)` з параметрами `student_scores` (`list` оцінок) і `threshold` (поріг «найвищого балу»).
Ця функція має повернути `list` усіх оцінок, які є `>=` за `threshold`.

```python
>>> above_threshold(student_scores=[90,40,55,70,30,68,70,75,83,96], threshold=75)
[90,75,83,96]
```

## 4. Обчислення літерних оцінок

Викладач, якому ми допомагаємо, любить ставити не лише числові оцінки, а й літерні.
Оскільки студенти рідко набирають 100 на екзамені, нижні пороги для «літерних оцінок» обчислюють на основі найвищої досягнутої оцінки, і вони рівномірно зростають між найвищою оцінкою та порогом невдачі **<= 40**.

Створіть функцію `letter_grades(highest)`, яка приймає «найвищу» оцінку на екзамені як аргумент і повертає `list` нижніх порогів для кожного інтервалу оцінок «американського стилю»: `["D", "C", "B", "A"]`.


```python
"""Where the highest score is 100, and failing is <= 40.
       "F" <= 40
 41 <= "D" <= 55
 56 <= "C" <= 70
 71 <= "B" <= 85
 86 <= "A" <= 100
"""

>>> letter_grades(highest=100)
[41, 56, 71, 86]


"""Where the highest score is 88, and failing is <= 40.
       "F" <= 40
 41 <= "D" <= 52
 53 <= "C" <= 64
 65 <= "B" <= 76
 77 <= "A" <= 88
"""

>>> letter_grades(highest=88)
[41, 53, 65, 77]
```

## 5. Зіставлення імен з оцінками

У нас є список оцінок за екзамен у спадному порядку та ще один список імен студентів, також відсортований у спадному порядку за їхніми оцінками.
Ми хочемо зіставити кожне імʼя студента з його оцінкою та вивести загальний рейтинг класу.

Створіть функцію `student_ranking(student_scores, student_names)` з параметрами `student_scores` і `student_names`.
Зіставте кожне імʼя зі `list` `student_names` з його оцінкою зі `list` `student_scores`.
Можна припустити, що кожен аргумент `list` буде відсортований від найвищої оцінки до найнижчої.
Функція має повернути `list` рядків тексту у форматі `<rank>. <student name>: <student score>`.

```python
>>> student_scores = [100, 99, 90, 84, 66, 53, 47]
>>> student_names =  ['Joci', 'Sara','Kora','Jan','John','Bern', 'Fred']
>>> student_ranking(student_scores, student_names)
...
['1. Joci: 100', '2. Sara: 99', '3. Kora: 90', '4. Jan: 84', '5. John: 66', '6. Bern: 53', '7. Fred: 47']
```

## 6. «Ідеальна» оцінка

Хоча «ідеальна» оцінка 100 на екзамені трапляється рідко, цікаво знати, чи досяг її хоч один студент.

Створіть функцію `perfect_score(student_info)` з параметром `student_info`.
`student_info` містить `list` списків з іменем та оцінкою кожного студента: `[["Charles", 90], ["Tony", 80]]`.
Функція має `return` _першу_ пару `[<name>, <score>]` студента, який набрав 100 на екзамені.

Якщо в `student_info` немає оцінок 100, потрібно повернути порожній список `[]`.

```python
>>> perfect_score(student_info=[["Charles", 90], ["Tony", 80], ["Alex", 100]])
["Alex", 100]

>>> perfect_score(student_info=[["Charles", 90], ["Tony", 80]])
[]
```

[round]: https://docs.python.org/3/library/functions.html#round
