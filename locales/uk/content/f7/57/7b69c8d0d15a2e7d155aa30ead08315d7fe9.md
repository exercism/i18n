# Інструкції

Ми ведемо онлайн-бутік модного одягу. Кожен товар в асортименті - це масив із двох елементів `{ name price }`, а весь асортимент - це масив товарів.

Відсутню ціну записано як `f`.

## 1. Відсортувати асортимент за ціною

Визначмо `sort-by-price`, яка повертає новий масив із товарами, відсортованими за ціною за зростанням.

```factor
{ { "Maxi Brown Dress" 65 } { "Red Skirt" 50 } { "Bamboo Socks Cats" 20 } }
sort-by-price .
! => { { "Bamboo Socks Cats" 20 } { "Red Skirt" 50 } { "Maxi Brown Dress" 65 } }
```

## 2. Знайти товари без ціни

Визначмо `with-missing-price`, яка повертає масив лише з тих товарів, ціна яких дорівнює `f`.

```factor
{ { "Black T-shirt" 40 } { "Denim Pants" f } { "Orange T-shirt" 40 } }
with-missing-price .
! => { { "Denim Pants" f } }
```

## 3. Порахувати дорогі товари

Визначмо `expensive-items`, яка приймає асортимент і ціновий поріг та повертає кількість товарів, що коштують суворо більше за поріг.

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } { "Dress" 80 } }
50 expensive-items .
! => 2

{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } { "Dress" 80 } }
0 expensive-items .
! => 4
```

## 4. Знайти найдешевший товар

Визначмо `cheapest-item`, яка повертає товар із найнижчою ціною. Товарів без ціни (`f`) у вхідних даних не буде.

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } } cheapest-item .
! => { "Hat" 25 }
```

## 5. Підсумувати всі ціни

Визначмо `total-price`, яка повертає суму всіх цін. Товарів без ціни (`f`) у вхідних даних не буде.

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } } total-price .
! => 195
```

## 6. Відформатувати товар як цінник

Визначмо `format-price-tag`, яка повертає рядок тексту (англ. string) виду `"name: $price"` для товару. Товарів без ціни (`f`) тут не буде.

```factor
{ "Skirt" 50 } format-price-tag .
! => "Skirt: $50"
```
