# Вступ

## Власні типи

[Власні типи][custom-types] в Elm представляють фіксовану кількість іменованих варіантів. Кожне значення відповідає рівно одному з іменованих варіантів.

Власні типи визначають за допомогою ключового слова `type`, і для цього потрібно дуже мало синтаксису. Це одна з найважливіших технік у програмуванні мовою Elm, і їх використовують, щоб можливі значення в коді точно збігалися з припустимими значеннями в реальному житті, що не залишає місця для некоректних даних і робить [неможливі стани такими, які неможливо подати в коді][impossible-states].

```elm
type Season
    = Spring
    | Summer
    | Autumn
    | Winter
```

Кожен варіант власного типу може необовʼязково мати повʼязані з ним дані, і різні варіанти можуть мати різні типи даних. Якщо жоден із варіантів не має повʼязаних даних, дискриміноване обʼєднання подібне до того, що в інших мовах зазвичай називають _переліком_ (або _enum_).

```elm
type FlexibleNumber
    = Integer Int
    | Float Float
    | Invalid
```

Створити значення для конкретного варіанта можна, звернувшись до його назви (`Spring`), якщо його визначено в тому самому модулі або імпортовано за допомогою синтаксису стилю `import SeasonModule exposing (Season(..))`, або звернувшись до його повністю кваліфікованого імені (`Season.Spring`), якщо його імпортовано за допомогою синтаксису стилю `import SeasonModule exposing (Season)`.

```elm
integerTwo = Integer 2
invalid = FlexibleNumber.Invalid
```

Власні типи, як і все в Elm, мають _структурну рівність_, що означає, що два значення для одного й того самого варіанта з однаковими (необовʼязковими) даними є еквівалентними.

Щоб працювати з власними типами, найкраще використовувати [зіставлення зі зразком][pattern-matching]:

```elm
let describe flexibleNumber =
    case flexibleNumber of
        Integer i ->
            "Integer: " ++ fromInt(i)

        Float f ->
            "Float: " ++ fromFloat(f)

        Invalid   ->
            "Invalid"
```
