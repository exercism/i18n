# Вступ

Пригадаймо з концепту «Основи»: програма AWK складається з **пар «pattern-дія»**.

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

## Що ми маємо на увазі під «pattern»?

«Pattern» - це будь-який вираз AWK.
Істинність результату виразу визначає, чи буде виконано дію.

## Порожній pattern

Pattern можна опустити.
У цьому випадку дія виконується для кожного запису.

Ми можемо вивести всі імена користувачів із файлу passwd.

```sh
awk -F: '{print $1}' /etc/passwd
```

## Регулярні вирази

AWK може порівнювати рядки тексту (англ. string) з регулярними виразами, щоб отримати булеве значення (англ. Boolean).

Використаймо оператор зіставлення з регулярним виразом `~`, щоб зіставити конкретне поле. 
Цей оператор приймає рядок тексту як лівий операнд, а регулярний вираз як правий операнд.
Літерал регулярного виразу беруть у похилі риски `/`.

Щоб знайти у файлі passwd користувачів, які входять за допомогою bash:

```sh
awk -F: '$7 ~ /bash/ {print $1}' /etc/passwd
```

`!~` - це оператор «регулярний вираз **не** збігається».

Щоб зіставити регулярний вираз із поточним записом, можна написати `$0 ~ /regex/`.
Це настільки поширено, що існує скорочена форма: можна опустити `$0` і `~` та просто написати `/regex/`.

```sh
awk '/regex/' data.txt
```

~~~~exercism/note
Порівняймо цей однорядковий вираз AWK з еквівалентною командою grep

```sh
grep 'regex' data.txt
```

AWK дає нам цілу мову програмування, не жертвуючи стислістю.
~~~~

## Вирази

Вирази AWK (арифметичні, логічні чи будь-які інші) можна використовувати як pattern.

Щоб вибрати всіх користувачів з UID 1000 або вище:

```sh
awk -F: '$3 >= 1000' /etc/passwd
```

Пригадаймо, що хибними значеннями в AWK є число нуль і порожній рядок тексту, а всі інші числа чи рядки тексту є істинними.
Будь-який вираз, що обчислюється в число або рядок тексту, можна використати як pattern.

## Функції

Будь-яку [вбудовану][builtins] чи [визначену користувачем][user-defined] функцію можна використати у виразі, а отже, і в pattern.
Кілька прикладів:

```awk
length($1) {print "first field is not empty"}
```
```awk
toupper(substr($1, 1, 1)) ~ /[AEIOU]/ {print "starts with a vowel"}
```

## Сталі pattern

Поширений ідіом AWK такий:

```sh
{
    xyz()   # some code that transforms each record
}
1
```

`1` - це істинний pattern без повʼязаної дії.
Це означає «вивести поточний запис».
