# Додаток до інструкцій

## Формат дошки

Дошка представлена як рядок тексту (англ. string), завершений нульовим символом, де кожен рядок закінчується символом нового рядка.

Приклад: `"X  \n XO\nOX \n"`

## Регістри

| Регістр | Використання        | Тип    | Опис                                                             |
| -------- | ------------ | ------- | ----------------------------------------------------------------------- |
| `$a0`    | вхідні дані        | адреса | рядок тексту, завершений нульовим символом                                            |
| `$v0`    | вихідні дані       | ціле число | стан гри (`1` = `ongoing`, `2` = `draw`, `3` = `win`, `-1` = `error`) |
| `$t0-9`  | тимчасовий    | будь-який     | для тимчасового зберігання                                                   |
