# Встановлення

## Встановлення tclsh

Єдиний потрібний інструмент - інтерпретатор TCL, `tclsh`.

Для Windows найкраще отримати Tcl з [інсталятора Tcl від Magicsplat][magicsplat].

У MacOS та Unix-подібних операційних системах `tclsh` уже буде встановлено.
Зазвичай встановлена версія - 8.6.*щось*.
Щоб установити поточну стабільну версію 9.0:
 - у MacOS скористайтеся [Homebrew][brew].
 - у Linux перевірте свій менеджер пакетів.
 - або [завантажте вихідний код][download] і [зберіть його][build].

Для розвʼязування вправ через вебінтерфейс Exercism тест-раннер (станом на лютий 2023 року) використовує Tcl версії 8.7a4.

## Робота з інтерактивною оболонкою tclsh

Часто ми запускаємо інтерактивний сеанс [`tclsh`][tclsh], щоб перевіряти команди під час написання коду.
Однак tclsh надає лише дуже простий інтерпретатор REPL без редагування командного рядка чи історії команд.
Для кращого досвіду існує програма `rlwrap`, яка додає функціональність readline:

```bash
rlwrap tclsh
```

Щоб установити rlwrap:
 - у MacOS скористайтеся [Homebrew][brew].
 - у Linux перевірте свій менеджер пакетів.
 - або [завантажте вихідний код][rlwrap-download] і [зберіть його][rlwrap-build].

Це настільки зручно, що захочеться використовувати його завжди: додайте це до свого ~/.bashrc

```bash
command -v rlwrap && alias tclsh='rlwrap tclsh'
```

## Яку версію використовувати?

Поточна стабільна версія - 9.0.
Як зазначено вище, версія 8.6 усе ще широко розгорнута.

Перевірити, яку версію `tclsh` у нас встановлено, можна, виконавши таку команду:

```bash
echo 'puts [info patchlevel]' | tclsh
```
