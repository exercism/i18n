# Вступ

Clojure використовує базовий тип `java.lang.Character`, який являє собою 16-бітну величину для подання найменших адресовних компонентів тексту.
Кілька `char` можуть утворювати рядок тексту (англ. string), як-от `"word"`, або ж `char` можна обробляти окремо. Їхні літерали записуються так: `\a \b \c`.

`char` у Clojure підтримують кодування UTF-16 Unicode, тож, крім латинського набору символів, можна подати практично всі системи письма, які використовуються у світі, наприклад грецьку літеру `'β'`.

Існує багато методів бібліотеки для вивчення та обробки `char`. До них можна звертатися через інтероп як до методів класу `Character`. Clojure також містить вбудовану бібліотеку для роботи з рядками тексту, `clojure.string`, яка пропонує багато потужних функцій для роботи із символами.
