# Вступ

Масиви ключових слів - це структура даних «ключ-значення».

```elixir
[month: "April", year: 2018]
```

Масиви ключових слів - це масиви кортежів `{key, value}`, і їх також можна записати в такому вигляді, але коротший синтаксис уживається частіше.

```elixir
[month: "April"] == [{:month, "April"}]
# => true
```

Ключами в масиві ключових слів мають бути [атоми][exercism-atoms], а значеннями може бути будь-що. Кожен ключ можна використати більше ніж один раз. Пари ключ-значення в масиві ключових слів упорядковані.

З масивами ключових слів можна працювати так само, як із масивами, або скористатися модулем `Keyword`.

[exercism-tuples]: https://exercism.org/tracks/elixir/concepts/tuples
[exercism-atoms]: https://exercism.org/tracks/elixir/concepts/atoms
