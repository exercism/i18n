# Перевірка golint не пройдена

Є чудовий інструмент [`golint`](https://github.com/golang/lint), який перевіряє код на поширені проблеми та недоліки стилю.
Запустіть `golint` для свого рішення, наприклад: `golint two_fer.go`; він дасть кілька корисних порад.

Гарна ідея - завжди перевіряти код за допомогою `golint`.
Коли ми створюємо програмне забезпечення на Go для продакшену, багато конвеєрів збірки автоматично завершуються помилкою, якщо код не проходить `golint`.

Якщо хочеться отримати значно більше відгуків від лінтерів коду, є проєкт [golangci-lint](https://github.com/golangci/golangci-lint),
який дозволяє запустити багато лінтерів однією командою.
Файл конфігурації проєкту може налаштувати поведінку під його потреби.

```
> golint
%{golint}
```
