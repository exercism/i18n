# Вступ

## Рядки тексту

`string` у C# - це обʼєкт, який представляє незмінний рядок тексту (англ. string) як послідовність символів Unicode (літер, цифр, розділових знаків тощо). Для створення примірника `string` використовують подвійні лапки:

```csharp
string fruit = "Apple";
```

### Методи

Рядки тексту опрацьовують, викликаючи їхні [вбудовані методи][docs-string-methods].
Наприклад, щоб прибрати пробільні символи з рядка тексту, можна скористатися [методом Trim][tutorial-docs.microsoft.com-trim-white-space] ось так:

```csharp
string name = " Jane "
name.Trim()
// => "Jane"
```

Щойно рядок тексту створено, його значення вже не може змінитися.
Будь-які методи, які нібито змінюють рядок тексту, насправді повертають новий рядок тексту.

### Конкатенація

Кілька рядків тексту можна зʼєднати (додати) разом. Найпростіший спосіб зробити це - використати оператор `+`.

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

### Форматування

Для будь-якого форматування рядків, складнішого за просту конкатенацію, краще використовувати інтерполяцію рядків. Щоб скористатися інтерполяцією в рядку тексту, поставимо перед ним символ долара (`$`). Тоді, щоб звернутися до змінних усередині рядка тексту, можна використати фігурні дужки (`{}`).

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
