# Вступ

C - статично типізована мова, а це означає, що все має тип на етапі компіляції.
Вибір імені для змінної та задання її типу називають оголошенням змінної.

Змінну оголошують, явно вказуючи її тип.
Імʼя змінної має починатися з літери або символу підкреслення.
Деякі імена використовувати не можна, оскільки вони зарезервовані [для ключових слів][reserved-keywords] або [інших ідентифікаторів][reserved-identifiers].

Встановлення або оновлення значення змінної виконують за допомогою присвоєння.
Встановлення значення визначає цю змінну.
Визначення змінної також називають ініціалізацією.

```c
int foo;      // Declare an integer named var
foo = 10;     // Define the variable

int bar = 15; // Both can also be done in a single statement
```

Значення змінної можна присвоїти й оновити за допомогою простого оператора присвоєння `=`.
Після визначення тип змінної вже ніколи не може змінитися.

```c
int foo = 10; // Assign initial value
foo = 25;     // Update to new value

foo = false;  // Compiler error when assigning value of a different type
```

C - імперативна процедурна мова.
Усі обчислення виконуються як послідовність інструкцій, що належать одній або кільком функціям.

Кожна функція може мати нуль або більше параметрів.
Під час визначення функції всі параметри та повернене значення потрібно явно типізувати.
Значення повертають із функцій за допомогою ключового слова `return`.
Функції типово мають зовнішній клас зберігання, тобто функція існує протягом усього часу роботи програми і може бути видимою поза межами файлу.
Щоб цього уникнути, можна додати ключове слово `static`, яке задає внутрішню видимість.

```c
static int add(int x, int y) {
  return x + y;
}
```

У наведеному вище прикладі змінні `x` та `y` можна використовувати лише всередині функції, тобто вони мають область видимості функції.
Область видимості означає, що значення, повʼязане з іменем (елемента програми), доступне лише в тій «ділянці» коду, де його визначено.
Основні ділянки коду в C:

- файл
- функція
- блок (наприклад, усередині циклів та інших конструкцій)

Функції викликають, вказуючи імʼя функції та передаючи аргументи для кожного з параметрів функції.

```c
int sum = add(1, 2);
```

C підтримує два типи коментарів.
Однорядкові коментарі починаються з `//` (починаючи з C99), а багаторядкові коментарі розміщують між `/*` та `*/`.
