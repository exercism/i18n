# Докладніше

Основною обʼєктно-орієнтованою конструкцією в C# є _клас_, який поєднує дані ([_поля_][fields]) та поведінку ([_методи_][methods]). Поля й методи класу називають його _членами_.

Доступ до членів можна обмежити за допомогою модифікаторів доступу, найпоширеніші з яких:

- [`public`][public]: член доступний будь-якому коду (без обмежень).
- [`private`][private]: член доступний лише коду в тому самому класі.

Усталено вказувати модифікатор доступу для всіх членів. Якщо модифікатор не вказано, типовим є `private`.

Описане вище обʼєднання повʼязаних даних і поведінки разом з обмеженням доступу до членів називають [інкапсуляцією][encapsulation], однією з основних обʼєктно-орієнтованих концепцій.

Сукупність значень полів обʼєкта в певний момент називають [станом][object-state] обʼєкта.

Клас можна уявляти як шаблон для створення екземплярів цього класу. Щоб [створити екземпляр класу][creating-objects] (його ще називають _обʼєктом_), використовують [ключове слово `new`][new]:

```csharp
class Car
{
}

// Create two car instances
var myCar = new Car();
var yourCar = new Car();
```

[Поля][fields] мають тип і можуть бути визначені будь-де в класі.
Публічні поля записують у [PascalCase][pascal-case], а приватні - у [camelCase][camel-case], додаючи на початку підкреслення `_`:

```csharp
class Car
{
    // Accessible by anyone
    public int Weight;

    // Only accessible by code in this class
    private string _color;
}
```

Полю можна за бажанням присвоїти початкове значення. Якщо поле _не_ задає початкового значення, йому буде встановлено [типове значення][default-values] його типу. До значень полів екземпляра можна звертатися й оновлювати їх через точкову нотацію.

```csharp
class Car
{
    // Will be set to specified value
    public int Weight = 2500;

    // Will be set to default value (0)
    public int Year;
}

var newCar = new Car();
newCar.Weight; // => 2500
newCar.Year;   // => 0

// Update value of the field
newCar.Year = 2018;
```

Приватні поля зазвичай оновлюються як побічний ефект виклику методу. Такі методи зазвичай не повертають жодного значення, і тоді типом поверненого значення має бути [`void`][void]:

```csharp
class CarImporter
{
    private int _carsImported;

    public void ImportCars(int numberOfCars)
    {
        // Update private field
        _carsImported = _carsImported + numberOfCars;
    }
}
```

Зауважмо, що публічні поля в класах C# використовувати не прийнято. Використовують або приватні поля, або інші типи членів, про які йтиметься в наступних вправах.

Усередині класу [ключове слово `this`][this] указує на поточний клас. Це особливо корисно, коли параметр має те саме імʼя, що й поле:

```csharp
class CarImporter
{
    private int carsImported;

    public void SetImportedCars(int carsImported)
    {
        // Update private field from public method
        this.carsImported = carsImported;
    }
}
```

Структура класів і методів дає природний спосіб обмежити видимість елементів програми, як-от полів і методів, та уникнути відомої [проблеми глобального стану][so-global-state-problem]. Публічні поля, методи й інші члени, щоб код поза класом їх бачив, потрібно кваліфікувати іменем обʼєкта (`object.field` чи `object.method()`, а для статичних членів іменем класу). Змінні та параметри, оголошені всередині методу, видно лише в межах цього методу.

У цьому підході варто остерігатися одного: якщо імʼя поля збігається з іменем змінної чи параметра в методі, то код усередині методу ігноруватиме поле, а це може бути не тим, чого ми хочемо. Загалом цього слід уникати, де можливо, хоч у конструкторах це поширена практика. Якщо однакові імена поля та змінної доречні, то в методі варто кваліфікувати імʼя поля ключовим словом `this`.

Ці [модифікатори доступу][access-modifiers] дають змогу додатково обмежити видимість.
