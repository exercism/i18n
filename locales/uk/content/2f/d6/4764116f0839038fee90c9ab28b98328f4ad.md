## Необовʼязкові аргументи

```julia-repl
julia> f(a, b=1) = a + b
f (generic function with 2 methods)
```

еквівалентно до

```julia-repl
julia> f(a, b) = a + b
f (generic function with 1 method)

julia> f(a) = f(a, 1)
f (generic function with 2 methods)
```

У відповіді REPL можна побачити, що перше визначення одразу визначає два методи.
