# Про мову

Z3 - це мова Satisfiability Modulo Theory (SMT), яку використовують, щоб зʼясувати, чи здійсненні рівняння або формули, чи мають вони можливий розвʼязок.

Найчастіше Z3 застосовують у верифікації програмного забезпечення, розвʼязуванні обмежень, геометричних задачах, у безпеці та в інших застосунках, яким потрібні швидкі математичні обчислення.

Z3 створила група Research in Software Engineering (RiSE) у Microsoft Research, а від 2015 року він став мовою з відкритим вихідним кодом. Репозиторій Z3 з відкритим кодом на Github можна знайти на https://github.com/Z3Prover/z3.
