# Кортежі

[Кортеж][tuple] - це скінченний впорядкований список елементів, який не можна змінити.
Кортежі вимагають, щоб усі позиції мали фіксований тип.
Це своєю чергою означає, що компілятор знає, який тип міститься в кожній позиції.
Типи, використані в кортежі, можуть відрізнятися в кожній позиції, але вони мають бути відомі під час компіляції.

## Створення кортежу

Залежно від того, чи можна визначити типи значень кортежу під час компіляції, кортеж можна створити різними способами.
Якщо значення відомі під час компіляції, кортеж можна створити за допомогою синтаксису літералів кортежу, інакше типи потрібно вказати явно.
Також важливо, щоб типи значень збігалися з типами, указаними в кортежі, а кількість значень відповідала кількості вказаних типів.
Ось приклад оголошення через синтаксис літералів кортежу:

```crystal
tuple = {1, "foo", 'c'} # Tuple(Int32, String, Char)
```

Також можна створити кортеж за допомогою класу `Tuple`.

```crystal
tuple = Tuple(Int32, String, Char).new(1, "foo", 'c')
```

Крім того, можна явно вказати тип змінної, якій присвоюється кортеж.

```crystal
tuple : Tuple(Int32, String, Char) = {1, "foo", 'c'}
```

Явне зазначення типу кортежу може бути корисним, адже це дає змогу вказати, що позиція має містити обʼєднання типів.
Це означає, що позиція може містити кілька типів.

```crystal
tuple : Tuple(Int32 | String, String, Char) = {1, "foo", 'c'}
```

## Перетворення

### Створення кортежу з масиву

Кортеж можна створити з масиву за допомогою методу `from` класу `Tuple`.
Для цього потрібно вказати тип кортежу.

```crystal
array = [1, "foo", 'c']
tuple = Tuple(Int32, String, Char).from(array)
```

### Перетворення на масив

Кортеж можна перетворити на масив за допомогою методу `to_a`.
Тип елементів отриманого масиву є обʼєднанням типів кожного поля кортежу.

```crystal
tuple = {1, "foo", 'c'}
array = tuple.to_a
array # => [1, "foo", 'c']
```

### Скорочене позначення типів кортежу

Існує скорочене позначення для оголошення явних типів кортежу.
Для цього типи записують усередині літерала кортежу.

```crystal
tuple : {Int32, String, Char} = {1, "foo", 'c'}
```

## Доступ до елементів

Як і масиви, кортежі мають індексацію з нуля, тобто перший елемент має індекс 0.
Однак, на відміну від масивів, тип кожного елемента є фіксованим і відомим під час компіляції, тому під час індексації кортежу тип елемента залежить від позиції.
Щоб отримати елемент кортежу, можна скористатися оператором `[]`.

```crystal
array = [1, "foo", 'c']
array[0]         # => 1
typeof(array[0]) # => Int32 | String | Char

tuple = {1, "foo", 'c'}
tuple[0]         # => 1
typeof(tuple[0]) # => Int32
```

Ще одна відмінність у доступі до елементів масиву полягає в тому, що коли індекс задано, компілятор перевіряє, чи він у межах кортежу.
Це означає, що замість помилки під час виконання ми отримаємо помилку під час компіляції.

```crystal
tuple = {1, "foo", 'c'}
tuple[3]
# => Error: index out of bounds for Tuple(Int32, String, Char) (3 not in -3..2)
```

Однак, якщо індекс збережено в змінній, компілятор не зможе перевірити під час компіляції, чи він у межах кортежу, і натомість видасть помилку під час виконання.

## Підкортеж

Підкортеж можна отримати за допомогою оператора `[]` з діапазоном.
Повертається новий кортеж з елементами із зазначеного діапазону.
Діапазон потрібно задати під час компіляції, інакше компілятор не зможе визначити типи елементів підкортежу.
Це означає, що діапазон має бути літералом діапазону, а не зберігатися в змінній.

```crystal
tuple = {1, "foo", 'c'}
subtuple = tuple[0..1] # Tuple(Int32, String)

i = 0..1
tuple[i]
# Error: Tuple#[](Range) can only be called with range literals known at compile-time
```

## Коли використовувати кортеж

Кортежі стають у пригоді, коли потрібно згрупувати фіксовану кількість значень, типи яких відомі під час компіляції.
Це тому, що кортежі потребують менше памʼяті та працюють швидше за масиви завдяки своїй незмінності.
Ще один випадок використання - повернення кількох значень з методу.
Це особливо корисно, якщо значення мають різні типи, адже кожна позиція кортежу може мати свій тип.

Кортежі не варто використовувати, коли потрібна структура даних, яка може збільшуватися чи зменшуватися або яку часто потрібно змінювати.
