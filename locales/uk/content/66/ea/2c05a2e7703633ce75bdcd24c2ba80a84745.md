# Перевантаження функцій

Ми вже бачили у вправі «Лазанья», як у Swift визначають функції: спочатку йде ключове слово `func`, потім узятий у дужки список назв параметрів, де кожна назва складається з необовʼязкової мітки аргументу та назви параметра, далі анотація типу, а тіло функції записують у фігурних дужках. Наприклад:

```swift
func add(_ x: Int, and y: Int, doubleResult: Bool) -> Int {
  let sum = x + y
  if doubleResult {
    return sum * 2
  } else {
    return sum
  }
}

let twentySix = add(6, and: 7, doubleResult: true)
// => 26
```

Дві функції у Swift вважаються різними, якщо в них різні назви, _або_ якщо справджується будь-що з наведеного нижче:

- У них різна кількість параметрів
- Зовнішні мітки аргументів відрізняються
- Типи будь-яких параметрів відрізняються

Отже, маючи наведене вище визначення `add(_:and:doubleResult)`, кожну з поданих нижче функцій вважатимуть окремою, і всі їх можна визначити та використати в одній програмі:

```swift
// Different number of parameters
func add(_ x: Int, and y: Int) -> Int {
  x + y
}

let eleven = add(5, and: 6)
// => 11

// Different parameter type
func add(_ x: Double, and y: Int, doubleResult: Bool) -> Double {
  let sum = x + Double(y)
  if doubleResult {
    return sum * 2
  } else {
    return sum
  }
}

let twentySeven = add(6.5, and: 7, doubleResult: true)
// => 27.0

// Different argument label
func add(_ x: Int, and y: Int, doubleThat: Bool) -> Int {
  let sum = x + y
  if doubleThat {
    return sum * 2
  } else {
    return sum
  }
}
let thirteen = add(6, and: 7, doubleThat: false)
// => 13
```

Функції також вважаються різними, якщо змінюється лише повернене значення, хоча в багатьох випадках доводиться підказати компілятору за допомогою анотації типу, яку саме версію функції викликати.

```swift
func add(_ x: Int, and y: Int, doubleResult: Bool) -> Double {
  let sum = Double(x + y)
  if doubleResult {
    return sum * 2
  } else {
    return sum
  }
}

let thirty = add(6, and: 9, doubleResult: true)
// Error: Ambiguous use of 'add(_:and:doubleResult:)'

let thirty: Double = add(6, and: 9, doubleResult: true)
// => 30
```

Але зміна лише внутрішньої назви параметра не робить дві функції різними.

```swift
func add(_ w: Int, and y: Int, doubleResult: Bool) -> Int {
  let sum = w + y
  if doubleResult {
    return sum * 2
  } else {
    return sum
  }
}
// Error: Invalid redeclaration of 'add(_:and:doubleResult:)'
```
