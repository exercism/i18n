# Докладніше

Базові класи `java.time`, як-от `LocalDate` і `LocalDateTime`, надають прості методи для додавання чи віднімання одиниць часу, але складніші коригування дат часто потребують витонченішої логіки (наприклад, пошуку «другого вівторка місяця» або «останнього дня року»).

Для цього пакет `java.time.temporal` надає функціональний інтерфейс [`TemporalAdjuster`][temporaladjuster-docs].
Він описує стратегію коригування темпорального обʼєкта (наприклад, `LocalDate`).
Допоміжний клас [`TemporalAdjusters`][temporaladjusters-docs] (звернімо увагу на «s» у кінці: це множина) містить статичні фабричні методи з багатьма поширеними наперед визначеними реалізаціями коригувальників.

## Використання TemporalAdjusters

Темпоральні обʼєкти, як-от `LocalDate` і `LocalDateTime`, мають метод `with()`, який приймає `TemporalAdjuster`.
Цей метод повертає *новий* темпоральний обʼєкт із застосованим коригуванням.

```exercism/note
Використання `with(TemporalAdjuster)` повертає _новий_ екземпляр і не змінює наявний, адже всі темпоральні класи `java.time` незмінні.
```

```java
import java.time.LocalDate;
import java.time.Month;
import java.time.DayOfWeek;
import java.time.temporal.TemporalAdjusters;

LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15 (a Thursday)

// Use a predefined adjuster from TemporalAdjusters
LocalDate firstDayOfNextMonth = date.with(TemporalAdjusters.firstDayOfNextMonth());
// => 2024-09-01

LocalDate nextSunday = date.with(TemporalAdjusters.next(DayOfWeek.SUNDAY));
// => 2024-08-18
```

## Поширені наперед визначені коригувальники

Клас `TemporalAdjusters` надає багато корисних статичних методів.
Ось кілька поширених прикладів:

### Пошук n-го дня тижня

Коригувальник `dayOfWeekInMonth(int ordinal, DayOfWeek dayOfWeek)` знаходить n-те входження заданого дня тижня в межах місяця.

```java
LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15

// Find the second Tuesday of August 2024
LocalDate secondTuesday = date.with(TemporalAdjusters.dayOfWeekInMonth(2, DayOfWeek.TUESDAY));
// => 2024-08-13

// Find the fourth Friday of August 2024
LocalDate fourthFriday = date.with(TemporalAdjusters.dayOfWeekInMonth(4, DayOfWeek.FRIDAY));
// => 2024-08-23
```

### Пошук першого й останнього дня тижня в місяці

Коригувальники `firstInMonth(DayOfWeek dayOfWeek)` і `lastInMonth(DayOfWeek dayOfWeek)` знаходять перше або останнє входження дня тижня в межах місяця.

```java
LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15

// Find the first Sunday of August 2024
LocalDate firstSunday = date.with(TemporalAdjusters.firstInMonth(DayOfWeek.SUNDAY));
// => 2024-08-04

// Find the last Monday of August 2024
LocalDate lastMonday = date.with(TemporalAdjusters.lastInMonth(DayOfWeek.MONDAY));
// => 2024-08-26
```

### Пошук першого й останнього дня місяця чи року

Простіші коригувальники знаходять перший або останній день поточного місяця чи року.

```java
LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15

LocalDate firstDay = date.with(TemporalAdjusters.firstDayOfMonth());
// => 2024-08-01

LocalDate lastDay = date.with(TemporalAdjusters.lastDayOfMonth());
// => 2024-08-31

LocalDate lastDayOfYear = date.with(TemporalAdjusters.lastDayOfYear());
// => 2024-12-31
```

### Відносні коригування (наступний/попередній)

Коригувальники `next()`, `previous()`, `nextOrSame()` і `previousOrSame()` знаходять наступне або попереднє входження заданого дня тижня відносно поточної дати.

- `next()`/`previous()`: не враховують поточну дату, навіть якщо вона збігається.
- `nextOrSame()`/`previousOrSame()`: враховують поточну дату, якщо вона збігається.

```java
LocalDate thursday = LocalDate.of(2024, Month.AUGUST, 15); // A Thursday

// Find the next Sunday (exclusive)
LocalDate nextSunday = thursday.with(TemporalAdjusters.next(DayOfWeek.SUNDAY));
// => 2024-08-18

// Find the next Thursday (exclusive)
LocalDate nextThursday = thursday.with(TemporalAdjusters.next(DayOfWeek.THURSDAY));
// => 2024-08-22

// Find the next Thursday (inclusive) - returns the same date
LocalDate nextOrSameThursday = thursday.with(TemporalAdjusters.nextOrSame(DayOfWeek.THURSDAY));
// => 2024-08-15

// Find the previous Monday (exclusive)
LocalDate previousMonday = thursday.with(TemporalAdjusters.previous(DayOfWeek.MONDAY));
// => 2024-08-12
```

## Власні коригувальники

Оскільки `TemporalAdjuster` є [`@FunctionalInterface`][functionalinterface-docs], ми можемо створювати власні коригувальники за допомогою лямбда-виразів для логіки, якої не покривають наперед визначені методи.
Інтерфейс вимагає реалізувати єдиний метод: `Temporal adjustInto(Temporal temporal)`.

```java
// Example: An adjuster that finds the next workday (Mon-Fri), skipping weekends.
TemporalAdjuster nextWorkday = temporal -> {
    LocalDate result = (LocalDate) temporal; // Assuming input is LocalDate
    do {
        result = result.plusDays(1);
    } while (result.getDayOfWeek() == DayOfWeek.SATURDAY || result.getDayOfWeek() == DayOfWeek.SUNDAY);
    return result;
};

LocalDate friday = LocalDate.of(2024, Month.AUGUST, 16);
LocalDate nextWorkdayDate = friday.with(nextWorkday);
// => 2024-08-19 (Monday)

LocalDate sunday = LocalDate.of(2024, Month.AUGUST, 18);
LocalDate nextWorkdayFromSunday = sunday.with(nextWorkday);
// => 2024-08-19 (Monday)
```

Власні коригувальники дають великі можливості, але наперед визначені коригувальники з класу `TemporalAdjusters` покривають широкий спектр типових випадків.
