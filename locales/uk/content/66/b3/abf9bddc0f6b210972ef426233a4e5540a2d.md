# Інструкції

Як майбутня чарівниця, Еліз має потренуватися в основах. У неї є колода карт, з якою вона хоче працювати.

Щоб було трохи легше, вона використовує лише карти від 1 до 10.

## 1. Витягніть карту з колоди

Реалізуйте функцію `getCard`, яка повертає карту на позиції `index` із заданої колоди. Якщо такого індексу немає в колоді, поверніть Nothing.

```elm
getCard 2 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Just 4
getCard 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Nothing
```

## 2. Змініть карту в колоді

Реалізуйте функцію `setCard`, яка повертає колоду, у якій карту на позиції `index` замінено на надану нову карту.
Якщо `index` немає в колоді, поверніть початкову колоду.

```elm
setCard 2 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Array.fromList [ 1, 2, 6, 1 ]
setCard 6 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Array.fromList [ 1, 2, 4, 1 ]
```

## 3. Додайте карту до колоди

Реалізуйте функцію `addCard`, яка повертає колоду з доданою новою картою.

```elm
addCard 8 ( Array.fromList [ 5, 9, 7, 1 ] )
    --> Array.fromList [ 5, 9, 7, 1, 8 ]
```

## 4. Видаліть карту з колоди

Реалізуйте функцію `removeCard`, яка повертає колоду, з якої видалено карту на позиції `index`.
Якщо наданий `index` не є допустимим індексом у колоді, поверніть початкову колоду.

```elm
removeCard 2 ( Array.fromList [ 3, 2, 6, 4, 8 ] )
    --> Array.fromList [ 3, 2, 4, 8 ]
removeCard 2 ( Array.fromList [ 3, 2 ] )
    --> Array.fromList [ 3, 2 ]
```

## 5. Підрахуйте кількість парних карт у колоді

Реалізуйте функцію `evenCardCount`, яка підраховує кількість парних карт у колоді.

```elm
evenCardCount (Array.fromList [ 3, 8, 4, 5, 1, 6, 10 ] )
    --> 4
```
