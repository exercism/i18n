# Вказівки

Ми ведемо табло на матчі з нетболу. На відміну від усього, що було досі, табло
має памʼятати те, що вже сталося.

Класу `SCOREBOARD` потрібне таке. Заготовка вже дає клас і два оголошення його
атрибутів; додайте решту.

## 1. Налаштуйте табло

`create` приймає назву команди господарів і назву команди гостей та повертає
табло, в якому обидва рахунки дорівнюють нулю.

```sather
board ::= #SCOREBOARD("Vixens", "Magpies");
board.home_score
-- => 0
```

## 2. Забийте гол

`home_goal` додає одиницю до рахунку господарів, а `away_goal` додає одиницю до
рахунку гостей. Жоден із них нічого не повертає.

```sather
board.home_goal;
board.home_score
-- => 1
```

## 3. Прочитайте табло

`summary` повертає табло в тому вигляді, у якому його записують: команда
господарів, її рахунок, дефіс, рахунок гостей, а потім команда гостей.

```sather
board.summary
-- => "Vixens 1 - 0 Magpies"
```

Пробіли стоять точно так, як показано, а дефіс один: `-`.

## 4. Хто перемагає?

`leader` повертає назву команди, що попереду, або `"Draw"`, коли рахунки рівні.

```sather
board.leader
-- => "Vixens"
```

## 5. Наскільки попереду?

`margin` повертає, скільки голів розділяє команди. Це значення ніколи не буває
відʼємним, хто б не був попереду.

```sather
board.margin
-- => 1
```
