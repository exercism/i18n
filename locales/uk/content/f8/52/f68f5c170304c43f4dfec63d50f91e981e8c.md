# Вступ

JavaScript належить до динамічних мов, які підтримують обʼєктно-орієнтований, імперативний і декларативний (як-от функціональне програмування) стилі.

## Змінні

У JavaScript є кілька основних способів присвоїти значення іменам: за допомогою змінних або констант.
На Exercism змінні завжди пишуть у [camelCase][wiki-camel-case], а константи - у [SCREAMING_SNAKE_CASE][wiki-snake-case].
Немає офіційного посібника, якого варто дотримуватися, і в різних компаній та організацій бувають різні посібники зі стилю.
_Можна писати змінні як завгодно_.
Перевага писати їх так, як підготовлено у вправах, у тому, що у вебінтерфейсі та більшості IDE вони будуть підсвічуватися по-різному.

Змінні в JavaScript можна визначати за допомогою ключового слова [`const`][mdn-const], [`let`][mdn-let] або [`var`][mdn-var].

Змінна може посилатися на різні значення протягом свого життя, якщо використовувати `let` або `var`.
Наприклад, `myFirstVariable` можна визначати й перевизначати багато разів за допомогою оператора присвоєння `=`:

```javascript
let myFirstVariable = 1;
myFirstVariable = 'Some string';
myFirstVariable = new SomeComplexClass();
```

На відміну від `let` і `var`, змінні, визначені через `const`, можна присвоїти лише один раз.
Так у JavaScript визначають константи.

```javascript
const MY_FIRST_CONSTANT = 10;

// Can not be re-assigned.
MY_FIRST_CONSTANT = 20;
// => TypeError: Assignment to constant variable.
```

## Оголошення функцій

У JavaScript одиниці функціональності інкапсульовані у _функціях_; зазвичай функції, які належать одна одній, групують в одному файлі.
Ці функції мають параметри (тобто можуть приймати аргументи) і можуть _повертати_ значення за допомогою ключового слова `return`.
Функції викликають за допомогою синтаксису `()`.

```javascript
function add(num1, num2) {
  return num1 + num2;
}

add(1, 3);
// => 4
```

У цьому прикладі функція має назву `add`.
Вона має два параметри: `num1` і `num2`.
Вона повертає значення: результат виразу `num1 + num2`

Потім функцію `add` _викликають_ з двома аргументами: `1` і `3`.
Результат роботи функції, повернене значення, - `4`.

```exercism/note
💡 У JavaScript є _багато_ різних способів оголосити функцію.
Деякі з цих інших способів мають інший вигляд, ніж використання ключового слова `function`.
Трек намагається поступово їх подавати, але якщо ці способи вже знайомі, можна використовувати будь-який із них.
У більшості випадків жоден із них не кращий і не гірший.
```

## Надання доступу іншим файлам

Щоб зробити `function`, константу або змінну доступними в _інших файлах_, їх потрібно [експортувати][mdn-export] за допомогою ключового слова `export`.
Інший файл може потім [імпортувати][mdn-import] їх за допомогою ключового слова `import`.
Це також відомо як модульна система.

Чудовий приклад - це те, як працюють усі тести.
Кожна вправа має щонайменше один файл, наприклад `lasagna.js`, який містить _реалізацію_.
Реалізацію експортують із файлу за допомогою `export`, тож її можна імпортувати в іншому файлі.
Крім того, є щонайменше один інший файл, наприклад `lasagna.spec.js`, який містить _тести_.
Цей файл імпортує публічні (тобто експортовані) сутності, щоб протестувати реалізацію:

```javascript
// file.js
export const MY_VALUE = 10;

export function add(num1, num2) {
  return num1 + num2;
}

// file.spec.js
import { MY_VALUE, add } from './file';

add(MY_VALUE, 5);
// => 15
```
