# Про кортежі

[Кортежи][tuples] використовуємо, щоб обʼєднати кілька значень в одне складене значення, де кожне зі значень може мати різний тип.
Складене значення має тип, який є комбінацією типів окремих значень.
Як і масиви, кортежі є впорядкованими колекціями.
Однак, на відміну від масивів, кортежі мають фіксований розмір, тому щоб змінити кількість елементів у кортежі, потрібно створити новий кортеж.

Щоб створити кортеж, ми беремо значення в дужки, розділені комами:

```swift
let order = ("biscuits", 2.99, 3)
```

Ми також можемо вказати тип кожного значення в кортежі:

```swift
let order: (String, Double, Int) = ("biscuits", 2.99, 3)
```

Щоб видобути окремі значення з кортежу, ми можемо використати синтаксис `.n`, де _n_ — це індекс елемента, до якого ми хочемо отримати доступ, починаючи з 0:

```swift
let orderItem = order.0
// Returns "biscuits"

let orderQuantity = order.2
// Returns 3
```

## Іменовані кортежі

Кортежі можна іменувати, надаючи мітки для кожного зі значень:

```swift
let order = (item: "biscuits", price: 2.99, quantity: 3)
```

Це може бути корисно, щоб зробити кортеж більш читабельним і зрозумілим, особливо коли кортеж використовується як повернене значення з функції.

Це також дозволяє нам отримувати доступ до окремих значень за їхніми назвами:

```swift
let orderItem = order.item
// Returns "biscuits"
let orderQuantity = order.quantity
// Returns 3
```

Як і з неіменованими кортежами, ми можемо вказати тип кожного значення в іменованому кортежі:

```swift
let order: (item: String, price: Double, quantity: Int) = (item: "biscuits", price: 2.99, quantity: 3)
```

## Зміна кортежів

Елементи кортежу можна змінювати; це можна зробити за допомогою синтаксису `.n`.

```swift
var order = ("biscuits", 2.99, 3)
order.0 = "cookies"
order.1 = 1.99
order.2 = 5

order
// Returns ("cookies", 1.99, 5)
```

## Кілька повернених значень

Функції в Swift можуть повертати лише одне значення.
Однак, оскільки кортеж є одним значенням, ми можемо спакувати кілька значень у кортеж і повернути цей кортеж з функції.
Це дозволяє нам ефективно [повертати кілька значень з функції][multiple-return-values].

Ось приклад функції, яка повертає кортеж із часткою та остачею:

```swift
func divide(_ dividend: Int, by divisor: Int) -> (quotient: Int, remainder: Int) {
  let quotient = dividend / divisor
  let remainder = dividend % divisor
  return (quotient, remainder)
}
```

## Декомпозиція кортежів

Ми можемо розкласти кортеж на окремі компоненти, надавши кількість змінних, що дорівнює кількості елементів у кортежі.
Використання декомпозиції кортежів може підвищити читабельність вашого коду, оскільки це дозволяє нам присвоювати значущі імена окремим значенням.

```swift
let order = ("biscuits", 2.99, 3)
let (item, price, quantity) = order

item
// Returns "biscuits"
```

Декомпозицію також можна виконати за допомогою циклів `for-in`:

```swift
let orders = [("biscuits", 2.99, 3), ("cookies", 1.99, 5)]

for (item, price, quantity) in orders {
  print("Item: \(item), Price: \(price), Quantity: \(quantity)")
}
```
