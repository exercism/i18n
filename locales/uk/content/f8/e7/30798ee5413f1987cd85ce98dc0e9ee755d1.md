# Вступ

[Словники][dictionaries] належать до основних типів колекцій у Swift.
Словник зберігає невпорядковані відповідності між унікальними ключами та відповідними значеннями.
Усі ключі в словнику мають бути одного типу, і всі значення так само.

Літерали словників записують як розділені комами пари `key: value`, узяті в квадратні дужки:

```swift
var addresses: Dictionary<String, String> = [
    "The Munsters": "1313 Mockingbird Lane",
    "The Simpsons": "742 Evergreen Terrace",
    "Buffy Summers": "1630 Revello Drive"
]

var sequences: [String: [Int]] = [
    "Euler's totient": [1, 1, 2, 2, 4, 2, 6, 4],
    "Lazy caterer": [1, 2, 4, 7, 11, 16, 22, 29, 37],
    "Carmichael": [561, 1105, 1729, 2465, 2821, 6601, 8911, 10585, 15841]
]

let constants = [
    "pi": 3.14159,
    "e": 2.71828,
    "phi": 1.618033,
    "avogadro": 6.02214076e23
]
```

Типи словників можна записати явно двома способами: `Dictionary<Key, Value>` або скороченим синтаксисом `[Key: Value]`.

Щоб створити порожній словник, потрібно явно вказати типи його ключів і значень:

```swift
var emptyDict1: [Int: Int] = [:]
var emptyDict2 = [Character: String]()
var emptyDict3 = Dictionary<Int, Double>()
```

## Доступ до значень

До значень можна звертатися за допомогою індексної нотації: ключ записують у квадратних дужках після назви словника.
Оскільки ключа може не бути в словнику, звернення за індексом повертає *опціональне* значення (`Value?`).
Якщо ключ присутній, Swift повертає загорнуте значення; якщо ні, повертає `nil`:

```swift
let munster: String? = addresses["The Munsters"]
// Returns Optional("1313 Mockingbird Lane")

let carmichael = sequences["Carmichael"]
// Returns Optional([561, 1105, 1729, 2465, 2821, 6601, 8911, 10585, 15841])

let planck = constants["planck"]
// Returns nil
```

Щоб не працювати з опціоналами, можна вказати типове значення за допомогою параметра `default`:

```swift
let e: Double = constants["e", default: 0]
// Returns 2.71828

let hoagie: [Int] = sequences["Hoagie", default: []]
// Returns []

let betty = addresses["Betty Cooper", default: "Address unknown"]
// Returns "Address unknown"
```

## Зміна словників

Для змінних словників, оголошених через `var`, можна додавати або оновлювати пари ключ-значення за допомогою присвоєння за індексом:

```swift
sequences["Euler's totient"]?.append(contentsOf: [6, 4])
// sequences["Euler's totient"] is now [1, 1, 2, 2, 4, 2, 6, 4, 6, 4]

addresses["Betty Cooper"] = "111 Queens Ave."
addresses["Betty Cooper", default: "Address unknown"]
// Returns "111 Queens Ave."

constants["Gelfond's"] = 23.140692
// Compiler error: Cannot assign through subscript: 'constants' is a 'let' constant
```

## Перебирання словника

Кожну пару ключ-значення словника можна перебрати за допомогою циклу `for-in`.
Кожен елемент подано як кортеж `(key, value)`:

```swift
for (name, address) in addresses {
    print("\(name) lives at \(address)")
}
```

## Сортування словників

Оскільки словники невпорядковані, їхнє сортування дає масив пар ключ-значення.
У метод `sorted(by:)` можна передати замикання, яке порівнює два кортежі `(key, value)` і повертає `true`, якщо перший кортеж має стояти перед другим:

```swift
func sortByNameLengthThenValue(_ lhs: (key: String, value: Double), _ rhs: (key: String, value: Double)) -> Bool {
    let left = lhs.value + Double(lhs.key.count)
    let right = rhs.value + Double(rhs.key.count)
    return left < right
}

let sortedConstants = constants.sorted(by: sortByNameLengthThenValue)
```
