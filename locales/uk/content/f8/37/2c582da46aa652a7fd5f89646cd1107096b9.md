# Концепції Luhn

Luhn - це алгоритм перевірки, який поєднує текстові та числові твердження. Рішення на Rust надають перевагу функціональним підходам.

## Загальне

### Примітиви

- `&str` і `char`
  - важливо розуміти, чим окремий `char` відрізняється від `&str`, щоб правильно виключати або включати частини наданих вхідних даних
- ціле число
  - розуміння цілих чисел потрібне для числової перевірки, якої вимагає задача
- булеві значення (англ. Boolean)
  - необхідні для тверджень про тотожність і остаточних порівнянь

### Можливості ітераторів

- ланцюжки
  - тут важливо розуміти ланцюжки ітераторів, щоб розвʼязати задачу впорядковано.
- `map`, `filter`, turbofish, можливо, `fold`
  - поєднання map і filter дає базову схему проєктування для таких задач на перевірку. Рішення з `fold` до того ж стисліші.
  - turbofish потрібен у деяких рішеннях, щоб підказати Rust, який тип ми створюємо з ланцюжкового виразу

## Приклад рішення 1

[Рішення](https://exercism.org/tracks/rust/exercises/luhn/solutions/7038c269a4af4f5b95ca35a99c5c3b4d) від york

```rust
pub fn is_valid(code: &str) -> bool {
    code.chars()
        .filter(|c| !c.is_ascii_whitespace())
        .rev()
        .try_fold((0, 0), |(num_count, sum), c| {
            c.to_digit(10).map(|x| {
                let double = x * (num_count % 2 + 1);
                let double = if double > 9 { double - 9 } else { double };
                (num_count + 1, sum + double)
            })
        })
        .map_or(false, |(num_count, sum)| num_count >= 2 && sum % 10 == 0)
}
```

## Приклад рішення 2

Канонічне

```rust
pub fn is_valid(candidate: &str) -> bool {
    if candidate.chars().filter(|c| c.is_ascii_digit()).take(2).count() <= 1
        || candidate.chars().any(|c| !c.is_ascii_digit() && c != ' ')
    {
        return false;
    }

    candidate
        .chars()
        .filter_map(|c| c.to_digit(10))
        .rev()
        .enumerate()
        .map(|(index, digit)| if index % 2 == 0 { digit } else { digit * 2 })
        .map(|digit| if digit > 9 { digit - 9 } else { digit })
        .sum::<u32>()
        % 10
        == 0
}
```
