# Про концепцію

## Функції

У Gleam функції визначаються за допомогою синтаксису `pub fn`.

```gleam
pub fn add(x: Int, y: Int) -> Int {
  x + y
}
```

Ця функція приймає два аргументи, обидва типу `Int`, і повертає значення типу `Int`. У Gleam немає ключового слова `return`, тому значення останнього виразу у функції завжди _повертається неявно_.

Анотації типів для аргументів і тип поверненого значення необовʼязкові, і Gleam завжди повністю перевіряє типи в нашому коді. Зазвичай ті, хто пише на Gleam, додають своїм функціям анотації типів для ясності, але за бажанням їх можна опустити.

```gleam
pub fn add(x, y) {
  x + y
}
```

Функцію можна викликати за допомогою синтаксису `function_name(argument1, argument2)`.

```gleam
pub fn double(x: Int) -> Int {
  // Call the add function defined above
  add(x, x)
}
```

## Змінні

У Gleam змінні визначаються за допомогою синтаксису `let name = expression`.

```gleam
pub fn main() {
  let count = 1
}
```

Змінні можна оголошувати з анотаціями типів. Як і аргументи функцій, вони необовʼязкові, хоча більшість програмістів на Gleam опускають анотації типів для змінних.

```gleam
pub fn main() {
  let count: Int = 1
}
```

## Літерали рядків тексту

У Gleam рядки тексту (англ. string) записуються в подвійних лапках.

```gleam
pub fn greeting() {
  "Hello, world!"
}
```

## Коментарі в коді

Коментарі можна використовувати, щоб залишати нотатки для інших розробників, які читають вихідний код. Коментарі в Gleam займають один рядок і починаються з `//`.

```gleam
pub fn main() {
  // This is a comment
  let x = 1
}
```
