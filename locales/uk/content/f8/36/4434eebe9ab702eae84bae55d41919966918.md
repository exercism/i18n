# Інструкції

Як майбутня фокусниця, Еліз має потренувати деякі основи. У неї є
стос карт, з якими вона хоче працювати.

Щоб трохи спростити собі роботу, вона використовує лише карти від 1 до 10, тож її стос карт можна подати як вектор чисел.
Позиція певної карти відповідає індексу у векторі.

## 1. Дістати карту зі стосу

Щоб вибрати карту, поверніть карту за індексом `position` із заданого стосу.

```R
stack <- c(1, 2, 4, 1)
position <- 3
get_item(stack, position)
# => 4
```

## 2. Обміняти карту в стосі

Продемонструйте трохи спритності рук і обміняйте карту за індексом `position` на надану карту для заміни.
Поверніть скоригований стос.

```R
stack <- c(1, 2, 4, 1)
position <- 3
replacement_card <- 6
set_item(stack, position, replacement_card)
# => c(1, 2, 6, 1)
```

## 3. Вставити карту на верхівку стосу

Примусьте карту зʼявитися, вставивши нову карту на верхівку стосу.
Поверніть скоригований стос.

```R
stack <- c(5, 9, 7, 1)
new_card <- 8
insert_item_at_top(stack, new_card)
# => c(5, 9, 7, 1, 8)
```

## 4. Прибрати карту зі стосу

Примусьте карту зникнути, прибравши зі стосу карту за заданою позицією `position`.
Поверніть скоригований стос.

```R
stack <- c(3, 2, 6, 4, 8)
position <- 3
remove_item(stack, position)
# => c(3, 2, 4, 8)
```

## 5. Перевірити розмір стосу

Перевірте, чи розмір стосу дорівнює `stack_size`, чи ні.

```R
stack <- c(3, 2, 6, 4, 8)
stack_size <- 4
check_size_of_stack(stack, stack_size)
# => FALSE
```

## 6. Прибрати верхню карту зі стосу

Примусьте карту зникнути, прибравши карту з верхівки стосу.
Поверніть скоригований стос.

```R
stack <- c(3, 2, 6, 4, 8)
remove_item_from_top(stack)
# => c(3, 2, 6, 4)
```

## 7. Вставити карту в низ стосу

Примусьте карту зʼявитися, вставивши нову карту в низ стосу.
Поверніть скоригований стос.

```R
stack <- c(5, 9, 7, 1)
new_card <- 8
insert_item_at_bottom(stack, new_card)
# => c(8, 5, 9, 7, 1)
```

## 8. Прибрати карту з низу стосу

Примусьте карту зникнути, прибравши карту з низу стосу.
Поверніть скоригований стос.

```R
stack <- c(8, 5, 9, 7, 1)
remove_item_at_bottom(stack)
# => c(5, 9, 7, 1)
```
