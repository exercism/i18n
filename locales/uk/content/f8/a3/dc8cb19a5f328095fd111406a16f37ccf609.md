# Вказівки для SQLite

* Стовпець **candidates** містить закодований у JSON список рядків тексту (англ. string).
  Наприклад:
  ```json
  ["stone","tones","banana","tons","notes","Seton"]
  ```
* Стовпець **result** також повинен містити закодований у JSON список рядків тексту.

## Схема таблиці

```sql
CREATE TABLE anagram (
  subject    TEXT NOT NULL,
  candidates TEXT NOT NULL,     -- json array of strings
  result     TEXT               -- json array of strings
);
```
