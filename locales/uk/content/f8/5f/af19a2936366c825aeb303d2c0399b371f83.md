# Інструкції

Наша подруга Лі Мей тримає бар соків, де продає смачні змішані фруктові соки.
Ми часто буваємо в її закладі й розуміємо, що можемо полегшити їй життя.
Тож вирішуємо застосувати свої навички програмування й допомогти Лі Мей у роботі.

## 1. Визначте, скільки часу потрібно на приготування одного соку

Лі Мей любить заздалегідь казати відвідувачам, скільки їм доведеться чекати на замовлений сік із меню.
Проте їй важко запамʼятати точні числа, бо час змішування соків буває різним:

| ID  | Напій                          | Час |
| --- | ------------------------------ | ---- |
| 1   | Чиста полунична насолода        | 1    |
| 2   | Заряд енергії                   | 3    |
| 3   | Зелений сад                     | 3    |
| 4   | Тропічний острів                | 4    |
| 5   | Усе або нічого                  | 5    |
| 6   | Гарне самопочуття               | 4    |
| 7   | Спеціальна пропозиція дня       | 7    |
| 8   | Вибір клієнта                   | 10   |

Напишіть функцію `time_to_make_juice`, яка приймає ID соку як 32-бітне число й повертає час приготування цього соку, також як 32-бітне число.

```c
time_to_make_juice(2);
// => 3
```

## 2. Визначте, скільки часу потрібно на приготування всіх замовлених соків

Лі Мей періодично поповнює запаси, тож їй потрібно заздалегідь знати, скільки часу вона витратить на приготування всіх поточних замовлень.

Щоб допомогти подрузі, напишіть функцію `time_to_prepare`, яка приймає масив ID кожного замовленого соку та кількість соків у масиві.
Функція має повернути загальний час, потрібний на приготування всіх напоїв у масиві.

Можна вважати, що кожен ID, кількість ID у масиві та повернене значення - це 32-бітні числа.
Результат завжди вміщується в 32-бітне число.

```c
time_to_prepare({2, 3, 8}, 3);
// => 16
```

## 3. Поповніть запас скибочок лайма

Багато напоїв Лі Мей містять скибочки лайма як інгредієнт або як прикрасу.
Тож, починаючи ранкову зміну, вона має подбати, щоб контейнер зі скибочками лайма був повний на весь день.

Реалізуйте функцію `limes_to_cut`, яка приймає кількість скибочок лайма, які Лі Мей потрібно нарізати, масив із наявними цілими лаймами та кількість лаймів у масиві.

Кожен лайм представлений у масиві символом, що позначає його розмір.
Різні розміри лайма дають Лі Мей різну кількість скибочок:

| Розмір | Скибочки |
| ------ | -------- |
| 'S'    | 6        |
| 'M'    | 8        |
| 'L'    | 10       |

~~~~exercism/note
Символ - це 8-бітне число, з яким можна робити все те саме, що й з будь-яким 8-бітним числом:

| Символ | Значення |
|--------|----------|
| 'S'    | 83       |
| 'M'    | 77       |
| 'L'    | 76       |

Його також можна використовувати безпосередньо в інструкціях, де він рівнозначний своєму значенню:

```x86asm
mov dl, 'S'
cmp cl, 'M'
```
~~~~

Лі Мей завжди нарізає лайми в тому порядку, у якому вони стоять у масиві, починаючи з першого.
Вона продовжує, доки не наріже потрібну кількість скибочок або доки не закінчаться лайми.

Лі Мей хотіла б заздалегідь знати, скільки лаймів їй потрібно нарізати.

Можна вважати, що потрібна кількість скибочок, кількість лаймів у масиві та повернене значення - це все 32-бітні числа.
Результат завжди вміщується в 32-бітне число.

```c
limes_to_cut(25, {'S', 'S', 'L', 'M', 'S'}, 5);
// => 4
```

## 4. Завершіть зміну

Лі Мей завжди працює до 15:00.
Потім її зміну приймає співробітник Дмитро.
Часто трапляється, що на момент закінчення зміни Лі Мей частину напоїв уже замовлено, але ще не приготовлено.
Тоді Дмитро готує решту соків.

Щоб спростити передачу зміни, реалізуйте функцію `remaining_orders`, яка приймає:

- Кількість хвилин, що залишилися до кінця зміни Лі Мей.
- Масив ID кожного соку, який замовлено, але ще не приготовлено.

Функція має повернути кількість замовлень, які Лі Мей встигла приготувати до кінця робочого дня.

Час, що залишився до кінця зміни, завжди більший за 0.
Масив соків для приготування ніколи не буває порожнім, і зміна завжди закінчується раніше, ніж ми дійдемо до кінця масиву.
Крім того, замовлення готують у тому порядку, у якому вони стоять у масиві.
Якщо Лі Мей почала змішувати якийсь сік, вона завжди доведе його до кінця, навіть якщо їй доведеться трохи затриматися.

Можна вважати, що кількість хвилин, кожен ID у масиві та повернене значення - це все 32-бітні числа.
Результат завжди вміщується в 32-бітне число.

```c
remaining_orders(5, {5, 5, 3});
// => 1
```
