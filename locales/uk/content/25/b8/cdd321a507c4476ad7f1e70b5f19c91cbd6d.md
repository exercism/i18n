# Вступ

## Масиви

Масиви в PHP - це впорядковані мапи.
Мапа - це структура даних, яка повʼязує ключ зі значенням.
Масиви універсальні: з ними можна працювати як із лінійним масивом (як у `C` чи `Java`), списком [вектором], хеш-таблицею, словником, колекцією, стеком або чергою.

Ключ необовʼязковий, але якщо його вказано, він має бути або `int`, або `string`.
Якщо ключ не вказано, PHP типово використовує цілі числа як ключі в порядку зростання, починаючи з `0`.

```php
$no_keys = ["my", "first", "array"];
$integer_keys = [0 => "my", 1 => "first", 2 => "array"];

$no_keys == $integer_keys // => equal returns true
$no_keys === $integer_keys // => strictly equal returns true
```

Масив може зберігати значення всіх типів.
Кожне значення може мати інший тип.

### Використання масивів

Масиви можна оголосити як літерал (записати в коді, як зроблено вище) або створити й обробляти за допомогою функцій.
Щоб отримувати, присвоювати й додавати значення, скористаймося оператором індексу:

```php
$prime_numbers = [2, 3, 5, 6];

$prime_numbers[3] = 7; // replace 6 with 7

$prime_numbers[] = 11; // array now contains [2, 3, 5, 7, 11]
```

## Аргументи змінної довжини

Аргументи функції можна оголосити так, щоб вона приймала будь-яку кількість аргументів:

```php
<?php

function actOnItems(...$items) {
  // $items is an array containing 0 or more values
  // used to call the function.
}

actOnItems(1, 2, 3, 4); // $items => [1, 2, 3, 4]
```
