# Вступ до побітових операцій

У Java є оператори для роботи з бітами `byte`, `short`, `int`, `long` або `char`.

## Оператори зсуву

Щоб зсунути біти вліво, використовуємо `<<`, а для зсуву вправо призначений `>>`.

```java
// Shift two places to the left
0b0000_1011 << 2;
// # => 0b0010_1100

// Shift two places to the right
0b0000_1011 >> 2;
// # => 0b0000_0010
```

Оператор `<<` завжди вставляє нулі праворуч.
Натомість `>>` вставляє той самий біт, що й найлівіший біт (1, якщо число відʼємне, або 0, якщо додатне).

```java
// Shift 2 places to the right preserves the sign
// This is a negative value, whose binary representation is
// 1000_0000_0000_0000_0000_0000_0010_0110
int value = -0x7FFFFFDA;

// Shift two places to the right, preserving the sign bit
value >> 2;
// # => 1110_0000_0000_0000_0000_0000_0000_1001
```

Натомість `>>>` використовуємо тоді, коли під час зсуву вправо треба вставляти нулі.

```java
// Shift two places to the right, inserting 0s on the left
value >>> 2;
// # => 0010_0000_0000_0000_0000_0000_0000_1001
```

## Побітові операції

### Побітове AND

Оператор побітового AND (`&`) приймає два значення й виконує AND над кожним бітом.
Він порівнює кожен біт першого значення з бітом на тій самій позиції другого значення.
Якщо обидва біти дорівнюють 1, то відповідний біт результату дорівнює 1.
Інакше біт результату дорівнює 0.

```java
0b0110_0101 & 0b0011_1100;
// # => 0b0010_0100
```

### Побітове OR

Оператор побітового OR (`|`) приймає два значення й виконує OR над кожним бітом.
Він порівнює кожен біт першого значення з бітом на тій самій позиції другого значення.
Якщо хоч один із бітів дорівнює 1, біт результату дорівнює 1.
Інакше він дорівнює 0.

```java
0b0110_0101 | 0b0011_1100;
// # => 0b0111_1101
```

### Побітове XOR

Оператор побітового XOR (`^`) виконує побітове XOR над двома значеннями.
Як і оператори побітового AND та побітового OR, він порівнює кожен біт першого значення з бітом на тій самій позиції другого значення.
Якщо лише один із них дорівнює 1, відповідний біт результату дорівнює 1.
Інакше він дорівнює 0.

```java
0b0110_0101 ^ 0b0011_1100;
// # => 0b0101_1001
```

### Побітове NOT (`~`)

І наостанок, оператор побітового NOT (`~`) інвертує кожен біт.
На відміну від попередніх операторів, це унарний оператор, який діє лише на одне значення.

```java
~0b0110_0101;
// # => 0b1001_1010
```
