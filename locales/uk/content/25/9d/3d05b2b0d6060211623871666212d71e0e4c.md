# Інструкції

Ми ведемо щоденний облік того, скільки птахів відвідує наш сад. Дані зберігаються як масив цілих чисел, де **сьогоднішня кількість стоїть першою**.

## 1. Сьогоднішня кількість

Визначте `today`, щоб вона брала масив щоденних кількостей зі стека й повертала сьогоднішню кількість, або `f`, якщо масив порожній.

```factor
{ 2 5 1 } today .
! => 2

{ } today .
! => f
```

## 2. Інкремент сьогоднішньої кількості

Визначте `increment-day-count`, щоб вона повертала новий масив, у якому сьогоднішню кількість збільшено на одиницю. Якщо вхідні дані порожні, поверніть `{ 1 }`.

```factor
{ 4 0 2 } increment-day-count .
! => { 5 0 2 }

{ } increment-day-count .
! => { 1 }
```

## 3. Чи був день без птахів?

Визначте `has-day-without-birds?`, щоб вона повертала `t`, якщо хоч один день мав нуль птахів, інакше `f`.

**Використайте рекурсію**, а не `any?` чи інші слова вищого порядку для послідовностей.

```factor
{ 2 0 4 } has-day-without-birds? .   ! => t
{ 3 8 1 5 } has-day-without-birds? . ! => f
```

## 4. Загальна кількість птахів від початку

Визначте `total`, щоб вона повертала суму всіх кількостей.

**Використайте рекурсію**, а не `sum`.

```factor
{ 4 0 9 0 5 } total .
! => 18
```

## 5. Зайняті дні

Зайнятим днем вважається день, коли птахів пʼять або більше. Визначте `busy-days`, щоб вона повертала кількість зайнятих днів.

**Використайте рекурсію**, а не `count`.

```factor
{ 4 5 0 0 6 } busy-days .
! => 2
```
