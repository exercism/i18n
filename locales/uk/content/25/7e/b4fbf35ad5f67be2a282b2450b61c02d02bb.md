# Інструкції

Коли прибульці з Ліспу вперше ступили на Землю, вони натрапили на безліч чудернацьких і чудових речей, але однією з їхніх найулюбленіших знахідок стали «улюбленці». Чесно кажучи, хто з прибульців не розчулився б над цуценям або кошеням?

Після недавньої відпустки на Землі Людвіг вирішив завести власного улюбленця! Єдина проблема? Аж надто багато варіантів! Може, ми напишемо програму, яка допоможе Людвігу знайти й доглянути наступного пухнастого друга?

## 1. Обираємо друга

Хоча Людвіг твердо налаштований завести улюбленця, у своїх роздумах він далі цього не зайшов. Тож перший крок: вирішити, якого саме улюбленця завести!

Людвіг хоче знайти друга, чия вдача доповнювала б його власну. Чи не могли б ми написати для Людвіга функцію `pal-picker`, яка приймає певну рису вдачі (ключове слово) і повертає тип улюбленця (рядок тексту (англ. string)) із цією рисою?

У цьому випадку:

- `:lazy` -> `"Cat"`
- `:energetic` -> `"Dog"`
- `:quiet` -> `"Fish"`
- `:hungry` -> `"Rabbit"`
- `:talkative` -> `"Bird"`

Для інших, невідомих вдач нехай функція повертає: `"I don't know... A dragon?"`

```lisp
(pal-picker :quiet) ; => "Fish"
```

## 2. У природному середовищі

Тепер, коли в Людвіга є новий друг, йому потрібне місце, де жити! Допоможімо Людвігу підібрати відповідний розмір лежанки, акваріума чи клітки для його улюбленця?

Тут Людвігу потрібна функція `habitat-fitter`, яка підбирає відповідний розмір житла (ключове слово) за вагою улюбленця в кілограмах (ціле число).

Яке житло потрібне улюбленцям кожного розміру:

- 40 кг і більше -> `:massive`
- від 20 кг до 39 кг включно -> `:large`
- від 10 кг до 19 кг включно -> `:medium`
- від 1 кг до 9 кг включно -> `:small`
- 0 кг і менше -> `:just-your-imagination`

```lisp
(habitat-fitter 42) ; => :MASSIVE
```

## 3. А тепер час їсти

Усі земні улюбленці мають одну спільну рису: потребу в їжі! Утім, Людвігу ця ідея дещо чужа, адже він схильний забувати наповнювати миску улюбленця.

Людвігу стала б у пригоді проста функція `feeding-time`, яка нагадувала б йому, коли миску треба наповнити. Функція приймає відсоток наповненості (ціле число) і повертає повідомлення у вигляді рядка тексту.

Якщо рівень їжі:

- Понад 20% -> `"All is well."`
- 20% або менше -> `"It's feeding time!"`

```lisp
(feeding-time 15) ; => "It's feeding time!"
```

## 4. Кодекс поведінки

Коли з усіма основами розібралися, Людвіг з нетерпінням чекає на купу захопливих занять, як-от «чухання» й гра в «апорт». Утім, не кожен улюбленець годиться для таких занять.

Людвіг хотів би мати пару функцій, `pet` і `play-fetch`, які приймають тип улюбленця (як рядок тексту) і повертають або нічого, або повідомлення на кшталт `"Maybe not with this pet..."`, якщо дія не годиться.

Вважаємо, що апорт приносять лише `"Dog"`, і що всіх улюбленців, крім `"Fish"`, можна чухати.

```lisp
(pet "Dog")         ; => NIL
(play-fetch "Fish") ; => "Maybe not with this pet..."
```
