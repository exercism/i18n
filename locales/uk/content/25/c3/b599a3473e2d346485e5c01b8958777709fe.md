# Вступ до лапок

Одну пораду нові програмісти bash чутимуть знову і знову:

> Беріть свої змінні в лапки!

Чому так?

Коли ми розкриваємо змінну (наприклад, `$name`), майже завжди ми хочемо використати _значення_ змінної як єдиний рядок тексту (англ. string) або число.
Ми не хочемо, щоб це значення несподівано обробили як два чи більше окремих рядків тексту.

## Лапки

Лапки - це основний механізм, який гарантує, що фрагмент тексту сприймається як одне слово.
Є два основні види лапок.

### Подвійні лапки

Подвійні лапки дозволяють усередині себе розкриття параметрів, арифметичне розкриття та підстановку команд.

```bash
echo "This is bash version $BASH_VERSION"
```

Усередину рядка в подвійних лапках можна включити буквальну подвійну лапку, поставивши перед нею зворотну скісну риску.

```bash
echo "She said \"Let me teach you about bash.\""
```

### Одинарні лапки

Одинарні лапки _не дозволяють_ жодних розкриттів усередині.

```bash
echo 'This is bash version $BASH_VERSION'
# ...^..................................^
# prints exactly: This is bash version $BASH_VERSION
```

Убудувати одинарну лапку в рядок в одинарних лапках _неможливо_.

## Важливість лапок

Що саме не так із `echo $name`?

Коли оболонка розбирає рядок коду, вона виконує [кілька видів розкриття][expansions], по порядку.
Два з останніх розкриттів - це _розбиття на слова_ та _розкриття імен файлів_.

### Розбиття на слова

Будь-які результати розкриття параметрів, підстановки команд чи арифметичного розкриття, _які виникли не в подвійних лапках_, можуть зазнати «розбиття на слова».
Оболонка бере розкритий результат і розбиває його за будь-якою послідовністю символів, наявних у значенні `$IFS`.
Типово це пробіл, табуляція та символ нового рядка.

Побачмо це в дії за допомогою циклу оболонки:

```bash
sentence="The quick brown fox jumps."
i=0
for word in "$sentence"; do echo "$((++i)) $word"; done
# ..........^.........^
```
виводить
```none
1 The quick brown fox jumps.
```

Але без лапок:

```bash
i=0
for word in $sentence; do echo "$((++i)) $word"; done
# .........^.........^
```
виводить
```none
1 The
2 quick
3 brown
4 fox
5 jumps.
```

Розгляньмо це з іншим значенням `$IFS`:

```bash
csv="first,second,third"
IFS=","
for word in $csv; do echo "$word"; done
```
виводить
```none
first
second
third
```

#### Вимкнення розбиття на слова

Спосіб вимкнути розбиття на слова - присвоїти `$IFS` порожній рядок тексту

```bash
sentence="The quick brown fox jumps."
IFS=    # or explicitly, IFS=""
i=0
for word in $sentence; do echo "$((++i)) $word"; done
# .........^.........^
```
виводить
```none
1 The quick brown fox jumps.
```

Однак залишати змінні без лапок не рекомендується, якщо тільки ми не вимкнемо також розкриття імен файлів.
Як це зробити, побачимо нижче.

### Розкриття імен файлів

«Шаблони glob» слугують для стислого опису зразка, за яким добирають набір файлів.
Наприклад, усі файли Markdown у каталозі можна зіставити шаблоном `*.md`.
[Шаблони glob][glob] існують від самого винайдення Unix.

Символи підстановки в glob такі:

* `*` збігається з нулем або більше будь-яких символів,
* `?` збігається рівно з одним будь-яким символом,
* `[...]` збігається рівно з одним символом із набору символів, перелічених усередині дужок.

   ~~~~exercism/advanced
   <details><summary>
   Є чимало подробиць про набори символів.
   Натисніть тут, щоб їх показати.
   </summary>

    * `[abc]` збігається рівно з одним символом, який є `a`, `b` або `c`.
        * щоб уключити буквальну закривальну дужку у вираз, поставте її першим символом після відкривальної дужки (після необовʼязкового `^`)
            * `[][]` - це набір символів, який збігається або з закривальною, або з відкривальною дужкою.
            * або екрануйте її зворотною скісною рискою: `[[\]]`
    * `[x-y]` збігається рівно з одним символом, який належить _діапазону_ від `x` до `y`
        * щоб уключити буквальний символ дефіса в набір символів, він має бути або першим символом після відкривальної дужки (після необовʼязкового `^`), або останнім символом перед закривальною дужкою.
            * `[-xy]` або `[xy-]` кожен збігається рівно з одним символом, який є `-`, `x` або `y`
            * або екрануйте його зворотною скісною рискою: `[x\-y]`
        * можна вказати кілька діапазонів, наприклад `[0-9A-Fa-f]` збігається з шістнадцятковою цифрою
    * `[^abc]` збігається рівно з одним символом, який **НЕ** є `a`, `b` або `c`,
    * `[^x-y]` збігається рівно з одним символом, який **НЕ** належить діапазону від `x` до `y`
    * `[[:character_class:]]` збігається з одним символом, який належить названому «character_class»
        * доступні класи символів такі: 
            * `lower` -- малі літери
            * `upper` -- великі літери
            * `alpha` -- літери
            * `digit` -- цифри
            * `alnum` -- літери та цифри
            * `space` -- пробільні символи
            * `blank` -- горизонтальні пробільні символи (пробіл і табуляція)
            * `xdigit` -- шістнадцяткові цифри
            * `word` -- символи, дозволені в ідентифікаторі (літери, цифри, знак підкреслення)
            * `punct` -- розділові знаки
            * `cntrl` -- керівні символи
            * `graph` -- «видимі» символи
            * `print` -- видимі символи плюс пробіл
        * їх можна комбінувати:
            * клас `[[:alpha:]]` складається з `[[:lower:][:upper:]]`
            * клас `[[:alnum:]]` складається з `[[:alpha:][:digit:]]`
            * клас `[[:word:]]` складається з `[[:alnum:]_]`
            * знак підкреслення (вісімкове 137) належить і до `[[:word:]]`, і до `[[:punct:]]`
            * клас `[[:graph:]]` складається з `[[:alnum:][:punct:]]`
            * клас `[[:print:]]` складається з `[[:graph:] ]` -- лише пробіл (вісімкове 040), а не будь-які інші пробільні символи.
   </details>   
   ~~~~

#### Перебирання списку файлів

Перебрати список файлів можна циклом `for`

```bash
for file in *.csv; do
    do_something_with "$file"
done
```

Звернімо увагу, що змінна `"$file"` узята в лапки.
Шаблон glob може повернути файли, у назвах яких є пробіли.
Нам треба взяти змінну в лапки, щоб команда `do_something_with` отримала рівно один аргумент - імʼя файлу.

#### Шаблони glob не є регулярними виразами

Шаблони glob **не є** регулярними виразами.

* збіг рівно з одним символом
   * регулярний вираз `.`
   * glob `?`
* збіг із нулем або більше символів
   * регулярний вираз `.*`
   * glob `*`
        * шаблон glob `.*` означає «зіставити імʼя файлу, у якому перший символ - буквальна крапка, за якою йде нуль або більше будь-яких символів».
* збіг з одним або більше символів
   * регулярний вираз `.+`
   * glob `?*`
* набори символів у регулярних виразах і в glob поводяться однаково.

#### Лапки та розкриття імен файлів

Бувають випадки, коли потрібно придушити розкриття імен файлів.
Обробка введених користувачем даних - один із таких випадків.
Розгляньмо такий фрагмент коду

```bash
read -p "Enter something: " user_input
echo $user_input
```

Якщо користувач введе зірочку (`*`), що буде виведено? 
Список файлів у поточному каталозі.
І це, найімовірніше, не те, що нам потрібно.

Інший приклад - передавати шаблони як аргументи програмам, які приймають шаблони.
Програму `tr` часто використовують для роботи з текстом. Щоб перетворити значення змінної на нижній регістр, можна зробити так

```bash
var="My Puppet"
echo "$var" | tr '[:upper:]' '[:lower:]'
```
виводить
```none
my puppet
```

Поширена помилка - забути взяти в лапки аргументи `tr`: `tr [:upper:] [:lower:]`

~~~~exercism/caution
Чому це проблема? 
Шаблони glob без лапок розкриються у список файлів, які їм відповідають.
Уявімо, що в людини, яка користується нашим скриптом, у поточному каталозі є файли з назвами `p`, `u` і `w`:

```bash
touch p u w
var="My Puppet"
echo "$var" | tr [:upper:] [:lower:]
```

Це призводить до помилки!

Шаблон `[:upper:]` без лапок збігається з будь-яким із символів `:`, `u`, `p`, `e` або `r`.
Шаблон `[:lower:]` без лапок збігається з будь-яким із символів `:`, `l`, `o`, `w`, `e` або `r`.
Bash зіставляє файли `p` і `u` з першим шаблоном, а файл `w` з другим, і `tr` викликають так

```bash
echo "$var" | tr p u w
```

А це неправильна кількість аргументів для `tr`.
~~~~

#### Вимкнення розкриття імен файлів

Вимкнути розкриття імен файлів можна командою [`set`][set].

```bash
echo *      # prints a list of files
set -f      # disable filename expansion
echo *      # prints a literal asterisk
set +f      # enable filename expansion
```

#### Керування розкриттям імен файлів

У вбудованої команди [`shopt`][shopt] є кілька налаштувань, які керують тим, як працює розкриття імен файлів.
Кілька цікавих із них:

* `shopt -s nocaseglob` -- виконувати зіставлення без урахування регістру
* `shopt -s extglob` -- увімкнути розширені шаблони
* `shopt -s nullglob` -- якщо жоден файл не збігається, замінити шаблон на порожнечу.
   Типова поведінка - залишити шаблон на місці як буквальний рядок тексту.
