# Докладніше

[Кортеж](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples) - це _незмінне_ обʼєднання неназваних, але впорядкованих значень.
Кортежі можуть містити будь-які (або кілька) типи даних, зокрема інші кортежі.

Кортежі визначають як розділені комами значення між символами `(` і `)`: `(<element_1>, ... , <element_n>)`.

```fsharp
("one", 2) // Tuple pair (2 values)
("one", 2, true) // Tuple triplet (3 values)
```

Порівнювати можна лише кортежі однакової довжини з однаковими типами (у тому самому порядку).
Кортежі мають структурну рівність: вони рівні _лише_ тоді, коли рівні всі їхні значення.

```fsharp
(1, 2) = (1, 2) // Same length, same types, same values, same order
// => true

(1, 2) = (2, 1) // Same length, same types, same values, different order
// => false

(1, 2) = (1, "2") // Same length, different types
// compiler error

(1, 2) = (1, 2, 3) // Different length
// compiler error
```

Існує [три способи видобути значення з кортежу](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples#obtaining-individual-values):

- Функції `fst` і `snd`
- Деконструкція кортежу
- Зіставлення зі зразком

```fsharp
let person = ("Jordan", 170)

// Option 1: fst/snd
let name1 = fst person
let length1 = snd person

// Option 2: deconstruction
let (name2, length2) = person

// Option 3: pattern matching
match person with
| name3, length3 -> printf "%s: %d" name3 length3
```

~~~~exercism/note
Технічно значення кортежу можна отримати за допомогою його властивостей `.Item1`, `.Item2`, ..., але так робити не рекомендується, і це призводить до попередження компілятора.
~~~~

## Ключові моменти про кортежі

Ось кілька ключових речей, які варто знати про кортежі:

- Конкретний примірник типу кортежу - це один обʼєкт, подібно до двоелементного масиву в C#, скажімо. У роботі з функціями він вважається одним параметром. Єдиний виняток - виклик коду, написаного не мовою F#, з кількома параметрами: у такому разі ми передаємо кортеж, і його значення автоматично розкладаються на відповідні значення параметрів.
- Типам кортежів не можна давати явні імена. «Імʼя» типу кортежу визначається комбінацією типів, які перемножуються між собою.
- Кома, а не дужки, є визначальним символом кортежу. Кортежі можна визначати й без дужок, хоча іноді це заплутує. У F#, якщо ви бачите кому, вона, найімовірніше, є частиною кортежу.
- Кортежі можна використовувати як аргументи функції та як повернене значення функції.
