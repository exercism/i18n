# Вступ

## Зрізи

Зрізи в Go схожі на масиви в інших мовах.
Вони містять кілька елементів певного типу (або інтерфейсу).

Зрізи в Go базуються на масивах.
Масиви мають фіксований розмір.
Зріз же - це динамічно розмірне, гнучке подання елементів масиву.

Зріз записують як `[]T`, де `T` - це тип елементів у зрізі:

```go
var empty []int                 // an empty slice
withData := []int{0,1,2,3,4,5}  // a slice pre-filled with some data
```

Можна отримати або встановити елемент за заданим індексом, що відраховується від нуля, використовуючи запис у квадратних дужках:

```go
withData[1] = 5
x := withData[1] // x is now 5
```

Можна створити новий зріз з наявного зрізу, взявши діапазон елементів.
Знову ж таки, використовуючи квадратні дужки, але вказуючи як початковий (включно), так і кінцевий (не включно) індекс.
Якщо не вказати початковий індекс, він типово дорівнює 0.
Якщо не вказати кінцевий індекс, він типово дорівнює довжині зрізу.

```go
newSlice := withData[2:4]
// => []int{2,3}
newSlice := withData[:2]
// => []int{0,1}
newSlice := withData[2:]
// => []int{2,3,4,5}
newSlice := withData[:]
// => []int{0,1,2,3,4,5}
```

Можна додавати елементи до зрізу за допомогою функції `append`.
Нижче ми додаємо `4` і `2` до зрізу `a`.

```go
a := []int{1, 3}
a = append(a, 4, 2)
// => []int{1,3,4,2}
```

`append` завжди повертає новий зріз, і коли ми просто хочемо додати елементи до наявного зрізу, зазвичай результат знову присвоюють тій самій змінній зрізу, яку ми передали першим аргументом, як це зроблено вище.

`append` також можна використати, щоб обʼєднати два зрізи:

```go
nextSlice := []int{100,101,102}
newSlice  := append(withData, nextSlice...)
// => []int{0,1,2,3,4,5,100,101,102}
```

## Варіативні функції

Зазвичай функції в Go приймають лише фіксовану кількість аргументів.
Однак у Go можна також писати варіативні функції.

Варіативна функція - це функція, яка приймає змінну кількість аргументів.

Якщо перед типом останнього параметра у визначенні функції стоїть трикрапка `...`, тоді функція може приймати будь-яку кількість аргументів для цього параметра.

```go
func find(a int, b ...int) {
    // ...
}
```

У наведеній вище функції параметр `b` варіативний, і ми можемо передати `b` 0 або більше аргументів.

```go
find(5, 6)
find(5, 6, 7)
find(5)
```

~~~~exercism/caution
Варіативний параметр має бути останнім параметром функції.
~~~~

Варіативні функції працюють так: змінну кількість аргументів перетворюють на зріз типу варіативного параметра.

Ось приклад реалізації варіативної функції.

```go
func find(num int, nums ...int) {
    fmt.Printf("type of nums is %T\n", nums)

    for i, v := range nums {
        if v == num {
            fmt.Println(num, "found at index", i, "in", nums)
            return
        }
    }

    fmt.Println(num, "not found in ", nums)
}

func main() {
    find(89, 90, 91, 95)
    // =>
    // type of nums is []int
    // 89 not found in  [90 91 95]

    find(45, 56, 67, 45, 90, 109)
    // =>
    // type of nums is []int
    // 45 found at index 2 in [56 67 45 90 109]

    find(87)
    // =>
    // type of nums is []int
    // 87 not found in  []
}
```

У рядку `find(89, 90, 91, 95)` наведеної вище програми змінною кількістю аргументів функції `find` є `90`, `91` і `95`.
Функція `find` приймає варіативний параметр типу `int` після `num`.
Отже, компілятор перетворить ці три аргументи на зріз типу `int` `[]int{90, 91, 95}` і потім передасть його функції `find` як `nums`.

Іноді в нас уже є зріз, і ми хочемо передати його варіативній функції.
Це можна зробити, передавши зріз, а після нього `...`.
Це вкаже компілятору використати зріз як є всередині варіативної функції.
Крок, описаний вище, де створюється зріз, у цьому випадку просто пропускається.

```go
list := []int{1, 2, 3}
find(1, list...) // "find" defined as shown above
```
