# Інструкції

У цій вправі ми будемо створювати звіти про погоду для місцевої новинної станції.

## Генеруємо звіти про погоду

Ми почнемо з кількох функцій-заглушок і такого переліку:

```rust
#[derive(Drop, Clone, PartialEq, Debug)]
pub enum WeatherCondition {
    Sunny,
    Rainy,
    Cloudy,
    Stormy
}
```

Нам потрібно буде відформатувати звіт про погоду у вигляді `"Today is <CONDITION> with a temperature of <TEMPERATURE> degrees Celsius."`.
Нам потрібно буде реалізувати функцію, яка виводить правильні погодні умови.

Наприклад, наведений нижче фрагмент демонструє очікуваний результат роботи функції `get_weather_report` для «rainy» дня.

```rust
get_weather_report(WeatherCondition::Rainy, "25")
// Returns: "Today is RAINY with a temperature of 25 degrees Celsius."
```

А для «sunny» дня:

```rust
get_weather_report(WeatherCondition::Sunny, "30")
// Returns: "Today is SUNNY with a temperature of 30 degrees Celsius."
```
