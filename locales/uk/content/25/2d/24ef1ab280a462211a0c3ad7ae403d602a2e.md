## Змінні екземпляра

Обʼєкти можуть зберігати власний стан, задаючи _змінні екземпляра_.
Ці змінні живуть усередині обʼєкта і зазвичай використовуються для зберігання якогось внутрішнього стану.

Змінні екземпляра завжди починаються з `@`.
Ми можемо створити нову змінну екземпляра, присвоївши змінну, що починається з `@`.
Наприклад:

```ruby
class Repeater
  def hear(something)
    # Save what's been heard into a new instance variable called @heard
    @heard = something
  end

  def repeat
    # Return the value of the instance variable
    @heard
  end
end

repeater = Repeater.new
repeater.hear("Hello, friend!")
print repeater.repeat # Prints "Hello, friend!"
```

Зазвичай обʼєкти задають свій початковий стан у методі `initialize`, який автоматично викликається, коли ми викликаємо `new` на класі.

```ruby
class Airplane
  def initialize
    @wings = 2
  end

  def wings
    @wings
  end
end

plane = Airplane.new
plane.wings # returns 2
```

Метод `initialize` також може приймати аргументи, щоб кожен екземпляр міг починати з власним станом:

```ruby
class Suitcase
  def initialize(locked)
    @locked = locked
  end
end
```

Гарна практика - вважати _змінні екземпляра_ приватними, закритими для зовнішнього читання й запису.
Замість цього ми визначаємо методи, щоб отримувати й задавати їхні значення.
Наприклад:

```ruby
class Suitcase
  def initialize
    @locked = false
  end

  def locked? # Query methods should be named with a trailing `?`
    @locked
  end

  def lock! # Methods which mutate state should have trailing `!`
    @locked = true
  end
end

suitcase = Suitcase.new
suitcase.locked? # false
suitcase.lock!
suitcase.locked? # true
```

## Nil

[Nil][nil-dictionary] - англійське слово, яке означає «ніщо» або «нуль».
У Ruby `nil` використовують, щоб виразити _відсутність_ обʼєкта.
В інших мовах програмування подібну роль можуть відігравати значення `null` або `none`.

```ruby
# I do not have a favorite color
favorite_color = nil
```

Будь-яка змінна екземпляра отримує типове значення `nil`, доки їй не нададуть іншого значення.

```ruby
print @favourite_color # prints nil
@favourite_color = "blue"
print @favourite_color # prints "blue"
```
