# Інструкції

Ми працюємо з командою веброзробників, щоб підтримувати сайт для місцевої баскетбольної команди. Команда веброзробників не дуже знайома з Elixir і просить функцію, яка дасть змогу витягувати дані з низки вкладених мап, щоб пришвидшити розробку.

## 1. Витягніть дані з вкладеної структури мап

Реалізуйте функцію `extract_from_path/2`, яка приймає два аргументи:

- `data`: вкладена структура мап із даними про баскетбольну команду.
- `path`: рядок тексту (англ. string), що складається з ключів, розділених крапками, щоб отримати значення, повʼязане з останнім ключем.

Якщо значення або ключ не існує в жодній точці шляху, поверніть `nil`.

```elixir
data = %{
  "team_mascot" => %{
    "animal" => "bear",
    "actor" => %{
      "first_name" => "Noel"
    }
  }
}

BasketballWebsite.extract_from_path(data, "team_mascot.animal")
# => "bear"
BasketballWebsite.extract_from_path(data, "team_mascot.colors")
# => nil
```

Використайте _поведінку Access_ під час реалізації цієї функції.

Не використовуйте жодних функцій модулів `Map` або `Kernel` для роботи з вкладеною структурою мап.

## 2. Відрефакторте за допомогою вбудованих функцій

Наш колега, який переглядає наш код, розповідає нам про функцію модуля `Kernel`, яка робить щось дуже схоже на нашу реалізацію.

Реалізуйте `get_in_path/2`, щоб використати цю функцію модуля `Kernel`.

Функція приймає ті самі аргументи, що й у частині 1.

```elixir
BasketballWebsite.get_in_path(data, "team_mascot.actor.first_name")
# => "Noel"
```
