# Інструкції

Ми працюємо в IT-службі підтримки й хочемо вдосконалити систему тікетів, щоб вона працювала ефективніше та давала статистику для нашого керівника.

Тікет має статус (new, in progress...), автора (його визначають за іменем користувача та ідентифікатором співробітника), його можна призначити IT-працівнику, і він містить історію коментарів.

Ось чотири завдання, які допоможуть удосконалити нашу поточну систему тікетів.

## 1. Виявити порожні коментарі

Порожні коментарі захаращують інтерфейс і не несуть жодної інформації, тож ми хочемо їх відфільтрувати.

Визначмо допоміжну функцію `emptyComment`, яка приймає пару «користувач/коментар» і повертає `True` для порожніх коментарів.

Використаймо деструктуризацію, щоб одразу дістати користувача й коментар із аргументу функції. Користувача можна проігнорувати, бо ця інформація нам не потрібна.

```elm
emptyComment ( User "Alice", "" )
-- => True
```

## 2. Порахувати кількість коментарів від автора тікета

Наш керівник хоче мати статистику залученості користувачів до роботи з тікетами.
Вона просить нас перевірити, скільки коментарів додає автор тікета.

Визначмо `numberOfCreatorComments`, яка приймає тікет і повертає кількість коментарів, доданих автором тікета.

Використаймо деструктуризацію в аргументі функції, щоб одночасно дістати запис із типу `Ticket` і потрібні нам поля цього запису.
Потім деструктуруймо `createdBy` у звʼязуванні `let`, щоб порахувати відповідні коментарі.
Використаймо функції з модуля `List` для підрахунку, а в аргументі анонімної функції застосуймо деструктуризацію, щоб розділити пару «користувач/коментар».

```elm
numberOfCreatorComments
numberOfCreatorComments
    (Ticket
        { status = Closed
        , createdBy = ( User "Chiaki", 1 )
        , assignedTo = Nothing
        , comments = [ ( User "Chiaki", "Never mind, fixed it." ) ]
        }
    )
-- => 1
```

## 3. Виявити тікети, призначені команді розробників

Деякі тікети потрібно ескалювати до Аліси, Боба або Чарлі з команди розробників.
Важливо стежити за ними, щоб переконатися, що робота просувається.

Визначмо допоміжну функцію `assignedToDevTeam`, яка перевіряє, чи призначено тікет одному з членів команди розробників.

Використаймо деструктуризацію в аргументі функції, щоб дістати запис із типу `Ticket` і потрібне нам поле.
Потім скористаймося однією конструкцією `case`, щоб перевірити, чи призначено тікет Алісі, Бобу або Чарлі: рекурсивне зіставлення зі зразком дістане їхні імена користувачів, а літеральне зіставлення зі зразком їх збіжить.

```elm
assignedToDevTeam
    (Ticket
        { status = InProgress
        , createdBy = ( User "Bill", 2 )
        , assignedTo = Just (User "Alice")
        , comments = [ ( User "Bill", "What's an 'undefined'?" ) ]
        }
    )
-- => True
```

## 4. Призначити тікети IT-працівникам

Іноді купу тікетів потрібно перепризначити іншим IT-працівникам.

Визначмо функцію `assignTicketTo`, яка допоможе це зробити. Функція приймає два аргументи: користувача, якому призначають тікет, і сам тікет.
Якщо статус тікета `New`, призначмо його новому користувачу й змінімо статус на `InProgress`.
Для інших статусів просто перепризначмо тікет новому користувачу, крім тікетів зі статусом `Archived`, які не можна змінювати взагалі.

Використаймо деструктуризацію в аргументі функції, щоб дістати запис із типу `Ticket` і потрібне нам поле, а також скористаймося ключовим словом `as`, щоб зберегти весь запис таким, як він є.
Скористаймося однією конструкцією `case`, щоб зіставити статус зі зразком і повернути відповідний тікет, створений зі зміненого оригінального запису, який ми зберегли за допомогою ключового слова `as`.

```elm
assignTicketTo (User "Danny")
    (Ticket
        { status = New
        , createdBy = ( User "Jesse", 3 )
        , assignedTo = Just (User "Alice")
        , comments = [ ( User "Jesse", "I've been waiting for 6 months!!" ) ]
        }
    )
-- => Ticket
--        { status = InProgress
--        , createdBy = ( User "Jesse", 3 )
--        , assignedTo = Just (User "Danny")
--        , comments = [ ( User "Jesse", "I've been waiting for 6 months!!" ) ]
--        }
```
