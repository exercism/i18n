# Докладніше

Головне, що варто запамʼятати про рядки тексту (англ. string) у C#: це незмінні обʼєкти, які подають текст як послідовність символів Unicode (літер, цифр, розділових знаків тощо). Подвійні лапки використовують, щоб створити екземпляр `string`:

```csharp
string fruit = "Apple";
```

Щоб працювати з рядком тексту, можна викликати один із його [методів][methods] або [властивостей][properties]. Оскільки значення рядка тексту ніколи не змінюються після того, як їх створили, усі методи роботи з рядками повертають новий рядок тексту.

Рядок тексту обмежують символи подвійних лапок (`"`). Деякі спеціальні символи потрібно [екранувати][escaping] за допомогою символу зворотного слеша (`\`). Рядок тексту також можна позначити символом «at» (`@`), і тоді він стане [дослівним рядком][verbatim], який ігнорує будь-які екрановані символи.

```csharp
string escaped = "c:\\test.txt";
string verbatim = @"c:\test.txt";
escaped == verbatim;
// => true
```

Якщо потрібна лише частина рядка тексту, можна скористатися [методом `Substring()`][substring], щоб видобути саме її:

```csharp
string sentence = "Frank chases the bus.";
string name = sentence.Substring(0, 5);
// => "Frank"
```

Метод [`IndexOf`()][indexof] можна використати, щоб знайти індекс першого входження одного рядка тексту в інший; він повертає `-1`, якщо вказаного значення не вдалося знайти:

```csharp
"continuous-integration".IndexOf("integration")
// => 11

"continuous-integration".IndexOf("deployment")
// => -1
```

Нарешті, існує [багато способів зʼєднати рядки тексту][concatenation]. Найпростіший з них - скористатися [оператором `+`][plus-operator].

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

Для будь-якого форматування рядків, складнішого за просте зʼєднання, краще використовувати [інтерполяцію рядків][interpolation]. Щоб увімкнути інтерполяцію в рядку тексту, потрібно поставити перед ним символ долара (`$`).

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
