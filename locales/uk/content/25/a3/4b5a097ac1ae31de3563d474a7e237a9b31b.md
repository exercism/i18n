## Запуск тестів

1. Перейдіть до кореня каталогу вправи з PHP, а саме `<EXERCISM_WORKSPACE>/php`.
   Щоб знайти робочий простір Exercism, виконайте

   ```shell
   exercism workspace
   ```

2. Встановіть [PHPUnit], якщо його ще не встановлено.
3. Запустіть тести командою:

   ```shell
   phpunit test_file.php
   ```

   Наприклад, щоб запустити тести для вправи «Привіт, світ», виконайте:

   ```shell
   phpunit HelloWorldTest.php
   ```

[PHPUnit]: https://exercism.org/docs/tracks/php/installation#h-via-php-archive-phar
