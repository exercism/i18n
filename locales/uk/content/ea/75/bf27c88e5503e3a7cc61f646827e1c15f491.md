# Модний бутик

## Історія

Уявімо, що ми керуємо онлайн-бутиком модного одягу. Чорна пʼятниця вже на носі, тож нам треба переглянути запаси, щоб переконатися, що ми готові.

Один товар у запасі представлено словником, а весь запас - масив таких словників.

```elixir
%{
  name: "White Shirt",
  price: 40,
  quantity_by_size: %{s: 3, m: 7, l: 8, xl: 4}
}
```

## Завдання

- Відсортувати товари за ціною
- Знайти всі товари без ціни
- Збільшити кількість товару на одиницю
- Обчислити загальну кількість товару
