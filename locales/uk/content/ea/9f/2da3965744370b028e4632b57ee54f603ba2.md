# Вступ

## Константи

Модифікатор `const` можна (і зазвичай варто) застосовувати до будь-якого поля, значення якого відоме під час компіляції і не змінюється протягом часу виконання програми.

```csharp
private const int num = 1729;
public const string title = "Grand" + " Master";
```

Модифікатор `readonly` можна (і зазвичай варто) застосовувати до будь-якого поля, яке не вдається зробити `const`, значення якого не змінюється протягом часу виконання програми і яке встановлюється або вбудованим ініціалізатором, або під час створення екземпляра (конструктором чи методом, який викликає конструктор).

```csharp
private readonly int num;
private readonly System.Random rand = new System.Random();

public MyClass(int num)
{
    this.num = num;
}
```

## Захисне копіювання

У ситуаціях, чутливих до безпеки (або навіть просто у великій кодовій базі, де розробники мають різні пріоритети й наміри), варто уникати того, щоб публічний API класу можна було обійти, приймаючи й зберігаючи змінні параметри методу або відкриваючи змінний член класу через повернене значення чи як `out`-параметр.

## Колекції лише для читання

Хоча модифікатор `readonly` захищає значення або посилання в полі від перезапису, він не дає жодного захисту для членів типу-посилання.

```csharp
readonly List<int> ints = new List<int>();

void Foo()
{
    ints.Add(1);    // ok
    ints = new List<int>(); // fails to compile
}
```

Щоб усі члени типу-посилання були захищені, поля можна зробити `readonly`, а автоматичні властивості оголосити без засобу доступу `set`.

Бібліотека базових класів (BCL) надає деякі версії колекцій, доступні лише для читання, коли потрібно зупинити оновлення членів колекції. Вони мають вигляд обгорток:

- `ReadOnlyDictionary<T>` надає `Dictionary<T>` лише для читання.
- `ReadOnlyCollection<T>` надає `List<T>` лише для читання.
