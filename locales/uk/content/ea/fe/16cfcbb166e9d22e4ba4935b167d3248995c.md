# Інструкції

Агов, сміливі ліспери! [Ленні, лісп-прибульцю][alien], потрібна допомога! Ленні хоче піти погуляти з усіма іншими лісп-прибульцями, але батьки сказали Ленні, що нікуди не пустять, поки в кімнаті не прибрано.

Річ у тім, що Ленні ледве бачить підлогу! Ленні не відрізняє свої атоми від консів, символи від ключових слів, `car` від `cdr`!

Чи можемо ми допомогти Ленні дати раду цьому безладдю? Не забудьмо [свої дужки][xkcd], вони нам знадобляться!

## 1. Нагадайте Ленні про символи

Перш ніж Ленні почне, треба нагадати, як мають вигляд символи та ключові слова, адже від останнього прибирання минуло чимало часу... Допоможіть Ленні, визначивши дві функції: `lennys-favorite-food`, яка обчислюється в певний символ, і `lennys-secret-keyword`, яка обчислюється в певне ключове слово. Наприклад:

```lisp
(lennys-favorite-food) ; => LASAGNA
```

```lisp
(lennys-secret-keyword) ; => :ALIENS-ARE-REAL
```

Зауважте, що можна повернути будь-який символ чи ключове слово (якщо ми не любимо лазанью чи не віримо в прибульців).

## 2. Допоможіть Ленні розрізняти атоми та конси

Щойно Ленні пригадає символи та ключові слова, настане час прибирати! Щоб розібрати всі S-вирази, розкидані по кімнаті, Ленні потрібна допомога визначити, що є консом, а що атомом. Допоможіть, реалізувавши дві функції, `is-an-atom-p` та `is-a-cons-p`:

```lisp
(is-an-atom-p 'one-thing)    ; => T
(is-an-atom-p '(two things)) ; => NIL
```

```lisp
(is-a-cons-p 'one-thing)    ; => NIL
(is-a-cons-p '(two things)) ; => T
```

У цьому розділі може стати в пригоді чимало вбудованих функцій Lisp. Крім того, поки що `T` можна просто вважати правдою, а `NIL` неправдою.

## 3. Допоможіть Ленні розділити конси

Нарешті, конси Ленні надто громіздкі, щоб акуратно їх скласти, тож їх треба розділити на менші частини. Допоможіть, визначивши ще дві функції, які розберуть їхні конси (`first-thing` і `rest-of-it`).

```lisp
(first-thing '(first second third)) ; => FIRST
(rest-of-it  '(first second third)) ; => (SECOND THIRD)
```

І знову тут можуть стати в пригоді деякі вбудовані функції Common Lisp.
