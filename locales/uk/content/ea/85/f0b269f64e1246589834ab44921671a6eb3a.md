# Вступ

Крім оголошень функцій та функціональних виразів, у JavaScript є ще один дуже лаконічний синтаксис для визначення функції.
Такі функції називаються _стрілковими функціями_.

У цій концепції ми зосередимося на синтаксисі, який використовується для написання стрілкової функції.
Є відмінності в тому, як працює стрілкова функція, наприклад привʼязування _this_, і про них ітиметься в інших концепціях.

Ось порівняння оголошення функції та стрілкової функції.

```javascript
function addUpTwoNumbers(num1, num2) {
  return num1 + num2;
}

// function keyword removed and => added
const addUpTwoNumbers = (num1, num2) => {
  return num1 + num2;
};
```

Вище ми бачимо, що синтаксис стрілкової функції:

1. прибирає ключове слово `function`
2. оголошує ідентифікатор `addUpTwoNumbers` як `const`
3. додає жирну стрілку `=>`

Якщо тіло функції містить лише інструкцію `return`, як у прикладі вище, то `{}` і ключове слово `return` можна опустити.

<!-- prettier-ignore-start -->
```javascript
const addUpTwoNumbers = (num1, num2) => { return num1 + num2 };

// can be shortened to
const addUpTwoNumbers = (num1, num2) => num1 + num2;
// braces {} and return removed
```
<!-- prettier-ignore-end -->

В окремому випадку, коли стрілкова функція повертає лише обʼєкт, потрібно взяти цей обʼєкт у дужки, щоб мати змогу опустити інструкцію `return`.

```javascript
// explicit return of object
const addUpTwoNumbers = (num1, num2) => {
  return {
    num1,
    num2,
  };
};

// implicit return of object
const addUpTwoNumbers = (num1, num2) => ({ num1, num2 });
```

Використання дужок навколо параметрів залежить від кількості параметрів.

<!-- prettier-ignore-start -->
```javascript
// one parameter does not need parenthesis
const square = num => num * num;

// two or more parameters need to be wrapped in parenthesis
const addUpTwoNumbers = (num1, num2) => num1 + num2;
```
<!-- prettier-ignore-end -->
