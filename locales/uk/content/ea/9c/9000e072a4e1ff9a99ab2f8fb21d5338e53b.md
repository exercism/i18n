# Вступ

У Python [перелік](https://docs.python.org/3/library/enum.html) складається з імен, привʼязаних до унікальних значень `literal` або `constant`. Переліки визначаються через успадкування класу `Enum`. Вбудовані типи переліків доступні в модулі `enum`, а клас `Enum` можна імпортувати за допомогою `from enum import Enum`.

```python
class Color(Enum):
    RED = 1
    GREEN = 2
```

Зауважмо, що значення членів переліку можуть бути будь-якого типу даних, наприклад str, tuple, float тощо.

```python
class Color(Enum):
    RED = 'red'
    GREEN = 'green'
```

Якщо двом членам переліку присвоїти однакове значення, то член, призначений пізніше, стане псевдонімом для першого. Не можна використовувати однакове імʼя для двох членів переліку.

```python
class Color(Enum):
    RED = 1
    GREEN = 2
    ALIAS_OF_RED = 1

Color.ALIAS_OF_RED
#=> <Color.RED: 1>

Color.ALIAS_OF_RED.value
#=> 1
```

Перебрати члени переліку можна за допомогою стандартного синтаксису `for member in`:

```python
for member in Color:
    print((member.name, member.value))
#=> (RED, 1)
#=> (GREEN, 2)
```

Члени переліку можна порівнювати за допомогою [`is` (_оператор ідентичності_)](https://www.w3schools.com/python/ref_keyword_is.asp) або `is not`. `==` або `!=` (_оператори рівності_) працюють так само.

```python
a = Color.RED

a is Color.RED
#=> True

a == Color.RED
#=> True
```

Щоб отримати член переліку за заданим значенням, можна скористатися `EnumName(value)`:

```python
g = Color(2)

g is Color.GREEN
#=> True

g
#=> <Color.GREEN: 2>
```
