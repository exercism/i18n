# Докладніше

У Common Lisp іменовані параметри називають ключовими параметрами.

Ключові параметри позначають ключовим словом `&key` у лямбда-списку.
Ключові параметри не є обовʼязковими, можуть мати типове значення, а також задавати «параметр supplied-p», який матиме значення «правда» або «неправда» залежно від того, чи передали для цього параметра аргумент.

```lisp
(defun keyword-parameter (&key (arg -1) arg)
(keyword-parameter)         ; => -1
(keyword-parameter :arg 13) ; => 13
```

В аргументах функції ключові параметри задають їхнім «ключовим іменем», яке типово є ключовим символом, утвореним з імені параметра (_тобто_ ключовий параметр `name` має ключове імʼя `:name`).
Можна задати інше імʼя для ключового параметра, використавши список із ключового імені та імені параметра замість самого лише імені параметра:

```lisp
(defun other-keyword-name (&key ((other-name arg))) (list arg))
(other-keyword-name 'other-name 5) ; => (5)
```

Хоча різні типи параметрів можна поєднувати з іншими типами параметрів (необовʼязковими та ключовими), це може бути проблематично, тож робити це слід обережно.
Про це йдеться в розділі [«Поєднання різних типів параметрів»][pcl-function] у книзі Practical Common Lisp.

[pcl-function]: http://www.gigamonkeys.com/book/functions.html
