# Вступ

Включення дають змогу легко й декларативно перетворювати _Enumerable_.

Щоб оголосити найпростіше включення, можна використати ключове слово `for`, за яким іде _генератор_ і _блок do_, який створює нові значення з перелічених.

```elixir
for n <- [0, 1, 2, 3], do: n + 1
# => [1, 2, 3, 4]
```

Включення також можуть мати _фільтри_. Значення, які не проходять фільтр, вилучаються з остаточного масиву:

```elixir
for n <- [0, 1, 2, 3], n > 1, do: n + 1
# => [3, 4]
```

Складніші включення можна оголосити на кількох рядках:

```elixir
for {atom, number} <- [a: 1, b: 2, c: 3, d: 4],
    rem(number, 2) == 0 do
  atom
end

# => [:b, :d]
```

_Декартів добуток_ можна створити за допомогою кількох генераторів. Це означає, що кожне значення, згенероване першим генератором, буде поєднане один раз із кожним значенням, згенерованим другим генератором:

```elixir
for x <- [0, 1],
    y <- [0, 1] do
  {x, y}
end

# => [{0, 0}, {0, 1}, {1, 0}, {1, 1}]
```
