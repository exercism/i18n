# Інструкції

У цій вправі ми будемо писати код, який друкує бейджі з іменами для працівників фабрики.

## 1. Надрукувати бейдж для працівника

Працівники мають ідентифікатор, імʼя та назву відділу. Підписи на бейджах працівників мають такий формат: `"[id] - name - DEPARTMENT"`.
Реалізуйте метод `Badge.print()`, щоб він повертав підпис на бейджі працівника:

```java
Badge badge = new Badge();
badge.print(734, "Ernest Johnny Payne", "Strategic Communication");
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

Зверніть увагу, що на бейджі назва відділу має бути написана великими літерами.

## 2. Надрукувати бейдж для нового працівника

Через особливість компʼютерної системи нові працівники іноді ще не мають ідентифікатора, коли починають працювати на фабриці.
Оскільки бейджі обовʼязкові, вони отримають тимчасовий бейдж без префікса з ідентифікатором. Змініть метод `Badge.print()`, щоб він підтримував нових працівників, які ще не мають ідентифікатора:

```java
Badge badge = new Badge();
Badge.print(null, "Jane Johnson", "Procurement");
// => "Jane Johnson - PROCUREMENT"
```

## 3. Надрукувати бейдж для власника

Навіть власник фабрики мусить постійно носити бейдж.
Однак у власника немає відділу. У цьому випадку замість назви відділу на бейджі має бути надруковано `"OWNER"`.
Змініть метод `Badge.print()`, щоб він друкував підпис для власника:

```java
Badge badge = new Badge();
badge.print(254, "Charlotte Hale", null);
// => "[254] - Charlotte Hale - OWNER"
```

Зверніть увагу, що власник може бути також новим працівником:

```java
Badge badge = new Badge();
badge.print(null, "Charlotte Hale", null);
// => "Charlotte Hale - OWNER"
```
