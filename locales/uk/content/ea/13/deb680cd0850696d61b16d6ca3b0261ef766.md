# Вступ

[Go](https://golang.org) — статично типізована компільована мова програмування.
Ця вправа знайомить із трьома важливими можливостями мови: пакетами, функціями та змінними.

## Пакети

Застосунки на Go організовано в пакети.
Пакет обʼєднує файли з кодом, що лежать в одній директорії.
Усі файли з кодом в одній директорії повинні мати однакову назву пакета.
Коли пакет імпортують, використовувати можна лише ті сутності (функції, типи, змінні, константи), назви яких починаються з великої літери.
У Go рекомендовано називати ідентифікатори в стилі `camelCase`, крім тих, що мають бути доступними з інших пакетів, - їх записують у стилі `PascalCase`.

```go
package lasagna
```

## Змінні

Go — статично типізована мова, тобто всі змінні [повинні мати визначений тип](https://en.wikipedia.org/wiki/Type_system) під час компіляції.

Змінну можна оголосити, явно вказавши її тип:

```go
var explicit int // Explicitly typed
```

Також можна скористатися ініціалізатором, і компілятор визначить тип змінної відповідно до типу ініціалізатора.

```go
implicit := 10   // Implicitly typed as an int
```

Після оголошення змінній можна присвоювати значення за допомогою оператора `=`.
Після оголошення тип змінної вже ніколи не може змінитися.

```go
count := 1 // Assign initial value
count = 2  // Update to new value

count = false // This throws a compiler error due to assigning a non `int` type
```

## Константи

Константи зберігають дані так само, як змінні, але їхнє значення не може змінитися під час виконання програми.

Константи оголошують за допомогою ключового слова `const`; вони можуть бути числами, символами, рядками тексту (англ. string) або булевими значеннями (англ. Boolean):

```go
const Age = 21 // Defines a numeric constant 'Age' with the value of 21
```

## Функції

Функції в Go приймають нуль або більше параметрів.
Параметри потрібно явно типізувати, тут немає виведення типу.

Значення з функцій повертають за допомогою ключового слова `return`.

Щоб викликати функцію, потрібно вказати її назву та передати аргументи для кожного з її параметрів.

Зауважмо, що Go підтримує два типи коментарів.
Однорядкові коментарі починаються з `//`, а багаторядкові вставляють між `/*` і `*/`.

```go
package greeting

// Hello is a public function.
func Hello (name string) string {
    return hi(name)
}

// hi is a private function.
func hi (name string) string {
    return "hi " + name
}
```
