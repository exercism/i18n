# Вступ

## Умовні конструкції

Умовні конструкції - це конструкції, які ухвалюють рішення: вони можуть або виконувати побічні ефекти, або керувати потоком виконання програми.
До умовних конструкцій належать `if`, `if/else`, `switch` і `ternary`.

Умовні конструкції використовують, щоб поставити запитання про значення або про відношення між значеннями.
Запитання дає булеву відповідь (англ. Boolean), але сама конструкція `if` може повернути будь-яке значення або просто виконати побічний ефект.

## Конструкції `if`

Найпростіша конструкція `if` обчислює вираз і виконує один рядок.
Вираз, який перевіряють, завжди беруть у дужки.

Вона може виконати побічний ефект

```c
if (count > 10)
    printf("count is greater than 10");
```

або змінити потік виконання


```c
if (count > 10)
    return sum;
```

Якщо конструкція `if` виконує більше ніж один рядок, ці рядки потрібно взяти у фігурні дужки

```c
if (count > 10) {
    printf("count is greater than 10");
    return sum;
}
```

Деякі команди можуть домовлятися, що конструкції `if` завжди використовують фігурні дужки, навіть для одного рядка.


## `if` і `else`

Конструкцію `if` можна поєднати з `else`

```c
if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## `else if`


`else` можна поєднати з іншим `if` і утворити так звану `if-else-if ladder`.

```c
if (number == 0)
    return "zero";
else if (number < 0)
    return "negative";
else if (number < 10)
    return "single digit";   
else if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## `switch`


Іноді `if-else-if ladder` краще подати через `switch`.
Як і в `if`, вираз, який перевіряють, завжди беруть у дужки.

```c
switch (number) {
    case -1:
        return "negative one";
    case 0:
        return "zero";
    case 1:
        return "positive one";
    case 10:
        return "positive ten";
    case -10:
        return "negative ten";
    default:
        return "don't care";
}
```

Варіант `default` виконується, якщо значення, яке перевіряють, не збігається з жодним із попередніх варіантів.

Якщо варіант `switch` не повертає значення, то для завершення кожного варіанта зазвичай додають `break`, інакше логіка «провалюється» в наступний варіант.
Іноді провалювання використовують навмисно

```c
switch (number) {
    case 0:
        msg = "zero"; break;
    case 1:
        msg = "one"; break;
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

Коли провалювання відбувається ненавмисно, це bug.

```c
switch (number) {
    case 0:
        msg = "zero"; // bug! fallthrough of 0 will set msg to "one"
    case 1:
        msg = "one"; break; 
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

Switch буває корисним, коли перевіряють конкретні значення, а не діапазон значень.
Він може бути швидшим за `if-else-if ladder`, бо компілятор може оптимізувати конструкцію `switch` так, як не може зробити з драбинкою.
Іноді switch читається краще, ніж драбинка.

## Тернарний оператор (він же умовний)

Тернарний оператор - це умовна конструкція з трьох частин, яку часто використовують, щоб присвоїти значення.
Вираз, який перевіряють, стоїть перед знаком питання, і його не обовʼязково брати в дужки.
Значення, яке повертається, якщо умова правдива, стоїть перед двокрапкою, а значення, яке повертається, якщо умова неправдива, - після двокрапки.
Повертати можна як літерал значення, так і змінну.

```c
int i = j > 5 ? 5: j;
```

Тернарні оператори можна вкладати, щоб зменшити синтаксичний безлад.

```c
// the below could also be 
i = j > 5 ? j :k > 5 ? k: 10;
// but that may not be quite as readable

i = j > 5 ? j
    :k > 5 ? k
    :10;

// which is the same as
if (j > 5) i = j;
else if (k > 5) i = k;
else i = 10;
```
