# Додаток до вказівок

## Структура проєкту

Вправи з Clojure на Exercism підтримують два найпоширеніші інструменти для керування залежностями й тестування: [leiningen][leiningen] і [Clojure CLI][clojure-cli].

У каталозі `test` ми знайдемо файл з тестами `hello_world_test.clj`.
Напишіть код у `src/hello_world.clj`. Він має використовувати простір імен `hello-world`, щоб тести могли його підхопити.

### Запуск тестів за допомогою Clojure CLI

```
$ clj -X:test
```

### Запуск тестів за допомогою Leiningen

```
$ lein test

lein test hello-world-test

Ran 3 tests containing 3 assertions.
0 failures, 0 errors.
```

Потім надішліть вправу за допомогою:

```
$ exercism submit src/hello_world.clj
```

Докладніші вказівки та навчальні матеріали шукайте на [сторінці мови Clojure на Exercism][exercism-clojure].

[leiningen]: https://leiningen.org
[clojure-cli]: https://clojure.org/guides/deps_and_cli
[exercism-clojure]: https://exercism.org/tracks/clojure
