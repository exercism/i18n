# Інструкції

Mecha Munch™, компанія з автоматизації закупівель продуктів, щойно найняла нас працювати над своїм застосунком для замовлень.
Перед нашою командою стоїть завдання створити MVP (_[мінімально життєздатний продукт][mvp]_), який керує всіма базовими операціями з кошиком для покупок: дозволяє користувачам додавати, видаляти та сортувати свої замовлення.
На щастя, усі грошові операції та оформлення замовлень узяла на себе інша команда!

## 1. Додавання товарів до кошика користувача

MVP має дозволяти користувачу додавати товари до свого кошика для покупок.
Це може бути один товар або кілька товарів одразу.
Оскільки це MVP, кількість товару позначається _повтореннями_.
Якщо користувач хоче додати 2 апельсини, «Oranges» зʼявиться у вхідній послідовності, яку можна перебрати, двічі.
Якщо товар уже є в кошику користувача, його кількість у кошику слід збільшити на 1.
Якщо товар _новий_ для кошика, його слід додати з кількістю 1.

Створіть функцію `add_items!(<cart>, <items>)`, яка приймає словник кошика та послідовність товарів для додавання як аргументи.
Вона має повернути оновлений словник кошика для покупок користувача.

```julia-repl
julia> additems!(Dict("Banana" => 3, "Apple" => 2, "Orange" => 1),
                 ("Apple", "Apple", "Orange", "Apple", "Banana"))
Dict{String, Int64} with 3 entries:
  "Apple"  => 5
  "Orange" => 2
  "Banana" => 4

julia> additems!(Dict("Banana" => 3, "Apple" => 2, "Orange" => 1),
                 ["Banana", "Orange", "Blueberries", "Banana"])
Dict{String, Int64} with 4 entries:
  "Blueberries" => 1
  "Apple"       => 2
  "Orange"      => 2
  "Banana"      => 5
```

## 2. Оновлення розділу «ідеї» з рецептами

У застосунку є розділ «ідеї», наповнений готовими рецептами різних кухонь.
Користувач може вибрати будь-який із цих рецептів, і всі його інгредієнти автоматично додадуться до кошика для покупок.
Керівник проєкту попросив створити спосіб редагувати ці рецепти з розділу «ідеї», адже команда контенту постійно змінює інгредієнти та їхні кількості.

Створіть функцію `update_recipes!(<ideas>, <updates>)`, яка приймає словник «ідеї» та словник оновлень рецептів як аргументи.

## 3. Надсилання кошика користувача до магазину для виконання замовлення

Застосунок має надіслати кошик користувача до магазину для виконання замовлення.
Однак працівникам магазину потрібно знати, де знайти товар, за унікальним кодом проходу.
«Кошик для виконання» потрібно відсортувати за кодами проходів товарів, щоб працівники магазину працювали ефективніше.

Створіть функцію `send_to_store(<cart>, <aislecodes>)`, яка приймає кошик користувача та словник із номерами проходів магазину.
Функція має повернути обʼєднаний «кошик для виконання», що містить пару `aislecode => quantity` для кожного товару, який замовляє покупець.
Товари мають бути впорядковані за своїми кодами проходів.

```julia-repl
julia> cart = Dict("Orange" => 1, "Milk" => 2, "Banana" => 3, "Apple" => 2, "Chocolate" => 2);

julia> aislecodes = Dict("Orange" => 2.4, "Milk" => 3.3, "Banana" => 2.6, "Apple" => 2.2, "Chocolate" => 5.7);

julia> send_to_store(cart, aislecodes)
5-element Vector{Pair{Float64, Int64}}:
 2.2 => 2
 2.4 => 1
 2.6 => 3
 3.3 => 2
 5.7 => 2
```

## 4. Оновлення запасів магазину відповідно до того, що замовив користувач.

Застосунок не може безкінечно приймати замовлення покупців.
Зрештою в магазині закінчаться різні товари.
Тож MVP нашого застосунку має оновлювати запаси магазину щоразу, коли користувач надсилає своє замовлення до магазину.
Інакше покупці замовлятимуть товари, яких насправді немає в наявності.

Створіть функцію `update_store_inventory!(<inventory>, <cart>)`, яка приймає `cart` та `inventory`.
Функція має зменшити запаси магазину на кількість, «замовлену» в `cart`, а потім повернути словник товарів, яких немає в наявності (тобто тих, кількість яких сягнула `0`).

```julia-repl
julia> inventory = Dict("Banana" => 15, "Apple" => 12, "Orange" => 1, "Milk" => 4);

julia> cart = Dict("Orange" => 1, "Milk" => 2, "Banana" => 3, "Apple" => 2);

julia> update_store_inventory!(inventory, cart)
Dict{String, Int64} with 1 entry:
  "Orange" => 0

julia> inventory
Dict{String, Int64} with 4 entries:
  "Milk"   => 2
  "Apple"  => 10
  "Orange" => 0
  "Banana" => 12
```

## 5. Повторне замовлення товарів, яких немає в наявності.

Окрім оновлення запасів, застосунок може допомогти з їх поповненням.
MVP має вміти готувати мінізамовлення на будь-які товари, які закінчилися після замовлення покупця.
Це спростить запуск великого замовлення.
До того ж іноді є акційні товари з обмеженим терміном дії, яких немає в списку запасів.
Якщо вони розпродалися до завершення акції, це означає, що вони популярні, і їх можна додати до списку запасів.

Створіть функцію `reorder!(<outofstock>, <stock>)`, яка приймає `outofstock` та `stock`.
Словник `stock` містить стандартні товари в запасі та кількості для їх повторного замовлення.
Словник `outofstock` є результатом `update_store_inventory!`, а саме словником товарів із нульовою кількістю.
Кількості в `outofstock` слід оновити відповідно до `stock` і повернути.
Також будь-які товари з `outofstock`, яких немає в `stock`, слід додати до `stock` з типовою кількістю `100`.

```julia-repl
julia> inventory = Dict("Banana" => 15, "Apple" => 12, "Orange" => 1, "Milk" => 4, "Chocolate" => 2);

julia> cart = Dict("Orange" => 1, "Milk" => 2, "Banana" => 3, "Apple" => 2, "Chocolate" => 2);

julia> stock = Dict("Banana" => 150, "Apple" => 120, "Orange" => 120, "Milk" => 45);

julia> outofstock = update_store_inventory!(inventory, cart)
Dict{String, Int64} with 1 entry:
  "Orange"    => 0
  "Chocolate" => 0

julia> reorder!(outofstock, stock)
Dict{String, Int64} with 1 entry:
  "Orange"    => 120
  "Chocolate" => 100

julia> stock 
Dict{String, Int64} with 5 entries:
  "Milk"      => 45
  "Apple"     => 120
  "Chocolate" => 100
  "Orange"    => 120
  "Banana"    => 150
```
