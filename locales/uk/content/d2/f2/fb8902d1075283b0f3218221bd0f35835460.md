# Про

Gleam має функції першого класу: функції тут - це звичайні значення, які можна присвоїти змінним, передати як аргументи й повернути з інших функцій.

На іменовану функцію, визначену в модулі, можна посилатися за її назвою.

```gleam
pub fn main() {
  // Assign the function to a variable
  let f = add_one
  
  // Invoke the function
  f(1) // -> 2
  f(2) // -> 3
}

fn add_one(x) {
  x + 1
}
```

У Gleam також є анонімні функції, які визначаються всередині інших функцій.

```gleam
// Define the function
let f = fn(x) { x + 1 }

// Invoke the function
f(1) // -> 2
f(2) // -> 3
```

Тип функції записується синтаксисом, подібним до синтаксису анонімних функцій. Тип функції, яка приймає `Int` і `Float` та повертає `Int`, записується так:

```gleam
fn(Int, Float) -> Int
```

Анонімні функції можуть посилатися на змінні, які були в області видимості на момент їх визначення, тому їх називають _замиканнями_.

```gleam
let secret_number = 42

// This function always returns 42
fn() { secret_number }
```

Синтаксис _захоплення функції_ дає зручний скорочений запис для створення анонімних функцій, які передають один аргумент у функцію. Ці два вирази рівнозначні:

```gleam
// Anonymous function syntax
let f = fn(x) { my_function(1, 2, x) }

// Function capture syntax
let f = my_function(1, 2, _)
```
