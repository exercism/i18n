# Вступ

## Цілі числа

Цілі числа - це числа без дробової частини, які належать множині `{..., -2, -1, 0, 1, 2, ...}`.
Максимальне й мінімальне значення цілого числа визначає система, у якій виконується PHP.
Зазвичай у більшості сучасних систем ціле число займає 64 біти, тобто воно може представляти значення від `-9_223_372_036_854_775_808` до `9_223_372_036_854_775_807` включно.

```php
<?php

$a = 1234;
$a = 1_234_567;
```

Цілочислові літерали можна записувати не лише в десятковій системі числення, а й в інших, за допомогою префікса основи:

```php
<?php

$a = 0123; // octal number (equivalent to 83 decimal)
$a = 0o123; // octal number (as of PHP 8.1.0)
$a = 0x1A; // hexadecimal number (equivalent to 26 decimal)
$a = 0b11111111; // binary number (equivalent to 255 decimal)
```

> Узято з [документації][syntax] PHP

## Числа з плаваючою комою

Числа з плаваючою комою використовуються в PHP для подання підмножини дійсних чисел.
Вони починаються з однієї або кількох цифр, розділених десятковим розділювачем.

```php
<?php

$a = 1.234; 
$b = 1.2e3; 
$c = 7E-10;
$d = 1_234.567; // as of PHP 7.4.0
```

### Поширені пастки

Не всі числа можна подати, і не всі арифметичні дії можна виконати з числами з плаваючою комою.
Використання чисел з плаваючою комою для подання доларів і центів може призвести до помилок округлення.

```php
<?php

$result = 0.1 + 0.2; // => 0.30000000000000004
```

## Арифметичні оператори

PHP надає низку операторів для виконання арифметичних дій. Для своїх арифметичних операторів PHP дотримується стандартного математичного порядку виконання дій. Ось оператори, які надає PHP:

* Тотожність (+)
* Заперечення (-)
* Додавання (+)
* Віднімання (-)
* Множення (*)
* Ділення (/)
* Остача (%)
* Піднесення до степеня (**)

```php
$moles = +'10';
$aLotOfMoles = 6.022 * 10**23 * $moles;
```
