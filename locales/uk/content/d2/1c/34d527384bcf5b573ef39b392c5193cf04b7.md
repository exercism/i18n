# Підказки

## Загальне

- Документацію до пакета `Random` можна знайти [тут][random-module]

## 1. Почнімо з кінця

- Використайте функцію [`Random.constant`][random-constant]

## 2. Муху на оцет не спіймаєш

- Використайте функцію [`Random.uniform`][random-uniform] для генерації скарбів
- Використайте функцію [`Random.map`][random-map] для обгортання скарбу

## 3. Розгалуження

- Використайте функцію [`Random.int`][random-int] для генерації значення від 2 до 4
- До цього значення можна отримати доступ, щоб створити `Branch` за допомогою функції [`Random.andThen`][random-andThen]
- Використайте функцію [`Random.list`][random-list] для генерації гілок
- Використайте функцію [`Random.map`][random-map] для обгортання гілок

## 4. Дивовижні лабіринти

- Використайте функцію [`Random.weighted`][random-weighted] для генерації нерівномірного розподілу результатів
- Використайте функцію [`Random.lazy`][random-lazy] для рекурсивного використання генератора
- Докладніше про визначення рекурсивних структур даних читайте [тут][bad-recursion]
- Якщо ми врешті визначимо вкладений генератор `Generator (Generator Maze)`, можна скористатися [`Random.andThen`][random-andThen] разом із функцією `identity`, щоб його розгорнути

## 5. Мусимо заглибитися глибше

- Використайте функцію [`Random.uniform`][random-uniform] для генерації глухих кутів або кімнат на глибині `0`
- Якщо ми врешті визначимо вкладений генератор `Generator (Generator Maze)`, можна скористатися [`Random.andThen`][random-andThen] разом із функцією `identity`, щоб його розгорнути
- Використайте функцію [`Random.lazy`][random-lazy] для рекурсивного використання генератора
- Докладніше про визначення рекурсивних структур даних читайте [тут][bad-recursion]
