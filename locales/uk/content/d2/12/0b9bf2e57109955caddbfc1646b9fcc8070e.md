# Інструкції

Перетворіть число від 1 до 31 на послідовність дій у таємному рукостисканні.

Послідовність дій визначають, дивлячись на пʼять найправіших цифр числа після перетворення його в двійкову систему.
Починаємо з найправішої цифри і рухаємося ліворуч.

Дії для кожного розряду такі:

```plaintext
00001 = wink
00010 = double blink
00100 = close your eyes
01000 = jump
10000 = Reverse the order of the operations in the secret handshake.
```

Розгляньмо число `9` як приклад:

- 9 у двійковій системі має вигляд `1001`.
- Цифра, що найдалі праворуч, дорівнює 1, тож перша дія буде `wink`.
- Рухаємося ліворуч, наступна цифра дорівнює 0, тож double blink не буде.
- Рухаємося ліворуч знову, наступна цифра дорівнює 0, тож очі залишаються розплющеними.
- Рухаємося ліворуч знову, наступна цифра дорівнює 1, тож буде jump.

Це була остання цифра, тож остаточний код такий:

```plaintext
wink, jump
```

Для числа 26, яке в двійковій системі має вигляд `11010`, отримуємо такі дії:

- double blink
- jump
- обернути порядок дій

Отже, таємне рукостискання для 26 таке:

```plaintext
jump, double blink
```
