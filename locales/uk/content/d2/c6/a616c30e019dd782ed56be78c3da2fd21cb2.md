# Тернарний оператор

Тернарний оператор дає альтернативний синтаксис, щоб виконати порівняння `if..else..` і повернути значення.

## Синтаксис

PHP надає умовну конструкцію, у якій дію можна виконати на основі «правдивості» умови.

```php
if ($condition) {
  $value = 1;
} else {
  $value = 2
}
```

Або ж ту саму операцію може представити тернарний оператор:

```php
$value = $condition
  ? 1  // True branch
  : 2; // False branch
```

Синтаксис порівняння короткий: `(condition) ? (evaluate if true) : (evaluate if false);`.

## Переваги

Очевидна перевага використання тернарного оператора - стислість: умовний вираз записується коротше, ніж конструкція `if..else..`. Але є й кілька інших переваг:

- Це вираз, який можна використати всередині іншого виразу.
- Він уможливлює ліниве обчислення кожної з гілок.

  ```php
  function expensiveCalculation(): int
  {
    // An expensive calculation is performed
    $answerToEverything = 42;
    return $answerToEverything;
  }

  $needExactAnswer = false;
  $estimatedAnswer = 40;
  $answer = $needExactAnswer ? expensiveCalculation() : $estimatedAnswer;
  ```

  У цьому прикладі, якщо точна відповідь не потрібна, дороге обчислення не викликається.

## Недоліки

Тернарні оператори мають кілька недоліків, тому важливо зважати на їхнє використання:

- Тернарний оператор може бути складнішим для читання, бо він вимагає тлумачення символів, а не ключових слів.
- Тернарний оператор може ненавмисно призводити до появи bug, бо в PHP він лівоасоціативний, на відміну від більшості сучасних мов (наприклад, C, Java, JavaScript).
- Обчислений вираз у гілці правди або неправди має повертати значення.

## Ще коротше

Синтаксис тернарного оператора можна скоротити ще більше до `(condition) ?: (evaluate if falsey)`.
Одне із застосувань - надати у виразі резервне значення:

```php
$fruit = null;
eat($fruit ?: 'apple');
```

Іноді його також називають _оператор Елвіса_ (`?:`)
