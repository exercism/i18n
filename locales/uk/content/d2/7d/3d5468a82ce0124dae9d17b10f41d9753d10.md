# Вступ

## Модулі

Код Gleam організовано в модулі, і кожен файл - це один модуль Gleam.

Досі ми писали функції із синтаксисом `pub fn`, який визначає функцію, доступну іншим модулям. Функції, визначені з `fn`, доступні лише всередині модуля, у якому їх визначено, і не можуть використовуватися іншими модулями.

```gleam
// This function is public
pub fn add(x, y) {
  x + y
}

// This function is private
fn subtract(x, y) {
  x - y
}
```

Модулі Gleam мають назви, і ця назва походить від шляху до файлу в каталозі `src` або `test`.

Наприклад, модуль, визначений у файлі `src\geometry\rectangle.gleam` (у Windows) або `src/geometry/rectangle.gleam` (у UNIX-подібних операційних системах), матиме назву `geometry/rectangle`.

## Імпортування функцій з інших модулів

Доступ до функцій, визначених в інших модулях, відбувається через імпорти.
Коли ми імпортуємо модуль, усі його експоновані функції стають доступними.
Але те, як ми до них звертаємося, залежить від способу імпорту модуля.

Типово використовуються кваліфіковані імпорти: щоб звернутися до функції з такого модуля (наприклад, до функції `map` у модулі `gleam/list`), перед нею ставлять назву модуля (`list.map`).

```gleam
// Import the int module
import gleam/int

pub fn run(x: Int) -> String {
  // Use the to_string function from the int module
  int.to_string(x)
}
```

Типово для посилання на модуль використовують останню частину його назви, у цьому випадку `int`, але це можна змінити за допомогою ключового слова `as`.

```gleam
// Import the int module and refer to it as i
import gleam/int as i

pub fn run(x: Int) -> String {
  i.to_string(x)
}
```

Імпорти без кваліфікації дають прямий доступ до експонованих функцій цього модуля, без префікса.

```gleam
// Import the to_string function from the int module
import gleam/int.{to_string}

pub fn run(x: Int) -> String {
  to_string(x)
}
```

Кваліфікованим імпортам віддають перевагу, бо вони ясніше показують читачеві, звідки походить функція, і допомагають уникати конфліктів назв.


## Стандартна бібліотека

Gleam має багату й добре задокументовану стандартну бібліотеку. Документація доступна онлайн на [hexdocs.pm/gleam_stdlib][docs]. Збережімо це посилання десь, воно нам ще не раз знадобиться!

Більшість вбудованих типів даних має відповідний модуль із функціями для роботи з цим типом даних, наприклад: модуль `gleam/int` для цілих чисел, модуль `gleam/string` для рядків тексту (англ. string), модуль `gleam/list` для масивів тощо.

[docs]: https://hexdocs.pm/gleam_stdlib/
