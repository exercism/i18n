# Додаток
## Бонус

Зберігайте кластери графем, тобто

```julia
myreverse("hi 👋🏾") == "👋🏾 ih"
myreverse("as⃝df̅") == "f̅ds⃝a"
```

Для цього бонусного завдання, ймовірно, стане в пригоді стандартна бібліотека `Unicode`.

Щоб увімкнути тест графем, додайте `const TEST_GRAPHEMES = true` у глобальну область видимості свого файлу.
