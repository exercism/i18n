# Вступ

У Haxe винятки дають безпечний спосіб обробляти помилки, які виникають під час виконання коду. Кожен виняток має містити повідомлення з описом помилки. Ми можемо _викидати_ винятки за допомогою ключового слова `throw`:

```haxe
public function main(num:Int) {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
  // ...
}
```

Коли виняток викинуто, код шукає фрагмент, призначений обробити помилку. Якщо такого фрагмента не знайдеться, тоді код покаже повідомлення про помилку й водночас зупинить виконання програми.

Щоб обробляти винятки в Haxe, ми використовуємо блок `try-catch`. Ця блокова конструкція складається з одного блоку `try` та одного або кількох блоків `catch`. Блок `try` _намагається_ виконати фрагмент коду, а блок `catch` чекає, чи не викинуто виняток, щоб _перехопити_ його й не дати виконанню зупинитися. Коли блок `catch` перехоплює виняток, він також виконує все, що є всередині блоку:

```haxe
try {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
} catch (e) {
  // All exceptions will be caught here
  trace(e.message); // Argument num cannot be greater than 10
}
```

Тип аргументу блоку `catch` слід опустити.
