# Гетери та сетери

Гетери та сетери - це методи, які дають змогу читати й записувати значення властивості обʼєкта.
У Crystal є макроси, завдяки яким легко визначати гетери та сетери для властивості.
Макроси - це спосіб генерувати код під час компіляції, про який ітиметься далі в концепції макросів.

У Ruby ці методи визначають за допомогою методів `attr_reader`, `attr_writer` та `attr_accessor`, і на перший погляд вони дуже схожі на реалізацію в Crystal.
У Crystal їх визначено як макроси `getter`, `setter` і `property`.

## Гетери

Макрос `getter` визначає метод, який повертає значення змінної екземпляра.
Це означає, що більше не потрібно писати `@` перед змінною екземпляра, коли до неї потрібно звернутися (у методах, крім initialize); натомість можна викликати метод, який визначив макрос `getter`.

Макрос `getter` може приймати кілька змінних екземпляра, розділених комами.

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name
    @name
  end

  def age
    @age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  getter name, :age
end
```

Як бачимо, використання `getter` зменшує обсяг коду, який ми пишемо, і робить його легшим для читання.
Крім того, Ruby і Crystal відрізняються тим, що Crystal приймає як аргументи для макросу `getter` і назву змінної, і symbol.
Про symbol ітиметься далі, в окремій концепції.

## Сетери

Макрос `setter` визначає метод, який встановлює значення змінної екземпляра.
Цей макрос трапляється нечасто, і замість нього зазвичай використовують макрос `property`.
Створені методи матимуть такий вигляд: `name_of_method=`; саме завдяки `=` властивість можна встановити.

Таке визначення методу трохи особливе: аргумент, який отримує метод, стоїть після знака `=`.
Кілька інших особливих методів у Crystal використовують цей синтаксис, наприклад метод `+`.

Як і з макросом `getter`, визначивши `setter`, ми можемо викликатистворений ним метод, щоб оновити значення змінної екземпляра.

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name=(name : String)
    @name = name
  end

  def age=(age : Int32)
    @age = age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  setter name, :age
end
```

## Властивість

Макрос `property` визначає і `getter`, і `setter` для змінної екземпляра.

```crystal
class Person
  @name : String
  @age : Int32

  property name, :age
end
```
