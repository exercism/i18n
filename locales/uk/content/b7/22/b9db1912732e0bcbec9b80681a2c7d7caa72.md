# Вступ

## Цикли `for`

Інструкція `for` повторює блок коду.
Її перший рядок визначає, скільки разів цей блок повторюється:

```go
for init; condition; post {
    // loop body
}
```

- Інструкція **init** виконується один раз перед першою ітерацією. Зазвичай тут оголошують та ініціалізують змінну-лічильник, яку використовує цикл.
- **Умова** - це булевий вираз (англ. Boolean), який обчислюється перед кожною ітерацією. Цикл зупиняється, коли вона дає `false`.
- Інструкція **post** виконується після кожної завершеної ітерації. Її можна використати, щоб оновити лічильник.

`init; condition; post` не оточують круглими дужками.
Однак фігурні дужки (`{ }`) навколо тіла циклу потрібні завжди.

Цей цикл починає `i` з `1`, виводить поточне значення `i`, збільшує його перед наступною ітерацією та зупиняється, коли `i` досягає `10`:

```go
for i := 1; i < 10; i++ {
    fmt.Println(i)
}
```
