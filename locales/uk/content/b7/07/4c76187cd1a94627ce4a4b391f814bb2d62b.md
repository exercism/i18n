# Тести

У каталозі `t/` є скрипт Perl із розширенням `.t`, який буде використано для перевірки рішення.
Пройти тести можна за допомогою команди:

```bash
`prove`
```

Документацію про твердження, які використовуються у файлах тестів, можна знайти в [Test2::Manual::Testing::Introduction][test2-manual].

[test2-manual]: https://metacpan.org/pod/Test2::Manual::Testing::Introduction
