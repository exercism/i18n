# Інструкції

Ми керуємо онлайн-бутиком модного одягу. Наближається наш великий щорічний розпродаж, тож потрібно перевірити інвентар, щоб переконатися, що ми готові.

Один товар в інвентарі представлено мапою, а весь інвентар - це список таких мап.

```elixir
%{
  name: "White Shirt",
  price: 40,
  quantity_by_size: %{s: 3, m: 7, l: 8, xl: 4}
}
```

## 1. Відсортувати товари за ціною

Реалізуйте функцію `sort_by_price/1`. Вона приймає інвентар і повертає його, відсортований за ціною товару за зростанням.

```elixir
BoutiqueInventory.sort_by_price([
  %{price: 65, name: "Maxi Brown Dress", quantity_by_size: %{}},
  %{price: 50, name: "Red Short Skirt", quantity_by_size: %{}},
  %{price: 50, name: "Black Short Skirt", quantity_by_size: %{}},
  %{price: 20, name: "Bamboo Socks Cats", quantity_by_size: %{}}
])

# => [
#      %{price: 20, name: "Bamboo Socks Cats", quantity_by_size: %{}},
#      %{price: 50, name: "Red Short Skirt", quantity_by_size: %{}},
#      %{price: 50, name: "Black Short Skirt", quantity_by_size: %{}},
#      %{price: 65, name: "Maxi Brown Dress", price: 65, quantity_by_size: %{}}
#    ]
```

## 2. Знайти всі товари без ціни

Після сортування інвентарю за ціною ми помітили, що, мабуть, припустилися помилки, коли проводили інвентаризацію, і забули вказати ціни для кількох товарів.

Реалізуйте функцію `with_missing_price/1`. Вона приймає інвентар і повертає список товарів, у яких немає ціни.

```elixir
BoutiqueInventory.with_missing_price([
  %{price: 40, name: "Black T-shirt", quantity_by_size: %{}},
  %{price: nil, name: "Denim Pants", quantity_by_size: %{}},
  %{price: nil, name: "Denim Skirt", quantity_by_size: %{}},
  %{price: 40, name: "Orange T-shirt", quantity_by_size: %{}}
])

# => [
#      %{price: nil, name: "Denim Pants", quantity_by_size: %{}},
#      %{price: nil, name: "Denim Skirt", quantity_by_size: %{}}
#    ]
```

## 3. Оновити назви товарів

Ми помітили, що в назвах деяких товарів є слово, яке ми більше не хочемо використовувати. Тепер потрібно оновити всі назви товарів із цим словом.

Реалізуйте функцію `update_names/3`. Вона приймає інвентар, старе слово, яке потрібно прибрати, і нове слово, яке потрібно використати замість нього. Вона повертає список товарів з оновленими назвами.

```elixir
BoutiqueInventory.update_names(
  [
    %{price: 40, name: "Black T-shirt", quantity_by_size: %{}},
    %{price: 70, name: "Denim Pants", quantity_by_size: %{}},
    %{price: 65, name: "Denim Skirt", quantity_by_size: %{}},
    %{price: 40, name: "Orange T-shirt", quantity_by_size: %{}}
  ],
  "T-shirt",
  "Tee"
)

# => [
#      %{price: 40, name: "Black Tee", quantity_by_size: %{}},
#      %{price: 70, name: "Denim Pants", quantity_by_size: %{}},
#      %{price: 65, name: "Denim Skirt", quantity_by_size: %{}},
#      %{price: 40, name: "Orange Tee", quantity_by_size: %{}}
#    ]
```


## 4. Збільшити кількість товару

Деякі товари продавалися особливо добре, тож ми замовили більше, у всіх розмірах.

Реалізуйте функцію `increase_quantity/2`. Вона приймає один товар і число `n` та повертає цей товар, у якому кількість для кожного розміру збільшено на `n`.

```elixir
BoutiqueInventory.increase_quantity(
  %{
    name: "Polka Dot Skirt",
    price: 68,
    quantity_by_size: %{s: 3, m: 5, l: 3, xl: 4}
  },
  6
)

# => %{
#      name: "Polka Dot Skirt",
#      price: 68,
#      quantity_by_size: %{l: 9, m: 11, s: 9, xl: 10}
#    }
```

## 5. Обчислити загальну кількість товару

Щоб знати, скільки місця потрібно на складі, потрібно знати, скільки всього одиниць кожного товару ми маємо.

Реалізуйте функцію `total_quantity/1`. Вона приймає один товар і повертає, скільки всього одиниць цього товару ми маємо в усіх розмірах разом.

```elixir
BoutiqueInventory.total_quantity(%{
  name: "Red Shirt",
  price: 62,
  quantity_by_size: %{s: 3, m: 6, l: 5, xl: 2}
})

# => 16
```
