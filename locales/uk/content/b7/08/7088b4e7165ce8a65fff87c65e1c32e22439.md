# Вступ

Swift пропонує варіант синтаксису для роботи із замиканнями, відомий як завершальні замикання. Завершальні замикання виникають тоді, коли останній параметр у списку параметрів функції має функціональний тип. У такому разі, якщо ми передаємо замикання, його можна написати _після_ закривальної дужки, а мітку аргументу опустити. Зауважимо, що коли у функції лише один параметр, дужки можна опустити цілком.

```swift
func fetchURL(_ urlString: String,
              uponReceipt handleResult: (String) -> ()
             )  -> () {
  if let url = URL(string: urlString), let htmlString = fetch(url) {
    handleResult(htmlString)
  }
}

fetchURL("https://www.swift.org") { print($0) }
// prints the fetched html string

["apple", "ball", "carrot"].sorted { $0.count < $1.count }
```
