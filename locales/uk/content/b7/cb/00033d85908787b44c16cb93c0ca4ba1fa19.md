# Вступ

У концепції [Пари та словники][pairs-dicts] ми розглянули основи типу словника в Julia.

Оскільки `Dict` - це важливий і часто вживаний тип колекції, для роботи з ним існує також багато функцій.

## Як отримати записи

Найпростіший спосіб отримати запис полягає в тому, щоб звернутися за ключем (як і в багатьох мовах).
Однак звернення до неіснуючого ключа спричиняє помилку `KeyError`.

```julia-repl
julia> d = Dict(i => ('a':'c')[i] for i in 1:3)
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'

julia> d[2]
'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)

# missing key
julia> d[4]
ERROR: KeyError: key 4 not found
```

Ми могли б перевірити наявність ключа, перш ніж отримувати його (наприклад, за допомогою `haskey(d, 4)` або `4 ∈ keys(d)`), але іноді корисно просто отримати типове значення для відсутніх ключів.

Для цього є функція `get()` та її варіант `get!()`, що змінює словник.
Вони різняться тим, чи додається «відсутній» ключ до `Dict`.

```julia-repl
julia> get(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)

# get() leaves Dict unchanged
julia> d
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'

julia> get!(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)

# get!() adds new key to Dict
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'
```

Раніше в концепції ми бачили, що `delete!()` видаляє запис за ключем.
Це можна поєднати з отриманням значення за допомогою функції `pop!()`.

```julia-repl
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'

# popped value is returned
julia> pop!(d, 3)
'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)

# Dict is shrunk
julia> d
Dict{Int64, Char} with 3 entries:
  4 => '!'
  2 => 'b'
  1 => 'a'
```

## Ітерація

Під час ітерації по `Dict` типово повертаються пари `key => value`.
До складових можна звернутися за звичною номенклатурою `.first` та `.second`.

```julia-repl
# d is from the previous example
julia> [(kv.first, kv.second) for kv in d]
3-element Vector{Tuple{Int64, Char}}:
 (4, '!')
 (2, 'b')
 (1, 'a')
```

Часто потрібні лише ключі або лише значення, і це легко зробити.

```juliajulia> [k for k in keys(d)]
julia> [k for k in keys(d)]
3-element Vector{Int64}:
 4
 2
 1

julia> [v for v in values(d)]
3-element Vector{Char}:
 '!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
```

## Обʼєднання

Поєднувати два `Dict` буває корисно, але варто чітко визначити, що робити з ключами, які трапляються більш ніж в одному вхідному словнику.

Функції `merge()` та `merge!()` поєднують довільну кількість переданих `Dict` зліва направо.

Значення наявних ключів просто перезаписуються, тож перемагає найправіший `Dict`.

```julia-repl
julia> d3 = Dict("color" => "red", "shape" => "circle")
Dict{String, String} with 2 entries:
  "shape" => "circle"
  "color" => "red"

julia> d4 = Dict("color" => "blue", "coords" => (3, 2))
Dict{String, Any} with 2 entries:
  "color"  => "blue"
  "coords" => (3, 2)

# color from d3 is lost
julia> merge(d3, d4)
Dict{String, Any} with 3 entries:
  "shape"  => "circle"
  "color"  => "blue"
  "coords" => (3, 2)
```

Функції `mergewith()` та `mergewith!()` дають змогу передати функцію першим аргументом, щоб визначити, як обʼєднувати повторювані ключі.
Додавання - простий приклад.

```julia-repl
julia> d5 = Dict("color" => "red", "area" => 3)
Dict{String, Any} with 2 entries:
  "area"  => 3
  "color" => "red"

julia> d6 = Dict("shape" => "circle", "area" => 5)
Dict{String, Any} with 2 entries:
  "shape" => "circle"
  "area"  => 5

# area values are added, not overwritten
julia> mergewith(+, d5, d6)
Dict{String, Any} with 3 entries:
  "shape" => "circle"
  "area"  => 8
  "color" => "red"
```

Конкатенація двох векторів - ще одна поширена операція під час обʼєднання.
Для цього Julia використовує функцію `vcat()`; причини пояснено в концепції [`Multi Dimensional Arrays`][multidim].

```julia-repl
julia> d7 = Dict("vals" => [1, 2, 3])
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [1, 2, 3]

julia> d8 = Dict("vals" => [4, 5])
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [4, 5]

julia> mergewith(vcat, d7, d8)
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [1, 2, 3, 4, 5]
```

Звернімо увагу, що функції `mergewith` - хороший приклад [функцій вищого порядку][hof] у дії.

Для кількох [`Set`][sets] відповідна функція обʼєднання - `union`.
