# Типи чисел

У Crystal є багато різних типів чисел для різних потреб.
Наприклад, деякі типи працюють швидше, але мають менший діапазон можливих значень, ніж інші.
Інші мають ширший діапазон можливих значень, але працюють повільніше.

У Crystal є як знакові, так і беззнакові типи цілих чисел.
Знакові цілі числа можуть бути додатними або відʼємними.
Беззнакові цілі числа можуть бути лише додатними.

## Знакові типи цілих чисел

Ось [знакові типи цілих чисел][int] у Crystal:

| Тип      | Розмір (бітів) | Діапазон                                                                                                    |
| -------- | -------------- | ----------------------------------------------------------------------------------------------------------- |
| `Int8`   | 8              | від -128 до 127                                                                                             |
| `Int16`  | 16             | від -32_768 до 32_767                                                                                       |
| `Int32`  | 32             | від -2_147_483_648 до 2_147_483_647                                                                         |
| `Int64`  | 64             | від -9_223_372_036_854_775_808 до 9_223_372_036_854_775_807                                                 |
| `Int128` | 128            | від -170_141_183_460_469_231_731_687_303_715_884_105_728 до 170_141_183_460_469_231_731_687_303_715_884_105_727 |

Менші типи використовують менше памʼяті та працюють швидше за більші, але мають менший діапазон можливих значень.

Коли ми знаємо, що значення перебуватимуть у певному діапазоні, найкраще використовувати якомога менший тип, щоб заощадити памʼять і підвищити швидкодію.

Типовим типом цілих чисел є `Int32`.
Щоб оголосити ціле число конкретного типу, можна використати назву типу як суфікс, додавши `<number>_I <bit>`.

```crystal
1_i8.class
# => Int8
```

Щоб перетворювати різні типи цілих чисел, можна використати метод `to_i<bit>`.
Метод `to_i` перетворює на типовий тип цілих чисел, `Int32`.

```crystal
1_i8.to_i16.class
# => Int16

2_i16.to_i.class
# => Int32
```

## Беззнакові типи цілих чисел

Ось [беззнакові цілі типи][uint] у Crystal:

`UInt8`, `UInt16`, `UInt32`, `UInt64`, `UInt128`

Єдина відмінність між знаковими та беззнаковими цілими числами полягає в тому, що беззнакові можуть бути лише додатними.
Щоб оголосити беззнакове ціле число конкретного типу, можна використати назву типу як суфікс, додавши `<number>_u<bit>`.
Щоб перетворювати різні беззнакові типи цілих чисел, можна використати метод `to_u<bit>`.
Метод `to_u` перетворює на типовий беззнаковий тип цілих чисел, `UInt32`.

```crystal
1_u8.to_u16.class
# => UInt16
```

## Типи чисел з плаваючою комою

Ось типи чисел з плаваючою комою в Crystal:

| Тип       | Розмір (бітів) | Діапазон             |
| --------- | -------------- | -------------------- |
| `Float32` | 32             | від 1.2E-38 до 3.4E+38 |
| `Float64` | 64             | від 2.3E-308 до 1.7E+308 |

Існують два різні [типи чисел з плаваючою комою][float], один з яких точніший за інший.

Типовим типом чисел з плаваючою комою є `Float64`.

Щоб перетворювати різні типи чисел з плаваючою комою, можна використати метод `to_f<bit>`.
Метод `to_f` перетворює на типовий тип чисел з плаваючою комою, `Float64`.

## Тип після операції

Коли ми виконуємо операцію між двома числами, результат матиме тип числа з найвищою точністю.
Число з плаваючою комою точніше за ціле число, а ціле число точніше за беззнакове ціле.
А `Float64` точніше за Float32, і так далі.

```crystal
(1_u8 + 2_u64).class
# => UInt64

(1_u8 + 2_i64).class
# => Int64

(1_u8 + 2.0_f64).class
# => Float64
```

## Заглибмося: беззнакові цілі проти знакових

~~~~exercism/advanced
Під капотом беззнакові та знакові цілі числа відрізняються тим, що знакові цілі використовують перший біт для зберігання знака.
Знак буває додатним або відʼємним.
У беззнакових цілих перший біт використовується для зберігання значення.
Тож для знакового 32-бітного цілого максимальне значення становить 2^31 - 1.
А для беззнакового 32-бітного цілого максимальне значення становить 2^32 - 1.

Щоб дізнатися більше про знаковість, можна почитати про це у [Вікіпедії](https://en.wikipedia.org/wiki/Signedness).
~~~~
