# Друк

Друк у Cairo дозволяє показувати повідомлення та значення в консолі, що полегшує налагодження програм і передавання інформації під час виконання.

Система друку водночас гнучка й проста: вона надає інструменти для форматування та виведення даних різних типів.

## Основи друку

Cairo надає два основні макроси для друку тексту в консолі:

- **`println!`**: друкує результат з нового рядка.
- **`print!`**: друкує результат у тому самому рядку, не додаючи нового.

Обидва макроси приймають як основний аргумент `ByteArray`, а це може бути простий рядок тексту (англ. string) або форматований рядок із заповнювачами для значень.

```rust
// Printing a simple message
println!("Hello, Cairo!");

// Printing with values
let x = 10;
let y = 20;
println!("Values: x = {}, y = {}", x, y);
```

У наведеному вище прикладі:

- заповнювачі `{}` замінюються значеннями `x` та `y`.
- `println!` гарантує, що результат закінчується новим рядком.

## Форматування рядків тексту

Іноді нам може знадобитися створити форматований рядок тексту, не друкуючи його одразу.

Макрос `format!` дозволяє це зробити.

Він працює подібно до `println!`, але повертає `ByteArray`, а не надсилає результат у консоль.

```rust
let s1: ByteArray = "tic";
let s2: ByteArray = "tac";
let s3: ByteArray = "toe";

// Create a formatted string
let result = format!("{s1}-{s2}-{s3}");

println!("{}", result); // Output: tic-tac-toe
```

У цьому прикладі:

- `format!` поєднує `s1`, `s2` і `s3` в один рядок тексту, розділяючи їх дефісами (`-`).
- Отриманий рядок тексту можна використати повторно або надрукувати пізніше.

## Друк власних типів даних

Типово Cairo може друкувати лише базові типи, як-от цілі числа та рядки тексту.

Якщо ми спробуємо надрукувати власний тип, наприклад структуру, то побачимо помилку, якщо тільки цей тип не реалізує трейти `Display` або `Debug`.

### Використання `Display` для власного форматування

Трейт `Display` дозволяє визначити, як саме друкувати власний тип.

Ось приклад:

```rust
use core::fmt::{Display, Formatter, Error};

struct Point {
    x: u8,
    y: u8,
}

impl PointDisplay of Display<Point> {
    fn fmt(self: @Point, ref f: Formatter) -> Result<(), Error> {
        write!(f, "Point({}, {})", *self.x, *self.y)
    }
}

let p = Point { x: 3, y: 4 };
println!("{}", p); // Output: Point(3, 4)
```

У цьому прикладі:

- функція `fmt` визначає, як структура `Point` перетворюється на рядок тексту, готовий до друку.
- макрос `write!` додає форматований рядок тексту до `Formatter`.

### Налагодження за допомогою `Debug`

Для налагодження Cairo надає трейт `Debug`.

Для більшості типів його можна згенерувати автоматично, і це дає швидкий та простий спосіб друкувати внутрішні деталі наших структур.

```rust
#[derive(Debug)]
struct Point {
    x: u8,
    y: u8,
}

let p = Point { x: 3, y: 4 };
println!("{:?}", p); // Output: Point { x: 3, y: 4 }
```

У цьому прикладі:

- `#[derive(Debug)]` автоматично генерує реалізацію трейту `Debug`.
- заповнювач `{:?}` вказує `println!` використовувати для форматування трейт `Debug`.

## Друк у шістнадцятковому форматі

Cairo дозволяє друкувати цілі числа у шістнадцятковому форматі за допомогою заповнювача `{:x}`.

```rust
let value: u32 = 255;
println!("{:x}", value); // Output: ff
```

Це особливо корисно під час роботи з низькорівневими представленнями даних.
