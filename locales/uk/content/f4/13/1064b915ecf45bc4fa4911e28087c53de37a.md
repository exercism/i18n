# Вступ

*Кортеж* - це тип запису, структури чи класу у Factor. Кожен клас кортежів має фіксований набір іменованих слотів, а Factor автоматично генерує для них гетери й сетери.

```factor
TUPLE: point
    { x initial: 0 }
    { y initial: 0 } ;

T{ point { x 3 } { y 4 } } x>> .   ! => 3
3 4 point boa .                    ! => T{ point { x 3 } { y 4 } }
point new .                        ! => T{ point }
```

`boa` («by order of arguments», тобто за порядком аргументів) заповнює слоти зі стека в порядку оголошення. `new` створює екземпляр, у якому кожен слот має оголошене значення `initial:` (або `f`, якщо його не вказано).

Гетер слота - це `slot>>`, а сетер - `>>slot`; сетер *мутує*, тож якщо потрібне оновлення без зміни оригіналу, спершу викличмо `clone`:

```factor
T{ point { x 3 } { y 4 } } clone 10 >>x .
! => T{ point { x 10 } { y 4 } }
```

Типові значення слотів задаються у вигляді `{ name initial: value }`; без `initial:` типове значення - `f`.
