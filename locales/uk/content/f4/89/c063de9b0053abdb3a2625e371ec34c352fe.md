# Вступ

Кортеж - це впорядкований контейнер значень. Як і всі типи даних у Gleam, кортежі незмінні. Кожен елемент кортежу може мати інший тип, і ним може бути навіть інший кортеж.

Кортежі записують як значення, розділені комами, між `#(` і `)`: `#(1, 2.0, "Three")`.

```gleam
#("one", 2)      // Tuple pair (2 values)
#("one", 2, 3.0) // Tuple triplet (3 values)
```

Кортежі однакової довжини з однаковими типами (у тому самому порядку) можна порівнювати на рівність.

```gleam
#(1, 2) == #(1, 2) // Same length, same types, same values, same order
// -> True

#(1, 2) == #(2, 1) // Same length, same types, same values, different order
// -> False

#(1, 2) == #(1, "2") // Same length, different types
// Compile error!

#(1, 2) == #(1, 2, 3) // Different length
// Compile error!
```

Є три способи дістати значення з кортежу:

- Індексування.
- Зіставлення зі зразком за допомогою `let`.
- Зіставлення зі зразком за допомогою `case`.

```gleam
let person = #("Jordan", 170)

// Option 1: Indexing
person.0 // -> "Jordan"
person.1 // -> 170

// Option 2: let
let #(name2, length2) = person
// -> name2 = "Jordan"
// -> length2 = 52

// Option 3: case
case person {
  #(name3, length3) -> {
    name3   // -> "Jordan"
    length3 // -> 170
  }
}
```
