# формат із Kernel

Окрім методу `format`, у Ruby рядки тексту (англ. string) часто створюють за допомогою [інтерполяції рядків](http://ruby-for-beginners.rubymonstas.org/bonus/string_interpolation.html). Наприклад:

```ruby
# Rather than:
format("One for %%s, one for me.", %{name_variable})

# Consider:
"One for #{%{name_variable}}, one for me."
```
