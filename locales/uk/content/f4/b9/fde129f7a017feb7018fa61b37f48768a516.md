# Докладніше

Тепер ми знаємо, як перебирати слайс або мапу в Go.

Повторимо: ми дізналися, що кожна ітерація повертає два значення: індекс/ключ і копію елемента за цим індексом/ключем.

## Перебір слайса

Простіше простого: цикли по слайсу йдуть у звичному порядку.

```go
xi := []int{10, 20, 30}
for i, x := range xi {
  fmt.Println(i, x)
}
// outputs:
// 0, 10
// 1, 20
// 2, 30
```

## Перебір мапи

Перебір мапи ставить нову проблему.
Порядок тепер випадковий.

```go
hash := map[int]int{9: 10, 99: 20, 999: 30}
for k, v := range hash {
  fmt.Println(k, v)
}
// outputs, for example:
// 99 20
// 999 30
// 9 10
```

~~~~exercism/note
Може здатися, що наведений вище вивід неправильний, адже можна було б очікувати, що перша пара ключ-значення з оголошення мапи `9 10` буде надрукована першою, а не останньою.
Однак мапи за своєю природою невпорядковані: у них немає першої чи останньої пари ключ-значення.
Через це, коли ми перебираємо записи мапи, порядок, у якому вони будуть відвідані, буде випадковим і не підпорядковується жодній конкретній закономірності.
Це означає, що наведений вище вивід можливий, але може відрізнятися від того, який ми отримаємо, якщо спробуємо запустити цей код самостійно.
Щоб дізнатися більше про це, дивіться [Go Language Spec: range clause](https://go.dev/ref/spec#RangeClause).
~~~~

## Ітерація без ключа або значення

У Go невикористана змінна спричиняє помилку під час збірки.
Іноді нам потрібне лише значення, як у першому прикладі:

```go
xi := []int{10, 20, 30}
for i, x := range xi {
  fmt.Println(x)
}
// Go build failed: i declared but not used
```

Ми можемо замінити `i` на `_`, що підказує компілятору, що ми не використовуємо це значення:

```go
xi := []int{10, 20, 30}
for _, x := range xi {
  fmt.Println(x)
}
// outputs:
// 10
// 20
// 30
```

Якщо ми хочемо надрукувати лише індекс, можна замінити `x` на `_` або просто пропустити оголошення:

```go
xi := []int{10, 20, 30}
// for i, _ := range xi {
for i := range xi {
  fmt.Println(i)
}
// outputs:
// 0
// 1
// 2
```

І останнє, але не менш важливе: якщо нам треба виконати якусь дію, але ні значення, ні ключі слайса чи мапи нас не цікавлять, можна пропустити й індекс, і значення:

```go
xi := []int{10, 20, 30}
count := 0
for range xi {
  count++
}
// count value:
// 3
```
