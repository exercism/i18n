# Завдання

У цій вправі ми створимо зручну програму, щоб нам не доводилося памʼятати значення смужок.
Програма прийматиме на вхід 1, 4 або 5 кольорів і видаватиме правильне значення в омах.
Кольорові смужки кодуються так:

| Колір  | Значення |
| ------ | -------- |
| Black  | 0        |
| Brown  | 1        |
| Red    | 2        |
| Orange | 3        |
| Yellow | 4        |
| Green  | 5        |
| Blue   | 6        |
| Violet | 7        |
| Gray   | 8        |
| White  | 9        |

У вправі [`Resistor Color Trio`][resistor-color-trio-exercise] ми розшифрували перші три кольорові смужки.
Наприклад: orange-orange-brown дає основне значення `330`.
У цій вправі нам потрібно додати до цього _допуск_.
Допуск - це максимальне відхилення, на яке значення може бути більшим або меншим за основне.
Наприклад, якщо остання смужка зелена, максимальний допуск становитиме `±0.5%`.

Смужка допуску матиме одне з таких значень:

| Колір  |    Допуск |
| ------ | --------: |
| Grey   |    ±0.05% |
| Violet |    ±0.10% |
| Blue   |    ±0.25% |
| Green  |    ±0.50% |
| Brown  |    ±1.00% |
| Red    |    ±2.00% |
| Gold   |    ±5.00% |
| Silver |   ±10.00% |

Резистор із чотирма смужками влаштований так:

| Смужка_1  | Смужка_2  | Смужка_3   | Смужка_4  |
| --------- | --------- | ---------- | --------- |
| Значення_1 | Значення_2 | Множник | Допуск |

Приклади:

- orange-orange-brown-green дасть `330` ом із допуском `±0.5%`.
- orange-orange-red-grey дасть `3300` ом із допуском `±0.05%`.

Різниця між резистором із чотирма та з пʼятьма смужками полягає в тому, що в резисторі з пʼятьма смужками є додаткова смужка, яка вказує точніше значення.

| Смужка_1  | Смужка_2  | Смужка_3  | Смужка_4   | Смужка_5  |
| --------- | --------- | --------- | ---------- | --------- |
| Значення_1 | Значення_2 | Значення_3 | Множник | Допуск |

Приклади:

- orange-orange-orange-black-green дасть `333` ом із допуском `±0.5%`.
- orange-red-orange-blue-violet дасть `323 million` ом із допуском `±0.1%`.

Бувають також резистори з однією смужкою.
Резистори з однією смужкою мають лише смужку кольору black зі значенням 0.

Наша програма має перетворювати вхідний `list` кольорів смужок резистора на позначку такого вигляду:

«... ohms ±...%»

Тож на вхідний `list` `["orange", "orange", "black", "green"]` програма має повертати:

«33 ohms ±0.5%»

Коли омів тисячі, ми кажемо «kiloohms».
Це так само, як казати «кілометр» про 1000 метрів і «кілограм» про 1000 грамів.

Тож на вхідний `list` `["orange", "orange", "orange", "grey"]` програма має повертати:

«33 kiloohms ±0.05%»

Коли омів мільйони, ми кажемо «megaohms».

Тож на вхідний `list` `["orange", "orange", "blue", "red"]` програма має повертати:

«33 megaohms ±2%»
