# Вивчення Visual Basic

## Вебсайти

Visual Basic за ці роки значно змінився, і багато сторонніх туторіалів посилаються на застарілий інструментарій або можливості.
Найактуальніше й найнадійніше місце, з якого варто розпочати свою подорож, - [офіційна документація Visual Basic](https://learn.microsoft.com/en-us/dotnet/visual-basic/).

## Екосистема .NET

Visual Basic працює на середовищі виконання .NET і поділяє багато базової функціональності з C# і F#.
Тож розуміння того, як працює .NET, зробить нас сильнішими розробниками VB.

- [Що таке .NET?](https://learn.microsoft.com/en-us/dotnet/core/introduction)
- [Глосарій .NET](https://learn.microsoft.com/en-us/dotnet/standard/glossary)
- [Спільна система типів (CTS)](https://learn.microsoft.com/en-us/dotnet/standard/base-types/common-type-system)
