# Доповнення до інструкцій

## Формат виведення

Виведіть рядок тексту (англ. string), завершений нульовим символом, використовуючи кому та пробіл як розділювачі.

Прикладом виведення може бути `"491, 914, 142"`

Якщо вхідні дані некоректні, виведіть порожній рядок тексту.

## Регістри

| Регістр | Використання        | Тип         | Опис                                              |
| ------- | ------------------- | ----------- | ------------------------------------------------- |
| `$a0`   | вхідні дані         | адреса      | рядок тексту серії, завершений нульовим символом  |
| `$a1`   | вхідні дані         | ціле число  | довжина зрізу                                     |
| `$a2`   | вхідні/вихідні дані | адреса      | вихідний рядок тексту, завершений нульовим символом |
| `$t0-9` | тимчасовий          | будь-який   | використовується для тимчасового зберігання       |
