# Докладніше

Блоки - це невеликі групи інструкцій, які можна виконати кілька разів.
Їх можна уявляти як замикання або анонімні функції.
Блоки визначають за допомогою синтаксису `do...end` (вище) або `{}` (нижче).
Ці стилі взаємозамінні, і щодо того, коли який з них варто використовувати, думки різняться.

## Скорочений синтаксис
Коли блок викликає лише один метод, його можна замінити на `&:` із назвою цього методу. Наприклад, ці два варіанти рівнозначні:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```
