# Довідка

Нижче зібрано кілька ресурсів, які допоможуть, якщо виникнуть труднощі:

- [The PSF](https://www.python.org) розміщує завантаження Python, документацію та ресурси спільноти.
- [Форуми спільноти Python](https://discuss.python.org/): допомога, обговорення PEP, розробники ядра Python та багато іншого.
- [Спільнота Exercism у Discord](https://exercism.org/r/discord)
- [Дискусійні форуми спільноти Exercism](https://forum.exercsim.org)
- [Спільнота Python у Discord](https://pythondiscord.com/) є дуже корисною та активною спільнотою.
- [/r/learnpython/](https://www.reddit.com/r/learnpython/) це сабредіт, створений для тих, хто вивчає Python.
- [#python у Libera.chat](https://www.python.org/community/irc/) саме тут збираються розробники ядра мови й працюють над проєктом.
- [Форуми спільноти Free Code Camp](https://forum.freecodecamp.org/)
- [Pythontutor](http://pythontutor.com/) допомагає візуально проходити невеликі фрагменти коду крок за кроком.

Крім того, [StackOverflow](http://stackoverflow.com/questions/tagged/python) є гарним місцем, де можна пошукати свою проблему чи запитання й перевірити, чи вже не відповіли на нього.
 Якщо ні, завжди можна [запитати](https://stackoverflow.com/help/how-to-ask) самому або [відповісти](https://stackoverflow.com/help/how-to-answer) на чиєсь запитання.
