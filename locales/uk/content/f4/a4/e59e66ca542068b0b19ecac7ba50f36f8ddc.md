# Деструктуризація

Деструктуризація розбиває елементи на їхні складові частини, привʼязуючи кожну до менших змінних.

## Деструктуризація кортежів

Деструктуризація кортежів проста: достатньо присвоїти кожному полю кортежу нові імена змінних:

```rust
let (first, second) = (1, 2);
```

## Деструктуризація кортежних структур

Деструктуризація кортежних структур ідентична деструктуризації кортежів, але з додаванням назви структури:

```rust
struct TupleStruct(&'static str, i32);
let my_tuple_struct = TupleStruct("foo", 123);
let TupleStruct(foo, num) = my_tuple_struct;
```

## Деструктуризація структур

Деструктуризація структур подібна до деструктуризації кортежних структур. Просто використовуємо назви полів:

```rust
struct ArabianNights {
    name: String,
    stories: usize,
}
let teller = ArabianNights { name: "Scheherazade".into(), stories: 1001 };
{
    let ArabianNights { name, stories } = teller;
    println!("{name} told {stories} stories");
}
```

## Часткова деструктуризація

Оператор `..` можна використати, щоб ігнорувати деякі поля під час деструктуризації:

```rust
let ArabianNights { name, .. } = teller;
println!("{name} survived by her wits");
```

## Умовна деструктуризація

Деструктуризація структур і кортежів завжди успішна. Однак переліки також можна деструктуризувати за допомогою конструкцій мови `if let`, `while let` і `match`.

```rust
if let Some(foo) = foo {
    println!("{foo:?}");
}
```
