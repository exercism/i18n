# Інструкції

Ніхто в цирку не виходить на трапецію, доки не пройдено перевірки безпеки.
Ми записуємо ці перевірки, щоб ті самі правила діяли для всіх.

Усі пʼять завдань розміщуємо в класі `SAFETY_CHECK`.

## 1. Чи готовий мат?

Мат готовий лише тоді, коли він і розстелений, і чистий.

```sather
SAFETY_CHECK::mat_ready(true, false)
-- => false
```

## 2. Чи є на що приземлитися?

Унизу має бути мат або сітка. Підійде будь-що з них, і якщо є і те, і те,
це теж добре.

```sather
SAFETY_CHECK::something_below(false, true)
-- => true
```

## 3. Кому ще потрібен інструктаж?

Кожен, хто не пройшов інструктаж, потребує інструктажу.

```sather
SAFETY_CHECK::needs_briefing(false)
-- => true
```

## 4. Чи достатньо років цьому артисту?

Трапеція призначена для артистів віком від 13 років.

```sather
SAFETY_CHECK::old_enough(13)
-- => true
```

## 5. Зберімо все докупи

Артиста допускають до трапеції, коли йому достатньо років, він пройшов
інструктаж і мат готовий.

```sather
SAFETY_CHECK::cleared(14, true, true, true)
-- => true
```

Чотири аргументи - це вік, чи пройдено інструктаж, чи розстелений мат і чи
чистий мат.
