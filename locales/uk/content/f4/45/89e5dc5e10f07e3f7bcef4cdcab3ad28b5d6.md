# Workflow «No important files changed»

Коли зливається PR треку, що зачіпає вправу, це запускає повторне тестування _всіх_ останніх опублікованих ітерацій рішень студентів.
Для популярних вправ це _дуже_ затратна операція (а в крайньому випадку це аж 70 000 запусків тестів для Python Hello World!).

Цей workflow перевіряє, чи спричинять зміни в PR повторне тестування рішень, і якщо так, додає коментар, який пояснює ризик злиття PR _як є_.
Він також пояснює, як злити PR без повторного тестування рішень.

Докладніше див. в документації [Як уникнути зайвих запусків тестів](https://exercism.org/docs/building/tracks#h-avoiding-triggering-unnecessary-test-runs).

## Джерело

Workflow визначено у файлі `.github/workflows/no-important-files-changed.yml`.
