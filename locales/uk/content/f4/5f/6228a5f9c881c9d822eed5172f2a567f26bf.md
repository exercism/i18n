# Вступ

Асоціативні масиви у Factor (хеш-таблиці та подібні до них структури) мають спільний [протокол][assoc-protocol] із [`assocs`][assocs]. Літерал хеш-таблиці має вигляд `H{ }`:

```factor
H{ { "coal" 1 } { "wood" 2 } } .

"coal" H{ { "coal" 1 } { "wood" 2 } } at .   ! => 1
"gold" H{ { "coal" 1 } { "wood" 2 } } at .   ! => f
```

Поширені операції:

```
at        ( key assoc -- value/f )
key?      ( key assoc -- ? )
set-at    ( value key assoc -- )
delete-at ( key assoc -- )
inc-at    ( key assoc -- )
change-at ( key assoc quot -- )
keys      ( assoc -- keys )
values    ( assoc -- values )
>alist    ( assoc -- alist )
```

Хеш-таблиці є *змінюваними*: перш ніж змінювати літерал `H{ }`, для нього слід виконати `clone`, щоб літерал не використовувався спільно між викликами.

[assocs]: https://docs.factorcode.org/content/vocab-assocs.html
[assoc-protocol]: https://docs.factorcode.org/content/article-assocs-protocol.html
