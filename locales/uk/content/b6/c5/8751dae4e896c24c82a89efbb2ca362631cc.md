# Інструкції

## 1. Огляд

[Зворотний польський запис](https://en.wikipedia.org/wiki/Reverse_Polish_notation) (ЗПЗ) - це спосіб запису математичних виразів.
На відміну від традиційного інфіксного запису, в ЗПЗ оператори *стоять після* своїх операндів.
Наприклад, замість того щоб писати:

```
2 + 2
```

ми пишемо:

```
2 2 +
```

Головна перевага зворотного польського запису в тому, що його значно простіше розібрати, ніж інфіксний запис.
У ЗПЗ не потрібні ні порядок операцій, ні дужки в складних виразах.
Наприклад:

```
(4 + 8) / (7 - 5)
```

можна записати так:

```
4 8 + 7 5 - /
```

В обох випадках значення виразу дорівнює 6.

## 2. Приклад

Обчислімо цей складний вираз вручну.
Як ми дізналися зі вступу, для обчислення ЗПЗ потрібен стек.
У цьому стеку зберігаються числові значення, з якими працюють оператори.
Ми починаємо роботу калькулятора з порожнього стеку, а потім обчислюємо кожен елемент по одному.

Спочатку нам трапляється `4`,
тож ми додаємо його до щойно створеного стеку.

```
4
```

Далі нам трапляється `8`.
Його ми теж додаємо до стеку.

```
4 8
```

Тепер нам трапляється `+`.
Ми виймаємо два верхні значення (4 і 8),
додаємо їх одне до одного
й додаємо суму назад до стеку.

```
12
```

Так само чинимо з `7`, `5` і `-`:

```
12 7
12 7 5
12 2
```

Тепер нам трапляється `/`.
Хоча останнім нам трапився `-`,
у стеку є два елементи.
Ми виймаємо ці два елементи,
ділимо їх
й додаємо результат назад до стеку.

```
6
```

Нарешті, оскільки в стеку залишився рівно один елемент,
можна сказати, що значення виразу дорівнює 6.

## 3. Мета

Мета цієї вправи - написати калькулятор, який обчислює список вхідних даних, упорядкованих за зворотним польським записом, і повертає останній елемент зі стеку.

Якщо в результаті в стеку не рівно один елемент, поверніть `None`.

Якщо в оператора замало операндів (наприклад, вхідні дані `2 +`), поверніть `None`.

За відправну точку нам дано такий перелік і таку функцію-заглушку.

    Value(i32),
