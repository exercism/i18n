# Робочий процес синхронізації міток

Робочий процес синхронізації міток синхронізує [мітки GitHub](https://docs.github.com/en/issues/using-labels-and-milestones-to-track-work/managing-labels) репозиторію з вмістом файлу `.github/labels.yml`.
Щоразу, коли файл `.github/labels.yml` змінюється, робочий процес синхронізації міток автоматично оновлює мітки репозиторію.

## Налаштування міток

Мітки, визначені у файлі `.github/labels.yml`, бувають двох видів:

- Спільні мітки: це мітки, які використовують _усі_ репозиторії Exercism, і вони визначені в [репозиторії org-wide-files](https://github.com/exercism/org-wide-files/blob/main/global-files/.github/labels.yml)
- Мітки, специфічні для треку: вони визначені у файлі `.appends/.github/labels.yml`

Щоб додати мітки, специфічні для треку, потрібно додати їх до файлу `.appends/.github/labels.yml` (див. [цей приклад](https://github.com/exercism/python/blob/main/.appends/.github/labels.yml)).
Щойно ми злиємо зміни в `main`, автоматично відкриється пул-реквест, який змінить файл `.github/labels.yml`.
Після злиття цього PR мітки оновляться автоматично (див. опис вище).

```exercism/caution
Ніколи не редагуйте файл `.github/labels.yml` вручну, бо ці зміни буде перезаписано під час наступної синхронізації міток.
```

## Джерело

Робочий процес визначено у файлі `.github/workflows/sync-labels.yml`.
