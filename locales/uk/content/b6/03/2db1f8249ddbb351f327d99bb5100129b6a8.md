# Додаток до інструкцій

## Регістри

| Регістр | Використання   | Тип            | Опис                                                      |
| ------- | -------------- | -------------- | --------------------------------------------------------- |
| `$a0`   | вхідні дані    | адреса         | рядок тексту (англ. string) із цифр, завершений нульовим символом |
| `$a1`   | вхідні дані    | ціле число     | довжина серії                                             |
| `$v0`   | вихідні дані   | ціле число     | найбільший добуток серії                                  |
| `$t0-9` | тимчасовий     | будь-який      | для тимчасового зберігання                                |
