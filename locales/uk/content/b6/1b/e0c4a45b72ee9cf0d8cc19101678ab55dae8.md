# Підказки

## Загальне

## 1. Реалізуйте метод `new()`

- Метод `new()` приймає аргументи, з якими ми хочемо створити екземпляр `User`. Він повинен повернути екземпляр `User` із зазначеними іменем, віком і вагою.

- Додаткові приклади визначення та створення екземплярів структур дивіться [тут](https://doc.rust-lang.org/book/ch05-01-defining-structs.html).

## 2. Реалізуйте методи-гетери

- Методи `name()`, `age()` і `weight()` - це гетери. Іншими словами, вони повертають відповідне поле з екземпляра структури.

- Зверніть увагу: метод `name` повертає `&str`, тоді як поле `name` структури `User` має тип `String`. Як змусити `&str` і `String` уживатися одне з одним?

- У Rust немає потреби використовувати інструкцію `return`, якщо ми явно не хочемо, щоб функція чи метод повернулися достроково. Інакше ідіоматичніше скористатися _неявним_ поверненням, прибравши крапку з комою після результату, який функція чи метод мають повернути. Використовувати явне повернення не _неправильно_, але де це можливо, краще скористатися неявним поверненням.

```rust
fn foo() -> i32 {
    1
}
```

- Ще кілька прикладів визначення методів для структур шукайте [тут](https://doc.rust-lang.org/book/ch05-03-method-syntax.html).

## 3. Реалізуйте методи-сетери

- Методи `set_age()` і `set_weight()` - це сетери, які оновлюють відповідне поле екземпляра структури значенням вхідного аргументу.

- Як випливає із сигнатур цих методів, сетери нічого не повертають.
