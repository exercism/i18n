# Вступ

## Основи

C# належить до статично типізованих мов, а це означає, що все має тип під час компіляції. Присвоєння значення імені називається визначенням змінної. Змінну можна визначити або явно вказавши її тип, або дозволивши компілятору C# вивести її тип на основі присвоєного значення (це називається _виведенням типу_). Отже, наведені нижче два визначення змінних є рівнозначними:

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

Оновлення значення змінної виконується за допомогою оператора `=`. Після визначення тип змінної вже ніколи не може змінитися.

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

C# належить до [обʼєктно-орієнтованих мов][object-oriented-programming] і вимагає, щоб усі функції були визначені в _класі_. Ключове слово `class` використовується для визначення класу. Обʼєкти (або _екземпляри_) створюються за допомогою ключового слова `new`.

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

Функція всередині класу називається _методом_. Кожен метод може мати нуль або більше параметрів. Усі параметри повинні мати явно вказаний тип, для параметрів виведення типу не працює. Так само потрібно явно вказати тип поверненого значення. Значення повертаються з методів за допомогою ключового слова `return`. Щоб метод можна було викликати з коду в інших файлах, потрібно додати модифікатор доступу `public`.

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

Методи викликаються за допомогою синтаксису з точкою (`.`) на екземплярі: ми вказуємо назву методу для виклику й передаємо аргументи для кожного з параметрів методу. Аргументи можуть необовʼязково вказувати назву відповідного параметра.

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

Область видимості в C# визначається між символами `{` і `}`.

C# підтримує два типи коментарів. Однорядкові коментарі починаються з `//`, а багаторядкові вставляються між `/*` і `*/`.
