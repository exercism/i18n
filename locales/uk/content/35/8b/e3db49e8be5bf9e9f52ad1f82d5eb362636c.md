# Докладніше

Символи у Factor є *цілими числами*, тобто кодовими точками Unicode, тому звичайні числові `<`, `>`, `=` уже дають упорядкування з урахуванням регістру. Словник [`unicode`][unicode] додає до цього предикати, які враховують Unicode, і перетворення регістру для окремих символів.

## Предикати

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
digit>   ( c -- n )    ! the integer value of a digit char
blank?   ( c -- ? )    ! whitespace
alpha?   ( c -- ? )    ! letter or decimal digit
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
CHAR: \n blank? .    ! => t
```

## Перетворення регістру

```
ch>upper  ( c -- c' )
ch>lower  ( c -- c' )
ch>title  ( c -- c' )
```

Варіанти `>upper`, `>lower` і `>title` для цілого рядка тексту (англ. string) застосовують ці перетворення до кожного його символу.

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```
