# Інтеграції Babashka з текстовими редакторами

## nREPL

### Emacs: [CIDER](https://cider.mx/)

Це той, з якого все почалося, і його екосистема [Orchard](https://metaredux.com/posts/2018/11/09/ciders-orchard-the-heart.html) живить багато інших плагінів.

1. Встановіть [Emacs](https://www.gnu.org/software/emacs/download.html) для своєї платформи.

2. Виберіть один із наявних дистрибутивів Emacs, як-от [Prelude](https://prelude.emacsredux.com/), [Spacemacs](https://www.spacemacs.org/) або [Doom Emacs](https://github.com/hlissner/doom-emacs) (усі вони чудові), або додайте це до свого `init.el`:

```elisp
(unless (package-installed-p 'cider)
  (package-install 'cider))
  
(add-hook 'clojure-mode-hook #'cider-mode)
```

Стисло з [документації CIDER](https://docs.cider.mx/cider/platforms/babashka.html):

Запустіть сервер nREPL з каталогу проєкту:

```bash
$ bb --nrepl-server
```

Створіть або відкрийте будь-який файл Clojure (`.clj`) за допомогою `C-x C-f` і підключіться до нього через `C-c C-x c j` (cider-connect-clj).

[Базові комбінації клавіш CIDER](https://docs.cider.mx/cider/usage/cider_mode.html#key-reference):

* `cider-load-buffer` - `C-c C-k`
* `cider-eval-last-sexp` - `C-x C-e` or `C-c C-e`
* `cider-eval-defun-at-point` - `C-M-x` or `C-c C-c`

### VSCode: [Calva](https://github.com/BetterThanTomorrow/calva)

1. Встановіть [VSCode](https://code.visualstudio.com/).

2. Встановіть [Calva](https://marketplace.visualstudio.com/items?itemName=betterthantomorrow.calva).

Наразі Calva вважає, що вихідний код лежить у контексті папки, тобто проєкту Clojure. Створити такий проєкт зручно за допомогою [clj-new](https://github.com/seancorfield/clj-new):

```bash
$ clj -A:new lib myorg/bbtest
Generating a project called bbtest based on the 'lib' template.
The lib template is intended for library projects, not applications.
```
3. Запустіть сервер nREPL з каталогу проєкту:

```bash
$ cd bbtest
bbtest$ bb --nrepl-server 1667
Started nREPL server at localhost:1667
For more info visit https://github.com/borkdude/babashka/blob/master/doc/repl.md#nrepl.
```

Відкрийте папку проєкту у VSCode (Ctrl+K Ctrl+O) або з іншого термінала:

```bash
$ cd bbtest
bbtest$ code .
```

4. У VSCode виконайте команду Calva `Connect to a running REPL` (ctrl+alt+c ctrl+alt+c). Коли зʼявиться запит, виберіть проєкт `Generic` і введіть `localhost:1667`.

Команди REPL:

* `Load Current File and Dependencies` ctrl+alt+c enter
* `Evaluate Current Form Inline` ctrl+alt+c e
* `Evaluate Current Top Level Form (defun)` ctrl+alt+c space

### IntelliJ: [Cursive](https://cursive-ide.com/)

1. Завантажте IntelliJ [тут](https://www.jetbrains.com/idea/download/index.html).
2. Встановіть Cursive, скориставшись [посібником користувача](https://cursive-ide.com/userguide/), і [налаштуйте залежності](https://cursive-ide.com/userguide/deps.html).
3. Докладніше дивіться в розділі [Cursive: робота з Babashka](https://cursive-ide.com/userguide/babashka.html).

## Socket REPL

### Atom: [chlorine](https://github.com/mauricioszabo/atom-chlorine)

1. Встановіть [atom](https://flight-manual.atom.io/getting-started/sections/installing-atom/)

2. Встановіть пакет `chlorine`

3. Запустіть socket REPL:

 ```
$ bb --socket-repl 1666
Babashka socket REPL started at localhost:1666
 ```

4. Відкрийте палітру команд Atom (ctrl+shift+p) і виконайте команду `Connect Clojure Socket REPL` з `localhost` `1666`

5. Відредагуйте комбінації клавіш у keymap.cson через меню `Edit` -> `Keymap...`:

```
'atom-text-editor[data-grammar="source clojure"]':
  'ctrl-; y':       'chlorine:connect-clojure-socket-repl'
  'ctrl-; e':       'chlorine:disconnect'
  'ctrl-; k':       'chlorine:clear-console'
  'ctrl-shift-enter':       'chlorine:load-file'
  'ctrl-enter':       'chlorine:evaluate-block'
  'shift-enter':       'chlorine:evaluate-top-block'
  'ctrl-; i':       'chlorine:inspect-block'
  'ctrl-; I':       'chlorine:inspect-top-block'
  'ctrl-; s':       'chlorine:evaluate-selection'
  'ctrl-; c':       'chlorine:break-evaluation'
  'ctrl-; S':       'chlorine:source-for-var'
  'ctrl-; d':       'chlorine:doc-for-var'
  'ctrl-; x':       'chlorine:run-tests-in-ns'
  'ctrl-; t':       'chlorine:run-test-for-var'
```

### Emacs: [inf-clojure](https://github.com/clojure-emacs/inf-clojure)

Для Emacs встановіть [inf-clojure](https://github.com/clojure-emacs/inf-clojure), додавши це до файлу `init.el`:

```
(unless (package-installed-p 'inf-clojure)
  (package-refresh-contents)
  (package-install 'inf-clojure))

(add-hook 'clojure-mode-hook #'inf-clojure-minor-mode)
```

Запустіть socket REPL, як описано вище, і в Emacs виконайте `M-x inf-clojure-connect` (C-c M-c).

Обчислюйте форми за допомогою C-c C-e. Щоб отримати список усіх доступних команд у inf-clojure-mode (він же REPL) та inf-clojure-minor-mode, можна або викликати C-h f RET inf-clojure-mode і C-h f RET inf-clojure-minor-mode, або просто переглянути їхні меню.

### Vim: [vim-iced](https://github.com/liquidz/vim-iced)

Завантажте [Neovim appimage](https://github.com/neovim/neovim/releases/download/v0.4.3/nvim.appimage) і створіть для нього псевдонім `vim`.

* Встановіть [vim-plug](https://github.com/junegunn/vim-plug):

```
$ curl -fLo ~/.local/share/nvim/site/autoload/plug.vim --create-dirs \
    https://raw.githubusercontent.com/junegunn/vim-plug/master/plug.vim
```

Створіть `~/.config/nvim/init.vim`:

```
call plug#begin('~/.vim/plugged')

Plug 'liuchengxu/vim-clap'
Plug 'guns/vim-sexp',    {'for': 'clojure'}
Plug 'liquidz/vim-iced', {'for': 'clojure'}

call plug#end()

" Enable vim-iced's default key mapping
" This is recommended for newbies
let g:iced_enable_default_key_mappings = v:true
```

Відкрийте Neovim і виконайте команду `:PlugInstall`.

Додайте команду `iced` до $PATH:

`$ export PATH=$PATH:~/.vim/plugged/vim-iced/bin`

* Запустіть сервер socket REPL, відкрийте файл вихідного коду і виконайте `:IcedConnectSocketRepl 1666`.

Типові команди REPL (`<Leader>` типово дорівнює `\`):

- `<Leader>ei` : Обчислити внутрішній елемент
- `<Leader>ee` : Обчислити зовнішній список
- `<Leader>et` : Обчислити зовнішній верхній список
