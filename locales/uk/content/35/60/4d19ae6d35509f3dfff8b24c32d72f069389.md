# Вступ

Коли блоку коду потрібно *запамʼятати* значення зі свого оточення, те, що в інших мовах називають *замиканням*, Factor використовує два інструменти: слово `curry` і синтаксис *fry* `'[ ]`.

## `curry`: захоплення одного значення

`curry` (у словнику [`kernel`][kernel]) приймає значення й блок коду та повертає новий блок коду з цим значенням усередині:

```
curry ( value quot -- newquot )
```

```factor
3 [ + ] curry .
! => [ 3 + ]

10 3 [ + ] curry call .
! => 13
```

Застосуймо `curry` двічі, щоб захопити два значення:

```factor
2 3 [ + + ] curry curry .
! => [ 2 3 + + ]
```

## `compose`: поєднання двох блоків коду

`compose` (у словнику [`kernel`][kernel]) поєднує два блоки коду в один:

```
compose ( quot1 quot2 -- quot )
```

```factor
[ 1 + ] [ 2 * ] compose .
! => [ 1 + 2 * ]

5 [ 1 + ] [ 2 * ] compose call .
! => 12
```

## Блоки коду fry: захоплення кількох значень

Коли захоплень більше ніж одне-два, ланцюжки викликів `curry` стають важкими для читання. *Fry* використовує `'[ … ]` з одним або кількома заповнювачами `_`; кожен `_` замінюється значенням, узятим зі стека даних, по порядку:

```factor
2 3 '[ _ _ + + ] .
! => [ 2 3 + + ]
```

І `curry`, і fry *споживають* свої значення зі стека тієї ж миті, коли створюється замикання. Рядок вище не залишає на стеку нічого і прямо замінює `[ + + ] curry curry`.

Заповнювачі заповнюються зліва направо значеннями зі стека знизу вгору: `2 3 '[ _ _ ]` дає `[ 2 3 ]`, а не `[ 3 2 ]`.

Fry також зазирає *всередину* вкладених блоків коду, що дає змогу розмістити захоплені значення саме там, де ми хочемо:

```factor
2 '[ [ _ > ] filter ] { 1 2 3 4 5 } swap call( s -- s ) .
! => { 3 4 5 }
```

Символ `_` стоїть усередині внутрішнього `[ … ]`, але fry все одно його заповнює.

## `call` з оголошеним ефектом

Коли ми нарешті запускаємо збережений блок коду, оголосимо його стековий ефект у `call`, щоб компілятор міг перевірити типи:

```factor
{ 3 4 5 } [ first2 + ] call( p -- n ) .
! => 7

{ 3 4 5 } [ first ] call( p -- n ) .
! => 3
```

## Векторна арифметика

Словник [`math.vectors`][math.vectors] поєднує дві послідовності однакової довжини поелементно. `v+` і `v*` додають або множать їх; `vmax` і `vmin` беруть більшу або меншу з кожної компоненти. Кожна повертає масив із 2 елементів:

```factor
{ 1 1 } { 3 4 } v+ .    ! => { 4 5 }
{ 2 5 } { 3 -1 } v* .   ! => { 6 -5 }
{ 1 9 } { 4 4 } vmax .  ! => { 4 9 }
{ 1 9 } { 4 4 } vmin .  ! => { 1 4 }
```
