# gofmt не використано

Запустіть `gofmt` для свого рішення, він допомагає форматувати код на Go.

Форматування коду в Go дуже важливе для спільноти.
Більшість середовищ розробки (IDE) можна налаштувати на автоматичне форматування коду під час кожного збереження. Наприклад:

- У Visual Studio Code [чудова підтримка Go](https://code.visualstudio.com/docs/languages/go)
- У Vim теж є [чудове розширення для Go](https://github.com/fatih/vim-go)
- [Jetbrains Goland](https://www.jetbrains.com/go/) - це повноцінне середовище розробки для Go

Щоб запустити `gofmt` вручну:

```bash
# will only show the differences
gofmt -d filename.go

# will apply the changes
gofmt -w filename.go
```

```git
%{gofmt}
```
