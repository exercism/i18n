# Цикли

**Цикл** робить те саме знову і знову.

```sather
   loop
      ...
   end;
```

Сам по собі він ніколи не зупиниться, тож щось усередині має його завершити.

## Де зберігати лічбу

Цикл майже завжди потребує значення, яке змінюється в процесі роботи. Це
**змінна**, і `::=` створює її:

```sather
   total ::= 0;
```

Змінна називається `total`, починається з `0`, і Sather визначає з цього
`0`, що вона містить `INT`. Після цього `:=` записує в неї нове значення:

```sather
   total := total + 5;
```

Читаймо це справа наліво: візьмімо те, чим `total` є зараз, додаймо 5 і
повернімо відповідь назад у `total`.

Змінна, створена так, живе до кінця процедури.

## until!

`until!` приймає запитання. Щоразу перед новим проходом його запитують, і
коли відповідь — правда, цикл зупиняється одразу ж.

```sather
   sum_to(last : INT) : INT is
      total ::= 0;
      n ::= 1;
      loop
         until!(n > last);
         total := total + n;
         n := n + 1;
      end;
      return total;
   end;
```

`n` лічить 1, 2, 3 ... і цикл завершується першого разу, коли `n` стає
більшим за `last`. Без `n := n + 1` запитання ніколи не змінило б своєї
відповіді, і цикл виконувався б вічно.

`until!` не обовʼязково має бути першим рядком. Поставмо його там, де
запитання має сенс: уверху цикл може не виконатися жодного разу; внизу він
завжди виконується принаймні один раз.

`!` є частиною назви. Sather позначає так деякі речі; що означає цей знак,
зʼясовано пізніше.

## break!

`break!` завершує цикл негайно, без жодного запитання. Він стає в пригоді,
коли причина зупинитися виникає посеред роботи.

```sather
   loop
      if too_far then break!; end;
      ...
   end;
```

`until!` і `break!` мають сенс лише всередині `loop`. Жоден із них не можна
використати сам по собі.
