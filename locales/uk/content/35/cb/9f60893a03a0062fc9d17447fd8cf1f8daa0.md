# Тернарний оператор

Тернарний оператор надає альтернативний синтаксис для виконання порівняння `if..else..` і повернення значення.

## Синтаксис

У PHP є умовна конструкція `if`, де дію можна виконати на основі «правдивості» умови.

```php
if ($condition) {
  $value = 1;
} else {
  $value = 2
}
```

Або ж ту саму дію може представити тернарний оператор:

```php
$value = $condition
  ? 1  // True branch
  : 2; // False branch
```

Синтаксис порівняння короткий і має такий вигляд: `(condition) ? (evaluate if true) : (evaluate if false);`.
