# Вказівки

Транслюйте послідовності РНК у білки.

Ланцюги РНК складаються з послідовностей із трьох нуклеотидів, які називаються **кодонами**.
Кожен кодон відповідає **амінокислоті**.
Коли вони зʼєднуються, ці амінокислоти утворюють білок.

У реальному світі існує 64 кодони, які, своєю чергою, відповідають 20 амінокислотам.
Однак у цій вправі ми використаємо лише кілька з можливих 64.
Вони наведені нижче:

| Кодон              | Амінокислота    |
| ------------------ | ------------- |
| AUG                | Methionine    |
| UUU, UUC           | Phenylalanine |
| UUA, UUG           | Leucine       |
| UCU, UCC, UCA, UCG | Serine        |
| UAU, UAC           | Tyrosine      |
| UGU, UGC           | Cysteine      |
| UGG                | Tryptophan    |
| UAA, UAG, UGA      | STOP          |

Наприклад, послідовність РНК «AUGUUUUCU» має три кодони: «AUG», «UUU» й «UCU».
Вони відповідають Methionine, Phenylalanine та Serine.

## Кодони «STOP»

З наведеної вище таблиці видно, що є три **кодони «STOP»**.
Якщо трапиться будь-який із цих кодонів, проігноруйте решту послідовності, адже білок завершено.

Наприклад, «AUGUUUUCUUAAAUG» містить кодон «STOP» («UAA»).
Щойно ми досягаємо цієї точки, ми припиняємо обробку.
Тому ми розглядаємо лише частину перед ним (тобто «AUGUUUUCU»), а не будь-які подальші кодони після нього (тобто «AUG»).
