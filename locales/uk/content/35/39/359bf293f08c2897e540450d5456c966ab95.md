# Інструкції

У цій вправі ми допоможемо закоханим зі школи зізнатися в коханні одне одному в соцмережах.

## 1. Показати імена пари, розділені сердечком

Реалізуйте статичний метод `HighSchoolSweethearts.DisplaySingleLine()`, щоб він приймав два імені та показував їх, розділені сердечком.
Відформатований текст має бути завширшки 61 символ, а сердечко стояти в центрі рядка тексту (англ. string).

Усі імена гарантовано добре вміщуються в ширину рядка.

```csharp
HighSchoolSweethearts.DisplaySingleLine("Lance Green", "Pat Riley");
// => "                  Lance Green ♡ Pat Riley                    "
```

## 2. Показати ініціали пари в сердечку з ASCII-графіки

Реалізуйте статичний метод `HighSchoolSweethearts.DisplayBanner()`, який показує два набори ініціалів, розділені знаком плюс.

```csharp
HighSchoolSweethearts.DisplayBanner("L. G.", "P. R.");
```

## 3. Німецькі школярі за обміном почуваються як удома завдяки оголошенням, чутливим до локалі

Реалізуйте статичний метод `HighSchoolSweethearts.DisplayGermanExchangeStudents()`, щоб показати дату початку стосунків і тривалість часу для наших німецьких школярів за обміном.

```csharp
HighSchoolSweethearts.DisplayGermanExchangeStudents("Norbert", "Heidi", new DateTime(2019, 1, 22), 1535.22f);
// => "Norbert and Heidi have been dating since 22.01.2019 - that's 1.535,22 hours"
```
