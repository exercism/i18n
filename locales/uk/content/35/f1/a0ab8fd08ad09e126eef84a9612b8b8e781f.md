# Вступ

## Включення масивів

Включення дають змогу легко й декларативно перетворювати _Enumerable_-структури.

Щоб оголосити найпростіше включення, скористаймося ключовим словом `for`, після якого йде _генератор_ і _блок do_, що створює нові значення з перелічених.

```elixir
for n <- [0, 1, 2, 3], do: n + 1
# => [1, 2, 3, 4]
```

Включення також можуть мати _фільтри_. Значення, які не проходять фільтр, не потрапляють до фінального масиву:

```elixir
for n <- [0, 1, 2, 3], n > 1, do: n + 1
# => [3, 4]
```

Складніші включення можна оголошувати в кілька рядків:

```elixir
for {atom, number} <- [a: 1, b: 2, c: 3, d: 4],
    rem(number, 2) == 0 do
  atom
end

# => [:b, :d]
```

_Декартів добуток_ можна створити за допомогою кількох генераторів. Це означає, що кожне значення, яке породив перший генератор, утворить пару з кожним значенням, яке породив другий генератор:

```elixir
for x <- [0, 1],
    y <- [0, 1] do
  {x, y}
end

# => [{0, 0}, {0, 1}, {1, 0}, {1, 1}]
```
