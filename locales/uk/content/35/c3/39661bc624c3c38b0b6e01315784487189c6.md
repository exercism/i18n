# Інструкції

У цій вправі ми напишемо трохи коду, який допоможе підготуватися до купівлі транспортного засобу.

На нас чекають три завдання: визначити, чи потрібне посвідчення водія; обрати один із двох транспортних засобів; та оцінити прийнятну ціну вживаного транспортного засобу.

## 1. Визначте, чи потрібне посвідчення водія

Деякі види транспортних засобів потребують посвідчення водія для керування ними.
Вважаємо, що посвідчення водія потребують лише види `"car"` і `"truck"`; усім іншим можна керувати без нього.

Реалізуйте функцію `needs_license`, яка приймає вид транспортного засобу й повертає булеве значення (англ. Boolean), що вказує, чи потрібне посвідчення водія для цього виду транспортного засобу.

```jq
"car" | needs_license
# => true

"bike" | needs_license
# => false
```

## 2. Оберіть один із двох можливих транспортних засобів для купівлі

Ми вже оцінили доступні варіанти транспортних засобів.
Нам вдалося звузити вибір до двох варіантів, але потрібна допомога, щоб ухвалити остаточне рішення.
Реалізуйте функцію `choose_vehicle`, яка приймає масив із двох транспортних засобів і повертає рішення, тобто варіант, що йде першим за словниковим порядком.

```jq
["Wuling Hongguang", "Toyota Corolla"] | choose_vehicle
# =>  "Toyota Corolla is clearly the better choice."

["Volkswagen Beetle", "Volkswagen Golf"] | choose_vehicle
# =>  "Volkswagen Beetle is clearly the better choice."
```

## 3. Обчисліть приблизну ціну вживаного транспортного засобу

Тепер, коли рішення ухвалено, ми хочемо бути впевнені, що отримаємо справедливу ціну в автосалоні.
Оскільки нас цікавить купівля вживаного транспортного засобу, ціна залежить від його віку.
Для приблизної оцінки вважаємо, що якщо транспортному засобу менше ніж 3 роки, він коштує 80% початкової ціни, яку мав, коли був новим.
Якщо йому понад 10 років, він коштує 50%.
Якщо транспортному засобу щонайменше 3 роки, але не більше ніж 10 років, він коштує 70% початкової ціни.

Реалізуйте функцію `resell_price`, яка застосовує цю логіку за допомогою `if`, `elif` та `else`.
Вона приймає обʼєкт із початковою ціною та віком транспортного засобу і повертає приблизну ціну в автосалоні.

```jq
{"original_price": 1000, "age": 1} | resell_price
# => 800

{"original_price": 1000, "age": 5} | resell_price
# => 700

{"original_price": 1000, "age": 15} | resell_price
# => 500
```
