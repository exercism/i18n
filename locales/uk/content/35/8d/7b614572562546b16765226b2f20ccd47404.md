# Використання специфікації типів

[comment]: # (Це попередження виникає, коли рішення не має специфікації типів)

Додайте [специфікації типів](https://elixir-lang.org/getting-started/typespecs-and-behaviours.html#types-and-specs) (`@spec`), щоб описати контракт між входом і виходом функції.

- Elixir - мова з динамічною типізацією, тобто перевірка типів відбувається лише під час виконання. Використання специфікації типів дозволяє лінтерам і засобам статичного аналізу, як-от [`Dialyxir`](https://hexdocs.pm/dialyxir/readme.html) (на основі [`Dialyzer`](http://erlang.org/doc/man/dialyzer.html) з Erlang), оцінювати код на предмет непередбаченої поведінки.
- [Повний перелік](https://hexdocs.pm/elixir/typespecs.html#basic-types) усіх вбудованих типів можна знайти в [документації мови](https://hexdocs.pm/elixir/typespecs.html#content)
- типи можна вказувати з дужками або без них: `atom()` проти `atom`
  - у стилі Exercism для Elixir прийнято записувати без дужок.

```elixir
# Example 1
@spec add_one(int) :: int
def add_one(n) when is_integer(n) do
  n + 1
end

# Example 2
@spec hello(String.t) :: String.t
def hello(what \\ "world") when is_binary(what) do
  "Hello, #{what}"
end
```
