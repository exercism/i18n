# Встановлення

## Вимоги треку PowerShell

Трек мови PowerShell на Exercism потребує, щоб у системі було встановлено:

- PowerShell або Windows PowerShell Core
- встановлений модуль фреймворку Pester для тестування й моків

(PS: підтримка PowerShell обмежується критичними виправленнями. PowerShell Core підтримується постійно й має ширшу кросплатформну підтримку.)

### Встановлення PowerShell

PowerShell попередньо встановлено в усіх операційних системах Windows, починаючи з Windows 7 SP1.

Найновішу версію PowerShell і вказівки зі встановлення для всіх платформ (Linux, macOS і Windows) можна знайти [тут][installation].

Також доступні вихідний код і ручне встановлення [PowerShell][source-code].

### Встановлення й оновлення фреймворку Pester

[Pester][pester] - це фреймворк для тестування в PowerShell.
Починаючи з версії 4.0.9, він сумісний із PowerShell Core у Windows, Linux і MacOS (з деякими обмеженнями).

Його попередньо встановлено у Windows 10, однак рекомендуємо оновити його, виконавши таку команду PowerShell:

```PowerShell
Install-Module -Name Pester -Force -SkipPublisherCheck
```

Для подальших оновлень виконайте:

```PowerShell
Update-Module -Name Pester
```

За потреби докладніші вказівки зі встановлення доступні тут: [https://github.com/pester/Pester/wiki/Installation-and-Update]()

## Використання IDE

Якщо потрібен повніший досвід редагування, ймовірно, варто скористатися IDE.
Ось найпопулярніші IDE, які підтримують створення проєктів PowerShell:

### Усі платформи

- [PowerShell ISE (Integrated Scripting Environment)][ise] - вбудоване графічне IDE, яке постачається разом із PowerShell (лише Windows).
  Щоб запустити PowerShell ISE, введіть `powershell_ise.exe` у консолі PowerShell.
- [Visual Studio Code][vsc] із [розширенням PowerShell][vsc-extension].
  Visual Studio Code також дає змогу запускати тести й налагоджувати код.
- [Sublime Text 3][sublime] із [пакетом PowerShell][sublime-package].
