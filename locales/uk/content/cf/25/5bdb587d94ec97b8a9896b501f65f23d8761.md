# Методи рядків

`String` має кілька методів, які дають змогу працювати з рядками тексту (англ. string).
Ці методи викликають на самому рядку тексту, і їх часто обʼєднують у ланцюжок, щоб виконати над рядком кілька операцій поспіль.

Нижче наведено список деяких найпоширеніших методів.
Повний список методів дивіться в [документації API `String`][string-api].

## String#upcase & String#downcase

Метод [`upcase`][upcase] повертає новий рядок тексту, у якому всі символи переведено у верхній регістр.

```crystal
"hello".upcase
# => "HELLO"
```

Метод [`downcase`][downcase] повертає новий рядок тексту, у якому всі символи переведено в нижній регістр.

```crystal
"HELLO".downcase
# => "hello"
```

## String#capitalize & String#camelcase & String#underscore & String#titleize

Кілька методів виконують специфічніші перетворення регістру.
Це може стати в пригоді, коли ми перетворюємо рядок тексту в певний формат.
Ось список деяких найпоширеніших методів:

| Метод                             | Опис                                                                                                               | Приклад                                              |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------- |
| [`String#capitalize`][capitalize] | Переводить першу літеру у верхній регістр, а решту у нижній                                                         | `"hEllO" # => "Hello"`                               |
| [`String#camelcase`][camel-case]  | Перетворює підкреслення на camel case                                                                              | `"eiffel_tower" # => "EiffelTower"`                  |
| `String#camelcase(lower: true)`   | Те саме, що `String#camelcase`, але перший символ залишається в нижньому регістрі                                  | `"empire_state_building" # => "empireStateBuilding"` |
| [`String#underscore`][underscore] | Переводить усі символи в нижній регістр і ставить підкреслення між малою літерою та великою літерою                 | `"PartyInTheUSA" # => "party_in_the_usa"`            |
| [`String#titleize`][titleize]     | Робить першу літеру кожного слова великою, а решту малими                                                          | `"the great gatsBY" # => "The Great Gatsby"`         |

## String#sub & String#gsub

У Crystal є методи для заміни частин рядка тексту.
Це [`sub`][sub] (_substitution_, тобто заміна) та [`gsub`][gsub] (_global substitution_, тобто глобальна заміна).

Ці методи можуть приймати рядок тексту, символ або регулярний вираз як перший аргумент і рядок тексту або символ як другий аргумент.
Перший аргумент - це частина рядка тексту, яку буде замінено, а другий - заміна.
`Char` і регулярні вирази ми розглянемо в наступних концепціях.

Метод `sub` замінює перше входження першого аргументу на другий аргумент.

```crystal
"hello".sub("l", "r")
# => "herlo"
```

Метод `gsub` працює так само, як `sub`, але замінює всі входження першого аргументу на другий аргумент.

```crystal
"hello".gsub("l", "r")
# => "herro"
```

## String#chomp & String#strip

Методи `chomp` і `strip` дають змогу прибрати з рядка тексту небажані символи.

Типово метод [`chomp`][chomp] прибирає з кінця рядка тексту останні символи `\r`, `\n` або `\r\n`.
Якщо викликати метод з аргументом, він прибере задане значення з кінця рядка тексту.
Якщо воно там є.

```crystal
"hello\n".chomp
# => "hello"

"hello".chomp("llo")
# => "he"
```

Типово метод [`strip`][strip] прибирає всі пробільні символи з початку та кінця рядка тексту.
Якщо викликати метод з аргументом, він прибере цей аргумент з початку та кінця рядка тексту.
Якщо той там є.

```crystal
" hello ".strip
# => "hello"
```

## String#reverse

Метод [`reverse`][reverse] перевертає рядок тексту.
Він повертає новий рядок тексту, у якому символи розташовано у зворотному порядку.

```crystal
"hello".reverse
# => "olleh"
```

## String#index

Метод [`index`][index] дає змогу знайти індекс символу в рядку тексту.
Метод `index` приймає `String`, `Char` або регулярний вираз як аргумент.
Він може приймати необовʼязковий другий аргумент, який задає індекс, з якого починати пошук.
Метод `index` повертає індекс першого входження аргументу.

```crystal
"hello".index("l")
# => 2

"hello".index("l", 3)
# => 3
```

## String#delete_at

Метод [`delete_at`][delete_at] дає змогу прибрати символ із рядка тексту.
Метод `delete_at` приймає індекс як аргумент і прибирає символ за цим індексом.

```crystal
"hello".delete_at(0)
# => "ello"

"hello".delete_at(3)
# => "helo"
```

## String#insert

Метод [`insert`][insert] дає змогу вставити рядок тексту за вказаним індексом.
Метод `insert` приймає індекс як перший аргумент і рядок тексту як другий аргумент.
Метод `insert` повертає новий рядок тексту, у який другий аргумент вставлено за вказаним індексом.

```crystal
"hello".insert(0, "h")
# => "hhello"

"hello".insert(3, "l")
# => "helllo"
```
