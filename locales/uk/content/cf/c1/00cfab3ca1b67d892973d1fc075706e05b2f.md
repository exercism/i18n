# Вступ

## Функції з кількома клаузами

Elixir допомагає дотримуватися **принципу відкритості-закритості**, дозволяючи функціям мати кілька клауз. Тож замість розростання й жорстко закодованої логіки керування можна писати точкові функції, щоб легко додавати і прибирати поведінку.

Elixir пропонує _кілька клауз функції_ та _охоронні вирази_, щоб писати:

```elixir
def number(n) when n == 7 do
  "Awesome, that's my favorite"
end

def number(_n) do
  "That's not my favorite"
end
```

Під час виконання Elixir перевірятиме згори донизу вихідного файлу, яку клаузу функції викликати.

Змінні, які не використовуються, слід починати з підкреслення.

## Охоронні вирази

Охоронні вирази використовують, щоб Elixir не викликав функції на основі оцінювання аргументів охоронними функціями. Охоронні вирази починаються з ключового слова `when`, за яким іде булевий вираз (англ. Boolean). Охоронні функції - це спеціальні функції, які:

- Мають бути чистими і не змінювати жодних глобальних станів.
- Мають повертати строго `true` або `false`.

Список поширених охоронних виразів можна знайти в [документації Elixir][kernel-guards]. Він охоплює перевірки типів, базову арифметику, порівняння та строго булеві оператори.

## Типові аргументи

Функції можуть оголошувати типові значення для одного або кількох аргументів. Розгляньмо цю функцію:

```elixir
def number(n \\ 13), do: "That's not my favorite"
```

Під час компіляції Elixir створює визначення функції для `number/0` (без аргументів) і `number/1` (з одним аргументом).

Якщо більш ніж один аргумент має типові значення, ці значення застосовуються до функції зліва направо, щоб заповнити пропущені аргументи.

Якщо функція має більше ніж одну клаузу, типові аргументи слід визначити в заголовку функції (функції без тіла) перед клаузами функції:

```elixir
def number(n \\ 13)
def number(n) when n < 10, do: "Dream bigger!"
def number(n) when n > 100, do: "Not that big..."
```
