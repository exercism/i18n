# Вступ

Функція дає змогу згрупувати код у повторно використовувану одиницю.
Вона складається з ключового слова `func`, назви функції та розділеного комами списку з нуля або більше параметрів і типів у круглих дужках.

## Параметри функції

Усі параметри повинні мати явно вказаний тип; для параметрів немає виведення типу.
Для параметрів немає типових значень, тому всі параметри функції обовʼязкові.

```go
import "fmt"

// No parameters
func PrintHello() {
    fmt.Println("Hello")
}

// One parameter
func PrintHelloName(name string) {
  fmt.Println("Hello " + name)
}
```

Параметри одного типу можна оголосити разом, указавши після них один спільний тип.

```go
import "fmt"

func PrintGreetingName(greeting, name string) {
  fmt.Println(greeting + " " + name)
}
```

## Параметри та аргументи

Швидко розгляньмо два терміни, які часто плутають: `parameters` і `arguments`.
Параметрами функції називають назви, визначені в сигнатурі функції, як-от `greeting` і `name` у функції `PrintGreetingName` вище.
Аргументами функції називають конкретні значення, які передають параметрам функції, коли ми викликаємо функцію.
Наприклад, у прикладі нижче `"Hello"` і `"Katrina"` - це аргументи, передані параметрам `greeting` і `name`:

```go
PrintGreetingName("Hello", "Katrina")
```

## Повернені значення

Після параметрів функції йде нуль або більше повернених значень, які теж повинні мати явно вказаний тип.
Одиничні повернені значення залишають без дужок, а кілька повернених значень беруть у дужки.
Значення повертаються до коду, який викликав функцію, за допомогою ключового слова `return`.
У функції може бути кілька інструкцій `return`.
Виконання функції завершується, щойно вона натрапляє на одну з цих інструкцій `return`.
Якщо з функції потрібно повернути кілька значень, їх розділяють комами.

```go
func Hello(name string) string {
  return "Hello " + name
}

func HelloAndGoodbye(name string) (string, string) {
  return "Hello " + name, "Goodbye " + name
}
```

## Виклик функцій

Щоб викликати функцію, треба вказати її назву й передати аргументи для кожного з параметрів функції в дужках.

```go
import "fmt"

// No parameters, no return value
func PrintHello() {
    fmt.Println("Hello")
}
// Called like this:
PrintHello()

// One parameter, one return value
func Hello(name string) string {
  return "Hello " + name
}
// Called like this:
greeting := Hello("Dave")

// Multiple parameters, multiple return values
func SumAndMultiply(a, b int) (int, int) {
    return a+b, a*b
}
// Called like this:
aplusb, atimesb := SumAndMultiply(a, b)
```

## Іменовані повернені значення та «голий» return

Як і параметрам, поверненим значенням можна за бажанням дати назви.
Якщо використано іменовані повернені значення, інструкція `return` без аргументів поверне ці значення.
Це називають «голим» return.

```go
func SumAndMultiplyThenMinus(a, b, c int) (sum, mult int) {
    sum, mult = a+b, a*b
    sum -= c
    mult -= c
    return
}
```
