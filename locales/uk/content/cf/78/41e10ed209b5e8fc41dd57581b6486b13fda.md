# Вступ

## Інструкції `switch`

Вікіпедія описує інструкцію `switch` як «різновид механізму керування вибором, який дозволяє значенню змінної або виразу змінювати потік виконання програми».

Механізм використовує такі ключові слова: `switch`, `case`, `break` і `default`.

У найпростішому випадку вони перевіряють примітивний вираз або рядок тексту (англ. string) і ухвалюють рішення на основі його значення. Наприклад:

```csharp
string direction = GetDirection();
switch (direction)
{
    case "left":
        GoLeft();
        break;
    case "right":
        GoRight();
        break;
    default:
        MarkTime();
        break;
}
```

У найскладніших випадках вони запроваджують низхідне приведення типів `case <Type> <variable>:` і охоронні умови (`when`).

```csharp
Animal animal = GetAnimal();

switch (animal)
{
    case Dog canine:
    case Coyote canine:
        canine.Bark();
        break;
    case Cat cat when cat.HasOnly8Lives():
        cat.IsCareful();
        cat.Meow();
        break;
    case Cat cat:
        cat.Meow();
        break;
}
```
