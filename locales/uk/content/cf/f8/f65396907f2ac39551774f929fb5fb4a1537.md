# Вступ

У цій вправі потрібно виконувати логіку за певної умови. Найпоширеніший спосіб зробити це в C# - скористатися умовною конструкцією `if/else`:

```csharp
int x = 6;

if (x == 5)
{
    // Execute logic if x equals 5
}
else if (x > 7)
{
    // Execute logic if x greater than 7
}
else
{
    // Execute logic in all other cases
}
```

Умова конструкції `if` має бути типу `bool`. У C# немає поняття _правдивих_ значень.
