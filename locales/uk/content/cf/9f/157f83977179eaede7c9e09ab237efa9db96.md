# Інструкції

Наша ностальгія за картками Blorkemon™️ і не збирається слабшати: ми навіть знову почали їх збирати й залучаємо до цього друзів.

У цій вправі колекцію карток представлено `MapSet`, адже дублікати карток не мають значення, коли наша мета - зібрати всі наявні картки.

## 1. Почати колекцію

Нам дуже хочеться, щоб друзі долучилися до нашого божевілля з Blorkemon™️, а найкращий спосіб - започаткувати їхню колекцію, давши їм одну картку.

Реалізуйте `GottaSnatchEmAll.new_collection`, яка перетворює картку на колекцію.

```elixir
GottaSnatchEmAll.new_collection("Newthree")
# => MapSet.new(["Newthree"])
```

## 2. Розширити колекцію

Щойно в нас є колекція, вона починає жити власним життям і має рости.

Реалізуйте `GottaSnatchEmAll.add_card`, яка приймає картку й колекцію та повертає кортеж із двох значень: булеве значення (англ. Boolean), яке вказує, чи вже була картка в колекції, і колекцію з доданою карткою.

```elixir
GottaSnatchEmAll.add_card("Scientuna", MapSet.new(["Newthree"]))
# => {false, MapSet.new(["Newthree", "Scientuna"])}
```

## 3. Почати обмін

Тепер, коли наші друзі знову божеволіють від Blorkemon™️, ми можемо скористатися цим, щоб приростити власну колекцію за допомогою обміну картками.

Не кожен обмін варто робити, і не кожен взагалі можливий.
Ми не можемо обміняти картку, якої в нас немає, і не варто обмінювати картку на ту, яка в нас уже є.

Реалізуйте `GottaSnatchEmAll.trade_card`, яка приймає дві картки для обміну (нашу й їхню) та нашу поточну колекцію.
Повернене значення - кортеж із двох значень: булеве значення, яке вказує, чи можливий обмін і чи варто його робити, і колекція, яку ми отримали б, якби здійснили обмін (навіть якщо насправді він неможливий).

```elixir
GottaSnatchEmAll.trade_card("Scientuna", "Newthree", MapSet.new(["Scientuna"]))
# => {true, MapSet.new(["Newthree"])}
```

## 4. Кожної може бути лише одна

Ми знаходимо старий запас карток на блошиному ринку.
Потрібно відсортувати картки й прибрати дублікати, щоб порівняти масив зі своєю колекцією.

Реалізуйте `GottaSnatchEmAll.remove_duplicates`, яка відсортує масив карток і поверне масив відсортованих унікальних карток.

```elixir
GottaSnatchEmAll.remove_duplicates(["Newthree", "Newthree", "Newthree", "Scientuna"])
# => ["Newthree", "Scientuna"]
```

## 5. Картки, яких у них немає

Час порадіти за свою колекцію.

Реалізуйте `GottaSnatchEmAll.extra_cards`, яка приймає нашу колекцію та якусь іншу колекцію й повертає кількість карток, яких немає в іншій колекції.

```elixir
GottaSnatchEmAll.extra_cards(MapSet.new(["Scientuna"]), MapSet.new(["Newthree", "Scientuna"]))
# => 0
```

## 6. Картки, які є в усіх

Ми з друзями, ентузіастами Blorkemon™️, збираємося разом і міркуємо, які картки найпоширеніші.

Реалізуйте `GottaSnatchEmAll.boring_cards`, яка приймає масив колекцій і повертає масив відсортованих карток, які є в усіх колекціях.

```elixir
GottaSnatchEmAll.boring_cards([MapSet.new(["Scientuna"]), MapSet.new(["Newthree", "Scientuna"])])
# => ["Scientuna"]
```

## 7. Усі картки

Чи маємо ми з друзями всі картки Blorkemon™️ разом?

Реалізуйте `GottaSnatchEmAll.total_cards`, яка приймає масив колекцій і повертає загальну кількість різних карток у всіх колекціях.

```elixir
GottaSnatchEmAll.total_cards([MapSet.new(["Scientuna"]), MapSet.new(["Newthree", "Scientuna"])])
# => 2
```

## 8. Блискучі перемагають

Скоро до нас приїде в гості наш племінник, і нам хочеться справити на нього враження.
Діти ж люблять блискучі речі, так?
Картки Blorkemon™️ бувають блискучими!

Реалізуйте `GottaSnatchEmAll.split_shiny_cards`, яка приймає колекцію й повертає кортеж із двох масивів відсортованих карток: один з усіма картками, що починаються з `"Shiny"`, і один з рештою карток.

```elixir
GottaSnatchEmAll.split_shiny_cards(MapSet.new(["Newthree", "Scientuna", "Shiny Scientuna"]))
# => {["Shiny Scientuna"], ["Newthree", "Scientuna"]}
```
