# Інструкції

Ми створюємо просту онлайн-гру, у якій друг може вгадати секретне число. Хочеться дати трохи зворотного звʼязку, але не видати відповідь самою здогадкою. Нам потрібно розробити функцію, яка даватиме різні відповіді залежно від того, як здогадка співвідноситься із секретним числом.

| Умова                                                          | Відповідь      |
| ------------------------------------------------------------- | -------------- |
| Коли здогадка збігається із секретним числом                    | "Correct"      |
| Коли здогадка на одиницю більша або на одиницю менша за секретне число | "So close"     |
| Коли здогадка більша за секретне число                          | "Too high"     |
| Коли здогадка менша за секретне число                           | "Too low"      |
| Коли здогадку не зроблено                                       | "Make a guess" |

Усі здогадки та секретні числа є цілими числами.

## 1. Сформуйте відповідь, коли здогадка збігається із секретним числом

Реалізуйте функцію `compare/2`, яка приймає два аргументи, `secret_number` і `guess`, обидва з яких є цілими числами.

```elixir
GuessingGame.compare(5, 5)
# => "Correct"
```

## 2. Сформуйте відповідь, коли здогадка більша за секретне число

Змініть функцію `compare`, щоб вона відповідала на здогадки, більші за секретне число.

```elixir
GuessingGame.compare(5, 8)
# => "Too high"
```

## 3. Сформуйте відповідь, коли здогадка менша за секретне число

Змініть функцію `compare`, щоб вона відповідала на здогадки, менші за секретне число.

```elixir
GuessingGame.compare(5, 2)
# => "Too low"
```

## 4. Сформуйте відповіді, коли здогадка на одиницю більша або на одиницю менша за секретне число

Змініть функцію `compare`, щоб вона відповідала на здогадки, близькі до секретного числа.

```elixir
GuessingGame.compare(5, 6)
# => "So close"
GuessingGame.compare(5, 4)
# => "So close"
```

## 5. Сформуйте відповідь, коли здогадки немає

Змініть функцію `compare`, щоб вона відповідала на відсутність здогадки.

```elixir
GuessingGame.compare(5)
# => "Make a guess"

GuessingGame.compare(5, :no_guess)
# => "Make a guess"
```
