# Вступ

У JavaScript є вбудований обʼєкт `Date`, який зберігає дату й час і надає методи для роботи з ними.

<!-- prettier-ignore -->
~~~exercism/caution
Його створили на основі класу Java `java.util.Date`, який замінили на початку 2010-х, але заради зворотної сумісності `Date` у JavaScript залишився.

Через те, що працювати з датами загалом складно, а підтримка часових поясів або погана, або її немає взагалі, існує багато бібліотек, як-от `moment.js`, `day.js`, `date-fns` і `luxon`.

Ця вправа зосереджена на `Date`, який залишатиметься актуальним до самого кінця JavaScript.

## Створення

Обʼєкт `Date` - це екземпляр класу `Date`.
Його можна створити, не передаючи у функцію-конструктор жодних аргументів.
У результаті отримаємо обʼєкт `Date` із поточною датою й часом:

```javascript
const now = new Date();
// => Thu Apr 14 2022 11:46:08 GMT+0530 (India Standard Time)
// Shows current day, date and time (in your time zone).
```

### Мітка часу Unix (число)

Якщо передати число, його буде інтерпретовано як `timestamp`.
Мітка часу - це ціле число, яке позначає кількість **мілісекунд**, що минули з **1 січня 1970 року [UTC][defn-utc]+0**.

```javascript
const epoch = new Date(0);
// Thu Jan 01 1970 01:00:00 GMT+0100 (Central European Standard Time)

const another = new Date(1749508766627);
// Tue Jun 10 2025 00:39:26 GMT+0200 (Central European Summer Time)
```

Можна було б очікувати, що `new Date(0)` створить «найраніший» обʼєкт дати, але JavaScript перетворить дату на наш локальний часовий пояс, тож значення [початку відліку Unix][defn-unix-epoch] насправді отримають лише ті, хто перебуває в зоні [GMT / з UTC+0][defn-gmt].

### Мітка часу ISO 8601 (рядок тексту)

У конструктор `Date` можна передати рядок тексту (англ. string), який представляє дату.
**Єдиний** формат, однаковий у всіх реалізаціях, - це [спрощена версія][mdn-date-string-format] міжнародно визнаних і стандартизованих так званих [рядків мітки часу ISO 8601][defn-iso8601].

Момент часу за [UTC][defn-gmt] має такий вигляд:

```text
YYYY-MM-DDTHH:mm:ss.mssZ
YYYYMMDDTHHmmss.mssZ
```

Тут відбуваються такі підстановки:

| Ключ | Опис                                          | Типове значення |
| ---- | --------------------------------------------- | ------- |
| YYYY | Календарний рік, записаний 4 цифрами          |         |
| MM   | Календарний місяць, записаний 2 цифрами       | 01      |
| DD   | Календарний день, записаний 2 цифрами         | 01      |
| T    | Буквальна літера T, яка відокремлює дату від часу |         |
| HH   | Години за 24-годинним годинником, 2 цифри     | 00      |
| mm   | Хвилини, 2 цифри                              | 00      |
| ss   | Секунди, 2 цифри                              | 00      |
| mss  | Мілісекунди, 3 цифри                          | 000     |
| Z    | Буквальна літера Z або зсув `+/-HH:mm`        |         |

Буквальна літера `Z` позначає UTC (без часового поясу, без переходу на літній час).

Оскільки для більшості компонентів є типові значення, частини в кінці можна опускати:

```text
YYYY-MM-DD
```

Типове значення часу - 00:00:00.000.

Якщо мітка часу не закінчується на `Z` і не закінчується на `+HH:mm` чи `-HH:mm` (що вказує на зсув часового поясу), тоді з історичних причин діє таке правило:

> Якщо зсув часового поясу відсутній, форми лише з датою інтерпретують як час UTC, а форми з датою й часом - як локальний час.
> Інтерпретацію як часу UTC зумовила історична помилка в специфікації, яка не узгоджувалася з ISO 8601, але її не можна було виправити через сумісність із вебом.
> Див. [Зламаний парсер – проблема вебреальності][ref-broken-parser].

### Обʼєкт дати

Наявний обʼєкт дати теж можна використати як аргумент конструктора.
Так створюється копія наявного обʼєкта `Date` з тією самою датою й часом.

```javascript
const t1 = new Date();
const t2 = new Date(t1);
// Values of t1 and t2 will be the same.
```

### Передавання окремих значень компонентів дати й часу

Обʼєкт, який позначає лише дату, можна створити, передавши три числа.
Обʼєкт, який позначає дату й час, можна створити, передавши 6 чисел.

```javascript
const date1 = new Date(95, 11, 17);
// Creates Date for Dec 17 1995 00:00 if your local timezone is equivalent to UTC.

const date2 = new Date(2013, 12, 5, 13, 24, 0);
// Creates Date for Jan 5 2014 13:24 if your local timezone is equivalent to UTC.
```

Друге значення - це `month`, який починається з `0` для січня й триває до `11` для грудня.

## `Date.parse()`

Можна натрапити на згадки про функцію розбору дат `Date.parse` або на посилання на неї.
Оскільки для цієї функції існує лише кілька інваріантів (істин), а решта реалізації не специфікована (а отже, не стандартизована), користуватися нею не варто.

## Доступ до компонентів `Date`

В обʼєктів дати є різні методи, які повертають компоненти дати:

```javascript
getFullYear(); // Get the year (4 digits)
getMonth(); // Get the month, from 0 to 11.
getDate(); // Get the day of month, from 1 to 31.
getHours(); // Get the hour in a 24 clock, from 0 to 23
getMinutes(); // Get the minutes, from 0 to 59
getSeconds(); // Get the seconds, from 0 to 59
getMilliseconds(); // Get the milliseconds, from 0 and 999
getDay(); // Get the day of week, from 0 (Sunday) to 6 (Saturday).
```

Кожен із них має відповідний варіант із `set` (наприклад, `setFullYear`), щоб оновити значення.
Будь-яке значення, що виходить за межі, переноситься на наступний компонент:

```javascript
const date = new Date('2025-02-28T12:42:00Z');
// => Fri Feb 28 2025 13:42:00 GMT+0100 (Central European Standard Time)

date.setDate(29);
// there was no February 29th in 2025.

date.getDate();
// => 1

date.toString();
// => Sat Mar 01 2025 13:42:00 GMT+0100 (Central European Standard Time)
```

Для всіх методів є варіанти UTC, які ігнорують локальний часовий пояс.

## Перетворення з дати

В обʼєктів дати є метод `getTime()`, який повертає мітку часу UNIX у мілісекундах, тобто кількість мілісекунд від опівночі 1 січня 1970 року за UTC.
Крім того, доступний метод `toISOString()`, який перетворює обʼєкт дати на рядок мітки часу ISO 8601.

## Порівняння дат

Оператори «більше» (`>`), «більше або дорівнює» (`>=`), а також «менше» (`<`) і «менше або дорівнює» (`<=`) можна застосовувати безпосередньо між двома датами або між датою й числом.
Це працює, бо JavaScript намагається звести дату до примітива.

Останній рівнозначний виклику [`date.getTime()`][mdn-date-get-time].

Якщо не хочемо покладатися на цю поведінку, спершу перетворімо дату на число за допомогою `getTime()`.
