# Вказівки

У цій вправі ми будемо обробляти рядки журналу.

Кожен рядок журналу - це рядок тексту (англ. string) такого формату: `"[<LEVEL>]: <MESSAGE>"`.

Є три різні рівні журналу:

- `INFO`
- `WARNING`
- `ERROR`

На нас чекають три завдання, і кожне з них приймає рядок журналу та просить щось із ним зробити.

## 1. Отримати повідомлення з рядка журналу

Реалізуйте функцію `message`, щоб вона повертала повідомлення з рядка журналу:

```clojure
(message "[ERROR]: Invalid operation")
;;=> "Invalid operation"
```

Пробільні символи на початку та в кінці потрібно прибрати:

```clojure
(message "[WARNING]:  Disk almost full\r\n")
;;=> "Disk almost full"
```

## 2. Отримати рівень журналу з рядка журналу

Реалізуйте функцію `log-level`, щоб вона повертала рівень журналу з рядка журналу в нижньому регістрі:

```clojure
(log-level "[ERROR]: Invalid operation")
;;=> "error"
```

## 3. Переформатувати рядок журналу

Реалізуйте функцію `reformat`, яка переформатує рядок журналу: спочатку йде повідомлення, а після нього в дужках рівень журналу:

```clojure
(reformat "[INFO]: Operation completed")
;;=> "Operation completed (info)"
```
