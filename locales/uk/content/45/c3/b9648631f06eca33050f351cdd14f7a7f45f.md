# Вказівки

Дано два масиви. Визначте, чи перший масив міститься в другому, чи другий масив міститься в першому, чи обидва масиви містяться один в одному, чи жодна з цих умов не виконується.

Зокрема, масив A є підмасивом масиву B, якщо, відкинувши 0 або більше елементів з початку B і 0 або більше елементів з кінця B, ми отримуємо масив, який повністю дорівнює A.

Приклади:

 * A = [1, 2, 3], B = [1, 2, 3, 4, 5], A є підмасивом B
 * A = [3, 4, 5], B = [1, 2, 3, 4, 5], A є підмасивом B
 * A = [3, 4], B = [1, 2, 3, 4, 5], A є підмасивом B
 * A = [1, 2, 3], B = [1, 2, 3], A дорівнює B
 * A = [1, 2, 3, 4, 5], B = [2, 3, 4], A є надмасивом B
 * A = [1, 2, 4], B = [1, 2, 3, 4, 5], A не є ні надмасивом B, ні підмасивом B, ні рівним B
