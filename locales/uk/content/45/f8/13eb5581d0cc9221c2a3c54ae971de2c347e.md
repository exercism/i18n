# Тести

## Налаштування

Пройдіть [інструкції зі встановлення JavaScript][docs-exercism-javascript], щоб установити потрібні залежності.

## Вимоги

Установіть залежності для вправи:

```shell
corepack pnpm install
```

Якщо `corepack` повідомляє, що його не ввімкнено, увімкнути його можна так:

```bash
corepack enable pnpm
```

## Як пройти набір тестів

Кожна вправа містить набір тестів, який допомагає перевірити рішення перед надсиланням.
Ці тести можна запустити, відкривши командний рядок у каталозі вправи, а потім виконавши:

```bash
corepack pnpm test
```

У деяких наборах тестів усі тести, крім першого, пропущено.

Коли тест почне проходити, можна ввімкнути наступний, змінивши `xtest` на `test`.

## Написання власних тестів

Якщо потрібно написати додаткові власні тести, створіть новий файл `custom.spec.js` і надішліть його разом із рішенням та цим новим файлом:

```shell
exercism submit numbers.js custom.spec.js
```
