# Докладніше

В Elixir, щоб вибрати випадковий елемент із перелічуваної структури даних (наприклад, масиву чи діапазону), ми використовуємо [`Enum.random/1`][enum-random]. Ця функція вибере один елемент, причому кожен елемент має однакову ймовірність бути вибраним. Вибір одного випадкового значення з діапазону виконується за сталий час, без перебирання всього діапазону.

## Випадкові цілі числа та літери

- Вибір випадкового цілого числа
  ```elixir
  Enum.random(1..10)
  # => 7
  ```
- Вибір випадкової літери як рядка тексту (англ. string)
  ```elixir
  <<Enum.random(?A..?Z)>>
  # => "K"
  ```
- Вибір випадкової літери як списку символів
  ```elixir
  [Enum.random(?A..?Z)]
  # => ~c"J"
  ```

Щоб вибрати більше ніж один елемент із перелічуваної структури даних, ми використовуємо [`Enum.take_random/2`][enum-take-random]. Щоб відсортувати перелічувану структуру даних у випадковому порядку, ми використовуємо [`Enum.shuffle/1`][enum-shuffle].

## Випадкові числа з плаваючою комою

В Elixir немає власних функцій для вибору випадкового числа з плаваючою комою. Щоб зробити це, нам доведеться скористатися модулем [`rand`][erl-rand] з Erlang, який, до того ж, використовує під капотом і сам `Enum.random`.

- Вибір випадкового числа з плаваючою комою (більшого або рівного 0.0 і меншого за 1.0):

  ```elixir
  :rand.uniform()
  # => 0.275329955448815
  ```

- Вибір випадкового числа з плаваючою комою (більшого або рівного `a` і меншого за `b`):
  ```elixir
  a = 13
  b = 20
  :rand.uniform() * (b - a) + a
  # => 18.96815556890448
  ```

## Нормальний розподіл

Усі функції, згадані вище, вибирають випадкове значення так, що кожне можливе значення має однакову ймовірність бути вибраним. Це називається _рівномірним розподілом_. Модуль `rand` також пропонує функції [`normal/0`][erl-rand-normal-0] і [`normal/2`][erl-rand-normal-2], які вибирають випадкове число з плаваючою комою з [нормальним розподілом][normal-distribution].

## Зерно

Важливо розуміти, що «випадкові» значення генерує [_псевдо_випадковий генератор чисел][prng]. ГПВЧ - це алгоритм, який, отримавши початкове значення, яке називають _зерном_, буде генерувати послідовність чисел, що здається випадковою, але насправді випадковою не є.

Цей факт може стати в пригоді під час налагодження. Можна змусити генератор псевдовипадкових чисел Erlang (а отже, й Elixir) видавати ту саму послідовність значень, скинувши його зерно за допомогою [`:rand.seed/2`][rand-seed-2]. Перший аргумент - це конкретний алгоритм ГПВЧ, а другий - кортеж із трьох цілих чисел, тобто зерно.

```elixir
:rand.seed(:exsss, {1, 2, 3})
Enum.take_random(100..999, 3)
# => [680, 127, 622]

:rand.seed(:exsss, {1, 2, 3})
Enum.take_random(100..999, 3)
# => [680, 127, 622]
```

## Криптографія

Випадкові значення, які повертають `Enum.random` і модуль `rand` з Erlang, не є [криптографічно стійкими][cryptographically-secure-rng]. Не варто використовувати їх для генерації криптографічних ключів, паролів чи нонсів. Для цього випадку в Erlang є [`:crypto.strong_rand_bytes/1`][erl-crypto-strong-rand-bytes].
