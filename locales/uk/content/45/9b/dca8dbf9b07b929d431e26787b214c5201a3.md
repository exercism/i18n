# Тести

Трек Factor використовує **Factor 0.101**. Кожна вправа постачається з вбудованим словником `exercism-tools`, який визначає слова розбору `STOP-HERE` і `TASK:` та засіб запуску тестів. Перебуваючи в каталозі вправи, запустіть:

```
factor -roots=. -run=exercism-tools <exercise>
```

Наприклад, для вправи `hello-world`:

```
factor -roots=. -run=exercism-tools hello-world
```

Засіб запуску завершується зі статусом 0, коли всі тести проходять, і з ненульовим статусом та діагностичним виводом, коли якийсь тест не проходить.

## Пропущені тести

Розвʼязати вправу означає змусити пройти всі її тести.
Типово, коли ми запускаємо тести, виконується лише один тест (перший).
Це зроблено навмисно, щоб ми могли зосередитися лише на тому, щоб цей один тест пройшов.

Механізм полягає в рядку `STOP-HERE` у файлі тестів: під час розбору він каже Factor ігнорувати все, що нижче, тож засіб запуску бачить лише тести вище. Щойно перший тест пройде, ми можемо увімкнути більше тестів двома способами:

- **Видалити рядок `STOP-HERE`**, щоб увімкнути всі решта тестів одразу.
- **Перемістити рядок `STOP-HERE` нижче**, щоб увімкнути тести по одному, або по одному завданню. Концептуальні вправи групують тести під маркерами `TASK:`, тож перемістити `STOP-HERE` безпосередньо перед наступним `TASK:` - це природний крок.

Коли всі тести увімкнено і наше рішення проходить їх усі, вправу розвʼязано!
