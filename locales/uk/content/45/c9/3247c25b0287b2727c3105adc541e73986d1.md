# Вступ

## Пакети

У Go застосунок організовано в пакети.
Пакет - це сукупність вихідних файлів, що лежать в одній теці.
Усі вихідні файли в одній теці повинні мати однакову назву пакета на початку файлу.
За домовленістю пакети називають так само, як теку, у якій вони лежать.

```go
package greeting
```

Go надає велику стандартну бібліотеку пакетів, які можна використати у своїй програмі за допомогою ключового слова `import`.
Пакети зі стандартної бібліотеки імпортують за їхньою назвою.

```go
package greeting

import "fmt"
```

До імпортованого пакета потім звертаються за назвою пакета:

```go
world := "World"
fmt.Sprintf("Hello %s", world)
```

Go визначає, чи можна викликати щось із коду в інших пакетах, за тим, як це оголошено.
Щоб функція, тип, змінна, константа чи поле структури були видимі ззовні (це називають _експортованими_), їхня назва має починатися з великої літери.

```go
package greeting

// Hello is a public function (callable from other packages).
func Hello(name string) string {
    return "Hello " + name
}

// hello is a private function (not callable from other packages).
func hello(name string) string {
    return "Hello " + name
}
```

## Форматування рядків

Go має вбудований пакет `fmt` (пакет форматування), який пропонує різноманітні функції для роботи з форматом вхідних і вихідних даних.
Найуживаніша функція - `Sprintf`. Вона використовує дієслова на кшталт `%s`, щоб підставляти значення в рядок тексту (англ. string), і повертає цей рядок тексту.

```go
import "fmt"

food := "taco"
fmt.Sprintf("Bring me a %s", food)
// Returns: Bring me a taco
```

У Go числа з плаваючою комою зручно форматувати за допомогою дієслов `Sprintf`: `%g` (компактне подання), `%e` (експонента) або `%f` (без експоненти).
Усі три дієслова дають змогу керувати шириною поля та позицією числа.

```go
import "fmt"

number := 4.3242
fmt.Sprintf("%.2f", number)
// Returns: 4.32
```

Повний список доступних дієслов можна знайти в [документації пакета форматування][fmt-docs].

`fmt` містить й інші функції для роботи з рядками тексту, як-от `Println`, яка просто друкує отримані аргументи в консолі, та `Printf`, яка форматує вхідні дані так само, як `Sprintf`, і лише потім їх друкує.

[fmt-docs]: https://pkg.go.dev/fmt
