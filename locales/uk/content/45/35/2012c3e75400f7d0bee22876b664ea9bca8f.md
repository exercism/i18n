# Оголошення типів

PHP - мова з _динамічною типізацією_: змінна може містити дані будь-якого типу.
Водночас PHP дозволяє _необовʼязкове_ оголошення строгих типів для властивостей класу, аргументів функцій і повернених значень.
Строгі оголошення типів у PHP забезпечують перевірку типів під час виконання, проте PHP намагається звести скалярні типи до оголошеного, якщо це можливо.
Таку поведінку зведення типів можна вимкнути за допомогою оголошення `strict_types` на початку файлу.

```php
<?php
declare(strict_types=1);
```

Крім того, функція може мати тип повернення `void`, щоб позначити, що вона не повертає жодного значення.

```php
<?php
declare(strict_types=1);

class Driver
{
    string $serial_number;

    function setSerialNumber(string $number): void
    {
        $this->serial_number = $number;
    }

    function getSerialNumber(): string
    {
        return $this->serial_number; 
    }
}

$driver = new Driver(); 
$driver->setSerialNumber(1234);
// => This will throw a TypeError with strict_types=1
```

## Обʼєднання типів

Якщо аргумент функції, повернене значення або властивість класу може мати більше ніж один тип, можна оголосити обʼєднання типів.

```php
<?php

class IdentityCard
{
    private int|float $id = 0;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

## Змішані типи

Працюючи з кодом, ми не завжди можемо вказати тип.
Починаючи з PHP 8.0, доступний рятівний тип `mixed`.
`mixed` рівнозначний обʼєднанню типів `object|resource|array|string|float|int|bool|null`.
