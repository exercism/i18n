# Підказки

## 1. Подвоїти кожну карту

- Для таких [простих перетворень][map_method_docs], як оце, чудово підходить вбудований метод.

## 2. Створити кілька копій кожної 3, що є в колоді

- Є вбудований метод, ідеальний для власних перетворень або [накопичень][reduce_method_docs] (як-от сумування масиву тощо).

## 3. Знайти дві карти з точної середини колоди

- Є вбудований метод, щоб [розбивати][slice_method_docs] масиви на менші частини.

## 4. Дві крайні карти знову опиняться в середині колоди

- Є вбудований метод для [вставлення або видалення][splice_method_docs] елементів із середини масиву.
- У масиву також є вбудовані методи для видалення першого й останнього елементів, див. [документацію про масиви на MDN][array_docs].

## 5. Усі карти, які не є 2, зникають

- Є вбудований метод для [фільтрування][filter_method_docs] або виключення елементів масиву.

## 6. Перетворити перетасовану колоду на ідеально впорядковану

- Є вбудований метод для [сортування][sort_method_docs].

## 7. Змінити порядок колоди

- Є вбудований метод для [обернення][reverse_method_docs] масиву.
