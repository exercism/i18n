# Про

Потоки у Factor - це *кооперативні корутини* в межах одного потоку операційної системи.
Потік виконується, доки явно не передасть керування або не виконає блокуючу
операцію вводу-виводу; тоді планувальник обирає інший потік, готовий до виконання.
Звідси випливають два наслідки:

- Усе, що відбувається між передаваннями керування, фактично атомарне.
- Справжній паралелізм на кількох ядрах вимагає вийти за межі стандартного
  словника `threads` (наприклад, `concurrency.distributed` для багатопроцесних
  схем).

Стандартні примітиви конкурентності утворюють кілька рівнів:

| Словник                       | Надає                               |
|-----------------------------|----------------------------------------|
| [`threads`][threads]                   | `spawn`, `yield`, ідентичність потоку      |
| [`concurrency.promises`][concurrency.promises]      | `<promise>`, `fulfill`, `?promise`     |
| [`concurrency.locks`][concurrency.locks]         | `<lock>`, `with-lock`                  |
| [`concurrency.combinators`][concurrency.combinators]   | `parallel-map`, `parallel-each`        |
| [`concurrency.semaphores`][concurrency.semaphores]    | `<semaphore>`, `acquire`, `release`    |
| [`concurrency.mailboxes`][concurrency.mailboxes]     | поштові скриньки кожного потоку, `send`, `receive`  |
| [`concurrency.channels`][concurrency.channels]      | дескриптори рандеву, `to`, `from`       |

```factor
USING: concurrency.combinators concurrency.locks
concurrency.promises kernel sequences threads ;

! parallel-map: fork-join, in order
{ "alpha" "beta" "gamma" } [ length ] parallel-map .
! => { 5 4 5 }

! spawn + promise: hand-rolled fork-join
<promise> [
    [ "hello, world" swap fulfill ] curry "greeter" spawn drop
] keep ?promise .   ! => "hello, world"

! <lock> + with-lock: protect a shared mutable slot
<lock> :> guard
guard [ "do thing under lock" drop ] with-lock
```

`parallel-map` - це високорівневий API, і саме до нього ідіоматичний Factor звертається
насамперед. Трійка `spawn` / `<promise>` / `?promise` - те, з чого побудовано
`parallel-map`; вона стане в пригоді, коли форма ітерації не вкладається в map
(наприклад, коли треба запустити робітників, які відповідають через інші канали).

Замки захищають *спільний змінний стан*, зазвичай комірку кортежу або
хеш-таблицю, яку читає чи записує більше ніж один потік. Якщо оновлення складене
й неатомарне, вважаємо, що замок потрібен і для читання, і для запису.
Пропущений з будь-якого боку замок - класичний рецепт розірваного читання.
