# Інструкції

У цій вправі ми граємо в рольову гру «Чарівник і воїни», де можна виступати або чарівником, або воїном.

Для воїнів і чарівників діють різні правила, які визначають, скільки одиниць шкоди вони завдають.

Для воїна правила такі:

- Завдає 6 одиниць шкоди, якщо персонаж, якого він атакує, невразливий
- Завдає 10 одиниць шкоди, якщо персонаж, якого він атакує, уразливий

Для чарівника правила такі:

- Завдає 12 одиниць шкоди, якщо чарівник заздалегідь підготував закляття
- Завдає 3 одиниці шкоди, якщо чарівник не підготував закляття заздалегідь

Зазвичай персонажі ніколи не бувають уразливими. Однак чарівники _уразливі_, якщо вони не підготували закляття.

На нас чекає шість завдань, повʼязаних із персонажами-воїнами та чарівниками.

## 1. Опишіть персонажа

Перевизначте метод `ToString()` у класі `Character`, щоб він повертав опис персонажа у форматі `"Character is a <CHARACTER_TYPE>"`.

```csharp
var warrior = new Warrior();
warrior.ToString();
// => "Character is a Warrior"
```

## 2. Зробіть так, щоб персонажі типово були невразливими

Переконайтеся, що метод `Character.Vulnerable()` завжди повертає `false`.

```csharp
var warrior = new Warrior();
warrior.Vulnerable();
// => false
```

## 3. Дозвольте чарівникам підготувати закляття

Реалізуйте метод `Wizard.PrepareSpell()`, щоб чарівник міг заздалегідь підготувати закляття.

```csharp
var wizard = new Wizard();
wizard.PrepareSpell();
```

## 4. Зробіть чарівників уразливими, коли закляття не підготовлено

Зробіть так, щоб метод `Vulnerable()` повертав `true`, якщо чарівник не підготував закляття, а інакше повертав `false`.

```csharp
var wizard = new Wizard();
wizard.Vulnerable();
// => true
```

## 5. Обчисліть одиниці шкоди для чарівника

Реалізуйте метод `Wizard.DamagePoints()`, щоб він повертав завдані одиниці шкоди: 12 одиниць шкоди, коли закляття підготовлено, і 3 одиниці шкоди, коли ні.

```csharp
var wizard = new Wizard();
var warrior = new Warrior();

wizard.PrepareSpell();
wizard.DamagePoints(warrior);
// => 12
```

## 6. Обчисліть одиниці шкоди для воїна

Реалізуйте метод `Warrior.DamagePoints()`, щоб він повертав завдані одиниці шкоди: 10 одиниць шкоди, коли ціль уразлива, і 6 одиниць шкоди, коли ні.

```csharp
var warrior = new Warrior();
var wizard = new Wizard();

warrior.DamagePoints(wizard);
// => 10
```
