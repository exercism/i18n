# Підказки

## Загальне

- Екземпляри struct створюються шляхом оголошення назви struct, після якої у фігурних дужках ідуть значення полів.
- `@T` можна використати, щоб оголосити snapshot деякого типу `T`, наприклад `let i: @u32 = @1;` оголошує змінну `i`, яка є snapshot значення `u32` `1`;
- Можна видобути значення зі snapshot за допомогою оператора `*` (desnap), наприклад `let int = *an_int_snapshot;`.
- Можна оголосити значення змінним за допомогою ключового слова `mut`, наприклад `let mut i = 1;`.

## 1. Створення лічильника голосів

- Потрібно створити вказівник на struct `VoteCounter`, тобто `@VoteCounter`.
- Параметр `value` можна присвоїти безпосередньо під час створення екземпляра struct.

## 2. Отримання кількості голосів із лічильника

- Можна застосувати оператор `*` до snapshot, щоб зробити desnap і отримати його значення, наприклад `*my_snapshot`

## 3. Збільшення голосів лічильника

- Замість того, щоб змінювати snapshot `@VoteCounter`, потрібно повернути новий екземпляр `VoteCounter` зі збільшеною кількістю голосів.
- Можна зробити desnap значення лічильника голосів за допомогою оператора `*` або викликати функцію, яку ми створили в попередньому завданні.

## 4. Створення результатів виборів

- Створіть новий struct або змінну `ElectionResult` з полями `name` і `vote_counter`, заповненими значеннями з аргументів функції.
- Можна створити snapshot `VoteCounter`, поставивши оператор `@` перед назвою змінної чи оголошенням struct, або викликати функцію `new_vote_counter`, яку ми створили в одному з попередніх завдань.

## 5. Оголошення результатів

- Хоча ми отримуємо snapshot на `ElectionResult`, до його полів можна звертатися через крапку `.`, наче це й не snapshot!
- Сформуйте повідомлення, звернувшись до полів `name` і `vote_counter` цього struct.
- Коли робимо desnap вкладеного snapshot, потрібно застосувати стільки операторів `*`, скільки snapshot потрібно розкрити:

```rust
let result = @ElectionResult {
    name: "John",
    vote_counter: @VoteCounter { value: 32 },
};

println!("{}", **result.vote_counter.value); 
// => 32
```

## 6. Перерахунок голосів

- Через [те, як реалізовано словники][dictionaries underneath], вони мають бути змінними, щоб і змінювати їх, і читати з них, а отже, зміни, які ми вносимо в словник усередині функції, будуть видні й поза функцією.
- Щоб збільшити значення ключа в `let mut m: Felt252Dict<u32>`, потрібно поєднати його функції `get` та `insert`: `m.insert('mykey', m.get('mykey') + 1);`
