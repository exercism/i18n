# Підказки

## Загальне

- Не забуваймо звертатися до таблиці в інструкціях.

## 1. Маючи розширення, повернути очікуваний тип медіа

- Скористайтеся [зіставленням із шаблоном][pattern-matching], щоб повернути правильний тип медіа.
- Можна скористатися [кількома визначеннями функції][mfc].

## 2. Маючи бінарний файл, повернути очікуваний тип медіа

- Скористайтеся [спеціальною формою для бінарних даних][special-forms], доступною вам для запису бінарного літерала.
- Скористайтеся [зіставленням із шаблоном][binary-matching], щоб зіставити перші кілька байтів бінарних даних файлу.

## 3. Маючи розширення та бінарний файл, перевірити, чи відповідає файл очікуваному типу

- Повторно використайте функції, створені для частин 1 і 2.
- Порівняйте повернені значення обох функцій, а потім поверніть відповідне значення.
  - Можна скористатися [умовним макросом `if`][if] для бінарних умов.
