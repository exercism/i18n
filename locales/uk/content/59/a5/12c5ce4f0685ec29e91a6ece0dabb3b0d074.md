# Вступ

[Конструкція `switch`][switch] порівнює значення з кількома можливими варіантами збігу. Вона дає змогу писати чистіший і зрозуміліший код, ніж ланцюжок із кількох конструкцій `if-else`.

Конструкція `switch` починається з ключового слова `switch`, після якого йде значення для перевірки. Кожен можливий збіг вводиться ключовим словом `case`. Ключове слово `default` визначає запасний випадок, який виконується, якщо жоден із явно заданих випадків не збігається. Як і ланцюжки `if-else`, конструкція `switch` виконує лише блок коду, повʼязаний із першим відповідним випадком.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Розгляньмо такий ланцюжок `if-else`:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

Це можна записати зрозуміліше за допомогою конструкції `switch`:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

[switch]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#Switch
