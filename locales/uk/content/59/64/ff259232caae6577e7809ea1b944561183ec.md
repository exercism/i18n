# Вступ

## Дати та час

Стандартна бібліотека Elixir пропонує чотири різні модулі для роботи з датами й часом, кожен зі своєю структурою.

- Модуль `Date`. Структуру `Date` можна створити за допомогою сигілу `~D`.

  ```elixir
  ~D[2021-01-01]
  ```

- Модуль `Time`. Структуру `Time` можна створити за допомогою сигілу `~T`.

  ```elixir
  ~T[12:00:00]
  ```

- Модуль `NaiveDateTime` для дати-часу без часового поясу. Структуру `NaiveDateTime` можна створити за допомогою сигілу `~N`.

  ```elixir
  ~N[2021-01-01 12:00:00]
  ```

- Модуль `DateTime` для дати-часу з часовим поясом. Використання цього модуля для часових поясів, відмінних від UTC, потребує зовнішньої залежності, а саме бази даних часових поясів.

### Порівняння

Щоб порівняти дати або час між собою, знайдіть функцію `compare` або `diff` у відповідному модулі. Оператори порівняння, як-от `==`, `>`, і `<`, _здаються_ робочими, але вони не виконують правильного семантичного порівняння для цих структур.
