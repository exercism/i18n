# Вступ

## Рівність

Типи Elm можна перевірити на «однаковість» за допомогою оператора рівності `(==)`.
Оператор нерівності - `(/=)` (*не* `!=`, як у багатьох мовах).
Оператор рівності працює з літералами, кортежами, записами та власними типами.

```elm
1 == 2
    --> False

1 /= 2
    --> True

(1, 2) == (2, 1)
    --> False

type alias MyRecord = { myInt : Int, myStrings : List String }
a : MyRecord
a = MyRecord (1 + 1) ["hello world"]

type alias MyOtherRecord = { myInt : Int, myStrings : List String }
myStrings =  (String.join " " ["hello", "world"]) :: []
b : MyOtherRecord
b = { myInt = 2, myStrings = myStrings}

a == b
    --> True
```

Зауважмо, що функції *ніколи не можна* порівнювати, бо це призведе до збою програми під час виконання.

## Порівняння

Оператори порівняння `(<)`, `(<=)`, `(>)`, `(>=)` і функції `min`, `max`, `compare` працюють з типами `comparable`.
Тип `comparable` - це особливий тип, який обʼєднує всі вбудовані типи, які можна порівнювати: числа, символи, рядки тексту (англ. string), масиви порівнюваних значень і кортежі порівнюваних значень.

```elm
1 < 1 + 1
    --> True

'x' < 'X'
    --> False

"abc" < "abz"
    --> True

"abc" < "abcd"
    --> True

"abc" < "b"
    --> True

min [1 , 2, 9000] [10]
    --> [1 , 2, 9000]

min (1, "hello") (3, "bye")
    --> (1, "hello")
```

Значення інших типів, як-от записи чи власні типи, не можна порівнювати безпосередньо.

Деякі вбудовані типи вимагають, щоб їхній вміст був `comparable`, наприклад ключі `Set` або `Dict`, оскільки їхня структура спирається на внутрішнє впорядкування.

Масиви `comparable`-значень можна сортувати за допомогою `List.sort`, а масиви значень, які можна зіставити з порівнюваними значеннями, можна сортувати за допомогою `List.sortBy`.
Якщо потрібне ієрархічне сортування (сортувати за однією властивістю, а збіги розвʼязувати за допомогою іншої), кортежі або масиви також можна використовувати з `List.sortBy`, оскільки кортежі й масиви сортуються в лексикографічному порядку.


```elm
List.sort ["hi", "hello", "bye", "goodbye"]
    --> ["bye", "goodbye", "hello", "hi"]

List.sortBy String.length ["hi", "hello", "bye", "goodbye"]
    --> ["hi", "bye", "hello", "goodbye"]

-- sort by length, then alphabetically
List.sortBy (\str -> (String.length str, str)) ["hi", "mum", "hello", "sis", "bye", "dad"]
    --> ["hi", "bye", "dad", "mum", "sis", "hello"]
```

Функція `compare` приймає два `comparable`-значення і повертає `Order`.
`Order` - це тип, який за одну операцію перевіряє, чи одне значення більше (`GT`), дорівнює (`EQ`) або менше (`LT`) за інше.

```elm
compare 1 2
    --> LT

compare "" ""
    --> EQ

compare [12] []
    --> GT
```

Функції порівняння можна будувати для довільних типів і використовувати, наприклад, для сортування за допомогою `List.sortWith`:

```elm
type Color = Red | Green | Blue

compareColors : Color -> Color -> Order
compareColors a b =
  case (a, b) of
    (Red, Red) -> EQ
    (Red, _) -> LT
    (_, Red) -> GT
    (Green, Green) -> EQ
    (Green, _) -> LT
    (_, Green) -> GT
    (Blue, Blue) -> EQ

List.sortWith compareColors [Blue, Red, Green, Green, Blue]
    --> [Red, Green, Green, Blue, Blue]
```
