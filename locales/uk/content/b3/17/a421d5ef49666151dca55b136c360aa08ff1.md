# Докладніше

Gleam подає значення правди та неправди типом `Bool`. Існує лише два значення: `True` і `False`. Їх можна присвоїти змінній:

```gleam
let true_variable = True
let false_variable = False
```

Оператори `&&` (логічне і), `||` (логічне або) та `!` дають змогу працювати з булевими значеннями (англ. Boolean):

```gleam
True && True  // -> True
True && False // -> False

False || True  // -> True
False || False // -> False

!False // -> True
!True  // -> False
```

Оператори `&&` (і) та `||` (або) використовують скорочене обчислення, а це означає, що вираз праворуч від оператора обчислюється лише за потреби.

Кожен з операторів має свій пріоритет: `!` обчислюється раніше за `&&` (і) та `||` (або). Фігурні дужки (`{}`) дають змогу обчислити одну частину виразу раніше за інші:

```gleam
!True && False   // -> False
!{True && False} // -> True
```
