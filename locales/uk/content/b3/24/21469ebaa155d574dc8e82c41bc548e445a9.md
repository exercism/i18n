# Докладніше

**Слово** - це назва функції у Factor. Ми вже бачили стек даних і
слова перестановки в `basics`; тут ми визначаємо власні слова, які
обчислюють зі своїми вхідними даними.

```factor
: square ( x -- x*x ) dup * ;
: hello  ( -- )       "Hello, world!" print ;
: max3   ( a b c -- max ) max max ;
```

Визначення складається з `:`, стекового ефекту, тіла, а потім `;`. Назви
всередині `( … -- … )` призначені для читача; а компілятор перевіряє
*кількість* вхідних і вихідних даних. Невідповідність - це помилка часу
компіляції, яка виявляє клас помилок, що були б помилками часу виконання
в динамічно типізованій мові без такого роду оголошень.

Слова цілочисельної арифметики `+`, `-`, `*` походять зі словника
`math` і кожне бере два числа з вершини стека. Вершина стека - це правий
операнд, тому `8 3 -` обчислює `8 - 3`.

`CONSTANT:` визначає назву для фіксованого значення; виклик назви кладе
значення на стек, точно як будь-яке інше слово. Розмістіть константи на
початку файлу, перед будь-яким словом, яке їх використовує.

Тіло слова може викликати будь-яке слово, уже наявне в області
видимості: раніші визначення в тому самому файлі, слова з імпортованих
словників і константи, які ми оголосили. Компонування малих
вузькоспеціалізованих слів - звичний спосіб побудувати програму.

Як прийнято:

- Слова та константи використовують `lowercase-kebab-case`.
- Предикати закінчуються на `?` і повертають булеве значення (англ. Boolean) (`even?`, `empty?`).
- Слова, які змінюють свої вхідні дані, часто мають ту саму назву, що й
  незмінювальна версія, і розрізняються лише за контекстом.
