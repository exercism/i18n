# Цикли `for`

Циклічне повторення - фундаментальна концепція програмування, яка дає змогу виконати блок коду кілька разів.
У Swift є два типи циклів: [цикли `for-in`][for-loops] і цикли `while`.
У цьому розділі ми познайомимося з циклами `for-in`.

Цикли `for` дають змогу перебирати послідовність значень, беручи по черзі кожен елемент і звʼязуючи його зі змінною, яку ми обираємо самі.
Swift дає змогу перебирати найрізноманітніші послідовності: діапазони, масиви, рядки тексту (англ. string) та інші типи, про які ми поговоримо далі.
Коли всі елементи послідовності перебрано, цикл завершується.

Цикли `for` оголошуються за допомогою ключового слова `for`, після якого йде імʼя змінної, ключове слово `in` і послідовність значень для перебирання.
Змінна, указана в циклі `for-in`, незмінна, тобто її значення не можна змінити всередині циклу.
Ось приклад циклу `for-in`, який перебирає масив чисел:

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
  print(number)
}
print("Done with numbers")

// prints:
// 3
// 10
// 7
// 11
// Done with numbers
```

~~~~exercism/note
Змінна `number` оголошується в циклі `for-in` і доступна лише в межах області видимості циклу.

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
    number + 1
}
number + 1
// Error: Use of unresolved identifier 'number'
```
~~~~

## Перебирання діапазону

За допомогою циклу `for-in` можна також перебирати діапазон чисел.
Це дає змогу виконати блок коду певну кількість разів. Наприклад, діапазон `1...5` охоплює числа 1, 2, 3, 4 і 5, тож цикл виконається 5 разів.
Іноді потрібно перебрати індекси в такій структурі даних, як масив, і тоді можна скористатися діапазоном `0..<array.count`.

```swift
let numbers = [3, 10, 7, 11]

for i in 0..<numbers.count {
  print(numbers[i])
}

// prints:
// 3
// 10
// 7
// 11
```

## Перебирання рядка тексту

Рядок тексту теж можна перебирати за допомогою циклу `for-in`.
Це дає змогу перебрати кожен символ у рядку тексту. Звернімо увагу: тип, указаний у циклі, це `Character`.

```swift
let message = "Hello!"

for character in message {
  print(character)
}

// prints:
// H
// e
// l
// l
// o
// !
```

## stride

Swift також надає функцію `stride`, яка дає змогу створити послідовність у межах діапазону із заданим кроком.
Цю послідовність потім можна перебрати за допомогою циклу `for-in`.
`stride` визначається як [`stride(from:to:by:)`][stride-to] або [`stride(from:through:by:)`][stride-through]: перший варіант не включає кінцеве значення, а другий включає його.

```swift
for i in stride(from: 0, to: 10, by: 2) {
  print(i)
}

// prints:
// 0
// 2
// 4
// 6
// 8
```

Звернімо увагу, що параметр `to` не включає кінцеве значення, тож цикл перебирає числа до значення перед параметром `to`, а параметр `through` його включає, тож у цьому випадку до послідовності потрапить і `10`.

[stride-to]: https://developer.apple.com/documentation/swift/stride(from:to:by:)
[stride-through]: https://developer.apple.com/documentation/swift/stride(from:through:by:)
[for-loops]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
