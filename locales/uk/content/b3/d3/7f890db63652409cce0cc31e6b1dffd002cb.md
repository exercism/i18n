# Інструкції

У цій вправі ми напишемо трохи коду, який допоможе нам підготуватися до купівлі транспортного засобу.

У нас є три завдання: визначити, чи потрібно буде отримати посвідчення водія, вибрати один із двох транспортних засобів і оцінити прийнятну ціну вживаного транспортного засобу.

## 1. Визначте, чи потрібне посвідчення водія

Для керування деякими видами транспорту потрібне посвідчення водія.
Вважаємо, що посвідчення потрібне лише для видів `car` і `truck`, а все інше можна експлуатувати без нього.

Реалізуйте функцію `needs_license(kind)`, яка приймає вид транспортного засобу і повертає булеве значення (англ. Boolean), що вказує, чи потрібне посвідчення для цього виду транспорту.

```R
needs_license("car");
# => TRUE

needs_license("bike");
# => FALSE
```

## 2. Виберіть між двома можливими транспортними засобами для купівлі

Ми оцінюємо доступні нам варіанти транспортних засобів.
Нам вдалося звузити вибір до двох варіантів, але потрібна допомога, щоб ухвалити остаточне рішення.
Для цього реалізуйте функцію `choose_vehicle(option1, option2)`, яка приймає два транспортні засоби як аргументи і повертає рішення, а саме варіант, що йде першим за словниковим порядком.

```R
choose_vehicle("Wuling Hongguang", "Toyota Corolla");
# =>  "Toyota Corolla"

choose_vehicle("Volkswagen Beetle", "Volkswagen Golf");
# =>  "Volkswagen Beetle"
```

## 3. Обчисліть орієнтовну ціну вживаного транспортного засобу

Тепер, коли рішення ухвалено, нам хочеться бути впевненими, що в автосалоні нам запропонують справедливу ціну.
Оскільки нас цікавить купівля вживаного транспортного засобу, ціна залежить від того, скільки йому років.
Для приблизної оцінки вважаємо: якщо транспортному засобу менше 3 років, він коштує 80% початкової ціни, яку мав новим.
Якщо йому більше 10 років, він коштує 50%.
Якщо транспортному засобу щонайменше 3 роки, але не більше 10 років, він коштує 70% початкової ціни.

Реалізуйте функцію `calculate_resale_price(original_price, age)`.
Вона приймає початкову ціну та вік транспортного засобу як аргументи і повертає орієнтовну ціну в автосалоні.

```R
calculate_resale_price(1000, 1);
# => 800

calculate_resale_price(1000, 5);
# => 700

calculate_resale_price(1000, 15);
# => 500
```
