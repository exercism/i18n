# Інструкції

У цій вправі ми напишемо трохи коду, щоб допомогти приготувати чудову лазанью з нашої улюбленої кулінарної книги.

У нас є пʼять завдань, усі повʼязані з часом, витраченим на приготування лазаньї.

## 1. Визначте очікуваний час у печі в хвилинах

Визначте незмінну змінну `expectedMinutesInOven`, яка повертає, скільки хвилин лазанья має бути в печі.
Її потрібно експортувати.
Згідно з кулінарною книгою, очікуваний час у печі в хвилинах становить 40:

```nim
nim> expectedMinutesInOven
40 == type int
```

## 2. Обчисліть час, що залишився в печі, у хвилинах

Реалізуйте процедуру `remainingMinutesInOven`, яка приймає фактичні хвилини, які лазанья вже провела в печі, як параметр і повертає, скільки хвилин лазаньї ще залишилося перебувати в печі, на основі очікуваного часу в печі в хвилинах із попереднього завдання.

```nim
nim> remainingMinutesInOven(30)
10 == type int
```

## 3. Обчисліть час підготовки в хвилинах

Реалізуйте процедуру `preparationTimeInMinutes`, яка приймає кількість шарів, доданих до лазаньї, як параметр і повертає, скільки хвилин витрачено на підготовку лазаньї, припускаючи, що кожен шар займає 2 хвилини на підготовку.

```nim
nim> preparationTimeInMinutes(2)
4 == type int
```

## 4. Обчисліть загальний час роботи в хвилинах

Реалізуйте процедуру `totalTimeInMinutes`, яка приймає два параметри: параметр `numberOfLayers` задає кількість шарів, доданих до лазаньї, а параметр `actualMinutesInOven` задає кількість хвилин, які лазанья провела в печі.
Процедура має повертати, скільки хвилин загалом витрачено на приготування лазаньї, що є сумою часу підготовки в хвилинах і часу в хвилинах, який лазанья провела в печі на цей момент.

```nim
nim> totalTimeInMinutes(3, 20)
26 == type int
```
