# Докладніше

Область видимості значення визначає, звідки в програмі можна отримати доступ до цього значення.

## Чотири типи області видимості: блок, функція, прототип функції, файл

### Область видимості блоку

До значення з областю видимості блоку можна отримати доступ лише зсередини блоку, де його визначено.
Докладніше про блоки йдеться в [концепції блоків](../blocks/introduction.md#Introduction).

### Область видимості функції

Область видимості функції - це особливий різновид області видимості, який застосовується до міток, що використовуються з інструкціями `goto`.
Дві мітки з однаковою назвою не можна використовувати в одній функції, навіть якщо ці мітки визначено в різних блоках усередині функції.

### Область видимості прототипу функції

Область видимості прототипу функції - це ще один особливий різновид області видимості, який застосовується лише до параметрів, названих у прототипі (його ще називають оголошенням, памʼятаючи, що не всі оголошення є прототипами).
У оголошенні функції назва параметра зазвичай необовʼязкова.
Область видимості назви має значення лише в межах оголошення.
У наступному прикладі ідентифікатор `len` визначено, а потім на нього посилаються далі в оголошенні функції.

```c
#include <stdio.h>

// len is defined and then referred to
void my_func(int len, int numbers[len]);

int main() {
    int numbers[2];
    numbers[0] = 1;
    numbers[1] = 2;
    my_func(2, numbers);
}

void my_func(int length, int numbers[length]) {
    // prints numbers should have 2 elements
    printf("numbers should have %d elements", length);
}
```

Зауважмо, що в межах оголошення назви мають збігатися, коли йдеться про ту саму змінну.
Якби `my_func` було оголошено як `void my_func(int len, int numbers[length]);`, то виникла б помилка компіляції приблизно такого вигляду

```
/tmp/scn62kKPEZ.c:4:35: error: 'length' undeclared here (not in a function)
    3 | void my_func(int len, int numbers[length]);
      |                                   ^~~~~~
/tmp/scn62kKPEZ.c: In function 'main':
/tmp/scn62kKPEZ.c:10:16: error: type of formal parameter 2 is incomplete
   10 |     my_func(2, numbers);
```

Визначення функції не обовʼязково має використовувати ту саму назву параметра, що була в оголошенні функції.
У наведеному вище прикладі в оголошенні використано `len`, а у визначенні - `length`, що демонструє: область видимості ідентифікатора `len` була лише в межах оголошення функції.

### Область видимості файлу

До значення з областю видимості файлу можна отримати доступ з будь-якого місця файлу.
Будь-яке таке значення визначено поза функцією.
