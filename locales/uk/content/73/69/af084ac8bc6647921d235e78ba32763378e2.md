# Інструкції

Ми працюємо системним адміністратором у великій компанії в Мюнхені, Німеччина. Одне з наших обовʼязків - керування електронними поштами.

Ми чуємо скарги від людей, які кажуть, що не можуть надіслати листів пану Мюллеру. Швидко стає зрозуміло, що більшість компанії користується старим поштовим клієнтом, який не розпізнає `müller@firma.de` як дійсну адресу електронної пошти через не-ASCII символ.

Переконувати людей відмовитися від улюбленого старого поштового клієнта - марна справа, тож ми вирішуємо створити очищені псевдоніми для всіх поштових акаунтів.

## 1. Очистити наявні імена користувачів, прибравши все, крім малих літер

Реалізуймо функцію `sanitize/1`. Вона має приймати імʼя користувача як charlist і повертати імʼя користувача, з якого прибрано всі символи, крім малих літер.

```elixir
Username.sanitize(~c"schmidt1985")
# => ~c"schmidt"
```

## 2. Дозволити підкреслення

Розширмо функцію `sanitize/1`. Вона не повинна прибирати підкреслення з імені користувача.

```elixir
Username.sanitize(~c"mark_fischer$$$")
# => ~c"mark_fischer"
```

## 3. Замінити німецькі символи

У німецькому алфавіті є 4 не-ASCII символи, і всі вони мають загальновизнані ASCII-відповідники.

| Німецький символ | ASCII-відповідник |
| ---------------- | ---------------- |
| ä                | ae               |
| ö                | oe               |
| ü                | ue               |
| ß                | ss               |

Розширмо функцію `sanitize/1`. Вона має замінювати німецькі символи згідно з таблицею. Можна сміливо припустити, що всі імена користувачів уже записані малими літерами.

```elixir
Username.sanitize(~c"cäcilie_weiß")
# => ~c"caecilie_weiss"
```
