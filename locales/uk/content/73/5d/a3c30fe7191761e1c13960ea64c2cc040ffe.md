# Про

[Lua](https://lua.org) - це проста, але потужна, ефективна, легка та вбудовувана скриптова мова. Її розробила, реалізувала й підтримує команда у складі Роберто Ієрусалімші, Вальдемара Селеса і Луїса Енріке де Фігейреду в [PUC-RIO](https://www.puc-rio.br/) у Бразилії з 1993 року.

## Коментарі

Однорядкові коментарі в Lua починаються з `--`, а багаторядкові коментарі починаються з `--[[` і закінчуються `]]`.
```lua
-- This is a single line comment.

--[[This is
a multiline
comment
]]
```

## Змінні

У Lua є три типи змінних: глобальні змінні, локальні змінні та поля таблиць. Щоб не ускладнювати, тут пояснюються лише локальні змінні. Типово всі змінні глобальні, тому локальні змінні потрібно оголошувати саме такими за допомогою ключового слова `local`.
```lua
local x
```

Значення можна присвоїти змінній за допомогою оператора `=`.
```lua
local x = 1
```

Область видимості змінної `local` обмежена блоком, де її оголошено. Блоком може бути тіло керуючої конструкції, тіло функції або файл чи рядок тексту (англ. string), де оголошено змінну.
```lua
local x = 1

if x == 1 then
  local x = 2
  print(x) -- prints 2
end

print(x) -- prints 1
```

## Функції

Функцію оголошують за допомогою ключового слова `function`; як і змінні, вона типово глобальна. Визначення функції має назву, список параметрів і тіло. Функція завершується, коли досягає ключового слова `return`, і повертає всі значення, перелічені після нього. Без указаного `return` функція поверне `nil`.

```lua
-- Defining a local function which returns "Hello " followed by 
-- the name which was given as parameter
local function say_hello(name)
  return 'Hello ' .. name
end
```

## Таблиці

Таблиці слугують єдиним механізмом структурування даних у Lua, і вони дуже потужні. Їх використовують для представлення масивів, множин, обʼєктів, модулів і багато чого іншого. По суті, таблиця в Lua - це асоціативний масив.
```lua
-- create a table and assign its reference to tbl
local tbl = {}

-- new entry with key 'x' and value 1
tbl['x'] = 1

-- printing the value
print(tbl['x'])  --> 1

-- uninitialized table fields evaluate to nil
print(tbl['y'])  --> nil

-- there is also syntactic sugar - the following is the same as above
tbl.y = 1
print(tbl.y)    --> 1
```

Це лише невеликий вступ, потрібний для наступного розділу. До цієї теми ми докладно повернемося згодом.

## Модулі

Модуль - це набір коду, збережений у вихідному файлі `.lua`. Усе, що експортує модуль, зберігається в таблиці, і цю таблицю повертають наприкінці файлу. Тож таблиця фактично відіграє роль простору імен.
```lua
-- say-hello.lua

-- defining the table 'say' which is exported at the end
local say = {}

-- defining the function 'hello' as a table field
-- this is syntax sugar for: say.hello = function() print('Hello!') end
function say.hello()
  print('Hello!')
end

-- returning (exporting) the table 'say'
return say
```

Потім цей модуль можна завантажити в інший файл через функцію `require`, яка повертає таблицю.
```lua
-- lets_say_hello.lua
local say = require('say-hello')
say.hello() -- prints "Hello!"
```

Коли ми бачимо `say.hello`, нам спадає на думку «функція `hello` з модуля `say`». Але знаючи, що наш `say-hello.lua` повертає таблицю, і повертаючись до розділу про таблиці, ми помічаємо, що в Lua цей вираз означає «індексування таблиці `say` з використанням рядка тексту `hello` як ключа».

Хоча для модуля вважається доброю практикою повертати таблицю, цілком можливо повертати й будь-який інший тип, наприклад функцію.

```lua
--- say-bye.lua
local function bye()
  print('Bye!')
end

return bye
```
