# Вступ

## Оператори порівняння

[Оператори порівняння][comparison-operators] порівнюють два значення одного типу й повертають значення `Bool` (`true` або `false`).
Якщо спробувати порівняти значення різних типів, компілятор видасть помилку.

Стандартні оператори порівняння у Swift такі:

| Оператор | Опис                     | Приклад           |
| -------- | ------------------------ | ----------------- |
| `==`     | дорівнює                 | `1 == 1` (правда) |
| `!=`     | не дорівнює              | `1 != 2` (правда) |
| `<`      | менше                    | `4 < 5`  (правда) |
| `<=`     | менше або дорівнює       | `4 <= 4` (правда) |
| `>`      | більше                   | `3 > 1`  (правда) |
| `>=`     | більше або дорівнює      | `2 >= 2` (правда) |

## Інструкції `if` та `else`

[Умовна конструкція][conditional-statement] виконує код залежно від того, чи обчислюється умова до `true` або `false`.
Найпоширеніша умовна конструкція - це [умовний оператор `if`][if], який виконує блок коду лише тоді, коли його умова дорівнює `true`.
Щоб написати умовний оператор `if`, використовують ключове слово `if`, після якого йде умова, а потім блок коду у фігурних дужках:

```swift
let wheelCount = 4
if wheelCount == 4 {
    print("Your vehicle is a car")
}
// Prints "Your vehicle is a car"
```

Можна поєднати `if` з частиною `else`, щоб виконати альтернативний код, коли умова дорівнює `false`:

```swift
let precipitationInMM = 0.5
if precipitationInMM > 0.5 {
    print("You will need an umbrella")
} else {
    print("You will not need an umbrella")
}
// Prints "You will not need an umbrella"
```

Щоб перевірити кілька умов послідовно, обʼєднують інструкції в ланцюжок за допомогою `else if`.
Інструкція `if` не потребує гілки `else`, але її можна додати, щоб обробити випадки, коли жодна з умов не збігається:

```swift
let favoriteFruit = "Apple"

if favoriteFruit == "Banana" {
    print("Your favorite fruit is a banana")
} else if favoriteFruit == "Orange" {
    print("Your favorite fruit is an orange")
} else if favoriteFruit == "Apple" {
    print("Your favorite fruit is an apple")
} else {
    print("Your favorite fruit is not a banana, orange, or apple")
}
// Prints "Your favorite fruit is an apple"
```

## Вираз `if`

У сучасному Swift інструкції `if` можна також використовувати як вирази, що дають значення.
Кожна гілка дає значення, тож результати легко присвоювати залежно від умови:

```swift
let cpuBits = 32
let architecture = if cpuBits == 64 {
    "x86_64"
} else {
    "x86_32"
}

print(architecture)
// Prints "x86_32"
```

## Тернарний оператор

[Тернарний оператор][ternary-operator] - це коротка форма інструкції `if`-`else`.
Він приймає булевий вираз (англ. Boolean) і два вирази, розділені двокрапкою.
Перший вираз обчислюється, якщо булевий вираз має значення правда, інакше обчислюється другий вираз.
Він має такий вигляд: `Boolean-expression ? expression1 : expression2`.

Тернарний оператор стане в пригоді, коли потрібна коротка форма інструкції `if`-`else`, а вирази короткі:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = showFahrenheit ? temperatureInCelsius * 9 / 5 + 32 : temperatureInCelsius
print(temperature)
// Prints 86
```

Наведений вище приклад - це скорочений запис коду нижче:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = if showFahrenheit {
    temperatureInCelsius * 9 / 5 + 32
} else {
    temperatureInCelsius
}
```
