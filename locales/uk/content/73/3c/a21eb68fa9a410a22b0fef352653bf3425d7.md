# Тести

Вправи можна розвʼязувати в онлайн-редакторі на сайті Exercism.
Або завантажте вправи на свій компʼютер, розвʼяжіть їх локально й потім надішліть на Exercism.
Далі в цьому документі йдеться про локальну роботу.

## Exercism CLI

Щоб завантажувати й надсилати вправи, знадобиться інструмент командного рядка `exercism`.
Інструкції зі встановлення та налаштування шукайте в [документації exercism cli][exercism-cli].

Щоб завантажити вправу, виконайте таку команду:

```bash
exercism download --track 8th --exercise hello-world
```

І перейдіть до каталогу вправи:

```bash
cd /path/to/your/exercism_workspace/8th/hello-world
```

або для Windows:

```cmd
cd \path\to\your\exercism_workspace\8th\hello-world
```

Розташування робочої області Exercism можна отримати за допомогою команди `exercism configure`.

## Локальне тестування

Щоб запустити тести для вправи, потрібно перебувати в каталозі цієї вправи.
Потім запустіть тести такою командою:

```bash
8th -f test.8th
```

## Пропущені тести

Розвʼязати вправу означає домогтися, щоб пройшли всі її тести.
Типово під час запуску тестів виконується лише один тест (перший).
Це зроблено навмисно, щоб можна було зосередитися лише на тому, щоб цей один тест пройшов.
Коли він пройде, можна увімкнути наступний тест, перемістивши рядок `SKIP-REST-OF-TESTS` нижче нього.

### Як скасувати пропуски

Щоб запустити всі тести, зокрема ті, що йдуть після слова `SKIP-REST-OF-TESTS`, можна встановити змінну середовища `RUN_ALL_TESTS` зі значенням `true`.
Один зі способів задати це лише на час запуску тестів такий (macOS і Linux):

```bash
RUN_ALL_TESTS=true 8th -f test.8th
```

## Надішліть своє рішення

Щоб завантажити своє рішення на сайт Exercism за допомогою інструмента exercism:

```bash
exercism submit
```

Зауважимо, що код можна завантажити, навіть якщо він не проходить усі тести.
Це стане в пригоді, якщо ми застрягли й потребуємо допомоги наставника.
