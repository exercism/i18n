# Докладніше

Вирази `switch` поводяться подібно до конструкцій `switch`, про які йдеться в [конструкції `switch`][switch-statements] і [concept:csharp/switch-statements](). Вони підтримують своєрідну таблицю рішень, яка зіставляє вхідні умови з діями або значеннями.

В основі виразу `switch` лежить _зіставлення зі зразками_. У вправі з програмування ми зіставляли значення зі зразками `const`. Тут вхідними даними для `switch` є _вираз діапазону_, який зіставляється зі значеннями const і зі значеннями, які використовують _захисні умови випадків_.

Випадки (їх ще називають _гілками `switch`_) обчислюються в порядку запису, і щойно знайдено збіг, обчислення припиняється достроково, а повʼязане значення повертається.

Випадок `_`, останній у списку, корисний тим, що робить зіставлення вичерпним і дає змогу уникнути можливих помилок під час виконання.

```csharp
double xx = 42d;

string interesting = xx switch
{
    0 => "I suppose zero is interesting",
    3.14 when DateTime.Now.Day == 14 && DateTime.Now.Month == 3 => "Mmm pie!",
    3.14 => "π",
    42 => "a bit of a cliché",
    1729 => "only if you are a pure mathematician",
    _ => "not interesting"
};

// => interesting == "a bit of a cliché"
```

Гілка `switch` вибирається тоді, коли зразок відповідає змінній діапазону, а захисна умова випадку набуває значення правда.

Вирази `switch` також підтримують [зразки типів][pattern-matching] і рекурсивне зіставлення.
