# Вступ

Загалом є два типи циклів:

1. Повторювати, доки не виконається умова.
2. Перебирати елементи колекції.

Обидва можливі в R, хоча перший трапляється частіше.

## `while` і `repeat`

Для задач без наперед відомої кількості повторів R має цикл `while` з умовою та цикл `repeat` без умови (еквівалентний `while (TRUE)`).

Базова форма досить проста:

```R
while (condition) {
  do_something()
}
```

У цьому разі програма повторюватиме цикл, доки `condition` не перестане бути `TRUE`.

Є два способи достроково вийти з циклу:

- `break` перериває цикл, і виконання продовжується з наступного рядка після закривної фігурної дужки `}` циклу.
- `return(x)` зупиняє виконання поточної функції та повертає значення `x` тому, хто її викликав.

Маючи ці можливості, іноді зручно створити «нескінченний» цикл за допомогою `repeat { ... }`, а потім покладатися на те, що всередині тіла циклу знайдеться умова зупинки, яка викличе `break` або `return`.

Ці три варіанти еквівалентні, і всі вони завершуються з `x == 0.4444...`

```R
x <- 12
while (x > 1) {
  x <- x / 3
}

x <- 12
while (TRUE) {
  x <- x/3
  if (x <= 1) break
}

x <- 12
# no boolean clause 
repeat { 
  x <- x/3
  if (x <= 1) break
}
```

## Перебирання вектора

У R це часто не потрібно.
Як зазначалося в інших концепціях, багато функцій працюють з цілими векторами.

Однак явних циклів іноді не уникнути.
Особливо це стосується випадків, коли:

- Тіло циклу має побічні ефекти, як-от виведення на екран чи робота з файлами.
- Цикл триває, доки не буде досягнуто певного критерію, після непередбачуваної кількості ітерацій.

Умова циклу має бути в дужках.
Як і з тілами функцій, для однорядкових тіл циклу фігурні дужки необовʼязкові (але їх часто додають).

```R
words <- c("This", "is", "a", "loop")
for (w in words) { print(w) } # the braces are optional here
#> [1] "This"
#> [1] "is"
#> [1] "a"
#> [1] "loop"
```

Якщо поточна ітерація не задовольняє певну умову, можна одразу перейти до наступної ітерації за допомогою `next`:

```R
for (n in 1:10) {
    if (is_useless(n)) next
     
    # we decided this iteration could be useful
    do_something_slow(n)
}
```

Якщо потрібен числовий індекс, скористаймося `seq_along()`.

```R
v <- LETTERS[1:3]
v
#> [1] "A" "B" "C"

for (i in seq_along(v)) { print(sprintf("%s%i", v[i], i)) }
#> [1] "A1"
#> [1] "B2"
#> [1] "C3"
```

Використовувати `i in 1:length(v)` _не_ рекомендовано, бо це може спричинити проблеми, коли `length(v)` дорівнює нулю.
Діапазон `1:0` еквівалентний `c(1, 0)`, тож тіло циклу виконається і, ймовірно, зазнає невдачі.
Функція `seq_along()` створена, щоб правильно обробити цей випадок.
