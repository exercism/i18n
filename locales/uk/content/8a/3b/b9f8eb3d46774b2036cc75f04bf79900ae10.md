# Кортежі

[Кортеж][tuple] - це скінченний впорядкований список елементів, який не можна змінити.
Кортежі вимагають, щоб кожна позиція мала фіксований тип.
Це, своєю чергою, означає, що компілятор знає, який тип стоїть на кожній позиції.
Типи, які використовуються в кортежі, можуть відрізнятися на різних позиціях, але всі вони повинні бути відомі під час компіляції.

## Створення кортежу

Залежно від того, чи можна визначити типи значень кортежу вже під час компіляції, кортеж можна створити різними способами.
Якщо значення відомі під час компіляції, кортеж можна створити за допомогою синтаксису літерала кортежу, інакше їх потрібно оголосити явно.
Також важливо, щоб типи значень збігалися з типами, указаними в кортежі, і щоб кількість значень збігалася з кількістю вказаних типів.
Ось приклад оголошення через синтаксис літерала кортежу:

```crystal
tuple = {1, "foo", 'c'} # Tuple(Int32, String, Char)
```

Кортеж можна також створити за допомогою класу `Tuple`.

```crystal
tuple = Tuple(Int32, String, Char).new(1, "foo", 'c')
```

Або ж можна явно вказати тип змінної, якій присвоюється кортеж.

```crystal
tuple : Tuple(Int32, String, Char) = {1, "foo", 'c'}
```

Явне зазначення типу кортежу буває корисним, адже воно дає змогу вказати, що позиція має містити обʼєднання типів.
Це означає, що одна позиція може містити значення різних типів.

```crystal
tuple : Tuple(Int32 | String, String, Char) = {1, "foo", 'c'}
```

## Перетворення

### Створення кортежу з масиву

Кортеж можна створити з масиву за допомогою методу `from` класу `Tuple`.
Для цього потрібно вказати тип кортежу.

```crystal
array = [1, "foo", 'c']
tuple = Tuple(Int32, String, Char).from(array)
```

### Перетворення в масив

Кортеж можна перетворити в масив за допомогою методу `to_a`.
Тип елементів отриманого масиву - це обʼєднання типів усіх полів кортежу.

```crystal
tuple = {1, "foo", 'c'}
array = tuple.to_a
array # => [1, "foo", 'c']
```

## Доступ до елементів

Як і в масивах, індексація кортежів починається з нуля: перший елемент має індекс 0.
Однак, на відміну від масивів, тип кожного елемента фіксований і відомий під час компіляції, тому під час індексації кортежу тип елемента залежить від його позиції.
Щоб отримати елемент кортежу, можна скористатися оператором `[]`.

```crystal
array = [1, "foo", 'c']
array[0]         # => 1
typeof(array[0]) # => Int32 | String | Char

tuple = {1, "foo", 'c'}
tuple[0]         # => 1
typeof(tuple[0]) # => Int32
```

Ще одна відмінність від доступу до елементів масиву: якщо індекс указано, компілятор перевіряє, чи він не виходить за межі кортежу.
Це означає, що ми отримаємо помилку під час компіляції, а не під час виконання.

```crystal
tuple = {1, "foo", 'c'}
tuple[3]
# => Error: index out of bounds for Tuple(Int32, String, Char) (3 not in -3..2)
```

Однак, якщо індекс збережено в змінній, компілятор не зможе перевірити під час компіляції, чи не виходить індекс за межі кортежу, і замість цього видасть помилку під час виконання.

## Підкортеж

Отримати підкортеж кортежу можна за допомогою оператора `[]` із діапазоном.
Повертається новий кортеж з елементами із зазначеного діапазону.
Діапазон потрібно вказати під час компіляції, інакше компілятор не зможе визначити типи елементів підкортежу.
Це означає, що діапазон має бути літералом діапазону, а не значенням, присвоєним змінній.

```crystal
tuple = {1, "foo", 'c'}
subtuple = tuple[0..1] # Tuple(Int32, String)

i = 0..1
tuple[i]
# Error: Tuple#[](Range) can only be called with range literals known at compile-time
```

## Коли використовувати кортеж

Кортежі стають у пригоді, коли потрібно згрупувати фіксовану кількість значень, типи яких відомі під час компіляції.
Це тому, що кортежі займають менше памʼяті й працюють швидше за масиви завдяки своїй незмінності.
Ще один варіант використання - повернення кількох значень із методу.
Це особливо зручно, коли значення мають різні типи, адже кожна позиція кортежу може мати власний тип.

Кортежі не варто використовувати, коли потрібна структура даних, яка може збільшуватися чи зменшуватися або яку часто доводиться змінювати.

# Докладніше

[Символи][symbols] - це іменовані ідентифікатори, які можна використати, щоб послатися на значення.
Символи створюються за допомогою літерала символу, тобто шляхом додавання знака `:` перед іменем, наприклад `:foo`.
Їх також можна записати в лапках, наприклад `:"foo"`, що дає змогу, скажімо, використовувати пробіли в імені.

```crystal
:foo           # => :foo
:"foo boo"     # => :"foo boo"
:foo == :"foo" # => true
```

Символи використовуються в мові в багатьох місцях: зокрема як ключі в іменованих кортежах і для позначення назв методів та змінних.

## Символи в Crystal

Символи в Crystal досить помітно відрізняються від символів у Ruby.
У Crystal символ - це різновид константи, тому він задається під час компіляції.
Це означає, що символи не можна створювати динамічно, а в Ruby це можливо.

У Crystal символи представлені значеннями `Int32`, що робить їх дуже ефективними.

## Перетворення

Символи можна перетворити на рядки тексту (англ. string), але не навпаки.
Це тому, що символи створюються під час компіляції, а рядки тексту - під час виконання.

```crystal
:foo.to_s # => "foo"
```
