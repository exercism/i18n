# Докладніше

Умовні конструкції Factor приймають **quotation** як свої гілки: код, записаний у квадратних дужках, `[ ... ]`, який кладеться в стек як значення, а не виконується, доки умовна конструкція не вибере його. (Самі quotation повністю розглянемо в пізнішій вправі.)

Базові три містяться в `kernel`:

```
if      ( ? then-quot else-quot -- )
when    ( ? quot -- )
unless  ( ? quot -- )
```

Два варіанти із зірочкою трактують булеве значення (англ. Boolean) як значення, яке варто використати, коли воно правдиве: канонічна пара «значення або `f`»:

```
if*     ( ? true false -- )    ! truthy: true called WITH value
unless* ( ? false      -- )    ! falsy: false runs and pushes default
```

```factor
: abs   ( x -- y ) dup 0 < [ neg ] [ ] if ;
: shout ( s -- )   dup empty? [ drop ] [ >upper print ] if ;
```

Для більш ніж двох гілок `cond` (у `combinators`) перебирає масив пар `{ predicate body }` і виконує тіло першого предиката, який спрацьовує. Звичний підхід використовує `dup` у кожному предикаті, щоб вхідні дані збереглися, а тіло починається з `drop`, щоб відкинути їх перед тим, як покласти результат:

```factor
{
    { [ dup 0 <  ] [ drop "negative" ] }
    { [ dup 0 =  ] [ drop "zero"     ] }
    [ drop "positive" ]
} cond
```

Завершальний запис без предиката - типова гілка.
