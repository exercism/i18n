# Використайте guard на рівні функції

[comment]: # (Ця помилка виникає, коли рішення використовує guards, але не в клаузулі функції)

Використайте [guards](https://hexdocs.pm/elixir/master/guards.html) у клаузулі функції, щоб `two_fer/1` не виконував код із небінарними вхідними даними.

```elixir
def hello(what) when is_binary(what) do
  "Hello, #{what}!"
end
```

Коли функцію викликають з аргументами, які не відповідають жодній із заданих клаузул, виникає `FunctionClauseError`.

```elixir
hello(123)

# => ** (FunctionClauseError) no function clause matching in hello/1
#
#    The following arguments were given to Foo.hello/1:
#
#    # 1
#    123
```
