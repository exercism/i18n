# Вступ

Ця вправа спирається на цілочисельну арифметику зі вправи [Смачна лазанья Леї][lasagna]. Тут ми працюватимемо з числами з плаваючою комою та обиратимемо правильне слово для ділення.

## Цілі числа та числа з плаваючою комою

Factor розрізняє цілі числа (`1`, `42`, `1_000_000`) і числа з плаваючою комою (`1.0`, `3.14`, `6.02e23`). Якщо змішати ціле число і число з плаваючою комою в одному обчисленні, результат вийде числом з плаваючою комою:

```factor
2 3 + .      ! => 5
2 3.0 + .    ! => 5.0
```

Усередині числа можна ставити підкреслення, щоб групувати цифри, як-от `1_000_000`, і Factor просто їх ігнорує.

## Слова для ділення

У Factor є окремі слова для ділення. Усі вони живуть у словнику [`math`][math].

```
/    ( x y -- x/y )    ! exact: ratio for two integers, float if either is a float
/f   ( x y -- f   )    ! always a float
/i   ( x y -- q   )    ! integer division (truncates toward zero)
mod  ( x y -- r   )    ! remainder
/mod ( x y -- q r )    ! quotient and remainder together
```

```factor
1 2 / .        ! => 1/2     (a proper ratio)
16 3 / .       ! => 5+1/3   (an improper ratio, printed as a mixed numeral)
16 3 /f .      ! => 5.333333333333333
16 3 /i .      ! => 5      (truncated)
16 3 mod .     ! => 1
16 3 /mod .s   ! quotient and remainder in one pass
! => 5
! => 1
16.0 3 / .     ! => 5.333333333333333
```

`/` дає `ratio` (точний раціональний тип у Factor) для двох цілих чисел або `float`, якщо хоч один із вхідних даних є числом з плаваючою комою. `/f` примусово повертає результат як число з плаваючою комою навіть для двох цілих чисел. `/i` завжди відкидає дробову частину в напрямку нуля.

## Перевірки

Предикати для чисел зі словників [`math`][math], [`math.functions`][math.functions] і [`math.primes`][math.primes]:

```
zero?    ( x       -- ? )
even?    ( x       -- ? )
odd?     ( x       -- ? )
prime?   ( x       -- ? )
divisor? ( m n     -- ? )    ! true when n divides m
integer? ( x       -- ? )    ! true for ints (fixnum or bignum)
float?   ( x       -- ? )    ! true for floats
number?  ( x       -- ? )    ! true for any numeric kind
```

```factor
0 zero? .            ! => t
0.0 zero? .          ! => t
3 zero? .            ! => f

4 even? .            ! => t
7 even? .            ! => f
7 odd? .             ! => t

7 prime? .           ! => t
9 prime? .           ! => f

15 5 divisor? .      ! => t   (5 divides 15)
15 4 divisor? .      ! => f
```

## Від числа з плаваючою комою до цілого

`floor`, `ceiling` і `round` зі словника [`math.functions`][math.functions] повертають число з плаваючою комою (`3.0`, а не `3`). Щоб отримати справжнє ціле число, скористаймося ланцюжком `>integer`:

```factor
3.7 floor >integer .       ! => 3
3.2 ceiling >integer .     ! => 4
```

## Степені та абсолютне значення

`sq`, `^` і `abs` (зі словника [`math.functions`][math.functions]) обчислюють квадрати, довільні степені та абсолютні значення:

```
sq  ( x   -- x*x )
^   ( x y -- x^y )
abs ( x   -- |x| )
```

```factor
5 sq .          ! => 25
2 10 ^ .        ! => 1024
2 0.5 ^ .       ! => 1.4142135623730951
-7 abs .        ! => 7
3 abs .         ! => 3
```

## Мінімум і максимум

`min ( x y -- z )` і `max ( x y -- z )` (зі словника [`math.order`][math.order]) повертають менше або більше з двох чисел:

```factor
3 7 min .       ! => 3
3 7 max .       ! => 7
```

Найчастіше це використовують для *обмеження*: притиснути значення до нижньої межі за допомогою `max` (наприклад, `0 max` утримує значення невідʼємним) або до верхньої межі за допомогою `min`.

## Предикати впорядкування

`math.order` також надає `before?`, `after?`, `before=?`, `after=?` для предикатів порівняння, які працюють з будь-яким упорядковуваним типом: числами, рядками тексту (англ. string), символами:

```
before?  ( obj1 obj2 -- ? )   ! obj1 <  obj2
before=? ( obj1 obj2 -- ? )   ! obj1 <= obj2
after?   ( obj1 obj2 -- ? )   ! obj1 >  obj2
after=?  ( obj1 obj2 -- ? )   ! obj1 >= obj2
```

Краще використовувати їх замість `<`/`<=`, коли значення можуть бути рядками тексту: арифметичні оператори не працюють із рядками.
