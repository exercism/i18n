# Тести

Кожна вправа містить тестовий файл.
Запустіть тести за допомогою програми `bats`.

```bash
bats hello_world.bats
```

Якщо під час локального запуску тестів потрібно вивести налагоджувальні дані, дивіться сторінку [Локальне налагодження][debugging].

`bats` потрібно встановити.
Інструкції зі встановлення `bats` для своєї системи шукайте на сторінці [Тестування на треку Bash][tests].

[tests]: https://exercism.org/docs/tracks/bash/tests
[debugging]: https://exercism.org/docs/tracks/bash/debugging

## Довідка щодо функцій assert

У тестах використовуються функції з бібліотеки [bats-assert][bats-assert].
Довідку про різні функції `assert*` можна знайти там.

[bats-assert]: https://github.com/bats-core/bats-assert

## Пропущені тести

Розвʼязати вправу означає домогтися, щоб усі її тести пройшли.
Типово під час запуску тестів виконується лише один тест (перший).
Це зроблено навмисно, щоб ми могли зосередитися лише на тому, щоб цей один тест пройшов.
Коли він пройде, ми можемо увімкнути наступний тест, закоментувавши або видаливши наступну анотацію:

```bash
[[ $BATS_RUN_SKIPPED == true ]] || skip
```

## Перевизначення пропусків

Щоб запустити всі тести, зокрема ті, що мають анотації `skip`, виконайте:

```bash
BATS_RUN_SKIPPED=true bats exercise_name.bats
```

Щоб менше друкувати, зручно скористатися функцією-обгорткою:

```bash
bats() {
    BATS_RUN_SKIPPED=true command bats *.bats
}
```

Тоді для запуску тестів достатньо:

```bash
bats
```
