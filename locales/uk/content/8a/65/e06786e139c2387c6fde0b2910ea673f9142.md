# Про це

Щоб виконувати логіку повторно, можна використовувати цикли. Якщо код у циклі має виконуватися принаймні один раз, можна використати цикл `do`/`while`:

```csharp
int x = 0;

do
{
    x = GetX();
    // do something with x
}
while (x != 0);
```

Його використовують рідше, ніж цикл `while`, але в деяких випадках код із ним має природніший вигляд.
