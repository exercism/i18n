# Використання документації модуля

[comment]: # (Ця помилка виникає, коли в поданому рішенні немає @moduledoc для модуля)

Рекомендуємо мати атрибут [`@moduledoc`](https://hexdocs.pm/elixir/writing-documentation.html#module-attributes), щоб описати призначення модуля.

- У Elixir документація є [повноправною складовою](https://hexdocs.pm/elixir/writing-documentation.html): документацію Elixir створено так, щоб її було легко читати й писати.
- Синтаксис Markdown підтримується всередині атрибутів документації `@moduledoc` і `@doc`
