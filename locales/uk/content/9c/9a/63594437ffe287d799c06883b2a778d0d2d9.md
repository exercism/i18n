# Вказівки

Метеостанція Веллінгтона замінить свою систему ручного запису температури на нову цифрову.
У старій системі обчислення виконували вручну.
У новій системі їх буде автоматизовано.
До цих обчислень належать переведення температури з Цельсія в Фаренгейт і визначення середньої температури.
Нова система має датчики, що записують дані про температуру в градусах Цельсія.

Метеостанція Веллінгтона хоче, щоб ми допомогли їй із новою системою.

## 1. Перевести температуру з Цельсія в Кельвін

На своєму сайті метеостанція має розділ, призначений для дослідників.
Дослідники цікавляться температурою в кельвінах.

Кельвін - це одиниця для вимірювання температури.
Він має ту саму шкалу, що й Цельсій, але з іншою початковою точкою.
Його початкова точка - абсолютний нуль, тобто 0K (кельвін) або -273.15°C (цельсій).

Ось таблиця, що показує переведення між Цельсієм і Кельвіном:

| Цельсій(°C) | Кельвін(K) |
| ----------- | ---------- |
| -273.15     | 0          |
| -100        | 173.15     |
| 0           | 273.15     |
| 100         | 373.15     |

Метеостанція хоче, щоб ми реалізували метод, який переводить температуру з Цельсія в Кельвін.

Реалізуйте метод `Temperature#to_kelvin`, який приймає аргумент `celsius` і повертає температуру в кельвінах, додавши 273.15 до переданого значення `celsius`.

```crystal
Temperature.new.to_kelvin(0)
# => 273.15
```

## 2. Округлити температуру

Датчик температури метеостанції дуже точний.
Він може вимірювати температуру з точністю до 0.0001°C.
Метеостанція хоче показувати температуру, округлену до 1 знака після коми, бо більшість користувачів не цікавиться таким рівнем точності.

Метеостанція хоче, щоб ми реалізували метод, який округлює температуру до 1 знака після коми.

Реалізуйте метод `Temperature#round`, який приймає аргумент `celsius` і повертає температуру, округлену до 1 знака після коми.

```crystal
Temperature.new.round(10.1234)
# => 10.1

Temperature.new.round(10.1567)
# => 10.2
```

## 3. Перевести температуру з Цельсія в Фаренгейт

На своєму сайті метеостанція має розділ, призначений для туристів.
Туристи цікавляться температурою в градусах Фаренгейта.

Фаренгейт - одиниця вимірювання температури.
Він має іншу шкалу, ніж Цельсій.
0°C - це 32°F, а 1 градус Цельсія дорівнює 1.8 градуса Фаренгейта.

Ось таблиця, що показує переведення між Цельсієм і Фаренгейтом:

| Цельсій(°C) | Фаренгейт(°F) |
| ----------- | ------------- |
| -273.15     | -459.8        |
| -100        | -148          |
| 0           | 32            |
| 100         | 212           |

Метеостанція хоче, щоб ми реалізували метод, який переводить температуру з Цельсія в Фаренгейт.

Реалізуйте метод `Temperature#to_fahrenheit`, який приймає аргумент `celsius` і повертає температуру в градусах Фаренгейта як ціле число.

```crystal
Temperature.new.to_fahrenheit(10)
# => 50
```

## 4. Дізнатися кількість відсутніх датчиків

Під час встановлення датчиків температури ремонтники помітили, що деяких датчиків не вистачає.
Кожен блок вимірювання температури потребує чотирьох датчиків температури.
Ремонтна бригада порахувала, скільки датчиків у неї є, але їй потрібно було дізнатися, скільки їх не вистачає.
Вони хотіли б, щоб ми допомогли порахувати, скільки датчиків потрібно купити, щоб зібрати ще один повний блок вимірювання температури.

Реалізуйте метод `Temperature#number_missing_sensors`, який приймає аргумент `number_of_sensors` і повертає кількість відсутніх датчиків.

```crystal
Temperature.new.number_missing_sensors(10)
# => 2
```
