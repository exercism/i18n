# Вступ

Визначення типу створює новий іменований тип, відмінний від будь-якого іншого типу, навіть якщо він має такий самий базовий тип.

## Визначення типів

Визначення типу починається з ключового слова `type`, за яким ідуть назва нового типу та його базовий тип:

```go
type File []bool
```

Тут `File` позначає одну вертикаль на шахівниці, яку зазвичай позначають літерами від A до H.
Кожна клітинка цієї вертикалі представлена булевим значенням (англ. Boolean), яке позначає, зайнята вона чи ні.
Тепер, коли `File` визначено, ми можемо використовувати його в інших визначеннях:

```go
type Chessboard map[string]File

board := Chessboard{
    "A": File{true, false, true},
    "B": File{false, true, false},
}
```

`Chessboard` зіставляє ідентифікатори вертикалей зі значеннями `File`.
Кожен `File` - це зріз булевих значень, який представляє клітинки однієї шахової вертикалі.
Без цих визначень типів `board` був би `map[string][]bool`, і це ускладнило б розуміння того, що саме ми представляємо.
