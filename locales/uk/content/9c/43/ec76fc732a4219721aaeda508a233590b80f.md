# Вступ

Масиви є основним типом послідовностей фіксованої довжини в Factor. Їх записують як `{ … }`: елементи можна змінювати, а довжину - ні. Словники `arrays` і `sequences` разом дають невеликі конструктори, які беруть значення зі стека, а також повсякденні операції для зʼєднання, обертання та пошуку елементів.

```factor
USING: arrays sequences ;

42 1array .                ! => { 42 }
"a" "b" "c" 3array .       ! => { "a" "b" "c" }
{ { 1 2 } { 3 4 } } concat .   ! => { 1 2 3 4 }
{ 1 2 3 } reverse .            ! => { 3 2 1 }
```

[arrays]: https://docs.factorcode.org/content/vocab-arrays.html
[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
