# Вступ

## Масиви

У Java масиви дають змогу зберігати кілька значень одного типу в одній структурі.
На відміну від інших структур даних, масиви після створення мають фіксований розмір.
Елементи можна присвоювати масиву або отримувати з нього за допомогою індексу.
У масивах Java індексація починається з нуля: індекс першого елемента дорівнює 0, індекс другого - 1, і так далі.

Ось стандартний синтаксис ініціалізації масиву:

```java
type[] variableName = new type[size];
```

`type` позначає тип елементів масиву, який може бути примітивним типом (наприклад, `int`) або класом (наприклад, `String`).

`size` задає кількість елементів, які може вмістити цей масив (її не можна буде змінити пізніше).
Після створення масиву елементи ініціалізуються своїми типовими значеннями (зазвичай `0`, `false` або `null`).

```java
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];
```

Масиви також можна визначати за допомогою скороченого запису, який дає змогу одночасно створити масив і встановити його значення:

```java
// Two equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = { 4, 9, 7 };
```

Оскільки компілятор тепер може визначити, скільки елементів буде в масиві, довжину можна не вказувати.

Присвоювати елементи масиву й звертатися до них можна за допомогою індексної нотації в квадратних дужках:

```java
// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index and assign to the int element
int secondElement = twoInts[1];
```

Спроба звернутися до індексу, який виходить за межі допустимих індексів масиву, призводить до `IndexOutOfBoundsException`.

Масивами можна керувати, або викликаючи методи чи властивості екземпляра масиву, або використовуючи статичні методи, визначені в класі `Arrays` (зазвичай вони використовуються лише в узагальненому коді).
Властивість `length` містить довжину масиву.
До неї можна звернутися так:

```java
int arrayLength = someArray.length;
```

Java також надає корисний допоміжний клас [`java.util.Arrays`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/Arrays.html) із багатьма корисними методами для роботи з масивами (наприклад, `Arrays.equals`).

Java також підтримує [багатовимірні масиви](https://www.programiz.com/java-programming/multidimensional-array), як-от `int[][] arr = new int[3][4];`, що можуть бути дуже корисними.

Те, що масив також є _колекцією_, означає, що, крім доступу до значень за індексом, можна перебирати _всі_ його значення за допомогою циклу `for-each`:

```java
char[] vowels = { 'a', 'e', 'i', 'o', 'u' };

for(char vowel: vowels) {
    // Output the vowel
    System.out.print(vowel);
}

// => aeiou
```

Якщо потрібен більший контроль над тим, які значення перебирати, можна використати цикл `for`:

```java
char[] vowels = { 'a', 'e', 'i', 'o', 'u' };

for (int i = 0; i < 3; i++) {
    // Output the vowel
    System.out.print(vowels[i]);
}

// => aei
```
