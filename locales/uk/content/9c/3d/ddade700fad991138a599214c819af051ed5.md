# Вступ

У Go кожна змінна має значення.
Якщо оголосити змінну, не присвоївши їй значення, вона отримає нульове значення для свого типу.

Базові типи, зокрема `bool`, числові типи та `string`, мають фіксоване нульове значення:

| Тип                    | Нульове значення |
| ---------------------- | ---------------- |
| bool                   | `false`          |
| int, int8, int64, тощо | `0`              |
| float32, float64       | `0`              |
| complex64, complex128  | `0+0i`           |
| string                 | `""`             |

Вказівники, функції, інтерфейси, зрізи, канали й мапи мають нульове значення `nil`.

Масиви та структури ніколи не дорівнюють `nil`, бо містять дані безпосередньо, а не посилання на них.
Кожен елемент масиву й кожне поле структури ініціалізується нульовим значенням власного типу.
Наприклад, `var a [3]int` створює масив `[0, 0, 0]`.

## Оголошення нульових значень

Для оголошення використовуйте `var`:

```go
var myBool bool   // false
var mySlice []int // nil
```

Для структур використовуйте складений літерал `T{}`:

```go
type Person struct {
    Name string
    Age  int
}

myPerson := Person{} // Person{Name: "", Age: 0}
```
