# Словники та множини

Масив зберігає значення в пронумерованих позиціях. Іноді корисна мітка не є числом.

## Словники

**Словник** зіставляє кожен **ключ** зі **значенням**. Знайдімо потрібне за ключем, і словник віддасть те, що під ним збережено.

`FMAP{K,T}` задає словник, який зіставляє ключі типу `K` зі значеннями типу `T`. Довідник, який зіставляє назву тварини з місцем її проживання, має тип `FMAP{STR,STR}`.

```sather
   guide ::= #FMAP{STR,STR};
   guide := guide.insert("emu", "grassland");
   guide.get("emu")               -- "grassland"
```

## Завжди присвоювати відповідь назад

Погляньмо ще раз на той середній рядок. `insert` повертає словник, у якому вже є ця додаткова пара, і цю відповідь потрібно зберегти:

```sather
   guide := guide.insert("emu", "grassland");     -- yes
   guide.insert("emu", "grassland");              -- no: the answer is lost
```

Це те саме правило, що й для `FSTR`, і з тієї самої причини. Відповіддю зазвичай є той самий словник, який ми передали, лише змінений на місці; іноді ж, коли у словнику закінчилося місце, це більший словник. Оскільки ми не можемо сказати, який саме випадок, **використовуймо відповідь і більше не користуймося старим іменем.** Імʼя, що залишилося від часів до `insert`, може бути застарілим або взагалі не описувати придатний для використання словник.

Це також означає, що словник, переданий у підпрограму, від неї не захищений. Якщо оригінал повинен зберегтися, звернімося до `copy` на сторінці концепції.

## Чи є воно там?

`has_ind` перевіряє, чи є ключ у словнику. Назва скорочена від «has index»: індексом ці словники називають ключ.

```sather
   guide.has_ind("emu")           -- true
   guide.has_ind("moa")           -- false
```

Запит ключа, якого немає, **не** спричиняє помилки. `get` повертає порожнє значення для цього типу: нуль для `INT` і void для `STR`, що згодом і в іншому місці обернеться помилкою. Тож спершу перевірмо, а потім діставаймо:

```sather
   if guide.has_ind(animal) then
      return guide.get(animal);
   else
      return "Unknown";
   end;
```

## Множини

**Множина** зберігає значення без повторів і без порядку. `FSET{T}` задає множину значень типу `T`.

```sather
   seen ::= #FSET{STR};
   seen := seen.insert("emu");
   seen := seen.insert("emu");    -- already there; nothing changes
   seen.size                      -- 1
   seen.has("emu")                -- true
```

Якщо вставити щось двічі, залишиться одна копія. Ось для чого й потрібна множина: збирати щось, забуваючи, скільки разів кожне траплялося.

`insert` для множини повертає множину, яку відтоді й використовуємо, точнісінько як і для словника, тож присвоюймо її назад щоразу.

## Скільки

`.size` працює і для того, і для того: показує, скільки пар містить словник і скільки значень у множині.
