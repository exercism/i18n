# Про це

## Повернення кількох значень

Функції Swift можуть [повертати кілька значень][multiple-return-values], якщо створити кортеж із цих різних значень і повернути його.

```swift
func reverseAndLength(_ str: String) -> (reverse: String, length: Int) {
  return (reverse: str.reverse, length: str.count)
}

reverseAndLength("Hello")
// => (reverse: "olleH", length: 5)
```

## Опускання `return`

```swift
func reverseAndLength(_ str: String) -> (reverse: String, length: Int) {
  (reverse: str.reverse, length: str.count)
}
```

Якщо все тіло функції складається з одного виразу, [ключове слово `return` можна опустити][implicit-returns].

Зауважмо, що це стосується всіх типів повернення, а не лише повернення кількох значень.

[multiple-return-values]: https://docs.swift.org/swift-book/LanguageGuide/Functions.html#ID164
[implicit-returns]: https://docs.swift.org/swift-book/LanguageGuide/Functions.html#ID607
