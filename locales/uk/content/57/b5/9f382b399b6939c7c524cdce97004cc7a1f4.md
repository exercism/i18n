# Інструкції

Борис дуже захоплюється модельними залізницями і вирішив поділитися своєю пристрастю зі світом, започаткувавши розсилку. Він почне з того, що надішле перший випуск розсилки друзям і знайомим, які поділяють це захоплення. Їхні адреси електронної пошти зберігаються в текстовому файлі.

Підказка: скористайтеся модулем [simplifile](https://hexdocs.pm/simplifile/simplifile.html) для операцій із файлами.

## 1. Зчитуємо адреси електронної пошти з файлу

Реалізуйте функцію `read_emails`. Вона приймає рядок тексту (англ. string) зі шляхом до текстового файлу, який містить адреси електронної пошти, розділені символами нового рядка, і повертає масив адрес електронної пошти з цього файлу.

```gleam
read_emails("/home/my_user/documents/model_train_friends_emails.txt")
// -> Ok(["rick@example.com", "choochoo42@example.com", "anna@example.com"])
```

## 2. Створюємо файл журналу для запису

Надсилання листа може не вдатися з багатьох непередбачуваних причин, як-от одруківка в адресі електронної пошти або тимчасові проблеми з мережею. Щоб мати змогу повторно надіслати листи всім друзям і не надсилати дублікатів, потрібно записувати до журналу адреси, які вже отримали лист. Для цього знадобиться файл журналу.

Реалізуйте функцію `create_log_file`. Вона приймає шлях до файлу і створює новий порожній файл за цим шляхом.

```gleam
create_log_file("/home/my_user/documents/newsletter_issue1_log.txt")
// -> Ok(Nil)
```

## 3. Записуємо надісланий лист до журналу

Реалізуйте функцію `log_sent_email`. Вона приймає шлях до файлу журналу та рядок тексту з адресою електронної пошти. Вона записує адресу до файлу, а за нею символ нового рядка.

```gleam
log_sent_email(
  "/home/my_user/documents/newsletter_issue1_log.txt",
  "joe@example.com",
)
// -> Ok(Nil)
```

## 4. Надсилаємо розсилку

Тепер, коли всі складники процесу надсилання листів уже є, потрібно поєднати їх в одну функцію.

Реалізуйте функцію `send_newsletter`. Вона приймає шлях до файлу з адресами електронної пошти, шлях до файлу журналу та анонімну функцію, яка надсилає лист на задану адресу.

Вона має зчитати всі адреси електронної пошти із заданого файлу і спробувати надіслати лист на кожну з них. Якщо анонімна функція, яка надсилає лист, повертає значення `Ok`, запишіть адресу електронної пошти до файлу журналу. Обовʼязково зробіть це одразу після надсилання листа.

```gleam
send_newsletter(
  "model_train_friends_emails.txt",
  "newsletter_issue1_log.txt",
  send_email,
)
// -> Ok(Nil)
```
