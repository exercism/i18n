# Інструкції

Еліс, майбутня чарівниця, продовжує своє навчання.
У неї є колода карт, з якою вона хоче працювати.

Щоб було простіше, вона зазвичай починає лише з картами з номерами від 2 до 10, хоча деякі з трюків можуть залучати додаткові (фігурні) карти.

<!-- prettier-ignore-start -->
~~~~exercism/note
Існує **багато** способів перетасувати карти, але щоб підтримувати ілюзію магії, важливо, щоб *жоден окремий метод не використовувався*, наприклад, Еліс не використовує `splice`, `slice`, `shift`, `unshift`, `push`, `at`.
Так само ніколи не можна використовувати доступ до масиву `array[index]` і доступ до обʼєкта (`object[key]` та `object.key`).
~~~~
<!-- prettier-ignore-end -->

Допоможімо Еліс удосконалити її магію?

<!-- prettier-ignore-start -->
~~~~exercism/advanced
Кожну функцію можна реалізувати, використовуючи параметри та тіло функції з єдиним `return expression`.
~~~~

## 1. Візьміть першу карту

Еліс покличе першу карту з колоди, не використовуючи `array[index]`, `.at(index)` чи `.shift()`.
Неначе справжня магія.

```javascript
const deck = [5, 9, 7, 1, 8];

getFirstCard(deck);
// => 5
```

## 2. Візьміть другу карту

Еліс демонструє спритність рук і кличе другу карту з колоди, не використовуючи `array[index]` чи `.shift()`.

```javascript
const deck = [3, 2, 10, 6, 7];

getSecondCard(deck);
// => 2
```

## 3. Поміняйте дві карти місцями

Еліс змусить дві карти в колоді помінятися місцями.
Їй не потрібно викликати жодної функції.

```javascript
const deck = [10, 7];

swapTwoCards(deck);
// => [7, 10]
```

## 4. Пересуньте три карти

Щоб знову продемонструвати спритність рук, Еліс бере три карти й швидко переставляє верхню карту в кінець, роблячи середню карту першою, а колишню нижню карту - середньою.
Їй не потрібно викликати жодної функції.

```javascript
const deck = [2, 6, 10];

shiftThreeCardsAround(deck);
// => [6, 10, 2]
```

## 5. Виберіть названу купку

Еліс розділить колоду на дві купки.
Потім вона просить глядача вибрати одну з двох купок, яку ми назвемо `chosen`.
Купка `disregarded` більше не має значення, і Еліс змушує її зникнути.
Їй не потрібно викликати жодної функції.

```javascript
const deck = [5, 4, 7, 10];
const chosen = [5, 4];
const disregarded = [7, 10];

pickNamedPile({ chosen, disregarded });
// => [5, 4]
```

## 5. Поміняйте вибрану купку місцями

На жаль, глядач постійно вибирає «не ту» купку, але завдяки спритній швидкій магії Еліс перейменовує купку `chosen` на `disregarded`, а купку `disregarded` - на купку `chosen`.
Їй не потрібно викликати жодної функції.

```javascript
const deck = [5, 4, 7, 10];
const chosen = [5, 4];
const disregarded = [7, 10];

swapNamedPile({ chosen, disregarded });
// => { chosen: [7, 10], disregarded: [5, 4] }
```
