# Доповнення до інструкцій

## Формат виводу

Виведіть ромб як рядок тексту (англ. string) із завершальним нульовим символом, додавши символ нового рядка в кінці кожного рядка ромба.

Приклад виводу: `"  A  \n B B \nC   C\n B B \n  A  \n"`

## Регістри

| Регістр | Використання        | Тип     | Опис                          |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | вхідні дані        | байт    | літера                        |
| `$a1`    | вхідні/вихідні дані | адреса | рядок тексту результату із завершальним нульовим символом |
| `$t0-9`  | тимчасовий    | будь-який     | для тимчасового зберігання         |
