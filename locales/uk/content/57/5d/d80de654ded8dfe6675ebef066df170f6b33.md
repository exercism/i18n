# Вступ

У Rust будь-який тип, що реалізує трейт [`Iterator`](https://doc.rust-lang.org/stable/std/iter/trait.Iterator.html), можна розглядати як ітератор.
Вбудовані в Rust [`collections`](https://doc.rust-lang.org/std/collections/index.html) можна перетворити на ітератори за допомогою методів `iter`, `iter_mut` та `into_iter`.
Ітератори мають широкий набір [потужних методів](https://doc.rust-lang.org/stable/std/iter/trait.Iterator.html#provided-methods), як-от `collect`, `map`, `filter` і `fold`, щоб ми могли виконувати операції зі своїми даними.

```rust
use std::collections::HashMap;

let v = vec![0, 1, 2];

let mut iter = v.iter();

// Call next() to return the next value
assert_eq!(Some(&0), iter.next());
assert_eq!(Some(&1), iter.next());
assert_eq!(Some(&2), iter.next());
// Ahen None once it's over
assert_eq!(None, iter.next());

// Loop over iterators with built-in methods, such as `map` and `collect`
let w: HashMap<_, _> = v.into_iter().map(|x| (x, x + 1)).collect();
println!("{w:?}");
// => {1: 2, 0: 1, 2: 3}
```
