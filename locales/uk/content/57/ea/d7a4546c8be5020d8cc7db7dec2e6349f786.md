# Вступ

`OpenStruct` дає змогу легко створити обʼєкт із `Hash`. Замість того щоб звертатися до значень за ключами `Hash`, `OpenStruct` дає нам змогу читати й присвоювати значення методами.


```ruby
attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

Ще одна перевага цього підходу в тому, що ми можемо скористатися скороченням, коли використовуємо синтаксис блоку.
Коли блок викликає лише один метод, його можна замінити на `&:`, після якого стоїть назва методу.
Наприклад, ці два рядки коду рівнозначні:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```

## Стандартна бібліотека

Усі класи, які ми бачили в попередніх вправах, належали до основної бібліотеки Ruby.

`OpenStruct` належить до стандартної бібліотеки Ruby (її часто скорочують до «stdlib»), яка містить класи для роботи з датами, json і мережами.
Вона також містить корисну функціональність, яка спрощує роботу з нашим кодом.

Коли ми маємо справу з класами не з основної бібліотеки (власний код в інших файлах, класи зі stdlib або зовнішні залежності), їх потрібно імпортувати методом `require`, перш ніж використовувати.
Наприклад:

```ruby
require 'ostruct'

person = OpenStruct.new(name: "Jeremy Walker")
# ...
```
