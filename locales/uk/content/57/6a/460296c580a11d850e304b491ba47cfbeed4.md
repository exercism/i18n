# Інструкції

У цій вправі ми працюватимемо з ощадними рахунками.
Щороку баланс ощадного рахунку оновлюється залежно від його процентної ставки.
Процентна ставка, яку надає банк, залежить від суми грошей на рахунку (його балансу):

- 3.213% для балансу, меншого за `0` доларів (баланс стає ще відʼємнішим).
- 0.5% для балансу, більшого або рівного `0` доларів і меншого за `1000` доларів.
- 1.621% для балансу, більшого або рівного `1000` доларів і меншого за `5000` доларів.
- 2.475% для балансу, більшого або рівного `5000` доларів.

На нас чекають чотири завдання, кожне з яких стосуватиметься балансу та його процентної ставки.

## 1. Обчисліть процентну ставку

Реалізуйте функцію `interest_rate`, щоб обчислити процентну ставку для вказаного балансу:

```cpp
interest_rate(200.75);
// => 0.5
```

## 2. Обчисліть проценти

Реалізуйте функцію `yearly_interest`, щоб обчислити проценти для вказаного балансу:

```cpp
yearly_interest(200.75):
// => 1.003750
```

## 3. Обчисліть річне оновлення балансу

Реалізуйте функцію `annual_balance_update`, щоб обчислити річне оновлення балансу з урахуванням процентної ставки:

```cpp
annual_balance_update(200.75);
// => 201.75375
```

## 4. Обчисліть кількість років до досягнення бажаного балансу

Реалізуйте функцію `years_until_desired_balance`, щоб обчислити мінімальну кількість років, потрібних для досягнення бажаного балансу, з урахуванням того, що щороку до балансу додаються проценти.
Це означає, що баланс після першого року дорівнює початковому балансу плюс проценти за початковий баланс.
Баланс після другого року дорівнює балансу після першого року плюс проценти за баланс після першого року.
І так далі, доки баланс за поточний рік не стане більшим або рівним цільовому балансу.

```cpp
double balance {200.75};
double targetBalance {214.88};
years_until_desired_balance(balance, targetBalance)
// => 14
```

Зауважте, що повернене значення має тип `int`.
