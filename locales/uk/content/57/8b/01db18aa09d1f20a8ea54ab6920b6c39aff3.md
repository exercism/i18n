# Інструкції

Ламонт - прибулець із Ліспу, який хоче написати власну відеогру. Одне із завдань, у якому знадобиться наша допомога, - ведення списку рекордів.

## 1. Створення таблиці рекордів

Визначте функцію `make-high-score-table`, яка не приймає жодних аргументів, а повертає нову порожню хеш-таблицю:

```lisp
(make-high-score-table) ; => #<HASH-TABLE :TEST EQL :COUNT 0 {1005A90103}>
```

## 2. Додавання гравця до таблиці

Щоб додати гравця до таблиці, визначте функцію `add-player`, яка приймає два аргументи:
- таблицю рекордів
- імʼя гравця як ключове слово

Встановіть початковий рахунок гравця рівним нулю.

```lisp
(add-player hash-table :louis) ; => 0
(add-player hash-table :lilly) ; => 0
```

## 3. Встановлення рахунку гравця

Щоб задати рахунок гравця, визначте функцію `set-score`, яка приймає три аргументи:
- таблицю рекордів
- імʼя гравця як ключове слово
- рахунок гравця як ціле число

```lisp
(set-score hash-table :louis 1234) ; => 1234
```

## 4. Отримання рахунку з таблиці

Щоб отримати рахунок гравця з таблиці, визначте функцію `get-score`, яка приймає два аргументи:
- таблицю рекордів
- імʼя гравця як ключове слово

Ця функція повинна повертати рахунок, збережений для гравця.
Якщо для цього гравця рахунок не збережено або цього гравця ще немає в таблиці, вона повинна повертати `0`.

```lisp
(get-score hash-table :louis)                         ; => 1234
(get-score hash-table :lilly)                         ; => 0
(get-score hash-table :not-a-character-in-this-story) ; => 0
```

## 5. Видалення гравця з таблиці

Щоб видалити гравця з таблиці рекордів, визначте функцію `remove-player`, яка приймає два аргументи:
- таблицю рекордів
- імʼя гравця як ключове слово

Ця функція повинна коректно обробляти випадки, коли гравця ще не додано до таблиці.
Звісно, якщо після видалення гравця ми запитаємо його рахунок із таблиці, він дорівнюватиме нулю.

```lisp
(set-score hash-table :louis 1234)           ; => 1234
(remove-player hash-table :louis)            ; => T
(get-score hash-table :louis)                ; => 0

(remove-player hash-table :not-in-the-table) ; => NIL
```
