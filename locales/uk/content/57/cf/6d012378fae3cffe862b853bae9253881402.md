# Встановлення Java

Крім Exercism CLI та улюбленого текстового редактора, для практики з вправами Exercism мовою Java потрібен **Java Development Kit** (JDK). JDK містить і середовище виконання Java, _і_ інструменти розробки (насамперед компілятор Java).

Нині існує багато варіантів JDK, деякі з них мають відкритий код. Тут, в Exercism, ми радимо використовувати [Eclipse Temurin від Adoptium][adoptium].

## Підтримувані версії Java

Трек Java в Exercism підтримує Java 25 LTS і раніші версії.

## Встановлення Eclipse Temurin

Щоб встановити Eclipse Temurin у своїй системі, звернімося до їхніх чудових [інструкцій зі встановлення][adoptium-installation-guide]. Там ми знайдемо вказівки, як встановити JDK за допомогою улюбленого менеджера пакетів, а також посилання на інсталятори для всіх основних операційних систем.

## IDE для Java

Для Java є багато безкоштовних IDE. Ось кілька популярних варіантів:

- [IntelliJ IDEA Community Edition][intellij-idea]
- [Eclipse][eclipse]
- [Visual Studio Code з розширенням Java][vscode-java]
