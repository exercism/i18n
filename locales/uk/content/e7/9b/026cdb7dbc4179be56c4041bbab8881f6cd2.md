# Про це

Атрибут `Flags` дає змогу подати значення, визначені в розрізнюваному обʼєднанні, як бітові позиції (тобто прапорці).
Як прапорці, такі значення можна поєднувати, завдяки чому кілька булевих умов можна подати в одному значенні.

```fsharp
[<Flags>]
type PhoneFeatures =
| Call = 1
| Text = 2
```

```fsharp
[<Flags>]
type PhoneFeaturesBinary =
| Call = 0b00000001
| Text = 0b00000010
```

Установити прапорець можна побітовим оператором АБО (`|||`); скинути прапорець можна поєднанням побітового оператора І (`&&&`) та побітового оператора заперечення (`~~~`).
Стан прапорця можна перевірити побітовим оператором І, а також методом HasFlag().

```fsharp
let features = PhoneFeatures.Call

// Set the Text flag
let moreFeatures = features ||| PhoneFeatures.Text

moreFeatures.HasFlag(PhoneFeatures.Call) // => true
moreFeatures.HasFlag(PhoneFeatures.Text) // => true

// Unset the Call flag
let lessFeatures = features &&& ~~~PhoneFeatures.Call

lessFeatures.HasFlag(PhoneFeatures.Call) // => false
lessFeatures.HasFlag(PhoneFeatures.Text) // => true
```

Повний перелік побітових операторів, доступних у мові F#, наведено в [Переліку побітових операторів][bitwise-operators].
