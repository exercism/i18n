# Підказки

## 1. Визначте очікуваний час запікання в хвилинах

- Оголосіть [константу][constants], яка має містити значення [`number`][numbers], вказане в рецепті.
- Експортуйте константу за допомогою [`export`][export].

## 2. Обчисліть час запікання, що залишився, у хвилинах

- [Явно поверніть число][return] з функції.
- Скористайтеся [математичним оператором для віднімання][operators], щоб відняти значення.

## 3. Обчисліть час підготовки в хвилинах

- [Явно поверніть число][return] з функції.
- Скористайтеся [математичним оператором для множення][operators], щоб перемножити значення.
- Скористайтеся додатковою константою для часу в хвилинах на один шар.

## 4. Обчисліть загальний час роботи в хвилинах

- [Явно поверніть число][return] з функції.
- [Викличте][invocation] один з інших методів, реалізованих раніше.
- Скористайтеся [математичним оператором для додавання][operators], щоб додати значення.
