# Вступ

## Зіставлення зі зразками-літералами

Хоча вирази `if/else` дають змогу виконувати умовну логіку, у Haskell є потужніший спосіб робити це: [зіставлення зі зразком][pattern-matching].
Зі зіставленням зі зразком значення можна перевірити на відповідність одному чи кільком _зразкам_.
Прикладом такого зразка є _константний зразок_, який зіставляє значення з константою (наприклад, `1` чи `"hello"`).

Визначаючи функції, для різних зразків можна задати окремі тіла функції.
Це дає чистий код, простий і зрозумілий.
Зіставляти зі зразком можна будь-який тип даних: числа, символи, масиви, кортежі тощо.

Наприклад, тривіальну функцію, яка бере ціле число (`Int`) і робить його _на 1_ ближчим до _0_, можна записати так:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero 1 = 0
```

Зіставлення зі зразком по-справжньому розкривається в поєднанні з іншими зразками, наприклад зі _зразком-змінною_:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero n = n - 1
```

У наведеному прикладі всі вхідні дані, крім _0_, обробляються однаково, і для чисел, менших за нуль, результат буде хибним.
Це можна розвʼязати за допомогою умовних зразків, відомих як _охоронні вирази_, які записують символом `|`:

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
```

У наведених прикладах не всі можливі вхідні дані мають відповідний зразок.
Компілятор це виявить і видасть попередження.
Це дуже корисна властивість Haskell: вона допомагає переконатися, що всі можливі шляхи покрито, і уникнути помилок часу виконання.
Це називають _вичерпною перевіркою_.
Щоб позбутися попередження, треба обробити всі випадки.
Усередині _охоронних виразів_ можна використати вираз `otherwise` як синтаксичний цукор для `True`, щоб перехопити всі решта зразків.

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
    | otherwise = 0
```

Зіставлення зі зразком перевіряє значення на відповідність кожному зразку згори донизу, доки не знайде відповідний зразок і не виконає логіку, повʼязану з ним.
**Порядок зразків має значення!**
