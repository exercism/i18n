# Вказівки

Ми працюємо над реалізацією рольової гри.
Персонажа гравця представлено так:

```rust
pub struct Player {
    health: u32,
    mana: Option<u32>,
    level: u32,
}
```

Гравці в цій грі мають досягти 10 рівня, перш ніж відкриють запас мани, який можна використовувати для чаклування.
До цього моменту мана гравця дорівнює `Option::None`.

Ми працюємо над двома частинами функціональності цієї гри: механікою відродження та механікою чаклування.

Метод `revive` має перевірити, що гравець справді мертвий (його здоровʼя досягло 0), і якщо це так, метод має повернути новий екземпляр Player зі здоровʼям 100.
Метод `revive` має зберегти рівень гравця.
Якщо рівень гравця 10 або вище, його слід відродити зі 100 мани.
Якщо рівень гравця нижче 10, його мана має бути `Option::None`.

```rust
let dead_player = Player { health: 0, mana: Option::None, level: 2 };
dead_player.revive()
// Returns Player { health: 100, mana: Option::None, level: 2 }
```

Якщо метод `revive` викликати для гравця, здоровʼя якого 1 або більше, то метод має повернути `Option::None`.

```rust
let alive_player = Player { health: 1, mana: Option::Some(15), level: 11 };
alive_player.revive()
// Returns Option::None
```

Метод `cast_spell` приймає змінне посилання на Player, а також параметр `mana_cost`, який указує, скільки мани коштує заклинання.
Він повертає кількість шкоди, яку завдає застосоване заклинання.

- Якщо гравець не має доступу до запасу мани, спроба застосувати заклинання має зменшити його здоровʼя на вартість заклинання в мани.
  Повернена шкода має дорівнювати 0.

  ```rust
  let not_a_wizard_yet = Player { health: 79, mana: Option::None, level: 9 };
  assert_eq!(not_a_wizard_yet.cast_spell(5), 0)
  assert_eq!(not_a_wizard_yet.health, 74);
  assert_eq!(not_a_wizard_yet.mana, Option::None);
  ```

- Якщо гравець має запас мани, але мани недостатньо, метод не повинен впливати на запас.
Повернена шкода має дорівнювати 0.

  ```rust
  let low_mana_wizard = Player { health: 93, mana: Option::Some(3), level: 12 };
  assert_eq!(low_mana_wizard.cast_spell(10), 0);
  assert_eq!(low_mana_wizard.health, 93);
  assert_eq!(low_mana_wizard.mana, Option::Some(3));
  ```

- В іншому разі заклинання застосовується успішно.
  `mana_cost` має бути віднято від запасу мани гравця.
  Повернена шкода має дорівнювати подвоєній вартості заклинання в мани.

  ```rust
  let wizard = Player { health: 123, mana: Option::Some(30), level: 18 };
  assert_eq!(wizard.cast_spell(10), 20);
  assert_eq!(wizard.health, 123);
  assert_eq!(wizard.mana, Option::Some(20));
  ```
