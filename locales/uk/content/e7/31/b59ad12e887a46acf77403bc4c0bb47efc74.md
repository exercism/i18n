# Підказки

`i32` має ширину чотири байти.

«Екземпляр памʼяті... містить вектор байтів. Довжина вектора завжди кратна розміру сторінки WebAssembly, який визначено як константа 65536»

[WebAssembly Specification: Memory Instances](https://webassembly.github.io/spec/core/exec/runtime.html#page-size)

«Інструкція `memory.size` повертає поточний розмір памʼяті. Інструкція `memory.grow` збільшує памʼять на задану дельту і повертає попередній розмір, або -1, якщо не вдається виділити достатньо памʼяті. Обидві інструкції працюють в одиницях розміру сторінки.»

[WebAssembly Specification: Memory Instructions](https://webassembly.github.io/spec/core/syntax/instructions.html#syntax-instr-memory)

Додаткові посилання:

- [memory.size у MDN](https://developer.mozilla.org/en-US/docs/WebAssembly/Reference/Memory/Size)
- [memory.grow у MDN](https://developer.mozilla.org/en-US/docs/WebAssembly/Reference/Memory/Grow)
