# Інструкції

У цій вправі ми напишемо ще трохи коду, який допоможе приготувати чудову лазанью з нашої улюбленої кулінарної книги.

На нас чекають пʼять завдань, і всі вони повʼязані з часом, витраченим на приготування лазаньї.

## 1. Дозвольте змінювати очікуваний час у печі

Ми хочемо написати покращену функцію `remainingMinutesInOven`, яка приймає як параметр кількість хвилин, що лазанья вже провела в печі, і повертає, скільки хвилин їй ще залишилося там побути, виходячи з очікуваного часу в печі в хвилинах із попереднього завдання.
Раніше ми покладалися на константу `expectedMinutesInOven`, яка була визначена поза функцією `remainingMinutesInOven`.
Це було і трохи заплутано на наш смак, і недостатньо гнучко, бо не давало змоги змінити очікуваний час у печі.

Щоб навести лад, визначте функцію `remainingMinutesInOven`, яка приймає як параметр кількість хвилин, що лазанья вже провела в печі, а також параметр `expectedMinutesInOven` із типовим значенням 40.
Наша функція повинна повертати, скільки хвилин лазаньї ще залишилося побути в печі, виходячи з очікуваного часу в печі в хвилинах із попереднього завдання.

```swift
remainingMinutesInOven(elapsedMinutes: 30)
// Returns 10
remainingMinutesInOven(elapsedMinutes: 30, expectedMinutesInOven: 75)
// Returns 45
```

## 2. Дозвольте різну кількість шарів

Раніше ми написали функцію `preparationTimeInMinutes`, яка приймає як параметр кількість шарів, доданих до лазаньї, і повертає, скільки хвилин ми витратили на підготовку лазаньї, якщо припустити, що на кожен шар іде 2 хвилини.
Однак ця функція нас не дуже тішить, бо перед її викликом доводиться самому рахувати шари в лазаньї, а кому хочеться витрачати на це час?

Щоб спростити собі життя, напишіть функцію `preparationTimeInMinutes`, яка приймає варіативний параметр `String` `layers`, де ми перелічуємо різні шари лазаньї.
Тоді функція порахує кількість шарів у лазаньї та поверне потрібний час на підготовку.

```swift
preparationTimeInMinutes(layers: "sauce", "noodles")
// Returns 4
preparationTimeInMinutes(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns 24
```

## 3. Обчисліть кількість локшини та соусу

Перш ніж складати лазанью, ми хочемо переконатися, що соусу й локшини вистачить на лазанью нашої мрії.
На кожен шар локшини в лазаньї потрібно 3 аркуші локшини.
На кожен шар соусу в лазаньї потрібно 0,2 літра соусу.

Визначте функцію `quantities`, яка приймає варіативний параметр `String` `layers`, де ми перелічуємо різні шари лазаньї.
Тоді функція визначить кількість локшини та соусу, потрібну для нашої страви. Результат слід повернути у кортежі типу `(noodles: Int, sauce: Double)`.

```swift
quantities(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns (noodles: 9, sauce: 0.8)
quantities(layers: "sauce", "noodles", "sauce", "noodles", "meat", "noodles", "mozzarella")
// Returns (noodles: 9, sauce: 0.4)
```

## 4. Перетворіть літри на рідкі унції на місці

На жаль, обʼєм соусу, який у нас є, вказано в рідких унціях, а не в літрах.
Щоб знати, чи вистачить соусу, напишіть функцію `toOz`, яка приймає in-out параметр-кортеж `(noodles: Int, sauce: Double)` і перетворює кількість соусу на рідкі унції.
Зауважте, що в одному літрі 33,814 рідкої унції.

```swift
var amount = (noodles: 9, sauce: 0.8)
toOz(&amount)

amount
// Returns (noodles: 9, sauce: 27.0512)
```

## 5. Визначте найкраще вино до столу

Насамкінець, ми хочемо знати, яке вино подати до лазаньї.
Ми чули, що біле вино варто подавати, якщо в лазаньї більше моцарели, рикоти й бешамелю, ніж мʼяса та соусу, а інакше - червоне.
Напишіть функцію `redWine`, яка приймає варіативний параметр `String` `layers`, де ми перелічуємо різні шари лазаньї.
Функція за допомогою пʼяти вкладених функцій визначить кількість шарів моцарели, рикоти, бешамелю, соусу та мʼяса в лазаньї й порівняє їх, щоб вирішити, чи слід подавати червоне вино, повертаючи `true`, якщо так, і `false`, якщо ні.

```swift
redWine(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns true
redWine(layers: "sauce", "noodles", "béchamel", "meat", "mozzarella", "noodles", "ricotta", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns false
```
