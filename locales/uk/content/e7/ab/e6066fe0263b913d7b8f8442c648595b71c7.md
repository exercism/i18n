# Додаток до інструкцій

## Підказки

Щоб тест пройшов, нам доведеться створити кілька типів, із якими працюватиме наш код: потрібен обʼєкт для `School`, який зберігатиме послідовність типу `Student`, а це буде кортеж із `string` та `int`, щоб зберігати імʼя та оцінку студентів.

Ось код із типами, який може стати в пригоді на початку

```nim
type
  Student* = tuple[name: string, grade: int]
  School* = object
    students*: seq[Student]
```
