# Вступ

У Julia використовуються три основні умовні конструкції:

- `if`-вирази
- Тернарний оператор
- Обчислення з коротким замиканням

## `if`-вирази

`if`-вирази в Julia схожі на ті, що ми бачимо в інших мовах:

```julia-repl
julia> function say_if_positive(n)
           if n > 0
               println("n is positive!")
           else
               println("n is not positive!")
           end
       end
say_if_positive (generic function with 1 method)

julia> say_if_positive(10)
n is positive!

julia> say_if_positive(-10)
n is not positive!
```

Якщо булевий вираз (англ. Boolean) після `if` набуває значення `true`, перший блок коду виконується, а другий пропускається.
Якщо булевий вираз після `if` набуває значення `false`, перший блок коду пропускається, а другий виконується.
Програма продовжує виконуватися з першого рядка коду після ключового слова `end`.

~~~~exercism/note
У Julia ключове слово `end` позначає кінець усіх блокових виразів.
Цей синтаксис стосується не лише `if`-виразів чи визначень функцій.
~~~~

Коли другий блок коду мав би бути ще одним `if`-виразом, `elseif` дає змогу уникнути вкладення `if`-виразів у цей блок:

```julia-repl
julia> function dessert(fruit)
           if fruit == "apple"
               return "Apple Crumble"
           elseif fruit == "lemon"
               return "Lemon Meringue Pie"
           else
               return "Fruit Salad"
           end
       end
dessert (generic function with 1 method)

julia> dessert("apple")
"Apple Crumble"

julia> dessert("lemon")
"Lemon Meringue Pie"

julia> dessert("peach")
"Fruit Salad"
```

Якщо `if`-вираз має виконати код лише для одного з випадків, гілку `else` писати не потрібно.

## Тернарний оператор

Прості інструкції `if-else` можна також записати за допомогою тернарного оператора `a ? b : c`.
Якщо `a` - правда, то обчислюється `b`.
Інакше обчислюється `c`.

Наприклад, таку функцію

```julia-repl
julia> function diagnose(heartrate)
           if heartrate > 100
               println("Elevated heart rate.")
           else
               println("Nominal heart rate or dead.")
           end
       end
diagnose (generic function with 1 method)
```

можна також записати як

```julia-repl
julia> diagnose(heartrate) = heartrate > 100 ? println("Elevated heart rate.") : println("Nominal heart rate or dead.")
diagnose (generic function with 1 method)
```

Це особливо корисно, коли потрібно присвоїти змінній різне значення залежно від умови.
`x = a ? b : c` присвоїть `x` значення `b`, якщо `a` - `true`, а інакше присвоїть `x` значення `c`.
Наприклад:

```julia-repl
julia> function patient_status(heartrate)
           status = heartrate > 0 ? "alive" : "dead"

           println("The patient is ", status)
       end

julia> patient_status(100)
The patient is alive

julia> patient_status(0)
The patient is dead
```

## Обчислення з коротким замиканням

Якщо кілька булевих виразів зʼєднати операторами `&&` (логічне і) та `||` (логічне або), Julia обчислить лише мінімальну кількість виразів, потрібних для визначення значення всього ланцюжка.

Наприклад, розглянемо ланцюжок виразів `n > 0 && k > 10`.
Якщо `n` дорівнює `5`, перша частина ланцюжка, `n > 0`, є `true`, і потрібно обчислити другий вираз `k > 10`, щоб визначити, чи весь вираз є `true`.
Однак, якщо `n` дорівнює `-5`, ми знаємо, що весь ланцюжок **не може** бути `true`, бо його перший вираз - `false`.

Якщо ж розглянути `n > 0 || k > 10`, відбувається протилежне.
Якщо `n` дорівнює `5`, перша частина ланцюжка, `n > 0`, є `true`, і ми знаємо, що весь ланцюжок буде `true` незалежно від другого виразу.
Однак, якщо `n` дорівнює `-5`, потрібно обчислити другий вираз.

Цю поведінку можна використати, щоб писати дуже короткі інструкції `if`:

```julia
if a
    b
end
```

еквівалентно

```julia
a && b
```

Останній вираз у ланцюжку `&&` (і) та `||` (або) не обовʼязково має бути булевим виразом.
Цю можливість часто використовують для дострокових помилок або повернень.
Наприклад, скористаймося наведеною вище функцією `dessert(fruit)`:

```julia-repl
julia> function whats_for_dessert(fruit, allergic_to)
           fruit == allergic_to && return "I can't eat that, guess I'll not have dessert tonight!"

           return dessert(fruit)
       end
whats_for_dinner (generic function with 1 method)

julia> whats_for_dinner("apple", "peach")
"Apple Crumble"

julia> whats_for_dinner("apple", "apple")
"I can't eat that, guess I'll not have dessert tonight!"
```
