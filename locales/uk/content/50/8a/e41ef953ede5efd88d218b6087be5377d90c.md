# Докладніше

Java - статично типізована мова, а це означає, що все має тип на етапі компіляції.
Присвоєння значення імені називають визначенням змінної.

```java
int explicitVar = 10; // Explicitly typed
```

Значення змінної можна присвоїти й оновити за допомогою [оператора `=`][assignment].
Після визначення тип змінної вже не можна змінити.

```java
int count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

Java - обʼєктно-орієнтована мова, яка вимагає, щоб усі функції були визначені в _класі_; класи визначаються за допомогою [ключового слова `class`][classes].
Функцію всередині класу називають _методом_.
Кожен [метод][methods] може мати нуль або більше параметрів.
Усі параметри повинні мати явно вказаний тип; для параметрів не існує виведення типу.
Так само потрібно явно вказати тип поверненого значення.
Значення повертаються з функцій за допомогою [ключового слова `return`][return].
Щоб метод можна було викликати з інших класів, потрібно додати модифікатор доступу `public`.

```java
class Calculator {
    public int add(int x, int y) {
        return x + y;
    }
}
```

Щоб викликати метод, потрібно вказати назву його класу й методу та передати аргументи для кожного з параметрів методу.

```java
int sum = new Calculator().add(1, 2);
```

Якщо метод не використовує жодного _стану_ класу (як у цій вправі), його можна зробити _статичним_ за допомогою модифікатора `static`.
Так само, якщо клас має лише статичні методи, його теж можна зробити статичним за допомогою модифікатора `static`.

```java
static class Calculator {
    public static int multiply(int x, int y) {
        return x * y;
    }
}
```

Область видимості в Java визначається між символами `{` та `}`.

Java підтримує два типи [коментарів][comments].
Однорядкові коментарі починаються з `//`, а багаторядкові вставляються між `/*` та `*/`.

Цілі числа визначаються як одна або більше (послідовних) цифр і підтримують [типові математичні оператори][operators].
