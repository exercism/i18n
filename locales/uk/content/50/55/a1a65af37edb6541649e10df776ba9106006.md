# Тести

Щоб запустити тести, виконайте таку команду:

```bash
make
```

## Пропущені тести

Розвʼязати вправу означає зробити так, щоб усі її тести проходили.
Типово, коли ми запускаємо тести, виконується лише один тест (перший).
Це зроблено навмисно, щоб ми могли зосередитися лише на тому, щоб цей один тест проходив.
Коли він пройде, ми можемо увімкнути наступний тест, видаливши рядок `TEST_IGNORE()`.
Коли всі тести буде увімкнено і наша реалізація проходитиме їх усі, вправу буде розвʼязано!

## Налагодження

Щоб допомогти з налагодженням, у файлі `debug.mac` визначено різні макроси.
Їх можна викликати з одним або кількома аргументами відповідного розміру.
Наприклад:

```x86asm
debugf32 xmm0, xmm1 ; prints the value of two 32-bit floating-point numbers
debugd16 ax, cx, dx ; prints the value of three signed 16-bit integers
debugx64 [rax]      ; prints the value of a 64-bit integer in hexadecimal format
debugs rsi          ; prints a NUL-terminated string whose address is stored in `rsi`
debugu8_xmm xmm1    ; prints 16 packed 8-bit unsigned integers
```

Щоб скористатися будь-яким із цих макросів, `debug.mac` потрібно включити на початку файлу рішення:

```x86asm
%include "debug.mac"
```
