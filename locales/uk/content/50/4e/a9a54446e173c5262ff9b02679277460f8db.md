# Інструкції

У цій вправі ми разом зі своїми найкращими друзями граємо в рольову гру «Wizard and Warriors». Ми виступаємо в ролі майстра гри, тобто людини, чиє завдання - оживити ігровий світ для гравців. Ключовий аспект цього - описувати гравцям гру: який статус у персонажа, який має вигляд місто, куди вони прямують, тощо.

На нас чекають пʼять завдань, у яких ми описуємо гравцям частини гри.

## 1. Описати персонажа

Кожен персонаж має клас, рівень і кількість очок здоровʼя, і його опис має такий вигляд: `"You're a level <LEVEL> <CLASS> with <HIT_POINTS> hit points."`. Реалізуйте (статичний) метод `GameMaster.Describe`, який приймає `Character` як єдиний параметр і повертає його опис.

```csharp
var character = new Character();
character.Class = "Wizard";
character.Level = 4;
character.HitPoints = 28;

GameMaster.Describe(character);
// => "You're a level 4 Wizard with 28 hit points."
```

## 2. Описати пункт призначення

Кожен пункт призначення має назву й кількість мешканців, і його опис має такий вигляд: `"You've arrived at <NAME>, which has <INHABITANTS> inhabitants."`. Реалізуйте (статичний) метод `GameMaster.Describe`, який приймає `Destination` як єдиний параметр і повертає його опис.

```csharp
var destination = new Destination();
destination.Name = "Muros";
destination.Inhabitants = 732;

GameMaster.Describe(destination);
// => "You've arrived at Muros, which has 732 inhabitants."
```

## 3. Описати спосіб подорожі

Персонажі можуть дістатися до пункту призначення одним із двох способів:

- Пішки, опис має такий вигляд: `"You're traveling to your destination by walking."`
- Верхом на коні, опис має такий вигляд: `"You're traveling to your destination on horseback."`

Реалізуйте (статичний) метод `GameMaster.Describe`, який приймає `TravelMethod` як єдиний параметр і повертає його опис.

```csharp
GameMaster.Describe(TravelMethod.Horseback);
// => "You're traveling to your destination on horseback."
```

## 4. Описати персонажа, який подорожує до пункту призначення

Коли персонаж подорожує до пункту призначення, це описується як поєднання окремих описів: `"<CHARACTER> <TRAVEL_METHOD> <DESTINATION>"`. Реалізуйте (статичний) метод `GameMaster.Describe`, який приймає `Character`, `Destination` і `TravelMethod` як параметри та повертає його опис.

```csharp
var character = new Character();
character.Class = "Wizard";
character.Level = 4;
character.HitPoints = 28;

var destination = new Destination();
destination.Name = "Muros";
destination.Inhabitants = 732;

GameMaster.Describe(character, destination, TravelMethod.Horseback);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination on horseback. You've arrived at Muros, which has 732 inhabitants."
```

## 5. Описати персонажа, який подорожує до пункту призначення, не вказуючи спосіб подорожі

У більшості випадків персонажі дістаються до пункту призначення пішки. Для зручності гравцям дозволено не згадувати спосіб подорожі, і тоді вважається, що це пішки. Реалізуйте (статичний) метод `GameMaster.Describe`, який приймає `Character` і `Destination` як параметри та повертає його опис.

```csharp
var character = new Character();
character.Class = "Wizard";
character.Level = 4;
character.HitPoints = 28;

var destination = new Destination();
destination.Name = "Muros";
destination.Inhabitants = 732;

GameMaster.Describe(character, destination);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination by walking. You've arrived at Muros, which has 732 inhabitants."
```
