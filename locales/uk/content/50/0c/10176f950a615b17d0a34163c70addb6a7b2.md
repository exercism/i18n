# Про поняття

Як і інші мови, C++ також має інструкцію `switch`.
За допомогою інструкції `switch` довгі ланцюжки `if ... else if` можна записати коротше.
Щоб створити `switch`, ми починаємо з ключового слова `switch`, після якого стоїть ціле число.
Далі ми оголошуємо кожну з умов за допомогою ключового слова `case`.
Також можна оголосити варіант `default`, який виконається, коли жодна з попередніх умов `case` не збігається.
Кожен варіант має завершуватися інструкцією `break` (або `return`).

```cpp
int price{0};
int adults{3};
int kids{2};

switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
        break;
    case 2:
        price = 70;
        break;
    default:
        price = group_size * 30;
}
```

## Провалювання

Важливо, що в конструкції switch код продовжує виконуватися, доки його не зупинить інструкція `break` (або `return`).
Це може призвести до несподіваної поведінки.

```cpp
int adults{1};
int kids{0};
switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
    case 2:
        price = 70;
    default:
        price = group_size * 30;
}
// price will be 30!
```

Найчастіше це продовження виконання потрібне для інструкції, яка має кілька міток.
Кілька результатів switch можуть указувати на той самий фрагмент коду, який треба виконати.
Завдяки цьому, наприклад у застосунку для бронювання, для розмірів групи 2 і 3 може викликатися та сама функція:
```cpp
switch (group_size) {
case 1:
    book_room();
    break;
case 2:
case 3:
    book_apartment(group_size);
    break;
default:
    book_house(group_size);
}
// book_apartment happens wheng roup_size is 2 or 3
```

~~~~exercism/note
Як ми вже бачили, інструкція switch у C++ дуже обмежена порівняно з іншими мовами.
Багато мов уміють робити розгалуження на основі булевих виразів (англ. Boolean) або навіть регулярних виразів.
Можна уявити собі, що версія C++ - це розширена конструкція goto/switch.
Стрибати на мітку може лише інструкція switch.
Після цього всі інші мітки ігноруються, і треба використати інструкцію `break`, щоб вийти з блоку коду.
~~~~
