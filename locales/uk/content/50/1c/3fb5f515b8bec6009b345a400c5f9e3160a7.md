# Докладніше

Лямбди - це функції без назви. По суті, це скорочений запис функцій.

Лямбди бувають [лямбдами-виразами](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/operators/lambda-expressions) або [лямбдами-інструкціями](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/operators/lambda-expressions#statement-lambdas):

```
(input_parameters) => expression
(input_parameters) => { <statements> }
```

## Як оголосити лямбди

Лямбди, які не повертають значення (`void`), можна перетворити на тип делегата `Action<T>`.

```csharp
// Statement lambda
Action = () =>
{
    Console.WriteLine("No parameters");
    Console.WriteLine("Still nice, right?");
}

// Expression lambda
Action<int> = (x) => Console.WriteLine(x);
```

Лямбди, що повертають значення, відмінне від `void`, можна перетворити на тип делегата `Func<T>`.

```csharp
// Expression lambda
Func<int, int> = (x) => x * x;

// Statement lambda
Func<string, string, bool> = (left, right) =>
{
    var equal = left == right;
    return equal;
}
```

Якщо лямбда має лише один параметр, дужки навколо параметра можна опустити:

```csharp
// Equivalent definitions
Action<int> = (x) => Console.WriteLine(x);
Action<int> = x => Console.WriteLine(x);
```

## Лямбди як аргументи

Лямбди найчастіше використовують для того, щоб передавати їх як аргументи іншим методам, як-от більшість методів LINQ:

```csharp
var numbers = new[] { 1, 2, 3, 4 };
var doubled = numbers.Select(n => n * 2);
foreach (var number in doubled)
{
    Console.Write(number)
}
// => 2468
```
