# Про

Змінним, оголошеним за допомогою ключового слова `final` замість `var`, можна присвоїти значення лише один раз.

```haxe
final a = "hello";
var b = "world";
trace(a, b); // hello, world
b = "haxe";
trace(a, b); // hello, haxe

// The following line would cause a compilation error:
// a = "bye";
```

Важливо зауважити, що `final` може не мати бажаного ефекту з типами, які не є незмінними, як-от масиви або обʼєкти:

```haxe
final a = [0, 1, 2];
trace(a); // [0,1,2]

// this would cause a compilation error:
// a = [0, 1, 2, 3];

// but the following line works:
a.push(3);
trace(a); // [0,1,2,3]
```
