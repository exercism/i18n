# Інструкції

Ми асистент викладача й перевіряємо студентські іспити.
Вести облік результатів вручну стає дедалі нудніше, та ще й легко помилитися.
Тож ми вирішуємо трохи урізноманітнити це й написати кілька функцій, які будуть рахувати та обчислювати результати для класу.

## 1. Округлення балів

Хоч за окремі питання іспиту можна давати «частковий бал», підсумкові бали мають бути типу `int`.
Тож перш ніж робити з балами класу щось інше, треба переглянути оцінки й перетворити всі бали `double` на `int`.

Створіть функцію `round_down_scores()`, яка приймає `vector` `student_scores`.
Школи просять округлювати саме відсіканням.
Нам пощастило: C++ уміє перетворювати один тип на інший за допомогою `static_cast`.
Перетворення `static_cast` з `double` на `int` відкидає всі цифри після коми.
Ця функція має прийняти вхідний `vector` і `return` новий `vector`, у якому всі бали перетворено на `int`.

```cpp
std::vector<double> student_scores {90.33, 40.5, 55.44, 70.05, 30.55, 25.45, 80.45, 95.3, 38.7, 40.3};
round_down_scores(student_scores)
// => {90, 40, 55, 70, 30, 25, 80, 95, 38, 40}
```

Є й інші способи досягти того самого результату, але _приведення типу_ трапляється найчастіше.

```cpp
int new_PI{static_cast<int>(3.14) + static_cast<int>(0.001592653589)};
// new_PI is 3.
```

## 2. Студенти, які не склали іспит

Перевіряючи іспит, ми помітили, що деякі студенти впоралися гірше, ніж хотілося б.
Але ми відволіклися й забули записати, _скільки_ саме студентів.

Створіть функцію `count_failed_students()`, яка приймає `vector` `student_scores`.
Ця функція має порахувати кількість студентів, які не набрали прохідного балу, і повернути цю кількість як ціле число.
Щоб отримати прохідний бал за іспит, студентові потрібно набрати більше ніж **40**.

```cpp
count_failed_students({90,40,55,70,30,25,80,95,38,40});
// => 5
```

## 3. Обчислення літерних оцінок

Учитель, якому ми допомагаємо, окрім числових балів любить виставляти ще й літерні оцінки.
Оскільки студенти рідко набирають 100 балів на іспиті, нижні пороги для «літерних оцінок» обчислюються на основі найвищого набраного балу й рівномірно зростають між найвищим балом і порогом неуспішності **<= 40**.

Створіть функцію `letter_grades()`, яка приймає «найвищий» бал за іспит як параметр і повертає `array` (а не vector) нижніх порогів балів для кожного інтервалу оцінок «американського стилю»: `["D", "C", "B", "A"]`.

```cpp
/*Where the highest score is 100, and failing is <= 40.
       "F" <= 40
 41 <= "D" <= 55
 56 <= "C" <= 70
 71 <= "B" <= 85
 86 <= "A" <= 100
*/

letter_grades(100);
// => {41, 56, 71, 86}


/*Where the highest score is 88, and failing is <= 40.
       "F" <= 40
 41 <= "D" <= 52
 53 <= "C" <= 64
 65 <= "B" <= 76
 77 <= "A" <= 88
*/

letter_grades(88);
// => {41, 53, 65, 77}
```

## 4. Зіставлення імен із балами

У нас є бали за іспит у спадному порядку та відповідні імена студентів (упорядковані за їхніми балами).
Ми хочемо зіставити імʼя кожного студента з його балом за іспит і надрукувати загальний рейтинг класу.

Створіть функцію `student_ranking()` з параметрами `student_scores` і `student_names`.
Зіставте кожне імʼя студента зі `vector` student_names з відповідним балом із `vector` student_scores.
Можна припустити, що кожен переданий `vector` відсортовано від найвищого балу до найнижчого.
Функція має повертати `vector` рядків тексту (англ. string) у форматі `<rank>. <student name>: <student score>`.

```cpp
std::vector<int> student_scores {100, 99, 90, 84, 66, 53, 47};
std::vector<std::string> student_names {"Joci", "Sara","Kora","Jan","Indra","Bern", "Fred"};
student_ranking(student_scores, student_names)
// =>
//  {"1. Joci: 100", "2. Sara: 99", "3. Kora: 90", "4. Jan: 84", "5. Indra: 66", "6. Bern: 53", "7. Fred: 47"}
```

## 5. «Ідеальний» бал

Хоч «ідеальний» бал 100 на іспиті трапляється рідко, цікаво дізнатися, чи досягнув його хоч один студент.

Створіть функцію `perfect_score()` з параметрами `student_scores` і `student_names`.
Списки ті самі, що й у завданні 5.
Функція має `return` _перше_ `<name>` (як рядок тексту) студента, який набрав 100 балів на іспиті.

Якщо балів 100 немає, має бути повернено порожній рядок тексту `""`.

```cpp
perfect_score({"Nur", "Tony", "Fatima"}, {90, 80, 100});
// => "Fatima"

perfect_score({"Nur", "Tony"}, {90, 80});
// => ""
```
