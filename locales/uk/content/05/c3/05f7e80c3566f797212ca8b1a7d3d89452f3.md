# Вступ

## Оголошення типів

Оголошення типів у PHP забезпечують перевірку типів під час виконання для аргументів функцій, повернених значень і властивостей класу.
У функціях можна додати тип повернення `void`, щоб указати, що функція не повертає жодного значення.
Оголошені типи також слугують перевіркою під час виконання, що функції повертають належно типізований результат.

```php
<?php

class Driver
{
    private int $serial_number;

    public function setSerialNumber(int $number): void
    {
        $this->serial_number = $number;
    }

    public function getSerialNumber(): int
    {
        return $this->serial_number; 
    }
}

$driver = new Driver();
$driver->setSerialNumber("Version 1b"); // This will throw a TypeError
```

### Обʼєднання типів

Якщо аргумент функції, повернене значення або властивість класу можуть мати більше ніж один тип, можна оголосити обʼєднання типів.

```php
<?php

class IdentityCard
{
    private int|null $id = null;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

### Змішані типи

Працюючи з кодом, ми не завжди можемо вказати тип.
Починаючи з PHP 8.0, надається тип-лазівка з назвою `mixed`.
`mixed` еквівалентний обʼєднанню типів `object|resource|array|string|float|int|bool|null`.
