# Вступ

`bit` - найдрібніше значення в обчисленнях.
Слово `bit` означає «двійкова цифра».
Це одиниця зберігання даних у середовищі виконання, достатньо велика, щоб умістити обʼєкт, який може мати одне з двох значень.
Тож він має двійкове значення: `1` або `0`.
Усі інші типи даних складаються з багатьох `bits`.
Наприклад, `byte` зазвичай складається з восьми `bits`.

## Бітові маски

Бітовою маскою може бути будь-яке значення, яке використовується для встановлення окремих бітів.
Наприклад, в англійському алфавіті двадцять шість літер.
Значення, що має принаймні двадцять шість бітів, як-от 32-бітне ціле число без знака, можна використати як бітову маску, щоб задати умову `true` або `false` для кожної літери англійського алфавіту.
Будь-яке значення з достатньою кількістю бітів, щоб охопити потрібний набір умов `true` або `false`, може слугувати бітовою маскою.
Встановлення та читання окремих бітів відбувається за допомогою бітових операторів.

## Бітові оператори

Скажімо, ми хочемо відстежувати, які літери трапляються в рядку тексту (англ. `string`).
У нашому прикладі ми будемо використовувати лише двадцять шість літер англійського алфавіту.
Нашою бітовою маскою буде 32-бітне ціле число без знака.
`0` означатиме, що літера не трапляється.
`1` означатиме, що літера трапляється один або більше разів.
Спочатку бітове представлення нашої бітової маски становитиме 32 `0s` підряд: `00000000000000000000000000000000`.
Найправіша позиція відповідатиме `A`.
Друга зліва відповідатиме `B`, і так далі.
Скажімо, ми обробляємо всі літери в рядку тексту в циклі, тож нам потрібен один рядок коду, який працюватиме для встановлення будь-якої літери.

### Оператор бітового зсуву вліво: як розмістити біт

`<<` - це бітовий оператор зсуву вліво.

Якщо наша літера - `A`, зсув уліво не потрібен, але якщо наша літера - `B`, нам треба зсунути вліво на одну позицію, а якщо `C` - на дві, і так далі.
Хоча ми можемо сприймати `chars` як літери, як-от `A` чи `B`, `char` у памʼяті реалізовано як цілочисельний тип, тож із `char` можна робити прості обчислення.
Маючи змінну з назвою `letter`, яка представляє `char`, що ми обробляємо, ми можемо зсунути вліво на потрібну кількість позицій, зсунувши `1` вліво на різницю між `letter` і `char` `A`, ось так: `1 << letter - 'A'`.
`A` мінус `A` дає `0`, тож якщо `letter` дорівнює `A`, ми зсунемо вліво на `0` позицій.
`B` мінус `A` дає `1`, тож якщо `letter` дорівнює `B`, ми зсунемо вліво на `1` позицію, і так далі.

### Оператор бітового включального АБО: як встановити біт

Коли ми знаємо, _де_ хочемо встановити біт, ми можемо власне встановити його за допомогою оператора бітового включального АБО, тобто `|`.
Результат оператора `|` буде `1` у кожній позиції, де встановлений біт має або лівий, або правий операнд.
Отже, результат `0010 | 0001` буде `0011`.
(Важливо памʼятати, що це значення - `11` у двійковій системі, але `3` у десятковій.)
Щоб присвоїти результат значенню, оператор `|` можна поєднати з оператором присвоєння, щоб встановлювати біти ось так: `|=`.
Щоб не ускладнювати, наступний приклад не використовує цикл, але демонструє, як ми могли б обробити літери `ABA` у бітовій масці.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    // it's important to initialize the mask to 0 so we don't get garbage values
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    mask |= 1 << letter_A_again - 'A';
    // prints 3
    printf("%d", mask);
}
```

Ми встановлюємо найправішу частину нашої маски в `0001` для `A`, а потім встановлюємо маску в `0011` для `B`.
Встановлення ще однієї `A` не змінює наявну маску.
Ми могли б уникнути повторного встановлення біта, перевіривши, чи `A` вже було встановлено.

### Оператор бітового І: як прочитати біт

`&` - це бітовий оператор І.
Результат оператора `&` буде `1` у кожній позиції, де встановлений біт мають і лівий, і правий операнд.
Отже, результат `0011 & 0001` буде `0001`.
Ми можемо побачити це в дії в наступному прикладі.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    // prints A already set
    if (mask & 1 << letter_A_again - 'A')
        printf("A already set\n");
    else
        mask |= 1 << letter_A_again - 'A';
    printf("%d", mask);
}
```

### Оператор бітового виключального АБО: як перемкнути біт

`^` - це бітовий оператор виключального АБО.
Оператор _включального_ АБО передбачає існування оператора _виключального_ АБО з іншою поведінкою.
Результат оператора `^` буде `1` у кожній позиції, де встановлений біт має _лише один_ із операндів, лівий або правий.
Отже, результат `0001 ^ 0011` буде `0010`.
Найправіший біт не буде встановлено, бо _обидва_ операнди мають `1` у найправішій позиції.
Операцію виключального АБО іноді позначають як XOR.
Якщо результат операції XOR над значенням ще раз піддати XOR, ми отримаємо початкове значення.
Це можна використати для дуже простого шифрування, де той самий ключ використовується і для шифрування, і для розшифрування даних.
Наприклад

```c
#include <stdio.h>

int main() {
    char a = 'a';
    char b = 'b';
    char c = 'c';
    // we will use "a" for the "key"
    char first = a ^ 'a';
    char second = b ^ 'a';
    char third = c ^ 'a';
    // prints three "dots" for unprintable characters
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 0 3 2
    printf("%d %d %d\n", first, second, third);
    first = first ^ 'a';
    second = second ^ 'a';
    third = third ^ 'a';
    // prints a b c
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 97 98 99
    printf("%d %d %d\n", first, second, third);
}
```

## Бітові поля

Ми бачили, як біти, упаковані в простий тип даних, можна адресувати за їхньою позицією.
Біти, упаковані в `struct`, можна адресувати за назвою.
Такий тип даних називається `bit field`.
`bit fields` можуть стати в пригоді, коли потрібен набір прапорців УВІМК/ВИМК, а використання памʼяті хочеться зменшити.

```c
#include <stdio.h>

int main() {

    struct lights {
        unsigned int number_of_lights;
        unsigned int red   : 1;
        unsigned int green : 1;
        unsigned int blue  : 1;
    };
    struct lights lightboard = {3, 0, 0, 0};
     
    //  prints 000
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    lightboard.green = 1;

    //  prints 010
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    // prints 3
    printf("%d\n", lightboard.number_of_lights);
}
```

Синтаксис `unsigned int variable_name : 1;` створює поле з `1` біта всередині `unsigned int`, розміщеного в структурі.
Замість `unsigned int` можна використати `signed int`, або, починаючи з C99, тип `bool`.
Структура, що містить бітові поля, може також містити поля інших типів даних, як-от `number_of_lights` у наведеному вище прикладі.
