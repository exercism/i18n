# Додатково

## GNU awk й арифметика довільної точності

Типово числа в `awk` представлено як числа з плаваючою комою подвійної
точності. Це дає 53 біти точності (див. [таблицю
16.3][table-16.3] у посібнику). На жаль, цього не вистачає, щоб
виконати цю вправу (спойлер: один тест вимагає 63 бітів точності).

«Недостатня точність» має такий вигляд:
```sh
$ gawk 'BEGIN {
  n = 2 ^ 54
  if (n == n + 1)
    print "not enough precision"
  else
    print "OK"
}'
```
```none
not enough precision
```

GNU `awk` може використовувати числа довільної точності, якщо відповідні
бібліотеки скомпільовано у виконуваний файл `awk`. Перевірмо версію свого
awk і пошукаймо «GNU MPFR»:
```sh
$ gawk --version
GNU Awk 5.0.1, API: 2.0 (GNU MPFR 4.0.2, GNU MP 6.2.0)
...
```

Якщо вона є, увімкнімо цю можливість за допомогою параметра `-M`:
```sh
$ gawk -M 'BEGIN {
  n = 2 ^ 54
  if (n == n + 1)
    print "not enough precision"
  else
    print "OK"
}'
```
```none
OK
```

А що, якщо наш `awk` не має `-M`? Доведеться звернутися до зовнішньої
програми, яка вміє виконувати арифметику довільної точності, як-от `bc`. Погляньмо на
розділ [Використання getline для читання з каналу у змінну][getline-pipe], де
наведено приклад, як це зробити.
