# Тести

## Інтерактивне тестування

Запустімо REPL із каталогу, у який ми завантажили вправу.

Запустити тести можна, завантаживши файл тестів у REPL за допомогою `(load "exercise-test")` (замінивши «exercise» на відповідну назву). Потім обчислімо `(exercise-test:run-tests)`, щоб запустити всі тести.

Якщо ми пишемо код безпосередньо в REPL, то просто обчислімо `(exercise-test:run-tests)`.

Якщо ми пишемо код у lisp-файлі вправи, то завантажмо його за допомогою `(load "exercise")`, а потім обчислімо `(exercise-test:run-tests)`.

## Тестування з командного рядка

Тести можна запустити таким викликом у командному рядку (знову ж таки, замінімо «exercise» на відповідну назву у двох місцях)

```sh
ros run --load exercise-test.lisp --eval '(uiop:quit (if (exercise-test:run-tests) 0 1))'
```
