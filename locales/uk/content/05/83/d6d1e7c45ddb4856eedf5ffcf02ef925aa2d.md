# Вступ

Абстрактне синтаксичне дерево (AST), яке також називають _quoted expression_, дає змогу подати код як дані.

Кожен вузол в AST - це кортеж із трьох елементів.

```elixir
# AST representation of:
# 2 + 3
{:+, [], [2, 3]}
```

Перший елемент, атом, позначає операцію. Другий елемент, список ключових слів, містить метадані. Третій елемент - список аргументів, що містить інші вузли. Літеральні значення, як-от цілі числа, атоми чи рядки тексту (англ. string), подаються в AST самі собою, а не як кортежі з трьох елементів.

## Перетворення коду на AST

Перетворення коду Elixir на AST і назад виконує стандартна бібліотека. Функції для роботи з AST можна знайти в модулях `Code` (наприклад, щоб перетворити рядок тексту з кодом на AST) і `Macro` (наприклад, щоб обійти AST або перетворити його на рядок тексту).

Зауважмо, що всі функції стандартної бібліотеки використовують назву «quoted» на позначення AST (скорочення від _quoted expression_).

Спеціальна форма для перетворення коду на AST називається `quote`. Вона приймає блок коду і повертає його AST.

```elixir
quote do
  2 + 3 - 1
end

# => {:-, [], [
#      {:+, [], [2, 3]},
#      1
#    ]}
```

## Варіанти використання

Уміння подати код як AST лежить в основі метапрограмування в Elixir. _Макроси_, тобто спосіб писати код Elixir, який породжує код Elixir, працюють, повертаючи AST як вихідні дані.

Ще один варіант використання AST - статичний аналіз коду, як-от власний інструмент Exercism під назвою Analyzer, який ми, можливо, вже знаємо як маленького бота, що залишає коментарі до наших рішень.
