# Інструкції

У цій вправі ми напишемо трохи коду, який допоможе приготувати чудову лазанью з улюбленої книги рецептів.

На нас чекають чотири завдання, і всі вони повʼязані з часом, витраченим на приготування лазаньї.

## 1. Визначте очікуваний час запікання в духовці у хвилинах

Визначте константу з назвою `$expected_minutes_in_oven`.
Згідно з книгою рецептів, очікуваний час запікання в духовці становить 40 хвилин:

```sh
$ jq -n -f lasagna.jq
{
  "expected_minutes_in_oven": 40,
  ...
```

## 2. Обчисліть залишковий час запікання в духовці у хвилинах

Це значення приймає як вхідні дані фактичну кількість хвилин, які лазанья вже провела в духовці, і повертає, скільки хвилин їй ще залишилося там провести, виходячи з очікуваного часу в духовці з попереднього завдання.

```sh
$ echo '{"actual_minutes_in_oven": 18}' | jq -f lasagna.jq
{
  "expected_minutes_in_oven": 40,
  "remaining_minutes_in_oven": 22,
  ...
```

## 3. Обчисліть час підготовки у хвилинах

Час підготовки показує, скільки часу потрібно, щоб підготувати лазанью, перш ніж поставити її в духовку.
На підготовку кожного шару потрібно 2 хвилини.

```sh
$ echo '{"number_of_layers": 3}' | jq -f lasagna.jq
{
  ...
  "preparation_time": 6,
  ...
```

## 4. Обчисліть загальний час роботи у хвилинах

Обчисліть, скільки хвилин загалом ми витратили на приготування лазаньї.
Це сума часу підготовки в хвилинах і часу, який лазанья на цей момент уже провела в духовці.

```sh
$ echo '{"actual_minutes_in_oven": 10, "number_of_layers": 2}' | jq -f lasagna.jq
{
  ...
  "total_time": 14,
  ...
```
