# Підказки

## 1. Загальне

- Прочитаймо про файли в офіційному [посібнику «З чого почати»][getting-started-file].
- Прочитаймо про файли на [joyofelixir.com][joy-of-elixir-file].
- Погляньмо на [документацію модуля `File`][file].

## 1. Зчитати адреси електронної пошти з файлу

- Є [вбудована функція][file-read], яка читає весь вміст файлу одразу.

## 2. Відкрити файл журналу для запису

- Є [вбудована функція][file-open] для відкриття файлу.
- Другим аргументом цієї функції є список режимів, який дає змогу вказати, що файл потрібно відкрити для запису.

## 3. Записати надісланий лист у журнал

- Функції для читання та запису у файл, відкритий за допомогою [`File.open!/1`][file-open], можна знайти в модулі [`IO`][io].
- Є [вбудована функція][io-puts], яка записує рядок тексту (англ. string) у файл, а потім додає символ нового рядка.

## 4. Закрити файл журналу

- Є [вбудована функція][file-close] для закриття файлу.

## 5. Надіслати розсилку

- Усі потрібні операції з файлами вже реалізовано на попередніх кроках.
- Перш ніж писати у файл, його потрібно відкрити.
- Після завершення всіх операцій запису у файл його слід закрити.
