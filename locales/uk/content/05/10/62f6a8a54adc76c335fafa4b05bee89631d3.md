# Вступ до основ

[Go](https://golang.org) - це мова програмування зі статичною типізацією, яку компілюють.
Синтаксично Go схожа на C.
Мову часто називають Golang через її колишнє доменне імʼя golang.org, але правильна назва - Go.

Концепція «Основи» знайомить із трьома важливими можливостями мови: пакетами, функціями та змінними.

## Пакети

Програми на Go організовано в пакети.
Пакет обʼєднує вихідні файли, що лежать в одному каталозі.
Усі вихідні файли в одному каталозі повинні мати однакове імʼя пакета.
За домовленістю імʼя пакета збігається з останнім каталогом у шляху імпорту.
Наприклад, файли з [пакета «math/rand»](https://golang.org/src/math/rand/) починаються з інструкції `package rand`.
Коли пакет імпортовано, використовувати можна лише ті сутності (функції, типи, змінні, константи), назви яких починаються з великої літери.
У Go рекомендують називати ідентифікатори в `camelCase`, крім тих, що мають бути доступними з інших пакетів: їх слід писати в `PascalCase`.

```go
package lasagna
```

## Змінні

Go має статичну типізацію, а це означає, що під час компіляції всі змінні [повинні мати визначений тип](https://en.wikipedia.org/wiki/Type_system).

Змінну можна визначити, явно вказавши тип:

```go
var explicit int // Explicitly typed
```

Можна також скористатися ініціалізатором: тоді компілятор сам надасть змінній тип, що відповідає типу ініціалізатора.

```go
implicit := 10   // Implicitly typed as an int
```

Після оголошення змінній можна присвоїти значення за допомогою оператора `=`.
Після оголошення тип змінної вже не може змінитися.

```go
count := 1 // Assign initial value
count = 2  // Update to new value

count = false // This throws a compiler error due to assigning a non `int` type
```

## Константи

Константи зберігають дані так само, як змінні, але їхнє значення не може змінюватися під час виконання програми.

Константи визначають за допомогою ключового слова `const`; вони бувають числами, символами, рядками тексту (англ. string) або булевими значеннями (англ. Boolean):

```go
const Age = 21 // Defines a numeric constant 'Age' with the value of 21
```

## Функції

Функції в Go приймають нуль або більше параметрів.
Тип параметрів потрібно вказувати явно: виведення типів тут не працює.

Значення повертають із функцій за допомогою ключового слова `return`.

Щоб викликати функцію, вказуємо її назву й передаємо аргументи для кожного з її параметрів.

Зауважмо, що Go підтримує два типи коментарів.
Однорядкові коментарі починаються з `//`, а багаторядкові вставляють між `/*` і `*/`.

```go
package greeting

// Hello is a public function.
func Hello (name string) string {
    return hi(name)
}

// hi is a private function.
func hi (name string) string {
    return "hi " + name
}
```
