# Розуміння рекурсії в JavaScript

Рекурсія - це потужна концепція в програмуванні, яка полягає в тому, що функція викликає саму себе.
Спочатку її буває трохи важко зрозуміти, але коли ми розберемося з основами, вона стає цінним інструментом для розвʼязання складних задач.
Ми розглянемо рекурсію в JavaScript на простих прикладах.

## Що таке рекурсія?

Рекурсія виникає тоді, коли функція викликає саму себе прямо або опосередковано.
Це схоже на цикл, але може передбачати розбиття задачі на менші, зручніші підзадачі.

### Приклад 1: Зворотний відлік

Почнімо з простого прикладу: функції зворотного відліку.

```javascript
function countdown(num) {
  // Base case
  if (num <= 0) {
    console.log('Blastoff!');
    return;
  }

  // Recursive case
  console.log(num);
  countdown(num - 1);
}

// Call the function
countdown(5);
```

У цьому прикладі:

- **Базовий випадок**: коли `num` стає меншим або дорівнює 0, функція друкує «Blastoff!» і припиняє викликати саму себе.
- **Рекурсивний випадок**: функція друкує поточне `num` і викликає саму себе з `num - 1`.

### Приклад 2: Факторіал

Тепер погляньмо на класичний приклад рекурсії: обчислення факторіала числа.

```javascript
function factorial(n) {
  // Base case
  if (n === 0 || n === 1) {
    return 1;
  }

  // Recursive case
  return n * factorial(n - 1);
}

// Test the function
console.log(factorial(5)); // Output: 120
```

У цьому прикладі:

- **Базовий випадок**: коли `n` дорівнює 0 або 1, функція повертає 1.
- **Рекурсивний випадок**: функція множить `n` на факторіал `n - 1`.

## Ключові поняття

### Базовий випадок

Кожна рекурсивна функція повинна мати принаймні один базовий випадок: умову, за якої вона припиняє викликати саму себе.
Без базового випадку рекурсія тривала б нескінченно, що призвело б до переповнення стека.

### Рекурсивний випадок

Рекурсивний випадок визначає, як функція викликає саму себе з меншою або простішою версією задачі.

## Переваги й недоліки рекурсії

**Переваги:**

- Витончене рішення для деяких задач.
- Повторює концепцію математичної індукції.

**Недоліки:**

- Може бути менш ефективною, ніж ітеративні рішення.
- Може призвести до переповнення стека за глибокої рекурсії.

## Висновок

Рекурсія - цінна техніка, яка спрощує складні задачі, розбиваючи їх на менші, зручніші підзадачі.
Розуміння базових і рекурсивних випадків має вирішальне значення для реалізації ефективних рекурсивних рішень у JavaScript.
