# Встановлення

- macOS: виконайте `brew install futhark`
- Linux: виконайте `brew install futhark`
- Windows: скористайтеся WSL або дотримуйтесь [інструкцій для Windows][windows-specific-instructions]

Інші способи встановлення описано в [офіційних інструкціях зі встановлення][instructions].

[instructions]: https://futhark.readthedocs.io/en/stable/installation.html
[windows-specific-instructions]: https://futhark.readthedocs.io/en/stable/installation.html#windows-installation
