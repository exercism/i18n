# Додаток до вказівок

## Деякі зауваження про рядки тексту (англ. string) в Arturo

У тестах ми побачимо синтаксис, який може бути новим для нас: багаторядкові рядки тексту, узяті в `{ braces }`.

### Посилання

* [Тип `:string`][string] у довіднику мови.
* Документація [Базове використання][usage] у модулі Strings.

[string]: https://arturo-lang.io/documentation/language/#string
[usage]: https://arturo-lang.io/documentation/library/strings/#basic-usage

### Літерали рядків тексту в Arturo

В Arturo є кілька способів записати літерали рядків тексту:

1. Однорядкові рядки тексту в подвійних лапках

    ```arturo
    greeting: "Hello, World!"

    print express greeting     ; => "Hello, World!"
    ```

1. Рядки тексту, що тривають до кінця рядка, задаються «розумною лапкою» `«`

    ```arturo
    farewell: « Goodbye, Mars!

    print express farewell     ; => "Goodbye, Mars!"
    ```

   Вони читаються досить зручно, якщо в нас є список коротких рядків тексту:

    ```arturo
    numberWords: [
        « one
        « two
        « three
        « four, and so on
    ]
 
    print express numberWords    ; => ["one" "two" "three" "four, and so on"]
    ```

1. Багаторядкові рядки тексту у фігурних дужках.
   «Спільний» відступ буде прибрано.
   Початкові та кінцеві символи нового рядка прибираються.

    ```arturo
    multiline: {
        First line
        Second line
            Third line keeps indentation
        Last line!


    }

    print express first multiline   ; => 'F'
    print express last multiline    ; => '!'
    lines: split.lines multiline
    print size lines                ; => 4
    print express lines\2           ; => "    Third line keeps indentation"
    ```

1. Дослівні рядки тексту зберігаються точно, разом із початковими та кінцевими пробільними символами

    ```arturo
    code: {:
        greet: function [name][
            print ~"Hello, |name|~"

        greet "World""
    :}

    print ">" ++ code ++ "<"
    print express first code
        ; => prints a literal newline character between single quotes
    print express (split.lines code | get 1)
        ; => "    greet: function [name]["
    ```

1. Рядки тексту в стилі heredoc розташовуються під рядком із 3 або більше дефісів і тривають до кінця файлу.
   Це діє так само, як ключове слово `__DATA__` у Perl.
   Цей стиль стане в пригоді в модулі, де ми можемо зберегти документацію чи текст ліцензії у змінній наприкінці файлу.

    Якщо це у файлі з назвою «mymodule.art»

    ```arturo
    myLicense:
    ---------
    This text has been placed in the public domain.
    Do with it what you will.
    ```

    Тоді

    ```arturo
    import {mymodule}!
    print ~">|myLicense|<"  ; => >This text has been placed in the public domain.
                            ; => Do with it what you will.<
    ```
