# Вступ

Функція - це блок організованого, багаторазово використовуваного коду, який виконує певну дію.
У JavaScript є кілька способів визначати функції.
Тут ми розглянемо _оголошення функцій_ та _функціональні вирази_.
Інші можливості, як-от [стрілкові функції][concept-arrow-functions], розглянемо в інших концепціях.

## Оголошення функції

Стандартний спосіб визначити функцію в JavaScript - це _оголошення функції_, яке також називають _визначенням функції_ або _інструкцією функції_.

Воно складається з ключового слова `function`, назви функції та розділеного комами списку параметрів у круглих дужках.
Далі йде тіло функції (набір інструкцій, що визначає, що робить функція), укладене у фігурні дужки.

```javascript
function someName(param1, param2, param3) {
  // ...
}
```

У JavaScript функцію викликають (запускають), записавши назву функції, а потім дужки з аргументами.

```javascript
someName(arg1, arg2, arg3);
```

## Параметри

Працюючи з параметрами всередині тіла функції, памʼятаймо про можливі побічні ефекти.

- Значення [примітивних типів даних][mdn-primitives] є _незмінними_.
  На початкове значення жодним чином не впливає те, що відбувається з аргументом у тілі функції.
- Для всіх інших значень (обʼєктів, масивів, функцій) повторне присвоєння не вплине на початкове значення.
  Однак якщо ми змінюємо такий аргумент (наприклад, додаємо ключ до обʼєкта), то це також змінює початкове значення, яке було передано.

Типово всі параметри, визначені в оголошенні функції, у JavaScript є необовʼязковими.
Якщо ми передаємо менше аргументів, ніж є параметрів, то відсутні аргументи всередині функції матимуть значення `undefined`, див. [Null та Undefined][concept-null-undefined].
У багатьох випадках має сенс присвоїти доречніше типове значення, ніж `undefined`.
Це можна зробити, вказавши типові параметри безпосередньо у визначенні функції.

```javascript
function someName(param1 = defaultValue1, param2 = defaultValue2) {
  // ...
}
```

## Інструкція `return`

Інструкція `return` завершує виконання функції та вказує значення, яке потрібно повернути тому, хто викликав функцію. Функція може мати кілька інструкцій `return`.

```javascript
function checkNumber(num) {
  if (num === 0) {
    return 'You passed 0, please provide another number.';
  }

  return 'Thanks for passing such a nice number.';
}
```

Результат функції, яка не повертає жодного значення або не має інструкції `return`, дорівнює `undefined`.
У JavaScript немає неявних `return`.

```javascript
function nakedReturn(a) {
  a * 2;
  return;
}

nakedReturn(1);
// => undefined

function noReturn(a) {
  a * 2;
}

noReturn(1);
// => undefined
```

У JavaScript можна повернути лише одне значення.
Якщо потрібно передати більше інформації, спершу треба поєднати її в одну сутність, зазвичай у [обʼєкт][concept-objects] або [масив][concept-arrays].

```javascript
function divide(a, b) {
  return {
    quotient: Math.floor(a / b),
    remainder: a % b,
  };
}
```

## Функціональний вираз

Оголошення функції - це окрема інструкція.
Але іноді корисно визначити функцію як частину іншого виразу, наприклад у присвоєнні, як параметр функції ([функція зворотного виклику][concept-callbacks]) або як значення в [обʼєкті][concept-objects].
Це можна зробити за допомогою функціонального виразу.
Він має той самий синтаксис, що й оголошення функції, лише назву функції можна опустити, щоб створити _анонімну функцію_.

```javascript
const someFunction = function (param) {
  // ...
};

someOtherFunction(function (param) {
  // ...
});

const obj = {
  someFunction: function (param) {
    // ...
  },
};
```
