# Докладніше

[Символи][symbols] - це іменовані ідентифікатори, які можна використовувати для посилання на значення.
Символи створюються за допомогою літерала символу, тобто додаванням до назви символу `:`, наприклад `:foo`.
Їх також можна записати в лапках, наприклад `:"foo"`, що дозволяє, зокрема, використовувати пробіли в назві.

```ruby
:foo # => :foo
:"foo boo" # => :"foo boo"
```

Символи використовуються в багатьох місцях мови, зокрема як ключі в хешах, для позначення назв методів і змінних.

## Ідентифікатор

Символи відрізняються від рядків тексту (англ. string) тим, що вони є ідентифікаторами й не представляють дані чи текст.
Це означає, що два символи з однаковою назвою завжди є одним і тим самим обʼєктом.

```ruby
"foo".object_id # => 60
"foo".object_id # => 80
:foo.object_id # => 1086748
:foo.object_id # => 1086748
```

## Зміна символів

Символи незмінні, тобто їх не можна модифікувати.
Це означає, що коли ми «змінюємо» символ, насправді ми створюємо новий символ.
Є кілька методів, якими можна маніпулювати символами, і всі вони повертають нові символи.
Усі методи можна знайти в [API символів][symbols-api].

```ruby
:foo.upcase # => :FOO

:foo.object_id # => 1086748
:foo.upcase.object_id # => 60
```

Перевага незмінності символів у тому, що вони ефективніше використовують памʼять, ніж рядки тексту, а також безпечніші у використанні як ідентифікатори.

## Перетворення

Символи можна перетворювати на рядки тексту й навпаки.
Це може стати в нагоді, коли ми хочемо змінити символ або використати символ як рядок тексту.
Щоб подати рядок тексту як символ, можна скористатися методом `String#to_sym`, а щоб зробити навпаки, скористатися методом `Symbol#to_s`.
Оскільки символи мають обмежений набір методів, може бути корисно перетворити символ на рядок тексту, щоб застосувати до нього методи рядків, якщо потрібен новий символ.

```ruby
:foo.to_s # => "foo"
"foo".to_sym # => :foo
```
