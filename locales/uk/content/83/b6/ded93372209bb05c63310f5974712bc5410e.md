# Додаток до інструкцій

## Слова

Визначте кортеж `school` для зберігання списку студентів (як саме зберігати студентів усередині нього, вирішуйте самі), а потім реалізуйте наведені нижче слова.

- `<school> ( -- school )`: створює порожню школу.
- `add-student ( school name grade -- ? )`: додає `name` до класу `grade`. Повертає `t` у разі успіху або `f`, якщо `name` уже додано (до цього чи будь-якого іншого класу); у цьому разі список студентів залишається без змін.
- `roster ( school -- names )`: усі студенти, відсортовані спочатку за класом, а потім за імʼям за абеткою.
- `grade ( school n -- names )`: студенти класу `n`, відсортовані за імʼям за абеткою.
