# Вступ

У C# є два різні типи чисел:

- Цілі числа: числа без цифр після десяткового розділювача (цілі величини). Приклади: `-6`, `0`, `1`, `25`, `976` і `500000`.
- Числа з плаваючою комою: числа з нулем або більше цифр після десяткового розділювача. Приклади: `-2.4`, `0.1`, `3.14`, `16.984025` і `1024.0`.

Два найпоширеніші числові типи в C# - це `int` і `double`. `int` - це 32-бітове ціле число, а `double` - 64-бітове число з плаваючою комою.

Арифметичні дії виконують за допомогою стандартних арифметичних операторів. Числа можна порівнювати за допомогою стандартних операторів порівняння чисел, а також операторів рівності (`==`) і нерівності (`!=`).

У C# є два типи перетворень чисел:

1. Неявні перетворення: дані не втрачаються і додатковий синтаксис не потрібен.
2. Явні перетворення: дані можуть втратитися і потрібен додатковий синтаксис у вигляді _приведення типу_.

Оскільки `int` має меншу точність, ніж `double`, перетворення з `int` на `double` є безпечним і тому є неявним перетворенням. Однак перетворення з `double` на `int` може означати втрату даних, тож для нього потрібне явне перетворення.

```csharp
int softCool = 1358938113;
double notLost = 4.8151623;

// implicit cast: no loss of information
double macDebug = softCool;         // 1358938113.0

// explicit cast: possible loss of information 
int somethingLost = (int)notLost;   // 4
```
