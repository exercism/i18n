# Вступ

## Модулі

Модулі - це спосіб згрупувати повʼязаний код, щоб уникати конфліктів імен; вони присутні майже в усіх кодових базах, крім найтривіальніших.

Синтаксис такий:

```rust
mod my_module {
    pub struct MyStruct {}

    pub struct OtherClass {}
}
```

За межами області видимості модуля до типів, укладених у модулі, звертаються, ставлячи перед назвою типу подвійну двокрапку (`::`).
Або, що буває частіше, можна розмістити директиву `use` на початку файлу (чи всередині модуля), і тоді типи можна використовувати без префікса.
Усередині того самого модуля немає потреби уточнювати назви типів.

```rust
mod my_module {
    #[derive(Drop)]
    pub struct MyStruct {}

    pub struct Foo {}

    #[generate_trait]
    pub impl FooImpl of FooTrait {
        fn bar() {
            let baz = MyStruct {};
        }
    }
}

#[derive(Drop)]
pub struct Qux {}

#[generate_trait]
impl QuxImpl of QuxTrait {
    fn box() {
        let nux = my_module::MyStruct {};
    }
}

mod other_module {
    use super::my_module::*;

    #[derive(Drop)]
    pub struct Tix {}

    #[generate_trait]
    pub impl TixImpl of TixTrait {
        fn jeg() {
            let lor = MyStruct {};
        }
    }
}
```

Можна дати модулю або типу псевдонім за допомогою синтаксису `use core::array::ArrayTrait as Arr;`, а потім використовувати цей псевдонім усюди, де можна було б використати сам модуль або тип.
