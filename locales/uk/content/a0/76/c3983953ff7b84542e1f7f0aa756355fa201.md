# Докладніше

`when` - ключове слово для фільтрування винятків. Його ставлять після інструкції `catch`, і воно може приймати булевий вираз (англ. Boolean), що містить будь-які значення, які на той момент є в області видимості. Ці значення не обовʼязково мають бути членами самого винятку. Якщо тип винятку збігається, а вираз обчислюється як правда, то виконується блок, повʼязаний із цією інструкцією `catch`; інакше перевіряється наступна інструкція `catch`, якщо вона взагалі є.

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```

- Ця стаття [Фільтри винятків][exception-filters] показує, як фільтрувати винятки.

[exception-filters]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/when
