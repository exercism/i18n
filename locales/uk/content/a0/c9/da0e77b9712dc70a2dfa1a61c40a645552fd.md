# Інструкції

Недалеко є магазин побутової техніки під назвою «Tech Palace».
Власник магазину нещодавно встановив великий дисплей, щоб показувати рекламні повідомлення та особливе вітання, коли покупці сканують свої картки лояльності біля входу.
Дисплей складається з безлічі дрібних світлодіодів і може показувати кілька рядків тексту.

Власникові магазину потрібна наша допомога з кодом, який генерує текст для нового дисплея.

## 1. Створіть вітальне повідомлення

<!-- markdownlint-disable-next-line MD038 -->
Для більшості покупців, які сканують свої картки лояльності, власник хоче бачити на дисплеї `Welcome to the Tech Palace, `, за яким іде імʼя покупця великими літерами.

Реалізуйте функцію `welcome_message`, яка приймає імʼя покупця як короткий рядок тексту (англ. string) в аргументі типу `felt252` і повертає потрібне повідомлення як `ByteArray`.

```rust
welcome_message("Judy")
// => Welcome to the Tech Palace, JUDY
```

## 2. Додайте декоративну рамку

Для постійних покупців, які багато купують у магазині, власник хоче зробити вітальне повідомлення на дисплеї більш ошатним, додавши рядок зірочок перед вітальним повідомленням і після нього.
Він ще не визначив, скільки зірочок має бути в рядках, тому хоче, щоб це можна було налаштувати.

Напишіть функцію `add_border`, яка приймає вітальне повідомлення (типу `ByteArray`) і кількість зірочок у рядку (тип `u32`) як аргументи.
Вона має повернути `ByteArray`, що складається з 3 рядків: рядка з потрібною кількістю зірочок, потім вітального повідомлення в тому вигляді, у якому його передали, і ще одного рядка зірочок.

```rust
add_border("Welcome!", 10)
```

Має повернути таке:

```bash
**********
Welcome!
**********
```

## 3. Приберіть старі рекламні повідомлення

Перед встановленням цього нового дисплея в магазині був схожий дисплей, який міг показувати лише статичні рядки, які не можна було налаштувати.
Власник хотів би використати частину старих рекламних повідомлень на новому дисплеї.
Однак у цих даних уже є рамка із зірочок і деякі небажані пробільні символи.
Наше завдання - прибрати все зайве з повідомлень, щоб їх можна було використати знову.

Реалізуйте функцію `clean_up_message`, яка приймає старе рекламне повідомлення як `ByteArray`.
Спочатку функція має прибрати з тексту всі зірочки, а потім прибрати пробільні символи на початку й у кінці того, що залишилося.
Після цього функція має повернути очищене повідомлення.

```rust
let message: ByteArray = "
**************************
*    BUY NOW, SAVE 10%   *
**************************
";

clean_up_message(message)
// => BUY NOW, SAVE 10%
```
