Приберіть усі явні виклики `Boolean(...)`.

У JavaScript результат виразу не потрібно _приводити_ до певного типу. Наприклад, результат бінарного виразу можна повернути як є, і він не потребує ще одного виклику, щоб зробити його `boolean`.

```javascript
// instead of
return Boolean(some_expression);

// ...In JavaScript, in general, values don't need to be explicitly changed
return some_expression;
```
