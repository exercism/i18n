# Додаток до інструкцій

## Робота з датами в Prolog

Вбудована підтримка дат у Prolog [досить елементарна][built-in-dates-support]. Значно зручніший спосіб працювати з датами - [пакет date_time][date_time-package].

### Встановлення пакета date_time

Якщо встановлена версія Swipl досить свіжа, пакет можна встановити командою:

```bash
swipl pack install date_time
```

Якщо це не спрацює, виконайте:

```shell
swipl -g 'pack_install(date_time)'
```

~~~~exercism/note
У онлайн-редакторі нічого не потрібно встановлювати вручну.
~~~~

### Використання пакета date_time

Додайте наведений код на початок файлу з рішенням, щоб скористатися пакетом `date_time`:

```prolog
:- use_module(library(date_time)).
```

~~~~exercism/note
Порада: [джерело пакета date_time][https://www.swi-prolog.org/pack/file_details/date_time/prolog/date_time.pl?show=src] добре задокументоване і може стати в пригоді!
~~~~
