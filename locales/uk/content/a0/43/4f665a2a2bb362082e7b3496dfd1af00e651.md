# Вступ

У Haxe **масив** - це колекція елементів (зазвичай) одного типу. У Haxe є три способи створити масив: за допомогою конструктора або синтаксису оголошення. У Haxe перший елемент масиву має індекс нуль:

```haxe
var a = [1, 2, 3];
trace(a); // [1,2,3]

// Here the second element is called by index
trace(a[1]); // 2

// The actual first element's index is 0
trace(a[0]); // 1
```

Щоб створити масив за допомогою конструктора, потрібно передати тип елементів, які будуть включені до масиву:

```haxe
var a:Array<Int> = [0, 1, 2, 3];
a[1] = "Hello"; // Error: the array a takes integers only
```

Якщо ми хочемо, щоб масив містив елементи різних типів, ми додаємо тип `Dynamic` до позначення типу:

```haxe
var a:Array<Dynamic> = [10, "Bob", true]
```
