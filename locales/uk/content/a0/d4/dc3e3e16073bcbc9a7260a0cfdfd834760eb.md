# Додаток до інструкцій

## Регістри

| Регістр | Використання | Тип | Опис |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | вхідні дані        | адреса | вхідний рядок тексту (англ. string), завершений нульовим символом  |
| `$a1`    | вхідні дані        | ціле число | ключ зсуву                     |
| `$a2`    | вхідні/вихідні дані | адреса | рядок тексту результату, завершений нульовим символом |
| `$t0-9`  | тимчасовий    | будь-який     | для тимчасового зберігання         |
