# Інструкції

Ми завзятий спостерігач за птахами й ведемо облік того, скільки птахів завітало до нашого саду.
Зазвичай ми ведемо підрахунок у записнику, але хочемо працювати з даними зручніше.
Ми вже оцифрували щоденні підрахунки птахів за минулі тижні, які вели в записнику.

Тепер ми хочемо визначити загальну кількість порахованих птахів, обчислити кількість птахів за конкретний тиждень і виправити помилку в підрахунку.

## 1. Визначте загальну кількість птахів, яких ми порахували на цей момент

Почнімо аналізувати дані із загального огляду.
Зʼясуйте, скільки всього птахів ми порахували відтоді, як почали вести записи.

Реалізуйте функцію `totalBirdCount`, яка приймає обʼєкт, подібний до масиву, з кількістю птахів за кожен день.
Вона має повернути загальну кількість порахованих птахів.

```javascript
birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1];
totalBirdCount(birdsPerDay);
// => 34
```

## 2. Обчисліть кількість птахів, що завітали, за конкретний тиждень

Тепер, коли ми маємо загальне уявлення про свої підраунки птахів, хочеться перейти до детальнішого аналізу.

Реалізуйте функцію `birdsInWeek`, яка приймає обʼєкт, подібний до масиву, з підрахунками птахів за кожен день, і номер тижня.
Вона повертає загальну кількість птахів, порахованих за цей конкретний тиждень.
Можна припустити, що тижні завжди записані повністю.

```javascript
birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1];
birdsInWeek(birdsPerDay, 2);
// => 12
```

## 3. Виправте помилку в підрахунку

Ми зрозуміли, що весь час, поки ми намагалися стежити за птахами, один птах ховався в далекому куточку саду.
Ми зʼясували, що цей птах завжди проводив у нашому саду кожен другий день.
Ми не знаємо точно, де він був у проміжні дні, але точно не в нашому саду.
Інтуїція спостерігача за птахами також підказує, що цей птах був у нашому саду першого дня, записаного в нашому списку.

З огляду на цю нову інформацію, напишіть функцію `fixBirdCountLog`, яка приймає як аргумент обʼєкт, подібний до масиву, з кількістю птахів, порахованих за кожен день. Вона має виправити помилку в підрахунку, змінивши переданий масив.

```javascript
birdsPerDay = [2, 5, 0, 7, 4, 1];
fixBirdCountLog(birdsPerDay);
// => [3, 5, 1, 7, 5, 1]
```
