# Вступ

У багатьох мовах є щось на кшталт `null` або `none`, щоб позначити неіснуюче значення.
Оскільки R створено для роботи з великими обсягами (часто неохайних) даних, у ньому є кілька форм ніщо.

Загальна мета - позначати відсутні або підозрілі значення, щойно ми з ними стикаємося, а потім продовжувати роботу, не викликаючи винятку.

## NULL

Якщо значення справді не існує, його позначають як `NULL`. Це, ймовірно, найближче до того, як поводилися б C або Python.

```R
v <- c() # zero-length vector
v
#> NULL
is.null(v)
#> [1] TRUE
```

У багатьох контекстах значення `NULL` просто ігноруються:

```R
c(2, 3, NULL, 5)
#> [1] 2 3 5
```

## NA

Для ситуацій, коли значення існує, але ми не знаємо, яке воно, використовують `NA`. Наприклад, коли рахують машини, що їдуть дорогою, живі спостерігачі можуть піти на лікарняний, а автоматичні датчики вийти з ладу, але потік транспорту не припиняється.

```R
v <- c(1, 2, NA, 4, 5)
v
#> [1]  1  2 NA 4  5
is.na(v) # test for data gaps
#> [1] FALSE FALSE  TRUE FALSE FALSE
```

Отже, `NA` слугує заповнювачем, який попереджає людей, що їм потрібно вирішити, як із цим поводитися.

## NaN

`NaN` (скорочення від «Not a Number») сигналізує про проблему з обчисленням у ситуаціях, де очікували число.

```R
n <- c(0, 2, 4)
d <- c(0, 1, 2)
n / d
#> [1] NaN   2   2  # 0/0 is mathematically undefined
is.nan(n / d)
#> [1]  TRUE FALSE FALSE
```

Це не єдина можливість для «некоректних» обчислень.
Ділення на нуль поверне `Inf` або `-Inf` для ненульового чисельника, і не викличе помилки.

```R
1 / 0
#> [1] Inf
```

## Порожні вектори

Можливо, на подив, у R немає стандартного способу перевірити порожнечу.

Навіть створити порожній вектор не зовсім очевидно.
У попередньому розділі ми бачили, що `c()` без аргументів повертає `NULL`, а не вектор.

```R
is.vector(c())
#> [1] FALSE
```

Такі функції, як `logical()` або `integer()`, приймають аргумент, що задає бажану довжину, яка може дорівнювати нулю.

```R
z <- logical(0)
is.vector(z)
#> [1] TRUE
length(z)
#> [1] 0
```

Ми також можемо створити вектор, а потім прибрати з нього кожен елемент, як описано в [концепції векторів][concept-vectors].
У результаті отримаємо вектор довжини 0 відповідного типу.

```R
v <- 5
v[-1]  # delete the first element
#> numeric(0)
```

[concept-vectors]: https://exercism.org/tracks/r/concepts/vectors
