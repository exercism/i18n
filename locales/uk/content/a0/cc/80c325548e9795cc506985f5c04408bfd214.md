# Інструкції

У цій вправі ми напишемо трохи коду, який допоможе приготувати чудову лазанью з нашої улюбленої кулінарної книги.

На нас чекають чотири завдання, усі повʼязані з часом, витраченим на приготування лазаньї.

## 1. Визначте очікуваний час у духовці в хвилинах

Визначте метод `expectedMinutesInOven()`, який не приймає жодних параметрів і повертає, скільки хвилин лазанья має провести в духовці. Згідно з кулінарною книгою, очікуваний час у духовці становить 40 хвилин:

```java
Lasagna lasagna = new Lasagna();
lasagna.expectedMinutesInOven();
// => 40
```

## 2. Обчисліть залишковий час у духовці в хвилинах

Визначте метод `remainingMinutesInOven()`, який приймає як параметр фактичну кількість хвилин, які лазанья вже провела в духовці, і повертає, скільки хвилин їй ще залишилося там провести, виходячи з очікуваного часу в духовці з попереднього завдання.

```java
Lasagna lasagna = new Lasagna();
lasagna.remainingMinutesInOven(30);
// => 10
```

## 3. Обчисліть час на підготовку в хвилинах

Визначте метод `preparationTimeInMinutes()`, який приймає як параметр кількість шарів, доданих до лазаньї, і повертає, скільки хвилин ми витратили на її підготовку, якщо припустити, що на кожен шар потрібно 2 хвилини.

```java
Lasagna lasagna = new Lasagna();
lasagna.preparationTimeInMinutes(2);
// => 4
```

## 4. Обчисліть загальний час роботи в хвилинах

Визначте метод `totalTimeInMinutes()`, який приймає два параметри: перший параметр - це кількість шарів, доданих до лазаньї, а другий - кількість хвилин, які лазанья провела в духовці. Функція має повернути, скільки хвилин у сумі ми витратили на приготування лазаньї, тобто суму часу на підготовку в хвилинах і часу в хвилинах, які лазанья на цей момент провела в духовці.

```java
Lasagna lasagna = new Lasagna();
lasagna.totalTimeInMinutes(3, 20);
// => 26
```
