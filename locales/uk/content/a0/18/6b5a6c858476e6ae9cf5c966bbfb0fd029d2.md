# Ресурси

Існує багато чудових безкоштовних онлайн-ресурсів для Lua, зокрема:

1.  [lua.org][8]
2.  Дуже рекомендований докладний і авторитетний вступ до всіх аспектів програмування Lua від головного архітектора Lua: [Programming in Lua, by Roberto Ierusalimschy][6]
3.  За офіційним визначенням мови Lua варто звернутися до [Lua 5.4 Reference Manual][7] авторства R. Ierusalimschy, L. H. de Figueiredo, W. Celes.
4.  [Lua Style Guide][4]
5.  [Learn Lua in 15 minutes][5]
6.  Хоча вікі [lua-users.org][14] і не має гарного вигляду, вона містить багато корисної інформації та знань
7.  Деякі варіанти для лінтингу
    -   [luacheck][12]
    -   [Detecting Undefined Variables][13]
8.  Реалізації Language Server Protocol для Lua
    -   [Lua Language Server][9]
    -   [EmmyLua-LanguageServer][10]
