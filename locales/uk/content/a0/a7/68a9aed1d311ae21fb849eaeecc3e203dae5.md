# Підказки

## 1. Розбити рядок тексту на окремі рядки

- Swift має [метод][nsstring-components-docs] для розбиття рядка тексту (англ. string) на масив рядків тексту за допомогою заданого розділювача.

## 2. Вхідні двері

- Вартовий продекламує вірш, і його потрібно буде розбити на окремі рядки. Для цього можна скористатися вже наявною функцією.
- Можна скористатися циклом `for`, щоб перебрати рядки вірша.
- Можна скористатися властивістю `first` рядка тексту, щоб отримати перший символ.
- Щоб зберегти перший символ кожного рядка, можна скористатися масивом символів або рядком тексту.

## 3. Задні двері

- Вартовий продекламує вірш, і його потрібно буде розбити на окремі рядки. Для цього можна скористатися вже наявною функцією.
- Можна скористатися циклом `for`, щоб перебрати рядки вірша.
- Можна скористатися властивістю `last` рядка тексту, щоб отримати останній символ.
- Щоб зберегти останній символ кожного рядка, можна скористатися масивом символів або рядком тексту.

## 4. Таємна кімната

- Вартовий продекламує вірш, і його потрібно буде розбити на окремі рядки. Для цього можна скористатися вже наявною функцією.
- Можна скористатися циклом `for`, який перебирає індекси в межах довжини рядків вірша.
- Swift має [метод][indexing] для отримання символу за вказаним індексом у рядку тексту.
- Swift має [метод][uppercased] для перетворення рядка тексту на верхній регістр.
