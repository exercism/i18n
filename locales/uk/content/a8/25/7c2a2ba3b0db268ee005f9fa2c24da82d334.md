# Інструкції

У цій вправі ми напишемо код, який допоможе фрилансеру спілкуватися з менеджером проєкту.
Наше завдання - надати кілька утиліт для швидкого обчислення денної та місячної ставок, за потреби з урахуванням заданої знижки.

Спершу встановімо кілька правил між фрилансером і менеджером проєкту:

- Денна ставка у 8 разів більша за погодинну.
- У місяці 22 оплачувані дні.

Іноді фрилансер пропонує застосувати знижку до своєї денної ставки (наприклад, для найвідданіших клієнтів або для неприбуткових організацій).

Знижки подаються як дробові числа, що позначають відсотки, наприклад `25.0` (25%).

~~~~exercism/note
Ось суфікси для інструкцій з плаваючою комою:

| Суфікс | Розмір операнда |
|--------|-----------------|
| `ss`   | 32-бітний       |
| `sd`   | 64-бітний       |

Ось деякі з інструкцій, згаданих у цій концепції:

| Інструкція              | Опис                                                       |
|-------------------------|------------------------------------------------------------|
| movss/movsd a, b        | копіює b в a                                               |
| addss/addsd a, b        | a = a + b                                                  |
| subss/subsd a, b        | a = a - b                                                  |
| mulss/mulsd a, b        | a = a * b                                                  |
| divss/divsd a, b        | a = a / b                                                  |
| cvtsi2ss/cvtsi2sd a, b  | перетворює ціле число b на число a з плаваючою комою       |
| roundss/roundsd a, b, c | округлює число b з плаваючою комою відповідно до c і зберігає результат у a |
| cvtss2si/cvtsd2si a, b  | перетворює число b з плаваючою комою на ціле число a        |
| comiss/comisd a, b      | порівнює a та b, виняток, якщо `NaN`                        |
| ucomiss/ucomisd a, b    | порівнює a та b, встановлює `PF`, якщо `NaN`                |

Ось числа керування округленням у `roundss` і `roundsd`:

| Число  | Режим                |
|:-------|:---------------------|
| 0      | До найближчого       |
| 1      | Униз (до меншого)    |
| 2      | Угору (до більшого)  |
| 3      | Відкинути дробову частину |
~~~~

## 1. Обчислити денну ставку за погодинною ставкою

Реалізуйте функцію `daily_rate`, яка обчислює денну ставку, отримуючи як параметр погодинну ставку у вигляді 64-бітного числа з плаваючою комою.
Умова визначає, що робочий день має 8 оплачуваних годин.

```c
daily_rate(60)
// => 480.0
```

Повернена денна ставка має бути 64-бітним числом з плаваючою комою.

## 2. Обчислити ціну зі знижкою

Реалізуйте функцію `apply_discount`, яка обчислює ціну після застосування знижки.
Вона має приймати два параметри: початкову ціну та розмір знижки у відсотках, обидва у вигляді 64-бітного числа з плаваючою комою.

```c
apply_discount(150.0, 10.0)
// => 135.0
```

Повернене значення завжди має бути 64-бітним числом з плаваючою комою.

## 3. Обчислити місячну ставку за погодинною ставкою та знижкою

Реалізуйте функцію `monthly_rate`, яка обчислює місячну ставку зі знижкою.
Вона приймає два параметри: погодинну ставку та знижку у відсотках, обидва у вигляді 64-бітного числа з плаваючою комою.

```c
monthly_rate(77.0, 10.5)
// => 12130
```

Повернену місячну ставку потрібно округлити вгору (взяти верхню межу) до найближчого 64-бітного цілого числа.

## 4. Обчислити кількість повних робочих днів за бюджетом, погодинною ставкою та знижкою

Реалізуйте функцію `days_in_budget`, яка приймає такі параметри:

1. Бюджет у вигляді 64-бітного беззнакового цілого числа.
2. Погодинну ставку у вигляді 64-бітного числа з плаваючою комою.
3. Знижку у відсотках у вигляді 64-бітного числа з плаваючою комою.

Ця функція має повернути кількість повних днів роботи, які покриває бюджет.

```c
days_in_budget(20000, 80, 11.0)
// => 35
```

Повернену кількість днів потрібно округлити вниз (взяти нижню межу) до найближчого 32-бітного цілого числа.
