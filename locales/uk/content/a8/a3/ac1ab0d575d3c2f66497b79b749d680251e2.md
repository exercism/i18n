# Вступ

Цикл `for` - одна з найуживаніших інструкцій для багаторазового виконання певної логіки.
У JavaScript він складається з ключового слова `for`, _заголовка_ в круглих дужках (`()`) і блоку коду, що містить _тіло_ циклу у фігурних дужках (`{}`).

```javascript
for (initialization; condition; step) {
  // code that is executed repeatedly as long as the condition is true
}
```

Ініціалізація зазвичай створює змінну-лічильник, умова перевіряє, чи слід продовжувати чи зупиняти цикл, а крок збільшує лічильник наприкінці кожного повторення.
Окремі частини заголовка розділені крапками з комою.

```javascript
const list = ['a', 'b', 'c'];
for (let i = 0; i < list.length; i++) {
  // code that should be executed for each item list[i]
}
```

Визначення кроку часто роблять за допомогою оператора інкременту або декременту JavaScript, як показано в прикладі вище.
Ці оператори змінюють значення змінної на місці.
`++` додає одиницю до числа, `--` віднімає одиницю від числа.

```javascript
let i = 3;
i++;
// i is now 4

let j = 0;
j--;
// j is now -1
```
