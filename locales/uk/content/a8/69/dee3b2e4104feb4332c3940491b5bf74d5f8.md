# Вступ

Поведінки дозволяють нам визначати інтерфейси (набори функцій і макросів) у _модулі поведінки_, які згодом можуть бути реалізовані різними _модулями зворотного виклику_. Завдяки спільному інтерфейсу ці модулі зворотного виклику можна використовувати взаємозамінно.

~~~~exercism/note
Звернімо увагу на британське написання «behaviours».
~~~~

## Визначення поведінок

Щоб визначити поведінку, нам потрібно створити новий модуль і вказати список функцій, які є частиною бажаного інтерфейсу. Кожну функцію потрібно визначити за допомогою атрибута модуля `@callback`. Синтаксис ідентичний до [специфікації типу функції][concept-typespecs] (`@spec`). Потрібно вказати назву функції, список типів аргументів і всі можливі типи повернених значень.

```elixir
defmodule Countable do
  @callback count(collection :: any) :: pos_integer
end
```

## Реалізація поведінок

Щоб додати наявну поведінку до нашого модуля (створити модуль зворотного виклику), ми використовуємо атрибут модуля `@behaviour`. Його значенням має бути назва модуля поведінки, який ми додаємо.

Потім нам потрібно визначити всі функції (зворотні виклики), які вимагає цей модуль поведінки. Якщо ми реалізуємо чужу поведінку, як-от вбудовані поведінки Elixir `Access` або `GenServer`, список усіх зворотних викликів цієї поведінки можна знайти в документації на [hexdocs.pm][hexdocs].

Модуль зворотного виклику не обмежується реалізацією лише тих функцій, що є частиною його поведінки. Також можливо, щоб один модуль реалізовував кілька поведінок.

Щоб позначити, яка функція належить якій поведінці, слід використовувати атрибут модуля `@impl` перед кожною функцією. Його значенням має бути назва модуля поведінки, що визначає цей зворотний виклик.

```elixir
defmodule BookCollection do
  @behaviour Countable

  defstruct [:list, :owner]

  @impl Countable
  def count(collection) do
    Enum.count(collection.list)
  end

  def mark_as_read(collection, book) do
    # other function unrelated to the Countable behaviour
  end
end
```

## Типові реалізації зворотних викликів

Визначаючи поведінку, можна надати типову реалізацію зворотного виклику. Цю реалізацію слід визначити в цитованому виразі макроса `__using__/1`. Щоб користувачі модуля поведінки могли перевизначити типову реалізацію, викличмо макрос `defoverridable/1` після реалізації функції. Він приймає список ключових слів, де ключі - назви функцій, а значення - їхні арності.

```elixir
defmodule Countable do
  @callback count(collection :: any) :: pos_integer

  defmacro __using__(_) do
    quote do
      @behaviour Countable
      def count(collection), do: Enum.count(collection)
      defoverridable count: 1
    end
  end
end
```

Звернімо увагу, що визначати функції всередині `__using__/1` не рекомендується для будь-якої іншої мети, крім визначення типових реалізацій зворотних викликів, але ми завжди можемо визначити функції в іншому модулі та імпортувати їх у макросі `__using__/1`.
