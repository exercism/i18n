# Інструкції

Ми розробляємо нову гру **Wings Quest**, яка має стати надзвичайно популярною.
У грі ми граємо за птаха, який рухається та збирає насіння.
Гравець перемагає, коли збирає все насіння.
Якщо гравець торкнеться орла, він втратить усе своє насіння і програє.
Із цього правила є виняток: гравець може мати активний підсилювач, який дозволяє йому літати вище за інших птахів.

Наша мета - написати кілька правил, які будуть використовуватися у грі.

## 1. Визначити, чи отримує птах бонусні очки

У грі птах отримує бонусні очки, якщо торкається орла, маючи активний підсилювач.

Визначимо функцію `bonusPoints(powerUpActive:touchingEagle:)`, яка приймає два аргументи: `powerUpActive`, що показує, чи має птах активний підсилювач, та аргумент `touchingEagle`, що показує, чи торкається птах орла.
Функція повинна повертати `true`, лише якщо птах має активний підсилювач і торкається орла, і повертати `false` в іншому випадку.

```Swift
bonusPoints(powerUpActive: false, touchingEagle: true)
// Returns false
```

## 2. Визначити, чи набирає птах очки

У грі гравець набирає очки, коли підбирає насіння або підсилювач.

Визначимо функцію `score(touchingPowerUp:touchingSeed:)`, яка приймає два аргументи: `touchingPowerUp`, що показує, чи торкається птах підсилювача, та аргумент `touchingSeed`, що показує, чи торкається птах насіння.
Функція повинна повертати `true`, якщо птах торкається підсилювача або насіння, і повертати `false` в іншому випадку.

```Swift
score(touchingPowerUp: true, touchingSeed: true)
// Returns true
```

## 3. Визначити, чи програє птах

Визначимо функцію `lose(powerUpActive:touchingEagle:)`, яка приймає два аргументи: `powerUpActive`, що показує, чи має птах активний підсилювач, та аргумент `touchingEagle`, що показує, чи торкається птах орла.
Функція повинна повертати `true`, якщо персонаж торкається орла і не має активного підсилювача, і повертати `false` в іншому випадку.

```Swift
lose(powerUpActive: false, touchingEagle: true)
// Returns true
```

## 4. Визначити, чи перемагає птах

Визначимо функцію `win(hasPickedUpAllSeeds:powerUpActive:touchingEagle:)`, яка приймає такі аргументи:

- `hasPickedUpAllSeeds` показує, чи зібрав птах усе насіння.
- `powerUpActive` показує, чи має птах активний підсилювач.
- `touchingEagle` показує, чи торкається птах орла.

Функція повинна повертати `true`, якщо птах зібрав усе насіння і не програв згідно з аргументами, визначеними в частині 3, і повертати `false` в іншому випадку.

```Swift
win(hasPickedUpAllSeeds: false, powerUpActive: true, touchingEagle: false)
// Returns false
```
