# без rescue

Не використовуйте винятки для керування потоком виконання.
Спробуйте розвʼязати цю вправу без `rescue`.

Якщо функція зі стандартної бібліотеки має назву, що закінчується на `!` (вона викидає помилки), пошукайте еквівалентну функцію без `!` (часто такі функції повертають `{:ok, result}` або `{:error, message}`).

Примітка: якщо цей автоматичний коментар показано для вашого рішення, інші автоматичні коментарі можуть бути неточними.
Спершу виправте цю проблему!

```elixir
# preferred: for example `case`

case Date.new(1999, 13, 1) do
  {:ok, date} -> date
  {:error, _} -> nil
end

# discouraged: rescuing exceptions

try do
  Date.new!(1999, 13, 1)
rescue
  ArgumentError ->
    nil
end
```
