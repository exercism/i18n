# Явне повернення

Приберіть явне повернення, щоб спростити метод.

У Ruby метод повертає результат останньої обчисленої інструкції. Тому явно використовувати ключове слово `return` не потрібно, крім випадків, коли треба достроково повернутися з методу.

Наприклад, цей код виведе `16`, бо метод `multiply` повертає результат `a * b`, свого останнього виразу.

```ruby
def multiple(a, b)
  a * b
end

print multiple(2, 8)
```
