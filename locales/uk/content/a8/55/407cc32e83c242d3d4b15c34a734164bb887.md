# Докладніше

Константи задаються під час компіляції, і їх не можна переприсвоїти.
Щоб оголосити одну константу, скористаймося ключовим словом `const`:

```go
const greeting = "hello"
```

У блоці можна оголосити кілька констант.
Усередині блоку константа без явно заданого значення повторює попередній вираз:

```go
const (
    greeting    = "hello"
    buffSize    = 4096
    chunkSize   // 4096
)
```

Константи зазвичай оголошують на рівні пакета, хоча їх можна оголосити й усередині функції.

## Типізовані та нетипізовані константи

Якщо оголосити константу, не вказуючи тип, вона стає нетипізованою.
Нетипізована константа не має фіксованого типу; її значення визначає, з якими типами вона сумісна.
Доки базове значення сумісне, компілятор буде перетворювати його на потрібний тип при кожному використанні:

```go
const numA = 2

math.Sqrt(numA)  // numA is treated as float64 here
var numB int = numA  // numA is treated as int here
```

Типізована константа фіксує тип під час оголошення:

```go
const num int = 2

math.Sqrt(num)  // compile error because a float is expected
```

## Що може бути константою

Константи можуть містити лише булеві значення (англ. Boolean), числа, рядки тексту (англ. string) і руни.
Оскільки значення задаються під час компіляції, результат виклику функції не можна використати для константи.

```go
const s = math.Sqrt(4)  // compile error because the value isn't known at compile time
```

## Iota

Усередині блоку констант `iota` позначає позицію константи в цьому блоці:

```go
const (
    Sunday    = iota // 0
    Monday           // 1
    Tuesday          // 2
    Wednesday        // 3
)
```

Кожна наступна константа успадковує той самий вираз, а `iota` збільшується на одиницю.

`iota` також працює у виразах.

```go
const (
    _  = iota             // position 0: value discarded
    KB = 1 << (10 * iota) // position 1: 1 << 10 = 1024
    MB                    // position 2: 1 << 20 = 1048576
    GB                    // position 3: 1 << 30 = 1073741824
)
```
