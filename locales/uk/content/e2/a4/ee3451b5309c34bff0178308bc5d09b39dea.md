# Вказівки

Нам доручено створити бібліотеку для роботи з журналами, яка допоможе керувати журналами нашої організації.
Ця бібліотека дасть змогу визначати, який застосунок створив відповідний журнал, виправляти пошкоджені журнали та зʼясовувати, чи вкладається рядок журналу в задану межу символів.

## 1. Визначити, який застосунок створив журнал

Журнали надходять від багатьох застосунків, кожен з яких використовує власний формат журналювання.
Перед тим як зберегти журнал у системі агрегації журналів, потрібно визначити застосунок, який його створив.

Реалізуйте функцію `Application`, яка приймає рядок журналу й повертає застосунок, що створив цей рядок журналу.

Щоб визначити, який застосунок створив заданий рядок журналу, знайдіть у цьому рядку символ, указаний у наступній таблиці:

| Застосунок      | Символ | Кодова позиція Unicode |
|------------------|-----------|--------------------|
| `recommendation` | ❗        | `U+2757`           |
| `search`         | 🔍        | `U+1F50D`          |
| `weather`        | ☀         | `U+2600`           |

Якщо рядок журналу не містить жодного символу з таблиці вище, поверніть `default` тому, хто викликав функцію.
Якщо рядок журналу містить більше ніж один символ із таблиці вище, поверніть застосунок, що відповідає першому символу, знайденому в рядку журналу зліва направо.

```go
Application("❗ recommended search product 🔍")
// => recommendation
```

## 2. Виправити пошкоджені журнали

Через рідкісний, але постійний bug в інфраструктурі журналювання деякі символи в журналах можуть пошкоджуватися.
Присвятивши час визначенню пошкоджених символів та їхніх вихідних значень, ми вирішуємо оновити бібліотеку, щоб вона допомагала виправляти пошкоджені журнали.

Реалізуйте функцію `Replace`, яка приймає рядок журналу, пошкоджений символ і вихідне значення та повертає змінений рядок журналу, у якому всі входження пошкодженого символу замінено на вихідне значення.

```go
log := "please replace '👎' with '👍'"

Replace(log, '👎', '👍')
// => please replace '👍' with '👍'"
```

## 3. Визначити, чи можна показати журнал

Системи, що відповідають за показ журналів, мають обмеження на кількість символів, які можна показати в одному рядку журналу.
Тож користувачі просять додати до цієї бібліотеки допоміжну функцію, яка визначає, чи вкладається рядок журналу в задану межу символів.

Реалізуйте функцію `WithinLimit`, яка приймає рядок журналу й межу символів та повертає, чи вкладається рядок журналу в цю межу символів.

```go
WithinLimit("hello❗", 6)
// => true
```
