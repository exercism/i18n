# Вступ

[Структури][structs-and-classes] (які зазвичай називають *структурами*) - один із головних будівельних блоків програм мовою Swift.
Структури дозволяють створювати власні типи, які обʼєднують повʼязані властивості (дані) та методи (поведінку).
Насправді стандартні типи Swift, зокрема `Int`, `Double`, `Bool`, `String`, `Array` і `Dictionary`, усі реалізовано як структури.

## Визначення структур

Структуру визначають за допомогою ключового слова `struct`, після якого йде назва типу, а потім фігурні дужки з її визначенням.
За конвенцією Swift назви структур записують у `UpperCamelCase`:

```swift
struct CharacterStats {
    var health = 0.0
    var speed = 0
    var strength = 0
}
```

## Створення екземплярів

Визначення структури - це креслення.
Щоб створити *екземпляр* структури, потрібно викликати її ініціалізатор, написавши назву типу, а потім пару дужок:

```swift
var someStats = CharacterStats()
```

Так ми створюємо екземпляр, заповнений типовими значеннями властивостей із визначення.

Swift також автоматично генерує **ініціалізатор за членами** для структур, який дозволяє ініціалізувати властивості за назвою:

```swift
let customStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

## Доступ і зміна властивостей

Щоб звернутися до властивостей екземпляра або змінити їх, потрібно використовувати *точкову нотацію*:

```swift
var stats = CharacterStats()

print(stats.health) // Prints 0.0

stats.health = 87.3
print(stats.health) // Prints 87.3
```

Оскільки структури є типами-значеннями, щоб змінити властивості екземпляра, сам екземпляр потрібно оголосити за допомогою `var`.
Якщо екземпляр оголошено за допомогою `let`, усі його властивості стають незмінними.
