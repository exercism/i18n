# Докладніше

Хеш - це тип даних у Perl, який містить невпорядковану колекцію ключів у вигляді рядків тексту (англ. string), зіставлених зі скалярними значеннями.

Змінну-хеш зазвичай заповнюють, присвоюючи їй масив, наприклад: `my %scores = (Alice => 10, Bob => 15, Charlie => 20);`.

Елементи масиву зазвичай розділяють комами, але часто можна побачити так звану «товсту кому» `=>`, яка розділяє ключі та значення в масиві.
Її поведінка майже така сама, як у коми, але вона має додаткову перевагу: елемент ліворуч від неї інтерпретується як рядок тексту.

Хеш можна заповнити й присвоєнням окремим ключам, наприклад: `$scores{Alice} = 10;`.

До значень хеша можна дістатися, вказавши ключі через індекс, наприклад: `$scores{Bob} # 15`.

Ключі в хеші унікальні.
Якщо ключ задано кілька разів, збережеться лише останнє задане значення.

## Функції

Функції для роботи з хешами включають [keys][keys] і [values][values], які повертають відповідні частини хеша у вигляді масиву.
Масиви, які повертають функції [keys][keys] і [values][values], можуть бути корисними для функцій, що працюють з масивами, як-от [grep][grep], [map][map] і [sort][sort], а також для циклів [for][for].

Інші функції для роботи з хешами: [exists][exists] перевіряє, чи існує ключ у хеші (навіть якщо його значення `undef`), а [delete][delete] видаляє ключ із хеша.

## Відмінність сигілів

Коли ми отримуємо значення хеша, результат визначає відповідний сигіл.
Індекс `{}` у кінці назви змінної вказує Perl, що ми звертаємося до хеша з такою назвою.

```perl
my %names = (Alice => 10, Bob => 15, Charlie => 20);

$names{Alice}; # 10            <- A scalar
@names{Alice}; # (10)          <- A slice (with only one key, this probably isn't what you want. There will be a warning.)
%names{Alice}; # ('Alice', 10) <- A key/index + value slice

$names{'Bob', 'Charlie'}; #                            <- An error (disabled syntax for an ancient feature.)
@names{'Bob', 'Charlie'}; # (15, 20)                   <- A slice
%names{'Bob', 'Charlie'}; # ('Bob', 15, 'Charlie', 20) <- A key/index + value slice
```

Хоча це й дозволено, заради читабельності радимо не давати різним типам змінних однакову назву.
