# Інструкції

У цій вправі ми - великі фанати спорту, які щойно відкрили для себе пристрасть до баскетболу НБА.
Оскільки ми новачки в баскетболі НБА, ми глибоко занурюємося в історію НБА: відстежуємо команди, тренерів, їхню статистику перемог і поразок та порівнюємо їх між собою.

Оскільки в нас ще немає улюбленої команди, ми також розробимо алгоритм, який допоможе визначити, чи варто вболівати за ту чи іншу команду.
На нас чекає сім завдань, які допоможуть розробити власний алгоритм _уболівання за команду_.

## 1. Визначте модель

Визначте псевдонім типу `Coach` для запису з двома такими полями, у такому порядку:

- `name`: імʼя тренера, типу `String`.
- `formerPlayer`: показує, чи був тренер колишнім гравцем, типу `Bool`.

Визначте псевдонім типу `Stats` для запису з двома такими полями, у такому порядку:

- `wins`: кількість перемог, типу `Int`.
- `losses`: кількість поразок, типу `Int`.

Визначте псевдонім типу `Team` для запису з трьома такими полями, у такому порядку:

- `name`: назва команди, типу `String`.
- `coach`: тренер команди, типу `Coach`.
- `stats`: статистика команди, типу `Stats`.

## 2. Створіть команду

Нам потрібно взаємодіяти зі стороннім кодом, у якому є поняття команди, але який викликає наш код із параметрами в іншому порядку. Додайте функцію `createTeam` із такою сигнатурою `String -> Stats -> Coach -> Team`.

## 3. Замініть тренера

Власники клубів НБА нетерплячі, тож ми помітили, що погані результати команди часто призводять до заміни тренера.
Реалізуйте функцію `replaceCoach`, яка приймає нового тренера й команду як параметри та повертає команду, але з новим тренером:

```elm
let
    coach = { name = "Larry Bird", formerPlayer = True }
    stats = { wins = 58, losses =  24 }
    team = { name = "Indiana Pacers", coach = coach, stats =  stats }
    newCoach = { name = "Isiah Thomas", formerPlayer = True }
in
replaceCoach newCoach team
--> { name = "Indiana Pacers"
--  , coach = { name = "Isiah Thomas", formerPlayer = True }
--  , stats = { wins = 58, losses = 24 } }
```

## 4. Перевірте, чи варто вболівати за команду

У майбутньому ми плануємо створити складний алгоритм, який визначатиме, чи варто вболівати за команду, але для першої спроби ми вирішили вболівати за будь-яку команду, у якої більше перемог, ніж поразок.

Ми хочемо, щоб цю функцію можна було повторно використовувати в інших контекстах, тож використайте розширюваний запис у сигнатурі типу, щоб приймати будь-який запис із відповідними полями.
Щоб функція була якомога лаконічнішою, скористайтеся зіставленням зі зразком, щоб дістати `stats` із параметра функції.
Реалізуйте функцію `rootForTeam`, яка приймає команду та повертає `True`, якщо за цю команду варто вболівати; інакше повертає `False`.

```elm
let
    spursCoach = { name = "Gregg Popovich", formerPlayer =  False }
    spursStats = { wins = 56, losses = 26 }
    spursTeam = { name = "San Antonio Spurs", coach = spursCoach, stats = spursStats }
in
rootForTeam spursTeam
--> True
```
