# Вступ

## Жонглювання типами

Жонглювання типами також називають приведенням типів.
Жонглювання типами - це коли два значення різних типів зводяться до одного типу, щоб виконати операцію.

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15
```

Це може відбуватися неявно (див. приклад вище) або явно, за допомогою приведення типів у стилі `C`:

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

Для ручного приведення типів дозволені такі типи: `bool`, `int`, `float`, `string`, `array`, `object`.
Найчастіше приведення типів використовують, щоб перетворити ціле число (`int`) на число з плаваючою комою (`float`) або навпаки.
