# Докладніше

[Методи розширення][extension-methods] дають змогу додавати методи до наявних типів, не створюючи нового похідного типу, не перекомпільовуючи та не змінюючи початковий тип у будь-який інший спосіб.

Методи розширення - це статичні методи, але викликаються вони так, ніби є методами екземпляра розширюваного типу. Досягається це тим, що перед типом ставиться `this`, а це вказує: екземпляр, до якого ми ставимо `.`, передається як перший параметр. Для коду-клієнта немає помітної різниці між викликом методу розширення та методів, визначених у типі.

```csharp
namespace MyExtensions
{
    public static int WordCount(this string str)
    {
        return str.Split().Length;
    }
}

"Hello World".WordCount();
// => 2
```

Методи розширення потрапляють в область видимості на рівні простору імен. Це означає, що якщо ми перебуваємо в іншому просторі імен, ніж той, де визначено метод розширення, його простір імен спершу має бути в директиві `using`; наприклад, якби ми хотіли використати наведений вище приклад у своєму коді, нам спершу знадобилася б директива `using MyExtensions`. Якщо ми перебуваємо в тому самому просторі імен, де визначено метод розширення, ми можемо користуватися методами розширення без директиви `using`.

Добре відомий приклад методів розширення - стандартні оператори запитів [LINQ][linq], які додають функціональність запитів до наявних типів IEnumerable. Щоб увести їх в область видимості, нам потрібна директива `using System.Linq;`.

[extension-methods]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/classes-and-structs/extension-methods
