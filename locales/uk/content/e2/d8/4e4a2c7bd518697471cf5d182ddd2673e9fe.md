# Додаток до інструкцій

## Формат вихідних даних

Кожну національність позначено однією літерою. (`E` = `Englishman`, `J` = `Japanese`, `N` = `Norwegian`, `S` = `Spaniard`, `U` = `Ukrainian`)

## Регістри

| Регістр | Використання | Тип   | Опис                            |
| -------- | --------- | ------- | ---------------------------- |
| `$v0`    | вихідні дані    | байт    | національність того, хто пʼє воду |
| `$v1`    | вихідні дані    | байт    | національність власника зебри   |
| `$t0-9`  | тимчасовий | будь-який     | для тимчасового зберігання        |
