# Налагодження

Увесь вивід скрипта Red можна побачити в консолі, коли ми запускаємо кожен тест. Можна вивести через `print` усе, що завгодно, наприклад значення слів:

```red
print ["x =" x]
```

Також дуже корисна функція `probe`. Коли її обчислюють, вона обчислює власні вхідні дані, друкує результат так, щоб було видно його тип, і повертає його. Тож у більшості випадків вона «прозора», і її можна вставити всередину виразів:

```red
x: 10
y: probe x + 5
```

Іноді перевірити тип значення допоможе функція з назвою `type?` (так, у її назві є знак питання!):

```red
print ["x type:" type? x]
```

Є також кілька просунутіших технік налагодження, [перелічених у вікі Red](https://github.com/red/red/wiki/%5BDOC%5D-Debugging).
