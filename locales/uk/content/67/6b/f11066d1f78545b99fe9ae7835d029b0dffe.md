# Вступ

Словник (`dict`) у Python - це структура даних, яка зіставляє [хешовані][term-hashable] _ключі_ зі _значеннями_; в інших мовах програмування його називають динамічною [хеш-таблицею][hashtable-wikipedia], хешмапом або [асоціативним масивом][associative-array]. Словники - це єдиний вбудований у Python [тип відображення][mapping-types-dict].


`keys` мають бути хешованими та унікальними в межах словника.
Типи ключів можуть включати `number`, `str` або `tuple` (із _незмінних_ значень).
Вони не можуть містити _змінні_ структури даних, як-от `list`, `dict` або `set`.
Починаючи з Python 3.7, порядок ключів у `dict` гарантовано збігається з порядком, у якому додають записи.

`values` можуть мати будь-який тип даних або структуру.
Значення також можуть _довільно_ вкладатися одне в одне, тож вони можуть містити масиви масивів, вкладені словники та інші власні чи складені структури даних.

За відомим `key` словник може дістати `value` за сталий час (у середньому) (_незалежно від кількості записів_).
Порівняно з пошуком значення в `list` чи `array` (_коли позиція `index` невідома_), `dict` використовує значно більше памʼяті, але дістає дані дуже швидко.

Словники особливо корисні в ситуаціях, коли колекція елементів велика і до неї потрібно часто звертатися та часто її оновлювати.
