# Про

Elm - це повністю функціональна мова, тож у ній немає інструкцій, лише вирази, а кожна функція є одним виразом.

Це заохочує писати маленькі прості функції, і загалом це добре, але іноді функції неминуче складніші, і нам потрібен спосіб писати їх елегантно.

Саме тут стають у пригоді вирази `let`. Вони складаються з двох частин: розділу `let`, де можна створити стільки визначень, скільки потрібно, і розділу `in`, який є єдиним виразом, що може використовувати ці визначення.

У термінах програмування `let` створює область видимості, локальну для виразу в розділі `in`.

Вираз `let` стає в пригоді в кількох ситуаціях:

- для спрощення виразів
- щоб дати імена результатам проміжних виразів
- щоб розбити вираз на менші частини, якщо він стає завеликим

Усередині виразу `let` можна робити майже все, зокрема деструктуризацію, але ось що заборонено:

- власні типи
- псевдоніми типів
- затінення імен (не можна перевизначити чи повторно використати імʼя, яке вже є в області видимості)

## Спрощення виразів

Цей вираз додає куби трьох чисел, але читати його важко, і легко зробити так, що для різних чисел обчислення відрізнятиметься.

```elm
(a * a * a) + (b * b * b) + (c * c * c)
```

Ми можемо визначити функцію `cube` у виразі `let`, щоб зробити обчислення простішим, виразнішим і безпечнішим. Ця функція могла б мати анотацію типу, але в ідіоматичному коді Elm це трапляється порівняно рідко.

```elm
let
  cube x = x * x * x
in
  cube a + cube b + cube c
```

## Іменування результатів проміжних виразів

Цей код визначає sideArea і topArea, щоб зробити обчислення простішим і виразнішим.

```elm
cylinderArea : Float -> Float -> Float
cylinderArea radius height =
    let
        sideArea = 2 * pi * radius * height
        topArea = pi * radius ^2
    in
        sideArea + 2 * topArea
```

## Розбиття великого виразу

Цей код створює початковий візерунок для [Game of Life](https://playgameoflife.com/) (поширена вправа-приклад із програмування).

Не обовʼязково точно розуміти, як це працює, але, сподіваємося, видно, що якби записати це одним виразом, без `let`, воно було б дуже великим.

```elm
beginWithPattern : Size -> Padding -> Pattern -> GameOfLife
beginWithPattern minimumSize padding pattern =
    let
        size = calculateSize minimumSize padding pattern

        center = Size.center size

        centeredPattern = Pattern.centerAt center pattern

        dimensions = { width = size, height = size }

        deadCells = Matrix.create dimensions Dead
    in
    GameOfLife (bringPatternToLife deadCells centeredPattern)
```
