# Про

[Побітові бінарні функції][bitwise-wiki] можна застосовувати до цілих чисел за допомогою функцій із [модуля Bitwise][bitwise-hexdocs].

- [`band/2`][bitwise-and]: побітове AND
- [`bsl/2`][bitwise-shift-left]: побітовий зсув ліворуч
- [`bsr/2`][bitwise-shift-right]: побітовий зсув праворуч
- [`bxor/2`][bitwise-xor]: побітове XOR
- [`bor/2`][bitwise-or]: побітове OR
- [`bnot/1`][bitwise-not]: побітове NOT

```elixir
Bitwise.band(0b1110, 0b1001)
# => 8 # 0b1000

Bitwise.bxor(0b1110, 0b1001)
# => 7 # 0b0111
```
