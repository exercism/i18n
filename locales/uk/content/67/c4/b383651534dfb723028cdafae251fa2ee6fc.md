# Інструкції

Вивчімо основи внутрішніх таблиць ABAP.

У нашому класі є внутрішня таблиця з назвою `initial_data`. Вона має три стовпці: `GROUP`, `NUMBER` і `DESCRIPTION`.

```abap
TYPES group TYPE c LENGTH 1.
TYPES: BEGIN OF initial_type,
         group       TYPE group,
         number      TYPE i,
         description TYPE string,
       END OF initial_type,
       initial_data TYPE STANDARD TABLE OF initial_type WITH EMPTY KEY.
```

## Крок 1

Перше завдання: завершіть метод `fill_itab` і додайте до цієї таблиці 6 записів із такими значеннями:

| GROUP | NUMBER | DESCRIPTION |
| --- | ----------- | ----------- |
| A | 10 | Group A-2 |
| B | 5 | Group B |
| A | 6 | Group A-1 |
| C | 22 | Group C-1 |
| A | 13 | Group A-3 |
| C | 500 | Group C-2 |

## Крок 2

Далі реалізуйте метод `add_to_itab`, щоб додати запис у кінець внутрішньої таблиці з таким значенням:

| GROUP | NUMBER | DESCRIPTION |
| --- | ----------- | ----------- |
| A | 19 | Group A-4 |

## Крок 3

Тепер посортуйте внутрішню таблицю в методі `sort_itab`: стовпець `GROUP` - за абеткою, а стовпець `NUMBER` - за спаданням.

## Крок 4

У методі `search_itab` виконайте пошук у відсортованій таблиці та поверніть індекс запису, у якого значення стовпця `NUMBER` дорівнює 6.
