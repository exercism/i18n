# Вступ

Багато типів членів struct і класів (головним винятком є поля) можуть використовувати синтаксис членів із тілом-виразом. Визначення члена за допомогою виразу часто дає стисліший і зрозуміліший код, ніж традиційні блоки коду та інструкції.

Методи і властивості лише для читання належать до членів, які можна визначити за допомогою тіла-виразу.

```csharp
public int Times3(int input) => input * 3;

public int Interesting => 1729;
```
