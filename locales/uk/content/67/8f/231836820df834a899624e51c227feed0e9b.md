# Як користуватися Markdown у наставництві

Ми можемо використовувати Markdown у своїх коментарях наставника на GitHub.
Це дозволяє вбудовувати фрагменти коду, додавати заголовки, жирний шрифт, курсив, списки тощо, а також цитувати попередні речення.

На Exercism ми також дозволяємо деякі елементи «Github-flavoured Markdown», зокрема підсвічування синтаксису, таблиці та закреслений текст.

Якщо ми ще не знайомі з Markdown або з додатковими можливостями GitHub, радимо прочитати [посібник GitHub з Markdown](https://guides.github.com/features/mastering-markdown/).
