# Докладніше

У Haxe ієрархію класів можна визначити за допомогою _спадкування_, яке дозволяє похідному класу (`Car`) успадкувати поведінку та дані його батьківського класу (`Vehicle`).

У батьківському класі можна визначити:

- Методи, які можна перевизначити
- Абстрактні методи, які повинні реалізувати похідні класи

```haxe
abstract class Vehicle {
  public function new() {}

  // Can be overridden
  public function drive() {
    // ...
  }

  // Must be implemented
  public abstract function getSpeed():Int;
}

class Car extends Vehicle {
  public function new() {
    super(); // Runs the parent class' constructor
  }

  public override function drive() {
    // ...
  }

  public function getSpeed():Int {
    // ...
  }
}
```

Якщо в батьківського класу є конструктор, ми викликаємо його за допомогою `super()`:

```haxe
abstract class Vehicle {
  var wheels:Int;

  public function new(wheels:Int) {
    this.wheels = wheels
  }
}

class Car extends Vehicle {
  var color:String;

  public function new(wheels:Int, color:String) {
    super(wheels);
    this.color = color;
  }
}

```
