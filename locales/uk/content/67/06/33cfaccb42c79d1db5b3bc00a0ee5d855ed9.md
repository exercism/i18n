# Інструкції

У цій вправі ми працюватимемо з ощадними рахунками. Щороку баланс ощадного рахунку оновлюється відповідно до його відсоткової ставки. Відсоткова ставка, яку надає банк, залежить від суми грошей на рахунку (його балансу):

- 3.213% для відʼємного балансу (баланс стає ще більш відʼємним).
- 0.5% для додатного балансу, меншого за `1000` доларів.
- 1.621% для додатного балансу від `1000` доларів (включно) і меншого за `5000` доларів.
- 2.475% для додатного балансу від `5000` доларів (включно).

На нас чекає чотири завдання, і кожне з них стосуватиметься балансу та його відсоткової ставки.

## 1. Обчислити відсоткову ставку

Реалізуйте (_статичний_) метод `SavingsAccount.InterestRate()`, щоб обчислити відсоткову ставку на основі заданого балансу:

```csharp
SavingsAccount.InterestRate(balance: 200.75m)
// 0.5f
```

Зверніть увагу, що повернене значення має тип `float`.

## 2. Обчислити відсотки

Реалізуйте (_статичний_) метод `SavingsAccount.Interest()`, щоб обчислити відсотки на основі заданого балансу:

```csharp
SavingsAccount.Interest(balance: 200.75m)
// 1.00375m
```

Зверніть увагу, що повернене значення має тип `decimal`.

## 3. Обчислити річне оновлення балансу

Реалізуйте (_статичний_) метод `SavingsAccount.AnnualBalanceUpdate()`, щоб обчислити оновлений річний баланс з урахуванням відсоткової ставки:

```csharp
SavingsAccount.AnnualBalanceUpdate(balance: 200.75m)
// 201.75375m
```

Зверніть увагу, що повернене значення має тип `decimal`.

## 4. Обчислити кількість років до досягнення бажаного балансу

Реалізуйте (_статичний_) метод `SavingsAccount.YearsBeforeDesiredBalance()`, щоб обчислити мінімальну кількість років, потрібних для досягнення бажаного балансу за щорічного нарахування складних відсотків:

```csharp
SavingsAccount.YearsBeforeDesiredBalance(balance: 200.75m, targetBalance: 214.88m)
// 14
```

Зверніть увагу, що повернене значення має тип `int`.

~~~~exercism/note
Коли до початкового балансу застосовують прості відсотки, баланс множать на відсоткову ставку, а добуток цих двох величин дає суму відсотків.

Складні відсотки, зі свого боку, нараховують через регулярні проміжки часу.
Щоразу суму відсотків обчислюють і додають до початкового балансу, тож наступні нарахування відсотків відбуваються вже від більшого балансу.
~~~~
