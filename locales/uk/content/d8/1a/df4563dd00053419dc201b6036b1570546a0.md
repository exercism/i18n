# Вступ

Common Lisp надає кілька різних умовних виразів, головна відмінність між ними - кількість гілок, які вони підтримують.

- `when` та `unless` дозволяють лише одну гілку:

```lisp
(when (= 2 2) "All is well")      ; => "All is well"
(unless (= 2 2) "Time to panic!") ; => NIL
```

Частина після виразу-умови може містити більше ніж один вираз.

- `if` забезпечує класичну конструкцію if-then-else:

```lisp
(if (= 2 2) 'how-honest 'you-liar) ; => HOW-HONEST
```

Зауважмо, що і гілка then, і гілка else можуть містити лише один вираз.

- `cond` дає змогу мати кілька гілок без вкладання виразів `if`:

```lisp
(cond ((= 0 2) 'nope)
      ((= 1 2) 'try-again)
      ((= 2 2) 'quite-true)
      ((= 3 2) 'too-far)
      (t 'something-else))
; => QUITE-TRUE
```

Зауважмо, що кількість виразів після виразу-умови не обмежена. 

- `case` дає класичну конструкцію у стилі «switch»: вона перевіряє одне значення на відповідність кільком гілкам:

```lisp
(case 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark")
  (otherwise "???"))
; => "???"
```

Зауважмо, що, як і в `cond`, кількість виразів після виразу-умови не обмежена.
