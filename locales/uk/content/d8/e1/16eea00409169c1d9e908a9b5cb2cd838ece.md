# Вказівки

Нас попросили виконати ще трохи роботи над системою мережевої автентифікації.

Крім того, що під час розробки ідентифікаційні дані адміністратора жорстко закодовані в системі, керівництво також хоче, щоб зі старшими розробниками вчинили так само.

## 1. Зберегти дані системного адміністратора жорстко закодованими в системі й зробити їх доступними для викликів.

Дані адміністратора такі:

| Електронна пошта | Колір очей | Ширина фільтруму | Імʼя     | Адреса 1 | Адреса 2 |
| ---------------- | ---------- | ---------------- | -------- | -------- | -------- |
| admin@ex.ism     | green      | 0.9              | Chanakya | Mumbai   | India    |

Реалізуйте властивість `Authenticator.Admin`, щоб вона повертала ідентифікаційні дані системного адміністратора. Імʼя та кожна частина адреси мають бути в окремому елементі масиву `NameAndAddress`.

```csharp
var authenticator = new Authenticator();
authenticator.Admin;
// => {"admin@ex.ism", {"green", 0.9m}, ["Chanakya", "Mumbai", "India"]}
```

## 2. Зберегти дані розробників жорстко закодованими в системі й зробити їх доступними у вигляді словника

Дані розробників такі:

| Електронна пошта | Колір очей | Ширина фільтруму | Імʼя      | Адреса 1 | Адреса 2 |
| ---------------- | ---------- | ---------------- | --------- | -------- | -------- |
| bert@ex.ism      | blue       | 0.8              | Bertrand  | Paris    | France   |
| anders@ex.ism    | brown      | 0.85             | Anders    | Redmond  | USA      |

Реалізуйте властивість `Authenticator.Developers`, щоб вона повертала ідентифікаційні дані розробників. Ключем словника є імʼя розробника.

```csharp
var authenticator = new Authenticator();
authenticator.Developers;
// => ["Bertrand"] = {"bert@ex.ism", {"blue", 0.8m}, ["Bertrand", "Paris", "France"]},
// ["Anders"] = {"anders@ex.ism", {"brown", 0.85m}, ["Anders", "Redmond", "USA"]},

```
