# Інструкції

У цій вправі ми граємо в рольову гру, де різні типи бійців можуть битися один з одним.
Гра має різні правила для кожного типу бійців.
Ми зосередимося на двох конкретних типах: Warrior і Wizard.

Ось правила для Warrior:

- Warrior ніколи не буває вразливим.
- Warrior завдає `6` одиниць шкоди, якщо боєць, якого він атакує, не вразливий.
- Warrior завдає `10` одиниць шкоди, якщо боєць, якого він атакує, вразливий.

Ось правила для Wizard:

- Wizard може заздалегідь підготувати закляття.
- Wizard вразливий, якщо він не підготував закляття заздалегідь.
- Wizard завдає `12` одиниць шкоди, якщо він підготував закляття заздалегідь.
- Wizard завдає `3` одиниці шкоди, якщо він не підготував закляття заздалегідь.

## 1. Створіть клас `Warrior`

Створіть новий клас `Warrior`.
Цей клас має успадковувати наявний клас `Fighter`.

## 2. Опишіть Warrior

Оновіть клас `Warrior`, щоб його метод `toString()` описував, який це боєць.
Метод має повертати рядок тексту (англ. string) `"Fighter is a Warrior"`.

```java
Warrior warrior = new Warrior();
warrior.toString();
// => "Fighter is a Warrior"
```

## 3. Зробіть Warrior невразливими

Оновіть клас `Warrior`, щоб його метод `isVulnerable()` завжди повертав `false`.

```java
Warrior warrior = new Warrior();
warrior.isVulnerable();
// => false
```

## 4. Обчисліть одиниці шкоди для Warrior

Оновіть клас `Warrior`, щоб його метод `getDamagePoints(Fighter)` обчислював шкоду, яку завдає Warrior, згідно з правилами вище.

```java
Warrior warrior = new Warrior();
Wizard wizard = new Wizard();

warrior.getDamagePoints(wizard);
// => 10
```

## 5. Створіть клас `Wizard`

Створіть ще один новий клас `Wizard`.
Цей клас також має успадковувати наявний клас `Fighter`.

## 6. Опишіть Wizard

Оновіть клас `Wizard`, щоб його метод `toString()` описував, який це боєць.
Метод має повертати рядок тексту `"Fighter is a Wizard"`.

```java
Wizard wizard = new Wizard();
wizard.toString();
// => "Fighter is a Wizard"
```

## 7. Дозвольте Wizard готувати закляття і робіть їх вразливими, коли закляття не підготовлено

Оновіть клас `Wizard`, додавши метод `prepareSpell()`.
Клас має запамʼятовувати, коли цей метод викликано, і стежити за тим, щоб його метод `isVulnerable()` повертав `false` лише тоді, коли закляття підготовлено.

```java
Wizard wizard = new Wizard();
wizard.prepareSpell();
wizard.isVulnerable();
// => false
```

## 8. Обчисліть одиниці шкоди для Wizard

Оновіть клас `Wizard`, щоб його метод `getDamagePoints(Fighter)` обчислював шкоду, яку завдає Wizard, згідно з правилами вище.

```java
Wizard wizard = new Wizard();
Warrior warrior = new Warrior();

wizard.prepareSpell();
wizard.getDamagePoints(warrior);
// => 12
```
