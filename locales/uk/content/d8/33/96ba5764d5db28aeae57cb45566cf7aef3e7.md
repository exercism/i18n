# Про

[Цикли `repeat-while`][repeat-loops] схожі на цикли `while`, але відрізняються тим, що булевий вираз стоїть і обчислюється _після_ виконання тіла циклу. Як наслідок, такі цикли завжди виконуються принаймні один раз.

```swift
repeat {
  print("This runs at least once")
} while false
print("Loop done")

// prints:
// This runs at least once
// Loop done
```

[repeat-loops]: https://docs.swift.org/swift-book/LanguageGuide/ControlFlow.html#ID126
