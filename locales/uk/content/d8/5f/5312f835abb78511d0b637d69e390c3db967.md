# Фіктивний заголовок верхнього рівня

## Числа в Euphoria

У Euphoria `atom` може зберігати число будь-якого виду, а його підтип `integer` призначений для цілих чисел.
Цю вправу можна розвʼязати мовами, схожими на C, повертаючи беззнакове 64-бітне ціле число.

Однак цілі числа в Euphoria є знаковими й _на один біт менші за машинне слово_, тож для цієї вправи вони замалі, тоді як `atom` може зберігати більші цілі числа з потрібною точністю у 64 біти.

### 32-бітна версія

32-бітна версія Euphoria й досі існує, щоб застарілі застосунки могли й надалі використовувати наперед зібрані 32-бітні dll/so, коли 64-бітної версії немає, або ж обгортка для них сповнена жорстко закодованих 32-бітних зсувів.
Ця версія цілком непридатна для розвʼязання цього завдання, оскільки такі atom мають лише 53 біти точності.
Якщо в нас виникають труднощі з розвʼязанням цієї вправи локально, переконаймося, що ми використовуємо 64-бітну версію Euphoria.
