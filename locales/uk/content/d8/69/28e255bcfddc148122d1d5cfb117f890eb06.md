# Інструкції

Ми в поході в Новій Зеландії й беремо азимути за компасом. Азимут - це ціле число градусів, і це значення: обертання на 20 градусів не змінює взятого азимуту, а дає інший.

Напишіть `immutable class BEARING`. Заготовка вже містить заголовок класу та його атрибут.

## 1. Візьміть азимут

`create` приймає число градусів і повертає азимут. Градуси йдуть від 0 до 359, тож усе, що виходить за межі, загортається по колу: 370 стає 10, а -10 стає 350.

```sather
#BEARING(370).degrees
-- => 10
#BEARING(-10).degrees
-- => 350
```

## 2. Оберніть

`turned` приймає число градусів, на яке треба обернути, і повертає новий азимут. Обертання на відʼємне число градусів іде в інший бік. Азимут, для якого викликали метод, не змінюється.

```sather
#BEARING(350).turned(20).degrees
-- => 10
```

## 3. Порівняйте

`is_eq` приймає інший азимут і відповідає, чи вони однакові. Коли `is_eq` уже визначено, `=` працює з азимутами.

```sather
#BEARING(10) = #BEARING(370)
-- => true
```

## 4. Назвіть точку

`point` повертає сторону світу, до якої азимут найближчий, як одне з `"N"`, `"NE"`, `"E"`, `"SE"`, `"S"`, `"SW"`, `"W"`, `"NW"`.

Кожна сторона світу охоплює 45 градусів, центруючись на своєму точному азимуті: північ тягнеться від 337.5 через 0 до 22.5, північний схід - від 22.5 до 67.5, і так далі. Оскільки азимути тут - цілі числа, азимут 22 - це `"N"`, а 23 - це `"NE"`.

```sather
#BEARING(0).point
-- => "N"
#BEARING(90).point
-- => "E"
#BEARING(225).point
-- => "SW"
```

## 5. Запишіть його

`str` повертає градуси та сторону світу, як-от `"90 degrees (E)"`.

```sather
#BEARING(90).str
-- => "90 degrees (E)"
```
