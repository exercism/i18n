# Про Rust

Rust - це мова програмування для систем, яка працює блискавично швидко, запобігає помилкам сегментації та гарантує безпеку потоків.
Її мета - принести в системне програмування сучасний дизайн мов і розвинену систему типів.
Rust не використовує збирач сміття, натомість застосовує розвинений статичний аналіз, щоб забезпечити детерміноване звільнення памʼяті.
Цього вдається досягти завдяки концепції [володіння](https://doc.rust-lang.org/book/ch04-00-understanding-ownership.html).

Ядро Rust і стандартна бібліотека навмисно мінімальні; «батарейки» не входять до комплекту.
Замість цього растаціанцям радять додавати до мови бібліотеки, які називають _крейтами_, ділячись ними на [crates.io](https://crates.io/).

Найчастіше Rust використовують для застосунків, де важливі швидкість, продуктивність і стабільність.
Список [Awesome Rust](https://github.com/kud1ing/awesome-rust) збирає приклади проєктів на Rust, серед яких інструменти командного рядка, ORM, операційні системи та ігри.
Хоч би що ми створювали на Rust, це буде швидко й безпечно для памʼяті!

Домашня сторінка Rust - [rust-lang.org](https://www.rust-lang.org/).
У Rust чудова документація на [rust-lang.org/documentation.html](https://www.rust-lang.org/documentation.html).
Новачкам варто почати з «The Book», що доступна на [doc.rust-lang.org/book/](https://doc.rust-lang.org/book/).
