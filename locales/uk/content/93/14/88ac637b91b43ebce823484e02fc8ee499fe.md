# Підказки

## 1. Надрукувати бейдж для працівника

- [Шаблонний рядок][string-template] можна використати, щоб створювати рядки тексту (англ. string) для опису.
- Є [вбудований метод, щоб перетворити рядок тексту на верхній регістр][to-upper-case].

## 2. Надрукувати бейдж для нового працівника

- Перш ніж використовувати ідентифікатор, перевірмо, чи він дорівнює `null`.
- Можна використати [оператор рівності][kotlin-operators], щоб перевірити, чи значення дорівнює `null`.

## 3. Надрукувати бейдж для власника

- Можна використати [оператор Елвіса][elvis-operator], щоб узяти альтернативне значення, коли змінна дорівнює `null`.
