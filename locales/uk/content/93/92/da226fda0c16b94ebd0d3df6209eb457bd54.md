# Докладніше

Масиви в C# - це колекції примітивних значень або екземплярів структур чи класів. Вони реалізовані в базовій бібліотеці класів як [`List<T>`][lists-docs], де `T` - це тип елемента в масиві. Цей API надає багатий набір методів для створення та роботи з масивами.

```csharp
var listOfStrings = new List<string>();
var listOfIntegers = new List<int>();
var listOfRandoms = new List<Random>();
var listOfBigIntegers = new List<BigInteger>();
```

Визначення колекції зазвичай містить заповнювач у кутових дужках, часто за домовленістю це `T`. Так той, хто користується колекцією, може вказати, який тип елементів зберігати в ній.

На відміну від [concept:csharp/arrays](), масиви можуть динамічно змінювати свій розмір.

## LINQ

Хоча вбудований API `List<T>` багатий на можливості (зокрема відображення та фільтри, як-от `ConvertAll`, `FindAll` і `Foreach`), а його [синтаксис циклів][for-each] дуже зрозумілий, і з цим API справді варто ознайомитися, Language Integrated Query ([LINQ][linq]) доступний для багатьох завдань, він ще потужніший і широко використовується та має ту перевагу, що дає однаковий інтерфейс для бібліотечних колекцій, сторонніх колекцій і власних класів.
