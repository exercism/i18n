# Інструкції

У цій вправі ми будемо писати код для аналізу виробництва на складальному конвеєрі автомобільного заводу. Швидкість конвеєра може бути від `0` (вимкнено) до `10` (максимум).

На найнижчій швидкості (`1`) за годину виробляється `221` автомобіль. Виробництво зростає лінійно зі швидкістю. Тож за швидкості `4` конвеєр має виробляти `4 * 221 = 884` автомобілі за годину. Однак вища швидкість підвищує ймовірність випуску бракованих автомобілів, які потім доводиться викидати. Наведений нижче перелік показує, як швидкість впливає на показник успішності:

- `0`: 0% успішності.
- від `1` до `4`: 100% успішності.
- від `5` до `8`: 90% успішності.
- `9`: 80% успішності.
- `10`: 77% успішності.

Перед нами три завдання.

## 1. Обчисліть показник успішності

Реалізуйте функцію `successRate`, щоб обчислити показник успішності залежно від швидкості виробництва:

```fsharp
successRate 6
// => 0.9
```

## 2. Обчисліть продуктивність за годину

Реалізуйте функцію `productionRatePerHour`, щоб обчислити продуктивність конвеєра за годину з урахуванням показника успішності:

```fsharp
productionRatePerHour 6
// => 1193.4
```

Зауважмо, що повернене значення має тип `float`.

## 3. Обчисліть кількість робочих автомобілів, що виробляються за хвилину

Реалізуйте функцію `workingItemsPerMinute`, щоб обчислити, скільки робочих автомобілів виробляється за хвилину:

```fsharp
workingItemsPerMinute 6
// => 19
```

Зауважмо, що повернене значення має тип `int`.
