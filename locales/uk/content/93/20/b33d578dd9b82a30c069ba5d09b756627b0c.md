# Встановлення

Щоб установити Julia, дотримуйтеся інструкцій на [сторінці завантажень Julia](https://julialang.org/downloads/).

~~~~exercism/caution
Не радимо встановлювати Julia через менеджер пакетів операційної системи. Ці пакети не мають офіційної підтримки й можуть спричинити проблеми.
~~~~

Для локального встановлення доступні плагіни для багатьох редакторів і IDE. Найбільшою популярністю користується [розширення для VS Code](https://github.com/julia-vscode/julia-vscode). Інтеграції для інших редакторів можна знайти в організації [JuliaEditorSupport](https://github.com/JuliaEditorSupport) на GitHub.

Якщо хочеться більш інтерактивного середовища, можна скористатися Jupyter Notebook разом з [IJulia](https://github.com/JuliaLang/IJulia.jl) або [Pluto.jl](https://github.com/fonsp/Pluto.jl) для простих реактивних блокнотів на Julia.

Простий спосіб почати працювати з Julia без локального встановлення - [Nextjournal](https://nextjournal.com/), онлайн-IDE на основі блокнотів. До нього можна зайти з браузера, авторизуватися й одразу розвʼязувати вправи. Якщо потрібен лише онлайн-REPL, можна скористатися [Repl.it](https://repl.it/languages/julia).
