# Жонглювання типами

Жонглювання типами також називають приведенням типів.
Жонглювання типами відбувається тоді, коли два значення різних типів приводяться до одного типу, щоб виконати операцію.

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15 // int
```

Коли вираз обчислюється, значення рядка тексту (англ. string) неявно перетворюється на `int`, щоб відповідати очікуванням оператора `*`.
Рішення про те, до якого типу приводити, ухвалює PHP за правилами операції, і ці правила дуже різняться.

Приведення типів також відбувається під час виклику функцій і методів:

```php
strlen(12321);
# => 5
```

## Явне приведення типів

Замість того щоб покладатися на неявне приведення, ми можемо явно змусити значення обчислитися як певний тип за допомогою приведення типів у стилі `C`:

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

Це перетворить значення на тип, указаний у дужках `(...)`.
Як цільовий тип можна використати всі примітивні типи: `bool`, `int`, `float`, `string`, `array`, `object`.

## Лише тимчасове перетворення

Жонглювання типами або приведення **не змінює** тип значення, збереженого у змінній.
Перетворюються лише вхідні дані операції.

```php
$apples_per_basket = "3" // string
5 * $apples_per_basket
# $apples_per_basket => "3" // string

$my_number = (int) $apples_per_basket // cast string to int
# $apples_per_basket => "3" // string
```

## Втрата інформації

Коли значення приводять до іншого типу, у процесі може втрачатися інформація:

```php
$exact_distance = 15.5
$rough_distance = (int) $exact_distance
// => 15

$is_distant = (bool) $exact_distance
// => true

$erroneous_distance = (float) $is_distant
// => 1.0
```

Покладання на приведення, явне чи неявне, може спричиняти помилки у більшій системі.

## Явне приведення до `array` та `object`

Значення також можна привести до типів `array` та `object`.
Якщо значення, яке не є масивом чи обʼєктом, привести до `array`, воно перетворюється на єдиний елемент, наявний у масиві:

```php
$day_of_the_week = 'Monday';
(array) $day_of_the_week
// => array(1) {
//      [0]=>
//        string(6) "Monday"
//    }
```

Коли значення приводять до `object`, воно стає публічною властивістю з назвою `scalar`:

```php
$car = "Honda"
(object) $car
// => object(stdClass)#1 (1) {
//      ["scalar"]=>
//        string(5) "Honda"
//    }
```

> `stdClass` - це тип вбудованого в PHP анонімного класу.
