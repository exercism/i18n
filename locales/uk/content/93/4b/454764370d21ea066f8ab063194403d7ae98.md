# Незмінні класи

`SCOREBOARD` належить до речей, які змінюються. Два імені для одного табло бачать однаковий рахунок, бо є лише одне табло, і обидва імені вказують на нього.

Азимут не такий. `350 degrees` не стає чимось іншим; він просто *є*. Числа поводяться так само, як і рядки тексту (англ. string), і так само можуть поводитися власні класи.

## Незмінність

```sather
immutable class BEARING is

   readonly attr degrees : INT;

end; -- class BEARING
```

Два слова змінюють усе. Обʼєкт незмінного класу - це **значення**, а не річ, на яку вказують:

- його копіюють, коли присвоюють або передають, тож ніхто інший не може його змінити;
- він ніколи не може бути void;
- а його атрибутам не можна присвоювати значення.

## Зміна одного через створення іншого

Оскільки `degrees := 90` не дозволено, `attr` дає дещо інше: процедуру, яка приймає нове значення й повертає **новий обʼєкт** із цим значенням.

```sather
   b ::= b.degrees(90);      -- not b.degrees := 90
```

Оригінал залишається незміненим. У цьому весь прийом, і саме так записують `create`:

```sather
   create(d : INT) : SAME is
      b : SAME;                     -- starts with everything at nought
      return b.degrees(d);
   end;
```

Тут немає `new`. Незмінний обʼєкт існує завжди, тож `b : SAME` уже є таким, у якого кожен атрибут має порожнє значення.

Тож процедура, яка «змінює» азимут, повертає новий:

```sather
   turned(by : INT) : SAME is
      return #BEARING(degrees + by);
   end;
```

## Порівняння

Значення порівнюють за тим, що вони містять, а не за тим, яким обʼєктом вони є, але треба вказати, як саме. Напишіть `is_eq`, і `=` використає його:

```sather
   is_eq(other : SAME) : BOOL is
      return degrees = other.degrees;
   end;
```

Без нього `=` для двох азимутів не скомпілюється.

## Що обрати

Незмінний клас варто використовувати, коли річ не має власної ідентичності й ніщо в ній не може розумно змінюватися: азимут, точка, дата, довжина. Звичайний клас варто використовувати, коли річ є чимось конкретним, із чим щось відбувається: табло, стенд, файл.

Перевірка в тому, чи «той самий» означає «рівний», чи «той самий обʼєкт».
