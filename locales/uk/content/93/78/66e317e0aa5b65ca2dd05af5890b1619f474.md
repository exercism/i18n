# Остача

Порівняння за допомогою остачі цілком припустиме в Crystal, але для порівняння остачі від ділення зрозуміліше використати метод [`divisible_by?`][divisible_by].
Наприклад:

```crystal
# Rather than:
number %% 2 == 0

# Consider:
number.divisible_by?(2)
```

[divisible_by]: https://crystal-lang.org/api/latest/Int.html#divisible_by%%3F%%28num%%29%%3ABool-instance-method
