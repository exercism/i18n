# Вступ

## Масиви

`list` у F# - це незмінна колекція, що містить нуль або більше значень. Усі значення в масиві мають бути одного типу. Оскільки масиви незмінні, після створення масиву його значення вже ніколи не зміниться. Будь-які функції чи оператори, які нібито змінюють масив (наприклад, додають елемент), насправді повертають новий масив.

Масиви можна визначити так:

```fsharp
let empty = []
let singleValue = [5]
let threeValues = ["a"; "b"; "c"]
```

Найчастіше елемент додають до масиву за допомогою оператора `::` (cons):

```fsharp
let twoToFour = [2; 3; 4]
let oneToFour = 1 :: twoToFour
// => [1; 2; 3; 4]
```

Масив у F# має _голову_ (перший елемент) і _хвіст_ (усе, що йде після першого елемента). Хвіст масиву - це теж масив.

Масиви можна обробляти або за допомогою функцій і операторів, визначених у модулі `List`, або вручну, за допомогою зіставлення зі зразком, використовуючи зразки _list_ і _cons_:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | head::tail -> sprintf "Non-empty list with head: %d" head

describe []        // => "Empty list"
describe [1]       // => "Non-empty with head: 1"
describe [5; 7; 9] // => "Non-empty with head: 5"
```

Ми також можемо _відкинути_ значення під час зіставлення зі зразком; коли значення в конкретному випадку нам не важливе (тобто ми не збираємося його _використовувати_), можна позначити це символом підкреслення (`'_'`):

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [x] -> "List with one item"
    | [_; y] -> "List with two items (first item ignored)"
    | _ -> "List with many items (all items ignored)"

describe []        // => "Empty list"
describe [1]       // => "List with one item"
describe [5; 7]     // => "List with two items (first item ignored)"
describe [5; 7; 9] // => "List with many items (all items ignored)"
```

Одиничний `'_'` завжди має стояти _останнім_ у зіставленні зі зразком: кожне значення, яке _не_ відповідає жодному з інших випадків, оброблятиметься цим випадком.
