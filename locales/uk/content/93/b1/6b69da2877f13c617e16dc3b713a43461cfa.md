# Вступ

## Функції зворотного виклику

Функціями зворотного виклику називають функції, які передають як аргументи. Цей прийом програмування створює послідовність викликів функцій як у синхронному, так і в асинхронному програмуванні. Написати функцію зворотного виклику нічим не відрізняється від написання звичайної функції; однак вона має відповідати сигнатурі, визначеній функцією, що її викликає.

```javascript
const sideLength = 5;

// Caller function takes a callback function
function applySideLength(callback) {
  return callback(sideLength);
}

// Callback must expect the possible argument from the calling function
function areaOfSquare(side) {
  return side * side;
}

applySideLength(areaOfSquare); // => 25
```

Функції зворотного виклику можна також записати як функціональний вираз:

```javascript
applySideLength(function squarePerimeterLength(side) {
  return side * 4;
});
```
