# Вступ до тверджень типу

Інтерфейси в Go можуть створювати неоднозначність щодо базового типу.
Твердження типу дає нам змогу витягти базове конкретне значення зі значення інтерфейсу за допомогою такого синтаксису: `interfaceVariable.(concreteType)`.

Наприклад:

```go
var input interface{} = 12
number := input.(int)
```

ПРИМІТКА: це спричинить паніку, якщо змінна інтерфейсу не містить значення конкретного типу.

Ми можемо перевірити, чи містить значення інтерфейсу певний конкретний тип, скориставшись обома поверненими значеннями твердження типу: базовим значенням і булевим значенням (англ. Boolean), яке повідомляє, чи вдалося твердження.
Наприклад:

```go
str, ok := input.(string) // no panic if input is not a string
```

Якщо `input` містить `string`, то `str` буде базовим значенням, а `ok` матиме значення правда.
Якщо `input` не містить `string`, то `str` матиме нульове значення типу `string` (тобто `""`, порожній рядок тексту (англ. string)), а `ok` матиме значення неправда.
Паніки не виникне в жодному разі.

## Перемикачі типів

**Перемикач типів** може виконати кілька тверджень типу послідовно.
Він має такий самий синтаксис, як твердження типу (`interfaceVariable.(concreteType)`), але замість `concreteType` стоїть ключове слово `type`.
Ось приклад:

```go
var i interface{} = 12 // try: 12.3, true, int64(12), []int{}, map[string]int{}

switch v := i.(type) {
case int:
    fmt.Printf("the integer %d\n", v)
case string:
    fmt.Printf("the string %q\n", v)
default:
    fmt.Printf("type, %T, not handled explicitly: %#v\n", v, v)
}
```
