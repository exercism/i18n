# Вступ

Значення `null` позначає _відсутність_ значення. **Нульований** тип дозволяє змінній набувати значення `null`. Щоб зробити будь-який тип нульованим, ми обгортаємо його в `Null<T>`:

```haxe
var a:Int = null; // Error
var b:Null<Int> = null; // Allowed
```

Щоб перевірити, чи значення зараз `null`, просто скористаймося виразом `if`:

```haxe
var a:Null<Int> = 10;

if (a != null) {
  trace("a is not null"); // a is not null
}
```
