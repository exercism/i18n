# Вступ

Структури - це надбудова над [мапами][exercism-maps], яка забезпечує перевірки під час компіляції та типові значення. Структура дістає назву від модуля, у якому її визначено. Щоб визначити структуру, скористаймося конструкцією `defstruct`. Зазвичай цю конструкцію розміщують одразу після визначення модуля. `defstruct` приймає або масив атомів (для типових значень `nil`), або масив ключових слів (для заданих типових значень). Поля без типових значень мають іти перед полями з типовими значеннями.

```elixir
defmodule Plane do
  defstruct [:engine, wings: 2]
end

plane = %Plane{}
# => %Plane{engine: nil, wings: 2}
```

## Доступ до полів та їх оновлення

Оскільки структури побудовані на мапах, ми можемо використовувати більшість функцій для роботи з мапами, щоб отримувати й обробляти значення. Для структур _поведінка Access_ **не** реалізована. Натомість радимо використовувати _оператор статичного доступу_ `.`, щоб отримати доступ до полів структури.

- отримати/витягнути значення полів:

  ```elixir
  plane = %Plane{}
  plane.engine
  # => nil
  Map.fetch(plane, :wings)
  # => {:ok, 2}
  ```

- оновити значення полів

  ```elixir
  plane = %Plane{}
  %{plane | wings: 4}
  # => %Plane{engine: nil, wings: 4}
  ```

## Зіставлення зі зразком

Структури можна використовувати в зіставленні зі зразком як із назвою структури, так і без неї.

```elixir
plane = %Plane{}
%Plane{wings: wings} = plane
%{wings: wings} = plane
```

Додавши назву структури до зразка, ми можемо переконатися, що і ліва, і права частина є структурами одного типу.

```elixir
defmodule Helicopter do
  defstruct [:engine, rotors: 1]
end

%Plane{} = %Helicopter{}
# => (MatchError) no match of right hand side value: %Helicopter{engine: nil, rotors: 1}
```

## Обовʼязкова ініціалізація значень полів

Ми можемо використати атрибут модуля `@enforce_keys` з масивом ключів полів, щоб гарантувати, що значення буде ініціалізовано під час створення структури. Якщо ключ не вказано, його значенням буде `nil`, як у наведеному вище прикладі. Якщо обовʼязковий ключ не ініціалізовано, виникає помилка.

```elixir
defmodule User do
  @enforce_keys [:username]
  defstruct [:username]
end

%User{}
# => (ArgumentError) the following keys must also be given when building struct User: [:username]
```
