# Про

Чотири слова з [`grouping`][grouping] і
[`splitting`][splitting] покривають майже всі потреби «порізати послідовність
на частини»:

```factor
USING: grouping kernel sequences splitting splitting.monotonic ;

! Disjoint chunks of N elements
{ 1 2 3 4 5 6 7 } 3 group .
! => { { 1 2 3 } { 4 5 6 } { 7 } }

! Overlapping sliding window of N elements
{ 1 2 3 4 5 } 2 clump .
! => { { 1 2 } { 2 3 } { 3 4 } { 4 5 } }

! Split wherever a predicate fires on an element
{ 1 2 0 3 4 0 5 } [ zero? ] split-when .
! => { { 1 2 } { 3 4 } { 5 } }

! Group runs where adjacent elements are "the same" by some test
{ 1 1 2 2 2 3 } [ = ] monotonic-split .
! => { { 1 1 } { 2 2 2 } { 3 } }
```

| слово             | дія                                                                                            |
|-------------------|-----------------------------------------------------------------------------------------------|
| `group`           | `( seq n -- groups )`: непересічні фрагменти по *n* елементів                                  |
| `clump`           | `( seq n -- clumps )`: перекривні вікна по *n* елементів                                       |
| `split-when`      | `( seq quot: ( elt -- ? ) -- pieces )`: розрив, коли предикат істинний                         |
| `monotonic-split` | `( seq quot: ( a b -- ? ) -- pieces )`: розрив, коли предикат для *сусідніх* елементів повертає `f` |

Корисна ментальна модель:

- **`group` / `clump`** орієнтуються на розміри; параметр *n* задає,
  наскільки велике кожне вікно.
- **`split-when`** дивиться на *окремі елементи*; предикат
  вирішує, чи є кожен елемент «розривом».
- **`monotonic-split`** дивиться на *пари*; предикат вирішує,
  чи ще належать два сусідні елементи до однієї серії.

[splitting]: https://docs.factorcode.org/content/vocab-splitting.html
