# Вступ

Вікіпедія описує конструкцію `switch` як «різновид механізму керування вибором, який дозволяє значенню змінної або виразу змінювати потік керування програми».

Цей механізм задіює такі ключові слова: `switch`, `case`, `break` і `default`.

У найпростішому вигляді вони перевіряють примітивний вираз або рядок тексту (англ. string) й ухвалюють рішення на основі його значення. Наприклад:

```csharp
string direction = GetDirection();
switch (direction)
{
    case "left":
        GoLeft();
        break;
    case "right":
        GoRight();
        break;
    default:
        MarkTime();
        break;
}
```

У найскладнішому вигляді вони запроваджують низхідне приведення типів `case <Type> <variable>:` і захисні умови (`when`).

```csharp
Animal animal = GetAnimal();

switch (animal)
{
    case Dog canine:
    case Coyote canine:
        canine.Bark();
        break;
    case Cat cat when cat.HasOnly8Lives():
        cat.IsCareful();
        cat.Meow();
        break;
    case Cat cat:
        cat.Meow();
        break;
}
```
