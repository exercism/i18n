# Докладніше

Іноді, коли функція приймає багато аргументів, буває важко запамʼятати порядок, у якому їх треба передавати. Щоб полегшити читання, Gleam дає змогу позначати аргументи іменем.

Щоб позначити аргумент, вкажімо назву мітки перед назвою аргументу, розділивши їх пробілом.

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

Коли ми викликаємо функцію з мітками, аргументи можна передавати в будь-якому порядку. Кожен із цих викликів `replace` рівнозначний:

```gleam
replace(in: "🍔🍔🍔" each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

Мітки завжди необовʼязкові. Навіть якщо функція має аргументи з мітками, її все одно можна викликати без міток.

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```

Коли ми визначаємо функцію з мітками, усі аргументи після першого позначеного аргументу також повинні мати мітки.

```gleam
// This function is valid
pub fn valid(
  x: Int,
  label1 y: Int,
  label2 z: Int
) -> Int {
  // ...
}

// This function is invalid
pub invalid(
  x: Int,
  label1 y: Int,
  z: Int
) -> Int {
  // ...
}
```
