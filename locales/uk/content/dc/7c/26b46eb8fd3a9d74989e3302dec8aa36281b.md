# Додаток до вказівок

## Тестування

Тести будуть виконувати деякі операції одночасно.
Варто подбати про те, щоб операції з Account залишали його в узгодженому стані.
Наприклад: кілька горутин можуть одночасно вносити і знімати гроші, а два зняття, що відбуваються одночасно, не повинні зробити баланс відʼємним.

Працюючи локально, можна перевірити, що наш код належно працює з одночасністю і не створює гонок даних, запустивши тести з увімкненим прапорцем `-race`.

```bash
cd exercism/project/directory/go/bank-account
go test -race
```
