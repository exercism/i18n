# Вступ

## Узагальнені типи

Визначення колекції зазвичай містить заповнювач у кутових дужках (`<>`), часто `T` за домовленістю. Таку колекцію називають узагальненим типом. Це дає змогу користувачеві колекції вказати, який тип елементів зберігати в колекції. У наведеному нижче прикладі коду ми створюємо примірник масиву рядків тексту (англ. string).

## Масиви

Масиви в C# є колекціями примітивних значень або примірників структур чи класів. Вони реалізовані в базовій бібліотеці класів як `List<T>`, де `T` позначає тип елемента в масиві. API надає багатий набір методів для створення та роботи з масивами.

Елементи можна додавати до масивів і видаляти з них. Вони збільшуються та зменшуються за потреби.

```csharp
var listOfStrings = new List<string>();
```
