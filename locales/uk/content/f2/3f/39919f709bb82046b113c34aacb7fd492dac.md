# Докладніше

_Рядок тексту_ (англ. string) - тип даних у JavaScript для зберігання текстових даних.
Окремого типу даних для одного символу немає.

## Створення рядка тексту

Ми створюємо [літерал][literal] рядка тексту, обгортаючи текст в одинарні або подвійні лапки.
На Exercism використовують одинарні лапки.

<!-- prettier-ignore-start -->
```javascript
'Hello, World!'
"Hello, World!"
```
<!-- prettier-ignore-end -->

Деякі спеціальні символи тексту потрібно писати зі зворотною косою рискою `\` на початку; див. [керівні послідовності на MDN][mdn-escape-sequences].

<!-- prettier-ignore-start -->
```javascript
const text = 'I\'m having fun.\nWhat about you?';
console.log(text);
// => I'm having fun.
// => What about you?
```
<!-- prettier-ignore-end -->

Крім одинарних і подвійних лапок, рядок тексту можна створити, узявши текст у зворотні лапки.
Цей синтаксис дає змогу включати одинарні чи подвійні лапки й навіть нові рядки без потреби їх екранувати.
Він також дає змогу вбудовувати вирази; докладніше див. [шаблонні рядки][mdn-template-strings].

```javascript
`A multi-line string
with 'single quotes'
and "double quotes"`;
```

## Рядки тексту як масиви символів

Рядок тексту можна розглядати як масив символів, де перший символ має індекс `0`.
До окремого символу рядка можна звернутися за допомогою квадратних дужок та індексу потрібної літери.
Крім того, є метод `charAt`.

```javascript
'cat'[1];
// => 'a'

'cat'.charAt(2);
// => 't'
```

Кількість символів у рядку тексту можна визначити, звернувшись до властивості `length`.

```javascript
'cat'.length;
// => 3
```

## Конкатенація та методи

Найпростіший спосіб зʼєднати рядки тексту - скористатися оператором додавання `+`.

```javascript
'I like' + ' ' + 'cats.';
// => "I like cats."
```

Рядки тексту надають багато допоміжних методів; повний список див. у [документації MDN про методи рядків][mdn-string-methods].
Нижче наведено кілька найуживаніших із них.

- [`toUpperCase`][mdn-to-upper-case] і [`toLowerCase`][mdn-to-lower-case] - змінюють регістр усіх символів
- [`trim`][mdn-trim] - прибирає пробільні символи на початку й у кінці
- [`includes`][mdn-includes], [`startsWith`][mdn-starts-with] і [`endsWith`][mdn-ends-with] - визначають, чи є інший рядок тексту частиною заданого рядка
- [`slice`][mdn-slice] - витягує частину рядка тексту

## Рядки тексту незмінні

Застосування наведених вище методів ніколи не змінює початковий рядок тексту. Замість цього створюється й повертається новий рядок.
Рядки тексту (як і інші примітивні типи даних) у JavaScript незмінні.
Це також означає, що не можна присвоїти інший символ за певним індексом за допомогою синтаксису з дужками, показаного вище (як це роблять у масивах).

```javascript
const str = 'cat';
str[1] = 'u'; // fails silently
console.log(str);
// => 'cat'
```
