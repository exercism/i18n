# Вказівки

Маючи вік у секундах, обчислімо, скільки років комусь було б на одній із планет нашої Сонячної системи.

Один земний рік дорівнює 365.25 земних діб, або 31,557,600 секунд.
Якби нам сказали, що комусь 1,000,000,000 секунд, його вік становив би 31.69 земних років.

Для інших планет треба врахувати їхній орбітальний період у земних роках:

| Планета | Орбітальний період у земних роках |
| ------- | --------------------------------- |
| Меркурій | 0.2408467                        |
| Венера   | 0.61519726                       |
| Земля    | 1.0                              |
| Марс     | 1.8808158                        |
| Юпітер   | 11.862615                        |
| Сатурн   | 29.447498                        |
| Уран     | 84.016846                        |
| Нептун   | 164.79132                        |

~~~~exercism/note
Насправді один повний оберт Землі навколо Сонця триває ближче до 365.256 діб (1 сидеричний рік).
У григоріанському календарі в середньому 365.2425 діб.
Хоча це не цілком точно, у цій вправі використовується значення 365.25.
Про інші способи вимірювання року можна дізнатися зі статті [Рік у Вікіпедії][year].
