# Інструкції

У цій вправі ми будемо організовувати гонки між різними типами радіокерованих машинок.
Кожна машинка має власні характеристики швидкості та витрати заряду.

Машинки починають із повністю зарядженими батареями (100%).
Щоразу, коли ми керуємо машинкою за допомогою пульта,
вона проїжджає відстань, що дорівнює її швидкості в метрах, а відсоток заряду, що залишився, зменшується на величину витрати заряду.

Якщо заряд машинки менший за відсоток витрати заряду, керувати нею більше не можна.

Кожна траса має власну довжину.
Машинки перевіряють на здатність проїхати трасу, не вичерпавши заряд.

## 1. Створіть радіокеровану машинку

Визначте структуру `Car` з такими полями типу `int`:

- battery
- batteryDrain
- speed
- distance

Забезпечте можливість створювати радіокеровану машинку, визначивши функцію `NewCar`, яка приймає швидкість машинки в метрах
і відсоток витрати заряду як свої два параметри (обидва типу `int`) та повертає екземпляр `Car`:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)
// => Car{speed: 5, batteryDrain: 2, battery:100, distance: 0}
```

## 2. Створіть трасу

Визначте ще один тип структури під назвою `Track` з полем `distance` цілочисельного типу.
Забезпечте можливість створювати трасу, визначивши функцію `NewTrack`, яка приймає довжину траси в метрах як свій єдиний параметр (типу `int`):

```go
distance := 800
track := NewTrack(distance)
// => Track{distance: 800}
```

## 3. Керуйте машинкою

Реалізуйте функцію `Drive`, яка оновлює кількість проїдених метрів відповідно до швидкості машинки та зменшує заряд відповідно до витрати заряду.
Якщо заряду не вистачає, щоб проїхати ще один раз, машинка не буде рухатися:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)
car = Drive(car)
// => Car{speed: 5, batteryDrain: 2, battery: 98, distance: 5}
```

## 4. Перевірте, чи може радіокерована машинка завершити гонку

Щоб завершити гонку, машинка повинна бути здатною проїхати всю дистанцію траси.
Це означає, що її заряд має не вичерпатися до того, як вона перетне фінішну лінію.
Реалізуйте функцію `CanFinish`, яка приймає екземпляри `Car` і `Track` як свої параметри та повертає `true`, якщо машинка може завершити гонку; інакше повертає `false`.

Вважайте, що ми зараз на стартовій лінії гонки та заводимо двигун машинки для гонки.
Зважте на те, що на старті гонки батарея машинки може бути заряджена не повністю:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

distance := 100
track := NewTrack(distance)

CanFinish(car, track)
// => true
```
