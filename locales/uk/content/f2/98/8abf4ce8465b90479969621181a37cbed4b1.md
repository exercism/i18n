# Довідка

Рядок тексту (англ. string) - це тип даних, який представляє текстове значення.
[`Strings`][strings-and-characters] у Swift - це колекція значень `Character`, які своєю чергою містять [скалярне значення Unicode][unicode-scalar-values].

Створити рядок тексту можна за допомогою літерала рядка тексту, тобто послідовності символів, узятої в подвійні лапки (`"`).
Для багаторядкових рядків тексту можна використовувати потрійні лапки (`"""`).

```swift
let hello : String = "Hello, World!"

let poem : String = """
Roses are red,
Violets are blue.
Sugar is sweet,
And so are you.
"""
```

Рядки тексту у Swift також отримують усю функціональність класу [NSString][nsstring-docs], який спочатку використовувався в бібліотеках Objective-C від Apple.

## Символ

`Character` - це тип даних, який зберігає одне [скалярне значення Unicode][unicode-scalar-values], що складається з однієї або кількох кодових точок Unicode.
Скалярне значення Unicode - це будь-яка [кодова точка Unicode][unicode] у діапазоні від `U+0000` до `U+D7FF` включно або від `U+E000` до `U+10FFFF` включно.

```swift
let aChar : Character = "A"
```

## Виведення типу

Swift може вивести тип літерала рядка тексту й типово виводить його як `String`.
Можна явно оголосити рядок тексту як `Character` за допомогою анотації типу `Character`, яка вимагає, щоб значення було одним символом.

```swift
let aString = "A"
let aChar: Character = "A"
print(type(of: aString)) // Prints String
print(type(of: aChar))   // Prints Character

// The following code will not compile
let badChar: Character = "Too many characters"
// Error: Cannot convert value of type 'String' to specified type 'Character'
```

## Конкатенація

У Swift рядки тексту можна [конкатенувати][concatenated] за допомогою оператора `+`.
Символи **не** можна конкатенувати з рядками тексту за допомогою оператора `+`, спершу не перетворивши символ на рядок тексту.

```swift
print("honey" + "comb")
// Prints "honeycomb"
```

Метод [`append(_:)`][append] змінює рядок тексту, додаючи в його кінець або рядок тексту, або символ.

```swift
var greeting = "Hello"
let world = ", world"
let period: Character = "."

greeting.append(world)
print(greeting) // Prints "Hello, world"

greeting.append(period)
print(greeting) // Prints "Hello, world."
```

## Інтерполяція рядків тексту

[Інтерполяція рядків тексту][string-interpolation] дає змогу побудувати рядок тексту на основі значень із різних джерел, як-от змінних і виразів.
Щоб вставити значення в рядок тексту за допомогою інтерполяції рядків, треба помістити вираз або значення в дужки, перед якими стоїть символ зворотної скісної риски.

```swift
let radius = 5.0
let circle = "The area of a circle with radius \(radius) is \(Double.pi * radius * radius)"
print(circle) // Prints "The area of a circle with radius 5.0 is 78.53981633974483"
```

## Властивості рядків тексту та символів

Рядки тексту й символи мають кілька різних _властивостей_, які можна запитати, щоб отримати інформацію про рядок тексту або символ.

### Властивості рядків тексту

Ось деякі з найпоширеніших властивостей рядків тексту, а повний перелік можна знайти в [документації][string-docs].

| Властивість | Опис                                           | Приклад                        |
| ----------- | ---------------------------------------------- | ------------------------------ |
| `isEmpty`   | Повертає `true`, якщо рядок тексту порожній    | `"Hello".isEmpty equals false` |
| `count`     | Повертає кількість символів у рядку тексту     | `"Hello".count   equals 5`     |

### Властивості символів

Ось деякі з найпоширеніших властивостей символів, а повний перелік можна знайти в [документації][string-docs].

| Властивість    | Опис                                          | Приклад                        |
| -------------- | --------------------------------------------- | ------------------------------ |
| `isLowercase`  | Повертає `true`, якщо символ у нижньому регістрі | `"a".isLowercase  equals true` |
| `isUppercase`  | Повертає `true`, якщо символ у верхньому регістрі | `"A".isUppercase  equals true` |
| `isNumber`     | Повертає `true`, якщо символ є числом         | `"1".isNumber     equals true` |
| `isWhitespace` | Повертає `true`, якщо символ є пробільним     | `" ".isWhitespace equals true` |

## Перетворення типів

Щоб перетворити тип на рядок тексту, можна скористатися ініціалізатором `String()`, який приймає різні типи, зокрема `Int`, `Double`, `Character` та інші.

```swift
let charX: Character = "x"
print(String(charX))     // Prints "x"
print(String(110))       // Prints "110"
print(String(Double.pi)) // Prints "3.141592653589793"
```

## Спеціальні символи

У Swift є кілька [спеціальних символів][special-characters], які можна використовувати в рядках тексту.

| Значення | Опис                              |
| -------- | --------------------------------- |
| `\0`     | Нульовий символ                   |
| `\\`     | Зворотна скісна риска             |
| `\t`     | Горизонтальна табуляція           |
| `\n`     | Переведення рядка                 |
| `\r`     | Повернення каретки                |
| `\'`     | Знак одинарної лапки              |
| `\"`     | Знак подвійної лапки              |
| `\uFFFF` | Шістнадцятковий символ Unicode    |

```swift
let quote : String = "\"Hello\", he said."
print(quote) // Prints "Hello", he said.

let unicode : Character = "\u{1F496}"
print(unicode) // Prints 💖
```
