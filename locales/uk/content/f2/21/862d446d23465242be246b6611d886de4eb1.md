# Вступ

`when` у Kotlin - це умовний вираз для вибору з кількох варіантів.
Він схожий на `switch` у Java і гнучкіший, ніж ланцюжок `if` ... `else if` ... `else`.

Як і `if`, `when` можна використовувати як вираз, що дає значення.

## Зіставлення значення

Передаймо `when` у дужках значення, з яким треба зіставити.
Кожна гілка порівнює це значення, доки одна з них не збіжиться:

```kotlin
val animal = "chicken"
val type = when (animal) {
    "chicken" -> "bird"
    "poodle" -> "dog"
    else -> "unknown"
}
// type => "bird"
```

- Кожна гілка записується як `pattern -> result`.
- Гілки перевіряються згори донизу, доки не знайдеться збіг.
  Виконується лише перша гілка, що збіглася.
- Використовуймо `else` для будь-якого значення, не переліченого вище (як останній `else` у ланцюжку `if`).

Це схоже на [зіставлення зі зразком][pattern-matching].
`pattern` може бути значенням для зіставлення, або ж можна використати `is`, щоб зіставити за типом:

```kotlin
fun typeText(subject: Any): String {
    return when(subject) {
        is Animal -> "Animal"
        is Fruit -> "Fruit"
        is String -> "Text"
        else -> "Unknown"
    }
}
```

або використати `in`, щоб перевірити, чи міститься воно в діапазоні, колекції, рядку тексту (англ. string) чи будь-чому іншому з методом `contains`:

```kotlin
fun describe(number: Int, position: String) {
    // Range
    when(number) {
        in 1..10 -> println("From 1 to 10")
        in 11..20 -> println("From 11 to 20")
    }

    // Collection
    when(number) {
        in listOf(2, 4, 6) -> println("small even")
        in listOf(3, 5, 7) -> println("small odd")
    }

    // String
    when(position) {
        in "center middle" -> println("inner")
        in "left right boundary" -> println("outer")
    }
}
```

~~~exercism/note
Можна також використовувати `in` з іншими обʼєктами, якщо визначити для них [функцію розширення оператора][kotlin-operator-overloading] `contains`.
Наприклад, із [Regex][kotlin-regex]:

```kotlin

}
```

## Захисні умови

Під час зіставлення значення можна поставити додаткові умови в `if` після зразка.
Такі умови називаються захисними.

```kotlin
val x = 5
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else -> "other"
}
// description => "x is 5, y is even"
```

Можна використати навіть `else if`.

```kotlin
val x = 7
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else if y % 2 == 0 -> "y is an even number"
    else -> "other"
}
// description => "y is an even number"
```


## Зіставлення умов

Або ж значення можна опустити й поставити на кожній гілці булеві умови (англ. Boolean):

```kotlin
val x = 5
val y = 8
val description = when {
    x % 2 != 0 -> "x is odd"
    y % 2 == 0 -> "y is even"
    else -> "neither condition matched first"
}
// description => "x is odd"
```

Знову ж таки, гілки перевіряються згори донизу, і виконується лише перша гілка, умова якої дорівнює `true`.

## Використання `when` як виразу

Коли `when` використовують заради його результату (присвоюють змінній, повертають із функції тощо), потрібно покрити всі можливі випадки.

- Якщо ми зіставляємо значення, додаймо `else`, хіба що всі можливі значення вже оброблено (наприклад, усі значення `Boolean` чи `enum`).
- Якщо ми зіставляємо умови, гілка `else` обовʼязкова, бо компілятор не може знати, що наші умови покривають усі випадки.

```kotlin
fun label(n: Int): String = when (n) {
    0 -> "zero"
    1 -> "one"
    else -> "other"
}
```
