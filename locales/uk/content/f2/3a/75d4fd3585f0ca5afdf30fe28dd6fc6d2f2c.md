# Інструкції

Майбутня чарівниця Еліз хоче потренувати деякі основи.
У неї є стос карток, з якими вона хоче працювати.

Щоб трохи спростити собі життя, вона використовує лише картки від 1 до 10, тож її стос карток можна представити масивом чисел.
Позиція певної картки відповідає її індексу в масиві.
Це означає, що позиція 0 вказує на першу картку, позиція 1 - на другу, і так далі.

~~~~exercism/note
Усі функції мають оновлювати масив карток, а потім повертати змінений масив. Це поширений підхід, відомий як патерн Builder, який дозволяє зручно зчіплювати функції в ланцюжок.
~~~~

## 1. Витягти картку зі стосу

Щоб вибрати картку, поверніть картку з індексом `position` із заданого стосу.

Реалізуйте функцію `getCard(at:from:)`, яка приймає два аргументи: `at` (позиція картки в стосі) і `from` (стос карток).
Функція має повернути картку на позиції `index` із заданого стосу.

```swift
let index = 2
getCard(at: index, from: [1, 2, 4, 1])
// returns 4
```

## 2. Замінити картку в стосі

Зробіть невеличкий фокус і обміняйте картку з індексом `position` на надану картку для заміни.

Реалізуйте функцію `setCard(at:in:to)`, яка приймає три аргументи: `at` (позиція картки в стосі), `in` (стос карток) і `to` (нова картка, якою треба замінити картку на позиції `index`).
Функція має повернути копію стосу, у якій картку на позиції `index` замінено новою карткою.
Якщо заданий `index` не є допустимим індексом у стосі, функція має повернути початковий стос без змін.

```swift
let index = 2
let newCard = 6
setCard(at: index, in: [1, 2, 4, 1], to: newCard)
// returns [1, 2, 6, 1]
```

## 3. Вставити картку на вершину стосу

Змусьте картку зʼявитися, вставивши нову картку на вершину стосу.

Реалізуйте функцію `insert(_:atTopOf:)`, яка приймає два аргументи: нову картку для вставлення та стос карток.
Функція має повернути копію стосу з наданою новою карткою, доданою на вершину стосу.

```swift
let newCard = 8
insert(newCard, atTopOf: [5, 9, 7, 1])
// returns [5, 9, 7, 1, 8]
```

## 4. Прибрати картку зі стосу

Змусьте картку зникнути, прибравши зі стосу картку на заданій позиції `position`.

Реалізуйте функцію `removeCard(at:from:)`, яка приймає два аргументи: `at` (позиція картки в стосі) і `from` (стос карток).
Функція має повернути копію стосу, з якої прибрано картку на позиції `index`.
Якщо заданий `index` не є допустимим індексом у стосі, функція має повернути початковий стос без змін.

```swift
let index = 2
removeCard(at: index, from: [3, 2, 6, 4, 8])
// returns [3, 2, 4, 8]
```

## 5. Вставити картку в стос

Змусьте картку зʼявитися, вставивши нову картку на задану позицію `position` у стосі.

Реалізуйте функцію `insert(_:at:from:)`, яка приймає три аргументи: нову картку для вставлення, позицію, на яку слід вставити нову картку, і стос карток.
Функція має повернути копію стосу з наданою новою карткою, доданою на задану позицію.
Якщо заданий `index` не є допустимим індексом у стосі, функція має повернути початковий стос без змін.

```swift
let newCard = 8
insert(newCard, at: 2, from: [5, 9, 7, 1])
// returns [5, 9, 8, 7, 1]
```

## 6. Перевірити розмір стосу

Перевірте, чи дорівнює розмір стосу `stackSize`, чи ні.

Реалізуйте функцію `checkSizeOfStack(_:_:)`, яка приймає два аргументи: `stack` (стос карток) і `stackSize` (розмір стосу).
Функція має повернути `true`, якщо розмір стосу дорівнює `stackSize`, і `false` в іншому разі.

```swift
let stackSize = 4
checkSizeOfStack([3, 2, 6, 4, 8], stackSize)
// returns false
```
