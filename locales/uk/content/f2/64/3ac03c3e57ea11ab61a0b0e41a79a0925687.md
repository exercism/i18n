# Вступ

Приведення та перетворення типів - це різні способи змінити тип даних виразу з одного на інший.

Вираз можна привести до іншого типу за допомогою оператора приведення `(<type>)`.

```csharp
long l = 1000L;
int i = (int)l;

object o = new Random();
Random r = (Random)o;
```

Якщо типи несумісні, викидається екземпляр `InvalidCastException`. У випадку чисел це означає, що тип, який приймає, не може представити приведене значення. У випадку класів один із типів має бути похідним від іншого (це так само очевидно стосується й структур).

Альтернатива _приведенню_ - _перетворення типів_ за допомогою оператора `is`. Зазвичай це застосовують до типів-посилань і типів, що допускають значення null.

```csharp
object o = new Random();
if (o is Random rand)
{
    int ii = rand.Next();
    // now, do something random
}
```

Якщо нам потрібно визначити точний тип обʼєкта, то `is` може бути трохи надто поблажливим, адже він поверне правду і для класу, і для будь-яких класів й інтерфейсів, від яких він успадкований прямо чи опосередковано. Рішенням у цьому випадку є `typeof` і `Object.GetType()`.

```csharp
object o = new List<int>();

o is ICollection<int> // true
o.GetType() == typeof(ICollection<int>) // false
o is List<int> // true
o.GetType() == typeof(List<int>) // true
```
