# Вступ

[`Set`][set-docs] - це невпорядкована колекція, яка (на відміну від `List`) гарантовано не містить дубльованих значень.

Параметр узагальненого типу інтерфейсу `Set` позначає тип елементів, які містить `Set`:

```java
Set<Integer> ints = Set.of(1, 2, 3);
Set<String> strings = Set.of("alpha", "beta", "gamma");
Set<Object> mixed = Set.of(1, false, "foo");
```

Зауважмо, що метод `Set.of()` створює [_незмінний_][unmodifiable-set-docs] примірник `Set`.
Спроба викликати такі методи, як `add` і `remove`, для цього примірника призведе до винятку під час виконання.

Щоб створити змінний `Set`, потрібно створити примірник класу, який реалізує інтерфейс `Set`.
Цей інтерфейс реалізує найуживаніший вбудований клас [`HashSet`][hashset-docs].

```java
Set<Integer> ints = new HashSet<>();
```

Інтерфейс `Set` розширює інтерфейси [`Collection`][collection-docs] та [`Iterable`][iterable-docs], а тому має багато спільних методів з іншими типами колекцій.
Однак помітна відмінність від інтерфейсу `Collection` полягає в тому, що такі методи, як `add` і `remove`, повертають `boolean` (а не `void`), який вказує, чи містився елемент у множині на момент виклику цього методу:

```java
Set<Integer> set = new HashSet<>();
set.add(1);
// => true
set.add(2);
// => true
set.add(1);
// => false
set.size();
// => 2
set.contains(1);
// => true
set.contains(3);
// => false
set.remove(3);
// => false
set.remove(2);
// => true
set.size();
// => 1
```
