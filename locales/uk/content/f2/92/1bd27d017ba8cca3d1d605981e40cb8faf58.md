# Про це

Умовні конструкції в C++ схожі на умовні конструкції в інших мовах.
Базовим типом будь-якої умовної операції є тип `bool`, який може мати значення `true` або `false`.
Умовні конструкції часто використовують як механізми керування потоком, щоб перевіряти різні умови.

Можна використати умовну конструкцію `if`, яка виконує свій код, коли відповідна умова має значення `true`, ось так:

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

У випадках, коли йдеться про більше ніж один варіант, багато умовних конструкцій `if` можна обʼєднати в ланцюжок за допомогою `else if` та `else`.

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

Починаючи з C++17, умовні конструкції можуть також містити коротку інструкцію ініціалізації, яку можна використати, щоб ініціалізувати одну або кілька змінних для цієї умовної конструкції.
Наприклад:

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> Примітка: до змінних, створених під час ініціалізації, не можна звертатися після завершення умовної конструкції.
