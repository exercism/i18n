# Вступ

`vector` у Clojure - це послідовна, індексована та незмінна колекція з нуля або більше значень. Це означає, що після створення вектора його вже не можна змінити. Функції, які працюють із векторами, повертають новий вектор, а початковий вектор залишається незмінним. Значення у векторі можуть бути різнорідних типів. Вектори можна визначати так:

```clojure
(def empty [])
(def single-value 5)
(def single-value-alternative (vector 5))
(def three-values [a b c]
```

Елементи вектора можна отримати за індексом. Вектори в Clojure мають нульову індексацію, тобто індекс першого елемента завжди дорівнює нулю:

```clojure
(def numbers [2 3 5])
;; Read value from vector
(get numbers 2)
;;=> 5
;; Update value in vector
(assoc numbers 2 9)
;;=> [2 3 9]
```

Початковий вектор залишається незмінним:

```clojure
numbers
;;=> [2 3 5]
```

Щоб запамʼятати оновлене значення, потрібно передати його далі або зберегти у var:

```clojure
(def updated-numbers
  (assoc numbers 2 9))
(get updated-numbers 2)
;;=> 9
```
