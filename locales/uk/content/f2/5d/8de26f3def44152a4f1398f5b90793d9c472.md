# Вступ

Алгебраїчний тип даних (ADT) описує фіксовану кількість іменованих варіантів.
Кожне значення ADT відповідає рівно одному з іменованих варіантів.

ADT визначають за допомогою ключового слова `data`, а варіанти розділяють символами вертикальної риски (`|`).
Якщо з жодним із варіантів не повʼязано даних, такий тип нагадує те, що в інших мовах зазвичай називають _переліченням_ (або _enum_).

```haskell
data Season
  = Spring
  | Summer
  | Autumn
  | Winter
```

Кожен варіант ADT може, за бажанням, мати повʼязані з ним дані, і різні варіанти можуть мати дані різних типів.
Якщо з варіантом повʼязано дані, потрібен конструктор.

```haskell
data Number
  = NInt Int      --'NInt' is the constructor for an Int Number.
  | NFloat Float  --'NFloat' is the constructor for an Float Number.
  | Invalid       --'Invalid' does not have data associated to it.
```

Щоб створити значення для конкретного варіанта, достатньо звернутися до його назви (наприклад, `NInt 22`).
Оскільки назви варіантів нічим не відрізняються від функцій-конструкторів, повʼязані дані можна передати як звичайний аргумент функції.

ADT мають _структурну рівність_: це означає, що два значення для одного й того самого варіанта з однаковими (необовʼязковими) даними рівнозначні.

Хоча для роботи з ADT можна використовувати вирази `if/else`, рекомендований спосіб - зіставлення зі зразком за допомогою інструкції _case_:

```haskell
add1 :: Number -> String
add1 number =
    case number of
      NInt    i -> show (i + 1)
      NFloat  f -> show (f + 1.0)
      Invalid   -> error "Invalid input"
```
