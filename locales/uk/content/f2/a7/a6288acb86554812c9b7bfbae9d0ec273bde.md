# Вступ

Коли кількість ітерацій циклу заздалегідь невідома, тобто коли треба
«продовжувати, доки певний предикат не перестане бути правдою», Factor
використовує комбінатор `while` із [`kernel`][kernel]:

```
while ( pred body -- )
```

І `pred`, і `body` - це quotation, які працюють зі стеком даних. `while`
викликає `pred`; якщо той залишає зверху значення, що зводиться до правди,
`while` виконує `body` і повторює все знову; інакше він зупиняється. Стан,
який переходить з однієї ітерації в наступну, зберігається в стеку між
викликами (або в іменованих локальних змінних, коли частин стану більше
ніж одна).

```factor
USING: kernel math ;

5 [ dup 0 > ] [ dup . 1 - ] while drop
! prints 5 4 3 2 1
```

`until` - це симетрична форма: він продовжує роботу, *доки* предикат не
стане правдою.

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
