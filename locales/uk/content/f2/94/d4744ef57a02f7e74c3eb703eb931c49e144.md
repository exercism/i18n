# Інструкції

У цій вправі ми реалізуємо деякі правила [блекджеку][blackjack], зокрема те, як у неї грають і нараховують очки.

**Примітка**: у цій вправі _`A`_ означає туза, _`J`_ — валета, _`Q`_ — даму, а _`K`_ означає короля.
Джокерів відкидають.
Мається на увазі [стандартна колода з 52 карт французьких мастей][standard_deck], але в більшості версій для гри перемішують кілька колод разом.

## 1. Обчислити значення карти

У блекджеку кожен гравець сам вирішує, чи туз коштує 1 чи 11 очок (_про це далі_).
Фігурні карти (`J`, `Q`, `K`) дають 10 очок, а будь-яка інша карта коштує свій «номінал» (числове значення).

Визначте функцію `value_of_card(<card>)` з параметром `card`.
Функція повинна повертати _числове значення_ переданої карти у вигляді рядка тексту (англ. string).
Оскільки туз може мати кілька значень (1 **або** 11), поки що ця функція має фіксувати значення туза на 1.
Пізніше ми реалізуємо функцію, щоб визначати значення туза з урахуванням наявної руки.

```python
>>> value_of_card('K')
10

>>> value_of_card('4')
4

>>> value_of_card('A')
1
```

## 2. Визначити, яка карта має вище значення

Визначте функцію `higher_card(<card_one>, <card_two>)` з параметрами `card_one` і `card_two`.
Для нарахування очок значення `J`, `Q` чи `K` дорівнює 10.
Функція повинна повертати карту з вищим значенням для нарахування очок.
Якщо обидві карти мають однакове значення, поверніть обидві.
Повернути обидві карти можна, використавши кому в інструкції `return`:

```python
# Using a comma in a return creates a Tuple.  Tuples will be covered in a later exercise.
>>> def returning_two_values(value_one, value_two):
        return value_one, value_two

>>> returning_two_values('K', '3')
('K', '3')
```

Туз може мати кілька значень, тож у цьому завданні ми зафіксуємо значення карт `A` на 1.

```python
>>> higher_card('K', '10')
('K', '10')

>>> higher_card('4', '6')
'6'

>>> higher_card('K', 'A')
'K'
```

## 3. Обчислити значення туза

Як уже згадувалося, туз може коштувати _або_ 1, **або** 11 очок.
Гравці намагаються якомога ближче підійти до 21 очка, не _перевищивши_ 21 (_не «перебравши»_).

Визначте функцію `value_of_ace(<card_one>, <card_two>)` з параметрами `card_one` і `card_two`, які є парою карт, що вже є в руці _перед_ отриманням туза.
Функція має вирішити, чи туз, який надійде, отримає значення 1 чи 11, і повернути це значення.
Памʼятаймо: значення руки з тузом має бути якомога вищим, _не_ перевищуючи 21.

**Підказка**: якщо в руці вже є туз, тоді значенням для туза, який надійде, буде 1.

```python
>>> value_of_ace('6', 'K')
1

>>> value_of_ace('7', '3')
11
```

## 4. Визначити «натуральну» або «блекджекову» руку

Якщо гравцеві як перші дві карти роздають туза (`A`) і карту вартістю десять (10, `K`, `Q` чи `J`), то він має 21 очко.
Таку руку називають **блекджек**.


Визначте функцію `is_blackjack(<card_one>, <card_two>)` з параметрами `card_one` і `card_two`, які є парою карт.
Визначте, чи ця рука з двох карт є **блекджеком**, і поверніть булеве значення (англ. Boolean) `True`, якщо так, і `False` в іншому разі.

**Примітка**: обчислити очки можна багатьма способами.
Але якщо це можливо, хотілося б, щоб ми перевіряли наявність туза і карти вартістю десять **_у_** руці (_або на певній позиції_), а не _сумували_ значення руки.

```python
>>> is_blackjack('A', 'K')
True

>>> is_blackjack('10', '9')
False
```

## 5. Розділення пар

Якщо перші дві карти в руці мають однакове значення (_наприклад, дві шістки або `Q` і `K`_), гравець може вирішити вважати їх двома окремими руками.
Це називають «розділенням пар».

Визначте функцію `can_split_pairs(<card_one>, <card_two>)` з параметрами `card_one` і `card_two`, які є парою карт.
Визначте, чи цю руку з двох карт можна розділити на дві пари.
Якщо руку можна розділити, поверніть булеве значення `True`, інакше поверніть `False`

```python
>>> can_split_pairs('Q', 'K')
True

>>> can_split_pairs('10', 'A')
False
```

## 6. Подвоєння ставки

Коли дві початкові роздані карти дають у сумі 9, 10 або 11 очок, гравець може зробити додаткову ставку, що дорівнює початковій.
Це називають «подвоєнням ставки».

Визначте функцію `can_double_down(<card_one>, <card_two>)` з параметрами `card_one` і `card_two`, які є парою карт.
Визначте, чи цю руку з двох карт можна «подвоїти», і поверніть булеве значення `True`, якщо так, і `False` в іншому разі.

```python
>>> can_double_down('A', '9')
True

>>> can_double_down('10', '2')
False
```
