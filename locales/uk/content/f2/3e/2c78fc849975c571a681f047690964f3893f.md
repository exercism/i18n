# Нотатки до цієї вправи на треку Python

Щодо вхідних даних для тестів функції `sum_of_multiples` можна зробити такі припущення:

- Усі вхідні числа є **_невідʼємними `int`_** (_тобто натуральні числа, включно з нулем_).
- Потрібно надати `list` множників, елементи якого унікальні і відсортовані за зростанням.
