# Інструкції

Ми завзяті спостерігачі за птахами й ведемо облік того, скільки птахів завітало до нашого саду.
Зазвичай ми позначаємо птахів паличками в зошиті, але щоб зручніше працювати з даними, ми оцифрували підрахунки птахів за останні тижні.

## 1. Визначте загальну кількість птахів, яких ми порахували досі

Почнімо аналізувати дані із загального огляду.
Зʼясуймо, скільки всього птахів ми порахували відколи почали вести записи.

Реалізуйте функцію `totalBirdCount`, яка приймає масив `Int`, що містить кількість птахів за кожен день.
Вона повинна повернути загальну кількість птахів, яких ми порахували.

```swift
let birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1]
totalBirdCount(birdsPerDay)
// Returns 34
```

## 2. Обчисліть кількість птахів, які завітали за конкретний тиждень

Тепер, коли ми маємо загальне уявлення про кількість птахів, хочеться зробити докладніший аналіз.

Реалізуйте функцію `birdsInWeek`, яка приймає масив із кількістю птахів за кожен день і номер тижня.

Вона повертає загальну кількість птахів, яку ми порахували за цей конкретний тиждень.
Можна припустити, що тижні завжди записані повністю.

```swift
let birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1]
birdsInWeek(birdsPerDay, weekNumber: 2)
// Returns 12
```

## 3. Виправте помилку в підрахунку

Ми зрозуміли, що весь час, поки ми намагалися стежити за птахами, один птах ховався в далекому куточку саду.

Ми зʼясували, що цей птах завжди проводив у нашому саду кожен другий день.

Ми не знаємо точно, де він був у проміжках між цими днями, але точно не в нашому саду.

Інтуїція спостерігача за птахами також підказує нам, що птах був у нашому саду першого дня, який ми записали до списку.

Зважаючи на цю нову інформацію, напишіть функцію `fixBirdCountLog`, яка приймає масив із кількістю птахів, порахованих за кожен день, як аргумент і повертає масив після виправлення помилки в підрахунку.

```swift
var birdsPerDay = [2, 5, 0, 7, 4, 1]
fixBirdCountLog(birdsPerDay)
// Returns [3, 5, 1, 7, 5, 1]
```
