# Ігнорувати

## Додаткові параметри командного рядка jq

У тестах можна помітити додаткові параметри для `jq`.

```sh
run jq -s -R -c -f minesweeper.jq << 'END_INPUT'
```

Що це за параметри?

- `-s`

  Це режим «slurp».
  Замість того щоб обробляти вхідні дані як потік JSON-обʼєктів,
  усі вхідні дані буде зібрано в масив.

  ```sh
  $ seq 5 | jq -c '.'
  1
  2
  3
  4
  5
  $ seq 5 | jq -s -c '.'
  [1,2,3,4,5]
  ```

- `-R`

  Можливо, ми вже бачили `-r`, який виводить «сирі» рядки тексту (англ. string) без лапок.
  Це протилежність.
  Кожен рядок вхідних даних сприймається як рядок тексту.

  Два приклади:

  ```sh
  $ seq 5 | jq -R -c .
  "1"
  "2"
  "3"
  "4"
  "5"

  $ echo 42 | jq '. * 2'      # input is a JSON number
  84
  $ echo 42 | jq -R '. * 2'   # input is a JSON string
  "4242"
  ```

Коли ми поєднуємо ці два параметри, ми _не_ отримуємо масив рядків тексту:
ми отримуємо всі вхідні дані як один рядок тексту, включно із символами нового рядка в кінці рядків.

```sh
$ seq 5 | jq -s -R -c .
"1\n2\n3\n4\n5\n"
```

Обробка цього є частиною виклику цієї вправи.
