# Вступ

Кортежі - це легкий спосіб згрупувати докупи фіксований набір даних довільних типів. Кортеж не має
конкретного імені; коли ми даємо структурі даних імʼя, вона стає `struct`. Поля кортежу не мають імен;
до них звертаються через деструктуризацію або за позицією.

## Синтаксис

### Створення

Кортежі завжди створюють за допомогою виразу кортежу:

```rust
// pointless but legal
let unit = ();
// single element
let single_element = ("note the comma",);
// two element
let two_element = (123, "elements can be of differing types");
```

Кортежі можуть містити довільну кількість елементів.

### Доступ через деструктуризацію

До елементів кортежу можна дістатися через деструктуризацію. Це просто означає, що ми даємо імена
змінних окремим елементам кортежу, поглинаючи його.

```rust
let (elem1, _elem2) = two_element;
assert_eq!(elem1, 123);
```

### Доступ за позицією

Також до елементів кортежу можна дістатися за числовим індексом позиції. Індексація, як завжди,
починається з 0.

```rust
let notation = single_element.0;
assert_eq!(notation, "note the comma");
```

## Кортежні структури

Також нам доведеться попрацювати з кортежними структурами. Як і звичайні структури, це іменовані типи;
на відміну від звичайних структур, вони мають анонімні поля. Їхній синтаксис дуже схожий на синтаксис
звичайних кортежів. Можна використовувати і деструктуризацію, і доступ за позицією.

```rust
struct TupleStruct(u8, i32);
let my_tuple_struct = TupleStruct(123, -321);
let neg = my_tuple_struct.1;
let TupleStruct(byte, _) = my_tuple_struct;
assert_eq!(neg, -321);
assert_eq!(byte, 123);
```

### Видимість полів

Усі поля анонімних кортежів завжди публічні. Проте поля кортежних структур мають власну
видимість, яка типово є приватною, так само як поля звичайних структур. Ми можемо зробити поля
публічними за допомогою модифікатора `pub`, так само як у звичайній структурі.

```rust
// fails due to private fields
mod tuple { pub struct TupleStruct(u8, i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```

```rust
// succeeds: fields are public
mod tuple { pub struct TupleStruct(pub u8, pub i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```
