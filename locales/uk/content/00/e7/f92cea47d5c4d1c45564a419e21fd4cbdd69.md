# Вступ

## Класи

Класи є одиницею організації коду в PHP.
Код, який описує поведінку предмета або поведінку процесу, можна згрупувати в клас.
Функції, що належать класу, за домовленістю називають `methods`.

```php
<?php

class Door
{
    function lock()
    {
        // ...
    }

    function unlock()
    {
        // ...
    }
}
```

Класи створюють екземпляри за допомогою ключового слова `new`: воно виділяє памʼять під екземпляр класу і викликає метод-конструктор класу.
Створений екземпляр класу можна присвоїти змінній.
Щоб викликати методи екземпляра класу, можна скористатися оператором доступу `->`.

```php
<?php

$a_door = new Door();
$a_door->lock();
$a_door->unlock();
```

Створений екземпляр класу може посилатися на себе самого за допомогою спеціальної змінної `$this`.
Класи також можуть мати властивості: вони поводяться як змінні, привʼязані до екземпляра обʼєкта класу.
До цих властивостей можна звертатися зсередини або ззовні.

```php
<?php

class Car
{
    public $color;

    function __construct($color)
    {
        $this->color = $color;
    }

    function getColor()
    {
        return $this->color;
    }
}

$a_car = new Car("red");
$a_car->color; // => "red" by accessing the property
$a_car->getColor(); // => "red" by invoking the instance method
```
