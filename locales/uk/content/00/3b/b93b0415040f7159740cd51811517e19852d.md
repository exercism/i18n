# Тести

Щоб скористатися засобом запуску тестів, нам знадобиться правильно [встановлений Godot][installation].

## Запуск тестів

[Засіб запуску тестів][test runner] використовується для завантаження й перевірки рішень.
Щоб запустити засіб запуску тестів, завантажмо його локально, а потім запустімо через `godot`.
У майбутньому засіб запуску тестів буде завантажуватися автоматично разом із вправами, коли ми використовуємо `exercism download`.

### Завантаження засобу запуску тестів

Наведений нижче фрагмент оболонки можна використати, щоб завантажити засіб запуску тестів.

```bash
exercism download --track gdscript --exercise hello-world
cd "$(exercism workspace)/gdscript"
curl --remote-name https://raw.githubusercontent.com/exercism/gdscript-test-runner/refs/heads/main/bin/test_runner.gd
```

### Запуск засобу запуску тестів

Засіб запуску тестів запускається через `godot` у безголовому режимі (без IDE).
`-s` або `--script` вказує Godot запустити скрипт засобу запуску тестів.
Засіб запуску тестів приймає два аргументи: слаг і шлях до каталогу рішення.

```bash
godot --headless -s to/test_runner.gd -- <solution-slug> <path/to/solution>
```

Наприклад,

```bash
godot --headless -s "$(exercism workspace)/gdscript/test_runner.gd" -- hello-world "$(exercism workspace)/gdscript/hello-world
```
