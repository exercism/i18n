# Вступ

Рядок тексту (англ. `string`) у Go - це незмінна послідовність байтів, яка не обовʼязково має представляти символи.

Рядковий літерал визначається між подвійними лапками:

```go
const name = "Jane"
```

Рядки тексту можна зʼєднувати за допомогою оператора `+`:

```go
"Jane" + " " + "Austen"
// => "Jane Austen"
```

Деякі спеціальні символи потрібно екранувати за допомогою зворотної скісної риски, наприклад `\t` для символу табуляції та `\n` для нового рядка в рядках тексту.

```go
"How is the weather today?\nIt's sunny"  
// =>
// How is the weather today?
// It's sunny
```

Пакет `strings` містить багато корисних функцій для роботи з рядками тексту.
Докладніше про функції для роботи з рядками можна дізнатися з [документації пакета `strings`](https://pkg.go.dev/strings).
Ось кілька прикладів:

```go
import "strings"

// strings.ToLower returns the string given as argument with all its characters lowercased
strings.ToLower("MaKEmeLoweRCase")
// => "makemelowercase"

// strings.Repeat returns a string with a substring given as argument repeated many times
strings.Repeat("Go", 3)
// => "GoGoGo"
```
