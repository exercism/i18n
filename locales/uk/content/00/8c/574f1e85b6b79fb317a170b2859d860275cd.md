# Основи

Програма мовою Sather складається з **класів**. Клас - це іменована коробка, у якій зберігаються підпрограми. А **підпрограма** - це іменований фрагмент роботи, який дає відповідь.

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

end; -- class GREETER
```

Читаймо це згори:

- `class GREETER is` відкриває коробку й дає їй назву. Назви класів пишуть великими літерами.
- `hello : STR is` починає підпрограму з назвою `hello`, яка дає `STR` — фрагмент тексту, який називають *рядком тексту (англ. string)*. Запис `: STR` - це обіцянка про те, якого виду буде відповідь.
- `return "Hello!";` повертає відповідь. Текст пишуть між подвійними лапками.
- `end;` закриває підпрограму, а другий `end;` закриває клас.

Усе після `--` у рядку - це **коментар**. Sather його ігнорує; він там для людей.

```sather
-- This line is for the reader, not the computer.
```

Щоб скористатися підпрограмою з іншого місця, пишемо назву класу, дві двокрапки й назву підпрограми:

```sather
GREETER::hello        -- this is "Hello!"
```

Усередині того самого класу можемо не писати назву класу:

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

   greeting_again : STR is
      return hello;      -- calls the routine just above
   end;

end; -- class GREETER
```

Підпрограму, яка не приймає аргументів, викликають без дужок: `hello`, а не `hello()`.
