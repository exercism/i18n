# Instructions

Кожну страхувальну систему в цирку розраховано на навантаження в кілограмах, і ніхто не підіймається, доки числа не перевірять.

Для класу `SAFETY_HARNESS` потрібно таке. У заготовці вже є клас і його атрибут, тож додайте решту. Кожен метод нижче має контракт, а підказки кажуть, який саме.

## 1. Зібрати страхувальну систему

`create` приймає навантаження, на яке розрахована страхувальна система, і повертає її. Якщо оцінка нуль або менше, то це взагалі не страхувальна система, тож це `pre`.

```sather
harness ::= #SAFETY_HARNESS(120);
harness.limit
-- => 120
```

## 2. Скільки ще витримає?

`spare_capacity` приймає навантаження на страхувальній системі й повертає, скільки ще вона може витримати. Навантаження не може бути відʼємним і не може перевищувати ліміт. Обидві умови є `pre`. Відповідь ніколи не буває відʼємною, і це `post`.

```sather
harness.spare_capacity(40)
-- => 80
```

## 3. Наскільки вона заповнена?

`percent_used` приймає навантаження й повертає його як відсоток від ліміту, заокруглений у менший бік. Навантаження не може бути відʼємним, і відповідь ніколи не буває відʼємною.

```sather
harness.percent_used(60)
-- => 50
```

## 4. Чи безпечно?

`is_safe` приймає навантаження й відповідає, чи воно в межах ліміту. Запитати можна про будь-яке навантаження, навіть безглузде, тож на навантаження немає `pre`. Але напишіть `post`, який каже, що відповідь дорівнює правді тоді й лише тоді, коли навантаження в межах ліміту.

```sather
harness.is_safe(200)
-- => false
```
