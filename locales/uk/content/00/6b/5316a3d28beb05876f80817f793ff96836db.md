# Докладніше

У Elixir функції можна викликати динамічно.

Усі назви модулів є атомами. Усі назви модулів Elixir під час компіляції автоматично отримують префікс `Elixir.`

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```

Elixir може визначити, яку функцію викликати під час виконання, використовуючи назву модуля для пошуку. Пошук можна виконати динамічно, якщо назву модуля привʼязано до змінної.

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```
