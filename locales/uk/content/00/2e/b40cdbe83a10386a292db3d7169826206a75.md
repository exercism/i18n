# Вступ

У Common Lisp є поняття The Printer, яке охоплює всі функції для запису текстових представлень даних Lisp. До таких функцій належить `format`, яка дає змогу програмісту форматувати дані на власний розсуд.

Тема можливостей `format` і Lisp Printer загалом дуже широка; тут ми опишемо лише основи використання `format`.

## Функція FORMAT

Функція `format` приймає щонайменше два аргументи: потік, у який друкувати, і керуючий рядок, що визначає, що саме і як друкувати.

Потоки - окреме поняття, про яке ми поговоримо деінде. Але поки що достатньо знати, що друк відбувається в потік, і що для цього аргументу є два особливі значення: `t` і `nil`. `t` означає друкувати в стандартний вивід (насправді в потік, з яким повʼязана змінна `*standard-output*`), а `nil` означає створити рядок тексту (англ. string) і повернути його.

Зауважмо, що `format` завжди обчислюється в `nil`, крім того останнього випадку, коли як потік указано `nil`. Це поширений спосіб просто виконати інтерполяцію рядків тексту або побудувати рядок.

```lisp
(format nil "hello world") ; => "hello world"
(format t "hello world")   ; => NIL (but "hello world" is printed to standard output)
```

## Директиви формату

Керуючий рядок може містити «директиви формату», які вказують `format`, що друкувати і як інтерпретувати будь-які інші параметри, передані `format`. Певною мірою керуючий рядок можна вважати програмою, яку `format` інтерпретує й виконує. Усі директиви починаються з `~`, за яким іде символ (наприклад, `~A`, `~D`, `~&`). Регістр символу не має значення.

Більшість директив формату просто підставляють аргумент, переданий `format`, у вихідні дані. Кажуть, що така директива «споживає» аргумент. Деякі директиви не споживають аргументів або споживають більше ніж один. Одна директива навіть дає змогу перестрибувати по списку аргументів або пропускати аргументи.

## Базове форматування

Дуже універсальна директива формату - `~A`. Вона друкує «зручну для людини» версію даних.

```lisp
(format nil "Value = ~a" 10)                ; => "10"
(format nil "hello ~a" "world")             ; => "hello world"
(format nil "The list is: ~A" (list 1 2 3)) ; => "The list is: (1 2 3)"
```

Ще одна корисна директива формату - `~S`. Вона друкує «зручну для машини» версію даних. Це може бути дуже корисно, якщо потрібно, щоб створені вихідні дані можна було прочитати як дані Lisp. Для багатьох речей вона матиме такий самий вигляд, як `~A`, але зауважмо, що, наприклад, для рядків тексту вихідні дані міститимуть лапки (екрановані, коли такий рядок входить до іншого рядка тексту), щоб це значення можна було прочитати назад як рядок тексту.

```lisp
(format nil "~s" 10)            ; => "10"
(format nil "~s" "hello world") ; => "\"hello world\""
(format nil "~s" (list 1 2 3))  ; => "(1 2 3)"
```

Ще дві дуже корисні директиви - `~%` і `~&`. Перша виводить символ нового рядка, а друга виводить «свіжий рядок». Різниця в тому, що `~%` завжди виводить символ нового рядка, а `~&` виведе його, лише якщо ми зараз не на початку рядка. Жодна з них не споживає аргументів.

```lisp
(format nil "~%new~%lines") ; => "
                                  new
                                  lines"

(format nil "~&new~&lines"  ; => "new
                                  lines"
```

І нарешті, `~~` - проста директива, яка виводить сам символ `~`.
