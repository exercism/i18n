# Підказки

Код має містити функцію frequency :: Int -> [Text] -> Map Char Int, яка приймає кількість воркерів для паралельної роботи та масив текстів і повертає загальну частоту кожної літери в тексті.

## Бенчмарк

Перевірте, як зміна кількості воркерів впливає на швидкодію рішення, запустивши бенчмарк. Для запуску використайте `stack bench`. Сміливо змінюйте `bench/Benchmark.hs`, щоб дослідити швидкодію рішення на різних вхідних даних.
