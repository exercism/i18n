# Вступ

`Tuple` багато в чому досить схожий на `Vector` (одновимірний `array`).
Однак є кілька важливих відмінностей.

- Кортежі записують у круглих дужках `( )`, а не в квадратних `[ ]`, хоча дужки можна опускати, коли зміст однозначний.
- Кортежі не обовʼязково однорідні: тип кожного елемента зберігається окремо.
- Кортежі незмінні.

Незмінність дає більше можливостей для оптимізацій компілятора і робить кортежі продуктивнішими за вектори, тож їм варто віддавати перевагу там, де змінність не потрібна.

```julia-repl
julia> t = (3, 5.2, "xyz")
(3, 5.2, "xyz")

# Non-homogeneous:
julia> dump(t)
Tuple{Int64, Float64, String}
  1: Int64 3
  2: Float64 5.2
  3: String "xyz"

julia> t[2]
5.2

# Immutable:
julia> t[2] = 7.3
ERROR: MethodError: no method matching setindex!(::Tuple{Int64, Float64, String})
```

Існує також конструктор `Tuple()`, який перетворює будь-яку колекцію, яку можна перебирати, на кортеж.
Це зручно: він трактує рядок тексту (англ. string) як колекцію символів, яку можна перебирати.

```julia-repl
julia> Tuple("Julia")
('J', 'u', 'l', 'i', 'a')
```

У будь-якому кортежі можна звертатися до елементів за індексом або перебирати їх у циклі.

Будь-який суто числовий кортеж можна так само використовувати в математичних функціях, як-от `sum()`, точнісінько як масиви.

## Розпакування

Кортеж можна розпакувати на окремі елементи за допомогою множинного присвоєння.
Для елементів, які не потрібні, як фіктивну змінну використовують підкреслення `_`.

```julia-repl
julia> tup = (1, "Julia", true)
(1, "Julia", true)

julia> num, name, _ = tup
(1, "Julia", true)

julia> uppercase(name), 2num
("JULIA", 2)
```

Програмістам, які пишуть на Python, цей синтаксис множинного присвоєння добре знайомий.

## Іменовані кортежі

`Tuple` містить лише значення.
`NamedTuple` поєднує кожне значення з іменем.

Окремі поля тоді доступні через «точкову» нотацію:

```jullia-repl
julia> nt = (a = 1, b = 7.3)
(a = 1, b = 7.3)

julia> dump(nt)
@NamedTuple{a::Int64, b::Float64}
  a: Int64 1
  b: Float64 7.3

julia> nt.b
7.3
```

Усередині імʼя зберігається як `Symbol` (незмінний тип, а перед іменем ставлять двокрапку `:`), тому доступний альтернативний синтаксис:

```julia-repl
julia> nt[:b]
7.3
```

Легко отримати окремо або імена (їх також називають «ключами»), або значення:

```julia-repl
julia> nt
(a = 1, b = 7.3)

julia> keys(nt)
(:a, :b)

julia> values(nt)
(1, 7.3)
```

Варто зауважити: коли ми перебираємо іменований кортеж, то отримуємо лише _значення_, а _імена_ ігноруються.

Кортежі (іменовані чи ні) дуже часто використовують, щоб передавати структуровані дані у функції та з них.
Незмінність у цьому випадку корисна: вона забезпечує безпеку даних і дає змогу застосовувати агресивніші оптимізації компілятора.
