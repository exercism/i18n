# Вступ

Іноді потрібно розглядати послідовність як низку *частин*,
а не елемент за елементом. Бібліотеки [`grouping`][grouping],
[`splitting`][splitting] та
[`splitting.monotonic`][splitting.monotonic] дають нам чотири
способи це зробити.

## `group`: неперетинні групи розміром *n*

```
group ( seq n -- groups )
```

```factor
USING: grouping ;

{ 1 2 3 4 5 6 7 } 3 group .
! => { { 1 2 3 } { 4 5 6 } { 7 } }
```

Якщо довжина послідовності не кратна *n*, остання група
буде коротшою за *n*.

## `clump`: ковзне вікно розміром *n* із перекриттям

```
clump ( seq n -- clumps )
```

```factor
USING: grouping ;

{ 1 2 3 4 5 } 2 clump .
! => { { 1 2 } { 2 3 } { 3 4 } { 4 5 } }
```

Якщо послідовність коротша за *n*, результат буде порожнім.

## `split-when`: розбиття там, де спрацьовує предикат

```
split-when ( seq quot: ( elt -- ? ) -- pieces )
```

```factor
USING: splitting ;

{ 1 2 0 3 4 0 5 } [ zero? ] split-when .
! => { { 1 2 } { 3 4 } { 5 } }
```

Кожен елемент отримує власний виклик предиката; істинні
елементи позначають *точки розриву* і не потрапляють
у результат.

## `monotonic-split`: розбиття серій там, де не проходить перевірка сусідніх пар

```
monotonic-split ( seq quot: ( a b -- ? ) -- pieces )
```

```factor
USING: splitting.monotonic ;

{ 1 1 2 2 2 3 } [ = ] monotonic-split .
! => { { 1 1 } { 2 2 2 } { 3 } }
```

Предикат працює з *сусідніми парами*. Поки він повертає
істину, серія продовжується; коли він повертає `f`,
починається нова частина. З `[ = ]` ми отримуємо серії
однакових елементів, а з `[ <= ]` - неспадні серії, і так далі.

## Коли що використовувати

- **`group`/`clump`**: ми знаємо потрібний *розмір*.
- **`split-when`**: ми знаємо, який вигляд має *елемент розриву*.
- **`monotonic-split`**: ми знаємо, завдяки чому два сусідні
  елементи *все ще належать до однієї серії*.
