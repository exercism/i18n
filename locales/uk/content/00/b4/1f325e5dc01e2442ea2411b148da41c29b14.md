# Докладніше

[`list`][list] - це змінна колекція елементів у _послідовності_.
 Як і більшість колекцій (_дивіться вбудовані [`tuple`][tuple], [`dict`][dict] і [`set`][set]_), масиви можуть зберігати посилання на будь-який тип (або кілька типів) даних, зокрема на інші масиви.
 У Python їх вважають [послідовністю][sequence type], і їх можна копіювати повністю або частково за допомогою [синтаксису зрізів][slice notation].
Як і в будь-якій послідовності, до елементів усередині `lists` можна звертатися за номером `0-based index` зліва або за номером `-1-based index` справа.

Масиви підтримують як [загальні][common sequence operations], так і [змінні][mutable sequence operations] операції над послідовностями, як-от `min(<list>)`/`max(<list>)`, `<list>.index()`, `<list>.append()` і `<list>.reverse()`.
 Елементи можна перебирати за допомогою конструкції `for item in <list>`, а також `for index, item in enumerate(<list>)`, коли потрібні і сам елемент, і його індекс.

Python надає багато корисних [методів][list-methods] для роботи з масивами.

 Оскільки масиви змінні, методи масиву **змінюють вихідний обʼєкт масиву**, переданий у метод.
Якщо змінювати обʼєкт небажано, потрібно зробити `shallow copy` (_щонайменше_) вихідного `list` за допомогою `slice` або `<list>.copy()`.


## Додавання елементів

Додати елементи в кінець наявного масиву можна за допомогою `<list>.append(<item>)`:

```python
>>> numbers = [1, 2, 3]
>>> numbers.append(9)

>>> numbers
[1, 2, 3, 9]
```

Замість _додавання в кінець_, `<list>.insert(<index>, <item>)` додає елемент за _конкретним індексом_ усередині масиву.
`<index>` - це індекс елемента, _перед яким_ має зʼявитися новий елемент.
`<item>` - це елемент, який потрібно вставити.

**Примітка**: Якщо `<index>` дорівнює 0, елемент буде додано на початок масиву.
Якщо `<index>` більший за останній індекс у масиві, елемент буде додано в останню позицію, що рівнозначно використанню `<list>.append(<item>)`.

```python
>>> numbers = [1, 2, 3]
>>> numbers.insert(0, -2)

>>> numbers
[-2, 1, 2, 3]

>>> numbers.insert(1, 0)

>>> numbers
[-2, 0, 1, 2, 3]
```

`iterable` можна _поєднати_ з наявним масивом (тобто зʼєднати їх) за допомогою `<list>.extend(<iterable>)`.
`<list>.extend(<iterable>)` _розпакує_ переданий iterable, додаючи його елементи в тому самому порядку в кінець цільового масиву.
Якби тут використати `<list>.append(<item>)`, увесь iterable додався б як _**один елемент**_.


```python
>>> numbers = [1, 2, 3]
>>> other_numbers = [5, 6, 7]

>>> numbers.extend(other_numbers)

>>> numbers
[1, 2, 3, 5, 6, 7]

>>> numbers.extend([8, 9])

>>> numbers
[1, 2, 3, 5, 6, 7, 8, 9]
```


## Видалення елементів

`<list>.remove(<item>)` можна використати, щоб видалити елемент із масиву.
 `<list>.remove(<item>)` викине `ValueError`, якщо такого елемента в масиві немає.


```python
>>> numbers = [1, 2, 3]
>>> numbers.remove(2)

>>> numbers
[1, 3]

# Trying to remove a value that is not in the list throws a ValueError.
>>> numbers.remove(0)
ValueError: list.remove(x): x not in list
```

Або ж метод `<list>.pop(<index>)` і видалить елемент, **і** поверне його (`return`) для подальшого використання.

`<list>.pop(<index>)` приймає один необовʼязковий параметр: `index` елемента, який треба видалити й повернути.
Якщо необовʼязковий аргумент `<index>` не вказано, буде видалено й повернено останній елемент масиву.
Якщо `<index>` більший за останній індекс масиву, буде викинуто `IndexError`.


```python
>>> numbers = [1, 2, 3]
>>> numbers.pop(0)
1

>>> numbers
[2, 3]
>>> numbers.pop()
3

>>> numbers
[2]

# This will throw an error because there is only index 0.
>>> numbers.pop(1)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
IndexError: pop index out of range
```

Усі елементи можна видалити з `list` за допомогою `<list>.clear()`. Він не приймає жодних параметрів.


```python
>>> numbers = [1, 2, 3]
>>> numbers.clear()

>>> numbers
[]
```


## Обернення та зміна порядку

Порядок елементів масиву можна обернути _**на місці**_ за допомогою `<list>.reverse()`. Це змінить вихідний масив.


```python
>>> numbers = [1, 2, 3]
>>> numbers.reverse()

>>> numbers
[3, 2, 1]
```

Масив можна перевпорядкувати _**на місці**_ за допомогою [`<list>.sort()`][sort].
Типовий порядок сортування - _за зростанням_ зліва.
Документація Python пропонує [додаткові поради й прийоми сортування][sorting how to].

Докладніше про цю зміну та її обговорення командою розробників ядра Python можна прочитати в GitHub [issue 78742][78742].  

Технічні подробиці алгоритму наведено в статті J. Ian Munro та Sebastian Wild [Nearly-Optimal Mergesorts: Fast, Practical Sorting Methods That Optimally Adapt to Existing Runs][nearly-optimal-mergesorts]

[78742]: https://github.com/python/cpython/issues/78742

```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]

# The default sort order is *ascending*.
>>> names.sort()

>>> names
["Bruce", "Natasha", "Thor", "Tony"]
```

Щоб відсортувати масив у _спадному_ порядку, передаймо методу аргумент `reverse=True`:


```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]
>>> names.sort(reverse=True)

>>> names
["Tony", "Thor", "Natasha", "Bruce"]
```


Коли змінювати вихідний `list` небажано, можна скористатися вбудованими функціями [`sorted()`][sorted] і [`reversed()`][reversed].
 `sorted(<list>)` поверне відсортовану _копію_ й приймає ті самі параметри, що й `<list>.sort()`.
 `reversed(<list>)` повертає _ітератор_, який видає елементи масиву у зворотному порядку.
 `Iterators` докладно розглянемо в іншій вправі.


## Кількість входжень елемента в масиві

Дізнатися, скільки разів елемент трапляється в масиві, можна за допомогою `<list>.count(<item>)`.
 Він повертає загальну кількість разів, які `<item>` трапляється в масиві як елемент.


```python
>>> items = [1, 4, 7, 8, 2, 9, 2, 1, 1, 0, 4, 3]

>>> items.count(1)
3
```


## Пошук індексу елементів

`<list>.index(<item>)` поверне номер індексу _першого входження_ переданого елемента.
 Якщо входжень немає, виникає `ValueError`.
 Індексація `0-based` ведеться зліва, тобто позиція першого елемента - це індекс `0`.
 Також підтримується індексація справа, яка починається з індексу `-1`.


```python
>>> items = [7, 4, 1, 0, 2, 5]
>>> items.index(4)
1

>>> items.index(10)
ValueError: 10 is not in list
```

Якщо вказати індекси `start` і `end`, пошук відбудеться в межах конкретної ділянки масиву:


```python
>>> names = ["Tina", "Leo", "Thomas", "Tina", "Emily", "Justin"]
>>> names.index("Tina")
0

>>> names.index("Tina", 2, 5)
3
```

Якщо точна позиція елемента не потрібна, вбудований оператор `in` ефективніше перевіряє належність.


```python
>>> names = ["Tina", "Leo", "Thomas", "Tina", "Emily", "Justin"]

>>> "Thomas" in names
True
```


## Створення копій

Памʼятаймо, що змінні в Python - це імена, які вказують на обʼєкти, що стоять за ними.
 Упродовж роботи програми імена можна привʼязувати й перепривʼязувати до різних обʼєктів.
 Присвоєння обʼєкта `list` новій _**змінній**_ не копіює ні сам обʼєкт, ні жодних даних, на які він посилається.
 І нове, і старе імʼя вказуватимуть на той самий обʼєкт `list`.
 Крім того, масиви - це обʼєкти _контейнерного_ типу. Щоб заощадити місце, контейнери зберігають лише _посилання_ на елементи, а не самі елементи.
 Ця «оптимізація» може мати непередбачувані наслідки для неуважних.

`<list>.copy()` створить новий обʼєкт `list`, але **не** створить нових обʼєктів для _елементів_ масиву, на які він посилається: копія буде «поверхневою».
 `shallow copy` зазвичай достатньо, коли треба додати або видалити елементи в одному з обʼєктів `list`, не змінюючи інший.
 Але якщо є хоч найменший шанс, що _елементи, на які посилається_ `list`, випадково зміняться (_а отже, зміняться й усі повʼязані поверхневі копії_), варто скористатися [`copy.deepcopy()`][deepcopy] із модуля `copy`, щоб створити повну, або «глибоку», копію **всіх** посилань і обʼєктів.

Докладне пояснення поведінки імен, значень, масивів і вкладених масивів можна знайти в цьому чудовому дописі в блозі від [Ned Batchelder][ned batchelder]: [Names and values: making a game board][names and values].
 [Shallow vs Deep Copying of Python Objects][shallow vs deep] також дає гарний огляд того, що варто враховувати під час копіювання.
