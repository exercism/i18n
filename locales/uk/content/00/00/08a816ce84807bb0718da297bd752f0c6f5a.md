# Вступ

*Регулярний вираз* (regex) описує, яким має бути якийсь текст. Інструменти Factor для роботи з регулярними виразами зібрані в модулі [`regexp`][regexp], а сам вираз записують між `R/ ` та `/`.

Більшість символів у виразі означають самі себе. Кілька особливих елементів позначають *різновиди* символів або те, *скільки* їх має бути:

```
\d        ! any digit 0–9
\s        ! any whitespace; \S means any non-whitespace
[A-Z]     ! any one capital letter
.         ! any single character

{4}       ! exactly 4 times       +   ! one or more
{2,5}     ! 2 to 5 times          *   ! zero or more
?         ! optional (0 or 1)
```

Отже, `R/ [A-Z]{2}-\d{4}/` означає «дві великі літери, дефіс, чотири цифри».

`matches?` перевіряє, чи вписується *увесь* рядок тексту (англ. string) у вираз:

```
matches? ( string regexp -- ? )
```

```factor
USING: regexp ;

"NS-1024" R/ [A-Z]{2}-\d{4}/ matches? .   ! => t
"NS-10"   R/ [A-Z]{2}-\d{4}/ matches? .   ! => f
```

Інші слова зазирають *усередину* рядка тексту: `all-matching-subseqs` повертає всі збіги, `count-matches` рахує їх, `re-contains?` повідомляє, чи є хоч один збіг, а `re-replace` замінює кожен збіг на новий текст:

```
all-matching-subseqs ( string regexp -- seq )
count-matches        ( string regexp -- n )
re-contains?         ( string regexp -- ? )
re-replace           ( string regexp replacement -- result )
```

```factor
USING: regexp ;

"seen NS-1024 then AB-0007" R/ [A-Z]{2}-\d{4}/ all-matching-subseqs .
! => { "NS-1024" "AB-0007" }

"user=alice pass=hunter2" R/ pass=\S+/ "pass=****" re-replace .
! => "user=alice pass=****"
```
