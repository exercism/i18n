# Вступ

Поширений спосіб умовно виконати логіку в JavaScript - це умовна конструкція `if`.
Вона складається з ключового слова `if`, умови в круглих дужках і блоку коду у фігурних дужках.
Блок коду буде виконано, лише якщо умова набуває значення `true`.

```javascript
if (condition) {
  // code that is executed if "condition" is true
}
```

Її можна використовувати окремо або разом із ключовим словом `else`.

```javascript
if (condition) {
  // code that is executed if "condition" is true
} else {
  // code that is executed otherwise
}
```

Щоб вкласти ще одну умову в конструкцію `else`, можна використати `else if`.

```javascript
if (condition1) {
  // code that is executed if "condition1" is true
} else if (condition2) {
  // code that is executed if "condition2" is true
  // but "condition1" was false
} else {
  // code that is executed otherwise
}
```
