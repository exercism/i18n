# Instructions

Працюючи в _Instruments of Texas_, ми отримуємо завдання попрацювати над експериментальним калькулятором зі зворотним польським записом [RPN], написаним на Elixir. У нашої команди проблема: деякі операції спричиняють помилки й призводять до аварійного завершення процесу. Наше завдання - написати функцію, яка обгортає функцію операції, щоб помилки можна було обробляти елегантніше, ідіоматичним кодом Elixir.

## 1. Попередити команду

Реалізуйте функцію `calculate!/2`, щоб викликати функцію операції, передаючи стек як єдиний аргумент. Функція операції визначена деінде, але відомо, що вона може або завершитися успішно, або спричинити помилку.

```elixir
stack = []
operation = fn _ -> :ok end
RPNCalculator.calculate!(stack, operation)
# => :ok

stack = []
operation = fn _ -> raise ArgumentError, "An error occurred" end
RPNCalculator.calculate!(stack, operation)
# => ** (ArgumentError) An error occurred
```

> Імена функцій, що закінчуються на `!`, попереджають програмістів про те, що така функція може спричинити помилку

## 2. Обгорнути помилку

Під час додаткового дослідження ми помічаємо, що багато функцій використовують атоми й кортежі, щоб позначити свій успіх або невдачу. Реалізуйте `calculate/2` за цією стратегією.

```elixir
stack = []
operation = fn _ -> "operation completed" end
RPNCalculator.calculate(stack, operation)
# => {:ok, "operation completed"}

stack = []
operation = fn _ -> raise ArgumentError, "An error occurred" end
RPNCalculator.calculate(stack, operation)
# => :error
```

## 3. Передати повідомлення

Деякі помилки містять важливу інформацію, яка потрібна колегам, щоб забезпечити правильну роботу системи. Реалізуйте `calculate_verbose/2`, щоб передати повідомлення про помилку. Помилка - це структура, яка має поле `:message`.

```elixir
stack = []
operation = fn _ -> "operation completed" end
RPNCalculator.calculate_verbose(stack, operation)
# => {:ok, "operation completed"}

stack = []
operation = fn _ -> raise ArgumentError, "An error occurred" end
RPNCalculator.calculate_verbose(stack, operation)
# => {:error, "An error occurred"}
```
