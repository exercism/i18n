# Вказівки

У цій вправі ми будемо писати код, який допоможе фрилансерові спілкуватися з менеджером проєкту за допомогою кількох інструментів для швидкого обчислення денних і місячних ставок, за потреби із заданою знижкою.

Спершу встановімо кілька правил між фрилансером і менеджером проєкту:

- Денна ставка у 8 разів більша за погодинну ставку.
- У місяці 22 оплачувані дні.

Іноді фрилансер пропонує застосувати знижку до своєї денної ставки (наприклад, для найвідданіших клієнтів або для неприбуткових організацій).

Знижки подаються як дробові числа, що позначають відсотки, наприклад `25.0` (25%).

## 1. Обчисліть денну ставку за погодинною ставкою

Реалізуйте функцію для обчислення денної ставки за заданою погодинною ставкою:

```elixir
FreelancerRates.daily_rate(60)
# => 480.0
```

Повернена денна ставка має бути числом з плаваючою комою.

## 2. Обчисліть ціну зі знижкою

Реалізуйте функцію для обчислення ціни після застосування знижки.

```elixir
FreelancerRates.apply_discount(150, 10)
# => 135.0
```

Повернене значення завжди має бути числом з плаваючою комою, без жодного округлення.

## 3. Обчисліть місячну ставку за погодинною ставкою та знижкою

Реалізуйте функцію для обчислення місячної ставки та застосування знижки:

```elixir
FreelancerRates.monthly_rate(77, 10.5)
# => 12130
```

Повернену місячну ставку слід округлити вгору (до найближчого більшого цілого).

## 4. Обчисліть кількість робочих днів за бюджетом, погодинною ставкою та знижкою

Реалізуйте функцію, яка приймає бюджет, погодинну ставку та знижку й обчислює, на скільки робочих днів цього вистачить.

```elixir
FreelancerRates.days_in_budget(20000, 80, 11.0)
# => 35.1
```

Повернену кількість днів слід округлити вниз (до найближчого меншого) до одного знака після коми.
