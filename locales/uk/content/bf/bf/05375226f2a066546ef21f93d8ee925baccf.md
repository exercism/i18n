# Вступ

Масив [`list`][list] - це змінювана колекція елементів, що йдуть у _послідовності_.
 Як і більшість колекцій (_див. вбудовані [`tuple`][tuple], [`dict`][dict] та [`set`][set]_), масиви можуть містити посилання на будь-який (або кілька) тип(ів) даних, зокрема на інші масиви.
 Масиви можна копіювати повністю або частково за допомогою [зрізів][slice notation] або через `<list>.copy()`.
 Як і в будь-якій [послідовності][sequence type], до елементів у `lists` звертаються за номером `0-based index` зліва або за номером `-1-based index` справа.

Масиви підтримують як [загальні][common sequence operations], так і [змінювані][mutable sequence operations] операції послідовностей, як-от `min(<list>)`/`max(<list>)`, `<list>.index()`, `<list>.append()` та `<list>.reverse()`.
 Елементи всередині `list` можна перебирати за допомогою конструкції `for item in <list>`.
 Конструкцію `for index, item in enumerate(<list>)` можна використати, коли потрібні і індекс елемента, і значення елемента.

Python також надає багато корисних [методів масиву][list-methods] для роботи з масивами.
 Далі розглянемо добірку з цих `list methods`.


Зауважте: коли ми працюємо з `list` за допомогою `list-method`, **ми змінюємо сам масив**, тобто той обʼєкт, який було передано.
 Якщо ми не хочемо змінювати початковий `list`, потрібно принаймні зробити його `shallow copy` за допомогою зрізу або `<list>.copy()`.


## Додавання елементів

Щоб додати елемент у кінець, тобто в «правий бік» наявного масиву, скористаймося `<list>.append(<item>)`:

```python
>>> numbers = [1, 2, 3]
>>> numbers.append(9)

>>> numbers
[1, 2, 3, 9]
```

Замість _додавання в кінець_, `<list>.insert()` дає змогу додати елемент за _конкретним індексом_ у масиві.
Він приймає 2 параметри:

1. `<index>`, за яким ми хочемо вставити елемент.
2. `<item>`, який треба вставити.

**Зауваження**: якщо вказаний `index` дорівнює 0, елемент буде додано на початок `list`, тобто в його «лівий бік».
 Якщо вказаний `index` більший за останній `index` у `list`, елемент буде додано в саму кінцеву позицію, що рівнозначно використанню `<list>.append(<item>)`.


```python
>>> numbers = [1, 2, 3]
>>> numbers.insert(0, -2)

>>> numbers
[-2, 1, 2, 3]

>>> numbers.insert(1, 0)

>>> numbers
[-2, 0, 1, 2, 3]
```


`<list>.extend(<item>)` можна використати, щоб поєднати наявний масив з елементами іншого ітерованого обʼєкта (наприклад, `set`, `tuple`, `str` або `list`).
  Ітерований обʼєкт _розпаковується_, і його елементи додаються по порядку (_якби ми в цьому випадку використали `<list>.append(<item>)`, весь ітерований обʼєкт додався б як **один елемент**._).


```python
>>> numbers = [1, 2, 3]
>>> other_numbers = [5, 6, 7]

>>> numbers.extend(other_numbers)

>>> numbers
[1, 2, 3, 5, 6, 7]

>>> numbers.extend([8, 9])

>>> numbers
[1, 2, 3, 5, 6, 7, 8, 9]

>>> numbers.append([8,9])

>>> numbers
[1, 2, 3, 5, 6, 7, 8, 9, [8, 9]]
```


## Видалення елементів

Щоб видалити елемент з масиву, скористаймося `<list>.remove(<item>)`, передавши елемент для видалення як аргумент.
 `<list>.remove(<item>)` викличе `ValueError`, якщо такого елемента немає в `list`.


```python
>>> numbers = [1, 2, 3]
>>> numbers.remove(2)

>>> numbers
[1, 3]

# Trying to remove a value that is not in the list throws a ValueError
>>> numbers.remove(0)
ValueError: list.remove(x): x not in list
```


Або ж метод `<list>.pop(<index>)` одночасно видалить елемент **і** поверне (`return`) його для подальшого використання.


`<list>.pop(<index>)` приймає один необовʼязковий параметр: `index` елемента, який треба видалити й повернути.
 Якщо (необовʼязковий) аргумент `index` не вказано, буде видалено й повернено останній елемент `list`.
 Якщо вказаний `index` більший за `index` останнього елемента, виникає `IndexError`.


```python
>>> numbers = [1, 2, 3]

>>> numbers.pop(0)
1

>>> numbers
[2, 3]

>>> numbers.pop()
3

>>> numbers
[2]

>>> numbers.pop(1)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
IndexError: pop index out of range
```

Усі елементи можна видалити з `list` за допомогою `list.clear()`. Він не приймає жодних параметрів.

```python
>>> numbers = [1, 2, 3]
>>> numbers.clear()

>>> numbers
[]
```

## Обернення та зміна порядку

Метод `<list>.reverse()` оберне порядок елементів **на місці**.


```python
>>> numbers = [1, 2, 3]
>>> numbers.reverse()

>>> numbers
[3, 2, 1]
```


Масив можна перевпорядкувати _**на місці**_ за допомогою [`<list>.sort()`][sort].
Типово елементи сортуються _за зростанням_ зліва.
Документація Python пропонує [додаткові поради та прийоми сортування][sorting how to].

~~~~exercism/note
 З 2002 до 2022 року Python внутрішньо використовував для впорядкування масивів алгоритм [`Timsort`][timsort], але починаючи з `Python 3.11` перейшов на [`Powersort`][powersort].

[powersort]: https://www.wild-inter.net/publications/munro-wild-2018
[timsort]: https://en.wikipedia.org/wiki/Timsort
~~~~


```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]

# The default sort order is *ascending*.
>>> names.sort()

>>> names
["Bruce", "Natasha", "Thor", "Tony"]
```

Якщо потрібен порядок _за спаданням_, передамо аргумент `reverse=True`:

```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]
>>> names.sort(reverse=True)

>>> names
["Tony", "Thor", "Natasha", "Bruce"]
```

Якщо змінювати початковий масив небажано, можна скористатися вбудованою функцією [`sorted(<iterable>)`][sorted], щоб отримати відсортовану **копію**.


```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]

>>> sorted(names)
['Bruce', 'Natasha', 'Thor', 'Tony']
```


## Входження елемента в масив

Кількість входжень елемента в масив можна обчислити за допомогою `list.count(<item>)`.
 Він приймає як аргумент `item`, який треба порахувати, і повертає загальну кількість разів, коли цей елемент трапляється в `list`.


```python
>>> items = [1, 4, 7, 8, 2, 9, 2, 1, 1, 0, 4, 3]

>>> items.count(1)
3
```

## Пошук індексу елементів

`<list>.index(<item>)` поверне номер `index` _першого входження_ переданого елемента.
 Якщо входжень немає, виникає `ValueError`.
 Якщо точна позиція елемента не потрібна, вбудований оператор `in` ефективніший для перевірки, чи містить масив задане значення.


Індексація починається з нуля зліва, тож «перший» елемент має позицію `0`.
Індексація також працює справа, починаючи з `-1`.


```python
>>> items = [7, 4, 1, 0, 2, 5]

>>> items.index(4)
1

>>> items.index(10)
ValueError: 10 is not in list
```

Можна також указати індекси `start` і `end`, щоб звузити пошук до конкретної частини `list`:

```python
>>> names = ["Tina", "Leo", "Thomas", "Tina", "Emily", "Justin"]

>>> names.index("Tina")
0

>>> names.index("Tina", 2, 5)
3
```
