# Вступ

Досі ми бачили, що аргументи, передані в метод, зіставляються з оголошеними параметрами методу за позицією. Альтернативний підхід, особливо коли процедура приймає велику кількість аргументів, полягає в тому, що той, хто викликає, може зіставити аргументи, вказавши ідентифікатор оголошеного параметра.

Далі показано синтаксис:

```csharp
class Card
{
    static string NewYear(int year, int month, int day)
    {
        return $"Happy {year}-{month}-{day}!";
    }
}

Card.NewYear(month: 1, day: 1, year: 2020);  // => "Happy 2020-1-1!"
```
