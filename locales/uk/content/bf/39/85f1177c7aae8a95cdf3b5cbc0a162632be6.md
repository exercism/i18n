# CLI

## Налаштування

Найпростіший спосіб установити PureScript - скористатися Node.js і NPM.

Якщо Node.js ще не встановлено, його можна завантажити з [вебсайту Node.js][nodejs-website]. Коли Node.js буде встановлено й готово до роботи, введіть у терміналі цю команду, щоб установити компілятор PureScript, а також Spago - менеджер пакунків та інструмент збірки.

```shell
npm install -g purescript spago
```

Більше інформації можна знайти в [репозиторії PureScript][purescript-repository].

## Вимоги

Встановіть залежності вправи:

```shell
spago install
spago build
```

## Проходження набору тестів

Виконайте тести командою:

```shell
spago test
```

У наборах тестів усі тести, крім першого, пропущено. Це зроблено для того, щоб ми розвʼязували вправу крок за кроком.

Коли один тест проходить, можна увімкнути наступний, змінивши `xit` на `it`.

## Надсилання рішення

Коли жодного тесту не пропущено і всі вони проходять, рішення можна надіслати командою:

```shell
exercism submit src/<NAME>.purs
```

## Написання власних тестів

Щоб написати додаткові власні тести, створіть новий файл `test/Custom.purs` і надішліть його разом із рішенням та новим файлом:

```shell
exercism submit src/<NAME>.purs test/Custom.purs
```
