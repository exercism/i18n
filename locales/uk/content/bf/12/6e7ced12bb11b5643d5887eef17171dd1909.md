# Вказівки

Майбутній чарівниці Еліз потрібно потренуватися в базових прийомах. У неї є стіс карток, з яким вона хоче працювати.

Щоб трохи спростити собі роботу, вона використовує лише картки від 1 до 10.

Стіс карток представлено у вигляді `queue`, де низ стосу розташований на початку черги, а верх - у кінці.

## 1. Додати картку на верх стосу

Реалізуйте функцію `insert_top`, яка повертає копію стосу з новою карткою, доданою на верх стосу.

```gleam
insert_top(queue.from_list([5, 9, 7, 1]), 8)
// -> queue.from_list([5, 9, 7, 1, 8])
```

## 2. Прибрати верхню картку зі стосу

Реалізуйте функцію `remove_top_card`, яка повертає копію стосу без верхньої картки. Якщо заданий стіс порожній, слід повернути початковий стіс без змін.

```gleam
remove_top_card(queue.from_list([3, 2, 6, 4, 8]))
// -> queue.from_list([3, 2, 6, 4])
```

## 3. Додати картку в низ стосу

Реалізуйте функцію `insert_bottom`, яка повертає копію стосу з новою карткою, доданою в низ стосу.

```gleam
insert_bottom(queue.from_list([5, 9, 7, 1]), 8)
// -> queue.from_list([8, 5, 9, 7, 1])
```

## 4. Прибрати картку з низу стосу

Реалізуйте функцію `remove_bottom_card`, яка повертає копію стосу без нижньої картки. Якщо заданий стіс порожній, слід повернути початковий стіс без змін.

```gleam
remove_bottom_card(queue.from_list([8, 5, 9, 7, 1]))
// -> queue.from_list([5, 9, 7, 1])
```

## 5. Перевірити розмір стосу

Реалізуйте функцію `check_size_of_stack`, яка перевіряє, чи дорівнює розмір стосу заданому `stack_size`.

```gleam
check_size_of_stack(queue.from_list([3, 2, 6, 4, 8]), 4)
// -> False
```
