# Запуск тестів

Вправи, завантажені за допомогою [клієнта командного рядка Exercism](https://exercism.io/cli), надходять щонайменше у вигляді трьох файлів: `readme.md`, `.dpr` і `.pas`. Файл `.dpr` - це файл проєкту Delphi, а файл `.pas` запускає тести. Завантажте проєкт Delphi, двічі клацнувши на файлі `.dpr`, або відкрийте проєкт із самого Delphi. Новий файл `.pas` доведеться створити самостійно: саме в ньому буде код нашого рішення, який перевірятимуть тести. Як скомпілювати й запустити код, читайте у файлі `readme.md`.

Усі тести, крім першого, позначені як ігноровані, щоб можна було почати саме з нього. Щоб рухатися далі, просто закоментуйте атрибут `[Ignore]` у тесті, і зможете почати з ним працювати.

Переконайтеся, що [DUnitX](https://github.com/VSoftTechnologies/DUnitX) встановлено, якщо його ще не встановлено під час налаштування вище.
