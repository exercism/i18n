# Вступ

У Swift `String` - це рядок тексту (англ. string), тобто впорядкована колекція значень `Character`, яка представляє текст, призначений для читання людиною. Рядки тексту у Swift повністю підтримують символи Unicode та емодзі.

Ми створюємо рядок тексту за допомогою рядкового літерала, беручи текст у подвійні лапки (`"`). Для спеціальних символів використовуються керуючі послідовності: наприклад, `\n` позначає символ нового рядка, а `\"` - екрановану подвійну лапку всередині рядкового літерала.

Порожній рядок тексту записують як пару подвійних лапок, між якими нічого немає (`""`).

```swift
let hello = "Hello, World!"
let sausage = "Weißwurst is a tasty sausage."
var family = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶"
var empty = ""
```
