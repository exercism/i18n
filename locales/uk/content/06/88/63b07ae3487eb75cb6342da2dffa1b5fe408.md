# Інструкції

Розглянемо поліноміальну функцію виду f(x) = ax^3 + bx^2 + cx + d. Локальні мінімуми визначаються як f(x) < f(x - delta) та f(x) < f(x + delta). Скористаймося цим означенням, виведімо вираз для локального мінімуму, а також знайдімо локальний мінімум за заданих коефіцієнтів (a, b, c, d). Коефіцієнти описують функцію, яка має принаймні один мінімум.
Поверніть координату x, у якій досягається мінімум.
