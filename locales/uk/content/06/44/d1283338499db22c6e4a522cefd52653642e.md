# Вступ

Ігри на удачу потребують джерела випадковості. Словник [`random`][random] у Factor надає одне узагальнене слово, `random`, яке пристосовується до того, що ми йому передаємо, а також допоміжні засоби для перемішування й вибирання та спосіб зробити випадковість *відтворюваною* для тестів.

## Позначення слова як `inline`

Деякі завдання цієї вправи визначають слово, яке приймає *quotation* (блок `[ … ]`) як аргумент і виконує його. Factor має щодо цього одне тверде правило: **слово, яке застосовує `call` до quotation, отриманого як аргумент, потрібно оголосити як `inline`**, що записується так: `inline` ставиться одразу після закривного символу `;`.

`inline` вказує компілятору вставити тіло слова в кожне місце виклику замість того, щоб скомпілювати його окремо один раз.

- Quotation того, хто викликає, вшивається безпосередньо, тож **усе, що quotation залишає на стеку, повертається до того, хто викликав**, навіть попри те, що власний стековий ефект слова не оголошує жодних вихідних даних.

Ось маленьке слово, яке кладе `10` на стек, а потім виконує переданий йому quotation:

```factor
USING: kernel math prettyprint ;

: with-ten ( quot -- ) 10 swap call ; inline
```

Його стековий ефект, `( quot -- )`, не називає жодних вихідних даних, а проте виклик із двома quotation *різних* ефектів дає різні результати, і всі вони повертаються до того, хто викликав:

```factor
[ 1 + ] with-ten .        ! => 11   (quotation ( n -- n ): one value back)
[ dup 2 * ] with-ten . .  ! => 20
                          ! => 10   (quotation ( n -- n n ): two values back)
```

## `random`: один елемент

`random` (у [`random`][random]) узагальнений щодо свого аргументу:

```
random ( obj -- elt )
```

- Якщо дати йому **ціле число** `n`, він повертає випадкове ціле число з проміжку `[0, n)`:

```factor
USING: random ;

6 random .    ! 4   (a value from 0 to 5)
```

- Якщо дати йому **послідовність**, він повертає випадковий елемент:

```factor
{ "rock" "paper" "scissors" } random .    ! "paper"
```

Щоб кинути звичайний кубик, зсунемо діапазон на одиницю вгору: `random` від `6` дає від 0 до 5, тож `6 random 1 +` дає від 1 до 6.

## Вибирання кількох значень

Щоб зібрати фіксовану кількість випадкових значень, повторімо quotation за допомогою `replicate` (у [`sequences`][sequences]):

```
replicate ( n quot -- seq )
```

```factor
USING: random sequences ;

3 [ 6 random 1 + ] replicate .    ! { 4 1 6 }   (three dice)
```

## `randomize`: перемішування на місці

`randomize` (у [`random`][random]) повертає послідовність, елементи якої розташовані у випадковому порядку:

```
randomize ( seq -- randomized )
```

```factor
{ 1 2 3 4 5 } randomize .    ! { 3 1 5 2 4 }
```

Він перемішує **на місці** й повертає ту саму послідовність, тож якщо потрібно зберегти початковий порядок, спершу застосуймо `clone`.

## `sample`: кілька різних елементів

`sample` (у [`random`][random]) вибирає `n` *різних* елементів із послідовності, наче роздає руку карт, де та сама карта не трапляється двічі:

```
sample ( seq n -- seq' )
```

```factor
{ 10 20 30 40 50 } 3 sample .    ! { 40 10 30 }
```

Якщо попросити більше елементів, ніж є в послідовності, це помилка.

## Відтворювана випадковість

Типово `random` бере значення з глобального генератора, ініціалізованого від системного годинника, тож кожен запуск дає інший результат. Для тестів, або коли хочеться мати гру, яку можна *перегравати*, привʼяжімо генератор до фіксованого **початкового значення**.

`<mersenne-twister>` (у [`random.mersenne-twister`][mt]) будує генератор із цілочисельного початкового значення, а `with-random` (у [`random`][random]) виконує quotation із цим генератором:

```
<mersenne-twister> ( seed -- rnd )
with-random        ( rnd quot -- )
```

```factor
USING: random random.mersenne-twister ;

42 <mersenne-twister> [ 6 random 1 + ] with-random .
! always the same value for seed 42
```

Усе всередині quotation (`random`, `randomize`, `sample`) бере значення з ініціалізованого генератора, тож те саме початкове значення завжди відтворює той самий результат.

Слово, яке приймає quotation як аргумент і виконує його через `with-random`, підпадає під правило з розділу [Позначення слова як `inline`](#marking-a-word-inline): `with-random` зрештою викликає цей quotation, тож таке слово-обгортку потрібно позначити як `inline`.
