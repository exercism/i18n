# Вступ

Умовні вирази використовують, щоб виконати код залежно від того, чи умова **if** є **true**, чи **false**. Ці вирази записують так:

```haxe
if (condition) {
  expressions
};
```

Результат умови має тип `Bool`, тож коли він дорівнює `true`, вирази виконуються.

Іноді, коли умова насправді `false`, ми хочемо, щоб виконався інший фрагмент коду. Саме тут стає в пригоді вираз `else`. `else` виконує вирази, коли початкова умова `false`. А що, якщо треба перевірити умову для кількох варіантів? Тоді використовуємо `else if (condition)`. Ось повний приклад:

```haxe
var a = 10;

if (a == 2) {
  trace("a is 2");
} else if (a == 5) {
  trace("a is 5");
} else {
  trace("a is 10");
}

// a is 10
```
