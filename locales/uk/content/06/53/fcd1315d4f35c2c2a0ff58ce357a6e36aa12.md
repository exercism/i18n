Але дещо тут трохи безладно: координати Азари, схоже, відформатовано й відсортовано інакше, ніж координати Руї, і їм доводиться раз у раз переглядати то один список, то інший, щоб зʼясувати, які скарби відповідають яким місцям.
Як початківці на F#, вони звернулися до нас по допомогу написати невеличку програму (насправді набір функцій), яка краще впорядкує відомості про їхні пошуки.

## 1. Витягти координати

Реалізуйте функцію `getCooordinate()`, яка приймає пару `(treasure, coordinate)` зі списку Азари й повертає лише витягнуту координату з карти.

```fsharp
getCoordinate ("Scrimshaw Whale's Tooth", "2A")
// "2A"
```

## 2. Відформатувати координати

Реалізуйте функцію `convertCoordinate()`, яка приймає координату у форматі «2A» і повертає кортеж у форматі `(2, 'A')`.

```fsharp
convertCoordinate "2A"
// (2, 'A')
```

## 3. Зіставити координати

Реалізуйте функцію `compareRecords()`, яка приймає пару `(treasure, coordinate)` і запис `(location, coordinate, quadrant)` та порівнює координати з кожного з них.
Поверніть **`true`**, якщо координати «збігаються», і поверніть **`false`**, якщо ні.
За потреби переформатуйте координати для точного порівняння.

```fsharp
compareRecords ("Brass Spyglass", "4B") ("Seaside Cottages", (1, 'C'), "blue")
// false

compareRecords ("Model Ship in Large Bottle", "8A") ("Harbor Managers Office", (8, 'A'), "purple")
// true
```

## 4. Поєднати зіставлені записи

Реалізуйте функцію `createrecord()`, яка приймає пару `(treasure, coordinate)` зі списку Азари та запис `(location, coordinate, quadrant)` зі списку Руї й повертає `(coordinate, location, quadrant, treasure)`, **якщо координати збігаються**.
Якщо координати _не_ збігаються, поверніть кортеж такої ж форми, але заповнений `""`.
За потреби переформатуйте координати для точного порівняння.

```fsharp
createRecord ("Brass Spyglass", "4B") ("Abandoned Lighthouse", (4, 'B'), "Blue")
// ("4B", "Abandoned Lighthouse", "Blue", "Brass Spyglass")

createRecord ("Brass Spyglass", "4B") ("Seaside Cottages", (1, 'C'), "Blue")
// ("", "", "", "")
```
