# Інструкції

Напишіть функцію, яка перетворює звичайні числа на [порядкові числівники](https://en.wikipedia.org/wiki/Ordinal_numeral). Для нуля (0) просто поверніть "0" як рядок тексту (англ. string).

Порядкові числівники - це числа, які позначають позицію чогось у списку.
Саме в цьому контексті ми будемо використовувати порядкові числівники, записуючи назву числівника англійською.

Порядкові числівники мають такий вигляд (принаймні, одна з їхніх форм):

```
1st 2nd 3rd 4th 5th... 9th 10th 11th 12th... 20th 21st 22nd 23rd 24th... etc.
```

Отже, коли ми вводимо звичайне число, отримуємо його порядковий відповідник:

```
1 -> 1st
2 -> 2nd
3 -> 3rd
(and so on...)
```
