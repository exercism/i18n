# Вступ

Типи, які реалізують інтерфейс `IEnumerable<T>`, називають _перелічуваними_. Усі вбудовані типи колекцій реалізують цей інтерфейс.

Перелічуваний тип можна перебрати за допомогою циклу `foreach`:

```csharp
var primes = new[] { 2, 3, 5, 7 };
foreach (var prime in primes)
{
    Console.Write(prime);
}
// => 2357
```

Щоб реалізувати `IEnumerable<T>`, тип має реалізувати один метод: `IEnumerator<T> GetEnumerator()`. Як бачимо, перелічуваний тип перекладає сам перебір колекції на тип `IEnumerator<T>`. Цей інтерфейс має одну властивість і три методи, які потрібно реалізувати:

- `public T Current { get; }`: отримати поточний елемент.
- `public bool MoveNext ();`: перейти до наступного елемента; повертає `true`, якщо перехід до наступного елемента вдався, і `false`, якщо ні (елементи закінчилися).
- `public void Reset ();`: скинути перелічувач до початкового стану (перед першим елементом).
