# Інструкції

У цій вправі ми напишемо узагальнену (/ чарівну!) скриню TreasureChest, щоб зберігати в ній скарби.

## 1. Визначте тип TreasureChest

Визначте параметричний тип `TreasureChest{T}` із двома полями.

- Поле `password` типу `String`, яке буде використовуватися для зберігання пароля від скрині зі скарбами.
- Поле `treasure` типу `T`, яке буде використовуватися для зберігання скарбу.
Це значення узагальнене, тож скарбом може бути будь-що.

```julia-repl
julia> chest = TreasureChest{String}("password", "gold")
TreasureChest{String}("password", "gold")
```



## 2. Визначте функцію get_treasure()

Ця функція приймає два аргументи.

- `String` (для спроби ввести пароль)
- Тип `TreasureChest`

Ця функція має порівняти надану спробу пароля з `password` у `TreasureChest`.

- Якщо паролі збігаються, повернути скарб.
- Якщо паролі не збігаються, повернути `nothing`.

```julia-repl
julia> get_treasure("password", chest)
"gold"

julia> get_treasure("wrong", chest)
# no output

julia> isnothing(get_treasure("wrong", chest))
true
```

## 3. Визначте функцію multiply_treasure()

Ця функція приймає два аргументи.

- Множник `n` (ціле число).
- Тип `TreasureChest{T}`.

Функція має повернути новий `TreasureChest{Vector{T}}`, у якому
- Той самий пароль, що й в оригіналі
- Помножений скарб як `Vector{T}` довжини `n`, де оригінальний скарб повторюється `n` разів.

```julia-repl
julia> multiply_treasure(3, chest)
TreasureChest{Vector{String}}("password", ["gold", "gold", "gold"])
```
