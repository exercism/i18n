# Доповнення до інструкцій

## Як цю вправу влаштовано в треку Python

Тести для цієї вправи очікують, що програму реалізовано як `class` Garden (_див. також [concept:python/classes]()_).
Якщо ми не знайомі з класами в Python, цей [туторіал від Real Python][how-to-make-a-class] може стати гарним додатковим місцем, з якого варто почати.

`class` має реалізувати [`method`][methods] із назвою `plants`, який приймає імʼя учня як аргумент і повертає `list` назв рослин, що належать цьому учневі.


## Конструктори

Створення саду з прикладу:

```python
[window][window][window]
VRCGVVRVCGGCCGVRGCVCGCGV
VRCCCGCRRGVCGCRVVCVGCGCV
```

у тестах буде представлено як `Garden("VRCGVVRVCGGCCGVRGCVCGCGV\nVRCCCGCRRGVCGCRVVCVGCGCV")`.

Щоб таке представлення працювало, `class` має реалізувати [`__init__()`][init] [спеціальний метод][special-methods].
Якщо ми не знайомі з `__init__()` чи [_конструкторами_][what-is-a-constructor], докладніше це пояснює розділ [обʼєкти класів і екземплярів][class vs instance objects in python] з документації Python.


## Типові параметри

У деяких тестах до `__init__()` як аргумент передають `list` учнів.
Це має замінити перелік із дванадцяти учнів, наведений в умові задачі.
Обидві ці інструкції мають працювати з методом `__init__()`:


```Python
# Make a garden based on the default 12-student roster.
Garden("VRCGVVRVCGGCCGVRGCVCGCGV\nVRCCCGCRRGVCGCRVVCVGCGCV") 

# Make a garden based on a 2-student roster.
Garden("VRCC\nVCGG", students=["Valorie", "Raven"]) 
```

Один з підходів - зробити `list` учнів [типовим аргументом][default argument values]; документація Python докладно описує `default parameters`, пояснюючи [визначення функцій][function definitions].
