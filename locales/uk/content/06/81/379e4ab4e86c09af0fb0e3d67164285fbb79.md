# Додаток до інструкцій

## Реалізація

У цій вправі ми побачимо файл `cases_test.go`.
У ньому зберігаються тестові випадки, які використовуються в `leap_test.go`.
Здебільшого цей файл можна не враховувати.

Утім, якщо цікаво... іноді ми генеруємо тестові дані з [міжмовного репозиторію][problem-specifications-leap].
У цьому репозиторії вправи можуть мати [.json-файл][problem-specifications-leap-json], який містить спільні тестові дані.
Деякі з наших локальних вправ мають [проміжну програму][local-leap-gen], яка бере JSON зі специфікації задачі та перетворює його на структури Go, що подаються у файл `<exercise>_test.go`.
Перетворення цих даних, специфічне для Go, міститься у файлі `cases_test.go`.

[problem-specifications-leap]: https://github.com/exercism/problem-specifications/tree/master/exercises/leap
[problem-specifications-leap-json]: https://github.com/exercism/problem-specifications/blob/master/exercises/leap/canonical-data.json
