# If, Elseif, Else

Умовні конструкції з `if`, `elseif` та `else` належать до фундаментальних частин керування потоком виконання програми.
Умовна конструкція `if` обчислює вираз і, якщо результат `true`, виконує відповідну гілку коду.

```php
<?php

if ($expression) {
    // .. executed if $expression is true
}
```

Якщо вираз не є булевим значенням (англ. Boolean), під час обчислення зʼясовується, чи значення «правдиве», чи «неправдиве».
У PHP наведені нижче значення вважаються рівними неправді:

- булеве значення `false`
- ціле число `0`
- число з плаваючою комою `0.0` та `-0.0`
- порожній масив `[]`
- порожній рядок тексту (англ. string) `""` або числовий рядок тексту `"0"`
- `null`

Усі інші значення вважаються правдивими.

## Реагування на кілька умов

Після умовної конструкції `if` можна поєднати кілька умов за допомогою `elseif` та `else`.

```php
<?php

if ($value === 0) {
    // .. do something
} elseif ($value === 1) {
    // .. do something else
} else {
    // ,, do this if nothing else
}
```

Виконається лише одна умовна конструкція, результат якої виявиться правдивим.
Тому якщо кілька умов можуть виявитися правдивими, важливо, у якому порядку їх записано.

```php
<?php

if (true) {
    // .. always do something
} elseif (true)
    // .. will never be executed
} else {
    // .. will never be executed
}
```
