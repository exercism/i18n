# Вступ

**Регулярні вирази** (regex) це послідовності символів, які задають шаблон пошуку в тексті.

Вивчення синтаксису регулярних виразів виходить за межі цієї теми.
Зосередимося на виразах, які надає `jq` для роботи з регулярними виразами.

## Різновид регулярних виразів

Різні інструменти реалізують різні версії регулярних виразів.
`jq` використовує бібліотеку регулярних виразів [Oniguruma][oniguruma], яка переважно сумісна з регулярними виразами Perl v5.8.

Конкретний синтаксис, який використовує `jq`, можна [знайти в репозиторії Oniguruma на GitHub][onig-syntax].

<!-- prettier-ignore -->
~~~~exercism/caution
У `jq` немає жодного спеціального синтаксису для регулярних виразів.
Вони просто записуються як рядки тексту (англ. string).
Це означає, що всі зворотні слеші в регулярному виразі потрібно екранувати в рядку тексту.

Наприклад, клас символів для цифри (`\d`) треба записати як `"\\d"`.
~~~~

<!-- prettier-ignore-end -->

## Функції для регулярних виразів

Робота з регулярними виразами в `jq` обмежена [набором фільтрів][jq-regex-funcs].

### Проста перевірка на відповідність

Коли потрібно зʼясувати, чи відповідає рядок тексту шаблону, використовуємо фільтр `test`.

```jq
STRING | test(REGEX)
STRING | test(REGEX; FLAGS)
STRING | test([REGEX, FLAGS])
```

Цей фільтр повертає _булеве значення_ (англ. Boolean).

```jq
"Hello World!" | test("W")    # => true
"Goodbye Mars" | test("W")    # => false
```

### Інформація про збіг

Коли потрібно видобути підрядок, який насправді збігся з шаблоном, використовуємо фільтр `match`.

```jq
STRING | match(REGEX)
STRING | match(REGEX; FLAGS)
STRING | match([REGEX, FLAGS])
```

Цей фільтр повертає:

- нічого, якщо збігів немає, або
- обʼєкт із різними властивостями, якщо збіг є.

У цьому прикладі шукаємо дві однакові голосні поспіль за допомогою синтаксису зворотного посилання, `\1`.

```jq
"Hello World!" | match("([aeiou])\\1")
# => empty

"Goodbye Mars" | match("([aeiou])\\1")
# => {
#      "offset": 1,
#      "length": 2,
#      "string": "oo",
#      "captures": [
#        {
#          "offset": 1,
#          "length": 1,
#          "string": "o",
#          "name": null
#        }
#      ]
#    }
```

Фільтр `match` повертає обʼєкт для _кожного_ збігу.
У цьому прикладі показано, як працює прапорець `"g"`, щоб знайти всі голосні.

```jq
"Goodbye Mars" | match("[aeiou]"; "g")
# => { "offset": 1, "length": 1, "string": "o", "captures": [] }
#    { "offset": 2, "length": 1, "string": "o", "captures": [] }
#    { "offset": 6, "length": 1, "string": "e", "captures": [] }
#    { "offset": 9, "length": 1, "string": "a", "captures": [] }
```

### Захоплені підрядки

Подібно до фільтра `match`, фільтр `capture` повертає обʼєкт, якщо збіг є.

```jq
STRING | capture(REGEX)
STRING | capture(REGEX; FLAGS)
STRING | capture([REGEX, FLAGS])
```

Повернений обʼєкт є відображенням **іменованих захоплень**.

```jq
"JIRAISSUE-1234" | capture("(?<project>\\w+)-(?<issue_num>\\d+)")
# => {
#      "project": "JIRAISSUE",
#      "issue_num": "1234"
#    }
```

### Лише підрядки

Фільтр `scan` подібний до `match` із прапорцем `"g"`.

```jq
STRING | scan(REGEX)
STRING | scan(REGEX; FLAGS)
```

`scan` повертає _потік_ підрядків.

```jq
"Goodbye Mars" | scan("[aeiou]")
# => "o"
#    "o"
#    "e"
#    "a"
```

Скористаймося конструктором масиву `[...]`, щоб захопити підрядки.

```jq
"Goodbye Mars" | [ scan("[aeiou]") ]
# => ["o", "o", "e", "a"]
```

### Розбиття рядка тексту

Якщо ми знаємо, які частини рядка тексту хочемо **залишити**, використовуємо `match` або `scan`.
Якщо знаємо, які частини хочемо **відкинути**, використовуємо `split`.

```jq
STRING | split(REGEX; FLAGS)
```

<!-- prettier-ignore -->
~~~~exercism/caution
Фільтр `split` з **одним аргументом** сприймає свій аргумент як **фіксований рядок тексту**.

Щоб використати регулярний вираз із `split`, **потрібно** передати другий аргумент; можна передати порожній рядок тексту.
~~~~

<!-- prettier-ignore-end -->

Приклад, який розбиває рядок тексту за довільними пробільними символами.

```jq
"first   second           third fourth" | split("\\s+"; "")
# => ["first", "second", "third", "fourth"]
```

### Заміни

Фільтри `sub` і `gsub` можуть перетворювати вхідний рядок тексту, замінюючи знайдені частини вхідних даних рядком заміни.

Щоб замінити лише перший збіг, використовуємо `sub`.
Щоб замінити всі збіги, використовуємо `gsub`.

```jq
STRING | sub(REGEX; REPLACEMENT)
STRING | sub(REGEX; REPLACEMENT; FLAGS)
STRING | gsub(REGEX; REPLACEMENT)
STRING | gsub(REGEX; REPLACEMENT; FLAGS)
```

```jq
"Goodnight kittens. Goodnight mittens." | sub("night"; " morning")
# => "Good morning kittens. Goodnight mittens."

"Goodnight kittens. Goodnight mittens." | gsub("night"; " morning")
# => "Good morning kittens. Good morning mittens."
```

Текст заміни може посилатися на знайдені підрядки; використовуємо іменовані захоплення та [інтерполяцію рядків][jq-interp].

```jq
"Some 3-letter acronyms: gnu, csv, png"
| gsub( "\\b(?<tla>[[:alpha:]]{3})\\b";     # find words 3 letters long
        "\(.tla | ascii_upcase)" )          # upper-case the match
# => "Some 3-letter acronyms: GNU, CSV, PNG"
```

## Прапорці

У всіх наведених вище фільтрах FLAGS це рядок тексту, що складається з нуля або більше підтримуваних прапорців.

- `g` - глобальний пошук (знайти всі збіги, а не лише перший)
- `i` - пошук без урахування регістру
- `m` - багаторядковий режим (`'.'` відповідатиме символам нового рядка)
- `n` - ігнорувати порожні збіги
- `p` - увімкнено обидва режими: `s` і `m`
- `s` - однорядковий режим (`'^'` -> `'\A'`, `'$'` -> `'\Z'`)
- `l` - знаходити найдовші можливі збіги
- `x` - розширений формат регулярного виразу (ігнорувати пробіли та коментарі)

Наприклад

```jq
"JIRAISSUE-1234" | capture("(?<project>\\w+)-(?<issue_num>\\d+)")

# or with Extended formatting

"JIRAISSUE-1234" | capture("
                     (?<project>   \\w+ )  # the Jira project
                     -                     # followed by a hyphen
                     (?<issue_num> \\d+ )  # followed by digits
                   "; "x")
```
