# Вступ

Цикли `repeat-while` схожі на цикли `while`, однак вони відрізняються тим, що булевий вираз стоїть і обчислюється _після_ виконання тіла циклу. Як наслідок, ці цикли завжди виконуються принаймні один раз.

```swift
repeat {
  print("This runs at least once")
} while false
print("Loop done")

// prints:
// This runs at least once
// Loop done
```
