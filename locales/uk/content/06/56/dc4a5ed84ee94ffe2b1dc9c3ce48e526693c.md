# Вступ

PHP надає низку операторів для виконання арифметичних операцій. Для своїх арифметичних операторів PHP дотримується стандартного математичного порядку виконання операцій. Ось які оператори надає PHP:

* Ідентичність (+)
* Заперечення (-)
* Додавання (+)
* Віднімання (-)
* Множення (*)
* Ділення (/)
* Остача (%)
* Піднесення до степеня (**)

```php
$moles = +'10';
$aLotOfMoles = 6.022 * 10**23 * $moles;
```
