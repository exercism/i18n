# Вступ

У Common Lisp функція може мати деякі аргументи, які необовʼязкові.
Вони позначаються в лямбда-списку ключовим словом `&optional`.
Параметр звʼязується зі значенням `nil`, якщо його не вказано.
Якщо необовʼязкових параметрів кілька, вони звʼязуються по порядку.
Для необовʼязкових параметрів можна вказати типові значення.
Нарешті, для кожного необовʼязкового параметра можна вказати символ, який звʼязується зі значенням правда або неправда залежно від того, чи передав цей параметр той, хто викликає функцію (це називається «параметр supplied-p»).

```lisp
(defun optional-parameters (&optional x (y 'default) (z nil z-supplied-p))
  (list x y (if z-supplied-p (list :z-was-supplied z)
                             (list :z-was-not-supplied z))))

(optional-parameters)          ; => (NIL DEFAULT (:Z-WAS-NOT-SUPPLIED NIL))
(optional-parameters 5 nil 10) ; => (5 NIL (:Z-WAS-SUPPLIED 10))
```
