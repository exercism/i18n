# Інструкції

У цій вправі ми реалізуємо частину набору службових функцій, які допомагають розробнику очищати імена ідентифікаторів.

У 6 завданнях ми поступово побудуємо функції `transform` для перетворення окремих символів і `clean` для перетворення рядків тексту (англ. string).

Допустимий ідентифікатор складається з нуля або більше літер, символів підкреслення, дефісів, знаків питання та емодзі.

Якщо до функції `clean` передати порожній рядок тексту, вона повинна повернути порожній рядок тексту.

## 1. Замініть усі наявні дефіси на підкреслення

Реалізуйте функцію `transform`, щоб замінювати всі дефіси на підкреслення.

```fsharp
transform '-'  // => "_"
```

## 2. Приберіть усі пробільні символи

Приберіть усі пробільні символи.
Сюди входять також пробільні символи на початку й у кінці.

```fsharp
transform ' '  // => ""
```

## 3. Перетворіть camelCase на kebab-case

Змініть функцію `transform`, щоб вона перетворювала camelCase на kebab-case

```fsharp
transform 'D'  // => "-d"
```

## 4. Пропустіть символи, які є цифрами

Змініть функцію `transform`, щоб вона пропускала всі символи, які є цифрами.

```fsharp
transform '7'  // => ""
```

## 5. Замініть грецькі малі літери на знаки питання

Змініть функцію `transform`, щоб вона замінювала всі грецькі літери в діапазоні від 'α' до 'ω'.

```fsharp
transform 'β' // => "?"
```

## 6. Поєднайте ці операції, щоб працювати з рядком тексту

Реалізуйте функцію `clean`, щоб застосувати ці операції до цілого рядка тексту.

Символи, які не підпадають під ці правила, повинні залишатися без змін.

```fsharp
clean "  a2b Cd-ω😀  " //  => "ab-cd_?😀"
```

## Як зібрати рядок тексту з символів

Цю тему ми докладно розглянемо далі в силабусі.

Наразі може бути корисно знати, що існує [функція вищого порядку][higher-order-function] під назвою [`String.collect`][string-collect], яка перетворює колекцію `char` на рядок тексту за допомогою функції, яку ми надаємо.

```fsharp
let transform ch = $"{ch}_"
String.collect transform "abc"  // =>  "a_b_c_"
```
