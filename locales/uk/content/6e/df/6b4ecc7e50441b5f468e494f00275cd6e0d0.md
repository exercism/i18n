## Структура проєкту

-   `contracts` - вихідний код усіх смарт-контрактів проєкту та їхніх залежностей. Редагуйте лише файл contracts/template.fc.
-   `wrappers` - класи-обгортки (що реалізують `Contract` з ton-core) для контрактів, включно з примітивами серіалізації та десеріалізації й функціями компіляції.
-   `tests` - тести для контрактів.
-   `scripts` - скрипти, які використовує проєкт, переважно скрипти розгортання.
