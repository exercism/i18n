# Вступ

У JavaScript значення можуть бути різних типів. Змінити тип змінної можна за допомогою явного _перетворення типу_.
Крім того, JavaScript також виконує _приведення типу_ (неявне перетворення типу), коли цього вимагає контекст.

## Перетворення типу

JavaScript не має конструкції для приведення до (іншого) типу, як багато інших мов, але натомість можна скористатися деякими вбудованими засобами.
Зокрема, `Boolean`, `Number` і `String` можна використовувати як функції, щоб перетворити значення на відповідний тип.

### Перетворення на булеве значення (правдиві та хибні значення)

За допомогою `Boolean(value)` можна перетворити будь-яке значення на булеве значення (англ. Boolean).
Існує фіксований набір значень, так званих _хибних_, які перетворюються на `false`.
Найважливіше: `false`, `0`, порожній рядок тексту (англ. string), `null`, `undefined` та `NaN` є хибними.

Для всіх інших значень `Boolean` повертає `true`.
Такі значення називають _правдивими_.

```javascript
Boolean(-1);
// => true

Boolean(0);
// => false

Boolean(' ');
// => true

Boolean('');
// => false
```

Зауважмо, що через описані правила `'0'`, `'false'`, `[]` та `{}` є **правдивими** у JavaScript.

### Перетворення на число

`Number(value)` можна використати, щоб перетворити значення на число.
Пробільні символи на початку та в кінці рядка тексту ігноруються, а порожній рядок тексту перетворюється на `0`.
Якщо спробувати перетворити непримітивне значення або рядок тексту, що не є числом, результатом буде `NaN` ([Не число][mdn-nan]).

```javascript
Number('  -12.34  ');
// => -12.34

Number('1,2');
// => NaN

Number('');
// => 0

Number({ num: 123 });
// => NaN
```

### Перетворення на рядок тексту

За допомогою `String(value)` можна перетворити значення на рядок тексту.
Для примітивних значень результат буде таким, як ми й очікуємо.

```javascript
String(12.34);
// => '12.34'

String(false);
// => 'false'

String(null);
// => 'null'

String(undefined);
// => 'undefined'
```

Для масивів функція `String` застосує перетворення на рядок тексту до кожного елемента й зʼєднає результати комою.
Можна також самостійно застосувати [метод `join`][mdn-join], наприклад, щоб налаштувати роздільник.
Зауважмо, що в цих випадках `null` та `undefined` перетворюються на порожній рядок тексту.

```javascript
String([42, null, true, 'abc']);
// => '42,,true,abc'
```

Для обʼєктів `String` типово повертає неінформативний текст.

```javascript
String({ key: 'value' });
// => '[object Object]'
```

## Приведення типу

У певних контекстах JavaScript автоматично перетворює значення на інший тип даних, перш ніж виконати інструкцію.
Це неявне перетворення називають _приведенням типу_.

### Булевий контекст

Коли небулеве значення використовується в булевому контексті, JavaScript застосовує ті самі правила, що й функція `Boolean`, щоб неявно перетворити це значення.

Приведення до булевого значення зазвичай відбувається для

- умови [умовної конструкції][concept-conditionals]
- першого операнда [тернарного оператора][mdn-ternary] `?`
- операнда оператора логічного заперечення `!`
- операндів операторів `&&` (логічне і) та `||` (логічне або) (результат виразу є одним з операндів, не обовʼязково булевим значенням)

```javascript
const num = 0;
if (num) {
  // this block is NOT executed because 0 is falsy
}
```

### Контекст рядка тексту

Якщо оператор додавання `+` застосовується до примітивних значень і один з операндів є рядком тексту, інший теж буде приведений до рядка тексту.
Логіка перетворення така сама, як під час використання функції `String`.
Після цього два рядки тексту зʼєднуються.

```javascript
let name;
'hello ' + name;
// => 'hello undefined'
```

### Числовий контекст

Багато операторів приводить операнди до чисел (за потреби) згідно з логікою функції `Number`, поясненою вище.

- Арифметичні оператори: `+` (якщо не задіяно рядок тексту), `-`, `*`, `/`, `%`, `**`
- Оператори унарного плюса та унарного заперечення: `+`, `-`
- Оператори порівняння (для операндів, що не є рядками тексту): `>`, `>=`, `<`, `<=`
- Побітові оператори: `|`, `&`, `^`, `~`

Звернімося до [списку операторів MDN][mdn-operators], щоб дізнатися більше про будь-який з них.

Щоб уникати помилок, добре завжди явно викликати `Number` перед застосуванням цих операторів.
