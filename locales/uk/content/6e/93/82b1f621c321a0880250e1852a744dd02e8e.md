# Вказівки

У цій вправі ми реалізовуємо спосіб вести облік рекордів для найпопулярнішої гри в нашому місцевому залі ігрових автоматів.

Нам потрібно реалізувати 5 функцій, здебільшого для роботи з обʼєктом, у якому зберігаються рекорди.

## 1. Створення нової таблиці рекордів

Створіть функцію `create_score_board`, яка повертає словник, що слугує таблицею рекордів.
Ключами цього обʼєкта будуть імена гравців, а значеннями - їхні рахунки.
Для тестування потрібно одразу внести до обʼєкта один запис.
Цей початковий запис має складатися з `"The Best Ever"` як імені гравця та `1_000_000` як рахунку.

```gleam
create_score_board()
// returns an object with one initial entry
```

## 2. Додавання гравців до таблиці рекордів

Щоб додати гравця до таблиці рекордів, визначте функцію `add_player`.
Вона приймає 3 параметри:

- Перший параметр - це наявний словник таблиці рекордів.
- Другий параметр - це імʼя гравця у вигляді рядка тексту (англ. string).
- Третій параметр - це рахунок у вигляді цілого числа.

Функція повертає словник із доданими новим гравцем і рахунком.

## 3. Видалення гравців із таблиці рекордів

Якщо гравці порушують правила залу ігрових автоматів, їх вручну видаляють із таблиці рекордів.
Визначте `remove_player`, яка приймає 2 параметри:

- Перший параметр - це наявний словник таблиці рекордів.
- Другий параметр - це імʼя гравця у вигляді рядка тексту.

Ця функція має повертати словник без видаленого гравця.

Якщо гравця взагалі не було в таблиці, з таблицею нічого не має статися: її треба повернути без змін.

## 4. Збільшення рахунку гравця

Якщо гравець завершує ще одну гру в залі ігрових автоматів, до попереднього рахунку в таблиці додається певна кількість очок.
Реалізуйте `update_score`, яка приймає 3 параметри:

- Перший параметр - це наявний словник таблиці рекордів.
- Другий параметр - це імʼя гравця, чий рахунок потрібно збільшити.
- Третій параметр - це рахунок, який потрібно **додати** до збереженого рекорду.

Функція має повертати словник з оновленим рахунком.

Якщо гравця взагалі не було в таблиці, з таблицею нічого не має статися: її треба повернути без змін.

## 5. Нарахування бонусних очок за понеділок

У залі ігрових автоматів по понеділках ведеться окрема таблиця рекордів.
Наприкінці дня кожен гравець із цієї таблиці отримує 100 додаткових очок.

Реалізуйте функцію `apply_monday_bonus`, яка приймає таблицю рекордів.
Функція повертає словник із доданими бонусними очками для кожного гравця, зазначеного в цій таблиці.
