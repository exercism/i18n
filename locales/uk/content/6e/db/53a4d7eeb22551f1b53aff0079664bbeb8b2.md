# Про числа

У Haskell є тип `Num`, що є базовим для всіх числових типів.
Усередині типу Number є чотири основні підтипи: [`Int`][int], [`Integer`][integer], [`Double`][double] та [`Float`][float].

У Haskell є два цілочисельні типи, які представляють цілі числа.
Тип `Int` відповідає цілим числам фіксованого розміру, а `Integer` - цілим числам довільної точності.

`Integer` вміщує будь-яке число, яким би великим воно не було, аж до межі памʼяті машини, тоді як `Int` відповідає множині додатних і відʼємних цілих чисел, які можна виразити в 32 або 64 бітах (гарантовано щонайменше від -2^29 до 2^29 - 1).

Зауважмо, що, записуючи відʼємні числа, варто брати їх у дужки, щоб уникнути двозначності.

```haskell
1

(-1)
```

`Float` відповідає множині дійсних чисел, обмеженій точністю компʼютера.
Операції, визначені для чисел, зазвичай працюють або з одним типом, або з іншим, але не з обома одночасно.
Тип `Double` - число з плаваючою комою подвійної точності.

```haskell
10.5
```

## Перетворення між цілими числами та числами з плаваючою комою

Функція `toFloat` дає змогу перетворити `Int` або `Integer` на `Float`.

```haskell
toFloat 1
-- -> 1.0
```

Є також функція `fromIntegral`, яка перетворює будь-який числовий тип на потрібний числовий тип, виведений з контексту.

```haskell
fromIntegral 1
-- -> 1.0
```

Щоб перетворити `Float` на `Int`, можна використати функції [`round`][round], [`floor`][floor] або [`ceiling`][ceiling].
Функція `round` округлює до найближчого цілого, `floor` округлює вниз, а `ceiling` округлює вгору.

```haskell
round 1.5
-- -> 2

floor 1.5
-- -> 1

ceiling 1.5
-- -> 2
```

## Арифметичні оператори

З числовими типами можна використовувати [основні арифметичні оператори][math].
Це оператори `+`, `-`, `*`, `/` і `%`.
Коли ми використовуємо ці оператори, типи чисел повинні збігатися.
Функція `fromIntegral` виконає перетворення, щоб типи збіглися.

### Додавання, віднімання та множення

Оператор `+` використовують для додавання, оператор `-` - для віднімання, а оператор `*` - для множення.

| Оператор | Приклад        |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### Ділення

Ділення дає змогу поділити одне число на інше.
Для ділення використовують оператор `/`.
Результат завжди буде числом з плаваючою комою.

```haskell
4.0 / 2.5
-- -> 1.6

4 / 2
-- -> 2.0
```

~~~~exercism/caution
У деяких мовах програмування ділення на нуль дає помилку.

У Haskell ділення на нуль дає `Infinity` або `-Infinity`.
Єдиний виняток - ділення нуля на нуль, результатом якого буде `NaN` (не число).

```haskell
1 / 0
-- -> Infinity

(-1) / 0
-- -> -Infinity

0 / 0
-- -> NaN
```
~~~~

## Ділення цілих чисел

Ділення цілих чисел дає змогу поділити цілі числа й отримати цілу частину результату.
У Haskell є дві функції ділення цілих чисел, які відрізняються округленням, коли результат відʼємний:

- `div` округлює вниз, до мінус нескінченності.
- `quot` округлює в бік нуля.

```haskell
6 `div` 2
-- -> 3

5 `div` 2
-- -> 2

(-5) `div` 2
-- -> -3

5 `quot` 2
-- -> 2

(-5) `quot` 2
-- -> -2
```

~~~~exercism/caution
Ділення на нуль під час ділення цілих чисел призводить до винятку.
Це відрізняється від звичайного ділення.
~~~~

### Остача

Остачу від ділення цілих чисел можна знайти за допомогою `mod` або `rem`.
Вони відрізняються знаком результату, коли одне з чисел відʼємне:

- `mod` працює разом із `div`, і його результат має той самий знак, що й дільник.
- `rem` працює разом із `quot`, і його результат має той самий знак, що й ділене.

```haskell
5 `mod` 3
-- -> 2

(-5) `mod` 3
-- -> 1

5 `mod` (-3)
-- -> -1

5 `rem` 3
-- -> 2

(-5) `rem` 3
-- -> -2

5 `rem` (-3)
-- -> 2
```

Для будь-яких `x` і `y` (де `y` не дорівнює нулю) справджуються такі закони:

```haskell
(x `div` y) * y + (x `mod` y) == x
(x `quot` y) * y + (x `rem` y) == x
```

~~~~exercism/note
Коли обидва числа додатні, `div` і `quot` дають однаковий результат, як і `mod` та `rem`.
У такому разі `quot` і `rem` можуть бути трохи ефективнішими, бо `div` і `mod` потребують додаткових кроків для обробки відʼємних чисел.
~~~~

~~~~exercism/caution
Ділення на нуль під час використання `mod` або `rem` призводить до винятку.
Це відрізняється від звичайного ділення.

```haskell
1 `mod` 0
-- Exception: divide by zero
```
~~~~

## Піднесення до степеня

У Haskell є три оператори «піднесення до степеня», які працюють по-різному та приймають різні типи аргументів.

- `**` приймає два **числа з плаваючою комою** і використовує логарифми, щоб обчислити степінь.
- `^^` приймає **число з плаваючою комою** і підносить його до додатного або відʼємного **цілого** степеня.
- `^` приймає **будь-який числовий тип** і підносить його до **додатного цілого** степеня.

```haskell
3.0 ** 2.1
-- -> 10.04510856630514

2.5 ^^ 2
-- -> 6.25

2 ^ 3
-- -> 8
```

## Пріоритет і дужки

У Haskell можна використовувати дужки (`()`), які групують вирази.
Це корисно, коли ми хочемо змінити порядок виконання операцій.

Коли ми використовуємо кілька арифметичних операторів, порядок виконання операцій такий самий, як у математиці, також відомий як [PEMDAS][pemdas].
Порядок такий: дужки (`()`), показники степеня (`**`), множення (`*`) і ділення (`/`), додавання (`+`) і віднімання (`-`).

```haskell
2 + 3 - 4 * 4
-- -> -11

(2 + 3 - 4) * 4
-- -> 4
```
