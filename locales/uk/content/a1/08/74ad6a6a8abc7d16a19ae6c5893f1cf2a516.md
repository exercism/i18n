# Додаток до інструкцій

Перезапишіть наданий рядок тексту (англ. string) з номером телефону.
Якщо номер телефону недійсний, замініть його на порожній рядок тексту.

## Регістри

| Регістр   | Використання          | Тип     | Опис                                          |
| --------- | --------------------- | ------- | --------------------------------------------- |
| `$a0`     | вхідні/вихідні дані   | адреса  | номер телефону як рядок тексту, що завершується нульовим символом |
| `$t0-9`   | тимчасовий            | будь-який | використовується для тимчасового зберігання  |
