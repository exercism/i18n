# Додаток до інструкцій

## Приклад вхідних даних

```j
  INPUTS=: 2 ; 1 0 0 1 0 1 ; 10
```

Це означає, що вхідні дані такі:
```
  0{INPUTS NB. is the input base.
  1{INPUTS NB. is the digits.
  2{INPUTS NB. is the output base.
```
## Обробка некоректних вхідних даних

Якщо якесь із вхідних значень є некоректним, ваша функція має повернути або `empty` (наприклад, `0$0` або `''`).

### Приклади

- Якщо _вхідна основа_ менша за 2:
    ```j
      '' -: rebase 10 ; 0 0 0 0 ; 1
    ```

- Якщо _вихідна основа_ менша за 2:
    ```j
      '' -: rebase 1 ; 0 0 0 0 ; _7
    ```

- Якщо _цифри_ містять значення, більші за вхідну основу або рівні їй:
    ```j
      '' -: rebase 10 ; 1 0 2 0 ; 2
    ```
