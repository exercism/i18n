# Тести

Ми використовуємо [PonyTest](https://stdlib.ponylang.io/pony_test--index/) зі stdlib, щоб писати тести для перевірки рішення. Щоб перевірити рішення, скомпілюйте та запустіть свій код.

Наприклад, сеанс для «Hello World» може мати такий вигляд:

```text
[red@apophenia:~/exercism/pony/hello-world]$ ponyc
Generating
 Reachability
 Selector painting
 Data prototypes
 Data types
 Function prototypes
 Functions
 Descriptors
Optimising
Writing ./hello-world.o
Linking ./hello-world

[red@apophenia:~/exercism/pony/hello-world]$ ./hello-world 
1 test started, 0 complete: hello-world/HelloWorld started
1 test started, 1 complete: hello-world/HelloWorld complete
---- Passed: hello-world/HelloWorld
----
---- 1 test ran.
---- Passed: 1
```
