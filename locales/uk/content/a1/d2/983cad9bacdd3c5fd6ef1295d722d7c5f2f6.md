# Вступ

## Визначення змінних

Визначити змінну означає присвоїти значення імені. У Scala є два різновиди змінних: `val` і `var`.

Змінна `val` незмінна, тому її значення вже не можна змінити після першого присвоєння:

```scala
val numberTen = 10

numberTen = 11
// --> raises a compile error "reassignment to val"
```

Змінній `var`, на відміну від неї, можна повторно присвоїти нове значення того самого типу:

```scala
var someNumber = 10

someNumber = 11
// now someNumber has been reassigned
```

Scala належить до статично типізованих мов, а це означає, що кожна річ має тип під час компіляції. Змінну можна визначити або явно вказавши її тип, або дозволивши компілятору Scala вивести її тип на основі присвоєного значення (це називається виведенням типів). Отже, наведені нижче два визначення змінної рівнозначні:

```scala
val explicitNumber: Int = 10; // Explicitly typed
val implicitNumber = 10; // Implicitly typed
```

Після визначення тип змінної вже ніколи не може змінитися.

```scala
var count = 1; // Assigning an initial value of type Int
count = 2;     // Updating to new value is possible, because it is defined as var

count = false;
// --> raises a compile error "type mismatch"
```

## Визначення методів усередині класів

Scala є _обʼєктно-орієнтованою мовою_ і вимагає, щоб усі методи були визначені в _класі_. Для визначення класу використовується ключове слово `class`.

```scala
class Calculator {
  // ...
}
```

Усередині класу методи можна визначати, починаючи з ключового слова `def`, після якого йде назва. Кожен метод може мати нуль або більше параметрів, які перелічуються через кому в круглих дужках. Усі параметри треба типізувати явно, для параметрів виведення типів не працює. Після списку параметрів через ще одну двокрапку вказується тип поверненого значення методу.

Після визначення методу ставиться знак `=`, з якого починається тіло методу. У наведеному нижче прикладі тіло методу складається з двох інструкцій, узятих у фігурні дужки.

Метод поверне значення останнього виразу, у цьому випадку метод `add` повертає значення змінної `sum`:

```scala
class Calculator {
  // long form
  def add(x: Int, y: Int): Int = {
    val sum = x + y
    sum
  }
}
```

Є кілька покращень, які можна зробити, щоб скоротити цей метод і поліпшити читабельність:

- оскільки до змінної `sum` звертаються лише один раз, щоб повернути значення, її можна опустити
- методи, що складаються лише з однієї інструкції, не потребують фігурних дужок
- тип поверненого значення методу можна вивести так само, як і типи змінних

Так ми отримуємо такий однорядковий метод із тією самою функціональністю:

```scala
class Calculator {
  // shortened form
  def add(x: Int, y: Int) = x + y
}
```

## Створення екземплярів класів і виклик методів

Щоб викликати метод, спочатку створюємо екземпляр класу, а потім викликаємо метод на цьому екземплярі з аргументами:

```scala
val calculator = new Calculator()
val sum = calculator.add(5, 7)
// sum is of type Int with assigned value of 12
```

## Коментарі

Scala підтримує два типи коментарів: однорядкові та багаторядкові:

```scala
// this is a single line comment

/*
This comment spans across
multiple lines.
*/
```
