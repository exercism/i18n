# Тести

## Запуск тестів

Виконайте специфікацію тестів командою:

```bash
$ gradle test
```

## Увімкнення додаткових тестів

Коли всі активні тести проходять, увімкніть наступний тест, прибравши `@Ignore` перед обраним тестом. Зробіть це, видаливши рядок `@Ignore` або закоментувавши його, додавши два слеші на початку рядка.

```Groovy
//@Ignore
def 'outputs "Hello, Alice!" when given the name "Alice"'() {
    expect: hello.hello('Alice') == 'Hello, Alice!'
}
```
