# Інструкції

Ми допоможемо шкільним закоханим освідчитися одне одному в коханні в соціальних мережах, згенерувавши unicode-серце з їхніми ініціалами:

```
❤ J.  +  M. ❤
```

## 1. Очистьте імʼя

Визначте `cleanupname`, яка бере імʼя зі стеку. Замініть кожен `-`
на пробіл, а потім приберіть пробільні символи на початку й у кінці.

```factor
"Jane-Ann" cleanupname .
! => "Jane Ann"
```

## 2. Візьміть першу літеру імені

Визначте `firstletter`, яка бере імʼя. Скористайтеся `cleanupname` із
попереднього завдання, а потім візьміть перший символ результату й поверніть
його як рядок тексту (англ. string) з одного символу.

```factor
"Jane" firstletter .
! => "J"
```

## 3. Відформатуйте першу літеру як ініціал

Визначте `initial`, яка бере імʼя. Скористайтеся `firstletter` із попереднього
завдання, переведіть літеру у верхній регістр, а потім додайте `.`.

```factor
"Robert" initial .
! => "R."
```

## 4. Розмістіть ініціали всередині серця

Визначте `couple`, яка бере два імені зі стеку. Застосуйте `initial` із
попереднього завдання до кожного імені, а потім зберіть результат:

```factor
"Blake Miller" "Riley Lewis" couple .
! => "❤ B.  +  R. ❤"
```
