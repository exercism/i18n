# Докладніше

Інструкція `guard` у Swift призначена для дострокового виходу з функцій, циклів або методів, коли не виконано потрібну умову:

```swift
guard myValue >= 0 else { return 0 }
let root = myValue.squareRoot()
```

У наведеному вище прикладі `guard` обчислює булевий вираз, що йде після нього.
Якщо умова дорівнює `true`, виконання продовжується кодом після інструкції `guard`.
Якщо умова дорівнює `false`, виконується код у блоці `else`.

На відміну від інструкції `if`:

- Інструкція `guard` **мусить** мати гілку `else`.
- Гілка `else` **мусить** передати керування так, щоб вийти за межі навколишньої області видимості (наприклад, за допомогою `return`, `continue`, `break` або викинувши помилку).

`guard` часто використовують, щоб чисто перевіряти передумови.
Наприклад, розглянемо функцію sinc ($\text{sinc}(x) = \frac{\sin(x)}{x}$, де $\text{sinc}(0) = 1$, щоб уникнути ділення на нуль):

```swift
func sinc(_ x: Double) -> Double {
    guard x != 0 else { return 1 }
    return sin(x) / x
}

sinc(0)             // returns 1
sinc(Double.pi / 2) // returns 0.6366197723675814
```
