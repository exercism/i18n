# Тести

## Запуск тестів

Коли [кроки встановлення][test-installation-steps] виконано, ми можемо почати з будь-якого каталогу вправи (наприклад, `~/exercism/gdscript/two-fer`) і запустити скрипт (який лежить на рівень вище, у `../`), щоб перевірити наше локальне рішення цієї вправи:

```sh
../test-local-gdscript-solution.sh
```

## Розвʼязування вправи

Розвʼязати вправу означає домогтися того, щоб усі її тести проходили.

Щоб допомогти нам почати, кожна вправа містить файл GDScript, названий так само, як вправа (наприклад, `exercism/gdscript/two-fer/two_fer.gd`).
Ми можемо використати цей файл як відправну точку для побудови нашого рішення.
Цей файл можна змінювати за потреби, але тести вимагають, щоб назви функцій були такими, як надано спочатку.

[test-installation-steps]: https://exercism.org/docs/tracks/gdscript/tests
