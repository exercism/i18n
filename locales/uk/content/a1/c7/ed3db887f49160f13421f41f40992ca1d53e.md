# Діапазони

[Діапазони][range] задають інтервал між двома значеннями.
Найпоширеніші типи, які підтримують діапазони, це `Int`, `String` і `Date`.
Їх можна використовувати для багатьох речей: швидкого створення колекції, зрізання масиву, перевірки, чи значення належить діапазону, та ітерації.
Їх створюють за допомогою оператора діапазону `...` або `..<` (включно та невключно відповідно).

```swift
1...5 // A range containing 1, 2, 3, 4, 5
1..<5 // A range containing 1, 2, 3, 4
```

Причина, чому існує два оператори діапазону, полягає у створенні діапазонів, які включають або не включають кінцеве значення, а це буває корисно, наприклад, коли ми працюємо з індексами, що починаються з нуля.

~~~~exercism/note
Коли ми створюємо діапазон у Swift за допомогою операторів діапазону `...` або `..<` і хочемо викликати метод на цьому діапазоні, потрібно взяти діапазон у дужки.
Інакше метод буде викликано на другому аргументі оператора діапазону.

```swift
(1...5).contains(3) // Returns true
1...5.contains(3) // => Error: value of type 'Int' has no member 'contains'
```
~~~~

## Перетворення діапазону на масив

Щоб перетворити діапазон на масив, можна використати ініціалізатор `Array`.
Це стане в пригоді, коли ми хочемо створити колекцію значень, не виписуючи їх усі.

```swift
let range = 1...5
let array = Array(range)
// Returns [1, 2, 3, 4, 5]
```

## Зрізання масиву

Діапазони можна використовувати для зрізання масиву.

```swift
let array = [1, 2, 3, 4, 5]
// Returns [1, 2, 3, 4, 5]
let slice = array[1...3]
// Returns [2, 3, 4]
```

## Методи діапазону

Діапазони мають набір методів, які можна використовувати для роботи з ними.
Наприклад, ці методи дають змогу отримати суму всіх значень діапазону або перевірити, чи містить діапазон певне значення.

| Метод                   | Опис                                                                     | Приклад                               |
| ----------------------- | ----------------------------------------------------------------------- | ------------------------------------- |
| `count`                 | Повертає розмір діапазону                                                | `(1...5).count // returns 5`          |
| [`contains`][contains]  | Повертає `true`, якщо діапазон містить задане значення, інакше `false`    | `(1...5).contains(3) // Returns true` |

## Діапазони без кінця та без початку

Діапазон може бути без кінця та без початку.

Використання діапазонів без кінця та без початку стає в пригоді, коли ми хочемо, наприклад, зрізати масив від початку або до кінця.

~~~~exercism/caution
Якщо застосувати діапазон без кінця не до колекції, він може утворити нескінченну послідовність, тож слід бути обережними.
~~~~

## Діапазони рядків тексту

Рядок тексту (англ. string) можна використовувати в діапазонах, і це дає змогу отримати інтервал рядків між двома рядками.
Наприклад, це стане в пригоді, коли ми хочемо отримати алфавіт.

```swift
"a"..."z" // A range containing ["a", "b", "c", ..., "z"]
```
