# Інструкції

Ми запускаємо систему, яка складається з кількох застосунків, що створюють багато логів. Хочемо написати невелику програму, яка збере ці логи разом і надасть їм мітки відповідно до рівня серйозності. Усі застосунки в нашій системі використовують однакові коди логів, але деякі застарілі застосунки підтримують не всі коди.

| Код логу              | Мітка логу | Чи підтримується в застарілих застосунках? |
|-----------------------| --------- | ------------------------- |
| 0                     | trace     | ні                        |
| 1                     | debug     | так                       |
| 2                     | info      | так                       |
| 3                     | warning   | так                       |
| 4                     | error     | так                       |
| 5                     | fatal     | ні                        |
| інший / не підтримується | unknown   | -                         |

## 1. Визначте мітку логу

Реалізуйте функцію `LogLevel.to_label/2`. Вона має приймати код як ціле число та булеве значення (англ. Boolean) - прапорець, який вказує, чи надійшов лог від застарілого застосунку, - і повертати мітку рядка логу як атом.

Коди логів, не вказані в таблиці, мають повертати мітку _unknown_. Коди логів, вказані в таблиці як непідтримувані в застарілих застосунках, також мають повертати мітку _unknown_, якщо лог надійшов від застарілого застосунку.

```elixir
LogLevel.to_label(0, false)
# => :trace

LogLevel.to_label(0, true)
# => :unknown
```

## 2. Надішліть сповіщення

Когось потрібно повідомляти, коли трапляється щось несподіване.

Реалізуйте функцію `LogLevel.alert_recipient/2`, щоб визначити, кому потрібно надіслати сповіщення. Вона має приймати код як ціле число та булеве значення - прапорець, який вказує, чи надійшов лог від застарілого застосунку, - і повертати імʼя отримувача як атом.

Скористайтеся функцією `LogLevel.to_label/2` з попереднього завдання. Якщо мітка логу - _error_ або _fatal_, надішліть сповіщення команді _ops_. Якщо надійшов лог із міткою _unknown_ від застарілої системи, надішліть сповіщення команді _dev1_, а інші мітки _unknown_ надсилайте команді _dev2_. Усі інші мітки логів можна спокійно ігнорувати, повернувши _false_.

```elixir
LogLevel.alert_recipient(-1, true)
# => :dev1

LogLevel.alert_recipient(0, false)
# => false
```
