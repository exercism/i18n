# Про основи

Kotlin належить до статично типізованих мов, і його створено для повної взаємодії з Java.

Від Java його відрізняє те, що Kotlin:

- має чистіший і лаконічніший синтаксис;
- увібрав багато можливостей функціональних мов;
- має широку підтримку значень, які можуть бути `null`.

## Змінні

Оскільки Kotlin статично типізований, тип кожного значення потрібно _знати_ вже на етапі компіляції.

Втім, [виведення типу][inference] у Kotlin дуже потужне, тож _вказувати_ тип часто необовʼязково.

Є два способи оголосити змінну.

1. `val` створює незмінну змінну, і спроба її змінити призводить до помилки на етапі компіляції.

```kotlin
val x = 42  // => 42
x = 43      // => 'val' cannot be reasssigned
```

2. `var` створює змінну, яку можна змінювати.

```Kotlin
var x = 42  // => 42
x = 43      // => 43
```

Оскільки незмінні змінні прибирають цілий клас поширених помилок, `val` варто використовувати всюди, де це можливо.

До того ж навіть `var` не може змінити тип:

```kotlin
var x = 42
x = "foobar" // => Type mismatch: inferred type is String but Int was expected
```

Щоб не відволікати увагу, у цьому силабусі ми здебільшого будемо опускати явні типи.
Утім, типи рекомендується вказувати принаймні для:

- публічних API
- сигнатур функцій
- місць, які потребують документації

Деякі компанії та організації вимагають суворої типобезпеки й забороняють виведення типу, тоді як інші обмежують його «простими» типами або ж цілком його приймають.

```kotlin
val x: Int = 42  // => 42
```

Загалом назви змінних і функцій мають бути в `camelCase`, а не в `snake_case`

## Функції

Щоб оголосити функцію, використовуємо ключове слово `fun`.
На відміну від Java, функції не обовʼязково мають бути частиною класу.

```Kotlin
fun hello(): String {
    return "Hello, World!"
}

fun add(x: Int, y: Int): Int {
    return x + y
}
```

Кілька моментів, на які варто звернути увагу:

- Дужки `()` потрібні після назви функції, навіть якщо вона не приймає аргументів.
- Для аргументів функції потрібно вказати тип: тут виведення типу не працює (на відміну від змінних).
- Тіло функції записують у фігурних дужках `{ }` (хоча див. нижче).
- Ключове слово `return` обовʼязкове, якщо функція повертає значення.
- Крапки з комою `;` у кінці рядків необовʼязкові й зазвичай опускаються.
- Арифметичні оператори `+`, `-`, `*`, `/` такі самі, як у більшості поширених мов.

Однак для цих дуже простих функцій «з одним виразом» є скорочений синтаксис:

```Kotlin
// return type is usually omitted for single-expression functions
fun add(x: Int, y: Int) = x + y  
```
Функції можуть мати параметри з типовими значеннями. 
Ці значення використовуються, якщо їх опустити під час виклику функції:

```kotlin
fun ping(host: String = "localhost") {
    println("PING --> $host")
}

ping("exercism.io")  // PING --> exercism.io
ping()               // PING --> localhost
```

Функції на Exercism зазвичай повертають значення (через те, як побудовано тестовий раннер).
Щоб користуватися Kotlin ширше, варто знати, що функція, яка не повертає значення, може опустити тип поверненого значення й ключове слово `return`.

Тоді кажуть, що вона має тип поверненого значення `Unit`: він відповідає `void` у Java та кількох інших мовах.

## Коментарі

Однорядкові коментарі починаються з `//`, а все, що йде далі в рядку, ігнорується.

Багаторядкові коментарі починаються з `/*` і закінчуються `*/`.

```Kotlin
fun hello(): String {
    /*
     * Failing to run this program on a new installation 
     * is considered bad luck
    */
    return "Hello, World!" // the compiler pixies are now happy
}
```

Тут усе так само, як у Java.
