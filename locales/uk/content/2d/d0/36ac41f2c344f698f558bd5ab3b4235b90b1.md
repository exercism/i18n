# Інструкції

Ми допомагаємо з дослідженням птахів. Щодня хтось сидить у засідці й рахує, що пролітає повз, а підрахунки за день повертаються у вигляді масиву.

Усі пʼять завдань належать до класу `BIRD_SURVEY`.

## 1. Загальна кількість

Підсумуймо підрахунки за кожен день.

```sather
BIRD_SURVEY::total_seen(|3, 0, 7|)
-- => 10
```

Дослідження, у якому немає жодного дня, налічує нуль птахів.

## 2. Найкращий день

Повернімо найбільший підрахунок. Якщо днів не було, повертаємо нуль.

```sather
BIRD_SURVEY::busiest_day(|3, 0, 7|)
-- => 7
```

## 3. Жваві дні

У скількох днях підрахунок був більшим за деяке число?

```sather
BIRD_SURVEY::days_over(|3, 0, 7|, 2)
-- => 2
```

«Більше» означає більше: підрахунок рівно 2 не зараховується.

## 4. Засідки для перевірки

Першого дня дослідження ми перевіряємо одну засідку, другого дня - дві, і так далі. Скільки всього перевірок засідок це становить?

```sather
BIRD_SURVEY::hides_to_check(4)
-- => 10
```

Це 1 + 2 + 3 + 4.

## 5. Перший жвавий день

Який день був першим із підрахунком, більшим за деяке число? Дні нумеруються від нуля, так само як позиції в масиві. Якщо жоден день не був настільки жвавим, повертаємо `-1`.

```sather
BIRD_SURVEY::first_busy_day(|3, 0, 7|, 5)
-- => 2
BIRD_SURVEY::first_busy_day(|3, 0, 7|, 9)
-- => -1
```
