# Вступ

## Основи

_Мову_ ми називатимемо **AWK**, а _виконувану програму_, яка інтерпретує програми AWK, називатимемо **`awk`** або **`gawk`**.

### Шаблони та дії

Програма AWK складається з **пар «шаблон-дія»**

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

**Шаблон** може бути шаблоном регулярного виразу, з яким зіставляються вхідні дані.
Ним також може бути будь-який вираз, який дає значення правда або неправда.

**Дія** - це одна або кілька команд AWK.
Фігурні дужки навколо неї обовʼязкові.

Якщо результат шаблону _правда_, тоді відповідна дія виконується.

### Записи та поля

AWK розбирає вхідні дані як послідовність **записів**.
Кожен запис розбивається на нуль або більше **полів**.

Типова поведінка така:

- розбивати вхідні дані на записи, використовуючи символ нового рядка як «роздільник записів», тож кожен _рядок_ стає окремим записом.
- розбивати запис на поля, використовуючи пробільні символи як «роздільник полів», тож кожне _слово_ стає окремим полем.

### Шаблони та дії, продовження

Шаблон можна опустити, і тоді дія виконується _для кожного вхідного запису_.

Дію теж можна опустити, і тоді типовою дією стає виведення поточного запису.

#### Спеціальні шаблони

Є два спеціальні шаблони, які використовують досить часто.

- `BEGIN` виконує повʼязану з ним дію, перш ніж буде прочитано будь-які вхідні дані.
- `END` виконує повʼязану з ним дію після того, як усі вхідні дані буде прочитано.

### Змінні полів

На поля ми посилаємося як на `$1`, `$2`, `$3` тощо.

Поточний запис - це `$0`.

Ось кілька інших вбудованих змінних, які часто використовують.

#### Вбудовані змінні, що керують розбором вхідних даних

- `RS` - роздільник записів у вхідних даних.
  Як уже згадувалося, його типове значення - символ нового рядка.
- `FS` - роздільник полів у вхідних даних.

Ці змінні часто задають у блоці дії `BEGIN`.

#### Вбудовані змінні, що передають інформацію

AWK встановлює ці змінні автоматично під час виконання програми.

- `NF` зберігає кількість полів у поточному записі.
  - Щоб отримати значення останнього поля, скористайтеся `$NF`.
- `NR` зберігає номер поточного запису.
  - Коли обробляється кілька вхідних файлів, `NR` містить загальну кількість записів, оброблених на цей момент.
- `FNR` зберігає номер поточного запису в поточному вхідному файлі.
  - Щоб показати різницю між NR і FNR, наведемо поширену ідіому AWK.
    ```awk
    NR == FNR {action}
    ```
    Вона означає «якщо накопичений номер запису дорівнює номеру запису в поточному файлі».
    Це може бути правдою лише для записів у _першому вхідному файлі_.

### Істинність

AWK використовує те саме поняття істинності, що й C.

- Число `0` - неправда.
- Будь-яке інше число - правда.

Оскільки AWK - мова обробки тексту, значення істинності поширюються й на рядки тексту (англ. string).

- Порожній рядок тексту `""` - неправда.
- Будь-який непорожній рядок тексту - правда.

### Коментарі

Коментарі починаються із символу `#` і тривають до кінця рядка.

### Приклади

У Unix-подібних системах `/etc/passwd` містить інформацію про користувачів.
Кожен користувач описаний в окремому рядку, а поля розділені двокрапками.

Щоб вивести список імен користувачів:

```sh
awk '
    BEGIN { FS = ":" }
    { print $1 }
' /etc/passwd
```

Зауважмо, що дія `{print $1}` не має шаблону, тож вона виконується для кожного запису.

Якщо обмежити виведення лише користувачами, які використовують bash як оболонку входу, можна зробити так:

```sh
awk '
    BEGIN { FS = ":" }
    $7 == "/bin/bash" { print $1 }
' /etc/passwd
```
