# Додаток до інструкцій

## Реалізація

Визначте `type Classification` для зберігання значень класифікації натуральних чисел.
Для цього типу можна обрати будь-яке подання.

Визначте три константи Classification з такими назвами:

```text
	ClassificationDeficient
	ClassificationPerfect
	ClassificationAbundant
```

Реалізуйте функцію з назвою Classify, яка приймає
вхідні дані типу int64 і повертає Classification та значення помилки.

Створіть помилку з назвою ErrOnlyPositive,
яка повертається, коли вхідні дані не є додатним цілим числом.
