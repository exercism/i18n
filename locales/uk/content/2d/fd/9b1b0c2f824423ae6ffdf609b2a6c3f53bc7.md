# Вказівки

Ми працюємо над грою для малопотужної вбудованої системи, і нам потрібно написати кілька допоміжних функцій, які будуть використовувати інші частини гри.

## 1. Обчисліть частку й остачу від ділення

Частку отримуємо в результаті ділення.

```rust
fn divmod(dividend: i16, divisor: i16) -> (i16, i16)
```

Приклад:

```rust
assert_eq!(divmod(10, 3), (3, 1));
```

## 2. Виберіть елементи на парних позиціях з ітератора

Це допоможе увімкнути оптимізацію буфера екрана, обіцяє керівник.

Ітератори - це обʼєкти, які надають методи, визначені трейтом [`Iterator`](https://doc.rust-lang.org/std/iter/trait.Iterator.html). Ця документація досить обширна, бо ітератори надають багато методів; ось найважливіші властивості:

- Ітератор - це потік елементів довільної довжини
- Вони мають [метод `enumerate`](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.enumerate), який повертає кортеж `(i, val)` для кожного значення
- Вони мають [метод `filter`](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.filter), який використовує замикання, щоб визначити, чи варто видавати елемент ітератора
- Вони мають [метод `map`](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.map), який використовує замикання, щоб змінювати елементи ітератора

Оскільки функція може працювати з будь-яким ітератором, у ній використовується `impl`, щоб показати, що це екземпляр трейту, а не простий елемент. Так само синтаксис `<Item=T>` просто означає, що не має значення, які саме елементи породжує ітератор; функція може повертати парні елементи будь-якого ітератора.

```rust
fn evens<T>(iter: impl Iterator<Item=T>) -> impl Iterator<Item=T>
```

Приклади:

```rust
let mut even_ints = evens(0_u8..);
assert_eq!(even_ints.next(), Some(0));
assert_eq!(even_ints.next(), Some(2));
assert_eq!(even_ints.next(), Some(4));
assert_eq!(even_ints.next(), Some(6));
```

```rust
let mut evens_from_odds = evens(1_i16..);
assert_eq!(evens_from_odds.next(), Some(1));
assert_eq!(evens_from_odds.next(), Some(3));
assert_eq!(evens_from_odds.next(), Some(5));
assert_eq!(evens_from_odds.next(), Some(7));
```

## 3. Обчисліть мангеттенську відстань позиції від початку координат

Для зручності роботи з координатами є кортежна структура `Position`:

```rust
struct Position(i16, i16);
```

Потрібно реалізувати метод `manhattan` у `Position`, який повертає [манхеттенську відстань](https://en.wikipedia.org/wiki/Taxicab_geometry) цієї позиції від початку координат (`Position(0, 0)`).

```rust
impl Position {
    fn manhattan(&self) -> i16
}
```

Приклад:

```rust
assert_eq!(Position(3, 4).manhattan(), 7);
```
