# Докладніше

Swift надає інструкції передачі керування, які дозволяють змінювати хід виконання циклів і конструкцій `switch`. Крім `return`, Swift має `continue`, `break`, мітки циклів і `fallthrough`.

## Continue

Інструкція `continue` каже циклу припинити виконання поточної ітерації й негайно почати наступну. У циклі `while` або `repeat-while` вона одразу переходить до перевірки умови. У циклі `for-in` вона переходить до наступного елемента послідовності.

```swift
var count = 1
while count < 6 {
    count += 1
    if count == 4 {
        continue
    }
    print(count)
}

// Prints:
// 2
// 3
// 5
// 6
```

## Break

Інструкція `break` негайно завершує весь цикл або конструкцію `switch`. Виконання продовжується з першого рядка коду після циклу чи `switch`.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    if !fruit.count.isMultiple(of: 2) {
        break
    }
    print(fruit)
}

// Prints:
// banana
// grapes
```

## Цикли з мітками

У вкладених циклах може виникнути потреба, щоб `break` або `continue` впливали на зовнішній цикл, а не на найвнутрішніший. Щоб позначити цикл міткою, поставимо перед ним імʼя та двокрапку (`labelName:`). Далі цю мітку можна передати `break` або `continue`:

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    print("\n--- \(fruit) ---")
    for letter in fruit {
        guard letter != "n" else {
            break outerLoop
        }
        print(letter)
    }
}

// Prints:
// --- banana ---
// b
// a
```

## Fallthrough

У Swift конструкції `switch` типово не переходять до наступного випадку: виконання автоматично зупиняється в кінці випадку, що збігся. Якщо ж потрібно, щоб виконання явно продовжилося в наступному випадку без перевірки його шаблону, використаймо ключове слово `fallthrough`:

```swift
let value = 1
switch value {
case 1:
    print("One")
    fallthrough
case 2:
    print("Two")
default:
    break
}

// Prints:
// One
// Two
```
