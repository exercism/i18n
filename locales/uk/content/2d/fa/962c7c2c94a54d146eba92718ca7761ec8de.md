# Немає іменованого експорту

Не знайдено [`export %{export.name}`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/export). Без нього тести не пройдуть.

Переконайтеся, що `%{export.name}` існує, і додайте `export` перед ним:
```javascript
// exporting a "const"
export const %{export.name} = /*...*/

// exporting a named function declaration
export function %{export.name}() { /* ... */ }
```
