# Вступ

Перебирання - це послідовний прохід колекцією (`Array`, `Hash` тощо) і виконання певної дії над кожним обʼєктом.

Перебирання - ключова концепція в Ruby, яку використовують для сортування (`sort_by`), групування (`group_by`), перетворення (`map`), зведення (`reduce`) і багато іншого.
Найчастіше саме перебирання, а не цикли, є ідіоматичним способом перебрати колекцію.

Просте перебирання з використанням `map` і `with_index` має такий вигляд:

```ruby
words = %w[the cat sat on the mat]
list = words.map.with_index do |word, index|
  "#{index}. #{word}"
end

puts list

# Output:
# 0. the
# 1. cat
# 2. sat
# 3. on
# 4. the
# 5. mat
```
