# Нормалізації репрезентера

[Репрезентер JavaScript][github-javascript-representer] застосовує такі нормалізації:

## Вилучення коментарів

Усі коментарі вилучаються.
Наведені нижче приклади рівнозначні:

### Приклад із коментарями

```javascript
/**
 * Returns the string literal 'hi there' just to say hello
 * @return [String]
 */
function hello(/* nothing*/) {
  // just return it
  return 'hi there';
}
```

### Приклад без коментарів

```javascript
function hello() {
  return 'hi there';
}
```

## Нормалізація пробілів

Коли код перетворюється на репрезентацію, значення має його _порядок_, а не фізичне розташування.
Це означає, що пробільні символи нормалізуються.
Наведені нижче приклади рівнозначні:

### Приклад із відступом у два пробіли

```javascript
function hello() {
  return 'hello world';
}
```

### Приклад із відступом у чотири пробіли

```javascript
function hello() {
  return 'hello world';
}
```

### Приклад із цікавим відступом

```javascript
function hello() {
  return 'hello world';
}
```

## Нормалізація ідентифікаторів

Ідентифікатори замінюються на значення-заповнювач.

### До

```javascript
const MY_CONSTANT = 42;

function answer(multiplier, addition = 1) {
  return MY_CONSTANT * multiplier + addition;
}
```

### Після

```javascript
const PLACEHOLDER_1 = 42;

function PLACEHOLDER_2(PLACEHOLDER_3, PLACEHOLDER_4 = 1) {
  return PLACEHOLDER_1 * PLACEHOLDER_3 + PLACEHOLDER_4;
}
```
