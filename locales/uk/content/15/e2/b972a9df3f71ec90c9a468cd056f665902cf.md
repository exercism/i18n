# Методи масивів

Масиви - поширена структура даних, з якою ми працюємо. Для роботи з ними є чимало методів, серед яких сортування, обернення, вставлення та багато інших.

Деякі з цих методів деструктивні: вони змінюють початковий масив. Інші недеструктивні: повертають новий масив і не змінюють початковий.

Ось кілька найпоширеніших методів, які можна використовувати під час роботи з масивами:

## insert

Коли ми вставляємо елемент у масив, можна скористатися методом [`insert`][insert], який приймає індекс та елемент як аргументи.
Елемент буде вставлено за вказаним індексом, а решту масиву зсунуто праворуч.
Якщо індекс виходить за межі масиву, буде викликано помилку `IndexError`.

```crystal
numbers = [1, 2, 3]
numbers.insert(1, 4)
numbers # => [1, 4, 2, 3]

numbers.insert(5, 5) # => Error: Index out of bounds (IndexError)
```

## delete

Коли потрібно видалити конкретний елемент із масиву, можна скористатися методом [`delete`][delete], який приймає елемент як аргумент.
Метод повертає елемент, який було вилучено.
Якщо елемента немає в масиві, буде повернуто `nil`.

```crystal
numbers = [1, 2, 3]
numbers.delete(2) # => 2
numbers           # => [1, 3]
```

## first & last

Коли потрібно отримати перший або останній елемент масиву, можна скористатися методами [`first`][first] та [`last`][last].
Ці методи приймають необовʼязковий аргумент, який указує, скільки елементів повернути.
Це може покращити читабельність порівняно з використанням індексу `0` або `-1`, чи діапазону.
Якщо масив порожній, буде викликано помилку `Enumerable::EmptyError`.

```crystal
numbers = [1, 2, 3]
numbers.first # => 1
numbers.last  # => 3

numbers.first(2) # => [1, 2]
numbers.last(2)  # => [2, 3]

empty_array = [] of Int32
empty_array.last # => Error: Empty enumerable (Enumerable::EmptyError)
```

## reverse

Коли потрібно обернути масив, можна скористатися методом [`reverse`][reverse], який повертає новий масив з елементами у зворотному порядку.
Важливо зазначити, що `reverse` повертає новий масив і не змінює початковий.
Якщо потрібно змінити початковий масив, слід додати `!` у кінці назви методу.

```crystal
numbers = [1, 2, 3]
numbers.reverse # => [3, 2, 1]
numbers         # => [1, 2, 3]

numbers.reverse! # => [3, 2, 1]
numbers          # => [3, 2, 1]
```

## flatten & compact & transpose & uniq

Наведені нижче методи стануть у пригоді, коли потрібно зробити масив одновимірним, вилучити елементи `nil`, прибрати дублікати або транспонувати масив масивів.
Як і у випадку з `reverse`, ці методи повертають новий масив і не змінюють початковий.

| Метод | Опис | Приклад |
| ------ | ----------- | ------- |
| [`flatten`][flatten] | Повертає новий масив, який є одновимірним розгортанням цього масиву (рекурсивно). Тобто для кожного елемента масиву потрібно витягнути його елементи в новий масив. | `[[1, 2], [3, 4]].flatten # => [1, 2, 3, 4]` |
| [`compact`][compact] | Повертає копію self, з якої вилучено всі елементи `nil`. | `[1, nil, 2, nil, 3].compact # => [1, 2, 3]` |
| [`transpose`][transpose] | Припускає, що self є масивом масивів, і [транспонує][transpose] рядки та стовпці. | `[[1, 2], [3, 4]].transpose # => [[1, 3], [2, 4]]` |
| [`uniq`][uniq] | Повертає новий масив, вилучаючи дублікати значень у self. | `[1, 2, 1, 3, 1].uniq # => [1, 2, 3]` |

## Concat(`+`)

Метод додавання (`<<`) стає у пригоді, коли потрібно додати обʼєкти до масиву.
Однак, коли потрібно поєднати два масиви, можна скористатися оператором [`+`][concat], який повертає новий масив з елементами обох масивів.

```crystal
[1, 2] + [3, 4] # => [1, 2, 3, 4]
```

Якщо додати масив до іншого масиву, цей масив буде додано як один елемент.

```crystal
[1, 2] << [3, 4] # => [1, 2, [3, 4]]
```

## empty?

Коли потрібно перевірити, чи масив порожній, можна скористатися методом [`empty?`][empty?], який повертає `true`, якщо масив порожній, і `false` в іншому разі.
Це покращує читабельність порівняно з перевіркою, чи довжина масиву дорівнює `0`.

```crystal
[].empty? # => true
[1, 2, 3].empty? # => false
```

## index

Коли потрібно отримати індекс елемента в масиві, можна скористатися методом [`index`][index], який приймає елемент як аргумент.
Якщо елемента немає в масиві, буде повернуто `nil`.

```crystal
numbers = [1, 2, 3]
numbers.index(2) # => 1
```

## size

Коли потрібно дізнатися кількість елементів у масиві, можна скористатися методом [`size`][size].

```crystal
numbers = [1, 2, 3]
numbers.size # => 3
```

## count

Коли потрібно порахувати, скільки разів елемент присутній у масиві, можна скористатися методом [`count`][count].

```crystal
fruits = ["apple", "banana", "apple"]
fruits.count("apple")      # => 2
fruits.count("banana")     # => 1
fruits.count("watermelon") # => 0
```

## sort

Коли потрібно відсортувати масив, можна скористатися методом [`sort`][sort], який повертає новий масив з відсортованими елементами.
Як і у випадку з `reverse`, цей метод повертає новий масив і не змінює початковий.

```crystal
numbers = [3, 2, 1]
numbers.sort # => [1, 2, 3]
numbers      # => [3, 2, 1]

numbers.sort! # => [1, 2, 3]
numbers       # => [1, 2, 3]
```
