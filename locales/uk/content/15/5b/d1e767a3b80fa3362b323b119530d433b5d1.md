# Вступ

Пригадаймо з концепції «Основи»: програма AWK складається з **пар «шаблон-дія»**.

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

## Що ми маємо на увазі під «шаблоном»?

«Шаблон» - це будь-який вираз AWK.
Правдивість результату цього виразу визначає, чи виконується дія.

## Порожній шаблон

Шаблон можна опустити.
У такому разі дія виконується для кожного запису.

Ми можемо вивести всі імена користувачів із файлу passwd.

```sh
awk -F: '{print $1}' /etc/passwd
```

## Регулярні вирази

AWK може порівнювати рядки тексту (англ. string) з регулярними виразами й отримувати булеве значення (англ. Boolean).

Щоб зіставити конкретне поле, скористаймося оператором зіставлення з регулярним виразом `~`.
Цей оператор приймає рядок тексту як лівий операнд, а регулярний вираз - як правий.
Літерал регулярного виразу записують між скісними рисками `/`.

Щоб знайти у файлі passwd користувачів, які входять у систему через bash:

```sh
awk -F: '$7 ~ /bash/ {print $1}' /etc/passwd
```

`!~` - це оператор «регулярний вираз **не** збігається».

Щоб зіставити регулярний вираз із поточним записом, можна написати `$0 ~ /regex/`.
Це настільки поширено, що існує скорочений запис: можна опустити `$0` і `~` та просто написати `/regex/`

```sh
awk '/regex/' data.txt
```

~~~~exercism/note
Порівняймо цю однорядкову команду AWK з еквівалентною командою grep

```sh
grep 'regex' data.txt
```

AWK дає нам цілу мову програмування, не жертвуючи стислістю.
~~~~

## Вирази

Вирази AWK (арифметичні, логічні чи будь-які інші) можна використовувати як шаблони.

Щоб вибрати всіх користувачів з UID 1000 або більше:

```sh
awk -F: '$3 >= 1000' /etc/passwd
```

Пригадаймо, що неправдивими значеннями в AWK є число нуль і порожній рядок тексту, а всі інші числа чи рядки тексту - правдиві.
Будь-який вираз, який обчислюється в число або рядок тексту, можна використати як шаблон.

## Функції

Будь-яку [вбудовану][builtins] або [визначену користувачем][user-defined] функцію можна використати у виразі, а отже, і в шаблоні.
Кілька прикладів:

```awk
length($1) {print "first field is not empty"}
```
```awk
toupper(substr($1, 1, 1)) ~ /[AEIOU]/ {print "starts with a vowel"}
```

## Шаблони-константи

Поширений прийом в AWK:

```sh
{
    xyz()   # some code that transforms each record
}
1
```

`1` - це правдивий шаблон без повʼязаної дії.
Це означає «вивести поточний запис».
