# Підказки

## Загальне

- Щоб отримати доступ до змінних екземпляра та визначити їх, ми пишемо `@`, а потім назву змінної.

## 1. Ініціалізувати `TaskHandler`

- Щоб створити `Proc`, скористаймося синтаксисом `-> (args) { block }`.
- Коли `Proc` визначають для змінної екземпляра, потрібно явно вказати його тип.
  Це можна зробити, додавши `: Proc(<arg_type>, <return_type>)` після назви змінної.
  Або за допомогою синтаксису `-> (arg_1 : <arg_type>) : <return_type> { block }`.
- `Proc` має порівнювати, чи аргумент більший або дорівнює 0.

## 2. Оновити логіку умови завдання

- Метод має приймати блок як аргумент і присвоювати його змінній екземпляра `@task_condition_logic`.

## 3. Виконати наступне завдання

- Щоб виконати `Proc`, можна скористатися методом `call`, який приймає аргументи цього `Proc`.
