# Вступ

Модуль [`fractions`][fractions] дає змогу створювати [`rational numbers`][rational] і працювати з ними: це дроби, у яких ціле число в чисельнику поділене на ціле число в знаменнику.
Наприклад, ми можемо зберегти `2/3` як точний дріб замість наближеного значення `float` `0.6666...`.

На відміну від чисел `int`, `float` і `complex`, дроби не мають літеральної форми.
Однак конструктор дробу доволі гнучкий.

Найочевидніше: він може приймати два цілі числа як аргументи.
Спільні множники автоматично скорочуються, і дріб перетворюється на «найпростішу форму» (_найменші цілі числа, які точно представляють дріб_):

```python
>>> from fractions import Fraction

>>> f1 = Fraction(2, 3) # 2/3
>>> f1
Fraction(2, 3)

>>> f2 = Fraction(6, 9)
>>> f2
Fraction(2, 3)  # automatically simplified

>>> f1 == f2
True
```

Конструктор дробу також може розібрати рядок тексту (англ. string):

```python
>>> f3 = Fraction('2/3')
>>> f3
Fraction(2, 3)
```

Дроби також можуть працювати з параметрами `float`, але тут можуть виникнути проблеми через наближену природу внутрішнього подання десяткового значення у двійковій формі.
Докладніше про цю проблему подання можна дізнатися на сайті [0.30000000000000004][0.30000000000000004] та в розділі [Арифметика з плаваючою комою: проблеми й обмеження][fp-issues] документації Python.

Для надійнішого результату, коли ми використовуємо числа з плаваючою комою разом із дробами, існує метод `<fraction>.limit_denominator()`.


## Арифметика з дробами

Звичайні [`arithmetic operators`][operators] `+ - * / **` працюють із дробами так само, як і з іншими числовими типами.

Цілі числа та інші `Fraction` можна включити у вираз, і результат буде `Fraction`.
Якщо ж у виразі є `float`, результат теж буде `float`, з можливою втратою точності:

```python
>>> Fraction(2, 3) + Fraction(1, 4) # addition
Fraction(11, 12)

>>> Fraction(2, 3) * Fraction(6, 5) # multiply fractions
Fraction(4, 5)

>>> Fraction(2, 3) * 6 / 5 # fraction with integers
Fraction(4, 5)

>>> Fraction(2, 3) * 1.2  # fraction with float -> float
0.7999999999999999

>>> Fraction(2, 3) ** 2  # exponentiation with integer
Fraction(4, 9)
```

Різні стандартні числові функції Python також дають результат, якого можна очікувати від роботи з типами `int` і `float`:

```python
>>> round(Fraction(11, 3))
4

>>> from math import floor, ceil
>>> floor(Fraction(11, 3))
3
>>> ceil(Fraction(11, 3))
4

>>> float(Fraction(11, 3))
3.6666666666666665
```
