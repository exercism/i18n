# Вступ

Python має три різні типи вбудованих чисел: цілі числа ([`int`][int]), числа з плаваючою комою ([`float`][float]) та комплексні числа ([`complex`][complex]).
Дроби ([`fractions.Fraction`][fractions]) і десяткові числа ([`decimal.Decimal`][decimals]) також доступні через імпорт зі стандартної бібліотеки.

Цілі числа, зокрема шістнадцяткові ([_`hex()`_][hex]), вісімкові ([_`oct()`_][oct]) та двійкові ([_`bin()`_][bin]) числа **без** десяткових знаків, також належать до типу `ints`:

```python
# Ints are whole numbers.
>>> 1234
1234
>>> type(1234)
<class 'int'>

>>> -12
-12
```

Числа, що містять десяткову точку (з дробовою частиною або без неї), належать до типу `floats`:

```python
>>> 3.45
3.45
>>> type(3.45)
<class 'float'>
```

## Арифметика

Python повністю підтримує арифметичні операції між цими різними типами чисел і перетворює вужчі числа, щоб узгодити їх із ширшими, коли застосовуються бінарні арифметичні оператори (`+`, `-`, `*`, `/`, `//` та `%`).

### Додавання та віднімання

Оператори додавання та віднімання поводяться так само, як у звичайній математиці.
Якщо один або кілька операндів є `float`, решту `int` також буде перетворено на `float`:

```python
>>> 5 - 3
2
# The int is widened to a float here, and a float is returned.
>>> 3 + 4.0
7.0
```

### Множення

Як і у випадку з додаванням і відніманням, множення перетворює вужчі числа, щоб узгодити їх із ширшими:

```python
>>> 3 * 2
6

>>> 3 * 2.0
6.0
```

### Ділення

Ділення завжди повертає `float`, навіть якщо результат є цілим числом:

```python
>>> 6/5
1.2

>>> 6/2
3.0
```

### Цілочисельне ділення

Якщо потрібен результат типу `int`, можна скористатися цілочисельним діленням, щоб відкинути дробову частину.
Цілочисельне ділення виконується за допомогою оператора `//`:

```python
>>> 6//5
1

>>> 6//2
3
```

### Остача

Оператор остачі (`%`) повертає остачу від ділення двох операндів:

```python
# The result of % is zero here, because dividing 8 by 2 leaves no remainder
>>> 8 % 2
0

# The result of % is 2 here, because 3 only goes into 5 once, with 2 leftover
>>> 5 % 3
2
```

Інший погляд на 5 % 3:

```python
>>> whole_part = int(5/3)
1

>>> decimal_part = 5/3 - whole_part
0.6666666666666667

>>> whole_remainder = decimal_part * 3
2.0
```

## Округлення

Python надає вбудовану функцію [`round(number, <decimal_places>)`][round], щоб округлити число з плаваючою комою до заданої кількості десяткових знаків.
Якщо кількість десяткових знаків не вказано, число округлюється до найближчого цілого й повертає `int`:

```python
>>> round(3.1415926535, 2)
3.14

>>> round(3.1415926535)
3
```

## Пріоритет і дужки

Python дозволяє використовувати круглі дужки, щоб групувати вирази.
Це корисно, коли потрібно змінити типовий порядок виконання операцій.

```python
>>> 2 + 3 * 4
14

>>> (2 + 3) * 4
20
```

Python дотримується правила [PEMDAS][pemdas] щодо пріоритету операторів.
Це означає, що обчислення всередині `()` мають найвищий пріоритет, далі йдуть `**`, потім `*`, `/`, `//`, `%`, `+` та `-`:

```python
>>> 2 + 3 - 4 * 4
-11

>>> (2 + 3 - 4) * 4
4

# In the following example, the `**` operator has the highest priority, then `*`, then `+`
# Meaning we first do 4 ** 4, then 3 * 64, then 2 + 192
>>> 2 + 3 * 4 ** 4
770
```

## Точність і подання

Цілі числа в Python мають [довільну точність][arbitrary-precision]: кількість цифр обмежується лише доступною памʼяттю системи, на якій виконується код.

Числа з плаваючою комою зазвичай реалізовано через `double` у C (_15 десяткових знаків точності_), але їхнє подання може відрізнятися залежно від системи.
Комплексні числа мають частини `real` та `imaginary`, кожна з яких подана числом з плаваючою комою.

Щоб докладніше дізнатися про проблеми й обмеження арифметики з плаваючою комою в різних мовах програмування, варто заглянути на [0.30000000000000004.com][0.30000000000000004.com] та в [The Python Tutorial][floating point math].
