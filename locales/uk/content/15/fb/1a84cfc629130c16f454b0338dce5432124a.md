# Про концепцію

[`Array`][array] в Elm є швидкою незмінною колекцією з нуля або більше значень одного типу.
Оскільки масиви незмінні, після створення масиву його значення вже ніколи не змінюється.
Для масивів немає літерального синтаксису (як для списків), тому натомість використовують запис Array.fromList.
Наприклад, `Array` з елементами "a", "b" і "c" зазвичай показують як `Array.fromList ["a", "b", "c"]`.
Такий запис ми побачимо у виводі консолі, у налагоджувачі та в інших подібних місцях.

На відміну від `List`, який належить до [типових імпортів][default-imports], модуль `Array` потрібно імпортувати явно, за допомогою `import Array` або подібного рядка.

Анотації типів для масивів можна записати так

```elm
Array String --> an array of String
Array Int --> an array of Int
```

Масиви можна визначити так:

```elm
import Array exposing (Array)

empty : Array Char
empty = Array.empty

singleValue = Array.fromList [ 5 ] --> Array Int

repeatSingleValue = Array.repeat 2 5 --> Array.fromList [ 5, 5 ]

initialiseFromIndex = Array.initialise 3 (\index -> index * 2) --> Array.fromList [ 0, 2, 4 ]

initialisefromList = Array.fromList [ "a", "b", "c" ] --> Array.fromList [ "a", "b", "c" ]
```

Елементи додають до масиву за допомогою `Array.push`:

```elm
twoToFour = Array.fromList [ 2, 3, 4 ]
oneToFour = Array.push 1 twoToFour --> Array.fromList [ 1, 2, 3, 4 ]
```

Масиви зʼєднують за допомогою `Array.append`:

```elm
sixSeven = Array.fromList [ 6, 7 ]
eightNine = Array.fromList [ 8, 9 ]
Array.append sixSeven eightNine --> Array.fromList [ 6, 7, 8, 9 ]
```

Елемент масиву отримують за допомогою `Array.get`:

```elm
sixSeven = Array.fromList [ 6, 7 ]
Array.get 0 sixSeven --> Just 6
```

Елемент масиву задають за допомогою `Array.set`:

```elm
sixSeven = Array.fromList [ 6, 7 ]
Array.set 1 8 sixSeven --> Array.fromList [ 6, 8 ]
```

Для роботи з масивами є функції, визначені в [модулі `Array`][array-module].

```elm
oneTwo = Array.fromList [ 1, 2 ]
Array.length oneTwo --> 2
```

Будь-яка функція чи оператор, що нібито змінює `Array` (наприклад, додає елемент), насправді поверне новий `Array`.
Продуктивність зазвичай не страждає, адже реалізація `Array` запобігає зайвим виділенням памʼяті та копіюванню.
