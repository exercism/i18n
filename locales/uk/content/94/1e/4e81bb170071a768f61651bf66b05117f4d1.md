# Вступ

`str` у Python - це [незмінна послідовність][text sequence] [кодових точок Unicode][unicode code points].
Вони можуть містити літери, діакритичні знаки, позиційні символи, числа, символи валют, емодзі, розділові знаки, різні пробіли, розриви рядків тощо.

Рядки тексту (англ. string) реалізують усі [загальні операції з послідовностями][common sequence operations], і їх можна перебирати за допомогою синтаксису `for item in <str>` або `for index, item in enumerate(<str>)`.
Їх можна зʼєднувати за допомогою `<str> + <other str>` або `<str>.join(<iterable>)`, розділяти за допомогою `<str>.split(<separator>)`, а також вони пропонують чимало варіантів форматування й компонування.

Щоб працювати з рядками тексту далі, Python надає багатий набір [методів для рядків][str-methods], які допомагають шукати, очищати, перетворювати, перекладати та виконувати багато інших операцій.

Через те що `str` є _незмінним_, значення обʼєкта `str` у памʼяті не змінюється; методи, які на вигляд змінюють рядок тексту, повертають нову копію або новий примірник цього обʼєкта `str`.
