# Великі витрати в базі даних

## Умова задачі

Компанії ABC Corp потрібно, щоб ми знайшли імʼя та відділ працівників, чиї записи про платежі перевищують задану суму (наприклад, `3000.00`).

Створімо запис із назвою `HighPayment`, щоб повернути потрібні дані. Визначення запису таке.

```ballerina
type HighPayment record {
    string name;
    string department;
    decimal amount;
    string reason;
};
```

Щоб отримати потрібні дані з бази даних, скористаймося операцією `query` клієнта JDBC.

> ПРИМІТКА: упорядкуймо результат за `payment_id` у порядку зростання.

## Деталі бази даних

Для цієї задачі скористаймося наданою базою даних H2.

> Зразок бази даних міститься у файлі `gofigure.mv.db`, а назва бази даних - `gofigure`. Його надано в теці `db`.

У зразку бази даних H2 вже є такі таблиці з деякими зразковими даними. Назви стовпців і типи даних наведено нижче.

**Назва таблиці** : `Employee`

| **Стовпці:**      | тип |
| -----------       | ----------- |
| `employee_id`     | ціле число, первинний ключ з автоінкрементом       |
| `name`            | рядок тексту (англ. string)        |
| `city`            | рядок тексту        |
| `department`      | рядок тексту        |
| `age`             | ціле число        |

**Назва таблиці**: `Payment`

| **Стовпці:**      | тип |
| -----------       | ----------- |
| `payment_id`      | ціле число, первинний ключ з автоінкрементом       |
| `date`            | дата        |
| `amount`          | десяткове число        |
| `employee_id`     | ціле число        |
| `reason`          | рядок тексту        |

* Файл бази даних - `gofigure.mv.db`. Використаймо такий JDBC URL: `jdbc:h2:file:/path/to/db/file`
* Імʼя користувача: `root`
* Пароль: `root`

## Обмеження

* Скористаймося файлом бази даних H2 із теки `db`, щоб перевіряти запити та зразок Ballerina
* Скористаймося підходом із параметрами залежностей maven, щоб додати драйвер бази даних H2 як платформну залежність у файлі Ballerina.toml

## Тестове середовище

* Тести можна запустити командою `bal test`, яка виконається на наданій зразковій базі даних.

## Підказки

* Скористаймося модулем [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc) для роботи з базою даних
* Звернімося до розділу [Передумови](https://lib.ballerina.io/ballerinax/java.jdbc/latest), щоб дізнатися кроки додавання драйвера JDBC як залежності
* Скористаймося віддаленим методом [query](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-query), щоб отримати дані з бази даних
* Подивімося на приклад [Простий запит](https://ballerina.io/learn/by-example/mysql-query-operation)
* Скористаймося типом [stream](https://ballerina.io/learn/by-example/stream-type) у Ballerina, щоб отримати доступ до даних
* Скористаймося обʼєднаннями SQL, щоб знайти потрібний набір даних у базі даних
