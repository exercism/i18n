# Вступ

У концепції `Types` ми дізналися, що:

- Типи в Julia утворюють ієрархію.
- Кожен тип має надтип.
- `Any` перебуває на вершині ієрархії та є власним надтипом.
- Типи _можуть_ мати підтипи, і ті, що мають, називаються `abstract types`.
- Типи без підтипів (листові вузли на дереві) називаються `concrete types`.
- Неподільні типи, як-от `Char` чи `Int64`, називаються `primitive types`.

Лише `primitive` типи відповідають схемі «абстрактне проти конкретного» у її простій формі.
`Vector` - це колекція, яку можна поділити на елементи з власним типом.

```julia-repl
julia> isprimitivetype(Int)
true

julia> isprimitivetype(Vector)
false
```

_Колекція чого?_

Кожен вектор (або множина) - це колекція елементів з деяким однорідним типом, який можна або задати за допомогою _параметра_ у фігурних дужках `{ }`, або опустити, щоб його визначило виведення типу.

```julia-repl
julia> v = [1, 2, 3]
3-element Vector{Int64}:
 1
 2
 3

julia> v8 = Vector{Int8}([2, 4, 6])
3-element Vector{Int8}:
 2
 4
 6
```

Ці `parametric types` - це форма `generic programming`, і багато сучасних мов мають щось загалом еквівалентне, хоч у деталях є чимало відмінностей.

## Параметричні складені типи

Іноді ми хочемо створити складений тип, достатньо гнучкий (узагальнений), щоб працювати з різними типами полів.

Цього можна досягти за допомогою фіктивного типу у визначенні, який зазвичай називають `T`.

```julia-repl
julia> struct Point{T}
               x::T
               y::T
       end

# high definition version

julia> real_point = Point(7.3, 4.2)
Point{Float64}(7.3, 4.2)

julia> typeof(real_point)
Point{Float64}

# low definition version

julia> int8point = Point{Int8}(17, 23)
Point{Int8}(17, 23)

julia> typeof(int8point)
Point{Int8}

julia> Point(Int8(17), Int8(23))
Point{Int8}(17, 23)
```

Звісно, цей підхід також працює з колекціями в полях:

```julia-repl
julia> struct Record{T}
           data::Vector{T}
           comment::String
       end

julia> rec = Record{Float64}([1.3, 5.2], "some data")
Record{Float64}([1.3, 5.2], "some data")

julia> rec.data
2-element Vector{Float64}:
 1.3
 5.2

julia> rec2 = Record{Int32}([3, 5], "more data")
Record{Int32}(Int32[3, 5], "more data")

julia> rec2.data
2-element Vector{Int32}:
 3
 5
```
