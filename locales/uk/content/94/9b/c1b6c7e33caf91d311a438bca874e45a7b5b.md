# Інструкції

Елена - нова менеджерка з якості на фабриці газет.
Оскільки вона тільки-но прийшла в компанію, вона вирішила переглянути частину процесів на фабриці й подивитися, що можна покращити.

Вона зʼясувала, що техніки виконують багато перевірок якості вручну.

Вона бачить гарну можливість для автоматизації й просить нас, незалежного розробника, розробити програмне забезпечення для моніторингу частини машин.

## 1. Відстежуємо рівень вологості в приміщенні

Наше перше завдання - написати програму, яка відстежуватиме рівень вологості у виробничому приміщенні.
До програмного забезпечення компанії вже підключено датчик, який періодично повертає відсоток вологості в приміщенні.

Реалізуйте у програмі функцію, яка викидатиме помилку, якщо відсоток вологості занадто високий.
Функція має називатися `check_humidity_level` і приймати відсоток вологості як параметр.

Якщо відсоток перевищує 70%, зупиніть виконання з помилкою (повідомлення не має значення). 
Інакше виведіть повідомлення, що містить «humidity test passed», і поверніть `TRUE`, щоб підтвердити, що вимірювання правильне.

```R
check_humidity_level(60)
#> humidity test passed
#> [1] TRUE

check_humidity_level(100)
#> Error in check_humidity_level(100) : pct_humidity <= 70 is not TRUE
```

## 2. Виявляємо перегрівання

Елена дуже задоволена нашим першим завданням і просить нас зайнятися відстеженням температури машин.
Під час розмови з техніком Грегом ми дізнаємося, що якщо температура машини перевищує 500 °C, техніки починають хвилюватися через перегрівання.

Машина оснащена датчиком, який вимірює її внутрішню температуру.
Варто знати, що датчик дуже чутливий і часто ламається.
У такому разі технікам доведеться його замінити.

Реалізуйте функцію `report_overheating`, яка приймає температуру як параметр і викидає помилку, якщо датчик зламався або якщо машина починає перегріватися.

Оскільки згодом на ці помилки потрібно буде реагувати по-різному, нам потрібен механізм, щоб розрізняти два види помилок.

- Якщо датчик зламався, температура буде `NULL`.
  У такому разі зупиніть виконання з повідомленням про помилку, яке містить «Sensor Broken» як частину рядка тексту (англ. string).
- Коли датчик працює, якщо температура перевищує 600 °C, зупиніть виконання з повідомленням, яке містить температуру.
- Якщо температура перевищує 500 °C, але не 600 °C, виведіть попередження, яке містить температуру, і поверніть `FALSE`.
- Інакше все гаразд, тож виведіть повідомлення `"temperature check passed: t °C"`, де `t` позначає температуру, і поверніть `TRUE`.

```R
report_overheating(NULL)
#> Error in report_overheating(NULL) : Sensor Broken

report_overheating(800)
#> Error in report_overheating(800) : Overheating: 800 C

report_overheating(550)
#> [1] FALSE
#> Warning message:
#> In report_overheating(550) : Risk of overheating: 550 C

report_overheating(450)
#> temperature check passed: 450 °C
#> [1] TRUE
```


## 3. Відстежуємо роботу машини

Тепер, коли наша машина вміє виявляти помилки й у нас є власна помилка машини, додамо функцію-обгортку, яка повідомлятиме, як усе працює.
Окрім повернення логів із попередніх функцій, ця обгортка також має додавати логи залежно від типів збоїв, які сталися.

- Перевірте вологість і температуру.
- Якщо є проблеми, нехай `check_humidity_level()` і `report_overheating()` просто виведуть свої логи.
- Якщо все гаразд, додайте повідомлення, яке містить «All OK».

Реалізуйте функцію `monitor_the_machine()`, яка приймає вологість і температуру як аргументи.

```R
# Working well
monitor_the_machine(53, 200)
#> humidity test passed
#> temperature check passed: 200 °C
#> All OK!

# High humidity
monitor_the_machine(90, 200)
#> Error in check_humidity_level(pct_humidity) : 
#>   pct_humidity <= 70 is not TRUE

# Faulty sensor
monitor_the_machine(53, NULL)
#> humidity test passed
#> Error in report_overheating(temperature) : Sensor Broken

# Mild overheating
monitor_the_machine(53, 550)
#> humidity test passed
#> Warning message:
#> In report_overheating(temperature) : Risk of overheating: 550 C

# Dangerous overheating: shutdown
monitor_the_machine(53, 650)
#> humidity test passed
#> Error in report_overheating(temperature) : Overheating: 650 C
```
