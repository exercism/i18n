# Вступ

Булеві значення (англ. Boolean) у Cairo представлені наперед визначеним булевим типом `bool`, значеннями якого можуть бути `true` або `false`.

```rust
let speeding = true;   // Boolean variable 'speeding' set to 'true'
let has_error = false; // Boolean variable 'has_error' set to 'false' 
```

Cairo підтримує три логічні оператори, які зводять вирази до булевих значень і повертають `true` або `false`.

| Оператор    | Що він означає                                 |
| ----------- | --------------------------------------------- |
| `&&` (логічне і)  | Це правда, якщо обидва твердження правдиві.       |
| `\|\|` (логічне або) | Це правда, якщо принаймні одне твердження правдиве. |
| `!` (логічне заперечення)   | Це правда, лише якщо твердження неправдиве.    |
