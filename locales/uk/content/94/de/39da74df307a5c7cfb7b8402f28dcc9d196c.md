# Вказівки

У цій вправі ми реалізуємо логіку квесту для нової RPG-гри, яку розробляє наш друг.

Головна героїня гри - Анналін, відважна дівчина з лютим і відданим собакою. На жаль, трапляється лихо: її найкращого друга викрали, коли він шукав у лісі ягоди.

Анналін спробує знайти й визволити свого найкращого друга, можливо, узявши з собою в цей квест і свого собаку.

Простеживши деякий час за слідом найкращого друга, вона знаходить табір, у якому його тримають у полоні. Виявляється, викрадачів двоє: могутній лицар і хитрий лучник.

Знайшовши викрадачів, Анналін обмірковує, до яких із наведених нижче дій вона може вдатися:

- _Швидка атака_: швидку атаку можна виконати, якщо лицар спить, адже йому потрібен час, щоб одягнути обладунки, тож він буде вразливим.
- _Стеження_: за групою можна стежити, якщо хоча б один із них не спить. Інакше стеження - марна трата часу.
- _Подати сигнал вʼязню_: вʼязню можна подати сигнал звуками птахів, якщо вʼязень не спить, а лучник спить, адже лучників навчають пташиних сигналів, тож вони можуть перехопити повідомлення.
- _Визволити вʼязня_: Анналін може спробувати непомітно пробратися в табір, щоб визволити вʼязня.
  Це ризикована справа, і вона може вдатися лише одним із двох способів:
  - Якщо Анналін узяла з собою собаку, вона може врятувати вʼязня, коли лучник спить.
    Лицар боїться собаки, а лучник не встигне підготуватися, перш ніж Анналін і вʼязень утечуть.
  - Якщо Анналін без собаки, то їй і вʼязню доведеться діяти дуже обережно!
    Анналін може визволити вʼязня, якщо вʼязень не спить, а лицар і лучник обоє сплять, але якщо вʼязень спить, його врятувати не можна: він злякається раптової появи Анналін і розбудить лицаря з лучником.

У нас чотири завдання: реалізувати логіку, яка визначає, чи доступні наведені дії, залежно від стану трьох персонажів, знайдених у лісі, і від того, чи є з Анналін її собака.

## 1. Перевірити, чи можна виконати швидку атаку

Реалізуйте метод `canFastAttack()`, який приймає булеве значення (англ. Boolean), що вказує, чи не спить лицар. Цей метод повертає `true`, якщо за станом лицаря швидку атаку можна виконати. Інакше повертає `false`:

```haxe
var knightIsAwake = true;
canFastAttack(knightIsAwake);
// => false
```

## 2. Перевірити, чи можна стежити за групою

Реалізуйте метод `canSpy()`, який приймає три булеві значення, що вказують, чи не сплять лицар, лучник і вʼязень відповідно. Метод повертає `true`, якщо за станом цих трьох персонажів за групою можна стежити. Інакше повертає `false`:

```haxe
var knightIsAwake = false;
var archerIsAwake = true;
var prisonerIsAwake = false;
canSpy(knightIsAwake, archerIsAwake, prisonerIsAwake);
// => true
```

## 3. Перевірити, чи можна подати сигнал вʼязню

Реалізуйте метод `canSignalPrisoner()`, який приймає два булеві значення, що вказують, чи не сплять лучник і вʼязень відповідно. Метод повертає `true`, якщо за станом цих двох персонажів вʼязню можна подати сигнал. Інакше повертає `false`:

```haxe
var archerIsAwake = false;
var prisonerIsAwake = true;
canSignalPrisoner(archerIsAwake, prisonerIsAwake);
// => true
```

## 4. Перевірити, чи можна визволити вʼязня

Реалізуйте метод `canFreePrisoner()`, який приймає чотири булеві значення. Перші три параметри вказують, чи не сплять лицар, лучник і вʼязень відповідно. Останній параметр указує, чи є з Анналін її собака. Метод повертає `true`, якщо за станом цих трьох персонажів і наявності собаки Анналін вʼязня можна визволити. Інакше повертає `false`:

```haxe
var knightIsAwake = false;
var archerIsAwake = true;
var prisonerIsAwake = false;
var petDogIsPresent = false;
canFreePrisoner(knightIsAwake, archerIsAwake, prisonerIsAwake, petDogIsPresent);
// => false
```
