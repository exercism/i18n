# Вказівки

У цій вправі нам потрібно реалізувати кілька функцій для роботи з масивом мов програмування.

## 1. Визначте функцію, яка повертає порожній масив мов

Визначте функцію `language_list`, яка не приймає аргументів і повертає порожній масив.

```php
<?php

language_list();
// => []
```

## 2. Змініть функцію, щоб вона створювала масив із будь-якої кількості мов

Змініть функцію `language_list` так, щоб вона приймала варіативний аргумент із мов, тобто рядків тексту (англ. string).
Вона має повертати отриманий масив, у якому будуть ці мови.

```php
<?php

$language_list = language_list();
// => []
$language_list = language_list("Clojure", "PHP");
// => ["Clojure", "PHP"]
$language_list = language_list("PHP", "Haskell", "Java", "C++", "Rust")
// => ["PHP", "Haskell", "Java", "C++", "Rust"]
```

## 3. Визначте функцію, яка додає мову до масиву

Визначте функцію `add_to_language_list`, яка приймає 2 аргументи: масив мов і нову мову.

```php
<?php

$language_list = language_list();
// => []
$language_list = add_to_language_list($language_list, "Clojure");
// => ["Clojure"]
```

## 4. Визначте функцію, яка видаляє елемент з масиву мов

Визначте функцію `prune_language_list`, яка видаляє першу мову з масиву мов.

```php
<?php

$language_list = language_list("PHP");
// => ["PHP"]
$language_list = prune_language_list($language_list);
// => []
```

## 5. Визначте функцію, яка отримує перший елемент масиву

Визначте функцію `current_language`, яка приймає 1 аргумент (_масив мов_).
Вона має повертати першу мову з масиву.
Вважайте, що масив завжди міститиме щонайменше один елемент.

```php
<?php

$language_list = language_list("PHP", "Prolog");
// => ["PHP", "Prolog"]
$first = current_language($language_list);
// => "PHP"
```

## 6. Визначте функцію, яка повертає кількість мов у масиві

Визначте функцію `language_list_length`, яка приймає 1 аргумент (_масив мов_).
Вона має повертати кількість мов у масиві.

```php
<?php

$language_list = language_list("PHP", "Prolog", "Wren");
// => ["PHP", "Prolog", "Wren"]
language_list_length($language_list);
// => 3
```
