# Про це

Один із ключових аспектів роботи з числами у F# - відмінність між цілими числами (числами без цифр після десяткового розділювача) та числами з плаваючою комою (числами, у яких після десяткового розділювача є нуль або більше цифр).

Двома найпоширенішими числовими типами у F# є `int` (32-бітне ціле число) та `float` (64-бітне число з плаваючою комою).

```fsharp
let i = 123   // Type is `int`
let d = 54.29 // Type is `float`
```

І цілі числа, і числа з плаваючою комою можуть використовувати символ `_` як _розділювач цифр_, що допомагає, коли ми задаємо великі числа:

```fsharp
let largeInt = 1_000_000
// => 1000000

let largeFloat = 9_876_543.21
// => 9876543.21
```

Арифметичні дії виконуються за допомогою стандартних [арифметичних операторів][arithmetic-operators] (`+`, `-`, `*` тощо). Числа можна порівнювати за допомогою [стандартних операторів порівняння][comparison-operators] (`<`, `>=` тощо), а також операторів рівності (`=`) і нерівності (`<>`).

```fsharp
5 * 6
// => 30

1.2 > 0.8
// => true

2 <> 4
// => true
```

Щоб перетворити один числовий тип на інший, треба скористатися вбудованим [оператором перетворення][conversion-operators]. Назва кожного з цих операторів походить від типу, на який він перетворює.

```fsharp
let floatFromInt = float 2
let intFromFloat = int 3.39
```

Перетворюючи один тип на інший, завжди слід бути уважними. Якщо значення неможливо подати цільовим типом, відбудеться _переповнення_.
