# Інструкції

Наша подруга Лі Мей тримає бар соків, де продає смачні змішані фруктові соки. Ми часто купуємо в неї й зрозуміли, що могли б трохи полегшити їй життя за допомогою коду на Factor.

## 1. Визначте, скільки часу потрібно на змішування соку

Лі Мей любить заздалегідь казати відвідувачам, скільки їм доведеться чекати на сік із меню. Їй важко пригадати точні числа, бо час на змішування соків різниться:

- `"Pure Strawberry Joy"` займає `0.5` хвилини.
- `"Energizer"` і `"Green Garden"` займають по `1.5` хвилини кожен.
- `"Tropical Island"` займає `3` хвилини.
- `"All or Nothing"` займає `5` хвилин.
- Усі інші напої (наприклад, спеціальні пропозиції) займають `2.5` хвилини.

Визначте `time-to-mix-juice`, яка приймає назву соку зі стека й повертає кількість хвилин, потрібних на змішування цього напою.

```factor
"Tropical Island" time-to-mix-juice .
! => 3

"Berries & Lime" time-to-mix-juice .
! => 2.5
```

## 2. Поповніть запас часточок лайма

Багато напоїв Лі Мей містять часточки лайма, або як складник, або як частину оздоблення. Тож коли вона починає ранкову зміну, їй треба подбати, щоб контейнер із часточками лайма був повним на весь день.

Визначте `wedges-from-lime`, яка приймає розмір лайма й повертає кількість часточок, які з нього виходять: `6` з лайма розміру `"small"`, `8` з лайма розміру `"medium"`, `10` з лайма розміру `"large"`.

Потім визначте `limes-to-cut`, яка приймає кількість часточок `needed` і масив `limes` (розміри лаймів у порядку нарізання). Вона нарізає лайми один за одним, по порядку, і зупиняється, щойно в неї буде достатньо часточок або скінчаться лайми. Поверніть кількість лаймів, які їй довелося нарізати.

```factor
25 { "small" "small" "large" "medium" "small" } limes-to-cut .
! => 4
```

## 3. Складіть список часу змішування кожного замовлення в черзі

Лі Мей любить відстежувати, скільки часу займе змішування замовлень, на які чекають відвідувачі.

Визначте `order-times`, яка приймає масив замовлень і повертає масив із часом змішування кожного замовлення, у тому ж порядку.

```factor
{ "Energizer" "Tropical Island" } order-times .
! => { 1.5 3 }
```

## 4. Завершіть зміну

Лі Мей завжди працює до 15:00. Потім її працівник Дмитро переймає справу. Часто, коли зміна Лі Мей закінчується, залишаються напої, які вже замовили, але ще не приготували; тоді Дмитро готує решту соків.

Щоб полегшити передачу справ, визначте `remaining-orders`, яка приймає кількість хвилин `time-left` у зміні Лі Мей і масив `orders` (соки, які вже замовили, але ще не приготували).

Поверніть замовлення, які доведеться перейняти Дмитрові, тобто ті, які Лі Мей не встигає почати до кінця своєї зміни.

`time-left` завжди більше за `0`. Замовлення готують у тому порядку, у якому вони розташовані в масиві. Щойно Лі Мей починає готувати сік, вона завжди доводить його до кінця, навіть якщо їй доведеться попрацювати трохи довше. Якщо вона встигає почати кожне замовлення, поверніть порожній масив.

```factor
5 { "Energizer" "All or Nothing" "Green Garden" } remaining-orders .
! => { "Green Garden" }
```
