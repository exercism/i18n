# Вступ

Вектор - це одновимірний масив.
Він може містити елементи різних типів.

## Створення векторів

Вектори можна створити за допомогою функції `vector` або скористатися її формою запису `#()`

```lisp
(vector 1 t "foo" 'b) ; => #(1 t "foo" B)
#(2 nil "bar" a)      ; => #(2 nil "bar" A)
```

## Доступ до елементів

Щоб отримати доступ до елементів вектора, скористаймося `aref`; індекси починаються з нуля:

```lisp
(aref #(1 2 3) 1) ; => 2
(aref #(a b c) 0) ; => A
```
