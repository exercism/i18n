# Основи

Програма мовою Sather складається з **класів**, які містять **підпрограми**.

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

end; -- class GREETER
```

## Класи

Назву класу записують великими літерами, а між словами ставлять підкреслення:
`GREETER`, `STAGE_DIRECTIONS`. Назва файлу зазвичай збігається з нею, лише малими
літерами: `stage_directions.sa`.

Кожна підпрограма живе всередині класу. Жодного коду поза класом немає.

## Підпрограми

Підпрограма, яка видає результат, оголошує тип цього результату після двокрапки:

```sather
   hello : STR is
      return "Hello!";
   end;
```

`STR` позначає тип для тексту. Підпрограму без аргументів пишуть і викликають без
дужок.

Підпрограма може приймати аргументи, які записують у дужках після назви:

```sather
   louder(word : STR) : STR is
      return word;
   end;
```

`return` повертає результат і одразу зупиняє підпрограму, тож усі рядки нижче
нього пропускаються.

## Виклик

Ззовні класу спершу вказують назву класу, потім `::`, а далі підпрограму:

```sather
GREETER::hello
```

Усередині того самого класу назву класу можна опустити. Саме так одна
підпрограма зазвичай використовує іншу:

```sather
   greeting_again : STR is
      return hello;
   end;
```

## Коментарі

Коментар починається з двох дефісів і триває до кінця рядка.

```sather
   -- Explain why, not what: the code already says what.
   hello : STR is
      return "Hello!";   -- a trailing comment is fine too
   end;
```

За домовленістю клас завершують коментарем із його назвою. Підпрограми, цикли і
класи закривають однаково, рядком `end;`, тож коментар підказує, якому саме з них
належить цей `end;`:

```sather
end; -- class GREETER
```

## Крапки з комою

Інструкції завершуються крапкою з комою. Крапка з комою після останньої інструкції
в підпрограмі необовʼязкова, але якщо ставити її щоразу, думати доведеться про
менше.
