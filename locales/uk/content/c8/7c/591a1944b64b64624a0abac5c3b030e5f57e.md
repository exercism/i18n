# Вступ

По суті, є два типи циклів:

1. Повторювати, доки не виконається умова.
2. Перебирати елементи в колекції.

Обидва можливі в Julia, хоча другий може бути поширенішим.

## Цикл `while`

Для задач, де заздалегідь невідомо, скільки разів ми пройдемо цикл, у Julia є цикл `while`.

Базова форма досить проста:

```julia
while condition
    do_something()
end
```

У цьому випадку програма продовжуватиме виконувати цикл, доки `condition` не перестане бути `true`.

Є два способи достроково вийти з циклу:

- `break` завершує цикл, і виконання продовжується з наступного рядка після `end` циклу.
- `return x` зупиняє виконання поточної функції та повертає значення `x` тому, хто її викликав.

Коли є ці можливості, іноді зручно створити «нескінченний» цикл за допомогою `while true ... end`, а потім покладатися на те, що умова зупинки всередині тіла циклу викличе `break` або `return`.

## Цикл по колекції

Найпростіше показати це на циклі по діапазону.

Якщо ми хочемо виконати щось 10 разів:

```julia
for n in 1:10
    do_something(n)
end
```

Якщо поточна ітерація не задовольняє якусь умову, можна одразу перейти до наступної ітерації за допомогою `continue`:

```julia
for n in 1:10
    if is_useless(n)
        continue
    end
    
    # we decided this iteration could be useful
    do_something_slow(n)
end
```

У коротшій формі блок `if` можна замінити на `is_useless(n) && continue`.

Можна перебирати й багато інших типів колекцій: елементи масиву, символи в рядку тексту (англ. string), ключі у словнику...

У прикладах досі ми перебираємо діапазон `1:10`, де значення також є індексом циклу.

Загалом індекс може бути потрібним, а не лише значення.
Для цього використовують функцію `eachindex()`, наприклад `for i in eachindex(my_array) ... end`.
