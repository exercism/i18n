# Інструкції

Джош працює над новою рольовою грою і потребує нашої допомоги з реалізацією частини механік.

## 1. Визначте обʼєднання типів

Визначте обʼєднання типів `String` і `Missing` під назвою `StringOrMissing`, яке можна буде використати в подальшому коді.
Визначте обʼєднання типів `Int64` і `Nothing` під назвою `IntOrNothing`, яке можна буде використати в подальшому коді.

## 2. Реалізуйте складений тип `Player`

Складений тип `Player` має містити чотири поля, кожне з анотацією типу та типовим значенням:
- `name` має тип `StringOrMissing` і типове значення `missing`
- `level` має тип `Int64` і типове значення `0`
- `health` має тип `Int64` і типове значення `100`
- `mana` має тип `IntOrNothing` і типове значення `nothing`

```julia-repl
julia> defaultplayer = Player()
Player(missing, 0, 100, nothing)

julia> wealthyplayer = Player(mana=100)
Player(missing, 0, 100, 100)

julia> namedplayer = Player(name="Guilian", level=10)
Player("Guilian", 10, 100, nothing)
```

## 3. Представтеся

Реалізуйте функцію `introduce`.

Скритні гравці можуть приховувати своє імʼя, і тоді їх представлять як `"Mighty Magician"`.
В іншому разі просто використайте імʼя гравця, щоб його представити.

```julia-repl
julia> introduce(Player(level=2, health=8))
"Mighty Magician"

julia> introduce(Player(name="Merlin", level=2, health=8))
"Merlin"
```

## 4. Реалізуйте методи `increment`

Допоміжна функція `increment` має два методи, кожен зі своєю сигнатурою функції.
Аргумент кожного з них потребує анотації типу, щоб зробити сигнатуру явною.

Метод `increment` для імен має приймати `name` гравця.
- Якщо імʼя `missing`, поверніть титул "The Great".
- В іншому разі до імені додається титул " the Great".

Цей метод `increment` повертає нове імʼя.

```julia-repl
julia> player1 = Player(name="Ogre", level=5, health=49, mana=26)
Player("Ogre", 5, 49, 26)

julia> increment(player1.name)
"Ogre the Great"

julia> player2 = Player(level=32, mana=57)
Player(missing, 32, 100, 57)

julia> increment(player2.name)
"The Great"
```

Метод `increment` для мани має приймати `mana` гравця.
- Якщо `mana` гравця дорівнює `missing`, поверніть значення `50`.
- В іншому разі `mana` слід збільшити на `100`.

Цей метод `increment` повертає оновлену `mana`.

```julia-repl
julia> player3 = Player(level=3)
Player(missing, 3, 100, nothing)

julia> increment(player3.mana)
50

julia> player4 = Player("Goblin", level=15, health=49, mana=26)
Player("Goblin", 5, 49, 26)

julia> increment(player4.mana)
126
```

## 5. Реалізуйте функцію `title!`

Найвищий рівень у грі - `42`. Щоб відзначити досягнення гравців, які сягають цього рівня, до їхніх імен додають титул. Функція `title!` оновлює імʼя гравця так:

- Якщо рівень гравця дорівнює 42, імʼя оновлюють за допомогою функції `increment`.
- В іншому разі імʼя залишається без змін.

У будь-якому разі функція `title!` повертає імʼя гравця.

```julia-repl
julia> player1 = Player(level=42, health=12)
Player(missing, 42, 12, nothing)

julia> title!(player1)
"The Great"

julia> player1.name
"The Great"

julia> player2 = Player(name="Svengali", level=42, health=36, mana=54)
Player("Svengali", 42, 36, 54)

julia> title!(player2)
"Svengali the Great"

julia> player2.name
"Svengali the Great"

julia> player3 = Player(name="Rasputin", level=21, health=100, mana=54)
Player("Rasputin", 21, 100, 54)

julia> title!(player3)
"Rasputin"

julia> player3.name
"Rasputin"
```

## 6. Реалізуйте функцію `revive!`

Функція `revive!` має перевірити, що персонаж гравця справді мертвий (його здоровʼя сягнуло `0`).

Якщо гравець мертвий:
- Гравця слід оживити зі `100` здоровʼя.
- `mana` гравця слід збільшити за допомогою функції `increment`.

Якщо гравець живий, з ним нічого не відбувається.

Функція `revive!` має повернути гравця.

```julia-repl
julia> deadplayer1 = Player(level=2, health=0)
Player(missing, 2, 0, nothing)

julia> revive!(deadplayer1)
Player(missing, 2, 100, 50)

julia> deadplayer2 = Player(level=12, health=0, mana=5)
Player(missing, 12, 0, 5)

julia> revive!(deadplayer2)
Player(missing, 12, 100, 105)

julia> aliveplayer = Player(level=23, health=1)
Player(missing, 23, 1, nothing)

julia> revive!(aliveplayer)
Player(missing, 23, 1, nothing)
```
