# Методи рядків

`String` має кілька методів, які допомагають працювати з рядками тексту (англ. string).
Ми викликаємо ці методи на самому рядку тексту, і часто поєднуємо їх у ланцюжки, щоб виконати кілька операцій над рядком.

Нижче наведено список деяких найпоширеніших методів.
Повний список методів наведено в [документації API `String`][string-api].

## String#upcase & String#downcase

Метод [`upcase`][upcase] повертає новий рядок тексту, у якому всі символи переведено у верхній регістр.

```crystal
"hello".upcase
# => "HELLO"
```

Метод [`downcase`][downcase] повертає новий рядок тексту, у якому всі символи переведено у нижній регістр.

```crystal
"HELLO".downcase
# => "hello"
```

## String#sub & String#gsub

У Crystal є методи для заміни частин рядка тексту.
Це [`sub`][sub] (_substitution_, тобто заміна) і [`gsub`][gsub] (_global substitution_, тобто глобальна заміна).

Ці методи можуть приймати рядок тексту, символ або регулярний вираз як перший аргумент і рядок тексту або символ як другий аргумент.
Перший аргумент задає ту частину рядка тексту, яку буде замінено, а другий аргумент задає заміну.
`Char` і регулярні вирази пояснимо в наступних концепціях.

Метод `sub` замінює перше входження першого аргументу на другий аргумент.

```crystal
"hello".sub("l", "r")
# => "herlo"
```

Метод `gsub` працює так само, як `sub`, але замінює всі входження першого аргументу на другий аргумент.

```crystal
"hello".gsub("l", "r")
# => "herro"
```

## String#chomp & String#strip

Методи `chomp` і `strip` можна використовувати, щоб прибрати зайві символи з рядка тексту.

За типової поведінки метод [`chomp`][chomp] прибирає останні символи `\r`, `\n` або `\r\n` з рядка тексту.
Якщо метод викликати з аргументом, він прибере вказане значення з кінця рядка тексту (якщо воно там є).

```crystal
"hello\n".chomp
# => "hello"

"hello".chomp("llo")
# => "he"
```

За типової поведінки метод [`strip`][strip] прибирає всі пробільні символи на початку та в кінці рядка тексту.
Якщо метод викликати з аргументом, він прибере цей аргумент на початку та в кінці рядка тексту (якщо він там є).

```crystal
" hello ".strip
# => "hello"
```

## String#index

Метод [`index`][index] можна використати, щоб знайти індекс символу в рядку тексту.
Метод `index` приймає `String`, `Char` або регулярний вираз як аргумент.
Він може приймати необовʼязковий другий аргумент, який задає індекс, від якого починати пошук.
Метод `index` повертає індекс першого входження аргументу.

```crystal
"hello".index("l")
# => 2

"hello".index("l", 3)
# => 3
```

## String#delete_at

Метод [`delete_at`][delete_at] можна використати, щоб прибрати символ із рядка тексту.
Метод `delete_at` приймає індекс як аргумент і прибирає символ за цим індексом.

```crystal
"hello".delete_at(0)
# => "ello"

"hello".delete_at(3)
# => "helo"
```

## String#insert

Метод [`insert`][insert] можна використати, щоб вставити рядок тексту за конкретним індексом.
Метод `insert` приймає індекс як перший аргумент і рядок тексту як другий аргумент.
Метод `insert` повертає новий рядок тексту з другим аргументом, вставленим за цим індексом.

```crystal
"hello".insert(0, "h")
# => "hhello"

"hello".insert(3, "l")
# => "helllo"
```
