# If, Elseif, Else

Умовні конструкції з `if`, `elseif` та `else` становлять фундаментальну частину потоку керування програмою.
Умовний оператор `if` обчислює вираз і, якщо той дорівнює `true`, виконує гілку коду.

```php
<?php

if ($expression) {
    // .. executed if $expression is true
}
```

Якщо вираз не є булевим значенням (англ. Boolean), обчислення визначає, чи воно «правдиве», а чи «неправдиве».
У PHP такі значення вважаються рівними неправді:

- булеве значення `false`
- ціле число `0`
- число з плаваючою комою `0.0` та `-0.0`
- порожній масив `[]`
- порожній рядок тексту (англ. string) `""` або числовий рядок тексту `"0"`
- `null`

Усі інші значення вважаються правдивими.

## Реакція на кілька умов

Після умовного оператора `if` можна обʼєднати в ланцюжок кілька умов за допомогою `elseif` та `else`.

```php
<?php

if ($value === 0) {
    // .. do something
} elseif ($value === 1) {
    // .. do something else
} else {
    // ,, do this if nothing else
}
```

Виконається лише одна умовна конструкція, обчислена як правдива.
Тож якщо кілька умов можуть обчислитися як правдиві, порядок, у якому їх записано, має значення.

```php
<?php

if (true) {
    // .. always do something
} elseif (true)
    // .. will never be executed
} else {
    // .. will never be executed
}
```
