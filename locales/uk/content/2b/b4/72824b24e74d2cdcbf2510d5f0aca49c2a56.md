# Доповнення до інструкцій

Одне з можливих рішень цієї вправи - реалізувати власну функцію модульного піднесення до степеня.
Щоб дізнатися більше про це, звернімося до [наступної сторінки](https://en.wikipedia.org/wiki/Modular_exponentiation).

## За додаткові бали

Багато реалізацій не працюють для всієї області вхідних даних.
Визначено додаткові необовʼязкові тести, які допомагають переконатися, що всі коректні вхідні дані дають коректні результати.

Щоб запустити тести для додаткових балів, приберіть прапорець `#[ignore]` і виконайте тести
з можливістю `big-primes`, ось так:

```bash
$ cargo test --features big-primes
```
