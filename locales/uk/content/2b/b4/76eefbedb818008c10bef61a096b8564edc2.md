# Вступ

## Масиви

У Common Lisp, як і в інших мовах, масив - це набір елементів, доступ до яких отримують за цілочисельними індексами.
Типи елементів можуть бути різнорідними.
Масив може бути багатовимірним (а не просто одновимірним).

### Створення

`make-array` дає змогу створювати масиви.
Він має багато опцій, але його простіші форми дають змогу створити N-вимірні масиви, усі елементи яких ініціалізовано одним значенням, або масив, ініціалізований значеннями з іншої послідовності (наприклад, зі списку). 
Його перший аргумент - це список розмірів кожного виміру.

```lisp
(make-array '(4) :initial-element 3)    ; => #(3 3 3 3)
(make-array '(2 2) :initial-element 'x) ; => #2A((X X) (X X))
```

(Звернімо увагу, як N-вимірні масиви друкуються разом із кількістю вимірів.)

Масиви також можна створювати, використовуючи той самий формат, у якому вони друкуються: 

```lisp
#(x y z)         ; => #(X Y Z)
#2A((1 2) (3 4)) ; => #2A((1 2) (3 4))
```

### Доступ до елементів

Щоб отримати доступ до елементів вектора, використовуймо `aref`; індекси починаються з нуля. 
Кількість наданих індексів має збігатися з рангом масиву.

```lisp
(aref #2A((1 2 3) (3 4 5)) 
       1 0)           ; => 3
(aref #3A(((a b) (c d)) 
           ((e f) (g h)) 
           ((t u) (v w))) 
       2 0 1)         ; => U
(aref #2A((1) (2)) 0) ; => ERROR (because not enough indexes provided)
```
