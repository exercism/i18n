# Інструкції

Ми працюємо над проєктом, який дозволяє користувачам завантажувати файли на сервер, щоб ділитися ними з іншими користувачами. Наше завдання - написати функцію, яка перевіряє, чи відповідає завантажений файл своєму [типу медіа][mimetype]. Ми трохи досліджуємо це питання і зʼясовуємо, що перші кілька байтів файлу зазвичай унікальні саме для цього типу, що дає йому своєрідний підпис.

Скористаймося наведеною таблицею як довідкою:

| Тип файлу | Поширене розширення | Тип медіа                    | бінарний «підпис»                                |
| --------- | ------------------- | ---------------------------- | ------------------------------------------------ |
| ELF       | `"exe"`             | `"application/octet-stream"` | `0x7F, 0x45, 0x4C, 0x46`                         |
| BMP       | `"bmp"`             | `"image/bmp"`                | `0x42, 0x4D`                                     |
| PNG       | `"png"`             | `"image/png"`                | `0x89, 0x50, 0x4E, 0x47, 0x0D, 0x0A, 0x1A, 0x0A` |
| JPG       | `"jpg"`             | `"image/jpg"`                | `0xFF, 0xD8, 0xFF`                               |
| GIF       | `"gif"`             | `"image/gif"`                | `0x47, 0x49, 0x46`                               |

## 1. За заданим розширенням повернути очікуваний тип медіа

Реалізуймо функцію `type_from_extension/1`. Вона приймає розширення файлу, тобто рядок тексту (англ. string), і повертає тип медіа, теж рядок тексту, або nil, якщо розширення не відповідає очікуваним.

```elixir
FileSniffer.type_from_extension("exe")
# => "application/octet-stream"

FileSniffer.type_from_extension("txt")
# => nil
```

## 2. За заданими бінарними даними файлу повернути очікуваний тип медіа

Реалізуймо функцію `type_from_binary/1`. Вона приймає файл (бінарні дані) і повертає тип медіа (рядок тексту) або nil, якщо підпис файлу не відповідає очікуваним.

```elixir
file = File.read!("application.exe")
FileSniffer.type_from_binary(file)
# => "application/octet-stream"

file = File.read!("example.txt")
FileSniffer.type_from_binary(file)
# => nil
```

Не переймаймося читанням файлу як бінарних даних. Вважаймо, що це вже зроблено за нас і тести передають це як аргумент.

## 3. За заданими розширенням і бінарними даними файлу перевірити, чи відповідає файл очікуваному типу

Реалізуймо функцію `verify/2`. Вона приймає файл (бінарні дані) та розширення (рядок тексту) і повертає кортеж `:ok` або `:error`.

```elixir
file = File.read!("application.exe")

FileSniffer.verify(file, "exe")
# => {:ok, "application/octet-stream"}

FileSniffer.verify(file, "png")
# => {:error, "Warning, file format and file extension do not match."}
```
