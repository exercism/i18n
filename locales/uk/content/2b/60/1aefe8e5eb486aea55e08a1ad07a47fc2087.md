# помилка клаузи функції в raise

[comment]: # (Ця помилка виникає, коли рішення містить виклик `raise FunctionClauseError` замість того, щоб Elixir сам не зміг зіставити виклик функції two_fer для типів, що не є рядками.)

Не викликайте `raise FunctionClauseError` напряму.

> Виклик цієї помилки - [запах коду](https://en.wikipedia.org/wiki/Code_smell), який означає, що клаузи функції слід переставити або додати сторожові вирази, щоб запобігти зіставленню функцій.

1. Коли Elixir виконує код, він намагається зіставити виклик [іменованих функцій](https://elixir-lang.org/getting-started/modules-and-functions.html#named-functions) та параметри з кожною функцією, рухаючись згори донизу.
2. Якщо використовувати [сторожові вирази](https://hexdocs.pm/elixir/master/guards.html), можна запобігти виклику функції з аргументами, які не відповідають її призначенню.
3. Якщо для іменованої функції немає відповідного зіставлення, [BEAM VM](<https://en.wikipedia.org/wiki/BEAM_(Erlang_virtual_machine)>) під час виконання викликає `FunctionClauseError`.
