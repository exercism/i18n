# Докладніше

Lua використовує два подання чисел: 64-бітні цілі числа та числа з плаваючою комою подвійної точності.

~~~exercism/note
До версії 5.3 Lua подавала всі числа у форматі чисел з плаваючою комою подвійної точності.
~~~

Числа можна записувати з необовʼязковою десятковою частиною та необовʼязковим десятковим показником степеня.
```lua
1               --> 1
0.2             --> 0.2
0.3e4           --> 3000.0
4.0e-3          --> 0.004
5.0e+20         --> 5e+20
```

Число з десятковою крапкою або показником степеня вважається числом з плаваючою комою, а число без них вважається цілим, але обидва мають тип 'number'.
```lua
type(1)         --> number
type(2.0)       --> number
```

Якщо ми хочемо розрізняти числа з плаваючою комою та цілі числа, можна скористатися функцією `type` з модуля `math`.
```lua
math.type(1)    --> integer
math.type(2.0)  --> float
```

## Порівняння

Цілі числа та числа з плаваючою комою з однаковим значенням вважаються рівними під час порівняння:
```lua
1 == 1.0        --> true
-2 == -2.0      --> true
0.3e3 == 300    --> true
```

## Арифметика

Lua підтримує звичайний набір арифметичних операторів: додавання, віднімання, множення, ділення та заперечення. Крім того, вона підтримує цілочисельне ділення, остачу від ділення та піднесення до степеня.

### Додавання, віднімання, множення та заперечення

Якщо обидва операнди є цілими числами, результат операції теж буде цілим числом. Те саме стосується чисел з плаваючою комою.
```lua
1 + 2     --> 3
1.0 + 2.0 --> 3.0
```

Якщо один операнд є числом з плаваючою комою, решту цілих чисел теж буде перетворено на числа з плаваючою комою, і результат операції буде числом з плаваючою комою.
```lua
1.0 + 2   --> 3.0
```

### Ділення

Ділення завжди працює з числами з плаваючою комою і дає в результаті число з плаваючою комою.
```lua
1.0 / 2.0 --> 0.5
2 / 1     --> 2.0
```

Ділення на нуль дає `inf` або `-inf`. Ділення нуля на нуль дає `-nan`.
```lua
1 / 0     --> inf
-1 / 0    --> -inf
0 / 0     --> -nan
```

### Цілочисельне ділення

Якщо потрібен цілочисельний результат, можна скористатися цілочисельним діленням. Воно завжди округлює частку в напрямку мінус нескінченності, тож результат буде цілим за будь-яких операндів.

~~~exercism/note
До версії 5.3 у Lua не було арифметичного оператора для цілочисельного ділення.
~~~

```lua
3 // 2    --> 1
6 // 2    --> 3
```

Цілочисельне ділення підпорядковується тим самим правилам, що й оператори додавання, віднімання, множення та заперечення: якщо обидва операнди є цілими числами, результат операції буде цілим числом, інакше результат буде числом з плаваючою комою.

```lua
3.0 // 2   --> 1.0
6.0 // 2.0 --> 3.0
```

Коли ми ділимо на нуль за допомогою цілочисельного ділення, Lua видасть помилку.
```lua
3 // 0     --> stdin:1: attempt to divide by zero
```

### Остача від ділення

Остачу від ділення використовують, щоб отримати залишок від ділення двох операндів.
```lua
8 % 2      --> 0
13 % 9     --> 4
-13 % -9   --> -4
-13 % 9    --> 5
13 % -9    --> -5
0.3 % 0.2  --> 0.1
```

### Піднесення до степеня

Як і ділення, піднесення до степеня також працює з числами з плаваючою комою і дає в результаті числа з плаваючою комою.
```lua
10 ^ 2    --> 100.0
```

## Пріоритет

Усі операції обчислюються згідно з [пріоритетом операторів](https://www.lua.org/manual/5.4/manual.html#3.4.8). Дужки можна використовувати, щоб змінити пріоритет обчислення виразу.

```lua
1 + 2 * 3   --> 7
(1 + 2) * 3 --> 9
```

## Округлення

Модуль `math` надає три функції округлення: `floor` округлює «вниз» (у напрямку мінус нескінченності), `ceil` округлює «вгору» (у напрямку плюс нескінченності), а `modf` округлює в напрямку нуля.

### `math.floor`

`floor` округлює в напрямку мінус нескінченності.
```lua
math.floor(1.3)    --> 1
math.floor(-1.3)   --> -2
```

### `math.ceil`

`ceil` округлює в напрямку плюс нескінченності.
```lua
math.ceil(1.3)    --> 2
math.ceil(-1.3)   --> -1
```

### `math.modf`

`modf` округлює в напрямку нуля. Функція повертає як округлене значення, так і дробову частину числа, яка завжди є числом з плаваючою комою.
```lua
math.modf(1.3)    --> 1    0.3
math.modf(-1.3)   --> -1   -0.3
```

## Перетворення

Якщо ми хочемо перетворити ціле число на число з плаваючою комою, можна додати до нього `0.0`.
```lua
1 + 0.0         --> 1.0
```

Якщо ми хочемо перетворити число з плаваючою комою на ціле, можна застосувати до нього побітове АБО з нулем або скористатися функцією `tointeger` з модуля `math`.
```lua
1.0 | 0              --> 1
math.tointeger(1.0)  --> 1
```

Якщо число неможливо перетворити на ціле, оператор АБО видасть помилку, а функція `tointeger` поверне `nil`.
```lua
1.1 | 0              --> stdin:1: number has no integer representation
math.tointeger(1.1)  --> nil
```

## Шістнадцяткові числа

Як і багато інших мов програмування, Lua підтримує шістнадцяткові числа, якщо передувати їм `0x`, але на відміну від багатьох інших мов програмування Lua підтримує також шістнадцяткові числа з плаваючою комою. Вони можуть мати дробову частину та двійковий показник степеня, перед яким стоїть 'p' або 'P'.
```lua
0xff            --> 255
0x0.2           --> 0.125
0x3p-1          --> 1.5
0xa.bp2         --> 42.75
```
