# Instructions

Олена, нова керівниця відділу якості на газетній фабриці, просить нас написати невелику програму для стеження за виробничим цехом.

## 1. Визначте власну помилку

Визначте клас кортежу помилки `machine-error` за допомогою слова розбору `ERROR:`. Йому не потрібні слоти.

```factor
machine-error   ! throws a fresh machine-error
```

## 2. Перевірте вологість

Визначте `check-humidity`. Воно приймає зі стека показник вологості й викликає `throw` зі рядком `"humidity too high"`, коли цей показник строго більший за `70`. Інакше воно нічого не повертає.

```factor
50 check-humidity   ! returns nothing
80 check-humidity   ! throws "humidity too high"
```

## 3. Перевірте температуру

Визначте `check-temperature`. Воно приймає показник температури й викликає `throw` зі рядком `"temperature too high"`, коли цей показник строго більший за `500`. Інакше воно нічого не повертає.

```factor
400 check-temperature   ! returns nothing
600 check-temperature   ! throws "temperature too high"
```

## 4. Стежте за машиною

Визначте `monitor`, щоб воно приймало зі стека вологість і температуру та виконувало обидві перевірки. Якщо будь-яка з перевірок викликає `throw`, `monitor` натомість має викликати `throw` з новим `machine-error`. Якщо обидві перевірки проходять, `monitor` нічого не повертає.

```factor
50 400 monitor   ! returns nothing
80 400 monitor   ! throws a machine-error
50 600 monitor   ! throws a machine-error
```

## 5. Стежте за партією показників

Визначте `monitor-batch`, щоб воно приймало масив показників `{ humidity temperature }` і повертало, скільки з них провалилися б (тобто скільки змусили б `monitor` викликати `throw`).

```factor
{ { 50 400 } { 80 400 } { 50 600 } { 60 200 } } monitor-batch .
! => 2
```
