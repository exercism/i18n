# Встановлення

Щоб запускати ці вправи, знадобляться лише встановлені [CommandBox CLI](https://commandbox.ortusbooks.com/getting-started-guide) та [Java 8](https://java.com/en/download/). CommandBox CLI підтримується на Mac, Linux і Windows, а посібник зі встановлення можна знайти тут:

[https://commandbox.ortusbooks.com/setup/installation](https://commandbox.ortusbooks.com/setup/installation)

Наприклад, якщо ми користуємося Homebrew на Mac, налаштування CommandBox CLI матиме такий вигляд:

```bash
brew install commandbox
```

Коли CLI встановлено, можна пограти з REPL:

```bash
box repl
```

Можна напряму виконувати сторінки .cfm:

```bash
box exec myTest.cfm
```

А ще можна запустити вебсервер у будь-якому каталозі на жорсткому диску:

```bash
box server start
```

У CommandBox є інтерактивна оболонка, якою можна користуватися: вона має покращене автодоповнення за допомогою Tab і працює швидше. Щоб увійти до неї, достатньо запустити бінарник `box` без аргументів.

```bash
box
```
