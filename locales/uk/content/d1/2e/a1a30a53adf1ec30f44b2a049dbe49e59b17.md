# Вступ

Багато мов мають спосіб на кшталт `null` або `none`, щоб позначити неіснуюче значення.
Оскільки Julia розроблена для роботи з великими обсягами (часто неохайних) даних, у неї є кілька форм неіснування.

Загальна мета: позначити відсутні або підозрілі значення, щойно ми з ними стикаємося, а потім продовжити роботу, не викликаючи винятку.

## `nothing`

Якщо значення справді не існує, його позначають через `nothing`. Це, ймовірно, найближче до того, що робить C (`NULL`) або Python (`None`).

```julia-repl
julia> n = nothing

julia> isnothing(n)
true

julia> typeof(n)
Nothing
```

Отже, `nothing` є єдиним значенням типу `Nothing`, і ми можемо його перевірити.

Одне з поширених застосувань `nothing` - це значення, яке повертають (або не повертають) функції, що використовуються лише заради побічних ефектів (друк, налаштування мережі тощо).

## `missing`

Для ситуацій, коли значення існує в теорії, але ми не знаємо, яке воно, використовують `missing`. Наприклад, коли рахують транспортні засоби, що рухаються дорогою, людям-спостерігачам може знадобитися перерва, або автоматичні датчики виходять з ладу, але рух транспорту триває.

Отже, `missing` - це заповнювач, який попереджає людей, що їм потрібно вирішити, як поводитися з цією прогалиною в даних.

```julia-repl
julia> mv = [1, 2, missing]
3-element Vector{Union{Missing, Int64}}:
 1
 2
  missing

julia> typeof(mv)
Vector{Union{Missing, Int64}} (alias for Array{Union{Missing, Int64}, 1})

julia> ismissing.(mv)  # broadcast function, displays as 1 for true, 0 for false
3-element BitVector:
 0
 0
 1
```

Мало які інші мови мають цю можливість убудованою, але близькі аналоги - це `NA` в R або `NULL` у SQL.

Вирази зазвичай повертають `missing`, якщо значення `missing` присутні.
Якщо ми хочемо, щоб ці значення ігнорували, скористаймося функцією `skipmissing()`, щоб зробити це явним:

```julia-repl
julia> mv = [1, 2, missing]
3-element Vector{Union{Missing, Int64}}:
 1
 2
  missing

julia> sum(mv)  # missing in, missing out
missing

julia> skipmissing(mv)
skipmissing(Union{Missing, Int64}[1, 2, missing])

julia> collect(skipmissing(mv))
2-element Vector{Int64}:
 1
 2

julia> sum(skipmissing(mv))  # functions like sum() can work with iterators
3
```

Оскільки `skipmissing` створює ітератор, обгорнімо його в `collect()`, якщо нам потрібен вектор.

Іноді корисно замінити значення `missing` на якесь типове значення.
Для цього стане в пригоді макрос `@coalesce()`, який повертає перше значення, відмінне від `missing` (або `missing`, якщо більше нічого немає).

```julia-repl
julia> str = ["I", "exist", missing]
3-element Vector{Union{Missing, String}}:
 "I"
 "exist"
 missing

julia> [@coalesce(s, "-") for  s in str]
3-element Vector{String}:
 "I"
 "exist"
 "-"
```

## `NaN`

Скорочення від «Not a Number» (не число): NaN позначає проблему обчислення в ситуаціях, де очікувалося число.

```julia-repl
julia> v = [0, 1, -1]
3-element Vector{Int64}:
  0
  1
 -1

julia> v / 0
3-element Vector{Float64}:
 NaN
  Inf
 -Inf
 
julia> sum(v / 0)
NaN
```

Будь-яке обчислення над даними, що містять NaN, дасть результат `NaN`.

Наразі немає спеціальної функції для видалення значень `NaN`, але стандартна функція `filter()` може зробити це досить просто.
До результуючого масиву потраплять лише ті значення, для яких задана умова є `true`:

```julia-repl
julia> filter(!isnan, [1, 2, NaN])
2-element Vector{Float64}:
 1.0
 2.0
```
