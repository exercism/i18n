# Додаток до інструкцій

## Підказки

Реалізуйте функцію `responseFor`, яка повертає відповідь Боба на задані вхідні дані. Можна скористатися наданою сигнатурою, якщо є сумніви щодо типів, але хай вона не обмежує творчості:

```haskell
responseFor :: String -> String
```

Щоб розвʼязати цю вправу, можна почитати про:

- [Вартові][guards]

[guards]: https://www.futurelearn.com/courses/functional-programming-haskell/0/steps/27226

Ця вправа працює з текстовими даними. З історичних причин тип `String` у Haskell є синонімом до `[Char]`, списку символів. Для ефективнішої роботи з текстовими даними можна використати тип `Text`.

Як необовʼязкове розширення до цієї вправи можна:

- Прочитати про [типи рядків тексту (англ. string)](https://haskell-lang.org/tutorial/string-types) у Haskell.
- Додати `- text` до списку залежностей у package.yaml.
- Імпортувати `Data.Text` [у такий спосіб](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

    ```haskell
    import qualified Data.Text as T
    import           Data.Text (Text)
    ```

- Тепер можна написати, наприклад, `responseFor :: Text -> Text`, і посилатися на комбінатори з `Data.Text` як, наприклад, `T.isSuffixOf`.
- Знайти документацію для [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html),
- Потім можна замінити всі входження `String` на `Text` у Bob.hs:

    ```haskell
    responseFor :: Text -> Text
    ```

Ця частина цілком необовʼязкова.
