# Про концепцію

Модуль `gleam/order` зі стандартної бібліотеки Gleam містить тип `Order`, який використовується для порівняння значень.

Визначення `Order` має такий вигляд:

```gleam
pub type Order {
  Gt
  Eq
  Lt
}
```

Тип має три варіанти, кожен з яких використовується для позначення відношення між значенням та іншим значенням:

- `Gt` - значення _більше_ за інше значення.
- `Eq` - значення _дорівнює_ іншому значенню.
- `Lt` - значення _менше_ за інше значення.

Якщо тип даних можна порівнювати за величиною, зазвичай модуль визначає функцію `compare`, яка повертає значення `Order`. Наприклад, `gleam/float` і `gleam/int` визначають функції `compare`, які працюють відповідно з числами з плаваючою комою та цілими числами.

```gleam
int.compare(1, 2)
// -> Lt

int.compare(2, 2)
// -> Eq

float.compare(1.0, 2.0)
// -> Lt
```

Функції сортування, як-от `list.sort`, зазвичай приймають функцію, яка повертає значення `Order`, що дає змогу тому, хто викликає, визначити, як сортувати масив.

```gleam
list.sort([3, 7, 3, 1], by: int.compare)
// -> [1, 3, 3, 7]
```
