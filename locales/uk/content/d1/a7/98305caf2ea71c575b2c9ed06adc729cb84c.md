# Вступ

Масиви вбудовані в мову Elixir. Вони вважаються базовим типом, який позначається квадратними дужками. Масиви можуть бути порожніми або містити будь-яку кількість елементів будь-якого типу. Наприклад:

```elixir
empty_list = []
one_item_list = [1]
two_item_list = [1, 2]
multiple_type_list = [1, :pi, 3.14, "four"]
```

Elixir реалізує масиви як звʼязану структуру, де кожен вузол зберігає два значення: перший елемент і ще один масив з рештою елементів. Перший елемент масиву називають _головою_, а решту елементів масиву - _хвостом_. Ми можемо використовувати цей запис у коді:

```elixir
# [1] represented in [head | tail] notation
[1 | []]

# [1, 2, 3] represented in [head | tail] notation
[1 | [2 | [3 | []]]]
```

Ми можемо використовувати запис _`[head | tail]`_, щоб додавати елементи на початок масиву:

```elixir
# Suppose
list = [2, 1]

[3, 2, 1] == [3 | list]
# => true
```

У модулі `Kernel` є кілька функцій для роботи з масивами, а також цілий модуль `List`.

```elixir
# Check if 1 is a member of the list
1 in [1, 2, 3, 4]
# => true
```
