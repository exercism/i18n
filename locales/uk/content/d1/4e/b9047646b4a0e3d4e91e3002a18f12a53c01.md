# Вступ

У Common Lisp функція може мати іменовані параметри (які називають «ключовими параметрами»). У лямбда-списку їх позначає ключове слово `&key`. Ключові параметри не є обовʼязковими параметрами. Як і необовʼязкові параметри, їм можна задати типові значення та символи, які звʼязуються з їхнім станом «передано чи ні».

Коли ми викликаємо функцію з ключовими параметрами, перед значенням параметра ставимо імʼя параметра як ключове слово. Ключові параметри можна задавати в будь-якому порядку.

```lisp
(defun keyword-parameters (&key x (y 'default) (z nil z-supplied-p))
  (list x y (if z-supplied-p (list :z-was-supplied z)
                             (list :z-was-not-supplied z))))

(keyword-parameters)            ; => (NIL DEFAULT (:Z-WAS-NOT-SUPPLIED NIL))
(keyword-parameters :y 5)       ; => (NIL 5 (:Z-WAS-NOT-SUPPLIED NIL))
(keyword-parameters :z 10 :x 5) ; => (5 DEFAULT (:Z-WAS-SUPPLIED 10))
```

Варто бути обережними, коли ми поєднуємо необовʼязкові та ключові параметри, бо імʼя ключового параметра й аргумент можуть бути поглинуті необовʼязковими параметрами:

```lisp
(defun could-be-confusing (&optional x y &key z) (list x y z))
(could-be-confusing :z 'huh?) ; => (:Z HUH? NIL)
```
