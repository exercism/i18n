# Запуск тестів

Якщо `sbt` встановлено, тести можна виконати з командного рядка командою:

```bash
$ sbt test
```

Зауважмо, що запускати `sbt test` щоразу буде повільно, адже це переініціалізує `sbt` при кожному виклику.

`sbt` працює як оболонка: щойно його запущено, всередині нього можна виконувати команди.

Наприклад, можна використати `sbt`, щоб перезапускати тести щоразу, коли змінюються вихідні файли:
```bash
$ sbt
>~ test
```

Зауважмо, що всі тести вимкнено, крім першого, над яким треба працювати.
Щоб продовжити, просто приберіть ключове слово `pending` з початку кожного тесту.

Перейдіть [сюди](https://www.scala-sbt.org/), щоб дізнатися більше про `sbt`.


Тести також можна запускати в таких середовищах розробки (IDE)

* [Metals](https://scalameta.org/metals/docs/#running-tests)
* [IntelliJ IDEA with Scala Plugin](https://www.jetbrains.com/idea/)
