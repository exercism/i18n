# Вступ

## Черги

Стандартна бібліотека Gleam реалізує тип `Queue` у модулі `gleam/queue`. Він схожий на тип `List`, але має кілька ключових відмінностей:

- Тип `Queue` не має синтаксису літералів, який можна було б використати, щоб створювати черги або зіставляти їх зі зразком.
- Елементи можна ефективно додавати та видаляти як з початку, так і з кінця типу `Queue`, тоді як тип `List` дає змогу ефективно додавати й видаляти елементи лише з початку.

Здебільшого ми хочемо використовувати тип `List`, але коли потрібно додавати й видаляти елементи з кінця колекції, тип `Queue` буде хорошим вибором.

Черги можна створювати за допомогою функцій `queue.new` і `queue.from_list`:

```gleam
let empty = queue.new()
let one_to_four = queue.from_list([1, 2, 3, 4])
```

Елементи можна додавати до черги за допомогою функцій `queue.push_front` і `queue.push_back`:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
let one_to_five = queue.push_back(one_to_four, 5)
let zero_to_five = queue.push_front(one_to_five, 0)
```

Елементи можна видаляти з черги за допомогою функцій `queue.pop_front` і `queue.pop_back`:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])

queue.pop_back(one_to_four)
// -> Ok(#(4, queue.from_list([1, 2, 3])))

queue.pop_front(one_to_four)
// -> Ok(#(1, queue.from_list([2, 3, 4])))

queue.pop_front(queue.new())
// -> Error(Nil)
```

Чергу можна перетворити на масив за допомогою функції `queue.to_list`:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
queue.to_list(one_to_four)
// -> [1, 2, 3, 4]
```

### Рівність черг

Через те, як реалізовано черги, дві черги з однаковими елементами в однаковому порядку можуть бути нерівними за оператором `==`, який порівнює значення структурно. Наприклад:

```gleam
let empty = queue.new()
let a = queue.push_front(empty, 1)
let b = queue.push_back(empty, 1)
a == b
// -> False
```

Якщо потрібно порівняти дві черги на рівність, можна використати функцію `queue.is_logically_equal`.

```gleam
queue.is_logically_equal(a, b, fn(x, y) { x == y })))
// -> True
```
