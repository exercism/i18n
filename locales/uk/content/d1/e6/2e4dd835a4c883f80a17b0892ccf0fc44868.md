# Case

[`case`][case] (в інших мовах його часто називають switch) належить до керуючих виразів, як і if-else.
`case` дає змогу обʼєднувати в ланцюжок кілька інструкцій if-else-if, буває читабельнішим і уможливлює потужні конструкції.

`case` визначають ключовим словом `case`, після якого йде необовʼязковий вираз.
Далі для кожної гілки використовують ключове слово `when`, після якого йде вираз, що порівнюється з виразом `case`.
Ключове слово `when` не повинно мати відступу відносно ключового слова `case`.
Після ключового слова `when` іде код, який потрібно виконати, якщо вираз `case` збігається з виразом `when`.
`case` дозволяє необовʼязкову інструкцію `else`, яка виконується, якщо жодна інша гілка не збігається.

Вираз `case` обчислюється, а потім порівнюється з кожним виразом `when`.
Порівняння виконується за допомогою [оператора підпорядкування `case` (`===`)][case-subsumption].

```Crystal
case 1
when 1
  puts "One"
when 2
  puts "Two"
else
  puts "Other"
end
# => One

# This is the same as:
tmp = 1
if 1 === tmp
  puts "One"
elsif 2 === tmp
  puts "Two"
else
  puts "Other"
end
```

## Оператор підпорядкування `case` (`===`)

Оператор підпорядкування `case` (`===`) дещо відрізняється від оператора рівності (`==`).
Він перевіряє, чи права частина належить до множини, описаної лівою частиною.
Це означає, що порядок операндів має значення.
Як саме це працює, залежить від типу лівої частини: наприклад, `Range` перевірить, чи права частина входить у діапазон, а `Object` перевірить, чи права частина є екземпляром `Object`.

```Crystal
(1..3) == 1  # => false
(1..3) === 1 # => true

String == "foo"  # => false
String === "foo" # => true
```

## `case` з кількома виразами

`case` дає змогу зіставити кілька виразів в одній гілці, розділяючи кожне можливе значення комою.
Код виконається, якщо збігається будь-який із виразів.
Це буває корисно, коли в одній гілці може бути кілька можливих значень.

```Crystal
case 1
when 1, 2
  puts "One or two"
else
  puts "Other"
end
```

## `case` з діапазонами

`case` також може перевіряти, чи значення належить діапазону.
Для цього як вираз `when` використовують діапазон.

```Crystal
case var
when 1..3
  puts "One to three"
else
  puts "Other"
end
```

## `case` без виразу `case`

Коли вираз `case` не потрібен, його можна опустити.
Тоді кожен вираз `when` перевіряється на істинність.
Це робить конструкцію схожою на інструкції if-else-if.

```Crystal
case
when 1 == 1
  puts "One is equal to one"
when 1 > 2
  puts "One is greater than two"
else
  puts "Other"
end
```

## `when` в один рядок

Crystal дозволяє записувати `case` в один рядок.
Це можна використати, коли потрібна проста однорядкова інструкція.
Гілку `when` в один рядок записують як `when <expression> then <statement>.`
А в інструкції `else` це має такий вигляд: `else <statement>`.

```Crystal
case var
when 1 then puts "One"
when 2 then puts "Two"
else puts "Other"
end
```

## `case` з типами

`case` дає змогу зіставляти за типами.
Для порівняння використовується оператор `is_a?`, який перевіряє тип змінної.
Наприклад, це дає змогу мати окрему гілку для кожного типу в обʼєднаному типі.

```Crystal
case var
when Int32
  puts "Int32"
when String
  puts "String"
else
  puts "Other"
end
```

## Неявний обʼєкт

`case` дає змогу використовувати неявний обʼєкт.
Завдяки цьому вираз `when` може бути, наприклад, викликом методу на виразі `case`.
Залежно від того, чи повертає метод істинне значення, гілка збігається або ні.

```Crystal
case 1
when .odd?
  puts "Odd"
when .even?
  puts "Even"
end
```
