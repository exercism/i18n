# Вступ

Factor моделює дати й час за допомогою словника [`calendar`][calendar].
Момент часу - це `timestamp`, а проміжок часу - це `duration`.

## Створення дати

`<date>` (зі словника [`calendar`][calendar]) будує `timestamp`
опівночі заданого дня:

```
<date> ( year month day -- timestamp )
```

```factor
USING: calendar ;

1904 11 16 <date> .
! a timestamp at midnight on 1904-11-16
```

`>date<` розкладає timestamp назад на його частини:

```
>date< ( timestamp -- year month day )
```

```factor
1904 11 16 <date> >date< .   ! => 16   (with 1904 and 11 below it)
```

## Огляд дати

`day-of-week` повертає день тижня як ціле число: `0` для неділі аж до
`6` для суботи. `day-names` (зі словника [`calendar.english`][english]) -
це відповідний масив назв, тож `day-names nth` перетворює число на слово:

```factor
USING: calendar calendar.english sequences ;

2024 1 8 <date> day-of-week .          ! => 1
day-names .   ! { "Sunday" "Monday" ... "Saturday" } — Sunday first
```

`leap-year?` приймає рік (або timestamp), а `days-in-month` повертає
довжину місяця timestamp, уже враховуючи високосні роки:

```
leap-year?    ( obj -- ? )
days-in-month ( timestamp -- n )
```

```factor
2024 leap-year? .                ! => t
2024 2 1 <date> days-in-month .  ! => 29
```

## Арифметика дат

Слова як-от `days`, `weeks` і `hours` будують `duration`, а `time+`
зсуває timestamp на нього:

```
days  ( x -- duration )
time+ ( timestamp duration -- timestamp )
```

```factor
2024 2 28 <date> 1 days time+ >date< .
! => 29   (2024-02-29, with 2024 and 2 below it)
```

Арифметика коректно переносить через межі місяців і років, а два
timestamp, що позначають один і той самий момент, порівнюються як рівні
за допомогою `=`.

## Час доби

`<timestamp>` будує повний timestamp аж до секунди. Його останній
аргумент - це зсув від UTC; `instant` (нульовий `duration`) залишає
timestamp у UTC:

```
<timestamp> ( year month day hour minute second gmt-offset -- timestamp )
```

```factor
USING: calendar ;

1969 7 21 2 56 15 instant <timestamp> .
! a timestamp at 02:56:15 on 1969-07-21
```

`>time<` - це відповідник `>date<`, він розкладає timestamp на години,
хвилини і секунди:

```
>time< ( timestamp -- hour minute second )
```

```factor
1969 7 21 2 56 15 instant <timestamp> >time< .   ! => 15   (with 2 and 56 below it)
```

`seconds` і `minutes` будують `duration` так само, як `days`, `weeks`
і `hours`, тож будь-яке з них можна передати в `time+`:

```
seconds ( x -- duration )
minutes ( x -- duration )
```

Окремі поля timestamp читаються за допомогою аксесорів `year>>`,
`month>>`, `day>>`, `hour>>`, `minute>>` і `second>>`:

```factor
1969 7 21 2 56 15 instant <timestamp> hour>> .   ! => 2
```
