# Інструкції

У цій вправі ми будемо моделювати компʼютерну систему, засновану на вікнах.
Ми створимо кілька вікон, які можна переміщати та змінювати їхній розмір.
Наступне зображення показує значення, з якими ми працюватимемо нижче.

```text
 ╔════════════════════════════════════════════════════════════╗
 ║                                                            ║
 ║        position::$y,_                                      ║
 ║        position::$x  \                                     ║
 ║                       \<---- size::$width ---->            ║
 ║                 ^      *──────────────────────┐            ║
 ║                 |      │        title         │            ║
 ║                 |      ├──────────────────────┤            ║
 ║                 |      │                      │            ║
 ║          size::$height │                      │            ║
 ║                 |      │       contents       │            ║
 ║                 |      │                      │            ║
 ║                 |      │                      │            ║
 ║                 v      └──────────────────────┘            ║
 ║                                                            ║
 ║                                                            ║
 ╚════════════════════════════════════════════════════════════╝
```

## 1. Визначте властивості вікна програми

Використовуючи наданий каркас класу, визначте властивості для значень `y`, `x`, `height` та `width`.

```php
<?php

$window = new ProgramWindow();
$window->y; // => null
$window->x; // => null
$window->height; // => null
$window->width; // => null
```

## 2. Визначте початкові значення для вікна програми

Визначте конструктор для `ProgramWindow`.
Він не повинен приймати жодних аргументів, але під час виконання конструктора встановіть типові значення для його властивостей.
Він повинен встановити початкові значення `y` та `x` у `0`.
Він повинен встановити початкові `height` і `width` відповідно до розміру екрана `600x800`.

```php
<?php

$window = new ProgramWindow();
$window->y; // => 0 
$window->x; // => 0
$window->height; // => 600
$window->width; // => 800
```

## 3. Визначте функцію для зміни розміру вікна

Визначте новий клас у `Size.php` для класу Size.
Він повинен приймати аргументи конструктора, щоб встановити властивості `height` і `width`.
Крім того, `ProgramWindow` потребує функції зміни розміру, яка приймає екземпляр обʼєкта `Size` і оновлює власні властивості.

```php
<?php 

$window = new ProgramWindow();
$size = new Size(764, 1080);
$window->resize($size)

$window->height;
// => 764
$window->width;
// => 1080
```

## 4. Визначте функцію для переміщення вікна

Визначте новий клас у `Position.php` для класу Position.
Він повинен приймати аргументи конструктора, щоб встановити властивості `y` і `x`.
Крім того, `ProgramWindow` потребує функції переміщення, яка приймає екземпляр обʼєкта `Position` і оновлює власні властивості.

```php
<?php 

$window = new ProgramWindow();
$position = new Position(80, 313);
$window->move($position)

$window->y;
// => 80
$window->x;
// => 313
```
