# Доповнення до інструкцій

## Побітові оператори

У PHP є [побітові оператори](https://www.php.net/manual/en/language.operators.bitwise.php).

Наприклад, оператор «побітове І» (`&`) можна використати, щоб перевірити, чи визначено біт числа:

```php
$number = 89; // 0b01011001
$mask16 = 16; // 0b00010000
$mask32 = 32; // 0b00100000

$isMask16 = ($number & $mask16) > 0; // 0b00010000 > 0 => TRUE
$isMask32 = ($number & $mask32) > 0; // 0b00000000 > 0 => FALSE
```
