# Детальніше

У Haxe `class` - це основна структура даних, яка інкапсулює дані (поля) та поведінку (методи). Поля й методи також називають членами класу.

Доступ до членів класу можна обмежити за допомогою [модифікаторів доступу][visibility], а саме:

- `public`: член доступний звідусіль.
- `private`: член доступний лише в межах того самого класу.

Класи можна уявляти собі як шаблони для створення екземплярів. Для створення [екземпляра][class-instance] достатньо використати ключове слово `new`:

```haxe
class Car {
  public function new() {}
}

var myCar = new Car();
var yourCar = new Car();
```

Щоб визначити поле, використаймо модифікатор доступу, а далі назву та тип змінної:

```haxe
class Car {
  public var weight:Int; // Accessable by anyone

  private var color:String; // Accessable only within this class
}
```

Під час визначення поля також можна задати його початкове значення. Якщо для поля не вказано початкового значення, воно отримає значення `null`. Доступитися до поля можна через крапкову нотацію:

```haxe
class Car {
  public var weight:Int = 2500; // Weight will be set to 2500
  public var year:Int; // year will be null

  public function new() {}
}

var newCar = new Car();
newCar.weight; // 2500
newCar.year; // null

// Update value of field
newCar.year = 2020;
```
