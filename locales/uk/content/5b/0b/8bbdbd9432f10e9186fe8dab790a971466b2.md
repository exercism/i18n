# Інструкції

Новий аеропорт у Берліні найняв розробників для своєї лабораторії роботів, і ми починаємо там працювати.
У них є незграбні, трохи схожі на людей роботи, яких вони намагаються використати, щоб покращити обслуговування клієнтів.

Наше перше завдання на цій роботі - написати програму, щоб робот міг вітати людей їхньою рідною мовою після того, як вони відсканували свої паспорти на стійці самообслуговування.

Робот пишається своїми здібностями, тож він завжди спершу скаже, якою мовою вміє говорити, а потім привітає людину.
Наприклад, якщо хтось сканує німецький паспорт, робот скаже:

```txt
I can speak German: Hallo Dietrich!
```

## 1. Створити абстрактну функціональність привітання

Ми не будемо писати код для різних мов самостійно, тож треба структурувати код робота так, щоб інші розробники могли легко додавати нові мови згодом.

Як перший крок визначмо інтерфейс `Greeter` із двома методами.

- `LanguageName`, який повертає назву мови (`string`), якою робот має вітати відвідувача.
- `Greet`, який приймає імʼя відвідувача (`string`) і повертає `string` із привітанням конкретною мовою.

Далі реалізуймо функцію `SayHello`, яка приймає імʼя відвідувача та будь-що, що реалізує інтерфейс `Greeter`, як аргументи й повертає потрібний рядок із привітанням.
Наприклад, уявімо німецьку реалізацію `Greeter`, у якій `LanguageName` повертає `"German"`, а `Greet` повертає `"Hallo {name}!"`:

```go
SayHello("Dietrich", germanGreeter)
// => "I can speak German: Hallo Dietrich!"
```

## 2. Реалізувати італійську

Тепер наше завдання - зробити так, щоб робот працював для людей, які сканують італійські паспорти.

Для цього створімо структуру `Italian` і реалізуймо два методи, потрібні, щоб структура задовольняла інтерфейс `Greeter`, який ми створили в завданні 1.
Італійською можна привітатися так: `"Ciao {name}!"`.

## 3. Реалізувати португальську

Перш ніж закінчити на сьогодні, треба також допрацювати функціональність, щоб вітати людей португальською.

Для цього створімо структуру `Portuguese` і тут так само реалізуймо два методи, потрібні, щоб структура задовольняла інтерфейс `Greeter`.
Португальською можна привітатися так: `"Olá {name}!"`.
