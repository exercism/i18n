# Вступ

## Константи та функції

Константне значення визначаємо за допомогою `name = expression`,
де в Elm усе, крім визначень, є виразами.

```elm
five = 5

six = 3 + 3
```

Функції визначаємо за допомогою `name parameters... = expression`,
причому параметри розділяються лише пробілом.

```elm
add number1 number2 = number1 + number2
```

Виклик функції теж є виразом, і його виконуємо,
вказуючи її назву та передаючи аргументи для кожного параметра функції,
розділені пробілом, так само як і у визначенні функції.

```elm
five = add 2 3
```

За допомогою дужок можна задати порядок обчислення виразу.

```elm
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## Відступи / значущі пробіли

Elm не використовує синтаксичних маркерів, як-от фігурні дужки, круглі дужки чи крапки з комою, щоб задавати межі коду. Натомість він використовує пробіли та відступи.

- Визначення модуля, імпорту та функцій верхнього рівня мають починатися з найлівішої колонки.
- Якщо вираз розбито на кілька рядків, код, який є частиною цього виразу, потрібно відступити під цим виразом щонайменше на один пробіл.
- Частини виразу, які згруповано разом, потрібно відступити на однакову кількість пробілів.

```elm
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://elmprogramming.com/indentation.html

## Модулі

Кожен файл в Elm - це модуль, і він має містити інструкцію `module` перед усім іншим кодом.
Назви модулів мають збігатися з назвою їхнього файлу, тож модуль `Calculator` має бути у файлі Calculator.elm.
Усе, визначене в модулі, має приватну область видимості щодо нього
і не доступне ззовні цього модуля, якщо його не вказано в `exposing`.

```elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## Коментарі

Коментар - це текст у файлі Elm, який не інтерпретується як код.
Його призначено переважно для читання нами самими та іншими програмістами.
Для однорядкових коментарів є простий синтаксис на основі двох дефісів.
Багаторядкові коментарі також можливі за допомогою пари
відкривального та закривального роздільників `{-` і `-}`.

```elm
-- a single line comment
-- another single line comment

{- a multiline comment
   spawning multiple lines
-}
```
