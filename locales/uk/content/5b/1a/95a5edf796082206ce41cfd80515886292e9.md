# Вступ

Factor належить до *конкатенативних* мов: кожне слово читає свої вхідні дані зі спільного **стеку даних** і кладе свої вихідні дані назад на нього. Іншого способу передавати значення тут немає.

Запис літерала кладе його на верхівку стеку; код читається зліва направо:

```factor
1 2 3    ! stack (bottom → top): 1 2 3
```

Оголошення *стекового ефекту* описує контракт слова:

```factor
: restow ( a b -- b a ) swap ;
```

`( a b -- b a )` означає, що слово знімає зі стеку два значення і залишає на ньому два в протилежному порядку. Назви тут - лише документація: компілятор перевіряє тільки *кількість* вхідних і вихідних даних, а верхівці стеку відповідає назва, що стоїть праворуч.

Повсякденні **слова перемішування** з `kernel` переставляють верхівку стеку:

```
dup  ( x   -- x x   )
drop ( x   --       )
swap ( x y -- y x   )
over ( x y -- x y x )
nip  ( x y -- y     )
rot  ( x y z -- y z x )
```

Слова визначають за допомогою `:`, а завершують `;`; компілятор відхиляє визначення, тіло якого не відповідає оголошеному ефекту.
