# Доповнення до інструкцій

## Підказки

У цій вправі ми надали визначення [алгебраїчного типу даних](https://learnyouahaskell.github.io/making-our-own-types-and-typeclasses) під назвою `Planet`.
Реалізуйте функцію `ageOn`, яка обчислює, скільки років було б людині на `Planet`, якщо відомий вік у секундах.

Можна використати надану сигнатуру, якщо є сумніви щодо типів, але не дозвольте їй обмежувати творчість:

```haskell
ageOn :: Planet -> Float -> Float
```
