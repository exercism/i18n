# Вступ

PowerShell - це динамічна мова сценаріїв із неявною типізацією (_але також підтримує [строго типізовані][strong typed] змінні_) від Microsoft, зосереджена переважно на автоматизації завдань і керуванні конфігурацією.

PowerShell підтримує імперативне, функціональне, обʼєктно-орієнтоване та навіть конвеєрне програмування.

PowerShell побудовано на платформі .NET і вперше випущено 2006 року.
Він входить за замовчуванням до всіх сучасних версій Windows, а також його можна встановити на Mac і Linux.


## Змінні

У PowerShell є два поширені способи визначити змінну.

Назви змінних у PowerShell мають починатися з `$`, а для привʼязування назви змінної до значення використовують оператор присвоєння `=`.

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

Також можна вказати тип змінної явно, якщо потрібно, щоб значення було певного типу.
PowerShell докладе всіх зусиль, щоб за можливості перетворити значення з одного типу на інший.

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```


### Константи

Константи в PowerShell - це змінні, які після визначення не можна ні **змінити**, ні **видалити**.
Це приводить нас до другого способу визначення змінних: використання командлета `New-Variable`.

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
```

Щоб дізнатися про докладніші й складніші способи створення нової змінної, читайте [New-Variable][New-Variable].


## Функції

[Функції][functions] у PowerShell визначають за допомогою ключового слова `function`.
Кожна функція може мати нуль або більше формальних параметрів у дужках `()`, після чого йде область видимості функції, що починається з `{` і закінчується `}`.

```powershell
function Greeting {
    return "Hello!"
}
```

Функції в PowerShell можуть явно повертати значення за допомогою ключового слова `return`, після виклику за синтаксисом `FuncName $Arg`.

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

Докладніший огляд того, як писати детальне визначення функції та як функції можуть неявно повертати значення, буде розглянуто в модулі концепції `Functions`.


## Коментарі

Однорядкові коментарі в PowerShell починаються з `#` і закінчуються в кінці рядка.
Блоки коментарів у PowerShell починаються з `<#` і закінчуються `#>`.
Докладніший показ блоків коментарів для створення довідки на основі коментарів буде розглянуто в модулі концепції `Functions`.

```powershell
function Main() {
    #This is a comment
    <#
    And this is a comment block
    that can span multiple lines
    #>
}
```
