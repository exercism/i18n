# Підказки

## Загальне

- `unparse` міститься в [`prettyprint`][prettyprint]; варіанти зі зрізами - у [`sequences`][sequences]; сімейство cleave для кількох вхідних даних - у [`combinators`][combinators].

## 1. Взяти значення в лапки

- Одне слово: `unparse`.

## 2. Зняти обрамлення прапорця

- Приберіть початковий маркер за допомогою `1 tail-slice`, а потім приберіть кінцевий маркер за допомогою `1 head-slice*`.

## 3. Розділити прапорець

- І `head-slice`, і `tail-slice` потребують, щоб на стеку були прапорець *та* довжина заголовка. Це - `[ head-slice ] [ tail-slice ] 2bi`.

## 4. Тріангулювати за двома показами

- Три різні блоки коду, кожен з яких приймає ті самі два покази: `[ - ] [ + 2 / ] [ / ] 2tri`.

## 5. Підсумувати три покази

- Три блоки коду, по три вхідні дані в кожному: `3tri`. Блок для підсумовування - `[ + + ]`; для множення - `[ * * ]`; для максимуму - `[ max max ]`.
