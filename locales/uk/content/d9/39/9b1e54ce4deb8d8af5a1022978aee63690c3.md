# Про

## Включення

Щоб включити вміст інших файлів, C++ використовує директиву `include`.
Ці включення слід зазначати на початку файлу.
Під час компіляції рядок із директивою замінюється вмістом відповідного файлу.
Після включень простори імен залишаються такими, як у вихідному файлі.

## Стандартна бібліотека

Стандартна бібліотека пропонує багато загальновживаних функцій, алгоритмів і структур даних.
Стандартна бібліотека використовує простір імен `std`.

Прикладом є бібліотека числових обчислень C `cmath`.
Вона надає багато загальновживаних математичних операцій.

```cpp
#include <cmath>

int cube_me(int a) {
    // raise `a` to the third power
    return std::pow(a, 3);
}
```

~~~~exercism/note
Стандартні бібліотеки включаються за допомогою кутових дужок `<>`, а не подвійних лапок `"`.
Різниця полягає в місці, де компілятор шукає відповідні файли.
Для версії з кутовими дужками пошук у поточному проєкті пропускається, і він одразу починається в системних каталогах включення.
Якщо ми хочемо включити локальні файли, використовуємо подвійні лапки: `#include "myfile"`
~~~~
