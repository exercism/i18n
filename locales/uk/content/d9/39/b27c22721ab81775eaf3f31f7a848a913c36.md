- [Windows](#windows)
- [З вихідного коду](#source)

## macOS

Ця ОС постачається з Vim типово, але це безнадійно застаріла версія.

Імовірно, для встановлення програм ми використовуємо [MacPorts](https://www.macports.org) або
[Homebrew](https://brew.sh).

Homebrew:

```
$ brew update
$ brew install vim
```

MacPorts:

```
$ sudo port install vim +huge
```

Якщо потрібен графічний інтерфейс, замість нього погляньмо на [MacVim](https://macvim-dev.github.io/macvim).

## Ubuntu / Debian

Установіть повноцінний Vim із підтримкою графічного інтерфейсу (`gvim`):

```
$ sudo apt-get update
$ sudo apt-get install vim-gtk
```

## Windows

За допомогою [Chocolatey](https://chocolatey.org):

```
C:\> choco install vim
```

Або завантажте й установіть безпосередньо [звідси](http://www.vim.org/download.php#pc).
