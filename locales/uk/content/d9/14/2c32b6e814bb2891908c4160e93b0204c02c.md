# Інструкції

Уявімо, що ми досвідчені міксологи, які готують смачні напої, щоб люди могли насолоджуватися ними під час вечірок. Але ми зрозуміли, що можемо полегшити собі життя, написавши трохи коду, який допоможе нам у роботі.

## 1. Визначаємо, скільки часу потрібно на приготування замовлення

Різні напої потребують різного часу на приготування:

- `"beer"`, `"soda"` і `"water"` - по 0,5 хвилини.
- `"shot"` - 1,0 хвилини, `"mixed drink"` - 1,5 хвилини.
- `"fancy drink"` - 2,5 хвилини.
- `"frozen drink"` - 3,0 хвилини.

Реалізуйте функцію `timeToPrepare(drinks:)`, яка приймає аргумент `drinks` - масив рядків тексту (англ. string), що представляє напої, які потрібно приготувати.
Функція повинна повернути загальний час, потрібний для приготування всіх напоїв у масиві.

```swift
timeToPrepare(drinks: ["beer", "frozen drink", "shot"])
// returns 4.5
```

## 2. Поповнюємо запас часточок лайма

Одна з перших речей, які потрібно зробити на початку зміни, - переконатися, що невеличка скринька з часточками лайма повна на всю майбутню зміну.
Лайми бувають різних розмірів, і з них виходить різна кількість часточок: з лайма "small" виходить 6 часточок, з лайма "medium" - 8, а з лайма "large" - 10.

Поки нам ще потрібні часточки, а лайми ще не закінчилися, беремо перший лайм з масиву і віднімаємо відповідну кількість часточок від потрібної кількості.
Продовжуємо, доки не отримаємо всі потрібні часточки або доки не закінчаться лайми.

Реалізуйте функцію `makeWedges(needed:limes:)`, яка приймає аргументи `needed` (кількість часточок, які потрібно нарізати) і `limes` (масив рядків тексту з розмірами лаймів, які є в наявності для нарізання).
Функція повинна повернути кількість нарізаних лаймів.

```swift
makeWedges(needed: 25, limes: ["small", "small", "large", "medium", "small"])
// returns 4
```

## 3. Завершуємо зміну

Вітаємо! Довгий робочий день майже завершився, і скоро ми підемо додому працювати над своїм новим застосунком.
Але в нас ще залишилася низка замовлень на напої, які треба приготувати, перш ніж передати замовлення наступній зміні й піти.

Поки в зміні ще залишається час, готуємо перше замовлення з масиву, а тоді видаляємо це замовлення з масиву.
Потім віднімаємо від часу, що залишився в зміні, час, витрачений на приготування цього замовлення, згідно з нашою функцією `timeToPrepare(drinks:)`.

Реалізуйте функцію `finishShift(minutesLeft:remainingOrders:)`, яка приймає кількість хвилин, що залишилися в зміні (гарантовано більша за 0), і непорожній масив замовлень напоїв.
Функція повинна повернути масив замовлень, до яких ми не встигли взятися до кінця зміни.

```swift
finishShift(minutesLeft: 5, remainingOrders: [["beer", "frozen drink", "shot"], ["fancy drink", "soda"], ["beer", "beer", "water"], ["mixed drink", "frozen drink"]])
// returns [["beer", "beer", "water"], ["mixed drink", "frozen drink"]]
```

## 4. Відстежуємо окремі замовлення

Щоб beer і soda залишалися свіжими, потрібно відстежувати їхні замовлення разом із часом, коли ці замовлення зробили.

Реалізуйте функцію `orderTracker(orders: [(drink: String, time: String)]) -> (beer: (first: String, last: String, total: Int)?, soda: (first: String, last: String, total: Int)?)` яка, отримавши список замовлень і часів, повертає пару опціональних кортежів із часом першого й останнього замовлення beer і soda, а також загальною кількістю замовлень кожного з них, і `nil`, якщо замовлень цих напоїв не було. Інші напої відстежувати не потрібно.

Реалізуйте функцію `orderTracker(orders:)`, яка приймає масив кортежів, де кожен кортеж містить замовлений напій і час, коли зробили замовлення.
Функція повинна повернути кортеж, що містить час першого й останнього замовлення beer, загальну кількість замовлень beer, час першого й останнього замовлення soda та загальну кількість замовлень soda.
Повернути його потрібно у вигляді кортежу такого формату: `(beer: (first: String, last: String, total: Int)?, soda: (first: String, last: String, total: Int)?)`.

```swift
let orders = [
    (drink: "beer", time: "10:01"), (drink: "frozen drink", time: "10:02"),
    (drink: "shot", time: "10:05"), (drink: "fancy drink", time: "10:06"),
    (drink: "soda", time: "10:09"), (drink: "beer", time: "10:15"), (drink: "beer", time: "10:22"),
    (drink: "water", time: "10:26"), (drink: "mixed drink", time: "10:28"),
    (drink: "frozen drink", time: "10:33"),
]

orderTracker(orders: orders)

// returns (beer: (first "10:01", last "10:22", total 3), soda: (first "10:09", last "10:09", total 1))
```
