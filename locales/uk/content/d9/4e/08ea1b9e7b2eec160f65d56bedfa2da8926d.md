# Вступ

Вектор - це одновимірний масив.
Вони можуть містити елементи різних типів.

## Створення векторів

Вектори можна створювати за допомогою функції `vector` або за допомогою його синтаксичної форми `#()`

```lisp
(vector 1 t "foo" 'b) ; => #(1 T "foo" B)
#(2 nil "bar" a)      ; => #(2 NIL "bar" A)
```

Оскільки це масиви, їх також можна створювати за допомогою `make-array`:

```lisp
(make-array 3 :initial-element 'x)        ; => #(X X X)
(make-array 3 :initial-contents '(a b c)) ; => #(A B C)
```

## Предикат вектора

Щоб перевірити, чи є обʼєкт вектором, просто скористаймося предикатом `vectorp`.

## Доступ до елементів

Щоб отримати доступ до елементів вектора, скористаймося `aref`; індекси починаються з нуля:

```lisp
(aref #(1 2 3) 1) ; => 2
(aref #(a b c) 0) ; => A
```
