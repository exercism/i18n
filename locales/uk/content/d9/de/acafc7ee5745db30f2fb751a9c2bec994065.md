# Вступ

## Константи

У Gleam константи дають змогу давати значенням імена. Їх визначають за допомогою ключового слова `const`.

```gleam
pub const pi: Float = 3.14159

pub fn circle_area(radius: Float) -> Float {
  radius *. radius *. pi
}
```

Якщо константу визначено з ключовим словом `pub`, до неї можна звертатися з інших модулів, інакше вона доступна лише всередині модуля, де її визначено.

## Порядок

Модуль `gleam/order` зі стандартної бібліотеки Gleam містить тип `Order`, який використовують для порівняння значень.

Визначення `Order` має такий вигляд:

```gleam
pub type Order {
  Gt
  Eq
  Lt
}
```

Тип має три варіанти, і кожен із них описує відношення між одним значенням та іншим:

- `Gt` - значення _більше_ за інше значення.
- `Eq` - значення _дорівнює_ іншому значенню.
- `Lt` - значення _менше_ за інше значення.

Якщо тип даних можна порівнювати за величиною, зазвичай модуль визначає функцію `compare`, яка повертає значення `Order`. Наприклад, `gleam/float` і `gleam/int` визначають функції `compare`, які працюють відповідно з числами з плаваючою комою та цілими числами.

```gleam
int.compare(1, 2)
// -> Lt

int.compare(2, 2)
// -> Eq

float.compare(1.0, 2.0)
// -> Lt
```

Функції сортування, як-от `list.sort`, зазвичай приймають функцію, яка повертає значення `Order`, тож той, хто викликає, може визначити, як саме сортувати список.

```gleam
list.sort([3, 7, 3, 1], by: int.compare)
// -> [1, 3, 3, 7]
```
