# Вступ

У Go ми можемо перебирати `slice` за допомогою `for` та індексу, або ж скористатися `range`.
`range` також дає змогу перебирати `map`.

Кожна ітерація повертає два значення: індекс/ключ і копію елемента за цим індексом/ключем.

## Перебирання слайса

Простіше простого: цикл по слайсу перебирає елементи в очікуваному порядку.

```go
xi := []int{10, 20, 30}
for i, x := range xi {
  fmt.Println(i, x)
}
// outputs:
// 0, 10
// 1, 20
// 2, 30
```

## Перебирання мапи

Перебирання мапи ставить нову проблему.
Порядок тепер випадковий.

```go
hash := map[int]int{9: 10, 99: 20, 999: 30}
for k, v := range hash {
  fmt.Println(k, v)
}
// outputs, for example:
// 99 20
// 999 30
// 9 10
```

~~~~exercism/note
Може здатися, що наведений вище вивід неправильний, адже можна було б очікувати, що перша пара ключ-значення з оголошення мапи, `9 10`, буде надрукована першою, а не останньою.
Однак мапи за своєю природою невпорядковані: у них немає першої чи останньої пари ключ-значення.
Через це, коли ми перебираємо елементи мапи, порядок, у якому їх буде відвідано, буде випадковим і не підпорядковується жодній закономірності.
Це означає, що наведений вивід можливий, але може відрізнятися від того, що ми побачимо, якщо спробуємо запустити це самостійно.
Щоб дізнатися більше, дивіться [Специфікація мови Go: конструкція range](https://go.dev/ref/spec#RangeClause).
~~~~

## Ітерація з пропущеним ключем або значенням

У Go невикористана змінна спричиняє помилку під час збірки.
Іноді потрібне лише значення, як у першому прикладі:

```go
xi := []int{10, 20, 30}
for i, x := range xi {
  fmt.Println(x)
}
// Go build failed: i declared but not used
```

Ми можемо замінити `i` на `_`, що вказує компілятору: це значення ми не використовуємо:

```go
xi := []int{10, 20, 30}
for _, x := range xi {
  fmt.Println(x)
}
// outputs:
// 10
// 20
// 30
```

Якщо потрібно надрукувати лише індекс, можна замінити `x` на `_`
або просто пропустити оголошення:

```go
xi := []int{10, 20, 30}
// for i, _ := range xi {
for i := range xi {
  fmt.Println(i)
}
// outputs:
// 0
// 1
// 2
```

## Неструктурні типи

Раніше ми вже бачили, як визначати типи-структури.
Також можна визначати неструктурні типи, які слугують псевдонімом для оголошення вбудованого типу, і додавати до них функції з отримувачем, щоб розширювати їх так само, як і типи-структури.

```go
type Name string
func SayHello(n Name) {
  fmt.Printf("Hello %s\n", n)
}
n := Name("Fred")
SayHello(n)
// Output: Hello Fred
```

Також можна визначати неструктурні типи, складені з масивів і мап.

```go
type Names []string
func SayHello(n Names) {
  for _, name := range n {
    fmt.Printf("Hello %s\n", name)
  }
}
n := Names([]string{"Fred", "Bill"})
SayHello(n)
// Output:
// Hello Fred
// Hello Bill
```
