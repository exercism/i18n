# Вступ до узагальнених типів

**Узагальнений тип** - це узагальнений клас або інтерфейс, параметризований типами.
Це дає компілятору змогу стежити за безпекою типів у класі чи інтерфейсі.

Розгляньмо цей неузагальнений інтерфейс `Container`:

```java
class Container {
    private Object object;

    public void set(Object object) { this.object = object; }
    public Object get() { return object; }
}
```

Оскільки він приймає та повертає обʼєкти, він працює з будь-яким непримітивним типом.
Однак за це доводиться платити: якась частина коду може викликати `get`, розраховуючи на `Integer`, тоді як інша викликає `set` і додає `String`, і все це закінчується помилкою часу виконання.

**Узагальнений клас** і **узагальнений інтерфейс** мають такий вигляд:

```java
class ClassName<T1, T2, ..., Tn> { ... }
interface InterfaceName<T1, T2, ..., Tn> { ... }
```

Секція параметрів типу, обмежена кутовими дужками (`<>`), яка йде після назви класу чи інтерфейсу, задає параметри типу (їх також називають змінними типу) `T1`, `T2`, ..., і `Tn`.
Їх можна використовувати всередині тіла класу чи інтерфейсу, щоб отримати безпеку типів.

Ось узагальнена версія `Container`:

```java
class Container<E> {
    private E object;

    public void set(E object) { this.object = object; }
    public E get() { return object; }
}
```

Тепер під час створення потрібно вказати, значення якого типу він зберігає, і компілятор стежитиме за дотриманням цього обмеження:

```java
// empty <> can infer from context
Container<String> stringContainer = new Container<>();
// compiler knows this is a String, so it is allowed
stringContainer.set("Some string");
// no cast needed, compiler knows it is a String
String result = stringContainer.get();
// this causes a compiler error:
stringContainer.set(42);
```
