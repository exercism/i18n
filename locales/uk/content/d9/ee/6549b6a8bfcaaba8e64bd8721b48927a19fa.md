# Вступ до умовних конструкцій

## Правдивість у Bash

У Bash немає поняття булевих значень (англ. Boolean).
Є рядки тексту (англ. string) і числа, а також масиви рядків тексту чи чисел.
Тож як умовні команди розрізняють правду та неправду?

## Статус завершення

Команди після завершення роботи повертають _статус завершення_.
Статус завершення - це ціле число від 0 до 255 включно.
Bash вважає статус завершення **нуль** ознакою _успіху_.
Будь-який інший статус завершення означає _невдачу_.

Це стосується всіх команд, зокрема вбудованих команд Bash, ключових слів і функцій.

## Команда «if»

Базовий синтаксис команди `if` такий:

```bash
if CONDITIONAL_COMMANDS; then TRUE_COMMANDS; else FALSE_COMMANDS; fi
```

Вона починається з `if`; умовні команди відокремлюються від команд «успіху» словом `then`; а завершується вона словом `fi`.
Вітка `else` необовʼязкова.

Умовні команди можуть бути однією командою або [списком команд][command-list].

Умовні команди виконуються, і

* якщо статус завершення нульовий (успіх), виконуються команди успіху.
* якщо статус завершення ненульовий (невдача), виконуються команди невдачі, якщо вони є.

Каскадні вітки можна задати за допомогою `elif`
```bash
if CONDITIONAL_COMMANDS
then TRUE_COMMANDS
elif CONDITIONAL_COMMANDS_2
then TRUE_COMMANDS_2
# more elif branches ...
else FALSE_COMMANDS
fi
```

Перед словами `then`, `elif`, `else` і `fi` має бути крапка з комою або символ нового рядка.

Наголосимо ще раз: саме **статус завершення** умовних команд керує ходом виконання.
Наприклад, `grep` повертає 0, якщо збіг знайдено, і 1, якщо збігу немає.
Опція `-q` пригнічує виведення, залишаючи лише статус завершення.

```bash
if grep -q "my pattern" my_file; then echo "the pattern is found in the file"; fi
```

## Команди «[» і «test»

Навколо умовних команд немає жодного спеціального синтаксису.
Ми звикли бачити умовні конструкції такого вигляду:

```if
if [ "$password" = "secure" ]; then
    echo "Welcome!"
fi
```

`[` не є спеціальним синтаксисом.
Це _команда_, яка обчислює умовний вираз і завершується зі статусом успіху або невдачі.
Як і в усіх команд, між нею та її аргументами **обовʼязковий** пробіл.

Насправді `[` є синонімом команди `test`.
Вони абсолютно однакові, хіба що останній аргумент `[` _мусить_ бути `]`.

### Умовні вирази

Усередині `[` і `]` ми записуємо умовний вираз.
Ось кілька типових умовних виразів:

```bash
[ -f "$filename" ]             # file operations
[ "$string1" = "$string2" ]    # string comparisons
[ "$num1" -eq "$num2" ]        # arithmetic comparisons
```

Доступних операцій набагато більше; вони перелічені в розділі [Bash Conditional Expressions][cond-expr] довідника.

~~~~exercism/note
У наведених вище прикладах звернімо увагу, що всі змінні взято в лапки.
Команди `test` і `[` є звичайними командами, у яких аргументи, як і в будь-якій іншій команді, підлягають розбиттю на слова та розгортанню імен файлів.

Про це важливо сказати, бо умовні вирази обчислюються по-різному залежно від того, _скільки аргументів_ ми передаємо:

* 0 аргументів: статус завершення ненульовий (невдача)
* 1 аргумент: статус завершення нульовий (успіх), якщо аргумент не порожній, і ненульовий, якщо він порожній.
* 2 аргументи: перший аргумент має бути унарним оператором (наприклад, `[ -z "$name" ]`) або `!` (заперечує статус перевірки з одним аргументом)
* і [більше випадків][test].

Можна отримати несподівані результати, якщо забути взяти змінну в лапки:

```bash
str=""

# this prints "empty"
if [ -n "$str" ]; then echo "not empty"; else echo "empty"; fi

# leaving the variable unquoted results in incorrect "not empty" output
if [ -n $str ]; then echo "not empty"; else echo "empty"; fi
```

[test]: https://www.gnu.org/software/bash/manual/bash.html#index-test
~~~~

## Ключове слово «[[»

Умовна конструкція [`[[...]]`][cond-construct] - це не _команда_, а **ключове слово**.
Це означає, що хоча з нею поводяться як із будь-якою іншою командою, для неї діють особливі правила розбору.
Особливість `[[` у тому, що змінні, розгорнуті всередині неї, **не** підлягають розбиттю на слова чи розгортанню імен файлів.
Тобто ця команда поводиться так, як ми й очікуємо, навіть без лапок.

```bash
if [[ -n $str ]]; then echo "not empty"; else echo "empty"; fi
```

`[[` підтримує всі умовні вирази, з якими вміють працювати `test` і `[`.
Крім того, `[[` надає

* оператор зіставлення з регулярним виразом `=~`,
* `==` і `!=` працюють як оператори зіставлення зі шаблоном,
* `&&` (логічне і) та `||` (логічне або) як логічні оператори (особливе правило розбору),
* `<` і `>` як «голі» оператори порівняння рядків тексту (особливе правило розбору: оскільки це символи перенаправлення, у `[` їх треба екранувати).

Широко вважається, що ці особливі можливості дають настільки велику перевагу, що `[[` варто використовувати завжди.
(Наприклад, [Google Shell Style Guide][goog-test].)

## Команда «case»

[`case`][case] - це ще одна команда керування ходом виконання.
Вона схожа на «switch» в інших мовах.

```bash
case WORD in [PATTERN [| PATTERN]...) COMMANDS ;;]... esac
```

Слово зіставляється з кожним шаблоном.
Коли один збігається, виконуються команди.

```bash
read -p "Guess the secret word: " word
case "$word" in
    secret) echo "Yes, you guessed it!" ;;
    ??????) echo "That's the right number of letters." ;;
    s*)     echo "You guessed the first letter." ;;
    *)      echo "Not even close! Try again." ;;
esac
```

Кожна група команд має завершуватися **двома** крапками з комою, `;;`.
