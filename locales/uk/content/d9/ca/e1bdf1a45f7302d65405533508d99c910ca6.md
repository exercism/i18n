# Вступ

*Узагальнене слово* оголошує операцію, яка може мати різні реалізації залежно від класу свого аргументу. Методи додаються за допомогою `M:`.

```factor
USING: kernel math ;

GENERIC: area ( shape -- n )

TUPLE: square side ;
TUPLE: circle radius ;

M: square area side>> dup * ;
M: circle area radius>> dup * 3.14159 * ;
```

```factor
T{ square { side 4 } } area .    ! => 16
T{ circle { radius 2 } } area .  ! => 12.56636
```

`GENERIC:` оголошує слово та його стековий ефект. `M:` визначає метод для конкретного класу; під час виконання Factor виконує диспетчеризацію за класом аргументу на вершині стека.

Можна запитати в узагальненого слова, для яких класів у нього є методи, і додавати або вилучати методи після оголошення. Немає спеціального синтаксису успадкування: для будь-якого класу кортежу автоматично можна визначати методи.
