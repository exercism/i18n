# Інструкції

Порахуйте прямокутники на ASCII-діаграмі, як на наведеній нижче.

```text
   +--+
  ++  |
+-++--+
|  |  |
+--+--+
```

Наведена вище діаграма містить такі 6 прямокутників:

```text


+-----+
|     |
+-----+
```

```text
   +--+
   |  |
   |  |
   |  |
   +--+
```

```text
   +--+
   |  |
   +--+


```

```text


   +--+
   |  |
   +--+
```

```text


+--+
|  |
+--+
```

```text

  ++
  ++


```

Можна припустити, що вхідні дані завжди утворюють правильний прямокутник (тобто довжина кожного рядка дорівнює довжині першого рядка).
