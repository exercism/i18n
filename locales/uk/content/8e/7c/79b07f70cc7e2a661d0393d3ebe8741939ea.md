# Вступ

Haxe - суворо типізована мова, але систему типізації за потреби можна обійти. Присвоєння значення імені називають визначенням змінної. Змінну можна визначити або явно вказавши її тип, або дозволивши компілятору Haxe вивести тип. Отже, наступні два визначення змінних рівнозначні:

```haxe
var explicitVariable:Int = 10; // Explicitly typed
var implicitVariable = 10; // Implicit typed
```

Оновити змінну можна за допомогою оператора `=`:

```haxe
var number = 0; // Initial value
number = 1; // Updated value
```

Компілятор видасть помилку, якщо ми спробуємо присвоїти значення, тип якого відрізняється від типу змінної:

```haxe
var number = 1; // Variable number is of integer type
number = "Hello" // Error trying to assign a string to an integer variable
```

Функція, що знаходиться всередині класу, називається _методом_. Методи можуть мати нуль або більше параметрів. Усі параметри повинні мати явно вказаний тип. Як і параметри, тип поверненого значення методу не можна вивести, його потрібно вказати явно. Значення повертаються з методів за допомогою ключового слова `return`:

```haxe
function add(x:Int, y:Int):Int {
  return x + y;
}
```

Щоб викликати метод, потрібно вказати його клас і назву методу та передати аргументи:

```haxe
var sum = add(1, 2) // sum = 3
```

Область видимості в Haxe визначається між символами `{` і `}`.

Haxe підтримує два типи коментарів. Однорядкові починаються з `//`, а багаторядкові розміщують між `/*` і `*/`.
