# Тести

## Clojure CLI

Вправи з Clojure на Exercism постачаються з файлом `deps.edn`, який містить аліас `:test` для запуску [cognitect-labs test-runner](https://github.com/cognitect-labs/test-runner):

``` bash
$ clj -X:test
```

## Leiningen

Leiningen також можна використати, щоб запустити тести вправи. Для цього виконайте таку команду з каталогу вправи:

```bash
lein test
```

## REPL

Щоб скористатися REPL для запуску тестів вправи, виконайте таку команду з каталогу вправи:

```bash
$ clj
```

-або-

```bash
$ lein repl
```

Потім викличте `require` для простору імен тестів вправи та простору імен тестів Clojure):

```clojure
;; replace <exercise> with the exercise's name
=> (require '<exercise>-test)
```

Потім викличте `run-tests` для `<exercise>-test`:

```clojure
;; replace <exercise> with the exercise's name
=> (clojure.test/run-tests '<exercise>-test)
```
