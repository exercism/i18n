# Перевантаження операторів

Перевантаження операторів - це можливість, яку мають деякі мови програмування: вона дозволяє перевизначити стандартні оператори, як-от додавання (`+`), віднімання (`-`), множення (`*`) і ділення (`/`), щоб вони працювали з типами, визначеними користувачем.

Це може зробити синтаксис коду зрозумілішим, адже операції над типами, визначеними користувачем, можна записувати так само, як операції над примітивними типами.

У Cairo перевантаження операторів досягається через реалізацію певних трейтів.

Кожен оператор має повʼязаний трейт, і перевантаження цього оператора передбачає надання реалізації цього трейта для власного типу.
Однак перевантаження операторів варто застосовувати виважено.

Неправильне використання може призвести до плутанини й зробити код складнішим для підтримки, наприклад, коли перевантажений оператор не має семантичного сенсу.

Розглянемо приклад, у якому потрібно поєднати дві `Potions`.

`Potions` мають два поля даних: ману та здоровʼя.

Поєднання двох `Potions` має додавати їхні відповідні поля.

```rust
struct Potion {
    health: felt252,
    mana: felt252,
}

impl PotionAdd of Add<Potion> {
    fn add(lhs: Potion, rhs: Potion) -> Potion {
        Potion { health: lhs.health + rhs.health, mana: lhs.mana + rhs.mana }
    }
}

fn main() {
    let health_potion: Potion = Potion { health: 100, mana: 0 };
    let mana_potion: Potion = Potion { health: 0, mana: 100 };
    let super_potion: Potion = health_potion + mana_potion;
    // Both potions were combined with the `+` operator.
    assert(super_potion.health == 100, '');
    assert(super_potion.mana == 100, '');
}
```

У наведеному коді ми реалізуємо трейт `Add` для типу `Potion`.

Функція `add` приймає два аргументи: `lhs` і `rhs` (ліва та права сторона).

Тіло функції повертає новий примірник `Potion`, значення полів якого поєднують `lhs` і `rhs`.

Як показано в прикладі, перевантаження оператора вимагає зазначити конкретний тип, для якого виконується перевантаження.

Перевантажений узагальнений трейт - це `Add<T>`, і ми визначаємо конкретну реалізацію для типу `Potion` за допомогою `Add<Potion>`.
