# Підказки

## Загальне

- Прочитайте про списки ключових слів в офіційному [посібнику з початку роботи][getting-started-keyword-lists].
- Прочитайте про списки ключових слів на [elixirschool.com][elixir-school-keyword-lists].
- Погляньте в [документацію модуля `Keyword`][keyword].

## 1. Поясніть кольори вина

- Інформацію з таблиці потрібно записати як список ключових слів.
- Погляньте на [приклади][keyword-examples] того, як визначати список ключових слів.

## 2. Отримайте всі вина заданого кольору

- Є [вбудована функція][keyword-get-values] для отримання списку всіх значень для заданого ключа.

## 3. Отримайте всі вина заданого кольору, розлиті в заданому році

- Є [вбудована функція][keyword-get] для отримання одного значення для заданого ключа.
- Фільтрування пляшок не потрібно реалізовувати самостійно. Достатньо умовно використати вже реалізовану функцію `filter_by_year/2`.

## 4. Отримайте всі вина заданого кольору, розлиті в заданій країні

- Є [вбудована функція][keyword-get] для отримання одного значення для заданого ключа.
- Фільтрування пляшок не потрібно реалізовувати самостійно. Достатньо умовно використати вже реалізовану функцію `filter_by_country/2`.
