# Вступ

У Swift є набір інструкцій, які дозволяють змінювати звичайний хід виконання циклів. Їх називають інструкціями передачі керування. Ми вже бачили `return`; у цьому концепті ми познайомимося з іншими, серед яких `continue`, `break` і мітки.

## Continue

Іноді потрібно достроково перейти до наступної ітерації циклу, не виконуючи решту інструкцій у поточній ітерації. Для цього можна використати ключове слово `continue`. Коли `continue` виконується, цикл переходить до наступної перевірки, чи можна запустити наступну ітерацію, тобто до `while` у циклах `while` і `repeat-while` або до перевірки, чи є в послідовності ще один елемент у циклах `for-in`.

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

## Break

Ключове слово `break` використовують, щоб достроково вийти з циклу. Коли `break` виконується, цикл негайно завершується, і програма продовжує з першої інструкції після циклу.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

## Мітки

Коли цикли вкладені, іноді виникає потреба використати `break` або `continue`, щоб вийти із зовнішніх циклів, які містять цикл, де застосовано `break` чи `continue`, або перезапустити їх. У таких випадках можна використати мітки, щоб указати цикл, з якого потрібно вийти або який потрібно перезапустити. Щоб позначити цикл міткою, поставимо імʼя та двокрапку перед `while`, `repeat` або `for`, які починають цикл.

Щоб побачити ефект від такого використання міток, розгляньмо такий цикл.

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```

## Fallthrough

Ключове слово `fallthrough` використовують, щоб перейти до наступного випадку в конструкції `switch`. Це означає, що код у наступному випадку виконається без перевірки його умов. Завдяки цьому конструкція `switch` поводитиметься так, як в інших мовах програмування, де після збігу випадку не потрібна інструкція `break`, щоб вийти з `switch`. Докладніше про `fallthrough` можна прочитати в [книзі про Swift][fallthrough].

```swift
let value = 1
switch value {
case 1:
  print("One")
  fallthrough
case 2:
  print("Two")
}

// prints:
// One
// Two
```
