# Інструкції

У цій вправі ми писатимемо код, який допоможе фрилансеру спілкуватися з клієнтами щодо цін на окремі проєкти.
Ми напишемо кілька допоміжних методів, щоб швидко обчислювати вартість для клієнтів.

```exercism/note
Параметр `rate_per_hour` і метод `day_rate` стосуються грошей.
Одиниці вимірювання - це гроші за одиницю часу: відповідно за години й за дні.
```

## 1. Обчислити денну ставку за погодинною ставкою

Клієнт звертається до фрилансера, щоб дізнатися про його ставки.
Фрилансер пояснює, що **_працює 8 годин на день._**
Однак фрилансер знає лише свою погодинну ставку для цього проєкту.
Допоможімо оцінити денну ставку за відомою погодинною ставкою.

```abap
DATA(freelancer_rates) = NEW zcl_freelancer_rates( ).

freelancer_rates->day_rate( 89 ).
// => 712
```

Денну ставку не потрібно округлювати чи приводити до «фіксованої» точності.

## 2. Обчислити кількість робочих днів за фіксованого бюджету

Наступного дня менеджер проєкту пропонує фрилансеру попрацювати над проєктом із фіксованим бюджетом.
Маючи фіксований бюджет і погодинну ставку фрилансера, допоможімо обчислити, скільки днів він працюватиме, доки бюджет не вичерпається.
Результат _обовʼязково_ потрібно **округлити в менший бік** до найближчого цілого числа.

```abap
freelancer_rates->days_in_budget(
  budget        = 20000
  rate_per_hour = 89 ).
// => 28
```

## 3. Обчислити ставку зі знижкою для великих проєктів

Часто клієнти фрилансера наймають його на проєкти, що тривають кілька місяців.
У таких випадках фрилансер вирішує давати знижку за кожен повний місяць, а решту днів оплачують за денною ставкою.
Чудовий баланс між роботою та життям означає, що ми працюємо лише 22 дні кожного календарного місяця, тож **_у кожному місяці 22 оплачувані дні._**
Допоможімо оцінити вартість таких проєктів, маючи погодинну ставку, кількість оплачуваних днів у проєкті та місячну ставку знижки.
Знижку завжди передають як число, де `42%` стає `0.42`. Результат _обовʼязково_ потрібно **округлити в більший бік** до найближчого цілого числа.

```abap
freelancer_rates->price_with_monthly_discount(
  rate_per_hour = 89
  num_days      = 230
  discount      = '0.42' ).
// => 97972
```
