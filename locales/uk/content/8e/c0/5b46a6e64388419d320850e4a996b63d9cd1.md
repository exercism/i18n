# Додаток до інструкцій

## Реалізація

Імена роботів можуть закінчитися. Коли всі можливі імена роботів уже розподілено, потрібно повернути помилку.

## Бонусний тест

Коли `go test` почне проходити, ми побачимо, що в наборі тестів є тест із назвою `TestCollisions`, який типово пропущено, бо він може виконуватися довго.
Цей тест створює нових роботів, доки не залишиться нових імен, які можна присвоїти роботу.

Щоб тест запустився, видаліть цей рядок:

```go
t.Skip("skipping test as it can take a long time to run if solution is sub-optimal.")
```

Щоб цей тест пройшов, потрібно подбати про те, щоб імʼя робота раніше не використовувалося, і про те, щоб імена розподілялися ефективно.
