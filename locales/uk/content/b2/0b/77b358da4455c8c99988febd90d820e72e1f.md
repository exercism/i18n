# Докладніше

У Java [літерал `null`][null-keyword] використовують, щоб позначити відсутність значення.

[Примітивні типи даних][primitive-data-types] у Java мають типове значення, а тому ніколи не можуть бути `null`.
За домовленістю їхні назви починаються з малої літери, наприклад `int`.

[Посилальні типи][reference-data-types] містять адресу обʼєкта в памʼяті й можуть мати значення `null`.
Зазвичай їхні назви починаються з великої літери, наприклад `String`.

Спроба присвоїти примітивній змінній значення `null` призведе до помилки часу компіляції, адже така змінна завжди зберігає типове значення присвоєного типу.

```java
// Throws compile time error stating the required type is int, but null was provided
int number = null;
```

Присвоєння посилальній змінній значення `null` не призведе до помилки часу компіляції, оскільки посилальні змінні допускають значення `null`.

```java
//No error will occur as the String variable str is nullable
String str = null;
```

Хоча звернення до посилальної змінної зі значенням `null` успішно скомпілюється, під час виконання це призведе до викидання `NullPointerException`.

```java
int[] arr = null;

// Throws NullPointerException at runtime
arr.length;
```

[`NullPointerException` викидається][null-pointer-exception], коли ми намагаємося звернутися до посилальної змінної, яка має значення `null`, але потребує обʼєкта.

Щоб безпечно працювати зі значеннями, які можуть бути `null`, слід перевіряти їх на `null` перед використанням. Це можна зробити за допомогою [операторів рівності][equality-operators], таких як `==` або `!=`:

```java
int[] arr = null;

if(arr != null) {
    System.out.println(arr.length);
} else {
    //Perform an alternate action when arr is null
}
```
