# Вступ

## Твердження `let assert`

Коли ми зіставляємо значення зі зразком у Gleam, треба подбати, щоб зразки охоплювали всі можливі значення цього типу, інакше код не скомпілюється.

Цю функцію буде відхилено, бо вона не обробила випадок, коли список порожній:

```gleam
pub fn get_first_element_or_crash(items: List(e)) -> e {
  case items {
    [item, ..] -> item
  }
}
```

Здебільшого в програмах на Gleam ми хочемо обробити всі можливі випадки, але в деяких програмах, як-от прототипах чи швидких скриптах, нам може захотітися зосередитися лише на щасливому шляху та не писати код для решти випадків. Саме тут стає в пригоді `let assert` із Gleam.

Із твердженнями `let assert` зразок може збігатися лише з частиною можливих значень типу, і якщо зразок не збігається зі значенням, програма аварійно завершиться. Використавши `let assert`, ми можемо записати наведену вище функцію так:

```gleam
pub fn get_first_element_or_crash(items: List(e)) -> e {
  let assert [item, ..] = items
  item
}
```

Бібліотеки Gleam ніколи не повинні використовувати твердження `let assert`, бо вони можуть призвести до аварійного завершення програми. Натомість їм варто використовувати тип `Result` і дозволити розробникові застосунку самому вирішити, як обробляти помилки.
