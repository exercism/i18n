# Докладніше

У Swift не можна індексувати рядок тексту (англ. string) цілим числом (наприклад, `string[3]`).
Оскільки рядки тексту в Swift складаються з символів Unicode змінної довжини, щоб дістатися до потрібного символу, потрібно перебрати всі попередні символи.

Щоб отримати символ у конкретній позиції, потрібно обчислити індекс типу `String.Index`.
Ці індекси називають *непрозорими індексами*, бо їхньою внутрішньою структурою керує Swift, і з ними не працюють безпосередньо як із простими цілими числами:

```swift
let csv = "apple,pear,peach,orange,cherry,lime,gooseberry"
let index = csv.index(csv.startIndex, offsetBy: 21)
print(csv[index])
// Prints "g"

print(index)
// Prints internal representation: Index(_rawBits: ...)
```
