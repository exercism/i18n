# Інструкції


Уявімо, що ми працюємо метрдотелем ресторану в готелі.
Наше завдання - керувати розсаджуванням у залі відповідно до кількості місць, доступних сьогодні, кількості бронювань і гостей, які «зайшли з вулиці» й зараз чекають, щоб їх посадили.
У цій вправі місця розподіляють за першим доступним порожнім місцем.


У цій вправі нам потрібно виконати 6 різних завдань з організації зали.


## 1. Створюємо схему розсаджування на сьогодні

Визначте функцію `new_seating_chart(<size=22>)`, яка приймає аргумент size, що означає кількість місць, які сьогодні розставлять у залі.
Якщо `size` не вказано, функція повинна повернути схему розсаджування на 22 місця.
Значення місць мають містити заповнювач `None`, щоб позначити, що їх можна призначити гостю.


## 2. Розподіляємо бронювання

Визначте функцію `arrange_reservations(<guest_names>)` з одним параметром: списком імен гостей.
Він означає кількість людей, які сьогодні мають заброньовані місця в залі.


Ця функція повинна повернути `dict` зі схемою розсаджування типового розміру (22 місця), де гостей призначено на місця в тому порядку, у якому вони йдуть у списку бронювань.
Усім непризначеним місцям слід надати значення `None`.
Якщо гостей немає, потрібно повернути «порожню» схему розсаджування, де всі заповнювачі - `None`.


```python
>>> arrange_reservations(guests=["Walter", "Frank", "Jenny", "Carol", "Alice", "George"])
...
{1: 'Walter', 2: 'Frank', 3: 'Jenny', 4: 'Carol', 5: 'Alice', 6: 'George', 7: None, 8: None, 9: None, 10: None, 11: None, 12: None, 13: None, 14: None, 15: None, 16: None, 17: None, 18: None, 19: None, 20: None, 21: None, 22: None}
```


## 3. Знаходимо всі «порожні» місця

Визначте функцію `find_all_available_seats(<seats>)`, яка приймає один параметр (_словник зі схемою розсаджування_) і повертає `list` з номерами місць, доступних для гостей, які зараз чекають.
Якщо місце порожнє, у словнику воно матиме значення `None`. Зайняті місця міститимуть імʼя гостя.


```python
>>> seats = {1: None, 2: 'Frank', 3: 'Jenny', 4: None, 5: 'Alice', 6: 'George', 7: None, 8: 'Carol', 9: None, 10: None, 11: None, 12: 'Walter'}

>>> find_all_available_seats(seats)
[1,4,7,9,10,11]
```

## 4. Поточна кількість порожніх місць

Визначте функцію `current_empty_seat_capacity(<seats>)`, яка приймає один параметр: `dict` з наявними бронюваннями місць.
Функція повинна повернути загальну кількість порожніх місць.

```python
>>> curr_empty_seat_capacity({1: "Occupied", 2: None, 3: "Occupied"})
1

>>> curr_empty_seat_capacity({1: "Occupied", 2: None, 3: None})
2
```


## 5. Чи варто чекати?

Визначте функцію `accommodate_waiting_guests(<seats>, <guests>)`, яка приймає два параметри.
Першим параметром буде `dict` зі схемою розсаджування.
Другим параметром буде `list` гостей, які несподівано «зайшли з вулиці».
Спершу потрібно зʼясувати, скільки місць доступно і чи взагалі можна зараз посадити незапланованих гостей.

Якщо місць не вистачає, поверніть `dict` зі схемою розсаджування без змін.

Якщо місця _таки_ є, призначте гостей на місця у схемі розсаджування й поверніть її оновленою.
**Порада:** можна скористатися раніше визначеними функціями, щоб виконати обчислення.


```python
# Guests cannot be accommodated.
>>> starting_reservations = {1: 'Carol', 2: 'Alice', 3: 'George', 4: None, 5: None, 6: None, 7: 'Frank', 8: 'Walter'}
>>> accommodate_guests(starting_reservations, ["Mort", "Suze", "Phillip", "Tony"])
...
{1: 'Carol', 2: 'Alice', 3: 'George', 4: None, 5: None, 6: None, 7: 'Frank', 8: 'Walter'}


# Guests can be accommodated.
>>> starting_reservations = {1: None, 2: None, 3: None, 4: 'Carol', 5: 'Alice', 6: 'George', 7: None, 8: None, 9: None, 10: None, 11: None, 12: None, 13: None, 14: None, 15: None, 16: None, 17: None, 18: 'Frank', 19:  'Jenny', 20: None, 21: None, 22: 'Walter'}
>>> accommodate_guests(starting_reservations, ["Mort", "Suze", "Phillip", "Tony"])
...
{1: 'Mort', 2: 'Suze', 3: 'Phillip', 4: 'Carol', 5: 'Alice', 6: 'George', 7: 'Tony', 8: None, 9: None, 10: None, 11: None, 12: None, 13: None, 14: None, 15: None, 16: None, 17: None, 18: 'Frank', 19: 'Jenny', 20: None, 21: None, 22: 'Walter'}
```

## 6. Порожні місця

Визначте функцію `empty_seats(<seats>, <seat_numbers>)`, яка приймає два параметри.
Першим параметром буде словник зі схемою розсаджування.
Другим параметром буде список номерів місць, які потрібно «звільнити» чи спорожнити, тобто надати значенню номера місця `None`.

Поверніть `dict` місць після оновлення значень місць, які потрібно спорожнити.

```python
>>> empty_seats(seats={1: "Alice", 2: None, 3: "Bob", 4: "George", 5: "Gloria"}, seat_numbers=[5,3,1])
{1: None, 2: None, 3: None, 4: "George", 5: None}
```
