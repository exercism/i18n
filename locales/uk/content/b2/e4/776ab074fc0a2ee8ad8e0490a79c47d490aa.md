# Вступ

_Тернарний оператор_ - це легка й компактна альтернатива простим умовним конструкціям _if/else_. Зазвичай його використовують в інструкціях повернення (але не лише в них): щоб ухвалити рішення, достатньо лише одного рядка, який повертає ліве значення, якщо вираз дорівнює `true`, і праве, якщо `false`, ось так:

```java
boolean expr = 0 != 200;

// Ternary statement
int value = expr ? 22 : 33;
// => 22
```

Багато простих виразів _if/else_ можна спростити за допомогою _тернарних операторів_.
