# Інструкції

Працюючи на заводі, ми стикаємося з потребою створити надруковане повідомлення на бейджах співробітників. Ми вирішуємо реалізувати цю функцію в JavaScript.

Для бейджа потрібні `id` співробітника, `name` співробітника, а також відділ, у якому співробітник працює.

## 1. Створіть текст бейджа

Реалізуйте функцію з назвою `printBadge`, яка повертає текст для друку на бейджі.

Імʼя співробітника надається завжди, але номер `id` співробітника та назва відділу можуть бути `null`. Номер `id` співробітника, якщо його надано, має бути в квадратних дужках (наприклад, `[20]`).

Бейдж власника не повинен мати `id` або `department`.

```javascript
printBadge(20, 'Bob', 'Marketing');
// => '[20] Bob - MARKETING'
```
