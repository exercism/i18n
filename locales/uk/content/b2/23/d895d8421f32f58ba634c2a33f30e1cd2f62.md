# Додаток до інструкцій

Кожен рядок сітки представлено як слово.

Наприклад,

```
    0 1 0
    1 0 0
    1 1 0
```

представлено як

```
0x2
0x4
0x6
```

Сітка має щонайбільше 32 стовпці.

## Регістри

| Регістр | Призначення | Тип           | Опис                            |
| -------- | ------------ | ------- | --------------------------- |
| `$a0`    | вхідні дані        | ціле число | кількість рядків              |
| `$a1`    | вхідні дані        | ціле число | кількість стовпців           |
| `$a2`    | вхідні дані        | адреса | сітка для поточного покоління |
| `$a3`    | вхідні та вихідні дані | адреса | сітка для наступного покоління    |
| `$t0-9`  | тимчасовий    | будь-який     | використовується для тимчасового зберігання  |
