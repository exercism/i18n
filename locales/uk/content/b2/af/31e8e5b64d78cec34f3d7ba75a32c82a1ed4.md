# Інструкції

У цій вправі ми аналізуємо номери телефонів.

Потрібно реалізувати 2 можливості.

Номери телефонів, які передаються в підпрограми, гарантовано мають вигляд
NNN-NNN-NNNN, наприклад 212-515-9876, і не дорівнюють null.

## 1. Проаналізувати номер телефону

Наш аналіз має повертати 3 частини даних

1. Ознака того, чи має номер нью-йоркський код набору, тобто 212 як перші 3 цифри
2. Ознака того, чи є номер фальшивим, якщо в позиціях з 5 по 7 (нумерація з 1) стоїть префіксний код 555
3. Останні 4 цифри номера.

Реалізуйте (статичний) метод `PhoneNumber.Analyze()`, який повертає інформацію про номер телефону.

```csharp
PhoneNumber.Analyze("631-555-1234");
// => (false, true, "1234")
```

## 2. Визначити, чи має номер телефону фальшивий префіксний код (555)

Реалізуйте (статичний) метод `PhoneNumber.IsFake()`, який визначає, чи є номер телефону фальшивим, використовуючи інформацію про номер, отриману в завданні 1.

```csharp
PhoneNumber.IsFake(PhoneNumbers.Analyze("631-555-1234"));
// => true
```
