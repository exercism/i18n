# Тести

У всіх вправах використовується фреймворк [Pester][pester] для імітації та тестування.
Усі тести містяться у файлі з назвою `[Exercise].tests.ps1`, як це прийнято у фреймворку Pester.
Якщо ми в потрібній директорії (тобто тій, що містить `[Exercise].ps1` та `[Exercise].tests.ps1`),
запустити тести з PowerShell можна так:

``` PowerShell
Invoke-Pester
```

Це запустить усі файли `.tests.ps1`, які вдасться знайти в директорії.

Якщо ми використовуємо іншу оболонку, ніж PowerShell, тести можна запустити так:

``` PowerShell
pwsh -Command "Invoke-Pester"
```

## Запуск тестів у Visual Studio Code

Потрібно переконатися, що у Visual Studio Code встановлено [розширення PowerShell][extension].

Запустити тести у Visual Studio Code можна кількома способами:

- Запустити скрипт `.Tests.ps1` з меню Debug. Комбінації клавіш: `F5` або `Shift + F5`
- Просто з редактора, натиснувши посилання «Run Tests» над ключовим словом `Describe` у самому коді тесту
- Налаштувати Task для запуску фреймворку Pester

[pester]: https://github.com/pester/Pester
[extension]: https://marketplace.visualstudio.com/items?itemName=ms-vscode.PowerShell
