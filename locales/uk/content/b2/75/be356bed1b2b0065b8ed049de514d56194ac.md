# Додаток до інструкцій

## Формат вихідних даних

Виведіть рослини учня як рядок тексту (англ. string), завершений нульовим символом, використовуючи кому та пробіл як роздільники.

## Регістри

| Регістр | Використання | Тип    | Опис                          |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | вхідні дані  | адреса  | схема городу                  |
| `$a1`    | вхідні дані  | адреса  | імʼя учня                     |
| `$a2`    | вхідні/вихідні дані | адреса | рядок тексту вихідних даних, завершений нульовим символом |
| `$t0-9`  | тимчасовий   | будь-який | використовується для тимчасового зберігання |
