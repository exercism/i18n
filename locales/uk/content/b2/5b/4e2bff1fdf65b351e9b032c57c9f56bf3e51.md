# Підказки

## 1. Створення нового відвідувача

- Перегляньте [концепцію «Обʼєкти»][concept-objects], щоб дізнатися, як створити обʼєкт із певними ключами та значеннями.

## 2. Анулювання квитка

- Скористайтеся оператором присвоєння `=`, щоб встановити властивість `ticketId` обʼєкта відвідувача в `null`.
- Потім поверніть обʼєкт відвідувача.

## 3. Визначення статусу квитка

- Перегляньте [концепцію «Умовні конструкції»][concept-conditionals], щоб дізнатися, як умовно повертати з функції різні значення.
- Скористайтеся квадратними дужками, щоб отримати значення заданого `ticketId` в обʼєкті.
- Скористайтеся оператором строгої рівності `===`, щоб перевірити на `null` або `undefined`.

## 4. Покращення відповіді про статус квитка

- Отримайте значення для заданого `ticketId` за допомогою квадратних дужок, як у попередній задачі.
- Для розвʼязання цієї задачі умовна конструкція не потрібна.
- Натомість скористайтеся [оператором обʼєднання з `null`][mdn-nullish-coalescing] `??`.

## 5. Визначення версії умов і положень

- Перегляньте [концепцію «Обʼєкти»][concept-objects], щоб дізнатися, як отримувати вкладені значення, і почніть із запису виразу для отримання версії.
- Потім скористайтеся [оператором опціонального ланцюжка][mdn-optional-chaining], щоб обробити випадок відсутнього обʼєкта gtc.
- Для розвʼязання цієї задачі умовна конструкція не потрібна.
