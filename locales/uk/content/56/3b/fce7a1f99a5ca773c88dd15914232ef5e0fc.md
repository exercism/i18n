# Докладніше

[Списки][list] - базовий тип даних у Haskell для зберігання колекції значень.
Списки _незмінні_, тобто їх не можна модифікувати.
Будь-яка операція, що змінює список, повертає новий список.
У Prelude є кілька функцій, які дають змогу працювати зі списками.

Списки в Haskell реалізовано як [звʼязані списки][linked-list-wiki], а не як масиви із суміжних комірок памʼяті.
Тому доступ до елемента списку займає лінійний час, що залежить від довжини списку.

Списки можна записати в літеральній формі, у записі «голова-хвіст» (який використовує оператор `cons` `:`) або поєднанням обох:

```haskell
-- Literal Form
[]
[1]
[1, 2, 3]

-- Head-tail Notation
[]
-- same as [1]
1 : []
-- same as [1, 2, 3]
1 : (2 : (3 : []))

-- Mixed
-- same as [1, 2, 3]
1 : [2, 3]
```

Запис «голова-хвіст» можна використовувати, щоб додавати елементи до списку.

```haskell
list = [2, 1]

[3, 2, 1] == 3 : list
-- -> True
```

Додавання елементів до списку під час ітерації вважається антипатерном. 
Щоб додати елемент у кінець, потрібно пройти весь список і додати елемент у його кінці, тому додавання нового елемента на кожній ітерації вимагало б проходження всього списку на кожній ітерації.

Ми можемо досягти того самого результату, додавши елемент на початок оберненого списку, а потім обернувши результат. Додавання на початок - швидка операція, яка потребує сталого часу.

```haskell
-- Appending to the end of a list (potentially slow)
[1, 2, 3] ++ [4] ++ [5] ++ [6]

-- Prepend to the start of a list (faster, due to the nature of linked lists)
6 : (5 : (4 : [3, 2, 1]))
-- then reverse!
```

Є кілька поширених функцій Prelude для списків:

- [`head`][head] повертає _голову_ списку, тобто _перший_ елемент списку.
- [`tail`][tail] повертає _хвіст_ списку, тобто список _без_ _першого_ елемента.
- [`length`][length] повертає кількість елементів у списку.
- [`elem`][elem] повертає булеве значення (англ. Boolean), яке вказує, чи є елемент у списку.

Є також [модуль `Data.List`][list].

## Типи списків

У Haskell списки **однорідні**.
Це означає, що всі елементи списку мають той самий тип.
Коли ми намагаємося покласти елементи різних типів в один список, ми отримаємо помилку типу.

```haskell
list = [1, "string"]
-- Error: No instance for (Num String) arising from the literal ‘1’
```

Анотація типу списку - `[a]`, де `a` - це тип, який зберігає список, наприклад `String` чи `Int`.

``` haskell
a :: [Int] 
a = [1, 2, 3]
```
