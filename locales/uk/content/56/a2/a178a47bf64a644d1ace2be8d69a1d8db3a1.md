# Про винятки

У Haxe винятки - це безпечний спосіб обробляти помилки, які виникають під час виконання коду. Усі винятки повинні містити повідомлення, яке описує помилку. Ми можемо _кидати_ винятки за допомогою ключового слова `throw`:

```haxe
public function main(num:Int) {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
  // ...
}
```

Коли виняток кинуто, код шукає частину, яка має обробити цю помилку. Якщо такої частини немає, він покаже повідомлення про помилку й водночас зупинить виконання програми.

Щоб обробляти винятки в Haxe, ми використовуємо блок `try-catch`. Ця блокова інструкція складається з одного блоку `try` та одного або кількох блоків `catch`. Блок `try` _намагається_ виконати частину коду, а блок `catch` чекає, чи не кинуто якийсь виняток, щоб _перехопити_ його, і виконання не зупинилося. Коли блок `catch` перехоплює виняток, він також виконує все, що є в блоці:

```haxe
try {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
} catch (e) {
  // All exceptions will be caught here
  trace(e.message); // Argument num cannot be greater than 10
}
```

Тип аргументу блоку `catch` слід опустити.

Важливо зауважити, що винятки варто використовувати в тих випадках, коли трапляється щось виняткове, тобто помилка, яка потребує особливої обробки. Їх не слід використовувати для керування потоком виконання програми, адже це вважається поганим проєктуванням і часто призводить до поганої продуктивності та складного супроводу.
