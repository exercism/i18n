# Вступ

Булевий вираз (англ. Boolean) - це питання, поставлене до одного чи кількох значень, на яке можна відповісти `true` або `false`.
Вираз зі значенням правда повертає `1`, а вираз зі значенням неправда повертає `0`.
Крім того, у чисел теж є значення правди й неправди. Нуль - це `false`, а будь-яке число, відмінне від нуля, - `true`.

У старому коді мовою C або використовують тип `int` напряму для булевих значень, або програміст визначав константи на кшталт `TRUE` і `FALSE`, щоб зіставити `1` і `0` з булевим поданням.

У версії C99 додали тип `_Bool`.
Заголовний файл `stdbool.h` визначає три нові булеві символи: `bool`, `true` і `false`.
`true` відповідає `1`, `false` відповідає `0`, а `bool` відповідає `_Bool`.
Тож тепер, замість того щоб напряму використовувати `int` чи створювати власні булеві відповідники, програміст може підключити `stdbool.h` і автоматично отримати булеві символи у своєму коді.

## Оператори порівняння

C підтримує шість операторів порівняння: `==` (дорівнює), `!=` (не дорівнює), `>` (більше), `<` (менше), `>=` (більше або дорівнює), `<=` (менше або дорівнює).
Ці оператори порівнюють співвідношення між значеннями й зводять результат до булевих значень.

```c
0 == 0 // true. Although 0 is false, 0 equals 0 is true.
0 != 0 // false
1 > 0 // true
1 < 0 // false
1 >= 0 // true
1 <= 0 // false
```

## Булеві оператори

C підтримує три булеві оператори: `||` (логічне або), `&&` (логічне і) та `!` (логічне заперечення).

`!` використовується з одним операндом.
Він обертає булеве значення операнда.
Наприклад, `0` - це `false`, але `!0` - це `true`.

`||` і `&&` використовуються з двома операндами.
Правий операнд обчислюється лише тоді, коли лівий операнд ще не визначає результат виразу.
Тобто `||` обчислює свій правий операнд лише тоді, коли лівий операнд набуває значення `false`.
`&&` обчислює свій правий операнд лише тоді, коли лівий операнд набуває значення `true`.
