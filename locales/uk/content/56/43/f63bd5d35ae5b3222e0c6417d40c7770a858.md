# Вступ

## Рядки тексту (англ. string)

Рядок тексту складається із символів, узятих у лапки.
Підтримуються як одинарні, так і подвійні лапки.

```php
<?php

$where = "Spain";
$what = 'rain';
```

### Розширення змінних у рядку тексту

Якщо в рядку тексту в подвійних лапках згадується змінна, яка перебуває в області видимості, її значення підставляється в цей рядок.

```php
<?php

$answer = 42;
$expanded = "The answer to life, the universe, and everything is $answer"; 
```

### Підтримка кодування символів

Історично функції для роботи з рядками тексту в PHP підтримували лише символи ASCII і не підтримували сучасні кодування Unicode.
Кожен символ ASCII займає 1 байт, тоді як символи Unicode можуть мати довжину від 1 до 4 байтів.
Якщо потрібно безпечно працювати з рядками тексту Unicode, звернімося до [багатобайтових версій][multi-byte-fns] цих історичних функцій.

```php
<?php

$byte_length = strlen('😃'); // => 4
$string_length = mb_strlen('😃'); // => 1
```

[multi-byte-fns]: https://www.php.net/manual/en/ref.mbstring.php
