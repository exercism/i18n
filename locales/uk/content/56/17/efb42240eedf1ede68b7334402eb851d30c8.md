# Інструкції

У цій вправі ми будемо застосовувати [правила гри ґо](https://matmoore.github.io/learngo/). Самі правила вже написані, нам лише треба застосувати їх, щоб оновити Game і обробити будь-які помилки та порушення правил.

Гру представлено так:

```gleam
pub type Player {
  Black
  White
}


pub type Game {
  Game(
    white_captured_stones: Int,
    black_captured_stones: Int,
    player: Player,
    error: String,
  )
}
```

У грі є 4 правила:

- На кожній точці може бути лише один камінь.
- Камені супротивника можна захопити.
- Не можна поставити камінь у точку, де він захопив би сам себе.
- Не можна використати ту саму точку двічі.

## 1. Застосуйте правила

Напишіть вміст функції `apply_rules`, яка приймає початковий `Game` і набір правил та повертає новий `Game` після застосування правил.

Три з цих правил перевіряють, чи не порушено правила, і можуть повернути помилку, тож їхній тип поверненого значення - `Result(Game, String)`. Якщо якесь із цих правил не проходить перевірку, потрібно повернути початковий Game, але з полем `error`, оновленим відповідною помилкою.

Інше правило не перевіряє порушень, тож не може повернути помилку (хоча може повернути змінений `Game`), а отже його тип поверненого значення - `Game`.

Якщо всі правила проходять, то всі зміни, які вони внесли в `Game`, слід зберегти, а гравця змінити.

```gleam
pub fn apply_rules(
  game: Game,
  rule1: fn(Game) -> Result(Game, String),
  rule2: fn(Game) -> Game,
  rule3: fn(Game) -> Result(Game, String),
  rule4: fn(Game) -> Result(Game, String),
) -> Game {
  // -> If all rules pass, return a `Game` with all changes from the rules applied, and change player
  // -> If any rule fails, return the original Game, but with the error field set
}
```
