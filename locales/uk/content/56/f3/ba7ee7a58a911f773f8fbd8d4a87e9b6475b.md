# Вступ

Common Lisp дозволяє програмісту писати «коментарі», які компʼютер ігнорує.
Однорядкові коментарі починаються з одного або кількох символів крапки з комою (`;`), і час від часу можна побачити таке:

```lisp
(code...) ; => value
```

Тут коментар показує, яке значення повертає Common Lisp після виконання коду в цьому рядку.

Прийнято писати один символ крапки з комою для короткого коментаря в кінці рядка, два символи для довшого коментаря над ділянкою коду, три для довгого коментаря, що описує щось на кшталт функції, і чотири для коментаря на кшталт заголовка на початку файлу з кодом.
