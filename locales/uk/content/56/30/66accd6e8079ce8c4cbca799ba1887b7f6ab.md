# Доповнення до інструкцій

## `Print` не бере рядкові значення в лапки

У цій вправі ми працюємо з числовими балами.
#[a: 1]` and `#[a: "1"]` не одне й те саме:

```arturo
inspect #[a: 1]
; [ :dictionary
;        a  :        1 :integer
; ]

inspect #[a: "1"]
; [ :dictionary
;        a  :        1 :string
; ]
equal? #[a: "1"] #[a: 1]
; false
```

Поширений прийом зневадження - виводити значення за допомогою `print`.
Однак виведення не додає лапок навколо рядків тексту (англ. string).
Тому числовий рядок тексту на кшталт `"1"` під час виведення має такий самий вигляд, як ціле число `1`.

```arturo
print #[a: 1]
; [a:1]
print #[a: "1"]
; [a:1]
```
У виводі тестів цієї вправи може трапитися результат на кшталт `:x: equal? [a:1 e:1 i:1 o:1 u:1] [a:1 e:1 i:1 o:1 u:1]`.
Два словники, які порівнюються, під час виведення мають однаковий вигляд.
Однак у першому словнику значення - числові рядки тексту, а в другому - цілі числа, тому вони не однакові.
Під час зневадження можна скористатися `inspect`, щоб перевірити вміст власного словника.

## `Express` таки бере рядкові значення в лапки

`express` перетворює значення на код Arturo і повертає рядок тексту, який є поданням цього коду.
У цьому результаті будь-які рядкові значення буде взято в лапки.
Тому `express "1"` поверне `"1"`, а не `1`.

```arturo
express #[name: "Octavius" age: 22]
; #[name: "Octavius" age: 22 ]
```
```arturo
express #[name: "Octavius" age: "22"]
; #[name: "Octavius" age: "22" ]
```
