# Інструкції

У цій вправі ми будемо писати код, який друкує іменні бейджі для працівників фабрики. Працівники мають ідентифікатор, імʼя та назву відділу. Мітки на бейджах працівників мають такий формат: `"[id] - name - DEPARTMENT"`.

## 1. Надрукувати бейдж для працівника

Реалізуйте функцію `NameBadge.print/3`. Вона має приймати ідентифікатор, імʼя та відділ. Вона має повертати мітку бейджа, у якій назва відділу записана великими літерами.

```elixir
NameBadge.print(67, "Katherine Williams", "Strategic Communication")
# => "[67] - Katherine Williams - STRATEGIC COMMUNICATION"
```

## 2. Надрукувати бейдж для нового працівника

Через особливість компʼютерної системи нові працівники іноді ще не мають ідентифікатора, коли починають працювати на фабриці. Оскільки бейджі обовʼязкові, вони отримають тимчасовий бейдж без префікса з ідентифікатором.

Розширте функцію `NameBadge.print/3`. Якщо ідентифікатор відсутній, вона має друкувати бейдж без нього.

```elixir
NameBadge.print(nil, "Robert Johnson", "Procurement")
# => "Robert Johnson - PROCUREMENT"
```

## 3. Надрукувати бейдж для власника

Навіть власник фабрики мусить постійно носити бейдж. Однак у власника немає відділу. У цьому випадку замість назви відділу на мітці потрібно надрукувати `"OWNER"`.

Розширте функцію `NameBadge.print/3`. Якщо відділ відсутній, вважайте, що бейдж належить власнику компанії.

```elixir
NameBadge.print(204, "Rachel Miller", nil)
# => "[204] - Rachel Miller - OWNER"
```

Зауважте, що власник може бути одночасно і новим працівником.

```elixir
NameBadge.print(nil, "Rachel Miller", nil)
# => "Rachel Miller - OWNER"
```
