# Встановлення

Phix для платформ Windows або Linux можна завантажити з [офіційного сайту][Download].

Після встановлення структура каталогів має збігатися з наведеною в [документації][Installation].

Перевірте, запустивши «p -test».

[Installation]: http://phix.x10.mx/docs/html/installation.htm
[Download]: http://phix.x10.mx/download.php
