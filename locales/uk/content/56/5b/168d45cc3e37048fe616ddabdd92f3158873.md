# Вступ

Go має статичну типізацію, тож кожна змінна матиме тип, відомий на час компіляції.
Після оголошення тип змінної змінити не можна.

## Створення змінної

Інструкція `var` може оголосити тип нової змінної, задати її значення або зробити і те, і те водночас:

```go
var total int     // Type explicitly declared, value implicitly set (see note on zero values below)
var count int = 1 // Type explicitly declared, value explicitly set
var sum = 100     // Type implictly declared, value explicitly set
```

Усередині функції також можна використати коротку інструкцію присвоєння `:=`.

```go
count := 1 // Type implictly declared, value explicitly set
```

Змінна в Go завжди має значення.
Якщо його не задати під час оголошення, Go надає значення, [яке називають нульовим][zero-values], виходячи з типу змінної.

```go
var total int     // 0
var name string   // ""
var ready bool    // false
```

## Оновлення змінної

Усередині функції оператор присвоєння `=` може задати нове значення для наявної змінної:

```go
count := 1
count = 2
```

Нове значення повинно мати той самий тип, що й змінна:

```go
count := 1
count = false // compile error: a Boolean is not an int
```

[zero-values]: https://exercism.org/tracks/go/concepts/zero-values
