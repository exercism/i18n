# Докладніше

Масиви - це тип послідовностей фіксованої довжини у Factor: елементи змінювати можна, а довжину - ні.
Літерали записують як `{ … }` із пробілами між елементами; словник
`arrays` додає маленькі конструктори, які знімають значення зі
стеку:

| слово     | ефект                              |
|----------|-------------------------------------|
| `1array` | `( a     -- { a } )`                |
| `2array` | `( a b   -- { a b } )`              |
| `3array` | `( a b c -- { a b c } )`            |
| `<array>`| `( n elt -- array )`: `n` копій `elt` |
| `array?` | `( obj   -- ? )`: предикат типу     |

Кілька слів [протоколу][sequence-protocol] зі словника `sequences` трапляються з
масивами так часто, що їх варто знати як одне ціле:

| слово      | ефект                                                |
|-----------|-------------------------------------------------------|
| `concat`  | `( seqs -- seq )`: розгортає послідовність послідовностей |
| `join`    | `( seqs glue -- seq )`: розгортає з розділювачем     |
| `reverse` | `( seq -- newseq )`                                   |
| `index`   | `( elt seq -- i/f )`: індекс елемента, або `f`       |
| `member?` | `( elt seq -- ? )`: перевірка належності              |

```factor
USING: arrays sequences ;

3 4 2array .                       ! => { 3 4 }
{ { 1 2 } { 3 4 } } concat .       ! => { 1 2 3 4 }
{ 1 2 3 4 } reverse .              ! => { 4 3 2 1 }
"b" { "a" "b" "c" } index .        ! => 1
"b" { "a" "b" "c" } member? .      ! => t
```

`all-unique?` і `members` зі словника [`sets`][sets] також приймають будь-яку
послідовність. Це зручно, коли елементи масиву треба позбутися дублікатів
або перевірити їх на повторення, не перетворюючи спершу на хеш-множину.

[sets]: https://docs.factorcode.org/content/vocab-sets.html
[sequence-protocol]: https://docs.factorcode.org/content/article-sequence-protocol.html
