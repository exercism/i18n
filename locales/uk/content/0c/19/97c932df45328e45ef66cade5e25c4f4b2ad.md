Raku - надзвичайно багата, гнучка та потужна мова програмування.
Її гнучкість дає змогу розробникам писати виразний код, що відповідає їхньому власному стилю.

Raku - велика мова, у якій багато глибини, щоб вивчати, досліджувати й експериментувати.
Цей силабус має на меті охопити основи, достатні для того, щоб ми могли почати.

Обʼєктно-орієнтоване програмування лежить в основі Raku, проте воно не навʼязує обʼєктно-орієнтованих практик.
Через свою обʼєктно-орієнтовану природу цей силабус часто буде звертатися до [обʼєктів, класів і методів][object-orientation].

## Змінні

У розділі «Основи» ми для простоти будемо використовувати лише скалярні [змінні][variables].

Скалярні змінні - це [ідентифікатори][identifiers] з префіксом-сигілом `$`.

Скалярні змінні можуть містити практично будь-що, а їхній типовий тип - [`Any`][Any].

Більшість змінних, які ми використовуємо, потребують [оголошення][variable-declarator].
Поки що обмежмося [`my`][my] та [`constant`][constant].

```raku
my $foo;
constant $BAR;
```

## Підпрограми

Підпрограму оголошують декларатором [`sub`][sub-declarator].

Після оголошення `sub` іде необовʼязковий [ідентифікатор][identifiers], далі необовʼязкова [сигнатура][signatures], а потім [блок][blocks].

Підпрограми (серед іншого) можна експортувати, додавши трейт [`is export`][exporting].

Підпрограму можна викликати за допомогою [постциркумфіксного оператора `( )`][postcircumfix-()] після ідентифікатора.

```raku
sub foo ($bar) is export { ... } # Subroutine definition

foo($bar); # Subroutine call
```

## Оператори

У Raku є широкий набір [операторів][operators].
Для вправ у розділі «Основи» ми будемо використовувати кілька базових математичних операторів, як-от `+` і `-`.

```raku
say 0.1 + 0.2 - 0.3;
# Raku is not like other languages -> https://0.30000000000000004.com/#raku
```

За бажанням ми легко можемо визначити власні оператори в Raku.
Більшість вбудованих операторів також доступні як підпрограми.

## Пакети та модулі

У Raku є кілька типів [пакетів][package-declarator]. У розділі «Основи» ми будемо використовувати лише `module`.

Щоб оголосити весь файл як `module`, перед оголошенням модуля ставлять `unit`.

```raku
unit module Foo;

sub bar () { ... }
```

## Коментарі

У Raku є [однорядкові][single-line-comments] та [багаторядкові/вбудовані][multi-line-comments] коментарі.

Однорядкові коментарі починаються з `#` і тривають до кінця рядка.

Багаторядкові/вбудовані коментарі починаються з решітки, за якою йдуть зворотний апостроф і символ Юнікоду з відкривальної пунктуації.
Вони закінчуються відповідним парним закривальним символом.

```raku
# This is a single-line comment

#`(
    This is a
    multi-line/embedded comment
)
```

## Стильові угоди

Ідентифікатори [змінних][identifiers] і підпрограм у Raku оформлюють у стилі `kebab-case`.
Константи оформлюють у стилі `ALL-CAPS`.
Назви пакетів оформлюють у стилі `PascalCase`.
