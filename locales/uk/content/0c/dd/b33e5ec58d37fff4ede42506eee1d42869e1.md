# Не змінюйте надані сигнатури

Як зазначено в інструкціях, не змінюйте сигнатури `makeChest` і `makeTreasureChest`.
Вони мають залишитися точно такими:

```elm
makeChest : String -> treasure -> Chest treasure {}

makeTreasureChest : Chest treasure { conditions | securePassword : (), uniqueTreasure : () } -> TreasureChest treasure
```
