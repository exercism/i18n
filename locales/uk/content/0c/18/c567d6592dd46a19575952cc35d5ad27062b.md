# Інструкції

Торі працює журналісткою і пише про клімат. Вона хоче написати статтю про погоду в різних містах. У неї є дані про погоду в різних містах, і вона хоче впорядкувати їх за температурою, але одні температури подано в градусах Фаренгейта, а інші - в градусах Цельсія. Їй потрібна наша допомога, щоб перевести температури в однакову одиницю виміру й упорядкувати їх.

## 1. Перевести градуси Фаренгейта в градуси Цельсія

Визначте функцію `fahrenheit_to_celsius`, яка приймає температуру в градусах Фаренгейта як аргумент і повертає температуру в градусах Цельсія.

Щоб перевести градуси Фаренгейта в градуси Цельсія, відніміть 32 від значення у градусах Фаренгейта, а потім поділіть результат на 1.8.

```gleam
fahrenheit_to_celsius(72.5)
// -> 22.5
```

## 2. Порівняти дві температури

Визначте функцію `compare_temperature`, яка приймає дві температури й повертає значення типу `Order`, що вказує, чи перша температура менша за другу, дорівнює їй чи більша за неї.

```gleam
compare_temperature(Celsius(30.5), Fahrenheit(82.1))
// -> Gt
```

## 3. Упорядкувати міста за температурою

Визначте функцію `sort_cities_by_temperature`, яка приймає масив міст і повертає їх від найхолоднішого до найтеплішого.

```gleam
sort_cities_by_temperature([
  City(name: "London", temperature: Celsius(30.5)),
  City(name: "Paris", temperature: Fahrenheit(82.1))
])
// -> [
//   City(name: "Paris", temperature: Fahrenheit(82.1)),
//   City(name: "London", temperature: Celsius(30.5)))
// ]
```
