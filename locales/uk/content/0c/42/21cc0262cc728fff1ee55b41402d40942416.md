# Вступ

У Go `struct` - це послідовність іменованих елементів, які називаються _полями_. Кожне поле має імʼя та тип.
Імʼя поля має бути унікальним у межах структури.
Структури можна порівняти з _класами_ в парадигмі обʼєктно-орієнтованого програмування.

## Визначення структури

Ми створюємо нову структуру за допомогою ключових слів `type` і `struct` та явно визначаємо імена й типи полів.
Наприклад, ось ми визначаємо структуру `Shape`, яка зберігає назву фігури та її розмір:

```go
type Shape struct {
    name string
    size int
}
```

Імена полів у структурах підпорядковуються угоді Go: поля, імʼя яких починається з малої літери, видимі лише коду в тому самому пакеті, а ті, чиє імʼя починається з великої літери, видимі в інших пакетах.

## Створення екземплярів структури

Щойно ми визначили `struct`, потрібно створити новий екземпляр, задавши поля за їхніми іменами в будь-якому порядку:

```go
s := Shape {
    name: "Square",
    size: 25,
}
```

Щоб прочитати або змінити поля екземпляра, використовуємо запис із `.`:

```go
// Update the name and the size
s.name = "Circle"
s.size = 35
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 35
```

Поля, яким не присвоєно початкового значення, отримають своє нульове значення.
Наприклад:

```go
s := Shape{name: "Circle"}
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 0
```

Можна створити екземпляр `struct`, не вказуючи імена полів, якщо визначити поля _в порядку_:

```go
s := Shape {
	"Oval",
	20,
}
```

Однак такий синтаксис вважається _крихким кодом_, бо він може зламатися, коли додають поле, особливо якщо нове поле іншого типу.
У наступному прикладі ми додаємо додаткове поле до `Shape`:

```go
type Shape struct {
	name        string
	description string // new field 'description' added
	size        int
}

s := Shape{
    "Circle",
    20,
}
// Since the second field of the struct is now a string and not an int,
// the compiler will throw an error when compiling the program:
// Output: cannot use 20 (type untyped int) as type string in field value
// Output: too few values in Shape{...}
```

## Функції «New»

Іноді буває зручно мати функції, які допомагають нам створювати екземпляри структур.
За домовленістю такі функції зазвичай називають `New` або дають їм імена, що починаються з `New`, але оскільки це просто звичайні функції, ми можемо дати їм будь-яке імʼя.
Вони можуть нагадувати конструктори в інших мовах, але в Go це просто звичайні функції.

У наступному прикладі одну з таких функцій `New` використано, щоб створити новий екземпляр `Shape` і автоматично встановити типове значення для `size` фігури:

```go
func NewShape(name string) Shape {
	return Shape{
		name: name,
		size: 100, //default-value for size is 100
	}
}

NewShape("Triangle")
// => Shape { name: "Triangle", size: 100 }

```

Використання функцій `New` може мати такі переваги:

* перевірка заданих значень
* робота з типовими значеннями
* оскільки функції `New` часто оголошують у тому самому пакеті, що й структури, які вони ініціалізують, вони можуть ініціалізувати навіть приватні поля структури

Щоб глибше зануритися в цей тип, можна переглянути ці ресурси: [Go by Example: Structs][go-by-example-structs], [A Tour of Go: Structs][tour-of-go-structs] або [Structures in Go (structs)][medium-structures-in-go]

## Вбудована функція `new`

Ще один спосіб створити новий екземпляр структури - скористатися вбудованою функцією `new`:

```go
s := new(Shape) // s will be of type *Shape (pointer to shape)
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name:  size: 0
```

У цьому прикладі `new` створює екземпляр структури `Shape`, усі значення якого ініціалізовано нульовим значенням їхнього типу, і повертає вказівник на нього.

~~~~exercism/note
Найчастіше ми не побачимо нових екземплярів структур, створених за допомогою вбудованої функції `new`.
Завжди віддаваймо перевагу літералу структури, власній функції `New` або будь-якій іншій функції з пакета, яка допомагає нам побудувати структуру.
Вбудовану функцію `new` використовуємо для створення нових екземплярів структур лише як останній засіб.
~~~~
