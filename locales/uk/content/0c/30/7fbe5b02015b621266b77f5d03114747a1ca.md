# Вступ

У JavaScript є вбудований обʼєкт `Date`, який зберігає дату і час та надає методи для роботи з ними.

<!-- prettier-ignore -->
~~~exercism/caution

Через те, що працювати з датами загалом складно, і через те, що робота з часовими зонами погана або відсутня, існує багато бібліотек, як-от `moment.js`, `day.js`, `date-fns` і `luxon`.

## Створення

Обʼєкт `Date` - примірник класу `Date`.
Його можна створити, не передаючи в функцію-конструктор жодних аргументів.
У результаті отримуємо обʼєкт `Date`, який представляє поточну дату і час:

```javascript
const now = new Date();
// => Thu Apr 14 2022 11:46:08 GMT+0530 (India Standard Time)
// Shows current day, date and time (in your time zone).
```

### Часова позначка Unix (число)

Якщо передати число, воно сприймається як `timestamp`.
Часова позначка - ціле число, яке представляє кількість **мілісекунд**, що минули з **1 січня 1970 року [UTC][defn-utc]+0**.

```javascript
const epoch = new Date(0);
// Thu Jan 01 1970 01:00:00 GMT+0100 (Central European Standard Time)

const another = new Date(1749508766627);
// Tue Jun 10 2025 00:39:26 GMT+0200 (Central European Summer Time)
```

Можна очікувати, що `new Date(0)` створить «найраніший» обʼєкт дати, але JavaScript перетворить дату на місцеву часову зону, тож насправді значення [епохи Unix][defn-unix-epoch] отримають лише ті, хто перебуває в часовій зоні [GMT / з UTC+0][defn-gmt].

### Часова позначка ISO 8601 (рядок тексту)

У конструктор `Date` можна передати рядок тексту (англ. string), який представляє дату.
**Єдиний** формат, однаковий у всіх реалізаціях, - це [спрощена версія][mdn-date-string-format] міжнародно визнаних і стандартизованих так званих [рядків часових позначок ISO 8601][defn-iso8601].

Момент часу за [UTC][defn-gmt] має такий вигляд:

```text
YYYY-MM-DDTHH:mm:ss.mssZ
YYYYMMDDTHHmmss.mssZ
```

де відбуваються такі підстановки:

| Ключ | Опис                                          | Типове значення |
| ---- | --------------------------------------------- | --------------- |
| YYYY | Календарний рік, записаний 4 цифрами          |                 |
| MM   | Календарний місяць, записаний 2 цифрами       | 01              |
| DD   | Календарний день, записаний 2 цифрами         | 01              |
| T    | Буква T у буквальному значенні, що розділяє дату і час | T       |
| HH   | Години за 24-годинним годинником, 2 цифри     | 00              |
| mm   | Хвилини, 2 цифри                              | 00              |
| ss   | Секунди, 2 цифри                              | 00              |
| mss  | Мілісекунди, 3 цифри                          | 000             |
| Z    | Буква Z у буквальному значенні або зміщення `+/-HH:mm` |        |

Буква `Z` у буквальному значенні позначає UTC (без часової зони, без переходу на літній час).

Оскільки для більшості компонентів є типові значення, цілком припустимо опускати частини в кінці:

```text
YYYY-MM-DD
```

Типове значення - час 00:00:00.000

Якщо часова позначка не закінчується на `Z` і не закінчується на `+HH:mm` чи `-HH:mm` (що вказує на зміщення часової зони), то з історичних причин діє таке правило:

> Якщо зміщення часової зони відсутнє, форми лише з датою інтерпретуються як час UTC, а форми з датою і часом - як місцевий час.
> Інтерпретація як часу UTC зумовлена історичною помилкою у специфікації, яка не відповідала ISO 8601, але її не можна було виправити через сумісність з вебом.
> Докладніше: [Broken Parser – A Web Reality Issue][ref-broken-parser].

### Обʼєкт дати

Наявний обʼєкт дати також можна використати як аргумент конструктора.
Так створюється копія наявного обʼєкта `Date` з тією самою датою і часом.

```javascript
const t1 = new Date();
const t2 = new Date(t1);
// Values of t1 and t2 will be the same.
```

### Передавання окремих значень компонентів дати і часу

Дату можна створити, передавши три числа.
Дату і час можна створити, передавши 6 чисел.

```javascript
const date1 = new Date(95, 11, 17);
// Creates Date for Dec 17 1995 00:00 if your local timezone is equivalent to UTC.

const date2 = new Date(2013, 12, 5, 13, 24, 0);
// Creates Date for Jan 5 2014 13:24 if your local timezone is equivalent to UTC.
```

Друге значення - це `month`, яке починається з `0` для січня і сягає `11` для грудня.

## `Date.parse()`

Можна натрапити на згадки про функцію розбору дат `Date.parse` або на посилання на неї.
Оскільки для цієї функції існує лише кілька інваріантів (істин), а решта реалізації не специфікована (а отже, не є стандартною), не варто нею користуватися.

## Доступ до компонентів `Date`

В обʼєктів дати є різні методи, які повертають компоненти дати:

```javascript
getFullYear(); // Get the year (4 digits)
getMonth(); // Get the month, from 0 to 11.
getDate(); // Get the day of month, from 1 to 31.
getHours(); // Get the hour in a 24 clock, from 0 to 23
getMinutes(); // Get the minutes, from 0 to 59
getSeconds(); // Get the seconds, from 0 to 59
getMilliseconds(); // Get the milliseconds, from 0 and 999
getDay(); // Get the day of week, from 0 (Sunday) to 6 (Saturday).
```

Кожен із них має відповідний варіант `set` (наприклад, `setFullYear`) для оновлення значення.
Будь-яке значення, що виходить за межі, переходить до наступного компонента:

```javascript
const date = new Date('2025-02-28T12:42:00Z');
// => Fri Feb 28 2025 13:42:00 GMT+0100 (Central European Standard Time)

date.setDate(29);
// there was no February 29th in 2025.

date.getDate();
// => 1

date.toString();
// => Sat Mar 01 2025 13:42:00 GMT+0100 (Central European Standard Time)
```

Для всіх цих методів існують варіанти UTC, які ігнорують місцеву часову зону.

## Перетворення з дати

Обʼєкти дати мають метод `getTime()`, який повертає часову позначку Unix у мілісекундах, тобто кількість мілісекунд від опівночі 1 січня 1970 року за UTC.
Крім того, доступний метод `toISOString()`, який перетворює обʼєкт дати на рядок тексту з часовою позначкою ISO 8601.

## Порівняння дат

Оператори «більше» (`>`), «більше або дорівнює» (`>=`), а також «менше» (`<`) і «менше або дорівнює» (`<=`) можна застосовувати безпосередньо між двома датами або між датою і числом.
Це працює, тому що JavaScript намагається звести дату до примітива.
