# Вступ

Екземпляр класу створюють, викликаючи його _конструктор_ через оператор `new`. Конструктор - це особливий метод у класі, мета якого - ініціалізувати клас. У Haxe метод-конструктор має назву `new()`.

```haxe
class Library {
  private var books:Int;

  public function new() {
    this.books = 10; // Initialize the books field
  }
}

var library = new Library(); // This calls the constructor
```

Як і звичайні методи, конструктори можуть приймати параметри. Ці параметри (зазвичай) зберігають у приватних полях і звертаються до них пізніше.

```haxe
class Building {
  private var numberOfStories:Int;
  private var totalHeight: Float;

  public function new(numberOfStories:Int, storyHeight:Float) {
    this.numberOfStories = numberOfStories;
    this.totalHeight = storyHeight * numberOfStories;
  }
}

var largeBuilding = new Building(55, 6.2);
```
