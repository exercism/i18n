# Докладніше

Рекурсія - це спосіб повторити код у функції, коли функція викликає саму себе.
Це ще один спосіб організувати цикл або ітерацію. Як і в циклі, функція має перевіряти булевий вираз (англ. Boolean), щоб знати, коли зупинитися.
На відміну від циклу, рекурсія, яка ніколи не завершується, не буде виконуватися нескінченно.
Значення, які використовуються в кожному виклику функції, можуть потрапляти у власний кадр стека.
Якщо кількість викликів функції займає більше місця, ніж є в стеку, це призведе до помилки переповнення стека.

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return i;
    printf("The number is %i\n", i++);
    printIncrement(i, maxValue);
}

int main() {
    printIncrement(1, 2);
    printf("After recursion");
    return 0;
}
```

Це виведе

```
The number is 1
The number is 2
After recursion
```

Бувають ситуації, які легше читати й осмислювати, коли їх виразити через рекурсію, а не через цикл.


## Хвостовий виклик

Хвостовий виклик - це коли остання інструкція функції лише викликає саму себе і більше нічого.

Хвостовий виклик - це особлива форма рекурсії, яка може дозволити компілятору оптимізувати рекурсію до циклу у скомпільованому коді.
Це дає найкраще з обох світів: читабельність рекурсії та швидкодію циклу.
Перетворення рекурсії на цикл під час компіляції називають `tail call elimination` або `tail call optimization.`

Коли хвостовий виклик компілюється в цикл, новий кадр стека не створюється для кожного виклику функції.
Оновлені значення передаються за адресою функції, викликаної спочатку, що заощаджує місце в стеку й підвищує швидкодію.

Цей приклад не є хвостовим викликом, бо функція додає 1 до результату свого виклику

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return 1;
    printf("The number is %i\n", i++);
    return 1 + printIncrement(i, maxValue);
}

int main() {
    int j = printIncrement(1, 2);
    printf("j is %i after recursion", j);
    return 0;
}
```

Це виведе

```
The number is 1
The number is 2
j is 3 after recursion
```

Щоб переробити його на хвостовий виклик, зробімо `j` параметром `printIncrement`

```c
int printIncrement (int i, int maxValue, int j){
    if (i > maxValue) return j;
    printf("The number is %i\n", i++);
    return printIncrement(i, maxValue, ++j);
}

int main() {
    int j = printIncrement(1, 2, 1);
    printf("j is %i after recursion", j);
    return 0;
}
```

Можливо, хвостовий виклик виявиться простішим для осмислення, ніж рекурсивний виклик, який не є хвостовим.
Однак компілятори зазвичай не гарантують, що всі хвостові виклики буде оптимізовано.
Використовуючи рекурсію, завжди важливо стежити, щоб ітерацій не було так багато, що стек переповниться.
