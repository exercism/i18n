# Індивідуальні вивіски

## Історія

У цій вправі ми напишемо код, який допоможе компанії з вивісками створювати індивідуальні написи для своїх вивісок.

## Завдання

Це приклади завдань, які пасують до історії про клієнта, що замовляє індивідуальну вивіску:

- Створити набір корисних рядків тексту (англ. string)
- Створити набір корисних символів
- Поєднувати фрази, щоб складати повідомлення
- Створити вивіску для випускного
- Обчислити вартість вивіски
