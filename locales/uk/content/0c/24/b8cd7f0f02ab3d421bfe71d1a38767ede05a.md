# Докладніше

[Тернарний умовний оператор][ternary-operator] є стислим записом виразу `if-else`.
Він обчислює умову і повертає одне з двох значень залежно від того, чи має ця умова значення `true` або `false`.

Оператор складається з трьох частин: `condition ? trueExpression : falseExpression`.
Якщо `condition` обчислюється як `true`, обчислюється і повертається `trueExpression`; інакше обчислюється і повертається `falseExpression`.

Тернарний оператор ідеально підходить для простих виборів в один рядок:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = showFahrenheit ? temperatureInCelsius * 9 / 5 + 32 : temperatureInCelsius
print(temperature)
// Prints 86
```

Наведений вище приклад є компактним відповідником такого коду:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = if showFahrenheit {
    temperatureInCelsius * 9 / 5 + 32
} else {
    temperatureInCelsius
}
```

[ternary-operator]: https://docs.swift.org/swift-book/LanguageGuide/BasicOperators.html#ID71
