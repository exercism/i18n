# Докладніше

Окрім `cond`, Elixir також надає макрос [`if/2`][getting-started-if], який стає в пригоді, коли потрібно перевірити лише одну умову.

[`if/2`][kernel-if] приймає умову та два варіанти. Він повертає перший варіант, якщо умова _truthy_, і другий варіант, якщо умова _falsy_.

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
else
  "No beer for you!"
end

# => "No beer for you!"
```

Якщо другий варіант не вказано, повертається `nil`.

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
end

# => nil
```

Також можна записати вираз `if` в одному рядку. Звернімо увагу на кому після умови.

```elixir
if age >= 16, do: "beer", else: "no beer"
```

Цей синтаксис стає в пригоді для дуже коротких виразів, але його варто уникати, якщо вираз не вміщається в один рядок.

## _Truthy_ та _falsy_

У Elixir усі типи даних набувають значення _truthy_ або _falsy_, коли потрапляють у булевий контекст (наприклад, у вираз `if`). Усі дані вважаються _truthy_ **крім** `false` та `nil`. Зокрема, порожні рядки тексту (англ. string), ціле число `0` та порожні списки вважаються _truthy_ в Elixir. У цьому сенсі [Elixir схожий на Ruby, але відрізняється від JavaScript, Python чи PHP][falsy-various-langs].

```elixir
truthy? = fn x -> if x, do: "truthy", else: "falsy" end

truthy?.(true)
# => "truthy"
truthy?.(0)
# => "truthy"
truthy?.([])
# => "truthy"

truthy?.(false)
# => "falsy"
truthy?.(nil)
# => "falsy"
```

[`&&/2`][kernel-and], [`||/2`][kernel-or] та [`!/1`][kernel-not] належать до _truthy_-булевих операторів, які працюють з будь-яким значенням і доповнюють _строгі_ булеві оператори [`and/2`][kernel-boolean-and], [`or/2`][kernel-boolean-or] та [`not/1`][kernel-boolean-not].

```elixir
0 and true
# => ** (BadBooleanError) expected a boolean on left-side of "and", got: 0

0 && true
# => true
```
