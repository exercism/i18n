# Вказівки

Ми керуємо ексклюзивним кінотеатром.
Щоб потрапити на сеанс, люди мають придбати річний абонемент, а далі можуть відвідувати сеанси безкоштовно.

Наш кінотеатр веде журнал відвідувань.
Ми хочемо скористатися цим журналом, щоб відстежити, які члени клубу використали свій річний абонемент цього місяця.
Ми також хочемо отримати інформацію про віковий склад наших відвідувачів.
Ми розуміємо, що для цих цілей можна використати множини.

## Множини

Множина - ідеальний тип даних для зберігання таких даних.

Множина - це тип даних, який використовують для зберігання різних, унікальних значень у довільному порядку.
Різні та унікальні означає, що елемент або є в множині, або ні; на відміну від масиву, він не може бути в множині кілька разів.
Множини зазвичай невпорядковані: якщо ми перелічимо елементи множини, порядок може відрізнятися від того, у якому їх додавали, або навіть від того, який ми отримали минулого разу!

Фундаментальна властивість множин - перевірка належності: можливість перевірити, чи містить множина елемент.
Перевірка належності лежить в основі майже всіх застосувань множини.

Go не надає вбудованого типу даних для множини.
Часто замість множини використовують `map[<type>]struct{}` або `map[<type>]bool`; подібно до множини, `map` дозволяє додавати різні, унікальні елементи й підтримує перевірку належності.

## 1. Місце для зберігання інформації про відвідувачів

Щоб відстежувати відвідуваність і віковий склад, ми хочемо використати множину.

Ми не хочемо писати окремі множини для імен і віку; натомість можна використати узагальнену множину для обох.
Визначимо тип `Set` як `map[T comparable]struct{}` для зберігання відвідувачів.
Напишемо функцію `NewSet[T comparable]()`, яка повертає порожню `Set[T]`.

```go
names := NewSet[string]()
```

## 2. Відстеження відвідувачів

Тепер ми готові записати інформацію про відвідувачів.

Напишемо метод `Add[T]()`, який додає елемент до множини.

```go
names := NewSet[string]()
names.Add("Alice")
```

## 3. Перевірка відвідувачів

Тепер, коли в нас є множина відвідувачів, ми можемо перевірити, чи прийшли конкретні члени клубу та вікові групи.
Напишемо метод `Contains[T](element)`, який повертає, чи є член клубу або вікова група в `Set`.

```
names := NewSet[string]()
names.Add("Alice")
names.Contains("Alice")
// => true
names.Contains("Bob")
// => false
```

## 4. Порівняння відвідувачів

Минув ще один місяць, і в нас є нова `Set` вікових груп.
Наш маркетинговий менеджер хоче знати, чи нові релізи цього місяця змінили віковий склад відвідувачів.
Напишемо метод `Equals[T](other)`, який визначає, чи дві множини мають однакові елементи.

```go
agesOne := NewSet[int]()
names.Add(25)

agesTwo := NewSet[int]()
names.Add(25)

agesOne.Equals(agesTwo)
// => true

agesThree := NewSet[int]()
names.Add(35)

agesOne.Equals(agesThree)
// => false
```
