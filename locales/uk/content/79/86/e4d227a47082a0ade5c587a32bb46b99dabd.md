# Встановлення

[Godot Engine][godot-engine] використовується для запуску коду GDScript.
Godot Engine працює на Windows, Linux, macOS та Android.



## Встановлення Godot Engine

Godot Engine можна завантажити безпосередньо з [вебсайту Godot Engine][download].
Завантаження містить один виконуваний файл, назва якого відповідає версії Godot Engine.
Цей файл потрібно перейменувати на `godot` і розмістити в одній із тек `$PATH`.
Після завершення встановлення можна перевірити, чи CLI встановлено успішно, виконавши в терміналі таку команду:

```bash
godot --version
```

У цьому треку використовується Godot версії 4.7.2.

[godot-engine]: https://godotengine.org/
[download]: https://godotengine.org/download/
