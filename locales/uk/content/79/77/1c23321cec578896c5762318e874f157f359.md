# Вступ

## Порівняння чисел

У JavaScript числа можна порівнювати за допомогою таких операторів відношення та рівності.

| Порівняння              | Оператор  |
| ----------------------- | --------- |
| Більше ніж              | `a > b`   |
| Більше або дорівнює     | `a >= b`  |
| Менше ніж               | `a < b`   |
| Менше або дорівнює      | `a <= b`  |
| (Строга) рівність       | `a === b` |
| Не (строга) рівність    | `a !== b` |

Результат порівняння завжди є булевим значенням (англ. Boolean), тобто або `true`, або `false`.

```javascript
1 < 3;
// => true

2 !== 2;
// => false

1 === 1.0;
// => true
// All numbers are floating-points, so this is different syntax for
// the exact same value.
```

## Порівняння рядків

У JavaScript наведені вище оператори порівняння можна також застосовувати до рядків тексту (англ. string).
У цьому разі застосовується словниковий (лексикографічний) порядок.
Список точного порядку всіх символів можна знайти [тут][utf-16-list].

```javascript
'Apple' > 'Pear';
// => false

'a' < 'above';
// => true

'a' === 'A';
// => false
```

## Строга рівність

Можна замислитися, чому для перевірки рівності в JavaScript використовують аж три знаки рівності.
`===` позначає перевірку на _строгу рівність_: це означає, що перетворення типів не виконується, а значення різних типів завжди нерівні.

```javascript
'3' === 3;
// => false
// The value on the left has type string, the value on the right has type number.

1 === 1n;
// => false
// The value on the left has type number, the value on the right has type bigint.
```

Для перевірки рівності в JavaScript рекомендовано використовувати `===` та `!==`.

Існують також `==` і `!=`, які позначають перевірку на _нестрогу рівність_.
Їх краще уникати, бо перед порівнянням вони виконують неявне перетворення типів.
Результати в таких випадках важко передбачити, і часом вони не такі, як можна очікувати.

```javascript
0 == false;
// => true
```
