# Вказівки

Знову вітаємо, Agent Double-Null0111.

Сили UMBRA знову активізувалися, і саме нам належить зірвати їхній черговий план.
Наш розвідувальний відділ повідомляє, що ті Minions планують підірвати смердючу бомбу на губернаторському балу.

Оскільки Minions такі незграбні, вони часто випадково зводять смердючі бомби у своїх лабораторіях та офісах.
А оскільки вони постійно забувають, як знешкоджувати свої смердючі бомби, вони впровадили систему, яка генерує вказівки для знешкодження, де перелічено порядок, у якому потрібно перерізати дроти, виходячи з ідентифікаційного номера бомби.

Наше завдання - написати код, який дозволить знешкодити смердючу бомбу на балу, перш ніж вона вибухне.

## 1. Напишіть замикання, яке міняє місцями два дроти

На кожній смердючій бомбі є три дроти різних кольорів.
Напишіть замикання, яке приймає кортеж `(String, String, String)` і повертає кортеж, у якому перші два елементи поміняно місцями.
Присвойте це замикання імені `flip`.

Важливо зазначити, що тип має бути `ChangeClosure` (або sendable-типом); визначення типу наведено у файлі-заготовці.
Інакше код не скомпілюється.

```swift
flip(("red", "yellow", "blue"))
// Returns ("yellow", "red", "blue")
```

## 2. Напишіть замикання, яке обертає дроти

Напишіть замикання, яке приймає кортеж `(String, String, String)` і повертає кортеж, у якому порядок дротів обернуто вліво.
Присвойте це замикання імені `rotate`.

Важливо зазначити, що тип має бути `ChangeClosure` (або sendable-типом); визначення типу наведено у файлі-заготовці.

```swift
rotate(("red", "yellow", "blue"))
// Returns ("yellow", "blue", "red")
```

## 3. Реалізуйте генератор перемішування дротів

Щоб визначити порядок, у якому потрібно перерізати дроти смердючої бомби, потрібно реалізувати функцію, яка генерує належну функцію перемішування на основі ідентифікаційного номера смердючої бомби.

Реалізуйте функцію:

```swift
makeShuffle(
  flipper: @escaping ((String, String, String)) -> (String, String, String),
  rotator: @escaping ((String, String, String)) -> (String, String, String)
) -> ([UInt8], (String, String, String)) -> (String, String, String)
```

яка приймає як вхідні дані замикання, що міняє місцями два дроти, і замикання, що обертає три дроти, а повертає замикання.
Це повернене замикання приймає ідентифікаційний номер смердючої бомби й порядок трьох дротів, а потім обчислює порядок, у якому дроти потрібно перерізати.
Ідентифікаційний номер складається з восьми бітів, і кожен біт визначає, чи потрібно поміняти дроти місцями, чи обернути їх.

Для кожного біта в ідентифікаційному номері, починаючи з найправішого, потрібно застосувати замикання `flipper` до кортежу дротів, якщо біт дорівнює 0, і застосувати замикання `rotator`, якщо він дорівнює 1, отримуючи новий стан дротів.
Після того як відповідні замикання застосовано для всіх восьми бітів ідентифікаційного номера, кінцевий стан дротів - це той порядок, у якому їх потрібно перерізати.

```swift
let shuffler = makeShuffle(flipper: flip, rotator: rotate)
// Returns ([UInt8], (String, String, String)) -> (String, String, String)
shuffler([1, 0, 0, 1, 1, 0, 1, 1], ("red", "yellow", "blue"))
// Returns ("red", "blue", "yellow")
```
