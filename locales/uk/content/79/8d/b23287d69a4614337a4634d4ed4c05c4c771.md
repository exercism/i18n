# Підказки

## Загальне

- Можливо, ми захочемо створити DSL на основі списків тегів і записів, ось так:

  ```roc
  my_graph =
      Graph.create([
          Title("My Graph"),
          Node("a", { color: Green }),
          Node("b", { color: Blue }),
          Edge("a", "b", { style: Dotted }),
      ])
  ```

- Або, можливо, нам більше до вподоби DSL на основі ланцюжків викликів функцій, ось так:

  ```roc
  my_graph =
      Graph.create()
          .with_title("My Graph")
          .add_node("a", Attr.create().with_color(Green))
          ...
  ```

  А може, у нас зовсім інший план?
  Сміливо берімося!

- Водночас DSL зазвичай кращий, якщо він зрозумілий, лаконічний і не надто несподіваний (наприклад, функція `minus` призначена для віднімання, а не для побудови ребра між двома вузлами, як у `node("a") - node("b")`).
