# Про

У Common Lisp неправду представляють порожній список `()` або символ `nil`.
Ці значення можна записати з апострофом або без нього.

```lisp
;; Equivalent False Values
()   ; => NIL
nil  ; => NIL
'()  ; => NIL
'nil ; => NIL
```

Усі інші значення в Lisp представляють правду.
Існує також спеціальний символ-константа `t`, який завжди дорівнює `t` (а отже, завжди представляє правду).

```lisp
;; Some Different True Values
42                        ; => 42
"this statement is false" ; => "this statement is false"
t                         ; => T
't                        ; => T
```
