# Інструкції

У цій вправі ми організовуємо гонки між різними типами радіокерованих машин.
Кожна машина має власні характеристики й бере участь у багатьох різних трасах у гонках протягом сезону турніру.

~~~~exercism/note
Функції в цій вправі оголошено у вихідному файлі C із наданими сигнатурами.
Код мовою асемблера x86-64 має відповідати цим специфікаціям.
~~~~

## 1. Створіть радіокеровану машину

Уже визначено структуру `car_t`, яка представляє радіокеровану машину:

```c
struct car_t {
    char name[10];
    int16_t speed;
    float battery;
};
```

Щоб мати змогу створити радіокеровану машину, визначте функцію `new_car` мовою асемблера x86-64.
Поле `battery` завжди починається зі значення `100.0`.

```c
struct car_t new_car(short speed, const char name[]);
```

## 2. Створіть нову трасу

Траси представлено структурою `track_t`:

```c
struct track_t {
    enum surface_t surface;
    size_t distance;
};
```

`enum surface_t` зберігає різні типи покриття для траси:

```c
enum surface_t {
    ASPHALT,
    SAND,
    ICE,
    CLAY
};
```

Щоб мати змогу створити нову трасу, визначте функцію `new_track` мовою асемблера x86-64.

```c
struct track_t new_track(enum surface_t surface, size_t distance);
```

## 3. Створіть гоночну подію

У кожній гонці беруть участь до 6 машин, які проїжджають визначену кількість кіл трасою.
Гонки представлено структурою `race_t`:

```c
struct race_t {
    struct track_t track;
    uint8_t num_of_laps;
    struct car_t cars[6];
    uint8_t num_of_running_cars;
};
```

Визначте функцію `new_race` мовою асемблера x86-64.
Спочатку для гонки немає підтверджених машин-учасниць:

```c
struct race_t new_race(struct track_t track, uint8_t num_of_laps);
```

## 4. Підтвердьте участь машини в гонці

Коли власник машини просить, щоб вона взяла участь у гонці, її участь підтверджують, лише якщо список ще не заповнений.

Визначте функцію `add_participant` мовою асемблера x86-64.
Якщо в гонці є місце ще для одного учасника, машину додають до списку, оновлюючи лічильник, і її участь підтверджують.
Інакше організатори гонки повинні повідомити власника машини, що цього разу вона не може взяти участь.

```c
bool add_participant(struct race_t *race, struct car_t car);
```

## 5. Створіть турнір

Гонки, заплановані на сезон, зберігають у структурі `tournament_t`:

```c
struct tournament_t {
    struct race_t races[20];
    size_t num_of_races;
};
```

Визначте функцію `add_race` мовою асемблера x86, щоб додати гонку до масиву турніру й також оновити його лічильник.
Можна вважати, що в масиві `races` завжди буде достатньо місця для нової гонки.

```c
void add_race(struct tournament_t *tournament, struct race_t race);
```
