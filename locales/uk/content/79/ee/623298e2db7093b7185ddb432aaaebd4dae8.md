# Додаток до інструкцій

## Формати вихідних даних

Функція `treeFromTraversals` має повертати обʼєкт із трьома властивостями:

- `value`: значення поточного вузла
- `left`: обʼєкт, що містить лівого нащадка вузла
- `right`: обʼєкт, що містить правого нащадка вузла

```javascript
{
    value: 'a',
    left: { value: 'i', left: {}, right: {} },
    right: { value: 'x', left: {}, right: {} },
}
```

Якщо дерево порожнє, потрібно повернути порожній обʼєкт.
