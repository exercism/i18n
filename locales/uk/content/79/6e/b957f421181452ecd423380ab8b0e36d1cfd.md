# Інструкції

Відділ заявок компанії Isaacs Asteroid Exploration Co. доручив нам поліпшити продуктивність їхньої системи реєстрації прав на ділянки.

Щоразу, коли новий астероїд готовий до освоєння, спекулянтів запрошують заявити свої права на ділянку землі. Землю астероїда поділено на ділянки з чотирма сторонами. Спекулянти заявляють права на землю, вказуючи її розміри.

Наша мета - розробити продуктивну систему, яка впорається з напливом охочих, що раніше призводив до падіння сайту.

Одиниця виміру - 100 метрів, але в цих завданнях її можна не враховувати.

## 1. Визначте ділянку

Завершіть реалізацію структури `Plot`, що складається з 4 структур координат, які вона приймає у своєму конструкторі.

## 2. Спекулянти можуть заявити свої права, указавши ділянку, визначену її розмірами

Реалізуйте метод `ClaimsHandler.StakeClaim()`, щоб дозволити реєструвати заявку.

Реалізуйте метод `ClaimsHandler.IsClaimStaked()`, щоб визначати, чи заявку вже зареєстровано.

```csharp
var ch = new ClaimsHandler();
ch.StakeClaim(new Plot(new Coord(1,1), new Coord(2,1), new Coord(1,2), new Coord(2,2)));
ch.IsClaimStaked(new Plot(new Coord(1,1), new Coord(2,1), new Coord(1,2), new Coord(2,2)));
// => true
```

## 3. Перевірте, чи поточна заявка збігається з останньою.

Реалізуйте метод `ClaimsHandler.IsLastClaim()`, щоб порівнювати поточну заявку з попередньою.

```csharp
var ch = new ClaimsHandler();
ch.StakeClaim(new Plot(new Coord(1,1), new Coord(2,1), new Coord(1,2), new Coord(2,2)));
ch.IsLastClaim(new Plot(new Coord(1,1), new Coord(2,1), new Coord(1,2), new Coord(2,2)));
// => true
```

## 4. Знайдіть заявлену ділянку з найдовшою стороною для дослідницьких цілей

Реалізуйте метод `ClaimsHandler.GetClaimWithLongestSide()`, щоб переглянути всі зареєстровані заявки та повернути ділянку з найдовшою стороною. Дані координат у ділянці гарантовано утворюють суміжну прямокутну форму.

```csharp
var ch = new ClaimsHandler();
ch.StakeClaim(new Plot(new Coord(1,1), new Coord(2,1), new Coord(1,2), new Coord(2,2)));
ch.StakeClaim(new Plot(new Coord(10,1), new Coord(20,1), new Coord(10,2), new Coord(20,2)));
ch.GetClaimWithLongestSide();
// => new Plot(new Coord(1,1), new Coord(20,1), new Coord(1,2), new Coord(2,2))
```
