# Підказки

## Загальне

- `accessors` надає автоматично створені гетери `slot>>`, сетери `>>slot` та оновлювачі `change-slot`.
- Сетери та `change-slot` *змінюють* кортеж. Спочатку викличте `clone`, якщо потрібне недеструктивне оновлення.

## 1. Визначте кортеж `player`

- Синтаксис слота: `{ name initial: value }` всередині `TUPLE: …  ;`.
- Слоти без `initial:` мають типове значення `f`.

## 2. Представте гравця

- `name>>` читає слот `name`.
- `unless*` з [`kernel`][kernel] - це ідіома «типове значення, якщо `f`».

## 3. Оживіть полеглого гравця

- `health>>` читає слот; `zero?` з [`math`][math] перевіряє, чи дорівнює нулю.
- Створіть нового гравця за допомогою `clone`, а потім `100 >>health` і `100 >>mana`.
- У випадку «ще живий» поверніть `f`.

## 4. Отримайте шкоду

- `change-health` приймає квотацію `( old-health -- new-health )`.
- Квотація fry `'[ _ - 0 max ]` (з `max` із [`math.order`][math.order]) дає змогу «відняти захоплену шкоду й обмежити нулем».
- Не забудьте викликати `clone` перед зміною.

[math]: https://docs.factorcode.org/content/vocab-math.html
