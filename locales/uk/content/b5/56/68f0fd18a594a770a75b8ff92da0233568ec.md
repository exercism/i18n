# Вступ

Ініціалізатори обʼєктів виступають альтернативою конструкторам. Синтаксис показано нижче. Ми надаємо розділений комами список пар імʼя-значення, у яких імʼя та значення розділені знаком `=`, у фігурних дужках:

```csharp
public class Person
{
    public string Name;
    public string Address;
}

var person = new Person{Name="The President", Address = "Élysée Palace"};
```

Колекції також можна ініціалізувати в такий спосіб. Зазвичай це роблять за допомогою списків, розділених комами, як показано тут:

```csharp
IList<Person> people = new List<Person>{ new Person(), new Person{Name="Joe Shmo"}};
```

Словники використовують такий синтаксис:

```csharp
IDictionary<int, string> numbers = new Dictionary<int, string>{ [0] = "zero", [1] = "one"...};

// or

IDictionary<int, string> numbers = new Dictionary<int, string>{ {0, "zero" }, {1,  "one"}...};
```
