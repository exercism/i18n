# Підказки

## 1. Обчисліть значення будь-якої карти

- Функція `ParseCard` повинна приймати рядок тексту (англ. string) `card` (наприклад, `ace`) і повертати його значення (наприклад, 11).
- Використайте велику [конструкцію `switch`][switch_statement] для змінної `card`.
- Короля, даму, валета і 10 можна обробити одним випадком.
- У конструкції `switch` може бути випадок `default`. У будь-якому разі функція повинна повертати `0` для невідомих карт.

## 2. Реалізуйте логіку рішень для першого ходу

- Скористайтеся функцією `ParseCard`, щоб визначити значення кожної карти.
- Обчисліть рахунок гравця, додавши значення двох карт гравця
- Можна використати велику [конструкцію `switch`][switch_statement] для рахунку гравця (можливо, з вкладеними умовними конструкціями `if` за рахунком дилера в деяких випадках).
- Або ж можна розрізняти окремі категорії рахунку гравця (скажімо, «малі руки» з рахунком менше 12, «середні руки» з рахунком у діапазоні 12..20 і «великі руки» з рахунком більше 20) і написати окремі функції для всіх (або деяких) цих категорій.

[switch_statement]: https://golang.org/ref/spec#Switch_statements
