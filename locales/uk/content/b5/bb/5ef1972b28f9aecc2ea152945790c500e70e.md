# Інструкції

Проєкт радіокерованого автомобіля, який ми започаткували у вправі `classes`, пройшов добре (вітаємо!), і завдяки низці нещодавніх спонсорських угод у бюджеті є гроші на вдосконалення.

Частину бюджету спрямували на телеметрію.

Щоб догодити спонсорам, на автомобіль встановили панель, яка показує імена спонсорів, поки він їде по трасі.

Зауважмо, що поява цих новомодних технологій різко скоротила час роботи батареї автомобіля.

## 1. Додайте радіокерованому автомобілю можливість показувати імена спонсорів

Реалізуйте `SetSponsors()`, щоб вона приймала одне або кілька імен спонсорів і зберігала їх на автомобілі.

Зауважмо, що аргумент методу `SetSponsors()` гарантовано не буде `null`.

Реалізуйте `DisplaySponsor()`, щоб показувати вибраного спонсора. Перший переданий спонсор має `sponsorNum` 0, другий - 1, і так далі.

```csharp
var car = RemoteControlCar.Buy();
car.SetSponsors("Exercism", "Walker Industries", "Acme Co.");
var sp2 = car.DisplaySponsor(sponsorNum: 1);
// => "Walker Industries"
```

## 2. Отримайте дані телеметрії автомобіля

Реалізуйте метод `RemoteControlCar.GetTelemetryData()`.

`GetTelemetryData()` має надавати відсоток заряду батареї та подолану відстань у метрах через параметри `out`.

`GetTelemetryData()` має повертати `false`, якщо аргумент serialNum менший за попередньо отримане значення. (Тут є проблема з кількома вузлами телеметрії, які беруть участь). У цьому випадку `serialNum` буде встановлено на найбільший попередній `serialNum`, а як відсоток заряду батареї, так і подолані метри буде встановлено на `-1`. Якщо виклик успішний, `serialNum` залишається без змін.

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
int serialNum = 4;
car.GetTelemetryData(ref serialNum, out int batteryPercentage, out int distanceDrivenInMeters);
// => true, 4L, 80, 4

serialNum = 1;
car.GetTelemetryData(ref serialNum, out batteryPercentage, out distanceDrivenInMeters);
// => false, 4L, -1, -1
```

## 3. Додайте функціональність, щоб система телеметрії могла отримувати витрату заряду на метр

Реалізуйте метод `TelemetryClient.GetBatteryUsagePerMeter()`.

Він викликатиме `RemoteControlCar.GetTelemetryData()`. Якщо `GetTelemetryData()` повертає `false` або автомобіль не їздив, то ця процедура має повернути «no data». Якщо `GetTelemetryData()` повертає `true`, то має бути повернуто повідомлення такого вигляду: «usage-per-meter=BATTERY-USAGE-PER-METER». Де розрахунок такий: (100 - поточний відсоток заряду батареї), поділене на подолану на цей момент відстань у метрах.

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
var tc = new TelemetryClient(car);
int serialNum = 4;
tc.GetBatteryUsagePerMeter(serialNum);
// => "usage-per-meter=5"

serialNum = 1;
tc.GetBatteryUsagePerMeter(serialNum);
// => "no data"
```
