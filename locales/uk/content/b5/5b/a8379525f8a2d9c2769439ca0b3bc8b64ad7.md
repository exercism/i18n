# Докладніше

Haxe підтримує рефлексію типів і полів під час виконання. Щоб правильно використовувати рефлексію, потрібно розуміти, які операції підтримуються, а які ні. Через динамічну природу рефлексії це не завжди можна визначити під час компіляції.

API рефлексії складається з двох класів:

- `Reflect`: легкий API, який найкраще працює з анонімними структурами й має обмежену підтримку класів.
- `Type`: потужніший API для роботи з класами та переліками.

Доступні методи докладно описано в API для [Reflect][reflect] і [Type][type].

У наступному прикладі ми використовуємо цільову платформу JavaScript:

```haxe
class Main {
  public static function main() {
    trace(Type.resolveClass("Main"));
  }
}

// This outputs
// class Test { static main() { console.log("Test.hx:3:",$hxClasses["Test"]); } }
```

[reflect]: https://api.haxe.org/Reflect.html
[type]: https://api.haxe.org/Type.html
