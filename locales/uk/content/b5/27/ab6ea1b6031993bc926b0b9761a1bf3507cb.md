# Інструкції

Настав день, на який ми так довго чекали, і тепер ми з гордістю володіємо чудовою фермою в Альпах.

Ми досі не любимо прокидатися надто рано, щоб нагодувати своїх корів.
Оскільки ми чудові інженери, ми будуємо дозатор корму `FEED-M-ALL`.

Аби завершити проєкт, залишилося написати фрагмент коду, який обчислює кількість корму, що має дістатися кожній корові.
Важливо, щоб кожна корова отримала однакову кількість, адже треба уникати конфліктів.
Корови дуже чутливі.

На щастя, нам не потрібно самостійно виводити всі формули для обчислення кількості корму.
Ми використовуємо якусь загадкову зовнішню бібліотеку, яку знайшли в інтернеті.
Вона має зробити корів найщасливішими.
Бібліотека надає клас, який реалізує такий інтерфейс.
Ми будемо покладатися на це у коді, який пишемо самі.

```crystal
class FodderCalculator
  def fodder_amount! : Number 
  end

  def fattening_factor! : Number
  end
end
```

Працюючи над кодом, ми вдосконалимо обробку помилок, щоб зробити її надійнішою і такою, яку потім буде легше налагоджувати в повсякденному житті на фермі.

## 1. Розділіть корм порівну

Насамперед зосередимося на написанні коду, потрібного для обчислення кількості корму на одну корову.

Реалізуйте метод `TheFarm.divide_food`, який приймає як аргументи обʼєкт `FodderCalculator` і кількість корів (ціле число).
*У цьому завданні вважаємо, що передана кількість корів завжди більша за нуль.*
Метод має повернути кількість корму на одну корову.

Щоб виконати обчислення, спершу треба отримати загальну кількість корму для всіх корів.
Для цього викликаємо метод `fodder_amount!` і передаємо кількість корів.
Крім того, потрібен коефіцієнт, на який цю кількість треба помножити.
Цей коефіцієнт отримуємо, викликавши метод `fattening_factor!`.
Маючи ці два значення та кількість корів, тепер можемо обчислити кількість корму на одну корову (як `float64`).

Якщо один із викликаних методів повертає помилку, виконання має зупинитися й повернути `0`.

```crystal
fodder_calculator = FodderCalculator.new(50, 1.5)
TheFarm.divide_food(fodder_calculator, 5)
# => 15.0

fodder_calculator = FodderCalculator.new(50, nil)
TheFarm.divide_food(fodder_calculator, 5)
# => 0
```

## 2. Перевірте кількість корів

Працюючи над першим завданням, ми зрозуміли, що зовнішня бібліотека, яку ми використовуємо, не така якісна, як здавалося.
Наприклад, вона не вміє належно обробляти некоректні вхідні дані.
Ми хочемо обійти це обмеження, додавши перевірку вхідного значення у власному коді.

Напишіть функцію `TheFarm.validate_input_and_divide_food` з тією самою сигнатурою, що й `TheFarm.divide_food` вище.

- Якщо передана кількість корів більша за 0, функція має викликати `TheFarm.divide_food` і повернути результат цього виклику.
- Якщо кількість корів дорівнює 0 або менша, функція має згенерувати помилку з повідомленням `"Number of cows must be greater than 0"`.

```crystal
TheFarm.validate_input_and_divide_food(fodderCalculator, 5)
# => 15

TheFarm.validate_input_and_divide_food(fodderCalculator, -2)
# Error: Number of cows must be greater than 0
```

## 3. Покращте обробку помилок

Перевірка кількості корів перед передаванням була слушним кроком, але нас не зовсім тішить неконкретне повідомлення про помилку.
Ми вирішуємо зробити краще й створюємо власний клас помилки `InvalidCowsError`.

Власна помилка має зберігати кількість корів (`Int32`) і власне повідомлення (`String`), а метод `Expection` має серіалізувати дані в такому форматі:
```txt
{number of cows} cows are invalid: {custom message}
```

Озброївшись власною помилкою, реалізуйте функцію `TheFarm.validate_number_of_cows`, яка приймає кількість корів як ціле число й повертає помилку (або nil).

- Якщо кількість корів менша за 0, функція повертає `InvalidCowsError` з власним повідомленням `"there are no negative cows"`.
- Якщо кількість корів дорівнює 0, функція повертає `InvalidCowsError` з власним повідомленням `"no cows don't need food"`.
- В іншому разі функція повертає `nil`, що означає, що перевірка успішна.

```crystal
TheFarm.validate_number_of_cows(5)
# => nil

TheFarm.validate_number_of_cows(-5)
# => InvalidCowsError: -5 cows are invalid: there are no negative cows
```

Після нелегкої роботи зі створення цієї функції перевірки ми помічаємо, що вже вечір, і залишаємо робоче місце, щоб помилуватися заходом сонця над горами.
А додавання нової функції перевірки до коду залишаємо на інший день.
