# Вступ

## Обʼєкти

Якщо скористатися термінологією з інших мов, JSON-**обʼєкт** - це «хеш», «мапа» або «словник».

JSON визначає _обʼєкт_ так:

> Обʼєкт - це невпорядкована множина пар **імʼя**/**значення**.
> Обʼєкт починається з `{` лівої фігурної дужки й закінчується `}` правою фігурною дужкою.
> Після кожного _імені_ йде `:` двокрапка, а пари _імʼя/значення_ розділяються `,` комою.

_Імʼя_ **має бути рядком тексту** (англ. string).
Інше слово для _імені_ - _ключ_.

_Значення_ може бути будь-якого типу JSON.
Різні _значення_ в одному обʼєкті можуть мати різні типи, як у цьому прикладі.

<!-- prettier-ignore -->
```json
{
  "name": "Jane",
  "age": 42,
  "pets": ["cat", "fish"],
  "address": {"street": "123 Main St", "city": "Springfield"}
}
```

<!-- prettier-ignore-end -->

Зауважмо, що після _останньої_ пари ключ-значення **не повинно** стояти коми.

### Створення обʼєктів

Щоб зібрати пари імʼя/значення, використовуймо фігурні дужки.
Хоча імена мають бути рядками тексту, їх не обовʼязково брати в лапки, якщо імена **схожі на ідентифікатори** (складаються з буквено-цифрових символів і символу підкреслення та не починаються з цифри).

```jq
{name: "Jane", age: 42}
```

Цілком припустимо використовувати ключі, що не _схожі на ідентифікатори_.
Просто берімо їх у лапки.

```jq
{"first name": "Jane", "last name": "Lopez", age: 42}
```

Якщо імʼя є результатом виразу, то вираз **має** бути в дужках.

```sh
$ echo "Jane" | jq -Rc '{.: 42}'
# verbose error message ...

$ echo "Jane" | jq -Rc '{(.): 42}'
{"Jane":42}
```

### Індексація

Значення з обʼєкта дістають за допомогою **точкової нотації**.

```jq
{name: "Jane", age: 42} | .age    # => 42
```

Якщо до ключа не вдається звернутися як до ідентифікатора, скористаймося **нотацією з квадратними дужками**.

```jq
"name" as $key | {name: "Jane", age: 42} | .$key    # => error
"name" as $key | {name: "Jane", age: 42} | .[$key]  # => "Jane"
```

### Додавання та зміна пар ключ-значення

Щоб додати нову пару ключ-значення до масиву або оновити значення наявного ключа, використовуймо оператор присвоєння `=`, де з лівого боку стоїть вираз з індексом.

```jq
{name: "Jane", age: 42} | .sport = "tennis" | .age = 21
# => {
#      "name": "Jane",
#      "age": 21,
#      "sport": "tennis"
#    }
```

Оператор `+` _обʼєднує_ обʼєкти.

```jq
{Richard: 54} + {Jane: 42}
# => {
#      "Richard": 54,
#      "Jane": 42
#    }
```

### Видалення ключа

Щоб видалити ключ, скористаймося функцією `del`.
Вона повертає оновлений обʼєкт.

```jq
{name: "Jane", age: 42} | del(.age)   # => {"name": "Jane"}
```

Параметр функції `del` - це **вираз з індексом** (з точковою нотацією або нотацією з квадратними дужками), який вказує на ключ в обʼєкті.
`jq` називає його **виразом шляху**.
Просто передати рядок тексту недостатньо.

```jq
{name: "Jane", age: 42} | del(name)        # error: name/0 is not defined
{name: "Jane", age: 42} | del("name")      # error: Invalid path expression with result "name"
{name: "Jane", age: 42} | del(.name)       # OK
{name: "Jane", age: 42} | del(.["name"])   # OK
```

### Перевірка належності

- Щоб перевірити, чи містить обʼєкт ключ, скористаймося функцією `has`.

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ($example | has("name")),    # => true
    ($example | has("sport"))    # => false
  ```

- Щоб перевірити, чи є ключ в обʼєкті, скористаймося `in`.

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ("name"  | in($example)),    # => true
    ("sport" | in($example))     # => false
  ```

### Перелік усіх ключів

Щоб вивести список усіх ключів, скористаймося функцією `keys`.

```jq
{name: "Jane", age: 42} | keys   # => ["age", "name"]
```

Зауважмо, що `keys` _сортує_ ключі.
Щоб отримати ключі в початковому порядку, скористаймося `keys_unsorted`.

Немає рівнозначної функції, щоб перелічити всі _значення_.
Утім, фільтр `.[]` виводить значення обʼєкта як _потік_, і цей потік можна зібрати конструктором масиву `[...]`.

```jq
[{first: "Jane", last: "Lopez", status: "awesome!"} | .[]]
# => ["Jane", "Lopez", "awesome!"]
```

### Перебирання

- Функція `map_values(filter)` застосовує фільтр до кожного _значення_ в обʼєкті.

  ```jq
  {first: "Jane", last: "Lopez", status: "awesome!"}
  | map_values(ascii_upcase)
  # => {"first": "JANE", "last": "LOPEZ", "status": "AWESOME!"}
  ```

- Щоб перебрати обʼєкт, спершу треба перетворити його на масив обʼєктів ключ-значення.
  Саме це робить функція `to_entries`.

  ```jq
  {name: "Jane", age: 42} | to_entries'
  # => [
  #      {
  #        "key": "name",
  #        "value": "Jane"
  #      },
  #      {
  #        "key": "age",
  #        "value": 42
  #      }
  #    ]
  ```

  Тепер ми можемо скористатися функціями ітерації масивів, як-от `map`.

- Функція `from_entries` виконує зворотну дію: перетворює масив обʼєктів ключ-значення на обʼєкт.

  ```jq
  [
    {"key":"name", "value":"Jane"},
    {"key":"age", "value":42}
  ] | from_entries                  # =>{"name": "Jane", "age": 42}
  ```

- Щоб застосувати фільтр до _кожної_ пари ключ-значення в обʼєкті, скористаймося функцією `with_entries(filter)`.

  Наприклад, маючи обʼєкт, який зіставляє імʼя з віком, можна поміняти місцями ключі та значення так.

  ```jq
  {"Jane": 42, "Richard": 54}
  | with_entries({key: (.value | tostring), value: .key})
  ```

  виводить

  ```json
  {
    "42": "Jane",
    "54": "Richard"
  }
  ```

  `with_entries(filter)` - це те саме, що

  ```jq
  to_entries | map(filter) | from_entries
  ```
