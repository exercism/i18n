# Вступ

## Масиви

JSON визначає **масив** так:

> Масив - це впорядкована колекція значень.
> Масив починається з лівої квадратної дужки `[` і закінчується правою квадратною дужкою `]`.
> Значення розділяються комою `,`.

Масиви можуть містити нуль або більше значень _будь-якого типу_ JSON.
Елементи масиву не обовʼязково мають бути одного типу.

### Створення масивів

Використаймо квадратні дужки, щоб зібрати елементи в масив.

```jq
[1, 2, 3]
```

Елементи _потоку_ можна зібрати в масив, узявши його в квадратні дужки.

```jq
range(5)     # => a stream of 5 numbers
[range(5)]   # => the array [0, 1, 2, 3, 4]
```

### Розмір

Функція `length` повертає кількість елементів у масиві.

### Індексація та зрізи

Індексація масивів починається з нуля.

Щоб отримати елемент із масиву, використаймо вираз із квадратними дужками:
`.[2]` дає третій елемент.

Відʼємні індекси рахуються від кінця масиву:
`.[-1]` дає останній елемент, а `.[-2]` - передостанній.

**Зріз** - це підпослідовність масиву.
`.[10:15]` повертає 5 елементів, починаючи з індексу 10; кінцевий індекс _не включається_.

Є кілька зручних функцій:

- `first` дає перший елемент.
- `last` дає останній елемент.
- `nth(n)` дає елемент за індексом `n`.

### Перебирання

`jq` надає багато функцій, що покривають типові задачі ітерації:

- `map(expr)` повертає новий масив, у якому `expr` застосовується по черзі до кожного елемента.

  ```jq
  [1, 2, 3] | map(. * 10)    # => [10, 20, 30]

  ```

- `select(expr)` - це функція, яка застосовує `expr` до _одного значення_;
  якщо результат виразу - правда, то значення повертається;
  якщо результат - неправда, то _нічого_ не повертається, не `null`, а насправді нічого.

  Щоб застосувати це до масиву, поєднаймо його з `map`.

  ```jq
  [range(10)] | map(select(. % 2 == 0))    # => [0, 2, 4, 6, 8]
  ```

  Або ж застосуймо `select` до _потоку_ й зберімо результати.

  ```jq
  [range(10) | select(. % 2 == 0)]    # => [0, 2, 4, 6, 8]
  ```

- `any(condition)` і `all(condition)` повертають булеве значення (англ. Boolean) залежно від того, чи проходять умову будь-які або всі елементи масиву.

  ```jq
  [1, 2, 3, 4] | any(. > 4)    # false
  [1, 2, 3, 4] | any(. >= 4)   # true

  [1, 2, 3, 4] | all(. >= 4)   # false
  [1, 2, 3, 4] | all(. <= 4)   # true
  ```
