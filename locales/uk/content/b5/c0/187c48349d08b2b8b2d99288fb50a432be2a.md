# Інструкції

Ваше завдання - взяти список бомбардирів гри та порахувати, скільки голів забив кожен гравець.

`PlayerName` - це псевдонім типу для `String`, щоб код було легше читати та щоб відрізняти це використання `String` від інших використань `String`.

## 1. Підсумувати бомбардирів

Спершу реалізуйте `updateGoalCountForPlayer`, щоб ініціалізувати або збільшити лічильник голів гравця.
Потім реалізуйте функцію `aggregateScorers`, щоб порахувати, скільки голів забив кожен гравець, використовуючи `updateGoalCountForPlayer`.
Ця функція приймає `List PlayerName` (імена гравців, які забили голи; імена можуть повторюватися) і повертає `Dict PlayerName Int` з усіма гравцями зі списку та кількістю забитих ними голів.

```elm
aggregateScorers [ "Betty", "Cedd", "Betty" ]
--> Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ]
```

## 2. Прибрати незначущих гравців

Реалізуйте функцію `removeInsignificantPlayers`, щоб відфільтрувати гравців, які забили менше голів, ніж поріг.

```elm
removeInsignificantPlayers 2 (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> Dict.fromList [ ( "Betty", 2 ) ]
```

## 3. Скинути лічильник голів гравця

Реалізуйте функцію `resetPlayerGoalCount`, щоб скинути кількість забитих гравцем голів до нуля.

```elm
resetPlayerGoalCount "Cedd" (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 0 ) ]
```

## 4. Відформатувати кількість голів одного гравця

Реалізуйте функцію `formatPlayer`, щоб відформатувати кількість голів одного гравця як рядок тексту (англ. string). Якщо гравця немає в словнику, вважайте, що він забив нуль голів.

```elm
formatPlayer "Betty" (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> "Betty: 2"
```

## 5. Відформатувати кількість голів усіх гравців

Реалізуйте функцію `formatPlayers`, щоб відформатувати кількість голів усіх гравців як рядок тексту. Гравців потрібно впорядкувати за іменем.

```elm
formatPlayers (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> "Betty: 2, Cedd: 1"
```

## 6. Обʼєднати ігри

Реалізуйте функцію `combineGames`, яка рахує загальну кількість голів, забитих кожним гравцем в обох іграх.

```elm
combine Games
  (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
  (Dict.fromList [ ( "Betty", 2 ), ( "Mario", 3 ) ] )
--> Dict.fromList [ ( "Betty", 4 ), ( "Cedd", 1 ), ( "Mario", 3 ) ]
```
