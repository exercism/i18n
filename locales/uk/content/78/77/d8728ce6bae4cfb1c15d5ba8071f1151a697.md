# Інструкції

У цій вправі ми будемо писати код, щоб відстежувати масив мов програмування, які хочемо вивчати на Exercism.

На нас чекає шість завдань, і всі вони будуть повʼязані з масивами.

## 1. Створіть новий список

Щоб відстежувати мови, які ми хочемо вивчати, нам потрібно створити новий масив. Визначте привʼязку `newList`, що містить новий порожній масив.

```fsharp
newList
// => []
```

## 2. Визначте наявний список

Зараз у нас є аркуш паперу з переліком мов, які ми хочемо вивчати: F#, Clojure і Haskell. Визначте привʼязку `existingList`, щоб представити цей масив.

```fsharp
existingList
// => ["F#"; "Clojure"; "Haskell"]
```

## 3. Додайте нову мову до списку

Досліджуючи Exercism і знаходячи цікавіші мови, ми хочемо додавати їх до свого масиву. Реалізуйте функцію `addLanguage`, щоб додати нову мову на початок масиву.

```fsharp
addLanguage "TypeScript" ["JavaScript"; "CoffeeScript"]
// => ["TypeScript"; "JavaScript"; "CoffeeScript"]
```

## 4. Порахуйте мови у списку

Порахувати мови по одній незручно. Реалізуйте функцію `countLanguages`, щоб порахувати кількість мов у масиві.

```fsharp
countLanguages ["C#"; "Racket"; "Rust"; "Ruby"]
// => 4
```

## 5. Переверніть список

У якийсь момент ми розуміємо, що наш масив насправді впорядковано у зворотному порядку! Реалізуйте функцію `reverseList`, щоб перевернути масив.

```fsharp
reverseList ["Prolog"; "C"; "Idris"; "Assembly"]
// => ["Assembly"; "Idris"; "C"; "Prolog"]
```

## 6. Перевірте, чи список захопливий

Хоча ми любимо всі мови, F# посідає особливе місце в нашому серці. Тож масив мов викликає в нас справжнє захоплення, якщо:

- Перший елемент масиву - F#.
- Другий елемент масиву - F#, і масив містить або дві, або три мови.

Реалізуйте функцію `excitingList`, щоб перевірити, чи масив мов захопливий:

```fsharp
excitingList ["Nim"; "F#"]
// => true
```
