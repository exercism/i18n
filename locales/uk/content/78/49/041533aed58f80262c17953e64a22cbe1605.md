# Встановлення

Щоб працювати над вправами, нам знадобиться таке програмне забезпечення:

1. [`OPAM`, менеджер пакунків OCaml](https://opam.ocaml.org/)

   Про те, як встановити й налаштувати `OPAM` для своєї операційної системи, читайте в [Real World Ocaml, 2nd Ed.: Installation Instructions](https://dev.realworldocaml.org/install.html).

2. Компілятор OCaml

   Перегляньте список доступних версій:

   ```bash
   opam switch
   ```

   Якщо switch для OCaml 5.1 уже існує, можна або завантажити його командою `opam switch <switch-name>`, або створити новий switch командою:

   ```bash
   opam switch create exercism 5.4.0
   ```

   Назва `exercism` тут необовʼязкова, але давати імена своїм switch - гарна практика.

3. Встановіть розширені стандартні бібліотеки та бібліотеки для тестування

   Виконайте наступне, щоб встановити залежності, потрібні для цього треку:

   ```bash
   opam install base core_kernel ounit qcheck
   ```

   Деякі вправи використовують лише стандартну бібліотеку OCaml, а деякі - розширені бібліотеки від Jane Street під назвами Base і Core_kernel.
   Бібліотека для тестування називається OUnit, а деякі вправи додатково використовують бібліотеку QCheck для тестів на основі властивостей.
   Виконання наведеної вище команди встановить ці бібліотеки.

4. Встановіть і використовуйте інтерактивну оболонку (необовʼязково)

   Коротко про [Setting up and using `utop`](https://dev.realworldocaml.org/install.html):

   ```bash
   opam install utop
   ```

   Створіть новий файл з назвою `.ocamlinit` у своїй домашній директорії та додайте до нього такі рядки:

   ```ocaml
   #use "topfind";;
   #require "base";;
   open Base
   ```

5. Встановіть інструменти у VS Code (необовʼязково)

   Якщо ми працюємо у VS Code:
   - Встановіть сервер мови OCaml [звідси](https://github.com/ocaml/ocaml-lsp).
   - Встановіть розширення OCaml для VS Code [звідси](https://marketplace.visualstudio.com/items?itemName=ocamllabs.ocaml-platform), або знайдіть `OCaml Platform` від Ocaml Labs.
