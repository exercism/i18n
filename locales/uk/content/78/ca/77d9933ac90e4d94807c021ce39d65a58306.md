# Вступ

## Рядки тексту

Рядки тексту (англ. string) у Gleam - це незмінний текст, оточений подвійними лапками. Вони підтримують символи Unicode і можуть бути багаторядковими.

```gleam
let greeting = "Hello, Joe! 📞"

let multi_line_string = "one
two
three"
```

Рядки тексту можна поєднувати за допомогою оператора `<>`:

```gleam
let name = "Mike"
"Hello, " <> name <> "!"
// -> "Hello, Mike!"
```

Модуль [`gleam/string`][stdlib] зі стандартної бібліотеки надає функції для роботи з рядками тексту.

Рядки тексту можна зіставляти у виразах `case`:

```gleam
pub fn on_an_excellent_adventure(name: String) -> Bool {
  case name {
    "Bill" -> True
    "Ted" -> True
    _ -> False
  }
}
```

Якщо ми хочемо зіставити початок рядка тексту й присвоїти решту змінній, можна скористатися шаблоном оператора `<>`:

```gleam
pub fn profession(name: String) -> String {
  case name {
    "Dr " <> rest -> rest <> " is a doctor"
    _ -> "I'm not sure what " <> name <> " does"
  }
}
```

[stdlib]: https://hexdocs.pm/gleam_stdlib/gleam/string.html
