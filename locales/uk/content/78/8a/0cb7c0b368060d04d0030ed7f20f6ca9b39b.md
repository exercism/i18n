# Доповнення до вказівок

## Реалізація

Предмети представлено [записами](https://lfe.gitbooks.io/reference-guide/content/16.html), визначеними у `item.lfe`.
Використайте `item-weight`, щоб отримати вагу, та `item-value`, щоб отримати значення.

```
;; Create an item with weight=5, value=50
(set item (make-item weight 5 value 50))

;; Get the weight. Returns 5.
(item-weight item)

;; Get the value. Returns 50.
(item-value item)
```
