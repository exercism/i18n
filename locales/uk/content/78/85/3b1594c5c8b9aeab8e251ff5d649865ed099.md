# Додаток до інструкцій

## Callable

У PHP є поняття [callable](https://www.php.net/manual/en/language.types.callable.php).

Вони можуть набувати різних форм, але ми зосередимося на [анонімних функціях](https://www.php.net/manual/en/functions.anonymous.php).

Можна створити анонімну функцію у змінній і викликати її з параметрами:

```php
$double = function ($number) {
    return $number * 2;
};

$double(2); // returns 4
$double(4); // returns 8
```
