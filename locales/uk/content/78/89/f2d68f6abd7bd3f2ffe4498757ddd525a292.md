# Підказки

## Загальне

- Дерево - це рекурсивна структура даних, яка має два випадки:
  - `nil`: листковий вузол, який не має значення
  - `node(Left, Value, Right)`: звичайний вузол, який має значення, а також лівий і правий вузли
- Як для прямого, так і для симетричного обходу нам потрібно визначити правила, які опрацьовують ці два випадки для дерев
