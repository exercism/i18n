# Вступ

Багато програм потребують (псевдо)випадкових значень, щоб імітувати події реального світу.

Поширені знайомі приклади:

- Підкидання монети: випадкове значення з ('H', 'T').
- Кидання кубика: випадкове ціле число від 1 до 6.
- Перемішування колоди карт: випадковий порядок списку карт.
- Створення дерев і кущів у тривимірній графічній симуляції.

Генерування справді випадкових значень на компʼютері - напрочуд складна технічна задача, тому й існують також «псевдовипадкові» генератори.

~~~exercism/advanced
[Специфікація мови][spec] для JavaScript не навʼязує певної реалізації генерації випадкових чисел.
Усі провідні браузери та середовища виконання JavaScript реалізують PRNG (генератор псевдовипадкових чисел).
Оскільки ці числа не є криптографічно стійкими, їх ніколи не варто використовувати для чогось, що потребує справді випадкових або принаймні криптографічно стійких випадкових чисел, як-от генерації сертифікатів чи паролів або відповідних операцій.

Існує стандарт під назвою [Web Cryptography][rfc], який стандартизує інтерфейс для роботи з криптографією в JavaScript.
Його реалізовано [у браузерах][crypto-web], а також у середовищах виконання, як-от [Node.JS][crypto-node] та [Deno][crypto-deno].

Ця концепція не про Web Crypto і обмежується генерацією псевдовипадкових чисел.

[rfc]: https://www.w3.org/TR/webcrypto-2/
[spec]: https://tc39.es/ecma262/multipage/numbers-and-dates.html#sec-math.random
[crypto-web]: https://developer.mozilla.org/en-US/docs/Web/API/Crypto/getRandomValues
[crypto-node]: https://nodejs.org/api/webcrypto.html#cryptogetrandomvaluestypedarray
[crypto-deno]: https://docs.deno.com/api/web/~/Crypto

## Генерування випадкових чисел

У JavaScript ми можемо генерувати псевдовипадкові числа за допомогою функції [`Math.random()`][Math.random].
Вона повертає псевдовипадкове число з плаваючою комою від 0 (включно) до 1 (не включно).

Щоб отримати випадкове число від _min_ (включно) до _max_ (не включно), можна використати функцію приблизно такого вигляду:

```javascript
function getRandomInRange(min, max) {
  return min + Math.random() * (max - min);
}
getRandomInRange(4, 10);
// => 5.72
```

## Генерування випадкових цілих чисел

Щоб згенерувати випадкове ціле число, можна використати `Math.floor()` або `Math.ceil()`, щоб перетворити випадково згенероване число на ціле.

[why-randomness-is-hard]: https://www.malwarebytes.com/blog/news/2013/09/in-computers-are-random-numbers-really-random
[Math.random]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Math/random
