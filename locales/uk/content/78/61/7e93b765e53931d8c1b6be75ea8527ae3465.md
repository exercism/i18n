# Вступ

## Числа

У C# є два різні типи чисел:

- Цілі числа: числа, у яких немає цифр після десяткового розділювача (без дробової частини). Наприклад, `-6`, `0`, `1`, `25`, `976` і `500000`.
- Числа з плаваючою комою: числа, у яких після десяткового розділювача є нуль або більше цифр. Наприклад, `-2.4`, `0.1`, `3.14`, `16.984025` і `1024.0`.

Два найпоширеніші числові типи в C# - це `int` і `double`. `int` - це 32-бітне ціле число, а `double` - це 64-бітне число з плаваючою комою.

Арифметичні дії виконують за допомогою стандартних арифметичних операторів. Числа можна порівнювати за допомогою стандартних операторів порівняння чисел, а також операторів рівності (`==`) і нерівності (`!=`).

У C# є два типи числових перетворень:

1. Неявні перетворення: дані не втрачаються, і додатковий синтаксис не потрібен.
2. Явні перетворення: дані можуть втратитися, і потрібен додатковий синтаксис у вигляді _приведення типу_.

Оскільки `int` має меншу точність, ніж `double`, перетворення з `int` на `double` безпечне, а отже, є неявним. Однак перетворення з `double` на `int` може призвести до втрати даних, тому воно потребує явного перетворення.

```csharp
int softCool = 1358938113;
double notLost = 4.8151623;

// implicit cast: no loss of information
double macDebug = softCool;         // 1358938113.0

// explicit cast: possible loss of information 
int somethingLost = (int)notLost;   // 4
```

## Умовні конструкції

У цій вправі ми маємо виконувати логіку за певної умови. Найпоширеніший спосіб зробити це в C# - скористатися конструкцією `if/else`:

```csharp
int x = 6;

if (x == 5)
{
    // Execute logic if x equals 5
}
else if (x > 7)
{
    // Execute logic if x greater than 7
}
else
{
    // Execute logic in all other cases
}
```

Умова конструкції `if` має бути типу `bool`. У C# немає поняття _істинних_ значень.
