# Форматування рядка тексту

Окрім методу `String#%%`, поширений спосіб створення рядків тексту (англ. string) у Ruby - це [інтерполяція рядків](http://ruby-for-beginners.rubymonstas.org/bonus/string_interpolation.html). Наприклад:

```ruby
# Rather than:
"One for %%s, one for me." %% %{name_variable}

# Consider:
"One for #{%{name_variable}}, one for me."
```
