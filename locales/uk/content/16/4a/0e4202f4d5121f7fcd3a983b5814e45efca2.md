# Вступ

Багатьом програмам потрібні _(здавалося б)_ випадкові значення, щоб імітувати події реального світу.

До поширених, знайомих прикладів належать:
- Підкидання монети: випадкове значення з `('Heads', 'Tails')`.
- Кидок кубика: випадкове ціле число від 1 до 6.
- Перемішування колоди карт: випадковий порядок масиву карт.
- Створення дерев і кущів у тривимірній графічній симуляції.

Згенерувати на компʼютері _справді_ випадкові значення - [напрочуд складна технічна задача][truly-random], тому такі результати часто називають «псевдовипадковими».

На практиці добре спроєктована бібліотека, як-от модуль [`random`][random] зі стандартної бібліотеки Python, працює швидко, гнучко й дає результати, цілком достатні для більшості застосунків у моделюванні, симуляції та іграх.

У цьому короткому вступі ми покажемо чотири найуживаніші функції з цього модуля.
Радимо дослідити повну документацію [`random`][random], адже там багато інструментів і варіантів.

Перш ніж скористатися інструментами модуля `random`, його треба імпортувати:

```python
>>> import random

# Choose random integer from a range
>>> random.randrange(1000)
360

>>> random.randrange(-1, 500)
228

>>> random.randrange(-10, 11, 2)
-8

# Choose random integer between two values (inclusive)
>>> random.randint(5, 25)
22

```

Щоб не писати щоразу назву модуля, можна імпортувати конкретні функції за назвою:

```python
>>> from random import choice, choices

# Using choice() to pick Heads or Tails 10 times
>>> tosses = []
... for side in range(10):
...    tosses.append(choice(['H', 'T']))    

>>> print(tosses)
['H', 'H', 'H', 'H', 'H', 'H', 'H', 'T', 'T', 'H']


# Using choices() to pick Heads or Tails 8 times
>>> picks = []
... picks.extend(choices(['H', 'T'], k=8))
... print(picks)
['T', 'H', 'H', 'T', 'H', 'H', 'T', 'T']
```



## `randrange()` і `randint()`

Як видно з першого прикладу вище, функція `randrange()` має три форми:

1. `randrange(stop)` дає ціле число `n` таке, що `0 <= n < stop`
2. `randrange(start, stop)` дає ціле число `n` таке, що `start <= n < stop`
3. `randrange(start, stop, step)` дає ціле число `n` таке, що `start <= n < stop`,
    і `n` належить послідовності `start, start + step, start + 2*step...`

Для найпоширенішого випадку, коли `step == 1`, зручнішим і зрозумілішим може бути `randint(a, b)`.
Можливі результати `randint()` _включають_ верхню межу, тож `randint(a, b)` дає те саме, що й `randrange(a, b+1)`.



## `choice()` і `choices()`

Ці дві функції припускають, що ми починаємо з якоїсь [послідовності][sequence-types] або іншого контейнера.
Зазвичай це `list`, або, з певними обмеженнями, `tuple` чи `set` (_`tuple` незмінний, а `set` невпорядкований_).

Функція `choice()` повертає один елемент, вибраний випадково з заданої послідовності, а `choices()` повертає вказану кількість елементів (`k`), вибраних випадково з заданої послідовності.
У наведених вище прикладах ми припускали чесну монету з однаковою ймовірністю випадання орла чи решки, але можна вказати й вагові коефіцієнти.

Наприклад, якщо в торбині 10 червоних кульок і 15 зелених, і ми хочемо витягти одну навмання:


```python
>>> random.choices(['red', 'green'], [10, 15])
['red']
```
