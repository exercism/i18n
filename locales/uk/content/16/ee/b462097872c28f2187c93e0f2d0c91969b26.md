# Вступ

У Go `struct` складається з послідовності іменованих елементів, які називаються _полями_. Кожне поле має назву та тип.
Назва поля має бути унікальною в межах структури.
Структури можна порівняти з _класами_ в парадигмі обʼєктно-орієнтованого програмування.

## Визначення структури

Ми створюємо нову структуру за допомогою ключових слів `type` і `struct`, а також явно визначаємо назву та тип її полів.
Наприклад, ось ми визначаємо структуру `Shape`, яка зберігає назву фігури та її розмір:

```go
type Shape struct {
    name string
    size int
}
```

Назви полів у структурах дотримуються конвенції Go: поля, назва яких починається з малої літери, видимі лише коду в тому самому пакеті, а ті, назва яких починається з великої літери, видимі в інших пакетах.

## Створення екземплярів структури

Коли ми визначили `struct`, потрібно створити новий екземпляр, задавши поля за їхніми назвами в будь-якому порядку:

```go
s := Shape {
    name: "Square",
    size: 25,
}
```

Щоб прочитати або змінити поля екземпляра, звертаємося до них через крапку `.`:

```go
// Update the name and the size
s.name = "Circle"
s.size = 35
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 35
```

Поля, яким не присвоєно початкового значення, отримають нульове значення.
Наприклад:

```go
s := Shape{name: "Circle"}
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 0
```

Можна створити екземпляр типу `struct` і без назв полів, якщо визначити поля _в порядку_:

```go
s := Shape {
	"Oval",
	20,
}
```

Однак такий синтаксис вважається _крихким кодом_, бо він може зламатися, коли додають нове поле, особливо якщо це поле іншого типу.
У наступному прикладі ми додаємо до `Shape` ще одне поле:

```go
type Shape struct {
	name        string
	description string // new field 'description' added
	size        int
}

s := Shape{
    "Circle",
    20,
}
// Since the second field of the struct is now a string and not an int,
// the compiler will throw an error when compiling the program:
// Output: cannot use 20 (type untyped int) as type string in field value
// Output: too few values in Shape{...}
```

## Функції «New»

Іноді буває зручно мати функції, які допомагають нам створювати екземпляри структур.
За конвенцією такі функції зазвичай називають `New` або дають їм назви, що починаються з `New`. Але оскільки це звичайні функції, ми можемо дати їм будь-яку назву.
Вони можуть нагадувати конструктори в інших мовах, але в Go вони залишаються просто звичайними функціями.

У наступному прикладі одну з таких функцій `New` використано, щоб створити новий екземпляр `Shape` й автоматично встановити типове значення для `size` фігури:

```go
func NewShape(name string) Shape {
	return Shape{
		name: name,
		size: 100, //default-value for size is 100
	}
}

NewShape("Triangle")
// => Shape { name: "Triangle", size: 100 }

```

Використання функцій `New` має такі переваги:

* перевірка переданих значень
* обробка типових значень
* оскільки функції `New` часто оголошують у тому самому пакеті, що й структури, які вони ініціалізують, вони можуть ініціалізувати навіть приватні поля цих структур
