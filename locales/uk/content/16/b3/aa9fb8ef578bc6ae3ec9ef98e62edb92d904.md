# Вступ

Зазвичай функції приймають лише фіксовану кількість аргументів.
Однак якщо поставити `...` перед типом останнього параметра, функція зможе приймати будь-яку кількість аргументів у кінці.
Тоді останній параметр стає _варіативним параметром_.

```go
func sum(nums ...int) int {
    total := 0
    for _, n := range nums {
        total += n
    }
    return total
}
```

Усередині функції варіативний параметр - це зріз:

```go
sum(1, 2, 3)    // nums is []int{1, 2, 3}
sum(1, 2, 3, 4) // nums is []int{1, 2, 3, 4}
sum()           // nums is []int{}
```

Функція може мати неваріативні параметри перед варіативним.
Функція може мати щонайбільше один варіативний параметр, і він має бути останнім.

```go
func greet(greeting string, names ...string) {
    for _, name := range names {
        fmt.Printf("%s, %s!\n", greeting, name)
    }
}
```

## Розгортання зрізу

Щоб передати зріз у варіативний параметр, після нього ставимо `...`:

```go
nums := []int{1, 2, 3}
sum(nums...) // equivalent to sum(1, 2, 3)
```

`...` допустимий лише під час передачі зрізу варіативному параметру.
