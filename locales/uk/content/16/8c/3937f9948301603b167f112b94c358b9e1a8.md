# Підказки

## 1. Згенерувати випадкову планету

- Java не надає функції для випадкового вибору елемента з колекції.
- Памʼятаймо, що елемент масиву можна отримати за його індексом, який є цілим числом.

## 2. Згенерувати випадковий реєстраційний номер зорельота

- Клас `java.util.Random` надає метод для генерації випадкового `int` у діапазоні від 0 до заданого максимуму.

## 3. Згенерувати випадкову зоряну дату

- Метод класу `java.util.Random` для генерації випадкового `double` завжди повертає число в діапазоні від `0.0` до `1.0`.
