# Інструкції

Друг Йоганнес обожнює збирати саморобну апаратуру (DIY, тобто «зроби сам»).
Він щойно зібрав соковижималку і дуже нею захоплений.
Мета Йоганнеса - щоранку готувати свіжий сік.

У соковижималки Йоганнеса багато цікавих можливостей.
Наприклад, вбудована система вимірювання, яка показує, скільки соку в склянці.
Є в неї й таймер, який підказує, як довго працює машина.

Йоганнес не дуже добре програмує, але хоче написати програму для керування машиною.
Тож він і попросив допомогти.

## 1. Індикатор debug

У машини є індикатор debug. Це простий механізм: якщо машина має живлення, індикатор debug горить.
Програма запуститься, лише якщо індикатор debug горить.

Цей метод має бути методом класу з назвою `JuiceMaker`.

Визначте метод класу `JuiceMaker.debug_light_on?`, який повертає `true`.

```crystal
JuiceMaker.debug_light_on?
#=> true
```

## 2. Ініціалізація машини

Коли машина вмикається, має створюватися екземпляр класу з назвою `JuiceMaker`.
Машина повинна мати ініціалізований стан.
Ініціалізований стан має містити таку інформацію:

1. Чи працює машина. Коли машина вмикається, це значення має завжди бути `false`.
2. Кількість соку в склянці; це буде сенсор, який вимірюватиме кількість соку в склянці.

Визначте ініціалізований стан, який приймає кількість соку в склянці як параметр, і сконструюйте цей стан.
Ініціалізований стан має містити змінну екземпляра `@running`, встановлену в `false`, і змінну екземпляра `@fluid`, значення якої базується на аргументі, переданому під час ініціалізації класу.

```crystal
JuiceMaker.new(5)
#=> #<JuiceMaker:0x10f0b8 @running=false, @fluid=5>
```

## 3. Увімкнення машини

Машину можна вмикати й вимикати.
Потрібно визначити метод, який вмикає машину.
Коли машина вмикається, стан роботи має встановлюватися в `true`.

Визначте метод `JuiceMaker#start`, який вмикає машину.

```crystal
juice_maker = JuiceMaker.new(5)
juice_maker.start

juice_maker
#=> #<JuiceMaker:0x10f0b8 @running=true, @fluid=5>
```

## 4. Стан машини

Машина повинна вміти повідомляти свій стан.
Він має повертати `true`, якщо машина працює, і `false`, якщо машина не працює.

Визначте метод `JuiceMaker#running?`, який повертає стан машини.

```crystal
juice_maker = JuiceMaker.new(5)
juice_maker.start

juice_maker.running?
#=> true
```

## 5. Додавання соку

Машина може додавати сік у склянку.
Машина вміє визначати, скільки соку додано в склянку.
Але їй потрібна допомога, щоб дізнатися, скільки соку в склянці після додавання.

Визначте метод `JuiceMaker#add_fluid`, який приймає кількість доданого соку як параметр і оновлює кількість соку в склянці.

```crystal
juice_maker = JuiceMaker.new(5)
juice_maker.add_fluid(5)

juice_maker
#=> #<JuiceMaker:0x10f0b8 @running=false, @fluid=10>
```

## 6. Вимкнення машини

Машину можна вмикати й вимикати.
Потрібно визначити метод, який вимикає машину.
Цей метод викликатиметься лише тоді, коли машина працює.
Коли машина вимикається, стан роботи має встановлюватися в `false`.
Також машині потрібна допомога, щоб визначити, скільки соку в склянці після вимкнення.
Машина витрачає пʼять одиниць соку за хвилину.

Визначте метод `JuiceMaker#stop`, який приймає кількість хвилин роботи машини як параметр і повертає кількість соку в склянці після вимкнення машини.

```crystal
juice_maker = JuiceMaker.new(5)

juice_maker.start
juice_maker
#=> <JuiceMaker:0x10f0b8 @running=true, @fluid=5>

juice_maker.stop(1)
#=> #<JuiceMaker:0x10f0b8 @running=false, @fluid=0>
```
