# Загальне

## 1. Визначте узагальнений власний тип `TreasureChest`

- У посібнику з Elm є розділ про [власні типи][custom-types].
- Власний тип `TreasureChest` має лише один варіант.
- За ідіоматичним стилем Elm, коли власний тип має один варіант, варіант і тип мають однакову назву (у цьому випадку обидва називатимуться `TreasureChest`)

## 2. Визначте функцію `getTreasure`

- Існує [скорочений запис для деструктуризації власних типів з одним членом][single-member-custom-destructuring].
- Якщо потрібно освіжити знання, у посібнику з Elm є розділ про [Maybe][maybe].

## 3. Визначте функцію `multiplyTreasure`

- Можна використати круглі дужки, щоб відокремити визначення типу для функції-множника від решти визначення типу для `multiplyTreasure`
