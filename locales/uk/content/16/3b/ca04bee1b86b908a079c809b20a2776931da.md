## 1. Захистімо знайдені секретні плани паролем

Щойно ми отримаємо секретні плани, їх потрібно буде захистити так, щоб дістати їх могли лише ті, хто знає пароль.

Для цього потрібно реалізувати функцію `protectSecret(_ secret: String, withPassword password: String) -> (String) -> String`.
Ця функція поверне іншу функцію, яка приймає як вхідні дані можливі паролі у вигляді рядків тексту (англ. string).
Якщо введений пароль правильний, нова функція повертає прихований секрет, а якщо пароль неправильний, функція повертає "Sorry. No hidden secrets here."

```swift
let secretFunction = protectSecret("Steal the world's supply of french fries!", withPassword: "5up3r53cr37")

secretFunction("Open sesame")
// Returns "Sorry. No hidden secrets here."

secretFunction("5up3r53cr37")
// Returns "Steal the world's supply of french fries!"
```

## 2. Згенеруймо комбінацію, щоб відкрити їхній сейф

Ми дізналися, що UMBRA будує всі комбінації до своїх сейфів на основі номера кімнати, у якій вони розташовані.
Комбінації до сейфів генеруються шляхом багаторазового застосування спеціальної функції до номера кімнати.
Отже, перше число комбінації утворюється застосуванням функції до номера кімнати, друге - застосуванням функції до першого числа, а третє - застосуванням функції до другого числа.

Однак UMBRA регулярно змінює функцію, яку використовує для генерування комбінацій, тож наш інструмент має приймати і номер кімнати, і відповідну функцію, щоб згенерувати комбінацію.

Реалізуймо функцію `generateCombination(forRoom room: Int, usingFunction f: (Int) -> Int) -> (Int, Int, Int)`, щоб згенерувати потрібну нам комбінацію.

```swift
func makeCombo(_ x: Int) -> Int {
  (x * 13) % 256
}

generateCombination(forRoom: 227, usingFunction: makeCombo)
// Returns (135, 219, 31)
```
