# Вступ

Концепції коваріантності та контраваріантності в PHP важливі, оскільки PHP стежить за дотриманням цих правил під час розширення класів або інтерфейсів.

Коваріантність зберігає звʼязок між двома типами, а контраваріантність змінює цей звʼязок на протилежний. Коротко кажучи, це означає, що під час розширення класів і перевизначення функцій можна дозволяти більш або менш конкретні типи для параметрів методу, а з методу можна повертати менш або більш конкретні типи.

## Приклади

Розгляньмо такий клас:

```php
class Calculator 
{
    public function add(int $x, int $y): int 
    {
        return $x + $y;
    }
}
```

Якщо ми розширюємо клас, ми можемо дозволити більше типів параметрів, ніж було оголошено спочатку, але не можемо повертати нічого, крім початкових типів повернення.

```php
class Floatulator extends Calculator
{
    // This is valid
    public function add(int|float $x, int|float $y): int 
    {
        return (int)($x + $y);
    }
}
```

Наведений нижче розширений клас недійсний, оскільки повернення додаткових або ширших типів не дозволено:

```php
class BrokenCalculator extends Calculator 
{
    // This is invalid and will not compile
    public function add(int|float $x, int|float $y): int|float{
        return $x + $y;
    }
}
```
