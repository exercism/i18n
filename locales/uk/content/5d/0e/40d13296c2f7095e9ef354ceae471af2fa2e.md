# Додаток до інструкцій

## Регістри

| Регістр | Використання    | Тип     | Опис                                        |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | вхідні дані        | адреса | фраза, завершена нульовим символом        |
| `$a1`    | вхідні/вихідні дані | адреса | результатний рядок тексту (англ. string), завершений нульовим символом |
| `$t0-9`  | тимчасовий    | будь-який     | для тимчасового зберігання         |
