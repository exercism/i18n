# Вступ

## Час

Модуль `Time` використовують, щоб показувати дати й час у зрозумілому для людини вигляді.
Хоча технічно працювати з часом можна й засобами `Time`, у спільноті Elm є пакети, які підходять для цього значно краще, як-от [`justinmimbs/date`][date] або [`CoderDennis/elm-time-format`][elm-time-format].

### Posix

Час подається непрозорим типом `Posix`, який обгортає час Unix-епохи, тобто кількість мілісекунд, що минули з півночі 1 січня 1970 року за UTC.
`Posix` - це однозначне значення, яке не змінюється від часового поясу, тому добре підходить для зберігання часу.
У застосунку Elm значення `Posix` зазвичай надходять із зовнішніх джерел, як-от браузер.

Перетворити `Posix` на число мілісекунд і навпаки можна за допомогою таких функцій:

```elm
posixToMillis : Posix -> Int
millisToPosix : Int -> Posix
```

### Часові пояси

У повсякденному житті ми зазвичай не читаємо `Posix`, а надаємо перевагу місцевому часу, який залежить від нашого розташування на Землі та від місцевих правил переходу на літній час.
В Elm ця інформація закодована в непрозорому типі `Zone`, який зазвичай надає браузер.

Є один особливий `Zone`, доступний завжди:

```elm
utc : Zone
```

### Час для людей

Маючи `Posix` і `Zone`, ми маємо достатньо інформації, щоб показати місцевий час із будь-яким рівнем деталізації.
Ось список функцій, які для цього можна використати:

```elm
toYear : Zone -> Posix -> Int
toMonth : Zone -> Posix -> Month
toDay : Zone -> Posix -> Int
toWeekday : Zone -> Posix -> Weekday
toHour : Zone -> Posix -> Int
toMinute : Zone -> Posix -> Int
toSecond : Zone -> Posix -> Int
toMillis : Zone -> Posix -> Int
```

Ми, напевно, вже помітили ще два власні типи з `Time`:

```elm
type Month = Jan | Feb | Mar | Apr | May | Jun | Jul | Aug | Sep | Oct | Nov | Dec
type Weekday = Mon | Tue | Wed | Thu | Fri | Sat | Sun
```

Перетворення цих власних типів на зрозумілі для людини значення залишається за користувачами.
