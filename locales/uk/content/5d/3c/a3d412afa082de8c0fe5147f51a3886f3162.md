# Вступ

Ruby — це динамічна [обʼєктно-орієнтована мова][object-oriented-programming].
Усе в Ruby є [обʼєктом][object].

У Ruby є два основні способи присвоїти обʼєктам імена: за допомогою змінних або констант.
Змінні завжди записуються в [snake case][snake-case].
Упродовж свого життя змінна може посилатися на різні обʼєкти.
Наприклад, `my_first_variable` можна визначати й перевизначати багато разів за допомогою оператора `=`:

```ruby
my_first_variable = 1
my_first_variable = "Some string"
my_first_variable = SomeComplexObject.new
```

Константи ж призначено для присвоєння лише один раз.
Вони мусять починатися з великої літери, і зазвичай їх записують великими літерами, розділяючи слова підкресленнями.

Наприклад:

```ruby
MY_FIRST_CONSTANT = 10

# Redefining not allowed
# MY_FIRST_CONSTANT = "Some String"
```

Ruby організовано в класи.
Класи визначають за допомогою ключового слова `class`, після якого йде назва класу.
Обʼєкти зазвичай створюють як екземпляри класів за допомогою методу `.new`.

Наприклад:

```ruby
# Define the class
class Calculator
  #...
end

# Create an instance of it and assign it to a variable
my_first_calc = Calculator.new
```

Одиниці функціональності інкапсульовано в методи, подібно до _функцій_ в інших мовах.
Метод можна за потреби визначити з позиційними аргументами та/або з іменованими аргументами, які визначають і викликають за допомогою синтаксису `:`.
Методи або неявно повертають результат останньої виконаної інструкції, або можуть явно повернути обʼєкт за допомогою ключового слова `return`.
Методи викликають за допомогою синтаксису `.`.

```ruby
class Calculator

  # Unnamed params
  def add(num1, num2)
    return num1 + num2 # Explicit return
  end

  # Named params
  def multiply(num1:, num2:)
    num1 * num2 # Implicit return
  end
end

calc = Calculator.new
calc.add(1, 3)
calc.multiply(num1: 2, num2: 5)
```
