# Вступ

Параметр методу можна зробити необовʼязковим, якщо присвоїти йому типове значення. Коли ми викликаємо метод із необовʼязковими параметрами, передавати для них значення не обовʼязково. Якщо для необовʼязкового параметра значення не передано, використовується його типове значення.

Необовʼязкові параметри _мають_ стояти в кінці списку параметрів; після них не можуть іти обовʼязкові параметри.

```csharp
class Card
{
    static string NewYear(int year = 2020)
    {
        return $"Happy {year}!";
    }
}

Card.NewYear();     // => "Happy 2020!"
Card.NewYear(1999); // => "Happy 1999!"
```
