# Як запускати тести

## Завантаження вправи

Скористайтеся [Exercism CLI][cli], щоб завантажити вправу, над якою хочете працювати.

```sh
exercism download --track=dart --exercise=hello-world
```

Потім перейдіть до каталогу вправи.

```sh
cd /path/to/exercism/dart/hello-world
```

## Встановлення залежностей

Перш ніж запускати тести, завантажте залежності вправи.

```sh
dart pub get
```

## Запуск тестів

```sh
dart test
```

## Розуміння результатів тестів

`dart test` за замовчуванням використовує компактний репортер, показуючи в одному рядку поточну кількість тестів, які пройдено, пропущено й не пройдено.

```sh
$ dart test

  Expected: <3>
    Actual: <0>

  package:matcher                    expect

To run this test again: dart test test/binary_search_test.dart -p vm --plain-name 'finds a value in the middle of an array'
```

## Опрацювання тестів

У більшості вправ тестів кілька, і всі, крім першого, за замовчуванням пропущені.

```dart
void main() {
  final twoFer = TwoFer();

  group('TwoFer', () {
    test('no name given', () {
      final result = twoFer.statement();
      expect(result, equals('One for you, one for me.'));
    }, skip: false);

    test('a name given', () {
      final result = twoFer.statement('Alice');
      expect(result, equals('One for Alice, one for me.'));
    }, skip: true);

    test('another name given', () {
      final result = twoFer.statement('Bob');
      expect(result, equals('One for Bob, one for me.'));
    }, skip: true);
  });
}
```

Щоб опрацьовувати тести по одному, змінюйте `skip: true` на `skip: false` у кожному тесті в міру просування. Або запустіть усі тести одразу, не редагуючи файл.

```sh
dart test --run-skipped
```

Під час надсилання рішення онлайн-засіб запуску тестів запускає всі тести, зокрема й пропущені.

## Як усунути помилку «Could not find a command named frontend_server.dart.snapshot»

Припустімо, у вас є вправа, яку ви вже розвʼязали й надіслали, і ви повертаєтеся до неї через деякий час. Під час запуску тестів може виникнути така помилка:

```sh
$ dart test
...
Could not find a command named "/path/to/frontend_server.dart.snapshot".
```

[Рішення][solution] полягає в тому, щоб видалити файл `pubspec.lock`. Потім запустіть команду dart знову.

[solution]: https://stackoverflow.com/q/79247335/7552
