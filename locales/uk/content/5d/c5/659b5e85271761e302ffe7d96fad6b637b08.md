# Вступ

Іноді, коли функція приймає багато аргументів, буває важко згадати порядок, у якому їх треба передавати. Щоб полегшити читання, Gleam дозволяє давати аргументам мітки.

Щоб дати аргументу мітку, вкажіть назву мітки перед назвою аргументу, розділивши їх пробілом.

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

Коли ми викликаємо функцію з мітками, аргументи можна передавати в будь-якому порядку. Усі ці виклики `replace` рівнозначні:

```gleam
replace(in: "🍔🍔🍔" each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

Мітки завжди необовʼязкові. Навіть якщо функція має аргументи з мітками, її все одно можна викликати без них.

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```
