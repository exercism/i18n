# Про

Методи можуть мати параметр varargs, який дозволяє тому, хто викликає, вказати нуль або більше аргументів так, ніби це звичайні параметри. Метод отримає ці аргументи в одному масиві.

Щоб перетворити параметр на параметр varargs, додайте ключове слово [`params`](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/params) до оголошення параметра:

```csharp
public static void PrintNumbers(params int[] numbers)
{
    foreach (var number in numbers)
    {
        Console.Write(number)
    }
}

// No values for a varags parameter is allowed
PrintNumbers();

PrintNumbers(1);
// => 1

PrintNumbers(1, 2, 3);
// => 123
```
