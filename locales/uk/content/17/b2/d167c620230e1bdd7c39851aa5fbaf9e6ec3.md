# Інструкції

Уявімо себе сигнальником на патрульному катері берегової охорони. До початку ранкової вахти в сьогоднішній сумці мають бути готові пʼять коротких слів.

## 1. Взяти значення в лапки

Судновий журнал фіксує кожне спостереження у *вихідній формі Factor*: той самий текст, який згодом прочитає парсер. Визначмо `quote-value`, щоб вона перетворювала будь-яке значення на рядок тексту (англ. string) у вихідній формі.

```factor
123 quote-value .   ! => "123"
"hi" quote-value .  ! => "\"hi\""
```

## 2. Зняти обрамлення прапора

Сигнальні прапори надходять обрамлені маркерним символом з кожного боку. Визначмо `flag-body`, щоб вона повертала все, що *між* двома маркерами, тобто відкидала перший символ і останній символ.

Повернімо зріз (подання), а не копію.

```factor
"#NS-1024#" flag-body .   ! => "NS-1024"
```

## 3. Розділити прапор

Кожен прапор несе короткий код-префікс, за яким іде корисне навантаження. Визначмо `split-flag`, щоб вона приймала прапор і довжину заголовка та повертала *як* зріз заголовка, *так і* зріз тіла.

```factor
"NS-1024" 2 split-flag .s
! => "NS"
! => "-1024"
```

## 4. Тріангуляція за двома показниками

Два послідовні показники сигналу дають три похідні величини: їхню *різницю* `a - b`, їхню *середину* `(a + b) / 2` та їхнє *відношення* `a / b`. Кожна величина використовує обидва показники.

Визначмо `triangulate`, щоб вона повертала всі три з пари показників.

```factor
100 50 triangulate .s
! => 50
! => 75
! => 2
```

## 5. Підсумувати три показники

Три послідовні показники узагальнюються як їхня **сума**, **добуток** і **максимум**. Кожна статистика використовує всі три показники.

Визначмо `triangle-stats`, щоб вона повертала всі три.

```factor
5 3 8 triangle-stats .s
! => 16
! => 120
! => 8
```
