# Вступ

Екземпляр класу `java.util.Random` можна використовувати для генерування випадкових чисел у Java.

## Випадкові цілі числа

Випадкове ціле число можна згенерувати за допомогою методу `nextInt()`.
Це згенерує значення в діапазоні від `Integer.MIN_VALUE` до `Integer.MAX_VALUE`.

```java
Random random = new Random();

random.nextInt();
// => -1169335537
```

Щоб обмежити діапазон згенерованих значень, використаймо метод `nextInt(int)`.
Це згенерує значення в діапазоні від `0` (включно) до заданої верхньої межі (не включно).

Наприклад, цей код згенерує випадкове число від `0` до `9` включно.

```java
Random random = new Random();

random.nextInt(10);
// => 6
```

А це згенерує випадкове число від `10` до `19` включно.

```java
Random random = new Random();

10 + random.nextInt(10);
// => 11
```

## Випадкові числа з плаваючою комою

Випадкове число з плаваючою комою можна згенерувати за допомогою методу `nextDouble()`.
Це згенерує значення в діапазоні від `0.0` до `1.0`.

```java
Random random = new Random();

random.nextDouble();
// => 0.19250004204021398
```

А це згенерує випадкове число від `100.0` до `200.0`.

```java
Random random = new Random();

100.0 + 100.0 * random.nextDouble();
// => 111.31849856260328
```
