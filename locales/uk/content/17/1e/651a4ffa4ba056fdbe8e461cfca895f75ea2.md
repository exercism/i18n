# Вступ

`string` (рядок тексту, англ. string) у C++ - це змінний обʼєкт, який представляє текст як послідовність символів (літер, цифр, розділових знаків тощо). З рядками тексту працюють, викликаючи методи цього рядка.

## Бібліотека рядків тексту

У C++ тип рядка тексту та повʼязані з ним функції потрібно підключити з бібліотеки рядків тексту перед використанням.
Це можна зробити, додавши `#include <string>` на початок файлу.
Після цього вони наповнять простір імен `std`.
Тип рядка тексту має повне кваліфіковане імʼя `std::string`.
Рядковий літерал записують у подвійних лапках: `"`.

```cpp
#include <string>
std::string w_berry_quote{"A well-made sentence, I think, is a thing of beauty."};
```

## Поширені операції з рядками тексту

Щоб зʼєднати рядки тексту, можна використати оператор `+`:

```cpp
std::string original_title{"The School of Rock"};
std::string sequel_indicator{"Electric Boogaloo"};
std::string next_movie_title = original_title + " 2: " + sequel_indicator;
```

Щоб скористатися бібліотекою рядків тексту, потрібно знати, що функцію, яка належить обʼєкту, можна викликати.
Такі функції називають функціями-членами.
Пізніше в силабусі ми дізнаємося більше про функції-члени та повʼязане з ними поняття класу.

```cpp
std::string qualification{"awesome"};
// 1st argument: from the index to the end of the string:
std::string who_is_awesome = qualification.substr(5);
// => "me"

// 2nd optional argument for the length:
std::string material{"haunted books"};
std::string ghost = material.substr(8, 3);
// => "boo"
```


Функція `find` також дуже корисна.
Її викликають як функцію-член рядка тексту, і вона приймає рядок тексту як аргумент.
`find` повертає позицію _першого_ входження в рядку тексту, рахуючи від нуля.

```cpp
std::string new_release{"apple released a new app!"};
new_release.find("app");
// => 0
new_release.find("e");
// => 4
```

Є також функція `std::to_string`, яку можна використати, щоб перетворити цілі числа та значення з плаваючою комою (float і double) на рядок тексту.

```cpp
int num{92};
double exponent{0.92e2};
std::string msg{ std::to_string(num) + " can also be written as " + std::to_string(exponent)};
// => 92 can also be written as 92.0000000
```
