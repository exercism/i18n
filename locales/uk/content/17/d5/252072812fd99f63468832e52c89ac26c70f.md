# Додаток до вказівок

## Реалізація

Дозволено використовувати базові засоби мови для створення й розбирання масивів за допомогою деструктуризації, а також літерал масиву `[]`, але не можна використовувати жодної функції з `Array.prototype`.

Щоб можна було перевірити ваше рішення, переконайтеся, що `forEach` реалізовано.

```typescript
const list = List.create(1, 2)
list.forEach((item) => console.log(item))
// =>
//    1
//    2
```
