# Вступ

Як і більшість мов програмування, Gleam має «побічні ефекти»: функції можуть читати та змінювати стан світу, а також повертати значення.

Модуль `gleam/io` у стандартній бібліотеці Gleam надає функції для виведення рядків тексту (англ. string) на консоль.

```gleam
io.println("Hello, Joe!")
// Hello, Joe!
// -> Nil
```

Інші пакунки можуть надавати інші функції введення-виведення, як-от пакунок `simplifile`, який надає функції для читання та запису файлів.

```gleam
simplifile.read("favourite-colour.txt")
// -> Ok("Pink\n")
```
