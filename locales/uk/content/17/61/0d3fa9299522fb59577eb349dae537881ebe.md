# Інструкції для SQLite

Стовпці **list_one** і **list_two** містять закодований у JSON список цілих чисел.

Приклад:

```json
[1, 2, 3]
```

## Схема таблиці

```sql
CREATE TABLE sublist (
    list_one TEXT NOT NULL,     -- json array
    list_two TEXT NOT NULL,     -- json array
    result   TEXT
);
```
