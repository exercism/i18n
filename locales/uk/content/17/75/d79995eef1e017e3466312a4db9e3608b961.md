# Вступ

Рекурсія - це спосіб повторювати код у функції, коли функція викликає саму себе.
Її можна розглядати як ще один спосіб організувати цикл або ітерацію.
Як і в циклі, щоб визначити, коли зупинити рекурсивне виконання, використовують булевий вираз (англ. Boolean) або перевірку на `True`/`False`.
_На відміну_ від циклу, рекурсія без завершення в Python не може виконуватися нескінченно.
Значення, які використовуються в кожному виклику функції, розміщуються у власному [кадрі][stack-frame] на [стеку інтерпретатора][what-is-the-call-stack] Python.
Якщо загальна кількість викликів функції займає більше місця, ніж є в стеку, це призведе до помилки.

```python
def print_increment(step, max_value):
    if step > max_value:
        return
    print(f'The step is {step}')
    print_increment(step + 1, max_value)


def main():
    print_increment(1, 2)
    print("After recursion")

if __name__ == "__main__":
    main()

```

Це виведе:

```
The step is 1
The step is 2
After recursion
```

Іноді код, виражений через рекурсію, читається краще та/або його легше осмислити, ніж той самий код, виражений через цикл.
