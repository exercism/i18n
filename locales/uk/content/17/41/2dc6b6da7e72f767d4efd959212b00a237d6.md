# Вказівки

Ми працюємо над реалізацією системи моніторингу здоровʼя. У межах цього нам потрібно відстежувати статистику здоровʼя користувачів.

Ми почнемо з кількох функцій-заглушок у блоці `impl`, а також із такого визначення структури:

```rust
pub struct User {
    name: String,
    age: u32,
    weight: f32,
}
```

Наша мета - реалізувати методи-заглушки на `struct` `User`, визначеній у блоці `impl`.

Наприклад, метод `new` має повертати екземпляр структури `User` із заданими значеннями імені, віку і ваги.

```rust
let mut bob = User::new(String::from("Bob"), 32, 155.2);
// Returns: a User with name "Bob", age 32, and weight 155.2
```

Метод `weight` має повертати вагу екземпляра `User`.

```rust
bob.weight();
// Returns: 155.2
```

Метод `set_age` має встановлювати вік екземпляра `User`.

```rust
bob.set_age(33);
// Updates Bob's age to 33; happy birthday Bob!
```
