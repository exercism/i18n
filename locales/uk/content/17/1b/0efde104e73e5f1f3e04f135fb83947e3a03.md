# Вступ

Інтерфейс - це тип, що містить члени, які визначають групу повʼязаної функціональності.
Він віддаляє використання класу від реалізації, що дозволяє мати кілька різних реалізацій або підтримувати якусь загальну поведінку, як-от форматування, порівняння чи перетворення.

Синтаксис інтерфейсу схожий на синтаксис класу, але методи подаються лише як сигнатура, без тіла.

```java
public interface Language {
    String getLanguageName();
    String speak();
}

public class ItalianTraveller implements Language, Cloneable {

    // from Language interface
    public String getLanguageName() {
        return "Italiano";
    }

    // from Language interface
    public String speak() {
        return "Ciao mondo";
    }

    // from Cloneable interface
    public Object clone() {
        ItalianTraveller it = new ItalianTraveller();
        return it;
    }
}
```

Усі операції, визначені інтерфейсом, має реалізувати клас, який його реалізує.

Інтерфейси зазвичай містять методи екземпляра.

Прикладом інтерфейсу з бібліотеки класів Java, крім `Cloneable`, показаного вище, є `Comparable<T>`.
Інтерфейс `Comparable<T>` можна реалізувати там, де потрібен типовий загальний порядок сортування в колекціях.
