# Інструкції

Нашу компанію найняли, щоб генерувати CSV-записи з даних, які вводить користувач.

Нам потрібен будівельник для CSV-запису за стандартом, описаним у [RFC 4180](https://tools.ietf.org/html/rfc4180).

Хоча формальна специфікація й існує, нашій компанії потрібно реалізувати лише таку функціональність:
- створити новий будівельник запису
- додати окреме поле до запису
- серіалізувати запис із базовим екрануванням

Базове екранування означає:

- Поля, що містять розриви рядків, подвійні лапки та коми, слід брати в подвійні лапки.

- Якщо поля беруть у подвійні лапки, то подвійну лапку всередині поля потрібно екранувати, поставивши перед нею ще одну подвійну лапку.


## 1. Створити новий будівельник

Щоб створити новий будівельник, потрібно реалізувати метод `new`.

```rust
let mut builder = CsvRecordBuilder::new();
```

## 2. Додати окремі поля до запису

Щоб додавати поля до будівельника запису, потрібно реалізувати метод `add`.
Метод `add` приймає як аргумент незмінні зрізи рядка тексту (англ. string), `&str`.

```rust
builder.add("ant");
builder.add("ba\"t");
builder.add("cat");
```


## 3. Серіалізувати запис із базовим екрануванням

Потрібно реалізувати метод `build`.
Метод `build` споживає будівельник і повертає CSV-запис.
```rust
let record = builder.build();
// Note that from now on we cannot use `builder`
assert_eq!(&record, r#"ant,"ba""t",cat"#);
```
