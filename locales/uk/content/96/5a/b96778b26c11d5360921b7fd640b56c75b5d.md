# Інструкції

Боцман щодня проводить інструктаж вахти на палубі: фіксоване привітання, перекличка екіпажу на вахті, а потім завершальна команда. Ми розкладемо інструктаж на маленькі іменовані рядки та скомпонуємо їх.

Для цієї вправи ми редагуватимемо **два файли**:

- `bosuns-briefing/helpers/helpers.factor` - маленькі повторно використовувані частини. Словник: `bosuns-briefing.helpers`.
- `bosuns-briefing/bosuns-briefing.factor` - головний файл, який компонує допоміжні слова. Словник: `bosuns-briefing`.

## 1. Привітання

У `helpers.factor` визначте `greeting`, який повертає фіксований рядок тексту (англ. string) відкриття `"All hands, attention!"`.

```factor
greeting .
! => "All hands, attention!"
```

## 2. Рядок екіпажу

У `helpers.factor` визначте `crew-line`, який приймає рядок тексту з іменем та повертає це імʼя з префіксом `"  - "` (два пробіли, дефіс, пробіл).

```factor
"Lopez" crew-line .
! => "  - Lopez"
```

## 3. Завершення

У `helpers.factor` визначте `closing`, який повертає фіксований рядок тексту завершення `"Carry on."`.

```factor
closing .
! => "Carry on."
```

## 4. Список екіпажу

У `bosuns-briefing.factor` визначте `roster`, який приймає масив імен екіпажу та повертає один багаторядковий рядок тексту, у якому кожне імʼя відформатовано за допомогою `crew-line`, а отримані рядки зʼєднано символами нового рядка.

```factor
{ "Lopez" "Mwangi" } roster .
! => "  - Lopez\n  - Mwangi"

{ } roster .
! => ""
```

## 5. Інструктаж

У `bosuns-briefing.factor` визначте `briefing`, який приймає масив імен екіпажу та повертає повний інструктаж як один рядок тексту: привітання в першому рядку, список екіпажу в наступних рядках, а завершення в останньому рядку. Використайте допоміжні слова та `roster`.

```factor
{ "Lopez" "Mwangi" } briefing .
! => "All hands, attention!\n  - Lopez\n  - Mwangi\nCarry on."

{ } briefing .
! => "All hands, attention!\n\nCarry on."
```
