# Вступ

У Haskell є тип `Num`, який є базовим типом для всіх числових типів.
Усередині типу Number є чотири основні підтипи: [`Int`][int], [`Integer`][integer], [`Double`][double] та [`Float`][float].

У Haskell є два цілочисельні типи, які представляють цілі числа.
`Int` - ціле число фіксованого розміру, тоді як `Integer` - ціле число довільної точності.
`Integer` зберігає будь-яке число, яким би великим воно не було, аж до межі памʼяті нашої машини, тоді як `Int` відповідає набору додатних і відʼємних цілих чисел, які можна подати у 32 або 64 бітах (гарантовано принаймні від -2^29 до 2^29 - 1).

Зауважмо, що записуючи відʼємні числа, варто брати їх у дужки, щоб уникнути двозначності.

```haskell
1

(-1)
```

`Float` відповідає набору дійсних чисел, обмеженому точністю компʼютера.
Операції, визначені для чисел, зазвичай працюють з одним типом або з іншим, але не з обома одночасно.
`Double` - число з плаваючою комою подвійної точності.

```haskell
10.5
```

## Перетворення між цілими числами та числами з плаваючою комою

Функція `toFloat` дає змогу перетворити `Int` або `Integer` на `Float`.

```haskell
toFloat 1
-- -> 1.0
```

Також є `fromIntegral`, яка перетворює будь-який числовий тип на потрібний виведений числовий тип.

```haskell
fromIntegral 1
-- -> 1.0
```

Щоб перетворити `Float` на `Int`, можна скористатися функціями [`round`][round], [`floor`][floor] або [`ceiling`][ceiling].
Функція `round` округлює до найближчого цілого, `floor` округлює вниз, а `ceiling` - вгору.

```haskell
round 1.5
-- -> 2

floor 1.5
-- -> 1

ceiling 1.5
-- -> 2
```

## Арифметичні оператори

З числовими типами можна використовувати [базові арифметичні оператори][math].
Це оператори `+`, `-`, `*`, `/` і `%`.
Використовуючи ці оператори, треба стежити, щоб типи чисел збігалися.
Функція `fromIntegral` перетворить значення так, щоб типи збіглися.

### Додавання, віднімання та множення

Оператор `+` використовується для додавання, `-` - для віднімання, а `*` - для множення.

| Оператор | Приклад        |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### Ділення

Ділення використовується, щоб поділити одне число на інше.
Оператор `/` використовується для ділення.
Результат завжди буде числом з плаваючою комою.

```haskell
4.0 / 2.5
-- -> 1.6

4 / 2
-- -> 2.0
```

~~~~exercism/caution
У деяких мовах програмування ділення на нуль дає помилку.

У Haskell ділення на нуль дає `Infinity` або `-Infinity`.
Єдиний виняток - ділення нуля на нуль, результатом якого буде `NaN` (не число).

```haskell
1 / 0
-- -> Infinity

(-1) / 0
-- -> -Infinity

0 / 0
-- -> NaN
```
~~~~

## Цілочисельне ділення

Цілочисельне ділення дає змогу поділити цілі числа й отримати цілу частину результату.
У Haskell є дві функції цілочисельного ділення, які відрізняються тим, як вони округлюють, коли результат відʼємний:

- `div` округлює вниз, у бік мінус нескінченності.
- `quot` округлює в бік нуля.

```haskell
6 `div` 2
-- -> 3

5 `div` 2
-- -> 2

(-5) `div` 2
-- -> -3

5 `quot` 2
-- -> 2

(-5) `quot` 2
-- -> -2
```

~~~~exercism/caution
Ділення на нуль під час цілочисельного ділення спричиняє виняток.
Це відрізняється від звичайного ділення.
~~~~

### Остача

Остачу від цілочисельного ділення можна знайти за допомогою `mod` або `rem`.
Вони відрізняються знаком результату, коли одне з чисел відʼємне:

- `mod` працює разом із `div`, і його результат має той самий знак, що й дільник.
- `rem` працює разом із `quot`, і його результат має той самий знак, що й ділене.

```haskell
5 `mod` 3
-- -> 2

(-5) `mod` 3
-- -> 1

5 `mod` (-3)
-- -> -1

5 `rem` 3
-- -> 2

(-5) `rem` 3
-- -> -2

5 `rem` (-3)
-- -> 2
```

Для будь-яких `x` і `y` (де `y` не дорівнює нулю) справджуються такі закони:

```haskell
(x `div` y) * y + (x `mod` y) == x
(x `quot` y) * y + (x `rem` y) == x
```

~~~~exercism/note
Якщо обидва числа додатні, `div` і `quot` дають однаковий результат, як і `mod` і `rem`.
У цьому разі `quot` і `rem` можуть бути трохи ефективнішими, бо `div` і `mod` потребують додаткових кроків, щоб обробити відʼємні числа.
~~~~

~~~~exercism/caution
Ділення на нуль під час використання `mod` або `rem` спричиняє виняток.
Це відрізняється від звичайного ділення.

```haskell
1 `mod` 0
-- Exception: divide by zero
```
~~~~

## Піднесення до степеня

У Haskell є три оператори «піднесення до степеня», які працюють по-різному й приймають різні типи аргументів.

- `**` приймає два **числа з плаваючою комою** і обчислює степінь за допомогою логарифмів.
- `^^` приймає **число з плаваючою комою** й підносить його до **цілого** степеня, додатного або відʼємного.
- `^` приймає **будь-який числовий тип** й підносить його до **додатного цілого** степеня.

```haskell
3.0 ** 2.1
-- -> 10.04510856630514

2.5 ^^ 2
-- -> 6.25

2 ^ 3
-- -> 8
```

## Пріоритет і дужки

Haskell дозволяє дужки (`()`), які можна використовувати для групування виразів.
Це корисно, коли треба змінити порядок операцій.

Коли ми використовуємо кілька арифметичних операторів, порядок операцій такий самий, як у математиці, також відомий як [PEMDAS][pemdas].
Він такий: дужки (`()`), степені (`**`), множення (`*`) і ділення (`/`), додавання (`+`) і віднімання (`-`).

```haskell
2 + 3 - 4 * 4
-- -> -11

(2 + 3 - 4) * 4
-- -> 4
```
