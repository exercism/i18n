# Вступ

## Змінні

Elixir - це динамічно типізована мова: тип змінної перевіряється лише під час виконання. За допомогою оператора зіставлення `=` ми можемо привʼязати значення будь-якого типу до імені змінної:

```elixir
# Bound an integer value of 1
count = 1
# You may re-bind variables
count = 2

# You may re-bind any type to a variable
count = false

# Strings can be created by enclosing characters within double quotes
message = "Success!"
```

## Модулі

Elixir - це мова [функціонального програмування][functional-programming], і вона вимагає, щоб усі іменовані функції були визначені в _модулі_. Для визначення модуля використовується ключове слово `defmodule`. Усі модулі доступні всім іншим модулям під час виконання і не потребують _модифікатора доступу_, щоб бути видимими для інших частин програми. _Модуль_ аналогічний до _класу_ в інших мовах програмування.

```elixir
defmodule Calculator do
  # ...
end
```

## Іменовані функції

_Іменовані функції_ потрібно визначати в модулі. Для визначення _публічної_ іменованої функції використовується ключове слово `def`.

Кожна функція може мати нуль або більше аргументів. Значення останнього виразу у функції завжди _неявно повертається_.

```elixir
defmodule Calculator do
  def add(x, y) do
    x + y
  end
end
```

Щоб викликати функцію, потрібно вказати її модуль і назву функції та передати аргументи для кожного з параметрів функції.

```elixir
sum = Calculator.add(1, 2)
# => 3
```

Замість `def` для визначення _приватної_ функції можна використати ключове слово `defp`. Приватні функції можна використовувати лише в межах того самого модуля, який їх визначив.

Коли ми викликаємо функцію в тому самому модулі, де її визначено, назву модуля можна опустити.

Також можна писати короткі функції в однорядковому синтаксисі (звернімо увагу на кому `,` і двокрапку `:` навколо ключового слова `do`).

```elixir
defmodule Calculator do
  def subtract(x, y) do
    private_subtract(x, y)
  end

  defp private_subtract(x, y), do: x - y
end

difference = Calculator.subtract(7, 2)
# => 5

difference = Calculator.private_subtract(7, 2)
# => ** (UndefinedFunctionError) function Calculator.private_subtract/2 is undefined or private
#       Calculator.private_subtract(7, 2)
```

## Арність функцій

Функції часто називають разом з їхньою _арністю_. _Арність_ функції - це кількість аргументів, які вона приймає.

```elixir
# add/3 because this function has three arguments, thus an arity of 3
def add(x, y, z) do
  x + y + z
end
```

## Правила найменування

У назвах модулів слід використовувати `PascalCase`. Назва модуля має починатися з великої літери `A-Z` і може містити літери `a-zA-Z`, цифри `0-9` та підкреслення `_`.

У назвах змінних і функцій слід використовувати `snake_case`. Назва змінної або функції має починатися з малої літери `a-z` або підкреслення `_`, може містити літери `a-zA-Z`, цифри `0-9` та підкреслення `_`, а також може закінчуватися знаком питання `?` або знаком оклику `!`.

## Стандартна бібліотека

Elixir має дуже багату й добре задокументовану стандартну бібліотеку. Документація доступна онлайн за посиланням [hexdocs.pm/elixir][docs]. Збережімо це посилання десь, воно нам ще не раз знадобиться!

Більшість вбудованих типів даних мають відповідний модуль, який пропонує функції для роботи з цим типом даних, наприклад: для цілих чисел існує модуль `Integer`, для рядків тексту (англ. string) - модуль `String`, для масивів - модуль `List` і так далі.

Варто відзначити модуль `Kernel`. Він надає базові можливості, на яких побудована решта стандартної бібліотеки: арифметичні оператори, макроси керування потоком виконання тощо. Функції модуля `Kernel` імпортуються автоматично, тож ми можемо використовувати їх без префікса `Kernel.`.

## Коментарі в коді

Коментарі можна використовувати, щоб залишати примітки для інших розробників, які читають вихідний код. Однорядкові коментарі в Elixir починаються з `#`.
