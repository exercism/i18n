# Докладніше

Коли ми моделюємо дані, які можуть набувати лише певного набору можливих станів, як-от дні тижня, сторони світу чи кнопки контролера, базові типи, як-от `Int` чи `String`, мають серйозні недоліки.
Із цілими числами або рядками тексту (англ. string) наш код мусить постійно перевіряти, чи не отримав він неприпустимих значень (як-от код стану `999` чи одруківку на кшталт `"leftt"`), а читачам-людям важко зрозуміти, що означають числа.

Swift розвʼязує цю проблему за допомогою [_переліків_][enumerations] (які часто скорочують до *enum*).
Перелік визначає спільний тип для групи повʼязаних іменованих значень. Оскільки компілятор заздалегідь знає всі можливі варіанти, він може перевірити наш код на правильність і повноту під час компіляції.
Переліки також можуть мати методи, ініціалізатори та обчислювані властивості.

## Визначення переліків

Визначмо перелік ключовим словом `enum`, після якого йде назва типу, а його варіанти перелічено у фігурних дужках.
За домовленістю Swift назва типу записується в `UpperCamelCase`, а кожен варіант записується в `lowerCamelCase`:

```swift
enum NESButton {
    case up
    case down
    case left
    case right
    case a
    case b
    case select
    case start
}
```

Також можна визначити кілька варіантів в одному рядку, розділивши їх комами:

```swift
enum NESButton {
    case up, down, left, right, a, b, select, start
}
```

Щоб послатися на варіант переліку, запишімо назву типу переліку, крапку (`.`) і назву варіанта. Коли тип відомий або його може вивести компілятор, назву типу можна опустити й використати коротший синтаксис із крапкою:

```swift
var lastPressed = NESButton.up

// Swift infers the type, so you can omit the type name:
lastPressed = .down

let konamiCode: [NESButton] = [.up, .up, .down, .down, .left, .right, .left, .right, .b, .a]
```

## Переліки та інструкції `switch`

Переліки чудово працюють разом з [інструкціями `switch`][enums-and-switches].
Оскільки `switch` у Swift має бути вичерпним, компілятор гарантує, що ми опрацюємо кожен можливий варіант:

```swift
lastPressed = .left
switch lastPressed {
case .up: print("You pressed the UP button")
case .down: print("You pressed the DOWN button")
case .left: print("You pressed the LEFT button")
case .right: print("You pressed the RIGHT button")
case .a: print("You pressed the A button")
case .b: print("You pressed the B button")
case .select: print("You pressed the SELECT button")
case .start: print("You pressed the START button")
}
// Prints "You pressed the LEFT button"
```

Якщо ми пропустимо якийсь варіант і не додамо гілку `default`, компілятор повідомить про помилку:

```swift
switch lastPressed {
case .up, .down, .left, .right:
    print("You pressed a direction button.")
}
// Error: Switch must be exhaustive
```

Часто краще явно перелічити всі варіанти, ніж використовувати `default`. Тоді, якщо згодом ми додамо новий варіант, компілятор одразу підкаже оновити кожну інструкцію `switch`, яка опрацьовує цей перелік.

## Методи та ініціалізатори

Переліки можуть визначати методи та власні ініціалізатори так само, як класи й структури. Усередині методу переліку `self` указує на поточне значення варіанта:

```swift
enum Coin {
    case heads
    case tails

    init(_ value: Int) {
        if value.isMultiple(of: 2) {
            self = .heads
        } else {
            self = .tails
        }
    }

    func flip() -> Coin {
        switch self {
        case .heads: return .tails
        case .tails: return .heads
        }
    }
}

let tails = Coin(13)     // .tails
let heads = Coin(0)      // .heads
let flipped = heads.flip() // .tails
```

## Сирі значення

Варіанти переліку можна наперед заповнити типовими значеннями, які називають [_сирими значеннями_][raw-values].
Усі сирі значення в переліку мають бути одного типу (як-от `Int`, `String` чи `Character`):

```swift
enum NESButton: Character {
    case up = "⬆️"
    case down = "⬇️"
    case left = "⬅️"
    case right = "➡️"
    case a = "🅰️"
    case b = "🅱️"
    case select = "✅"
    case start = "🚦"
}

print(NESButton.left.rawValue) // Prints "⬅️"
```

Ініціалізувати перелік із сирого значення можна за допомогою `init(rawValue:)`. Оскільки може бути передано неприпустиме сире значення, цей ініціалізатор повертає необовʼязкове значення:

```swift
let upButton = NESButton(rawValue: "⬆️") // Optional(NESButton.up)
let invalid = NESButton(rawValue: "🙄")  // nil
```

Swift може автоматично присвоювати сирі значення для переліків `String` і `Int`:

- Для переліків `String` сире значення кожного варіанта типово дорівнює назві цього варіанта.
- Для переліків `Int` сирі значення починаються з `0` і зростають на 1, якщо не вказано іншого.

```swift
enum Planet: Int {
    case mercury = 1, venus, earth, mars
}

print(Planet.earth.rawValue) // Prints 3
```

## Повʼязані значення

Варіанти переліку також можуть зберігати власні значення різних типів разом із кожним варіантом, відомі як [_повʼязані значення_][associated-values]:

```swift
enum Suit: Character {
    case diamonds = "♦️", clubs = "♣️", hearts = "♥️", spades = "♠️"
}

enum Card {
    case ace(Suit)
    case king(Suit)
    case queen(Suit)
    case jack(Suit)
    case number(Suit, Int)

    func description() -> String {
        switch self {
        case .ace(let suit): return "A\(suit.rawValue)"
        case .king(let suit): return "K\(suit.rawValue)"
        case .queen(let suit): return "Q\(suit.rawValue)"
        case .jack(let suit): return "J\(suit.rawValue)"
        case let .number(suit, value): return "\(value)\(suit.rawValue)"
        }
    }
}

let aceOfSpades = Card.ace(.spades)
let twoOfHearts = Card.number(.hearts, 2)

print(aceOfSpades.description()) // Prints "A♠️"
print(twoOfHearts.description()) // Prints "2♥️"
```

Перелік може використовувати або сирі значення, або повʼязані значення, але не обидва.

## Рекурсивні переліки

[Рекурсивний перелік][recursive-enumerations] - це перелік, який має інший примірник цього ж переліку як повʼязане значення для одного чи кількох варіантів.
Щоб увімкнути рекурсію, позначмо варіант (або весь перелік) ключовим словом `indirect`:

```swift
enum BinaryTree {
    case leaf(value: Int)
    indirect case node(left: BinaryTree, value: Int, right: BinaryTree)
}

let tree: BinaryTree = .node(
    left: .leaf(value: 1),
    value: 3,
    right: .node(left: .leaf(value: 5), value: 6, right: .leaf(value: 9))
)
```
