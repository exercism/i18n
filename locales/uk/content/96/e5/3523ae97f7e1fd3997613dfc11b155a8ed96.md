# зайва умовна конструкція

Замість створення блоку `if (...) {}` скористайтеся булевим значенням (англ. Boolean), яке можна безпосередньо повернути з перевірки значення параметра.

Наприклад, такий код:

```javascript
if (param === true) {
  return true;
}
```

можна перетворити на такий:

```javascript
return param === true;
```
