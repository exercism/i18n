# Докладніше

У C# [літерал `null`][null-keyword] позначає відсутність значення. _Нульований_ тип - це тип, який допускає значення `null`.

До C# 8.0 типи посилань завжди були нульованими, а типи значень - ні. Однак [тип значення можна зробити нульованим][nullable-value-types], дописавши до нього знак питання (`?`).

```csharp
string nullableReferenceType = "hello";
nullableReferenceType = null; // Valid as type is nullable

int nonNullableValueType = 5;
nonNullableValueType = null; // Compile error as type is not nullable

int? nullableValueType = 5; // Define nullable value type
nullableValueType = null;   // Valid as type is nullable
```

Звернення до члена змінної, значення якої `null`, скомпілюється без помилок, але під час виконання призведе до винятку `NullReferenceException`:

```csharp
string sentence = "What a nice day!";

// Throws NullReferenceException at runtime
sentence.Length;
```

Щоб запобігти цій поширеній помилці, у C# 8 можна [увімкнути можливість][nullable-csharp-8], яка робить [типи посилань ненульованими за замовчуванням][nullable-reference-types]:

```csharp
string nonNullableReferenceType = "book";
nonNullableReferenceType = null; // Compile warning (no error!)

string? nullableReferenceType = "movie";
nullableReferenceType = null; // Valid as type is nullable
```

Щоб [безпечно працювати зі значеннями, які можуть бути `null`][nullable-types-tutorial], слід перевіряти, чи вони не `null`, перш ніж їх використовувати:

```csharp
string NormalizedName(string? name)
{
    if (name == null)
    {
        return "UNKNOWN";
    }
    else
    {
        // Value is not null at this point, so no compile warning
        // and no runtime NullReferenceException being thrown
        return name.ToUpper();
    }
}

NormalizedName(null); // => "UNKNOWN"
NormalizedName("Elisabeth"); // => "ELISABETH"
```

[Оператор `??`][null-coalescing-operator] дає змогу повернути типове значення, коли значення дорівнює `null`:

```csharp
string? name1 = "John";
name1 ?? "Paul"; // => "John"

string? name2 = null;
name2 ?? "George"; // => "George"
```

[Оператор `?.`][null-conditional-operator] дає змогу безпечно викликати члени значення, яке може бути `null`:

```csharp
string? fruit = "apple";
fruit?.Length; // => 5

string? vegetable = null;
vegetable?.Length; // => null
```

Якщо компілятор вважає, що значення може бути `null`, але ми впевнені, що це не так, [оператор `!.`][null-forgiving-operator] можна використати, щоб придушити попередження. Однак вдаватися до цього оператора варто лише як до останнього засобу.

```csharp
void PrintName(string? name)
{
    // Assume that the IsValid() method only return true
    // when its argument is not null
    if (IsValid(name))
    {
        // No compile warning
        Console.WriteLine(name!.Length);
    }
}
```
