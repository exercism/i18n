# Вступ

Тип `Result` - це рішення в мові Elm для повідомлення про помилки та основа для відновлення після них. Він дещо схожий на тип `Maybe`, але якщо `Maybe` можуть повертати функції, які можуть зазнати невдачі, то він нічого не каже про те, чому ця невдача сталася. `Result` містить цей контекст про причину невдачі.

Тип `Result` визначено так:

```elm
type Result error value
  = Ok value
  | Err error
```

У термінології Elm це називається визначенням «власного типу».
`error` і `value` у `OK value` та `Error error` позначають типову змінну, тобто вони можуть бути будь-якого типу, як-от `Int`, `Bool` чи `String`.
Відповідно, `Result String Int` - це змінна, яка має містити `Int`, а якщо станеться помилка, її буде представлено як `String`.
Існує [модуль Result](https://package.elm-lang.org/packages/elm/core/latest/Result) з безліччю корисних допоміжних функцій для роботи з `Result`.
