# Підказки

## Загальне

- Для кожного завдання кожна функція має повертати замикання, використовуючи передані аргументи.

## 1. Перемістити координати

- Передані аргументи задають величину, на яку треба перемістити пару координат уздовж осей _x_ та _y_.

## 2. Масштабувати координати

- Передані аргументи задають величину, на яку треба масштабувати пару координат по осях _x_ та _y_.

## 3. Поєднати функції перетворення

- Результат першого перетворення - це масив, але функції перетворення приймають два числові аргументи. Нам доведеться дістати значення з масиву.
- Памʼятаймо, що порядок виконання функцій має значення.

## 4. Зберегти результати функцій

- Для цієї функції достатньо мемоїзувати результат останнього перетворення.
- Щоб повернути результат останнього перетворення, нам доведеться перевірити, чи однакові вхідні аргументи.
