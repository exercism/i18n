# Вступ

## Константи та функції

Програми на Haskell складаються з визначень і виразів.

Константне значення визначаємо за допомогою `name = expression`.

```haskell
five = 5

six = 3 + 3
```

Функції визначаємо за допомогою `name parameters... = expression`, де параметри розділяються лише пробілом.

```haskell
add number1 number2 = number1 + number2
```

Виклик функції теж є виразом. Для цього вказуємо її назву й передаємо аргументи для кожного з параметрів функції, розділені пробілами, так само як і у визначенні функції.

```haskell
five = add 2 3
```

Дужки можна використати, щоб задати порядок обчислення виразу.

```haskell
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## Відступи / значущі пробіли

Haskell використовує пробіли та відступи, щоб задавати межі коду.
***Код, який є частиною якогось виразу, має бути відсунутий далі, ніж початок цього виразу.***

- Визначення модуля, імпорту та функцій верхнього рівня мають починатися з найлівішого стовпця.
- Якщо вираз розбито на кілька рядків, код, який є частиною цього виразу, потрібно відсунути під цим виразом щонайменше на один пробіл.
- Частини виразу, згруповані разом, мають бути відсунуті на однакову кількість пробілів.

```haskell
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

## Модулі

Модулі експортують функції.
Це означає, що ми можемо використовувати функції, які модуль надає у своєму списку експорту.
Модуль також може визначати функції лише для внутрішнього використання.
Типово функції, які явно не експортовано, не можна використати ззовні модуля.

На початку модуля ми вказуємо назву модуля.
Якщо у нас є файл Calculator.hs, то модуль слід назвати Calculator.
Потім ми вказуємо функції, які він експортує, а після цього можемо почати писати самі функції.
Отже, почнімо з цього.

```haskell
module Calculator ( add ) where
```

https://learnyouahaskell.github.io/modules#making-our-own-modules

## Коментарі

Коментар - це певний текст у файлі Haskell, який не інтерпретується як код.
Він призначений насамперед для того, щоб його читали ми самі та інші програмісти.
Для однорядкових коментарів є простий синтаксис на основі подвійних дефісів.
Багаторядкові коментарі теж можливі за допомогою пари відкривального та закривального роздільників `{-` і `-}`.

```haskell
-- a single line comment
-- another single line comment

{- a multiline comment
   spanning multiple lines
-}
```
