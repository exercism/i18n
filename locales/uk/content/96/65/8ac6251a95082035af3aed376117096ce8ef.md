# Вказівки

У цій вправі ми напишемо трохи коду, щоб допомогти підготуватися до купівлі транспортного засобу.

На нас чекають три завдання: визначити, чи потрібне посвідчення водія, допомогти вибрати між двома транспортними засобами та оцінити прийнятну ціну вживаного транспортного засобу.

## 1. Визначте, чи потрібне посвідчення водія

Деякі види транспортних засобів вимагають посвідчення водія для керування ними.
Припустімо, що посвідчення вимагають лише види `"car"` і `"truck"`, а всім іншим можна керувати без нього.

Реалізуйте функцію `NeedsLicense(kind)`, яка приймає вид транспортного засобу і повертає булеве значення (англ. Boolean), що вказує, чи потрібне посвідчення для такого виду транспорту.

```go
needLicense := NeedsLicense("car")
// => true

needLicense = NeedsLicense("bike")
// => false

needLicense = NeedsLicense("truck")
// => true
```

## 2. Виберіть між двома можливими транспортними засобами для купівлі

Ми оцінюємо доступні варіанти транспортних засобів.
Нам вдається звузити вибір до двох варіантів, але потрібна допомога, щоб ухвалити остаточне рішення.
Для цього реалізуйте функцію `ChooseVehicle(option1, option2)`, яка приймає два транспортні засоби як аргументи і повертає рішення, що містить варіант, який стоїть першим у лексикографічному порядку.

```go
vehicle := ChooseVehicle("Wuling Hongguang", "Toyota Corolla")
// => "Toyota Corolla is clearly the better choice."

ChooseVehicle("Volkswagen Beetle", "Volkswagen Golf")
// => "Volkswagen Beetle is clearly the better choice."
```

## 3. Обчисліть приблизну ціну вживаного транспортного засобу

Тепер, коли рішення ухвалено, ми хочемо переконатися, що в автосалоні отримаємо справедливу ціну.
Оскільки нас цікавить купівля вживаного транспортного засобу, ціна залежить від його віку.
Для приблизної оцінки припустімо: якщо вік транспортного засобу менший за 3 роки, він коштує 80% початкової ціни, яку мав новим.
Якщо йому щонайменше 10 років, він коштує 50%.
Якщо вік транспортного засобу щонайменше 3 роки, але менше ніж 10 років, він коштує 70% початкової ціни.

Реалізуйте функцію `CalculateResellPrice(originalPrice, age)`, яка застосовує цю логіку за допомогою `if`, `else if` та `else` (є й інші способи, якщо захочеться потренуватися).
Вона приймає початкову ціну та вік транспортного засобу як аргументи і повертає оцінену ціну в автосалоні.

```go
CalculateResellPrice(1000, 1)
// => 800

CalculateResellPrice(1000, 5)
// => 700

CalculateResellPrice(1000, 15)
// => 500
```

**Зверніть увагу**: повернене значення має тип `float64`.
