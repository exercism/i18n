# Додаток до інструкцій

## Про здатність `Stream`

`Stream` - це здатність Unison, яку використовують, щоб випромінювати значення.

Ми можемо використати здатність `Stream`, якщо маємо функцію, яка має видавати значення як побічний ефект під час її виклику. Наприклад, ця функція повертає останнє значення масиву, але випромінює поточний підсумок у міру перегляду кожного елемента:

```
emitRunningTotal : '{Stream Nat} Nat
emitRunningTotal = 'let
  use Nat +
  List.foldLeft (
    acc a -> let
      runningTotal = acc + a
      Stream.emit runningTotal
      a
    ) 0 [1,2,3,4,5]
```

Ми можемо матеріалізувати Stream як List разом із поверненим значенням функції, яка його продукує, за допомогою обробника здатності:

```
> Stream.toListWithResult! emitRunningTotal
  ⧩
  ([1, 3, 5, 7, 9], 5)
```
