# Вступ

[`string`][ref-string] у мові Kotlin - це незмінна послідовність символів Unicode.

[`Immutable`][wiki-immutable] означає, що будь-яка операція над рядком тексту (англ. string) повинна повернути новий рядок тексту: початковий рядок тексту ніколи не змінюється.

[`Unicode`][wiki-unicode] означає, що можна подати більшість систем письма світу, але (на відміну від старіших мов, як-от C) між символами й байтами немає взаємно однозначної відповідності.

Рядок тексту беруть у подвійні лапки `" "`.

Деякі символи потрібно екранувати: `\\`, а також звичні недруковані символи, як-от `\t` (табуляція) та `\n` (перехід на новий рядок).

```kotlin
val s = "Escape backslash \\."
// Escape backslash \.
```

Багаторядкові рядки тексту беруть у три подвійні лапки, і вони можуть містити довільний текст (екранувати не потрібно).

```kotlin
val multi = """I'm a
    multi-line
    string with special characters \ \t """
//I'm a
//    multi-line
//    string with special characters  \ \t 
```

Скористаймося [trimIndent][trimIndent-doc], щоб прибрати спільний відступ у рядках.
Це зручно для форматування рядка тексту:

```kotlin
val multi = """
    I'm a
      multi-line
    string""".trimIndent()

//I'm a
//  multi-line
//string
```

Або ж [trimMargin][trimMargin-doc] дає змогу задати роздільник.
Тоді кожен рядок у `String` починається після роздільника.
Типовим роздільником є `|`, але можна вказати інший роздільник як параметр.
Наприклад:

```kotlin
val multi = """
    |I'm a
    |  multi-line
    |string""".trimMargin()

//I'm a
//  multi-line
//string

val multi2 = """
    start>I'm a
    start>  multi-line
    start>string""".trimMargin("start>")

//I'm a
//  multi-line
//string
```

Рядки тексту можна зʼєднувати за допомогою `+`, але це краще робити лише в коротких і простих випадках.
Є й інші, часто кращі можливості.

## Шаблонні рядки

Ідеться про те, що в деяких інших мовах називають «інтерполяцією».

Якщо рядок тексту містить знак долара `$`, за яким іде ідентифікатор, або містить фігурні дужки (`{expression}`) навколо виразу, то замість них підставляються відповідно значення або результат виразу.

```kotlin
val x = 42
val st = "x is $x, x squared is {x * x}"
// x is 42, x squared is 1764
```

Фігурні дужки `{ }` потрібні навколо виразів, коли інакше розбір був би неоднозначним.

Загалом шаблонні рядки - це ефективніший та ідіоматичніший спосіб поєднувати рядки тексту, ніж використання `+`.

## Функції для роботи з рядками

Kotlin надає _багато_ [`functions`][ref-string-functions] для роботи з рядками.

Здебільшого це [`extensions functions`][ref-extensions], а не члени класу `String`, хоча на те, як ми їх використовуємо, це майже не впливає.

~~~~exercism/note
Доволі складні сторінки [документації][ref-string-functions] Kotlin ховають функції-розширення в типовому поданні.
Обовʼязково натисніть `Members & Extensions`, щоб розгорнути цей розділ.

[ref-string-functions]: https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/
~~~~

Далі наведено лише невелику добірку того, що доступно:

```kotlin
val str = "Hello World!"

str.length              // => 12 (a property, not a function)
str.elementAt(6)        // => W
str.elementAtOrNull(20) // => null (index out of range)
str.substring(6, 11)    // => "World"
str.substringAfter(" ") // => "World!"

str.lowercase()         // => "hello world!"
str.uppercase()         // => "HELLO WORLD!"

str.startsWith("Hel")   // => true
str.endsWith("xyz")     // => false
str.indexOf("0")        // => 4

str.toCharArray()       // => [H, e, l, l, o,  , W, o, r, l, d, !]
"42".toInt() + 1        // => 43  (parsing; see also toFloat)

"Howdy!  ".trim()       // => "Howdy"
```
