# Інструкції

У цій вправі ми допоможемо закоханим старшокласникам зізнатися в коханні в соцмережах, згенерувавши ASCII-серце з їхніми ініціалами:

```
     ******       ******
   **      **   **      **
 **         ** **         **
**            *            **
**                         **
**     J. K.  +  M. B.     **
 **                       **
   **                   **
     **               **
       **           **
         **       **
           **   **
             ***
              *
```

## 1. Отримати першу літеру імені

Реалізуйте функцію `first_letter`. Вона має приймати імʼя та повертати його першу літеру. Вона має прибирати з імені всі зайві пробіли.

```gleam
first_letter("Jane")
// -> "J"
```

## 2. Відформатувати першу літеру як ініціал

Реалізуйте функцію `initial`. Вона має приймати імʼя та повертати його першу літеру у верхньому регістрі, після якої йде крапка. Обовʼязково застосуйте повторно функцію `first_letter`, яку ми визначили на попередньому кроці.

```gleam
initial("Robert")
// -> "R."
```

## 3. Розділити повне імʼя на імʼя та прізвище

Реалізуйте функцію `initials`. Вона має приймати повне імʼя, що складається з імені та прізвища, розділених пробілом, і повертати ініціали. Обовʼязково застосуйте повторно функцію `initial`, яку ми визначили на попередньому кроці.

```gleam
initials("Lance Green")
// -> "L. G."
```

## 4. Помістити ініціали всередину серця

Реалізуйте функцію `pair`. Вона має приймати два повні імені та повертати ініціали всередині ASCII-серця. Обовʼязково застосуйте повторно функцію `initials`, яку ми визначили на попередньому кроці.

```gleam
pair("Blake Miller", "Riley Lewis")
// -> "
//      ******       ******
//    **      **   **      **
//  **         ** **         **
// **            *            **
// **                         **
// **     B. M.  +  R. L.     **
//  **                       **
//    **                   **
//      **               **
//        **           **
//          **       **
//            **   **
//              ***
//               *
// "
```
