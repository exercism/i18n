# Вступ

Словник (`dict`) у Python - це структура даних, яка повʼязує [хешовані][term-hashable] _ключі_ зі _значеннями_ і відома в інших мовах програмування як [хеш-таблиця][hashtable-wikipedia], що змінює розмір, хеш-відображення або [асоціативний масив][associative-array].
Словники - це єдиний вбудований [тип відображення][mapping-types-dict] у Python.


`Keys` мають бути хешованими й унікальними в межах словника.
Типи ключів можуть включати `numbers`, `str` або `tuples` (зі _незмінних_ значень).
Вони не можуть містити _змінні_ структури даних, як-от `lists`, `dict`s або `set`s.
Починаючи з Python 3.7, порядок ключів у `dict` гарантовано збігається з порядком, у якому додано записи.

`values` можуть бути будь-якого типу даних або структури.
 Значення також можуть вкладатися _довільно_, тож вони можуть містити списки списків, підсловники та інші власні чи складені структури даних.

За заданим `key` словники можуть отримати `value` за (у середньому) сталий час (_незалежно від кількості записів_).
Порівняно з пошуком значення в `list` чи `array` (_без знання позиції `index`_), `dict` використовує значно більше памʼяті, але забезпечує дуже швидкий доступ.
Словники особливо корисні в ситуаціях, коли набір елементів великий і до нього потрібно часто звертатися та оновлювати його.


## Створення словників

Словники можна створювати багатьма способами.
Два найпростіші: скористатися конструктором `dict()` або оголосити _літерал_ `dict`.

### Конструктор класу `dict()`

`dict()` (_конструктор класу словників_) можна застосувати до будь-якого обʼєкта, який можна перебрати, де елементи є парами `key`, `value`, або до низки _аргументів_ вигляду `<name>=<value>`:

```python
#Passing a list of key,value tuples.
>>> wombat = dict([('name', 'Wombat'),('speed', 23),('land_animal', True)])
{'name': 'Wombat', 'speed': 23, 'land_animal': True}


#Using key=value arguments.
>>> bear = dict(name="Black Bear", speed=40, land_animal=True)
{'name': 'Black Bear', 'speed': 40, 'land_animal': True}
```

### Літерали словників

`dict` також можна задати безпосередньо як _літерал словника_, використовуючи фігурні дужки (`{}`), які охоплюють пари `key : value`:

```python
>>> whale = {"name": "Blue Whale", "speed": 35, "land_animal": False}
{'name': 'Blue Whale', 'speed': 35, 'land_animal': False}
```

## Доступ до значень у словнику

Щоб отримати запис зі словника, використовують _ключ_ у квадратних дужках (`[]`).
Якщо `key` відсутній у `dict`, виникає `KeyError`:

```python
>>> bear["speed"]
40

>>> bear["color"]
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'color'
```

Звернення до запису через метод `.get(<key>, <default value>)` дозволяє уникнути `KeyError`:

```python
>>> bear.get("color", 'not found')
'not found'
```

## Зміна та додавання значень у словнику

Можна змінити `value` запису, присвоївши його _ключу_ нове значення:

```python
#Assigning the value "Grizzly Bear" to the name key.
>>> bear["name"] = "Grizzly Bear"
{'name': 'Grizzly Bear', 'speed': 40, 'land_animal': True}

>>> whale["speed"] = 25
{'name': 'Blue Whale', 'speed': 25, 'land_animal': False}
```

Нові пари `key`:`value` можна _додати_ у такий самий спосіб:

```python
# Adding a new "color" key with a new "tawney" value.
>>> bear["color"] = 'tawney'
{'name': 'Grizzly Bear', 'speed': 40, 'land_animal': True, 'color': 'tawney'}

>>> whale["blowholes"] = 1
{'name': 'Blue Whale', 'speed': 25, 'land_animal': False, 'blowholes': 1}
```

## Видалення (Pop) записів зі словника

Щоб видалити запис зі словника, використовують метод `.pop(<key>)`.
`.pop()` видаляє пару (`key`, `value`) і повертає `value`, щоб ним можна було скористатися.
Як і `.get()`, `.pop(<key>)` приймає другий аргумент (_`dict.pop(<key>, <default value>)`_), який буде повернуто, якщо `key` не знайдено.
Це запобігає виникненню `KeyError`:

```python
#Using .pop() removes both the key and value, returning the value.
>>> bear.pop("name")
'Grizzly Bear'


#The "name" key is now removed from the dictionary.
#Attempting .pop() a second time will throw a KeyError.
>>> bear.pop("name")
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'name'


#Using a default argument with .pop() will prevent a KeyError from a missing key.
>>> bear.pop("name", "Unknown")
'Unknown'
```

## Перебирання словника в циклі

Перебираючи словник за допомогою `for item in dict` або `while item`, ми типово проходимо лише за _ключами_.
У тому самому циклі можна дістатися до _значень_ за допомогою _квадратних дужок_:

```python
>>> for key in bear:
>>>     print((key, bear[key])) #this forms a tuple of (key, value) and prints it.
('name', 'Black Bear')
('speed', 40)
('land_animal', True)
```

Також можна використати метод `.items()`, який автоматично повертає кортежі (`key`, `value`):

```python
#dict.items() forms (key, value tuples) that can be unpacked and iterated over.
>>> for key, value in whale.items():
>>>     print(key, ":", value)
name : Blue Whale
speed : 25
land_animal : False
blowholes : 1
```

Так само метод `.keys()` повертає `keys`, а метод `.values()` повертає `values`.
