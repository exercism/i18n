# Додаток до інструкцій

## Регістри

| Регістр | Використання | Тип          | Опис                                                        |
| -------- | --------- | ------- | ---------------------------------------------------------- |
| `$a0`    | вхідні дані     | ціле число | категорія: `0` = choice, `1` = ones, `2` = twos, `3` = threes, `4` = fours, `5` = fives, `6` = sixes, `7` = little_straight, `8` = big_straight, `9` = full_house, `10` = four_of_a_kind, `11` = yacht |
| `$a2`    | вхідні дані     | адреса | кубики (масив машинних слів)                                          |
| `$v0`    | вихідні дані     | ціле число | підсумковий рахунок                                            |
| `$t0-9`  | тимчасовий | будь-що     | використовується для тимчасового зберігання                                 |
