# Інструкції

Мозаїку громадського мистецького центру завершили встановлювати минулого
місяця, і тепер Сорока Марґ її виявила. Більшість днів вона міняє одну-дві
плитки на блискучіші зі свого **скарбу** поблизу, або виймає плитку і
зникає на годину.

Наша роль - волонтер, який фіксує кожну зміну. Сама мозаїка - це
**масив фіксованого розміру**: одна комірка на позицію плитки, яка
містить рядок тексту (англ. string) із кольором або `f` для «відсутня».
Скарб Сороки Марґ - це **вектор** окремих плиток, які вона вкрала.

## 1. Розкладіть новий ряд

Визначте `fresh-mosaic`, що приймає довжину `n` і повертає масив
із `n` порожніх комірок (кожна `f`).

```factor
4 fresh-mosaic .
! => { f f f f }
```

## 2. Покладіть плитку

Визначте `place-tile`, що приймає ряд, позицію та колір і
оновлює ряд на місці так, щоб зазначена позиція містила цей колір.
Слово нічого не повертає.

```factor
5 fresh-mosaic   ! { f f f f f }
dup 2 "ruby" place-tile
.
! => { f f "ruby" f f }
```

## 3. Відколіть плитку

Визначте `chip-tile`, що приймає ряд і позицію та оновлює
ряд на місці так, щоб зазначена позиція знову стала `f`.

```factor
{ "ruby" "lapis" "jade" } 1 chip-tile .
! => { "ruby" f "jade" }
```

## 4. Перефарбуйте плитку

Визначте `recolour-tile`, що приймає ряд, позицію та квотейшн
з одним аргументом, і оновлює ряд на місці, застосовуючи квотейшн
до плитки на цій позиції.

```factor
{ "RUBY" "LAPIS" "JADE" } 1 [ >lower ] recolour-tile .
! => { "RUBY" "lapis" "JADE" }
```

## 5. Зробіть знімок, перш ніж прийде Марґ

Визначте `snapshot-mosaic`, що приймає ряд і повертає
незалежну копію, на яку не вплинуть подальші зміни
оригіналу.

```factor
{ "ruby" "lapis" "jade" } dup snapshot-mosaic    ! two equal but independent copies
swap 0 "amber" place-tile                        ! mutate the first
.s
! => { "ruby" "lapis" "jade" }                   (the snapshot)
! => { "amber" "lapis" "jade" }                  (the mutated original)
```

## 6. Марґ кладе плитку до кишені

Визначте `stash-tile`, що приймає скарб Марґ (вектор) і колір
та додає колір до скарбу. Нічого не повертає.

```factor
V{ } clone   ! a fresh empty hoard
dup "ruby"  stash-tile
dup "lapis" stash-tile
.
! => V{ "ruby" "lapis" }
```

## 7. Марґ повертає плитку

Визначте `return-tile`, що приймає скарб Марґ і вилучає та повертає
останню додану плитку (ту, що зверху).

```factor
V{ "ruby" "lapis" "jade" } clone
dup return-tile .
! => "jade"
.
! => V{ "ruby" "lapis" }
```
