# Вступ

## Масиви ключових слів

Масиви ключових слів - це структура даних ключ-значення.

```elixir
[month: "April", year: 2018]
```

Масиви ключових слів - це масиви кортежів `{key, value}`; їх можна записати і в такому вигляді, але коротший синтаксис уживають частіше.

```elixir
[month: "April"] == [{:month, "April"}]
# => true
```

Ключі в масиві ключових слів мають бути [атомами][exercism-atoms], а значеннями може бути будь-що. Кожен ключ можна використати більше ніж один раз. Пари ключ-значення в масиві ключових слів упорядковані.

З масивами ключових слів можна працювати так само, як і з масивами, або скористатися модулем `Keyword`.

[exercism-tuples]: https://exercism.org/tracks/elixir/concepts/tuples
[exercism-atoms]: https://exercism.org/tracks/elixir/concepts/atoms
