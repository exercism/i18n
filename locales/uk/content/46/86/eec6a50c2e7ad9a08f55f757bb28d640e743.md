# Про поняття

Swift - компільована мова програмування з кількома парадигмами, розроблена з трьома основними цілями:

- **Безпека**: вбудовані можливості мови допомагають виявляти і запобігати помилкам, перш ніж код запуститься в продакшені.
- **Швидкість**: оптимізована швидкодія, порівнянна з мовами на базі C.
- **Виразність**: чистий, сучасний синтаксис, який приємно читати і писати.

Компанія Apple представила Swift у 2014 році як сучасну заміну Objective-C, мові, якою раніше розробляли застосунки для iOS і macOS.
Сьогодні Swift має відкритий код і працює на платформах Apple, у Linux і Windows.

## З чого почати

### Змінні

Значення можна зберігати й давати їм імена, визначивши [змінну][constants-variables].
Після визначення змінної її імʼя можна використовувати, щоб посилатися на це значення в усьому коді.
Змінні _змінювані_, тобто їхні значення можна змінити після визначення.

Змінну визначають за допомогою ключового слова `var`:

```swift
var variableName = 10
```

Swift - статично типізована мова, а це означає, що кожне значення має відомий тип уже під час компіляції.
Можна явно оголосити тип за допомогою [анотації типу][type annotations] або дозволити компілятору Swift [вивести тип][type-inferring] із присвоєного значення:

```swift
var explicitVar: Int = 10 // Explicitly typed
var implicitVar = 10      // Implicitly typed (inferred as Int)
```

Оновити значення змінної можна за допомогою оператора присвоєння (`=`):

~~~~exercism/note
Тип змінної не може змінитися після її оголошення.

```swift
variableName = 13 // Allowed: same type (Int)

// Compiler error: cannot assign a different type
variableName = "Hello, world!" // Cannot assign value of type 'String' to type 'Int'
```
~~~~

Змінну можна оголосити без початкового значення, вказавши її тип, але перед використанням їй потрібно присвоїти значення:

```swift
var someInt: Int

// This triggers a compiler error:
// print(someInt) // Variable 'someInt' used before being initialized

// Assign a value first
someInt = 169
print(someInt) // Prints 169
```

### Константи

[Константи][constants-variables] так само повʼязують імʼя зі значенням, але їхні значення не можна змінити після присвоєння.
Вони _незмінні_.
Константу визначають за допомогою ключового слова `let`:

```swift
let constantName = 10          // Inferred constant
let explicitConstant: Int = 10 // Explicitly typed constant
```

### Арифметичні оператори

Swift надає стандартні [арифметичні оператори][arithmetical-operators] для базових обчислень:

- Додавання: `+`
- Віднімання: `-`
- Множення: `*`

```swift
print(1 + 1) // Prints 2
print(2 - 1) // Prints 1
print(2 * 2) // Prints 4
```

### Функції

У Swift [функції][functions] - це самодостатні блоки коду, які виконують конкретне завдання.
Функції можуть приймати вхідні дані, повертати значення і передаватися як значення іншим функціям.
Функцію визначають за допомогою ключового слова `func`, після якого йде назва функції, список параметрів у дужках і необовʼязковий тип поверненого значення:

```swift
func functionName(argumentLabel parameterName: ParameterType) -> ReturnType {
    // Function body
}
```

Функції у Swift використовують [мітки аргументів][argument-labels], завдяки яким код читається як звичайні речення:

- **Мітку аргументу** вказують під час виклику функції.
- **Назву параметра** використовують усередині тіла функції, щоб звертатися до значення.

Якщо вказати лише одне імʼя, Swift використає його і як мітку аргументу, і як назву параметра:

```swift
func greet(name: String) {
    print("Hello, \(name)!")
}

greet(name: "Alice")
```

Якщо під час виклику функції мітка аргументу не потрібна, перед назвою параметра пишуть знак підкреслення (`_`):

```swift
func square(_ number: Int) -> Int {
    return number * number
}

square(5) // Called without an argument label
```

Усі параметри функції типово є константами (`let`), тобто їхні значення не можна змінити всередині тіла функції.

Щоб повернути значення з функції, вказують тип поверненого значення після `->` і використовують ключове слово `return`:

```swift
func addTen(to value: Int) -> Int {
    return value + 10
}

addTen(to: 10) // Returns 20
```

Коли функція не повертає значення, її тип поверненого значення - `Void` (це те саме, що й порожній кортеж, `()`).
У таких функціях можна опустити і тип поверненого значення `-> Void`, і інструкцію `return`.

### Коментарі

У Swift є дві форми [коментарів][comments]:

- **Однорядкові коментарі** починаються з `//` і тривають до кінця рядка.
- **Багаторядкові коментарі** беруть у `/*` та `*/`.

```swift
// This is a single-line comment

/* This is a comment
   that spans multiple lines */
```
