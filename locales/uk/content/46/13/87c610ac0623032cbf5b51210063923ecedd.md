# Детальніше

**Користувацькі** функції створюють за допомогою ключового слова `function`. Після нього потрібно вказати назву функції та список аргументів.

```php
function alarm($hour, $minute, $second)
{
    return 'Alarm!';
}
```

Функції можна викликати у файлі до того, як їх визначено, оскільки вони піднімаються на початок своєї області видимості.

## Іменування

Назви функцій у PHP підкоряються тим самим правилам, що й інші назви: вона має починатися з підкреслення або літери, а далі може містити будь-яку кількість літер, цифр або підкреслень.
