# Інструкції

Ми ведемо розклад рейсів невеликого острівного порома. Відправлення
записуються як дати, тож нам знадобиться кілька помічників для роботи з ними.

## 1. Запис дати рейсу

Визначте `make-date`, яка приймає рік, місяць і день і повертає
відповідну позначку часу.

```factor
2024 7 14 make-date .
! => T{ timestamp { year 2024 } { month 7 } { day 14 } ... }
```

## 2. Назва дня тижня

Визначте `weekday-name`, яка приймає позначку часу рейсу і повертає назву
дня тижня, на який він припадає.

```factor
2024 1 8 make-date weekday-name .
! => "Monday"
```

## 3. Високосні роки

Визначте `leap?`, яка приймає рік і повертає, чи є він високосним.

```factor
2024 leap? .   ! => t
2023 leap? .   ! => f
```

## 4. Кількість днів у місяці

Визначте `month-length`, яка приймає рік і місяць і повертає кількість
днів у цьому місяці (не забудьте про лютий).

```factor
2024 2 month-length .   ! => 29
2023 2 month-length .   ! => 28
```

## 5. Через стільки днів

Визначте `add-days`, яка приймає позначку часу і кількість днів і повертає
позначку часу на стільки днів пізніше.

```factor
2024 2 28 make-date 1 add-days >date< .
! => 29   (2024-02-29)
```
