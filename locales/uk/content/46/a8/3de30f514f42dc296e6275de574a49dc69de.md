# Модулі та шляхи в Cairo

Cairo використовує **модулі** для організації коду.

Модулі допомагають структурувати проєкти та керувати видимістю таких елементів, як функції, структури і трейти.

## Визначення модулів

Модулі визначаємо за допомогою `mod`, і вони можуть бути вкладеними:

```rust
mod front_of_house {
    pub mod hosting {
        pub fn add_to_waitlist() {}
    }
}
```

Функції, структури і трейти **типово приватні**.

Щоб зробити їх доступними поза їхнім модулем, скористаймося `pub`.

## Шляхи: абсолютні та відносні

Щоб звернутися до елемента з іншого модуля, можна скористатися:

- **Абсолютні шляхи** (починаються з `crate::`):

  ```rust
  crate::front_of_house::hosting::add_to_waitlist();
  ```

- **Відносні шляхи** (починаються з поточного модуля):

  ```rust
  front_of_house::hosting::add_to_waitlist();
  ```

  Це працює, якщо `front_of_house` перебуває в тому самому модулі.

## Уведення модулів в область видимості за допомогою `use`

Щоразу писати повні шляхи незручно.

Ключове слово `use` дає змогу писати коротші посилання:

```rust
use crate::front_of_house::hosting;

pub fn eat_at_restaurant() {
    hosting::add_to_waitlist(); // Shorter path
}
```

`use` діє **лише в тій області видимості, де його написано**; якщо він потрібен деінде, його доведеться повторити.

### Ідіоматичне використання `use`

- Вводимо в область видимості **модулі**, а не функції:

  ```rust
  use crate::front_of_house::hosting; // ✅
  hosting::add_to_waitlist();
  ```

  А не так:

  ```rust
  use crate::front_of_house::hosting::add_to_waitlist; // ❌
  add_to_waitlist();
  ```

- Для **трейтів, структур і енумів** використовуємо повний шлях:

  ```rust
  use core::num::traits::BitSize;
  ```

### Псевдоніми за допомогою `as`

За потреби перейменовуємо імпорти:

```rust
use core::array::ArrayTrait as Arr;

fn main() {
    let mut arr = Arr::new();
    arr.append(1);
}
```

### Імпорт кількох елементів

Замість кількох інструкцій `use` групуємо імпорти:

```rust
use shapes::{Square, Circle, Triangle};
```

## Повторний експорт за допомогою `pub use`

Щоб відкрити модуль в іншій структурі, скористаймося `pub use`:

```rust
pub use crate::front_of_house::hosting;
```

Тепер зовнішній код може використовувати `restaurant::hosting::add_to_waitlist()` замість `restaurant::front_of_house::hosting::add_to_waitlist()`.

## Використання зовнішніх пакунків зі Scarb

Щоб додати залежність, оновімо `Scarb.toml`:

```toml
[dependencies]
alexandria_math = { git = "https://github.com/keep-starknet-strange/alexandria.git" }
```

Щоб додати залежності, скористаймося `scarb add <package>`, а щоб видалити їх, скористаймося `scarb rm <package>`.

## Оператор глоб (`*`)

Щоб імпортувати все з модуля:

```rust
use core::num::traits::*;
```

З ним варто поводитися обережно, бо він може зробити код важчим для читання.
