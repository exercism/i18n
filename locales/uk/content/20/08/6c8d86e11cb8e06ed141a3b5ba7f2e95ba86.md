# Вступ

У PHP можна оголошувати функції всередині інших функцій. Такі функції не обовʼязково називати: їх можна присвоїти змінним або навіть одразу передати в іншу функцію, яка приймає функцію як параметр.

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, function($num) {
        return $num % 2 === 1;
    });
}
```
