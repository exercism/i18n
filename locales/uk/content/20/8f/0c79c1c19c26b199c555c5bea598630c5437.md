# Просування властивостей конструктора

Коли клас оголошує багато властивостей, доводиться окремо оголошувати і сам клас, і його властивості, і конструктор, який ці властивості встановлює, а це породжує повторення.
За допомогою просування властивостей конструктора ми можемо зменшити кількість цих повторень.

```php
<?php

class Book
{
    private string $isbn;
    private string $doi;
    private string $title;

    public function __construct(string $isbn, string, $doi, string $title)
    {
        $this->isbn = $isbn;
        $this->doi = $doi;
        $this->title = $title;
    }
}

// Using constructor property promotion
class Book
{
    public function __construct(
        private string $isbn,
        private string $doi,
        private string $title
    ) {
    }
}
