# Вступ

Арифметичне переповнення виникає тоді, коли обчислення, наприклад арифметична операція чи перетворення типів, дає значення, більше за місткість типу, який його приймає.

Вирази типу `int` і `long` та їхні беззнакові відповідники в такому разі непомітно загортаються.

Поведінку обчислень із цілими числами можна змінити за допомогою ключового слова `checked`. Коли переповнення трапляється всередині блоку `checked`, викидається примірник `OverflowException`.

```csharp
int one = 1;
checked
{
    int expr = int.MaxValue + one;   // OverflowException is thrown
}

// or

int expr2 = checked(int.MaxValue + one);     // OverflowException is thrown
```

Вирази типу `float` і `double` набувають спеціального значення нескінченності.

Вирази типу `decimal` викидають примірник `OverflowException`.
