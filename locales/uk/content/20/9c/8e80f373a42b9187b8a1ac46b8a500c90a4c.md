# Інструкції

У цій вправі ми будемо обробляти записи журналу.

Кожен рядок журналу - це рядок тексту (англ. string) такого формату: `"[<LEVEL>]: <MESSAGE>"`.

Є три різні рівні журналу:

- `INFO`
- `WARNING`
- `ERROR`

У нас є три завдання; у кожному треба взяти рядок журналу і щось із ним зробити. Є багато способів розвʼязати ці завдання: виберімо улюблені прийоми з наведених вище прикладів і подивімося, що в нас вийде.

## 1. Отримати повідомлення з рядка журналу

Реалізуйте функцію `message`, щоб вона повертала повідомлення з рядка журналу:

```jq
"[ERROR]: Invalid operation" | message
# => "Invalid operation"
```

Усі пробільні символи на початку та в кінці потрібно прибрати:

```jq
"[WARNING]:  Disk almost full\r\n" | message
# => "Disk almost full"
```

## 2. Отримати рівень журналу з рядка журналу

Реалізуйте функцію `log_level`, яка повертає рівень журналу з рядка журналу; його потрібно повертати малими літерами:

```ruby
"[ERROR]: Invalid operation" | log_level
# => "error"
```

## 3. Переформатувати рядок журналу

Реалізуйте функцію `reformat`, яка переформатовує рядок журналу, ставлячи повідомлення першим, а рівень журналу після нього в дужках:

```ruby
"[INFO]: Operation completed" | reformat
# => "Operation completed (info)"
```
