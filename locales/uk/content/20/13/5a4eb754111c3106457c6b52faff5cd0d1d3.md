# Вступ

Коли треба розгалужуватися за кількома окремими можливими значеннями, `case` (з [`combinators`][combinators]) пасує краще, ніж ланцюжок `if`.

## `case`

```
case ( obj assoc -- )
```

`case` знімає значення з вершини стека і бере *асоціативний масив* клауз. Кожна клауза має вигляд `{ value [ body ] }`. Перемагає перша клауза, чиє значення `=` вхідному; її тіло виконується, а вхідне значення на той час *уже знято зі стека*. Завершальний запис, який містить лише `[ body ]`, є типовим: коли він виконується, вхідне значення *все ще лежить на стеку*.

```factor
USING: combinators ;

: name-of ( n -- s )
    {
        { 1 [ "one" ] }
        { 2 [ "two" ] }
        [ drop "many" ]
    } case ;
```

Рівність визначає `=`, тож ключем може бути будь-що, що порівнюється як рівне: числа, рядки тексту (англ. string) і символи.

## `cond` для розгалужень за умовою

Коли вибір залежить від *предиката*, а не від рівності (наприклад, `x > 11`), `cond` — саме той інструмент. Ми вже зустрічали `cond` у вправі [Машини, збираймося!][cars-assemble].

## Символи

`SYMBOL:` оголошує слово, яке кладе саме себе на стек, тобто значення-мітку, що обчислюється саме в себе. `SYMBOLS:` оголошує одразу кілька таких слів:

```factor
SYMBOLS: yes no maybe ;
```

Тепер `yes` є значенням, яке порівнюється через `=` і яке можна використати як ключ для `case`:

```factor
: invert ( ? -- ?' )
    { { yes [ no ] } { no [ yes ] } [ ] } case ;
```
