# Інструкції

Танцювальна трупа шикується в ряди, а ми стежимо за тим, хто де стоїть.

Усі пʼять завдань потрібно виконати в класі `DANCE_FORMATION`.

## 1. Скільки людей у ряду?

```sather
DANCE_FORMATION::dancer_count(|"Mia", "Ana", "Ben"|)
-- => 3
```

## 2. Хто веде?

Ряд очолює той, хто стоїть першим.

```sather
DANCE_FORMATION::leader(|"Mia", "Ana", "Ben"|)
-- => "Mia"
```

## 3. Хто в кінці?

Ряд замикає той, хто стоїть останнім, яким би довгим він не був.

```sather
DANCE_FORMATION::back_marker(|"Mia", "Ana", "Ben"|)
-- => "Ben"
```

## 4. Початкова побудова

Трупа завжди відкриває виступ у тому самому порядку: Mia, Ana, Ben. Поверніть цей ряд.

```sather
DANCE_FORMATION::opening_row
-- => an array holding "Mia", "Ana" and "Ben", in that order
```

Ця процедура не приймає аргументів.

## 5. Порахуйте кроки

Кожен танцюрист має свою кількість кроків. Додайте їх.

```sather
DANCE_FORMATION::total_steps(|8, 16, 8|)
-- => 32
```

Порожній ряд - це нуль кроків.
