# Інструкції

Перетворіть шістнадцяткове число, подане як рядок тексту (англ. string), наприклад «10af8c», на відповідне десяткове число, виходячи з базових принципів (тобто ні, для цього перетворення не можна використовувати вбудовані або зовнішні бібліотеки).

У вебі ми використовуємо шістнадцяткові числа для позначення кольорів, наприклад: зелений: 008000, бірюзовий: 008080, темно-синій: 000080.

Програма повинна вміти обробляти некоректні шістнадцяткові рядки тексту.
