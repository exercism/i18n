# Тести

Якщо завантажити вправу за допомогою інструмента CLI, ми побачимо файл Uiua, названий за назвою вправи, і файл `tests.ua`.
Цей файл містить усі тестові випадки, які збігаються з тими, що їх запускає засіб запуску тестів, коли ми завантажуємо свій розвʼязок.
Додавайте додаткові тестові випадки для експериментів.
Однак редагування тестів не впливає на онлайн-перевірку.

## Локальне тестування

Щоб запустити тести вправи, відкрийте термінал у каталозі вправи та виконайте команду `uiua test tests.ua`.

Наприклад, виведення незміненої вправи `hello-world` може мати такий вигляд:

```bash
$ uiua test tests.ua
Error: Goodbye, Mars!
  at tests.ua:3:1
3 | ⍤⤙≍ "Hello, World!" Hello
    ─
Test failed
```

Рядок `Error` показує фактичне виведення нашого коду.
Номер рядка вказує на місце очікуваного результату у файлі `tests.ua`.
Правильний розвʼязок дає такий результат:

```bash
$ uiua test tests.ua
Test passed
```
