# Інструкції

У цій вправі ми працюватимемо над планувальником записів для салону краси.

На нас чекають три завдання, і всі вони повʼязані з датами записів.

## 1. Перевірте, чи запис уже минув

Реалізуйте підпрограму `appointment_has_passed`, яка приймає рядок тексту (англ. string) з датою й перевіряє, чи запис був десь у минулому:

```perl
appointment_has_passed("2019-07-25T13:45:00")
// => true
```

Рядки тексту з датами передаватимуться у форматі дати й часу ISO 8601: `YYYY-mm-ddTHH:MM:SS`

Вам знадобиться реалізувати приватну підпрограму `_parse_datetime`.
Пропонуємо кілька модулів:

- [Time::Piece][time-piece] входить до стандартної поставки Perl.
- [DateTime::Tiny][datetime-tiny] можна встановити з CPAN.

## 2. Перевірте, чи запис припадає на час після обіду

Реалізуйте функцію `is_afternoon_appointment`, яка приймає рядок тексту з датою й перевіряє, чи запис припадає на час після обіду (>= 12:00 та < 18:00):

```perl
is_afternoon_appointment("2019-07-25T13:45:00")
// => true
```

## 3. Опишіть час і дату запису

Реалізуйте функцію `describe_appointment`, яка приймає рядок тексту з датою й повертає опис цих дати й часу:

```perl
describe_appointment("2019-07-25T13:45:00")
// => "You have an appointment on 07/25/2019 1:45 PM"
```

Зауважте: година лежить у діапазоні від 0 до 12 і не має провідного нуля чи пробілу.

[time-piece]: https://perldoc.perl.org/Time::Piece
[datetime-tiny]: https://metacpan.org/pod/DateTime::Tiny
