# Instructions

У нашому місті є кілька піцерій, які продають піцу шматками, і ми хочемо написати вебзастосунок, який дозволить порівнювати дві різні конфігурації піци, щоб дізнатися, хто дасть більший шматок.

## 1. Напишіть функцію, яка обчислює розміри шматків і повертає `nil` для некоректних вхідних даних.

Реалізуйте функцію `sliceSize(diameter: Double?, slices: Int?) -> Double?`, яка за діаметром піци та кількістю шматків на піцу повертає площу одного шматка.
Для відʼємних діаметрів і кількості шматків менше 1 поверніть `nil`, адже не існує піци з відʼємним діаметром і неможливо розрізати піцу на менш ніж 1 шматок.
Якщо будь-який із параметрів дорівнює `nil`, також поверніть `nil`.

```swift
sliceSize(diameter: 16, slices: 12)
// Returns 16.75516081914556
sliceSize(diameter: nil, slices: 8)
// Returns nil
```

## 2. Обробіть вхідні дані з вебзастосунку, щоб визначити більший шматок.

Наш вебзастосунок передаватиме у функцію `biggestSlice(diameterA: String, slicesA: String, diameterB: String, slicesB: String) -> String` чотири рядки тексту (англ. string).
Перший і другий рядки тексту містять відповідно діаметр і кількість шматків першої піци, а третій і четвертий - діаметр і кількість шматків другої піци.

Реалізуйте `biggestSlice` так, щоб вона намагалася перетворити діаметр і кількість шматків кожної піци відповідно на `Double` та `Int`.
Якщо обидва ці значення можна отримати з рядків тексту, скористайтеся першою функцією, щоб спробувати обчислити площу, інакше площа цього шматка дорівнює `nil`.
Коли площі обох шматків отримано, порівняйте ці дві площі за такими правилами:

1. Якщо площа шматка A має тип `Double`, а площа шматка B дорівнює `nil`, поверніть «Slice A is bigger». Якщо навпаки, поверніть «Slice B is bigger».
2. Якщо обидві площі мають тип `Double`, поверніть «Slice A is bigger» або «Slice B is bigger» залежно від того, який шматок має більшу площу.
3. Якщо обидві площі дорівнюють `nil` або якщо обидві мають тип `Double` і вони рівні, поверніть «Neither slice is bigger».

~~~~exercism/note
Навіть якщо вхідні дані призводять до площі шматка 0, шматок усе одно вважається дійсним і має розглядатися як більший за шматок із площею `nil`.
~~~~

```swift
biggestSlice(diameterA: "10", slicesA: "6", diameterB: "14", slicesB: "12")
// Returns "Slice A is bigger"
biggestSlice(diameterA: "10", slicesA: "6", diameterB: "12", slicesB: "8")
// Returns "Slice B is bigger"
biggestSlice(diameterA: "Pepperoni", slicesA: "6", diameterB: "Sausage", slicesB: "12")
// Returns "Neither slice is bigger"
```
