# Інструкції

Еліз, майбутня чарівниця, продовжує навчання. Їй дадуть кілька стосів карт, з якими вона виконуватиме свої трюки.
Щоб трохи спростити, вона використовує лише карти від 1 до 10.

У цій вправі використайте вбудовані методи, щоб проаналізувати вміст масиву.

## 1. Знайти позицію карти

Еліз хоче знати позицію (індекс) карти в стосі.

```javascript
const card = 2;
getCardPosition([9, 7, 3, 2], card);
// => 3
```

## 2. Визначити, чи є карта в стосі

Еліз хоче визначити, чи є карта в стосі, тобто чи містить стос конкретне `number`.

```javascript
const card = 3;
doesStackIncludeCard([2, 3, 4, 5], card);
// => true
```

## 3. Визначити, чи кожна карта парна

Еліз хоче знати, чи кожна карта парна, тобто чи кожне число в стосі є парним `number`.

```javascript
isEachCardEven([2, 4, 6, 7]);
// => false
```

## 4. Перевірити, чи містить стос карту з непарним значенням

Еліз хоче знати, чи є в стосі непарне число.

```javascript
doesStackIncludeOddCard([3, 2, 6, 4, 8]);
// => true
```

## 5. Отримати першу непарну карту зі стосу

Еліз хоче знати значення першої карти, яка є непарною.

```javascript
getFirstOddCard([4, 2, 8, 7, 9]);
// => 7
```

## 6. Визначити позицію першої парної карти

Еліз хоче знати позицію першої парної карти.

```javascript
getFirstEvenCardPosition([5, 2, 3, 1]);
// => 1
```
