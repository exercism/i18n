# Вступ

Інтерфейс можна розуміти як сигнатуру класу, адже він описує публічні поля класу. Клас _implements_ `interface` за допомогою ключового слова `implments`.

Синтаксис інтерфейсу дуже схожий на синтаксис класу, за винятком того, що методи подано як сигнатури без тіл:

```haxe
interface Language {
  private var languageName:String;

  public function speak():String;
}

class FrenchSpeaker implements Language {
  var languageName = "French";

  public function speak():String {
    return "Bonjour!";
  }
}
```

Поля, які реалізуються з інтерфейсу, **повинні** завжди використовувати той самий модифікатор видимості. Наприклад, якщо змінна `a` є `public` в інтерфейсі, її реалізація також має бути `public`.
