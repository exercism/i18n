# Вступ

`string` (рядок тексту) у C# - це обʼєкт, який представляє незмінний текст як послідовність символів Unicode (літер, цифр, розділових знаків тощо). Подвійні лапки використовують для визначення екземпляра `string`:

```csharp
string fruit = "Apple";
```

Рядками тексту керують, викликаючи методи рядка. Після створення рядка тексту його значення вже ніколи не може змінитися. Будь-які методи, які на вигляд змінюють рядок тексту, насправді повертають новий рядок тексту.

Кілька рядків тексту можна зʼєднати (додати) один до одного. Найпростіший спосіб зробити це - використати оператор `+`.

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

Для будь-якого форматування рядків тексту, складнішого за просту конкатенацію, краще використовувати інтерполяцію рядків тексту. Щоб використати інтерполяцію в рядку тексту, поставимо перед ним символ долара (`$`). Тоді ми можемо використати фігурні дужки (`{}`), щоб отримати доступ до будь-яких змінних усередині рядка тексту.

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
