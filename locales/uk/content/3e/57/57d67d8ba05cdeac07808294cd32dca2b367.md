# Вступ

**Слово** у Factor - це назва функції. Спираючись на стек даних із `basics`, ця концепція присвячена визначенню власних слів: виконанню арифметичних дій, наданню імен фіксованим значенням і побудові слів з інших слів.

Означення починається з `:`, задає стековий ефект, далі йде тіло, а потім `;`. Компілятор перевіряє, що тіло відповідає оголошеному ефекту:

```factor
: square ( x -- x*x ) dup * ;

4 square .    ! => 16
```

Слова цілочисельної арифметики `+`, `-`, `*` кожне вилучає зі стека два числа й кладе результат на стек. Вони належать до словника `math`, тож файл, який їх використовує, потребує `math` у рядку `USING:`. Правий операнд лежить на верхівці стека:

```factor
2 3 + .    ! => 5
8 3 - .    ! => 5    (8 - 3, not 3 - 8)
2 3 * .    ! => 6
```

`CONSTANT:` дає імʼя фіксованому значенню. Константа сама є словом: виклик її кладе значення на стек:

```factor
CONSTANT: pi 3

pi pi * .    ! => 9
```

Тіло слова може викликати будь-яке слово, яке вже є в області видимості, зокрема ті, що ми визначили раніше в тому самому файлі:

```factor
: double    ( x -- 2x ) 2 * ;
: quadruple ( x -- 4x ) double double ;

5 quadruple .    ! => 20
```

Кінцевий `?` у вихідних даних означає булеве значення (англ. Boolean), а слова й константи використовують `lowercase-kebab-case`.
