# Вступ до масивів

Bash надає два типи параметрів: «скалярні» значення та масиви.
Скалярне значення може бути рядком тексту (англ. string) або числом; воно представляє одну «річ».

Здебільшого скалярних значень достатньо, щоб умістити наші дані.
Але іноді потрібно зберегти масив скалярних значень.
У такому разі ми використаємо _масив_.

Є два види масивів:

* Масиви з числовими індексами зіставляють цілому числу як ключу значення, що є рядком тексту.
  (В інших мовах це можуть називати «списком» або «послідовністю».)
* Асоціативні масиви зіставляють ключ-рядок тексту зі значенням-рядком тексту.
  (В інших мовах це можуть називати «мапою» або «словником».)

Перші кілька розділів цього документа присвячено масивам з числовими індексами (далі просто «масиви»).
Подробиці про асоціативні масиви будуть наприкінці.

~~~~exercism/caution
Масиви Bash можуть зберігати _лише_ скалярні значення.
Створити двовимірний масив (масив масивів) неможливо.
~~~~

## Оголошення та ініціалізація змінної-масиву

Ми можемо ініціалізувати масив, присвоївши змінній узятий у дужки список елементів (можливо, порожній).

```bash
myarray=("one" "two" "three")
```

Як і в разі будь-якого присвоєння змінній, навколо знака рівності не повинно бути пробілів.

Зауважмо, що між елементами немає ком; це список рядків тексту, розділених пробільними символами.

Насправді кількість пробільних символів усередині дужок цілком довільна.
Переходи на новий рядок дозволені; щоб покращити читабельність, можна додати їх скільки завгодно.

```bash
myarray=(
    "first element"
    "second element"
    "this is the last element"
)
```

Якщо присвоїти список рядків тексту змінній-масиву в такий спосіб, перший рядок тексту буде збережено за індексом нуль, наступний за індексом один, наступний за індексом два, і так далі.

Можна ініціалізувати «розріджений масив», указавши потрібні нам індекси.

```bash
raindrops=([3]="Pling" [5]="Plang [7]="Plong")
```

~~~~exercism/note
Повторимо: індекси масиву починаються з нуля.
Цей фрагмент виводить «true»:

```bash
myarray=("one" "two" "three")
[[ "${myarray[0]}" == "one" ]] && echo true || echo false
```
~~~~

Щоб указати, що змінна міститиме масив, можна скористатися командою `declare` (або `local` усередині функції).

```bash
declare -a myarray
```

Ідіоматичніше просто присвоїти змінній узятий у дужки список (можливо, порожній), щоб її ініціалізувати.

## Доступ до елементів масиву

Як ми бачили в примітці вище, синтаксис доступу до елемента масиву такий: `${myarray[$index]}`.
Індекс указується в квадратних дужках.
Фігурні дужки обовʼязкові.

~~~~exercism/note
У масивах з числовими індексами індекс є арифметичним виразом.
Посібник Bash [зазначає][arithmetic]:

> В арифметичному виразі змінні оболонки також можна згадувати за іменем, не використовуючи синтаксис розкриття параметрів.

Це означає, що для «простої» підстановки змінної `$` не обовʼязковий.
Доступ до елементів можна записати так, і це трохи легше читати:

```bash
i=5
echo "${myarray[i]}"
# ..............^
```

[arithmetic]: https://www.gnu.org/software/bash/manual/bash.html#Shell-Arithmetic
~~~~

Якщо заданого індексу немає в масиві, результатом розкриття буде порожній рядок тексту.

## Присвоєння елементів масиву

Щоб присвоїти значення конкретному елементу масиву, скористаймося таким синтаксисом:

```bash
myarray[10]="hello"
```

Щоб _дописати_ елементи в масив, скористаймося оператором конкатенації-присвоєння `+=` і дужками:

```bash
myarray+=("new element 1" "new element 2")
```

## Перебирання масиву

Зазвичай нам потрібно перебрати _значення_ масиву.
Скористаймося циклом `for` (який ми бачили в концепції [Цикл][looping]):

```bash
myarray=("one" "two" "three")
for value in "${myarray[@]}"; do
    echo "$value"
done
```

Звернімо увагу на спеціальний синтаксис розкриття масиву: `"${myarray[@]}"`
Ця форма розкриття параметра підставляє значення масиву як окремі слова.
Вона приблизно еквівалентна такому запису:

```bash
for value in "${myarray[0]}" "${myarray[1]}" ... "${myarray[n]}"
```

Форма `"${myarray[@]}"` працює й з розрідженими масивами, розкриваючись лише в задані значення.

Це спеціальне розкриття, де замість індексу стоїть символ `@`, особливе лише всередині подвійних лапок.

#### Інші спеціальні розкриття параметрів

Ось ще кілька фрагментів спеціального синтаксису, потрібних нам для перебирання масиву.
Вони описані в посібнику в розділі [Shell Parameter Expansion][man-expn].

Щоб дізнатися _довжину_ масиву, скористаймося `${#myarray[@]}`, із символом `#` перед іменем.
«Довжина» масиву - це кількість елементів у ньому.

Щоб отримати список _індексів_ масиву, скористаймося `"${!myarray[@]}"`, із символом `!` перед іменем, а розкриття берімо в подвійні лапки.
У масивах з числовими індексами індекси розкриваються в числовому порядку.

### Перебирання індексів масиву

Іноді нам потрібен як індекс, так і значення.
Є кілька способів це зробити.

1. Якщо відомо, що індекси утворюють неперервну послідовність, можна скористатися _арифметичним_ циклом `for`.

   ```bash
   for ((i = 0; i < ${#myarray[@]}; i++)); do
       echo "$i -> ${myarray[i]}"
   done
   ```

   Звернімо увагу на синтаксис `${#myarray[@]}` із символом `#` перед іменем масиву.
   Оскільки індексація масивів починається з нуля, останній індекс масиву на одиницю менший за довжину масиву.

2. Якщо масив розріджений, можна скористатися такою формою:

   ```bash
   for index in "${!raindrops[@]}"; do
       echo "$index -> ${raindrops[index]}"
   done
   ```

   Звернімо увагу на синтаксис `${!myarray[@]}` із символом `!` перед іменем масиву.

## Перегляд вмісту масиву

Щоб подивитися вміст масиву, скористаймося командою `declare` з опцією `-p`:

```bash
a=("the 'first' element"
   second
   third
   'the "last" element')
declare -p a
```

Вона виводить вміст у канонічному для оболонки форматі лапок.

```bash
declare -a a=([0]="the 'first' element" [1]="second" [2]="third" [3]="the \"last\" element")
```

## Асоціативні масиви

Повторимо: в асоціативних масивах як індекси використовуються рядки тексту, а не числа.
Усе сказане вище стосується й асоціативних масивів, але з невеликими відмінностями.
Зазвичай ми вживаємо термін «ключ», а не «індекс»: асоціативні масиви зіставляють ключі зі значеннями.

### Оголошення асоціативного масиву

На відміну від масивів, асоціативні масиви **обовʼязково** треба оголошувати.
Скористаймося опцією `-A` для `declare` (або `local` у функції):

```bash
declare -A mymap

myfunc() {
    local -A my_local_map
    # ...
}
```

### Ініціалізація асоціативного масиву

Пари ключ-значення задаються в списку в дужках:

```bash
mymap=([first]=foo [second]=bar [third]=baz)
declare -p mymap
```

Це виводить:

```
declare -A mymap=([second]="bar" [first]="foo" [third]="baz")
```

~~~~exercism/note
Зауважмо, що асоціативні масиви **невпорядковані**.
~~~~

Оголошення й ініціалізацію можна записати одним рядком.

```bash
declare -A mymap=([first]=foo [second]=bar [third]=baz)
```

У новіших версіях Bash для ініціалізації можна використати список вигляду `(key value key value ...)`.

```bash
declare -A mymap=(first foo second bar third baz)
```

### Доступ до значень

Для доступу до елементів використовується той самий синтаксис, що й раніше: `${mymap[$key]}`.

Ключі асоціативних масивів не обчислюються в арифметичному контексті.
Потрібен звичайний синтаксис розкриття параметрів.

### Присвоєння в асоціативному масиві

Присвоєння використовує той самий синтаксис, що й раніше:

```bash
mymap[$key]="$value"
```

### Перебирання

Для перебирання можна скористатися циклом `for value in "${mymap[@]}"`.
Однак зазвичай нам потрібен і ключ разом зі значенням.

Скористаймося синтаксисом `"${!mymap[@]}"`, який ми бачили вище.

```bash
for key in "${!mymap[@]}"; do
    echo "$key -> ${mymap[$key]}"
done
```

Це виводить

```
second -> bar
first -> foo
third -> baz
```

Наголосимо ще раз: ключі не мають жодного порядку.
