# Додаток до інструкцій

## Регістри

| Регістр | Використання | Тип | Опис |
| -------- | --------- | ------- | ---------------------------------------------------------------------------------- |
| `$a0`    | вхід     | ціле число | сторона a                                                                             |
| `$a1`    | вхід     | ціле число | сторона b                                                                             |
| `$a2`    | вхід     | ціле число | сторона c                                                                             |
| `$v0`    | вихід    | ціле число | тип трикутника (`0` = різносторонній, `1` = рівнобедрений, `2` = рівносторонній, `3` = недійсний) |
| `$t0-9`  | тимчасовий | будь-який | використовується для тимчасового зберігання                                                         |
