# Інструкції

У цій вправі ми великі фанати спорту й щойно відкрили в собі пристрасть до баскетболу НБА. Оскільки ми новачки в баскетболі НБА, ми глибоко занурюємося в історію НБА, відстежуємо команди, тренерів, їхню статистику перемог і поразок та порівнюємо їх між собою.

Оскільки в нас ще немає улюбленої команди, ми також розробимо алгоритм, який визначатиме, чи варто вболівати за ту чи іншу команду.

На нас чекають сім завдань, які допоможуть розробити власний алгоритм _вболівання за команду_.

## 1. Визначмо модель

Визначмо запис `Coach` із такими двома полями:

- `name`: імʼя тренера, типу `String`.
- `former_player`: указує, чи був тренер колишнім гравцем, типу `Bool`.

Визначмо запис `Stats` із такими двома полями:

- `wins`: кількість перемог, типу `Int`.
- `losses`: кількість поразок, типу `Int`.

Визначмо запис `Team` із такими трьома полями:

- `name`: назва команди, типу `String`.
- `coach`: тренер команди, типу `Coach`.
- `stats`: статистика команди, типу `Stats`.

## 2. Створімо тренера команди

Реалізуймо функцію `create_coach`, яка приймає імʼя тренера та його статус колишнього гравця як параметри й повертає запис `Coach`:

```gleam
create_coach("Larry Bird", True)
// -> Coach(name: "Larry Bird", former_player: True)
```

## 3. Створімо статистику команди

Реалізуймо функцію `create_stats`, яка приймає кількість перемог і кількість поразок як параметри й повертає запис `Stats`:

```gleam
create_stats(58, 24)
// -> Stats(wins: 58, losses: 24)
```

## 4. Створімо команду

Реалізуймо функцію `create_team`, яка приймає назву команди, тренера та запис зі статистикою як параметри й повертає запис `Team`:

```gleam
let coach = create_coach("Larry Bird", True)
let stats = create_stats(58, 24)
create_team("Indiana Pacers", coach, stats)
// -> Team(
//   name: "Indiana Pacers",
//   coach: Coach(name: "Larry Bird", FormerPlayer = True),
//   stats: Stats(wins: 58, losses: 24),
// ) 
```

## 5. Замінімо тренера

Власники клубів НБА нетерплячі, тож ми помітили, що погані результати команди часто призводять до заміни тренера. Реалізуймо функцію `replace_coach`, яка приймає команду та її нового тренера як параметри й повертає команду, але вже з новим тренером:

```gleam
let coach = create_coach("Larry Bird", True)
let record = create_stats(58, 24)
let team = create_team("Indiana Pacers", coach, record)

let new_coach = create_coach("Isiah Thomas", True)
replace_coach(team, new_coach)
// -> Team(
//   name: "Indiana Pacers",
//   coach: Coach(name: "Isiah Thomas", FormerPlayer = True),
//   stats: Stats(wins: 58, losses: 24),
// ) 
```

## 6. Перевірмо, чи це та сама команда

Порпаючись у статистиці, ми ведемо списки команд та їхню статистику. Іноді ми помиляємося, і в списку трапляються дублікати. Реалізуймо функцію `is_same_team`, яка приймає дві команди й повертає `True`, якщо це та сама команда, інакше повертає `False`:

```gleam
let pacers_coach = create_coach("Larry Bird", True)
let pacers_stats = create_stats(58, 24)
let pacers_team = create_team("Indiana Pacers", pacers_coach, pacers_stats)

let lakers_coach = create_coach("Del Harris", False)
let lakers_stats = create_stats(61, 21)
let lakers_team = create_team("LA Lakers", lakers_coach, lakers_stats)

is_same_team(pacers_team, lakers_team)
// -> False
```

## 7. Перевірмо, чи варто вболівати за команду

Передивившись багато команд і матчів, ми вигадали алгоритм. Якщо виконується хоча б одна з наведених умов, ми вболіваємо за цю команду:

- Імʼя тренера - «Gregg Popovich»
- Тренер раніше був гравцем
- Команда має назву «Chicago Bulls»
- Команда здобула 60 або більше перемог
- Команда має більше поразок, ніж перемог

Реалізуймо функцію `root_for_team`, яка приймає команду й повертає `True`, якщо за цю команду варто вболівати, інакше повертає `False`:

```gleam
let spurs_coach = create_coach("Gregg Popovich", False)
let spurs_stats = create_stats(56, 26)
let spurs_team = create_team("San Antonio Spurs", spurs_coach, spurs_stats)
root_for_team(spurs_team)
// -> True
```
