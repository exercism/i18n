# Вступ

Конструкція `try..rescue` дає змогу перехоплювати помилки, коли вони виникають. Перехоплення помилок дозволяє функціям повертати визначені значення, коли це потрібно. Конструкція `try..rescue` також має дві додаткові можливості, які ми можемо використати:

- блок `else`
  - Коли блок `try` виконується успішно, результат зіставляється з цим блоком.
- блок `after`
  - Незалежно від того, чи блок `try` виконується успішно, чи спричиняє помилку, код у блоці `after` завжди виконується, якщо програма на цей момент усе ще працює.
  - Результат блоку `after` не повертається до області видимості, з якої його викликали.

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```
