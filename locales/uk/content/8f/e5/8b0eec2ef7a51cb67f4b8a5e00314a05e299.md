# Онбординг працівників у базі даних

## Постановка задачі

ABC Corp планує зберігати в базі даних всю інформацію про дрібні грошові виплати працівникам. Ми допомагаємо фінансовому відділу ABC Corp це впровадити. Оскільки ABC Corp розширює свою діяльність, нових працівників наймають часто, тож і додавати їх до системи доводиться регулярно.

Завдання - додати надані дані нового працівника до таблиці `Employee` у базі даних і повернути значення автоматично згенерованого стовпця `employee_id`, не виконуючи додаткового запиту до бази даних, щоб його знайти. Якщо під час виконання виникне помилка, потрібно повернути `-1`.

## Відомості про базу даних

Для цієї задачі використовуйте надану базу даних H2.

> Файл зразкової бази даних - `gofigure.mv.db`, а назва бази даних - `gofigure`. Його надано в папці `db`.

У зразковій базі даних H2 вже є такі таблиці з деякими зразковими даними. Назви стовпців і типи даних наведено нижче.

**Назва таблиці**: `Employee`

| **Стовпці:**      | тип |
| -----------       | ----------- |
| `employee_id`     | ціле число, автоінкрементований первинний ключ       |
| `name`            | рядок тексту (англ. string)        |
| `city`            | рядок тексту        |
| `department`      | рядок тексту        |
| `age`             | ціле число        |

**Назва таблиці**: `Payment`

| **Стовпці:**      | тип |
| -----------       | ----------- |
| `payment_id`      | ціле число, автоінкрементований первинний ключ       |
| `date`            | дата        |
| `amount`          | десяткове число        |
| `employee_id`     | ціле число        |
| `reason`          | рядок тексту        |

* Файл бази даних - `gofigure.mv.db`. Використовуйте JDBC URL у вигляді `jdbc:h2:file:/path/to/db/file`
* Імʼя користувача: `root`
* Пароль: `root`

## Обмеження

* Використовуйте файл бази даних H2, наданий у папці `db`, щоб перевіряти запити та зразок Ballerina
* Скористайтеся підходом maven dependency params, щоб додати драйвер бази даних H2 як платформну залежність у своєму файлі Ballerina.toml
* Не виконуйте ще одного запиту до бази даних, щоб знайти автоматично згенерований ідентифікатор


## Середовище тестування

* Тести можна запустити командою `bal test`, і вони виконаються проти наданої зразкової бази даних.

## Приклади

### Приклад 1

**Вхідні дані** : dbFilePath: `"./db/gofigure"`, name : `“John Doe”`, city: `“Omaha”`, department : `“Sales”`, age: `24`

**Вихідні дані** : `4`

### Приклад 2

**Вхідні дані** : dbFilePath: `"./db/invalidDB"`, name : `“John"`, city: `"Colombo"`, department : `"HR"`, age: `25`

**Вихідні дані** : `-1`

## Підказки

* Скористайтеся модулем [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc) для роботи з базою даних
* Зверніться до розділу [Prerequisite](https://lib.ballerina.io/ballerinax/java.jdbc/latest), щоб дізнатися кроки додавання драйвера JDBC як залежності
* Використовуйте віддалений метод [execute](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-execute), щоб вставити дані
* Перегляньте приклади [операцій DML і DDL](https://ballerina.io/learn/by-example/mysql-execute-operation/)
