# Вказівки

Сьогодні День Валентина. У партнера є кілька ідей, як провести час, і він просить оцінити кожну з них: `yes`, `no` або `maybe`.

Дії подано як масиви з двох елементів `{ tag value }`, де `tag` - одне з `board-game`, `chill`, `movie`, `restaurant` або `walk`.

| дія                          | форма                       |
| ------------------------- | --------------------------- |
| Зіграти в настільну гру   | `{ board-game f }`          |
| Розслабитися              | `{ chill f }`               |
| Подивитися фільм у жанрі `genre` | `{ movie genre }`    |
| Поїсти в закладі з кухнею `cuisine` | `{ restaurant cuisine }` |
| Пройти пішки `km` кілометрів | `{ walk km }`            |

Жанр - одне з `crime`, `horror`, `romance`, `thriller`. Кухня - `korean` або `turkish`.

## 1. Оцініть кухню

Визначте `rate-restaurant`, щоб вона приймала кухню зі стека і повертала наше схвалення:

- `korean` → `yes`
- `turkish` → `maybe`

```factor
korean rate-restaurant .   ! => yes
turkish rate-restaurant .  ! => maybe
```

## 2. Оцініть жанр фільму

Визначте `rate-movie`, щоб вона приймала жанр і повертала:

- `romance` → `yes`
- будь-що інше → `no`

```factor
romance rate-movie .   ! => yes
horror rate-movie .    ! => no
```

## 3. Оцініть прогулянку

Визначте `rate-walk`, щоб вона приймала кількість кілометрів і повертала:

- більше ніж `11` → `yes`
- більше ніж `6`, але не більше `11` → `maybe`
- інакше → `no`

```factor
12 rate-walk .   ! => yes
8 rate-walk .    ! => maybe
3 rate-walk .    ! => no
```

## 4. Оцініть дію

Визначте `rate-activity`, щоб вона приймала дію `{ tag value }` зі стека і повертала наше схвалення. Використайте допоміжні функції, визначені вище:

- `board-game`, `chill` → завжди `no`
- `movie` → покластися на `rate-movie`
- `restaurant` → покластися на `rate-restaurant`
- `walk` → покластися на `rate-walk`

```factor
{ restaurant turkish } rate-activity .   ! => maybe
{ movie horror } rate-activity .         ! => no
{ walk 12 } rate-activity .              ! => yes
{ board-game f } rate-activity .         ! => no
```

## 5. Порахуйте схвалення

Визначте `approval-counts`, щоб вона приймала масив дій і повертала масив із трьох елементів `{ yes-count maybe-count no-count }`: скільки дій отримали кожну з оцінок.

```factor
{ { restaurant korean } { restaurant turkish } { walk 3 } { movie romance } }
approval-counts .
! => { 2 1 1 }
```
