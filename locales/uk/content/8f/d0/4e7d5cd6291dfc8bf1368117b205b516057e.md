# Оператор розвʼязання області видимості

Оператор розвʼязання області видимості (`::`) дозволяє нам посилатися на клас, щоб отримати доступ до його констант, статичних властивостей або статичних методів.

```php
class MyClass
{
  public const MY_VALUE = 1;
}

// MyClass::class => "MyClass"
// MyClass::MY_VALUE => 1
```

## Використання `self` і `static` з оператором розвʼязання області видимості

Іноді може виникнути потреба, щоб обʼєкт посилався на власну область видимості. Щоб це забезпечити, ключове слово `self` дозволяє класу посилатися на власну область видимості. Використання ключового слова `self` відвʼязує клас від його власної назви, що полегшує підтримку коду з часом.

```php
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return self::MY_VALUE;
  }
}

// (new MyClass)->getMyValue() => 1
```

Щоб «пізньо звʼязати» посилання з поточним класом-нащадком, використаймо ключове слово `static` разом з оператором розвʼязання області видимості.

```php
// Update MyClass:
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return static::MY_VALUE;
  }
}
```

## Використання `parent` з оператором розвʼязання області видимості

Ключове слово `parent` використовується для посилання на константу, властивості або методи батьківського класу. Зазвичай його використовують, щоб викликати батьківський конструктор під час створення обʼєкта:

```php
class ChildClass extends ParentClass
{
  public function __construct(): void
  {
    parent::__construct();
  }
}
```

## Застереження

### Видимість констант, властивостей і методів

Оператор розвʼязання області видимості все ще підпорядковується правилам, встановленим модифікаторами видимості `public`, `private` і `protected`.
