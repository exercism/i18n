Приберіть усі зайві літерали.

У JavaScript не потрібно писати `return` із літералом `true` чи `false`, щоб повернути булеве значення (англ. Boolean).
Результат виразу можна повернути напряму.

```javascript
// instead of
if (some_expression) {
  return true;
} else {
  return false;
}

// ...in JavaScript, these can be returned directly
return some_expression;
```
