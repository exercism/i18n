## Інструкції

Згенеруйте ідеальні лабіринти для Міккі та Мінерви, такі, що мають лише один розвʼязок і не мають ізольованих ділянок. 
Ось що потрібно знати:

- Лабіринт має прямокутну форму з отвором на початку й у кінці.
- Лабіринт має кімнати та проходи, які перетинаються під прямими кутами.
- Програма повинна приймати два параметри: rows і columns. Розмір лабіринту має бути від 5 до 100 клітинок.
- Лабіринт, який має `x` columns завширшки та `y` rows заввишки, повинен мати `2x + 1` символів завширшки та `2y + 1` символів заввишки.
- Якщо seed не задано, згенеруйте випадковий лабіринт. Якщо той самий seed задано кілька разів, отриманий лабіринт щоразу має бути однаковим.
- Використовуйте [символи псевдографіки][Box-drawing] для малювання стін, а символ стрілки (⇨) - для входу ліворуч і виходу праворуч.

Час створити ідеальні лабіринти для цих відважних мишей!

### Приклади

1. Маленький квадратний лабіринт 5x5 клітинок (або 11x11 символів)
```text
	┌───────┬─┐
	│       │ │
	│ ┌─┬── │ │
	│ │ │   │ ⇨
	│ │ │ ──┤ │
	⇨ │ │   │ │
	┌─┤ └── │ │
	│ │     │ │
	│ │ ────┘ │
	│         │
	└─────────┘
```
2. Прямокутний лабіринт 6x18 клітинок
```text
	┌───────────┬─────────┬───────────┬─┐
	│           │         │           │ │
	│ ┌───────┐ │ ┌─┐ ──┐ └───┐ ┌───┐ │ │
	│ │       │ │ │ │   │     │ │   │   ⇨
	│ └─┐ ┌─┐ │ │ │ ├── ├───┐ │ │ ──┼── │
	│   │ │ │   │   │   │   │ │ │   │   │
	└── │ │ ├───┴───┤ ┌─┘ ┌─┘ │ ├── │ ──┤
	⇨   │   │       │ │   │   │ │   │   │
	┌─┬─┴─┐ └─┐ ┌─┐ │ └─┐ │ ┌─┘ │ ──┴─┐ │
	│ │   │   │ │ │ │   │   │   │     │ │
	│ │ │ └── │ │ │ └── │ ──┘ ┌─┘ ──┐ │ │
	│   │       │       │     │     │   │
	└───┴───────┴───────┴─────┴─────┴───┘
```
