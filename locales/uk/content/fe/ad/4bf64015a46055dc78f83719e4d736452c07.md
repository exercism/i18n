# Вступ

## Обʼєктно-орієнтоване програмування в Python

Якщо ми досі програмували у [функціональному][functional], [декларативному][declarative] чи [імперативному][imperative] стилі, перехід до [обʼєктно-орієнтованого програмування][oop] (ООП) може видатися трохи незвичним.
Підхід ООП пропонує програмісту думати про задачу як про один або кілька `objects`, які взаємодіють між собою, зберігають стан і діють над даними.
Обʼєкти можуть представляти реальні сутності (_як-от машини чи коти_) або абстрактніші поняття (_як-от цілі числа, транспортні засоби чи ссавці_).
Кожен обʼєкт стає окремим екземпляром у памʼяті компʼютера й представляє частину загальної моделі.

## Класи

`Classes` - це визначення нових типів обʼєктів, з яких створюються нові `instances` обʼєктів.
Часто вони поєднують дані з кодом або функціями, які працюють із цими даними.
У цьому сенсі класи - це _креслення_ або набори інструкцій, з яких можна створити й використовувати багато обʼєктів схожого типу.
Складна програма може мати багато класів, кожен з яких будує багато різних варіантів обʼєктів.
Процес побудови обʼєкта з класу називається `instantiation` (_або створенням екземпляра класу_).

Визначення класу в Python досить просте:

```python
class MyClass:
    # Class body goes here
```

### Атрибути класу

Поля класу (_інакше відомі як `properties`, `attributes`, `data members` або `variables`_) можна додати до тіла класу:

```python
class MyClass:
    number = 5
    string = "Hello!"
```

Екземпляр (_обʼєкт_) `MyClass` можна створити й привʼязати до імені, [_викликавши_][calling] клас (_так само, як викликається функція_):

```python
>>> new_object = MyClass()

# Class is instantiated and resulting object is bound to the "new_object" name.
# Note: the object address 'at 0x15adc55b0' will vary by computer.
>>> new_object
<__main__.MyClass at 0x15adc55b0>
```

`Class attributes` спільні для всіх обʼєктів (_або екземплярів_), створених із класу, і доступні через [`dot notation`][dot notation], тобто через крапку `.`, поставлену після імені обʼєкта й перед іменем атрибута:

```python
>>> new_object = MyClass()

# Accessing the class attribute "number" via dot-notation.
>>> new_object.number
5

# Accessing the class attribute "string" via dot-notation.
>>> new_object.string
'Hello!'

# Instantiating an additional object and binding it to the "second_new_object" name.
>>> second_new_object = MyClass()

>>> second_new_object
# Note: the object address "at 0x15ad99970" will vary by computer.
<__main__.MyClass at 0x15ad99970>

# Second_new_object shares the same class attributes as new_object.
>>> new_object.number == second_new_object.number
True
```

Атрибути класу визначаються в тілі самого класу, перед будь-якими іншими методами.
Вони належать класу, що дозволяє спільно використовувати їх між екземплярами класу.
Оскільки ці атрибути спільні, до їхнього значення можна звертатися й змінювати його _безпосередньо_ з класу.
Зміна значення атрибутів класу змінює значення _**для всіх обʼєктів, створених із цього класу**_:

```python
>>> obj_one = MyClass()
>>> obj_two = MyClass()

# Accessing a class attribute from an object.
>>> obj_two.number
5

# Accessing the class attribute from the class itself.
>>> MyClass.number
5

# Modifying the value of the "number" class attribute.
>>> MyClass.number = 27

# Modifying the "number" class attribute changes the "number" attribute for all objects.
>>> obj_one.number
27

>>> obj_two.number
27
```

Мати купу обʼєктів із постійно синхронізованими даними не надто корисно.
На щастя, обʼєкти, створені з класу, можна налаштувати під себе за допомогою власних `instance attributes` (_або властивостей, змінних чи полів екземпляра_).
Як випливає з назви, атрибути екземпляра унікальні для кожного обʼєкта й можуть змінюватися незалежно.

## Налаштування створення обʼєкта за допомогою `__init__()`

Спеціальний [«дундер-метод»][dunder] (_скорочено від «метод із подвійним підкресленням»_) `__init__()` використовується, щоб налаштовувати екземпляри класу, і ним можна ініціалізувати атрибути чи властивості екземпляра обʼєктів.
Через свою роль в ініціалізації атрибутів екземпляра `__init__()` також називають `class constructor` або `initializer`.
`__init__()` приймає один обовʼязковий параметр під назвою `self`, який указує на щойно ініціалізований або створений обʼєкт.
Дані для атрибутів чи властивостей екземпляра потім можна передати як аргументи `__init__()` після параметра `self`.

Нижче `MyClass` має атрибути екземпляра під назвами `location_x` і `location_y`.
Як бачимо, ці два атрибути присвоєно першому та другому індексам аргументу `location` (_кортежу_), переданого в `__init__()`.
Атрибути `location_x` і `location_y` для екземпляра класу тепер ініціалізуються під час створення екземпляра класу й обʼєкта:

```python
class MyClass:
    # These are class attributes, variables, or fields.
    number = 5
    string = "Hello!"

    # This is the class "constructor", with a "location" parameter that is a tuple.
    def __init__(self, location):

        # This is an instance or object property, attribute, or variable.
        # Note that we are unpacking the tuple argument into two separate instance variables.
        self.location_x = location[0]
        self.location_y = location[1]

# Create a new object "new_object_one", with object property (1, 2).
>>> new_object_one = MyClass((1, 2))

# Create a second new object "new_object_two" with object property (-8, -9).
>>> new_object_two = MyClass((-8, -9))

# Note that new_object_one.location_x and new_object_two.location_x two different values.
>>> new_object_one.location_x
1

>>> new_object_two.location_x
-8
```

Зауважмо, що під час ініціалізації `MyClass` вище достатньо передати один аргумент: Python сам подбає про передавання `self`, коли клас викликають.

## Методи

`method` - це `function`, привʼязана або до самого класу (_відома як [class method][class method], про неї йтиметься в одній із наступних вправ_), або до _екземпляра_ класу (обʼєкта).
Методи, які працюють з обʼєктом (екземпляром), потрібно визначати з `self` як першим параметром.
Решту параметрів ми можемо визначити так само, як для «звичайної» чи незвʼязаної функції:

```python
class MyClass:
    number = 5
    string = "Hello!"

    # Class constructor.
    def __init__(self, location):
        # Instance properties
        self.location_x = location[0]
        self.location_y = location[1]

    # Instance method. Note "self" as first parameter.
    def change_location(self, amount):
        self.location_x += amount
        self.location_y += amount
        return self.location_x, self.location_y
```

Як і у випадку з доступом до атрибутів, щоб викликати метод, достатньо поставити `.` після імені обʼєкта й перед іменем методу.
Викликаному методу не потрібна копія обʼєкта як перший параметр: Python автоматично підставляє `self`:

```python
class MyClass:
    number = 5
    string = "Hello!"

    def __init__(self, location):
        self.location_x = location[0]
        self.location_y = location[1]

    def change_location(self, amount):
        self.location_x += amount
        self.location_y += amount
        return self.location_x, self.location_y

# Make a new test_object with location (3,7)
>>> test_object = MyClass((3,7))
>>> (test_object.location_x, test_object.location_y)
(3,7)

# Call change_location to increase location_x and location_y by 7.
>>> test_object.change_location(7)
(10, 14)
```

До атрибутів класу можна звертатися зсередини методів екземпляра так само, як і ззовні класу:

```python
class MyClass:
    number = 5
    string = "Hello!"

    def __init__(self, location):
        self.location_x = location[0]
        self.location_y = location[1]

    # Alter instance variable location_x and location_y
    def change_location(self, amount):
        self.location_x += amount
        self.location_y += amount
        return self.location_x, self.location_y

    # Alter class variable number for all instances from within an instance.
    def increment_number(self):
        # Increment the 'number' class variable by 1.
        MyClass.number += 1


>>> test_object_one = MyClass((0,0))
>>> test_object_one.number
5

>>> test_object_two = MyClass((13, -3))
>>> test_object_two.increment_number()
>>> test_object_one.number
6
```

## Створення заглушки для реалізації за допомогою Pass

У попередніх концептуальних вправах і заготовках практичних вправ ми, напевно, бачили ключове слово `pass` у тілі функцій замість справжнього коду.
Ключове слово `pass` - це синтаксично допустима заглушка: воно не дає Python видати синтаксичну помилку для порожнього визначення функції чи класу.
По суті, це спосіб сказати інтерпретатору Python: «Не хвилюйся! Я _обовʼязково_ напишу тут код, просто ще не зробив цього».

```python
class MyClass:
    number = 5
    string = "Hello!"

    def __init__(self, location):
        self.location_x = location[0]
        self.location_y = location[1]

    # Alter instance variable location_x and location_y
    def change_location(self, amount):
        self.location_x += amount
        self.location_y += amount
        return  self.location_x, self.location_y

    # Alter class variable number for all instances
    def increment_number(self):
        # Increment the 'number' class variable by 1.
        MyClass.number += 1

    # This will compile and run without error, but has no current functionality.
    def pending_functionality(self):
       # Stubbing or placholding the body of this method.
       pass
```
