# Підказки

## 1. Надрукувати бейдж для працівника

- Щоб побудувати рядки тексту (англ. string) у Base R, стане в пригоді функція [`sprintf`][ref-sprintf].
- Для підходу в стилі Tidyverse можна скористатися [`str_glue`][ref-str_glue] з бібліотеки `stringr`.

## 2. Надрукувати бейдж для нового працівника

- Розгалужуємо за [`is.na`][ref-isna].

## 3. Надрукувати бейдж для власника

- Розгалужуємо за [`is.null`][ref-isnull].

## 4. Обчислити загальну зарплату працівників без ID

- Можна [відфільтрувати][concept-vector-filtering] за [`is.na`][ref-isna], а потім застосувати [`sum`][ref-sum].
- Що таке `salaries[is.na(ids)]`, якщо працівників без ID немає? Це варто перевірити в консолі R. Якщо R не встановлено на компʼютері, можуть допомогти онлайн-консолі, як-от [rdrr.io][web-rdrr].
