# Вступ

## Часткове застосування та композиція функцій

### Часткове застосування

Усі функції в Elm [каррійовані][currying], а це означає, що якщо ми викликаємо функцію, не передавши всі аргументи, вона повертає нову функцію.

Результат цього називається [частковим застосуванням][partial-application] (ми не передаємо функції всі аргументи, а застосовуємо лише частину з них).

```elm
add: Int -> Int -> Int
add a b = a + b

add2: Int -> Int
add2 = add 2

eight: Int
eight = add2 6
--> 8
```

Часткове застосування завжди застосовує аргументи по порядку.

```elm
contains: String -> String -> Bool
contains first second =
--> This function is in the standard library, and returns True if the second string contains the first one

containsCedd: String -> Bool
containsCedd = contains "Cedd"
--> (partial application always applies the arguments in order, so "Cedd" becomes the first argument to contains
--> This is a function that takes a string, and returns True if that string contains Cedd)

ceddBurgeContainsCedd: Bool
ceddBurgeContainsCedd = containsCedd "Cedd Burge"
--> True
--> ("Cedd Burge" ends up being the second argument to contains, and it does include "Cedd", the first argument)
```

### Оператор конвеєра (`|>`)

Запис `x |> f` означає рівно те саме, що й `f x`. Конкретний приклад: `"5" |> String.toInt` дає те саме, що й `String.toInt "5"`.

Спочатку це не здається надто корисним, але його називають [оператором конвеєра][pipe-operator], бо він дає змогу писати «конвеєрний» код.

Наприклад, уявімо, що в нас є функція `sanitize` для перетворення введених користувачем даних на цілі числа:

```elm
sanitize : String -> Maybe Int
sanitize input =
    String.toInt (String.trim input)
```

Ми можемо переписати її так:

```elm
sanitize : String -> Maybe Int
sanitize input =
    input
    |> String.trim
    |> String.toInt
```

Це дозволяє обійтися без дужок і показує функції в тому порядку, у якому вони застосовуються (спочатку `String.trim`, потім `String.toInt`), що полегшує читання.

Існує також [зворотний оператор конвеєра `(<|)`][reverse-pipe-operator].
Запис `f <| x` означає рівно те саме, що й `f x`.
На перший погляд це теж не здається надто корисним, і його точно вживають рідше, ніж оператор конвеєра, але в деяких ситуаціях він допомагає обійтися без дужок.

### Композиція функцій / point-free стиль

Оператор [`(>>)`][forward-composition] має тип `(a -> b) -> (b -> c) -> (a -> c)` і створює функцію типу `a -> c`, компонуючи дві сумісні функції типів `a -> b ` та `b -> c`.
Він робить це так: бере вихідні дані (типу `b`) першої функції й використовує їх як перший аргумент другої функції (яка мусить мати той самий тип `b`).
Створена функція прийматиме ті самі вхідні дані (типу `a`), що й перша функція, і повертатиме те `c`, яке повертає друга функція.

Конкретний приклад: `String.trim >> String.toInt`.
`String.trim` приймає рядок тексту (англ. string) як свій єдиний параметр, тож саме це й прийматиме створена функція.
`String.toInt` повертає `Maybe Int`, тож саме це й повертатиме створена функція.
`String.trim` повертає `String`, який `String.toInt` приймає як параметр, тож приклад компілюється.

Тепер ми можемо переписати нашу функцію `sanitize` так:

```elm
sanitize : String -> Maybe Int
sanitize =
    String.trim >> String.toInt
```

Звернімо увагу, що ми більше не використовуємо параметр `input`, який є у вихідному прикладі, хоча функціональність ідентична.
Такий спосіб створення функцій, які не посилаються на свої параметри, називається «point-free стиль».
Перевага цього стилю в тому, що код стає лаконічнішим, а недолік у тому, що його буває важче зрозуміти, особливо початківцям.

Варто памʼятати, що всі функції в Elm каррійовані, тож `String.length >> max` компілюється.

- Оператор [`(>>)`][forward-composition] має тип `(a -> b) -> (b -> c) -> (a -> c)`.
- `String.length` має тип `String -> Int`, тобто це частина `(a -> b)`, отже `a` - це `String`, а `b` - це `Int`.
- `max` має тип `Int -> Int -> Int`, тобто це частина `b -> c`.
- `b` - це `Int`, тож `max` застосовується частково, а `c` - це результат цього часткового застосування (`Int -> Int`).
- Отже, тип `String.length >> max` - це `String -> (Int -> Int)`.
- Отже, `((String.length >> max) "123") 2` повертає `3`, бо довжина `"123"` дорівнює 3, що більше за 2 з аргументу типу `Int`.

### Проєктування функцій

Щоб в Elm було легко писати елегантний код, робімо основну структуру даних останнім параметром функцій.
Усі поширені функції зі стандартної бібліотеки роблять саме так, наприклад `List.map` (сигнатура типу наведена нижче).

```elm
map : (a -> b) -> List a -> List b
```

Тут ми бачимо, що останній параметр функції `map` - це `List a`, а повертає вона `List b`, тож основна структура даних (`List`) стоїть останнім параметром.

Це дає змогу писати елегантний конвеєрний код, як-от нижче.

```elm
trimAndUpperCase : List String -> List String
trimAndUpperCase names =
    names
    |> List.map String.trim
    |> List.map String.toUpper
```

Це також робить зручним використання композиції функцій і point-free стилю як альтернативи конвеєрам.

```elm
trimAndUpperCase : List String -> List String
trimAndUpperCase =
    List.map String.trim
    >> List.map String.toUpper
```

Композиція функцій також дає змогу звести цей приклад до одного виклику `List.map`.

```elm
trimAndUpperCase : List String -> List String
trimAndUpperCase =
    List.map (String.trim >> String.toUpper)
```
