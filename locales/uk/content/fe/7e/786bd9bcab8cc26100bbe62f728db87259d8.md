# Інструкції

У цій вправі ми реалізуємо спосіб відстежувати рекорди для найпопулярнішої гри у місцевому залі ігрових автоматів.

Нам потрібно реалізувати 6 функцій, переважно повʼязаних із роботою з обʼєктом, який зберігає рекорди.

## 1. Створити нову таблицю рекордів

Напишіть функцію `create_score_board`, яка створює обʼєкт, що править за таблицю рекордів.
Ключами цього обʼєкта будуть імена гравців, а значеннями - їхні рахунки.
Для тестування потрібно безпосередньо включити до обʼєкта один запис.
Цей початковий запис має складатися з `"The Best Ever"` як імені гравця та `1000000` як рахунку.

```jq
create_score_board
# returns an object with one initial entry
```

## 2. Додати гравців до таблиці рекордів

Щоб додати гравця до таблиці рекордів, реалізуйте функцію `add_player`.
Вона приймає таблицю рекордів як вхідні дані та потребує два параметри: імʼя гравця та рахунок гравця.
Функція повертає обʼєкт таблиці рекордів із доданим новим гравцем.

```jq
{"José Valim", 486373}
| add_player("Dave Thomas"; 0)
# => {"Dave Thomas": 0, "José Valim": 486373} -- in some order
```

Якщо гравець уже є в таблиці, поверніть таблицю без змін.

## 3. Видалити гравців із таблиці рекордів

Якщо гравці порушують правила залу ігрових автоматів, їх вручну видаляють із таблиці рекордів.
Реалізуйте `remove_player`, яка приймає таблицю як вхідні дані та один параметр: імʼя гравця, якого потрібно видалити.
Ця функція має видалити запис указаного гравця з таблиці та повернути нову таблицю.
Якщо гравця спочатку не було в таблиці, з таблицею нічого не має статися; її слід повернути без змін.

```q
{"Dave Thomas": 0} | remove_player("Dave Thomas")
# => {}

{"Dave Thomas": 0} | remove_player("Rose Fanaras")
# => {"Dave Thomas": 0}
```

## 4. Збільшити рахунок гравця

Якщо гравець завершує ще одну гру в залі ігрових автоматів, до попереднього рахунку в таблиці додається певна кількість очок.
Реалізуйте `update_score`, яка приймає таблицю рекордів як вхідні дані та потребує два параметри: імʼя гравця й кількість очок для додавання.
Функція має повернути таблицю рекордів після виконання оновлення.

```jq
{"Freyja Ćirić": 12771000} | update_score("Freyja Ćirić"; 73)
# => {"Freyja Ćirić": 12771073}
```

Ця функція має додати гравця до таблиці, якщо його там ще не було.

## 5. Застосувати бонусні очки за понеділок

У понеділок зал ігрових автоматів веде окрему таблицю рекордів.
Наприкінці дня кожен гравець у цій таблиці отримує 100 додаткових очок.

Реалізуйте функцію `apply_monday_bonus`.
Функція додає бонусні очки кожному гравцеві, зазначеному в цій таблиці.

```jq
{
  "Dave Thomas": 44,
  "Freyja Ćirić": 539,
  "José Valim": 265
}
| apply_monday_bonus
# => {"Dave Thomas": 144, "Freyja Ćirić": 639, "José Valim": 365}
```

## 6. Знайти загальний рахунок

Різні зали ігрових автоматів змагаються між собою, щоб визначити, у кого найкращі гравці.
Зал із найвищим загальним рахунком отримує цю честь.

Напишіть функцію `total_score`.
Вона приймає таблицю рекордів як вхідні дані та повертає суму рахунків усіх гравців.

```jq
{
  "Dave Thomas": 44,
  "Freyja Ćirić": 539,
  "José Valim": 265
}
| total_score
# => 848
```
