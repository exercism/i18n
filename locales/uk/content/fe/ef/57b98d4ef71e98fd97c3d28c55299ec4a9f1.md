# Вступ

## Змінні

Нагадаємо, що програма `jq` - це _конвеєр виразів_.
**Присвоєння змінної** підкоряється такому правилу: _присвоєння змінної_ - це вираз, який має такий вигляд:

```jq
... | expr as $varname | ...
```

### Фільтр виводить вхідні дані

Як і _вираз тотожності_ `.`, _присвоєння змінної_ повертає на виході ті самі дані, що отримує на вході.
Встановлення значення змінної - це побічний ефект.

Приклад, що показує: `.` після присвоєння - це ті самі дані, що й початковий вхід:

```sh
$ jq -c -n '42 | (. * 2) as $double | [., $double]'
[42,84]
```

### Область видимості змінної

Область видимості змінної є «лексичною»: змінна залишається видимою до кінця конвеєра.
Змінні, визначені у функціях (до функцій ми дійдемо пізніше), є «локальними» для цієї функції.

### Імена змінних

Назва змінної має починатися з `$`.
Решта назви змінної - це **ідентифікатор**: він починається з літери або підкреслення, за якими йдуть літери, цифри або підкреслення.

### Деструктуризаційне присвоєння

З документації:

> За допомогою одного виразу `as` можна оголосити кілька змінних, надавши шаблон, який _відповідає структурі вхідних даних_ (це називають «деструктуризацією»).

Приклади:

```jq
[1, 2, 3] as [$a, $b, $c]
| [$a, $b, $c]     # => [1, 2, 3]
```

```jq
{"foo": "bar", "len": [10, 20]} as {foo: $f, len: [$h, $w]}
| [$f, $h, $w]     # => ["bar", 10, 20]
```

Збіг назви змінної з _ключем обʼєкта_ дає змогу скористатися скороченням:

```jq
{"x": 4, "y": 7} as {$x, $y}
| [$x, $y]         # => [4, 7]
```

```jq
{"foo": "bar", "len": [10, 20]} as {$foo, $len}
| [$foo, $len]     # => ["bar", [10, 20]]
```

### Константи

Як видно з наведеного вище прикладу, змінні зручні для зберігання констант.
Краще дати константам імʼя, ніж допускати появу «магічних чисел» у коді.

### Часто змінні не потрібні

Часто код стає зрозумілішим, якщо обійтися без змінних.

Розглянемо обчислення середнього значення масиву чисел

```jq
[2, 4, 8, 7]
| add as $sum
| length as $len
| $sum / $len
```

порівняно з

```jq
[2, 4, 8, 7] | add / length
```

Це демонструє одну з найпотужніших рис `jq`: вхідні дані фільтра передаються _кожному_ підвиразу:

- вхідний масив `[2,4,8,7]` передається у `add` (який додає числа, застосовуючи оператор `+` до всіх елементів)
- _паралельно_ `[2,4,8,7]` також передається в `length`
- коли ці підвирази завершуються, їхні результати діляться, повертаючи середнє значення чисел вхідного масиву.

### Оператори `jq`, які знадобляться для цієї вправи

#### Альтернативний оператор: `//`

Вираз `a // b` видає `b`, якщо `a` має значення false або null, а інакше видає `a`.
У контексті присвоєння змінної це дуже зручно, коли потрібно задати типове значення:

```jq
(.input.theAnswer // 42) as $answer | ...
```

#### Арифметичні оператори

- `+`, `-`, `*` - це звичайні оператори додавання, віднімання та множення чисел.
