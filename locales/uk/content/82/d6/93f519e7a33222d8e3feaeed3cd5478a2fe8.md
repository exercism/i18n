# Додаток до інструкцій

## Реалізація

Припущення:

1. Нуль у вихідних даних завжди позначається як [0], а не [].
2. В усіх інших випадках провідних нулів у вихідних даних немає.
3. Провідні нулі у вхідних даних приймаються.
4. Порожня послідовність вхідних цифр вважається нулем, а не помилкою.

Обробляйте проблемні випадки, повертаючи помилку, метод `Error()` якої повертає одне з таких повідомлень:

- input base must be >= 2
- output base must be >= 2
- all digits must satisfy 0 <= d < input base
