# Вектори як стек

Стек - це лінійна структура даних, оптимізована для доступу з одного кінця. Доречна метафора - стос аркушів паперу на стрижні: нові аркуші завжди додаються з того самого кінця, а знімаються вони в порядку, протилежному до того, у якому їх додавали. Аркуші, додані першими, знімаються останніми, а додані останніми - першими.

Структура даних `Vec` у Rust добре підходить для використання як стек. [Метод `push`](https://doc.rust-lang.org/std/vec/struct.Vec.html#method.push) додає елементи в кінець вектора. [Метод `pop`](https://doc.rust-lang.org/std/vec/struct.Vec.html#method.pop) вилучає останній елемент із вектора. І `push`, і `pop` потребують лише амортизованого часу `O(1)`.

## Приклад

У цьому прикладі ми використовуємо вектор як стек для простого [RPN](https://en.wikipedia.org/wiki/Reverse_Polish_notation)-калькулятора. Повний код можна знайти на [пісочниці](https://play.rust-lang.org/?version=stable&mode=debug&edition=2018&gist=b40514e282cb753d0c3272778f92d736).

```rust
#[derive(Default)]
pub struct RpnCalculator {
    stack: Vec<Value>,
}

impl RpnCalculator {
    pub fn evaluate(&mut self, argument: Argument) -> Result<(), Error> {
        match argument {
            Argument::Value(value) => self.stack.push(value),
            Argument::Operator(operator) => {
                let b = self.stack.pop().ok_or(Error::StackUnderflow)?;
                let a = self.stack.pop().ok_or(Error::StackUnderflow)?;
                let output = operator.execute()(a, b);
                self.stack.push(output);
            }
        }
        Ok(())
    }

    pub fn conclude(self) -> Result<Value, Error> {
        if self.stack.len() == 1 {
            Ok(self.stack[0])
        } else {
            Err(Error::IncompleteCalculation)
        }
    }
}
```
