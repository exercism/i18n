# Докладніше

[Включення][for] дають змогу легко й декларативно перетворювати _перелічувані структури_. Це _синтаксичний цукор_ для перебирання перелічуваних структур в Elixir.

[//]: # (elixir-formatter-disable-next-block)

```elixir
for s <- ["a", "b", "hello", "c"], # 1. generator
  String.length(s) == 1,           # 2. filter
  into: "",                        # 3. collectable
  do: String.upcase(s)

# => "ABC"
```

Включення складається з трьох частин:

1. _Генератори_:
   - Значення, перелічені зі структур, які реалізують протокол [_Enumerable_][enumerable].
   - Вирази зіставлення зі зразком для деструктурування перелічених значень.
2. _Фільтри_: булеві умови (англ. Boolean), які визначають, які з перелічених значень використати під час створення нових.
3. _Збирачі_: структура, яка реалізує протокол [_Collectable_][collectable] і використовується для збору нових значень.

Включення бувають однорядковими та багаторядковими. Коли використовується більше ніж один генератор, перелічується [декартів добуток][cartesian-product] згенерованих значень. Це означає, що кожне значення, згенероване першим генератором, буде один раз поєднано з кожним значенням, згенерованим другим генератором.

```elixir
for n <- [0, 1, 2, 3], do: n + 1
# => [1, 2, 3, 4]

for x <- [0, 1],
    y <- [0, 1] do
  {x, y}
end

# => [{0, 0}, {0, 1}, {1, 0}, {1, 1}]
```

Значення з блоку `do` вставляється в _збирач_ **для кожного значення, згенерованого** з _перелічуваної структури_.

```elixir
for _ <- [1, 2, 3], do: :a
# => [:a, :a, :a]
```

Зіставлення зі зразком може відбуватися у включенні: або в лівій частині `<-`, або в окремому рядку.

```elixir
for {atom, str} <- [a: "string"], do: str
# => ["string"]

for pair <- [a: "string"],
    {atom, str} = pair do
  str
end

# => ["string"]
```
