# Інструкції

Міка, організаторка заходів, отримала підвищення на роботі, і серед її нових обовʼязків тепер відповідальність за базу даних заходів. Вона швидко помітила, що багато даних зберігається у спосіб, з яким незручно працювати, тож ми обʼєднуємо зусилля, щоб упорядкувати їх одноразовим скриптом.

Оскільки скрипт запускатиметься лише один раз, і ми впевнені у структурі даних, ми вважаємо, що це слушна нагода скористатися _твердженнями let_ у Gleam.

## 1. Витягти помилки

Кожен минулий захід має список проблем, які трапилися під час нього. Їх збережено як результати, але вони завжди є варіантом `Error`.

Реалізуйте функцію `extract_error`, яка приймає результат, що, за припущенням, завжди є `Error`, і повертає вміщене значення помилки.

```gleam
extract_error(Error("Not enough coffee"))
// -> "Not enough coffee"
```

## 2. Прибрати префікс команди

До назв команд додано префікс "Team ", але він не потрібен. Реалізуйте функцію `remove_team_prefix`, щоб прибрати цей префікс із назви команди.

```gleam
remove_team_prefix("Team Turtle")
// -> "Turtle"
```

## 3. Розділити регіон і команду

Кожен захід проводить команда, а кожна команда належить до регіону. У базі даних вони зберігаються одним рядком тексту (англ. string), розділені комою.

Реалізуйте функцію `split_region_and_team`, щоб розділити рядок тексту на кортеж із двох рядків тексту: один для регіону, один для команди. Префікс "Team " слід прибрати з назви команди.

```gleam
split_region_and_team("East,Team Orange")
// -> #("East", "Orange")
```
