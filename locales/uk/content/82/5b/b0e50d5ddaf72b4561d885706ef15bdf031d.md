# Вступ

У C# структури даних, які можуть містити нуль або більше елементів, називаються _колекціями_. **Масив** - це колекція, яка має фіксований розмір/довжину, і всі елементи якої мають бути одного типу. Елементи можна присвоювати масиву або отримувати з нього за допомогою індексу. Масиви C# мають нульову індексацію, тобто індекс першого елемента завжди дорівнює нулю:

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true
```

Масиви також можна визначати за допомогою скороченого запису, який дозволяє одночасно створити масив і встановити його значення. Оскільки компілятор тепер може визначити, скільки елементів буде в масиві, довжину можна опустити:

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

Масивами можна керувати, викликаючи методи чи властивості екземпляра масиву, або використовуючи статичні методи, визначені в класі `Array`.
