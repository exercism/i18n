# Вступ

Зіставлення зі зразком - це процес розгалуження залежно від того, чи відповідає значення заданим, можливо, глибоким зразкам. У Haxe **зіставлення зі зразком** виконується за допомогою виразу `switch` та окремих виразів `case`.

Розглянемо таку структуру даних:

```haxe
enum Tree<T> {
  Leaf(v:T);
  Node(l:Tree<T>, r:Tree<T>);
}
```

- Зразки завжди зіставляються згори донизу.
- Для найвищого зразка, що відповідає вхідному значенню, виконується його вираз.
- Зразок `_` відповідає будь-чому, тож `case _:` дорівнює `default:`

## Зіставлення enum

Типи enum можна зіставляти за їхніми конструкторами природним чином:

```haxe
var myTree = Node(Leaf("foo"), Node(Leaf("bar"), Leaf("foobar")));

var match = switch (myTree) {
  // Matches any Leaf
  case Leaf(_):
    "0";

  // Matches any Node that has r = Leaf
  case Node(_, Leaf(_)):
    "1";

  // Matches any Node that has
  // r = another Node which has
  // l = Leaf("bar")
  case Node(_, Node(Leaf("bar", _))):
    "2";

  // Matches anything
  case _:
    "3";
}

trace(match); // 2
```
