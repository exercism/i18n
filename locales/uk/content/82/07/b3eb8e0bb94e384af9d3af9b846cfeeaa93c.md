# Додаток до інструкцій

## Формат вихідних даних

Метод `solve()` повинен повернути обʼєкт із такими властивостями:

- `moves` - кількість дій із відрами, потрібних, щоб досягти мети
  (включно з наповненням початкового відра),
- `goalBucket` - назва відра, яке досягло цільової кількості,
- `otherBucket` - кількість, що міститься в іншому відрі.

Приклад:

```json
{
  "moves": 5,
  "goalBucket": "one",
  "otherBucket": 2
}
```
