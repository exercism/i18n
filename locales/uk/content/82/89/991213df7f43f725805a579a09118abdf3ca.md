# Додаток до вказівок

## Регістри

| Регістр  | Використання | Тип          | Опис                                                       |
| -------- | ------------ | ------------ | ---------------------------------------------------------- |
| `$a0`    | вхідні дані  | адреса       | перший колір як рядок тексту (англ. string), що завершується нульовим символом |
| `$a1`    | вхідні дані  | адреса       | другий колір як рядок тексту, що завершується нульовим символом |
| `$a2`    | вхідні дані  | адреса       | третій колір як рядок тексту, що завершується нульовим символом (можливо, порожній) |
| `$v0`    | вихідні дані | ціле число   | значення резистора                                         |
| `$t0-9`  | тимчасовий   | будь-який    | для тимчасового зберігання                                 |
