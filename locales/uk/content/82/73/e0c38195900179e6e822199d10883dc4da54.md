## Форматування

Хоча Common Lisp не зважає ні на відступи й оформлення коду, ні на те, чи використовуємо ми пробіли чи табуляцію, для рішень, надісланих на exercism, це важливо.
Віджет коду на Exercism.org погано працює зі змішаними символами табуляції й пробілів, тож радимо використовувати лише пробіли, щоб код було легше читати людям, які його перевіряють.
Перегляньте налаштування свого редактора, щоб дізнатися, як це зробити.
Нижче наведено вказівки для популярних редакторів для Common Lisp.

### VIM

Скористайтеся наведеними командами, щоб VIM використовував для відступів лише пробіли:

```vimscript
:set tabstop=2
:set shiftwidth=2
:set expandtab
```

(або одним рядком `:set tabstop=2 shiftwidth=2 expandtab`). Це можна додати до файлу `~/.vimrc`, щоб користуватися цим постійно.

### Emacs

Emacs чудово підходить для редагування Common Lisp і має багато потужних додаткових пакетів. Щоб стандартний emacs добре працював з exercism.org, потрібно лише виконати такий код:

`(setq-default indent-tabs-mode nil)`

Це можна додати до `~/.emacs` (або `~/.emacs.d/init.el`), щоб налаштування застосовувалися щоразу під час запуску Emacs.

Для Emacs і Common Lisp радять додаток [SLIME][slime], який тісно інтегрується з REPL і робить ітеративне написання коду та тестування дуже простим.
