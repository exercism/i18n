# Вступ

## Перевантаження методів

_Перевантаження методів_ дає змогу мати кілька методів з однаковою назвою в одному класі. Перевантажені методи мають відрізнятися один від одного хоча б одним із цього:

- Кількістю параметрів
- Типом параметрів

Перевантаження за типом поверненого значення не існує.

Компілятор автоматично визначить, який із перевантажених методів викликати, виходячи з кількості параметрів та їхніх типів.

## Іменовані аргументи

Досі ми бачили, що аргументи, передані в метод, зіставляються з оголошеними параметрами методу за позицією. Альтернативний підхід, особливо коли підпрограма приймає багато аргументів, дає змогу коду, що викликає, зіставляти аргументи, вказуючи ідентифікатор оголошеного параметра.

Далі показано синтаксис:

```csharp
class Card
{
    static string NewYear(int year, int month, int day)
    {
        return $"Happy {year}-{month}-{day}!";
    }
}

Card.NewYear(month: 1, day: 1, year: 2020);  // => "Happy 2020-1-1!"
```

## Необовʼязкові параметри

Параметр методу можна зробити необовʼязковим, присвоївши йому типове значення. Коли ми викликаємо метод із необовʼязковими параметрами, передавати для них значення не потрібно. Якщо для необовʼязкового параметра не передано значення, буде використано його типове значення.

Необовʼязкові параметри _мають_ стояти в кінці списку параметрів; після них не можуть іти обовʼязкові параметри.

```csharp
class Card
{
    static string NewYear(int year = 2020)
    {
        return $"Happy {year}!";
    }
}

Card.NewYear();     // => "Happy 2020!"
Card.NewYear(1999); // => "Happy 1999!"
```
