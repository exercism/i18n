# Інструкції

Як майбутня чарівниця, Еліз має відпрацювати деякі основи. У неї є стос карток, з яким вона хоче працювати.

Щоб трохи спростити собі життя, вона використовує лише картки від 1 до 10, тож її стос карток можна подати як масив чисел. Позиція певної картки відповідає індексу в масиві. Це означає, що позиція 0 вказує на першу картку, позиція 1 - на другу, і так далі.

<!-- prettier-ignore-start -->
~~~~exercism/note
Усі функції, крім двох, повинні оновлювати масив карток, а потім повертати змінений масив. Це поширений підхід, відомий як патерн Builder, який дозволяє зручно поєднувати функції в ланцюжок.

Винятків лише два: `getItem`, яка повинна повертати картку за вказаною позицією, і `checkSizeOfStack`, яка повинна повертати `true`, якщо наданий розмір збігається.
~~~~
<!-- prettier-ignore-end -->

## 1. Витягніть картку зі стосу

Щоб узяти картку, поверніть картку за індексом `position` із наданого стосу.

```javascript
const position = 2;
getItem([1, 2, 4, 1], position);
// => 4
```

## 2. Обміняйте картку в стосі

Виконайте невеличкий фокус: обміняйте картку за індексом `position` на надану картку для заміни.
Поверніть змінений стос.

```javascript
const position = 2;
const replacementCard = 6;
setItem([1, 2, 4, 1], position, replacementCard);
// => [1, 2, 6, 1]
```

## 3. Вставте картку вгорі стосу

Зробіть так, щоб картка зʼявилася: вставте нову картку вгорі стосу.
Поверніть змінений стос.

```javascript
const newCard = 8;
insertItemAtTop([5, 9, 7, 1], newCard);
// => [5, 9, 7, 1, 8]
```

## 4. Видаліть картку зі стосу

Зробіть так, щоб картка зникла: видаліть картку за вказаною позицією `position` зі стосу.
Поверніть змінений стос.

```javascript
const position = 2;
removeItem([3, 2, 6, 4, 8], position);
// => [3, 2, 4, 8]
```

## 5. Видаліть верхню картку зі стосу

Зробіть так, щоб картка зникла: видаліть картку вгорі стосу.
Поверніть змінений стос.

```javascript
removeItemFromTop([3, 2, 6, 4, 8]);
// => [3, 2, 6, 4]
```

## 6. Вставте картку внизу стосу

Зробіть так, щоб картка зʼявилася: вставте нову картку внизу стосу.
Поверніть змінений стос.

```javascript
const newCard = 8;
insertItemAtBottom([5, 9, 7, 1], newCard);
// => [8, 5, 9, 7, 1]
```

## 7. Видаліть картку знизу стосу

Зробіть так, щоб картка зникла: видаліть картку знизу стосу.
Поверніть змінений стос.

```javascript
removeItemAtBottom([8, 5, 9, 7, 1]);
// => [5, 9, 7, 1]
```

## 8. Перевірте розмір стосу

Перевірте, чи дорівнює розмір стосу `stackSize`.

```javascript
const stackSize = 4;
checkSizeOfStack([3, 2, 6, 4, 8], stackSize);
// => false
```
