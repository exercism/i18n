# Вступ

У Haxe ієрархію класів можна визначити за допомогою _успадкування_, яке дозволяє похідному класу (`Car`) успадковувати поведінку та дані батьківського класу (`Vehicle`).

У батьківському класі ми можемо:

- Методи, які можна перевизначити
- Абстрактні методи, які мають реалізувати похідні класи

```haxe
abstract class Vehicle {
  public function new() {}

  // Can be overridden
  public function drive() {
    // ...
  }

  // Must be implemented
  public abstract function getSpeed():Int;
}

class Car extends Vehicle {
  public function new() {
    super(); // Runs the parent class' constructor
  }

  public override function drive() {
    // ...
  }

  public function getSpeed():Int {
    // ...
  }
}
```

Якщо батьківський клас має конструктор, ми використовуємо `super()`, щоб викликати його:

```haxe
abstract class Vehicle {
  var wheels:Int;

  public function new(wheels:Int) {
    this.wheels = wheels
  }
}

class Car extends Vehicle {
  var color:String;

  public function new(wheels:Int, color:String) {
    super(wheels);
    this.color = color;
  }
}

```
