# Додаток до інструкцій

## Формат вхідних даних

Кожне доміно зберігається як один байт: ліва половина в старшому [напівбайті][nibble], а права в молодшому [напівбайті][nibble]. Наприклад, кісточки `[2|1]`, `[2|3]` і `[1|3]` представлені байтами `0x21 0x23 0x13`.

## Регістри

| Регістр | Використання | Тип | Опис |
| ------- | ------------ | --- | ---- |
| `$a0`   | вхідний      | адреса | масив байтів кісточок |
| `$a1`   | вхідний      | ціле число | кількість кісточок |
| `$v0`   | вихідний     | булеве значення (англ. Boolean) | доміно можна скласти в ланцюжок (`0` = `false`, `1` = `true`) |
| `$t0-9` | тимчасовий   | будь-який | використовується для тимчасового зберігання |

[nibble]: https://en.wikipedia.org/wiki/Nibble
