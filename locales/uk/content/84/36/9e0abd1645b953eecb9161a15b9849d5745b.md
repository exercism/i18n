# Основи

## Початок роботи

### Змінні

Щоб оголосити [змінну][variables], використовуймо оператор присвоєння `=`.
У Crystal змінні записують у форматі [snake_case][snake-case].

```crystal
number = 1
puts number # => 1

number = 2
puts number # => 2
```

### Константи

[Константи][constants] оголошують за допомогою того самого оператора присвоєння `=`, але записують великими літерами, що називається SCREAMING_SNAKE_CASE.

```crystal
NUMBER = 1
puts NUMBER # => 1
```

Присвоєння значення вже визначеній константі призведе до помилки часу компіляції.

```crystal
NUMBER = 1

NUMBER = 2
# Error: already initialized constant NUMBER
```

### Типи

Crystal - це компільована мова, тобто кожній змінній або аргументу методу під час компіляції призначається тип.
Компілятор здатен виводити тип змінної чи аргументу методу.
Однак у деяких випадках тип потрібно вказати явно.
Випадки, у яких потрібно вказати тип, буде пояснено в наступних концепціях.

### Методи

[Методи][methods] - це спосіб згрупувати набір інструкцій, які можна використовувати повторно.
У Crystal методи часто визначають у класі, модулі чи структурі.
Однак методи можна визначати й поза класом, модулем чи структурою.
Методи оголошують за допомогою ключового слова `def`, після якого йде назва методу.
У Crystal методи записують у snake_case.
Дужки можна опустити, коли метод не має аргументів.
Щоб позначити кінець методу, потрібно використати ключове слово `end`.

```crystal
def hello
  puts "Hello World!"
end
```

Використання методу, якого не існує для типу змінної чи аргументу методу, призведе до помилки часу компіляції.

```crystal
number = 1
number + "1"
# Error: no overload matches 'Int32#+' with type String
```

### Аргументи

Методи можуть мати [аргументи][arguments].
Аргументи - це дані, які передають методу.
Щоб мати змогу передати методу аргументи, потрібно вказати назву аргументу.
У Crystal аргументи записують у snake_case.
Метод може мати кілька аргументів, але їх обовʼязково розділяє кома.

```crystal
def hello(name)
  puts "Hello #{name}!"
end
```

Метод також може мати кілька аргументів.
У цьому випадку аргументи потрібно розділяти комою.

```crystal
def hello(name, language)
  puts "Hello #{name}! You are learning #{language}."
end
```

### Виклик методів

Коли викликаємо метод, що належить класу, модулю чи структурі, потрібно використовувати оператор крапки (`.`).
Формат має бути таким: `<ClassName>.<method_name>`.
Коли метод не належить класу, модулю чи структурі, його можна просто викликати за назвою.
Методи завжди неявно повертають значення останнього виразу.

Коли метод має аргументи, можна використовувати дужки, вказуючи аргументи під час виклику та визначення методу, ось так: `<method_name>(<argument_1>, <argument_2>, ...)`.
Коли метод не має аргументів, дужки потрібно опускати.

```crystal
def hello(name)
  "Hello #{name}!"
end

hello("Crystal")
# => Hello Crystal!
```

Коли викликаємо метод із кількома аргументами, аргументи потрібно розділяти комою.
Аргументи потрібно наводити в тому самому порядку, що й аргументи методу.

```crystal
def hello_language(name, language)
  "Hello #{name}! You are learning #{language}."
end

hello_language("World", "Crystal")
# => Hello World! You are learning Crystal.
```

Виклик методу з неправильною кількістю аргументів призведе до помилки часу компіляції.

```crystal
hello_language("Crystal")
# wrong number of arguments for 'hello_language' (given 1, expected 2)
```

### Додавання, віднімання та множення

У Crystal можна використовувати оператор `+`, щоб додавати два числа.
Також можна використовувати оператор `-`, щоб віднімати два числа.
А оператор `*` дозволяє множити два числа.

```crystal
1 + 1
# => 2

2 - 1
# => 1

2 * 2
# => 4
```

### Коментарі

У Crystal [коментарі][comments] записують за допомогою символу `#`, після якого йде пробіл, а далі сам коментар.
Коментарі використовують для документування коду.
Компілятор не виконує коментарів.

```crystal
# This is a comment
```
