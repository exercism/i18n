# Вказівки

У цій вправі ми допоможемо закоханим старшокласникам освідчитися в коханні в соціальних мережах, згенерувавши ASCII-серце з їхніми ініціалами:

```
❤ J.  +  M. ❤
```

## 1. Очистьте імʼя

Реалізуйте метод `HighSchoolSweetheart.clean_up_name`.
Він має приймати імʼя, видаляти з нього всі символи `-` та замінювати їх на пробіл.
Також він має видаляти будь-які пробільні символи на початку та в кінці імені.

```crystal
HighSchoolSweetheart.clean_up_name("Jane-Ann")
# => "Jane Ann"
```

## 2. Отримайте першу літеру імені

Реалізуйте метод `HighSchoolSweetheart.first_letter`.
Він має приймати імʼя та повертати його першу літеру.
Обовʼязково використайте `HighSchoolSweetheart.clean_up_name` із попереднього кроку.

```crystal
HighSchoolSweetheart.first_letter("Jane")
# => "J"
```

## 3. Відформатуйте першу літеру як ініціал

Реалізуйте метод `HighSchoolSweetheart.initial`.
Він має приймати імʼя та повертати його першу літеру у верхньому регістрі, після якої йде крапка.
Обовʼязково використайте `HighSchoolSweetheart.first_letter` із попереднього кроку.

```crystal
HighSchoolSweetheart.initial("Robert")
# => "R."
```

## 4. Розмістіть ініціали всередині серця

Реалізуйте метод `HighSchoolSweetheart.pair`.
Він має приймати два імені та повертати ініціали, оточені емодзі-серцями.
Обовʼязково використайте `HighSchoolSweetheart.initial` із попереднього кроку.

```crystal
HighSchoolSweetheart.pair("Blake Miller", "Riley Lewis")
# => "❤ B.  +  R. ❤"
```
