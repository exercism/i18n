# Про множину

Множина - це незмінна й невпорядкована колекція унікальних значень. Усі елементи в множині мають бути одного типу.

Модуль `gleam/set` визначає тип `Set` і надає функції для роботи з множинами.

Перетворювати масиви й множини одне в одного можна за допомогою `set.to_list` і `set.from_list`. Порядок елементів у множині не гарантований.

```gleam
set.from_list([2, 3, 3, 3, 1, 1, 2])
// -> set.from_list([1, 2, 3])

set.to_list(set.from_list([2, 3, 3, 3, 1, 1, 2]))
// -> [1, 2, 3]
```

Створювати й наповнювати множини можна за допомогою `set.new`, `set.insert` та `set.delete`.

```gleam
set.new()
// -> set.from_list([])

let eighty_eight = set.from_list([88])

set.insert(eighty_eight, 88)
// -> set.from_list([88])

set.insert(eighty_eight, 89)
// -> set.from_list([88, 89])

set.delete(eighty_eight, 88)
// -> set.from_list([])

set.delete(eighty_eight, 89)
// -> set.from_list([88])
```

Дізнатися про вміст множини можна за допомогою функцій `set.contains` і `set.size`.

```gleam
set.contains(eighty_eight, 88)
// -> True

set.size(eighty_eight)
// -> 1
```

Множини можна поєднувати за допомогою `set.union` і `set.intersect`.

```gleam
let a = set.from_list([1, 5, 10])
let b = set.from_list([1, 2, 3, 4, 5])

set.union(a, b)
// -> set.from_list([1, 2, 3, 4, 5, 10])

set.intersection(a, b)
// -> set.from_list([1, 5])
```

Множини можна фільтрувати.

```gleam
let is_small = fn(n) { x <= 3 }

set.filter(b, is_small)
// -> set.from_list([1, 2, 3])
```
