# Вступ

## Властивості

Властивість у C# - це член класу, який надає доступ до даних усередині цього класу.
Код, який викликає, може встановлювати ці дані або отримувати (get) їх. Властивості можуть
бути автоматично реалізованими або мати допоміжне поле. Вони складаються із засобу доступу
set та/або засобу доступу get.
У деяких інших мовах «мутатор» приблизно відповідає засобу доступу
set, а «аксесор» - засобу доступу get, хоча
будова синтаксису зовсім інша.

Коли ми встановлюємо значення властивості, вхідне значення можна перевірити, відформатувати
чи якось інакше обробити, і взагалі можна виконати будь-яку програмну операцію, доступну
коду в класі.

Так само, коли ми отримуємо значення властивості, дані можна обчислити чи відформатувати, і
знову ж таки можна виконати будь-яку програмну операцію, доступну класу.

Властивості мають модифікатори доступу (`public`, `private` тощо) так само, як і інші
члени класу, але засіб доступу set може мати рівень доступу, незалежний від засобу доступу
get, і навпаки. Властивість не обовʼязково повинна мати обидва засоби доступу, вона може мати лише один (або get, або set).

Базовий синтаксис для опису властивостей може мати дві форми:

### Властивості на основі поля/виразу:

```csharp
private int myField;
public int MyProperty
{
    get { return myField; }
    set { myField = value; }
}
```

### Автоматично реалізовані властивості

```
public int MyProperty { get; private set; } = 42;
```

Ініціалізація необовʼязкова.
