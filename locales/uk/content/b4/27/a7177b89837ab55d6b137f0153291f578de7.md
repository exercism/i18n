## Змінні

Змінні - це символічні імена, які вказують або на значення, або на контейнери.
Імена змінних можуть починатися як зі спеціального символу під назвою [сигіл][sigils], так і без нього, а далі йде ідентифікатор.
Після сигіла також може йти [твігіл][twigils].

Змінні з різними сигілами містять різні види структур даних.

```raku
my $scalar; # Assigned value will be stored as-is
my @array;  # Assigned value will be coerced into an array
my %hash;   # Assigned value will be coerced into a hash
my &code;   # Assigned value must be a code object
```

Найчастіше трапляються твігіли `^` і `:`, які слугують скороченнями для сигнатур блоків коду.
`^` призначений для позиційних параметрів.
`:` призначений для іменованих параметрів.

```raku
{ $^a + $^b }; #`[same as] ->  $a,  $b { $a + $b }; # Called with (1, 2)
{ $:a + $:b }; #`[same as] -> :$a, :$b { $a + $b }; # Called with (a => 1, b => 2)
```

## Контейнери

Саме контейнери дозволяють змінювати змінну.

Змінні, оголошені за допомогою `constant`, і змінні без сигіла (оголошені з `\` перед ідентифікатором) не мають контейнерів, а вказують безпосередньо на значення.

```raku
my $foo = 1;
$foo = 2;

constant $bar = 3;
my \baz = 4;

# The following will fail
$bar = 5;
baz  = 6;
```

## Типи

Змінні можна оголошувати з обмеженням типу.
Обмеження типу може також мати приведення: для цього прийнятний тип передають як аргумент потрібному типу.

```raku
my Bool   $foo = True; # Booleans only.
my Bool() $bar = 0;    # Accepts type `Any`. Coerced to False.

my Str(Bool(Int)) $baz;
$baz = 1;   # "True"
$baz = "1"; # "1"
```

Обмеження типів дають змогу скористатися багатоваріантними процедурами.

```raku
multi foo (Int $bar) { say 'Type of arg to $bar is Int!' }
multi foo (Str $bar) { say 'Type of arg to $bar is Str!' }
```

Типи в Raku - це просто ще один різновид обʼєктів.
Оголошення `class`, `role` або `enum` - це способи створювати власні обʼєкти типів.
Наприклад, вбудований тип `Bool` створено за допомогою переліку: `enum Bool <False True>`.

Також можна створювати прості обмеження типів на основі інших типів за допомогою ключового слова `subset`.
Новий тип можна додатково обмежити за допомогою умови `where`.
Умову `where` також можна використати в сигнатурі.

```raku
subset PositiveInt of Int where * > 0;

sub is-even (PositiveInt $n where  %% 2) { say "$n is even!" }
```
