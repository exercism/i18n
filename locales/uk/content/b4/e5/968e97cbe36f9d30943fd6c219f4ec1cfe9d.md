# Про арифметичні оператори

## Оператори

Go підтримує такі арифметичні оператори:

| Оператор | Приклад        |
| -------- | -------------- |
| `+`      | `4 + 6 == 10`  |
| `-`      | `15 - 10 == 5` |
| `*`      | `2 * 3 == 6`   |
| `/`      | `13 / 3 == 4`  |
| `%`      | `13 % 3 == 1`  |

Під час ділення цілих чисел остачу відкидають (наприклад, `5 / 2 == 2`).

Оператор `+` також зʼєднує рядки тексту (англ. string): `"foo" + "bar" == "foobar"`.

## Арифметика зі змішаними типами

Go не дозволяє арифметичні операції між різними числовими типами:

```go
x := 42
n := 2.0
value := n * x // invalid operation: n * x (mismatched types float64 and int)
```

Операнди повинні бути одного типу, іноді це потребує явного перетворення:

```go
x := float64(42)
n := 2.0
value := n * x 
```

## Скорочені присвоєння

Кожен оператор має скорочену форму присвоєння, яка оновлює змінну на місці:

```go
a := 1
a += 2 // same as a = a + 2 == 3

b := 2
b -= 2 // same as b = b - 2 == 0

c := 4
c *= 2 // same as c = c * 2 == 8

d := 8
d /= 2 // same as d = d / 2 == 4

e := 16
e %= 2 // same as e = e % 2 == 0
```

## Інкремент і декремент

Коли інструкції інкременту (`++`) та декременту (`--`) стоять після змінної, вони збільшують або зменшують збережене в ній числове значення на 1.
Якщо поставити їх перед змінною, це синтаксична помилка.

```go
a := 10
a++ // same as a += 1, a == 11

b := 10
b-- // same as b -= 1, b == 9
```

Оскільки це інструкції, вони не повертають значення.
