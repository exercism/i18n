# Про константи

Константи в Gleam дають змогу давати імена значенням. Їх визначають за допомогою ключового слова `const`.

```gleam
pub const pi: Float = 3.14159

pub fn circle_area(radius: Float) -> Float {
  radius *. radius *. pi
}
```

Якщо визначити константу з ключовим словом `pub`, до неї можна звертатися з інших модулів, інакше вона доступна лише з модуля, у якому її визначено.
