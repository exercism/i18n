# Інструкції

Уявімо себе скарбниками на кораблі, які ведуть облік запасів у коморі. Інвентар - хеш-таблиця, у якій ключами є назви предметів, а значеннями - їхня кількість на складі.

## 1. Створити інвентар з масиву

Визначмо `create-inventory`, яка приймає послідовність назв предметів і повертає хеш-таблицю, що зіставляє кожну унікальну назву з її кількістю.

```factor
{ "coal" "wood" "wood" "diamond" "diamond" "diamond" } create-inventory .
! => H{ { "coal" 1 } { "wood" 2 } { "diamond" 3 } }
```

## 2. Додати більше предметів

Визначмо `add-items`, яка приймає інвентар і послідовність предметів та повертає новий інвентар, у якому кількості збільшено на одиницю для кожного з перелічених предметів. Початковий інвентар не повинен змінюватися.

```factor
H{ { "coal" 1 } } { "wood" "iron" "coal" "wood" } add-items .
! => H{ { "coal" 2 } { "wood" 2 } { "iron" 1 } }
```

## 3. Зменшити кількості

Визначмо `decrement-items`, яка приймає інвентар і послідовність предметів та повертає новий інвентар, у якому кількості зменшено на одиницю для кожного з перелічених предметів. Кількості ніколи не повинні ставати меншими за нуль, а предмети, яких ще немає в інвентарі, слід пропустити (записи з відʼємними значеннями не додаються).

```factor
H{ { "coal" 3 } { "diamond" 1 } { "iron" 5 } }
{ "diamond" "coal" "iron" "iron" } decrement-items .
! => H{ { "coal" 2 } { "diamond" 0 } { "iron" 3 } }
```

## 4. Вилучити предмет повністю

Визначмо `remove-item`, яка приймає інвентар і предмет та повертає новий інвентар без цього предмета. Якщо предмета немає в інвентарі, повернімо незмінену копію.

```factor
H{ { "coal" 2 } { "wood" 1 } { "diamond" 2 } } "coal" remove-item .
! => H{ { "wood" 1 } { "diamond" 2 } }
```

## 5. Перелічити наявні предмети

Визначмо `list-inventory`, яка приймає інвентар і повертає масив пар `{ name quantity }`, що містять лише предмети, кількість яких більша за нуль, відсортований за назвами в абетковому порядку.

```factor
H{ { "coal" 7 } { "wood" 11 } { "diamond" 2 } { "iron" 7 } { "silver" 0 } }
list-inventory .
! => { { "coal" 7 } { "diamond" 2 } { "iron" 7 } { "wood" 11 } }
```
