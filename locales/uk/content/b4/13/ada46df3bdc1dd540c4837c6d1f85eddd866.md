# Вступ

AWK - дуже маленька мова, у якій є лише кілька базових типів даних.
У цьому уроці ми розглянемо числа та рядки тексту (англ. string).

## Числа

Числа в AWK реалізовано як числа з плаваючою комою подвійної точності.
Тут немає різниці між цілими числами, числами з плаваючою комою та числами подвійної точності.

AWK розуміє вісімкові числові константи (які починаються з `0`) та шістнадцяткові числові константи (які починаються з `0x` або `0X`).

### Числові операції

Ми можемо використовувати [стандартні арифметичні оператори][ops-arith] `+`, `-`, `*`, `/`, `%`.
Оператор піднесення до степеня - `^` (його визначено стандартом POSIX), хоча можна використовувати і `**`.
Є кілька [вбудованих числових функцій][funcs-numeric], зокрема тригонометричні функції, генерація випадкових чисел і `int(x)`, щоб відкинути дробову частину числа до найближчого цілого між _x_ і нулем.

Побітових _операторів_ немає.
gawk реалізує їх як функції.
Аргументи мають бути невідʼємними числами.

| функція             | операція                                        |
| ------------------- | ---------------------------------------------- |
| `and(a, b [, ...])` | побітове І аргументів                          |
| `or(a, b [, ...])`  | побітове АБО аргументів                        |
| `xor(a, b [, ...])` | побітове виключне АБО аргументів               |
| `lshift(v, count)`  | значення _v_, зсунуте вліво на _count_ бітів   |
| `rshift(v, count)`  | значення _v_, зсунуте вправо на _count_ бітів  |
| `compl(v, count)`   | побітове доповнення _v_                        |

## Рядки тексту

Рядки тексту в AWK є послідовностями символів.
Рядкову константу задаємо за допомогою подвійних лапок.

~~~~exercism/caution
GNU awk дозволяє символи Unicode у рядках тексту, інші реалізації awk можуть цього не робити.
Порівняймо `gawk` з `mawk`, ще однією популярною реалізацією AWK:

```sh
$ echo "Hi friend 😀!" | gawk '{print length($3)}'
2
$ echo "Hi friend 😀!" | mawk '{print length($3)}'
5
```
~~~~

### Операції з рядками тексту

Існує лише одна операція з рядками тексту: конкатенація.
Конкатенація не має спеціального оператора: щоб зʼєднати два рядки тексту, достатньо поставити їх поруч:

```awk
BEGIN {
    hw = "Hello" "World"
    print hw
}
# => HelloWorld
```

~~~~exercism/note
`print` - це **інструкція**, а не функція.
`print` не потребує дужок.
~~~~

AWK має безліч [функцій для роботи з рядками тексту][funcs-string].
Ми докладно познайомимося з ними в міру просування.

## Перетворення між числами і рядками тексту

Немає явних операторів для перетворення між числами і рядками тексту.
AWK робить це неявно, виходячи з контексту програми.
Це робить роботу зі значеннями полів вхідних даних дуже простою: зазвичай AWK просто робить те, чого ми хочемо.

* `print x + y` перетворить значення змінних `x` і `y` на числа завдяки числовій операції `+`.
* `print x y` перетворить значення змінних `x` і `y` на рядки тексту завдяки операції конкатенації.

Якщо ми хочемо зробити це явно, `0 + x` дає подання _x_ як числа, а `"" x` дає подання _x_ як рядка тексту.

### Від рядків тексту до чисел

Те, як AWK перетворює рядок тексту на число, може збивати з пантелику.
Простий спосіб уявити це: AWK читає «числові символи» з початку рядка тексту, доки не знайде «нечисловий» символ.
Ось кілька прикладів:

* `"2.5"` перетворюється на число `2.5`;
* `"1e3"` перетворюється на число `1000` (наукова нотація);
* `"456abc"` перетворюється на число `456` (оскільки `a` не є «цифрою», перетворення там зупиняється).
* `"abc789"` перетворюється на число `0` (на **початку** рядка тексту немає чисел).

Повні подробиці наведено [у посібнику][str-to-num].

## Визначення типу змінної

[Функція `typeof(var)`][func-typeof] повертає тип як рядок тексту.

```awk
BEGIN {
    x = "42"
    print x, typeof(x)
    x = x + 1           # type conversion
    print x, typeof(x)
}
```
виводить
```none
42 string
43 number
```
