# Докладніше

## Числа

У Swift є два основні типи чисел: цілі числа та числа з плаваючою комою.
[Цілі числа][integers] - це числа без дробової частини, наприклад `0`, `1`, `-1`, `42` та `-273`.
[Числа з плаваючою комою][floatingpoint] мають дробову частину, наприклад `0.0`, `3.14` та `-1.36969e-10`.
Swift також дозволяє використовувати підкреслення, щоб зробити числа зрозумілішими, наприклад `1_000_000` дорівнює `1000000`.
Числа з плаваючою комою можна записати як у десятковій, так і в експоненційній формі.

У більшості випадків тип для цілих чисел визначають як [`Int`][int], а для чисел з плаваючою комою як [`Double`][double].

Щоб оголосити змінну або константу типу `Int` чи `Double`, можна використати анотацію типу:

```swift
let speed: Int = 42                           // speed is an Int
let pi: Double = 3.14                         // pi is a Double
let giga: Double = 1_000_000_000              // giga is a Double
let plancksConstant : Double = 6.62607015e-34 // plancksConstant is a Double
```

## Арифметичні оператори

~~~~exercism/caution
У Swift не можна змішувати типи в арифметичних операціях, тому не можна застосувати жоден арифметичний оператор до `Int` разом із `Double` чи навпаки.
Тому спершу потрібно виконати перетворення типу.
~~~~

У Swift є набір [арифметичних операторів][arithmetic-operators], які можна використовувати для виконання базових математичних дій.
Оператор `+` використовується для додавання, оператор `-` - для віднімання, а оператор `*` - для множення.

| Оператор | Приклад                 |
| -------- | ----------------------- |
| `+`      | `4 + 6   // equals  10` |
| `-`      | `15 - 10 // equals  5`  |
| `*`      | `2 * 3   // equals  6`  |

### Ділення

Оператор `/` використовується для ділення.
Якщо використовувати число з плаваючою комою, результатом буде число з плаваючою комою.
Якщо використовувати цілі числа, результатом буде ціле число.

```swift
5 / 2.0 // equals 2.5
5 / 2   // equals 2
```

Якщо поділити число з плаваючою комою на нуль, результатом буде `inf`, або `-inf`, відповідно до знаку цього числа.
Якщо поділити нуль на нуль, і одне з них є числом з плаваючою комою, результатом буде `nan`.
Якщо поділити ціле число на нуль, ми отримаємо помилку компіляції.

```swift
print(5.0 / 0.0)  // Prints inf
print(-5.0 / 0.0) // Prints -inf
print(0.0 / 0.0)  // Prints nan

// The following code will not compile
print(5 / 0) // error: division by zero
```

### Остача

Оператор [`%`][remainder-operator] повертає остачу від ділення першого аргументу на другий.
Оператор остачі працює лише з цілими числами.
І, як і з діленням, якщо другий аргумент дорівнює нулю, результатом буде помилка компіляції.

```swift
5 % 2  // equals 1
-5 % 2 // equals -1

// The following code will not compile
5 % 0 // error: division by zero
```

~~~~exercism/note
`%` у Swift - це оператор остачі, на відміну від багатьох інших мов, де він використовується як оператор модуля.
Оператор остачі (`REM`) та оператор модуля (`MOD`) поводяться по-різному, коли йдеться про відʼємні числа.
З _оператором остачі_ результат має той самий знак, що й перший аргумент; знак другого аргументу не впливає на результат.
З _операторами модуля_ в інших мовах результат має той самий знак, що й другий аргумент.

```swift
+5 % -2 // equals 1
```
~~~~

## Округлення чисел

Щоб округлити число, використовують метод `rounded()` для числа з плаваючою комою.
Щоб округлити до найближчого цілого, можна викликати метод `rounded()` без аргументів.
Щоб округлити вгору чи вниз, можна вказати [правило округлення][rounding-rule]: `rounded(.up)` або `rounded(.down)`.

```swift
let x = 3.14
let y = x.rounded()      // y equals 3.0
let w = x.rounded(.down) // w equals 3.0
let z = x.rounded(.up)   // z equals 4.0
```

## Виведення типу

Swift може [визначити тип][typeinference] числа на основі контексту; без додаткового контексту компілятор вважатиме, що це число має тип `Int`.
Якщо потрібно повідомити компілятору, що ціле число має бути `Double`, слід використати анотацію типу або додати `.0` у кінець числового літерала, наприклад:

```swift
let x = 42         // x is an Int
let y = 42.0       // y is a Double
let z: Double = 42 // z is a Double
```

## Перетворення типу

У Swift, щоб перетворити значення з одного типу на інший, потрібно виконати [перетворення типу][type-conversion].
Наприклад, щоб перетворити `Int` на `Double` і навпаки, потрібно зробити таке:

```swift
let x = 42
let d = Double(x)
print(d)           // Prints 42.0
print(type(of: d)) // Prints Double

let pi = 3.14
let iPi = Int(pi)
print(iPi)           // Prints 3
print(type(of: iPi)) // Prints Int
```
