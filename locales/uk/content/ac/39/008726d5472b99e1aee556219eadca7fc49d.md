# Вказівки

Визначте, який це трикутник: equilateral, isosceles чи scalene.

Трикутник _equilateral_ має всі три сторони однакової довжини.

Трикутник _isosceles_ має щонайменше дві сторони однакової довжини.
(Іноді його визначають як такий, що має рівно дві сторони однакової довжини, але для цієї вправи будемо вважати, що щонайменше дві.)

Трикутник _scalene_ має всі сторони різної довжини.

## Примітка

Щоб фігура взагалі вважалася трикутником, усі її сторони повинні мати довжину, більшу за 0, а сума довжин будь-яких двох сторін має бути більшою за довжину третьої сторони або дорівнювати їй.

У рівняннях:

Нехай `a`, `b` і `c` будуть сторонами трикутника.
Тоді всі три наведені нижче вирази мають виконуватися:

```text
a + b ≥ c
b + c ≥ a
a + c ≥ b
```
