# Інструкції

У цій вправі ми будемо працювати з рядками логу.

Кожен рядок логу - це рядок тексту (англ. string), відформатований так: `"[<LVL>]: <MESSAGE>"`.

Ось різні рівні логу:

- `TRC` (trace)
- `DBG` (debug)
- `INF` (info)
- `WRN` (warning)
- `ERR` (error)
- `FTL` (fatal)

На нас чекають три завдання, і кожне з них потрібно виконати, щоб реалізувати потрібну функціональність.

## 1. Створіть перелік LogLevel

Визначте перелік `LogLevel` із шістьма варіантами, що відповідають наведеним вище рівням логу, а також варіант unknown для рівнів, які відсутні або є нестандартними.

- `trace`
- `debug`
- `info`
- `warning`
- `error`
- `fatal`
- `unknown`

## 2. Розберіть рівень логу

Далі реалізуйте ініціалізатор `LogLevel`, який розбирає рівень логу з рядка логу:

```swift
LogLevel("[INF]: File deleted")
// Returns LogLevel.info
LogLevel("Something went wrong!")
// Returns LogLevel.unknown
```

## 3. Перетворіть рядок логу на короткий формат

Рівень логу в рядку логу досить багатослівний.
Щоб зменшити обсяг дискового простору, потрібний для зберігання рядків логу, розроблено короткий формат: `"<ENCODED_LEVEL>:<MESSAGE>"`.

Закодований рівень логу - це просте зіставлення рівня логу з числом:

- `trace` - `0`
- `debug` - `1`
- `info` - `4`
- `warning` - `5`
- `error` - `6`
- `fatal` - `7`
- `unknown` - `42`

Реалізуйте метод `shortFormat(message: String) -> String`, який може виводити скорочений формат рядка логу як `String`:

```swift
let overflow = LogLevel.error
overflow.shortFormat(message: "Stack overflow")
// Returns "6:Stack overflow"
```
