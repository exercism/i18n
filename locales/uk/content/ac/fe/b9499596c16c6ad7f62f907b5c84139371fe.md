# Інструкції

Ми працюємо над реалізацією системи моніторингу здоровʼя.
У межах цієї роботи нам потрібно відстежувати статистику здоровʼя користувачів.

Ми почнемо з кількох функцій-заглушок у блоці `impl`, а також з такого визначення структури:

```rust
pub struct User {
    name: String,
    age: u32,
    weight: u32,
}
```

Наша мета - реалізувати методи-заглушки, визначені в блоці `impl` для `User` `struct`.

Наприклад, метод `new` має повертати екземпляр структури `User` із зазначеними значеннями імені, віку та ваги.

```rust
let mut bob = User::new("Bob", 32, 72);
// Returns: a User with name "Bob", age 32, and weight 72
```

Метод `weight` має повертати вагу `User`.

```rust
bob.weight();
// Returns: 72
```

Метод `set_age` має встановлювати вік `User`.

```rust
bob.set_age(33);
// Updates Bob's age to 33; happy birthday Bob!
```
