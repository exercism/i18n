# Вступ

Функція дозволяє згрупувати код у повторно використовуваний блок.
Вона складається з ключового слова `func`, назви функції та розділеного комами списку з нуля або більше параметрів і типів у круглих дужках.

## Параметри функції

Усі параметри повинні мати явно вказаний тип; виведення типу для параметрів не працює.
Параметри не мають типових значень, тому всі параметри функції є обовʼязковими.

```go
import "fmt"

// No parameters
func PrintHello() {
    fmt.Println("Hello")
}

// Two parameters
func PrintGreetingName(greeting string, name string) {
  fmt.Println(greeting + " " + name)
}
```

Параметри одного типу можна оголосити разом, а після них указати один спільний тип.

```go
import "fmt"

func PrintGreetingName(greeting, name string) {
  fmt.Println(greeting + " " + name)
}
```

## Параметри проти аргументів

Швидко розглянемо два терміни, які часто плутають: `parameters` і `arguments`.
Параметри функції - це назви, визначені в сигнатурі функції, як-от `greeting` і `name` у функції `PrintGreetingName` вище.
Аргументи функції - це конкретні значення, які передаються параметрам функції, коли ми викликаємо функцію.
Наприклад, у прикладі нижче `"Hello"` і `"Katrina"` - це аргументи, передані параметрам `greeting` і `name`:

```go
PrintGreetingName("Hello", "Katrina")
```

## Повернені значення

Після параметрів функції йдуть нуль або більше повернених значень, які теж повинні мати явно вказаний тип.
Одиничні повернені значення записують без дужок, а кілька повернених значень беруть у дужки.
Значення повертаються у код, що викликав функцію, за допомогою ключового слова `return`.
У функції може бути кілька інструкцій `return`.
Виконання функції завершується, щойно вона натрапить на одну з таких інструкцій `return`.
Якщо з функції потрібно повернути кілька значень, їх розділяють комами.

```go
func Hello(name string) string {
  return "Hello " + name
}

func HelloAndGoodbye(name string) (string, string) {
  return "Hello " + name, "Goodbye " + name
}
```

## Виклик функцій

Щоб викликати функцію, потрібно вказати її назву та передати аргументи для кожного з параметрів функції в дужках.

```go
import "fmt"

// No parameters, no return value
func PrintHello() {
    fmt.Println("Hello")
}
// Called like this:
PrintHello()

// One parameter, one return value
func Hello(name string) string {
  return "Hello " + name
}
// Called like this:
greeting := Hello("Dave")

// Multiple parameters, multiple return values
func SumAndMultiply(a, b int) (int, int) {
    return a+b, a*b
}
// Called like this:
aplusb, atimesb := SumAndMultiply(a, b)
```

## Іменовані повернені значення та «голий» return

Так само, як і параметри, повернені значення можна за бажанням назвати.
Якщо використано іменовані повернені значення, інструкція `return` без аргументів поверне саме їх.
Це називають «голим» return.

```go
func SumAndMultiplyThenMinus(a, b, c int) (sum, mult int) {
    sum, mult = a+b, a*b
    sum -= c
    mult -= c
    return
}
```

## Передача за значенням і передача за посиланням

Також важливо розібратися з поняттям передачі за значенням і передачі за посиланням.

Спершу розберемо передачу за значенням.
У прикладі нижче, коли ми передаємо змінну `val` у функцію `MultiplyByTwo`, ми передаємо копію `val`.
Через це `newVal` має оновлене значення `4`, але початкова змінна `val` досі дорівнює `2`.
Під капотом Go по суті створює копію початкового значення, тож функція змінює лише цю копію, вона ж `v`.

```go
val := 2
func MultiplyByTwo(v int) int {
    v = v * 2
    return v
}
newVal := MultiplyByTwo(val)
// newval is 4, val is still 2 because only a copy of its value was passed into the function
```

Строго кажучи, у Go всі аргументи передаються за значенням, тобто створюється копія значення чи даних, наданих функції.
Але якщо ми не хочемо створювати копію даних, переданих у функцію, і хочемо змінювати ці дані всередині функції,
слід використовувати `pointers` як аргументи, тобто передачу за посиланням.

## Вказівники

Щоб досягти передачі за посиланням, ми використовуємо `pointer`.
Передаючи аргументи-`pointer` у функцію,
ми можемо змінювати самі дані, передані у функцію, а не лише працювати з копією цих даних.

Поки що достатньо знати, що типи вказівників можна розпізнати за символом `*` перед типом у сигнатурі функції.

```go
func HandlePointers(x, y *int) {
    // Some logic to handle integer values referenced by pointers x and y
}
```

Якщо поняття `pointer` здається заплутаним, не варто хвилюватися.
Далі в силабусі є окремий розділ, який допоможе нам опанувати вказівники.

## Винятки

Зауважмо, що `slices` і `maps` - це винятки з правила, згаданого вище.
Коли ми передаємо `slice` або `map` як аргументи у функцію, з ними поводяться як з типами вказівників, навіть якщо в типі немає явного `*`.
Це означає, що якщо ми передаємо слайс або мапу у функцію й змінюємо дані, що лежать в їхній основі,
ці зміни відобразяться на початковому слайсі чи мапі.
