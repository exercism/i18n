# Інструкції

Боб працює фінансовим радником і допомагає людям керувати своїми витратами.
Клієнти Боба надсилають йому записи про витрати для аналізу.
У Боба є записи за попередні періоди, тож він бачить, як змінюються витрати.
Боб не любить календарі й використовує *епоху Боба* замість дат.
*Епоха Боба* - це кількість днів, що минули від початку активності клієнта Боба.

У цій вправі ми створимо програму, яка допоможе Бобові керувати витратами його клієнтів і аналізувати їх.

Боб працює з `Record` і `DaysPeriod`.

`Record` описує запис про витрату, який містить день здійснення витрати, витрачену суму та категорію витрати.

```go
// Record represents an expense record.
type Record struct {
	Day         int
	Amount      float64
	Category    string
}
```

`DaysPeriod` описує діапазон днів і охоплює всі дні від дня `From` до дня `To`.
Обидва кінці включено до діапазону.

```go
// DaysPeriod represents a period of days.
type DaysPeriod struct {
	From int
	To   int
}

p := DaysPeriod{From: 1, To: 31}
// p represents all days from the day 1 to the day 31:
//  - days 1, 20, 16 and 31 are examples of days that are included
//    in the range of time specified by p
//  - days 50 and 40 are examples of days that are not included
//    in the range of time specified by p
```

## 1. Реалізуйте загальний фільтр записів

Щодня Боб має справу з великою кількістю записів, але не всі з них цікаві залежно від того, який аналіз робить Боб.
Допоможімо Бобові виконати базове фільтрування записів.

Реалізуйте загальну функцію `Filter`, щоб фільтрувати записи за критерієм, заданим функцією.
Ця функція фільтрування приймає колекцію записів і функцію-предикат, а повертає лише ті записи з колекції, що задовольняють предикат.

```go
records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
}

// Day1Records only returns true for records that are from day 1
func Day1Records(r Record) bool {
  return r.Day == 1
}

Filter(records, Day1Records)
// =>
// [
//   {Day: 1, Amount: 15, Category: "groceries"}
// ]
```

## 2. Відфільтруйте записи в межах періоду часу

Бобові часто потрібно фільтрувати записи, що належать до заданого періоду часу.

Реалізуйте функцію `ByDaysPeriod`, яка допоможе Бобові створювати такі фільтри.
Ця функція приймає `DaysPeriod` і повертає функцію, яка бере запис і повідомляє, чи належить цей запис до періоду часу, заданого переданим аргументом `DaysPeriod`.

```go
records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
  {Day: 26, Amount: 300, Category: "university"},
  {Day: 28, Amount: 1300, Category: "rent"},
}

period := DaysPeriod{From: 1, To: 15}

Filter(records, ByDaysPeriod(period))
// =>
// [
//   {Day: 1, Amount: 15, Category: "groceries"},
//   {Day: 11, Amount: 300, Category: "utility-bills"},
//   {Day: 12, Amount: 28, Category: "groceries"},
// ]
```

## 3. Відфільтруйте записи за категорією

Окрім фільтрування записів за періодом часу, Бобові також потрібно фільтрувати записи за категорією.

Реалізуйте функцію `ByCategory`, яка допоможе Бобові створювати такі фільтри.
Ця функція приймає категорію і повертає функцію, яка бере запис і повідомляє, чи збігається категорія цього запису з категорією, переданою як аргумент.

```go
records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
  {Day: 28, Amount: 1300, Category: "rent"},
}

Filter(records, ByCategory("groceries"))
// =>
// [
//   {Day: 1, Amount: 15, Category: "groceries"},
//   {Day: 12, Amount: 28, Category: "groceries"},
// ]
```

## 4. Обчисліть загальну суму витрат за період

Боб також хоче знати загальну суму витрат за період часу.

Реалізуйте функцію `TotalByPeriod`, яка повертає суму витрат за період днів.

```go
records := []Record{
  {Day: 15, Amount: 16, Category: "entertainment"},
  {Day: 32, Amount: 20, Category: "groceries"},
  {Day: 40, Amount: 30, Category: "entertainment"}
}

p1 := DaysPeriod{From: 1, To: 30}
p2 := DaysPeriod{From: 31, To: 60}

TotalByPeriod(records, p1)
// => 16

TotalByPeriod(records, p2)
// => 50
```

## 5. Обчисліть загальну суму витрат для записів певної категорії за період

Для найскладніших звітів, які Боб робить для своїх клієнтів, йому потрібно фільтрувати записи одночасно за категорією та періодом часу.
Тобто Боб хоче знати загальну суму витрат для записів певної категорії за заданий період часу.

Реалізуйте функцію `CategoryExpenses`, яка повертає загальну суму витрат у певній категорії за заданий період днів.
Функція також повинна розрізняти випадок, коли заданої категорії немає серед записів про витрати, і випадок, коли в наданому періоді немає витрат цієї категорії.
Якщо категорія не є категорією жодного із записів (незалежно від періоду часу), функція повинна повернути помилку.

```go
p1 := DaysPeriod{From: 1, To: 30}
p2 := DaysPeriod{From: 31, To: 60}

records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
  {Day: 26, Amount: 300, Category: "university"},
  {Day: 28, Amount: 1300, Category: "rent"},
}

CategoryExpenses(records, p1, "entertainment")
// => 0, error(unknown category entertainment)

CategoryExpenses(records, p1, "rent")
// => 1300, nil

CategoryExpenses(records, p2, "rent")
// => 0, nil
```
