# Додаток до інструкцій

## Регістри

| Регістр | Використання | Тип | Опис |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | вхідні дані        | ціле число | задане число                  |
| `$a1`    | вхідні та вихідні дані | адреса | рядок тексту (англ. string) з результатом, завершений нульовим символом |
| `$t0-9`  | тимчасові дані    | будь-який     | для тимчасового зберігання         |
