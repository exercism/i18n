# Інструкції

Наш друг щойно надіслав нам повідомлення з важливим секретом.
Не бажаючи, щоб інші легко його прочитали, він зашифрував повідомлення за допомогою низки маніпуляцій з бітами.
Нам потрібно буде написати програму, яка допоможе розшифрувати повідомлення.

## 1. Зсуньте біти назад

Щоб розшифрувати повідомлення, спочатку треба скасувати зсув, зроблений під час шифрування, зсунувши біти назад уліво.
Кількість позицій для зсуву може відрізнятися залежно від повідомлення.

Реалізуйте метод `Secrets.shift_back`, який приймає значення та кількість позицій для зсуву вліво.

```crystal
Secrets.shift_back(0b0001, 2)
# => 0b0100
```

## 2. Застосуйте бітову маску

Далі застосовуємо бітову маску, щоб видобути значення певних бітів.
Маску застосовують, виконуючи побітове AND між значенням і маскою.

Реалізуйте метод `Secrets.apply_mask`, який приймає значення та застосовує до нього маску.

```crystal
Secrets.apply_mask(0b0110, 0b0101)
# => 0b0100
```

## 3. Установіть деякі біти

Зсув бітів уліво додав нові біти зі значенням 0.
Деякі з цих нових бітів потрібно встановити в 1.
Побітове OR стає в пригоді, коли треба встановити певні біти в 1, зберігши решту без змін.

Реалізуйте метод `Secrets.set_bits`, який приймає два значення та виконує побітове OR.

```crystal
Secrets.set_bits(0b0110, 0b0101)
# => 0b111
```

## 4. Зворотний XOR

Частина процесу шифрування застосовує XOR з узгодженим значенням.
Щоб повернутися до початкового значення, достатньо ще раз застосувати XOR до зашифрованого значення та узгодженого значення.
Однак через непорозуміння наш друг перед застосуванням XOR перевернув біти узгодженого значення (тобто застосував побітове NOT до узгодженого значення).

Реалізуйте метод `Secrets.reverse_xor`, який приймає зашифроване значення й узгоджене значення та обчислює початкове значення.

```crystal
Secrets.reverse_xor(0b1100, 0b0101)
# => 0b(0110)
```
