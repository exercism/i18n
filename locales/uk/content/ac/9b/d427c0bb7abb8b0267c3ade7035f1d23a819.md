# defmacro з `_is` і знаком питання

[comment]: # (- option2: the correct name for guards)

В Elixir є особливі конвенції найменування, які охоплюють те, як називати [функції, що повертають булеві значення (англ. Boolean)](https://hexdocs.pm/elixir/naming-conventions.html#trailing-question-mark-foo) і [перевірки, що повертають булеві значення та є дозволеними в охоронних умовах](https://hexdocs.pm/elixir/naming-conventions.html#is_-prefix-is_foo):

> Функції, що повертають булеве значення, мають у назві знак питання в кінці.

> Перевірки типів та інші булеві перевірки, дозволені в охоронних умовах, мають у назві префікс `is_`.

Макроси можна застосовувати в обох контекстах, тож позначення залежить від випадку, але ці дві конвенції найменування не можна змішувати.

```elixir
# this is the expected name of macros that return booleans

%{option1}

# this is the expected name of macros that return booleans and are valid in guard clauses

%{option2}

# this is the current name

%{actual}
```
