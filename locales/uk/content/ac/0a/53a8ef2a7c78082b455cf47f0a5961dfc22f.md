# Генератори

`generator` - це функція або вираз, що повертає особливий тип [ітератора][iterator], який називається [`generator iterator`][generator-iterator].
`Generator-iterator`-и [ліниві][lazy iterator]: вони не зберігають свої `values` у памʼяті, а _генерують_ свої значення тоді, коли вони потрібні.

Функція-генератор має такий самий вигляд, як і будь-яка інша функція, але містить один або кілька [виразів `yield`][yield expression].
Кожен `yield` призупиняє виконання коду, зберігаючи поточний стан виконання (_разом з усіма локальними змінними та інструкціями `try`_).
Коли генератор відновлює роботу, він повертається до збереженого стану, на відміну від звичайних функцій, які скидають стан за кожного виклику.


## Створення генератора

Генератори створюють майже так само, як інші функції з циклами чи рекурсією, але вони потребують [виразу `yield`](#the-yield-expression), який ми трохи згодом розглянемо докладніше.

Ось приклад: функція, що повертає _квадрати_ чисел із заданого масиву.
У поточному вигляді всі вхідні дані потрібно обробити, перш ніж повернути хоч якісь значення:

```python
>>> def squares(list_of_numbers):
...     squares = []
...     for number in list_of_numbers:
...         squares.append(number ** 2)
...     return squares
```

Перетворити цю функцію на генератор можна так:

```python
>>> def squares_generator(list_of_numbers):
...     for number in list_of_numbers:
...         yield number ** 2
```

Сенс у тому, що генератор використовують, коли не потрібно отримувати всі значення _одразу_.
Це заощаджує памʼять і обчислювальні ресурси, адже обчислюється лише те значення, з яким ми _працюємо в цей момент_.


## Використання генератора

У Python генератори можна використовувати замість більшості `iterables`.
Це стосується _функцій_ та _обʼєктів_, які приймають `iterable`/`iterator` як аргумент.

Щоб скористатися генератором `squares_generator()`:

```python
>>> squared_numbers = squares_generator([1, 2, 3, 4])

>>> for square in squared_numbers:
...     print(square)
...
1
4
9
16
```

Значення з `generator` можна також отримувати й читати за допомогою функції `next()`.
`next()` викликає метод `__next__()` обʼєкта-генератора-ітератора, «просуваючи» або обчислюючи код до його виразу `yield`, який потім «віддає» чи повертає значення:

```python
>>> squared_numbers = squares_generator([1, 2])

>>> next(squared_numbers)
1
>>> next(squared_numbers)
4
```

Коли `generator-iterator` повністю вичерпано й більше немає значень для повернення, він викидає помилку `StopIteration`.

```python
>>> next(squared_numbers)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
StopIteration
```


~~~~exercism/note

Генератори-ітератори - це особливий підвид [ітераторів][iterator].
`Iterators` - це механізм чи протокол, який уможливлює перебирання _iterables_.
Генератори-ітератори та ітератори, які повертають звичайні Python-[`iterables`][iterables], поводяться дуже схоже, але варто звернути увагу на кілька важливих відмінностей:

- Вони _[обчислюються ліниво][lazy evaluation]_; ітерація є _односторонньою_, і «відкату» до попереднього значення немає.
- Вони _вичерпуються_, коли ми перебираємо повернуті значення; скинути їх чи зберегти в памʼяті не можна.
- Їх не можна сортувати й не можна розвертати.
- Вони не належать до послідовностей і _не мають_ `indexes`. 
  До попереднього чи наступного значення не можна дістатися додаванням чи відніманням, а також не можна використовувати запис із квадратними дужками (`[]`) чи зрізи.
- Їх не можна використовувати з функцією `len()`, бо вони не мають довжини.
- Вони можуть бути _скінченними_ або _нескінченними_ - будьмо обережні, збираючи всі значення з _нескінченного_ `generator-iterator`!

## Вираз `yield`

[Вираз `yield`][yield expression] дуже схожий на вираз `return`.
_На відміну_ від виразу `return`, `yield` віддає значення тому, хто викликав, у _певній точці_, призупиняючи обчислення й повернення решти значень, доки їх не запросять.
Коли `yield` обчислюється, він зупиняє виконання функції, у якій міститься, і повертає значення цієї функції _на той момент часу_.
Після цього функція _залишається в області видимості_, і коли викликають `__next__()`, виконання продовжується, доки `yield` не зустрінеться знову.


~~~~exercism/note
Використовувати вирази `yield` поза функціями заборонено.
~~~~

```python
>>> def infinite_sequence():
...     current_number = 0
...     while True:
...         yield current_number
...         current_number += 1

>>> lets_try = infinite_sequence()
>>> lets_try.__next__()
0
>>> lets_try.__next__()
1
```


## Навіщо створювати генератор?

Генератори стають у пригоді в багатьох задачах.

Коли ми працюємо з великим набором значень, класти їх усі в памʼять, імовірно, не варто.
Генератор дає змогу обробляти великі дані частина за частиною, заощаджуючи памʼять і підвищуючи швидкодію.

Генератори також дуже помічні, коли процес чи обчислення _складні_, _затратні_ або _нескінченні_:

```python
>>> def infinite_sequence():
...     current_number = 0
...     while True:
...         yield current_number
...         current_number += 1
```

Тепер, коли для обʼєкта `infinite_sequence` викликають `__next__()`, він повертатиме _попереднє число_ + 1.
