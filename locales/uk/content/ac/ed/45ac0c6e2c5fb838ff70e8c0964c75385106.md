# Розвʼязування вправ

Exercism найбільше допомагає нам навчатися через розвʼязування вправ.

На Exercism є два способи розвʼязувати вправи:

1. [Онлайн, через редактор у браузері на сайті](/docs/using/solving-exercises/using-the-online-editor)
2. [На власному компʼютері через CLI](/docs/using/solving-exercises/working-locally)

## Який варіант обрати?

Між онлайн-редактором і CLI є різні компроміси:

|            | Онлайн-редактор                        | CLI                                          |
| ---------- | -------------------------------------- | -------------------------------------------- |
| Встановлення | Ні                                   | Так (наприклад, SDK)                         |
| Редагування | Браузер                              | Наш улюблений редактор                       |
| Тестування | Запуск тестів на сайті                 | Запуск тестів локально                       |
| Налагодження | Обмежена підтримка (лише для деяких треків) | Повна підтримка (залежно від середовища) |

Загалом онлайн-редактор ідеально підходить для початку нових треків, а підхід на основі CLI чудово працює, якщо ми хочемо використовувати власне персоналізоване середовище для програмування.
