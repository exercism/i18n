# Підказки

## Загальні

- Прочитайте про [структури][getting-started-structs] у посібнику «Початок роботи».
- Прочитайте про [`defstruct`][docs-defstruct] у документації.
- Подивіться [Elixir Casts - #106: Intro to Structs][elixir-casts].

## 1. Створіть нову радіокеровану машину

- Атрибут модуля `@enforce_keys` можна використати, щоб указати обовʼязкові значення. Його потрібно визначити перед викликом `defstruct`.
- Для поля `nickname` не потрібно вказувати типове значення.
- Функція `new/0` має ініціалізувати `nickname` значенням `"none"`.

## 2. Створіть нову радіокеровану машину з іменем

- Скористайтеся [`multiple-function-clauses`][multiple-fn-clauses], щоб повторно використати назву функції, але приймати різні аргументи.
- Розгляньте [`default-argument`][default-arg] для функції.

## 3. Покажіть відстань

- Для функцій, які приймають лише структуру певного типу, обовʼязково виконуйте зіставлення зі зразком, щоб перевірити аргумент.
- Щоб отримати значення полів, використовуйте _оператор статичного доступу_.

## 4. Покажіть відсоток заряду батареї

- Для функцій, які приймають лише структуру певного типу, обовʼязково виконуйте зіставлення зі зразком, щоб перевірити аргумент.
- Щоб отримати значення полів, використовуйте _оператор статичного доступу_.

## 5. Їзда змінює заряд батареї і пройдену відстань

- Для функцій, які приймають лише структуру певного типу, обовʼязково виконуйте зіставлення зі зразком, щоб перевірити аргумент.
- Щоб отримати значення полів, використовуйте _оператор статичного доступу_.
- Перегляньте вступ, щоб дізнатися, як оновлювати структури.

## 6. Врахуйте їзду з розрядженою батареєю

- Якщо батарея розряджена, функція має повернути структуру без змін.
