# Підказки

## Загальні

- За потреби поверніться до [концепції обʼєктів][concept-objects], щоб освіжити базові знання.

## 1. Визначте Size для зберігання розмірів вікна

- Не забудьте використати [синтаксис прототипів][mdn-prototype] для цього завдання.
- Почніть з визначення функції з назвою `Size` і не забудьте її [експортувати][mdn-export].
- Аргументи, передані у функцію-конструктор, потрібно додати до обʼєкта `this`.
- Типові значення можна застосувати за допомогою [типових параметрів][mdn-default-params].
- Метод можна додати через властивість `prototype` функції-конструктора.

## 2. Визначте Position для зберігання позиції вікна

- Не забудьте використати [синтаксис прототипів][mdn-prototype] для цього завдання.
- Почніть з визначення функції з назвою `Position` і не забудьте її [експортувати][mdn-export].
- Аргументи, передані у функцію-конструктор, потрібно додати до обʼєкта `this`.
- Типові значення можна застосувати за допомогою [типових параметрів][mdn-default-params].
- Метод можна додати через властивість `prototype` функції-конструктора.

## 3. Визначте клас ProgramWindow

- Не забудьте використати [синтаксис класів][mdn-class] для цього завдання.
- Не забудьте [експортувати][mdn-export] клас.
- Визначте поля, додавши їх до обʼєкта `this`.
- Скористайтеся класами, визначеними в попередніх завданнях.
- Переконайтеся, що функція-конструктор не приймає жодних аргументів.

## 4. Додайте метод для зміни розміру вікна

- Не забудьте використати [синтаксис класів][mdn-class] для цього завдання.
  Це означає, що визначення методу додається безпосередньо в тіло класу.
- Щоб знайти правильні значення для зміни розміру, спершу подумайте про бажану ширину, якої хочете досягти, враховуючи нижню межу (`1`).
- Потім обчисліть максимальну дозволену ширину, враховуючи розмір екрана й поточну позицію `x` вікна.
- Маючи ці два значення, можна вирішити, яке з них застосувати, і скористатися аналогічною логікою для висоти.
- Скористайтеся методом `resize` обʼєкта `Size`, щоб застосувати зміну.

## 5. Додайте метод для переміщення вікна

- Не забудьте використати [синтаксис класів][mdn-class] для цього завдання.
  Це означає, що визначення методу додається безпосередньо в тіло класу.
- Щоб знайти правильні значення для переміщення, спершу подумайте про бажану позицію `x`, якої хочете досягти, враховуючи нижню межу (`0`).
- Потім обчисліть максимально дозволене значення `x`.
  Врахуйте розмір екрана й поточну ширину вікна.
- Маючи ці два значення, можна вирішити, яке з них застосувати, і скористатися аналогічною логікою для висоти.
- Скористайтеся методом `move` обʼєкта `Position`, щоб застосувати зміну.

## 6. Змініть вікно програми

- Спершу визначте функцію `changeWindow` і не забудьте її [експортувати][mdn-export].
- Створіть екземпляр класу `Size` за допомогою ключового слова `new` і передайте бажані розміри як аргументи. (Так само для потрібного обʼєкта позиції.)
- Скористайтеся методами, визначеними в завданнях 4 і 5. Наприклад, метод `a` обʼєкта `obj` викликають так: `obj.a()`.
- Не забудьте повернути екземпляр `Window`, отриманий на вході.
