# Вступ

## Nil

Слово [Nil][nil-dictionary] в англійській мові означає «ніщо» або «нуль». В Elixir `nil` - це особливе значення, яке означає _відсутність_ значення.

```elixir
# I do not have a favorite color
favorite_color = nil
```

В інших мовах програмування подібну роль можуть відігравати значення `null` або `none`.

## If

Крім `cond`, Elixir також надає макрос [`if/2`][getting-started-if], який стає в пригоді, коли потрібно перевірити лише одну умову.

[`if/2`][kernel-if] приймає умову та два варіанти. Він повертає перший варіант, якщо умова _truthy_, і другий варіант, якщо умова _falsy_.

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
else
  "No beer for you!"
end

# => "No beer for you!"
```

Вираз `if` можна також записати в один рядок. Звернімо увагу на кому після умови.

```elixir
if age > 16, do: "beer", else: "no beer"
```

Цей синтаксис стає в пригоді для дуже коротких виразів, але його варто оминати, якщо вираз не вміщується в один рядок.

### _Truthy_ та _falsy_

В Elixir усі типи даних набувають значення _truthy_ або _falsy_, коли потрапляють у булевий контекст (англ. Boolean), наприклад у вираз `if`. Усі дані вважаються _truthy_ **крім** `false` та `nil`. Зокрема, порожні рядки тексту (англ. string), ціле число `0` та порожні масиви в Elixir теж вважаються _truthy_.
