# Вступ

## Інструкція «switch»

Як і умовна конструкція _if/else_, інструкція `switch` дозволяє змінити хід виконання програми, виконуючи код за певної умови.
Різниця в тому, що інструкція `switch` може порівнювати значення виразу примітивного типу або рядка тексту (англ. string) лише з наперед визначеними сталими значеннями.

Коли ми працюємо з інструкцією `switch`, стають у пригоді деякі ключові слова.

- `switch`: це ключове слово дозволяє оголосити структуру `switch`.
  Після нього йде вираз або змінна, від яких залежатиме результат.
- `case`: це ключове слово ми використовуємо, щоб оголосити різні можливі результати.
- `break`: ключове слово `break` дуже корисне, щоб зупинити виконання `switch` наприкінці потрібної гілки.
  Якщо його забути, програма продовжить роботу й може дати несподівані результати.
- `default`: як підказує сама назва, його використовують як типовий результат, коли жоден інший варіант `case` не відповідає результату виразу.

У найпростішому випадку вони перевіряють вираз примітивного типу або рядок тексту й ухвалюють рішення на основі його значення.
Наприклад:

```java
String direction = getDirection();
switch (direction) {
    case "left":
        goLeft();
        break;
    case "right":
        goRight();
        break;
    default:
        // otherwise
        markTime();
        break;
}
```
