# Докладніше

`Map` використовують для зберігання пар **ключа** та **значення**. `Maps` ініціалізують так само, як масив, але з оператором літерала словника `=>`. Типи ключів і значень можна також задати явно, або ж їх можна вивести. Ключі мають бути унікальними, інакше буде викинуто помилку.

```haxe
var map1:Map<Int, String> = [1 => "one", 2 => "two", 3 => "three"];

var map2 = ["one" => 1, "two" => 2, "three" => 3];

var map3 = [1 => "cat", 1 => "dog"]; // Error: Duplicate Key

var map4 = ["h" => "Hello", "b" => "Bye"];
trace(map4["h"]); // Hello
```

`Map` можна перебрати за допомогою циклу `for`. Перебирати можна або значення, або ключі:

```haxe
for (value in map) {
  // ...
}

for (key in map.keys()) {
  // ...
}
```

На рівні реалізації `Map` належить до абстрактних типів. Під час компіляції він перетворюється на один із кількох спеціалізованих типів залежно від типу ключа:

- `String`: `haxe.ds.StringMap`
- `Int`: `haxe.ds.IntMap`
- `EnumValue`: `haxe.ds.EnumValueMap`
- `{}`: `haxe.ds.ObjectMap`

Типу `Map` під час виконання не існує. Його замінено одним із наведених вище обʼєктів.
