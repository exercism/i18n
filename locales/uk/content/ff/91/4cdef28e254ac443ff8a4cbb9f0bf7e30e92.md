# Навчання

* [The Rust Programming Language](https://doc.rust-lang.org/book/). Це чудовий ресурс як для початку роботи з Rust, так і для глибшого занурення в окремі можливості Rust.
* [Rust by Example](https://doc.rust-lang.org/stable/rust-by-example/). Тут показано приклади найпоширеніших речей, які ми будемо писати мовою Rust.
* [Into_rust()](http://intorust.com/): «Скринкасти для вивчення Rust.»
* [Rustlings](https://github.com/carols10cents/rustlings): «Малі вправи, які допоможуть звикнути до читання й написання коду Rust.»
* [Rust User Forum](http://users.rust-lang.org) відповідає на запитання будь-якого рівня
