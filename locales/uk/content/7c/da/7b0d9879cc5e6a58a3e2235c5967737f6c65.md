# Вступ

Параметр методу можна зробити необовʼязковим, присвоївши йому типове значення. Коли ми викликаємо метод із необовʼязковими параметрами, передавати для них значення не обовʼязково. Якщо для необовʼязкового параметра не передано жодного значення, буде використано його типове значення.

Необовʼязкові параметри повинні стояти в кінці списку параметрів; після них не може бути обовʼязкових параметрів.

```haxe
class Card {
  static function newYear(year = 2021):String {
    return "Happy " + year;
  }
}

Card.newYear(); // Happy 2020
Card.newYear(1990); // Happy 1990
```

Необовʼязковому параметру можна присвоїти значення `null`, використавши оператор `?` перед назвою змінної:

```haxe
function newYear(?year:Int) {
  if (year != null)
    return "It's " + year;
  return "Year is null";
}

newYear(); // Year is null
```
