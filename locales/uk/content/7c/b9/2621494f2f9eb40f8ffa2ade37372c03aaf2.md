# Інструкції

Леслі, іншопланетянин з Lisp, має зробити покупки. Дуже важливо мати список покупок. До нього треба додавати речі й вилучати їх.

Звісно, звичайні ручка й папір не годяться для іншопланетянина з Lisp. Слово «List» - це ж майже все слово «Lisp»! Тож треба написати кілька функцій, які допоможуть стежити за покупками.

Допоможемо Леслі стежити за списком покупок?

## 1. Створення нового списку

Перш за все Леслі треба створити порожній список. Ідеально підійде функція `new-list`.

```lisp
(new-list) ; => ()
```

Ой ні... Леслі вже має на думці кілька речей, тож потрібна функція, яка приймає три елементи (на щастя, Леслі створює списки лише з трьох елементів. Ні більше, ні менше!) і створює з них новий список покупок. Напишіть функцію `list-of-things`, яка приймає три елементи й повертає список із них.

```lisp
(list-of-things 'bread 'milk 'butter) ; => '(bread milk butter)
```

## 2. Додавання речей до списку

Перш ніж іти до магазину, Леслі зазирає до комори, щоб подивитися, чого бракує. Допоможіть Леслі, написавши функцію `add-to-list`, яка додає елемент на початок списку.

```lisp
(add-to-list 'butter '(bread)) ; => '(butter bread)
```

## 3. Що наступне у списку?

Під час покупок Леслі хоче знати, що шукати далі. А ще любить зазирати наперед у список, щоб побачити другий, третій чи навіть двадцять третій елемент (його щасливе число).

- `first-thing` повертає перший елемент списку
- `second-thing` повертає другий елемент
- `third-thing` повертає третій елемент
- `twenty-third-thing` повертає двадцять третій елемент

```lisp
(first-thing '(bread butter milk)) ; => 'bread
(second-thing '(bread butter milk)) ; => 'butter
(third-thing '(bread butter milk)) ; => 'milk
```

## 4. Вилучення речі зі списку

Леслі хоче знайти перший елемент списку й забрати його з полиці. Допоможіть Леслі, написавши функцію `remove-first-item`, яка повертає список з усім, крім першого елемента вхідного списку.

```lisp
(remove-first-item '(bread butter milk)) ; => '(butter milk)
```

## 5. Більші списки з менших

Леслі зрозумів, що випадково склав два списки покупок замість одного! Напишіть функцію `list-append`, яка повертає список з елементів першого списку, за якими йдуть елементи другого списку.

```lisp
(list-append '(bread salt) '(butter milk)) ; => '(bread salt butter milk)
```

## 6. Наскільки ж довгий список?

Леслі починає хвилюватися, що цей похід за покупками забере чимало часу. То скільки ж речей у цьому списку? Напишіть функцію `just-how-long`, яка поверне довжину списку.

```lisp
(just-how-long '(bread milk butter salt)) ; => 4
```
