# Докладніше

## Опціонали

Swift використовує [_опціонали_][optionals], щоб дозволити програмістам представляти можливу відсутність значення.
Опціонал - це тип, який може або містити значення, або бути [`nil`][nil], що представляє відсутність значення.
Використання опціоналу вимагає, щоб програма перевірила, чи значення справді існує, перш ніж використати його після розгортання.

Будь-який тип можна зробити опціональним, додавши `?` у кінець назви типу.
Тож опціональне ціле число матиме тип `Int?`, а опціональний рядок тексту (англ. string) - тип `String?`.
Оголошення констант або змінних опціонального типу й присвоєння їм значень відбувається так само, як і для значень неопціональних типів.

```swift
let x: Int? = 42
var y: String? = "Hello"
y = "Goodbye"
```

Можна присвоїти змінній опціонального типу відсутність значення, присвоївши їй спеціальне значення `nil`.
`nil` можна використовувати з усіма опціональними типами, але `nil`, присвоєні двом різним опціональним типам, мають різні типи, тож їх не можна взаємозамінювати чи навіть порівнювати.

```swift
let intOpt: Int? = nil
let stringOpt: String? = nil

intOpt = stringOpt
// Compiler error: Cannot assign value of type 'String?' to type 'Int?'

intOpt == stringOpt
// Compiler error: Binary operator '==' cannot be applied to operands of type 'Int?' and 'String?'
```

Зауважмо також, що хоча `nil` можна присвоїти будь-якому опціональному типу, його не можна присвоїти неопціональному типу (навіть якщо той насправді не містить `nil`).
А методу, який приймає неопціональний тип, не можна передати опціональний тип, не розгорнувши його спершу.

```swift
var x: Int = 42
var y: Int? = 42

y = x
// Works fine
x = y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
x + y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
```

## Використання опціоналів

Оскільки опціональні типи не тотожні своїм базовим типам, ці два типи не можна використовувати однаково.
Наприклад: `Int("123") + 1` дає помилку компілятора «Value of optional type 'Int?' must be unwrapped to a value of type 'Int'».
Це тому, що `Int("123")` повертає опціональний тип `Int?`, а не тип `Int`, адже якщо рядок тексту не вдається перетворити на ціле число, результатом буде `nil`.
Щоб дістати `Int` із цього перетворення, спершу треба його «розгорнути».

Найчастіше в Swift це роблять за допомогою конструкцій `if-let` і `guard-let` для [_привʼязування опціоналів_][optional-binding], які перевіряють на `nil` і йдуть одним шляхом коду, привʼязуючи розгорнуте значення до вказаного імені, якщо значення існує, або іншим шляхом, якщо знайдено `nil`.

```swift
if let safeNum = Int("123") {
	let sum = safeNum + 1
	…
} else {
  // code for the case where nil was found -- may be left out
}
```

Варто зауважити, що змінна `safeNum` має тип `Int`, а не `Int?`.
У прикладі нижче `num` має тип `Int?`, а `safeNum` - тип `Int`.

```swift
let num = Int("123")
if let safeNum = num {
  // num is of type Int
}
```

Це _привʼязування опціоналів_ важливе, бо воно розгортає (або «прибирає») опціональний тип зі значення, дозволяючи використати його як неопціональне значення.
Якщо ж просто зробити умовну перевірку того, чи значення дорівнює `nil`, значення все одно матиме опціональний тип:

```swift
let num = Int("123")
if num != nil {
  // num is of type Int?
}
```

Варіант із `guard-let` також можна використати в тих випадках, коли потрібне дострокове повернення:

```swift
guard let num = Int("123") else { return nil }
let sum = num + 1
…
```

## Порівняння опціоналів

Зауважмо, що навіть якщо базові типи пари опціоналів можна порівняти стандартними операторами порівняння, самі опціонали порівняти не можна.
Їх можна лише перевірити на рівність.
Два опціонали рівні, якщо обидва дорівнюють `nil`, або якщо значення, які вони містять, рівні в межах своїх базових типів.

Однак можна написати код, який виконає власне порівняння двох опціональних значень.
Нижче наведено приклад інструкції `switch`, яка поверне `true` лише тоді, коли обидва опціональні значення не дорівнюють nil і перше значення менше за друге.
Для цього вона використовує _опціональний шаблон_ `varName?`, який збігається лише з опціоналами, що не дорівнюють nil, привʼязуючи значення всередині опціоналу до імені `varName`.

```swift
switch (optionalA, optionalB) {
case let (valA?, valB?): return valA < valB
default: return false
}
```
