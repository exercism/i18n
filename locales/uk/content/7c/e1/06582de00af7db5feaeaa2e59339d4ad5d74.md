# Вступ

Хоча для виконання умовної логіки можна використовувати вирази `if/else`, у Haskell є й потужніший спосіб робити це: [зіставлення зі зразком][pattern-matching].
За допомогою зіставлення зі зразком значення можна перевірити на відповідність одному або кільком _зразкам_.
Прикладом такого зразка є _константний зразок_, який зіставляє значення з константою (наприклад, `1` або `"hello"`).

Визначаючи функції, ми можемо задати окремі тіла функції для різних зразків.
Це дає чистий код, простий і зрозумілий.
Зіставляти зі зразком можна будь-який тип даних: числа, символи, масиви, кортежі тощо.

Наприклад, просту функцію, яка приймає ціле число (`Int`) і робить його на _1_ ближчим до _0_, можна записати так:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero 1 = 0
```

Зіставлення зі зразком розкривається найкраще, коли його поєднують з іншими зразками, наприклад зі _змінним зразком_:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero n = n - 1
```

У наведеному прикладі всі вхідні дані, крім _0_, обробляються однаково, і для відʼємних чисел результат буде неправильним.
Це можна розвʼязати за допомогою умовних зразків, відомих як _вартові вирази_, які записують за допомогою символу `|`:

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
```

У наведених прикладах не всі можливі вхідні дані мають відповідний зразок.
Компілятор це виявить і видасть попередження.
Це дуже корисна можливість Haskell, яка допомагає переконатися, що всі можливі шляхи покрито, щоб уникнути помилок під час виконання.
Її називають _перевіркою на вичерпність_.
Щоб позбутися попередження, потрібно обробити всі випадки.
Усередині _вартових виразів_ можна використати вираз `otherwise` як синтаксичний цукор для `True`, щоб уловити всі решта зразків.

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
    | otherwise = 0
```

Зіставлення зі зразком перевіряє значення на відповідність кожному зразку згори донизу, доки не знайде відповідний зразок і не виконає логіку, повʼязану з цим зразком.
**Порядок зразків має значення!**
