# Підвищення властивостей конструктора

У класах, які оголошують багато властивостей, окреме оголошення класу, його властивостей і конструктора для встановлення цих властивостей вимагає повторень.
За допомогою підвищення властивостей конструктора ми можемо зменшити кількість повторень.

```php
<?php

class Book
{
    private string $isbn;
    private string $doi;
    private string $title;

    public function __construct(string $isbn, string, $doi, string $title)
    {
        $this->isbn = $isbn;
        $this->doi = $doi;
        $this->title = $title;
    }
}

// Using constructor property promotion
class Book
{
    public function __construct(
        private string $isbn,
        private string $doi,
        private string $title
    ) {
    }
}
