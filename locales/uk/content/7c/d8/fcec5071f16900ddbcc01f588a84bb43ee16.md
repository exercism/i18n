# Інструкції

У цій вправі ми напишемо ще трохи коду, повʼязаного з приготуванням і запіканням нашої чудової лазаньї з улюбленої книги рецептів.

У нас пʼять завдань.
Перше стосується самого запікання, а решта чотири присвячені ідеальній підготовці.

## 1. Визначте, чи готова лазанья

Коли лазанья в печі, ми хочемо знати, чи вже можна її дістати.
Щоб лазанья не згоріла в печі, зазвичай ставлять таймер.
Але іноді ми забуваємо про це.

Напишіть функцію `cookingStatus`, яка приймає час, що залишився на таймері, у хвилинах як параметр.
Функція має три можливі результати.

- Якщо таймер показує `0`, вона повинна повернути `'Lasagna is done.'`.
- Якщо таймер показує будь-яке інше число, результат має бути `'Not done, please wait.'`.
- Якщо функцію викликати без значення таймера, результат має бути `'You forgot to set the timer.'`.

Таймер ніколи не показує значення, менше за 0.

```javascript
cookingStatus(12);
// => 'Not done, please wait.'

cookingStatus();
// => 'You forgot to set the timer.'
```

## 2. Оцініть час підготовки

Для наступної лазаньї, яку ми будемо готувати, ми хочемо переконатися, що в нас зарезервовано достатньо часу, щоб насолодитися приготуванням.
Ми вже склали план з усіма шарами, які матиме наша лазанья.
Тепер хочемо оцінити, скільки часу займе підготовка на основі цього.

Реалізуйте функцію `preparationTime`, яка приймає масив шарів і середній час підготовки на шар у хвилинах.
Функція повинна повернути оцінку загального часу підготовки на основі кількості шарів.
Якщо функцію викликати без середнього часу підготовки, замість цього слід припустити `2` хвилини.

```javascript
const layers = ['sauce', 'noodles', 'sauce', 'meat', 'mozzarella', 'noodles'];
preparationTime(layers, 3);
// => 18

preparationTime(layers);
// => 12
```

## 3. Обчисліть потрібну кількість локшини та соусу

Окрім резервування часу, ми також хочемо переконатися, що маємо достатньо соусу і локшини, щоб приготувати лазанью своєї мрії.
На кожен шар локшини в нашій лазаньї знадобиться 50 грамів локшини.
На кожен шар соусу в нашій лазаньї знадобиться 0.2 літра соусу.

Визначте функцію `quantities`, яка приймає масив шарів як параметр.
Тоді функція визначить кількість локшини та соусу, потрібну для приготування страви.
Результат потрібно повернути як обʼєкт із ключами `noodles` і `sauce`.

```javascript
quantities(['sauce', 'noodles', 'sauce', 'meat', 'mozzarella', 'noodles']);
// => { noodles: 100, sauce: 0.4 }
```

## 4. Додайте секретний інгредієнт

Якось ми відвідали друга і куштували там лазанью.
Вона була неймовірна і мала в собі щось особливе.
Друг надіслав нам список інгредієнтів і сказав, що останній пункт у списку - це «секретний інгредієнт», який зробив страву такою особливою.
Тепер ми хочемо додати цей секретний інгредієнт і до свого рецепту.

Напишіть функцію `addSecretIngredient`, яка приймає два масиви інгредієнтів як параметри.
Перший параметр - список, який надіслав нам друг, а другий - список інгредієнтів для нашого власного рецепту.
Функція має додати останній елемент зі списку друга в кінець нашого списку.
Масив, який представляє наш рецепт, потрібно змінити безпосередньо, і функція не повинна нічого повертати.
Однак перший аргумент не можна змінювати.

```javascript
const friendsList = ['noodles', 'sauce', 'mozzarella', 'kampot pepper'];
const myList = ['noodles', 'meat', 'sauce', 'mozzarella'];

addSecretIngredient(friendsList, myList);
// => undefined

console.log(myList);
// => ['noodles', 'meat', 'sauce', 'mozzarella', 'kampot pepper']
```

## 5. Масштабуйте рецепт

Наведених у книзі рецептів кількостей вистачає лише на дві порції лазаньї.
Оскільки наступного разу ми хочемо приготувати для більшої кількості людей, потрібно обчислити кількості для різної кількості порцій.

Реалізуйте функцію `scaleRecipe`, яка приймає два параметри.

- Обʼєкт рецепту, який містить кількості, потрібні для 2 порцій.
  Формат обʼєкта можна побачити в прикладі нижче.
- Кількість порцій, яку ми хочемо приготувати.

Функція повинна повернути обʼєкт рецепту з кількостями, потрібними для бажаної кількості порцій.
Але ми хочемо зберегти початковий рецепт.
Це означає, що в цьому завданні аргумент рецепту не можна змінювати.

```javascript
const recipe = {
  noodles: 200,
  sauce: 0.5,
  mozzarella: 1,
  meat: 100,
};

scaleRecipe(recipe, 4);
// =>
// {
//   noodles: 400,
//   sauce: 1,
//   mozzarella: 2,
//   meat: 200,
// };

console.log(recipe);
// =>
// {
//   noodles: 200,
//   sauce: 0.5,
//   mozzarella: 1,
//   meat: 100,
// };
```
