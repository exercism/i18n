# Про

Статичне розширення дає змогу нібито розширювати наявні типи, не змінюючи їхній вихідний код. Для цього використовують інструкцію `using`. Статичні розширення можуть бути потужним інструментом, який дає змогу доповнювати типи, фактично їх не змінюючи.

```haxe
using Main.IntExtender;

class Main {
  public static function main() {
    trace(2.triple()); // 6
  }
}

class IntExtender {
  public static function triple(i:Int):Int {
    return i * 3;
  }
}
```
