# Довідка

[Символи][symbols] - це іменовані ідентифікатори, які можна використовувати для посилання на значення.
Символи створюються за допомогою символьного літерала: перед іменем ставимо двокрапку `:`, наприклад `:foo`.
Їх також можна записувати в лапках, наприклад `:"foo"`, що дає змогу, зокрема, використовувати пробіли в імені.

```crystal
:foo           # => :foo
:"foo boo"     # => :"foo boo"
:foo == :"foo" # => true
```

Символи використовуються в багатьох місцях мови, зокрема як ключі в NamedTuple і для позначення назв методів та змінних.

## Символи в Crystal

Символи в Crystal досить сильно відрізняються від символів у Ruby.
У Crystal символ - це різновид константи, а отже, він задається під час компіляції.
Це означає, що символи неможливо створити динамічно, а в Ruby це можливо.

Символи в Crystal подаються як `Int32`, що робить їх дуже ефективними.

## Перетворення

Символи можна перетворити на рядки тексту (англ. string), але не навпаки.
Це тому, що символи створюються під час компіляції, а рядки тексту створюються під час виконання.

```crystal
:foo.to_s # => "foo"
```
