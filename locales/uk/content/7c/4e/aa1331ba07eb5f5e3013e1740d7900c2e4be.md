# Докладніше

C# належить до мов зі статичною типізацією, а це означає, що кожна сутність має тип під час компіляції. Вибір імені для [змінної][variable] називають визначенням змінної. Після того як змінну визначено, встановлення чи оновлення її значення називають присвоєнням. Змінну можна визначити або явно вказавши її тип, або скориставшись [ключовим словом `var`][var], щоб компілятор C# вивів її тип на основі присвоєного значення. Використання `var` називають _виведенням типу_.

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

Значення змінної можна присвоїти й оновити за допомогою [оператора `=`][assignment]. Після визначення тип змінної вже не можна змінити.

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

C# належить до обʼєктно-орієнтованих мов, і вона вимагає, щоб усі [функції][function] були визначені в _класі_, а класи визначають за допомогою [ключового слова `class`][classes]. Обʼєкти (або _екземпляри_) створюють за допомогою ключового слова `new`.

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

Функцію всередині класу називають _методом_. Кожен [метод][methods] може мати нуль або більше параметрів. Усі параметри потрібно типізувати явно: для параметрів виведення типу не працює. Так само потрібно явно вказати тип поверненого значення. Значення повертають із методів за допомогою [ключового слова `return`][return]. Щоб метод можна було викликати з коду в інших файлах, потрібно додати модифікатор доступу `public`.

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

Методи викликають через крапку (`.`) на екземплярі: вказують назву методу, який потрібно викликати, і передають аргументи для кожного з параметрів методу. В аргументах за бажанням можна вказати назву відповідного параметра.

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

Якщо метод, який потрібно викликати, визначено в тому самому класі, що й метод, який його викликає, назву класу можна опустити.

Якщо метод не використовує жодного _стану_ обʼєкта, його можна зробити _статичним_ за допомогою модифікатора `static`. Статичні методи теж викликають через крапку (`.`), але не на екземплярі, а на самому класі.

Якщо клас має лише статичні методи, його також можна зробити статичним за допомогою модифікатора `static`. Так ми позначаємо призначення цього класу.

```csharp
static class Calculator
{
    public static int Multiply(int x, int y)
    {
        return x * y;
    }
}

Calculator.Multiply(2, 4); // => 8
```

Область видимості в C# визначається між символами `{` і `}`.

C# підтримує два типи [коментарів][comments]. Однорядкові коментарі починаються з `//`, а багаторядкові розміщують між `/*` і `*/`.

Цілі числа визначають як одну або більше (послідовних) цифр, і для них працюють [типові математичні оператори][operators].

Назва змінної [має відповідати певним правилам][identifier-names], наприклад починатися з літери або підкреслення, і [повинна дотримуватися угод іменування C#][naming-guidelines]. Якщо назва змінної збігається із зарезервованим [ключовим словом C#][csharp-keywords], її потрібно екранувати за допомогою `@`. Цю нотацію не рекомендується використовувати, але вона може траплятися у виняткових випадках, наприклад: `var @this`, `var @class` або `var @var`.

Є кілька понять, настільки фундаментальних для мови родини C, як C#, що вони природно виникають майже в будь-якому нетривіальному коді. Це [мутація][mutation] та [область видимості][scope]. Мутація означає, що значення змінної може змінюватися протягом часу виконання програми. Область видимості означає, що значення, повʼязане з іменем (елемента програми), доступне лише в тій «ділянці» коду, де його визначено. До основних ділянок коду в C# належать _клас/структура_ та _функція_ (зазвичай метод), але до них також можуть належати тіла циклів та інших конструкцій.
