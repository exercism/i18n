# Інструкції

Перетворіть описи дати доставки на _справжні_ дати доставки, залежно від того, коли почалася зустріч.

Є два типи описів дати доставки:

1. Фіксовані: наперед визначений набір слів.
2. Змінні: слова, що мають змінну складову, але відповідають наперед визначеному набору закономірностей.

## Фіксовані описи дати доставки

Є три фіксовані описи дати доставки:

- `"NOW"`
- `"ASAP"` (якнайшвидше)
- `"EOW"` (кінець тижня)

У наступній таблиці показано, як їх перекладати:

| Опис    | Початок зустрічі              | Дата доставки                       |
| ------- | ----------------------------- | ----------------------------------- |
| `"NOW"` | -                             | Дві години після початку зустрічі   |
| `"ASAP"`| До 13:00                      | Сьогодні о 17:00                    |
| `"ASAP"`| Після 13:00 або о 13:00       | Завтра о 13:00                      |
| `"EOW"` | Понеділок, вівторок або середа | Пʼятниця о 17:00                    |
| `"EOW"` | Четвер або пʼятниця           | Неділя о 20:00                      |

## Змінні описи дати доставки

Є дві закономірності для опису змінної дати доставки:

- `"<N>M"` (N-й місяць)
- `"Q<N>"` (N-й квартал)

| Опис     | Початок зустрічі               | Дата доставки                                              |
| -------- | ------------------------------ | ---------------------------------------------------------- |
| `"<N>M"` | До N-го місяця                 | О 8:00 у _перший_ робочий день N-го місяця цього року      |
| `"<N>M"` | Після N-го місяця або в ньому  | О 8:00 у _перший_ робочий день N-го місяця наступного року |
| `"Q<N>"` | До N-го кварталу або в ньому   | О 8:00 в _останній_ робочий день N-го кварталу цього року  |
| `"Q<N>"` | Після N-го кварталу            | О 8:00 в _останній_ робочий день N-го кварталу наступного року |

~~~~exercism/note
Робочий день - це понеділок, вівторок, середа, четвер або пʼятниця.

Рік має чотири квартали, у кожному з яких три місяці:
1. Січень/лютий/березень
2. Квітень/травень/червень
3. Липень/серпень/вересень
4. Жовтень/листопад/грудень.
~~~~
