# Доповнення до інструкцій

## Реалізація

Визначте одну функцію Go, `Cost`, яка обчислює вартість для заданого списку книжок на основі визначених знижок.

Використайте такий підпис для функції `Cost`:

```go
func Cost(books []int) int
```

`Cost` повертатиме загальну вартість (після знижок) у центах.
Наприклад, для однієї книжки вартість становить 800 центів, що дорівнює $8.00.
Для цієї вправи достатньо лише обчислень із цілими числами.
