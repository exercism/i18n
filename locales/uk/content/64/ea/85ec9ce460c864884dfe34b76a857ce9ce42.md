# Вступ

## Ключове слово `auto` у C++

У C++ ключове слово `auto`, яке додали в C++11, дає змогу оголошувати змінні з виведеним типом даних.
Компілятор виводить тип змінної на основі її ініціалізатора, завдяки чому код стає зрозумілішим і його легше супроводжувати.

## Приклад використання

Розглянемо приклад, у якому `auto` використано для оголошення змінних:

```cpp
auto dragon_population{3};          // dragon_population is deduced as an integer
auto westeros{7.7777};              // westeros is deduced as a double
auto wedding_location{"The Twins"}; // wedding_location is deduced as a const char*, not std::string
```

У кожному з цих випадків тип змінної виводиться зі значення, яким її ініціалізують.

## Виведення типу

Ключове слово `auto` допомагає писати стисліший і зрозуміліший код, зменшуючи багатослівність явних типів.

```cpp
const std::vector<std::string> pigeon_pie{"flour", "butter", "pigeon", "salt"};
auto purple_wedding_pie{pigeon_pie};
purple_wedding_pie.emplace_back("the strangler");
```

Тут `auto` виводить тип `purple_wedding_pie` як `std::vector<std::string>`, тож явно вказувати тип удруге вже не потрібно.

## Сумісність

Ключове слово `auto` сумісне з різними конструкціями C++, що робить його універсальним інструментом у сучасному програмуванні на C++.

```cpp
auto& element{array[0]};           // reference to an element
const auto object{otherObject};    // const type version of otherObject's type
auto* ptr{&x};                     // pointer to x with the same type as x, but as a pointer.
```

У наступних концепціях ми часто будемо бачити ключове слово `auto` поряд із лямбда-виразами, циклами `for` на основі діапазону та ітераторами.
