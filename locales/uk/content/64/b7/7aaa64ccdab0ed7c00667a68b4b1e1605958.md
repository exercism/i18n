# Вступ

## Випадковість

В Elixir, щоб вибрати випадковий елемент зі структури даних, яку можна перебирати (наприклад, масиву чи діапазону), ми використовуємо `Enum.random`. Ця функція вибирає один елемент, причому кожен елемент має однакову ймовірність бути вибраним.

Elixir не має власних функцій для вибору випадкового числа з плаваючою комою. Щоб це зробити, доводиться звертатися безпосередньо до Erlang.

## Бібліотеки Erlang

Код Elixir виконується на віртуальній машині BEAM. BEAM є частиною системи виконання Erlang. Натхненний Erlang і поділяючи з ним середовище виконання, Elixir забезпечує чудову взаємодію з бібліотеками Erlang. Це означає, що розробники Elixir можуть використовувати бібліотеки Erlang у своєму коді на Elixir. Насправді, писати бібліотеки Elixir для функціональності, яку вже надають бібліотеки Erlang, у спільноті Elixir не заохочують.

Як наслідок, певна функціональність, як-от математичні операції чи функції таймера, доступна в Elixir лише через Erlang.

Стандартна бібліотека Erlang доступна для використання в нашому коді Elixir без жодних додаткових кроків.

Функції Erlang можна викликати так само, як ми викликаємо функції Elixir, з однією невеликою відмінністю. Назви модулів Erlang записують як атоми в `snake_case`. Наприклад, щоб викликати функцію Erlang `pi/0` з модуля `math`, треба написати:

```elixir
:math.pi()
# => 3.141592653589793
```

Найпоширеніші функції Erlang, які не мають відповідника в Elixir:

- `:timer.sleep/1` призупиняє процес на задану кількість мілісекунд.
- `:rand.uniform/0` генерує випадкове число з плаваючою комою `x`, де `0.0 <= x < 1.0`.
- `:io_lib.format/2` забезпечує форматування рядків тексту (англ. string) у стилі C (за допомогою керівних послідовностей). За допомогою цієї функції ми могли б, наприклад, надрукувати ціле число в будь-якій системі числення від 2 до 36 або відформатувати число з плаваючою комою з потрібною точністю. Зауважмо, що ця функція, як і багато функцій Erlang, повертає charlist.
- Модуль `math`, який надає математичні функції, як-от `sin/1`, `cos/1`, `log2/1`, `log10/1`, `pow/2` та інші.

Щоб пізнати стандартну бібліотеку Erlang, перегляньте [Довідник STDLIB][erl-stdlib-ref].

[erl-stdlib-ref]: https://www.erlang.org/doc/apps/stdlib/index.html
