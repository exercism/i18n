# Доповнення до інструкцій

## Формат вихідних даних

Виведіть послідовність білків як рядок тексту (англ. string), завершений нульовим символом, із символом нового рядка після кожного білка.

Ось приклад вихідних даних: `"Methionine\nPhenylalanine\nSerine\n"`

Якщо вхідні дані неправильні, виведіть порожній рядок тексту.

## Регістри

| Регістр | Призначення            | Тип         | Опис                                                 |
| ------- | ---------------------- | ----------- | ---------------------------------------------------- |
| `$a0`   | вхідні дані            | адреса      | вхідний рядок тексту, завершений нульовим символом   |
| `$a1`   | вхідні та вихідні дані | адреса      | вихідний рядок тексту, завершений нульовим символом  |
| `$t0-9` | тимчасовий             | будь-який   | використовується для тимчасового зберігання          |
