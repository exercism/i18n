# Абстрактні класи

Циркова вистава складається з номерів. Жонглювання, трапеція й акробатика влаштовані по-різному, але тому, хто складає порядок виступів, потрібні від кожного лише дві речі: як він називається і скільки триває.

**Абстрактний клас** описує рівно стільки, і не більше.

```sather
abstract class $ACT is
   name : STR;
   minutes : INT;
end; -- abstract class $ACT
```

Його назва починається з `$`. Він перелічує підпрограми без тіл: лише сигнатури, кожна завершується крапкою з комою. З нього нічого не можна створити: немає ні `create`, ні `new`.

## Відповідність

Справжній клас обіцяє бути `$ACT`, указавши його після `<`:

```sather
class JUGGLING < $ACT is

   create : SAME is return new; end;

   name : STR is return "Juggling"; end;

   minutes : INT is return 5; end;

end; -- class JUGGLING
```

`<` читається як «є». Клас мусить надати кожну підпрограму, яку перелічує абстрактний клас, з тими самими аргументами і тим самим типом повернення. Якщо одну з них пропустити, це помилка компіляції, а не несподіванка під час виконання.

Клас може додати будь-що інше, що захоче. `TRAPEZE` може мати висоту, якої немає в жодного іншого номера; абстрактний клас про це ні знає, ні дбає.

## Використання типу

`$ACT` є типом, тож із ним можна оголосити будь-що:

```sather
   acts : ARRAY{$ACT} := |#JUGGLING, #TRAPEZE(4), #TUMBLING|;
```

Цей масив містить обʼєкти трьох різних класів одночасно, чого не міг би `ARRAY{JUGGLING}`.

## Диспетчеризація

```sather
   loop
      total := total + acts.elt!.minutes;
   end;
```

`acts.elt!` має тип `$ACT`. Який саме `minutes` виконається, вирішується тоді, коли виконується цей рядок, залежно від того, чим обʼєкт є насправді: `JUGGLING::minutes` для жонглювання, `TRAPEZE::minutes` для трапеції. Цей вибір називається **диспетчеризацією**.

Підпрограма, яка виконує додавання, ніколи не питає, який перед нею номер. Додати четвертий різновид номера означає написати один новий клас і більше нічого не змінювати, і саме заради цього все так і робиться.
