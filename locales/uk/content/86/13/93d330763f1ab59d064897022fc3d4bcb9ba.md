# Вступ

Більшість даних у Factor зберігається в *послідовностях*. Масиви, вектори й рядки тексту (англ. string) - це все послідовності, які спільно використовують набір слів зі словника [`sequences`][sequences].

## Літерали масивів

Літерал масиву записуємо за допомогою `{ }`, розділяючи елементи пробільними символами:

```factor
{ 1 2 3 } .          ! => { 1 2 3 }
{ "a" "b" "c" } .    ! => { "a" "b" "c" }
```

Масиви мають фіксовану довжину, тож такі слова, як `suffix` і `remove-nth` (вони змінюють кількість елементів), повертають *нову* послідовність, а не збільшують початкову.

## Довжина та індексація

```
length   ( seq -- n   )
first    ( seq -- elt )
rest     ( seq -- tailseq )    ! everything but the first element
last     ( seq -- elt )
but-last ( seq -- headseq )    ! everything but the last element
nth      ( n seq -- elt )      ! 0-based
?nth     ( n seq -- elt/f )    ! 0-based; f when out of bounds
```

```factor
{ 10 20 30 } length .       ! => 3
{ 10 20 30 } first .        ! => 10
{ 10 20 30 } rest .         ! => { 20 30 }
{ 10 20 30 } last .         ! => 30
{ 10 20 30 } but-last .     ! => { 10 20 }
1 { 10 20 30 } nth .        ! => 20
```

`?nth` працює безпечно щодо меж: можна взяти елемент за позицією, не перевіряючи спершу довжину.

```factor
1 { 10 20 30 } ?nth .       ! => 20
9 { 10 20 30 } ?nth .       ! => f  (out of bounds, no error)
```

## Зрізи

```
head ( seq n -- headseq )    ! first n elements
tail ( seq n -- tailseq )    ! drop first n
```

```factor
{ 1 2 3 4 5 } 3 head .   ! => { 1 2 3 }
{ 1 2 3 4 5 } 3 tail .   ! => { 4 5 }
```

Обидва слова викидають помилку, якщо `n` більше за довжину послідовності. Якщо `n` завелике, `index-or-length` зменшує його до довжини послідовності, тож наступний зріз не вийде за межі:

```
index-or-length ( seq n -- seq n' )
```

```factor
{ 10 20 30 40 50 } 3 index-or-length head .   ! => { 10 20 30 }
{ 10 20 } 3 index-or-length head .            ! => { 10 20 }
```

Варіанти із зірочкою `head*` і `tail*` рахують від кінця: `head*` відкидає останні `n` елементів, а `tail*` залишає останні `n`:

```
head* ( seq n -- headseq )   ! everything except the last n
tail* ( seq n -- tailseq )   ! the last n elements
```

```factor
{ 1 2 3 4 5 } 2 head* .   ! => { 1 2 3 }
{ 1 2 3 4 5 } 2 tail* .   ! => { 4 5 }
```

Для довільного зрізу між двома індексами `subseq` приймає *початок* (включно) та *кінець* (не включно):

```
subseq ( from to seq -- subseq )
```

```factor
1 4 { 10 20 30 40 50 } subseq .   ! => { 20 30 40 }
1 4 "hello" subseq .              ! => "ell"
```

Коли маємо *початок і довжину*, додаємо їх, щоб отримати кінець:

```factor
2 dup 3 + "hello world" subseq .  ! => "llo"
```

(Ідеться про діапазон індексів `[2, 5)`: три символи, починаючи з позиції 2.)

Обернене запитання, *де* трапляється підпослідовність, розв'язує `subseq-index`: він повертає початковий індекс першого збігу або `f`, якщо збігу немає:

```
subseq-index ( seq subseq -- i/f )
```

```factor
"hello world" "o w" subseq-index .   ! => 4
"hello world" "xyz" subseq-index .   ! => f
```

## Доповнення

```
pad-head ( seq n elt -- padded )    ! prepend copies of elt
pad-tail ( seq n elt -- padded )    ! append copies of elt
```

Обидва розширюють `seq`, доки його довжина не становитиме щонайменше `n`. Якщо `seq` уже такої довжини, його повертають без змін.

```factor
{ 2 5 0 } 6 0 pad-tail .   ! => { 2 5 0 0 0 0 }
{ 4 1 } 5 9 pad-head .     ! => { 9 9 9 4 1 }
```

## Ті самі слова працюють і з рядками тексту

Рядок тексту - це послідовність символів, тож усе описане вище працює і з рядками тексту. Результат буде просто іншим рядком тексту, а не масивом:

```factor
"hello" length .            ! => 5
"hello" 3 head .             ! => "hel"
"abc" 6 CHAR: . pad-tail .   ! => "abc..."
```

## Агрегування

`sum` і `product` (зі словника [`sequences`][sequences]) додають або множать елементи числової послідовності:

```factor
{ 2 5 0 7 } sum .        ! => 14
{ 2 5 3 7 } product .    ! => 210
```

`count` запускає предикат над послідовністю й повертає, скільки елементів йому відповідають:

```
count ( seq quot -- n )
```

```factor
{ 2 5 0 7 4 1 } [ even? ] count .    ! => 3
```

## Предикати над усією послідовністю

```
any?   ( seq quot -- ? )
all?   ( seq quot -- ? )
empty? ( seq -- ? )
```

```factor
{ 2 5 0 7 } [ 4 > ] any? .      ! => t
{ 2 5 0 7 } [ 0 > ] all? .      ! => f
```

## Побудова нової послідовності

`suffix` додає елемент у кінець послідовності; `prefix` додає елемент на початок. `unclip` відділяє перший елемент, а `unclip-last` - останній:

```
prefix      ( seq elt -- newseq )
suffix      ( seq elt -- newseq )
unclip      ( seq -- rest first )
unclip-last ( seq -- butlast last )
```

```factor
{ 7 9 } 3 prefix .             ! => { 3 7 9 }
{ 7 9 } 3 suffix .             ! => { 7 9 3 }
{ 4 0 9 } unclip .s
! => { 0 9 }
! => 4
```

Поєднання `unclip-last` і `suffix` дає недеструктивне оновлення останнього елемента (а `unclip` + `prefix` робить те саме для першого):

```factor
{ 10 20 30 } unclip-last 2 * suffix .
! => { 10 20 60 }
```

## Приведення між типами послідовностей

`>array`, `>vector` і `>string` (зі словника [`arrays`][arrays] та відповідних словників) приводять послідовність до конкретного типу. Це стає в пригоді, коли операція повернула зріз або узагальнену послідовність, а нам потрібен масив (або рядок тексту) назад.

```factor
{ 1 2 3 } 1 tail >array .   ! => { 2 3 }
"hello" >array .            ! => { 104 101 108 108 111 }
{ 65 66 67 } >string .      ! => "ABC"
```
