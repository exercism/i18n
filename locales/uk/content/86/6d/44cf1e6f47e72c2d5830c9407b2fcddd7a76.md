# Підказки

## Загальне

- Може стати в пригоді список усіх числових операцій у Lisp.
– повний список можна знайти [тут](http://www.lispworks.com/documentation/HyperSpec/Body/12_aa.htm)

## 1. Співвідношення тіста

- У Common Lisp є [вбудована константа](http://www.lispworks.com/documentation/HyperSpec/Body/v_pi.htm) для π (пі)
- Що стосується округлення, специфікація CL пропонує [низку функцій](http://www.lispworks.com/documentation/HyperSpec/Body/f_floorc.htm)

## 2. Трохи соусу

- Є [вбудований оператор](http://www.lispworks.com/documentation/HyperSpec/Body/f_sqrt_.htm), який може допомогти взяти квадратний корінь із числа

## 3. Трохи сиру, будь ласка

- Для піднесення числа до квадрата чи куба є [вбудована функція піднесення до степеня](http://www.lispworks.com/documentation/HyperSpec/Body/f_exp_e.htm)
- Можливо, варто поглянути на [цю сторінку операцій округлення](http://www.lispworks.com/documentation/HyperSpec/Body/f_floorc.htm) і розглянути деякі альтернативи `round`.

## 4. Справедлива частка

- Ця частина вимагає використати функцію, з якою ми, можливо, ще не стикалися, а саме [функцію остачі](https://en.wikipedia.org/wiki/Modulo_operation) (`mod`). Ця функція повертає остачу від ділення одного числа на інше.
- Щоб порівняти результат `mod` з іншим числом, [ця сторінка операторів порівняння](http://www.lispworks.com/documentation/HyperSpec/Body/f_eq_sle.htm).
