# Вступ

Протоколи - це механізм досягнення поліморфізму в Elixir, коли ми хочемо, щоб поведінка змінювалася залежно від типу даних.

Протоколи визначаються за допомогою `defprotocol` і містять один або кілька заголовків функцій.

```elixir
defprotocol Reversible do
  def reverse(term)
end
```

Протоколи можна реалізувати за допомогою `defimpl`.

```elixir
defimpl Reversible, for: List do
  def reverse(term) do
    Enum.reverse(term)
  end
end
```

Протокол можна реалізувати для будь-якого наявного типу даних Elixir або для структури.

Коли викликається функція протоколу, відповідна реалізація автоматично вибирається на основі типу першого аргументу.
