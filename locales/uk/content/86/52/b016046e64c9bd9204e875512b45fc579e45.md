# Інструкції

Салон краси в Нью-Йорку, з яким ми допомагали у вправі «Запис на красу», процвітає, і багато його клієнтів стали постійними.
Замість того щоб записуватися на кожен візит окремо, постійний клієнт має сталу домовленість: «кожен другий вівторок», «остання пʼятниця місяця» тощо.
Власниця попросила нас зробити помічник, який обчислює дати, що стоять за цими домовленостями, а також дати щомісячної рутини самого салону.

## 1. Знайти регулярний запис клієнта

Реалізуйте метод `SalonCalendar.standingAppointment()`, який приймає рік, місяць, номер повторення (`1` для першого, `2` для другого тощо) і день тижня.
Він повертає дату відповідного повторення цього дня тижня в межах місяця:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.standingAppointment(2024, Month.AUGUST, 2, DayOfWeek.TUESDAY);
// => LocalDate.of(2024, 8, 13)
```

## 2. Знайти останній у місяці запис клієнта

Деяким постійним клієнтам до вподоби останній такий день тижня в місяці.
Реалізуйте метод `SalonCalendar.lastAppointment()`, який приймає рік, місяць і день тижня та повертає дату останнього повторення цього дня тижня в межах місяця:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.lastAppointment(2024, Month.AUGUST, DayOfWeek.FRIDAY);
// => LocalDate.of(2024, 8, 30)
```

## 3. Знайти найближчий вільний день для клієнта без запису

Клієнт на рецепції просить «найближчу суботу».
Якщо день, у який він звертається, уже субота, то йдеться саме про цей день.
Реалізуйте метод `SalonCalendar.nextAvailable()`, який приймає дату й день тижня та повертає першу дату, що не раніше за задану і припадає на цей день тижня:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.nextAvailable(LocalDate.of(2024, 8, 15), DayOfWeek.SATURDAY);
// => LocalDate.of(2024, 8, 17)
calendar.nextAvailable(LocalDate.of(2024, 8, 17), DayOfWeek.SATURDAY);
// => LocalDate.of(2024, 8, 17)
```

## 4. Знайти день закриття обліку

Салон закриває облік в останній день кожного місяця.
Проте на вихідних салон не працює, тож якщо останній день місяця припадає на суботу чи неділю, облік закривають у пʼятницю перед цим.
Реалізуйте метод `SalonCalendar.bookkeepingDay()`, який приймає рік і місяць та повертає день закриття обліку в цьому місяці:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.bookkeepingDay(2024, Month.SEPTEMBER);
// => LocalDate.of(2024, 9, 30)
calendar.bookkeepingDay(2024, Month.AUGUST);
// => LocalDate.of(2024, 8, 30)
```

## 5. Використати правило вихідних ще й для зарплати

Працівники отримують зарплату 15-го числа кожного місяця, і діє те саме правило вихідних: коли 15-те припадає на суботу чи неділю, зарплату виплачують у пʼятницю перед цим.
Замість того щоб писати це правило вдруге, зробімо з нього повторно використовуваний коригувальник.

Реалізуйте метод `SalonCalendar.precedingWorkday()`, який повертає `TemporalAdjuster`: він залишає будній день без змін, а суботу чи неділю переносить на попередню пʼятницю.
Потім реалізуйте метод `SalonCalendar.payday()`, який приймає рік і місяць, використовуючи цей коригувальник:

```java
SalonCalendar calendar = new SalonCalendar();
LocalDate.of(2024, 6, 15).with(calendar.precedingWorkday());
// => LocalDate.of(2024, 6, 14)
calendar.payday(2024, Month.JUNE);
// => LocalDate.of(2024, 6, 14)
calendar.payday(2024, Month.AUGUST);
// => LocalDate.of(2024, 8, 15)
```

Цілком можна повернутися й використати коригувальник так само і в `bookkeepingDay()`.
