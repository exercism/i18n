# Інструкції

У цій вправі ми працюватимемо над планувальником записів для салону краси в Нью-Йорку, який відкрився 15 вересня 2012 року.

У нас є чотири завдання, і всі вони стосуватимуться дат записів. Дати та час використовуватимуть один із трьох наведених форматів:

- `"7/25/2019 13:45:00"`
- `"July 25, 2019 13:45:00"`
- `"Thursday, July 25, 2019 13:45:00"`

Тести автоматично встановлюють культуру `en-US`, тож нам не потрібно самостійно встановлювати чи вказувати культуру.

## 1. Розібрати дату запису

Реалізуйте (_static_) метод `Appointment.Schedule()`, який розбирає текстове представлення дати запису у відповідний формат `DateTime`:

```csharp
Appointment.Schedule("7/25/2019 13:45:00")
// => new DateTime(2019, 7, 25, 13, 45, 0)
```

## 2. Перевірити, чи вже минув запис

Реалізуйте (_static_) метод `Appointment.HasPassed()`, який приймає дату запису та перевіряє, чи запис уже минув:

```csharp
Appointment.HasPassed(new DateTime(1999, 12, 31, 9, 0, 0))
// => true
```

## 3. Перевірити, чи припадає запис на другу половину дня

Реалізуйте (_static_) метод `Appointment.IsAfternoonAppointment()`, який приймає дату запису та перевіряє, чи припадає запис на другу половину дня (>= 12:00 та < 18:00):

```csharp
Appointment.IsAfternoonAppointment(new DateTime(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. Описати час і дату запису

Реалізуйте (_static_) метод `Appointment.Description()`, який приймає дату запису та повертає опис цієї дати й часу:

```csharp
Appointment.Description(new DateTime(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on 3/29/2019 3:00:00 PM."
```

## 5. Повернути дату річниці

Реалізуйте (_static_) метод `Appointment.AnniversaryDate()`, який повертає дату річниці цього року, а саме 15 вересня:

```csharp
Appointment.AnniversaryDate()
// => new DateTime(2019, 9, 15, 0, 0, 0)
```
