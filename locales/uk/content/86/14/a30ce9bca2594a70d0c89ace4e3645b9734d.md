# Додаток до інструкцій

## Підказки

Потрібно реалізувати функцію `rotate`, яка приймає `Int` і `String`, а потім кодує його за допомогою ротаційного шифру.
Можна скористатися наданою сигнатурою, якщо є сумніви щодо типів, але не варто дозволяти їй обмежувати творчість.

Ця вправа працює з текстовими даними. З історичних причин тип `String` у Haskell
є синонімом до `[Char]`, списку символів. Для ефективнішої роботи з текстовими
даними можна використовувати тип `Text`.

Як необовʼязкове розширення до цієї вправи можна:

- прочитати про [типи рядків](https://haskell-lang.org/tutorial/string-types) у
  Haskell.
- додати `- text` до списку залежностей у package.yaml.
- імпортувати `Data.Text` [у такий
  спосіб](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- використовувати тип `Text`, наприклад `rotate :: Int -> Text -> Text`, і звертатися
  до комбінаторів `Data.Text` як, наприклад, `T.pack`.
- знайти документацію для
  [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html).
- замінити всі входження `String` на `Text` у RotationalCipher.hs, тобто:

```haskell
rotate :: Int -> Text -> Text
```

Ця частина цілком необовʼязкова.
