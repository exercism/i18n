# Тести

Щоб запустити тести, потрібно зібрати й запустити файл запуску тестів для потрібної вправи: або через графічний інтерфейс симулятора MARS, або з командного рядка. Щоб запустити з командного рядка, вкажімо спочатку файл запуску, а потім свою реалізацію, ось так:

    java -jar /path/to/mars.jar nc runner.mips impl.mips

Щоб запустити в графічному інтерфейсі, додаймо в кінець «runner.mips» директиву `include` зі своєю реалізацією, розкоментувавши останній рядок.

Засіб запуску тестів або завершить роботу повідомленням «success», або зупиниться на невдалому тесті з повідомленням, у якому буде вказано вхідні дані, для яких цей тест не пройшов.
