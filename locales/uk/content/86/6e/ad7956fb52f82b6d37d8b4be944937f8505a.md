# Докладніше

У Common Lisp час подається трьома способами

- Універсальний час - це абсолютний час, ціле число, що позначає кількість секунд від `1900-01-01T00:00:00Z` (тобто від опівночі 1 січня 1900 року за UTC).
- Декодований час - це кортеж із 9 значень, які разом описують конкретний календарний час: секунди, хвилини, годину, день місяця, місяць, рік, день тижня, прапорець переходу на літній час, часовий пояс.
(Докладніше про це йдеться нижче.)
- Внутрішній час - це додатне ціле число у «внутрішніх одиницях часу», визначених реалізацією, які можна використовувати для вимірювання часу виконання.

## Універсальний час

Щоб отримати поточний універсальний час, використовують `get-universal-time` або `get-decoded-time`.
Перша функція повертає кількість секунд, що минули від `1900-01-01T00:00Z`, а друга повертає ті самі дані в декодованому форматі.

Зауважмо, що оскільки це число додатне, закодувати дати раніше 1900 року неможливо.

## Декодований час

`decode-universal-time` та `encode-universal-time` - це основні функції для роботи з часом.
Перша приймає універсальний час і повертає декодоване значення часу як [множинні значення][concept-multiple-values], а друга приймає декодовані значення часу як аргументи й повертає універсальний час.

Обидві приймають необовʼязковий аргумент часового поясу.
Формат часового поясу описано нижче.

Декодований час - це набір значень:

- *секунди*: ціле число від 0 до 59
- *хвилини*: ціле число від 0 до 59
- *година*: ціле число від 0 до 23
- *день місяця*: ціле число від 1 до 31 (верхня межа, звісно, залежить від місяця й року)
- *місяць*: ціле число від 1 до 12
- *рік*: ціле число, що позначає рік.
- *день тижня*: ціле число від 0 до 6. 0 означає понеділок, 1 означає вівторок і так далі ... 6 означає неділю.
- *прапорець переходу на літній час*: значення «правда» означає, що літній час увімкнено.
- *часовий пояс*: кількість годин від -24 до 24, що позначає зсув від UTC.
Це раціональне число, і воно має бути кратним `1/3600`

```lisp
(encode-universal-time 1 2 3 4 5 2000 0) ; => 3166398121
(decode-universal-time 3166398121 0)     ; => 1
                                         ;    2
                                         ;    3
                                         ;    4
                                         ;    5
                                         ;    2000
                                         ;    3 (Thursday)
                                         ;    NIL
                                         ;    0
(decode-universal-time 2208988800 0)     ; => 0
                                         ;    0
                                         ;    0
                                         ;    1
                                         ;    1
                                         ;    1970
                                         ;    3
                                         ;    NIL
                                         ;    0
```

Зауважмо, що коли параметр часового поясу не вказано, поведінка буває цікавою.
Докладніше дивіться в документації для [`decode-universal-time`][hyperspec-decode-universal-time] та [`encode-universal-time`][hyperspec-encode-universal-time].

## Внутрішній час

Внутрішній час - це додатне ціле число «внутрішніх одиниць часу». Різницю між двома такими значеннями можна використати, щоб виміряти час під час виконання.

- `get-internal-real-time` повертає поточний «реальний» або «часовий» час.
- `get-internal-run-time` дуже залежить від реалізації й може включати або не включати, наприклад, час, витрачений на посторінковий обмін чи збирання сміття.

Змінна `internal-time-units-per-second` містить значення, яке дорівнює кількості «внутрішніх одиниць часу» за секунду в поточному середовищі Lisp.
