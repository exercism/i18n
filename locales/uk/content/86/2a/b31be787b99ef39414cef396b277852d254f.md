# Навчання

Coq - це система керування формальними доведеннями. Вона надає формальну мову для запису математичних означень, виконуваних алгоритмів і теорем, а також середовище для напівінтерактивної розробки доведень із машинною перевіркою.

Є кілька безкоштовних ресурсів для вивчення Coq, як-от:

* Серія Software Foundations:
    + [Volume 1: Logical Foundations](https://softwarefoundations.cis.upenn.edu/lf-current/index.html)
    + [Volume 2: Programming Language Foundations](https://softwarefoundations.cis.upenn.edu/plf-current/index.html)
    + [Volume 3: Verified Functional Algorithms](https://softwarefoundations.cis.upenn.edu/vfa-current/index.html)
* Certified Programming with Dependent Types:
    + Яка безкоштовно доступна на [сайті Адама Чіпали](http://adam.chlipala.net/cpdt/).
