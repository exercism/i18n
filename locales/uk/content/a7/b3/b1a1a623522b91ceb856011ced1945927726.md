# Докладніше

У JavaScript є оператори інкременту та декременту.
Вони змінюють змінну безпосередньо.
`++` додає одиницю до числа, `--` віднімає одиницю від числа.

```javascript
let i = 3;
i++;
// i is now 4

let j = 0;
j--;
// j is now -1
```

У прикладі вище показано постфіксний оператор інкременту/декременту.
У цьому випадку оператор стоїть після змінної, а поверненим значенням виразу є значення змінної _до_ збільшення/зменшення.

```javascript
let a = 3;
let b = a++;
// a = 4
// b = 3
```

Існує також префіксна форма, у якій оператор стоїть перед змінною.
Тоді поверненим значенням буде значення змінної _після_ збільшення/зменшення.

```javascript
let a = 3;
let b = ++a;
// a = 4
// b = 4
```
