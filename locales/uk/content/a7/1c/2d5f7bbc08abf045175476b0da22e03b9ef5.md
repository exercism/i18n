# Інструкції

Люсі, інопланетянка з Lisp, любить числа, вона вважає деякі з них «чудовими».

Вона просить нас допомогти їй написати функції, щоб зробити числа ще чудовішими.

Те, що, на думку Люсі, робить число чудовим, може змінюватися, тож функції мають бути гнучкими.

## 1. Зробити чудовими

Щоб перетворити список чисел на список більш чудових чисел, напишіть функцію `make-magnificent-maybe`, яка приймає функцію для застосування до чисел і список чисел.
Вона має обчислюватися в список чисел, які є більш чудовими (відповідно до наданої функції).

```lisp
(make-magnificent-maybe #'square '(1 2 3)) ; => (1 4 9)
(make-magnificent-maybe #'1+ '(1 2 3))     ; => (2 3 4)
```

## 2. Лише найкращі

Після того як (сподіваємося) числа стали більш чудовими, Люсі хоче побачити лише ті числа, які справді чудові.

Вона точно знає, що 1 *ніколи* не буває чудовим, тож це потрібно просто прибрати.

Але крім цього, Люсі іноді змінює свою думку, тож вона знову дасть нам функцію, яка скаже, чудове число чи ні.

Напишіть функцію `only-the-best`, яка приймає функцію та список чисел і повертає лише найкращі числа (не `1` і не числа, для яких функція дає правду).

```lisp
(only-the-best #'evenp '(1 2 3 4 5)) ; => (3 5)
(only-the-best #'oddp '(1 3 5))    ; => ()
```
