# Вступ

## Успадкування

Успадкування - основний концепт ООП (обʼєктно-орієнтованого програмування).
Воно описує відношення IS-A.
У програмуванні воно означає буквально те саме, що й в англійській мові: успадкування характеристик від батьківського класу (у програмуванні такими характеристиками зазвичай є функції та змінні).

Розглянемо клас `Animal`, як показано нижче:

```java
//Creating an Animal class with bark() as a member function.
public class Animal {

    public void bark() {
        System.out.println("This is an animal");
    }

}
```

`Animal` - батьківський клас, тому що властивості, які має цей клас, можна поширити на всіх тварин загалом.

Розглянемо тварину на імʼя `Lion`, яка має такий клас:

```java
//Lion class is a child class of Animal.
public class Lion extends Animal {

    @Override
    public void bark() {
        System.out.println("Lion here!!");
    }

}
```

~~~~exercism/note
Анотація `Override` вказує, що метод у підкласі перевизначає метод свого суперкласу.
Це не обовʼязково, але вважається найкращою практикою.
~~~~

Тепер, коли ми робимо так:

```java
Animal animal = new Lion(); //creating instance of Animal, of type Lion
animal.bark();
```

Зауваження: ініціалізація класу `Animal` обʼєктом `Lion`.
Виведення матиме такий вигляд:

```java
Lion here!!
```

Згідно з ООП, існує багато типів успадкування, але Java підтримує лише деякі з них (багаторівневе та ієрархічне).
Щоб дізнатися більше, прочитайте [цю статтю][java-inheritance].
