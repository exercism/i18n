# Інструкції

У цій вправі ми будемо працювати з рядками логу.

Кожен рядок логу — це рядок тексту (англ. string) у такому форматі: `"[<LEVEL>]: <MESSAGE>"`.

Існує три різні рівні логування:

- `INFO`
- `WARNING`
- `ERROR`

На нас чекають три завдання, і кожне з них приймає рядок логу та пропонує щось із ним зробити.

## 1. Отримати повідомлення з рядка логу

Реалізуйте функцію `message`, яка повертає повідомлення з рядка логу:

```fsharp
message "[ERROR]: Invalid operation"
// => "Invalid operation"
```

Пробіли на початку та в кінці треба прибрати:

```fsharp
message "[WARNING]:  Disk almost full\r\n"
// => "Disk almost full"
```

## 2. Отримати рівень логування з рядка логу

Реалізуйте функцію `logLevel`, яка повертає рівень логування з рядка логу; рівень має бути в нижньому регістрі:

```fsharp
logLevel "[ERROR]: Invalid operation"
// => "error"
```

## 3. Переформатувати рядок логу

Реалізуйте функцію `reformat`, яка переформатовує рядок логу, ставлячи повідомлення першим, а рівень логування після нього в дужках:

```fsharp
reformat "[INFO]: Operation completed"
// => "Operation completed (info)"
```
