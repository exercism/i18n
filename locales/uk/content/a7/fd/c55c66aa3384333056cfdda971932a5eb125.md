# Підказки

## Загальні

- `case` (у [`combinators`][combinators]) підходить для зіставлення за рівними значеннями, а `cond` для предикатів із перевірками.
- Символи (`yes`, `no`, `maybe`, `korean`, …) уже оголошені через `SYMBOLS:` у файлі вправи.

## 1. Оцініть кухню

- `case` із двома гілками, що зіставляє `korean` і `turkish` з їхніми значеннями схвалення.

## 2. Оцініть жанр фільму

- Зіставте `romance` і поставте типове значення `[ drop no ]` для решти. Памʼятайте: типова гілка бачить початкове значення на вершині, тож скиньте його, перш ніж покласти результат.

## 3. Оцініть прогулянку

- Використайте `cond` (також у `combinators`): кожна перевірка має вигляд `[ dup N > ]`. Тіло має застосувати `drop` до кілометрів, перш ніж покласти схвалення.

## 4. Оцініть активність

- Активність має вигляд `{ tag value }`. Використайте `first2`, щоб покласти обидва значення в стек, потім `swap`, щоб тег опинився на вершині; саме з цим і зіставляється `case`.
- Гілки для `board-game` і `chill` бачать значення (`f`), яке все ще лежить на стеку; застосуйте `drop` до нього, перш ніж покласти схвалення.
- Гілки для `movie`, `restaurant` і `walk` бачать відповідне значення все ще на стеку, тож можна викликати слово із завдання 2/1/3 безпосередньо.
