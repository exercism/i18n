# Вказівки

Ми розробляємо власну рольову відеогру. У нашій грі є _персонажі_ та _предмети_. Одна з багатьох дій, які можна виконати з предметом, - змусити персонажа зʼїсти його.

Не всі предмети їстівні, і не всі їстівні предмети однаково впливають на персонажа. Деякі предмети, коли їх зʼїсти, перетворюються на інший предмет (наприклад, якщо зʼїсти яблуко, залишається огризок).

Щоб забезпечити всю цю гнучкість, ми вирішили створити протокол `Edible`, який можуть реалізувати деякі з предметів.

## 1. Визначте їстівність

Створіть протокол `RPG.Edible`. Протокол має одну функцію - `eat`. Функція `eat` приймає предмет і персонажа та повертає побічний продукт і персонажа.

## 2. Зробіть буханці хліба їстівними

Реалізуйте протокол `RPG.Edible` для предмета `RPG.LoafOfBread`. Коли його зʼїсти, буханець хліба дає персонажу 5 одиниць здоровʼя і не має побічного продукту.

```elixir
RPG.Edible.eat(%RPG.LoafOfBread{}, %RPG.Character{health: 31})
# => {nil, %RPG.Character{health: 36, mana: 0}}
```

## 3. Зробіть зілля мани їстівними

Реалізуйте протокол `RPG.Edible` для предмета `RPG.ManaPotion`. Коли його зʼїсти, зілля мани дає персонажу стільки одиниць мани, скільки становить сила зілля, і створює порожню пляшечку.

```elixir
RPG.Edible.eat(%RPG.ManaPotion{strength: 13}, %RPG.Character{mana: 50})
# => {%RPG.EmptyBottle{}, %RPG.Character{health: 100, mana: 63}}
```

## 4. Зробіть отрути їстівними

Реалізуйте протокол `RPG.Edible` для предмета `RPG.Poison`. Коли його зʼїсти, отрута забирає в персонажа всі одиниці здоровʼя і створює порожню пляшечку.

```elixir
RPG.Edible.eat(%RPG.Poison{}, %RPG.Character{health: 3000})
# => {%RPG.EmptyBottle{}, %RPG.Character{health: 0, mana: 0}}
```
