# Вступ

## Функції

Ми можемо визначати **власні функції** у `jq`, щоб інкапсулювати будь-яку логіку, яка нам потрібна.
_Функції_ поводяться так само, як вбудовані: вони приймають вхідні дані й видають нуль, одні або кілька вихідних даних.

### Визначення функції

Ми можемо визначити _функцію_ `jq` за таким синтаксисом:

```jq
# no arguments
def funcname: expression;

# or with arguments
def funcname(args): expression;
```

- починається з ключового слова `def`,
- двокрапка перед тілом функції,
- тіло складається з одного виразу,
- закінчується крапкою з комою,
- як і решта синтаксису `jq`, ми можемо використовувати довільні пробіли для читабельності.

### Де розміщувати функції

_Функції_ потрібно визначити до того, як ми їх використаємо: ось це помилка:

```jq
def A: B(10);
def B(n): n + 1;
A
# => error: B/1 is not defined
```

Це означає, що _функції_ треба розмістити на початку нашого коду `jq`, перед «головним» виразом.

#### Вкладені функції

_Функції_ можна вкладати:

```jq
def A:
    def B(n): n + 1;
    B(10)
    ;
A
# => 11
```

Тут _функція_ `B` видима лише в тілі `A`.

### Область видимості

_Функція_ вводить нову **область видимості** для змінних і вкладених функцій.

### Аргументи

**Аргументи** _функції_ розділяються _крапками з комою_, а не комами.
Наприклад, _функція_, яка приймає число, а потім додає число і множить на число:

```jq
def add_mul(adder; multiplier): (. + adder) * multiplier;

10 | add_mul(5; 4)    # => 60
```

```jq
10 | add_mul(5, 4)
```

#### Аргументи - це _вирази_

_Аргументи_ функції - це фільтри, а не значення.
У цьому сенсі вони поводяться як те, що в інших мовах називають колбеками:

Візьмімо функцію `add_mul` як приклад:

```jq
10 | add_mul(. + 5; . - 2)    # => 200
```

Що тут відбувається?

- аргумент `adder` отримує _вираз_ `. + 5`
  - коли функція виконує `. + adder`, це стає `. + . + 5`
  - це дає 25, оскільки `. == 10`
- так само аргумент `multiplier` - це вираз `. - 2`
  - це дає 8
  - тоді результат - `25 * 8 == 200`

#### Аргументи як значення

Іноді нам захочеться «матеріалізувати» _аргумент_ у змінну:

```jq
def my_func(arg):
    arg as $arg
    | other stuff ...
;
```

Для цього є скорочений запис:

```jq
def my_func($arg):
    other stuff ...
;
```

Зауважмо, що це лише «синтаксичний цукор»: імʼя `arg` без `$` усе ще перебуває в області видимості _функції_.

### Арність

_Функції_ мають **арність**, тобто кількість _аргументів_, які вони приймають.

_Функції_ можуть використовувати однакове імʼя з різною _арністю_.
Вбудована функція [`range`][man-range] демонструє це: `range/1`, `range/2` і `range/3` співіснують.

Це може стати в нагоді для визначення рекурсивних функцій, які переносять стан через аргументи.
Наприклад, `map` _можна_ було б реалізувати так:

```jq
def my_map($accumulator; func):
    if length == 0
        then $accumulator
        else first as $elem | .[1:] | my_map($accumulator + [$elem | func]; func)
    end
    ;

def my_map(func):
    my_map([]; func)
    ;

[1, 2, 3, 4] | my_map(. * 10)   # => [10, 20, 30, 40]
```

### Рекурсія

`jq` виконує оптимізацію хвостових викликів, але лише для функцій з арністю 0.

### Модулі

Модуль `jq` - це файл, що містить лише функції.
Модулі підключаються до програми jq командами [`include`][man-include] або [`import`][man-import].
