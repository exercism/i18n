# Інструкції

У цій вправі ми граємо з другом у гру на вгадування чисел. Правила прості: ми потай загадуємо число від `1` до `100`, а наш друг намагається вгадати, яке число ми загадали. Щоб допомогти другові, ми відповідаємо по-різному залежно від того, наскільки близьким було припущення до загаданого числа (`42`). Ось правила для різних відповідей:

- Якщо припущення `42`: «Correct»
- Якщо припущення `41` або `43`: «So close»
- Якщо припущення менше за `41`: «Too low»
- Якщо припущення більше за `43`: «Too high»

На нас чекають чотири завдання, у яких ми закодуємо відповіді на припущення.

## 1. Відповідь на правильне припущення

Реалізуйте функцію `reply`, щоб вона відповідала на правильне припущення:

```gleam
reply(42)
// -> "Correct"
```

## 2. Відповідь на близьке припущення

Змініть функцію `reply`, щоб вона відповідала на близькі припущення:

```gleam
reply(41)
// -> "So close"
```

## 3. Відповідь на занизьке припущення

Змініть функцію `reply`, щоб вона відповідала на занизькі припущення:

```gleam
reply(25)
// -> "Too low"
```

## 4. Відповідь на зависоке припущення

Змініть функцію `reply`, щоб вона відповідала на зависокі припущення:

```gleam
reply(88)
// -> "Too high"
```
