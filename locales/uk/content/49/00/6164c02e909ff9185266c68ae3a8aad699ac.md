# Instructions

Озан збирає плейлист для майбутньої подорожі. Він не хоче чути той самий трек більше ніж один раз, але плейлист став таким довгим, що йому вже важко згадати, які треки вже додані.

API музичного плеєра Озана вміє працювати лише з масивами, тож він намагається написати код, який використовує `Array.indexOf()`, щоб перевірити наявність треку перед тим як додати його до плейлиста. На жаль, його програма виконується надто довго. Йому потрібна наша допомога!

Прийшовши на допомогу Озанові, ми з подивом виявляємо, що його плейлист містить _пів мільйона_ треків. Можливо, ми знаємо іншу структуру даних, яка дозволить ефективніше працювати з плейлистом?

## 1. Видалити дублікати треків

Реалізуйте функцію `removeDuplicates`, яка приймає плейлист як _параметр_ і _повертає_ новий плейлист, у якому всі треки унікальні.

```javascript
const playlist = [
  'Court and Spark - Joni Mitchell',
  'Big Yellow Taxi - Joni Mitchell',
  'Court and Spark - Joni Mitchell',
];

removeDuplicates(playlist);
//=> ['Court and Spark - Joni Mitchell', 'Big Yellow Taxi - Joni Mitchell']
```

## 2. Перевірити, чи трек уже додано

Реалізуйте функцію `hasTrack`, яка приймає плейлист і трек як _параметри_ і _повертає_ булеве значення (англ. Boolean), яке вказує, чи містить плейлист цей трек.

```javascript
const playlist = [
  'The Fashion Show - Grace Jones',
  'Dr. Funkenstein - Parliament',
];

hasTrack(playlist, 'Dr. Funkenstein - Parliament');
//=> true

hasTrack(playlist, 'Walking in the Rain - Grace Jones');
//=> false
```

## 3. Додати трек

Реалізуйте функцію `addTrack`, яка приймає плейлист і трек як _параметри_ і _повертає_ новий плейлист, що містить цей трек.

```javascript
const playlist = ['Selma - Bijelo Dugme'];

addTrack(playlist, 'Atomic Dog - George Clinton');
//=> ['Selma - Bijelo Dugme', 'Atomic Dog - George Clinton']

addTrack(playlist, 'Selma - Bijelo Dugme');
//=> ['Selma - Bijelo Dugme', 'Atomic Dog - George Clinton']
```

## 4. Видалити трек

Реалізуйте функцію `deleteTrack`, яка приймає плейлист і трек як _параметри_ і _повертає_ новий плейлист, який не містить цього треку.

```javascript
const playlist = [
  'The Treasure - Fra Lippo Lippi',
  'After the Fall - Klaus Nomi',
];

deleteTrack(playlist, 'The Treasure - Fra Lippo Lippi');
//=> ['After the Fall - Klaus Nomi']

deleteTrack(playlist, 'I Feel the Magic - Belinda Carlisle');
//=> ['After the Fall - Klaus Nomi']
```

## 5. Вивести унікальних виконавців

Реалізуйте функцію `listArtists`, яка приймає плейлист як _параметр_ і _повертає_ масив унікальних виконавців у плейлисті. Зауважте, що назви треків мають формат `<SONG> - <ARTIST>`.

```javascript
const playlist = [
  'All Mine - Portishead',
  'Sight to Behold - Devendra Banhart',
  'Sour Times - Portishead',
];

listArtists(playlist);
//=> ['Portishead', 'Devendra Banhart']
```
