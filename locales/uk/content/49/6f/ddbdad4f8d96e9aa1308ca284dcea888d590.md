# Докладніше

Factor зосереджує всю випадковість у словнику [`random`][random] навколо одного узагальненого слова:

```
random ( obj -- elt )
```

Воно обирає дію залежно від свого аргументу:

- **ціле число** `n` дає випадкове ціле число з проміжку `[0, n)`;
- **послідовність** дає випадковий елемент;
- асоціативні масиви, геш-множини та кортежі `uniform-distribution` теж
  підтримуються.

На ньому побудовано два допоміжні слова для послідовностей:

```factor
USING: random ;

{ 1 2 3 4 5 } randomize .   ! shuffle in place (Fisher–Yates)
{ 1 2 3 4 5 } 3 sample .    ! 3 distinct elements; error if too many
```

`randomize` змінює послідовність і повертає її, тож якщо потрібно зберегти
початковий порядок, спершу варто викликати `clone`.

## Звідки береться випадковість

`random` читає генератор, що міститься в динамічній змінній
`random-generator`. Типово це вихор Мерсенна, ініціалізований від системного
годинника, тож у кожному процесі він різний. Можна встановити інший генератор
на час динамічної дії квотейшена:

```
<mersenne-twister> ( seed -- rnd )
with-random        ( rnd quot -- )
```

```factor
USING: random random.mersenne-twister ;

42 <mersenne-twister> [ { 1 2 3 } randomize ] with-random .
! => the same ordering on every run
```

Оскільки `with-random` лише звʼязує `random-generator` на час динамічної дії
квотейшена, слово, що його обгортає, слід позначити `inline`, щоб квотейшен міг
залишити свій результат на стеку для того, хто його викликав.

Крім цього, `random` пропонує `random-bits`, `random-unit`,
`uniform-random` і `normal-random` для інших розподілів, а також
`system-random-generator` і `secure-random-generator` для
невідтворюваних і криптографічних потреб.

[random]: https://docs.factorcode.org/content/vocab-random.html
