# Інструкції

У цій вправі ми змоделюємо машину для зважування.

## 1. Створіть початковий стан для машини для зважування

Під час ініціалізації машина для зважування має орієнтуватися на заводські налаштування, які відрізняються залежно від того, де цю машину продають.
Тож машину має бути можливо ініціалізувати із заданою точністю та вказівкою, чи використовувати метричну систему, чи імперську.

Реалізуйте метод `WeighingMachine#initialize`, який приймає два аргументи: `precision` типу `Int32` і `metric` типу `Bool`.
Аргумент `metric` зі значенням `true` означає, що машина має використовувати метричну систему, інакше вона має використовувати імперську.
Метод `initialize` також має встановити значення змінної екземпляра `@weight` рівним `0.0`.

```crystal
precision = 3
metric = true
vm = WeighingMachine.new(precision, metric)
```

## 2. Дозвольте задавати точність машини для зважування

Щоб задовольнити різні потреби, кожну машину для зважування можна налаштувати з певною точністю (кількістю цифр після десяткового розділювача).

Реалізуйте метод-гетер `WeighingMachine#precision`, який повертає точність машини для зважування.

```crystal
precision = 3
metric = true
vm = WeighingMachine.new(precision, metric)
vm.precision
# => 3
```

## 3. Дозвольте встановлювати вагу на машині для зважування

Реалізуйте властивість `WeighingMachine#weight`, щоб вагу можна було і читати, _і_ встановлювати:

```crystal
precision = 3
metric = true
wm = WeighingMachine.new(precision, metric)
wm.weight = 60.5
wm.weight
# => 60.5

wm.weigh
# => 60.5
```

## 4. Дозвольте перемикати машину між метричною та імперською системами одиниць

Реалізуйте властивість `WeighingMachine#metric=`, щоб можна було змінювати одиниці вимірювання.
Вона має приймати булеве значення (англ. Boolean).

```crystal
precision = 3
metric = true
wm = WeighingMachine.new(precision, metric)
vm.weight = 60.5
wm.metric = false

vm.weigh
# => 133.377
```
