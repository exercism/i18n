# Інструкції

Перетворіть двійкове число, подане як рядок тексту (англ. string), наприклад «101010», на його десятковий еквівалент, виходячи з базових принципів.

Реалізуйте перетворення двійкового числа на десяткове. Отримавши на вході двійковий рядок тексту, програма має видати десяткове число. Програма має вміти обробляти некоректні вхідні дані.

## Примітка

- Реалізуйте перетворення самостійно.
  Не використовуйте щось інше, щоб виконати перетворення за вас.

## Про двійкову систему (основа 2)

Десяткова система має основу 10.

Число 23 в десятковому записі можна подати як лінійну комбінацію степенів числа 10:

- Найправіша цифра множиться на 10^0 = 1
- Наступна цифра множиться на 10^1 = 10
- ...
- *n*-та цифра множиться на 10^_(n-1)_.
- Усі ці значення додаються.

Отже: `23 => 2*10^1 + 3*10^0 => 2*10 + 3*1 = 23 base 10`

Двійкова система схожа, але використовує степені 2, а не степені 10.

Отже: `101 => 1*2^2 + 0*2^1 + 1*2^0 => 1*4 + 0*2 + 1*1 => 4 + 1 => 5 base 10`.
