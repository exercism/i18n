# Вступ

Наша подруга Еліуд успадкувала ферму від своєї бабусі Тігіст.
Її бабуся була винахідницею і мала схильність робити все надто складно.
У курнику є цифровий дисплей, який показує закодоване число, що представляє позиції всіх яєць, які можна зібрати.

Еліуд просить нас написати програму, яка показує справжню кількість яєць у курнику.

Кодування інформації про позиції обчислюють так:

1. Пройдімося по місцях, де могли б бути яйця, і позначимо `1` для наявного яйця або `0` для порожнього місця.
2. Переведімо число з двійкової системи в десяткову.
3. Покажімо результат на дисплеї.

Приклад 1:

```text
Chicken Coop:
 _ _ _ _ _ _ _
|E| |E|E| | |E|

Resulting Binary:
 1 0 1 1 0 0 1

Decimal number on the display:
89

Actual eggs in the coop:
4
```

Приклад 2:

```text
Chicken Coop:
 _ _ _ _ _ _ _ _
| | | |E| | | | |

Resulting Binary:
 0 0 0 1 0 0 0 0

Decimal number on the display:
16

Actual eggs in the coop:
1
```
