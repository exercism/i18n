# Вступ

Функція в Cairo дає змогу згрупувати код у багаторазово використовуваний блок, завдяки чому наші програми стають більш модульними та зрозумілішими.
Функції в Cairo складаються з ключового слова `fn`, далі йде назва функції, список параметрів у дужках і блок коду, який визначає, що робить функція.

## Параметри функції

У Cairo всі параметри функції повинні мати явно вказаний тип.
На відміну від деяких мов, Cairo не виводить типи, і типових значень параметрів тут немає, тому всі параметри обовʼязкові.

```rust
// Function with no parameters
fn print_hello() {
    // Function body
}

// Function with two parameters
fn print_greeting_name(greeting: ByteArray, name: ByteArray) {
    // Function body
}
```

## Параметри та аргументи

Важливо розрізняти `parameters` та `arguments`:

- **Параметри** - це назви змінних, які використовуються у визначенні функції, наприклад `greeting` і `name` у функції `print_greeting_name`.
- **Аргументи** - це фактичні значення, які передаються у функцію, коли її викликають.

```rust
// Calling the function with arguments
print_greeting_name(123, 456)
```

## Інструкції та вирази

Тіла функцій складаються з низки інструкцій, які необовʼязково завершуються виразом.

- Інструкції виконують певну дію і не повертають значення.
- Вирази обчислюються до певного значення.

Створення змінної та присвоєння їй значення за допомогою ключового слова `let` - це інструкція.

```rust
let y = 6;
```

Але `6` у наведеній вище інструкції - це вираз, який обчислюється до значення `6`.

Виклик функції - це вираз, оскільки він завжди обчислюється до якогось значення: явно вказаного поверненого значення функції, якщо його задано, або типу «одиниця» `()`, якщо ні.

## Повернені значення

Функції Cairo можуть повертати значення коду, який їх викликає.
Повернені значення вказуються після параметрів і відокремлюються стрілкою `->`.
У Cairo повернене значення функції збігається зі значенням останнього виразу в блоці тіла функції.
Можна достроково повернутися з функції, використавши ключове слово `return` і вказавши значення.

```rust
// Function returning the last (and only) expression
fn hello(name: ByteArray) -> ByteArray {
    "Hello " + name
}

// Function returning using the `return` keyword
fn double_if_even(value: u32) -> u32 {
    if value % 2 == 0 {
        return value * 2;
    }
    return value;
}
```

## Виклик функцій

Щоб викликати функцію в Cairo, ми просто використовуємо назву функції, а потім аргументи в дужках.

```rust
// Calling a function with no parameters
print_hello()

// Calling a function with one parameter
let greeting = hello("John")

// Calling a function with multiple parameters
print_greeting_name("Howdy", "Joel")
```
