# Інструкції

У цій вправі ми напишемо ще трохи коду, повʼязаного з приготуванням і запіканням нашої чудової лазаньї з улюбленої кулінарної книги.

На нас чекають чотири завдання.
Перше стосується самого приготування, а решта три - ідеальної підготовки.

## 1. Оцініть час підготовки

Готуючись до наступної лазаньї, ми хочемо переконатися, що в нас зарезервовано достатньо часу, аби приготування було в радість.
Ми вже спланували, з яких шарів складатиметься наша лазанья.
Тепер ми хочемо оцінити, скільки часу займе підготовка, виходячи з цього.

Реалізуйте функцію `PreparationTime`, яка приймає зріз шарів як `[]string` і середній час підготовки одного шару в хвилинах як `int`.
Функція має повернути оцінку загального часу підготовки на основі кількості шарів як `int`.
У Go немає типових значень для функцій.
Якщо середній час підготовки передано як `0` (типове початкове значення для `int`), тоді слід використати типове значення `2`.

```go
layers := []string{"sauce", "noodles", "sauce", "meat", "mozzarella", "noodles"}
PreparationTime(layers, 3)
// => 18
PreparationTime(layers, 0)
// => 12
```

## 2. Обчисліть потрібну кількість локшини й соусу

Окрім зарезервованого часу, ми також хочемо переконатися, що в нас достатньо соусу й локшини, щоб приготувати лазанью своєї мрії.
На кожен шар локшини в нашій лазаньї знадобиться 50 грамів локшини.
На кожен шар соусу в нашій лазаньї знадобиться 0.2 літра соусу.

Визначте функцію `Quantities`, яка приймає зріз шарів як параметр типу `[]string`.
Потім функція визначить кількість локшини й соусу, потрібну для нашої страви.
Результат має бути повернуто як два значення: `noodles` типу `int` і `sauce` типу `float64`.

```go
Quantities([]string{"sauce", "noodles", "sauce", "meat", "mozzarella", "noodles"})
// => 100, 0.4
```

## 3. Додайте секретний інгредієнт

Якось ми завітали до друга й їли там лазанью.
Вона була неймовірна, і в ній було щось особливе.
Друг надіслав нам список інгредієнтів і сказав, що останній елемент у списку - це «секретний інгредієнт», який зробив страву такою особливою.
Тепер ми хочемо додати цей секретний інгредієнт і до свого рецепта.

Напишіть функцію `AddSecretIngredient`, яка приймає два зрізи інгредієнтів типу `[]string` як параметри.
Перший параметр - це список, який надіслав нам друг, а другий - список інгредієнтів нашого власного рецепта.
Останній елемент у нашому списку інгредієнтів завжди `"?"`.
Функція має замінити його останнім елементом зі списку друга.
**Примітка:** `AddSecretIngredient` нічого не повертає, тож список наших інгредієнтів ми маємо змінити безпосередньо.
Список з інгредієнтами друга **не** має бути змінений.
Крім того, оскільки `slice` передається у функцію як вказівник, зміни в обох аргументах `[]string`, переданих у `AddSecretIngredient`, застосовуються безпосередньо.

```go
friendsList := []string{"noodles", "sauce", "mozzarella", "kampot pepper"}
myList := []string{"noodles", "meat", "sauce", "mozzarella","?"}

AddSecretIngredient(friendsList, myList)
// myList => []string{"noodles", "meat", "sauce", "mozzarella", "kampot pepper"}
```

## 4. Масштабуйте рецепт

Кількості, наведені в кулінарній книзі, дають лазанью лише на дві порції.
Оскільки наступного разу ми хочемо приготувати для більшої кількості людей, потрібно обчислити кількості для різної кількості порцій.

Реалізуйте функцію `ScaleRecipe`, яка приймає два параметри.

- Зріз кількостей типу `float64`, потрібних для 2 порцій.
- Кількість порцій, яку ми хочемо приготувати.

Функція має повернути зріз `float64` з кількостями, потрібними для бажаної кількості порцій.
Але ми хочемо зберегти початковий рецепт.
Це означає, що аргумент `quantities` не має змінюватися в цій функції.

```go
quantities := []float64{ 1.2, 3.6, 10.5 }
scaledQuantities := ScaleRecipe(quantities, 4)
// => []float64{ 2.4, 7.2, 21 }
```
