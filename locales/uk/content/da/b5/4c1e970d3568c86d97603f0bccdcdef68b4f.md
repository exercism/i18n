# Break, Continue

Коли ми використовуємо циклічну або ітераційну керуючу структуру, ключові слова `break` і `continue` можуть допомогти керувати потоком виконання програми.
Ключове слово `break` перериває цикл, виходячи з його контексту в зовнішню область видимості, і таким чином завершує цикл.
Ключове слово `continue` пропускає решту поточної ітерації та перезапускає контекст циклу з початку наступної ітерації.
Хоча це трапляється нечасто, разом із ключовим словом можна вказати число, щоб керувати тим, зі скількох контекстів вийти або скільки контекстів пропустити до наступної ітерації.

```php
<?php
$i = 1;
while ($i <= 10) {

    if ($i <= 5) {
        i += 1;
        continue;
    }
    break;
}
```

У попередньому прикладі `continue` виконується пʼять (5) разів, але на шостій (6) ітерації виконується `break`, і код виходить із циклу.
