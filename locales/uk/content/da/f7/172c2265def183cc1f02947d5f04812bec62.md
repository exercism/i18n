# Про це

У Factor `<iota>` створює *віртуальну* послідовність цілих чисел
`0, 1, …, n-1`. Якщо пройтися нею з `map`, отримаємо табульовану послідовність,
де кожен елемент є функцією своєї позиції:

```factor
USING: math sequences ;

5 <iota> [ sq ] map .         ! => { 0 1 4 9 16 }
8 <iota> [ 1 + ] map .        ! => { 1 2 3 4 5 6 7 8 }
```

Дві складові дають змогу перетворити послідовність цілочисельних кодів на
рядок тексту (англ. string):

| слово     | роль                                                    |
|-----------|---------------------------------------------------------|
| `CHAR:`   | літерал часу розбору, який кладе на стек кодову точку символу |
| `>string` | перетворює послідовність кодових точок на рядок тексту   |

Разом вони утворюють стандартний прийом для побудови послідовності
символів, індексованих за позицією:

```factor
USING: kernel math sequences strings ;

10 <iota> [ 2 mod zero? [ CHAR: O ] [ CHAR: . ] if ] map >string .
! => "O.O.O.O.O."
```

Вибір символу за допомогою `if` (або `?`) усередині квотейшна
залишає рішення для кожної позиції поруч з індексом, від якого воно залежить.
