# Вступ

[Спеціальна форма with][with] дає змогу зосередитися на «щасливому шляху» низки кроків, які можуть зазнати невдачі, а самі невдачі обробити пізніше.

```elixir
with {:ok, id} <- get_id(username),
     {:ok, avatar} <- fetch_avatar(id),
     {:ok, image_type} <- check_valid_image_type(avatar) do
  {:ok, image_type, avatar}
else
  :not_found ->
    {:error, "invalid username"}

  {:error, "not an image"} ->
    {:error, "avatar associated to #{username} is not an image"}

  err ->
    err
end
```

На кожному кроці, якщо збіг успішний, ланцюжок продовжується, доки не виконається блок `do`. Якщо ж якийсь збіг не вдався, ланцюжок зупиняється і повертається результат цього кроку. Можна також скористатися блоком `else`, щоб перехопити невдалі збіги та змінити повернене значення.

[with]: https://hexdocs.pm/elixir/Kernel.SpecialForms.html#with/1
