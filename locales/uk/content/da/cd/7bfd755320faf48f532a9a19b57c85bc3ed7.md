# Докладніше

У Python [перелік][enum-docs] - це набір унікальних імен, яким відповідають унікальні **константні** значення.
`Enums` визначаються шляхом успадкування класу `Enum`.
Вбудовані типи переліків доступні в модулі `enum`, а клас `Enum` можна імпортувати за допомогою `from enum import Enum`.


```python
from enum import Enum

class Color(Enum):
    RED = 1
    GREEN = 2
```

Зауважмо, що значеннями членів `enum` можуть бути будь-які типи даних, як-от `str`, `tuple`, `float` тощо.

```python
class Color(Enum):
    RED = 'red'
    GREEN = 'green'
```

`Enums` також можна створити за допомогою [синтаксису виклику функції][enum-functional-example].

```python
from enum import Enum

Animal = Enum('Animal', 'ANT BEE CAT DOG')
list(Animal)
#=> [<Animal.ANT: 1>, <Animal.BEE: 2>, <Animal.CAT: 3>, <Animal.DOG: 4>]

Animal.ANT.value
#=> 1
```

Якщо присвоїти однакове значення двом членам `enum`, то член, присвоєний пізніше, стане псевдонімом першого. Використовувати однакове імʼя для двох різних членів `enum` не можна.

```python
class Color(Enum):
    RED = 1
    GREEN = 2
    ALIAS_OF_RED = 1

Color.ALIAS_OF_RED
#=> <Color.RED: 1>
```

Перебрати члени переліку можна за допомогою стандартного синтаксису `for member in`:

```python
for member in Color:
    print((member.name, member.value))
#=> (RED, 1)
#=> (GREEN, 2)

# __members__.items() helps you to loop through alias as well
for member in Color.__members__.items():
    print(member)
#=> ('RED', <Color.RED: 1>)
#=> ('GREEN', <Color.GREEN: 2>)
#=> ('ALIAS_OF_RED', <Color.RED: 1>)
```

Члени `Enum` можна порівнювати за допомогою [`is` (_оператор ідентичності_)][identity-keyword] або `is not`. `==` і `!=` (_оператори рівності_) працюють так само:


```python
a = Color.RED

a is Color.RED
#=> True

a == Color.RED
#=> True
```

Щоб присвоювати цілі значення, [функція `auto()`][enum-auto-docs] починає з `1` і автоматично задає наступні значення.

```python
class Shape(Enum):
    CIRCLE = auto()
    SQUARE = auto()
    OVAL = auto()
```

Щоб заборонити псевдоніми (_запобігти дублюванню значень під різними іменами_), можна скористатися [декоратором класу][class-decorator] [`@enum.unique`][enum-unique-decorator].

```python
@enum.unique
class Shape(Enum):
    CIRCLE = 1
    SQUARE = 2
    TRIANGLE = 1
#=> ValueError: duplicate values found in <enum 'Shape'>: TRIANGLE -> CIRCLE
```

Щоб отримати член `enum` за заданим значенням, можна скористатися таким записом: `<EnumName>(<value>)`.

```python
g = Color(2)

g is Color.GREEN
#=> True

g
#=> <Color.GREEN: 2>
```

Власний [обмежений `Enum`][restricted-enums] можна написати, успадкувавши клас `Enum` разом із будь-яким міксином або типом даних.
Наприклад:


```python
class StrEnum(str, Enum):
    pass
```

Успадковувати `Enum` можна лише тоді, коли `enum` **не** визначає жодного члена.
