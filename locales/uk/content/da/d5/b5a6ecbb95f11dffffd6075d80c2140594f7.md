# Інструкції

Базова машина Take-A-Number продавалася дуже добре, але деякі користувачі скаржилися на брак розширених можливостей порівняно з іншими моделями, доступними на ринку.

Виробник дослухався до відгуків користувачів і вирішив випустити модель делюкс із більшою кількістю можливостей, і нам знову доручили написати програмне забезпечення для цієї машини.

Серед нових можливостей, доданих до моделі делюкс:
- Відстеження номерів, які зараз стоять у черзі.
- Встановлення мінімального й максимального номера. Це дозволить використовувати кілька машин делюкс Take-A-Number, щоб ставити в чергу відвідувачів різних відділів однієї установи, і розрізняти відділи за діапазоном номерів.
- Дозвіл певним номерам оминати чергу, щоб надавати пріоритетне обслуговування вагітним жінкам і людям похилого віку.
- Автоматичне вимкнення, яке не дає випадково залишити машину ввімкненою на цілі вихідні й марно витрачати енергію.

Бізнес-логіку машини вже реалізував колега, і її можна знайти в модулі `TakeANumberDeluxe.State`. Тепер наше завдання - обгорнути її в `GenServer`.

## 1. Запустіть машину

Використайте поведінку `GenServer` у модулі `TakeANumberDeluxe`.

Реалізуйте функцію `start_link/1` і відповідний колбек `GenServer`.

У `start_link/1` передають список ключових слів. Він містить ключі `:min_number` і `:max_number`. Значення за цими ключами потрібно передати у функцію `TakeANumberDeluxe.State.new/2`.

Якщо `TakeANumberDeluxe.State.new/2` повертає кортеж `{:ok, state}`, машина повинна запуститися, використавши повернений стан як свій стан. Якщо ж він повертає кортеж `{:error, error}`, машина повинна зупинитися, а повернена помилка стане причиною зупинки.

```elixir
TakeANumberDeluxe.start_link(min_number: 1, max_number: 9)
# => {:ok, #PID<0.174.0>}

TakeANumberDeluxe.start_link(min_number: 9, max_number: 1)
# => {:error, :invalid_configuration}
```

Можна помітити, що функція `TakeANumberDeluxe.State.new/2` також приймає необовʼязковий третій аргумент, `auto_shutdown_timeout`. Ми використаємо його в останньому кроці цієї вправи.

## 2. Повідомте стан машини

Реалізуйте функцію `report_state/1` і відповідний колбек `GenServer`. Машина повинна відповісти тому, хто викликав, своїм поточним станом.

```elixir
{:ok, machine} = TakeANumberDeluxe.start_link(min_number: 1, max_number: 10)
TakeANumberDeluxe.report_state(machine)
# => %TakeANumberDeluxe.State{
#      max_number: 10,
#      min_number: 1,
#      queue: %TakeANumberDeluxe.Queue{in: [], out: []},
#      auto_shutdown_timeout: :infinity,
#    }
```

## 3. Поставте нові номери в чергу

Реалізуйте функцію `queue_new_number/1` і відповідний колбек `GenServer`.

Вона повинна викликати функцію `TakeANumberDeluxe.State.queue_new_number/1` з поточним станом машини.

Якщо `TakeANumberDeluxe.State.queue_new_number/1` повертає кортеж `{:ok, new_number, new_state}`, машина повинна відповісти тому, хто викликав, новим номером і зробити новий стан своїм станом. Якщо ж він повертає кортеж `{:error, error}`, машина повинна відповісти тому, хто викликав, помилкою і не змінювати свій стан.

```elixir
{:ok, machine} = TakeANumberDeluxe.start_link(min_number: 1, max_number: 2)
TakeANumberDeluxe.queue_new_number(machine)
# => {:ok, 1}

TakeANumberDeluxe.queue_new_number(machine)
# => {:ok, 2}

TakeANumberDeluxe.queue_new_number(machine)
# => {:error, :all_possible_numbers_are_in_use}
```

## 4. Обслужіть наступний номер із черги

Реалізуйте функцію `serve_next_queued_number/2` і відповідний колбек `GenServer`.

Вона повинна викликати функцію `TakeANumberDeluxe.State.serve_next_queued_number/2` з поточним станом машини та її другим необовʼязковим аргументом, `priority_number`.

Якщо `TakeANumberDeluxe.State.serve_next_queued_number/2` повертає кортеж `{:ok, next_number, new_state}`, машина повинна відповісти тому, хто викликав, наступним номером і зробити новий стан своїм станом. Якщо ж він повертає кортеж `{:error, error}`, машина повинна відповісти тому, хто викликав, помилкою і не змінювати свій стан.

```elixir
{:ok, machine} = TakeANumberDeluxe.start_link(min_number: 1, max_number: 10)
TakeANumberDeluxe.queue_new_number(machine)
# => {:ok, 1}

TakeANumberDeluxe.serve_next_queued_number(machine)
# => {:ok, 1}

TakeANumberDeluxe.serve_next_queued_number(machine)
# => {:error, :empty_queue}
```

## 5. Скиньте стан

Реалізуйте функцію `reset_state/1` і відповідний колбек `GenServer`.

Вона повинна викликати функцію `TakeANumberDeluxe.State.new/2`, щоб створити новий стан із `min_number` і `max_number` поточного стану. Машина повинна зробити новий стан своїм станом. Вона не повинна відповідати тому, хто викликав.

```elixir
{:ok, machine} = TakeANumberDeluxe.start_link(min_number: 1, max_number: 10)

TakeANumberDeluxe.reset_state(machine)
# => :ok
```

## 6. Реалізуйте автоматичне вимкнення

Змініть запуск машини. Вона повинна прочитати значення за ключем `:auto_shutdown_timeout` у списку ключових слів, переданому як `init_arg`, і передати його третім аргументом у `TakeANumberDeluxe.State.new/3`. Якщо `:auto_shutdown_timeout` не задано, використайте типове значення `:infinity`.

Змініть скидання стану машини так, щоб воно також передавало `auto_shutdown_timeout` у `TakeANumberDeluxe.State.new/3`.

Змініть повернені значення всіх реалізованих колбеків (`init/1` і всіх колбеків `handle_*`), щоб вони встановлювали тайм-аут. Використайте значення за ключем `:auto_shutdown_timeout` у поточному стані машини. Не додавайте тайм-аут до поверненого значення `{:stop, reason}` функції `init/1`: тайм-аути діють лише після того, як сервер запустить цикл отримання повідомлень.

Реалізуйте колбек `GenServer`, який оброблятиме повідомлення `:timeout`, що надійде машині, якщо протягом заданого тайм-ауту вона не отримає жодних інших повідомлень. Він повинен завершити процес із причиною `:normal`.

Подбайте також про будь-які несподівані повідомлення: просто ігноруйте їх.

```elixir
{:ok, machine} =
  TakeANumberDeluxe.start_link(
    min_number: 1,
    max_number: 10,
    auto_shutdown_timeout: :timer.hours(2)
  )

# after 3 hours...

TakeANumberDeluxe.queue_new_number(machine)
# => ** (exit) exited in: GenServer.call(#PID<0.171.0>, :queue_new_number, 5000)
#        ** (EXIT) no process: the process is not alive or there's no process currently associated with the given name, possibly because its application isn't started
#       (elixir 1.13.0) lib/gen_server.ex:1030: GenServer.call/3
```
