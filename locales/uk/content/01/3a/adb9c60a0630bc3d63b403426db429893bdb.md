# Докладніше

Інтерфейс можна розуміти як сигнатуру класу, бо він описує публічні поля класу. Клас _реалізує_ `interface` за допомогою ключового слова `implments`.

Його синтаксис дуже схожий на синтаксис класу, хіба що методи подано як сигнатури без тіл:

```haxe
interface Language {
  private var languageName:String;

  public function speak():String;
}

class FrenchSpeaker implements Language {
  var languageName = "French";

  public function speak():String {
    return "Bonjour!";
  }
}
```

Поля, які реалізовано з інтерфейсу, **повинні** завжди використовувати той самий модифікатор видимості. Наприклад, якщо змінна `a` в інтерфейсі є `public`, її реалізація теж повинна бути `public`.
