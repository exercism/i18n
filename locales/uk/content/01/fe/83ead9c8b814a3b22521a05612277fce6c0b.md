# Функції

Функції відіграють фундаментальну роль у Cairo.

За домовленістю, у Cairo назви функцій і змінних записують у **зміїному регістрі**: слова малі, а розділяються вони підкресленнями.

Ось приклад:

```rust
fn another_function() {
    println!("Another function.");
}

fn main() {
    println!("Hello, world!");
    another_function();
}
```

Функції визначають за допомогою `fn`, далі йде назва, дужки для параметрів (якщо вони є) і тіло у фігурних дужках.

Щоб викликати функцію, треба написати її назву, а потім дужки.

Порядок функцій не має значення, аби вони були в області видимості.

## Параметри

Функції можуть приймати **параметри**. Це змінні, оголошені в сигнатурі функції.

Коли ми викликаємо функцію, ми передаємо **аргументи**: значення, передані цим параметрам.

```rust
fn main() {
    another_function(5);
}

fn another_function(x: felt252) {
    println!("The value of x is: {}", x);
}
```

Тут `x` - параметр типу `felt252`.

Якщо викликати функцію з `5`, вона виведе «The value of x is: 5».

Кілька параметрів розділяють комами:

```rust
fn main() {
    print_labeled_measurement(5, "h");
}

fn print_labeled_measurement(value: u128, unit_label: ByteArray) {
    println!("The measurement is: {value}{unit_label}");
}
```

Це виведе: `The measurement is: 5h`.

## Інструкції та вирази

Функції в Cairo складаються з **інструкцій** і **виразів**:

- **Інструкції** виконують дії, але не повертають значень.
Наприклад, `let x = 3;` - це інструкція.
- **Вирази** обчислюються до певного значення.
Наприклад, `5 + 6` дає `11`.

Блоки у фігурних дужках теж є виразами, і повертається їхнє останнє значення:

```rust
fn main() {
    let y = {
        let x = 3;
        x + 1
    };
    println!("The value of y is: {}", y);
}
```

Тут змінній `y` присвоюється значення `4`.

## Повернені значення

Функції можуть повертати значення; для цього за допомогою синтаксису `->` указують тип поверненого значення.

Типово функція повертає значення свого останнього виразу:

```rust
fn five() -> u32 {
    5
}

fn main() {
    let x = five();
    println!("The value of x is: {}", x);
}
```

Це виведе: `The value of x is: 5`.

Для складніших випадків:

```rust
fn plus_one(x: u32) -> u32 {
    x + 1
}

fn main() {
    let x = plus_one(5);
    println!("The value of x is: {}", x);
}
```

Це виведе: `The value of x is: 6`.

Стежте за тим, щоб не додати крапку з комою в кінці останнього виразу: вона перетворить вираз на інструкцію, і функція поверне `()` (одиничний тип) замість очікуваного значення.
