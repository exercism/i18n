# Використовуйте хвостову рекурсію

Мета цієї вправи - навчити хвостової рекурсії. Розвʼяжіть її, не використовуючи рекурсивних функцій без хвостової рекурсії.

Хвостові рекурсивні функції, знайдені в рішенні: %{tail_call_recursive_functions}. Інші рекурсивні функції, знайдені в рішенні: %{non_tail_call_recursive_functions}.

Нагадаємо: хвостова рекурсія виникає тоді, коли _останній_ вираз, який обчислює функція, викликає саму себе.

```elixir
# this is tail call recursion,
# the last expression is a call to `do_encode`
defp do_encode([n | rest], acc) do
  do_encode(rest, <<acc::bitstring, encode_nucleotide(n)::4>>)
end

# this is not tail call recursion,
# the last expression is a call to `<<>>`
def encode([head | tail]) do
  <<encode_nucleotide(head)::4, encode(tail)::bitstring>>
end
```
