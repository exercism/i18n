# Вступ

## Початок роботи

### Змінні

Значення можна повʼязати з іменами, визначивши [змінну][constants-variables] і присвоївши цій змінній значення.
Потім це імʼя можна використовувати, щоб посилатися на це значення в усій програмі.
Змінні _змінювані_, тобто їхнє значення можна змінити в будь-який момент.

Змінні визначають за допомогою ключового слова `var`.

```swift
var variableName = 10
```

Swift належить до мов зі статичною типізацією та перевіркою типів, що означає, що всі значення мають тип під час компіляції.
Ми можемо або явно вказати тип змінної за допомогою [анотацій типів][type annotations], або дозволити компілятору [вивести тип][type-inferring].

```swift
var explicitVar: Int = 10 // Explicitly typed
var implicitVar = 10      // Implicitly typed
```

Оновлення значення змінної виконують за допомогою оператора `=`.

~~~~exercism/note
Тип змінної фіксується після її початкового визначення.

```swift
variableName = 13 // update to new value

// compiler error when assigning a different type
variableName = "Hello, world!" // Cannot assign value of type 'String' to type 'Int'
```
~~~~

Змінні можна оголосити без присвоєння значення, вказавши імʼя та тип, але їх не можна використовувати до того, як значення присвоєно.

```swift
var someInt: Int

// This would trigger a compiler error
// print(someInt) // Variable 'someInt' used before being initialized

// Assign a value to the names
someInt = 169

print(someInt) // Prints '169'
```

### Константи

[Константи][constants-variables] схожі на змінні тим, що вони повʼязані з іменем і значенням, але значення константи не можна змінити після його початкового присвоєння, тому воно є _незмінним_.
Константи визначають за допомогою ключового слова `let`.

```swift
let constantName = 10          // constant
let explicitConstant: Int = 10 // Explicitly typed constant
```

### Додавання, віднімання та множення

У Swift є [оператори][arithmetical-operators] для додавання, віднімання та множення.
Це оператори `+`, `-` і `*` відповідно.

```swift
print(1 + 1) // Prints 2
print(2 - 1) // Prints 1
print(2 * 2) // Prints 4
```

### Функції

У Swift [функції][functions] - це фрагмент коду, який виконує певне завдання.
Функція має тип поверненого значення, тому її можна використовувати як значення й передавати як аргумент іншим функціям.
У Swift функції визначають за допомогою ключового слова `func`, після якого йде назва функції, аргументи, розділені комами, та тип поверненого значення.

Аргументи визначають через мітку аргументу, імʼя параметра, двокрапку після нього і потім тип.
Тип поверненого значення визначають через `->`, після якого вказують тип значення, що повертається.

```swift
func functionName(argumentName parameterName: ArgumentType) -> ReturnType {
  // function body
}
```

Аргументи в Swift дещо особливі порівняно з іншими мовами: вони використовують [мітки аргументів][argument-labels].
Мітку аргументу використовують під час виклику функції.
Імʼя параметра використовують усередині тіла функції, щоб посилатися на значення аргументу.
Якщо для аргументу вказати лише одне імʼя, воно буде і міткою аргументу, і іменем параметра.
Якщо вказати мітку аргументу як `_`, аргумент не матиме мітки під час виклику функції, наприклад: `functionName(argumentValue)`

Щоб викликати функцію, використовують її назву, а потім мітку аргументу та значення аргументу, ось так:

```swift
func functionName(argumentLabel parameterName: ArgumentType) -> ReturnType {
  // function body
}

// calling the function
functionName(argumentLabel: argumentValue)
```

Усі аргументи типово незмінні, і їх не можна змінити всередині функції.
Якщо функція має тип поверненого значення, обовʼязково повертаємо значення цього типу.
Це роблять за допомогою ключового слова `return`, після якого вказують значення, яке потрібно повернути.

```swift
func addTen(number value: Int) -> Int {
  return value + 10
}

// calling the function
addTen(number: 10) // Returns 20
```

Коли функції не повертають значення, вони мають тип поверненого значення `Void`, що те саме, що й `()`, але в таких випадках тип поверненого значення можна й опустити.

### Коментарі

Swift підтримує два типи [коментарів][comments].
Однорядкові коментарі починаються з `//`, а багаторядкові розміщують між `/*` і `*/`.
