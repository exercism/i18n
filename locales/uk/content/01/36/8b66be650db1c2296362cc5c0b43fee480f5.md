# Debug

Щоб додати повідомлення до тестів, які не проходять, можна скористатися [Debug.log](https://package.elm-lang.org/packages/elm/core/latest/Debug#log):

```elm
hoursToSeconds : Int -> Int
hoursToSeconds hours =
    let
        secondsInOneHour =
            Debug.log "secondsInOneHour" (60 * 60)
    in
    hours * secondsInOneHour
```

У разі невдалого тесту додане повідомлення матиме такий вигляд: `secondsInOneHour: 3600`.

Є одне застереження: константи верхнього рівня обчислюються лише один раз, до початку запуску тестів, тому тести не можуть отримати їхні повідомлення логу. Наприклад:

```elm
secondsInOneHour : Int
secondsInOneHour =
    Debug.log "secondsInOneHour" (60 * 60)
```

не залогує нічого під час тестів, бо змінна JavaScript, повʼязана з `secondsInOneHour`, вже отримала значення 3600.
