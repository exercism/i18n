# Вступ

## Рядки тексту

`string` (рядок тексту) у F# - це обʼєкт, який являє собою незмінний текст у вигляді послідовності символів Unicode (літер, цифр, розділових знаків тощо) і визначається так:

```fsharp
let fruit = "Apple"
```

З рядками тексту працюють, викликаючи методи самого рядка або функції модуля `String`. Після того як рядок тексту створено, його значення вже не може змінитися. Будь-які методи чи функції, які на вигляд змінюють рядок тексту, насправді повертають новий рядок тексту.

Рядки тексту можна зʼєднувати або форматувати кількома різними способами.
* Для конкатенації можна скористатися оператором `+`:
```fsharp
let sentence = "Apple" + " is a type of fruit."
```
* Для форматування тексту можна скористатися функцією `sprintf`: у тексті формату розміщують заповнювачі (`%s` для `string`), а значення передають як аргументи:
```fsharp
let sentence = sprintf "%s is a type of %s." "Apple" "fruit"
```
