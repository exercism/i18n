# Цикли `while` і `until`

Цикл як керувальна конструкція дає змогу виконувати код повторно, доки виконується певна умова.

## Цикли `while`

Цикл `while` як керувальна конструкція дає змогу виконувати код повторно, доки виконується певна умова.
Код усередині циклу `while` виконується доти, доки умова дає правдиве значення.
Цикли `while` часто використовують, коли кількість ітерацій заздалегідь невідома, але їх можна застосовувати в будь-якій ситуації, де потрібен цикл.

Умова перевіряється перед виконанням коду всередині циклу, тож якщо умова хибна, код у циклі не виконається жодного разу.

```crystal
i = 0
while i < 3
  puts i
  i += 1
end

# Output:
# 0
# 1
# 2
```

Щоб перебрати символи рядка тексту (англ. string), можна пройтися циклом по довжині цього рядка тексту.

```crystal
str = "Hello"
i = 0
while i < str.size
  puts str[i]
  i += 1
end

# Output:
# H
# e
# l
# l
# o
```

## Цикли `until`

Цикли `until` працюють так само, як цикли `while`, з однією відмінністю: код у циклі виконується доти, доки умова не дасть правдивого значення.
Це та сама різниця, що й між `if` та `unless`.

```crystal
i = 0
until i == 3
  puts i
  i += 1
end
```

### Нескінченні цикли

З циклами `while` часто трапляється така помилка: програма потрапляє в «нескінченний цикл», який ніколи не завершується.
Нескінченний цикл виникає, коли умова _ніколи_ не дає потрібного правдивого чи неправдивого значення.
Найчастіше причина в помилці програміста, наприклад, коли забувають збільшити змінну циклу.
Але іноді нескінченний цикл є найзрозумілішим способом реалізувати логіку програми.
Або ж цикл справді мусить тривати вічно. Наприклад, HTTP-сервер чекає на вхідне зʼєднання, обробляє його, а тоді чекає на наступне.

## Break

Ключове слово `break` дає змогу вийти з циклу достроково.
Це зручно, коли за певних умов потрібно завершити цикл раніше.

```crystal
i = 0
while i <= 3
  puts i
  i += 1
  if i == 2
    break
  end
end

# Output:
# 0
# 1
```

## Next

Ключове слово `next` дає змогу перейти до наступної ітерації циклу.
Це зручно, коли деякі ітерації циклу потрібно пропустити.

```crystal
i = 0
while i <= 3
  i += 1
  if i == 2
    next
  end
  puts i
end

# Output:
# 1
# 3
```

## Типи в циклі

Тип змінної в циклі може змінюватися.
У прикладі нижче тип `a` дорівнює `Int32 | String`, бо в першій частині циклу змінна може містити `Int32` або `String`.
Змінна `a` матиме тип `Int32 | String` лише в першій частині циклу, адже на початку циклу вона містить `Int32`, а на другій ітерації вже `String`.
Про цю систему з кількома типами ми детально поговоримо пізніше.
Але оскільки ми впевнені, що в другій частині циклу змінна міститиме лише `String`, тип `a' is `String` under the second part of the loop.
At runtime, it will never simultaneously hold `Int32` and `String`.

```crystal
i = 0
a = 4
while i < 3
  p typeof(a)
  # => Int32 | String
  a = "4"
  p typeof(a)
  # => String
  i += 1
end
```
