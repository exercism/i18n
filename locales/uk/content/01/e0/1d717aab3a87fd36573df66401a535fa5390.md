# Додаток до інструкцій

## Формат вихідних даних

Виведімо текст пісні як рядок тексту (англ. string), що завершується нульовим символом.

## Регістри

| Регістр | Використання | Тип | Опис |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | вхідні дані        | ціле число | початковий куплет                   |
| `$a1`    | вхідні дані        | ціле число | кінцевий куплет                     |
| `$a2`    | вхідні дані / вихідні дані | адреса | вихідний рядок тексту, що завершується нульовим символом |
| `$t0-9`  | тимчасовий    | будь-який     | для тимчасового зберігання         |
