# Вступ

## Символи

### Символи

Примітивний тип `char` у Java - це 16-бітове представлення одного символу.
Кілька `char` можуть утворювати рядок тексту (англ. string), наприклад `"word"`, або кожен `char` можна обробляти окремо.
Літерал `char` записують в одинарних лапках (наприклад, `'A'`).

```java
char lowerA = 'a';
char upperB = 'B';
```

### Як отримати `char` зі `String`

Метод `String.toCharArray` повертає символи рядка тексту як масив.
Як згадувалося в розділі про масиви, щоб перебрати масив, можна використати цикл `for`.

```java
String text = "Hello";
char[] asArray = text.toCharArray();

for (char ch: asArray) {
    System.out.println(ch);
}

// Outputs:
// H
// e
// l
// l
// o
```

### Клас Character

У бібліотеці є багато вбудованих методів для перевірки та обробки значень `char`.
Їх можна знайти серед статичних методів класу `java.lang.Character`.
Ось кілька прикладів:

```java
Character.isWhitespace(' ');    // true
Character.isWhitespace('#');    // false

Character.isLetter('a');        // true
Character.isLetter('3');        // false

Character.isDigit('6');         // true
Character.isDigit('?');         // false
```

### Додавання `char` до `String`

Оператор `+` можна використати, щоб додати `char` до `String`.

```java
'a' + " banana"     // => "a banana"
"banana " + 'a'     // => "banana a"
```

~~~~exercism/caution
Будьмо уважні: _не_ використовуймо `+`, щоб зʼєднати два `char` в один `String`!
Додавання двох `char` у такий спосіб дає `int`, _а не_ `String`!
Наприклад:

```java
'b' + 'c';
// => 197 (not the String "bc")
```

Це тому, що Java підвищує `char` до `int` (див. [4.2 Примітивні типи та значення][jls-primitives] у [специфікації мови Java][jls-main]).

[jls-main]: https://docs.oracle.com/javase/specs/jls/se21/html/
[jls-primitives]: https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.2
~~~~

Однак, коли треба додати багато символів, ефективніше скористатися `StringBuilder`:

```java
StringBuilder builder = new StringBuilder();
builder.append('a');
builder.append('b');
builder.append('c');

String builtString = builder.toString();
// => abc
```
