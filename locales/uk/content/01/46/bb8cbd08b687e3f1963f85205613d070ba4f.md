# Вступ

Умовні конструкції - це інструкції, які виконують різний код залежно від того, чи умова має значення `true`, чи `false`.

Умовна конструкція `if` виконує своє тіло лише тоді, коли її умова має значення `true`.
У Go немає понять truthy чи falsy, тому умова повинна мати тип `bool`.
Вирази на кшталт `if mySlice { ... }` чи `if 1 { ... }` призводять до помилок компіляції.

```go
func describe(val string) string {
    if val == "val" {
        return "was val"
    }
    return "was not val"
}
```

Щоб перевірити додаткові умови, скористаймося `else if`, а `else` застосуймо як запасний варіант, якщо жодна умова не збігається.
Умови перевіряються згори вниз, і виконається лише перша гілка, умова якої має значення `true`.

```go
number := 0
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

Умовна конструкція `if` може також містити коротку інструкцію ініціалізації.
Змінні, оголошені в такий спосіб, доступні лише в межах усього ланцюжка `if`/`else`.

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```
