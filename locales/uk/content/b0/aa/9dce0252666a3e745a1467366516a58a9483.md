# Додаток до вказівок

## Повідомлення про винятки

Іноді потрібно [викликати виняток](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). Роблячи це, варто завжди додавати **змістовне повідомлення про помилку**, яке вказує на джерело помилки. Це робить наш код зрозумілішим і значно спрощує налагодження. У ситуаціях, коли відомо, що джерело помилки матиме певний тип, можна викликати один із [вбудованих типів помилок](https://docs.python.org/3/library/exceptions.html#base-classes), але все одно варто додати змістовне повідомлення.

Ця вправа вимагає, щоб ми використали [інструкцію raise](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) і «кинули» `ValueError`, коли наша функція `largest_product()` отримує некоректні вхідні дані. Тести пройдуть лише тоді, коли ми і викличемо `exception` через `raise`, і додамо до нього повідомлення. Можна сміливо повторно використати код із вправи `series`!

Щоб викликати `ValueError` із повідомленням, передайте повідомлення як аргумент типу `exception`:

```python
# span of numbers is longer than number series
raise ValueError("span must not exceed string length")

# span of number is negative
raise ValueError("span must not be negative")

# series includes non-number input
raise ValueError("digits input must only contain digits")
```
