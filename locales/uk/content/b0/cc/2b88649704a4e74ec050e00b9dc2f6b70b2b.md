# Додаток до інструкцій

## Регістри

| Регістр | Призначення   | Тип             | Опис                                                    |
| -------- | ------------ | ------- | -------------------------------------- |
| `$a0`    | вхідні дані   | адреса | рядок тексту (англ. string) із запитанням, завершений нульовим символом |
| `$v0`    | вихідні дані  | ціле число | результат, 0, якщо запитання некоректне |
| `$t0-9`  | тимчасові     | будь-що | для тимчасового зберігання              |
