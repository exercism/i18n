# Інструкції

У цій вправі ми напишемо трохи коду, який допоможе нам підготуватися до купівлі транспортного засобу.

На нас чекають три завдання: визначити, чи потрібне посвідчення водія, допомогти обрати між двома транспортними засобами та оцінити прийнятну ціну вживаного транспортного засобу.

## 1. Визначте, чи потрібне посвідчення водія

Деякі види транспортних засобів вимагають посвідчення водія для керування ними.
Вважайте, що лише види `'car'` і `'truck'` потребують посвідчення, а все інше можна керувати без нього.

Реалізуйте функцію `needsLicense(kind)`, яка приймає вид транспортного засобу та повертає булеве значення (англ. Boolean), що вказує, чи потрібне посвідчення для цього виду транспортного засобу.

```javascript
needsLicense('car');
// => true

needsLicense('bike');
// => false
```

## 2. Оберіть між двома можливими транспортними засобами для купівлі

Ми оцінюємо доступні варіанти транспортних засобів.
Нам вдається звузити вибір до двох варіантів, але потрібна допомога, щоб ухвалити остаточне рішення.
Для цього реалізуйте функцію `chooseVehicle(option1, option2)`, яка приймає два транспортні засоби як аргументи та повертає рішення, що містить варіант, який іде першим за словниковим порядком.

```javascript
chooseVehicle('Wuling Hongguang', 'Toyota Corolla');
// =>  'Toyota Corolla is clearly the better choice.'

chooseVehicle('Volkswagen Beetle', 'Volkswagen Golf');
// =>  'Volkswagen Beetle is clearly the better choice.'
```

## 3. Обчисліть орієнтовну ціну вживаного транспортного засобу

Тепер, коли рішення ухвалено, хочеться переконатися, що в автосалоні нам дадуть справедливу ціну.
Оскільки нас цікавить купівля вживаного транспортного засобу, ціна залежить від його віку.
Для приблизної оцінки припустімо, що транспортний засіб віком до 3 років коштує 80% початкової ціни, яку мав новим.
Якщо йому понад 10 років, він коштує 50%.
Якщо транспортному засобу щонайменше 3 роки, але не більше 10 років, він коштує 70% початкової ціни.

Реалізуйте функцію `calculateResellPrice(originalPrice, age)`, яка застосовує цю логіку за допомогою `if`, `else if` та `else` (є й інші способи, якщо хочеться потренуватися).
Вона приймає початкову ціну та вік транспортного засобу як аргументи і повертає орієнтовну ціну в автосалоні.

```javascript
calculateResellPrice(1000, 1);
// => 800

calculateResellPrice(1000, 5);
// => 700

calculateResellPrice(1000, 15);
// => 500
```
