# Вступ

`String` у Julia - це впорядкована послідовність символів. Як зазначає посібник: «Звісно, справжні труднощі починаються, коли ми запитуємо, що таке символ».

Значну частину цієї складності ми докладніше розглянемо в концепції `Chars`, а поки що коротко:

- Усі рядки тексту (англ. string) в Julia закодовано в Unicode.
- З рядками тексту, які до того ж виявляються ASCII (англійські літери від A до Z у верхньому та нижньому регістрі, цифри й кілька розділових знаків), працювати _легко_.
- З більшістю інших систем письма світу працювати _можливо_, але потрібно більше уваги й обережності.

## Рядкові літерали

Загалом рядки тексту беруть у подвійні лапки `" "`.
Одинарні лапки `' '` використовують лише для `Chars`.

Також можна використовувати потрійні подвійні лапки `""" """`, що дозволяє вживати `"` всередині рядка тексту без екранування.
Що важливіше, у багаторядкових рядках тексту прибирають зайві відступи.

```julia-repl
julia> """
       Multiline
       String
       """
"Multiline\nString\n"
```

### Екранування символів

Як і більшість мов, починаючи з C, Julia використовує зворотний слеш `\` для екранування:

1. Щоб увести недруковані символи, як-от символ нового рядка `\n` у попередньому прикладі.
2. Щоб захистити символи, які інакше мали б спеціальне значення, як-от `\$` (див. нижче).

## Індексація

В принципі, рядки тексту можна індексувати точно так само, як вектори:

```julia-repl
julia> s[1], s[5]
('J', 'a')
```

Це явно працює для ASCII-рядка, як-от "Julia", але так ми ігноруємо більшість мов світу.

Розгляньмо один із символів у «Беовульфі», написаному староанглійською близько 15 століть тому.

«Hrōðgār» складається з 7 символів, але не всі вони ASCII.

```julia-repl
julia> king = "Hrōðgār"
"Hrōðgār"

julia> length(king)
7

julia> isascii(king)
false

# collect() converts to a Char vector:
julia> collect(king)
7-element Vector{Char}:
 'H': ASCII/Unicode U+0048 (category Lu: Letter, uppercase)
 'r': ASCII/Unicode U+0072 (category Ll: Letter, lowercase)
 'ō': Unicode U+014D (category Ll: Letter, lowercase)
 'ð': Unicode U+00F0 (category Ll: Letter, lowercase)
 'g': ASCII/Unicode U+0067 (category Ll: Letter, lowercase)
 'ā': Unicode U+0101 (category Ll: Letter, lowercase)
 'r': ASCII/Unicode U+0072 (category Ll: Letter, lowercase)
```

Індексація такого рядка тексту починається добре, але в якийсь момент дає збій:

```julia-repl
julia> king[3]
'ō': Unicode U+014D (category Ll: Letter, lowercase)

julia> king[4]
ERROR: StringIndexError: invalid index [4], valid nearby indices [3]=>'ō', [5]=>'ð'
```

Проблема в тому, що така індексація рахує _байти_, які для не-ASCII рядків тексту не мають співвідношення 1:1 із символами.
Щоб подати один символ Unicode/UTF-8, може знадобитися до 4 байтів, і концепція `Chars` розгляне це докладніше.

## Побудова рядків тексту

### Конкатенація

Багато мов використовують `+` як оператор конкатенації рядків тексту, але не Julia.
Принаймні повідомлення про помилку корисне.

```julia-repl
julia> "s1 " + "s2"
ERROR: MethodError: no method matching +(::String, ::String)
The function `+` exists, but no method is defined for this combination of argument types.
String concatenation is performed with * 

julia> "s1 " * "s2"
"s1 s2"
```

Функція `string()` конкатенує довільну кількість рядків тексту.

```julia-repl
julia> string("lots ", "of ", "bits")
"lots of bits"
```

Функція `join()` робить те саме, а ще приймає вектор рядків тексту й зʼєднує їх із заданим роздільником (типовим значенням є `""`).

```julia-repl
julia> join(["lots", "of", "bits"], "_")
"lots_of_bits"
```

Зауважмо, що рядки тексту незмінні, а конкатенація передбачає копіювання.
Тож повторювані конкатенації всередині циклу неефективні, і краще зібрати фрагменти у вектор, а потім зʼєднати їх усі наприкінці.

### Повторення

Просто:

```julia-repl
julia> repeat("Abc", 5)
"AbcAbcAbcAbcAbc"
```

### Інтерполяція

Багато мов мають спосіб вставляти обчислені значення в рядки тексту, хоч щодо найкращого синтаксису для цього існують надзвичайно різні думки.

У Julia перед інтерпольованими значеннями ставлять `$`.

```julia-repl
julia> myvar = 42
42

julia> "myvar evaluates to $myvar"
"myvar evaluates to 42"

julia> r = 5.3
5.3

julia> "A circle of radius $r has area $(π * r^2)"
"A circle of radius 5.3 has area 88.24733763933729"
```

Дужки потрібні, коли їх пропуск був би неоднозначним, але необовʼязкові для одного ідентифікатора, за яким іде пробіл.

Щоб уключити $ у рядок тексту, екрануймо його як `\$`.

Зауважмо обмеження: інтерполяція наразі не дозволяє форматування, як-от задання кількості десяткових знаків для показу.

### `@sprintf()`

Для тоншого контролю над збиранням рядків тексту Julia запозичує функцію `sprintf` з C (і кількох пізніших мов: Вікіпедія налічує близько 30).

У Julia це реалізовано як `macro` у модулі `Printf`, звідси префікс `@`.

```julia-repl
julia> using Printf

julia> r = 5.3
5.3

julia> @sprintf("A circle of radius %.1f has area %.2f", r, π * r^2)
"A circle of radius 5.3 has area 88.25"
```

## Функції для рядків тексту

Для простоти цей розділ зосередиться на функціях, які повертають новий рядок тексту й залишають вхідні дані без змін.
Багато з них мають відповідник із суфіксом `!`, який змінює вхідні дані на місці.

### Довжина

Який завдовжки рядок тексту?
Іноді це залежить від того, як ми рахуємо.

Найпростіший випадок - ASCII-рядки, де кожен символ займає 1 байт.

```julia-repl
julia> string_asc = "Julia"
"Julia"

julia> length(string_asc)
5

julia> sizeof(string_asc)
5
```

Функція `length()` повертає кількість _символів_, а функція `sizeof()` - кількість _байтів_.

Ця відмінність стає важливою для інших наборів символів:

```julia-repl
julia> king = "Hrōðgār"
"Hrōðgār"

julia> length(king)
7

julia> sizeof(king)
10
```

### Розбиття

Часта операція в програмуванні - узяти довгий рядок тексту й розбити його на частини за рядком-роздільником з одного або кількох символів.

Найзагальніше ми використовуємо функцію `split()`.
Типовим роздільником є (будь-які) пробільні символи, але можна вказати й інші.

```julia-repl
julia> split("my little string")
3-element Vector{SubString{String}}:
 "my"
 "little"
 "string"

julia> split("My_snake_case_string", "_")
4-element Vector{SubString{String}}:
 "My"
 "snake"
 "case"
 "string"
```

У цих прикладах рядок тексту розбивають на менші _рядки тексту_.
Розбиття рядка тексту на _символи_ - це інша операція.

### Пошук і заміна

Чи містить рядок тексту заданий підрядок?
Як не дивно, для цього є дві функції: `occursin()` і `contains()` різняться лише порядком своїх аргументів.

```julia-repl
julia> needle = "Julia"
"Julia"

julia> haystack = "Python, Julia and R"
"Python, Julia and R"

julia> occursin(needle, haystack)
true

julia> contains(haystack, needle)
true
```

Щоб точніше визначити позицію:

```julia-repl
julia> startswith(haystack, "Python")
true

julia> endswith(haystack, "Python")
false
```

Щоб отримати індекси початку й кінця підрядка, у нас є кілька функцій:

- `findfirst()`
- `findlast()`
- `findprev()`
- `findnext()`

```julia-repl
julia> findfirst(needle, haystack)
9:13
```

Щоб замінити підрядки, зміни перелічують у синтаксисі `x => y`.

```julia-repl
julia> replace("abc", "a"=>"b", "b"=>"c", "c"=>"a")
"bca"
```

Починаючи з Julia 1.7, функція `replace` може приймати довільну кількість змін, із гарантією, що під час заміни жоден символ не буде змінено більше ніж один раз.

Синтаксис `x => y` називають `pair`; це важливий тип у Julia, який докладніше розглянуто в концепції `Dicts and Pairs`.

### Пробільні символи

Часто потрібно прибрати провідні та/або кінцеві пробільні символи з рядка тексту.

Для цього є функції `lstrip()` (ліворуч), `rstrip()` (праворуч), `strip()` (з обох боків).

```julia-repl
julia> strip("\n\t  useful_bit\n\n")
"useful_bit"
```

### Зміна регістру

Назви цих функцій досить промовисті:

```julia-repl
julia> s = repeat("aBcD ", 5)
"aBcD aBcD aBcD aBcD aBcD "

julia> uppercase(s)
"ABCD ABCD ABCD ABCD ABCD "

julia> lowercase(s)
"abcd abcd abcd abcd abcd "

julia> titlecase(s)  # Initial letter of each word uppercase
"Abcd Abcd Abcd Abcd Abcd "
```
