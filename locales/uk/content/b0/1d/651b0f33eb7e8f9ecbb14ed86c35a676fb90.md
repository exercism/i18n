# віддайте перевагу константі верхнього рівня

Спробуйте винести число `GIGASECOND` в константу:

```javascript
const %{name} = %{value}

// the rest of your code below it
export const gigasecond = (...)
```

Лише функції, класи та константи, позначені `export`, видні й доступні ззовні. Зазвичай має сенс дати назву [магічним числам](https://en.wikipedia.org/wiki/Magic_number_%%28programming%%29), що полегшує супровід коду. Такі константи можуть залишатися в тому самому файлі й не бути видимими для іншого коду.
