# Підказки для вправи «Сапер» на Bash

Ця вправа, здається, потребує двовимірного масиву.
Bash пропонує лише одновимірні індексовані або асоціативні [масиви][array].

Багатовимірні масиви можна змоделювати за допомогою асоціативного масиву: закодувати індекси в рядок, розділений комами, і використати його як ключ масиву.

```bash
# store this matrix:
#   a b
#   c d
declare -A array2d
array2d["0,0"]="a"
array2d["0,1"]="b"
array2d["1,0"]="c"
array2d["1,1"]="d"
```

[array]: https://www.gnu.org/software/bash/manual/bash.html#Arrays
