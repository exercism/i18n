# Про це

Кожен примірник структури чи класу має неявну властивість з назвою `self`, яка вказує на сам цей примірник.
Найчастіше `self` використовують, щоб розрізнити властивість примірника та параметр, який має таку саму назву:

```swift
struct Position {
    var x = 0

    mutating func move(x: Int) {
        // Here, 'self.x' refers to the struct's property,
        // while 'x' refers to the parameter passed to the method.
        self.x = x
    }
}
```

Типи Swift також надають ключове слово `Self` з великої літери, яке вказує на *тип* примірника, а не на сам примірник.
