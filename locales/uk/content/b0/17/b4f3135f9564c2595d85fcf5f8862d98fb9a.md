# Докладніше

У Go є базові числові типи, які можуть представляти набори цілих чисел або чисел з плаваючою комою.
Існують різні типи залежно від розміру значення, який нам потрібен, і архітектури компʼютера, на якому виконується програма (наприклад, 32-бітні та 64-бітні).

У цьому розділі ми зосередимося на двох числових типах:

- `int`: наприклад, `0`, `255`, `2147483647`.
   Знакове ціле число розміром щонайменше 32 біти (діапазон значень: від -2147483648 до 2147483647).
   Але це залежить від архітектури системи.
   Більшість сучасних компʼютерів 64-бітні, тому `int` матиме розмір 64 біти (діапазон значень: від -9223372036854775808 до 9223372036854775807).

- `float64`: наприклад, `0.0`, `3.14`.
   Містить набір усіх 64-бітних чисел з плаваючою комою.

Повний перелік доступних числових типів і докладнішу інформацію можна знайти в цих джерелах:

- [Go builtin type declarations][go-builtins]
- [Digital Ocean - Understanding Data Types in Go][do-understanding-types]
- [Arden Labs - Understanding Type in Go][arden-understanding-types]

Go підтримує стандартний набір арифметичних операторів: `+`, `-`, `*`, `/` і `%` (остача, а не модуль).

У Go, щоб присвоїти значення одного типу змінній іншого типу, потрібне явне перетворення.
Наприклад, щоб перетворити `int` у `float64`, потрібно зробити таке:

```go
var x int = 42
f := float64(x)

fmt.Printf("x is of type: %s\n", reflect.TypeOf(x))
// Output: x is of type: int

fmt.Printf("f is of type: %s\n", reflect.TypeOf(f))
// Output: f is of type: float64
```

Докладніше про перетворення типів можна дізнатися тут: [A Tour of Go: Type Conversions][type-conversion]
