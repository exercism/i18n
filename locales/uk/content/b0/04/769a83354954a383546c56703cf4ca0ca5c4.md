# Інструкції

У цій вправі ми займемося обробкою помилок для простого калькулятора.

Мета - мати робочий калькулятор, який повертає рядок тексту (англ. string) за таким зразком: `16 + 51 = 67`, якщо передати йому аргументи `16`, `51` і `+`.

```ruby
SimpleCalculator.calculate(16, 51, "+")
# => "16 + 51 = 67"
SimpleCalculator.calculate(32, 6, "*")
# => "32 * 6 = 192"
SimpleCalculator.calculate(512, 4, "/")
# => "512 / 4 = 128"
```

## 1. Обробити код, який може викликати помилки, у методі `calculate`

Головним методом, який ми реалізуємо в цьому завданні, буде метод класу `SimpleCalculator.calculate()`.
Він приймає три аргументи.
Перші два аргументи - числа, над якими буде виконуватися операція.
Третій аргумент має тип рядок тексту, і в цій вправі потрібно реалізувати такі операції:

- додавання за допомогою рядка тексту `+`
- множення за допомогою рядка тексту `*`
- ділення за допомогою рядка тексту `/`

## 2. Обробити неприпустимі операції

Оновіть метод `SimpleCalculator.calculate()`, щоб він викликав виняток `UnsupportedOperation` для невідомих символів операцій.

```ruby
SimpleCalculator.calculate(1, 2, '-')
# => Raises an UnsupportedOperation
```

~~~~exercism/note
У цій вправі потрібно визначити виняток `UnsupportedOperation` для конкретної області видимості.
~~~~

## 3. Обробити неправильні аргументи

Оновіть метод `SimpleCalculator.calculate()`, щоб він викликав виняток `ArgumentError` для неправильних типів аргументів.

```ruby
SimpleCalculator.calculate(1, '2', '*')
# => Raises an ArgumentError
```

## 4. Обробити винятки DivideByZero

Оновіть `SimpleCalculator.calculate()`, щоб він обробляв винятки `ZeroDivisionError`.
Код обробки має повернути рядок тексту з таким вмістом: `Division by zero is not allowed.`.
Усі інші винятки метод `SimpleCalculator.calculate()` обробляти не повинен.

```ruby
SimpleCalculator.calculate(512, 0, "/")
# => returns "Division by zero is not allowed."
```
