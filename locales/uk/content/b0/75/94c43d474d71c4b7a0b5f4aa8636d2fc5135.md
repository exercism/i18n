# Вступ

## Цикли `while`

За допомогою циклу `while` можна повторно виконувати код, доки виконується певна умова.
Він записується за допомогою ключового слова `while`, після якого йде умова в круглих дужках (`()`) і блок коду з _тілом_ циклу у фігурних дужках (`{}`).

```javascript
while (condition) {
  // code that is executed repeatedly as long as the condition is true
}
```

У JavaScript також є цикл `do-while`.
Тут умова перевіряється після виконання тіла циклу.
Це корисно, коли умова залежить від обчислень, виконаних у тілі.

```javascript
do {
  // The code here will always be executed once and then
  // repeatedly while the condition is true.
} while (condition);
```

Усередині тіла циклу можна використати ключове слово `break`, щоб повністю зупинити виконання циклу.
На противагу цьому, ключове слово `continue` зупиняє виконання лише поточної ітерації та переходить до наступної.
За допомогою `continue` часто вдається уникнути обгортання великих частин тіла циклу в умовну конструкцію.

```javascript
let i = 0;

while (i < 100) {
  i = i + 2;

  if (i % 3 === 0) {
    continue;
  }

  // The code here will only be executed when i was not divisible
  // by 3 in the check above.
}
```

## Конструкція `switch`

Крім умовної конструкції, у JavaScript також є конструкція `switch` для умовного виконання логіки.
Її використовують, коли одну змінну потрібно порівняти з кількома варіантами.
Порівняння виконується перевіркою на сувору рівність (`===`), див. [концепція порівняння][concept-comparison].
Для деякої змінної `x` конструкція `switch` у JavaScript має такий синтаксис.

<!-- prettier-ignore-start -->
```javascript
switch (x) {
  case option1:
    // code that is executed when "x === option1" is true
    break;
  case option2:
    // code that is executed when "x === option2" is true
    break;
  default:
    // code that is executed when x does not equal any of the options
}
```
<!-- prettier-ignore-end -->

Варіант `default` необовʼязковий. Його використовують, коли потрібно виконати код, якщо жоден з інших варіантів не збігається зі змінною.

Наведені вище інструкції `break` потрібні, тому що за замовчуванням у JavaScript усі варіанти «провалюються».
Це означає, що без інструкції `break` виконався б увесь код у варіантах після першого збігу, навіть якщо `x` не збігається з ними.
Така поведінка «провалювання за замовчуванням» є поширеною пасткою під час використання `switch` у JavaScript.
Усередині функції замість `break` можна також використати `return`, щоб уникнути цієї проблеми.
