# Вступ

## Порівняння

Python підтримує такі базові оператори порівняння:

| Оператор | Операція                       | Опис                                                                                  |
| -------- | ------------------------------ | ------------------------------------------------------------------------------------- |
| `>`      | «більше ніж»                   | `a > b` дорівнює `True`, якщо `a` **строго** більше за `b` за значенням                |
| `<`      | «менше ніж»                    | `a < b` дорівнює `True`, якщо `a` **строго** менше за `b` за значенням                 |
| `==`     | «дорівнює»                     | `a == b` дорівнює `True`, якщо `a` **строго** дорівнює `b` за значенням                |
| `>=`     | «більше ніж або дорівнює»      | `a >= b` дорівнює `True`, якщо `a > b` АБО `a == b` за значенням                       |
| `<=`     | «менше ніж або дорівнює»       | `a <= b` дорівнює `True`, якщо `a < b` або `a == b` за значенням                       |
| `!=`     | «не дорівнює»                  | `a != b` дорівнює `True`, якщо `a == b` дорівнює `False`                               |
| `is`     | «ідентичність»                 | `a is b` дорівнює `True`, якщо **_і тільки якщо_** `a` і `b` є тим самим _обʼєктом_     |
| `is not` | «заперечення ідентичності»     | `a is not b` дорівнює `True`, якщо `a` і `b` **не** є тим самим _обʼєктом_             |
| `in`     | «перевірка входження»          | `a in b` дорівнює `True`, якщо `a` є членом, підмножиною або елементом `b`             |
| `not in` | «заперечення перевірки входження» | `a not in b` дорівнює `True`, якщо `a` не є членом, підмножиною або елементом `b`   |

Усі вони мають однаковий пріоритет (_вищий, ніж у [булевих операцій (англ. Boolean)][boolean operations], але нижчий, ніж в арифметичних чи побітових операцій_).

## Порівняння між різними типами даних

Обʼєкти різних типів (_крім числових типів_) типово ніколи не вважаються рівними.
Неідентичні примірники `class` також _**не**_ вважатимуться рівними, якщо тільки `class` не визначає спеціальних методів [розширеного порівняння][rich comparisons], які змінюють типову поведінку порівняння `object`.
Налаштування через `rich comparisons` розглянемо в одній із наступних вправ.
Щоб дізнатися (набагато) більше про цю тему, дивіться [порівняння значень][value comparisons] у документації Python.

Числові типи (переважно) є винятком із цього правила відповідності типів.
`integer` **може** вважатися рівним `float` (_або [`octal`][octal] рівним [`hexadecimal`][hex]_), якщо типи можна неявно перетворити для порівняння.

Для інших числових типів зі стандартної бібліотеки Python ([complex][complex numbers], [decimal][decimal numbers], [fractions][rational numbers]) оператори порівняння визначено там, де вони «мають сенс» (_де неявне перетворення не змінює результат_), але вони викликають `TypeError`, якщо базові обʼєкти не можна точно перетворити для порівняння.
Докладніше про правила, які Python використовує для _числового перетворення_, дивіться в розділі [арифметичні перетворення][arithmetic conversions] у документації Python.

```python
>>> import fractions

# A string cannot be converted to an int.
>>> 17 == '17'
False

# An int can be converted to float for comparison.
>>> 17 == 17.0
True

# The fraction 6/3 can be converted to the int 2
# The int 2 can be converted to 0b10 in binary.
>>> 6/3 == 0b10
True

# An int can be converted to a complex number with a 0 imaginary part.
>>> 17 == complex(17)
True

# The fraction 2/5 can be converted to the float 0.4
>>> 0.4 == 2/5
True

>>> complex(2/5, 1/2) == complex(0.4, 0.5)
True
```

Будь-яке впорядковане порівняння числа з типом `NaN` (_не число_) дає `False`.
Заплутаний побічний ефект визначення `NaN` у Python полягає в тому, що `NaN` ніколи не вважається рівним `NaN`.

```python
>>> x = float('NaN')

>>> 3 < x
False

>>> x < 3
False

# NaN never compares equal to NaN
>>> x == x
False
```

## Порівняння рядків тексту

На відміну від чисел, рядки тексту (англ. string) (`str`) порівнюються [_лексикографічно_][lexographic order], за їхніми окремими кодовими точками Unicode (_результат передачі кожної кодової точки зі `str` у вбудовану функцію [`ord()`][ord], яка повертає `int`_).
Якщо всі кодові точки в обох рядках тексту збігаються і розташовані _**в однаковому порядку**_, ці два рядки тексту вважаються рівними.
Це порівняння виконується попарно: перший з першим, другий з другим тощо.
У Python 3.x `str` і `bytes` не можна безпосередньо звести одне до одного чи порівняти.

```python
>>> 'Python' > 'Rust'
False

>>> 'Python' > 'JavaScript'
True

# Examples with Mandarin.
# hello < goodbye
>>> '你好' < '再见'
True

# ord() of first characters
>>> ord('你'), ord('再')
(20320, 20877)

# ord() of second characters
>>> ord('好'), ord('见')
(22909, 35265)

# And with Korean words.
# Pretty < beautiful.
>>> '예쁜' < '아름다운'
False

>>> ord('예'), ord('아')
(50696, 50500)
```

## Ланцюгове порівняння

Оператори порівняння можна обʼєднувати в ланцюжки _довільно_, тобто використовувати в будь-якій комбінації будь-якої довжини.
Зауважмо, що обчислення виразу відбувається від `left` до `right`.

Наприклад, `x < y <= z` еквівалентний `x < y` `and` `y <= z`, за винятком того, що `y` обчислюється **лише один раз**.
В обох випадках `z` _не_ обчислюється **взагалі**, коли `x < y` виявляється `False`.
Це часто називають `short-circuit evaluation`: обчислення припиняється, якщо істинність виразу вже встановлено.

`Short circuiting` підтримують різні булеві оператори, функції, а також ланцюгове порівняння в Python.
На відміну від багатьох інших мов програмування, зокрема `C`, `C++`, `C#` і `Java`, ланцюгові вирази на кшталт `a < b < c` у Python мають звичне [математичне тлумачення][three way boolean comparison] і пріоритет.

```python
>>> x = 2
>>> y = 5
>>> z = 10

>>> x < y < z
True

>>> x < y > z
False

>>> x > y < z
False
```

## Порівняння ідентичності обʼєктів

Оператори `is` і `is not` перевіряють [_ідентичність_][object identity] обʼєкта, а не його _значення_.
Ідентичність обʼєкта ніколи не змінюється після створення, і її можна дізнатися за допомогою функції [`id()`][id function].

`<apple> is <orange>` дає `True`, якщо **_і тільки якщо_** `id(<apple>)` == `id(<orange>)`.
`<apple> is not <orange>` дає протилежний результат.

Через те, що `None` і `NotImplemented` є єдиними у своєму роді, для їх порівняння з іншими обʼєктами завжди варто використовувати `is` і `is not`.
Докладніше про цю конвенцію дивіться в довідці Python про [порівняння значень][value comparisons none] і в [PEP8][pep8 programming recommendations].

```python
>>> my_fav_numbers = [1, 2, 3]

>>> your_fav_numbers = my_fav_numbers

>>> my_fav_numbers is your_fav_numbers
True

# The returned id will differ by system and python version.
>>> id(my_fav_numbers)
4517478208

# your_fav_numbers is only an alias pointing to the original my_fav_numbers object.
# Assigning a new name does not create a new object.
>>> id(your_fav_numbers)
4517478208


>>> my_fav_numbers is not your_fav_numbers
False

>>> my_fav_numbers is not None
True

>>> my_fav_numbers is NotImplemented
False
```

## Перевірка належності

Оператори `in` і `not in` перевіряють _належність_.
`<fish> in <soup>` дає `True`, якщо `<fish>` є членом `<soup>` (_якщо `<fish>` є підмножиною `<soup>` або міститься в ньому_), а інакше дає `False`.
`<fish> not in <soup>` повертає заперечення, тобто _протилежне_ до `<fish> in <soup>`.

Для типів рядків тексту і `bytes` вираз `<name> in <fullname>` дорівнює `True` **_і тільки якщо_** `<name>` є підрядком `<fullname>`.

```python
# A set of lucky numbers.
>>> lucky_numbers = {11, 22, 33}
>>> 22 in lucky_numbers
True

>>> 44 in lucky_numbers
False

# A dictionary of employee information.
>>> employee = {'name': 'John Doe', 
                'id': 67826, 'age': 33, 
                'title': 'ceo'}

# Checking for the membership of certain keys.
>>> 'age' in employee
True

>>> 33 in employee
False

>>> 'lastname' not in employee
True

# Checking for substring membership
>>> name = 'Super Batman'
>>> 'Bat' in name
True

>>> 'Batwoman' in name
False
```
