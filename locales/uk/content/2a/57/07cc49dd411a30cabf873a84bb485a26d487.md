# Видимість

Коли ми використовуємо класи, щоб упорядкувати код, видимість властивостей, методів і констант допомагає будувати правильні абстракції та розподіляти відповідальність.
Видимість властивостей, методів і констант визначається тим, чи використано ключові слова `public`, `private` або `protected` у момент їх оголошення.
Видимість завжди стосується зовнішнього використання властивості, методу або константи класу.
Тобто, якщо властивість оголошено як `public`, її можна бачити і використовувати із зовнішніх викликів.
Властивості, методи й константи, оголошені як `private`, не можна ні побачити, ні використати із зовнішніх викликів.

```php
<?php

class SecretDocument
{
    private $encryption_key;

    public $title;

    public function __construct($encryption_key, $title)
    {
        $this->encryption_key = $encryption_key;
        $this->title = $title;
    }
}

$document = new SecretDocument('secret_password', 'Secret Plans');
$title = $document->title; // => succeeds
$key = $document->encryption_key; // => fails
```

Властивості, методи й константи, оголошені як `protected`, можна бачити лише з них самих і з дочірніх класів (успадкованих).

```php
<?php

class Shape
{
    protected $color = "blue";
}

class Square extends Shape
{
    public function getColor()
    {
        return $this->color;
    }
}

$square = new Square();
$color = $square->getColor(); // => succeeds
```
