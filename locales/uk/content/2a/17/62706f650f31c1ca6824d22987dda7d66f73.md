# Вступ

## Списки символів

Списки символів створюють за допомогою сигіла `~c`.

```elixir
~c"hello"
```

~~~~exercism/note
Звернімо увагу: у старіших версіях Elixir списки символів записуються як `'hello'` в одинарних лапках.
~~~~

Хоча списки символів дуже схожі на рядки тексту (англ. string), ці два типи даних досить різняться між собою. Список символів - це список цілих чисел. Цілі числа представляють значення Unicode заданого символу, які також називають кодовими точками.

```elixir
[65, 66, 67]
# => ~c"ABC"
```

Щоб отримати кодову точку символу, поставмо `?` перед ним.

```elixir
?A
# => 65

[?:, ?)]
# => ~c":)"
```

Оскільки списки символів - це списки, з ними можна працювати так само, як і з будь-яким іншим списком: за допомогою рекурсії та зіставлення зі зразком.

```elixir
[first_letter | _] = ~c"cat"
first_letter
# => 99
```

Два списки можна зʼєднати за допомогою `++`.

```elixir
~c"hi" ++ ~c"!"
# => ~c"hi!"
```

Чим довший перший список, тим повільніше відбувається зʼєднання, тому уникаймо повторного дописування елементів у списки довільної довжини.

## `case`

`case` - це конструкція керування потоком, яка дозволяє порівнювати задане значення з багатьма зразками. Гілки виразу `case` обчислюються згори донизу, доки не знайдеться збіг.

```elixir
age = 15

case age do
  0 -> ~c"infant"
  age when age < 4 -> ~c"baby"
  age when age < 13 -> ~c"child"
  age when age < 18 -> ~c"teenager"
  _ -> ~c"adult"
end

# => ~c"teenager"
```
