# Вступ

Число з плаваючою комою - це число, яке має нуль або більше цифр після десяткового розділювача.
Наприклад: `-2.4`, `0.1`, `3.14`, `5.`, `16.984025` і `1024.0`.

Різні типи чисел з плаваючою комою можуть зберігати різну кількість цифр після десяткового розділювача. Це називається точністю.

У Go є два типи чисел з плаваючою комою:

- `float32`: 32 біти (точність ~6-9 цифр).
- `float64`: 64 біти (точність ~15-17 цифр).
   Це типовий тип для чисел з плаваючою комою.

Як бачимо, обидва типи можуть зберігати різну кількість цифр.
Це означає, що якщо ми спробуємо зберегти число π у `float32`, збережуться лише перші 6-9 цифр (а остання цифра буде округлена).

Типово Go використовує `float64` для чисел з плаваючою комою, якщо тільки це число не:

1. присвоєно змінній типу `float32`, або
2. повернуто з функції з типом повернення `float32`, або
3. передано як аргумент у функцію `float32()`.

[Пакет `math`] містить багато корисних математичних функцій.

[Пакет `math`]: https://pkg.go.dev/math
