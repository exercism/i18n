# Підказки

## Загальне

- У кожному завданні текст будується в циклі, тому кожне з них починається з `#FSTR` і закінчується `.str`.
- Присвоюймо результат кожного `+` назад у змінну-накопичувач:
  `script := script + ...`.

## 1. Повторити репліку

- `1.upto!(times)` виконує цикл потрібну кількість разів. Значення, яке воно дає, не потрібне, тому його можна одразу присвоїти змінній, яка ніде не використовується, або скористатися `times.times!`, який взагалі нічого не дає.
- Коли разів нуль, жодної особливої обробки не потрібно: цикл просто не виконується.

## 2. Ініціали акторів

- `names.elt!` дає кожне імʼя; `[0]` бере його перший символ.
- `FSTR` приймає `CHAR` безпосередньо, тому не потрібно спершу перетворювати його на рядок тексту (англ. string).

## 3. Пронумерувати рядки

- Два ітератори в одному циклі, як у попередній вправі: `1.up!` для числа, а `lines.elt!` для тексту.
- Новий рядок ставиться *перед* кожним рядком, крім першого. Найпростіше перевірити число: `if number > 1 then ... end`.
- `FSTR` приймає число безпосередньо, тому `script + number + ". "` працює без перетворення.

## 4. Прокричати рядок

- `line.elt!` перебирає рядок тексту символ за символом.
- `.upper` не чіпає нічого, що не є літерою, тому пробіл не потребує особливої обробки.
