# Додаток до інструкцій

Ця вправа добре підходить, щоб поекспериментувати з нестандартними рядковими літералами та метапрограмуванням.

Короткий вступ до нестандартних рядкових літералів можна знайти в цьому [дописі блогу](https://web.archive.org/web/20170625222109/https://iaindunning.com/blog/julia-unicode.html). Докладний посібник із метапрограмування можна знайти в [офіційній документації](https://docs.julialang.org/en/v1/manual/metaprogramming/).

Можна розширити власне рішення, додавши функціональність, описану нижче.

Бонус A потребує лише базових знань, окреслених у дописі блогу. Бонус B потребує значно глибших знань метапрограмування в Julia.

## Бонус A
Реалізуйте рядковий літерал, що застосовує `ROT13` до рядка:
```julia
R13"abcdefghijklmnopqrstuvwxyz" == "nopqrstuvwxyzabcdefghijklm"
```

## Бонус B
Реалізуйте рядкові літерали `R<i>`, `i = 0, ..., 26`, які зсувають рядок на `i` позицій:
```julia
R0"Hello, World!" == "Hello, World!"
R4"Testing 1 2 3 testing" == "Xiwxmrk 1 2 3 xiwxmrk"
R13"abcdefghijklmnopqrstuvwxyz" == "nopqrstuvwxyzabcdefghijklm"
```
