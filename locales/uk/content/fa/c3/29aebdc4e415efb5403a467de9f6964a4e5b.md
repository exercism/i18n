# Класи

Класи - центральне поняття [обʼєктно-орієнтованого програмування][object-oriented-programming].
[У Crystal усе є обʼєктом][everything-is-an-object], кожен обʼєкт має тип і може відповідати на деякі методи.
Класи - це креслення для створення обʼєктів: вони задають початкові значення для стану, як-от змінні, і реалізації поведінки, як-от методи.
Обʼєкти - це екземпляри класу, які зберігають усі змінні екземпляра та стани.

## Визначення класу

Клас визначають за допомогою ключового слова `class`, після якого йде назва класу, записана в `UpperCamelCase`.

```crystal
class Account
end
```

## Створення екземпляра

Щоб [створити екземпляр класу][new-initialize], викликаємо назву класу за допомогою методу `new`.

```crystal
class Account
end

account = Account.new
```

У наведеному вище прикладі змінна `account` - це екземпляр класу `Account`.

Під час створення екземпляра спеціальний метод `initialize` виконує роль конструктора.
Його викликають під час створення екземпляра.
Конструктор дає змогу задати початковий стан екземпляра.
Метод `initialize` може приймати аргументи, які передаються під час створення екземпляра.

```crystal
class Account
  def initialize(number)
    5 + number # => 9
  end
end

Account.new(4)
```

~~~~exercism/note
Метод `initialize` не може повертати значення вручну; натомість `new` повертає щойно створений екземпляр.

```crystal
class Account
  def initialize(number)
    5 + number
  end
end

Account.new(4)
# => #<Account:0x7f5dc33dcea0>
```
~~~~

## Методи екземпляра

Метод екземпляра - це метод, доступний екземпляру класу, який можна викликати на цьому екземплярі.
Методи екземпляра визначають за допомогою ключового слова `def`, після якого йде назва методу.
Їх визначають усередині визначення класу.

```crystal
class Account
  def balance
    100
  end
end

account = Account.new
account.balance # => 100
```

## Змінні екземпляра

[Змінні екземпляра][instance-variable] - це змінні, доступні в усіх методах екземпляра.
Щоб отримати доступ до змінної екземпляра, треба визначити метод екземпляра.
Їх можна ініціалізувати в методі `initialize`.
Їх визначають за допомогою префікса `@`.

```crystal
class Account
  def initialize
    @balance = 100
  end

  def balance
    @balance
  end
end

account = Account.new
account.balance
# => 100
```

Змінні екземпляра також можна визначити всередині визначення класу.

```crystal
class Account
  @age = 0
end
```

### Змінні екземпляра з ініціалізацією

Змінні екземпляра можна ініціалізувати аргументом, переданим у метод `initialize`.
Оскільки Crystal не може вивести тип аргументу, використаного під час ініціалізації, його потрібно вказати.
Докладніше про це можна прочитати тут: [виведення типу][type-inference].
Щоб указати тип змінної, можна використати символ `:`, після якого йде тип.
Наприклад, щоб створити змінну екземпляра з назвою `balance` типу `Int32`, можна зробити так: `@balance : Int32`.
Або, щоб створити змінну екземпляра з назвою `raining` типу `Bool`, можна зробити так: `@raining : Bool`.

Є кілька способів це зробити: або оголосити аргумент із типом у методі `initialize`, а потім присвоїти змінній екземпляра значення аргументу, як у наступному прикладі:

```crystal
class Account
  def initialize(balance : Int32)
    @balance = balance
  end

  def balance
    @balance
  end
end

account = Account.new(1)
account_2 = Account.new(5)

account.balance
# => 1

account_2.balance
# => 5
```

Інший спосіб - оголосити тип змінної екземпляра у визначенні класу у формі: `@<variable> : <Type>`, як у наступному прикладі:

```crystal
class Weather

  @raining : Bool

  def initialize(raining)
    @raining = raining
  end

  def raining
    @raining
  end
end

weather = Weather.new(true)
weather.raining
# => true
```

## Зміна змінних екземпляра

Методи можуть змінювати змінні екземпляра.
Ці методи можна викликати на екземплярі класу.
Коли метод змінює змінну екземпляра, ця зміна доступна лише в тому екземплярі класу, на якому його викликали.

```crystal
class Account
  def initialize(balance : Int32)
    @balance = balance
  end

  def withdraw(amount)
    @balance -= amount
  end

  def balance
    @balance
  end
end

account = Account.new(10)
account_2 = Account.new(10)
account.balance
# => 10

account_2.balance
# => 10

account.withdraw(5)
account.balance
# => 5

account_2.balance
# => 10
```

## Методи класу

[Методи класу][class-methods] - це методи, визначені для класу, а не для його екземплярів.
Вони дають змогу створювати методи, які не залежать від стану екземпляра.
Їх визначають за допомогою ключового слова `def`, після якого йде `self.<method name>`.
`self` - це посилання на простір імен, з якого викликають `self`.
У цьому випадку він указує на клас `Account`.
Це те саме, якби написати `Account.`, але краще використовувати `self.`.

```crystal
class Account
  def self.balance
    100
  end
end

Account.balance
# => 100
```
