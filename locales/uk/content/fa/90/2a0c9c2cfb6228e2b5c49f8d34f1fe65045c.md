# Вступ

Запис - це набір полів (які можуть мати різні типи), що повʼязані між собою. Для визначення запису використовують ключове слово `type`. Поля запису визначають між символами `{` і `}`, і кожне поле має імʼя _і_ тип. Щоб створити запис, вказують імена полів і присвоюють їм значення між символами `{` і `}`. Під час створення запису всім полям обовʼязково присвоюють значення. До значень полів екземпляра запису можна звертатися через точкову нотацію.

Коли ми визначаємо або створюємо запис, кожне поле має бути або на окремому рядку, або відокремлене крапкою з комою (`;`), якщо воно на одному рядку.

```fsharp
// Define a record
type Address =
    { Street: string
      HouseNumber: int }

// Create a record
let oldAddress: Address =
    { Street = "Main Street"
      HouseNumber = 17 }

// Single-line alternative
type ConciseAddress = { Street: string; HouseNumber: int }
let conciseAddress: ConciseAddress = { Street = "Main Street"; HouseNumber = 17 }
```

Оскільки записи незмінні, після створення запису його значення полів уже не можуть змінитися. Якщо ми хочемо змінити значення запису, ключове слово `with` дозволяє створити копію наявного запису, але з новими значеннями для одного чи кількох полів.

```fsharp
// Copy the old address but change the house number
let newAddress: Address = { oldAddress with HouseNumber = 86 }
newAddress.Street      // => "Main Street"
newAddress.HouseNumber // => 86
```

Записи мають _структурну рівність_: це означає, що два екземпляри одного запису з однаковими значеннями є рівнозначними.

Окрім можливості використовувати точкову нотацію для доступу до полів запису, записи можна також _деструктурувати_ у привʼязках і в зіставленні зі зразком:

```fsharp
let myAddress: Address = { Street = "Broadway"; HouseNumber = 123 }
let { Street = myStreet; HouseNumber = myHouseNumber } = myAddress

match myAddress with
| { HouseNumber = 1 } -> printfn "First house"
| { HouseNumber = houseNumber; Street = street } -> printfn "House number %d on %s" houseNumber street
// => "House number 123 on Broadway
```
