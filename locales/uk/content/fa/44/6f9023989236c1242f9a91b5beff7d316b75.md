# Вступ

_«Дати й час - це те, чого ми вчимо малих дітей. Ну що там складного?»_

Багато програмістів припускалися цієї помилки, і наступний досвід зазвичай погано позначається на їхньому здоровʼї та щасті.

Той, хто займається нетривіальним програмуванням із датами й часом, має принаймні бути готовим розуміти потенційні проблеми та зменшувати їхній вплив.

У цьому документі ми спробуємо дати загальний огляд того, як Julia працює з датами й часом, але для подальших подробиць потрібно звертатися до [посібника][Dates].
Є також [вікіпідручник][Wikibook], пояснення якого деяким читачам можуть здатися зрозумілішими, і він містить корисну [діаграму][type-hierarchy] ієрархії типів.

## Модуль `Dates`

Більша частина базової функціональності міститься в модулі `Dates`. Він входить до типової інсталяції, але не є частиною стандартної бібліотеки.

Щоб скористатися модулем, є два варіанти:

1. Додати `import Dates`, а потім ставити `Dates.` перед кожним викликом функції.
2. Додати `using Dates`, що вносить увесь модуль у поточний простір імен (_крім кількох проблемних назв_).

```julia-repl
# option 1
julia> import Dates

julia> Dates.now()
2025-06-21T16:02:39.080

julia> now()  # wrong: need to include `Dates.` after an import
ERROR: UndefVarError: `now` not defined in `Main`


# option 2
julia> using Dates

julia> now()  # functions are now in the namespace
2025-06-21T16:03:04.161
```

Модуль `Dates` великий і складний, але він надає чотири основні види функціональності:

- `Dates.Date`, який містить день, місяць і рік, але не час доби.
- `Dates.Time`, який містить час доби, але не дату.
- `Dates.DateTime`, який поєднує дату й час.
- `Dates.Period`, який працює з інтервалами часу й дат.

Звернімо увагу, що `DateTime` зазвичай _не_ містить інформації про часовий пояс (у Python це назвали б «наївним» datetime).
Винятком є `now()`, який бере місцевий час із системного годинника й за потреби може перетворити його на UTC.

Мабуть, найчастіші потреби такі:

- Розібрати відповідний вхідний формат, щоб побудувати тип із `Dates`.
- Отримати з типу `Dates` потрібний числовий формат або формат рядка тексту (англ. string).
- Застосувати зміщення до значення `Date`, `Time` або `DateTime`.
- Обчислити інтервал між двома такими значеннями.
- Отримати поточну дату (за допомогою `today()`) та/або час (за допомогою `now()`).

~~~~exercism/note
Щоб менше відволікати увагу, більшість прикладів коду в решті цього документа припускає `using Dates` і не включає назву модуля `Dates.` у виклики функцій.
~~~~

### Формати дати й часу

Існує багато способів записувати дати й час, і вони часто залежать від культури.
Дати, записані самими числами, як-от «7/6/23», неоднозначні, заплутані й призвели до багатьох дорогих помилок у міжнародних організаціях (_автор каже це з гіркого особистого досвіду_).

Міжнародний стандарт визначено в `ISO 8601`, і він має дві головні переваги:

- Розбір швидкий і недвозначний.
- Сортування легке, бо datetime можна вважати звичайним текстом і сортувати за алфавітом.

У попередньому прикладі ми бачили, що `Date.now()` повернув `2025-06-21T16:03:04.161`.

Він складається з кількох частин:

- `YYYY-MM-DD` для частини з датою.
- `hh:mm:ss` для частини з часом.
- За бажанням після десяткової коми можуть стояти мілісекунди (або ще менша одиниця).

Інші формати рядків тексту ми розглянемо в одному з наступних розділів.

## Дати

`Dates.Date` - це відносно простий тип лише для дати, який нічого не знає про час або часові пояси.

```julia-repl
# constructor with year, month, day arguments
julia> date1 = Date(2025, 06, 23)
2025-06-23

# constructor with ISO 8601 string
julia> date2 = Date("2025-06-23")
2025-06-23

julia> date1 == date2
true

julia> typeof(date1)
Date
```

Для окремих частин дати є функції доступу, і вони утворюють пари, які розрізняються регістром.

```julia-repl
# lowercase returns an integer
julia> month(date1)
6

julia> typeof(month(date1))
Int64

# Propercase returns a Period type
julia> Month(date1)
6 months

julia> typeof(Month(date1))
Month
```

### Функції запитів

Є чимало функцій, які певною мірою розуміють календар.
У наступному прикладі показано лише кілька з них.

```julia-repl
julia> date1
2025-06-23

julia> dayofweek(date1) # 1 = Monday, 7 = Sunday
1

julia> dayname(date1)
"Monday"

julia> daysinmonth(date1)
30

julia> isleapyear(date1)
false

julia> lastdayofmonth(date1)
2025-06-30
```

## Час

`Dates.Time` - це базовий тип лише для часу.
Він нічого не знає про дати: час автоматично переходить у `Time(0, 0, 0)` опівночі.

Повний формат конструктора має такий вигляд: `Time(hour, min, sec, millisec, microsec)` або відповідний рядок за ISO 8601.

Усі параметри необовʼязкові, і типовим значенням буде `0`.

```julia-repl
julia> Time(14, 57, 25, 142)
14:57:25.142

julia> Time("14:57:25.142")
14:57:25.142

julia> Time(14, 57, 25, 142, 32)
14:57:25.142032
```

Як і для `Date`, окремі частини доступні через функції доступу:

```julia-repl
julia> minute(t) # => integer
57

julia> Minute(t) # => Period
57 minutes
```

## Дата й час

`Dates.DateTime` поєднує більшість можливостей типів `Date` і `Time`.

```julia-repl
julia> dt1 = DateTime(2025, 6, 23, 14, 57, 25, 142)
2025-06-23T14:57:25.142

# date1 and t were defined in previous examples
julia> dt2 = DateTime(date1, t)
2025-06-23T14:57:25.142
```

Типове значення параметрів року, місяця й дня - `1`, а всіх параметрів часу - `0`.

Не заплутатися в усіх цих параметрах буває непросто, тож для вхідних даних кращим може бути формат ISO.

Або ж `DateTime` можна побудувати з `Date` і `Time`, як у прикладі вище.

## Періоди

Кожен складник дати й часу має власний тип `Period`, від `Year` до `Nanosecond`, що позначає інтервал часу.
Вони особливо зручні для арифметики.

```julia-repl
julia> dt1
2025-06-23T14:57:25.142

julia> Year(21)
21 years

julia> Second(61)
61 seconds

julia> dt1 + Year(21) - Second(61)
2046-06-23T14:56:24.142

julia> Date(2025, 07, 03) - Date(2025, 04, 25)
69 days
```

Працюючи з типами `Period`, Julia намагається розумно поводитися з календарними нерівностями, як-от різна довжина місяців, і за потреби округлює.

```julia-repl
# February has fewer days than January
julia> Date(2025, 1, 31) + Month(1) 
2025-02-28
```

## Подання у вигляді рядків тексту

Раніше ми згадували стандарт ISO 8601, який для Julia є типовим поданням дати й часу під час форматування або розбору рядків тексту.

Очевидно, що багато інших форматів уживаються часто, нерідко в культурно зумовлений спосіб.
Щоб упоратися з ними, у Julia є тип `DateFormat`, який можна побудувати з рядка тексту формату довільної складності.

```julia-repl
# dateformat"" string syntax
julia> dtfmt = dateformat"d/m/y"
dateformat"d/m/y"

julia> typeof(dtfmt)
DateFormat{Symbol("d/m/y"), Tuple{Dates.DatePart{'d'}, Dates.Delim{Char, 1}, Dates.DatePart{'m'}, Dates.Delim{Char, 1}, Dates.DatePart{'y'}}}

# DateFormat constructor
julia> DateFormat("d/m/y")
dateformat"d/m/y"
```

Наведений приклад дуже простий: це лише дата у форматі день/місяць/рік, поширеному в Європі.
Показано два варіанти синтаксису, але результат однаковий.

Далі `DateFormat` можна використати для розбору будь-якого відповідного рядка тексту:

```julia-repl
julia> DateTime("14/7/2023", dtfmt)
2023-07-14T00:00:00
```

Створення `DateFormat` потребує значних накладних витрат, тож зробити цей крок лише один раз (як тут із `dtfmt`) допомагає з продуктивністю, коли ми перебираємо багато рядків тексту з датами й часом.

Формати можуть бути значно складнішими, тож подробиці можна знайти в [посібнику][dateformat].

Той самий `DateFormat` можна також використати, щоб вивести дату й час у будь-якому потрібному форматі рядка тексту, за допомогою функції [`Dates.format()`][format].

На жаль, із `format` виникає конфлікт просторів імен (принаймні станом на Julia 1.11.5), тож краще вказувати префікс `Dates.` навіть після `using Dates`.

```julia-repl
julia> dt1
2025-06-23T14:57:25.142

julia> Dates.format(dt1, dateformat"e, u d")
"Mon, Jun 23"
```

Як [зазначено в документації][wiki-format], `"e, u d"` дає скорочене текстове подання для дня тижня й місяця.

Типовим для текстового подання є англійська мова.
Можна додати й інші мови, хоча підтримка цього поки що не найкраща.
