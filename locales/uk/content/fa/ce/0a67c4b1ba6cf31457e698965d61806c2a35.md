# Instructions

Задача про вісім ферзів - класичне питання на співбесіді з програмування. На щастя, із Z3 її легко розвʼязати. Суть ось у чому: розставити 8 ферзів на шахівниці так, щоб жодні два ферзі не могли взяти один одного. У шахах ферзь може переміщатися на будь-яку кількість клітинок у будь-якому одному напрямку (уперед, назад, ліворуч, праворуч, по діагоналі). Напишіть функцію, яка повертає список кортежів Python із позиціями 8 ферзів.
