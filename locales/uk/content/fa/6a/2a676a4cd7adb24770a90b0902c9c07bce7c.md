# Встановлення

PureScript найпростіше встановити через Node.js і NPM.

Якщо на компʼютері ще не встановлено Node.js, його можна завантажити з [вебсайту Node.js](https://nodejs.org/). Коли Node.js буде встановлено й працюватиме, введіть цю команду в терміналі, щоб встановити компілятор PureScript та інструмент збірки Spago:

    npm install --global purescript spago

Більше інформації можна знайти в [репозиторії PureScript](https://github.com/purescript/purescript/blob/master/INSTALL.md).
