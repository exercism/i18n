# Вказівки

Якісь «інші» розробники працювали над проєктом радіокерованої машинки [exercise:csharp/remote-control-competition](). Нас запросили, щоб навести лад у коді.

## 1. Розділіть відповідальності між самою машинкою і системою телеметрії

Проведіть рефакторинг класу `RemoteControlCar`, щоб відокремити методи і властивості телеметрії, доступ до яких здійснюється через властивість `Telemetry`.

```csharp
var car = new RemoteControlCar();
car.Telemetry.Calibrate();
car.Telemetry.SelfTest();
car.Telemetry.ShowSponsor("Walker Industries Inc.");
car.CurrentSponsor
// => "Walker Industries Inc."
car.Telemetry.SetSpeed(100, "cps");
car.GetSpeed()
// => "100 centimeters per second"
```

## 2. Не дозвольте іншому коду надто залежати від типу `Telemetry`

Переконайтеся, що екземпляр `Telemetry` не можна створити поза областю видимості машинки.

## 3. Не дозвольте іншому коду залежати від структури `Speed`

Переконайтеся, що структуру `Speed` не можна використовувати поза областю видимості класу `RemoteControlCar`.

## 4. Не дозвольте іншому коду залежати від переліку `SpeedUnits`

Переконайтеся, що перелік `SpeedUnits` не можна використовувати поза областю видимості класу `RemoteControlCar`.
