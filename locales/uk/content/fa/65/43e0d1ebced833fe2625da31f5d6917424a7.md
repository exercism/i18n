# Для супровідників

## Допоміжний скрипт для створення тестів Fortran: create_fortran_test.py

Найпростіший спосіб створити тест для вправи - скористатися скриптом
`bin/create\_fortran\_test.py`

За допомогою цього скрипта можна створити початковий файл <exercise>\_test.f90, який потім стане шаблоном для тесту.
Зазвичай функцію «response» у згенерованому файлі доведеться замінити на правильний виклик функції.

Також зауважмо, що Fortran має проблеми зі спеціальними символами, як-от `\n` і `\t`, тож будьмо з ними особливо уважні.

### Передумови

- Робочі CMake і компілятор Fortran
- Python3.x (може вдатися змусити його працювати з Python2, але я не доклав зусиль, щоб забезпечити зворотну сумісність)
- найновіша версія https://github.com/exercism/problem-specifications.git
- git

### Робочий процес створення нового тесту

- забрати останні зміни з `exercism/problem-specifications`, напр. git clone git@github.com:exercism/problem-specifications.git
- створити нову гілку для нової вправи, напр. git checkout -b exercise-bob
- запустити цей скрипт для потрібного прикладу
- скопіювати `config/CMakeLists.txt` до каталогу вправи (для цього можна скористатися `bin/update-cmake-files`)
- реалізувати робочу вправу
- виправити потенційно проблемні тести (див., напр., exercise/bob «Test 20» і «Test 24»)
- переконатися, що команда `ctest` проходить без помилок
- скопіювати своє рішення до .meta/example.f90 і прибрати справжню реалізацію з файлу вправи, напр. bob.f90
- оновити каталоги .docs і .meta
  - cp ../problem-specifications/exercises/bob/description.md exercises/practice/bob/.docs/instructions.md
    - замінити «# Description» на «# Instructions»
  - заповнити .meta/tests.toml вручну (поки не зʼявиться автоматичний спосіб)
  - заповнити .meta/config.json вручну (поки не зʼявиться автоматичний спосіб)
    - скористатися ../problem-specifications/exercises/bob/metadata.yml
- відкрити pull request зі своїми змінами

Наприклад, для bob:

```bash
$ python bin/create_fortran_test.py -j ../problem-specifications/main/exercises/bob/canonical-data.json -t exercises/practice/bob/bob_test.f90
Namespace(json='../problem-specifications/main/exercises/bob/canonical-data.json', target='exercises/practice/bob/bob_test.f90')
Wrote : exercises/practice/bob/bob_test.f90
$ cp config/CMakeLists.txt exercises/practice/bob/.
$ cd exercises/practice/bob
$ touch bob.f90
$ mkdir build
$ cd build
$ cmake ..
$ make
$ ctest -V
```

### Зміна `CMakeLists.txt`

Коли ми змінюємо файл cmake, потрібно оновити головну копію в `config/` і за допомогою `bin/update-cmake-files` скопіювати її до всіх каталогів вправ.

## Рішення

Коли рішення готове, скопіюймо його до каталогу «.meta» як «example.f90».

Можливо, варто залишити в каталозі вправи файл із назвою вправи, а в ньому скелетну реалізацію функції або підпрограми, яка допоможе учневі.
