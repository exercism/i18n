# Тестування в командному рядку

Виконайте тести командою:

```bash
scarb cairo-test
```

Усі тести, крім першого, позначено як ігноровані. Після того, як перший тест
пройде, відкрийте файл із кодом тестів, який лежить у каталозі `tests`,
приберіть прапорець `#[ignore]` із наступного тесту й знову зробіть так, щоб
тести проходили. Кожен окремий тест - це функція з прапорцем `#[test]` над нею.
Продовжуйте, доки не пройдете всі тести.

Якщо потрібно виконати _всі_ тести, не редагуючи файл із кодом тестів,
скористайтеся:

```bash
scarb cairo-test --include-ignored
```

Щоб виконати конкретний тест, незалежно від того, ігнорований він чи ні,
наприклад `some_test`, можна скористатися:

```bash
scarb cairo-test -f some_test
```

Щоб дізнатися більше про тести в Cairo, зверніться до онлайн-[документації з тестування][cairo-tests].

[cairo-tests]: https://book.cairo-lang.org/ch10-01-how-to-write-tests.html
