# Про це

Двійкові цифри зрештою прямо відповідають транзисторам у процесорі чи оперативній памʼяті та тому, увімкнений кожен із них чи вимкнений.

Низькорівневі маніпуляції, які неформально називають «жонглюванням бітами», особливо важливі в мовах системного програмування.

Високорівневі мови, як-от Julia, зазвичай приховують більшість цих деталей.
Утім, повний набір побітових операцій [доступний][bitwise] у самій мові.

***Примітка:*** Щоб побачити зрозумілий для людини двійковий вивід у REPL, майже всі наведені нижче приклади треба обгорнути у функцію [`bitstring()`][bitstring].
Це відволікає візуально, тож більшість входжень цієї функції ми прибрали.

## Операції побітового зсуву

Типи цілих чисел, зі знаком чи без знаку, можна подати як рядок з одиниць і нулів.

```julia-repl
julia> bitstring(UInt8(5))
"00000101"
```

Побітові зсуви просто пересувають усе ліворуч або праворуч на вказану кількість позицій.
Для типів `UInt` частина бітів відпадає з одного кінця, а інший кінець заповнюється нулями:

```julia-repl
julia> ux::UInt8 = 5
5

julia> bitstring(ux)
"00000101"

julia> ux << 2 # left by 2
"00010100"

julia> ux >> 1 # right by 1
"00000010"
```

Кожен зсув ліворуч подвоює значення, а кожен зсув праворуч ділить його навпіл (з урахуванням відкидання залишку).
Це видно наочніше в десятковому записі:

```julia-repl
julia> 3 << 2
12

julia> 24 >> 3
3
```

Такі побітові зсуви працюють набагато швидше за «справжню» арифметику, тож цей прийом дуже популярний у низькорівневому програмуванні.

Із цілими числами зі знаком треба бути трохи обережнішими.

Зсуви ліворуч відносно прості:

```julia-repl
julia> sx = Int8(5)
5

julia> sx # positive integer
"00000101"

julia> sx << 2
"00010100"

julia> -sx # negative integer
"11111011"

julia> -sx << 2
"11101100"
```

Отже, зсув ліворуч додатних цілих чисел зі знаком такий самий, як і для цілих чисел без знаку.

Відʼємні значення зберігаються у формі [доповняльного коду][2complement], а це означає, що найлівіший біт дорівнює 1.
Для зсуву ліворуч це не проблема, але як заповнювати найлівіші біти під час зсуву праворуч?

```julia-repl
julia> sx >> 2 # simple for positive values!
"00000001"

julia> -sx # negative integer
"11111011"

julia> -sx >> 2 # pad with repeated sign bit
"11111110"

julia> -sx >>> 2 # pad with 0
"00111110"
```

Оператор `>>` виконує [арифметичний зсув][arithmetic], зберігаючи знаковий біт.

Оператор `>>>` виконує [логічний зсув][logical], заповнюючи нулями, ніби число без знаку.

Якщо цього все ще бракує, є також функція [`bitrotate()`][bitrotate].

## Побітова логіка

У попередньому концепті ми бачили, що оператори `&&` (логічне і), `||` (логічне або) та `!` (не) використовуються з булевими значеннями (англ. Boolean).

Є рівнозначні оператори `&` (побітове і), `|` (побітове або) та `~` (тильда, побітове не) для порівняння бітів у двох цілих числах.

```julia-repl
julia> 0b1011 & 0b0010 # bit is 1 in both numbers
"00000010"

julia> 0b1011 | 0b0010 # bit is 1 in at least one number
"00001011"

julia> ~0b1011 # flip all bits
"11110100"

julia> xor(0b1011, 0b0010) # bit is 1 in exactly one number, not both
"00001001"
```

Тут `xor()` позначає [виключне «або»][xor], використане як функція (альтернативний запис дивіться нижче).

До речі, оператори `&` і `|` також можна використовувати з булевими значеннями.
На відміну від `&&` (і) та `||` (або), у цьому разі обчислюються всі частини виразу: скороченого обчислення немає.


## Інші символи

Julia любить математику, а математики люблять загадкові символи, тож маємо ще символи, щоб побавитися.

```julia-repl
julia> 0b1011 ⊻ 0b0010 # xor() in infix notation
"00001001"

julia> 0b1011 ⊼ 0b0010 # not and
"11111101"

julia> 0b1011 ⊽ 0b0010 # not or
"11110100"
```

У редакторах, які розуміють Julia, вони вводяться як `\xor`, `\nand` і `\nor` плюс табуляція в кожному випадку.

Ці символи відомі небагатьом, навіть серед людей, які вивчали математику в університеті (автор цього концепту ніколи їх раніше не бачив).
Якщо ми хочемо їх використовувати, варто уважно вибирати, кого просити переглянути код!
