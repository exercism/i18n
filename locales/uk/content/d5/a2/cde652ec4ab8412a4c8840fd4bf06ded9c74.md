# Інструкції

Перетворімо число, подане як послідовність цифр в одній основі, на будь-яку іншу основу.

Реалізуймо загальне перетворення між основами.
Маючи число з основою **a**, подане як послідовність цифр, перетворімо його на число з основою **b**.

## Примітка

- Спробуймо реалізувати перетворення самостійно.
  Не використовуймо щось інше, що виконало б перетворення за нас.

## Про [позиційний запис][positional-notation]

У позиційному записі число з основою **b** можна розуміти як лінійну комбінацію степенів **b**.

Число 42, *з основою 10*, означає:

`(4 * 10^1) + (2 * 10^0)`

Число 101010, *з основою 2*, означає:

`(1 * 2^5) + (0 * 2^4) + (1 * 2^3) + (0 * 2^2) + (1 * 2^1) + (0 * 2^0)`

Число 1120, *з основою 3*, означає:

`(1 * 3^3) + (1 * 3^2) + (2 * 3^1) + (0 * 3^0)`

Гадаю, суть зрозуміла!

*Так. Ті три числа вище - це те саме число. Вітаємо!*
