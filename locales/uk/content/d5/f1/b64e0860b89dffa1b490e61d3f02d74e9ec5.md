# Вступ

Макрос `use` дає нам змогу швидко розширити наш модуль функціональністю, яку надає інший модуль. Коли ми застосовуємо `use` до модуля, цей модуль може вставити код у наш модуль: наприклад, визначити функції, викликати `import` чи `alias` для інших модулів або встановити атрибути модуля.

Якщо ми колись заглядали в тестові файли якихось вправ з Elixir тут, на Exercism, то, найпевніше, помітили, що всі вони починаються з `use ExUnit.Case`. Саме цей один рядок коду робить макроси `test` і `assert` доступними в тестовому модулі.

```elixir
defmodule LasagnaTest do
  use ExUnit.Case

  test "expected minutes in oven" do
    assert Lasagna.expected_minutes_in_oven() === 40
  end
end
```

## Макрос `__using__/1`

Що саме відбувається, коли ми застосовуємо `use` до модуля, визначає макрос `__using__/1` цього модуля. Він приймає один аргумент, список ключових слів з опціями, і повертає [цитований вираз][concept-ast]. Код із цього цитованого виразу вставляється в наш модуль, коли ми викликаємо `use`.

```elixir
defmodule ExUnit.Case do
  defmacro __using__(opts) do
    # some real-life ExUnit code omitted here
    quote do
      import ExUnit.Assertions
      import ExUnit.Case, only: [describe: 2, test: 1, test: 2, test: 3]
    end
  end
end
```

Опції можна передати другим аргументом, коли ми викликаємо `use`, наприклад `use ExUnit.Case, async: true`. Якщо їх не вказати явно, типовим значенням буде порожній список.

[concept-ast]: https://exercism.org/tracks/elixir/concepts/ast
