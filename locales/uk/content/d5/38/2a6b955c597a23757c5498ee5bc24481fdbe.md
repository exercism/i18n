# Докладніше

C - це статично типізована мова, що означає, що все має тип на етапі компіляції.
Вибір імені для [змінної][variable] і встановлення її типу називають оголошенням змінної.

Змінну оголошують, явно вказуючи її тип.
Імʼя змінної [має відповідати певним правилам][name-rules], наприклад починатися з літери або знака підкреслення.
Деякі імена використовувати не можна, бо вони зарезервовані [для ключових слів][reserved-keywords] або [інших ідентифікаторів][reserved-identifiers].

Встановлення або оновлення змінної відбувається через присвоєння.
Встановлення значення визначає цю змінну.
Визначення змінної також називають ініціалізацією.

```c
int foo;      // Declare an integer named var
foo = 10;     // Define the variable

int bar = 15; // Both can also be done in a single statement
```

Значення змінної можна присвоїти й оновити за допомогою [простого оператора присвоєння `=`][assignment-operator].
Після визначення тип змінної вже ніколи не змінюється.

```c
int foo = 10; // Assign initial value
foo = 25;     // Update to new value

foo = false;  // Compiler error when assigning value of a different type
```

C - це [імперативна][imperative] [процедурна][procedural] мова.
Усі обчислення виконуються як частина послідовності [інструкцій][statements], що входять до складу однієї [функції][function] або кількох функцій.

Кожна функція може мати нуль або більше [параметрів][parameters].
Під час визначення функції всі параметри та повернене значення потрібно явно типізувати.
Значення повертаються з функцій за допомогою [ключового слова `return`][return-keyword].
Типово функції мають зовнішній [клас зберігання][storage_class], тобто він існує протягом часу роботи програми й може бути видимим ззовні файлу.
Щоб цього уникнути, можна додати ключове слово `static`, яке задає внутрішню видимість.

```c
static int add(int x, int y) {
  return x + y;
}
```

У наведеному вище прикладі змінні `x` і `y` можна використовувати лише всередині функції, тобто вони мають область видимості функції.
[Область видимості][scope] - це ідея, що значення, повʼязане з іменем (елемента програми), доступне лише в тій «ділянці» коду, де його визначено.
Основні ділянки коду в C:

- файл
- функція
- блок (наприклад, усередині циклів та інших конструкцій)

Функції викликають, вказуючи імʼя функції та передаючи аргументи для кожного з її параметрів.

```c
int sum = add(1, 2);
```

C підтримує два типи [коментарів][comments].
Однорядкові коментарі починаються з `//` (починаючи з C99), а багаторядкові вставляють між `/*` та `*/`.
