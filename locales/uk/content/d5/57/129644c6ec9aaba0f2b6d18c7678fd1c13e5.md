# Інструкції

У цій вправі ми будемо працювати над планувальником зустрічей для салону краси в Нью-Йорку, який відкрився 15 вересня 2012 року.

На нас чекають чотири завдання, і всі вони стосуються дат зустрічей. Дати й час будуть використовувати один із трьох наведених нижче форматів:

- `"7/25/2019 13:45:00"`
- `"July 25, 2019 13:45:00"`
- `"Thursday, July 25, 2019 13:45:00:00"`

~~~~exercism/caution
Тести автоматично встановлять культуру `en-US`, тож нам не потрібно встановлювати чи вказувати її самостійно.
~~~~

## 1. Розберіть дату зустрічі

Реалізуйте функцію `schedule`, яка вміє розібрати текстове подання дати зустрічі у відповідний формат `DateTime`:

```fsharp
schedule "7/25/2019 13:45:00"
// => DateTime(2019, 7, 25, 13, 45, 0)
```

## 2. Перевірте, чи зустріч уже минула

Реалізуйте функцію `hasPassed`, яка приймає дату зустрічі й перевіряє, чи відбулася зустріч десь у минулому:

```fsharp
hasPassed (DateTime(1999, 12, 31, 9, 0, 0))
// => true
```

## 3. Перевірте, чи припадає зустріч на другу половину дня

Реалізуйте функцію `isAfternoonAppointment`, яка приймає дату зустрічі й перевіряє, чи припадає зустріч на другу половину дня (>= 12:00 і < 18:00):

```fsharp
isAfternoonAppointment (DateTime(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. Опишіть час і дату зустрічі

Реалізуйте функцію `description`, яка приймає дату зустрічі й повертає опис цієї дати та часу:

```fsharp
description (DateTime(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on 3/29/2019 3:00:00 PM."
```

## 5. Поверніть дату річниці

Реалізуйте функцію `anniversaryDate`, яка повертає дату річниці цього року, а саме 15 вересня:

```fsharp
anniversaryDate()
// => DateTime(2019, 9, 15, 0, 0, 0)
```
