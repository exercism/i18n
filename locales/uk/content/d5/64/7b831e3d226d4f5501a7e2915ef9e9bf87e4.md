# Вступ

Щоб створити екземпляр _класу_, потрібно викликати його _конструктор_ через оператор `new`. Конструктор - це особливий тип методу, мета якого - ініціалізувати щойно створений екземпляр. Конструктори мають такий самий вигляд, як звичайні методи, але без типу повернення й з назвою, що збігається з назвою класу.

```csharp
class Library
{
    private int books;

    public Library()
    {
        // Initialize the books field
        this.books = 10;
    }
}

// This will call the constructor
var library = new Library();
```

Як і звичайні методи, конструктори можуть мати параметри. Параметри конструктора зазвичай зберігають як (приватні) поля, щоб звертатися до них пізніше, або використовують у якомусь одноразовому обчисленні. Аргументи можна передавати конструкторам так само, як передають аргументи звичайним методам.

```csharp
class Building
{
    private int numberOfStories;
    private int totalHeight;

    public Building(int numberOfStories, double storyHeight)
    {
        this.numberOfStories = numberOfStories;
        this.totalHeight = numberOfStories * storyHeight;
    }
}

// Call a constructor with two arguments
var largeBuilding = new Building(55, 6.2)
```
