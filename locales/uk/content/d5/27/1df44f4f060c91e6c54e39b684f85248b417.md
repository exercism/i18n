# Докладніше

У F# усе, що має тип і може бути визначене, називається _значенням_. Сюди належать булеві значення (англ. Boolean), цілі числа і масиви, але також і функції. Цілі числа визначаються як одна або більше (послідовних) цифр і підтримують [типові математичні оператори][operators].

Присвоєння значення імені називається _звʼязуванням_. [Звʼязування][bindings] є незмінними, що робить їх схожими на константи в інших мовах. Звʼязування визначаються за допомогою ключового слова `let`.

Оскільки F# належить до статично типізованих мов, кожне звʼязування має тип. Зазначати тип звʼязування необовʼязково для більшості звʼязувань, адже _виведення типів_ у F# зазвичай дає змогу визначити тип на основі значення.

```fsharp
// Automatically inferred type
let fingers = 10
```

[Функції][functions] теж є звичайними звʼязуваннями, але з одним або кількома параметрами. Функція автоматично повертає свій останній вираз. Виведення типів працює і для більшості функцій: воно аналізує, з якими значеннями функцію викликають і яке значення вона повертає.

```fsharp
// Automatically inferred types for parameters and return type
let add x y = x + y
```

Щоб викликати функцію, треба вказати її назву й передати аргументи для кожного з її параметрів.

```fsharp
let five = add 2 3
```

Якщо тип звʼязування не вдається вивести, компілятор повідомить про помилку. Щоб це виправити, вкажімо тип звʼязування явно.

```fsharp
// Explicit type annotation
let fingers: int = 10

// Explicit type annotation (also for parameters)
let add (x: int) (y: int): int = x + y
```

Звʼязування у F# можна використовувати лише _після_ того, як їх визначено. Використання звʼязування до того, як його визначено, призводить до помилки компіляції.

```fsharp
// Compile error as the add binding has not yet been defined
// let seven = add 3 + 4

let add x y = x + y
```

Для визначення області видимості використовуються значущі відступи: код відступає пробілами відносно рядка, який оголошує звʼязування. Типова домовленість - використовувати для відступу чотири пробіли.

```fsharp
let toes =
    let left = 5
    let right = 5
    left + right

let multiplyPlusTwo x y =
    let product = x * y
    product + 2

// Trying to access the left, right or product bindings
// here would result in a compile error
```

Звʼязування у F# (зокрема функції) зазвичай організовано в модулі. Модуль обʼєднує споріднену функціональність і визначається за допомогою ключового слова `module`. Визначення модуля має передувати його звʼязуванням:

```fsharp
module Calculator

let pi = 3.14

let add x y = x + y
```

F# підтримує два типи [коментарів][comments]. Однорядкові коментарі починаються з `//`, а багаторядкові розміщують між `(*` і `*)`.
