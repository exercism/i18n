# Вступ

## Записи

Запис - це колекція полів (які можуть мати різні типи), що повʼязані між собою. Щоб визначити запис, використовують ключове слово `type`. Поля запису визначають між символами `{` і `}`, і кожне поле має назву _і_ тип. Щоб створити запис, потрібно вказати назви полів і присвоїти їм значення між символами `{` і `}`. Під час створення запису всім полям потрібно присвоїти значення. До значень полів екземпляра запису можна звертатися за допомогою точкової нотації.

Коли ми визначаємо або створюємо запис, кожне поле має бути або на окремому рядку, або відокремлене крапками з комою (`;`), якщо весь запис розміщено в одному рядку.

```fsharp
// Define a record
type Address =
    { Street: string
      HouseNumber: int }

// Create a record
let oldAddress: Address =
    { Street = "Main Street"
      HouseNumber = 17 }

// Single-line alternative
type ConciseAddress = { Street: string; HouseNumber: int }
let conciseAddress: ConciseAddress = { Street = "Main Street"; HouseNumber = 17 }
```

Оскільки записи незмінні, після створення запису його значення полів більше не можуть змінитися. Якщо ми хочемо змінити значення запису, ключове слово `with` дає змогу створити копію наявного запису, але з новими значеннями для одного або кількох полів.

```fsharp
// Copy the old address but change the house number
let newAddress: Address = { oldAddress with HouseNumber = 86 }
newAddress.Street      // => "Main Street"
newAddress.HouseNumber // => 86
```

Записи мають _структурну рівність_, а це означає, що два екземпляри одного запису з однаковими значеннями еквівалентні.

Окрім можливості використовувати точкову нотацію для доступу до полів запису, записи також можна _деконструювати_ у привʼязках і зіставленні зі зразком:

```fsharp
let myAddress: Address = { Street = "Broadway"; HouseNumber = 123 }
let { Street = myStreet; HouseNumber = myHouseNumber } = myAddress

match myAddress with
| { HouseNumber = 1 } -> printfn "First house"
| { HouseNumber = houseNumber; Street = street } -> printfn "House number %d on %s" houseNumber street
// => "House number 123 on Broadway
```
