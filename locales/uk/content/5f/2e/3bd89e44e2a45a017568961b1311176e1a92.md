# Встановлення

## Linux

Bash як оболонка GNU присутній у будь-якій системі GNU/Linux.
У BSD та інших похідних UNIX її, найімовірніше, доведеться встановлювати самостійно.
Якщо йдеться про BSD, AIX або Linux, який не містить bash, варто звернутися до документації операційної системи щодо встановлення пакетів, які не входять до базової поставки.

У графічному інтерфейсі, який ми обрали, пошукаймо застосунок із назвою «Terminal»: він може бути в розділі «Administrative/System Tools».

Щоб перевірити доступну версію Bash, з командного рядка або в терміналі виконайте:

    echo $BASH_VERSION

Якщо наша оболонка це `bash`, вона має показати щось таке:

    4.4.19(1)-release

Більше нічого робити не потрібно: на цьому етапі bash уже має бути встановлений і доступний у нашому PATH, адже це наша поточна оболонка.

Якщо наша оболонка не bash, немає жодних причин її змінювати.
Ми можемо писати й запускати скрипти bash, навіть не перебуваючи в оболонці bash.

Щоб перевірити встановлену версію bash, виконайте:

```plain
bash --version
```

Вона покаже щось таке:

```
GNU bash, version 4.4.19(1)-release (x86_64-pc-linux-gnu)
Copyright (C) 2016 Free Software Foundation, Inc.
License GPLv3+: GNU GPL version 3 or later <http://gnu.org/licenses/gpl.html>

This is free software; you are free to change and redistribute it.
There is NO WARRANTY, to the extent permitted by law.
```

Якщо цього не сталося, можливо, bash у нас не встановлено.
Тоді його варто встановити за допомогою менеджера пакетів нашого дистрибутива.

## Windows

Для Windows 10 можна встановити [WSL](https://docs.microsoft.com/en-us/windows/wsl/about).
Це встановлює повноцінний (точніше, без графічних компонентів) дистрибутив Linux, який працює у Windows нативно.

Або ж можна встановити:

* [Cygwin](https://cygwin.com/)
* [git for windows](https://gitforwindows.org/)
* [MinGW](http://mingw.org/)
* повноцінний дистрибутив Linux у [віртуальній машині](https://docs.microsoft.com/en-us/virtualization/hyper-v-on-windows/about/)

## MacOS

Для Apple OSX:

* відкрийте Finder,
* відкрийте теку Applications,
* відкрийте теку Utilities,
* нарешті, відкрийте застосунок `Terminal`.

Зауважмо, що встановлена в MacOS версія bash дуже стара, версія 3.2.
Це повʼязано з тим, що (i) новіші версії bash ліцензовано під GPLv3, і (ii) Apple не хоче, щоб її змушували виконувати умови цієї ліцензії.
Крім того, Apple дала зрозуміти, що bash поступово зникне з MacOS: стандартну оболонку для входу нещодавно [змінили з bash на zsh](https://support.apple.com/en-us/HT208050).

Щоб отримати актуальну версію bash на Mac:

1. встановіть [Homebrew](https://brew.sh)
1. у терміналі введіть: `brew install bash`

Це встановлює актуальну версію bash, як на мене, у `/usr/local/bin/bash` (щоб стандартний bash системи не було перезаписано, адже інші інструменти можуть покладатися на /bin/bash).

Якщо ми хочемо, щоб bash із Homebrew запускався, коли ми вводимо `bash`, відредагуймо файл ~/.bash_profile (або ~/.profile) так, щоб /usr/local/bin стояв у PATH *раніше* за /bin:

    PATH=/usr/local/bin:$PATH
