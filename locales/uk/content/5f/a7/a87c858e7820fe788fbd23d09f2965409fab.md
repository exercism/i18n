# Тести

## Написання коду

Пишіть код у `src/lib.cairo`.
До вправ додається файл-заготовка `src/lib.cairo`, який покаже сигнатури коду, який потрібно написати.

Для більшості вправ краще писати весь код в одному файлі `src/lib.cairo`.
Щоб розбити рішення на кілька файлів, зверніться до [розділу про модулі][chapter-modules] у книзі The Cairo Book.

[chapter-modules]: https://book.cairo-lang.org/ch07-02-defining-modules-to-control-scope.html

## Запуск тестів

Щоб запустити тести, спочатку змініть робочу директорію на директорію вправи, яку потрібно протестувати:

```bash
cd path/to/exercise
```

А потім виконайте таку команду:

```bash
scarb cairo-test
```

Типово ввімкнено лише перший тест.
Коли настане час проходити наступний тест, приберіть прапорець `ignore` з наступного тесту (`#[ignore]`).

Щоб запустити всі тести, зокрема й пропущені, можна прибрати прапорець `ignore` з усіх тестів або просто виконати:

```bash
scarb cairo-test --include-ignored
```

Сміливо пишіть якомога менше коду, щоб тести проходили.
Невдалі тести підкажуть, що написати далі.

Оскільки Cairo перевіряє весь код під час компіляції, тести можуть не компілюватися, доки не буде написано потрібний код.
Навіть `ignore`-тести перевіряються під час компіляції.
Можна [закоментувати][comments] тести, які не компілюються, почавши кожен рядок з `//`.
А коли настане час попрацювати над цим тестом, його можна розкоментувати.
У Cairo також є спеціальний макрос `panic!()`, який можна застосувати на незавершених ділянках коду, щоб програма скомпілювалася.

[comments]: https://book.cairo-lang.org/ch02-04-comments.html
