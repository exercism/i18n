# Про

[Тернарні оператори][ternary-operators] дозволяють визначати умови if у виразах, а не в блоках інструкцій. Це перегукується з підходами функціонального програмування і часто може робити код виразнішим і менш схильним до помилок.

Тернарний оператор поєднує три вирази: умову, за якою йде вираз, який слід обчислити й повернути, якщо умова правда (частина `if`, яку вводить `?`), та вираз, який слід обчислити й повернути, якщо умова неправда (частина `else`, яку вводить `:`).

```csharp
int a = 3, b = 4;
int max = a > b ? a : b;
// => 4
```
