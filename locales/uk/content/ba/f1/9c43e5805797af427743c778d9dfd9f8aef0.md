# Інструкції

Ми подаємо репліки для шкільної вистави. Сценічний менеджер хоче, щоб стандартні репліки були записані, аби будь-хто міг керувати пультом.

У нас чотири завдання, і всі вони в класі `STAGE_DIRECTIONS`.

## 1. Оголосіть початок

Поверніть репліку, якою відкривається вистава.

```sather
STAGE_DIRECTIONS::opening_line
-- => "The curtain rises."
```

## 2. Оголосіть антракт

Поверніть репліку, яку подають у перерві.

```sather
STAGE_DIRECTIONS::interval_line
-- => "Interval. Fifteen minutes."
```

## 3. Оголосіть кінець

Поверніть репліку, якою завершується вистава.

```sather
STAGE_DIRECTIONS::closing_line
-- => "The curtain falls."
```

## 4. Подайте останню репліку

Остання репліка збігається з тією, якою завершується вистава. Замість того, щоб писати текст удруге, викличте процедуру, яку вже написали.

```sather
STAGE_DIRECTIONS::final_cue
-- => "The curtain falls."
```
