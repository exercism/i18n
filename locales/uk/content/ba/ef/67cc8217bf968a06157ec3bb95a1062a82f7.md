# Підказки

## 1. Створення нового масиву

- У Common Lisp є [функція з досить промовистою назвою][hyper-list] для створення _LIST_.

## 2. Додаємо елементи до масиву

- Щоб додати щось на початок масиву, ідіоматично *CONS*труювати новий масив, де елемент стає `car`, а масив - `cdr`. У Hyperspec можна знайти [сторінку][hyper-cons], яка описує цю функцію.

## 3. Що йде далі в масиві?

- У Common Lisp є функція загального призначення, щоб дістати елемент [за будь-яким індексом масиву][hyper-nth].
- Також є [кілька допоміжних функцій][hyper-first-tenth] для доступу до індексів, менших за 11.
- Індекси масивів починаються з нуля.

## 4. Видалення елемента з масиву

- Ідіоматичний спосіб видалити перший елемент масиву - скористатися функцією, яка відокремлює `cdr` масиву від `car` масиву. У Hyperspec можна знайти [сторінку][hyper-rest], яка описує одну з таких функцій.

## 5. Більші масиви з менших масивів

- У Common Lisp є функція [спеціально для додавання одного масиву на початок іншого][hyper-append].

## 6. Наскільки довший?

- У Common Lisp є [функція з очевидною назвою][hyper-length], щоб отримати довжину масиву.
