# Вступ

## Структури

C# `struct`-и тісно повʼязані з `class`-ами. Вони мають стан і поведінку. Вони мають конструктори, які приймають аргументи, екземпляри можна присвоювати, перевіряти на рівність і зберігати в колекціях.

```csharp
enum Unit
{
    Kg,
    Lb
}
struct Weight
{
    private double count;
    private Unit unit;

    public Weight(double count, Unit unit)
    {
        this.count = count;
        this.unit = unit;
    }

    public override string ToString()
    {
        return count.ToString() + unit.ToString();
    }
}

new Weight(77.5, Unit.Kg).ToString();
// => "77.6Kg"
```
