# Вступ

Нагадаємо, що програма `jq` - це _конвеєр виразів_.
**Присвоєння змінній** підпорядковується такому правилу: _присвоєння змінній_ - це вираз, який має такий вигляд:

```jq
... | expr as $varname | ...
```

## Фільтр виводить те саме, що отримав на вхід

Як і _вираз ідентичності_ `.`, _присвоєння змінній_ виводить те саме, що отримує на вхід.
Присвоєння значення змінній - це побічний ефект.

Приклад, який показує, що `.` після присвоєння збігається з початковими вхідними даними:

```sh
$ jq -c -n '42 | (. * 2) as $double | [., $double]'
[42,84]
```

## Область видимості змінної

Область видимості змінної «лексична»: змінна залишається видимою до кінця конвеєра.
Змінні, визначені у функціях (до функцій ми дійдемо згодом), «локальні» для своєї функції.

## Імена змінних

Імʼя змінної має починатися з `$`.
Решта імені змінної - це **ідентифікатор**: він починається з літери або підкреслення, за якими йдуть літери, цифри або підкреслення.

## Деструктуризаційне присвоєння

З посібника:

> Кілька змінних можна оголосити за допомогою одного виразу `as`, надавши шаблон, який _відповідає структурі вхідних даних_ (це називається «деструктуризацією»).

Приклади:

```jq
[1, 2, 3] as [$a, $b, $c]
| [$a, $b, $c]     # => [1, 2, 3]
```

```jq
{"foo": "bar", "len": [10, 20]} as {foo: $f, len: [$h, $w]}
| [$f, $h, $w]     # => ["bar", 10, 20]
```

Якщо імʼя змінної збігається з _ключем обʼєкта_, можна скористатися скороченням:

```jq
{"x": 4, "y": 7} as {$x, $y}
| [$x, $y]         # => [4, 7]
```

```jq
{"foo": "bar", "len": [10, 20]} as {$foo, $len}
| [$foo, $len]     # => ["bar", [10, 20]]
```

## Константи

Як видно з прикладу вище, змінні зручні для зберігання констант.
Краще дати константі імʼя, ніж залишати в коді «магічні числа».

## Часто змінні не потрібні

Часто код читається краще, якщо обійтися без змінних.

Розглянемо обчислення середнього значення масиву чисел

```jq
[2, 4, 8, 7]
| add as $sum
| length as $len
| $sum / $len
```

порівняймо з

```jq
[2, 4, 8, 7] | add / length
```

Це підкреслює одну з найпотужніших рис `jq`: вхідні дані фільтра доступні _кожному_ підвиразу:

- вхідний масив `[2,4,8,7]` передається у `add` (який додає числа, застосовуючи оператор `+` до всіх елементів)
- _паралельно_ `[2,4,8,7]` також передається у `length`
- коли ці підвирази завершуються, їхні результати діляться між собою, повертаючи середнє значення чисел вхідного масиву.

## Оператори `jq`, які знадобляться для навчальної вправи

### Альтернативний оператор: `//`

Вираз `a // b` виводить `b`, якщо `a` дорівнює неправді або `null`; інакше він виводить `a`.
Коли ми присвоюємо значення змінній, це дуже зручно для надання типового значення:

```jq
(.input.theAnswer // 42) as $answer | ...
```

### Арифметичні оператори

- `+`, `-`, `*` - звичайні оператори додавання, віднімання та множення чисел.
