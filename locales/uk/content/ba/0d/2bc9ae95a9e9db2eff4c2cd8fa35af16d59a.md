# Підказки

## Загальне

- Скрізь використовується тип `LIST{STR}`, тобто список рядків тексту (англ. string). Записуйте його повністю всюди, де блокнот передається чи повертається.

## 1. Відкрийте справу

- `#LIST{STR}` створює порожній список. Функція не приймає аргументів і повертає `LIST{STR}`.

## 2. Занотуйте зачіпку

- `append` - це функція, яка нічого не повертає, тож у неї теж немає типу повернення: `add_clue(notes : LIST{STR}, clue : STR) is`.
- Ніде не присвоюйте результат `append`. На відміну від `FMAP::insert`, результату тут немає.

## 3. Скільки зачіпок?

- `.size`.

## 4. Вилучіть одну

- `remove_index` приймає позицію. Типу повернення знову немає.

## 5. Прочитайте справу

- Цикл по `notes.elt!` і `FSTR`, як у `rehearsal-script`.
- `"; "` стоїть перед кожною зачіпкою, крім першої, і саме завдяки цьому порожній блокнот дає порожній рядок тексту без спеціальної обробки.
