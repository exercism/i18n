# Запуск тестів

Щоб запустити тест для певної вправи, перейдімо в її теку за допомогою `cd` і виконаймо такі команди:

```bash 
box task run TestRunner
# Or start up a test watcher that will rerun when files change
box task run TestRunner --:watcher
```

Тести використовують бібліотеку TestBox, яка підтримує стилі тестування xUnit і BDD. Усі набори тестів написано в [стилі BDD](https://testbox.ortusbooks.com/content/primers/bdd/specs.html), який використовує замикання для опису тестових специфікацій. Про встановлення TestBox турбуватися не доведеться. Про це подбає CLI-засіб запуску тестів. Підключення до інтернету потрібне лише під час першого запуску. Докладніше про це можна прочитати тут:

[https://testbox.ortusbooks.com](https://testbox.ortusbooks.com)
