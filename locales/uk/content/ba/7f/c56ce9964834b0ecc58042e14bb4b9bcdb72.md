# Вступ

Багато мов мають спосіб, як-от `null` або `none`, щоб позначити неіснуюче значення.
Оскільки R створено для роботи з великими обсягами (часто неохайних) даних, у ньому є кілька форм нічого.

Загальна мета - позначати пропущені або підозрілі значення, коли ми з ними стикаємося, а потім продовжувати роботу, не викликаючи винятку.

## NULL

Якщо значення справді не існує, його позначають як `NULL`. Це, ймовірно, найближче до того, як поводяться C або Python.

```R
v <- c() # zero-length vector
v
#> NULL
is.null(v)
#> [1] TRUE
```

У багатьох контекстах значення `NULL` просто ігноруються:

```R
c(2, 3, NULL, 5)
#> [1] 2 3 5
```

## NA

Коли значення існує, але ми не знаємо, яке воно, використовують `NA`. Наприклад, коли рахують транспорт, що рухається дорогою, живі спостерігачі можуть захворіти, а автоматичні датчики можуть вийти з ладу, але потік машин не припиняється.

```R
v <- c(1, 2, NA, 4, 5)
v
#> [1]  1  2 NA 4  5
is.na(v) # test for data gaps
#> [1] FALSE FALSE  TRUE FALSE FALSE
```

Отже, `NA` слугує заповнювачем, який попереджає людей, що їм треба вирішити, як із цим поводитися.

## Порожні вектори

Хоч як це дивно, у R немає стандартного способу перевірити порожнечу, хоча деякі сторонні пакети реалізують власні функції, як-от `is.empty()`.

Навіть створити порожній вектор не зовсім очевидно.
У попередньому розділі ми бачили, що `c()` без аргументів повертає `NULL`, а не вектор.

```R
is.vector(c())
#> [1] FALSE
```

Функції, як-от `logical()` або `integer()`, приймають аргумент, який задає потрібну довжину, а вона може дорівнювати нулю.

```R
z <- logical(0)
is.vector(z)
#> [1] TRUE
length(z)
#> [1] 0
```

Ми також можемо створити вектор, а потім видалити кожен його елемент, як описано в [концепції векторів][concept-vectors].
У результаті отримуємо вектор довжини 0 відповідного типу.

```R
v <- 5
v[-1]  # delete the first element
#> numeric(0)
```

[concept-vectors]: https://exercism.org/tracks/r/concepts/vectors
