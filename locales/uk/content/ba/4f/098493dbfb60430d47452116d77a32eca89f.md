# Вступ

У Python інструкції [`if`][if statement], `elif` (_скорочення від «else and if»_) та `else` використовуються, щоб [керувати потоком][control flow tools] виконання та ухвалювати рішення в програмі.
На відміну від багатьох інших мов програмування, версії Python 3.9 і нижчі не мають формальної конструкції case-switch, натомість використовують кілька інструкцій `elif` для схожої мети.

Python 3.10 додає варіант конструкції case-switch під назвою `pattern matching`, який ми розглянемо окремо в іншій концепції.

Умовні конструкції використовують вирази, які мають зводитися до `True` або `False`: або повертаючи `bool` напряму, або обчислюючи [«truthy» чи «falsy»][truth value testing].


```python
x = 10
y = 5

# The comparison '>' returns the bool 'True',
# so the statement is printed.
if x > y:
    print("x is greater than y")
...
>>> x is greater than y
```

У парі з `if` необовʼязковий блок коду `else` виконається тоді, коли початкова умова `if` дає `False`:

```python
x = 5
y = 10

# The comparison '>' here returns the bool False,
# so the 'else' block is executed instead of the 'if' block.
if x > y:
    print("x is greater than y")
else:
    print("y is greater than x")
...
>>> y is greater than x
```

`elif` дає змогу зробити кілька перевірок і розгалужень.

```python
x = 5
y = 10
z = 20

# The elif statement allows for the checking of more conditions.
if x > y > z:
    print("x is greater than y and z")
elif y > x > z:
    print("y is greater than x and z")
else:
    print("z is greater than x and y")
...
>>> z is greater than x and y
```

[Булеві операції][boolean operations] (англ. Boolean) та [порівняння][comparisons] можна поєднувати з умовними конструкціями для складніших перевірок:

```python
>>> def classic_fizzbuzz(number):
...     if number % 3 == 0 and number % 5 == 0:
...         say = 'FizzBuzz!'
...     elif number % 5 == 0:
...         say = 'Buzz!'
...     elif number % 3 == 0:
...         say = 'Fizz!'
...     else:
...         say = str(number)
...     return say

>>> classic_fizzbuzz(15)
'FizzBuzz!'

>>> classic_fizzbuzz(13)
'13'
```
