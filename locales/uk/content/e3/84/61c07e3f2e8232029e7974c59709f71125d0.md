# Вступ

Java - мова зі статичною типізацією: це означає, що тип змінної відомий під час компіляції.
Присвоєння значення імені називається визначенням змінної.
Змінна визначається явним зазначенням її типу.

```java
int explicitVar = 10;
```

Оновлення значення змінної виконується за допомогою оператора `=`.
Тут `=` не означає математичну рівність.
Він просто присвоює значення змінній.
Після визначення тип змінної вже ніколи не може змінитися.

```java
int count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning a different type
// count = false;
```

Java - це [обʼєктно-орієнтована мова][object-oriented-programming], і вона вимагає, щоб усі функції були визначені в _класі_.
Для визначення класу використовується ключове слово `class`.

```java
class Calculator {
    // ...
}
```

Функція всередині класу називається _методом_.
Кожен метод може мати нуль або більше параметрів.
Усі параметри повинні мати явно вказаний тип, виведення типів для параметрів не існує.
Так само потрібно явно вказати тип поверненого значення.
Значення повертаються з методів за допомогою ключового слова `return`.
Щоб метод можна було викликати з інших класів, потрібно додати модифікатор доступу `public`.

```java
class Calculator {
    public int add(int x, int y) {
        return x + y;
    }
}
```

Щоб викликати метод, потрібно вказати назву його класу та методу й передати аргументи для кожного параметра методу.

```java
int sum = new Calculator().add(1, 2);  // here the  "add" method has been called to perform the task of addition
```

Область видимості в Java визначається між символами `{` і `}`.

Java підтримує два типи коментарів.
Однорядкові коментарі починаються з `//`, а багаторядкові вставляються між `/*` і `*/`.

[object-oriented-programming]: https://docs.oracle.com/javase/tutorial/java/javaOO/index.html
