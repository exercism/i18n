# Навчання

Exercism пропонує вправи та зворотний звʼязок, але тим, хто вперше вивчає Common Lisp, буває важко одразу взятися до справи.
Ці ресурси допоможуть почати:

* [A Road to Common Lisp][road-to-cl], допис у блозі про те, як одна людина йшла до Common Lisp, і про її думки щодо того, як із нього почати
* [Practical Common Lisp][practical-cl], повна книга для вивчення Common Lisp, доступна безкоштовно онлайн (а також у друкованому вигляді)
* [Common Lisp Cookbook][cl-cookbook]
* [Cliki.net Getting Start Started Page][cliki-getting-started]
* [Wikibooks book of Common Lisp, First steps][wikibooks-cl-first-steps]
  від різних дописувачів
* [Awesome Common Lisp Learning][awesome-cl]

Також у межах цього треку Common Lisp на Exercism варто переглянути [Важливі ресурси][track-resources].
