# Вступ

У Kotlin класи використовують, щоб інкапсулювати дані та поведінку.
Клас оголошують за допомогою ключового слова `class`.
Наприклад:

```kotlin
class Car
```

Екземпляр класу створюють, викликавши клас.

```kotlin
val instance = Car()
```

## Властивості

У наведених вище прикладах клас `Car` оголошено без жодної властивості.
Властивості класу можна оголосити в тілі, між `{}`, використовуючи `var` для змінюваних властивостей і `val` для незмінних.
Наприклад:

```kotlin
class Car {
    // color is mutable
    var color = "red"

    // year is immutable
    val year = 2025
}
```

Або ж властивості можна визначити в конструкторі, який їх приймає.

## Конструктори

У Kotlin є два типи конструкторів: первинний і вторинний.
Первинний конструктор оголошують у тому самому рядку, що й оголошення класу.
Наприклад:

```kotlin
class Car constructor(var color : String = "red", val year : Int = 2025) {
    // ...
}
```

Ключове слово `constructor` можна пропустити, якщо немає ані анотацій, ані модифікаторів видимості:

```kotlin
class Car(var color : String = "red", val year : Int = 2025) {
    // ...
}
```

~~~~exercism/note
Kotlin дозволяє визначати клас із тілом, якщо воно містить лише властивості, тож фігурні дужки `{}` не потрібні:

```kotlin
class Car (var color : String = "red", val year : Int = 2025)
```
~~~~

Клас може мати лише один первинний конструктор.
Вторинні конструктори - це додаткові конструктори, які можна додати, оголосивши їх у тілі класу за допомогою ключового слова `constructor`.
Наприклад:

```kotlin
class Car constructor(var color : String = "red", val year : Int = 2025) {

    // This constructor allows the year to be provided as a String
    constructor(color : String = "red", yearText : String) : this(color, yearText.toIntOrNull() ?: 0)
}
```

Вторинні конструктори повинні викликати первинний конструктор через `this`.

## Блоки ініціалізації

Первинний конструктор задає властивості класу.
Якщо під час створення обʼєкта потрібно зробити більше, можна використати блоки `init`, щоб виконати додаткові дії.

```kotlin
class Car constructor(var color: String = "red", val year : Int = 2025) {
    init {
        println("Car is ${color}, made in ${year}")
    }
}
```

## Функції

Функції можна визначати в тілі класу.
Наприклад:

```kotlin
class Car (var color : String = "red", val year : Int = 2025) {
    fun repaint(newColor : String) {
        color = newColor
    }
}
```

## Видимість

Властивості та функції можуть бути `private`, `public`, `internal` або `protected`.

- `private` доступні лише всередині класу
- `protected` доступні елементам усередині класу, а також будь-яким підкласам
- `internal` доступні в межах того самого модуля
- `public` доступні іншим компонентам, які використовують клас

Наприклад:

```kotlin
class Car {
    private val color: String
    public val year: Int
    internal val model: String
    protected val brand: String

    private fun drive() {
        // ...
    }

    internal fun start() {
        // ...
    }

    protected fun stop() {
        // ...
    }

    public fun make() {
        // ...
    }
}
```
