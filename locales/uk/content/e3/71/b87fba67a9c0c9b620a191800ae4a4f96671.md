# Підказки

## Загальне

- Прочитайте про використання бібліотек Erlang у [офіційному посібнику зі швидкого старту][getting-started-erlang-libraries], зокрема про [форматування рядків тексту (англ. string)][getting-started-formatted-text-output].

## 1. Згенерувати випадкову планету

- Використайте наданий атрибут модуля з масивом літер, які позначають планетарні класи.
- Є [вбудована функція][enum-random] для випадкового вибору елемента з масиву.

## 2. Згенерувати випадковий реєстраційний номер зорельота

- Є [вбудована функція][enum-random] для випадкового вибору елемента з діапазону.

## 3. Згенерувати випадкову зоряну дату

- У Elixir немає функції, яка повертала б випадкове число з плаваючою комою.
- Є [вбудована функція Erlang][erl-rand-uniform], яка повертає випадкове число з плаваючою комою x, де `0.0 <= x < 1.0`.
- Якщо `x` належить діапазону `0.0 <= x < 1.0`, але потрібне число з іншого діапазону `a <= x < b`, можна зсунути діапазон x, помноживши його на ширину діапазону (`b - a`) і додавши початок діапазону (`a`). Тобто: `x * (b - a) + a`.

## 4. Відформатувати зоряну дату

- У Elixir немає функції, яка могла б за один крок відформатувати число з плаваючою комою як рядок тексту із заданою точністю.
- Є [вбудована функція Erlang][erl-io-lib-format], яка приймає рядок формату й масив даних і повертає charlist.
- Є [вбудована функція][to-string], яка перетворює charlist на рядок тексту.
- Рядок формату цієї функції містить керівні послідовності.
- Керівна послідовність починається з `~` і має вигляд `~F.P.PadModC`, де `F` означає ширину вихідних даних, `P` означає точність, `Pad` означає символ заповнення, `Mod` означає модифікатор керівної послідовності, а `C` означає тип керівної послідовності.
- Щоб відформатувати число з плаваючою комою із потрібною точністю, достатньо керівної послідовності з виглядом `~.PC`.
- Тип керівної послідовності для чисел з плаваючою комою позначається як `f`.
- Отже, потрібний рядок формату має такий вигляд: `~.1f`.
