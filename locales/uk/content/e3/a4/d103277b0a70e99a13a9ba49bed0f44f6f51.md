# Вступ

*Комбінаторика* - це галузь математики, яка займається підрахунком і переліком способів вибрати чи впорядкувати набір елементів. Словник [`math.combinatorics`][math.combinatorics] у Factor охоплює два базові питання:

- **Комбінації** - варіанти вибору, у яких порядок *не* має значення.
- **Перестановки** - варіанти впорядкування, у яких порядок *має* значення.

Для кожного питання є *лічильне* слово, яке повертає число, і слово *переліку*, яке повертає самі вибірки, а також потоковий варіант із префіксом `each-`, який викликає quotation для кожного з них:

```
nCk              ( n k -- m )              ! count of k-combinations
nPk              ( n k -- m )              ! count of k-permutations
all-combinations ( seq k -- combinations )
all-permutations ( seq -- permutations )
each-combination ( seq k quot -- )
each-permutation ( seq quot -- )
```

```factor
USING: math.combinatorics prettyprint ;

5 2 nCk .                        ! => 10
{ 1 2 3 } 2 all-combinations .   ! => { { 1 2 } { 1 3 } { 2 3 } }
{ 1 2 } all-permutations .       ! => { { 1 2 } { 2 1 } }
```
