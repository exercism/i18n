# Вступ

## Протоколи

Протоколи дають змогу досягти поліморфізму в Elixir, коли ми хочемо, щоб поведінка змінювалася залежно від типу даних.

Протоколи визначаються за допомогою `defprotocol` і містять один або кілька заголовків функцій.

```elixir
defprotocol Reversible do
  def reverse(term)
end
```

Протоколи можна реалізувати за допомогою `defimpl`.

```elixir
defimpl Reversible, for: List do
  def reverse(term) do
    Enum.reverse(term)
  end
end
```

Протокол можна реалізувати для будь-якого наявного типу даних Elixir або для структури.

Коли викликають функцію протоколу, відповідну реалізацію автоматично обирають на основі типу першого аргументу.
