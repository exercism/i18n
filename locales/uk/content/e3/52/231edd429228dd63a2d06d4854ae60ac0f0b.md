# Встановлення

## Цільова версія

Тестування в цьому треку використовує Docker-образ `alpine:3.24.1`, який станом на вересень 2026 року використовує `sqlite3 version 3.53.4`.
Ми прагнемо, щоб інструменти, які надає цей трек, працювали на найновішому випуску Ubuntu LTS.
Хоча в користувачів можуть бути встановлені новіші версії, варто знати, що деякі можливості можуть не працювати з нашим засобом запуску тестів.
Можливості можна порівняти в [історії версій SQLite][version-history].

## Windows

Щоб встановити SQLite у Windows, виконайте такі кроки:

1. Завантажте скомпільовані бінарні файли для Windows з [офіційної сторінки завантаження][sqlite-download].
2. Розпакуйте завантажений ZIP-файл у вибрану теку.
   Наприклад, `C:\Program Files\sqlite3`.
3. Додайте теку, що містить `sqlite3.exe`, до системної змінної середовища PATH.
   Процес трохи відрізняється для кожної версії Windows, але цю інформацію легко знайти.
   Наприклад, [інструкції для Windows 11][windows-11-install] та [Windows 10][windows-10-install].

## macOS

На macOS SQLite встановлено заздалегідь.
Однак, якщо потрібна новіша версія, можна скористатися [Homebrew][homebrew]:

```bash
brew install sqlite
```

## Ubuntu / Debian

На системах Ubuntu і Debian SQLite можна встановити за допомогою apt:

```bash
sudo apt install sqlite3
```

## CentOS / Fedora / RHEL

На системах CentOS, Fedora і Red Hat SQLite можна встановити за допомогою yum або dnf:

```bash
sudo yum install sqlite3
# OR
sudo dnf install sqlite3
```

## Arch Linux

На Arch Linux SQLite можна встановити за допомогою pacman:

```bash
sudo pacman -S sqlite
```
