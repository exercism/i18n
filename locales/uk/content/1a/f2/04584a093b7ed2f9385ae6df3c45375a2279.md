# Інструкції

У цій вправі ми будемо писати код, щоб відстежувати масив мов програмування, які хочемо вивчити на Exercism.
У нас шість завдань, і всі вони повʼязані з роботою з масивами.

## 1. Створити новий масив

Щоб відстежувати мови, які ми хочемо вивчити, нам потрібно створити новий масив.
Визначте константу `newList`, яка містить новий, порожній масив.

```elm
newList
    --> []
```

## 2. Визначити наявний масив

Зараз у нас є аркуш паперу з переліком мов, які ми хочемо вивчити: Elm, Clojure і Haskell.
Визначте константу `existingList`, щоб представити цей масив.

```elm
existingList
    --> [ "Elm", "Clojure", "Haskell" ]
```

## 3. Додати нову мову до масиву

Досліджуючи Exercism і знаходячи цікавіші мови, ми хочемо додати їх до свого масиву.
Реалізуйте функцію `addLanguage`, щоб додати нову мову на початок масиву.

```elm
addLanguage "TypeScript" [ "JavaScript", "CoffeeScript" ]
    --> [ "TypeScript", "JavaScript", "CoffeeScript" ]
```

## 4. Порахувати мови в масиві

Порахувати мови вручну незручно.
Реалізуйте функцію `countLanguages`, щоб порахувати кількість мов у масиві.

```elm
countLanguages [ "C#", "Racket", "Rust", "Ruby" ]
    --> 4
```

## 5. Обернути масив

У якийсь момент ми усвідомлюємо, що наш масив насправді впорядковано у зворотному порядку!
Реалізуйте функцію `reverseList`, щоб обернути масив.

```elm
reverseList [ "Prolog", "C", "Idris", "Assembly" ]
    --> [ "Assembly", "Idris", "C", "Prolog" ]
```

## 6. Перевірити, чи масив захопливий

Хоча ми любимо всі мови, Elm посідає особливе місце в нашому серці.
Тож масив мов викликає в нас справжнє захоплення, якщо:

- Перший елемент масиву - Elm.
- Або другий елемент масиву - Elm, і масив містить три мови або менше.

Реалізуйте функцію `excitingList`, щоб перевірити, чи масив мов захопливий:

```elm
excitingList [ "Nim", "Elm" ]
    --> True
```
