# Підказки

## Загальне

- `MACRO:` міститься в [`macros`][macros]. Будівельні блоки лежать у `kernel` (`dup`, `curry`), `sequences` (`append`, `concat`, `<repetition>`, `map`) та `quotations` (`>quotation`).
- Тіло макросу має залишити на стеку **один quotation**. Якщо тіло створює масив коду, його треба завершити `>quotation`.
- Щоб перевірити хід думок, виконаймо слова тіла на літералі в listener і подивімося на quotation, який отримаємо назад: це має бути прямолінійний код із рядка «compiles to» завдання.

## 1. Двічі

- Ви отримуєте `[ A ]`, а хочете `[ A A ]`. Зробімо копію і зʼєднаймо їх: `dup append`.

## 2. N повторень

- Ви отримуєте `[ A ] n`, а хочете `n` копій, зʼєднаних докупи.
- `<repetition>` будує копії, але вона має ефект `( length elt -- repetition )`: лічильник має бути зверху, тож спершу `swap`.
- Потім розплющмо і перетворімо: `swap <repetition> concat >quotation`.

  ```factor
  ! stack: [ 1 + ] 3
  swap <repetition>     ! 3 copies of [ 1 + ]
  concat >quotation     ! => [ 1 + 1 + 1 + ]
  ```

## 3. Складання багатьох

- Ви вже отримуєте масив quotation; треба лише розплющити його в один. Усе тіло складається з `concat >quotation`.

## 4. Розгорнута ітерація

Ви отримуєте послідовність і quotation, наприклад `{ 10 20 30 } [ + ]`, а хочете `[ 10 + 20 + 30 + ]`. Побудуймо це за три кроки.

**Один елемент.** Вбудувати елемент у quotation - саме це робить `curry`:

```factor
10 [ + ] curry .   ! => [ 10 + ]
```

**Кожен елемент.** Хочеться застосувати до цього `map` по послідовності, але `map` дає quotation-перетворювачу лише один вхід (елемент), тоді як `[ + ]` теж має бути під рукою щоразу. Тож спершу вбудуймо `[ + ]` у quotation-перетворювач, знову ж таки через `curry`:

```factor
! stack: { 10 20 30 } [ + ]
[ curry ] curry    ! => { 10 20 30 } [ [ + ] curry ]
map                ! runs  10 [ + ] curry,  20 [ + ] curry, …
                   ! => { [ 10 + ] [ 20 + ] [ 30 + ] }
```

`[ curry ] curry` читається як «покласти маленький quotation `[ curry ]`, а потім укаррити в нього `[ + ]`», що дає `[ [ + ] curry ]`. Застосування цього до елемента `e` виконує `e [ + ] curry`, тобто `[ e + ]`.

**Зʼєднаймо їх.** Той самий фінал, що й у решті завдань:

```factor
concat >quotation  ! => [ 10 + 20 + 30 + ]
```

- Усе тіло: `[ curry ] curry map concat >quotation`.
