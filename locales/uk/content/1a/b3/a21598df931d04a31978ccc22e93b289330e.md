# Тести

  ## Короткий огляд

  1. Внесіть зміни у файл `<myFileName>.u`
  2. Збережіть файл `<myFileName>.u`
  3. Якщо файл проходить перевірку типів, виконайте команди UCM `add` або `update`
    * Якщо файл не проходить перевірку типів, змінюйте код у файлі `<myFileName>.u`, доки він не скомпілюється. Не забудьте виконати `update` для своїх функцій після змін! 
  4. Виконайте команду `load <myFileName>.test.u` у CLI UCM, щоб додати тести в область видимості та запустити їх

  ## Покроковий розбір

  Якщо ми працюємо над завданням Exercism у командному рядку, то, найімовірніше, реалізовуватимемо своє рішення в каталозі, названому на честь відповідної вправи. Наприклад, якщо вправа називається `hello-world`, потрібно відкрити `ucm` з командного рядка, попередньо виконавши `cd` у `~/exercism/unison/hello-world`. Внесімо зміни до реалізації у файлі `hello.u`, а коли будемо задоволені своєю реалізацією, введімо команду `add` або `update` в Unison codebase manager CLI (UCM), щоб додати свою роботу з файлу до кодової бази.

  Файл, який містить тести для кожної вправи, має суфікс `.test.u`. Варто скористатися командою `load` в UCM, щоб додати тести в область видимості та запустити їх. Команда `load` приймає як аргумент шлях до файлу. Ось як це може мати вигляд для вправи hello world:

  ```
  .> load hello.test.u
  ```

  Ми побачимо повідомлення від UCM про терміни, додані в область видимості, і, що важливо, результат запуску тесту:

  ```

    ⍟ These new definitions are ok to `add`:

      hello.test : Test.Test
      tests      : [Result]

  Now evaluating any watch expressions (lines starting with
  `>`)... Ctrl+C cancels.


    6 | test> tests = runAll [hello.test]

    🚫 FAILED
  ```

  Припустімо, тести не пройшли з першого разу. Повернімося до редагування файлу `myExercise.u`, і після збереження ми зможемо виконати `update`

  ```
  I found and typechecked these definitions in ~/Exercism/unison/hello-world/hello.u. If you do an
  `add` or `update`, here's how your codebase would change:

    ⍟ These names already exist. You can `update` them to your new definition:

      hello : Text

  .> update

  ⍟ I've updated these names to your new definition:

    hello : Text
  ```

  Далі можемо знову завантажити тести й подивитися, чи щось змінилося!

  ```
  .> load hello.test.u
    Now evaluating any watch expressions (lines starting with `>`)... Ctrl+C cancels.


    6 | test> tests = runAll [hello.test]

    ✅ Passed : Passed 1 tests.
  ```
