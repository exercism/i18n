# Вступ

## Загальні відомості

Рядком тексту (англ. string) називають фрагмент тексту між лапками.
Будь-яка версія R, яку зараз підтримують, кодує рядки тексту в UTF-8, тому більшість мов світу можна підтримувати.

```R
mystring <- "some text"
mystring
#> [1] "some text"
typeof(mystring)
#> [1] "character"
```

На жаль, ця термінологія може заплутати програмістів, знайомих з іншими мовами.

Хоча `type` тут дорівнює `character`, R не розрізняє одну літеру (у багатьох інших мовах її називають `char`, але _не_ в R) і довгий рядок тексту.
І те, і те є одним елементом, який можна брати в одинарні `' '` або подвійні `" "` лапки взаємозамінно.

Посібник зі стилю радить використовувати подвійні лапки, крім випадків, коли всередині рядка тексту потрібні подвійні лапки без екранування.

```R
str2 <- 'String with "quotes"'  # convenience format
str2
#> [1] "String with \"quotes\""    # standard format
```

Отже, `character vector` - це вектор рядків тексту, у якому кожен рядок тексту є окремим елементом.

```R
s <- c("some", "strings")
s
#> [1] "some"    "strings"
length(s)
#> [1] 2
length(s[1])  # the number of vector elements, not the string length
#> [1] 1

nchar(s[1])  # the number of characters in the string "some"
#> [1] 4
```

У наведеному вище прикладі `length(s[1])` дає те саме, що `length("some")`: кількість _елементів вектора_, а не _довжину рядка тексту_.

Маніпулювати окремим рядком тексту, очевидно, можна, як у прикладі вище з `nchar()`, але для цього потрібні спеціальні функції, про які йтиметься далі.

### Функції для рядків тексту

У базовому R _можливо_ майже все, але багато програмістів вважають підтримку роботи з рядками тексту досить обмеженою і заплутаною.

На щастя, є пакети `tidyverse`, значно інтуїтивніші, гнучкіші та узгодженіші між собою.

### Базовий R

Досі залишається багато застарілого коду, який використовує функції для рядків тексту старого зразка.
Це стосується більшості рішень спільноти на Exercism.

Крім того, для невеликих завдань буває корисно скористатися вбудованими функціями замість того, щоб імпортувати велику бібліотеку.
Супровідники треку R зазвичай роблять саме так, коли пишуть зразкові рішення для перевірки вправ.

Тож знання старих підходів усе ще варте вивчення.

#### `nchar`

Повертає кількість символів у рядку тексту.

```R
nchar("string")
#> [1] 6

nchar("Hrōðgār") # a person in Beowulf, written in Old English
#> [1] 7
```

Тема того, що означає «символ» (_а вона складна!_), виходить за межі цієї статті.
Звернімо увагу лише на кілька моментів у прикладах вище:

- Хоча рядки тексту в R усередині реалізовано мовою C, вони не завершуються `\0` (це додало б 1 до довжини).
- Багатобайтові символи Unicode обробляються так, як ми й сподіваємося. «Hrōðgār» містить 7 символів (їх також називають «рунами» або «кодовими точками»), але для зберігання потребує 10 байтів.

#### `paste` і `paste0`

Поєднує довільну кількість рядків тексту в один рядок тексту.

За потреби для `paste` можна вказати роздільник: типовим значенням є пробіл.

`paste0(v)` рівнозначне `paste(v, sep = "")`.

```R
paste("bits", "of", "a", "string")
#> [1] "bits of a string"
paste0("bits", "of", "a", "string")
#> [1] "bitsofastring"
```

#### `sprintf`

Для точнішого контролю над складанням рядків тексту R запозичує функцію `sprintf` з C (і з кількох пізніших мов: Вікіпедія [наводить][wiki-printf-ports] близько 30).

```R
r <- 5.3
pi <- 3.14159
sprintf("A circle of radius %.1f has area %.2f", r, pi * r^2)
#> [1] "A circle of radius 5.3 has area 88.25"
```

#### `trimws`

Провідні та/або кінцеві пробільні символи можна прибрати за допомогою `trimws()`:

```R
s <- "    messy string   "
trimws(s)
#> [1] "messy string"
```

Є параметр `which = "left"` (або «right»), щоб не обрізати обидва кінці.

#### `substr`

Працює з одним рядком тексту й повертає підрядок між двома межами (включно).

```R
substr("Exercism", 5, 7)
#> [1] "cis"
```

#### `strsplit`

Розбиває рядок тексту на список R за вказаним роздільником.
Роздільник обовʼязковий (типового значення немає), але може бути порожнім рядком тексту.

```R
strsplit("R, Python, Julia", ", ")
[[1]]
#> [1] "R"      "Python" "Julia" 

strsplit("Exercism", "")
[[1]]
#> [1] "E" "x" "e" "r" "c" "i" "s" "m"
```

Списки розглянемо в окремому [концепті][concept-lists].
Якщо ми ще не дійшли до цієї частини силабусу, достатньо поки знати, що функція `unlist()` у цьому випадку перетворює список на вектор.

```R
unlist(strsplit("Exercism", ""))
#> [1] "E" "x" "e" "r" "c" "i" "s" "m"
```

### Tidyverse

Якщо бути поблажливими, можна сказати, що функції для рядків тексту старого зразка не є найкращим, що може запропонувати R (_є й менш поблажливі думки_).

Щоб виправити становище, бібліотека `stringr` розробляється з 2009 року й зараз є ключовою частиною збірки Tidyverse.

Імпортуймо її у свій простір імен за допомогою `library(stringr)` або `library(tidyverse)`.

Серед ключових можливостей:

- Усі назви функцій мають префікс `str_` і покликані робити своє призначення зрозумілим.
- Порядок аргументів намагається бути самопослідовним: вхідні дані стоять першим аргументом.
- Вхідні дані можуть бути від одного рядка тексту до складних структур даних. Функції намагаються пристосуватися й зробити найрозумніше.

Як і всі пакети Tidyverse, `stringr` має добру документацію, яку зазвичай пишуть автори пакета.

- [Довідковий вебсайт][ref-stringr]
- [Шпаргалка][cheat-stringr]
- [Розділ][book-strings] у книжці «R for Data Science».

#### Відступ: короткий вступ до конвеєрів

Використання конвеєрів `|>` для зʼєднання функцій докладніше розглянемо в інших частинах силабусу.

Поки що корисно знати, що:

- Результат зліва від конвеєра стає першим аргументом функції справа (причому «справа» ігнорує необовʼязкові перенесення рядків).
- Будь-які решта аргументів можна додати у виклик функції.
- У R передавати через конвеєр треба у _виклик_ функції, а не просто в її _назву_, тому дужки потрібні завжди (_це відрізняє R від деяких інших мов_).

Приклад нижче показує синтаксис.
Окремі функції розглянемо пізніше.

```R
library(stringr)

"Monday-25-February" |> 
  str_split("-") |>     
  unlist() |>               # [1] "Monday"   "25"       "February"
  str_sub(1, 3) |>          # [1] "Mon" "25"  "Feb"
  str_to_upper() |>         # [1] "MON" "25"  "FEB"
  str_flatten(collapse = ", ")
#> [1] "MON, 25, FEB"
```

#### Керування довжиною

`str_length` рахує кодові точки (подібно до `nchars`).

Різні інші функції працюють із пробільними символами, зокрема `str_trim()` і `str_squish()`.
Часто це важливе очищення на початку будь-якого проєкту з аналізу даних.

```R
# The first 3 kernels in JuPyteR notebooks:
str_length(c("Julia", "Python", "R"))           #> [1] 1 6 5
#> [1] 5 6 1
str_pad(c("Julia", "Python", "R"), 8, "right")  # add spaces if necessary
#> [1] "Julia   " "Python  " "R       "

str_trim("Julia    Python    R    ")   # remove leading & trailing whitespace
#> [1] "Julia    Python    R"
str_squish("Julia   Python  R    ")  # trim, collapse multiple spaces 
#> [1] "Julia Python R"
```

#### Вибір підрядків

Функція `str_sub(string, start, end)` повертає підрядок від `start` до `end` (включно), а `str_sub_all()` може працювати з кількома рядками тексту.

Тут багато гнучкості.
`start` і `end` типово вказують на перший і останній символ відповідно.
Вони можуть бути векторами індексів.
На приємну відміну від індексації векторів, відʼємні значення відраховуються від кінця рядка тексту, як у Python.

```R
s <- "abcdefgh"
str_sub(s, 2, 4)
#> [1] "bcd"
str_sub(s, 5)
#> [1] "efgh"
str_sub(s, -3, -2)
#> [1] "fg"
str_sub(s, c(1, 4), c(2, 5))
#> [1] "ab" "de"
str_sub(s, c(1, 4, 6), c(2, 5, -1))
#> [1] "ab"  "de"  "fgh"

s |> str_sub(2, 4) # these functions are designed for pipes
#> [1] "bcd"
```

#### Зʼєднання рядків тексту

`str_flatten` перетворює вектор символів на один рядок тексту.
Аргумент `collapse` вставляється між елементами, а його типовим значенням є `""`.

```R
c("R", "Julia", "Python") |> str_flatten()
#> [1] "RJuliaPython"
c("R", "Julia", "Python") |> str_flatten(collapse = " - ")
#> [1] "R - Julia - Python"
```

`str_c` перетворює кілька векторів символів на один вектор символів, за потреби повторюючи елементи коротших.

```R
str_c(LETTERS[1:8], 1:8, sep = ":")
#> [1] "A:1" "B:2" "C:3" "D:4" "E:5" "F:6" "G:7" "H:8"
```

`str_glue` приносить у R просту інтерполяцію рядків тексту.
Вирази у фігурних дужках `{ }` обчислюються, а замість них підставляється їхній текстовий вигляд.

```R
r <- 5.3
pi <- 3.14159
str_glue("A circle of radius {r} has area {pi * r^2}")
A circle of radius 5.3 has area 88.2472631
```

#### Розбиття рядків тексту

Дуже часто R використовують, щоб привести неохайні дані до узгодженого формату для аналізу.
Щоб допомогти з цим, є кілька способів розбити текст на підрядки.
Більшість із них виходять за межі цієї статті.

`str_split_1` найпростіша: перетворює один рядок тексту на вектор частин, розбиваючи його за вказаною закономірністю (типової закономірності немає).

```R
s <- "R Julia Python"
str_split_1(s, " ")
#> [1] "R"      "Julia"  "Python"
```

#### Змінювання рядків тексту

Деякі мови (переважно європейські) розрізняють ВЕЛИКІ та малі літери.
У `stringr` є набір функцій, щоб перетворювати їх одні на інші у спосіб, доречний для відповідної локалі:

- `str_to_lower()`
- `str_to_upper()`
- `str_to_title()` : першу літеру кожного слова робить великою
- `str_to_sentence()` : першу літеру речення робить великою

```R
str_to_upper("elixir")    # defaults to locale = "en"
#> [1] "ELIXIR"
str_to_upper("ελληνικά")  # infers Greek
#> [1] "ΕΛΛΗΝΙΚΆ"

str_to_title("the cat sat on the mat")
#> [1] "The Cat Sat On The Mat"
str_to_sentence("the cat sat on the mat")
#> [1] "The cat sat on the mat"
```

Для заміни підрядків на основі зіставлення із закономірністю `str_replace()` змінює перше входження закономірності, а `str_replace_all()` - усі входження.

Для заміни підрядків на основі індексації символів існує форма присвоєння для str_sub().

```R
 s <- "abcde"
str_sub(s, 3, 4) <- "yz"
s
#> [1] "abyze"
```
