# Налагодження

Щоб полегшити налагодження, можна скористатися тим, що весь вивід у консоль перехоплюється й показується у вікні результатів тестів.
Ми можемо вивести будь-яке значення, передавши його до `@show`.

`@show` показує вираз і його результат, повертаючи при цьому цей самий результат.

```julia
@show uppercase("hello") # HELLO will be shown as debug output
```

```julia-repl
julia> function f(a, b)
           @show a b
           return (@show a^b) / 1000
       end
f (generic function with 1 method)

julia> f(3, 5)
a = 3
b = 5
a ^ b = 243
0.243
```

Також можна скористатися [`println`](https://docs.julialang.org/en/v1/base/io-network/#Base.println) або будь-яким іншим методом, який записує вивід до [`stdout`](https://en.wikipedia.org/wiki/Standard_streams#Standard_output_(stdout)).
