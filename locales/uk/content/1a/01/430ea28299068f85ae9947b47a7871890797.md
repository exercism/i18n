# Не порівнюйте булеві значення з true чи false

Порівнювати булеві значення (англ. Boolean) з true чи false - зайве.
Використання `==` і так дає булеве значення, тож порівнювати його з іншим жорстко заданим булевим значенням немає потреби.
Якщо потрібно отримати протилежне булеве значення, використайте оператор `!`.

```crystal
# Rather than:
some_bool == true
some_bool == false

# Consider:
some_bool
!some_bool
```
