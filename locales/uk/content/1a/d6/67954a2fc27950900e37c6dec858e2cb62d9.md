# Детальніше

Щоб створити екземпляр _класу_, ми викликаємо його [_конструктор_][constructors] за допомогою [оператор `new`][new]. Конструктор - це особливий тип методу, мета якого - ініціалізувати щойно створений екземпляр. [Конструктори мають вигляд звичайних методів][constructor-syntax], але без типу повернення і з назвою, що збігається з назвою класу.

```csharp
class Library
{
    private books;

    public Library()
    {
        this.books = 10;
    }
}

// This will call the constructor
var library = new Library();
```

Як і звичайні методи, конструктори можуть мати параметри. Параметри конструктора зазвичай зберігаються як (приватні) [поля][fields], щоб мати до них доступ пізніше, або використовуються в якомусь одноразовому обчисленні. Аргументи можна передавати конструкторам так само, як аргументи передаються звичайним методам.

```csharp
class Building
{
    private int numberOfStories;
    private int totalHeight;

    public Building(int numberOfStories, double storyHeight)
    {
        this.numberOfStories = numberOfStories;
        this.totalHeight = numberOfStories * storyHeight;
    }
}

// Call a constructor with two arguments
var largeBuilding = new Building(55, 6.2);
```

Вказувати конструктор необовʼязково. Якщо конструктор не вказано, компілятор генерує [конструктор без параметрів][parameterless-constructors]:

```csharp
class Elevator
{
}

// This will call the (empty) generated constructor
var elevator = new Elevator();
```

Якщо поля мають початкове значення, компілятор створить код, у якому присвоєння фактично відбувається всередині конструктора. Наступні оголошення класів, таким чином, є функціонально еквівалентними:

```csharp
class UsingFieldInitialization
{
    private int players = 5;
}

class UsingConstructorInitialization
{
    private int players;

    public UsingConstructorInitialization()
    {
        players = 5;
    }
}
```
