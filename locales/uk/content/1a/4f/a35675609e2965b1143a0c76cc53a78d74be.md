# Вступ
## Switch

Конструкція [switch][switch] дозволяє порівнювати значення з кількома можливими значеннями, які можуть збігтися.
Вона дає змогу писати лаконічніший код, ніж із кількома конструкціями `else-if`.
Конструкція `switch` починається з ключового слова `switch`, за яким іде значення для порівняння.
Далі варіанти описують за допомогою ключового слова `case`, за яким указують значення для порівняння.
Ключове слово `default` використовують, щоб задати типовий варіант, коли жоден з варіантів не збігається.
Як і конструкції `else-if`, конструкції `switch` виконують лише блок коду, повʼязаний із першим варіантом, що збігся.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Розгляньмо такий приклад:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

Натомість це можна записати так:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## Цикли `while`

[Цикл while][while-loops] - це інструкція керування потоком, яка дозволяє виконувати код, поки певна умова істинна.
Swift надає два різновиди циклів `while`: цикл `while` і цикл `repeat-while`.
Умова циклу `while` перевіряється перед виконанням тіла циклу; якщо умова хибна, тіло циклу не виконається взагалі.
Цикли `while` у Swift мають таку структуру:

```swift
while <#condition#> {
  <#code#>
}
```

Тут цикл виконуватиметься, доки count більше за 0, і надрукує числа 2, 1 та «Liftoff!».

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

[Цикл repeat-while][while-loops] схожий на цикл `while`, але умова перевіряється після виконання тіла циклу.
Це означає, що тіло циклу виконується принаймні один раз, навіть якщо умова хибна.
Цикли `repeat-while` у Swift мають таку структуру:

```swift
repeat {
  <#code#>
} while <#condition#>
```

Тут цикл виконається лише один раз, оскільки умова хибна.
Оскільки це цикл `repeat-while`, тіло циклу виконається один раз, перш ніж перевірять умову.

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```

## Передача керування

У Swift є набір інструкцій, які змінюють звичний потік керування циклами.
Їх називають інструкціями передачі керування.
Ми вже бачили `return`; у цьому концепті ми познайомимося з іншими, серед яких `continue`, `break` і мітки.
У цьому концепті ми не розглядаємо `fallthrough`, але про нього можна прочитати в [книзі про Swift][fallthrough].

### Continue

Іноді потрібно достроково перейти до наступної ітерації циклу, не виконавши решту інструкцій поточної ітерації.
Для цього використовують ключове слово `continue`.
Коли виконується `continue`, цикл переходить до наступної перевірки, щоб визначити, чи можна виконати наступну ітерацію: тобто до умови `while` в циклах `while` і `repeat-while` або до перевірки, чи є в послідовності ще один елемент, у циклах `for-in`.

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

### Break

Break використовують, щоб достроково перервати цикл.
Коли виконується `break`, цикл негайно завершується, і програма продовжує з першої інструкції після циклу.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

### Мітки

Коли цикли вкладені, іноді потрібно використати `break` або `continue`, щоб вийти із зовнішніх циклів, які містять цикл, де використано ці `break` або `continue`, чи перезапустити їх.
У таких випадках можна скористатися мітками, щоб указати цикл, з якого треба вийти або який треба перезапустити.
Цикл можна позначити міткою, поставивши імʼя та двокрапку перед `while`, `repeat` або `for`, які починають цикл.

Щоб побачити, як працюють мітки, розгляньмо такий цикл.

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```
