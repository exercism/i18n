# Вступ

## Вкладені типи

Типи C# можна визначати в межах області видимості класу або структури. Зовнішній тип відіграє роль своєрідного простору імен. Доступ до типу відбувається через зовнішній тип за допомогою синтаксису з крапкою.

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

Ми можемо задавати рівні доступу для вкладених типів.

Приватні члени зовнішнього типу перебувають в області видимості членів вкладеного типу, але не навпаки.
