# Інструкції

Порт Палермо - це жвава гавань, куди прибуває і звідки вирушає безліч кораблів.
Уже давно тут діє ручна система обліку кораблів, які наразі перебувають у гавані.
Ця система дуже схильна до помилок, тож начальник гавані вирішив замінити її на компʼютеризовану систему.

Начальник гавані найняв нас, щоб ми впровадили нову систему.
Система має працювати з ідентифікаторами кораблів, а також пунктів призначення.

## 1. Створіть ідентифікатор порту

Перше, що потрібно зробити, - створити ідентифікатор для порту Палермо.
Ідентифікатор складається з перших чотирьох літер назви порту, записаних великими літерами.

Визначте константу `Port::IDENTIFIER` як символ зі значенням `:PALE`.
    
```ruby
Port::IDENTIFIER 
# => :PALE
```

## 2. Отримайте ідентифікатори для інших портів

Програма також має працювати з іншими портами, тож потрібно створити ідентифікатори і для них.
Порт хотів би, щоб система була автоматизованою, а оскільки порти використовують різні правила найменування, ідентифікатори слід генерувати з назви порту.
Ідентифікатор складається з перших чотирьох літер назви порту, записаних великими літерами.

Визначте метод `Port.get_identifier`, який приймає рядок тексту (англ. string) як аргумент і повертає ідентифікатор цього порту як символ.

```ruby
Port.get_identifier("Hamburg") 
# => :HAMB
```

## 3. Визначте, до якого терміналу має пришвартуватися корабель

Порт має два термінали, і система має визначати, до якого терміналу має пришвартуватися корабель.
Термінал визначається ідентифікатором корабля.

Ідентифікатор складається з 2 частин: перша - це 3 великі літери, які вказують, який вантаж везе корабель, а далі 3 цифри, унікальний ідентифікатор корабля.

Якщо ідентифікатор корабля містить **OIL** або **GAS**, корабель має пришвартуватися до терміналу **A**.
Інакше корабель має пришвартуватися до терміналу **B**. 

Визначте метод `Port.get_terminal`, який приймає символ як аргумент - ідентифікатор корабля.
Метод має повертати термінал як символ.

```ruby
Port.get_terminal(:OIL123)
# => :A
```
