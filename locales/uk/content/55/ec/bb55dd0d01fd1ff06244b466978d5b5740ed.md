# Підказки

## Загальне

- `disposable` міститься в `destructors`; узагальнені слова протоколу
  потоків містяться в `io`; `<string-reader>` (його використовують тести)
  міститься в `io.streams.string`.
- Оголошення `TUPLE: x < y ...` змушує `x` успадковувати слоти `y`.
  `disposable` додає прапорець `disposed` і реєструє кортеж у фреймворку
  деструкторів, коли його створюють через `new-disposable`.

## 1. Визначте стрічку

- Конструктор: `tape new-disposable swap >>wire ;`. `swap` потрібен для
  того, щоб дріт опинився нижче щойно створеної стрічки, звідки його
  візьме `>>wire`.

## 2. Приєднайте домішок вхідного потоку

- Один рядок на верхньому рівні, після оголошення `TUPLE:`.

## 3. Прочитайте один символ Морзе

- Найпростіша форма - невеликий цикл: прочитати байт, перевірити його,
  повернути, якщо це символ Морзе або `f`, інакше прочитати наступний.
- Символьний літерал записують так: `CHAR: .`. Пробіл - це `CHAR: \s`.
- `member?` для невеликого масиву цілком підходить:
  `B{ CHAR: . CHAR: - CHAR: \s } member?`.
- Найпростіша конструкція керування: цикл `while`, який читає, доки не
  отримає символ Морзе або `f`, разом із завершальним `dup`, щоб передати
  результат тому, хто викликав.

## 4. Делегуйте тип елемента

- Метод в один рядок: `wire>> stream-element-type`.

## 5. Приберіть за собою

- Та сама форма: `wire>> dispose`.
- `dispose*` не потрібно викликати самостійно, достатньо викликати
  `dispose` для дроту. Завдання фреймворку - подбати про те, щоб
  `dispose*` виконався лише один раз.
