# Масиви

Масиви в PHP - це впорядковані мапи.
Мапа - це структура даних, яка зіставляє ключ зі значенням.
Масиви універсальні: з ними можна працювати як з лінійним масивом (як у `C` чи `Java`), списком [вектором], хеш-таблицею, словником, колекцією, стеком або чергою.

Ключ необовʼязковий, але якщо його вказано, він має бути або `int`, або `string`.
Коли ключ не вказано, PHP типово використовує цілочисельні ключі в порядку зростання, починаючи з `0`.

```php
$no_keys = ["my", "first", "array"];
$integer_keys = [0 => "my", 1 => "first", 2 => "array"];

$no_keys == $integer_keys // => equal returns true
$no_keys === $integer_keys // => strictly equal returns true
```

Масив може зберігати значення всіх типів.
Кожне значення може мати інший тип.

```php
$my_arr = [
  1,
  "second",
  new \DateTimeImmutable()
];
```

## Використання масивів

Масиви можна оголосити літералом (записати прямо в коді, як це зроблено вище) або створити й опрацьовувати за допомогою функцій.

```php
$my_empty_arr = [];

// or
$my_empty_arr = array(); // => []

// or
$letters = mb_str_split("Hello"); // => ["H", "e", "l", "l", "o"] 
```

Отримувати, присвоювати й додавати значення можна за допомогою оператора індексу:

```php
$prime_numbers = [2, 3, 5, 6];

$prime_numbers[3] = 7; // replace 6 with 7

$prime_numbers[] = 11; // array now contains [2, 3, 5, 7, 11]
```

Перебирати масив можна за допомогою foreach:

```php
$names = ["Ani", "Jack", "Rami"]

// Iterate just the values
foreach ($names as $name) {
  echo $name;
}

// Iterate keys and values
foreach ($names as $index => $name) {
  echo "$index => $name";
}
```
