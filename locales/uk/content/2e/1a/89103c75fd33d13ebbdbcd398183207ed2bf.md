# Робочий процес configlet

Робочий процес configlet використовує [інструмент configlet](/docs/building/configlet), щоб перевірити, чи правильно структуровані (конфігураційні) файли треку, як синтаксично, так і семантично.
Для цього він запускає [`configlet lint`](/docs/building/configlet/lint).

## Увімкнення перевірки форматування файлів

Треки можуть використовувати [`configlet fmt`](/docs/building/configlet/format), щоб форматувати різні конфігураційні файли треку.
Цю саму команду можна також використати, щоб перевірити, чи всі конфігураційні файли відформатовано правильно.

Робочий процес `configlet` підтримує перевірку того, чи правильно відформатовано конфігураційні файли, але це необовʼязково й типово вимкнено.
Щоб увімкнути перевірку форматування конфігураційних файлів, виконайте такі кроки:

1. Створіть файл `.github/org-wide-files-config.toml` з таким вмістом

```toml
[configlet]
fmt = true
```

2. Після того як цей файл буде злито в `main`, автоматично відкриється PR, який змінить робочий процес `configlet.yml` так:

```diff
  jobs:
    configlet:
      uses: exercism/github-actions/.github/workflows/configlet.yml@main
+     with:
+       fmt: true
```

3. Після злиття цього PR робочий процес `configlet` також перевірятиме форматування конфігураційних файлів треку.

## Джерело

Робочий процес визначено у файлі `.github/workflows/configlet.yml`.
