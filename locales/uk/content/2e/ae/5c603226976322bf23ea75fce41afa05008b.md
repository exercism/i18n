# Додаток до інструкцій

## Підказки

Треба реалізувати функції `decode` та `encode`, які декодують і кодують `String` за допомогою шифру Атбаш.
Можна скористатися наданою сигнатурою, якщо є сумніви щодо типів, але хай вона не обмежує творчості.

Ця вправа працює з текстовими даними. З історичних причин тип `String` у Haskell є синонімом `[Char]`, тобто масиву символів. Для ефективнішої роботи з текстовими даними можна використати тип `Text`.

Як необовʼязкове розширення до цієї вправи, можна

- почитати про [типи рядків тексту (англ. string)](https://haskell-lang.org/tutorial/string-types) у Haskell.
- додати `- text` до списку залежностей у package.yaml.
- імпортувати `Data.Text` [у такий спосіб](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- використовувати тип `Text`, наприклад `decode :: Text -> Text`, і звертатися до комбінаторів `Data.Text` як, наприклад, `T.pack`.
- пошукати документацію для [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html).
- замінити всі входження `String` на `Text` у Atbash.hs, тобто:

```haskell
decode :: Text -> Text
decode cipherText = ...

encode :: Text -> Text
encode plainText = ...
```

Ця частина цілком необовʼязкова.
