# Інструкції

У цій вправі ми будемо писати код, щоб відстежувати масив мов програмування, які хочемо вивчати на Exercism.

На нас чекає шість завдань, і всі вони повʼязані з роботою з масивами.

## 1. Створити новий масив

Щоб відстежувати мови, які ми хочемо вивчати, нам потрібно створити новий масив. Визначмо функцію `new_list`, яка повертає новий порожній масив.

```gleam
new_list()
// -> []
```

## 2. Визначити наявний масив

Зараз у нас є аркуш паперу з переліком мов, які ми хочемо вивчати: Gleam, Go і TypeScript. Визначмо функцію `existing_list`, яка повертає цей масив.

```gleam
existing_list()
// -> ["Gleam", "Go", "TypeScript"]
```

## 3. Додати нову мову до масиву

Досліджуючи Exercism і знаходячи цікавіші мови, ми хочемо додавати їх до свого масиву. Реалізуймо функцію `add_language`, щоб додавати нову мову на початок масиву.

```gleam
add_language(["OCaml", "Elixir"], "Scheme")
// -> ["Scheme", "OCaml", "Elixir"]
```

## 4. Порахувати мови в масиві

Рахувати мови по одній незручно. Реалізуймо функцію `count_languages`, щоб порахувати кількість мов у масиві.

```gleam
count_languages(["jq", "Elm", "Rust", "Kotlin"])
// -> 4
```

## 5. Перевернути масив

У якийсь момент ми усвідомлюємо, що наш масив насправді впорядковано у зворотному порядку! Реалізуймо функцію `reverse_list`, щоб перевернути масив.

```gleam
reverse_list(["Python", "Julia", "Idris", "COBOL"])
// -> ["COBOL", "Idris", "Julia", "Python"]
```

## 6. Перевірити, чи масив захопливий

Хоча ми любимо всі мови, Gleam посідає особливе місце в нашому серці. Тому масив мов викликає в нас справжнє захоплення, якщо:

- Першою в масиві стоїть мова Gleam.
- Другою в масиві стоїть мова Gleam, і масив містить або дві, або три мови.

Реалізуймо функцію `exciting_list`, щоб перевірити, чи масив мов захопливий:

```gleam
exciting_list(["Lua", "Gleam"])
// -> True
```
