# Вступ

Хоча модифікатор `readonly` забороняє перезаписувати значення або посилання в полі, він аж ніяк не захищає члени типу посилання.

```csharp
readonly List<int> ints = new List<int>();

void Foo()
{
    ints.Add(1);    // ok
    ints = new List<int>(); // fails to compile
}
```

Щоб захистити всі члени типу посилання, можна зробити поля `readonly`, а автоматичні властивості оголосити без аксесора `set`.

Бібліотека базових класів (BCL) надає деякі версії колекцій лише для читання, коли потрібно зупинити оновлення членів колекції. Вони надаються у вигляді обгорток:

- `ReadOnlyDictionary<T>` надає `Dictionary<T>` лише для читання.
- `ReadOnlyCollection<T>` надає `List<T>` лише для читання.
