# Вступ

## Пояснення

Окрім примітивних типів даних, як-от `number` і `string`, у JavaScript є ще один важливий тип даних, який називається `object`.
Обʼєкти - це колекції пар ключ-значення.
Тож їх можна використовувати як те, що в інших мовах часто називають мапами або словниками.

В інших мовах усі значення в мапі часто мають бути одного типу даних.
У JavaScript обмежено лише тип ключа: він має бути рядком тексту (англ. string).
Значення всередині одного обʼєкта можуть мати різні типи.
Вони можуть бути примітивними типами, як-от числа, але також масивами, іншими обʼєктами чи навіть функціями.
Це робить обʼєкти дуже універсальними, тому вони також є ключовими сутностями для [обʼєктно-орієнтованого програмування][oop] (ООП) у JavaScript.

Далі ми зосередимося на обʼєктах як на колекціях або мапах. Про інші випадки використання обʼєктів ітиметься в інших концепціях, див., наприклад, [класи][concept-classes].

## Створення обʼєкта

Ми створюємо обʼєкт за допомогою фігурних дужок.
Також можна одразу додати кілька записів.
Для цього спочатку вказуємо ключ, далі двокрапку, а потім значення.

```javascript
const emptyObject = {};

const obj = {
  favoriteNumber: 42,
  greeting: 'Hello World',
  useGreeting: true,
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
  fruits: ['melon', 'papaya'],
  addNumbers: function (a, b) {
    return a + b;
  },
};
```

Кома після останнього запису в JavaScript необовʼязкова.

Можливо, виникає питання, чому ключі не взято в лапки, хоча вони й мають бути рядками тексту.
Це скорочена форма запису.
Якщо ключ відповідає правилам найменування [ідентифікатора][mdn-identifier] у JavaScript, лапки можна опустити.
Для ключів, у назві яких є спеціальні символи, потрібно використати звичний рядковий запис.

```javascript
const obj = {
  '1keyStartsWithNumber': '...',
  'key/with/slashes': '...',
  'key-with-dashes': '...',
  'key with spaces': '...',
  '#&()[]{}èä樹keyWithSpecialChars': '...',
};
```

## Отримання значення

Існує два способи отримати значення для заданого ключа: точкова нотація та дужкова нотація.

```javascript
const obj = { greeting: 'hello world' };

obj.greeting;
// => hello world

obj['greeting'];
// => hello world

// Bracket notation also works with variables.
const key = 'greeting';
obj[key];
// => hello world
```

Використання точкової нотації як скорочення має те саме обмеження, що й пропуск лапок.
Вона працює лише тоді, коли ключ відповідає правилам найменування ідентифікаторів.
Інакше кажучи, якщо ключ не є одним словом з самих лише літер, потрібно використати дужкову нотацію.

## Додавання або зміна значення

Додати або змінити значення можна за допомогою оператора присвоєння `=`.
І знову доступні обидві нотації: точкова та дужкова.

```javascript
const obj = { greeting: 'hello world' };

obj.greeting = 'Hi there!';
obj['greeting'] = 'Welcome.';

obj.newKey1 = 'new value 1';
obj['new key 2'] = 'new value 2';

const key = 'new key 3';
obj[key] = 'new value 3';
```

## Видалення запису

Видалити пару ключ-значення з обʼєкта можна за допомогою ключового слова `delete`.

```javascript
const obj = {
  key1: 'value1',
  key2: 'value2',
};

delete obj.key1;
delete obj['key2'];
```

## Перевірка наявності ключа

Перевірити, чи існує певний ключ в обʼєкті, можна методом `hasOwnProperty`.

```javascript
const obj = { greeting: 'hello world' };

obj.hasOwnProperty('greeting');
// => true

obj.hasOwnProperty('age');
// => false
```

## Перебирання обʼєкта

Існує спеціальний цикл `for...in`, щоб перебрати всі ключі обʼєкта.

```javascript
const obj = {
  name: 'Ali',
  age: 65,
};

for (let key in obj) {
  console.log(key, obj[key]);
}
// name Ali
// age 65
```

Щоб уникнути неочевидних помилок, завжди маємо виходити з того, що цикл `for...in` обходить ключі в довільному порядку.
Також зважаймо на те, що під час перебирання `for...in` включає й [успадковані ключі][concept-inheritance].
