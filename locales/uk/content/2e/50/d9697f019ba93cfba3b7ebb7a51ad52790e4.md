# Вступ

У F# присвоєння значення імені називають _звʼязуванням_. Звʼязування є незмінними, що робить їх схожими на константи в інших мовах. Оскільки F# є статично типізованою мовою, кожне звʼязування має тип під час компіляції.

Звʼязування визначають за допомогою ключового слова `let`. Зазначати тип звʼязування необовʼязково для більшості звʼязувань, оскільки _виведення типів_ у F# зазвичай може вивести тип на основі їхнього значення. Звʼязування має такий вигляд:

```fsharp
// Automatically inferred type
let fingers = 10
```

Функції також є звичайними звʼязуваннями, але з одним або кількома параметрами. Функція автоматично повертає свій останній вираз. Виведення типів також працює для більшості функцій: воно аналізує, з якими значеннями функцію викликають і яке значення вона повертає.

```fsharp
// Automatically inferred types for parameters and return type
let add x y = x + y
```

Щоб викликати функцію, вказуємо її назву і передаємо аргументи для кожного з її параметрів.

```fsharp
let five = add 2 3
```

Якщо тип звʼязування неможливо вивести, компілятор повідомить про помилку. Щоб це виправити, додаймо до звʼязування явну анотацію типу.

```fsharp
// Explicit type annotation
let fingers: int = 10

// Explicit type annotation (also for parameters)
let add (x: int) (y: int): int = x + y
```

Звʼязування у F# можна використовувати лише _після_ того, як їх визначено. Використання звʼязування до того, як його визначено, призводить до помилки компіляції.

```fsharp
// Compile error as the add binding has not yet been defined
// let seven = add 3 4

let add x y = x + y
```

F# використовує значущі пробіли для визначення області видимості. Це означає, що область видимості визначається відступами в коді, зробленими пробілами відносно рядка, у якому оголошено звʼязування. Типова домовленість - використовувати для відступу чотири пробіли:

```fsharp
let toes =
    let left = 5
    let right = 5
    left + right

let multiplyPlusTwo x y =
    let product = x * y
    product + 2

// Trying to access the left, right or product bindings
// here would result in a compile error
```

Звʼязування у F# (до яких належать і функції) зазвичай організовують у модулі. Модуль обʼєднує споріднену функціональність і визначається за допомогою ключового слова `module`. Визначення модуля має передувати його звʼязуванням:

```fsharp
module Calculator

let pi = 3.14

let add x y = x + y
```

F# підтримує два типи коментарів. Однорядкові коментарі починаються з `//`, а багаторядкові вставляють між `(*` і `*)`.
