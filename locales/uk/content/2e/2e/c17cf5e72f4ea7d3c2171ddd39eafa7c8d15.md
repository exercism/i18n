# Вступ

Зіставлення зі зразком домінує у впевненому, ідіоматичному коді Elixir. Пригадаймо, що `=/2` описують як оператор зіставлення, а не як оператор присвоєння. Коли ми користуємося оператором зіставлення і зразок ліворуч збігається з правим боком, усі змінні ліворуч звʼязуються, а значення правого боку повертається. Якщо збігу немає, виникає `MatchError`.

```elixir
2 = 2
# => 2
# Literals can be matched if they are the same

2 = 3
# => ** (MatchError) no match of right hand side value: 3

{_, denominator} = Float.ratio(0.25)
# => {1, 4}
# the variable `denominator` is bound to the value 4
```

Памʼятаймо, що зіставлення відбувається з правого боку до лівого.

В останньому прикладі, якщо змінна в зіставленні зі зразком нам не потрібна, ми можемо її відкинути, звернувшись до `_`. Будь-яка змінна, що починається з `_`, не відстежується середовищем виконання.

## Зіставлення зі зразком в іменованих функціях

Зіставлення зі зразком також стає в пригоді, коли ми створюємо кілька варіантів функції. Його можна застосовувати до аргументів функції, і воно визначає, який варіант функції викликати: від початку файлу вниз до першого збігу. Змінні можна звʼязати в заголовку функції й використати в тілі функції.

```elixir
defmodule Example do
  def named_function(:a = variable_a) do
    {variable_a, 1}
  end

  def named_function(:b = variable_b) do
    {variable_b, 2}
  end
end

Example.named_function(:a)
# => {:a, 1}

Example.named_function(:b)
# => {:b, 2}

Example.named_function(:c)
# => ** (FunctionClauseError) no function clause matching in Example.named_function/1
```
