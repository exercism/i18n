# Докладніше

## Порівняння чисел

У `jq` числа можна порівнювати за допомогою таких операторів відношення та рівності.

| Порівняння             | Оператор |
| ---------------------- | -------- |
| Більше ніж             | `a > b`  |
| Більше або дорівнює    | `a >= b` |
| Менше ніж              | `a < b`  |
| Менше або дорівнює     | `a <= b` |
| Дорівнює               | `a == b` |
| Не дорівнює            | `a != b` |

Результатом порівняння завжди є булеве значення (англ. Boolean), тобто `true` або `false`.

```jq
1 < 3,      # => true
2 != 2,     # => false
1 == 1.0    # => true
            # All numbers are floating-points, so this is different syntax
            # for the exact same value.
```

## Порівняння рядків тексту

Наведені вище оператори порівняння можна застосовувати і до рядків тексту (англ. string).
У цьому випадку застосовується словниковий (лексикографічний) порядок.
Порядок визначається [за значенням коду символу Unicode][sort].

[sort]: https://jqlang.org/manual/#sort-sort_by

```jq
"Apple" > "Pear",   # => false
"a" < "above",      # => true
"a" == "A"          # => false
```

Варто бути уважними, коли ми порівнюємо дві змінні, які, здавалося б, містять числові значення, але мають тип рядок тексту.
Через словниковий порядок результат буде не таким, як у разі порівняння значень типу число.

```jq
10 < 2,     # => false
"10" < "2"  # => true (because "1" comes before "2")
```

## «Сувора» рівність

Оператор `==` у `jq` схожий на `===` у JavaScript: речі, які мають однаковий вигляд, але належать до різних типів, не є рівними.

```jq
"3" == 3    # => false
            # the value on the left has type string,
            # the value on the right has type number.
```

## Порівняння масивів

Два масиви вважаються рівними, якщо всі відповідні елементи рівні.

```jq
[1, 2, 3] == [1, 2, 3]      # => true
[1, 2, 3] == [1, 3, 2]      # => false, different order
[1, 2, 3] == [1, 2, "3"]    # => false, different types
```

## Порівняння обʼєктів

Два обʼєкти вважаються рівними, якщо вони мають однакові пари ключ-значення.

```jq
{name: "Joe", age: 42} == {age: 42, name: "Joe"}                # => true
{name: "Joe", age: 42} == {age: 42, name: "Jane"}               # => false
{name: "Joe", age: 42} == {age: "42", name: "Joe"}              # => false
{name: "Joe", age: 42} == {age: 42, name: "Joe", height: 175}   # => false

# comparisons will drill down as deeply as required
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2]}}}                  # => true
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2, 3]}}}               # => false
```
