# Тести

## Запуск тестів

1. Завантажмо вправу:

    ```bash
    $ exercism download -track=kotlin --exercise=hello-world
    ```

2. Перейдімо в каталог вправи:

    ```bash
    $ cd <path_to_exercise_directory>
    ```

3. Запустімо тести:

    ```bash
    $ ./gradlew test
    ```

У більшості вправ типово запускається лише перший тест.  
Решта тестів мають анотацію `@Ignore`, щоб їх пропустити.  
Коли ми розвʼязуємо черговий тест, прибираємо `@Ignore` з наступного, щоб рухатися далі.

Це звична практика в розробці через тестування (test-driven development, скорочено TDD).
Її використовують, щоб працювати над однією задачею за раз.
