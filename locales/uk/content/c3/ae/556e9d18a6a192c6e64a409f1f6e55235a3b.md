# Інструкції

Один виробник може випускати два різні типи моторів; надалі називатимемо їх мотор A і мотор B. Обидва мотори мають 3 компоненти, потрібні для виробництва: прокладання дротів, свердління і складання. Для кожного з цих етапів виробництва кожен мотор потребує різної кількості часу. Загалом, одна одиниця мотора A потребує t_a_1 годин на прокладання дротів, t_a_2 годин на свердління і t_a_3 годин на складання. З іншого боку, одна одиниця мотора B потребує t_b_1 годин на прокладання дротів, t_b_2 годин на свердління і t_b_3 годин на складання. Реалізуйте функцію, яка, отримавши загальну кількість годин, виділених на кожен етап виробництва (t_1 годин на прокладання дротів, t_2 годин на свердління і t_3 годин на складання), і ціни для кожного типу мотора (p_a, p_b), обчислює оптимальні кількості мотора A і мотора B, що максимізують прибуток.

Функція матиме 4 вхідні параметри. Їх описано нижче:
1. a_hours: кортеж із трьох значень (t_a_1, t_a_2, t_a_3) у годинах
2. b_hours: кортеж із трьох значень (t_b_1, t_b_2, t_b_3) у годинах
3. total_hours: кортеж із трьох значень (t_1, t_2, t_3) у годинах
4. prices: кортеж із двох значень (p_a, p_b) у доларах

Результатом має бути один кортеж із трьох значень (q_a, q_b, profit), де:
1. q_a: оптимальна кількість мотора A для виробництва
2. q_b: оптимальна кількість мотора B для виробництва
3. profit: значення прибутку, яке максимізується, у доларах

Інші важливі моменти:
q_a і q_b не можуть бути числами з плаваючою комою, бо частину мотора виробити неможливо.
Результати моделі Z3 для змінних потрібно перед виведенням перетворити на цілі числа. Якщо результат
моделі Z3 має тип `IntNumRef`, можна скористатися методом класу `as_long()`, щоб перетворити його на ціле число.
Якщо задача нерозвʼязна через некоректні вхідні дані, тоді викличте вбудований у Python виняток
`ArithmeticError()`.
