# Вступ

Тип `char` у F# є 16-бітним значенням, що представляє найменші адресовані компоненти тексту; він типово незмінний.

`char` можна визначити як літерали в одинарних лапках:

```fsharp
let ch = 'A'
// => val ch: char = 'A'
```

Рядки тексту (англ. string) є послідовністю символів.

Окремий `char` можна отримати з рядка тексту за допомогою індексації (з відліком від нуля):

```fsharp
"Exercism"[4] //  =>  'c'
```

Перебирання рядка тексту повертає `char` на кожному кроці.

У наступному прикладі для зручності використано функцію вищого порядку та анонімну функцію.
Їх належно розглянемо пізніше в силабусі, але поки що це, по суті, стислий спосіб записати цикл по символах рядка тексту.

```fsharp
Seq.map (fun c -> c, int c) "F#"  //  =>  [('F', 70); ('#', 35)]
```

Як показано вище, `char` можна привести до його значення `int`.
Це також працює (*принаймні іноді*) для інших систем письма:

```fsharp
Seq.map (fun c -> c, int c) "東京"  //  =>  [('東', 26481); ('京', 20140)]
```

Для порівняння символів використовується базовий тип Int16:

```fsharp
'A' < 'D'  // =>  true
```

Також `int` можна привести до `char`:

```fsharp
char 77  // => 'M'
```

Бібліотека `System.Char` містить повний набір методів, очікуваних для мови .NET, як-от перетворення на верхній/нижній регістр:

```fsharp
'a' |> System.Char.ToUpper  // =>  'A'

'Q' |> System.Char.ToLower  // =>  'q'
```
