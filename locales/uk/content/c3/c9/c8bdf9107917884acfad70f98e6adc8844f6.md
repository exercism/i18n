# Вступ

Атрибут Flags дозволяє подати значення, визначені в розпізнаваному обʼєднанні, як позиції бітів (тобто прапорці).
Як прапорці, такі значення можна поєднувати, що дає змогу подати кілька булевих умов (англ. Boolean) одним значенням.

```fsharp
[<Flags>]
type PhoneFeatures =
| Call = 1
| Text = 2
```

```fsharp
[<Flags>]
type PhoneFeaturesBinary =
| Call = 0b00000001
| Text = 0b00000010
```

Установити прапорець можна побітовим оператором OR (`|||`); зняти прапорець можна поєднанням побітового оператора AND (`&&&`) і побітового оператора заперечення (`~~~`).
Стан прапорця можна перевірити побітовим оператором AND, а також скористатися методом `HasFlag()`.

```fsharp
let features = PhoneFeatures.Call

// Set the Text flag
let moreFeatures = features ||| PhoneFeatures.Text

moreFeatures.HasFlag(PhoneFeatures.Call) // => true
moreFeatures.HasFlag(PhoneFeatures.Text) // => true
```

Повний перелік побітових операторів, доступних у мові F#, наведено в [Зведенні побітових операторів][bitwise-operators].

[bitwise-operators]: https://learn.microsoft.com/en-us/dotnet/fsharp/language-reference/symbol-and-operator-reference/bitwise-operators#summary-of-bitwise-operators
