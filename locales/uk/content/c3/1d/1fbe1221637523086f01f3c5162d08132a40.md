# Вступ

Клас Lambda містить набір функціональних методів, які дають змогу застосовувати функціональний стиль програмування в Haxe. Він дозволяє одразу працювати з цілим Iterable. Це часто краще, ніж писати цикли, бо такий код менш схильний до помилок і його легше читати. Для зручності класи Array і List містять частину методів із класу Lambda, які найчастіше використовують.

Деякі з функцій класу `Lambda`:

- `Lambda.array`, `Lambda.list` Перетворюють Iterable на Array або List. Завжди повертають новий примірник.
- `Lambda.count` Рахує кількість елементів. Якщо Iterable має тип Array або List, тоді швидше скористатися його властивістю length.
- `Lambda.has` Визначає, чи є вказаний елемент в Iterable.
- `Lambda.indexOf` Знаходить індекс вказаного елемента.
- `Lambda.find` Знаходить перший елемент за заданою функцією пошуку.
- `Lambda.concat` Обʼєднує два Iterable і повертає новий List.
- `Lambda.filter` Знаходить елементи, які задовольняють критерій, і повертає новий List.

Приклад, який демонструє деякі з цих функцій:

```haxe
using Lambda;

class Main {
  static function main() {
    var words = ["boat", "dog", "phone", "cat", "food"];

    var isThreeLetters = function(word) return word.length == 3;

    trace(words.filter(isThreeLetters)); // [dog,cat]
  }
}
```
