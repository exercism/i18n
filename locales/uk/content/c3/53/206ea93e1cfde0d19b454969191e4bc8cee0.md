# Цілі числа

Цілі числа - це числа без дробової частини, які належать до множини `{..., -2, -1, 0, 1, 2, ...}`.
Максимальне та мінімальне значення цілого числа визначається системою, у якій виконується PHP.
Зазвичай на більшості сучасних систем ціле число займає 64 біти, тобто може представляти значення від `-9_223_372_036_854_775_808` до `9_223_372_036_854_775_807` включно.

```php
<?php

$a = 1234;
$a = 1_234_567;
```

Цілочисельні літерали можна записувати не лише в десятковій системі числення, використовуючи префікс основи:

```php
<?php

$a = 0123; // octal number (equivalent to 83 decimal)
$a = 0o123; // octal number (as of PHP 8.1.0)
$a = 0x1A; // hexadecimal number (equivalent to 26 decimal)
$a = 0b11111111; // binary number (equivalent to 255 decimal)
```
