# Тести

## Коротко

- Перейдіть до каталогу задачі (напр., `~/Exercism/hello-world`).
- Запустіть сеанс `jconsole` у терміналі.
- Завантажте файл свого рішення (напр., `load 'hello-world.ijs'`).
- Завантажте фреймворк модульних тестів, ввівши `load  'general/unittest'`.
- Перевірте своє рішення, ввівши `unittest 'test.ijs'`.
<br></br>
- Або можна запустити тести одним рядком ось так: `jconsole -js "load 'hello-world.ijs'" "echo unittest 'test.ijs'" "exit 0"`.

## Сеанс jconsole

Сподіваємося, що налаштування тестів вийшло якомога простішим.
Якщо ми працюємо над вправою, скажімо `hamming.ijs`, ось як має відбуватися робота.
Відредагуйте `hamming.ijs`, записавши своє рішення.
Побудуйте його поступово в інтерактивному режимі, спочатку ввівши:

```j
NB. your j terminal binary may be ijconsole (eg. on Debian)
jconsole 'hamming.ijs' NB. start a J console session with definitions loaded hamming.ijs
```

Потім із самої консолі J перезавантажте його, ввівши

```j
load 'hamming.ijs'
```

Наступний крок: завантажте фреймворк модульних тестів, ввівши

```j
load 'general/unittest'
```

Щоб запустити тести після того, як завантажили своє рішення, введіть

```j
unittest 'test.ijs'
```

А потім подивіться на результати.

## Командний рядок

Можна запустити тести однією командою в терміналі, скориставшись прапорцем -js:

```j
jconsole  -js "load 'hamming.ijs'" "echo unittest 'test.ijs'" "exit 0"
```
де кожен аргумент задає команду, яку буде виконано послідовно.
