# Встановлення

## Встановлення Clojure CLI

Clojure надає інструменти командного рядка, за допомогою яких можна запустити REPL Clojure, скористатися бібліотеками Clojure та Java і запустити програми Clojure.

Якщо потрібно встановити Java, радимо [Adoptium Temurin 17](https://adoptium.net/).

### Linux

Переконайтеся, що встановлено такі залежності: `bash`, `curl`, `rlwrap` і `Java`.
Clojure можна встановити одним із цих двох способів:

1. LinuxBrew - потребує [Homebrew](https://brew.sh/)

```bash
brew install clojure/tools/clojure
```

2. Скрипт-інсталятор

```bash
curl -O https://download.clojure.org/install/linux-install-1.11.1.1347.sh
chmod +x linux-install-1.11.1.1347.sh
sudo ./linux-install-1.11.1.1347.sh
```

### Homebrew для Mac OS X

Встановіть інструменти командного рядка за допомогою brew із tap-у [clojure/tools](https://github.com/clojure/homebrew-tools):

```bash
brew install clojure/tools/clojure
```

#### Java

Підійде будь-який дистрибутив Java. За потреби можна встановити Temurin за допомогою brew:

```bash
brew tap homebrew/cask-versions
brew install --cask temurin17
```

### Windows

Clojure на Windows останнім часом значно покращився. Раніше ми радили використовувати WSL2, який чудово працює, але тепер є інсталятор для PowerShell. Clojure на Windows поки що в стані альфи, відомі проблеми дивіться в [clj-on-windows](https://github.com/clojure/tools.deps.alpha/wiki/clj-on-Windows#known-issues).

Переконайтеся, що Java встановлено, а змінну середовища `JAVA_HOME` задано, і виконайте:

```powershell
iwr -useb download.clojure.org/install/win-install-1.11.1.1165.ps1 | iex
```

Ще один спосіб встановити Clojure на Windows - скористатися менеджером пакетів [Scoop](https://scoop.sh/). Щоб встановити Scoop, відкрийте PowerShell і виконайте ці дві команди одну за одною:

 ```sh
 iwr -useb get.scoop.sh | iex
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser -Force
```

Щоб встановити Clojure із Scoop, спершу треба додати два важливі кошики:

```sh
# if you don't have git version control system installed
# it is required for adding new external buckets to your scoop installer
# you can skip this step otherwise
scoop install git

# add scoop bucket for Java 
scoop bucket add java

# add scoop bucket for clojure build
scoop bucket add scoop-clojure https://github.com/littleli/scoop-clojure
```

Тепер ми готові встановити Java і Clojure, виконавши такі команди:

```sh
# install Java runtime and compiler
scoop install adoptopenjdk-lts-hotspot

# install official clojure tools
scoop install clojure

# update to the newest version
scoop update clojure
```

Після успішного виконання цих кроків Clojure можна буде запустити так:

```sh
clj
```

## Встановлення Leiningen (необовʼязково)

Хоча він більше не обовʼязковий, ми досі підтримуємо повнофункціональний інструмент керування проєктами [Leiningen](https://leiningen.org/).
Він пропонує безліч корисних завдань, як-от зручне тестування, збірки та покращений REPL.

1. Завантажте [скрипт lein](https://raw.githubusercontent.com/technomancy/leiningen/stable/bin/lein) або [lein.bat](https://raw.githubusercontent.com/technomancy/leiningen/stable/bin/lein.bat) (Windows)
2. Розмістіть його в `$PATH`, де його зможе знайти оболонка (наприклад, `/usr/local/bin/`)
3. Зробіть його виконуваним (`sudo chmod a+x /usr/local/bin/lein`)
4. Запустіть `lein`.
