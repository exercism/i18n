# Вступ

## Узагальнені типи

**Узагальнений тип** - це узагальнений клас або інтерфейс, параметризований типами. Це дає компілятору змогу забезпечувати типобезпеку класу або інтерфейсу.

Розгляньмо цей неузагальнений інтерфейс `Container`:

```java
class Container {
    private Object object;

    public void set(Object object) { this.object = object; }
    public Object get() { return object; }
}
```

Оскільки він приймає й повертає обʼєкти типу Object, він працює з будь-яким непримітивним типом. Однак за це доводиться платити: якийсь код може викликати `get`, розраховуючи на `Integer`, а інший код викликає `set`, додаючи `String`, що призводить до винятку часу виконання.

**Узагальнений клас** і **узагальнений інтерфейс** мають такий формат:

```java
class ClassName<T1, T2, ..., Tn> { ... }
interface InterfaceName<T1, T2, ..., Tn> { ... }
```

Секція параметрів типу, обмежена кутовими дужками (`<>`), яка йде після назви класу або інтерфейсу, задає параметри типу (які також називають змінними типу) `T1`, `T2`, ..., і `Tn`. Їх можна використовувати всередині тіла класу або інтерфейсу, щоб отримати типобезпеку узагальнень.

Ось узагальнена версія `Container`:

```java
class Container<E> {
    private E object;

    public void set(E object) { this.object = object; }
    public E get() { return object; }
}
```

Коли ми його створюємо, нам тепер треба оголосити, який тип він зберігає, і компілятор забезпечить це обмеження:

```java
// empty <> can infer from context
Container<String> stringContainer = new Container<>();
// compiler knows this is a String, so it is allowed
stringContainer.set("Some string");
// no cast needed, compiler knows it is a String
String result = stringContainer.get();
// this causes a compiler error:
stringContainer.set(42);
```

## Списки

У Java **списки** - це впорядкована колекція-послідовність. На відміну від масивів, [`List`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/List.html) може збільшуватися в розмірі, щоб умістити будь-яку кількість елементів. Одна зі стандартних реалізацій - це `ArrayList`, який базується на масиві, розмір якого можна змінювати. Інша стандартна реалізація - це клас `LinkedList`, який базується на двозвʼязному списку.

`List` може бути порожнім або містити будь-яку кількість елементів (зокрема дублікати). `List` - це **узагальнений інтерфейс**, типізований так, щоб указувати, які типи обʼєктів він може містити. Наприклад:

```java
List<String> emptyListOfStrings = List.of();
List<Integer> singleInteger = List.of(1);
List<Boolean> threeBooleans = List.of(true, false, true);
List<Object> listWithMultipleTypes = List.of("hello", 1, true);
```

`List` має різні корисні методи, щоб додати елемент, видалити його, отримати або перевірити, чи він наявний:

```java
List<Character> vowels = new ArrayList<>(List.of('a', 'e', 'i', 'o', 'i', 'e', 'a'));
int startingSize = vowels.size(); // 7
vowels.add('u'); // vowels is now ['a', 'e', 'i', 'o', 'i', 'e', 'a', 'u']
char a = vowels.get(0); // 'a'
boolean hadI = vowels.remove('i'); // true and vowels is now ['a', 'e', 'o', 'i', 'e', 'a', 'u']
boolean hasI = vowels.contains('i'); // true (still have one more left)
```
