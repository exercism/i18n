# Заповнювач

## Поради щодо `jq`

Ця вправа про те, щоб узяти вхідний обʼєкт і перетворити його на новий обʼєкт.
Кілька вбудованих функцій, які можуть допомогти:

- [`to_entries`][x_entries]
  - ця функція приймає обʼєкт як вхідні дані
  - вона повертає _масив_: кожен елемент масиву є обʼєктом `{"key": "K", "value": V}`
    - кожен `K` є ключем із вхідного обʼєкта
    - кожен `V` є відповідним значенням `K`.
- [`from_entries`][x_entries]
  - обернена операція
  - приймає масив обʼєктів `{"key": K, "value": V}` і будує обʼєкт

Приклад:

```sh
jq -n '
    {
        "username": "glennj",
        "tracks": ["bash", "awk", "jq"],
        "reputation": 123
    }
    | to_entries
'
```

виводить

```json
[
  {
    "key": "username",
    "value": "glennj"
  },
  {
    "key": "tracks",
    "value": ["bash", "awk", "jq"]
  },
  {
    "key": "reputation",
    "value": 123
  }
]
```

[x_entries]: https://jqlang.org/manual/#to_entries-from_entries-with_entries
