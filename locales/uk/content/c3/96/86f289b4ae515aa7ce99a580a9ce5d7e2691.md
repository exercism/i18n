# Вказівки

Перетворіть число, подане як послідовність цифр в одній основі, на будь-яку іншу основу.

Реалізуйте загальне перетворення основ. Маючи число в основі **a**, подане як послідовність цифр, перетворіть його на основу **b**.

## Примітка

- Спробуйте реалізувати перетворення самостійно.
  Не використовуйте щось інше для виконання перетворення.

## Про [позиційну систему числення](https://en.wikipedia.org/wiki/Positional_notation)

У позиційній системі числення число в основі **b** можна розуміти як лінійну
комбінацію степенів **b**.

Число 42, *в основі 10*, означає:

(4 * 10^1) + (2 * 10^0)

Число 101010, *в основі 2*, означає:

(1 * 2^5) + (0 * 2^4) + (1 * 2^3) + (0 * 2^2) + (1 * 2^1) + (0 * 2^0)

Число 1120, *в основі 3*, означає:

(1 * 3^3) + (1 * 3^2) + (2 * 3^1) + (0 * 3^0)

Гадаю, ми вловили ідею!

*Так. Ці три числа вище - це одне й те саме число. Вітаємо!*
