# Масиви

**Масив** містить ряд значень, усі одного типу, у певному порядку.

Тип записують як `ARRAY{T}`, де `T` позначає, що саме масив містить. Масив рядків тексту (англ. string) має тип `ARRAY{STR}`; масив цілих чисел має тип `ARRAY{INT}`.

```sather
   row : ARRAY{STR} := |"Mia", "Ana", "Ben"|;
```

Значення між двома позначками `|` утворюють **літерал масиву**. Sather визначає розмір за кількістю цих значень.

## Як отримати значення

Позицію вказують у квадратних дужках:

```sather
row[0]      -- "Mia"
row[1]      -- "Ana"
row[2]      -- "Ben"
```

Лічба починається з **нуля**, а не з одиниці. Отже, перше значення розташоване на позиції `0`, а останнє в масиві з трьох елементів розташоване на позиції `2`.

## Скільки?

`.size` показує, скільки значень містить масив.

```sather
row.size    -- 3
```

Оскільки лічба починається з нуля, остання позиція завжди дорівнює `.size - 1`:

```sather
row[row.size - 1]     -- "Ben"
```

Звернення до позиції, якої немає, наприклад `row[3]` або `row[-1]`, є помилкою, яку Sather не виявить за нас. Тому краще писати `.size - 1`, ніж рахувати значення на око.

## Перебираємо масив

Масив і цикл працюють разом. Збільшуймо змінну, проходячи позиції, і використовуймо її, щоб дістатися кожного значення:

```sather
   total ::= 0;
   i ::= 0;
   loop
      until!(i >= scores.size);
      total := total + scores[i];
      i := i + 1;
   end;
```
