# Вступ

На відміну від багатьох інших мов, у JavaScript є дві різні сутності, які позначають відсутність (змістовного) значення.
Це `null` та `undefined`.

## Null

Примітивне значення `null` використовують як навмисне «порожнє значення» для змінних будь-якого типу.

```javascript
let name = null;
// name is intentionally set to "empty" because it is not
// available
```

Перевірити, чи змінна дорівнює `null`, можна за допомогою [оператора суворої рівності][mdn-strict-equality] `===`.

```javascript
let name = null;

name === null;
// => true
```

## Undefined

> Змінна, якій не присвоїли значення, має тип `undefined`.[^1]

Це означає, що `null` позначає порожнє значення (хоч усе ж значення), тоді як `undefined` позначає цілковиту відсутність значення. 🤯

`undefined` виникає в різних ситуаціях.

- Якщо змінну оголосили без значення (без ініціалізації), вона має значення `undefined`.

  ```js
  let name;
  console.log(name); // => undefined
  ```

- Якщо ми намагаємося отримати значення за неіснуючим ключем в обʼєкті, отримуємо `undefined`.

  ```js
  let obj = {
    name: 'John',
  };
  console.log(obj.age); // => undefined
  ```

- Якщо функція не повертає значення, отримуємо `undefined`.

  ```js
  function printName(name) {
    'My name is ' + name;
  }
  console.log(printName('John')); // => undefined
  ```

- Якщо аргумент не передали у функцію, він має значення `undefined`, якщо тільки цей аргумент не має типового значення.

  ```js
  function printName(name) {
    return name;
  }
  console.log(printName()); // => undefined
  ```

Перевірити, чи змінна має значення `undefined`, можна за допомогою оператора суворої рівності `===`.

```javascript
let name;

name === undefined;
// => true
```

## Опціональний ланцюжок

Якщо ми намагаємося отримати вкладене значення в обʼєкті, але батьківського ключа не існує, JavaScript видасть помилку.
Щоб легко цього уникнути, 2020 року до специфікації мови додали опціональний ланцюжок.
За допомогою оператора опціонального ланцюжка `?.` можна зробити так, щоб JavaScript звертався до вкладеного ключа лише тоді, коли батьківський ключ не `null` та не `undefined`.
Інакше повертається `undefined`.

```javascript
const obj = {
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
};

obj.address.zipCode;
// => undefined

obj.residence.street;
// => TypeError: Cannot read property 'street' of undefined

obj.residence?.street;
// => undefined
```

## Нульове обʼєднання

Бувають ситуації, коли потрібно застосувати типове значення, якщо змінна дорівнює `null` або `undefined` (але тільки тоді).
Щоб це врахувати, 2020 року ввели оператор нульового обʼєднання `??`.
Він повертає правий операнд лише тоді, коли лівий операнд - `null` або `undefined`.
Інакше повертається лівий операнд.

```javascript
let amount = null;
amount = amount ?? 1;
// => 1

amount = 0;
amount = amount ?? 1;
// => 0
```
