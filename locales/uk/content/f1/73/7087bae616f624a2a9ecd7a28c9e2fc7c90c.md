# Інструкції

Жив-був собі гамірний град на імʼя Кіберпростір.
Кіберпростір був цифровим мегаполісом, де мільйони мешканців щодня входили в систему й виходили з неї.
Щоб стежити за всіма цими користувачами, у Кіберпросторі був особливий файл /etc/passwd.

Файл /etc/passwd був для міста як телефонний довідник.
У ньому було перелічено кожного користувача, який мав обліковий запис у системі, разом із важливою інформацією про кожного з них:

| n   | поле |
| --- | --- |
| 1   | імʼя користувача |
| 2   | пароль («x» означає, що справжній пароль зберігається деінде, з міркувань безпеки) |
| 3   | UID, унікальний числовий ідентифікатор користувача |
| 4   | GID, унікальний числовий ідентифікатор групи (зазвичай збігається з UID) |
| 5   | інформація про користувача (зазвичай повне імʼя користувача, але може містити й інші дані) |
| 6   | домашній каталог |
| 7   | командна оболонка входу |

Поля розділені символом двокрапки.
Ось типовий запис:

```none
glennj:x:1010:1010:Glenn Jackman:/home/glennj:/usr/local/bin/fish
```

Файлом керувала команда системних адміністраторів, які створювали нові облікові записи, оновлювали наявні та видаляли старі.
Системні адміністратори були воротарями Кіберпростору й дбали про те, щоб доступ до системи мали лише авторизовані користувачі.

Одного дня до команди приєднався новий системний адміністратор на імʼя Алекс.
Алекс із захопленням узялися до роботи й швидко опанували всі тонкощі файлу /etc/passwd.
Вони навчилися додавати нових користувачів до системи, оновлювати інформацію про них і видаляти старих.

Працюючи з файлом /etc/passwd, Алекс помітили дещо дивне.
У деяких користувачів були дивні або незвичні домашні каталоги.
У когось домашнім каталогом було вказано /dev/null, а в когось - химерні шляхи, яких не існувало.

Алекс зрозуміли, що ці користувачі - не справжні люди, а фальшиві облікові записи, які створили хакери.
Хакери знайшли спосіб скористатися вразливістю в системі й створили ці фальшиві записи, щоб отримати доступ до Кіберпростору.

Алекс розуміли, що потрібно діяти.
Вони використали awk, щоб проаналізувати файл /etc/passwd, і написали скрипт, який виявляв усі фальшиві записи.
Далі вони разом з рештою команди видалили ці записи й залатали вразливість, яка дозволила хакерам створити їх.

Завдяки тому, що Алекс використали awk, команда змогла виявити й видалити фальшиві записи та зробити Кіберпростір безпечнішим місцем для всіх.
Системні адміністратори й далі керували файлом /etc/passwd, підтримували його в актуальному й захищеному стані та дбали про те, щоб доступ до системи мали лише авторизовані користувачі.

Тепер наша черга побути системним адміністратором, як Алекс.

~~~~exercism/note
Ось додатковий синтаксис AWK, який знадобиться, щоб розвʼязати цю вправу.

* Булеві оператори (англ. Boolean) схожі на ті, що є в інших мовах:

    | операція             | приклад            |
    | -------------------- | ------------------ |
    | Логічне і            | `expr1 && expr2`   |
    | Логічне або          | `expr1 \|\| expr2` |
    | Логічне заперечення  | `! expr`           |

* Виклик функції має знайомий синтаксис:

    ```awk
    function greet(name) {
        print "Hello", name
    }
    BEGIN {
        greet("Mary")   # prints "Hello Mary"
    }
    ```

~~~~

## 1. Вивести список імен користувачів

Напишіть програму awk, яка виводить перше поле, відокремлене двокрапкою, для кожного рядка у файлі passwd.

## 2. Вивести номери рядків

Напишіть команду awk, яка виводить номер рядка кожного запису у вхідному файлі.
Виводьте лише номер рядка, без жодної іншої інформації.

## 3. Вивести записи з недійсними домашніми каталогами.

У Кіберпросторі «дійсний» домашній каталог починається з `/home` або `/root`.
Виведіть записи з вхідного файлу, у яких домашні каталоги **недійсні**.

## 4. Вивести дійсних користувачів, які використовують bash

Виведіть записи, у яких домашній каталог дійсний, **і** командна оболонка входу - `bash`.
