# Налагодження

Щоб допомогти з налагодженням, можна скористатися тим, що весь вивід консолі буде захоплено й показано у вікні результатів тестів. Можна вивести будь-яке значення, передавши його до `IO.inspect`.

`IO.inspect` повертає значення незміненим, що робить його особливо корисним для перевірки проміжних значень у ланцюжках викликів функцій.

```elixir
"hello"
|> String.upcase()
|> IO.inspect()
|> String.split("", trim: true)
```

Зауважимо, що з міркувань безпеки вивід для кожного тесту буде обрізано після 500 символів.
