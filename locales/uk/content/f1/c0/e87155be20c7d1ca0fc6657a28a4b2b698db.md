# Про мову

[Java](https://go.java/index.html) належить до найпопулярніших мов програмування завдяки своїй універсальності та сумісності.
Її широко використовують для розробки програмного забезпечення, мобільних застосунків і більших систем.

Java народилася 1995 року, а підтримує її [Oracle](https://www.oracle.com/index.html).
Попри те, що вона не така молода, як деякі нові мови, Java досі дуже популярна.
Її створили так, щоб вона була швидкою, безпечною, надійною, зручною для новачків і надзвичайно портативною.
Ця перевага портативності існує тому, що Java виконується на кросплатформній [віртуальній машині Java - JVM](https://en.wikipedia.org/wiki/Java_virtual_machine).
Застосунки для Android теж розробляють на Java, адже [операційна система Android](<https://en.wikipedia.org/wiki/Android_(operating_system)>) працює в середовищі мови Java.

Спільнота Java величезна!
Наприклад, на GitHub понад 1,5 мільйона проєктів на Java.
Варто також згадати, що Java має другу за величиною спільноту на [StackOverflow](https://stackoverflow.com/questions/tagged/java)!
Це важливо, бо чим більша спільнота мови програмування, тим більше підтримки ми, найімовірніше, отримаємо.

Java також має потужний і добре спроєктований набір вбудованих [API - інтерфейсів прикладного програмування](https://docs.oracle.com/en/java/javase/11/docs/api/index.html), які можна використовувати для найрізноманітніших завдань, як-от підключення до баз даних, робота з мережами, введення-виведення, розбір XML, утиліти та багато іншого.

Від ноутбуків до центрів обробки даних, від ігрових консолей до наукових суперкомпʼютерів, від мобільних телефонів до інтернету: [Java всюди](https://en.wikipedia.org/wiki/Write_once,_run_anywhere)!
