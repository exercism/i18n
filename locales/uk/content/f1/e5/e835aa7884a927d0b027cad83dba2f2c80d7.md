# Виносимо константу на верхній рівень

Розгляньмо винесення константи в область видимості верхнього рівня:

```javascript
const %{name} = %{value}

// the rest of your code below it
export %{method.signature}
```

Лише функції, класи та константи, позначені `export`, видимі та доступні ззовні.
Ці константи можуть залишатися в тому самому файлі й не бути відкритими для іншого коду.
Також винесення констант економить памʼять, адже дозволяє уникнути повторних виділень памʼяті у функціях, коли ті самі константи використовуються знову.
