# Інструкції

Завантажений банк обслуговує клієнтів за *пріоритетом*, а не в тому порядку, у якому вони прийшли. Кожен клієнт отримує номер пріоритету, коли бере талон, і касир завжди обслуговує наступним найменший номер (`1` означає найвищу терміновість). Для цього ідеально підходить мінімальна купа.

## 1. Відкрийте чергу

Визначте `new-queue`, яка нічого не приймає й повертає нову порожню пріоритетну чергу.

```factor
new-queue
! => an empty priority queue
```

## 2. Додайте клієнта

Визначте `join-queue`, яка приймає імʼя клієнта, номер пріоритету та чергу. Вона додає клієнта до черги й повертає чергу, тож клієнтів можна додавати одного за одним.

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue
! => the queue, now holding alice (5) and bob (2)
```

## 3. Хто наступний?

Визначте `next-name`, яка приймає чергу й повертає імʼя клієнта, якого слід обслужити наступним, тобто того, у кого найменший номер пріоритету, і *не* вилучає його з черги.

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue next-name .
! => "bob"
```

## 4. Обслужіть усіх

Визначте `serve-all`, яка приймає чергу й повертає імена всіх клієнтів, що чекають, у тому порядку, у якому їх обслугували б.

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue
"carol" 9 rot join-queue serve-all .
! => { "bob" "alice" "carol" }
```
