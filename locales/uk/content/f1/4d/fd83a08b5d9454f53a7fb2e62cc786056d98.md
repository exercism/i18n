# Підказки

## Загальне

- Оголосимо чотири символи сторін світу і чотири символи відносного пеленга однією лінією
  `SYMBOLS:`:
  `SYMBOLS: north east south west ahead starboard behind port ;`
- Кожен кортеж оголошується рядком `TUPLE: <class> <slot1> <slot2> ;`.
- Рядок `GENERIC:` оголошує слово; кожен рядок `M:` додає метод для одного
  класу. Використайте `M::`, якщо в тілі методу потрібні іменовані локальні
  змінні.

## 1. `>cartesian` для сторін світу

- Достатньо невеликого `case` за чотирма символами напрямків.
- `{ north [ 0 1 ] }`: тіло просто кладе на стек два значення;
  тест вимагає, щоб `x` лежало на стеку під `y`.

## 2. `>cartesian` для полярних координат

- Переведімо градуси в радіани: `bearing pi * 180 /`.
- `sin` і `cos` містяться в `math.functions`.
- Кладемо на стек `magnitude * sin(rad)`, а потім `magnitude * cos(rad)`.

## 3. `>cartesian` для відносного пеленга

- Оголосимо динамічну змінну: `SYMBOL: heading`.
- Читаємо її у своєму методі за допомогою `heading get`.
- Зіставляємо `ahead/starboard/behind/port` зі зсувом `0/90/180/270`
  за допомогою `case`, а потім додаємо значення `heading`. Далі це те саме
  перетворення полярних координат, що й у завданні 2, тож варто винести
  допоміжне слово `: deg>cartesian ( magnitude bearing -- x y ) ... ;`.

## 4. `flip`

- `change-direction` для `cardinal` і `change-bearing` для `polar` або
  `relative` створюють новий кортеж з одним зміненим слотом, не чіпаючи
  решту:
  `[ <transformation-quotation> ] change-bearing`.
- Для обертання `polar`: `[ 180 + 360 mod ] change-bearing`.

## 5. `add-bearings`

- Викликаємо `>cartesian` для кожного вхідного значення, а потім додаємо
  компоненти x і компоненти y. Локальні змінні роблять це читабельним:
  ```factor
  :: add-bearings ( a b -- x y )
      a >cartesian :> ay :> ax
      b >cartesian :> by :> bx
      ax bx +
      ay by + ;
  ```
