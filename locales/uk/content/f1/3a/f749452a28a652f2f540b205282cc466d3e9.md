# Вступ

## Порівняння

### Порівняння чисел

У `jq` числа можна порівнювати за допомогою таких операторів відношення та рівності.

| Порівняння             | Оператор |
| ---------------------- | -------- |
| Більше ніж             | `a > b`  |
| Більше або дорівнює    | `a >= b` |
| Менше ніж              | `a < b`  |
| Менше або дорівнює     | `a <= b` |
| Дорівнює               | `a == b` |
| Не дорівнює            | `a != b` |

Результат порівняння завжди є булевим значенням (англ. Boolean), тобто або `true`, або `false`.

```jq
1 < 3,      # => true
2 != 2,     # => false
1 == 1.0    # => true
            # All numbers are floating-points, so this is different syntax
            # for the exact same value.
```

### Порівняння рядків тексту

Оператори порівняння вище можна також використовувати для порівняння рядків тексту (англ. string).
У цьому разі застосовується словниковий (лексикографічний) порядок.
Порядок визначається _значенням коду символу Unicode_.

```jq
"Apple" > "Pear",   # => false
"a" < "above",      # => true
"a" == "A"          # => false
```

Треба бути уважними, коли ми порівнюємо дві змінні, які, на перший погляд, містять числові значення, але насправді є рядками тексту.
Через словниковий порядок результат буде не таким, як під час порівняння значень типу число.

```jq
10 < 2,     # => false
"10" < "2"  # => true (because "1" comes before "2")
```

### «Сувора» рівність

Оператор `==` у `jq` схожий на `===` у JavaScript у тому сенсі, що речі, які мають однаковий вигляд, але належать до різних типів, не є рівними.

```jq
"3" == 3    # => false
            # the value on the left has type string,
            # the value on the right has type number.
```

### Порівняння масивів

Два масиви рівні, якщо всі відповідні елементи рівні.

```jq
[1, 2, 3] == [1, 2, 3]      # => true
[1, 2, 3] == [1, 3, 2]      # => false, different order
[1, 2, 3] == [1, 2, "3"]    # => false, different types
```

### Порівняння обʼєктів

Два обʼєкти рівні, якщо вони мають однакові пари ключ-значення.

```jq
{name: "Joe", age: 42} == {age: 42, name: "Joe"}                # => true
{name: "Joe", age: 42} == {age: 42, name: "Jane"}               # => false
{name: "Joe", age: 42} == {age: "42", name: "Joe"}              # => false
{name: "Joe", age: 42} == {age: 42, name: "Joe", height: 175}   # => false

# comparisons will drill down as deeply as required
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2]}}}                  # => true
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2, 3]}}}               # => false
```

## Умовні конструкції

### Вираз `if`

**Умовний вираз** у `jq` має такий вигляд: `if A then B else C end`.

`if-then-else` - це фільтр, як і всі вбудовані функції `jq`: він приймає вхідні дані та видає вихідні дані.

Якщо вираз `A` дає «правдиве» значення, то фільтр `if` обчислює `B`.
Інакше він обчислює `C`.
Вхідні дані фільтра `if` буде передано до `B` або `C`.

```jq
42 | if . < 50 then "small" else "big" end      # => "small"
```

```jq
5 | if . % 2 == 0 then . / 2 else . * 4 end     # => 20
```

~~~~exercism/note
Блок `else` є **необовʼязковим**; наведені нижче дві інструкції рівнозначні.

```jq
if A then B else . end
if A then B end
```
~~~~

### Вкладені умовні конструкції

Додаткові умови можна додавати за допомогою `elif`.

```jq
42 | if . < 33 then "small"
     elif . < 66 then "medium"
     else "big"
     end
# => "medium"
```

Можна використати стільки блоків `elif`, скільки потрібно.

### Правдивість

Єдині «неправдиві» значення в `jq` - це `false` і `null`.
Усе інше є «правдивим», навіть число нуль і порожній рядок тексту, масив та обʼєкт.

### Булеві оператори

**Булеві оператори** `and` та `or` можна використовувати для побудови складних запитів.

```jq
42 | if . < 33 or . > 66 then "big or small"
     else "medium"
     end
```

Щоб заперечити, можна скористатися `not`. Це **фільтр**, а не оператор.

```jq
42 | if (. < 33 or . > 66 | not) then "medium"
     else "big or small"
     end
```

### Оператор альтернативи

**Оператор альтернативи** дає змогу вказати «типове» значення, якщо вираз є неправдивим або `null`.

```jq
A // B

# This is identical to
if A then A else B end
```

Для прикладу

```jq
[3, 5, 18] | add / 2       # => 13
[]         | add / 2       # => error: null (null) and number (2) cannot be divided
[]         | add // 0 / 2  # => 0
```
