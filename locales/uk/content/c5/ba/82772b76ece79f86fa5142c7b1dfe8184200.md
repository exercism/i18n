# Докладніше

У Haxe **масив** - це колекція елементів (зазвичай) одного типу. У Haxe є три способи створити масив: або за допомогою конструктора, або за допомогою синтаксису оголошення. У Haxe перший елемент масиву має індекс нуль:

```haxe
var a = [1, 2, 3];
trace(a); // [1,2,3]

// Here the second element is called by index
trace(a[1]); // 2

// The actual first element's index is 0
trace(a[0]); // 1
```

Щоб створити масив за допомогою конструктора, потрібно передати тип елементів, які будуть включені в масив:

```haxe
var a:Array<Int> = [0, 1, 2, 3];
a[1] = "Hello"; // Error: the array a takes integers only
```

Оскільки доступ до масиву в Haxe є необмеженим, тобто гарантовано не викликає винятку, це потребує додаткового пояснення:

- Якщо читання відбувається за неіснуючим індексом, повертається значення, залежне від цільової платформи.
- Якщо запис відбувається за додатним індексом, який виходить за межі, `null` (або типове значення для базових типів на статичних цілях) вставляється на всі позиції між останнім визначеним індексом і щойно записаним.
- Якщо запис відбувається за відʼємним індексом, результат не визначено.

Якщо ми хочемо, щоб масив містив елементи різних типів, додамо до позначення типу тип `Dynamic`:

```haxe
var a:Array<Dynamic> = [10, "Bob", true]
```

## Ітерація

Масиви можна перебирати за допомогою циклу `for`:

```haxe
var nums = [2, 3, 5];
var sum = 0;
for (num in nums) {
  sum += num;
}
trace(sum); // 10
```
