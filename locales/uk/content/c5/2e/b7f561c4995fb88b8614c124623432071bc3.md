# Інструкції

У цій вправі ми генеруватимемо напівструктуровані лог-повідомлення.

## Створюймо напівструктуровані повідомлення

Ми почнемо з кількох функцій-заглушок і такого переліку:

```rust
#[derive(Drop, Clone, PartialEq, Debug)]
pub enum LogLevel {
    Info,
    Warning,
    Error,
    Debug
}
```

Наша мета - створити лог-повідомлення такого вигляду: `"[<LEVEL>]: <MESSAGE>"`.
Нам потрібно реалізувати функції, що відповідають рівням логування.

Наприклад, наведений фрагмент демонструє очікуваний результат для функції `log`.

```rust
log(LogLevel::Error, "Stack overflow")
// Returns: "[ERROR]: Stack overflow"
```

А для `info`:

```rust
info("Timezone changed")
// Returns: "[INFO]: Timezone changed"
```

Гарного кодування!
