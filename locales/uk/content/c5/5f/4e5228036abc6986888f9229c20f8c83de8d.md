# Вступ

У Common Lisp є багато різних предикатів рівності.
Це відрізняється від інших мов програмування, у яких може бути лише один чи два (наприклад, `==` і `===`).
Деякі з цих предикатів у Common Lisp привʼязані до конкретних типів, а інші є загальними.
Тут розглянемо саме останні.

Є чотири загальні предикати рівності, і вони різняться тим, наскільки суворо визначають, що вважати «рівним».
Ось вони, у порядку від найсуворішого до найменш суворого: `eq`, `eql`, `equal` і `equalp`.

Ось кілька коротких визначень (опускаючи деякі деталі):

- `eq`: визначає рівність так, що два обʼєкти ідентичні.
  _напр._:

```lisp
(eq 'a 'a)                 ; => T
(eq (list 1 2) (list 1 2)) ; => NIL
```

- `eql`: визначає рівність так: два числа з однаковим типом і значенням, два однакові символи, а для всього іншого - якщо вони `eq`.
  _напр._:

```lisp
(eql 1 1)     ; => T
(eql #\a #\a) ; => T
(eql 1 1.0)   ; => NIL
(eql #\a #\A) ; => NIL
```

- `equal`: визначає рівність так: два списки є `equal`, якщо кожен елемент також `equal`; два рядки тексту (англ. string) є `equal`, якщо кожен елемент також `eql`; два масиви є `equal`, якщо вони `eq`; усе інше є `equal`, якщо воно `eql`.
  _напр._:

```lisp
(equal (list 1 2) (list 1 2)) ; => T
(equal #(1 2) #(1 2))         ; => NIL
(equal "foo" "foo")           ; => T
```

- `equalp`: визначає рівність так: рядки тексту й символи порівнюються без урахування регістру; числа порівнюються з певним перетворенням типів; списки й масиви є `equalp`, якщо кожен елемент також `equalp`; структури - якщо вони того самого типу і всі їхні слоти `equalp`; а хеш-таблиці - якщо їхні ключі та значення `equalp`
  _напр._:

```lisp
(equalp "foo" "FoO")                          ; => T
(equalp 3 3.0)                                ; => T
(equalp (make-a-structure :slot1 1 :slot2 2) 
        (make-a-structure :slot1 1 :slot2 2)) ; => T
```
