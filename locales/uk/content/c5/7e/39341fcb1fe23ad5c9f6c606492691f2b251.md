# Вступ

Цикли `for` - найскладніший тип циклу в PHP. Вони поводяться так само, як цикли `for` у `C`, `Java` та `JavaScript`. Основна форма має такий вигляд:

```php
for (expr1; expr2; expr3) {
  // statements
}
```

Перший вираз (_expr1_) обчислюється перед початком циклу. Другий вираз (_expr2_) обчислюється перед кожною ітерацією; якщо він дає _truthy_ значення, інструкції виконуються. Після виконання інструкцій обчислюється третій вираз (_expr3_).
