# Вступ

Основні арифметичні оператори та оператори порівняння можна адаптувати для використання у власних класах і структурах. Це називається _перевантаженням операторів_.

Більшість операторів мають такий вигляд:

```csharp
static <return type> operator <operator symbols>(<parameters>);
```

Оператори приведення мають такий вигляд:

```csharp
static (explicit|implicit) operator <cast-to-type>(<cast-from-type> <parameter name>);
```

Оператори поводяться так само, як статичні методи. Символ оператора займає місце ідентифікатора методу, а оператори мають параметри та тип повернення. Правила типів для параметрів і типу повернення відповідають нашій інтуїції, і ми можемо покластися на компілятор, який надасть докладні вказівки.
