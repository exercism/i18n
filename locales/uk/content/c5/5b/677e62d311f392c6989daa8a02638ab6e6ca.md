# Вступ

## Перетворення типів

Go вимагає явного перетворення між різними типами.
Перетворення між типами (також відоме як **приведення типів**) виконується за допомогою функції з назвою типу, до якого потрібно перетворити.
Наприклад, щоб перетворити `int` на `float64`, потрібно зробити таке:

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
```

## Перетворення між примітивними типами та рядками тексту

Існує пакет `strconv` для перетворення між примітивними типами (як-от `int`) і рядками тексту (англ. string).

```go
import "strconv"

var intString string = "42"
var i, err = strconv.Atoi(intString)

var number int = 12
var s string = strconv.Itoa(number)
```

## Твердження типу

Інтерфейси в Go можуть створювати неоднозначність щодо базового типу.
Твердження типу дає змогу вилучити конкретне значення, що лежить в основі значення інтерфейсу, за допомогою такого синтаксису: `interfaceVariable.(concreteType)`.

Наприклад:

```go
var input any = 12
number := input.(int)
```

ПРИМІТКА: це спричинить паніку, якщо змінна інтерфейсу не містить значення конкретного типу.

Ми можемо перевірити, чи містить значення інтерфейсу конкретний тип, скориставшись обома поверненими значеннями твердження типу: значенням, що лежить в основі, і булевим значенням (англ. Boolean), яке вказує, чи було твердження успішним.
Наприклад:

```go
str, ok := input.(string) // no panic if input is not a string
```

Якщо `input` містить `string`, то `str` буде значенням, що лежить в основі, а `ok` дорівнюватиме правді.
Якщо `input` не містить `string`, то `str` буде нульовим значенням типу `string` (тобто `""`, порожній рядок тексту), а `ok` дорівнюватиме неправді.
Паніки не виникне в жодному разі.

## Перемикачі типів

**Перемикач типів** може виконати кілька тверджень типу послідовно.
Він має той самий синтаксис, що й твердження типу (`interfaceVariable.(concreteType)`), але `concreteType` замінено на ключове слово `type`.
Ось приклад:

```go
var i any = 12 // try: 12.3, true, int64(12), []int{}, map[string]int{}

switch v := i.(type) {
case int:
    fmt.Printf("the integer %d\n", v)
case string:
    fmt.Printf("the string %s\n", v)
default:
    fmt.Printf("type, %T, not handled explicitly: %#v\n", v, v)
}
```
