# Доповнення до інструкцій

## Повідомлення про помилки

Іноді потрібно [викликати виняток][raise-an-exception]. Коли ми це робимо, слід завжди додавати **змістовне повідомлення про помилку**, яке вказує на її джерело. Це робить код зрозумілішим і значно допомагає в налагодженні. Якщо ми знаємо, що джерело помилки матиме певний тип, можна викликати один із [вбудованих типів помилок][built-in-errors], але повідомлення все одно має бути змістовним.

Ця вправа вимагає використати [інструкцію `raise`][raise-statement], щоб «кинути» `ValueError`, якщо питання, передане до `answer()`, має неправильний формат або є недійсним, чи містить невідому операцію. Тести пройдуть лише тоді, коли ми і виконаємо `raise` для `exception`, і додамо до нього повідомлення.
**Зверніть увагу**: потрібне повідомлення відрізняється для кожного сценарію, навіть попри те, що викликається той самий _тип помилки_.
Перевірте тести уважно.

Щоб викликати [`ValueError`][value-error] із повідомленням, запишемо повідомлення як аргумент типу `exception`:


```python
# if the question contains an unknown operation.
raise ValueError("unknown operation")

# if the question is malformed or invalid.
raise ValueError("syntax error")
```

Щоб _обробити_ викликаний виняток у межах певного блоку коду, можна скористатися конструкцією [try-except][handling-exceptions]. Блоки `try-except` «обгортають» код, який потенційно може спричинити помилку, зіставляючи всі винятки з однією помилкою, кількома помилками або іншими фрагментами коду, які мають зарадити проблемі:


```python
while len(equation) > 1:
        try:
           # The questionable/error-prone code goes here,in an indented block
           # It can contain statements, loops, if-else blocks, or other executable code.
           x_value, operation, y_value, *rest = equation
           ...
           ...

        except:
            # Code for what to do when an error gets thrown in the code above.
            # This could be one error, or more complicated logging, error checking and messaging.
            raise ValueError("syntax error")
```
