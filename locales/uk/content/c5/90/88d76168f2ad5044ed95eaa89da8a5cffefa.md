# Вказівки

У місцевій школі неподалік дуже активна асоціація учнів.
Асоціацією учнів керує президент, і раз на 2 роки проводяться вибори, щоб обрати нового президента.

На цьогорічних виборах вирішили, що потрібна нова цифрова система для підрахунку голосів.
Школі потрібна наша допомога, щоб створити цю нову систему.

## 1. Створити лічильник голосів

Новій системі голосування передусім потрібен лічильник голосів.
Цей лічильник дає змогу відстежувати кількість голосів, які має певний кандидат.

Створіть функцію `NewVoteCounter`, яка приймає початкову кількість голосів кандидата і повертає вказівник на `int`, ініціалізований цією кількістю початкових голосів.

```go
var initialVotes int
initialVotes = 2

var counter *int
counter = NewVoteCounter(initialVotes)
*counter == initialVotes // true
```

## 2. Отримати кількість голосів із лічильника

Тепер у нас є спосіб створювати нові лічильники! Але тепер ми розуміємо, що новій системі також знадобиться спосіб отримувати кількість голосів із лічильника.

Створіть функцію `VoteCount`, яка приймає лічильник (`*int`) як аргумент і повертає кількість голосів у лічильнику.
Якщо лічильник дорівнює `nil`, вважайте, що в ньому немає голосів:

```go
var votes int
votes = 3

var voteCounter *int
voteCounter = &votes

VoteCount(voteCounter)
// => 3

var nilVoteCounter *int
VoteCount(nilVoteCounter)
// => 0
```

## 3. Збільшити кількість голосів у лічильнику

Нарешті настав час підрахувати голоси! Тепер нам потрібен спосіб збільшувати кількість голосів у лічильнику.

Створіть функцію `IncrementVoteCount`, яка приймає лічильник (`*int`) як аргумент і число голосів, і збільшує лічильник на це число голосів.
Можна вважати, що переданий вказівник ніколи не буде `nil`.

```go
var votes int
votes = 3

var voteCounter *int
voteCounter = &votes

IncrementVoteCount(voteCounter, 2)

votes == 5          // true
*voteCounter == 5   // true
```

## 4. Створити результати виборів

Тепер, коли всі голоси підраховано, настав час підготувати оголошення результатів для всієї школи.
Для цього ми помічаємо, що самих лише лічильників голосів недостатньо.
Потрібен спосіб повʼязати кількість голосів із певним кандидатом.

Створіть функцію `NewElectionResult`, яка приймає імʼя кандидата та кількість його голосів і повертає новий результат виборів.

```go
var result *ElectionResult
result = NewElectionResult("Peter", 3)

result.Name == "Peter"  // true
result.Votes == 3       // true
```

Структуру результату виборів уже створено для нас, і вона визначена так:

```go
type ElectionResult struct {
    // Name of the candidate
    Name    string
    // Votes of votes the candidate had
    Votes   int
}
```

## 5. Оголосити результати

Настав час оголосити школі нового президента!
Про нового президента оголосять на маленьких цифрових табло, які є в школі.
Повідомлення має містити імʼя нового президента та кількість голосів, які він отримав, у такому форматі: `<candidate_name> (<votes>)`.
Ось приклад такого повідомлення: `"Peter (51)"`.

Створіть функцію `DisplayResult`, яка приймає `*ElectionResult` як аргумент і повертає рядок тексту (англ. string) з повідомленням для показу.

```go
var result *ElectionResult
result = &ElectionResult{
    Name: "John",
    Votes: 32,
}

DisplayResult(result)
// => John (32)
```

## 6. Перерахунок голосів

Щоб переконатися, що остаточні результати точні, голоси перерахували.
Під час перерахунку зʼясувалося, що кількість голосів деяких кандидатів відрізнялася на одиницю.

Створіть функцію `DecrementVotesOfCandidate`, яка приймає остаточні результати та імʼя кандидата, кількість голосів якого потрібно зменшити на одиницю.
Остаточні результати подано у вигляді `map[string]int`, де ключами є імена кандидатів, а значеннями - загальна кількість їхніх голосів.

```go
var finalResults = map[string]int{
    "Mary":  10,
    "John":  51,
}

DecrementVotesOfCandidate(finalResults, "Mary")

finalResults["Mary"]
// => 9
```
