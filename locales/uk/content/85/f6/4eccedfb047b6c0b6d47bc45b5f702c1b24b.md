# Додаток до інструкцій

## Реалізація

Визначте одну функцію Go, Solve, яка приймає рядок тексту (англ. string) із головоломкою, що може містити нуль або більше операторів + і один оператор ==; Solve має спробувати розвʼязати головоломку альфаметики та повернути словник усіх замін літер як для головоломки, так і для розвʼязку додавання.

Використайте такий підпис для функції Solve:

```go
func Solve(puzzle string) (map[string]int, error) {
```

Solve має повернути помилку, якщо для заданої головоломки немає розвʼязку.

Приклад головоломки та поверненого розвʼязку:

```go
Solve("SEND + MORE == MONEY")
```

поверне

```go
map[string]int{"M":1, "O":0, "N":6, "E":5, "Y":2, "S":9, "D":7, "R":8}, nil
```

```text
  S E N D
  M O R E +
-----------
M O N E Y
```

Якщо замінити їх на коректні числа, отримаємо:

```text
  9 5 6 7
  1 0 8 5 +
-----------
1 0 6 5 2
```
