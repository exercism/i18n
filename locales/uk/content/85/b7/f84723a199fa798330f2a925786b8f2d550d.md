# Вказівки

У цій вправі ми напишемо трохи коду, який допоможе приготувати чудову лазанью з улюбленої кулінарної книги.
На нас чекають чотири завдання, усі повʼязані з часом, витраченим на приготування лазаньї.

## 1. Визначте очікуваний час у печі в хвилинах

Визначте константу `expectedMinutesInOven`, яка зберігає, скільки хвилин лазанья має бути в печі.
Згідно з кулінарною книгою, очікуваний час у печі становить 40 хвилин:

```swift
expectedMinutesInOven
// Returns 40
```

## 2. Обчисліть час, що залишився в печі, у хвилинах

Визначте функцію `remainingMinutesInOven(elapsedMinutes:)`, яка приймає аргумент `elapsedMinutes`, що містить кількість хвилин, які лазанья вже провела в печі.
Функція має повернути, скільки хвилин лазаньї ще потрібно залишатися в печі, спираючись на очікуваний час у печі з попереднього завдання.

```swift
remainingMinutesInOven(elapsedMinutes: 30)
// Returns 10
```

## 3. Обчисліть час на підготовку в хвилинах

Визначте функцію `preparationTimeInMinutes(layers:)`, яка приймає аргумент `layers`, що містить кількість шарів, доданих до лазаньї.
Функція має повернути, скільки хвилин ми витратили на підготовку лазаньї, якщо кожен шар забирає 2 хвилини.

```swift
preparationTimeInMinutes(layers: 2)
// Returns 4
```

## 4. Обчисліть загальний час роботи в хвилинах

Визначте функцію `totalTimeInMinutes(layers:elapsedMinutes:)`, яка приймає два аргументи: параметр `layers` - це кількість шарів, доданих до лазаньї, а параметр `elapsedMinutes` - це кількість хвилин, які лазанья провела в печі.
Функція має повернути, скільки хвилин загалом ми витратили на приготування лазаньї, тобто суму часу на підготовку в хвилинах і часу в хвилинах, який лазанья на цей момент провела в печі.

```swift
totalTimeInMinutes(layers: 3, elapsedMinutes: 20)
// Returns 26
```
