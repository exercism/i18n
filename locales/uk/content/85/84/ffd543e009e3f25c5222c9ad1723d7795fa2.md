# Запуск тестів

Щоб запустити набір тестів, виконайте таку команду:

```bash
stack test
```

#### Якщо ми побачимо таке повідомлення про помилку...

```
No .cabal file found in directory
```

або

```
RedownloadInvalidResponse Request {
...
}
 "/home/username/.stack/build-plan/lts-xx.yy.yaml" (Response {responseStatus = Status {statusCode = 404, statusMessage = "Not Found"},
```

Ймовірно, у нас стара версія stack, і її потрібно оновити. Спробуймо виконати:

```bash
stack upgrade
```

Або подивімося інші способи оновлення в [документації Stack](https://docs.haskellstack.org/en/stable/install_and_upgrade/#upgrade).

#### Інакше, якщо ми побачимо таке повідомлення про помилку...

```
No compiler found, expected minor version match with...
Try running "stack setup" to install the correct GHC...
```

Просто зробіть так, як там сказано, і потрібну версію компілятора буде завантажено й встановлено:

```bash
stack setup
```

# Запуск *GHCi*

Якщо ми хочемо погратися зі своїм рішенням у GHCi, просто виконайте команду:

```bash
stack ghci
```
