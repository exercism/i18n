# Вступ

## Типи функцій

Якщо прибрати з сигнатури функції Swift усі назви та мітки, залишиться лише тип цієї функції.

```swift
func shoppingList(item: String, quantity: Int) -> String {
  "You need to buy \(quantity) \(item)."
}
// shoppingList: (String, Int) -> String

func repeater(_ phrase: String, times: Int) -> String {
  var result = ""
  for _ in 1...times {
    result += phrase
  }
  return result
}
// repeater: (String, Int) -> String

func printString(line: String) {
  print(line)
}
// printString: (String) -> ()
```

Звернімо увагу, що типи перших двох функцій однакові, `(String, Int) -> String`, хоча ці дві сигнатури різні й самі функції працюють зовсім по-різному. Обидві вони приймають `String` та `Int` як вхідні дані й повертають `String`. А як бачимо з типу третьої функції, навіть попри те, що тіло функції начебто нічого не повертає, насправді воно неявно повертає `()`, єдине значення типу `Void`.

Ці типи функцій можна використовувати так само, як і будь-який інший тип у Swift. Наприклад, у оголошенні змінних або констант. А оскільки функції у Swift є значеннями, уже наявні функції можна присвоювати цим константам і змінним:

```swift
var stringAndIntToString: (String, Int) -> String

stringAndIntToString = shoppingList
stringAndIntToString("carrots", 3)
// => "You need to buy 3 carrots."
```

Як і з іншими змінними та константами, значення, яке ми присвоюємо, має бути правильного типу:

```swift
stringAndIntToString = printShoppingList
// Error: Cannot assign value of type '(String) -> ()' to type '(String, Int) -> String'
```

## Типи функцій як типи параметрів

Оскільки типи функцій можна використовувати будь-де, де можна використовувати інші типи, з цього випливає, що їх можна використовувати як типи параметрів, передавати в інші функції та викликати зсередини цих функцій.

```swift
func apply3(to str: String, function f: (String, Int) -> String) -> String {
  f(str,3)
}
// apply3: ([String], (String, Int) -> String) -> [String]

apply3(to: "eggs", function: shoppingList)
// => "You need to buy 3 eggs."

apply3(to: "eggs", function: repeater)
// => "eggseggseggs"
```

## Типи функцій як типи повернених значень

Так само типи функцій можна використовувати як типи повернених значень. Іншими словами, можна писати функції, які створюють і повертають інші функції. Створюючи такі функції, функція, яку повертають, може використовувати інші параметри, передані у функцію, або локальні змінні, створені всередині батьківської функції.

```swift
func makeAdder(base: Int) -> (Int) -> Int {
  func adder(_ i: Int) -> Int {
    base + i
  }
  return adder
}
// makeAdder: (Int) -> (Int) -> Int

let add10 = makeAdder(base: 10)
// add10: (Int) -> Int

let subtract20 = makeAdder(base: -20)
// subtract20: (Int) -> Int

add10(5)
// => 15

subtract20(5)
// => -15
```
