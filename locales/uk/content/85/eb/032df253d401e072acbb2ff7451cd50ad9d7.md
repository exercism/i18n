# Вступ

Python представляє значення правди та неправди за допомогою типу [`bool`][bools], який є підкласом `int`.
Під цим типом є лише два значення: `True` та `False`.
Ці значення можна присвоїти змінній:

```python
>>> true_variable = True
>>> false_variable = False
```

Ми можемо обчислювати булеві вирази (англ. Boolean) за допомогою операторів `and`, `or` та `not`.

```python
>>> true_variable = True and True
>>> false_variable = True and False

>>> true_variable = False or True
>>> false_variable = False or False

>>> true_variable = not False
>>> false_variable = not True
```

[bools]: https://docs.python.org/3/library/stdtypes.html#typebool
