Але дещо тут переплутано: координати Азари, схоже, записані та відсортовані не так, як у Руї, тож їм доводиться раз у раз переглядати один список за одним, щоб зрозуміти, які скарби відповідають яким місцям.
Як програмісти-початківці на Julia, вони звернулися до нас по допомогу з написанням невеликої програми (насправді набору функцій), щоб краще впорядкувати інформацію про свої пошуки.

## 1. Витягти координати

Реалізуйте функцію `get_cooordinate()`, яка приймає пару `(treasure, coordinate)` зі списку Азари й повертає лише витягнуту координату на карті.

```julia-repl
julia> get_cooordinate( ("Scrimshaw Whale's Tooth", "2A") )
"2A"
```

## 2. Відформатувати координати

Реалізуйте функцію `convert_coordinate()`, яка приймає координату у форматі «2A» і повертає кортеж у форматі `('2', 'A')`.

```julia-repl
julia> convert_coordinate("2A")
('2', 'A')
```

## 3. Зіставити координати

Реалізуйте функцію `compare_records()`, яка приймає пару `(treasure, coordinate)` та запис `(location, coordinate, quadrant)` і порівнює координати з кожного з них.
Поверніть **`true`**, якщо координати «збігаються», і **`false`**, якщо ні.
За потреби переформатуйте координати, щоб порівняння було точним.

```julia-repl
julia> compare_records(("Brass Spyglass", "4B"), ("Seaside Cottages", ('1', 'C'), "blue"))
false

julia> compare_records(("Model Ship in Large Bottle", "8A"), ("Harbor Managers Office", ('8', 'A'), "purple"))
true
```

## 4. Обʼєднати зіставлені записи

Реалізуйте функцію `create_record()`, яка приймає пару `(treasure, coordinate)` зі списку Азари та запис `(location, coordinate, quadrant)` зі списку Руї й повертає `(coordinate, location, quadrant, treasure)`, **якщо координати збігаються**.

Якщо координати _не_ збігаються, поверніть порожній кортеж.
За потреби переформатуйте координати, щоб порівняння було точним.

```julia-repl
julia> create_record(("Brass Spyglass", "4B"), ("Abandoned Lighthouse", ('4', 'B'), "Blue"))
("4B", "Abandoned Lighthouse", "Blue", "Brass Spyglass")

julia> create_record(("Brass Spyglass", "4B"), ("Seaside Cottages", ('1', 'C'), "Blue"))
()
```
