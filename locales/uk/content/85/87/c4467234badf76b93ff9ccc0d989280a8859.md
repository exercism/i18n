# Вступ

*Disposable* - це будь-що, що утримує ресурс операційної системи (відкритий файл, сокет, замок на основі хеш-таблиці), і яке треба звільнити, коли ми закінчуємо з ним роботу. Словник [`destructors`][destructors] у Factor загортає їх у невеликий framework, тож очищення відбувається навіть тоді, коли виняток розгортає стек.

```factor
USING: destructors io.files io.encodings.utf8 ;

"log.txt" utf8 <file-writer> [
    "hello, world" write
] with-disposal
! file is closed even if write throws
```

`with-disposal ( disposable quot -- )` виконує блок коду з ресурсом і звільняє його після виходу. Якщо ресурсів більше ніж один, відкриваємо область видимості за допомогою `with-destructors` і реєструємо кожен із них через `&dispose` (звільнення і після нормального виходу, *і* в разі помилки) або `|dispose` (звільнення лише в разі помилки).

Клас долучається до framework, успадковуючи `disposable` і реалізуючи узагальнену функцію `dispose*`: framework викликає його один і тільки один раз на кожен обʼєкт. Публічне слово, яке використовують для виклику, - це `dispose`.

[destructors]: https://docs.factorcode.org/content/vocab-destructors.html
