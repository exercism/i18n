# Тести

## Запуск тестів

Щоб запустити тести, виконайте таку команду:

```bash
dotnet test
```

## Розвʼязування вправи

Розвʼязати вправу - це зробити так, щоб усі її тести проходили. Типово під час запуску тестів виконується лише один тест (перший). Це зроблено навмисно, щоб ми могли зосередитися лише на тому, щоб цей один тест пройшов. Коли він пройде, можна увімкнути наступний тест, прибравши `Skip = "Remove this Skip property to run this test"` з атрибута `[<Fact>]` або `[<Theory>]` цього тесту. Коли всі тести буде увімкнено і наша реалізація зробить так, що вони всі проходять, вправу розвʼязано!

Щоб допомогти нам почати, кожна вправа містить файл-заглушку з реалізацією. Цей файл можна використати як відправну точку для побудови свого рішення. Сміливо видаляйте або змінюйте цей файл, якщо вважаєте, що це доречно.

## Використання пакетів

Більшість вправ можна розвʼязати без жодних зовнішніх пакетів. Однак у вправах, де зовнішній пакет справді потрібен, його можна додати до свого проєкту, виконавши таку команду:

```bash
dotnet add package [package-name]
```
