# Доповнення до інструкцій

## Регістри

| Регістр | Використання       | Тип     | Опис                                                  |
| -------- | ------------ | ------- | -------------------------------------- |
| `$a0`    | вхідні дані        | адреса | перший колір як рядок тексту (англ. string) із завершальним нулем  |
| `$a1`    | вхідні дані        | адреса | другий колір як рядок тексту із завершальним нулем |
| `$a2`    | вхідні дані        | адреса | третій колір як рядок тексту із завершальним нулем  |
| `$a3`    | вхідні та вихідні дані | адреса | вихідний рядок тексту із завершальним нулем          |
| `$t0-9`  | тимчасовий    | будь-який     | використовується для тимчасового зберігання             |
