# Вступ

## Числа

У Java є два різні типи чисел:

- Цілі числа: числа без цифр після десяткового розділювача (цілі числа).
  Приклади: `-6`, `0`, `1`, `25`, `976` і `-500000`.
- Числа з плаваючою комою: числа з нулем або більше цифр після десяткового розділювача.
  Приклади: `-20.4`, `0.1`, `2.72`, `16.984025` і `1024.0`.

У Java найчастіше використовують два числові типи: `int` і `double`.
`int` - це 32-бітове ціле число, а `double` - 64-бітове число з плаваючою комою.

Арифметичні дії виконують за допомогою стандартних арифметичних операторів.
Числа можна порівнювати за допомогою стандартних операторів порівняння (наприклад, `5 > 4` і `4 <= 5`), а також операторів рівності (`==`) і нерівності (`!=`).

У Java є два типи числових перетворень:

1. Неявні перетворення: дані не втрачаються, і додатковий синтаксис не потрібен.
2. Явні перетворення: дані можуть втратитися, і потрібен додатковий синтаксис у вигляді _приведення типу_.

Оскільки точність `int` менша, ніж у `double`, перетворення з `int` у `double` безпечне, тож це неявне перетворення.
Однак перетворення з `double` у `int` може призвести до втрати даних, тому воно потребує явного перетворення.

## Інструкції if-else

### Інструкція _if-then_

Найпростіша інструкція керування потоком виконання в Java - інструкція _if-then_.
Цю інструкцію використовують, щоб виконувати частину коду лише за певної умови, яка дорівнює `true`.
Інструкцію _if-then_ визначають за допомогою конструкції `if`:

```java
class Car {
    void drive() {
        // the "if" clause: the car needs to have fuel left to drive
        if (fuel > 0) {
            // the "then" clause: the car drives, consuming fuel
            fuel--;
        }
    }
}
```

У наведеному прикладі, якщо в машині закінчилося пальне, виклик методу `Car.drive` нічого не зробить.

### Інструкція _if-then-else_

Інструкція _if-then-else_ дає альтернативний шлях виконання на випадок, коли умова в конструкції `if` набуває значення `false`.
Цей альтернативний шлях виконання йде після конструкції `if` і визначається за допомогою конструкції `else`:

```java
class Car {
    void drive() {
        if (fuel > 0) {
            fuel--;
        } else {
            stop();
        }
    }
}
```

У наведеному прикладі, якщо в машині закінчилося пальне, виклик методу `Car.drive` викличе інший метод, щоб зупинити машину.

Інструкція _if-then-else_ також підтримує кілька умов за допомогою конструкції `else if`:

```java
class Car {
    void drive() {
        if (fuel > 5) {
            fuel--;
        } else if (fuel > 0) {
            turnOnFuelLight();
            fuel--;
        } else {
            stop();
        }
    }
}
```

У наведеному прикладі, якщо пального залишилося `5` або менше, машина поїде, але при цьому увімкнеться індикатор пального.
Коли пальне сягне `0`, машина перестане рухатися.
