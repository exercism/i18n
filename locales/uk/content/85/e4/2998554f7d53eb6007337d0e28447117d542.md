# Інструкції

Ми працюємо за стійкою охорони на дослідницькій станції. Працівники носять *перепустки*, коди яких мають строгий формат, журнал доступу повен таких кодів, перемішаних зі звичайним текстом, і його потрібно очистити, перш ніж ним можна буде поділитися. Для кожного з цих завдань найкращий інструмент - регулярні вирази.

Дійсний код перепустки - це **дві великі літери, дефіс, а потім чотири цифри**, наприклад `NS-1024`.

## 1. Перевірити код перепустки

Визначте `valid-badge?`, яка приймає рядок тексту (англ. string) із кодом перепустки та повертає `t`, коли *весь* цей рядок є дійсним кодом перепустки, і `f` в іншому разі.

```factor
"NS-1024" valid-badge? .   ! => t
"NS-10"   valid-badge? .   ! => f
```

## 2. Витягнути всі коди з рядка журналу

Визначте `badge-codes`, яка приймає рядок журналу доступу та повертає послідовність усіх кодів перепусток, що в ньому трапляються, у порядку появи.

```factor
"seen NS-1024 then AB-0007 today" badge-codes .
! => { "NS-1024" "AB-0007" }
```

## 3. Порахувати цифри в коді

Визначте `digit-count`, яка приймає рядок тексту та повертає, скільки цифр він містить.

```factor
"NS-1024" digit-count .   ! => 4
```

## 4. Замаскувати паролі

Іноді рядки журналу записують пароль як `pass=`, за яким іде секрет (будь-яка послідовність символів, крім пробілів). Визначте `redact`, яка приймає рядок і повертає його, замінивши кожен такий пароль на `pass=****`.

```factor
"user=alice pass=hunter2 ok" redact .
! => "user=alice pass=**** ok"
```
