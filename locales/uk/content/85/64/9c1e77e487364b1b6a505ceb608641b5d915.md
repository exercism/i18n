# Інструкції

У цій вправі ми будемо писати код, який допоможе фрилансеру спілкуватися з клієнтами про ціни на певні проєкти.
Ми напишемо кілька допоміжних функцій, щоб швидко розраховувати вартість для клієнтів.

```exercism/note
Змінна `ratePerHour` і функція `dayRate` стосуються грошей.
Ми вимірюємо гроші за одиницю часу: відповідно за годину та за день.
```

## 1. Розрахуйте денну ставку на основі погодинної ставки

Клієнт звертається до фрилансера, щоб дізнатися про його ставки.
Фрилансер пояснює, що **_працює 8 годин на день._**
Однак фрилансер знає лише погодинні ставки на проєкт.
Допоможіть йому оцінити денну ставку на основі погодинної ставки.

```javascript
dayRate(89);
// => 712
```

Денну ставку не потрібно округлювати чи приводити до «фіксованої» точності.

## 2. Розрахуйте кількість робочих днів на основі фіксованого бюджету

Наступного дня менеджер проєкту пропонує фрилансеру попрацювати над проєктом із фіксованим бюджетом.
Маючи фіксований бюджет і погодинну ставку фрилансера, допоможіть йому розрахувати кількість днів, які він працюватиме, поки бюджет не вичерпається.
Результат _обовʼязково_ потрібно **округлити в менший бік** до найближчого цілого числа.

```javascript
daysInBudget(20000, 89);
// => 28
```

## 3. Розрахуйте ставку зі знижкою для великих проєктів

Часто клієнти наймають фрилансера на проєкти, що тривають кілька місяців.
У таких випадках фрилансер вирішує дати знижку за кожен повний місяць, а решту днів оплачують за денною ставкою.
Завдяки чудовому балансу між роботою та життям ми працюємо лише 22 дні в кожному календарному місяці, тож **_у кожному місяці 22 оплачувані дні._**
Допоможіть йому оцінити вартість таких проєктів, маючи погодинну ставку, кількість оплачуваних днів у проєкті та місячну ставку знижки.
Знижку завжди передають як число, де `42%` стає `0.42`. Результат _обовʼязково_ потрібно **округлити в більший бік** до найближчого цілого числа.

```javascript
priceWithMonthlyDiscount(89, 230, 0.42);
// => 97972
```
