# Вступ

Хеш-таблиці в Common Lisp — це структури даних для зберігання асоціативних даних.
Вони зіставляють ключі (якими може бути будь-який обʼєкт) зі значеннями (якими може бути будь-який обʼєкт).
В інших мовах це поняття можуть називати відображеннями, словниками або хешами.

## Створення хеш-таблиць

Хеш-таблиці можна створити за допомогою функції `make-hash-table`.

`(make-hash-table) ; => #<HASH-TABLE :TEST EQL :COUNT 0 {10024AD2B3}>`

(Зауважте, що надруковане представлення хеш-таблиці залежить від реалізації, тож у REPL воно може мати інший вигляд.)

## Отримання значень за ключами

Щоб отримати значення за ключем із хеш-таблиці, скористаймося функцією `gethash`:

```lisp
*h* ; => #<HASH-TABLE :TEST EQL :COUNT 3 {10024AD2B3}>`
(gethash :foo *h*) ; => :bar
                   ;    T
```

`gethash` повертає [кілька значень][concept-multiple-values], які ми розглянемо в іншому понятті.

## Вставлення значень

Щоб вставити значення в хеш-таблицю, скористаймося `setf` разом із `gethash` ось так:

`(setf (gethash :foo *hash-table*) :bar) : => :bar`

Це змінить значення для ключа `:foo` у хеш-таблиці `*hash-table*` на `:bar`.
Воно повертає це значення.

Використання `setf` ми розглянемо в іншому понятті.
