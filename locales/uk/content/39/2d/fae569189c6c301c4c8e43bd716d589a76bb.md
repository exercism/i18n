# Інструкції

У нашого друга є старий оптовий магазин під назвою **Gross Store**.

Назва походить від кількості товару, який продає магазин: усе вимірюється в [одиницях грос][gross-unit].

Друг попросив нас реалізувати для його магазину систему для точки продажу (POS).

**Спершу ми хочемо створити для неї прототип.**

**У прототипі наша система записуватиме лише кількість.**

Друг дав нам список мір, щоб допомогти:

| Одиниця            | Значення |
| ------------------ | -------- |
| quarter_of_a_dozen | 3        |
| half_of_a_dozen    | 6        |
| dozen              | 12       |
| small_gross        | 120      |
| gross              | 144      |
| great_gross        | 1728     |

## 1. Збережіть одиницю вимірювання у програмі

Щоб скористатися мірою, потрібно зберегти її у програмі.

```rust
let units = units();
// Felt252Dictionary with entries like { 'dozen': 12 }
```

## 2. Створіть новий рахунок покупця

Потрібно реалізувати функцію, яка створює новий (порожній) рахунок для покупця.

```rust
let bill = new_bill();
// Empty Felt252Dictionary
```

## 3. Додайте товар до рахунку покупця

Щоб це реалізувати, потрібно:

- Повернути `false`, якщо `unit` відсутня у словнику `units`.
- Інакше додати товар до рахунку покупця `bill`, індексуючи його за назвою товару, а потім повернути `true`.
- Якщо товар уже є в рахунку, збільшити його кількість на величину, яку задає вказана `unit`.

```rust
let bill = new_bill();
let units = units();
let ok = add_item(bill, units, 'carrot', 'dozen');
println!(ok);
// Output: true (since dozen is a valid unit)
```

> Зауважимо, що повернене значення має тип `bool`.

## 4. Приберіть товар із рахунку покупця

Щоб це реалізувати, потрібно:

- Повернути `false`, якщо наданого товару **немає** в рахунку.
Товар вважається відсутнім у рахунку, якщо його кількість дорівнює 0.
- Повернути `false`, якщо `unit` відсутня у словнику `units`.
- Повернути `false`, якщо нова кількість була б меншою за 0.
- Якщо нова кількість дорівнює 0, товар вважається видаленим із `bill`, тож можна повернути `true`.
- Інакше зменшити кількість товару і повернути `true`.

```rust
let bill = new_bill();
let units = units();
let ok = remove_item(bill, units, 'carrot', 'dozen');
println!(ok);
// Output: false (because there are no carrots in the bill)
```

> Зауважимо, що повернене значення має тип `bool`.

## 5. Поверніть кількість конкретного товару, який є в рахунку покупця

```rust
let mut bill: Felt252Dict<u32> = Default::default();
bill.insert('carrot', 12);
bill.insert('grapes', 3);
let qty = get_item(bill, 'carrot');
println!(qty);
// Output: 12
```

> Зауважимо, що повернене значення має тип `u32`.
