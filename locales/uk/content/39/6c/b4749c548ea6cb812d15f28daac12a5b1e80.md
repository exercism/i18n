# Додаток до інструкцій

## Функції та тестування

Нам надано початкове визначення функції `SayHi`.

```delphi
function SayHi : string;
begin
  result := 'Goodbye, Mars!';
end;
```

Засіб запуску тестів бере цю функцію, запускає її та порівнює значення, яке вона [returns], з очікуваним значенням.
Використайте це початкове визначення функції як основу для свого рішення.

[returns]: https://www.freepascal.org/docs-html/3.2.2/ref/refse94.html
