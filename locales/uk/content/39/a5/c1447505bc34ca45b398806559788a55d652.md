# Вступ

`list` у R - це впорядкована колекція елементів, яка відрізняється від `vectors` кількома особливостями:

- Елементи можуть мати різні типи (наприклад, поєднувати `numeric` з `character`).
- Елементи можуть бути складними структурами (наприклад, вектори, інші масиви тощо).
- Синтаксис доступу до елементів дещо інший.

Аналогії з іншими мовами неточні. 
`list` у R дещо схожий на словник у Python, але він упорядкований, і до його елементів можна звертатися за числовим індексом.
Він дещо схожий на `struct` у C, за винятком того, що `list` можна легко розширити під час виконання.

## Створення масивів

Давати елементам імена (які часто називають «тегами») частіше доводиться в масивах, ніж у векторах:

```R
list(x = 5.3, y = 4.2, color = "blue")
$x
#> [1] 5.3

$y
#> [1] 4.2

$color
#> [1] "blue"
```

Однак теги необовʼязкові, і тоді R просто використає номери індексів:

```R
list(5.3, 4.2, "blue")
#> [[1]]
#> [1] 5.3

#> [[2]]
#> [1] 4.2

#> [[3]]
#> [1] "blue"
```

## Доступ до елементів масиву

Є три способи зробити це, і кожен із них стане в пригоді в різних ситуаціях.

### 1. За допомогою нотації `$tag`

Дуже поширений, якщо назви тегів відомі заздалегідь.

```R
point <- list(x = 5.3, y = 4.2, color = "blue")
point$x
#> [1] 5.3
point$color
#> [1] "blue"
```

### 2. За допомогою нотації `[[tag]]`

Його перевага в тому, що назву тега можна вибрати під час виконання.
Звернімо увагу на подвійні дужки.

```R
want <- "y"
point[[want]] # same as point$y
#> [1] 4.2
```

### 3. За допомогою позиційного індексу

Він працює незалежно від того, чи має масив теги.
І знову дужки подвоюються.

```R
point[[3]] # same as point$color
#> [1] "blue"
```

## Додавання та видалення елементів

Усе просто: присвоєння елементу змінює його, якщо він уже існує, або додає новий, якщо його немає.

```R
point$color <- "red"
point[[trust]] <- TRUE
str(point)
#> List of 4
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
#>  $ trust: logi TRUE
```

Щоб видалити, присвоймо небажаному елементу `NULL`.

```R
point$trust <- NULL
str(point)
#> List of 3
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
```
