# Вступ

Масив у Gleam - це незмінна колекція з нуля або більше значень. Усі значення в масиві повинні мати однаковий тип. Оскільки масиви незмінні, щойно масив створено, його значення вже не може змінитися. Будь-які функції чи оператори, які на вигляд змінюють масив (наприклад, додають елемент), насправді повертають новий масив.

Масиви можна визначати так:

```gleam
let empty = []
let singleValue = [5]
let threeValues = ["a", "b", "c"]
```

Найчастіше елемент додають до масиву за допомогою синтаксису розгортання:

```gleam
let two_to_four = [2, 3, 4]
let one_to_four = [1, ..two_to_four]
// -> [1, 2, 3, 4]
```

Модуль [`gleam/list`](https://hexdocs.pm/gleam_stdlib/gleam/list.html) зі стандартної бібліотеки Gleam містить багато корисних функцій для роботи з масивами. Цей модуль дуже часто використовують у коді Gleam, тож варто з ним ознайомитися.

Зразки масивів можна використовувати у виразах `case`, щоб зіставляти їх із масивами та присвоювати змінним значення, які в них містяться:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [] -> "Empty list"
    [x] -> "List with one item: " <> x
    [x, y] -> "List with two items: " <> x <> " and " <> y
    _ -> "List with three or more items"
  }
}
```

Окрім зіставлення з масивами точної довжини, синтаксис розгортання дає змогу зіставляти масиви довжиною щонайменше певного числа:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [_, _, ..] -> "List with at least two items"
    [_] -> "List with one item"
    [] -> "Empty list"
  }
}
```

Синтаксис розгортання також дає змогу присвоїти решту масиву змінній:

```gleam
pub fn remove_first_item(list: List(String)) -> List(String) {
  case list {
    // Return the list without the first item
    [_, ..rest] -> rest

    // There's no first item to remove, return an empty list
    _ -> []
  }
}
```

У виразах `case` варто мати зразок для кожного можливого значення типу, з яким відбувається зіставлення, тому завершальний зразок-замінник (`_`) часто використовують, щоб охопити всі решта значень.
