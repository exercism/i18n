# Кортежі

Кортежі в Elm можуть містити два або три значення, і кожне значення може мати будь-який тип.
У Elm кортежі здебільшого використовують для простих тимчасових типів.
Тому кортежі мають щонайбільше 3 значення, а щоб заохотити до цього ще більше, зручні функції передбачено лише для 2 значень.
Для складніших даних краще перейти на записи.
Часто кортежі потрібні, коли треба повернути з функції більше ніж одне значення.
Поля кортежу не мають назв; доступ до них отримують через деструктуризацію або за позицією.

Можна прочитати [стислий вступ до кортежів][tuples-concise].
Також є [докладніший вступ][tuples-in-depth], а [документація API модуля `Tuple`][tuple-core] містить приклади коду й детальний опис.

## Оголошення

Типи для кортежів створюють за допомогою дужок, а їхні типи елементів розділяють комами.

```elm
type alias IntStringTuple = (Int, String)
```

### Створення

Кортежі створюють за допомогою дужок, а їхні елементи розділяють комами.

```elm
aTuple : IntStringTuple
aTuple = (123, "elements can be of differing types")
```

Також можна використати `Tuple.pair`, щоб створити кортеж із двома значеннями.

```elm
anotherTuple : (String, String)
anotherTuple = Tuple.pair "this time it's" "two strings"
    --> ("this time it's", "two strings")
```

### Доступ

Є також функції для доступу до значень кортежу за позицією: `Tuple.first` і `Tuple.second`.

```elm
Tuple.first aTuple
    --> 123

Tuple.second aTuple
    --> "elements can be of differing types"
```

Кортежі можна _деструктурувати_ у привʼязуваннях, використовуючи зіставлення зі зразком кортежу.
Деструктуризацію можна виконувати у виразах `let`, оголошеннях функцій та конструкціях `case`.

```elm
repeatString : (Int, String) -> Bool
repeatString aTuple =
let
    (aNumber, aString) = aTuple
in
    String.repeat aNumber aString

repeatStringAgain : (Int, String) -> Bool
repeatStringAgain (aNumber, aString) = String.repeat aNumber aString
```

Зіставлення зі зразком у конструкції `case` також дає змогу зіставляти вміст значень:

```elm
has123 : (Int, String, Bool) -> Bool
has123 aTuple =
    case aTuple of
        (123, _, _) ->
            True
        (_, "123", _) ->
            True
        (_, _, True) ->
            True
        _ ->
            False
```
