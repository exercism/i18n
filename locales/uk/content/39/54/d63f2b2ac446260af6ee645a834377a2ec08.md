# Про це

У PHP є низка вбудованих конструкцій для керування циклами, зокрема `while`. Базова форма інструкції `while` має такий вигляд:

```php
while (expr) {
  // statements
}
```

Поки вираз (_expr_) має _правдиве_ значення, він перебирає інструкції в тілі циклу. Якщо вираз (_expr_) набуває значення неправда ще перед першою ітерацією, інструкції не виконуються жодного разу.

Або можна використати цикл `do-while`, який один раз виконує інструкції, перш ніж обчислити вираз (_expr_).

```php
do {
  // statements
} while (expr);
```
