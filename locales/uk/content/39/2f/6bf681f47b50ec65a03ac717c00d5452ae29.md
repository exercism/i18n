# Вступ

## Псевдонім

Щоб ділитися кодом між різними модулями Elixir у межах одного проєкту, потрібно посилатися на зовнішній модуль за його повним імʼям. Але що робити, якщо це імʼя задовге або заплутане?

Спеціальна форма `alias` дає змогу скоротити чи змінити імʼя, за яким ми посилаємося на зовнішній модуль. Якщо використати її без аргументів, вона вкорочує імʼя модуля до останнього сегмента, наприклад `MyApp.Logger.Settings` стає `Settings`. Власне імʼя можна задати за допомогою опції `:as`.

Зазвичай псевдоніми додають на початку визначення модуля.

```elixir
defmodule Square do
  alias Integer, as: I

  def area(a), do: I.pow(a, 2)
end
```

## Імпорт

Спеціальна форма `import` дає змогу використовувати функції із зовнішнього модуля, не згадуючи імені цього модуля.

Імпортування цілого зовнішнього модуля може створити конфлікти з наявними локальними функціями. Щоб цього уникнути, є дві опції: `:except` і `:only`. Обидві приймають список ключових слів, де ключ - це назва функції, а значення - арність функції.

Зазвичай імпорти додають на початку визначення модуля.

```elixir
defmodule Square do
  import Integer, only: [pow: 2]

  def area(a), do: pow(a, 2)
end
```
