# Вступ

Про помилки корисно повідомляти, коли щось у програмі чи фрагменті коду є хибним або несподіваним.

Це обʼєкти JavaScript.

Головна властивість цього обʼєкта - `message`:

```javascript
const error = new Error('Oops, something went wrong');

console.log(error.message);
// => "Oops, something went wrong"
```

За допомогою синтаксису `throw` ми можемо викинути помилку Error.

```javascript
throw new Error('Oops');
```

Коли викидають `Error`, поточне виконання зупиняється й відновлюється в першому блоці `catch` у стеку викликів.

```javascript
try {
  throw new Error('Oops');
} catch (error) {
  console.log(error.message);
  // => "Oops"
}
```

Як і з будь-яким класом у JavaScript, підкласи можуть успадковувати від `Error`, щоб створювати власні помилки за допомогою ключового слова `extends`.
Синтаксис `instanceof` перевіряє, чи є перехоплена помилка екземпляром певного підкласу `Error`.

```javascript
class CustomError extends Error {}

try {
  // ... Code that may throw an error
} catch (error) {
  if (error instanceof CustomError) {
    console.log('The error thrown is an instance of the CustomError');
  }
}
```
