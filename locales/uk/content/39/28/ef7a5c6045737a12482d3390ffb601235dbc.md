# Числа

`INT` - це тип у Sather для цілих чисел: `0`, `7`, `-3`. Підпрограма, яка повертає ціле число, зазначає це після двокрапки, так само як підпрограма, що повертає текст, зазначає `STR`.

```sather
   goals : INT is
      return 42;
   end;
```

Підпрограми можуть приймати **аргументи**, тобто значення, які передають під час виклику підпрограми. Кожен аргумент має імʼя й тип, записані в дужках після назви підпрограми:

```sather
   total(first : INT, second : INT) : INT is
      return first + second;
   end;
```

Коли два аргументи мають однаковий тип, їх можна назвати разом:

```sather
   total(first, second : INT) : INT is
```

Щоб викликати її, поставмо значення в дужках:

```sather
SCORES::total(3, 4)     -- this is 7
```

Є пʼять арифметичних операторів: `+`, `-`, `*`, `/` і `%`.

`/` для двох `INT` - це **цілочисельне ділення**: воно відкидає остачу, а не дає дріб.

```sather
7 / 2      -- 3, not 3.5
```

`%` дає остачу від цього ділення.

```sather
7 % 2      -- 1
```

Ці дві операції повʼязані: `7` - це `3` рази по `2` і `1` в остачі.
