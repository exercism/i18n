# Інструкції

У цій вправі ми будемо писати код, щоб опрацьовувати масив мов програмування, які плануємо практикувати на платформі Exercism.

На нас чекає шість завдань.

## 1. Створіть новий масив

Перш ніж додавати мови, потрібно спочатку створити новий масив. Визначте функцію, яка повертає порожній масив.

```clojure
(new-list)
;; => ()
```

## 2. Додайте нову мову до масиву

Коли ми досліджуємо Exercism і знаходимо мови, які хочемо вивчати, потрібно мати змогу додавати їх до нашого масиву. Визначте функцію, яка додає нову мову на початок масиву.

```clojure
(add-language "JavaScript" '("Clojurescript"))
;; => '("JavaScript" "Clojurescript")
```

## 3. Перевірте мову, додану останньою

Нам захочеться швидко перевірити, яку мову ми щойно додали. Визначте функцію, яка повертає першу мову з масиву.

```clojure
(first-language '("Haskell" "Python"))
;; => "Haskell"
```

## 4. Видаліть першу мову з масиву

Іноді ми змінюємо думку щодо мови, яку щойно додали. Визначте функцію, яка видаляє першу мову з масиву.

```clojure
(remove-language '("Common Lisp" "Racket" "Scheme"))
;; => '("Racket" "Scheme")
```

## 5. Порахуйте мови в масиві

Рахувати мови по одній незручно. Визначте функцію, яка рахує кількість мов у масиві.

```clojure
(count-languages '("C#" "Racket" "Rust" "Ruby"))
;; => 4
```

## 6. Зберіть усе разом

Визначте функцію `learning-list`, у якій ми використаємо деякі з функцій, визначених вище.

- Створіть порожній масив
- Додайте 2 нові мови програмування до масиву.

  - "Clojure"
  - "Lisp"

- Видаліть "Lisp" з масиву, бо на нього може не вистачити часу цього року, і він досить схожий на Clojure.
- Додайте ще 2 мови програмування до масиву.

  - "Java"
  - "JavaScript"

- Поверніть загальну кількість мов. Підказка: має бути 3.

```clojure
(learning-list)
;; => 3
```
