# Конструкції `case`

Коли одне значення порівнюють зі списком можливих варіантів, ланцюжок `elsif` повторює те саме знову й знову:

```sather
   if zone = 0 then
      return 0;
   elsif zone = 1 then
      return 550;
   elsif zone = 2 then
      return 370;
   else
      return 920;
   end;
```

`case` промовляє це один раз:

```sather
   case zone
   when 0 then return 0;
   when 1 then return 550;
   when 2 then return 370;
   else return 920;
   end;
```

Значення записують після `case`. Кожен `when` дає значення, з яким його порівнюють, і виконується той, що збігся першим.

## Кілька значень в одному `when`

`when` може перелічувати значення, розділені комами:

```sather
   case day
   when "Sat", "Sun" then return "Weekend";
   when "Mon", "Tue", "Wed", "Thu", "Fri" then return "Weekday";
   else return "Unknown";
   end;
```

Це працює з цілими числами, символами й рядками тексту (англ. string), тобто з усім, що можна порівняти оператором `=`.

## Без `else` не обійтися

**`case`, який ні з чим не збігається і не має `else`, є помилкою, що зупиняє програму, коли таке стається.**

Це не те саме, що `if`, де відсутність `else` просто означає, що нічого не відбувається. Це також не те саме, що в більшості мов, де `case`, який ні з чим не збігся, тихо нічого не робить.

Тож кожен `case` потребує `else`, навіть коли ми впевнені, що частини `when` уже охоплюють усі значення. Пізніше додають четверту зону, `case` не оновлюють відповідно, і програма зупиняється на першому пасажирові, який нею скористається.

## Виконується лише один `when`

Коли якийсь `when` збігається, інструкції після його `then` виконуються, і `case` на цьому завершується: програма продовжує роботу після `end`. На частини `when`, що йдуть нижче, уже не звертають уваги, тож не потрібно нічого писати, щоб зупинити виконання наступного.
