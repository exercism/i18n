# Вказівки

У цій вправі нам потрібно реалізувати кілька правил із класичної гри Pac-Man.

Потрібно реалізувати чотири правила, і всі вони повʼязані зі станами гри.

## 1. Визначити, чи Pac-Man зʼїдає привида

Реалізуйте функцію, яка приймає, чи має Pac-Man активну енергетичну пігулку і чи торкається Pac-Man привида, і повертає булеве значення (англ. Boolean) про те, чи може Pac-Man зʼїсти привида. Функція має повертати `true` лише якщо Pac-Man має активну енергетичну пігулку і торкається привида.

```lua
rules.eat_ghost(false, true)
-- => false
```

## 2. Визначити, чи Pac-Man набирає очок

Реалізуйте функцію, яка приймає, чи торкається Pac-Man енергетичної пігулки і чи торкається Pac-Man крапки, і повертає булеве значення про те, чи набрав Pac-Man очок. Функція має повертати `true`, якщо Pac-Man торкається енергетичної пігулки або крапки.

```lua
rules.score(true, true)
-- => true
```

## 3. Визначити, чи Pac-Man програє

Реалізуйте функцію, яка приймає, чи має Pac-Man активну енергетичну пігулку і чи торкається Pac-Man привида, і повертає булеве значення про те, чи програє Pac-Man. Функція має повертати `true`, якщо Pac-Man торкається привида і не має активної енергетичної пігулки.

```lua
rules.lose(false, true)
-- => true
```

## 4. Визначити, чи Pac-Man виграє

Реалізуйте функцію, яка приймає, чи зʼїв Pac-Man усі крапки, чи має Pac-Man активну енергетичну пігулку і чи торкається Pac-Man привида, і повертає булеве значення про те, чи виграв Pac-Man. Функція має повертати `true`, якщо Pac-Man зʼїв усі крапки і не програв згідно з аргументами, визначеними в частині 3.

```lua
rules.win(false, true, false)
-- => false
```
