# Вступ

Статичне розширення дає змогу псевдорозширювати наявні типи, не змінюючи їхній вихідний код. Цього можна досягти за допомогою інструкції `using`. Статичні розширення можуть бути потужним інструментом, який дозволяє доповнювати типи, насправді не змінюючи їх.

```haxe
using Main.IntExtender;

class Main {
  public static function main() {
    trace(2.triple()); // 6
  }
}

class IntExtender {
  public static function triple(i:Int):Int {
    return i * 3;
  }
}
```
