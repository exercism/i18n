# Про це

## Булеві значення

У PowerShell є тип [`bool`][booleans], який представляє булеві значення (англ. Boolean): правду та неправду.
У цьому типі є лише два значення: `True` і `False`.
Ці значення можна привʼязати до змінних із префіксом `$`:

```powershell
> $TrueVar  = $true
> $FalseVar = $FALSE
#Case senstitivity doesn't matter here
```

За допомогою [логічних операторів][logical-operators], як-от `-and`, `-or` і `-not`, ми можемо поєднувати й обчислювати булеві вирази.

```powershell
> $TrueVar  = $true -and $true
> $FalseVar = $true -and $false

> $TrueVar  = $true -or $false
> $FalseVar = $false -or $false

> $TrueVar  = -not $false
> $FalseVar = -not $true
```

## Перетворення та істинність

PowerShell може неявно трактувати будь-який тип як булеве значення.
Однак можна також скористатися прискорювачем типу `[bool]` для явного перетворення.

Ось кілька загальних правил, які PowerShell використовує, щоб перетворювати інші типи в булеві значення:

$false:
- Порожні рядки тексту (англ. string), як-от `''` або `""`
- Значення null, як-от `$null`
- Числовий тип зі значенням нуль (0)

$true:
- Непорожні рядки тексту
- Примірники будь-якого іншого типу, що не є колекцією

```powershell
> [bool] 0
False

> [bool] 0.0
False

> [bool] ""
False

> [bool] "Hello"
True

> [bool] 1234
True
```

Щоб дізнатися докладніші правила перетворення булевих значень із типів-колекцій, читайте [тут][collection-conversion].
