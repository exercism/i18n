# Докладніше

Виконувати код за умовою можна за допомогою [виразів `if/elif/else`][conditional-expression]. Умови, які використовуються у виразі `if/elif/else`, повинні мати тип `bool`. У F# немає поняття _truthy_-значень.

```fsharp
if x = 5 then
    printfn "x equals 5"
elif x > 7 then
    printfn "x is not 5 and greater than 7"
else
    printfn "x is not 5 and not greater than 7"
```

Оскільки `if/elif/else` є виразом, його можна привʼязати до імені або повернути з функції.

```fsharp
let message =
    if x = 5 then
        "x equals 5"
    elif x > 7 then
        "x is not 5 and greater than 7"
    else
        "x is not 5 and not greater than 7"
```

Усі гілки повинні повертати той самий тип. Інакше виникне помилка компілятора:

```fsharp
if x = 5 then
    true
elif x > 7 then
    5.6

// Results in compiler error
```

Гілки `else` та `elif` необовʼязкові, але лише якщо повернений вираз має тип [`unit`][unit-type].

```fsharp
// Valid if expression
if x > 2 then
    printfn "x is greater than two"

// Invalid if expression, results in compiler warning
if x > 2 then
    true
```

Вираз `if/else` можна також записати в один рядок. Це варто використовувати лише для простих виразів `if`.

```fsharp
let y = if x > 5 then 10 else 20
```
