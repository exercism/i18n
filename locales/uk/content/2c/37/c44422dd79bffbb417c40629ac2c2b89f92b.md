# Підказки

## Загальні відомості

- [Кортежі](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples) - це незмінне групування безіменних, але впорядкованих значень, які можуть мати різні типи.
- Елементи в кортежах можна [отримати](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples#obtaining-individual-values) за допомогою зіставлення зі зразком, деконструкції кортежу або допоміжних функцій.

## 1. Витягнути координати

- Памʼятайте: кортежі дозволяють отримувати доступ через допоміжні функції або деконструкцію.
- Перевірте [синтаксичний розбір](https://docs.microsoft.com/en-us/dotnet/api/system.int32.parse?view=net-5.0), щоб отримати число з рядка тексту (англ. string).

## 2. Відформатувати координати

- Перегляньте [приклади](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples#examples), щоб дізнатися більше про створення кортежів.
- Перегляньте [зрізи рядків](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/strings#string-indexing-and-slicing), щоб дізнатися більше про рядки тексту.

## 3. Зіставити координати

- Які оператори можна тут використати для [перевірки належності](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/strings#string-indexing-and-slicing)?
- Чи можна повторно використати функцію `convertCoordinate()`?

## 4. Обʼєднати зіставлені записи

- Памʼятайте, що кортежі підтримують [зіставлення зі зразком](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples#obtaining-individual-values).
- Чи можна тут повторно використати функцію `compareRecords()`?
