# Завдання

Завдання - це issue на GitHub, над якими ми хотіли б, щоб люди попрацювали: від вичитки тексту до створення Concept Exercises.
Вони показуються на сайті і посилаються на відповідні issue на GitHub.
Кожне завдання позначене однією або кількома властивостями, які беруться з міток issue.
Далі користувач може фільтрувати завдання за цими властивостями.

## Теги

Щоб issue вважався завданням, його потрібно позначити одним або кількома тегами, специфічними для завдань.
Отже, супровідники можуть зробити так, щоб завданнями відображалися лише деякі issue.

Кожен тег завдання має вигляд `x:<type>/<value>`, і підтримується пʼять типів завдань:

- `action`
- `knowledge`
- `module`
- `size`
- `type`

### Тег action

Мітки `x:action/<value>` описують, якою роботою займатиметься контрибʼютор, працюючи над issue.

| Тег                  | Опис                                   |
| -------------------- | -------------------------------------- |
| `x:action/create`    | Робота над чимось з нуля               |
| `x:action/fix`       | Виправити issue                        |
| `x:action/improve`   | Покращити наявну функціональність або вміст |
| `x:action/proofread` | Вичитати текст                         |
| `x:action/sync`      | Синхронізувати вміст з його найновішою версією |

### Тег knowledge

Мітки `x:knowledge/<value>` описують, скільки знань про Exercism потрібно контрибʼюторові.

| Тег                        | Опис                                       |
| -------------------------- | ------------------------------------------ |
| `x:knowledge/none`         | Знання Exercism не потрібні                |
| `x:knowledge/elementary`   | Потрібні невеликі знання Exercism          |
| `x:knowledge/intermediate` | Потрібно чимало знань Exercism             |
| `x:knowledge/advanced`     | Потрібні вичерпні знання Exercism          |

### Тег module

Мітки `x:module/<value>` вказують, над якою частиною Exercism працюватиме контрибʼютор.

| Тег                          | Опис                        |
| ---------------------------- | --------------------------- |
| `x:module/analyzer`          | Робота над Analyzers        |
| `x:module/concept`           | Робота над Concepts         |
| `x:module/concept-exercise`  | Робота над Concept Exercises |
| `x:module/generator`         | Робота над Exercise generators |
| `x:module/practice-exercise` | Робота над Practice Exercises |
| `x:module/representer`       | Робота над Representers     |
| `x:module/test-runner`       | Робота над Test Runners     |

### Тег size

Мітки `x:size/<value>` описують очікуваний обсяг роботи для контрибʼютора.

| Тег              | Опис                   |
| ---------------- | ---------------------- |
| `x:size/tiny`    | Дуже малий обсяг роботи |
| `x:size/small`   | Малий обсяг роботи     |
| `x:size/medium`  | Середній обсяг роботи  |
| `x:size/large`   | Великий обсяг роботи   |
| `x:size/massive` | Величезний обсяг роботи |

### Тег type

Мітки `x:type/<value>` описують тип роботи, якою займатиметься контрибʼютор.

| Тег              | Опис                                                                                                                                                                                                    |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `x:type/ci`      | Робота над Continuous Integration (наприклад, workflows GitHub Actions)                                                                                                                                        |
| `x:type/coding`  | Написання коду, який не є частиною вмісту для тих, хто навчається. Зазвичай це завдання, повʼязані з інструментарієм для продакшену (наприклад, test runners), внутрішнім інструментарієм (generators) або бібліотеками, які підтримує Exercism. |
| `x:type/content` | Робота над вмістом (наприклад, вправами, концепціями)                                                                                                                                                           |
| `x:type/docker`  | Робота над Dockerfiles                                                                                                                                                                                         |
| `x:type/docs`    | Робота над документацією                                                                                                                                                                                       |

## Мітки claimed та unclaimed

Щоб приховати завдання, бо над ним уже хтось працює, до issue можна додати мітку `x:status/claimed`.
