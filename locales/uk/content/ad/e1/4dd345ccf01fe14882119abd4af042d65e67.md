# Запуск тестів

Виберіть свою операційну систему:

- [Windows](#windows)
- [macOS](#macos)
- [Linux](#linux)

## Windows

1. Відкрийте Command Prompt.
2. Отримайте першу вправу:

   ```batchfile
   C:\Users\JohnDoe>exercism download --exercise hello-world --track java
   ```

3. Перейдіть у каталог вправи:

   ```batchfile
   C:\Users\JohnDoe>cd C:\Users\JohnDoe\exercism\java\hello-world
   ```

4. Запустіть тести:

   ```batchfile
   C:\Users\JohnDoe>gradlew.bat test
   ```

   _(Не варто хвилюватися, якщо тести спочатку не проходять: саме так починається кожна вправа.)_

5. Розвʼяжіть вправу. Знайдіть і опрацюйте посібник `instructions.append.md` ([переглянути на GitHub](https://github.com/exercism/java/blob/main/exercises/practice/hello-world/.docs/instructions.append.md#tutorial)).

Успіхів! Гарного настрою!
