# Інструкції

Ліллі любить готувати.
Вона хоче влаштувати вечірку з піцою разом із друзями.
Щоб якнайкраще використати свої інгредієнти, їй треба знати, скільки кожного з них знадобиться, перш ніж почати.

Щоб розвʼязати цю задачу, Ліллі написала чернетку програми, яка автоматизує частину планування, але їй потрібна наша допомога, щоб її завершити.
Допоможемо Ліллі влаштувати пропорційно бездоганну вечірку з піцою?

## 1. Пропорція тіста

Ліллі полюбляє тонкі хрусткі піци з тоншою скоринкою.
Тіста для середини потрібно щонайменше 200 г, але на кожну людину, яку нагодує піца, потрібно ще 20 г тіста.

`grams = pizzas * ((persons * 20) + 200)`

Ліллі потрібна функція, яка:

- приймає кількість піц
- кількість людей, яких нагодує кожна піца
- і повертає потрібну кількість тіста, округлену до найближчого грама.

Наприклад, щоб приготувати 4 піци, які нагодують 8 людей:

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateDoughRequirement(4, 8);
// => 1440
```

## 2. Трохи соусу

Ліллі дуже ретельно наносить соус, але розмір її піц може бути неоднаковим.
З досвіду вона знає, що на одну піцу йде 125 мл соусу.
Ліллі потрібна функція, яка обчислює, скільки банок соусу купити.

`cans of sauce = pizzas * sauce per pizza / sauce can volume`

Наприклад, якщо Ліллі треба приготувати 8 піц, а в кожній банці 250 мл:

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateSauceRequirement(8, 250);
// => 4
```

## 3. Трохи сиру, будь ласка

Сир продається ідеальними кубами, за розміром.

Формула, яку використовує Ліллі, не є формулою площі піци, адже вона _не_ хоче, щоб сир покривав усю площу.
Вона вирішила скористатися такою формулою, щоб визначити, скільки піц певного діаметра (`diameter`) можна зробити з куба сиру з певною довжиною ребра (`cheese_dimension`):

`pizzas = (cheese_dimension³) / (thickness * PI * diameter)`

Створіть функцію, яка:

- приймає довжину ребра куба сиру
- приймає бажану товщину шару сиру
- приймає діаметр піци
- і за формулою Ліллі повертає кількість піц, які можна приготувати, округлену вниз.

Наприклад, якщо куб сиру має розмір 25×25×25 см, шар сиру завтовшки 0,5 см, а діаметр піц 30 см:

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateCheeseCubeCoverage(25, 0.5, 30);
// => 331
```

## 4. Справедлива частка

Нарешті, Ліллі хоче, щоб кожна піца ділилася на 8 шматків і шматки рівномірно розподілялися між її друзями.

Створіть функцію, яка:

- приймає кількість піц і кількість друзів
- і повертає кількість шматків, які залишаться, якщо кожна людина візьме однакову кількість шматків.

Наприклад:

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateLeftOverSlices(2, 4);
// => 0
$pizza_pi->calculateLeftOverSlices(4, 3);
// => 2
```
