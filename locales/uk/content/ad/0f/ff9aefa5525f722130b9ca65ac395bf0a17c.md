# Встановлення

## Що потрібно

Основні складники, потрібні для розробки мовою Common Lisp:

- «Реалізація» Lisp, яка дозволить компілювати й виконувати код, а також надасть REPL.
- Текстовий редактор із підтримкою коду Lisp. 
- (Бажано мати) Часто використовуваний довідник з мови Common Lisp, [«Common Lisp Hyperspec»][hyperspec].

## Roswell

[Roswell][roswell] - це команда для встановлення й керування реалізаціями Common Lisp, що має багато можливостей, які полегшують розробку та розповсюдження Lisp-застосунків.
Ми використовуємо його, щоб спростити кроки встановлення й тестування.

### Встановлення Roswell

Перегляньте [настанову зі встановлення][ros-inst] і дотримуйтеся вказівок для своєї платформи.
Для більшості користувачів буде достатньо такого:

* У MacOS і Linux це легко зробити за допомогою [Homebrew][brew]:
  ```sh
  brew install roswell
  ```
* У Windows скористайтеся [Scoop][scoop]:
  ```powershell
  scoop install roswell
  ```

Коли ми вперше використовуємо Roswell, він завантажить і встановить SBCL та Quicklisp.
Просто запустіть ось це:
```sh
ros help
```

Увійдіть у REPL за допомогою
```sh
ros run
```

## Налаштування текстового редактора

Тим, хто щойно береться за Common Lisp, особливо якщо вже має досвід із Emacs, швидкий і легкий старт забезпечить встановлення [Portacle, портативного середовища Common Lisp][portacle]. 
Безкоштовний і багатофункціональний, він працює на всіх поширених платформах і надходить уже налаштованим «з коробки». Він надає:

- Реалізацію Lisp: SBCL, разом із Quicklisp й ASDF.
- Текстовий редактор: Emacs

... з безліччю додаткових засобів для написання коду Lisp: 
- SLIME («Superior Lisp Interaction Mode for Emacs») перетворює Emacs на середовище розробки для Common Lisp
- ParEdit, який полегшує роботу з дужками. 

Усе вже налаштовано «з коробки». Щоб установити Portacle, завантажте його з [головної сторінки][portacle].

Зауваження: Emacs (текстовий редактор) спершу може збивати з пантелику, якщо до нього немає звички. На щастя, в мережі є чимало вступних посібників з Emacs і SLIME. 

## Традиційний старт

Якщо ми надаємо перевагу окремому встановленню потрібних інструментів, доведеться встановити й налаштувати таке:

- текстовий редактор із підтримкою Lisp: [Emacs][emacs] із пакетом [Slime][slime] або [Sly][sly] - поширений вибір, але [VIM][vim] із [SLIMV][slimv], [Atom][atom] із [SLIMA][slima] або [VSCode][vscode] із [плагіном для Common Lisp][vscode-plugin] теж гарні.
- реалізацію Common Lisp: [SBCL][sbcl] - «безпечний» вибір, який працює на Linux, MacOS і Windows. Оскільки мова ґрунтується на стандарті, будуть працювати й інші [відповідні реалізації][awesome-cl-implementations].
- [Quicklisp][quicklisp] для керування бібліотеками. Після завантаження дотримуйтеся [вказівок][quicklisp-install], щоб переконатися, що його правильно інтегровано з реалізацією Common Lisp.
