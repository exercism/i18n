# Вступ

## Математичні функції

Квадратні корені, кути та криві зростання важко обчислити самими лише `+`, `-`, `*` і `/`. У словнику [`math.functions`][math.functions] є слова, які обчислюють їх за нас, а в [`math.constants`][math.constants] є π. Як і кожне інше слово, кожне з них бере свої вхідні дані зі стеку й залишає там свою відповідь.

## Квадратні корені

```
sqrt ( x -- y )
```

```factor
USING: kernel math math.constants math.functions math.libm prettyprint ;

9 sqrt .     ! => 3.0
2 sqrt .     ! => 1.4142135623730951
```

Драбина завдовжки 5 метрів, основа якої стоїть за 3 метри від стіни, дістає на 4 метри вгору по ній:

```factor
5 sq 3 sq - sqrt .   ! => 4.0
```

## Число пі

`pi` (з `math.constants`) кладе на стек π, тобто число, яке показує, скільки разів діаметр кола вкладається в його довжину:

```factor
: wheel-edge ( diameter -- edge ) pi * ;

2 wheel-edge .   ! => 6.283185307179586
```

## Кути в радіанах

```
sin ( x -- y )
cos ( x -- y )
tan ( x -- y )
```

`sin`, `cos` і `tan` приймають кут, але не в градусах. Вони використовують **радіани**, де пів оберту - це π, а не 180. Дати їм градуси - не помилка: вони просто непомітно дадуть неправильну відповідь.

`deg>rad` переводить градуси в радіани, а `rad>deg` переводить назад. Це те саме, що помножити на π і поділити на 180, або навпаки:

```
deg>rad ( x -- y )
rad>deg ( x -- y )
```

```factor
30 deg>rad .       ! => 0.5235987755982988
30 pi * 180 / .    ! => 0.5235987755982988
pi rad>deg .       ! => 180.0
```

Перетворімо градуси в радіани перед тим, як викликати `sin`:

```factor
: ramp-rise ( length degrees -- rise ) deg>rad sin * ;

10 30 ramp-rise .   ! => 4.999999999999999
```

Рампа завдовжки 10 метрів під кутом 30 градусів піднімається на 5 метрів. Відповідь друкується як `4.999999999999999`, бо математичні функції дають найближче число з плаваючою комою, а не точне значення. Без перетворення `30 sin` трактує 30 як радіани (майже пʼять повних обертів), і рампа «піднялася» б на `-9.88` метрів.

## Знаходження кута

`fatan2` працює в інший бік: знаючи, наскільки вгору і наскільки вбік, він видає кут у радіанах. Він живе в [`math.libm`][math.libm]. Відстань *вгору* кладеться на стек першою, потім відстань *вбік*:

```
fatan2 ( y x -- radians )
```

```factor
1.0 1.0 fatan2 .              ! => 0.7853981633974483
1.0 1.0 fatan2 rad>deg .      ! => 45.0
-1.0 -1.0 fatan2 rad>deg .    ! => -135.0
0.0 -1.0 fatan2 rad>deg .     ! => 180.0
```

Кут вимірюється від додатного напрямку *вбік*. `fatan2` дивиться на знаки обох відстаней, тож може дати відповідь будь-де від −180 до 180 градусів.

## Степені десяти: 10^ і log10

`10^` підносить 10 до степеня:

```factor
5 10^ .     ! => 100000
2 10^ .     ! => 100
0.5 10^ .   ! => 3.1622776601683795
```

`log10` іде назад. Він відповідає на питання «10 у якому степені дасть це число?» Ця відповідь - **логарифм** числа:

```factor
100000 log10 .   ! => 5.0
100 log10 .      ! => 2.0
1 log10 .        ! => 0.0
0.001 log10 .    ! => -3.0
```

## e^ і log

`e^` і `log` - та сама пара, лише з *e* (приблизно 2.718) замість 10. `e^` підносить *e* до степеня, а `log` відповідає: «*e* у якому степені дасть це число?»

```
e^  ( x -- y )
log ( x -- y )
```

Математики використовують *e* для всього, що зростає або зменшується на ту саму частку за кожен крок. Гроші, які приносять відсотки, - один приклад, а чашка чаю, що холоне, - інший:

```factor
! 80 degrees hotter than the room, the gap shrinking by 5% a minute
: tea-gap ( minutes -- gap ) -0.05 * e^ 80 * ;

0 tea-gap .    ! => 80.0
10 tea-gap .   ! => 48.52245277701067
```

`log` скасовує `e^`. Це відповідає на питання з іншого боку: за скільки хвилин проміжок скоротиться до 40 градусів?

```factor
80 40 / log 0.05 / .   ! => 13.862943611198904
```
