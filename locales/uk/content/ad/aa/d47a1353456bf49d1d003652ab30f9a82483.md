# Передумови

Для треку мови D потрібно, щоб у системі було встановлено таке програмне забезпечення:

* компілятор D версії 2
* (необовʼязково, але рекомендовано) DUB

## Передумова: компілятор D версії 2

На сайті мови D [dlang.org](https://dlang.org) можна завантажити й встановити найновішу версію еталонного компілятора DMD (Digital Mars D) для кількох платформ.
Докладніше дивіться на [офіційній сторінці завантажень](https://dlang.org/download.html).
У Windows альтернативний варіант - [скористатися Chocolatey](https://chocolatey.org/packages/dmd).
На Mac з процесорами Intel альтернативний варіант - [скористатися Homebrew](https://formulae.brew.sh/formula/dmd).

### Інші компілятори
Крім еталонного компілятора DMD, який використовує власний бекенд, є ще два компілятори, які можна отримати в розділі завантажень dlang.org:

* [GDC](http://gdcproject.org/downloads), який використовує бекенд GCC
* [LDC](https://github.com/ldc-developers/ldc#installation) на основі бекенду LLVM

GDC і LDC не завжди мають найновіші версії фронтенду DMD, але забезпечують кращі рівні оптимізації та підтримку інших платформ, наприклад ARM.

Дивіться вікі, щоб дізнатися [більше інформації](https://wiki.dlang.org/Compilers).

### Підтримка IDE

Мову D також підтримують різні IDE, наприклад [VisualD](http://rainers.github.io/visuald/visuald/StartPage.html) для Visual Studio та [плагін D](https://plugins.jetbrains.com/plugin/7727?pr=clion) для IntelliJ CLion.
Дивіться вікі, щоб дізнатися [більше інформації](https://wiki.dlang.org/IDEs).

### Передумова: DUB

[DUB](https://github.com/dlang/dub) - це менеджер збірки для D.

Ми рекомендуємо його, щоб спростити процес запуску тестів, але без DUB цілком можна обійтися, якщо немає можливості або бажання його встановлювати.
