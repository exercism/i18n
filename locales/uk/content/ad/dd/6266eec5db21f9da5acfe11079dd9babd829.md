# Вступ

## Структури

Структури - це розширення, побудоване поверх [мап][exercism-maps], яке забезпечує перевірки під час компіляції та типові значення. Структура називається так само, як модуль, у якому її визначено. Щоб визначити структуру, скористаймося конструкцією `defstruct`. Зазвичай ця конструкція йде відразу після визначення модуля. `defstruct` приймає або список атомів (для типових значень `nil`), або список ключових слів (для заданих типових значень). Поля без типових значень мають іти перед полями з типовими значеннями.

```elixir
defmodule Plane do
  defstruct [:engine, wings: 2]
end

plane = %Plane{}
# => %Plane{engine: nil, wings: 2}
```

### Доступ до полів і оновлення

Оскільки структури побудовані на мапах, ми можемо використовувати більшість функцій для мап, щоб отримувати значення та працювати з ними. Для структур _Поведінка доступу_ **не** реалізована. Натомість для доступу до полів структури радимо використовувати _оператор статичного доступу_ `.`.

- отримати або вибрати значення полів:

  ```elixir
  plane = %Plane{}
  plane.engine
  # => nil
  Map.fetch(plane, :wings)
  # => {:ok, 2}
  ```

- оновити значення полів

  ```elixir
  plane = %Plane{}
  %{plane | wings: 4}
  # => %Plane{engine: nil, wings: 4}
  ```

### Зіставлення зі зразком

Структури можна використовувати в зіставленні зі зразком як із назвою структури, так і без неї.

```elixir
plane = %Plane{}
%Plane{wings: wings} = plane
%{wings: wings} = plane
```

Якщо включити назву структури у зразок, ми можемо переконатися, що і ліва, і права частина є структурами одного типу.

```elixir
defmodule Helicopter do
  defstruct [:engine, rotors: 1]
end

%Plane{} = %Helicopter{}
# => (MatchError) no match of right hand side value: %Helicopter{engine: nil, rotors: 1}
```

### Обовʼязкова ініціалізація значень полів

Ми можемо скористатися атрибутом модуля `@enforce_keys` зі списком ключів полів, щоб гарантувати, що значення ініціалізуються під час створення структури. Якщо ключ не вказано в списку, його значенням буде `nil`, як у прикладі вище. Якщо обовʼязковий ключ не ініціалізовано, виникає помилка.

```elixir
defmodule User do
  @enforce_keys [:username]
  defstruct [:username]
end

%User{}
# => (ArgumentError) the following keys must also be given when building struct User: [:username]
```
