# Вступ

## Псевдоніми типів

У Gleam псевдонім типу можна використати, щоб дати зручну назву наявному типу, який інакше було б громіздко писати.

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

Якщо записати його з `pub type`, псевдонім можна використовувати поза модулем, у якому його визначено. Якщо `pub` пропустити, псевдонім буде приватним, і на нього не можна посилатися в інших модулях.
