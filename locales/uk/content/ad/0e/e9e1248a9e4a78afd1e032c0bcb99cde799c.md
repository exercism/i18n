# Вступ

Булеві значення (англ. Boolean) у C++ представлені типом `bool`.
`bool` може набувати лише двох значень: `true` або `false`.

## Логічні оператори

C++ підтримує три логічні оператори: `!` (логічне заперечення), `&&` (логічне і) та `||` (логічне або).
Також можна використовувати альтернативні варіанти: `not`, `and` та `or`.

```cpp
true || false // => true
true && false // => false
!true // => false
not false // => true
```

## Пріоритет

Кожен із трьох логічних операторів має власний _пріоритет операторів_.
Як наслідок, вони обчислюються в такому порядку: спочатку `!`, потім `&&`, і нарешті `||`.
Якщо потрібно задати інший порядок, можна взяти булевий вираз у дужки (тобто `()`), адже дужки мають ще вищий пріоритет операторів.

```cpp
!true && false   // => false
!(true and false) // => true
```

## Перетворення

Якщо використати `true` або `false` там, де потрібне число, їх буде перетворено на `1` і `0` відповідно.
Якщо використати число в булевій операції, усе, крім `0`, вважається `true`, навіть відʼємні значення.

```cpp
!true && 0.0   // => false
true + true + false // => 2
```
