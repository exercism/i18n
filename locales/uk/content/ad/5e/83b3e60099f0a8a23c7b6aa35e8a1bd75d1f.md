# Вступ

## Власні типи

Власні типи дають змогу визначати в Gleam нові типи даних. Вони можуть мати кілька _варіантів_, кожен зі своєю назвою.

```gleam
pub type Season {
  Spring
  Summer
  Autumn
  Winter
}
```

Кожен варіант власного типу може за бажанням містити деякі дані, і різні варіанти можуть мати різні типи даних. Коли варіант містить дані, його називають _записом_.

```gleam
pub type Number {
  SomeInt(Int)
  SomeFloat(Float)
  Invalid
}
```

Створити значення для конкретного варіанта можна, звернувшись до його назви, якщо він не містить додаткових даних (`Spring`), або викликавши його як функцію, якщо містить (`SomeInt(2)`).

```gleam
let spring = Spring
let integerTwo = SomeInt(2)
```

Власні типи, як і все в Gleam, мають _структурну рівність_, тобто два значення одного варіанта з однаковими даними є еквівалентними.

```gleam
Spring == Spring // -> True
Spring == Autumn // -> False
SomeInt(2) == SomeInt(2) // -> True
SomeInt(2) == SomeFloat(2.0) // -> False
```

Варіанти власних типів можна зіставляти зі зразками за допомогою виразів case.

```gleam
import gleam/int
import gleam/float

pub fn describe(flexible_number: Number) -> String {
  case flexible_number {
    SomeFloat(f) -> "Float: " <> float.to_string(f)
    SomeInt(i) -> "Int: " <> int.to_string(i)
    Invalid -> "Neither a float nor an int"
  }
}
```
