# Вступ

Коли нам потрібна послідовність із `n` значень, де кожне залежить від свого індексу, Factor дає нам `<iota>` (віртуальну послідовність цілих чисел `0, 1, …, n-1`) і `map`:

```factor
USING: math sequences ;

5 <iota> [ 2 * ] map .   ! => { 0 2 4 6 8 }
```

`<iota>` не виділяє памʼять під цілі числа заздалегідь; `map` перебирає їх по порядку, застосовуючи quotation до кожного.

Якщо результат для кожної позиції є кодом символу, `>string` перетворює результат на рядок тексту (англ. string). Це природний спосіб зібрати низку символів із рішень, зумовлених індексом:

```factor
USING: strings ;

5 <iota> [ CHAR: a + ] map >string .   ! => "abcde"
```

[strings]: https://docs.factorcode.org/content/article-strings.html
