# Вступ

Непрозорі типи в Gleam — це власні типи, у яких лише модуль, що визначає тип, може створювати значення цього типу або зіставляти їх зі зразком. Це стає в пригоді, коли треба створити типи, які слід використовувати лише певним чином.

Непрозорі типи визначають за допомогою ключового слова `opaque`.

```gleam
pub opaque type PositiveInt {
  PositiveInt(inner: Int)
}
```

Цей тип `PositiveInt` призначений для ситуацій, де потрібне ціле число, але воно має бути не меншим за нуль. Звичайний `Int` у Gleam тут не підійде, бо він може бути й відʼємним.

Модуль, який визначає цей тип, може визначити функцію, щоб отримати внутрішнє ціле значення, і функцію для створення типу `PositiveInt`, яка повертатиме помилку, якщо значення не додатне.

```gleam
pub fn from_int(i: Int) -> Result(PositiveInt, String) {
  case i {
    _ if i < 0 -> Error("Value must be positive")
    _ -> Ok(PositiveInt(i))
  }
}

pub fn to_int(i: PositiveInt) -> Int {
  i.inner
}
```

Із таким API інші модулі не можуть створити `PositiveInt` з відʼємним значенням, тож будь-яка функція, яка приймає `PositiveInt`, може бути певна, що значення додатне.
