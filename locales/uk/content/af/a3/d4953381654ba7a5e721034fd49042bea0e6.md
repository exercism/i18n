# Заповнювач

## Реалізація операцій List

Мета цієї вправи - самостійно реалізувати деякі методи List.
Природно використовувати обʼєкт List у внутрішній реалізації, щоб зберігати дані.
Не чіпайте методи List (як-от `where`, `map` тощо).

Є кілька «примітивних» операцій List, яких не уникнути, наприклад:

* зрізання: `list[from..to]`
* додавання: `list.add(item)`

## Протокол ітератора

Операції з List, які треба реалізувати, зводяться до різних способів перебирання.
Прочитайте про [протокол ітератора][iter].
Тоді ми зможемо зробити так:

```wren
var list = ListOps.new([1, 2, 3, 4])
for (item in list) {
    do_something_with(item)
}
```

[iter]: https://wren.io/control-flow.html#the-iterator-protocol
