# Довідка

Модуль `Time` використовують, щоб показувати дати й час у зрозумілому для людини форматі.
Хоча технічно працювати з часом за допомогою `Time` і можливо, в Elm є пакети від спільноти, які значно краще підходять для цього завдання, наприклад [`justinmimbs/date`][date] або [`CoderDennis/elm-time-format`][elm-time-format].

## Posix

Час подають непрозорим типом `Posix`, який обгортає час Unix-епохи, тобто кількість мілісекунд, що минули з опівночі 1 січня 1970 року за UTC.
`Posix` - це однозначне значення, яке не змінюється залежно від часового поясу, тому це вдалий вибір для зберігання часу.
У застосунку Elm час у форматі `Posix` зазвичай надають зовнішні джерела, наприклад браузер.

Перетворити `Posix` на кількість мілісекунд і навпаки можна за допомогою таких функцій:

```elm
posixToMillis : Posix -> Int
millisToPosix : Int -> Posix
```

## Часові пояси

У повсякденному житті ми зазвичай не читаємо `Posix`, а віддаємо перевагу місцевому часу, який залежить від нашого розташування на Землі та місцевих правил переходу на літній час.
В Elm цю інформацію закодовано в непрозорому типі `Zone`, який зазвичай надає браузер.

Є особливий `Zone`, який доступний завжди:

```elm
utc : Zone
```

## Час для людини

Маючи `Posix` і `Zone`, ми маємо достатньо інформації, щоб показати місцевий час із будь-яким рівнем деталізації.
Ось список функцій, які для цього можна використати:

```elm
toYear : Zone -> Posix -> Int
toMonth : Zone -> Posix -> Month
toDay : Zone -> Posix -> Int
toWeekday : Zone -> Posix -> Weekday
toHour : Zone -> Posix -> Int
toMinute : Zone -> Posix -> Int
toSecond : Zone -> Posix -> Int
toMillis : Zone -> Posix -> Int
```

Ми вже помітили ще два власні типи з `Time`:

```elm
type Month = Jan | Feb | Mar | Apr | May | Jun | Jul | Aug | Sep | Oct | Nov | Dec
type Weekday = Mon | Tue | Wed | Thu | Fri | Sat | Sun
```

Перетворення цих власних типів на зрозумілі для людини значення залишається за користувачем.
