# Підказки

## Загальне

- Кожне завдання - лише тонка обгортка над словом зі словника
  [`math.combinatorics`][math.combinatorics].
- Слова для підрахунку приймають два цілі числа, а слова для переліку -
  послідовність.

## 1. Порахувати комбінації

- `nCk ( n k -- m )` повертає кількість способів вибрати `k` елементів
  із `n`. Стек уже в потрібному порядку, тож просто викличмо його.

## 2. Порахувати перестановки

- `nPk ( n k -- m )` повертає кількість упорядкованих способів вибрати `k`
  елементів із `n`.

## 3. Перелічити комбінації

- `all-combinations ( seq k -- combinations )` повертає кожну
  підмножину з `k` елементів `seq` у лексикографічному порядку.

## 4. Перелічити перестановки

- `all-permutations ( seq -- permutations )` повертає всі впорядкування
  `seq`.

## 5. Комбінації, сума яких дорівнює цільовому значенню

- Почнімо з усіх `k`-комбінацій з `all-combinations`.
- Залишмо лише ті, елементи яких у сумі дають `target`. `filter` із
  [`sequences`][sequences] приймає quotation, що повертає булеве значення
  (англ. Boolean); усередині нього `sum` (з [`math`][math]) підсумовує одну
  комбінацію, а `=` порівнює результат із `target`.
- Оскільки всередині quotation потрібен `target`, визначення слова через
  `::` (з [`locals`][locals]) дає змогу звертатися до `seq`, `k` і `target`
  на імʼя.
