# Вступ

Ця вправа навчить нас базових складників мови Ruby.
Тут буде багато матеріалу, але не варто хвилюватися, якщо щось видасться надто складним: ми розглянемо все набагато глибше в міру просування треком.

Одна з ключових речей, які варто зрозуміти про Ruby, полягає в тому, що це [обʼєктно-орієнтована мова][object-oriented-programming] і що **усе в Ruby є [обʼєктом][object]**. Числа, рядки тексту (англ. string), масиви, усе це обʼєкти.

## Змінні та константи

Ми зазвичай користуємося обʼєктами, даючи їм імена за допомогою змінних або констант.

Змінні завжди записують у [зміїному регістрі][snake-case].
Змінна протягом свого існування може посилатися на різні обʼєкти.
Наприклад, `my_first_variable` можна визначати й перевизначати багато разів за допомогою оператора `=`:

```ruby
my_first_variable = 1
my_first_variable = "Some string"
my_first_variable = SomeComplexObject.new
```

Константи ж передбачають лише одне присвоєння.
Вони мають починатися з великої літери й зазвичай пишуться великими літерами, а слова розділяються підкресленнями.
Наприклад:

```ruby
MY_FIRST_CONSTANT = 10

# Redefining not allowed
# MY_FIRST_CONSTANT = "Some String"
```

## Класи

Ruby організовано в класи.
Класи визначають за допомогою ключового слова `class`, після якого йде назва класу.
Обʼєкти зазвичай створюють шляхом побудови примірників класів за допомогою методу `.new`.
Наприклад:

```ruby
# Define the class
class Calculator
  #...
end

# Create an instance of it and assign it to a variable
my_first_calc = Calculator.new
```

## Методи

Одиниці функціональності інкапсульовані в методах, подібно до _функцій_ в інших мовах.

Метод можна визначити з позиційними аргументами, ключовими аргументами (які визначають і викликають за допомогою синтаксису `:`) або взагалі без аргументів.

Методи або неявно повертають результат останньої виконаної інструкції, або можуть явно повернути обʼєкт за допомогою ключового слова `return`.

```ruby
class Calculator

  # Positional arguments
  def add(num1, num2)
    return num1 + num2 # Explicit return
  end

  # Keyword arguments
  def multiply(num1:, num2:)
    num1 * num2 # Implicit return
  end
end
```

Методи викликають за допомогою синтаксису `.`:

```ruby
calc = Calculator.new
calc.add(1, 3)
calc.multiply(num1: 2, num2: 5)
```
