# Доповнення до інструкцій

## Повідомлення винятків

Іноді виникає потреба [підняти виняток](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). Роблячи це, завжди варто додати **змістовне повідомлення про помилку**, яке вказує на її джерело. Це робить код зрозумілішим і суттєво допомагає під час налагодження. Якщо ми знаємо, що джерело помилки матиме певний тип, можна підняти один із [вбудованих типів помилок](https://docs.python.org/3/library/exceptions.html#base-classes), але все одно варто додати змістовне повідомлення.

У цій вправі потрібно використати [інструкцію raise](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement), щоб «викинути» `ValueError` для різних основ вхідних і вихідних даних. Тести пройдуть лише тоді, коли ми і зробимо `raise` для `exception`, і додамо до нього змістовне повідомлення.

Щоб підняти `ValueError` з повідомленням, запишіть повідомлення як аргумент типу `exception`:

```python
# for input.
raise ValueError("input base must be >= 2")

# another example for input.
raise ValueError("all digits must satisfy 0 <= d < input base")

# or, for output.
raise ValueError("output base must be >= 2")
```
