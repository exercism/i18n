## Дуже коротка історія

Обробляти символи в компʼютерах було значно простіше в попередні десятиліття, коли програмісти вважали англійську єдиною важливою мовою.
Отже: 26 літер у верхньому та нижньому регістрі, 10 цифр, кілька розділових знаків, а також код (0x07), щоб продзвонити в дзвіночок. І все це вміщалося в 7 бітів: набір символів ASCII.

Звісно, люди почали питати про à, ä та Ł, потім інші почали питати про ऄ, ஹ та ญ, а молодь захотіла емодзі 😱.
Що ж робити?

Коротко кажучи, багатьом розумним і терплячим людям довелося роками засідати в комітетах, зʼясовуючи деталі набору символів Unicode і таких кодувань, як UTF-8, а безліч програм потребували _дуже_ складної переробки.
Крім того, зʼявилося багато нових bug.

Щоб _усе_ не зламалося, дизайн Unicode/UTF-8 гарантує, що перші 127 кодів збігаються з ASCII _(навіть дзвіночок)_.

## Символи в Julia

Мови, створені після приблизно 2005 року, мають величезну перевагу: досить стабільний стандарт Unicode уже існував.

Julia (уперше випущена 2012 року) могла припускати, що все буде в Unicode: символи, рядки тексту (англ. string), назви змінних і функцій, математичні оператори...

Як сказано в документації: «Julia робить роботу зі звичайним текстом ASCII простою та ефективною, а робота з Unicode є настільки ж простою та ефективною, наскільки це можливо».
Звернімо увагу на «наскільки це можливо»: це важлива частина твердження.

***Символьні літерали записують в одинарних лапках, і вони відрізняються від рядків тексту, записаних у подвійних лапках.***

Для людей зі світу C/C++ це очевидно, але для програмістів Python і Javascript може збивати з пантелику.

```julia-repl
julia> a = 'a'  # Roman alphabet
'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)

julia> typeof(a)
Char

julia> jha = 'झ'  # Devanagari alphabet
'झ': Unicode U+091D (category Lo: Letter, other)

julia> typeof(jha)
Char

julia> '❤'  # heart emoji
'❤': Unicode U+2764 (category So: Symbol, other)
```

З прикладів видно, що йдеться про тип `Char`, і в Julia є додаткова інформація про категорію символу.

Придивившись ближче, бачимо, що ці символи можна подати чотирма шістнадцятковими цифрами.
Повному набору символів потрібно до 6 шістнадцяткових цифр.

Ці числа називають «кодовими точками», і зараз вони охоплюють діапазон від U+0000 до U+10FFFF.
У REPL вони відображаються, але в коді, щоб отримати їх, скористайтеся `codepoints()`.

Перетворити `Char` на `Int` і навпаки дуже просто:

```julia-repl
julia> Int('a')
97

julia> Char(97)
'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
```

Компілятор дозволяє _деякі_ форми цілочисельної арифметики над `Char`:

```julia-repl
julia> 'b' - 'a'  # interval, in alphabetic order
1

julia> 'b' + 'a'
ERROR: MethodError: no method matching +(::Char, ::Char)

julia> 'a' + 5
'f': ASCII/Unicode U+0066 (category Ll: Letter, lowercase)

julia> 'f' + ('A' - 'a')  # same as `uppercase('f')`
'F': ASCII/Unicode U+0046 (category Lu: Letter, uppercase)
```

## Функції для символів

Багато функцій для роботи з рядками тексту можуть також працювати з вхідними даними типу `Char`.

- Для відповідних абеток змінюйте регістр за допомогою `uppercase()` і `lowercase()`.
- Перевіряйте регістр за допомогою `isuppercase()` і `islowercase()`.
- Перевіряйте тип символу за допомогою:
  - `isletter()` охоплює багато абеток
  - `isdigit()` перевіряє строго 0:9
  - `isnumeric()` ширша за `isdigit`, тож повертає `true` для ¾ і різних неєвропейських писемностей
  - `isxdigit()`, шістнадцяткові цифри
  - `isascii()`, символ до Unicode
  - `ispunct()`, розділові знаки
  - `isspace()`, будь-який пробільний символ
  - `isprint()`, друковані символи (протилежна до неї - `iscntrl()`)

```julia
islowercase('A')  # false
uppercase('γ')  # 'Γ': Unicode U+0393 (category Lu: Letter, uppercase)
ispunct('@')  # true
isdigit('A')  # false
isxdigit('A')  # true
```

## Перетворення між вектором `Char` і рядком тексту

Щоб перетворити рядок тексту на вектор `Char`, можна скористатися `collect()`.

Щоб перетворити вектор `Char` на рядок тексту, є конструктор `String()`.

```julia-repl
julia> s = "abcde"
"abcde"

julia> cv = collect(s)
5-element Vector{Char}:
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)
 'd': ASCII/Unicode U+0064 (category Ll: Letter, lowercase)
 'e': ASCII/Unicode U+0065 (category Ll: Letter, lowercase)

julia> String(cv)
"abcde"
```

Це працює з будь-якими символами, не лише з ASCII.

```julia-repl
julia> collect("❤,😱")
3-element Vector{Char}:
 '❤': Unicode U+2764 (category So: Symbol, other)
 ',': ASCII/Unicode U+002C (category Po: Punctuation, other)
 '😱': Unicode U+1F631 (category So: Symbol, other)
```

Зауважмо, що конструктор `String()` працює з вектором.
Щоб _перетворити_ один `Char` на рядок тексту з одного символу, потрібна функція `string()`, з малої літери `s`.

```julia-repl
julia> string('a')
"a"
```

## Зберігання

Усе, про що йшлося в цьому документі досі, здається досить простим, тож невже справді немає про що хвилюватися?

На жаль, це надто оптимістично!

Одна зі складнощів випливає з потреби в «до» 6 шістнадцяткових цифр на одну кодову точку.
Це означає, що різні символи потребують різного обсягу памʼяті в кодуванні UTF-8.

Один байт може зберігати (беззнакові) числа лише до 255, тобто дві шістнадцяткові цифри, тож UTF-8 використовує змінну кількість байтів (від 1 до 4), щоб зберегти `Char`.
Їх називають «кодовими одиницями», а функція `ncodeunits()` поверне число, потрібне для заданого символу.

```julia-repl
julia> codepoint(jha)  # jha 'झ' is defined in an earlier example
0x0000091d

julia> ncodeunits(jha)
3

julia> ncodeunits('a')  # ASCII character
1

julia> ncodeunits('😱')  # emoji
4
```

До того ж, не все, що можна показати на екрані, має власну унікальну кодову точку.
Деякі візуально різні символи вважаються похідними від інших, тож Unicode розглядає їх як батьківський символ плюс модифікатор.
