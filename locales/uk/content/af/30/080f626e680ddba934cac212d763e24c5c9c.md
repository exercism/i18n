# Докладніше

Окрім класів символів і кванторів, регулярні вирази вміють описувати *структуру* та *контекст* тексту. Ці можливості живуть у тому самому словнику [`regexp`][regexp] і записуються літералом `R/ /`.

## Групування та чергування

Круглі дужки `( )` групують частину виразу, щоб квантор або `|` («це або те») застосовувався до всієї групи. `?` після групи робить її необовʼязковою:

```factor
USING: regexp ;

"abab"    R/ (ab)+/ matches? .             ! => t
"cat"     R/ cat|dog/ matches? .           ! => t
"$100.50" R/ \$\d+(\.\d{2})?/ matches? .   ! => t
"$100"    R/ \$\d+(\.\d{2})?/ matches? .   ! => t   (group optional)
```

## Привʼязки

```
^    ! start of the string
$    ! end of the string
\b   ! a word boundary
```

*Межа слова* (`\b`) виникає там, де символ слова (літера, цифра або підкреслення) стикається із символом, який не належить слову, зокрема на кінцях рядка тексту (англ. string). Тож `\bcat\b` знаходить збіг із `cat` лише тоді, коли він стоїть окремо:

```factor
USING: regexp ;

"cat nap" R/ \bcat\b/ re-contains? .   ! => t
"scatter" R/ \bcat\b/ re-contains? .   ! => f
```

## Перевірка навколо

*Перевірка навколо* зʼясовує, що стоїть одразу до або після певного місця, і не робить ці символи частиною збігу, бо має нульову ширину:

```
(?=...)    ! lookahead
(?!...)    ! negative lookahead
(?<=...)   ! lookbehind
```

```factor
USING: regexp ;

"spent $100 and $25" R/ (?<=\$)\d+/ all-matching-subseqs .
! => { "100" "25" }

"up 5% then 12%" R/ \d+(?=%)/ all-matching-subseqs .
! => { "5" "12" }
```

## Опції

Літера опції після закривної `/` змінює весь вираз. `i` робить пошук незалежним від регістру:

```factor
USING: regexp ;

"REFUND" R/ refund/i matches? .   ! => t
```

## Перетворення кожного збігу

`map-matches` виконує quotation для кожного збігу й збирає результати; `each-match` робить те саме, але лише заради побічних ефектів. Обидва передають quotation індекс `start`, індекс `end` і весь рядок тексту, тож `subseq` дістає текст збігу:

```
map-matches ( string regexp quot: ( start end string -- obj ) -- seq )
each-match  ( string regexp quot: ( start end string --     ) --     )
```

```factor
USING: math regexp sequences ;

"a1 b22 c333" R/ \d+/ [ subseq length ] map-matches .
! => { 1 2 3 }
```

## Що Factor не підтримує

Рушій регулярних виразів у Factor не має **вилучення груп захоплення** (група `( )` структурує вираз, але прочитати текст, який вона захопила, не можна), **зворотних посилань** (`\1`) і **лінивих/нежадібних** кванторів (`*?`, `+?`). Ідіоматична заміна груп захоплення - це перевірка навколо: знаходимо потрібну частину й розпізнаємо її за контекстом навколо.
