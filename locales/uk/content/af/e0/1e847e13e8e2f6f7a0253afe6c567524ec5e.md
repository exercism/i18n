# Докладніше

Є два основні типи властивостей:

1. автоматично реалізовані властивості, у яких аксесори `get` і `set` не мають тіла.
   Їх можна явно ініціалізувати, а можна й ні. Наприклад:
   ```csharp
   public int MyProperty {get; set;} = 42;
   ```
2. ті, у яких аксесори обчислюють вирази та виконують інструкції. Код може
   бути таким простим, як повернення чи присвоєння значення допоміжному полю. Наприклад:
   ```csharp
   private int myField;
   public int MyProperty
   {
     get { return myField; }
     set { myField = value; }
   }
   ```

Між властивостями та методами чимало спільного і в поведінці, і в можливостях.
Якщо властивість не є автоматично реалізованою, вона може містити будь-яку інструкцію чи вираз,
які допустимі в межах класу. У типовому випадку про них часто кажуть, що вони обгортають
допоміжне поле.
Хоча часто буває очевидно, чи кодувати поведінку як властивість, а чи як метод у конкретному випадку, нерідко
це рішення на розсуд розробника, зокрема й щодо того, скільки коду має
виконуватися в аксесорах. Часто трапляється перевірка в аксесорі set і просте обчислення чи форматування в
аксесорі get:

```csharp
private float fraction;
public float Percentage
{
  get { return fraction * 100; }
  set
  {
    if (value < 0 || value > 100)
    {
      throw new ArgumentException("Percentage must be between 0 and 100");
    }
    fraction = value / 100;
  }
}
```

Так само, як і інші члени класу, властивості можуть мати рівні доступу.
Найчастіше властивості мають рівень доступу, відмінний від приватного, відповідно до
свого основного призначення. Іноді один з аксесорів має
інший рівень доступу, ніж сама властивість. У випадку з `TareWeight`
за досить штучного обмеження «безпеки» була можливість
зробити публічну властивість із приватним аксесором get. Це означає, що код, зовнішній
щодо класу, може встановлювати значення властивості, але прочитати його (get) може лише код усередині
класу.

```csharp
public int ConfidentialValueUsedInternally {private get; set; }
```

Аксесори set з непублічним доступом також підтримуються, але частіше трапляється випадок, коли
аксесор set можна взагалі опустити. Можливо, це тому, що
значення властивості задають у конструкторі класу.

```csharp
class MyClass
{
  public MyClass( int importantValue)
  {
    ConstructedValue = importantValue;
  }
  public int ConstructedValue {get;}
}
```

У цій вправі ми розглянули базове використання властивостей. Складніші
теми ми знайдемо в інших вправах:

- властивості, аксесори get і set з тілом-виразом (див. «Члени з тілом-виразом»)
- властивості в інтерфейсах (див. «Інтерфейси»)
- властивості й абстрактні властивості в абстрактних класах (див. «Успадкування»)
- використання ключового слова `readonly` зі властивостями (див. «Незмінність»)
- статичні властивості (див. «Статика»)
- індексатори (див. «Індексатори»)
