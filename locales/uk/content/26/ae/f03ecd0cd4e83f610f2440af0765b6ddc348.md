# Доповнення до інструкцій

## Слова

Реалізуйте:

- `grep ( pattern flags files -- lines )`

`pattern` - це рядок тексту (англ. string), який шукаємо, `flags` - це масив із нуля або більше рядків тексту-прапорців: `"-n"`, `"-l"`, `"-i"`, `"-v"` і `"-x"`, а `files` - це масив з одного або більше імен файлів. Поверніть рядки, що збігаються (з будь-якими запитаними префіксами з імені файлу та номера рядка), як масив рядків тексту.

Коли задано прапорець `-l`, поверніть масив імен файлів, які містять принаймні один збіг.

## Читання файлів

Читайте рядки файлу за допомогою `file-lines`, передаючи кодування:

```factor
USING: io.encodings.utf8 io.files ;

"iliad.txt" utf8 file-lines
! => { "Achilles sing, O Goddess! Peleus' son;" ... }
```

Три файли з тестовими даними (`iliad.txt`, `midsummer-night.txt` і `paradise-lost.txt`) постачаються разом із вправою в робочій директорії, тож їх можна просто прочитати за назвою.
