# Вступ

Метод - це функція з особливим аргументом, _отримувачем_.
Отримувач стоїть у власному списку аргументів між ключовим словом `func` і назвою методу.

```go
func (receiver type) MethodName(parameters) (returnTypes) {

}
```

Визначити метод можна лише з отримувачем, тип якого визначено в тому самому пакеті, що й метод.

```go
type Person struct {
    Name string
}

func (p Person) Greetings() string {
	return fmt.Sprintf("Welcome %s!", p.Name)
}

s := Person{Name: "Bronson"}
fmt.Println(s.Greetings())
// Output: Welcome Bronson!
```

Є два типи отримувачів: отримувачі-значення та отримувачі-вказівники.

Методи з отримувачем-значенням працюють з копією переданого значення, тобто будь-яка зміна, зроблена з отримувачем усередині методу, не видима для того, хто викликав метод.

Можна оголошувати методи з отримувачами-вказівниками, щоб змінювати значення, на яке вказує отримувач.
Для цього перед назвою типу ставлять `*`: наприклад, для типу `rect` отримувач-вказівник оголошується як `*rect`.
Такі зміни також видимі для того, хто викликав метод.

```go
type rect struct {
	width, height int
}
func (r *rect) squareIt() {
	r.height = r.width
}

r := rect{width: 10, height: 20}
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 20

r.squareIt()
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 10

```
