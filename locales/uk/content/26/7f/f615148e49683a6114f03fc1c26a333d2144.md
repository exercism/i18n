# Інструкції

Комплексним числом називають число виду `a + b * i`, де `a` і `b` є дійсними числами, а `i` задовольняє умову `i^2 = -1`.

`a` називають дійсною частиною, а `b` називають уявною частиною `z`.
Спряженим до числа `a + b * i` називають число `a - b * i`.
Модуль комплексного числа `z = a + b * i` дорівнює дійсному числу `|z| = sqrt(a^2 + b^2)`. Квадрат модуля `|z|^2` є результатом множення `z` на спряжене до нього число.

Сума/різниця двох комплексних чисел передбачає окреме додавання/віднімання їхніх дійсних і уявних частин:
`(a + i * b) + (c + i * d) = (a + c) + (b + d) * i`,
`(a + i * b) - (c + i * d) = (a - c) + (b - d) * i`.

Результат множення за означенням такий:
`(a + i * b) * (c + i * d) = (a * c - b * d) + (b * c + a * d) * i`.

Число, обернене до ненульового комплексного числа, дорівнює:
`1 / (a + i * b) = a/(a^2 + b^2) - b/(a^2 + b^2) * i`.

Ділення комплексного числа `a + i * b` на інше `c + i * d` дає:
`(a + i * b) / (c + i * d) = (a * c + b * d)/(c^2 + d^2) + (b * c - a * d)/(c^2 + d^2) * i`.

Піднесення e до комплексного степеня можна виразити як `e^(a + i * b) = e^a * e^(i * b)`, останній член якого задає формула Ейлера `e^(i * b) = cos(b) + i * sin(b)`.

Реалізуйте такі операції:
 - додавання, віднімання, множення і ділення двох комплексних чисел,
 - спряження, модуль, експонента заданого комплексного числа.

Будемо вважати, що мова програмування, яку ми використовуємо, не має реалізації комплексних чисел.
