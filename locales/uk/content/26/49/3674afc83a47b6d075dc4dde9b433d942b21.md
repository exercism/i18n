# Встановлення

У цьому треку ми всюди покладаємося на [Wren Console][wren-console], щоб мати локальне середовище виконання для Wren. Це означає, що ми припускаємо: весь код Wren на компʼютері виконуватиметься за допомогою [Wren Console][wren-console]. Будь ласка, не плутайте це з офіційним <abbr title="Інтерфейс командного рядка">CLI</abbr> від Wren. В ідеальному світі можна було б користуватися цим середовищем виконання, але наразі воно [має](https://github.com/wren-lang/wren-cli/pull/74) [кілька](https://github.com/wren-lang/wren/pull/1006) [різних](https://github.com/wren-lang/wren-cli/issues/108) [проблем](https://github.com/wren-lang/wren-cli/pull/105), що робить його не найкращим вибором для вивчення Wren з Exercism.

Wren Console відгалужено від Wren CLI, він розвʼязує ці проблеми та додає можливості, щоб наше навчання було простішим. Не варто хвилюватися: знання та концепції мови Wren, які ми тут вивчаємо, стануть у пригоді всюди, де ми забажаємо використовувати Wren у майбутньому.

## Огляд встановлення

- Встановіть Git, щоб мати команду `git`
- Встановіть [Wren Console][wren-console], щоб мати команду `wrenc`

### Встановлення Git

Нам потрібен виконуваний файл `git`, встановлений і доступний у PATH. Саме так Wren Package встановлює пакунки (наприклад, набір тестів, який знадобиться для перевірки наших вправ тощо).

- **Windows** - Офіційне [завантаження Git](https://git-scm.com/download/win) - гарний початок.
- **Linux** - Тут стане в пригоді улюблений менеджер пакунків.
- **Mac** - Усі останні версії Mac OS містять `git` одразу з коробки.

Переконатися, що Git встановлено, можна командою `git --version`:

```
$ git --version
git version 2.31.1
```

Не варто хвилюватися, якщо точна версія не збігається, зазвичай це не так уже й критично.


### Встановлення Wren Console

#### Windows

Найімовірніше, нам захочеться [завантажити останній випуск][releases] із GitHub. Після цього треба розпакувати архів і скопіювати виконуваний файл `wrenc` у PATH.

Також можна [зібрати з джерельного коду][build-from-source] за допомогою Visual Studio.

#### Linux

Можна [завантажити останній випуск][releases] із GitHub або [зібрати з джерельного коду][build-from-source].

```sh
wget -c https://github.com/joshgoebel/wren-console/releases/download/v0.3.1/wren-console-v0.3.1-linux.tar.gz
tar xzf wren-console-v0.3.1-linux.tar.gz
```

І переконайтеся, що він доступний у `PATH`.

```sh
cp bin/wrenc /usr/local/bin/
```


#### Mac

Найпростіший спосіб встановлення - скористатися [Homebrew][homebrew] tap і формулою від Exercism:

```
brew tap exercism/wren
brew install wren-console
```

Або можна [завантажити останній випуск][releases] із GitHub і встановити його вручну, як показано в інструкціях для Linux. Зібрати з джерельного коду теж досить просто, якщо ми знайомі з такими речами.

### Перевірка встановлення

Після того, як нам здається, що бінарний файл встановлено правильно, варто перевірити, чи все працює.

1. Відкрийте _термінал_ (`Terminal`, `cmd`, `Powershell`, `bash`, ...)
2. Запустіть `wrenc -v`

Ми побачимо перелік версій і `wrenc`, і Wren:

```
wrenc v0.3.1 (wren v0.4.0)
```

**Примітка**. Важливо відкрити _нове_ вікно термінала. Уже відкриті вікна термінала могли не оновитися після завершення встановлення. Це означає, що відкриті термінали не знають про встановлення нової програми.

> _**Довідка**_: `'wrenc' is not recognised`
>
> Ймовірно, `wrenc` не додано до PATH... У MacOS і Linux можна змінити шлях, додавши наступне до `~/.bash_profile` або `~/.zshrc`:
>
> ```bash
> export PATH=/path/to/your/wrenc/:$PATH
> ```
> **Не знаю, чи все це правильно.**
> У Windows відкрийте «start menu» і знайдіть «environment variables». Тут потрібно відредагувати запис `PATH` і _додати_ шлях до бінарних файлів `wrenc`. Зазвичай вони розташовані за шляхом `C:\Program Files\nodejs`. Якщо переглянути цю теку в `File Explorer`, там мають бути `node.exe`, `npm.bat` і `npx.bat`.
>
> Закрийте всі відкриті термінали та відкрийте новий.

## Вимоги до завдання

Дотримуйтеся [цих інструкцій][cli-walkthrough], щоб завантажити CLI `exercism` для своєї операційної системи.

Після налаштування CLI завантажте першу вправу - `hello-world`:

```bash
$ exercism download --exercise=hello-world --track=wren
```

Далі кожному завданню потрібні певні пакунки Wren, щоб запускати тести. Їх можна встановити, виконавши цю команду в теці завдання:

```bash
$ wrenc package.wren install
```
