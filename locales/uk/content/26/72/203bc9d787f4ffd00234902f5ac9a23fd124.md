# Детальніше

Параметр методу можна зробити необовʼязковим, присвоївши йому типове значення. Коли ми викликаємо метод із необовʼязковими параметрами, нам не обовʼязково передавати для них значення. Якщо для необовʼязкового параметра не передано значення, використовується його типове значення.

Необовʼязкові параметри повинні стояти в кінці списку параметрів; після них не можуть іти обовʼязкові параметри.

```haxe
class Card {
  static function newYear(year = 2021):String {
    return "Happy " + year;
  }
}

Card.newYear(); // Happy 2020
Card.newYear(1990); // Happy 1990
```

Необовʼязковому параметру можна присвоїти `null`, використавши оператор `?` перед іменем змінної:

```haxe
function newYear(?year:Int) {
  if (year != null)
    return "It's " + year;
  return "Year is null";
}

newYear(); // Year is null
```
