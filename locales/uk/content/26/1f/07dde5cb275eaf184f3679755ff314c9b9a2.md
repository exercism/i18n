# Докладніше

[Вирази `throw`][throw-expressions] є альтернативою інструкціям `throw` і, зокрема, розширюють можливості тернарних та інших складених виразів.

```csharp
string trimmed = str == null ? throw new ArgumentException() : str.Trim();
```

Якщо `str` у наведеному вище коді дорівнює `null`, буде викинуто виняток.

[throw-expressions]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/throw#the-throw-expression
