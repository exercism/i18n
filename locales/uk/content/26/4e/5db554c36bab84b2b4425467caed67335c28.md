# Докладніше

[Замикання][closures] у Swift - це самодостатні блоки коду, яким можна передати параметри, щоб запустити їхнє обчислення й отримати повернені значення.
Замикання також захоплюють значення зі свого середовища й використовують їх у своїх обчисленнях.
Оскільки вони самодостатні, їх можна передавати в програмі, як і будь-які інші значення, або присвоювати константам і змінним.

Замикання можуть видатися дуже схожими на функції Swift; так воно і є, і недарма.
Функції у Swift - це окремі випадки замикань, які мусять мати імʼя і визначаються трохи іншим синтаксисом.

Хоча функції у Swift технічно є замиканнями, коли люди кажуть «замикання» у Swift, вони мають на увазі [вирази замикань][closure-expressions].
Вираз замикання записують як список параметрів, після якого йде тип поверненого значення і ключове слово `in`, а далі тіло замикання, і все це вкладено в пару фігурних дужок:

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}
```

Це визначає вираз замикання типу `(Double, Double) -> Double`, і його можна виконати подібно до функції цього типу, застосувавши його до параметрів відповідного типу:

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}(10.0, 15.0)
// returns 12.5
```

Оскільки щоразу виписувати повний вираз замикання, коли хочеться його виконати, не дуже зручно, замикання можна присвоювати іменам, як і будь-яке інше значення у Swift.
Тоді їх можна викликати, застосувавши імʼя до параметрів:

```swift
let mean = { (a: Double, b: Double) -> Double in
  (a + b) / 2.0
}

mean(13.0, 100.0)
// returns 56.5
```

Як видно вище, замикання, як і звичайні функції, можуть опускати ключове слово `return`, якщо тіло замикання складається з одного виразу.

Найчастіше замикання використовують із функціями вищого порядку, або передаючи їх як параметри, або повертаючи як результат:

```swift
[11, 75, 3, 99, 53].contains(where: { (x: Int) -> Bool in x > 100 })
// returns false

["apple", "ball", "carrot"].sorted(by: { (s1: String, s2: String) -> Bool in s1.count < s2.count })
// returns ["ball", "apple", "carrot"]

func makeAdder(base: Int) -> (Int) -> Int {
  { (x: Int) -> Int in base + x }
}
```

## Виведення типів замикань

Коли тип поверненого значення або типи параметрів можна [вивести з контексту][inferring-closure-types], їх можна опустити у виразі замикання.
Крім того, якщо типи параметрів можна опустити, то можна опустити й дужки навколо імен параметрів:

```swift
let mean: (Double, Double) -> Double = { a, b in a + b / 2.0 }

func makeAdder(base: Int) -> (Int) -> Int {
  { x in base + x }
}

["apple", "ball", "carrot"].sorted(by: { s1, s2 in s1.count < s2.count })
```

- У першому прикладі тип можна вивести з анотації константи `mean`.
- У другому компілятор знає з визначення `makeAdder`, що `base` є цілим числом, і що повернена функція мусить мати тип `(Int) -> Int`. Далі він може перевірити, що якщо `x` має тип `Int`, тоді замикання матиме тип `(Int) -> Int`, а отже, ми можемо опустити сигнатуру типу в замиканні, оскільки `(Int) -> Int` є єдиною можливою допустимою сигнатурою замикання.
- Третій приклад схожий, але компілятор має взяти частину інформації про типи з масиву, з яким використовують цей метод. Він знає, що метод `sorted(by:)` приймає як параметр замикання з двома параметрами того самого типу, що й елементи колекції, яку сортують, і яке повертає `Bool`, тож компілятор може вивести, що тип поверненого значення замикання мусить бути `Bool`. А оскільки метод використовують із масивом рядків тексту (англ. string), він може визначити, що типи параметрів `s1` і `s2` обидва мусять бути `String`.

## Обмеження замикань

Як згадано вище, функції та замикання у Swift дуже схожі, але між ними є кілька важливих відмінностей:

- Замикання не можуть використовувати зовнішні мітки аргументів. Їх неможливо визначити, і спроба використати імʼя параметра під час виклику замикання призводить до помилки:

```swift
let add5 = { x in x + 5 }
add5(x: 10)
// Error: Extraneous argument label 'x:' in call
```

- Параметри в замиканнях не можуть мати типового значення параметра.
- Параметри в замиканнях можуть бути варіативними, але вони мусять мати імʼя та анотацію типу.
