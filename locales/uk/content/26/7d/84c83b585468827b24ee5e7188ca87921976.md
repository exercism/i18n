# Вказівки

Скрипку налаштовують на слух за еталонною нотою. Струни розташовані далеко одна від одної за висотою тону, а числа, задіяні тут, нецілі.

Усі пʼять завдань виконайте в класі `TUNING_THE_STRINGS`.

## 1. На октаву вгору

Нота на октаву вище має вдвічі більшу частоту.

```sather
TUNING_THE_STRINGS::octave_up(440.0d)
-- => 880.0d
```

## 2. На октаву вниз

На октаву нижче означає половину частоти.

```sather
TUNING_THE_STRINGS::octave_down(440.0d)
-- => 220.0d
```

## 3. Посередині

Дано дві частоти. Поверніть ту, що рівно посередині між ними.

```sather
TUNING_THE_STRINGS::midpoint(440.0d, 442.0d)
-- => 441.0d
```

## 4. Наскільки розходяться частоти?

Коли дві ноти близькі, але не однакові, ми чуємо биття раз на секунду за кожен цикл їхньої різниці. Поверніть, наскільки частоти розходяться. Відповідь ніколи не буває відʼємною, яка б нота не була вищою.

```sather
TUNING_THE_STRINGS::beats_per_second(441.5d, 440.0d)
-- => 1.5d
```

## 5. Розподіл практики

Дано кількість хвилин і кількість виконавців. Скільки хвилин отримує кожен? Кількість хвилин і кількість виконавців є цілими числами, але відповідь може бути нецілою.

```sather
TUNING_THE_STRINGS::minutes_each(45, 2)
-- => 22.5d
```
