# Інструкції

Як і майже всім, хто працює, Layla the Lisp Alien іноді потрібно робити звіти, щоб ділитися інформацією з іншими. Вона просить нас допомогти їй відформатувати дані, які вона має для цих звітів.

## 1. Форматування квартальних значень

Перше, що потрібно Layla, це функція `format-quarter-value`, яка приймає два параметри: календарний квартал і значення, та форматує їх для звіту. Вона повинна обчислюватися в рядок тексту (англ. string).

```lisp
(format-quarter-value "last" 3.14) ; => "The value last quarter: 3.14"
(format-quarter-value "this" 0) ; => "The value this quarter: 0"
```

## 2. Звіт за два квартали

Layla дякує нам за функцію `format-quarter-value` і каже, що вона буде дуже корисною в *наступній* функції, яка знадобиться.

У наступному звіті потрібно показати квартал і значення за два квартали, виведені на двох рядках.

Також вихідні дані потрібно спрямувати в потік, наданий як перший аргумент.

Наприклад, `(format-two-quarters t "last" 3.14 "this" 0)` виведе на стандартний вивід таке:

```

The value last quarter: 3.14
The value this quarter: 0

```

Звернімо увагу на порожні рядки навколо.

## 3. Читабельність для людей і для Lisp Alien

Layla забула розповісти нам, що Lisp Aliens люблять бачити значення у вигляді, який можна прочитати як дані Lisp. Тож їм потрібна нова функція, результат якої можна прочитати як дані Lisp (знову ж таки у вказаний потік):

```lisp
(format-two-quarters-for-reading nil "last" 3.14 "this" 0) ; =>

"(\"The value last quarter: 3.14\" \"The value this quarter: 0\")"
```
