# Доповнення до інструкцій

## Підказки

Щоб виконати цю вправу, потрібно реалізувати функцію `slices`,
яка приймає *text* і повертає підпослідовності цифр заданого
розміру:

Якщо ми розвʼязуємо цю вправу вперше, радимо дотримуватися наданої
сигнатури:

```haskell
slices :: Int -> String -> [[Int]]
```

Пізніше варто повернутися до цієї задачі та поекспериментувати з іншими типами
даних і бібліотеками:

- `ByteString` з пакета *bytestring*.
- `Sequence` з пакета *containers*.
- `Text` з пакета *text*.
- `Vector` з пакета *vector*.

Набір тестів навмисно створено так, щоб приймати майже будь-яку сигнатуру типу,
яка має сенс, тож радимо знайти ту, яку вважаємо найкращою.
