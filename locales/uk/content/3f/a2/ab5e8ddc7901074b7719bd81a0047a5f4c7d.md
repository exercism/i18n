# Вказівки

Ми працюємо ельфом у відділі логістики Санта-Клауса, і начальник дав нам пару завдань для оновлення програмного забезпечення системи.

## 1. Отримати назву іграшки

Система повинна мати змогу отримати назву іграшки з бази даних.
База даних складається з кортежів типу `(name: String, quantity: Int)`.

Реалізуйте функцію `getName(_:)`, яка приймає аргумент, що містить кортеж типу `(name: String, quantity: Int)`.

```swift
let toy = (name: "Doll", quantity: 10)
getName(toy)
// Returns "Doll"
```

## 2. Додати нову іграшку до бази даних

Ринок іграшок дуже динамічний: популярні іграшки змінюються дуже швидко.
Тому потрібна функція, яка створює нову іграшку.

Реалізуйте функцію `createToy(name:amount:)`, яка приймає аргументи `name`, що містить назву іграшки, та `amount`, що містить кількість іграшки.

```swift
getName(name: "Doll", quantity: 10)
// Returns (name: "Doll", quantity: 10)
```

## 3. Оновити кількість іграшки

Ельфи в майстерні Санти постійно виготовляють нові іграшки, і Санті потрібно відстежувати кількість кожної іграшки.
Щоб це робити, система повинна мати змогу оновлювати кількість іграшки в базі даних.

Реалізуйте функцію `updateQuantity(_:toy:Amount:)`, яка приймає такі аргументи:
- `toys`, що містить масив кортежів типу `(name: String, quantity: Int)`.
- `toy`, що містить назву іграшки, яку потрібно оновити.
- `amount`, що містить нову кількість іграшки.

Можна припустити, що іграшка вже є в базі даних, і це не потрібно перевіряти.

```swift
let toys = [(name: "Doll", quantity: 10), (name: "Car", quantity: 5), (name: "Train", quantity: 3)]
updateQuantity(toys, toy: "Doll", amount: 15)
// Returns [(name: "Doll", quantity: 15), (name: "Car", quantity: 5), (name: "Train", quantity: 3)]
```

## 4. Додати ключ категорії до іграшки

Санта хоче мати змогу розподіляти іграшки за категоріями в базі даних.
Це потрібно, щоб можна було легко знайти іграшки, коли треба зробити доставку, і щоб можна було сортувати іграшки в базі даних.

Однак, коли систему вперше реалізували, ключ категорії забули.
Тепер система повинна мати змогу додати ключ категорії до іграшки в базі даних.

Реалізуйте функцію `addCategory(_:category:)`, яка приймає такі аргументи:
- `toys`, що містить масив кортежів типу `(name: String, quantity: Int)`.
- `category`, що містить ключ категорії, який потрібно додати до іграшок.

Можна припустити, що іграшка вже є в базі даних, і це не потрібно перевіряти.
Також можна припустити, що іграшка ще не має ключа категорії.

```swift
let toys = [(name: "Car", quantity: 5), (name: "Train", quantity: 3)]
addCategory(toys,, category: "Vehicle")
// Returns [(name: "Car", quantity: 5, category: "Vehicle"), (name: "Train", quantity: 3, category: "Vehicle")]
```
