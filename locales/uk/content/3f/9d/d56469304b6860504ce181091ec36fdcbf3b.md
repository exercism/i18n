# Інструкції

Власниця місцевої піцерії попросила нас допомогти їй розрахувати час приготування різних піц. У цій вправі ми напишемо кілька функцій для цих розрахунків.

На нас чекають три завдання.

## 1. Обчислити залишок часу випікання у хвилинах

Визначте та реалізуйте функцію `remainingMinutesInOven()`, яка порахує, скільки ще хвилин потрібно тримати піцу в печі.

Функція має приймати один **необовʼязковий** параметр (із типовим значенням) для кількості хвилин, що минули від початку випікання піци. Якщо параметр не передано, вважаємо, що ми щойно поставили піцу в піч і вже минуло **0 (нуль)** хвилин.

Для простоти припустімо, що всім видам піци потрібно рівно 40 хвилин у печі, щоб бути готовими.

```kotlin
remainingMinutesInOven()   // => 40

remainingMinutesInOven(10)   // => 30
```

## 2. Обчислити час підготовки у хвилинах

Перед випіканням піци потрібно підготувати тісто, розкачати його та викласти на нього начинку.

Визначте та реалізуйте функцію `preparationTimeInMinutes()`, яка порахує, скільки хвилин потрібно на підготовку піци, перш ніж поставити її в піч.

Функція має приймати один **обовʼязковий** параметр (`numberOfIngredientTypes`) для кількості видів інгредієнтів начинки, які буде використано.

Вважаємо, що на замішування та розкачування тіста потрібно 5 хвилин, а на **кожен** вид начинки потрібно 2 хвилини.

```kotlin
preparationTimeInMinutes(0) // => 5

preparationTimeInMinutes(1) // => 7
```

## 3. Обчислити витрачений час у хвилинах

Визначте та реалізуйте функцію `elapsedCookingTimeInMinutes()`, яка порахує, скільки хвилин потрібно, щоб підготувати, спекти та подати піцу. Під час розрахунків використайте функції з попередніх кроків.

Функція має приймати два параметри. Перший параметр **обовʼязковий** і задає кількість видів інгредієнтів начинки. Другий параметр **необовʼязковий** і задає час подачі у хвилинах (вважаємо, що він дорівнює 0, якщо його не вказано).

```kotlin
elapsedCookingTimeInMinutes(1)  // => 47

elapsedCookingTimeInMinutes(2, 3)  // => 52
```
