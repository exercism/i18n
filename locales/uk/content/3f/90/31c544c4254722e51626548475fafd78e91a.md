# Вступ

## Класи

Основною обʼєктно-орієнтованою конструкцією в Java є _клас_, який поєднує дані (_поля_) і поведінку (_методи_).
Поля й методи класу називають його _членами_.

Доступ до членів можна контролювати за допомогою модифікаторів доступу, з яких два найпоширеніші:

- `public`: до члена може звертатися будь-який код (без обмежень).
- `private`: до члена може звертатися лише код у тому самому класі.

Клас можна уявити як шаблон для створення екземплярів цього класу.
Щоб створити екземпляр класу (його ще називають _обʼєктом_), використовують ключове слово `new`:

```java
class Car {
}

// Create two car instances
Car myCar = new Car();
Car yourCar = new Car();
```

Поля мають тип і назву (її записують у camelCase) і можуть бути визначені будь-де в класі (за домовленістю їх записують у PascalCase):

```java
class Car {
    // Accessible by anyone
    public int weight;

    // Only accessible by code in this class
    private String color;
}
```

Полю можна за бажанням присвоїти початкове значення.
Якщо поле _не_ задає початкового значення, йому встановлюється типове значення його типу.
Значення полів екземпляра можна читати й оновлювати через точкову нотацію.

```java
class Car {
    // Will be set to specified value
    public int weight = 2500;

    // Will be set to default value (0)
    public int year;
}

Car newCar = new Car();
newCar.weight; // => 2500
newCar.year;   // => 0

// Update value of the field
newCar.year = 2018;
```

Приватні поля зазвичай оновлюють як побічний ефект виклику методу.
Такі методи зазвичай не повертають жодного значення, і тоді типом повернення має бути `void`:

```java
class CarImporter {
    private int carsImported;

    public void importCars(int numberOfCars)
    {
        // Update private field from public method
        carsImported = carsImported + numberOfCars;
    }
}
```
