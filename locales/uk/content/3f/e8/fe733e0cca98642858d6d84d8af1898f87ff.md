# Підказки

## 1. Опишіть прості числа

- використайте `fmt.Sprintf` для форматування

## 2. Опишіть числову коробку

- отримайте результат із методу `Number()`
- використайте `fmt.Sprintf` для форматування

## 3. Реалізуйте метод, який витягує число з вигадливої числової коробки

- використайте твердження типу, щоб перевірити, чи це `FancyNumber`
- отримайте `string` із методу `Value()`
- використайте `strconv.Atoi`, щоб перетворити `string` на `int` (ми можемо відкинути помилку, бо нам потрібен 0, якщо це не вдасться перетворити на `int`)

## 4. Опишіть вигадливу числову коробку

- використайте `ExtractFancyNumber`, щоб отримати значення `int`
- перетворіть `int` на `float64`
- використайте `fmt.Sprintf` для форматування

## 5. Реалізуйте `DescribeAnything`, який використовує їх усі

- використайте або твердження типу (наприклад, `i.(someType)`), або перемикач типу (`switch v := i.(type)`)
- не забудьте перетворити `int` на `float64`
