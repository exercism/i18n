# Вступ

## Параметри

У цій вправі ми розглянемо деякі деталі параметрів методів і їх використання в C#.

Параметри передають інформацію від методу, що викликає, до викликаного методу.

- Поведінку параметрів можна змінити за допомогою таких модифікаторів, як `ref` і `out`.

- Параметр із модифікатором `out` передає значення назад від викликаного методу до того, хто викликав. Цей параметр можна передати викликаному методу без ініціалізації, і в будь-якому разі всередині викликаного методу з ним поводяться так, ніби на вході його не було ініціалізовано. Розібратися в поведінці та правилах щодо модифікаторів параметрів найлегше на прикладах (див. нижче) і повідомленнях компілятора.

```csharp
void Foo(out int val)
{
    val = 42;
}
void Bar(int val)
{
    val = 42;
}

int importantValue = 1729;
Foo(out importantValue);
var result = importantValue == 42;
// => true

importantValue = 1729;
Bar(importantValue);
result = importantValue == 1729;
// => true
```

- Параметрам `out` потрібно присвоїти значення всередині викликаного методу.

- Параметр із модифікатором `ref` передає значення у викликаний метод. Коли метод повертає керування, той, хто викликав, побачить у цьому параметрі всі зміни, які зробив викликаний метод.

```csharp
void Foo(ref int val)
{
    val *= 7;
}

int importantValue = 6;
Foo(ref importantValue);
return importantValue;
// => 42
```

- Параметри `ref` мають бути змінними, оскільки викликаний метод працюватиме безпосередньо з тим параметром, який бачить той, хто викликав.
- Модифікатори `out` і `ref` потрібні як у сигнатурі викликаного методу, так і в місці виклику.
