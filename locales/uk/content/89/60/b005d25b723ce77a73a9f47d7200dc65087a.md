# Вступ

## Модулі

Досі всі вправи, які ми бачили, використовували класи.
Іноді нам не потрібні накладні витрати на створення обʼєкта зі станом, тож замість цього ми використовуємо `module`.

Модуль дуже схожий на клас (насправді `Module` є батьком `Class` в ієрархії обʼєктів), а головна різниця полягає в тому, що замість методів екземпляра ми використовуємо методи класу.
Методи класу починаються з `self.` і викликаються безпосередньо на модулі.

Наприклад:

```ruby
module Speaker
  def self.echo(something)
    "#{something} ... #{something}"
  end
end

Speaker.echo("Hello")   #=> "Hello ... Hello"
```

## Цикли

У Ruby є кілька способів писати цикли, але оскільки загалом ми частіше використовуємо перебирання, ніж цикли, найпоширенішим циклом, мабуть, є цикл `while`:

```ruby
counter = 0

while counter < 5
  counter += 1
end
```

Також можна використати його побратима `until`:

```ruby
counter = 0

until counter == 5
  counter += 1
end
```
