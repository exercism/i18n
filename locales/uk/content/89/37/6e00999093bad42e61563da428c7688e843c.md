# Докладніше

[Замикання][closures] в Swift - це самодостатні блоки коду, яким можна передати параметри, щоб запустити їхнє обчислення, і які повертають значення.
Замикання також захоплюють значення зі свого оточення й використовують їх у своїх обчисленнях.
Оскільки вони самодостатні, їх можна передавати в програмі, як і будь-які інші значення, або присвоювати константам і змінним.

Замикання можуть звучати дуже схоже на функції Swift; так і є, і на те є поважна причина.
Функції в Swift - це окремі випадки замикань, які повинні мати назву та визначаються дещо іншим синтаксисом.

Хоча функції в Swift технічно є замиканнями, коли в Swift говорять про «замикання», то мають на увазі [вирази замикання][closure-expressions].
Вирази замикання записуються як список параметрів, за яким іде тип повернення, ключове слово `in`, а далі тіло замикання, і все це в парі фігурних дужок:

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}
```

Це визначає вираз замикання типу `(Double, Double) -> Double`, і його можна виконати подібно до функції цього типу, застосувавши його до параметрів відповідного типу:

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}(10.0, 15.0)
// returns 12.5
```

Оскільки щоразу виписувати повний вираз замикання не дуже зручно, замикання можна присвоїти іменам, як і будь-яке інше значення в Swift.
Потім їх можна викликати, застосувавши імʼя до параметрів:

```swift
let mean = { (a: Double, b: Double) -> Double in
  (a + b) / 2.0
}

mean(13.0, 100.0)
// returns 56.5
```

Як видно вище, замикання, як і звичайні функції, можуть опускати ключове слово `return`, якщо тіло замикання складається з єдиного виразу.

Найчастіше замикання використовують із функціями вищого порядку, або передаючи їх як параметри, або повертаючи як результат:

```swift
[11, 75, 3, 99, 53].contains(where: { (x: Int) -> Bool in x > 100 })
// returns false

["apple", "ball", "carrot"].sorted(by: { (s1: String, s2: String) -> Bool in s1.count < s2.count })
// returns ["ball", "apple", "carrot"]

func makeAdder(base: Int) -> (Int) -> Int {
  { (x: Int) -> Int in base + x }
}
```
