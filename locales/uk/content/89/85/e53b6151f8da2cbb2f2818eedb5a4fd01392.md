# Вступ

У JavaScript масив - це схожа на список структура без фіксованої довжини, яка може містити примітиви чи обʼєкти будь-яких типів, навіть змішаних.

Щоб створити масив, додаймо елементи між квадратними дужками `[]`.
Щоб прочитати елемент із масиву, поставимо індекс у квадратних дужках `[]` після ідентифікатора.
Індекси масиву починаються з нуля.

Наприклад:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[2];
// => 3
```

Щоб дізнатися кількість елементів у масиві, скористаймося властивістю `length`:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.length;
// => 4
```

Щоб змінити елемент масиву, присвоїмо значення за його індексом:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[0] = 'one';
numbers;
// => ['one', 'two', 3, 'four']
```

## Методи

Деякі з [методів][array_methods], доступних для кожного обʼєкта Array, можна використати, щоб додати елементи до масиву або вилучити їх.

### push

> Метод `push()` додає один або кілька елементів у кінець масиву й повертає нову довжину масиву.[^1]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.push(5); // => 5
numbers;
// => [1, 'two', 3, 'four', 5]
```

### pop

> Метод `pop()` вилучає останній елемент масиву й повертає його.
> Цей метод змінює довжину масиву.[^2]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.pop(); // => four
numbers;
// => [1, 'two', 3]
```

### shift

> Метод `shift()` вилучає перший елемент масиву й повертає вилучений елемент.
> Цей метод змінює довжину масиву.[^3]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.shift(); // => 1
numbers;
// => ['two', 3, 'four']
```

### unshift

> Метод unshift() додає один або кілька елементів на початок масиву й повертає нову довжину масиву.[^4]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.unshift('one'); // => 5
numbers;
// => ['one', 1, 'two', 3, 'four']
```

### splice

> Метод splice() змінює вміст масиву, вилучаючи або замінюючи наявні елементи та/або додаючи нові елементи на місці. Цей метод повертає масив, що містить вилучені елементи.[^5]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.splice(2, 1, 'one'); // => [3]
numbers;
// => [1, 'two', 'one', 'four']
```
