# Вказівки

У Гіперії є свої проблеми. Зокрема, інфляція вийшла з-під контролю. Нас запросили сюди працювати за контрактом у центральному банку.

## 1. Надрукуйте номінали банкнот

Щоб спростити внутрішнє адміністрування, центральний банк розділив кожен номінал на частини: _базу_, яка залишається відносно незмінною, і _множник_ (однаковий для всіх номіналів), який можна змінювати щороку, щотижня або навіть щодня.

Коли банкноти друкують, номінал на них є добутком _бази_ і _множника_.

На момент запровадження цієї системи мінімальна банкнота вже мала номінал 10 000 000. Таблиця нижче показує становище (для перших 3 номіналів), коли систему тільки-но запровадили. Відтоді все стало набагато гірше, і змінюється не лише множник, а й база.

| База    | Множник | Номінал |
| ------- | ---------- | ------------ |
| 10 000  | 1 000      | 10 000 000   |
| 50 000  | 1 000      | 50 000 000   |
| 100 000 | 1 000      | 100 000 000  |
| ...     | 1 000      | ...          |

Підсумовуючи, це означає, що _номінал_ = _база_ \* _множник_.

Реалізуйте метод `CentralBank.DisplayDenomination()`, який приймає базу і множник та повертає рядок тексту (англ. string) з їхнім добутком (база \* множник). Повернутий числовий рядок тексту не потрібно форматувати.

Якщо множення спричиняє переповнення, потрібно повернути рядок тексту `"*** Too Big ***"`.

```csharp
CentralBank.DisplayDenomination(10000L, 1000L);
// => "10000000"
CentralBank.DisplayDenomination(long.MaxValue / 2, 10000L);
// => "*** Too Big ***"
```

## 2. Покажіть ВВП Гіперії

Центральний банк використовує той самий підхід із множником для внутрішнього обліку ВВП. Статистику записують у базовому номіналі, а потім масштабують за допомогою множника.

Реалізуйте метод `CentralBank.DisplayGDP()`, який приймає базовий ВВП і поточний множник та повертає ВВП як рядок тексту.

Якщо ВВП неможливо обчислити, повертається `"*** Too Big ***"`.

```csharp
CentralBank.DisplayGDP(555f, 10000f);
// => "5550000"
CentralBank.DisplayGDP(float.MaxValue / 2, 10000f);
// => "*** Too Big ***"
```

## 3. Покажіть зарплату головного економіста

Керівник банку хоче переконатися, що під час виплати зарплати не буде проблем.

Реалізуйте метод `CentralBank.DisplayChiefEconomistSalary()`, який приймає зарплату в базових одиницях (як вище) і множник та повертає рядок тексту з їхнім добутком.

Якщо зарплату неможливо обчислити, повертається `"*** Much Too Big ***"`.

```csharp
CentralBank.DisplayChiefEconomistSalary(555000m, 10000m);
// => "5550000000"
CentralBank.DisplayChiefEconomistSalary(555000m, decimal.MaxValue / 2L);
// => "*** Much Too Big ***"
```
