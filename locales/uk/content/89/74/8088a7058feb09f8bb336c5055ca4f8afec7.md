## Термінологія

Ми вже використовували функції C++ і писали їх у кількох концепціях.
Настав час перейти до технічних деталей.
Наведений нижче фрагмент коду показує найуживаніші терміни для довідки.
Оскільки C++ ігнорує пробільні символи, форматування змінено так, щоб кожен елемент був на окремому рядку.

```cpp
// Function declaration:
bool                                              // Return type
admin_detected(string user, string password)      // Type signature
;                                                 // Don't forget the ';' for the declaration

// Function definition:
bool                                              // Return type
admin_detected                                    // Function name
(string user, string password)                    // Parameter list
{ return user == "admin" && password == "1234"; } // Function body
```
~~~~exercism/advanced
Оголошення працює як зауваження для компілятора про те, що існує функція з такою назвою, типом повернення й списком параметрів.
Код не працюватиме, якщо визначення немає.
Оголошення необовʼязкові; вони потрібні, якщо ми використовуємо функцію до її визначення.
Оголошення розвʼязують такі проблеми, як циклічні посилання, і дають змогу відокремити інтерфейс від реалізації.
~~~~

## Кваліфікатор `const`

Іноді нам потрібно переконатися, що значення не можна змінити після їх ініціалізації.
У C++ ключове слово `const` слугує кваліфікатором для констант.

```cpp
const int number_of_dragon_balls{7};
number_of_dragon_balls--; // compilation error
```

~~~~exercism/note
Константи часто записують у _UPPER_SNAKE_CASE_.
Якщо немає іншої домовленості, цей регістр краще залишати для макросів.
~~~~

Якщо ми спробуємо змінити константну змінну після того, як її встановлено, код не скомпілюється.
Це допомагає уникати ненавмисних змін, а також відкриває для компілятора можливості оптимізації.
Людині також легше міркувати про код, коли вона знає, що певні частини залишаться незмінними.

`const` також може бути кваліфікатором параметрів функції.

```cpp
string guess_number(const int& secret, const int& guess) {
    if (secret < guess) return "lower.";
    if (secret > guess) return "higher.";
    return "exact!";
}
```

Коли ми передаємо у функцію `const`-посилання, можемо бути впевнені, що його не змінять.
`const`-посилання часто використовують для обʼєктів, копіювання яких може бути дорогим, наприклад для довших рядків тексту (англ. string).
Третій випадок використання кваліфікатора `const` - це функції-члени, які не змінюють екземпляр класу.

```cpp
class Stubborn {
    public:
    Stubborn(string reply) {
        response = reply;
    }
    string answer(const string& question) const {
        if (question.length() == 0) { return "";}
        return response;
    }
    private:
    string response{};
};
```

Функція-член `answer` класу `Stubborn` використовує посилання `const string&` як параметр.
Це дає змогу уникнути копіювання початкового обʼєкта, переданого у функцію.

## Перевантаження функцій

Кілька функцій можуть мати однакову назву, якщо їхні списки параметрів різні.
Це називають перевантаженням функцій, і до нього зазвичай вдаються, коли ці функції виконують дуже схожі завдання.

Заголовок функції без типу повернення - це __сигнатура типу__ функції.
Зміна сигнатури типу дає нову функцію.

У прикладі з `play_sound` є шість різних перевантажень для різних ситуацій:

```cpp
// different argument types:
void play_sound(char note);         // C, D, E, ..., B
void play_sound(string solfege);    // do, re, mi, ..., ti
void play_sound(int jianpu);        // 1, 2, 3, ..., 7

// different number of arguments:
void play_sound(string solfege, double duration);

// different qualifiers:
void play_sound(vector<string>& solfege);
void play_sound(const vector<string>& solfege);
```

~~~~exercism/advanced
Сигнатуру типу визначають назва функції, кількість параметрів, їхні типи та їхні кваліфікатори (але не їхні назви).
Тип повернення свідомо не входить до сигнатури типу, і ми отримаємо помилки компіляції, якщо дві функції відрізняються лише типом повернення.
Компілятор скаржитиметься, бо незрозуміло, яку з двох слід використати.
~~~~

## Типові аргументи

Деякі функції можуть бути дуже довгими, і в багатьох викликах більшість параметрів отримують ті самі значення.
Повторення в таких викликах можна уникнути за допомогою типових аргументів.

```cpp
void record_new_horse_birth(string name, int weight, string color="brown-ish", string dam="Alruccaba", string sire="Poseidon");

record_new_horse_birth("Urban Sea", 130); // color will be brown, dam "Alruccabam", sire "Poseidon"
record_new_horse_birth("Highclere", 175, "off-white", "Fall Aspen");   // sire will be "Poseidon"
```

Оскільки оголошення функції часто читають раніше за визначення, типові аргументи краще задавати саме там.
Якщо для одного параметра вказано типове значення, то й для всіх параметрів праворуч від нього теж потрібно вказати типове значення.
Іноді складні перевантаження функцій можна переробити на меншу кількість функцій із типовими аргументами, щоб полегшити супровід.
