# Про умовні конструкції

## Оператори порівняння

[Оператори порівняння][operators] схожі на оператори в багатьох інших мовах, щоправда з кількома розширеннями.

Для перевірки на рівність використовують оператори `==` (дорівнює) і `!=` (не дорівнює).

```Kotlin
val txt = "abc"
txt == "abc" // => true
txt != "abc" // => false
```

Крім того, оператори `===` і `!==` перевіряють [«рівність за посиланням»][referential-equality]: `a === b` тоді й лише тоді, коли `a` і `b` указують на той самий обʼєкт.
Це стане зрозумілішим далі в силабусі.

Оператори «більше» та «менше» теж цілком звичні.

```Kotlin
1 < 3 // => true
3 > 3 // => false
3 <= 3 // => true
4 >= 3 // => true
```

## Розгалуження за допомогою `if`

Ось повна форма [виразу `if`][if-else]:

```Kotlin
if (conditional1) {
//    something...
} else if (conditional2) {
//    something...
} else {
//    something...
}
```

- Дужки `()` навколо кожної умови обовʼязкові.
- Кожна умова повинна обчислюватися до булевого значення (англ. Boolean) `true` або `false`.
  У Kotlin немає поняття «істинних» і «хибних» значень, яке трапляється в деяких мовах.
- Фігурні дужки `{}` необовʼязкові, якщо є лише один вираз.
- І `else if`, і `else` необовʼязкові, а блоків `else if` може бути кілька.

Вираз `if` також можна використати, щоб «вибрати» значення:

```Kotlin
val number = 100000
val description = if (number > 100) "number is over 100" else "number is less than 100"
// => description = "number is over 100"
```

## А чи є альтернативи?

Це свідоме рішення: у Kotlin _немає_ тернарного оператора `? :`, який є в Java.
Перевагу віддають стислій формі `if ... else`:

```Kotlin
val result = if (isOk) goodValue else badValue

return if (isOK) goodValue else badValue
```

На відміну від Ruby, стисла форма `if ... else` *завжди* потребує `else`, тож її не можна використати як вартову інструкцію:

```kotlin
return 42 if (isOk)
// Syntax error: Unexpected tokens (use ';' to separate expressions on the same line).
// Syntax error: Expecting an expression.

return if (isOk) true
// 'if' must have both main and 'else' branches when used as an expression.
```

Зауважмо, що в Kotlin `if` це [_вираз_][expression], який повертає значення.
Це не [_інструкція_][statement], як у Java.

Пізніше в одному з концептів ми побачимо, що в Kotlin є потужна конструкція [`when`][when], покликана замінити довгі ланцюжки гілок `else if` зіставленням зі зразком.
