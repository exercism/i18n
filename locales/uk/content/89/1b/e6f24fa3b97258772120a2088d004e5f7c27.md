# Тести

Оскільки OCaml компілюється, перш ніж запустити тести, потрібно скомпілювати своє рішення та код тестів.
Для збірки ми використовуємо [`dune`](https://dune.build/).
У кожній теці є файл dune, який визначає, як збирати, а також Makefile, який делегує роботу dune.

Щоб скомпілювати й запустити тести, просто введіть у теці вправи:

```bash
make
```
