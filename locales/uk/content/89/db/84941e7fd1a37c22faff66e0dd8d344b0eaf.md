# Інструкції

Перегляньте документацію PHP про [оголошення типів][type-declaration].

## 1. Задокументуйте типи для класу Address

- У PHP типи для примітивних значень збігаються з їхніми назвами, дивіться [вступ до типів][type-intro]

## 2. Задокументуйте типи, щоб заповнити форму порожніми значеннями

- У PHP типи для примітивних значень збігаються з їхніми назвами, дивіться [вступ до типів][type-intro]

## 3. Задокументуйте тип, коли розділяємо значення на окремі літери

- У PHP типи для примітивних значень збігаються з їхніми назвами, дивіться [вступ до типів][type-intro]

## 4. Задокументуйте тип, коли перевіряємо, чи значення вміститься у форму

- У PHP типи для примітивних значень збігаються з їхніми назвами, дивіться [вступ до типів][type-intro]

## 5. Задокументуйте тип, коли форматуємо адресу у формі

- У PHP оголошення типів для класів можуть використовувати або `object`, або назву конкретного класу як оголошений тип.
