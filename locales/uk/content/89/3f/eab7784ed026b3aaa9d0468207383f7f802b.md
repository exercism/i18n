# Інструкції

Як майбутня чарівниця, Еліз має потренувати дещо з основ. 
У неї є стос карток, яким вона хоче маніпулювати.

Щоб трохи спростити собі життя, вона використовує лише картки від 1 до 10, тож її стос карток можна подати як вектор чисел. 
Позиція певної картки відповідає індексу у векторі. 

## 1. Дістати картку зі стосу

Щоб узяти картку, поверніть картку за індексом `position` із заданого стосу.

```julia-repl
julia> stack = [1, 2, 4, 1];
julia> position = 3;
julia> get_item(stack, position)
4
```

## 2. Обміняти картку в стосі

Виконайте невеличкий фокус і обміняйте картку за індексом `position` на надану картку для заміни.
Поверніть змінений стос.

```julia-repl
julia> stack = [1, 2, 4, 1];
julia> position = 3;
julia> replacement_card = 6;
julia> set_item!(stack, position, replacement_card)
[1, 2, 6, 1]
```

## 3. Вставити картку на верх стосу

Змусьте картку зʼявитися, вставивши нову картку на верх стосу.
Поверніть змінений стос.

```julia-repl
julia> stack = [5, 9, 7, 1];
julia> new_card = 8;
julia> insert_item_at_top!(stack, new_card)
[5, 9, 7, 1, 8]
```

## 4. Прибрати картку зі стосу

Змусьте картку зникнути, прибравши картку за вказаним індексом `position` зі стосу.
Поверніть змінений стос.

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> position = 3;
julia> remove_item!(stack, position)
[3, 2, 4, 8]
```

## 5. Прибрати верхню картку зі стосу

Змусьте картку зникнути, прибравши картку згори стосу.
Поверніть змінений стос.

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> remove_item_from_top!(stack)
[3, 2, 6, 4]
```

## 6. Вставити картку в низ стосу

Змусьте картку зʼявитися, вставивши нову картку в низ стосу.
Поверніть змінений стос.

```julia-repl
julia> stack = [5, 9, 7, 1];
julia> new_card = 8;
julia> insert_item_at_bottom!(stack, new_card)
[8, 5, 9, 7, 1]
```

## 7. Прибрати картку з низу стосу

Змусьте картку зникнути, прибравши картку з низу стосу.
Поверніть змінений стос.

```julia-repl
julia> stack = [8, 5, 9, 7, 1];
julia> remove_item_at_bottom!(stack)
[5, 9, 7, 1]
```

## 8. Перевірити розмір стосу

Перевірте, чи розмір стосу дорівнює `stack_size`, чи ні.

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> stack_size = 4;
julia> check_size_of_stack(stack, stack_size)
false
```
