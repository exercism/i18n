# Докладніше

*Неперетинна множина* (структура обʼєднання-пошуку) зберігає набір значень, поділений на групи, що не перетинаються, і швидко відповідає на одне питання: чи ці два значення в одній групі? Вона живе у словнику [`disjoint-sets`][disjoint-sets].

`<disjoint-set>` створює порожню структуру. Значення, тобто *атоми*, додають за допомогою `add-atom` або гуртом за допомогою `add-atoms`; кожне з них спочатку утворює окрему групу:

```
<disjoint-set> ( -- disjoint-set )
add-atom       ( atom disjoint-set -- )
add-atoms      ( seq disjoint-set -- )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ "a" "b" "c" "d" } over add-atoms   ! four singleton groups
```

`equate` обʼєднує групи, що містять два атоми. Обʼєднання транзитивне: щойно `a` прирівняно до `b`, а `b` до `c`, усі три належать до однієї групи.

```
equate ( atom1 atom2 disjoint-set -- )
```

Кожну групу позначає один канонічний член, її *представник*. `representative` повертає його, і два атоми належать до однієї групи саме тоді, коли їхні представники рівні. `equiv?` виконує цю перевірку напряму:

```
representative ( atom disjoint-set -- representative )
equiv?         ( atom1 atom2 disjoint-set -- ? )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ "a" "b" "c" "d" } over add-atoms
"a" "b" pick equate
"b" "c" pick equate
"a" "c" pick equiv? .          ! => t   (transitively connected)
"a" "d" pick equiv? .          ! => f
"a" over representative
"c" pick representative = .     ! => t   (same representative)
```

Який саме атом стає представником групи, це подробиця внутрішньої реалізації: ним може бути будь-який член групи, і він може змінитися, коли групи зливаються. Не варто покладатися на те, що представником буде конкретний атом; покладатися можна лише на те, що два атоми з однієї групи мають однакового представника.

`disjoint-set-members` повертає кожен доданий атом.

Структура *змінювана*: `equate` й `add-atom` змінюють неперетинну множину на місці, а не повертають нову. Реалізація використовує обʼєднання за рангом зі стисканням шляхів, тож кожен виклик у довгій низці `equate` і `representative` виконується фактично за сталий час.
