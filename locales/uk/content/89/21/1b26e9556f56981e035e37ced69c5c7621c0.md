# Іменні бейджики

## Історія

У цій вправі ми писатимемо код, щоб друкувати іменні бейджики для працівників заводу. Працівники мають ідентифікатор, імʼя та назву відділу. Етикетки на бейджиках працівників мають такий формат: `"[id] - [name] - [DEPARTMENT]"`.

Через особливість компʼютерної системи нові працівники іноді ще не мають ідентифікатора, коли починають працювати на заводі. Оскільки бейджики обовʼязкові, вони отримають тимчасовий бейджик без префікса з ідентифікатором.

Навіть власник заводу мусить носити бейджик постійно. Однак у власника немає відділу. У цьому разі на етикетці замість назви відділу має бути надруковано `"OWNER"`.

## Завдання

Ось приклади завдань, які пасують до вправи з бейджиками працівників:

- Надрукувати бейджик для працівника
- Надрукувати бейджик для нового працівника
- Надрукувати бейджик для власника
