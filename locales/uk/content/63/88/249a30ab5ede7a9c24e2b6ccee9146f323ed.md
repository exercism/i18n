# Вступ

Починаючи з версії `PHP 8.0.0`, **оголошення обʼєднаних типів** приймають значення кількох різних типів, а не одного. Визначення обʼєднаного типу створюють за допомогою вертикальної риски (`|`), якою розділяють типи.

```php
function add(int|float $a, int|float $b): int|float
{
    return $a + $b;
}
```

У строгому режимі PHP викине помилку `TypeError`, якщо вхідні параметри не є ані `float`, ані `int`. У нестрогому режимі помилку типу буде викинуто, якщо вхідні параметри неможливо привести до `float` або `int`.

Так само, якщо функція не повертає один із оголошених типів, PHP викине помилку `TypeError` під час виконання.
