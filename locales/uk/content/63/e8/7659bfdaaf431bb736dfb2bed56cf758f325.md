# Інструкції

У цій вправі нам потрібно перекласти деякі правила з класичної гри Pac-Man у функції Haskell.

Нам потрібно перекласти чотири правила, усі повʼязані зі станами гри.

> Не варто перейматися тим, як отримуються аргументи; зосередьмося на поєднанні аргументів, щоб повернути потрібний результат.

## 1. Визначте, чи Pac-Man зʼїдає привида

Визначте функцію `eatsGhost`, яка приймає два аргументи (_чи активна в Pac-Man енергетична пігулка_ та _чи торкається Pac-Man привида_) і повертає значення `Bool`, коли Pac-Man може зʼїсти привида.
Функція повинна повертати `True` лише тоді, коли в Pac-Man активна енергетична пігулка і він торкається привида.

```haskell
eatsGhost False True
-- -> False
```

## 2. Визначте, чи Pac-Man набирає очок

Визначте функцію `scores`, яка приймає два аргументи (_чи торкається Pac-Man енергетичної пігулки_ та _чи торкається Pac-Man крапки_) і повертає значення `Bool`, якщо Pac-Man набрав очок.
Функція повинна повертати `True`, коли Pac-Man торкається енергетичної пігулки або крапки.

```haskell
scores True True
-- -> True
```

## 3. Визначте, чи Pac-Man програє

Визначте функцію `loses`, яка приймає два аргументи (_чи активна в Pac-Man енергетична пігулка_ та _чи торкається Pac-Man привида_) і повертає значення `Bool`, якщо Pac-Man програє.
Функція повинна повертати `True`, коли Pac-Man торкається привида і не має активної енергетичної пігулки.

```haskell
loses False True
-- -> True
```

## 4. Визначте, чи Pac-Man виграє

Визначте функцію `wins`, яка приймає три аргументи (_чи зʼїв Pac-Man усі крапки_, _чи активна в Pac-Man енергетична пігулка_ та _чи торкається Pac-Man привида_) і повертає значення `Bool`, якщо Pac-Man виграє.
Функція повинна повертати `True`, коли Pac-Man зʼїв усі крапки _і_ не програв за аргументами, визначеними в частині 3.

```haskell
wins False True False
-- -> False
```
