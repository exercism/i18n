# Основи синтаксису Elm 2

## Експорт функцій

Експорт функцій ми вже розглядали в першій концепції, тож ось коротке нагадування.

Кожен файл в Elm є модулем і мусить містити інструкцію `module` перед усім іншим кодом.

Назви модулів мають збігатися з назвами файлів, тож модуль `Calculator` має бути у файлі Calculator.elm, а модуль `Parser.Utils` - у файлі Parser/Utils.elm.

Усе, визначене в модулі, має приватну область видимості й недоступне ззовні цього модуля, якщо його не перелічено в `exposing`.

```elm
-- Calculator.elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Calculator.elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## Імпорт функцій з інших модулів

Доступ до функцій, визначених в інших модулях, отримуємо через імпорт.
Коли ми імпортуємо модуль, усі функції цього модуля, які він експортує, стають доступними.
Але те, як ми до них звертаємося, залежить від того, як ми імпортували модуль.

Типово ми використовуємо кваліфікований імпорт, і щоб звернутися до функції з такого модуля (наприклад, до функції `map` у модулі `List`), перед нею дописують назву модуля (`List.map`).

Відкритий імпорт дає прямий доступ до експортованих функцій цього модуля, без префікса. Для цього використовують ключове слово `exposing`, дзеркальне до того, яке ми застосовуємо в експорті. Можна експортувати всі доступні функції (за допомогою `..`) або лише конкретні (наприклад, `map`).

Також можна імпортувати з інших модулів типи та їхні конструктори, але це буде в пізнішій концепції.

Перевагу віддають кваліфікованому імпорту, щоб було зрозуміліше й не виникало конфліктів імен.

```elm
-- qualified imports
import List                            -- List.map, List.foldl
import List as L                       -- L.map, L.foldl

-- open imports
import List exposing (..)              -- map, foldl, concat, ...
import List exposing ( map, foldl )    -- map, foldl, List.concat
```

https://elm-lang.org/docs/syntax#modules

## Анотації типів

Анотацію типу записують у вигляді `name : parameter types -> return type`, де типи параметрів також розділяють знаком `->`.

```elm
add : Int -> Int -> Int
add number1 number2 = number1 + number2
```

Дужки можна використати, щоб описати параметри функції (які й самі описують тим самим синтаксисом, звідси й потреба в дужках).

```elm
-- Transform every character in a string
map : (Char -> Char) -> String -> String
map charMapperFunction string =
    -- ...
```

https://elm-lang.org/docs/syntax#type-annotations

## Числа

В Elm є два різновиди чисел, визначені типами `Int` і `Float`.
`Int` відповідає множині додатних і відʼємних цілих чисел.
`Float` відповідає множині дійсних чисел, обмеженій точністю компʼютера.
Операції, визначені для чисел, зазвичай працюють з одним або з іншим типом, але не змішують їх.
Існують функції для перетворення між ними: наприклад, `toFloat` перетворює `Int` на `Float`, а `round`, `floor`, `ceiling` чи `truncate` перетворюють `Float` на `Int` з різною семантикою.

https://package.elm-lang.org/packages/elm/core/latest/Basics#Int

## Операції з рядками тексту

Щоб описувати в коді слова й речення, Elm має вбудований тип `String`.
Літерали рядків тексту (англ. string) записують у подвійних лапках, наприклад `"Hello World!"`.
Для рядків тексту одразу доступні оператор конкатенації `++` та оператор рівності `==`.

```elm
hello : String -> String
hello subject = "Hello " ++ subject

hello "World!" --> "Hello World!"
```

Більшість інших функцій для рядків тексту містяться в модулі `String`, який потрібно імпортувати.

https://package.elm-lang.org/packages/elm/core/latest/String
