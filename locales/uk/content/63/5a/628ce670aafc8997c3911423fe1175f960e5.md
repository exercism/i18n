# Інструкції

Дівчина Лусіана вже повертається додому, а він ще не приготував вечерю на річницю!

У цій вправі ми напишемо трохи коду, який допоможе Лусіану приготувати вишукану лазанью за його улюбленою кулінарною книгою.

На нас чекають чотири завдання, і всі вони повʼязані з часом, витраченим на приготування лазаньї.

## 1. Визначте очікуваний час запікання в хвилинах

Визначте метод `Lasagna.ExpectedMinutesInOven()`, який не приймає жодних параметрів і повертає, скільки хвилин лазанья має провести в печі. Згідно з кулінарною книгою, очікуваний час запікання в хвилинах становить 40:

```csharp
var lasagna = new Lasagna();
lasagna.ExpectedMinutesInOven();
// => 40
```

## 2. Обчисліть залишок часу запікання в хвилинах

Визначте метод `Lasagna.RemainingMinutesInOven()`, який приймає як параметр фактичну кількість хвилин, які лазанья вже провела в печі, і повертає, скільки хвилин лазаньї ще залишилося провести в печі, виходячи з очікуваного часу запікання в хвилинах із попереднього завдання.

```csharp
var lasagna = new Lasagna();
lasagna.RemainingMinutesInOven(30);
// => 10
```

## 3. Обчисліть час підготовки в хвилинах

Визначте метод `Lasagna.PreparationTimeInMinutes()`, який приймає як параметр кількість шарів, доданих до лазаньї, і повертає, скільки хвилин пішло на підготовку лазаньї, якщо припустити, що на кожен шар витрачається 2 хвилини.

```csharp
var lasagna = new Lasagna();
lasagna.PreparationTimeInMinutes(2);
// => 4
```

## 4. Обчисліть витрачений час у хвилинах

Визначте метод `Lasagna.ElapsedTimeInMinutes()`, який приймає два параметри: перший параметр - кількість шарів, доданих до лазаньї, а другий параметр - кількість хвилин, які лазанья провела в печі. Функція має повернути, скільки хвилин пішло на приготування лазаньї, тобто суму часу підготовки в хвилинах і часу в хвилинах, який лазанья на цей момент провела в печі.

```csharp
var lasagna = new Lasagna();
lasagna.ElapsedTimeInMinutes(3, 20);
// => 26
```
