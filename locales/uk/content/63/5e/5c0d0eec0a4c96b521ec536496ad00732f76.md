# Інструкції

Ми ведемо польовий довідник: зіставлення назви тварини із середовищем існування, у якому вона живе.

Усі пʼять завдань розмістіть у класі `FIELD_GUIDE`.

## 1. Чи є тварина в довіднику?

```sather
FIELD_GUIDE::is_listed(guide, "emu")
-- => true
```

## 2. Де вона живе?

Поверніть середовище, записане для тварини. Якщо довідник про неї нічого не знає, поверніть `"Unknown"`.

```sather
FIELD_GUIDE::habitat_of(guide, "emu")
-- => "grassland"
FIELD_GUIDE::habitat_of(guide, "moa")
-- => "Unknown"
```

## 3. Додайте запис

Поверніть довідник із ще однією твариною. Якщо тварину вже записано, її середовище замінюється.

```sather
FIELD_GUIDE::add_entry(guide, "wombat", "forest")
-- => the guide, now with wombat in it
```

Те, що повертає ця функція, стає довідником, яким ми користуємося далі. Додавання до цілком порожнього довідника теж працює й дає довідник з однією твариною в ньому.

## 4. Скільки тварин?

```sather
FIELD_GUIDE::entry_count(guide)
-- => 3
```

## 5. Які середовища?

Поверніть множину середовищ, згаданих у довіднику. Кілька тварин можуть жити в одному середовищі, але в множині воно має бути лише раз.

```sather
FIELD_GUIDE::all_habitats(guide)
-- => a set holding "grassland" and "forest"
```
