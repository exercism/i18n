# Інструкції

У цій вправі ми допомагаємо криптографу керувати захищеною системою звʼязку та перевіряти її.
Система значною мірою покладається на елементи поля, зокрема на тип `felt252` у Cairo, щоб усі арифметичні операції залишалися в межах визначеного діапазону.

## 1. Обчислити суму двох повідомлень

Два зашифровані повідомлення, кожне з яких представлено як `felt252`, потрібно додати одне до одного, щоб отримати обʼєднане повідомлення.
Однак через шифрування будь-який результат, що перевищує максимальне значення $P - 1$, потрібно загорнути за допомогою остачі від ділення на $P$.

Реалізуйте функцію, яка приймає два значення `felt252` і повертає їхню суму, гарантуючи, що результат залишається в допустимому діапазоні:

```rust
add_messages(3618502788666131213697322783095070105623107215331596699973092056135007822949, 987654321)
// => 123456789
```

> **Примітка:** Повернене значення має бути `felt252`.

## 2. Обчислити різницю між двома повідомленнями

Іноді повідомлення потрібно відняти, щоб відновити початкові дані.
Якщо результат віднімання відʼємний, система автоматично коригує його, додаючи $P$, щоб повернути в діапазон допустимого значення `felt252`.

Реалізуйте функцію, яка приймає два значення `felt252` і повертає їхню різницю, гарантуючи, що результат залишається в допустимому діапазоні:

```rust
subtract_messages(123456789, 987654321)
// => 3618502788666131213697322783095070105623107215331596699973092056135007822949
```

> **Примітка:** Повернене значення має бути `felt252`.

## 3. Обчислити допустимий добуток двох повідомлень

Щоб забезпечити цілісність зашифрованих даних, криптографічна система часто перемножує два повідомлення (`felt252`), щоб їхній добуток залишався в допустимому діапазоні.
Результат потрібно обчислити за остачею від ділення на $P$, щоб він залишався в допустимому діапазоні.

Реалізуйте функцію, яка приймає два значення `felt252` і повертає їхній добуток, гарантуючи, що результат залишається в допустимому діапазоні:

```rust
multiply_messages(382927772233671078546147897004315551461400594453673204174697055647611, 9449570)
// => 123456789
```

> **Примітка:** Повернене значення має бути `felt252`.
