# Підказки

## Загальне

- Словник `locals` надає `::` і `[| | ]`.
- Локальні змінні не замінюють код зі стеком: використовуйте їх там, де вони додають
  ясності.

## 1. Визначте стан приготування

- `cond` із [`combinators`][combinators] має саме ту форму, яка потрібна: одна
  гілка перевіряє `dup not` (таймер дорівнює `f`), інша перевіряє
  `dup zero?`, а типова гілка обробляє решту. Кожна гілка має виконати `drop`
  для таймера, перш ніж покласти рядок тексту (англ. string).

## 2. Оцініть час підготовки

- `:: preparation-time ( layers minutes-per-layer -- total )`
  разом із `layers length minutes-per-layer *`.

## 3. Обчисліть потрібну кількість локшини й соусу

- Локальні змінні дають змогу звертатися до `layers` двічі без `dup`. `count`
  із предикатом `[ "noodles" = ]` (або `"sauce" =`) дає кількість для
  кожного шару.
- `1/5` позначає раціональний літерал у Factor.

## 4. Додайте секретний інгредієнт

- `last` (з [`sequences`][sequences]) читає останній елемент;
  `suffix` додає один елемент у кінець.

## 5. Масштабуйте рецепт

- Коефіцієнт масштабування дорівнює `portions / 2`. Локальні змінні дають
  змогу звернутися до `portions` усередині лямбди.
- `assoc-map` із [`assocs`][assocs] приймає квотейшн `( key value -- newkey newvalue )`.
  Усередині `[| key value | … ]` поверніть обидва значення, щоб зберегти
  той самий ключ і отримати нове значення.

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
