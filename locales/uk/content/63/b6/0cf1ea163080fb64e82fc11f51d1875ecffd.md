# Вступ

Тип `Result` дає функції змогу повернути єдине значення, яке вказує на все перелічене нижче:
- Чи завершилася операція успішно чи зазнала невдачі
- Отримане значення операції в разі успіху
- Причину невдачі в разі помилки

## Використання

Тип `Result` - узагальнений тип, який містить два внутрішні типи:
- Тип отриманого значення в разі успішної операції
- Тип помилки в разі невдачі

Тип `Result` - також [дискриміноване обʼєднання][discriminated-union] із такими можливими випадками:
* `Ok <value>` позначає успішний результат
* `Error <reason>` позначає невдачу

Наступна функція демонструє, як створити значення типу `Result`:

```fsharp
let validateName (name: string) : Result<string, string> = 
    match name with
    | null -> Error "Name not found."
    | "" -> Error "Name is empty."
    | _ -> Ok name
```

У цьому прикладі значення `Ok` - це рядок тексту (англ. string), а саме передане імʼя, а значення `Error` теж є рядком тексту (причина помилки, у зрозумілій людині формі).

## Читання вмісту значення `Result`

Розгляньмо таке визначення типу та сигнатуру функції:

```
type FileOpenError = 
| NotFound
| AccessDenied
| FileLocked

let openFile (filename: string) : Result<int, FileOpenError> =
```

Код, який викликає функцію `openFile`, може використати зіставлення зі зразком, щоб опрацювати випадки успіху й невдачі, як у наступному прикладі:

```fsharp
match openFile(filename) with
| Ok handle -> doSomethingWithFile(handle)
| Error NotFound -> printfn $"Error: file {filename} was not found."
| Error AccessDenied -> printfn $"Error: you do not have permission to open the file {filename}."
| Error FileLocked -> printfn $"Error: file {filename} is already in use."
```
