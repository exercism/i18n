# Інструкції

Трамваї Мельбурна беруть плату за зонами, а центр міста безкоштовний. Ми пишемо правила оплати для квиткового автомата. Усі тарифи в центах.

Усі чотири завдання виконуємо в класі `TRAM_FARES`.

## 1. Вартість проїзду в зоні

Зона 0 - це Безкоштовна трамвайна зона, і проїзд у ній нічого не коштує. Зона 1 - 550. Зона 2 - 370. Будь-яке інше число взагалі не є трамвайною зоною, і проїзд у ній нічого не коштує.

```sather
TRAM_FARES::zone_fare(1)
-- => 550
TRAM_FARES::zone_fare(7)
-- => 0
```

## 2. Який це квиток?

Квитки мають літеру. `'f'` - повний тариф. І `'c'`, і `'s'` - пільгові квитки: один для дітей, один для студентів. `'x'` - безкоштовний проїзний. Будь-що інше - невідоме.

```sather
TRAM_FARES::ticket_kind('s')
-- => "Concession"
TRAM_FARES::ticket_kind('q')
-- => "Unknown"
```

Чотири відповіді - це `"Full fare"`, `"Concession"`, `"Free pass"` і `"Unknown"`.

## 3. Який це день?

`"Sat"` і `"Sun"` - вихідні. Від `"Mon"` до `"Fri"` - будній день. Будь-що інше - невідоме.

```sather
TRAM_FARES::day_type("Sun")
-- => "Weekend"
```

Три відповіді - це `"Weekend"`, `"Weekday"` і `"Unknown"`.

## 4. Денна межа

Хоч би скільки разів ми їхали трамваєм, ми ніколи не платимо більше за межу для цього дня: 1100 у будній день і 700 на вихідних. У дня, який ніхто не розпізнає, межі немає, тобто вона дорівнює нулю.

```sather
TRAM_FARES::daily_cap("Sat")
-- => 700
```
