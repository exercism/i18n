# Булеві значення

Деякі запитання мають лише дві відповіді: так або ні. У Sather для такої відповіді є тип `BOOL`, а сама відповідь записується як `true` або `false`.

```sather
   ready : BOOL is
      return true;
   end;
```

## Порівняння

Порівняння двох чисел дає `BOOL`.

| Оператор | Що запитує |
| --- | --- |
| `=` | чи вони однакові? |
| `/=` | чи вони різні? |
| `<` | чи ліве менше? |
| `<=` | менше чи однакове? |
| `>` | чи ліве більше? |
| `>=` | більше чи однакове? |

```sather
   old_enough(age : INT) : BOOL is
      return age >= 13;
   end;
```

Зауважмо, що `=` ставить запитання. А щоб покласти значення *в* щось, використовують `:=`, який ми вже бачили, і це не те саме.

## Поєднання

Три оператори складають більші запитання з менших.

`and` дає правду, коли **обидві** сторони правдиві.

```sather
harness_on and rope_checked
```

`or` дає правду, коли правдива **хоч одна** сторона, або обидві.

```sather
mat_below or net_below
```

`~` перевертає відповідь: він перетворює правду на неправду, а неправду на правду.

```sather
~ready       -- true exactly when ready is false
```

`and` і `or` ставлять між двома відповідями, а `~` - перед однією.
