# Learning

Haskell - це чисто функціональна мова, чия парадигма принципово відрізняється від поширенішого [обʼєктно-орієнтованого підходу](https://en.wikipedia.org/wiki/Object-oriented_programming). Через це вивчення Haskell може відчуватися інакше, ніж просто опанування ще однієї мови.

На щастя, є чимало ресурсів, які передбачають певні початкові знання з програмування, наприклад:

  - Упереджений посібник для початківців з Haskell ([2019](https://github.com/theindigamer/not-a-blog/blob/master/opinionated-haskell-guide-2019.md), [2018](https://lexi-lambda.github.io/blog/2018/02/10/an-opinionated-guide-to-haskell-in-2018/))
  - популярна безплатна онлайн-книга [Learn You a Haskell For Great Good!](https://learnyouahaskell.github.io/)
  - курс [Functional Programming in Haskell](https://www.futurelearn.com/courses/functional-programming-haskell) від Університету Глазго
  - [School of Haskell](https://www.schoolofhaskell.com/) від FP Complete
  - [Happy Learn Haskell Tutorial](http://www.happylearnhaskelltutorial.com/)
  - туторіали [Haskell for Mac](http://learn.hfm.io/)

Серед недавніх книг про Haskell:

  - [Haskell Programming From First Principles](https://haskellbook.com) від Крістофера Аллена і Джулі Моронукі (ця книга не передбачає попередніх знань з програмування)
  - [Programming in Haskell](https://www.cambridge.org/us/academic/subjects/computer-science/programming-languages-and-applied-logic/programming-haskell-2nd-edition?format=PB&isbn=9781316626221) від Грема Гаттона

Також ми можемо звернутися до [Haskell wiki](https://wiki.haskell.org/Learning_Haskell#Online_tutorials), щоб знайти безліч інших ресурсів для початку.
