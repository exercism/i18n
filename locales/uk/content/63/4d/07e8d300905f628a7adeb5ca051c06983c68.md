# Вказівки

Щойно наш друг надіслав нам повідомлення з важливою таємницею. Не бажаючи, щоб інші легко його прочитали, друг зашифрував повідомлення, виконавши низку операцій з бітами. Нам потрібно буде написати слова, які допоможуть розшифрувати повідомлення.

## 1. Зсуваємо біти назад

Перший крок до розшифрування повідомлення - скасувати зсув із процесу шифрування, зсунувши біти назад праворуч. Подальші кроки припускають, що нулі вставляються зліва.

Визначте `shift-back`, яка приймає 32-бітове значення та кількість, і повертає значення, зсунуте праворуч на цю кількість із заповненням нулями.

```factor
0b1001 2 shift-back .
! => 0b0010
```

## 2. Встановлюємо деякі біти

Далі деякі біти потрібно встановити в 1.

Визначте `set-bits`, яка приймає значення та маску. Кожен біт `value`, для якого відповідний біт `mask` дорівнює 1, треба встановити в 1; усі інші біти залишаються без змін.

```factor
0b0110 0b0101 set-bits .
! => 0b0111
```

## 3. Перевертаємо окремі біти

Під час шифрування деякі біти перевертають. Щоб розшифрувати повідомлення, їх потрібно перевернути назад.

Визначте `flip-bits`, яка приймає значення та маску. Кожен біт `value`, для якого відповідний біт `mask` дорівнює 1, треба перевернути; усі інші біти залишаються без змін.

```factor
0b1100 0b0101 flip-bits .
! => 0b1001
```

## 4. Скидаємо окремі біти

Нарешті, є також певні біти, які завжди розшифровуються в 0.

Визначте `clear-bits`, яка приймає значення та маску. Кожен біт `value`, для якого відповідний біт `mask` дорівнює 1, треба скинути до 0; усі інші біти залишаються без змін.

```factor
0b0110 0b0101 clear-bits .
! => 0b0010
```
