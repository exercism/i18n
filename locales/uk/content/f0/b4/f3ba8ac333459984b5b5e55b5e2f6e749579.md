# Докладніше

Якщо типи параметрів можна вивести, Swift також дозволяє пропустити назви параметрів і ключове слово `in` у визначенні замикання. Замість цього до параметрів можна звертатися за допомогою [спеціального скороченого синтаксису][shorthand-argument-names], де `$0` указує на перший параметр, `$1` - на другий, і так далі.

```swift
let mean: (Double, Double) -> Double = { $0 + $1 / 2.0 }

["apple", "ball", "carrot"].sorted(by: { $0.count < $1.count })
```

Цей стиль найчастіше використовують, коли передають замикання у функції вищого порядку і коли цінується стислість.

[shorthand-argument-names]: https://docs.swift.org/swift-book/LanguageGuide/Closures.html#ID100
