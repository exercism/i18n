# Debug

```pyret
fun print-forty-two():
  print(42) # 42
end
```

```pyret
fun return-forty-two() block:
  print(42) # 42
  42
end
```

[print][print] є виразом, що повертає значення.
Pyret дозволяє лише один вираз у межах заданого блоку коду, якщо зовнішній блок не позначено `block`.
У другому прикладі додавання `block` до оголошення функції дозволяє вивести 42 перед тим, як його повернути.

## Spies

```pyret
fun do-something():
    x = "foo"
    y = "bar"
    spy "strings": x, y end
    a = 1
    b = 2
    spy "numbers": a, b end
end
do-something();

# Spying "strings" (at <clipped>/example.arr:4:4-4:27)
#  x: "foo"
#  y: "bar"
# Spying "numbers" (at <clipped>/example.arr:7:4-7:27)
#  a: 1
#  b: 2
```

Інструкція spy приймає необовʼязкову позначку, одну або більше змінних і виводить кожну змінну та її значення.
Оскільки це не вираз, spy можна використати в блоці, не позначаючи зовнішній блок як `block`.

[print]: https://pyret.org/docs/latest/_global_.html#%28idx._%28gentag._57%29%29
[spy]: https://pyret.org/docs/latest/s_spies.html
