# Докладніше

## Числа та числові оператори

Усі **числа**, цілі чи ні, - це числа з плаваючою комою подвійної точності IEEE754.
Реалізація `jq` використовує тип `double` мови C.
Це обмежує точність 53 бітами.

З числами можна використовувати звичайні оператори:

- арифметичні: `+`, `-`, `*`, `/`, `%`
- порівняння: `==`, `!=`, `<`, `<=`, `>=`, `>`
- стандартні [математичні функції][man-math]

  Для функцій з одним входом передаємо значення у функцію через конвеєр

  ```sh
  $ jq -n '(1 | atan) * 4'
  3.141592653589793
  ```

  Для функцій із двома входами функція ігнорує вхідні дані, а потрібні значення приймає як параметри

  ```sh
  $ jq -n 'pow(2; 10)'
  1024
  ```

  Роздільником аргументів функції є крапка з комою, а не кома.

<!-- prettier-ignore -->
~~~~exercism/caution
Що означає вислів «це обмежує точність 53 бітами»?

Демонстрація:

```sh
$ jq -n 'pow(2;52) as $n | [$n, $n+1]'
[
  4503599627370496,
  4503599627370497
]
```

Здається, все гаразд. А що, якщо збільшити показник степеня?

```sh
$ jq -n 'pow(2;53) as $n | [$n, $n+1]'
[
  9007199254740992,
  9007199254740992
]
```

Ці числа не повинні бути рівними. 
Саме так має вигляд «втрата точності».
Це означає, що `jq` не здатен працювати з довільно великими числами.
~~~~

## Умовні вирази

`jq` використовує [вираз `if-then-else`][if-then-else] для **умовних виразів**.
Як _вираз_, його розміщують у конвеєрі.

Синтаксис такий: `if CONDTITION then TRUE_EXPR else FALSE_EXPR end`.

Гілка `else` необовʼязкова.

```jq
42 | if . < 33 then "small" else "larger" end
# => "larger"
```

Для додаткових умов використовують `elif`

```jq
42 | if . < 33 then "small"
     elif . < 67 then "medium"
     else "large"
     end
# => "medium"
```
