# Вступ

У Factor ми визначаємо нове слово за допомогою `: name ( stack-effect ) body ;`.
Тіло складається з послідовності слів; виклик нового слова виконує їх по
порядку.

```factor
USING: kernel ;
IN: my-vocab

: shout ( str -- str ) "!" append ;
```

Коли підпрограма розростається, її можна, і навіть варто, *факторизувати*: виокремити
групи слів у менші іменовані слова, кожне з яких виконує одну роботу. Саме
на честь цього й названо мову.

## Словники

Кожен файл `.factor` оголошує словник за допомогою `IN:`. Слова з одного
словника можуть викликати слова з іншого, якщо перелічити інший словник у
`USING:`.

```factor
! file: my-vocab/helpers/helpers.factor
USING: kernel ;
IN: my-vocab.helpers

: shout-line ( str -- str ) "!" append ;
```

```factor
! file: my-vocab/my-vocab.factor
USING: kernel my-vocab.helpers sequences ;
IN: my-vocab

: announce ( names -- strs )
    [ shout-line ] map ;
```

Структура каталогів відповідає назві словника з крапками: словник `my-vocab`
міститься у `my-vocab/my-vocab.factor`; словник `my-vocab.helpers` міститься
у `my-vocab/helpers/helpers.factor`. Завантажувач Factor проходить
оголошення `USING:` транзитивно, завантажуючи кожен словник за потреби.
