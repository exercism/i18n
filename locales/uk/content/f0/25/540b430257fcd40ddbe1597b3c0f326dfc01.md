# Про це

[`List`][lists] в Elm - це незмінна колекція з нуля або більше значень одного типу.
Оскільки списки незмінні, то після створення списку його значення вже ніколи не зміниться.
Списки в Elm мають _голову_ (перший елемент) і _хвіст_ (усе після першого елемента).
Хвіст списку теж є списком.

Анотації типів для списків можна визначити так

```elm
List String --> a list of String
List Int --> a list of Int
```

Списки можна визначити так:

```elm
empty : List Char
empty = []

singleValue = [ 5 ] --> List Int
singleValueAlternative = List.singleton 5 --> List Int

threeValues = [ "a", "b", "c" ] --> List String
```

Найпоширеніший спосіб додати елемент до списку - скористатися оператором `::` (cons):

```elm
twoToFour = [ 2, 3, 4 ]
oneToFour = 1 :: twoToFour --> [1; 2; 3; 4]
```

Списки можна зʼєднувати за допомогою оператора `++` або `List.append`:

```elm
[ 6, 7 ] ++ [ 8, 9 ]           --> [6, 7, 8, 9]
List.append [ 6, 7 ] [ 8, 9 ]  --> [6, 7, 8, 9]
```

Зі списками працюють функції та оператори, визначені в [модулі `List`][list-module].

```elm
List.length [ 7, 8 ] --> 2
```

Будь-яка функція чи оператор, які нібито змінюють список (наприклад, додають елемент), насправді повертають новий список.
Утім, продуктивність зазвичай не страждає, адже реалізація списків уникає зайвих виділень памʼяті та копіювань.

Списки також можна обробляти за допомогою [зіставлення зі зразком][list-destructuring].

```elm
describe : List String -> String
describe list =
    case list of
        [] ->
            "Empty list"

        [ "hello" ] ->
            "Singleton list with: hello"

        x :: xs ->
            "Non-empty list with head: " ++ x

describe []                   --> "Empty list"
describe [ "hello" ]          --> "Singleton list with: hello"
describe [ "hello", "world" ] --> "Non-empty list with head: hello"
```
