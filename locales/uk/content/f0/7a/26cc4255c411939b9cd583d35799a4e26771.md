# Повернення

У Crystal останній вираз у методі повертає своє значення.
Однак іноді потрібно повернути значення раніше за останній вираз.
Для цього можна використати ключове слово `return`, яке поверне значення наступного виразу.
Код, написаний після ключового слова `return`, не виконується.

```crystal
def speed_limit(road_number)
    if road_number == 1
        return 50
        puts "This will not be executed"
    elsif road_number == 2
        return 80
        puts "This will not be executed"
    end
    100
end

p speed_limit(1) # => 50
p speed_limit(2) # => 80
p speed_limit(3) # => 100
```

~~~~exercism/note
Ключове слово `return` варто пропускати, якщо останній вираз у методі вже повертає потрібне значення.
~~~~
