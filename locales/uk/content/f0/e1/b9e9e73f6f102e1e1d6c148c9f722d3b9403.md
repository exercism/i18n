# Інструкції

Готуючись спекти печиво для друзів, ми виявили, що частину мірок із рецепта доведеться перетворювати.
Оскільки ми знайомі лише з метричною системою, нам потрібен спосіб перетворювати поширені американські кулінарні мірки в мілілітри (мл) для власної зручності.

Для рішення використайте цю таблицю перетворення:

| Одиниця для перетворення | обʼєм | у мілілітрах (мл) |
| --------------- | ------ | ------------------- |
| мл              | 1      | 1                   |
| американська чашка          | 1      | 240                 |
| американська рідка унція  | 1      | 30                  |
| американська чайна ложка     | 1      | 5                   |
| американська столова ложка   | 1      | 15                  |

Будучи талановитим програмістом-початківцем, ми вирішуємо використати мілілітри як проміжну одиницю, щоб спростити перетворення з будь-якої наведеної одиниці в будь-яку іншу (навіть у неї саму).

## 1. Отримайте числовий компонент із пари обʼєму

Реалізуйте функцію `getVolume`. Отримавши кортеж пари обʼєму, вона повинна повернути лише числовий компонент.

```haskell
getVolume (Cup, 2.0)
-- -> 2.0
```

## 2. Перетворіть пару обʼєму в мілілітри

Реалізуйте функцію `toMilliliter`. Отримавши кортеж пари обʼєму, вона повинна перетворити обʼєм у мілілітри за допомогою таблиці перетворення.

Використайте кілька визначень функції та зіставлення зі зразком, щоб створити функції для кожної одиниці. Атоми, якими позначають кожну одиницю: `Cup`, `FluidOunce`, `Teaspoon`, `Tablespoon`, `Milliliter`.
Поверніть результат перетворення, загорнутий у кортеж.

```haskell
toMilliliter (Cup, 2.5)
-- -> (Milliliter, 600.0)
```

## 3. Перетворіть пару обʼєму в мілілітрах в іншу одиницю

Реалізуйте функцію `fromMilliliter`. Отримавши кортеж пари обʼєму та бажану одиницю, вона повинна перетворити обʼєм у бажану одиницю за допомогою таблиці перетворення.

Використайте кілька визначень функції та зіставлення зі зразком, щоб створити функції для кожної одиниці. Атоми, якими позначають кожну одиницю: `Cup`, `FluidOunce`, `Teaspoon`, `Tablespoon`, `Milliliter`.

```haskell
fromMilliliter (Milliliter, 1320.0) Cup
-- -> (Cup, 5.5)
```

## 4. Перетворіть з будь-якої одиниці в будь-яку

Реалізуйте функцію `convert`. Отримавши кортеж пари обʼєму та бажану одиницю, вона повинна перетворити заданий обʼєм у бажану одиницю.

```haskell
convert (Teaspoon, 9.0) Tablespoon
-- -> (Tablespoon, 3.0)
```
