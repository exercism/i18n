# Запуск тестів

Перейдіть у терміналі до базового каталогу вправи, а потім виконайте тести командою:

```bash
$ mix test
```

Це запустить файл тестів із підкаталогу `test`, тобто файл, назва якого закінчується на `_test.exs`

Документація:

* [`mix test` - інструмент запуску тестів в Elixir](https://hexdocs.pm/mix/Mix.Tasks.Test.html)
* [`ExUnit` - бібліотека модульного тестування в Elixir](https://hexdocs.pm/ex_unit/ExUnit.html)

## Відкладені тести

У наборах тестів практичних вправ усі тести, крім першого, позначені як пропущені.

Коли якийсь тест починає проходити, можна увімкнути наступний, закоментувавши відповідний `@tag :pending` символом `#`.

Наприклад:

```elixir
# @tag :pending
test "shouting" do
  assert Bob.hey("WATCH OUT!") == "Whoa, chill out!"
end
```

Якщо треба запустити всі тести одразу, можна додати всі пропущені тести за допомогою прапорця `--include` у команді `mix test`:

```bash
$ mix test --include pending
```

Або ж можна увімкнути всі тести, закоментувавши рядок `ExUnit.configure` у файлі `test/test_helper.exs`.

```elixir
# ExUnit.configure(exclude: :pending, trace: true)
```

## Корисні опції `mix test`

* `test/<FILE>.exs:LINENUM` - запускає лише один тест із файлу `<FILE>.exs`, визначення якого міститься на рядку `LINENUM`
* `--failed` - запускає лише ті тести, які не пройшли під час останнього запуску
* `--max-failures` - набір тестів припиняє виконувати тести, коли кількість невдач досягає цього числа
* `--seed 0` - вимикає рандомізацію, тож тести в одному файлі завжди будуть виконуватися в тому самому порядку, у якому їх було визначено
