# Інструкції

Ми пишемо вбудовану систему для машини, що видає номери. Це дуже проста модель. Вона може видавати послідовні номери й повідомляти, який номер було видано останнім.

## 1. Запустіть машину

Реалізуйте функцію `start/0`. Вона повинна створити новий процес і повернути PID цього процесу. Новий процес поки що не повинен нічого робити.

```elixir
TakeANumber.start()
# => #PID<0.138.0>
```

Зауважте, що щоразу, коли ми запускаємо цей код, PID може бути іншим.

## 2. Повідомте стан машини

Змініть машину так, щоб новостворений процес був готовий отримувати повідомлення (запустивши _цикл отримання_) з початковим станом `0`. Він повинен уміти отримувати повідомлення `{:report_state, sender_pid}`. У відповідь на ці повідомлення він повинен надіслати свій поточний стан (номер останнього виданого талона) до `sender_pid`, а потім чекати на нові повідомлення.

```elixir
machine_pid = TakeANumber.start()

# a client sending a message to the machine
send(machine_pid, {:report_state, self()})

# a client receiving a message from the machine
receive do
  msg -> msg
end

# => 0
```

## 3. Видавайте номери

Змініть машину так, щоб вона могла отримувати повідомлення `{:take_a_number, sender_pid}`. Вона повинна збільшити свій стан на 1, надіслати новий стан до `sender_pid`, а потім чекати на нові повідомлення.

```elixir
machine_pid = TakeANumber.start()

# a client sending a message to the machine
send(machine_pid, {:take_a_number, self()})

# a client receiving a message from the machine
receive do
  msg -> msg
end

# => 1
```

## 4. Зупиніть машину

Змініть машину так, щоб вона могла отримувати повідомлення `:stop`. Вона повинна перестати чекати на нові повідомлення.

## 5. Ігноруйте неочікувані повідомлення

Змініть машину так, щоб, коли вона отримує неочікуване повідомлення, вона його ігнорувала й продовжувала чекати на нові повідомлення.
