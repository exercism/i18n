# Інструкції для SQLite

Стовпець **result** повинен містити закодований у JSON обʼєкт обʼєктів, де кожне слово - ключ, а кількість - ціле число.

Наприклад, візьмімо речення вище: `"That's the password: 'PASSWORD 123'!", cried the Special Agent.\nSo I fled.`
**result** для цих вхідних даних має бути таким:

```json
{"123":1,"agent":1,"cried":1,"fled":1,"i":1,"password":2,"so":1,"special":1,"that's":1,"the":2}
```

## Схема таблиці

```sql
CREATE TABLE "word-count" (
    sentence TEXT NOT NULL,
    result   TEXT               -- json object
);
```
