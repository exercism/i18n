# Робочий процес розгортання

Робочий процес розгортання використовується для розгортання [інструментарію треку](/docs/building/tooling) у:

1. [Docker Hub](https://hub.docker.com/): Використовується в скриптах або для локального тестування.
   Загальнодоступний.
2. [ECR](https://aws.amazon.com/ecr/): Використовується в продакшн-середовищі для тестування надісланих рішень.
   Приватний.

## Джерело

Робочий процес визначено у файлі `.github/workflows/deploy.yml`.
