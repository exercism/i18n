# Тести


Ми використовуємо [pytest][pytest: Getting Started Guide] для запуску тестів на нашому сайті.
Щоб запускати тести треку Python локально, потрібно встановити `pytest` на своєму компʼютері.
Також варто встановити такі плагіни `pytest`:

- [pytest-cache][pytest-cache]
- [pytest-subtests][pytest-subtests]

Докладніше про це можна дізнатися в [посібнику з тестування Python][Python track tests page] на нашому сайті.


### Запуск тестів

Щоб запустити тести, які додаються до вправи, перейдіть до теки, де зберігається вправа, за допомогою `cd` у терміналі (_замініть `<exercise-folder-location>` нижче на свій шлях_).
Файли з тестами зазвичай закінчуються на `_test.py`, і це ті самі тести, які запускаються на сайті, коли завантажують рішення.

Linux/MacOS
```bash
$ cd <path/to/exercise-folder-location>
```

Windows
```powershell
PS C:\Users\foobar> cd <path\to\exercise-folder-location>
```

<br>

Далі запустіть команду `pytest` у терміналі, замінивши `<exercise_test.py>` на назву файлу з тестами:

Linux/MacOS
```bash
$ python3 -m pytest -o markers=task <exercise_test.py>
==================== 7 passed in 0.08s ====================
```

Windows
```powershell
PS C:\Users\foobar> py -m pytest -o markers=task <exercise_test.py>
==================== 7 passed in 0.08s ====================
```


### Поширені параметри
- `-o` : перевизначити типовий `pytest.ini` (_це дає змогу уникнути попереджень про маркери_)
- `-v` : увімкнути докладний вивід.
- `-x` : зупинити виконання тестів після першої невдачі.
- `--ff` : спочатку запустити тести, що не пройшли попереднього разу, а вже потім решту.

Щоб побачити інші параметри, використайте `python3 -m pytest -h` або `py -m pytest -h`.


### Як позбутися попереджень

Якщо під час запуску `pytest` не використовувати `pytest -o markers=task`, можна отримати `PytestUnknownMarkWarning` для тестів, які використовують наш новий синтаксис:

```bash
PytestUnknownMarkWarning: Unknown pytest.mark.task - is this a typo?  You can register custom marks to avoid this warning - for details, see https://docs.pytest.org/en/stable/mark.html
```

Щоб не вводити `pytest -o markers=task` щоразу, коли запускаємо тести, можна скористатися файлом конфігурації `pytest.ini`.
Ми створили такий файл, і його можна завантажити з кореня теки треку Python: [pytest.ini][pytest.ini].

Можна також створити власний файл `pytest.ini` з таким вмістом:

```ini
[pytest]
markers =
    task: A concept exercise task.
```

Якщо покласти файл `pytest.ini` у _кореневу_ або _робочу_ теку для вправ треку Python, маркери зареєструються і попередження зникнуть.
Докладніше про маркери pytest можна прочитати в документації `pytest` про [позначення тестових функцій][pytest: marking test functions with attributes] і в документації `pytest` про [роботу з власними маркерами][pytest: working with custom markers].

Про налаштування конфігурацій pytest можна дізнатися з документації `pytest` про [формати файлів конфігурації][pytest: configuration file formats].
