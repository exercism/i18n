# Вступ

## Рекурсія

Рекурсивною називають функцію, яка викликає саму себе.

Рекурсивна функція повинна мати щонайменше один _базовий випадок_ і щонайменше один _рекурсивний випадок_.

_Базовий випадок_ повертає значення, не викликаючи функцію знову.
_Рекурсивний випадок_ викликає функцію знову, змінюючи вхідні дані так, щоб вони колись збіглися з базовим випадком.

В Elm рекурсивні функції зазвичай визначають за допомогою зіставлення зі зразком у виразах `case` або кількох варіантів визначення функції.

```elm
count : List a -> Int
count list =
    case list of
        [] ->
            0  -- base case

        _ :: tail ->
            1 + count tail  -- recursive case
```

### Цикли через рекурсію

Через незмінність цикли в Elm пишуть інакше, ніж в імперативних мовах.
Наприклад, цикли зазвичай мають такий вигляд:

```c
for(i = 0; i < array.length; i++) {
  // do something with array[i]
}
```

У функціональній мові, як-от Elm, змінювати змінні неможливо.
Тож цикли доводиться реалізовувати через рекурсію.

Еквівалент циклу `for` в Elm мав би такий вигляд:

```elm
loop : List a -> (a -> b) -> List b
loop list f =
    case list of
        [] ->
            []

        head :: tail ->
            f head :: loop tail f
```

На практиці для перебирання масивів та інших структур даних в Elm найчастіше використовують функції з модуля `List`, як-от `List.map`, `List.filter` і `List.foldl`.
Усередині ці функції реалізовано через рекурсію.
