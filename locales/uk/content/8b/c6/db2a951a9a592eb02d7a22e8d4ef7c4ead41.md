# Підказки

## Загальне

- Прочитайте про [модуль `Agent`][getting-started-agent] у посібнику із початку роботи.
- Прочитайте документацію про [модуль `Agent`][elixir-doc-agent].
- Подивіться [ElixirCasts: Introduction to Agents][elixircasts-agent].

## 1. Відкрити сад

- Перегляньте документацію [`Agent`][elixir-doc-agent].
- Функція для ініціалізації стану _процесу агента_ повинна повертати початковий стан.

## 2. Перелічити реєстрації

- Модуль [`Agent`][elixir-doc-agent] містить багато функцій для отримання поточного стану _процесу агента_.

## 3. Зареєструвати ділянки за людиною

- Модуль [`Agent`][elixir-doc-agent] містить функції для отримання й оновлення стану _процесу агента_.
- Ці функції зазвичай приймають функцію, яка перетворює стан і повертає певну форму.
- Щоб відстежувати id наступної ділянки, яку потрібно призначити, стан _процесу агента_ має зберігати і ділянки, і наступний id, який слід використати для ділянки.

## 4. Звільнити ділянки

- Модуль [`Agent`][elixir-doc-agent] містить функції для отримання й оновлення стану _процесу агента_.
- Ці функції зазвичай приймають функцію, яка перетворює стан і повертає наступний стан.

## 5. Отримати зареєстровану ділянку

- Модуль [`Agent`][elixir-doc-agent] містить функції для отримання стану _процесу агента_.
- Отримайте ділянку, а потім обробіть результат так, щоб повернути правильний результат.
