# Вступ

Фільтрування - це процес створення однієї послідовності з іншої шляхом копіювання всіх елементів оригінальної послідовності, крім певних.
Вибір того, які елементи включити до нової послідовності, можна зробити за допомогою функції-предиката (функції, яка обчислюється в булеве значення (англ. Boolean)), або за допомогою рівності з конкретним обʼєктом.

## Видалення за предикатом

`remove-if` - це функція, яка приймає функцію-предикат і послідовність як аргументи та повертає послідовність лише з тих елементів, для яких предикат обчислився в неправду.
Іншими словами, вона «видаляє» всі елементи послідовності, для яких предикат обчислюється в правду. Однак зауважмо: ця функція не змінює оригінальну послідовність!
Натомість вона повертає нову послідовність без відповідних елементів. Якщо предикат був правдою для всіх значень, повертається порожня послідовність.

```lisp
(remove-if #'evenp '(1 2 3 4 5)) ; => (1 3 5)
(remove-if #'oddp '(1 3 5))      ; => ()
```

## Видалення конкретного елемента

Щоб видалити конкретний елемент із послідовності, можна скористатися функцією `remove`, яка приймає елемент для видалення та послідовність.
Повертаються всі значення послідовності, які не дорівнюють елементу для видалення.
ЗАУВАЖЕННЯ: для перевірки рівності типово використовується [загальний предикат рівності][concept-equality] `eql`.

```lisp
(remove 1 '(1 2 1 3 1 4)) ; => (2 3 4)
(remove #\l "hello")      ; => "heo"
```
