# Вступ

## Переліки

_Перелічуваний тип_ - це спеціальний тип даних, який дає змінній змогу набувати однієї з наперед визначених констант.
Змінна має дорівнювати одному зі значень, наперед визначених для цього типу.
Поширені приклади: сторони світу (значення `NORTH`, `SOUTH`, `EAST` і `WEST`) і дні тижня.

Оскільки це константи, назви полів перелічуваного типу записують великими літерами.

### Визначення перелічуваного типу

У мові програмування Java перелічуваний тип визначають за допомогою ключового слова `enum`.
Наприклад, перелічуваний тип для днів тижня можна визначити так:

```java
public enum DayOfWeek {
    SUNDAY,
    MONDAY,
    TUESDAY,
    WEDNESDAY,
    THURSDAY,
    FRIDAY,
    SATURDAY
}
```

Перелічувані типи варто використовувати щоразу, коли потрібно представити фіксований набір констант.
Це охоплює природні перелічувані типи, як-от планети нашої Сонячної системи, і набори даних, де всі можливі значення відомі на етапі компіляції, наприклад пункти меню, прапорці командного рядка тощо.

### Використання перелічуваного типу

Далі наведено код, який показує, як використовувати перелічуваний тип `DayOfWeek`, визначений вище:

```java
public class Shop {
    public String getOpeningHours(DayOfWeek dayOfWeek) {
        switch (dayOfWeek) {
            case MONDAY:
            case TUESDAY:
            case WEDNESDAY:
            case THURSDAY:
            case FRIDAY:
                return "9am - 5pm";
            case SATURDAY:
                return "10am - 4pm"
            case SUNDAY:
                return "Closed.";
        }
    }
}
```

```java
var shop = new Shop();
shop.getOpeningHours(DayOfWeek.WEDNESDAY);
// => "9am - 5pm"
```

### Додавання методів і полів

Перелічувані типи в мові програмування Java значно потужніші, ніж їхні відповідники в інших мовах.
Оголошення `enum` визначає _клас_ (який називають _перелічуваним типом_).
Тіло цього класу може містити методи та інші поля:

```java
public enum Rating {
    GREAT(5),
    GOOD(4),
    OK(3),
    BAD(2),
    TERRIBLE(1);

    private final int numberOfStars;

    Rating(int numberOfStars) {
        this.numberOfStars = numberOfStars;
    }

    public int getNumberOfStars() {
        return this.numberOfStars;
    }
}
```

Виклик методу `getNumberOfStars` для елемента перелічуваного типу `Rating`:

```java
Rating.GOOD.getNumberOfStars();
// => 4
```
