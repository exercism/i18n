# Вступ

На відміну від багатьох інших мов, у JavaScript є дві різні сутності, які позначають відсутність (змістовного) значення.
Це `null` і `undefined`.

## Null

Примітивне значення `null` використовують як навмисне «порожнє значення» для змінних будь-якого типу.

```javascript
let name = null;
// name is intentionally set to "empty" because it is not
// available
```

Перевірити, чи змінна дорівнює `null`, можна за допомогою [оператора строгої рівності][mdn-strict-equality] `===`.

```javascript
let name = null;

name === null;
// => true
```

## Undefined

> Змінна, якій не присвоєно значення, має тип `undefined`.<sup>1</sup>

Це означає, що хоча `null` позначає порожнє значення (але все ж значення), `undefined` позначає цілковиту відсутність значення. 🤯

`undefined` трапляється в різних контекстах.

- Якщо змінну оголошено без значення (без ініціалізації), вона дорівнює `undefined`.
- Якщо ми намагаємося отримати значення для неіснуючого ключа в обʼєкті, отримуємо `undefined`.
- Якщо функція не повертає значення, результатом буде `undefined`.
- Якщо аргумент не передано у функцію, він дорівнює `undefined`, якщо тільки цей аргумент не має типового значення.

```javascript
let name;
console.log(name);
// => undefined
```

Перевірити, чи змінна дорівнює `undefined`, можна за допомогою оператора строгої рівності `===`.

```javascript
let name;

name === undefined;
// => true
```

## Опціональне звʼязування

Якщо ми намагаємося отримати вкладене значення в обʼєкті, але батьківського ключа не існує, JavaScript викине помилку.
Щоб легко цього уникнути, до специфікації мови у 2020 році додали опціональне звʼязування.
За допомогою оператора опціонального звʼязування `?.` можна зробити так, щоб JavaScript звертався до вкладеного ключа лише тоді, коли батьківський ключ не дорівнює `null` чи `undefined`.
Інакше повертається `undefined`.

```javascript
const obj = {
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
};

obj.address.zipCode;
// => undefined

obj.residence.street;
// => TypeError: Cannot read property 'street' of undefined

obj.residence?.street;
// => undefined
```

## Нульове обʼєднання

Бувають ситуації, коли треба застосувати типове значення, якщо змінна дорівнює `null` або `undefined` (але тільки тоді).
Щоб це врахувати, у 2020 році ввели оператор нульового обʼєднання `??`.
Він повертає правий операнд лише тоді, коли лівий операнд дорівнює `null` або `undefined`.
Інакше повертається лівий операнд.

```javascript
let amount = null;
amount = amount ?? 1;
// => 1

amount = 0;
amount = amount ?? 1;
// => 0
```
