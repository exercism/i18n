# Вступ

ABAP підтримує обʼєктно-орієнтовану модель програмування, яка ґрунтується на класах та інтерфейсах ABAP Objects.

## (Пере)присвоєння

Існує кілька основних способів присвоїти значення іменам в ABAP: за допомогою змінних або констант. На Exercism змінні завжди записують у стилі [snake-case][wiki-snake-case]. Офіційного посібника, якого варто дотримуватися, немає, а різні компанії та організації мають різні настанови зі стилю. _Пишімо змінні так, як нам завгодно_. Перевага того, що ми пишемо їх так, як підготовлено у вправах, полягає в тому, що вони по-іншому будуть підсвічуватися у вебінтерфейсі та більшості IDE.

Змінні в ABAP можна визначати за допомогою ключових слів [`constant`][constant] або [`data`][data].

Якщо використовувати `data`, змінна може містити різні значення протягом свого життя. Наприклад, `my_first_variable` можна визначати та перевизначати багато разів за допомогою [оператора присвоєння `=`][assignment]:

```abap
DATA my_first_variable TYPE i. " integer

my_first_variable = 1.
my_first_variable = 4711 * 3.
my_first_variable = some_complex_calculation( ).
```

На відміну від `data`, змінним, визначеним через `constant`, можна присвоїти значення лише один раз. Саме так у ABAP визначають константи.

```abap
CONSTANT my_first_constant TYPE i VALUE 10.

" Can not be re-assigned
my_first_constant = 20.
// => SyntaxError: Assignment to constant variable.
```

## Оголошення класів і методів

В ABAP одиниці функціональності інкапсульовані в _методах_, які зазвичай обʼєднують у тому самому [класі][classes], якщо вони належать одна до одної. Ці методи можуть приймати параметри (аргументи) та можуть _повертати_ значення за допомогою ключового слова `returning` в оголошенні методу. Методи викликають за допомогою синтаксису `( )`.

```abap
CLASS my_class DEFINITION.

  PUBLIC SECTION.

    METHODS add
      IMPORTING
        num1          TYPE i
        num2          TYPE i
      RETURNING
        VALUE(result) TYPE i.

ENDCLASS.

CLASS my_class IMPLEMENTATION.

  METHOD add.
    result = num1 + num2.
  ENDMETHOD.

ENDCLASS.

add( num1 = 1 num2 = 3 ).
// => 4
```

> 💡 В ABAP є _багато_ різних способів оголошувати класи та методи. Трек намагається поступово їх подавати, але якщо ми вже з ними знайомі, то можемо вільно скористатися будь-яким із них. Здебільшого використання того чи того з них не краще й не гірше.
