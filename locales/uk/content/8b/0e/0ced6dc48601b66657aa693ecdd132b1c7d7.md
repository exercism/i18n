# Інструкції

Ми розробляємо нову надзвичайно популярну гру **Crystal Hunter**.
У грі ми граємо за персонажа, який рухається та збирає кристали.
Гравець перемагає, якщо збере всі кристали.
Якщо гравець торкнеться бандита, він втратить усі свої кристали і програє.
У цього правила є виняток: у гравця може бути активне підсилення, яке робить його невидимим для бандитів.

Наша мета - написати правила, які будуть використовуватися у грі.

## 1. Визначити, чи отримує персонаж бонусні очки

У грі персонаж отримує бонусні очки, якщо торкнеться бандита, маючи активне підсилення.

Визначте метод `Rules#bonus_points?`, який приймає два аргументи (_чи має персонаж активне підсилення_ та _чи торкається персонаж бандита_) і повертає булеве значення (англ. Boolean), яке вказує, чи отримає персонаж бонусні очки.
Метод має повертати `true`, лише якщо персонаж має активне підсилення і торкається бандита, та `false` в іншому разі.

```Crystal
Rules.new.bonus_points?(false, true)
# => false
```

## 2. Визначити, чи отримує персонаж очки

Гравець отримує очки, коли підбирає кристал або підсилення.

Визначте метод `Rules#score?`, який приймає два аргументи (_чи торкається персонаж підсилення_ та _чи торкається персонаж кристала_) і повертає булеве значення, яке вказує, чи отримав персонаж очки.
Метод має повертати `true`, якщо персонаж торкається підсилення або кристала, та `false` в іншому разі.

```crystal
Rules.new.score?(true, true)
# => true
```

## 3. Визначити, чи програє персонаж

Визначте метод `Rules#lose?`, який приймає два аргументи (_чи має персонаж активне підсилення_ та _чи торкається персонаж бандита_) і повертає булеве значення, яке вказує, чи програє персонаж.
Метод має повертати `true`, якщо персонаж торкається бандита і не має активного підсилення, та `false` в іншому разі.

```crystal
Rules.new.lose?(false, true)
# => true
```

## 4. Визначити, чи перемагає персонаж

Визначте метод `Rules#win?`, який приймає три аргументи (_чи зібрав персонаж усі кристали_, _чи має персонаж активне підсилення_ та _чи торкається персонаж бандита_) і повертає булеве значення, яке вказує, чи перемагає персонаж.
Метод має повертати `true`, якщо персонаж зібрав усі кристали і не програв згідно з аргументами, визначеними в частині 3, та `false` в іншому разі.

```crystal
Rules.new.win?(false, true, false)
# => false
```
