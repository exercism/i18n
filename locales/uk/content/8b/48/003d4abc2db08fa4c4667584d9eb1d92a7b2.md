# Вступ

Двійкові цифри зрештою безпосередньо відповідають транзисторам у нашому процесорі чи оперативній памʼяті та тому, у якому стані кожен із них перебуває: «увімкнено» чи «вимкнено».

Низькорівнева робота з даними, яку неформально називають «жонглюванням бітами», особливо важлива в системних мовах.

Високорівневі мови, як-от Julia, зазвичай приховують більшість цих деталей.
Однак повний набір операцій на рівні бітів доступний уже в самій мові.

***Примітка:*** Щоб побачити двійковий вивід у зрозумілому для людини вигляді в REPL, майже всі наведені нижче приклади потрібно обгорнути у функцію `bitstring()`.
Це відволікає, тому більшість входжень цієї функції ми прибрали.

## Операції зсуву бітів

Цілі типи, зі знаком або без нього, можна подати як рядок тексту (англ. string) з одиниць і нулів.

```julia-repl
julia> bitstring(UInt8(5))
"00000101"
```

Зсуви бітів просто пересувають усе вліво або вправо на вказану кількість позицій.
У типах `UInt` частина бітів відкидається з одного кінця, а інший кінець доповнюється нулями:

```julia-repl
julia> ux::UInt8 = 5
5

julia> bitstring(ux)
"00000101"

julia> ux << 2 # left by 2
"00010100"

julia> ux >> 1 # right by 1
"00000010"
```

Кожен зсув вліво подвоює значення, а кожен зсув вправо ділить його навпіл (з відкиданням залишку).
Це помітніше в десятковому записі:

```julia-repl
julia> 3 << 2
12

julia> 24 >> 3
3
```

Такий зсув бітів працює значно швидше за «справжню» арифметику, тому цей прийом дуже популярний у низькорівневому коді.

Із цілими числами зі знаком варто бути трохи обережнішими.

Зсуви вліво відносно прості:

```julia-repl
julia> sx = Int8(5)
5

julia> sx # positive integer
"00000101"

julia> sx << 2
"00010100"

julia> -sx # negative integer
"11111011"

julia> -sx << 2
"11101100"
```

Отже, зсув вліво додатних цілих чисел зі знаком нічим не відрізняється від зсуву беззнакових.

Відʼємні значення зберігаються у формі [доповняльного коду][2complement], тобто найлівіший біт дорівнює 1.
Для зсуву вліво це не проблема, але як під час зсуву вправо доповнити найлівіші біти?

```julia-repl
julia> sx >> 2 # simple for positive values!
"00000001"

julia> -sx # negative integer
"11111011"

julia> -sx >> 2 # pad with repeated sign bit
"11111110"

julia> -sx >>> 2 # pad with 0
"00111110"
```

Оператор `>>` виконує арифметичний зсув, зберігаючи знаковий біт.

Оператор `>>>` виконує логічний зсув, доповнюючи нулями, наче число беззнакове.

## Побітова логіка

У попередньому концепті ми бачили, що оператори `&&` (логічне і), `||` (логічне або) та `!` (заперечення) використовуються з булевими значеннями (англ. Boolean).

Існують відповідні оператори `&` (побітове і), `|` (побітове або) та `~` (тильда, побітове заперечення), щоб порівнювати біти двох цілих чисел.

```julia-repl
julia> 0b1011 & 0b0010 # bit is 1 in both numbers
"00000010"

julia> 0b1011 | 0b0010 # bit is 1 in at least one number
"00001011"

julia> ~0b1011 # flip all bits
"11110100"

julia> xor(0b1011, 0b0010) # bit is 1 in exactly one number, not both
"00001001"
```

Тут `xor()` - це виключне або, використане як функція.

[2complement]: https://en.wikipedia.org/wiki/Two%27s_complement
