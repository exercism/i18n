# Вступ

Регулярні вирази дають надзвичайно універсальний спосіб _знаходити збіги за зразком_ у рядках тексту (англ. string) за допомогою предметно-орієнтованої мови (DSL), створеної саме для цього.

Як і чимало інших мов програмування, Julia не намагається реалізувати власну бібліотеку регулярних виразів.
Натомість вона обгортає популярну бібліотеку [PCRE2][PCRE], тож синтаксис регулярних виразів у ній ідентичний до (наприклад) Gleam і дуже схожий на JavaScript.

~~~~exercism/note
Цей силабус Julia припускає, що ми вже знайомі з базовим синтаксисом регулярних виразів.
Ми зосередимося виключно на особливостях, властивих Julia.

Нижче наведено кілька ресурсів, щоб освіжити знання регулярних виразів.
~~~~

- [Regex101][regex101]
- [RegExr][regexr]
- [RexEgg][rexegg]
- [RegexOne][regexone]
- [Regular Expressions Info][regex-info]

Інтерфейс Julia для роботи з регулярними виразами описано в [посібнику][regex].

У Julia регулярний вираз — це просто рядок тексту, перед яким стоїть `r`, а вже потім відкривальна `"`.
Уся базова функціональність входить до стандартної бібліотеки.

Насправді багато функцій, які вже розглядалися в концепції [`Strings`][strings], стандартно призначені для пошуку за регулярними виразами, як-от `occursin()`.

```julia-repl
julia> re = r"test$"
r"test$"

julia> typeof(re)
Regex

# Does a string end with "test"?
julia> occursin(re, "this is a test")
true

julia> occursin(re, "these are tests")
false
```

Після закривальної лапки можуть стояти символи-модифікатори, як-от `i` для пошуку без урахування регістру.

```julia-repl
julia> occursin(r"test", "Testing")
false

julia> occursin(r"test"i, "Testing")
true
```

## Захоплення

Часто нам хочеться знати, _що_ саме збіглося. Для цього в регулярний вираз додають групи захоплення в дужках, а потім використовують функцію [`match()`][match].

```julia-repl
julia> m = match(r"(\d+g) .* (\d+ml)", "dissolve 25g sugar in 200ml water")
RegexMatch("25g sugar in 200ml", 1="25g", 2="200ml")

julia> m.captures
2-element Vector{Union{Nothing, SubString{String}}}:
 "25g"
 "200ml"

# how many matches?
julia> length(m.captures)
2

# what matched?
julia> m[1], m[2]
("25g", "200ml")

# Starting positions of the matches (character index)
julia> m.offsets
2-element Vector{Int64}:
 10
 23
```

Звісно, збіг може й не знайтися.
Тоді результатом замість `RegexMatch` буде особливе значення `Nothing`, тож варто бути готовими це перевірити.

```julia-repl
# failed match
m = match(r"(not here)", "dissolve 25g sugar in 200ml water")

julia> typeof(m)
Nothing

julia> isnothing(m)
true
```

Хоча `match` типово починає пошук від початку рядка тексту, ми можемо вказати зсув `n`, щоб проігнорувати перші `n` символів.

```julia-repl
# capture first match
julia> m = match(r"(\wat)", "cat, sat, mat")
RegexMatch("cat", 1="cat")

# ignore first 5 characters, then match
julia> m = match(r"(\wat)", "cat, sat, mat", 5)
RegexMatch("sat", 1="sat")
```

У Julia `match()` знаходить лише _перший_ збіг у цільовому рядку тексту: глобального модифікатора, як у деяких інших мовах, тут немає.

Натомість є [`eachmatch()`][eachmatch], яка повертає ітератор збігів.
Він обчислюється ліниво, тож, імовірно, його доведеться перетворити на потрібний формат.

```julia-repl
julia> matches = eachmatch(r"(\wat)", "cat, sat, mat")
Base.RegexMatchIterator{String}(r"(\wat)", "cat, sat, mat", false)

# convert to vector
julia> collect(matches)
3-element Vector{RegexMatch}:
 RegexMatch("cat", 1="cat")
 RegexMatch("sat", 1="sat")
 RegexMatch("mat", 1="mat")

# convert with comprehension
julia> [m.match for m in matches]
3-element Vector{SubString{String}}:
 "cat"
 "sat"
 "mat"

# broadcast an anonymous function
julia> (m -> m.match).(matches)
3-element Vector{SubString{String}}:
 "cat"
 "sat"
 "mat"
```

## Заміна

Одна з поширених причин скористатися регулярними виразами - замінити знайдений збіг іншим рядком тексту.

Функцію [`replace()`][replace] ми вже розглядали в концепції [`Strings`][strings], коли шукали за рядковими літералами.
Та сама функція може задіяти всю потугу зіставлення з регулярними виразами.

```julia-repl
julia> replace("some string", r"[aeiou]" => "*")
"s*m* str*ng"

julia> replace("first second", r"(\w+) (?<agroup>\w+)" => s"\g<agroup> \1")
"second first"
```

Другий приклад вище показує, як і нумеровані, і іменовані групи захоплення можна використати в заміні, всередині рядка `s" "`.

Докладніше дивімося в [посібнику][regex]: це тема, яка постійно повертає більшість програмістів до документації!
