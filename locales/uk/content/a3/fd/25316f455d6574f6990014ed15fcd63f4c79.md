# Вступ

Код Elixir виконується у віртуальній машині BEAM. BEAM є частиною системи виконання Erlang. Elixir, натхненний Erlang і поділяючи з ним середовище виконання, забезпечує чудову сумісність із бібліотеками Erlang. Це означає, що розробники Elixir можуть використовувати бібліотеки Erlang зі свого коду Elixir. Насправді, спільнота Elixir не радить писати бібліотеки Elixir для функціональності, яку вже надають бібліотеки Erlang.

Як наслідок, деякі можливості, як-от математичні операції чи функції таймера, доступні в Elixir лише через Erlang.

Стандартна бібліотека Erlang доступна для використання в нашому коді Elixir без жодних додаткових кроків.

Функції Erlang можна викликати так само, як ми викликаємо функції Elixir, з однією невеликою відмінністю. Назви модулів Erlang записуємо як атоми в `snake_case`. Наприклад, щоб викликати функцію `pi/0` з модуля `math`, ми напишемо:

```elixir
:math.pi()
# => 3.141592653589793
```

Найпоширеніші функції Erlang, які не мають відповідника в Elixir:

- `:timer.sleep/1`, яка зупиняє процес на вказану кількість мілісекунд.
- `:rand.uniform/0`, яка генерує випадкове число з плаваючою комою `x`, де `0.0 <= x < 1.0`.
- `:io_lib.format/2`, яка забезпечує форматування рядків тексту (англ. string) у стилі C (за допомогою керуючих послідовностей). За допомогою цієї функції ми могли б, наприклад, надрукувати ціле число в будь-якій основі від 2 до 36 або відформатувати число з плаваючою комою з потрібною точністю. Зауважмо, що ця функція, як і багато функцій Erlang, повертає charlist.
- Модуль `math`, який надає математичні функції, як-от `sin/1`, `cos/1`, `log2/1`, `log10/1`, `pow/2` та інші.

Щоб ближче познайомитися зі стандартною бібліотекою Erlang, розгляньмо [довідник STDLIB][erl-stdlib-ref].

[erl-stdlib-ref]: https://www.erlang.org/doc/apps/stdlib/index.html
