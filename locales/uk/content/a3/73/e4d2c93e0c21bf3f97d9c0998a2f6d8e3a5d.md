# Вступ

Factor виконує кооперативні потоки в межах одного процесу операційної системи. Вони передають керування під час вводу-виводу та в явних викликах `yield`, що робить синхронізацію простішою, ніж у мовах із витіснювальним плануванням, але гонки все одно можливі, бо будь-який потік може виконатися між двома неатомарними операціями над спільним станом. Словники конкурентності у Factor надають стандартний набір інструментів: `spawn` для запуску потоку, проміси для одноразового передавання результату, `parallel-map` для розгалуження й обʼєднання над послідовністю та блокування для взаємного виключення.
