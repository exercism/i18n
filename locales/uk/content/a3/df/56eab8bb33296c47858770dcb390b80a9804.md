# Про рядки

[Рядки тексту (англ. string)][getting-started-strings] в Elixir обмежуються подвійними лапками і кодуються в UTF-8:

```elixir
"Hi!"
```

Рядки тексту можна зʼєднати за допомогою оператора [`<>/2`][kernel-concat]:

```elixir
"Welcome to" <> " " <> "New York"
# => "Welcome to New York"
```

Рядки тексту в Elixir підтримують [інтерполяцію][string-interpolation] із синтаксисом `#{}`:

```elixir
"6 * 7 = #{6 * 7}"
# => "6 * 7 = 42"
```

Усередині інтерполяції можна використати будь-який вираз Elixir. Якщо підставити рядок тексту, він вставляється як є. Якщо підставити будь-яке інше значення, Elixir спробує перетворити його на рядок тексту.

```elixir
"Elixir can convert booleans to strings: #{true}"
# => "Elixir can convert booleans to strings: true"

"And #{["lists", ", ", "too!"]}"
# => "And lists, too!"

"But not functions: #{fn x -> x end}"

# => ** (Protocol.UndefinedError) protocol String.Chars not implemented for #Function<7.126501267/1 in :erl_eval.expr/5> of type Function
#        (elixir 1.10.1) lib/string/chars.ex:3: String.Chars.impl_for!/1
#        (elixir 1.10.1) lib/string/chars.ex:22: String.Chars.to_string/1
```

Elixir надає багато функцій для роботи з рядками тексту в модулі `String`. Якщо ми не впевнені, як обробити рядок тексту потрібним чином, варто переглянути [функції, доступні в модулі `String`][string-module-functions], і, найімовірніше, ми знайдемо те, що потрібно.

```elixir
String.downcase("PLEASE NO SHOUTING")
# => "please no shouting"

String.split("hello", "", trim: true)
# => ["h", "e", "l", "l", "o"]

String.replace("Do I enjoy Elixir? Maybe...", "Maybe...", "Definitely!")
# => "Do I enjoy Elixir? Definitely!"

String.at("12345", 2)
# => "3"
```

Користуючись деякими з цих функцій, памʼятаймо, що перший символ рядка тексту має індекс `0`.

Деякі символи потрібно [екранувати][escape-characters], щоб вставити їх у рядок тексту, наприклад символи нового рядка, подвійні лапки або символ `#`:

```elixir
"\"A\" is the \#1st letter of the alphabet.\n"
```

Щоб зручно працювати з текстами з великою кількістю символів нового рядка, краще використати [синтаксис heredoc із потрійними подвійними лапками][heredoc-syntax]:

```elixir
"""
1
2
3
"""
```

Дуже часто цей синтаксис використовують для документування коду:

```elixir
defmodule MyApp.Hello do
  @moduledoc """
  This is the Hello module.
  """

  @doc """
  Says hello to the given `name`.

  Returns `:ok`.

  ## Examples

      iex> MyApp.Hello.world(:john)
      :ok

  """
  def world(name) do
    IO.puts("hello #{name}")
  end
end
```
