# Вступ

## Структурні типи

Ми вже бачили структурні типи. Нагадаємо: `struct` складається з послідовності іменованих елементів, які називаються _полями_, і кожне поле має назву та тип.
Назва поля має бути унікальною в межах структури.
Структури можна порівняти з _класом_ у парадигмі обʼєктно-орієнтованого програмування.

Ми створюємо нову структуру за допомогою ключових слів `type` і `struct`, а потім явно визначаємо назву й тип полів, як показано в прикладі нижче.

```go
type StructName struct{
    field1 fieldType1
    field2 fieldType2
}
```

## Неструктурні типи

Також можна визначати неструктурні типи, які можна використовувати як псевдоніми для вбудованих типів.

```go
type Name string
func SayHello(n Name) {
  fmt.Printf("Hello %s\n", n)
}
n := Name("Fred")
SayHello(n)
// Output: Hello Fred
```

Крім того, можна визначати неструктурні типи, складені з масивів і словників.

```go
type Names []string
func SayHello(n Names) {
  for _, name := range n {
    fmt.Printf("Hello %s\n", name)
  }
}
n := Names([]string{"Fred", "Bill"})
SayHello(n)
// Output:
// Hello Fred
// Hello Bill
```
