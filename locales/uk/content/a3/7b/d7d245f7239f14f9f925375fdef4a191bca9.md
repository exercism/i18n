# Вступ

Цикл `for` дозволяє перебирати масив і повторювати код для кожного елемента:

```haxe
var fruitList = ["apple", "banana", "pear"];

for (fruit in fruitList) {
  trace(fruit);
}

// apple
// banana
// pear
```

У наведеному прикладі `fruit` - це змінна, яка зберігає значення окремого елемента масиву `fruitList`. Компілятор перевіряє, що `fruitList` можна перебрати, інакше він зупинить виконання.

Перебирати числа можна за допомогою оператора діапазону. Цей оператор приймає два операнди типу `Int` і записується як `min...max`:

```haxe
for (i in 0...10) {
  trace(i); // from 0 to 9
}
```
