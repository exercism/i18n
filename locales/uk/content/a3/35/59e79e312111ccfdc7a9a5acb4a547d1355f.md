# Інструкції

У цій вправі ми будемо реалізовувати механіки рольової гри.
Персонаж гравця представлений таким типом:

```fsharp
type Player = {
    Name: string option
    Level: int
    Health: int
    Mana: int option
}
```

Гравці в цій грі повинні досягти 10 рівня, перш ніж відкрити запас мани, щоб почати читати заклинання.
Ми будемо працювати над двома частинами функціональності цієї гри: механікою відродження та механікою чаклування.

## 1. Представтеся

Напишіть вміст функції `introduce`.
Зверніть увагу, що поле `Name` запису `Player` має тип `Option`.
Гравці-потайники можуть схотіти приховати своє імʼя, залишивши його рівним `None`. Такі гравці будуть представлені як `"Mighty Magician"`.
Інакше просто використайте імʼя, щоб представитися.

```fsharp
introduce { Name = None; Level = 2; Health = 8; Mana = None }
    --> "Mighty Magician"

introduce { Name = Some "Merlin"; Level = 2; Health = 8; Mana = None }
    --> "Merlin"
```

## 2. Реалізуйте механіку відродження

Функція `revive` повинна перевірити, що персонаж гравця справді мертвий (його здоровʼя досягло 0).
Якщо так, вона повинна повернути новий екземпляр `Player` зі здоровʼям 100.
Інакше, якщо персонаж гравця не мертвий, функція `revive` повертає `None`.

Якщо рівень гравця 10 або вищий, його також слід відродити зі 100 мани.
Якщо рівень гравця нижчий за 10, його мана повинна бути `None`.
Функція `revive` повинна зберегти рівень гравця.

```fsharp
let deadPlayer = { Name = None; Level = 2; Health = 0; Mana = None }

revive deadPlayer
    --> Some { Name = None; Level = 2; Health = 100; Mana = None }
```

Якщо метод `revive` викликати для гравця, здоровʼя якого 1 або більше, то функція повинна повернути `None`.

```fsharp
let alivePlayer = { Name = None; Level = 2; Health = 42; Mana = None }

revive alivePlayer
    --> None
```

## 3. Реалізуйте механіку чаклування

Функція `castSpell` приймає як аргументи `int`, що вказує, скільки мани коштує заклинання, а також `Player`.
Вона повертає оновленого гравця, а також кількість шкоди, яку завдає прочитане заклинання.
Успішно прочитане заклинання завдає шкоди, що дорівнює подвоєній витраті мани на заклинання.
Однак якщо гравцеві не вистачає мани, нічого не відбувається: гравець не змінюється, і шкоди не завдається.
Якщо у гравця взагалі немає запасу мани, спроба прочитати заклинання повинна зменшити його здоровʼя на витрату мани на заклинання і не завдає шкоди.

```fsharp
let wizard = { Name = None; Level = 18; Health = 123; Mana = Some 30 }

let updatedWizard, damage = castSpell 14 wizard

updatedWizard.Mana --> Some 16
damage             --> 28
```
