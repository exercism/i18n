# використання оголених повернень

Спільнота Go радить уникати *оголених повернень* (або *порожніх повернень*) за звичайних обставин,
оскільки вони зазвичай роблять код важчим для читання.
Докладніше див. в [офіційному посібнику з рецензування коду Go](https://github.com/golang/go/wiki/CodeReviewComments#naked-returns).
Є [пропозиція](https://github.com/golang/go/issues/21291) повністю прибрати порожні повернення в Go 2.
