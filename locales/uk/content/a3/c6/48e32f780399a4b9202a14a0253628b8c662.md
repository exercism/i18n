# Інструкції

Перетворіть шістнадцяткове число, представлене як рядок тексту (англ. string) (наприклад, "10af8c"), на його десятковий еквівалент, спираючись лише на базові принципи (тобто ні, не можна використовувати вбудовані чи зовнішні бібліотеки для цього перетворення).

У вебі шістнадцяткову систему використовують для позначення кольорів, наприклад зелений: 008000, бірюзовий: 008080, темно-синій: 000080).

Програма повинна обробляти некоректні шістнадцяткові рядки тексту.
