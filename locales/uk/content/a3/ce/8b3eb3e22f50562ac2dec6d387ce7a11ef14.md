# Інструкції

Ми завзяті спостерігачі за птахами й ретельно записуємо, скільки птахів відвідало наш сад за останні сім днів.

У нас шість завдань, і всі вони стосуються кількості птахів, що відвідали наш сад.

## 1. Перевірте, якими були підрахунки минулого тижня

Для порівняння ми завжди тримаємо напохваті копію підрахунків за минулий тиждень, а саме: 0, 2, 5, 3, 7, 8 і 4. Створіть вектор із підрахунками минулого тижня:

```clojure
last-week
;;=> [0 2 5 3 7 8 4]
```

## 2. Перевірте, скільки птахів прилетіло сьогодні

Реалізуйте функцію `today`, щоб вона повертала кількість птахів, які відвідали наш сад сьогодні. Підрахунки птахів упорядковано за днями: перший елемент показує кількість за найдавніший день, а останній - за сьогодні.

```clojure
(def birds-per-day [2 5 0 7 4 1])
(today birds-per-day)
;;=> 1
```

## 3. Збільште сьогоднішній підрахунок на одиницю

Реалізуйте функцію `inc-bird`, щоб збільшити сьогоднішній підрахунок на одиницю:

```clojure
(inc-bird birds-per-day)
;;=> [2 5 0 7 4 2]
```

## 4. Перевірте, чи був день, коли не прилітав жоден птах

Реалізуйте функцію-предикат `day-without-birds?`, яка повертає `true`, якщо був день, коли до саду не прилетів жоден птах; інакше повертається `false`:

```clojure
(day-without-birds? birds-per-day)
;;=> true
```

## 5. Обчисліть кількість птахів за вказану кількість днів

Реалізуйте функцію `n-days-count`, яка повертає кількість птахів, що відвідали наш сад від початку тижня, обмежену вказаною кількістю днів від початку тижня.

```clojure
(n-days-count birds-per-day 4)
;;=> 14
```

## 6. Обчисліть кількість насичених днів

Деякі дні бувають насиченішими за інші. Насичений день - це день, коли до нашого саду прилетіло пʼять або більше птахів.
Реалізуйте функцію `busy-days`, щоб вона повертала кількість насичених днів:

```clojure
(busy-days birds-per-day)
;;=> 2
```

## 7. Перевірте, чи тиждень непарний

За останній рік ми помітили, що деякі тижні мають ту саму непарну закономірність, коли кількість птахів чергується між одиницею та нулем. Реалізуйте функцію `odd-week?`, яка повертає `true`, якщо закономірність підрахунку птахів цього тижня збігається з непарною закономірністю:

```clojure
(odd-week? [1 0 1 0 1 0 1])
;;=> true
```
