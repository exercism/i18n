# Функції

У JavaScript функції є _обʼєктами першого класу_, а це означає, що їх можна присвоювати змінним і властивостям, передавати іншим функціям і повертати з функцій. Вони можуть мати властивості й методи, як і будь-який інший _обʼєкт_.

## Вхідні дані: передавання аргументів

Функції JavaScript дозволяють передавати аргументи під час виклику. Аргументи завжди [передаються за значенням](https://dev.to/xpbytes/javascript-ruby-and-c-are-not-call-by-reference-23f7). Інакше кажучи, якщо функція присвоює параметру нове значення всередині себе, то зовні функції значення не зміниться. Це не означає, що передані обʼєкти не можна змінювати.

> [!TIP]
> Коли ми передаємо обʼєкт, посилання на цей обʼєкт передається за значенням. Через це _здається_, що з переданими обʼєктами поводяться інакше, але це не так.

Ось приклад функції, яка приймає два аргументи й перемножує їх:

```javascript
function multiply(a, b) {
  return a * b;
}

multiply(2, 3);
// => 6
```

## Вихідні дані: повернене значення

JavaScript може повернути з функції одне значення за допомогою ключового слова `return`, після якого йде вираз. Якщо функція нічого не повертає, повернене значення дорівнює `undefined`.

Ось приклад функції, яка повертає значення:

```javascript
function multiply(a, b) {
  return a * b;
}

multiply(2, 3);
// => 6
```

## Визначення функцій

У JavaScript є чотири різновиди функцій:

1. Звичайні функції, які можуть повертати будь-що і завжди виконуються до кінця;
2. Асинхронні функції, які завжди повертають `Promise` і які можна призупинити та відновити за допомогою оператора `await`;
3. Функції-генератори: вони завжди повертають обʼєкт `Generator`, і їх можна призупинити та відновити за допомогою оператора `yield`;
4. Асинхронні функції-генератори: вони завжди повертають обʼєкт `AsyncGenerator`, і їх можна призупинити та відновити за допомогою _і_ оператора `yield`, _і_ оператора `await`.

Для кожного з цих чотирьох різновидів є три способи визначення:

1. за допомогою оголошення
2. за допомогою виразу
3. за допомогою конструктора

І нарешті, є окремий синтаксис для визначення _стрілкових функцій і методів_.
