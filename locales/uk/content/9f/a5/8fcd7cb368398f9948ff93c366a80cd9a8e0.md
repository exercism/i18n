# Інструкції

У цій вправі ми будемо працювати над планувальником записів для салону краси, який відкрився 15 вересня 2012 року.

На нас чекає пʼять завдань, і всі вони повʼязані з датами прийомів.

## 1. Розберіть дату прийому

Реалізуйте функцію `Schedule`, щоб перетворити текстове подання дати прийому у відповідний формат `time.Time`:

```go
Schedule("7/25/2019 13:45:00")
// => 2019-07-25 13:45:00 +0000 UTC
```

## 2. Перевірте, чи прийом уже минув

Реалізуйте функцію `HasPassed`, яка приймає дату прийому й перевіряє, чи був прийом десь у минулому:

```go
HasPassed("July 25, 2019 13:45:00")
// => true
```

## 3. Перевірте, чи припадає прийом на другу половину дня

Реалізуйте функцію `IsAfternoonAppointment`, яка приймає дату прийому й перевіряє, чи припадає прийом на другу половину дня (>= 12:00 і < 18:00):

```go
IsAfternoonAppointment("Thursday, July 25, 2019 13:45:00")
// => true
```

## 4. Опишіть час і дату прийому

Реалізуйте функцію `Description`, яка приймає дату прийому й повертає опис цієї дати й часу:

```go
Description("7/25/2019 13:45:00")
// => "You have an appointment on Thursday, July 25, 2019, at 13:45."
```

## 5. Поверніть дату річниці відкриття салону

Реалізуйте функцію `AnniversaryDate`, яка повертає дату річниці відкриття салону для поточного року в UTC.

Припустімо, що поточний рік - 2020:

```go
AnniversaryDate()

// => 2020-09-15 00:00:00 +0000 UTC
```

**Примітка:** повернене значення має тип `time.Time`, а час доби не має значення.
