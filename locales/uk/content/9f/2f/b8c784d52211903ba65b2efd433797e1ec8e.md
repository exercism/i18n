# Вступ

Введення-виведення у Factor побудоване на *потоках*: це обʼєкти, з яких ми читаємо байти чи символи або в які ми їх записуємо. Словник [`io`][io] дає нам два погляди на той самий [протокол][stream-protocol].

## Два погляди

**Слова з явним потоком** приймають потік як аргумент. Усі вони починаються з `stream-`:

```
stream-read       ( n stream -- seq/f )
stream-readln     ( stream -- str/f )
stream-write      ( seq stream -- )
stream-flush      ( stream -- )
stream-contents   ( stream -- seq )
stream-lines      ( stream -- seq )
```

**Слова з потоком оточення** читають із того потоку, який *наразі звʼязаний*, або пишуть у нього, а ним є динамічна змінна `input-stream` чи `output-stream`, спільна для всієї програми. У них короткі назви:

```
read1 read readln write write1 print flush
```

Форму з потоком оточення використовує більшість повсякденного коду. До форми з явним потоком звертаємося тоді, коли маємо конкретний потік під рукою й не хочемо замінювати потік оточення.

## Потоки в памʼяті

У цій вправі ми працюватимемо з потоками, побудованими на рядках тексту (англ. string), із [`io.streams.string`][io.streams.string]:

```
<string-reader>   ( str -- reader )
<string-writer>   ( -- writer )
```

`<string-reader>` читає з рядка тексту так, ніби це файл; `<string-writer>` збирає все, що в нього записують, щоб згодом можна було прочитати це назад. Обидва реалізують той самий протокол, що й файлові потоки, тож ці уроки безпосередньо переносяться на `<file-reader>` / `<file-writer>`.

## Область видимості за допомогою `with-…`

Щоб звʼязати явний потік як потік оточення для квотейшна й потім звільнити його, використовуємо комбінатор `with-…`:

```
with-input-stream    ( stream quot -- )
with-output-stream   ( stream quot -- )
with-string-writer   ( quot -- str )
with-file-reader     ( path encoding quot -- )
with-file-writer     ( path encoding quot -- )
```

[`with-string-writer`][with-string-writer] - це зручна форма для того, щоб «зібрати все, що друкує цей квотейшн»: вона створює записувач, виконує квотейшн, узявши цей записувач за потік виведення з оточення, і повертає зібраний рядок тексту:

```factor
USING: io io.streams.string ;

[ "captured" print ] with-string-writer .
! => "captured\n"
```

Усі комбінатори `with-…` є деструкторними комбінаторами (тієї самої родини, що й `with-disposal` і `with-destructors` із вправи [`boatswains-bilge`][boatswains-bilge]): потік звільняється при виході, навіть якщо квотейшн викидає виняток.
