# Структури

Структури - це власні типи даних, які дають змогу давати назви кільком повʼязаним значенням і обʼєднувати їх в одне ціле.
Вони схожі на кортежі, але гнучкіші й дають змогу назвати кожну частину даних, що робить код зрозумілішим.
Структури в Cairo мають такі властивості:

- Кожен тип структури має власне імʼя.
- Кожен член структури називається **полем**.
- Кожне поле структури має власне імʼя.
- Видимість визначається на рівні поля: кожне поле може бути окремо публічним або приватним.

## Визначення та створення екземплярів структур

Щоб визначити структуру, використовуємо ключове слово `struct`, після якого вказуємо імʼя та фігурні дужки з полями, їхніми іменами й типами:

```rust
#[derive(Drop)]
struct User {
    active: bool,
    username: ByteArray,
    email: ByteArray,
    sign_in_count: u64,
}
```

Щоб створити екземпляр `struct`, вказуємо його імʼя та використовуємо фігурні дужки з парами ключ-значення для полів.
Зауважмо, що під час створення екземпляра поля можна перелічити в будь-якому порядку:

```rust
let user1 = User {
   active: true, username: "someusername123", email: "someone@example.com", sign_in_count: 1
};

let user2 = User {
    sign_in_count: 1, username: "someusername123", active: true, email: "someone@example.com"
};
```

## Робота з екземпляром структури

Щоб отримати доступ до полів екземпляра `struct` або змінити їх, використовуємо точкову нотацію.
Зауважмо, що для зміни поля екземпляр має бути змінним:

```rust
let mut user1 = User {
    active: true, username: "someusername123", email: "someone@example.com", sign_in_count: 1
};
user1.email = "anotheremail@example.com";
```

Як і з будь-яким виразом, ми можемо створити новий екземпляр `struct` як останній вираз у тілі функції, щоб неявно повернути цей новий екземпляр:

```rust
fn build_user(email: ByteArray, username: ByteArray) -> User {
    User {
        email: email,
        username: username,
        active: true,
        sign_in_count: 1,
    }
}
```

## Скорочений запис ініціалізації полів

У попередньому прикладі було доречно назвати параметри функції `email` і `username` так само, як поля в `struct`, але повторювати їх під час присвоєння полям структури трохи втомливо.
На щастя, існує зручний скорочений запис для ініціалізації полів структури зі змінних з такими самими іменами:

```rust
fn build_user_short(email: ByteArray, username: ByteArray) -> User {
    User { email, username, active: true, sign_in_count: 1, }
}
```

## Створення екземплярів з інших екземплярів за допомогою синтаксису оновлення структури

Щоб створити новий екземпляр з наявного, змінивши частину полів і залишивши решту без змін, використовуємо синтаксис оновлення структури.
Це робиться за допомогою оператора `..`.

Без синтаксису оновлення:

```rust
let user2 = User {
    active: user1.active,
    username: user1.username,
    email: "another@example.com",
    sign_in_count: user1.sign_in_count,
};
```

Із синтаксисом оновлення:

```rust
let user2 = User { email: "another@example.com", ..user1 };
```

Синтаксис `..user1` копіює решту полів з `user1` до `user2`.
Зауважмо, що це переміщує дані з `user1` до `user2`, тож `user1` не можна використовувати після цього, якщо він містить типи, які не можна копіювати.
