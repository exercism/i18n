# Докладно

Клас Lambda - це набір функціональних методів, які дають змогу застосовувати функціональний стиль програмування в Haxe. Він дозволяє працювати з цілим Iterable одразу. Це часто краще, ніж писати цикли, адже такий код менш схильний до помилок і його легше читати. Для зручності класи Array і List містять деякі з найуживаніших методів класу Lambda.

Деякі з функцій класу `Lambda`:

- `Lambda.array`, `Lambda.list` Перетворюють Iterable на Array або List. Завжди повертають новий екземпляр.
- `Lambda.count` Рахує кількість елементів. Якщо Iterable є Array або List, швидше скористатися його властивістю length.
- `Lambda.has` Визначає, чи є вказаний елемент в Iterable.
- `Lambda.indexOf` Знаходить індекс вказаного елемента.
- `Lambda.find` Знаходить перший елемент, що задовольняє задану функцію пошуку.
- `Lambda.concat` Обʼєднує два Iterable, повертаючи новий List.
- `Lambda.filter` Знаходить елементи, що задовольняють критерій, і повертає новий List.

Приклад, що демонструє деякі з функцій:

```haxe
using Lambda;

class Main {
  static function main() {
    var words = ["boat", "dog", "phone", "cat", "food"];

    var isThreeLetters = function(word) return word.length == 3;

    trace(words.filter(isThreeLetters)); // [dog,cat]
  }
}
```
