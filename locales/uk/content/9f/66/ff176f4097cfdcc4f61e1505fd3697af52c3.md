# Вказівки

У цій вправі ми працюватимемо з рядками журналу.

Кожен рядок журналу - це рядок тексту (англ. string) такого формату: `"[<LEVEL>]: <MESSAGE>"`.

Є три різні рівні журналу:

- `INFO`
- `WARNING`
- `ERROR`

На нас чекають три завдання, і кожне з них отримує рядок журналу та просить щось із ним зробити.

## 1. Отримати повідомлення з рядка журналу

Реалізуйте (_static_) метод `LogLevels.message()`, який повертає повідомлення рядка журналу:

```java
LogLevels.message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

Усі пробіли на початку та в кінці потрібно прибрати:

```java
LogLevels.message("[WARNING]:  Disk almost full\r\n")
// => "Disk almost full"
```

## 2. Отримати рівень журналу з рядка

Реалізуйте (_static_) метод `LogLevels.logLevel()`, який повертає рівень журналу рядка журналу; його слід повертати в нижньому регістрі:

```java
LogLevels.logLevel("[ERROR]: Invalid operation")
// => "error"
```

## 3. Переформатувати рядок журналу

Реалізуйте (_static_) метод `LogLevels.reformat()`, який переформатовує рядок журналу: спочатку ставить повідомлення, а потім рівень журналу в дужках:

```java
LogLevels.reformat("[INFO]: Operation completed")
// => "Operation completed (info)"
```
