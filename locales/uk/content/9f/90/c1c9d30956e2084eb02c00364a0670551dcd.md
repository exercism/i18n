# Вступ

Пакет [math/rand][mathrand] надає підтримку для генерування псевдовипадкових чисел.

Ось як згенерувати випадкове ціле число від `0` до `99`:

```go
n := rand.Intn(100) // n is a random int, 0 <= n < 100
```

Функція `rand.Float64` повертає випадкове число з плаваючою комою від `0.0` до `1.0`:

```go
f := rand.Float64() // f is a random float64, 0.0 <= f < 1.0
```

Є також підтримка перемішування масиву (та інших структур даних):

```go
x := []string{"a", "b", "c", "d", "e"}
// shuffling the slice put its elements into a random order
rand.Shuffle(len(x), func(i, j int) {
	x[i], x[j] = x[j], x[i]
})
```

## Початкові значення

Послідовності чисел, які генерує пакет `math/rand`, не є справді випадковими.
Якщо задати конкретне «початкове значення» (англ. seed), результати будуть повністю передбачуваними.

У Go 1.20+ початкове значення обирається випадково автоматично, тож під час кожного запуску програми ми бачитимемо іншу послідовність випадкових чисел.

У попередніх версіях Go початкове значення типово дорівнювало `1`.
Тому, щоб отримувати різні послідовності під час різних запусків програми, потрібно було вручну задати початкове значення для генератора випадкових чисел, наприклад, за поточним часом, перш ніж отримувати будь-які випадкові числа.

```go
rand.Seed(time.Now().UnixNano())
```

[mathrand]: https://pkg.go.dev/math/rand
