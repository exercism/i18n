# Вказівки

Продовжуючи роботу з парком розваг, нам потрібно написати кілька допоміжних методів, які полегшать перевірку, чи може відвідувач скористатися атракціоном.

## 1. Перевірити, чи відвідувач має перепустку на атракціон

Реалізуйте метод `Attendee#has_pass?`, який повертає булеве значення (англ. Boolean, `true`/`false`) залежно від наявності перепустки на атракціон.

```ruby
Attendee.new(100).has_pass?
# => false
```

## 2. Перевірити, чи відвідувач підходить для атракціону

Реалізуйте метод `Attendee#fits_ride?`, щоб визначити, чи відвідувач підходить для атракціону за своїм зростом.
Мінімальний необхідний зріст для атракціону передається як аргумент.
Зріст відвідувача має бути більшим або дорівнювати мінімальному необхідному зросту для атракціону.

```ruby
Attendee.new(140).fits_ride?(100)
# => true
```

## 3. Перевірити, чи відвідувачу дозволено кататися на атракціоні

Реалізуйте метод `Attendee#allowed_to_ride?`, щоб визначити, чи відвідувачу дозволено кататися на атракціоні. Мінімальний необхідний зріст для атракціону передається як аргумент. Відвідувач повинен мати перепустку на атракціон і підходити для атракціону за зростом.

```ruby
attendee = Attendee.new(100)
attendee.issue_pass!(42)
attendee.allowed_to_ride?(120)
# => false
```
