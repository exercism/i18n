# Інструкції

Ми допомагаємо другові створити звіт із вимірювань, які він зробив у різних куточках свого саду.
На жаль, друг зберіг дані в дивному форматі.
Кожне вимірювання складається з полів, розділених комами.
Проте двоцифрові числа він розділив на два стовпці.

| номер поля | значення |
| --- | --- |
| 1 | ідентифікаційний номер |
| 2 | місце |
| 3 | перше вимірювання, десятки |
| 4 | перше вимірювання, одиниці |
| 5 | друге вимірювання, десятки |
| 6 | друге вимірювання, одиниці |

Для вхідного рядка, як-от `101,house,4,2,5,4`
- перше вимірювання - `42`,
- друге вимірювання - `54`.

## Завдання 1: створити звіт

Знайдіть середнє двох вимірювань і виведіть результати кожного рядка в такому форматі:

```none
#<id>, <label> = <average>
```

Оскільки середнє 42 і 54 дорівнює 48, виведення для рядка з прикладу має бути таким:

```none
#101, house = 48
```
