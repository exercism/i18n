# Вступ

Найкорисніші слова для роботи з послідовностями приймають як одні зі своїх вхідних даних *quotation* і використовують його, щоб керувати операцією:

```
each   ( seq quot -- )
map    ( seq quot -- newseq )
filter ( seq quot -- newseq )
reject ( seq quot -- newseq )
count  ( seq quot -- n )
any?   ( seq quot -- ? )
all?   ( seq quot -- ? )
```

```factor
{ 1 2 3 4 5 } [ even? ] filter .   ! => { 2 4 }
{ 1 2 3 4 5 } [ sq ] map .         ! => { 1 4 9 16 25 }
{ 1 2 3 4 5 } [ 2 > ] count .      ! => 3
```

`map-sum` (також у `sequences`) застосовує quotation до всіх елементів послідовності й додає результати за один прохід. Так само працюють `sort-by` (у [`sorting`][sorting]) та `minimum-by` / `maximum-by` (у `sequences`).

[sorting]: https://docs.factorcode.org/content/vocab-sorting.html
