# Вступ

Щоб визначити глобальну функцію в Common Lisp, використовують вираз `defun`.
Першим аргументом цього виразу є список параметрів (порожній список означає, що функція не має параметрів).
Далі йде необовʼязковий рядок документації (див. нижче), а потім нуль або більше виразів, які складають «тіло» функції.

Функції можуть мати нуль або більше параметрів.

```lisp
(defun no-args () (+ 1 1))

(defun add-one (x) (1+ x))

(defun add-nums (x y) (+ x y))
```

Функцію викликають, обчислюючи вираз, першим елементом якого є символ, що позначає цю функцію, а рештою елементів - аргументи функції (якщо вони є).

Значення, до якого обчислюється функція - це значення останнього виразу в тілі функції, який було обчислено.
Усі функції обчислюються до певного значення.

```lisp
(add-nums 2 2) ;; => 4
```

Функції також можуть мати, необовʼязково, рядок документації (його ще називають «docstring»).
Якщо його вказано, він іде після списку аргументів, але перед тілом функції.
До рядка документації можна отримати доступ через `documentation`.

```lisp
(defun add-nums (x y) "Add X and Y together" (+ x y))

(documentation 'add-nums 'function) ;; => "Add X and Y together"

;; Note that if one provides a docstring but fails to provide a body
;; then the docstring is interpreted by Common Lisp as the body, not
;; the docstring
(defun no-body ())
(no-body) ;; => NIL

(defun mistake () "This is not a docstring")
(mistake) ;; => "This is not a docstring"
(documentation 'mistake 'function) ;; => NIL
```
