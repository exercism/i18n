# Вступ

*Купа* - це колекція, яка завжди знає свій найменший елемент і дозволяє швидко його вилучити. Це природна реалізація *черги з пріоритетами*. Купи живуть у словнику [`heaps`][heaps].

`<min-heap>` створює порожню купу, з якої першим виходить найменший ключ; `<max-heap>` - її дзеркальне відображення. Кожен елемент - це *значення*, збережене під *ключем*, а ключ задає пріоритет:

```
<min-heap> ( -- min-heap )
heap-push  ( value key heap -- )
```

```factor
USING: heaps ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
```

Купу можна *змінювати*: `heap-push` змінює її на місці. `heap-peek` повертає перше значення і ключ, не вилучаючи їх, `heap-pop` вилучає їх і повертає, а `heap-pop-all` спорожнює купу в асоціативний список із пар `{ key value }` у порядку пріоритету:

```
heap-peek    ( heap -- value key )
heap-pop     ( heap -- value key )
heap-pop-all ( heap -- alist )
```

```factor
USING: heaps kernel prettyprint ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
dup heap-peek drop .     ! => "bob"
heap-pop-all .           ! => { { 2 "bob" } { 5 "alice" } }
```

[heaps]: https://docs.factorcode.org/content/vocab-heaps.html
