# Тести

Щоб запустити тести із каталогу вправи, виконайте команду:

```sh
odin test .
```

Під час тестування Odin може виконати «vet» для коду: він може шукати такі речі, як невикористані імпорти та змінні. Запустіть тести так:

```sh
odin test . -vet
```

Щоб дізнатися про інші параметри, дивіться `odin test -help`.
