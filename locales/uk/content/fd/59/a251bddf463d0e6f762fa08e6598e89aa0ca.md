# Інструкції

У цій вправі ми будемо писати код, щоб проаналізувати виробництво на конвеєрі автомобільного заводу. Швидкість конвеєра може бути від `0` (вимкнено) до `10` (максимум).

За найнижчої швидкості (`1`) за годину виробляється `221` автомобіль. Виробництво зростає лінійно зі швидкістю. Тож зі швидкістю `4` має вироблятися `4 * 221 = 884` автомобілі на годину. Однак вищі швидкості підвищують імовірність виробництва бракованих автомобілів, які потім доводиться відкидати.

У нас є три завдання.

## 1. Обчисліть показник успішності

Реалізуйте метод `success_rate()`, щоб обчислити частку виробів, створених без помилок, за заданої швидкості. Наступна таблиця показує, як швидкість впливає на показник успішності:

- `0`: показник успішності 0%.
- від `1` до `4`: показник успішності 100%.
- від `5` до `8`: показник успішності 90%.
- `9`: показник успішності 80%.
- `10`: показник успішності 77%.

```R
success_rate(10)
# => 0.77
```

## 2. Обчисліть обсяг виробництва за годину

Реалізуйте метод `production_rate_per_hour()`, щоб обчислити обсяг виробництва конвеєра за годину з урахуванням його показника успішності:

```R
production_rate_per_hour(6)
# => 1193.4
```

Зауважте, що повернене значення має тип `double`.

## 3. Обчисліть кількість придатних виробів, вироблених за хвилину

Реалізуйте метод `working_items_per_minute()`, щоб обчислити, скільки придатних автомобілів виробляється за хвилину:

```R
working_items_per_minute(6)
# => 19
```

Зауважте, що повернене значення є цілим числом: незавершені вироби не враховуються.
