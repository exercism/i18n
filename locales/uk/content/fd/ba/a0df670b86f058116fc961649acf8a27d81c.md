# Інструкції

У цій вправі ми опрацьовуватимемо рядки журналу.

Кожен рядок журналу - це рядок тексту (англ. string) такого формату: `"[<LEVEL>]: <MESSAGE>"`.

Є три різні рівні журналювання:

- `INFO`
- `WARNING`
- `ERROR`

На нас чекають три завдання: у кожному ми беремо рядок журналу і щось із ним робимо.

## 1. Отримати повідомлення з рядка журналу

Реалізуйте функцію `message()`, щоб вона повертала повідомлення з рядка журналу:

```haxe
message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

Будь-які пробіли на початку чи в кінці потрібно прибрати:

```haxe
message("[WARNING]:  Disk almost full\r\n")/ => "Disk almost full"
```

## 2. Отримати рівень журналювання з рядка журналу

Реалізуйте функцію `logLevel()`, щоб вона повертала рівень журналювання рядка журналу, причому в нижньому регістрі:

```haxe
logLevel("[ERROR]: Invalid operation")
// => "error"
```

## 3. Переформатувати рядок журналу

Реалізуйте функцію `reformat()`, яка переформатовує рядок журналу так, щоб повідомлення стояло першим, а рівень журналювання йшов після нього в дужках:

```haxe
reformat("[INFO]: Operation completed")
// => "Operation completed (info)"
```
