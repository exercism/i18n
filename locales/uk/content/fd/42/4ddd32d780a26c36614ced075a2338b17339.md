# Інструкції

Ми великі шанувальники [YouTube-каналу Numberphile](https://www.youtube.com/watch?v=PeUbRXnbmms) й щойно побачили круте відео про _послідовність чисел Лукаса_. Ми хочемо створити цю послідовність за допомогою Elixir.

Розробляючи функцію, хочемо скористатися _лінивим обчисленням_, щоб генерувати скільки завгодно чисел, але лише за потреби. Тож вирішуємо використати потік.

## 1. Перехопіть неправильні аргументи

Додайте захисну клаузу, щоб виникала помилка, якщо для генерації послідовності використано неціле число або ціле число, менше ніж 1. Якщо зробити це першим кроком, це запобіжить помилкам нескінченної рекурсії на наступних кроках.

```elixir
LucasNumbers.generate("Hello World")
# => ** (ArgumentError) count must be specified as an integer >= 1
```

## 2. Згенеруйте базові випадки

Ми знаємо, що послідовність має два початкові числа, які не підкоряються тому самому правилу. Напишіть дві клаузи базових випадків, щоб повернути ці числа:

```elixir
LucasNumbers.generate(1)
# => [2]

LucasNumbers.generate(2)
# => [2, 1]
```

## 3. Створіть узагальнений випадок

Для будь-якої послідовності довшої за 2 ми знаємо, що треба додати два попередні числа, щоб отримати наступне число, і так далі. Напишіть узагальнений випадок.

```elixir
LucasNumbers.generate(3)
# => [2, 1, 3]

LucasNumbers.generate(4)
# => [2, 1, 3, 4]
```
