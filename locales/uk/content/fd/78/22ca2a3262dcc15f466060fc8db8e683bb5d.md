# Вступ

У Swift є набір інструкцій, які можна використати, щоб змінити звичайний потік керування циклами.
Їх називають інструкціями передачі керування.
Ми вже бачили `return`; у цій концепції ми познайомимося з іншими, до яких належать `continue`, `break` і мітки.
`fallthrough` у цій концепції ми не розглядатимемо, але про нього можна прочитати в [книзі Swift][fallthrough].

## Continue

Іноді потрібно достроково перейти до наступної ітерації циклу, не виконавши решту інструкцій поточної ітерації циклу.
Для цього можна використати ключове слово `continue`.
Коли виконується `continue`, цикл переходить до наступної перевірки, чи можна виконати наступну ітерацію, тобто до `while` у циклі `while` і циклі `repeat-while` або до перевірки, чи є в послідовності ще один елемент, у циклі `for-in`.

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

## Break

Break використовується, щоб достроково вийти з циклу.
Коли виконується `break`, цикл негайно завершується, і програма продовжує з першої інструкції після циклу.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

## Мітки

Коли цикли вкладені, буває потрібно використати `break` або `continue`, щоб вийти із зовнішніх циклів, які містять цикл, у якому використано `break` чи `continue`, або перезапустити їх.
У таких випадках можна використати мітки, щоб указати цикл, з якого треба вийти або який треба перезапустити.
Цикл можна позначити міткою, поставивши імʼя, а потім двокрапку, перед `while`, `repeat` або `for`, які починають цикл.

Щоб побачити ефект від такого використання міток, розгляньмо такий цикл.

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```
