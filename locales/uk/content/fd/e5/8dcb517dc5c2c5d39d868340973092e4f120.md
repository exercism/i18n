# Вступ

У Go константа - це просте незмінне значення, яке привʼязують до імені за допомогою ключового слова `const`:

```go
const myWebsite = "Exercism"
```

Такі константи не мають типу, але коли тип потрібен, їм надають типовий тип на основі їхнього синтаксису, наприклад, коли їх передають методу.
Типізовані константи можна створити, явно вказавши тип:

```go
const myWebsite string = "Exercism"
```

У Go немає переліків, як у деяких інших мовах, але є наперед оголошений ідентифікатор `iota` для створення перелічуваних констант.
Константи в блоці неявно повторюються:

```go
const (
    a = 9
    b
    c
    d = iota
    e
    f
    g
)
fmt.Print(a, b, c, d, e, f, g)
// Output: 9 9 9 3 4 5 6
```
