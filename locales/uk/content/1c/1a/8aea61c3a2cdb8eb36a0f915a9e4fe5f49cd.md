# Інструкції

Піфагорова трійка - це набір із трьох натуральних чисел, {a, b, c}, для яких

```text
a² + b² = c²
```

і таких, що

```text
a < b < c
```

Наприклад,

```text
3² + 4² = 5².
```

Для заданого вхідного цілого числа N знайдіть усі піфагорові трійки, для яких `a + b + c = N`.

Наприклад, для N = 1000 існує рівно одна піфагорова трійка, для якої `a + b + c = 1000`: `{200, 375, 425}`.
