# Інструкції

У цій вправі ми будемо писати код, щоб відстежувати міжнародні телефонні коди за допомогою хеш-мапи міжнародних телефонних кодів.

У цій мапі як ключі використовуються цілі числа (телефонний код), а як значення - рядок тексту (англ. string), а саме назва країни.

На нас чекає 11 завдань, що стосуються телефонних кодів.

## 1. Створити попередньо заповнену хеш-мапу

Існує попередньо заповнена хеш-мапа, яка містить такі 3 телефонні коди: «United States of America» з кодом 1, «Brazil» з кодом 55 та «India» з кодом 91. Визначте змінну `countries`, щоб зберегти цю попередньо заповнену хеш-мапу:

```clojure
countries
;;=> {1 "United States of America", 55 "Brazil", 91 "India"}
```

## 2. Додати країну до мапи

Додайте «United Kingdom» з телефонним кодом 44 до мапи, створеної в завданні 1:

```clojure
(add-country countries 44 "United Kingdom")
;;=> {1 "United States of America", 44 "United Kingdom", 55 "Brazil", 91 "India"}
```

## 3. Отримати назву країни за кодом країни

Отримайте назву країни з телефонним кодом 55

```clojure
(country-name countries 55)
;;=> "Brazil"
```

## 4. Оновити назву країни

Змініть назву «United States of America» на «Les États-Unis»:

```clojure
(update-map countries 1 "Les États-Unis")
;;=> {1 "Les États-Unis", 55 "Brazil", 91 "India"}
```

## 5. Перевірити, чи є країна в мапі

Перевірте, чи існує в мапі, створеній у завданні 1, запис для країни Brazil

```clojure
(code-exists? countries 55)
;;=> true
```

## 6. Спробувати оновити назву країни, якої немає в мапі

Спробуйте змінити назву країни з кодом, якого немає в мапі, наприклад 999. Це не повинно призвести до жодних змін у мапі:

```clojure
(update-map countries 999, "Newlands")
;;=> {1 "United States of America", 44 "United Kingdom", 55 "Brazil", 91 "India"}
```

## 7. Видалити країну з мапи

Видаліть із мапи країну India:

```clojure
(remove-country countries 91)
;;=> {1 "United States of America", 55 "Brazil"}
```

## 8. Знайти країну з найдовшою назвою

Опрацюйте значення в мапі, щоб знайти те, у якого найдовша назва:

```clojure
(longest-name countries)
;;=> "United States of America"
```
