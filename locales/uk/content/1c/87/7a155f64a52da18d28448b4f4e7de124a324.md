# Додаток до інструкцій

## Бонус

Перевірте свою функцію на цьому рядку тексту (англ. string): `uüu` і подивіться, що станеться.
Спробуйте написати функцію, яка правильно перевертає цей рядок тексту.
Підказка: графемні кластери

Щоб запустити бонусний тест, приберіть прапорець ignore (`#[ignore]`) з останнього тесту та виконайте тести командою:

```bash
cargo test --features grapheme
```

Для бонусного завдання нам знадобляться зовнішні бібліотеки (у термінології Rust це `crate`).
Гарне місце, де їх шукати, це [crates.io](https://crates.io/), офіційний репозиторій крейтів.
Памʼятайте, що наш засіб запуску тестів підтримує лише обмежений набір крейтів.
Повний список наведено в [цьому файлі](https://github.com/exercism/rust-test-runner/blob/main/local-registry/Cargo.toml) у розділі `[dependencies]`.

[Перегляньте документацію](https://doc.rust-lang.org/cargo/guide/dependencies.html), щоб дізнатися, як використовувати зовнішні крейти у своїх проєктах.
