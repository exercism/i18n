# Вступ

Тип `char` у F# - це 16-бітне значення, яке представляє найменші адресовані компоненти тексту; типово незмінний.

Символи `char` можна визначати як літерали в одинарних лапках:

```fsharp
let ch = 'A'
// => val ch: char = 'A'
```

Рядки тексту (англ. string) - це послідовність символів `char`.

Окремий символ `char` можна дістати з рядка тексту за допомогою індексації (з відліком від нуля):

```fsharp
"Exercism"[4] //  =>  'c'
```

Перебираючи рядок тексту, на кожному кроці отримуємо символ `char`.

Наступний приклад для зручності використовує функцію вищого порядку та анонімну функцію.
Докладно про них розповімо далі в силабусі, а поки що це стислий спосіб записати цикл по символах у рядку тексту.

```fsharp
Seq.map (fun c -> c, int c) "F#"  //  =>  [('F', 70); ('#', 35)]
```

Як показано вище, `char` можна привести до його значення `int`.
Це також працює (*принаймні іноді*) і для інших письменностей:

```fsharp
Seq.map (fun c -> c, int c) "東京"  //  =>  [('東', 26481); ('京', 20140)]
```

Під час порівняння символів використовується базовий тип Int16:

```fsharp
'A' < 'D'  // =>  true
```

Також `int` можна привести до `char`:

```fsharp
char 77  // => 'M'
```

Бібліотека `System.Char` містить повний набір методів, які очікуються від мови .NET, як-от перетворення до верхнього й нижнього регістру:

```fsharp
'a' |> System.Char.ToUpper  // =>  'A'

'Q' |> System.Char.ToLower  // =>  'q'
```
