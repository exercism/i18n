# Докладніше

[Nil][nil-dictionary] - це англійське слово, що означає «ніщо» або «нуль». В Elixir `nil` - особливе значення, яке означає _відсутність_ значення.

```elixir
# I do not have a favorite color
favorite_color = nil
```

`nil` належить до атомів, але його зазвичай записують як `nil`, а не `:nil`. Булеві значення (англ. Boolean) `true` і `false` теж є атомами.

[//]: # (elixir-formatter-disable-next-block)

```elixir
nil === :nil
# => true

true === :true
# => true
```

Перевірити, чи значення змінної дорівнює `nil`, можна за допомогою [`==`][kernel-equal], зіставлення зі зразком або ґарда [`is_nil`][kernel-is-nil].

```elixir
def call(phone_number) do
  if phone_number == nil do
    :error
  end
end
```

```elixir
def call(phone_number) when is_nil(phone_number) do
  :error
end
```

```elixir
def call(nil) do
  :error
end
```
