# Вступ

**Рекурсивні функції** - це функції, які викликають самі себе.

_Рекурсивна функція_ повинна мати щонайменше один _базовий випадок_ і щонайменше один _рекурсивний випадок_.

**Базовий випадок** повертає значення, не викликаючи функцію знову.
**Рекурсивний випадок** викликає функцію знову, змінюючи вхідні дані так, щоб вони колись збіглися з базовим випадком.

Ось приклад, який рахує елементи масиву.

```jq
def count:
  if length == 0 then
    0                       # base case
  else
    1 + (.[1:] | count)     # recursive case
  end;

([] | count),           # => 0
([11, 22, 33] | count)  # => 3
```

_Рекурсивна функція_ може мати багато _базових випадків_ та/або багато _рекурсивних випадків_.
Наприклад, [послідовність Фібоначчі][wiki-fibonacci] є рекурсивною послідовністю з двома _базовими випадками_.

```jq
def fibonacci:
  if . == 0 then
    0
  elif . == 1 then
    1
  else
    (. - 1 | fibonacci) + (. - 2 | fibonacci)
  end;

10 | fibonacci          # => 55
```

Підрахунок кількості входжень певного заданого значення `x` у масиві має два _рекурсивні випадки_.

```jq
def count_occurrences(x):
  if length == 0 then
    0
  elif first == x then
    1 + (.[1:] | count_occurrences(x))
  else
    (.[1:] | count_occurrences(x))
  end;

[11, 22, 33, 22, 44] | count_occurrences(22)    # => 2
```

На практиці перебирання елементів масивів та інших перелічуваних структур даних найчастіше виконують за допомогою вбудованих функцій, як-от `map` і `reduce`, або [використовуючи потоки][map-implementation], як `[.[] | select(...)]`.
Під капотом деякі вбудовані функції [реалізовано за допомогою рекурсії][walk-implementation].
