# Доповнення до інструкцій

## Хвилинку, це неможливо!

Реалізувати ці операції зі списками, не використавши _жодної_ вбудованої функції, у Roc практично неможливо, бо для цього потрібен спосіб додавати елементи на початок або в кінець списку.
В інших мовах можна було б скористатися операторами на кшталт `:` у Haskell або `+=` у Python, але в Roc доведеться використовувати [функції `List`](https://www.roc-lang.org/builtins/main/#Builtin.List).

Тож у цій вправі дозволено використовувати `List.append` (але уникаймо будь-яких інших вбудованих функцій).

Багато функціональних мов програмування використовують звʼязні списки як основний тип колекції.
Додати елемент на початок або вилучити перший елемент зі звʼязного списку ефективно, тож у таких мовах операції зі списками реалізують через `List.prepend`.
У Roc ж `List` - це масив (безперервна ділянка байтів).
Масиви мають інші властивості, ніж звʼязні списки, як-от здатність ефективно звертатися до елементів за індексом і додавати нові елементи.
Через це в Roc ми часто використовуємо `List.append` і рідко вживаємо `List.prepend`.

## Іменування

У Roc назви трохи відрізняються від тих, що наведені в загальних інструкціях:

- `concat` замість `append`
- `join` замість `concatenate`
- `len` замість `length`
- `fold` замість `foldl`
- `fold_rev` замість `foldr`

Водночас у Roc стандартними є такі назви функцій:
- `filter`
- `map`
- `reverse`

## Підказка

Спробуймо використати:

```roc
match list {
    [] => ...
    [first, .. as rest] => ...
}
```

або

```roc
match list {
    [] => ...
    [.. as rest, last] => ...
}
```
