# Інструкції

Наш японський друг Куроко працює стрімером і має міжнародну популярність.
Розклад стрімів Куроко досить заплутаний: здається, кожен стрім щодня починається в різний час.

Він просить допомогти створити невеликий застосунок, який буде показувати його розклад у місцевих часових поясах глядачів: Годинник Куроко.
У нього є додаткова вимога: застосунок має вміти показувати час двома різними мовами: японською та англійською (США).

## 1. Це дата

Визначте функцію `showLocalDate : Locale -> Int -> Month -> Int -> String`, яка відображатиме (дійсну) місцеву дату.

У локалі `US` формат буде `Month/Day/Year` без провідних нулів.

У локалі `JP` формат буде `Year年Month月Day日`, також без провідних нулів.

```elm
showLocalDate US 2025 May 1
    -- "5/1/2025"
showLocalDate JP 2025 May 1
    -- "2025年5月1日"
```

## 2. Час показу

Визначте функцію `showLocalTime : Locale -> Int -> Int -> String`, яка відображатиме (дійсний) місцевий час.

У локалі `US` години буде показано у 12-годинному форматі разом із «PM» або «AM», а хвилини буде показано з провідними нулями.

У локалі `JP` годину буде показано у 24-годинному форматі перед «時», а хвилини буде показано без провідних нулів перед «分».

```elm
showLocalTime US 13 8
    -- "1:08 PM"
showLocalTime JP 13 8
    -- "13時8分"
```

## 3. Увійдіть у зону

Визначте функцію `showDateTime : Locale -> Zone -> Posix -> String`, яка відображатиме дату й час відносно часового поясу в певній локалі.

Використайте `showLocalDate` та `showLocalTime`, щоб відобразити остаточний результат.

```elm
showDateTime US Time.utc (Time.millisToPosix 0)
    -- "1/1/1970 12:00 AM"
showDateTime JP Time.utc (Time.millisToPosix 0)
    -- "1970年1月1日0時0分"
```
