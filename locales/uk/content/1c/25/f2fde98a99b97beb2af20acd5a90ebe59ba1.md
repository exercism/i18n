# Вступ

Часто буває корисно зібрати набір елементів докупи й працювати з такими групами як з єдиним цілим. У Cairo таку групу ми називаємо struct, а кожен елемент - одним із полів цього struct. Struct визначає загальний набір доступних полів, а конкретний приклад struct називається екземпляром.

Крім того, для struct можна визначити методи, які мають доступ до полів. Сам struct у такому разі позначають як `self`. Коли метод використовує `ref self: SomeStruct`, поля можна змінювати, тобто мутувати. Коли метод використовує `self: SomeStruct` або `self: @SomeStruct`, поля змінити не можна: вони незмінні. Контроль над змінністю допомагає borrow checker гарантувати, що цілі класи помилок конкурентності у Cairo просто не трапляються.

У цій вправі ми реалізуємо два різновиди методів для struct. Перший зазвичай називають гетерами: вони показують поля struct назовні, не дозволяючи будь-кому іншому змінювати це значення.

Ми також реалізуємо методи іншого типу, які зазвичай називають сетерами. Вони змінюють значення поля. Сетери в Cairo не надто поширені: якщо поле можна вільно змінювати, його зазвичай просто роблять публічним. Але вони стануть у пригоді, якщо оновлення поля має спричиняти побічні ефекти.

Struct визначають за допомогою ключового слова `struct`, після якого йде назва типу з великої літери, який цей struct описує:

```rust
struct Item {}
```

Далі до тіла struct додають додаткові типи як _поля_ struct, кожне зі своїм типом:

```rust
struct Item {
    name: String,
    weight: f32,
    worth: u32,
}
```

Trait визначає набір методів, які може реалізувати тип (тут ми зосередимося на struct, але trait можна реалізувати і для enum). Ці методи можна викликати на екземплярах типу, коли цей trait реалізовано. Trait визначають за допомогою ключового слова `trait`, і всередині trait ми визначаємо сигнатури методів, які хочемо, щоб реалізував наш тип.

```rust
trait ImplTrait {
    // Define the method signature
    fn new() -> Item;
}
```

І нарешті, методи можна визначати для struct усередині блоку `impl`, який реалізує визначений trait:

```rust
impl ItemImpl of ImplTrait {
    // initializes and returns a new instance of our Item struct
    fn new() -> Item {
        Item {}
    }
}
```
