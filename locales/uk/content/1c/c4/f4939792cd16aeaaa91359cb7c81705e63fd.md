# Інструкції

Ми завзяті спостерігачі птахів і відстежуємо, скільки птахів відвідало наш сад за останні сім днів.

На нас чекає пʼять завдань, і всі вони стосуються кількості птахів, що відвідали наш сад.

## 1. Перевірмо, якими були підрахунки минулого тижня

Ми зберігаємо підрахунки птахів у форматі JSON.
«Головний» масив зберігає масиви тижневих підрахунків.
Кожен тижневий підрахунок - це масив із семи цілих чисел, по одному числу на кожен день тижня.
Ми завжди додаємо нові тижні в кінець головного масиву.
Реалізуйте фільтр, який повертає підрахунки за минулий тиждень.

```sh
$ cat bird-counting-data.json
[
  ...,
  [0, 2, 5, 3, 7, 8, 4],
  [4, 5, 9, 10, 9, 4, 3]
]

$ jq -f bird-count.jq < bird-counting-data.json
{
  "last_week": [0, 2, 5, 3, 7, 8, 4],
  ...
```

## 2. Перевірмо, скільки птахів відвідало сад учора

Реалізуйте фільтр, який повертає кількість птахів, що відвідали наш сад учора.
Підрахунки птахів упорядковано за днями: перший елемент - кількість за найдавніший день, а останній - сьогоднішня кількість.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "yesterday": 4,
  ...
```

## 3. Порахуймо загальну кількість птахів, що прилетіли

Реалізуйте фільтр, який повертає загальну кількість птахів, що відвідали наш сад цього тижня.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "total": 44,
  ...
```

## 4. Порахуймо кількість насичених днів

Деякі дні насиченіші за інші.
Насичений день - це день, коли до нашого саду відвідало пʼять або більше птахів.
Реалізуйте фільтр, який повертає кількість насичених днів цього тижня.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "busy_days": 4,
  ...
```

## 5. Перевірмо, чи був день, коли птахи не прилітали

Реалізуйте фільтр, який повертає `true`, якщо цього тижня був хоч один день, коли до саду не прилетів жоден птах; інакше поверніть `false`.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "has_day_without_birds": false
}
```
