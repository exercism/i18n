# Додаток до вказівок

## Переваги та недоліки `from_quote`

Функція `DateOfBirth.from_quote` розбирає рядок тексту (англ. string) у форматі `"YYYY-MM-DD"` у значення типу `DateOfBirth`.
Це дає змогу писати такий код:

```roc
birthdate : DateOfBirth
birthdate = "2019-01-20"
```

Цей код неявно викликає `DateOfBirth.from_quote("2019-01-20")` під час компіляції. Це може пришвидшити програму, адже розбір не потрібно виконувати під час роботи програми, а також гарантує, що дати, відхилені `from_quote`, буде виявлено під час компіляції, а не під час виконання. До того ж код стає гарним і читабельним. Наприклад, ось один із тестів цієї вправи:

```roc
# multiple birthdates with one shared birthday
expect {
	shared_birthday(["1966-07-29", "1977-02-12", "2001-07-29", "1980-11-10"])
}
```

Однак той, хто читає цей код, може припустити, що функція `shared_birthday` приймає `List(Str)`, тоді як насправді вона приймає `List(DateOfBirth)`. Це може призводити до плутанини та помилок. Тому ми можемо віддати перевагу трохи довшому, але явнішому формату: `"2019-01-20".DateOfBirth`, який також викликає `from_quote` під час компіляції.

У власних програмах ми можемо створити зручний конструктор, наприклад такий:

```roc
DateOfBirth := { year : I64, month : U8, day : U8 }.{
    from_ymd : I64, U8, U8 -> Try(DateOfBirth, [InvalidMonth, InvalidDay])
    from_ymd = |year, month, day| ...
}
```

Цей конструктор також можна викликати під час компіляції, ось так:

```roc
Ok(birthdate) = DateOfBirth.from_ymd(2019, 1, 20)
```

Примітка: розміщення цього визначення на верхньому рівні змушує його виконуватися під час компіляції (адже функція чиста, а вхідні дані відомі під час компіляції). Усередині функції той самий конструктор можна використати під час виконання.

## Бібліотека Random

Пакунок [`roc-random`](https://github.com/kili-ilo/roc-random) доступний у тестовому застосунку з псевдонімом `random`.
У заготовці імпортовано `random.Random`.

## Підказки

<details>
<summary>Показати підказки</summary>

`Random.Generator(a)` описує, як згенерувати значення типу `a`.
Поєднаймо вибірки за допомогою `Random.list`, а їхні результати перетворімо за допомогою `Random.map`.
`Random.step(state, generator)` повертає `{ value, state }`; переносимо оновлений стан між симульованими групами, щоб не повторювати ту саму вибірку.

</details>
