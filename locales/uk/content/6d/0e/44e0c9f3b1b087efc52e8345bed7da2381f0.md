# Докладніше

Хоча Swift містить чимало функціональності у своїй Стандартній бібліотеці, значно більше функціональності доступне у вигляді зовнішніх бібліотек.
Ці бібліотеки можуть походити від самого проєкту Swift, як-от [Swift Argument Parser][argument-parser], бути закритими бібліотеками від компаній, як-от [Network Framework][network-framework] від Apple, або сторонніми бібліотеками, як [Swifty Beaver][swifty-beaver].

Деякі з цих модулів, як-от Network Framework або [Foundation][apple-foundation] (мабуть, найуживаніша бібліотека у Swift), уже входять до дистрибутива Swift.
Зовнішні сторонні бібліотеки потрібно спершу додати до проєкту, перш ніж їх можна буде імпортувати, хоча це виходить за межі цієї вправи.

Щоб імпортувати модуль, треба написати ключове слово `import`, а потім назву модуля. Тож, щоб імпортувати Foundation, достатньо додати до своєї програми таке.

```swift
import Foundation
```

Це відкриває доступ до всіх типів, значень і функціональності всередині цього модуля; наприклад, якщо потрібно скористатися методом `components(separatedBy:)` типу `String`, то з цим імпортом він стає доступним для `String`.

Хоча інструкції імпорту можна розміщувати будь-де в коді перед тим фрагментом, який використовує щось із вмісту модуля, зазвичай їх ставлять на початку файлу, що їх використовує, задля кращої читабельності.

[argument-parser]: https://apple.github.io/swift-argument-parser/documentation/argumentparser/
[network-framework]: https://developer.apple.com/documentation/network
[swifty-beaver]: https://github.com/SwiftyBeaver/SwiftyBeaver
[apple-foundation]: https://developer.apple.com/documentation/foundation
