# Вступ

## IO

Функції для обробки введення та виведення надає модуль `IO`.

### Виведення

Щоб записати рядок тексту (англ. string) у стандартний вивід, скористаймося функцією `IO.puts`. `IO.puts` завжди додає новий рядок у кінці рядка тексту. Якщо така поведінка не потрібна, скористаймося функцією `IO.write`. Обидві функції в разі успіху повертають атом `:ok`.

```elixir
IO.puts("Hi!")
# > Hi!
# => :ok
```

`IO.puts` стає в пригоді для запису рядків тексту, але не для чогось іншого. Якщо нам потрібен інструмент для налагодження, який дасть змогу записати будь-яке значення у стандартний вивід, скористаймося функцією `IO.inspect`. `IO.inspect` повертає передане йому значення без змін, тож його можна вставити в будь-якому місці коду. Він також приймає багато опцій, наприклад `:label`, які дають змогу відрізнити його від інших викликів `IO.inspect`.

### Введення

Щоб прочитати рядок зі стандартного введення, скористаймося функцією `IO.gets`. `IO.gets` приймає один аргумент: рядок тексту, який буде надрукований як запрошення до введення. `IO.gets` не додає нового рядка після запрошення; додаймо його самі, якщо потрібно.

```elixir
IO.gets("What's your name?\n")
# > What's your name?
# < Mary
# => "Mary\n"
```
