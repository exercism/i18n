# Доповнення до інструкцій

## Створімо власний DSL

У цій вправі ми цілком вільні спроєктувати графовий DSL своєї мрії.

Можливо, нам захочеться створити DSL на основі списків тегів і записів, ось так:

```roc
my_graph =
    Graph.new([
        Title("My Graph"),
        Node("a", { color: Green }),
        Node("b", { color: Blue }),
        Edge("a", "b", { style: Dotted }),
    ])
```

Або, можливо, нам більше до вподоби DSL на основі ланцюжків викликів функцій, ось так:

```roc
my_graph =
    Graph.new
        .with_title("My Graph")
        .add_node("a", Attr.new.with_color(Green))
        ...
```

А може, у нас зовсім інший план? Тож берімося! Тести вимагають лише створити кілька конкретних графів, а як ми їх будуємо, цілком залежить від нас.

Утім, DSL зазвичай кращий, якщо він зрозумілий, лаконічний і не надто несподіваний (наприклад, функція `minus` призначена для віднімання, а не для побудови ребра між двома вузлами, як у `node("a") - node("b")`).

Щоб подвоїти задоволення, можемо за бажанням спробувати реалізувати функцію `to_dot`, яка перетворює наш граф на формат DOT!
