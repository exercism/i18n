# не використовуйте функції для масивів

Будь ласка, не використовуйте жодних зовнішніх модулів (як-от `List`, `Enum` чи `Stream`) у своєму рішенні. Мета цієї вправи - створити ці базові функції самостійно. Можете використовувати базові функції `Kernel` (як-от `Kernel.+/2` для додавання чисел), але, будь ласка, не використовуйте функції `Kernel` для масивів, як-от `++`, `--`, `hd`, `tl`, `in`, `for` та `length`.
