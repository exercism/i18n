# Ресурси

* [The Rust Programming Language](https://doc.rust-lang.org/book/) - чудовий ресурс як для знайомства з Rust, так і для глибшого занурення в окремі можливості мови.
* [Rust by Example](https://doc.rust-lang.org/stable/rust-by-example/) показує приклади найпоширеніших речей, які ми писатимемо мовою Rust.
* [Rust API Documentation](http://doc.rust-lang.org/std/) можна використовувати, щоб відкривати для себе нові методи та дізнаватися, як вони працюють.
* [Stack Overflow](http://stackoverflow.com/questions/tagged/rust) можна використовувати, щоб пошукати свою проблему й подивитися, чи на неї вже відповіли. Там також можна ставити запитання й відповідати на них.
* [Rust User Forum](http://users.rust-lang.org) - це місце для загального обговорення Rust.
* [/r/rust](http://www.reddit.com/r/rust/) - офіційний сабредіт Rust.
* Офіційний сервер [The Rust Programming Language](https://discord.gg/rust-lang) у [Discord](https://discordapp.com/) можна використовувати для швидких запитань і обговорень цієї мови.
