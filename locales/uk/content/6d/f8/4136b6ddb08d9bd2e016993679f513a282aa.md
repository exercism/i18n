# Навчання

## Початок роботи з Emacs

Отже, Emacs установлено. Що далі?

Ну що ж, можна почати туторіал, натиснувши `C-h t`, і це непогане місце для початку. Туторіал навчить основам редагування, пошуку та навігації в Emacs.

Якщо Emacs для нас зовсім новий, має сенс узяти стартовий набір, у якому вже налаштовано набір конфігурацій і пакунків.

Пакунок [Emacs Prelude](http://batsov.com/prelude/) пропонує вдалий набір розумних типових налаштувань і пакунків.

Щоб установити Emacs Prelude, виконайте в терміналі таку команду:

```
curl -L https://github.com/bbatsov/prelude/raw/master/utils/installer.sh | sh
```

і обовʼязково перегляньте [посібник зі встановлення](https://prelude.emacsredux.com/en/latest/installation/), щоб дізнатися більше.


Якщо ми вже знайомі з vim, може зацікавити стартовий набір [Doom Emacs](https://github.com/doomemacs/doomemacs), який інтегрує емуляцію vim на базі [evil-mode](https://github.com/emacs-evil/evil).

Щоб установити Doom Emacs, виконайте в терміналі таке:

```
git clone --depth 1 https://github.com/doomemacs/doomemacs ~/.emacs.d
~/.emacs.d/bin/doom install
```

і обовʼязково перегляньте [посібник зі встановлення](https://github.com/doomemacs/doomemacs#install), щоб дізнатися більше.

## Налаштування перевірки синтаксису та лінтингу

Радимо налаштувати перевірку синтаксису та лінтинг за допомогою [Flycheck](https://www.flycheck.org/en/latest/).

Якщо репозиторій [MELPA](https://melpa.org/) ще не додано до Emacs, додайте до [init-файлу](https://www.flycheck.org/en/latest/glossary.html#term-init-file) таке:

```elisp
(require 'package)

(add-to-list 'package-archives
             '("MELPA Stable" . "https://stable.melpa.org/packages/") t)
(package-initialize)
(package-refresh-contents)
```

Щоб установити й налаштувати Flycheck без [use-package](https://github.com/jwiegley/use-package), додайте до [init-файлу](https://www.flycheck.org/en/latest/glossary.html#term-init-file) таке:

```elisp
(package-install 'flycheck)
(add-hook 'after-init-hook #'global-flycheck-mode)
```

Щоб установити й налаштувати Flycheck з [use-package](https://github.com/jwiegley/use-package), додайте до [init-файлу](https://www.flycheck.org/en/latest/glossary.html#term-init-file) таке:

```elisp
(use-package flycheck
  :ensure t
  :init (global-flycheck-mode))
```

Докладнішу інформацію та поради щодо розвʼязання проблем шукайте в [документації Flycheck](https://www.flycheck.org/en/latest/user/troubleshooting.html).

## Вивчення Emacs Lisp

Найкраща документація з Emacs Lisp... постачається разом із самим Emacs!
Щоб відкрити
[Emacs Lisp Reference](https://www.gnu.org/software/emacs/manual/elisp.html),
наберіть `C-h i` і знайдіть розділ Elisp або виберіть Help &rarr; More Manuals
&rarr; Emacs Lisp Reference.  Зауважте, що в деяких дистрибутивах посібник може
бути відсутній, і тоді його можна знайти
[онлайн](https://www.gnu.org/software/emacs/manual/elisp.html).

Якщо ми зовсім не знайомі з Elisp, можна прочитати
[Introduction to Emacs Lisp](http://www.emacswiki.org/emacs/EmacsLispIntro),
який відкривається так само.

## Найкращі практики та домовленості Emacs Lisp

Посібник Emacs містить розділ про [Coding Conventions](https://www.gnu.org/software/emacs/manual/html_node/elisp/Coding-Conventions.html) для Emacs Lisp.
Є також [Style Guide](https://github.com/bbatsov/emacs-lisp-style-guide), який підтримує спільнота на GitHub.
