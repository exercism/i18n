# Встановлення

## Встановлення .NET

Трек C# побудовано на платформі [.NET](https://dotnet.microsoft.com/learn/dotnet/what-is-dotnet), яка працює на Windows, Linux та macOS.
Щоб збирати проєкти .NET, можна скористатися інтерфейсом командного рядка .NET (CLI).
Цей CLI є частиною .NET SDK, який можна встановити, дотримуючись [інструкцій зі встановлення](https://dotnet.microsoft.com/download/dotnet/8.0).
Примітка: трек C# потребує SDK версії 9.0 або новішої.

Після завершення встановлення можна перевірити, чи CLI встановлено успішно, виконавши цю команду в терміналі:

```bash
dotnet --version
```

Якщо виведення є версією, більшою або рівною `9.0.100`, то .NET SDK встановлено успішно.

## Використання IDE

Якщо ми хочемо повноціннішого досвіду редагування, ймовірно, варто скористатися [IDE або інтегрованим середовищем розробки)](https://en.wikipedia.org/wiki/Integrated_development_environment).
Це найпопулярніші IDE, які підтримують збирання проєктів .NET:

- [Visual Studio 2022](https://www.visualstudio.com/downloads/)
- [Visual Studio Code](https://code.visualstudio.com/download) з [C# extension](https://marketplace.visualstudio.com/items?itemName=ms-dotnettools.csharp)
- [Visual Studio for Mac](https://www.visualstudio.com/vs/visual-studio-mac/)
- [Project Rider](https://www.jetbrains.com/rider/download/)

Примітка: оскільки формат проєкту .NET значно відрізняється від попередніх версій, старіші IDE (як-от Visual Studio 2015) не підтримуються.
