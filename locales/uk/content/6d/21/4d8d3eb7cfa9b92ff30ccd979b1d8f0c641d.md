# Вступ

У Gleam є два різні види чисел: цілі числа та числа з плаваючою комою.

Цілі числа не мають дробової частини.

```gleam
let integer = 3
// -> 3
```

Gleam має кілька операторів, які працюють із цілими числами.

```gleam
1 + 1 // -> 2
5 - 1 // -> 4
5 / 2 // -> 2
3 * 3 // -> 9
5 % 2 // -> 1

2 > 1  // -> True
2 < 1  // -> False
2 >= 1 // -> True
2 <= 1 // -> False
```
