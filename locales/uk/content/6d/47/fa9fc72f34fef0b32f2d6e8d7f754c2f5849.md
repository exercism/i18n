# Встановлення

Рішення на цьому треку пишуть мовою асемблера 32-бітної архітектури RISC-V, і вони працюють в емуляції, тож обладнання RISC-V не потрібне.
Кожна вправа постачається з Makefile, який збирає тести й запускає їх.
Щоб цим скористатися, потрібні три інструменти:

- [Zig][zig], який через `zig cc` надає асемблер RISC-V, а також компілятор і компонувальник C.
- [Make][make], який виконує збірку.
- `qemu-riscv32` із [QEMU][qemu], який запускає отриману програму.

## macOS

Запустіть віртуальну машину з Linux, скориставшись будь-яким придатним рішенням для віртуалізації (наприклад, [Lima][lima]), і виконайте кроки з відповідного розділу про дистрибутив Linux нижче.

## Windows

Скористайтеся [Windows Subsystem for Linux][wsl] і виконайте кроки з відповідного розділу про дистрибутив Linux нижче.
Або ж налаштуйте віртуальну машину з Linux.

## Debian / Ubuntu

Встановіть Make і емулятори QEMU в режимі користувача:

```shell
sudo apt install make qemu-user
```

Потім встановіть Zig 0.15.2 або новіший, як описано в розділі [«Пряме завантаження»][zig-install].

## Fedora

Встановіть усі три інструменти командою:

```shell
sudo dnf install zig make qemu-user
```

## Arch Linux

Встановіть усі три інструменти командою:

```shell
sudo pacman -S zig make qemu-user
```

## openSUSE Tumbleweed

Встановіть усі три інструменти командою:

```shell
sudo zypper install zig make qemu-linux-user
```

## Перевірка встановлення

Переконайтеся, що всі три інструменти знайдено:

```shell
zig version
make --version
qemu-riscv32 --version
```

Потім завантажте вправу за допомогою Exercism CLI і запустіть її тести:

```shell
exercism download --track=risc-v --exercise=hello-world
cd ~/exercism/risc-v/hello-world/
make
```
