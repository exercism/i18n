# Встановлення

## Вимоги

* 64-бітний процесор x86
* Сучасний компілятор C
* Інструмент збірки Make
* Netwide Assembler (NASM)

Зверніть увагу, що цей трек підтримує лише угоду про виклики System V AMD64 ABI. Користувачам Windows потрібно встановити Windows Subsystem for Linux (WSL) або налаштувати віртуальну машину Linux.

## Linux

Встановіть потрібне програмне забезпечення за допомогою менеджера пакетів вашої системи:

* Ubuntu, Debian: `$ sudo apt-get install gcc make nasm`
* Fedora: `$ sudo dnf install gcc make nasm`
* CentOS, RHEL: `$ sudo yum install gcc make nasm`
* Arch Linux: `$ sudo pacman -S gcc make nasm`
* OpenSUSE: `$ sudo zypper install gcc make nasm`

## macOS

Встановіть Xcode Command Line Tools:

```bash
$ xcode-select --install
```

Встановіть NASM за допомогою [Homebrew](http://brew.sh/):

```bash
$ brew install nasm
```

## Windows

Щоб встановити WSL, дивіться https://docs.microsoft.com/en-us/windows/wsl/install-win10.
