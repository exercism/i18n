# Вступ

## Рядки

`String` у Java - це обʼєкт, який представляє незмінний рядок тексту (англ. string) як послідовність символів Unicode (літер, цифр, розділових знаків тощо).
Для створення екземпляра `String` використовують подвійні лапки:

```java
String fruit = "Apple";
```

З рядками тексту працюють, викликаючи їхні методи.
Після створення рядка тексту його значення вже не може змінитися.
Будь-які методи, які нібито змінюють рядок тексту, насправді повертають новий рядок тексту.
Клас `String` надає кілька _статичних_ методів для перетворення рядків тексту.
