# Вступ

## Булеві значення (англ. Boolean)

Булеві значення в Java представлені типом `boolean`, значення якого можуть бути або `true`, або `false`.

Java підтримує три булеві оператори:  

- `!` (логічне заперечення): заперечує булеве значення  
- `&&` (логічне і): приймає два булеві значення і повертає `true`, якщо обидва дорівнюють `true`
- `||` (логічне або): повертає `true`, якщо хоча б одне з двох булевих значень дорівнює `true`

### Приклади

```java
!true // => false
!false // => true
true && false // => false
true && true // => true
false || false // => false
false || true // => true
```
