# Вступ

Визначення колекції зазвичай містить заповнювач у кутових дужках, часто це T за домовленістю. Таку колекцію називають узагальненим типом. Це дає тому, хто використовує колекцію, змогу вказати, який тип елементів зберігати в ній. У наведеному вище прикладі коду ми створюємо екземпляр масиву рядків тексту (англ. string).

Щоб зробити клас або функцію **узагальненими**, ми використовуємо атрибут `@:generic`. Завдяки цьому компілятор розпізнає клас або функцію як узагальнені:

```haxe
@:generic
class MyValue<T> {
  public var value:T;

  public function new(value:T) {
    this.value = value;
  }
}

var a = MyValue<String>("Hello");
trace(a.value); // Hello
```
