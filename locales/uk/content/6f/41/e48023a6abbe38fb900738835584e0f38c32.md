# Встановлення

## Встановлення .NET

Трек F# побудовано на платформі [.NET](https://dotnet.microsoft.com/learn/dotnet/what-is-dotnet), яка працює на Windows, Linux і macOS. Щоб збирати проєкти .NET, можна використати інтерфейс командного рядка .NET (CLI). Цей CLI входить до складу .NET SDK, який можна встановити за [інструкціями зі встановлення](https://dotnet.microsoft.com/download). Зауваження: трек F# потребує SDK версії 8.0 або новішої.

Після завершення встановлення перевіримо, чи CLI встановлено успішно, виконавши в терміналі таку команду:

```bash
dotnet --version
```

Якщо команда виводить версію `8.0.100` або новішу, .NET SDK встановлено успішно.

## Використання IDE

Якщо потрібен повнофункціональніший досвід редагування, імовірно, варто скористатися IDE. Ось найпопулярніші IDE, які підтримують збирання проєктів .NET:

- [Visual Studio 2022](https://www.visualstudio.com/downloads/)
- [Visual Studio Code](https://code.visualstudio.com/download) з [розширенням Ionide-fsharp](https://marketplace.visualstudio.com/items?itemName=Ionide.Ionide-fsharp)
- [Visual Studio for Mac](https://www.visualstudio.com/vs/visual-studio-mac/)
- [Project Rider](https://www.jetbrains.com/rider/download/)

Зауваження: оскільки формат проєктів .NET суттєво відрізняється від попередніх версій, старіші IDE (як-от Visual Studio 2015) не підтримуються.
