# Вступ

У JavaScript масив є структурою, схожою на список, без фіксованої довжини, яка може зберігати примітиви чи обʼєкти будь-якого типу, навіть змішаних типів.

Щоб створити масив, додамо елементи між квадратними дужками `[]`.
Щоб прочитати значення з масиву, поставимо індекс у квадратних дужках `[]` після ідентифікатора.
Індекси масиву починаються з нуля.

Наприклад:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[2];
// => 3
```

Щоб дізнатися кількість елементів у масиві, використаємо властивість `length`:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.length;
// => 4
```

Щоб змінити елемент масиву, присвоїмо значення за його індексом:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[0] = 'one';
numbers;
// => ['one', 'two', 3, 'four']
```

## Методи

Деякі з [методів][mdn-array], доступних для кожного обʼєкта Array, можна використати, щоб додати елементи до масиву або видалити їх.
Ось кілька з них, які варто розглянути, працюючи над цією вправою:

### push

`value` можна _додати_ в кінець масиву за допомогою `.push(value)`.
Метод повертає нову довжину масиву.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.push(5); // => 5
numbers;
// => [1, 'two', 3, 'four', 5]
```

### pop

_Останнє_ `value` можна _видалити_ з масиву за допомогою `.pop()`.
Метод повертає видалене значення.
Через цю зміну довжина масиву зменшиться.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.pop(); // => four
numbers;
// => [1, 'two', 3]
```

### shift

_Перше_ `value` можна _видалити_ з масиву за допомогою `.shift()`.
Метод повертає видалене значення.
Через цю зміну довжина масиву зменшиться.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.shift(); // => 1
numbers;
// => ['two', 3, 'four']
```

### unshift

`value` можна _додати_ на початок масиву за допомогою `.unshift(value)`.
Метод повертає нову довжину масиву.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.unshift('one'); // => 5
numbers;
// => ['one', 1, 'two', 3, 'four']
```

### splice

`value` за певним `index` можна _видалити_ з масиву за допомогою `.splice(index, 1)`.
Метод повертає видалений елемент (або елементи).

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.splice(2, 1, 'one'); // => [3]
numbers;
// => [1, 'two', 'one', 'four']
```

~~~exercism/advanced
Ці методи потужніші, ніж описано:

- І `push`, і `unshift` дають змогу додати чи вставити кілька значень одразу, додавши більше аргументів.
  Для виконання цієї вправи це не потрібно.
- Splice може видалити кілька значень, якщо збільшити другий аргумент.
  Для виконання цієї вправи це не потрібно.
- Splice також може додати кілька значень, якщо передати їх як аргументи після `deleteCount`.
  Це можна використати, щоб замінити значення або вставити значення в середину масиву (наприклад, видаливши 0 елементів).
  Для виконання цієї вправи це не потрібно.
~~~
