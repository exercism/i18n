# Блоки та Proc

[Блок][block] - це фрагмент коду, який можна передати методу.
В інших мовах програмування це називають [анонімною функцією або лямбдою][anonymous function].
Метод може перетворити блок на [Proc][proc], який представляє блок коду.

```crystal
def my_method(&block)
  1 + yield
end

my_method { 2 }
# => 3
```

Блоки й Proc дуже часто використовують у Crystal, зокрема для ітерації та колбеків, а також для створення [DSL (предметно-орієнтовані мови)][dsl]. Прикладами DSL є вебфреймворк [Kemal][kemal] і фреймворк для тестування [Spec][spec] (саме його використовують для тестування рішень на Crystal).

## Блоки

Щоб створити метод, який приймає блок, потрібно додати амперсанд (`&`) перед останнім аргументом.
Так блок перетвориться на Proc і буде присвоєний аргументу.
Потім `yield` виконає блок, переданий методу.

```crystal
def my_method(&block)
  1 + yield
end
```

Щоб передати блок, є два способи: або за допомогою ключових слів `do ... end`, або за допомогою фігурних дужок (`{}`).
Головна різниця між ними - пріоритет: `do ... end` підтримує багаторядкові блоки, а фігурні дужки (`{}`) - ні.

```crystal
my_method do
  2
end
# => 3

my_method { 2 }
# => 3
```

## Yield

[`yield`][yield] - це ключове слово, яке виконує блок, переданий методу.
Це означає, що блок ніколи не буде виконано, якщо не викликати `yield`.
Йому також можна передати аргументи, які отримає блок.
Кількість аргументів, які можна передати блоку, не обмежена.
Щоб скористатися аргументами в блоці, застосовують синтаксис `|x, y, ...|`.
Тут x, y, ... - назви аргументів.

```crystal
def my_method(&block)
  1 + yield 2
end

# With curly braces:

my_method { |x| x * 3 }
# => 7

# With do ... end:

my_method do |x|
  x * 3
end
# => 7
```

У наведеному прикладі блоку передають аргумент `2`, блок множить його на `3` і повертає `6`.
Потім метод додає `1` до результату й повертає `7`.

Якщо кількість аргументів, переданих `yield`, більша за кількість аргументів, які приймає блок, виникне помилка.

```crystal
def my_method(&block)
  1 + yield
end

my_method { |x| x * 3 }
# Error: too many block parameters (given 1, expected maximum 0)
```

## Типи блоків

Блоки можна записувати явно або неявно.
Неявні блоки трапляються найчастіше, саме вони показані в прикладах вище.
Блоку можна навіть передавати аргументи різних типів, і компілятор виведе їхні типи та створить обʼєднання типів.

```crystal
def my_method(&block)
  yield "a"
  yield 1
end

my_method do |x|
  p typeof(x)
end

# output: (String | Int32)
```

У явних блоках можна вказати типи аргументів і тип повернення.
Це робиться за допомогою синтаксису `Arg1Type, Arg2Type, ... -> ResultType`.
Тут аргументи розділені комами (`,`), а тип результату відокремлюється за допомогою `->`.

```crystal
def my_method(&block : Int32, Int32 -> Int32)
  1 + yield(2, 3)
end

my_method { |x, y| x * y }
# => 7
```

Як і з іншими явними типами, компілятор стежить за тим, щоб типи відповідали вказаним.
Якщо блок не відповідає типу, указаному для методу, виникне помилка.

## Proc

[`Proc`][proc] тісно повʼязаний із блоками.
Ключова відмінність у тому, що `Proc` є типом, а блок - ні.
`Proc` представляє вказівник на функцію, і його можна передавати як змінну.

Щоб визначити `Proc`, використовують синтаксис літерала proc `->(args) { ... }`.
Аргументи розділяються комами (`,`), а тіло записується у фігурних дужках `{ ... }`.
Щоб викликати Proc, використовують метод `call` і передають йому аргументи.
Типи параметрів обовʼязкові.
Тип повернення виводиться з тіла proc, але його можна вказати й явно.

```crystal
my_proc = ->(x : Int32, y : Int32) : Int32 { x * y }
my_proc.call(2, 3)
# => 6
```

## Захоплення блоків

[Захоплення блоків][capturing-blocks] - це спосіб створити `Proc` із блоку.
Для цього використовують оператор `&` перед останнім аргументом методу.
Так блок перетворюється на `Proc` і присвоюється аргументу. 

```crystal
def my_method(&block)
  block.call
end

my_method { 1 + 2 }
# => 3
```

### Передавання Proc у методи

Proc можна передавати методам, які приймають блок.
Це зручно, коли потрібно передавати різні блоки залежно від певної умови.

```crystal
def my_method(&block)
  yield 5
end

my_proc = -> (x) { x * 2 }
my_method(&my_proc)
# => 10
```

### Оголошення типу змінних

Оголошуючи змінну, можна скористатися синтаксисом `: Type`, щоб указати тип цієї змінної.
Для proc використовують синтаксис `Proc((ArgType, ...), ResultType)`.
Останній тип завжди є типом повернення, а решта - типами аргументів.
Тобто якщо тип лише один, він буде типом повернення, а proc не прийматиме аргументів.

```crystal
my_proc : Proc(Int32, Int32, Int32) = ->(x, y) { x * y }
other_proc : Proc(Int32) = -> { 1 }
```
