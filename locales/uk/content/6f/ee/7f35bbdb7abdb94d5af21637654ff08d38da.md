# Вступ

[`Set`][set] - це колекція елементів із такими властивостями:

- Невпорядкована.
- Елементи унікальні, тож спроби додати дублікати тихо ігноруються.
- Підтримує багато операцій, типових для математичних множин.

Створюймо їх за допомогою конструктора `Set()`, використовуючи як параметр будь-який ітератор.

```julia-repl
julia> s1 = Set(1:4)
Set([4, 2, 3, 1])
```

Додаваймо нові елементи за допомогою `push!()` (так само, як у масивах), а видаляймо їх за допомогою `delete!()`.

```julia-repl
julia> push!(s1, 5)
Set([5, 4, 2, 3, 1])

# Duplicates are ignored
julia> push!(s1, 3)
Set([5, 4, 2, 3, 1])

julia> delete!(s1, 5)
Set([4, 2, 3, 1])

julia> length(s1)  # length counts entries, despite the non-sequential type
4
```

## Операції над множинами

Як і в багатьох інших типах колекцій, належність перевіряймо за допомогою оператора `in` або `∈` (щоб отримати цей символ, наберіть `\in` і натисніть Tab).

```julia-repl
julia> 3 ∈ s1
true
```

Підтримуються такі операції над парами множин (скорочення до символу оператора наведено в дужках).

- `union(A, B)` або `A ∪ B` (`\cup`): усі елементи, що є в A, у B або в обох.
- `intersect(A, B)` або `A ∩ B` (`\cap`): усі елементи, спільні для A і B.
- `setdiff(A, B)` (без символу): елементи, що є в A, але не в B.
- `symdiff(A, B)` (без символу): елементи, що є в A або B, але не в обох.
- `issubset(A, B)` або `A ⊆ B` (`\subseteq`) або `B ⊇ A` (`\supseteq`): `true`, якщо всі елементи A також є в B.
- `issetequal(A, B)` (без символу): `true`, якщо A і B містять точно ті самі елементи.
- `isdisjoint(A, B)` (без символу): `true`, якщо A і B не мають спільних елементів (тобто їхній перетин порожній).

```julia-repl
julia> s1 = Set(1:4);
julia> s2 = Set(3:6);
julia> s1 ∪ s2  # union
Set([5, 4, 6, 2, 3, 1])

julia> s1 ∩ s2  # intersect
Set([4, 3])
  
julia> setdiff(s1, s2)
Set([2, 1])

julia> symdiff(s1, s2)
Set([5, 6, 2, 1])
  
julia> s1 ⊇ s2  # issubset
false
```

Для багатьох із цих операцій також є версії, що змінюють множину, з `!`, доданим до назви функції.
Повний список функцій наведено в [посібнику][set].
