# Вступ

З [посібника][man-types]

> jq підтримує той самий набір типів даних, що й JSON: числа, рядки тексту (англ. string), булеві значення (англ. Boolean), масиви, обʼєкти (які мовою JSON є хешами, ключами яких можуть бути лише рядки тексту) та "null".

Зосередьмося на **числах**.

## Числа та числові оператори

Усі числа, цілі чи ні, є числами з плаваючою комою подвійної точності IEEE754.
Це обмежує нас 53 бітами точності.

З числами можна використовувати звичні оператори:

- арифметичні: `+`, `-`, `*`, `/`, `%`
- порівняння: `==`, `!=`, `<`, `<=`, `>=`, `>`
- стандартні [математичні функції][man-math]

  Для функцій з одним аргументом значення передають у функцію через конвеєр

  ```sh
  $ jq -n '(1 | atan) * 4'
  3.141592653589793
  ```

  Для функцій із двома аргументами функції ігнорують вхідні дані й приймають їх як параметри (нагадаємо, що параметри розділяються крапками з комою)

  ```sh
  $ jq -n 'pow(2; 10)'
  1024
  ```

  Аргументи функції розділяються крапкою з комою, а не комою.

## Інші вирази `jq`

Щоб розвʼязати вправу, нам потрібно знати про умовні вирази.

### Умовні вирази

`jq` використовує [вираз `if-then-else`][if-then-else] для **умовних виразів**.
Як _вираз_, він стоїть у конвеєрі.

Синтаксис такий: `if CONDITION then TRUE_EXPR else FALSE_EXPR end`.

Гілка `else` необовʼязкова.

```jq
42 | if . < 33 then "small" else "larger" end
# => "larger"
```

Додаткові умови використовують `elif`

```jq
42 | if . < 33 then "small"
     elif . < 67 then "medium"
     else "large"
     end
# => "medium"
```
