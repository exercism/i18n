# Вступ

У Factor система помилок складається з трьох частин: `throw` (з
[`kernel`][kernel]) кидає помилку, `recover` (з
[`continuations`][continuations]) перехоплює її, а `ERROR:` визначає
клас помилки на основі кортежу.

```factor
! "file not found" throw          (raises a string as the error)

[ "boom" throw ] [ drop "caught" ] recover .
! => "caught"
```

`recover ( try recovery -- )` виконує quotation *try*; якщо вона
кидає помилку, помилка потрапляє в стек, і запускається
quotation *recovery*.

`ERROR:` оголошує і клас, *і* слово-конструктор, яке кидає новий
примірник:

```factor
! DOCTEST: SKIP
ERROR: not-found path ;

"/missing" not-found
! throws T{ not-found { path "/missing" } }
```

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
[continuations]: https://docs.factorcode.org/content/vocab-continuations.html
