# використання ґардів

[comment]: # (Ця помилка виникає, коли рішення взагалі не використовує ґарди)

Використаймо [ґарди](https://hexdocs.pm/elixir/master/guards.html), щоб `two_fer/1` не виконувала код із небінарними вхідними даними.

> Памʼятаймо, що в Elixir [рядки тексту (англ. string)](https://elixir-lang.org/getting-started/binaries-strings-and-char-lists.html) вважаються [бінарними даними](https://elixir-lang.org/getting-started/binaries-strings-and-char-lists.html).

```elixir
# Consider this function with a guard:
def hello(what) when is_binary(what) do
  "Hello, #{what}!"
end
```

> Цей ґард можна перевірити в `iex`

```shell
iex> hello("world")
"Hello, world!"
iex> hello(123)
** (FunctionClauseError) no function clause matching in hello/1

    The following arguments were given to hello/1:

        # 1
        123
```
