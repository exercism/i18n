# Вказівки

Ми розробляємо систему, яка допомагає персоналу вебсайту футбольного клубу звітувати про матчі.
Ця система вміє аналізувати різні аспекти матчу, як на полі, так і поза полем, і перетворює їх на потік подій.

## 1. Виведіть описи гравців за номером на футболці

Команда грає виключно за схемою 4-3-3 і так і не визнала зміну правил 1965 року, що дозволяє заміни, не кажучи вже про розширені склади.

Описи гравців такі:

```text
1 -> "goalie"
2 -> "left back"
3 & 4 -> "center back"
5 -> "right back"
6, 7 & 8 -> "midfielder"
9 -> "left wing"
10 -> "striker"
11 -> "right wing"
```

Реалізуйте статичний метод `PlayAnalyzer.AnalyzeOnField()`, щоб виводити опис гравця за його номером на футболці.

```csharp
PlayAnalyzer.AnalyzeOnField(10);
// => "striker"
```

## 2. Обробіть невідомі номери на футболках

Змініть метод `PlayAnalyzer.AnalyzeOnField()`, щоб він виводив `UNKNOWN`, коли обробляється номер на футболці поза діапазоном від 1 до 11.

## 3. Розширте охоплення, щоб врахувати активність поза полем

Реалізуйте метод `PlayAnalyzer.AnalyzeOffField()`, щоб виводити описи діяльностей і персонажів навколо ігрового поля.
Цей метод приймає різні типи даних, які потрібно проаналізувати й перетворити на відповідний текст, щоб допомогти журналістам.

Для початку розглянемо дані про стадіон:

- Поточна кількість уболівальників на стадіоні (будь-яке `int`)
- Оголошення, зроблені через систему гучного оповіщення стадіону (будь-який `string`)

Невідомі типи даних не потрібно обробляти, тож якщо метод отримує дані іншого типу, слід повернути порожній рядок тексту (англ. string).

```csharp
PlayAnalyzer.AnalyzeOffField(5000);
// => "There are 5000 supporters at the match."

PlayAnalyzer.AnalyzeOffField("5 minutes to go!");
// => "5 minutes to go!"

PlayAnalyzer.AnalyzeOffField(0.5);
// => ""
```

## 4. Повідомте про інциденти під час матчу

Змініть метод `PlayAnalyzer.AnalyzeOffField()`, щоб виводити описи інцидентів, які трапляються під час матчу.

Інциденти можуть бути будь-яким підкласом типу `Incident` і міститимуть опис інциденту.
Травми є особливим різновидом інцидентів, бо через них матч призупиняється, тож їх слід обробляти інакше.

```csharp
PlayAnalyzer.AnalyzeOffField(new Foul());
// => "The referee deemed a foul."

PlayAnalyzer.AnalyzeOffField(new Injury(8));
// => "Oh no! Player 8 is injured. Medics are on the field."
```

## 5. Повідомте про менеджерів клубів

Змініть метод `PlayAnalyzer.AnalyzeOffField()`, щоб згадувати менеджерів клубів, присутніх під час матчу.

Менеджери є екземплярами типу `Manager` і мають імʼя та назву клубу, яким керують.
Клуб менеджера може бути невідомим, і тоді його буде встановлено в `null`.
Якщо клуб менеджера невідомий, він не повинен бути частиною опису.

```csharp
PlayAnalyzer.AnalyzeOffField(new Manager("José Mário dos Santos Mourinho Félix", null));
// => "José Mário dos Santos Mourinho Félix"

PlayAnalyzer.AnalyzeOffField(new Manager("Jürgen Klopp", "Liverpool"));
// => "Jürgen Klopp (Liverpool)"
```
