# Exercism API

## Опис

Більшість мовних треків Exercism використовують інструмент командного рядка `exercism` для отримання й надсилання вправ, який взаємодіє з `exercism.io` через REST API. Мовний трек Pharo Smalltalk натомість використовує той самий REST API, щоб додавати вправи до образу Pharo і прибирати їх звідти без жодного проміжного інструментарію. Цей документ докладно описує Exercism API, зосереджуючись на тому, як його використовує мовний трек Pharo Smalltalk. Він призначений для мейнтейнерів інструментарію Pharo Smalltalk.

## Заголовки

Усі кінцеві точки вимагають, щоб заголовки запиту мали такі значення:

```
Authorization: Bearer <token>
```

Значення `<token>` - це токен автентифікації CLI користувача, доступний на `https://exercism.io/my/settings`.

## Отримання вправ

```
Content-Type: application/json
```

`GET api.exercism.io/v1/solutions/latest?exercise_id=<slug>&track_id<language> HTTP/1.1`

У наведеній вище URL-адресі `<slug>` - це назва вправи, наприклад `hello-world`, а `<language>` - це мовний трек, наприклад `pharo-smalltalk`.

### Відповідь

#### 200

Успішний запит надішле відповідь із вмістом JSON. Усередині JSON буде інформація про вправу та URL-адреса, з якої можна завантажити файли вправи.

```json
"solution":{
	"id":"<id-string>",
	"url":"https://exercism.io/my/solutions/<id-string>",
	"team":null,
	"user":{
		"handle":"<exercism-user-name>",
		"is_requester":true
		},
		"exercise":{
			"id":"isogram",
			"instructions_url":"https://exercism.io/my/solutions/<id-string>",
			"auto_approve":false,
			"track":{
				"id":"pharo-smalltalk",
				"language":"Pharo"
				}
			},
			"file_download_base_url":"https://api.exercism.io/v1/solutions/<id-string>/files/",
			"files":[
				"IsogramTest.class.st",
				"README.md"
				],
			"iteration":null
		}
	}
```

#### 400

Назва мовного треку неоднозначна, або надіслані файли вправи не змінилися.

#### 403

Рішення не розблоковано для користувача, або користувач не приєднався до мовного треку.

#### 404

Мовний трек або вправу не вдалося знайти.

## Надсилання вправ

```
Content-Type: application/octet-stream
```

`PATCH api.exercism.io//v1/solutions/<some-kind-of-token-or-hash> HTTP/1.1`

### Відповідь

#### 201

Успішне надсилання.

#### 400

Надісланий файл завеликий (більший за один мегабайт), або рішення є дублікатом.

#### 403

Рішення недоступне для користувача. Ідентифікатор користувача рішення та ідентифікатор поточного користувача не збігаються.

#### 404

Ідентифікатор рішення не знайдено.
