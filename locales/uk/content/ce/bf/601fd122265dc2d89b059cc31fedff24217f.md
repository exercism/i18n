# Вступ

`String` у Haxe - це обʼєкт, який представляє незмінний текст як послідовність символів Unicode (літер, цифр, розділових знаків тощо). Щоб створити примірник `String`, використовуємо подвійні лапки:

```haxe
var fruit:String = "Apple";
```

Рядки тексту (англ. string) опрацьовуємо, викликаючи методи рядка. Щойно рядок тексту створено, його значення вже ніколи не зміниться. Будь-які методи, які нібито змінюють рядок тексту, насправді повертають новий рядок тексту.

Кілька рядків тексту можна зʼєднати (додати) один до одного. Найпростіший спосіб - скористатися оператором `+`.

```haxe
var name:String = "Jane";
trace("Hello " + name + "!");
// => "Hello Jane!"
```

Для будь-якого форматування рядків тексту, складнішого за просту конкатенацію, краще використовувати інтерполяцію рядків. Щоб скористатися інтерполяцією в рядку тексту, беремо його в одинарні лапки (`'`). Тоді за допомогою знака долара (`$`) можна запустити інтерполяцію:

```haxe
var name:String = "Jane";
trace('Hello $name!');
// => "Hello Jane!"
```
