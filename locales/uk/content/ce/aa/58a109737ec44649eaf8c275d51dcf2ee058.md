# Про функції вищого порядку

У Kotlin функції є повноправними обʼєктами.
Це означає, що їх можна зберігати у змінних, передавати як аргументи й навіть повертати з інших функцій.
Наприклад, присвоєння функції змінній `addOne`:

```kotlin
val addOne = fun (num : Int) : Int {
    return num + 1
}
```

Функція також може повертати іншу функцію:

```kotlin
fun makeAddOne() : (Int) -> Int {
    return fun(num : Int) : Int {
        return num + 1
    }
}
```

Після присвоєння функцію можна викликати через змінну, наче це просто ще одна функція:
```kotlin
addOne(3)
// => 4
```

## Оголошення типів функцій

Тип змінної або параметра можна оголосити за допомогою синтаксису `(parameter types) -> return type`.
Наприклад, оголошення змінної:

```kotlin
val addOne : (Int) -> Int = fun (num : Int) : Int {
    return num + 1
}
```

А ось для параметра функції:

```kotlin
fun perform(operation : (Int) -> Int) {
    operation(3)
}
```

## Лямбда-вирази

Лямбда-вираз - це коротший спосіб визначити функцію.
Їх записують у формі `{ parameters -> body }`.
Вираз повертає останнє значення з останньої інструкції в тілі.
Наприклад:

```kotlin
// Assigning to a variable
val addOne = { num : Int -> num +  1}

// In a function call
perform({ num : Int -> num + 1 })
```

Kotlin може виводити типи, коли є достатньо інформації.
Наприклад, наведені вище приклади можна також записати так:

```kotlin
// Assigning to a variable
val addOne : (Int) -> Int = { num -> num + 1 }

// Or ...
val addOne  = { num : Int -> num + 1 }

// Using in a function
perform({ num -> num + 1 })
```

## `it` для лямбд з одним параметром

Коли вираз має лише один параметр, цей параметр можна опустити.
Тоді Kotlin зробить у тілі доступним параметр із назвою `it`.
Наприклад:

```kotlin
val addOne : (Int) -> Int = { it +  1 }
```

## Передавання завершальних лямбд

Коли останній аргумент функції - це лямбда, лямбда-вираз записують безпосередньо _після_ дужок.
Наприклад:

```kotlin
// Function that takes a function as last argument
fun calculateFrom(from : Int, operation : (Int) -> Int) : Int {
    return operation(from)
}

// Call the calculateFrom function
calculateFrom(2) { it * 3 }
// => 6
```
