# Підказки

## Загальне

- Памʼятаймо, що перевантаження операторів у Cairo реалізується через трейти
- Атрибут `#[derive(PartialEq)]` автоматично реалізує порівняння на рівність
- Реалізуючи `PartialOrd`, достатньо реалізувати лише метод `lt`; решта операторів порівняння виводяться з нього

## 1. Реалізація `Add`

- Метод `add` повинен поєднати поля `value` обох TimeShards
- Памʼятаймо, що TimeShards містять значення `i32`, для яких додавання вже визначено

## 2. Реалізація `Sub`

- Схоже на додавання, але між полями `value` використовується оператор віднімання
- У відніманні порядок операндів має значення

## 3. Реалізація `PartialOrd`

- Метод `lt` має порівнювати поля `value` TimeShards
- Щойно `lt` реалізовано, решта операторів порівняння (`>`, `<=`, `>=`) будуть працювати автоматично
- Памʼятаймо, що `PartialEq` уже виведено, тож реалізовувати його вручну не потрібно
