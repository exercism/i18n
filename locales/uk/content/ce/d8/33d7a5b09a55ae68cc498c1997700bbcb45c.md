# Опис

Піфагоровою трійкою називають три натуральні числа {a, b, c}, для яких

```text
a² + b² = c²
```

і які задовольняють умову

```text
a < b < c
```

Наприклад,

```text
3² + 4² = 5².
```

Дано ціле число N. Знайдіть усі піфагорові трійки, для яких `a + b + c = N`.

Наприклад, якщо N = 1000, існує рівно одна піфагорова трійка, для якої `a + b + c = 1000`: `{200, 375, 425}`.
