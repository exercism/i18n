# Підказки

## 1. Розібрати дату запису

- Клас `LocalDateTime` має метод, який [розбирає][localdatetime-parse] `String` у `LocalDateTime`.
- Використайте [`DateTimeFormatter`][datetimeformatter-docs] із власним шаблоном, щоб розібрати нестандартний формат дати й часу.

## 2. Перевірити, чи запис уже минув

- В екземплярів `LocalDateTime` є [методи][localdatetime-methods] для порівняння їх з іншими `LocalDateTime`.
- Є [метод][localdatetime-methods] для отримання поточної дати й часу.

## 3. Перевірити, чи запис після обіду

- Щоб отримати часову частину екземпляра `LocalDateTime`, можна скористатися одним із його [методів][localdatetime-methods].

## 4. Описати час і дату запису

- Використайте [`DateTimeFormatter`][datetimeformatter-docs] із власним шаблоном, щоб відформатувати `LocalDateTime`.
- Тести виконуються так, ніби код запущено на машині у Сполучених Штатах, тож переконайтеся, що форматер [використовує правильну локаль][datetimeformatter-ofpattern-with-locale].

## 5. Повернути дату річниці

- Клас `LocalDate` має [метод][localdate-methods] для отримання поточної дати.
- Щоб отримати рік з екземпляра `LocalDate`, можна скористатися одним із його [методів][localdate-methods].
