# Вступ

Для коротких слів цілком можна обійтися перекиданням значень зі стека. Але коли слово має кілька вхідних даних і нам треба звертатися до них на імʼя, Factor пропонує *локальні змінні*: це іменовані привʼязки, які вводяться через `::` (для визначень слів) або `[| | ]` (для вбудованих лямбд), обидва походять із [`locals`][locals].

```factor
USING: locals ;

:: hypotenuse ( a b -- c )
    a a *
    b b *
    + sqrt ;
```

Усередині квотейшна `[| inputs | body ]` - це лямбда з іменованими вхідними даними:

```factor
USING: assocs locals ;

H{ { "a" 1 } { "b" 2 } }
[| key value | key value 10 * ] assoc-map .
! => H{ { "a" 10 } { "b" 20 } }
```

[locals]: https://docs.factorcode.org/content/vocab-locals.html
