# Вступ

## Масиви та вектори

C++ пропонує різні контейнери, щоб зберігати елементи одного типу впорядковано.
Є `std::array` для контейнерів фіксованого розміру та `std::vector`, який уміє динамічно змінювати розмір.

### Створення

Коли ми оголошуємо масив або вектор, потрібно вказати тип елементів, які зберігатиме цей контейнер.
Масивам також потрібен розмір.
Погляньмо на ці приклади, щоб побачити, як ініціалізуються обидва типи контейнерів:

```cpp
#include <array>
#include <string>

// std::array<element_type, size> variable_name {list of elements}
std::array<std::string, 3> indie_rock {"yeah", "yeah", "yeah"};
// indie_rock contains the elements "yeah" three times
```

Векторам зазвичай потрібно більше місця, бо вони виділяють памʼять для подальшого зростання.
Розмір указувати не потрібно:

```cpp
#include <vector>

// std::vector<element_type> variable_name {list of elements}
std::vector<int> countdown {3, 2, 1};
// countdown contains the elements 3, 2 and 1
```

> Зауваження: точний механізм, що стоїть за концепцією шаблонів, поки що знати не потрібно, для неї буде окрема концепція далі в дереві силабусу.

### Доступ до елементів

Вектори та масиви мають однакові функції для доступу до своїх елементів.
Щоб отримати перший і останній елемент контейнера, можна скористатися функціями-членами `front` і `back`.
Також є `at` і оператор `[]`, щоб звертатися до конкретних елементів.

```cpp
countdown[0];
// => 3
countdown.at(2);
// => 1
countdown[1] = 4;
// countdown now contains 3, 4 and 1
indie_rock.back() = "yeahs";
// indie_rock is now "yeah", "yeah", "yeahs"
```

> Зауваження: якщо ми виберемо позицію, якої немає в діапазоні контейнера, `[]` може призвести до невизначеної поведінки.
> Функція `at` натомість згенерує виняток, що зрештою може полегшити нам життя.

### Модифікатори вектора

Оскільки `vector` не має фіксованого розміру, до нього можна додавати елементи й видаляти їх.
Дві поширені функції для цього: `emplace_back` і `pop_back`.

```cpp
std::vector<std::string> witches {"Holly", "Alyssa", "Shannen"};
witches.pop_back();
// Shannen is no longer with the witches
witches.emplace_back("Rose");
// Rose has joined the team
```

### Місткість

Перевірити контейнери на порожнечу можна функцією-членом `empty`.
А якщо ми хочемо дізнатися кількість елементів, скористаймося `size`.
