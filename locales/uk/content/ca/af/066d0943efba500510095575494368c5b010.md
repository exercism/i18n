# Про

Умовні вирази використовуються для виконання коду залежно від **if**-умови: вона набуває значення **правда** або **неправда**. Ці вирази записуються так:

```haxe
if (condition) {
  expressions
};
```

Вихідні дані умови мають тип `Bool`, тож коли вони є `true`, вирази виконуються.

Іноді, коли умова насправді є `false`, ми хочемо, щоб виконався інший фрагмент коду. Ось тут і стає в пригоді вираз `else`. `else` виконує вирази, коли початкова умова є `false`. Але що, якщо ми хочемо перевірити умову для кількох можливостей? Тоді ми використовуємо `else if (condition)`. Ось повний приклад:

```haxe
var a = 10;

if (a == 2) {
  trace("a is 2");
} else if (a == 5) {
  trace("a is 5");
} else {
  trace("a is 10");
}

// a is 10
```
