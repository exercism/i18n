# Інструкції

Ми працюємо з парком розваг, і нам передали специфікацію, за якою треба спроєктувати систему для обліку відвідувачів і атракціонів. Нам доручили змоделювати Attendee (людину, яка відвідує парк).

## 1. Створіть нових відвідувачів

Реалізуйте метод `Attendee#initialize` класу `Attendee`. Він має приймати зріст (у сантиметрах) і зберігати його як змінну екземпляра.

```ruby
Attendee.new(106)
# => #<Attendee:0x000055c33e6c7e18 @height=106>
```

## 2. Який зріст відвідувача

Реалізуйте гетер `Attendee#height` класу `Attendee`. Він має повертати зріст екземпляра.

```ruby
Attendee.new(106).height
# => 106
```

## 3. Який ідентифікатор перепустки на атракціон

Не всі відвідувачі купили перепустку на атракціон, але нам треба знати, чи мають вони перепустку. Реалізуйте гетер `Attendee#pass_id` класу `Attendee`. Він має повертати `pass_id` екземпляра або `nil`, якщо у відвідувача немає перепустки.

```ruby
Attendee.new(106).pass_id
# => nil
```

## 4. Дозвольте людям купити перепустку

Реалізуйте `Attendee#issue_pass!`, щоб змінити стан екземпляра й записати значення аргументу в змінну екземпляра для ідентифікатора перепустки. Він має повертати ідентифікатор перепустки.

```ruby
attendee = Attendee.new(106)
attendee.issue_pass!(42)
attendee.pass_id
# => 42
```

## 5. Скасуйте перепустку

Деякі гості порушують правила небезпечною поведінкою, тож парк хоче мати змогу скасовувати перепустки. Реалізуйте `Attendee#revoke_pass!`, щоб змінити стан екземпляра і встановити ідентифікатор перепустки в `nil`.

```ruby
attendee = Attendee.new(106)
attendee.issue_pass!(42)
attendee.revoke_pass!
attendee.pass_id
# => nil
```
