# Додаток до інструкцій

## Робота з датами в Prolog

Вбудована підтримка дат у Prolog [доволі елементарна][built-in-dates-support].
Хоча цю вправу можна розвʼязати лише вбудованими засобами Prolog, значно зручніший спосіб працювати з датами дає [пакет date_time][date-time-package].

### Встановлення пакета date_time

Якщо встановлена версія Swipl досить свіжа, пакет можна встановити командою:

```bash
swipl pack install date_time
```

Якщо це не спрацює, можна виконати:

```shell
swipl -g 'pack_install(date_time)'
```

~~~~exercism/note
В онлайн-редакторі нічого не потрібно встановлювати вручну.
~~~~

### Використання пакета date_time

Додайте на початок файлу з рішенням такий код, щоб скористатися пакетом `date_time`:

```prolog
:- use_module(library(date_time)).
```

~~~~exercism/note
Порада: [джерельний код пакета date_time][date-time-package-source] добре задокументовано, і він стане чудовим помічником!
