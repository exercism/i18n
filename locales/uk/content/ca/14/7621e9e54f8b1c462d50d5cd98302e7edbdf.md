# Вступ

## Булеві значення (англ. Boolean)

Elixir представляє значення правда та неправда за допомогою булевого типу. Існує лише два значення: `true` та `false`. Ці значення можна привʼязати до змінної:

```elixir
true_variable = true
false_variable = false
```

Ми можемо обчислювати строгі булеві вирази за допомогою операторів `and/2`, `or/2` та `not/1`.

```elixir
true_variable = true and true
false_variable = true and false

true_variable = false or true
false_variable = false or false

true_variable = not false
false_variable = not true
```

Коли ми пишемо функцію, яка повертає булеве значення, ідіоматично завершувати назву функції знаком `?`. Таку саму домовленість можна застосувати до змінних, які зберігають булеві значення.

```elixir
def either_true?(a?, b?) do
  a? or b?
end
```
