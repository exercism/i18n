# Вступ

Функції та методи Go можуть повертати кілька значень:

```go
func GetCard() (Card, error) { ... }
```

Кожне повернене значення потрібно присвоїти по порядку й розділити комами:

```go
card, err := GetCard()
```

Кожна позиція в присвоєнні оголошує змінну.
Go не скомпілюється, якщо якась оголошена змінна ніде не використовується.
Порожній ідентифікатор `_` займає місце назви змінної, щоб пропустити це повернене значення:

```go
card, _ := GetCard()
```

`error` - вбудований інтерфейс.
Якщо `error` дорівнює `nil`, це означає, що помилки не сталося; будь-яке значення, відмінне від `nil`, означає, що щось пішло не так.
За домовленістю функції, які можуть завершитися помилкою, мають повертати `error` останнім значенням.
Той, хто викликає функцію, повинен перевірити це значення, перш ніж використовувати інші повернені значення:

```go
card, err := GetCard()
if err != nil {
    return err // do not use card here
}
// safe to use card here
```
