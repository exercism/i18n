# Запуск тестів

SWI Prolog можна запускати як в інтерактивному режимі, так і безпосередньо з командного рядка.

## Командний рядок

Щоб запустити тести з командного рядка, скористайтеся такою командою:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)'
```

Замініть `<exercise>` на назву вправи, над якою працюємо.

## Інтерактивний режим

Щоб запустити Prolog в інтерактивному режимі, спочатку виконайте:

```bash
swipl
```

Після запуску консолі Prolog завантажте свою реалізацію та запустіть тести:

```
?- ["<exercise>.pl"].
?- ["<exercise>_tests.plt"].
?- run_tests.
```

Замініть `<exercise>` на назву вправи, над якою працюємо.

### Перезавантаження змін

Коли ці файли завантажено, можна застосувати всі внесені зміни, виконавши:

```
?- make.
```

## Пропущені тести

Коли ми тільки починаємо вправу, запускається лише перший тест. Решту пропущено, бо до цілі `test` додано `condition(pending)`.
Коли перший тест пройде, увімкніть наступний тест, змінивши `pending` у `condition(pending)` на `true`.
Повторюйте для кожного тесту, доки всі вони не запускатимуться і не проходитимуть.

### Командний рядок

Додайте аргумент `-- --all` у кінець команди, щоб також запустити всі пропущені тести:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)' -- --all
```
