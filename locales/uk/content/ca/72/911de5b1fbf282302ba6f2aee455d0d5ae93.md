# Вступ

## Переліки

Досі ми переважно мали справу з числами та рядками тексту (англ. string).
Щоб моделювати реальний світ, нам може знадобитися обмежений набір значень, які може набувати змінна.
Іноді потрібен окремий тип із кількома різними значеннями, кожне зі своєю назвою.
Наприклад, на фабриці скейтбордів матеріал дошки може бути лише кленом, бамбуком або пластиком.

Можна було б закодувати ці значення цілими числами, але тоді довелося б писати додатковий код, щоб перевіряти, чи не надійшло з системи неприпустиме значення матеріалу.
Значення таких [_магічних чисел_][magic numbers] важко простежити в коді, і їх легко переплутати.
`enumerations` допомагають писати виразний код і запобігати випадковим помилкам порівняння.

## Приклад використання

Конкретна назва такого різновиду переліку - `scoped enumeration`.
Наведений нижче фрагмент показує, як записати `enumeration` `DeckMaterial`.
Звернімо увагу на ключове слово `enum class` та на `;` у кінці визначення:

```cpp
enum class DeckMaterial {
    maple,
    bamboo,
    plastic
};
```
Тепер розгляньмо функцію ціноутворення в магазині скейтбордів і звернімо увагу на оператор розвʼязання області видимості (`::`), який указує `enumerator` з `enumeration`:

```cpp
double deck_price(double base_price, DeckMaterial material) {
    if(material == DeckMaterial::plastic) {
        return base_price * 0.9;
    }
    return base_price * 1.3;
}
```

## Область видимості

Уявімо, що в нас є другий `enumeration` для матеріалу коліс:

```cpp
enum class WheelMaterial {
    steel,
    clay,
    plastic
};
```
Хоча і колеса, і дошка можуть бути з _plastic_, їх неможливо переплутати.
Це різні _типи_:  `DeckMaterial` пластик і `WheelMaterial` пластик.
Кожен `enumeration` має свої `enumerators` у власній області видимості - власному `namespace`.
Саме тому їх називають `scoped enumerations`.

## Переліки без області видимості
Можна подумати, що якщо є назва `scoped`, то існують і _`unscoped`_ переліки, і це справді так.
`Unscoped enumerations` стають дедалі менш популярними, бо всі вони поділяють один і той самий глобальний простір імен.
Через це не можна мати два `unscoped enumerations` з однаковими `enumerators`, як _plastic_ у прикладі вище.

Крім того, `unscoped enumerations` неявно перетворюються на цілі числа.
Погляньмо на приклад нижче, щоб побачити несподіваний результат:

```cpp
enum CitrusFruits {
    lemons,  // 0
    oranges, //1
};

enum IceCream {
    walnut,  // 0
    apples,  // 1
};

bool comparison{apples == oranges};
// => true

// Example from above:
bool comparison{DeckMaterial::plastic == WheelMaterial::plastic};
// => Does not compile!
```

Якщо потрібно перетворити `scoped enumerations` на цілі числа, можна скористатися `static_cast<int>`.

## Інструкція `switch`

Як і в інших мовах, у C++ є інструкція `switch`.
Інструкція `switch` дає коротший спосіб записати довгі конструкції `if ... else if`.
Щоб створити switch, ми починаємо з ключового слова `switch`, після якого йде ціле число.
Далі оголошуємо кожну з умов за допомогою ключового слова `case`.
Також можна оголосити варіант `default`, який виконається, якщо жодна з попередніх умов `case` не збіглася.
Кожен варіант має завершуватися інструкцією `break` (або `return`).

```cpp
int price{0};
int adults{3};
int kids{2};

switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
        break;
    case 2:
        price = 70;
        break;
    default:
        price = group_size * 30;
}
```

## Провалювання

Одна важлива особливість конструкції `switch` полягає в тому, що код продовжує виконуватися, доки його не зупинить інструкція `break` (або `return`).
Це може призвести до несподіваної поведінки.

```cpp
int adults{1};
int kids{0};
switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
    case 2:
        price = 70;
    default:
        price = group_size * 30;
}
// price will be 30!
```

Головний випадок використання такого наскрізного виконання - це варіант із кількома мітками.
Кілька результатів `switch` можуть відповідати тому самому фрагменту коду, який треба виконати.
Так, наприклад, у застосунку для бронювання функція, яку викликають для групи з 2 і 3 осіб, може бути однією й тією самою:
```cpp
switch (group_size) {
case 1:
    book_room();
    break;
case 2:
case 3:
    book_apartment(group_size);
    break;
default:
    book_house(group_size);
}
// book_apartment happens when group_size is 2 or 3
```
