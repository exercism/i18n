# Інструкції

Ми продовжуємо працювати над системою керування запасами, яку створили раніше.
Відколи ми відкрили для себе `OpenStruct` і скорочені записи блоків, ми вирішили трохи відрефакторити код.
Замість того щоб зберігати товари як хеші, ми застосуємо нові набуті навички.

## 1. Дозволити отримання списку товарів

Нам потрібно й надалі отримувати список товарів на складі, але цього разу це мають бути обʼєкти, у яких можна викликати методи.

```ruby
inventory = BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
])

inventory.items.first.name
# => "Maxi Brown Dress"

inventory.items.first.price
# => 65

inventory.items.size
# => 4
```

## 2. Відрефакторити `item_names`

Відрефакторте `item_names`, щоб використовувати новий скорочений запис блоку, який ми вивчили, а не хеші.
Нагадаємо, метод має повертати:

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).item_names

# => ["Bamboo Socks Cats", "Black Short Skirt", "Maxi Brown Dress", "Red Short Skirt"]
```

## 3. Відрефакторити `total_stock`

Відрефакторте `total_stock`, щоб використовувати метод OpenStruct, а не звертатися до хешу.
Нагадаємо, метод має повертати:

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).total_stock

# => 36
```
