# Вказівки

У цій вправі ми будемо писати код для аналізу виробництва на складальній лінії автомобільного заводу.
Швидкість складальної лінії може бути від `0` (вимкнено) до `10` (максимум).

За найнижчої швидкості (`1`) щогодини виробляється `221` автомобіль.
Обсяг виробництва зростає лінійно зі швидкістю.
Тож зі швидкістю `4` має вироблятися `4 * 221 = 884` автомобілі на годину.
Однак вищі швидкості підвищують імовірність виробництва дефектних автомобілів, які потім доводиться вибраковувати.

На нас чекають три завдання.

## 1. Обчислити коефіцієнт успішності

Реалізуйте (_статичний_) метод `AssemblyLine.SuccessRate()`, щоб обчислити частку виробів, створених без помилок, за заданої швидкості.
У таблиці нижче показано, як швидкість впливає на коефіцієнт успішності:

- `0`: 0% успішності.
- від `1` до `4`: 100% успішності.
- від `5` до `8`: 90% успішності.
- `9`: 80% успішності.
- `10`: 77% успішності.

```csharp
AssemblyLine.SuccessRate(10)
// => 0.77
```

## 2. Обчислити продуктивність за годину

Реалізуйте (_статичний_) метод `AssemblyLine.ProductionRatePerHour()`, щоб обчислити продуктивність складальної лінії за годину з урахуванням коефіцієнта успішності:

```csharp
AssemblyLine.ProductionRatePerHour(6)
// => 1193.4
```

Зауважте, що повернене значення має тип `double`.

## 3. Обчислити кількість робочих виробів, виготовлених за хвилину

Реалізуйте (_статичний_) метод `AssemblyLine.WorkingItemsPerMinute()`, щоб обчислити, скільки робочих автомобілів виготовляється за хвилину:

```csharp
AssemblyLine.WorkingItemsPerMinute(6)
// => 19
```

Зауважте, що повернене значення має тип `int`.
