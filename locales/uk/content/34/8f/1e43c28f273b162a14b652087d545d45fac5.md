# Вступ

Булеві значення (англ. Boolean) в Java представлені типом `boolean`, значеннями якого можуть бути `true` або `false`.

Java підтримує три булеві оператори:  

- `!` (логічне заперечення): заперечує булеве значення  
- `&&` (логічне і): приймає два булеві значення і повертає правду, якщо обидва з них є правдою  
- `||` (логічне або): повертає правду, якщо хоч одне з двох булевих значень є правдою  

## Приклади

```java
!true // => false
!false // => true
true && false // => false
true && true // => true
false || false // => false
false || true // => true
```
