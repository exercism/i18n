# Додаток до інструкцій

## Примітки щодо реалізації

Обʼєкт дерева має два атрибути:

- `String` label
- `List<Tree>` children

Тестова програма створює дерева повторним застосуванням функції-будівника
`Tree.of`. Наприклад, інструкція

```java
Tree tree = Tree.of("a", List.of(Tree.of("b"), Tree.of("c", List.of(Tree.of("d")))));
```

створює таке дерево:

```text
      "a"
       |
    -------
    |     |
   "b"   "c"
          |
         "d"
```

Можемо припустити, що в тестових деревах не буде однакових значень.

---

Методи `FromPov` і `PathTo` - найцікавіша частина вправи.

Метод `FromPov` приймає рядковий аргумент `from`, який задає вузол у дереві
через його значення. Він має повернути дерево зі значенням `from` у корені.
Можемо змінити початкове дерево й повернути його або створити нове дерево й
повернути його. Якщо ми повертаємо нове дерево, можемо вільно використати чи
знищити початкове дерево. Звісно, краще залишити його без змін.

Метод `PathTo` приймає два рядкові аргументи `from` і `to`, які задають два
вузли в дереві через їхні значення. Він має повернути найкоротший шлях у дереві
від першого вузла до другого.

## Повідомлення винятків

Іноді потрібно [кинути виняток](https://docs.oracle.com/javase/tutorial/essential/exceptions/throwing.html).
Коли ми робимо це, завжди варто додати **змістовне повідомлення про помилку**, щоб указати, у чому джерело помилки.
Це робить код читабельнішим і суттєво допомагає з налагодженням.

У цій конкретній вправі потрібно використати [ключове слово throw](https://docs.oracle.com/javase/tutorial/essential/exceptions/throwing.html),
щоб «кинути» кілька `UnsupportedOperationException`, якщо класу `Tree()` передано дерево, яке неможливо переорієнтувати, або якщо між `start node` та `end node` не вдається знайти шлях.
Тести пройдуть, лише якщо ми і викинemo `exception` за допомогою `throw`, і додамо до нього повідомлення.

Щоб кинути `UnsupportedOperationException` з повідомленням, запишіть повідомлення як аргумент типу `exception`:

```java
// when a tree cannot be oriented to a new node POV
throw new UnsupportedOperationException("Tree could not be reoriented");

// when a path cannot be found between a start and end node on the tree.
throw new UnsupportedOperationException("No path found");
```
