# Тести

## Запуск тестів

Трек Haxe покладається на фреймворк для тестування [Buddy](https://github.com/ciscoheat/buddy).
Установити його можна так:

```bash
haxelib install buddy
```

Щоб запустити тести, виконаймо таку команду:

```bash
haxe test.hxml
```

У файлі тестів кожен блок `describe` позначає розділ тестів вправи, а кожен тест записано як блок `it` або `xit`.
Блоки `it` виконуються, коли ми запускаємо тести, а блоки `xit` позначають тести, які ще очікують на запуск.
Коли ми надсилаємо рішення, засіб запуску тестів Exercism виконає всі блоки `it` і `xit`.
Під час роботи локально зазвичай запускається лише перший тест.
Щоб запустити інші тести, змінімо відповідні блоки `xit` на блоки `it` і знову виконаймо `haxe test.hxml`.


Крім того, деякі вправи можуть вимагати встановлення додаткових бібліотек через haxelib.
Коли це так, у вказівках до вправи буде примітка.

## Розвʼязування вправи

Розвʼязати вправу означає зробити так, щоб усі її тести проходили.
Щоб полегшити початок, кожна вправа містить файл із заготовкою реалізації.
Ми можемо використати цей файл як відправну точку для побудови свого рішення.
Якщо вважаємо це доречним, цілком можна видалити або змінити цей файл.
Працюючи над рішенням, спробуймо зосереджуватися на одному тесті за раз.
