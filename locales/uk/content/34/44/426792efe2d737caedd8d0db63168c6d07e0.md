# Вступ

## Nil

`Nil` у Gleam - це тип з єдиним значенням, яке теж називається `Nil`. Він схожий на `void` в інших мовах тим, що його використовують, коли функції немає іншого, доречнішого значення для повернення.

```gleam
io.println("Hello, Joe!")
// -> Nil
```

Значення в Gleam не бувають «nil-able» чи «nullable», як у деяких інших мовах. Значення може бути `Nil`, лише якщо його тип - `Nil`, а значення будь-якого іншого типу ніколи не буває `Nil`.

## IO

Як і більшість мов програмування, Gleam має «побічні ефекти», тож функції можуть читати стан світу й змінювати його, а також повертати значення.

Модуль `gleam/io` зі стандартної бібліотеки Gleam надає функції для виведення рядків тексту (англ. string) у консоль.

```gleam
io.println("Hello, Joe!")
// Hello, Joe!
// -> Nil
```

Інші пакети можуть надавати інші функції введення-виведення, як-от `simplifile`, пакет із функціями для читання й запису файлів.

```gleam
simplifile.read("favourite-colour.txt")
// -> Ok("Pink\n")
```
