# Інструкції

У цій вправі ми допоможемо керувати щоденними справами маленької пекарні за допомогою конструкцій керування потоком у Cairo.

## 1. Обчислити підсумок замовлення

Реалізуйте функцію `calculate_total`, яка обчислює вартість замовлення залежно від типу випічки та кількості:

- Круасан: 3 монети за штуку
- Мафін: 2 монети за штуку
- Печиво: 1 монета за штуку

```rust
calculate_total(Pastry::Croissant, 4) // Returns: 12 (4 * 3)
calculate_total(Pastry::Cookie, 10)   // Returns: 10 (10 * 1)
```

## 2. Застосувати знижки за обсяг

Реалізуйте функцію `apply_discount`, яка застосовує знижки залежно від підсумку замовлення.
Застосуйте відсоткову знижку до підсумку, а потім округліть у менший бік до найближчої цілої монети (округлення вниз).

- Замовлення ≥ 20 монет: знижка 10%
- Замовлення ≥ 10 монет: знижка 5%
- Замовлення < 10 монет: без знижки

```rust
apply_discount(25) // Returns: 22
apply_discount(15) // Returns: 14
apply_discount(8)  // Returns: 8
```

## 3. Створити розклад випікання

Реалізуйте функцію `baking_schedule`, яка створює план випікання на день.
Пекарня випікає партіями по 5 замовлень на годину:

```rust
baking_schedule(18) // Returns: [5, 5, 5, 3] (3 full batches + 3 remaining)
baking_schedule(10) // Returns: [5, 5] (2 full batches)
baking_schedule(3)  // Returns: [3] (1 partial batch)
```

Щоб ефективно розвʼязати кожну задачу, використайте відповідні конструкції керування потоком (`if`/`else`, `loop`).
