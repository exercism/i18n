# Інструкції

У цій вправі нам потрібно перекласти кілька правил із класичної гри Pac-Man у функції Gleam.

У нас є чотири правила для перекладу, і всі вони повʼязані зі станами гри.

> Не переймаймося тим, як утворюються аргументи, просто зосередьмося на тому, щоб поєднати аргументи й повернути потрібний результат.

## 1. Визначте, чи Pac-Man зʼїдає привида

Визначте функцію `eat_ghost`, яка приймає два аргументи (_чи в Pac-Man активна енергетична кулька_ і _чи торкається Pac-Man привида_) і повертає булеве значення (англ. Boolean) залежно від того, чи може Pac-Man зʼїсти привида. Функція має повертати `True` лише тоді, коли в Pac-Man активна енергетична кулька і він торкається привида.

```gleam
eat_ghost(False, True)
// -> False
```

## 2. Визначте, чи Pac-Man набирає очки

Визначте функцію `score`, яка приймає два аргументи (_чи торкається Pac-Man енергетичної кульки_ і _чи торкається Pac-Man точки_) і повертає булеве значення залежно від того, чи набрав Pac-Man очки. Функція має повертати `True`, якщо Pac-Man торкається енергетичної кульки або точки.

```gleam
score(True, True)
// -> True
```

## 3. Визначте, чи Pac-Man програє

Визначте функцію `lose`, яка приймає два аргументи (_чи в Pac-Man активна енергетична кулька_ і _чи торкається Pac-Man привида_) і повертає булеве значення залежно від того, чи програє Pac-Man. Функція має повертати `True`, якщо Pac-Man торкається привида і в нього немає активної енергетичної кульки.

```gleam
lose(False, True)
// -> True
```

## 4. Визначте, чи Pac-Man перемагає

Визначте функцію `win`, яка приймає три аргументи (_чи зʼїв Pac-Man усі точки_, _чи в Pac-Man активна енергетична кулька_ і _чи торкається Pac-Man привида_) і повертає булеве значення залежно від того, чи перемагає Pac-Man. Функція має повертати `True`, якщо Pac-Man зʼїв усі точки і не програв за аргументами, визначеними в частині 3.

```gleam
win(False, True, False)
// -> False
```
