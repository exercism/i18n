# Інструкції

Ми знову працюємо над системою ORM (обʼєктно-реляційне відображення), представленою в [exercise:csharp/object-relational-mapping]().

Аналіз використання нашої ORM показує, що 95% транзакцій виконуються з одного методу, який їх викликає, і було вирішено, що доцільніше мати один метод ORM, який відкриває, записує та фіксує транзакцію.

База даних має такі методи екземпляра:

- `Database.BeginTransaction()` починає транзакцію в базі даних.
- `Database.Write(string data)` записує дані до бази даних у межах транзакції. Якщо вона отримає некоректні дані, буде викинуто виняток. Спроба викликати цей метод без попереднього виклику `BeginTransaction()` спричинить викидання винятку. У разі успіху внутрішній стан бази даних зміниться на `DataWritten`.
- `Database.EndTransaction()` фіксує транзакцію в базі даних. Він може викинути виняток, якщо не вдасться закрити транзакцію або якщо `Database.BeginTransaction()` не було викликано.
- Виклик `Database.Dispose()` очистить базу даних, якщо під час транзакції буде викинуто виняток. Це змінить стан бази даних на `Closed`.

## 1. Запис до бази даних

Реалізуйте метод `Orm.Write()`, щоб почати транзакцію бази даних, записати передані дані та зафіксувати транзакцію. Усі винятки, зокрема `InvalidOperationException`, мають передаватися тому, хто викликав метод, без логування чи будь-якого іншого втручання.

```csharp
Database db = new Database();
Orm orm = new Orm(db);
orm.Write("good write");
// => database has an internal state of State.Closed
orm.Write("bad write");
// => an exception is thrown but database is left with an internal state of State.Closed
orm.Write("bad commit");
// => an exception is thrown but database is left with an internal state of State.Closed
```

## 2. Запис до бази даних і повернення ознаки успішності тому, хто викликав

Минуло кілька місяців відтоді, як було додано `Orm.Write()`, і в команді немає одностайності. Багато розробників хотіли б, щоб _ORM_ обробляла помилки, коли викидається виняток, і просто повертала тому, хто викликав, ознаку успіху.

Будь ласка, реалізуйте метод `Orm.WriteSafely()`, щоб почати транзакцію бази даних, записати передані дані та зафіксувати транзакцію (як описано вище). Він має повертати `true`, якщо _запис_ був успішним, інакше `false`. Не намагайтеся логувати виняток.

```csharp
Database db = new Database();
Orm orm = new Orm(db);
orm.WriteSafely("good write");
// => true
orm.WriteSafely("bad write");
// => false
orm.WriteSafely("bad commit");
// => false
```
