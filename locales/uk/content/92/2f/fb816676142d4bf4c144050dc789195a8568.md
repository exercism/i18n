# Булевий тип

У Cairo булевий тип (булеві значення, англ. Boolean) відіграє ключову роль у логічних операціях та умовних конструкціях.
Булеві значення в Cairo за розміром дорівнюють одному `felt252`, що забезпечує ефективне використання простору й водночас зберігає простоту логіки правда/неправда.

Булевий тип у Cairo задається ключовим словом `bool`.
Це дає змогу оголошувати булеві змінні та працювати з ними в межах мови.
Наприклад, розгляньмо такий приклад:

```rust
fn main() {
    let t = true;
    let f: bool = false; // with explicit type annotation
}
```

У цьому прикладі оголошено дві булеві змінні.
Змінній `t` присвоєно значення `true`, а її тип визначено неявно, тоді як змінна `f` явно позначена типом `bool` і отримала значення `false`.

Важливо зауважити, що під час оголошення булевої змінної в Cairo обовʼязково використовувати як значення літерали `true` або `false`.
Це означає, що цілочисельні літерали, як-от `0` чи `1`, не можна використовувати замість `false` або `true`.
Суворе дотримання цього правила забезпечує безпеку типів і запобігає потенційним логічним помилкам під час розробки смартконтрактів.

## Булеві оператори в Cairo

- `||` (логічне або): повертає `true`, якщо хоча б один з операндів дорівнює `true`.
- `&&` (логічне і): повертає `true`, якщо обидва операнди дорівнюють `true`.
- `!` (логічне заперечення): повертає протилежне булеве значення операнда.

## Приклад коду

Наведений фрагмент коду показує, як використовувати булеві типи в Cairo.
У ньому показано оголошення булевих змінних, присвоєння булевих виразів і використання тверджень для перевірки правильності булевої логіки:

```rust
fn main() {
    // Declaration of Boolean variables
    let t: bool = true;
    let f: bool = false;

    // Boolean expression evaluation
    let true_expr = 5 == 5; // true
    let false_expr = 7 == 5; // false

    // Using Boolean operators
    let or_expr = t || f; // true || false => true
    let and_expr = t && f; // true && false => false
    let not_expr = !f; // !false => true

    // Assertions to verify the correctness
    assert(t == true_expr, 'this should be true'); // t == true
    assert(f == false_expr, 'this should be false'); // f == false
    assert(or_expr == true, 'this should be true for OR'); // true
    assert(and_expr == false, 'this should be false for AND'); // false
    assert(not_expr == true, 'this should be true for NOT'); // true
}
```
