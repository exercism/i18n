# Інструкції

Ми в прибережній радіорубці, стежимо за радіообміном на каналі: повідомлення надходять ефіром, ми їх записуємо, а відповіді відправляємо назад. Пʼять маленьких слів виконують роботу за одну зміну.

Тести подають нам на вхід дані `<string-reader>` (вхідний трафік) і використовують `<string-writer>` для вихідних даних, але кожне слово тут працює так само зі справжнім `<file-reader>` або сокетом.

## 1. Вислухати все

Визначте `hear-out`, щоб він зчитав увесь вхідний потік в один рядок тексту (англ. string).

```factor
"all quiet on the channel" <string-reader> hear-out .
! => "all quiet on the channel"
```

## 2. Порахувати повідомлення

Визначте `count-messages`, щоб він читав кожен рядок із вхідного потоку й повертав, скільки їх було.

```factor
"alpha\nbravo\ncharlie\n" <string-reader> count-messages .
! => 3
```

## 3. Повторити останній виклик

Визначте `echo-back`, щоб він читав кожен рядок і повертав **останній у верхньому регістрі**. Це стандартна радіовідповідь «повторюю: X».

```factor
"alpha\nbravo\n" <string-reader> echo-back .
! => "BRAVO"
```

## 4. Передати повідомлення

Визначте `broadcast`, щоб він записував повідомлення в наданий потік запису й скидав потік, аби воно вийшло негайно. Нічого не повертає.

```factor
[ "mayday" output-stream get broadcast ] with-string-writer .
! => "mayday"
```

## 5. Захопити вихідні дані quotation

Визначте `capture`, щоб він запускав quotation із новим string-writer як поточним вихідним потоком і повертав усе, що надрукував quotation. Цей quotation не приймає аргументів, він просто пише в поточний потік, як завжди.

```factor
[ "test broadcast" print ] capture .
! => "test broadcast\n"
```
