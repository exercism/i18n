# Вступ

## Множини

`Set` - це невпорядкована колекція, яка (на відміну від `List`) гарантовано не містить дублікатів значень.

Параметр узагальненого типу інтерфейсу `Set` позначає тип елементів, що містяться в `Set`:

```java
Set<Integer> ints = Set.of(1, 2, 3);
Set<String> strings = Set.of("alpha", "beta", "gamma");
Set<Object> mixed = Set.of(1, false, "foo");
```

Зауважмо, що метод `Set.of()` створює [_незмінний_][unmodifiable-set-docs] екземпляр `Set`.
Спроба викликати методи `add` і `remove` у цього екземпляра призведе до винятку під час виконання.

Щоб створити змінюваний `Set`, потрібно створити екземпляр класу, який реалізує інтерфейс `Set`.
Найчастіше для цього використовують вбудований клас [`HashSet`][hashset-docs], який реалізує цей інтерфейс.

```java
Set<Integer> ints = new HashSet<>();
```

Інтерфейс `Set` розширює інтерфейси [`Collection`][collection-docs] і [`Iterable`][iterable-docs], а тому має багато спільних методів з іншими типами колекцій.
Однак помітна відмінність від інтерфейсу `Collection` полягає в тому, що методи `add` і `remove` повертають `boolean` (а не `void`), який указує, чи містився елемент у множині на момент виклику методу:

```java
Set<Integer> set = new HashSet<>();
set.add(1);
// => true
set.add(2);
// => true
set.add(1);
// => false
set.size();
// => 2
set.contains(1);
// => true
set.contains(3);
// => false
set.remove(3);
// => false
set.remove(2);
// => true
set.size();
// => 1
```
