# Доповнення до інструкцій

## Заготовка

`src/TreeBuilding.hs` уже містить робоче рішення, яке проходить усі тести.
Воно повільне й важко читається, і ваше завдання - зробити його кращим, не зламавши тести.

`buildTree` повертає `Nothing`, коли записи не утворюють коректного дерева.

## Зміна представлення

Тести ніколи не використовують конструктори `Tree` напряму.
Натомість вони будують очікувані дерева за допомогою функції

```haskell
node :: Int -> [Tree] -> Tree
```

де `node i children` - це вузол з id `i` і заданими дочірніми вузлами, у порядку зростання id.

Це означає, що ми можемо вільно змінити спосіб представлення `Tree`, наприклад так:

```haskell
import qualified Data.Tree as T

type Tree = T.Tree Int

node :: Int -> [Tree] -> Tree
node = T.Node
```

аби лише `Tree` і далі мав екземпляри `Eq` і `Show`, а `node` зберігав своє значення.
Якщо використовувати бібліотеку на кшталт `containers`, не забудьте додати її до `dependencies` у `package.yaml`.
