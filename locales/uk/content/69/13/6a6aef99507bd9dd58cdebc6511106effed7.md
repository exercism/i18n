# Інструкції

У цій вправі ми напишемо трохи коду, щоб допомогти Ларрі, прибульцю з Ліспу, розбирати й форматувати рядки журналу (англ. string). Ці рядки журналу надходять із різних систем, і їх потрібно обробити, щоб їхні повідомлення можна було показати на інформативному дисплеї моніторингу.

Рядки журналу мають вигляд `"[<level>]: <message>"`. Рівень буде одним із таких значень: `info`, `warn` або `ohno`.

## 1. Витягти повідомлення

Визначте функцію `log-message`, яка приймає рядок журналу й повертає повідомлення, що в ньому міститься.

```lisp
(log-message "[ohno]: whoops!") ; => "whoops!"
```

## 2. Визначити серйожність

Рівень рядка журналу визначає його серйозність.

- рівень `info` означає серйозність `:everything-ok`
- рівень `warn` означає серйозність `:getting-worried`
- рівень `ohno` означає серйозність `:run-for-cover`

Визначте функцію `log-severity`, яка приймає рядок журналу й повертає правильну серйозність.

```lisp
(log-severity "[warn]: might want to get that checked") ; => :getting-worried
```

## 3. Як упоратися з примхами реальності

На жаль, іноді рядки журналу відформатовано неправильно. Зокрема, рівень журналу може бути не повністю в нижньому регістрі, як зазначено вище. Змініть `log-severity`, щоб вона це враховувала.

```lisp
(log-severity "[WaRn]: string case system failing") ; => :getting-worried
```

## 4. Переформатування повідомлення журналу відповідно до серйозності

Залежно від серйозності повідомлення потрібно змінювати по-різному:

- якщо серйозність `:everything-ok`, повідомлення потрібно перевести в нижній регістр.
- якщо серйозність `:getting-worried`, кожне слово в повідомленні потрібно написати з великої літери.
- якщо серйозність `:run-for-cover`, повідомлення потрібно перевести у верхній регістр.

Визначте функцію `log-format`, яка приймає повідомлення журналу й повертає належно відформатоване повідомлення.

```lisp
(log-format "[ohno]: whoops!") ; => WHOOPS!
```
