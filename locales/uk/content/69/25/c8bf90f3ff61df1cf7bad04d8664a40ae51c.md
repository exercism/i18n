# Докладніше

У концепції [Пари та словники][pairs-dicts] ми розглянули основи типу словник у Julia.

Оскільки [`Dict`-и][dict] належать до важливих і часто вживаних типів колекцій, для роботи з ними існує також багато функцій.

## Отримання записів

Найпростіший спосіб дістати запис - за ключем (як і в багатьох мовах).
Однак спроба звернутися до неіснуючого ключа викликає `KeyError`.

```julia-repl
julia> d = Dict(i => ('a':'c')[i] for i in 1:3)
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'

julia> d[2]
'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)

# missing key
julia> d[4]
ERROR: KeyError: key 4 not found
```

Ми могли б перевірити наявність ключа, перш ніж намагатися отримати його (наприклад, за допомогою `haskey(d, 4)` або `4 ∈ keys(d)`), але іноді корисно просто отримати типове значення для відсутніх ключів.

Для цього є функція [`get()`][get] й її варіант, який змінює словник, [`get!()`][get-bang].
Вони різняться тим, чи додається «відсутній» ключ до `Dict`.

```julia-repl
julia> get(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)

# get() leaves Dict unchanged
julia> d
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'

julia> get!(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)

# get!() adds new key to Dict
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'
```

Раніше в концепції ми бачили, що `delete!()` видаляє запис за ключем.
Це можна поєднати з отриманням значення, скориставшись функцією `pop!()`.

```julia-repl
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'

# popped value is returned
julia> pop!(d, 3)
'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)

# Dict is shrunk
julia> d
Dict{Int64, Char} with 3 entries:
  4 => '!'
  2 => 'b'
  1 => 'a'
```

## Ітерація

Коли ми перебираємо `Dict`, він типово видає пари `key => value`.
До складників можна дістатися звичними позначеннями `.first` і `.second`.

```julia-repl
# d is from the previous example
julia> [(kv.first, kv.second) for kv in d]
3-element Vector{Tuple{Int64, Char}}:
 (4, '!')
 (2, 'b')
 (1, 'a')
```

Часто нам потрібні лише ключі або лише значення, і зробити це легко.

```juliajulia> [k for k in keys(d)]
julia> [k for k in keys(d)]
3-element Vector{Int64}:
 4
 2
 1

julia> [v for v in values(d)]
3-element Vector{Char}:
 '!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
```

## Злиття

Поєднувати два `Dict` буває корисно, але слід чітко розуміти, що ми збираємося робити з ключами, які присутні більш ніж в одному вхідному словнику.

Функції [`merge()`][merge] і [`merge!()`][merge-bang] поєднують довільну кількість переданих `Dict` зліва направо.

Значення наявних ключів просто перезаписуються, тож «перемагає» найправіший `Dict`.

```julia-repl
julia> d3 = Dict("color" => "red", "shape" => "circle")
Dict{String, String} with 2 entries:
  "shape" => "circle"
  "color" => "red"

julia> d4 = Dict("color" => "blue", "coords" => (3, 2))
Dict{String, Any} with 2 entries:
  "color"  => "blue"
  "coords" => (3, 2)

# color from d3 is lost
julia> merge(d3, d4)
Dict{String, Any} with 3 entries:
  "shape"  => "circle"
  "color"  => "blue"
  "coords" => (3, 2)
```

Функції [`mergewith()`][mergewith] і [`mergewith!()`][mergewith-bang] дають нам змогу передати функцію першим аргументом, щоб визначити, як зливати повторювані ключі.
Додавання - простий приклад.

```julia-repl
julia> d5 = Dict("color" => "red", "area" => 3)
Dict{String, Any} with 2 entries:
  "area"  => 3
  "color" => "red"

julia> d6 = Dict("shape" => "circle", "area" => 5)
Dict{String, Any} with 2 entries:
  "shape" => "circle"
  "area"  => 5

# area values are added, not overwritten
julia> mergewith(+, d5, d6)
Dict{String, Any} with 3 entries:
  "shape" => "circle"
  "area"  => 8
  "color" => "red"
```

Конкатенація двох векторів - ще одна поширена операція під час злиття.
Для цього Julia використовує функцію [`vcat()`][vcat], а причини пояснено в концепції [`Multi Dimensional Arrays`][multidim].

```julia-repl
julia> d7 = Dict("vals" => [1, 2, 3])
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [1, 2, 3]

julia> d8 = Dict("vals" => [4, 5])
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [4, 5]

julia> mergewith(vcat, d7, d8)
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [1, 2, 3, 4, 5]
```

Для кількох [`Set`-ів][sets] відповідна функція злиття - [`union`][union].

Зауважмо, що функції `mergewith` - гарний приклад [функцій вищого порядку][hof] у дії.
