# Про концепцію

До окремих символів у `String` можна отримати доступ за допомогою індексування, яке застосовують до масивів.
Однак [індекси][string-indices], які використовуються для рядків тексту (англ. string), _не_ є цілими числами, і з ними не можна працювати напряму.
Натомість їх потрібно обчислювати на основі якогось іншого відомого індексу, наприклад `startIndex`, який вказує на позицію першого символу в непорожньому рядку тексту, користуючись методами з бібліотек [`String`][string-docs] та [`NSString`][nsstring-docs] (коли імпортовано модуль `Foundation`, рядки тексту у Swift мають доступ до всіх властивостей і методів NSString).

Наприклад, маємо такий рядок тексту:

```swift
let csv = "apple,pear,peach,orange,cherry,lime,goosberry"
```

Не можна написати `csv[21]`, щоб отримати «g» у слові «orange»; натомість потрібно обчислити значення типу `String.Index` і передати саме його.
Зауважмо, що ці індекси не призначені для того, щоб людина читала їх безпосередньо.
Їх називають _непрозорими індексами_, бо людині не потрібно знати, що всередині них.

```swift
let index = csv.index(csv.startIndex, offsetBy: 21)
csv[index]
// "g"
print(index)
// prints Index(_rawBits: 1376513)
```

Звернімо увагу, однак, що якщо зсув не є дійсним індексом, тобто якщо він вказує на індекс перед `startIndex` або після `endIndex`, операція спричинить помилку й аварійно завершить програму.
Щоб запобігти цій проблемі, можна вказати обмежувальний індекс.
Він повертає опціональний індекс, а для індексів, які інакше були б недійсними, повертає nil.

```swift
let tooFar = csv.index(csv.startIndex, offsetBy: 200)
// error: Execution was interrupted, reason: EXC_BAD_INSTRUCTION (code=EXC_I386_INVOP, subcode=0x0).
let tooFarButSafe = csv.index(csv.startIndex, offsetBy: 200, limitedBy: csv.endIndex)
// nil
```

Крім того, індекси не можна використовувати для різних рядків тексту.
Наприклад, якщо взяти обчислений вище `index` для «g» в «orange» і проіндексувати ним рядок тексту `fam = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶, this is our cat: 🐱!"`, тобто `fam[index]`, програма аварійно завершиться.

Причин для всього цього багато, але всі вони зводяться до того, що «з Unicode усе непросто».

Загалом, якщо потрібен довільний доступ до окремих символів, імовірно, варто використати іншу структуру даних, наприклад `Array<Character>`.

## Кілька корисних методів

У Swift є методи `first` і `last`, щоб отримати перший та останній символ рядка тексту.
Ці методи повертають опціональний символ, тож якщо рядок тексту порожній, вони повернуть nil.

```swift
let str = "Hello, world!"
print(str.first) // Prints Optional("H")
print(str.last)  // Prints Optional("!")
```

Також можна скористатися методами `prefix` і `suffix`, щоб отримати підрядок рядка тексту.
Ці методи приймають ціле число як аргумент і повертають підрядок, що містить перші або останні n символів рядка тексту.

```swift
let str = "Hello, world!"
print(str.prefix(5)) // Prints "Hello"
print(str.suffix(6)) // Prints "world!"
```

## Глибоке занурення: індексація в Unicode

~~~~exercism/advanced

Стандарт [Unicode][unicode] призначений для кодування тексту; він містить велику кількість символів із багатьох мов і систем письма.
Це надмножина ASCII, тобто всі символи ASCII є також символами Unicode.
Unicode використовує кодування зі змінною довжиною, тобто деякі символи займають більше байтів, ніж інші.
А чому це важливо, пояснимо в наступному розділі.

Тож, щоб насправді побачити проблему, доведеться звернутися до інших мов (не англійської). Візьмімо символ «ü» з німецької мови (зауважмо, що тут ми використовуємо двобайтовий варіант, є також однобайтовий).
Спочатку він може мати вигляд одного символу, але насправді це два символи: «u» та «¨». Тож якщо надрукувати довжину рядка тексту «ü», у мовах на кшталт Python вона дорівнюватиме 2.
Однак ми як користувачі чи програмісти сказали б, що це один символ, і Swift із нами погоджується.
Але чому Swift робить так, а Python ні?
Річ у тім, що Swift використовує інше представлення рядків тексту, ніж Python.
У Python рядки тексту подаються як послідовність байтів, тобто довжина рядка тексту дорівнює кількості байтів, які він займає в памʼяті.
У Swift рядки тексту подаються як послідовність символів, тобто довжина рядка тексту дорівнює кількості символів, які він містить.
Це дуже важлива відмінність, адже вона означає, що у Swift довжина рядка тексту не обовʼязково збігається з кількістю байтів, які він займає в памʼяті.
Саме через це ми не можемо індексувати рядки тексту цілими числами.
