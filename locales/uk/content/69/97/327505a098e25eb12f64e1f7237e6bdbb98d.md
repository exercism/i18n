# Інструкції

У цій вправі ми будемо обробляти рядки із записаного звіту.
Кожен рядок журналу - це рядок тексту (англ. string) такого формату: `"[<LEVEL>]: <MESSAGE>"`.

Існує три різні рівні логування:

- `INFO`
- `WARNING`
- `ERROR`

На нас чекають три завдання, кожне з яких приймає рядок журналу й просить щось із ним зробити.

## 1. Отримати повідомлення з рядка журналу

Реалізуйте метод `log_line::message`, щоб він повертав повідомлення рядка журналу:

```cpp
log_line::message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

## 2. Отримати рівень логування з рядка журналу

Реалізуйте метод `log_line::log_level`, щоб він повертав рівень логування рядка журналу, причому у верхньому регістрі:

```cpp
log_line::log_level("[ERROR]: Invalid operation")
// => "ERROR"
```

## 3. Переформатувати рядок журналу

Реалізуйте метод `log_line::reformat`, який переформатовує рядок журналу, ставлячи повідомлення першим, а рівень логування після нього в дужках:

```cpp
log_line::reformat("[INFO]: Operation completed")
// => "Operation completed (INFO)"
```
