# Вступ

## Простори імен

Важливий метод організації коду - використання просторів імен.
Дві функції можуть мати конфлікт імен, який можна розвʼязати, розмістивши їх у різних просторах імен.
Простори імен можна вкладати один в одного, що допомагає структурувати великі кодові бази.
Доступ до просторів імен здійснюється через оператор дозволу області видимості `::`.

У прикладі нижче показано використання двох різних функцій `foo`.
Їх можна використати разом, якщо перед кожною дописати назву відповідного простору імен.

```cpp
namespace my_ns {
    int foo() {
        return 44;
    }
    namespace my_inner_ns {
        int baz() {
            return 90;
        }
    }
}
namespace my_other_ns {
    int foo() {
        return -2;
    }
}

int myresult{my_ns::foo() + my_other_ns::foo() * my_ns::my_inner_ns::baz()};
```
