# Потік керування

Вирази `if` і цикли керують потоком виконання в Cairo так:
`

- **Вирази `if`** умовно виконують код залежно від того, чи умова обчислюється як `true`.
- **Цикли** (як-от `loop`, `while` і `for`) повторно виконують код, поки виконується задана умова, або доки не спрацює умова виходу.

Ці конструкції є основою для реалізації логіки та ітерації в Cairo.

## Вирази `if`

Вирази `if` у Cairo дають змогу керувати потоком виконання залежно від умовної логіки.
Вони мають структуру, у якій код виконується залежно від того, яке булеве значення (англ. Boolean) має умова: `true` чи `false`.

```rust
fn main() {
    let temperature = 30;

    if temperature > 25 {
        println!("It's hot outside!");
    }
}
```

Цей приклад демонструє простий блок `if` у Cairo.
Повідомлення `"It's hot outside!"` виводиться лише тоді, коли умова `temperature > 25` обчислюється як `true`.
Якщо умова `false`, жоден код не виконується, і програма продовжує роботу.

```rust
fn main() {
    let number: u32 = 5;

    if number < 10 {
        println!("The number is less than 10.");
    } else {
        println!("The number is 10 or greater.");
    }
}
```

Запуск цього коду виведе в консоль `"The number is less than 10."`.

### Робота з кількома умовами за допомогою `else if`

Можна використовувати кілька умов, поєднуючи `if` і `else` у виразі `else if`.

```rust
fn main() {
    let score: u64 = 85;

    if score >= 90 {
        println!("Grade: A");
    } else if score >= 80 {
        println!("Grade: B");
    } else if score >= 70 {
        println!("Grade: C");
    } else {
        println!("Grade: F");
    }
}
```

Запуск цього коду виведе в консоль `"Grade: B"`.

### Використання `if` в інструкції `let`

Вираз `if` у Cairo можна використати в правій частині інструкції `let`, щоб присвоїти результат змінній.

```rust
fn main() {
    let condition: bool = true;
    let number: felt252 = if condition {
        5
    } else {
        6
    };

    if number == 5 {
        println!("condition was true and number is {}", number);
    }
}
```

## Цикли

Цикли належать до фундаментальних конструкцій, які дозволяють повторювати блоки коду та забезпечують ефективне й контрольоване виконання завдань.
Цикли можуть перебирати послідовність або повторно виконувати код залежно від умови.
Cairo має три основні різновиди циклів:

- **loop**: базовий цикл, який виконується нескінченно, доки його явно не зупинити за допомогою інструкції `break`.
- **while**: продовжує виконуватися, поки задана умова залишається `true`.
  Зупиняється тоді, коли умова стає `false`.
- **for**: перебирає елементи колекції, наприклад масиву, виконуючи код для кожного елемента.

### Повторення коду за допомогою `loop`

Ключове слово `loop` каже Cairo виконувати блок коду знову й знову, нескінченно, або доки ми явно не скажемо йому зупинитися.

```rust
fn main() {
    loop {
        println!("again!");
    }
}
```

Виконання цього коду нескінченно виводитиме в консоль `"again!"`, доки в програмі не закінчиться gas або доки ми не зупинимо її вручну.

> Примітка: Cairo не дозволяє запустити програму з нескінченним циклом, бо містить лічильник gas.
> Лічильник gas - це механізм, який обмежує обсяг обчислень, який можна виконати в програмі.
> Gas - це одиниця вимірювання, яка виражає обчислювальну вартість інструкції.
> Коли лічильник gas вичерпається, програма зупиниться.

Щоб вийти з циклу, розмістимо ключове слово `break` усередині циклу й таким чином скажемо програмі, коли припинити його виконання.

```rust
fn main() {
    let mut i: usize = 0;
    loop {
        if i > 10 {
            break;
        }
        println!("i = {}", i);
        i += 1;
    }
}
```

Ключове слово `continue` каже програмі перейти до наступної ітерації циклу й пропустити решту коду в цій ітерації.

```rust
fn main() {
    let mut i: usize = 0;
    loop {
        if i > 10 {
            break;
        }
        if i == 5 {
            i += 1;
            continue;
        }
        println!("i = {}", i);
        i += 1;
    }
}
```

Під час виконання цієї програми значення `i` не виведеться, коли воно дорівнює `5`.

#### Повернення значень із `loop`

Ми можемо повернути значення з `loop`, використавши ключове слово `break`, після якого стоїть значення, яке хочемо повернути.
Це дає змогу вийти з `loop` і передати результат решті коду.

```rust
fn main() {
    let mut counter = 0;

    let result = loop {
        if counter == 10 {
            break counter * 2;
        }
        counter += 1;
    };

    println!("The result is {}", result); // prints "The result is 20"
}
```

### Умовні цикли з `while`

`while` виконує код, поки умова дорівнює `true`, і завершується, коли умова стає `false`.

```rust
fn main() {
    let mut number = 3;
    while number != 0 {
        println!("{}!", number);
        number -= 1;
    }
    println!("LIFTOFF!!!");
}
```

### Перебирання колекції за допомогою `for`

`for` перебирає кожен елемент колекції, виконуючи код для кожного елемента.

```rust
fn main() {
    let a = [10, 20, 30, 40, 50].span();
    for element in a {
        println!("the value is: {}", element);
    }
}
```
