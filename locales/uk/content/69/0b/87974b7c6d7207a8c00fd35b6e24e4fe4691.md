# Додаток до інструкцій

## Слова

- `<bst> ( data-seq -- tree )` - побудувати дерево, вставляючи кожен елемент із `data-seq` по порядку.
- `sorted-data ( tree -- seq )` - повернути елементи дерева за зростанням (обхід у порядку).

## Ієрархія кортежів

Вузол у двійковому дереві пошуку або *порожній*, або *має дані та два піддерева*. Змоделюймо це як невелику ієрархію успадкування:

```factor
TUPLE: bst ;
TUPLE: leaf < bst ;
TUPLE: branch < bst data left right ;
```

`bst` - абстрактний батьківський тип; `leaf` - випадок порожнього дерева; `branch` містить значення і двох нащадків `bst` (кожен із них своєю чергою або `leaf`, або `branch`).

## Упорядкування

Порівнюймо дані за допомогою `before=?` (з `math.order`), який працює як із рядками тексту (англ. string), так і з числами: тести використовують рядкові дані, як-от `"1"`, `"2"`, `"3"`.
