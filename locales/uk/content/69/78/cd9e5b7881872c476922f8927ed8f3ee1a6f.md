## Встановлення Z3

### Завантажте Python (якщо його ще не встановлено)

Найновішу версію Python можна завантажити [тут.](https://python.org)

* Під час встановлення обовʼязково позначте пункт, який додає Python до PATH

### Завантажте Visual Studio (якщо її ще не встановлено)

Найновішу версію Visual Studio можна завантажити [тут.](https://visualstudio.microsoft.com/downloads/?utm_medium=microsoft&utm_source=docs.microsoft.com&utm_campaign=inline+link&utm_content=download+vs2019)

* Під час встановлення виберіть робоче навантаження **Python Development**
* Позначте всі необовʼязкові пакети для розробки Python у правій частині вікна

Після встановлення відкрийте Visual Studio і налаштуйте початкові параметри.

### Встановіть команди Git

Інструкції зі встановлення Git можна знайти [тут.](https://git-scm.com/book/en/v2/Getting-Started-Installing-Git)

* Потрібно [додати Git до системних змінних](https://stackoverflow.com/questions/4492979/git-is-not-recognized-as-an-internal-or-external-command)

### Клонуйте Z3

Перейдіть до [репозиторію Z3 на Github](https://github.com/Z3Prover/z3), щоб переглянути проєкт.

Відкрийте термінал на своєму компʼютері та перейдіть до місця, де хочете клонувати репозиторій Z3 (наприклад: C:\Z3).

Звідти виконайте:

```bash
git clone https://github.com/z3Prover/z3.git
```

### Збірка Z3 у Windows за допомогою командного рядка Visual Studio

Відкрийте **Developer Command Prompt for VS 2019** через меню «Пуск».

Перейдіть до папки, у яку ви клонували репозиторій Z3 (наприклад: C:\Z3).

Для 32-бітної збірки виконайте:

```bash
python scripts/mk_make.py
```

Для 64-бітної збірки виконайте:

```bash
python scripts/mk_make.py -x
```

а потім виконайте:

```bash
cd build
pip install z3-solver
```



Тепер можна відкрити Visual Studio і запустити Z3 з його Python-привʼязкою.


Щоб перевірити, виконайте:
```python
from x3 import *
x = Real('x')
y = Real('y)
s = Solver()
s.add(x + y > 5, x > 1, y > 1)
print(s.check())
print(s.model())
```

Останні два рядки мають вивести `sat` і `[y = 4, x = 2]`.
