# Встановлення

Щоб встановити Reason, знадобиться Node Package Manager (npm). Дотримуйтеся інструкцій [тут](https://www.npmjs.com/get-npm)

Після цього встановіть Reason такою командою:
```
npm install -g bs-platform
```

Reason має інтеграції з низкою редакторів, дивіться [тут](https://reasonml.github.io/docs/en/editor-plugins.html#officially-supported-editors)

Деякі інструменти командного рядка (зокрема REPL, що дозволяє обчислювати вирази Reason у командній оболонці) можна знайти [тут](https://github.com/reasonml/reason-cli)
