# Вступ

Як і властивості, що зберігають дані у структурах і класах, можна також визначати _методи_, які зберігають функції у структурі або класі.

Методи визначають так само, як звичайну функцію, лише всередині тіла структури або класу. Звернімо увагу: якщо функція змінює значення властивості у структурі, перед нею має стояти ключове слово `mutating`. Крім того, якщо властивість може змінювати метод, цю властивість потрібно визначати за допомогою `var`, а не `let`, так само як і звичайні змінні.

```swift
struct CharacterStats {
  var health = 0.0
  var speed = 0
  var strength = 0

  mutating func takeHit(_ damage: Double) {
    health = max(0.0, health - damage)
  }
  func canLift(_ weight: Int) -> Bool {
    weight < strength * 100
  }
}
```

Ці методи можна викликати через точкову нотацію, так само як і властивості.

```swift
var stats = CharacterStats(health: 72.8, speed: 19, strength: 6)
stats.canLift(500)
// => true
```
