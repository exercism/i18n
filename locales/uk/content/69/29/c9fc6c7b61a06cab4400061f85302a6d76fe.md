# Інструкції

У цій вправі ми будемо обробляти рядки журналу.

Кожен рядок журналу - це рядок тексту (англ. string), відформатований так: `"[<LEVEL>]: <MESSAGE>"`.

Є три різні рівні журналу:

- `INFO`
- `WARNING`
- `ERROR`

У нас є три завдання, кожне з яких приймає рядок журналу й просить зробити з ним щось.

## 1. Отримати повідомлення з рядка журналу

Реалізуйте функцію `message`, щоб вона повертала повідомлення з рядка журналу:

```gleam
message("[ERROR]: Invalid operation")
// -> "Invalid operation"
```

Приберіть усі пробільні символи на початку та в кінці:

```gleam
message("[WARNING]:  Disk almost full\r\n")
// -> "Disk almost full"
```

## 2. Отримати рівень журналу з рядка журналу

Реалізуйте функцію `log_level`, щоб вона повертала рівень журналу з рядка журналу в нижньому регістрі:

```gleam
log_level("[ERROR]: Invalid operation")
// -> "error"
```

## 3. Переформатувати рядок журналу

Реалізуйте функцію `reformat`, яка переформатовує рядок журналу так, щоб повідомлення йшло першим, а рівень журналу був після нього в дужках:

```gleam
reformat("[INFO]: Operation completed")
// -> "Operation completed (info)"
```
