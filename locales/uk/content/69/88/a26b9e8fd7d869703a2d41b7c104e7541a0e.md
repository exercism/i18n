# Про цикл `for`

[Цикл `for`](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/for.html) дає змогу багаторазово виконувати групу інструкцій, доки не виконається певна умова.
Цикл складається з чотирьох частин:

```java
for (initialization; test; update) {
    body;
}
```

`initialization` задає початковий стан циклу і виконується рівно один раз на початку циклу.
Зазвичай тут оголошують і присвоюють змінну, яку використовують у виразі `test` та виразі `update`.
Наприклад:

```java
int i = 1
```

Вираз `test` перевіряє, чи має цикл завершитися.
Якщо він дає правду, виконаються тіло циклу, а потім вираз `update`.
Якщо він дає неправду, не виконається ані тіло, ані вираз `update`, і виконання продовжиться після закривної дужки циклу.
Зазвичай він перевіряє змінну, присвоєну в блоці ініціалізації.
Наприклад:

```java
i <= 10
```

Після виконання тіла циклу виконується вираз `update`.
Зазвичай він збільшує або зменшує змінну циклу на певне значення.
Наприклад:

```java
i++
```

Цикл `for`, який друкує перші чотири квадрати, матиме такий вигляд:

```java
for (int i = 1; i <= 4; i++) {
    System.out.println(i * i);
}

/* =>
1
4
9
16
*/
```

Якщо треба перебрати кожен елемент колекції, краще використати цикл `for-each`, але це можна зробити й циклом `for` ось так:

```java
for (int i = 0; i < array.length; i++) {
    System.out.print(array[i]);
}
```

Цикл `for` має деякі переваги перед циклом `for-each`:

- Можна почати або зупинитися на потрібному індексі.
- Можна використати будь-яку булеву умову завершення (англ. Boolean).
- Можна пропускати елементи, налаштувавши збільшення змінної циклу.
- Можна обробляти колекції від кінця до початку, ведучи відлік назад.
- Можна використовувати цикл `for` у ситуаціях, не повʼязаних із колекціями.
