# Тести

## Запуск тестів

Щоб запустити тести, виконайте таку команду:

```bash
make
```

## Розвʼязування вправи

Розвʼязати вправу означає домогтися, щоб усі її тести пройшли. Типово під час запуску тестів виконується лише один тест (перший). Це зроблено навмисно, щоб можна було зосередитися лише на тому, щоб цей один тест пройшов. Коли він пройде, можна увімкнути наступний тест, прибравши рядок `TEST_IGNORE()`. Коли всі тести увімкнено і реалізація проходить їх усі, вправу розвʼязано!
