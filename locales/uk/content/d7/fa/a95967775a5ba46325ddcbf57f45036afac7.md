# Вступ

Перетворення типів у Cairo дають змогу трансформувати дані з одного типу в інший, що забезпечує гнучку та безпечну роботу з даними.

## Основи

Cairo надає кілька механізмів перетворення типів:

### Пряме приведення

Для сумісних числових типів можна використовувати пряме приведення:

```rust
let small_number: u8 = 42;
let big_number: u32 = small_number.into();
```

### Трейт `Into`

Трейт `Into` уможливлює перетворення з одного типу в інший:

```rust
let value: u16 = 100;
let converted: u32 = value.into();
```

### Трейт `TryInto`

Для перетворень, які можуть не вдатися, використаймо `TryInto`, який повертає `Option`:

```rust
let large_value: u32 = 70000;
let small_value: Option<u16> = large_value.try_into();

match small_value {
    Option::Some(v) => println!("Converted: {}", v),
    Option::None => println!("Conversion failed"),
}
```

## Власні перетворення типів

Можна реалізувати `Into` для власних типів:

```rust
#[derive(Drop)]
struct Celsius {
    value: i32,
}

#[derive(Drop)]
struct Fahrenheit {
    value: i32,
}

impl CelsiusIntoFahrenheit of Into<Celsius, Fahrenheit> {
    fn into(self: Celsius) -> Fahrenheit {
        Fahrenheit { value: (self.value * 9) / 5 + 32 }
    }
}
```

## Міркування щодо безпеки

- Використовуймо `TryInto`, коли перетворення може не вдатися (наприклад, з більшого типу в менший)
- Використовуймо `Into`, коли перетворення завжди успішне
- Завжди опрацьовуймо випадки `Option::None`, які повертає `TryInto`
- Зважаймо на переповнення та недоповнення під час перетворення між знаковими та беззнаковими типами
