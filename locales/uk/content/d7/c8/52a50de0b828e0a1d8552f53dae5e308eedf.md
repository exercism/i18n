# Інструкції

Сара працює над новою рольовою грою і потребує нашої допомоги з механікою гравця.

## 1. Визначте кортеж `player`

Визначте клас кортежу `player` із чотирма слотами та типовими значеннями:

| слот     | типове значення |
| -------- | ------- |
| `name`   | `f`     |
| `level`  | `0`     |
| `health` | `100`   |
| `mana`   | `f`     |

Коли клас визначено, гравця можна створити як літерал:

```factor
T{ player { name "Merlin" } { level 5 } } .
! => T{ player { name "Merlin" } { level 5 } }
```

## 2. Представте гравця

Визначте `introduce`, щоб вона повертала імʼя гравця. Гравці в режимі
невидимості приховують своє імʼя (`name` дорівнює `f`), і їх слід
представляти як `"Mighty Magician"`.

```factor
T{ player { name "Merlin" } } introduce .
! => "Merlin"

T{ player { health 8 } } introduce .
! => "Mighty Magician"
```

## 3. Оживіть полеглого гравця

Визначте `revive`, щоб вона повертала *нового* гравця, у якого `health`
дорівнює 100, а `mana` дорівнює 100, але лише якщо `health` гравця
дорівнює `0`. Якщо гравець ще живий, поверніть `f`.

```factor
T{ player { name "Merlin" } { health 0 } } revive .
! => T{ player { name "Merlin" } { health 100 } { mana 100 } }

T{ player { health 50 } } revive .
! => f
```

## 4. Отримайте ушкодження

Визначте `take-damage`, щоб вона повертала *нового* гравця, `health`
якого зменшено на задану величину, причому ніколи не нижче за `0`.

```factor
T{ player { health 100 } } 30 take-damage .
! => T{ player { health 70 } }

T{ player { health 5 } } 30 take-damage .
! => T{ player { health 0 } }
```
