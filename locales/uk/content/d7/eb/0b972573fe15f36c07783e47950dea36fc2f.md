# Докладніше

Elixir представляє значення правди і неправди булевим типом (англ. Boolean). Є лише два значення: `true` і `false`. Ці значення можна поєднувати булевими операторами ([`and/2`][strict-and], [`or/2`][strict-or], [`not/1`][strict-not]):

```elixir
true_variable = true and true
false_variable = true and false

true_variable = false or true
false_variable = false or false

true_variable = not false
false_variable = not true
```

Оператори [`and/2`][strict-and], [`or/2`][strict-or] та [`not/1`][strict-not] є строго булевими, тобто вимагають, щоб їхній _перший_ аргумент був булевим значенням. Існують також рівнозначні булеві оператори, які працюють з аргументами будь-якого типу: [`&&/2`][and], [`||/2`][or] та [`!/1`][not].

Булеві оператори використовують _обчислення з коротким замиканням_: вираз праворуч від оператора обчислюється лише за потреби.

Кожен з операторів має свій пріоритет: `not/1` обчислюється раніше за `and/2` та `or/2`. Дужки можна використати, щоб обчислити одну частину виразу раніше за інші:

```elixir
not true and false
# => false

not (true and false)
# => true
```

Коли ми пишемо функцію, що повертає булеве значення, прийнято [завершувати її назву][naming] знаком `?`. Ту саму домовленість можна застосувати й до змінних, які зберігають булеві значення.

```elixir
def either_true?(a?, b?) do
  a? or b?
end
```
