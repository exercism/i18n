# Вступ

Тип [`Time`][time] у Go описує момент часу.
Інформацію про дату й час можна отримувати, порівнювати та змінювати через його методи, але є також функції, які викликаються на самому пакеті `time`.
Поточну дату й час можна отримати за допомогою функції [`time.Now`][now].

Функція [`time.Parse`][parse] розбирає рядки тексту (англ. string) у значення типу `Time`.
У Go є особливий спосіб визначення макета, який ми очікуємо для розбору.
Потрібно написати приклад макета, використовуючи значення з цієї особливої позначки часу:
`Mon Jan 2 15:04:05 -0700 MST 2006`.

Наприклад:

```go
import "time"

func parseTime() time.Time {
    date := "Tue, 09/22/1995, 13:00"
    layout := "Mon, 01/02/2006, 15:04"

    t, err := time.Parse(layout,date) // time.Time, error
}

// => 1995-09-22 13:00:00 +0000 UTC
```

Метод [`Time.Format()`][format] повертає рядкове подання часу.
Так само, як і з функцією `Parse`, цільовий макет знову задається через приклад, який використовує значення з особливої позначки часу.

Наприклад:

```go
import (
    "fmt"
    "time"
)

func main() {
    t := time.Date(1995,time.September,22,13,0,0,0,time.UTC)
    formattedTime := t.Format("Mon, 01/02/2006, 15:04") // string
    fmt.Println(formattedTime)
}

// => Fri, 09/22/1995, 13:00
```

## Параметри макета

Для власного макета використаймо комбінацію цих параметрів.
У Go також доступні наперед визначені [константи форматування][const] дати й позначки часу.

| Час          | Параметри                                      |
| ----------- | ---------------------------------------------- |
| Рік         | 2006 ; 06                                      |
| Місяць      | Jan ; January ; 01 ; 1                         |
| День        | 02 ; 2 ; \_2 (для провідного 0)                |
| День тижня  | Mon ; Monday                                   |
| Година      | 15 ( 24-годинний формат часу ) ; 3 ; 03 (AM або PM) |
| Хвилина     | 04 ; 4                                         |
| Секунда     | 05 ; 5                                         |
| Позначка AM/PM | PM                                          |
| День року   | 002 ; \_\_2                                    |

Тип `time.Time` має різні методи для доступу до конкретного часу. Наприклад, година: [`Time.Hour()`][hour], місяць: [`Time.Month()`][month].
Докладніше про те, як це працює, можна дізнатися в [офіційній документації][time].

У [`time`][time] є ще один тип, [`Duration`][duration], який представляє час, що минув, а також підтримка локацій і часових поясів, таймерів та іншої повʼязаної функціональності, яку буде розглянуто в іншій концепції.
