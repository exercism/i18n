# Встановлення Python

Якщо Python ще не встановлено у вашій системі, докладні інструкції для кожної платформи можна знайти в розділі [Встановлення та використання Python][using python] офіційної документації.
Real Python також пропонує [чудовий посібник][helpful guide] зі встановлення на різних платформах, зокрема iOS та Android.

Нарешті, ці дописи Бретта Кеннона, [A quick-and-dirty guide][quick-and-dirty] і [Why you should use `python -m pip`][python-m-pip], дають дуже корисні поради щодо керування встановленнями та пакетами Python.

**Примітка для користувачів MacOS:**  до MacOS Monterey (12.3) `Python 2.7` постачався попередньо встановленим разом з операційною системою.
Використання `Python 2.7` з Exercism чи більшістю інших програм не підтримується.
Замість цього варто встановити [Python 3][Python-three downloads] одним із методів, описаних нижче.
Починаючи з MacOS Monterey (12.3), жодна версія Python не встановлюється попередньо разом з MacOS.

Кілька швидких посилань на документацію за операційною системою:

-  [Windows][windows] Крім того, стане в пригоді ця стаття Microsoft про [встановлення Python у Windows][python-on-windows].
-  [Системи Unix і Linux][unix-and-linux] (_значною мірою вони працюють і для MacOS_)
-  [MacOS][macos]

   Також радимо переглянути деякі з методів, описаних у статті Real Python [Installing Python][installing-python] або в дописах Бретта Кеннона, посилання на які наведено вище.


Тести та інструментарій Exercism наразі підтримують `3.10` - `3.13.5` (_тести_) та [`Python 3.13.5`][313-new-features] (_інструментарій_).
Винятки з цієї підтримки зазначено там, де вони трапляються.
Більшість вправ працюватиме з `Python 3.6+` або навіть ранішими версіями.
Але ми не гарантуємо підтримку версій, не перелічених серед [Активних випусків Python][active-python-releases].


Про те, що підтримується наразі, дивіться в [документації Python 3.13.x][3.13 docs].
