# Вступ

Класи на кшталт `LocalDate` і `LocalDateTime` описують _точку_ в часі.
У пакеті `java.time` є також два класи, які описують _проміжок_ часу:

- `java.time.Period` описує проміжок часу в роках, місяцях і днях, наприклад «2 місяці та 5 днів».
- `java.time.Duration` описує проміжок часу в годинах, хвилинах, секундах, мілісекундах і наносекундах, наприклад «1 година 30 хвилин».

`Period` працює за календарем, тому його застосовують до дат і до дат-часів.
`Duration` вимірює точний час, тому його застосовують до значень часу й дат-часів, але не до самих дат.

```exercism/note
Як і інші класи `java.time`, `Period` і `Duration` незмінні.
Методи, які на вигляд змінюють їх, натомість повертають _новий_ примірник.
```

## `Period`

`Period` створюють одним із його статичних фабричних методів:

```java
Period.ofDays(10);
// => P10D

Period.ofMonths(3);
// => P3M

Period.of(1, 2, 15);
// => P1Y2M15D
```

Результат `toString()` записано в нотації [ISO-8601][iso-8601-durations]: `P` (від англ. «period»), а далі кількість років (`Y`), місяців (`M`) і днів (`D`).

Період можна додати до дати або відняти від неї:

```java
LocalDate date = LocalDate.of(2024, 3, 10);

date.plus(Period.ofMonths(2));
// => 2024-05-10

date.minus(Period.ofDays(10));
// => 2024-02-29
```

Місяці мають різну довжину, тому після додавання місяців можна потрапити на день, якого не існує.
У такому разі результат переносять на останній чинний день місяця:

```java
LocalDate.of(2025, 1, 31).plus(Period.ofMonths(1));
// => 2025-02-28
```

`Period.between()` повертає період від однієї дати (включно) до іншої (не включно):

```java
LocalDate start = LocalDate.of(2023, 3, 10);
LocalDate end = LocalDate.of(2024, 5, 25);

Period period = Period.between(start, end);
// => P1Y2M15D

period.getYears();
// => 1
period.getMonths();
// => 2
period.getDays();
// => 15
```

## Підрахунок одиниць за допомогою `ChronoUnit`

`Period` зберігає роки, місяці та дні окремо.
Тому `getDays()` повертає лише ту _частину_ періоду, що припадає на дні, а не загальну кількість днів.
Щоб порахувати загальну кількість однієї одиниці між двома датами, скористаймося методом `between()` із [`java.time.temporal.ChronoUnit`][chronounit-docs]:

```java
LocalDate start = LocalDate.of(2024, 1, 15);
LocalDate end = LocalDate.of(2024, 3, 20);

Period.between(start, end);
// => P2M5D

Period.between(start, end).getDays();
// => 5

ChronoUnit.DAYS.between(start, end);
// => 65
```

Результат буде відʼємним, якщо друга дата передує першій:

```java
ChronoUnit.DAYS.between(end, start);
// => -65
```

## `Duration`

`Duration` так само створюють за допомогою статичних фабричних методів:

```java
Duration.ofMinutes(90);
// => PT1H30M

Duration.ofHours(2).plusMinutes(15);
// => PT2H15M
```

У нотації ISO-8601 літера `T` відокремлює дату від часу, тому тривалості записують як `PT...`.

Тривалість можна додати до дати-часу або відняти від неї:

```java
LocalDateTime start = LocalDateTime.of(2024, 3, 10, 22, 30);

start.plus(Duration.ofMinutes(90));
// => 2024-03-11T00:00
```

`Duration.between()` повертає точний проміжок часу між двома датами-часами:

```java
LocalDateTime checkIn = LocalDateTime.of(2024, 3, 10, 18, 5);
LocalDateTime checkOut = LocalDateTime.of(2024, 3, 10, 19, 40);

Duration.between(checkIn, checkOut);
// => PT1H35M
```

Тривалість можна перевести в одну одиницю методами на кшталт `toHours()`, `toMinutes()` і `toSeconds()`.
Вони повертають _загальну_ кількість у цій одиниці, округлену вниз:

```java
Duration duration = Duration.ofMinutes(95);

duration.toHours();
// => 1
duration.toMinutes();
// => 95
```

Щоб розкласти тривалість на складники, як на годиннику, скористаймося натомість методами `toXxxPart()`:

```java
Duration duration = Duration.ofMinutes(95);

duration.toHoursPart();
// => 1
duration.toMinutesPart();
// => 35
```
