# Встановлення

Crystal можна встановити на Linux, macOS і Windows.

Варто зауважити, що підтримка Windows у Crystal експериментальна.
Це означає, що деякі крайні випадки можуть не працювати, і для виробничого використання такий варіант може бути не найкращим.
Утім, для Exercism і базового використання рідний Windows має бути здебільшого придатним.

Якщо для розробки на Windows потрібне середовище не в статусі попереднього перегляду, радимо скористатися [WSL (Windows Subsystem for Linux)][wsl].
Це **безкоштовна** можливість Windows 10 (1903+) і 11, яка дає розробнику змогу запускати середовище Linux без потреби у віртуальній машині.

Скористайтеся одним із [посібників зі встановлення][installation guides], щоб дізнатися, як встановити Crystal.

[wsl]: https://learn.microsoft.com/en-us/windows/wsl/install
[installation guides]: https://crystal-lang.org/install/
