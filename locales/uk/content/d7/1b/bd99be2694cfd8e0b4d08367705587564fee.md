# Вказівки

Наш друг Коjo дуже любить числа.
У нього є невеликий сайт під назвою «fun-with-numbers».
Коjo не дуже добре володіє програмуванням, тож він попросив нас про допомогу.

Ми створимо дві допоміжні функції для нових ігор із числами на сайті Коjo і третю, щоб перевіряти деякі вхідні дані, які може ввести користувач.

## 1. Обчислити суму чисел на гральному автоматі

Одна з ігор на сайті Коjo має вигляд грального автомата, який показує дві групи коліс із цифрами.
Кожна група цифр представляє число.
Для ігрової механіки Коjo потрібно знати суму цих двох чисел.

Напишіть функцію `twoSum`, яка приймає два масиви як параметри.
Кожен масив складається з одного або кількох чисел від 0 до 9.
Функція має інтерпретувати кожен масив як число й повернути суму цих двох чисел.

```javascript
twoSum([1, 2, 3], [0, 7]);
//=> 130

// [1, 2, 3] represents 123 and [0, 7] represents 7.
// 123 + 7 = 130
```

## 2. Визначити, чи є число паліндромом

Ще одна гра на сайті - невелика вікторина під назвою «Щасливі числа».
Користувач може ввести число й побачити, чи належить воно до якоїсь таємної послідовності або закономірності.
Послідовність або закономірність «щасливих чисел» змінюється щомісяця, і кожен користувач має лише обмежену кількість спроб, щоб її вгадати.

Щасливими числами цього місяця мають бути числа-паліндроми.
Числа-паліндроми залишаються тими самими, якщо записати цифри у зворотному порядку.

Реалізуйте нову функцію `luckyNumber`, яка приймає число як параметр.
Функція має повернути `true`, якщо число є паліндромом, і `false` в іншому разі.
Вхідне число завжди буде додатним цілим числом.

```javascript
luckyNumber(1441);
//=>  true

luckyNumber(123);
//=> false
```

## 3. Створити повідомлення про помилку для некоректних вхідних даних користувача

У різних місцях сайту є поля введення, де користувачі можуть вводити числа й натискати кнопку, щоб викликати якусь дію.
Коjo хоче покращити досвід користування своїм сайтом.
Він хоче показувати повідомлення про помилку, якщо користувач натискає кнопку, а поле містить некоректне вхідне значення.

Ось трохи більше інформації про те, як надається значення поля введення.

- Якщо користувач вводить щось у поле, повʼязане значення завжди є рядком тексту (англ. string), навіть якщо він ввів лише цифри.
- Якщо користувач щось вводить, а потім стирає, змінна буде порожнім рядком тексту.
- Ще до того, як користувач почне вводити, змінна може бути `undefined` або `null`.

Напишіть функцію `errorMessage`, яка приймає введені користувачем дані як параметр.
Якщо користувач не надав жодних вхідних даних, `errorMessage` має повернути `'Required field'`.
Якщо вхідні дані не є числом, відмінним від нуля (згідно з правилами перетворення JavaScript), потрібно повернути `'Must be a number besides 0'`.
В усіх інших випадках можемо вважати вхідні дані коректними, і тоді поверненим значенням має бути порожній рядок тексту.

```javascript
errorMessage('123');
// => ''

errorMessage('');
// => 'Required field'

errorMessage('abc');
// => 'Must be a number besides 0'
```
