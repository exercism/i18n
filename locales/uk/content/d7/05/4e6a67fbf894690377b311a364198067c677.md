# Вступ

JSON-**обʼєкт** - це, якщо скористатися термінологією з інших мов, «хеш», «мапа» або «словник».

JSON визначає _обʼєкт_ так:

> Обʼєкт - це невпорядкований набір пар **назва**/**значення**.
> Обʼєкт починається з `{` (лівої фігурної дужки) і закінчується `}` (правої фігурної дужки).
> За кожною _назвою_ йде `:` (двокрапка), а пари _назва/значення_ розділяються `,` (комою).

_Назва_ **повинна бути рядком тексту** (англ. string).
Інше слово для _назви_ - _ключ_.

_Значення_ може бути будь-якого типу JSON.
Різні _значення_ в одному обʼєкті можуть мати різні типи, як у цьому прикладі.

<!-- prettier-ignore -->
```json
{
  "name": "Jane",
  "age": 42,
  "pets": ["cat", "fish"],
  "address": {"street": "123 Main St", "city": "Springfield"}
}
```

<!-- prettier-ignore-end -->

Зауважмо, що після _останньої_ пари ключ-значення **не повинно** бути коми.

## Створення обʼєктів

Щоб зібрати пари назва/значення, використовуємо фігурні дужки.
Хоча назви й повинні бути рядками тексту, їх не обовʼязково брати в лапки, якщо назви **подібні до ідентифікаторів** (складаються з літер, цифр і символу підкреслення та не починаються з цифри).

```jq
{name: "Jane", age: 42}
```

Цілком припустимо використовувати ключі, які не є _подібними до ідентифікаторів_.
Просто берімо їх у лапки.

```jq
{"first name": "Jane", "last name": "Lopez", age: 42}
```

Якщо назва є результатом виразу, цей вираз **повинен** бути в дужках.

```sh
$ echo "Jane" | jq -Rc '{.: 42}'
# verbose error message ...

$ echo "Jane" | jq -Rc '{(.): 42}'
{"Jane":42}
```

## Індексування

Значення дістають з обʼєкта за допомогою **крапкової нотації**.

```jq
{name: "Jane", age: 42} | .age    # => 42
```

Якщо до ключа не можна звернутися як до ідентифікатора, використовуємо **дужкову нотацію**.

```jq
"name" as $key | {name: "Jane", age: 42} | .$key    # => error
"name" as $key | {name: "Jane", age: 42} | .[$key]  # => "Jane"
```

## Додавання або зміна пар ключ-значення

Щоб додати нову пару ключ-значення до масиву або оновити значення наявного ключа, використовуємо оператор присвоєння `=`, а ліворуч записуємо вираз з індексом.

```jq
{name: "Jane", age: 42} | .sport = "tennis" | .age = 21
# => {
#      "name": "Jane",
#      "age": 21,
#      "sport": "tennis"
#    }
```

Оператор `+` _зливає_ обʼєкти.

```jq
{Richard: 54} + {Jane: 42}
# => {
#      "Richard": 54,
#      "Jane": 42
#    }
```

## Видалення ключа

Щоб видалити ключ, використовуємо функцію `del`.
Вона повертає оновлений обʼєкт.

```jq
{name: "Jane", age: 42} | del(.age)   # => {"name": "Jane"}
```

Параметром для `del` є **вираз з індексом** (з крапковою або дужковою нотацією), який указує на ключ в обʼєкті.
`jq` називає його **виразом шляху**.
Просто передати рядок тексту недостатньо.

```jq
{name: "Jane", age: 42} | del(name)        # error: name/0 is not defined
{name: "Jane", age: 42} | del("name")      # error: Invalid path expression with result "name"
{name: "Jane", age: 42} | del(.name)       # OK
{name: "Jane", age: 42} | del(.["name"])   # OK
```

## Перевірка належності

- Щоб перевірити, чи має обʼєкт ключ, використовуємо функцію `has`.

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ($example | has("name")),    # => true
    ($example | has("sport"))    # => false
  ```

- Щоб перевірити, чи є ключ в обʼєкті, використовуємо `in`.

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ("name"  | in($example)),    # => true
    ("sport" | in($example))     # => false
  ```

## Вивести всі ключі

Щоб вивести список усіх ключів, використовуємо функцію `keys`.

```jq
{name: "Jane", age: 42} | keys   # => ["age", "name"]
```

Зауважмо, що `keys` _сортує_ ключі.
Щоб отримати ключі в початковому порядку, використовуємо `keys_unsorted`.

Немає рівноцінної функції, щоб вивести всі _значення_.
Утім, фільтр `.[]` виводить значення обʼєкта як _потік_, і цей потік можна зібрати конструктором масиву `[...]`.

```jq
[{first: "Jane", last: "Lopez", status: "awesome!"} | .[]]
# => ["Jane", "Lopez", "awesome!"]
```

## Ітерація

- Функція `map_values(filter)` застосовує фільтр до кожного _значення_ в обʼєкті.

  ```jq
  {first: "Jane", last: "Lopez", status: "awesome!"}
  | map_values(ascii_upcase)
  # => {"first": "JANE", "last": "LOPEZ", "status": "AWESOME!"}
  ```

- Щоб перебрати обʼєкт, спершу треба перетворити його на масив обʼєктів ключ-значення.
  Функція `to_entries` робить саме це.

  ```jq
  {name: "Jane", age: 42} | to_entries'
  # => [
  #      {
  #        "key": "name",
  #        "value": "Jane"
  #      },
  #      {
  #        "key": "age",
  #        "value": 42
  #      }
  #    ]
  ```

  Тепер можна скористатися функціями для перебору масивів, як-от `map`.

- Функція `from_entries` робить навпаки: перетворює масив обʼєктів ключ-значення на обʼєкт.

  ```jq
  [
    {"key":"name", "value":"Jane"},
    {"key":"age", "value":42}
  ] | from_entries                  # =>{"name": "Jane", "age": 42}
  ```

- Щоб застосувати фільтр до _кожної_ пари ключ-значення в обʼєкті, використовуємо функцію `with_entries(filter)`.

  Наприклад, якщо обʼєкт зіставляє назву з віком, ключі та значення можна поміняти місцями так.

  ```jq
  {"Jane": 42, "Richard": 54}
  | with_entries({key: (.value | tostring), value: .key})
  ```

  виводить

  ```json
  {
    "42": "Jane",
    "54": "Richard"
  }
  ```

  `with_entries(filter)` - те саме, що

  ```jq
  to_entries | map(filter) | from_entries
  ```
