# Інструкції

У цій вправі потрібно реалізувати кілька правил із гри [Pac-Man][Pac-Man], класичної аркадної гри 1980-х років.

Потрібно реалізувати чотири правила, і всі вони стосуються станів гри.

> _Не переймаймося тим, звідки беруться аргументи, а зосередьмося на тому, щоб поєднати їх і повернути потрібний результат._

## 1. Визначте, чи Pac-Man зʼїдає привида

Визначте функцію `eat_ghost()`, яка приймає два параметри (_чи в Pac-Man активна енергетична кулька_ та _чи торкається Pac-Man привида_) і повертає булеве значення (англ. Boolean), якщо Pac-Man може зʼїсти привида.
 Функція повинна повертати `True` лише тоді, коли в Pac-Man активна енергетична кулька і він торкається привида.

```python
>>> eat_ghost(False, True)
...
False
```

## 2. Визначте, чи Pac-Man набирає очки

Визначте функцію `score()`, яка приймає два параметри (_чи торкається Pac-Man енергетичної кульки_ та _чи торкається Pac-Man крапки_) і повертає булеве значення, якщо Pac-Man набрав очки.
 Функція повинна повертати `True`, якщо Pac-Man торкається енергетичної кульки або крапки.

```python
>>> score(True, True)
...
True
```

## 3. Визначте, чи програє Pac-Man

Визначте функцію `lose()`, яка приймає два параметри (_чи в Pac-Man активна енергетична кулька_ та _чи торкається Pac-Man привида_) і повертає булеве значення, якщо Pac-Man програє.
 Функція повинна повертати `True`, якщо Pac-Man торкається привида і в нього немає активної енергетичної кульки.

```python
>>> lose(False, True)
...
True
```

## 4. Визначте, чи перемагає Pac-Man

Визначте функцію `win()`, яка приймає три параметри (_чи зʼїв Pac-Man усі крапки_, _чи в Pac-Man активна енергетична кулька_ та _чи торкається Pac-Man привида_) і повертає булеве значення, якщо Pac-Man перемагає.
 Функція повинна повертати `True`, якщо Pac-Man зʼїв усі крапки і не програв за правилами, визначеними в частині 3.

```python
>>> win(False, True, False)
...
False
```
