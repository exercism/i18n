# Вступ

## Експорт функцій

Експорт функцій ми розглядали в першій концепції, тож ось коротке нагадування.

Кожен файл в Elm - це модуль, який має містити інструкцію `module` перед усім іншим кодом.

Назви модулів мають збігатися з назвами їхніх файлів, тож модуль `Calculator` має бути в файлі Calculator.elm, а модуль `Parser.Utils` - у файлі Parser/Utils.elm.

Усе, визначене всередині модуля, має приватну область видимості в його межах, і до нього не можна отримати доступ ззовні цього модуля, якщо його не перелічено в `exposing`.

```elm
-- Calculator.elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Calculator.elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## Імпорт функцій з інших модулів

Доступ до функцій, визначених в інших модулях, відбувається через імпорт.
Усі функції в цьому модулі, які він експортував, стають доступними, коли ми імпортуємо цей модуль.
Але те, як ми до них звертаємося, залежить від того, як імпортовано модуль.

Типовим є кваліфікований імпорт, і щоб звернутися до функції в такому модулі (наприклад, до функції `map` у модулі `List`), треба додати перед нею назву модуля (`List.map`).

Відкритий імпорт дає прямий доступ до експортованих функцій цього модуля без префікса. Його роблять за допомогою ключового слова `exposing`, ніби дзеркально відображаючи те, що використовується в експорті. Можна експортувати всі доступні функції (через `..`) або лише конкретні (наприклад, `map`).

Також можна імпортувати типи та їхні конструктори з інших модулів, але це вже наступна концепція.

Перевагу віддають кваліфікованому імпорту, щоб код був зрозумілішим і не виникало конфліктів назв.

```elm
-- qualified imports
import List                            -- List.map, List.foldl
import List as L                       -- L.map, L.foldl

-- open imports
import List exposing (..)              -- map, foldl, concat, ...
import List exposing ( map, foldl )    -- map, foldl, List.concat
```

https://elm-lang.org/docs/syntax#modules

## Анотації типів

Анотації типів визначають у вигляді `name : parameter types -> return type`, де типи параметрів також розділено через `->`.

```elm
add : Int -> Int -> Int
add number1 number2 = number1 + number2
```

Дужки можна використовувати для визначення параметрів функції (які й самі визначаються тим самим синтаксисом, звідси й потреба в дужках).

```elm
-- Transform every character in a string
map : (Char -> Char) -> String -> String
map charMapperFunction string =
    -- ...
```

https://elm-lang.org/docs/syntax#type-annotations

## Числа

В Elm доступні два типи чисел, визначені типами `Int` і `Float`.
`Int` відповідає множині додатних і відʼємних цілих чисел.
`Float` відповідає множині дійсних чисел, обмеженій точністю компʼютера.
Операції, визначені над числами, зазвичай працюють з одним типом або з іншим, але не змішують їх.
Існують функції для перетворення між ними, як-от `toFloat`, що перетворює `Int` на `Float`, та `round`, `floor`, `ceiling` і `truncate`, які перетворюють `Float` на `Int` з різною семантикою.

https://package.elm-lang.org/packages/elm/core/latest/Basics#Int

## Операції з рядками тексту

Щоб описати слова й речення в коді, Elm має вбудований тип `String`.
Рядок тексту (англ. string) записують між подвійними лапками, наприклад `"Hello World!"`.
Оператор конкатенації рядків `++` і оператор рівності `==` доступні типово.

```elm
hello : String -> String
hello subject = "Hello " ++ subject

hello "World!" --> "Hello World!"
```

Більшість інших функцій для роботи з рядками тексту міститься в модулі `String`, який потрібно імпортувати.

https://package.elm-lang.org/packages/elm/core/latest/String
