# Про

Зовнішні типи можна використовувати, щоб посилатися на типи даних, визначені в інших мовах, як-от Erlang або JavaScript.

Щоб визначити зовнішній тип, оголошуємо тип, але не надаємо жодних конструкторів. Потім його можна використовувати так само, як будь-який інший тип.

```gleam
pub type OrderedDictionary(element)
```
