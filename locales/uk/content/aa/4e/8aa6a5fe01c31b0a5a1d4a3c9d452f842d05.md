# Вступ

В Elixir ми можемо визначати атрибути модуля, які можна використовувати як константи у наших функціях.

```elixir
defmodule Example do
  # Defines the attribute as the value 1
  @constant_number 1

  def example_value() do
    # Returns the value 1
    @constant_number
  end
end
```

Коли атрибути використовують для визначення констант модуля, вони можуть бути будь-яким виразом, який можна обчислити під час компіляції. Після компіляції атрибути модуля недоступні, оскільки вони розкриваються під час компіляції, подібно до визначених макросів у таких мовах, як C.
