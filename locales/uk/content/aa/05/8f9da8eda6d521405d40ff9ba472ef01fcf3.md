# Тестування в командному рядку

Виконайте тести за допомогою:

```bash
$ cargo test
```

Усі тести, крім першого, позначено як ігноровані. Після того як перший тест
пройде, відкрийте файл із тестами, який лежить у каталозі `tests`, приберіть
атрибут `#[ignore]` з наступного тесту й знову зробіть так, щоб тести
проходили. Кожен окремий тест - це функція з атрибутом `#[test]` над нею.
Продовжуйте, доки всі тести не пройдуть.

Якщо потрібно запустити _лише ігноровані_ тести, не редагуючи файл із тестами, скористайтеся:

```bash
$ cargo test -- --ignored
```

У Rust 1.51 або новішій версії можна запустити _усі_ тести за допомогою

```bash
$ cargo test -- --include-ignored
```

Щоб запустити конкретний тест, наприклад `some_test`, скористайтеся:

```bash
$ cargo test some_test
```

Якщо конкретний тест ігнорується, скористайтеся:

```bash
$ cargo test some_test -- --ignored
```

Щоб дізнатися більше про тести Rust, зверніться до [документації з тестування][rust-tests] онлайн.

[rust-tests]: https://doc.rust-lang.org/book/ch11-02-running-tests.html
