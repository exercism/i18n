# Підказки

## Загальні

- Використайте крейт `enum-iterator`, щоб мати змогу перебирати enum. Перегляньте [документацію](https://docs.rs/enum-iterator/1.2.0/enum_iterator/), щоб дізнатися, як це робити.

- Використайте крейт `int-enum`, щоб мати змогу перетворювати цілі числа на enum. Дивіться [документацію](https://docs.rs/int-enum/0.5.0/int_enum/) для подробиць.

- Трейт `Debug` тут, бо він, імовірно, знадобиться.

- Знадобиться розширити список трейтів, виведених через `derive`, в enum кольорів.
