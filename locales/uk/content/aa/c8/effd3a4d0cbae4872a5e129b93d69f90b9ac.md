# Про

Булеві значення (англ. Boolean) у C# представлені типом `bool`, значення якого можуть бути або `true`, або `false`.

C# підтримує чотири [булеві оператори][operators]: `!` (заперечення), `&&` (логічне і), `||` (логічне або), та `^` (виключне або). Оператори `&&` (і) та `||` (або) використовують _скорочене обчислення_, що означає, що права частина оператора обчислюється лише за потреби.

```csharp
true || false // => true
true && false // => false
true ^ false  // => true
true ^ true   // => false
```

Три булеві оператори мають різний [_пріоритет операторів_][precedence]. Як наслідок, вони обчислюються в такому порядку: спочатку `not`, потім `&&` (і), далі `^`, і нарешті `||` (або). Щоб «обійти» ці правила, можна взяти булевий вираз у дужки (`()`), оскільки дужки мають ще вищий пріоритет операторів.

```csharp
!true && false   // => false
!(true && false) // => true
```
