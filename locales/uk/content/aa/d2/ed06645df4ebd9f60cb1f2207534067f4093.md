# Докладніше

[Анонімні функції][anon-fns] часто використовують в Elixir окремо, як повернені значення та як аргументи функцій вищого порядку, як-от `Enum.map/2`:

```elixir
Enum.map([1, 2, 3], fn n -> n + 1 end)
# => [2, 3, 4]
```

У Elixir до функцій ставляться як до обʼєктів першого класу:

- Іменовані та анонімні функції можна присвоювати змінним.
- Іменовані та анонімні функції можна передавати, як дані, як аргументи та повернені значення.
- Анонімні функції можна створювати динамічно.

Анонімні функції створюють за допомогою ключового слова [`fn`][kernel-fn] і викликають із крапкою (`.`):

```elixir
function_variable = fn n -> n + 1 end

function_variable.(1)
# => 2
```

Анонімні функції також можна створювати за допомогою [скороченого запису захоплення `&`][kernel-capture].

- Початковий `&` позначає початок виразу захоплення.
- `&1`, `&2` тощо вказують на позиційні аргументи анонімної функції.

  ```elixir
  # Instead of:
  fn x, y -> abs(x) + abs(y) end

  # We can write:
  &(abs(&1) + abs(&2))
  ```

- Оператор захоплення `&` також можна використати, щоб [_захопити_ наявну іменовану функцію][capture]:

  ```elixir
  # Instead of:
  fn a, b -> a <= b end

  # We can capture the function using its name and arity:
  &<=/2
  ```

Анонімні функції в Elixir - це [замикання][closure]. Вони мають доступ до змінних, які перебувають в області видимості на момент визначення функції. Змінні, присвоєні всередині анонімної функції, недоступні поза нею:

```elixir
y = 2

square = fn ->
  x = 3
  x * y
end

square.()
# => 6

x
# => ** (CompileError): undefined function x/0
```
