# Про це

Умовні конструкції - це інструкції, які виконують різний код залежно від того, чи умова є `true` або `false`.

Умовна конструкція [`if`][if_statement] виконує своє тіло лише тоді, коли її умова є `true`.
У Go немає поняття правдивих чи неправдивих значень, тому умова повинна мати тип `bool`.
Вирази на кшталт `if mySlice { ... }` або `if 1 { ... }` спричиняють помилку компіляції.

```go
func describe(val string) string {
    if val == "val" {
        return "was val"
    }
    return "was not val"
}
```

Використаймо `else if`, щоб перевірити додаткові умови, а `else` - як запасний варіант, якщо жодна не підходить.
Умови перевіряються згори донизу, і виконається лише перша гілка, умова якої справджується.

```go
number := 0
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

Загалом Go надає перевагу достроковому поверненню з виняткового випадку та униканню `else`.

```go
func getVal(connected bool) int {
    if !connected {
        return readLocalVal()
    }

    return readVal()
}
```

Умовна конструкція `if` також може містити коротку інструкцію ініціалізації.
Зазвичай так перевіряють помилку одразу після виклику:

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```

Змінні, оголошені в інструкції ініціалізації, перебувають в області видимості лише в межах усього ланцюжка `if`/`else`.
Примітно, що в Go немає тернарного оператора - це свідомий вибір дизайну, щоб код було легко читати.

Щоб дізнатися більше, звернімося до [Go by Example: If/Else][go_by_example_if].
