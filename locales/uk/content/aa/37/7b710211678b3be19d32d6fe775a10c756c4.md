# Додаток до інструкцій

## Регістри

| Регістр | Використання | Тип            | Опис                                                  |
| ------- | ------------ | -------------- | ----------------------------------------------------- |
| `$a0`   | вхідні дані  | ціле число     | початкове число                                       |
| `$v0`   | вихідні дані | ціле число     | очікувана кількість кроків, -1, якщо число недійсне   |
| `$t0-9` | тимчасовий   | будь-який      | використовується для тимчасового зберігання           |
