# Докладніше

ABAP підтримує звичайні арифметичні оператори для числових значень:

- `+` додає значення.
- `-` віднімає значення.
- `*` множить значення.
- `/` ділить значення.
- `MOD` повертає остачу від ділення цілих чисел.

```abap
DATA total TYPE i.
total = 6 + 4 * 2.

DATA remaining_days TYPE i.
remaining_days = 70 MOD 22.
```

Множення і ділення обчислюються раніше за додавання і віднімання. Використовуймо дужки, коли обчислення потрібно згрупувати явно.

```abap
DATA result TYPE i.
result = ( 6 + 4 ) * 2.
```
