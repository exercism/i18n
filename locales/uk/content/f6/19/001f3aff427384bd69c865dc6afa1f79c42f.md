# Вказівки

У кожної ролі в шкільній виставі є дублер: хтось, хто може вийти на сцену й зробити те, що потрібно для ролі, так, щоб помічник режисера не знав, хто вона.

Усі пʼять завдань виконуються в класі `UNDERSTUDY`. Перші два - звичайні процедури, які пізніші завдання звʼяжуть.

## 1. Два способи вимовити репліку

Напишіть `shout`, який повертає репліку великими літерами, і `whisper`, який повертає її малими літерами з `"..."` на обох кінцях.

```sather
UNDERSTUDY::shout("who's there")
-- => "WHO'S THERE"
UNDERSTUDY::whisper("Who's There")
-- => "...who's there..."
```

## 2. Відрепетирувати репліку

`rehearse` приймає репліку та спосіб її вимови й повертає результат. Її другий аргумент має тип `ROUT{STR}:STR`.

```sather
UNDERSTUDY::rehearse("who's there", bind(UNDERSTUDY::shout(_)))
-- => "WHO'S THERE"
```

## 3. Уся сцена

`run_scene` приймає масив реплік і спосіб їх вимови та повертає їх усі, вимовлені в той спосіб, зʼєднані через `" "`.

```sather
UNDERSTUDY::run_scene(|"Enter", "Exit"|, bind(UNDERSTUDY::shout(_)))
-- => "ENTER EXIT"
```

Порожня сцена - це порожній рядок тексту (англ. string).

## 4. Повернути спосіб вимови

`understudy_for` приймає назву стилю, `"shout"` або будь-що інше, і повертає `ROUT{STR}:STR`. `"shout"` дає той, що кричить; будь-що інше дає той, що шепоче.

```sather
part ::= UNDERSTUDY::understudy_for("shout");
part.call("who's there")
-- => "WHO'S THERE"
```

## 5. Зафіксувати аргумент

Напишіть `repeat`, який приймає число разів і репліку та повертає репліку, повторену стільки разів, нічого не вставляючи між ними:

```sather
UNDERSTUDY::repeat(3, "Ha")
-- => "HaHaHa"
```

Потім напишіть `doubler`, який не приймає аргументів і повертає `ROUT{STR}:STR`, що повторює двічі все, що йому передадуть, звʼязавши `repeat` із уже заповненим числом.

```sather
UNDERSTUDY::doubler.call("Ha")
-- => "HaHa"
```
