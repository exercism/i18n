# Інструкції

У цій вправі ми палко вболіваємо за спорт і щойно відкрили для себе баскетбол NBA. Оскільки баскетбол NBA для нас новий, ми глибоко занурюємося в історію NBA: відстежуємо команди, тренерів, їхню статистику перемог і поразок та порівнюємо їх між собою.

Оскільки улюбленої команди в нас ще немає, ми також розробимо алгоритм, який допоможе визначити, за яку команду вболівати.

На нас чекає сім завдань, які допоможуть розробити наш власний алгоритм _вболівання за команду_.

## 1. Визначте модель

Визначте запис `Coach` із такими двома полями:

- `Name`: імʼя тренера, типу `string`.
- `FormerPlayer`: указує, чи був тренер колишнім гравцем, типу `bool`.

Визначте запис `Stats` із такими двома полями:

- `Wins`: кількість перемог, типу `int`.
- `Losses`: кількість поразок, типу `int`.

Визначте запис `Team` із такими трьома полями:

- `Name`: назва команди, типу `string`.
- `Coach`: тренер команди, типу `Coach`.
- `Stats`: статистика команди, типу `Stats`.

## 2. Створіть тренера команди

Реалізуйте функцію `createCoach`, яка приймає імʼя тренера та його статус колишнього гравця як параметри і повертає запис `Coach`:

```fsharp
createCoach "Larry Bird" true
// => { Name = "Larry Bird"; FormerPlayer = true }
```

## 3. Створіть статистику команди

Реалізуйте функцію `createStats`, яка приймає кількість перемог і кількість поразок як параметри та повертає запис `Stats`:

```fsharp
createStats 58 24
// => { Wins = 58; Losses = 24 }
```

## 4. Створіть команду

Реалізуйте функцію `createTeam`, яка приймає назву команди, тренера та статистику як параметри і повертає запис `Team`:

```fsharp
let coach = createCoach "Larry Bird" true
let record = createStats 58 24
createTeam "Indiana Pacers" coach record
// => { Name = "Indiana Pacers"
//      Coach = { Name = "Larry Bird"; FormerPlayer = true }
//      Stats = { Wins = 58; Losses = 24 } }
```

## 5. Замініть тренера

Власники клубів NBA нетерплячі, тож ми помітили, що погані результати команди часто призводять до заміни тренера. Реалізуйте функцію `replaceCoach`, яка приймає команду та її нового тренера як параметри й повертає команду, але вже з новим тренером:

```fsharp
let coach = createCoach "Larry Bird" true
let record = createStats 58 24
let team = createTeam "Indiana Pacers" coach record

let newCoach = createCoach "Isiah Thomas" true
replaceCoach team newCoach
// => { Name = "Indiana Pacers"
//      Coach = { Name = "Isiah Thomas"; FormerPlayer = true }
//      Stats = { Wins = 58; Losses = 24 } }
```

## 6. Перевірте, чи це та сама команда

Порпаючись у статистиці, ми ведемо списки команд та їхньої статистики. Іноді ми помиляємося, і в списку виникають дублікати. Реалізуйте функцію `isSameTeam`, яка приймає дві команди й повертає `true`, якщо це та сама команда, інакше повертає `false`:

```fsharp
let pacersCoach = createCoach "Larry Bird" true
let pacersStats = createStats 58 24
let pacersTeam = createTeam "Indiana Pacers" pacersCoach pacersStats

let lakersCoach = createCoach "Del Harris" false
let lakersStats = createStats 61 21
let lakersTeam = createTeam "LA Lakers" lakersCoach lakersStats

isSameTeam pacersTeam lakersTeam
// => false
```

## 7. Перевірте, чи варто вболівати за команду

Переглянувши багато команд і матчів, ми вигадали алгоритм. Якщо виконується одна з наведених умов, ми вболіваємо за цю команду:

- Імʼя тренера — «Gregg Popovich»
- Тренер — колишній гравець
- Назва команди — «Chicago Bulls»
- Команда здобула 60 або більше перемог
- У команди більше поразок, ніж перемог

Реалізуйте функцію `rootForTeam`, яка приймає команду й повертає `true`, якщо за цю команду варто вболівати, інакше `return` false:

```fsharp
let spursCoach = createCoach "Gregg Popovich" false
let spursStats = createStats 56 26
let spursTeam = createTeam "San Antonio Spurs" spursCoach spursStats
rootForTeam spursTeam
// => true
```
