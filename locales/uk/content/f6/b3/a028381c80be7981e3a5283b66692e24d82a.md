# Підказки

## Загальне

- Індекси `Vector` починаються з `1`.
- У колодах карт немає жодної повторюваної карти.

## 1. Визначити, чи присутня карта

- У Base є метод [`in`/`∈`](https://docs.julialang.org/en/v1/base/collections/#Base.in), щоб визначити, чи містить колекція значення.

## 2. Знайти позицію карти

- У Base є метод [`findfirst`](https://docs.julialang.org/en/v1/base/arrays/#Base.findfirst-Tuple{Function,%20Any}), щоб знайти позицію першого елемента колекції, який відповідає заданому предикату.
- `==(x)` можна використати як предикат, щоб знайти елементи, що дорівнюють `x`, у методах, які приймають функції-предикати.

## 3. Визначити, чи кожна карта парна

- У Base є метод [`all`](https://docs.julialang.org/en/v1/base/collections/#Base.all-Tuple{AbstractArray,%20Any}), який повертає `true`, якщо всі елементи колекції задовольняють заданий предикат.
- [`iseven`](https://docs.julialang.org/en/v1/base/numbers/#Base.iseven) є функцією-предикатом.

## 4. Перевірити, чи містить колода карту з непарним значенням

- У Base є метод [`any`](https://docs.julialang.org/en/v1/base/collections/#Base.any-Tuple{AbstractArray,%20Any}), який повертає `true`, якщо будь-які елементи колекції задовольняють заданий предикат.
- [`isodd`](https://docs.julialang.org/en/v1/base/numbers/#Base.isodd) є функцією-предикатом.

## 5. Визначити позицію першої парної карти

- У Base є метод [`findfirst`](https://docs.julialang.org/en/v1/base/arrays/#Base.findfirst-Tuple{Function,%20Any}), щоб знайти позицію першого елемента колекції, який відповідає заданому предикату.
- [`iseven`](https://docs.julialang.org/en/v1/base/numbers/#Base.iseven) є функцією-предикатом.

## 6. Отримати першу непарну карту з колоди

- Щоб отримати `n`-те значення у векторі `v`, можна скористатися `v[n]`.
- У Base є метод [`findfirst`](https://docs.julialang.org/en/v1/base/arrays/#Base.findfirst-Tuple{Function,%20Any}), щоб знайти позицію першого елемента колекції, який відповідає заданому предикату.
- Якщо жоден елемент заданої колекції не відповідає предикату, переданому `findfirst`, то `findfirst` повертає `nothing`.
- Пригадаймо, як працює `nothing` у Julia: [concept:julia/nothingness](../../../../concepts/nothingness/about.md)
- Пригадаймо, як працюють умовні конструкції у Julia: [concept:julia/conditionals](../../../../concepts/conditionals/about.md)
