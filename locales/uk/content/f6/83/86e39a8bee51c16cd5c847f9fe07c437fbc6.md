# Вступ

## Числа

Багато мов програмування мають окремі числові типи для різних видів чисел, але в JavaScript їх лише два:

- `number`: числовий тип даних у форматі 64-бітного числа з плаваючою комою подвійної точності (IEEE 754).
  Наприклад: `-6`, `-2.4`, `0`, `0.1`, `1`, `3.14`, `16.984025`, `25`, `976`, `1024.0` та `500000`.
- `bigint`: числовий тип даних, який може представляти _цілі числа_ у форматі довільної точності.
  Наприклад: `-12n`, `0n`, `4n` та `9007199254740991n`.

Якщо нам потрібна довільна точність або доводиться працювати з надзвичайно великими числами, використаймо тип `bigint`.
Інакше тип `number`, найімовірніше, буде кращим вибором.

### Округлення

Є вбудований глобальний обʼєкт `Math`, який надає різні [функції округлення][ref-math-object-rounding].
Наприклад, ми можемо округлити десяткові числа вниз (`floor`) або вгору (`ceil`) до найближчого цілого числа.

```javascript
Math.floor(234.34); // => 234
Math.ceil(234.34); // => 235
```

## Арифметичні оператори

JavaScript надає 6 різних операторів для виконання базових арифметичних дій над числами.

- `+`: оператор додавання використовується, щоб знайти суму чисел.
- `-`: оператор віднімання використовується, щоб знайти різницю між двома числами
- `*`: оператор множення використовується, щоб знайти добуток двох чисел.
- `/`: оператор ділення використовується, щоб поділити два числа.

```javascript
2 - 1.5; //=> 0.5
19 / 2; //=> 9.5
```

- `%`: оператор остачі (від ділення) використовується, щоб знайти остачу від виконаного ділення.

  ```javascript
  40 % 4; // => 0
  -11 % 4; // => -3
  ```

- `**`: оператор піднесення до степеня використовується, щоб піднести число до степеня.

  ```javascript
  4 ** 3; // => 64
  4 ** 1 / 2; // => 2
  ```

### Порядок виконання операцій

Коли в одному рядку використовується кілька операторів, JavaScript дотримується порядку старшинства, показаного в [цій таблиці старшинства][mdn-operator-precedence].
Якщо спростити це для нашого контексту, JavaScript використовує правило PEDMAS (дужки, степені, ділення/множення, додавання/віднімання), яке ми вивчали на уроках елементарної математики.

<!-- prettier-ignore-start -->
```javascript
const result = 3 ** 3 + 9 * 4 / (3 - 1);
// => 3 ** 3 + 9 * 4/2
// => 27 + 9 * 4/2
// => 27 + 18
// => 45
```
<!-- prettier-ignore-end -->

### Скорочені оператори присвоєння

Скорочені оператори присвоєння - це коротший спосіб записати код, який виконує арифметичні дії над змінною та присвоює нове значення тій самій змінній.
Наприклад, розгляньмо дві змінні `x` та `y`.
Тоді `x += y` - те саме, що `x = x + y`.
Часто це використовують із числом замість змінної `y`.
Решту 5 операцій також можна виконувати в подібний спосіб.

```javascript
let x = 5;
x += 25; // x is now 30

let y = 31;
y %= 3; // y is now 1
```
