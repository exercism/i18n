# Інструкції

Наша ностальгія за картками Blorkemon™️ і не думає вщухати: ми навіть знову почали їх колекціонувати і залучаємо до цього своїх друзів.

У цій вправі ми скористаємося інтерфейсом `Set`, щоб упорядкувати свою колекцію, адже коли наша мета - зібрати всі наявні картки, дублікати не мають значення.

## 1. Почати колекцію

Ми щойно знайшли свої старі запаси карток Blorkemon™️!
У цих запасах повно дублікатів, тож час створити нову колекцію, прибравши дублікати.

Ми дуже хочемо, щоб друзі долучилися до нашого божевілля Blorkemon™️, і найкращий спосіб - започаткувати їхню колекцію, подарувавши їм одну картку.

Реалізуйте метод `newCollection`, який перетворює список карток на `Set`, що представляє нашу нову колекцію.

```java
GottaSnatchEmAll.newCollection(List.of("Newthree", "Newthree", "Newthree"));
// => {"Newthree"}
```

## 2. Розширити колекцію

Коли колекція вже є, вона починає жити власним життям і мусить рости.

Реалізуйте метод `addCard`, який приймає нову картку та наш поточний набір зібраних карток.
Метод має додати нову картку до колекції, якщо її там ще немає, і повернути `boolean`, що вказує, чи було оновлено колекцію.

```java
Set<String> collection = GottaSnatchEmAll.newCollection("Newthree");
GottaSnatchEmAll.addCard("Scientuna",collection);
// => true

collection.contains("Scientuna");
// => true
```

## 3. Почати обмін

Ми дуже хочемо, щоб друзі долучилися до нашого божевілля Blorkemon™️, тож час починати обмін!

Коли ми обмінюємося з друзями, не кожен обмін вартий того, та й не кожен можна здійснити взагалі.
Обмінюватися варто лише тоді, коли і в нас, і в друга є картка, якої немає в іншого.

Реалізуйте метод `canTrade`, який приймає нашу поточну колекцію та колекцію одного з наших друзів.
Він має повернути `boolean`, що вказує, чи можливий обмін, за наведеними вище правилами.

```java
Set<String> myCollection = Set.of("Newthree");
Set<String> theirCollection = Set.of("Scientuna");
GottaSnatchEmAll.canTrade(myCollection, theirCollection);
// => true
```

## 4. Визначити спільні картки

Ми збираємося з друзями-ентузіастами Blorkemon™️ і міркуємо, які картки найпоширеніші.

Реалізуйте метод `commonCards`, який приймає список колекцій і повертає колекцію карток, які є в усіх колекціях.

```java
GottaSnatchEmAll.commonCards(List.of(Set.of("Scientuna"), Set.of("Newthree","Scientuna")));
// => {"Scientuna"}
```

## 5. Усі картки

Чи маємо ми з друзями разом усі картки Blorkemon™️?

Реалізуйте метод `allCards`, який приймає список колекцій і повертає колекцію всіх різних карток з усіх колекцій разом.

```java
GottaSnatchEmAll.allCards(List.of(Set.of("Scientuna"), Set.of("Newthree","Scientuna")));
// => {"Newthree", "Scientuna"}
```
