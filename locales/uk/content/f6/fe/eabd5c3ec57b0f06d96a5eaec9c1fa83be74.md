# Вступ

## Цілі числа

C#, як і багато статично типізованих мов, надає низку типів, які представляють цілі числа, і кожен із них має власний діапазон значень. На нижньому кінці тип `sbyte` має мінімальне значення -128 і максимальне значення 127. Як і в усіх цілочисельних типів, ці значення доступні як `<type>.MinValue` і `<type>.MaxValue`. На верхньому кінці тип `long` має мінімальне значення -9,223,372,036,854,775,808 і максимальне значення 9,223,372,036,854,775,807. А між ними лежать типи `short` і `int`.

Діапазони визначаються розрядністю типу, яку виділяє система. Наприклад, тип `byte` використовує 8 бітів, а тип `long` використовує 64 біти.

Кожен із наведених вище типів має відповідний беззнаковий тип: `sbyte`/`byte`, `short`/`ushort`, `int`/`uint` і `long`/`ulong`. У всіх випадках діапазон значень охоплює від 0 до найбільшого відʼємного значення зі знаком, помноженого на 2, плюс 1.

| Тип    | Розрядність | Мінімум                    | Максимум                    |
| ------ | ----------- | -------------------------- | --------------------------- |
| sbyte  | 8 біт       | -128                       | +127                        |
| short  | 16 біт      | -32_768                    | +32_767                     |
| int    | 32 біт      | -2_147_483_648             | +2_147_483_647              |
| long   | 64 біт      | -9_223_372_036_854_775_808 | +9_223_372_036_854_775_807  |
| byte   | 8 біт       | 0                          | +255                        |
| ushort | 16 біт      | 0                          | +65_535                     |
| uint   | 32 біт      | 0                          | +4_294_967_295              |
| ulong  | 64 біт      | 0                          | +18_446_744_073_709_551_615 |

Змінну (або вираз) одного типу можна легко перетворити в інший тип. Наприклад, під час присвоєння, якщо тип значення, яке присвоюють (ліва частина), гарантує, що значення лежить у межах діапазону типу, якому присвоюють (права частина), то присвоєння буде простим:

```csharp
uint ui = uint.MaxValue;
ulong ul = ui;    // no problem
```

З іншого боку, якщо діапазон типу, з якого присвоюють, не є підмножиною діапазону значень типу, якому присвоюють, то потрібна операція приведення типів `()`, навіть якщо конкретне значення входить до діапазону типу, якому присвоюють:

```csharp
short s = 42;
uint ui = (uint)s;
```
