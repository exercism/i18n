# Вступ

Символи та рядки тексту (англ. string) формують основу для представлення тексту в Elm.
Рядки тексту можна уявити як масиви символів, і більшість функцій `List` мають відповідники в модулі `String`.

## Символи

Тип `Char` представляє один символ Unicode, записаний в одинарних лапках, наприклад `'a'`.
Модуль `Char` надає функції-предикати (`Char -> Bool`) для перевірки властивостей символу: `isUpper`, `isLower`, `isAlpha` та `isAlphaNum`.
Модуль також надає функції для перетворення символу: `toUpper`, `toLower`, `toLocaleUpper`, `toLocaleLower`, а також для перетворення в числове значення Unicode (`Int`) і назад за допомогою `toCode` та `fromCode`.

## Рядки тексту

Тип `String` надає вбудоване представлення для ефективної роботи з рядками тексту та може представляти будь-яку послідовність символів Unicode, наприклад «this is an Elm string.»
Багаторядкові рядки тексту записуються трьома подвійними лапками та можуть містити неекрановані лапки й символи нового рядка.
```elm
"""
    This is a multiline string.
All line-breaks and whitespace,
are preserved. 
"""
```

## Функції `String`

Модуль `String` містить усі функції, наведені в таблиці нижче.
Деякі з найуживаніших функцій:

`cons : Char -> String -> String` додає символ на початок рядка тексту.
```elm
cons 'T' "he truth is out there" 
    --> "The truth is out there"
```

`(++): String -> String -> String` приєднує два рядки тексту.
```elm
"butter" ++ "fly" 
    --> "butterfly"
```

`split : String -> String -> List String` розбиває рядок тексту на масив рядків тексту за заданим роздільником.
```elm
split ";" "cat;dog;cow" 
    --> ["cat", "dog", "cow"]
```

`join : String -> List String -> String` зʼєднує масив рядків тексту за допомогою заданого роздільника.
```elm
join "a" ["H", "w", "ii", "n"] 
    --> "Hawaiian"
```

`replace : String -> String -> String -> String` замінює всі входження заданого підрядка.
```elm
replace "Hello" "Goodbye cruel" "Hello world." 
    --> "Goodbye cruel world."
```

`length : String -> Int` повертає кількість символів у рядку тексту.
```elm 
length "Hello world." 
    --> 12
```

`toInt : String -> Maybe Int` намагається перетворити рядок тексту на `Just Int` і повертає `Nothing` для рядків тексту з неправильним форматом.
```elm
toInt "-42" 
    --> Just -42
```    

`contains : String -> String -> Bool` перевіряє, чи другий рядок тексту містить перший.
```elm
contains "the" "theory" 
    --> True
```

`map : (Char -> Char) -> String -> String` застосовує задану функцію до кожного `Char` у рядку тексту.
Зауважте, що надана функція має відображати `Char` у `Char`.
```elm
map (\c -> if c == '/' then '.' else c) "a/b/c" 
    --> "a.b.c"
```
