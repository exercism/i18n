# Інструкції

Надрукуйте числа від 1 до n за такими правилами:

1. Якщо число кратне 3, надрукуйте «Fizz»
2. Якщо число кратне 5, надрукуйте «Buzz»
3. Якщо число кратне і 3, і 5, надрукуйте «Fizz Buzz»
4. Якщо число не кратне ні 3, ні 5, надрукуйте число

Вихідні дані мають бути вектором рядків тексту (англ. string), наприклад: «1» «2» «Fizz» «4» «Buzz» ...
