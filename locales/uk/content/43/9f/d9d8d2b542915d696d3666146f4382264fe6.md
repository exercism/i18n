# Підказки

## 1. Створити нову таблицю рекордів

- Створіть новий обʼєкт за допомогою фігурних дужок.
- Запишіть ключ як рядок тексту (англ. string), щоб ключ міг містити пробіли.
- Відокремте ключ і значення двокрапкою.

## 2. Додати гравців до таблиці рекордів

- Використайте запис через квадратні дужки, щоб додати ключ, імʼя якого збережено в змінній (це аргумент).
- Використайте оператор присвоєння (`=`), щоб задати значення для нового ключа.
- Поверніть параметр таблиці рекордів після того, як додали гравця.

## 3. Видалити гравців з таблиці рекордів

- Використайте [оператор delete][mdn-delete].
- Зверніться до ключа так, як робили це в попередньому завданні (запис через квадратні дужки).

## 4. Збільшити рахунок гравця

- Спочатку подумайте, як виразити нове значення, яке хочете присвоїти.
- Потім використайте оператор присвоєння, як у завданні 2, щоб задати це нове значення.
- Якщо це ще не зроблено, можна скористатися [скороченим оператором присвоєння][mdn-shorthand-assignment] `+=`.

## 5. Застосувати бонусні бали за понеділок

- Використайте цикл `for...in`, щоб перебрати всі ключі в обʼєкті.
- Для кожного ключа задайте нове значення, як у завданні 4.
