# Інструкції

У місцевій школі поблизу діє дуже активна учнівська асоціація.
Асоціацією учнів керує президент, і раз на 2 роки проводяться вибори, щоб обрати нового президента.
На цьогорічних виборах було вирішено, що потрібна нова цифрова система для підрахунку голосів.

Школа потребує допомоги у створенні цієї нової системи.

## 1. Створіть лічильник голосів

Новій системі голосування в першу чергу потрібен лічильник голосів.
Цей лічильник дає змогу відстежувати голоси, які має певний кандидат.

Створіть функцію `new_vote_counter`, яка приймає кількість початкових голосів за кандидата і повертає знімок структури `VoteCounter`, ініціалізований заданою кількістю початкових голосів.

```rust
let initial_votes: u32 = 2;
let counter: @VoteCounter = new_vote_counter(initial_votes);
// @VoteCounter {
//     value: 2,
// }
```

## 2. Отримайте кількість голосів із лічильника

Тепер у нас є спосіб створювати нові лічильники!
Але тепер ми розуміємо, що новій системі також знадобиться спосіб отримувати кількість голосів із лічильника.

Створіть функцію `vote_count`, яка приймає лічильник (`@VoteCounter`) як аргумент і повертає кількість голосів у лічильнику.

```rust
let initial_votes: u32 = 3;
let vote_counter: @VoteCounter = new_vote_counter(initial_votes);

let count = vote_count(vote_counter);
// => 3
```

## 3. Збільште кількість голосів лічильника

Нарешті настав час підрахувати голоси!
Тепер нам потрібен спосіб збільшувати кількість голосів у лічильнику.

Створіть функцію `increment_vote_count`, яка приймає лічильник (`@VoteCounter`) як аргумент і кількість голосів, і збільшує лічильник на цю кількість голосів.

```rust
let votes: u32 = 3;
let vote_counter: @VoteCounter = new_vote_counter(initial_votes);
let vote_counter: VoteCounter = increment_vote_count(vote_counter, 2);

let count = vote_count(@vote_counter);
// => 5
```

## 4. Створіть результати виборів

Коли всі голоси підраховано, настав час підготувати оголошення результатів для всієї школи.
Для цього ми помічаємо, що самих лише лічильників голосів недостатньо.
Потрібен спосіб повʼязати кількість голосів із певним кандидатом.

Створіть функцію `new_election_result`, яка отримує імʼя кандидата та його кількість голосів і повертає новий результат виборів.

```rust
let result: ElectionResult = new_election_result("Peter", 3);
// ElectionResult {
//     name: "Peter",
//     votes: @VoteCounter {
//         value: 3,
//     },
// }
```

Структуру результату виборів уже створено для нас, і вона визначена так:

```rust
struct ElectionResult {
    name: ByteArray,
    counter: @VoteCounter,
}
```

## 5. Оголосіть результати

Настав час оголосити школі нового президента!
Нового президента оголосять на маленьких цифрових табло, які є в школі.

Повідомлення має показувати імʼя нового президента та кількість його голосів у такому форматі: `<candidate_name> (<votes>)`.
Ось приклад такого повідомлення: `"Peter (51)"`.

Створіть функцію `display_result`, яка отримує `@ElectionResult` як аргумент і повертає `ByteArray` із повідомленням для показу.

```rust
let result = ElectionResult {
    name: "John",
    votes: @VoteCounter {
        value: 32,
    },
};

let msg = display_result(@result);
// => "John (32)"
```

## 6. Перерахунок голосів

Щоб переконатися, що остаточні результати точні, голоси перерахували.
Під час перерахунку виявилося, що кількість голосів деяких кандидатів відрізнялася на одиницю.

Створіть функцію `decrement_votes_of_candidate`, яка отримує остаточні результати та імʼя кандидата, для якого слід зменшити кількість голосів.
Остаточні результати подано у формі `Felt252Dict<u32>`, де ключами є імена кандидатів, а значеннями - їхні загальні голоси.

```rust
let mut final_results: Felt252Dict<u32> = Default::default();
final_results.insert('Mary', 10);
final_results.insert('John', 51);

decrement_votes_of_candidate(ref final_results, 'Mary');

let decremented_votes = final_results.get('Mary');
// => 9
```
