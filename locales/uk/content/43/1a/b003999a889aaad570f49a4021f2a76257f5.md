# Тести

Якщо бінарний файл 8th доступний у PATH, введіть команду:

```bash
8th -f test.8th
```

Якщо бінарного файлу 8th немає в PATH, у Windows введіть

```cmd
\path\to\8th -f test.8th
```

Linux або macOS:

```bash
/path/to/8th -f test.8th
```

## Тестування в REPL

Запустіть 8th, завантаживши test-words.8th:

```sh
8th -f test-words.8th
```

Так розпочнеться сесія CLI, у якій, щойно ми напишемо код у файлі свого рішення, його можна буде завантажити в REPL.
Наприклад, для вправи «word-count» потрібно ввести:

```8th
"word-count.8th" f:include
```

А запустити тести можна так:
```sh
"word-count-tests.8th" f:include
```

Або скопіювати один тест із цього файлу чи ввести власний.

## Пропущені тести

Розвʼязати вправу означає домогтися, щоб усі її тести пройшли.
Типово, коли ми запускаємо тести, виконується лише один тест (перший).
Це зроблено навмисно, щоб ми могли зосередитися лише на тому, аби цей один тест пройшов.
Щойно він пройде, можна увімкнути наступний тест, перемістивши слово `SKIP-REST-OF-TESTS` після нього.

## Скасування пропусків

Щоб запустити всі тести, зокрема ті, що йдуть після слова `SKIP-REST-OF-TESTS`, можна встановити змінну середовища `RUN_ALL_TESTS` зі значенням `true`.
Один зі способів зробити це лише на час запуску тестів (macOS і Linux):

```bash
RUN_ALL_TESTS=true 8th -f test.8th
```
