# Додаток до інструкцій

## Регістри

| Регістр | Використання | Тип | Опис |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | вхідні дані | адреса | рядок тексту (англ. string) з іменем, завершений нульовим символом |
| `$a1`    | вхідні дані | ціле число | число |
| `$a2`    | вхідні/вихідні дані | адреса | рядок тексту з результатом, завершений нульовим символом |
| `$t0-9`  | тимчасове | будь-який | для тимчасового зберігання |
