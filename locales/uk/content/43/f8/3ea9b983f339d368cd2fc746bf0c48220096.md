### Динамічний виклик функцій

Функції awk не є обʼєктами першого класу: їх не можна передавати так, як це дозволяють деякі інші мови.
Однак змінна може зберігати _імʼя_ функції, тобто рядок тексту (англ. string), а викликати функцію можна за допомогою спеціального запису `@varname(args)`.
Приклад:

```awk
function greet(name) {
    print "Hello, " name
}
BEGIN {
    greet("John")       # => "Hello, John"

    f = "greet"
    f("Bill")           # => error
    @f("Bill")          # => "Hello, Bill"
}
```
Це описано в [Непрямі виклики функцій][indirect].
Це розширення `gawk`.
