# Розумні вказівники

Розумні вказівники в Cairo - потужний інструмент, який забезпечує безпечне й ефективне керування памʼяттю.

Розумний вказівник - це структура даних, яка поводиться як звичайний вказівник, але має додаткові засоби безпеки, що допомагають уникати типових проблем із керуванням памʼяттю, як-от розіменування нульових вказівників чи доступ до неініціалізованої памʼяті.

## Що таке розумний вказівник?

Загалом вказівник - це змінна, яка зберігає адресу памʼяті й зазвичай указує на значення, що зберігається за цією адресою.

Однак необроблені вказівники можуть бути небезпечними: якщо вказівник не вказує на коректну ділянку памʼяті або його розіменовано неправильно, це може призвести до аварійного завершення програми чи непередбачуваної поведінки.

Розумні вказівники розвʼязують цю проблему, встановлюючи суворі правила керування памʼяттю, завдяки яким доступ до памʼяті відбувається безпечно й контрольовано.

Cairo, як і багато сучасних мов, зокрема Rust, використовує розумні вказівники, щоб запобігти небезпечному доступу до памʼяті.

Розумний вказівник у Cairo не лише зберігає адресу памʼяті, а й відстежує володіння та гарантує безпеку памʼяті.

## Типи розумних вказівників у Cairo

Cairo надає кілька типів розумних вказівників, зокрема `Box<T>` і `Nullable<T>`, кожен з яких виконує власну роль.

Розгляньмо докладніше, як працюють ці типи і коли їх варто використовувати.

### `Box<T>`

Тип `Box<T>` - головний розумний вказівник у Cairo.

Він дає змогу зберігати дані в особливому сегменті памʼяті, який називають «boxed segment». `Box<T>` - це вказівник, що вказує на цей сегмент, і коли ми створюємо бокс, ми виділяємо місце для даних у цьому сегменті.

Бокси ідеально підходять у ситуаціях, коли:

- Потрібно зберегти значення типу, розмір якого неможливо визначити під час компіляції.
- У нас великий обсяг даних, і ми хочемо передати володіння ними без копіювання.

Завдяки боксу великі структури даних можна зберігати ефективніше.

Коли ми передаємо `Box<T>` у функцію, передається лише вказівник, тож копіювати всі дані не потрібно, а це підвищує продуктивність, особливо з великими структурами.

### `Nullable<T>`

Тип `Nullable<T>` - ще один важливий розумний вказівник у Cairo.

Він може вказувати на коректне значення типу `T` або дорівнювати `null`, якщо значення немає.

Цей тип стає в пригоді, коли треба зберігати значення, яких може й не бути, наприклад у словнику, що може містити необовʼязкові елементи.

У Cairo `Nullable<T>` зазвичай використовують у словниках, щоб працювати з випадками, де не можна застосувати типове значення.

Він дає змогу зберігати значення умовно, завдяки чому безпечніше працювати з відсутністю даних.

## Безпека памʼяті з розумними вказівниками

Одна з головних переваг розумних вказівників полягає в тому, що вони допомагають забезпечити безпеку памʼяті.

Керуючи володінням і правилами доступу, Cairo запобігає типовим проблемам, як-от розіменування нульових або висячих вказівників.

Розумні вказівники відстежують, коли дані більше не потрібні, і можуть автоматично звільняти памʼять, коли ті виходять з області видимості, що зменшує ризик витоків памʼяті.

### Приклад: використання `Box<T>` для рекурсивних типів

Робота з рекурсивними типами - поширена складність у багатьох мовах програмування.

Рекурсивні типи містять посилання на самих себе.

Без належного керування памʼяттю визначення рекурсивного типу може призвести до проблем, як-от нескінченна рекурсія.

У Cairo `Box<T>` дає змогу безпечно визначати рекурсивні типи.

Наприклад, за допомогою `Box<T>` можна реалізувати бінарне дерево, де кожен вузол містить посилання на інший вузол.

Зберігаючи посилання в боксах, Cairo гарантує, що обсяг використаної памʼяті буде скінченним, і компілятор може визначити потрібний розмір памʼяті для структури.

```rust
use core::box::{BoxTrait};

#[derive(Copy, Drop)]
enum BinaryTree {
    Leaf: u32,
    Node: (u32, Box<BinaryTree>, Box<BinaryTree>),
}

fn main() {
    let leaf1 = BinaryTree::Leaf(1);
    let leaf2 = BinaryTree::Leaf(2);
    let node = BinaryTree::Node((3, BoxTrait::new(leaf1), BoxTrait::new(leaf2)));
    println!("{:?}", node);
}
```

### Переваги розумних вказівників для продуктивності

Розумні вказівники також підвищують продуктивність програм.

Коли ми використовуємо `Box<T>`, передається лише вказівник на дані, а не копія всієї структури даних.

Це особливо корисно з великими наборами даних, бо суттєво зменшує накладні витрати на операції з памʼяттю.

У наступному прикладі дані передаються за посиланням через `Box<T>`, щоб уникнути витрат на копіювання всієї структури:

```rust
#[derive(Drop)]
struct Cart {
    paid: bool,
    items: u256,
    buyer: ByteArray,
}

fn pass_data(cart: Cart) {
    println!("{} is shopping today and bought {} items", cart.buyer, cart.items);
}

fn pass_pointer(cart: Box<Cart>) {
    let cart = cart.unbox();
    println!("{} is shopping today and bought {} items", cart.buyer, cart.items);
}

fn main() {
    let new_cart = Cart { paid: true, items: 1, buyer: "John" };
    pass_data(new_cart);

    let new_box = BoxTrait::new(Cart { paid: false, items: 3, buyer: "Jane" });
    pass_pointer(new_box);
}
```

У цьому прикладі `pass_pointer` приймає `Box<Cart>` замість `Cart`, що зменшує обсяг памʼяті, скопійованої під час виклику функції.
