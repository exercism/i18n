# Вступ

Методи розширення дозволяють додавати методи до наявних типів, не створюючи нового похідного типу, не перекомпільовуючи й не змінюючи жодним іншим чином початковий тип. Їх визначають як статичні методи, але викликають за допомогою синтаксису методів екземпляра. Перед першим параметром такого методу стоїть модифікатор `this`, який указує, з яким типом працює метод, а самі методи потрапляють в область видимості на рівні простору імен.

```csharp
public static int WordCount(this string str)
{
    return str.Split().Length;
}

"Hello World".WordCount();
// => 2
```
