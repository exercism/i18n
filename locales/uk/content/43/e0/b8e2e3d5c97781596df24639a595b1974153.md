# Докладніше

Цілі числа - це числа без десяткової коми (як-от `-6`, `0`, `25`, `1234` тощо).

Тип цілих чисел поділено на два підтипи: `fixnum` і `bignum`.

* `fixnum` визначено як ціле число зі знаком, що займає щонайменше 16 бітів, але залежно від реалізації воно, найімовірніше, більше.
* `bignum` - це тип, що містить будь-яке ціле число, більше за `fixnum`.

У Common Lisp цілі числа можуть бути довільно великими або малими, тож не потрібно хвилюватися про «переповнення», працюючи з ними.
Хоча в деяких інших мовах можна натрапити на втрату точності або на переповнення великих чисел, розмір цілих чисел у Common Lisp обмежує лише обсяг доступної памʼяті.

```lisp
;; Big integers are no problem
(expt 2 200) ; => 1606938044258990275541962092341162602522202993782792835301376
```
