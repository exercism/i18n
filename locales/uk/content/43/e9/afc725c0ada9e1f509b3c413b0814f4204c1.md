# Вступ

[Варіативні параметри][variadic-parameters] дають змогу функції приймати нуль або більше значень указаного типу для одного параметра.
Ми визначаємо варіативний параметр, дописуючи три крапки (`...`) до анотації типу параметра.

Усередині тіла функції Swift робить ці значення доступними як масив указаного типу:

```swift
import Foundation

func geometricMean(_ numbers: Double...) -> Double {
    var total = 1.0
    for number in numbers {
        total *= number
    }
    return pow(total, 1.0 / Double(numbers.count))
}

let result = geometricMean(1, 2, 3, 4, 5)
// result is 2.605171084697352
```

~~~~exercism/note
Якщо функція має додаткові параметри після варіативного параметра, то перший параметр після варіативного **обовʼязково** повинен мати явну мітку аргументу, щоб Swift знав, де закінчується список варіативних аргументів.
~~~~
