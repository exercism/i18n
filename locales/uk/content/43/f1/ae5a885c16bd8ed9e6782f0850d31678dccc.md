# Інструкції

У цій вправі ми реалізуємо спосіб відстежувати найвищі результати для найпопулярнішої гри в місцевому залі ігрових автоматів.

Тут потрібно реалізувати 7 функцій, і всі вони повʼязані з поверненням та змінюванням словника даних про найвищі результати.

## 1. Визначте новий словник найвищих результатів

Створіть функцію `newScoreBoard()`, яка не приймає параметрів і повертає новий словник найвищих результатів із ключами типу `String` і значеннями типу `Int`.

## 2. Додайте гравців до словника найвищих результатів

Щоб додати гравця до словника найвищих результатів, визначте функцію `addPlayer(_:_:_:)`, яка приймає 3 параметри:

- Перший параметр - словник результатів.
    Це має бути in-out-параметр.
- Другий параметр - імʼя гравця у вигляді рядка тексту (англ. string).
- Третій параметр - результат у вигляді цілого числа.
    Параметр необовʼязковий. Реалізуйте третій параметр із типовим значенням 0.

```swift
var highScores = newScoreBoard()
addPlayer(&highScores, "Dave Thomas")
// Returns ["Dave Thomas": 0]
addPlayer(&highScores, "José Valim", 486_373)
// Returns ["Dave Thomas": 0, "José Valim": 486_373]
```

## 3. Видаліть гравців зі словника результатів

Щоб видалити гравця зі словника найвищих результатів, визначте функцію `removePlayer(_:_:)`, яка приймає 2 параметри:

- Перший параметр - словник результатів.
    Це має бути in-out-параметр.
- Другий параметр - імʼя гравця у вигляді рядка тексту.

Ця функція має видалити гравця зі словника, якщо він там є, і нічого не робити в іншому разі.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373]
removePlayer(&highScores, "Dave Thomas")
// Returns ["José Valim": 486_373]
removePlayer(&highScores, "Rose Fanaras")
// Returns ["José Valim": 486_373]
```

## 4. Скиньте результат гравця

Щоб скинути результат гравця, визначте функцію `resetPlayer(_:_:)`, яка приймає 2 параметри:

- Перший параметр - словник результатів.
    Це має бути in-out-параметр.
- Другий параметр - імʼя гравця у вигляді рядка тексту, чий результат потрібно скинути.

Функція встановить гравцеві результат 0.
Якщо гравця немає у словнику, нічого не має статися.

```swift
var highScores = ["Dave Thomas": 486_373, "José Valim": 10]
resetScore(&highScores, "Dave Thomas")
// Returns ["Dave Thomas": 0, "José Valim": 10]
```

## 5. Оновіть результат гравця

Щоб оновити результат гравця, додавши його до попереднього результату, визначте функцію `updateScore`, яка приймає 3 параметри:

- Перший параметр - словник результатів. Це має бути in-out-параметр.
- Другий параметр - імʼя гравця у вигляді рядка тексту, чий результат потрібно оновити.
- Третій параметр - результат, який потрібно **додати** до збереженого найвищого результату.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373]
addPlayer(&highScores, "Freyja Ćirić", 12_771_008)
updateScore(&highScores, "Freyja Ćirić", 73)
// Returns ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_081]
```

## 6. Отримайте список гравців із результатами, відсортований за іменем гравця

Визначте функцію `orderByPlayers`, яка приймає 1 параметр:

- Перший параметр - словник результатів.

Функція поверне масив кортежів `(String, Int)`, які містять гравців та їхні найвищі результати, відсортовані за іменем гравця в порядку зростання.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_091]
orderByPlayers(highScores)
// Returns [("Dave Thomas", 0), ("Freyja Ćirić", 12_771_091), ("José Valim", 486_373)]
```

## 7. Отримайте список гравців, відсортований за результатом у порядку спадання

Щоб отримати список гравців, відсортований за результатами у порядку спадання, визначте функцію `orderByScores`, яка приймає 1 параметр:

- Перший параметр - словник результатів.

Функція поверне масив кортежів `(String, Int)`, які містять гравців та їхні найвищі результати, відсортовані за результатом гравця у порядку спадання.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_091]
orderByScores(highScores)
// Returns [("Freyja Ćirić", 12_771_091), ("José Valim", 486_373), ("Dave Thomas", 0)]
```
