# Рядки тексту

У Crystal є тип [`String`][strings], який використовують для представлення тексту.
Рядки тексту (англ. string) у Crystal - це послідовності символів Unicode.
Рядки тексту незмінні: після створення їх уже не можна змінити.
Тому щоразу, коли ми змінюємо рядок тексту, створюється новий рядок, а початковий залишається без змін.

Щоб визначити рядок тексту, використовують подвійні лапки `"`.

```crystal
"Hello World"
```

## Конкатенація

Щоб зʼєднати два рядки тексту, використаймо оператор `+`.
Оператор `+` повертає новий рядок тексту, який поєднує ці два рядки.

```crystal
hello = "Hello"
hello + " World"
# => "Hello World"
```

## Перетворення між рядками тексту та числами

Метод `to_i` перетворює рядок тексту на ціле число.
Натомість метод `to_f` повертає число з плаваючою комою.
Якщо рядок тексту не вдається перетворити на число, буде викликано помилку `ArgumentError`.

```crystal
"1".to_i
# => 1

"1.0".to_f
# => 1.0

"Hello".to_i
# => ArgumentError: Invalid integer: Hello
```

Ціле число або число з плаваючою комою можна перетворити на рядок тексту методом `to_s`.

```crystal
1.to_s
# => "1"

1.0.to_s
# => "1.0"
```

## Інтерполяція

Інтерполяція - це зручний спосіб поєднувати рядки тексту й вбудовувати вирази в рядки.
Щоб інтерполювати рядок тексту, використаймо символ `#`, за яким ідуть фігурні дужки `{}` із виразом усередині.

```crystal
name = "World"
"Hello #{name}!"
# => "Hello World!"
```

Crystal автоматично перетворить результат виразу на рядок тексту.

```crystal
"Hello #{1 + 1}!"
# => "Hello 2!"
```

## Розмір

Коли потрібно дізнатися кількість символів у рядку тексту, скористаймося методом `size`, який повертає довжину рядка як ціле число.
Розмір рядка тексту зберігається як властивість цього рядка, тож його не потрібно обчислювати щоразу при виклику методу, завдяки чому метод працює дуже швидко.

```crystal
"Hello World".size
# => 11
```

## Індексація

Індексація потрібна, коли ми хочемо дістати конкретний символ із рядка тексту.
Щоб дістати символ із `String`, можна скористатися звичним записом у квадратних дужках.

~~~~exercism/note
`[]` реалізовано як метод екземпляра `String`, де індекс є аргументом методу.
~~~~

Перший символ у рядку тексту в Crystal має індекс 0.

```crystal
"Hello World"[0]
# => 'H'

"Hello World"[6]
# => 'W'
```

Щоб дістати символ із кінця рядка тексту, можна взяти довжину рядка мінус один, і це буде індекс останнього символу; для передостаннього символу - довжину мінус два, і так далі.
Є й коротший шлях: скористатися відʼємним індексом, де останній символ має індекс -1, передостанній - індекс -2, і так далі.

```crystal
name = "Hello World"
name[name.size - 1]
# => 'd'

name[-1]
# => 'd'
```

## Екранування

Деякі символи не можна записати в рядку тексту безпосередньо, для них потрібна керуюча послідовність.
Наприклад, щоб ужити подвійні лапки всередині рядка тексту, їх потрібно екранувати.
Керуючу послідовність записують за допомогою символу `\`, за яким іде символ, який потрібно екранувати.

Ось спеціальні символи в Crystal:

| Значення | Опис                          |
| -------- | ----------------------------- |
| `\a`     | Сигнал                        |
| `\b`     | Крок назад                    |
| `\e`     | Керуючий символ               |
| `\f`     | Подача сторінки               |
| `\n`     | Переведення рядка або новий рядок |
| `\r`     | Повернення каретки            |
| `\t`     | Горизонтальна табуляція       |
| `\v`     | Вертикальна табуляція         |
| `\\`     | Зворотна коса риска           |
| `\'`     | Одинарні лапки                |
| `\"`     | Подвійні лапки                |
| `\377`   | Вісімковий символ ASCII       |
| `\xFF`   | Шістнадцятковий символ ASCII  |
| `\uFFFF` | Шістнадцятковий символ Unicode |

```crystal
puts "Hello \"World\""
# => Hello "World"

puts "Hello \nWorld"
# => Hello
# => World
```

## Багаторядкові рядки тексту

Щоб записати багаторядковий рядок тексту, використовують той самий синтаксис, що й для однорядкового, але кожен рядок вмісту переносять на новий рядок.

```crystal
"Hello
World"
# => "Hello\nWorld"
```
