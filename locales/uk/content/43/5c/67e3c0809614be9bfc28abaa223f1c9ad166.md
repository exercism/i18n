# Встановлення

## Встановлення Godot Engine

Трек GDScript побудовано на основі [Godot Engine][godot-engine], який працює на Windows, Linux, macOS та Android.
Наразі засіб запуску тестів для [роботи локально][working-locally] потребує Linux.
Цьому треку потрібен Godot версії 4.0 або новішої.

Після завершення встановлення можна перевірити, чи CLI встановлено успішно, виконавши в терміналі таку команду:

```bash
godot --version
```

## Встановлення засобу запуску тестів для треку GDScript в Exercism

Для роботи із засобом запуску тестів потрібно [правильно встановити Godot][installation].

Щоб збирати й тестувати скрипти GDScript для Exercism, Godot запускатиметься з CLI в режимі «headless».
Ці інструкції наразі потребують Linux і bash.

### Крок 1: Встановлення загальної інфраструктури засобу запуску тестів

Щоб налаштувати тестування, клонуйте [https://github.com/exercism/gdscript-test-runner][gdscript-test-runner] і перемістіть його вміст до `/opt/test-runner/`:

```sh
git clone https://github.com/exercism/gdscript-test-runner.git
sudo mv gdscript-test-runner/ /opt/test-runner/
```

### Крок 2: Завантаження скрипту засобу запуску тестів для однієї вправи

Якщо інструмент `exercism` уже налаштовано і завантажено принаймні одну вправу з GDScript, він мав створити теку `gdscript` у робочому просторі (її показує команда `exercism configure`) для зберігання вправ.
Збережіть [засіб запуску тестів][test-local-gdscript-solution] у цій теці та позначте файл як виконуваний.

## Запуск тестів

Коли кроки встановлення виконано, можна почати з будь-якої теки вправи (наприклад, `~/exercism/gdscript/two-fer`) і запустити скрипт (розташований на рівень вище, у `../`), щоб перевірити локальне рішення цієї вправи:

```sh
../test-local-gdscript-solution.sh
```

## Використання IDE

Щоб отримати підсвічування синтаксису GDScript у редакторі на кшталт [Visual Studio Code][vscode], потрібно встановити розширення, як-от [godot-tools][godot-tools], а також мати запущений сервер зневадження.
Godot запускає цей сервер зневадження автоматично, коли проєкт відкрито в його власному редакторі, і тримає його запущеним, доки не закрито проєкт або сам Godot.
