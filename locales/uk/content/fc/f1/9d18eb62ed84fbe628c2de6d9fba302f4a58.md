# Вказівки

Кожна рутина, яку виконує танцювальна трупа, будується на тій самій розминці, а далі йде своїм шляхом.

У заготовці вже є `WARM_UP`. Нижче напишіть ще три класи.

## 1. Джазова рутина

`JAZZ_ROUTINE` бере з `WARM_UP` усе без змін і нічого не додає.

```sather
JAZZ_ROUTINE::counts
-- => 8
JAZZ_ROUTINE::describe
-- => "8 counts"
```

## 2. Чечіткова рутина

`TAP_ROUTINE` бере `counts` з `WARM_UP`, але описує себе по-своєму. Залиште `describe` поза include і напишіть новий.

```sather
TAP_ROUTINE::counts
-- => 8
TAP_ROUTINE::describe
-- => "Tap: 8 counts"
```

## 3. Фінал

`FINALE` бере `counts` з `WARM_UP` під іменем `warm_up_counts` і не включає `describe`. Далі в нього є власний `counts`, удвічі більший за розминковий, і власний `describe`.

```sather
FINALE::warm_up_counts
-- => 8
FINALE::counts
-- => 16
FINALE::describe
-- => "Finale: 16 counts"
```

Зверніть увагу: `FINALE::counts` не збігається з `WARM_UP::counts`, і обидва доступні під різними іменами в одному класі.
