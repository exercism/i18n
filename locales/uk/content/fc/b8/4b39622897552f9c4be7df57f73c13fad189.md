# Вступ

## Основи

### Функції

У Gleam функції визначають за допомогою синтаксису `pub fn`.

```gleam
pub fn add(x: Int, y: Int) -> Int {
  x + y
}
```

Ця функція приймає два аргументи, обидва типу `Int`, і повертає значення типу `Int`. У Gleam немає ключового слова `return`: значення останнього виразу у функції завжди повертається _неявно_.

Анотації типів для аргументів і тип поверненого значення необовʼязкові, і Gleam завжди повністю перевірятиме типи в коді. Зазвичай програмісти Gleam додають анотації типів для ясності, але за бажанням їх можна опустити.

```gleam
pub fn add(x, y) {
  x + y
}
```

Функцію можна викликати за допомогою синтаксису `function_name(argument1, argument2)`.

```gleam
pub fn double(x: Int) -> Int {
  // Call the add function defined above
  add(x, x)
}
```

### Змінні

У Gleam змінні визначають за допомогою синтаксису `let name = expression`.

```gleam
pub fn main() {
  let count = 1
}
```

Змінні можна оголошувати з анотаціями типів. Як і аргументи функцій, вони необовʼязкові, хоча більшість програмістів Gleam заради стислості опускає анотації типів для змінних.

```gleam
pub fn main() {
  let count: Int = 1
}
```

### Рядкові літерали

У Gleam рядки тексту (англ. string) записують у подвійних лапках.

```gleam
pub fn greeting() {
  "Hello, world!"
}
```

### Коментарі в коді

Коментарі можна використовувати, щоб залишати нотатки іншим розробникам, які читають вихідний код. У Gleam коментар займає один рядок і починається з `//`.

```gleam
pub fn main() {
  // This is a comment
  let x = 1
}
```
