# Вступ

Конструкція `guard` у Swift використовується для дострокового повернення з функцій Swift, коли не виконано необхідну умову, потрібну для продовження обробки, наприклад:

```swift
guard myValue >= 0 else { return 0 }
let root = myValue.squareRoot()
```

Тут `guard` перевіряє, чи булевий вираз (англ. Boolean) після ключового слова `guard` обчислюється як правда. Якщо так, обробка продовжується кодом після конструкції guard (тут `let root = myValue.squareRoot()`. Інакше буде виконано код у гілці else. На відміну від умовної конструкції `if`, конструкція `guard` _обовʼязково_ повинна мати гілку else, а на відміну від гілки else конструкції if-else, гілка else конструкції guard _обовʼязково_ повинна вийти з області видимості конструкції guard. Тобто вона повинна використати інструкцію передачі керування, як-от `return`, `continue`, `break`, або викинути помилку чи завершити програму.
