# Char

`Char` - це тип даних у Crystal, що представляє 32-бітну [кодову точку Unicode][unicode].
Його розмір робить його економним щодо памʼяті та надає йому особливих властивостей, яких не мають рядки тексту (англ. string).
Такі значення створюють за допомогою одинарних лапок (`'`), і всередину можна помістити лише одну кодову точку Unicode.

```crystal
'a' # => 'a'
'a'.class # => Char
```

У Crystal досить часто доводиться працювати з `Char`, коли ми працюємо з рядками тексту, адже чимало методів класу `String` повертають `Char` або приймають `Char` як аргументи.
Наприклад, метод [`String#[]`][index] повертає `Char`, а метод [`String#chars`][chars] повертає колекцію `Char`.

## Інкремент і декремент

Оскільки `Char` є 32-бітною кодовою точкою Unicode, він підтримує інкремент і декремент: якщо у нас є `'a'`, то, додавши одиницю, ми отримаємо `'b'`.

```crystal
'a' + 5
# => 'f'

'z' - 25
# => 'a'
```

Також є метод [`Char#succ`][succ], який повертає наступний символ у таблиці Unicode, і [`Char#pred`][pred], який повертає попередній символ у таблиці Unicode.

```crystal
'a'.succ
# => 'b'

'z'.pred
# => 'y'
```

## Конкатенація

Оскільки `Char` призначений лише для представлення 32-бітної кодової точки Unicode, два символи не можна конкатенувати.
Тому `Char` можна конкатенувати лише з рядками тексту.

```Crystal
'a' + "bc"
# => "abc"

'a' + 'b'
# => error: expected argument #1 to 'Char#+' to be Int or String, not Char
```

## Методи властивостей

У Crystal є кілька методів, які дають змогу дізнатися більше про символ: наприклад, чи є він числом або літерою, чи написаний у верхньому чи нижньому регістрі.
Ось список деяких із цих методів; повний список дивіться в [API Char][char-api]:

| Метод                            | Опис                                                 |
| -------------------------------- | ---------------------------------------------------- |
| [`Char#number?`][number]         | Повертає `true`, якщо символ є числом                |
| [`Char#letter?`][letter]         | Повертає `true`, якщо символ є літерою               |
| [`Char#lowercase?`][lowercase]   | Повертає `true`, якщо символ у нижньому регістрі     |
| [`Char#uppercase?`][uppercase]   | Повертає `true`, якщо символ у верхньому регістрі    |
| [`Char#ascii?`][ascii]           | Повертає `true`, якщо символ належить до ASCII       |
| [`Char#whitespace?`][whitespace] | Повертає `true`, якщо символ є пробільним            |

## Перетворення

### Перетворення між кодовими точками та `Char`

Оскільки `Char` представляє 32-бітну кодову точку Unicode, ми можемо перетворювати `Char` у кодові точки (`Int`) і навпаки.
Для цього використовують метод [`Char#ord`][ord], який повертає кодову точку символу, або метод [`Int#chr`][chr], який повертає символ за його кодовою точкою.

```crystal
'a'.ord
# => 97

97.chr
# => 'a'
```

### Перетворення між типами

Як і в інших типів даних, у символів є кілька методів для перетворення між типами.
Найпоширеніший із них - метод `Char#to_s`, який перетворює символ у рядок тексту. Крім того, є метод `Char#to_i`, який перетворює символ у Int, і метод `Char#to_f`, який перетворює символ у Float.

```crystal
'a'.to_s
# => "a"

'4'.to_i
# => 4

'a'.to_i
# => Error: Invalid integer: a (ArgumentError)
```
