## Вступ

Рішення наших вправ різняться надзвичайно.
Найпростіша «справжня» вправа в більшості треків - це `TwoFer`.
Типове рішення має такий вигляд (це Ruby, але в більшості мов усе схоже):

```ruby
module TwoFer
  def self.two_fer(name='you')
    "One for #{name}, one for me."
  end
end
```

Однак із 500 останніх рішень, що пройшли тести, понад 350 виявилися унікальними 😲
І навіть якщо нормалізувати пробіли й назви змінних, понад половина все одно буде справді унікальними рішеннями.

Це робить дослідження того, як усі розвʼязують задачі, неймовірно захопливим.
Але це й цілком непрактично. На Exercism мільйони рішень, і прочитати їх усі буквально означало б витратити ціле життя.

Однак! Розробивши вправи й провівши через них сотні тисяч людей як наставники, наша команда досить добре уявляє, які різні підходи обирають люди.
Тож ми додали нову вкладку «Dig Deeper», щоб показати різні ідіоматичні (або неідіоматичні, але цікаві) способи розвʼязати вправу.

## Приклад

Розгляньмо приклад, щоб побачити це в дії.
У C# рядок тексту (англ. string) можна перевернути різними способами.

Можна скористатися методом `Array.Reverse()`:
```csharp
var chars = input.ToCharArray();
Array.Reverse(chars);
return new string(chars);
```

Або застосувати коротший підхід на основі LINQ:
```csharp
return new string(input.Reverse().ToArray());
```

або скористатися `StringBuilder`:
```
var chars = new StringBuilder();
for (var i = input.Length - 1; i >= 0; i--)
{
    chars.Append(input[i]);
}
return chars.ToString();
```

або навіть трохи менш ідіоматично (але продуктивніше!) використати `Span<T>`:

```csharp
Span<char> chars = stackalloc[input.Length];
for (var i = 0; i < input.Length; i++)
{
    chars[input.Length - 1 - i] = input[i];
}
return new string(chars);
```

Кожен із них ми називаємо підходом, і для кожного є окрема стаття, яка його пояснює.
Сторінка «Dig Deeper» для цієї вправи збирає їх докупи, а також містить статтю про продуктивність, яка досліджує компроміси.
