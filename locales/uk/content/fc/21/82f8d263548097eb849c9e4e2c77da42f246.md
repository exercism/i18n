# Інструкції

Ми відкриваємо сирний клуб, який використовуватиме машинне навчання (ML), щоб добирати нові сири для наших любителів сиру на основі їхньої історії та смаків.

Нові учасники мають заповнити початкове опитування, щоб ми могли зібрати трохи базових даних для початку.
Завдяки цьому зʼясувалося, що є частина категоричних клієнтів, чиїм відгукам бракує нюансів.
Оскільки це може безповоротно викривити алгоритм, чутливіший до нюансів, для їхніх потреб налаштовано окремий алгоритм.
Потрібно написати кілька допоміжних функцій, щоб упорядкувати їхні дані.

~~~~exercism/note
Хоча наведені нижче завдання можна розвʼязати різними способами, кожне з них розвʼязується не більше ніж двома функціями вищого порядку.
~~~~

## 1. Класифікувати клієнтів

Система оцінювання має пʼятизіркову шкалу, яка складається з цілих чисел `1:5`.
Категоричні клієнти ставлять лише оцінки `1` або `5`, і ми хочемо знати, чи клієнт поводиться саме так.

Реалізуйте `all_15()`, яка приймає вектор оцінок і повертає `true`, якщо всі оцінки дорівнюють `1` або `5`, і false в іншому разі.

```R
all_15(c(2, 3, 4, 4, 1))
#> [1] FALSE

all_15(c(1, 5, 5, 1, 5))
#> [1] TRUE
```

## 2. Дати імена клієнтам

Потрібно зіставити імʼя клієнта (або ID) з його оцінками.

Реалізуйте `name_customers()`, яка приймає вектор імен і список оцінок та «зшиває» їх у список списків.

Елементи внутрішнього списку повинні мати імена `name` і `rating`.

```R
names <- c("c1", "c2")
ratings <- list(c(2, 3, 5), c(1, 1, 5))
name_customers(names, ratings)
#> [[1]]
#> [[1]]$name
#> [1] "c1"

#> [[1]]$rating
#> [1] 2 3 5

#> [[2]]
#> [[2]]$name
#> [1] "c2"

#> [[2]]$rating
#> [1] 1 1 5
```

## 3. Відокремити категоричних клієнтів

Потрібно відокремити категоричніших клієнтів від решти.

Реалізуйте `emphatics()`, яка приймає клієнтів та оцінки.
Повертає список, до якого потрапляють лише ті, хто ставить оцінки `1` або `5`.

```R
# names and ratings as in the task 2 example

emphatics(names, ratings)
#> [[1]]
#> [[1]]$name
#> [1] "c2"

#> [[1]]$rating
#> [1] 1 1 5
```

## 4. Змінити оцінки на двійкові

Оскільки категоричні клієнти ставлять лише оцінки `1` і `5`, обчислювально зручніше замінити їх на `0` і `1`.

Реалізуйте `to_binary()`, яка приймає вектор категоричних оцінок.
Повертає двійкові оцінки, де `1` змінено на `0`, а `5` - на `1`.

```R
to_binary(c(1, 1, 5, 5, 1))
#> [1] 0 0 1 1 0
```

## 5. Обчислити середні оцінки з плином часу

Ми хочемо постійно покращувати рекомендації для кожного окремого клієнта (не лише для категоричних) з часом, у міру того як краще розуміємо їхні смаки.

Реалізуйте `satisfactions()`, яка приймає вектор оцінок.
Повертає вектор кумулятивних середніх оцінок на цей момент.
Округліть результати до 2 знаків після коми.

Сподіваємося, що ці числа й надалі будуть зростати, на радість щасливим клієнтам!

```R
satisfactions(c(1, 2, 2, 3))
#> [1] 1.00 1.50 1.67 2.00
```
