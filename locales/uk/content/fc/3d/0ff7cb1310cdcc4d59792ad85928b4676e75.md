# Інструкції

Mecha Munch™, компанія з автоматизації покупок продуктів, щойно найняла нас працювати над їхнім застосунком для замовлень.
Перед нашою командою стоїть завдання створити MVP (_[мінімально життєздатний продукт][mvp]_), який керує всіма базовими діями з кошиком для покупок і дає користувачам змогу додавати, видаляти та сортувати свої замовлення.
На щастя, усі фінансові питання та оформлення замовлень бере на себе інша команда!

## 1. Додати товар(и) до кошика користувача

MVP має давати користувачеві змогу додавати товари до свого кошика для покупок.
Це може бути один товар або кілька товарів одразу.
Оскільки йдеться про MVP, кількість товару позначається _повторами_.
Якщо користувач хоче додати 2 апельсини, «Oranges» зʼявиться двічі у вхідному обʼєкті, який можна перебрати.
Якщо цей товар уже є в кошику користувача, його кількість у кошику потрібно збільшити на 1.
Якщо товар _новий_ для кошика, його додають із кількістю 1.

Створіть функцію `add_item(<current_cart>, <items_to_add>)`, яка як аргументи приймає словник кошика та будь-який схожий на список обʼєкт із товарами для додавання, який можна перебрати.
Вона має повернути новий (оновлений) словник кошика користувача.

```python
>>> add_item({'Banana': 3, 'Apple': 2, 'Orange': 1},
              ('Apple', 'Apple', 'Orange', 'Apple', 'Banana'))
{'Banana': 4, 'Apple': 5, 'Orange': 2}

>>> add_item({'Banana': 3, 'Apple': 2, 'Orange': 1},
              ['Banana', 'Orange', 'Blueberries', 'Banana'])
{'Banana': 5, 'Apple': 2, 'Orange': 2, 'Blueberries': 1}
```

## 2. Зчитати товари зі списку в застосунку нотаток користувача

Ой-ой.
Схоже, продуктова команда взялася за [розростання можливостей][feature creep].
Вони хочуть додати до MVP додаткові можливості.
Тепер застосунок має створювати кошик для покупок, зчитуючи товари із застосунку нотаток користувача.
Зручно для користувачів, але трохи більше роботи для команди.

Створіть функцію `read_notes(<notes>)`, яка приймає як аргумент будь-який схожий на список обʼєкт, який можна перебрати.
Функція має розібрати товари та створити словник кошика користувача.
Кожен товар додається з кількістю 1.
Потім потрібно повернути новий кошик користувача.

```python
>>> read_notes(('Banana','Apple', 'Orange'))
{'Banana': 1, 'Apple': 1, 'Orange': 1}

>>> read_notes(['Blueberries', 'Pear', 'Orange', 'Banana', 'Apple'])
{'Blueberries' : 1, 'Pear' : 1, 'Orange' : 1, 'Banana' : 1, 'Apple' : 1}
```

## 3. Оновити розділ рецептів «ideas»

У застосунку є розділ «ideas», наповнений готовими рецептами різних кухонь.
Користувач може вибрати будь-який із цих рецептів, і всі його інгредієнти автоматично додадуться до кошика для покупок.
Менеджер проєкту попросив нас зробити спосіб редагувати ці рецепти з «ideas», бо команда контенту постійно змінює інгредієнти та кількості.

Створіть функцію `update_recipes(<ideas>, <recipe_updates>)`, яка як аргументи приймає словник «ideas» та обʼєкт з оновленнями рецептів, який можна перебрати.

## 4. Відсортувати товари в кошику користувача

Коли користувач уже почав кошик, застосунок дає змогу відсортувати товари за абеткою.
Так легше щось знайти, і це допомагає, коли трапляються помилки введення даних, як-от «potatoes» і «Potato» у базі даних.

Створіть функцію `sort_entries(<cart>)`, яка приймає кошик (словник) як аргумент і повертає новий, відсортований за абеткою.

```python
>>> sort_entries({'Banana': 3, 'Apple': 2, 'Orange': 1})
{'Apple': 2, 'Banana':3, 'Orange': 1}
```

## 5. Надіслати кошик користувача до магазину для виконання замовлення

Застосунок має надіслати кошик користувача до магазину для виконання замовлення.
Однак працівникам магазину, які збирають замовлення, потрібно знати, у якому відділі магазину лежить товар і чи потребує він охолодження.
Тож (_досить умовно_) «кошик виконання» потрібно відсортувати у зворотному алфавітному порядку, а кількість кожного товару поєднати з інформацією про місце й охолодження.

Створіть функцію `send_to_store(<cart>, <aisle_mapping>)`, яка приймає кошик користувача та словник, де для кожного товару вказано номер відділу магазину й `True`/`False` щодо потреби в охолодженні.
Функція має `return` обʼєднаний «кошик виконання», який містить (кількість, відділ і охолодження) для кожного товару, який замовляє клієнт.
Товари мають бути в _зворотному_ алфавітному порядку.

```python
>>> send_to_store({'Banana': 3, 'Apple': 2, 'Orange': 1, 'Milk': 2},
                  {'Banana': ['Aisle 5', False], 'Apple': ['Aisle 4', False], 'Orange': ['Aisle 4', False], 'Milk': ['Aisle 2', True]})
{'Orange': [1, 'Aisle 4', False], 'Milk': [2, 'Aisle 2', True], 'Banana': [3, 'Aisle 5', False], 'Apple': [2, 'Aisle 4', False]}
```

## 6. Оновити запаси магазину відповідно до того, що замовив користувач.

Застосунок не може просто без кінця приймати замовлення клієнтів.
Рано чи пізно в магазині закінчаться різні товари.
Тож MVP застосунку має оновлювати запаси магазину щоразу, коли користувач надсилає своє замовлення до магазину.
Інакше клієнти будуть замовляти товари, яких насправді немає.

Створіть функцію `update_store_inventory(<fulfillment_cart>, <store_inventory>)`, яка приймає «кошик виконання» та запаси магазину.
Функція має зменшити запаси магазину на кількість, «замовлену» в «кошику виконання», а потім повернути оновлені запаси магазину.
Там, де кількість товару в магазині падає до 0, її потрібно замінити повідомленням «Out of Stock».

```python
>>> update_store_inventory({'Orange': [1, 'Aisle 4', False], 'Milk': [2, 'Aisle 2', True], 'Banana': [3, 'Aisle 5', False], 'Apple': [2, 'Aisle 4', False]},
{'Banana': [15, 'Aisle 5', False], 'Apple': [12, 'Aisle 4', False], 'Orange': [1, 'Aisle 4', False], 'Milk': [4, 'Aisle 2', True]})

{'Banana': [12, 'Aisle 5', False], 'Apple': [10, 'Aisle 4', False], 'Orange': ['Out of Stock', 'Aisle 4', False], 'Milk': [2, 'Aisle 2', True]}
```
