# Вступ

Замикання в Swift - це самодостатні блоки коду, яким можна передати параметри, щоб запустити їхнє обчислення й отримати повернені значення. Замикання також захоплюють значення зі свого середовища і використовують їх у своїх обчисленнях. Оскільки вони самодостатні, їх можна передавати в програмі, як і інші значення, або присвоювати константам і змінним.

Замикання можуть видаватися дуже схожими на функції Swift, і недарма. Функції у Swift - це лише окремий випадок замикань, які повинні мати імʼя і визначаються дещо іншим синтаксисом.

Хоча функції у Swift технічно є замиканнями, коли кажуть «замикання» у Swift, то мають на увазі саме вирази замикання. Вираз замикання записують як список параметрів, далі тип повернення та ключове слово `in`, а потім тіло замикання; усе це міститься в парі фігурних дужок:

```swift
{ (a: Double, b: Double) -> Double in
  return a + b / 2.0
}
```

Це визначає вираз замикання типу `(Double, Double) -> Double`, і його можна виконати так само, як функцію цього типу, застосувавши його до параметрів відповідного типу:

```swift
{ (a: Double, b: Double) -> Double in
  return a + b / 2.0
}(10.0, 15.0)
// => 12.5
```

Як видно з прикладу вище, замикання, як і звичайні функції, можуть опускати ключове слово `return`, якщо тіло замикання складається з єдиного виразу.
