# Символи

**Символ** - це одна літера, цифра, пробіл або знак. У Sather тип для одного
символу - `CHAR`, а сам символ записують в одинарних лапках.

```sather
   initial : CHAR is
      return 'M';
   end;
```

Одинарні лапки для одного символу, подвійні для рядка тексту (англ. string).
`'M'` і `"M"` - це різні типи, і їх не можна замінювати один одним.

## Символи з рядка тексту

Рядок тексту - це послідовність символів, а квадратні дужки дістають окремий
символ за позицією, рахуючи від нуля, так само як у масиві.

```sather
"Marlowe"[0]      -- 'M'
"Marlowe"[3]      -- 'l'
```

## Запитуємо про символ

| Виклик | Відповідь |
| --- | --- |
| `c.is_alpha` | це літера? |
| `c.is_digit` | це одна з `0`–`9`? |
| `c.is_upper` | це велика літера? |
| `c.is_lower` | це мала літера? |

Кожен із них повертає `true` або `false`.

```sather
'M'.is_alpha      -- true
'7'.is_alpha      -- false
'7'.is_digit      -- true
```

## Зміна регістру

`.upper` дає велику літеру, а `.lower` - малу. Усе, що не є літерою,
повертається без змін.

```sather
'm'.upper         -- 'M'
'M'.lower         -- 'm'
'7'.upper         -- '7'
```

## Символи як числа

Кожен символ має число. `.int` дає його, а `.char` перетворює число назад
на символ.

```sather
'a'.int           -- 97
'b'.int           -- 98
98.char           -- 'b'
```

Точні числа рідко мають значення. Важливо те, що літери від `a` до `z`
йдуть по порядку і одна за одною, тож `'c'.int - 'a'.int` дорівнює 2,
тобто наскільки `c` віддалена від початку алфавіту. Саме завдяки цьому
й працює шифрувальне колесо.
