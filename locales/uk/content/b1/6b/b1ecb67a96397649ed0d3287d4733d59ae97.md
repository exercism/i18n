# Додаток до інструкцій

## Слова

- `tick ( matrix cols -- matrix' )` - просуває сітку на одне покоління вперед і повертає нову сітку.

Кожен рядок сітки представлено як 64-бітне ціле число; `cols` - це кількість стовпців (не більше 64). Наприклад,

```
    0 1 0
    1 0 0
    1 1 0
```

представлено як

```
0b010
0b100
0b110
```
