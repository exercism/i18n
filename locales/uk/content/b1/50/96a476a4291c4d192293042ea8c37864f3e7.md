# Вказівки

У цій вправі ми будемо писати код, який аналізує конвеєр на автомобільному заводі.

## 1. Обчислити кількість робочих машин, виготовлених за годину

Реалізуйте функцію, яка приймає кількість машин, виготовлених за годину, і рівень успішності та обчислює кількість успішно виготовлених машин за годину. Рівень успішності задано у відсотках, від `0` до `100`:

```lua
cars.calculate_working_cars_per_hour(1547, 90)
--> => 1392.3
```

**Примітка:** повернене значення має бути числом з плаваючою комою.

## 2. Обчислити кількість робочих машин, виготовлених за хвилину

Реалізуйте функцію, яка приймає кількість машин, виготовлених за годину, і рівень успішності та обчислює, скільки машин успішно виготовляється щохвилини:

```lua
cars.calculate_working_cars_per_minute(1105, 90)
-- => 16
```

**Примітка:** повернене значення має бути цілим числом.

## 3. Обчислити вартість виробництва 

Кожна машина зазвичай коштує $10.000, якщо виробляти її окремо, незалежно від того, успішна вона чи ні. Але трохи спланувавши, можна виробити 10 машин разом за $95.000. Наприклад, 37 машин можна виробити так:
37 = 3 x груп по десять + 7 окремих машин

Отже, вартість 37 машин така:
3 \* 95,.000 + 7 \* 10.000 = 355.000

Реалізуйте функцію, яка обчислює вартість виробництва певної кількості машин, незалежно від того, успішні вони чи ні:

```lua
cars.calculate_cost(37)
-- => 355000

cars.calculate_cost(21)
-- => 200000
```

**Примітка:** повернене значення має бути цілим числом.
