# Підказки

## Загальне

- Кожне слово для читання й запису міститься в [`io.files`][io.files]; кодування
  `utf8`, яке вони всі приймають, походить із [`io.encodings.utf8`][utf8].

## 1. Прочитати кожне показання

- `file-lines` повертає масив рядків без символів нового рядка.

## 2. Знайти найновіше показання

- Прочитаймо рядки за допомогою `file-lines`, а потім візьмімо `last` (із
  `sequences`).

## 3. Прочитати необроблений журнал

- `file-contents` повертає файл як один рядок тексту (англ. string), разом з
  усіма символами нового рядка.

## 4. Записати показання

- Відкриймо файл у режимі дописування і виведімо показання всередині quotation
  за допомогою `print`:
  `with-file-appender ( path encoding quot -- )`. Показання використовується
  всередині quotation, а шлях споживається перед ним, тому локальні змінні `::`
  зберігають тіло читабельним:
  `:: record-reading ( reading path -- ) path utf8 [ reading print ]
  with-file-appender ;`.

## 5. Переписати журнал

- `set-file-lines` записує кожен елемент послідовності в окремому рядку,
  додаючи символи нового рядка за нас.

[utf8]: https://docs.factorcode.org/content/vocab-io.encodings.utf8.html
