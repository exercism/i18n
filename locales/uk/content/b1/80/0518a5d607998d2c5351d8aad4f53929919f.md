# Інструкції

Ліллі, прибулець із Ліспу, точно приготувала багато лазаньї з нашою допомогою. Вона хоче подякувати нам, віддавши трохи залишків. Але спершу в неї є кілька зауважень про одну з функцій, з якою ми їй допомогли.

У цій вправі ми напишемо ще кілька функцій, щоб допомогти Ліллі готувати лазанью, а також поділити з нами залишки.

На нас чекає шість завдань: три про вдосконалення наявних функцій для приготування лазаньї та три про поділ залишків.

## 1. Зробімо `preparation-time-in-minutes` зручнішою у використанні

Ліллі каже, що користуватися нашою `preparation-time-in-minutes` було трохи незручно, бо перед викликом функції доводилося перелічувати всі шари. Ліллі цікавиться, чи не могли б ми зробити версію функції, яка приймає шари (будь-яку їхню кількість) як аргументи, а потім обчислює час підготовки залежно від того, скільки було шарів. Нагадаємо: на підготовку одного шару потрібно 19 хвилин.

```lisp
(preparation-time 'sauce 'cheese 'right-handed-macaroni 'cheese 'sauce
                  'left-handed-macaroni 'sauce 'sauce 'cheese 'cheese)
                  ;; => 190 (because there are 10 layers.)
```

## 2. Дозвольмо змінювати очікуваний час у печі

Хоча батьківські одиниці Ліллі завжди запікали свою лазанью 337 хвилин, Ліллі визнає, що інші прибульці з Ліспу люблять запікати свою лазанью довше або коротше.

Тож було б добре, якби `remaining-minutes-in-oven` не використовувала `expected-minutes-in-oven`, а натомість могла приймати _необовʼязковий_ параметр, який визначає, чи має час бути довшим, дуже довгим, коротшим або дуже коротким. Довший або коротший означає додати або відняти 100 від типового часу 337. Дуже довгий або дуже короткий означає додати або відняти 200. Якщо параметр не передано або аргумент дорівнює «normal», то має повертатися типове значення 337.

```lisp
(remaining-minutes-in-oven)             ;; => 337
(remaining-minutes-in-oven :normal)     ;; => 337
(remaining-minutes-in-oven :shorter)    ;; => 237
(remaining-minutes-in-oven :very-short) ;; => 137
(remaining-minutes-in-oven :longer)     ;; => 437
(remaining-minutes-in-oven :very-long)  ;; => 537
```

## 3. Ліллі згадує ще один улюблений стиль приготування

Щойно ми завершили цю зміну, Ліллі згадує, що є прибульці з Ліспу, які люблять _дуже короткий_ час приготування. По суті, вони хочуть, щоб вона була сирою. Тож тепер функція має повертати 0, якщо аргументом було `NIL`, а також ті самі значення, що й у попередньому завданні.

```lisp
(remaining-minutes-in-oven)     ;; => 337
(remaining-minutes-in-oven nil) ;; => 0
```

## 4. Поділ залишків

Тепер, коли ми допомогли вдосконалити функції для приготування лазаньї, маємо _багато лазаньї_! Ліллі хоче віддячити нам за всю допомогу, поділивши з нами залишки. Нам потрібно буде написати функцію, яка приймає три параметри: загальну кількість залишків, кількість контейнерів для залишків, які Ліллі знайшла у своїх шафах, і таку саму кількість для нас. Оскільки пошук контейнерів для залишків може тривати різний час, а точна кількість залишків може зʼясуватися, поки ми з Ліллі шукаємо у своїх шафах, ми домовляємося, що функція має приймати аргументи в будь-якому порядку, тож коли чергове число визначено, ми можемо його записати. Коли в нас є всі три числа, достатньо просто закрити дужку у виклику функції й обчислити його.

Функція має повертати кількість залишків, які залишилися, тобто різницю між вагою залишків і загальною кількістю контейнерів, які знайшли ми з Ліллі.

```lisp
(split-leftovers :weight 20 :human 10 :alien 5) ;; => 5
(split-leftovers :weight 20 :alien 10 :human 2) ;; => 8
(split-leftovers :alien 12 :weight 20 :human 4) ;; => 4
```

## 5. Робимо припущення

Після кількох походів туди й назад до наших відповідних шаф ми з Ліллі погоджуємося, що було б чудово, якби функція могла просто _припускати_, що в нас або в Ліллі є... скажімо, 10 контейнерів, якщо їх не вказано.

```lisp
(split-leftovers :weight 20 :human 5) ;; => 5
(split-leftovers :weight 20 :alien 5) ;; => 5
(split-leftovers :weight 20)          ;; => 0
```

## 6. Стандартна кількість залишків

Ще краще: функція могла б _припускати_, що залишків достатньо, щоб уміститися в контейнери. Тож якщо вагу не вказано, функція має повертати `:just-split-it`. _Однак_ якщо вагу вказано і вона дорівнює `nil`, то функція має повертати `:looks-like-someone-was-hungry`.

```lisp
(split-leftovers :human 5 :alien 5) ;; => :JUST-SPLIT-IT
(split-leftovers :weight NIL :human 5 :alien 5) ;; => :LOOKS-LIKE-SOMEONE-WAS-HUNGRY
```
