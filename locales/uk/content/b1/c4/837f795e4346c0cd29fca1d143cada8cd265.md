# Вступ

## Цілі числа

У Gleam є два різні види чисел: цілі числа та числа з плаваючою комою.

Цілі числа не мають дробової частини.

```gleam
let integer = 3
// -> 3
```

У Gleam є кілька операторів для роботи з цілими числами.

```gleam
1 + 1 // -> 2
5 - 1 // -> 4
5 / 2 // -> 2
3 * 3 // -> 9
5 % 2 // -> 1

2 > 1  // -> True
2 < 1  // -> False
2 >= 1 // -> True
2 <= 1 // -> False
```

## Числа з плаваючою комою

Числа з плаваючою комою мають одну або більше цифр після десяткового розділювача.

```gleam
let float = 3.45
// -> 3.45
```

Для чисел з плаваючою комою теж є власний набір операторів.

```gleam
1.0 +. 1.4 // -> 2.4
5.0 -. 1.5 // -> 3.5
5.0 /. 2.0 // -> 2.5
3.0 *. 3.1 // -> 9.3

2.0 >. 1.0  // -> True
2.0 <. 1.0  // -> False
2.0 >=. 1.0 // -> True
2.0 <=. 1.0 // -> False
```

## Модулі

### Модулі

Код Gleam організовано в модулі, і кожен файл є одним модулем Gleam.

Досі ми писали функції із синтаксисом `pub fn`, який визначає функцію, загальнодоступну для інших модулів. Функції, визначені через `fn`, є приватними для модуля, у якому їх визначено, і не можуть використовуватися іншими модулями.

```gleam
// This function is public
pub fn add(x, y) {
  x + y
}

// This function is private
fn subtract(x, y) {
  x - y
}
```

Модулі Gleam мають назви, і назва походить від шляху до файлу в каталозі `src` або `test`.

Наприклад, модуль, визначений у `src\geometry\rectangle.gleam` (у Windows) або `src/geometry/rectangle.gleam` (у UNIX-подібних операційних системах), матиме назву `geometry/rectangle`.

### Імпорт функцій з інших модулів

Доступ до функцій, визначених в інших модулях, відбувається через імпорт.
Усі функції, які цей модуль надає, стають доступними, коли ми імпортуємо цей модуль.
Але спосіб доступу до них залежить від того, як імпортовано модуль.

Кваліфікований імпорт є типовим, і доступ до функції в такому модулі (наприклад, до функції `map` у модулі `gleam/list`) відбувається через додавання назви модуля як префікса (`list.map`).

```gleam
// Import the int module
import gleam/int

pub fn run(x: Int) -> String {
  // Use the to_string function from the int module
  int.to_string(x)
}
```

Типово для звернення до модуля використовується остання частина його назви, у цьому випадку `int`, але це можна змінити за допомогою ключового слова `as`.

```gleam
// Import the int module and refer to it as i
import gleam/int as i

pub fn run(x: Int) -> String {
  i.to_string(x)
}
```

Некваліфікований імпорт дає прямий доступ до наданих функцій цього модуля без префікса.

```gleam
// Import the to_string function from the int module
import gleam/int.{to_string}

pub fn run(x: Int) -> String {
  to_string(x)
}
```

Кваліфікований імпорт кращий, бо він ясніше показує читачеві, звідки походить функція, і допомагає уникати збігу назв.


### Стандартна бібліотека

Gleam має багату й добре задокументовану стандартну бібліотеку. Документація доступна онлайн на [hexdocs.pm/gleam_stdlib][docs]. Збережіть це посилання десь, воно нам дуже знадобиться!

Більшість вбудованих типів даних має відповідний модуль із функціями для роботи з цим типом даних, наприклад, є модуль `gleam/int` для цілих чисел, модуль `gleam/string` для рядків тексту (англ. string), модуль `gleam/list` для масивів тощо.

[docs]: https://hexdocs.pm/gleam_stdlib/
