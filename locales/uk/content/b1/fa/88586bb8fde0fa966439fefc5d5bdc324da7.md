# Конкатенація рядків

Конкатенація рядків тексту (англ. string) цілком припустима в Crystal, але скласти рядок тексту частіше вдається за допомогою [інтерполяції рядків][interpolation].
Наприклад:

```crystal
# Rather than:
"One for " + name_variable + ", one for me"

# Consider:
"One for #{name_variable}, one for me."
```

[interpolation]: https://crystal-lang.org/reference/latest/syntax_and_semantics/literals/string.html#interpolation
