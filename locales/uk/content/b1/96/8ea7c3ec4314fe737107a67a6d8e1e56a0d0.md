# Вступ

Ця вправа продовжує те, що ми бачили у вправі [Спостерігач за птахами у дворі][backyard-birdwatcher], і знайомить зі словами вищого порядку, які приймають *quotation* (фрагмент коду в дужках `[ ]`), щоб керувати виконанням операції.

## Quotation як значення

Quotation - це просто буквальний фрагмент коду. Його можна передати як дані іншому слову:

```factor
{ 1 2 3 4 5 } [ 2 > ] count .   ! => 3
```

Тут `[ 2 > ]` - це quotation, який приймає число й залишає булеве значення (англ. Boolean). `count` запускає його для кожного елемента й підраховує правдиві результати.

## Фільтрування та відкидання

```
find      ( seq quot    -- i/f elt/f ) ! first match: index and element, or f f
find-last ( seq quot    -- i/f elt/f ) ! same, but searches from the end
filter    ( seq quot    -- newseq )    ! keep elements where quot is truthy
reject    ( seq quot    -- newseq )    ! drop them instead
without   ( seq exclude -- newseq )    ! drop every element that's in `exclude`
sift      ( seq         -- newseq )    ! drop every `f`, keep the rest
```

```factor
{ 1 2 3 4 5 } [ 3 > ] find .s
! => 3            (index)
! => 4            (element)
{ 1 2 3 4 5 } [ 3 > ] find-last .s
! => 4            (index)
! => 5            (element)
{ 1 2 3 4 5 } [ even? ] filter .    ! => { 2 4 }
{ 1 2 3 4 5 } [ even? ] reject .    ! => { 1 3 5 }
"hello world" " ld" without .       ! => "heowor"
{ 1 f 2 f 3 } sift .                ! => { 1 2 3 }
```

`without` розглядає свій другий аргумент як множину: будь-який елемент `seq`, який `=` *будь-якому* елементу `exclude`, відкидається. `sift` - це окремий випадок `reject` без quotation: він зберігає кожен елемент, крім `f`, що стане в пригоді, коли треба прибрати прогалини, які залишив попередній `map`.

### Збереження результату перевірки

`find` повертає відповідний *елемент*. Коли перевірка вже *обчислює* значення, яке нам насправді потрібне, `map-find` позбавляє нас другого проходу: він запускає quotation для кожного елемента й повертає перший результат, відмінний від `f`, **і** елемент, який його дав.

```
map-find ( seq quot: ( elt -- result/f ) -- result elt )
```

```factor
USING: kernel math sequences ;

! First multiple of 3, paired with that multiple divided by 3.
{ 11 13 15 17 } [ dup 3 mod 0 = [ 3 /i ] [ drop f ] if ] map-find .s
! => 5            (result: 15/3)
! => 15           (element)
```

Quotation повертає `f` для елементів, які не підходять, і результат, який треба зберегти, для того, який підходить. Якщо не підходить ніщо, `map-find` залишає `f f`, так само як `find`.

### Фільтрування записів за слотом

Коли елементи - це *кортежі*, предикат зазвичай дістає слот через автоматично згенерований метод доступу `slot>>` і перевіряє вже його:

```factor
USING: accessors sequences ;

TUPLE: customer name vip? ;

{
    T{ customer { name "Alice" } { vip? t } }
    T{ customer { name "Bob"   } { vip? f } }
    T{ customer { name "Carol" } { vip? t } }
}
[ vip?>> ] filter [ name>> ] map .
! => { "Alice" "Carol" }
```

## Передавання фіксованого значення через `with`

Іноді предикатові потрібне значення, однакове для кожного виклику: поріг, дільник, цільовий рядок тексту (англ. string). `with` (із [`kernel`][kernel]) вбудовує це фіксоване значення в quotation, перетворюючи quotation із двома аргументами `( value elt -- ? )` на quotation з одним аргументом, який приймають `filter`, `count`, `map` та `each`:

```
with ( value seq quot -- seq curry )
```

Кожен виклик для окремого елемента бачить у стеку `( value elt )`: спочатку фіксоване значення, потім поточний елемент:

```factor
USING: kernel sequences ;

! Count elements greater than 5 — value=5 is threaded in
5 { 2 7 4 9 1 8 } [ < ] with count .   ! => 3
```

## Відображення та перебирання

`map` (із [`sequences`][sequences]) застосовує quotation до кожного елемента й повертає масив результатів. `each` виконує той самий обхід, але відкидає результати, що стане в пригоді, коли quotation потрібен лише заради побічних ефектів. `2map` проходить *дві* послідовності синхронно й поєднує відповідні елементи; `2each` і `2reduce` - його родичі для самих лише побічних ефектів і для згортання; `zip` - це короткий запис для «зʼєднати їх у пари, не комбінуючи»:

```
map     ( seq       quot           -- newseq )
map-as  ( seq       quot exemplar  -- newseq )
each    ( seq       quot           -- )
2map    ( seq1 seq2 quot           -- newseq )
2each   ( seq1 seq2 quot           -- )
2reduce ( seq1 seq2 identity quot  -- result )
zip     ( seq1 seq2                -- pairs )
```

`2reduce` протягує акумулятор одночасно через обидві послідовності. Його quotation приймає `( accumulator elt1 elt2 -- accumulator' )`. Тут він накопичує скалярний добуток: кожну пару перемножують, а добутки додають (`1*10 + 2*20 + 3*30`):

```factor
{ 1 2 3 } { 10 20 30 } 0 [ * + ] 2reduce .   ! => 140
```

`map-as` - це родич `map`, який задає тип вихідної послідовності примусово: передаємо порожній `{ }` або `V{ }` як зразок, щоб перевизначити типовий тип вхідних даних (інакше відображення рядка тексту на не-символи дасть помилку, коли Factor спробує запакувати результати назад у рядок тексту).

```factor
USING: formatting math sequences ;

{ 1 2 3 } [ sq ] map .                         ! => { 1 4 9 }
{ 1 2 3 } [ . ] each                           ! prints 1, then 2, then 3
{ 1 2 3 } { 10 20 30 } [ + ] 2map .            ! => { 11 22 33 }
{ "x" "y" } { 1 2 } [ "%s%d" sprintf ] 2map .  ! => { "x1" "y2" }
{ 1 2 3 } { 10 20 30 } [ + . ] 2each           ! prints 11, then 22, then 33
{ "a" "b" "c" } { 1 2 3 } zip .                ! => { { "a" 1 } { "b" 2 } { "c" 3 } }
```

Обидві форми з двома послідовностями зупиняються на довжині коротшої з них. `zip` - те саме, що `[ 2array ] 2map`: зберігає пари, а не згортає їх.

## Сортування

`sort` повертає відсортовану копію в природному порядку; `sort-by` (із [`sorting`][sorting]) сортує за ключем, добутим із кожного елемента:

```
sort    ( seq      -- sortedseq )
sort-by ( seq quot -- sortedseq )
```

```factor
{ 3 1 4 1 5 9 2 6 } sort .
! => { 1 1 2 3 4 5 6 9 }

{ -3 5 -1 4 } [ abs ] sort-by .
! => { -1 -3 4 5 }
```

## Агрегування

`map-sum` (із [`sequences`][sequences]) застосовує quotation до всієї послідовності й додає результати за один прохід:

```
map-sum ( seq quot -- n )
```

```factor
{ 1 2 3 4 } [ sq ] map-sum .   ! => 30
```

## Мінімум і максимум

`minimum` і `maximum` одразу повертають найменший або найбільший елемент послідовності. `minimum-by` і `maximum-by` (усі з [`sequences`][sequences]) повертають елемент, чий добутий ключ найменший або найбільший:

```
minimum     ( seq      -- elt )
maximum     ( seq      -- elt )
minimum-by  ( seq quot -- elt )
maximum-by  ( seq quot -- elt )
```

```factor
{ 3 1 4 1 5 9 2 6 } minimum .       ! => 1
{ 3 1 4 1 5 9 2 6 } maximum .       ! => 9

{ -3 5 -1 4 } [ abs ] minimum-by .
! => -1
```

## Як написати власне слово вищого порядку

Коли *наше* слово приймає quotation як аргумент під час виконання й передає його далі в `map`, `filter`, `each` тощо, треба оголосити його з `; inline`. Це вказує компіляторові вбудувати наше слово в кожному місці виклику, де quotation є відомим літералом. Без цього компілятор не має способу дізнатися стековий ефект quotation.

```factor
USING: math sequences ;

: tax-on ( inventory quot -- total )
    map-sum ; inline

{ { "shirt" 20 } { "hat" 15 } } [ second 1/10 * ] tax-on .
! => 3+1/2
```

Словам, побудованим лише з літеральних quotation, `inline` не потрібен, лише тим, які передають далі *вхідний* quotation.

Якщо таке `inline`-слово колись викликає *саме себе* (рекурсивний комбінатор), оголошуємо його як `; inline recursive`. Без цього додаткового слова компілятор зупиняється з повідомленням *«The inline recursive word ... must be declared recursive»*, яке точно підказує, що додати.

## Витягування другого елемента

Для масиву з 2 елементів `second` повертає його другий елемент. `first` повертає перший. Обидва є в [`sequences`][sequences].

## Числа в рядки тексту

`number>string ( n -- str )` (із [`math.parser`][math.parser]) перетворює число на його десятковий рядок тексту:

```factor
42 number>string .     ! => "42"
3.5 number>string .    ! => "3.5"
```
