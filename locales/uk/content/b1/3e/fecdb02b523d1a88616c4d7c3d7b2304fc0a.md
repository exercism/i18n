# Вступ

Робота з двійковими даними - важлива концепція в будь-якій мові, і Elixir дає елегантний синтаксис для запису, зіставлення та конструювання двійкових даних.

В Elixir двійкові дані називають типом «бітовий рядок». _Тип_ двійкових даних (не плутати з двійковими даними загалом) - це окремий різновид бітового рядка, який ми розглянемо в одній із наступних вправ.

Літерали бітових рядків визначаються за допомогою спеціальної форми `<<>>`. Коли ми визначаємо літерал бітового рядка, він складається з сегментів. Кожен сегмент має значення і тип, розділені оператором `::`. Тип визначає, скільки бітів буде використано для кодування значення. Тип можна не вказувати зовсім, і тоді типовим значенням буде 8-бітове ціле число.

```elixir
# This defines a bitstring with three segments of a single bit each
<<0::1, 1::1, 0::1>>
```

Запис типу як `::1` - це скорочення для `::size(1)`. Довший синтаксис потрібно використовувати, якщо розмір у бітах береться зі змінної.

## Двійкові літерали

Записуючи двійкові цілі літерали, ми можемо записати їх прямо в двійковій системі числення, поставивши перед літералом префікс `0b`. Зауважмо, що вони все одно відображаються як десяткові числа в результатах тестів або під час роботи з iex.

```elixir
<<0b1011::4>> == <<11::4>>
# => true
```

## Обрізання

Якщо значення сегмента перевищує місткість типу цього сегмента, його буде обрізано зліва.

```elixir
<<0b1011::3>> == <<0b0011::3>>
# => true
```

## Додавання на початок і в кінець

Ми можемо додавати дані як на початок, так і в кінець наявного бітового рядка за допомогою спеціальної форми. Тип `::bitstring` потрібно вказати для наявного бітового рядка, якщо його розмір невідомий.

```elixir
value = <<0b110::3, 0b001::3>>
new_value = <<0b011::3, value::bitstring, 0b000::3>>
# => <<120, 8::size(4)>>
```

## Конкатенація

Ми можемо зʼєднувати бітові рядки, збережені у змінних, за допомогою спеціальної форми. Тип `::bitstring` потрібно використовувати, коли ми зʼєднуємо два бітові рядки невідомого розміру.

```elixir
first = <<0b110::3>>
second = <<0b001::3>>
concatenated = <<first::bitstring, second::bitstring>>
# => <<49::size(6)>>
```

## Зіставлення зі зразком

За допомогою зіставлення зі зразком також можна отримати значення зі спеціальної форми. Потрібно знати кількість бітів для кожного фрагмента, який ми хочемо отримати, з одним винятком: тип `::bitstring` можна використати для зіставлення зі зразком для бітового рядка невідомого розміру, але це працює лише для останнього фрагмента.

```elixir
<<value::4, rest::bitstring>> = <<0b01101001::8>>
value == 0b0110
# => true
```

## Відображення бітових рядків

~~~~exercism/note
Бітові рядки можуть друкуватися (під час запуску тестів або в iex) у форматі, відмінному від того, у якому їх створили. Це часто спантеличує, коли ми вивчаємо бітові рядки.
~~~~

Типово бітові рядки відображаються фрагментами по 8 бітів (байт), навіть якщо ми створили їх із фрагментів іншого розміру.

```elixir
<<2011::11>>
# => <<251, 3::size(3)>>
```

Якщо ми створюємо бітовий рядок, який представляє друкований рядок тексту (англ. string) у кодуванні UTF-8, він відображається як рядок тексту.

```elixir
<<>>
# => ""

<<65, 66, 67>>
# => "ABC"
```
