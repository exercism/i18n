# Докладніше

[Рядки тексту (англ. string)][strings] у Haxe - це незмінні обʼєкти, що представляють текст як послідовність символів Unicode (літер, цифр, розділових знаків тощо). Подвійні лапки використовуються для визначення екземпляра `string`:

```haxe
var fruit:String = "Apple";
```

З рядком тексту можна працювати, викликавши один із його [методів або властивостей][string-api]. Оскільки значення рядків тексту ніколи не змінюються після визначення, усі методи роботи з рядками тексту повертають новий рядок тексту.

Рядок тексту обмежується символами подвійних лапок (`"`). Деякі спеціальні символи потребують [екранування][escaping] за допомогою символу зворотної скісної риски (`\`). Крім того, рядки тексту в Haxe можуть бути багаторядковими, що дозволяє легко створювати довгі рядкові літерали:

```haxe
var escaped:String = "c:\\test.txt";
var multiline:String = "
- apple
- pear
- banana";
```

Найпростіший спосіб зʼєднати рядки тексту - використати [оператор `+`][plus-operator].

```haxe
var name:String = "Jane";
trace("Hello " + name + "!");
// => "Hello Jane!"
```

Для складнішого форматування рядків тексту краще використовувати [інтерполяцію рядків тексту][interpolation]. Для цього рядок тексту беруть в одинарні лапки (`'`) і використовують знак долара (`$`), щоб запустити інтерполяцію змінних. Також можна обчислювати цілі вирази за допомогою `${expr}`, де `expr` може бути будь-яким дійсним виразом Haxe:

```haxe
var name:String = "Jane";
trace('Hello $name!');
// => "Hello Jane!"
trace('HELLO ${name.toUpperCase()}!');
// => "HELLO JANE!"
```
