# Інструкції

У цій вправі ми допоможемо закоханим старшокласникам зізнатися в коханні в соцмережах. Для цього ми згенеруємо з їхніх ініціалів серце з юнікод-символів:

```
❤ J.  +  M. ❤
```

## 1. Очищення імені

Реалізуйте метод `cleanupname`.
Він має приймати імʼя, видаляти з нього всі символи `-` і замінювати їх пробілом.
Також він має прибирати всі пробільні символи на початку й у кінці імені.

```julia-repl
julia> cleanupname("Jane-Ann")
"Jane Ann"
```

## 2. Перша літера імені

Реалізуйте метод `firstletter`.
Він має приймати імʼя й повертати його першу літеру як рядок тексту (англ. string).
Обовʼязково повторно використайте `cleanupname`, який ми визначили на попередньому кроці, і поєднайте його з іншими функціями.

```julia-repl
julia> firstletter("Jane")
"J"
```

## 3. Перша літера як ініціал

Реалізуйте метод `initial`.
Він має приймати імʼя й повертати його першу літеру у верхньому регістрі, після якої стоїть крапка.
Обовʼязково повторно використайте `firstletter`, який ми визначили на попередньому кроці.

```julia-repl
initial("Robert")
"R."
```

## 4. Ініціали всередині серця

Реалізуйте метод `couple`.
Він має приймати два імені й повертати ініціали, оточені сердечками-емодзі.
Обовʼязково повторно використайте `initial`, який ми визначили на попередньому кроці.

```julia-repl
couple("Blake Miller", "Riley Lewis")
"❤ B.  +  R. ❤"
```
