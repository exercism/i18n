# Debug

Коли тест не проходить, відображається повідомлення, яке описує, що пішло не так і для яких вхідних даних.
Ми можемо переглядати довільні значення у своїй програмі, передаючи їх методу `debug` (доступний у `exercism/test_runner`).
Це зафіксує значення і покаже вихідні дані.


```gleam
import exercism/test_runner.{ debug }

let value: String = "test"
debug("The value is " <> value)
```
