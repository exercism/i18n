# Створено зайву змінну для імені

Створювати зайву змінну для зберігання імені не потрібно, адже Go не передає змінні за посиланням. Присвоєння нового значення змінній `name` не змінить значення за межами області видимості функції `ShareWith`. Оскільки Go не дає змоги задавати типові значення для параметрів функції, у Go часто просто присвоюють значення ще раз, щоб задати типове.
