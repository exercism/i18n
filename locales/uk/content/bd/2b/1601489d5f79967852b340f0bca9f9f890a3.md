# Вступ

Тип `Result` дає змогу функції повернути одне значення, яке вказує на все з переліченого нижче:

- Чи операція завершилася успішно, чи зазнала невдачі
- У разі успіху: значення, отримане внаслідок операції
- У разі невдачі: причина невдачі

## Використання

`Result` є узагальненим типом, який містить два внутрішні типи:

- Тип значення, отриманого в разі успішної операції
- Тип, який у разі невдачі описує її причину

Тип `Result` також є [розрізнюваним обʼєднанням][discriminated-union] із такими можливими варіантами:

- `Ok <value>` представляє успішний результат
- `Error <reason>` представляє невдачу

Ця функція демонструє, як створити значення `Result`:

```fsharp
let validateName (name: string) : Result<string, string> =
    match name with
    | null -> Error "Name not found."
    | "" -> Error "Name is empty."
    | _ -> Ok name
```

У цьому прикладі значення `Ok` є рядком тексту (англ. string), у якому записано передане імʼя, а значення `Error` теж є рядком тексту, у якому записано причину помилки у формі, зрозумілій людині.

## Читання вмісту значення `Result`

Розглянемо таке визначення типу та сигнатуру функції:

```
type FileOpenError =
| NotFound
| AccessDenied
| FileLocked

let openFile (filename: string) : Result<int, FileOpenError> =
```

Код, який викликає функцію `openFile`, може використати зіставлення зі зразком, щоб опрацювати випадки успіху й невдачі, як у наступному прикладі:

```fsharp
match openFile(filename) with
| Ok handle -> doSomethingWithFile(handle)
| Error NotFound -> printfn $"Error: file {filename} was not found."
| Error AccessDenied -> printfn $"Error: you do not have permission to open the file {filename}."
| Error FileLocked -> printfn $"Error: file {filename} is already in use."
```
