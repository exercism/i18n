# Доповнення до інструкцій

## Створімо власний DSL

У цій вправі ми цілком вільні спроєктувати графовий DSL своєї мрії.

Тести вимагають лише створити кілька конкретних графів, а як ми їх будуємо, цілком залежить від нас.

Щоб подвоїти задоволення, можемо за бажанням спробувати реалізувати функцію `to_dot`, яка перетворює наш граф на формат DOT!

## Представлення графа

Визначмо свій DSL у файлі `Graph.roc`, а потім скористаймося ним, щоб побудувати графи, які вимагає заглушка.
Два ідентифікатори вузлів у кожному `EdgeId` мають бути впорядковані за алфавітом.

| Визначення | Граф для побудови |
| --- | --- |
| `empty_graph` | Порожній граф |
| `graph_with_one_node` | Один вузол |
| `graph_with_one_node_with_attribute` | Один вузол з атрибутом |
| `graph_with_one_edge` | Одне ребро |
| `graph_with_one_attribute` | Один атрибут графа |
| `graph_with_nodes_edges_and_attributes` | Вузли, ребра й атрибути |
| `multiple_edges_on_one_line` | Кілька ребер, записаних в одному рядку |
| `only_1_edge_between_nodes` | Лише одне ребро між кожною парою вузлів |
