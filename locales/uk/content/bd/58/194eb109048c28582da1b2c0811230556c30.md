# Вступ

_Рядок тексту_ (англ. string) - це тип даних у JavaScript для зберігання текстових даних.

## Створення рядка тексту

Щоб створити рядок тексту, беремо текст в одинарні або подвійні лапки.
На Exercism прийнято використовувати одинарні лапки.

<!-- prettier-ignore-start -->
```javascript
'Hello, World!'
"Hello, World!"
```
<!-- prettier-ignore-end -->

## Рядки тексту як масиви символів

Рядок тексту можна розглядати як масив символів, де перший символ має індекс `0`.
Дістати окремий символ рядка тексту можна за допомогою квадратних дужок та індексу потрібної літери.

```javascript
'cat'[1];
// => 'a'
```

Кількість символів у рядку тексту можна визначити, звернувшись до властивості `length`.

```javascript
'cat'.length;
// => 3
```

## Конкатенація та методи

Найпростіший спосіб зʼєднати рядки тексту - скористатися оператором додавання `+`.

```javascript
'I like' + ' ' + 'cats.';
// => "I like cats."
```

Рядки тексту мають багато допоміжних методів; повний список наведено в [документації MDN щодо методів рядків][mdn-string-methods].
Нижче наведено кілька найуживаніших допоміжних методів.

- [`toUpperCase`][mdn-to-upper-case] і [`toLowerCase`][mdn-to-lower-case] - змінюють регістр усіх символів
- [`trim`][mdn-trim] - прибирає пробіли на початку й у кінці
- [`includes`][mdn-includes], [`startsWith`][mdn-starts-with] і [`endsWith`][mdn-ends-with] - визначають, чи є інший рядок тексту частиною заданого
- [`slice`][mdn-slice] - вибирає частину рядка тексту

Рядки тексту в JavaScript незмінні. Тому будь-яка «модифікація», наприклад, за допомогою деяких із наведених вище методів, завжди створює новий рядок тексту.
