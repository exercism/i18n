# Вступ

## Початок роботи

### Змінні

Ми можемо зберігати значення й давати їм імена, визначивши [змінну][constants-variables].
Після визначення змінної ми можемо використовувати її імʼя, щоб посилатися на це значення в усьому коді.
Змінні _змінювані_, тобто їхні значення можна змінити після визначення.

Змінну визначають за допомогою ключового слова `var`:

```swift
var variableName = 10
```

Swift належить до мов зі статичною типізацією, що означає, що кожне значення має відомий тип під час компіляції.
Ми можемо або явно вказати тип за допомогою [анотацій типів][type annotations], або дозволити компілятору Swift [вивести тип][type-inferring] із присвоєного значення:

```swift
var explicitVar: Int = 10 // Explicitly typed
var implicitVar = 10      // Implicitly typed (inferred as Int)
```

Оновити значення змінної можна за допомогою оператора присвоєння (`=`):

~~~~exercism/note
Тип змінної не може змінитися після її оголошення.

```swift
variableName = 13 // Allowed: same type (Int)

// Compiler error: cannot assign a different type
variableName = "Hello, world!" // Cannot assign value of type 'String' to type 'Int'
```
~~~~

Змінну можна оголосити без початкового значення, вказавши її тип, але перед використанням їй потрібно присвоїти значення:

```swift
var someInt: Int

// This triggers a compiler error:
// print(someInt) // Variable 'someInt' used before being initialized

// Assign a value first
someInt = 169
print(someInt) // Prints 169
```

### Константи

[Константи][constants-variables] теж повʼязують імʼя зі значенням, але їхні значення не можна змінити після присвоєння.
Вони _незмінні_.
Константу визначають за допомогою ключового слова `let`:

```swift
let constantName = 10          // Inferred constant
let explicitConstant: Int = 10 // Explicitly typed constant
```

### Арифметичні оператори

Swift надає стандартні [арифметичні оператори][arithmetical-operators] для базових обчислень:

- Додавання: `+`
- Віднімання: `-`
- Множення: `*`

```swift
print(1 + 1) // Prints 2
print(2 - 1) // Prints 1
print(2 * 2) // Prints 4
```

### Функції

У Swift [функції][functions] - це самодостатні блоки коду, які виконують певне завдання.
Функції можуть приймати вхідні дані, повертати значення й передаватися як значення іншим функціям.
Функцію визначають за допомогою ключового слова `func`, після якого йде назва функції, список параметрів у дужках і необовʼязковий тип поверненого значення:

```swift
func functionName(argumentLabel parameterName: ParameterType) -> ReturnType {
    // Function body
}
```

Функції Swift використовують [мітки аргументів][argument-labels], завдяки чому код читається як звичайні речення:

- **Мітка аргументу** використовується під час виклику функції.
- **Імʼя параметра** використовується всередині тіла функції для доступу до значення.

Якщо вказати лише одне імʼя, Swift використає його і як мітку аргументу, і як імʼя параметра:

```swift
func greet(name: String) {
    print("Hello, \(name)!")
}

greet(name: "Alice")
```

Якщо ми не хочемо мітки аргументу під час виклику функції, пишемо підкреслення (`_`) перед іменем параметра:

```swift
func square(_ number: Int) -> Int {
    return number * number
}

square(5) // Called without an argument label
```

Усі параметри функції типово є константами (`let`), тобто їхні значення не можна змінити всередині тіла функції.

Щоб повернути значення з функції, вказуємо тип поверненого значення після `->` і використовуємо ключове слово `return`:

```swift
func addTen(to value: Int) -> Int {
    return value + 10
}

addTen(to: 10) // Returns 20
```

Коли функція не повертає значення, її тип поверненого значення - `Void` (що еквівалентно порожньому кортежу, `()`).
У таких функціях можна опустити і тип поверненого значення `-> Void`, і інструкцію `return`.

### Коментарі

Swift підтримує дві форми [коментарів][comments]:

- **Однорядкові коментарі** починаються з `//` і тривають до кінця рядка.
- **Багаторядкові коментарі** розміщують між `/*` і `*/`.

```swift
// This is a single-line comment

/* This is a comment
   that spans multiple lines */
```
