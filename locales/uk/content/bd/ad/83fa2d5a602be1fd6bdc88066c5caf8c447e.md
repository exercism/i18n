# Вступ

## Час життя ресурсу

[concept:csharp/resource-cleanup]() використовує інтерфейс `IDispose`, щоб позначити, що ресурс якогось обʼєкта або інший стан програми потрібно звільнити чи скинути, коли обʼєкт більше не потрібен (і що покладатися на збирач сміття не дасть цього результату чи потрібного рівня контролю), а також що метод `IDisposable.Dispose()` був природним місцем для таких операцій очищення.

Є й інша конструкція, блок `using`, яка дає змогу з погляду того, хто викликає код, зібрати все керування часом життя ресурсів в одну інструкцію.

```csharp
using (var file = new File("my_secrets"))
{
    file.WriteSecret("xxxxxxx");
}
```

У наведеному вище прикладі ресурси файлової системи, повʼязані з `file`, будуть звільнені й повернуті операційній системі, коли виконання виходить за межі блоку `using`.

Щоб ця конструкція працювала, змінна в інструкції `using` має бути посилального типу, який реалізує інтерфейс `IDisposable`, і має звільняти ресурси та скидати стан програми у своєму методі `Dispose()`.

C# 8 пропонує удосконалення цієї конструкції. Інструкцію `using` можна розмістити на початку блоку.

```csharp
using var drawingResource = some_provided_or_new_object;
try
{
    drawingResource.DrawSomething();
}
catch (Exception)
{
    throw;
}
```

Розробники Java можуть упізнати в цьому аналог механізму _автоматичного керування ресурсами_, запровадженого в Java 7.
