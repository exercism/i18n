# Докладніше

## Успадкування

Java підтримує успадкування як одну з основних можливостей, яке також використовується для реалізації багатьох принципів ООП, як-от абстракція.

Клас може розширювати інший клас за допомогою ключового слова `extends` і може успадковувати від інтерфейсу за допомогою ключового слова `implements`.

## Модифікатори доступу

Модифікатори доступу визначають правила для змінних-членів і методів класу щодо їхнього доступу з інших класів (або з будь-якого місця в коді).

Існує чотири модифікатори доступу:

- `private`
- `public`
- `protected`
- типовий (ключове слово не потрібне)

Про них можна прочитати більше [у цій статті][access-modifiers]

## Успадкування проти композиції

Ці концепції дуже схожі, й їх часто плутають.

- Успадкування означає, що дочірній клас має відношення IS-A з батьківським класом.

```java
interface Animal() {
    public void bark();
}

class Dog implements Animal {
    public void bark() {
        System.out.println("Bark");
    }
}
```

Тут `Dog` IS-A `Animal`

- Композиція представляє відношення HAS-A.

```java
interface Engine {

}

class Car {
    private Engine engine;
}
```

Тут `Car` HAS-A `Engine`
