# Додаток до інструкцій

## Переваги та недоліки `from_quote`

Функція `Time.from_quote` розбирає рядок тексту (англ. string) у форматі `"HH:MM:SS"` і повертає `Time`.
Завдяки цьому можна писати такий код:

```roc
time : Time
time = "00:01:23"
```

Цей код неявно викликає `Time.from_quote("00:01:23")` під час компіляції.
Це потенційно пришвидшує програму, оскільки їй не потрібно обробляти розбір під час виконання, а також гарантує, що час, який `from_quote` відхиляє, буде виявлено під час компіляції, а не під час виконання.
Крім того, код стає гарним і читабельним.
Наприклад, ось один із тестів у цій вправі:

```roc
## start initiates time tracking for current lap
expect {
	result = Stopwatch.create()
		.start()?
		.advance_time("00:00:05")
		|> expect_current_lap("00:00:05")

	result.is_ok()
}
```

Однак той, хто читає цей код, може припустити, що функція `advance_time` приймає `Str`, тоді як насправді вона приймає `Time`.
Це може призводити до плутанини та помилок.
Тому можна віддати перевагу трохи довшому, але явнішому формату: `"00:00:05".Time`, який також викликає `from_quote` під час компіляції.

У власних програмах можна натомість використати `from_str`:

```roc
Time := { ... }.{
    from_str : Str -> Try(Time, [InvalidTime])
    from_str = |time_str| ...
}
```

Також можна викликати `from_str` (або будь-яку іншу чисту функцію) під час компіляції, ось так:

```roc
Ok(time) = Time.from_str("00:01:23")
```

Примітка: якщо розмістити це визначення на верхньому рівні, воно буде виконуватися під час компіляції (оскільки функція чиста, а її вхідні дані відомі під час компіляції).
Усередині функції `from_str` можна використати під час виконання.

## Підказки

<details>
<summary>Показати підказки</summary>

Операції повертають оновлений секундомір, а не змінюють свій аргумент.
Такі оновлення запису, як `{ ..stopwatch, state: Running }`, зберігають інші поля.
`advance_time` отримує від тестів уже минулу тривалість, тож годинник чи платформні ефекти не потрібні.
Перш ніж виконувати арифметику, яка може вийти за межі діапазону `U8`, розширмо типи хвилин і секунд.

</details>
