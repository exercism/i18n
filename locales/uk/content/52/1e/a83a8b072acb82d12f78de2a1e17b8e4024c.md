# Тести

Запустіть тести за допомогою `exercism test` або `eutest`. Усі тести запускаються за замовчуванням.

## Пропуск тестів

Гарний спосіб почати - закоментувати всі тести, крім першого, у файлі `t_<exercise>.e`.

```euphoria
test_equal("no name given", "One for you, one for me.", two_fer())
-- test_equal("a name given", "One for Alice, one for me.", two_fer("Alice"))
-- test_equal("another name given", "One for Bob, one for me.", two_fer("Bob"))
```

Пропрацюймо їх по одному, розкоментовуючи наступний тест, щойно поточний пройде. Коли всі тести пройдуть, вправу виконано.
