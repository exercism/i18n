# Вказівки

У цій вправі ми писатимемо код, який допоможе фрилансеру спілкуватися з менеджером проєкту. Ми надамо кілька допоміжних функцій, щоб швидко розраховувати денні та місячні ставки, за потреби зі знижкою.

Спершу встановімо кілька правил між фрилансером і менеджером проєкту:

- Денна ставка у 8 разів більша за погодинну.
- У місяці 22 оплачувані робочі дні.

Іноді фрилансер пропонує застосувати знижку до своєї денної ставки (наприклад, для найвідданіших клієнтів або неприбуткових організацій).

Знижки подаються як дробові числа, що позначають відсотки, наприклад `25.0` (25%).

## 1. Обчислити денну ставку за погодинною ставкою

Реалізуйте функцію `dailyRateFrom`, щоб обчислити денну ставку, де погодинна ставка передається як параметр.
За домовленістю день має 8 оплачуваних годин.

```swift
dailyRateFrom(hourlyRate: 60)
// Returns 480.0
```

Повернена денна ставка має бути `Double`.

## 2. Обчислити місячну ставку за погодинною ставкою та знижкою

Реалізуйте функцію `monthlyRateFrom`, щоб обчислити місячну ставку зі знижкою.
Вона приймає два параметри: погодинну ставку та знижку у відсотках.


```swift
monthlyRateFrom(hourlyRate: 77, withDiscount: 10.5)
// Returns 12129
```

Повернену місячну ставку потрібно округлити вгору (взяти стелю) до найближчого цілого числа.

## 3. Обчислити кількість повних робочих днів за бюджетом, погодинною ставкою та знижкою

Реалізуйте функцію `workdaysIn`, яка приймає бюджет, погодинну ставку та знижку й обчислює, на скільки повних днів роботи цього вистачить.

```swift
workdaysIn(budget: 20000, hourlyRate: 80, withDiscount: 11.0)
// Returns 35.0
```
Повернену кількість днів потрібно округлити вниз (взяти підлогу) до найближчого цілого числа.
