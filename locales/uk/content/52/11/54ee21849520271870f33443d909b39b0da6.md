# Вступ

Цикли використовують, щоб багаторазово виконувати певну логіку.
Два найпоширеніші типи - це `while loop` (невизначене повторення) і `for loop` (визначене, або лічильне повторення).
Є також цикл `for each`, про який ітиметься в наступному концепті.


## Загальний синтаксис

`for loop` складається із заголовка та блоку коду, який містить тіло циклу, укладене у фігурні дужки.
Заголовок складається з 3 компонентів, розділених крапками з комою `;`: інструкції ініціалізації, умови та ще одного виразу.
Кожен із них може бути порожнім.

```cpp
for (init-statement; condition; expression) {
  some_statement;
}
```

- Компонент **init** - це код, який виконується лише один раз перед початком циклу.
- Компонент **condition** має бути виразом, який обчислюється як булеве значення (англ. Boolean) і керує тим, коли цикл має зупинитися.
Код усередині циклу виконуватиметься, доки ця умова обчислюється як правда.
Щойно цей вираз обчислиться як неправда, більше жодна ітерація циклу не виконається.
- Компонент **expression** - це код, який виконується в кінці кожної ітерації.


`while loop` виконує своє тіло, доки його перевірка умови повертає правду.
Наведений нижче фрагмент коду показує, як перетворити цикл for на цикл while.

```cpp
init-statement;
while(condition) {
    some_statement;
    expression;
}
```

## Вставка: інкременти та декременти

Працюючи з циклами, часто потрібно додати 1 або відняти 1 від змінної-лічильника.
Це настільки поширена операція, що для неї є спеціальні оператори: `++` і `--`.

Вони бувають у префіксній та постфіксній формах.
Префіксна форма змінює змінну до використання в інструкції, а постфіксна - після.
Здебільшого краще використовувати префіксну форму.

```cpp
int a{3};
int b{--a};
// b is 2, a is now 2
int c{a++};
// c is 2, a is now 3
```

## Цикли for - приклад

Компонент init зазвичай створює змінну-лічильник, компонент condition перевіряє, чи потрібно продовжувати чи зупиняти цикл, а компонент post зазвичай збільшує лічильник у кінці кожного повторення.

```cpp
int sum{0};
for (int i{1}; i < 10; ++i) {
  sum += i;
}
```

Цей цикл підсумує числа від `1` до `9` (включно з `9`).

## Break і continue

Усередині тіла циклу можна використати ключове слово `break`, щоб повністю зупинити виконання циклу:

```cpp
int sum{2};
while(true) {
    sum *= 2;
    if (sum > 1000)
        break;
}
// sum is now 1024
```

Натомість ключове слово `continue` зупиняє виконання лише поточної ітерації та переходить до наступної:

```cpp
int equal_sum{0};
for (int i{1}; i < 7; ++i) {
  if  (i%2 == 1) {
    continue;
  }
  equal_sum += i;
}
// equal_sum is now 12
```
> Примітка: зазвичай логіку циклу легше зрозуміти, коли використання `break` і `continue` зведено до мінімуму або їх повністю уникають.
