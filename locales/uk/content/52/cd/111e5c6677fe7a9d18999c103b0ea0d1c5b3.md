# Вступ

## Цикли

Цикли потрібні, щоб багаторазово виконувати одну й ту саму логіку.
Два найпоширеніші типи - це `while loop` (невизначене повторення) та `for loop` (визначене, або пораховане повторення).
Є також цикл `for each`, з яким ми познайомимося в одному з наступних концептів.

### Загальний синтаксис

`for loop` складається із заголовка та блоку коду, який містить тіло циклу, оточене фігурними дужками.
Заголовок складається з 3 компонентів, розділених крапками з комою `;`: інструкція ініціалізації, умова та ще один вираз.
Кожен із них може бути порожнім.

```cpp
for (init_statement; condition; expression) {
  some_statement;
}
```

- Компонент **інструкція ініціалізації** - це код, який виконується лише один раз перед початком циклу.
- Компонент **умова** має бути виразом, який обчислюється в значення `boolean` і визначає, коли цикл має зупинитися.
  Код усередині циклу виконуватиметься, доки ця умова обчислюється в `true`.
  Щойно цей вираз обчислиться в `false`, цикл більше не виконає жодної ітерації.
- Компонент **вираз** - це код, який виконується в кінці кожної ітерації.

`while loop` виконує своє тіло, доки перевірка його **умови** дорівнює `true`.
Наведений нижче фрагмент коду показує, як перетворити `for` на `while loop`.

```cpp
init_statement;
while(condition) {
    some_statement;
    expression;
}
```

### Невеликий відступ: інкремент і декремент

Працюючи з циклами, часто потрібно додати 1 або відняти 1 від змінної-лічильника, яка відстежує ітерації.
Це настільки поширена дія, що для інкременту та декременту є спеціальні оператори: `++` і `--`.

Вони бувають у **префіксній** та **постфіксній** формі.
Префіксна форма змінює змінну до її використання в інструкції, а постфіксна - після.
У більшості випадків нам, найімовірніше, знадобиться саме префіксна форма.

```cpp
int a{3};
int b{--a};
// b is 2, a is now 2
int c{a++};
// c is 2, a is now 3
```

### Цикли `for`: приклад

_Компонент ініціалізації_ зазвичай задає змінну-лічильник, _умова_ перевіряє, чи слід продовжувати цикл чи зупиняти його, а _завершальний компонент_ зазвичай збільшує лічильник у кінці кожного повторення.

```cpp
int sum{0};
for (int i{1}; i < 10; ++i) {
  sum += i;
}
```

Цей цикл додає числа від `1` до `9` (включно з `9`).

### `break` і `continue`

Усередині тіла циклу можна використати ключове слово `break`, щоб повністю зупинити виконання циклу:

```cpp
int sum{2};
while(true) {
    sum *= 2;
    if (sum > 1000)
        break;
}
// sum is now 1024
```

На відміну від нього, ключове слово `continue` зупиняє лише виконання поточної ітерації та переходить до наступної:

```cpp
int equal_sum{0};
for (int i{1}; i < 7; ++i) {
  if  (i%2 == 1) {
    continue;
  }
  equal_sum += i;
}
// equal_sum is now 12
```

~~~~exercism/note
Зазвичай логіку циклу легше зрозуміти, коли використання `break` і `continue` зведено до мінімуму або й зовсім прибрано.
Обидва ключові слова пропускають певні ділянки коду, і через це часто важче простежити за його перебігом.
~~~~
