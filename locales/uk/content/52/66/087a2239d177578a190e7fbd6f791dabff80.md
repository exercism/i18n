# Інструкції

Ми волонтеримо в громадському мистецькому центрі, де над головним входом
викладають довгу мозаїку з керамічних плиток. Команда дизайнерів
розклала роботу **рядок за рядком**: кожен рядок - це масив кольорів
плиток, а вся мозаїка - це масив рядків.

Поки волонтери ріжуть, укладають і переставляють плитки, ми пишемо
невеликі багаторазові слова, щоб будувати, поєднувати й шукати
частини дизайну.

## 1. Смужка з однієї плитки

Визначте `tile-strip`, щоб вона приймала колір і повертала рядок з
одного елемента, який містить лише цей колір.

```factor
"sky-blue" tile-strip .
! => { "sky-blue" }
```

## 2. Рядок із трьох плиток

Визначте `row-of-three`, щоб вона брала три кольори зі стека і
повертала рядок із трьох елементів.

```factor
"red" "white" "blue" row-of-three .
! => { "red" "white" "blue" }
```

## 3. Поєднайте рядки в плаский список плиток

Команді дизайнерів потрібно перевірити загальну кількість кольорів
у всіх рядках мозаїки. Визначте `combine-rows`, щоб вона приймала
масив рядків і повертала одну послідовність усіх плиток у порядку.

```factor
{ { "red" "white" } { "blue" "red" } } combine-rows .
! => { "red" "white" "blue" "red" }
```

## 4. Дзеркальне відображення рядка

Для симетричних панелей команда віддзеркалює рядок, перш ніж
розмістити копію з протилежного боку. Визначте `mirror-row`, щоб
вона повертала рядок у зворотному порядку.

```factor
{ "red" "white" "blue" } mirror-row .
! => { "blue" "white" "red" }
```

## 5. Де в рядку цей колір?

Визначте `tile-position`, щоб вона приймала рядок і колір і повертала
індекс (з відліком від 0) першої плитки з цим кольором у рядку. Якщо
кольору немає, поверніть `f`.

```factor
{ "red" "white" "blue" } "white" tile-position .
! => 1

{ "red" "white" "blue" } "green" tile-position .
! => f
```

## 6. Чи містить цей рядок колір?

Визначте `has-colour?`, щоб вона приймала рядок і колір і повертала `t`,
якщо колір трапляється десь у рядку, інакше `f`.

```factor
{ "red" "white" "blue" } "white" has-colour? .
! => t

{ "red" "white" "blue" } "green" has-colour? .
! => f
```
