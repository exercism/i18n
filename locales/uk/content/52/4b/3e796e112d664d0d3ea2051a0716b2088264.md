# Додаток до інструкцій

# Вхідні дані

Вхідні дані для цієї вправи такі:

- `target`: рядок тексту (англ. string), наприклад `'stone'`, буде _лівим аргументом_.
- `candidates`: список рядків у коробках (наприклад, `'stone' ; 'tones' ; 'banana' ; 'tons' ; 'notes' ; 'Seton'`) буде _правим аргументом_.

Ваше дієслово буде викликано так:

```j
  target     =. 'stone'
  candidates =. 'stone' ; 'tones' ; 'banana' ; 'tons' ; 'notes' ; 'Seton'
  
  subject findAnagrams candidates
```

## Вихідні дані

Ваше дієслово має повернути _список_ коробок із рядками, які є анаграмами цільового рядка. Якщо анаграм немає, результатом має бути `empty`.
