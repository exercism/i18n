# Докладніше

Тип `Option` - це механізм мови F# для роботи зі значеннями, які можуть існувати або не існувати.
Він дає типобезпечну альтернативу використанню `null`, який у багатьох інших мовах застосовують для роботи з такими значеннями.
Його використовують у багатьох стандартних функціях бібліотеки F#, тож розуміти його конче потрібно, щоб ефективно працювати зі стандартною бібліотекою F#.

## Переваги використання типу `Option`

* __Безпека під час компіляції__: роблячи наявність або відсутність значення явною в системі типів, компілятор може гарантувати, що ми опрацюємо випадок «немає значення», запобігаючи великій категорії помилок, які могли б виникнути з `null`.

* __Безпека під час виконання__: замість `null` F# використовує `None` для позначення відсутності значення, тож `NullReferenceException` не може виникнути.

* __Змушує опрацьовувати все явно__: система типів вимагає, щоб код явно опрацьовував і випадок `Some value`, і випадок `None`, що робить код надійнішим і передбачуванішим.

* __Працює зі зіставленням зі зразком__: `Option` бездоганно поєднується з ідіомою зіставлення зі зразком у F#, даючи чистий і безпечний спосіб розібрати значення на частини й опрацювати його, якщо воно є, або виконати іншу дію, якщо його немає.

## Використання

Тип `Option` належить до узагальнених типів (тобто має базовий тип).
Значення `Option` буває або `Some value`, тобто якесь конкретне значення, або `None`, тобто відсутність значення.

Наступна функція показує, як створити значення `Option`:

```fsharp
let keepIfPositive (a: int) : int option = if a > 0 then Some a else None
```

~~~~exercism/note
`T option` - це постфіксний синтаксис, рівнозначний `Option<T>`; обидві форми синтаксису можна використовувати взаємозамінно.
Однак, згідно з F# Style Guide, для типів Option перевагу віддають постфіксній нотації (див. [розділ F# Style Guide про форматування типів і анотацій типів](https://learn.microsoft.com/en-us/dotnet/fsharp/style-guide/formatting#for-types-prefer-prefix-syntax-for-generics-foot-with-some-specific-exceptions)).
~~~~

Типово `Option` використовують у функціях пошуку.
Наприклад, функція `List.tryFind` повертає `Some index`, коли елемент є в масиві (де `index` позначає позицію шуканого значення в масиві), або `None`, коли елемента в масиві немає.

## Читання вмісту значення `Option`

Ідіоматичний спосіб прочитати значення `Option` полягає в зіставленні зі зразком, як показано в наступному прикладі:

```fsharp
// Returns "Hello, <name>!" if the name is provided; otherwise returns "Hello, you!"
let sayHello (optionalName: string option): string = 
    match optionalName with
    | Some name -> "Hello, " + name + "!"
    | None -> "Hello, you!"

sayHello (Some "Matthieu")
// --> "Hello, Matthieu!"

sayHello None
// --> "Hello, you!"
```

## Розгортання `Option` за допомогою типових значень

Значення `Option` можна «розгорнути» (перетворити на тип, який вони містять), вказавши типові значення за допомогою функції `Option.defaultValue`.
Це особливо корисно, коли потрібно переконатися, що значення не дорівнює `None`.
Наприклад:

```fsharp
Option.defaultValue "" (Some "F#")
// --> "F#"

Option.defaultValue 0 None
// --> 0
```

## Більше функцій у модулі `Option`

Модуль `Option` також містить функції, що відповідають функціям, доступним для списків, масивів, послідовностей та інших типів колекцій, як-от `Option.map`, `Option.iter`, `Option.forall`, `Option.count`.
Ці функції дозволяють працювати зі значеннями `Option` як з колекцією з нуля або одного елемента.
