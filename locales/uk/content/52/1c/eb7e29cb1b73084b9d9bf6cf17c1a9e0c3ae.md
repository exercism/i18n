# Інструкції

У цій вправі ми будемо писати код, який друкує іменні бейджі для працівників фабрики.
Працівники мають ID, імʼя та назву відділу.
Написи на бейджах працівників мають такий формат: `"[id] - name - DEPARTMENT"`.

## 1. Надрукуйте бейдж для працівника

Реалізуйте функцію `print_name_badge`. Вона приймає ID, імʼя та відділ.
Вона має повертати напис на бейджі, де назву відділу записано великими літерами.

```R
print_name_badge(67, "Katherine Williams", "Strategic Communication")
# => "[67] - Katherine Williams - STRATEGIC COMMUNICATION"
```

## 2. Надрукуйте бейдж для нового працівника

Через особливість компʼютерної системи нові працівники іноді ще не мають ID, коли починають працювати на фабриці.
Оскільки бейджі обовʼязкові, вони отримають тимчасовий бейдж без префікса ID.

Розширте функцію `print_name_badge`. Якщо ID немає, вона має надрукувати бейдж без нього.

```R
print_name_badge(NA, "Robert Johnson", "Procurement")
# => "Robert Johnson - PROCUREMENT"
```

## 3. Надрукуйте бейдж для власника

Навіть власник фабрики мусить постійно носити бейдж.
Однак власник не має відділу і ніколи не матиме: він стоїть над усіма відділами.
У цьому разі напис має містити `"OWNER"` замість назви відділу.

Розширте функцію `print_name_badge`. Якщо відділ дорівнює `NULL`, вважайте, що бейдж належить власнику компанії.

```R
print_name_badge(204, "Rachel Miller", NULL)
# => "[204] - Rachel Miller - OWNER"
```

Зауважте, що власник може бути і новим працівником.

```R
print_name_badge(NA, "Rachel Miller", NULL)
# => "Rachel Miller - OWNER"
```

## 4. Обчисліть сумарну зарплату працівників без ID

Щоб хоч приблизно оцінити, як добре видають ID, ми хочемо бачити сумарну зарплату працівників без ID.
Високе значення означає, що багато хто чекає або що проблема зачіпає досвідчених працівників: і те, і те погано.

Реалізуйте функцію `salaries_no_id`, яка приймає вектор ID і відповідний вектор зарплат та повертає суму зарплат працівників, які ще не отримали ID.
Обидва вектори мають однакову довжину.

```R
ids <- c(204, NA, 210, 352, NA, 263)
salaries <- c(23, 21, 47, 35, 17, 101) * 1000
salaries_no_id(ids, salaries)
# => 38,000
```

_Додаткове навчання, яке не перевіряють тести:_ Якщо працівників без ID немає, то який «порожній вектор» ми підсумовуємо?
