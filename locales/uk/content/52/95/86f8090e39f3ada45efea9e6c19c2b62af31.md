# Умовні конструкції

У Ruby є так звані вирази керування потоком. Вони визначають, як виконуватиметься програма, і приймають правдиве або неправдиве значення.
Існують оператори, які можна використати, щоб утворити правдиві або неправдиві значення; їх називають [операторами порівняння][comparison-operators].

Є два основні вирази керування, які визначають, який код виконається, а який ні.
Інакше кажучи, яка саме гілка виконається.

Це `if` і вираз `unless`.

## Оператори порівняння

[Оператори порівняння][comparison-operators] використовують, щоб порівнювати значення й повертати значення `true` або `false`.
Наведені далі оператори вимагають двох значень одного типу.
Якщо значення мають різні типи, компілятор видасть помилку.
Ось перелік операторів і приклад, коли вони дають значення `true`:

| Метод | Опис                  | Приклад |
| ------ | --------------------- | ------- |
| <      | менше ніж             | 4 < 5   |
| <=     | менше або дорівнює    | 4 <= 4  |
| >      | більше ніж            | 3 > 1   |
| >=     | більше або дорівнює   | 2 >= 2  |

Оператори рівності й нерівності, на відміну від уже згаданих операторів, можна застосовувати до значень будь-якого типу.
Оператор `==` перевіряє, чи два значення рівні, і це включає перевірку типу значення.
Оператор `!=` працює так само, але повертає `true`, якщо значення не рівні, і `false`, якщо вони рівні.
Ось перелік операторів рівності й нерівності та приклад, коли вони дають значення `true`:

| Метод | Опис         | Приклад |
| ------ | ------------ | ------- |
| ==     | дорівнює     | 4 == 4  |
| !=     | не дорівнює  | 5 != 4  |

## Умовна конструкція if

Умовну конструкцію [`if`][if] використовують, щоб перевірити, чи задана умова «правдива» чи «неправдива».
Якщо умова правдива, виконається код усередині умовної конструкції `if`.
Умовна конструкція `if` завершується ключовим словом `end`.

```ruby
value = 1
if value == 1
  "1 is equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
end
# => nil
```

## Конструкція unless

Конструкція `unless` працює дуже схоже на умовну конструкцію `if`, але вона виконує код усередині себе, якщо умова неправдива.

```ruby
value = 1
unless value == 1
  "1 is not equal to 1"
end
# => nil

unless value > 2
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## Конструкція else

Конструкцію `else` можна поєднувати з умовною конструкцією `if`.
Код у конструкції `else` виконається, якщо гілка `if` не виконалася.

```ruby
value = 1
if value == 1
  "1 is equal to 1"
else
  "1 is not equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
else
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## «Каскадні» конструкції if

Конструкцію `elsif` можна поєднувати з умовною конструкцією if.
Код у конструкції `elsif` виконається, якщо гілка if не виконалася, а умова конструкції elsif правдива.
Конструкції elsif можна вишикувати в ланцюжок, і виконається перша правдива умова.
У кінці умовної конструкції if може також стояти конструкція else, яка виконається, якщо жодна з попередніх умов не була правдива.

```ruby
value = 1
if value == 0
  "1 is equal to 0"
elsif value > 2
  "1 is greater than 2"
else
  "1 is not equal to 0 and 1 is not greater than 2"
end
# => "1 is not equal to 0 and 1 is not greater than 2"
```
