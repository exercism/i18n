# Інструкції

Як майбутня чарівниця, Еліз має попрактикуватися в основах.

У неї є стос карт, з якими вона хоче працювати.

Щоб трохи спростити собі завдання, вона використовує лише карти від 1 до 10.

Стос карт представлено `Array`, де низ стосу розташований на початку масиву, а верх - у кінці.

## 1. Вставити карту на верх стосу

Реалізуйте функцію `insert_top`, яка повертає копію стосу з новою наданою картою, доданою на верх стосу.

```rust
let stack = array![5, 9, 7, 1];
insert_top(stack, 8);
// -> [5, 9, 7, 1, 8]
```

## 2. Прибрати верхню карту зі стосу

Реалізуйте функцію `remove_top_card`, яка повертає копію стосу з прибраною верхньою картою.

Якщо наданий стос порожній, слід повернути початковий стос без змін.

```rust
let stack = array![3, 2, 6, 4, 8];
remove_top_card(stack);
// -> [3, 2, 6, 4]
```

## 3. Вставити карту в низ стосу

Реалізуйте функцію `insert_bottom`, яка повертає копію стосу з новою наданою картою, доданою в низ стосу.

```rust
let stack = array![5, 9, 7, 1];
insert_bottom(stack, 8);
// -> [8, 5, 9, 7, 1]
```

## 4. Прибрати карту з низу стосу

Реалізуйте функцію `remove_bottom_card`, яка повертає копію стосу з прибраною нижньою картою.

Якщо наданий стос порожній, слід повернути початковий стос без змін.

```rust
let stack = array![8, 5, 9, 7, 1];
remove_bottom_card(stack);
// -> [5, 9, 7, 1]
```

## 5. Перевірити розмір стосу

Реалізуйте функцію `check_size_of_stack`, яка перевіряє, чи дорівнює розмір стосу наданому `stack_size`, чи ні.

```rust
let stack = array![3, 2, 6, 4, 8];
check_size_of_stack(stack, 4);
// -> false
```
