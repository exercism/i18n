# Додаток до інструкцій

## Як цю вправу реалізовано в Python: рекурсія

Цю вправу призначено для виконання з використанням [concept:python/recursion](), а не циклів.
Рекурсивна функція - це функція, яка викликає саму себе. Це корисно під час розвʼязування задач, які визначені через самі себе.
Щоб уникнути нескінченної рекурсії (а точніше, щоб не переповнити стек), використовують так званий «базовий випадок».
Коли ми досягаємо базового випадку, повертається нерекурсивне значення, яке дозволяє попередньому виклику функції завершитися й повернути своє значення, і так далі, поки хвиля не прокотиться назад по стеку й перший виклик функції не поверне відповідь.
Ми могли б написати рекурсивну функцію, щоб знайти відповідь на 5! (тобто 5 * 4 * 3 * 2 * 1), ось так:

````python
def factorial(number):
  if number <= 1:  # base case
    return 1

  return number * factorial(number - 1) # recursive case

print(factorial(5)) # returns 120
````

І насамкінець зауважимо, що Python обмежує кількість рекурсивних викликів (типово 1000) і не оптимізує [хвостову рекурсію][tail-recursion].

## Повідомлення про винятки

Іноді буває потрібно [порушити виняток][raising].
Коли ми це робимо, слід завжди додавати **змістовне повідомлення про помилку**, яке вказує, у чому джерело помилки.
Це робить код читабельнішим і значно допомагає з налагодженням.
Якщо ми знаємо, що джерело помилки має певний тип, можна порушити один із [вбудованих типів помилок][built-in-errors], але все одно варто додати змістовне повідомлення.

У цій конкретній вправі потрібно використати [інструкцію `raise`][raise-statement], щоб «кинути» кілька `ValueError`, якщо у функцію `rows()` передано відʼємне число.
Тести пройдуть лише за умови, що ми і порушимо `exception`, і додамо до нього повідомлення.

Щоб порушити `ValueErrors` з повідомленням, запишімо повідомлення як аргумент типу `exception`:

```python
# if the rows function is passed a negative number.
raise ValueError("number of rows is negative")
```
