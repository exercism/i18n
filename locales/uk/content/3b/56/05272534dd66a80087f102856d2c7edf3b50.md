# Мутабельність

Cairo, з його орієнтацією на блокчейн, типово реалізує модель незмінної памʼяті.
Це означає, що щойно значення записано в памʼять, його вже не можна перезаписати, лише прочитати.
Однак Cairo надає механізм для створення мутабельних змінних за допомогою ключового слова `mut`.
Коли змінну оголошено мутабельною і її значення змінюється, нове значення записується в нову комірку памʼяті, а змінна починає вказувати на цю нову комірку.
Цей механізм дає гнучкість, зберігаючи переваги незмінності.

У наведеному нижче прикладі `x` оголошено незмінною змінною.
Якщо спробувати змінити значення `x`, компілятор видасть помилку.

```rust
let x = 5;
x = 2; // Error: cannot assign twice to immutable variable
```

Ми можемо оголосити `x` мутабельною змінною за допомогою ключового слова `mut`.
Це дає змогу змінити значення `x` після його оголошення.

```rust
let mut x = 5;
x = 10;
```

Зрештою, рішення про те, чи використовувати мутабельність, залишається за нами і залежить від того, що, як ми вважаємо, є найзрозумілішим у конкретній ситуації.

## Константи

Як і незмінні змінні, константи - це значення, привʼязані до імені, які не можна змінювати, але між константами та змінними є кілька відмінностей:

- Константи оголошують за допомогою ключового слова `const`
- З константами не можна використовувати `mut`
- Тип значення завжди потрібно вказувати явно
- Константи можна оголошувати лише в глобальній області видимості
- Константам можна присвоювати лише константні вирази, а не результат обчислення, виконаного під час роботи програми

```rust
struct AnyStruct {
    a: u256,
    b: u32
}

enum AnyEnum {
    A: felt252,
    B: (usize, u256)
}

const ONE_HOUR_IN_SECONDS: u32 = 3600;
const STRUCT_INSTANCE: AnyStruct = AnyStruct { a: 0, b: 1 };
const ENUM_INSTANCE: AnyEnum = AnyEnum::A('any enum');
const BOOL_FIXED_SIZE_ARRAY: [bool; 2] = [true, false];
```

За допомогою макроса `consteval_int!` можна створити змінну `const`, значенням якої є результат певного обчислення.

```rust
const ONE_HOUR_IN_SECONDS: u32 = consteval_int!(60 * 60);
```

## Затінення

Це можливо, і часто так роблять: коли значення перетворюється, імʼя змінної можна використати повторно, оголосивши його заново кількома викликами `let`.
Це називається _затіненням_.
Фактично друга змінна заступає першу й перебирає на себе всі використання цього імені, доки її саму не затінить інша змінна або доки не завершиться область видимості.

```rust
fn main() {
    let s: ByteArray = "my string";
    let s: ByteArray = s + " and a shadow";
    {
        let s: ByteArray = "a nested shadow";
        println!(s); // emits "a nested shadow"
    }
    println!(s); // emits "my string and a shadow"
}
```

Завдяки затіненню ми можемо навіть змінити тип змінної, повторно використавши те саме імʼя.

```rust
fn main() {
    let x: u64 = 2;
    println!("x is u64, value: {}", x);               // prints "x is u64, value: 2"
    let x: ByteArray = format!("fizz");               // converts x to a ByteArray, type annotation is required
    println!("x is now ByteArray, value: \"{}\"", x); // prints 'x is now ByteArray, value: "fizz"'
}
```
