# Створення файлів у Configlet

Коли ми додаємо новий підхід, статтю або вправу, нам доводиться створювати файли з дуже конкретними назвами.
До них також потрібно додавати або оновлювати файли конфігурації.
За допомогою команди `create` [configlet](/docs/building/configlet) може зробити все це за нас.

## Використання

Команду `create` можна використати, щоб створити файли, потрібні для додавання нового підходу, статті або вправи, а також змінити будь-які файли конфігурації.

```shell
configlet [global-options] create [command-options]

Options for create:
      --approach <slug>           The slug of the approach
      --article <slug>            The slug of the article
      --practice-exercise <slug>  The slug of the practice exercise
      --concept-exercise <slug>   The slug of the concept exercise
  -e, --exercise <slug>           Only operate on this exercise
  -o, --offline                   Do not update the cached 'problem-specifications' data
```

## Створення практичної вправи

У документах [Додавання практичної вправи](/docs/building/tracks/practice-exercises/add) є докладні вказівки, як додати практичну вправу.

## Створення концептуальної вправи

Щоб створити концептуальну вправу, треба вказати її slug:

```shell
configlet create --concept-exercise bird-watcher
```

Це створить потрібні файли концептуальної вправи, як описано в [документах про концептуальні вправи](/docs/building/tracks/concept-exercises).

Звісно, це лише перший крок до створення вправи.
Далі нам треба:

- Додати тести до файлу тестів
- Додати зразкову реалізацію
- Визначити вміст файлу-заглушки
- Написати вступ у `.docs/introduction.md`
- Написати вказівки у `.docs/instructions.md`
- У файлі `.meta/config.json` вправи:
  - Додати імʼя користувача GitHub авторів вправи до ключа `authors`
- У файлі `config.json` треку:
  - Перевірити або оновити складність вправи
  - Додати концепції до ключа `concepts`
  - Додати концепції до ключа `prerequisites`

## Створення підходу

Щоб створити файли підходу, треба вказати slug підходу та його вправи:

```shell
configlet create --approach recursion --exercise collatz-conjecture
```

Це створить потрібні файли підходу, як описано в [документах про підходи](/docs/building/tracks/approaches).

## Створення статті

Щоб створити файли статті, треба вказати slug статті та її вправи:

```shell
configlet create --article performance --exercise collatz-conjecture
```

Це створить потрібні файли статті, як описано в [документах про статті](/docs/building/tracks/articles).
