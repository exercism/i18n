# Інструкції

Наш друг щойно надіслав нам повідомлення з важливою таємницею.
Щоб інші не могли легко його прочитати, повідомлення зашифрували, виконавши низку операцій над бітами.
Нам потрібно буде написати функції, які допоможуть розшифрувати повідомлення.

## 1. Зсунути біти назад

Перший крок до розшифрування повідомлення - скасувати зсув, зроблений під час шифрування, зсунувши біти назад праворуч.
На подальших кроках розшифрування вважається, що нулі вставляються з лівого боку.

Реалізуйте функцію `shift_back()`, яка приймає значення та кількість позицій для зсуву й виконує зсув.

```julia
shift_back(0b1001, 2) # => 0b0010
```

## 2. Встановити деякі біти

Далі, деякі біти потрібно встановити в 1.

Реалізуйте функцію `set_bits()`, яка приймає значення та маску й повертає результат встановлення бітів у значенні в 1.
Біт зі `value` потрібно встановити в 1 там, де біт у `mask` також дорівнює 1.
Усі інші біти слід залишити без змін.

```julia
set_bits(0b0110, 0b0101) # => 0b0111
```

## 3. Перевернути певні біти

Під час шифрування деякі біти перевертаються.
Щоб розшифрувати повідомлення, їх потрібно перевернути назад.

Реалізуйте функцію `flip_bits()`, яка приймає значення та маску.
Маска вказує, які біти у значенні перевертати.
Якщо біт у `mask` дорівнює 1, відповідний біт у `value` перевертається.
Усі інші біти залишаються без змін.

```julia
flip_bits(0b1100, 0b0101) # => 0b1001
```

## 4. Очистити певні біти

Нарешті, є також певні біти, які завжди розшифровуються в 0.

Реалізуйте функцію `clear_bits()`, яка приймає значення та маску.
Біти у `value` потрібно встановити в 0 там, де біт у масці дорівнює 1.
Усі інші біти слід залишити без змін.

```julia
clear_bits(0b0110, 0b0101) # => 0b0010
```
