# Інструкції

Дафна працює над системою, яка запускає її експерименти та записує їхні результати. Частина коду стала трохи багатослівною і повторюваною, тож вона попросила нас написати кілька виразів `use`, які допоможуть його прибрати.

## 1. Визначте функцію `with_retry`

Іноді експеримент може не вдатися через випадкову помилку, тож якщо експеримент не вдається, Дафна хоче повторити його й подивитися, чи спрацює він із другого разу.

Визначте функцію `with_retry`, яка приймає як аргумент функцію, що повертає результат.

Якщо функція повертає значення `Ok`, то `with_retry` має повернути це значення.

Якщо функція повертає значення `Error`, то `with_retry` має викликати функцію ще раз і повернути результат цього виклику.

Дафна використає функцію так:

```gleam
pub fn main() {
  use <- with_retry
  // Perform the experiment here
}
```

## 2. Визначте функцію `record_timing`

Дафна записує, скільки часу виконується кожен експеримент, викликаючи функцію запису часу до і після кожного експерименту.

Визначте функцію `record_timing`, яка приймає два аргументи:
- Функція запису часу, яка не приймає аргументів і повертає `Nil`.
- Функція експерименту, яка не приймає аргументів і повертає результат.

`record_timing` має викликати функцію запису часу, потім викликати функцію експерименту, потім знову викликати функцію запису часу й нарешті повернути результат функції експерименту.

Дафна використає функцію так:

```gleam
pub fn main() {
  use <- record_timing(time_logger)
  // Perform the experiment here
}
```

## 3. Визначте функцію `run_experiment`

Експеримент складається з трьох фаз: підготовки, дії та запису. Усі три фази повертають результат, і кожній фазі для запуску потрібен успішний результат попередньої.

Визначте функцію `run_experiment`, яка приймає чотири аргументи:
- Назва експерименту у вигляді `String`.
- Функція підготовки, яка не приймає аргументів і повертає результат.
- Функція дії, яка приймає значення `Ok` функції підготовки як аргумент і повертає результат.
- Функція запису, яка приймає значення `Ok` функцій підготовки і дії як аргументи та повертає результат.

Якщо всі три функції завершаться успішно, то `run_experiment` має повернути `Ok(#(experiment_name, recording_data))`.

Якщо якась із функцій повертає значення `Error`, то `run_experiment` має повернути його.

Дафна використає функцію так:

```gleam
pub fn main() {
  use setup_data, action_data <- run_experiment("Test 1", setup, action)
  // Record the results here
}
```
