# Інструкції case

```sather
   case zone
   when 0 then return 0;
   when 1, 2 then return 550;
   else return 920;
   end;
```

## Як відбувається зіставлення

Значення після `case` порівнюється з кожним значенням після `when` за допомогою `=`,
згори вниз. Виконується перший збіг, і тільки він. Решту частин `when` пропущено,
а виконання продовжується після `end`.

Можна використовувати будь-який тип, який підтримує `=`: `INT`, `CHAR`, `STR`, `BOOL`.

## Гілка else

Якщо жоден варіант не збігся, а гілки `else` немає, під час виконання стається
фатальна помилка. Тож завжди пишімо її. Коли решта випадків справді не повинна
траплятися, скажімо про це саме там, а не пропускаймо гілку:

```sather
   else
      raise "unknown zone: " + zone;
   end;
```

`raise` ми розглянемо пізніше; а поки що цілком достатньо повернути розумне типове
значення.

## Коли краще обрати if

`case` порівнює одне значення з константами. Усе інше потребує `if`:

```sather
   -- ranges
   if age < 13 then ... elsif age < 16 then ... end;

   -- more than one value at a time
   if score >= 8 and sings then ... end;
```

Спроба втиснути діапазон у `case` дає щось довше й гірше за той `if`, який воно
замінило.

## case як вираз

`case` є інструкцією, а не виразом, тож ось це не Sather:

```sather
   -- wrong
   fare := case zone when 1 then 550 else 920 end;
```

Повертайте значення з середини кожної гілки або присвоюйте значення змінній
усередині кожної гілки.
