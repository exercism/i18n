# Вступ

Переліки в Cairo дозволяють визначити тип, який може бути одним із кількох іменованих варіантів.

## Основи

Переліки, скорочено від «enumeration», обмежують усі можливі значення даних заздалегідь визначеним набором. Можливі значення `enum` називаються варіантами:

```rust
#[derive(Drop)]
enum Direction {
    North,
    South,
    East,
    West,
}
```

Створімо значення переліку, вказавши варіант:

```rust
let my_direction = Direction::North;
let another_direction = Direction::West;
```

## Зіставлення з шаблоном

Використаймо match, щоб обробити різні варіанти переліку:

```rust
match my_direction {
    Direction::North => println!("Going north!"),
    Direction::South => println!("Going south!"),
    Direction::East => println!("Going east!"),
    Direction::West => println!("Going west!"),
}
```

Кожна гілка match обробляє один варіант переліку.

## Переліки з даними

Варіанти переліку можуть містити додаткові дані:

```rust
struct Location {
    x: u32,
    y: u32,
}

enum Message {
    Text: ByteArray,
    Number: u32,
    Location: Location,
}
```

Зіставмо з шаблоном, щоб витягти дані:

```rust
match msg {
    Message::Text(content) => println!("Text: {}", content),
    Message::Number(val) => println!("Number: {}", val),
    Message::Location(Location { x, y }) => println!("Position: ({}, {})", x, y),
}
```
