# Про це

Код Elixir виконується на [віртуальній машині BEAM][beam]. BEAM входить до складу системи виконання [Erlang][erlang]. Elixir натхненний Erlang і поділяє з ним середовище виконання, тому чудово взаємодіє з бібліотеками Erlang. Це означає, що розробники Elixir можуть використовувати бібліотеки Erlang у своєму коді Elixir. Насправді, спільнота Elixir не радить писати бібліотеки Elixir для функціональності, яку вже надають бібліотеки Erlang.

Як наслідок, деяка функціональність, як-от математичні операції чи функції таймерів, доступна в Elixir лише через Erlang.

Цей тісний звʼязок між Elixir і Erlang означає, що для того, щоб стати досвідченим розробником Elixir, варто приділити час вивченню базового синтаксису Erlang.

## Як користуватися

Стандартна бібліотека Erlang доступна для використання в нашому коді Elixir без жодних додаткових кроків.

Функції Erlang можна викликати так само, як ми викликаємо функції Elixir, з однією невеликою різницею. Назви модулів Erlang - це атоми в `snake_case`. Наприклад, щоб викликати функцію `pi/0` з модуля `math` в Erlang, ми пишемо:

```elixir
:math.pi()
# => 3.141592653589793
```

## Найуживаніші модулі Erlang

Найуживаніші модулі Erlang надають функціональність, якої бракує стандартній бібліотеці Elixir. Це:

- Модуль `timer`, який надає такі функції, як [`sleep/1`][erl-timer-sleep], [`send_after/2`][erl-timer-send-after] і [`send_interval/2`][erl-timer-send-interval].
- Модуль `rand`, який надає такі функції, як [`uniform/0`][erl-rand-uniform], [`normal/0`][erl-rand-normal] і [`seed/2`][erl-rand-seed-2].
- [`:io_lib.format/2`][erl-io-lib-format] надає форматування рядків тексту (англ. string) у стилі C (за допомогою керівних послідовностей).
- Модуль `math`, який надає математичні функції, як-от [`sin/1`][erl-math-sin], [`cos/1`][erl-math-cos], [`log2/1`][erl-math-log2], [`log10/1`][erl-math-log10], [`pow/2`][erl-math-pow] та інші.
- Модуль [`queue`][erl-queue], який надає структуру даних «черга».
- Модуль [`crypto`][erl-crypto], який надає криптографічні функції.
- Модуль [`zip`][erl-zip], який надає функції для роботи з zip-архівами.
- Модуль [`calendar`][erl-calendar], який надає функції для роботи з датами й часом, як-от [`iso_week_number/1`][erl-calendar-iso-week-number]. Щоб передати структуру `Date`, `Time` або `NaiveDateTime` в одну з функцій Erlang, її потрібно перетворити на формат Erlang за допомогою функції `to_erl` з відповідного модуля.

Щоб ознайомитися зі стандартною бібліотекою Erlang, зазирнімо до [STDLIB Reference Manual][erl-stdlib-ref].

Взаємодія Elixir із бібліотеками Erlang не обмежується стандартною бібліотекою Erlang. Будь-яку бібліотеку Erlang можна використовувати в коді Elixir.
