# Про це

`call` - це універсальний примітив «запустити цю quotation зараз». Коли компілятор бачить quotation безпосередньо, він може вивести ефект; коли quotation походить зі змінної, масиву чи параметра, ми маємо оголосити ефект:

```factor
: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .   ! => 2
5 3 [ + ] apply-binary .   ! => 8
```

Оголошення `call( a b -- c )` компілюється в перевірку під час виконання, яка зʼясовує, чи справді quotation має оголошений ефект. Невідповідність дає зрозумілу помилку, а не зіпсований стан стека.

Одна з рис, що роблять конкатенативний код таким компактним, - це ставлення до quotation як до даних. Ми кладемо їх у стек, збираємо в масиви, повертаємо зі слів. «Програмою» може бути проста послідовність, і `each` разом із `call` цілком достатньо, щоб її виконати.
