# Доповнення до інструкцій

## Формат вхідних і вихідних даних

Кожен набір слів подано як рядок тексту (англ. string), завершений нульовим символом, із символом нового рядка в кінці кожного слова.

Повертати анаграми потрібно в тому самому порядку, у якому вони перелічені серед слів-кандидатів.

Наприклад: `"tones\nnotes\nSeton\n"`

## Регістри

| Регістр | Використання | Тип    | Опис                                                    |
| -------- | ------------ | ------- | -------------------------------------------------------------- |
| `$a0`    | вхідні дані        | адреса | цільовий рядок тексту, завершений нульовим символом, без символу нового рядка                 |
| `$a1`    | вхідні дані        | адреса | рядок тексту кандидатів, завершений нульовим символом, із символом нового рядка після кожного слова |
| `$a2`    | вхідні/вихідні дані | адреса | рядок тексту вихідних даних, завершений нульовим символом, із символом нового рядка після кожного слова     |
| `$t0-9`  | тимчасовий    | будь-який     | для тимчасового зберігання                                          |
