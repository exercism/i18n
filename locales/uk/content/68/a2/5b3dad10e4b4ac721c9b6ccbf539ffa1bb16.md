# Тести

На MacOS/Linux виконайте:

```sh
$ chmod +x gradlew
```

Виконайте тести так:

```sh
$ ./gradlew test
```

> На Windows використайте `gradlew.bat`

## Пропущені тести

Після того, як перший тест (або тести) пройде, продовжте, закоментувавши або видаливши анотації `@Ignore`, які стоять перед іншими тестами.
