# Інструкції

Наша дизайнерська компанія переважно працювала з CSS-перетвореннями для створення вебсторінок. Після деяких обговорень ми вирішили почати використовувати Clojure, щоб виконувати частину обчислень динамічно. Деякі наші колеги мають менший досвід із Clojure, тож ми вирішуємо скористатися замиканням функції, щоб створювати багаторазові перетворення для пар координат `{x, y}`.

## 1. Перемістіть координати

Реалізуйте функцію `translate2d`, яка повертає функцію, що використовує замикання, щоб виконувати повторюване двовимірне переміщення пари координат.

```clojure
(def move-coordinates-right-2px (translate2d 2 0))
(def result (move-coordinates-right-2px 4 8))
;; result => [6 8]
```

## 2. Масштабуйте координати

Реалізуйте функцію `scale2d`, яка повертає функцію, що використовує замикання, щоб виконувати повторюване двовимірне масштабування пари координат.

> У цій вправі вважайте, що значення масштабування лише додатні.

```clojure
(def double-scale (scale2d 2 2))
(def result (double-scale 6 -3))
;; result => [12 -6]
```

## 3. Поєднайте функції перетворення

Поєднайте дві функції перетворення, щоб виконати повторюване перетворення. Це часто називають _композицією функцій_, де результат першої функції _«f(x)»_ використовується як вхідні дані для другої функції _«g(x)»_.

```clojure
(def move-coordinates-right-2px (translate2d 2 0))
(def double-coordinates (scale2d 2 2))
(def composed-transformations 
  (compose-transform move-coordinates-right-2px 
                     double-coordinates))
(def result (composed-transformations 0 1))
;; result => [4 2]
```

## 4. Збережіть результати функцій

Реалізуйте функцію `memoize-transform`. Вона приймає функцію, яку треба _мемоїзувати_, а потім повертає нову функцію, що запамʼятовує вхідні дані переданої функції, тож останнє повернене значення можна «запамʼятати» й обчислити лише один раз, якщо функцію знову викличуть із тими самими аргументами.

> Мемоїзацію іноді називають _динамічним програмуванням_: вона дає змогу виконувати дорогі операції лише один раз, адже їхній результат запамʼятовується.

```clojure
(def triple-scale (scale2d 3 3))
(def memoized-scale (memoize-transform triple-scale))

(memoized-scale 4 3)
;; => [12, 9], this is computed since it hasn't been computed before for the arguments

(memoized-scale 4 3)
;; => [12, 9], this is remembered, since it was computed already
```
