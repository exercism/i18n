# https://www.php.net/manual/en/language.basic-syntax.phptags.php"Оператор розвʼязання області видимості

Оператор розвʼязання області видимості (`::`) дозволяє нам посилатися на клас, щоб отримати доступ до його іменованих констант, статичних властивостей або статичних методів.

```php
class MyClass
{
  public const MY_VALUE = 1;
}

// MyClass::class => "MyClass"
// MyClass::MY_VALUE => 1
```

## Використання `self` і `static` з оператором розвʼязання області видимості

Іноді обʼєкту потрібно послатися на власну область видимості. Щоб це уможливити, ключове слово `self` дозволяє класу посилатися на власну область видимості. Використання ключового слова `self` відвʼязує клас від його власної назви, що полегшує підтримку коду з часом.

```php
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return self::MY_VALUE;
  }
}

// (new MyClass)->getMyValue() => 1
```

Однак `self` лексикографічно привʼязаний до класу, у якому він міститься.

```php
class MyOtherClass extends MyClass
{
  public const MY_VALUE = 99;
}

// (new MyOtherClass)->getMyValue() => 1
```

Обчислення `MyOtherClass::getMyValue` усе одно повертає `1`, а не `99`. Щоб обійти це, використаймо ключове слово `static` разом з оператором розвʼязання області видимості, щоб «пізно звʼязати» посилання з поточним класом-нащадком.

```php
// Update MyClass:
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return static::MY_VALUE;
  }
}
```

## Використання `parent` з оператором розвʼязання області видимості

Іноді потрібно звернутися саме до константи, властивості або методу, доступного з батьківської області видимості:

```php
class MyClass
{
  public function getMaximum(): int
  {
    return 5;
  }
}

class AnotherClass extends MyClass
{
  public function getMaximum(): int
  {
    return parent::getMaximum() * 2;
  }
}

// (new AnotherClass())->getMaximum() => 10
```

Найчастіше в обʼєктно-орієнтованому програмуванні `parent` використовують, щоб викликати конструктор батьківського класу під час створення обʼєкта:

```php
class ChildClass extends ParentClass
{
  public function __construct(): void
  {
    parent::__construct();
  }
}
```

## Застереження

### Видимість констант, властивостей і методів

Оператор розвʼязання області видимості все ще підкоряється правилам, які задають модифікатори видимості `public`, `private` і `protected`.
