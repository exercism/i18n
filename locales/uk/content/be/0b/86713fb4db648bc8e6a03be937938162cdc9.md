# Вступ

У Go `for range` повторює блок коду для кожного значення з виразу діапазону.
Саме вираз діапазону визначає, чи кожна ітерація даватиме одне значення, чи два.

## Вирази діапазону

### Перебирання зрізу

`range` по зрізу дає індекс і значення кожного елемента по порядку:

```go
vals := []int{10, 20, 30}
for i, v := range vals {
    fmt.Println(i, v)
}
// 0 10
// 1 20
// 2 30
```

### Перебирання мапи

`range` по мапі дає кожен ключ і значення, але порядок перебирання не гарантовано.
Go навмисно перемішує порядок перебирання мапи, тож та сама програма за різних запусків може давати різні вихідні дані.

```go
hash := map[int]int{9: 10, 99: 20, 999: 30}
for k, v := range hash {
    fmt.Println(k, v)
}
// 99 20
// 999 30
// 9 10
```

### Перебирання рядка тексту

`range` по рядку тексту (англ. string) дає індекс байта та кожну руну (кодову точку Unicode).
У наступному прикладі `子` займає три байти, тож `猫` починається з індексу байта `3`, а не `1`.

```go
for i, r := range "子猫" {
    fmt.Println(i, r, string(r))
}
// 0 23376 子
// 3 29483 猫
```

Якщо потрібні індекси рун, перетворімо рядок тексту на зріз рун:

```go
for i, r := range []rune("子猫") {
    fmt.Println(i, r, string(r))
}
// 0 23376 子
// 1 29483 猫
```

### Перебирання цілого числа

`range` може перебирати ціле число напряму, даючи значення від `0` до цього числа, не включаючи його.
Нуль і відʼємні значення допустимі, але не дають жодної ітерації.

```go
for n := range 3 {
    fmt.Println(n)
}
// 0
// 1
// 2
```

### Перебирання ітератора

`range` приймає ітератор типу `iter.Seq[V]` або `iter.Seq2[K, V]`.
Ітератор - це функція, яка видає послідовність значень по одному за раз.
Тоді `range` перебирає ці значення одне за одним.

```go
text := "The quick brown fox"
for word := range strings.FieldsSeq(text) {
    fmt.Println(word)
}
// The
// quick
// brown
// fox

names := []string{"Alice", "Bob", "Vera"}
for i, v := range slices.All(names) {
    fmt.Println(i, ":", v)
}
// 0 : Alice
// 1 : Bob
// 2 : Vera
```

### Перебирання каналу

І нарешті, `range` може приймати значення, надіслані через канал, доки цей канал не закриють деінде.
Канали докладніше розглянемо далі в силабусі треку.

## Пропускання індексу або значення

Go не скомпілює код, якщо змінну оголошено, але ніколи не використано.

```go
vals := []int{10, 20, 30}
for i, v := range vals {
    fmt.Println(v)
}
// Go build failed: declared and not used: i
```

Якщо потрібне лише значення, присвоймо `_` замість індексу або ключа, щоб його проігнорувати.

```go
vals := []int{10, 20, 30}
for _, v := range vals {
    fmt.Println(v)
}
// 10
// 20
// 30
```

Якщо потрібен лише індекс, пропустімо його зовсім:

```go
vals := []int{10, 20, 30}
for i := range vals {
    fmt.Println(i)
}
// 0
// 1
// 2
```

Якщо не потрібні ні індекс, ні значення, можна пропустити обидва:

```go
vals := []int{10, 20, 30}
count := 0
for range vals {
    count++
}
// count == 3
```
