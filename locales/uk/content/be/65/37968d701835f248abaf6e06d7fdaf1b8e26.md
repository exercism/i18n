# Вступ

У Haxe абстрактний тип - це тип, який під час виконання є іншим типом. Це можливість часу компіляції, яка визначає типи «над» конкретними типами, щоб змінити або доповнити їхню поведінку:

```haxe
abstract AbstractInt(Int) {
    inline public function new(i:Int) {
        this = i;
    }
}
```

Тут ми оголошуємо тип `AbstractInt` за допомогою ключового слова `abstract`. Його синтаксис дуже схожий на синтаксис `class`. І так само, як класи, абстрактні типи можуть мати методи. Їх також можна створювати і використовувати так само, як класи:

```haxe
class Main {
    static public function main() {
        var a = new AbstractInt(12);
        trace(a); // 12
    }
}
```
