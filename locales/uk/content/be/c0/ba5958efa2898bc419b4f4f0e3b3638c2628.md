# Докладніше

*Регулярний вираз* (regex) - це невеликий шаблон, який описує форму якогось тексту. Інструменти Factor для регулярних виразів живуть у словнику [`regexp`][regexp], а шаблон записують як літерал між `R/ ` і `/`.

Більшість символів у шаблоні збігаються самі із собою. Виразна сила походить від класів символів і квантифікаторів:

```
\d        ! a digit 0–9            \s   ! whitespace
\D        ! any non-digit          \S   ! non-whitespace
[A-Z]     ! one capital letter     .    ! any one character
[^0-9]    ! any char except a digit

{4}       ! exactly 4              +    ! one or more
{2,5}     ! between 2 and 5        *    ! zero or more
?         ! optional               |    ! either side (alternation)
```

Отже, `R/ [A-Z]{2}-\d{4}/` збігається з таким описом: «дві великі літери, дефіс, чотири цифри».

## Збіг цілого рядка проти пошуку

`matches?` спрацьовує лише тоді, коли шаблону відповідає *весь* рядок тексту (англ. string). Інші слова шукають *усередині* рядка тексту:

```
matches?             ( string regexp -- ? )
re-contains?         ( string regexp -- ? )
count-matches        ( string regexp -- n )
all-matching-subseqs ( string regexp -- seq )
first-match          ( string regexp -- slice/f )
re-split             ( string regexp -- seq )
re-replace           ( string regexp replacement -- result )
```

```factor
USING: regexp ;

"NS-1024" R/ [A-Z]{2}-\d{4}/ matches? .         ! => t
"id NS-1024 ok" R/ [A-Z]{2}-\d{4}/ matches? .   ! => f   (extra text)
"id NS-1024 ok" R/ [A-Z]{2}-\d{4}/ re-contains? .   ! => t

"a1b2c3" R/ \d/ count-matches .   ! => 3
"a1b2c3" R/ \d/ re-replace .      ! NOTE: see re-replace below
```

## Зрізи

`first-match` і `re-split` повертають обʼєкти `slice`. Це легкі подання оригінального рядка тексту, а не нові рядки тексту. Коли потрібен окремий рядок тексту (наприклад, щоб порівняти з рядковим літералом), перетворюймо `slice` на рядок тексту за допомогою `>string`. `all-matching-subseqs` уже повертає рядки тексту.

## Заміна

`re-replace` замінює кожен збіг на рядок тексту заміни й повертає результат:

```factor
USING: regexp ;

"user=alice pass=hunter2" R/ pass=\S+/ "pass=****" re-replace .
! => "user=alice pass=****"
```

## Побудова шаблону під час виконання

`R/ /` розбирається під час завантаження файлу. Щоб побудувати шаблон із рядка тексту, обчисленого під час виконання, скористаймося `<regexp>`:

```
<regexp> ( string -- regexp )
```
