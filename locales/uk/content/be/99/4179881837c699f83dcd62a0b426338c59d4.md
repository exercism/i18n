# Встановлення

Cairo можна встановити, просто завантаживши Scarb. Scarb обʼєднує компілятор Cairo і мовний сервер Cairo в один пакет, який легко встановити, тож ми можемо одразу почати писати код на Cairo. Scarb також є пакетним менеджером для Cairo.

Щоб отримати рекомендовані інструкції зі встановлення для своєї платформи, перейдімо на [офіційний сайт Cairo](https://www.cairo-lang.org/tutorials/getting-started-with-cairo/).

За операційною системою:

- Linux/MacOS
    1. Встановіть [asdf](https://asdf-vm.com/guide/getting-started.html)
    2. Встановіть [scarb](https://docs.swmansion.com/scarb/download#install-via-asdf)
    3. Перевірте встановлення в новому сеансі термінала `scarb --version`
- Windows
    1. Встановіть [scarb](https://docs.swmansion.com/scarb/download#windows)
    2. Перевірте встановлення в новому сеансі термінала `scarb --version`

Встановленого інструментарію замало! Підтримка IDE значно підвищує продуктивність, і більшість розробників уже звикли до неї.
Якщо ми користуємося Visual Studio Code, радимо встановити [розширення Cairo](https://marketplace.visualstudio.com/items?itemName=starkware.cairo1), яке забезпечує підсвічування синтаксису, доповнення коду й інші корисні можливості!
