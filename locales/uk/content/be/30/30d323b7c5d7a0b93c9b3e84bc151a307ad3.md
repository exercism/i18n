# Про

Доступні, починаючи з `PHP 8.0.0`, **оголошення обʼєднаних типів** приймають значення кількох різних типів, а не одного. Щоб визначити обʼєднаний тип, використовують вертикальну риску (`|`) для розділення типів.

```php
function add(int|float $a, int|float $b): int|float
{
    return $a + $b;
}
```

## Нюанси

- Типи `null` можна оголосити як _nullable_, використавши `?Type` або `Type1|Type2|null`.
- Якщо оголосити дубльовані або надлишкові типи, виникне помилка на етапі компіляції.
- `void` не можна використовувати як частину оголошення обʼєднаного типу.
