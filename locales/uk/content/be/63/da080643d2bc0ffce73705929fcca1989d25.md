# Про

`List` дуже схожий на [`Array`][array]. Однак є суттєві відмінності, які не варто пропускати:

1. Список не можна індексувати квадратними дужками, тобто `[0]`.
2. Список не можна ініціалізувати.
3. Немає спискових включень.
4. Список може вільно змінювати елементи під час перебирання.

`List` належить до пакета `haxe.ds`, тому щоразу, коли ми хочемо використовувати списки, потрібно імпортувати цей пакет:

```haxe
import haxe.ds.List;

class Main {
  static function main() {
    var myList = List<Int>();

    for (i in 0...5) {
      myList.add(i);
    }

    trace(myList); // {0, 1, 2, 3, 4}
  }
}
```

[array]: https://haxe.org/manual/std-Array.html
