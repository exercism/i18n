# Вказівки

У цій вправі ми будемо працювати з ощадними рахунками. Щороку баланс ощадного рахунку оновлюється залежно від відсоткової ставки. Відсоткова ставка, яку дає банк, залежить від суми грошей на рахунку (його балансу):

- 0,5% для невідʼємного балансу, меншого за `1000` доларів.
- 1,621% для додатного балансу, що більший або дорівнює `1000` доларам і менший за `5000` доларів.
- 2,475% для додатного балансу, що більший або дорівнює `5000` доларам.
- 3,213% для відʼємного балансу (це дає відʼємні відсотки).

На нас чекають три завдання, і кожне з них стосується балансу та його відсоткової ставки.

## 1. Обчислити відсоткову ставку

Реалізуйте метод `SavingsAccount.interest_rate`, щоб обчислити відсоткову ставку на основі заданого балансу:

```ruby
SavingsAccount.interest_rate(200.75)
#=> 0.5
```

Зауважте, що повернене значення - це екземпляр `Float`.

## 2. Обчислити щорічне оновлення балансу

Реалізуйте метод `SavingsAccount.annual_balance_update`, щоб обчислити щорічне оновлення балансу з урахуванням відсоткової ставки:

```ruby
SavingsAccount.annual_balance_update(200.75)
#=> 201.75375
```

Зауважте, що повернене значення - це екземпляр `Float`.

## 3. Обчислити кількість років до досягнення бажаного балансу

Реалізуйте метод `SavingsAccount.years_before_desired_balance`, щоб обчислити мінімальну кількість років, потрібну для досягнення бажаного балансу:

```ruby
SavingsAccount.years_before_desired_balance(200.75, 214.88)
#=> 14
```

Зауважте, що повернене значення - це екземпляр `Integer`.
