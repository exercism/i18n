# Вступ

У Go немає поняття порожнього значення, null чи undefined для значень змінних.
Змінні, оголошені без явного початкового значення, типово набувають нульового значення для свого типу.

Нульовими значеннями для примітивних типів, як-от булевих значень (англ. Boolean), числових типів і рядків тексту (англ. string), є `false`, `0` та `""` відповідно.

Ідентифікатор `nil`, що означає нуль, є нульовим значенням для складніших типів, як-от вказівників, функцій, інтерфейсів, зрізів, каналів і мап.

У наведеній таблиці описано нульове значення для типів Go.

| Тип        | Нульове значення |
| ---------- | ---------------- |
| булевий    | `false`          |
| числовий   | `0`              |
| рядок тексту | `""`           |
| вказівник  | `nil`            |
| функція    | `nil`            |
| інтерфейс  | `nil`            |
| зріз       | `nil`            |
| канал      | `nil`            |
| мапа       | `nil`            |

Ми могли помітити, що структурних типів у наведеній таблиці немає.
Це тому, що нульове значення для типу-структури залежить від її полів.
Структура набуває нульового значення, коли всі її поля набувають відповідних нульових значень.
