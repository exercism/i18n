# Рядки

У Crystal є тип [`String`][strings], який використовується для представлення тексту.
Рядок тексту (англ. string) у Crystal складається з послідовності символів Unicode.
Рядки тексту незмінні: щойно створений рядок уже не можна змінити.
Це означає, що кожного разу, коли ми змінюємо рядок тексту, створюється новий рядок, а початковий залишається без змін.

Щоб визначити рядок тексту, ми використовуємо подвійні лапки `"`.

```crystal
"Hello World"
```

## Конкатенація

Щоб зʼєднати два рядки тексту, скористаймося оператором `+`.
Оператор `+` повертає новий рядок тексту, який поєднує ці два рядки.

```crystal
hello = "Hello"
hello + " World"
# => "Hello World"
```

## Перетворення між рядками тексту та числами

Метод `to_i` перетворює рядок тексту на ціле число.
Натомість метод `to_f` повертає число з плаваючою комою.
Якщо рядок тексту не вдається перетворити на число, буде викинуто помилку `ArgumentError`.

```crystal
"1".to_i
# => 1

"1.0".to_f
# => 1.0

"Hello".to_i
# => ArgumentError: Invalid integer: Hello
```

Ціле число або число з плаваючою комою можна перетворити на рядок тексту за допомогою методу `to_s`.

```crystal
1.to_s
# => "1"

1.0.to_s
# => "1.0"
```

## Інтерполяція

Інтерполяція - це зручний спосіб поєднувати рядки тексту й вбудовувати вирази в них.
Щоб інтерполювати рядок тексту, скористаймося символом `#`, після якого йдуть фігурні дужки `{}`, а всередині дужок міститься вираз.

```crystal
name = "World"
"Hello #{name}!"
# => "Hello World!"
```

Crystal автоматично перетворює результат виразу на рядок тексту.

```crystal
"Hello #{1 + 1}!"
# => "Hello 2!"
```

## Розмір

Коли нам потрібно дізнатися кількість символів у рядку тексту, ми можемо скористатися методом `size`, який повертає довжину рядка як ціле число.
Розмір рядка тексту зберігається як властивість самого рядка, тому його не потрібно обчислювати щоразу під час виклику методу, завдяки чому метод працює дуже швидко.

```crystal
"Hello World".size
# => 11
```

## Індексування

Індексування потрібне тоді, коли ми хочемо отримати конкретний символ із рядка тексту.
Щоб отримати символ із `String`, скористаймося звичним записом із дужками.

~~~~exercism/note
`[]` реалізовано як метод екземпляра `Bool`, де індекс передається як аргумент методу.
~~~~

У рядку тексту перший символ має індекс 0.

```crystal
"Hello World"[0]
# => 'H'

"Hello World"[6]
# => 'W'
```

Щоб отримати символ із кінця рядка тексту, можна взяти довжину рядка мінус один, щоб отримати індекс останнього символу, а для передостаннього символу взяти довжину рядка мінус два, і так далі.
Але є й коротший шлях: просто використати відʼємний індекс, де останній символ має індекс -1, передостанній має індекс -2, і так далі.

```crystal
name = "Hello World"
name[name.size - 1]
# => 'd'

name[-1]
# => 'd'
```

### Перевірка на підрядок

У Crystal можна перевірити, чи містить рядок тексту підрядок, за допомогою індексування.
Тут працює той самий запис із дужками, але замість індексу ми передаємо підрядок.
Якщо підрядок знайдено в рядку тексту, повертається цей підрядок, інакше виникає помилка `NilAssertionError`.

```crystal
"Hello World"["Hello"]
# => "Hello"

"Hello World"["Goodbye"]
# => NilAssertionError
```

Якщо нам потрібне булеве значення (англ. Boolean), яке показує, чи знайдено підрядок, скористаймося методом `includes?`.

```crystal
"Hello World".includes?("Hello")
# => true

"Hello World".includes?("Goodbye")
# => false
```

## Екранування

Деякі символи не можна записати в рядку тексту напряму, для них доводиться використовувати керуючу послідовність.
Наприклад, якщо ми хочемо використати в рядку тексту подвійні лапки, їх потрібно екранувати.
Керуюча послідовність починається із символу `\`, після якого йде символ, який ми хочемо екранувати.

Ось спеціальні символи в Crystal:

| Значення | Опис                          |
| -------- | ----------------------------- |
| `\a`     | Сигнал                        |
| `\b`     | Забій                         |
| `\e`     | Escape                        |
| `\f`     | Подача сторінки               |
| `\n`     | Подача рядка або новий рядок  |
| `\r`     | Повернення каретки            |
| `\t`     | Горизонтальна табуляція       |
| `\v`     | Вертикальна табуляція         |
| `\\`     | Зворотна коса риска           |
| `\'`     | Одинарні лапки                |
| `\"`     | Подвійні лапки                |
| `\377`   | Вісімковий символ ASCII       |
| `\xFF`   | Шістнадцятковий символ ASCII  |
| `\uFFFF` | Шістнадцятковий символ Unicode |

```crystal
puts "Hello \"World\""
# => Hello "World"

puts "Hello \nWorld"
# => Hello
# => World
```

## Багаторядкові рядки тексту

Щоб записати багаторядковий рядок тексту, ми використовуємо той самий синтаксис, що й для однорядкового, але переносимо на новий рядок кожен рядок, який хочемо отримати.

```crystal
"Hello
World"
# => "Hello\nWorld"
```

## Unicode

[Unicode][unicode] - це стандарт для кодування, подання й обробки тексту в різних системах письма.
Unicode підтримує понад 100 000 символів, зокрема літери, розділові знаки, символи та емодзі.

Оскільки Crystal використовує Unicode для рядків тексту, ми можемо, наприклад, додавати емодзі в рядки тексту.

```crystal
"Hello 🌍"
# => "Hello 🌍"
```

Іноді нам потрібен символ, якого немає, наприклад, у нашому редакторі чи системі.
У такому разі скористаймося керуючою послідовністю Unicode, щоб записати цей символ.

```crystal
"\u{1F310}"
# => "🌐"
```
