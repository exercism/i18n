# Вступ

У програмуванні важливо вміло обробляти помилки, щоб несподівані ситуації не призводили до аварійного завершення програми чи непередбачуваної поведінки.
Cairo пропонує два основні механізми обробки помилок:

1. **Невідновлювані помилки** з `panic`, які негайно зупиняють програму.
2. **Відновлювані помилки** з `Result`, які дають програмі змогу обробити помилки й відреагувати на них.

## Невідновлювані помилки з `panic`

Іноді програма стикається з такою серйозною помилкою, що не може продовжити роботу.
У таких випадках Cairo використовує функцію `panic`, щоб негайно зупинити виконання.
Це допомагає, коли помилка, наприклад спроба звернутися до індексу поза межами масиву, унеможливлює розумне продовження роботи програми.
Функція `panic` приймає повідомлення типу `ByteArray`, яке описує причину помилки.

Наприклад, у Cairo:

```rust
fn main() {
    let data = array![1, 2];
    panic("An unrecoverable error has occurred!");
}
```

Цей приклад демонструє примусовий виклик `panic`, який негайно зупиняє програму з повідомленням.

### Макрос `assert!`

Макрос `assert!` стає в пригоді, коли потрібно перевірити певні умови в коді.
Якщо умова в `assert!` набуває значення `false`, програма викличе `panic` із повідомленням про помилку типу `ByteArray`.
Його часто використовують, щоб перевірити припущення під час розробки та переконатися, що значення відповідають певним критеріям.

Наприклад:

```rust
fn main() {
    let x = 5;
    assert!(x > 0, "x must be greater than zero");
}
```

Якщо `x` не більше за нуль, програма викличе `panic` з повідомленням `"x must be greater than zero"`. `assert!` допомагає перевіряти інваріанти та попередні умови, не пишучи код обробки помилок вручну.

## Відновлювані помилки з `Result`

Не всі помилки мають зупиняти програму.
Деякі з них можна обробити так, щоб програма продовжила роботу.
Перелік `Result` у Cairo представляє такі відновлювані помилки і має два варіанти:

- `Result::Ok` указує на успіх.
- `Result::Err` представляє помилку.

За допомогою `Result` функція може повернути або значення успіху, або помилку, і тоді функція, яка її викликала, вирішує, що робити далі.

```rust
fn divide(a: u32, b: u32) -> Result<u32, ByteArray> {
    if b == 0 {
        Result::Err("Error: Division by zero")
    } else {
        Result::Ok(a / b)
    }
}
```

У цьому прикладі, якщо `b` дорівнює нулю, повертається помилка; інакше повертається результат ділення.
