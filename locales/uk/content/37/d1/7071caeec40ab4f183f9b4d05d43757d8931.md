# Докладно

У Haxe абстрактний тип - це тип, який під час виконання виявляється іншим типом. Це можливість часу компіляції, яка визначає типи «поверх» конкретних типів, щоб змінити або доповнити їхню поведінку:

```haxe
abstract AbstractInt(Int) {
    inline public function new(i:Int) {
        this = i;
    }
}
```

Тут ми оголошуємо тип `AbstractInt` за допомогою ключового слова `abstract`. Його синтаксис дуже схожий на синтаксис `class`. І так само, як класи, абстрактні типи можуть мати методи. Їх також можна створювати й використовувати так само, як класи:

```haxe
class Main {
    static public function main() {
        var a = new AbstractInt(12);
        trace(a); // 12
    }
}
```

Як зазначено вище, абстрактні типи - це можливість часу компіляції. Якщо скомпілювати наведений вище приклад у JavaScript, отримаємо таке:

```javascript
var a = 12;
console.log(a)
```

Абстрактний тип `AbstractInt` повністю зникає з вихідних даних. Це тому, що конструктор `Abstract` [вбудовується][inline], і ми побачимо це далі.

[inline]: https://haxe.org/manual/class-field-inline.html
