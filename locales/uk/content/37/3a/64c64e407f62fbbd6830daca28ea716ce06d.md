## Завершальні замикання

Swift пропонує ще один варіант свого синтаксису для роботи із замиканнями, відомий як [завершальні замикання][trailing-closures]. Завершальні замикання виникають, коли останній параметр у списку параметрів функції має тип функції. У цьому разі, якщо ми передаємо замикання, його можна написати _після_ закривальної дужки, а мітку аргументу пропустити. Зауважмо, що якщо у функції лише один параметр, дужки можна взагалі не писати.

```swift
func fetchURL(_ urlString: String,
              uponReceipt handleResult: (String) -> ()
             )  -> () {
  if let url = URL(string: urlString), let htmlString = fetch(url) {
    handleResult(htmlString)
  }
}

fetchURL("https://www.swift.org") { print($0) }
// prints the fetched html string

["apple", "ball", "carrot"].sorted { $0.count < $1.count }
```

## Кілька завершальних замикань

Хоча попередні версії Swift підтримували лише одне завершальне замикання, починаючи з версії 5.2.4 Swift підтримує кілька завершальних замикань.

Якщо функція має більше ніж одне замикання в кінці списку параметрів, синтаксис завершальних замикань дає змогу винести їх усі за дужки. Однак пропускають лише мітку першого аргументу, для решти мітки потрібно вказувати:

```swift
func fetchURL(_ urlString: String,
              uponReceipt handleResult: (String) -> (),
              onFailure handleFailure: () -> ()
             )  -> () {
  if let url = URL(string: urlString), let htmlString = fetch(url) {
    handleResult(htmlString)
  } else {
    handleFailure()
  }
}

fetchURL("https://www.swift.org") {
  print($0)
} onFailure: {
  print("Error: https://www.swift.org could not be fetched")
}
// prints the fetched html string on successful fetch or prints error message on failure
```

[trailing-closures]: https://docs.swift.org/swift-book/LanguageGuide/Closures.html#ID102
