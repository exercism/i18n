# Інструкції

Вітаю, агенте Double-Null0111.

Наша місія, якщо ми вирішимо її прийняти, - написати пару інструментів, які допоможуть нам проникнути до штаб-квартири UMBRA (Обʼєднані поплічники, які насправді жахливі) і здобути плани їхньої найновішої справді жахливої оборудки. Для виконання цієї місії нам знадобляться три інструменти.

## 1. Згенерувати ідентифікаційний номер

Кожен поплічник має унікальний ідентифікатор, який змінюється щодня й залежить від кількості секретів, які він знає, та кількості годин, які він спить.
Нам потрібно написати функцію, яка приймає день (як `Int`) і створює функцію генерації ідентифікатора для цього дня.
Функція генерації ідентифікатора приймає два параметри:

1. кількість секретів, які він знає
2. кількість годин, які він спить

Ідентифікатор обчислюється так:

1. помножити кількість секретів на кількість годин сну
2. додати день (поданий як `Int`) до результату

```kotlin
val idGenerator = makeIdGenerator(4)
idGenerator(3, 6)
// => 22

idGenerator(11, 5)
//  => 59
```

## 2. Захистити здобуті секретні плани секретним паролем

Коли ми вже маємо секретні плани, потрібно захистити їх так, щоб лише ті, хто знає пароль, могли їх дістати.
Для цього потрібно реалізувати функцію `protectSecret(secret: String, password: String) : (String) -> String`.
Ця функція поверне іншу функцію, яка приймає як вхідні дані можливі рядки тексту (англ. string) з паролем.
Якщо введений пароль правильний, нова функція повертає прихований секрет, а якщо пароль неправильний, функція повертає «Sorry. No hidden secrets here.»

```kotlin
val secretFunction = protectSecret("Steal the world's supply of french fries!", "5up3r53cr37")

secretFunction("Open sesame")
// Returns "Sorry. No hidden secrets here."

secretFunction("5up3r53cr37")
// Returns "Steal the world's supply of french fries!"
```

## 3. Знайти секретний пароль

У базі UMBRA є кілька кімнат, які охороняє охоронець, що питатиме в нас секретний пароль.
Секретний пароль залежить від номера кімнати.
На жаль, нам відома лише половина алгоритму обчислення пароля.
Іншу половину можна дізнатися, запитавши одного з поплічників.

Реалізуйте функцію `getPassword`, яка приймає наведене нижче й повертає пароль:

1. номер кімнати
2. функцію поплічника, і повертає секретний пароль

Секретний пароль отримують, викликавши функцію поплічника з іншою функцією, яка представляє відомий нам алгоритм.
Наша частина алгоритму:

1. приймає два числа й додає їх одне до одного
2. множить результат на ідентифікатор кімнати

```kotlin
val minionFunction = { yourFunc : (Int, Int) -> Int ->
    "Password=${yourFunc(1, 3)}"
}

getPassword(5, minionFunction)
// Returns "Password=20"
```
