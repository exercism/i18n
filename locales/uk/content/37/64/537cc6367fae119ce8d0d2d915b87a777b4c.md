# Додаток до інструкцій

Якщо вхідні дані неправильні, поверніть порожню довжину.

## Зарезервовані адреси

Буфер для першого рядка тексту (англ. string) використовує байти 1024-2047 лінійної памʼяті.
Буфер для другого рядка тексту використовує байти 2048-3071 лінійної памʼяті.
Буфер для третього рядка тексту використовує байти 3072-4095 лінійної памʼяті.

Перший сегмент байтів 0-1023 лінійної памʼяті вільний для використання.
