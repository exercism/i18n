# Доповнення до інструкцій

## Інструкції, специфічні для треку

Функції мають повертати добуток, а також зсув і довжину масиву множників.
Множники просто записуються в памʼять як пари i32:

```
Return value:
[u32 $product] [u32 $factorsOffset] [u32 $factorsLength]

Memory at $factorsOffset
[u32 firstFactor] [u32 firstCofactor] [u32 secondFactor] [u32 secondCofactor] ...
```

Для найбільшого одноцифрового добутку-паліндрома це має такий вигляд:

```
Return value
0009 0000 0004

Memory at offset 0
0001 0009 0003 0003
```
