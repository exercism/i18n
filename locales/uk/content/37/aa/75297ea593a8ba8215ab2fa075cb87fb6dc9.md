# Вказівки

Наше завдання - визначити, що ми скажемо, віддаючи зайве печиво.

Якщо наш друг любить печиво і його звати Do-yun, то ми скажемо:

```text
One for Do-yun, one for me.
```

Якщо наш друг не любить печиво, ми віддаємо печиво наступній людині в черзі в пекарні.
Оскільки ми не знаємо імені цієї людини, то скажемо _you_ замість нього.

```text
One for you, one for me.
```

Ось кілька прикладів:

| Імʼя   | Діалог                      |
| :----- | :-------------------------- |
| Alice  | One for Alice, one for me.  |
| Bohdan | One for Bohdan, one for me. |
|        | One for you, one for me.    |
| Zaphod | One for Zaphod, one for me. |
