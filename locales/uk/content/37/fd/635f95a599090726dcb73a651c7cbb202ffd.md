# Додаток до інструкцій

## Друк дерева

Ця вправа містить кілька наперед визначених методів класу, які допомагають вивести дерево в зручному форматі.
Основна мета - допомогти з налагодженням і додати ясності.
Якщо ми правильно реалізуємо решту класу, він має вивести дерево за нас.

```powershell
.Example
$tree = [BinarySearchTree]::new(@(50, 76, 1, 34, 89, 44, 25, 6, 26, 100, 13))
$tree.ToString()

Return:
@"
50
├──L:1
│   └──R:34
│       ├──L:25
│       │   ├──L:6
│       │   │   └──R:13    
│       │   └──R:26        
│       └──R:44
└──R:76
    └──R:89
        └──R:100
"@
```
