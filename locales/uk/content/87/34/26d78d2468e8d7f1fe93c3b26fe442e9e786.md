# Налаштування інструментів

Для свого треку варто налаштувати три інструменти:

- **[Лічильник рядків коду](/docs/building/tooling/lines-of-code-counter)**: цей інструмент рахує рядки коду для кожної надісланої ітерації.
- **[Витягувач фрагментів](/docs/building/tooling/snippet-extractor)**: цей інструмент витягує фрагмент для кожної ітерації, який показується на сайті.
- **[Exercism CLI](/docs/building/tooling/cli)**: цим інструментом студенти користуються, щоб працювати над треком локально, на власній машині.

```exercism/note
Налаштування цих інструментів не є обовʼязковим, але воно зробить інтеграцію свого треку із сайтом _набагато_ кращою.
Тому ми наполегливо радимо налаштувати всі три інструменти.
```
