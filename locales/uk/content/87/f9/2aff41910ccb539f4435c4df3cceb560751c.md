# Вступ

`Integer` зберігає будь-яке число, яким би великим воно не було, аж до межі памʼяті нашої машини, тоді як `Int` відповідає набору додатних і відʼємних цілих чисел, які можна подати у 32 або 64 бітах (гарантовано принаймні від -2^29 до 2^29).

`Float` відповідає набору дійсних чисел, обмеженому точністю компʼютера.
Операції, визначені для чисел, зазвичай працюють з одним типом або з іншим, але не з обома одночасно.

Функції для перетворення між `Float` та `Integer` включають, серед інших, `toFloat`, яка перетворює `Int`/`Integer` на `Float`, і `ceiling`, яка перетворює `Float` на `Int`.

Перетворення з цілого типу (`Int` або `Integer`) на будь-який інший числовий тип виконується за допомогою функції `fromIntegral`.
Цільовий тип виводиться автоматично.
Наприклад:

```haskell
n :: Integer
n = 6
x :: Float
x = fromIntegral n      --> x = 6.0

m :: Int
m = 7
y :: Double
y = fromIntegral m      --> y = 7.0
```
