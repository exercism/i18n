# Вступ

## Успадкування

У C# ієрархію _класів_ можна визначити за допомогою _успадкування_, яке дозволяє похідному класу (`Car`) успадковувати поведінку та дані свого батьківського класу (`Vehicle`). Якщо батьківський клас не вказано, клас успадковується від класу `object`.

Батьківські класи можуть надавати похідним класам функціональність у три способи:

- Визначити звичайний метод.
- Визначити `virtual`-метод, який схожий на звичайний метод, але похідні класи _можуть_ його змінити.
- Визначити `abstract`-метод, тобто метод без реалізації, який похідні класи _повинні_ реалізувати. Клас з `abstract`-методами також має бути позначений як `abstract`. Абстрактні класи не можна створювати.

Модифікатор доступу `protected` дозволяє отримати доступ до члена батьківського класу в похідному класі, але блокує доступ з інших класів.

Похідні класи можуть отримати доступ до членів батьківського класу через ключове слово `base`.

```csharp
// Inherits from the 'object' class
abstract class Vehicle
{
    // Can be overridden
    public virtual void Drive()
    {
    }

    // Must be overridden
    protected abstract int Speed();
}

class Car : Vehicle
{
    public override void Drive()
    {
        // Override virtual method

        // Call parent implementation
        base.Drive();
    }

    protected override int Speed()
    {
        // Implement abstract method
    }
}
```

Конструктор похідного класу автоматично викличе конструктор свого батьківського класу _перед_ виконанням логіки власного конструктора. Аргументи можна передати конструктору батьківського класу за допомогою ключового слова `base`:

```csharp
abstract class Vehicle
{
    protected Vehicle(int wheels)
    {
        Console.WriteLine("Called first");
    }
}

class Car : Vehicle
{
    public Car() : base(4)
    {
        Console.WriteLine("Called second");
    }
}
```

Коли від базового класу походять більше ніж один клас, ці два (або більше) класи часто реалізують різні версії методу базового класу. Це дуже важливий принцип, який називається поліморфізмом. Наприклад, у варіації наведеного вище прикладу ми показуємо, як код, що використовує `Vehicle`, може змінювати свою поведінку залежно від того, який тип транспортного засобу було створено.

```csharp
abstract class Vehicle
{
   public abstract string GetDescription();
}

class Car : Vehicle
{
   public Car()
   {
   }

   public override string GetDescription()
   {
      return "Runabout";
   }
}

class Rig : Vehicle
{
   public Rig()
   {
   }

   public override string GetDescription()
   {
      return "Big Rig";
   }
}

Vehicle v1 = new Car();
Vehicle v2 = new Rig();

v1.GetDescription();
// => Runabout
v2.GetDescription();
// => Big Rig
```
