# Вступ

`List` дуже схожий на `Array`. Однак є суттєві відмінності, які не варто пропускати:

1. Його не можна індексувати за допомогою квадратних дужок, тобто `[0]`.
2. Його не можна ініціалізувати.
3. Немає спискових включень.
4. Він може вільно змінювати елементи, коли ми перебираємо їх.

`List` є членом пакета `haxe.ds`, тому щоразу, коли ми хочемо використовувати його, потрібно імпортувати його пакет:

```haxe
import haxe.ds.List;

class Main {
  static function main() {
    var myList = List<Int>();

    for (i in 0...5) {
      myList.add(i);
    }

    trace(myList); // {0, 1, 2, 3, 4}
  }
}
```
