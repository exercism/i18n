# Інструкції

У цій вправі ми будемо обробляти рядки журналу.

Кожен рядок журналу - це рядок тексту (англ. string) такого формату: `"[<LEVEL>]: <MESSAGE>"`.

Існує три різні рівні журналу:

- `INFO`
- `WARNING`
- `ERROR`

На нас чекають три завдання, і кожне з них приймає рядок журналу та просить щось із ним зробити.

## 1. Отримати повідомлення з рядка журналу

Реалізуйте (_статичний_) метод `LogLine.Message()`, який повертає повідомлення з рядка журналу:

```csharp
LogLine.Message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

Усі пробіли на початку та в кінці потрібно прибрати:

```csharp
LogLine.Message("[WARNING]:  Disk almost full\r\n")
// => "Disk almost full"
```

## 2. Отримати рівень журналу з рядка журналу

Реалізуйте (_статичний_) метод `LogLine.LogLevel()`, який повертає рівень журналу з рядка журналу. Рівень потрібно повертати в нижньому регістрі:

```csharp
LogLine.LogLevel("[ERROR]: Invalid operation")
// => "error"
```

## 3. Переформатувати рядок журналу

Реалізуйте (_статичний_) метод `LogLine.Reformat()`, який переформатовує рядок журналу: спочатку йде повідомлення, а після нього в дужках - рівень журналу:

```csharp
LogLine.Reformat("[INFO]: Operation completed")
// => "Operation completed (info)"
```
