# Про рядки тексту

У Kotlin [`string`][ref-string], тобто рядок тексту (англ. string), - це незмінна послідовність символів Unicode.

[`Immutable`][wiki-immutable] означає, що будь-яка операція над рядком тексту має повертати новий рядок тексту: початковий рядок тексту ніколи не може змінитися.

[`Unicode`][wiki-unicode] означає, що більшість систем письма світу можна подати, але (на відміну від старіших мов, як-от C) однозначної відповідності між символами та байтами немає.
Докладніше про це йтиметься в концепції [`Chars`][concept-chars].

Рядок тексту беруть у подвійні лапки `" "`.

Деякі символи потрібно екранувати: `\\`, а також звичайні недруковані символи, як-от `\t` (табуляція) і `\n` (перехід на новий рядок).

```kotlin
val s = "Escape backslash \\."
// Escape backslash \.
```

Багаторядкові рядки тексту беруть у три подвійні лапки, і вони можуть містити довільний текст (екранувати не потрібно).

```kotlin
val multi = """I'm a
    multi-line
    string with special characters \ \t """
//I'm a
//    multi-line
//    string with special characters  \ \t 
```

Скористаймося [trimIndent][trimIndent-doc], щоб прибрати спільний відступ з усіх рядків.
Це зручно для форматування рядка тексту:

```kotlin
val multi = """
    I'm a
      multi-line
    string""".trimIndent()

//I'm a
//  multi-line
//string
```

Альтернативно, [trimMargin][trimMargin-doc] дає змогу задати роздільник.
Тоді кожен рядок у `String` починається після роздільника.
Типово роздільником є `|`, але можна задати інший роздільник як параметр.
Наприклад:

```kotlin
val multi = """
    |I'm a
    |  multi-line
    |string""".trimMargin()

//I'm a
//  multi-line
//string

val multi2 = """
    start>I'm a
    start>  multi-line
    start>string""".trimMargin("start>")

//I'm a
//  multi-line
//string
```

Рядки тексту можна зʼєднувати оператором `+`, але краще обмежитися короткими й простими випадками.
Є й інші, часто кращі варіанти.

## Шаблонні рядки

[`Templates`][ref-templates] - це те, що в деяких інших мовах називають «інтерполяцією».

Якщо рядок тексту містить знак долара `$`, після якого йде ідентифікатор, або містить фігурні дужки (`{expression}`) навколо виразу, то замість них підставляються відповідно значення або результат цього виразу.

```kotlin
val x = 42
val st = "x is $x, x squared is {x * x}"
// x is 42, x squared is 1764
```

## Форматування рядків

На платформі JVM (і лише там) `String.format()` дає змогу форматувати точніше, ніж шаблонні рядки, за допомогою [синтаксису][web-formats], подібного до (_дуже старих!_) функцій [`printf`][wiki-printf].

```kotlin
String.format("%s %.3f", "π ≈", 3.14159)
//π ≈ 3.142
```

## Функції для рядків

Kotlin надає _багато_ [`functions`][ref-string-functions] для роботи з рядками тексту.

Здебільшого це [`extensions functions`][ref-extensions], а не члени класу `String`, хоч це майже не впливає на те, як ми їх використовуємо.

~~~~exercism/note
Досить складні сторінки [документації][ref-string-functions] Kotlin ховають функції-розширення у типовому поданні.
На момент написання цього тексту найцінніший вміст сховано на вкладці `Members & Extensions`.
Натисніть її, щоб розгорнути цей розділ і побачити всі члени та розширення, доступні для класу `String`.

[ref-string-functions]: https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/
~~~~

У наступному прикладі показано лише невелику частину того, що доступно:

```kotlin
val str = "Hello World!"

str.length              // => 12 (a property, not a function)
str.elementAt(6)        // => W
str.elementAtOrNull(20) // => null (index out of range)
str.substring(6, 11)    // => "World"
str.substringAfter(" ") // => "World!"

str.lowercase()         // => "hello world!"
str.uppercase()         // => "HELLO WORLD!"

str.startsWith("Hel")   // => true
str.endsWith("xyz")     // => false
str.indexOf("0")        // => 4

str.toCharArray()       // => [H, e, l, l, o,  , W, o, r, l, d, !]
"42".toInt() + 1        // => 43  (parsing; see also toFloat)

"Howdy!  ".trim()       // => "Howdy"
```

## Побудова рядка тексту

Іноді довгий рядок тексту потрібно будувати поступово, наприклад усередині циклу.

Зʼєднувати рядки тексту через `+` швидко стає ані елегантним, ані продуктивним: незмінність означає, що потрібно _багато_ копіювання.

У Kotlin є кілька ефективніших способів поєднати кілька рядків тексту:

- Шаблонні рядки, описані вище.
- [`joinToString()][ref-jointostring], який ми розглянемо в концепції [Списки][concept-lists].
- [`StringBuilder`][ref-stringbuilder] із Java, який не вважають особливо ідіоматичним для Kotlin.
- [`buildString()`][ref-buildstring] із Kotlin, який загортає `StringBuilder` у лаконічніший та ідіоматичніший синтаксис.
Він приймає логіку побудови рядка як лямбда-аргумент, про який поговоримо в одній із наступних концепцій.

По суті, `StringBuilder` - це структура, схожа на масив, із багатьма зручними методами.
Ось невелика добірка:

- [`append()`][ref-sb-append] додає в кінець.
- [`insert()`][ref-sb-insert] додає в указану позицію.
- [`deleteAt()`][ref-sb-deleteat] і [`deleteRange()`][ref-sb-deleterange] видаляють із указаних позицій.
- `toString()` перетворює все на звичайний рядок тексту наприкінці: зʼєднує все за одну продуктивну операцію.

```kotlin
// Available, not recommended
val sb = StringBuilder()
sb.append("Hello ")
sb.append("World!")
sb.toString()
//Hello World!
```

Приклад із `buildString()`, який використовує синтаксис із наступних концепцій:

```kotlin
val countDown = buildString {
    for (i in 5 downTo 1) {
        append(i)
        append("_")
    }
}
// countDown is "5_4_3_2_1_"
```
