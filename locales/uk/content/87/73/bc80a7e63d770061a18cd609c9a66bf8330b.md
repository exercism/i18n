# Доповнення до інструкцій

## Слова

Визначте кортеж `rat` зі слотами `numerator` та `denominator`.
`<rat>` має зводити свої аргументи до нескоротного вигляду, зі
знаком у чисельнику (тож знаменник завжди додатний).

- `<rat> ( numerator denominator -- rat )`: будує зведений дріб.
- `>rat ( pair -- rat )`: будує `rat` з `{ numerator denominator }`.
- `rat>pair ( rat -- pair )`: повертає `{ numerator denominator }`.
- `r+ ( a b -- c )`, `r- ( a b -- c )`, `r* ( a b -- c )`,
  `r/ ( a b -- c )`: арифметика над двома раціональними дробами.
- `r-abs ( a -- |a| )`: абсолютне значення.
- `r^ ( a n -- a^n )`: підносить раціональне число до цілого степеня
  (відʼємні показники дозволені).
- `real^r ( x a -- y )`: підносить дійсне число до раціонального
  степеня і повертає число з плаваючою комою.

Родові слова `MATH:` у Factor (`+`, `-`, `*`, `/`) диспетчеризуються
лише за вбудованою математичною ієрархією, тож у цій вправі
використано окремі назви слів, а не методи цих родових слів.
