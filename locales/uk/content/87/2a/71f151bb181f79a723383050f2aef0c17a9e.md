# Інструкції

Наша ностальгія за картками Blorkemon™️ і не збирається вщухати: ми навіть знову почали їх збирати й залучаємо до цього друзів.

У цій вправі колекція карток представлена як `Set(String)`, адже коли мета - зібрати всі наявні картки, дублікати не мають значення.

## 1. Започаткуйте колекцію

Нам дуже хочеться, щоб друзі долучилися до нашого божевілля з Blorkemon™️, а найкращий спосіб - започаткувати їхню колекцію, подарувавши їм одну картку.

Реалізуйте `new_collection`, яка перетворює картку на колекцію.

```gleam
new_collection("Newthree")
// -> set.from_list(["Newthree"])
```

## 2. Розширте колекцію

Коли в нас уже є колекція, вона починає жити власним життям і мусить рости.

Реалізуйте `add_card`, яка приймає картку й колекцію та повертає кортеж із двох значень: `Bool`, що вказує, чи вже була картка в колекції, і колекцію з доданою карткою.

```gleam
add_card(set.from_list(["Newthree"]), "Scientuna")
// -> #(False, set.from_list(["Newthree", "Scientuna"]))
```

## 3. Почніть обмінюватися картками

Тепер, коли друзі знову божеволіють від Blorkemon™️, ми можемо примножити власну колекцію, обмінюючи картки.

Не кожен обмін вартий того, а деякі взагалі неможливі.
Не можна обміняти картку, якої в нас немає, і не варто віддавати картку за ту, яка в нас уже є.

Реалізуйте `trade_card`, яка приймає дві картки для обміну (нашу й чужу) та нашу поточну колекцію.
Повернене значення - кортеж із двох значень: `Bool`, який указує, чи обмін можливий і чи вартий він того, і колекція, яку ми отримали б у результаті обміну (навіть якщо насправді він неможливий).

```gleam
trade_card("Scientuna", "Newthree", set.from_list(["Scientuna"]))
// -> #(True, set.from_list(["Newthree"]))
```

## 4. Картки, які є в усіх

Ми з друзями, ентузіастами Blorkemon™️, збираємося разом і міркуємо, які картки найпоширеніші.

Реалізуйте `boring_cards`, яка приймає масив колекцій і повертає масив відсортованих карток, які є в усіх колекціях.

```gleam
boring_cards([set.from_list(["Scientuna"]), set.from_list(["Newthree", "Scientuna"])])
// -> ["Scientuna"]
```

## 5. Усі картки

Чи володіємо ми з друзями разом усіма картками Blorkemon™️?

Реалізуйте `total_cards`, яка приймає масив колекцій і повертає загальну кількість різних карток у всіх колекціях.

```gleam
total_cards([set.from_list(["Scientuna"]), set.from_list(["Newthree", "Scientuna"])])
// -> 2
```

## 6. Блискучі картки - це перемога

Наш племінник скоро приїде до нас у гості, і нам хочеться його вразити.
Діти ж люблять усе блискуче, правда?
Картки Blorkemon™️ бувають блискучими!

Реалізуйте `shiny_cards`, яка приймає колекцію й повертає множину, що містить усі картки, які починаються з `"Shiny "`.

```gleam
shiny_cards(set.from_list(["Newthree", "Scientuna", "Shiny Scientuna"]))
// -> set.from_list(["Shiny Scientuna"])
```
