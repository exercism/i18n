# Вступ

Це потенційно _величезна_ тема!
Про неї можна написати цілу книжку, і дехто вже це зробив (за пошуковим запитом «unicode book» на Amazon можна знайти кілька прикладів).

## Дуже коротка історія

Обробляти символи в компʼютерах було значно простіше в попередні десятиліття, коли програмісти вважали, що єдина важлива мова - англійська.
Отже: 26 літер у верхньому й нижньому регістрі, 10 цифр, кілька розділових знаків, плюс код (0x07), щоб продзвонити в дзвіночок, і все це вміщалося в 7 бітів: набір символів [ASCII][wiki-ascii].

Звісно, люди почали питати: а як же à, ä та Ł? Потім інші почали питати про ऄ, ஹ та ญ, а молодь захотіла емодзі 😱.
Що робити?

Якщо коротко, багато розумних і терплячих людей роками засідали в комітетах, опрацьовуючи деталі набору символів [Unicode][web-unicode] та таких кодувань, як [UTF-8][wiki-utf-8], а чимало програмного забезпечення потребувало _дуже_ складної переробки.
Крім того, було допущено багато нових помилок.

Щоб _усе_ не зламалося, дизайн Unicode/UTF-8 гарантує, що перші 127 кодів ідентичні ASCII _(навіть дзвіночок)_.

## Символи в Kotlin

Мови, створені приблизно після 2005 року, мають величезну перевагу: досить стабільний стандарт Unicode уже існував.

Kotlin (уперше випущений 2011 року) мав змогу припустити, що користувачі будуть використовувати різні (людські) мови й потребуватимуть Unicode, щоб їх виражати.

Символьні літерали записують в одинарних лапках, і вони відрізняються від рядків тексту (англ. string), записаних у подвійних лапках.
Для тих, хто прийшов зі світу C/C++, це, ймовірно, очевидно, а от програмістів Python і JavaScript це може заплутати.

```kotlin
val a = 'a'
a::class.qualifiedName  // => kotlin.Char
a.code  // => 97

val jha = 'झ'  // Devanagari alphabet
jha.code  // => 2333

val heart = '❤'  // heart emoji
heart.code  // => 10084

Char.MAX_VALUE.code  // => 65535 (64k, the largest code point allowed)
```

Перетворювати `Char` на `Int` і навпаки просто:

```kotlin
a.code  // => 97  (a.toInt() is deprecated)
Char(97) // => 'a'
```

Компілятор дозволяє _деякі_ форми цілочисельної арифметики над `Char`:

```kotlin
'a' + 5       // => 'f'
'c' - 'a'   // => 2
'c' + 'a'   // => error!

'f' + ('A' - 'a')  // => 'F' (same as 'f'.uppercase()

'f'.dec() // => 'e' (decrement)
'f'.inc() // => 'g' (increment)
```

## Деякі функції для `Char`

Як завжди, [функцій][ref-char-lib] тут надто багато, щоб розглянути їх усі, тож це лише добірка.

- Для відповідних алфавітів регістр можна змінити за допомогою [`uppercase()`][ref-uppercase] та [`lowercase()`][ref-lowercase].
- Перевірити регістр можна за допомогою [`isUpperCase()`][ref-isuppercase] та [`isLowerCase()`][ref-islowercase].
- Перевірити тип символу можна за допомогою:
    - [`isLetter()`][ref-isletter] охоплює багато алфавітів
    - [`isDigit()`][ref-isdigit] у діапазоні 0..9
    - `isLetterOrDigit()` поєднує два попередні
    - [`isWhitespace()`][ref-iswhitespace] будь-який пробільний символ

```kotlin
'झ'.isLetter()      // => true
'A'.isLowerCase()   // => false
'4'.isDigit()       // => true
'\t'.isWhitespace() // => true  (tab character)
```

## Перетворення між списком символів і рядком

Щоб перетворити рядок на список символів, можна скористатися `toList()`.

Щоб перетворити список символів на рядок, є функція [`joinToString()`][ref-jointostring], яка приймає розділювач (часто порожній рядок) як аргумент.

```kotlin
val kt = "kotlin".toList()  // => [k, o, t, l, i, n]
kt.joinToString("")   // => "kotlin"
kt.joinToString("_")  // => "k_o_t_l_i_n"
```

Зауважте, що `joinToString()` працює зі списком або масивом.
Щоб _привести_ окремий `Char` до рядка з одного символу, можна скористатися `toString()`.

```kotlin
'a'.toString() // => "a"
```

Щоб перевірити, чи присутній символ у `String`, списку або масиві `Char`, є `in`, який відповідає функції [`contains()`][ref-contains].

```kotlin
val clist = "kotlin".toList()  // => [k, o, t, l, i, n]
't' in clist     // => true
't' in "kotlin"  // => true
```
