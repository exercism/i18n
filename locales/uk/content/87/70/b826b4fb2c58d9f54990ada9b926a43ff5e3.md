# Інструкції

У нас знову насичена ніч на сортувальній станції в Антверпені. Сьогодні роль чергового диспетчера виконуємо ми: вантажні вагони, що прибувають, потрібно перегрупувати у поїзди на вихід, оглянути зчіпки, розділити маршрути на вузлах, а однакові вантажі обʼєднати для виставлення рахунків.

Кожен *вагон* - це рядок тексту (англ. string), що називає його вантаж: `"coal"`, `"timber"`, `"crates"` тощо.

## 1. Зчепити вагони в поїзди

Визначте `couple`, яка приймає масив вагонів і довжину `n`, та повертає поїзди по `n` вагонів, які не перекриваються. Останній поїзд може бути коротшим, якщо кількість не ділиться націло.

```factor
{ "coal" "coal" "coke" "ore" "ore" "timber" "timber" } 3 couple .
! => { { "coal" "coal" "coke" } { "ore" "ore" "timber" } { "timber" } }
```

## 2. Поглянути на зчіпки

Визначте `peek-couplings`, яка приймає масив вагонів і повертає кожну сусідню пару, щоб оглядач міг перевірити кожну зчіпку.

```factor
{ "coal" "ore" "timber" "crates" } peek-couplings .
! => { { "coal" "ore" } { "ore" "timber" } { "timber" "crates" } }
```

## 3. Розділити ланцюг за вузлами

Визначте `split-at-junctions`, яка приймає масив вагонів і масив `junctions` (вагонів, що позначають точку розриву), та повертає ділянки між вагонами-вузлами. Самі вагони-вузли до результату не входять.

```factor
{ "coal" "coal" "switch" "ore" "switch" "timber" }
{ "switch" } split-at-junctions .
! => { { "coal" "coal" } { "ore" } { "timber" } }
```

## 4. Обʼєднати однаковий вантаж

Визначте `coalesce-cargo`, яка приймає масив вагонів і групує *послідовні* вагони з однаковим вантажем у групи.

```factor
{ "coal" "coal" "ore" "ore" "ore" "timber" "coal" } coalesce-cargo .
! => { { "coal" "coal" } { "ore" "ore" "ore" } { "timber" } { "coal" } }
```
