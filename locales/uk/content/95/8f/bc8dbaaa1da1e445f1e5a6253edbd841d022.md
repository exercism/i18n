# Про

Визначення колекції зазвичай містить заповнювач у кутових дужках, часто T за домовленістю. Таку колекцію називають узагальненим типом. Це дає змогу користувачеві колекції вказати, який тип елементів зберігати в колекції. У наведеному вище прикладі коду ми створюємо екземпляр масиву рядків тексту (англ. string).

Клас або функцію роблять **узагальненими** за допомогою атрибута `@:generic`. Це змушує компілятор розпізнавати клас або функцію як узагальнені:

```haxe
@:generic
class MyValue<T> {
  public var value:T;

  public function new(value:T) {
    this.value = value;
  }
}

var a = MyValue<String>("Hello");
trace(a.value); // Hello
```
