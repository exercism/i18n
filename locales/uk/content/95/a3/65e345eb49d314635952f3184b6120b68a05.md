# Вступ

## Винятки

Винятки в C# забезпечують структурований, уніфікований і типобезпечний спосіб обробки помилкових ситуацій, що виникають під час виконання. Належна обробка винятків і помилок важлива, коли ми намагаємося запобігти збоям застосунку.

У C# усі винятки мають клас `System.Exception` як базовий тип. Він містить важливі властивості, як-от `Message`, що містить зрозумілий людині опис причини викидання винятку.

Щоб повідомити про помилку в певній частині коду, потрібно створити новий обʼєкт винятку, а потім викинути його за допомогою ключового слова `throw`:

```csharp
using System;
static int Square(int number)
{
    if (number >= 46341)
    {
        throw new ArgumentException($"Argument {number} cannot be higher than 46340 as its' square doesn't fit into int type.");
    }
    return number * number;
}
```

Коли виняток викидається, середовище виконання має знайти фрагмент коду, відповідальний за обробку цього винятку. Якщо відповідного обробника не знайдено, середовище виконання показує повідомлення про необроблений виняток і зупиняє виконання програми.

Щоб створити обробник для винятку, C# використовує конструкцію try-catch, яка складається з блоку `try` та однієї або кількох гілок `catch`. Блок `try` має містити й охороняти код, який може призвести до викидання винятку. Гілки `catch` мають містити код, який керує поведінкою програми після виникнення помилки. Важливо зауважити, що порядок винятків після блоку `try` має значення, оскільки коли перелічено кілька винятків, виконується перша відповідна гілка `catch`.

```csharp
try
{
   if (number == 42)
   {
       throw new ArgumentException("The number cannot be equal to 42.", "number");
   }

   if (number < 0)
   {
      throw new ArgumentOutOfRangeException("number", "The number cannot be negative.");
   }

    // Process number ...
}
catch (ArgumentOutOfRangeException e)
{
    Console.WriteLine($"Number is out of range: {e.Message}.");
}
catch (ArgumentException)
{
    Console.WriteLine("Invalid number.");
}
```
