# Про

Числа з плаваючою комою - це числа, які мають одну або більше цифр після десяткового розділювача.

```gleam
let float = 3.45
// -> 3.45
```

Числа з плаваючою комою також мають власний набір операторів.

```gleam
1.0 +. 1.4 // -> 2.4
5.0 -. 1.5 // -> 3.5
5.0 /. 2.0 // -> 2.5
3.0 *. 3.1 // -> 9.3

2.0 >. 1.0  // -> True
2.0 <. 1.0  // -> False
2.0 >=. 1.0 // -> True
2.0 <=. 1.0 // -> False
```

Символи підкреслення також можна додавати до чисел з плаваючою комою для наочності.

```gleam
1_000_000.0 // One million
```

З числами з плаваючою комою також можна використовувати науковий запис:

```gleam
1.01e3 // -> 1010
15.1e-3 // -> 0.0151
```
