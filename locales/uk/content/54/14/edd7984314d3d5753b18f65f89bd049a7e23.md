# Вступ

`String` у Julia - це рядок тексту (англ. string), тобто незмінна скінченна послідовність символів [Unicode](https://en.wikipedia.org/wiki/Unicode) у кодуванні [UTF-8](https://en.wikipedia.org/wiki/UTF-8).

Літерал `String` записують як послідовність символів у подвійних лапках:

```julia-repl
julia> "Christopher"
"Christopher"
```

Рядки тексту можна зʼєднувати за допомогою оператора `*`:

```julia-repl
julia> "Christopher" * " " * "Paolini"
"Christopher Paolini"
```

~~~~exercism/advanced
Якщо цікаво, чому Julia використовує `*`, а не `+` для конкатенації рядків, зазирніть до [посібника Julia](https://docs.julialang.org/en/v1/manual/strings/#man-concatenation).
~~~~

Деякі спеціальні символи потрібно екранувати, поставивши перед ними зворотну скісну риску:

```julia-repl
julia> println("\t or spaces?")
         or spaces?
```

Julia має багато корисних вбудованих функцій для роботи з рядками тексту:

```julia-repl
julia> lowercase("TEST")
"test"

julia> titlecase("TEST")
"Test"
```
