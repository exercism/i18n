# Вступ

Enum у Swift дають змогу створювати нові типи, які складаються зі скінченної кількості іменованих значень. Кожне з цих значень може нести додаткову повʼязану інформацію, а самі типи можуть мати приєднані властивості та методи.

## Визначення enum

Найпростіші enum визначають ось так.

```swift
enum NESButton {
  case up
  case down
  case left
  case right
  case a
  case b
  case select
  case start
}
```

Для стислості кілька варіантів можна записати в одному рядку, розділивши їх комами, з одним ключовим словом `case`.

```swift
enum NESButton {
  case up, down, left, right, a, b, select, start
}
```

Так ми визначаємо новий тип `NESButton`, значеннями якого можуть бути `up`, `down`, `left`, `right`, `a`, `b`, `select` і `start`. Щоб послатися на таке значення, після назви типу ставлять крапку (`.`) і саме значення. Якщо назву типу можна вивести з контексту, достатньо самої крапки та значення.

## Методи

Як і інші типи у Swift, enum можуть містити методи, які дають змогу надавати функціональність, спираючись на поточне значення enum.

Методи подібні до функцій, тільки визначені всередині тіла enum і привʼязані до поточного значення enum. До них звертаються через _точкову нотацію_: після назви значення enum ставлять крапку (`.`), а далі назву методу та його параметри.

Усередині методу на значення enum можна посилатися як на `self`, а в сигнатурі типу, якщо метод приймає параметр або повертає значення цього enum, на сам тип можна посилатися як на `Self`.

### Ініціалізатори

Ініціалізатори - це особливі методи, якими створюють значення enum. Їхнє визначення дуже схоже на визначення методу, тільки без ключового слова `func` і без типу повернення; назва має бути `init`, а ініціалізатор _обовʼязково_ має присвоїти `self` значення enum. Ініціалізатори викликають або через точкову нотацію, або передаючи параметри ініціалізатора у назву enum.

```swift
enum Coin {
  case heads
  case tails

  init(_ i: Int) {
    if i.isMultiple(of: 2) {
      self = .heads
    } else {
      self = .tails
    }
  }

  func flip() -> Self {
    switch self {
    case .heads: return .tails
    case .tails: return .heads
    }
  }
}

let tails = Coin.init(13)
// .tails
let heads = Coin(0)
// .heads
let anotherTails = heads.flip()
// .tails
```

### Сирі значення

Enum також можуть нести внутрішнє значення, відоме як _сире значення_. Усі сирі значення мають бути одного типу, який оголошують у визначенні enum. Тож ми могли б, наприклад, присвоїти enum `NESButton` значення типу Character, змінивши його визначення:

```swift
enum NESButton: Character {
  case up = "⬆️"
  case down = "⬇️"
  case left = "⬅️"
  case right = "➡️"
  case a = "🅰️"
  case b = "🅱️"
  case select = "✅"
  case start = "🚦"
}
```

Тут `: Character` повідомляє компілятору, що сирі значення матимуть тип `Character`, а присвоєння сирого значення йде після кожного варіанта.

До сирих значень можна дістатися через автоматично згенеровану властивість `rawValue` кожного варіанта.

```swift
NESButton.left.rawValue
// => "⬅️"
NESButton.b.rawValue
// => "🅱️"
```

Swift може неявно присвоювати сирі значення для типів `String` і `Int`. Якщо вказано тип сирого значення `String`, сирим значенням неявно стане назва варіанта як рядок тексту (англ. string), якщо тільки неявне значення не перекрити явним присвоєнням.

Якщо вказано тип сирого значення `Int`, сирим значенням неявно стане ціле число на 1 більше за сире значення попереднього варіанта, якщо його не перекрити явним присвоєнням. Якщо не вказано іншого, перший варіант типово отримує сире значення 0.

```swift
enum Coin: String {
  case heads
  case tails = "eagle"
}

Coin.heads.rawValue
// => "heads"
Coin.tails.rawValue
// => "eagle"

enum Dwarf: Int {
  case grumpy, sleepy, sneezy, happy = 8, bashful, dopey, doc
}

Dwarf.grumpy.rawValue
// => 0
Dwarf.sneezy.rawValue
// => 2
Dwarf.happy.rawValue
// => 8
Dwarf.bashful.rawValue
// => 9
```
