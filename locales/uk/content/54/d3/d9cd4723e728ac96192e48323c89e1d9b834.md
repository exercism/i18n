# Докладніше

У Gleam вираз `case` можна використати для умовного виконання коду. За допомогою виразу case значення можна зіставити з одним або кількома _зразками_. Прикладом такого зразка є _літеральний зразок_, який зіставляє значення з літеральним значенням (наприклад, `1` або `"hello"`).

Вирази case записуються за допомогою ключового слова `case`:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    1 -> "One"
  }
}
```

Хоча це може мати вигляд інструкцій `switch` в інших мовах, зіставлення зі зразками розкривається повною мірою тоді, коли ми використовуємо й інші зразки. Один із таких зразків - _зразок-змінна_, який дає змогу присвоїти значення змінній. У цьому прикладі змінній `i` буде присвоєно значення `number`, якщо воно не дорівнює `0`:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i -> "Non zero"
  }
}
```

У деяких випадках може знадобитися додати до зразка додаткову умову. Це називається _сторожовою умовою_, яку можна додати за допомогою ключового слова `if`:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
  }
}
```

З міркувань продуктивності у сторожових умовах дозволені лише базові математичні та булеві оператори; інші функції в сторожових умовах використовувати не можна.

У наведеному вище прикладі не для всіх можливих вхідних даних знайдеться відповідний зразок. Компілятор це виявить і видасть помилку. Це називається _вичерпною перевіркою_. Щоб позбутися попередження, треба обробити всі випадки. Для цього можна використати _зразок-ігнорування_, який зіставляється з будь-яким значенням:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
    _ -> "Positive number"
  }
}

// No compiler error
```

Вирази case зіставляють значення з кожним зразком згори донизу, доки не знайдуть відповідний зразок і не виконають логіку, повʼязану з цим зразком. Порядок зразків має значення!
