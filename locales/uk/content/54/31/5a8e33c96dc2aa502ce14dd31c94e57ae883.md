# Докладніше

Хоча модифікатор `readonly` запобігає перезаписуванню значення або посилання в полі, він не надає захисту членам типу посилання.

```csharp
readonly List<int> ints = new List<int>();

void Foo()
{
    ints.Add(1);    // ok
    ints = new List<int>(); // fails to compile
}
```

Щоб захистити всі члени типу посилання, поля можна зробити `readonly`, а автоматичні властивості можна визначити без методу доступу `set`.

Бібліотека базових класів (BCL) надає деякі версії колекцій, доступні лише для читання, коли є потреба запобігти оновленню членів колекції. Вони мають вигляд обгорток:

- [`ReadOnlyDictionary<T>`][ReadOnlyDictionary]
- [`ReadOnlyCollection<T>`][ReadOnlyCollection]

[ReadOnlyDictionary]: https://docs.microsoft.com/en-us/dotnet/api/system.collections.objectmodel.readonlydictionary-2
[ReadOnlyCollection]: https://docs.microsoft.com/en-us/dotnet/api/system.collections.objectmodel.readonlycollection-1
