# Вступ

## Оператори порівняння

Оператори порівняння схожі на ті, що є в багатьох інших мовах.

Для перевірки рівності використовуються оператори `==` (дорівнює) та `!=` (не дорівнює).

```Kotlin
val txt = "abc"
txt == "abc" // => true
txt != "abc" // => false
```

Оператори «більше/менше» теж цілком звичні.

```Kotlin
1 < 3 // => true
3 > 3 // => false
3 <= 3 // => true
4 >= 3 // => true
```

## Розгалуження з `if`

Це повна форма виразу `if`:

```Kotlin
if (conditional1) {
//    something...
} else if (conditional2) {
//    something...
} else {
//    something...
}
```

- Дужки `()` навколо кожної умови обовʼязкові.
- Умова має набувати булевого значення (англ. Boolean) `true` або `false`.
  У Kotlin немає поняття «truthy» та «falsy», як у деяких інших мовах.
- Фігурні дужки `{}` необовʼязкові, якщо вираз лише один.
- І `else if`, і `else` необовʼязкові, а блоків `else if` може бути кілька.

Вираз `if` також можна використати, щоб «вибрати» значення:

```Kotlin
val number = 100000
val description = if (number > 100) "number is over 100" else "number is less than 100"
// => description = "number is over 100"
```

## Альтернативи?

Свідомим рішенням у Kotlin _немає_ тернарного оператора `? :`, який є в Java.
Замість нього віддають перевагу стислій формі `if ... else`:

```Kotlin
return if (isOK) goodValue else badValue
```
