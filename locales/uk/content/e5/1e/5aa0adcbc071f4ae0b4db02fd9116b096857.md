# Доповнення до інструкцій

~~~~exercism/note

В описі вище згадуються [_математичні множини_][math-sets], а також те, що піфагорова трійка {a, b, c} _**обовʼязково**_ має бути впорядкована так, щоб a < b < c (_у порядку зростання_). 

Це робить тип [`set`][python-sets] у Python непридатним для цієї вправи, оскільки він за своєю природою _невпорядкований_. 
Поверніть натомість [`list`][python-list], що складається з `list`-ів (_наприклад, `[[a, b, c]]`_). 
Можна генерувати самі трійки в будь-якому порядку, оскільки в тестах порядок зовнішнього `list` не буде враховуватися. 

[math-sets]: https://en.wikipedia.org/wiki/Set_(mathematics)
[python-sets]: https://docs.python.org/3/tutorial/datastructures.html#sets
[python-list]: https://docs.python.org/3/tutorial/datastructures.html#more-on-lists
