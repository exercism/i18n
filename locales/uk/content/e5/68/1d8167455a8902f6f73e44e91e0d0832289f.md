# Тести

Для кожного прикладу потрібно виконати такі загальні кроки.

Спочатку перейдіть до каталогу вправи, яку ми хочемо відпрацювати, у цьому
випадку `bob`.

```bash
$ cd </path/to/exercism>/lfe/bob
```

Далі запустіть тести. Ціль `test` у make залежить від `compile`,
тому запуск `make test` спершу скомпілює наш код,
 а потім виконає тести.


```bash
$ make test
```

Вітаємо! У нас падають тести!!!

Тепер прочитайте `README.md`, щоб дізнатися, що потрібно зробити, аби всі
тести пройшли.


Виправте першу помилку, яку повідомив тест, і знову запустіть тести.

```bash
$ make test
```

Продовжуйте: виправляйте наступний тест, що падає, у своєму коді та
запускайте тести, доки всі вони не пройдуть.

Коли всі тести пройдуть, востаннє перегляньте код у каталозі `src`,
щоб переконатися, що він нас влаштовує, і надішліть його на перевірку.

Отримайте відгук, доопрацюйте рішення, надішліть його, візьміться за наступну
вправу і повторюйте все це, доки не досягнете просвітлення в LFE.
