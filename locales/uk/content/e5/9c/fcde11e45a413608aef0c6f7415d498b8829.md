# Про

У Go функції є значеннями першого класу.
Це означає, що з функціями можна робити те саме, що й з усіма іншими значеннями: присвоювати функції змінним, передавати їх як аргументи іншим функціям або навіть повертати функції з інших функцій.

Нижче ми створюємо дві функції, `engGreeting` і `espGreeting`, і присвоюємо їх змінній `greeting`:

```go
import "fmt"

func engGreeting(name string) string {
	return fmt.Sprintf("Hello %s, nice to meet you!", name)
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := engGreeting			// greeting is a variable of type func(string) string
fmt.Println(greeting("Alice"))	// Hello Alice, nice to meet you!

greeting = espGreeting
fmt.Println(greeting("Alice")) 	// ¡Hola Alice, mucho gusto!
```

Функціональні значення дають змогу параметризувати функції не лише даними, а й поведінкою.
У наступному прикладі ми передаємо поведінку функції `dialog` через параметр `greetingFunc`:

```go
func dialog(name string, greetingFunc func(string) string) {
	fmt.Println(greetingFunc(name))
	fmt.Println("I'm a dialog bot.")
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := espGreeting
dialog("Alice", greeting)
// Output:
// ¡Hola Alice, mucho gusto!
// I'm a dialog bot.
```

Значення неініціалізованої змінної функціонального типу дорівнює `nil`.
Тому виклик функціонального значення `nil` спричиняє паніку.

```go
var dutchGreeting func(string) string
dutchGreeting("Alice") // panic: call of nil function
```

Функціональні значення можна порівнювати з `nil`.
Це може стати в пригоді, щоб уникати зайвих панік у програмі.

```go
var dutchGreeting func(string) string
if dutchGreeting != nil {
	dutchGreeting("Alice") // safe to call dutchGreeting
}
```

## Типи функцій

Використовувати функціональні значення можливо завдяки типам функцій у Go.
Тип функції позначає множину всіх функцій з однаковою послідовністю типів параметрів і однаковою послідовністю типів результатів.
На основі типів функцій можна оголошувати власні типи.
Наприклад, функцію `dialog` з попередніх прикладів можна оновити так:

```go
type greetingFunc func(string) string

func dialog(name string, f greetingFunc) {
	fmt.Println(f(name))
	fmt.Println("I'm a dialog bot.")
}
```

## Анонімні функції

Ще одним потужним інструментом, доступним завдяки підтримці функцій першого класу, є анонімні функції.
Анонімні функції визначаються в місці використання, без імені після ключового слова `func`.
Такі функції мають доступ до змінних зовнішньої функції.

Наприклад:

```go
func fib() func() int {
	var n1, n2 int

	return func() int {
		if n1 == 0 && n2 == 0 {
			n1 = 1
		} else {
			n1, n2 = n2, n1 + n2
		}
		return n2
	}
}

next := fib()
for i := 0; i < N; i++ {
  fmt.Printf("F%d\t= %4d\n", i, next())
}
```

Виклик `fib` оголошує змінні `n1` і `n2` та повертає анонімну функцію, яка, своєю чергою, змінює значення цих змінних щоразу, коли функцію викликають.
N-ні виклики анонімної функції повертають N-те число послідовності Фібоначчі, починаючи з 0. Внутрішня анонімна функція має доступ до локальних змінних (`n1` і `n2`) зовнішньої функції `fib`.
Це чудовий спосіб досягти того, щоб функціональні значення зберігали стан між викликами.
Кажуть, що анонімна функція є замиканням змінних `n1` і `n2`.
[Замикання][closure] широко використовують у програмуванні, і можна побачити, що інші мови їх підтримують.

[closure]: https://en.wikipedia.org/wiki/Closure_(computer_programming)
