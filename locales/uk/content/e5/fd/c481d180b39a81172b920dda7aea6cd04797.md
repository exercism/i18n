# Вказівки

У цій вправі ми реалізуємо логіку квесту для нової рольової гри, яку розробляє друг. Головна героїня гри - Анналін, відважна дівчина з грізним і відданим псом. На жаль, трапляється лихо: її найкращу подругу викрали, коли вона шукала в лісі ягоди. Анналін спробує знайти і визволити свою найкращу подругу, можливо, взявши із собою в цей квест свого пса.

Провівши деякий час, ідучи слідом за найкращою подругою, вона знаходить табір, де ту тримають у полоні. Виявляється, викрадачів двоє: могутній лицар і хитрий лучник.

Знайшовши викрадачів, Анналін міркує, які з наведених дій вона може вчинити:

- Швидка атака: швидку атаку можна здійснити, якщо лицар спить, бо йому потрібен час, щоб вдягнути обладунки, тож він буде вразливим.
- Шпигунство: за групою можна шпигувати, якщо принаймні один із них не спить. Інакше шпигувати - лише марно витрачати час.
- Подати сигнал полоненій: полоненій можна подати сигнал за допомогою пташиних звуків, якщо полонена не спить, а лучник спить, бо лучники вміють розпізнавати пташині сигнали, тож могли б перехопити повідомлення.
- _Визволити полонену_: Анналін може спробувати потай пробратися до табору, щоб визволити полонену.
  Це ризикована справа, і вона може вдатися лише одним із двох способів:
  - Якщо з Анналін є її пес, вона може врятувати полонену, якщо лучник спить.
    Лицар боїться пса, а лучник не встигне приготуватися, перш ніж Анналін і полонена втечуть.
  - Якщо пса з Анналін немає, то їй і полоненій доведеться діяти дуже потай!
    Анналін може визволити полонену, якщо полонена не спить, а лицар і лучник обоє сплять, але якщо полонена спить, її не врятувати: вона злякалася б раптової появи Анналін і розбудила б лицаря та лучника.

У нас чотири завдання: реалізувати логіку, яка визначає, чи доступні наведені дії, залежно від стану трьох персонажів, знайдених у лісі, та від того, чи присутній з Анналін її пес.

## 1. Перевірте, чи можна здійснити швидку атаку

Реалізуйте метод `canFastAttack()`, який приймає булеве значення (англ. Boolean), що вказує, чи не спить лицар. Цей метод повертає `true`, якщо швидку атаку можна здійснити залежно від стану лицаря. Інакше повертає `false`:

```kotlin
val knightIsAwake = true

canFastAttack(knightIsAwake)
// => false
```

## 2. Перевірте, чи можна шпигувати за групою

Реалізуйте метод `canSpy()`, який приймає три булеві значення, що вказують відповідно, чи не сплять лицар, лучник і полонена. Метод повертає `true`, якщо за групою можна шпигувати, залежно від стану трьох персонажів. Інакше повертає `false`:

```kotlin
val knightIsAwake = false
val archerIsAwake = true
val prisonerIsAwake = false

canSpy(knightIsAwake, archerIsAwake, prisonerIsAwake)
// => true
```

## 3. Перевірте, чи можна подати сигнал полоненій

Реалізуйте метод `canSignalPrisoner()`, який приймає два булеві значення, що вказують відповідно, чи не сплять лучник і полонена. Метод повертає `true`, якщо полоненій можна подати сигнал, залежно від стану двох персонажів. Інакше повертає `false`:

```kotlin
val archerIsAwake = false
val prisonerIsAwake = true

canSignalPrisoner(archerIsAwake, prisonerIsAwake)
// => true
```

## 4. Перевірте, чи можна визволити полонену

Реалізуйте метод `canFreePrisoner()`, який приймає чотири булеві значення. Перші три параметри вказують відповідно, чи не сплять лицар, лучник і полонена. Останній параметр вказує, чи присутній пес Анналін. Метод повертає `true`, якщо полонену можна визволити, залежно від стану трьох персонажів і присутності пса Анналін. Інакше повертає `false`:

```kotlin
val knightIsAwake = false
val archerIsAwake = true
val prisonerIsAwake = false
val petDogIsPresent = false

canFreePrisoner(knightIsAwake, archerIsAwake, prisonerIsAwake, petDogIsPresent)
// => false
```
