# Докладніше

Звʼязування описує, з якого місця коду можна отримати доступ до ідентифікатора.
Значення з областю видимості блоку, функції або прототипу функції не мають звʼязування.
Це означає, що до них не можна отримати доступ ззовні їхньої області видимості.
Докладніше про область видимості див. [концепцію області видимості](../scope/introduction.md#Introduction).

## Зовнішнє звʼязування

Ідентифікатори з областю видимості файлу типово мають зовнішнє звʼязування.
Ідентифікатор із зовнішнім звʼязуванням можна викликати з будь-якого файлу програми.

## Внутрішнє звʼязування

Ідентифікатору з областю видимості файлу можна надати внутрішнє звʼязування за допомогою специфікатора `static`.
Ідентифікатор із внутрішнім звʼязуванням можна використовувати лише в межах його файлу.

Наприклад

```c
int public_count = 0; // file scope, external linkage by default
static int private_count = 0;  // file scope, internal linkage 

// file scope, internal linkage
static void some_function()
{
    // code snipped
}

// file scope, external linkage by default
int main()
{
    // code snipped
}
```

Статичне звʼязування не слід плутати зі статичною тривалістю зберігання.
Докладніше про статичну тривалість зберігання див. [концепцію тривалості зберігання](https://github.com/exercism/c/blob/main/concepts/storage-class-specifiers/about.md#static-the-storage-specifier-not-to-be-confused-with-the-static-linkage-type).

Якщо значення (на відміну від функції) оголошено в заголовному файлі, але визначено у вихідному файлі як `static`-ідентифікатор з областю видимості файлу з ініціалізованим значенням, то його ініціалізоване значення не буде доступним ззовні його вихідного файлу.
Воно може скомпілюватися, злінкуватися й запуститися без помилки, але значенням ідентифікатора буде нульове значення, навіть якщо його оголошено з `extern`.
(Докладніше про `extern` див. [концепцію `extern`](https://github.com/exercism/c/blob/main/concepts/storage-class-specifiers/about.md#extern-how-to-access-a-variable-in-another-translation-unit).)
Ідентифікатор з областю видимості файлу, позначений як `static` у вихідному файлі, не слід оголошувати в його заголовному файлі.
