# Вступ

## Загальний синтаксис

Цикл `for` - одна з найпоширеніших інструкцій для багаторазового виконання якоїсь логіки.
У Go він складається з ключового слова `for`, заголовка та блоку коду, який містить тіло циклу, укладене у фігурні дужки.
Заголовок складається з трьох компонентів, розділених крапками з комою `;`: init, умова та post.

```go
for init; condition; post {
  // loop body - code that is executed repeatedly as long as the condition is true
}
```

- Компонент **init** містить код, який виконується лише один раз, перед початком циклу.
- Компонент **умова** має бути виразом, який обчислюється в булеве значення (англ. Boolean) і визначає, коли цикл має зупинитися.
  Код усередині циклу буде виконуватися, доки ця умова дає правду.
  Щойно цей вираз дасть неправду, жодна наступна ітерація циклу не виконається.
- Компонент **post** містить код, який виконується наприкінці кожної ітерації.

**Зауваження:** На відміну від інших мов, три компоненти заголовка не оточені круглими дужками (`()`).
Насправді, такі дужки призведуть до помилки компіляції.
Однак фігурні дужки (`{ }`) навколо тіла циклу потрібні завжди.

## Цикли `for`: приклад

Компонент **init** зазвичай створює змінну-лічильник, компонент **умова** перевіряє, чи продовжувати цикл чи зупинити його, а компонент **post** зазвичай збільшує лічильник наприкінці кожного повторення.

```go
for i := 1; i < 10; i++ {
  fmt.Println(i)
}
```

Цей цикл виведе числа від `1` до `9` (включно з `9`).
Крок часто задають інструкцією інкременту або декременту, як показано в прикладі вище.
