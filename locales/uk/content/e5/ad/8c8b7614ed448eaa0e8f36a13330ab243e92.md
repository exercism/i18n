# Тести

Виконайте тести за допомогою:

```shell
npm run test
```

Також можна запустити Jest у режимі «watch», який автоматично перезапускатиме тести, коли ми зберігаємо зміни в коді або тестовому модулі:

```shell
npm run watch
```

## Розуміння пропущених тестів

Метод skip вказує набору тестів не запускати тест; цей метод також можна використовувати під такими псевдонімами: `it.skip(name, fn)` або `xit(name, fn)` або `xtest(name, fn)`

- Чому їх пропускають?

Щоб дати змогу зосередитися на одному тесті за раз і вмикати їх по одному в міру того, як ми розвиваємо рішення.

- Як їх увімкнути?

Змініть `xtest` на `test`.

```javascript
test("title cased phrases", () => {
  expect(Acronyms.parse("Portable Network Graphics")).toEqual("PNG");
});
```
