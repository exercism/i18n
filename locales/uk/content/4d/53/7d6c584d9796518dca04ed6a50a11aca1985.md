# Встановлення

## Ubuntu (і більшість інших дистрибутивів на основі Debian)

Щоб збирати код локально, нам знадобляться gcc і make, які можна встановити за допомогою

```shell
sudo apt install gcc make
```

Якщо ми не працюємо на обладнанні ARM64, встановіть емулятор [QEMU][] і крос-інструментарій GCC ARM64 за допомогою

```shell
sudo apt install qemu-user libc6-dev-arm64-cross gcc-aarch64-linux-gnu
```

## Windows

Використайте [Windows Subsystem for Linux][] з дистрибутивом на основі Debian і дотримуйтесь інструкцій для Ubuntu, наведених вище.
Або налаштуйте віртуальну машину Linux.

## macOS

Віртуальну машину Linux можна запустити за допомогою будь-якого відповідного рішення для віртуалізації (наприклад, [Lima][]).

[QEMU]: https://www.qemu.org/
[Windows Subsystem for Linux]: https://docs.microsoft.com/en-gb/windows/wsl/about
[Lima]: https://lima-vm.io/
