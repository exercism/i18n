# Вступ

## Функції зворотного виклику

Функції зворотного виклику - це функції, які передають як аргументи.
Цей прийом програмування створює послідовність викликів функцій як у синхронному, так і в асинхронному програмуванні.
Написати функцію зворотного виклику нічим не відрізняється від написання звичайної функції; однак функція зворотного виклику має відповідати сигнатурі, яку визначає функція, що її викликає.

```javascript
const squareLength = 5;

// Caller function takes a callback function
function applyToSquare(callback) {
  return callback(squareLength);
}

// Callback must expect the possible argument from the calling function
function areaOfSquare(number) {
  return number * number;
}

applyToSquare(areaOfSquare); // => 25
```

Функції зворотного виклику також можна записати як функціональний вираз, анонімний функціональний вираз або стрілковий функціональний вираз:

```javascript
applyToSquare(function squarePerimeter(side) {
  return side * 4;
});

applyToSquare(function (side) {
  return side * 4;
});

applyToSquare((side) => {
  return side * 4;
});
```
