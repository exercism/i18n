# Вступ

У кожного екземпляра структури чи класу є неявне значення з назвою `self`, яке вказує на сам цей екземпляр. У `self` є кілька застосувань, але найчастіше його використовують, щоб розрізнити назви властивостей і методів структури чи класу, коли може виникнути плутанина.

```swift
struct MySelf {
  var x = 0

  mutating func move(x: Int) {
    // here if we just say x = x it is unclear if we mean
    // the property x or the method parameter x, so we use
    // self for clarity
    self.x = x
  }
}
```
