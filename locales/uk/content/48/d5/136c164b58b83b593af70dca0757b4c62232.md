# Тести

Встановіть залежності.

```sh
dart pub get
```

Запустіть тести.

```sh
dart test
```

Щоб отримати докладніший вивід по кожному тесту, скористайтеся розширеним репортером.

```sh
dart test -r expanded
```

У більшості вправ є кілька тестів, і всі, крім першого, типово пропущені.
Щоб проходити тести по одному, змінюйте `skip: true` на `skip: false` у кожному тесті в міру просування.

Або ж запустіть усі тести одразу, не редагуючи файл.

```sh
dart test --run-skipped
```

Усі тести запускає онлайн-ранер тестів під час подання, зокрема й пропущені.
