# Основи

Детальнішу інформацію про ці теми можна знайти на [сторінці концепції][exercism-concept].

## Загальний синтаксис

Відкривальний тег PHP `<?php` позначає початок коду PHP.
Усі інструкції мають завершуватися символом `;` для розділення інструкцій.

```php
<?php

$message = "Success!"; // Statement correctly ends with `;`
$message = "I fail." // PHP Parse error: syntax error, [...]
```

Для легшого читання всі приклади коду опускають відкривальний тег PHP `<?php`.

## Коментарі

Однорядкові коментарі починаються з `//`.

```php
// Single line comment
```

## Значення та змінні

За допомогою оператора присвоєння `=` значення можна присвоїти змінній.
Назви змінних мають починатися зі знака долара `$` і відповідати [правилам найменування][exercism-concept-naming-conventions].

```php
$count = 1; // Assign value of 1

// Strings can be created by enclosing the characters
// within single `'` quotes or double `"` quotes.
$message = "Success!";
```

## Функції та методи

Значення та змінні можна передавати у функції.
Аргументи функції стають новими змінними, які зберігають передані значення.
Функції можуть повертати будь-яке значення за допомогою ключового слова `return`.

```php
function window_height($height)
{
    return $height + 10;
}

window_height(100);
// => 110
```

Функції всередині класів та їхніх екземплярів називаються методами.
Щоб викликати метод, перед назвою ставлять екземпляр і `->`.
Методи мають доступ до спеціальної змінної `$this`, яка вказує на поточний екземпляр.

```php
<?php

class Calculator {
    public function sub($x, $y)
    {
        return $this->add($x, -$y); // Calls the method add() of the current instance
    }

    public function add($x, $y)
    {
        return $x + $y;
    }
}

$calculator = new Calculator(); // Creates a new instance of Calculator class
$calculator->sub(3, 1); // Calls the method sub() of the instance stored in $calculator
// => 2
```
