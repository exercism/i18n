# Вступ

## Стрілкові функції

Крім оголошень функцій і функціональних виразів, у JavaScript є ще один дуже стислий синтаксис для визначення функції.
Такі функції називають _стрілковими функціями_.

Порівняймо оголошення функції та стрілкову функцію.

```javascript
function addUpTwoNumbers(num1, num2) {
  return num1 + num2;
}
// function keyword removed and => added
const addUpTwoNumbers = (num1, num2) => {
  return num1 + num2;
};
```

Якщо тіло функції містить лише інструкцію `return`, як у прикладі вище, то `{}` і ключове слово `return` можна опустити.
Якщо параметр лише один, дужки `()` теж можна опустити.

<!-- prettier-ignore-start -->
```javascript
const addUpTwoNumbers = (num1, num2) => num1 + num2;
const square = num => num * num;
```
<!-- prettier-ignore-end -->

Стрілкові функції часто використовують, щоб визначити короткі колбек-функції безпосередньо у виклику функції.

<!-- prettier-ignore-start -->
```javascript
applyToSquare(number => number * number);
```
<!-- prettier-ignore-end -->

## Аналіз масивів

[Масиви][arrays-concept] мають вбудовані методи для аналізу вмісту масиву.
Більшість із цих методів приймає функцію, яка повертає true або false, як аргумент.
Таку функцію називають [`predicate`][predicate_in_programming].

Ці вбудовані методи призначені для використання _замість циклу `for`_ або вбудованого методу `forEach`:

Приклад аналізу з використанням циклу `for`:

```javascript
const numbers = [1, 'two', 3, 'four'];
for (var i = 0; i < numbers.length; i++) {
  if (numbers[i] === 'two') {
    return i;
  }
}
// => 1
```

Приклад аналізу з використанням вбудованого методу:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.indexOf('two');
// => 1
```

Нижче показано деякі інші корисні вбудовані методи, доступні для аналізу масиву.
Повний перелік методів масиву можна знайти в [MDN][mdn-array-methods].

### `includes`

Метод `includes(value)` визначає, чи містить масив певне значення.
Він повертає `true`, якщо значення присутнє, і `false` в іншому разі.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.includes(1);
// => true
numbers.includes('one');
// => false
```

### `every`

Метод `every(predicate)` приймає функцію, яка є _предикатом_.
Він перевіряє, чи всі елементи масиву повертають `true`, коли їх передати предикату.
Іншими словами, метод перевіряє, що всі його елементи проходять перевірку, передану у виклик функції.
Він повертає `true`, коли кожен елемент проходить перевірку предиката, і `false` в іншому разі.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.every((num) => num % 2 !== 0);
// => true
```

### `some`

Метод `some(predicate)` такий самий, як метод `every`, але повертає `true`, якщо принаймні один елемент масиву проходить перевірку _предиката_.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.some((num) => num % 2 !== 0);
// => true
```

### `find`

Метод `find(predicate)` повертає значення першого елемента масиву, який проходить перевірку `predicate`.
Там, де `some()` повертає `true`, коли перевірка проходить, `find()` повертає саме значення з масиву.
Метод повертає `undefined`, коли жоден елемент масиву не проходить перевірку _предиката_.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.find((num) => num < 5);
// => 1
```

### `findIndex`

Метод `findIndex(predicate)` такий самий, як метод `find()`, але повертає (перший) _індекс_ елемента, який проходить перевірку _предиката_, а не `value`.
Метод повертає `-1`, коли жоден елемент масиву не проходить перевірку _предиката_.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.findIndex((num) => num > 7);
// => 4
numbers.findIndex((num) => num > 9);
// => -1
```
