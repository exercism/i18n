# Інструкції

Ми обслуговуємо станцію обробки мережі сейсмографів - датчиків, які записують, як рухається земля.

Показники надходять блоками значень.
Одні з них - зміщення ґрунту, збережені як 32-бітні числа з плаваючою комою, інші - необроблені відліки та слова стану, збережені як 32-бітні цілі числа.
Станція обробляє весь блок одразу, застосовуючи ту саму операцію до кожного значення.

У нас шість завдань, і кожне з них працює з блоком значень, що лежить у памʼяті.
Операнди ми отримуємо через адреси памʼяті, а відповідь записуємо через адресу результату.
Усі адреси памʼяті в цій вправі вирівняно на 16 байтів.

~~~~exercism/note
Обчислення в цій вправі слід виконувати за допомогою порозрядних SIMD-операцій і зсувів, а не скалярних операцій.
~~~~

## 1. Випрямити трасу

Для аналізу амплітуди важливий лише розмір кожного зміщення ґрунту, а не його напрямок.
На першому кроці обробки ми зводимо кожен показник до невідʼємного значення.

Реалізуйте функцію `rectify_trace`, яка обчислює абсолютне значення кожного показника.
Блок містить 4 показники, кожен з яких - 32-бітне число з плаваючою комою.

Функція приймає такі аргументи в такому порядку:

- `result`: адреса памʼяті для буфера, куди записуються 4 випрямлені показники.
- `trace`: адреса памʼяті записаних показників, що містить 4 значення, кожне з яких - 32-бітне число з плаваючою комою.

```c
trace  = {1.5, -2.25, 0.0, -135.75}
result = {1.5,  2.25, 0.0,  135.75}
```

Функція не повертає значення.

## 2. Зчитати масштаб поштовху

Аналітики оцінюють поштовхи за степенем двійки: показник, близький до `8.0`, має масштаб `3`, а показник, близький до `0.25`, має масштаб `-2`.
Цей масштаб уже збережено всередині кожного числа з плаваючою комою, у полі його експоненти.

32-бітне число з плаваючою комою складається з біта знака в біті 31, 8-бітної експоненти в бітах з 30 по 23 і 23-бітної мантиси в бітах з 22 по 0.
Збережена експонента зміщена на 127, тож значення числа дорівнює `(-1)^sign * 1.fraction * 2^(exponent - 127)`.

Реалізуйте функцію `reading_scale`, яка видобуває незміщену експоненту кожного показника як знакове 32-бітне ціле число.

Функція приймає такі аргументи в такому порядку:

- `result`: адреса памʼяті для буфера, куди записуються 4 масштаби, кожен - знакове 32-бітне ціле число.
- `trace`: адреса памʼяті випрямлених показників, що містить 4 значення, кожне з яких - 32-бітне число з плаваючою комою.

```c
trace  = {8.0, 0.25, 1.0, 13.5}
result = {  3,   -2,   0,   3}
```

Функція не повертає значення.
Усі показники - нормальні ненульові числа з плаваючою комою.

## 3. Згрубити роздільну здатність

Для довготривалого зберігання необроблені відліки зміщення зберігаються з грубішою роздільною здатністю: кожен відлік ділиться на степінь двійки.

Відліки зміщення - знакові: земля може рухатися в обидва боки.
Щоб поділити їх правильно, потрібен зсув, який зберігає знак.

Реалізуйте функцію `coarsen_displacements`, яка ділить кожен знаковий відлік на `2^shift`, округлюючи в бік мінус нескінченності.

Функція приймає такі аргументи в такому порядку:

- `result`: адреса памʼяті для буфера, куди записуються 4 згрублені відліки, кожен - знакове 32-бітне ціле число.
- `counts`: адреса памʼяті необроблених відліків, що містить 4 знакові 32-бітні цілі числа.
- `shift`: степінь двійки, на який треба поділити, як 64-бітне беззнакове ціле число від `0` до `31`.

```c
counts = {1024, -1024, 25, -25}
shift  = 3
result = { 128,  -128,  3,  -4}
```

~~~~exercism/note
Інструкцію `movq` можна використати, щоб скопіювати 64-бітне ціле число із регістра загального призначення до регістра `xmm`, не змінюючи базового бітового подання.
~~~~

Функція не повертає значення.

## 4. Застосувати шлюз до каналів

Кожна станція поєднує дві кампанії запису, а потім заглушує канали, які звіт обладнання позначає як несправні.
Кожен блок містить 4 маски каналів - беззнакові 32-бітні цілі числа, у яких кожен біт представляє один канал: `1` - увімкнено, `0` - вимкнено.

Реалізуйте функцію `gate_channels`, яка поєднує канали, увімкнені в будь-якій із кампаній, а потім очищає кожен канал, позначений як несправний.

Функція приймає такі аргументи в такому порядку:

- `result`: адреса памʼяті для буфера, куди записуються 4 маски після шлюзу, кожна - беззнакове 32-бітне ціле число.
- `enable_a`: адреса памʼяті масок увімкнення першої кампанії, що містить 4 беззнакові 32-бітні цілі числа.
- `enable_b`: адреса памʼяті масок увімкнення другої кампанії, що містить 4 беззнакові 32-бітні цілі числа.
- `faulty`: адреса памʼяті масок несправних каналів, що містить 4 беззнакові 32-бітні цілі числа.

```c
enable_a = {0b1100, 0b0001, 0b1111, 0b0000}
enable_b = {0b0110, 0b0001, 0b0000, 0b0000}
faulty   = {0b0100, 0b0011, 0b1001, 0b1111}
result   = {0b1010, 0b0000, 0b0110, 0b0000}
```

Функція не повертає значення.

## 5. Перемкнути біти калібрування

Раз на день станція запускає прохід калібрування, перемикаючи вибраний набір бітів конфігурації в кожному слові стану й залишаючи всі інші біти без змін.
Але деякі біти заблоковані обладнанням і ніколи не повинні змінюватися, хоч би що вимагав прохід.
Дворазовий запуск того самого проходу відновлює початкову конфігурацію.

Реалізуйте функцію `toggle_calibration`, яка в кожному слові стану перемикає саме ті біти, що встановлені у відповідній масці перемикання і не встановлені у відповідній масці блокування.

Функція приймає такі аргументи в такому порядку:

- `result`: адреса памʼяті для буфера, куди записуються 4 оновлені слова стану, кожне - беззнакове 32-бітне ціле число.
- `status`: адреса памʼяті поточних слів стану, що містить 4 беззнакові 32-бітні цілі числа.
- `toggle`: адреса памʼяті масок перемикання, що містить 4 беззнакові 32-бітні цілі числа.
- `locked`: адреса памʼяті масок блокування, що містить 4 беззнакові 32-бітні цілі числа.

```c
status = {0b1100, 0b0001, 0b1111, 0b1010}
toggle = {0b0110, 0b0011, 0b1111, 0b1010}
locked = {0b0010, 0b0001, 0b1100, 0b0000}
result = {0b1000, 0b0011, 0b1100, 0b0000}
```

Функція не повертає значення.

## 6. Підсилити трасу

Кожен канал масиву має власне коригування підсилення, виражене степенем двійки: підсилення `3` множить показник каналу на `8`, а підсилення `-5` ділить його на `32`.

Станція застосовує ці підсилення без жодного множення, маніпулюючи полем експоненти кожного числа з плаваючою комою.

Реалізуйте функцію `amplify_trace`, яка множить кожен показник на `2` у степені підсилення відповідного каналу, працюючи лише з необробленими бітами.

Функція приймає такі аргументи в такому порядку:

- `result`: адреса памʼяті для буфера, куди записуються 4 підсилені показники.
- `trace`: адреса памʼяті показників, що містить 4 значення, кожне з яких - 32-бітне число з плаваючою комою.
- `gains`: адреса памʼяті підсилень для кожного каналу, що містить 4 знакові 32-бітні цілі числа.

```c
trace  = {1.5, -2.0, 0.25, 96.0}
gains  = {  2,    1,    3,   -5}
result = {6.0, -4.0,  2.0,  3.0}
```

Функція не повертає значення.
Усі показники - нормальні ненульові числа з плаваючою комою, і кожен підсилений результат також нормальний.
