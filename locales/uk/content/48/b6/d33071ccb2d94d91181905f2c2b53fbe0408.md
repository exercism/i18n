# Вступ

Elixir уможливлює дотримання **принципу відкритості-закритості**, дозволяючи функціям мати кілька клозів. Тож замість розгалуженої й жорстко закодованої логіки керування можна писати точкові функції, щоб легко додавати або прибирати поведінку.

Elixir пропонує _кілька клозів функції_ та _ґарди_, щоб писати:

```elixir
def number(n) when n == 7 do
  "Awesome, that's my favorite"
end

def number(_n) do
  "That's not my favorite"
end
```

Під час виконання Elixir перевіряє, який клоз функції викликати, рухаючись від початку файла вихідного коду до кінця.

Перед назвами невикористаних змінних ставимо знак підкреслення.
