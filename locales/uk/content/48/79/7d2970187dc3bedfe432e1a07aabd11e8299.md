# Інструкції

У цій вправі ми допоможемо закоханим старшокласникам освідчитися в коханні в соціальних мережах, згенерувавши ASCII-рамку з їхніми ініціалами:

```
❤-------------------❤
|  J. K.  +  M. B.  |
❤-------------------❤
```

## 1. Отримати першу літеру імені

Реалізуйте функцію `HighSchoolSweetheart.first_letter/1`. Вона приймає імʼя та повертає його першу літеру. Вона також має прибрати з імені всі зайві пробіли.

```elixir
HighSchoolSweetheart.first_letter("Jane")
# => "J"
```

## 2. Оформити першу літеру як ініціал

Реалізуйте функцію `HighSchoolSweetheart.initial/1`. Вона приймає імʼя та повертає його першу літеру у верхньому регістрі, після якої стоїть крапка. Обовʼязково використайте функцію `HighSchoolSweetheart.first_letter/1`, яку ми визначили на попередньому кроці.

```elixir
HighSchoolSweetheart.initial("Robert")
# => "R."
```

## 3. Розділити повне імʼя на імʼя та прізвище

Реалізуйте функцію `HighSchoolSweetheart.initials/1`. Вона приймає повне імʼя, що складається з імені та прізвища, розділених пробілом, і повертає ініціали. Обовʼязково використайте функцію `HighSchoolSweetheart.initial/1`, яку ми визначили на попередньому кроці.

```elixir
HighSchoolSweetheart.initials("Lance Green")
# => "L. G."
```

## 4. Розмістити ініціали всередині ASCII-рамки

Реалізуйте функцію `HighSchoolSweetheart.pair/2`. Вона приймає два повні імені та повертає ініціали всередині ASCII-рамки. Малювати рамку самостійно не потрібно, скористайтеся рамкою, наведеною в коментарі до коду. Обовʼязково використайте функцію `HighSchoolSweetheart.initials/1`, яку ми визначили на попередньому кроці.

```elixir
HighSchoolSweetheart.pair("Blake Miller", "Riley Lewis")
# => """
# ❤-------------------❤
# |  B. M.  +  R. L.  |
# ❤-------------------❤
# """
```
