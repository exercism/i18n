# Вступ

[`Rational numbers`][rational] - це дроби, у яких чисельник і знаменник є цілими числами.

Наприклад, ми можемо зберегти `2//3` як точний дріб, а не як наближене значення `Float64` `0.6666...`

Перевага в тому, що (окрім крайнього випадку [переповнення цілих чисел][integer-overflow]) раціональне число залишається точним, і ми уникаємо помилок округлення, які часто неминучі для чисел з плаваючою комою.

Деякі додаткові подробиці можна знайти на [сторінці посібника][julia-rational] Julia.

Раціональні числа - досить простий числовий тип, і поводяться вони майже так, як ми й очікуємо.
Оскільки це стандартний тип у Julia від найперших версій, більшість функцій приймають їх як вхідні дані так само, як цілі числа та числа з плаваючою комою.

## Створення раціональних чисел

Створити їх так само просто, як поставити `//` між двома цілими числами.

```julia-repl
julia> 3//4
3//4

julia> a = 3; b = 4;

julia> a//b
3//4
```

Спільні множники автоматично скорочуються, тож дріб зводиться до свого [«найпростішого вигляду»][lowest-terms]: найменших цілих чисел, що точно описують цей дріб, із невідʼємним знаменником.

```julia-repl
julia> 5//15
1//3

julia> 5//-15
-1//3
```

Нескінченні результати приймаються, а от `NaN` - ні.

```julia-repl
julia> 1//0
1//0

julia> float(1//0)
Inf

julia> 0//0
ERROR: ArgumentError: invalid rational: zero(Int64)//zero(Int64)
```

## Арифметика з раціональними числами

Звичайні [`arithmetic operators`][operators] `+ - * / ^ %` працюють із раціональними числами фактично так само, як і з іншими числовими типами.

До виразу можна включати цілі числа та інші `Rational`, і результат теж буде `Rational`.
Якщо у виразі є `float`, результат теж буде `float`, з можливою втратою точності.

Якщо потрібен `float`, достатньо скористатися функцією `float()`, щоб перетворити раціональне число.
Цілком нормально використовувати раціональні числа, щоб зберегти точність протягом довгих обчислень, а в кінці перетворити результат на число з плаваючою комою.

```julia-repl
julia> 3//4 + 1//3  # addition
13//12

julia> 3//4 * 1//3  # multiplication
1//4

julia> 3//4 / 1//3  # division
9//4

julia> 3//4 ^ 2  # exponentiation
3//16

julia> 3//4 + 5  # rational and int => rational
23//4

julia> 3//4 + 5.3  # rational and float => float
6.05

julia> float(3//4)  # casting
0.75
```

Раціональні числа можна також поєднувати з [комплексними числами][complex].
Комплексні числа розглядаються в [окремій концепції][complex-concept].

## Інші операції

У Julia раціональні числа - це просто числа.
Компілятор зазвичай сам перетворює типи, коли це потрібно.

Однак варто памʼятати, що порівняння працюють для дробів зі скінченним десятковим представленням:

```julia-repl
julia> 3//4 == 0.75
true

julia> 3//4 < 0.74
false
```

Але в інших випадках для порівняння `Rational` потрібно привести до `Float`:

```julia-repl
julia> 1//3 == 1/3
false

julia> float(1//3) == 1/3
true
```

Математичні функції приймають раціональні числа як вхідні дані, але можуть повертати результат із плаваючою комою:

```julia-repl
julia> sqrt(9//16)
0.75
```
