# Додаток до інструкцій

## Повідомлення про винятки

Іноді буває потрібно [згенерувати виняток](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). Роблячи це, завжди додавайте **змістовне повідомлення про помилку**, яке вказує на джерело помилки. Це робить код зрозумілішим і значно допомагає з налагодженням. Якщо відомо, що джерело помилки буде певного типу, можна згенерувати один із [вбудованих типів помилок](https://docs.python.org/3/library/exceptions.html#base-classes), але все одно варто додати змістовне повідомлення.

У цій вправі потрібно використати [інструкцію `raise`](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement), щоб «викинути» `ValueError`, якщо параметри послідовності та/або довжини, передані у функцію `slice()`, порожні або поза межами діапазону. Тести пройдуть лише тоді, коли буде і виконано `raise` для `exception`, і додано до нього повідомлення.

Щоб згенерувати `ValueError` із повідомленням, запишіть повідомлення як аргумент до типу `exception`:

```python
# if the slice length is zero.
raise ValueError("slice length cannot be zero")

# if the slice length is negative.
raise ValueError("slice length cannot be negative")

# if the series provided is empty.
raise ValueError("series cannot be empty")

# if the slice length is longer than the series.
raise ValueError("slice length cannot be greater than series length")
```
