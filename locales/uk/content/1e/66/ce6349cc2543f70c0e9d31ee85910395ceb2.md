# Додаток до інструкцій

## Регістри

| Регістр | Використання | Тип | Опис |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | вхідні дані        | адреса | вхідний рядок тексту (англ. string), завершений нульовим символом  |
| `$a1`    | вхідні та вихідні дані | адреса | вихідний рядок тексту, завершений нульовим символом |
| `$t0-9`  | тимчасовий    | будь-який     | використовується для тимчасового зберігання    |
