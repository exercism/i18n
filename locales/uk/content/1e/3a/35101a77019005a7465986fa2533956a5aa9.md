# Додаток до інструкцій

## Риси Rust для `.to_string()`

Також потрібно реалізувати `.to_string()` для структури `Clock`.
Ми використаємо це, щоб показати стан годинника.
Це можна зробити безпосередньо або скористатися [рисою `Display`][display-trait].

Якщо оберете другий шлях, спробуйте реалізувати [рису `Display`][display-trait] для `Clock`.

Риси дають змогу реалізовувати функціональність для різних типів у спільний спосіб.

Для додаткового навчання подумайте, як можна було б реалізувати `String::from` для типу `Clock`.
Насправді цього робити не обовʼязково, адже це надлишково порівняно з `Display`, який загалом
є кращим вибором, коли цільовий тип це `String`, але корисно мати в своєму арсеналі
кілька рис перетворення типів.

[display-trait]: https://doc.rust-lang.org/std/fmt/trait.Display.html
