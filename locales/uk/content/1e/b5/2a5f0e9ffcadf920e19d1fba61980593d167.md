# Інтеграція з редакторами

Найкращий спосіб розробляти Clojure - це REPL, підʼєднаний до редактора. Для найпопулярніших редакторів та IDE доступні плагіни:

- Emacs: [CIDER](https://cider.mx)
- IntelliJ: [Cursive](https://cursive-ide.com)
- VSCode: [Calva](https://calva.io)
- Vim: [Conjure](https://github.com/Olical/conjure)

Більше інформації можна знайти в [офіційній документації](https://clojure.org/guides/editors).
