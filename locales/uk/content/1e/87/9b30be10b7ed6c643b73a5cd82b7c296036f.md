# Instructions

У цій вправі ми будемо організовувати перегони між різними типами радіокерованих автомобілів. Кожен автомобіль має власні характеристики швидкості та розряджання батареї.

Автомобілі стартують із повністю зарядженими батареями (100%). Щоразу, коли ми керуємо автомобілем за допомогою пульта, він проїжджає відстань, що дорівнює швидкості автомобіля в метрах, і зменшує залишок заряду батареї на відсоток її розряджання.

Якщо заряд батареї автомобіля менший за відсоток її розряджання, ми більше не можемо керувати цим автомобілем.

Кожна гоночна траса має власну дистанцію. Автомобілі перевіряють, чи можуть вони завершити трасу, не розрядивши батарею.

На нас чекає шість завдань, кожне з яких працює з екземплярами радіокерованих автомобілів.

## 1. Створення радіокерованого автомобіля

Дозвольте створити радіокерований автомобіль, визначивши конструктор для класу `RemoteControlCar`, який приймає швидкість автомобіля в метрах і відсоток розряджання батареї як свої два параметри (обидва типу `int`):

```csharp
int speed = 5;
int batteryDrain = 2;
var car = new RemoteControlCar(speed, batteryDrain);
```

## 2. Створення гоночної траси

Дозвольте створити гоночну трасу, визначивши конструктор для класу `RaceTrack`, який приймає дистанцію траси в метрах як свій єдиний параметр (типу `int`):

```csharp
int distance = 800;
var raceTrack = new RaceTrack(distance);
```

## 3. Керування автомобілем

Реалізуйте метод `RemoteControlCar.Drive()`, який оновлює кількість пройдених метрів відповідно до швидкості автомобіля. Також реалізуйте метод `RemoteControlCar.DistanceDriven()`, який повертає кількість метрів, пройдених автомобілем:

```csharp
int speed = 5;
int batteryDrain = 2;
var car = new RemoteControlCar(speed, batteryDrain);
car.Drive();

car.DistanceDriven();
// => 5
```

## 4. Перевірка розрядженої батареї

Оновіть метод `RemoteControlCar.Drive()`, щоб він розряджав батарею відповідно до показника розряджання автомобіля. Також реалізуйте метод `RemoteControlCar.BatteryDrained()`, який показує, чи розряджена батарея:

```csharp
int speed = 5;
int batteryDrain = 2;
var car = new RemoteControlCar(speed, batteryDrain);
car.Drive();

car.BatteryDrained();
// => false
```

## 5. Створення радіокерованого автомобіля Nitro

Найпопулярніший радіокерований автомобіль - це Nitro, який має вражаючу максимальну швидкість 50 метрів із розряджанням батареї 4%. Реалізуйте (статичний) метод `RemoteControlCar.Nitro()`, який повертає автомобіль цього типу:

```csharp
var car = RemoteControlCar.Nitro();
car.Drive();
car.DistanceDriven();
// => 50
```
## 6. Перевірка, чи може радіокерований автомобіль завершити гонку

Щоб завершити гоночну трасу, автомобіль має бути здатним проїхати її дистанцію. Це означає не розрядити батарею, перш ніж перетнути фінішну лінію. Реалізуйте метод `RaceTrack.TryFinishTrack()`, який приймає екземпляр `RemoteControlCar` як свій параметр і повертає `true`, якщо автомобіль може завершити гоночну трасу; інакше повертає `false`:

```csharp
int speed = 5;
int batteryDrain = 2;
var car = new RemoteControlCar(speed, batteryDrain);

int distance = 100;
var raceTrack = new RaceTrack(distance);

raceTrack.TryFinishTrack(car);
// => true
```
