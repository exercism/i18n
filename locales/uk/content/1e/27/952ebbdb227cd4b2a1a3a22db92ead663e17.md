# Посилання та знімки

Коли ми передаємо змінну у функцію, її володіння зазвичай переходить до функції, і початкова змінна стає непридатною для використання. Це трохи незручно, якщо до стану потрібно звертатися більше ніж один раз.
У Cairo є дві можливості для передавання значення без його знищення чи переміщення, які називаються `references` та `snapshots`.

## Знімки

Знімки дають незмінний вигляд значення на певний момент часу: вони дозволяють зберегти володіння змінною й водночас звертатися до її стану.
Будь-яка зміна змінної створює нову комірку памʼяті, тож те, що показує знімок, залишається без змін.

```rust
fn get_len(arr: @Array<u128>) -> u32 { // this parameter takes in a snapshot using `@` with the data-type
    arr.len()
}

fn foo(arr: Array<u128>) {
    arr.pop_front();
}

fn main() {
    let mut new_arr: Array<u128> = array![1, 2, 3, 4, 5, 6, 7, 8];
    let snapshot = @new_arr; // using `@` to create a snapshot of a variable
    let len = get_len(snapshot); // pass the snapshot as argument, retaining ownership
    foo(new_arr); // `new_arr` is still valid up until here and no further

    // let new_len = new_arr.len(); // this would throw an error if you uncommented the code because `new_arr` has been moved when it was passed into `foo()` above
}
```

## Оператор скасування знімка

Щоб перетворити знімок назад у звичайну змінну, можна скористатися оператором скасування знімка `*`, який діє протилежно до оператора `@`.
Скасувати знімок можна лише для тих типів, які реалізують трейт `Copy`.

```rust
#[derive(Drop)]
struct Rectangle {
    height: u64,
    width: u64,
}

fn main() {
    let rec = Rectangle { height: 3, width: 10 };
    let area = calculate_area(@rec);
    println!("Area: {}", area);
}

fn calculate_area(rec: @Rectangle) -> u64 {
    // We need to transform the snapshots back into values using the desnap operator `*`.
    // Here we use `*` to both multiply the height and width and to desnap the snapshots.
    *rec.height * *rec.width
}
```

## Змінні посилання

Змінні посилання дозволяють передавати у функцію змінні значення, які потім неявно повертаються назад, завдяки чому володіння зберігається в контексті виклику.
Це можливо за допомогою модифікатора `ref`, за умови, що змінну оголошено з ключовим словом `mut`.

```rust
fn foo(ref arr: Array<u128>) { // using `ref` marks the argument as a mutable reference
    arr.pop_front(); // modifies the state of arr
}

fn main() {
    let mut new_arr: Array<u128> = array![1, 2, 3, 4, 5, 6, 7, 8];

    foo(ref new_arr);  // use `ref` to pass a mutable reference to the function

    let new_len = new_arr.len();  // the current context retains ownership of `new_arr`, so we can still use it
}
```
