# Докладніше

## Побітові операції

Побітові операції дають змогу працювати з окремими розрядами двійкових чисел.
Ці операції є основоположними в обчислювальній техніці: вони дають змогу ефективно виконувати низькорівневі завдання, як-от керування окремими бітами в памʼяті, оптимізація математичних обчислень, шифрування, звʼязок і кодування та декодування даних.

### Як Elm представляє 32-бітні цілі числа

В Elm цілі числа зберігаються як 32-бітні знакові цілі числа в [доповняльному коді](https://en.wikipedia.org/wiki/Two%27s_complement), тобто для зберігання кожного значення використовується 32 двійкові розряди (_біти_).
Це обмеження на кількість бітів визначає діапазон цілих чисел, які Elm може представити безпосередньо:

Додатний діапазон: від 0 до 2<sup>31</sup> - 1 (або від 0 до 2,147,483,647)
Відʼємний діапазон: від -2<sup>31</sup> до -1 (або від -2,147,483,648 до -1).

Наприклад, ціле число `5` у двійковій системі має вигляд `00000000000000000000000000000101`, хоча зазвичай ми відкидаємо провідні нулі й просто кажемо `101`.

### Модуль Bitwise

Elm надає кілька побітових операторів у своєму [модулі Bitwise](https://package.elm-lang.org/packages/elm/core/latest/Bitwise)

## Базові операції

Зміну окремих бітів числа називають _маскуванням_.
_Маска_ - це число, у якому певні біти встановлені в особливий спосіб, щоб за допомогою побітових операторів, як-от `and`, `or` і `xor`, змінювати інше число.

### and

`and` поєднує два числа, залишаючи лише ті біти, які дорівнюють `1` в обох числах.
Це зручно, коли треба перевірити, чи встановлено окремий біт.
Наприклад, щоб перевірити, чи встановлено 4-й біт числа в `1`, застосуймо до нього `and` з маскою `01000` (`8` у десятковій системі) й подивімося, чи результат не дорівнює нулю:

```elm
Bitwise.and 13 8 --> 8
--  13 = 01101
--   8 = 01000
-- and = 01000 = 8
```

### or

`or` поєднує два числа, встановлюючи кожен біт у `1`, якщо він дорівнює `1` в одному з чисел або в обох.
Це зручно, коли треба встановити конкретний біт у `1`.
Наприклад, щоб встановити 2-й біт у `10101`, виконаймо операцію `or` з маскою `00010`:

```elm
Bitwise.or 21 2 --> 23
-- 21 = 10101
--  2 = 00010
-- or = 10111 = 23
```

### Виключне або (xor)

`xor` поєднує два числа, встановлюючи кожен біт у `1`, якщо він дорівнює `1` в одному числі, але `0` в іншому.
Це зручно, коли треба перемкнути біт у протилежне значення:

```elm
Bitwise.xor 20 5 --> 17
--  20 = 10100
--   5 = 00101
-- xor = 10001 = 17
```

### Доповнення

`complement` інвертує кожен біт числа (`0` стає `1`, `1` стає `0`).

Зауважмо, що внаслідок цього додатні числа стають відʼємними, а відʼємні - додатними.
Це тому, що відʼємні числа в двійковій системі мають `1` в найлівішій позиції.

```elm
Bitwise.complement 21 --> -22
--         21 = 00000000000000000000000000010101
-- complement = 11111111111111111111111111101010 = -22
```

### Побітовий зсув

Наведені далі оператори зсувають біти ліворуч або праворуч на вказану кількість позицій, що фактично множить або ділить на степені 2.

`shiftLeftBy` зсуває біти ліворуч, заповнюючи їх нулями (`0`) з правого боку.
Наприклад, щоб зсунути `21` ліворуч на 3 позиції:

```elm
Bitwise.shiftLeftBy 3 21 --> 168
--  21 = 10101
-- shiftLeftBy 3 = 10101000 = 168
```

Це те саме, що й `21 * 2^3 = 21 * 2 * 2 * 2 = 168`

`shiftRightBy`: зсуває біти праворуч:

```elm
Bitwise.shiftRightBy 2 21 --> 5
--  21 = 10101
-- shiftRightBy 2 = 00101 = 5
```

Зсув праворуч на 2 позиції рівнозначний цілочисельному діленню на 4.

Зауважмо, що ця функція дублює значення найлівішого біта.
Тож відʼємні числа залишаться відʼємними:

```elm
Bitwise.shiftRightBy 3 -21 --> -3
--  -21 = 111...101011
-- shiftRightBy 3 = 111...11101 = -3
```

Якщо треба зсунути праворуч і заповнити нулями, скористаймося `shiftRightZfBy`:

```elm
Bitwise.shiftRightZfBy 3 -21 --> 536870909
--  -21 = 111...101011
-- shiftRightZfBy 3 = 00111...11101 = 536870909
```
