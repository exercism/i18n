# Докладніше

Swift надає три основні різновиди циклів:

- **Цикли `while`**: повторюють блок коду, доки задана умова залишається `true`. Умову перевіряють перед виконанням тіла циклу.
- **Цикли `repeat-while`**: схожі на цикли `while`, але умову перевіряють після виконання тіла циклу. Це гарантує, що тіло виконається принаймні один раз.
- **Цикли `for-in`**: виконують блок коду по одному разу для кожного елемента послідовності або колекції, як-от діапазон, масив або рядок тексту (англ. string).
