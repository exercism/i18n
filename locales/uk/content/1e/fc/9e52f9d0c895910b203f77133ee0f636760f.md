# Вступ

У R немає окремого типу [множини][wiki-set]; замість нього для подібних операцій над векторами використовують різні функції.

Оператор [`%in%`][ref-match] перевіряє належність до множини.
Цей інфіксний оператор працює так само, як функція `is.element()`.

```R
2 %in% 1:10 # TRUE
12 %in% 1:10 # FALSE
```

До відповідних функцій належать:

- [`unique()`][ref-unique] для видалення дублікатів.
- [`union()`][ref-sets] для поєднання множин (математично `A ∪ B`).
- [`intersect()`][ref-sets] для пошуку елементів, спільних для обох множин (`A ∩ B`).
- [`setdiff()`][ref-sets] для віднімання однієї множини від іншої (`A - B`).
- [`setequal`][ref-sets] для перевірки рівності множин, ігноруючи дублікати та порядок.

```R
> set_1 <- c("a", "b", "c", "b", "a")
> unique(set_1) # deduplicate
[1] "a" "b" "c"

> set_2 <- c('a', "c", "d")
> union(set_1, set_2) # values in either set
[1] "a" "b" "c" "d"

> intersect(set_1, set_2) # values in both sets
[1] "a" "c"

> setdiff(set_1, set_2) # values in set_1 but not set_2
[1] "b"

> setdiff(set_2, set_1) # values in set_2 but not set_1
[1] "d"

setequal(set_1, c("c", "b", "a", "b")) # are elements the same after deduplication?
[1] TRUE
```

У кожному з цих випадків функція повертає копію, а аргументи залишає без змін.

## Геш-таблиці

Описані вище операції над векторами входять до base R.
Вони зручні для невеликих задач, але стають повільними для великих множин.

Різні сторонні пакети реалізують [геш-таблиці][wiki-hash], щоб покращити швидкодію в деяких випадках.

Наприклад, пакет [`hashtable`][ref-hashtable] надає реалізації `hashmap` і `hashset`, які краще масштабуються.
Як і більшість зовнішніх пакетів, він недоступний на Exercism, але його варто дослідити для задач із реального світу.
