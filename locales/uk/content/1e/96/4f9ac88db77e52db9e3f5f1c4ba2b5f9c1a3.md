# Підказки

## Загальне

- Оператори для цілих чисел і чисел з плаваючою комою описано в [огляді мови][tour].
- Функції для роботи з цілими числами визначені в [модулі `gleam/int`][int].
- Функції для роботи з числами з плаваючою комою визначені в [модулі `gleam/float`][float].
- Функції для роботи з рядками тексту (англ. string) визначені в [модулі `gleam/string`][string].

[tour]: https://gleam.run/book/tour/ints-and-floats.html
[int]: https://hexdocs.pm/gleam_stdlib/gleam/int.html
[float]: https://hexdocs.pm/gleam_stdlib/gleam/float.html
[string]: https://hexdocs.pm/gleam_stdlib/gleam/string.html
