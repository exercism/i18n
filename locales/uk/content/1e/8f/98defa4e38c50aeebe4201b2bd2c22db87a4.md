# Інструкції

Відділ заявок компанії Isaac's Asteroid Exploration Co. доручив нам покращити продуктивність їхньої системи реєстрації ділянок.

Щоразу, коли астероїд готовий до розробки, спекулянтів запрошують заявити права на ділянку землі.
Землю астероїда поділено на прямокутні ділянки, що не перетинаються.
Розміри різняться, але всі сторони паралельні осям координат.
Спекулянти заявляють права на одну з ділянок, вказуючи її координати.

Наша мета - розробити продуктивну систему, яка впорається з ажіотажем навколо ділянок, що в минулому спричиняв падіння сайту.

Одиниця вимірювання становить 100 метрів, але в цих завданнях її можна не враховувати.

## 1. Визначте точку

Визначте `struct` для зберігання координат `x` і `y`.
Це досить малі невідʼємні цілі числа, тож використайте тип `UInt16`.

```julia-repl
julia> Coord(7, 3)
Coord(0x0007, 0x0003)  # unsigned integers display in hex format by default
```

## 2. Визначте ділянку

Оскільки всі ділянки мають бути прямокутними, з горизонтальними та вертикальними сторонами, для їх визначення достатньо двох протилежних кутів.

Реалізуйте структуру `Plot`, яка приймає дві структури Coord у своєму конструкторі.

`Plot` має бути структурою, що приймає іменовані аргументи, з полями `bottom_left` і `top_right`.

```julia-repl
julia> plot = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2))
Plot(Coord(0x000a, 0x0001), Coord(0x0014, 0x0002))

julia> plot.top_right
Coord(0x0014, 0x0002)
```

## 3. Перевірте, чи вже заявлено права на вашу ділянку

За ці заявки точиться конкуренція, тож перш ніж вашу заявку буде прийнято, її перевірять на збіг із наявними заявками в реєстрі.

Реалізуйте функцію `is_claim_staked()`, щоб визначити, чи вже заявлено права на ділянку.

```julia-repl
julia> claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));
julia> register = Set{Plot}();
julia> is_claim_staked(claim, register)
false
```

## 4. Спекулянти можуть заявити права, вказавши ділянку за координатами її кутів

Реалізуйте мутаційну функцію `stake_claim!()`, щоб дозволити реєстрацію заявки.

Якщо права на цю саму ділянку вже заявлено, поверніть `false`.

Якщо заявку можна подати, додайте її до реєстру та поверніть `true`.

```julia_repl
julia> claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));
julia> register = Set{Plot}();
julia> stake_claim!(claim, register)
true
```

## 5. Знайдіть довжину довшої сторони ділянки

Реалізуйте функцію `get_longest_side()`, щоб отримати довшу сторону (горизонтальну або вертикальну) ділянки.

```julia-repl
claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));

julia> get_longest_side(claim)
0x000a
```

## 6. Знайдіть ділянку з найдовшою стороною для дослідницьких цілей

Реалізуйте функцію `get_claim_with_longest_side()`, щоб переглянути всі зареєстровані ділянки та повернути ділянку (або ділянки) з найдовшою стороною.

```julia-repl
julia> plot1 = Plot(bottom_left=Coord(5, 3), top_right=Coord(10, 5));
julia> plot2 = Plot(bottom_left=Coord(0, 0), top_right=Coord(3, 3));
julia> register = Set{Plot}([plot1, plot2]);

julia> get_claim_with_longest_side(register)
Plot(Coord(0x0005, 0x0003), Coord(0x000a, 0x0005))
```

Поверніть ділянку (або ділянки) як `Set`: один елемент, якщо найдовша ділянка одна, і кілька елементів у разі нічиєї.
