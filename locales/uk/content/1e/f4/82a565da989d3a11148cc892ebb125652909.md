# Вступ

## Переповнення

Арифметичне переповнення виникає тоді, коли обчислення, як-от арифметична операція чи перетворення типу, дає значення, більше за місткість типу, що приймає це значення.

За таких обставин вирази типу `int` і `long` та їхні беззнакові відповідники непомітно загортаються по колу.

Поведінку обчислень із цілими числами можна змінити, скориставшись ключовим словом `checked`. Коли переповнення стається всередині блоку `checked`, викидається виняток `OverflowException`.

```csharp
int one = 1;
checked
{
    int expr = int.MaxValue + one;   // OverflowException is thrown
}

// or

int expr2 = checked(int.MaxValue + one);     // OverflowException is thrown
```

Вирази типу `float` і `double` набудуть особливого значення нескінченності.

Вирази типу `decimal` викинуть виняток `OverflowException`.
