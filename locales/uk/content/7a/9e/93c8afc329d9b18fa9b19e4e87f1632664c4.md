# Двійкова, вісімкова та шістнадцяткова системи числення

Двійкова, вісімкова та шістнадцяткова системи (_також відома як hex_) - це різні [системи числення][numeral-systems] з різними основами.
Двійкова має основу 2, вісімкова - основу 8, а шістнадцяткова - основу 16.
Звичайні цілі числа в Crystal мають основу 10.
Двійкова, вісімкова та шістнадцяткова системи - це способи подання цілих чисел.
Це означає, що вони подають додатні та відʼємні числа (_разом із нулем_) без дробових або десяткових частин і підтримують усі операції, які ми можемо виконувати з цілими числами.

## Двійкова система

[Двійкова система][binary] має основу 2 і використовує лише цифри 0 та 1.
Нею зазвичай позначають стани 0 («вимкнено») та 1 («увімкнено») електричного струму крізь транзистори й перемикачі в компʼютерах, а також додатний і відʼємний заряди на магнітних носіях.
Двійкова система може подати всі цілі числа, які використовуються в системі з основою 10.

Фрагмент системи з основою 2 має такий вигляд (хоч вона продовжується нескінченно й не зупиняється на 128):

| 128      | 64       | 32       | 16       | 8        | 4        | 2        | 1        |
| -------- | -------- | -------- | -------- | -------- | -------- | -------- | -------- |
| 2 \*\* 7 | 2 \*\* 6 | 2 \*\* 5 | 2 \*\* 4 | 2 \*\* 3 | 2 \*\* 2 | 2 \*\* 1 | 2 \*\* 0 |

Отже, якщо ми хочемо подати число 6, у двійковій системі воно матиме такий вигляд: 110

| Розряд        | 4   | 2   | 1   |
| ------------- | --- | --- | --- |
| Двійкове число | 1   | 1   | 0   |

А обчислення буде таким: `4 + 2 + 0 = 6`

Ще один приклад: 19

| Розряд        | 16  | 8   | 4   | 2   | 1   |
| ------------- | --- | --- | --- | --- | --- |
| Двійкове число | 1   | 0   | 0   | 1   | 1   |

Двійкове число буде таким: 10011
А обчислення буде таким: `16 + 0 + 0 + 2 + 1 = 19`

## Двійкова система в Crystal

У Crystal ми можемо записувати двійкові літерали за допомогою префікса `0b`.
Якщо ми напишемо `0b10011`, Crystal сприйме це як двійкове число й перетворить його на число в системі з основою 10.

```crystal
0b10011
# => 19

typeof(0b10011)
# => Int32
```

Якщо написати з префіксом `0b` число, яке не належить до двійкової системи, це викличе помилку компіляції.

```crystal
0b10211
# => Error: unexpected token: "211"
```

### Операції з двійковими числами

Оскільки двійкові числа - це цілі числа, ми можемо виконувати з ними всі ті самі операції, що й з цілими числами.

```crystal
0b10011 + 0b10011
# => 38

0b10011 * 0b10011
# => 361

0b10011 / 3
# => 6.333333333333333
```

### Перетворення на двійкове подання й навпаки

Crystal автоматично перетворює двійковий літерал на `Int32`.
Щоб перетворити `Int32` на двійкове подання, скористаймося методом [`<int>.to_s(base)`][to_s], передавши йому аргумент base зі значенням 2.
Метод поверне рядок тексту (англ. string), що подає двійкове число:

```crystal
19.to_s(2)
# => "10011"
```

Щоб перетворити рядок тексту з двійковим числом на ціле число, ми можемо скористатися методом [`<int>.to_i(base)`][to_i], передавши основу (2) як аргумент:

```crystal
"10011".to_i(2)
# => 19
```

Якщо вказати неправильну основу (_або некоректне двійкове подання_), це викличе `ArgumentError`:

```crystal
"011021".to_i(2)
# => Invalid Int32: "011021" (ArgumentError)
```

### Методи для двійкових чисел

Існують певні методи, які можна застосовувати до цілих чисел, щоб отримати інформацію про двійкове подання числа.

[`<int>.bit_length`][bit_length] повертає кількість бітів, потрібних для подання числа:

```crystal
19.bit_length
# => 5
```

[`<int>.bit(index)`][bit] повертає біт за вказаним індексом, рахуючи справа (_наймолодший біт_):

```crystal
19.bit(0)
# => 1

0b10011.bit(1)
# => 1
```

## Вісімкова система

[Вісімкова система][octal] має основу 8.
Вона використовує цифри 0, 1, 2, 3, 4, 5, 6 і 7.

У Crystal ми можемо записувати вісімкові числа за допомогою префікса `0o`.
Як і з двійковою системою, Crystal автоматично перетворює вісімкове подання на `Int32`.

```crystal
0o123
# => 83
```

Якщо додати префікс `0o` до числа, яке не належить до вісімкової системи, це викличе помилку компіляції.

### Перетворення на вісімкове подання й навпаки 

Як і з двійковою системою, ми можемо скористатися методом [`<int>.to_s(base)`][to_s], щоб перетворити `Int32` на вісімкове подання.
А за допомогою методу [`<int>.to_i(base)`][to_s] можемо перетворити вісімкове подання на `Int32`.

```crystal
83.to_s(8)
# => "123"

"123".to_i(8)
# => 83
```

Як і з двійковою системою, неправильна основа викличе `ArgumentError`.

## Шістнадцяткова система

[Шістнадцяткова система][hexadecimal] має основу 16.
Вона використовує цифри 0 - 9 та літери A, B, C, D, E і F.
A - це 10, B - це 11, C - це 12, D - це 13, E - це 14, а F - це 15.

У Crystal ми можемо записувати шістнадцяткові числа за допомогою префікса `0x`.
Як і з двійковою та вісімковою системами, Crystal автоматично перетворює шістнадцяткові літерали на `Int32`.

```crystal
#=> 0x123
291
```
 
Якщо додати префікс `0x` до числа, яке не є шістнадцятковим, це викличе помилку компіляції.

###  Перетворення на шістнадцяткове подання й навпаки

Як і з двійковою системою, ми можемо скористатися методом [`<int>.to_s(base)`][to_i], щоб перетворити `Int32` на шістнадцяткове подання.
А за допомогою методу [`<int>.to_i(base)`][to_s] можемо перетворити шістнадцяткове подання на `Int32`.

```crystal
291.to_s(16)
# => "123"

"123".to_i(16)
# => 291
```

Як і з двійковою та вісімковою системами, неправильна основа викличе `ArgumentError`.

## Точність

Перетворюючи число на рядок тексту, ми можемо вказати точність числа.
Тобто **мінімальну** кількість цифр, які використовуються для подання числа.
Якщо в числа менше цифр, ніж задає точність, до рядка тексту додадуться провідні нулі.
Це робиться передаванням аргументу `precision` методу [`<int>.to_s(<base>, precision: <value>)`][to_s].

```crystal
291.to_s(16, precision: 5)
# => "00123"

543.to_s(precision: 2)
# => "543"
```

## Верхній регістр

Перетворюючи число на рядок тексту, ми можемо вказати, чи хочемо ми записати літери у верхньому регістрі.
Це робиться передаванням аргументу `upcase` методу [`<int>.to_s(<base>, upcase: <value>)`][to_s].

```crystal
255.to_s(16, upcase: true)
# => "FF"

255.to_s(16, upcase: false)
# => "ff"
```
