# Підказки

## Загальне

- За потреби перегляньте [концепцію обʼєктів][concept-class-basics], щоб освіжити основи.
- Уважно прочитайте інструкції щодо розташування параметрів `x`, `y`, `width` і `height`. Їх легко переплутати.

## 1. Визначте клас ProgramWindow

- Не забудьте використати [синтаксис класів][php-class] для цього завдання.
- Визначте [властивості][php-properties], додавши їх до оголошення класу.

## 2. Визначте функцію-конструктор для класу ProgramWindow

- Перевірте, що ваша функція-конструктор не приймає жодних аргументів.
- Перевірте, що кожній властивості присвоюється очікуване ціле значення.

## 3. Додайте метод для зміни розміру вікна

- Не забудьте використати новий [клас][php-class] у файлі `Size.php` для цього завдання.
  - За домовленістю файли зазвичай містять лише один клас.
- Конструктор `Size` має приймати аргументи для початкових значень [властивостей][php-properties] класу.
- Створіть метод `resize` обʼєкта `ProgramWindow`, щоб застосувати зміну за допомогою примірника `Size`.

## 4. Додайте метод для переміщення вікна

- Не забудьте використати новий [клас][php-class] у файлі `Position.php` для цього завдання.
  - За домовленістю файли зазвичай містять лише один клас.
- Конструктор `Position` має приймати аргументи для початкових значень [властивостей][php-properties] класу.
- Створіть метод `move` обʼєкта `ProgramWindow`, щоб застосувати зміну за допомогою примірника `Position`.
