# Тести

Щоб запустити набір тестів:

```bash
tclsh exercise.test
```

## Пропущені тести

Розвʼязати вправу означає зробити так, щоб усі її тести проходили. Типово, коли ми запускаємо тести, виконується лише один тест (перший). Це зроблено навмисно, адже так ми можемо зосередитися на тому, щоб пройшов лише цей один тест. Коли він пройде, ми можемо увімкнути наступний тест, закоментувавши або видаливши команду `skip` перед ним.

Або, щоб запустити всі тести незалежно від їхнього статусу «skipped»:

```bash
RUN_ALL=1 tclsh exercise.test
```
