# Інструкції

Наш друг Чендлер планує відвідати екзотичні країни по всьому світу. На жаль, Чендлер не дуже добре знає математику. Він трохи хвилюється, що під час подорожі його обдурять на обміні валют, і хоче, щоб ми зробили для нього валютний калькулятор. Ось його вимоги до застосунку:

## 1. Оцініть вартість після обміну

Створіть функцію `exchange_money()`, яка приймає 2 параметри:

1. `budget` : сума грошей, яку ми плануємо обміняти.
2. `exchange_rate` : сума національної валюти, що дорівнює одній одиниці іноземної валюти.

Ця функція повинна повернути вартість обміненої валюти.

**Примітка:** Якщо наша валюта - USD і ми хочемо обміняти USD на EUR за курсом `1.20`, то `1.20 USD == 1 EUR`.

```python
>>> exchange_money(127.5, 1.2)
106.25
```

## 2. Обчисліть залишок валюти після обміну

Створіть функцію `get_change()`, яка приймає 2 параметри:

1. `budget` : сума грошей до обміну.
2. `exchanging_value` : сума грошей, яку *беруть* із бюджету для обміну.

Ця функція повинна повернути суму грошей, що *залишилася* від бюджету.

```python
>>> get_change(127.5, 120)
7.5
```

## 3. Обчисліть вартість купюр

Створіть функцію `get_value_of_bills()`, яка приймає 2 параметри:

1. `denomination` : вартість однієї купюри.
2. `number_of_bills` : загальна кількість купюр.

Цей обмінний пункт працює лише з готівкою певних номіналів.
Загальна сума, яку ми отримуємо, повинна ділитися на вартість однієї «купюри», або одиниці, що може залишити дріб чи остачу.
Наша функція повинна повернути лише загальну вартість купюр (_без дробових сум_), які пункт видасть.
На жаль, пункт залишає собі остачу/решту як додатковий бонус.

```python
>>> get_value_of_bills(5, 128)
640
```

## 4. Обчисліть кількість купюр

Створіть функцію `get_number_of_bills()`, яка приймає `amount` і `denomination`.

Ця функція повинна повернути _кількість купюр_, які можна отримати в межах заданої _суми_.
Іншими словами: скільки _цілих купюр_ уміщується в початкову суму?
Памʼятаймо: отримати можна лише _цілі купюри_, а не частини купюр, тож не забуваймо ділити відповідно.
Фактично ми округлюємо _вниз_ до найближчої цілої купюри/номіналу.

```python
>>> get_number_of_bills(127.5, 5)
25
```

## 5. Обчисліть залишок після обміну на купюри

Створіть функцію `get_leftover_of_bills()`, яка приймає `amount` і `denomination`.

Ця функція повинна повернути _суму залишку_, яку не можна видати з початкової _суми_ за заданого номіналу купюр.
Дуже важливо точно знати, скільки пункт залишає собі.

```python
>>> get_leftover_of_bills(127.5, 20)
7.5
```

## 6. Обчисліть вартість після обміну

Створіть функцію `exchangeable_value()`, яка приймає `budget`, `exchange_rate`, `spread` і `denomination`.

Параметр `spread` - це *відсоток, який беруть* як комісію за обмін, записаний цілим числом.
Його потрібно перетворити на десяткове число, поділивши на 100.
Якщо `1.00 EUR == 1.20 USD`, а *spread* дорівнює `10`, то фактичний курс обміну буде таким: `1.00 EUR == 1.32 USD`, бо 10% від 1.20 становить 0.12, і цю додаткову комісію додають до курсу обміну.

Ця функція повинна повернути максимальну вартість нової валюти після обчислення *курсу обміну* разом із *spread*.
Памʼятаймо, що *номінал* валюти - це ціле число, і його не можна ділити на дрібніші частини.

**Примітка:** Повернене значення має бути типу `int`.

```python
>>> exchangeable_value(127.25, 1.20, 10, 20)
80
>>> exchangeable_value(127.25, 1.20, 10, 5)
95
```
