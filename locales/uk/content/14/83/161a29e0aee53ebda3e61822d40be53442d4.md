# Вступ

Оголошення `MACRO:` схоже на `:`, але його тіло виконується під час *компіляції* й має повертати квотейшн. Компілятор підставляє цей повернений квотейшн замість виклику макроса. Оскільки тіло написане звичайним кодом Factor, побудувати потрібний квотейшн означає лише маніпулювати послідовностями слів.

```factor
USING: kernel macros sequences ;

MACRO: twice ( quot -- compound )
    dup append ;

: shout-twice ( name -- ) [ " ahoy!" append print ] twice ;
! At compile time, the call site is replaced with
! [ " ahoy!" append print " ahoy!" append print ].
```

Вхідні дані макроса — це *літерали в місці виклику*. Якщо передати нелітеральне значення, компілятор відмовиться спеціалізувати виклик, бо тіло макроса потребує значення під час компіляції, а не під час виконання.

Поруч із макросами стоїть блок обчислення на етапі розбору `<< … >>`: він виконує довільний код Factor під час компіляції, але без контракту повернення квотейшну. І те, й інше належить до інструментарію [`macros`][macros] у мові Factor.

[macros]: https://docs.factorcode.org/content/vocab-macros.html
