# Інструкції

Іззі завзято спостерігає за птахами і щодня записує, скільки птахів побувало в її саду.

Вона попросила нас допомогти вивести її спостереження за птахами на новий рівень і реалізувати кілька інструментів, які допоможуть їй відстежувати та обробляти дані.

Ми вирішили зберігати дані як масив цілих чисел. Перше число в масиві - кількість птахів, які побували в нашому саду сьогодні, друге - вчора, і так далі.

## 1. Перевірка, скільки птахів прилетіло сьогодні

Реалізуйте функцію `today`. Вона має приймати масив із кількістю птахів за кожен день і повертати сьогоднішню кількість. Якщо масив порожній, вона має повернути `0`.

```gleam
today([2, 5, 1])
// -> 2
```

## 2. Збільшення сьогоднішньої кількості

Реалізуйте функцію `increment_day_count`. Вона має приймати масив із кількістю птахів за кожен день і збільшувати сьогоднішню кількість на 1. Якщо масив порожній, поверніть `[1]`.

```gleam
increment_day_count([4, 0, 2])
// -> [5, 0, 2]
```

## 3. Перевірка, чи був день без птахів

Реалізуйте функцію `has_day_without_birds`. Вона має приймати масив із кількістю птахів за кожен день. Вона має повертати `True`, якщо був принаймні один день, коли жоден птах не побував у саду, і `False` в іншому разі. Якщо масив порожній, це означає, що птахів _поки що_ не записано; поверніть `False`.

```gleam
has_day_without_birds([2, 0, 4])
// -> True

has_day_without_birds([3, 8, 1, 5])
// -> False
```

## 4. Обчислення загальної кількості птахів, які прилітали

Реалізуйте функцію `total`. Вона має приймати масив із кількістю птахів за кожен день і повертати загальну кількість птахів, які побували в нашому саду відтоді, як ми почали збирати дані.

```gleam
total([4, 0, 9, 0, 5])
// -> 18
```

## 5. Обчислення кількості насичених днів

Деякі дні бувають насиченішими за інші. Насичений день - це день, коли в нашому саду побувало пʼять або більше птахів.

Реалізуйте функцію `busy_days`. Вона має приймати масив із кількістю птахів за кожен день і повертати кількість насичених днів.

```gleam
busy_days([4, 5, 0, 0, 6])
// -> 2
```
