# Вступ

У Go ми можемо перебирати `slice` за допомогою `for` та індексу, або ж можемо використовувати `range`.
`range` також дає змогу перебирати `map` або `channel`.
У цій концепції ми розглянемо перебирання `map`, але перебирання `channel` виходить за межі цієї концепції.

Кожна ітерація повертає два значення: індекс/ключ і копію елемента за цим індексом/ключем.

## Перебирання `slice`

Простіше нікуди: цикл по `slice` впорядкований, як і очікується.

```go
xi := []int{10, 20, 30}
for i, x := range xi {
  fmt.Println(i, x)
}
// outputs:
// 0, 10
// 1, 20
// 2, 30
```

## Перебирання `map`

Перебирання `map` породжує нову проблему.
Тепер порядок випадковий.

```go
hash := map[int]int{9: 10, 99: 20, 999: 30}
for k, v := range hash {
  fmt.Println(k, v)
}
// outputs, for example:
// 99 20
// 999 30
// 9 10
```

~~~~exercism/note
Може здатися, що наведений вище вивід неправильний, адже можна було б очікувати, що першою буде надрукована саме перша пара ключ-значення з оголошення `map` (`9 10`), а не остання.
Однак `map` за своєю природою невпорядковані: у них немає ні першої, ні останньої пари ключ-значення.
Через це, коли ми перебираємо записи `map`, порядок, у якому їх буде відвідано, буде випадковим і не підкорятиметься жодній конкретній закономірності.
Це означає, що наведений вище вивід можливий, але може відрізнятися від того, що ми отримаємо, якщо спробуємо запустити це самостійно.
Щоб дізнатися більше про це, дивіться [Go Language Spec: range clause](https://go.dev/ref/spec#RangeClause).
~~~~

## Ітерація з пропущеним ключем або значенням

У Go невикористана змінна спричинить помилку під час збірки.
Іноді нам потрібне лише значення, як у першому прикладі:

```go
xi := []int{10, 20, 30}
for i, x := range xi {
  fmt.Println(x)
}
// Go build failed: i declared but not used
```

Ми можемо замінити `i` на `_`, що підказує компілятору, що ми не використовуємо це значення:

```go
xi := []int{10, 20, 30}
for _, x := range xi {
  fmt.Println(x)
}
// outputs:
// 10
// 20
// 30
```

Якщо ми хочемо надрукувати лише індекс, можна замінити `x` на `_` або просто пропустити оголошення:

```go
xi := []int{10, 20, 30}
// for i, _ := range xi {
for i := range xi {
  fmt.Println(i)
}
// outputs:
// 0
// 1
// 2
```

І останнє, але не менш важливе: якщо нам потрібно виконати якусь дію, але нас не
цікавлять ні значення, ні ключі `slice` чи `map`, ми можемо пропустити й індекс, і
значення:

```go
xi := []int{10, 20, 30}
count := 0
for range xi {
  count++
}
// count value:
// 3
```
