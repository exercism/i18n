# Додаток до інструкцій

## Реалізація

Визначте власний тип 'DNA' з функцією 'Counts', яка повертає два значення:

- підрахунок частоти для заданого ланцюга ДНК
- помилку (якщо є неприпустимі нуклеотиди)

Який тип добре підійде для ланцюга ДНК?

Які типи Go найкраще підходять для подання вихідних значень?

Погляньте на тестові випадки, щоб отримати підказку про можливі вхідні дані.
