# Довідка

Рядок тексту (англ. string) представляє текстові дані.
У Swift [`String`][strings-and-characters] - це впорядкована колекція значень `Character`, кожне з яких представляє символ Unicode.

Рядок тексту створюють за допомогою літерала рядка тексту, тобто послідовності символів, узятої в подвійні лапки (`"`).
Для багаторядкових рядків тексту можна використовувати потрійні лапки (`"""`):

```swift
let hello: String = "Hello, World!"

let poem: String = """
Roses are red,
Violets are blue.
Sugar is sweet,
And so are you.
"""
```

Рядки тексту у Swift безперешкодно поєднуються з класом [`NSString`][nsstring-docs] фреймворку Foundation, що відкриває доступ до широких можливостей обробки тексту.

## Символи

`Character` представляє один розширений графемний кластер, тобто зрозумілий людині символ, що складається з одного або кількох [скалярних значень Unicode][unicode-scalar-values].
Скалярне значення Unicode - це 21-бітна кодова точка в діапазоні від `U+0000` до `U+D7FF` включно або від `U+E000` до `U+10FFFF` включно.

```swift
let aChar: Character = "A"
```

## Виведення типу

Коли ми пишемо літерал рядка тексту, Swift автоматично виводить його тип як `String`.
Щоб зберегти один символ як `Character`, потрібно надати явну анотацію типу:

```swift
let aString = "A"        // Inferred as String
let aChar: Character = "A" // Explicitly typed as Character
print(type(of: aString)) // Prints String
print(type(of: aChar))   // Prints Character

// The following code will not compile:
let badChar: Character = "Too many characters"
// Error: Cannot convert value of type 'String' to specified type 'Character'
```

## Конкатенація

Рядки тексту можна зʼєднувати за допомогою оператора додавання (`+`):

```swift
print("honey" + "comb")
// Prints "honeycomb"
```

Не можна безпосередньо конкатенувати `Character` з рядком тексту за допомогою `+`, спершу не перетворивши символ на рядок тексту.
Однак можна скористатися методом [`append(_:)`][append], щоб додати рядок тексту або символ безпосередньо до змінюваного рядка тексту:

```swift
var greeting = "Hello"
let world = ", world"
let period: Character = "."

greeting.append(world)
print(greeting) // Prints "Hello, world"

greeting.append(period)
print(greeting) // Prints "Hello, world."
```

## Інтерполяція рядків тексту

[Інтерполяція рядків тексту][string-interpolation] дає змогу побудувати рядок тексту, вбудовуючи константи, змінні, літерали та вирази всередину літералів рядків тексту.
Кожен вираз поміщають у дужки, перед якими стоїть символ зворотної скісної риски (`\(` ... `)`):

```swift
let radius = 5.0
let circle = "The area of a circle with radius \(radius) is \(Double.pi * radius * radius)"
print(circle) // Prints "The area of a circle with radius 5.0 is 78.53981633974483"
```

## Властивості рядків тексту та символів

Рядки тексту та символи мають кілька властивостей, які дають змогу дослідити їхній вміст.

### Властивості рядків тексту

Ось деякі з найпоширеніших властивостей рядків тексту:

| Властивість | Опис                                           | Приклад                               |
| ----------- | ---------------------------------------------- | ------------------------------------- |
| `isEmpty`   | Повертає `true`, якщо рядок тексту не має символів | `"Hello".isEmpty` дає `false`         |
| `count`     | Повертає кількість символів у рядку тексту     | `"Hello".count` дає `5`               |

Повний перелік властивостей дивіться в [документації String від Apple][string-docs].

### Властивості символів

Ось деякі з найпоширеніших властивостей символів:

| Властивість    | Опис                                          | Приклад                              |
| -------------- | --------------------------------------------- | ------------------------------------ |
| `isLowercase`  | Повертає `true`, якщо символ у нижньому регістрі | `"a".isLowercase` дає `true`         |
| `isUppercase`  | Повертає `true`, якщо символ у верхньому регістрі | `"A".isUppercase` дає `true`         |
| `isNumber`     | Повертає `true`, якщо символ є цифрою         | `"1".isNumber` дає `true`            |
| `isWhitespace` | Повертає `true`, якщо символ є пробільним     | `" ".isWhitespace` дає `true`        |

Повний перелік властивостей дивіться в [документації Character від Apple][character-docs].

## Перетворення типів

Інші типи можна перетворити на рядки тексту за допомогою ініціалізатора `String(_:)`, який підтримує стандартні типи, як-от `Int`, `Double` і `Character`:

```swift
let charX: Character = "x"
print(String(charX))     // Prints "x"
print(String(110))       // Prints "110"
print(String(Double.pi)) // Prints "3.141592653589793"
```

## Спеціальні символи

Літерали рядків тексту у Swift підтримують кілька [керуючих послідовностей][special-characters] для спеціальних символів:

| Послідовність | Опис                              |
| ------------- | --------------------------------- |
| `\0`          | Нульовий символ                   |
| `\\`          | Зворотна скісна риска             |
| `\t`          | Горизонтальна табуляція           |
| `\n`          | Переведення рядка (новий рядок)   |
| `\r`          | Повернення каретки                |
| `\'`          | Знак одинарної лапки              |
| `\"`          | Знак подвійної лапки              |
| `\u{n}`       | Довільне скалярне значення Unicode (шістнадцяткове) |

```swift
let quote: String = "\"Hello\", he said."
print(quote) // Prints "Hello", he said.

let unicode: Character = "\u{1F496}"
print(unicode) // Prints 💖
```
