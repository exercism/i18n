# Підказки

## 1. Замінити всі пробіли на підкреслення

- Ось [довідкова документація][char-docs] для `Char`.
- Літерали `Char` беруть у 'одинарні лапки', а літерали `String` - у "подвійні".

## 2. Видалити всі пробільні символи

- Дивіться [цей метод][isspace] для визначення пробільних символів і [цей метод][isdigit] для цифр.

## 3. Перетворити camel case на kebab case

- Дивіться [цей метод][isuppercase], щоб перевірити, чи символ у верхньому регістрі.
- Дивіться [цей метод][lowercase], щоб перетворити символ на нижній регістр.

## 5. Пропустити грецькі малі літери

- `Char` підтримує типові оператори рівності та порівняння.

## 6. Поєднати ці операції, щоб працювати з рядком тексту (англ. string)

- Рядок тексту можна перебирати так само, як масив.
- Щоб виконати всі перетворення, розгляньте використання включення.
- Кілька рядків тексту можна [зʼєднати][join] в один.
