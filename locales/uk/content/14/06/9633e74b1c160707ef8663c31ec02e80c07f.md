# Доповнення до інструкцій

## Регістри

| Регістр | Використання       | Тип         | Опис                                   |
| ------- | ------------------ | ----------- | -------------------------------------- |
| `$a0`   | вхідні дані        | адреса      | вхідний рядок, завершений нульовим символом |
| `$a1`   | вхідні/вихідні дані | адреса     | рядок результату, завершений нульовим символом |
| `$t0-9` | тимчасові          | будь-який   | для тимчасового зберігання             |
