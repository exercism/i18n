# Вступ

У Haxe роль основної структури даних виконує `class`, який інкапсулює дані (поля) та поведінку (методи). Поля й методи також називають членами класу.

Доступ до членів класу можна обмежити за допомогою модифікаторів доступу, а саме:

- `public`: до члена можна звертатися звідусіль.
- `private`: до члена можна звертатися лише з того самого класу.

Класи можна уявляти як шаблони для створення екземплярів. Щоб створити екземпляр, просто використаймо ключове слово `new`:

```haxe
class Car {
  public function new() {}
}

var myCar = new Car();
var yourCar = new Car();
```

Щоб визначити поле, використаймо модифікатор доступу, а потім назву та тип змінної:

```haxe
class Car {
  public var weight:Int; // Accessable by anyone

  private var color:String; // Accessable only within this class
}
```

Також під час визначення поля можна задати початкове значення. Якщо поле не має початкового значення, воно набуде значення `null`. До поля можна звертатися через точкову нотацію:

```haxe
class Car {
  public var weight:Int = 2500; // Weight will be set to 2500
  public var year:Int; // year will be null

  public function new() {}
}

var newCar = new Car();
newCar.weight; // 2500
newCar.year; // null

// Update value of field
newCar.year = 2020;
```
