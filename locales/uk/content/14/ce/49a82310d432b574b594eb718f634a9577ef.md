# Паливна надбавка

## Постановка задачі

Кожен співробітник ABC Corp отримує необмежену паливну надбавку. Співробітники мають надсилати запис щоразу, коли заправляють свої автомобілі. Ці записи дописуються до того самого CSV-файлу й обробляються наприкінці місяця.

Ми входимо до команди цифрових операцій, тож наше завдання - прочитати цей CSV-файл і записати результати в інший CSV-файл. Вихідний файл має містити по одному запису для кожного співробітника з такими даними:

- Номер співробітника
- Кількість заправок
- Загальна вартість пального
- Загальна кількість галонів
- Загальний пробіг у милях

На вхід подаються два аргументи `string`.

1. Шлях до вхідного CSV-файлу
1. Шлях до вихідного CSV-файлу

Вхідний CSV-файл містить `n` рядків, і кожен рядок має такий вигляд.

| Column name      | Ballerina type |
| ----------- | ----------- |
| employee_id      | `int`       |
| odometer_reading   | `int`       |
| gallons   | `decimal` |
| gas_price(USD)  |`decimal`|

Вихідний файл має містити по одному запису для кожного співробітника, відсортованих за зростанням `employee_id`. Кожен рядок має такий вигляд:

| Column name      | Ballerina type |
| ----------- | ----------- |
| employee_id      | `int`       |
| gas_fill_up_count   | `int`        |
| total_fuel_cost(USD)   | `decimal` |
| total_gallons  |`decimal`|
| total_miles_accrued  |`int`|

## Обмеження

- Кількість рядків `n` у вхідному CSV-файлі:  2 <= n <= 1000
- Кількість співробітників у компанії: 97
- Ціна пального вказана за галон
- Усі записи про заправки наявні

## Приклад 1

- Вхідні дані: `example01_input.csv`

```csv
2312,230,18.561,4.56
2312,500,19.345,4.89
```

- Вихідні дані: `example01_output.csv`

```csv
2312,2,179.23521,37.906,270
```
