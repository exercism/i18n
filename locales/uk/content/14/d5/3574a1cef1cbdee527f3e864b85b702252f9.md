# Вступ

## Масиви

Масиви вбудовані в мову Elixir. Їх вважають базовим типом, який позначається квадратними дужками. Масиви можуть бути порожніми або містити будь-яку кількість елементів будь-якого типу. Наприклад:

```elixir
empty_list = []
one_item_list = [1]
two_item_list = [1, 2]
multiple_type_list = [1, :pi, 3.14, "four"]
```

Elixir реалізує масиви як звʼязаний масив, де кожен вузол зберігає два значення: перший елемент і ще один масив з усіма рештою елементів. Перший елемент масиву називають _головою_, а масив з решти елементів - _хвостом_. Цю нотацію можна використати в коді:

```elixir
# [1] represented in [head | tail] notation
[1 | []]

# [1, 2, 3] represented in [head | tail] notation
[1 | [2 | [3 | []]]]
```

Нотацію _`[head | tail]`_ можна використати, щоб додати елементи на початок масиву:

```elixir
# Suppose
list = [2, 1]

[3, 2, 1] == [3 | list]
# => true
```

У модулі `Kernel` є кілька функцій для роботи з масивами, а також цілий модуль `List`.

```elixir
# Check if 1 is a member of the list
1 in [1, 2, 3, 4]
# => true
```
