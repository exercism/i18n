# Інструкції

Шифрувальне колесо складається з двох дисків, один усередині одного, які обертають алфавіт: встановімо його на 3, і кожна літера стає тією, що стоїть на три позиції далі, а `z` повертається назад до `a`. Детективи користуються ними вже століттями. А ми будуємо таке саме.

Усі пʼять завдань містяться в класі `CIPHER_WHEEL`.

## 1. Це літера?

```sather
CIPHER_WHEEL::is_letter('m')
-- => true
CIPHER_WHEEL::is_letter('7')
-- => false
```

## 2. Крикнімо його

Поверніть велику літеру символу. Усе, що не є літерою, повертається без змін.

```sather
CIPHER_WHEEL::shout('m')
-- => 'M'
```

## 3. Яке це число?

Поверніть число, яке позначає символ.

```sather
CIPHER_WHEEL::code('a')
-- => 97
```

## 4. Перший символ

Поверніть перший символ рядка тексту (англ. string).

```sather
CIPHER_WHEEL::first_character("Marlowe")
-- => 'M'
```

## 5. Обернімо колесо

Маючи малу літеру та кількість позицій, поверніть літеру, що стоїть на стільки позицій далі в алфавіті. Після `z` вона повертається назад до `a`.

```sather
CIPHER_WHEEL::turn('a', 3)
-- => 'd'
CIPHER_WHEEL::turn('z', 1)
-- => 'a'
```

Обертання назад теж працює, з відʼємною кількістю позицій.

```sather
CIPHER_WHEEL::turn('a', -1)
-- => 'z'
```

Можна припустити, що переданий символ - мала літера.
