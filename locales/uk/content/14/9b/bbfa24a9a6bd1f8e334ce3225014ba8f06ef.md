# Вступ

Буфер рядків тексту (англ. string) - це ефективний спосіб побудувати великий рядок тексту, додаючи маленькі елементи один до одного. На відміну від String, екземпляр StringBuf не є незмінним у тому сенсі, що його можна передати як аргумент функціям, які змінюють його, додаючи нові значення.

```haxe
var a = new StringBuf();
a.add("Hello");
trace(a.toString()); // Hello
a.add("Haxe!");
trace(a.toString()); // HelloHaxe
```
