# Встановлення

Цей трек використовує ReScript 12 і потребує [Node.js][nodejs] версії 22 або новішої.
На багатьох системах його вже встановлено, або ж ми могли встановити його раніше для іншого треку.

Відкрийте термінал і виконайте:

```sh
node -v
```

Якщо Node не встановлено або вказано старішу версію, дотримуйтеся [офіційних інструкцій зі встановлення Node.js][nodejs-install] для своєї платформи.

## Встановлення залежностей

Кожна вправа з ReScript - це самодостатній проєкт npm.
Після завантаження вправи за допомогою [Exercism CLI][exercism-cli] встановімо залежності проєкту, зокрема ReScript, і все готово до роботи:

```sh
cd /path/to/exercise
npm install
```
