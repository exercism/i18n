# Вступ

Те, що масив також є _колекцією_, означає, що, крім доступу до значень за індексом, ми можемо перебрати _усі_ його значення за допомогою циклу `foreach`:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```
