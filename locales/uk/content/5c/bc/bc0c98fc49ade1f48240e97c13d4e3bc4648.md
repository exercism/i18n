# Вступ

## Result

Тип `Result` у мові Elm дає змогу повідомляти про помилки та відновлюватися після них. Він дещо схожий на тип `Maybe`, але якщо `Maybe` може бути повернене функціями, які можуть зазнати невдачі, то він нічого не каже про причину цієї невдачі. `Result` містить цей контекст: чому щось не вдалося.

Тип `Result` визначено так:

```elm
type Result error value
  = Ok value
  | Err error
```

У термінології Elm це називають «власним типом». `error` і `value` у `OK value` та `Error error` позначають змінну типу, тобто будь-який тип, як-от `Int`, `Bool` чи `String`. Отже, `Result String Int` - це змінна, яка має містити `Int`, а якщо станеться помилка, її буде представлено як `String`. Існує [модуль Result](https://package.elm-lang.org/packages/elm/core/latest/Result) із безліччю корисних допоміжних функцій для роботи з `Result`.
