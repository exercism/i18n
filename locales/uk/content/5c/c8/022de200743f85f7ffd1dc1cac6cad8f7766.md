# Вказівки

У цій вправі ми побудуємо обробку помилок для простого калькулятора цілих чисел.
Щоб спростити завдання, методи для обчислення додавання, множення та ділення вже надані.

Мета - мати робочий калькулятор, який повертає рядок тексту (англ. string) такого вигляду: `16 + 51 = 67`, коли йому передати аргументи `16`, `51` і `+`.

```java
CalculatorConundrum calculator = new CalculatorConundrum();

calculator.calculate(16, 51, "+");
// => returns "16 + 51 = 67"

calculator.calculate(32, 6, "*");
// => returns "32 * 6 = 192"

calculator.calculate(512, 4, "/");
// => returns "512 / 4 = 128"
```

## 1. Реалізуйте метод calculate, щоб підтримувати кілька базових операцій

Головний метод, який потрібно реалізувати в цьому завданні, - метод `CalculatorConundrum.calculate()`.
Він приймає три аргументи.
Перші два аргументи `operand1` і `operand2` - цілі числа, над якими виконуватиметься операція.
Третій аргумент `operation` має тип рядок тексту, і в цій вправі потрібно реалізувати такі операції:

- додавання за допомогою рядка тексту `+`
- множення за допомогою рядка тексту `*`
- ділення за допомогою рядка тексту `/`

## 2. Опрацюйте недопустимі операції

Оновіть метод `CalculatorConundrum.calculate()`, щоб він опрацьовував недопустимі операції:

- Коли аргумент `operation` дорівнює `null`, потрібно викинути `IllegalArgumentException` з повідомленням `Operation cannot be null`.
- Коли аргумент `operation` дорівнює `""`, потрібно викинути `IllegalArgumentException` з повідомленням `Operation cannot be empty`.
- Коли аргумент `operation` є будь-якою операцією, крім `+`, `*` або `/`, потрібно викинути `IllegalOperationException` з повідомленням `Operation '{operation}' does not exist`.

```java
calculator.calculate(10, 1, null);
// => throws IllegalArgumentException with message "Operation cannot be null"

calculator.calculate(10, 1, "");
// => throws IllegalArgumentException with message "Operation cannot be empty"

calculator.calculate(10, 1, "-");
// => throws IllegalOperationException with message "Operation '-' does not exist"
```

## 3. Опрацюйте виняток, що виникає при діленні на нуль

У Java спроба поділити на нуль викидає `ArithmeticException`.
Оновіть метод `CalculatorConundrum.calculate()`, щоб він перехоплював цей виняток, а потім викидав `IllegalOperationException` з повідомленням `Division by zero is not allowed`, вказавши перехоплений `ArithmeticException` як причину.

```java
calculator.calculate(512, 0, "/");
// => throws IllegalOperationException with message "Division by zero is not allowed"
```
