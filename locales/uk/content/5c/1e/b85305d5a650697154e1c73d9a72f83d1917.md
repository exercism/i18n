# Інструкції

У цій вправі ми пограємося з радіокерованою машинкою, на яку нарешті назбирали достатньо грошей.

Машинки починають роботу з повністю зарядженими (100%) акумуляторами.
Щоразу, коли ми керуємо машинкою за допомогою пульта, вона проїжджає 20 метрів і витрачає один відсоток заряду акумулятора.
Прізвисько машинки невідоме, доки її не створено.

Радіокерована машинка має вигадливий LED-дисплей, який показує дві частини інформації:

- Загальна відстань, яку вона проїхала, показана як: `"<METERS> meters"`.
- Залишок заряду акумулятора, показаний як: `"Battery at <PERCENTAGE>%"`.

Якщо заряд акумулятора становить 0%, ми більше не можемо керувати машинкою, і дисплей заряду показуватиме `"Battery empty"`.

## 1. Створіть цілком нову радіокеровану машинку

Реалізуйте функцію `new_remote_control_car/0`, яка повертає цілком новий обʼєкт радіокерованої машинки:

```jq
new_remote_control_car
# => {
#      "battery_percentage": 100,
#      "distance_driven_in_meters": 0,
#      "nickname": null
#    }
```

## 2. Створіть цілком нову радіокеровану машинку з прізвиськом

Реалізуйте функцію `new_remote_control_car/1`, яка повертає цілком новий обʼєкт радіокерованої машинки із заданим прізвиськом:

```jq
new_remote_control_car("Blue")
# => {
#      "battery_percentage": 100,
#      "distance_driven_in_meters": 0,
#      "nickname": "Blue"
#    }
```

## 3. Покажіть відстань

Реалізуйте функцію `display_distance/0`, яка приймає обʼєкт машинки як вхідні дані та повертає рядок тексту (англ. string) з відстанню, як на LED-дисплеї:

```jq
new_remote_control_car | display_distance
# => "0 meters"
```

## 4. Покажіть відсоток заряду акумулятора

Реалізуйте функцію `display_battery/0`, яка приймає обʼєкт машинки як вхідні дані та повертає рядок тексту із відсотком заряду акумулятора, як на LED-дисплеї:

```jq
new_remote_control_car | display_battery
# => "Battery at 100%"
```

Якщо заряд акумулятора становить 0%, дисплей заряду показуватиме `"Battery empty"`.

## 5. Керування змінює заряд акумулятора і пройдену відстань

Реалізуйте функцію `drive/0`, яка:

- приймає обʼєкт машинки як вхідні дані
- збільшує кількість пройдених метрів на 20
- витрачає 1% заряду акумулятора
- повертає змінений обʼєкт машинки

```jq
new_remote_control_car("Red") | drive
# => {
#      "battery_percentage": 99,
#      "distance_driven_in_meters": 20,
#      "nickname": "Red"
#    }
```

## 6. Врахуйте керування з розрядженим акумулятором

Оновіть функцію `drive/0`, щоб вона не збільшувала пройдену відстань і не зменшувала відсоток заряду акумулятора, коли акумулятор розряджений (0%):

```jq
{
  battery_percentage: 0,
  distance_driven_in_meters: 2000,
  nickname: "Red"
} | drive
# => {
#      "battery_percentage": 0,
#      "distance_driven_in_meters": 2000,
#      "nickname": "Red"
#    }
```
