# Встановлення

Ми будемо використовувати *PolyML* як нашу реалізацію Standard ML.

Якщо ми працюємо у Windows, інсталятор можна завантажити з [https://github.com/polyml/polyml/releases](https://github.com/polyml/polyml/releases).
Загальні інструкції для Linux/OS X/Free BSD можна знайти на [https://github.com/polyml/polyml#readme](https://github.com/polyml/polyml#readme).

Якщо ми хочемо встановити з вихідного коду, процес досить простий:

```sh
$ git clone https://github.com/polyml/polyml.git
$ cd polyml
$ ./configure
```

Якщо ми хочемо встановити його в іншому місці, наприклад у `$HOME/.local`:

```sh
$ ./configure --prefix=$HOME/.local
```

Останній крок:

```sh
$ make compiler
$ make install
```

Перевірмо, чи встановлення пройшло правильно:

```sh
$ poly
```

Якщо ми бачимо інтерпретатор, усе готово!
Якщо ні, ймовірно, нам доведеться додати `$HOME/.local/bin` (або `<you prefix>/bin`) до нашого `$PATH`.
