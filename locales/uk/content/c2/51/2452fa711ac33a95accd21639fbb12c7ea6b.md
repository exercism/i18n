# Вступ

Вирушаючи в подорож C++, почнімо зі змінних, викликів функцій і коментарів.

## Коментарі

Коментарі бувають двох видів: однорядкові та багаторядкові.
Усе, що йде після `//` у тому самому рядку, компілятор ігнорує.
Багаторядкові коментарі ще називають коментарями у стилі C.
Їх обрамляють `/*` і `*/`.
Усе, що стоїть між ними, теж буде проігноровано.

## Змінні

C++ належить до типізованих мов.
Усі типи мають бути відомі під час компіляції, і зазвичай їх потрібно вказувати явно.
Тип змінної не може змінюватися.
Змінну цілого типу з назвою `years` можна оголосити так:

```cpp
int years;
```

Вважається хорошою практикою ініціалізувати змінні під час оголошення.
C++ пропонує для цього різні механізми.
Версія з фігурними дужками більше відповідає сучасному C++, але версія зі знаком рівності теж дуже поширена.

```cpp
int tomatoes{80};
int potatoes = 40;
```

~~~~exercism/caution
У C++ справді можна використовувати неініціалізовані змінні.
Поки змінній навмисно не надали значення, вона невизначена й може містити будь-що.
Щоб уникнути помилок використання до присвоєння та невизначеної поведінки, радимо **завжди ініціалізувати**.
Невизначена поведінка може спричинити збій програми в найгірший можливий момент, хоча раніше вона працювала справно.
Не зайве наголосити: уникаймо невизначеної поведінки за будь-яку ціну.
~~~~

## Арифметичні операції

Арифметичні оператори, як-от `*`, `+` чи `-`, можуть бути частиною виразу на кшталт `3 * 2` або `tomatoes + potatoes`.

## Оновлення змінних

Можна присвоювати змінним нові значення, якщо вони зберігають свій тип:

```cpp
tomatoes = tomatoes - 5; // tomatoes is now 75
potatoes = (32 * 2) + 11; // potatoes is now 75 as well
```

## Функції

Функція має назву, тип повернення та (можливо, порожній) список параметрів.
Приклад функції з назвою `always_fortyseven`, яка завжди повертатиме 47, має такий вигляд:

```cpp
int always_fortyseven() {
    return 47;
}
```

Ось `vip_fee` з одним параметром:
```cpp
int vip_fee(int standard_fee) {
    /*
    vip_fee calculates the vip fee based on the standard_fee.
    */
    int vip_multi{3};
    return standard_fee * vip_multi;
}
```

Або `total_fee`: функція з трьома параметрами та викликом іншої функції.

```cpp
int total_fee(int vips, int adults, int kids) {
    /*
    total_fee calculates the total price for a group of VIP and adult guests with kids.
    Kids get a flat discount on the standard fee.
    VIP guest fees are calculated by calling vip_fee.
    */
    int standard_fee{30};
    int kids_discount{15};

    int kids_total_fee = kids  * (standard_fee - kids_discount);
    int vips_total_fee = vips * vip_fee(standard_fee);
    int adult_total_fee = adults * standard_fee;

    return vips_total_fee + adult_total_fee + kids_total_fee;
}
```

У C++ функції не повертають значення останньої інструкції, як у деяких інших мовах.
Ключове слово `return` обовʼязкове, щоб код скомпілювався.

### Пробільні символи

Пробільні символи використовують для форматування вихідного коду; до них належать пробіли, табуляції та символи нового рядка.
Оскільки компілятор ігнорує зайві пробільні символи, їх можна використовувати, щоб структурувати код.
Розумне використання пробільних символів може покращити читабельність коду.
Існують різні стандарти форматування, але всі вони умовні, і компілятор їх не вимагає.

```cpp
// Formatting makes it easier to find bugs

int eggs_yolks =  3;
int      yeast = 15;

int flour=500;int sugar=200;// compact, but difficult to read
```
