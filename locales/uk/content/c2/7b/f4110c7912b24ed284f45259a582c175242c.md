# Вступ

## Числа

У Ruby найпоширеніші два типи чисел:

- **Цілі числа:** числа без цифр після десяткового розділювача (цілі числа). Наприклад, `-6`, `0`, `1`, `25`, `976` і `500000`.
- **Числа з плаваючою комою:** числа з однією або кількома цифрами після десяткового розділювача. Наприклад, `-2.4`, `0.1`, `3.14`, `16.984025` і `1024.0`.

Вони реалізовані через класи `Integer` і `Float`.

Ці класи мають методи, які перетворюють значення з одного типу на інший. Цілі числа `Integer` точні до цілої одиниці, тоді як `Float` має точність, дробову щодо цілого числа:

- `Integer#to_f`: перетворює на нове число з плаваючою комою
- `Float#ceil`: округляє вгору до найближчого цілого числа
- `Float#floor`: округляє вниз до найближчого цілого числа
- `Float#round`: округляє до найближчого цілого числа
- `Float#to_i`: усікає до найближчого цілого числа

## Умовні конструкції

У Ruby є так звані вирази керування потоком. Вони керують тим, як виконується програма, і приймають правдиве або неправдиве значення.

Існують оператори, які створюють правдиві або неправдиві значення. Їх називають [операторами порівняння][comparison-operators].

Є два основні керуючі вирази, які визначають, який код виконається, а який ні. Інакше кажучи, яка саме гілка спрацює.

Це `if` і вираз `unless`.

## Оператори порівняння

[Оператори порівняння][comparison-operators] використовують, щоб порівнювати значення й повертати `true` або `false`.

Наведені нижче оператори потребують двох значень одного типу для порівняння. Якщо значення різних типів, компілятор видасть помилку. Ось список операторів і приклад, коли вони дають значення `true`:

| Метод | Опис                  | Приклад |
| ------ | --------------------- | ------- |
| <      | менше ніж             | 4 < 5   |
| <=     | менше ніж або дорівнює | 4 <= 4  |
| >      | більше ніж            | 3 > 1   |
| >=     | більше ніж або дорівнює | 2 >= 2  |

Оператори рівності й нерівності, на відміну від уже згаданих, можна застосовувати до значень будь-якого типу. Оператор `==` перевіряє, чи два значення рівні, і це включає перевірку типу значення. `!=` працює так само, але повертає `true`, якщо значення не рівні, і `false`, якщо рівні. Ось список операторів рівності й нерівності та приклад, коли вони дають значення `true`:

| Метод | Опис      | Приклад |
| ------ | ------------ | ------- |
| ==     | дорівнює     | 4 == 4  |
| !=     | не дорівнює  | 5 != 4  |

## Конструкція if

Конструкцію [`if`][if] використовують, щоб перевірити, чи задана умова «правдива» чи «неправдива». Якщо умова правдива, виконається код усередині конструкції if. Конструкція `if` завершується ключовим словом `end`.

```ruby
value = 1
if value == 1
  "1 is equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
end
# => nil
```

## Конструкція unless

Конструкція `unless` працює дуже схоже на конструкцію `if`, але виконує код усередині себе, якщо умова неправдива.

```ruby
value = 1
unless value == 1
  "1 is not equal to 1"
end
# => nil

unless value > 2
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## Конструкція else

Конструкцію `else` можна використовувати разом із конструкцією `if`. Конструкція `else` виконається, якщо гілка `if` не виконалася.

```ruby
value = 1
if value == 1
  "1 is equal to 1"
else
  "1 is not equal to 1"
end
# => "1 is equal to 1"
```

## «Каскадні» конструкції if

Конструкцію `elsif` можна використовувати разом із конструкцією if. Конструкція `elsif` виконається, якщо гілка if не виконалася, а умова конструкції elsif правдива. Конструкції elsif можна обʼєднувати в ланцюжок, і виконається перша правдива умова. Наприкінці конструкції if також може бути конструкція else, яка виконається, якщо жодна з попередніх умов не була правдивою.

```ruby
value = 1
if value != 1
  "1 is not equal to 1"
elsif value > 2
  "1 is greater than 2"
else
  "1 is not equal to 1 and 1 is not greater than 2"
end
# => "1 is not equal to 1 and 1 is not greater than 2"
```
