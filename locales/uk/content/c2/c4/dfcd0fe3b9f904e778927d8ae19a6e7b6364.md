# Вступ

У Kotlin рядок тексту (англ. [`string`][ref-string]) - це незмінна послідовність символів Unicode.

[`Immutable`][wiki-immutable] означає, що будь-яка операція над рядком тексту має повертати новий рядок тексту: сам початковий рядок тексту ніколи не може змінитися.

[`Unicode`][wiki-unicode] означає, що більшість систем письма світу можна подати, але (на відміну від старіших мов, як-от C) немає взаємно однозначної відповідності між символами й байтами.

Рядок тексту зазвичай беруть у подвійні лапки `" "`.

Деякі символи потрібно екранувати: `\'`, `\\`, а також звичайні недруковані символи, як-от `\t` (табуляція) і `\n` (переведення рядка).

```kotlin
val s = "Escape apostrophe \' and backslash \\."
// Escape apostrophe ' and backslash \.
```

Багаторядкові рядки тексту беруть у 3 подвійні лапки, і вони можуть містити довільний текст (екранувати не потрібно).

```kotlin
val multi = """I'm a
    multi-line
    string with special characters \ \t """
//I'm a
//    multi-line
//    string with special characters  \ \t 
```

Скористаймося [trimIndent][trimIndent-doc], щоб прибрати спільний відступ на початку рядків.
Це зручно для форматування рядка тексту:

```kotlin
val multi = """
    I'm a
      multi-line
    string""".trimIndent()

//I'm a
//  multi-line
//string
```

Або ж [trimMargin][trimMargin-doc] дає змогу задати роздільник.
Тоді кожен рядок у `String` починається після роздільника.
Типовим роздільником є `|`, але можна вказати інший роздільник як параметр.
Наприклад:

```kotlin
val multi = """
    |I'm a
    |  multi-line
    |string""".trimMargin()

//I'm a
//  multi-line
//string

val multi2 = """
    start>I'm a
    start>  multi-line
    start>string""".trimMargin("start>")

//I'm a
//  multi-line
//string
```

Рядки тексту можна зʼєднувати за допомогою `+`, але це краще обмежити короткими й простими випадками.
Є й інші, часто кращі варіанти.

## Шаблонні рядки

Ідеться про те, що в деяких інших мовах називають «інтерполяцією».

Якщо рядок тексту містить знак долара `$`, після якого йде ідентифікатор, або містить фігурні дужки (`{expression}`) навколо виразу, то замість них підставляються відповідно значення або результат цього виразу.

```kotlin
val x = 42
val st = "x is $x, x squared is {x * x}"
// x is 42, x squared is 1764
```

Фігурні дужки `{ }` потрібні навколо виразів, коли без них розбір був би неоднозначним.

Загалом шаблонні рядки - ефективніший та ідіоматичніший спосіб поєднувати рядки тексту, ніж використання `+`.

## Функції для рядків

Kotlin надає _багато_ [`functions`][ref-string-functions] для роботи з рядками тексту.

Переважно це [`extensions functions`][ref-extensions], а не члени класу `String`, хоча на те, як ми їх використовуємо, це майже не впливає.

~~~~exercism/note
Досить складні сторінки [документації][ref-string-functions] Kotlin ховають функції-розширення в типовому поданні.
Натисніть `Members & Extensions`, щоб розгорнути цей розділ.

[ref-string-functions]: https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/
~~~~

Наведені далі приклади показують лише невелику частину того, що доступно:

```kotlin
val str = "Hello World!"

str.length              // => 12 (a property, not a function)
str.elementAt(6)        // => W
str.elementAtOrNull(20) // => null (index out of range)
str.substring(6, 11)    // => "World"
str.substringAfter(" ") // => "World!"

str.lowercase()         // => "hello world!"
str.uppercase()         // => "HELLO WORLD!"

str.startsWith("Hel")   // => true
str.endsWith("xyz")     // => false
str.indexOf("0")        // => 4

str.toCharArray()       // => [H, e, l, l, o,  , W, o, r, l, d, !]
"42".toInt() + 1        // => 43  (parsing; see also toFloat)

"Howdy!  ".trim()       // => "Howdy"
```
