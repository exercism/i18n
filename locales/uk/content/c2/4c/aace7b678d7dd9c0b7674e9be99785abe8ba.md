# Вступ

Elixir належить до мов із динамічною типізацією, тобто не виконує перевірки типів під час компіляції. Утім, специфікації типів можна використовувати як форму документації.

Специфікацію типу можна додати до функції за допомогою атрибута модуля `@spec` безпосередньо перед визначенням функції. Після `@spec` іде назва функції та список типів усіх її аргументів у дужках, розділених комами. Тип поверненого значення відокремлюється від аргументів функції подвійною двокрапкою `::`.

```elixir
@spec longer_than?(String.t(), non_neg_integer()) :: boolean()
def longer_than?(string, length), do: String.length(string) > length
```

## Типи

Найуживаніші типи:

- булеві значення (англ. Boolean): `boolean()`
- рядки тексту (англ. string): `String.t()`
- числа: `integer()`, `non_neg_integer()`, `pos_integer()`, `float()`
- масиви: `list()`
- значення будь-якого типу: `any()`

Деякі типи можна також параметризувати, наприклад `list(integer)` описує масив цілих чисел.

Літеральні значення теж можна використовувати як типи.

Обʼєднання типів можна записати за допомогою вертикальної риски `|`. Наприклад, `integer() | :error` означає або ціле число, або атом `:error`.

Повний список усіх типів можна знайти в [розділі «Typespecs» в офіційній документації][types].

## Іменування аргументів

Аргументи у специфікації типу теж можна назвати, що корисно, коли треба розрізнити кілька аргументів одного типу. Назва аргументу, після якої стоїть подвійна двокрапка, ставиться перед типом аргументу.

```elixir
@spec to_hex({hue :: integer, saturation :: integer, lightness :: integer}) :: String.t()
```

## Власні типи

Специфікації типів не обмежуються лише вбудованими типами. Власні типи можна визначити за допомогою атрибута модуля `@type`. Визначення власного типу починається з назви типу, далі стоїть подвійна двокрапка, а потім сам тип.

```elixir
@type color :: {hue :: integer, saturation :: integer, lightness :: integer}

@spec to_hex(color()) :: String.t()
```

Власний тип можна використовувати як у тому самому модулі, де його визначено, так і в іншому модулі.
