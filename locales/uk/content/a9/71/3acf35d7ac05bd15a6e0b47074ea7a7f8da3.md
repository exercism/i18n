# Вступ

Рядок тексту (англ. string) у Factor складається з послідовності символів. Із рядками тексту працює більшість слів зі словника [`sequences`][sequences], а також спеціальні слова для роботи з рядками зі словників [`splitting`][splitting], [`ascii`][ascii] та подібних.

## Рядкові літерали

Рядки тексту записують у подвійних лапках. Підтримуються звичайні екрановані послідовності, як-от `\n`, `\t`, `\r`, `\\`, `\"`:

```factor
"hello, world" .                 ! => "hello, world"
"first\nsecond" print            ! prints two lines
```

## Довжина та індексація

Оскільки рядок тексту складається з послідовності символів, слова `length` і `nth` зі словника [`sequences`][sequences] працюють із ним безпосередньо.

`length` повертає кількість символів:

```factor
"hello" length .    ! => 5
```

`nth` приймає індекс із відліком від нуля та послідовність і повертає елемент на цій позиції. Для рядка тексту елементом є *символ*, тобто кодова точка (ціле число), а не підрядок з одного символу:

```factor
0 "hello" nth .     ! => 104   (CHAR: h)
4 "hello" nth .     ! => 111   (CHAR: o)
```

## Від символу назад до рядка тексту

Щоб перетворити окрему кодову точку на рядок тексту з одного символу, скористаймося словом `1string ( char -- str )` зі словника [`strings`][strings]. `CHAR:` - це форма літерала кодової точки, яку розпізнає парсер:

```factor
CHAR: A 1string .                ! => "A"
0 "hello" nth 1string .          ! => "h"
```

## Розбиття

Словник [`splitting`][splitting] розрізає рядок тексту на частини.

`split1` розрізає за *першим* входженням роздільника й повертає обидві половини:

```
split1 ( seq subseq -- before after )
```

```factor
"foo: bar" ": " split1 .s
! => "foo"
! => "bar"
```

`split` розрізає за *будь-яким* символом із набору роздільників, унаслідок чого можуть утворитися порожні частини:

```factor
"[ERROR]: Stack overflow" "[]" split .
! => { "" "ERROR" ": Stack overflow" }
```

`harvest` (зі словника [`sequences`][sequences]) відкидає порожні частини:

```factor
"[ERROR]: Stack overflow" "[]" split harvest .
! => { "ERROR" ": Stack overflow" }
```

## Вибір потрібної частини

Коли рядок тексту розбито на масив частин, слова `first`, `second`, `third` і `fourth` (зі словника [`sequences`][sequences]) повертають частину на відповідній позиції:

```factor
"apple,bee,carrot,duck" "," split first .    ! => "apple"
"apple,bee,carrot,duck" "," split second .   ! => "bee"
"apple,bee,carrot,duck" "," split third .    ! => "carrot"
"apple,bee,carrot,duck" "," split fourth .   ! => "duck"
```

Коли нам потрібні всі початкові частини на стеку одразу, `first2` і `first3` розпаковують дві чи три з них за один крок:

```factor
"apple,bee,carrot,duck" "," split first2 .s
! => "apple"
! => "bee"

"apple,bee,carrot,duck" "," split first3 .s
! => "apple"
! => "bee"
! => "carrot"
```

Для самого рядка тексту `first` повертає перший **символ**, тобто кодову точку, а не підрядок:

```factor
"hello" first .                         ! => 104   (CHAR: h)
```

## Обрізання

`[ blank? ] trim` (зі словника [`sequences`][sequences], де `blank?` походить зі словника [`ascii`][ascii]) прибирає пробільні символи на початку й у кінці:

```factor
"  Disk full \r\n" [ blank? ] trim .
! => "Disk full"
```

## Зміна регістру

`>lower` і `>upper` (зі словника [`ascii`][ascii]) повертають новий рядок тексту зі зміненим регістром:

```factor
"WARNING" >lower .    ! => "warning"
"hello" >upper .      ! => "HELLO"
```

## Зʼєднання

Два слова зі словника [`sequences`][sequences] збирають рядки тексту:

`surround` обгортає рядок тексту префіксом і суфіксом:

```
surround ( seq pre post -- new-seq )
```

```factor
"warning" "(" ")" surround .    ! => "(warning)"
```

`glue` зʼєднує два рядки тексту, ставлячи між ними роздільник:

```
glue ( s1 s2 sep -- s )
```

```factor
"Disk full" "(error)" " " glue .    ! => "Disk full (error)"
```
