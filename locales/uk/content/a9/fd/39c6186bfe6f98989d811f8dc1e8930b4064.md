# Підказки

## Загальне

- [Структури та класи][structs-and-classes] мають схожий синтаксис оголошення.

## 1. Визначити структуру Size

- Властивості потрібно оголошувати як `var`, якщо їх можна змінювати.
- Властивостям height і width потрібно надати типові значення 80 і 60 відповідно.
- Методи в структурі потрібно позначати `mutating`, якщо вони змінюють властивості структури.

## 2. Визначити структуру Position

- Властивості потрібно оголошувати як `var`, якщо їх можна змінювати.
- Властивостям x і y потрібно надати типове значення 0.
- Методи в структурі потрібно позначати `mutating`, якщо вони змінюють властивості структури.

## 3. Визначити клас Window

- Структури можна ініціалізувати різними значеннями властивостей за допомогою [ініціалізаторів для членів структури][memberwise-initializers].
- Константні властивості потрібно оголошувати за допомогою `let`.
- Властивість `contents` має бути опціональною, бо в неї може не бути значення.
- Для класу потрібно визначити порожній ініціалізатор (`init() {}`).

## 4. Додати метод для зміни розміру вікон

- Метод має приймати параметр `to` типу `Size`.
- Ширину й висоту можна витягти з параметра `to` за допомогою точкової нотації.

## 5. Додати метод для переміщення вікон

- Метод має приймати параметр `to` типу `Position`.
- x і y можна витягти з параметра `to` за допомогою точкової нотації.

## 6. Додати метод для встановлення вмісту вікна

- У Swift можна мати два методи з однаковою назвою, але різними параметрами.
- Визначити метод із параметром `title`, який встановлює властивість `title`.
- Визначити метод із параметром `text`, який встановлює властивість `contents`.
- Визначити метод display, який виводить заголовок і вміст вікна.

## 7. Створити ініціалізатор для класу Window

- Клас має мати два ініціалізатори: один без параметрів і один із параметрами.
- Новий ініціалізатор має мати параметри `title` і `contents`, а також дозволяти опціональні параметри `size` і `position`
    Якщо параметри не передані, потрібно використати типові значення.
- Опціональні параметри можна реалізувати за допомогою [типових значень параметрів][default-parameters-vales].
