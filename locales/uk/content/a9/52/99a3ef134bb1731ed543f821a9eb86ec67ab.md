# Вступ

Оператор `|>` називається оператором конвеєра. Ним можна поєднувати виклики функцій у ланцюжок так, що значення, повернене попереднім викликом функції, передається наступному виклику.

```gleam
"hello"
|> string.uppercase
|> string.append("?!")
// -> "HELLO?!"
```

Наведений вище код еквівалентний такому:

```gleam
string.append(string.uppercase("hello"), "?!")
```

Оператор конвеєра передає значення або як перший аргумент до виклику функції, або як єдиний аргумент до нового виклику, обираючи той варіант, який матиме правильний тип.

```gleam
100
|> function_that_takes_two_arguments(1)

// Is equivalent to
function_that_takes_two_arguments(100, 1)
```

```gleam
100
|> function_that_returns_a_function(1)

// Is equivalent to
function_that_returns_a_function(1)(100)
```

Іноді ми хочемо передати значення в іншу позицію. У цьому випадку можна використати заповнювач `_`, щоб указати, куди саме потрібно вставити значення.

```gleam
100
|> some_function(1, _, 2)
```
