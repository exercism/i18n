# Додаток до вказівок

## Структура проєкту

Вправи з Clojure на Exercism використовують [leiningen](http://leiningen.org/), щоб налаштувати й запускати код, і [стандартну структуру каталогів leiningen](https://github.com/technomancy/leiningen/blob/master/doc/TUTORIAL.md#directory-layout).

У каталозі `test` ми знайдемо файл з тестами `hello_world_test.clj`.
Напишіть код у `src/hello_world.clj`. Він має використовувати простір імен `hello-world`, щоб тести могли його підхопити.

## Запуск тестів

Запустіть тести командою `lein test` і зробіть так, щоб вони пройшли:

```
$ lein test

lein test hello-world-test

Ran 3 tests containing 3 assertions.
0 failures, 0 errors.
```

Потім надішліть вправу за допомогою:

```
$ exercism submit src/hello_world.clj
```

Докладніші вказівки та навчальні матеріали шукайте на [сторінці мови Clojure на Exercism](http://exercism.io/languages/clojure).
