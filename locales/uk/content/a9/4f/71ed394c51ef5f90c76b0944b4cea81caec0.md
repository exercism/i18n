# Вступ

Функція `switch()` може стати стислою заміною довгій низці перевірок `if` ... `else if`.
Змінна, за якою виконується перемикання, найчастіше є рядком тексту (англ. string), і в такому разі лапки в селекторі можна опустити.

```R
star <- function(type) {
  switch(type,
    M = , # will "fall through" if no value given
    K = "red dwarf",
    G = "Earth-like",
    "bigger star" # only correct for O,B,A,F
  )
}

> star("M")
[1] "red dwarf"
```

Зауважмо, що варіанти «провалюються» далі лише тоді, коли значення залишено порожнім, як у випадку з `M` у прикладі вище.
Немає потреби додавати інструкції `break`, як у деяких інших мовах.

Коли перемикання виконується за типом `character`, останнє значення є типовим, як тут.
А для цілих чисел типове значення вказати не можна.

## Функції в `dplyr`

`switch` у базовому R досить обмежений: він уміє лише точно збігатися з одним вхідним значенням.
Це здавалося розумним, коли R уперше вийшов 1993 року, але потребує вдосконалення для сучасного використання.

~~~~exercism/note
Як згадано в концепції [`Conditionals`][concept-conditionals], набір пакетів `tidyverse` покликаний доповнювати (а іноді й замінювати) функціональність базового R, не порушуючи зворотної сумісності.

Пакет `dplyr` можна підключити, додавши `library(dplyr)` (для одного пакета) або `library(tidyverse)` (для всього набору) на початок коду.

[concept-conditionals]: https://exercism.org/tracks/r/concepts/conditionals
~~~~

Бібліотека `dplyr` надає дві додаткові функції, повʼязані зі `switch`.

### Функції `recode_values` і `replace_values`

Ці дві споріднені функції дозволяють векторно відображати старі значення на нові, подібно до `switch`.

Головна відмінність між ними в тому, що `recode_values()` створює цілком новий вектор, а `replace_values()` дозволяє частково оновлювати наявний вектор.

Зіставлення так само точне, але:

- Варіанти ліворуч можуть бути векторами, і вхідні дані збігаються, якщо збігається будь-який елемент.
- Варіанти ліворуч і результати праворуч зʼєднані тильдою `~`, а не знаком `=`.
- Типове значення можна вказати в усіх випадках.

```R
library(dplyr)

x <- c("a", "b", "a", "d", "b", NA, "c", "e", "z")
recode_values(
  x,
  "a" ~ 1,
  "b" ~ 2,
  "c" ~ 3,
  c("d", "e") ~ 4, # either "d' or "e" will match
  NA ~ 0,          # matches missing values
  default = 100   # note the different syntax for the default
)
#> [1]   1   2   1   4   2   0   3   4 100
```

### Функція `case_when`

`case_when` розвиває синтаксис `case_match` далі, дозволяючи будь-який логічний вираз ліворуч від `~`.

Вхідний вектор (`x` у прикладі нижче) не передається як аргумент, він просто має бути вже визначений.

```R
x <- 1:10
case_when(
  x < 3 ~ "low",
  between(x, 3, 5) ~ "mid",
  between(x, 6, 8) ~ "high",
  .default = "what?"
)
#>  [1] "low"   "low"   "mid"   "mid"   "mid"   "high"  "high"  "high"  "what?" "what?"
```

Функція `between()` також входить до складу `dplyr`.
