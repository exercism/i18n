# Докладніше
Цикл дає змогу багаторазово виконувати набір з однієї або кількох інструкцій.
Кожне виконання такого набору інструкцій називають ітерацією.

## Цикл `while`

Цикл `while` виконує набір інструкцій, поки булевий вираз (англ. Boolean) угорі циклу дорівнює правді.
Коли булевий вираз дорівнює неправді, цикл припиняє роботу, і виконання переходить до наступного рядка коду після циклу.

Якщо булевий вираз від самого початку обчислюється як неправда, цикл `while` не виконається жодного разу, і виконання перейде до наступного рядка коду після циклу.

```c
int main() {
    int i = 0;
    while (i < 5) {
        printf("Number is %i\n", i++);
    }    
    return 0;
}
```

Важливо, щоб існувала умова завершення циклу; інакше це нескінченний цикл, який зупинить виконання коду.
Якби в наведеному вище коді прибрати `++` від `i`, це був би нескінченний цикл.

## Цикл `do`

У циклі `do` булевий вираз перевіряється внизу циклу.
Цикл `do` завжди виконується принаймні один раз, як у наступному прикладі

```c
do {
    printf("Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
} while (answer != 42); 
// Note that a semicolon is needed after the Boolean expression.
```

Із циклом `while` це було б багатослівніше

```c
printf(""Enter the Answer to the Ultimate Question of Life: ");
scanf("%d", &answer);
while (answer != 42) {
    printf(""Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
}
```

## Цикл `for`

Часто цикл оновлює змінну й завершується, коли змінна досягає певного значення.
Цикл `for` дає змогу ініціалізувати, оновлювати й перевіряти одну або кілька змінних в одному рядку в круглих дужках.
Перша частина призначена для ініціалізації змінної, друга - для перевірки змінної, а третя - для оновлення її значення.

```c
for (int i = 0; i < 5; i++) {
    printf("Number is %i\n", i);
}
```

Це менш багатослівно, ніж еквівалентний цикл `while`, і при цьому залишається читабельним.

Частини ініціалізації та оновлення циклу `for` можуть працювати з кількома змінними, розділяючи вирази оператором коми всередині умови.

```c
    int i, j;
    for (i = 0, j = 5; i < 5 && j > 2; i++, j--) {
        printf("i is %i\n", i);
        printf("j is %i\n", j);
    }
    printf("After the loop");
```

Це виведе

```
i is 0
j is 5
i is 1
j is 4
i is 2
j is 3
After the loop
```

Жодну з частин циклу `for` визначати не обовʼязково.
Порожній вираз перевірки обчислюється як правда, тож цикл `for` можна використати, щоб задати нескінченний цикл ось так

```c
int i = 0;
for (;;) {
    printf("Number is %i\n", i++);
    if (i == 5) break;
}
```

Це схоже на цикл `while`: змінна `i` ініціалізується перед циклом і збільшується всередині нього.
Крім того, `i` перевіряється всередині циклу, а сам цикл завершується інструкцією `break`.

## Інструкція `break`

Іноді цикл потрібно завершити за особливої умови, яка не перевіряється в його булевому виразі.
Інструкція `break` завершує цикл, і виконання переходить до наступного рядка коду після циклу.

```c
int i, j, k;
for (int i = 0, j = 5, k = 3; i < 5 && j > 2; i++, j--) {
    printf("i is %i\n", i);
    printf("j is %i\n", j);
    if (k == 3) break;
}
printf("After the loop");
```

Це виведе

```
i is 0
j is 5
After the loop
```

## Інструкція `continue`

Іноді циклу потрібно розпочати наступну ітерацію, не завершуючи поточної.
Інструкція `continue` зупиняє виконання поточної ітерації і продовжує виконання з початку наступної.

```c
int i, j;
for (int i = 0, j = 4; i < 4 && j > 0; i++, j--) {
    if (i == j) continue;
    printf("i is %i\n", i);
    printf("j is %i\n", j);
}
printf("After the loop");
```

Це виведе

```
i is 0
j is 4
i is 1
j is 3
i is 3
j is 1
After the loop
```

Вона не виводить значення `i` та `j`, коли обидві дорівнюють `2`.
