# Про

Elm - це чарівна мова для створення надійних вебзастосунків.
Вона має дружні повідомлення про помилки, чудову продуктивність, невеликі ресурси й жодних винятків під час виконання.

Мабуть, найвідоміша й найчастіше наслідувана частина Elm - це Архітектура Elm: проста схема впорядкування вебзастосунків, за якою написано всі вебзастосунки на Elm.

Основна ідея в тому, що код будується навколо `Model` - моделі стану застосунку, способу `update` цієї моделі та способу `view` її.

`Model` містить стан застосунку, тобто всі дані, потрібні застосунку.
Якщо уявити простий застосунок із текстовим полем і текстом, що показує цей текст у зворотному порядку, модель матиме такий вигляд.
Цей приклад також можна побачити в [посібнику Elm][elm-guide-text-fields].

```elm
type alias Model =
  { text : String
  }
```

`update` - це функція, яку викликають з `Msg`, коли щось змінюється (наприклад, користувач натискає кнопку).
Вона приймає `Msg` і поточний `Model` та повертає новий `Model`.

```elm
type Msg
  = TextChanged String

update : Msg -> Model -> Model
update msg model =
  case msg of
    TextChanged newText ->
      { model | text = newText }
```

`view` - це функція, яка повертає HTML для показу користувачеві в браузері.
Вона приймає поточний `Model` і повертає `Html Msg` (тип, яким Elm представляє HTML).

```elm
view : Model -> Html Msg
view model =
  Html.div []
    [ Html.input
      [ Html.Attributes.placeholder "Text to reverse"
      , Html.Attributes.value model.text
      , Html.Events.onInput TextChanged
      ]
      []
    , Html.div [] [ Html.text (String.reverse model.text) ]
    ]
```

[elm-guide-text-fields]: https://guide.elm-lang.org/architecture/text_fields
