# Інструкції

Продовжуючи працювати в _Instruments of Texas_, ми бачимо поступ у роботі над реалізацією калькулятора зі зворотним польським записом на Elixir. Наша команда хотіла б мати змогу викликати помилки, конкретніші за загальні помилки зі стандартної бібліотеки. Ми ще дещо досліджуємо, але вже вирішили реалізувати дві нові помилки, які втілюють _Exception Behaviour_.

## 1. Помилка для ділення на нуль

Ділення числа на нуль дає невизначений результат, і команда вирішує, що найкраще подати його як помилку.

Реалізуйте модуль `DivisionByZeroError` з таким повідомленням про помилку: `"division by zero occurred"`

```elixir
raise DivisionByZeroError
# => ** (DivisionByZeroError) division by zero occurred
```

## 2. Помилка в разі спустошення стека

Калькулятори зі зворотним польським записом використовують _стек_, щоб зберігати числа до того, як їх додадуть. Команда подає цей _стек_ як список чисел (цілих і з плаваючою комою), наприклад: `[3, 4.0]`. Кожній операції потрібна певна кількість чисел у стеку, щоб виконати своє обчислення. Коли чисел у стеку не вистачає, це називається помилкою спустошення стека. Реалізуйте виняток `StackUnderflowError`, який надає типове повідомлення та необовʼязковий додатковий контекст

```elixir
raise StackUnderflowError
# => ** (StackUnderflowError) stack underflow occurred

raise StackUnderflowError, "when dividing"
# => ** (StackUnderflowError) stack underflow occurred, context: when dividing
```

## 3. Напишіть функцію ділення

Реалізуйте функцію `divide/1`, яка приймає стек _(список із двох чисел)_ і:

- викликає помилку _спустошення стека_, коли в стеку недостатньо чисел
- викликає помилку _ділення на нуль_, коли дільник дорівнює 0 (зверніть увагу, що стек чисел зберігається у зворотному порядку)
- виконує ділення, коли жодної помилки не виникає

```elixir
RPNCalculator.Exception.divide([])
# => ** (StackUnderflowError) stack underflow occurred, context: when dividing

RPNCalculator.Exception.divide([0, 100])
# => ** (DivisionByZeroError) division by zero occurred

RPNCalculator.Exception.divide([4, 16])
# => 4
```

> Зверніть увагу, що порядок елементів у списку зворотний!
