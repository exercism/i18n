# Про ітератори

Ітератори в Haxe використовуються для перебирання значення за допомогою циклу `for`. Існує два типи ітераторів:

- `Iterator` — це тип, який перебирає значення.
- `Iterable` — це дані, які дають змогу перебирати тип даних.

Обидва ці поняття представлені `Iterator<T>` і `Iterable<T>`:

```haxe
typedef Iterator<T> = {
  function hasNext():Bool;
  function next():T;
}

typedef Iterable<T> = {
  function iterator():Iterator<T>;
}
```

Будь-який клас, який уніфікується з одним із цих типів, можна перебирати за допомогою циклу `for`. Якщо клас визначає методи `hasNext` і `next`, його вважають ітератором; інакше, якщо він визначає метод `iterator`, його вважають ітерабельним типом:

```haxe
class MyStringIterator {
  var str:String;
  var i:Int;

  public function new(str:String) {
    this.str = str;
    i = 0;
  }

  public function hasNext():Bool {
    return i < str.length;
  }

  public function next():String {
    return str.charAt(i++);
  }
}
```

У наведеному вище прикладі клас `MyStringIterator` вважають ітератором, оскільки він реалізує обидва методи `hasNext` і `next`, що робить його сумісним із `Iterator<String>`.

```haxe
class MyArrayWrap<T> {
  var arr:Array<T>;

  public function new(a:Array<T>) {
    this.a = a;
  }

  public function iterator() {
    return a.iterator();
  }
}
```

Тут клас `MyArrayWrap` вважають ітерабельним типом даних, оскільки він сумісний із `Iterable<Array<T>>`.
