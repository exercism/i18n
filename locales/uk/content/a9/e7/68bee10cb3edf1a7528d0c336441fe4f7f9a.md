# Докладніше

[Структури][structs-and-classes] (які зазвичай називають *struct*) - це один з основних будівельних блоків програм мовою Swift.
Структури дають змогу створювати власні типи, які обʼєднують повʼязані властивості (дані) та методи (поведінку).
Насправді всі стандартні типи Swift, як-от `Int`, `Double`, `Bool`, `String`, `Array` і `Dictionary`, реалізовано як структури.

## Визначення структур

Структуру визначають за допомогою ключового слова `struct`, після якого йде назва типу й фігурні дужки з її визначенням.
За домовленістю Swift назви структур записують у `UpperCamelCase`:

```swift
struct CharacterStats {
    var health = 0.0
    var speed = 0
    var strength = 0
}
```

## Створення примірників

Визначення структури - це лише креслення.
Щоб створити *примірник* структури, треба викликати її ініціалізатор: написати назву типу, а потім пару дужок:

```swift
var someStats = CharacterStats()
```

Так створюється примірник, заповнений типовими значеннями властивостей із визначення.

Swift також автоматично генерує для структур **ініціалізатор за членами**, який дає змогу ініціалізувати властивості за назвою:

```swift
let customStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

## Доступ і зміна властивостей

До властивостей примірника звертаються й змінюють їх за допомогою *точкової нотації*:

```swift
var stats = CharacterStats()

print(stats.health) // Prints 0.0

stats.health = 87.3
print(stats.health) // Prints 87.3
```

Оскільки структури є типами-значеннями, для зміни властивостей примірника сам примірник потрібно оголосити за допомогою `var`.
Якщо ж примірник оголошено з `let`, усі його властивості стають незмінними.
