# Вступ

## Масиви

У Ruby **масиви** - це впорядковані колекції будь-яких обʼєктів з індексами-цілими числами.
Індексація масиву починається з `0`.
Відʼємний індекс вважається відносним до кінця масиву, наприклад, індекс `-1` указує на останній елемент масиву, `-2` - на передостанній елемент масиву, і так далі.

### Створення масивів

Масиви зазвичай створюють за допомогою запису `[]`.
Вони можуть містити обʼєкти різних типів.

```ruby
array = [1, "two", 3.0]
```

### Доступ до елементів

Елементи масиву можна отримати за їхніми індексами, використовуючи метод `#[]`.
Він повертає елемент за індексом або підмасив, що починається з початкового індексу й триває вказану довжину.
Відʼємні індекси відраховуються назад від кінця масиву.

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[2]       #=> "c"
a[6]       #=> nil
a[1, 3]    #=> [ "b", "c", "d" ]

a[-1]      #=> "e"
a[-2]      #=> "d"
a[-3, 2]   #=> ["c", "d"]
```

### Допоміжні методи

У масивів є багато корисних допоміжних методів.
Ось деякі з найпоширеніших:

```ruby
fibonacci = [0, 1, 1, 2, 3, 5, 8, 13]

fibonacci.size      #=> 8
fibonacci.sum       #=> 33
fibonacci.reverse   #=> [13, 8, 5, 3, 2, 1, 1, 0]
```

## Перебирання

Замість того щоб перебирати колекції циклами, у Ruby ми використовуємо перебирання.

Перебирання - це процес проходження колекцією (у цьому випадку масивом) і виконання певної дії над кожним обʼєктом. Перебирання - ключова концепція в Ruby, і його використовують для таких речей, як сортування, групування, перетворення, згортання та багато іншого.

Перебирання, яке виводить кожне слово з масиву, матиме такий вигляд:

```ruby
words = ["the", "cat", "sat"]
words.each do |word|
  puts word
end

# Output:
# the
# cat
# sat
```

У цьому прикладі ми викликали метод `.each` на нашому масиві й передали _блок_, який приймає один параметр (`word`) і виводить його.

Ми детальніше розглянемо _блоки_ пізніше в треку, а поки що сприймаймо їх як анонімні функції, які можуть приймати нуль або більше аргументів.
Їх можна визначити за допомогою синтаксису `do...end` (вище) або синтаксису `{}` (нижче).

Ось інші приклади методів масиву, які використовують блоки:

```ruby
fibonacci = [0, 1, 1, 2, 3, 5, 8, 13]

fibonacci.count  { |number| number == 1 }   #=> 2
fibonacci.any?   { |number| number == 6 }   #=> false
fibonacci.select { |number| number.odd? }   #=> [1, 1, 3, 5, 13]
fibonacci.all?   { |number| number < 20 }   #=> true
fibonacci.map    { |number| number * 2  }   #=> [0, 2, 2, 4, 6, 10, 16, 26]
```
