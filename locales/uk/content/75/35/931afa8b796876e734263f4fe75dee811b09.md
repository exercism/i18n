# Інструкції

Дано два довільні масиви `A` і `B`. Визначмо, чи:

- масив `A` дорівнює масиву `B`; або
- масив `A` містить масив `B` (`A` є надмасивом `B`); або
- масив `A` міститься в масиві `B` (`A` є підмасивом `B`); або
- жодна з наведених умов не виконується, отже масиви `A` і `B` нерівні

Зокрема, масив `A` дорівнює масиву `B`, якщо обидва масиви містять однакові значення в однаковому порядку.
Масив `A` є надмасивом `B`, якщо `A` містить підпослідовність значень, що дорівнює `B`.
Масив `A` є підмасивом `B`, якщо `B` містить підпослідовність значень, що дорівнює `A`.

Приклади:

- Якщо `A = []` і `B = []` (обидва масиви порожні), то `A` і `B` рівні
- Якщо `A = [1, 2, 3]` і `B = []`, то `A` є надмасивом `B`
- Якщо `A = []` і `B = [1, 2, 3]`, то `A` є підмасивом `B`
- Якщо `A = [1, 2, 3]` і `B = [1, 2, 3, 4, 5]`, то `A` є підмасивом `B`
- Якщо `A = [3, 4, 5]` і `B = [1, 2, 3, 4, 5]`, то `A` є підмасивом `B`
- Якщо `A = [3, 4]` і `B = [1, 2, 3, 4, 5]`, то `A` є підмасивом `B`
- Якщо `A = [1, 2, 3]` і `B = [1, 2, 3]`, то `A` і `B` рівні
- Якщо `A = [1, 2, 3, 4, 5]` і `B = [2, 3, 4]`, то `A` є надмасивом `B`
- Якщо `A = [1, 2, 4]` і `B = [1, 2, 3, 4, 5]`, то `A` і `B` нерівні
- Якщо `A = [1, 2, 3]` і `B = [1, 3, 2]`, то `A` і `B` нерівні
