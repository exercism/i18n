# Інструкції

Conda Airlines - найбільша авіакомпанія у світі програмування, що виконує понад 10 000 рейсів щодня!

Зараз вони призначають усі місця пасажирам вручну; це потрібно автоматизувати.

Вони попросили _нас_ створити програмне забезпечення, яке автоматизує призначення місць пасажирам.
Вони вимагають, щоб наше програмне забезпечення економно витрачало памʼять і працювало швидко.

## 1. Згенеруйте літери місць

Conda хоче генерувати літери місць для своїх літаків.
Літак складається з рядів місць.
У кожному ряду _4 місця_.
Місця в кожному ряду завжди мають назви `A`, `B`, `C` і `D`.
Перше місце в ряду - `A`, друге місце в ряду - `B`, і так далі.
Після `D` усе починається знову з `A`.

Реалізуйте функцію `generate_seat_letters(<number>)`, яка приймає `int`, у якому записано, скільки літер місць потрібно згенерувати.
Тоді функція має повернути _ітерабельний обʼєкт_ з літер місць.

```python
>>> letters = generate_seat_letters(4)
>>> next(letters)
"A"
>>> next(letters)
"B"
```

## 2. Згенеруйте місця

Conda хоче систему, яка може згенерувати задану кількість місць для своїх літаків.
У кожного літака _4 місця_ в кожному ряду.
Ряди задаються числами, починаючи з `1` і далі.
Місця мають бути впорядковані так: `1A`, `1B`, `1C`, `1D`, `2A`, `2B`, `2C`, `2D`, `3A`, `3B`, `3C`, `3D`, ...

Ось приклад:

|      x      |  1  |  2  |
| :---------: | :-: | :-: |
|     Ряд     |  5  | 21  |
| Літера місця |  A  |  D  |
|  Результат  | 5A  | 21D |

Через забобони серед пасажирів багато авіакомпаній не використовують _ряд_ номер 13 на своїх рейсах.
Conda Airlines також дотримується цієї традиції, тож подбайте, щоб ми _не_ генерували місця для _ряду_ номер 13.

Реалізуйте функцію `generate_seats(<number>)`, яка приймає `int`, у якому записано, скільки місць потрібно згенерувати.
Тоді функція має повернути _ітерабельний обʼєкт_ із цими місцями.

```python
>>> seats = generate_seats(10)
>>> next(seats)
"1A"
>>> next(seats)
"1B"
```

## 3. Призначте місця пасажирам

Тепер, коли у нас є функція, яка генерує місця, ми можемо використати її, щоб призначити місця пасажирам.

Реалізуйте функцію `assign_seats(<passengers>)`, яка приймає `list` з іменами пасажирів.
Тоді функція має повернути _словник_, де `passenger` - _ключ_, а `seat_number` - _значення_.

```python
>>> passengers = ['Jerimiah', 'Eric', 'Bethany', 'Byte', 'SqueekyBoots', 'Bob']

>>> assign_seats(passengers)
{'Jerimiah': '1A', 'Eric': '1B', 'Bethany': '1C', 'Byte': '1D', 'SqueekyBoots': '2A', 'Bob': '2B'}
```

## 4. Коди квитків

Conda Airlines хотіла б мати унікальний код для кожного квитка.
Оскільки це велика авіакомпанія, у неї багато рейсів.
Це означає, що є багато рейсів з однаковим номером місця.
Вони хочуть, щоб ми створили систему, яка формує унікальний квиток - рядок тексту (англ. string) завдовжки _12_ символів.

Цей код починається з `assigned_seat`, за яким іде `flight_id`.
Решту коду заповнюють `0s`.

Реалізуйте функцію `generate_codes(<seat_numbers>, <flight_id>)`, яка приймає `list` із `seat_numbers` і `string` з номером рейсу.
Тоді функція має повернути `generator`, який видає `ticket_number`.

```python
>>> seat_numbers = ['1A', '17D']
>>> flight_id = 'CO1234'
>>> ticket_ids = generate_codes(seat_numbers, flight_id)

>>> next(ticket_ids)
'1ACO12340000'
>>> next(ticket_ids)
'17DCO1234000'
```
