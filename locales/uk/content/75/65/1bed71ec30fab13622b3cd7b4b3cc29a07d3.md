# Entry API

Часто найідіоматичніший спосіб керувати вмістом мапи - це Entry API. Однак, що для Rust незвично, його не формалізовано в трейт: це лише набір типів і методів, реалізованих для типів мап стандартної бібліотеки.

По суті, метод `map.entry()` надає `enum`:

```rust
enum Entry {
    Occupied(_),
    Vacant(_),
}
```

Користь походить від подальших методів, реалізованих для цього `enum`. Наприклад, якщо ми хочемо отримати значення для певного ключа й, можливо, змінити його, а типове значення цього типу нам підходить, можна просто зробити так:

```rust
// `entry` has type `&mut Value` for the value type of the map
let entry = map.entry(key).or_default();
```

Для застосунків на кшталт лічильника це дуже полегшує життя:

```rust
let counts: HashMap<_, usize> = HashMap::new();
for item in sequence {
    *counts.entry(item).or_default() += 1;
}
```

Якщо типове значення типу нам не підходить, можна вказати власне стале типове значення за допомогою `or_insert` або обчислити його за допомогою `or_insert_with`.

У деяких випадках може знадобитися виконати обчислення над наявним значенням ще до можливих вставок. У таких випадках це дозволяє `and_modify`. Однак таке застосування трапляється доволі рідко. Частіше `and_modify` використовують, щоб уникнути потреби розіменовувати значення:

```rust
map.entry(key).and_modify(|v| *v += 1).or_default();
```

Іноді буває зручно зіставляти `Entry` напряму. Це цілком припустимо:

```rust
match map.entry(key) {
    Entry::Occupied(occupied) => println!("removed from the map: {:?}", occupied.remove_entry()),
    Entry::Vacant(vacant) => println!("key not present in map: {:?}", vacant.key()),
}
```

Щоб дізнатися більше, див. [`std::collections::hash_map::Entry`](https://doc.rust-lang.org/std/collections/hash_map/enum.Entry.html) та [`std::collections::btree_map::Entry`](https://doc.rust-lang.org/std/collections/btree_map/enum.Entry.html).
