# Вступ

`Option` - це enum, який використовують, щоб перевіряти коректність повернених значень функції. Він визначений так:

```haxe
enum Option<T> {
  Some(v:T);
  None;
}
```

Він належить до пакета `haxe.ds`:

```haxe
import haxe.ds.Option;

class Main {
  static public function main() {
    var result = trySomething();

    switch (result) {
      case None:
        trace("Nothing");
      case Some(s):
        trace("Got: " + s);
    }
  }

  static public function trySomething():Option<String> {
    if (Math.random() > 0.5) {
      return None;
    } else {
      return Some("Success");
    }
  }
}
```
