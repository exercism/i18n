# Умовні конструкції

**Умовна конструкція** обирає між двома варіантами дій залежно від того, чи є щось правдою.

```sather
   verdict(score : INT) : STR is
      if score >= 5 then
         return "Recalled";
      else
         return "Thank you";
      end;
   end;
```

Читаймо це так: спочатку `if`, потім питання, яке дає відповідь `true` або `false`, потім `then`. Рядки після `then` виконуються, коли відповідь — правда, а рядки після `else` — коли вона неправда. `end;` закриває всю конструкцію.

## Більше ніж два варіанти

`elsif` додає ще одне питання, яке ставиться лише тоді, коли попередні виявилися неправдою.

```sather
   verdict(score : INT) : STR is
      if score >= 8 then
         return "Cast";
      elsif score >= 5 then
         return "Recalled";
      else
         return "Thank you";
      end;
   end;
```

Порядок має значення. Оцінку `9` перехоплює перше питання, і вона вже не доходить до другого, хоча `9 >= 5` теж правда. Найчастіша помилка тут — записати перевірки в неправильному порядку.

Пишеться `elsif`, а не `elseif` і не `else if`.

## Коли `else` можна опустити

`else` можна опустити, якщо в цьому випадку нічого робити не треба.

```sather
   if late then
      apologise;
   end;
```

Функція, яка має щось повернути, потребує, щоб кожен шлях повертав значення, тому в цій вправі кожен `if` залишає свій `else`.
