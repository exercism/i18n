# Вступ

Припускаємо, що синтаксис і типи даних JSON нам уже знайомі.

`jq` працює так: пропускає вхідні дані JSON через _єдиний вираз_ (записаний як _конвеєр фільтрів_), щоб отримати потрібні перетворені дані.

<!-- prettier-ignore -->
~~~~exercism/note
Мову `jq` реалізує _програма_ `jq`.
Ця програма має кілька зручних параметрів командного рядка, які керують тим, як обробляються вхідні дані та як подаються вихідні.

Нижче в прикладах ми побачимо:

- `-n` або `--null-input`

    Зазвичай програмі `jq` дають файл для читання, або ми надсилаємо дані на її вхід.
    Параметр `--null-input` дає змогу генерувати дані JSON без жодних вхідних даних.

- `-c` або `--compact-output`

    Типово `jq` виводить результат у гарно відформатованому вигляді.
    Людям дуже зручно дивитися на дані, коли вони гарно відформатовані.
    Однак для машин це не потрібно: параметр `--compact-output` прибирає пробіли форматування, щоб зменшити розмір отриманого JSON.

- `-f filename` або `--from-file filename`

    Читає програму `jq` з `filename` замість того, щоб передавати її в командному рядку.
    І `sed`, і `awk` використовують параметр `-f` для тієї самої мети.
    Ми побачимо це в тестових скриптах для практичних вправ.

Решта цього уроку присвячена _мові_ `jq`.
~~~~

## Фільтри та конвеєри

**Фільтри** також відомі як **вирази**.

_Фільтр_ приймає вхідні дані й видає вихідні.
Так само, як ми працюємо в оболонці Unix, _фільтри_ можна поєднувати конвеєром `|`, щоб зʼєднати вихідні дані одного _фільтра_ з вхідними даними іншого.

## Фільтр тотожності: `.`

Це найпростіший _фільтр_.
Він просто передає свої вхідні дані на вихід.

```sh
$ echo '[1, 2, 3]' | jq '.'
[
  1,
  2,
  3
]
```

## Масиви

Це буде короткий вступ до роботи з **масивами**.
Докладніше ми розглянемо цю тему пізніше.

До елементів _масиву_ звертаються через дужки, і їхній індекс починається з нуля.

```sh
$ echo '[10, 20, 30]' | jq '.[1]'
20
```

_Фільтр_ може побудувати _масив_, обгорнувши вираз у `[` та `]`

- з відомим масивом елементів:

  ```sh
  jq -n '[1, 2, 3]'
  ```

- щоб зібрати потік елементів: наприклад,
  `range` - це функція, яка видає потік чисел

  ```sh
  $ jq -n 'range(10; 70; 15)'
  10
  25
  40
  55
  ```

  Використання `[]` збирає результати виразу в масив

  ```sh
  $ jq -c -n '[range(10; 70; 15)]'
  [10,25,40,55]
  ```

## Кома як оператор

_Кома_ - не лише синтаксис, що розділяє елементи _масиву_.
**Кома** - це **оператор**, який обʼєднує потоки.

Наприклад, `[1, 2, 3]` - це _фільтр_, який використовує конструктор _масиву_ `[]`, щоб зібрати результат обʼєднання трьох виразів `1`, `2` і `3`.

Чи помітили ми крапки з комою в `range(10; 70; 15)` вище?
Оскільки _коми_ мають особливе призначення в мові `jq`, функції, які приймають кілька аргументів, розділяють аргументи крапками з комою.

## Обʼєкти

Короткий вступ до **обʼєктів**.

Як і в багатьох мовах програмування, до властивостей _обʼєкта_ звертаються через крапку

```sh
$ echo '{"foo": {"bar": "qux"}}' | jq '.foo.bar'
"qux"
```

<!-- prettier-ignore -->
~~~~exercism/note
Дужки можна використовувати й для _обʼєктів_, але тоді для рядкових літералів (англ. string) потрібні лапки.
Це один зі способів працювати з ключами, що містять пробіли.

```sh
$ echo '{"foo bar": "qux"}' | jq '.["foo bar"]'
"qux"
```
~~~~

<!-- prettier-ignore-end -->

_Обʼєкт_ можна побудувати з `{}` і пар `key: value`.
Лапки не потрібні навколо _ключів_, які є «простими» рядками тексту.

```sh
jq -n '{question: (6 * 9), answer: 42}'
```

виводить

```none
{
  "question": 54,
  "answer": 42
}
```

Щоб розглядати _ключ_ як _вираз_, його потрібно взяти в дужки (наступний приклад виводить те саме, що й вище).

```sh
echo '[{"key":"question", "value":54}, {"key":"answer", "value":42}]' \
| jq '{(.[0].key): .[0].value, (.[1].key): .[1].value}'
```

## Конвеєри

Наприклад, якщо `file.json` містить

```json
{
  "key1": "value1",
  "key2": [5, 15, 25]
}
```

Обчислімо довжину _масиву_ key2:

```sh
$ jq '.key2 | length' file.json
3
```

Ми _спрямовуємо_ вихідні дані виразу `.key2` конвеєром на вхід `length`, який, що не дивно, виводить кількість елементів у _масиві_.

## Фільтри можуть ігнорувати свої вхідні дані

У цьому прикладі вхідні дані JSON ігноруються й не впливають на результат:

```sh
$ echo '{"answer": 42}' | jq '6 * 9'
54
```

## Фільтри можуть видавати потоки даних

_Фільтр_ може видавати більше ніж одне значення.
Наприклад, _фільтр_ `.[]` видає кожен елемент _масиву_ як окреме значення:

```sh
$ jq -n -c '[1, 2, 3]'
[1,2,3]

$ jq -n -c '[1, 2, 3] | .[]'
1
2
3
```

Якщо спрямувати такий _фільтр_ в інший, другий _фільтр_ виконається **_для кожного значення_**:

```sh
$ jq -n -c '[1, 2, 3] | .[] | . * 2'
2
4
6
```

Це схоже на неявну ітерацію.
Коли ми зрозуміємо цей прийом, то побачимо, що дуже потужні _фільтри_ `jq` можуть бути вельми лаконічними.

## Круглі дужки

**Круглі дужки** використовують, щоб групувати підвирази й задавати порядок виконання операцій, як і в інших мовах.
У `jq` потреба в них може здатися дещо несподіваною.

Наприклад, скажімо, ми хочемо побудувати _масив_ із 2 елементів: квадратний корінь з 9 та _e_ у степені 1.
Два окремі вирази - це `9 | sqrt` і `1 | exp`.
Ми очікуємо, що результатом буде _масив_ `[3, 2.7...]`

```jq
$ jq -n '[ 9|sqrt, 1|exp ]'
[
  20.085536923187668,
  2.718281828459045
]
```

Чому ми отримали не те, що очікували? `jq` розуміє це так:

```jq
[ ((9|sqrt), 1) | exp ]
```

`jq` будує потік із двох елементів (`3` та `1`), і кожен з них передається в `exp`.

Треба подбати, щоб `exp` приймав на вхід лише одне число.
Інакше кажучи, треба зробити так, щоб конвеєр обчислювався раніше за кому.

```jq
$ jq -n '[ 9|sqrt, (1|exp) ]'
[
  3,
  2.718281828459045
]
```

## Функції та оператори

Не заглиблюючись надто (функції будуть темою іншої вправи), ось кілька корисних вбудованих функцій:

- `length`

  Якщо на вхід подано масив, виводить кількість елементів у ньому.

  ```sh
  $ jq -n '[10, 20, 30, 40] | length'
  4
  ```

- `+`

  Цей оператор робить різні речі залежно від типу своїх операндів:
  додає числа,
  зʼєднує рядки тексту,
  приєднує масиви,
  обʼєднує обʼєкти.

  ```sh
  $ jq -c -n '
      3 + 4,
      "foo" + "bar",
      ["a", "b"] + ["c"],
      {"m": 10} + {"n": 20}
  '
  7
  "foobar"
  ["a","b","c"]
  {"m":10,"n":20}
  ```

  `add` - це функція, яка приймає масив і повертає елемент, у якому всі елементи додано разом за правилами `+`.
  `[1, 2, 3] | add` виводить `6`.

- `map`

  Якщо на вхід подано масив, а як аргумент - фільтр, виводить масив, у якому фільтр застосовано до кожного елемента

  ```sh
  $ jq -c -n '[10, 20, 30, 40] | map(. / 5)'
  [2,4,6,8]
  ```

- `select`

  Якщо подано _якісь_ вхідні дані та фільтр як аргумент:
  - якщо застосування фільтра до аргументу дає значення _правда_, виводить вхідні дані без змін
  - інакше не виводить _нічого_ (не значення `null`, а справді нічого)

  Наприклад, маючи деякі числа, виберімо ті, що діляться на 3

  ```sh
  $ jq -n 'range(10) | select(. % 3 == 0)'
  0
  3
  6
  9
  ```

  Пригадаймо, що `range` видає _потік_ чисел.
  `select` викликається для кожного числа.
  Виводяться лише ті числа, які «проходять» цей вираз.

  Часто потрібно вибрати елементи масиву.
  Є кілька способів це зробити.

  Маючи вхідні дані `["Anne", "Bob", "Cathy", "Dave"]`, виберімо імена довжиною 4.
  - використати `map` і `select` разом

    ```jq
    map(select(length == 4))
    ```

  - розкласти масив на елементи, застосувати `select` до цього потоку й зібрати результати

    ```jq
    [ .[] | select(length == 4) ]
    ```
