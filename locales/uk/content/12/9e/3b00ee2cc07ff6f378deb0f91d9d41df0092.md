# Вступ

`String` у Java - це обʼєкт, який представляє незмінний текст як послідовність символів Unicode (літер, цифр, розділових знаків тощо).
Щоб створити екземпляр `String`, використовують подвійні лапки:

```java
String fruit = "Apple";
```

Рядки тексту (англ. string) опрацьовують, викликаючи їхні методи.
Щойно рядок тексту створено, його значення вже не може змінитися.
Будь-які методи, які нібито змінюють рядок тексту, насправді повертають новий рядок тексту.
Клас `String` надає деякі _статичні_ методи для перетворення рядків тексту.
