# Використовуйте `||` замість if-else

Коли потрібно змінити значення, якщо воно дорівнює `nil` або будь-якому іншому неправдивому значенню, використовуйте оператор `||` замість умовної конструкції if-else.
Це ідіоматичніше й лаконічніше, а також працює швидше.

Оператор `||` повертає значення ліворуч від оператора, якщо воно правдиве, інакше він повертає значення праворуч від оператора.

Наприклад:

```crystal
# Rather than:
value.nil? ? "default" : value

# Consider:
value || "default"
```
