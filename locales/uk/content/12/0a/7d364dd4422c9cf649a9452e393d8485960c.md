# Додаток до інструкцій

## Регістри

| Регістр | Використання | Тип | Опис |
| -------- | ------------ | ------- | ----------------------------------- |
| `$a0`    | вхідні дані | ціле число | межа |
| `$a1`    | вхідні/вихідні дані | адреса | масив призначення для простих чисел |
| `$v0`    | вихідні дані | ціле число | кількість простих чисел |
| `$t0-9`  | тимчасовий | будь-який | використовується для тимчасового зберігання |
