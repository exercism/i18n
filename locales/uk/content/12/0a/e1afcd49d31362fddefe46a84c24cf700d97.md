Perl - мова програмування, створена Ларрі Воллом; уперше випущена 1987 року.

## Пакети та модулі

Пакет - це набір коду, який часто міститься у файлі модуля з тією самою назвою та розширенням `.pm`.
Потім модуль можна імпортувати в інший файл, зазвичай за допомогою ключового слова `use`.

```perl
# Foo.pm
package Foo;

# Accessible with `Foo::bar` when module is used
# or just `bar` if the subroutine is exported.
sub bar () {
    return 1;
}
```

## Змінні

Є скалярні змінні (`$foo`), масиви (`@bar`) і словники (`%baz`).
Щоб не ускладнювати, тут ми будемо використовувати лише скалярні змінні.
Скалярне значення може бути таким: рядок тексту (англ. string), число, булеве значення (англ. Boolean) або [посилання][perlreftut] на щось.
Відсутність значення позначається як `undef`.


Ключові слова `my` і `our` оголошують змінну в лексичній області видимості, наприклад `my $foo;`.
З `our` змінна також буде повʼязана зі змінною пакета з тією самою назвою.
Існують й інші способи оголошення змінних, які тут не розглядаються.

Присвоїти значення змінній можна за допомогою оператора `=`, наприклад `$foo = 1;`, і це можна зробити одночасно з оголошенням змінної, наприклад `my $foo = 1;`.

```perl
package Foo;

sub baz () {
    our $bar = 1; # Sets both $bar and $Foo::bar as 1.
    return $bar;
}

$Foo::bar = 2; # $bar is not accessible here, but $Foo::bar is.

# Both of these will print 1.
say baz;
say $Foo::bar;
```

## Підпрограми

Ключове слово `sub` оголошує [підпрограму][perlsub].
Ключове слово `return` завершує підпрограму, повертаючи вказані значення, або порожній список, якщо нічого не вказано.
Без явного `return` повернене значення визначається контекстом (скалярним, списковим чи порожнім) викликаної підпрограми та її останньою інструкцією.

```perl
sub hello () {
    return 'Hello, World!';
}
```

У новіших версіях Perl можна вказати формальні параметри в [сигнатурі][perlsubsig].
Список параметрів може містити скалярні змінні, масиви або словники.
Порожній список параметрів означає, що підпрограма приймає нуль аргументів.
У старіших версіях Perl аргументи доводилося діставати зі спеціальної змінної `@_`, але тут ми це не розглядаємо.
