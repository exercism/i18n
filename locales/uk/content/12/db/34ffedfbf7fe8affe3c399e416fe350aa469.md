# Інструкції

У цій вправі ми будемо створювати обробку помилок для простого калькулятора цілих чисел. Щоб спростити завдання, методи для обчислення додавання, множення та ділення вже надані.

Мета - мати робочий калькулятор, який повертає рядок тексту (англ. string) такого вигляду: `16 + 51 = 67`, коли йому передано аргументи `16`, `51` та `+`.

```csharp
SimpleCalculator.Calculate(16, 51, "+"); // => returns "16 + 51 = 67"

SimpleCalculator.Calculate(32, 6, "*"); // => returns "32 * 6 = 192"

SimpleCalculator.Calculate(512, 4, "/"); // => returns "512 / 4 = 128"
```

## 1. Реалізуйте операції калькулятора

Головним методом, який треба реалізувати в цьому завданні, буде (_статичний_) метод `SimpleCalculator.Calculate()`. Він приймає три аргументи. Перші два аргументи - цілі числа, над якими буде виконуватися операція. Третій аргумент має тип рядка тексту, і в цій вправі потрібно реалізувати такі операції:

- додавання за допомогою рядка тексту `+`
- множення за допомогою рядка тексту `*`
- ділення за допомогою рядка тексту `/`

## 2. Обробіть неприпустимі операції

Будь-який інший символ операції має викидати виняток `ArgumentOutOfRangeException`. Якщо аргумент операції є порожнім рядком тексту, тоді метод має викидати виняток `ArgumentException`. Якщо як аргумент операції передано `null`, тоді метод має викидати виняток `ArgumentNullException`.

```csharp
SimpleCalculator.Calculate(100, 10, "-"); // => throws ArgumentOutOfRangeException

SimpleCalculator.Calculate(8, 2, ""); // => throws ArgumentException

SimpleCalculator.Calculate(58, 6, null); // => throws ArgumentNullException
```

## 3. Обробіть помилки під час ділення на нуль

Коли ми намагаємося поділити на `0`, калькулятор має повернути рядок тексту з вмістом `Division by zero is not allowed.`. Будь-які інші винятки метод `SimpleCalculator.Calculate()` обробляти не повинен.

```csharp
SimpleCalculator.Calculate(512, 0, "/"); // => returns "Division by zero is not allowed."
```
