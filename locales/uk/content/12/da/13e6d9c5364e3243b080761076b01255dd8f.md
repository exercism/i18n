# Тип кортеж

Кортеж - це універсальний й ефективний складений тип даних у Cairo, який дає змогу обʼєднати кілька значень різних типів в одну сутність.
Кортежі мають фіксовану довжину: щойно їх оголошено, їхній розмір не може змінитися.

## Створення кортежів

Щоб створити кортеж, ми записуємо список значень, розділених комами, у дужках.
Кожна позиція в кортежі має певний тип, і ці типи можуть відрізнятися один від одного.

```rust
fn main() {
    let tup: (u32, u64, bool) = (10, 20, true);
}
```

Кортеж може містити кілька значень різних типів даних, зокрема інші кортежі.
Наприклад:

```rust
fn main() {
    let nested_tup: ((i32, u64), (u8, bool)) = ((10, 3), (5, false));
}
```

Тут змінна `nested_tup` - це кортеж, що містить два кортежі, а отже, кортежі можуть містити інші кортежі як елементи.

## Деструктурування кортежів

Щоб отримати доступ до окремих значень у кортежі, можна скористатися зіставленням із зразком і деструктурувати кортеж.
Це розбиває кортеж на його складові частини.

```rust
fn main() {
    let tup = (500, 6, true);

    let (x, y, z) = tup;

    println!("x is: {x}"); // prints "x is: 500"
    println!("y is: {y}"); // prints "x is: 6"
    println!("z is: {z}"); // prints "z is: true"
}
```

## Одночасне оголошення й деструктурування

Ми також можемо оголосити кортеж і одразу його деструктурувати.

```rust
fn main() {
    let (x, y): (felt252, felt252) = (2, 3);
}
```

## Одиничний тип `()`

Одиничний тип - це особливий тип у Cairo, який має лише одне значення: `()`.
Його представляє кортеж без елементів.
Розмір одиничного типу завжди нульовий, і гарантовано, що в скомпільованому коді його не буде.

У Cairo кожен вираз повертає значення, а коли вираз не повертає нічого, він неявно повертає `()`.
Це може бути корисно для функцій, які мають повернути значення, але не мають жодного змістовного значення для повернення.

## Оголошення іменованого типу кортежу

Іменований кортеж дає змогу створити описовіший псевдонім типу для кортежу, що покращує читабельність коду.

```rust
type Point = (u32, u32);

fn main() {
    let point: Point = (10, 8);
    println!("{point:?}"); // prints "(10, 8)"
}
```

У цьому прикладі `Point` - це іменований тип кортежу, що представляє пару 32-бітних беззнакових цілих чисел, завдяки чому код стає виразнішим.
