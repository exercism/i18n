# конкатенація рядків

Конкатенація рядків тексту (англ. string) у Ruby цілком припустима, але частіше рядок тексту складають за допомогою [інтерполяції рядків](http://ruby-for-beginners.rubymonstas.org/bonus/string_interpolation.html). Наприклад:

```ruby
# Rather than:
"One for " + %{name_variable} + ", one for me"

# Consider:
"One for #{%{name_variable}}, one for me."
```
