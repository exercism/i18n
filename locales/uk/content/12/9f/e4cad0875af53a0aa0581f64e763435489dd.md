# Докладніше

[concept:csharp/enumerables]() можна перебирати за допомогою циклу [`foreach`][foreach-statement]:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```

Цикл `foreach` складається з трьох частин:

1. Оголошення: визначаємо змінну, яка міститиме значення, що перебирається. Цю змінну можна (і можна лише) використовувати всередині циклу.
2. Обʼєкт, який можна перебирати: саме той обʼєкт, чиї елементи ми перебираємо.
3. Тіло циклу.

## Цикли `for` проти `foreach`

Однак зазвичай цикл `foreach` кращий за цикл `for` з таких причин:

- Цикл `foreach` гарантовано перебирає _всі_ значення. У циклі `for` легко пропустити елементи, наприклад через помилку на одиницю.
- Цикл `foreach` більш _декларативний_: наш код повідомляє, _що_ ми хочемо зробити, на відміну від циклу `for`, який повідомляє, _як_ ми хочемо це зробити.
- Цикл `foreach` не дає помилитися, тоді як у циклах `for` легко припуститися помилки на одиницю.
- Цикл `foreach` працює з усіма типами колекцій, зокрема з тими, які не підтримують доступ до елементів через індексатор.

Щоб гарантувати, що цикл `foreach` перебере _всі_ значення, компілятор не дозволяє змінювати колекцію всередині циклу `foreach`:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

Цикл `for` має деякі переваги над циклом `foreach`:

- Можна почати або зупинитися на потрібному індексі.
- Можна використати будь-яку (булеву) умову завершення.
- Можна пропускати елементи, налаштувавши інкремент змінної циклу.
- Можна обробляти колекції з кінця до початку, рахуючи у зворотному порядку.
- Можна використовувати цикли `for` у випадках, які не стосуються колекцій.

Повʼязані теми:

- Варто знати, що C# підтримує [багатовимірні масиви][multi-dimensional-arrays], як-от `int[,] arr = new int[10, 5]`, які можуть бути дуже корисними.
- Також варто знати, що можна створювати обʼєкти типу [`System.Array`][system-array-object] за допомогою `Array.CreateInstance`. Такі обʼєкти майже не потрібні, головним чином для взаємодії з кодом VB.NET. Їх не можна заміняти стандартними масивами (`T[]`). Вони можуть мати нижню межу, відмінну від нуля.

Обидві ці теми докладніше розглядаються в одній із наступних вправ.
