# Інструкції

Наш друг Лінус - машиніст локомотива, який водить вантажні потяги між містами. Хоча він чудово дає раду потягам, із логістикою та компʼютерами він не такий майстерний. Він хотів би залучити нашу допомогу як програмістів, щоб упорядкувати дані про потяги та виправити помилки в даних маршрутів.

~~~~exercism/note
Цю вправу можна було б легко розвʼязати за допомогою зрізів, індексації та різних методів `dict`. Однак нам хотілося б, щоб, розвʼязуючи кожну з наведених нижче задач, ми практикували пакування, розпакування та множинне присвоєння.
~~~~

## 1. Створення масиву всіх вагонів

Наш друг веде облік ідентифікаторів (ID) кожного вагона, але ніколи не знає, скільки вагонів системі доведеться обробити в той чи інший момент. Решті програми логістики було б набагато простіше, якби ці дані були запаковані в єдиний `list`.

Реалізуйте функцію `get_list_of_wagons()`, яка приймає довільну кількість ID вагонів. Кожен ID буде додатним цілим числом. Далі функція має `return` задані ID як один `list`.

```python
>>> get_list_of_wagons(1, 7, 12, 3, 14, 8, 5)
[1, 7, 12, 3, 14, 8, 5]
```

## 2. Виправлення масиву вагонів

На цьому етапі ми вже потроху розуміємо дані та те, як вони використовуються в програмі логістики. Система ID завжди присвоює локомотиву ID **1**, а решті вагонів у потязі - випадково вибраний ID, більший за **1**.

Нашому другові довелося приєднати до потяга два нових вагони, і він забув оновити систему! Тепер перші два вагони в `list` потяга треба перемістити в кінець, інакше все буде не в тому порядку.

Щоб усе ще більше ускладнити, наш друг щойно виявив другий `list`, який, схоже, містить зниклі ID вагонів. Він памʼятає лише те, що після переміщення нових вагонів ID із цього другого `list` мають опинитися одразу після позначеного локомотива.

Лінус буде дуже вдячний, якщо ми виправимо його помилки й упорядкуємо дані.

Реалізуйте функцію `fix_list_of_wagons()`, яка приймає два `lists` з ID вагонів. Вона має перемістити перші два елементи першого `list` у кінець і вставити значення з другого `list` позаду (_праворуч від_) ID локомотива (**1**). Далі функція має `return` `list` зі змінами.

```python
>>> fix_list_of_wagons([2, 5, 1, 7, 4, 12, 6, 3, 13], [3, 17, 6, 15])
[1, 3, 17, 6, 15, 7, 4, 12, 6, 3, 13, 2, 5]
```

## 3. Додавання пропущених зупинок

Тепер, коли всі дані про вагони правильні, Лінус хотів би, щоб ми оновили інформацію про маршрути в системі. На транспортному маршруті потяг може робити зупинки на кількох різних станціях, щоб забрати та/або залишити вантаж. У кожної подорожі може бути різна кількість таких проміжних пунктів доставки. Наш друг хотів би, щоб ми оновили `dict` маршрутизації в системі, додавши будь-яку відсутню чи додаткову інформацію про доставку.

Реалізуйте функцію `add_missing_stops()`, яка приймає `dict` маршрутизації, а далі довільну кількість іменованих аргументів. Ці аргументи можуть бути у вигляді `dict`, що містить одну або більше зупинок, або будь-якої кількості пар `stop_number=city`. Далі ваша функція має повернути `dict` маршрутизації, оновлений додатковим `key`, який містить `list` усіх доданих зупинок у порядку.

```python
>>> add_missing_stops({"from": "New York", "to": "Miami"},
                      stop_1="Washington, DC", stop_2="Charlotte", stop_3="Atlanta",
                      stop_4="Jacksonville", stop_5="Orlando")

{"from": "New York", "to": "Miami", "stops": ["Washington, DC", "Charlotte", "Atlanta", "Jacksonville", "Orlando"]}
```

## 4. Розширення інформації про маршрут

Лінус працював над програмою маршрутизації й помітив, що деяким маршрутам бракує важливих деталей. Початкова інформація про маршрут була створена як `dict`, і наш друг хотів би, щоб ми оновили цей `dict` усім, чого може бракувати. Кожен маршрут у системі потребує трохи інших деталей, тож Лінус дуже хотів би мати загальне рішення.

Реалізуйте функцію `extend_route_information()`, яка приймає два `dicts`. Перший `dict` містить міста відправлення та призначення, між якими проходить маршрут потяга.

Другий `dict` містить інші деталі маршруту, як-от швидкість потяга, довжину чи температуру. Функція має повернути обʼєднаний `dict` з усією інформацією про маршрут.

~~~~exercism/note
Другий `dict` може містити інші або додаткові властивості, ніж ті, що показані в прикладі.
~~~~

```python
>>> extend_route_information({"from": "Berlin", "to": "Hamburg"}, {"length": "100", "speed": "50"})
{"from": "Berlin", "to": "Hamburg", "length": "100", "speed": "50"}
```

## 5. Виправлення вагонного депо

Коли Лінус оглядав вагонне депо, він помітив, що вагони зберігаються не в правильному порядку. Окрім ID, кожен вагон має колір, який відповідає типу вантажу, який він перевозить. Вагони зберігаються в депо у вигляді сіток, де в кожному стовпці сітки стоять вагони одного кольору.

Однак система логістики показує, що в `lists` вагонів, які треба зберегти в депо, _рядки_ згруповані за кольором. Але щоб сітка зберігання працювала правильно, у кожному _рядку_ мають бути три різні кольори, щоб _стовпці_ вирівнювалися за кольором. Наш друг хотів би, щоб ми впорядкували `lists` вагонного депо, аби вагони зберігалися правильно.

Реалізуйте функцію `fix_wagon_depot()`, яка приймає `list` із трьох елементів. Кожен елемент `list` - це вкладений масив (або «рядок»), який містить три `tuples`. Кожен `tuple` - це пара `(<wagon ID>, <wagon color>)`.

Функція має повернути `list`, де три `lists`-«рядки» переставлено так, щоб вагони опинилися на своїх правильних місцях.

```python
>>> fix_wagon_depot([
                    [(2, "red"), (4, "red"), (8, "red")],
                    [(5, "blue"), (9, "blue"), (13,"blue")],
                    [(3, "orange"), (7, "orange"), (11, "orange")],
                    ])

[
[(2, "red"), (5, "blue"), (3, "orange")],
[(4, "red"), (9, "blue"), (7, "orange")],
[(8, "red"), (13,"blue"), (11, "orange")]
]
```
