# Використання інтерполяції рядків тексту

[comment]: # (Це попередження виникає, коли рішення не використовує інтерполяцію рядків тексту)

Використайте [інтерполяцію рядків тексту (англ. string)](https://github.com/elixir-lang/elixir/blob/9cac52833e91b5ebac0d322b20e39605d8dafad9/lib/elixir/lib/string.ex#L20), щоб вставити параметр `name` у вихідний рядок тексту.

- Коли це можливо, у треку Elixir на Exercism для читабельності рекомендується використовувати інтерполяцію рядків тексту, а не конкатенацію рядків тексту.

```elixir
def hello(what) do
  "Hello, #{what}"
end
```

- [Будь-який вираз Elixir](https://github.com/elixir-lang/elixir/blob/9cac52833e91b5ebac0d322b20e39605d8dafad9/lib/elixir/lib/string.ex#L30) може стояти в синтаксисі інтерполяції рядків тексту

```elixir
def pluralize_apple(n) when n >= 1 do
  "apple#{if n > 1, do: "s"}"
end
```
