# Встановлення Kotlin

Окрім exercism CLI та улюбленого текстового редактора, для практики з вправами Exercism на Kotlin потрібні

* **Java Development Kit** (JDK): Kotlin компілюється в байт-код Java, тож потрібно встановити JDK, який містить і середовище виконання Java (*Java Runtime*), *і* інструменти розробки (зокрема компілятор Java); та
* **Gradle** - інструмент збірки, призначений спеціально для проєктів на JVM, який підтримує Kotlin.

Виберіть операційну систему:

* [Windows](#h-windows)
* [macOS](#h-macos)
* [Linux](#h-linux)

... або ...
* або, якщо не використовувати менеджер пакетів, можна [встановити вручну](#h-install-manually).

За бажанням також можна скористатися [Java IDE](#h-java-ides).

## Windows

Відкрийте командний рядок із правами адміністратора.  (Якщо потрібна допомога з відкриттям командного рядка з правами адміністратора, дивіться [відкриття командного рядка з підвищеними правами у Windows 8+](http://www.howtogeek.com/194041/how-to-open-the-command-prompt-as-administrator-in-windows-8.1/) (або [Windows 7](http://www.howtogeek.com/howto/windows-vista/run-a-command-as-administrator-from-the-windows-vista-run-box/)).

1. Якщо Chocolatey ще не встановлено, зробіть це зараз:

      ```batchfile
        C:\Windows\system32> @powershell -NoProfile -ExecutionPolicy unrestricted -Command "iex ((new-object net.webclient).DownloadString('https://chocolatey.org/install.ps1'))" && SET PATH=%PATH%;%ALLUSERSPROFILE%\chocolatey\bin
      ```

2.  Встановіть JDK:

       ```batchfile
        C:\Windows\system32> choco install openjdk11
        ...
        C:\Windows\system32> refreshenv
        ...
       ```

Радимо закрити командний рядок із правами адміністратора й відкрити новий командний рядок: для практики з вправами Exercism права адміністратора не потрібні.

Тепер ми готові розпочати роботу з треком Kotlin на Exercism!

Щоб почати, дивіться «[Запуск тестів](https://exercism.org/docs/tracks/kotlin/tests)».

## macOS

Нижче наведено інструкції зі встановлення найпоширенішим способом, за допомогою Homebrew.  За бажанням можна також [встановити на macOS без Homebrew](#h-installing-on-macos-without-homebrew).

### Встановлення

1. Якщо [Homebrew](http://brew.sh) ще не встановлено, зробіть це зараз:

      ```sh
        $ /usr/bin/ruby -e "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/master/install)"
      ```

2. Підключіть [Homebrew Cask](https://caskroom.github.io/): це дає змогу встановлювати готові бінарні файли, як-от JDK.

      ```
        $ brew tap adoptopenjdk/openjdk
      ```

3.  Встановіть JDK:

       ```
        $ brew install --cask adoptopenjdk11
       ```

Тепер ми готові розпочати роботу з треком Kotlin на Exercism!

Щоб почати, дивіться «[Запуск тестів](https://exercism.org/docs/tracks/kotlin/tests)».

## Linux

Нижче наведено інструкції зі встановлення за допомогою менеджера пакетів дистрибутива.  За бажанням можна також [встановити на Linux без менеджера пакетів](#h-installing-on-linux-without-a-package-manager).

* [Debian](#h-debian)
* [Інші дистрибутиви Linux](#h-other-linux-distributions)

### Debian

Для Debian та його похідних (як-от Ubuntu чи Linux Mint) скористайтеся APT:

*(перевірено на: Ubuntu 14, 16 та 18)*

1. Встановіть JDK:

      ```sh
        $ sudo apt-get update
        $ sudo apt-get install software-properties-common
        $ sudo add-apt-repository ppa:openjdk-r/ppa
        $ sudo apt-get update
        $ sudo apt-get install openjdk-11-jdk
      ```


Тепер ми готові розпочати роботу з треком Kotlin на Exercism!

Щоб почати, дивіться «[Запуск тестів](https://exercism.org/docs/tracks/kotlin/tests)».

### Інші дистрибутиви Linux

Є багато способів встановити JDK 11, але один із найпростіших - скористатися SDKMAN, 
який дає змогу легко встановити OpenJDK 11. Виконайте такі кроки:

1. Встановіть SDKMAN:
    ```sh
    $ curl -s "https://get.sdkman.io" | bash
    ``` 
    (якщо це не спрацює, погляньте на інструкції тут: https://sdkman.io/install )
1. Встановіть OpenJDK 11:
    ```
    $ sdk install java 11.0.2-open
    ``` 

Тепер ми готові розпочати роботу з треком Kotlin на Exercism!

Щоб почати, дивіться «[Запуск тестів](https://exercism.org/docs/tracks/kotlin/tests)».

### Встановлення на Windows вручну

*ПРИМІТКА: ці інструкції призначено для досвідчених користувачів Windows.  Тим, хто ще не знає, як задавати змінні середовища, і не має досвіду керування структурою каталогів, радимо скористатися встановленням через Chocolatey, [вище](#h-windows).*

1. Встановіть JDK:
   1. Завантажте «**OpenJDK 11 (LTS)**» з [AdoptOpenJDK](https://adoptopenjdk.net/releases.html?variant=openjdk11#x64_win) (виберіть **«Install JDK»**).
   -  Запустіть інсталятор, прийнявши всі типові налаштування.

Тепер ми готові розпочати роботу з треком Kotlin на Exercism!
