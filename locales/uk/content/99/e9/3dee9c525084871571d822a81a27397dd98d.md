# Інструкції

Пірат прокладає маршрут крізь карту прихованих бухт.
Карта - це хеш-таблиця, ключами якої є назви бухт; кожне
значення - масив бухт, до яких можна дістатися безпосередньо з цієї.

## 1. Спустошити чергу припливу

Визначте `tide-queue` так, щоб вона приймала масив елементів, додавала кожен у
новий deque (у порядку), а потім витягувала їх усі назад у масив,
який зберігає початковий порядок. Це і є схема FIFO:
додаємо в кінець, витягуємо з початку.

```factor
{ "alpha" "bravo" "charlie" } tide-queue .
! => { "alpha" "bravo" "charlie" }
```

## 2. Досяжні бухти

Визначте `coves-reachable` так, щоб вона приймала початкову бухту й карту
та повертала хеш-множину всіх бухт, досяжних із `start`,
включно із самим `start`.

```factor
"Skull Bay" H{
    { "Skull Bay"   { "Hidden Cove" } }
    { "Hidden Cove" { "Reef Point"  } }
    { "Reef Point"  { } }
} coves-reachable .
! => HS{ "Skull Bay" "Hidden Cove" "Reef Point" }
```

Використайте `<dlist>` як фронт пошуку в ширину (BFS), а `HS{ }` -
для множини відвіданих.

## 3. Кількість переходів

Визначте `hop-count` так, щоб вона приймала початкову бухту, цільову бухту
й карту та повертала мінімальну кількість переходів між ними, або
`f`, якщо цільова бухта недосяжна.

```factor
"Skull Bay" "Hidden Cove"
H{
    { "Skull Bay"   { "Hidden Cove" } }
    { "Hidden Cove" { } }
} hop-count .
! => 1
```

Тримайте кожну бухту разом із її відстанню від початку в
deque (підійде масив із 2 елементів).

## 4. Кількість золота

Заготовка оголошує `gold-count` через `:`. Змініть його на `MEMO:`
(не `:`), щоб результат для кожної бухти обчислювався один раз і
кешувався. Знайдіть кількість золота для бухти в константі
`gold-distribution`, яку надає вправа.
Бухта, якої немає в розподілі, має нуль золота.

```factor
"Smuggler's Hollow" gold-count .   ! => 200
"Davy Jones' Locker" gold-count .  ! => 0
```

## 5. Маршрут до скарбу

Визначте `treasure-route` так, щоб вона приймала початкову бухту й карту та
повертала досяжну бухту з найбільшою кількістю золота. Використайте
`coves-reachable` із завдання 2 і `gold-count` із завдання 4.

```factor
"Skull Bay" some-chart treasure-route .
! => "Smuggler's Hollow"   (the richest reachable cove)
```

Мемоїзований `gold-count` робить повторні звернення безкоштовними, що
корисно, коли кілька частин алгоритму звертаються до тієї самої бухти.
