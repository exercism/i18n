# Вступ

**Замикання** - це прийом програмування [у Clojure][clojure-guide-closures], який дозволяє використовувати змінні із зовнішньої [лексичної області видимості][wiki-lexical-scope] всередині функції. Clojure підтримує замикання прозоро, і їх часто використовують, навіть не знаючи, що це таке.

```clojure
;; Top-level definitions are global-scope
(def dozen 12)

;; Functions create a new scope.
;; Referencing the outer variable here is a closure.
(fn [n] (* dozen n))
```

## Замикання для збереження стану та передачі значень

Використання atom дає змогу зберегти певний стан:

```clojure
;; This function closure increments the counter's state
;; in the outer lexical context.
;; This way the counter can be shared between many calling contexts.

(def increment
  (let [counter (atom 0)]
    (fn [] (swap! counter inc))))
```

Кожен наступний виклик `increment` збільшує його лічильник на одиницю:

``` clojure
(increment)
;;=> 1
(increment)
;;=> 2
```
