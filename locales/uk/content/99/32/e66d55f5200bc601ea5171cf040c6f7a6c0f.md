# Вступ

До появи класу `Promise` існував лише один спосіб працювати з асинхронним кодом: _патерн колбеків_.

Колбек - це функція, яку передають як аргумент іншій функції, і яку буде викликано, коли певна дія в тій іншій функції завершиться. Поширений підхід до таких функцій-колбеків полягає в тому, що вони приймають «помилку» як перший параметр (див. приклад нижче).

```javascript
function callback(error, arg2, arg3) {}
```

Як це повʼязано з асинхронним кодом?

Історично колбеки використовували, щоб ми могли виконати певну роботу після завершення асинхронної задачі й не блокувати всю програму.

```javascript
fetchProduct(productId, function (error, data) {
  if (error) {
    // Handle the error
  } else {
    // Do some work
  }
});
```

У наведеному вище прикладі функція `fetchProduct` (яка є асинхронною) приймає колбек як другий аргумент, який вирішує, що робити, коли дані про товар отримано.
