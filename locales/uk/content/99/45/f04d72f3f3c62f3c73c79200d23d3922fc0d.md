# Інструкції

Примітка: ця вправа є продовженням вправи `need-for-speed`.

У цій вправі ми будемо організовувати перегони між різними типами радіокерованих машин.
Кожна машина має власні характеристики швидкості та витрати батареї.

У кожної машини батарея спочатку заряджена на 100%.
Щоразу, коли ми керуємо машиною за допомогою пульта, вона проїжджає відстань, що дорівнює її швидкості в метрах, а залишок заряду батареї зменшується на величину її витрати.

Якщо заряд батареї машини менший за відсоток її витрати, керувати нею більше не можна.

Радіокерована машина має гарний LED-дисплей, який показує дві частини інформації:

- Загальну пройдену відстань, яка відображається як: `"Driven <METERS> meters"`.
- Залишковий заряд батареї, який відображається як: `"Battery at <PERCENTAGE>%"`.

Кожна траса має власну довжину.
Машини перевіряють на те, чи можуть вони проїхати трасу, не розрядивши батарею.

## 1. Керувати машиною

Реалізуйте метод `Drive` на `Car`, який оновлює кількість пройдених метрів відповідно до швидкості машини та зменшує заряд батареї відповідно до її витрати:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)
car.Drive()
// car is now Car{speed: 5, batteryDrain: 2, battery: 98, distance: 5}
```

Примітка: не намагайтеся керувати машиною, якщо від цього заряд її батареї стане меншим за 0.

## 2. Показати пройдену відстань

Реалізуйте метод `DisplayDistance` на `Car`, який повертає відстань такою, як вона відображається на LED-дисплеї, у вигляді `string`:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

fmt.Println(car.DisplayDistance())
// Output: "Driven 0 meters"
```

## 3. Показати відсоток заряду батареї

Реалізуйте метод `DisplayBattery` на `Car`, який повертає відсоток заряду батареї таким, як він відображається на LED-дисплеї, у вигляді `string`:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

fmt.Println(car.DisplayBattery())
// Output: "Battery at 100%"
```

## 4. Перевірити, чи може радіокерована машина фінішувати в перегонах

Щоб фінішувати в перегонах, машина повинна мати змогу проїхати всю дистанцію перегонів.
Це означає, що вона не повинна розрядити батарею, не перетнувши фінішну лінію.
Реалізуйте метод `CanFinish`, який приймає параметр `trackDistance int` і повертає `true`, якщо машина може фінішувати в перегонах, або `false` в іншому разі:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

trackDistance := 100

car.CanFinish(trackDistance)
// => true
```
