# Розвʼязування вправ локально

Розвʼязуючи вправи на власному компʼютері, ми пишемо весь код у звичному для нас середовищі.

## Встановлення CLI

Щоб розвʼязати вправу на власному компʼютері, спершу потрібно встановити і налаштувати інтерфейс командного рядка Exercism за [цими вказівками](https://exercism.org/cli-walkthrough).

### Налаштування

Потрібно повідомити CLI, хто ми, щоб усе завантажувалося правильно.
Токен можна знайти на [сторінці налаштувань](/settings/api_cli).
Далі налаштуйте CLI командою нижче, замінивши `<your-api-token>` на значення зі сторінки налаштувань:

```
exercism configure --token=<your-api-token>
```

## Завантаження вправи

Коли CLI встановлено, завантажте вправу на власний компʼютер такою командою (замінивши `<exercise-slug>` і `<track-slug>` на відповідні значення:

```
exercism download --exercise=<exercise-slug> --track=<track-slug>
```

Запамʼятовувати цю структуру команди не обовʼязково, бо на сторінці вправи наведено відповідну команду для цієї вправи.

Коли команда завантаження завершиться, файли вправи буде завантажено на власний компʼютер.

## Розвʼязування вправи

Мета кожної вправи - створити реалізацію, яка проходить усі тести.
Таку реалізацію називають _рішенням_.

Щоб допомогти з цим, кожна вправа містить такі файли:

- README.md: вказівки, які пояснюють, що від нас очікується
- HELP.md: інформація про те, як запускати тести й як отримати допомогу, коли ми застрягли
- HINTS.md (необовʼязково): підказки, які допомагають розвʼязати вправу
- Файл(и) з тестами: містять тести, які перевіряють правильність нашого рішення
- Файл(и) заглушки: дають відправну точку, яка допомагає почати створювати реалізацію

Залежно від треку, можуть бути й інші файли, потрібні інструментарію треку для запуску тестів.

## Надсилання рішення

Коли рішення проходить усі тести, надішліть його такою командою:

```
exercism submit <implementation_file_paths>
```

Ця команда завантажить рішення на сайт Exercism і виведе URL сторінки рішення.

Знову ж таки, запамʼятовувати цю команду не обовʼязково: правильну команду наведено у файлі `HELP.md` вправи.

Можна надіслати й незавершене рішення. Це дає змогу:

- побачити, як цю вправу виконали інші
- попросити допомоги в наставника

## Інші можливості CLI

### Як побачити всі команди

Запустіть підкоманду help, щоб отримати повний список доступних команд.

```bash
exercism help
```

### Усунення неполадок

Переконайтеся, що встановлено найновішу версію.

Перевірте, яка версія встановлена:

```bash
exercism version
```

Порівняйте з останнім випуском і оновіться, якщо встановлена версія не найновіша.

Після оновлення перевірте версію ще раз. Якщо версія не змінилася, переконайтеся, що запускається саме оновлений виконуваний файл.

```bash
which exercism
```

Якщо проблеми не зникли, відкрийте issue у репозиторії exercism/cli на GitHub, додавши вивід команди troubleshoot.

```bash
exercism troubleshoot
```

Можна відкривати issue у [нашому трекері issue](https://github.com/exercism/exercism/issues), і спільнота спробує допомогти. **Перш ніж відкривати будь-які issue, обовʼязково пройдіть [Інтерактивний посібник](https://exercism.org/cli-walkthrough).**
