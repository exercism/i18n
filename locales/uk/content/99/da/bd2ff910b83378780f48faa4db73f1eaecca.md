# Debug

Коли тест не проходить, показується повідомлення, яке описує, що пішло не так і для яких вхідних даних.
Ми можемо переглянути довільні значення у своїй програмі, передавши їх методу `debug`.
Це зафіксує значення й покаже вихідні дані.

```ruby
debug "The value is #{value}."
debug "The input is #{input.inspect}"
```
