# Додаток до вказівок

## Регістри

| Регістр | Використання     | Тип        | Опис                          |
| -------- | ---------------- | ---------- | ----------------------------- |
| `$a0`    | вхідні дані      | ціле число | N, сума сторін трикутника     |
| `$a1`    | вхідні/вихідні дані | адреса  | значення a                    |
| `$a2`    | вхідні/вихідні дані | адреса  | значення b                    |
| `$a3`    | вхідні/вихідні дані | адреса  | значення c                    |
| `$v0`    | вихідні дані     | ціле число | кількість трійок              |
| `$t0-9`  | тимчасовий       | будь-який  | для тимчасового зберігання    |
