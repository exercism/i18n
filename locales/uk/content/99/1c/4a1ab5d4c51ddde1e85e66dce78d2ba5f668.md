# Докладніше

Бібліотека базових класів .NET надає клас [`Regex`][regex] для опрацювання регулярних виразів.

Порівняння C# з іншими реалізаціями регулярних виразів наведено в цій [статті][regex-comparison].

## Групи захоплення

Варто взяти до уваги такий аспект, як групи захоплення, які повертають частини тексту, що відповідають різним частинам шаблону регулярного виразу. До груп захоплення треба звикнути. Погляньмо на цю [документацію][capture].

Зауважмо, що тут є ієрархія, у якій задіяні групи захоплення `(?<capture-name>pattern)`:

- повертається набір із нуля або більше збігів (по одному на кожен збіг, знайдений у тексті);
- кожен збіг містить кілька груп захоплення;
- кожна група містить кілька захоплень.

Крім того:

- `Match` успадковується від `Group`;
- `Group` успадковується від `Capture`.

Застереження:

- Найбезпечніший підхід - використовувати іменовані захоплення.
- Групи захоплення зазвичай розташовані в колекції `Groups` у тому самому порядку, у якому вони трапляються в тексті.
- `Groups[0]`, схоже, стосується всього збігу.
- `Groups[<capture name>].Value` - майже напевно саме те, що нам потрібно. Окремі захоплення (крім `Caputures[0]`), якщо вони є, призначені, схоже, для діагностики.

## Параметри Regex

Ознайоммося з [`RegexOptions`][regex-options].

Крім звичних параметрів `IgnoreCase`, є параметри `MultiLine`, який стає в пригоді, коли потрібно опрацювати кілька рядків тексту за раз, і `IgnorePatternWhitespace`, який у поєднанні з дослівними рядками тексту (англ. string), інтерполяцією рядків тексту та коментарями може бути дуже виразним, як показує цей приклад:

```csharp
const string PREAMBLE = "preamble";
const string PWTEXT = "pwtext";
const string PW = "pw";
const string SPACE = "space";
const string POSTAMBLE = "postamble";

var pattern = $@"
    ^
    (?<{PREAMBLE}>.*)          # any text
    (?<{PWTEXT}>password)      # the literal text - password
    (?<{SPACE}>\s+)
    (?<{PW}>\w*)               # the password itself
    (?<{POSTAMBLE}>.*)         # any text
    $
  ";

var rewrittenLine = $"{grps[PREAMBLE].Value}{grps[PWTEXT].Value}{grps[SPACE].Value}{mask}{grps[POSTAMBLE].Value}";
```

Ще один цікавий параметр - `RegexOptions.Compiled` для [скомпільованих][regex-compilation] регулярних виразів.
