# Додаток до інструкцій

## Порада

Функція з *типом повернення* може повертати дані лише цього *типу* та `null`.
Однак той, хто викликає функцію, розраховує лише на один тип даних.

Приклад:
```dart
String hello(int a){
    if ( a == 0){
        return "a";
    } else {
        return null;
    }
}
```
Щоб було зрозуміліше, що ця функція може також повертати `null` або більше типів даних, використайте `dynamic`.
```dart
dynamic hello(int a){
    if ( a == 0){
        return "a";
    } else {
        return null;
    }
}
