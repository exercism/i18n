# Вступ

## Оператори порівняння

[Оператори порівняння][comparison-operators] застосовують для порівняння значень і повертають `true` або `false`.
Ці оператори потребують двох значень одного типу.
Якщо значення різного типу, компілятор видасть помилку.
Ось список операторів порівняння та приклади, коли вони повертають `true`:

| Метод | Опис                  | Приклад |
| ------ | --------------------- | ------- |
| ==     | дорівнює              | 1 == 1  |
| !=     | не дорівнює           | 1 != 2  |
| <      | менше                 | 4 < 5   |
| <=     | менше або дорівнює    | 4 <= 4  |
| >      | більше                | 3 > 1   |
| >=     | більше або дорівнює   | 2 >= 2  |

## Інструкції `if` та `else`

[Умовна конструкція][conditional-statement] дає змогу виконувати код залежно від умови, яка буває `true` або `false`.
Найпростіша умовна конструкція - це [умовний оператор `if`][if], який виконує код, коли умова дорівнює `true`.
Щоб оголосити умовний оператор `if`, використовують ключове слово `if`, після якого йде умова, а потім код для виконання у фігурних дужках.

```swift
let wheelCount = 4
if wheelCount == 4 {
  print("Your vehicle is a car")
}
// Prints "Your vehicle is a car"
```

`if` можна поєднати з `else`, щоб виконати код, коли умова дорівнює `false`.
Інструкцію `else` можна використовувати лише разом з інструкцією `if`, окремо вона не працює.
Щоб оголосити інструкцію `else`, використовують ключове слово `else` після фігурних дужок інструкції `if`, а потім код для виконання у фігурних дужках.

```swift
let precipitationInMM = 0.5
if precipitationInMM > 0.5 {
  print("You will need an umbrella")
} else {
  print("You will not need an umbrella")
}
// Prints "You will not need an umbrella"
```

Інструкції `if` можна також обʼєднувати в ланцюжок за допомогою `else if`, щоб перевіряти кілька умов.
Це той самий принцип, що й в оголошенні інструкції `if`, але замість `if` використовують ключове слово `else if`.
Інструкції `if` не потребують `else`, щоб бути дійсними, але за потреби можуть його мати.

```swift
let favoriteFruit = "Apple"

if favoriteFruit == "Banana" {
    print("Your favorite fruit is a banana")
} else if favoriteFruit == "Orange" {
    print("Your favorite fruit is an orange")
} else if favoriteFruit == "Apple" {
    print("Your favorite fruit is an apple")
} else {
    print("Your favorite fruit is not a banana, orange or apple")
}
// Prints "Your favorite fruit is an apple"
```

## Вираз `if`

Інструкції `if` можна також використовувати як вирази, щоб присвоїти значення змінній.
Остання інструкція в блоці `if` править за значення виразу `if`.
Це зручно, коли потрібно присвоїти змінній значення залежно від умови.

```swift
let CpuBits = 32
let largest = if CpuBits == 64 {
  "x86_64"
} else {
  "x86_32"
}

print(largest)
// Prints "x86_32"
```

## Тернарний оператор

[Тернарний умовний оператор][ternary-operator] - це стислий скорочений запис виразу `if-else`.
Він обчислює умову та повертає одне з двох значень залежно від того, чи є ця умова `true` чи `false`.

Оператор складається з трьох частин: `condition ? trueExpression : falseExpression`.
Якщо `condition` обчислюється як `true`, тоді обчислюється й повертається `trueExpression`; інакше обчислюється й повертається `falseExpression`.

Тернарний оператор ідеально підходить для простих виборів в один рядок:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = showFahrenheit ? temperatureInCelsius * 9 / 5 + 32 : temperatureInCelsius
print(temperature)
// Prints 86
```

Наведений вище приклад - це компактний відповідник такого коду:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = if showFahrenheit {
    temperatureInCelsius * 9 / 5 + 32
} else {
    temperatureInCelsius
}
```
