# Додаток до інструкцій

## Підказки

Модуль Sgf має експортувати модуль parseSgf з такою сигнатурою:

```haskell
parseSgf :: Text -> Maybe (Tree (Map Text [Text]))
```

Можливо, нам буде корисно скопіювати наведені нижче визначення для SgfTree
та SgfNode:

```haskell
-- | A tree of nodes.
type SgfTree = Tree SgfNode

-- | A node is a property list, each key can only occur once.
-- Keys may have multiple values associated with them.
type SgfNode = Map Text [Text]
```
