# Докладніше

Іноді накладні витрати на створення обʼєкта зі станом нам не потрібні. У таких випадках можна використати `module`.

Модуль дуже схожий на клас (насправді `Module` є батьківським класом для `Classes` в ієрархії обʼєктів). Головна відмінність у тому, що замість методів екземпляра ми використовуємо методи класу. Методи класу починаються з `self.` і викликаються безпосередньо на модулі.

Наприклад:

```ruby
module Speaker
  def self.echo(something)
    "#{something} ... #{something}"
  end
end

Speaker.echo("Hello")   #=> "Hello ... Hello"
```
