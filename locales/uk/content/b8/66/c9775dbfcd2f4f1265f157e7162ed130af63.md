# Умовні конструкції

У Crystal є так звані керуючі вирази. Вони визначають, як виконуватиметься програма, і приймають істинне або хибне значення.
Існують оператори, за допомогою яких можна отримати істинні або хибні значення, їх називають [операторами рівності та порівняння][equality-and-comparison].

Є два основні керуючі вирази, які визначають, який код виконається, а який ні.
Інакше кажучи, яка саме гілка спрацює.

Це `if` і `unless`.

## Оператори порівняння

Оператори порівняння порівнюють значення й повертають `true` або `false`.
Щоб порівняти два значення, вони мають бути одного типу.
Якщо типи значень різняться, компілятор видасть помилку.
Ось список операторів порівняння та приклади, коли вони дають `true`:

| Метод | Опис                  | Приклад |
| ------ | --------------------- | ------- |
| <      | менше ніж             | 4 < 5   |
| <=     | менше ніж або дорівнює | 4 <= 4  |
| >      | більше ніж            | 3 > 1   |
| >=     | більше ніж або дорівнює | 2 >= 2  |

## Оператори рівності

Оператори рівності схожі на оператори порівняння, але вони перевіряють, чи два значення рівні.

Оператор `==` перевіряє, чи два значення рівні, враховуючи й тип значення.
Якщо значення однакові, він поверне `true`, інакше поверне `false`.
Оператор `==` може порівнювати значення будь-якого типу зі значенням будь-якого іншого типу.
Оператор `!=` працює так само, але повертає `true`, якщо значення не рівні, і `false`, якщо рівні.

## Умовна конструкція `if`

Умовна конструкція [`if`][if] перевіряє, чи задана умова істинна або хибна.
Якщо умова істинна, код усередині конструкції `if` виконається.
Конструкція `if` завершується ключовим словом `end`.

```crystal
if 1 == 1
  puts "1 is equal to 1"
end
# => 1 is equal to 1

if 1 > 2
  puts "1 is greater than 2"
end
# => no output
```

## Умовна конструкція `unless`

Умовна конструкція [`unless`][unless] працює майже так само, як `if`, але виконує код усередині, якщо умова хибна.

```crystal
unless 1 == 1
  puts "1 is not equal to 1"
end
# => no output

unless 1 > 2
  puts "1 is not greater than 2"
end
# => 1 is not greater than 2
```

## Конструкція `else`

Конструкцію `else` можна поєднувати з `if` і `unless`.
Гілка `else` виконається, якщо гілка `if` або `unless` не виконалася.

~~~~exercism/warning
Хоча гілку `else` можна поєднувати з `unless,` робити так не варто, бо це погіршує читабельність.
Натомість радимо використовувати `if !condition` із гілкою `else`.
~~~~

```crystal
if 1 == 1
  puts "1 is equal to 1"
else
  puts "1 is not equal to 1"
end
# => 1 is equal to 1

unless 1 < 2
  puts "1 is not greater than 2"
else
  puts "1 is greater than 2"
end
# => 1 is greater than 2
```

## «Каскадні» конструкції `if`

Конструкцію `elsif` можна поєднувати з конструкцією `if`.
Гілка `elsif` виконається, якщо гілка `if` не виконалася, а умова `elsif` істинна.
Конструкції `elsif` можна обʼєднувати в ланцюжок, і виконається перша умова, що виявиться істинною.
Наприкінці можна також додати `else`, який виконається, якщо жодна з попередніх умов не була істинною.

```crystal
if 1 != 1
  puts "1 is not equal to 1"
elsif 1 > 2
  puts "1 is greater than 2"
else
  puts "1 is not equal to 1 and 1 is not greater than 2"
end
# => 1 is not equal to 1 and 1 is not greater than 2
```

## Типи в умовних конструкціях

Якщо в різних гілках змінній присвоюються значення різних типів, вона матиме обидва типи.
Так стається, бо компілятор не знає, яка гілка виконається.
Це множинне присвоєння, яке також називають обʼєднанням типів, пояснять у наступних концепціях.
Це видно в такому прикладі:

```crystal
if 1 == 1
  a = 1
else
  a = "1"
end

typeof(a) # => Int32 | String
```

## Тернарний оператор

У Crystal є тернарний оператор, однорядковий запис умови `if`-`else`: `condition ? expression_if_truthy : expression_if_falsey`

```crystal
1 == 1 ? puts("1 is equal to 1") : puts("1 is not equal to 1")
# => 1 is equal to 1
```
