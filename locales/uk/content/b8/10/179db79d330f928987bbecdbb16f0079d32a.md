# Вступ

`string` у Clojure - це рядок тексту (англ. string) з мови Java, тобто обʼєкт, який представляє незмінний текст як послідовність символів Unicode (літер, цифр, розділових знаків тощо) і визначається так:

```clojure
(def fruit "Apple")
```

Бібліотека `clojure.string` надає багато стандартних функцій для роботи з рядками тексту та їх обробки. Крім того, усі звичайні методи Java для роботи з рядками тексту доступні також завдяки взаємодії з Java.
