# Діапазони

[Діапазони][range] представляють інтервал між двома значеннями.
Найпоширеніші типи, які підтримують діапазони: `Int`, `Char` і `String`.
Їх можна використовувати для багатьох речей, як-от швидке створення колекції, розрізання рядків тексту (англ. string), перевірка, чи входить значення в діапазон, та ітерація.
Їх створюють за допомогою оператора діапазону `..` або `...` (включно та не включно відповідно).

```crystal
1..5  # A range containing 1, 2, 3, 4, 5
1...5 # A range containing 1, 2, 3, 4
```

Причина існування двох операторів діапазону полягає в тому, щоб створювати діапазони, які включають або не включають кінцеве значення; це буває корисно, наприклад, коли ми працюємо з індексами з відліком від нуля.

Діапазони також можна створювати за допомогою ініціалізатора `Range`.

```crystal
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
Коли ми створюємо діапазон у Crystal за допомогою операторів `..` або `...` і хочемо викликати метод на цьому діапазоні, потрібно взяти діапазон у дужки.
Інакше метод буде викликано на другому аргументі оператора діапазону.

```crystal
(1..5).size # => 5
1..5.size # => Error: undefined method 'size' for Int32
```
~~~~

## Отримання підрядків

Коли ми хочемо розрізати рядок тексту, можна скористатися оператором діапазону, щоб отримати підрядок.
Тобто створити діапазон із початковим і кінцевим індексом підрядка.

```crystal
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

Також можна використовувати відʼємні індекси, щоб отримати підрядок із кінця рядка тексту.

```crystal
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## Методи діапазонів

Діапазони мають набір методів, які можна використовувати для роботи з ними.
Наприклад, ці методи дають змогу отримати суму всіх значень у діапазоні або перевірити, чи діапазон містить певне значення.

| Метод                   | Опис                                                                    | Приклад                         |
|-------------------------|-------------------------------------------------------------------------|---------------------------------|
| [`sum`][sum]            | Повертає суму всіх значень у діапазоні                                  | `(1..5).sum # => 15`            |
| [`size`][size]          | Повертає розмір діапазону                                               | `(1..5).size # => 5`            |
| [`includes?`][indludes] | Повертає `true`, якщо діапазон містить задане значення, інакше `false`  | `(1..5).includes?(3) # => true` |

## Безкінечні та безпочаткові діапазони

Діапазон може бути безкінечним або безпочатковим.
У безкінечного чи безпочаткового діапазону початкове або кінцеве значення дорівнює `nil`, але `nil` можна опустити, визначаючи діапазон.

Використовувати безпочаткові та безкінечні діапазони зручно, коли ми хочемо, наприклад, розрізати рядок тексту від початку або до кінця.

```crystal
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
Безкінечний діапазон, застосований не до колекції, може спричинити безкінечну послідовність, якщо не користуватися ним обережно.
~~~~

## Діапазони символів

Символи можна використовувати в діапазонах, що дає змогу отримати інтервал символів між двома символами.
Наприклад, це стане в пригоді, коли ми хочемо отримати алфавіт.

```crystal
'a'..'z' # A range containing ['a', 'b', 'c', ..., 'z']
```

## Діапазони рядків тексту

Рядки тексту також можна використовувати в діапазонах, що дає змогу отримати інтервал рядків тексту між двома рядками тексту.
Але їхня поведінка трохи відрізняється від поведінки `Char`, коли в діапазоні рядків тексту використовується кілька символів.
Поведінка може стати заплутаною, коли ми будуємо складніші діапазони рядків тексту, тож будьмо обережні.

```crystal
("aa".."az") # A range containing ["aa", "ab", "ac", ..., "az"]
```
