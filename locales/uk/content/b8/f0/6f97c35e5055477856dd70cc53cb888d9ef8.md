# Підказки

## Загальне

- `n <iota>` створює віртуальну послідовність цілих чисел
  `0, 1, …, n-1`.
- `map` (з [`sequences`][sequences]) запускає quotation для кожного
  елемента й збирає результати.
- `>string` (з [`strings`][strings]) перетворює послідовність
  кодів символів на рядок тексту (англ. string).

## 1. Алфавітна гірлянда

- `CHAR: a` розбирається в ціле число `97`. Додавання індексу `i`
  дає код малої літери під індексом `i`.

## 2. Лічильна гірлянда

- `mod` (з [`math`][math]) повертає остачу від ділення цілих
  чисел.
- Коди символів для цифр ідуть послідовно (`CHAR: 0`,
  `CHAR: 1`, …), тож `CHAR: 0 +` перетворює ціле число з `0..9` на
  відповідний символ цифри.

## 3. Смугаста гірлянда

- `even?` (з [`math`][math]) повертає `t` для парних цілих чисел і `f`
  для всіх інших.
- Усередині quotation для `map` конструкція `if` вибирає один із двох
  символьних літералів залежно від умови.

## 4. Маркерна гірлянда

- `5 mod zero?` дає `t` саме на позиціях `0`, `5`, `10`, … .

## 5. Долинна гірлянда

- `-5 5 [a..b)` (з [`ranges`][ranges]) дає напіввідкритий
  діапазон `-5, -4, …, 4`.
- `abs` (з [`math`][math]) змінює знак відʼємного цілого числа на
  протилежний, а невідʼємні цілі числа залишає без змін.
