# Класи зі станом

```sather
class SCOREBOARD is

   attr home_team, away_team : STR;
   attr home_score, away_score : INT;

   create(home, away : STR) : SAME is
      board ::= new;
      board.home_team := home;
      board.away_team := away;
      return board;
   end;

   home_goal is home_score := home_score + 1; end;

end; -- class SCOREBOARD
```

## attr, readonly attr, private attr

| Записано | Читання ззовні | Зміна ззовні |
| --- | --- | --- |
| `attr x : INT` | так | так |
| `readonly attr x : INT` | так | ні |
| `private attr x : INT` | ні | ні |

Типово варто використовувати саме `readonly`. Він дозволяє будь-кому бачити
рахунок і вимагає, щоб зміна проходила через `home_goal`, де й живуть
правила нарахування очок.

## create і new

`new` створює обʼєкт цього класу, у якого всі атрибути порожні. Його можна
використовувати лише всередині класу.

`create` - звичайна підпрограма з узгодженою назвою: `#C(args)` - це точно
те саме, що `C::create(args)`. У класу їх може бути кілька, і розрізняють їх
за аргументами, а клас, у якого немає жодної, просто не можна створити
через `#`.

## SAME

`SAME` позначає клас, у якому його написано. У `create` він є типом
повернення; він також працює і в аргументі, і саме він змушує успадковану
підпрограму говорити про клас-нащадок, а не про той, з якого вона прийшла.

## Підпрограми без типу повернення

```sather
   home_goal is
      home_score := home_score + 1;
   end;
```

Немає ні `:`, ні типу. Таку підпрограму викликають як інструкцію, і вона не
може стояти у виразі. Це знак того, що весь сенс виклику - у зміні, яку
вона вносить.

## self

Усередині підпрограми `self` - це обʼєкт, для якого її викликали. Його
пишуть рідко, бо атрибут чи підпрограма, названі самі по собі, вже означають
належні `self`. Він потрібен, коли обʼєкт треба передати далі або повернути:

```sather
   with_goal : SAME is
      home_score := home_score + 1;
      return self;
   end;
```

`self`, `new`, `void`, `result`, `value` та `out` - усі ці слова вже зайняті
в Sather, і жодне з них не можна використати як власну назву.

## Посилання, а не значення

До обʼєкта дістаються через посилання. Два імені для одного табло бачать
один і той самий рахунок:

```sather
   a ::= #SCOREBOARD("Vixens", "Magpies");
   b ::= a;         -- not a copy
   b.home_goal;
   a.home_score     -- 1
```

`immutable class`, про який ітиметься далі, дає змогу отримати іншу
поведінку.
