# Вступ

## Правда і неправда

У Ruby логічні стани «правда» і «неправда» позначаються літералами `true` та `false`.
Їх можна використовувати як самостійні літерали або як результат логічних методів чи методів порівняння.

```ruby
happy = true
sad = false

true && false
# => false

1 < 2
# => true
```

## _Truthy_ та _falsey_

Коли обʼєкти обчислюються в умовних конструкціях `if` або в інших контекстах, де потрібні булеві значення (англ. Boolean), усі вони вважаються _truthy_ **окрім** `false` і `nil`.

## Потік керування

Оцінювання _truthy_ та _falsey_ стає в пригоді в контексті потоку керування.
Як і в процедурних мовах, у Ruby є конструкція `if`...`else`, але частіше `if` використовують як «захисну» інструкцію, щоб змінити обчислення виразу.

```ruby
def falsey
  nil || false
end

def truthy
  not falsey
end

if truthy
  # this block is evaluated
end

if falsey
  # this block is not evaluated
else
  # this block is evaluated
end

1 + 1 if truthy
# this will evaluate and return 2

2 + 2 if falsey
# the numbers are not added because of the modifier, nil is returned
```

Ruby надає `unless`, щоб код читався краще.
Наприклад, замість `eat_desert if not too_full` можна також написати `eat_desert unless too_full`.

```ruby
3 + 3 unless truthy
# the numbers are not added because of the modifier, nil is returned

4 + 4 unless falsey
# this will evaluate and return 8
```
