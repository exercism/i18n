# Дорожня карта

Цей документ дає огляд основних тем, на яких учасники та супроводжувачі, ймовірно, зосередяться найближчими місяцями.

## Огляд тем

- Покращити наявні концептуальні вправи (див. [issue для відстеження](https://github.com/exercism/javascript/issues/1415))
- Створити додаткові концептуальні вправи (див. огляд силабусу нижче)
- Визначити списки `prerequisites` і `practices` для всіх практичних вправ (див. [issue для відстеження](https://github.com/exercism/javascript/issues/960))
- Покращити [тест-ранер](https://github.com/exercism/javascript-test-runner/)
  - Виправити помилки
  - Кращий вивід, коли змінні визначено поза тестовим випадком
  - Повʼязати тести із завданнями
- Додати коментарі [аналізатора](https://github.com/exercism/javascript-analyzer/) для всіх наявних концептуальних вправ
- Покращити, оновити та вичитати різну документацію (настанови для учасників, як реалізувати концептуальну вправу, docs, exercises/shared, теку reference)

## Огляд силабусу

### Концепти, які вже існують, або для яких створено issue

- `basics`
- `strings` (включно з методами рядків тексту (англ. string))
- `numbers`
- `booleans`
- `conditionals` (if/else) і `comparison`
- `for-loops` і `increment-decrement`
- `while-loops`
- `conditionals-switch`
- `objects` (як колекції пар ключ-значення)
- `null-undefined`
- `functions`
- `type-conversion` (включно з truthy/falsy)
- `template-strings`
- `conditionals-ternary`
- `callbacks`
- `arrow-functions`
- `classes` і `prototypes`
- `inheritance`
- `errors`
- `arrays` (включно з роботою з масивами через push, pop тощо)
- `array-loops`
- `array-analysis`
- `array-transformation`
- `array-destructering`
- `rest-and-spread`
- `promises`
- `recursion`
- `closures`
- `sets`
- `randomness`
- `regular-expressions`
- `dates`
- `async-await`
- `type-checking`

### Потенційні майбутні концепти

- `maps` (можна додати до вправи про множини, WeakSet/WeakMap могли б увійти в about як перша ітерація)
- `JSON`
- `math`
- гетери/сетери, прапорці, дескриптори
- `proxy`
- `variables` (глибоке занурення в const/let/var)
- `immutability` (включно з freeze, можна обʼєднати з концептом variables)
- `object-helpers` (наприклад, Object.assign)
- символи та кодові точки
- this і область видимості (включно з call/bind)
- ітератори та «енумератори»
- генератори/yield
- асинхронні генератори та ітератори
- побітові оператори
- модулі, імпорти, експорти, динамічні імпорти
- качина типізація
- API інтернаціоналізації
- `bigint`
- `symbol`
- коментарі JSDoc
- асинхронність, цикл подій
- setTimeout/setInterval
- події
- «усе є обʼєктом» іноді (звʼязок функцій, масивів і примітивів з обʼєктами, наприклад, упаковані типи)
