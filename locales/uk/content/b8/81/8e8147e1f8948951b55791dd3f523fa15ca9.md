# Introduction

## Булеві значення в Julia

Правду й неправду представляє тип `Bool`.
Він містить лише два значення: `true` і `false`.

```julia-repl
julia> true
true

julia> false
false
```

## Булеві оператори

У Julia є три булеві оператори (англ. Boolean).

`&&` (логічне і) означає булеве «і».
Він дає `true`, якщо вирази з *обох* боків `&&` дорівнюють `true`.

```julia-repl
julia> true && true
true

julia> true && false
false
```

`||` (логічне або) означає булеве «або».
Він дає `true`, якщо вираз *з будь-якого* боку від `||` дорівнює `true`.

```julia-repl
julia> true || true
true

julia> false || true
true
```

`!` означає логічне заперечення, тобто «не».
Він міняє місцями значення `true` і `false`.

```julia-repl
julia> !true
false

julia> !false
true
```

Для довших і складніших виразів краще використовувати дужки, щоб намір був зрозумілим.

```julia-repl
julia> (true || false) && (false && true)
false
```
