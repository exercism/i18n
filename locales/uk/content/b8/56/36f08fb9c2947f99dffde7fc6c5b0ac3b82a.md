# Вступ

C#, як і багато мов зі статичною типізацією, надає низку типів для представлення цілих чисел, і кожен із них має власний діапазон значень. На нижньому краї тип `sbyte` має мінімальне значення -128 і максимальне 127. Як і в усіх цілочисельних типів, ці значення доступні як `<type>.MinValue` та `<type>.MaxValue`. На верхньому краї тип `long` має мінімальне значення -9,223,372,036,854,775,808 і максимальне 9,223,372,036,854,775,807. А посередині містяться типи `short` та `int`.

Діапазони визначаються шириною зберігання типу, яку виділяє система. Наприклад, `byte` використовує 8 бітів, а `long` - 64 біти.

Кожен із наведених вище типів має відповідник без знака: `sbyte`/`byte`, `short`/`ushort`, `int`/`uint` та `long`/`ulong`. У всіх випадках діапазон значень - від 0 до подвоєного найменшого відʼємного значення зі знаком плюс 1.

| Тип    | Ширина | Мінімум                    | Максимум                    |
| ------ | ------ | -------------------------- | --------------------------- |
| sbyte  | 8 біт  | -128                       | +127                        |
| short  | 16 біт | -32_768                    | +32_767                     |
| int    | 32 біт | -2_147_483_648             | +2_147_483_647              |
| long   | 64 біт | -9_223_372_036_854_775_808 | +9_223_372_036_854_775_807  |
| byte   | 8 біт  | 0                          | +255                        |
| ushort | 16 біт | 0                          | +65_535                     |
| uint   | 32 біт | 0                          | +4_294_967_295              |
| ulong  | 64 біт | 0                          | +18_446_744_073_709_551_615 |

Змінну (або вираз) одного типу легко перетворити на інший тип. Наприклад, під час присвоєння, якщо тип значення, яке присвоюють (ліва частина), гарантує, що значення потрапить у діапазон типу, якому присвоюють (права частина), достатньо простого присвоєння:

```csharp
uint ui = uint.MaxValue;
ulong ul = ui;    // no problem
```

З іншого боку, якщо діапазон типу-джерела не є підмножиною діапазону значень типу-приймача, потрібна операція приведення `()`, навіть якщо конкретне значення вкладається в діапазон приймача:

```csharp
short s = 42;
uint ui = (uint)s;
```
