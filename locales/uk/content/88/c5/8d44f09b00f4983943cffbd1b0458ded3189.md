# Вступ

Символи у Factor є цілими числами, кодовими точками Unicode, тож числові `<`, `>`, `=` дають змогу напряму впорядковувати з урахуванням регістру. Словник [`unicode`][unicode] додає предикати з підтримкою Unicode і перетворення регістру одного символу.

## Предикати символів

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
blank?   ( c -- ? )    ! whitespace
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
```

## Перетворення регістру

`ch>upper` і `ch>lower` змінюють регістр одного символу. `>upper` і `>lower` на рівні рядка тексту (англ. string) застосовують їх до кожного символу рядка тексту.

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```
