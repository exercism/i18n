# Інструкції

У цій вправі ми працюватимемо з ощадними рахунками. Щороку баланс ощадного рахунку оновлюється відповідно до його відсоткової ставки. Відсоткова ставка, яку дає нам банк, залежить від суми грошей на рахунку (його балансу):

- 3.213% для відʼємного балансу (це дає відʼємні відсотки).
- 0.5% для додатного балансу, меншого за `1000` доларів.
- 1.621% для додатного балансу, що становить `1000` доларів або більше, але менше ніж `5000` доларів.
- 2.475% для додатного балансу, що становить `5000` доларів або більше.

Щороку держава дозволяє нам пожертвувати відсоток своїх грошей на благодійність без сплати податків. Оскільки ми хороші люди, то якщо наприкінці року баланс виявиться додатним, ми беремо цей неоподатковуваний відсоток і подвоюємо його, округлюючи вниз до найближчого цілого долара. Ми не проти сплатити податок на другу половину пожертви.

На нас чекають три завдання, кожне з яких стосується балансу та його відсоткової ставки.

## 1. Обчисліть відсоткову ставку

Реалізуйте функцію `interestRate`, щоб обчислити відсоткову ставку на основі заданого балансу:

```fsharp
interestRate 200.75m
// => 0.5f
```

Зауважте, що повернене значення має тип `single`.

## 2. Обчисліть відсотки

Реалізуйте метод `interest`, щоб обчислити відсотки на основі заданого балансу:

```fsharp
interest 200.75m
// => 1.00375m
```

Зауважте, що повернене значення має тип `decimal`.

## 3. Обчисліть щорічне оновлення балансу

Реалізуйте функцію `annualBalanceUpdate`, щоб обчислити щорічне оновлення балансу з урахуванням відсоткової ставки:

```fsharp
annualBalanceUpdate 200.75m
// => 201.75375m
```

Зауважте, що повернене значення має тип `decimal`.

## 4. Обчисліть, скільки грошей пожертвувати

Реалізуйте функцію `amountToDonate`, щоб обчислити, скільки грошей пожертвувати на благодійність, на основі балансу та неоподатковуваного відсотка, який дозволяє держава:

```fsharp
let balance = 550.5m
let taxFreePercentage = 2.5
amountToDonate balance taxFreePercentage
// => 27
```

Зауважте, що повернене значення має тип `int`.
