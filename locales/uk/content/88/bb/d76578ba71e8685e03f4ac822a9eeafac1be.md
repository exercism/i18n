# Інструкції

Після нещодавньої перевірки безпеки нам доручили прибрати в архівних файлах журналів організації.

## 1. Визначте спотворені рядки журналу

Нам потрібно приблизно уявляти, скільки рядків журналу в архіві не відповідають поточним стандартам.
Ми вважаємо, що проста перевірка показує, чи є рядок журналу дійсним.
Щоб рядок вважався дійсним, він має починатися з одного з наведених нижче рядків тексту:

- [DEBUG]
- [INFO]
- [WARNING]
- [ERROR]

Реалізуйте функцію `valid_line?/1`, яка повертає `true`, якщо рядок журналу дійсний.

```elixir
LogParser.valid_line?("[ERROR] Network Failure")
# => true

LogParser.valid_line?("Network Failure")
# => false
```

## 2. Розбийте рядок журналу

Невдовзі після початку проєкту з розбору журналів ми розуміємо, що журнали одного застосунку не розбито на рядки, як в інших. У цьому проєкті те, що мало бути окремими рядками, лежить в одному рядку, зʼєднане химерними стрілками на кшталт `<--->` або `<*~*~>`.

Насправді будь-який рядок, перший символ якого `<`, останній символ `>`, а між ними будь-яка комбінація символів `~`, `*`, `=` і `-`, можна використовувати як розділювач у журналах цього проєкту.

Реалізуйте функцію `split_line/1`, яка приймає рядок і повертає масив рядків тексту.

```elixir
LogParser.split_line("[INFO] Start.<*>[INFO] Processing...<~~~>[INFO] Success.")
# => ["[INFO] Start.", "[INFO] Processing...", "[INFO] Success."]
```

## 3. Вилучіть артефакти з журналу

Ми виявили, що під час попередньої обробки журналів по них розсипався текст «end-of-line» разом із номером рядка (без пробілу між ними).

Реалізуйте функцію `remove_artifacts/1`, яка приймає рядок тексту, вилучає всі входження тексту «end-of-line» (без урахування регістру) і повертає чистий рядок журналу.

Рядки, що не містять тексту «end-of-line», повертаються без змін.

Просто вилучіть рядок «end-of-line», коригувати пробіли не потрібно.

```elixir
LogParser.remove_artifacts("[WARNING] end-of-line23033 Network Failure end-of-line27")
# => "[WARNING]  Network Failure "
```

## 4. Позначте рядки іменами користувачів

Ми помітили, що деякі рядки журналу містять речення, які згадують користувачів.
Ці речення завжди містять рядок `"User"`, за яким іде один або більше пробільних символів, а потім імʼя користувача.
Ми вирішуємо позначати такі рядки.

Реалізуйте функцію `tag_with_user_name/1`, яка обробляє рядки журналу:

- Рядки, що не містять рядка `"User"`, залишаються без змін.
- У рядках, що містять рядок `"User"`, додайте на початок рядка `[USER]`, за яким іде імʼя користувача.

```elixir
LogParser.tag_with_user_name("[INFO] User Alice created a new project")
# => "[USER] Alice [INFO] User Alice created a new project"
```

Можна припустити, що:

- Кожне входження рядка `"User"` супроводжується одним або більше пробільними символами та імʼям користувача.
- У кожному рядку є щонайбільше одне входження рядка `"User"`.
- Імена користувачів мають бути непорожніми рядками тексту, що не містять пробільних символів.
