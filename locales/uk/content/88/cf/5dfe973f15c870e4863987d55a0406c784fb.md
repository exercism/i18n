# Ресурси

## Навчання

- [Nim basics](https://narimiran.github.io/nim-basics/) - для програмістів-початківців.
- [Nim tutorial, part 1](https://nim-lang.org/docs/tut1.html) - для тих, хто вже має певний досвід програмування.
- [Learn X in Y minutes for Nim](https://learnxinyminutes.com/docs/nim/) - огляд синтаксису.
- [Nim for Python programmers](https://github.com/nim-lang/Nim/wiki/Nim-for-Python-Programmers)
- [Nim for C programmers](https://github.com/nim-lang/Nim/wiki/Nim-for-C-programmers)
- [Nim in Action](https://www.manning.com/books/nim-in-action) - доступна як друкована книжка або електронна книжка.

Більше матеріалів на офіційній сторінці [Learn Nim](https://nim-lang.org/learn.html).
