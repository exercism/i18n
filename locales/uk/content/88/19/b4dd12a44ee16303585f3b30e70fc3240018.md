# Булеві значення

У Swift є тип, відомий як [`Bool`][bools]. Він використовується для представлення значень `true` та `false`.

## Логічні оператори

У Swift є 3 [логічні оператори (`!`, `||`, `&&`)][logical-operators], які використовуються для поєднання булевих значень (англ. Boolean) і створення виразів, що дають різні значення.

### І (`&&`)

[Оператор _і_][and] у Swift позначається `&&` (логічне і) та повертає `true`, якщо обидва подані значення `true`, інакше повертає `false`.
Коли ми використовуємо оператор _і_, одне булеве значення ставимо праворуч від `&&` (і), а друге - ліворуч.

```Swift
true && true  // true
true && false // false
```

### Або (`||`)

[Оператор _або_][or] у Swift позначається `||` (логічне або) та повертає `true`, якщо **принаймні одне** з поданих значень є `true`. Якщо обидва значення `false`, то він повертає `false`.
Коли ми використовуємо оператор _або_, одне булеве значення ставимо праворуч від `||` (або), а друге - ліворуч.

```swift
true || true   // true
true || false  // true
false || false // false
```

### Логічне заперечення (`!`)

[Оператор логічного заперечення][not] у Swift позначається `!` і повертає `true`, якщо подане булеве значення `false`, та повертає `false`, якщо подано `true`.
Коли ми використовуємо логічне заперечення, булеве значення ставимо після оператора (`!`).

```swift
!true  // false
!false // true
```

## Використання дужок (`()`)

Працюючи з булевими значеннями, можна використати [явні дужки][explicit-parentheses], щоб визначити, які булеві значення обчислити першими.
Результат може відрізнятися залежно від того, як розставлено дужки.
У Swift першим обчислюється те, що стоїть у дужках.

```swift
true && false && false || true   // true
true && false && (false || true) // false
```

Оскільки те, що стоїть у дужках, обчислюється першим, у наступному прикладі логічне заперечення застосується до виразу всередині дужок.

```Swift
!true && false   // false
!(true && false) // true
```

Дужки варто використовувати лише тоді, коли вони впливають на результат, інакше їх слід опустити.
~~~~
