# Вступ

Основною обʼєктно-орієнтованою конструкцією в C# є _клас_, який поєднує дані (_поля_) та поведінку (_методи_). Поля й методи класу називають його _членами_.

Доступ до членів можна обмежити модифікаторами доступу, два найпоширеніші з яких:

- `public`: член доступний будь-якому коду (без обмежень).
- `private`: член доступний лише коду в тому самому класі.

Клас можна уявляти як шаблон для створення екземплярів цього класу. Щоб створити екземпляр класу (його ще називають _обʼєктом_), використовують ключове слово `new`:

```csharp
class Car
{
}

// Create two car instances
var myCar = new Car();
var yourCar = new Car();
```

Поля мають тип і можуть бути визначені будь-де в класі.
Публічні поля записують у PascalCase. Приватні поля записують у camelCase і додають на початок підкреслення `_`:

```csharp
class Car
{
    // Accessible by anyone
    public int Weight;

    // Only accessible by code in this class
    private string _color;
}
```

Полю можна за бажанням присвоїти початкове значення. Якщо поле _не_ задає початкового значення, йому буде присвоєно типове значення його типу. До значень полів екземпляра можна звертатися й оновлювати їх через точкову нотацію.

```csharp
class Car
{
    // Will be set to specified value
    public int Weight = 2500;

    // Will be set to default value (0)
    public int Year;
}

var newCar = new Car();
newCar.Weight; // => 2500
newCar.Year;   // => 0

// Update value of the field
newCar.Year = 2018;
```

Приватні поля зазвичай оновлюють як побічний ефект виклику методу. Такі методи зазвичай не повертають жодного значення, і тоді типом повернення має бути `void`:

```csharp
class CarImporter
{
    private int _carsImported;

    public void ImportCars(int numberOfCars)
    {
        // Update private field from public method
        _carsImported = _carsImported + numberOfCars;
    }
}
```
