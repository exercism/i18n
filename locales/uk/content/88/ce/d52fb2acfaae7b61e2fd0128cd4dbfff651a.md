# Вступ

Іноді певний фрагмент коду потрібно використати більше ніж один раз. У такому разі може бути зручно винести цей код у функцію. Функція зазвичай виконує лише одну конкретну дію. У Rust для визначення функцій використовують ключове слово ```fn```. Код, що належить функції, завжди розміщений між фігурними дужками (тобто `{}`). Функція з назвою `main` особлива, бо вона є точкою входу для програм. З цієї функції можна викликати інші функції.

```rust
fn say_my_name(name: &str) -> &str {
    name
}
```

Функції також можуть приймати параметри, як-от ```name: &str``` у ```say_my_name()```. Функції також можуть повертати значення, як-от `-> &str` вище.
