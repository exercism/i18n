# Підказки

## Загальне

## 1. Купити цілком нову радіокеровану машинку

- [На цій сторінці показано, як створити новий екземпляр класу][creating-objects].

## 2. Показати пройдену відстань

- Відстежуйте пройдену відстань у [полі][fields].
- Подумайте, яку видимість використати для поля (чи потрібно використовувати його поза класом?).
- Спробуйте скористатися [інтерполяцією рядків][string-interpolation], щоб сформувати рядок тексту (англ. string) для повернення.

## 3. Показати відсоток заряду батареї

- Відстежуйте початковий заряд батареї в [полі][fields].
- Ініціалізуйте поле конкретним значенням, що відповідає очікуваному початковому заряду батареї.
- Подумайте, яку видимість використати для поля (чи потрібно використовувати його поза класом?).
- Спробуйте скористатися [інтерполяцією рядків][string-interpolation], щоб сформувати рядок тексту для повернення.

## 4. Оновлювати кількість пройдених метрів під час руху

- Оновлюйте поле, що представляє пройдену відстань.

## 5. Оновлювати відсоток заряду батареї під час руху

- Оновлюйте поле, що представляє відсоток заряду батареї під час руху.

## 6. Заборонити рух, коли батарея розряджена

- Додайте умову, щоб оновлювати відстань і заряд батареї, лише якщо батарея ще не розряджена.
- Додайте умову, щоб показати повідомлення про розряджену батарею, якщо батарея розряджена.
