# Числа

У Crystal є тип `Number`, базовий для всіх числових типів.
Усередині типу Number є два основні підтипи: [`Int`][int] і [`Float`][float].

`Int` - скорочення від integer, він позначає цілі числа.
`Int` може бути як відʼємним, так і додатним, без десяткової точки.

```crystal
1.class
# => Int32

-1.class
# => Int32
```

`Float` позначає числа з десятковою точкою.
Числа `Float` можуть бути як відʼємними, так і додатними.

```crystal
10.5.class
# => Float64
```

## Перетворення між `Int` і `Float`

За допомогою методів «to_i» та «to_f» можна перетворювати значення між `Int` і `Float`.
Під час перетворення з `Float` на `Int` число округлюється в менший бік.

```crystal
1.to_f
# => 1.0

1.0.to_i
# => 1

1.9.to_i
# => 1
```

## Арифметичні оператори

До `Int` і `Float` можна застосовувати [базові арифметичні оператори][math].
Це оператори `+`, `-`, `*`, `/` і `%`.
Використовуючи ці оператори, можна поєднувати `Int` і `Float`.

### Додавання, віднімання та множення

Оператор `+` виконує додавання, оператор `-` - віднімання, а оператор `*` - множення.

| Оператор | Приклад        |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### Ділення

Ділення використовують, щоб ділити числа.
Для ділення використовують оператор `/`.
Результат завжди буде `Float`.

```crystal
4 / 2
# => 2.0

4.0 / 2
# => 2.0
```

~~~~exercism/caution
У деяких мовах програмування ділення на нуль спричиняє помилку.

У Crystal ділення на нуль дає `Infinity` або `-Infinity`.
Єдиний виняток - ділення нуля на нуль, яке дає `NaN` (Not a Number).
`Infinity` і `NaN` - це особливі значення типу `Float`.

```crystal
1 / 0
# => Infinity

-1 / 0
# => -Infinity

0 / 0
# => NaN
```
~~~~

### Остача

Остача дає залишок від ділення.
Для цього використовують оператор `%`.

```crystal
5 % 2
# => 1

5.0 % 2
# => 1.0

5 % 3
# => 2
```

~~~~exercism/caution
Ділення на нуль під час обчислення остачі дає DivisionByZeroError.
Це відрізняється від звичайного ділення.

```crystal
1 % 0
# Error: Unhandled exception: Division by 0 (DivisionByZeroError)
```
~~~~

## Округлення

Метод `round` приймає необовʼязковий аргумент: кількість десяткових знаків для округлення.
Типова кількість десяткових знаків - 0.

```crystal
1.0.round
# => 1

1.5.round
# => 2

1.234.round(2)
# => 1.23
```

## Пріоритет і дужки

Crystal дозволяє використовувати дужки (`()`), які можна застосовувати, щоб групувати вирази.
Це корисно, коли потрібно змінити порядок виконання операцій.

Коли використовується кілька арифметичних операторів, порядок операцій такий самий, як у математиці, він відомий як [PEMDAS][pemdas].
Він такий: дужки (`()`), піднесення до степеня (`**`), множення (`*`) і ділення (`/`), додавання (`+`) і віднімання (`-`).

```crystal
2 + 3 - 4 * 4
# => -11

(2 + 3 - 4) * 4
# => 4
```
