# Сортування

Упорядковувати речі доводиться досить часто, тож бібліотека робить це за нас.

```sather
   scores : ARRAY{INT} := |3, 1, 2|;
   scores.sort;              -- 1, 2, 3
```

`sort` працює з будь-чим, що вже вміє порівнювати себе. Числа й рядки тексту (англ. string) вміють, бо в них є `is_lt`.

## Сортування за власним правилом

Більшість порядків не збігається зі вбудованим. Турнірна таблиця з нетболу не будується ні за алфавітом, ні за довжиною назви: спершу за очками, а для команд з однаковою кількістю очок - за різницею мʼячів. `ARRAY` ніяк не може цього вгадати.

Тож ми передаємо порядок ззовні, як привʼязану підпрограму:

```sather
   before(a, b : STR) : BOOL is
      return a.size < b.size;
   end;

   ...

   words.insertion_sort_by(bind(before(_, _)));
```

`insertion_sort_by` приймає `ROUT{T,T}:BOOL`: підпрограму, яка бере два елементи з тих, що сортуються, і відповідає, чи перший має стояти перед другим. Вона викликає цю підпрограму стільки разів, скільки потрібно, і впорядковує масив так, як підказують ці відповіді.

Ось для чого був `understudy`. Бібліотека вміє сортувати і нічого не знає про наше уявлення про порядок; саме в привʼязаній підпрограмі вони й зустрічаються.

## Як писати порівняння

Підпрограма дає відповідь **правда, коли перший аргумент іде першим**.

```sather
   -- shortest first
   return a.size < b.size;

   -- longest first: turn it round
   return a.size > b.size;
```

Якщо правило має більше ніж одну частину, розгляньмо ці частини за важливістю:

```sather
   higher(a, b : TEAM) : BOOL is
      if a.points /= b.points then
         return a.points > b.points;      -- more points comes first
      end;
      return a.difference > b.difference; -- level: better difference wins
   end;
```

Перший `if` вирішує все, щойно очки різняться. Лише коли вони однакові, вступає в дію другий рядок. Якби ми поставили додатковий показник першим, очки б ніколи не мали значення.

## Сортування змінює масив

`insertion_sort_by` упорядковує сам масив і нічого не повертає:

```sather
   teams.insertion_sort_by(bind(higher(_, _)));   -- teams is now sorted
```

Якщо початковий порядок важливий, відсортуймо копію:

```sather
   ranked ::= teams.copy;
   ranked.insertion_sort_by(bind(higher(_, _)));
   return ranked;
```
