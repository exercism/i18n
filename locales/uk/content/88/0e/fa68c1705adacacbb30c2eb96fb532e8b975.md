# Вступ

## Регулярні вирази

Регулярні вирази в Gleam відповідають специфікації **PCRE** (**P**erl **C**ompatible **R**egular **E**xpressions), як і в інших популярних мовах, таких як Java, JavaScript чи Ruby.

Модуль `gleam/regexp` з пакета `gleam_regexp` надає функції для роботи з регулярними виразами.

~~~~exercism/note
Ця вправа припускає, що ми вже знайомі із синтаксисом регулярних виразів, зокрема з класами символів, квантифікаторами, групами та захопленнями.

Якщо потрібно освіжити знання про регулярні вирази, зазирнімо до одного з цих джерел: [Regular-Expressions.info](https://www.regular-expressions.info), [Rex Egg](https://www.rexegg.com/), [RegexOne](https://regexone.com/), [Regular Expressions 101](https://regex101.com/), [RegExr](https://regexr.com/).
~~~~

Найпоширеніший спосіб створити регулярний вираз - скористатися функцією `regexp.from_string`.

```gleam
let assert Ok(re) = regexp.from_string("test")
```

Функції створення регулярних виразів повертають помилку, якщо синтаксис регулярного виразу неправильний, тому тут використано твердження `let`, щоб переконатися, що регулярний вираз правильний.

Функцію `regexp.check` можна використати, щоб перевірити, чи регулярний вираз збігається з рядком тексту (англ. string).

```gleam
let assert Ok(re) = regexp.from_string("test")

regexp.check(re, "this is a test")
// -> True

regexp.check(re, "this is too")
// -> False
```


### Захоплення

Якщо ми хочемо захопити підрядки за допомогою регулярного виразу, можна скористатися функцією `regexp.scan`, яка повертає масив збігів.

```gleam
let assert Ok(re) = regexp.from_string("[oi]n a (\\w+)")
regexp.scan(with: re, content: "I am on a boat in a lake.")
// -> [
//   Match(
//     content: "on a boat",
//     submatches: [Some("boat")]
//   ),
//   Match(
//     content: "in a lake",
//     submatches: [Some("lake")]
//   )
// ]
```

### Модифікатори

Поведінку регулярного виразу можна змінити, створивши його функцією `regexp.compile` і передавши опції.

```gleam
let options = regexp.Options(case_insensitive: True, multi_line: False)
let assert Ok(re) = regexp.compile("[A-Z]", with: options)
regexp.check(re, "abc123")
// -> True
```
