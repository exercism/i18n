# Інструкції

Друг, який прагне стати митцем, звернувся до нас з ідеєю проєкту. Поєднаймо його творчу уяву з нашими технічними знаннями. Час узятися за [генеративне мистецтво][generative-art]!

Обмеження допомагають творчості й скорочують терміни проєкту, тож ми обидва домовилися обмежити наш шедевр однією формою - колом. Але кіл буде багато. І вони можуть рухатися! Назвімо це... «танцювальні крапки».

Друг неодмінно захоче вигадувати нові складні рухи для крапок, тож почнімо кодувати зі створення архітектури, яка згодом дасть змогу легко визначати нові анімації.

## 1. Визначте поведінку анімації

Кожен модуль анімації має реалізувати два колбеки: `init/1` і `handle_frame/3`. Визначте їх у модулі `Animation`.

Визначте колбек `init/1`. Він має приймати один аргумент типу `opts` і повертати або кортеж `{:ok, opts}`, або кортеж `{:error, error}`. Реалізації цього колбека перевірятимуть, чи надані опції придатні для цього конкретного типу анімації.

Визначте колбек `handle_frame/3`. Він має приймати три аргументи: крапку, номер кадру й опції. Він завжди має повертати крапку. Реалізації цього колбека змінюватимуть атрибути крапки на основі поточного номера кадру й опцій анімації.

## 2. Надайте типову реалізацію колбека `init/1`

Поведінку `Animation` має бути легко включити в інші модулі, викликавши `use DancingDots.Animation`.

Щоб це працювало, реалізуйте макрос `__using__` у модулі `Animation` так, щоб він задавав модуль `Animation` як поведінку іншого модуля. Він також має надавати типову реалізацію колбека `init/1`. Типова реалізація `init/1` має повертати надані опції без змін.

```elixir
defmodule MyCustomAnimation do
  use DancingDots.Animation
end

MyCustomAnimation.init(some_option: true)
# => {:ok, [some_option: true]}
```

## 3. Реалізуйте анімацію `Flicker`

Використайте поведінку `Animation`, щоб реалізувати мерехтливу анімацію.

Вона має використовувати типовий колбек `init/1`, бо не приймає жодних опцій.

Реалізуйте колбек `handle_frame/3`, який обробляє один кадр. Якщо номер кадру кратний чотирьом, функція має повертати крапку з половиною її початкової непрозорості. В інших кадрах вона має повертати крапку без змін.

Кадри лічаться від `1`. Крапка, передана в `handle_frame/3`, завжди перебуває в початковому стані, а не в стані з попереднього кадру.

```elixir
dot = %DancingDots.Dot{x: 100, y: 100, radius: 24, opacity: 1}

DancingDots.Flicker.handle_frame(dot, 1, [])
# => %DancingDots.Dot{opacity: 1, radius: 24, x: 100, y: 100}

DancingDots.Flicker.handle_frame(dot, 4, [])
# => %DancingDots.Dot{opacity: 0.5, radius: 24, x: 100, y: 100}
```

## 4. Реалізуйте анімацію `Zoom`

Використайте поведінку `Animation`, щоб реалізувати анімацію масштабування.

Ця анімація приймає одну опцію - швидкість. Швидкість може бути будь-яким числом. Якщо вона відʼємна, крапка зменшується замість того, щоб збільшуватися.

Реалізуйте колбек `init/1`. Він має перевіряти, що надані опції є списком ключових слів із ключем `:velocity`. Значення швидкості має бути числом. Якщо це не число, поверніть помилку `"The :velocity option is required, and its value must be a number. Got: #{inspect(velocity)}"`.

Реалізуйте колбек `handle_frame/3`. Він має повертати крапку з радіусом, збільшеним на добуток (поточного номера кадру мінус один) і швидкості.

Кадри лічаться від `1`. Крапка, передана в `handle_frame/3`, завжди перебуває в початковому стані, а не в стані з попереднього кадру.

```elixir
DancingDots.Zoom.init(velocity: nil)
# => {:error, "The :velocity option is required, and its value must be a number. Got: nil"}

dot = %DancingDots.Dot{x: 100, y: 100, radius: 24, opacity: 1}

DancingDots.Zoom.handle_frame(dot, 1, velocity: 10)
# => %DancingDots.Dot{radius: 24, opacity: 1, x: 100, y: 100}

DancingDots.Zoom.handle_frame(dot, 2, velocity: 10)
# => %DancingDots.Dot{radius: 34, opacity: 1, x: 100, y: 100}
```
