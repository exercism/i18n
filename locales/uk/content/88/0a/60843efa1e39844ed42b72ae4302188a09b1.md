# Вступ

Розумні вказівники в Cairo - це просунуті структури даних, які забезпечують безпечне та ефективне керування памʼяттю: вони додають до звичайних вказівників запобіжні механізми й усувають типові проблеми, як-от розіменування нульового вказівника чи доступ до неініціалізованої памʼяті.

## Що таке розумний вказівник?

Розумний вказівник поводиться як звичайний вказівник, але відстежує володіння та забезпечує безпечний доступ до памʼяті, запобігаючи таким проблемам, як розіменування нульового чи висячого вказівника.

## Типи розумних вказівників

Cairo надає кілька типів розумних вказівників, як-от `Box<T>` і `Nullable<T>`:

- **`Box<T>`**: зберігає дані в окремому сегменті памʼяті, що ідеально підходить для великих даних або даних з динамічним розміром.
                Він дає змогу передавати володіння без копіювання даних.
- **`Nullable<T>`**: указує або на припустиме значення типу `T`, або на `null`; стає в пригоді для роботи з необовʼязковими значеннями.

## Безпека памʼяті

Розумні вказівники допомагають запобігти небезпечному доступу до памʼяті: вони гарантують, що памʼять автоматично звільняється, коли більше не потрібна, і тим самим зменшують ризик витоків памʼяті.

### Приклад: використання `Box<T>` для рекурсивних типів

Такі розумні вказівники, як `Box<T>`, дають змогу безпечно працювати з рекурсивними типами, наприклад з бінарним деревом: вони ефективно виділяють памʼять і запобігають нескінченній рекурсії.

```rust
use core::box::{BoxTrait};

#[derive(Copy, Drop)]
enum BinaryTree {
    Leaf: u32,
    Node: (u32, Box<BinaryTree>, Box<BinaryTree>),
}

fn main() {
    let leaf1 = BinaryTree::Leaf(1);
    let leaf2 = BinaryTree::Leaf(2);
    let node = BinaryTree::Node((3, BoxTrait::new(leaf1), BoxTrait::new(leaf2)));
    println!("{:?}", node);
}
```

## Переваги для продуктивності

Розумні вказівники підвищують продуктивність, передаючи посилання на дані замість копіювання великих структур, що зменшує накладні витрати на памʼять.

```rust
// `Cart` is a large struct that contains a lot of information
fn pass_pointer(cart: Box<Cart>) {
    let cart = cart.unbox();
    println!("{} is shopping today and bought {} items", cart.buyer, cart.items);
}
```
