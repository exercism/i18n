# Вказівки

У цій вправі ми реалізуємо спосіб відстежувати рекорди найпопулярнішої гри в місцевому залі ігрових автоматів.

## 1. Визначте нову мапу рекордів

Щоб створити нову мапу рекордів, визначте функцію `HighScore.new/0`, яка не приймає жодних аргументів і повертає нову порожню мапу рекордів.

```elixir
HighScore.new()
# => %{}
```

## 2. Додайте гравців до мапи рекордів

Щоб додати гравця до мапи рекордів, визначте функцію `HighScore.add_player/3`, яка приймає 3 аргументи:

- Перший аргумент - мапа рахунків.
- Другий аргумент - імʼя гравця у вигляді рядка тексту (англ. string).
- Третій аргумент - рахунок у вигляді цілого числа. Цей аргумент необовʼязковий, тож реалізуйте третій аргумент з типовим значенням 0.

Збережіть типове початкове значення рахунку в атрибуті модуля. Воно ще знадобиться.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas")
# => %{"Dave Thomas" => 0}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"Dave Thomas" => 0, "José Valim"=> 486_373}
```

## 3. Видаліть гравців з мапи рахунків

Щоб видалити гравця з мапи рекордів, визначте функцію `HighScore.remove_player/2`, яка приймає 2 аргументи:

- Перший аргумент - мапа рахунків.
- Другий аргумент - імʼя гравця у вигляді рядка тексту.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas")
# => %{"Dave Thomas" => 0}
score_map = HighScore.remove_player(score_map, "Dave Thomas")
# => %{}
```

## 4. Скиньте рахунок гравця

Щоб скинути рахунок гравця, визначте функцію `HighScore.reset_score/2`, яка приймає 2 аргументи:

- Перший аргумент - мапа рахунків.
- Другий аргумент - імʼя гравця у вигляді рядка тексту, чий рахунок потрібно скинути.

Функція повинна також працювати, якщо гравець не має рахунку.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"José Valim"=> 486_373}
score_map = HighScore.reset_score(score_map, "José Valim")
# => %{"José Valim"=> 0}
```

## 5. Оновіть рахунок гравця

Щоб оновити рахунок гравця, додавши до попереднього рахунку, визначте функцію `HighScore.update_score/3`, яка приймає 3 аргументи:

- Перший аргумент - мапа рахунків.
- Другий аргумент - імʼя гравця у вигляді рядка тексту, чий рахунок потрібно оновити.
- Третій аргумент - рахунок, який потрібно **додати** до збереженого рекорду.

Функція повинна також працювати, якщо гравець не має попереднього рахунку: вважайте, що попередній рахунок дорівнює 0.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"José Valim"=> 486_373}
score_map = HighScore.update_score(score_map, "José Valim", 5)
# => %{"José Valim"=> 486_378}
```

## 6. Отримайте список гравців

Щоб отримати список гравців, визначте функцію `HighScore.get_players/1`, яка приймає 1 аргумент:

- Перший аргумент - мапа рахунків.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas", 2_374)
# => %{"Dave Thomas" => 2_374}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"Dave Thomas" => 2_374, "José Valim"=> 486_373}
HighScore.get_players(score_map)
# => ["Dave Thomas", "José Valim"]
```
