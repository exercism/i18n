# Ігноруйте мене

## Вхідні дані

Скрипт отримає алфаметричну головоломку як один рядок тексту (англ. string) через
стандартний ввід (stdin). Рядок головоломки має формат
`WORD1 + WORD2 + ... == RESULT`.

Наприклад:

```text
SEND + MORE == MONEY
```

## Вихідні дані

Якщо головоломка має розвʼязок, надрукуйте один рядок, що складається з пар
`LETTER=DIGIT`, розділених пробілами, відсортованих за алфавітом за літерою.

Для наведеного вище прикладу вихідні дані мають бути такими:

```text
D=7 E=5 M=1 N=6 O=0 R=8 S=9 Y=2
```

Якщо головоломка має кілька правильних розвʼязків, можна надрукувати будь-який з них.

Якщо головоломка не має розвʼязку, не друкуйте нічого (порожній рядок).
