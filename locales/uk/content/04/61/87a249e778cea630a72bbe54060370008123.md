# Інструкція switch

Інструкція `switch` дає змогу реалізувати умовну конструкцію керування `if..elseif..else`.

```php
function getMessage(string $letter): string
{
  switch ($letter) {
    case 'a':
      $message = 'First letter of the english alphabet';
      break;
    case 'z':
      $message = 'Last letter of the english alphabet';
      break;
    case 'l':
    default:
      $message = 'A letter, neither the first nor the last of the alphabet';
  }
  return $message;
}

// getMessage('a') => 'First letter of the english alphabet'
// getMessage('z') => 'Last letter of the english alphabet'
// getMessage('l') => 'A letter, neither the first nor the last of the alphabet'
// getMessage('k') => 'A letter, neither the first nor the last of the alphabet'
```

Унікальна особливість інструкції `switch` полягає в поведінці «fall-through» кожного `case`.
Звернімо увагу на конкретне розташування інструкцій `break` у прикладі.
Без інструкції `break` кожен `case` буде виконуватися від початку першого `case`, доки не буде виконано інструкцію `break`.
Порядок `case` усередині `switch` має значення, адже обчислюються лише `case` до першого відповідного включно.

> Кілька слів застереження: поведінка «fall-through» дає змогу спільно використовувати код у схожих `case`, але вона також може бути джерелом непередбачуваної поведінки та помилок, якщо забути про інструкцію `break`.

Кожен `case` виконує нестроге (вільне) порівняння:

```php
function matches($value): string
{
  switch ($value) {
    case false:
      return 'matches false';
    case true:
      return 'matches true';
  }
}

// matches([]) => 'matches false'
// matches(0) => 'matches false'
// matches(null) => 'matches false'
// matches('') => 'matches false'

// matches([1]) => 'matches true'
// matches(1) => 'matches true'
// matches('a') => 'matches true'
```

## Варіант `switch` без `break`

Припустімо, що наведену вище функцію переписано так:

```php
function getMessage(string $letter): string
{
  switch ($letter) {
    case 'a':
      return 'First letter of the english alphabet';
    case 'z':
      return 'Last letter of the english alphabet';
    case 'l':
    default:
      return 'A letter, neither the first nor the last of the alphabet';
  }
}

// getMessage('a') => 'First letter of the english alphabet'
// getMessage('z') => 'Last letter of the english alphabet'
// getMessage('l') => 'A letter, neither the first nor the last of the alphabet'
// getMessage('k') => 'A letter, neither the first nor the last of the alphabet'
```

Поведінка функції залишається тією самою, але повернення безпосередньо з інструкції `switch` дає змогу уникнути можливого пропуску інструкції `break`.

## Варіант `switch` із умовними виразами

Ще один варіант використання інструкції `switch` - порівнювати кожен `case` за допомогою виразу:

```php
function compareSum(int $sum): string
{
  switch (true) {
    case $sum < 10:
      return 'Less than 10';
    case $sum > 10:
      return 'More than 10';
    default:
      return 'Sum is 10';
  }
}
```

Це дає певну гнучкість, щоб писати різноманітніші вирази і компонувати функції, коли ми визначаємо, яку гілку `case` виконувати.
