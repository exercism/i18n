# Інструкції

Ми працюємо боцманом на прибережному вантажному судні. Трюм,
найнижчий відсік корпусу, збирає стічні води, і щоразу за
зміну трюмне обладнання доводиться відкривати, запускати і
прибирати на місце. Хоч би що сталося під час відкачування,
обладнання *мусить* знову опинитися в прибраному стані.

Тести дають нам `<test-pump>`, щоб отримувати свіжі насоси.
Кожен насос має слот `opened>>`, який читається як `t`, поки
насос відкритий, і як `f`, коли його звільнено.

## 1. Осушити трюм

Визначте `drain-bilge`, щоб звільняти один насос. Виклик
`drain-bilge` для того самого насоса двічі має бути
нешкідливим, адже про це подбає фреймворк.

```factor
<test-pump> dup drain-bilge opened>> .   ! => f
```

## 2. Процедура відкачування

Визначте `pump-out`, який приймає насос і quotation, кладе
насос у стек, щоб quotation ним скористався, і після цього
звільняє насос, *навіть якщо quotation викине виняток*.

```factor
<test-pump> [ drop ] pump-out   ! pump released
```

## 3. Процедура на цілу зміну

Визначте `shift-routine`, який приймає два насоси і quotation.
Відкрийте область видимості деструкторів, зареєструйте *обидва*
насоси для безумовного звільнення, а тоді викличте quotation.
Обидва насоси виявляться звільненими незалежно від того, чи
quotation завершиться нормально, чи викине виняток.

На вхід quotation отримує обидва насоси у стеку.

```factor
<test-pump> <test-pump> [ 2drop ] shift-routine
! both pumps released
```

## 4. Ризиковане відкачування

Іноді насос позичений: звільняти його хочеться лише тоді, коли
щось піде не так, бо інакше наступній вахті він потрібен
відкритим. Визначте `risky-pump-out`, який приймає насос і
quotation, реєструє насос для звільнення **лише в разі помилки**
і викликає quotation, тримаючи насос у стеку.

Якщо quotation завершиться успішно, насос залишиться відкритим.
Якщо quotation викине виняток, насос буде звільнено, а виняток
пошириться далі.

```factor
<test-pump> [ drop ] risky-pump-out                ! stays open
<test-pump> [ drop "boom" throw ] risky-pump-out   ! pump released, throws
```

## 5. Власний disposable: клапан

Доповніть набір інструментів зовсім новим disposable: клапаном
`valve`. Кортеж уже оголошено для нас:

```factor
TUPLE: valve < disposable is-open ;
```

- Визначте `<valve> ( -- valve )`, щоб створювати свіжий клапан
  через `new-disposable`, зі значенням `is-open`, установленим у
  `t`.
- Реалізуйте `M: valve dispose*`, щоб перемикати `is-open` на `f`.

```factor
<valve> is-open>> .                ! => t
<valve> dup dispose is-open>> .    ! => f
```
