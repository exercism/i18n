# Докладніше

## Рівність

Типи Elm можна перевіряти на «однаковість» за допомогою [оператора рівності][equality-operator] `(==)`.
Оператор нерівності - це `(/=)` (*не* `!=`, як у багатьох мовах).

```elm
1 == 2
    --> False

1 /= 2
    --> True
```

Обидва значення, які порівнюють, мають бути одного типу.
Оператор рівності працює з літералами, кортежами, записами та власними типами.
Оператор перевіряє структурну рівність, тобто рівні значення мають однаковий вміст і однакову глибоку структуру, незалежно від анотації типу чи позиції в памʼяті.

```elm
(1, 2) == (2, 1)
    --> False

type alias MyRecord = { myInt : Int, myStrings : List String }
a : MyRecord
a = MyRecord (1 + 1) ["hello world"]

type alias MyOtherRecord = { myInt : Int, myStrings : List String }
myStrings =  (String.join " " ["hello", "world"]) :: []
b : MyOtherRecord
b = { myInt = 2, myStrings = myStrings}

a == b
    --> True
```

Зауважмо, що функції *ніколи не варто* порівнювати, бо це призведе до аварійного завершення програми під час виконання.
Більше про це обмеження [тут][equality-operator].

## Порівняння

[Оператори порівняння][comparison-operators] `(<)`, `(<=)`, `(>)`, `(>=)` та функції `min`, `max`, `compare` працюють із типами `comparable`.
Тип `comparable` - це спеціальний тип, який обʼєднує всі вбудовані типи, які можна порівнювати: числа, символи, рядки тексту (англ. string), масиви порівнюваних значень і кортежі порівнюваних значень.
Символи порівнюються за їхніми [кодовими точками Unicode][unicode-codepoint].

```elm
1 < 1 + 1
    --> True

'x' < 'X'
    --> False

'互' < '🙏'
    --> True
```

Типи, схожі на послідовності (рядки тексту, масиви та кортежі), порівнюються в [лексикографічному порядку][lexicographic-order].
Стисло кажучи, елементи послідовності порівнюються попарно за порядком, доки не знайдеться менший елемент або не закінчиться послідовність.

```elm
"abc" < "abz"
    --> True

"abc" < "abcd"
    --> True

"abc" < "b"
    --> True

min [1 , 2, 9000] [10]
    --> [1 , 2, 9000]

min (1, "hello") (3, "bye")
    --> (1, "hello")

min (1, ['a', 'b']) (1, ['A', 'B'])
    --> (1, ['A', 'B'])
```

Значення інших типів, як-от записи чи власні типи, не можна порівнювати безпосередньо.

Деякі вбудовані типи вимагають, щоб їхній вміст був `comparable`, наприклад `Set` чи ключі `Dict`, оскільки їхня структура спирається на внутрішнє впорядкування.
Це означає, що власні типи не можна зберігати в `Set`, хоча є альтернативи від спільноти: [`AnySet`][any-set], [`AnyDict`][any-dict], [`Sort`][sort] та інші.

Масиви значень `comparable` можна сортувати за допомогою `List.sort`, а масиви значень, які можна відобразити в порівнювані значення, можна сортувати за допомогою `List.sortBy`.
Якщо потрібне ієрархічне сортування (сортування за однією властивістю, а якщо значення збігаються, то за іншою), можна використати кортежі чи масиви разом із `List.sortBy` (серед інших [альтернатив][sort-by]), оскільки кортежі й масиви сортуються в лексикографічному порядку.


```elm
List.sort ["hi", "hello", "bye", "goodbye"]
    --> ["bye", "goodbye", "hello", "hi"]

List.sortBy String.length ["hi", "hello", "bye", "goodbye"]
    --> ["hi", "bye", "hello", "goodbye"]

-- sort by length, then alphabetically
List.sortBy (\str -> (String.length str, str)) ["hi", "mum", "hello", "sis", "bye", "dad"]
    --> ["hi", "bye", "dad", "mum", "sis", "hello"]
```

Функція `compare` приймає два `comparable`-значення і повертає `Order`.
`Order` - це тип, який за одну операцію перевіряє, чи одне значення більше (`GT`), дорівнює (`EQ`) або менше (`LT`) за інше.

```elm
compare 1 2
    --> LT

compare "" ""
    --> EQ

compare [12] []
    --> GT
```

Функції порівняння можна побудувати для довільних типів і використовувати, наприклад, для сортування за допомогою `List.sortWith`:

```elm
type Color = Red | Green | Blue

compareColors : Color -> Color -> Order
compareColors a b =
  case (a, b) of
    (Red, Red) -> EQ
    (Red, _) -> LT
    (_, Red) -> GT
    (Green, Green) -> EQ
    (Green, _) -> LT
    (_, Green) -> GT
    (Blue, Blue) -> EQ

List.sortWith compareColors [Blue, Red, Green, Green, Blue]
    --> [Red, Green, Green, Blue, Blue]
```
