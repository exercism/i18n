# Вступ

## Непрозорі типи

Непрозорі типи в Gleam - це власні типи, значення яких може створювати або зіставляти зі зразком лише модуль, що визначає цей тип. Це корисно, коли треба створити типи, які можна використовувати лише в певний спосіб.

Непрозорі типи визначають за допомогою ключового слова `opaque`.

```gleam
pub opaque type PositiveInt {
  PositiveInt(inner: Int)
}
```

Тип `PositiveInt` призначений для ситуацій, де потрібне ціле число, але воно має бути нулем або більшим. Звичайний `Int` у Gleam тут не підійде, бо він може бути й відʼємним.

Модуль, що визначає цей тип, може визначити функцію, яка повертає внутрішнє ціле число, і функцію для створення типу `PositiveInt`, яка поверне помилку, якщо значення не є додатним.

```gleam
pub fn from_int(i: Int) -> Result(PositiveInt, String) {
  case i {
    _ if i < 0 -> Error("Value must be positive")
    _ -> Ok(PositiveInt(i))
  }
}

pub fn to_int(i: PositiveInt) -> Int {
  i.inner
}
```

Із цим API інші модулі не можуть створити `PositiveInt` з відʼємним значенням, тож будь-яка функція, що приймає `PositiveInt`, може бути певна, що значення додатне.
