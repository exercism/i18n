# Типові аргументи не використано

У визначенні функції цього рішення типовий аргумент не використано.
[Типові аргументи в Python][default arguments in python] допомагають захиститися від ситуацій, коли функцію викликають без потрібного аргументу або коли передати нічого.
`Default arguments` також допомагають уникати зайвого умовного коду або перевірок усередині функції.

Це рішення можна покращити, використавши `default argument` разом із [str.format][str.format] або [f-strings][f-strings] (_інакше кажучи, «форматовані рядки-літерали» або «рядки з інтерполяцією»_).

[Форматування рядків у Python][string formatting in python] від Real Python може стати добрим початком для вивчення варіантів форматування рядків у Python.
