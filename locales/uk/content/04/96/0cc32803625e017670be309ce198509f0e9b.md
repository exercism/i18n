# Генератори тестів

C#-трек використовує [генератор тестів](https://exercism.org/docs/building/tooling/test-generators), щоб автоматично генерувати тести практичних вправ.
Він спирається на те, що більшість вправ, визначених у [репозиторії problem-specifications](https://github.com/exercism/problem-specifications/), також мають файл `canonical-data.json`, який містить стандартизовані вхідні та вихідні дані тестів, які можна використати для реалізації вправи.

## Кроки

Щоб згенерувати тести практичної вправи, генератор тестів:

1. Читає тестові випадки вправи з її файлу `canonical-data.json`
2. Використовує файл `tests.toml`, щоб пропускати виключені тестові випадки
3. Рендерить тестові випадки за допомогою шаблону генератора цієї вправи
4. Форматує відрендерений шаблон за допомогою Roslyn
5. Записує відформатований шаблон у файл тестів вправи

### Крок 1: читаємо файл `canonical-data.json`

Генератор тестів розбирає тестові випадки з файлу `canonical-data.json` вправи за допомогою [простору імен System.Text.Json](https://learn.microsoft.com/en-us/dotnet/api/system.text.json).

Оскільки деякі канонічні дані використовують вкладеність, розібраний тестовий випадок містить додаткове поле `path`, яке включає властивості `description` усіх батьківських елементів, а також власну властивість `description` цього тестового випадку.

### Крок 2: пропускаємо виключені тести з файлу `tests.toml`

Кожна вправа має файл `tests.toml`, у якому окремі тести можна виключити або вимкнути.
Генератор тестів видаляє всі тестові випадки, позначені як виключені (`include = false`).

### Крок 3: рендеримо тестові випадки

Потім (можливо, перетворені) тестові випадки передаються у файл `.meta/Generator.tpl`, який визначає, як рендерити тести на основі цих тестових випадків.

### Крок 4: форматуємо відрендерений шаблон за допомогою Roslyn

Потім відрендерений шаблон форматується за допомогою [Roslyn](https://github.com/dotnet/roslyn).
Це дає такі переваги:

- Вправи форматуються однаково
- Пишучи шаблони, нам не потрібно надто перейматися пробілами та вирівнюванням

### Крок 5: записуємо відрендерений шаблон у файл тестів вправи

Нарешті, результат відрендереного шаблону записується у файл тестів вправи.

## Шаблони

Шаблони рендеряться за допомогою [бібліотеки Scriban](https://github.com/scriban/scriban/).

## Інтерфейс командного рядка

Генератор тестів можна запустити двома способами:

1. `bin/update-tests.ps1`: оновити тести для всіх вправ, які мають шаблон генератора
2. `bin/update-tests.ps1 -e <slug>`: оновити тести для вказаної вправи, якщо вона має шаблон генератора
