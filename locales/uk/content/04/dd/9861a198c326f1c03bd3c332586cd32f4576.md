# Числа

`INT` зберігає ціле число. У цьому Sather він займає рівно 32 біти, тож може набувати значень від -2147483648 до 2147483647.

```sather
   goals : INT is
      return 42;
   end;
```

## Аргументи

Підпрограма приймає аргументи в дужках, і кожен має свій тип:

```sather
   total(first : INT, second : INT) : INT is
      return first + second;
   end;
```

Аргументи одного й того самого типу можна оголосити разом, і це звичний стиль:

```sather
   total(first, second : INT) : INT is
```

## Арифметика

| Оператор | Дія |
| --- | --- |
| `+` | додавання |
| `-` | віднімання та зміна знака |
| `*` | множення |
| `/` | ділення з відкиданням остачі |
| `%` | остача від цього ділення |

`/` між двома `INT` ніколи не дає дробу:

```sather
7 / 2      -- 3
7 % 2      -- 1
```

Якщо потрібен дріб, знадобиться `FLTD`, про який ітиметься далі.

Множення і ділення мають вищий пріоритет, ніж додавання і віднімання, як і у звичайній арифметиці. Коли потрібен інший порядок обчислень, вираз групують дужками:

```sather
2 + 3 * 4        -- 14
(2 + 3) * 4      -- 20
```

## Корисні підпрограми для INT

```sather
7.max(3)     -- 7
7.min(3)     -- 3
(-7).abs     -- 7
7.str        -- "7", the number written as text
```

Завдяки `.str` число стає частиною речення, коли ми вже познайомимося з рядками тексту (англ. string).
