# Вступ

## Оператори порівняння

R має набір операторів, такий самий, як у багатьох інших мовах:

```R
1 == 2 # FALSE
1 != 2 # TRUE
1 < 2 # TRUE
1 > 2 # FALSE
1 <= 2 # TRUE
1 >= 2 # FALSE
```

## Розгалуження

Базова форма конструкції if-else має такий вигляд:

```R
if (x > 10) {
    y <- "big"
} else if (x > 2) {
    y <- "medium"
} else {
    y <- "tiny"
}
```

У цьому випадку обовʼязкові і круглі дужки (`()`) навколо булевого значення (англ. Boolean), і фігурні дужки (`{}`) навколо тіла.

Просту умовну конструкцію `if` можна скоротити:

```R
if (x == 0) return("success")
```
