# Вступ

Haxe підтримує рефлексію типів і полів під час виконання. Щоб правильно використовувати рефлексію, потрібно розуміти, які операції підтримуються, а які ні. З огляду на динамічну природу рефлексії, це не завжди можна визначити під час компіляції.

API рефлексії складається з двох класів:

- `Reflect`: легкий API, який найкраще працює з анонімними структурами, з обмеженою підтримкою класів.
- `Type`: надійніший API для роботи з класами та переліками.

Для наступного прикладу ми використовуємо цільову платформу JavaScript:

```haxe
class Main {
  public static function main() {
    trace(Type.resolveClass("Main"));
  }
}

// This outputs
// class Test { static main() { console.log("Test.hx:3:",$hxClasses["Test"]); } }
```
