# Власні ітератори

```sather
   markers!(once spacing : INT, once count : INT) : INT is
      loop
         yield spacing * 1.upto!(count);
      end;
   end;
```

| | підпрограма | ітератор |
| --- | --- | --- |
| назва | `foo` | `foo!` |
| повертає значення | `return` | `yield` |
| завершується | `return` або кінець | `quit` або вичерпання |
| можна викликати | будь-де | лише всередині циклу `loop` |
| зберігає позицію | ні | так |

## yield

`yield` передає значення і призупиняється. Усе відновлюється на наступному кроці: локальні змінні, позиція у власних циклах ітератора та позиції будь-яких ітераторів, які він сам викликає.

`yield` у вкладених циклах відновлюється на найглибшому з них, і саме це робить написання обходу чогось вкладеного простим:

```sather
   all_cells!(grid : ARRAY{ARRAY{INT}}) : INT is
      loop
         row ::= grid.elt!;
         loop
            yield row.elt!;
         end;
      end;
   end;
```

## quit

Завершує ітератор, а отже й цикл, що його викликав. Він не передає значення: `quit` - це не останній результат, а повідомлення, що їх немає.

Ітератор із типом повернення повинен щоразу, коли виконує `yield`, передавати значення; `quit` - це спосіб відмовитися.

## once

```sather
   markers!(once count : INT) : INT is
```

Аргумент `once` обчислюється, коли ми входимо в цикл, і зберігається. Звичайний аргумент обчислюється заново на кожному кроці, що важливо, коли вираз, який передається, містить виклик іншого ітератора:

```sather
   loop
      #OUT + TRAIL::markers!(sizes.elt!);     -- a new count every turn
   end;
```

Позначаймо аргументи `once`, якщо тільки нам не потрібне саме таке повторне обчислення. Уся бібліотека так робить.

## self та ітератори

Ітератор можна викликати на обʼєкті, і тоді `self` є цим обʼєктом. Його призупинений стан належить місцю виклику, а не обʼєкту, тому два цикли, що перебирають один і той самий обʼєкт, не заважають один одному.

## Коли писати ітератор

Пишімо ітератор, коли відповідь є послідовністю, а той, хто викликає, має вирішувати, скільки її взяти. Зупинитися раніше нічого не коштує, і не будується нічого, що не використовується, тоді як підпрограма, яка повертає `ARRAY`, мусить спершу побудувати все ціле.
