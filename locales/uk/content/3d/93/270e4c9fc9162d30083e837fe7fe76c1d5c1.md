# Інструкції

Ми завзятий спостерігач за птахами і відстежуємо, скільки птахів завітало до нашого саду за останні сім днів.

У нас пʼять завдань, і всі вони стосуються кількості птахів, які завітали до нашого саду.

## 1. Перевірмо, якими були підрахунки минулого тижня

Для порівняння ми завжди тримаємо поруч копію підрахунків минулого тижня, а саме: 0, 2, 5, 3, 7, 8 і 4. Реалізуйте метод `BirdCount.last_week`, який повертає підрахунки минулого тижня:

```ruby
BirdCount.last_week
# => [0, 2, 5, 3, 7, 8, 4]
```

## 2. Перевірмо, скільки птахів завітало вчора

Реалізуйте метод `BirdCount#yesterday`, щоб повернути, скільки птахів завітало до нашого саду вчора. Підрахунки птахів упорядковано за днями: першим елементом є кількість птахів найдавнішого дня, а останнім - сьогоднішня кількість.

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.yesterday
# => 4
```

## 3. Обчислімо загальну кількість птахів, які завітали

Реалізуйте метод `BirdCount#total`, щоб повернути загальну кількість птахів, які завітали до нашого саду:

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.total
# => 19
```

## 4. Обчислімо кількість насичених днів

Деякі дні насиченіші за інші. Насиченим вважається день, коли до нашого саду завітало пʼять або більше птахів.
Реалізуйте метод `BirdCount#busy_days`, щоб повернути кількість насичених днів:

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.busy_days
# => 2
```

## 5. Перевірмо, чи був день без птахів

Реалізуйте метод `BirdCount#day_without_birds?`, який повертає `true`, якщо був день, коли до саду не завітав жоден птах; інакше поверніть `false`:

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.day_without_birds?
# => true
```
