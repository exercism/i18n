# Вступ


## Булеві значення

У PowerShell є тип [`bool`][booleans], який представляє булеві значення (англ. Boolean), тобто правду й неправду.
У цьому типі є лише два значення: `True` і `False`.
Ці значення можна привʼязати до змінних за допомогою префікса `$`:

```powershell
> $TrueVar  = $true
> $FalseVar = $FALSE
#Case senstitivity doesn't matter here
```

Щоб поєднувати й обчислювати булеві вирази, можна використовувати [логічні оператори][logical-operators], як-от `-and`, `-or` і `-not`.

```powershell
> $TrueVar  = $true -and $true
> $FalseVar = $true -and $false

> $TrueVar  = $true -or $false
> $FalseVar = $false -or $false

> $TrueVar  = -not $false
> $FalseVar = -not $true
```


## Довідка на основі коментарів

[`Comment-based help`][comment-based help] у PowerShell допомагає надавати докладну інформацію про функції та скрипти, написані в коментарях.
Для цього використовують спеціальні ключові слова довідки, які задають потрібні розділи, наприклад `.SYNOPSIS`, `.EXAMPLE` чи `.NOTES`.

```powershell
function ExampleFunction($Arg) {
    <#
    .DESCRIPTION
    A detailed description of the function or script. This keyword can be used only once in each topic.

    .PARAMETER Arg
    The description of a parameter, it must be follow with the parameter name.
    #>
}
```

Переглянути довідку на основі коментарів можна за допомогою командлета `Get-Help`.

```powershell
> Get-Help -Name "ExampleFunction"
```
