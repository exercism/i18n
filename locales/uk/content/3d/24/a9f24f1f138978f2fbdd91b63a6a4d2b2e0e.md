# Вступ

## Основи

У F# присвоєння значення імені називається _привʼязуванням_. Привʼязування незмінні, що робить їх схожими на константи в інших мовах. Оскільки F# є статично типізованою мовою, кожне привʼязування має тип під час компіляції.

Привʼязування визначаються за допомогою ключового слова `let`. Вказувати тип привʼязування необовʼязково для більшості привʼязувань, оскільки _виведення типів_ F# зазвичай може вивести тип на основі їхніх значень. Привʼязування має такий вигляд:

```fsharp
// Automatically inferred type
let fingers = 10
```

Функції також є звичайними привʼязуваннями, але з одним або кількома параметрами. Функція автоматично повертає свій останній вираз. Виведення типів також працює для більшості функцій: воно аналізує, з якими значеннями викликають функцію і яке значення вона повертає.

```fsharp
// Automatically inferred types for parameters and return type
let add x y = x + y
```

Щоб викликати функцію, потрібно вказати її назву і передати аргументи для кожного з параметрів функції.

```fsharp
let five = add 2 3
```

Якщо тип привʼязування неможливо вивести, компілятор повідомить про помилку. Щоб це виправити, додаймо до привʼязування явну анотацію типу.

```fsharp
// Explicit type annotation
let fingers: int = 10

// Explicit type annotation (also for parameters)
let add (x: int) (y: int): int = x + y
```

Привʼязування у F# можна використовувати лише _після_ того, як їх визначено. Використання привʼязування до його визначення призводить до помилки компіляції.

```fsharp
// Compile error as the add binding has not yet been defined
// let seven = add 3 4

let add x y = x + y
```

F# використовує значущі відступи для визначення області видимості. Це означає, що область видимості визначається відступами в коді, зробленими пробілами відносно рядка, який оголошує привʼязування. Типово прийнято використовувати чотири пробіли для відступу:

```fsharp
let toes =
    let left = 5
    let right = 5
    left + right

let multiplyPlusTwo x y =
    let product = x * y
    product + 2

// Trying to access the left, right or product bindings
// here would result in a compile error
```

Привʼязування F# (які включають функції) зазвичай організовані в модулі. Модуль групує повʼязану функціональність і визначається за допомогою ключового слова `module`. Визначення модуля має передувати його привʼязуванням:

```fsharp
module Calculator

let pi = 3.14

let add x y = x + y
```

F# підтримує два типи коментарів. Однорядкові коментарі починаються з `//`, а багаторядкові вставляються між `(*` і `*)`.
