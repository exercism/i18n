# Навчання

Vim уже має чудову вбудовану документацію. Доступ до неї надає команда `:help`.

Для вступу звернімося до `:h user-manual`.

Майже всі інсталяції Vim також містять інтерактивний туторіал:

```
$ vimtutor
```

Vim існує вже десятки років і досі популярний. В інтернеті можна знайти багато ресурсів про нього, деякі кращі за інші. Хороші з них зібрано [тут](https://exercism.org/docs/tracks/vimscript/resources).
