# Інструкції

Записник детектива наповнюється в міру того, як триває розслідування, і знову порожніє, коли чергову версію відкидають.

Усі пʼять завдань реалізуються в класі `CASE_NOTES`.

## 1. Відкрийте справу

Поверніть новий порожній записник.

```sather
notes ::= CASE_NOTES::new_case;
notes.size
-- => 0
```

## 2. Запишіть зачіпку

Додайте зачіпку в кінець записника. Це нічого не повертає: метод змінює записник, який йому передали.

```sather
CASE_NOTES::add_clue(notes, "muddy boots");
notes.size
-- => 1
```

## 3. Скільки зачіпок?

```sather
CASE_NOTES::clue_count(notes)
-- => 1
```

## 4. Відкиньте одну

Приберіть зачіпку з указаної позиції. Усе, що йшло після неї, зсувається на позицію вище. Це теж нічого не повертає.

```sather
CASE_NOTES::rule_out(notes, 0);
```

## 5. Зачитайте справу

Поверніть усі зачіпки із записника, зʼєднані рядком `"; "`. Порожній записник читається як порожній рядок тексту (англ. string).

```sather
CASE_NOTES::summary(notes)
-- => "muddy boots; broken window"
```
