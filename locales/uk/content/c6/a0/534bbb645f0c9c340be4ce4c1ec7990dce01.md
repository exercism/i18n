# Інструкції

Компанія, у якій ми працюємо, ось-ось випустить свій цілком новий смартфон під назвою **Smarty 5**. У ньому є цілком нова система камер, новий дизайн і революційно новий процесор, що працює на новій операційній системі **smartyOS**.

Новий процесор здатен працювати з безпечнішими паролями, ніж будь-коли раніше, і компанія вирішила скористатися цією перевагою.
Нас попросили реалізувати для телефона систему блокування паролем, яка дозволить користувачеві встановити пароль, а потім перевіряти, чи правильний заданий пароль.

~~~~exercism/caution
Система паролів, яку ми розглядаємо в цій вправі, не є безпечною і використовується лише з освітньою метою.
Її **НЕ** слід застосовувати в жодних реальних застосунках.
~~~~

## 1. Встановити пароль

Телефон дозволяє користувачам використовувати різні типи паролів: від простого цифрового пароля до безпечнішого буквено-цифрового і навіть пароля, який зберігає відбиток пальця.

Ці різні типи паролів використовують різні типи даних: цифровий пароль використовує `Int32`, буквено-цифровий - `String`, а пароль із відбитком пальця - `Float64`.

Реалізуйте клас `PasswordLock` з ініціалізатором, який приймає будь-який із трьох типів паролів як аргумент і зберігає його у змінній екземпляра `@password`.

```crystal
password_lock = PasswordLock.new(1234)
# => #<PasswordLock:0x7f8e1b8c0b80 @password=1234>
```

## 2. Зашифрувати пароль

Компанія вирішила шифрувати пароль, щоб він не зберігався у відкритому вигляді, і попросила нас реалізувати метод для його шифрування.

Кожен тип пароля має власний спосіб шифрування:

- пароль `Int32`: пароль ділиться на два й округлюється до найближчого цілого.
- пароль `String`: пароль записується у зворотному порядку.
- пароль `Float64`: пароль множиться на чотири.

Реалізуйте метод екземпляра `encrypt`, який не приймає аргументів і змінює змінну екземпляра `@password` так, щоб вона була зашифрована.

```crystal
password_lock = PasswordLock.new(1234)
# => #<PasswordLock:0x7f8e1b8c0b80 @password=1234>

password_lock.encrypt
# => #<PasswordLock:0x7f8e1b8c0b80 @password=617>
```

## 3. Перевірити, чи правильний пароль

Компанія також попросила нас реалізувати метод, який перевіряє, чи правильний заданий пароль.

Вони хочуть, щоб метод повертав `nil`, якщо пароль неправильний, і `"Unlocked"`, якщо пароль правильний.

Реалізуйте метод екземпляра `unlock?`, який приймає як аргумент пароль для перевірки.
Метод має повертати `nil`, якщо пароль неправильний, і `"Unlocked"`, якщо пароль правильний.

```crystal
password_lock = PasswordLock.new(1234)
password_lock.encrypt
password_lock.unlock?(1234)
# => "Unlocked"
```
