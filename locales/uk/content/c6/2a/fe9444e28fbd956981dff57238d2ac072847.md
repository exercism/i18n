# Вступ

## Методи розширення

Методи розширення дозволяють додавати методи до наявних типів, не створюючи новий похідний тип, не перекомпільовуючи код і не змінюючи в інший спосіб початковий тип. Їх визначають як статичні методи, але викликають за допомогою синтаксису методів екземпляра. Перед їхнім першим параметром ставлять модифікатор `this`, який указує, з яким типом працює метод, а самі методи додаються до області видимості на рівні простору імен.

```csharp
public static int WordCount(this string str)
{
    return str.Split().Length;
}

"Hello World".WordCount();
// => 2
```
