# Типи рядків тексту

У Cairo немає вбудованого типу даних для рядків тексту (англ. string).
Однак є два способи представити рядок тексту: короткі рядки тексту за допомогою одного `felt252` та рядки тексту довільної довжини за допомогою `ByteArray`.

## Короткі рядки тексту

Короткий рядок тексту утворюється в одинарних лапках, де кожен символ, з якого складається рядок, кодується одним байтом згідно зі [стандартом ASCII][ascii-table].

Як рядок тексту ASCII, наприклад, `'abc'` буде:

- `'a'` відповідає `0x61`
- `'b'` відповідає `0x62`
- `'c'` відповідає `0x63`
- `'abc'` відповідає `0x616263`

Тип даних `felt252` у Cairo зберігає короткий рядок тексту.
Оскільки `felt252` містить 251 біт, короткий рядок тексту обмежений 31 символом (31 \* 8 = 248 біт, що є максимальним кратним 8, яке вміщується в 251 біт).

Приклади оголошення коротких рядків тексту:

```rust
    let my_first_char = 'D';
    let my_first_char_in_hex = 0x44;

    let my_first_string = 'Hello world';
    let my_first_string_in_hex = 0x48656C6C6F20776F726C64;
```

### ByteArray

Структуру `ByteArray` було представлено в Cairo 2.4.0.
Рядки тексту `ByteArray` записуються в подвійних лапках так:

```rust
    let long_string: ByteArray = "this is a string which has more than 31 characters";
```

Технічно те саме оновлення представило тип `bytes31`, який містить 31 байт і вміщується у felt.
Структура `ByteArray` по суті представляє довгий рядок тексту за допомогою масиву `bytes31`, які містять «цілі слова» (тобто слова, що заповнюють увесь felt), й одного поля felt, яке містить «неповне слово» (кількість байтів у ньому вказано в окремому полі довжини).

```rust
#[derive(Drop, Clone, PartialEq, Serde, Default)]
struct ByteArray {
    data: Array<bytes31>,
    pending_word: felt252,
    pending_word_len: usize,
}
```
