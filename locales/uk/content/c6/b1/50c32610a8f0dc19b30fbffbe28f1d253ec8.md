# Вступ

У JavaScript _шаблонні рядки_ дають змогу вбудовувати вирази в рядки тексту (англ. string); це ще називають інтерполяцією рядків.
Ця функціональність розширює можливості вбудованого глобального обʼєкта [`String`][string-reference].

Ми можемо створювати шаблонні рядки в JavaScript, узявши текст у зворотні лапки.
Вони дозволяють не лише додавати в текст нові рядки та інші спеціальні символи, а й вбудовувати змінні та інші вирази.

```javascript
const num1 = 1;
const num2 = 2;

`Adding ${num1} and ${num2} gives ${num1 + num2}.`;
// => Adding 1 and 2 gives 3.
```

У наведеному вище прикладі зворотні лапки (<code>\`\`</code>) позначають шаблонний рядок. `${...}` - це заповнювач, який використовують для підстановки.
Будь-які типи, що не є рядками тексту, _неявно_ перетворюються на рядки тексту.
Цю тему розглянуто в концепції [перетворення типів][type-conversion-concept].
З шаблонними рядками можна використовувати всі типи виразів.

```javascript
const track = 'JavaScript';

`This track on exercism.org is ${track.toUpperCase()}.`;
// => This track on exercism.org is JAVASCRIPT.
```

Коли нам потрібно, щоб рядок тексту був розбитий на кілька рядків:

```javascript
`This is an example of using template
strings to accomplish multiple
lines`;
```

Завдяки наявним можливостям підстановки ми можемо також додати в цей процес логіку, щоб визначити, яким має бути вихідний рядок тексту.

Приклад цього - вбудовування [тернарного оператора][ternary-operator].
Цей оператор - коротка форма запису інструкції `if/else`.
Синтаксис такий: `condition ? consequent-expression : alternative-expression`.
Якщо умова правдива, повертається операнд ліворуч від двокрапки.
Інакше результатом тернарного виразу буде операнд праворуч від двокрапки.

```javascript
const grade = 95;

`You have ${grade > 90 ? 'passed' : 'failed'} the exam.`;
// => You have passed the exam.
```
