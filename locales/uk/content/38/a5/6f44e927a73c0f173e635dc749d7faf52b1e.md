# Вступ

## Помилки

Помилки корисно повідомляти, коли в програмі або фрагменті коду щось іде не так або стається несподіване.

Це обʼєкти JavaScript.

Головна властивість цього обʼєкта - `message`:

```javascript
const error = new Error('Oops, something went wrong');

console.log(error.message);
// => "Oops, something went wrong"
```

За допомогою синтаксису `throw` можна викинути помилку.

```javascript
throw new Error('Oops');
```

Коли помилку викинуто, поточне виконання зупиняється й відновлюється в першому блоці catch стека викликів.

```javascript
try {
  throw new Error('Oops');
} catch (error) {
  console.log(error.message);
  // => "Oops"
}
```

## Наслідування

Наслідування - це спосіб створювати звʼязки «батько-дитина» між класами.
Дочірній клас (його іноді називають _підкласом_) має доступ до поведінки та даних, визначених батьківським класом (його іноді називають _надкласом_).

```javascript
class Pet {
  constructor(name) {
    this.name = name;
  }

  introduce() {
    console.log(`This is my pet, ${this.name}.`);
  }
}

class Dog extends Pet {}

const dog = new Dog('Otis');
dog.introduce();
// => This is my pet, Otis.
```

Ключове слово `extends` в оголошенні дочірнього класу встановлює звʼязок із батьківським класом через [ланцюжок прототипів][prototype-chain].

Обʼєкти, створені конструктором дочірнього класу, матимуть прототип батьківського класу у своєму ланцюжку прототипів, що дає доступ до будь-яких методів чи даних, визначених батьком.

```javascript
const dog = new Dog('Otis');

Dog.prototype.isPrototypeOf(dog); // => true
Pet.prototype.isPrototypeOf(dog); // => true
Pet.prototype.isPrototypeOf(Dog.prototype); // => true

Pet.prototype.hasOwnProperty('introduce'); // => true
Dog.prototype.hasOwnProperty('introduce'); // => false
dog.hasOwnProperty('introduce'); // => false
```

Як і будь-який клас у JavaScript, підкласи можуть успадковуватися від `Error`, щоб створювати власні помилки за допомогою ключового слова `extends`.
Синтаксис `instanceof` перевіряє, чи є спіймана помилка екземпляром конкретного підкласу `Error`.

```javascript
class CustomError extends Error {}

try {
  // ... Code that may throw an error
} catch (error) {
  if (error instanceof CustomError) {
    console.log('The error thrown is an instance of the CustomError');
  }
}
```

[prototype-chain]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Inheritance_and_the_prototype_chain
