# Докладніше

Swift надає вбудований тип під назвою [`Bool`][bools], який представляє булеві значення (англ. Boolean): `true` та `false`.

## Логічні оператори

Swift надає три [логічні оператори][logical-operators] (`!`, `&&` і `||`) для поєднання й обчислення булевих виразів.

### Логічне і (`&&`)

Оператор [_і_][and] у Swift позначається `&&` (логічне і) і повертає `true`, лише якщо обидва операнди дорівнюють `true`.
Якщо хоч один операнд дорівнює `false`, оператор повертає `false`.
З кожного боку від символу `&&` ставимо вираз або булеве значення:

```swift
true && true  // true
true && false // false
```

### Логічне або (`||`)

Оператор [_або_][or] у Swift позначається `||` (логічне або) і повертає `true`, якщо **принаймні один** з операндів дорівнює `true`.
Він повертає `false`, лише коли обидва операнди дорівнюють `false`.
З кожного боку від символу `||` ставимо вираз або булеве значення:

```swift
true || true   // true
true || false  // true
false || false // false
```

### Логічне заперечення (`!`)

Оператор [_заперечення_][not] (`!`) інвертує булеве значення.
Він повертає `true`, якщо значення дорівнює `false`, і `false`, якщо значення дорівнює `true`.
Оператор `!` ставимо безпосередньо перед значенням або виразом:

```swift
!true  // false
!false // true
```

## Використання дужок (`()`)

Ми можемо використати [дужки][explicit-parentheses], щоб згрупувати вирази й керувати порядком обчислення.
У Swift спершу обчислюються вирази всередині дужок:

```swift
true && false && false || true   // true
true && false && (false || true) // false
```

Групування за допомогою дужок також визначає, як оператор заперечення застосовується до складних виразів:

```swift
!true && false   // false (evaluates (!true) first, then false && false)
!(true && false) // true  (evaluates (true && false) first to false, then !false)
```

~~~~exercism/note
Використовуймо дужки, коли потрібно уточнити порядок обчислення або зробити складні умови зрозумілішими.
Не додаваймо зайвих дужок, коли звичний порядок обчислення вже очевидний.
~~~~
