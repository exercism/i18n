# Інструкції

У цій вправі ми змоделюємо зважувальну машину, у якій одиницею вимірювання є кілограми.

На нас чекає 6 завдань, кожне з яких вимагає реалізувати одну або кілька властивостей:

## 1. Дозвольте зважувальній машині мати точність

Щоб задовольнити різні потреби, кожну зважувальну машину можна налаштувати з точністю (кількість цифр після десяткового розділювача).
Реалізуйте клас `WeighingMachine` так, щоб у нього була властивість `Precision` лише для читання, значення якої дорівнює аргументу `precision` конструктора:

```csharp
var wm = new WeighingMachine(precision: 3);

//  => wm.Precision == 3
```

## 2. Дозвольте задавати вагу зважувальній машині

Реалізуйте властивість `WeighingMachine.Weight` так, щоб вагу можна було і читати, _і_ задавати:

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = 60.5;

//  => wm.Weight == 60.5
```

## 3. Переконайтеся, що відʼємну вхідну вагу відхилено

Очевидно, що вага не може бути відʼємною.
Додайте перевірку до властивості `WeighingMachine.Weight`, щоб під час спроби задати відʼємну вагу вона викидала `ArgumentOutOfRangeException`:

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = -10; // Throws an ArgumentOutOfRangeException
```

## 4. Дозвольте застосовувати коригування тари до зважувальної машини

Коригування тари може бути будь-яким значенням (навіть відʼємним або таким, що робить показану вагу відʼємною)
Реалізуйте властивість `WeighingMachine.TareAdjustment`, щоб коригування тари можна було задавати:

```csharp
var wm = new WeighingMachine(precision: 3);
wm.TareAdjustment = -10.6;

// => wm.TareAdjustment == -10.6
```

## 5. Переконайтеся, що зважувальна машина має типове коригування тари

Після ретельних тестувань зʼясувалося, що через виробничу проблему всі зважувальні машини схильні завищувати вагу на `5`.
Змініть властивість `WeighingMachine.TareAdjustment` так, щоб її типовим значенням було `5`.

```csharp
var wm = new WeighingMachine(precision: 3);

// => wm.TareAdjustment == 5.0
```

## 6. Дозвольте отримувати вагу

Реалізуйте властивість `WeighingMachine.DisplayWeight`, яка має повертати рядок тексту (англ. string) із вагою після коригування тари, із застосованою правильною точністю та доданою одиницею вимірювання.
Зауважте, що:
``` display-weight = input-weight - tare-adjustment ```

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = 60.567;
wm.TareAdjustment = 10;

// => wm.DisplayWeight == "50.567 kg"
```
