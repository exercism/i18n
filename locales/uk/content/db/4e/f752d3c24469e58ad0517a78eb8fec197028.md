# Вступ

## Псевдоніми типів

### Псевдоніми типів

Псевдонім типу в Gleam дає зручну назву для наявного типу, який інакше було б громіздко писати.

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

Якщо написати `pub type`, псевдонім можна використовувати поза модулем, у якому його визначено. Якщо `pub` пропущено, псевдонім є приватним, і на нього не можна посилатися в інших модулях.

## Словники

Словники в Gleam - це структура даних для зберігання інформації у вигляді пар ключ-значення. В інших мовах їх також можуть називати асоціативними масивами, хешами або словниками.

Для ключів і значень у словнику можна використовувати будь-який тип, і словники не гарантують порядку своїх записів, коли до них звертаються або їх повертають.

### Робота зі словниками

Словники створюють і обробляють за допомогою функцій з модуля `gleam/dict`.

```gleam
// Create an empty dict
let dict1 = dict.new()

// Create a dict with some values
let dict2 = dict.from_list([
  #("name", "Gleam"),
  #("colour", "Pink"),
])

// Add a value to a dict
let dict3 = dict.insert(dict2, "website", "https://gleam.run")

// Get a value from a dict
let name = dict.get(dict3, "name")
// -> Ok("Gleam")
```
