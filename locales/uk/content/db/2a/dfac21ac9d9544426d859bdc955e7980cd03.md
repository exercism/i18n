# Інструкції

Джош працює над новою рольовою грою, і йому потрібна наша допомога з реалізацією деяких механік.

## 1. Представтеся

Реалізуйте функцію `introduce`.

Гравці, які ховаються, можуть приховувати своє імʼя, і тоді їх представляють як `"Mighty Magician"`.
Інакше просто використайте імʼя гравця, щоб його представити.

```gleam
introduce(Player(name: None, level: 2, health: 8, mana: None))
// -> "Mighty Magician"

introduce(Player(name: Some("Merlin"), level: 2, health: 8, mana: None))
// -> "Merlin"
```

## 2. Реалізуйте механіку відродження

Функція `revive` має перевіряти, що персонаж гравця справді мертвий (його здоровʼя сягнуло 0).
Якщо так, вона має повернути новий екземпляр `Player` зі здоровʼям 100.
Інакше, якщо персонаж гравця не мертвий, функція `revive` повертає `None`.

Якщо рівень гравця 10 або вищий, його також треба відродити зі 100 одиницями мани.
Якщо рівень гравця нижчий за 10, його мана має залишитися незмінною.
Функція `revive` має зберегти рівень гравця.

```gleam
let dead_player = Player(name: None, level: 2, health: 0, mana: None)

revive(dead_player)
// -> Some(Player(name: None, level: 2, health: 100, mana: None))
```

Якщо метод `revive` викликати для гравця, здоровʼя якого 1 або більше, функція має повернути `None`.

```gleam
let alive_player = Player(name: None, level: 2, health: 42, mana: None)

revive(alive_player)
// -> None
```

## 3. Реалізуйте механіку чаклування

Функція `cast_spell` приймає як аргументи `Int`, що вказує, скільки мани коштує закляття, а також `Player`.
Вона повертає оновленого гравця, а також обсяг шкоди, якої завдає застосоване закляття.
Успішне застосування закляття завдає шкоди, що вдвічі перевищує витрачену на нього ману.
Однак, якщо гравцеві бракує мани, нічого не відбувається: гравець залишається незмінним, і шкоди не завдано.
Якщо в гравця взагалі немає запасу мани, спроба застосувати закляття має зменшити його здоровʼя на вартість закляття в мани й не завдає жодної шкоди.
Майте на увазі, що здоровʼя гравця не може бути меншим за нуль (0).

```gleam
let wizard = Player(name: None, level: 18, health: 123, mana: Some(30))
let #(wizard, damage) = cast_spell(wizard, 14)

wizard.mana // -> Some 16
damage      // -> 28
```
