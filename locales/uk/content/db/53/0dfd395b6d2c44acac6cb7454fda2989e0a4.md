# Докладніше

[Бітові рядки][bitstring] дають програмістам змогу ефективно працювати з бінарними даними.

- Можна елегантно створювати бітові рядки за допомогою [спеціальної форми `<<>>`][bitstring-form].

  ```elixir
  <<0b101::3>> == <<5::3>> and <<5::3>> == <<5::size(3)>>
  # => true

  first = <<0b110::3>>
  second = <<0b001::3>>
  combined = <<first::bitstring, second::bitstring>>
  # => <<49::size(6)>>
  ```

- Можна зіставляти за допомогою форми `<<>>` і скористатися цим зіставленням, щоб [розкласти бінарні дані][bitstring-matching] на частини.

  ```elixir
  <<data_size::32, count::size(data_size)>> = <<8::32, 3::8>>
  # => <<0, 0, 0, 8, 3>>
  data_size
  # => 8
  count
  # => 3
  ```

- Можна зіставити решту бітового рядка за допомогою `::bitstring`.

  ```elixir
  <<_::32, remainder::bitstring>> = <<8::32, 3::8>>
  # => <<0, 0, 0, 8, 3>>
  remainder
  # => <<3>>
  ```

- Бінарний *тип* даних - це окремий тип бітового рядка, у якому кількість бітів кратна 8.
  - Усі бінарні дані є бітовими рядками, але не всі бітові рядки є бінарними даними.
- Elixir надає синтаксичний цукор для роботи з [літералами цілих чисел][integer-literal] у різних формах:
  - `0b1000001 = ?A = 65`
