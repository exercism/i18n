# Додаток до інструкцій

## Слова

Визначте кортеж `stopwatch` і конструктор `<stopwatch> ( -- stopwatch )`, який повертає новий секундомір у стані `"ready"` без витраченого часу й без попередніх кіл.

Надайте такі слова, які працюють із секундоміром:

- `state ( stopwatch -- str )` - `"ready"`, `"running"` або `"stopped"`.
- `current-lap ( stopwatch -- str )` - витрачений час поточного кола як рядок `"HH:MM:SS"`.
- `total ( stopwatch -- str )` - сумарний витрачений час поточного кола й усіх попередніх кіл як рядок `"HH:MM:SS"`.
- `previous-laps ( stopwatch -- seq )` - масив раніше записаних кіл, кожне як рядок `"HH:MM:SS"`.
- `start ( stopwatch -- )`, `stop ( stopwatch -- )`, `reset ( stopwatch -- )` і `lap ( stopwatch -- )` - чотири команди з таблиці вище. Виклик одного з них зі стану, який його не дозволяє, має призводити до `throw` помилки.

Час просуваємо так:

- `advance-time ( str stopwatch -- )` - додає тривалість `"HH:MM:SS"` до поточного кола. Це діє лише тоді, коли секундомір запущено.
