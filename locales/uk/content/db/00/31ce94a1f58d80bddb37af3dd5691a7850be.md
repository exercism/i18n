# Вступ

Булеві значення (англ. Boolean) у Rust представлені типом `bool`, значеннями якого можуть бути `true` або `false`.

Rust підтримує шість операторів порівняння: `==` (дорівнює), `!=` (не дорівнює), `>` (більше), `<` (менше), `>=` (більше або дорівнює), `<=` (менше або дорівнює). Їх можна використовувати, щоб обчислити відношення між небулевими значеннями й отримати булеве значення.

```rust
1 > 0 // true
1 < 0 // false
1 == 0 // false
1 != 0 // true
1 >= 0 // true
1 <= 0 // false
```

На відміну від деяких інших мов, `0` не є `false`, а ненульове значення не є `true`.

Rust підтримує два логічні оператори: `||` (логічне або), `&&` (логічне і). Вони обчислюються лише тоді, коли лівий операнд ще не визначає результат виразу. Тобто `||` обчислює свій правий операнд лише тоді, коли лівий операнд має значення `false`, а `&&` обчислює його лише тоді, коли лівий операнд має значення `true`.
