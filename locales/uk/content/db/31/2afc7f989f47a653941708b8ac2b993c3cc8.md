# Інструкції

У цій вправі нам доручено написати програмне забезпечення для пристрою шифрування, який виконує перетворення над даними. Нам потрібен спосіб гнучко створювати складні функції, поєднуючи простіші функції.

Для кожного завдання поверніть анонімну функцію, яку можна викликати з області видимості виклику.

Усі функції мають приймати цілі числа як аргументи. Цілі числа також підходять для виконання побітових операцій в Elixir.

## 1. Створіть функцію додавання

Реалізуйте `Secrets.secret_add/1`. Вона має повернути функцію, яка приймає один аргумент і додає до нього аргумент, переданий у `secret_add`.

```elixir
adder = Secrets.secret_add(3)
adder.(2)
# => 5
```

## 2. Створіть функцію віднімання

Реалізуйте `Secrets.secret_subtract/1`. Вона має повернути функцію, яка приймає один аргумент і віднімає від цього аргументу секрет, переданий у `secret_subtract`.

```elixir
subtractor = Secrets.secret_subtract(2)
subtractor.(3)
# => 1
```

## 3. Створіть функцію множення

Реалізуйте `Secrets.secret_multiply/1`. Вона має повернути функцію, яка приймає один аргумент і множить його на секрет, переданий у `secret_multiply`.

```elixir
multiplier = Secrets.secret_multiply(7)
multiplier.(3)
# => 21
```

## 4. Створіть функцію ділення

Реалізуйте `Secrets.secret_divide/1`. Вона має повернути функцію, яка приймає один аргумент і ділить його на секрет, переданий у `secret_divide`.

```elixir
divider = Secrets.secret_divide(3)
divider.(32)
# => 10
```

Використайте цілочисельне ділення, щоб результат був сумісний із вхідними даними, які приймають інші функції.

## 5. Створіть функцію «and»

Реалізуйте `Secrets.secret_and/1`. Вона має повернути функцію, яка приймає один аргумент і виконує побітову операцію _and_ над ним і секретом, переданим у `secret_and`.

```elixir
ander = Secrets.secret_and(1)
ander.(2)
# => 0
```

## 6. Створіть функцію «xor»

Реалізуйте `Secrets.secret_xor/1`. Вона має повернути функцію, яка приймає один аргумент і виконує побітову операцію _xor_ над ним і секретом, переданим у `secret_xor`.

```elixir
xorer = Secrets.secret_xor(1)
xorer.(3)
# => 2
```

## 7. Створіть комбінатор функцій

Реалізуйте `Secrets.secret_combine/2`. Вона має повернути функцію, яка приймає один аргумент і застосовує до нього дві функції, передані в `secret_combine`, у вказаному порядку.

```elixir
add_one = Secrets.secret_add(1)
multiply_by_2 = Secrets.secret_multiply(2)
combined = Secrets.secret_combine(add_one, multiply_by_2)

combined.(3)
# => 8
```
