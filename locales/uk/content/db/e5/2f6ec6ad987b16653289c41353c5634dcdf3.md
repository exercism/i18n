# Підказки

## 1. Представтеся

Функція `introduce` повинна «розгорнути» значення, що міститься в `player.Name`.
Спробуйте використати функцію [`Options.defaultValue`][defaultvalue], щоб перетворити `player.Name` на його «загорнуте» значення, коли воно `Some`, або на потрібне типове значення, коли воно `None`.

## 2. Реалізуйте механіку відродження

Функція `revive` повинна повернути або `Some <player>`, або `None`, де `<player>` - це запис `Player`, можливо, з деякими зміненими полями.

## 3. Реалізуйте механіку чаклування

Спробуйте використати вираз зіставлення, щоб охопити обидва випадки: `Some` і `None`, як у наступному прикладі:

```fsharp
let exists (x: int option) =
    match x with
    | Some n -> true
    | None -> false
```
