# Вступ

## Масиви

Основна бібліотека Cairo реалізує тип `Array`.

Він схожий на звичайні типи масивів в інших мовах програмування, але має кілька ключових відмінностей:

- Елементи можна ефективно додавати лише в кінець типу `Array`, а ефективно видаляти лише з початку.
- Неможливо вручну встановити елемент за індексом масиву.

Масиви можна створювати за допомогою функції `ArrayTrait::new`, а також макросу `array!`:

```rust
let empty: Array<u32> = ArrayTrait::new();
let one_to_four = array![1, 2, 3, 4];
```

Елементи можна додавати до масиву за допомогою функції `ArrayTrait::append`:

```rust
let mut num_array = array![1, 2, 3, 4];
num_array.append(5);
// -> [1, 2, 3, 4, 5]
```

Елементи можна видаляти з масиву за допомогою функції `ArrayTrait::pop_front`:

```rust
let mut one_to_four = array![1, 2, 3, 4];

one_to_four.pop_front();
// -> [2, 3, 4]
```

Крім того, Cairo вводить тип `Span`, який поводиться як «знімок» `Array`.

Кожен `Array` можна перетворити на `Span` за допомогою функції `ToSpanTrait::span`:

```rust
let one_to_four = array![1, 2, 3, 4];
let one_to_four_span = one_to_four.span();
// -> [1, 2, 3, 4]
```

Перетворення масиву на `Span` дуже ефективне, адже `Span` - це просто структура даних, яка дозволяє Cairo «переглядати» частину масиву й жодним чином його не змінює.

Перетворивши масив на `Span`, Cairo дозволяє виконувати більше операцій, ніж було б дозволено безпосередньо над `Array`, наприклад видаляти елемент з початку `Span`:

```rust
let one_to_four = array![1, 2, 3, 4];
let mut one_to_four_span = one_to_four.span();
one_to_four_span.pop_back();
// -> [2, 3, 4]
```

Варто зауважити, що нам довелося зробити `one_to_four_span` змінним за допомогою ключового слова `mut`, щоб викликати `pop_back`, який змінює `Span`, скорочуючи ту частину масиву, яку `Span` «переглядає».
