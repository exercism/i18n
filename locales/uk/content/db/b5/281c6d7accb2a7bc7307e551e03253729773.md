# Тести

Тести можна запускати кількома способами.

## Інтерактивно в Emacs

1. Відкрийте файл тестів, `M-x eval-buffer RET`
2. Інтерактивно й по одному, за допомогою `M-x ert RET test-name RET`
3. Інтерактивно й одразу всі, за допомогою `M-x ert RET t RET`
   Зауважте, що це запустить усі тести, наразі завантажені в Emacs!
4. Перезапускайте `M-x eval-buffer RET` перед тестуванням, коли вносите зміни

Щоб виконувати тести лише в поточному буфері, можна додати це до `.emacs` або `init.el`:

```elisp
(defun my-eval-and-run-all-tests-in-buffer ()
  "Deletes all loaded tests from the runtime, evaluates the current buffer and runs all loaded tests with ert."
  (interactive)
  (ert-delete-all-tests)
  (eval-buffer)
  (ert 't))
```

Після перезапуску Emacs:

1. Відкрийте файл тестів
2. `M-x my-eval-and-run-all-tests-in-buffer RET`

## З термінала

Щоб запустити всі тести з термінала в пакетному режимі, виконайте `emacs -batch -l ert -l *-test.el -f ert-run-tests-batch-and-exit`

Наведена команда трохи громіздка, тож якщо бажаєте:

1. Створіть файл у `$PATH` (імовірно, у `~/bin`) із назвою `ert-run`
2. Вміст файлу має бути таким:
   ```sh
   #!/usr/bin/env sh
   emacs -batch -l ert -l $1 -f ert-run-tests-batch-and-exit
   ```
3. Зробіть файл виконуваним за допомогою `chmod +x ert-run`

Тепер можна просто викликати `ert-run *-test.el` і запустити тести
в пакетному режимі.

## Інші варіанти

Інші варіанти можна знайти в документації, `C-h i m ert RET`.
