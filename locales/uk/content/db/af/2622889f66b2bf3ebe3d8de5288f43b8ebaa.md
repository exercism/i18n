# Instructions

Нас знову заманили до Гіперії (з її високою інфляцією) запаморочливою денною ставкою.

Центральний банк розглядає запровадження долара США як другої валюти, тож усі бухгалтерські системи доведеться адаптувати до роботи з кількома валютами.

Нас попросили реалізувати обʼєкт суми в валюті.

## 1. Зробіть так, щоб суму в валюті можна було перевіряти на рівність

Змініть структуру `CurrencyAmount`, щоб вона підтримувала перевірку на рівність. Якщо дві структури суми в валюті мають різні валюти («USD» або «HD»), то слід викинути екземпляр `ArgumentException`.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
CurrencyAmount amountB = new CurrencyAmount(55, "HD");
CurrencyAmount amountC = new CurrencyAmount(55, "USD");
amountA == amountB
// => true
amountA != amountB
// => false
amountA == amountC
// => ArgumentException
amountA != amountC
// => ArgumentException
```

## 2. Порівняйте суми в валюті

Змініть структуру `CurrencyAmount`, щоб вона підтримувала порівняння (лише `>` і `<`). Якщо дві структури суми в валюті мають різні валюти («USD» або «HD»), то слід викинути екземпляр `ArgumentException`.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
amountA > new CurrencyAmount(50, "HD")
// => true
amountA < new CurrencyAmount(50, "HD")
// => false
amountA > new CurrencyAmount(50, "USD")
// => ArgumentException
```

## 3. Додайте і відніміть суми в валюті

Змініть структуру `CurrencyAmount`, щоб вона підтримувала арифметичне додавання і віднімання (лише `+` і `-`). Якщо дві структури суми в валюті мають різні валюти («USD» або «HD»), то слід викинути екземпляр `ArgumentException`.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
CurrencyAmount amountB = new CurrencyAmount(100, "HD");
CurrencyAmount amountC = new CurrencyAmount(55, "USD");
amountA + amountB
// => {155, HD}
amountB - amountA
// => {45, HD}
amountA + amountC
// => ArgumentException
```

## 4. Помножте і поділіть суми в валюті

Змініть структуру `CurrencyAmount`, щоб вона підтримувала арифметичне множення і ділення (лише `*` і `/`).

```csharp
CurrencyAmount amountA = new CurrencyAmount(10, "HD");
amountA * 2m
// => {20, HD}
amountA / 2m
// => {5, HD}
```

## 5. Перетворіть суму в валюті на double

Змініть структуру `CurrencyAmount` так, щоб екземпляр можна було явно привести до типу `double`.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55.5m, "HD");
(double)amountA
// => 55.5d
```

## 6. Перетворіть суму в валюті на decimal

Змініть структуру `CurrencyAmount` так, щоб екземпляр можна було неявно перетворити на тип `decimal`.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55.5m, "HD");
decimal d = amountA;
// => d == 55.5m
```
