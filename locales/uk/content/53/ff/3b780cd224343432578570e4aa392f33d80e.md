# Докладніше

Як і більшість мов програмування, Gleam має «побічні ефекти», тож функції можуть читати й змінювати стан світу, а також повертати значення.

Модуль `gleam/io` зі стандартної бібліотеки Gleam надає функції для виведення рядків тексту (англ. string) у консоль.

```gleam
io.println("Hello, Joe!")
// Hello, Joe!
// -> Nil
```

Інші пакети можуть надавати інші функції вводу-виводу, як-от `simplifile`, пакет, який надає функції для читання та запису файлів.

```gleam
simplifile.read("favourite-colour.txt")
// -> Ok("Pink\n")
```
