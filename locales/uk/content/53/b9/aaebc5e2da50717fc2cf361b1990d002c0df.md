# Встановлення

## Встановлення .NET 10

Трек Visual Basic використовує .NET 10.
Щоб збирати й тестувати вправи локально, встановіть [SDK .NET 10 для відповідної операційної системи][install-sdk]:
встановіть саме SDK, а не лише середовище виконання.

## Перевірка встановлення

Відкрийте новий термінал і виконайте:

```bash
dotnet --version
```

Команда має вивести `10.0.0` або новішу версію.

## Підтримка редакторів

Щоб виконати вправи, достатньо .NET SDK і простого текстового редактора.
Якщо потрібні додаткові можливості, як-от автодоповнення коду та зневадження, зверніть увагу на один із цих редакторів:

- [Visual Studio 2026][visual-studio] у Windows
- [Visual Studio Code][visual-studio-code] у Windows, Linux або macOS
- [JetBrains Rider][rider] у Windows, Linux або macOS

[install-sdk]: https://learn.microsoft.com/en-us/dotnet/core/install
[rider]: https://www.jetbrains.com/rider/
[visual-studio]: https://visualstudio.microsoft.com/downloads/
