# Рядки тексту

Рядок тексту (англ. string) - це послідовність символів, узята в лапки.
Підтримуються і одинарні, і подвійні лапки.

```php
<?php

$where = "Spain";
$what = 'rain';
```

## Інтерполяція змінних у рядках тексту

У рядках тексту в подвійних лапках, якщо змінна перебуває в області видимості, її значення підставляється в рядок.

```php
<?php

$answer = 42;
$expanded = "The answer to life, the universe, and everything is $answer"; 
```

## Підтримка кодування символів

Історично функції для роботи з рядками тексту в PHP підтримували лише символи ASCII і не підтримували сучасні кодування Unicode.
Кожен символ ASCII займає 1 байт, тоді як символи Unicode можуть мати довжину від 1 до 4 байтів.
Якщо потрібно безпечно працювати з рядками тексту Unicode, зверніться до [багатобайтових версій][multi-byte-fns] цих історичних функцій.

```php
<?php

$byte_length = strlen('😃'); // => 4
$string_length = mb_strlen('😃'); // => 1
```

[multi-byte-fns]: https://www.php.net/manual/en/ref.mbstring.php
