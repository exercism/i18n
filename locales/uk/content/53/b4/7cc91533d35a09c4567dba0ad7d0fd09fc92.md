# Діапазони

[Діапазони][range] представляють проміжок між двома значеннями.
Найпоширеніші типи, які підтримують діапазони, це `Integer` і `String`.
Їх можна використовувати для багатьох речей, як-от швидке створення колекції, нарізання рядків тексту (англ. string), перевірка, чи значення належить діапазону, та ітерація.
Їх створюють за допомогою оператора діапазону `..` або `...` (включно та виключно відповідно).

```ruby
1..5  # => 1..5
1...5 # => 1...5

(1..5).to_a # => [1, 2, 3, 4, 5]
(1...5).to_a # => [1, 2, 3, 4]
```

Причина наявності двох операторів діапазону - це можливість створювати діапазони, які включають або не включають кінцеве значення, що може бути корисним, наприклад, під час роботи з індексами, які починаються з нуля.

Діапазони також можна створювати за допомогою ініціалізатора `Range`.

```ruby
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
Коли ми створюємо діапазон у Ruby за допомогою операторів діапазону `..` або `...` і хочемо викликати метод на діапазоні, потрібно взяти діапазон у дужки.
Інакше метод буде викликано на 2-му аргументі оператора діапазону.

```ruby
(1..5).sum # => 15
1..5.sum # => Error: undefined method `sum' for 5:Integer (NoMethodError)
```
~~~~

## Отримання підрядків

Коли ми хочемо нарізати рядок тексту, можна використати оператор діапазону, щоб отримати підрядок.
Тобто створити діапазон із початковим і кінцевим індексом підрядка.

```ruby
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

Також можна використовувати відʼємні індекси, щоб отримати підрядок із кінця рядка тексту.

```ruby
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## Методи діапазону

Діапазони справді мають набір методів, які можна використовувати для роботи з ними.
Наприклад, ці методи можна використовувати, щоб отримати суму всіх значень у діапазоні або перевірити, чи діапазон містить значення.

| Метод                  | Опис                                                             | Приклад                         |
| ----------------------- | ----------------------------------------------------------------------- | ------------------------------- |
| [`sum`][sum]            | Повертає суму всіх значень у діапазоні                          | `(1..5).sum # => 15`            |
| [`size`][size]          | Повертає розмір діапазону                                           | `(1..5).size # => 5`            |
| [`include?`][indlude]   | Повертає `true`, якщо діапазон містить задане значення, інакше `false` | `(1..5).include?(3) # => true` |

## Нескінченні та безпочаткові діапазони

Діапазон може бути нескінченним і безпочатковим.
У нескінченного або безпочаткового діапазону початкове чи кінцеве значення дорівнює `nil`, але під час визначення діапазону `nil` можна опустити.

Використання безпочаткових і нескінченних діапазонів корисне, коли ми хочемо, наприклад, нарізати рядок тексту від початку або до кінця.

```ruby
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
Якщо не використовувати нескінченний діапазон на колекції, він може спричинити нескінченну послідовність, якщо не бути обережним.
~~~~

## Діапазони рядків тексту

Рядки тексту також можна використовувати в діапазонах, і вони дають змогу отримати проміжок рядків тексту між двома рядками тексту.
Поведінка таких діапазонів може бути трохи несподіваною під час використання певних рядків тексту, тож використовуймо їх обережно.

```ruby
"aa".."az".to_a # => ["aa", "ab", "ac", ..., "az"]
```
