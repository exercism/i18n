# Тести

Щоб перевірити рішення, просто виконайте:

```bash
make test
```

Це запустить файл тестів `<exercise-name>-test.ys`, який містить усі тести, які потрібно пройти, щоб рішення вважалося правильним.
Вивчіть файл тестів, щоб точно зрозуміти, що саме має робити рішення.

> Примітка: коли `make test` запускається вперше, він також подбає про те, щоб правильна версія інтерпретатора YAMLScript `ys` була встановлена в потрібному місці.

Якщо запустити `make test`, не змінивши жодного файлу, усі тести проваляться.
Це правильна й очікувана поведінка.
Звичайний процес роботи над вправою полягає в тому, щоб поступово вдосконалювати рішення, запускаючи `make test` після кожної зміни, доки всі тести не пройдуть.

Якщо потрібно запустити лише конкретний тест (зосередившись на відповідній частині рішення), додайте до цього тесту таку пару ключ-значення:

```yaml
  ONLY: true
```

Якщо потрібно пропустити окремі тести (працюючи над іншими частинами рішення), додайте до них таку пару ключ-значення:

```yaml
  SKIP: true
```


## Передумови для тестування

Наразі YAMLScript працює на MacOS і Linux.

На компʼютері мають бути встановлені такі дуже поширені команди:

* `bash` - тести можна запускати в будь-якій оболонці, але `bash` має бути доступним.
* `make` - для запуску тестів потрібно використовувати GNU `make`.
  У деяких середовищах він може мати іншу назву, ніж `make`.
  Можливо, `gmake`.
* `prove` - ця програма входить до будь-якої звичайної інсталяції Perl.
* `curl` - використовується для встановлення ys, якщо його ще не встановлено.

Цілком імовірно, що всі ці програми вже встановлено.
