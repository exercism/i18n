# Інструкції

Ми завзяті спостерігачі птахів і ведемо облік того, скільки птахів прилітало до нашого саду за останні сім днів.

На нас чекають шість завдань, і всі вони стосуються кількості птахів, які відвідали наш сад.

## 1. Перевірте, скільки птахів прилетіло сьогодні

Реалізуйте функцію `today()`, яка повертає кількість птахів, що прилетіли до нашого саду сьогодні. 
Підрахунки птахів упорядковані за днями: перший елемент - це підрахунок найдавнішого дня, а останній - сьогоднішній.

```julia-repl
julia> birds_per_day = [2, 5, 0, 7, 4, 1]
julia> today(birds_per_day)
1
```

## 2. Збільште сьогоднішній підрахунок на одиницю

Реалізуйте функцію `increment_todays_count()`, щоб збільшити сьогоднішній підрахунок на одиницю:

```julia-repl
julia> birds_per_day = [2, 5, 0, 7, 4, 1]
julia> increment_todays_count(birds_per_day)
[2, 5, 0, 7, 4, 2]
```

## 3. Перевірте, чи був день без птахів

Реалізуйте функцію `has_day_without_birds()`, яка повертає `true`, якщо був день, коли до нашого саду не прилетів жоден птах; інакше поверніть `false`:

```julia-repl
julia> birds_per_day = [2, 5, 0, 7, 4, 1]
julia> has_day_without_birds(birds_per_day)
true
```

## 4. Обчисліть кількість птахів за вказану кількість днів

Реалізуйте функцію `count_for_first_days()`, яка повертає кількість птахів, що прилетіли до нашого саду від початку тижня, але обмежте підрахунок вказаною кількістю днів від початку тижня.

```julia-repl
julia> birds_per_day = [2, 5, 0, 7, 4, 1]
julia> count_for_first_days(birds_per_day, 4)
14
```

## 5. Обчисліть кількість насичених днів

Деякі дні насиченіші за інші. 
Насиченим вважається день, коли до нашого саду прилетіло пʼять або більше птахів.
Реалізуйте функцію `busy_days()`, яка повертає кількість насичених днів:

```julia-repl
julia> birds_per_day = [2, 5, 0, 7, 4, 1]
julia> busy_days(birds_per_day)
2
```

## 6. Обчисліть середні значення за днями тижня

Ми вирішуємо розширити свої записи, зберігаючи підрахунки за кілька тижнів.
У кожному випадку підрахунки впорядковані за днями тижня: від понеділка як першого запису до неділі як останнього.

Реалізуйте функцію `average_per_day()`, яка повертає середнє значення за 2 тижні.

```julia-repl
julia> week1 = [7, 2, 9, 1, 3, 0, 10]
julia> week2 = [2, 6, 4, 1, 3, 8, 9]
julia> average_per_day(week1, week2)
[4.5, 4.0, 6.5, 1.0, 4.0, 3.0, 9.5]
```
