# Встановлення

## Встановлення Clojure CLI

Clojure надає інструменти командного рядка для: запуску інтерактивного REPL (цикл читання-обчислення-виведення), запуску програм Clojure, обчислення виразів Clojure.
Радимо використовувати Clojure CLI для вправ. Щоб установити [Clojure CLI](https://clojure.org/guides/deps_and_cli):

### Windows
Інструкції зі встановлення для Windows можна знайти тут: [Встановлення Clojure CLI](https://clojure.org/guides/getting_started#_installation_on_windows).

### Linux
Інструкції зі встановлення для більшості платформ можна знайти тут: [Встановлення Clojure CLI](https://clojure.org/guides/getting_started#_installation_on_linux).

### Homebrew для Mac OS X
Оновімо Homebrew:

``` bash
$ brew update
```

Установімо Clojure CLI:
``` bash
$ brew install node clojure/tools/clojure
```

`Node` потрібен для середовища Node.

## Перевірка встановлення

Щоб перевірити, чи встановлення правильне, запустімо `clojure --help`: якщо все минуло гаразд, команда покаже версію.

```bash
$ clojure --help
Version: 1.10.1.547
...
```
