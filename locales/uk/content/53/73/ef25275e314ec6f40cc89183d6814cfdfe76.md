# Про

Коли ми перебираємо послідовність, іноді самого елемента недостатньо: потрібна ще й позиція. Слова *індексованої* ітерації Factor дають квотейшну для кожного елемента і елемент, і індекс, причому індекс лежить на вершині стека. `times` — споріднене слово для ітерації із заданою кількістю повторів, якій не потрібна послідовність.

```factor
USING: io kernel math.parser sequences ;

! map-index: build a new sequence; quot sees ( elt index )
{ "alice" "bob" "carol" }
[ number>string ": " glue ] map-index .
! => { "alice: 0" "bob: 1" "carol: 2" }

! each-index: for side effect; quot sees ( elt index )
{ "alice" "bob" } [
    number>string ": " glue print
] each-index
! prints alice: 0
! prints bob: 1

! times: run a quotation N times
3 [ "tick " print ] times
```

| слово        | ефект                                                                |
|--------------|----------------------------------------------------------------------|
| `each-index` | `( seq quot: ( elt index -- ) -- )`                                  |
| `map-index`  | `( seq quot: ( elt index -- newelt ) -- newseq )`                    |
| `times`      | `( n quot: ( -- ) -- )`, але про це нижче                            |

Тонкість щодо `times`: хоча його квотейшн задокументовано як `( -- )`, слово є `inline`, тож збалансований за ефектом квотейшн, як-от `( str -- str )`, чудово працює й протягує стек крізь ітерації. Це дає нам акумулятор із підрахунком без будь-якого змінюваного стану:

```factor
USING: kernel sequences ;

"" 3 [ "clop " append ] times .    ! => "clop clop clop "
```

Той самий прийом працює для `each-index` і `map-index`: оголошений ефект для кожного елемента є *мінімумом*, а не максимумом.
