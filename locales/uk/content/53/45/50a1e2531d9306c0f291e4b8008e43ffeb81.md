# Додаток до інструкцій

## Регістри

| Регістр | Використання   | Тип          | Опис                                      |
| -------- | ------------ | ------- | ----------------------------------- |
| `$a0`    | вхідні дані        | ціле число | натуральне число для розкладання на множники     |
| `$a1`    | вхідні/вихідні дані | адреса | масив призначення для простих множників |
| `$v0`    | вихідні дані       | ціле число | кількість множників                   |
| `$t0-9`  | тимчасові    | будь-що     | використовується для тимчасового зберігання          |
