## Змінні та присвоєння

R належить до динамічно типізованих мов, тож загалом не потрібно вказувати тип змінної. Для присвоєння бажано використовувати оператор `<-`

```R
x <- 42
avogadro <- 6.02e23
mystr <- "Hello, World!"
```

Використання `=` замість `<-` часто, але не завжди, працює, і вважається поганим стилем.
Якщо ми працюємо в RStudio, його можна ввести за допомогою комбінації клавіш `Alt-minus`.

Оператори здебільшого звичні, але звернімо увагу на `%/%` і `%%`:

```R
2 + 3   # 5
2 - 3   # -1
2 * 3   # 6
2 / 3   # 0.6666667
8 %/% 3 # 2 (integer division)
8 %% 3  # 2 (remainder)
2 ^ 3   # 8 (exponential)
```

У R символ `#` починає однорядковий коментар.
Окремого синтаксису для багаторядкових коментарів немає.

## Функції

Щоб визначити функцію:

```R
squareit <- function(x) {
    x * x
}
```

Функції можуть мати нуль або більше аргументів, розділених комами.
Круглі дужки `()` потрібні разом із `function()`, навіть якщо параметрів немає.

Для аргументів функції можна вказати типові значення, але вони мають іти після всіх аргументів без типових значень, і для присвоєння типового значення використовують `=`, а не `<-`.
Досить безглуздий приклад:

```R
squareit <- function(x = 42) {
    x * x
}

squareit()
#> [1] 1764
```

Фігурні дужки `{ }` не є строго обовʼязковими для однорядкових тіл функцій, але їх додавання вважається добрим стилем.

R автоматично повертає останнє значення функції, як у прикладах вище.

`return()` можна використати будь-де в тілі функції, щоб явно вказати повернене значення.

Функцію викликають так само, як і в багатьох інших мовах:

```R
squareit(3)
#> [1] 9
```
