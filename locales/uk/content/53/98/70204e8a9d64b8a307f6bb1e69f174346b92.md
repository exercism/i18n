# Докладніше

Типи переліків можна використовувати, якщо потрібен фіксований набір сталих значень. Використання `enum` дає типобезпечний спосіб роботи зі сталими значеннями. Визначення переліку відбувається за допомогою ключового слова `enum`. Щоб звернутися до члена переліку, перед ним ставлять назву переліку та крапку (наприклад, `Status.Active`).

Кожен член переліку поєднує назву зі значенням типу `int`. Якщо перший член не має явного значення, його значення дорівнює `0`. Якщо для члена переліку явно не вказано значення, йому автоматично присвоюється значення попереднього члена плюс `1`.

```csharp
enum Season
{
    Spring,     // Auto set 0
    Summer = 2, // Set the value 2
    Autumn,     // Auto set 3
    Winter = 7  // Set the value 7
}
```

Переліки дуже декларативні. Порівняймо наступні два виклики методів:

```csharp
Users.WithStatus(1)
Users.WithStatus(Status.Active)
```

Тому, хто читає код, другий варіант (з переліком) буде зрозумілішим.

## Переліки з числовим типом

Хоча типовий числовий тип значень - `int`, його можна змінити, явно вказавши будь-який інший [цілочисельний тип][integral numeric].

У наступному переліку для значень використовується числовий тип `byte`:

```csharp
enum Priority : byte
{
    Low = 0,
    Medium = 127,
    High = 255
}
```

## Перетворення на член переліку

Варто завжди розглянути використання переліку, коли потрібно змоделювати щось на кшталт булевого значення (англ. Boolean). Окрім згаданих переваг у читабельності, переліки мають ще одну перевагу над булевими значеннями: до переліку завжди можна додати нові значення, тоді як булеве значення завжди буде лише `true` або `false`. Тож використання переліку краще витримує майбутні зміни.

```csharp
enum Status
{
    Inactive = 0,
    Active = 1
}

Status active = (Status) 1;
active == Status.Active; // True
```

Зауважмо, що хоча цілочисельні значення _можна_ привести до переліку, це може дати несподівані результати, якщо ціле число не відповідає жодному значенню переліку:

```csharp
Status status = (Status) 2;
status == Status.Inactive; // False
status == Status.Active;   // False
```

## Розбір переліку

Іноді корисно перетворити рядок тексту (англ. string) на член переліку за його назвою за допомогою [`Enum.Parse`][enum parse]:

```csharp
var input = "Inactive";
Status status = (Status)Enum.Parse(typeof(Status), input);
// Inactive
```

Щоб перевірити, чи існує в переліку назва або значення, можна використати [`Enum.TryParse`][enum tryparse] або [`Enum.IsDefined`][enum isdefined]; обидва повертають булеве значення, яке вказує, чи існує член переліку:

```csharp
bool doesExist = Enum.IsDefined(typeof(Status), "Inexistent");
// False
```
