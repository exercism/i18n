# Підказки

## Загальне

- Ознайомтеся з [документацією `elm/parser`][elm-parser]
- У вступі розглянуто всі поняття, потрібні для розвʼязання вправи

## 1. Розбір ціни піци

- Парсер [`int`][int] призначений для розбору цілих чисел
- € може обробити не один парсер, але найкраще підходить [`symbol`][symbol]
- Оператор [`(|.)`][(|.)] може розібрати дві речі, але залишити лише одну

## 2. Розбір позначки вегетаріанської піци

- Парсер [`oneOf`][oneOf] може спробувати різні варіанти
- Існує не один спосіб розібрати конкретний рядок тексту (англ. string); у цьому випадку підійдуть [`keyword`][keyword] або [`symbol`][symbol]
- Існує не один спосіб повернути `True`, якщо парсер успішний; добрий варіант: скористатися [`succeed`][succeed]

## 3. Розбір назв піци та інгредієнтів

- Парсер [`chompWhile`][chompWhile] призначений для розбору довільних символів
- Функція [`isAlpha`][isAlpha] уміє перевіряти символи ASCII у верхньому й нижньому регістрі
- Функцію [`map`][map] можна використати, щоб змінити вміст парсера
- Функція [`String.toLower`][toLower] переводить рядок тексту в нижній регістр

## 4. Розбір масиву інгредієнтів

- Парсер [`sequence`][sequence] призначений для розбору масивів елементів
- Використайте всі доречні функції, які ми вже визначили

## 5. Розбір повної піци

- Оператор [`(|=)`][(|=)] дозволяє досить просто зберегти в конвеєрі більше ніж одну річ
- Використайте `Pizza` як конструктор типу з [`succeed`][succeed]
- «:» і «-» може обробити не один парсер, але найкраще підходить [`symbol`][symbol]
- Парсер [`spaces`][spaces] стане в пригоді, щоб позбутися зайвих пробілів
- Використайте всі доречні функції, які ми вже визначили

## 6. Розбір повного меню

- Парсер [`sequence`][sequence] призначений для розбору масивів елементів
- Памʼятайте, що `spaces` також споживає символи нового рядка, і це може завадити розділювачу
- Парсер [`end`][end] призначений для перевірки, чи дійшли ми кінця рядка тексту
- Оператор [`(|.)`][(|.)] може розібрати дві речі, але залишити лише одну
- Використайте всі доречні функції, які ми вже визначили

## 7. Розбір багатослівних назв інгредієнтів

- Парсер [`chompWhile`][chompWhile] призначений для розбору довільних символів
- Функція [`isAlpha`][isAlpha] уміє перевіряти символи ASCII у верхньому й нижньому регістрі
- Функцію [`andThen`][andThen] можна використати, щоб переглянути вміст парсера
- Функція [`problem`][problem] повертає парсер, який зайшов у глухий кут
- Функція [`String.toLower`][toLower] переводить рядок тексту в нижній регістр
- Функція [`String.trim`][trim] може позбутися пробільних символів із країв рядка тексту
