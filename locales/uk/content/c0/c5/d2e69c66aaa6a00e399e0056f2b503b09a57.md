# Вступ

## Посилання

### Копії та посилання

З огляду на наші поточні знання, оновлювати змінну за допомогою функції трохи незручно.
Кожен аргумент функції обробляється як копія і не змінює початкове значення.
Залежно від розміру типу це може серйозно позначитися на швидкодії коду.

```cpp
int adjust_salary(int base, int kids) {
    return base + kids * 500;
}
int now_a_mother_of_twins{2500};
adjust_salary(now_a_mother_of_twins, 2);

// now_a_mother_of_twins is still 2500
now_a_mother_of_twins = adjust_salary(now_a_mother_of_twins, 2);
// now_a_mother_of_twins is now 3500
```

`References` можна розуміти як псевдоніми: зміни в них впливають на початкову змінну.
У `References` в оголошенні типу використовується **амперсанд** (`&`).

```cpp
int balance{1000};
int& budget{balance};
int pro_computer_wheels{699};
budget -= pro_computer_wheels;
// budget is now 301;
// balance is also 301;
```
Перепривʼязати (змінити привʼязку `reference`) неможливо.
Не можна мати неініціалізований `reference`.
`References` потрібно ініціалізувати наявною змінною.

```cpp
int main_acc{1'000'000};
int side_acc{-20};
int& savings{main_acc};
// => main_acc and savings are 1'000'000

// try to reseat savings to use main account
savings = side_acc;
// savings and main_acc are now -20
// as this uses the **value** of side_acc
savings += 20;
// savings and main_acc are now 0, side_acc is still -20

int& future_budget;
// => compiler error, reference must be bound!
```

### `void`

Завдяки можливостям `references` повертати значення з функції взагалі може не знадобитися.
У цьому випадку `void` використовується як тип поверненого значення.

```cpp
void increase_power(int& level) {
    level += 500;
}
int goku{8700};
increase_power(goku);
// goku's power level?
// It's over 9000!
```
