# Підказки

## Загальне

- Це завдання присвячене створенню [_стеку_][Baeldung: The Stack Data Structure] за допомогою [однозвʼязного списку][singly linked list].
- На відміну від стеків, побудованих на `lists`, `collections.deque` чи `queue.LifoQueue`, ми просимо створити власні `Node` і `LinkedList` [`classes`][classes tutorial], щоб зберігати й звʼязувати елементи.

![Схема, що зображує стек, реалізований за допомогою звʼязаного списку. Круг зі штриховою рамкою під назвою New_Node розташований на самому лівому краю, і від нього праворуч ведуть дві пунктирні лінії зі стрілками. На New_Node написано "(becomes head) - New_Node - next = node_6". Верхня пунктирна стрілка підписана "push" і вказує на Node_6, розташований вище й праворуч. На Node_6 написано "(current) head - Node_6 - next = node_5". Нижня пунктирна стрілка підписана "pop" і вказує на прямокутник із написом "gets removed on pop()". Від Node_6 веде суцільна стрілка праворуч до Node_5, на якому написано "Node_5 - next = node_4". Від Node_5 веде суцільна стрілка праворуч до Node_4, на якому написано "Node_4 - next = node_3". Ця закономірність продовжується аж до Node_1, на якому написано "(current) tail - Node_1 - next = None". Від Node_1 веде пунктирна стрілка праворуч до вузла з написом "None".](https://assets.exercism.org/images/tracks/python/simple-linked-list/linked-list.svg)

- [Real Python: Linked Lists][Real Python Linked Lists], [Towards Data Science: Demystifying the Linked List][towards data science demystifying the linked list] і [ADS Stack in Python][Koder Dojo Coding an ADS Stack in Python] стануть у пригоді, якщо треба пригадати подробиці реалізації.
- `LinkedList` має приймати аргумент `list` у своєму _конструкторі_, але не повинен використовувати `list` для зберігання вузлів чи елементів.
- `len()` - вбудована функція для більшості обʼєктів Python.
Щоб _власні обʼєкти_ підтримували `len()`, потрібно визначити спеціальний метод [`__len__`][__len__].
- Ітерація в Python підтримується для більшості обʼєктів типу послідовності, контейнера чи колекції.
Щоб _власний_ обʼєкт підтримував перебирання елементів чи зміну порядку, потрібно визначити спеціальний метод `__iter__`.
[Implementing an iterator for a class][implementing iterators] допоможе показати, як це зробити.
