# Вступ

Конструкція `guard` у Swift використовується для дострокового виходу з функцій, циклів або методів, коли потрібну умову не виконано:

```swift
guard myValue >= 0 else { return 0 }
let root = myValue.squareRoot()
```

У наведеному вище прикладі `guard` обчислює булевий вираз (англ. Boolean), що стоїть після нього.
Якщо умова має значення `true`, виконання продовжується кодом після конструкції `guard`.
Якщо умова має значення `false`, виконується код у блоці `else`.

На відміну від умовної конструкції `if`:

- Конструкція `guard` **обовʼязково** повинна мати гілку `else`.
- Гілка `else` **обовʼязково** повинна передати керування так, щоб вийти з області видимості, яка її оточує (наприклад, за допомогою `return`, `continue`, `break` або викинувши помилку).

Конструкцію `guard` часто використовують, щоб чисто перевірити передумови.
Наприклад, розглянемо функцію sinc ($\text{sinc}(x) = \frac{\sin(x)}{x}$, де $\text{sinc}(0) = 1$, щоб уникнути ділення на нуль):

```swift
func sinc(_ x: Double) -> Double {
    guard x != 0 else { return 1 }
    return sin(x) / x
}

sinc(0)             // returns 1
sinc(Double.pi / 2) // returns 0.6366197723675814
```
