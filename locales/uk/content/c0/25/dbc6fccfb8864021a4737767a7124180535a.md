# Тести

## Clojure CLI

Вправи з Clojure на Exercism постачаються з файлом `deps.edn`, який містить аліас `:test` для виклику [cognitect-labs test-runner](https://github.com/cognitect-labs/test-runner):

``` bash
$ clj -X:test
```

Це перегляне каталог `test` проєкту в пошуках тестів, визначених за допомогою `clojure.test`, і запустить їх.

## Leiningen

Щоб запустити тести вправи за допомогою Leiningen, просто викличте:

``` bash
$ lein test

lein test bob-test

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
```
