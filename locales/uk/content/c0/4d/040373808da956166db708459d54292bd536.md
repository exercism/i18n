# Вступ

Крім конструкції `if`, існує також конструкція `switch`, яка дає змогу виконувати логіку за умовою. Її застосовують, коли одну змінну потрібно порівняти з кількома варіантами. Для деякої змінної x конструкція `switch` у Haxe має такий синтаксис.

```haxe
var a = 2;

switch (a) {
  case 0:
    trace("a is 0");
  case 1:
    trace("a is 1");
  case 2:
    trace("a is 2");
  default:
    trace("a is something else");
}

// a is 2
```

Варіант `default` виконується тоді, коли жоден з інших варіантів не збігається.
