# Вступ

Файл - це просто потік, у якого є імʼя на диску. Набір слів [`io.files`][io.files] дає нам два способи працювати з ним: зручні слова для роботи з файлом цілком, які читають або записують усе за один виклик, і засоби відкриття потоків для випадків, коли ми хочемо читати або записувати поступово.

Кожне слово, яке працює з файлом, приймає **кодування**: схему, яка перетворює байти на символи й назад. Для тексту це майже завжди [`utf8`][utf8] з `io.encodings.utf8`.

## Читання файлу цілком

```
file-contents   ( path encoding -- str )
file-lines      ( path encoding -- seq )
```

`file-contents` повертає весь файл як один рядок тексту (англ. string); `file-lines` повертає масив його рядків, з яких прибрано символи нового рядка.

```factor
USING: io.encodings.utf8 io.files prettyprint ;

"sunny\ncloudy\n" "forecast.txt" utf8 set-file-contents

"forecast.txt" utf8 file-contents .
! => "sunny\ncloudy\n"

"forecast.txt" utf8 file-lines .
! => { "sunny" "cloudy" }
```

## Запис файлу цілком

```
set-file-contents   ( str path encoding -- )
set-file-lines      ( seq path encoding -- )
```

Обидва **замінюють** вміст файлу (створюючи його за потреби). `set-file-contents` записує рядок тексту дослівно; `set-file-lines` записує кожен елемент послідовності в окремому рядку й сам додає символи нового рядка.

```factor
USING: io.encodings.utf8 io.files prettyprint ;

{ "sunny" "cloudy" } "forecast.txt" utf8 set-file-lines
"forecast.txt" utf8 file-contents .
! => "sunny\ncloudy\n"
```

## Дописування у файл

Щоб додати щось у файл, не стираючи того, що вже там є, відкриймо його комбінатором `with-…` і запишімо в поточний потік усередині блоку коду:

```
with-file-appender   ( path encoding quot -- )
with-file-reader     ( path encoding quot -- )
with-file-writer     ( path encoding quot -- )
```

```factor
USING: io io.encodings.utf8 io.files prettyprint ;

"sunny\ncloudy\n" "forecast.txt" utf8 set-file-contents
"forecast.txt" utf8 [ "rainy" print ] with-file-appender
"forecast.txt" utf8 file-contents .
! => "sunny\ncloudy\nrainy\n"
```

Як і кожен комбінатор `with-…`, вони утворюють область дії деструктора: дескриптор файлу закривається, коли блок коду завершується, навіть якщо той викидає виняток.
