# Вступ

Кожен екземпляр структури чи класу має неявну властивість з назвою `self`, яка вказує на сам цей екземпляр.
Найчастіше `self` використовують, щоб розрізнити властивість екземпляра та параметр, який має ту саму назву:

```swift
struct Position {
    var x = 0

    mutating func move(x: Int) {
        // Here, 'self.x' refers to the struct's property,
        // while 'x' refers to the parameter passed to the method.
        self.x = x
    }
}
```

Типи Swift також мають ключове слово `Self`, написане з великої літери, яке вказує на *тип* екземпляра, а не на сам екземпляр.
