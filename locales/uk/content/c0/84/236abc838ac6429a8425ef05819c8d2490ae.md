# Умовні конструкції

У Python інструкції [`if`][if statement], `elif` (_скорочення від «else and if»_) та `else` використовуються, щоб [керувати потоком виконання][control flow tools] і ухвалювати рішення в програмі.
На відміну від багатьох інших мов програмування, у версіях Python 3.9 і нижче немає формальної конструкції перемикання: замість неї для схожої мети використовуються кілька інструкцій `elif`.

Python 3.10 запроваджує різновид конструкції перемикання під назвою `structural pattern matching`, який ми розглянемо окремо в іншій концепції.

Умовні конструкції використовують вирази, які мають зводитися до `True` або `False`: або повертаючи тип `bool` напряму, або обчислюючись як [«truthy» або «falsy»][truth value testing].

```python
x = 10
y = 5

# The comparison '>' returns the bool 'True',
# so the statement is printed.
if x > y:
    print("x is greater than y")
...
>>> x is greater than y
```

У парі з `if` необовʼязковий блок коду `else` виконається тоді, коли початкова умова `if` обчислиться як `False`:

```python
x = 5
y = 10

# The comparison '>' here returns the bool 'False',
# so the 'else' block is executed instead of the 'if' block.
if x > y:
    print("x is greater than y")
else:
    print("y is greater than x")
...
>>> y is greater than x
```

`elif` дає змогу виконувати кілька перевірок і мати кілька гілок.

```python
x = 5
y = 10
z = 20

# The 'elif' statement allows for the checking of more conditions.
if x > y:
    print("x is greater than y and z")
elif y > z:
    print("y is greater than x and z")
else:
    print("z is greater than x and y")
...
>>> z is greater than x and y
```

[Булеві операції (англ. Boolean)][boolean operations] та [порівняння][comparisons] можна поєднувати з умовними конструкціями для складніших перевірок:

```python
>>> def classic_fizzbuzz(number):
        if number % 3 == 0 and number % 5 == 0:
            say = 'FizzBuzz!'
        elif number % 5 == 0:
            say = 'Buzz!'
        elif number % 3 == 0:
            say = 'Fizz!'
        else:
            say = str(number)
        
        return say

>>> classic_fizzbuzz(15)
'FizzBuzz!'

>>> classic_fizzbuzz(13)
'13'
```
