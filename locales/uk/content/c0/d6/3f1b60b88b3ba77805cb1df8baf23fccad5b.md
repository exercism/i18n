# Вступ

Програма мовою `jq`, яка натрапляє на проблему під час обробки значення (індексування числа рядком тексту (англ. string), розбір некоректного тексту JSON, виклик функції з аргументом неправильного типу), породжує **помилку виконання**.
Якщо помилку виконання не перехопити, `jq` друкує повідомлення в _стандартний потік помилок_ і завершує роботу зі статусом `5`.

## Породження помилок: `error` і `error(message)`

- `error` породжує помилку, значення якої - **вхідні дані**.
- `error(message)` породжує помилку, значення якої - результат обчислення `message`.

Значення помилки може бути _будь-яким_ значенням JSON, а не лише рядком тексту.

```jq
42 | error("invalid value: \(.)")
# => "invalid value: 42"

42 | error
(not a string): 42
```

## Перехоплення помилок: `try` і `catch`

Помилки можна перехопити конструкцією `try EXP catch HANDLER`.
Спершу виконується перший вираз; якщо він породжує помилку, виконується вираз `HANDLER`, **причому його вхідними даними стає значення помилки**.
Вихідні дані `try catch` - це вихідні дані того виразу, який виконався останнім (`EXP` або `HANDLER`).

```jq
{a: 42} | try .a catch "no index a in \(.)"
# => 42

true | try .a catch "cannot index a \(type)"
# => "cannot index a boolean"

true | try error("some exception") catch .
# => "some exception"
```

Коротша форма `try EXP` рівносильна `try EXP catch empty`: помилка відкидається, і жодних вихідних даних не буде.

```jq
[{}, true, {"a": 1}] | [.[] | try .a]
# => [null, 1]
```

## Придушення помилок: оператор `?`

Оператор `?`, застосований як `EXP?`, - це скорочений запис `try EXP`.
Він перетворює вираз, що зазнає невдачі, на такий, що просто не дає жодних вихідних даних.

```jq
["1", "invalid", "3", 4] | [.[] | tonumber?]
# => [1, 3, 4]
```

Його часто можна побачити приєднаним до операторів індексування: `.foo?` і `.[]?`.

## Зупинка програми: `halt_error` і `halt`

`halt_error` зупиняє програму, друкує її вхідні дані в _стандартний потік помилок_ як необроблений текст і завершує роботу із заданим статусом, який типово становить `5`.
Повʼязаний фільтр `halt` зупиняє програму без повідомлень зі статусом завершення `0`.

```jq
"Error: something went wrong" | halt_error(1)
```
