# Вступ

Cairo надає словники в складі базових бібліотек, і представляє їх тип `Felt252Dict<T>`.

У Cairo тип ключа словника обмежено `felt252`, що відрізняється від інших мов, де тип ключа можна задавати самостійно.

Щоб створити словник, можна скористатися методом `default` трейту `Default`:

```rust
let mut foo: Felt252Dict<u32> = Default::default();
```

Найчастіше використовують такі базові операції:

1. `insert(felt252, T) -> ()`, щоб записувати значення в екземпляр словника, та
2. `get(felt252) -> T`, щоб читати з нього значення.

А ось як ці операції застосувати:

```rust
let mut foo: Felt252Dict<u32> = Default::default();
// Add a value to the dictionariy
foo.insert('bar', 42);
// Here we update the element of 'bar'
foo.insert('bar', 73);
// To retrieve a dictionary value, you can use
baz = foo.get('bar');
```

Якщо спробувати отримати значення за ключем, якого немає в словнику, тоді повернеться нульове значення цього типу.

Це може заплутати, особливо коли типове значення цього типу (наприклад, 0 для цілого числа) саме є допустимим значенням.

Це також означає, що зі словника жодним чином не можна видалити дані.

Це варто враховувати, коли ми впроваджуємо цю структуру у свій код.
