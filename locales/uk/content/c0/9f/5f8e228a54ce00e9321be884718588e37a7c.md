# Інструкції

Робота над проєктом радіокерованої машинки триває. Пропускна здатність у системі телеметрії дуже обмежена, і ми маємо реалізувати протокол обміну повідомленнями для передавання даних телеметрії.

Дані передаються в буфері (масиві байтів). Коли надсилаються цілі числа, розмір буфера зменшується завдяки протоколу, описаному нижче.

Кожне значення слід подати в найменшому можливому цілому типі (типи `byte` і `sbyte` не враховуються, бо економія була б мізерною):

| Від                        | До                        | Тип      |
| -------------------------- | ------------------------- | -------- |
| 4_294_967_296              | 9_223_372_036_854_775_807 | `long`   |
| 2_147_483_648              | 4_294_967_295             | `uint`   |
| 65_536                     | 2_147_483_647             | `int`    |
| 0                          | 65_535                    | `ushort` |
| -32_768                    | -1                        | `short`  |
| -2_147_483_648             | -32_769                   | `int`    |
| -9_223_372_036_854_775_808 | -2_147_483_649            | `long`   |

Значення слід перетворити на відповідну кількість байтів для призначеного йому типу. Повний буфер складається з байта, який указує кількість додаткових байтів у буфері (_префіксний байт_), а далі йдуть байти, що містять ціле число (_байти даних_).

Деякі типи використовують однакову кількість байтів (наприклад, типи `uint` та `int`). Зазвичай вони мали б однаковий _префіксний байт_, але це ускладнило б декодування. Щоб це обійти, протокол застосовує невелику хитрість: для знакових типів значення _префіксного байта_ дорівнює `256` мінус кількість додаткових байтів у буфері.

У повідомленні надсилаються лише префіксний байт і та кількість наступних байтів, яку вказує префікс. Усередині як для надсилання, так і для отримання використовується буфер на 9 байтів (за потреби з кінцевими нулями).

## 1. Закодувати ціле значення, готове до надсилання

Реалізуйте статичний метод `TelemetryBuffer.ToBuffer()`, щоб закодувати буфер на основі параметра, переданого методу.

```csharp
// Type: ushort, bytes: 2, signed: no, prefix byte: 2
TelemetryBuffer.ToBuffer(5)
// => {0x2, 0x5, 0x0, 0x0, 0x0, 0x0, 0x0, 0x0, 0x0 };

// Type: int, bytes: 4, signed: yes, prefix byte: 256 - 4
TelemetryBuffer.ToBuffer(Int32.MaxValue)
// => {0xfc, 0xff, 0xff, 0xff, 0x7f, 0x0, 0x0, 0x0, 0x0 };
```

## 2. Декодувати отриманий буфер

Реалізуйте статичний метод `TelemetryBuffer.FromBuffer()`, щоб декодувати отриманий буфер і повернути значення у вигляді `long`.

```csharp
TelemetryBuffer.FromBuffer(new byte[] {0xfc, 0xff, 0xff, 0xff, 0x7f, 0x0, 0x0, 0x0, 0x0 })
// => 2147483647
```

Якщо значення префіксного байта неочікуване, слід повернути `0`.
