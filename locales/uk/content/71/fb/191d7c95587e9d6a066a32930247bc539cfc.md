# Вступ

## Основи

Java - це статично типізована мова, а це означає, що тип змінної відомий під час компіляції.
Присвоєння значення імені називають визначенням змінної.
Змінну визначають, явно вказуючи її тип.

```java
int explicitVar = 10;
```

Оновлення значення змінної виконують через оператор `=`.
Тут `=` не означає математичної рівності.
Він просто присвоює значення змінній.
Після визначення тип змінної вже не може змінитися.

```java
int count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning a different type
// count = false;
```

Java - це [обʼєктно-орієнтована мова][object-oriented-programming], і в ній усі функції потрібно визначати всередині _класу_.
Для визначення класу використовують ключове слово `class`.

```java
class Calculator {
    // ...
}
```

Функцію всередині класу називають _методом_.
Кожен метод може мати нуль або більше параметрів.
Усі параметри потрібно явно типізувати; для параметрів не існує виведення типів.
Так само потрібно явно вказати і тип поверненого значення.
Значення повертають із методів за допомогою ключового слова `return`.
Щоб метод можна було викликати з інших класів, потрібно додати модифікатор доступу `public`.

```java
class Calculator {
    public int add(int x, int y) {
        return x + y;
    }
}
```

Щоб викликати метод, указують його клас і назву методу та передають аргументи для кожного з параметрів методу.

```java
int sum = new Calculator().add(1, 2);  // here the  "add" method has been called to perform the task of addition
```

Область видимості в Java визначають між символами `{` і `}`.

Java підтримує два типи коментарів.
Однорядкові коментарі починаються з `//`, а багаторядкові вставляють між `/*` і `*/`.

[object-oriented-programming]: https://docs.oracle.com/javase/tutorial/java/javaOO/index.html
