# Вступ

_«Дати й час ми вчимо малих дітей. Що в цьому складного?»_

Багато програмістів припускалися цієї помилки, і подальший досвід зазвичай погано позначається на їхньому здоровʼї та щасті.

Кожен, хто займається нетривіальним програмуванням із датами й часом, має принаймні бути готовим розуміти й помʼякшувати потенційні проблеми.

У цьому документі ми спробуємо дати огляд того, як Julia працює з датами й часом, але для подробиць доведеться звернутися до [посібника][Dates].
Є також [Вікіпідручник][Wikibook], чиї пояснення деяким читачам можуть здатися зрозумілішими, і в ньому є корисна [діаграма][type-hierarchy] ієрархії типів.

## Модуль `Dates`

Більшість базової функціональності міститься в `Dates`, модулі, який входить до типової інсталяції, але не є частиною стандартної бібліотеки.

Щоб скористатися модулем, є два варіанти:

1. Додамо `import Dates`, а потім додаватимемо `Dates.` перед усіма викликами функцій.
2. Додамо `using Dates`, що вносить увесь модуль у поточний простір імен (_крім кількох проблемних назв_).

```julia-repl
# option 1
julia> import Dates

julia> Dates.now()
2025-06-21T16:02:39.080

julia> now()  # wrong: need to include `Dates.` after an import
ERROR: UndefVarError: `now` not defined in `Main`


# option 2
julia> using Dates

julia> now()  # functions are now in the namespace
2025-06-21T16:03:04.161
```

Модуль `Dates` великий і складний, але він надає чотири основні типи функціональності:

- `Dates.Date`, який містить день, місяць і рік, але без часу доби.
- `Dates.Time`, який містить час доби, але без дати.
- `Dates.DateTime`, який поєднує дату й час.
- `Dates.Period`, який опрацьовує інтервали часу й дат.

Зауважмо, що `DateTime` зазвичай _не_ містить інформації про часовий пояс (Python назвав би це «наївним» datetime).
Один виняток - `now()`, який бере місцевий час із системного годинника й за потреби може перетворити його на UTC.

Мабуть, найчастіші потреби такі:

- Розібрати вхідні дані у відповідному форматі, щоб побудувати тип із `Dates`.
- Отримати з типу `Dates` потрібний числовий формат або рядок тексту (англ. string).
- Застосувати зсув до значення `Date`, `Time` або `DateTime`.
- Обчислити інтервал між двома такими значеннями.
- Отримати поточну дату (за допомогою `today()`) та/або час (за допомогою `now()`).

~~~~exercism/note
Щоб зменшити візуальне відволікання, більшість прикладів коду в решті цього документа припускає `using Dates` і не включає назву модуля `Dates.` у виклики функцій.
~~~~

### Формати дати й часу

Існує багато способів записувати дати й час, і вони зазвичай залежать від культури.
Дати, записані самими числами, як-от «7/6/23», неоднозначні, заплутані й призводили до багатьох дорогих помилок у міжнародних організаціях (_автор каже це з гіркого особистого досвіду_).

Міжнародний стандарт визначено в `ISO 8601`, і він має дві головні переваги:

- Розбір швидкий і однозначний.
- Сортування легке, бо дату й час можна розглядати як звичайний текст і сортувати за алфавітом.

У попередньому прикладі ми бачили, що `Date.now()` повернув `2025-06-21T16:03:04.161`.

Він складається з різних частин:

- `YYYY-MM-DD` для частини з датою.
- `hh:mm:ss` для частини з часом.
- За бажанням, мілісекунди (або ще менша одиниця) після десяткової коми.

Інші формати рядків тексту ми обговоримо в пізнішому розділі.

## Дати

`Dates.Date` - відносно простий тип лише для дати, який нічого не знає про час чи часові пояси.

```julia-repl
# constructor with year, month, day arguments
julia> date1 = Date(2025, 06, 23)
2025-06-23

# constructor with ISO 8601 string
julia> date2 = Date("2025-06-23")
2025-06-23

julia> date1 == date2
true

julia> typeof(date1)
Date
```

Для окремих частин дати є функції доступу, і вони йдуть парами, які розрізняються регістром.

```julia-repl
# lowercase returns an integer
julia> month(date1)
6

julia> typeof(month(date1))
Int64

# Propercase returns a Period type
julia> Month(date1)
6 months

julia> typeof(Month(date1))
Month
```

### Функції запитів

Є чимало функцій, які дещо знають про календар.
Наступний приклад показує лише кілька з них.

```julia-repl
julia> date1
2025-06-23

julia> dayofweek(date1) # 1 = Monday, 7 = Sunday
1

julia> dayname(date1)
"Monday"

julia> daysinmonth(date1)
30

julia> isleapyear(date1)
false

julia> lastdayofmonth(date1)
2025-06-30
```

## Час

`Dates.Time` - базовий тип лише для часу.
Він нічого не знає про дати: час автоматично переходить до `Time(0, 0, 0)` опівночі.

Повний формат конструктора - `Time(hour, min, sec, millisec, microsec)` або його еквівалент за ISO 8601.

Усі параметри необовʼязкові й типово дорівнюють `0`.

```julia-repl
julia> Time(14, 57, 25, 142)
14:57:25.142

julia> Time("14:57:25.142")
14:57:25.142

julia> Time(14, 57, 25, 142, 32)
14:57:25.142032
```

Як і з `Date`, окремі частини доступні через функції доступу:

```julia-repl
julia> minute(t) # => integer
57

julia> Minute(t) # => Period
57 minutes
```

## Дати й час

`Dates.DateTime` поєднує більшість можливостей типів `Date` і `Time`.

```julia-repl
julia> dt1 = DateTime(2025, 6, 23, 14, 57, 25, 142)
2025-06-23T14:57:25.142

# date1 and t were defined in previous examples
julia> dt2 = DateTime(date1, t)
2025-06-23T14:57:25.142
```

Параметри року, місяця й дня типово дорівнюють `1`, а параметри часу - `0`.

Не заплутатися в усіх цих параметрах - непросте завдання, тож для вхідних даних формат ISO може виявитися кращим.

Або ж `DateTime` можна побудувати з `Date` і `Time`, як у наведеному вище прикладі.

## Періоди

Кожен із компонентів дати й часу має власний тип `Period`, від `Year` аж до `Nanosecond`, що представляє інтервал часу.
Вони особливо корисні для арифметики.

```julia-repl
julia> dt1
2025-06-23T14:57:25.142

julia> Year(21)
21 years

julia> Second(61)
61 seconds

julia> dt1 + Year(21) - Second(61)
2046-06-23T14:56:24.142

julia> Date(2025, 07, 03) - Date(2025, 04, 25)
69 days
```

Працюючи з типами `Period`, Julia намагається розумно поводитися з календарними нерівностями, як-от довжина місяця, округлюючи за потреби.

```julia-repl
# February has fewer days than January
julia> Date(2025, 1, 31) + Month(1) 
2025-02-28
```

## Подання рядків тексту

Раніше ми згадували стандарт ISO 8601 - типове подання дати й часу в Julia під час форматування чи розбору рядків тексту.

Очевидно, часто використовують багато інших форматів, нерідко з огляду на культурні особливості.
Щоб їх опрацьовувати, у Julia є тип `DateFormat`, який можна побудувати з рядка формату довільної складності.

```julia-repl
# dateformat"" string syntax
julia> dtfmt = dateformat"d/m/y"
dateformat"d/m/y"

julia> typeof(dtfmt)
DateFormat{Symbol("d/m/y"), Tuple{Dates.DatePart{'d'}, Dates.Delim{Char, 1}, Dates.DatePart{'m'}, Dates.Delim{Char, 1}, Dates.DatePart{'y'}}}

# DateFormat constructor
julia> DateFormat("d/m/y")
dateformat"d/m/y"
```

Наведений вище приклад дуже простий: лише дата у форматі день/місяць/рік, поширеному в Європі.
Показано два варіанти синтаксису, але результат однаковий.

Тоді `DateFormat` можна використати для розбору будь-якого відповідного рядка тексту:

```julia-repl
julia> DateTime("14/7/2023", dtfmt)
2023-07-14T00:00:00
```

Створення `DateFormat` повʼязане зі значними накладними витратами, тож виконати цей крок лише раз (як тут із `dtfmt`) корисно для швидкодії, коли ми перебираємо багато рядків тексту з датами й часом.

Формати можуть бути значно складнішими за це, тож для подробиць звернімося до [посібника][dateformat].

Той самий `DateFormat` можна також використати, щоб вивести дату й час у будь-якому бажаному форматі рядка тексту, за допомогою функції [`Dates.format()`][format].

На жаль, схоже, є конфлікт просторів імен із `format` (принаймні станом на Julia 1.11.5), тож краще додавати префікс `Dates.` навіть після `using Dates`.

```julia-repl
julia> dt1
2025-06-23T14:57:25.142

julia> Dates.format(dt1, dateformat"e, u d")
"Mon, Jun 23"
```

Як [задокументовано][wiki-format], `"e, u d"` дає скорочене текстове подання для дня тижня й місяця.

Текстове подання типово англійською.
Можна додати інші мови, хоча нині підтримка цього не найкраща.
