# Вступ

`list` у F# - це незмінна колекція з нуля або більше значень. Усі значення в масиві мають бути одного типу. Оскільки масиви незмінні, після створення масиву його значення вже ніколи не зміниться. Будь-які функції чи оператори, які нібито змінюють масив (наприклад, додають елемент), насправді повертають новий масив.

Масиви можна визначити так:

```fsharp
let empty = []
let singleValue = [5]
let threeValues = ["a"; "b"; "c"]
```

Найчастіше елемент додають до масиву за допомогою оператора `::` (cons):

```fsharp
let twoToFour = [2; 3; 4]
let oneToFour = 1 :: twoToFour
// => [1; 2; 3; 4]
```

Масив у F# має _голову_ (перший елемент) і _хвіст_ (усе після першого елемента). Хвіст масиву сам є масивом.

З масивами працюють або через функції та оператори, визначені в модулі `List`, або вручну, за допомогою зіставлення зі зразком із зразками _list_ і _cons_:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | head::tail -> sprintf "Non-empty list with head: %d" head

describe []        // => "Empty list"
describe [1]       // => "Non-empty with head: 1"
describe [5; 7; 9] // => "Non-empty with head: 5"
```

Під час зіставлення зі зразком значення також можна _відкинути_; коли в конкретному випадку значення нас не цікавить (тобто ми не збираємося його _використовувати_), можна позначити це підкресленням (`'_'`):

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [x] -> "List with one item"
    | [_; y] -> "List with two items (first item ignored)"
    | _ -> "List with many items (all items ignored)"

describe []        // => "Empty list"
describe [1]       // => "List with one item"
describe [5; 7]     // => "List with two items (first item ignored)"
describe [5; 7; 9] // => "List with many items (all items ignored)"
```

Одиничне підкреслення `'_'` завжди має стояти _останнім_ під час зіставлення зі зразком: будь-яке значення, що _не_ збігається з жодним з інших випадків, обробить цей випадок.
