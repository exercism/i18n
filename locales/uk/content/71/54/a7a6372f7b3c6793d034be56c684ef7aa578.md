# Інструкції

Як майбутня фокусниця, Еліз має потренуватися в основах.
У неї є стос карт, з якими вона хоче працювати.

Щоб трохи спростити собі справу, вона використовує лише карти від 1 до 10.

## 1. Створити зріз із певними картами

Практикуючись зі своїми картами, Еліз любить починати з трьох улюблених карт колоди: 2, 6 і 9.
Напишіть функцію `FavoriteCards`, яка повертає зріз із цими картами в такому порядку.

```go
cards := FavoriteCards()
fmt.Println(cards)
// Output: [2 6 9]
```

## 2. Отримати карту зі стосу

Поверніть карту на позиції `index` із заданого стосу.

```go
card := GetItem([]int{1, 2, 4, 1}, 2) // card == 4
```

Якщо індекс виходить за межі (тобто якщо він відʼємний або після кінця стосу), потрібно повернути `-1`:

```go
card := GetItem([]int{1, 2, 4, 1}, 10) // card == -1
```

~~~~exercism/note
У Go за домовленістю замість повернення значення «поза межами» повертають помилку.
Тут значенням «поза межами» є `-1`, коли на цьому місці має бути додатне ціле число.
Повертаючи помилку, ідіоматично повертати разом із нею [`zero value`](https://www.geeksforgeeks.org/zero-value-in-golang/).
Повернення помилки разом із належним значенням буде розглянуто в одній із наступних вправ.
~~~~

## 3. Замінити карту в стосі

Замініть карту на позиції `index` на надану нову карту й поверніть змінений стос.
Зауважте, що це змінить вхідний зріз, і саме така поведінка очікується.

```go
index := 2
newCard := 6
cards := SetItem([]int{1, 2, 4, 1}, index, newCard)
fmt.Println(cards)
// Output: [1 2 6 1]
```

Якщо індекс виходить за межі (тобто якщо він відʼємний або після кінця стосу), потрібно додати нову карту в кінець стосу:

```go
index := -1
newCard := 6
cards := SetItem([]int{1, 2, 4, 1}, index, newCard)
fmt.Println(cards)
// Output: [1 2 4 1 6]
```

## 4. Додати карти на верхівку стосу

Додайте карту (або карти), указану в параметрі `value`, на верхівку стосу.

```go
slice := []int{3, 2, 6, 4, 8}
cards := PrependItems(slice, 5, 1)
fmt.Println(cards)
// Output: [5 1 3 2 6 4 8]
```

Якщо для параметра `value` не передано жодного аргументу, результат дорівнює початковому зрізу.

```go
slice := []int{3, 2, 6, 4, 8}
cards := PrependItems(slice)
fmt.Println(cards)
// Output: [3 2 6 4 8]
```

## 5. Вилучити карту зі стосу

Вилучіть карту на позиції `index` зі стосу й поверніть стос.
Зауважте, що це може змінити вхідний зріз, і це нормально.

```go
cards := RemoveItem([]int{3, 2, 6, 4, 8}, 2)
fmt.Println(cards)
// Output: [3 2 4 8]
```

Якщо індекс виходить за межі (тобто якщо він відʼємний або після кінця стосу), потрібно залишити стос без змін:

```go
cards := RemoveItem([]int{3, 2, 6, 4, 8}, 11)
fmt.Println(cards)
// Output: [3 2 6 4 8]
```
