# Інструкції

У цій вправі ми будемо керувати системою інвентарю.

Інвентар має бути впорядкований за назвою предмета й зберігати кількість наявних предметів.

Нам доведеться додавати предмети до інвентарю.
Щоразу, коли предмет трапляється в наведеному списку, кількість цього предмета в інвентарі має збільшуватися на `1`.
Також нам доведеться видаляти предмети з інвентарю, зменшуючи кількість на `1` на запит.

Нарешті, нам потрібно реалізувати функцію, яка повертатиме всі пари ключ-значення з наведеного інвентарю як `list` із `tuples`.


## 1. Створіть інвентар на основі списку

Реалізуймо функцію `create_inventory(<input list>)`, яка створює «інвентар» із вхідного списку предметів.
Вона має повертати `dict`, що містить кожну назву предмета в парі з відповідною кількістю.

```python
>>> create_inventory(["coal", "wood", "wood", "diamond", "diamond", "diamond"])
{"coal":1, "wood":2, "diamond":3}
```

## 2. Додайте предмети зі списку до наявного словника

Реалізуймо функцію `add_items(<inventory dict>, <item list>)`, яка додає список предметів до переданого інвентарю:

```python
>>> add_items({"coal":1}, ["wood", "iron", "coal", "wood"])
{"coal":2, "wood":2, "iron":1}
```

## 3. Зменште кількість предметів в інвентарі

Реалізуймо функцію `decrement_items(<inventory dict>, <items list>)`, яка приймає `list` предметів.
Наша функція має віднімати `1` від кількості предмета щоразу, коли цей предмет трапляється в `list`:

```python
>>> decrement_items({"coal":3, "diamond":1, "iron":5}, ["diamond", "coal", "iron", "iron"])
{"coal":2, "diamond":0, "iron":3}
```

Кількість предметів в інвентарі не повинна опускатися нижче 0.
 Якщо предмет трапляється у вхідному `list` більше разів, ніж є в наявності, указана кількість цього предмета має залишатися на 0.
 Додаткові запити на зменшення кількості слід ігнорувати, щойно кількість падає до нуля.

```python
>>> decrement_items({"coal":2, "wood":1, "diamond":2}, ["coal", "coal", "wood", "wood", "diamond"])
{"coal":0, "wood":0, "diamond":1}
```

## 4. Повністю вилучіть запис з інвентарю

Реалізуймо функцію `remove_item(<inventory dict>, <item>)`, яка повністю вилучає предмет і його кількість з інвентарю:

```python
>>> remove_item({"coal":2, "wood":1, "diamond":2}, "coal")
{"wood":1, "diamond":2}
```

Якщо предмета немає в інвентарі, функція має повернути початковий інвентар без змін.

```python
>>> remove_item({"coal":2, "wood":1, "diamond":2}, "gold")
{"coal":2, "wood":1, "diamond":2}
```

## 5. Поверніть весь вміст інвентарю

Реалізуймо функцію `list_inventory(<inventory dict>)`, яка приймає інвентар і повертає список кортежів виду `(item, quantity)`.
До списку мають потрапити лише _наявні_ предмети (_з кількістю, більшою за нуль_):

```python
>>> list_inventory({"coal":7, "wood":11, "diamond":2, "iron":7, "silver":0})
[('coal', 7), ('diamond', 2), ('iron', 7), ('wood', 11)]
```
