# Вступ

Більшість слів Factor для роботи з послідовностями повертають *нові* послідовності й не чіпають свої вхідні дані, але і масиви, і вектори також підтримують **мутацію на місці**, коли треба зафіксувати стан, що змінюється з часом.

`set-nth` і `change-nth` змінюють комірку на місці й працюють як з масивом, так і з вектором. `<array>` створює масив фіксованої довжини, який можна змінювати; літерали `V{ }`, `<vector>`, `push` і `pop` належать лише векторам, бо масиви не можуть змінювати довжину. `clone` створює копію послідовності, щоб подальші мутації не зачепили оригінал.

```factor
USING: arrays kernel sequences ;

5 0 <array>                 ! a fresh array { 0 0 0 0 0 }
dup 7 2 swap set-nth        ! { 0 0 7 0 0 } — set position 2 to 7
.

V{ } clone                  ! a fresh, empty vector
"alice" over push           ! V{ "alice" }
"bob" over push             ! V{ "alice" "bob" }
dup pop .                   ! "bob"
.                           ! V{ "alice" }
```

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
