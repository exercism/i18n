# Тести

## Запуск тестів

У каталозі вправи мають бути два підкаталоги:

* `Sources/<Exercise>` містить рішення вправи
* `Tests/<Exercise>Tests` містить тести, які потрібно запустити для вправи

Якщо ми в потрібному каталозі (тобто в тому, що містить `Sources` і `Tests`), тести для цієї вправи можна запустити командою `swift test`:

```bash
$ pwd
/Users/johndoe/Code/exercism/swift/hello-world

$ ls
HELP.md  Package.swift  README.md  Sources  Tests

$ swift test
```

Коли тест проходить, приберіть `.enabled(if: RUNALL)` в інструкції `@Test`, щоб увімкнути наступний тест. Або можна запустити всі тести, встановивши змінну середовища `RUNALL` у `true` на Linux чи macOS:

```bash
$ export RUNALL=true
```

Або, якщо ми використовуємо PowerShell у Windows:

```powershell
set RUNALL=true
```

## Надсилання рішення

Щоб завантажити рішення на Exercism, потрібно бути в каталозі, що містить каталоги `Sources` і `Tests`.

```bash
$ exercism submit 
```
