# Вступ

У Common Lisp, як і в багатьох інших мовах, числа бувають кількох типів. Ось два з найпростіших:

## Цілі числа

Як і в багатьох мовах, у Common Lisp є цілі числа.
Це цілі числа без десяткової точки (як-от `-6`, `0`, `25`, `1234` тощо).

Common Lisp не обмежує величину цілих чисел.
Цілі числа можуть бути як завгодно великими (або малими, якщо вони відʼємні).

Загалом, якщо ми працюємо лише з цілими числами, варто надавати перевагу цілим числам, адже під час багатьох обчислень вони не втрачають точність так, як це роблять числа з плаваючою комою.

## Числа з плаваючою комою

Як і в багатьох мовах, у Common Lisp є числа з плаваючою комою.
Це дробові або цілі числа, записані з десятковою точкою (як-от `3.14`, `-1.7`, `99.99`, `2048.0`).

## Арифметика

Для більшості операцій Common Lisp використовує стандартні арифметичні оператори, але дещо вирізняється тим, що застосовує «префіксний запис» замість звичнішого «інфіксного запису».

Наочніше:

```lisp
;; Infix-notation (non-lisp languages)
1 + 2 + 3 + 4 + 5 ; => 15
;; Prefix-notation (lisp languages)
(+ 1 2 3 4 5)     ; => 15
```

Хоча префіксний запис перетворює деякі операції, як-от `2 + 2`, на дещо незвичну форму `(+ 2 2)`, він значно полегшує роботу з кількома числами водночас.

### Основна математика

У Common Lisp є всі типові функції: `+`, `-`, `*`, `/` для додавання, віднімання, множення й ділення.

Коли маємо справу з діленням, може знадобитися дізнатися остачу від ділення. Для цього є функція `mod` (від modulo), яка приймає число та дільник як аргументи:

```lisp
(mod 4 2)  ; => 0
(mod 2 4)  ; => 2
(mod 10 3) ; => 1
```

### Порівняння чисел

Нарешті, порівнювати різні числа може бути корисно за допомогою таких функцій, як `=` (дорівнює), `/=` (не дорівнює) та `>=` (більше або дорівнює).
Коли ці порівняння істинні (як-от `(= 1 1)`), вони повертають `T`, а коли хибні (як-от `(> 0 1)`), то повертають `NIL`.
