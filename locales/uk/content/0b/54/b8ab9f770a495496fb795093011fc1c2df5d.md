# Ігнорувати

## Додаткові параметри командного рядка jq

У тестах ми помітимо додаткові параметри для `jq`.

```sh
run jq -s -R -c -f flower-field.jq << 'END_INPUT'
```

Що це за параметри?

- `-s`

  Це режим «slurp».
  Замість того щоб обробляти вхідні дані як потік JSON-обʼєктів,
  усі вхідні дані буде зібрано в один масив.

  ```sh
  $ seq 5 | jq -c '.'
  1
  2
  3
  4
  5
  $ seq 5 | jq -s -c '.'
  [1,2,3,4,5]
  ```

- `-R`

  Можливо, ми вже бачили `-r`, який виводить «сирі» рядки тексту (англ. string), тобто без лапок.
  Цей параметр робить навпаки.
  Кожен рядок вхідних даних вважається рядком тексту.

  Два приклади:

  ```sh
  $ seq 5 | jq -R -c .
  "1"
  "2"
  "3"
  "4"
  "5"

  $ echo 42 | jq '. * 2'      # input is a JSON number
  84
  $ echo 42 | jq -R '. * 2'   # input is a JSON string
  "4242"
  ```

Коли ми поєднуємо ці два параметри, ми _не_ отримаємо масив рядків тексту:
ми отримаємо всі вхідні дані як один рядок тексту, разом із символами нового рядка в кінці кожного рядка.

```sh
$ seq 5 | jq -s -R -c .
"1\n2\n3\n4\n5\n"
```

Впоратися з цим - частина складності цієї вправи.
