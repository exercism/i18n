# Заповнювач

## Нові концепції AWK

Це перша вправа, де рішення не є скриптом «main».
Мета - написати бібліотеку функцій, яку можна включати в інші програми awk.
У цій вправі ми побачимо кілька цікавих нових концепцій.

Наведені далі розділи з позначкою «(gawk)» описують розширення, властиві саме GNU awk.

### Читання з файлу

У цій вправі ми будемо читати дані з файлу, а не з основного вхідного потоку. 
Прочитаймо про [`getline`][getline] у посібнику Gnu awk, зокрема про форми `Getline/File` та `Getline/Variable/File`.

### Більше про масиви

Двовимірний масив може стати способом реалізувати це рішення.
GNU awk має два способи його подати:

* [багатовимірні масиви][multi]
* [масиви масивів][a-of-a] <sup><sup>(gawk)</sup></sup>

### Файли для включення <sup><sup>(gawk)</sup></sup>

Звернімо увагу на директиву [`@include`][d-include] у тестовому файлі.  
Вона вказує gawk прочитати й обчислити вказаний файл.

### Простори імен <sup><sup>(gawk)</sup></sup>

Усі змінні awk глобальні (крім параметрів функцій, які локальні в межах функції).
Існує висока ймовірність збігу імен, особливо коли включають сторонні бібліотеки. 
[Простори імен][namespaces] - це спосіб розмежувати, де зберігаються змінні.
Звернімо увагу на директиву [`@namespace`][d-namespace] у файлах цієї вправи.

Типовий простір імен має назву «awk». 
Наявність типового простору імен дає програмісту змогу викликати вбудовану функцію awk зсередини функції в іншому просторі імен.

### Як передаються параметри функцій

Параметри-масиви передаються **за посиланням**.
Зміни, зроблені з масивом у функції, видно тому, хто викликав функцію.

Параметри, що не є масивами, передаються **за значенням**.

Для _нетипізованих_ параметрів усе залежить від того, що функція з ними робить:
- якщо функція ініціалізує його як масив, він стає параметром, переданим за посиланням;
- якщо функція ініціалізує його як скалярне значення, тобто число або рядок тексту (англ. string), то це не посилання.

Повні подробиці можна знайти в посібнику, у розділі [Передавання аргументів функції за значенням або за посиланням][pass-by].

#### Локальні змінні

Локальні (у межах функції) змінні можна створити, використовуючи параметри, що передаються «за значенням».
Не є помилкою передати у функцію менше значень, ніж кількість перелічених параметрів;
зайві параметри залишаються «нетипізованими», доки їх не використають.
Вони доступні для присвоєння скалярних значень у функції, які не зберігаються в глобальному просторі імен.

- Якщо присвоїти параметру скалярне значення, воно локальне для функції.
- Якщо присвоїти скаляр змінній, **не** названій у списку параметрів, ця змінна глобальна.

За домовленістю в сигнатурі функції спочатку йдуть очікувані параметри, потім пропуск (пробільні символи), а далі локальні параметри.
Приклад:

```awk
function add(a, b,    total) {
    # here, `typeof(total)` is "untyped"
    total = a + b
    # now, `typeof(total)` is "number"
    return total
}

BEGIN {
    sum = add(5, 10)
    print sum             # 15
    print typeof(total)   # untyped, meaning "total" is unused in this scope
}
```
