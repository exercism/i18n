# Додаток до інструкцій

## Інструкції, специфічні для треку

Для цієї вправи потрібно визначити **локаль** із назвою `robot`, яка визначає **іменники** `position` і `direction` та **дієслово** `move`.

- Дієслово `create` у локалі `robot` приймає початкові позицію та напрямок як масив коробок.
    
    ```j
      r=. (0 0;'north') conew 'robot'
    ```
- `move` оновлює значення `position` і `direction` в **екземплярі**, який було створено.
    ```j
      r=. (0,0;'north') conew 'robot'
      
      NB. initial state
      NB. ====================================
      position__r
        0 0
      direction__r
        north
      
      NB. new states after `move` is executed 
      NB. ====================================
      move__r 'LA'
      position__r
        _1 0
      direction__r
        west      
    ```
