# Про

Функція називається [хвостово-рекурсивною][recursion-tc], якщо _останнє_, що вона виконує, - це виклик самої себе.

Щоразу, коли викликається будь-яка функція, _стековий кадр_ з її локальними змінними, аргументами тощо кладеться на вершину [стека викликів функцій][call-stack]. Коли функція повертає результат, стековий кадр знімається зі стека.

Хвостово-рекурсивні функції дають змогу застосувати [оптимізацію хвостових викликів][tail-call-optimization]. Це оптимізація, яка дозволяє наступному виклику функції повторно використати останній стековий кадр, бо попередній функції він уже точно не потрібен. Це зменшує ризик переповнення стека викликів функцій, тобто ситуації, коли кадрів у стеку так багато, що не лишається памʼяті, щоб створити ще один.

- Щоб досягти хвостової рекурсії в Elixir, через правила незмінності даних часто потрібен акумулятор.

  - Акумулятор - це змінна, яку передають далі в рекурсивному виклику, зберігаючи поточний стан рекурсивної функції _на цей момент_, доки в базовому випадку не буде повернено остаточний результат.

    ```elixir
    # Count the length of a list without an accumulator
    def count([]), do: 0
    def count([_head | tail]), do: 1 + count(tail)

    # Count the length of a list with an accumulator
    def count(list), do: do_count(list, 0)

    defp do_count([], count), do: count
    defp do_count([_head | tail], count), do: do_count(tail, count + 1)
    ```

- Працюючи зі списками, памʼятаймо, що вони реалізовані як однозвʼязні списки: додавання на початок дуже швидке, а додавання в кінець дуже повільне.

  ```elixir
  # Reverse a list with an accumulator
  def reverse(list), do: do_reverse(list, [])

  defp do_reverse([], acc), do: acc

  defp do_reverse([head | tail], acc) do
    do_reverse(tail, [head | acc])
  end
  ```
