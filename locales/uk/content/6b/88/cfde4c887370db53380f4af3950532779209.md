# Вступ

Unison представляє значення правда і неправда за допомогою булевого типу (англ. Boolean) `Boolean`. Існує лише два такі значення: `true` і `false`.

```unison
trueVariable = true
falseVariable = false
```

Ми можемо обчислювати булеві вирази за допомогою операторів: і, позначеного `&&` (логічне і); або, позначеного `||` (логічне або); та заперечення, позначеного `not`.

```unison
trueVariable = true && true
falseVariable = true && false

trueVariable = false || true
falseVariable = false || false

trueVariable = not false
falseVariable = not true
```
