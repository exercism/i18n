# Про зрізи

Зрізи в Go схожі на масиви в інших мовах. Вони містять кілька елементів певного типу (або інтерфейсу).

Зрізи в Go базуються на масивах. Масиви мають фіксований розмір. Зріз же натомість дає динамічне за розміром, гнучке представлення елементів масиву.

Зріз записується як `[]T`, де `T` позначає тип елементів у зрізі:

```go
var empty []int                 // an empty slice
withData := []int{0,1,2,3,4,5}  // a slice pre-filled with some data
```

Отримати або встановити елемент за заданим індексом із відліком від нуля можна за допомогою квадратних дужок (`[]`):

```go
withData[1] = 5
x := withData[1] // x is now 5
```

Новий зріз можна створити з наявного зрізу, взявши діапазон елементів.
Знову використовуємо квадратні дужки, але цього разу вказуємо і початковий індекс (включно), і кінцевий (не включно).
Якщо не вказати початковий індекс, він типово дорівнює 0.
Якщо не вказати кінцевий індекс, він типово дорівнює довжині зрізу.

```go
newSlice := withData[2:4]
// => []int{2,3}
newSlice := withData[:2]
// => []int{0,1}
newSlice := withData[2:]
// => []int{2,3,4,5}
newSlice := withData[:]
// => []int{0,1,2,3,4,5}
```

Додати елементи до зрізу можна за допомогою функції `append`.
Нижче ми додаємо `4` і `2` до зрізу `a`.

```go
a := []int{1, 3}
a = append(a, 4, 2)
// => []int{1,3,4,2}
```

`append` завжди повертає новий зріз, і коли ми просто хочемо додати елементи до наявного зрізу, зазвичай ми присвоюємо результат назад тій самій змінній зрізу, яку передали першим аргументом, як це зроблено вище.

`append` також можна використати, щоб обʼєднати два зрізи:

```go
nextSlice := []int{100,101,102}
newSlice  := append(withData, nextSlice...)
// => []int{0,1,2,3,4,5,100,101,102}
```

## Індекси у зрізах

Роботу з індексами зрізів слід завжди захищати перевіркою, яка переконується, що індекс справді існує.
Якщо цього не зробити, вся програма впаде.

## Порожні зрізи

`nil`-зріз - це типовий порожній зріз.
Він не має жодних недоліків порівняно зі зрізом без значень.
Функція `len` працює з `nil`-зрізами, елементи можна додавати, не ініціалізуючи його, і так далі.
Створюючи новий зріз, краще взяти `var s []int` (`nil`-зріз), а не `s := []int{}` (порожній зріз, не `nil`).

## Продуктивність

Коли ми створюємо зрізи, які заповнюватимемо в циклі, є очевидний спосіб підвищити продуктивність, якщо відомий кінцевий розмір зрізу.
Головне - мінімізувати кількість виділень памʼяті, а це досить дорога операція, яка відбувається, коли зріз виростає за межі виділеного обсягу памʼяті.
Найбезпечніше - вказати місткість `cap` для зрізу через `s := make([]int, 0, cap)`, а потім додавати елементи до зрізу через `append` як завжди.
Так памʼять під `cap` елементів виділяється одразу, хоч довжина зрізу поки що нульова.
На практиці `cap` часто дорівнює довжині іншого зрізу: `s := make([]int, 0, len(otherSlice))`.

## Append не є чистою функцією

Функція `append` у Go оптимізована для продуктивності, тому не копіює вхідний зріз.
Це означає, що початковий зріз (перший параметр `append`) іноді змінюватиметься.
