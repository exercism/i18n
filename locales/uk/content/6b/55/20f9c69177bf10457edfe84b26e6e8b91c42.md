# Інструкції

Наша команда працює над застосунком для метеорології.
Вона визначила API з різними типами і константами для метеорологічних даних у файлі `meteorology.go`.

Наше завдання - додати до всіх типів відповідні методи `String`, щоб вони реалізовували інтерфейс `Stringer`.

## 1. Реалізуйте інтерфейс `Stringer` для типу `TemperatureUnit`

Після нетривалого обговорення команда вирішила, що одиницею температури буде `Celsius` або `Fahrenheit`.
Значення мають бути відформатовані так, як показано в прикладах нижче.

Зробіть так, щоб тип `TemperatureUnit` реалізовував інтерфейс `Stringer`, додавши до нього метод `String`.
Цей метод має повертати рядок тексту (англ. string) `"°C"`, якщо одиниця температури - це `Celsius`, або `"°F"`, якщо одиниця температури - це `Fahrenheit`.

```go
celsiusUnit := Celsius
fahrenheitUnit := Fahrenheit

celsiusUnit.String()
// => °C
fahrenheitUnit.String()
// => °F
fmt.Sprint(celsiusUnit)
// Output: °C
```

## 2. Реалізуйте інтерфейс `Stringer` для типу `Temperature`

Значення температури складаються з цілого числа та одиниці температури.
Їх слід форматувати так, як у прикладах нижче.

Щоб це працювало, зробіть так, щоб тип `Temperature` реалізовував інтерфейс `Stringer`, додавши до нього метод `String`.
Цей метод має повертати рядок тексту з числовим значенням температури та одиницею температури, розділеними пробілом: `<temperature> <unit>`:

```go
celsiusTemp := Temperature{
    degree: 21,
    unit: Celsius,
}
celsiusTemp.String()
// => 21 °C
fmt.Sprint(celsiusTemp)
// Output: 21 °C

fahrenheitTemp := Temperature{
    degree: 75,
    unit: Fahrenheit,
}
fahrenheitTemp.String()
// => 75 °F
fmt.Sprint(fahrenheitTemp)
// Output: 75 °F
```

## 3. Реалізуйте інтерфейс `Stringer` для типу `SpeedUnit`

Після тривалих обговорень команда вирішила, що одиницею швидкості вітру буде `KmPerHour` або `MilesPerHour`.
Значення мають бути відформатовані так, як у прикладах нижче.

Щоб це працювало, зробіть так, щоб тип `SpeedUnit` реалізовував інтерфейс `Stringer`, додавши до нього метод `String`.
Цей метод має повертати рядок тексту `"km/h"`, якщо одиниця швидкості - це кілометри за годину, або `"mph"`, якщо одиниця швидкості - це милі за годину:

```go
mphUnit := MilesPerHour
mphUnit.String()
// => mph
fmt.Sprint(mphUnit)
// Output: mph

kmhUnit := KmPerHour
kmhUnit.String()
// => km/h
fmt.Sprint(kmhUnit)
// Output: km/h
```

## 4. Реалізуйте інтерфейс `Stringer` для `Speed`

Значення швидкості вітру складаються з цілого числа та одиниці швидкості.
Їх слід форматувати так, як у прикладі нижче.

Щоб це працювало, зробіть так, щоб тип `Speed` реалізовував інтерфейс `Stringer`, додавши до нього метод `String`.
Цей метод має повертати рядок тексту з числовим значенням швидкості та одиницею швидкості, розділеними пробілом: `<speed> <unit>`:

```go
windSpeedNow := Speed{
    magnitude: 18,
    unit: KmPerHour,
}
windSpeedNow.String()
// => 18 km/h
fmt.Sprintf(windSpeedNow)
// Output: 18 km/h

windSpeedYesterday := Speed{
    magnitude: 22,
    unit: MilesPerHour,
}
windSpeedYesterday.String()
// => 22 mph
fmt.Sprint(windSpeedYesterday)
// Output: 22 mph
```

## 5. Реалізуйте інтерфейс `Stringer` для типу `MeteorologyData`

Метеорологічні дані вказують місцеположення, температуру, напрямок вітру, швидкість вітру та вологість.
Їх слід форматувати так, як у прикладі нижче:

Щоб це працювало, зробіть так, щоб тип `MeteorologyData` реалізовував інтерфейс `Stringer`, додавши до нього метод `String`.
Цей метод має повертати метеорологічні дані в такому форматі:

```text
<location>: <temperature>, Wind <wind_direction> at <wind_speed>, <humidity>% Humidity
```

```go
sfData := MeteorologyData{
    location: "San Francisco",
    temperature: Temperature{
        degree: 57,
        unit: Fahrenheit
    },
    windDirection: "NW",
    windSpeed: Speed{
        magnitude: 19,
        unit: MilesPerHour
    },
    humidity: 60
}

sfData.String()
// => San Francisco: 57 °F, Wind NW at 19 mph, 60% Humidity
fmt.Sprint(sfData)
// Output: San Francisco: 57 °F, Wind NW at 19 mph, 60% Humidity
```
