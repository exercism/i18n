# Про

Булеві значення (англ. Boolean) у F# представлені типом `bool`, значення якого можуть бути або `true`, або `false`.

F# підтримує три [логічні оператори][operators]: `not` (логічне заперечення), `&&` (логічне і) та `||` (логічне або). Оператори `&&` та `||` використовують _скорочене обчислення_, що означає, що праву частину оператора буде обчислено лише за потреби.

```fsharp
true || false // => true
true && false // => false
```

Кожен із трьох логічних операторів має різний [_пріоритет операторів_][precedence]. Як наслідок, вони обчислюються в такому порядку: спочатку `not`, потім `&&`, і нарешті `||`. Якщо потрібно «обійти» ці правила, можна взяти булевий вираз у дужки (`()`), адже дужки мають ще вищий пріоритет операторів.

```fsharp
not true && false   // => false
not (true && false) // => true
```

[precedence]: https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/symbol-and-operator-reference/#operator-precedence
