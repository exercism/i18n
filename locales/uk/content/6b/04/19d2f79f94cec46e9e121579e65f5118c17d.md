# Instructions

У цій вправі ми реалізуємо частину набору допоміжних процедур, які допомагають розробнику очищати імена SqueakyClean.

У цих 4 завданнях ми поступово побудуємо метод `clean`.
Правильне імʼя SqueakyClean складається з нуля або більше літер і символів підкреслення.

У всіх випадках вхідний рядок тексту (англ. string) гарантовано не є null. Зауважмо, що метод `clean` має вважати порожній рядок тексту допустимим.

## 1. Заміна будь-яких пробілів на символи підкреслення

Реалізуйте (_статичний_) метод `SqueakyClean.clean()`, який замінює всі пробіли на символи підкреслення. Це стосується також пробілів на початку й у кінці.

```java
SqueakyClean.clean("my   Id");
// => "my___Id"
```

## 2. Перетворення kebab-case на camelCase

Змініть (_статичний_) метод `SqueakyClean.clean()`, щоб він перетворював kebab-case на camelCase.

```java
SqueakyClean.clean("a-bc");
// => "aBc"
```

## 3. Перетворення leetspeak на звичайний текст

Змініть (_статичний_) метод `SqueakyClean.clean()`, щоб він перетворював [leetspeak][leet-speak] на звичайний текст.

Для простоти ми будемо замінювати лише `4`, `3`, `0`, `1` і `7` на `a`, `e`, `o`, `l` і `t` відповідно.

```java
SqueakyClean.clean("H3ll0 W0rld");
// => "Hello_World"
SqueakyClean.clean("4 73s7");
// => "a_test"
```

## 4. Відкидання символів, які не є літерами

Змініть (_статичний_) метод `SqueakyClean.clean()`, щоб він відкидав усі символи, які не є літерами.

```java
SqueakyClean.clean("a$#.b");
// => "ab"
```

[leet-speak]: https://en.wikipedia.org/wiki/Leet
