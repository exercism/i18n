# Вступ

## Порівняння

У C++ можна порівнювати значення за допомогою операторів порівняння.

| Порівняння        | Оператор  |
| ------------------| --------- |
| дорівнює          | `==`      |
| не дорівнює       | `!=`      |
| менше             | `<`       |
| менше або дорівнює | `<=`     |
| більше            | `>`       |
| більше або дорівнює | `>=`    |

Результат цих порівнянь завжди є булевим значенням (англ. Boolean):

```cpp
int a{3};

bool eq1 = a != 4; // true

bool eq2 = a > 5;  // false
```

Оператори `==` та `!=` перевіряють, чи одне значення дорівнює іншому, чи ні, відповідно.
Ось кілька поширених прикладів:

```cpp
bool eq3 = 2 == 3; // false, integer comparison

bool eq4 = 2.1 != 2.2; // true, float comparison

bool eq5 = "hello" == "hello"; // true, string comparison
```

Інші оператори перевіряють, чи одне значення більше за (`>`), більше або дорівнює (`>=`), менше за (`<`) і менше або дорівнює (`<=`) іншому значенню.
Таке порівняння доступне для чисел і рядків тексту (англ. string).
Під час порівняння рядків тексту використовується порядок словника (його також називають лексикографічним порядком).

```cpp
bool eq6 = 2 > 3; // false, integer comparison

bool eq7 = 1.2 < 1.3; // true, float comparison

bool eq8 = "Hello" < "World"; // true, string comparison
```

## Умовні конструкції

Умовні конструкції в C++ схожі на умовні конструкції в інших мовах.
Базовим типом будь-якої умовної операції є тип `bool`, який може мати значення `true` або `false`.
Умовні конструкції часто використовують як механізми керування потоком, щоб перевіряти різні умови.

Можна використати умовну конструкцію `if`, яка виконує свій код, якщо відповідна умова `true`, ось так:

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

У сценаріях із більш ніж одним випадком багато умовних конструкцій `if` можна обʼєднати в ланцюжок за допомогою конструкцій `else if` та `else`.

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

Починаючи з C++17, умовні конструкції if також можуть містити коротку інструкцію ініціалізації, яку можна використати для ініціалізації однієї або кількох змінних для конструкції if.
Наприклад:

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> Примітка: будь-які змінні, створені в ініціалізації, не можна використовувати після завершення умовної конструкції if.
