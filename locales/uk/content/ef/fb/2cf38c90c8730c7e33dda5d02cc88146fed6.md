# Вступ

Винятки в C# дають структурований, однаковий і типобезпечний спосіб обробки помилкових ситуацій, які виникають під час виконання. Належна обробка винятків і помилок важлива, коли ми намагаємося запобігти аварійному завершенню застосунку.

У C# усі винятки мають базовий тип `System.Exception`. Він містить важливі властивості, як-от `Message`, що містить зрозумілий людині опис причини, з якої виняток було викинуто.

Щоб повідомити, що в певній частині коду має статися помилка, потрібно створити новий обʼєкт винятку, а потім викинути його за допомогою ключового слова `throw`:

```csharp
using System;
static int Square(int number)
{
    if (number >= 46341)
    {
        throw new ArgumentException($"Argument {number} cannot be higher than 46340 as its' square doesn't fit into int type.");
    }
    return number * number;
}
```

Коли виняток викидається, середовище виконання має знайти фрагмент коду, відповідальний за обробку цього винятку. Якщо відповідного обробника не знайдено, середовище виконання виводить повідомлення про необроблений виняток і зупиняє виконання програми.

Щоб створити обробник винятку, C# використовує інструкцію `try-catch`, яка складається з блоку `try` та однієї або кількох гілок `catch`. Блок `try` повинен містити й захищати код, який може призвести до викидання винятку. Гілки `catch` мають містити код, який керує поведінкою програми після того, як сталася помилка. Важливо зазначити, що порядок винятків після блоку `try` має значення, адже коли перелічено кілька винятків, виконується перша відповідна гілка `catch`.

```csharp
try
{
   if (number == 42)
   {
       throw new ArgumentException("The number cannot be equal to 42.", "number");
   }

   if (number < 0)
   {
      throw new ArgumentOutOfRangeException("number", "The number cannot be negative.");
   }

    // Process number ...
}
catch (ArgumentOutOfRangeException e)
{
    Console.WriteLine($"Number is out of range: {e.Message}.");
}
catch (ArgumentException)
{
    Console.WriteLine("Invalid number.");
}
```
