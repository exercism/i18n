# Додаток до інструкцій

## Інструкції для треку

Історично Elm використовував функціональне реактивне програмування, аж поки не зосередився на використанні Elm Architecture.

Розвʼяжіть цю вправу так, ніби це вебзастосунок на Elm Architecture.
Вихідні дані програми мають бути HTML із такою структурою

```html
<div>
  <dl>
    <dt>State</dt>
    <dd>Ongoing</dd>
    <dt>Word</dt>
    <dd>______</dd>
    <dt>Remaining failures</dt>
    <dd>5</dd>
  </dl>
</div>
```

де `<dl>` - елемент списку описів, `<dt>` - елемент терміна опису, а `<dd>` - елемент деталей опису, усі стандартні елементи HTML.

Якщо сталася помилка, вихідні дані мають мати таку структуру

```html
<div>
  <p>error message</p>
</div>
```
