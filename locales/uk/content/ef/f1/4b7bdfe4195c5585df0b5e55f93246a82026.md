# Про

Усе в Common Lisp є виразом.
Вираз складається або з чогось одного (його називають атомом), або з масиву речей, обмеженого дужками: `()`.

## Цитування

Усі S-вирази, як і символи, можна цитувати:

```lisp
;; This line is evaluated as code
(gimme-foo)  ; => FOO

;; This line is treated as data
'(gimme-foo) ; => (GIMME-FOO)
```

Таке цитування запобігає обчисленню S-виразу і натомість трактує його як дані.
Ось чудова [відповідь на Stack Overflow][so-quoting], де цитування розглядається трохи детальніше.

[so-quoting]: https://stackoverflow.com/questions/134887/when-to-use-or-quote-in-lisp
