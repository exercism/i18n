# Вступ

## `Base.@kwdef`

Макрос `Base.@kwdef` можна використовувати, щоб автоматично визначати конструктори, які приймають ключові аргументи для визначення [структури][struct].
Він також дає змогу задавати типові значення для полів.

Наприклад, таке визначення

```julia
Base.@kwdef struct HumanStats
    birthyear::Int
    height::Int
    mass::Int
    bmi::Float64 = mass / (0.01 * height)^2
end
```

визначає одразу три конструктори

```julia-repl
julia> methods(HumanStats)
# 3 methods for type constructor:
[1] HumanStats(; birthyear, height, mass, bmi) [...]
[2] HumanStats(birthyear::Int64, height::Int64, mass::Int64, bmi::Float64) [...]
[3] HumanStats(birthyear, height, mass, bmi) [...]
```

зокрема конструктор на основі ключових аргументів

```julia-repl
julia> HumanStats(
           birthyear = 2002,
           height = 193,
           mass = 83
       )
HumanStats(2002, 193, 83, 22.28247738194314)
```

тоді як стандартне визначення

```julia
struct HumanStats
    birthyear::Int
    height::Int
    mass::Int
    bmi::Float64
end
```

визначає лише такі два

```julia-repl
julia> methods(HumanStats)
# 2 methods for type constructor:
[1] HumanStats(birthyear::Int64, height::Int64, mass::Int64, bmi::Float64) [...]
[2] HumanStats(birthyear, height, mass, bmi) [...]
```

і вимагало б визначити конструктор на основі ключових аргументів вручну.

### Коли використовувати `Base.@kwdef`?

Конструктори на основі ключових аргументів особливо корисні для створення структур, які приймають велику кількість аргументів, зокрема коли тип чи значення аргументів безпосередньо не повʼязані зі змістом цих аргументів.

Розглянемо таке визначення:

```julia
dirk = BasketballPlayer(1978, 1994, 2019, 213, 111, 42, 1998, [2011], 31560, 11489, 3651)
```

Без знання визначення типу незрозуміло, що означає кожне значення.
І навіть якщо визначення відоме, порядок імовірно доведеться знову й знову звіряти.

Однак, коли ми використовуємо конструктор на основі ключових аргументів, їхній зміст відразу очевидний:

```julia
dirk = BasketballPlayer(
    birthyear = 1978,
    career_start = 1994,
    career_end = 2019,
    height = 213,
    weight = 111,
    number = 42,
    drafted = 1998,
    championships = [2011],
    points = 31560,
    rebounds = 11489,
    assists = 3651
)
```

~~~~exercism/caution
`Base.@kwdef` не експортується й не задокументований у посібнику, а отже, не є частиною [публічного API Julia][public-api].
Це означає, що його інтерфейс технічно не гарантовано стабільний і може змінитися між мінорними оновленнями Julia.

Однак макрос широко використовується в екосистемі, і малоймовірно, що його змінять у несумісний спосіб.
