# Вступ

Swift надає вбудований тип [`Bool`][bools] для представлення булевих значень (англ. Boolean): `true` та `false`.

## Логічні оператори

Swift має три [логічні оператори][logical-operators] для поєднання й обчислення булевих виразів: `!` (логічне заперечення), `&&` (логічне і) та `||` (логічне або).

### Логічне і (`&&`)

Оператор [_і_][and] (`&&`) повертає `true`, тільки якщо обидва операнди дорівнюють `true`.
Якщо хоч один з операндів дорівнює `false`, він повертає `false`.
З кожного боку від символу `&&` ставимо вираз або булеве значення:

```swift
true && true  // true
true && false // false
```

### Логічне або (`||`)

Оператор [_або_][or] (`||`) повертає `true`, якщо **принаймні один** з операндів дорівнює `true`.
Він повертає `false`, лише коли обидва операнди дорівнюють `false`.
З кожного боку від символу `||` ставимо вираз або булеве значення:

```swift
true || true   // true
true || false  // true
false || false // false
```

### Логічне заперечення (`!`)

Оператор [_заперечення_][not] (`!`) інвертує булеве значення.
Він повертає `true`, якщо значення дорівнює `false`, і `false`, якщо значення дорівнює `true`.
Ставмо оператор `!` безпосередньо перед значенням або виразом:

```swift
!true  // false
!false // true
```

## Використання дужок (`()`)

Ми можемо використовувати [дужки][explicit-parentheses], щоб групувати вирази й керувати порядком обчислення.
У Swift спершу обчислюється те, що стоїть у дужках:

```swift
true && false && false || true   // true
true && false && (false || true) // false
```

Групування за допомогою дужок також визначає, як оператор заперечення застосовується до складних виразів:

```swift
!true && false   // false (evaluates (!true) first, then false && false)
!(true && false) // true  (evaluates (true && false) first to false, then !false)
```

~~~~exercism/note
Використовуймо дужки тоді, коли потрібно уточнити порядок обчислення або зробити складні умови легшими для читання.
Не додаваймо зайвих дужок, якщо порядок обчислення й без них зрозумілий.
~~~~
