# Булеві значення

У Crystal є тип, відомий як [`Bool`][bools].
Він представляє булеві значення (англ. Boolean): `true` і `false`.

## Логічні оператори

У Crystal є три логічні оператори (`!`, `||`, `&&`), які поєднують булеві значення й утворюють вирази, що дають різні значення.

### Логічне і (`&&`)

[Логічне і][and] у Crystal позначається `&&` і повертає `true`, якщо обидва значення істинні; інакше повертає `false`.
Коли ми використовуємо логічне і, одне булеве значення ставимо праворуч від `&&`, а друге ліворуч.

```crystal
true && true
# => true

true && false
# => false
```

### Логічне або (`||`)

[Логічне або][or] у Crystal позначається `||` і повертає `true`, якщо **принаймні одне** з наданих значень істинне. 
Якщо обидва значення хибні, то повертається `false`.
Коли ми використовуємо логічне або, одне булеве значення ставимо праворуч від `||`, а друге ліворуч.

```crystal
true || true
# => true

true || false
# => true

false || false
# => false
```

### Логічне заперечення (`!`)

Логічне заперечення у Crystal позначається `!` і повертає `true`, якщо задане булеве значення хибне, та повертає `false`, якщо задано `true`.
Коли ми використовуємо логічне заперечення, булеве значення ставимо після оператора (`!`).

```crystal
!true
# => false

!false
# => true
```

## Використання дужок (`()`)

Коли ми працюємо з булевими значеннями, дужки допомагають визначити, які булеві значення обчислити першими.
Результат може відрізнятися залежно від того, як розставлено дужки.
У Crystal спершу обчислюється те, що стоїть у дужках.

```crystal
true && false && false || true
# => true

true && false && (false || true)
# => false
```

Оскільки те, що в дужках, обчислюється першим, у наведеному нижче прикладі логічне заперечення застосується до виразу в дужках.

```crystal
!true && false
# => false

!(true && false)
# => true
```

~~~~exercism/note
Дужки варто використовувати лише тоді, коли вони впливають на результат; інакше їх слід опускати.
~~~~

## Істинні та хибні значення

У Crystal «хибними» вважаються такі значення: `false`, `nil` і нульові вказівники; **усе інше** вважається «істинним».
Ці значення можна використовувати з логічними операторами, згаданими вище.

```crystal

true && nil
# => false

false && 4
# => false

true || nil
# => true
```

## Домовленості щодо назв методів із булевими значеннями

У Crystal прийнято завершувати назву методу, який повертає істинне чи хибне значення, знаком питання (`?`).
Здебільшого такий метод повертає булеве значення, але це не обовʼязково.
Це означає, що метод можна використовувати там, де потрібне істинне чи хибне значення, наприклад, як умову для умовної конструкції `if`:

```crystal
def exchange(value)
    if value.nil?
        value = 5
    end
    value
end

exchange(10)
# => 10

exchange(nil)
# => 5
```

Методи зі знаком питання в кінці назви, які не повертають булевого значення, часто натомість повертають `nil`. `nil` _схожий на `None` або `null` з інших мов_.
