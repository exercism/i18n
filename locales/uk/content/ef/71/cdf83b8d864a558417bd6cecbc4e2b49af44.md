# Зневадження

Оскільки поточний засіб запуску тестів використовує [PonyTest](https://stdlib.ponylang.io/pony_test--index/), актор Main описано у файлі test.pony, і редагувати його як частину рішення не слід.

Як і заведено в застосунках Pony, ми не надаємо доступ до `Env`, якщо він не потрібен. Це означає, що майже в усіх випадках ми не можемо скористатися зневадженням у стилі printf через `env.out.print()`.

Утім, у Pony є модуль [debug](https://stdlib.ponylang.io/debug--index/), який дає змогу програмам, скомпільованим із прапорцем `-d`, отримати особливий доступ до STDOUT і STDERR без доступу до `Env`.

Якщо нам потрібне зневадження в стилі printf, варто скористатися саме цією можливістю.

Приклад зневадження:

```pony
use "debug"

actor Main
  new create(env: Env) =>
    MySolution.examplefn("First String", 42)

primitive MySolution
  fun examplefn(arg1: String, arg2: USize) =>
    Debug.out("arg1: " + arg1 + ", arg2: " + arg2.string() + " were provided to MySolution.examplefn()")
```
