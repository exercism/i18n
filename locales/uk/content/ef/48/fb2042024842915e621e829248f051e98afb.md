## Pairs

`Pair` — це структура даних, яка містить рівно два елементи, доступні через поля `first` і `second`.

Їх можна створити за допомогою `x => y`:

```julia-repl
julia> p = 3 => true
3 => true

julia> p.first
3

julia> p.second
true
```

Елементи `Pair` можуть бути різних типів:

```julia-repl
julia> typeof(p)
Pair{Int64,Bool}
```

У Julia `Pair` має два поширені застосування: словники та заміни.

### Заміни

Багато методів заміни приймають `Pair` як аргумент, щоб було зрозуміло, який саме елемент замінюється.
Це дає змогу записати так:

```julia-repl
julia> replace!([1, 3, 4, 1], 4 => 0)
4-element Array{Int64,1}:
 1
 3
 0
 1
```

де кожну `4` в колекції замінено на `0`, замість менш зрозумілого синтаксису

```julia
replace!([1, 3, 4, 1], 4, 0) # this method doesn't exist
```
