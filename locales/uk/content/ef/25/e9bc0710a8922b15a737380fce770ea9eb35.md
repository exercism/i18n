# Докладніше

Оператор `|>` називається оператором конвеєра. За його допомогою можна поєднувати виклики функцій у ланцюжок так, що значення, повернене попереднім викликом функції, передається наступному виклику функції.

```gleam
"hello"
|> string.uppercase
|> string.append("?!")
// -> "HELLO?!"
```

Наведений вище код еквівалентний такому:

```gleam
string.append(string.uppercase("hello"), "?!")
```

Оператор конвеєра передає значення або як перший аргумент у виклик функції, або як єдиний аргумент у новий виклик, вибираючи той варіант, який дасть правильний тип.

```gleam
100
|> function_that_takes_two_arguments(1)

// Is equivalent to
function_that_takes_two_arguments(100, 1)
```

```gleam
100
|> function_that_returns_a_function(1)

// Is equivalent to
function_that_returns_a_function(1)(100)
```

Іноді нам треба передати значення в іншу позицію. У такому разі можна використати заповнювач `_`, щоб позначити, куди саме слід вставити значення.

```gleam
100
|> some_function(1, _, 2)
```
