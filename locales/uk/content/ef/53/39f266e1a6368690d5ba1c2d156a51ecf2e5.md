# Вказівки

Ми працюємо в престижній юридичній фірмі, яка спеціалізується на незвичайних запитах щодо заповітів.

У цій вправі ми відкриємо таємниче сховище.
Ми виконуємо обовʼязки виконавця заповіту та зберемо секретні коди трьох родин, які довго зберігалися в таємниці, щоб отримати номер рахунку та відповідний код.

Щоб жодна родина не могла відкрити сховище самостійно, відкрити його можна лише, поєднавши їхні знання із секретним модифікатором, який нам відомий із заповіту.

На нас чекають три завдання, і всі вони повʼязані з тим, щоб допомогти родинам відкрити сховище.

# 1. Займіть своє місце перед родинами та розкладіть папери

Визначте простір імен `EstateExecutor`.
Код із наступних завдань потрібно визначити в тілі простору імен `EstateExecutor`.

```ruby
class SomeName
  # The space between the class/module name
  # and the `end` keyword
  # is called body of the  namespace.
end
```

# 2. Знайдіть секретний номер рахунку

Це наш зоряний час.
Лише в нас є секретний ключ-модифікатор, щоб розкрити секретний номер рахунку.

Визначте метод `assemble_account_number(secret_modifier)`, який приймає секретний модифікатор типу `Integer` як аргумент і повертає зібраний номер рахунку типу `Integer`.

Щоб отримати правильний номер, потрібно підсумувати `bank_number_part` кожної з трьох родин.

# 3. Останній крок: введіть секретний код

У заповіті нас просять додати спочатку всі сині, а потім усі червоні фрагменти.
Підсумковий код отримуємо, перемноживши обидві суми.

Визначте метод `assemble_code`, який повертає підсумковий код, поєднуючи фрагменти від трьох родин в один результат типу `Integer`.
Метод не має аргументів і спирається лише на інформацію у відповідних просторах імен родин.
