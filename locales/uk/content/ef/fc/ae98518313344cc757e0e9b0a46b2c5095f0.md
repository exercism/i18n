# Тести

Щоб запустити тести для вправ із SQLite, виконайте такі кроки:

1. Відкрийте термінал, яким зручно користуватися.
2. Перейдіть до каталогу з відповідним файлом `${slug}_test.sql`, де `${slug}` позначає назву вправи, записану через дефіси замість пробілів, усіма малими літерами.
3. Виконайте таку команду: 
```bash
sqlite3 -bail < ${slug}_test.sql
```
  
Ця команда ініціалізує SQLite з порожньою базою даних, запускає тести, указані у `${slug}_test.sql`, і після цього завершує роботу.
`-bail` гарантує, що виконання коду зупиниться, якщо код некоректний.

Результати тестів показуються в консолі у вигляді таблиці: опис кожного тесту, його статус (наприклад, «pass») і повідомлення, якщо статус має значення «fail».

## Налагодження

Для налагодження можна використовувати інструкції `SELECT`.
Вихідні дані буде передано у `user_output.md` і показано у веб-редакторі, якщо тести не проходять.

## Деталі виконання

Файл тестів (`${slug}_test.sql`) - доволі складний скрипт.
Ось огляд того, що він робить.

1. Створює таблиці, читаючи `create_fixture.sql`.
   Він створює таблиці, а потім наповнює їх значеннями з `data.csv` для коректних даних і з `error_data.csv` для записів, які мають спричинити помилку.
   Під час тестів перевіряються лише ці таблиці; зміни в інших таблицях ігноруються.
2. Запускає код рішення, читаючи файл `${slug}.sql`.
3. Створює таблиці для збереження тестових випадків і результатів.
4. Заповнює результати тестів на основі даних у таблиці (або таблицях), які оновив код рішення.
5. Показує результати тестів (pass або fail і необовʼязкові подробиці).
Ці CSV-файли містять потрібні дані для тестування різних сценаріїв.
