# Тести

Щоб завантажити вправу, наприклад `hello-world`, відкрийте термінал і виконайте:

```bash
exercism download --track roc --exercise hello-world
```

Потім перейдіть до каталогу вправи та відредагуйте код, щоб розвʼязати вправу. Наприклад:

```bash
cd {your Exercism folder}/roc/hello-world
edit HelloWorld.roc
```

Кожна вправа містить набір тестів. Запустити тести можна командою `roc test`, наприклад:

```
roc test hello-world-test.roc
```

Якщо вправу розвʼязано, ми побачимо 0 невдалих тестів, наприклад:

```
All (5) tests passed in 123.4 ms.
```

Якщо ж у коді є помилки, вони матимуть такий вигляд:

```
── EXPECT FAILED in hello-world-test.roc ───────────────────────────────────────

This expectation failed:

6│  expect hello == "Hello, World!"
    ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^


1 failed and 0 passed in 123.4 ms.
```

Це допоможе виправити код. Коли код запрацює, його можна надіслати командою `exercism submit` (докладніше дивіться в `HELP.md` у каталозі вправи).
