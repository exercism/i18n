# Вказівки

Ліллі, інопланетянка з планети Лісп, любить готувати. Вона хоче влаштувати вечірку з піцою для своїх друзів, але, щоб оптимально використати інгредієнти, їй хотілося б точно знати, скільки кожного з них знадобиться, перш ніж почати.

Щоб розвʼязати цю задачу, Ліллі написала чернетку програми, яка автоматизує частину планування, але їй потрібна наша допомога, щоб її завершити.
Допоможемо Ліллі влаштувати ідеально пропорційну вечірку з піцою?

## 1. Пропорція тіста

Почнімо з головного: кожна чудова піца починається зі смачного тіста!

Ліллі любить тонкі хрусткі піци з товстішою скоринкою.
Для середини потрібно незмінно 200 г тіста, а на кожні 20 см скоринки йде 45 г тіста.

На щастя, Ліллі вивела рівняння для грамів тіста (g) з кількості піц (n) та їхнього діаметра (d):

`g = n * (((45 * pi * d) / 20) + 200)`

Ліллі потрібна функція, яка:
* Приймає кількість піц (n) та їхній діаметр (d)
* І повертає потрібну кількість тіста, округлену до найближчого грама (g).

Наприклад, щоб приготувати 4 піци діаметром 30 см:

```lisp
(dough-calculator 4 30) ; => 1648
```

## 2. Трохи соусу

Ліллі ретельно наносить соус, але розмір її піц може виходити різним.

Щоб визначити діаметр (d), вона користується наведеним нижче рівнянням, у якому змінна s означає кількість нанесеного соусу:

`d = square-root of ((40 * s) / (3 * pi))`

Ліллі потрібна функція, яка обчислює діаметр піци (d) з кожного мілілітра нанесеного соусу (s).

Наприклад, якщо Ліллі використала 250 мл соусу:

```lisp
(size-from-sauce 250) ; => 32.57
```

## 3. Трохи сиру, будь ласка

На планеті Ліллі весь сир має форму ідеальних кубів і продається за розміром.
(А чого ж іще чекати? Це ж таки інопланетна планета...)

І знову Ліллі вивела рівняння для кількості піц (n) певного діаметра (d), які можна приготувати з куба сиру з довжиною сторони (l):

`n = (2 * (l^3)) / (3* pi * (d^2))`

Створіть функцію, яка:
* Приймає довжину сторони куба сиру (l) та діаметр піц (d),
* І повертає кількість піц (n), округлену в менший бік.

Наприклад, для куба сиру 25x25x25 см і піц діаметром 30 см:

```lisp
(pizzas-per-cube 25 30) ; => 3
```

## 4. Справедлива частка

Нарешті, Ліллі хоче, щоб кожна піца ділилася на 8 шматків і рівномірно розподілялася між її друзями.

Створіть функцію, яка:
* Приймає кількість піц і кількість друзів
* і повертає `T`, якщо піци розподіляться між друзями порівну, та `NIL` в іншому разі.

Наприклад:

```lisp
;; For splitting 3 pizzas between 4 friends
(fair-share-p 3 4) ; => T
;; For splitting 2 pizzas between 3 friends
(fair-share-p 2 3) ; => NIL
```
