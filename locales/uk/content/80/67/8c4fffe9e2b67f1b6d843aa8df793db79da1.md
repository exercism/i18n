## Булеві значення в R

Значення правди та неправди представлені типом `logical`.
Він містить лише два значення: `TRUE` та `FALSE`.

```R
TRUE
#> [1] TRUE
FALSE
#> [1] FALSE
typeof(TRUE)
#> [1] "logical"
```

## Булеві оператори

У R є пʼять булевих (англ. Boolean) операторів, але на цьому етапі силабусу важливі лише три.
Інші два будуть важливими під час роботи з векторами, про які йдеться в кількох пізніших концепціях.

`&&` (логічне і) - це булеве «і».
Він набуває значення `TRUE`, якщо вирази з *обох* боків від `&&` (і) мають значення `TRUE`.

```R
TRUE && TRUE
#> [1] TRUE
TRUE && FALSE
#> [1] FALSE
```

`||` (логічне або) - це булеве «або».
Він набуває значення `TRUE`, якщо вираз з *будь-якого* боку від `||` (або) має значення `TRUE`.

```R
TRUE || TRUE
#> [1] TRUE
FALSE || TRUE
#> [1] TRUE
```

`!` - це логічне заперечення.
Воно міняє місцями значення `TRUE` та `FALSE`.

```R
!TRUE
#> [1] FALSE
!FALSE
#> [1] TRUE
```

Для довших і складніших виразів краще використовувати дужки, щоб чітко показати, що ми маємо на увазі.

```R
(TRUE || FALSE) && (FALSE && TRUE)
#> [1] FALSE
```
