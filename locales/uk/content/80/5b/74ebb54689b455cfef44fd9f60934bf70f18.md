# Символи

`CHAR` — це один символ, записаний між одинарними лапками.

```sather
   c : CHAR := 'M';
```

## Спеціальні символи

Деякі символи неможливо набрати безпосередньо, тож їх записують зі зворотною скісною рискою:

| Запис | Що це |
| --- | --- |
| `'\n'` | новий рядок |
| `'\t'` | табуляція |
| `'\''` | одинарна лапка |
| `'\\'` | зворотна скісна риска |

## Питання

```sather
'M'.is_alpha      -- true
'7'.is_digit      -- true
'M'.is_upper      -- true
' '.is_space      -- true
'M'.is_alphanum   -- true, a letter or a digit
```

## Регістр

`.upper` і `.lower` змінюють регістр літери й не чіпають нічого іншого, тож їх безпечно застосовувати до символу, який ми не перевіряли.

## Числа

```sather
'a'.int           -- 97
97.char           -- 'a'
```

`.int` і `.char` — точні протилежності. Корисні факти про нумерацію полягають ось у чому: `'a'` до `'z'` ідуть підряд, `'A'` до `'Z'` ідуть підряд, і `'0'` до `'9'` ідуть підряд. Отже:

```sather
   c.int - 'a'.int          -- how far c is along the alphabet
   ('a'.int + n).char       -- the letter n places along
   d.int - '0'.int          -- the value of a digit character
```

## Обертання по колу

Колесо шифру, обертаючись, проходить повз `z` і повертається до `a`. `%` робить саме це:

```sather
   ('a'.int + (c.int - 'a'.int + places) % 26).char
```

`%` у Sather ніколи не дає відʼємного результату, коли права частина додатна, тож це працює і для обертання колеса назад, і вперед.

## Символи та рядки

`STR` — це рядок тексту (англ. string), тобто низка байтів, а `CHAR` — один байт. Для англійського тексту байт — це літера, тож `"Marlowe".size` дорівнює 7, а `"Marlowe"[0]` — це `'M'`. Для тексту з діакритичними знаками чи іншою абеткою одна літера може займати кілька байтів, і ні те, ні інше не справджується.
