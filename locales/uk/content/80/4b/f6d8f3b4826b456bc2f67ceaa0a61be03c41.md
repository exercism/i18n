# Підказки

## 1. Замініть усі пробіли на підкреслення

- [Цей посібник][chars-tutorial] стане в пригоді.
- Отримати `char` з рядка тексту (англ. string) можна за допомогою методу [charAt][char-at].
- Для побудови вихідного рядка тексту варто використати [`StringBuilder`][string-builder].
- Перегляньте документацію [Character][chars-docs], щоб знайти метод для виявлення пробільних символів. Не забудьте, що це статичний метод.
- Літерали `char` записуються в одинарних лапках.

## 2. Перетворіть kebab-case на camel-case

- Перегляньте документацію [Character][chars-docs], щоб знайти метод для перетворення символу на верхній регістр. Не забудьте, що це статичний метод.

## 3. Перетворіть leetspeak на звичайний текст

- Перегляньте документацію [Character][chars-docs], щоб знайти метод для визначення, чи є символ цифрою. Не забудьте, що це статичний метод.

## 4. Пропустіть символи, які не є літерами

- Перегляньте документацію [Character][chars-docs], щоб знайти метод для визначення, чи є символ літерою. Не забудьте, що це статичний метод.
