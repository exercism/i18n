# Вступ

`Rational numbers` (раціональні числа) - це дроби, у яких чисельник і знаменник виражені цілими числами.

Наприклад, ми можемо зберегти `2//3` як точний дріб замість наближеного значення `Float64` `0.6666...`

Перевага в тому, що (окрім крайнього випадку *переповнення цілих чисел*) раціональне число залишається точним, і це дає змогу уникнути помилок округлення, які часто неминучі для чисел з плаваючою комою.

Раціональні числа - досить простий числовий тип, який поводиться майже так, як ми й очікуємо.
Оскільки вони є стандартним типом у Julia ще з ранніх версій, більшість функцій приймає їх на вхід так само, як цілі числа й числа з плаваючою комою.

## Створення раціональних чисел

Створити їх так само просто, як поставити `//` між двома цілими числами.

```julia-repl
julia> 3//4
3//4

julia> a = 3; b = 4;

julia> a//b
3//4
```

Спільні множники автоматично скорочуються, тобто дріб зводиться до «найменших членів»: найменших цілих чисел, які точно представляють дріб, з невідʼємним знаменником.

```julia-repl
julia> 5//15
1//3

julia> 5//-15
-1//3
```

## Арифметика з раціональними числами

Звичайні `arithmetic operators` `+ - * / ^ %` працюють із раціональними числами практично так само, як з іншими числовими типами.

Цілі числа та інші `Rational` можна включати у вираз, і результат теж буде `Rational`.
Якщо у виразі є `float`, результат теж буде `float`, що може призвести до втрати точності.

Якщо потрібен `float`, достатньо функції `float()`, яка перетворює раціональне число.
Цілком нормально використовувати раціональні числа, щоб зберегти точність протягом довгих обчислень, а в кінці перетворити результат на число з плаваючою комою.

```julia-repl
julia> 3//4 + 1//3  # addition
13//12

julia> 3//4 * 1//3  # multiplication
1//4

julia> 3//4 / 1//3  # division
9//4

julia> 3//4 ^ 2  # exponentiation
3//16

julia> 3//4 + 5  # rational and int => rational
23//4

julia> 3//4 + 5.3  # rational and float => float
6.05

julia> float(3//4)  # casting
0.75
```

## Інші операції

У Julia раціональні числа - це просто числа.
Компілятор зазвичай сам перетворює типи, коли це потрібно.

Проте варто памʼятати, що порівняння працюють для дробів зі скінченним десятковим представленням:

```julia-repl
julia> 3//4 == 0.75
true

julia> 3//4 < 0.74
false
```

В інших випадках, щоб порівняти, `Rational` слід привести до `Float`:

```julia-repl
julia> 1//3 == 1/3
false

julia> float(1//3) == 1/3
true
```

Математичні функції приймають раціональні числа на вхід, але можуть повертати результат із плаваючою комою:

```julia-repl
julia> sqrt(9//16)
0.75
```
