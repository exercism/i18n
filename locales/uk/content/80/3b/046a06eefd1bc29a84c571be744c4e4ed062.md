# Додаток до інструкцій

## Примітки щодо реалізації

Визначення інтерфейсу Cipher міститься у файлі `cipher.go`.

Реалізації повинні відповідати інтерфейсу Cipher.

```go
type Cipher interface {
    Encode(string) string
    Decode(string) string
}
```

Передбачається, що `Encode` ігноруватиме всі символи в рядку тексту (англ. string), які не належать до A-Za-z, і вони не потраплять до вихідних даних.
Вихідні дані також буде зведено до нижнього регістру.

Функції, які використовуються для отримання шифрів:

```go
func NewCaesar() Cipher { }

func NewShift(distance int) Cipher { }

func NewVigenere(key string) Cipher { }
```

Аргумент для `NewShift` має бути в діапазоні від 1 до 25 або від -1 до -25.
Нуль не допускається.
За некоректних аргументів `NewShift` повертає nil.

Аргумент для `NewVigenere` має складатися лише з малих літер від a до z.
Значення, що складаються лише з літери «a», не допускаються.
За некоректних аргументів `NewVigenere` повертає `nil`.
