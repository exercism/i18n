# Підказки

## 1. Витягти картку з колоди

- Індекси `Vector` починаються з `1`.
- `n`-те значення у векторі `v` можна отримати за допомогою `v[n]`.

## 2. Замінити картку в колоді

- Обʼєкти `Vector` змінні, тож їхній вміст можна змінювати будь-коли.
- Метод приймає [Pair](https://docs.julialang.org/en/v1/base/collections/#Base.Pair) як аргумент.
- Доступ до полів пари `p` можна отримати за допомогою `p.first` та `p.second`.

## 3. Вставити картку на верх колоди

- У Base є метод [`push!`](https://docs.julialang.org/en/v1/base/collections/#Base.push!), який додає нове значення в кінець колекції.

## 4. Вилучити картку з колоди

- У Base є метод [`deleteat!`](https://docs.julialang.org/en/v1/base/collections/#Base.deleteat!), який видаляє елемент із `Vector` за заданим індексом.

## 5. Вилучити верхню картку з колоди

- У Base є метод [`pop!`](https://docs.julialang.org/en/v1/base/collections/#Base.pop!), який вилучає елемент у кінці колекції.

## 6. Вставити картку в низ колоди

- У Base є метод [`pushfirst!`](https://docs.julialang.org/en/v1/base/collections/#Base.pushfirst!), який вставляє нове значення на початок колекції.

## 7. Вилучити картку з низу колоди

- У Base є метод [`popfirst!`](https://docs.julialang.org/en/v1/base/collections/#Base.popfirst!), який вилучає елемент на початку колекції.

## 8. Перевірити розмір колоди

- У Base є метод [`length`](https://docs.julialang.org/en/v1/base/collections/#Base.length), який повертає довжину колекції.
