# Вступ

Словник - це набір елементів, кожен з яких складається з ключа та значення. Якщо передати ключ методу словника, той поверне повʼязане з цим ключем значення. Він відіграє ту саму роль, що мапи чи асоціативні масиви в інших мовах.

Словник можна створити так:

```csharp
new Dictionary<int, string>();
// Empty dictionary
```

Або

```csharp
new Dictionary<int, string>
{
    [1] = "One",
    [2] = "Two"
};

// Or

new Dictionary<int, string>
{
    {1, "One"},
    {2, "Two"}
};
// 1 => "One", 2 => "Two"
```

Зауважимо, що типи ключа та значення входять до визначення словника.

Після створення словника до нього можна додавати та видаляти записи за допомогою його вбудованих методів `Add` і `Remove`.

Отримати або оновити значення у словнику можна за допомогою індексування словника за ключем:

```csharp
var numbers = new Dictionary<int, string>
{
   {1, "One"},
   {2, "Two"}
};

// Set the value of the element with key 2 to "Deux"
numbers[2] = "Deux";

// Get the value of the element with key 2
numbers[2];
// => "Deux"
```

Перевірити, чи існує значення у словнику, можна так:

```csharp
var dict = new Dictionary<string, string>{/*...*/};
dict.ContainsKey("some key that exists");
// => true
```

Перебираючи словник, ми перебираємо його пари ключ-значення. Словники також мають властивості, які дозволяють перебирати їхні ключі або значення.
