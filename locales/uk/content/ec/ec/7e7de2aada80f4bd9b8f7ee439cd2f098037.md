# Числа з плаваючою комою

`INT` зберігає лише цілі числа, а ділення двох із них відкидає остачу:

```sather
7 / 2        -- 3, not 3.5
```

Коли дробова частина важлива, потрібен тип `FLTD`, **число з плаваючою комою**, яке може зберігати значення між цілими числами.

## Як його записати

Літерал числа з плаваючою комою має десяткову точку і `d` у кінці.

```sather
   concert_a : FLTD is
      return 440.0d;
   end;
```

`d` не можна опускати. `440.0` сам по собі належить до іншого типу, з меншою точністю; `d` вказує на той тип, який цей трек використовує всюди.

Записуймо `2.0d`, а не `2d`: десяткова точка теж мусить бути.

## Арифметика

`+`, `-`, `*` та `/` усі працюють, а `/` тепер зберігає дробову частину:

```sather
7.0d / 2.0d      -- 3.5
```

Обидві сторони мають бути `FLTD`. Sather не буде нишком змішувати ці два типи, тож `7 / 2.0d` викличе помилку, а не несподіванку.

## З цілого числа

`.fltd` перетворює `INT` на `FLTD`:

```sather
   halve(n : INT) : FLTD is
      return n.fltd / 2.0d;
   end;
```

`halve(7)` дає `3.5`. Звернімо увагу на те, де відбувається перетворення: `(7 / 2).fltd` дало б `3.0`, бо ділення вже відкинуло б половину. Перетворюймо **до** ділення, а не після.

## Наскільки далеко одне від одного?

`.abs` відкидає знак мінус, тож так можна дізнатися, наскільки далеко одне від одного два значення, не зважаючи на те, яке з них більше:

```sather
(440.0d - 442.0d).abs      -- 2.0
```
