# Докладніше

У C++ ми можемо порівнювати значення за допомогою операторів порівняння.

| Порівняння          | Оператор  |
| ------------------| --------- |
| дорівнює          | `==`      |
| не дорівнює       | `!=`      |
| менше             | `<`       |
| менше або дорівнює | `<=`      |
| більше            | `>`       |
| більше або дорівнює | `>=`      |

Результатом таких порівнянь завжди є булеве значення (англ. Boolean):

```cpp
int a{3};

bool eq1 = a != 4; // true

bool eq2 = a > 5;  // false
```

Оператори `==` і `!=` перевіряють відповідно, чи одне значення дорівнює іншому, чи ні.
Ось кілька поширених прикладів:

```cpp
bool eq3 = 2 == 3; // false, integer comparison

bool eq4 = 2.1 != 2.2; // true, float comparison

bool eq5 = "hello" == "hello"; // true, string comparison
```

Інші оператори перевіряють, чи одне значення більше за інше (`>`), більше або дорівнює йому (`>=`), менше за нього (`<`) і менше або дорівнює йому (`<=`).
Таке порівняння доступне для чисел і рядків тексту (англ. string).
Порівнюючи рядки тексту, ми дотримуємося словникового порядку (його ще називають лексикографічним).

```cpp
bool eq6 = 2 > 3; // false, integer comparison

bool eq7 = 1.2 < 1.3; // true, float comparison

bool eq8 = "Hello" < "World"; // true, string comparison
```
