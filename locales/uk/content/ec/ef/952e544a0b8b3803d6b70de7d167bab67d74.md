# Додаток до інструкцій

## Формат вихідних даних

Виведіть вік у сотих частинах року.

Наприклад, 100 × 1 000 000 000 ÷ 31 557 600 ≈ 3 169, тож вік того, кому 1 000 000 000 секунд, становить `3169` сотих частин земного року.

## Регістри

| Регістр  | Використання | Тип          | Опис                          |
| -------- | ------------ | ------------ | ----------------------------- |
| `$a0`    | вхідні дані  | ціле число   | планета (`0` = Меркурій, `1` = Венера, `2` = Земля, `3` = Марс, `4` = Юпітер, `5` = Сатурн, `6` = Уран, `7` = Нептун) |
| `$a1`    | вхідні дані  | ціле число   | секунди                       |
| `$v0`    | вихідні дані | ціле число   | вік у сотих частинах року     |
| `$t0-9`  | тимчасовий   | будь-який    | використовується для тимчасового зберігання |
