# Подання

[Репрезентер Python][representer] обробляє рішення учнів і нормалізує їх до більш «загальної» форми:

- Код перетворюється на AST за допомогою [модуля AST Python][python-ast].
- Остаточне дерево AST перетворюється на рядок тексту (англ. string) без пробілів та відступів і виводиться у `representation.txt`.
- Для діагностики `representation.out` містить початкове дерево AST, відредаговане дерево AST та подання коду із застосованими нормалізаціями.

- Вилучення:
    - анотації типів (_зокрема анотації типів у датакласах, див. «Нормалізації» нижче_)
    - інструкції `print()`
    - блоки `if __name__ == __main__`
    -  коментарі
    -  рядки документації

- Заміни:
    - імена, визначені користувачем, замінюються на заповнювачі (_зокрема назви функцій, параметри та змінні в лямбдах_)

- Нормалізації:
  - лапки навколо рядків тексту `'` змінюються на `"` (_подвійні лапки_), крім випадків, де потрібне екранування, тоді вони залишаються без змін.
  - у числових літералах прибираються всі підкреслення, а наукова нотація обчислюється за розрядами:
    - **66_777_888_433** --> 66777888433
    - **1_999_878_473.66** --> 1999878473.66
    - **77_555_998_125.445_779** --> 77555998125.44579
    - **44_573_123.445_312+123_674.889_12j** --> 44573123.445312 + 123674.88912j
    - **1e6** --> 1000000.0 #1000000
    -  **1e2+.23** --> 100.0 + 0.23 #100.23
    - **1e2+1_23e0+4.4e-1** --> 100.0 + 123.0 + 0.44 #223.44
    - **7e6+7e5+5e4+9.98e2+4.45_779e-1** -->7000000.0 + 700000.0 + 50000.0 + 998.0 + 0.445779 #7750998.445779
    - **(7e6+7e5+5e4+9.98e1+4.457_79e-1)+(1e2+1.23e1+4.444_23e-1)*1*j** --> (7000000.0 + 700000.0 + 50000.0 + 99.8 + 0.445779 + (100.0 + 12.3 + 0.444423) * 1j)  #7750100.245779+112.744423j
  - для функцій і класів, чиє тіло залишилося порожнім після вилучення рядків документації, у тіло записується `pass`.
  - у датакласах, де члени даних мають анотацію типу, але не мають значення, цим членам як значення призначається `None`. Докладніше див. у рядку документації, який починається на рядку 153 у normalizer.py.
