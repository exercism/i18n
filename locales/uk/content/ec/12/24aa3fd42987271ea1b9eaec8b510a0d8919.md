# Вступ

Нагадаємо, що `jq` підтримує ті самі типи даних, що й JSON.
JSON описує **рядки тексту (англ. string)** так:

> Рядок тексту - це послідовність із нуля або більше символів Unicode, узята в подвійні лапки, де для екранування використовується зворотна скісна риска.

## Екрановані послідовності

Усередині рядка тексту використовуємо зворотну скісну риску, щоб вставити «спеціальні» символи:

- `\"` буквальна лапка,
- `\\` буквальна зворотна скісна риска,
- пробільні символи `\n`, `\t`, `\r`, `\f`, `\b`
- символи Unicode `\uAAAA`, де `A` - шістнадцяткова цифра

## Довжина рядка тексту

Щоб дізнатися кількість символів, використовуємо функцію `length`.

```sh
$ jq -cn --args  '$ARGS.positional[] | length' "Hello world!" "❄🌡🤧🤒🏥🕰😀"
12
7
```

## Підрядки

Нотацію **зрізу** можна використати, щоб видобути підрядки.
Синтаксис такий: `.[i:j]`.
Повернутий підрядок має довжину `j - i` і містить символи від індексу `i` (включно) до індексу `j` (не включно).
Будь-який з індексів може бути відʼємним, і тоді він відраховується від кінця рядка тексту.
Будь-який з індексів можна пропустити, і тоді він указує на початок або кінець рядка тексту.
Індекси відраховуються від нуля.

```jq
"abcdefghij"[3:6]   # => "def"
"abcdefghij"[3:]    # => "defghij"
"abcdefghij"[:-2]   # => "abcdefgh"
```

## Конкатенація

Щоб зʼєднати рядки тексту, використовуємо `+`:

```jq
"Hello" + " " + "world!"
# => "Hello world!"
```

Використовуємо `add`, коли маємо масив рядків тексту:

```jq
["Hello", " ", "world!"] | add
# => "Hello world!"
```

## Розділення та зʼєднання

Для розділення використовуємо функцію `split/1` або оператор `/`:

```jq
"Hello beautiful world!" | split(" ")   # => ["Hello", "beautiful", "world!"]
```

```jq
"Hello beautiful world!" / " "          # => ["Hello", "beautiful", "world!"]
```

Функція `join/1` виконує обернену дію до `split/1`.

Часто потрібно перетворити рядок тексту на масив символів.
Є два способи це зробити:

1. розділити за порожнім рядком

   ```jq
   "Hi friend 😀" / ""   # => ["H","i"," ","f","r","i","e","n","d"," ","😀"]
   ```

1. `explode` у масив _кодових точок_

   ```jq
   "Hi friend 😀" | explode   # => [72,105,32,102,114,105,101,110,100,32,128512]
   ```

   `implode` виконує обернену дію до `explode`.

## Пошук індексу підрядка

Використовуємо функцію `index/1`; індекс відраховується від нуля.

```jq
"hello" | index("el")'   # => 1
```

Якщо підрядка немає в рядку тексту, результат - `null`

```jq
"hello" | index("elk")   # => null
```

## Інтерполяція рядків тексту

Усередині рядка тексту послідовність `\(expression)` вставить _результат_ цього виразу [у рядок тексту][interpolate]:

```jq
"The current datetime is \(now | strflocaltime("%c"))"   # => "The current datetime is Wed Nov 16 17:06:33 2022"
```

## Зміна регістру

Використовуємо функції `ascii_downcase` та `ascii_upcase`.

## Регулярні вирази

`jq` має багату підтримку регулярних виразів: це буде темою пізнішого уроку.

[interpolate]: https://jqlang.org/manual/#string-interpolation
