# Вступ

## Мапи

Мапи в Elixir використовують для зберігання інформації у вигляді пар ключ-значення. В інших мовах їх також можуть називати асоціативними масивами (PHP), хешами (Perl 5, Raku) або словниками (Python).

Ключі та значення можуть бути будь-якого типу даних, але якщо ключ є атомом, ми можемо скористатися скороченим синтаксисом. Мапи не гарантують порядку своїх записів під час доступу до них або повернення.

### Літеральні форми

Порожню мапу можна просто оголосити за допомогою `%{}`. Якщо ми хочемо додати елементи до літерала мапи, можемо скористатися двома формами:

```elixir
# If the key is an atom:
%{atom_key: 1}

# If the key is a different type:
%{1 => :atom_value}

# You can even mix these if the atom form comes second:
%{"first_form" => :a, atom_form: :b}
```

Хоча канонічного формату немає, обираймо послідовний спосіб представлення пар ключ-значення.

### Функції модуля Map

Elixir надає багато функцій для роботи з мапами в _модулі Map_. Деякі функції _модуля Map_ вимагають, щоб ми передали в них _анонімну_ функцію, яка допомагає перетворити мапу.

## Атрибути модуля як константи

В Elixir ми можемо визначати атрибути модуля, які потім можна використовувати як константи у своїх функціях.

```elixir
defmodule Example do
  # Defines the attribute as the value 1
  @constant_number 1

  def example_value() do
    # Returns the value 1
    @constant_number
  end
end
```

Коли атрибути використовують для визначення констант модуля, ними може бути будь-який вираз, який можна обчислити під час компіляції. Після компіляції атрибути модуля стають недоступними, оскільки вони розкриваються під час компіляції, подібно до визначених макросів у таких мовах, як C.
