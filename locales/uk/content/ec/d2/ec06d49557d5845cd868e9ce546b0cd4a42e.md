# Докладніше

Введення-виведення у Factor побудоване на одному [протоколі][stream-protocol], який може реалізувати будь-яке джерело чи приймач даних. Вбудовані потоки - `<file-reader>`, `<file-writer>`, `<string-reader>`, `<string-writer>`, мережеві сокети, масиви байтів, tty - це все класи, які реалізують той самий набір узагальнених слів із [`io`][io] і успадковують `disposable` з [`destructors`][destructors].

```factor
USING: io ;

GENERIC: stream-read1        ( stream -- elt/f )
GENERIC: stream-read-unsafe  ( n buf stream -- count )
GENERIC: stream-write1       ( elt stream -- )
GENERIC: stream-write        ( seq stream -- )
GENERIC: stream-flush        ( stream -- )
GENERIC: stream-element-type ( stream -- type )
```

`stream-read-unsafe` - це низькорівневе пакетне читання: заповнити буфер, наданий викликачем, і повернути, скільки елементів було записано. Публічні `stream-read` і `stream-read-partial` побудовані на ньому й беруть на себе виділення памʼяті. Більшість потоків, визначених користувачем, реалізують або `stream-read1` (коли читання відбувається по одному елементу за раз), або `stream-read-unsafe` (коли читання можна обʼєднувати в пакети).

`stream-element-type` повертає один із двох токенів-одинаків: `+byte+` для потоків байтів (читачі файлів, сокети) і `+character+` для потоків символів (читачі рядків, tty). Потік-обгортка зазвичай просто делегує своєму базовому потоку.

## Приєднання до міксинів

```factor
INSTANCE: my-stream input-stream
INSTANCE: my-stream output-stream
```

Клас може бути одним із них, іншим або обома одразу. Приєднання до міксина робить так, що методи за замовчуванням на `input-stream` / `output-stream` диспетчеризуються до цього класу. Це той самий підхід відкритого міксина, що й `set` зі словника `sets`.

## Фреймворк disposable

`new-disposable ( class -- disposable )` реєструє новий примірник у поточній області деструкторів, щоб виняток посеред налаштування ресурсів коректно розгортав стек:

```factor
USING: destructors ;

[
    "log.txt" utf8 <file-writer>   ! registered automatically
    "log.txt" utf8 <file-reader>   ! and so is this one
    ! ... use them ...
] with-destructors
! both files closed even if an error is thrown above
```

`dispose` - це публічне слово, а `dispose*` - узагальнене слово, яке реалізує клас. Перевизначення `dispose*` у підкласі має прибрати за собою власний стан, а потім звільнити всі ресурси, якими володіє:

```factor
M: my-stream dispose* underlying>> dispose ;
```

Фреймворк гарантує, що `dispose*` виконується щонайбільше один раз на обʼєкт: повторні виклики `dispose` нічого не роблять.

## Засоби доступу в межах області

Три комбінатори встановлюють глобальний «поточний потік введення/виведення», який використовують `print`, `read1` тощо:

```
with-input-stream   ( stream quot -- )    ! reads in quot use stream
with-output-stream  ( stream quot -- )    ! writes in quot use stream
with-disposal       ( disposable quot -- )! generic — any disposable
```

Кожен із них звільняє ресурс при виході, навіть якщо квотейшн згенерує виняток. Саме так більшість коду використовує власний потік, а не передає його через кожен виклик.
