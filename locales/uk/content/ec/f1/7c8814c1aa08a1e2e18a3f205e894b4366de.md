# Break, Continue

Коли ми використовуємо циклічну або ітераційну керуючу конструкцію, ключові слова `break` і `continue` допомагають керувати потоком виконання програми.
Ключове слово `break` перериває контекст циклу та виходить у зовнішню область видимості, тим самим завершуючи цикл.
Ключове слово `continue` пропускає решту поточної ітерації та перезапускає контекст циклу з початку наступної ітерації.
Хоч це й трапляється нечасто, разом із ключовим словом можна вказати число, щоб керувати тим, зі скількох контекстів вийти або скільки ітерацій пропустити до наступної.

```php
<?php
$i = 1;
while ($i <= 10) {

    if ($i <= 5) {
        i += 1;
        continue;
    }
    break;
}
```

У попередньому прикладі `continue` виконується пʼять (5) разів, але на шостій (6) ітерації виконується `break`, і код виходить із циклу.
