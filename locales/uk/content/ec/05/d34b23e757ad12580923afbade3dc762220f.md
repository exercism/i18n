# Вступ

## Рівність

У Common Lisp є багато різних предикатів рівності.
Це відрізняється від інших мов програмування, у яких може бути лише один або два (наприклад, `==` і `===`).
Деякі з цих предикатів у Common Lisp привʼязані до типів, тоді як інші є загальними.
Саме про останні йтиметься далі.

Є чотири загальні предикати рівності, і вони відрізняються тим, наскільки суворо визначають «рівність».
Ось вони, від найсуворішого до найменш суворого: `eq`, `eql`, `equal` і `equalp`.

Короткий набір визначень (з пропуском кількох деталей) такий:

- `eq`: визначає рівність так: два обʼєкти ідентичні.
  _наприклад_:

```lisp
(eq 'a 'a)                 ; => T
(eq (list 1 2) (list 1 2)) ; => NIL
```

- `eql`: визначає рівність так: два числа однакового типу й значення, два однакові символи,
  або, для будь-чого іншого, якщо вони `eq`.
  _наприклад_:

```lisp
(eql 1 1)     ; => T
(eql #\a #\a) ; => T
(eql 1 1.0)   ; => NIL
(eql #\a #\A) ; => NIL
```

- `equal`: визначає рівність так: два списки є `equal`, якщо кожен елемент також є `equal`; два рядки тексту (англ. string) є `equal`, якщо кожен елемент є `eql`; два масиви є `equal`, якщо вони `eq`; будь-що інше є `equal`, якщо воно `eql`.
  _наприклад_:

```lisp
(equal (list 1 2) (list 1 2)) ; => T
(equal #(1 2) #(1 2))         ; => NIL
(equal "foo" "foo")           ; => T
```

- `equalp`: визначає рівність так: рядки тексту та символи порівнюються без урахування регістру; числа порівнюються з деяким перетворенням типів; списки та масиви є `equalp`, якщо кожен елемент також є `equalp`, структури, якщо вони однакового типу й усі слоти є `equalp`, і хеш-таблиці, якщо їхні ключі та значення є `equalp`
  _наприклад_:

```lisp
(equalp "foo" "FoO")                          ; => T
(equalp 3 3.0)                                ; => T
(equalp (make-a-structure :slot1 1 :slot2 2) 
        (make-a-structure :slot1 1 :slot2 2)) ; => T
```
