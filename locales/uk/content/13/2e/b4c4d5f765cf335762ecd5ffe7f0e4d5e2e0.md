# Довідка

## Запуск тестів

Трек Factor використовує **Factor 0.101**. Після [встановлення](https://exercism.org/docs/tracks/factor/installation) запустіть з каталогу цієї вправи:

```
factor -roots=. -run=exercism-tools <exercise>
```

Наприклад, для `hello-world`:

```
factor -roots=. -run=exercism-tools hello-world
```

Кожна вправа постачається з невеликим вбудованим набором `exercism-tools`, який керує запуском тестів. Коли проходять усі тести, запуск завершується зі статусом 0. Якщо ж якийсь тест не проходить, запуск завершується з ненульовим статусом і діагностичним виводом.

### Пропущені тести

Типово виконується лише перший тест. Механізм полягає в рядку `STOP-HERE` у файлі тестів: під час розбору він каже лексеру Factor ігнорувати все, що нижче, тож виконуються лише тести, розташовані вище. Щойно перший тест пройде, можна увімкнути більше тестів у два способи:

- **Видаліть рядок `STOP-HERE`**, щоб увімкнути всі решта тестів одразу.
- **Перемістіть рядок `STOP-HERE` далі вниз**, щоб увімкнути тести по одному, або по одному завданню. Концептуальні вправи групують свої тести під маркерами `TASK:`. Перемістити `STOP-HERE` безпосередньо перед наступним `TASK:` - це природний крок.

Коли проходять усі тести, вправу розвʼязано.

## Надсилання рішення

З каталогу вправи:

```
exercism submit <exercise>/<exercise>.factor
```

Наприклад:

```
exercism submit hello-world/hello-world.factor
```

Якщо у файлі `.meta/config.json` вправи вказано більше ніж один файл рішення (деякі концептуальні вправи розділяють рішення між допоміжним піднабором), передайте до `exercism submit` кожен файл, який було відредаговано.

## Надсилання незавершених рішень

Рішення можна надіслати навіть із тестами, що не проходять. Це дає змогу побачити, як до вправи підходили інші, і попросити в наставника відгук про те, що вже є.

## Як отримати більше допомоги

- [Категорія Factor на форумі Exercism](https://forum.exercism.org/c/programming/factor/) найкраще підходить для запитань і відгуків про цей трек.
- [Discord Exercism](https://exercism.org/r/discord) має канали як для загальної допомоги, так і для окремих треків.
- Офіційна документація Factor доступна для пошуку й досить вичерпна. Дві хороші точки входу:
  - [The Factor handbook](https://docs.factorcode.org/content/article-handbook.html): довідковий стиль, матеріал організовано за наборами.
  - [The Factor cookbook](https://docs.factorcode.org/content/article-cookbook.html): короткі ідіоматичні приклади за темами.
- [Туторіал з Factor](https://andreaferretti.github.io/factor-tutorial/) від Андреа Ферретті - швидкий і привітний вступ до мови та середовища розробки.
