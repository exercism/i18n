# Вступ до змінних

## Змінні

_Змінні_ - це місце, де зберігаються дані.
У Bash є два види даних: рядки тексту (англ. string) і масиви.
Про масиви поговоримо пізніше.

Присвоєння значення змінній має такий вигляд:
```bash
name="value"
```

~~~~exercism/note
**Важливо**: навколо знака рівності _не повинно бути пробілів_!

Коли пробіли є, як у цьому прикладі,

```bash
x = 10
```

bash викличе **команду** `x` з **двома аргументами** `=` і `10`!
~~~~

Змінні також називають _параметрами_.
У цьому документі ці два терміни вживатимуться взаємозамінно.

Ось деякі важливі параметри, які використовує або встановлює bash:

* `PATH` - список каталогів, розділених двокрапкою, який використовується для пошуку зовнішніх команд.
* `IFS` - «внутрішній роздільник полів».
   Як він використовується, побачимо нижче.
* `PWD` - поточний робочий каталог.
   Його значення збігається з виводом команди `pwd`.
* `RANDOM` - псевдовипадкове ціле число від 0 до 32767.
* `BASH_VERSION` - рядок тексту з версією запущеного примірника bash.

## Імена змінних

Імʼя змінної складається з _великих літер, малих літер, цифр і знака підкреслення_.
Воно не може починатися з цифри.

~~~~exercism/caution
Найкраще **уникати імен змінних, записаних усіма великими літерами**.
Оболонка використовує цю конвенцію для своїх параметрів, а випадково перезаписати параметри оболонки, які мають особливе значення, не варто.

## Розкриття параметрів

Значення параметра отримують за допомогою синтаксису `$varname`.

```bash
x=10
echo "The value of x is $x"
```

Щоб імʼя змінної не змішувалося з навколишнім текстом, його можна взяти у фігурні дужки.
Наприклад, щоб надрукувати рядок тексту `10x10`

```bash
echo "${x}x$x"
# or
echo "${x}x${x}"
```

Деякі [посібники зі стилю][google-style-guide] рекомендують у більшості випадків використовувати фігурні дужки задля читабельності та узгодженості.

## Позиційні параметри

Як ми обговорювали в уроці [«Команди та аргументи»][cmds-args], команди можуть приймати аргументи.
Сценарії Bash не виняток.
Аргументи поточного примірника bash називаються _позиційними параметрами_.
Отримати їх можна за допомогою цих спеціальних параметрів:

* `$1` - перший позиційний параметр
* `$2` ... `$9` - наступні параметри
* `${10}` ... - для двозначних параметрів потрібні фігурні дужки.
* `$0` - імʼя поточного сценарію.

Аргументи функції оболонки теж належать до позиційних параметрів, і з ними працюють точно так само.
Докладніше про функції поговоримо в одному з наступних уроків.

### Спеціальні позиційні параметри

Існують _спеціальні параметри_, які допомагають працювати з позиційними параметрами.

* `$#` розкривається в _кількість_ позиційних параметрів.
* `"$@"` розкривається в список усіх позиційних параметрів, кожен з яких є окремим словом.
* `"$*"` розкривається в один рядок тексту з усіх позиційних параметрів, зʼєднаних певним символом.
  * Символом зʼєднання є _перший символ_ змінної `$IFS`, який типово дорівнює пробілу.

`"$@"` - найбезпечніший спосіб передати позиційні параметри іншій команді, зберігши їх у лапках.
Саме його ми використовуватимемо, щоб перебрати позиційні параметри в циклі:

```bash
for arg in "$@"; do
    do_something_with "$arg"
done
```

На практиці `"$@"` використовують частіше, ніж `"$*"`.

## Підстановка команд

Дуже часто в сценаріях bash доводиться перехоплювати вивід команди та зберігати його у змінній.
Для цього використовують _підстановку команд_.

```bash
var=$(command)
```

Наприклад, щоб перевести рядок тексту у верхній регістр, можна зробити так:

```bash
text="Hello world!"
uppercase=$(echo "$text" | tr '[:lower:]' '[:upper:]')
echo "$uppercase"
# => HELLO WORLD!
```

## Докладніше про розкриття параметрів

У bash є багато вбудованих засобів для роботи зі змінними та рядками тексту, тож не потрібно викликати зовнішні команди.

* Переведення тексту у верхній регістр.
  У попередньому розділі ми бачили, як за допомогою `tr` перевести текст у верхній регістр.
  А ось як зробити це засобами bash:

  ```bash
  echo "${text^^}"
  ```

  Так само `${text,,}` переводить значення в нижній регістр.

* Надання типового значення, якщо змінна порожня.

  ```bash
  default="nothing here"
  result=""
  echo "${result:-$default}"
  # => nothing here
  ```

* Пошук і заміна.

  ```bash
  text="Hello world!"
  echo "${text//[aeiou]/X}"
  # => HXllX wXrld!"
  ```

Існує багато інших цікавих розкриттів параметрів: видобути підрядок, отримати довжину рядка тексту, _присвоїти_ типове значення, прибрати текст з початку чи кінця значення тощо.
Про них можна прочитати [в посібнику][param-exp].
