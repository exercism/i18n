# Булеві значення

Haskell має тип, відомий як [`Bool`][bools].
Це перелічення `True` та `False`.

## Логічні оператори

Haskell має три логічні оператори (`not`, `||` (логічне або), `&&` (логічне і)), які поєднують булеві значення (англ. Boolean) і утворюють вирази, що дають різні значення.

### І (`&&`)

[Оператор _і_][and] у Haskell представлений як `&&` (і) і повертає `True`, якщо обидва значення `True`; інакше повертає `False`.
Коли ми використовуємо оператор _і_, одне булеве значення ставимо праворуч від `&&` (і), а інше ліворуч.

```haskell
True && True
-- -> True

True && False
-- -> False
```

### Або (`||`)

[Оператор _або_][or] у Haskell представлений як `||` (або) і повертає `True`, якщо **принаймні одне** з наданих значень `True`. 
Якщо обидва значення `False`, тоді він повертає `False`.
Коли ми використовуємо оператор _або_, одне булеве значення слід ставити праворуч від `||` (або), а інше ліворуч.

```haskell
True || True
-- -> True

True || False
-- -> True

False || False
-- -> False
```

### Заперечення (`not`)

Оператор _not_ у Haskell представлений як `not` і повертає `True`, якщо надане булеве значення `False`, і повертає `False`, якщо надано `True`.
Коли ми використовуємо оператор _not_, одне булеве значення слід ставити після оператора (`not`).

```haskell
not True
-- -> False

not False
-- -> True
```

## Використання дужок (`()`)

Коли ми працюємо з булевими значеннями, ми можемо використовувати дужки, щоб вирішити, які булеві значення обчислити першими.
Результат може відрізнятися залежно від того, як використано дужки.
У Haskell те, що стоїть у дужках, обчислюється першим.

```haskell
True && False && False || True
-- -> True

True && False && (False || True)
-- -> False
```

Оскільки те, що стоїть у дужках, обчислюється першим, оператор _not_ буде застосовуватися до виразу всередині дужок у наступному прикладі.

```haskell
not True && False
-- -> False

not (True && False)
-- -> True
```

~~~~exercism/note
Дужки варто використовувати лише тоді, коли вони впливають на результат; інакше їх слід опускати.
~~~~
