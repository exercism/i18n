# Докладніше

Рядок тексту (англ. string) у Factor - це послідовність символів. Він поділяє весь протокол [`sequences`][sequence-protocol] (`length`, `nth`, `head`, `tail`, `map`, `filter` тощо) і має власні спеціалізовані словники.

```factor
"hello"  length .       ! => 5
"hello"  reverse .      ! => "olleh"
"abcdef" 3 head .       ! => "abc"
```

Слова, призначені саме для рядків тексту, живуть переважно в [`splitting`][splitting], [`ascii`][ascii] та [`unicode`][unicode]:

| слово        | словник         | що воно робить                          |
|--------------|---------------|---------------------------------------|
| `split1`     | [`splitting`][splitting]   | розрізати за першим входженням           |
| `split`      | [`splitting`][splitting]   | розрізати за будь-яким символом із набору         |
| `harvest`    | [`sequences`][sequences]   | відкинути порожні частини з результату розбиття |
| `replace`    | [`splitting`][splitting]   | замінити підрядок                |
| `surround`   | [`sequences`][sequences]   | обгорнути префіксом і суфіксом         |
| `glue`       | [`sequences`][sequences]   | зʼєднати два рядки тексту роздільником     |
| `join`       | [`sequences`][sequences]   | зʼєднати масив рядків тексту роздільником |
| `>lower`     | [`ascii`][ascii]       | перевести в нижній регістр (ASCII)                     |
| `>upper`     | [`ascii`][ascii]       | перевести у верхній регістр (ASCII)                     |
| `[ blank? ] trim` | [`sequences`][sequences] | прибрати пробільні символи на початку й у кінці |
| `first`, `second`, `third`, `fourth` | [`sequences`][sequences] | провідний слот |
| `first2`, `first3`         | [`sequences`][sequences]   | розпакувати два або три провідні слоти |
| `>string`    | [`strings`][strings]     | перетворити послідовність символів на рядок тексту |
| `1string`    | [`strings`][strings]     | загорнути один символ у рядок тексту з одного символу |
| `CHAR: x`    | parser        | літерал з одного символу (наприклад, `CHAR: A` → `65`) |

Для взаємних перетворень між числами та рядками тексту [`math.parser`][math.parser]
надає `number>string` і `string>number`. Для виведення за форматом
[`formatting`][formatting] надає `sprintf` та супутні слова.

Для зміни регістру чи класифікації символів з урахуванням Unicode варто
використовувати відповідні слова з [`unicode`][unicode].
