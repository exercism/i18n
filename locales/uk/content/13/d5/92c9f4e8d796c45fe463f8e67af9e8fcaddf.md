# Вступ

## Хеш-таблиці

Хеш-таблиці в Common Lisp - це структури даних для зберігання асоціативних даних.
Вони зіставляють ключі (якими може бути будь-який обʼєкт) зі значеннями (якими теж може бути будь-який обʼєкт).
В інших мовах цю концепцію можуть називати мапами, словниками або хешами.

### Створення хеш-таблиць

Хеш-таблиці можна створювати за допомогою функції `make-hash-table`.

`(make-hash-table) ; => #<HASH-TABLE :TEST EQL :COUNT 0 {10024AD2B3}>`

(Зауважте, що надруковане представлення хеш-таблиці залежить від реалізації, тож у REPL вона може мати інший вигляд.)

### Отримання значень за ключами

Щоб отримати значення за ключем із хеш-таблиці, ми використовуємо функцію `gethash`:

```lisp
*h* ; => #<HASH-TABLE :TEST EQL :COUNT 3 {10024AD2B3}>`
(gethash :foo *h*) ; => :bar
                   ;    T
```

`gethash` повертає [кілька значень][concept-multiple-values], про які йтиметься в іншій концепції.

### Вставлення значень

Щоб вставити значення в хеш-таблицю, ми використовуємо `setf` разом із `gethash` ось так:

`(setf (gethash :foo *hash-table*) :bar) : => :bar`

Це змінить значення для ключа `:foo` у хеш-таблиці `*hash-table*` на `:bar`.
Воно повертає це значення.

Використання `setf` буде пояснено в іншій концепції.
