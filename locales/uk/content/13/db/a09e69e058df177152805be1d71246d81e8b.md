# Інструкції

Після кожного туру нашому нетбольному клубу потрібно обчислити турнірну таблицю.

Усі чотири завдання потрібно виконати в класі `NETBALL_LADDER`.

## 1. Очки в турнірній таблиці

Перемога дає 4 очки, а нічия - 2. Поразки не приносять очок.

```sather
NETBALL_LADDER::ladder_points(3, 1)
-- => 14
```

## 2. Різниця мʼячів

Забиті мʼячі мінус пропущені. Різниця може бути відʼємною.

```sather
NETBALL_LADDER::goal_difference(180, 205)
-- => -25
```

## 3. Цілі зіграні чверті

Чверть триває 15 хвилин. Якщо маємо певну кількість хвилин, то скільки цілих
чвертей це буде?

```sather
NETBALL_LADDER::whole_quarters(38)
-- => 2
```

## 4. Хвилини всередині чверті

Дано ту саму кількість хвилин: скільки хвилин минуло в поточній чверті?

```sather
NETBALL_LADDER::minutes_into_quarter(38)
-- => 8
```
