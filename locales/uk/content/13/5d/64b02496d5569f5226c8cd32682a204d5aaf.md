# Додаток до інструкцій

## Регістри

| Регістр | Використання   | Тип         | Опис                                       |
| ------- | -------------- | ----------- | ------------------------------------------ |
| `$a0`   | вхідні дані    | адреса      | масив слів множників                       |
| `$a1`   | вхідні дані    | ціле число  | кількість множників                        |
| `$a2`   | вхідні дані    | ціле число  | межа                                       |
| `$v0`   | вихідні дані   | ціле число  | сума кратних, що не перевищують межу       |
| `$t0-9` | тимчасовий     | будь-який   | використовується для тимчасового зберігання |
