# Вступ

Хоча Swift містить багато функціональності у своїй стандартній бібліотеці, ще більше функціональності доступно у вигляді зовнішніх бібліотек.
Ці бібліотеки можуть бути від самого проєкту Swift, як-от [Swift Argument Parser][argument-parser], закриті бібліотеки від компаній, як-от [Network Framework][network-framework] від Apple, або сторонні бібліотеки, як-от [Swifty Beaver][swifty-beaver].

Деякі з цих модулів, як-от Network Framework або [Foundation][apple-foundation] (яка, ймовірно, є найуживанішою бібліотекою у Swift), входять до дистрибутива Swift.
Зовнішні сторонні бібліотеки потрібно додати до свого проєкту, перш ніж їх можна буде імпортувати, хоча це виходить за межі цієї вправи.

Щоб імпортувати модулі, ми пишемо ключове слово `import`, а потім назву модуля. Отже, щоб імпортувати Foundation, достатньо додати таке до своєї програми.

```swift
import Foundation
```

Це дає доступ до всіх типів, значень і функціональності усередині цього модуля; наприклад, якщо ми хочемо використати метод `components(separatedBy:)` типу `String`, цей метод стає доступним для `String` завдяки цьому імпорту.

Хоча інструкції `import` можна розмістити в коді будь-де перед фрагментом коду, який використовує вміст модуля, зазвичай їх розміщують на початку файлу, який їх використовує, для кращої читабельності.

[argument-parser]: https://apple.github.io/swift-argument-parser/documentation/argumentparser/
[network-framework]: https://developer.apple.com/documentation/network
[swifty-beaver]: https://github.com/SwiftyBeaver/SwiftyBeaver
[apple-foundation]: https://developer.apple.com/documentation/foundation
