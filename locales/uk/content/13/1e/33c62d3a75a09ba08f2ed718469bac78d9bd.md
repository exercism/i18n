# Встановлення

Трек мови C потребує, щоб на системі було встановлено таке програмне забезпечення:

* Сучасний компілятор C
* Інструмент збирання Make

IDE Xcode від Apple поєднує компілятор і нативну систему збирання в єдине інтегроване середовище розробки (IDE, integrated development environment).
У середовищах Linux компілятор і нативна система збирання зазвичай доступні як окремі інструменти командного рядка.

## Linux

Користувачам Linux знадобиться gcc або clang як компілятор, а для нативного збирання знадобиться `make`.
Make попередньо встановлено в більшості unix-систем, але найімовірніше він доступний через пакетний менеджер.
У дистрибутивах на основі Debian і Ubuntu усе потрібне можна встановити командою `sudo apt-get install build-essential`, якщо його ще немає.

## MacOS

Користувачі MacOS можуть встановити gcc або clang за допомогою [Homebrew][] командою `brew install gcc` або `brew install llvm`.

## Windows

Користувачам Windows 10 радимо скористатися [Windows Subsystem for Linux][] і далі виконувати наведену вище інструкцію для Linux.

Якщо використовується старіша версія Windows або WSL Bash недоступний, можна скористатися [MSYS][] або [mingw-w64][].

[Homebrew]: https://brew.sh
[Windows Subsystem for Linux]: https://docs.microsoft.com/en-gb/windows/wsl/about
[MSYS]: https://www.msys2.org
[mingw-w64]: http://mingw-w64.org
