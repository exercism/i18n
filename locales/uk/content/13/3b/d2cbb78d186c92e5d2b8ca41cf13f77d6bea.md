# Інструкції

Перетворіть фразу на її акронім.

Айтівці обожнюють свої TLA (трилітерні акроніми)!

Допоможіть згенерувати трохи жаргону: напишіть програму, яка перетворює довгу назву на кшталт Portable Network Graphics на її акронім (PNG).

З розділовими знаками поводимося так: дефіси розділяють слова (як пробіли); усі інші розділові знаки можна прибрати з вхідних даних.

Наприклад:

| Вхід                      | Вихід |
| ------------------------- | ------ |
| As Soon As Possible       | ASAP   |
| Liquid-crystal display    | LCD    |
| Thank George It's Friday! | TGIF   |
