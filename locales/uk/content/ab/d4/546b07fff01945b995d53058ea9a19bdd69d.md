# Докладніше

У програмуванні часто доводиться працювати з рядками тексту (англ. string). Тому Swift надає багато методів для роботи з ними. У цьому документі ми розглянемо деякі з найпоширеніших методів і властивостей для рядків тексту; частина з них потребує імпорту фреймворку Foundation.

## [`components(separatedBy:)`][components]

Коли потрібно розбити рядок тексту на масив підрядків, можна скористатися методом `components(separatedBy:)`. Наприклад, щоб отримати кожне слово в реченні, можна використати символ пробілу як роздільник.

```swift
let sentence = "Hello, world!"
let words = sentence.components(separatedBy: " ")
print(words) // Prints ["Hello,", "world!"]
```

## [`hasPrefix(_:)`][hasPrefix], [`hasSuffix(_:)`][hasSuffix]

Коли потрібно перевірити, чи починається або закінчується рядок тексту певним підрядком, можна скористатися методами `hasPrefix(_:)` і `hasSuffix(_:)`. Обидва ці методи приймають рядок тексту як аргумент і повертають булеве значення (англ. Boolean), яке вказує, чи починається або закінчується рядок тексту вказаним підрядком.

```swift
let greeting = "Hello, world!"
print(greeting.hasPrefix("Hello"))  // Prints true
print(greeting.hasSuffix("world!")) // Prints true
```

## [`lowercased`][lowercased], [`uppercased`][uppercased], [`capitalized`][capitalized]

Коли потрібно змінити регістр рядка тексту, можна скористатися властивостями `lowercased`, `uppercased` і `capitalized`. Властивість `lowercased` повертає новий рядок тексту, у якому всі символи записані в нижньому регістрі, властивість `uppercased` повертає новий рядок тексту, у якому всі символи записані у верхньому регістрі, а властивість `capitalized` повертає новий рядок тексту, у якому перший символ кожного слова записано з великої літери.

```swift
let greeting = "hello, world!"
print(greeting.lowercased)  // Prints "hello, world!"
print(greeting.uppercased)  // Prints "HELLO, WORLD!"
print(greeting.capitalized) // Prints "Hello, World!"
```

## [`replacingOccurrences(of:with:)`][replacingOccurrences]

Коли потрібно замінити всі входження підрядка в рядку тексту на інший підрядок, можна скористатися методом `replacingOccurrences(of:with:)`. Цей метод приймає два рядки тексту як аргументи: підрядок, який потрібно замінити, і підрядок, на який його замінюємо. Він повертає новий рядок тексту, у якому всі входження вказаного підрядка замінено.

```swift
let greeting = "Hello, world!"
let newGreeting = greeting.replacingOccurrences(of: "world", with: "Swift")
print(newGreeting) // Prints "Hello, Swift!"
```

## [`joined(separator:)`][joined]

Це метод не типу String, а типу Array. Коли потрібно зʼєднати масив рядків тексту в один рядок із вказаним роздільником, можна скористатися методом `joined(separator:)`. Цей метод приймає рядок тексту як аргумент і повертає новий рядок тексту, у якому всі елементи масиву зʼєднано разом і розділено вказаним рядком.

```swift
let words = ["Hello", "world"]
let sentence = words.joined(separator: ", ")
print(sentence) // Prints "Hello, world"
```
