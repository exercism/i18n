# Вступ

У JavaScript клас `Array` має багато потужних вбудованих методів для перетворення масивів.
Завдяки цим методам перетворити один масив на інший значно простіше, ніж робити це звичайним циклом `for` чи прямим маніпулюванням.

Деякі методи є [_чистими_][pure-function-definition]: вони не змінюють вихідний масив, а повертають новий.
Інші ж методи змінюють масив, для якого їх викликали, і **не** повертають змінений масив.

Нижче наведено деякі з найуживаніших методів перетворення масивів.
Повний список доступних методів можна знайти в [документації MDN][array-methods].

### map (чиста)

Створює новий масив, перетворюючи кожен елемент за допомогою функції, переданої як аргумент.
Такі функції зворотного виклику часто записують як [стрілкові функції][concept-arrow-functions].

```javascript
let arr = [1, 2, 3, 4];

const newArr = arr.map((value) => value - 1);
console.log(newArr);
// => [0, 1, 2, 3]
console.log(arr);
// => [1, 2, 3, 4]
```

Варто зазначити, що отриманий масив завжди матиме ту саму довжину, що й вихідний.

### filter (чиста)

Створює масив, фільтруючи наявний за допомогою функції фільтрування (вона повертає правду, якщо елемент потрібно зберегти, і неправду, якщо його потрібно прибрати).

```javascript
let arr = [1, 2, 3, 4];

arr.filter((value) => value % 2 === 0);
// => [2, 4]
```

### reduce (чиста)

Зводить масив до одного значення за допомогою функції, яка приймає _акумулятор_ і поточний елемент масиву як параметри.
Ця функція визначає, як поточний елемент потрібно приєднати до акумулятора, і повертає акумулятор, який буде використано на наступній ітерації.

```javascript
let arr = [1, 2, 3, 4];

// Get the sum of elements
arr.reduce((accumulator, currentValue) => accumulator + currentValue, 0);
// => 10

// Classify the numbers by whether they are odd or not
arr.reduce(
  (accumulator, currentValue) => {
    if (currentValue % 2 === 0) {
      accumulator.even.push(currentValue);
    } else {
      accumulator.odd.push(currentValue);
    }

    return accumulator;
  },
  { even: [], odd: [] },
);
// => { even: [2, 4], odd: [1, 3] }
```

### reverse

Змінює порядок елементів масиву на протилежний.

```javascript
const arr = [1, 2, 3, 4];

arr.reverse();
// => [4, 3, 2, 1]
```

Цей метод змінює масив, для якого його викликали.

### slice (чиста)

За заданими початковим і кінцевим індексами створює підмасив із масиву, для якого його викликали.

Елемент із кінцевим індексом не включається.
Крім того, всі параметри необовʼязкові:
початковий індекс типово дорівнює `0`, а кінцевий індекс типово дорівнює довжині масиву.

```javascript
const arr = [1, 2, 3, 4];

arr.slice(1, 2); // [2]
arr.slice(1); // [2, 3, 4]
// You can also use negative numbers, that represent the indexes
// starting from the end of the array
arr.slice(-2); // [3, 4]
```

### splice

Видаляє або замінює та/або додає нові елементи масиву.

Він приймає такі параметри:

- індекс елемента, з якого починається змінювання масиву
- кількість елементів для видалення
- елементи, які потрібно вставити в масив (необовʼязково)

`splice` повертає елементи, які було видалено.

```javascript
const arr = ['1', '2', '5', '6'];

// Insert an element at index 2
arr.splice(2, 0, '3');
console.log(arr);
// => ['1', '2', '3', '5', '6']

// Remove 2 elements, starting at index 3 and insert 2 elements
const removed = arr.splice(3, 2, '4', '5');
console.log(removed);
// => ['5', '6']
console.log(arr);
// => ['1', '2', '3', '4', '5']

// Remove 1 element at index 1
arr.splice(1, 1);
console.log(arr);
// => ['1', '3', '4', '5']
```

### sort

Типово `sort` сортує елементи масиву, спершу перетворюючи їх на рядки тексту (англ. string), а потім застосовуючи порівняння рядків (див. [Порівняння][concept-comparison]).
Сортування відбувається _на місці_, тобто вихідний масив змінюється.
`sort` також повертає цей змінений масив, що зручно, якщо ми хочемо приєднати до нього ланцюжком інші методи.

```javascript
const arr = ['c', 'a', 'z', 'b'];
const result = arr.sort();
console.log(result);
// => ['a', 'b', 'c', 'z']
console.log(arr);
// => ['a', 'b', 'c', 'z']
```

Щоб налаштувати поведінку сортування, можна передати функцію порівняння як аргумент.
Саму функцію порівняння викликають із двома аргументами, які є двома елементами масиву.
Вона має повернути таке:

- відʼємне число, якщо перший аргумент має стояти перед другим після сортування
- додатне число, якщо перший аргумент має стояти після другого
- `0`, якщо порядок елементів має залишитися незмінним

Наприклад, щоб відсортувати числа, можна використати таку функцію порівняння.

```javascript
const arr = [3, 1, 2, 10];
arr.sort((a, b) => a - b);
// => [1, 2, 3, 10]
// "a - b" is negative when b is greater than a, positive when
// a is greater than b and 0 when they are equal.
```
