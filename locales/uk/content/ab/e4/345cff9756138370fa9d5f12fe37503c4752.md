# Додаток до інструкцій

## Вказівки, специфічні для треку

Для чогось трохи іншого можемо також спробувати рішення з функцією `unfold`.
Ми, ймовірно, вже знайомі з `foldLeft/Right`: «map» цілу колекцію в щось інше (зазвичай не колекцію).
`unfold` - це «обернена» операція: «map» щось (зазвичай не колекцію) в колекцію.
Тож `unfold` - це логічне доповнення до стандартного арсеналу функціонального програмування і водночас його частина.

Цю вправу можна розглядати як випадок для `unfold`: «map» `Int` у `String` (який, звісно, неявно є `Seq[Char]`).

Колекції Scala мають його з версії 2.13, наприклад [`List.unfold`][list] і `Iterator.unfold`.
Він приймає початковий стан і функцію, яка повертає наступний елемент і наступний стан, або `None`, щоб зупинитися:

```scala
List.unfold(1234)(n => Option.when(n > 0)((n % 10, n / 10)))
// List(4, 3, 2, 1)
```

[list]: https://www.scala-lang.org/api/current/scala/collection/immutable/List$.html
