# Докладніше

## Конструкція _if-then_

Найпростішу конструкцію керування потоком виконання в Java задає [умовна конструкція _if-then_][if-statement].
Її використовують, щоб виконати частину коду лише тоді, коли певна умова набуває значення `true`.
Умовну конструкцію _if-then_ визначають за допомогою гілки `if`:

```java
class Car {
    void drive() {
        // the "if" clause: the car needs to have fuel left to drive
        if (fuel > 0) {
            // the "then" clause: the car drives, consuming fuel
            fuel--;
        }
    }
}
```

У наведеному вище прикладі, якщо в автомобіля закінчилося пальне, виклик методу `Car.drive` нічого не зробить.

## Конструкція _if-then-else_

Конструкція _if-then-else_ задає альтернативний шлях виконання для випадку, коли умова в гілці `if` набуває значення `false`.
Цей альтернативний шлях виконання йде після гілки `if` і визначається за допомогою гілки `else`:

```java
class Car {
    void drive() {
        if (fuel > 0) {
            fuel--;
        } else {
            stop();
        }
    }
}
```

У наведеному вище прикладі, якщо в автомобіля закінчилося пальне, виклик методу `Car.drive` викличе інший метод, який зупинить автомобіль.

Конструкція _if-then-else_ також підтримує кілька умов за допомогою гілки `else if`:

```java
class Car {
    void drive() {
        if (fuel > 5) {
            fuel--;
        } else if (fuel > 0) {
            turnOnFuelLight();
            fuel--;
        } else {
            stop();
        }
    }
}
```

У наведеному вище прикладі, якщо пального менше або рівно `5`, автомобіль усе одно буде рухатися, але загориться індикатор пального.
Коли пальне сягне `0`, автомобіль зупиниться.
