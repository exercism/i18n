# Інструкції

Нічна зміна на причалі в Галлі. Вантажний корабель *Olwen* пришвартовано борт об борт, і бригада вантажників паралельно опрацьовує маніфест. Кожен ящик треба зважити, перш ніж його піднімуть на борт, а начальник порту веде єдиний поточний **тоннажний підсумок**, який оновлює кожен підйом. Заковика ось у чому: на причалі лише один кран, тож не можна допустити, щоб двоє вантажників одночасно оновлювали підсумок і пошкодили його.

Кожен ящик - це масив ваг окремих предметів. Вага ящика - це сума ваг цих предметів.

## 1. Зважити ящик

Визначте `weigh-crate` так, щоб він приймав ящик і повертав його загальну вагу. Це звичайна послідовна робота: один ящик, одне число на виході.

```factor
{ 12 8 15 } weigh-crate .
! => 35
```

## 2. Зважити весь маніфест паралельно

Визначте `weigh-all` так, щоб він приймав масив ящиків і повертав масив їхніх ваг у тому самому порядку. Використайте `parallel-map`, щоб робота з кожним ящиком відбувалася паралельно.

```factor
{ { 5 5 } { 10 } { 3 4 5 } } weigh-all .
! => { 10 10 12 }
```

## 3. Створити новий кран

Визначте `<crane>` так, щоб він створював новий кран: кортеж із новим `<lock>` і тоннажем `0`. Кран - це спільний ресурс, який будуть захищати наступні завдання.

```factor
<crane> tonnage>> .
! => 0
```

## 4. Підняти ящик і оновити поточний підсумок

Визначте `hoist-crate` так, щоб він приймав `weight` і `crane` та додавав вагу до тоннажу крана **під замком крана**, щоб операція «читання-додавання-запис» була атомарною щодо інших вантажників, які піднімають ящики одночасно.

```factor
<crane>
35 over hoist-crate
17 over hoist-crate
tonnage>> .
! => 52
```

## 5. Прочитати поточний тоннаж

Визначте `crane-tonnage` так, щоб він повертав поточний тоннаж крана, теж під замком, щоб читання не побачило пошкодженого значення посеред підйому.

```factor
<crane>
35 over hoist-crate
crane-tonnage .
! => 35
```

## 6. Завантажити вантаж

Визначте `load-cargo` так, щоб він приймав масив ящиків і кран та **для кожного ящика породжував потік вантажника**, який зважує ящик і піднімає вагу на кран. Слово повертає результат лише після того, як завершать роботу всі вантажники. Використайте `<promise>` і `?promise`, щоб скоординувати приєднання потоків.

```factor
<crane> :> crane
{ { 5 5 } { 10 } { 3 4 5 } } crane load-cargo
crane crane-tonnage .
! => 32
```
