# Встановлення

Потрібен [NodeJS LTS](https://nodejs.org/en).

> 💡 Імовірно, цей трек працює і зі старішими стабільними версіями, і з «поточною» версією.
> Однак [за задумом](https://github.com/nodejs/release#release-schedule) непарні версії ніколи не бувають стабільними.
> Завжди встановлюйте парну версію NodeJS.

Установіть [Yarn 4+](https://yarnpkg.com/getting-started/install) за допомогою `corepack` із Node.JS:

```shell
corepack enable yarn
```

## Перевірка встановлення

Зазвичай потрібно відкрити новий термінал, щоб скористатися щойно встановленими виконуваними файлами.

```shell
$ node -v
v20.15.0

$ corepack -v
0.28.1

$ corepack yarn -v
v4.3.1
```

_Примітка: цілком імовірно, що версії відрізнятимуться від наведених._

## Встановлення для вправ

**Кожній вправі** потрібні деякі інструменти, щоб запускати тести:

Їх можна встановити, виконавши цю команду в каталозі кожної вправи:

```bash
$ corepack yarn install
```

Залежно від редактора, у кожній вправі потрібно встановити [Editor SDK](https://yarnpkg.com/getting-started/editor-sdks), щоб усе працювало зі встановленнями Plug'n'Play.
На момент написання підтримуються такі:

- [CoC nvim](https://yarnpkg.com/getting-started/editor-sdks#coc-nvim)
- [Emacs](https://yarnpkg.com/getting-started/editor-sdks#emacs)
- [Neovim Native LSP](https://yarnpkg.com/getting-started/editor-sdks#neovim-native-lsp)
- [VSCode](https://yarnpkg.com/getting-started/editor-sdks#vscode)
