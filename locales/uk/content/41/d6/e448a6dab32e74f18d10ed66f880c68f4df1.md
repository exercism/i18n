# Про це

Стандартна бібліотека Elixir пропонує 4 різні модулі для роботи з датами й часом, і кожен має власну структуру.

- Модуль [`Date`][date]. Структуру `Date` можна створити за допомогою сигіла [`~D`][sigil-d].
    ```elixir
    ~D[2021-01-01]
    ```

- Модуль [`Time`][time]. Структуру `Time` можна створити за допомогою сигіла [`~T`][sigil-t].
    ```elixir
    ~T[12:00:00]
    ```

- Модуль [`NaiveDateTime`][naivedatetime] для дати й часу без часового поясу. Структуру `NaiveDateTime` можна створити за допомогою сигіла [`~N`][sigil-n].
    ```elixir
    ~N[2021-01-01 12:00:00]
    ```

- Модуль [`DateTime`][datetime] для дати й часу з часовим поясом. Щоб використовувати цей модуль із часовими поясами, відмінними від UTC, потрібна зовнішня залежність, база даних часових поясів. Структуру `DateTime` можна подати сигілом [`~U`][sigil-u], але створювати її слід за допомогою функцій `DateTime`.
    ```elixir
    DateTime.new!(~D[2021-01-01], ~T[12:00:00], "Etc/UTC")
    # => ~U[2021-01-01 12:00:00Z]
    ```

## Порівняння

Щоб порівняти дати або час між собою, пошукаймо у відповідному модулі функцію `compare` або `diff`. Оператори порівняння, як-от `==`, `>` і `<`, _здаються_ робочими, але для цих структур вони не виконують правильного семантичного порівняння.

```elixir
Date.compare(~D[2020-11-30], ~D[2020-12-01])
# => :lt

Time.diff(~T[13:45:00], ~T[13:46:30])
# => -90
```

## Зсув

Дати, час і дати з часом можна зсувати вперед і назад у часі за допомогою функції `add/2` з відповідного модуля.

```elixir
# add 4 days
Date.add(~D[2021-01-01], 4)
# => ~D[2021-01-05]

# subtract 1 second
Time.add(~T[12:00:00], -1)
# => ~T[11:59:59.000000]

# add 4 days and 30 seconds
NaiveDateTime.add(~N[2021-01-01 12:00:00], 4 * 24 * 60 * 60 + 30)
# => ~N[2021-01-05 12:00:30]
```

## Перетворення

Структуру `NaiveDateTime` можна розібрати на структуру `Date` і структуру `Time` за допомогою [`NaiveDateTime.to_date/1`][naivedatetime-to-date] і [`NaiveDateTime.to_time/1`][naivedatetime-to-time]. Зворотну дію можна виконати за допомогою [`NaiveDateTime.new!/2`][naivedatetime-new].

```elixir
NaiveDateTime.to_date(~N[2021-01-01 12:00:00])
# => ~D[2021-01-01]

NaiveDateTime.to_time(~N[2021-01-01 12:00:00])
# => ~T[12:00:00]

NaiveDateTime.new!(~D[2021-01-01], ~T[12:00:00])
# => ~N[2021-01-01 12:00:00]
```
