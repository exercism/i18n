# Встановлення

Спершу переконайтеся, що Erlang встановлено, і за потреби скористайтеся інструкціями на сторінці встановлення [Erlang][1].
[1]: /languages/erlang

## Homebrew для Mac OS X

Оновіть Homebrew до найновішої версії:

```bash
$ brew update
```

Встановіть LFE:

```bash
$ brew install lfe
```

## Встановлення з вихідного коду
Встановіть системні «developer tools» або «essential build packages», а також `git` та `erl` з Erlang.

Наприклад, на Ubuntu 18.04:

```bash
$ sudo apt-get install build-essential git erlang erlang-base-hipe
```

Після цього можна завантажити й зібрати LFE так:

```bash
$ git clone https://github.com/lfe/lfe.git
$ cd lfe
$ make
$ make install
```

Після компіляції LFE можна запустити REPL (інтерактивну сесію), виконавши бінарний файл ``lfe``:

```bash
$ ./bin/lfe
```
