# Докладніше

Ruby постачається зі стандартною бібліотекою (її часто скорочують до «stdlib») - набором класів для роботи з датами, json і мережею.
Вона також надає корисні можливості, які роблять наш код зручнішим у роботі.

`OpenStruct` - частина стандартної бібліотеки, яка дозволяє легко створити обʼєкт із `Hash`.
Замість того щоб звертатися до значень за ключами `Hash`, `OpenStruct` дозволяє нам користуватися методами, щоб читати й записувати значення.

Коли ми використовуємо класи зі стандартної бібліотеки чи будь-якої іншої, нам потрібно підключити цей клас за допомогою методу `require`.

```ruby
require 'ostruct'

attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

Це дає ще одну приємну перевагу: для блокового синтаксису можна скористатися скороченням.
Коли блок викликає лише один метод, ми можемо замінити блок на `&:`, після якого йде назва методу.
Наприклад, ці два рядки рівнозначні:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```
