# Вступ

`Complex numbers` зовсім не складні.
Їм просто потрібна назва, яка не так лякає.


Вони настільки корисні, особливо в інженерії та науці, що Python включає [`complex`][complex] як стандартний числовий тип, поряд із цілими числами ([`int`s][ints]) та числами з плаваючою комою ([`float`s][floats]).


Значення `complex` у Python по суті складається з пари чисел з плаваючою комою:

```python
>>> my_complex = 5.443+6.77j
(5.443+6.77j)
```

Їх називають «дійсною» та «уявною» частинами.
Часто кажуть, що `i` (або `j`) - це квадратний корінь із -1.
Поки що це означає лише те, що уявна частина _за визначенням_ задовольняє рівність `1j * 1j == -1`.
Це проста ідея, але вона веде до цікавих математичних наслідків.

У Python уявну частину позначають літерою `j` (_а не `i`, як у підручниках з математики_), і ця `j` має йти безпосередньо після числа, щоб Python не сприйняв її як імʼя змінної:


```python
>>> j
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
NameError: name 'j' is not defined

>>> 1j
1j

>>> type(1j)
<class 'complex'>
```


Є два поширені способи створити комплексні числа.

1) Конструктор [`complex(real, imag)`][complex] приймає два параметри типу `float`:

    ```python
    >>> z1 = complex(1.5, 2.0)
    >>> z1
    (1.5+2j)
    ```

    Конструктор також уміє розбирати вхідні дані у вигляді рядка тексту (англ. string).
    У цього є дивне обмеження: він не спрацює, якщо рядок тексту містить пробіли.

    ```python
    >>> complex('4+2j')
    (4+2j)
    
    >>> complex('4 + 2j')
    Traceback (most recent call last):
      File "<stdin>", line 1, in <module>
    ValueError: complex() arg is a malformed string
    ```


2) Комплексне число можна задати літералом `<real part> + <complex part>j` або просто `<complex part>j`, якщо дійсна частина дорівнює нулю:


    ```python
    >>> z2 = 2.0 + 1.5j
    >>> z2
    (2+1.5j)
    ```
    Кінцевий результат такий самий, як і під час використання конструктора `complex()`.


## Арифметика

Більшість [`operators`][operators], які використовуються з числами з плаваючою комою та цілими числами, також працюють із комплексними числами.

Цілочисельне ділення _**не**_ можливе для комплексних чисел, тож оператори `//` і `%` та функція `divmod()` не працюватимуть із типом комплексних чисел.

Пояснення правил множення й ділення комплексних чисел виходить за межі цієї концепції (_і навряд чи ці операції часто доведеться виконувати вручну_).

Будь-який [математичний][math-complex] чи [електротехнічний][engineering-complex] вступ до комплексних чисел охоплює ці сценарії, якщо захочеться заглибитися в тему.

Стандартна бібліотека Python має модуль [`math`][math-module], сповнений корисних можливостей для роботи з дійсними числами, а модуль [`cmath`][cmath] - його відповідник для роботи з комплексними числами.
