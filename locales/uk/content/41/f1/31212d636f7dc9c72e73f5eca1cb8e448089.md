# Структури

Структури збирають фіксований, неоднорідний набір даних в одну одиницю. Структури в Rust мають такі властивості:

- Кожен тип структури має певну назву.
- Кожен член структури називається **полем**.
- Кожне поле структури має певну назву.
- Видимість відстежується на рівні поля: кожне поле може бути незалежно публічним, приватним або іншим[^1].

# Огляд структур

Структури визначають за допомогою ключового слова `struct`, за яким іде назва типу, який описує структура.
Після назви можуть іти фігурні дужки (для звичайної структури), круглі дужки (для кортежної структури) або крапка з комою (для одиничної структури).

```rust
struct Item {}
```

Далі до тіла структури додаються інші типи як _поля_ структури, кожне зі своїм типом:

```rust
struct Item {
    name: String,
    weight: f32,
    worth: u32,
}
```

І нарешті, методи можна визначати для структур усередині блоку `impl`:

```rust
impl Item {
    // initializes and returns a new instance of our Item struct
    fn new() -> Self {
        todo!()
    }
}
```

# Різновиди структур

Структури бувають трьох різновидів: структури з іменованими полями (звичайні структури), кортежні структури та одиничні структури.

Структури дуже схожі на **кортежі**. Насправді єдина відмінність між структурами та кортежами стосується того, що саме є анонімним. Загальна схема така:

- Структури мають назву та іменовані поля:

  ```rust
  struct Foo {
      bar: Bar,
      bat: Bat,
  }
  ```

  До полів звертаються за назвою:

  ```rust
  let bar = foo.bar;
  ```

- Кортежні структури мають назву та анонімні поля:

  ```rust
  Foo(Bar, Bat)
  ```

  До полів звертаються через розпакування або за числовим індексом:

  ```rust
  // unpacking
  let (bar, bat) = foo;
  ```

  ```rust
  // numeric index
  let bar = foo.0;
  let bat = foo.1;
  ```

- Кортежі анонімні та мають анонімні поля:

  ```rust
  (Bar, Bat)
  ```

  Як і в кортежних структурах, до полів звертаються через розпакування або за числовим індексом.

- Анонімні структури, як підказує назва, анонімні, але мають іменовані поля. Можливо, вони знайомі нам з інших мов, як-от Go чи Java. У Rust їх немає; замість них ідіоматично використовувати кортеж.

# Типи нульового розміру

У структурі може бути стільки полів, скільки потрібно, або як завгодно мало. З цього випливає, що структура цілком законно може мати нуль полів. Структура без полів називається **типом нульового розміру** й отримує особливу обробку від компілятора: типи нульового розміру (часто скорочено **ZST**) ніколи не займають місця ні в стеку, ні в купі, навіть коли ми могли б цього очікувати. Наприклад, `Box<T>` не виділяє жодної памʼяті в купі, якщо `T` є ZST.

Пишучи ZST, можна використовувати синтаксис звичайної або кортежної структури:

```rust
// declaration
struct Foo {}
// instantiation
let foo = Foo {}
```

```rust
// declaration
struct Foo();
// instantiation
let foo = Foo();
```

Для ZST існує також скорочений запис:

```rust
// declaration
struct Foo;
// instantiation
let foo = Foo;
```

Зазвичай, пишучи ZST, краще надавати перевагу скороченому запису, бо змішувати стилі не можна: який стиль використали для оголошення ZST[^2], такий самий стиль потрібен і для створення її екземпляра.

Після всієї цієї розмови про синтаксис ZST поговорімо про те, навіщо взагалі може знадобитися така річ. ZST не може зберігати жодних даних, але чудово підходить для реалізації трейтів.

[^2]: Це окремий випадок загального правила: який стиль використали для оголошення будь-якого типу структури, такий самий стиль потрібен і для створення його екземпляра.
