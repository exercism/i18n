# Вступ

Списки символів створюються за допомогою сігіла `~c`.

```elixir
~c"hello"
```

~~~~exercism/note
Звернімо увагу, що в старіших версіях Elixir списки символів позначаються як `'hello'` з одинарними лапками.
~~~~

Хоча вони дуже схожі на рядки тексту (англ. string), ці два типи даних досить різні. Список символів - це масив цілих чисел. Цілі числа представляють значення Unicode даного символу, які також називають кодовими точками.

```elixir
[65, 66, 67]
# => ~c"ABC"
```

Можна поставити `?` перед символом, щоб отримати його кодову точку.

```elixir
?A
# => 65

[?:, ?)]
# => ~c":)"
```

Оскільки списки символів є масивами, з ними можна працювати так само, як і з будь-яким іншим масивом: за допомогою рекурсії та зіставлення зі зразком.

```elixir
[first_letter | _] = ~c"cat"
first_letter
# => 99
```

Можна зʼєднати два масиви за допомогою `++`.

```elixir
~c"hi" ++ ~c"!"
# => ~c"hi!"
```

Чим довший перший масив, тим повільніша конкатенація, тому уникаймо повторного додавання до масивів довільної довжини.
