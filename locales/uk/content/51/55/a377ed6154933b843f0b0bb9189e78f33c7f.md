# Вступ

Цикл дає змогу багаторазово виконувати групу з однієї або кількох інструкцій.
Кожне виконання такої групи інструкцій називається ітерацією.

## Цикл `while`

Цикл `while` виконує групу інструкцій, поки значенням булевого виразу (англ. Boolean) на початку циклу є правда.
Коли значенням булевого виразу стає неправда, цикл припиняє роботу, і виконання переходить до наступного рядка коду після циклу.

Якщо значення булевого виразу від самого початку дорівнює неправді, цикл `while` не виконається жодного разу, і виконання перейде до наступного рядка коду після циклу.

```c
int main() {
    int i = 0;
    while (i < 5) {
        printf("Number is %i\n", i++);
    }    
    return 0;
}
```

Важливо, щоб існувала умова завершення циклу; інакше він стане нескінченним і повністю зупинить подальше виконання коду.
Якби в наведеному вище коді з `i` прибрати `++`, це був би нескінченний цикл.

## Цикл `do`

У циклі `do` булевий вираз перевіряється в кінці циклу.
Цикл `do` завжди виконається принаймні один раз, як у наступному прикладі:

```c
do {
    printf("Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
} while (answer != 42); 
// Note that a semicolon is needed after the Boolean expression.
```

Із циклом `while` цей код був би довшим:

```c
printf(""Enter the Answer to the Ultimate Question of Life: ");
scanf("%d", &answer);
while (answer != 42) {
    printf(""Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
}
```

## Цикл `for`

Часто цикл оновлює змінну й завершується, коли змінна досягає певного значення.
Цикл `for` дає змогу ініціалізувати, оновлювати й перевіряти одну або кілька змінних в одному рядку в дужках.
Перша частина - для ініціалізації змінної, друга - для перевірки змінної, а третя - для оновлення значення змінної.

```c
for (int i = 0; i < 5; i++) {
    printf("Number is %i\n", i);
}
```

Це коротше, ніж еквівалентний цикл `while`, і водночас залишається читабельним.
