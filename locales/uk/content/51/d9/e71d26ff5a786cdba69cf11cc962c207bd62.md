# Вказівка

Завдання - розвʼязати бінарну головоломку.
У кожної бінарної головоломки є рівно _одне_ рішення, яке можна знайти, застосувавши ці правила:

1. У кожній комірці має бути нуль або одиниця.
2. Понад дві однакові цифри не можуть стояти поруч. Тож якщо дві сусідні комірки містять одну й ту саму цифру, комірки поруч із ними повинні містити іншу цифру.
3. Кожен рядок і кожен стовпець повинні містити однакову кількість нулів та одиниць.
4. Кожен рядок і кожен стовпець унікальні.

На вхід надійде незаповнена головоломка у вигляді рядків нулів та одиниць, де невідомі значення позначено заповнювачами (`_`).
Мета - визначити правила для бінарної головоломки, завдяки яким тести зможуть визначити значення для заповнювачів (це робити не потрібно).
Реалізація повинна використовувати [логічне програмування з обмеженнями над скінченними доменами (CLP(FD))](https://www.swi-prolog.org/man/clpfd.html) у Prolog, яке ідеально підходить для таких завдань.

````exercism/note
Щоб було легше почати, файл-заготовка вже містить [бібліотеку `clpfd`](https://www.swi-prolog.org/man/clpfd.html), підключену через:

```prolog
:- use_module(library(clpfd)).
```
````
