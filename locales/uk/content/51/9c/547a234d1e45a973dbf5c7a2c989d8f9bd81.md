# Інструкції

У цій вправі ми гратимемося з радіокерованою машиною, на яку нарешті назбирали грошей.

Машини починають роботу з повністю зарядженими батареями (100%). Щоразу, коли ми керуємо машиною за допомогою пульта, вона проїжджає 20 метрів і витрачає один відсоток заряду батареї.

Радіокерована машина має стильний світлодіодний дисплей, який показує дві частини інформації:

- Загальну відстань, яку вона проїхала, показану як: `"Driven <METERS> meters"`.
- Залишок заряду батареї, показаний як: `"Battery at <PERCENTAGE>%"`.

Якщо заряд батареї становить 0%, керувати машиною більше не можна, і на дисплеї батареї буде показано `"Battery empty"`.

На нас чекає шість завдань, кожне з яких працюватиме з примірниками радіокерованої машини.

## 1. Купити нову радіокеровану машину

Реалізуйте (_статичний_) метод `RemoteControlCar.Buy()`, щоб повернути новий примірник радіокерованої машини:

```csharp
RemoteControlCar car = RemoteControlCar.Buy();
```

## 2. Показати пройдену відстань

Реалізуйте метод `RemoteControlCar.DistanceDisplay()`, щоб повернути відстань у тому вигляді, у якому вона показана на світлодіодному дисплеї:

```csharp
var car = RemoteControlCar.Buy();
car.DistanceDisplay();
// => "Driven 0 meters"
```

## 3. Показати відсоток заряду батареї

Реалізуйте метод `RemoteControlCar.BatteryDisplay()`, щоб повернути відсоток заряду батареї у тому вигляді, у якому він показаний на світлодіодному дисплеї:

```csharp
var car = RemoteControlCar.Buy();
car.BatteryDisplay();
// => "Battery at 100%"
```

## 4. Оновлювати кількість пройдених метрів під час руху

Реалізуйте метод `RemoteControlCar.Drive()`, який оновлює кількість пройдених метрів:

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
car.DistanceDisplay();
// => "Driven 40 meters"
```

## 5. Оновлювати відсоток заряду батареї під час руху

Оновіть метод `RemoteControlCar.Drive()`, щоб він оновлював відсоток заряду батареї:

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
car.BatteryDisplay();
// => "Battery at 98%"
```

## 6. Заборонити рух, коли батарея розряджена

Оновіть метод `RemoteControlCar.Drive()` так, щоб він не збільшував пройдену відстань і не зменшував відсоток заряду батареї, коли батарея розряджена (0%):

```csharp
var car = RemoteControlCar.Buy();

// Drain the battery
// ...

car.DistanceDisplay();
// => "Driven 2000 meters"

car.BatteryDisplay();
// => "Battery empty"
```
