# Вступ

## Нульованість

У Java літерал `null` використовується для позначення відсутності значення.

Примітивні типи даних у Java мають типове значення, тому ніколи не можуть бути `null`.
За домовленістю вони починаються з малої літери, наприклад `int`.

Посилальні типи містять адресу обʼєкта в памʼяті й можуть мати значення `null`.
Зазвичай вони починаються з великої літери, наприклад `String`.

Спроба присвоїти примітивній змінній значення `null` призведе до помилки часу компіляції, оскільки змінна завжди зберігає примітивне значення присвоєного типу.

```java
//Throws compile time error stating the required type is int, but null was provided
int number = null;
```

Присвоєння посилальній змінній значення `null` не призведе до помилки часу компіляції, оскільки посилальні змінні можуть бути `null`.

```java
//No error will occur as the String variable str is nullable
String str = null;
```
