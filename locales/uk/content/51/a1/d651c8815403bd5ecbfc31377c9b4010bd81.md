# Докладніше

Основні арифметичні оператори та оператори порівняння можна пристосувати до роботи з власним **абстрактним типом**. Це називається перевантаженням операторів.

Щоб перевантажити оператор, скористаймося метаданими `@:op()` на полі класу:

```haxe
abstract MyAbstract(String) {
  public inline function new(s:String) {
    this = s;
  }

  @:op(A * B)
  public function repeat(rhs:Int):MyAbstract {
    var s:StringBuf = new StringBuf();
    for (i in 0...rhs)
      s.add(this);
    return new MyAbstract(s.toString());
  }
}

class Main {
  static public function main() {
    var a = new MyAbstract("foo");
    trace(a * 3); // foofoofoo
  }
}
```
