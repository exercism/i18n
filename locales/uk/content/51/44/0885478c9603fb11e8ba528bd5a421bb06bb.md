# Докладніше

У Clojure привʼязування значення до імені називають [_var_][vars]. Var верхнього рівня (глобальні) схожі на константи в інших мовах, але їх часто перевизначають, щоб полегшити динамічну розробку.

Var верхнього рівня визначають за допомогою [`def`][def]:

```clojure
(def fingers 10)
```

Для арифметичних дій зі значеннями можна використовувати основні функції для [операцій над числами][operators].

Макрос `defn` можна використати, щоб визначити [функцію][functions], яка приймає нуль або більше аргументів. Функція завжди повертає результат останнього виразу у своєму тілі.

```clojure
(defn add [x y]
  (+ x y))
```

Щоб викликати функцію, потрібно вказати її назву й передати аргументи для кожного з її параметрів.

```clojure
(def five (add 2 3))
```

Функції та значення в Clojure можна використовувати лише _після_ того, як їх визначено. Якщо використати їх до визначення, це призведе до помилки компіляції.

```clojure
;; Compile error as `add` has not yet been defined
(def seven (add 3 4))

(defn add [x y]
  (+ x y))
```

У Clojure пробільні символи не мають жодного значення, крім форматування.

Функції та var у Clojure організовано в простори імен. Простір імен групує споріднену функціональність і визначається за допомогою макросу `ns`:

```clojure
(ns calculator)

(def pi 3.14)

(defn add [x y]
  (+ x y))
```

Clojure підтримує два типи коментарів. Однорядкові коментарі починаються з `;`, а форма `comment` використовується, щоб запобігти обчисленню всього між `(comment` і `)`.
