# Про це

Послідовності у Factor бувають двох видів, коли нам потрібно їх *змінити*:

- **Масиви** (`{ … }`) мають фіксовану довжину. Ми можемо змінити те, що *стоїть* на кожній позиції, за допомогою `set-nth` / `change-nth`, але не можемо їх збільшити чи зменшити.
- **Вектори** (`V{ … }`) мають змінну довжину. `push` додає елемент у кінець, а `pop` вилучає й повертає останній елемент.

```factor
USING: arrays kernel sequences ;

! Fixed-length: build a counter array of zeros, then bump one slot.
3 0 <array>            ! { 0 0 0 }
dup [ 1 + ] 1 rot change-nth
.                      ! { 0 1 0 }

! Variable-length: build a vector of names by pushing.
V{ } clone
"alice" over push
"bob" over push
dup pop drop           ! removes "bob"
.                      ! V{ "alice" }
```

| слово           | дія                                            |
|-----------------|------------------------------------------------|
| `<array>`       | `( n elt -- array )` - масив з `n` копій `elt` |
| `<vector>`      | `( n -- vector )` - порожній вектор з ємністю `n` |
| `V{ }`          | порожній літерал вектора                       |
| `set-nth`       | `( elt n seq -- )` - присвоїти елемент за індексом `n` |
| `change-nth`    | `( i seq quot -- )` - застосувати `quot` до елемента за індексом `i` |
| `push`          | `( elt seq -- )` - додати в кінець вектора     |
| `suffix!`       | `( seq elt -- seq )` - додати на місці, повертає вектор |
| `pop`           | `( seq -- elt )` - вилучити й повернути останній |
| `pop*`          | `( seq -- )` - вилучити останній, відкинути    |
| `clone`         | `( obj -- copy )` - нова незалежна копія       |
| `new-sequence`  | `( n exemplar -- newseq )` - нова послідовність того самого класу, що й `exemplar` |
| `new-resizable` | `( n exemplar -- newseq )` - новий варіант зі змінним розміром |

Коли ми змінюємо послідовність, яку передав викликач, ця зміна видима для викликача, адже він тримає той самий обʼєкт. Якщо нам потрібно інакше, спочатку застосуймо `clone`, щоб отримати незалежну копію.
