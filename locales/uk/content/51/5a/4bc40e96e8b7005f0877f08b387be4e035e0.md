# Інструкції

У цій вправі ми будемо писати код, щоб друкувати бейджі з іменами для працівників фабрики.

## 1. Надрукувати бейдж для працівника

Працівники мають ID, імʼя та назву відділу.
Мітки на бейджах працівників мають такий формат: `"[id] - name - DEPARTMENT"`.
Реалізуйте метод `printBadge()`, щоб він повертав мітку на бейджі працівника:

```kotlin
printBadge(734, "Ernest Johnny Payne", "Strategic Communication")
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

~~~~exercism/note
Зауважте, що назва відділу на мітці має бути написана великими літерами.
~~~~

## 2. Надрукувати бейдж для нового працівника

Через особливість компʼютерної системи нові працівники іноді ще не мають ID, коли починають працювати на фабриці.
Оскільки бейджі обовʼязкові, вони отримають тимчасовий бейдж без префікса ID.
Змініть метод `printBadge()`, щоб він підтримував нових працівників, які ще не мають ID:

```kotlin
printBadge(null, "Jane Johnson", "Procurement")
// => "Jane Johnson - PROCUREMENT"
```

## 3. Надрукувати бейдж для власника

Навіть власник фабрики мусить постійно носити бейдж.
Однак у власника немає відділу.
У цьому випадку на мітці замість назви відділу має бути надруковано `"OWNER"`.
Змініть метод `printBadge()`, щоб він друкував мітку для власника:

```kotlin
printBadge(254, "Charlotte Hale", null)
// => "[254] - Charlotte Hale - OWNER"
```

~~~~exercism/note
Зауважте, що власник може бути одночасно і новим працівником:

```kotlin
printBadge(null, "Charlotte Hale", null)
// => "Charlotte Hale - OWNER"
```
~~~~
