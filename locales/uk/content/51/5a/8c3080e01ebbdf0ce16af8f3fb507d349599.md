# Вступ

Модуль `Agent` надає абстракцію для створення [процесів і циклу _receive-send_][exercism-processes]. Далі процеси, запущені за допомогою модуля `Agent`, будемо називати _«агент-процеси»_. _Агент-процес_ можна обрати, щоб він представляв центральний спільний стан.

Щоб запустити _агент-процес_, `Agent` надає функцію `start/2`. Передана функція, коли ми запускаємо _агент-процес_ через `start`, повертає початковий стан процесу:

```elixir
# Start an agent process with an initial value of an empty list
{:ok, agent_pid} = Agent.start(fn -> [] end)
```

Як і `Map` або `List`, `Agent` надає багато функцій для роботи з _агент-процесами_.

Прийнято організовувати й інкапсулювати всю функціональність, повʼязану з `Agent`, в модулі для предметної області, яку моделюємо.

[exercism-processes]: https://exercism.org/tracks/elixir/concepts/processes
