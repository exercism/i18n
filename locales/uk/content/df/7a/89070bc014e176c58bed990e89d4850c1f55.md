# Інструкції

Ми працюємо вчителями.
Наприкінці року ми згенерували числову оцінку для кожного нашого учня.
Тепер нам потрібно перетворити це на літерну оцінку та порахувати, скільки учнів отримали кожну літерну оцінку

## 1. Перетворити числову оцінку на літерну оцінку

Функція `letter_grade` прийматиме числову оцінку як вхідні дані та повертатиме літеру.
Використовуйте ці діапазони:

| Літера |      Оцінка |
| :----: | ---------: |
|   A    | 90% - 100% |
|   B    |  80% - 89% |
|   C    |  70% - 79% |
|   D    |  60% - 69% |
|   F    |   0% - 59% |

Приклад:

```jq
75 | letter_grade   # => "C"
```

## 2. Порахувати кількість учнів для кожної літерної оцінки

Функція `count_letter_grades` прийматиме обʼєкт, який зіставляє імена учнів з їхніми оцінками.
Вихідні дані будуть обʼєктом, який зіставляє кожну літерну оцінку з кількістю учнів, які мають цю оцінку.

Приклад:

```jq
{"Joe": 78, "Jane": 93, "Richard": 72} | count_letter_grades
# => {"A": 1, "B": 0, "C": 2, "D": 0, "F": 0}
```

Існує кілька різних способів розвʼязати це.
Використовуйте фільтр `reduce` для практики.
