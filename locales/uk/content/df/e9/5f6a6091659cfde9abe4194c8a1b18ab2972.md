# Вступ

Символи та рядки тексту (англ. string) формують основу для подання тексту в Elm.
Рядки тексту можна уявляти як масиви символів, і більшість функцій `List` мають відповідник у модулі `String`.

## Символи

Тип `Char` представляє один символ Unicode, узятий в одинарні лапки, наприклад `'a'`.
Модуль `Char` надає функції-предикати (`Char -> Bool`) для перевірки якостей символу: `isUpper`, `isLower`, `isAlpha` та `isAlphaNum`.
Модуль також надає функції перетворення символу: `toUpper`, `toLower`, `toLocaleUpper`, `toLocaleLower`, а також у числове значення Unicode (`Int`) і назад за допомогою `toCode` та `fromCode`.

## Рядки тексту

Тип `String` надає вбудоване подання для ефективної роботи з рядками тексту і може подати будь-яку послідовність символів Unicode.
Рядки тексту записують у подвійних лапках: `"this is a string"`.
Багаторядкові рядки тексту записують трьома подвійними лапками, і в них можуть бути неекрановані лапки та символи нового рядка.

```elm 
haiku = 
"""
    Code's strings entwine
    , In binary, thoughts combine
    , Logic's elegant line.
"""
```

## Робота з рядками тексту

`reverse : String -> String` перевертає рядок тексту.
```elm 
reverse "Hello world." 
    --> ".dlrow olleH"
```

`repeat : Int -> String -> String` повторює рядок тексту n разів.
```elm 
repeat 2 "Hello world." 
    --> "Hello world.Hello world."
```

`replace : String -> String -> String -> String` замінює всі входження заданого підрядка.
```elm
replace "Hello" "Goodbye cruel" "Hello world." 
    --> "Goodbye cruel world."
```

`append : String -> String -> String` приєднує один рядок тексту до іншого.
Для цього також можна використати оператор `++`.
```elm
append "butter" "fly" 
    --> "butterfly"
"butter" ++ "fly" 
    --> "butterfly"
```

`concat : List String -> String` поєднує масив рядків тексту в один рядок тексту.
```elm
concat ["never", "the", "less"] 
    --> "nevertheless"
```

`split : String -> String -> List String` розбиває рядок тексту на масив рядків тексту за заданим роздільником.
```elm
split ";" "cat;dog;cow" 
    --> ["cat", "dog", "cow"]
```

`join : String -> List String -> String` поєднує масив рядків тексту заданим роздільником.
```elm
join "a" ["H", "w", "ii", "n"] 
    --> "Hawaiian"
```

`words : String -> List String` розбиває рядок тексту на рядки тексту, розділяючи його за групами пробільних символів.
```elm
words "How are \t you? \n Good?" 
    --> ["How", "are", "you?", "Good?"]
```

`lines : String -> List String` розбиває рядок тексту на рядки, розділяючи його за символами нового рядка.
```elm
lines "How are you?\nGood?" 
    --> ["How are you?", "Good?"]
```

`cons : Char -> String -> String` додає символ на початок рядка тексту.
```elm
cons 'T' "he truth is out there" 
    --> "The truth is out there"
```

`uncons : String -> Maybe ( Char, String )` розбиває непорожній рядок тексту на голову та хвіст.
Це дає змогу зіставляти рядки тексту за зразком так само, як ми робимо це з масивами.
Порожні рядки тексту повертають `Nothing`.
```elm
uncons "abc" 
    --> Just ('a', "bc")
uncons ""
    --> Nothing
```

## Отримання підрядків

`slice : Int -> Int -> String -> String` повертає підрядок за заданими початковим і кінцевим індексом.
Відʼємні індекси відраховуються від кінця рядка тексту.
```elm
slice 0 6 "snakes on a plane!" 
    --> "snakes"
slice 0 -7 "snakes on a plane!"
    --> "snakes on a"
```

`left : Int -> String -> String` і `right : Int -> String -> String` беруть n символів відповідно з лівого або правого боку рядка тексту.

```elm
left 2 "Mulder" 
    --> "Mu"
right 2 "Scully" 
    --> "ly"
```

`dropLeft : Int -> String -> String` і `dropRight : Int -> String -> String` відкидають n символів відповідно з лівого або правого боку рядка тексту.
```elm
dropRight 6 "Hello world." 
    --> "Hello"
dropLeft 6 "Hello world." 
    --> "world"
```

## Перевірка якостей рядка тексту

`length : String -> Int` повертає кількість символів у рядку тексту.
```elm 
length "Hello world." 
    --> 12
```

`isEmpty : String -> Bool` визначає, чи порожній рядок тексту.
```elm 
isEmpty "Hello world." 
    --> False
```

`contains : String -> String -> Bool` перевіряє, чи містить другий рядок тексту перший.
```elm
contains "the" "theory" 
    --> True
contains "THE" "theory" 
    --> False
```

`startsWith : String -> String -> Bool` і `endsWith : String -> String -> Bool` перевіряють, чи починається/закінчується другий рядок тексту заданим підрядком.
```elm
startsWith "the" "theory" 
    --> True
endsWith "ory" "theory" 
    --> True
```

`indexes : String -> String -> List Int` отримує масив усіх початкових індексів підрядка в іншому рядку тексту.
```elm
indexes "ss" "Mississippi"  
    --> [2, 5]
```

## Перетворення рядків тексту
`toInt : String -> Maybe Int` намагається перетворити рядок тексту на `Just Int`, а для неправильно оформлених рядків тексту повертає `Nothing`.
```elm
toInt "-42" 
    --> Just -42
toInt "3.1" 
    --> Nothing
toInt "two" 
    --> Nothing
```

`fromInt : Int -> String` перетворює ціле число на рядок тексту.
```elm
fromInt -42 
    --> "-42"
```

`toFloat : String -> Maybe Float` намагається перетворити рядок тексту на число з плаваючою комою, зазнаючи невдачі на неправильно оформлених рядках тексту.
```elm
toFloat "-42" 
    --> Just -42.0
toFloat "3.1" 
    --> Just 3.1
toFloat "two" 
    --> Nothing
```

`fromFloat : Float -> String` перетворює число з плаваючою комою на рядок тексту.
```elm
fromFloat 3.9 
    --> "3.9"
```

`toList : String -> List Char` і `fromList : List Char -> String` відповідно перетворюють рядок тексту на масив символів і навпаки.
```elm 
toList "abc" 
    --> ['a', 'b', 'c']
fromList ['a', 'b', 'c'] 
    --> "abc"
```

`fromChar : Char -> String` перетворює символ на рядок тексту.
```elm
fromChar 'a' 
    --> "a"
```

## Форматування рядків тексту

`toUpper : String -> String` і `toLower : String -> String` перетворюють рядки тексту відповідно на верхній або нижній регістр.
Стане в пригоді для порівнянь без урахування регістру.
```elm
toUpper "skinner" 
    --> "SKINNER"
toLower "X-FILES" 
    --> "x-files"
```

`pad : Int -> Char -> String -> String` доповнює рядок тексту з обох боків наданим `Char`, доки він не матиме заданої довжини.
```elm
pad 5 ' ' "11"  
    --> "  11 "
```
Так само `padLeft` і `padRight` доповнюють рядок тексту з відповідного боку, доки він не матиме заданої довжини.

`trim : String -> String` прибирає пробільні символи з обох боків рядка тексту.
```elm
trim "  hats  \n" 
    --> "hats"
```
`trimLeft` і `trimRight` прибирають пробільні символи з відповідного боку рядка тексту.

## Функції вищого порядку

`map : (Char -> Char) -> String -> String` перетворює кожен символ у рядку тексту заданою функцією.
Зауважмо, що надана функція має відображати `Char` у `Char`.
```elm
map (\c -> if c == '/' then '.' else c) "a/b/c" 
    --> "a.b.c"
```

`filter : (Char -> Bool) -> String -> String` залишає лише ті символи, які проходять перевірку.
```elm
filter isDigit "R2-D2" 
    --> "22"
```

`foldl : (Char -> b -> b) -> b -> String -> b` згортає рядок тексту, починаючи зліва.
Функція застосовується з першим символом як своїм першим параметром і наданим початковим значенням як другим параметром.
Результат функції має бути того самого типу, що й надане початкове значення, і застосовується до кожного символу по черзі.
```elm
foldl (\c acc -> Char.toCode c + acc) 0 "the sum of my unicode is " 
    --> 2260
```
`foldr` робить те саме, але починаючи з правого боку рядка тексту.

`any : (Char -> Bool) -> String -> Bool` визначає, чи повертає хоч один символ `True` для наданого предиката.
```elm
any isDigit "R2-D2" 
    --> True
any isDigit "heart" 
    --> False
```
`all : (Char -> Bool) -> String -> Bool` визначає, чи повертають усі символи в рядку тексту `True` для наданого предиката.
```elm
all isDigit "R2-D2" 
    --> False
all isAlpha "heart" 
    --> True
```
