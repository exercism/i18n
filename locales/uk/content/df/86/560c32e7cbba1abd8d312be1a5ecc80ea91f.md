# Інструкції

У своїй лабораторії дослідження ДНК ми перепробували різні способи стиснути дані досліджень, щоб заощадити місце для зберігання. Один із колег по команді пропонує перевести дані ДНК у двійкове подання:

| Нуклеїнова кислота | Код   |
| ------------ | ----- |
| Adenine      |  `00` |
| Cytosine     |  `01` |
| Guanine      |  `10` |
| Thymine      |  `11` |

Ми обмірковуємо цю пропозицію: вона потенційно зменшить витрати на зберігання даних, але коштом зручності для читання людиною. Ми вирішуємо написати модуль для кодування й декодування даних, щоб оцінити економію.

## 1. Кодування нуклеїнової кислоти в двійкове значення

Реалізуйте `encode_nucleotide`, щоб вона приймала нуклеотид і повертала цілочисельне значення закодованого коду.

```gleam
encode_nucleotide(Cytosine)
// -> 1
// (which is equal to 0b01)
```

## 2. Декодування двійкового значення в нуклеїнову кислоту

Реалізуйте `decode_nucleotide`, щоб вона приймала цілочисельне значення закодованого коду й повертала нуклеотид.

```gleam
decode_nucleotide(0b01)
// -> Ok(Cytosine)
```

## 3. Кодування масиву ДНК

Реалізуйте `encode`, щоб вона приймала масив нуклеотидів і повертала бітовий масив закодованих даних.

```gleam
encode([Adenine, Cytosine, Guanine, Thymine])
// -> <<27>>
```

## 4. Декодування бітового масиву ДНК

Реалізуйте `decode`, щоб вона приймала бітовий масив, який представляє нуклеїнову кислоту, і повертала декодовані дані як масив нуклеотидів.

```gleam
decode(<<27>>)
// -> Ok([Adenine, Cytosine, Guanine, Thymine])
```
