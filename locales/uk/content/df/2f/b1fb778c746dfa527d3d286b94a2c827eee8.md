# Інструкції

Ми захоплюємося спостереженням за птахами і ведемо облік того, скільки птахів завітало до нашого саду за останні сім днів.

На нас чекає шість завдань, і всі вони стосуються кількості птахів, які завітали до нашого саду.

## 1. Перевірте, якими були підрахунки минулого тижня

Для порівняння ми завжди тримаємо поруч копію підрахунків минулого тижня, які були такими: 0, 2, 5, 3, 7, 8 і 4. Реалізуйте метод `BirdWatcher.getLastWeek()`, який повертає підрахунки минулого тижня:

```java
BirdWatcher.getLastWeek();
// => [0, 2, 5, 3, 7, 8, 4]
```

## 2. Перевірте, скільки птахів завітало сьогодні

Реалізуйте метод `BirdWatcher.getToday()`, який повертає кількість птахів, що завітали до нашого саду сьогодні. Підрахунки птахів упорядковано за днями: перший елемент - це підрахунок найдавнішого дня, а останній - сьогоднішній підрахунок.

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getToday();
// => 1
```

## 3. Збільште сьогоднішній підрахунок на одиницю

Реалізуйте метод `BirdWatcher.incrementTodaysCount()`, який збільшує сьогоднішній підрахунок на одиницю:

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.incrementTodaysCount();
birdCount.getToday();
// => 2
```

## 4. Перевірте, чи був день, коли не завітав жоден птах

Реалізуйте метод `BirdWatcher.hasDayWithoutBirds()`, який повертає `true`, якщо був день, коли до саду не завітав жоден птах, а інакше повертає `false`:

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.hasDayWithoutBirds();
// => true
```

## 5. Порахуйте кількість птахів за вказану кількість днів

Реалізуйте метод `BirdWatcher.getCountForFirstDays()`, який повертає кількість птахів, що завітали до нашого саду від початку тижня, але обмежує підрахунок указаною кількістю днів від початку тижня.

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getCountForFirstDays(4);
// => 14
```

## 6. Порахуйте кількість насичених днів

Деякі дні бувають насиченішими за інші. Насичений день - це день, коли до нашого саду завітало пʼять або більше птахів.
Реалізуйте метод `BirdWatcher.getBusyDays()`, який повертає кількість насичених днів:

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getBusyDays();
// => 2
```
