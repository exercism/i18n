# Вступ

## Числа

У Python є три різні види вбудованих чисел: `ints`, `floats` і `complex`. Однак у цій вправі ми будемо мати справу лише з `ints` і `floats`.

### ints

`ints` - це цілі числа. Наприклад: `1234`, `-10`, `20201278`.

Цілі числа в Python мають [довільну точність][arbitrary-precision]: кількість цифр обмежує лише обсяг доступної памʼяті системи, на якій виконується код.

### floats

`floats` - це десяткові числа, тобто числа з десятковою точкою. Наприклад: `0.0`, `3.14`, `-9.01`.

Числа з плаваючою комою зазвичай реалізовано в Python через `double` у C _(точність до 15 десяткових знаків)_, але їхнє представлення залежить від системи та інших деталей реалізації. Це може спричиняти несподіванки під час роботи з такими числами, але для більшості ситуацій цього цілком достатньо.

## Арифметика

Python повністю підтримує арифметику між `ints` і `floats`. Коли використовуються бінарні арифметичні оператори (`+`, `-`, `*`, `/`, `//` і `%`), вужчі числа перетворюються так, щоб відповідати ширшим.

Python вважає `ints` вужчими за `floats`. Тому число з плаваючою комою у виразі гарантує, що й результат буде числом з плаваючою комою. Однак під час ділення результат завжди буде числом з плаваючою комою, навіть якщо використано лише цілі числа.

```python
# The int is widened to a float here, and a float type is returned.
>>> 3 + 4.0
7.0
>>> 3 * 4.0
12.0
>>> 3 - 2.0
1.0
# Division always returns a float.
>>> 6 / 2
3.0
>>> 7 / 4
1.75
# Calculating remainders.
>>> 7 % 4
3
>>> 2 % 4
2
>>> 12.75 % 3
0.75
```

Якщо потрібен результат у вигляді цілого числа, можна використати `//`, щоб відкинути дробову частину.

```python
>>> 6 // 2
3
>>> 7 // 4
1
```

Щоб перетворити число з плаваючою комою на ціле, можна використати `int()`. Щоб перетворити ціле число на число з плаваючою комою, можна використати `float()`.

```python
>>> int(6 / 2)
3
>>> float(1 + 2)
3.0
```
