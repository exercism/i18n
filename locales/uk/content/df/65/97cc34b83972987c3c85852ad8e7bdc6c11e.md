# Додаток до інструкцій

## Нотатки щодо WebAssembly

Сигнатура функції для експорту WebAssembly `convert` така:

```wasm
(func (export "convert")
    (param $arrOffset i32)
    (param $arrLength i32)
    (param $inputBase i32)
    (param $outputBase i32)
    (result i32 i32 i32)
)
```

Перші два параметри `$arrOffset` і `$arrLength` задають базове зміщення та довжину масиву 32-бітних знакових цілих чисел. Параметр довжини вимірюється кількістю елементів у масиві, а не байтами. Перед викликом цієї функції той, хто викликає, записує цей масив у лінійну памʼять WebAssembly, починаючи зі зміщення `$arrOffset`. Лінійна памʼять WebAssembly завжди подається у порядку little-endian.

Отже, той, хто викликає, закодував би масив `[1,2]` як таку послідовність із восьми байтів.

```
| 64 | 65 | 66 | 67 | 68 | 69 | 70 | 71 |
| ---- arr[0] ----- | ---- arr[1] ----- |
,0x01,0x00,0x00,0x00,0x02,0x00,0x00,0x00,
```

Параметри `$inputBase` і `$outputBase` не стосуються лінійної памʼяті.

Результат має тип `(i32 i32 i32)`. Перші два значення задають `offset` і `length` вихідних даних у лінійній памʼяті. За бажанням можна перезаписати адреси лінійної памʼяті, використані для вхідних даних. Третє повернене значення містить код стану i32, який використовують для обробки помилок.

Якщо третє повернене значення вказує на стан помилки, модульні тести не читають перші два повернені значення.
