# Докладніше

Принтер у Common Lisp виконує роль засобу для виведення даних у потоки. Одна з поширених функцій цього засобу - `format`.

`format` приймає два обовʼязкові параметри: потік, у який треба писати, і керуючий рядок тексту (англ. string). Вміст керуючого рядка тексту визначає, як використовуються подальші аргументи.

Перший параметр має два спеціальні значення: `t` і `nil`. `t` указує, що слід використати потік, привʼязаний до `*standard-output*`, а `nil` указує, що треба створити й повернути рядок тексту. `format` набуває значення `nil`, якщо параметр потоку не дорівнює `nil`.

Керуючий рядок тексту може містити директиви форматування, які позначаються символом `~`, після якого йде символ (регістр символу не має значення). Директива форматування визначає, чи споживає вона аргументи і як вони форматуються у потік.

Найважливіші базові директиви форматування:

* `~A` - форматує _естетично_, у «людиночитному» вигляді.
* `~S` - форматує у _стандартному_ вигляді, придатному для «читання машиною».
* `~%` - виводить символ нового рядка
* `~&` - виводить символ нового рядка, окрім випадку, коли ми вже на початку рядка.
* `~~` - виводить тильду.

Приклади:

```lisp
(format nil "The list is: ~A~%" (list 1 2 3)) ; => "The list is: (1 2 3)
                                                   "
(format nil "(format t ~S)" "hello world")    ; => "(format t \"hello world\""
(format nil "~&fresh~&lines")                 ;=> "fresh
                                                   lines"
(format nil "directives start with a ~~")     ; => "directives start with a ~"
```
