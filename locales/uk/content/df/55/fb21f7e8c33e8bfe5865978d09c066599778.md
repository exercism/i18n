# Про комбінатори

Комбінатори перетворюють закономірності перемішування стека на іменовані слова, які можна поєднувати. Коли ми напишемо достатньо коду на Factor, ми вже не думатимемо «треба `dup`, потім виконати F, а тоді зберегти початкове значення», а просто напишемо `[ F ] keep`.

| закономірність                        | перемішування                 | комбінатор      |
|------------------------------------|-------------------------------|-----------------|
| застосувати F, зберегти вхідні дані | `dup F swap`                  | `[ F ] keep`    |
| дві функції від одного вхідного значення | `dup F swap G`            | `[ F ] [ G ] bi`|
| три функції від одного вхідного значення | заплутано                 | `[ F ] [ G ] [ H ] tri` |
| багато функцій від одного вхідного значення | дуже заплутано        | `{ Fs … } cleave`|
| працювати зі значеннями *під* верхівкою | `swap F swap`             | `[ F ] dip`     |
| та сама операція над двома значеннями | `swap F swap F`             | `[ F ] bi@`     |
| різні операції над двома значеннями | `swap F swap G`              | `[ F ] [ G ] bi*`|

Сімейство слів із префіксом `2` (`2bi`, `2dip`, `2tri`, `2dup`, `2drop`, `2nip`, `2swap`) робить те саме, коли кожній операції потрібно *два* вхідні значення; `3dup` і `4dup` поширюють прийом дублювання на три чи чотири значення на верхівці стека.

Окрім родини cleave/dip/bi, [`kernel`][kernel] також пропонує варіанти керування потоком виконання, які чисто передають `f` далі:

| слово       | дія                                                 |
|-------------|-----------------------------------------------------|
| `if*`       | гілка правди бачить значення; гілка неправди - ні   |
| `?last`     | останній елемент послідовності, або `f`, якщо вона порожня |
| `pop*`      | варіант `pop`, який відкидає значення (змінює вектор) |
| `dupd`      | продублювати *друге* значення від верхівки          |
| `pick`      | скопіювати *третє* значення від верхівки на верхівку |
| `swapd`     | поміняти місцями друге і третє значення від верхівки |
| `rotd`      | обернути нижні три значення з чотирьох на стеку     |
| `tuck`      | скопіювати верхівку під друге значення від верхівки |
| `with`      | вбудувати фіксоване значення в quotation для HOS    |
| `while`     | цикл, поки виконується предикат                     |
| `until`     | цикл, доки не виконається предикат                  |

Вибір правильного комбінатора - це сама по собі навичка. Загальне правило: коли в тілі визначення йде більше ніж одне слово перемішування підряд, зазвичай є комбінатор, який точніше передає задум.

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
