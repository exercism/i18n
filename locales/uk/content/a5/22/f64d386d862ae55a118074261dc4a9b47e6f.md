# Тести

## Встановлення засобу запуску тестів для треку Exercism GDScript

Щоб скористатися засобом запуску тестів, нам знадобиться правильно [встановлений Godot][installation].

Щоб збирати і тестувати скрипти GDScript для Exercism, Godot буде запускатися в «headless»-режимі з CLI. Ці вказівки наразі вимагають Linux і bash.

### Крок 1: Встановлення загальної інфраструктури засобу запуску тестів

Щоб налаштувати тестування, клонуймо [https://github.com/exercism/gdscript-test-runner][gdscript-test-runner] і перемістімо його вміст до `/opt/test-runner/`:

```sh
git clone https://github.com/exercism/gdscript-test-runner.git
sudo mkdir -p /opt/
sudo mv gdscript-test-runner/ /opt/test-runner/
```

### Крок 2: Завантаження скрипту засобу запуску тестів для однієї вправи

Якщо інструмент `exercism` уже налаштовано і ми завантажили принаймні одну вправу GDScript, він мав створити теку `exercism/gdscript` для зберігання вправ.
Збережімо [засіб запуску тестів][test-local-gdscript-solution] у цій теці та позначмо файл як виконуваний, або просто створімо посилання на нього:

```sh
cd ~/exercism/gdscript # replace with your exercism/gdscript directory
ln /opt/test-runner/bin/test-local-gdscript-solution.sh
```

## Запуск тестів

Коли кроки встановлення виконано, ми зможемо почати з будь-якої теки вправи (наприклад, `~/exercism/gdscript/two-fer`) і запустити скрипт (який лежить на рівень вище, у `../`), щоб перевірити власне локальне рішення цієї вправи:

```sh
../test-local-gdscript-solution.sh
```
