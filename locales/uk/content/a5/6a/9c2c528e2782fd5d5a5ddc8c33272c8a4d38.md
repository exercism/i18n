# Вступ

Символи у Factor - це цілі числа, кодові точки Unicode, тож числові оператори `<`, `>`, `=` напряму дають упорядкування з урахуванням регістру. Словник [`unicode`][unicode] додає предикати, які враховують Unicode, та перетворення регістру для одного символу.

## Предикати для символів

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
digit>   ( c -- n )    ! the integer value of a digit char
blank?   ( c -- ? )    ! whitespace
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
CHAR: 7 digit>  .    ! => 7
```

## Перетворення регістру

`ch>upper` і `ch>lower` змінюють регістр одного символу. `>upper` і `>lower` працюють на рівні рядка тексту (англ. string) і застосовують їх до кожного символу рядка тексту.

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```

`capitalize` переводить увесь рядок тексту в нижній регістр, а потім перший символ у верхній, тобто робить так, що слово пишеться з великої літери:

```factor
"hELLO" capitalize .   ! => "Hello"
```

## Літерали символів

`CHAR: A` розбирається в ціле число, кодову точку символу `A`. Для іменованих символів використовуємо назви `space`, `tab`, `\n` тощо:

```factor
CHAR: A .        ! => 65
CHAR: space .    ! => 32
CHAR: \n .       ! => 10
```

## Позначки

Коли слово має повернути тег, а не значення, скажімо, `yes`/`no`/`maybe` замість булевого значення (англ. Boolean), оголошуємо кожен тег як *позначку*. Позначка - це слово, яке при виклику кладе на стек саму себе, і дві позначки вважаються рівними, лише коли мають те саме імʼя.

```factor
USING: kernel ;

SYMBOLS: yes no maybe ;

yes .    ! => yes
yes yes = .    ! => t
yes no = .     ! => f
```

`SYMBOL: name` оголошує одну; `SYMBOLS: a b c ;` оголошує кілька.
