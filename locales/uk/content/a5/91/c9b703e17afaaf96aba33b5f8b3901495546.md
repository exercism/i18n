# Про

Функції для роботи з введенням і виведенням надає [модуль `IO`][module-io].

- [`IO.puts/2`][io-puts] записує рядок тексту (англ. string) у стандартне виведення, а потім додає символ нового рядка. Повертає `:ok`.
- [`IO.write/2`][io-write] записує рядок тексту у стандартне виведення, не додаючи символу нового рядка. Повертає `:ok`.
- [`IO.gets/2`][io-gets] читає рядок зі стандартного введення.
- [`IO.inspect/2`][io-inspect] записує будь-що у стандартне виведення та приймає корисні опції, як-от `:label`. Повертає значення, яке їй передали, без змін. Стане в пригоді для налагодження.

## Протокол `String.Chars`

Якщо ми спробуємо передати в [`IO.puts/2`][io-puts] значення, яке вона не може вивести, ми побачимо помилку `Protocol.UndefinedError`.

```elixir
IO.puts({:ok, 7})
# ** (Protocol.UndefinedError) protocol String.Chars not implemented for {:ok, 7} of type Tuple
```

У такому разі варто скористатися [`IO.inspect/2`][io-inspect].

## `IO.inspect/2` для налагодження

[`IO.inspect/2`][io-inspect] ідеально підходить для налагодження, бо повертає свій аргумент без змін, уміє вивести будь-що і має опцію `:label`.

```elixir
"HELLO\n"
|> String.trim()
|> IO.inspect(label: "step 1")
|> String.downcase()
|> IO.inspect(label: "step 2")

# > step 1: "HELLO"
# > step 2: "hello"
# => "hello"
```

## Пристрої введення-виведення

Першим аргументом усіх цих функцій є [пристрій введення-виведення][io-devices], який типово має значення `:stdio` (стандартне введення/виведення). Щоб писати в пристрій стандартних помилок, використаймо `:stderr`. Пристроєм введення-виведення може бути й процес, наприклад створений викликом [`File.open/2`][file-open], що дало б змогу писати у файл.
