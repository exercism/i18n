# Вступ

JavaScript - динамічна мова, яка підтримує обʼєктно-орієнтований, імперативний і декларативний (наприклад, функційний) стилі програмування.

## (Пере)присвоєння

У JavaScript є кілька основних способів присвоїти значення іменам: за допомогою змінних або констант. На Exercism змінні завжди записують у [camelCase][wiki-camel-case], а константи - у [SCREAMING_SNAKE_CASE][wiki-snake-case]. Немає офіційного посібника, якого треба дотримуватися, і різні компанії та організації мають різні настанови щодо стилю. _Змінні можна записувати як завгодно_. Якщо записувати їх так, як підготовлено у вправах, вони будуть по-іншому підсвічені в інтерфейсі сайту та більшості IDE.

Змінні в JavaScript можна визначати за допомогою ключового слова [`const`][mdn-const], [`let`][mdn-let] або [`var`][mdn-var].

Змінна, оголошена через `let` або `var`, може протягом свого існування посилатися на різні значення. Наприклад, `myFirstVariable` можна визначати й перевизначати багато разів за допомогою оператора присвоєння `=`:

```javascript
let myFirstVariable = 1;
myFirstVariable = 'Some string';
myFirstVariable = new SomeComplexClass();
```

На відміну від `let` і `var`, змінній, визначеній через `const`, можна присвоїти значення лише один раз. Саме так у JavaScript визначають константи.

```javascript
const MY_FIRST_CONSTANT = 10;

// Cannot be re-assigned.
MY_FIRST_CONSTANT = 20;
// => TypeError: Assignment to constant variable.
```

> 💡 У пізнішій навчальній вправі ми розглянемо й пояснимо різницю між присвоєнням чи звʼязуванням константи та її значенням.

## Оголошення функцій

У JavaScript одиниці функціональності вміщуються у _функціях_; якщо функції належать одна одній, їх зазвичай групують в одному файлі. Такі функції можуть приймати параметри (аргументи) і _повертати_ значення за допомогою ключового слова `return`. Функції викликають за допомогою синтаксису `()`.

```javascript
function add(num1, num2) {
  return num1 + num2;
}

add(1, 3);
// => 4
```

> 💡 У JavaScript є _багато_ різних способів оголосити функцію. Ці інші способи мають інакший вигляд, ніж використання ключового слова `function`. Трек намагається знайомити з ними поступово, але якщо вони вже знайомі, можна сміливо користуватися будь-яким із них. У більшості випадків жоден із них не кращий і не гірший.

## Надання доступу іншим файлам

Щоб зробити `function`, константу чи змінну доступними в _інших файлах_, їх потрібно [експортувати][mdn-export] за допомогою ключового слова `export`. Тоді інший файл може [імпортувати][mdn-import] їх за допомогою ключового слова `import`. Це також називають системою модулів. Чудовий приклад - це те, як працюють усі тести. Кожна вправа має щонайменше один файл, наприклад `lasagna.js`, який містить _реалізацію_. Крім того, є щонайменше один інший файл, наприклад `lasagna.spec.js`, який містить _тести_. Цей файл _імпортує_ публічні (тобто експортовані) сутності, щоб протестувати реалізацію:

```javascript
// file.js
export const MY_VALUE = 10;

export function add(num1, num2) {
  return num1 + num2;
}

// file.spec.js
import { MY_VALUE, add } from './file';

add(MY_VALUE, 5);
// => 15
```
