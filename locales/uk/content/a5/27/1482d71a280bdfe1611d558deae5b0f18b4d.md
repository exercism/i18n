# Додаток до інструкцій

## Зарезервована памʼять

Буфер для вхідного рядка тексту (англ. string) використовує байти 64-191 лінійної памʼяті.

## Формат вхідних даних

Вхідні дані надходять як один рядок тексту, що містить три рядки, кожен із яких закінчується символом переведення рядка. Хрестики та нулики завжди будуть великими літерами `X` та `O`.

Отже, поле

```
X··
OXO
XOX
```
буде закодовано як

```
"X  \nOXO\nXOX\n"
```
