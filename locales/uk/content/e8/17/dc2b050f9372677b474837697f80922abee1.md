# Додаток до інструкцій

## Реалізація

Якщо останній елемент масиву є `object`, а не `string`, він містить уточнювач, який змінює останній рядок прислівʼя.

```javascript
proverb('nail', 'shoe', { qualifier: 'horseshoe' });
// => For want of a nail the shoe was lost.
//    And all for the want of a horseshoe nail.
```
