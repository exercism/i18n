# Вступ

## Умовні конструкції if

### Логічні оператори

Java підтримує три логічні оператори: `&&` (логічне і), `||` (логічне або) та `!` (логічне заперечення).

### Умовна конструкція if

Основою будь-якої умовної операції є тип `boolean`, який може мати значення `true` або `false`. Умовні конструкції часто використовують як механізми керування потоком виконання, щоб перевіряти різні умови. Для перевірки конкретного випадку можна використати умовну конструкцію `if`, яка виконує свій код, якщо умова дорівнює `true`, ось так:

```java
int val;

if(val == 9) {
    // conditional code
}
```

У сценаріях із кількома випадками багато умовних конструкцій `if` можна обʼєднати в ланцюжок за допомогою конструкцій `else if` та `else`.

```java
if(val == 10) {
    // conditional code
} else if(val == 17) {
    // conditional code
} else {
    // executes when val is different from 10 and 17
}
```

### Конструкція switch

Java також надає конструкцію `switch` для сценаріїв із багатьма варіантами.

```java
int val;

// switch statement on variable content
switch(val) {
    case 1:
        // conditional code
        break;
    case 2: case 3: case 4:
        // conditional code
        break;
    default:
        // if all cases fail
        break;
}
```
