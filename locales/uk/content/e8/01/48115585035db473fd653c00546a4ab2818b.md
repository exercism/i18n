# Про

Булеві значення (англ. Boolean) в Rust представлені типом `bool`, який може мати одне з двох значень: `true` або `false`.

Rust підтримує один [оператор логічного заперечення][negation operators]: `!` (заперечення).

Rust підтримує шість [операторів порівняння][comparison operators]: `==` (дорівнює), `!=` (не дорівнює), `>` (більше ніж), `<` (менше ніж), `>=`
(більше або дорівнює), `<=` (менше або дорівнює). Їх можна використовувати, щоб порівнювати небулеві значення й отримувати булеве значення.

```rust
1 > 0 // true
1 < 0 // false
1 == 0 // false
1 != 0 // true
1 >= 0 // true
1 <= 0 // false
```

На відміну від деяких інших мов, `0` не є `false`, а ненульове значення не є `true`.

Rust підтримує три [логічні бінарні оператори][logical binary operators]: `&` (логічне і), `|` (логічне або), `^` (логічне виключне або).

Rust підтримує два [булеві оператори][lazy boolean operators]: `||` (логічне або), `&&` (логічне і). Вони відрізняються від `|` і `&` тим, що правий операнд
обчислюється лише тоді, коли лівий операнд ще не визначає результат виразу. Тобто `||` обчислює
свій правий операнд лише тоді, коли лівий операнд має значення `false`, а `&&` лише тоді, коли він має значення `true`.

```rust
true || false // == true; the right-hand side was not evaluated
true && false // == false
```
