# Instructions

Наше завдання - зʼясувати, чи є в пакеті цукерок колір, який становить більшість вмісту пакета. 🍬 Елемент більшості - це той, який займає понад половину місця в колекції. Маючи масив елементів, що позначають кольори, повертаємо колір, який становить більшість, інакше вказуємо, що більшості не знайдено.

Для простого масиву `[Red, Red, Blue, Red, Green]` поверненим значенням має бути Red, бо Red трапляється 3 рази з 5. Але для масиву `[Red, Red, Blue, Green]` більшості немає, хоч Red і найчастіший елемент, бо 2/4 не більше за половину елементів.
