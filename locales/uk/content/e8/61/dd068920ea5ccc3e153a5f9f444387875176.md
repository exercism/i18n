# Докладніше

[Цикл `while`][while-loops] - це конструкція керування потоком виконання, яка дозволяє виконувати код, поки певна умова є правдою.
Swift надає два види циклів `while`: цикл `while` і цикл `repeat-while`.
Умова циклу `while` обчислюється до виконання тіла циклу; якщо умова неправдива, тіло циклу не виконається взагалі.
Цикли `while` у Swift мають таку структуру:

```swift
while <#condition#> {
  <#code#>
}
```

Тут цикл виконуватиметься, поки count більше за 0, і надрукує числа 2, 1 та «Liftoff!».

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

[Цикл `repeat-while`][while-loops] схожий на цикл `while`, але умова обчислюється після виконання тіла циклу.
Це означає, що тіло циклу виконається принаймні один раз, навіть якщо умова неправдива.
Цикли `repeat-while` у Swift мають таку структуру:

```swift
repeat {
  <#code#>
} while <#condition#>
```

Тут цикл виконається лише один раз, оскільки умова неправдива.
Оскільки це цикл `repeat-while`, тіло циклу виконається один раз, перш ніж обчислиться умова.

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```

## Цикли з опціональним звʼязуванням

Одним із поширених варіантів циклів `while` у Swift є цикл `while` з опціональним звʼязуванням.
Такі цикли повторюються, доки виклик якоїсь функції, що повертає опціональне значення, дає значення, відмінне від `nil`.
Це (неопціональне) значення потім звʼязується з вибраним нами іменем, і його можна використовувати в тілі циклу.

```swift
var arr = [1,2]
while let count = arr.popLast() {
  print("\(count)…")
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```
