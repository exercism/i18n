# Додаток до інструкцій

## Регістри

| Регістр | Призначення | Тип | Опис |
| -------- | --------- | ------- | ------------------------------------- |
| `$a0`    | вхідні дані | адреса | рядок тексту (англ. string) із вісімкових символів, завершений нульовим символом |
| `$v0`    | вихідні дані | ціле число | десяткове значення вхідного рядка тексту |
| `$t0-9`  | тимчасовий | будь-який | використовується для тимчасового зберігання |
