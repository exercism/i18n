# Вступ

## Try/Rescue/Else/After

Конструкція `try..rescue` - потужний засіб, який дає змогу перехоплювати помилки, коли вони виникають. Перехоплення помилок дає змогу функціям повертати визначені значення, коли це потрібно. Конструкція `try..rescue` також пропонує нам дві додаткові можливості, які ми можемо використати:

- блок `else`
  - Коли блок `try` виконується успішно, його результат зіставляється з цим блоком.
- блок `after`
  - Незалежно від того, чи блок `try` завершується успішно, чи з помилкою, код у блоці `after` виконується завжди, якщо на цей момент програма ще працює.
  - Результат блоку `after` не повертається до області видимості, з якої його викликали.

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```

## Динамічна диспетчеризація

Коли Elixir визначає, яку функцію потрібно викликати, він використовує назву модуля, щоб виконати пошук. Пошук можна виконати динамічно, якщо назву модуля привʼязано до змінної.

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```

Назва модуля в Elixir - це атом. Усі атоми модулів Elixir автоматично отримують префікс `Elixir.`

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```
