# Вступ

У Factor умовні конструкції вибирають між **цитатами**, фрагментами коду, записаними в квадратних дужках, `[ ... ]`. Запис `[ ... ]` кладе код на стек як значення, а не виконує його; далі умовна конструкція вирішує, яку цитату виконати. (Цитати докладно розглянемо в одній із наступних вправ.)

`if` (з [`kernel`][kernel]) - це базова умовна конструкція Factor. Вона приймає булеве значення (англ. Boolean) і дві цитати: виконує першу, якщо булеве значення правдиве, і другу в іншому разі.

```
if ( ? then-quot else-quot -- )
```

```factor
: abs ( x -- y ) dup 0 < [ neg ] [ ] if ;
```

`when` виконує свою цитату лише тоді, коли булеве значення правдиве, а `unless` - лише коли неправдиве. Для багатоваріантного розгалуження є `cond` (з [`combinators`][combinators]):

```factor
USING: combinators ;

: classify ( n -- s )
    {
        { [ dup 0 <  ] [ drop "negative" ] }
        { [ dup 0 =  ] [ drop "zero"     ] }
        [ drop "positive" ]
    } cond ;
```

[combinators]: https://docs.factorcode.org/content/vocab-combinators.html
