# Вступ

## Agent

Модуль `Agent` надає абстракцію для породження [процесів та циклу _receive-send_][exercism-processes]. Далі процеси, запущені за допомогою модуля `Agent`, ми називатимемо _«агентними процесами»_. _Агентний процес_ можна вибрати для представлення центрального спільного стану.

Щоб запустити _агентний процес_, `Agent` надає функцію `start/2`. Функція, яку ми передаємо, коли викликаємо `start` для _агентного процесу_, повертає початковий стан процесу:

```elixir
# Start an agent process with an initial value of an empty list
{:ok, agent_pid} = Agent.start(fn -> [] end)
```

Як і `Map` чи `List`, `Agent` надає багато функцій для роботи з _агентними процесами_.

Зазвичай усю функціональність, повʼязану з `Agent`, організовують і інкапсулюють у модуль для предметної області, яку моделюють.

[exercism-processes]: https://exercism.org/tracks/elixir/concepts/processes
