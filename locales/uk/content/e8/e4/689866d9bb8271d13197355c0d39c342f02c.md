# Вступ

Іноді частину стану потрібно спільно використовувати кільком словам, не протягуючи його щоразу через їхні стекові ефекти. *Динамічні змінні* у Factor, оголошені за допомогою `SYMBOL:`, дають кожному слову доступ до значення, збереженого в просторі імен.

## `SYMBOL:` і `SYMBOLS:`

`SYMBOL: name` оголошує одну змінну. `SYMBOLS: a b c ;` оголошує одразу кілька:

```factor
USING: namespaces ;

SYMBOLS: counter total ;
```

## Встановлення та отримання

`set-global` і `get-global` (у [`namespaces`][namespaces]) працюють із глобальним простором імен:

```
set-global    ( value variable -- )
get-global    ( variable -- value )
change-global ( variable quot: ( old -- new ) -- )
```

```factor
0 counter set-global
counter get-global .         ! => 0
counter [ 10 + ] change-global
counter get-global .         ! => 10
```

Для стану на рівні модуля потрібні саме варіанти з `-global`.

## Привʼязки в межах області видимості за допомогою `with-variable`

Динамічна змінна підтримує також другий варіант, *з областю видимості*. `set` / `get` / `change` (без суфікса `-global`) читають і записують *поточну* динамічну область видимості, а `with-variable` (у [`namespaces`][namespaces]) створює нову область видимості на час виконання quotation:

```
with-variable ( value variable quot -- )
set           ( value variable -- )
get           ( variable -- value )
change        ( variable quot: ( old -- new ) -- )
```

Змінна привʼязана до `value`, поки виконується `quot`; щойно він завершується, привʼязка зникає. Це дає змогу зовнішньому коду «впорснути» значення, яке внутрішній код може прочитати, не протягуючи його через кожну сигнатуру стека.

```factor
SYMBOL: greeting

"Hello" greeting [
    greeting get .                ! => "Hello"
    "Howdy" greeting set
    greeting get .                ! => "Howdy"
    greeting [ "!" append ] change
    greeting get .                ! => "Howdy!"
] with-variable

greeting get-global .    ! => f   (the scoped binding is gone)
```

У цій вправі ми вживаємо глобальний варіант, але вміння розпізнати паралельне сімейство `set`/`get`/`change` стане в пригоді, коли ми читаємо чужий код.

## Змінні вектори

Оскільки динамічні змінні тримають посилання, можна зберігати в них *змінну* колекцію й оновлювати її на місці:

```factor
SYMBOL: history

V{ } clone history set-global
"first event" history get-global push
"second event" history get-global push
history get-global .
! => V{ "first event" "second event" }
```

`V{ … }` - літерал вектора. Перед збереженням літерала `V{ }` завжди викликаймо `clone`: літерали спільні між викликами.

## `find` - перший збіг

`find` (у [`sequences`][sequences]) повертає перший елемент, для якого предикат істинний, а також його індекс:

```
find ( seq quot -- index elt/f )
```

Якщо нічого не збігається, обидва значення дорівнюють `f`. Відкинути індекс за допомогою `nip` і скористатися `unless*` - це стандартна комбінація «типове значення, якщо нічого не знайдено».

## `reject` - відкидання збігів

`reject` (також у [`sequences`][sequences]) - протилежність до `filter`: він повертає елементи, які *не задовольняють* предикат.
