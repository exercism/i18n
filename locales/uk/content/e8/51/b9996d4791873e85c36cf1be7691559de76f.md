# Остача

У математиці **остача** означає те, що залишається після виконання певного обчислення.
Наприклад, остача від `5 / 3` дорівнює `2`.

Багато мов програмування використовують знак відсотка (`%`) як оператор для обчислення остачі.
Наприклад:
```javascript
5 % 3 == 2
```

Остачу часто можна обчислити як для цілих чисел, так і для чисел з плаваючою комою.
Наприклад,
```javascript
5.3 % 3 == 2.3
```

Працюючи з відʼємними числами, результат завжди має той самий знак, що й ділене (число ліворуч, яке ділиться).
Наприклад:
```javascript
-5 % 3 == -2
5 % -3 == 2
-5 % -3 == -2
```

Деякі мови (наприклад, Python) використовують оператор `%` для обчислення модуля, а не остачі.
Це по-іншому обробляє відʼємні числа.
Більше про це можна дізнатися [у Вікіпедії](https://en.wikipedia.org/wiki/Modulo).
