# Інструкції

У цій вправі нам потрібно реалізувати кілька функцій для роботи з масивом мов програмування.

## 1. Визначте функцію, яка повертає порожній масив мов

Визначте функцію `new/0`, яка не приймає аргументів і повертає порожній масив.

```elixir
LanguageList.new()
# => []
```

## 2. Визначте функцію, яка додає мову до масиву

Визначте функцію `add/2`, яка приймає 2 аргументи (_масив мов_ і рядок тексту (англ. string) _мови_). Вона має повернути отриманий масив, додавши нову мову на початок наданого масиву.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Clojure")
# => ["Clojure"]
language_list = LanguageList.add(language_list, "Haskell")
# => ["Haskell", "Clojure"]
```

## 3. Визначте функцію, яка вилучає мову з масиву

Визначте функцію `remove/1`, яка приймає 1 аргумент (_масив мов_). Вона має повернути масив без першого елемента. Припускаємо, що в масиві завжди буде принаймні один елемент.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Clojure")
# => ["Clojure"]
language_list = LanguageList.add(language_list, "Haskell")
# => ["Haskell", "Clojure"]
language_list = LanguageList.remove(language_list)
# => ["Clojure"]
```

## 4. Визначте функцію, яка повертає перший елемент масиву

Визначте функцію `first/1`, яка приймає 1 аргумент (_масив мов_). Вона має повернути першу мову в масиві. Припускаємо, що в масиві завжди буде принаймні один елемент.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elm")
# => ["Elm"]
language_list = LanguageList.add(language_list, "Prolog")
# => ["Prolog", "Elm"]
LanguageList.first(language_list)
# => "Prolog"
```

## 5. Визначте функцію, яка повертає кількість мов у масиві

Визначте функцію `count/1`, яка приймає 1 аргумент (_масив мов_). Вона має повернути кількість мов у масиві.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elm")
# => ["Elm"]
language_list = LanguageList.add(language_list, "Prolog")
# => ["Prolog", "Elm"]
LanguageList.count(language_list)
# => 2
```

## 6. Визначте функцію, яка визначає, чи містить масив функціональну мову

Визначте функцію `functional_list?/1`, яка приймає 1 аргумент (_масив мов_). Вона має повернути булеве значення (англ. Boolean). Вона має повертати правду, якщо _Elixir_ є однією з мов у масиві.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elixir")
# => ["Elixir"]
LanguageList.functional_list?(language_list)
# => true
```
