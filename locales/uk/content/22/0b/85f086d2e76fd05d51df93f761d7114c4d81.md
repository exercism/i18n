# Уникайте імперативних циклів

У цій вправі уникайте циклів `for`.

Як зазначено у вступі, в обʼєкта Array у JavaScript є вбудовані методи, призначені для аналізу.

Перегляньте вступ та/або [документацію MDN](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array#instance_methods) про те, які методи можна використовувати.
