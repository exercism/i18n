# Про

Вбудовані числові типи в C++ поділяються на цілі числа та числа з плаваючою комою.
Цілі числа - це числа без дробової частини, як-от `0`, `691` чи `-2`.
Числа з плаваючою комою - це числа з десятковою точкою, як-от `6.02214076`, `0.1` чи `-1.616`.

## Цілі числа
У наступному прикладі показано оголошення та ініціалізацію чотирьох різних змінних

```cpp
int m_morales{9241};              // base 10: 0-9
int a_apaec{0x24CD};              // base 16: 0-9 and A-F
int m_gargan{0b10010000011001};   // base  2: 0-1
int b_reilly{022031};             // base  8: 0-7
                                  // Leading with a 0 not the letter o.
```

Коли ми присвоюємо значення змінній типу `int`, це можна зробити безпосередньо за допомогою літерала.
Літерал - це жорстко задане в коді число, як-от `9241`.
Для різних основ запису числа існують різні цілочисельні літерали.
Десяткові цілочисельні літерали найпоширеніші, вони використовують цифри від `0` до `9`.
Додавши спеціальний префікс, як-от `0x`, можна використовувати інші основи.
Наведений вище приклад показує число `9421` у чотирьох представленнях із відповідними префіксами.
Усі змінні ініціалізовано одним і тим самим значенням.

Щоб дізнатися більше про різні системи представлення, зазирнімо до [невеликого туторіалу][cpp_numerical_bases].

Щоб полегшити читання, цифри можна розділяти апострофом.
`9'241` - те саме, що `0b0100'100'0001'1001` або `92'4'1`.

## Числа з плаваючою комою

Літерали з плаваючою комою бувають двох видів.
Крім інтуїтивного `0.0024`, можна використати його науковий запис `2.4e-3`.
Найпоширеніший тип із плаваючою комою - `double`.

## Арифметика

C++ підтримує `+`, `-`, `*`, `/`, `(` і `)` та `%` для побудови виразів.
Операція між двома цілими числами дає в результаті теж ціле число.
`5 / 2` поверне `2`.
Якщо серед задіяних типів є тип із плаваючою комою, то й результат буде числом з плаваючою комою.
`5.0 / 2` і `5 / 2.0` повернуть `2.5`.
`%` - це оператор остачі (від ділення), він повертає остачу від ділення цілих чисел: `5%3` дає `2`.

## Оператор присвоєння

Оператор присвоєння присвоює змінній літерал.
Присвоєння завжди відбувається справа наліво, і ніколи навпаки.

```cpp
int length = 5;
int width = 2;
length = width;
```

Тут ціле значення `5` присвоюється змінній `length`.
Потім ціле значення `2` присвоюється змінній `width`.
Нарешті значення `width` копіюється у змінну `length`, а попереднє значення `5` буде втрачено.
Звернімо увагу й на те, що значення `width` присвоюється `length` лише в момент виконання операції присвоєння.
Тож якщо значення `width` зміниться пізніше, це не вплине на значення, яке має `length`.

Оператор присвоєння можна поєднувати з іншими операторами (арифметичними та побітовими), відомими як оператори `compound assignment`: `+=`, `-=`, `*=`, `/=`, `%=`.
Ці оператори змінюють поточне значення змінної, виконуючи над ним операцію.

```cpp
// we start with 0 people
int people{};
// we need 0 eggs
int eggs{};
// two people joined:
people += 2;
// people is now 2
// let's add 3 eggs per person
eggs += 3 * people;
// eggs is now 6
```

Змінні `people` та `eggs` ініціалізовано значенням `0`.
Далі ми додаємо ціле значення `2` до наявного значення `0` змінної `people` і присвоюємо результат назад змінній `people`.
Тепер `people` дорівнює `2`.
Потім ми додаємо `3` яйця на кожну людину, і разом виходить `6` яєць.
Тепер додамо ці `6` до наявного значення `0` змінної `eggs` і присвоїмо результат назад змінній `eggs`.
Тепер `eggs` дорівнюватиме `6`.
Еквівалентний вираз мав би такий вигляд: `people = people + 2` та `eggs = eggs + (3 * people)`.

## Приведення типів

Приведення типів - це перетворення одного типу на інший.
Якщо потрібен `double`, на його місці можна використати `int`.
У наведеному вище прикладі `5.0 / 2` працює неявне приведення `2` до `2.0`.
`double`, приведений до `int`, може втратити частину інформації.
Гарною практикою є робити такі приведення до іншого типу T явними за допомогою `static_cast<T>`.
Старе приведення в стилі C через `(T)` не рекомендується в сучасному C++, але його все ж варто знати.

```cpp
double pi{3.14};
int about_2_times_pi_cpp{static_cast<int>(pi) * 2};
// Old C-style cast:
int about_2_times_pi_c{(int)pi * 2};
```

## Точність і представлення

Числа в C++ не можуть бути як завгодно великими.
Наприклад, `int` представлено 32 бітами.
Цього достатньо для `2^32` чисел, тобто приблизно 4 мільярдів.
З урахуванням `0` це робить найбільшим і найменшим числом типу `int` значення `-2^31` та `2^31 - 1`.

Числа з плаваючою комою зазвичай реалізують із точністю до 15 десяткових знаків, але їхнє представлення залежить від системи, на якій виконується код.
