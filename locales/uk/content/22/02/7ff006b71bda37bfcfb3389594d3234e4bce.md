# Про це

Список у Gleam - це незмінна колекція, що містить нуль або більше значень. Усі значення в списку мають бути одного типу. Оскільки списки незмінні, щойно список створено, його значення вже ніколи не зміниться. Будь-які функції чи оператори, які нібито змінюють список (наприклад, додають елемент), насправді повертають новий список.

Списки можна визначати так:

```gleam
let empty = []
let singleValue = [5]
let threeValues = ["a", "b", "c"]
```

Найпоширеніший спосіб додати елемент до списку - додати його на початок за допомогою синтаксису розгортання:

```gleam
let two_to_four = [2, 3, 4]
let one_to_four = [1, ..two_to_four]
// -> [1, 2, 3, 4]
```

Модуль [`gleam/list`](https://hexdocs.pm/gleam_stdlib/gleam/list.html) зі стандартної бібліотеки Gleam містить багато корисних функцій для роботи зі списками. Цей модуль дуже часто використовують у коді Gleam, тож варто з ним ознайомитися.

Зразки списків можна використовувати у виразах case, щоб зіставляти списки та присвоювати змінним значення, які в них містяться:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [] -> "Empty list"
    [x] -> "List with one item: " <> x
    [x, y] -> "List with two items: " <> x <> " and " <> y
    _ -> "List with three or more items"
  }
}
```

Окрім зіставлення зі списками точної довжини, синтаксис розгортання дає змогу зіставляти зі списками щонайменше заданої довжини:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [_, _, ..] -> "List with at least two items"
    [_] -> "List with one item"
    [] -> "Empty list"
  }
}
```

Синтаксис розгортання також дає змогу присвоїти решту списку змінній:

```gleam
pub fn remove_first_item(list: List(String)) -> List(String) {
  case list {
    // Return the list without the first item
    [_, ..rest] -> rest

    // There's no first item to remove, return an empty list
    _ -> []
  }
}
```

У виразах case має бути зразок для кожного можливого значення типу, з яким виконується зіставлення, тож для обробки решти значень часто використовують завершальний зразок-замінник (`_`).
