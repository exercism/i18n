# Вступ

`vector` у Clojure - це послідовна, індексована, незмінна колекція з нуля або більше значень. Це означає, що після створення вектора його не можна змінити. Функції для роботи з векторами повертають новий вектор, а початковий вектор залишається незмінним. Значення у векторі можуть мати різнорідні типи. Вектори можна визначати так:

```clojure
(def empty [])
(def single-value [5])
```

Елементи можна отримати з вектора за індексом. Вектори в Clojure індексуються з нуля, тобто індекс першого елемента завжди дорівнює нулю:

```clojure
(def numbers [2 3 5])
;; Read value from vector
(get numbers 2)
;;=> 5
;; Update value in vector
(assoc numbers 2 9)
;;=> [2 3 9]
```

Початковий вектор залишається незмінним:

```clojure
numbers
;;=> [2 3 5]
```

Щоб запамʼятати оновлене значення, його потрібно передати далі або зберегти у var:

```clojure
(def updated-numbers
  (assoc numbers 2 9))
(get updated-numbers 2)
;;=> 9
```
