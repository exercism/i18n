# Тести

Щоб скористатися засобом запуску тестів, нам знадобиться правильно [встановлений Godot][installation].

## Запуск тестів

[Засіб запуску тестів][test runner] використовується для завантаження й перевірки рішень.
Коли вправу завантажено локально, разом із нею додається копія засобу запуску тестів і скрипт оболонки, щоб його викликати.

Щоб запустити вправу, просто запустімо скрипт `run_tests` у каталозі вправи за допомогою `bash`.

Наприклад,

```bash
cd "$(exercism workspace)/gdscript/hello-world"
bash run_tests
```

[installation]: https://exercism.org/docs/tracks/gdscript/installation
[test runner]: https://raw.githubusercontent.com/exercism/gdscript-test-runner/refs/heads/main/bin/test_runner.gd
