# Вступ

Основним обʼєктно-орієнтованим конструктом у Java є _клас_, який поєднує дані (_поля_) та поведінку (_методи_).
Поля та методи класу називаються його _членами_.

Доступом до членів можна керувати за допомогою модифікаторів доступу, два найпоширеніші з яких:

- `public`: до члена можна отримати доступ з будь-якого коду (без обмежень).
- `private`: до члена можна отримати доступ лише з коду в тому самому класі.

Ми можемо уявити клас як шаблон для створення екземплярів цього класу.
Щоб створити екземпляр класу (також відомий як _обʼєкт_), використовується ключове слово `new`:

```java
class Car {
}

// Create two car instances
Car myCar = new Car();
Car yourCar = new Car();
```

Поля мають тип і назву (визначену в camelCase) і можуть бути визначені в будь-якому місці класу (за домовленістю в PascalCase):

```java
class Car {
    // Accessible by anyone
    public int weight;

    // Only accessible by code in this class
    private String color;
}
```

Можна за бажанням присвоїти полю початкове значення.
Якщо поле _не_ вказує початкового значення, йому буде присвоєно типове значення його типу.
Можна отримати доступ до значень полів екземпляра та оновити їх за допомогою точкової нотації.

```java
class Car {
    // Will be set to specified value
    public int weight = 2500;

    // Will be set to default value (0)
    public int year;
}

Car newCar = new Car();
newCar.weight; // => 2500
newCar.year;   // => 0

// Update value of the field
newCar.year = 2018;
```

Приватні поля зазвичай оновлюються як побічний ефект виклику методу.
Такі методи зазвичай не повертають жодного значення, і в цьому випадку тип повернення має бути `void`:

```java
class CarImporter {
    private int carsImported;

    public void importCars(int numberOfCars)
    {
        // Update private field from public method
        carsImported = carsImported + numberOfCars;
    }
}
```
