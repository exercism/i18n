# Інструкції

У цій вправі ми будемо моделювати компʼютерну систему з віконним інтерфейсом.
Ми створимо кілька вікон, які можна переміщати, змінювати в розмірі та показувати їхній вміст.
Наступне зображення ілюструє значення, з якими ми будемо працювати далі.

       |          ║                                                            ║

## 1. Визначте структуру Size

Визначте структуру з назвою `Size` з двома властивостями типу `Int`, `width` і `height`, які зберігають поточну ширину та висоту вікна відповідно.
Початкова ширина та висота мають дорівнювати 80 і 60 відповідно.
Додайте метод `resize(newWidth:newHeight:)`, який приймає нові параметри ширини та висоти й змінює властивості відповідно до нового розміру.

```swift
let size1080x764 = Size(width: 1080, height: 764)
// Returns Size
var size1200x800 = size1080x764
// Returns Size
size1200x800.resize(newWidth: 1200, newHeight: 800)
size1200x800.height
// Returns 800
```

## 2. Визначте структуру Position

Визначте структуру з назвою `Position` з двома властивостями типу `Int`, `x` і `y`, які зберігають поточну горизонтальну та вертикальну позицію відповідно верхнього лівого кута вікна.
Початкові значення x та y мають дорівнювати 0. Позиція (0, 0) - це верхній лівий кут екрана, причому значення `x` зростають, коли ми рухаємося праворуч, а значення `y` зростають, коли ми рухаємося вниз.

Додайте метод `moveTo(newX:newY:)`, який приймає нові параметри x та y і змінює властивості відповідно до нової позиції.

```swift
var point = Position(x: 10, y: 20)
// Returns Position
point.moveTo(newX: 100, newY: -100)
point.y
// Returns -100
```

## 3. Визначте клас Window

Визначте клас вікна з такими властивостями:

- `title` : `String`, початкове значення - "New Window"
- `screenSize` : `Size`, стале значення з `width` = 800 і `height` = 600
- `size` : `Size`, початкове значення - типове значення структури `Size`
- `position` : `Position`, початкове значення - типове значення структури `Position`
- `contents` : `String?`, початкове значення - `nil`

Також визначте порожній ініціалізатор для цього класу.

```swift
let window = Window()
window.title
// Returns "New Window"
```

## 4. Додайте метод зміни розміру вікон

- `resize(to:)` : `(Size) -> ()`. Цей метод приймає структуру `Size` як вхідні дані та намагається змінити розмір вікна до вказаного розміру. Однак новий розмір не може перевищувати певні межі.
- Мінімальна дозволена висота або ширина - 1.
  Запитані висота чи ширина, менші за 1, обрізаються до 1.
- Максимальна висота та ширина залежать від поточної позиції вікна: краї вікна не можуть виходити за межі екрана.
  Значення, більші за ці межі, обрізаються до найбільшого розміру, який вони можуть мати.
  Наприклад, якщо позиція вікна `x` = 400, `y` = 300, а запит на зміну розміру вказує `height` = 400, `width` = 300, то вікно буде змінено до `height` = 300, `width` = 300, оскільки екран недостатньо великий у напрямку `y`, щоб повністю задовольнити запит.

## 5. Додайте метод переміщення вікон

- `move(to:)` : `(Position) -> ()`. Цей метод схожий на `resize(to:)`, але змінює _позицію_ вікна на запитане значення, а не розмір. Як і `resize`, нова позиція не може перевищувати певні межі.
- Найменша позиція - 0 і для `x`, і для `y`.
- Максимальна позиція в кожному з напрямків залежить від поточного розміру вікна; краї не можуть виходити за межі екрана.
       Значення, більші за ці межі, обрізаються до найбільшого розміру, який вони можуть мати. Наприклад, якщо розмір вікна `x` = 250, `y` = 100, а запит на переміщення вказує `x` = 600, `y` = 200, то вікно буде переміщено до `x` = 550, `y` = 200, оскільки екран недостатньо великий у напрямку `x`, щоб повністю задовольнити запит.

## 6. Додайте методи оновлення тексту вікна та виведення інформації про вікно

- `update(title:)` : `(String) -> ()`. Цей метод встановлює властивість `title` у значення рядка тексту (англ. string), який було передано.
- `update(text:)` : `(String?) -> ()`. Цей метод встановлює властивість `contents` у значення необовʼязкового рядка тексту, який було передано.
- `display()` : `() -> String`. Цей метод повертає рядок тексту, який описує поточний стан вікна. Наприклад, якщо вікно має `title` "My First Window", позицію: x = 10, y = 100; розмір: width = 200, height = 150; і вміст: "I 😍 my window", то він має повернути рядок: `"My First Window\nPosition: (10, 100), Size: (200 x 150)\nI 😍 my window\n"` - Якщо `contents` дорівнює nil, останній рядок має бути "[This window intentionally left blank]"

## 7. Створіть ініціалізатор для класу Window

Віконна система повинна мати ініціалізатор, щоб вікно можна було створити з власними вхідними даними.
Створіть **ще один** ініціалізатор для класу `Window`.
Ініціалізатор має приймати такі параметри: `title`, `contents` і два необовʼязкові параметри `size` та `position`.
Параметри `size` і `position` мають мати типові значення структур `Size` і `Position`.

```swift
let window = Window(title: "My First Window", contents: "I 😍 my window")
window.display()
// Returns "My First Window\nPosition: (0, 0), Size: (80 x 60)\nI 😍 my window\n"

let window2 = Window(title: "My Second Window", contents: "I 😍 my window", size: Size(width: 200, height: 150), position: Position(x: 10, y: 100))
window2.display()
// Returns "My Second Window\nPosition: (10, 100), Size: (200 x 150)\nI 😍 my window\n"
```
