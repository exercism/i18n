# Основи: довідка

У концепції «Основи» ми познайомилися з [Go](https://golang.org) як зі статично типізованою компільованою мовою програмування.
Мову часто називають Golang через її колишню доменну назву, golang.org, але правильна назва - Go.

Концепція «Основи» знайомить із трьома основними можливостями мови: пакетами, функціями та змінними.

## Пакети

Застосунки Go організовано в пакети.
Пакет - це набір вихідних файлів, розташованих в одному каталозі.
Усі вихідні файли в одному каталозі повинні мати однакову назву пакета.
За домовленістю назвою пакета роблять останній каталог у шляху імпорту.
Наприклад, файли в [пакеті «math/rand»](https://golang.org/src/math/rand/) починаються з інструкції `package rand`.
Коли пакет імпортовано, використовувати можна лише ті сутності (функції, типи, змінні, константи), назви яких починаються з великої літери.
Рекомендований стиль найменування в Go такий: ідентифікатори записують у `camelCase`, а ті, що мають бути доступними з інших пакетів, - у `PascalCase`.

```go
package lasagna
```

## Змінні

Go - статично типізована мова, тобто всі змінні [повинні мати визначений тип](https://en.wikipedia.org/wiki/Type_system) під час компіляції.

Змінну можна визначити, явно вказавши тип:

```go
var explicit int // Explicitly typed
```

Також можна скористатися ініціалізатором, і компілятор призначить змінній тип, що відповідає типу ініціалізатора.

```go
implicit := 10   // Implicitly typed as an int
```

Після оголошення змінним можна присвоювати значення за допомогою оператора `=`.
Після оголошення тип змінної вже не може змінитися.

```go
count := 1 // Assign initial value
count = 2  // Update to new value

count = false // This throws a compiler error due to assigning a non `int` type
```

## Константи

Константи зберігають дані так само, як змінні, але їхнє значення не може змінитися під час виконання програми.

Константи визначають за допомогою ключового слова `const`; вони можуть бути числами, символами, рядками тексту (англ. string) або булевими значеннями (англ. Boolean):

```go
const Age = 21 // Defines a numeric constant 'Age' with the value of 21
```

## Функції

Функції Go приймають нуль або більше параметрів.
Параметри потрібно вказувати з типом явно, тут немає виведення типів.

Значення повертають із функцій за допомогою ключового слова `return`.

Функцію викликають, вказуючи її назву та передаючи аргументи для кожного з параметрів функції.

Зауважмо, що Go підтримує два типи коментарів.
Однорядкові коментарі починаються з `//`, а багаторядкові вставляють між `/*` і `*/`.

```go
package greeting

// Hello is a public function.
func Hello (name string) string {
    return hi(name)
}

// hi is a private function.
func hi (name string) string {
    return "hi " + name
}
```
