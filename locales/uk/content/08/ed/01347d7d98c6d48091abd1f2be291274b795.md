# Встановлення


## Отримуємо GHCup

Інструменти Haskell рекомендовано встановлювати через [GHCup][ghcup].

За допомогою GHCup можна керувати встановленими компіляторами, менеджерами проєктів і пакетів та мовним сервером.


## Встановлюємо Stack

Для виконання вправ на Exercism потрібен лише Stack.

Щоб установити Stack, запустіть команду або скрипт встановлення GHCup.
Дотримуйтеся типових налаштувань, але вкажіть, що хочете встановити ще й Stack.

Випадково пропустили встановлення Stack?
Не хвилюйтеся: просто запустіть `ghcup install stack` згодом.

GHCup установить

- **Компілятор** (GHC: Glasgow Haskell Compiler)

  Строго кажучи, для Exercism він не потрібен, але стане в пригоді, якщо захочеться погратися з [GHCi][ghc-guide-ghci] поза теками вправ.

- **Cabal**

  Менеджер проєктів і пакетів.
  Для Exercism він не потрібен.

- **Stack**

  Менеджер проєктів і пакетів, який будемо використовувати для Exercism.
  Він подбає про те, щоб для кожного окремого проєкту (вправи) були потрібні компілятор і бібліотеки.

Щоб перевірити, чи встановлення пройшло успішно, запустіть будь-яку з команд

- `ghcup list`: успіх має такий вигляд: довгий список версій інструментів, де Stack позначено як встановлений
- `stack --version`: успіх має такий вигляд: `Version 2.7.5, Git revision ...`


## Отримуємо потрібну версію GHC

Stack автоматично завантажить і встановить GHC, коли це потрібно.
Запустити встановлення й перевірити його можна, виконавши в терміналі такі команди:

```bash
# Note: it only makes sense to run Stack
# inside projects, so navigate into an
# exercise directory first!
exercism download --exercise=hello-world --track=haskell
cd ~/Exercism/haskell/hello-world
stack ghc -- --version
```

Якщо на виході буде щось на кшталт

```
The Glorious Glasgow Haskell Compilation System, version 8.8.4
```

тоді GHC встановлено правильно.


## Налаштовуємо редактор для роботи з Haskell

Підтримку Haskell забезпечує Haskell Language Server (HLS).
Підтримка мови не обовʼязкова, але наполегливо рекомендована.


### Visual Studio Code (рекомендовано)

Просто встановіть [розширення Haskell для Visual Studio Code][vscode-haskell].
Воно скористається GHCup, щоб автоматично встановити HLS, і на цьому все буде готово.

**Примітка:** зі свіжозавантаженими вправами HLS може мати проблеми із запуском.
Якщо це сталося, запустіть `stack test` і перезапустіть мовний сервер.


### Інші редактори

Дивіться [документацію HLS щодо налаштування редактора][hls-editor-config].
Можливо, HLS доведеться встановити вручну.
Щоб це зробити, запустіть `ghcup install hls`.
