# Тести

Запустіть тести за допомогою:

```bash
$ wrenc exercise-name.spec.wren
```

Наприклад, для `hello-world`:

```bash
$ wrenc hello-world.spec.wren
```


## Що таке пропуск тестів

Метод `skip` вказує набору тестів не запускати конкретний тест.

- Чому їх пропускають?

Щоб можна було зосередитися на одному тесті за раз і вмикати їх по одному в міру
того, як ми вдосконалюємо рішення.

- Як їх увімкнути?

Пропущений тест:

```js
// this test will be skipped and not run
skip.test("title cased phrases") {
    Expect.value(Acronyms.parse("Portable Network Graphics")).toEqual("PNG")
}
```

Просто замініть `skip.test` на `do.test`.

```js
// now the test will be run normally
do.test("title cased phrases") {
    Expect.value(Acronyms.parse("Portable Network Graphics")).toEqual("PNG")
}
```

## Створення першого модуля Wren

Тести на цьому треку завантажують нашу реалізацію, імпортуючи її як модуль Wren:
`import "./bob" for Bob`. Немає спеціального синтаксису для експорту нашої
реалізації. Просто назвімо клас `Bob` так, щоб він збігався з інструкціями імпорту
`for Bob`, і все має запрацювати.

```javascript
class Bob {
  static hey(message) {
    // Your solution to the exercise goes here
  }
}
```

Більше інформації про модулі можна знайти в
[документації з модульності Wren][modularity].
Щоб було легше почати, у каталозі кожної вправи є _скелетний_ файл Wren.

[modularity]: https://wren.io/modularity.html
