# Докладніше

У Go ми можемо порівнювати значення за допомогою операторів рівності та порядку.
Таких операторів є шість:

| Порівняння            | Оператор  |
| ------------------| --------- |
| дорівнює          | `==`      |
| не дорівнює       | `!=`      |
| менше             | `<`       |
| менше або дорівнює | `<=`     |
| більше            | `>`       |
| більше або дорівнює | `>=`    |

Результатом порівняння завжди є булеве значення (англ. Boolean):

```go
a := 3

a != 4 // true
a > 5  // false
```

## Оператори рівності

Оператори рівності `==` і `!=` перевіряють, чи дорівнює значення іншому, чи ні, відповідно.
Оператори рівності можна застосовувати до більшості типів у Go.
Ось кілька типових прикладів:

```go
2 == 3 // false, integer comparison

2.1 != 2.2 // true, float comparison 

"hello" == "hello" // true, string comparison

'a' != 'b' // true, rune/byte comparison
```

## Оператори порядку

Оператори порядку перевіряють, чи одне значення більше за (`>`), більше або дорівнює (`>=`), менше за (`<`) і менше або дорівнює (`<=`) іншому значенню.
Таке порівняння доступне для чисел, байтів, рун і рядків тексту (англ. string).
Коли ми порівнюємо рядки тексту, використовується словниковий порядок (його ще називають лексикографічним).

```go
2 > 3 // false, integer comparison

1.2 < 1.3 // true, float comparison

'a' > 'b' // false, rune/byte comparison

"Hello" < "World" // true, string comparison
```
