# Вступ

Потік керування в Cairo дозволяє керувати шляхом виконання наших програм залежно від умов і повторень.

## Умовне виконання

Використовуймо вирази `if`, щоб виконувати код залежно від умов:

```rust
let number = 42;
if number > 0 {
    println!("Positive number");
} else if number < 0 {
    println!("Negative number");  
} else {
    println!("Zero");
}
```

`if` є виразом, тому може повертати значення:

```rust
let result = if condition { 5 } else { 10 };
```

## Цикли

Використовуймо `loop`, щоб повторювати код.
Цикл виконується нескінченно, доки ми його не зупинимо; використовуймо `break`, щоб перервати цикл, коли умова виконується.

```rust
let mut counter = 0;
loop {
    if counter == 5 {
        break;
    }
    println!("Counter: {}", counter);
    counter += 1;
}
```

Цикли можуть повертати значення за допомогою `break`:

```rust
let result = loop {
    counter += 1;
    if counter == 10 {
        break counter * 2; // Returns 20
    }
};
```

Використовуймо `continue`, щоб перейти до наступної ітерації:

```rust
let mut i = 0;
loop {
    i += 1;
    if i % 2 == 0 {
        continue; // Skip even numbers
    }
    if i > 10 {
        break;
    }
    println!("{}", i); // Only prints odd numbers
}
```
