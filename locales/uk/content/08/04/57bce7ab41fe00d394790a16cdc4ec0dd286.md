# Додаток до інструкцій

## Повідомлення про винятки

Іноді виникає потреба [викликати виняток](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). Коли ми це робимо, варто завжди додавати **змістовне повідомлення про помилку**, яке вказує, що є джерелом помилки. Це робить код зрозумілішим і суттєво допомагає з налагодженням. Якщо відомо, що джерело помилки буде певного типу, можна викликати один із [вбудованих типів помилок](https://docs.python.org/3/library/exceptions.html#base-classes), але повідомлення все одно має бути змістовним.

У цій вправі потрібно скористатися [інструкцією raise](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement), щоб «кинути» `ValueError`, якщо у вхідних даних немає належних роздільників, вони записані не у верхньому регістрі, не утворюють дерева з вузлами або не утворюють дерева взагалі. Тести пройдуть, лише якщо і викликати `exception` за допомогою `raise`, і додати до нього повідомлення.

Щоб викликати `ValueError` з повідомленням, потрібно записати повідомлення як аргумент типу `exception`:

```python
# if the tree properties as given do not have proper delimiters.
raise ValueError("properties without delimiter")

# if the tree properties as given are not all in uppercase.
raise ValueError("property must be in uppercase")

# if the input does not form a tree, or is empty.
raise ValueError("tree missing")

# if the input is a tree without any nodes.
raise ValueError("tree with no nodes")
```
