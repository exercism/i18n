# Інструкції

Друг щойно надіслав повідомлення з важливою таємницею.
Щоб іншим було не так просто його прочитати, повідомлення зашифрували, виконавши низку операцій з бітами.
Щоб допомогти розшифрувати повідомлення, нам потрібно написати кілька функцій.

## 1. Зсунути біти назад

Перший крок до розшифрування повідомлення - скасувати зсув, зроблений під час шифрування, зсунувши біти назад праворуч.
Далі в процесі розшифрування будуть кроки, які припускають, що з лівого боку вставляються нулі.

Реалізуйте функцію `shiftBack`, яка приймає значення та кількість позицій для зсуву і виконує цей зсув.

```kotlin
shiftBack(0b1001, 2)
# => 0b0010
```

## 2. Встановити деякі біти

Далі є біти, які потрібно встановити в 1.

Реалізуйте функцію `setBits`, яка приймає значення та маску й повертає результат встановлення бітів значення в 1.
Біт значення має бути встановлений в 1 там, де біт у масці також дорівнює 1.
Усі інші біти залишаються без змін.

```kotlin
setBits(0b0110, 0b0101);
# => 0b0111
```

## 3. Перевернути окремі біти

Під час шифрування деякі біти перевертаються.
Щоб розшифрувати повідомлення, їх потрібно перевернути назад.

Реалізуйте функцію `flipBits`, яка приймає значення та маску.
Маска вказує, які біти значення перевернути.
Якщо біт у масці дорівнює 1, відповідний біт значення перевертається.
Усі інші біти залишаються без змін.

```java
flipBits(0b1100, 0b0101);
# => 0b1001
```

## 4. Очистити окремі біти

Насамкінець, є також певні біти, які завжди розшифровуються в 0.

Реалізуйте функцію `clearBits`, яка приймає значення та маску.
Біти у `value` мають бути встановлені в 0 там, де біт у масці дорівнює 1.
Усі інші біти залишаються без змін.

```java
clearBits(0b0110, 0b0101);
# => 0b0010
```
