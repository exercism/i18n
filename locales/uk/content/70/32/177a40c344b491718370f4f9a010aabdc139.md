# Інструкції

Одна дослідницька організація помітила, що деякі з її молодших дослідників використовували не найкращі методи у своєму аналізі.
Один із цих методів полягає в тому, щоб одразу перетворювати дискретні ймовірності на числа з плаваючою комою (тобто дійсні числа), перш ніж робити подальші обчислення.

Старші дослідники віддають перевагу раціональним числам в обчисленнях, які можуть дати вищу точність, і хотіли б знати, чи вплинули погані практики молодших дослідників на результати досліджень.

Було проведено два типи досліджень:
- Запускали багато тестів, кожен з яких повертав дискретну ймовірність успіху, а потім обчислювали середнє цих ймовірностей.
- Перевіряли багато незалежних подій, і загальну ймовірність того, що всі події відбудуться, обчислювали, перемноживши їх.

Старші дослідники просять нас написати функції, які допоможуть їм визначити, чи є в аналізах помилки округлення через використання чисел з плаваючою комою, і просять надати точне раціональне число для результату, якщо помилки є.

## 1. Наведіть відношення успіхів до спроб

Функція `rationalize(successes, trials)` приймає два масиви, `successes` і `trials`.
Для індексу `i` елемент `successes[i]` відповідає кількості успіхів, що сталися за `trials[i]` спроб.
Функція повертає масив раціональних чисел, тобто відношень успіхів до кількості спроб, у тому самому порядку, що й вхідні масиви.

```julia-repl
julia> rationalize([1, 2, 3], [4, 5, 6])
3-element Vector{Rational{Int64}}:
 1//4
 2//5
 1//2
```

## 2. Знайдіть дійсні ймовірності за співвідношенням успіхів і спроб

Так само функція `probabilities(successes, trials)` приймає два масиви, `successes` і `trials`.
Вона повертає масив чисел з плаваючою комою, тобто відношень успіхів до кількості спроб, у тому самому порядку, що й вхідні масиви.

```julia-repl
julia> probabilities([1, 2, 3], [4, 5, 6])
3-element Vector{Float64}:
 0.25
 0.4
 0.5
```

## 3. Перевірте середнє ймовірностей

Функція `checkmean(successes, trials)` приймає два масиви, `successes` і `trials`.
Вона порівнює середнє дійсних ймовірностей із середнім раціональних ймовірностей.
- Якщо ці дві ймовірності рівні, `checkmean` повертає `true`
- Якщо ці дві ймовірності різні, `checkmean` повертає раціональну ймовірність.

```julia-repl
julia> successes, trials = [9, 4, 7, 8, 6], [22, 22, 11, 17, 12];
julia> checkmean(successes, trials)
true

julia> successes, trials = [6, 5, 9, 8, 9], [21, 19, 13, 25, 22];
julia> checkmean(successes, trials)
1873629//4754750
```

## 4. Перевірте незалежну ймовірність

Функція `checkprob(successes, trials)` приймає два масиви, `successes` і `trials`.
Вона порівнює сумарну ймовірність, обчислену з чисел з плаваючою комою, із сумарною ймовірністю, обчисленою з раціональних чисел.
- Якщо ці дві ймовірності рівні, `checkprob` повертає `true`
- Якщо ці дві ймовірності різні, `checkprob` повертає раціональну ймовірність.

```julia-repl
julia> successes, trials = [2, 9, 4, 4, 5], [15, 11, 17, 19, 15];
julia> checkprob(successes, trials)
true

julia> successes, trials = [9, 8, 5, 4, 3], [22, 14, 19, 25, 18];
julia> checkprob(sucesses, trials)
12//7315
```
