# Вступ

## Умовний вираз

**Умовний вираз** у `jq` має такий вигляд: `if A then B else C end`.

`if-then-else` - це фільтр, як і всі вбудовані функції `jq`: він приймає вхідні дані та видає вихідні.

Якщо вираз `A` дає «істинне» значення, то фільтр `if` обчислює `B`.
Інакше він обчислює `C`.
Вхідні дані фільтра `if` буде передано до `B` або `C`.

```jq
42 | if . < 50 then "small" else "big" end      # => "small"
```

```jq
5 | if . % 2 == 0 then . / 2 else . * 4 end     # => 20
```

~~~~exercism/note
Гілка `else` **необовʼязкова**; наведені нижче дві інструкції рівнозначні.

```jq
if A then B else . end
if A then B end
```
~~~~

## Вкладені умовні вирази

Додаткові умови можна додати за допомогою `elif`.

```jq
42 | if . < 33 then "small"
     elif . < 66 then "medium"
     else "big"
     end
# => "medium"
```

Можна використати стільки гілок `elif`, скільки потрібно.

## Істинність

Єдині «хибні» значення в `jq`: `false` і `null`.
Усе інше - «істинне», навіть число нуль і порожній рядок тексту (англ. string), порожній масив та порожній обʼєкт.

## Булеві оператори

**Булеві оператори** (англ. Boolean) `and` та `or` можна використовувати для побудови складних запитів.

```jq
42 | if . < 33 or . > 66 then "big or small"
     else "medium"
     end
```

Щоб заперечити, можна використати `not`. Це **фільтр**, а не оператор.

```jq
42 | if (. < 33 or . > 66 | not) then "medium"
     else "big or small"
     end
```

## Альтернативний оператор

**Альтернативний оператор** дозволяє вказати «типове» значення, якщо вираз має значення `false` або `null`.

```jq
A // B

# This is identical to
if A then A else B end
```

Для наочності

```jq
[3, 5, 18] | add / 2       # => 13
[]         | add / 2       # => error: null (null) and number (2) cannot be divided
[]         | add // 0 / 2  # => 0
```
