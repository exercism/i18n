# Тести

Більшість тестів перевіряють, що, присвоюючи значення [result] або передаючи значення [exit], ми повертаємо очікуване значення.

Деякі тести перевіряють, що ми [raise] очікуваний виняток.

## Запуск тестів

Щоб запускати тести, потрібна утиліта `make`.

Перебуваючи в каталозі вправи, введіть у консолі або терміналі:

```sh
make
```

Якщо ми навіть не торкалися файлу з рішенням вправи, ми побачимо приблизно таке повідомлення:

```
Please implement your solution.
```

Тож видаліть цей рядок, перш ніж почати писати рішення.

Типово виконується лише перший тест.

```text
TAP version 14
1..10
ok 1 - ...
```

Щоб запустити всі тести, введіть:

```sh
make test=all
```

```text
TAP version 14
1..10
ok 1 - empty_sentence
ok 2 - perfect_lower_case
ok 3 - only_lower_case
ok 4 - missing_the_letter_x
ok 5 - missing_the_letter_h
ok 6 - with_underscores
ok 7 - with_numbers
ok 8 - missing_letters_replaced_by_numbers
ok 9 - mixed_case_and_punctuation
ok 10 - am_and_AM_are_26_different_characters_but_not_a_pangram
```

Коли всі тести пройдено, вправу завершено, і ми можемо надіслати рішення.

Можна вибрати один тест для запуску, передавши відповідне число, наприклад:

```sh
make test=2
```

виконає лише другий тест.
