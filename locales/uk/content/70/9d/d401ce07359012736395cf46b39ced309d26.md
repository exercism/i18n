# Доповнення до інструкцій

## Регістри

| Регістр | Використання        | Тип          | Опис                              |
| ------- | ------------------- | ------------ | --------------------------------- |
| `$a0`   | вхідні дані         | адреса       | масив ваг предметів               |
| `$a1`   | вхідні дані         | адреса       | масив значень предметів           |
| `$a2`   | вхідні дані         | ціле число   | кількість предметів               |
| `$a3`   | вхідні дані         | ціле число   | максимальна вага                  |
| `$v0`   | вихідні дані        | ціле число   | максимальне значення              |
| `$t0-9` | тимчасове зберігання | будь-який   | використовується для тимчасового зберігання |
