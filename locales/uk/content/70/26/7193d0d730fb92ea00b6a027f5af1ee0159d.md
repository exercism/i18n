# Вступ

Ми будемо називати _мову_ **AWK**, а _виконуваний файл_, який інтерпретує програми AWK, позначатимемо як **`awk`** або **`gawk`**.

## Шаблони та дії

Програма AWK складається з **пар «шаблон-дія»**

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

**Шаблон** може бути регулярним виразом, який зіставляється з вхідними даними.
Він також може бути будь-яким виразом, результат якого - правда або неправда.

**Дія** - це одна або кілька команд AWK.
Фігурні дужки навколо неї обовʼязкові.

Якщо результат шаблону - _правда_, тоді виконується відповідна дія.

## Записи та поля

AWK розбирає вхідні дані як послідовність **записів**.
Кожен запис розбивається на нуль або більше **полів**.

Типова поведінка полягає в тому, щоб:

- розбити вхідні дані на записи, використовуючи символ нового рядка як «роздільник записів», тож кожен _рядок_ - це запис.
- розбити запис на поля, використовуючи пробільні символи як «роздільник полів», тож кожне _слово_ - це поле.

## Шаблони та дії, продовження

Шаблон можна опустити, і тоді дія виконується _для кожного вхідного запису_.

Дію можна опустити, і тоді типовою дією є виведення поточного запису.

### Спеціальні шаблони

Є два спеціальні шаблони, які часто використовуються.

- `BEGIN` виконує повʼязану дію до того, як буде прочитано будь-які вхідні дані.
- `END` виконує повʼязану дію після того, як усі вхідні дані буде прочитано.

## Змінні полів

Поля записуються як `$1`, `$2`, `$3` тощо.

Поточний запис - це `$0`.

Ось кілька інших вбудованих змінних, які часто використовуються.

### Вбудовані змінні, які керують розбором вхідних даних

- `RS` - це роздільник записів у вхідних даних.
  Як уже згадувалося, його типове значення - символ нового рядка.
- `FS` - це роздільник полів у вхідних даних.

Ці змінні часто задають у блоці дії `BEGIN`.

### Вбудовані змінні, які несуть інформацію

AWK автоматично встановлює ці змінні під час виконання програми.

- `NF` зберігає кількість полів у поточному записі.
  - Щоб отримати значення останнього поля, використовують `$NF`.
- `NR` зберігає номер поточного запису.
  - Коли обробляється кілька вхідних файлів, `NR` міститиме загальну кількість записів, оброблених на цей момент.
- `FNR` зберігає номер поточного запису в поточному вхідному файлі.
  - Щоб проілюструвати різницю між NR і FNR, ось поширений прийом AWK.
    ```awk
    NR == FNR {action}
    ```
    Це означає «якщо накопичений номер запису дорівнює номеру запису поточного файлу».
    Це справджується лише для записів у _першому вхідному файлі_.

## Що вважається правдою

AWK визначає правду й неправду так само, як C.

- Число `0` - неправда.
- Будь-яке інше число - правда.

Оскільки AWK - це мова обробки тексту, значення правди поширюються і на рядки тексту (англ. string).

- Порожній рядок тексту `""` - неправда.
- Будь-який непорожній рядок тексту - правда.

## Коментарі

Коментарі починаються із символу `#` і тривають до кінця рядка.

## Приклади

У Unix-подібних системах `/etc/passwd` містить інформацію про користувачів.
Кожен користувач описаний в окремому рядку, а поля розділені двокрапками.

Щоб вивести список імен користувачів:

```sh
awk '
    BEGIN { FS = ":" }
    { print $1 }
' /etc/passwd
```

Звернімо увагу, що дія `{print $1}` не має шаблону, тож вона виконується для кожного запису.

Якщо ми хочемо обмежити виведення лише користувачами, які використовують bash як свою командну оболонку для входу, можна зробити так:

```sh
awk '
    BEGIN { FS = ":" }
    $7 == "/bin/bash" { print $1 }
' /etc/passwd
```
