# Масиви

`ARRAY{T}` - це фіксований ряд значень типу `T`.

```sather
   row : ARRAY{STR} := |"Mia", "Ana", "Ben"|;
   sizes : ARRAY{INT} := |3, 1, 2|;
```

## Фігурні дужки

`ARRAY{STR}` читається як «масив `STR`». У фігурних дужках стоїть **параметр типу**: сам по собі `ARRAY` не є типом, бо масив має бути масивом чогось. Більша частина бібліотеки Sather побудована саме так, а як написати такий клас самостійно, розповімо пізніше.

## Позиції

```sather
row[0]                 -- the first
row[row.size - 1]      -- the last
row.size               -- how many
```

Позиції йдуть від `0` до `.size - 1`. Масив знає свій розмір і ніколи його не змінює: дописати щось у кінець `ARRAY` неможливо.

## Як створити масив без літерала

`#ARRAY{INT}(n)` створює масив із `n` значень, і кожне з них дорівнює нулю:

```sather
   counts ::= #ARRAY{INT}(5);      -- five noughts
   counts[0] := 7;
```

Щоб присвоїти значення позиції, використовують ті самі квадратні дужки ліворуч від `:=`.

## Вихід за межі

Читання або запис позиції, якої не існує, не перевіряється під час звичайної збірки. Програма не зупиниться з корисним повідомленням; вона прочитає або запише те, що випадково опинилося поруч у памʼяті. Дві звички допоможуть цього уникнути: брати `.size - 1`, а не число, пораховане на око, і завершувати цикли умовою `until!(i >= a.size)`, а не літералом.

## Як надрукувати масив

`.str` показує вміст у фігурних дужках, що зручно, коли треба щось прикинути:

```sather
   #OUT + row.str;      -- {Mia,Ana,Ben}
```
