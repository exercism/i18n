# Навчання

Odin - мова програмування системного рівня.
Як і в C, програміст має керувати памʼяттю вручну.
Утім, це досить проста мова.

Наведені нижче ресурси допоможуть вивчити Odin:

Для першого знайомства з мовою:

* Подивіться [Introduction to Odin][video], яке представив творець Odin.
* Прочитайте статтю [Introduction to Odin][intro], написану автором книги ["Understanding the Odin Programming Language"][book].
* Вивчіть [Демонстраційний файл][demo], який показує в коді концепції Odin.

Заглибмося глибше:

* [Огляд мови Odin][overview].
* Документація для [офіційних пакетів][packages].
* Книга ["Understanding the Odin Programming Language"][book] (платна).
* Офіційний набір ["Odin Examples"][examples].
