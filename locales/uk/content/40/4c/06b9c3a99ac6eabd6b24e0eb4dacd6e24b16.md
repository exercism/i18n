# Вступ

## Докладніше про шаблони

Пригадаймо з концепції Fundamentals: програма AWK складається з **пар «шаблон-дія»**.

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

### Що ми маємо на увазі під «шаблоном»?

«Шаблон» - це будь-який вираз AWK.
Від істинності результату виразу залежить, чи буде виконано дію.

### Порожній шаблон

Шаблон можна опустити.
У цьому разі дія виконується для кожного запису.

Ми можемо вивести всі імена користувачів із файлу passwd.

```sh
awk -F: '{print $1}' /etc/passwd
```

### Регулярні вирази

AWK може порівнювати рядки тексту (англ. string) з регулярними виразами, щоб отримати булевий результат (англ. Boolean).

Скористайтеся оператором зіставлення з регулярним виразом `~`, щоб зіставити конкретне поле.
Цей оператор приймає рядок тексту як лівий операнд, а регулярний вираз як правий операнд.
Літерал регулярного виразу беруть у скісні риски `/`.

Щоб знайти у файлі passwd користувачів, які входять у систему за допомогою bash:

```sh
awk -F: '$7 ~ /bash/ {print $1}' /etc/passwd
```

`!~` - це оператор «регулярний вираз **не** збігається».

Щоб зіставити регулярний вираз із поточним записом, можна написати `$0 ~ /regex/`.
Це настільки поширено, що існує скорочений запис: можна опустити `$0` і `~` та просто написати `/regex/`

```sh
awk '/regex/' data.txt
```

~~~~exercism/note
Порівняймо цей однорядковий вираз AWK з еквівалентною командою grep

```sh
grep 'regex' data.txt
```

AWK дає нам цілу мову програмування, не жертвуючи стислістю.
~~~~

Докладніше про діалект регулярних виразів GNU AWK ми поговоримо в іншій концепції.

### Вирази

Вирази AWK (арифметичні, логічні чи будь-які інші) можна використовувати як шаблони.

Щоб вибрати всіх користувачів з UID 1000 або більше:

```sh
awk -F: '$3 >= 1000' /etc/passwd
```

Пригадаймо, що неправда в AWK - це число нуль і порожній рядок тексту, а правда - це всі інші числа чи рядки тексту.
Будь-який вираз, результатом якого є число або рядок тексту, можна використати як шаблон.

### Функції

Будь-яку [вбудовану функцію][builtins] або [функцію, визначену користувачем][user-defined] можна використати у виразі, а отже, і в шаблоні.
Кілька прикладів:

```awk
length($1) {print "first field is not empty"}
```
```awk
toupper(substr($1, 1, 1)) ~ /[AEIOU]/ {print "starts with a vowel"}
```

### Сталі шаблони

Поширена ідіома AWK:

```sh
{
    xyz()   # some code that transforms each record
}
1
```

`1` - це істинний шаблон без повʼязаної дії.
Він означає «вивести поточний запис».
