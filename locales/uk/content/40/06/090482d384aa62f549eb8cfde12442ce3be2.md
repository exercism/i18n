# Інструкції

Наше завдання - створювати й підтримувати частини IT-системи парку розваг.
Зокрема, ми відповідаємо за програму, яка керує відвідувачами та квитками.

Спочатку ми створимо нового відвідувача в системі.
Потім ми додамо функцію для відкликання квитка.
У завданнях 3 і 4 ми будемо працювати над системою відстеження квитків, яка допомагає запобігати підробкам.
Насамкінець ми допоможемо адаптувати систему до нових законодавчих вимог.

## 1. Створіть нового відвідувача

Коли відвідувачі вперше приходять до парку розваг, їм потрібно зареєструватися: ввести своє імʼя та вік у терміналі й погодитися з умовами користування.
Звісно, їм також потрібно купити квиток.
Кожен квиток має ідентифікатор, наприклад `H32AZ123`.

Напишіть функцію `createVisitor`, яка приймає три аргументи.

- Імʼя відвідувача.
- Вік відвідувача.
- Ідентифікатор квитка, який купив відвідувач.

Функція повинна повернути обʼєкт, який містить цю інформацію.
Ключі в обʼєкті мають називатися `name`, `age` і `ticketId`.

```javascript
createVisitor('Verena Nardi', 45, 'H32AZ123');
// => { name: 'Verena Nardi', age: 45, ticketId: 'H32AZ123' }
```

## 2. Відкличте квиток

Коли люди залишають парк розваг, їхній квиток відкликають.
Якщо вони повертаються, їм потрібно купити новий.
Щоб заощадити час постійним відвідувачам, їм потрібно зареєструватися лише один раз, і інформація про відвідувача зберігається для наступних відвідувань.

Це означає, що коли відвідувач залишає парк, потрібно зробити недійсним лише його квиток, а решта обʼєкта відвідувача має залишитися незмінною.
Реалізуйте функцію `revokeTicket`, яка приймає обʼєкт відвідувача, встановлює ідентифікатор квитка в `null` і після цього повертає обʼєкт.

```javascript
const visitor = {
  name: 'Verena Nardi',
  age: 45,
  ticketId: 'H32AZ123',
};

revokeTicket(visitor);
// => { name: 'Verena Nardi', age: 45, ticketId: null }
```

## 3. Визначте статус квитка

Щоб запобігти підробкам, ідентифікатори квитків унікальні.
Щойно квиток друкують, його ідентифікатор додають як ключ до обʼєкта в системі, щоб його можна було відстежувати.

Перш ніж квиток продадуть відвідувачу, його зберігають зі значенням `null` в обʼєкті відстеження квитків.
Коли його продають відвідувачу, як значення присвоюють імʼя відвідувача.
Коли в працівників виникають сумніви щодо дійсності квитка, їм потрібно перевірити статус квитка в системі.

Реалізуйте функцію `ticketStatus`, яка приймає обʼєкт відстеження та ідентифікатор квитка як аргументи.
Вона повинна повернути один із таких результатів.

- `'unknown ticket id'`, якщо ідентифікатор не знайдено в обʼєкті відстеження
- `'not sold'`, якщо квиток надрукували, але не продали
- `'sold to {name}'`, де `{name}` - імʼя відвідувача, якщо квиток продали

```javascript
const tickets = {
  '0H2AZ123': null,
  '23LA9T41': 'Verena Nardi',
};

ticketStatus(tickets, 'RE90VAW7');
// => 'unknown ticket id'

ticketStatus(tickets, '0H2AZ123');
// => 'not sold'

ticketStatus(tickets, '23LA9T41');
// => 'sold to Verena Nardi'
```

## 4. Покращте відповідь про статус квитка

Через деякий час ми отримуємо відгук від працівників: вони хочуть, щоб статус квитка було легше зрозуміти з першого погляду.
Вони хочуть бачити лише імʼя відвідувача або те, що квиток недійсний.

Напишіть функцію `simpleTicketStatus`, яка приймає ті самі аргументи, що й `ticketStatus` у завданні 3.
Ця функція повертає лише один із двох різних результатів.

- імʼя відвідувача, якщо квиток продали
- `'invalid ticket !!!'`, якщо квиток ще не продали або ідентифікатора немає в обʼєкті відстеження

```javascript
const tickets = {
  '0H2AZ123': null,
  '23LA9T41': 'Verena Nardi',
};

simpleTicketStatus(tickets, '23LA9T41');
// => 'Verena Nardi'

simpleTicketStatus(tickets, '0H2AZ123');
// => 'invalid ticket !!!'

simpleTicketStatus(tickets, 'RE90VAW7');
// => 'invalid ticket !!!'
```

## 5. Визначте версію загальних умов і положень

Через нові законодавчі вимоги новостворені обʼєкти відвідувачів тепер також містять докладну інформацію про «Загальні умови та положення» (GTC), з якими погодився користувач.
Нижче наведено приклад нового обʼєкта відвідувача.

Касирам парку розваг тепер потрібно перевіряти, чи потрібно відвідувачу підписати нову версію GTC.
Для цього реалізуйте функцію `gtcVersion`, яка приймає обʼєкт відвідувача як аргумент і повертає версію GTC, якщо вона доступна.
Якщо інформація про версію недоступна, функція не повинна нічого повертати.

```javascript
const visitorNew = {
  name: 'Verena Nardi',
  age: 45,
  ticketId: 'H32AZ123',
  gtc: {
    signed: true,
    version: '2.1',
  },
};

gtcVersion(visitorNew);
// => '2.1'

const visitorOld = {
  name: 'Verena Nardi',
  age: 45,
  ticketId: 'H32AZ123',
};

gtcVersion(visitorOld);
// => undefined
```
