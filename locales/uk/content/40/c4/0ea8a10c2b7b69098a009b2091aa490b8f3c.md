# Вступ

[Оператор порівняння][comparisons] у Python (_його також називають оператором відношень_), дивиться на _значення_ двох [операндів][operand] і повертає булеве значення (англ. Boolean) `True` або `False` залежно від того, чи виконується умова `comparison`.

У таблиці нижче наведено найпоширеніші оператори порівняння в Python:

| Оператор | Операція                   | Опис                                                                                      |
| -------- | -------------------------- | ----------------------------------------------------------------------------------------- |
| `>`      | «більше ніж»               | `a > b` є `True`, якщо значення `a` **строго** більше за `b`                              |
| `<`      | «менше ніж»                | `a < b` є `True`, якщо значення `a` **строго** менше за `b`                               |
| `==`     | «дорівнює»                 | `a == b` є `True`, якщо `a` **строго** дорівнює `b` за значенням                          |
| `>=`     | «більше ніж або дорівнює»  | `a >= b` є `True`, якщо `a > b` АБО `a == b` за значенням                                 |
| `<=`     | «менше ніж або дорівнює»   | `a <= b` є `True`, якщо `a < b` або `a == b` за значенням                                 |
| `!=`     | «не дорівнює»              | `a != b` є `True`, якщо `a == b` є `False`                                                |
| `is`     | «ідентичність»             | `a is b` є `True`, якщо **_і тільки якщо_** `a` і `b` вказують на той самий _обʼєкт_       |
| `is not` | «заперечена ідентичність»  | `a is not b` є `True`, якщо **_і тільки якщо_** `a` і `b` **не** вказують на той самий _обʼєкт_ |
| `in`     | «перевірка на входження»   | `a in b` є `True`, якщо `a` є членом, підмножиною або елементом `b`                       |
| `not in` | «заперечена перевірка на входження» | `a not in b` є `True`, якщо `a` не є членом, підмножиною або елементом `b`       |

Усі вони мають однаковий пріоритет (_який вищий, ніж у [булевих операцій][boolean operations], але нижчий, ніж в арифметичних чи побітових операцій_).

## Порівняння між різними типами даних

Обʼєкти різних типів (_крім числових типів_) типово ніколи не вважаються рівними.
Неідентичні екземпляри `class` також _**не**_ будуть вважатися рівними, якщо тільки `class` не визначає спеціальних методів, які змінюють типову поведінку порівняння `object`.

Числові типи (переважно) є винятком із цього правила відповідності типів.
`integer` **може** вважатися рівним `float` (_або [`octal`][octal] рівним [`hexadecimal`][hex]_), якщо типи можна неявно перетворити для порівняння.

Для інших числових типів ([комплексні числа][complex numbers], [десяткові числа][decimal numbers], [дроби][rational numbers]) оператори порівняння визначені там, де вони «мають сенс» (_де неявне перетворення не змінює результату_), але спричиняють `TypeError`, якщо базові обʼєкти не можна точно перетворити для порівняння.

## Порівняння ідентичності обʼєктів

Оператори `is` і `is not` перевіряють [_ідентичність_][object identity] обʼєкта, а не його _значення_.
Ідентичність обʼєкта ніколи не змінюється після створення, і її можна дізнатися за допомогою функції [`id()`][id function].

`<apple> is <orange>` дає `True`, якщо **_і тільки якщо_** `id(<apple>)` == `id(<orange>)`.
`<apple> is not <orange>` дає протилежний результат.

## Порівняння на входження

Оператори `in` і `not in` перевіряють _входження_.
`<fish> in <soup>` дає `True`, якщо `<fish>` є членом `<soup>` (_якщо `<fish>` є підмножиною `<soup>` або міститься в ній_), а інакше дає `False`.
`<fish> not in <soup>` повертає заперечення, або _протилежність_ `<fish> in <soup>`.

Для рядків тексту (англ. string) і байтів `<name> in <fullname>` є `True` **_і тільки якщо_** `<name>` є підрядком `<fullname>`.
