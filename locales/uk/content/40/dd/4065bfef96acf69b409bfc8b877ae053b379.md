# Інструкції

Двоє скрипалів репетирують дует. Кожна партія - це масив, у якому зберігається кількість нот у кожному такті, і партії не завжди мають однакову довжину.

Усі чотири завдання містяться в класі `DUET_PRACTICE`.

## 1. Скільки тактів вони грають разом?

Вони грають разом доти, доки в обох партіях залишається такт.

```sather
DUET_PRACTICE::bars_together(|4, 4, 8, 8|, |4, 4|)
-- => 2
```

## 2. Скільки тактів збігається?

Порахуймо такти, у яких обидві партії мають однакову кількість нот. Збігатися можуть лише ті такти, які є в обох партіях.

```sather
DUET_PRACTICE::in_unison(|4, 4, 8|, |4, 2, 8|)
-- => 2
```

## 3. Хто більше грає?

Порахуймо такти, у яких у першій партії більше нот, ніж у другій.

```sather
DUET_PRACTICE::louder_bars(|4, 8, 2|, |4, 2, 8|)
-- => 1
```

## 4. Зважуємо такти

Пізніші такти складніші, тож такт важить стільки, скільки його позиція: перший такт рахується один раз, другий - двічі, третій - тричі. Помножмо кількість нот у кожному такті на його номер і додаймо все.

```sather
DUET_PRACTICE::weighted_total(|4, 4, 8|)
-- => 36
```

Це 1×4 + 2×4 + 3×8. Такти нумеруються з одиниці, а не з нуля.
