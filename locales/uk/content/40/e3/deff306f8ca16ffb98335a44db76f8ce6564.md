# Вступ

Більшість даних у Factor зберігається в *послідовностях*. Масиви (`{ … }`), вектори (`V{ … }`) і рядки тексту (англ. string) мають спільний [протокол][sequence-protocol] із [`sequences`][sequences].

```factor
{ 1 2 3 } length .    ! => 3
{ 1 2 3 } first .     ! => 1
{ 1 2 3 } last .      ! => 3
{ 1 2 3 4 5 } 3 head .! => { 1 2 3 }
```

Агрегації (`sum`, `count`, `any?`, `all?`) і предикати, як-от `empty?` та `member?`, працюють однаково з кожним типом послідовності. Створення нових послідовностей без зміни наявних: `prefix`, `suffix`, `append`, `unclip`, `unclip-last`.

`>array`, `>vector` і `>string` (у [`arrays`][arrays] та відповідних модулях) перетворюють один тип послідовності на інший, коли з загальної операції потрібно дістати конкретний тип.

[arrays]: https://docs.factorcode.org/content/vocab-arrays.html

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
[sequence-protocol]: https://docs.factorcode.org/content/article-sequence-protocol.html
