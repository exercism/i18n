# Встановлення

## Яку версію обрати?

Радимо використовувати стабільний випуск PHP з активною підтримкою.
Наразі це **PHP 8.2, 8.3 і 8.4**.
Деталі про поточні випуски та графіки їхньої підтримки можна знайти в [офіційній документації PHP](https://www.php.net/supported-versions.php).

## Встановлення PHP

Більшість менеджерів пакетів для Linux / macOS пропонують готові збірки.
PHP можна завантажити й зібрати з вихідного коду, доступного на [php.net/downloads.php](https://php.net/downloads.php) або [windows.php.net/download](https://windows.php.net/download).

~~~~exercism/note
Для виконання вправ не потрібен вебсервер, як-от nginx чи сервер Apache HTTP.
~~~~

### Linux

Різні дистрибутиви мають різні способи.
Залежно від менеджера пакетів, достатньо виконати одну з команд:

```shell
yum install php
```

або

```shell
apt-get install php
```

Додаткові інструкції шукайте в посібнику PHP: [Встановлення в системах Unix](https://www.php.net/manual/en/install.unix.php).

### macOS

Хоча PHP часто входить до складу macOS, він часто застарілий.
Радимо встановлювати PHP через [Homebrew](https://brew.sh/).
Homebrew можна встановити за інструкціями [на його головній сторінці](https://brew.sh/#install).

Щоб переконатися, що встановлення вдалося, виконайте таку команду; на момент написання вона має вивести Homebrew `4.5.x`.

```shell
brew --version 
```

Встановіть PHP через Homebrew

```shell
brew install php@8.4
```

Ця команда має показати встановлену версію PHP, щонайменше версію `8.2.0`.

```shell
php -v
```

Додаткові інструкції шукайте в посібнику: [Встановлення в macOS](https://www.php.net/manual/en/install.macosx.php).

### Windows

Офіційні бінарні файли PHP для Windows можна завантажити з [windows.php.net/download](https://windows.php.net/download).

Існують готові збірки, зокрема [WAMP](https://www.wampserver.com/en/) (Windows, Apache, MySQL, PHP) та [XAMPP](https://www.apachefriends.org/de/index.html).

Додаткові інструкції шукайте в посібнику: [Встановлення в системах Windows](https://www.php.net/manual/en/install.windows.php).

### Docker

Якщо потрібне контейнерне рішення, можна завантажити [офіційний образ PHP із Docker Hub](https://hub.docker.com/_/php).
Також знадобиться [Docker](https://docs.docker.com/engine/install/).

### Інші

Якщо потрібна інша операційна система, дивіться інструкції на [php.net/manual/en/install](https://www.php.net/manual/en/install.php).

## Встановлення PHPUnit

PHPUnit 12 поки що не підтримується!
~~~~

### Через PHP-архів (PHAR)

Найпростіший спосіб використовувати PHPUnit для вправ Exercism - завантажити дистрибутив, запакований як PHP-архів (PHAR); це також рекомендований спосіб роботи з PHPUnit.
Збережіть PHAR там, де збережено CLI `exercism`, щоб запускати PHPUnit з будь-якого місця.

Випуск пакетів PHPUnit можна завантажити як PHP-архів:

```shell
wget -O phpunit.phar https://phar.phpunit.de/phpunit-11.phar
```

Потім зробіть завантажений файл виконуваним:

```shell
chmod +x phpunit.phar
```

І перемістіть його туди ж, куди переміщено CLI `exercism`, давши команді назву `phpunit`:

```shell
mv phpunit.phar ~/bin/phpunit
```

Тепер можна запускати `phpunit` з будь-якого місця, як показано в [документації з тестування треку PHP](https://exercism.org/docs/tracks/php/tests):

```shell
phpunit --version
```

Вивід має мати такий вигляд:

```text
PHPUnit 11.5.45 by Sebastian Bergmann and contributors.
```

Також можна скористатися офіційною інструкцією [Встановлення PHPUnit](https://docs.phpunit.de/en/11.5/installation.html#installing-phpunit), щоб встановити PHPUnit.

### Через Composer

PHPUnit версії 11 також можна встановити через [Composer](https://getcomposer.org).

#### Встановлення Composer

Встановіть [Composer](https://getcomposer.org), скориставшись [інструкціями зі встановлення](https://getcomposer.org/doc/00-intro.md) для операційної системи пристрою. Радимо встановити його глобально, щоб було зручніше користуватися.

#### Додавання PHPUnit як глобального інструмента

Скористайтеся такою командою:

```shell
composer global require phpunit/phpunit ^11.5
```

Обовʼязково встановіть версію 11.5 або новішу.
