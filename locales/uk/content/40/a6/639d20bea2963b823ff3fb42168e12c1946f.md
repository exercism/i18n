# Додаток до інструкцій

## Як цю вправу структуровано на треку Python

Тести для цієї вправи очікують, що ми створимо [`class`][classes] Matrix (див. також [concept:python/classes]()).
Це відрізняється від _використання_ обʼєкта Matrix зі сторонньої бібліотеки, як-от [Numpy][numpy-matrix], що не підтримується.
 _Не варто хвилюватися, це не так складно, як здається!_
 Щоб дізнатися більше про `classes` і структури даних, перегляньмо ресурси нижче:


-   [**Перший погляд на класи**](https://docs.python.org/3/tutorial/classes.html#a-first-look-at-classes) з документації Python 3. 
-   [**Як визначити клас у Python**](https://realpython.com/python3-object-oriented-programming/#how-to-define-a-class-in-python) із сайту Real Python.  
-   [**Структури даних у Python**](https://docs.python.org/3/tutorial/datastructures.html) з документації Python 3.

[numpy-matrix]: https://numpy.org/doc/stable/reference/generated/numpy.matrix.html
