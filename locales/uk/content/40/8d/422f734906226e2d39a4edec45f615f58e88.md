# Підказки

## 1. Створіть табличку для нагоди

- [шаблонні рядки][mdn-template-strings] (шаблонні літерали) дозволяють підставляти один або кілька рядків тексту (англ. string) і вбудовані вирази

## 2. Створіть табличку до дня народження

- [шаблонні рядки][mdn-template-strings] (шаблонні літерали) дозволяють підставляти рядки тексту та вбудовані вирази
- [тернарний оператор][mdn-ternary-operator] дає змогу коротко працювати з умовами, подібно до `if/else`. У шаблонних рядках його буває зручніше використовувати, бо він компактніший.

## 3. Створіть табличку для випускного

- [шаблонні рядки][mdn-template-strings] дають змогу записати рядок тексту на кількох рядках.

## 4. Обчисліть вартість таблички

- Зʼясуйте [`length`][mdn-string-length] символів.
- Покажіть лише перші два десяткові знаки у [записі з фіксованою комою][mdn-to-fixed].
