# Тести

Перш ніж запускати тести, переконаймося, що теку із завданням налаштовано правильно: виконаймо кроки зі встановлення, а саме `corepack yarn install` і налаштування Editor SDK.

Запустімо тести так:

```bash
$ corepack yarn test
```

## Пропущені тести

У наборах тестів пропущено всі тести, крім першого.

Коли тест почне проходити, можна увімкнути наступний, змінивши `xit` на `it`.
Крім того, тести можна групувати за допомогою `xdescribe`.
Увімкнімо групу, змінивши це на `describe`.
Нарешті, деякі вправи можуть мати необовʼязкові тести `it.skip`.
Вилучімо `.skip`, щоб виконати необовʼязковий тест.
