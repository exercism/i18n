# Булеві значення

У Swift є тип під назвою [`Bool`][bools]; він представляє булеві значення (англ. Boolean), тобто значення `true` та `false`.

## Логічні оператори

У Swift є три [логічні оператори (`!`, `||`, `&&`)][logical-operators], які поєднують булеві значення й утворюють вирази, що дають різні значення.

### І (`&&`)

Оператор [_і_][and] у Swift позначається `&&` (логічне і) і повертає `true`, якщо обидва подані значення дорівнюють `true`, інакше повертає `false`.
Коли ми використовуємо оператор _і_, одне булеве значення ставимо праворуч від `&&`, а друге - ліворуч.

```Swift
true && true  // true
true && false // false
```

### Або (`||`)

Оператор [_або_][or] у Swift позначається `||` (логічне або) і повертає `true`, якщо **принаймні одне** з поданих значень дорівнює `true`; якщо ж обидва значення дорівнюють `false`, то повертає `false`.
Коли ми використовуємо оператор _або_, одне булеве значення ставимо праворуч від `||`, а друге - ліворуч.

```swift
true || true   // true
true || false  // true
false || false // false
```

### Заперечення (`!`)

Оператор [_заперечення_][not] у Swift позначається `!` і повертає `true`, якщо подане булеве значення дорівнює `false`, і `false`, якщо подано `true`.
Коли ми використовуємо оператор _заперечення_, одне булеве значення ставимо після оператора (`!`).

```swift
!true  // false
!false // true
```

## Використання дужок (`()`)

Працюючи з булевими значеннями, ми можемо скористатися [явними дужками][explicit-parentheses], щоб визначити, які булеві значення обчислити першими.
Результат може відрізнятися залежно від того, як розставлено дужки.
У Swift спершу обчислюється те, що стоїть у дужках.

```swift
true && false && false || true   // true
true && false && (false || true) // false
```

Оскільки те, що стоїть у дужках, обчислюється першим, у наведеному нижче прикладі оператор _заперечення_ застосується до виразу всередині дужок.

```Swift
!true && false   // false
!(true && false) // true
```

~~~~exercism/note
Дужки варто використовувати лише тоді, коли вони впливають на результат; інакше їх слід опустити.
~~~~
