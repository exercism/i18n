# Локальне налагодження

Коли ми запускаємо тести треку Bash з [Bats](https://github.com/bats-core/bats-core), Bats перехоплює і STDOUT, і STDERR, щоб можна було перевіряти вивід.

```exercism/caution
Це працює локально з `bats`, але **не** в онлайн-редакторі Exercism.
```

Якщо ми хочемо надрукувати вивід для налагодження, не впливаючи на результат тесту, записуємо його у файловий дескриптор (fd) 3.

```bash
echo 'debug message' >&3
```

Bats показує вивід, записаний у fd 3, під час запуску тестів, але не включає цей вивід у твердження, як-от `assert_output`.

Приклад запуску:

```none
$ bats hello_world.bats
hello_world.bats
 ✓ Say Hi!
debug message
1 test, 0 failures
```

Це корисно, коли ми запускаємо тести локально.
