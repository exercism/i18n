# Інструкції

Ми працюємо в інтернет-магазині модного одягу.
У нас виникає ідея нової можливості сайту: пропонувати користувачам комплекти одягу.
Нас цікавлять можливі комплекти, їхні ціни та усунення несумісних варіантів.

~~~~exercism/note
Хоча наведені нижче задачі можна розвʼязати різними способами, усі їх можна розвʼязати за допомогою генератора.
~~~~

## 1. Створити елемент одягу


Реалізуйте `clothingitem()`, яка приймає два `Tuple`: один із `categories`, а другий із відповідними `qualities`.
Функція повинна повернути `Dict`, де ключами є `categories`, а значеннями - `qualities`.

```julia-repl
julia> categories = ("item_name", "price", "color", "base_color");

julia> qualities = ("Descriptive Name", 99.00, "Ochre Red", "red");

julia> clothingitem(categories, qualities)
Dict{String, Any} with 4 entries:
  "price"      => 99.0
  "item_name"  => "Descriptive Name"
  "base_color" => "red"
  "color"      => "Ochre Red"
```

Функція повинна впоратися з будь-якою кількістю `categories`.

## 2. Запропонувати комбінації

Реалізуйте `get_combinations()`, яка приймає `Tuple` верхів і `Tuple` низів.
Функція повинна повернути `cartesian product` цих кортежів як двовимірний масив (тобто `Matrix`).
Кожен елемент - це комбінація `(top, bottom)` у вигляді `Tuple`.
Верх змінюється від рядка до рядка, а низ - від стовпця до стовпця.

```julia-repl
julia> tops = (
        Dict("item_name" => "Dress shirt"),
        Dict("item_name" => "Casual shirt")
        );

julia> bottoms = (
        Dict("item_name" => "Jeans"),
        Dict("item_name" => "Dress trousers")
       );

julia> get_combinations(tops, bottoms)
2×2 Matrix{Tuple{Dict{String, String}, Dict{String, String}}}:
 (Dict("item_name"=>"Dress shirt"), Dict("item_name"=>"Jeans"))   (Dict("item_name"=>"Dress shirt"), Dict("item_name"=>"Dress trousers"))
 (Dict("item_name"=>"Casual shirt"), Dict("item_name"=>"Jeans"))  (Dict("item_name"=>"Casual shirt"), Dict("item_name"=>"Dress trousers"))
```

## 3. Підсумувати ціни комплектів

Кожен елемент одягу має повʼязане з ним поле `price`, тож корисно мати змогу порівнювати повну ціну комплектів.
Реалізуйте `get_prices()`, яка приймає масив комбінацій одягу.
Функція повинна повернути масив такої самої форми з цінами комплектів на відповідних позиціях.

```julia-repl
julia> tops = (
        Dict("item_name" => "Dress shirt", "base_color" => "blue", "price" => 35),
        Dict("item_name" => "Casual shirt", "base_color" => "black", "price" => 20)
       );

julia> bottoms = (
        Dict("item_name" => "Jeans", "base_color" => "blue", "price" => 30),
        Dict("item_name" => "Dress trousers", "base_color" => "black", "price" => 75)
       );

julia> combomatrix = get_combinations(tops, bottoms);

julia> get_prices(combomatrix)
2×2 Matrix{Int}::
 65  110
 50   95

julia> filteredmatrix = filter_clashing(combomatrix)
1-element Vector{Tuple{Dict{String, Any}, Dict{String, Any}}}:
 (Dict("price" => 20, "item_name" => "Casual shirt", "base_color" => "black"), Dict("price" => 30, "item_name" => "Jeans", "base_color" => "blue"))

julia> get_prices(filteredmatrix)
1-element Vector{Int}:
 50
```

## 4. Відфільтрувати несумісні комплекти

Кожен елемент одягу має поле `base_color`.
Скористайтеся цим полем, щоб прибрати всі комбінації, у яких верх і низ мають однаковий базовий колір.
Реалізуйте `filter_clashing()`, яка приймає масив комбінацій одягу.
Поверніть одновимірний масив (тобто `Vector`) відповідних комбінацій.

```julia-repl
julia> tops = (
        Dict("item_name" => "Dress shirt", "base_color" => "blue", "price" => 35),
        Dict("item_name" => "Casual shirt", "base_color" => "black", "price" => 20)
       );

julia> bottoms = (
        Dict("item_name" => "Jeans", "base_color" => "blue", "price" => 30),
        Dict("item_name" => "Dress trousers", "base_color" => "black", "price" => 75)
       );

julia> combos = get_combinations(tops, bottoms);

julia> filter_clashing(combos)
1-element Vector{Tuple{Dict{String, Any}, Dict{String, Any}}}:
 (Dict("price" => 20, "item_name" => "Casual shirt", "base_color" => "black"), Dict("price" => 30, "item_name" => "Jeans", "base_color" => "blue"))
```
