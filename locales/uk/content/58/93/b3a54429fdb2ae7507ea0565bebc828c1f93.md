# Докладніше

[Охоронні вирази][guards] використовують як доповнення до [зіставлення зі зразком][exercism-pattern-matching]. Його ми розглянемо в одному з наступних понять.
Охоронні вирази дають нам змогу мати різні реалізації функції залежно від значення вхідних даних.
Вони дозволяють робити складніші перевірки.

Охоронний вираз починається з вертикальної риски `|`, після якої йде булевий вираз (англ. Boolean), і завершується знаком рівності `=` та тілом функції.
Для однієї функції може бути кілька охоронних виразів.
Охоронні вирази обчислюються згори вниз, і виконується той, який першим дає `True`.
Охоронний вираз може містити `otherwise`, який перехоплює будь-яке значення, що не збігається з попередніми охоронними виразами.

```haskell
isEven :: Int -> String
isEven n
    | even n = "n is even"
    | otherwise = "n is odd"
```

Ми також можемо визначити власну функцію і використати її в охоронному виразі.

```haskell
isEven' :: Int -> Bool
isEven' n = even n

isEven :: Int -> String
isEven n
    | isEven' n = "n is even"
    | otherwise = "n is odd"
```
