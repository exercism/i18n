# Вступ

Загалом, у програмуванні ми не хочемо винаходити колесо заново.
Для багатьох стандартних алгоритмів уже знайдеться хтось, хто, можливо, вже зробив цю роботу за нас.

## Включення

Щоб включити вміст інших файлів, C++ використовує директиву `include`.
Ці включення слід записувати на початку файлу.
Під час компіляції рядок із директивою замінюється вмістом відповідного файлу.
Простори імен після включень залишаються такими ж, як у вихідному файлі.

## Стандартна бібліотека

Стандартна бібліотека пропонує багато поширених функцій, алгоритмів і структур даних.
Стандартна бібліотека використовує простір імен `std`.

Один із прикладів - бібліотека числових обчислень C `cmath`.
Вона надає багато поширених математичних операцій.

```cpp
#include <cmath>

int cube_me(int a) {
    // raise `a` to the third power
    return std::pow(a, 3);
}
```

~~~~exercism/note
Стандартні бібліотеки включають за допомогою кутових дужок `<>`, а не подвійних лапок `"`.
Різниця в тому, де компілятор шукає відповідні файли.
Для версії з кутовими дужками пошук у поточному проєкті пропускається, і компілятор одразу починає з системних каталогів включення.
Якщо потрібно включити локальні файли, використовують подвійні лапки: `#include "myfile"`
~~~~
