# неочікуваний обовʼязковий параметр

У тестах `${'parameter.name'}\`${'parameter.name'}\`` викликають і зі значенням, і без нього, але параметр _не позначено як необовʼязковий_, а отже тести не пройдуть. У TypeScript параметр можна явно позначити як необовʼязковий за допомогою постфікса `?`:

```typescript
function(${'parameter.name'}?: ${'parameter.type'}) {
  //
}
```

Або, як альтернатива, присвоївши йому типове значення:

```typescript
function(${'parameter.name'}: ${'parameter.type'} = <default>) {
  //
}
```
