# Вступ

*Дизʼюнктна множина* (структура union-find) зберігає набір значень, розбитих на групи, що не перетинаються, і швидко відповідає на одне запитання: чи перебувають ці два значення в одній групі? Вона живе у словнику [`disjoint-sets`][disjoint-sets].

## Створення дизʼюнктної множини

`<disjoint-set>` створює порожню структуру. Значення (*атоми*) додають по одному за допомогою `add-atom` або з послідовності за допомогою `add-atoms`. Спочатку кожен атом перебуває у власній групі.

```
<disjoint-set> ( -- disjoint-set )
add-atom       ( atom disjoint-set -- )
add-atoms      ( seq disjoint-set -- )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ 1 2 3 } over add-atoms   ! 1, 2 and 3 each in their own group
```

Дизʼюнктна множина *змінювана*: `add-atom`, `add-atoms` і `equate` змінюють її на місці, а не повертають нову. `keep` стає в пригоді, коли треба повернути дизʼюнктну множину на стек після того, як одне з цих слів її спожило.

## Обʼєднання груп

`equate` обʼєднує дві групи, які містять його атоми. Обʼєднання транзитивне: прирівняймо два атоми, потім один із них із третім, і всі три опиняться в одній групі.

```
equate ( atom1 atom2 disjoint-set -- )
```

## Представники

Кожна група має одного канонічного члена, свого *представника*. `representative` повертає його, і два атоми належать до однієї групи тоді й лише тоді, коли їхні представники рівні.

```
representative ( atom disjoint-set -- representative )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ 1 2 3 } over add-atoms
1 2 pick equate
1 over representative .   ! => 1
2 over representative .   ! => 1   (same representative as 1)
3 over representative .   ! => 3   (still on its own)
```

Те, який атом група обирає своїм представником, є внутрішньою деталлю: не покладаймося на вибір конкретного атома, а лише на те, що два атоми в одній групі узгоджуються.
