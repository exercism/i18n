# Про D

[D](https://dlang.org) — це мова системного програмування з C-подібним синтаксисом і статичною типізацією. Вона поєднує ефективність, контроль і потужність моделювання з безпекою та продуктивністю програміста. Мову започаткували [Волтер Брайт](https://en.wikipedia.org/wiki/Walter_Bright) та [Андрій Александреску](https://en.wikipedia.org/wiki/Andrei_Alexandrescu) починаючи з версії D 2.

D — результат десятиліть досвіду створення компіляторів для багатьох різноманітних мов, і вона має безліч [унікальних можливостей](http://dlang.org/overview.html):

- високорівневі конструкції для потужного моделювання
- високопродуктивна компільована мова
- статична типізація
- еволюція C++ (без його помилок)
- прямий інтерфейс до API операційної системи та апаратного забезпечення
- блискавично швидка компіляція
- дає змогу писати безпечний щодо памʼяті код (SafeD)
- код, який легко підтримувати й розуміти.
- швидке опанування (C-подібний синтаксис, схожий на Java та інші)
- сумісність із двійковим інтерфейсом застосунків мови C
- мультипарадигмовність (імперативне, структурне, обʼєктно-орієнтоване, узагальнене, чистота функціонального програмування і навіть асемблер)
- вбудоване запобігання помилкам (контракти, модульні тести)

[D Language Foundation](https://dlang.org/foundation.html) — це організація, яка займається розробкою та розвитком мови D.
