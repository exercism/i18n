# Рядок тексту

Тип даних `String` - це лінійна послідовність символів, закодованих у UTF-8. Він стане в пригоді для зберігання текстових даних.

## Створення рядка тексту

Створити рядок тексту (англ. string) можна за допомогою асоційованих функцій `String::new()` або `String::from()`. Багато типів мають метод `to_string`, щоб отримати рядок тексту, наприклад, із числа.

```rust
let my_string = String::from("The answer is");
let answer = 42.to_string();
println!("{my_string} {answer}");
```

### Макрос `format!`

Оскільки створення великого рядка тексту з кількох менших значень різних типів даних трапляється часто, у Rust є також скорочений запис, який бере на себе подробиці виклику `to_string`: макрос `format!`. Наприклад, ми могли б спростити побудову складеного рядка тексту вище так:

```rust
let the_answer = format!("{} {}.", "The answer is", 42);
assert_eq!("The answer is 42.", the_answer);
```

## Зрізи рядка тексту

Рядки тексту тісно повʼязані зі зрізами. Зріз рядка тексту - це незмінне посилання на ділянку памʼяті відомого розміру, що містить лінійну послідовність символів, закодованих у UTF-8. Будь-який рядок тексту можна звести до зрізу рядка тексту, позичивши його за допомогою оператора розіменування (`&`). Щоб перетворити зріз рядка тексту на рядок тексту, підійде і метод `to_string()`, і `String::from`.

У коді Rust рядковий літерал беруть у подвійні лапки. Такі рядкові літерали завжди є зрізами рядка тексту, бо вказують на незмінну ділянку памʼяті всередині виконуваного файлу програми.

```rust
let string = String::from("string");
let slice = "string";
assert_eq!(slice, &string);
```

## Змінювання рядка тексту

Щоб зʼєднати рядок тексту з одним символом, скористаймося методом `push`. Щоб зʼєднати рядок тексту зі зрізом рядка тексту, скористаймося методом `push_str` або оператором `+`.

```rust
fn main() {
    // For demonstration purposes, we're not using `format!`
    let s1 = String::from("tic");
    let s2 = String::from("tac");
    let s3 = String::from("toe");

    let s = s1 + "-" + &s2 + "-" + &s3;
    println!("{s}");
}
```

## Доступ до символів у рядку тексту

Оскільки рядки в Rust закодовані в UTF-8, не всі символи мають однаковий розмір. Тому тип даних `String` не надає оператора індексування (`[]`). Щоб отримати всі символи або конкретний символ у рядку тексту, можна скористатися методом `chars()`. Він перебирає символи рядка один за одним.

```rust
let alphabet: String = ('a'..='z').collect();
for c in alphabet.chars() {
    println!("{c}");
}
let j = alphabet.chars().nth(9);
println!("{j:?}"); // prints Some('j')
```
