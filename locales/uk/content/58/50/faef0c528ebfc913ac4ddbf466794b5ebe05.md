# Вступ

Зрізи в Go схожі на списки або масиви в інших мовах.
Вони містять кілька елементів певного типу (або інтерфейсу).

Зрізи в Go базуються на масивах.
Масиви мають фіксований розмір.
Зріз же, на відміну від них, має динамічний розмір і є гнучким поданням елементів масиву.

Зріз записують як `[]T`, де `T` позначає тип елементів у зрізі:

```go
var empty []int                 // an empty slice
withData := []int{0,1,2,3,4,5}  // a slice pre-filled with some data
```

Щоб отримати або змінити елемент за заданим індексом з відліком від нуля, використовують запис із квадратними дужками:

```go
withData[1] = 5
x := withData[1] // x is now 5
```

Новий зріз можна створити з наявного зрізу, узявши діапазон елементів.
Знову ж таки використовують квадратні дужки, але вказують і початковий (включно), і кінцевий (не включно) індекс.
Якщо не вказати початковий індекс, він типово дорівнює 0.
Якщо не вказати кінцевий індекс, він типово дорівнює довжині зрізу.

```go
newSlice := withData[2:4]
// => []int{2,3}
newSlice := withData[:2]
// => []int{0,1}
newSlice := withData[2:]
// => []int{2,3,4,5}
newSlice := withData[:]
// => []int{0,1,2,3,4,5}
```

Додавати елементи до зрізу можна за допомогою функції `append`.
Нижче ми додаємо `4` і `2` до зрізу `a`.

```go
a := []int{1, 3}
a = append(a, 4, 2)
// => []int{1,3,4,2}
```

`append` завжди повертає новий зріз, і коли ми просто хочемо додати елементи до наявного зрізу, зазвичай результат присвоюють назад змінній зрізу, яку ми передали першим аргументом, як це зроблено вище.

`append` також можна використати, щоб обʼєднати два зрізи:

```go
nextSlice := []int{100,101,102}
newSlice  := append(withData, nextSlice...)
// => []int{0,1,2,3,4,5,100,101,102}
```

## Індекси у зрізах

Роботу з індексами зрізів слід завжди захищати перевіркою на існування індексу.
Інакше вся програма аварійно завершиться.

## Порожні зрізи

`nil`-зрізи - це типовий порожній зріз.
Вони нічим не поступаються зрізу без жодного значення.
Функція `len` працює з `nil`-зрізами, до них можна додавати елементи без ініціалізації тощо.
Якщо створюємо новий зріз, краще віддати перевагу `var s []int` (`nil`-зріз), а не `s := []int{}` (порожній, не-`nil` зріз).

## Швидкодія

Коли ми створюємо зріз, який наповнюватимемо в циклі, і знаємо його кінцевий розмір, швидкодію можна підвищити досить просто.
Головна ідея - звести до мінімуму кількість виділень памʼяті, адже це досить дорого, і воно трапляється, коли зріз виростає за межі виділеного простору.
Найбезпечніший спосіб - вказати для зрізу ємність `cap` за допомогою `s := make([]int, 0, cap)`, а потім, як завжди, додавати елементи через `append`.
Так місце для `cap` елементів виділяється одразу, хоч довжина зрізу поки що нульова.
На практиці `cap` часто дорівнює довжині іншого зрізу: `s := make([]int, 0, len(otherSlice))`.

## `append` не є чистою функцією

Функція `append` у Go оптимізована для швидкодії, тому вона не копіює вхідний зріз.
Це означає, що початковий зріз (перший параметр `append`) іноді змінюватиметься.
