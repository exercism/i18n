# Вступ

Зовнішні типи можна використовувати для посилання на типи даних, визначені в інших мовах, таких як Erlang або JavaScript.

Щоб визначити зовнішню функцію, оголосимо тип, але не надаватимемо жодних конструкторів. Потім його можна використовувати так само, як і будь-який інший тип.

```gleam
pub type OrderedDictionary(element)
```
