Ці віджети можна відображати самостійно й у Markdown-документах, наприклад, у кінці документа, щоб запропонувати додаткове читання або гарні вправи, з яких можна чогось навчитися.

**Примітка:** для тексту в рядку можна також використовувати звичайні посилання, і до них додадуться підказки. Докладніше див. у [документації про внутрішні посилання](/docs/building/markdown/internal-linking).

## Використання

Віджети можна використовувати всюди, де можна використовувати Markdown: у документації, підходах і обговореннях учнів та наставників.

Вони відображаються в такому форматі:

```md
[<type>:<id>]()
```

Частини `<type>` та `<id>` є змінними й залежать від конкретного віджета, який використовується.

Посилання-посилання, тобто вміст `()`, сайт ігнорує. Для зручності супроводу туди можна вказати будь-що.

## Віджет вправи

Формат посилання: `[exercise:<track-slug>/<exercise-slug>]()`

### Приклад

```markdown
Great job on solving this exercise! Some other exercises that you might also like to try:

- [exercise:fsharp/anagram]()
- [exercise:fsharp/isogram]()
```

## Віджет концепції

Формат посилання: `[concept:<track-slug>/<concept-slug>]()`

### Приклад

```markdown
There are three primary conditional statements that are used in Julia:

- [concept:julia/if-statements]()
- [concept:julia/ternary-operator]()
- [concept:julia/short-circuiting]()
```

## Віджет підходу

Формат посилання: `[approach:<track-slug>/<exercise-slug>/<approach-slug>]()`

### Приклад

```markdown
Here are some approaches you might want to checkout!

- [approach:csharp/two-fer/method-overloading]()
- [approach:csharp/two-fer/optional-parameter]()
```

## Віджет статті

Формат посилання: `[article:<track-slug>/<exercise-slug>/<article-slug>]()`

### Приклад

```markdown
We have an article you might be interested in:

- [article:csharp/reverse-string/performance]()
```
