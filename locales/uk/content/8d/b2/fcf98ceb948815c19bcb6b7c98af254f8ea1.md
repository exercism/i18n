# Інструкції

Наш друг Лінус - машиніст локомотива, який водить вантажні потяги між містами.
Хоча він чудово дає раду потягам, із логістикою та компʼютерами він не такий вправний.
Він хотів би скористатися нашою допомогою з програмування, щоб упорядкувати дані про потяги й виправити помилки в даних про маршрути.

~~~~exercism/note
Цю вправу можна було б легко розвʼязати за допомогою зрізів, індексування та різних методів `Dict`.
Однак нам хотілося б попрактикувати пакування (тобто slurping), розпакування (тобто splatting) і множинне присвоєння, розвʼязуючи кожну з наведених нижче задач.
~~~~

## 1. Створіть вектор усіх вагонів

Наш друг записував ідентифікатори (ID) кожного вагона, але він ніколи не знає наперед, скільки вагонів системі доведеться обробити в той чи інший момент. Решті логістичної програми було б набагато простіше, якби ці дані були запаковані в єдиний `Vector`.

Реалізуйте функцію `get_vector_of_wagons(args...)`, яка приймає довільну кількість ID вагонів.
Кожен ID буде додатним цілим числом.
Тоді функція повинна за допомогою `return` повернути надані ID як єдиний `Vector`.

```julia-repl
julia> get_vector_of_wagons(1, 7, 12, 3, 14, 8, 5)
7-element Vector{Int64}:
  1
  7
 12
  3
 14
  8
  5
```

## 2. Виправте вектор вагонів

На цьому етапі ми вже починаємо відчувати, які це дані й як вони використовуються в логістичній програмі.
Система ID завжди присвоює локомотиву ID **1**, а решта вагонів у потязі отримують випадково вибраний ID, більший за **1**.

Наш друг мав приєднати до потяга два нові вагони й забув оновити систему!
Тепер перші два вагони у `Vector` потяга потрібно перемістити в кінець, інакше все буде не в тому порядку.

Ускладнюючи ситуацію, наш друг щойно знайшов другий `Vector`, який, схоже, містить зниклі ID вагонів.
Усе, що він може пригадати, - це те, що після переміщення нових вагонів ID з цього другого `Vector` потрібно розмістити безпосередньо після позначеного локомотива.

Лінус був би дуже вдячний нам за виправлення його помилок і впорядкування даних.

Реалізуйте функцію `fix_vector_of_wagons(each_wagons_id, missing_wagons)`, яка приймає два `Vectors` з ID вагонів.
Вона має перемістити перші два елементи першого `Vector` у кінець і вставити значення з другого `Vector` позаду (_праворуч від_) ID локомотива (**1**).
Тоді функція повинна за допомогою `return` повернути `Vector` з цими змінами.

```julia-repl
julia> fix_vector_of_wagons([2, 5, 1, 7, 4, 12, 6, 3, 13], [3, 17, 6, 15])
13-element Vector{Int64}:
  1
  3
 17
  6
 15
  7
  4
 12
  6
  3
 13
  2
  5
```

## 3. Додайте пропущені зупинки

Тепер, коли всі дані про вагони правильні, Лінус хотів би, щоб ми оновили інформацію про маршрути в системі.
На транспортному маршруті потяг може зупинятися на кількох різних станціях, щоб забрати та/або залишити вантаж.
Кожна подорож може мати різну кількість таких проміжних пунктів доставки.
Наш друг хотів би, щоб ми оновили системний `Dict` маршрутизації будь-якою відсутньою або додатковою інформацією про доставку.

Реалізуйте функцію `add_missing_stops(route, stops...)`, яка приймає `Dict` маршрутизації, а далі - змінну кількість пар `stop_number => city`.
Тоді функція має повернути `Dict` маршрутизації, оновлений додатковим `key`, який містить `Vector` усіх доданих зупинок у порядку.

```julia-repl
julia> add_missing_stops(Dict("from" => "New York", "to" => "Miami"), :stop_1 => "Washington, DC", :stop_2 => "Charlotte", :stop_3 => "Atlanta", :stop_4 => "Jacksonville")
Dict{String, Any} with 3 entries:
  "stops" => ["Washington, DC", "Charlotte", "Atlanta", "Jacksonville"]
  "to"    => "Miami"
  "from"  => "New York"
```

## 4. Розширте інформацію про маршрут

Лінус працював над програмою маршрутизації й помітив, що деяким маршрутам бракує важливих деталей.
Початкову інформацію про маршрут було створено як `Dict`, і наш друг хотів би, щоб ми оновили цей `Dict` усім, чого може бракувати.
Кожен маршрут у системі потребує трохи інших деталей, тож Лінус дуже хотів би мати універсальне рішення.

Реалізуйте функцію `extend_route_information(route; more_route_information...)`, яка приймає `Dict` з містами відправлення й призначення, між якими пролягає маршрут потяга, а також змінну кількість іменованих аргументів із деталями маршруту, як-от швидкість, довжина чи температура.
Функція має повернути зведений `Dict` з усією інформацією про маршрут.

```julia-repl
julia> extend_route_information(Dict("from" => "Berlin", "to" => "Hamburg"); length = "100", speed = "50")
Dict{Any, String} with 4 entries:
  :speed  => "50"
  "to"    => "Hamburg"
  "from"  => "Berlin"
  :length => "100"


julia> extend_route_information(Dict("from" => "Paris", "to" => "London"), length = "15", temperature = "20", timeOfArrival = "10:30")
Dict{Any, String} with 5 entries:
  :temperature   => "20"
  :timeOfArrival => "10:30"
  "to"           => "London"
  "from"         => "Paris"
  :length        => "15"
```
