# Учасники

Учасники Exercism допомагають створювати мовні треки та інструментарій Exercism.

**Будь-хто може стати учасником Exercism**. Немає жодних передумов чи вимог для початку, і ми активно вітаємо людей з будь-яких кіл.
Понад 4000 людей вже допомогли створити Exercism!

Є багато різних способів допомогти Exercism:

- Написання вправ
- Розробка концепцій треку
- Покращення документації
- Створення відсутнього інструментарію (наприклад, Test Runners чи Code Analyzers)
- Виправлення bug
- Покращення вмісту треку.

...і багато іншого.

Відвідайте наш спеціальний [Розділ для учасників](/contributing), щоб переглянути всі завдання, які зараз потребують виконання.
