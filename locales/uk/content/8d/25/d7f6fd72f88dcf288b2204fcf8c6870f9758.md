# Інструкції

У цій вправі ми пограємося з радіокерованою машинкою, на яку ми нарешті назбирали грошей.

Машинки починають із повністю зарядженою батареєю (100%). Щоразу, коли ми керуємо машинкою за допомогою пульта дистанційного керування, вона проїжджає 20 метрів і витрачає один відсоток заряду батареї. Прізвисько машинки невідоме, доки її не створять.

Радіокерована машинка має гарний світлодіодний дисплей, який показує дві частини інформації:

- Загальну відстань, яку вона проїхала, у вигляді: `"<METERS> meters"`.
- Залишок заряду батареї у вигляді: `"Battery at <PERCENTAGE>%"`.

Якщо заряд батареї сягає 0%, ми більше не можемо керувати машинкою, і дисплей батареї покаже `"Battery empty"`.

## 1. Створіть нову радіокеровану машинку

Реалізуйте функцію `RemoteControlCar.new/0`, яка повертає структуру нової радіокерованої машинки:

```elixir
RemoteControlCar.new()
# => %RemoteControlCar{
#      battery_percentage: 100,
#      distance_driven_in_meters: 0,
#      nickname: "none"
#    }
```

Прізвисько є обовʼязковим для структури, тож переконайтеся, що значення ініціалізується у функції `new`, а не в самій структурі.

## 2. Створіть нову радіокеровану машинку з прізвиськом

Реалізуйте функцію `RemoteControlCar.new/1`, яка повертає структуру нової радіокерованої машинки із заданим прізвиськом:

```elixir
RemoteControlCar.new("Blue")
# => %RemoteControlCar{
#      battery_percentage: 100,
#      distance_driven_in_meters: 0,
#      nickname: "Blue"
#    }
```

## 3. Покажіть відстань

Реалізуйте функцію `RemoteControlCar.display_distance/1`, яка повертає відстань у тому вигляді, як її показано на світлодіодному дисплеї:

```elixir
car = RemoteControlCar.new()
RemoteControlCar.display_distance(car)
# => "0 meters"
```

Переконайтеся, що функція приймає як аргумент лише структуру `RemoteControlCar`.

## 4. Покажіть відсоток заряду батареї

Реалізуйте функцію `RemoteControlCar.display_battery/1`, яка повертає відсоток заряду батареї у тому вигляді, як його показано на світлодіодному дисплеї:

```elixir
car = RemoteControlCar.new()
RemoteControlCar.display_battery(car)
# => "Battery at 100%"
```

Переконайтеся, що функція приймає як аргумент лише структуру `RemoteControlCar`. Якщо заряд батареї сягає 0%, на дисплеї батареї відобразиться «Battery empty».

## 5. Керування змінює заряд батареї та пройдену відстань

Реалізуйте функцію `RemoteControlCar.drive/1`, яка:

- збільшує пройдену відстань у метрах на 20
- витрачає 1% заряду батареї

```elixir
RemoteControlCar.new("Red")
|> RemoteControlCar.drive()

# => %RemoteControlCar{
#      battery_percentage: 99,
#      distance_driven_in_meters: 20,
#      nickname: "Red"
#    }
```

Переконайтеся, що функція приймає як аргумент лише структуру `RemoteControlCar`.

## 6. Врахуйте керування з розрядженою батареєю

Оновіть функцію `RemoteControlCar.drive/1` так, щоб вона не збільшувала пройдену відстань і не зменшувала відсоток заряду батареї, коли батарея розряджена (0%):

```elixir
%RemoteControlCar{
  battery_percentage: 0,
  distance_driven_in_meters: 1980,
  nickname: "Red"
}
|> RemoteControlCar.drive()

# => %RemoteControlCar{
#      battery_percentage: 0,
#      distance_driven_in_meters: 1980,
#      nickname: "Red"
#    }
```
