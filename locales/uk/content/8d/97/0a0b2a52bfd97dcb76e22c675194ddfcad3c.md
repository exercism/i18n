# Підказки

## 1. Створіть нового мешканця

- Перегляньте [концепцію структур](/tracks/go/concepts/structs), щоб дізнатися, як створювати структури.

## 2. Перевірте інформацію про мешканця

- Нульове значення для рядка тексту (англ. string) - `""`.
- Нульове значення для мапи - `nil`.
- Перегляньте [концепцію мап](/tracks/go/concepts/maps), щоб дізнатися, як визначити, чи існує ключ у мапі.

## 3. Видаліть інформацію про мешканця

- Мешканця вважають видаленим, коли всі його поля встановлено в нульове значення.
- Перегляньте [концепцію нульових значень](/tracks/go/concepts/zero-values), щоб дізнатися, яке нульове значення має кожен тип у Go.

## 4. Порахуйте мешканців

- Перегляньте [концепцію ітерації з `range`](/tracks/go/concepts/range-iteration), щоб дізнатися, як перебирати елементи зрізу за допомогою `range`.
