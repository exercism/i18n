# Інструкції

Ми завзяті спостерігачі за птахами й щодня рахуємо, скільки птахів завітало до нашого саду.

Ми вирішили підняти спостереження за птахами на новий рівень і створити кілька інструментів, які допоможуть відстежувати й обробляти дані.

Дані ми вирішили зберігати як масив цілих чисел.
Перше число в масиві показує, скільки птахів завітало до нашого саду сьогодні, друге - вчора, і так далі.

```exercism/note
У справжніх застосунках завжди варто використовувати модулі ядра, де це можливо, однак для вивчення рекурсії не використовуйте в цій вправі жодної функції з `List`.
```

## 1. Перевірити, скільки птахів завітало сьогодні

Реалізуйте функцію `today`.
Вона має приймати масив із кількістю птахів за кожен день і повертати сьогоднішню кількість.
Якщо масив порожній, вона має повертати `Nothing`, інакше кількість буде загорнута в `Just`.

```elm
BirdCount.today [2, 5, 1]
    -- Just 2
```

## 2. Збільшити сьогоднішню кількість на одиницю

Реалізуйте функцію `incrementDayCount`.
Вона має приймати масив із кількістю птахів за кожен день і збільшувати сьогоднішню кількість на 1.
Якщо масив порожній, вона має повертати `[1]`.

```elm
BirdCount.incrementDayCount [4, 0, 2]
    -- [5, 0, 2]
```

## 3. Перевірити, чи був день без птахів

Реалізуйте функцію `hasDayWithoutBirds`.
Вона має приймати масив із кількістю птахів за кожен день.
Вона має повертати `True`, якщо був принаймні один день, коли птахи не завітали до саду, і `False` в іншому разі.

```elm
BirdCount.hasDayWithoutBirds [2, 0, 4]
    -- True

BirdCount.hasDayWithoutBirds [3, 8, 1, 5]
    -- False
```

## 4. Обчислити загальну кількість птахів, що завітали

Реалізуйте функцію `total`.
Вона має приймати масив із кількістю птахів за кожен день і повертати загальну кількість птахів, які завітали до нашого саду відтоді, як ми почали збирати дані.

```elm
BirdCount.total [4, 0, 9, 0, 5]
    -- 18
```

## 5. Обчислити кількість насичених днів

Деякі дні насиченіші за інші.
Насичений день - це день, коли до нашого саду завітало пʼятеро або більше птахів.

Реалізуйте функцію `busyDays`.
Вона має приймати масив із кількістю птахів за кожен день і повертати кількість насичених днів.

```elm
BirdCount.busyDays [4, 5, 0, 0, 6]
    -- 2
```
