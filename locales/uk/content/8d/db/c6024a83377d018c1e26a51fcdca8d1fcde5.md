# Інструкції

Маючи рядок цифр, обчисліть найбільший добуток для неперервного підрядка цифр довжиною n.

Наприклад, для вхідних даних `'1027839564'` найбільший добуток для серії з 3 цифр дорівнює 270 (9 * 5 * 6), а найбільший добуток для серії з 5 цифр дорівнює 7560 (7 * 8 * 3 * 9 * 5).

Зауважте, що ці серії мають займати лише *суміжні позиції* у вхідних даних; цифри не обовʼязково мають бути *послідовними за значенням*.

Для вхідних даних `'73167176531330624919225119674426574742355349194934'` найбільший добуток для серії з 6 цифр становить 23520.
