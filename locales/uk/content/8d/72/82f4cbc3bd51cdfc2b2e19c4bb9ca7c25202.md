# Інструкції

Ми працюємо над системою, яка має спростити процес входу в мережу нашої організації. Завдання стосуються автентифікації. Система використовує розпізнавання облич, щоб підтвердити особу.

У всіх випадках параметр кольору очей гарантовано не є null.

## 1. Переконайтеся, що риси обличчя збігаються

Реалізуйте `Authenticator.AreSameFace()`, щоб перевіряти, чи збігаються два обличчя.

Додайте методи перевірки рівності до класу `FacialFeatures`.

```csharp
Authenticator.AreSameFace(new FacialFeatures("green", 0.9m), new FacialFeatures("green", 0.9m);
// => true
Authenticator.AreSameFace(new FacialFeatures("blue", 0.9m), new FacialFeatures("green", 0.9m);
// => false
```

## 2. Автентифікуйте системного адміністратора

Попри всі заперечення, системний адміністратор наполягає на тому, щоб під час приймального тестування була вбудована ідентичність, яку завжди можна автентифікувати.

Електронна пошта адміністратора: admin@exerc.ism. У адміністратора зелені очі та губний жолобок шириною 0.9.

Додайте методи перевірки рівності до класу `Identity`.

Реалізуйте метод `Authenticator.IsAdmin()`, щоб перевірити, чи передана ідентичність збігається з ідентичністю адміністратора.

```csharp
var authenticator = new Authenticator();
authenticator.IsAdmin(new Identity("admin@exerc.ism", new FacialFeatures("green", 0.9m)));
// => true
authenticator.IsAdmin(new Identity("admin@thecompetition.com", new FacialFeatures("green", 0.9m)));
// => false
```

## 3. Зареєструйте нові ідентичності

Реалізуйте метод `Authenticator.Register()`, який зберігає ідентичність у самому автентифікаторі так, щоб виклики `IsRegistered()` повертали `true` для цієї ідентичності, інакше `IsRegistered()` повертає `false`.

Щоб виявляти повторні спроби зареєструвати ідентичність: якщо ідентичність уже зареєстровано, то `Authenticator.Register()` повертає `false`, інакше `true`.

```csharp
var authenticator = new Authenticator();
authenticator.Register(new Identity("tunde@thecompetition.com", new FacialFeatures("blue", 0.9m)));
// => true
authenticator.IsRegistered(new Identity("tunde@thecompetition.com", new FacialFeatures("blue", 0.9m)));
// => true
authenticator.Register(new Identity("tunde@thecompetition.com", new FacialFeatures("blue", 0.9m)));
// => false
```

## 4. Унеможливте автентифікацію недійсних ідентичностей

Реалізуйте метод `Authenticator.IsRegistered()` і подбайте про те, щоб він повертав false, коли не зареєстровано жодної ідентичності.

```csharp
var authenticator = new Authenticator();
authenticator.IsRegistered(new Identity("alice@thecompetition.com", new FacialFeatures("blue", 0.8m)));
// => false
```

## 5. Додайте діагностику для виявлення кількох спроб автентифікації

Повідомили про помилку: метод `Authenticator.IsRegistered()` викликається кілька разів підряд для тієї самої ідентичності. Ми вважаємо, що це якась проблема «відбиття», коли той самий запис надсилається кілька разів. Додайте діагностичну процедуру `Authenticator.AreSameObject()`, щоб підтримати будь-яке тестування. Ця процедура порівнює два обʼєкти й повертає `true`, якщо це той самий екземпляр, інакше `false`.

```csharp
var identityA = new Identity("alice@thecompetition.com", new FacialFeatures("blue", 0.9m));
var identityB = identityA;
Authenticator.AreSameObject(identityA, identityB);
// => true

var identityC = new Identity("alice@thecompetition.com", new FacialFeatures("blue", 0.9m));
var identityD = new Identity("alice@thecompetition.com", new FacialFeatures("blue", 0.9m));
Authenticator.AreSameObject(identityC, identityD);
// => false
```
