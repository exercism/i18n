# Інструкції

Ми розробляємо систему керування вмістом для вебсайту, де публікуються статті, дописи в блогах та інший письмовий вміст.
Наше завдання - реалізувати обробник завдань, який опрацьовуватиме завдання в черзі з пріоритетами.
Обробник завдань отримуватиме завдання і на основі навантаження на сервер та їхнього пріоритету вирішуватиме, яке завдання виконувати наступним.
Якщо сервер зазнає великого навантаження, тоді число пріоритету має бути вищим, щоб завдання було виконано.
Сервер динамічно змінюватиме навантаження залежно від навантаження.

## 1. Ініціалізуйте `TaskHandler`

`TaskHandler` потрібно ініціалізувати з чергою та типовим значенням load_level.

Реалізуйте ініціалізатор класу `TaskHandler`, який приймає як аргумент `Array` з `String`-ів із назвами завдань і зберігає його у змінній екземпляра `@tasks`.
Ініціалізатор також має створити змінну екземпляра `@task_condition_logic`, яка зберігає `Proc`, що приймає `Int32` і повертає true, якщо аргумент дорівнює 0 або більший за 0, та false, якщо він менший за 0.

```crystal
task_handler = TaskHandler.new(["task1", "task2", "task3"])
# => #<TaskHandler:0x7fd8d4cfbf00 @tasks=["task1", "task2", "task3"], @task_condition_logic=#<Proc(Int32, Bool):0x562536a4a330>>
```

## 2. Оновіть логіку умови завдання

Сервер має вміти оновлювати логіку умови завдання залежно від навантаження на сервер.

Реалізуйте метод `TaskHandler#update_task_condition_logic`, який приймає блок як аргумент; цей блок має зберігатися у змінній екземпляра `@task_condition_logic`.

```crystal
task_handler = TaskHandler.new(["task1", "task2", "task3"])
task_handler.update_task_condition_logic { |load| load > 1 }
# => #<TaskHandler:0x7f068118cf00 @tasks=["task1", "task2", "task3"], @task_condition_logic=#<Proc(Int32, Bool):0x562df99d0370>>
```

## 3. Виконайте наступне завдання

Сервер має вміти виконувати наступне завдання в черзі.

Перше завдання в масиві `@tasks` буде виконано наступним.
Завдання потрібно виконати, якщо заданий рівень пріоритету завдання дає true, коли його передати в `Proc` `@task_condition_logic`.

Метод повертає повідомлення залежно від того, чи було завдання виконано.
Якщо завдання було виконано, метод має повернути: `"Completed <task>"`.
Якщо завдання не було виконано, метод має повернути: `"Could not complete <task>"`.

Якщо завдання було виконано, його потрібно вилучити з масиву `@tasks`.

Реалізуйте метод `TaskHandler#execute_next_task`, який приймає як аргумент рівень пріоритету наступного завдання у вигляді `Int32` і повертає `String` залежно від того, чи було завдання виконано.

```crystal
task_handler = TaskHandler.new(["task1", "task2", "task3"])
task_handler.update_task_condition_logic { |load| load > 1 }
task_handler.execute_next_task(2)
# => "Completed task1"

task_handler.execute_next_task(1)
# => "Could not complete task2"
```
