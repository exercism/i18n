# Інструкції

Ми з друзями любимо грати в настільні рольові ігри, але помітили, що нових людей складно залучити до нашої групи. Їм часто важко дається створення персонажа. Вони не знають, з чого почати. Щоб допомогти новачкам, ми вирішили написати невеличку програму, яка проведе їх через цей процес.

## 1. Привітаймо нового гравця

Реалізуйте функцію `RPG.CharacterSheet.welcome/0`. Вона повинна вивести вітальне повідомлення й повернути `:ok`.

```elixir
RPG.CharacterSheet.welcome()
# > Welcome! Let's fill out your character sheet together.
# => :ok
```

## 2. Запитаймо імʼя персонажа

Реалізуйте функцію `RPG.CharacterSheet.ask_name/0`. Вона повинна вивести запитання, дочекатися відповіді й повернути відповідь без пробільних символів на початку й у кінці.

```elixir
RPG.CharacterSheet.ask_name()
# > What is your character's name?
# < Mathilde
# => "Mathilde"
```

## 3. Запитаймо клас персонажа

Реалізуйте функцію `RPG.CharacterSheet.ask_class/0`. Вона повинна вивести запитання, дочекатися відповіді й повернути відповідь без пробільних символів на початку й у кінці.

```elixir
RPG.CharacterSheet.ask_class()
# > What is your character's class?
# < healer
# => "healer"
```

## 4. Запитаймо рівень персонажа

Реалізуйте функцію `RPG.CharacterSheet.ask_level/0`. Вона повинна вивести запитання, дочекатися відповіді й повернути відповідь як ціле число.

```elixir
RPG.CharacterSheet.ask_level()
# > What is your character's level?
# < 2
# => 2
```

## 5. Поєднаймо попередні кроки в один

Реалізуйте функцію `RPG.CharacterSheet.run/0`. Вона повинна привітати нового гравця, запитати імʼя, клас і рівень персонажа, а також повернути аркуш персонажа у вигляді мапи. Крім того, вона повинна вивести мапу з підписом «Your character».

```elixir
RPG.CharacterSheet.run()
# > Welcome! Let's fill out your character sheet together.
# > What is your character's name?
# < Mathilde
# > What is your character's class?
# < healer
# > What is your character's level?
# < 2
# > Your character: %{class: "healer", level: 2, name: "Mathilde"}
# => %{class: "healer", level: 2, name: "Mathilde"}
```
