# Докладніше

Так само, як вказівник можна створити на `int` чи інший базовий тип даних, вказівник можна створити й на функцію.
Вказівник на функцію дозволяє передати функцію в іншу функцію.
Функцію, яку передають як значення параметра в іншу функцію, називають функцією першого класу.
Функцію, яка приймає одну або кілька функцій як параметр або повертає функцію, називають функцією вищого порядку.

У наступному прикладі `is_even` та `is_odd` є функціями першого класу.
А функцією вищого порядку є `test_number`.

```c
#include <stdio.h>
#include <stdbool.h>

bool is_even (int number) {
    return number & 1 != 1;
}

bool is_odd (int number) {
    return number & 1 == 1;
}

// this function takes any other function which takes a number and returns a bool
void test_number(bool (*func) (int), int number, char *text){
    printf(text, number, func(number)? "true": "false");
}

int main() {
    // prints Testing odd for 3 is true
    test_number(is_odd, 3,"Testing odd for %d is %s\n");
    // prints Testing even for 3 is false
    test_number(is_even, 3,"Testing even for %d is %s\n");
}
```
Сигнатура функції `bool (*func) (int)` для першого аргументу `test_number` збігається з сигнатурою переданих функцій.
І `is_even`, і `is_odd` приймають параметр типу `int` і повертають `bool`.
У `(*func)` запис `func` означає назву функції, яку буде використано.
Якби використали `(*fn)`, то викликали б його так: `printf(text, number, fn(number)? "true": "false");`.
Щоб передати щось у параметр типу вказівник на функцію, під час виклику `test_number` ми вказуємо назву функції з потрібною сигнатурою.
Отже, бачимо, що назва функції вказує на адресу цієї функції.

Виклик вказівника на функцію з неправильною сигнатурою призводить до невизначеної поведінки (UB).
Залежно від компілятора код може взагалі не скомпілюватися, а може скомпілюватися з попередженнями чи без них, але потім аварійно завершитися під час виконання.
