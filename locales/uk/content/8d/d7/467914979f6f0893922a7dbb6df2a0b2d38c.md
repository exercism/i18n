# Про

Haxe має строгу типізацію, але систему типів за потреби можна обійти. Присвоєння значення імені називають визначенням змінної. Змінну можна визначити або явно вказавши її тип, або дозволивши компілятору Haxe вивести тип за допомогою [`var`var`](var). Отже, ці два визначення змінної рівнозначні:

```haxe
var explicitVariable:Int = 10; // Explicitly typed
var implicitVariable = 10; // Implicit typed
```

Оновити змінну можна за допомогою оператора `=`:

```haxe
var number = 0; // Initial value
number = 1; // Updated value
```

Компілятор видасть помилку, якщо спробувати присвоїти значення, тип якого відрізняється від типу змінної:

```haxe
var number = 1; // Variable number is of integer type
number = "Hello" // Error trying to assign a string to an integer variable
```

У Haxe код зазвичай пишуть усередині _функції_, яку також називають [_методом_](method). Ці функції можуть приймати параметри (аргументи) і повертати значення за допомогою ключового слова `return`. Функції викликають за допомогою синтаксису `()`. Усі функції повинні мати тип поверненого значення.

```haxe
function add(x:Int, y:Int):Int {
  return x + y;
}
```

Область видимості в Haxe визначається між символами `{` і `}`.

Haxe підтримує два типи коментарів. Однорядкові починаються з `//`, а багаторядкові вставляють між `/*` і `*/`.
