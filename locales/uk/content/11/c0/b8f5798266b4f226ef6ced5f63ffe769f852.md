## Ітерація масиву

Цикл `for` дає змогу перебрати масив і повторити код для кожного елемента:

```haxe
var fruitList = ["apple", "banana", "pear"];

for (fruit in fruitList) {
  trace(fruit);
}

// apple
// banana
// pear
```

У наведеному прикладі `fruit` - це змінна, яка зберігає значення окремого елемента масиву `fruitList`. Компілятор перевіряє, що `fruitList` можна перебрати; інакше він зупинить виконання.

## Ітерація діапазону

Перебирати числа можна за допомогою оператора діапазону. Оператор приймає два операнди типу `Int` і записується як `min...max`. Значення `min` входить у діапазон, а `max` - ні (`min` <= i і `max` > i)

```haxe
for (i in 0...10) {
  trace(i); // from 0 to 9
}
```

## Ітерація пар ключ-значення

Можна перебирати колекції пар ключ-значення. Єдина відмінність у синтаксисі полягає в тому, що замість однієї змінної використовують ідентифікатор змінної для ключа, потім `=>`, а потім ідентифікатор змінної для значення:

```haxe
var map = [1 => 101, 2 => 202, 3 => 303];

for (k => v in map) {
  trace(key, value);
}

// 1, 101
// 2, 202
// 3, 303
```
