# Додаток до інструкцій

Піднесення комплексних чисел до степеня потребує експоненційної функції, а також функцій синуса й косинуса, жодної з яких немає у WebAssembly. На щастя, для їх обчислення можна скористатися [рядом Тейлора](https://en.wikipedia.org/wiki/Taylor_series). Точність має бути принаймні `1/26!`, щоб отримані значення збігалися з очікуваними.

## Експоненційна функція

```
exp(x) ≃ 1 + x + x ^ 2 / 2! + x ^ 3 / 3! + x ^ 4 / 4! + ... + x ^ n / n!
```

## Функція синуса

```
sin(x) ≃ x - x ^ 3 / 3! + x ^ 5 / 5! - x ^ 7 / 7! + ... - x ^ n / n!
```

## Функція косинуса

```
cos(x) ≃ 1 - x ^ 2 / 2! + x ^ 4 / 4! - x ^ 6 / 6! + ... - x ^ n / n!
```
