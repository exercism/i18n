# Тести

Щоб запустити тести з командного рядка, виконайте таку команду з каталогу вправи:

```bash
java -jar /path/to/mars.jar nc runner.mips impl.mips
```

## Графічний інтерфейс

Щоб запустити тести через графічний інтерфейс симулятора MARS, підключіть свою реалізацію за допомогою `include` унизу `runner.mips`, розкоментувавши останній рядок.
