# Інструкції

Уявімо себе вахтовим офіцером на катері, що перетинає Берингову протоку. Три джерела називають позицію кожної крижини й кожного мису в зоні видимості:

- **Стіл із картами** говорить мовою сторін світу: `north`, `east`, `south`, `west`. Лише напрямок, без відстані.
- **Штурман** говорить у *полярних* координатах від останнього визначення позиції катера: величина в морських милях і азимут у градусах за годинниковою стрілкою від півночі (тож `0` - це північ, `90` - схід, `180` - південь, `270` - захід).
- **Спостерігач на щоглі** говорить у *відносних* координатах: відстань уперед і одне зі значень `ahead`, `starboard`, `behind`, `port`. Відносні азимути відмірюються від *поточного курсу корабля*. Капітан оголошує цей курс на містку перед кожною вахтою.

Наше завдання - перетворити всі три подання на спільну декартову систему `(x, y)`, щоб можна було побудувати карту. Азимути вимірюються в градусах; `(0, 1)` - це одна морська миля на північ, `(1, 0)` - одна морська миля на схід.

## 1. Модель даних і перехід від сторін світу до декартових координат

Спершу окресліть частини, які використовує вся вправа:

- Визначте три кортежі: `cardinal` (одне поле, `direction`), `polar` (поля `magnitude` і `bearing`) і `relative` (поля `distance` і `bearing`).
- Оголосіть символи напрямків за допомогою `SYMBOLS:`: `north`, `east`, `south`, `west`, `ahead`, `starboard`, `behind`, `port`.
- Оголосіть динамічну змінну `heading` за допомогою `SYMBOL:` (її використаємо в завданні 3).
- Оголосіть два узагальнені слова: `GENERIC: >cartesian ( direction -- x y )` і `GENERIC: flip ( direction -- direction' )`. Їхні методи ми додамо в наступних завданнях.

Потім додайте метод `M: cardinal` до `>cartesian`, що повертає одиничний вектор для вказаного напрямку.

```factor
T{ cardinal { direction north } } >cartesian . .
! => 1
! => 0
! (top of stack is `y`, just below it is `x`)
```

## 2. Перехід від полярних координат до декартових

Додайте метод `M: polar` до `>cartesian`, який перетворює полярну форму на `(x, y)`:

```
x = magnitude * sin(bearing-in-radians)
y = magnitude * cos(bearing-in-radians)
```

```factor
T{ polar { magnitude 10 } { bearing 90 } } >cartesian . .
! => 0   (close to zero — the cosine of π/2 isn't exactly 0 in floats)
! => 10
```

## 3. Перехід від відносних координат до декартових

Додайте метод `M: relative` до `>cartesian`. Ось у чому складність: відносний азимут відмірюється від *поточного курсу* корабля, який не входить до кортежу. Прочитайте змінну `heading` (оголошену в завданні 1) за допомогою `heading get`, додайте зсув азимута (`ahead = 0`, `starboard = 90`, `behind = 180`, `port = 270`) і отримайте декартову точку. Той, хто викликає, задає `heading` усередині блоку `with-variable`.

```factor
0 heading [
    T{ relative { distance 5 } { bearing starboard } } >cartesian
] with-variable . .
! => 0   (heading 0 is north; starboard is east; (5, 0))
! => 5
```

## 4. Перевертання

Додайте методи узагальненого слова `flip` (оголошеного в завданні 1), щоб воно повертало протилежний напрямок.

- Для `cardinal`: north ↔ south, east ↔ west.
- Для `polar`: додайте 180° до азимута (остача від ділення на 360).
- Для `relative`: ahead ↔ behind, starboard ↔ port.

```factor
T{ cardinal { direction north } } flip .
! => T{ cardinal { direction south } }

T{ polar { magnitude 10 } { bearing 90 } } flip .
! => T{ polar { magnitude 10 } { bearing 270 } }

T{ relative { distance 5 } { bearing ahead } } flip .
! => T{ relative { distance 5 } { bearing behind } }
```

## 5. Додавання азимутів

Визначте `add-bearings ( a b -- x y )`, який перетворює обидва напрямки на декартові координати й повертає їхню суму. Він працює з будь-яким поєднанням `cardinal`, `polar` і `relative`. Ось у чому виграш від використання узагальненого слова для `>cartesian`.

```factor
T{ cardinal { direction north } } T{ cardinal { direction east } } add-bearings . .
! => 1
! => 1
```
