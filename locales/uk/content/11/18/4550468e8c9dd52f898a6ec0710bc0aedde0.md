# Інструкції

HTTP-ендпоінти стають кращими, коли є перевірка типів. Якщо додати тип Record до POST-запиту, це гарантує, що щоразу надсилатимуться правильні дані.

## Цілі

- Змініть наданий код.
- Додайте до цього запису потрібні атрибути, щоб він приймав два операнди й оператор.
- Додайте функцію HTTP-ресурсу, яка прийматиме POST-запит за шляхом '/calc'
- Функція повинна приймати тип запису Calculation як корисне навантаження й повертати узагальнений JSON-обʼєкт

### Приймає

```json
{ "operand1": 4, "operand2": 10.2, "operator": "+" }
```

### Повертає

```json
{ "expression": "4+10.2", "result": 14.2 }
```
