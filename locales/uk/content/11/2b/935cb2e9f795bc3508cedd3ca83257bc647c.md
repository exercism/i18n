# Підказки

## 1. Визначити функцію для перевірки, чи список мов порожній

- Один із [методів][list] типу List можна використати, щоб перевірити, чи він порожній.

## 2. Визначити функцію для додавання мови до списку

- Один із [методів][list] типу List можна використати, щоб додавати елементи.
- Нагадування: методи, які повертають `void`, не потребують інструкцій `return`.

## 3. Визначити функцію для видалення мови зі списку

- Один із [методів][list] типу List можна використати, щоб видаляти елементи.
- Нагадування: методи, які повертають `void`, не потребують інструкцій `return`.

## 4. Визначити функцію, яка повертає перший елемент списку

- Один із [методів][list] типу List можна використати, щоб отримати елементи за певним індексом.

## 5. Визначити функцію, яка повертає кількість мов у списку

- Один із [методів][list] типу List можна використати, щоб отримати розмір списку.

## 6. Визначити функцію, яка визначає, чи є мова у списку

- Один із [методів][list] типу List можна використати, щоб перевірити, чи міститься елемент у списку.

## 7. Визначити функцію, яка визначає, чи список захопливий

- Спробуйте використати метод, уже визначений у класі.
