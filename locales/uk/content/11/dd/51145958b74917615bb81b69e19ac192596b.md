# Вкладені функції

Функції можна визначати [всередині інших функцій][nested-functions].
Це часто використовують, щоб створювати допоміжні функції, які потрібні лише тій функції, що їх містить, а отже, не засмічують зовнішній простір імен.

Ці функції визначають і викликають так само, як звичайні функції, але поза функцією, що їх містить, вони невидимі.

```swift
func makeNumber(_ number: Int) -> Int {
  func double(_ x: Int) -> Int { 2 * x }
  func add(_ x: Int) -> Int { x + 1 }

  return number.isMultiple(of: 2) ? add(double(number)) : double(number)
}

makeNumber(3)
// Returns 6
makeNumber(4)
// Returns 9
```

[nested-functions]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/functions/#Nested-Functions
