# Інструкції

Ми ведемо невеличкий метеопост на березі Влтави в Празі, і щозміни занотовуємо показники температури до простого текстового журналу: один показник на рядок. Пʼять невеличких слів дають раду всьому обліку за одну зміну.

Кожне слово приймає шлях до файлу журналу.

## 1. Прочитайте всі показники

Визначте `read-readings` так, щоб вона повертала всі показники з журналу як масив рядків тексту (англ. string), по одному в рядку.

```factor
"weather.log" read-readings .
! => { "21.5" "19.0" "22.3" }
```

## 2. Знайдіть останній показник

Визначте `latest-reading` так, щоб вона повертала найновіший показник, тобто останній рядок журналу.

```factor
"weather.log" latest-reading .
! => "22.3"
```

## 3. Прочитайте необроблений журнал

Визначте `log-text` так, щоб вона повертала весь файл журналу як один рядок тексту, точно в тому вигляді, у якому його збережено.

```factor
"weather.log" log-text .
! => "21.5\n19.0\n22.3\n"
```

## 4. Запишіть показник

Визначте `record-reading` так, щоб вона додавала новий показник у кінець журналу окремим рядком, не змінюючи попередніх показників. Нічого не повертає.

```factor
"23.1" "weather.log" record-reading
"weather.log" log-text .
! => "21.5\n19.0\n22.3\n23.1\n"
```

## 5. Перезапишіть журнал

Визначте `rewrite-log` так, щоб вона замінювала весь журнал новим масивом показників, по одному в рядку.

```factor
{ "10.0" "11.0" } "weather.log" rewrite-log
"weather.log" log-text .
! => "10.0\n11.0\n"
```
