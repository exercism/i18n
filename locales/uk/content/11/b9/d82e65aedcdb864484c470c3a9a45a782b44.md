# Інструкції

Ендрю, розробник у своїй компанії, нещодавно створив легкий генератор SQL-запитів для інструменту міграції баз даних.
Його перша наївна реалізація чудово працювала з невеликими наборами даних.
Однак під час масштабних міграцій у продакшені застосунок почав споживати надто багато памʼяті й не витримував великого навантаження.
Профілюючи застосунок, Ендрю зрозумів, що звичайна конкатенація рядків тексту (англ. string) усередині циклів змушувала Go постійно перевиділяти памʼять.
Тепер йому потрібна наша допомога, щоб переробити утиліту з використанням `strings.Builder` із Go, аби застосунок добре масштабувався й обробляв великі обсяги тексту, не переповнюючи купу памʼяті.

## 1. Генерація запитів SELECT

Реалізуйте функцію `BuildSelectQuery`.
Вона приймає назву таблиці (`string`) і слайс назв колонок (`[]string`).
Вона має повертати повністю сформований SQL-запит `SELECT`, що закінчується крапкою з комою.
Якщо слайс колонок порожній або дорівнює `nil`, запит має використати символ підстановки `*`, щоб вибрати всі колонки.

```go
columns := []string{"id", "name", "email"}
BuildSelectQuery("users", columns)
// Function return: "SELECT id, name, email FROM users;"

BuildSelectQuery("orders", nil)
// Function return: "SELECT * FROM orders;"
```

## 2. Генерація пакетних запитів INSERT

Реалізуйте функцію `BuildBatchInserts`.
Вона приймає назву таблиці (`string`) і двовимірний слайс, що представляє рядки бази даних (`[][]ColumnValue`).
Кожен елемент у рядку повʼязує назву конкретної колонки з її значенням у вигляді рядка тексту.
Функція має повернути слайс окремих рядків тексту з SQL-записами `INSERT`.
Структурований формат слайса гарантує передбачуваний і стабільний порядок запитів на виході.
Якщо вхідний слайс рядків порожній, поверніть порожній слайс рядків тексту.
Якщо якийсь окремий рядок порожній, пропустіть його.
Значення рядків тексту в конструкції `VALUES` потрібно брати в одинарні лапки `'`.

```go
rows := [][]ColumnValue{
    {
        {Column: "title", Value: "Book"},
        {Column: "price", Value: "100"},
    },
    {
        {Column: "title", Value: "Magazine"},
        {Column: "price", Value: "15"},
    },
}

BuildBatchInserts("products", rows)
// Function returns string slice: [
//   "INSERT INTO products (title, price) VALUES ('Book', '100');",
//   "INSERT INTO products (title, price) VALUES ('Magazine', '15');"
// ]
```
