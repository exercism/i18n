## Інструкції

Нас найняв центр переробки.
Через брак місця всі продукти кладуть на один конвеєр, але через це різні матеріали змішуються між собою й стають непридатними.
Щоб це виправити, нам доручили створити функції, які визначають тип продукту.

### 1. Перевірити, чи значення є булевим

Реалізуйте функцію `isBoolean`, яка перевіряє, чи є значення булевим (англ. Boolean).

```javascript
isBoolean(true);
// => true

isBoolean(null);
// => false
```

### 2. Перевірити, чи значення є числом.

Реалізуйте функцію `isNumber`, яка перевіряє, чи є значення _скінченним_ `number` або `bigint`, тобто не `NaN` і не `Infinity`.

Іноді пристрій для зчитування ідентифікаторів дає збій і зчитує нечислове значення як `NaN` (не число) або `Infinity`.
Наша функція також повинна правильно це обробляти.

```javascript
isNumber(42);
// => true

isNumber('Hello, World!');
// => false

isNumber(42n);
// => true

isNumber(NaN);
// => false
```

### 3. Перевірити, чи значення є обʼєктом

Реалізуйте функцію `isObject`, яка повинна перевіряти, чи є значення обʼєктом.
На конвеєрі `null` не означає нічого, і його не вважають обʼєктом.

```javascript
isObject({ greeting: 'Hello' });
// => true

isObject(25n);
// => false
```

### 4. Перевірити, чи рядок тексту є числовим

Реалізуйте функцію `isNumericString`, яка повинна перевіряти, чи є значення рядком тексту (англ. string), що складається лише з цифр або з мінуса й цифр після нього, які позначають відʼємне число.
Розглядаємо лише цілі числа: десяткові числа не вважаються числовими для цієї перевірки робота-переробника.

```javascript
isNumericString(42);
// => false

isNumericString('42');
// => true

isNumericString('Hi!');
// => false
```

### 5. Перевірити, чи обʼєкт є електронним

Реалізуйте функцію `isElectronic`, яка перевіряє, чи є обʼєкт екземпляром наданого класу `ElectronicDevice` або одного з його дочірніх класів.

```javascript
class Duck {
  //...
}

class WashingMachine extends ElectronicDevice {
  //...
}

isElectronic(new Duck());
// => false

isElectronic(new WashingMachine());
// => true
```

### 6. Перевірити, чи значення є непорожнім масивом

Реалізуйте функцію `isNonEmptyArray`, яка перевіряє, чи є значення непорожнім масивом.

```javascript
isNonEmptyArray([1, 2, 3]);
// => true

isNonEmptyArray([]);
// => false
```

### 7. Перевірити, чи значення є порожнім масивом

Реалізуйте функцію `isEmptyArray`, яка перевіряє, чи є значення порожнім масивом.

```javascript
isEmptyArray([1, 2, 3]);
// => false

isEmptyArray([]);
// => true
```

### 8. Перевірити, чи має обʼєкт властивість або метод `type`

Реалізуйте функцію `hasType`, яка перевіряє, чи має обʼєкт властивість або метод `type`.

```javascript
class Keyboard(){
  type(){
    // ...
  }
}
hasType({ type:"car", color:"red" })
// => true

hasType({ color:"green" })
// => false

hasType(new Keyboard())
// => true
```

### 9. Викинути помилку, якщо обʼєкт не має властивості або методу `id`

Реалізуйте функцію `assertHasId`, яка викине `Error`, якщо в обʼєкта немає властивості `id`.

Якщо ж обʼєкт має властивість `id`, функція не повинна нічого повертати.

```javascript
assertHasId({ id: 42, color: 'red' });
// => undefined

assertHasId({ color: 'green' });
// Error: "Object is missing the 'id' property"
```

### 10. Перевірити, чи має обʼєкт властивість `id`

Реалізуйте функцію `hasIdProperty`, яка перевіряє, чи має обʼєкт властивість `id`.

```javascript
class SimpleData {
  constructor() {
    this.number = '42';
    this.id = 'BC269327FE1D9B95';
  }
}

class StealingData extends SimpleData {}

class MethodData {
  constructor() {
    this.number = '42';
    this._id = 'BC269327FE1D9B95';
  }

  get id() {
    return this._id;
  }
}

hasIdProperty(new SimpleData());
// => true

hasIdProperty(new MethodData());
// => false

hasIdProperty(new StealingData());
// => false
```

### 11. Перевірити, чи має обʼєкт визначену властивість `type`

Реалізуйте функцію `hasDefinedType`, яка перевіряє, чи має обʼєкт властивість `type`, що не дорівнює `undefined`.

```javascript
hasDefinedType({ type: undefined, color: 'red' });
// => false

hasDefinedType({ type: 'car', color: 'green' });
// => true
```
