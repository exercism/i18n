# Вступ

Тип `enum` у C# представляє фіксований набір іменованих констант (перелік). Його головна мета - забезпечити типобезпечний спосіб роботи з числовими константами, обмежуючи доступні значення заздалегідь визначеним набором. Простий enum можна визначити так:

```csharp
enum Season
{
    Spring,
    Summer,
    Autumn,
    Winter
}
```

Якщо не визначити їх явно, членам enum автоматично присвоюються цілі значення, що збільшуються на одиницю, а перше значення дорівнює нулю. Також можна явно присвоїти значення:

```csharp
enum Answer
{
    Maybe = 1,
    Yes = 3,
    No = 5
}
```
