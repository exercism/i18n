# Докладніше

`TUPLE:` оголошує клас з іменованими слотами. Factor автоматично генерує слово-конструктор (до назви класу додається суфікс `new`), конструктор `boa` («за порядком аргументів»), синтаксис літерала `T{ class … }` і слова-аксесори для кожного слота.

```factor
TUPLE: player
    { name initial: f }
    { level initial: 0 }
    { health initial: 100 } ;

player new .                                    ! T{ player }
3 100 "Merlin" player boa .                     ! by-order construction
T{ player { name "Merlin" } { health 50 } } .   ! literal syntax
```

Система аксесорів у [`accessors`][accessors] надає по чотири варіанти на кожен слот: `name>>`, `>>name`, `change-name` і мутаційну пару `[ … ] change-name`. `>>name` і `change-name` змінюють кортеж, тож якщо треба залишити оригінал без змін, спочатку викличмо `clone`.

Кортежі підтримують `=` через структурну рівність і під час друку показують значення слотів, відмінні від типових.

[accessors]: https://docs.factorcode.org/content/vocab-accessors.html
