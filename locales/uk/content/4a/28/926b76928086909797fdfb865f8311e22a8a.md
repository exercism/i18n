# Підказки

## Загальне

- Прочитайте про модуль `Enum` в [офіційному посібнику Getting Started][getting-started-enum] або на [elixirschool.com][elixir-school-enum].
- Загляньте в документацію, щоб побачити повний [список функцій модуля `Enum`][enum-functions].

## 1. Відсортуйте товари за ціною

- Існує [вбудована функція][enum-sort-by] для сортування перелічуваних за допомогою функції сортування.

## 2. Знайдіть усі товари без ціни

- Існує [вбудована функція][enum-filter] для фільтрування перелічуваних.

## 3. Оновіть назви товарів

- Існує [вбудована функція][enum-map] для перетворення кожного елемента в перелічуваному.
- Існує [вбудована функція][string-replace], яка може замінити всі входження одного рядка тексту (англ. string) на інший.

## 4. Збільште кількість товару

- Мапи реалізують протокол перелічуваних.
- Функції `Enum` перетворюють мапи на список кортежів `{key, value}`.
- Існують дві різні функції, які можуть перетворити список кортежів `{key, value}` назад на мапу за допомогою функції перетворення. [Одна з них завжди повертає нову мапу][map-new], а [інша дозволяє вибрати колекцію][enum-into].

## 5. Обчисліть загальну кількість товару

- Мапи реалізують протокол перелічуваних.
- Функції `Enum` перетворюють мапи на список кортежів `{key, value}`.
- Існує [вбудована функція][enum-reduce] для зведення перелічуваного до одного значення.
