# Про `Time`

[`Time`][time] у Go - це тип, що описує момент часу.
До інформації про дату й час можна отримати доступ, порівняти її та змінити за допомогою методів цього типу, але є також функції, що належать самому пакету `time`.
Поточну дату й час можна отримати за допомогою функції [`time.Now`][now].

Функція [`time.Parse`][parse] перетворює рядки тексту (англ. string) на значення типу `Time`.
У Go є особливий спосіб задавати формат, за яким потрібно розібрати рядок.
Потрібно написати приклад формату, використовуючи значення з цієї спеціальної позначки часу:
`Mon Jan 2 15:04:05 -0700 MST 2006`.

Наприклад:

```go
import "time"

func parseTime() time.Time {
    date := "Tue, 09/22/1995, 13:00"
    layout := "Mon, 01/02/2006, 15:04"

    t, err := time.Parse(layout,date) // time.Time, error
}

// => 1995-09-22 13:00:00 +0000 UTC
```

Метод [`Time.Format()`][format] повертає рядок тексту, що представляє час.
Як і у функції `Parse`, цільовий формат знову задають через приклад, який використовує значення зі спеціальної позначки часу.

Наприклад:

```go
import (
    "fmt"
    "time"
)

func main() {
    t := time.Date(1995,time.September,22,13,0,0,0,time.UTC)
    formattedTime := t.Format("Mon, 01/02/2006, 15:04") // string
    fmt.Println(formattedTime)
}

// => Fri, 09/22/1995, 13:00
```

## Параметри формату

Щоб задати власний формат, можна поєднати ці параметри.
У Go також є наперед визначені [константи формату][const] дати й позначки часу.

| Час            | Параметри                                          |
| -------------- | -------------------------------------------------- |
| Рік            | 2006 ; 06                                          |
| Місяць         | Jan ; January ; 01 ; 1                             |
| День           | 02 ; 2 ; \_2 (для провідного нуля)                 |
| День тижня     | Mon ; Monday                                       |
| Година         | 15 (24-годинний формат часу) ; 3 ; 03 (AM або PM)  |
| Хвилина        | 04 ; 4                                             |
| Секунда        | 05 ; 5                                             |
| Позначка AM/PM | PM                                                 |
| День року      | 002 ; \_\_2                                        |

Тип `time.Time` має різні методи для доступу до конкретних частин часу. Наприклад: годину повертає [`Time.Hour()`][hour], а місяць - [`Time.Month()`][month].
Докладніше про те, як це працює, можна прочитати в [офіційній документації][time].

Пакет [`time`][time] містить також тип [`Duration`][duration], який представляє час, що минув, а також підтримку часових поясів, таймерів та іншої повʼязаної функціональності, яку розглянемо в іншій концепції.
