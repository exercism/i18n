# Вступ

## Розрізнювані обʼєднання

Тип «розрізнюване обʼєднання» представляє фіксовану кількість іменованих варіантів. Кожне значення розрізнюваного обʼєднання відповідає рівно одному з іменованих варіантів.

Розрізнюване обʼєднання визначають за допомогою ключового слова `type`, а його варіанти розділяють символами вертикальної риски (`|`):

```fsharp
type Season =
    | Spring
    | Summer
    | Autumn
    | Winter
```

Кожен варіант розрізнюваного обʼєднання може необовʼязково мати повʼязані з ним дані, і різні варіанти можуть мати різні типи даних. Якщо з жодним із варіантів не повʼязано даних, розрізнюване обʼєднання подібне до того, що в інших мовах зазвичай називають _переліком_ (або _enum_).

```fsharp
type Number =
    | Integer of int
    | Float of float
    | Invalid
```

Створити значення для конкретного варіанта можна, звернувшись до його назви (наприклад, `Success`). Оскільки назви варіантів - це просто функції-конструктори, повʼязані дані можна передати як звичайний аргумент функції. Якщо в іншому розрізнюваному обʼєднанні визначено варіант із такою самою назвою, доведеться використати його повну назву (наприклад, `Result.Success`).

```fsharp
let byName = Integer 2
let byFullName = Number.Invalid
```

Розрізнювані обʼєднання мають _структурну рівність_, тобто два значення одного й того самого варіанта з однаковими (необовʼязковими) даними є рівнозначними.

Хоча для роботи з розрізнюваними обʼєднаннями можна використовувати вирази `if/elif/else`, рекомендований спосіб роботи з ними - це зіставлення зі зразком за допомогою _зразка-ідентифікатора_:

```fsharp
let describe number =
    match number with
    | Integer i -> sprintf "Integer: %d" i
    | Float d  -> sprintf "Float: %f" d
    | Invalid   -> "Invalid"
```
