# Вступ

Функції типово мають зовнішнє звʼязування, тож їх можна викликати з будь-якого іншого файлу проєкту.
Докладніше про звʼязування йдеться в [концепції звʼязування](../linkage/introduction.md#Introduction).
Функцію `static` можна викликати лише в межах вихідного файлу, де її визначено.

Наприклад

```c
// file scope, internal linkage
// can only be called from within this file
static void some_function()
{
    // code snipped
}

// file scope, external linkage by default
// can be called from any other file in the project
int main()
{
    // code snipped
}
```
