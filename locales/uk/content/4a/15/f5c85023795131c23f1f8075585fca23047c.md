# Про

Багато операторів також можна використовувати як [складені присвоєння][compound-assignment], тобто скорочений запис, у якому `x = op y` можна записати як `x op= y`:

```csharp
var features = PhoneFeatures.Call;
features |= PhoneFeatures.Text;
features &= ~PhoneFeatures.Call;
```
