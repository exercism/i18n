# Вступ

## Імпортування

Хоча Swift включає багато функціональності у свою стандартну бібліотеку, значно більше функціональності доступно у вигляді зовнішніх бібліотек.
Ці бібліотеки можуть бути від самого проєкту Swift, як-от [Swift Argument Parser][argument-parser], закриті бібліотеки від компаній, як-от [Network Framework][network-framework] від Apple, або сторонні бібліотеки, як [Swifty Beaver][swifty-beaver].

Деякі з цих модулів, як-от Network Framework або [Foundation][apple-foundation] (мабуть, найуживаніша бібліотека у Swift), входять до складу дистрибутива Swift.
Зовнішні сторонні бібліотеки потрібно додати до проєкту, перш ніж їх можна буде імпортувати, хоча це виходить за межі цієї вправи.

Імпортування модулів відбувається так: пишемо ключове слово `import`, а потім назву модуля. Тож щоб імпортувати Foundation, достатньо додати до своєї програми таке.

```swift
import Foundation
```

Це відкриває доступ до всіх типів, значень і функціональності всередині цього модуля; наприклад, якщо потрібно скористатися методом `components(separatedBy:)` типу String, із цим імпортом цей метод стає доступним для `String`.

Хоча їх можна розмістити в коді будь-де перед фрагментом, який використовує якийсь вміст модуля, інструкції import зазвичай ставлять на початку файлу, який ними користується, щоб код було легше читати.

## Індексування рядків

Окремі символи в `String` можна отримати тим самим способом індексування, який використовують для масивів.
Однак [індекси][string-indices], які використовують для рядків тексту, _не_ є цілими числами, і працювати з ними безпосередньо не можна.
Замість цього їх потрібно обчислити на основі якогось іншого відомого індексу, наприклад `startIndex`, який указує на позицію першого символу в непорожньому рядку тексту, скориставшись методами, доступними в бібліотеках [`String`][string-docs] та [`NSString`][nsstring-docs] (коли модуль `Foundation` імпортовано, рядки тексту у Swift мають доступ до всіх властивостей і методів NSString).

Наприклад, маємо такий рядок тексту:

```swift
let csv = "apple,pear,peach,orange,cherry,lime,goosberry"
```

Не можна написати `csv[21]`, щоб отримати "g" в "orange": замість цього потрібно обчислити значення типу `String.Index` і передати саме його.
Зауважмо, що ці індекси не призначені для безпосереднього сприйняття людиною.
Їх називають _непрозорими індексами_, бо людині не потрібно знати, що всередині них.

```swift
let index = csv.index(csv.startIndex, offsetBy: 21)
csv[index]
// "g"
print(index)
// prints Index(_rawBits: 1376513)
```

Проте зауважмо: якщо зсув не відповідає дійсному індексу, тобто якщо він указує на позицію перед `startIndex` або після `endIndex`, операція спричинить помилку й аварійно завершить програму.
Щоб запобігти цій проблемі, можна вказати обмежувальний індекс.
Тоді операція повертає необовʼязковий індекс і поверне nil для індексів, які інакше були б недійсними.

```swift
let tooFar = csv.index(csv.startIndex, offsetBy: 200)
// error: Execution was interrupted, reason: EXC_BAD_INSTRUCTION (code=EXC_I386_INVOP, subcode=0x0).
let tooFarButSafe = csv.index(csv.startIndex, offsetBy: 200, limitedBy: csv.endIndex)
// nil
```

Крім того, індекси не можна використовувати для різних рядків тексту.
Наприклад, якщо скористатися обчисленим вище `index` для "g" в "orange", щоб проіндексувати рядок `fam = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶, this is our cat: 🐱!"`, тобто `fam[index]`, програма аварійно завершиться.

Для всього цього є багато причин, але всі вони зводяться до того, що «з Unicode усе непросто».

Загалом, якщо потрібен довільний доступ до окремих символів, імовірно, варто використати якусь іншу структуру даних, як-от `Array<Character>`.

### Деякі корисні методи

У Swift є методи `first` і `last`, щоб отримати перший і останній символ рядка тексту.
Ці методи повертають необовʼязковий символ, тож якщо рядок тексту порожній, вони повернуть nil.

```swift
let str = "Hello, world!"
print(str.first) // Prints Optional("H")
print(str.last)  // Prints Optional("!")
```

Також можна скористатися методами `prefix` і `suffix`, щоб отримати підрядок рядка тексту.
Ці методи приймають ціле число як аргумент і повертають підрядок, що містить перші або останні n символів рядка тексту.

```swift
let str = "Hello, world!"
print(str.prefix(5)) // Prints "Hello"
print(str.suffix(6)) // Prints "world!"
```

## Методи рядків

Робота з рядками тексту трапляється в програмуванні часто.
Тому Swift надає різноманітні методи для роботи з рядками тексту.
У цьому документі ми розглянемо деякі з найпоширеніших методів і властивостей для рядків тексту; деякі з них вимагають імпорту фреймворку Foundation.

### [`components(separatedBy:)`][components]

Коли потрібно розбити рядок тексту на масив підрядків, можна скористатися методом `components(separatedBy:)`.
Скажімо, потрібно отримати кожне слово в реченні, тоді можна використати символ пробілу як розділювач.

```swift
let sentence = "Hello, world!"
let words = sentence.components(separatedBy: " ")
print(words) // Prints ["Hello,", "world!"]
```

### [`hasPrefix(_:)`][hasPrefix], [`hasSuffix(_:)`][hasSuffix]

Коли потрібно перевірити, чи рядок тексту починається або закінчується певним підрядком, можна скористатися методами `hasPrefix(_:)` і `hasSuffix(_:)`.
Обидва ці методи приймають рядок тексту як аргумент і повертають булеве значення (англ. Boolean), яке вказує, чи починається або закінчується рядок тексту вказаним підрядком.

```swift
let greeting = "Hello, world!"
print(greeting.hasPrefix("Hello"))  // Prints true
print(greeting.hasSuffix("world!")) // Prints true
```

### [`lowercased`][lowercased], [`uppercased`][uppercased], [`capitalized`][capitalized]

Коли потрібно змінити регістр рядка тексту, можна скористатися властивостями `lowercased`, `uppercased` і `capitalized`.
Властивість `lowercased` повертає новий рядок тексту, у якому всі символи записані в нижньому регістрі, властивість `uppercased` повертає новий рядок тексту з усіма символами у верхньому регістрі, а властивість `capitalized` повертає новий рядок тексту, у якому перший символ кожного слова записано з великої літери.

```swift
let greeting = "hello, world!"
print(greeting.lowercased)  // Prints "hello, world!"
print(greeting.uppercased)  // Prints "HELLO, WORLD!"
print(greeting.capitalized) // Prints "Hello, World!"
```

### [`replacingOccurrences(of:with:)`][replacingOccurrences]

Коли потрібно замінити всі входження підрядка в рядку тексту на інший підрядок, можна скористатися методом `replacingOccurrences(of:with:)`.
Цей метод приймає два рядки тексту як аргументи: підрядок, який потрібно замінити, і підрядок, яким його замінюють. Він повертає новий рядок тексту, у якому всі входження вказаного підрядка замінено.

```swift
let greeting = "Hello, world!"
let newGreeting = greeting.replacingOccurrences(of: "world", with: "Swift")
print(newGreeting) // Prints "Hello, Swift!"
```

### [`joined(separator:)`][joined]

Це метод не типу String, а типу Array.
Коли потрібно поєднати масив рядків тексту в один рядок тексту із заданим розділювачем, можна скористатися методом `joined(separator:)`.
Цей метод приймає рядок тексту як аргумент і повертає новий рядок тексту, у якому всі елементи масиву поєднано й розділено вказаним рядком тексту.

```swift
let words = ["Hello", "world"]
let sentence = words.joined(separator: ", ")
print(sentence) // Prints "Hello, world"
```
