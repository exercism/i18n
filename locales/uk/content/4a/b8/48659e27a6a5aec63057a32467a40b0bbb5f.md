# Доповнення до інструкцій

## Регістри

| Регістр | Використання | Тип                            | Опис                                                    |
| ------- | ------------ | ------------------------------ | ------------------------------------------------------- |
| `$a0`   | вхідні дані  | адреса                         | вхідний рядок тексту (англ. string), що завершується нульовим символом |
| `$v0`   | вихідні дані | булеве значення (англ. Boolean) | чи дійсний ISBN (`0` = `false`, `1` = `true`)           |
| `$t0-9` | тимчасовий   | будь-який                      | використовується для тимчасового зберігання             |
