# Докладніше

Рядок тексту (англ. string) у F# - це незмінний обʼєкт, який подає текст як послідовність символів Unicode (літер, цифр, розділових знаків тощо). Для визначення екземпляра `string` використовують подвійні лапки:

```fsharp
let fruit = "Apple"
```

Керувати рядком тексту можна, викликавши один з його [методів][methods] чи [властивостей][properties], або скориставшись однією з функцій [модуля `String`][string-module]. Оскільки значення рядка тексту ніколи не змінюються після визначення, всі методи й функції для роботи з рядками тексту повертають новий рядок тексту.

Рядок тексту обмежують подвійні лапки (`"`). Деякі спеціальні символи потрібно [екранувати][escaping] за допомогою зворотної скісної риски (`\`). Рядок тексту можна також почати із символу «ет» (`@`), і тоді він стане [дослівним рядком][verbatim], який ігнорує будь-які символи екранування.

```fsharp
let escaped = "c:\\test.txt"
let verbatim = @"c:\test.txt"
escaped = verbatim
// => true
```

Крім того, рядок тексту можна визначити за допомогою [потрійних лапок][triple-quoted] (`"""`), що дозволяє використати подвійну лапку всередині рядка без екранування.

```fsharp
let tripledQuoted = """<movie title="Se7en" />"""
// => "<movie title="Se7en" />
```

І нарешті, зʼєднати рядки тексту можна за допомогою [оператора `+`][plus-operator]:

```fsharp
let name = "Jane"
"Hello " + name + "!"
// => "Hello Jane!"
```
