# Тести

## Запуск тестів

Щоб запустити тести, виконайте таку команду:

```bash
bats test-<exercise-slug>.bats
```

### bats реалізовано мовою bash

Файл bats - це скрипт bash із кількома спеціальними функціями, які розпізнає команда `bats`.
Ми побачимо кілька тестів, які мають такий вигляд:

```bash
sed -E -f <exercise-slug>.sed <<< "$input"
```

Синтаксис `<<<` - це bash *Here String*.
Він надсилає рядок з правого боку до стандартного вводу програми з лівого боку.
Це приблизно те саме, що й

```bash
echo "$input" | sed -E -f <exercise-slug>.sed
```

## Пропущені тести

Розвʼязати вправу означає зробити так, щоб усі її тести проходили.
Типово, коли ми запускаємо тести, виконується лише один тест (перший).
Це зроблено навмисно, щоб ми могли зосередитися лише на тому, щоб цей один тест пройшов.
Коли він пройде, ми можемо увімкнути наступний тест, закоментувавши або видаливши

    [[ $BATS_RUN_SKIPPED == true ]] || skip

анотації, які стоять перед іншими тестами.

## Обхід пропусків

Щоб запустити всі тести, зокрема ті, що мають анотації `skip`, виконайте:

```bash
BATS_RUN_SKIPPED=true bats test-<exercise-slug>.bats
```

або закоментуйте чи видаліть рядок:

```bash
[[ $BATS_RUN_SKIPPED == "true" ]] || skip
```

з файлу тестів.
