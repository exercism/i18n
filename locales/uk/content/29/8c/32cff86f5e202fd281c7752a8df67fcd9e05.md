# Класи

Класи - це одиниця організації коду в PHP.
Код, який описує поведінку якогось предмета або перебіг якогось процесу, можна згрупувати в клас.
Функції, закріплені за класом, за традицією називають `methods`.

```php
<?php

class Door
{
    function lock()
    {
        // ...
    }

    function unlock()
    {
        // ...
    }
}
```

Екземпляр класу створюють за допомогою ключового слова `new`: воно виділяє памʼять для екземпляра класу та викликає метод-конструктор цього класу.
Створений екземпляр класу можна присвоїти змінній.
Щоб викликати методи екземпляра класу, можна скористатися оператором доступу `->`.

```php
<?php

$a_door = new Door();
$a_door->lock();
$a_door->unlock();
```

Екземпляр класу може посилатися на самого себе через спеціальну змінну `$this`.
Класи також можуть мати властивості: вони поводяться як змінні, привʼязані до екземпляра обʼєкта класу.
До цих властивостей можна звертатися як зсередини, так і ззовні.

```php
<?php

class Car
{
    public $color;

    function __construct($color)
    {
        $this->color = $color;
    }

    function getColor()
    {
        return $this->color;
    }
}

$a_car = new Car("red");
$a_car->color; // => "red" by accessing the property
$a_car->getColor(); // => "red" by invoking the instance method
```
