# Вступ

Як і в інших мовах, у C++ є конструкція `switch`.
Конструкція `switch` дає коротший спосіб записати довгі ланцюжки `if ... else if`.
Щоб створити `switch`, спочатку пишемо ключове слово `switch`, після якого вказуємо ціле число.
Далі оголошуємо кожну з умов за допомогою ключового слова `case`.
Також можна оголосити випадок `default`, який виконається, коли жодна з попередніх умов `case` не збігається.
Кожен випадок має завершуватися інструкцією `break` (або `return`).

```cpp
int price{0};
int adults{3};
int kids{2};

switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
        break;
    case 2:
        price = 70;
        break;
    default:
        price = group_size * 30;
}
```

## Провалювання

Одна важлива особливість конструкції `switch` полягає в тому, що код продовжує виконуватися, доки його не зупинить інструкція `break` (або `return`).
Це може призвести до несподіваної поведінки.

```cpp
int adults{1};
int kids{0};
switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
    case 2:
        price = 70;
    default:
        price = group_size * 30;
}
// price will be 30!
```

Здебільшого цю особливість продовження виконання використовують, коли інструкція має кілька міток.
Кілька результатів `switch` можуть вказувати на той самий фрагмент коду, який потрібно виконати.
Так, наприклад, у застосунку для бронювання та сама функція може обслуговувати розміри групи 2 та 3:

```cpp
switch (group_size) {
case 1:
    book_room();
    break;
case 2:
case 3:
    book_apartment(group_size);
    break;
default:
    book_house(group_size);
}
// book_apartment happens when group_size is 2 or 3
```
