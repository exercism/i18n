# Інструкції

У цій вправі ми організовуємо гонки між різними типами радіокерованих машинок. Кожна машинка має власну швидкість і власний розряд батареї.

Машинки стартують із повністю зарядженою батареєю (100%). Щоразу, коли ми керуємо машинкою за допомогою пульта дистанційного керування, вона проїжджає відстань, що дорівнює її швидкості в метрах, а відсоток заряду, що залишився, зменшується на величину розряду батареї.

Якщо заряд батареї машинки менший за відсоток її розряду, ми більше не можемо нею керувати.

Кожна траса має власну дистанцію. Машинки перевіряють на те, чи здатні вони подолати трасу, не розрядивши батарею.

На нас чекає шість завдань, і в кожному з них ми працюватимемо з екземплярами радіокерованих машинок.

## 1. Створення радіокерованої машинки

Щоб мати змогу створювати радіокеровану машинку, визначмо конструктор класу `NeedForSpeed`, який приймає два параметри: швидкість машинки в метрах і відсоток розряду батареї (обидва типу `int`):

```java
int speed = 5;
int batteryDrain = 2;
var car = new NeedForSpeed(speed, batteryDrain);
```

## 2. Створення траси

Щоб мати змогу створювати трасу, визначмо конструктор класу `RaceTrack`, який приймає єдиний параметр: дистанцію траси в метрах (типу `int`):

```java
int distance = 800;
var raceTrack = new RaceTrack(distance);
```

## 3. Керування машинкою

Реалізуймо метод `NeedForSpeed.drive()`, який оновлює кількість пройдених метрів відповідно до швидкості машинки. Також реалізуймо метод `NeedForSpeed.distanceDriven()`, який повертає кількість метрів, пройдених машинкою:

```java
int speed = 5;
int batteryDrain = 2;
var car = new NeedForSpeed(speed, batteryDrain);
car.drive();

car.distanceDriven();
// => 5
```

## 4. Перевірка розрядженої батареї

Оновімо метод `NeedForSpeed.drive()`, щоб він зменшував заряд батареї відповідно до її розряду. Також реалізуймо метод `NeedForSpeed.batteryDrained()`, який показує, чи батарея розряджена настільки, що керувати машинкою вже неможливо:

```java
int speed = 5;
int batteryDrain = 2;
var car = new NeedForSpeed(speed, batteryDrain);
car.drive();

car.batteryDrained();
// => false
```

## 5. Створення радіокерованої машинки Nitro

Найпопулярніша радіокерована машинка - це Nitro, у якої приголомшлива максимальна швидкість 50 метрів і розряд батареї 4%. Реалізуймо (статичний) метод `NeedForSpeed.nitro()`, який повертає машинку цього типу:

```java
var car = NeedForSpeed.nitro();
car.drive();
car.distanceDriven();
// => 50
```

## 6. Перевірка, чи здатна радіокерована машинка завершити гонку

Щоб завершити гонку, машинка має бути здатною проїхати дистанцію гонки. Це означає, що її батарея не повинна розрядитися до того, як вона перетне фінішну лінію. Реалізуймо метод `RaceTrack.canFinishRace()`, який приймає екземпляр `NeedForSpeed` як параметр і повертає `true`, якщо машинка здатна завершити гонку, інакше повертає `false`:

```java
int speed = 5;
int batteryDrain = 2;
var car = new NeedForSpeed(speed, batteryDrain);

int distance1 = 100;
var race1 = new RaceTrack(distance1);

int distance2 = 300;
var race2 = new RaceTrack(distance2);

race1.canFinishRace(car);
// => true

race2.canFinishRace(car);
// => false
```
