# Доповнення до інструкцій

## Підказки

Реалізуйте функцію `convert`, яка повертає число, перетворене на звук краплі. Можна використати надану сигнатуру, якщо є сумніви щодо типів, але не дозвольте їй обмежувати творчість:

```haskell
convert :: Int -> String
```

У цій вправі ми працюємо з текстовими даними. З історичних причин тип `String` у Haskell є синонімом `[Char]`, масиву символів. Для ефективнішої роботи з текстовими даними можна використати тип `Text`.

Як необовʼязкове розширення до цієї вправи, можна

- Прочитайте про [типи рядків тексту (англ. string)](https://haskell-lang.org/tutorial/string-types) у Haskell.
- Додайте `- text` до списку залежностей у package.yaml.
- Імпортуйте `Data.Text` [у такий спосіб](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- Тепер можна написати, наприклад, `convert :: Int -> Text` і звертатися до комбінаторів `Data.Text` як, наприклад, `T.pack`.
- Знайдіть документацію для [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html),
- Потім замініть усі входження `String` на `Text` у Raindrops.hs:

```haskell
convert :: Int -> Text
```

Ця частина цілком необовʼязкова.
