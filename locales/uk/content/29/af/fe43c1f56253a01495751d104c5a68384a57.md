# Ітерація

У програмуванні [ітерація][iteration] означає процес багаторазового повторення блоку коду.
Цього можна досягти за допомогою таких концепцій, як цикли `while` та `until`.
Цього також можна досягти за допомогою рекурсії, тобто функції, яка викликає саму себе.

Однак найчастіше ми хочемо перебрати колекцію елементів, як-от `Array`, `Range` або `String`.
І клас `Array`, і клас `Range` у Crystal включають модуль [`Enumerable`][enumerable], який надає низку методів для перебирання елементів.
Водночас клас `String` має власний набір методів для перебирання символів.

Crystal також не має інструкції `for`, як інші мови.
Замість неї є кілька методів, які можна використати для перебирання.

## Перебирання

Найпоширеніший спосіб перебрати колекцію - скористатися методом [`each`][each], який передає кожен елемент колекції у блок.
Це легко зробити з `Range`.
Скажімо, ми хочемо пройтися циклом від 1 до 3, тоді можна скористатися методом `each`, щоб перебрати цей діапазон.

```crystal
(1..3).each do |n|
  puts n
end

# Output:
# 1
# 2
# 3
```

Ще простіше, якщо потрібно перебрати щось певну кількість разів, можна скористатися методом [`times`][times], який існує в класі `Int`.

```crystal
3.times do |n|
  puts n
end

# Output:
# 0
# 1
# 2
```

## Перебирання `String`

`String` - це послідовність символів, і він не належить до модуля `Enumerable`, а отже, має власний набір методів для перебирання символів.
Найпоширеніший спосіб перебрати `String` - скористатися методом [`each_char`][each_char], який передає кожен символ `String` у блок.

~~~~exercism/note
Метод `each_char` передає у блок обʼєкт `Char`, а не обʼєкт `String`.
~~~~

```crystal
str = "hello"
str.each_char { |char| puts char }

# Output:
# h
# e
# l
# l
# o
```

Ще один спосіб перебрати `String` - скористатися методом [`each_line`][each_line].
Цей метод переважно використовують, коли читають файл рядок за рядком.

```crystal
str = "hello\nworld"
str.each_line do |line|
  puts line
end

# Output:
# hello
# world
```

## Перебирання обʼєкта, який включає модуль `Enumerable`

Модуль [`Enumerable`][enumerable] надає низку методів для перебирання елементів колекції.
Колекції, які включають модуль `Enumerable`, - це `Array`, `Range`, `Hash`, `Set` та інші; про решту йтиметься в наступних концепціях.

Найпоширеніший спосіб перебрати `Array` - скористатися методом [`each`][each], який передає кожен елемент `Array` у блок.

```crystal
arr = [5, 2, 3]
arr.each do |element|
  puts element
end

# Output:
# 5
# 2
# 3
```

### Map

Метод [`map`][map] - це ще один спосіб перебрати `Array`; він повертає новий `Array`, що містить результати застосування блоку до кожного елемента.
Він схожий на метод `each`, але повертає новий `Array` з перетвореними елементами.
Перетворення дуже корисне, коли ми хочемо застосувати функцію до кожного елемента колекції, що є поширеною операцією.

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  element * 2
end

new_arr
# => [2, 4, 6]
```

За допомогою керуючої конструкції, як-от `if`, ми можемо фільтрувати, які елементи перетворювати.

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  if element.odd?
    element * 2
  else
    element
  end
end

new_arr
# => [2, 2, 6]
```

### З індексом

Іноді нам потрібно знати індекс елемента, який ми перебираємо; для цього можна скористатися методом [`each_with_index`][each_with_index] або [`map_with_index`][map_with_index].
Він передає кожен елемент та його індекс у блок; метод також приймає необовʼязковий аргумент, щоб указати початковий індекс.

```crystal
arr = [1, 2, 3]
arr.each_with_index(4) do |element, index|
  puts "Element: #{element}, Index: #{index}"
end

# Output:
# Element: 1, Index: 4
# Element: 2, Index: 5
# Element: 3, Index: 6
```

Зауважмо, що метод [`each_char_with_index`][each_char_with_index] також доступний для обʼєктів `String`.

### sum

Метод [`sum`][sum] повертає суму всіх елементів колекції; він також приймає необовʼязковий блок, щоб перетворити елементи перед підсумовуванням.
Він також приймає необовʼязковий аргумент, щоб указати початкове значення суми.

```crystal
arr = [1, 2, 3]
arr.sum
# => 6

arr.sum(2) { |n| n * 2 }
# => 14
```

### reduce

[`reduce`][reduce], або згортка, як його знають в інших мовах, - це метод, який разом із методом поєднання та початковим значенням поєднує всі елементи колекції.
Метод `reduce` має акумулятор, який передається в блок; акумулятор - це результат попередньої ітерації.
Це стає рекурсивним процесом, який поєднає всі елементи колекції.

```crystal
arr = [1, 2, 3]
arr.reduce(0) do |acc, n|
  acc + n
end
# => 6
```

`reduce` може здаватися схожим на `sum`, але `reduce` гнучкіший, бо дає змогу вказати початкове значення акумулятора та метод поєднання.
`reduce` можна використати, щоб реалізувати `sum`, `count` та інші методи.
