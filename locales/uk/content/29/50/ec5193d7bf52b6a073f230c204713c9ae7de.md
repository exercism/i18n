# Звʼязані процедури

Досі ми всюди передавали *значення*: числа, рядки тексту (англ. string), обʼєкти. **Звʼязана процедура** дає змогу передавати саму процедуру: щось таке, що пізніше викличе код, який не знає, що це таке.

Дублер утілює саме цю ідею: помічник режисера має спосіб зіграти роль, не знаючи, хто саме вийде на сцену і як зіграє.

## Як створити звʼязану процедуру

`bind` приймає виклик, у якому є дірки, позначені `_`:

```sather
   shout(line : STR) : STR is return line.upper; end;

   ...

   part ::= bind(shout(_));
```

Тепер `part` нічим не відрізняється від будь-якого іншого значення. Виклик відбувається пізніше:

```sather
   part.call("who's there")      -- "WHO'S THERE"
```

## Тип

Звʼязана процедура має тип `ROUT`, де типи аргументів записані у фігурних дужках, а тип поверненого значення стоїть після двокрапки:

```sather
   part : ROUT{STR}:STR := bind(shout(_));
```

Читаємо `ROUT{STR}:STR` так: «процедура, що приймає `STR` і повертає `STR`».

| Запис | Що означає |
| --- | --- |
| `ROUT{STR}:STR` | приймає `STR`, повертає `STR` |
| `ROUT{INT,INT}:BOOL` | приймає два `INT`, повертає `BOOL` |
| `ROUT{STR}` | приймає `STR`, нічого не повертає |
| `ROUT:INT` | нічого не приймає, повертає `INT` |

Оскільки це тип, він може бути аргументом:

```sather
   rehearse(line : STR, part : ROUT{STR}:STR) : STR is
      return part.call(line);
   end;
```

`rehearse` гадки не має, що робить `part`. У цьому й суть: їй можна передати `shout`, `whisper` або будь-що інше такої форми.

## Як заповнити частину аргументів

Не кожен аргумент має бути діркою. Усе, що виписано явно, фіксується тоді, коли відбувається `bind`:

```sather
   repeat(times : INT, line : STR) : STR is ... end;

   twice ::= bind(repeat(2, _));      -- ROUT{STR}:STR
```

`twice` приймає лише рядок, бо `2` уже визначено. Значення обчислюється в момент звʼязування і зберігається, тож якщо потім змінити змінну, з якої воно взялося, це вже нічого не змінить.

Так одна загальна процедура перетворюється на багато конкретних.

## Як звʼязати й обʼєкт

Для процедури на обʼєкті обʼєкт стоїть першим у виклику, і його можна зафіксувати або залишити діркою:

```sather
   bind(board.home_goal)      -- this board's, always
   bind(_.home_goal)          -- whichever board is handed in later
```
