# Про цикл `for-each`

[Цикл `for-each`](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/for.html) надає механізм виконання блоку коду для кожного елемента колекції.
Деяка документація (наприклад, документація Oracle) називає його розширеним циклом `for`.

Ось загальний синтаксис:

```java
for(declaration: collection) {
    body;
}
```

`declaration` визначає змінну, у якій зберігаються значення, взяті з колекції.

`collection` позначає масив або колекцію зі значеннями, які буде присвоєно змінній циклу.

`body` містить інструкції, які буде виконано по одному разу для кожного значення з колекції.

Наприклад:

```java
char[] vowels = {'a', 'e', 'i', 'o', 'u'};

for(char vowel: vowels) {
    System.out.println(vowel);
}
```

що виводить:

```text
a
e
i
o
u
```

Зазвичай циклу `for-each` варто надавати перевагу перед циклом `for` з таких причин:

- Цикл `for-each` гарантовано перебирає _всі_ значення.
- Цикл `for-each` більш _декларативний_: код повідомляє, _що_ він робить, а не _як_ він це робить.
- Цикл `for-each` не дає змоги помилитися, тоді як у циклі `for` легко припуститися помилки на одиницю (згадаймо `<` проти `<=`).
- Цикл `for-each` працює з усіма типами колекцій, зокрема з тими, які не підтримують доступ до елементів за індексом (наприклад, `Set`).
