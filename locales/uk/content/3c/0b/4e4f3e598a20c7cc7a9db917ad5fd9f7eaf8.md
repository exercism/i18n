# Вступ

Обʼєкти можуть зберігати власний стан, задаючи _змінні екземпляра_, які створюються додаванням `@` перед назвою змінної.

```ruby
@name = 2
```

Зазвичай обʼєкти задають свій початковий стан у методі `initialize`, який автоматично викликається, коли ми викликаємо `new` для класу.

```ruby
class Airplane
  def initialize
    @wings = 2
  end
end
```

Метод `initialize` також може приймати аргументи, тож кожен екземпляр може починати роботу з власним станом:

```ruby
class Suitcase
  def initialize(locked)
    @locked = locked
  end
end
```

Розглядаймо _змінні екземпляра_ як приватні щодо зовнішнього читання й запису. А для отримання й задання змінних екземпляра слід використовувати _методи екземпляра_:

```ruby
class Suitcase
  #...

  def locked? # Query methods should be named with a trailing `?`
    @locked
  end

  def unlock! # Methods which mutate state should have trailing `!`
    @locked = false
  end
end
```
