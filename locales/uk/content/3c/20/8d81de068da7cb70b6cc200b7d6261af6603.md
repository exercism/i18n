# Про це

## Escaping-функції

Буває, що функція вищого порядку приймає іншу функцію як параметр і використовує її так, що передана функція викликається _після_ завершення функції вищого порядку. Це називають escaping функції вищого порядку, а передану функцію називають [escaping-функцією][escaping].

Найчастіше це трапляється в асинхронному коді, але може траплятися і у функціях вищого порядку, коли передану функцію (або функцію, яка її викликає) повертають із функції вищого порядку. Наприклад:

```swift
func emptyKitchen(_ order: String) -> String {
  "Sorry, we're all out of \(order)."
}

func prepare(order: String, kitchen: (String) -> String) -> (String) -> String {
  func newKitchen(_ newOrder: String) -> String {
    if newOrder == order {
      return "One \(order) coming up!"
    } else {
      return kitchen(newOrder)
    }
  }
  return newKitchen
}
```

Тут функція `prepare` приймає функцію у параметрі `kitchen`, а потім створює нову функцію `newKitchen`, яка може викликати `kitchen`. Цю функцію `newKitchen` повертають тому, хто викликав `prepare`. Спроба написати цю функцію мовою Swift призводить до помилки: _Escaping local function captures non-escaping parameter 'kitchen'_

Swift видає помилку в цьому випадку, бо бувають ситуації, коли вкладена або передана функція може захопити значення, що призводить до витоку памʼяті. Те, як саме це відбувається і як запобігти таким витокам, виходить за межі цієї вправи. Однак цю помилку можна залагодити, поставивши атрибут `@escaping` перед сигнатурою типу переданої функції.

```swift
func prepare(order: String, kitchen: @escaping (String) -> String) -> (String) -> String {
  func newKitchen(_ newOrder: String) -> String {
    if newOrder == order {
      return "One \(order) coming up!"
    } else {
      return kitchen(newOrder)
    }
  }
  return newKitchen
}

let restaurant =
  prepare(order: "sandwich",
          kitchen: prepare(order: "chicken",
                           kitchen: prepare(order: "steak",
                                            kitchen: emptyKitchen)))

restaurant("pork chop")
// => "Sorry, we're all out of pork chop."
restaurant("chicken")
// => "One chicken coming up!"
```

Цей атрибут повідомляє компілятору Swift, що автор свідомо робить цю функцію escaping-функцією і усвідомлює, що через це може статися витік памʼяті.

[escaping]: https://docs.swift.org/swift-book/LanguageGuide/Closures.html#ID546
