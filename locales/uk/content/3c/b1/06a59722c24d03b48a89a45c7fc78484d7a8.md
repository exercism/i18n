# Вступ

Вираз `let` створює локальну область видимості і стає в пригоді в кількох ситуаціях:

- Щоб спростити вирази
- Щоб дати назви результатам проміжних виразів
- Щоб розбити вираз на дрібніші частини, якщо він стає завеликим

Усередині виразу `let` можна робити більшість речей, зокрема деструктуризацію (докладніше про це в наступних вправах), але визначити новий Custom Type чи Type Alias не можна.

```elm
let
  cube x = x * x * x
in
  cube a + cube b + cube c
```

```elm
beginWithPattern : Size -> Padding -> Pattern -> GameOfLife
beginWithPattern minimumSize padding pattern =
    let
        size = calculateSize minimumSize padding pattern

        center = Size.center size

        centeredPattern = Pattern.centerAt center pattern

        dimensions = { width = size, height = size }

        deadCells = Matrix.create dimensions Dead
    in
    GameOfLife (bringPatternToLife deadCells centeredPattern)
```
