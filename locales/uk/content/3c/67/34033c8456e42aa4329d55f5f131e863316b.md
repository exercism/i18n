# Про

Ефективно побудувати великий рядок тексту (англ. string) можна за допомогою буфера рядків, додаючи маленькі елементи один до одного. На відміну від String, екземпляр StringBuf не є незмінним у тому сенсі, що його можна передати як аргумент до функцій, які змінюють його, додаючи нові значення.

```haxe
var a = new StringBuf();
a.add("Hello");
trace(a.toString()); // Hello
a.add("Haxe!");
trace(a.toString()); // HelloHaxe
```
