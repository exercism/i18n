# Вступ

Хешмапа - це колекція, яка використовується для зберігання пар ключ-значення. Вона дозволяє використовувати довільні типи як ключі та значення. Хешмапа має швидкі функції вставлення та отримання і дуже корисна, наприклад, для підрахунку частот, зберігання звʼязків тощо. Хешмапа також має потужний API `entry`, який робить її використання зручним.
