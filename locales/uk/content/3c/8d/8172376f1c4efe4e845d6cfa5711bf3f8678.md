# Вступ

Метод - це функція з особливим аргументом, _одержувачем_.
Одержувач стоїть у власному списку аргументів між ключовим словом `func` і назвою методу.

```go
func (receiver type) MethodName(parameters) (returnTypes) {
}
```

Визначити метод можна лише з одержувачем, тип якого визначено в тому самому пакеті, що й метод.

```go
package person 

type Person struct {
	Name string
}

func (p Person) Greetings() string {
	return fmt.Sprintf("Welcome %s!", p.Name)
}
```

Метод структури можна викликати за допомогою точкової нотації.

```go
p := Person{Name: "Bronson"}
fmt.Println(p.Greetings())
// Output: Welcome Bronson!
```

Звернімо увагу, як ми викликали метод `Greetings()` у `p`, екземплярі `Person`.
Це точно так само, як ми викликаємо методи в обʼєктно-орієнтованій мові програмування.

Памʼятаймо: метод - це просто функція з аргументом-одержувачем.
Методи допомагають уникати конфліктів імен: метод привʼязаний до конкретного типу одержувача, тому одну й ту саму назву методу можна мати для різних типів.

```go
import "math"

type rect struct {
	width, height int
}
func (r rect) area() int {
	return r.width * r.height
}

type circle struct {
	radius int
}
func (c circle) area() float64 {
	return math.Pow(float64(c.radius), 2) * math.Pi
}
```

Є два типи одержувачів: одержувачі за значенням і одержувачі за вказівником.

Усі методи, які ми досі бачили, мають одержувач за значенням, а це означає, що вони отримують копію значення, переданого методу, тож будь-які зміни, зроблені з одержувачем усередині методу, не видно з місця виклику.

Методи можна оголошувати з одержувачами за вказівником, щоб змінювати значення, на яке вказує одержувач.
Для цього перед назвою типу ставимо `*`.
Наприклад, для типу `rect` одержувач за вказівником оголошується як `*rect`.
Такі зміни також видно з місця виклику методу.

```go
type rect struct {
	width, height int
}
func (r *rect) squareIt() {
	r.height = r.width
}

r := rect{width: 10, height: 20}
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 20

r.squareIt()
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 10
```
