# Вступ

## Порівняння

У Go числа можна порівнювати за допомогою таких операторів відношення та рівності.

| Порівняння         | Оператор  |
| ------------------ | --------- |
| дорівнює           | `==`      |
| не дорівнює        | `!=`      |
| менше              | `<`       |
| менше або дорівнює | `<=`      |
| більше             | `>`       |
| більше або дорівнює| `>=`      |

Результатом порівняння завжди є булеве значення (англ. Boolean), тобто `true` або `false`.

```go
a := 3

a != 4 // true
a > 5  // false
```

Наведені вище оператори порівняння також можна використовувати для порівняння рядків тексту (англ. string).
У цьому випадку застосовується лексикографічний (словниковий) порядок.
Наприклад:

```Go
	"apple" < "banana"  // true
	"apple" > "banana"  // false
```

## Умовні конструкції

Умовні конструкції в Go подібні до умовних конструкцій в інших мовах.
Базовим типом будь-якої умовної операції є тип `bool`, який може мати значення `true` або `false`.
Умовні конструкції часто використовуються як механізми керування потоком, щоб перевіряти різні умови.

Для перевірки конкретного випадку можна використати умовну конструкцію `if`, яка виконує свій код, якщо відповідна умова дорівнює `true`, ось так:

```go
var value string

if value == "val" {
    return "was val"
}
```

У сценаріях із більш ніж одним випадком багато умовних конструкцій `if` можна обʼєднати в ланцюжок за допомогою конструкцій `else if` та `else`.

```go
var number int
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

Умовні конструкції також можуть містити коротку інструкцію ініціалізації, яку можна використати, щоб ініціалізувати одну або кілька змінних для конструкції `if`.
Наприклад:

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```

> Примітка: будь-які змінні, створені в інструкції ініціалізації, виходять з області видимості після завершення умовної конструкції `if`.
