# Вступ

**Map** - це структура даних для зберігання пар ключ-значення.
Він схожий на словники в інших мовах програмування.
Інтерфейс [Map][map-javadoc] визначає операції над мапою.

У Java є чимало різних реалізацій Map.
[HashMap][hashmap-javadoc] - одна з найуживаніших.

```java
// Make an instance
Map<String, Integer> fruitPrices = new HashMap<>();
```

Додаймо записи до мапи за допомогою [put][map-put-javadoc].

```java
fruitPrices.put("apple", 100);
fruitPrices.put("pear", 80);
// => { "apple" => 100, "pear" => 80 }
```

З кожним ключем можна повʼязати лише одне значення.
Виклик `put` із тим самим ключем оновить значення цього ключа.

```java
fruitPrices.put("pear", 40);
// => { "apple" => 100, "pear" => 40 }
```

Щоб отримати значення для ключа, скористаймося [get][map-get-javadoc].

```java
fruitPrices.get("apple"); // => 100
```

Щоб перевірити, чи є в мапі певний ключ, скористаймося [containsKey][map-containskey-javadoc].

```java
fruitPrices.containsKey("apple");   // => true
fruitPrices.containsKey("orange");  // => false
```

Вилучимо записи за допомогою [remove][map-remove-javadoc].

```java
fruitPrices.put("plum", 90);  // Add plum to map
fruitPrices.remove("plum");   // Removes plum from map
```

Метод [size][map-size-javadoc] повертає кількість записів.

```java
fruitPrices.size();  // Returns 2
```

За допомогою методів [keySet][map-keyset-javadoc] або [values][map-values-javadoc] можна отримати ключі або значення мапи як Set або колекцію відповідно.

```java
fruitPrices.keySet();  // Returns "apple" and "pear" in a set
fruitPrices.values();  // Returns 100 and 80, in a Collection
```
