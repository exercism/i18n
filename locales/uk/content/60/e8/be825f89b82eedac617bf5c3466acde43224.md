# Підказки

## Загальне

- Слова для читання містяться в [`io`][io]; конструктори потоків рядків тексту (англ. string)
  і `with-string-writer` містяться в
  [`io.streams.string`][io.streams.string].
- Для завдання зі скиданням буфера записувача локальні змінні (`::` і `:>`)
  тримають тіло читабельним, коли потрібно звернутися до того самого потоку двічі.

## 1. Вислухати все до кінця

- Одне слово: `stream-contents`.

## 2. Порахувати повідомлення

- `stream-lines` розбиває потік на масив рядків;
  `length` повертає кількість.

## 3. Відлунити останній виклик

- Той самий `stream-lines`, що й вище, потім `last`, потім `>upper` (з
  `ascii`).

## 4. Передати повідомлення в ефір

- `stream-write` записує повідомлення, а `stream-flush` виводить його
  назовні. Записувач використовується двічі, тож варто взяти локальні
  змінні `::`:
  `:: broadcast ( message writer -- ) message writer stream-write
  writer stream-flush ;`.

## 5. Перехопити вивід quotation

- Одне слово: `with-string-writer`. Додайте `inline` після закриваючої
  `;`, щоб компілятор бачив крізь аргумент quotation:
  `: capture ( quot -- captured ) with-string-writer ; inline`.
