# Вступ

[C# `Attribute`](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/) дає змогу оздобити оголошення, щоб повʼязати з ним метадані: клас, метод, перелік, поле, властивість або будь-які [інші підтримувані](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/#attribute-targets) оголошення.

Атрибут можна застосувати, додавши його в рядку перед оголошенням за допомогою `ClassAttribute` і `FieldAttribute`:

```csharp
[Class]
class MyClass
{
    [Field]
    int myField;
}
```

Ці декларативні метадані лише повʼязують із кодом додаткову структуровану інформацію й не змінюють його поведінки, але інші частини коду використовують їх, щоб змінити поведінку цілі атрибута, додати, змінити чи прибрати або обмежити деякі її можливості.

Існує багато [визначених наперед і зарезервованих атрибутів](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/attributes/general#conditional-attribute), наприклад: `Flags`, `Obsolete`, `Conditional`. Кожен має свою специфіку, яку можна знайти в документації C#. Зауважмо, що такий атрибут, як [`Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute), за домовленістю має повну назву `FlagsAttribute`, але суфікс _Attribute_ можна опустити, застосовуючи атрибут до оголошення.
