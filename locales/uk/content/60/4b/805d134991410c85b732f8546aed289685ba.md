# Докладніше

Перебір - це коли ми проходимо колекцією (`Array`, `Hash` тощо) і виконуємо певну дію над кожним обʼєктом.

Перебір - ключова концепція в Ruby, яку використовують для сортування (`sort_by`), групування (`group_by`), перетворення (`map`), згортання (`reduce`) та багато чого іншого.
Найчастіше ми бачимо перебір як ідіоматичний спосіб перебирати колекції, а не використовувати цикли.

Простий перебір, який друкує кожне слово з масиву, матиме такий вигляд:

```ruby
words = %w[the cat sat on the mat]
words.each do |word|
  puts word
end

# Output:
# the
# cat
# sat
# on
# the
# mat
```

У цьому прикладі ми викликали метод `Array#each` і передали йому _блок_, який приймає один параметр (`word`) і друкує його.

Ми також можемо поєднувати методи перебирання в ланцюжки.
Наприклад, ми можемо приєднати `.with_index` до `each`, щоб надрукувати й індекс обʼєкта, і його значення:

```ruby
words = %w[the cat sat on the mat]
list = words.map.with_index { |word, index| "#{index}. #{word}" }
puts list

# Output:
# 0. the
# 1. cat
# ...
# 5. mat
```

Перебір обʼєктів `Hash` нічим не відрізняється від перебору обʼєктів `Array`, хіба що блок приймає два аргументи: ключ і значення:

```ruby
pet_names = {cat: "bob", horse: "caris", mouse: "arya"}
words.each { |animal, name| ... }

# The two arguments should be put in brackets when chaining
words.each.with_index { |(animal, name), index| ... }
```

Описані вище методи є частиною [модуля `Enumerable`][enumerable-module], який включено в `Array`, `Hash` та інші класи, яким потрібна здатність перебирати.

[enumerable-module]: https://docs.ruby-lang.org/en/master/Enumerable.html
