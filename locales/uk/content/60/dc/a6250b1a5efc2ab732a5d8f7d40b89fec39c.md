# Про

Batch-скриптинг - це мова сценаріїв, яку переважно використовують для запуску команд у Windows Command Prompt (cmd.exe).
Вона дає змогу автоматизувати завдання, керувати файлами та керувати системним середовищем за допомогою низки команд у командному рядку.

Хоча Batch-скриптинг і простий, він здатен виконувати широкий спектр завдань: від простих операцій із файлами до складніших процесів автоматизації.

Файли Batch мають розширення `.bat` або `.cmd` і можуть виконуватися безпосередньо інтерпретатором команд Windows.

Гнучкість Batch-скриптингу робить його потужним інструментом для системних адміністраторів, розробників і досвідчених користувачів, яким потрібно автоматизувати рутинні завдання або створювати власні інструменти командного рядка.
