# Підказки

## Загальне

- Прочитайте офіційну документацію про [діапазони][range].

## 1. Визначте діапазон горизонталей

- Існує [спеціальний оператор][range-creation-operator] для створення діапазонів.

## 2. Визначте діапазон вертикалей

- Існує [спеціальний оператор][range-creation-operator] для створення діапазонів.
- Існує [спеціальний синтаксис][unicode-code-points], щоб записати кодову точку символу, не знаючи її значення явно.

## 3. Перетворіть діапазон горизонталей на список горизонталей

- Діапазони реалізують протокол `Enumerable`.
- Існує [вбудована функція][enum-to-list], щоб перетворити перелічувану структуру даних на список.

## 4. Перетворіть діапазон вертикалей на список вертикалей

- Діапазони реалізують протокол `Enumerable`.
- Існує [вбудована функція][enum-map], щоб перетворити перелічувану структуру даних на список, змінюючи її елементи.
- [Спеціальну форму для бітових рядків][bitstring-special-form] можна використати, щоб перетворити кодову точку на рядок тексту (англ. string).
