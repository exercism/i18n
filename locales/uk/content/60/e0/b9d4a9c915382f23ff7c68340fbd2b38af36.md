# Статичні ключові слова класу

У PHP клас виступає одиницею організації коду, яка часто представляє екземпляр якоїсь речі, сервісу чи процедури.
За допомогою ключових слів `static` і `self` властивості та методи можуть існувати на рівні класу для всіх екземплярів (або жодного екземпляра).

```php
<?php

class Book
{
    static $genre = 'Adventure';

    static function getGenre()
    {
        return self::$genre;
    }
}

// Usage
$genre = Book::$genre;
$genre = Book::getGenre();
```

## Обмеження

Статичні методи класу можуть звертатися лише до інших статичних властивостей або методів класу зі свого ж класу.

```php
<?php

class Book
{
    $name = 'Treasure Island';

    static function getName()
    {
        // This static method cannot access the instance variable
        return $this->name;
    }
}
```
