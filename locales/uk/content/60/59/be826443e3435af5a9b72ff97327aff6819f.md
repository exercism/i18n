# Тести

Якщо бінарний файл phix доступний у PATH, введіть команду:

```bash
p test 
```
Вона запустить файл тестів (test.exw).

Якщо бінарного файлу phix немає в PATH, у Windows введіть

```cmd
\path\to\p.exe test
```

Linux:

```bash
/path/to/p test
```

## Пропущені тести

Розвʼязати вправу означає домогтися, щоб усі її тести проходили.
Типово виконуються всі тести з файлу test.exw.
Щоб пропустити тест, додайте два дефіси (стандартний маркер коментаря у Phix) на початок рядка.

Зауважте: тести не враховують жодних прапорців include=false у файлі tests.toml. Натомість автор
test.exw має підтримувати їх вручну в цьому файлі, щоб відображати реальність на користь
сайту Exercism (наприклад, для збору статистики треку). Але ніщо в самому треку не використовує
їх зовсім, зокрема й генератор тестів і запускач тестів.
