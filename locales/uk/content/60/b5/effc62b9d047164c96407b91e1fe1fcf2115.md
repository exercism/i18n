# Підказки

## Загальне

- Про протоколи можна прочитати в [офіційному посібнику Getting Started][getting-started-protocols] або на [elixirschool.com][elixir-school-protocols].

## 1. Визначте їстівність

- Для визначення протоколів є [спеціальний макрос][kernel-defprotocol].
- Протоколи складаються з одного або кількох заголовків функцій.
- Заголовок функції схожий на визначення функції, але без блоку `do`. Він визначає назву функції та її аргументи, але не те, що вона робить.

## 2. Зробіть буханці хліба їстівними

- Для реалізації протоколу для заданого типу даних існує [спеціальний макрос][kernel-defimpl].
- Реалізувати протокол означає написати визначення функції для кожного заголовка функції з цього протоколу.

## 3. Зробіть зілля мани їстівними

- Для реалізації протоколу для заданого типу даних існує [спеціальний макрос][kernel-defimpl].
- Реалізувати протокол означає написати визначення функції для кожного заголовка функції з цього протоколу.

## 4. Зробіть отрути їстівними

- Для реалізації протоколу для заданого типу даних існує [спеціальний макрос][kernel-defimpl].
- Реалізувати протокол означає написати визначення функції для кожного заголовка функції з цього протоколу.
