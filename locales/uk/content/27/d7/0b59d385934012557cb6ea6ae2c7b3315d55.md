# Інструкції

У цій вправі ми напишемо трохи коду, який допоможе приготувати чудову лазанью з улюбленої кулінарної книги.

На нас чекають чотири завдання, і всі вони повʼязані з часом, витраченим на приготування лазаньї.

~~~~exercism/note
Це інструкції, згадані в цій концепції:

| Інструкція | Опис                            |
|-------------|---------------------------------|
| mov a, b    | копіює вміст з b в a            |
| add a, b    | a = a + b                       |
| sub a, b    | a = a - b                       |
| imul a, b   | a = a * b                       |
| call a      | викликає функцію a              |
| ret         | повертається з функції          |
~~~~

## 1. Визначте очікуваний час у духовці в хвилинах

Визначте функцію `expected_minutes_in_oven`, яка не приймає жодних параметрів і повертає, скільки хвилин лазанья має провести в духовці.
Згідно з кулінарною книгою, очікуваний час у духовці становить 40 хвилин:

```c
expected_minutes_in_oven();
// => 40
```

## 2. Обчисліть залишок часу в духовці в хвилинах

Визначте функцію `remaining_minutes_in_oven`, яка приймає як параметр фактичну кількість хвилин, які лазанья вже провела в духовці, і повертає, скільки хвилин їй ще залишилося там провести, виходячи з очікуваного часу в духовці з попереднього завдання.

```c
remaining_minutes_in_oven(30);
// => 10
```

## 3. Обчисліть час підготовки в хвилинах

Визначте функцію `preparation_time_in_minutes`, яка приймає як параметр кількість шарів, доданих до лазаньї, і повертає, скільки хвилин ми витратили на підготовку лазаньї, якщо на кожен шар іде 2 хвилини.

```c
preparation_time_in_minutes(2);
// => 4
```

## 4. Обчисліть витрачений час у хвилинах

Визначте функцію `elapsed_time_in_minutes`, яка приймає два параметри в такому порядку:

1. Кількість шарів, доданих до лазаньї.
2. Кількість хвилин, які лазанья провела в духовці.

Функція має повернути, скільки хвилин ми витратили на приготування лазаньї.
Це сума часу підготовки в хвилинах і часу в хвилинах, який лазанья на цей момент провела в духовці.

```c
elapsed_time_in_minutes(3, 20);
// => 26
```
