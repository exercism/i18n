# Про

## Вступ

Узагальнення - це можливість мови, яка дає змогу повторно використовувати код.
Наприклад, не повинно мати значення, який тип зберігає масив, щоб обчислити його довжину.
Ось чому функція `length` використовує узагальнений параметр типу `a` у своїй сигнатурі типу.

```elm
length : List a -> Int
```

## Параметри в типах

Коли тип є узагальненим щодо іншого типу, ми використовуємо назву з малої літери для цього іншого типу й називаємо її параметром типу.
До поширених прикладів належать власні типи `List`, `Maybe` і `Result`.

```elm
-- Maybe is generic over the type a
type Maybe a
    = Nothing
    | Just a

someString : Maybe String
someString = Just "hello"

someInt : Maybe Int
someInt = Just 42
```

Одне важливе зауваження щодо назв параметрів типу: вони можуть складатися з кількох символів.
Єдине обмеження: вони мають бути назвами з малої літери.
Тож коли це доцільно, ми схильні давати їм описові назви.

Тип може бути узагальненим щодо кількох інших типів і, отже, мати кілька параметрів типу.
У такому разі кожен незалежний тип отримує іншу назву з малої літери.
Незалежність не заважає їм стати одним і тим самим типом, вона лише дає їм змогу бути різними.

```elm
-- Result is generic over the types error and value
type Result error value
    = Ok value
    | Err error
```

Псевдоніми типів записів також можуть мати параметри типу, хоча це трапляється рідше.

```elm
-- Event is generic over the type a
type alias Event a =
    { at : Time
    , data : a 
    }
```

## Параметри типів у функціях

Оскільки типи можуть бути узагальненими, функції також можуть.
Можна писати функції, які працюють з узагальненими типами, наприклад `Maybe.withDefault`.

```elm
withDefault : a -> Maybe a -> a
withDefault default maybe =
    case maybe of
      Just value -> value
      Nothing -> default
```

Функції, які приймають інші функції як параметри, називаються функціями вищого порядку, і вони також можуть бути узагальненими.

```elm
map : (a -> b) -> Maybe a -> Maybe b
map function maybe =
  case maybe of
    Just value ->
      Just (function value)

    Nothing ->
      Nothing
```
