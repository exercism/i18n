# Вступ

Здатність чогось визначатися через самого себе називається рекурсією. У F# рекурсія найчастіше трапляється в рекурсивних функціях, тобто функціях, які викликають самі себе.

Рекурсивна функція потребує щонайменше одного _базового випадку_ і щонайменше одного _рекурсивного випадку_. _Базовий випадок_ повертає значення, не викликаючи функцію знову. _Рекурсивний випадок_ викликає функцію знову, змінюючи вхідні дані так, щоб вони в якийсь момент збіглися з базовим випадком.

Рекурсивні функції визначають так само, як звичайні, але з модифікатором `rec`. Без цього модифікатора функція _не_ зможе викликати саму себе, і будь-яка спроба це зробити призведе до помилки компіляції. Тож рекурсію потрібно вмикати явно.

```fsharp
let rec factorial x =
    // Base case
    if x = 1 then
        1
    // Recursive case
    else
        x * factorial (x - 1)
```

F# також підтримує рекурсивні типи через розпізнавані обʼєднання. У рекурсивного розпізнаваного обʼєднання один або кілька його варіантів у своїх даних посилаються на нього саме. Як і рекурсивним функціям, рекурсивним типам потрібен базовий випадок. Але на відміну від рекурсивних функцій, рекурсивні типи не використовують ключове слово `rec`.

```fsharp
type RussianDoll =
    | Doll                 // Base case
    | Layer of RussianDoll // Recursive case
```
