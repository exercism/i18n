# Вступ

Мапи в Elixir — це структура даних для зберігання інформації у парах ключ-значення. В інших мовах їх також можуть називати асоціативними масивами (PHP), хешами (Perl 5, Raku) або словниками (Python).

Ключі та значення можуть мати будь-який тип даних, але якщо ключ є атомом, ми можемо скористатися скороченим синтаксисом. Мапи не гарантують порядку своїх записів під час доступу чи повернення.

## Літеральні форми

Порожню мапу оголошують просто за допомогою `%{}`. Якщо ми хочемо додати елементи до літерала мапи, можна скористатися двома формами:

```elixir
# If the key is an atom:
%{atom_key: 1}

# If the key is a different type:
%{1 => :atom_value}

# You can even mix these if the atom form comes second:
%{"first_form" => :a, atom_form: :b}
```

Хоча канонічного формату не існує, виберімо послідовний спосіб запису літеральних пар ключ-значення.

## Функції модуля Map

Elixir надає багато функцій для роботи з мапами в _модулі Map_. Деякі функції _модуля Map_ вимагають, щоб у функцію передали _анонімну_ функцію, яка допомагає з перетворенням мапи.
