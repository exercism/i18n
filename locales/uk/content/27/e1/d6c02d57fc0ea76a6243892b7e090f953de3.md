# Вступ

`string` у F# - це обʼєкт, який представляє незмінний текст як послідовність символів Unicode (літер, цифр, розділових знаків тощо) і визначається так:

```fsharp
let fruit = "Apple"
```

Рядки тексту опрацьовують, викликаючи або методи самого рядка тексту, або функції модуля `String`. Після створення рядка тексту його значення вже ніколи не змінюється. Будь-які методи чи функції, які нібито змінюють рядок тексту, насправді повертають новий рядок тексту.

Рядки тексту можна зʼєднати або відформатувати кількома способами.
* Для конкатенації використовують оператор `+`:
```fsharp
let sentence = "Apple" + " is a type of fruit."
```
* Функція `sprintf` форматує текст: у рядку формату вказують заповнювачі (`%s` для `string`), а значення передають як аргументи:
```fsharp
let sentence = sprintf "%s is a type of %s." "Apple" "fruit"
```
