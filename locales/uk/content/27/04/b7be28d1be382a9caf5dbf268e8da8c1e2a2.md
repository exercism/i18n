# Вступ

Є по суті два типи циклів:

1. Повторювати, доки умова не виконається.
2. Перебирати елементи колекції.

Обидва варіанти можливі в Julia, хоча другий, імовірно, трапляється частіше.

## Цикл `while`

Для задач, у яких кількість повторів заздалегідь невідома, у Julia є цикл `while`.

Базова форма досить проста:

```julia
while condition
    do_something()
end
```

У цьому разі програма повторюватиме цикл, доки значення `condition` не перестане бути `true`.

Є два способи достроково вийти з циклу:

- `break` перериває цикл, і виконання продовжується з наступного рядка після `end` циклу.
- `return x` зупиняє виконання поточної функції та повертає значення `x` тому, хто її викликав.

Маючи ці два варіанти, іноді зручно створити «нескінченний» цикл `while true ... end`, а потім покладатися на те, що умова зупинки всередині тіла циклу запустить `break` або `return`.

## Перебирання колекції

Почнімо з найпростішого: переберімо діапазон.

Якщо ми хочемо виконати щось 10 разів:

```julia
for n in 1:10
    do_something(n)
end
```

Якщо поточна ітерація не задовольняє якусь умову, можна одразу перейти до наступної за допомогою `continue`:

```julia
for n in 1:10
    if is_useless(n)
        continue
    end
    
    # we decided this iteration could be useful
    do_something_slow(n)
end
```

У коротшій формі блок `if` можна замінити на `is_useless(n) && continue`.

Можна перебирати й багато інших типів колекцій: елементи масиву, символи рядка тексту (англ. string), ключі словника...

У наведених прикладах ми перебирали діапазон `1:10`, де значення водночас є індексом циклу.

У загальнішому випадку може знадобитися не лише значення, а й індекс.
Для цього використовують функцію `eachindex()`, наприклад `for i in eachindex(my_array) ... end`.

## Включення

Явні цикли в Julia трапляються рідше, ніж у багатьох традиційних мовах, бо є чимало лаконічніших варіантів.

Особливо часто виникає ситуація, коли нам потрібно побудувати новий вектор з елементів якоїсь іншої колекції (вектора, рядка тексту, множини ... можливостей багато).

Тим, кому подобаються спискові включення в Python, буде приємно дізнатися, що в Julia можна використовувати схожий синтаксис.

Суть у тому, щоб задати дуже компактний цикл усередині вектора.

Найпростіший синтаксис має вигляд `result = [f(x) for x in some_collection]`.

Із традиційним циклом це можна записати так:

```julia
result = []
for x in some_collection
    push!(result, f(x))
end
```

За бажанням, у кінці можна додати умову, щоб вибрати лише відповідні елементи колекції:

```julia-repl
# multiples of 3
julia> [n^2 for n in 1:10 if n%3 == 0]
3-element Vector{Int64}:
  9
 36
 81
```
