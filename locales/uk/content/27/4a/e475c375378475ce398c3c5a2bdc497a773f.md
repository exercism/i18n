# Вступ

У Go `map` є вбудованим типом даних, який зіставляє ключі зі значеннями.
В інших мовах програмування ця концепція `map` може бути знайома нам як словник, хеш-таблиця, сховище ключ-значення або асоціативний масив.

Синтаксично `map` має такий вигляд:

```go
map[KeyType]ElementType
```

Також важливо знати, що кожен ключ унікальний, тобто якщо присвоїти той самий ключ двічі, значення відповідного ключа буде перезаписано.

Щоб створити map, можна зробити так:

```go
  // With map literal
  foo := map[string]int{}
```

або

```go
  // or with make function
  foo := make(map[string]int)
```

Ось деякі операції, які можна виконувати з map

```go
  // Add a value in a map with the `=` operator:
  foo["bar"] = 42
  // Here we update the element of `bar`
  foo["bar"] = 73
  // To retrieve a map value, you can use
  baz := foo["bar"]
  // To delete an item from a map, you can use
  delete(foo, "bar")
```

Якщо ми спробуємо отримати значення для ключа, якого немає в map, повернеться нульове значення для цього типу.
Це може заплутати нас, особливо якщо типове значення нашого `ElementType` (наприклад, 0 для int) є припустимим значенням.
Щоб перевірити, чи існує ключ у map, можна використати

```go
  value, exists := foo["baz"]
  // If the key "baz" does not exist,
  // value: 0; exists: false
```
