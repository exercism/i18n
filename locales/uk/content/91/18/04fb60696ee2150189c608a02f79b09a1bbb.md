# Інструкції

Мета цієї вправи - розібрати координати GPS.
Кожна координата має [формат десяткових градусів](https://en.wikipedia.org/wiki/Decimal_degrees) із явним зазначенням півкулі:

```text
<LATITUDE_DEGREES> <LATITUDE_HEMISPHERE>, <LONGITUDE_DEGREES> <LONGITUDE_HEMISPHERE>
```

Ось дозволені значення для кожного окремого компонента:

- `<LATITUDE_DEGREES>`: число з плаваючою комою в діапазоні 0..90 (включно)
- `<LATITUDE_HEMISPHERE>`: `N` або `S`
- `<LONGITUDE_DEGREES>`: число з плаваючою комою в діапазоні 0..180 (включно)
- `<LONGITUDE_HEMISPHERE>`: `E` або `W`

Наприклад, `"48.8584 N, 2.2945 E"` розбирається на:

- `<LATITUDE_DEGREES>`: 48.8584
- `<LATITUDE_HEMISPHERE>`: N
- `<LONGITUDE_DEGREES>`: 2.2945
- `<LONGITUDE_HEMISPHERE>`: E

На нас чекає 11 завдань, у яких ми будемо крок за кроком розбирати координати GPS.
Ми будемо використовувати підтримку [Definite Clause Grammar](https://en.wikipedia.org/wiki/Definite_clause_grammar) (DCG) у Prolog, призначену для розбору структурованого тексту.

````exercism/note
Щоб полегшити нам старт, файл-заготовка вже містить [бібліотеку `dcg/basics`](https://www.swi-prolog.org/pldoc/doc/_SWI_/library/dcg/basics.pl), підключену так:

```prolog
:- use_module(library(dcg/basics)).
```
````

## 1. Розібрати кому

Реалізуйте правило `comma`, яке розбирає одну кому (`","`):

```prolog
?- string_codes(",", Codes), phrase(comma, Codes).
```

## 2. Розібрати пробіл

Реалізуйте правило `space`, яке розбирає один пробіл (`" "`):

```prolog
?- string_codes(" ", Codes), phrase(space, Codes).
```

## 3. Підтримати всі пробільні символи (крім символів нового рядка)

Змініть правило `space` так, щоб воно розбирало _всі_ пробільні символи, крім символів нового рядка:

```prolog
?- string_codes("\t", Codes), phrase(space, Codes).

?- string_codes("\n", Codes), phrase(space, Codes).
false.
```

## 4. Розібрати півкулю широти

Півкуля широти може бути `"N"` або `"S"`, і під час розбору її треба перетворити на атом `north` або `south`.
Реалізуйте правило `latitude_hemisphere`, яке розбирає півкулю широти:

```prolog
?- string_codes("N", Codes), phrase(latitude_hemisphere(Hemisphere), Codes).
Hemisphere = north.
```

## 5. Розібрати півкулю довготи

Півкуля довготи може бути `"E"` або `"W"`, і під час розбору її треба перетворити на атом `east` або `west`.
Реалізуйте правило `longitude_hemisphere`, яке розбирає півкулю довготи:

```prolog
?- string_codes("E", Codes), phrase(longitude_hemisphere(Hemisphere), Codes).
Hemisphere = east.
```

## 6. Розібрати градуси

Градуси довготи чи широти задаються числом з плаваючою комою.
Реалізуйте правило `degrees`, яке розбирає числа з плаваючою комою:

```prolog
?- string_codes("748.012", Codes), phrase(degrees(Degrees), Codes).
Degrees = 748.012.
```

## 7. Розібрати градуси широти

Градуси широти - це не просто числа з плаваючою комою, а числа з плаваючою комою в діапазоні 0..90 (включно).
Реалізуйте правило `latitude_degrees`, яке розбирає градуси широти в межах зазначеного діапазону:

```prolog
?- string_codes("48.745", Codes), phrase(latitude_degrees(Degrees), Codes).
Degrees = 48.745.

?- string_codes("117.844", Codes), phrase(latitude_degrees(Degrees), Codes).
false.
```

## 8. Розібрати градуси довготи

Градуси довготи - це не просто числа з плаваючою комою, а числа з плаваючою комою в діапазоні 0..180 (включно).
Реалізуйте правило `longitude_degrees`, яке розбирає градуси довготи в межах зазначеного діапазону:

```prolog
?- string_codes("178.773", Codes), phrase(longitude_degrees(Degrees), Codes).
Degrees = 178.773.

?- string_codes("-22.523", Codes), phrase(longitude_degrees(Degrees), Codes).
false.
```

## 9. Розібрати широту

Широта складається з двох частин: градусів і півкулі, розділених пробілом.
Реалізуйте правило `latitude`, яке розбирає широту:

```prolog
?- string_codes("56.101 N", Codes), phrase(latitude(Degrees, Hemisphere), Codes).
Degrees = 56.101,
Hemisphere = north.
```

## 10. Розібрати довготу

Довгота складається з двох частин: градусів і півкулі, розділених пробілом.
Реалізуйте правило `longitude`, яке розбирає довготу:

```prolog
?- string_codes("143.889 W", Codes), phrase(longitude(Degrees, Hemisphere), Codes).
Degrees = 143.889,
Hemisphere = west.
```

## 11. Розібрати координату

Координата складається з двох частин: широти і довготи, розділених комою та пробілом після неї.
Реалізуйте правило `coordinate`, яке розбирає і широту (градуси та півкулю), і довготу:

```prolog
?- string_codes("48.8584 N, 2.2945 E", Codes), phrase(coordinate(Latitude, LatitudeHemisphere, Longitude, LongitudeHemisphere), Codes).
Latitude = 48.8584,
LatitudeHemisphere = north,
Longitude = 2.2945,
LongitudeHemisphere = east.
```
