# Докладніше

Числа з плаваючою комою - це дробові або цілі числа із десятковою точкою (як-от `3.14`, `-1.7`, `99.99`, `2048.0`)

Тип float у Common Lisp поділяється на кілька підтипів, кожен із яких має власні характеристики й точність: short-float, single-float, double-float і long-float.

Підтип short-float зазвичай займає найменше памʼяті та дає найнижчу точність із чотирьох підтипів. Він підходить для випадків, коли обсяг використаної памʼяті має значення, але менша точність прийнятна.

Підтип single-float пропонує баланс між використанням памʼяті та точністю. Його зазвичай використовують для загальних обчислень із плаваючою комою.

Підтип double-float дає вищу точність порівняно з single-float і підходить для застосунків, які потребують точніших обчислень, як-от наукові розрахунки та чисельне моделювання.

Підтип long-float дає найвищу точність із чотирьох підтипів, але може потребувати більше памʼяті, ніж інші. Його зазвичай використовують у спеціалізованих застосунках, які вимагають надзвичайно точних обчислень.

Ці підтипи дають програмістам Common Lisp змогу обирати відповідний рівень точності та використання памʼяті відповідно до потреб своїх конкретних застосунків.

Загалом, якщо ми працюємо лише з цілими числами, варто надавати перевагу цілим числам, адже під час багатьох обчислень вони не втрачають точність так, як числа з плаваючою комою.

## Довідка

```lisp
;; Rounding to the Nearest Whole Number
(round 3.14)  ; => 3
(round -3.14) ; => -3
(round 2.72)  ; => 3
(round -2.72) ; => -3

;; Rounding Towards Zero
(truncate 3.14)  ; => 3
(truncate -3.14) ; => -3
(truncate 2.72)  ; => 2
(truncate -2.72) ; => -2

;; Rounding Towards Negative Infinity
(floor 3.14)  ; => 3
(floor -3.14) ; => -4
(floor 2.72)  ; => 2
(floor -2.72) ; => -3

;; Rounding Towards Positive Infinity
(ceiling 3.14)  ; => 4
(ceiling -3.14) ; => -3
(ceiling 2.72)  ; => 3
(ceiling -2.72) ; => -2
```
