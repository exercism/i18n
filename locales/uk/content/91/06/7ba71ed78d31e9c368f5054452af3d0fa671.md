# Інструкції

Жив собі ексцентричний програміст у дивному будинку з ґратами на вікнах.
Якось він знайшов на онлайн-дошці вакансій замовлення на створення робота для вечірок.
Робот має вітати людей і проводжати їх до їхніх місць.
Перша версія була дуже технічною і виказувала, що програміст геть не вміє спілкуватися з людьми.
Дещо з цього також потрапило в наступну версію.

## 1. Привітати нового гостя на вечірці

Реалізуйте функцію `Welcome`, яка повертає вітальне повідомлення з використанням переданого імені:

```go
Welcome("Christiane")
// => Welcome to my party, Christiane!
```

## 2. Привітати нового гостя, у якого сьогодні день народження

Реалізуйте функцію `HappyBirthday`, яка повертає привітання з днем народження, використовуючи передане імʼя та вік людини.
На жаль, програміст не проти похизуватися, тож робот має продемонструвати, що знає день народження кожного гостя.

```go
HappyBirthday("Frank", 58)
// => Happy birthday Frank! You are now 58 years old!
```

## 3. Показати дорогу

Реалізуйте функцію `AssignTable`, яка вказує дорогу.
Вона має приймати 5 параметрів.

- Імʼя нового гостя, якого потрібно привітати (`string`)
- Номер столика (`int`)
- Імʼя сусіда по столику (`string`)
- Напрямок, де шукати столик (`string`)
- Відстань до столика (`float64`)

Точний формат результату можна побачити в прикладі нижче.

Робот подає номер столика у форматі з 3 цифр.
Якщо число має менше ніж 3 цифри, до нього додаються провідні нулі, щоб вийшло 3 цифри (наприклад, 3 стає 003).
Робот також називає відстань до столика.
На щастя, лише з точністю до 1 цифри.

```go
AssignTable("Christiane", 27, "Frank", "on the left", 23.7834298)
// =>
// Welcome to my party, Christiane!
// You have been assigned to table 027. Your table is on the left, exactly 23.8 meters from here.
// You will be sitting next to Frank.
```
