# Вказівки

Еліза, майбутня чарівниця, продовжує навчання.
Їй даватимуть кілька колод карток, з якими вона виконуватиме свої фокуси.
Щоб трохи спростити собі роботу, вона використовує лише картки від 1 до 10.
Кожна картка в неї лише одна, у її колодах немає повторів.

У цій вправі скористайтеся методами з бібліотеки Base мови Julia, щоб проаналізувати вміст масиву.

## 1. Визначте, чи присутня картка

Еліза хоче визначити, чи присутня картка в колоді, тобто чи містить колода певне число.

```julia-repl
julia> card = 3;

julia> has_card([2, 3, 4, 5], card)
true
```

## 2. Знайдіть позицію картки

Еліза хоче знати позицію (індекс) картки в колоді.
Якщо картки немає в колоді, поверніть `nothing`.

```julia-repl
julia> card = 2;

julia> find_card([9, 7, 3, 2], card)
4
```

## 3. Визначте, чи кожна картка парна

Еліза хоче знати, чи кожна картка парна, тобто чи кожне число в колоді парне.

```julia-repl
julia> all_cards_even([2, 4, 6, 7])
false
```

## 4. Перевірте, чи містить колода картку з непарним значенням

Еліза хоче знати, чи є в колоді непарне число.

```julia-repl
julia> any_odd_cards([3, 2, 6, 4, 8])
true
```

## 5. Визначте позицію першої парної картки

Еліза хоче знати позицію першої парної картки.
Якщо в колоді немає парних карток, поверніть `nothing`.

```julia-repl
julia> first_even_card_idx([5, 2, 3, 1])
2
```

## 6. Отримайте першу непарну картку з колоди

Еліза хоче знати значення першої непарної картки.
Якщо в колоді немає непарних карток, поверніть `nothing`.

```julia-repl
julia> first_odd_card([4, 2, 8, 7, 9])
7
```
