# Про

`SYMBOL:` не *зберігає* значення - це лише назва. Значення живе у просторі імен, а назва є ключем до нього.

```factor
USING: namespaces ;

SYMBOL: history

V{ } clone history set-global
"first event" history get-global push
"second event" history get-global push
history get-global .
! => V{ "first event" "second event" }
```

Дві області видимості:

- **глобальна** - записується і читається за допомогою `set-global`, `get-global`,
  `change-global`. Значення зберігаються протягом усього часу роботи
  процесу.
- **динамічна** - записується і читається за допомогою `set`, `get`, `change`.
  Привʼязки існують протягом дії форми `with-variable`,
  тож зовнішній код може «впорскувати» значення, яке бачить внутрішній код, не
  змінюючи кожну сигнатуру на шляху.

```factor
"verbose" log-level [
    log-level get .   ! => "verbose"
] with-variable
```

`SYMBOL:` і `SYMBOLS:` оголошують символи під час завантаження словника,
роблячи їх спільними посиланнями між файлами.
