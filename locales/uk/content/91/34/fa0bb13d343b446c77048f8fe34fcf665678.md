# Докладніше

Щоб обʼєкт можна було порівняти з іншим обʼєктом, він повинен реалізувати інтерфейс `IComparable<T>`.
Цей інтерфейс має один метод, який потрібно реалізувати: `int CompareTo(T other)`.

Метод `CompareTo` може повернути одне з трьох значень:

- Значення менше за нуль: поточний обʼєкт менший за інший обʼєкт.
- Значення більше за нуль: поточний обʼєкт більший за інший обʼєкт.
- Значення дорівнює нулю: поточний обʼєкт дорівнює іншому обʼєкту.

```csharp
public class Book : IComparable<Book>
{
    public int PageCount { get; set; }

    public int CompareTo(Book other)
    {
        // If other is not a valid object reference, this instance is greater.
        if (other == null) return 1;

        // Compare books using their number of pages
        return PageCount.CompareTo(other.PageCount);
    }
}

var smallBook = new Book { PageCount = 99 };
var largeBook = new Book { PageCount = 3333 };

smallBook.CompareTo(largeBook);
// => -1
```
