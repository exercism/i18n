# Вступ

Визначення `:` може викликати саме себе напряму. Компілятор Factor виводить стековий ефект рекурсивних слів так само, як і будь-яких інших. Для звичайної рекурсії жодного спеціального оголошення не потрібно.

```factor
: total ( seq -- sum )
    [ 0 ] [ unclip swap total + ] if-empty ;

{ 4 0 9 0 5 } total .    ! => 18
```

Дві половини - це *базовий випадок* рекурсії (тут порожня послідовність дає суму `0`) і *рекурсивний крок* (відокремити один елемент, застосувати рекурсію до решти, поєднати результати).

Для рекурсії по послідовностях канонічними супутниками є `if-empty` та `unclip`. `if-empty ( seq emptyquot nonemptyquot -- )` виконує один із двох quotation залежно від послідовності; `unclip` знімає перший елемент, щоб у рекурсивного кроку було щось простіше.
