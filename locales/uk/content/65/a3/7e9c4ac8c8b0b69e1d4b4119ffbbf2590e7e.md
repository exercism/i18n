# Вступ

У Gleam вираз `case` можна використати, щоб умовно виконувати код. За допомогою виразу `case` значення можна зіставити з одним або кількома _зразками_. Прикладом такого зразка є _літеральний зразок_, який зіставляє значення з літеральним значенням (наприклад, `1` або `"hello"`).

Вирази `case` записують за допомогою ключового слова `case`:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    1 -> "One"
  }
}
```

Хоча це може мати вигляд `switch`-інструкцій в інших мовах, зіставлення зі зразками по-справжньому розкривається, коли ми використовуємо й інші зразки. До таких зразків належить _зразок-змінна_, який дає змогу присвоїти значення змінній. У цьому прикладі змінній `i` буде присвоєно значення `number`, якщо воно не дорівнює `0`:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i -> "Non zero"
  }
}
```

У деяких випадках нам може знадобитися додати до зразка додаткову умову. Це називається _охоронною умовою_ (або _охоронним виразом_), яку можна додати за допомогою ключового слова `if`:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
  }
}
```

З міркувань продуктивності в охоронних умовах дозволені лише базові математичні та булеві оператори, інші функції в них використовувати не можна.

У наведеному вище прикладі не для всіх можливих вхідних даних знайдеться відповідний зразок. Компілятор це виявить і видасть помилку. Це називається _перевіркою вичерпності_. Щоб позбутися попередження, потрібно обробити всі випадки. Для цього можна використати _зразок-заглушку_, тобто зразок, який збігається з будь-яким значенням:

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
    _ -> "Positive number"
  }
}

// No compiler error
```

Вирази `case` перевіряють значення на відповідність кожному зразку згори донизу, доки не знайдуть відповідний зразок і не виконають логіку, повʼязану з ним. Порядок зразків має значення!
