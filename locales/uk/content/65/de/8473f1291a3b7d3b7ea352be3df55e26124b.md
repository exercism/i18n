# Докладніше

Визначення типу створює новий іменований тип, відмінний від будь-якого іншого типу, навіть якщо той має такий самий базовий тип.

## Визначення типів

Визначення типу починається з ключового слова `type`, після якого йде імʼя нового типу та його базовий тип:

```go
type File []bool
```

Тут `File` позначає одну вертикаль на шахівниці, яку зазвичай підписують літерами від A до H.
Кожну клітинку цієї вертикалі представлено булевим значенням (англ. Boolean), яке вказує, зайнята вона чи ні.
Тепер, коли `File` визначено, його можна використовувати в інших визначеннях:

```go
type Chessboard map[string]File

board := Chessboard{
    "A": File{true, false, true},
    "B": File{false, true, false},
}
```

`Chessboard` зіставляє ідентифікатори вертикалей зі значеннями `File`.
Кожен `File` містить зріз булевих значень, які позначають клітинки однієї вертикалі шахівниці.
Без цих визначень типів `board` був би `map[string][]bool`, а це ускладнило б розуміння того, що ми описуємо.

## Визначені типи є окремими

Хоча `Score` та `int` обидва зберігають цілі числа, перевести одне в одне можна лише явним перетворенням:

```go
type Score int

var number int = 42

// var score Score = number is a compile error
var score Score = Score(number)
var converted int = int(score)
```

`42` є нетипізованою константою, тому її можна присвоїти змінній типу `Score` безпосередньо.

Визначені типи також можуть мати методи, які розглядаються в концепції «Методи».

## Структурні типи

Визначення структур використовують те саме ключове слово `type`:

```go
type Player struct {
    Name  string
    Score Score
}
```

Структурні типи розглядаються в концепції «Структури».

## Псевдоніми типів

Псевдонім типу створює ще одну назву для наявного типу, а не новий тип.
Оскільки псевдонім і його початковий тип ідентичні, їхні значення можна використовувати взаємозамінно.
Псевдоніми оголошують за допомогою ключового слова `type`, імені псевдоніма, знака рівності (`=`) та наявного типу.

```go
type Square = bool

var isOccupied bool = true
var square Square = isOccupied // no conversion needed
```
