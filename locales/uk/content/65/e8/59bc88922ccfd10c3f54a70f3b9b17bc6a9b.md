# Вступ

Класи - це основний засіб для обʼєктно-орієнтованого програмування у F#.

Клас у F# складається з його полів і методів. Поля та методи класу відомі як його _члени_.

Класи у F# визначаються за допомогою ключового слова `type`. Методи визначаються за допомогою ключового слова `member` і завжди є публічними. Щоб визначити (приватні) поля, можна використати звʼязування `let`.

```fsharp
type Shoe() =
    let size = 8

    member this.Describe() = $"This is a size {size} shoe"
```

Класи - це шаблони, за допомогою яких створюють обʼєкти. Щоб створити екземпляр класу, викличмо назву класу як функцію. Екземпляр класу також відомий як _обʼєкт_.

До членів обʼєкта можна звертатися за допомогою точкової нотації.

```fsharp
let myShoe = Shoe()
myShoe.Describe()
// => "This is a size 8 shoe"
```
