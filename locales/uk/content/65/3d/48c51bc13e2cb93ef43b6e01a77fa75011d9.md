# Навчання

Цікавить почати працювати з Groovy або дізнатися більше під час роботи над вправами?

Спробуймо Groovy:

* у [браузері з онлайн-інтерпретатором](https://www.jdoodle.com/execute-groovy-online)
* у [Groovy Console](http://groovy-lang.org/groovyconsole.html), набравши `groovyConsole` у командному рядку
* у [Groovy Shell](http://groovy-lang.org/groovyconsole.html), набравши `groovysh` у командному рядку

Зробімо короткий огляд Groovy:

* [Groovy Tutorial for Java Developers](https://www.timroes.de/2015/06/27/groovy-tutorial-for-java-developers/) від Tim Rows так само добре підходить для розробників, які не працюють із Java
* [Learn X in Y minutes, Where X=Groovy ](https://learnxinyminutes.com/docs/groovy/)
* [Groovy Basics](http://docs.smartthings.com/en/latest/getting-started/groovy-basics.html) від SmartThings
* кілька [online Groovy Koans](http://www.groovy-koans.org/) від JDriven

Пориньмо глибше:

* [Groovy Documentation](http://www.groovy-lang.org/documentation.html)
* [Groovy In Action](https://www.manning.com/books/groovy-in-action-second-edition), _книга_ про Groovy
* [Making Java Groovy](https://www.manning.com/books/making-java-groovy) від Ken Kousen
