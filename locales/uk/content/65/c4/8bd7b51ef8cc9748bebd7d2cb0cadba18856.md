# Вступ

## Поведінка Access

У коді Elixir _поведінки_ задають спільні узагальнені інтерфейси, але при цьому кожен модуль, який її реалізує, може мати власну реалізацію. Один із таких поширених прикладів - це _поведінка Access_.

_Поведінка Access_ надає спільний інтерфейс для отримання даних зі структури даних, побудованої на ключах. Її реалізовано для мап і списків ключових слів, але розглянемо її використання з мапами, щоб краще зрозуміти, як це працює. _Поведінка Access_ визначає, що коли в нас є мапа, ми можемо поставити після неї _квадратні дужки_, а потім використати ключ, щоб отримати значення, повʼязане з цим ключем.

```elixir
# Suppose we have these two maps defined (note the difference in the key type)
my_map = %{key: "my value"}
your_map = %{"key" => "your value"}

# Obtain the value using the Access Behaviour
my_map[:key] == "my value"
your_map[:key] == nil
your_map["key"] == "your value"
```

Якщо ключа немає в структурі даних, то повертається `nil`. Це може стати джерелом неочікуваної поведінки, бо помилка не виникає. Зазначимо, що `nil` сам реалізує поведінку Access і завжди повертає `nil` для будь-якого ключа.
