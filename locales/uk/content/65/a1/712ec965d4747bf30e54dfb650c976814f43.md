# Класи та властивості readonly

Класи та властивості readonly дають класам змогу оголошувати публічні властивості для зручного доступу, але забороняють їх змінювати.
Щоб оголосити властивість як readonly, перед зазначенням типу потрібно додати `readonly`.
Властивості дозволено присвоїти значення лише один раз, а будь-яка спроба повторно присвоїти чи змінити значення призведе до помилки Error.

```php
<?php

class Block
{
    public function __construct(
        public readonly int $length,
        public readonly int $width,
    ) {
    }
}
```

Класи readonly розвивають цю поведінку: якщо клас оголошено як `readonly`, оголошення про доступ лише для читання застосовується до кожної його властивості.
Крім того, це унеможливлює додавання динамічних властивостей.

```php
<?php

readonly class Block
{
    public function __construct(
        public int $length,
        public int $width,
    ) {
    }
}
```
