# Внесок через GitHub

Внески до кодової бази Exercism робляться через [GitHub][github].

Як видно з назви, GitHub використовує [git][git] як систему контролю версій. Якщо ми ще не знайомі з Git, найкращий онлайн-ресурс - [Pro Git][pro-git].

Якщо ми не знайомі з GitHub і процесом внесення змін, ось кілька ресурсів, які допоможуть почати:

- [Вступ до GitHub - інтерактивний курс][github-course]
- [Як створити pull request на GitHub - посібник][pr-tutorial]
- [Як зробити простий PR на GitHub - відео від anthonywritescode][anthonywritescode]

## Посібники

Докладніше про те, як зробити свій внесок бажаним, можна прочитати в посібнику [Як зробити чудовий Pull Request][great-pr].

У нас також є кілька посібників з pull request, специфічних для Exercism:

- [Як зробити чудовий Pull Request][how-to-make-a-great-pr]
- [Посібник з pull request для контрибʼюторів][contributors-pr-guide]
- [Посібник з pull request для мейнтейнерів][maintainers-pr-guide]
- [Права доступу мейнтейнерів до репозиторію][maintainers-repo-permissions]
