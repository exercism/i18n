# Інструкції

Готуючись спекти печиво для друзів, ми виявили, що деякі міри з рецепта доведеться перевести.
Знайомі лише з метричною системою, ми маємо придумати спосіб переводити поширені американські кулінарні міри в мілілітри (мл) для власної зручності.

Скористайтеся цією таблицею переведення у своєму рішенні:

| Одиниця для переведення | обʼєм | у мілілітрах (мл) |
| --------------- | ------ | ------------------- |
| мл              | 1      | 1                   |
| чашка США       | 1      | 240                 |
| рідка унція США | 1      | 30                  |
| чайна ложка США | 1      | 5                   |
| столова ложка США | 1    | 15                  |

Будучи талановитим програмістом-початківцем, ми вирішуємо використати мілілітри як проміжну одиницю, щоб зручно переводити будь-яку одиницю з таблиці в будь-яку іншу (навіть у неї саму).

## 1. Отримати числову складову з пари обʼєму

Реалізуйте метод `KitchenCalculator.get_volume`.
Отримавши кортеж-пару обʼєму, він має повернути лише числову складову.

```crystal
KitchenCalculator.get_volume({:cup, 2.0})
# => 2.0
```

## 2. Перевести пару обʼєму в мілілітри

Реалізуйте метод `KitchenCalculator.to_milliliter`.
Отримавши кортеж-пару обʼєму, він має перевести обʼєм у мілілітри за таблицею переведення.

```crystal
KitchenCalculator.to_milliliter({:cup, 2.5})
# => {:milliliter, 600.0}
```

## 3. Перевести пару обʼєму в мілілітрах в іншу одиницю

Реалізуйте метод `KitchenCalculator.from_milliliter`.
Отримавши кортеж-пару обʼєму та потрібну одиницю, він має перевести обʼєм у потрібну одиницю за таблицею переведення.

```crystal
KitchenCalculator.from_milliliter({:milliliter, 1320.0}, :cup)
# => {:cup, 5.5}
```

## 4. Перевести з будь-якої одиниці в будь-яку

Реалізуйте метод `KitchenCalculator.convert`.
Отримавши кортеж-пару обʼєму та потрібну одиницю, він має перевести заданий обʼєм у потрібну одиницю.

```crystal
KitchenCalculator.convert({:teaspoon, 9.0}, :tablespoon)
# => {:tablespoon, 3.0}
```
