# Вступ

## Масиви

У C# структури даних, які можуть містити нуль або більше елементів, називаються _колекціями_. **Масив** - це колекція, що має фіксований розмір (довжину), усі елементи якої мають бути одного типу. Елементи можна присвоювати масиву або отримувати з нього за допомогою індексу. Масиви в C# індексуються з нуля, тобто індекс першого елемента завжди дорівнює нулю:

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true
```

Масиви також можна визначати за допомогою скороченого запису, який дозволяє одночасно створити масив і задати його значення. Оскільки тепер компілятор може визначити, скільки елементів буде в масиві, довжину можна не вказувати:

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

Масивами можна керувати, викликаючи методи чи властивості примірника масиву або використовуючи статичні методи, визначені в класі `Array`.

## Цикли `for`

Цикл `for` дозволяє повторно виконувати код, доки не виконається певна умова.

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

Цикл `for` складається з чотирьох частин:

1. Ініціалізатор: виконується один раз перед входом у цикл. Зазвичай використовується для визначення змінних, які використовуються всередині циклу.
2. Умова: перевіряється перед кожною ітерацією циклу. Цикл продовжує виконуватися, доки вона має значення `true`.
3. Ітератор: виконується після кожної ітерації циклу. Зазвичай використовується для зміни (часто: інкременту/декременту) змінних циклу.
4. Тіло: код, який виконується на кожній ітерації циклу.

## Цикли `foreach`

Те, що масив також є _колекцією_, означає, що окрім доступу до значень за індексом, можна перебрати _всі_ його значення за допомогою циклу `foreach`:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```
