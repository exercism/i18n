# Докладніше

Помилкою може бути будь-яке значення. `throw` (у `kernel`) подає сигнал; стековий ефект поточного слова відкидається, а керування передається назовні, до найближчого `recover`.

```factor
[ 0 1 / ] [ "div by zero" prepend ] recover
```

`ERROR:` - це слово розбору, яке одразу визначає і клас кортежу помилки, *і* слово-конструктор:

```factor
ERROR: not-found path ;
! defines:
!   TUPLE: not-found path ;
!   : not-found ( path -- * ) \ not-found boa throw ;
!   : not-found? ( object -- ? ) … class predicate
```

Завдяки цьому кожна власна помилка отримує унікальний клас, зручний конструктор для викидання та предикат класу (`name?`) для перевірки перехоплених помилок:

```factor
[ "/missing" not-found ]
[ dup not-found? [ path>> "missing: " prepend ] [ drop "other" ] if ]
recover
```

Про прибирання в стилі `finally` ідеться в `cleanup` із `continuations`, а про умови з перезапуском - у `condition`.
