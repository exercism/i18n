# Інструкції

Помічник режисера хоче, щоб сценарій репетиції надрукували, а кілька його частин будуються повторенням або поєднанням чогось.

Усі чотири завдання виконуються в класі `REHEARSAL_SCRIPT`.

## 1. Повторити репліку

Маючи репліку та число, повертаємо цю репліку, повторену стільки разів, нічого не додаючи між ними.

```sather
REHEARSAL_SCRIPT::repeat_cue("Ha", 3)
-- => "HaHaHa"
```

Повторення чогось нуль разів дає порожній рядок тексту (англ. string).

## 2. Ініціали акторів

Маючи список акторів, повертаємо перші літери їхніх імен, злиті докупи.

```sather
REHEARSAL_SCRIPT::initials(|"Mia", "Ana", "Ben"|)
-- => "MAB"
```

## 3. Пронумерувати рядки

Маючи рядки сцени, пронумеруймо їх від одиниці, кожен на окремому рядку.

```sather
REHEARSAL_SCRIPT::numbered_lines(|"Enter", "Exit"|)
-- => "1. Enter\n2. Exit"
```

*Між* рядками стоїть символ нового рядка, а після останнього його немає. Сцена без рядків дає порожній рядок тексту.

## 4. Прокричати рядок

Повертаємо рядок, у якому кожну літеру перетворено на велику.

```sather
REHEARSAL_SCRIPT::shout("quiet please")
-- => "QUIET PLEASE"
```
