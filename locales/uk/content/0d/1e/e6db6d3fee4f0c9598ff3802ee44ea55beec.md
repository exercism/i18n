# Вступ

## Файли

Функції для роботи з файлами надає модуль `File`.

Щоб прочитати файл повністю, використаймо `File.read/1`. Щоб записати у файл, використаймо `File.write/2`.

Щоразу, коли ми записуємо у файл за допомогою `File.write/2`, відкривається дескриптор файлу і створюється новий [процес][exercism-processes] Elixir. Тому запису у файл у циклі за допомогою `File.write/2` варто уникати.

Замість цього файл можна відкрити за допомогою `File.open/2`. Другим аргументом `File.open/2` є список режимів, який дає змогу вказати, чи відкриваємо ми файл для читання чи для запису.

`File.open/2` повертає PID процесу, який обробляє файл. Щоб читати з файлу й записувати до нього, скористаймося функціями з модуля `IO` і передамо цей PID як пристрій вводу-виводу.

Коли ми завершимо роботу з файлом, закриймо його за допомогою `File.close/1`.

Усі згадані функції з модуля `File` також мають варіант із `!`, який спричиняє помилку замість повернення кортежу помилки (наприклад, `File.read!/1`). Скористаймося цим варіантом, якщо ми не збираємося обробляти такі помилки, як відсутній файл або брак дозволів.

[exercism-processes]: https://exercism.org/tracks/elixir/concepts/processes
