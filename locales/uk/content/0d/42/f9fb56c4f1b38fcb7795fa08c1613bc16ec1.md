# Про

Класи - це фундаментальний будівельний блок програм на Swift.
Вони дають змогу обʼєднувати повʼязані властивості (дані) та методи (функції) в самодостатні одиниці функціональності.

### Визначення класів

Щоб визначити клас, використаймо ключове слово `class`, після якого йде назва класу, а саме визначення класу міститься між фігурними дужками:

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id = makeRandomID()
}
```

Тіло класу може містити збережені властивості, які визначаються та поводяться так само, як звичайні константи (`let`) чи змінні (`var`).

### Екземпляри

Визначення класу слугує кресленням: воно визначає новий тип і описує, як матимуть вигляд його значення, але саме по собі не створює жодного екземпляра.

Щоб створити *екземпляр* класу, викличмо його ініціалізатор, написавши назву класу, а потім дужки:

```swift
let someCharacter = GameCharacter()
```

Це створює новий екземпляр, властивості якого ініціалізуються типовими значеннями, заданими у визначенні класу.
Для опціональних властивостей без явних типових значень (як-от `name`) Swift типово встановлює `nil`.

### Доступ до властивостей

До властивостей екземпляра ми отримуємо доступ за допомогою *крапкової нотації*: пишемо назву екземпляра, крапку (`.`) та назву властивості.
Крапкова нотація також працює для вкладених властивостей.

Крапкову нотацію можна використовувати, щоб читати значення і, якщо властивість змінна (`var`), присвоювати нові значення:

```swift
someCharacter.name
// => nil

someCharacter.name = "Luther"
someCharacter.name
// => "Luther"

someCharacter.id = "new id"
// Error: Cannot assign to property: 'id' is a 'let' constant
```

### Методи

Окрім властивостей, класи можуть визначати *методи*, тобто функції, повʼязані з класом.

Методи визначаються всередині тіла класу за допомогою стандартного синтаксису `func`.
Якщо метод змінює властивість, цю властивість потрібно оголосити за допомогою `var`:

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id: String = makeRandomID()

    func takesDamage(_ damage: Double) {
        if damage > 100 {
            active = false
        }
    }

    func sayName() -> String {
        return "My name is \(name ?? "no one"), my class is \(characterClass ?? "undetermined")"
    }
}
```

Викликаймо методи в екземпляра за допомогою крапкової нотації, так само як і властивості:

```swift
var myChar = GameCharacter()
myChar.active = true
myChar.takesDamage(200)
myChar.active
// => false
```

### Self

Кожен екземпляр класу має неявну властивість із назвою `self`, яка вказує на сам екземпляр.
Хоча під час звернення до властивостей чи методів його часто опускають, `self` зазвичай використовують, щоб розрізняти назви властивостей і назви параметрів методу, коли вони збігаються.
