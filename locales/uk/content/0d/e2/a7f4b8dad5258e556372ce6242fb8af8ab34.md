# Доповнення до інструкцій

## Реалізація

Для виконання цієї вправи визначте тип даних `stopwatch` та реалізуйте функції:

- newStopwatch
- start
- stop
- lap
- reset
- advanceTime
- getState
- currentLap
- total
- previousLaps

Заготовка визначення типу вже є на місці, але функції потрібно визначити самостійно та створити змістовний тип даних.
