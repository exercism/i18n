# Докладніше

[Власні типи][custom-types] в Elm описують фіксовану кількість іменованих варіантів. Кожне значення відповідає рівно одному з іменованих варіантів. В інших мовах і контекстах їх називають _сумарними типами_, _дискримінованими обʼєднаннями_, _тегованими обʼєднаннями_ та _алгебраїчними типами даних_.

Кожен варіант дискримінованого обʼєднання може (необовʼязково) мати повʼязані дані, і різні варіанти можуть мати дані різних типів. Якщо жоден з варіантів не має повʼязаних даних, таке дискриміноване обʼєднання схоже на те, що в інших мовах зазвичай називають _переліком_ (або _enum_).

Власний тип визначають за допомогою ключового слова `type`, і для цього потрібно зовсім небагато синтаксису. Це одна з найважливіших технік програмування в Elm: вона дає змогу зробити так, щоб можливі значення в коді точно збігалися з допустимими значеннями в реальному житті. Завдяки цьому не залишається місця для некоректних даних, і [неможливі стани][impossible-states] неможливо подати в коді.

```elm
-- Custom Type without associated data
type Season
    = Spring
    | Summer
    | Autumn
    | Winter

-- Custom Type with associated data
type FlexibleNumber
    = Integer Int
    | Float Float
    | Invalid
```

Створити значення для конкретного варіанта можна, звернувшись до його назви (`Spring`), якщо його визначено в тому самому модулі або імпортовано синтаксисом `import SeasonModule exposing (Season(..))`, або за повністю кваліфікованим імʼям (`Season.Spring`), якщо його імпортовано синтаксисом `import SeasonModule exposing (Season)`.

```elm
integerTwo = Integer 2
invalid = FlexibleNumber.Invalid
```

Власні типи, як і все в Elm, мають _структурну рівність_: це означає, що два значення для одного й того самого варіанта з однаковими (необовʼязковими) даними еквівалентні.

Найзручніший спосіб працювати з власними типами - зіставлення зі зразком:

```elm
let describe flexibleNumber =
    case flexibleNumber of
        Integer i ->
            "Integer: " ++ fromInt(i)

        Float f ->
            "Float: " ++ fromFloat(f)

        Invalid   ->
            "Invalid"
```
