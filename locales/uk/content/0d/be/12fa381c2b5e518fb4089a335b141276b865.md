# Вступ

Функції можуть оголошувати типові значення для одного або кількох аргументів. Розглянемо цю функцію:

```elixir
def number(n \\ 13), do: "That's not my favorite"
```

Під час компіляції Elixir створює визначення функції для `number/0` (без аргументів) та `number/1` (один аргумент).

Якщо більше ніж один аргумент має типові значення, типові значення застосовуються до функції зліва направо, щоб заповнити відсутні аргументи.

Якщо функція має більше ніж один клауз, типові аргументи слід визначити в заголовку функції (функція без тіла) перед клаузами функції:

```elixir
def number(n \\ 13)
def number(n) when n < 10, do: "Dream bigger!"
def number(n) when n > 100, do: "Not that big..."
```
