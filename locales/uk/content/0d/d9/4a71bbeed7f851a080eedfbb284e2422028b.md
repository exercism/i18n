# Інструкції

Нас найняли спеціалістом із регулярних виразів у компанії, яка розробляє Chatbot.

Це лише початковий етап розробки, тож наше завдання - використати регулярні вирази, щоб Chatbot краще розумів природну мову та вмів її генерувати.

## Перевірка коректної команди

Chatbot не лише розумний, а й відданий помічник.

Щоб поставити запитання, користувач має сказати слово «**Chatbot**» на першій позиції команди.

Неважливо, чи ключове слово написане великими літерами, чи малими. Важлива тут саме позиція слова.

Реалізуйте функцію `isValidCommand()`, за допомогою якої Chatbot розпізнає, коли користувач дає команду.

```javascript
isValidCommand("Chatbot, play a song from the 80's.";
// => True
isValidCommand("Hey Chatbot, where is the closest pharmacy?";
// => False
isValidCommand("CHATBOT, do you have a solution for this challenge?";
// => True
```

## Видалення зашифрованих емодзі

Chatbot непросто розуміє, як люди використовують емодзі, щоб виражати свої емоції.

Коли Chatbot отримує повідомлення від користувача, кожне емодзі подане як «_emoji_», після чого йде його _id_.

Реалізуйте метод `removeEmoji()`, який приймає рядок тексту (англ. string) і прибирає з повідомлення все шифрування емодзі.

Рядки, у яких немає тексту емодзі, повертаються без змін.

Просто видаліть цей рядок з емодзі. Не намагайтеся коригувати пробіли.

У цьому завданні для створення регулярного виразу використайте синтаксис конструктора.

```javascript
removeEmoji("I love playing videogames emoji3465 it's one of my hobbies");
// => "I love playing videogames  it's one of my hobbies"
```

## Перевірка коректного номера телефону

Оскільки можливості Chatbot можна завантажити в мобільний застосунок, під час розмови користувач має ввести номер телефону.

Проблема в тому, що Chatbot уміє прочитати й перевірити лише номер певного формату.

Якщо номер коректний (відповідає послідовності символів, заданій **регулярним виразом**), Chatbot відповідає повідомленням, у якому дякує користувачеві й підтверджує номер. Якщо номер некоректний, функція повідомляє користувачеві, що номер телефону неправильний.

Очікуваний формат такий: (+##) ###-###-###

```javascript
checkPhoneNumber('(+34) 659-771-594');
// => "Thanks! You can now download me to your phone."
checkPhoneNumber('659-771-594');
// => "Oops, it seems like I can't reach out to 659-771-594"
```

## Отримання посилання на вебсайт

Chatbot - дуже допитлива програма. Хоча він уміє шукати в інтернеті інформацію на певну тему, йому подобається розпитувати користувачів про цікаві вебсайти чи URL-адреси, де можна знайти потрібні відомості.

Приклад розмови:

- **Chatbot**: Привіт, користувачу, я хотів би навчитися програмувати на JavaScript. Чи є цікавий вебсайт, де можна цього навчитися?
- **Користувач**: Я багато чого навчився на [exercism.org](http://exercism.org)

Реалізуйте функцію `getURL()`, яка повертає масив, що містить лише посилання на кожен вебсайт. Написати регулярний вираз, який розпізнає будь-яку URL-адресу, було б дуже складно, але Chatbot має читати лише прості URL-адреси. У цій вправі URL-адреса - це будь-яка послідовність слів, розділених `"."`.

```javascript
getURL(
  'I learned a lot from exercism.org and developer.mozilla.org, but I found ts39.es very boring!',
);
// => ["exercism.org", "developer.mozilla.org", "ts39.es"];
```

## Привітання з користувачем

Щоб зберігати дані про всіх, із ким він спілкувався, Chatbot уміє взяти повне імʼя з профілю користувача в такому вигляді: **«smith, john»**.

Так ми хочемо, щоб наш Chatbot був по-справжньому ввічливим і справляв гарне враження.

Напишіть функцію `niceToMeetYou()`, яка приймає рядок тексту з повним іменем користувача й повертає рядок **«Nice to meet you, John Smith»**

Для навчання реалізуйте функцію за допомогою **методу заміни** з регулярних виразів.

```javascript
let str = 'Smith, John';

niceToMeetYou(str);
// => "Nice to meet you, John Smith"
```
