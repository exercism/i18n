# Про

Шаблон - це рядок тексту (англ. string) або файл, який використовується для створення будь-яких вихідних даних у вигляді рядка тексту залежно від вхідних даних.

```haxe
var sample = "My name is ::name::";
var template = new haxe.Template(sample);
var myName = {name: "Joe"};
var output = template.execute(myName);

trace(output); // My name is Joe
```

Крім іншого, ми також можемо використовувати умови, щоб перевіряти всередині шаблонів:

```haxe
var sample = "::if isAwake:: I'm awake ::else:: Zzzzz ::end::";
var template = new haxe.Template(sample);
var awake = {isAwake: false};
var output = template.execute(awake);

trace(output); // Zzzzz
```
