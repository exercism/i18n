# Інструкції

У цій вправі нам потрібно реалізувати кілька функцій для роботи з масивом мов програмування.

## 1. Визначте функцію, яка повертає порожній масив мов

Визначте функцію `new`, яка не приймає аргументів і повертає порожній масив.

```haskell
new
-- -> []
```

## 2. Визначте функцію, яка додає мову до масиву

Визначте функцію `add/2`, яка приймає 2 аргументи (масив мов і рядок тексту (англ. string) з назвою _мови_).
Вона повинна повернути отриманий масив, додавши нову мову на початок переданого масиву.

```haskell
add new "Clojure"
-- -> ["Clojure"]
add ["Clojure"] "Haskell"
-- -> ["Haskell", "Clojure"]
```

## 3. Визначте функцію, яка видаляє мову з масиву

Визначте функцію `remove`, яка приймає 1 аргумент (масив мов).
Вона повинна повернути масив без першого елемента. Вважайте, що масив завжди міститиме принаймні один елемент.

```haskell
remove ["Haskell", "Clojure", "Erlang"]
-- -> ["Clojure", "Erlang"]
```

## 4. Визначте функцію, яка повертає перший елемент масиву

Визначте функцію `first`, яка приймає 1 аргумент (масив мов).
Вона повинна повернути першу мову в масиві.
Вважайте, що масив завжди міститиме принаймні один елемент.

```haskell
first ["Elixir", "Haskell", "Clojure", "Prolog"]
-- -> "Elixir"
```

## 5. Визначте функцію, яка повертає кількість мов у масиві

Визначте функцію `count`, яка приймає 1 аргумент (масив мов).
Вона повинна повернути кількість мов у масиві.

```haskell
count ["Prolog", "Elm"]
-- -> 2
```

## 6. Визначте функцію, яка перевіряє, чи є в масиві функціональна мова

Визначте функцію `isFunctionalList`, яка приймає 1 аргумент (масив мов).
Вона повинна повернути булеве значення (англ. Boolean).
Вона повинна повернути `True`, якщо _"Haskell"_ є однією з мов у масиві.

```haskell
isFunctionalList ["Haskell"]
-- -> True
```
