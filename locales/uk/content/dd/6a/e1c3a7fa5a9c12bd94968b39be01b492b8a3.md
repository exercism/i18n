# Доповнення до інструкцій

## Інструкції для цього треку

У вправі «Яхта» ми створимо дієслово, яке обчислює рахунок за один кидок пʼяти кубиків у грі «Яхта», залежно від обраної категорії.

Наше дієслово прийматиме два аргументи:

- **Лівий аргумент**: рядок тексту (англ. string), що задає категорію підрахунку, яку слід застосувати до цього кидка.
- **Правий аргумент**: масив цілих чисел, які представляють пʼять кинутих кубиків.

Визначте своє дієслово так, щоб воно приймало ці вхідні дані:

```j
  category =. 'Full House'
  dice     =. 1 3 3 3 5
  
  category scoreYacht dice
```
