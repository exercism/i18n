# Тести

Щоб запустити тести вправи за допомогою CLI, виконайте таку команду з каталогу вправи:

```bash
clojure -M:test
```

## REPL

Щоб запустити тести вправи за допомогою REPL, виконайте таку команду з каталогу вправи:

```bash
$ clojure -m cljs.main -re node
```

Потім за допомогою `require` підключіть тестовий простір імен вправи та простір імен тестів Clojure):

```clojure
;; replace <exercise> with the exercise's name
=> (require '<exercise>-test)
nil
;; and the test namespace
=> (require 'cljs.test)
```

Змініть ns на тестовий простір імен:

```clojure
;; replace <exercise> with the exercise's name
=> (ns <exercise>-test)
nil
```

Потім викличте `run-tests`:

```clojure
=> (cljs.test/run-tests)
```
