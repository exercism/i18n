# Instructions

У цій вправі ми працюватимемо з ощадними рахунками.
Щороку баланс нашого ощадного рахунку оновлюється відповідно до його відсоткової ставки.
Відсоткова ставка, яку дає нам банк, залежить від суми грошей на рахунку (його балансу):

- 3.213% для балансу, меншого за `0` доларів (баланс стає ще більш відʼємним).
- 0.5% для балансу, більшого або рівного `0` доларів, і меншого за `1000` доларів.
- 1.621% для балансу, більшого або рівного `1000` доларів, і меншого за `5000` доларів.
- 2.475% для балансу, більшого або рівного `5000` доларів.

На нас чекають чотири завдання, кожне з яких стосуватиметься балансу та його відсоткової ставки.

## 1. Обчисліть відсоткову ставку

Реалізуйте функцію `InterestRate()`, щоб обчислити відсоткову ставку за вказаним балансом:

```go
InterestRate(200.75)
// => 0.5
```

Зауважте, що повернене значення має тип `float32`.

## 2. Обчисліть відсотки

Реалізуйте функцію `Interest()`, щоб обчислити відсотки за вказаним балансом:

```go
Interest(200.75)
// => 1.003750
```

Зауважте, що повернене значення має тип `float64`.

## 3. Обчисліть річне оновлення балансу

Реалізуйте функцію `AnnualBalanceUpdate()`, щоб обчислити річне оновлення балансу з урахуванням відсоткової ставки:

```go
AnnualBalanceUpdate(200.75)
// => 201.75375
```

Зауважте, що повернене значення має тип `float64`.

## 4. Обчисліть кількість років до досягнення бажаного балансу

Реалізуйте функцію `YearsBeforeDesiredBalance()`, щоб обчислити мінімальну кількість років, потрібних для досягнення бажаного балансу, зважаючи на те, що щороку до балансу додаються відсотки.
Це означає, що баланс за один рік становить: початковий баланс + відсотки за початковий баланс.
Баланс за другий рік становить: баланс за один рік + відсотки за баланс за один рік.
І так далі, доки баланс поточного року не стане більшим або рівним цільовому балансу.

```go
balance := 200.75
targetBalance := 214.88
YearsBeforeDesiredBalance(balance, targetBalance)
// => 14
```

Зауважте, що повернене значення має тип `int`.
