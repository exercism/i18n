# Встановлення Swift

Swift доступний на macOS, Linux і Windows.
Процес встановлення залежить від операційної системи, яку ми використовуємо.
Важливо зазначити, що офіційно Swift підтримується лише на таких дистрибутивах Linux:
- Ubuntu
- Debian
- RedHat
- Fedora
- Amazon Linux

Якщо ми використовуємо інший дистрибутив Linux, доведеться самостійно знайти спосіб встановити Swift.

## Xcode (macOS)

Swift входить до складу Xcode, IDE від Apple для розробки під macOS та iOS.
Для треку Exercism нам знадобиться встановлений Xcode версії 16.0 або новішої.
Xcode безкоштовно доступний у [Mac App Store][xcode].
Інші версії Xcode (зокрема найновіша бета) можна знайти в [центрі розробників Apple][apple-developer-center].

## macOS & Linux

Для macOS і Linux існує менеджер встановлення Swift під назвою [swiftly][swiftly].
Це інструмент командного рядка, який дозволяє встановлювати кілька версій Swift у системі та керувати ними.
Команду для встановлення swiftly на macOS можна знайти [тут][swiftly-macos], а для Linux її наведено [тут][swiftly-linux].

Для macOS також можна скористатися [Homebrew][homebrew].
Для Linux можна встановити з tarball-архіву з офіційного [сайту Swift][tarball].

## Windows

Щоб встановити Swift у Windows, радимо скористатися [інсталятором WinGet][winget-windows].
Також можна встановити Swift за допомогою менеджера пакетів Scoop або вручну.
Усі варіанти описано на сторінці [Встановлення Swift для Windows][swift-windows].
