# Інструкції

Ми проводимо ігри на удачу в аркаді на морській набережній. Відвідувачі кидають кубики, автомат із захватом хапає приз, а картковий стіл потребує перетасованої колоди й розданих карт. Усе це працює на випадковості. Наприкінці вечора нам також потрібна можливість «повтору», щоб спірну гру можна було запустити знову з тим самим початковим значенням.

## 1. Кинути кубик

Визначте `roll-die`, щоб він приймав кількість сторін і повертав результат кидка в діапазоні від `1` до `sides` включно.

```factor
6 roll-die .
! => 4   (some value from 1..6)
```

## 2. Схопити приз

Визначте `pick-prize`, щоб він приймав послідовність призів і повертав один із них випадково.

```factor
{ "teddy" "goldfish" "keyring" } pick-prize .
! => "goldfish"
```

## 3. Перетасувати колоду

Визначте `shuffle-deck`, щоб він приймав колоду (послідовність) і повертав її з картами у випадковому порядку.

```factor
{ 1 2 3 4 5 } shuffle-deck .
! => { 3 1 5 2 4 }
```

## 4. Роздати карти

Визначте `deal-hand`, щоб він приймав колоду й кількість `n` і повертав `n` *різних* карт з колоди.

```factor
{ 10 20 30 40 50 } 3 deal-hand .
! => { 40 10 30 }
```

## 5. Повторний запуск із початкового значення

Визначте `play-seeded`, щоб він приймав початкове значення й quotation і запускав quotation із генератором, ініціалізованим цим цілим числом, тож те саме початкове значення завжди дає той самий результат. Результат quotation потрібно повернути тому, хто її викликає.

```factor
42 [ 6 roll-die ] play-seeded .
! => the same value every time for seed 42

! Same seed, same game:
99 [ 5 deal-hand ] play-seeded   99 [ 5 deal-hand ] play-seeded   =  .
! => t
```
