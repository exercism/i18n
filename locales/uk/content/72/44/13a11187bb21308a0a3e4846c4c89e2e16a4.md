# Вступ

У Python `None` часто використовують, щоб позначити відсутність значення: це заповнювач, який задає `null` (порожню) змінну, обʼєкт або аргумент.

Якщо ми чули про тип `NULL` або `nil` в іншій мові програмування чи користувалися ним, то це вживання `None` у Python буде нам знайомим. `None` допомагає оголосити змінні або аргументи функції, для яких у нас ще немає значень. Згодом, коли потрібно, їм можна присвоїти конкретні значення.

```python
a = None
print(a)
#=> None
type(a)
#=> <class 'NoneType'>

# Adding a Default Argument with `None`
def add_to_todos(new_task, todo_list=None):
  if todo_list is None:
    todo_list = []
    todo_list.append(new_task)
  return todo_list

```

У перевірці умови `None` обчислюється як `False`, тож він стане в пригоді, щоб визначати «наявність» чи «відсутність» значення, _будь-якого_ значення. Цей прийом часто використовують, коли функція або процес можуть повернути обʼєкт або повідомлення про помилку.

```python
a = None
if a: #=> a will be evaluated to False when its used in a conditional check.
    print("This will not be printed")
```
