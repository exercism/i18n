# Вказівки

У цій вправі ми напишемо трохи коду, щоб підготуватися до покупки транспортного засобу.

На нас чекають три завдання: визначити, чи вистачить нам грошей на щомісячні платежі; зʼясувати, які права водія нам знадобляться; та оцінити прийнятну ціну вживаного транспортного засобу.

## 1. Обчислити, чи можемо ми дозволити собі щомісячні платежі за конкретний автомобіль

Усі автодилери в нашому місті проводять пʼятирічну акцію з 0% річних, якою ми хотіли б скористатися.
Але ми не впевнені, чи зможемо дозволити собі щомісячні платежі за автомобіль, який хочемо.

Щомісячний платіж - це загальна ціна автомобіля, поділена на кількість місяців у пʼятирічному періоді.

Реалізуйте функцію `canIBuy(vehicle:price:monthlyBudget:)`, яка приймає такі аргументи:
- `vehicle` - назва транспортного засобу, який ми хочемо купити.
- `price` - ціна транспортного засобу, який ми хочемо купити.
- `monthlyBudget` - сума грошей, яку ми можемо дозволити собі платити щомісяця.

Залежно від умов функція має повернути таке повідомлення:
- Якщо щомісячний платіж за транспортний засіб менший або дорівнює щомісячному бюджету, поверніть повідомлення `"Yes! I'm getting a <vehicle>"`.
- Якщо щомісячний платіж за транспортний засіб перевищує наш щомісячний бюджет не більше ніж на 10% (включно), поверніть повідомлення `"I'll have to be frugal if I want a <vehicle>"`.
- Якщо щомісячний платіж за транспортний засіб перевищує наш щомісячний бюджет більше ніж на 10%, поверніть повідомлення `"Darn! No <vehicle> for me"`.

```swift
canIBuy(vehicle: "1974 Ford Pinto", price: 516.32, monthlyBudget: 100.00)
// returns "Yes! I'm getting a 1974 Ford Pinto"
canIBuy(vehicle: "2011 Bugatti Veyron", price: 2_250_880.00, monthlyBudget: 10000.00)
// returns "Darn! No 2011 Bugatti Veyron for me"
canIBuy(vehicle: "2020 Indian FTR 1200", price: 12_500, monthlyBudget: 200)
// returns "I'll have to be frugal if I want a 2020 Indian FTR 1200"
```

## 2. Визначити, які права водія нам знадобляться

Ми вирішили купити вживаний транспортний засіб і маємо визначити, які права водія потрібні, щоб ним керувати.

Реалізуйте функцію `licenseType(numberOfWheels:)`, яка приймає аргумент `numberOfWheels` - кількість коліс транспортного засобу, який ми хочемо купити.

Залежно від умов функція має повернути таке повідомлення:
- Якщо кількість коліс дорівнює 2 або 3, поверніть повідомлення `"You will need a motorcycle license for your vehicle"`.
- Якщо кількість коліс дорівнює 4 або 6, поверніть повідомлення `"You will need an automobile license for your vehicle"`.
- Якщо кількість коліс дорівнює 18, поверніть повідомлення `"You will need a commercial trucking license for your vehicle"`.
- Якщо це будь-яке інше число, поверніть повідомлення `"We do not issue licenses for those types of vehicles"`.

```swift
licenseType(numberOfWheels: 2)
// returns "You will need a motorcycle license for your vehicle"
licenseType(numberOfWheels: 6)
// returns "You will need an automobile license for your vehicle"
licenseType(numberOfWheels: 18)
// returns "You will need a commercial trucking license for your vehicle"
licenseType(numberOfWheels: 0)
// returns "We do not issue licenses for those types of vehicles"
```

## 3. Обчислити орієнтовну ціну вживаного транспортного засобу

Тепер, коли ми прийняли рішення, хочеться переконатися, що в автосалоні нам дадуть справедливу ціну.
Оскільки ми хочемо купити вживаний транспортний засіб, його ціна залежить від віку.
Для приблизної оцінки припустімо, що якщо транспортному засобу менше ніж 3 роки, він коштує 80% початкової ціни, яку мав, коли був новим.
Якщо йому щонайменше 10 років, він коштує 50%.
Якщо транспортному засобу щонайменше 3 роки, але не більше ніж 10 років, він коштує 70% початкової ціни.

Реалізуйте функцію `calculateResellPrice(originalPrice:yearsOld:)`, яка приймає аргументи `originalPrice` - початкова ціна транспортного засобу, та `yearsOld` - вік транспортного засобу в роках.
Функція має повернути ціну перепродажу транспортного засобу.

```swift
calculateResellPrice(originalPrice: 1000, yearsOld: 1)
// returns 800
calculateResellPrice(originalPrice: 1000, yearsOld: 5)
// returns 700
calculateResellPrice(originalPrice: 1000, yearsOld: 15)
// returns 500
```
