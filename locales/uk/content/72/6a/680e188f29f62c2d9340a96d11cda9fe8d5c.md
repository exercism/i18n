# Запуск тестів

Щоб запустити тести для вправи, запустіть скрипт `<exercise>.test` у каталозі вправи:

```bash
tclsh <exercise>.test
```

У більшості вправ усі тести, крім першого, буде позначено як «skipped».
Це дає нам змогу займатися розробкою через тестування: писати лише стільки коду, скільки потрібно, щоб пройти кожен тест по черзі.
Щоб перевизначити команди пропуску, встановіть змінну середовища `RUN_ALL` у коректне істинне значення Tcl \[1\] перед запуском набору тестів:

```bash
RUN_ALL=yes tclsh <exercise>.test
```

\[1\]: Істинні та хибні значення Tcl описано на сторінці man для функції бібліотеки C [Tcl_GetBoolean][bool].

[bool]: https://www.tcl-lang.org/man/tcl8.6/TclLib/GetInt.htm
