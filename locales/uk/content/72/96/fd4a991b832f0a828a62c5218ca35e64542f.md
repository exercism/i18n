# Детальніше

## Оператори порівняння

[Оператори порівняння][comparison-operators] порівнюють два значення одного типу й повертають значення `Bool` (`true` або `false`).
Якщо спробувати порівняти значення різних типів, компілятор видасть помилку.

Стандартні оператори порівняння у Swift:

| Оператор | Опис                     | Приклад         |
| -------- | ------------------------ | --------------- |
| `==`     | дорівнює                 | `1 == 1` (true) |
| `!=`     | не дорівнює              | `1 != 2` (true) |
| `<`      | менше                    | `4 < 5`  (true) |
| `<=`     | менше або дорівнює       | `4 <= 4` (true) |
| `>`      | більше                   | `3 > 1`  (true) |
| `>=`     | більше або дорівнює      | `2 >= 2` (true) |

## Умовні конструкції `if` та `else`

[Умовна конструкція][conditional-statement] виконує код залежно від того, чи умова набуває значення `true` або `false`.
Найпоширеніша умовна конструкція - це [умовний оператор `if`][if], який виконує блок коду лише тоді, коли його умова має значення `true`.
Щоб записати оператор `if`, ми використовуємо ключове слово `if`, після якого йде умова, а далі блок коду, узятий у фігурні дужки:

```swift
let wheelCount = 4
if wheelCount == 4 {
    print("Your vehicle is a car")
}
// Prints "Your vehicle is a car"
```

Ми можемо поєднати `if` з гілкою `else`, щоб виконати альтернативний код, коли умова має значення `false`:

```swift
let precipitationInMM = 0.5
if precipitationInMM > 0.5 {
    print("You will need an umbrella")
} else {
    print("You will not need an umbrella")
}
// Prints "You will not need an umbrella"
```

Щоб перевірити кілька умов послідовно, обʼєднаймо оператори в ланцюжок за допомогою `else if`.
Оператор `if` не потребує гілки `else`, але її можна додати, щоб обробити випадки, коли жодна з умов не збігається:

```swift
let favoriteFruit = "Apple"

if favoriteFruit == "Banana" {
    print("Your favorite fruit is a banana")
} else if favoriteFruit == "Orange" {
    print("Your favorite fruit is an orange")
} else if favoriteFruit == "Apple" {
    print("Your favorite fruit is an apple")
} else {
    print("Your favorite fruit is not a banana, orange, or apple")
}
// Prints "Your favorite fruit is an apple"
```

## Вирази `if`

У сучасному Swift оператори `if` можна також використовувати як вирази, що дають значення.
Кожна гілка набуває певного значення, тож результати можна легко присвоювати залежно від умови:

```swift
let cpuBits = 32
let architecture = if cpuBits == 64 {
    "x86_64"
} else {
    "x86_32"
}

print(architecture)
// Prints "x86_32"
```
