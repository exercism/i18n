# Вступ

`call` (у [`kernel`][kernel]) виконує quotation. Коли стековий ефект quotation неможливо вивести, зазвичай тому, що quotation походить з іншого місця, оголосимо ефект для `call` явно:

```
call( stack-effect ) ! e.g. call( a b -- c )
```

```factor
3 4 [ + ] call .                 ! => 7
3 4 [ + ] call( a b -- c ) .     ! => 7

: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .         ! => 2
```

Оскільки quotation належить до значень, масив може містити суміш чисел і quotation, тож «програма» стає просто ще однією послідовністю:

```factor
{ [ 1 + ] [ 2 * ] } 5 swap [ call( x -- y ) ] each .   ! 5 -> 6 -> 12
```

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
