# Вказівки

Якщо ми хочемо щось зібрати за допомогою Raspberry Pi, нам, імовірно, знадобляться _резистори_.
Для цієї вправи нам потрібно знати про них дві речі:

- Кожен резистор має значення опору.
- Резистори маленькі, настільки маленькі, що якби ми надрукували на них значення опору, його було б важко прочитати.

Щоб обійти цю проблему, виробники наносять на резистори кольорові смуги, які позначають їхні значення опору.
Кожна смуга має позицію та числове значення.

Перші 2 смуги резистора мають просту схему кодування: кожен колір відповідає одному числу.

Третя смуга виконує роль множника.

У цій вправі ми створимо корисну програму, щоб нам не доводилося запамʼятовувати значення смуг.

Більше інформації про кольорове кодування резисторів можна знайти в [статті Вікіпедії про електронний кольоровий код][e-color-code].

## 1. Визначте іменований вектор

Кольори кодуються так:

- black: 0
- brown: 1
- red: 2
- orange: 3
- yellow: 4
- green: 5
- blue: 6
- violet: 7
- grey: 8
- white: 9

Створіть іменований вектор `resistor_bands`, у якому назвами є кольори, а значеннями - числа.

## 2. Поверніть значення, повʼязане зі смугою

Спершу нам треба вміти знаходити єдине значення для будь-якої кольорової смуги.

Визначте функцію `band_value(band)`, яка приймає `string` з кольором смуги.
Функція повертає відповідне значення для цього кольору.

```R
band_value("green")
# => [1] 5

band_value("violet")
# => [1] 7
```

## 3. Поверніть значення, повʼязане з двома смугами

Перші дві смуги резистора обʼєднуються, утворюючи одне число.
Якщо перші дві смуги мають відповідно числа `m` та `n`, то разом вони утворюють одне число `mn`.

Визначте функцію `two_band_value(bands)`, яка приймає `vector` з двох `string` з кольорами смуг.
Функція повертає відповідне значення для комбінації цих двох кольорів.

```R
two_band_value(c("yellow", "red"))
# => [1] 42

two_band_value(c("green", "violet"))
# => [1] 57
```

## 4. Поверніть опір в омах для всіх трьох смуг

Нарешті, потрібно буде знайти повний опір в омах, поєднуючи перші дві смуги з третьою.
Для цього потрібно знайти значення перших двох смуг і множник.
Множник можна уявити як кількість нулів, дописаних до значення перших двох смуг.

Визначте функцію `ohms(bands)`, яка приймає `vector` з трьох `string` з кольорами смуг.
Функція повертає відповідний опір в омах для комбінації цих трьох кольорів.

```R
ohms(c("yellow", "red", "orange"))
# => [1] 42000

ohms(c("green", "violet", "yellow"))
# => [1] 570000
```
