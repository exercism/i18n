# Встановлення

## Встановлення середовища виконання R
Відвідайте [головну сторінку CRAN](https://cran.r-project.org/). Там можна знайти посилання для завантаження для Linux, Mac OSX і Windows. Завантажте та запустіть інсталятор для своєї операційної системи.

## Встановлення RStudio IDE (рекомендовано)
RStudio - популярне кросплатформне інтегроване середовище розробки (IDE) для програмування мовою R (а також підтримує інші мови, як-от Python, JavaScript і Markdown). Використання RStudio полегшить написання розвʼязків коду та запуск тестів.

Завантажте та встановіть [поточну стабільну версію RStudio](https://www.rstudio.com/products/rstudio/download/). Або, як альтернативу, візьміть [попередню версію](https://www.rstudio.com/products/rstudio/download/preview/) майбутнього випуску.

## Встановлення розширення R для Visual Studio Code (альтернатива)
Розширення R для Visual Studio Code підтримує розширене підсвічування синтаксису, автодоповнення коду, лінтинг, форматування, взаємодію з терміналами R, перегляд даних, графіків, змінних робочого простору, сторінок довідки, керування пакетами та роботу з документами R Markdown.

Завантажте та встановіть [поточну версію розширення R](https://code.visualstudio.com/docs/languages/r)

## Встановлення пакетів R для запуску тестів
Для запуску тестів специфікацій використовується бібліотека [`testthat`](https://github.com/hadley/testthat) від Гедлі Вікгема, популярний вибір серед авторів пакетів R.

Щоб установити цю бібліотеку, введіть наведене нижче у консолі RStudio (або будь-де, де використовується R).

```{R}
install.packages("testthat")
```

Хоча малоймовірно, що _доведеться_ встановлювати пакети, щоб розвʼязувати задачі Exercism, можливо, захочеться залучити універсальний службовий пакет, як-от [`tidyverse`](https://github.com/tidyverse/tidyverse), що пасує стилю програмування. Щоб установити та завантажити такий пакет, як `tidyverse`:

```{R}
install.packages("tidyverse")
library(tidyverse)
```
