# Вступ

## Початок роботи

### Змінні

Значення можна повʼязати з іменами, визначивши [змінну][constants-variables] і присвоївши цій змінній значення.
Потім це імʼя можна використовувати, щоб посилатися на це значення в усій програмі.
Змінні є _змінюваними_, тобто їхнє значення можна змінити будь-коли.

Змінні визначають за допомогою ключового слова `var`.

```swift
var variableName = 10
```

Swift належить до мов із суворою статичною типізацією, а це означає, що всі значення мають тип під час компіляції.
Ми можемо або явно вказати тип змінної за допомогою [анотацій типу][type annotations], або дозволити компілятору [вивести тип][type-inferring].

```swift
var explicitVar: Int = 10 // Explicitly typed
var implicitVar = 10      // Implicitly typed
```

Щоб оновити значення змінної, використовуємо оператор `=`.

~~~~exercism/note
Тип змінної фіксується, щойно її визначено.

```swift
variableName = 13 // update to new value

// compiler error when assigning a different type
variableName = "Hello, world!" // Cannot assign value of type 'String' to type 'Int'
```
~~~~

Змінну можна оголосити без присвоєння значення, вказавши імʼя та тип, але не можна використовувати її до того, як їй присвоєно значення.

```swift
var someInt: Int

// This would trigger a compiler error
// print(someInt) // Variable 'someInt' used before being initialized

// Assign a value to the names
someInt = 169

print(someInt) // Prints '169'
```

### Константи

[Константи][constants-variables] схожі на змінні: вони теж повʼязані з іменем і значенням, але значення константи не можна змінити після початкового присвоєння, тобто вона є _незмінною_.
Константи визначають за допомогою ключового слова `let`.

```swift
let constantName = 10          // constant
let explicitConstant: Int = 10 // Explicitly typed constant
```

### Додавання, віднімання та множення

У Swift є [оператори][arithmetical-operators] для додавання, віднімання та множення.
Це оператори `+`, `-` і `*` відповідно.
  
```swift
print(1 + 1) // Prints 2
print(2 - 1) // Prints 1
print(2 * 2) // Prints 4
```

### Функції

У Swift функцією називають частину коду, яка виконує певне завдання.
Функція має тип повернення, тому її можна використовувати як значення і передавати як аргумент іншим функціям.
У Swift функції визначають за допомогою ключового слова `func`, після якого йде назва функції, аргументи, розділені комами, і тип повернення.

Аргументи визначаються міткою аргументу, назвою параметра, після якої йде двокрапка, а потім тип.
Тип повернення визначається знаком `->`, після якого йде тип поверненого значення.

```swift
func functionName(argumentName parameterName: ArgumentType) -> ReturnType {
  // function body
}
```

Аргументи в Swift дещо особливі порівняно з іншими мовами: вони використовують [мітки аргументів][argument-labels].
Мітку аргументу використовують під час виклику функції.
Назву параметра використовують усередині тіла функції, щоб посилатися на значення аргументу.
Якщо аргументу призначити лише одне імʼя, його використають і як мітку аргументу, і як назву параметра.
Якщо ж як мітку аргументу вказати `_`, то під час виклику функції аргумент не матиме мітки, наприклад: `functionName(argumentValue)`

Щоб викликати функцію, використовують назву функції, після якої йдуть мітка аргументу та значення аргументу, ось так:

```swift
func functionName(argumentLabel parameterName: ArgumentType) -> ReturnType {
  // function body
}

// calling the function
functionName(argumentLabel: argumentValue)
```

Усі аргументи типово є незмінними, і їх не можна змінити всередині функції.
Якщо функція має тип повернення, слід повернути значення цього типу.
Це роблять за допомогою ключового слова `return`, після якого йде значення для повернення.

```swift
func addTen(number value: Int) -> Int {
  return value + 10
}

// calling the function
addTen(number: 10) // Returns 20
```

Коли функції не повертають значення, вони мають тип повернення `Void`, що те саме, що й `()`, але в таких випадках тип повернення можна й опустити.

### Коментарі

Swift підтримує два типи [коментарів][comments].
Однорядкові коментарі починаються з `//`, а багаторядкові вставляють між `/*` та `*/`.
