# Докладніше

Функції можуть оголошувати [типові значення][default-arguments] для одного або кількох аргументів.

```elixir
def number(n \\ 13), do: "That's not my favorite"
```

- Під час компіляції наведеного вище прикладу Elixir створює визначення функції `number/0` (без аргументів) і `number/1` (з одним аргументом).
- Якщо типові значення оголошено для більш ніж одного аргументу, вони застосовуються до функції зліва направо, щоб заповнити пропущені аргументи.
- Якщо функція має кілька клозів, для типових аргументів потрібно написати [заголовок функції][function-header].
- Типовим значенням може слугувати будь-який вираз.
- Анонімні функції не можуть мати типових аргументів.

```elixir
def guess(number \\ 5)
def guess(number) when number != 5, do: false
def guess(number) when number == 5, do: true

guess()
# => true
```
