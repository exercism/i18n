# Інструкції

У цій вправі ми будемо писати код, який аналізує виробництво на складальній лінії автомобільного заводу. Швидкість складальної лінії може бути від `0` (вимкнено) до `10` (максимум).

За найнижчої швидкості (`1`) щогодини виробляється `221` автомобіль. Зі зростанням швидкості виробництво зростає лінійно. Тож за швидкості `4` має вироблятися `4 * 221 = 884` автомобілі на годину. Однак вищі швидкості підвищують імовірність появи бракованих автомобілів, які потім доводиться вибраковувати. Наступна таблиця показує, як швидкість впливає на відсоток успішних автомобілів:

- Від `1` до `4`: 100% успішних автомобілів.
- Від `5` до `8`: 90% успішних автомобілів.
- `9`: 80% успішних автомобілів.
- `10`: 77% успішних автомобілів.

Попереду два завдання.

## 1. Обчисліть продуктивність за годину

Реалізуйте метод `CarsAssemble.productionRatePerHour()`, щоб обчислити продуктивність складальної лінії за годину з урахуванням поточної швидкості лінії та відсотка успішних автомобілів:

```Java
CarsAssemble.productionRatePerHour(6)
// => 1193.4
```

Зверніть увагу, що повернене значення має тип `double`.

## 2. Обчисліть кількість робочих автомобілів, вироблених за хвилину

Реалізуйте метод `CarsAssemble.workingItemsPerMinute()`, щоб обчислити, скільки робочих автомобілів виробляється за хвилину:

```Java
CarsAssemble.workingItemsPerMinute(6)
// => 19
```

Зверніть увагу, що повернене значення має тип `int`.
