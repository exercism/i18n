# Char

`Char` — це тип даних у Crystal, який представляє 32-бітну кодову точку [Unicode][unicode].
Їхній розмір робить їх економними щодо памʼяті та надає їм особливих властивостей, яких не мають рядки тексту (англ. string).
Символи створюють за допомогою одинарних лапок (`'`), і всередину можна вмістити лише одну кодову точку Unicode.

```crystal
'a' # => 'a'
'a'.class # => Char
```

У Crystal, працюючи з рядками тексту, досить часто доводиться мати справу із символами, адже чимало методів класу String повертають символи або приймають їх як аргументи.
Наприклад, метод [`String#[]`][index] повертає символ, а метод [`String#chars`][chars] повертає колекцію символів.

## Інкремент і декремент

Оскільки `Char` представляє 32-бітну кодову точку Unicode, символи підтримують інкремент і декремент. Це означає, що, маючи `'a'`, ми можемо отримати `'b'`, додавши одиницю.

```crystal
'a' + 5
# => 'f'

'z' - 25
# => 'a'
```

Є також метод [`Char#succ`][succ], який повертає наступний символ у таблиці Unicode, і метод [`Char#pred`][pred], який повертає попередній символ у таблиці Unicode.

```crystal
'a'.succ
# => 'b'

'z'.pred
# => 'y'
```

## Конкатенація

Оскільки `Char` призначений лише для представлення 32-бітної кодової точки Unicode, два символи не можна зʼєднати.
Тому символи можна зʼєднувати лише з рядками тексту.

```Crystal
'a' + "bc"
# => "abc"

'a' + 'b'
# => error: expected argument #1 to 'Char#+' to be Int or String, not Char
```

## Методи для визначення властивостей

У Crystal є кілька методів, які дають змогу дізнатися більше про символ: наприклад, чи є він числом або літерою, чи записаний у верхньому або нижньому регістрі.
Ось перелік деяких методів; повний перелік можна знайти в [Char API][char-api]:

| Метод                            | Опис                                                |
| -------------------------------- | --------------------------------------------------- |
| [`Char#number?`][number]         | Повертає `true`, якщо символ є числом               |
| [`Char#letter?`][letter]         | Повертає `true`, якщо символ є літерою              |
| [`Char#lowercase?`][lowercase]   | Повертає `true`, якщо символ у нижньому регістрі    |
| [`Char#uppercase?`][uppercase]   | Повертає `true`, якщо символ у верхньому регістрі   |
| [`Char#ascii?`][ascii]           | Повертає `true`, якщо символ належить до ASCII      |
| [`Char#whitespace?`][whitespace] | Повертає `true`, якщо символ є пробільним           |

## Перетворення

### Перетворення між кодовими точками та символами

Оскільки `Char` представляє 32-бітну кодову точку Unicode, символи можна перетворювати на кодові точки (Int) і навпаки.
Зробити це можна за допомогою методу [`Char#ord`][ord], який повертає кодову точку символу, або методу [`Int#chr`][chr], який повертає символ за його кодовою точкою.

```crystal
'a'.ord
# => 97

97.chr
# => 'a'
```

### Перетворення між типами

Як і в інших типів даних, у символів є кілька методів для перетворення між типами.
Найчастіше з них використовують метод `Char#to_s`, який перетворює символ на рядок тексту. Крім нього, є метод `Char#to_i`, який перетворює символ на Int, і метод `Char#to_f`, який перетворює символ на Float.

```crystal
'a'.to_s
# => "a"

'4'.to_i
# => 4

'a'.to_i
# => Error: Invalid integer: a (ArgumentError)
```

## Екранування

Як і з рядками тексту, деякі символи неможливо записати безпосередньо, і щоб їх записати, потрібно їх екранувати.
Для запису екранувальної послідовності використовують символ `\`, за яким іде символ, який потрібно екранувати.

Ось спеціальні символи в Crystal:

| Значення | Опис                              |
| -------- | --------------------------------- |
| `\a`     | Звуковий сигнал                   |
| `\b`     | Повернення на один символ назад   |
| `\e`     | Escape                            |
| `\f`     | Подача сторінки                   |
| `\n`     | Переведення рядка або новий рядок |
| `\r`     | Повернення каретки                |
| `\t`     | Горизонтальна табуляція           |
| `\v`     | Вертикальна табуляція             |
| `\\`     | Зворотна коса риска               |
| `\'`     | Одинарна лапка                    |
| `\"`     | Подвійна лапка                    |
| `\377`   | Вісімковий символ ASCII           |
| `\xFF`   | Шістнадцятковий символ ASCII      |
| `\uFFFF` | Шістнадцятковий символ Unicode    |
