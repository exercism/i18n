# Вступ

## Булеві значення в R

Значення правди та неправди — це булеві значення (англ. Boolean); їх представляє тип `logical`.
Він містить лише два значення: `TRUE` і `FALSE`.

```R
TRUE
#> [1] TRUE
FALSE
#> [1] FALSE
typeof(TRUE)
#> [1] "logical"
```

## Булеві оператори

У R є пʼять булевих операторів, але на цьому етапі силабусу важливі лише три.
Решта два будуть важливими під час роботи з векторами, які розглянемо в кількох наступних концепціях.

`&&` (логічне і) — оператор булевого «і».
Він обчислюється в `TRUE`, якщо вирази з *обох* боків від `&&` дорівнюють `TRUE`.

```R
TRUE && TRUE
#> [1] TRUE
TRUE && FALSE
#> [1] FALSE
```

`||` (логічне або) — оператор булевого «або».
Він обчислюється в `TRUE`, якщо вираз з *будь-якого* боку від `||` дорівнює `TRUE`.

```R
TRUE || TRUE
#> [1] TRUE
FALSE || TRUE
#> [1] TRUE
```

`!` — оператор логічного заперечення.
Він міняє місцями значення `TRUE` і `FALSE`.

```R
!TRUE
#> [1] FALSE
!FALSE
#> [1] TRUE
```

Для довших і складніших виразів краще використовувати дужки, щоб намір був зрозумілим.

```R
(TRUE || FALSE) && (FALSE && TRUE)
#> [1] FALSE

TRUE || FALSE && (FALSE && TRUE)
#> [1] TRUE
```
