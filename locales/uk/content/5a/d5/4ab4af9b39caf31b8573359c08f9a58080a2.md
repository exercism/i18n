# Вказівки

Наше завдання - знайти ідеальну розсадку за столом.
Зробимо це, визначаючи _факти_ (те, що завжди правдиве) і _правила_ (те, що правдиве за певних умов).

## 1. Перелічіть балакучих людей

Визначте факт `chatty`, який позначає балакучих людей.
Факт `chatty` приймає один аргумент: імʼя балакучої людини, записане малими літерами.

```prolog
chatty(gustavo).
true.
```

## 2. Перелічіть, хто кому подобається

Визначте факт `likes`, який позначає, хто кому подобається.
Факт `likes` приймає два аргументи:

1. Імʼя людини, якій подобається інша людина, записане малими літерами
2. Імʼя людини, яка подобається, записане малими літерами

```prolog
likes(esteban, malena).
true.
```

## 3. Люди, які подобаються одне одному, утворюють хорошу пару

Визначте правило `pairing` так, щоб воно було правдивим, коли двоє людей подобаються одне одному.
Правило `pairing` приймає два аргументи:

1. Імʼя першої людини, записане малими літерами
2. Імʼя другої людини, записане малими літерами

```prolog
pairing(malena, esteban).
true.
```

## 4. Балакучі люди утворюють пару з будь-ким

Визначте правило `pairing` так, щоб воно було правдивим, коли (принаймні) одна з двох людей у парі балакуча.

```prolog
pairing(valeria, jaime).
true.
```

## 5. Перевірте розсадку

Визначте правило `seating` так, щоб воно було правдивим, коли всі пʼять пар утворюють хороші пари.

Правило `pairing` приймає пʼять аргументів:

1. Імʼя першої людини, записане малими літерами
2. Імʼя другої людини, записане малими літерами
3. Імʼя третьої людини, записане малими літерами
4. Імʼя четвертої людини, записане малими літерами
5. Імʼя пʼятої людини, записане малими літерами

Скористайтеся щойно визначеними фактами і правилами, щоб перевірити розсадку.

```prolog
seating(esteban, jaime, gustavo, malena, valeria).
false.
```
