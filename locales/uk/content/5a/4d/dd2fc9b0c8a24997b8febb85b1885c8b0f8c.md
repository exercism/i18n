# Вступ

Блок - це набір інструкцій та оголошень, обʼєднаних в одну синтаксичну одиницю.
Блоки часто, але не завжди, визначають у фігурних дужках.
Блоки можна вкладати у функції та в інші блоки.

Функція поводиться дещо подібно до блоку.
Ідентифікатор змінної, визначеної у функції, не видно за межами функції, так само як ідентифікатор змінної, визначеної в блоці, не видно за межами блоку.
Дві змінні у двох функціях можуть мати однакову назву, бо ці дві функції не бачать одна одну, так само як дві змінні у двох блоках можуть мати однакову назву, бо ці два блоки не бачать один одного.
Але функції та блоки не тотожні.
Функцію не можна вкласти в іншу функцію, а блок можна вкласти в інший блок.

У наступному прикладі `number` визначено у функції `main`.
`flag` визначено в блоці `if`, вкладеному у функцію `main`.
Змінні, визначені в блоці, дійсні лише в межах цього блоку.
Тож спроба скомпілювати цей код призводить до помилки компіляції.

```c
#include <stdio.h>

int main() {

  int number = 1;

  if (number == 1) {
      int flag = 1;
      printf("%d", flag);
  }

  // this line generates a compilation error
  // error: 'flag' undeclared (first use in this function)
  printf("%d", flag);
    
}
```

Повідомлення про помилку може збивати з пантелику, адже `flag` _справді_ використовується раніше у функції.
Однак `flag` визначено в блоці всередині функції.
Внутрішній блок може «бачити» змінну `number` у зовнішній функції, але зовнішня функція не може «бачити» змінну `flag`, визначену в її внутрішньому блоці.
Щойно виконання виходить за межі блоку, змінна `flag` автоматично знищується і більше не доступна програмі.
Сама функція `main` уперше бачить ідентифікатор `flag` в останній інструкції `printf`.
Якщо прибрати останню інструкцію `printf`, програма скомпілюється і під час запуску надрукує `1`.
Це тому, що змінна `flag` дійсна в блоці, який містить першу інструкцію `printf`.

Починаючи з `C99`, однорядкові інструкції `if`, `for`, `while` і `do` також вважаються блоками.
У наступному прикладі, хоча `i` й не визначено у фігурних дужках, ця змінна існує лише в блоці, визначеному інструкцією `for`, і не видима для зовнішньої функції `main`.

```c
#include <stdio.h>

int main() {

    for (int i = 0, j = 11; i < j; i+=2)
        printf("%d", i);

    // this line generates a compilation error
    // error: 'i' undeclared (first use in this function)
    printf("%d", i);
    
}
```

Якщо прибрати останню інструкцію `printf`, програма скомпілюється і під час запуску надрукує `0 2 4 6 8 10 `.
Деякі мови, як-от Go та Rust, прямо зазначають, що однорядкові умовні конструкції та цикли утворюють блок.
Вони вимагають, щоб такі однорядкові інструкції все одно були взяті у фігурні дужки.
