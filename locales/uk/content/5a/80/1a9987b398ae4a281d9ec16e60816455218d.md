# Вступ

Elixir підтримує чимало функцій для роботи з бітами, які містяться в _модулі Bitwise_.

- `band/2`: побітове І
- `bsl/2`: побітовий зсув ліворуч
- `bsr/2`: побітовий зсув праворуч
- `bxor/2`: побітове виключне АБО
- `bor/2`: побітове АБО
- `bnot/1`: побітове заперечення

Ось приклад використання побітової функції:

```elixir
Bitwise.bsl(1, 3)
# => 8
```

Усі побітові функції працюють лише з цілими числами.

Якщо використовується Elixir версії 1.9 або нижче, потрібно викликати `require Bitwise` на початку визначення модуля, щоб мати змогу користуватися модулем _Bitwise_.
