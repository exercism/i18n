# Інструкції для SQLite

* Стовпець **digits** містить список цілих чисел, закодований у JSON.
  Приклад:
  ```json
  [1,0,1,0,1,0]
  ```
* Стовпець **result** має містити дані, закодовані у JSON: обʼєкт, у якому цифри є цілими числами, або опис будь-яких помилок.
  Приклади:
  ```json
  {"digits":[1,0,1,0,1,0]}
  ```
  або
  ```json
  {"error":"some error description"}
  ```

## Схема таблиці

```sql
CREATE TABLE IF NOT EXISTS "all-your-base" (
  input_base  INTEGER NOT NULL,
  digits      TEXT    NOT NULL, -- json array
  output_base INTEGER NOT NULL,
  result      TEXT              -- json object
);
```
