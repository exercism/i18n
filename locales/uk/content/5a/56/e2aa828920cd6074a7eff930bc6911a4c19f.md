# Інструкції

Мері дуже любить серіал _Star Trek: The Next Generation_. Вона часто грає в настільні рольові ігри, де разом із друзями вдає себе за екіпаж _Starship Enterprise_. Мері грає капітана Пікара, тож їй доводиться вести капітанський журнал. Їй подобається творча частина гри, але не подобається придумувати випадкові дані на ходу.

Допоможіть Мері: створіть генератори випадкових даних для того, що часто трапляється в капітанському журналі.

## 1. Згенерувати випадкову планету

_Starship Enterprise_ під час своїх подорожей зустрічає багато планет. Планети у всесвіті Star Trek поділяються на категорії за своїми властивостями. Наприклад, Земля належить до планет класу M. Усі можливі класи планет: D, H, J, K, L, M, N, R, T і Y.

Реалізуйте функцію `random_planet_class/0`. Вона має повертати один із класів планет випадковим чином.

```elixir
CaptainsLog.random_planet_class()
# => "K"
```

## 2. Згенерувати випадковий реєстраційний номер зорельота

У космосі літає не лише Enterprise (реєстраційний номер NCC-1701)! Коли він зустрічає інший зореліт, Мері треба занотувати реєстраційний номер цього зорельота.

Реєстраційні номери починаються з префікса «NCC-», після якого йде число від 1000 до 9999 (включно).

Реалізуйте функцію `random_ship_registry_number/0`, яка повертає випадковий реєстраційний номер зорельота.

```elixir
CaptainsLog.random_ship_registry_number()
# => "NCC-1947"
```

## 3. Згенерувати випадкову зоряну дату

Який сенс у журналі, якщо в ньому немає дат?

Зоряна дата - це число з плаваючою комою. Пригоди _Starship Enterprise_ з першого сезону _The Next Generation_ відбуваються між зоряними датами 41000.0 і 42000.0. «4» означає 24-те століття, а «1» - перший сезон.

Реалізуйте функцію `random_stardate/0`, яка повертає число з плаваючою комою від 41000.0 (включно) до 42000.0 (не включно).

У реалізації слід використати функцію Erlang.

```elixir
CaptainsLog.random_stardate()
# => 41458.15721310934
```

## 4. Відформатувати зоряну дату

У капітанському журналі зоряні дати зазвичай округлюють до одного знака після коми.

Реалізуйте функцію `format_stardate/1`, яка приймає число з плаваючою комою і повертає рядок тексту (англ. string) із цим числом, округленим до одного знака після коми.

У реалізації слід використати функцію Erlang.

```elixir
CaptainsLog.format_stardate(41458.15721310934)
# => "41458.2"
```
