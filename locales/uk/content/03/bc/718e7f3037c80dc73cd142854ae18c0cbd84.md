# Вступ

Ми побачили в концепції `Vectors`, що вектор можна використати в умовному виразі, отримавши логічний вектор.
Його, своєю чергою, можна використати у функціях, як-от `all()` і `any()`.

```R
v <- c(4, 7, 10)
v >= 6
#> [1] FALSE  TRUE  TRUE
all(v > 6)
#> [1] FALSE    # not all elements match this condition
any(v > 6)
#> [1] TRUE     # at least one element matches
```

Але цей прийом значно потужніший, ніж здається.

## Підмножини вектора

Вибрані елементи вектора можна витягти за номером індексу або за вектором індексів:

```R
v <- 5:10
v
#> [1]  5  6  7  8  9 10
v[3] 
#> [1] 7
v[c(2, 4)]
#> [1] 6 8
```

Або ж відфільтруймо початковий вектор логічним вектором, щоб отримати підмножину елементів, які відповідають значенню `TRUE`:

```R
v <- 1:3
bools <- c(FALSE, TRUE, TRUE)
v[bools]
#> [1] 2 3
```

Звідси вже один крок до того, щоб згенерувати логічний вектор за допомогою умовного виразу:

```R
bools <- v >= 2
bools
#> [1] FALSE  TRUE  TRUE

v[bools]
#> [1] 2 3

# simpler form
v[v >= 2]
#> [1] 2 3
```

## Пошук індексів

Функція `which()` приймає логічний аргумент і повертає вектор індексів, які дають `TRUE`.

```R
v
#> [1] 2 7 9

v[v > 5]  # returns values
#> [1]  7  9

which(v > 5) # returns indices
#> [1] 2 3
```

## Перевірка наявності елемента

У попередніх розділах ішлося про пошук елементів, які відповідають певному критерію.

Якщо нам лише потрібно дізнатися, чи містить вектор конкретний елемент, використовується оператор `%in%`.

```R
3 %in% 1:5
#> [1] TRUE
7 %in% 1:5
#> [1] FALSE
```

Це функціонально рівнозначно наступному коду, але значно зручніше:

```R
v <- 1:5
length(v[v == 3]) > 0
#> [1] TRUE
```
