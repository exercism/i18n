# Інструкції

Компанія, у якій ми працюємо, хоче зменшити свій вуглецевий слід, тож хоче, щоб ми написали програму для обчислення споживання електроенергії та вартості роботи їхніх електроприладів.

## 1. Отримати додаткові години

У роботодавця є програма, яка обчислює час роботи різних електроприладів.
Наразі час зберігається в годинах.
Коли роботодавець додав години, він помітив, що тривалість часу неправильна.
Він хоче, щоб ми додали 3 додаткові години до даних про час.
Він також хотів би знати, скільки «додаткових» годин залишиться після переведення даних у «повні» дні (у добі 24 години).
Час, який потрібно перевести, може не становити повних днів.

Реалізуйте функцію `get_extra_hours()`, яка приймає ціле число, у якому зберігається кількість годин.
Функція повинна виконати відповідне коригування «додаткових годин», а потім повернути (`return`) ціле число, яке показує, скільки годин потрібно відняти від загальної кількості, щоб отримати час у «повних» днях.

```python
>>> get_extra_hours(25)
4
```

## 2. Отримати значення в кВт

Роботодавець хоче знати споживання електроенергії різних електроприладів у кВт.
кВт означає кіловат, а вати - це одиниця потужності.
Кіло в назві одиниці - це префікс метричної системи, що означає 1000.
Один кіловат == 1000 ват.

Реалізуйте функцію `get_kW_value()`, яка приймає ціле число, у якому зберігається кількість ват.
Тоді функція повинна повернути (`return`) вати як кіловати, округлені до 1 знака після коми.

```python
>>> get_kW_value(1150)
1.2
```

## 3. Отримати значення в кВт·год

Щоб обчислити вартість роботи електроприладів, роботодавцю потрібно знати споживання електроенергії в кВт·год.
кВт·год означає кіловат-годину, де година - це одиниця часу.
Одна кіловат-година == 1000 ват, використаних за 1 годину.
Година складається з 60 хвилин, а хвилина - з 60 секунд.
Одна година дорівнює 3600 секундам.
Щоб обчислити значення в кВт·год, потрібно перевести вати в кВт, а потім націло поділити результат на 3600.

Реалізуйте функцію `get_kWh_value()`, яка приймає ціле число, у якому зберігається кількість ват.
Тоді функція повинна повернути (`return`) кіловат-години як ціле число.

```python
>>> get_kWh_value(5000000)
1
```

## 4. Отримати ефективність

Електроприлади не мають 100% ефективності.
Тому роботодавець хоче, щоб ми обчислили _ефективність_ електроприладів.
Щоб отримати ефективність, потрібно поділити коефіцієнт потужності (_число з плаваючою комою від 0 до 100_) на 100.

Реалізуйте функцію `get_efficiency()`, яка приймає число з плаваючою комою — коефіцієнт потужності.
Тоді функція повинна повернути (`return`) обчислену ефективність як число з плаваючою комою.

```python
>>> get_efficiency(80)
0.8
```

## 5. Отримати вартість

Роботодавець хоче знати вартість роботи електроприладів.
Вартість роботи електроприладів - це використана потужність, помножена на вартість однієї кВт·год.
Використана потужність - це задана потужність, поділена на обчислену ефективність.

Реалізуйте функцію `get_cost(<watts>,<power_factor>,<price>)`, яка приймає ціле число з кількістю ват, число з плаваючою комою — коефіцієнт потужності, і число з плаваючою комою — вартість однієї кВт·год.
Тоді функція повинна повернути (`return`) вартість роботи електроприладів як число з плаваючою комою.

```python
>>> get_cost(5000000, 80, 0.25)
0.3125
```
