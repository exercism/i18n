# Вступ

Коли ми [застосовуємо рекурсію][exercism-recursion] до перелічуваних структур, як-от списки, бітові рядки та рядки тексту (англ. string), часто постає два питання:

- скільки памʼяті потрібно, щоб зберегти ланцюжок рекурсивних викликів функцій
- як ефективно побудувати рішення

Щоб дати раду цим питанням, можна скористатися _акумулятором_.

Акумулятор - це змінна, яку передають додатково до даних. Його використовують, щоб передавати поточний стан виконання функції від одного виклику до іншого, доки не буде досягнуто _базового випадку_. У базовому випадку акумулятор використовують, щоб повернути остаточне значення рекурсивного виклику функції.

Ініціалізувати акумулятор має автор функції, а не її користувач. Щоб це зробити, визначають дві функції: публічну функцію, яка приймає лише потрібні дані як аргументи й ініціалізує акумулятор, і приватну функцію, яка приймає також акумулятор. В Elixir прийнято додавати до назви приватної функції префікс `do_`.

```elixir
# Count the length of a list without an accumulator
def count([]), do: 0
def count([_head | tail]), do: 1 + count(tail)

# Count the length of a list with an accumulator
def count(list), do: do_count(list, 0)

defp do_count([], count), do: count
defp do_count([_head | tail], count), do: do_count(tail, count + 1)
```

Завдяки акумулятору рекурсивні функції можна перетворити на _хвостово-рекурсивні_. Функція вважається хвостово-рекурсивною, якщо _останнє_, що вона виконує, - це виклик самої себе.
