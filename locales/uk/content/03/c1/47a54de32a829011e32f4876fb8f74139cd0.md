# Діапазони

[Діапазони][range] представляють інтервал між двома значеннями.
Найпоширеніші типи, які підтримують діапазони, - це `Int`, `Char` і `String`.
Їх можна використовувати для багатьох речей: швидко створити колекцію, нарізати рядки тексту (англ. string), перевірити, чи значення є в діапазоні, та для ітерації.
Їх створюють за допомогою оператора діапазону `..` або `...` (включно та виключно відповідно).

```crystal
1..5  # A range containing 1, 2, 3, 4, 5
1...5 # A range containing 1, 2, 3, 4
```

Причина існування двох операторів діапазону - створювати діапазони, які включають або не включають кінцеве значення. Це буває корисно, наприклад, коли ми працюємо з індексами, що починаються з нуля.

Діапазони також можна створювати за допомогою ініціалізатора `Range`.

```crystal
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
Коли ми створюємо діапазон у Crystal за допомогою операторів діапазону `..` або `...` і хочемо викликати метод на цьому діапазоні, потрібно взяти діапазон у дужки.
Інакше метод буде викликано на другому аргументі оператора діапазону.

```crystal
(1..5).size # => 5
1..5.size # => Error: undefined method 'size' for Int32
```
~~~~

## Отримання підрядків

Коли ми хочемо нарізати рядок тексту, можна скористатися оператором діапазону, щоб отримати підрядок.
Тобто створити діапазон із початковим і кінцевим індексом підрядка.

```crystal
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

Також можна використовувати відʼємні індекси, щоб отримати підрядок із кінця рядка тексту.

```crystal
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## Методи діапазону

Діапазони мають набір методів, які можна використовувати для роботи з ними.
Наприклад, за допомогою цих методів можна отримати суму всіх значень у діапазоні або перевірити, чи діапазон містить значення.

| Метод                   | Опис                                                                    | Приклад                         |
|-------------------------|-------------------------------------------------------------------------|---------------------------------|
| [`sum`][sum]            | Повертає суму всіх значень у діапазоні                                  | `(1..5).sum # => 15`            |
| [`size`][size]          | Повертає розмір діапазону                                               | `(1..5).size # => 5`            |
| [`includes?`][indludes] | Повертає `true`, якщо діапазон містить задане значення, інакше `false`  | `(1..5).includes?(3) # => true` |

## Діапазони без кінця та без початку

Діапазон може бути без кінця і без початку.
У діапазону без кінця або без початку початкове чи кінцеве значення дорівнює `nil`, але `nil` можна опустити, коли ми визначаємо діапазон.

Діапазони без початку та без кінця стають у пригоді, коли потрібно, наприклад, узяти підрядок від початку рядка тексту або до його кінця.

```crystal
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
Якщо використовувати діапазон без кінця не на колекції та без обережності, він може спричинити нескінченну послідовність.
~~~~

## Діапазони символів

Символи можна використовувати в діапазонах, і це дає змогу отримати інтервал символів між двома символами.
Наприклад, це стає у пригоді, коли потрібно отримати абетку.

```crystal
'a'..'z' # A range containing ['a', 'b', 'c', ..., 'z']
```

## Діапазони рядків тексту

Рядки тексту також можна використовувати в діапазонах, що дає змогу отримати інтервал рядків між двома рядками.
Але їхня поведінка трохи відрізняється від поведінки `Char`, коли в діапазоні рядків використовують кілька символів.
Під час складніших діапазонів рядків поведінка може заплутати, тож будьмо обережні.

```crystal
("aa".."az") # A range containing ["aa", "ab", "ac", ..., "az"]
```

## Власні обʼєкти в діапазонах

~~~~exercism/advanced
Crystal дає змогу використовувати власні обʼєкти в діапазонах.
Для цього обʼєкт має реалізовувати таке:

- включати модуль `Comparable`
- метод `succ`
- метод `<=>`

Завдяки цим методам діапазон може перебирати обʼєкт і порівнювати обʼєкти в діапазоні.

```crystal
class Foo
  include Comparable(Foo)

  getter value

  def initialize(@value : Int32)
  end

  def succ
    Foo.new(value + 1)
  end

  def <=>(other : Foo)
 value <=> other.value
  end
end

Foo.new(1)..Foo.new(5)
# => #<Foo:0x7f3552bebe70 @value=1>, #<Foo:0x7f3552bebe50 @value=2>, #<Foo:0x7f3552bebe40 @value=3>, #<Foo:0x7f3552bebe30 @value=4>, #<Foo:0x7f3552bebe20 @value=5>
```
~~~~
