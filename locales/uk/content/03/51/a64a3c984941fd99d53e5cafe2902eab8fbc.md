# Вступ

Кортежі - це легкий спосіб згрупувати разом фіксований набір даних довільних типів. Кортежі можуть містити довільну кількість елементів. Доступ до елементів можна отримати через деструктуризацію.

```rust
fn main() {
    let tup: (u32, u64, bool) = (10, 20, true);
}

fn main() {
    let (x, y, z) = (500, 6, true);

    if y == 6 {
        println!("y is 6!");
    }
}
