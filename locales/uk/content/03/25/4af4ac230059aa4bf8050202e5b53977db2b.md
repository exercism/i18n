# Вступ

## Основи

[Lua](https://lua.org) - це проста, але водночас потужна, ефективна, легка та вбудовувана сценарна мова. Її спроєктувала, реалізувала та підтримує у [PUC-RIO](https://www.puc-rio.br/) у Бразилії з 1993 року команда Роберто Ієрузалімскі, Валдемара Селеса та Луїса Енріке де Фігейреду.

### Коментарі

Однорядкові коментарі в Lua починаються з `--`, а багаторядкові - з `--[[` і закінчуються `]]`.
```lua
-- This is a single line comment.

--[[This is
a multiline
comment
]]
```

### Змінні

У Lua є три типи змінних: глобальні змінні, локальні змінні та поля таблиць. Щоб не ускладнювати, тут розглянемо лише локальні змінні. Типово всі змінні глобальні, тож локальні змінні потрібно оголошувати явно, ключовим словом `local`.
```lua
local x
```

Значення змінній можна присвоїти за допомогою оператора `=`.
```lua
local x = 1
```

Область видимості змінної `local` обмежена блоком, у якому її оголошено. Блоком може бути тіло керуючої конструкції, тіло функції, або файл чи рядок тексту (англ. string), у якому оголошено змінну.
```lua
local x = 1

if x == 1 then
  local x = 2
  print(x) -- prints 2
end

print(x) -- prints 1
```

### Функції

Функцію оголошують за допомогою ключового слова `function`, і, як і змінні, типово вона глобальна. Визначення функції містить назву, список параметрів і тіло. Функція завершується, коли досягає ключового слова `return`, і повертає всі значення, перелічені після нього. Без явно вказаного `return` функція поверне `nil`.

```lua
-- Defining a local function which returns "Hello " followed by 
-- the name which was given as parameter
local function say_hello(name)
  return 'Hello ' .. name
end
```

### Таблиці

У Lua таблиці - єдиний механізм структурування даних, і вони дуже потужні. Їх використовують, щоб представляти масиви, множини, обʼєкти, модулі та багато іншого. По суті, таблиця в Lua є асоціативним масивом.
```lua
-- create a table and assign its reference to tbl
local tbl = {}

-- new entry with key 'x' and value 1
tbl['x'] = 1

-- printing the value
print(tbl['x'])  --> 1

-- uninitialized table fields evaluate to nil
print(tbl['y'])  --> nil

-- there is also syntactic sugar - the following is the same as above
tbl.y = 1
print(tbl.y)    --> 1
```

Це лише маленький фрагмент, потрібний для наступного розділу. До цієї теми ми повернемося докладніше пізніше.

### Модулі

Модуль - це набір коду, який зберігається у вихідному файлі `.lua`. Усе, що модуль експортує, зберігається в таблиці, і цю таблицю повертають у кінці файлу. Тож таблиця фактично відіграє роль своєрідного простору імен.
```lua
-- say-hello.lua

-- defining the table 'say' which is exported at the end
local say = {}

-- defining the function 'hello' as a table field
-- this is syntax sugar for: say.hello = function() print('Hello!') end
function say.hello()
  print('Hello!')
end

-- returning (exporting) the table 'say'
return say
```

Потім цей модуль можна завантажити в інший файл через функцію `require`, яка повертає цю таблицю.
```lua
-- lets_say_hello.lua
local say = require('say-hello')
say.hello() -- prints "Hello!"
```

Коли ми бачимо `say.hello`, то думаємо про «функцію `hello` з модуля `say`». Але знаючи, що наш `say-hello.lua` повертає таблицю, і повертаючись до розділу про таблиці, ми помічаємо, що в Lua цей вираз означає «індексування таблиці `say` з використанням рядка тексту `hello` як ключа».

Хоча повертати таблицю з модуля - це добра практика, так само можна повернути й будь-який інший тип, наприклад функцію.

```lua
--- say-bye.lua
local function bye()
  print('Bye!')
end

return bye
```
