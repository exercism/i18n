# Інструкції

У цій вправі ми напишемо трохи коду, щоб допомогти Betty's Bike Shop, онлайн-магазину велосипедів і запчастин.
На нас чекають три завдання, мета яких - правильно показати ціни на велосипеди й запчастини на сайті.

## 1. Експортуйте функцію `pence_to_pounds`

Наш колега вже написав скелет модуля, а також неповні функції `pence_to_pounds` і `pounds_to_string`.
Однак він забув експортувати функцію `pence_to_pounds`, тож зараз її не бачать інші модулі або набір тестів.

Експортуйте функцію `pence_to_pounds`.

## 2. Перетворіть пенси на фунти

Зараз ціна зберігається як ціле число *пенсів* (магазин розташований у Великій Британії).
На сайті ми хочемо показувати ціну у *фунтах*, де 1.00 фунта дорівнює 100 пенсам.
Перше завдання - реалізувати функцію `pence_to_pounds`, яка приймає `Int` з кількістю пенсів і перетворює його на еквівалентну кількість фунтів як `Float`.
Також додайте анотації типів для цієї функції.

```gleam
pence_to_pounds(106)
// -> 1.06
```

## 3. Відформатуйте ціну для показу на сайті

Оскільки велосипеди Betty's Bike Shop продаються за фунти, ціни слід показувати із символом «£».
Отже, друге завдання - реалізувати функцію `pounds_to_string`, яка приймає суму у фунтах як `Float` і повертає ціну, показану як `String` із символом фунта попереду.

Перш ніж використовувати модулі `gleam/float` і `gleam/string`, їх треба імпортувати.

Також визначте анотацію типу для `pounds_to_string`.

```gleam
pounds_to_string(1.06)
// -> "£1.06"
```
