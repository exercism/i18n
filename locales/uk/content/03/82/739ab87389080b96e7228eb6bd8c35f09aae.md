# Інструкції

Еллен створює гру, у якій гравцеві доведеться битися з прибульцями.
Вона щойно дізналася про обʼєктно-орієнтоване програмування (ООП) і прагне скористатися всім, що може дати її програмі застосування `classes`.

На радість Еллен, ми погодилися допомогти, і вона доручила нам запрограмувати прибульців, з якими має битися гравець.


## 1. Створіть клас `Alien`

Визначте клас `Alien` із конструктором, який приймає два параметри типу `int` `x` і `y` та записує їх у змінні-члени `x_coordinate` і `y_coordinate`.
Кожен прибулець також починатиме з рівнем здоровʼя `3`, тож змінну-член `health` теж слід ініціалізувати.

`health` має бути приватною змінною-членом.
Щоб інші частини програми могли читати інформацію про здоровʼя, Еллен хоче мати метод `get_health()` із модифікатором `public`, який повертає `int`.

```cpp
Alien alien{2, 0};
alien.x_coordinate;
// => 2
alien.y_coordinate;
// => 0
alien.get_health();
// => 3
```

Тепер кожен прибулець має вміти самостійно відстежувати власну позицію та здоровʼя.

## 2. Функція `hit`

Еллен хотіла б, щоб клас `class` мав метод `hit`, який при виклику зменшує здоровʼя обʼєкта прибульця на `1`.
Так вона зможе просто викликати `some_alien_instance.hit()`, а не змінювати здоровʼя прибульця вручну.
Подбайте, щоб здоровʼя не опускалося нижче нуля.
Функція має повертати `true`.
Пізніше Еллен хоче додати щити, і тоді функція повертатиме `false`, якщо щит активний.

```cpp
Alien alien {0, 0};
alien.get_health();
// => 3 (Initial health value)

alien.hit(); // Decrements health by 1 point.
alien.get_health();
// => 2
```

## 3. Функція `is_alive`

Ми розуміємо, що якщо здоровʼя й далі зменшуватиметься, то рано чи пізно воно сягне `0`.
Було б добре додати метод `is_alive`, який Еллен зможе швидко викликати, щоб перевірити, чи прибулець... ну... живий. 😉
`some_alien_instance.is_alive()` має повертати булеве значення (англ. Boolean).

```cpp
alien.get_health();
// => 1
alien.is_alive();
// => true
alien.hit();
alien.get_health();
// => 0
alien.is_alive();
// => false
```

## 4. Функція `teleport`

У грі Еллен прибульці вміють телепортуватися!
Потрібно написати метод `teleport`, який приймає значення `x_new` і `y_new` та відповідно змінює координати прибульця.
Поки що функція має повертати `true`.
Пізніше Еллен хоче додати бомби, які блокують телепортацію, і тоді функція повертатиме `false`, якщо спроба телепортації не вдалася.

```cpp
alien.teleport(5, -4);
alien.x_coordinate;
// => 5
alien.y_coordinate;
// => -4
```

## 5. Функція `collision_detection`

Якщо прибульців можна в щось влучити, то вони мають уміти визначати, коли може статися таке зіткнення.
Еллен потрібно знати, чи двоє прибульців займають однакові координати.
Функція `collision_detection()` приймає як аргумент інший обʼєкт прибульця та повертає `bool`.

```cpp
Alien lrrr {3, 6};
Alien ndnd {-2, 12};
lrrr.collision_detection(ndnd);
// => false
ndnd.teleport(3, 6);
ndnd.collision_detection(lrrr);
// => true
```
