# Підказки

Перші три завдання викликають ту саму функцію `print_name_badge()`.
Реалізацію цього можна нарощувати крок за кроком, додаючи логіку для завдань 2 і 3 у міру просування.

## 1. Створення бейджа для працівника

- Це типовий випадок: просто зберімо 3 аргументи у відповідний рядок тексту (англ. string).
- [Інтерполяція рядків][interpolation] - мабуть, найпростіший підхід.

## 2. Створення бейджа для нового працівника

- Тепер ID має значення `missing,`, тож цільовий формат рядка тексту інший.
- `[`ismissing()][ismissing] стане тут у пригоді.
- У Julia є [тернарний оператор][ternary] із лаконічним синтаксисом.

## 3. Створення бейджа для власника

- Тепер відділ має значення `nothing`.
- Існує функція [`isnothing()`][isnothing].

## 4. Обчислення загальної зарплати працівників без ID

- Чи [any][any] вказує, що якийсь ID відсутній? Якщо ні, повернене значення дорівнює нулю.
- Щоб дістати записи з відсутнім ID, можливо, варто почати з [обʼєднання в пари][zip] векторів `ids` і `salaries`.
- Є кілька способів перебрати отриманий вектор кортежів, не пишучи явного циклу.
  - У стилі Python, за допомогою [включення][comprehension] вектора.
  - Функціонально, за допомогою [`map()`][map] і [анонімної функції][anonymous].
  - Векторно, за допомогою [трансляції][broadcasting] [анонімної функції][anonymous].
- Наприкінці буде [`sum()`][sum] по зміненому вектору зарплат.
   - Зарплати працівників з ID можна або пропустити, або встановити на нуль.
