# Вступ

У Go функції є повноправними значеннями.
Це означає, що з функціями можна робити те саме, що й з усіма іншими значеннями: присвоювати функції змінним, передавати їх як аргументи іншим функціям і навіть повертати функції з інших функцій.

Нижче ми створюємо дві функції, `engGreeting` і `espGreeting`, і присвоюємо їх змінній `greeting`:

```go
import "fmt"

func engGreeting(name string) string {
	return fmt.Sprintf("Hello %s, nice to meet you!", name)
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := engGreeting			// greeting is a variable of type func(string) string
fmt.Println(greeting("Alice"))	// Hello Alice, nice to meet you!

greeting = espGreeting
fmt.Println(greeting("Alice")) 	// ¡Hola Alice, mucho gusto!
```

Значення функцій дають змогу параметризувати функції не лише даними, а й поведінкою.
У наступному прикладі ми передаємо поведінку функції `dialog` через параметр `greetingFunc`:

```go
func dialog(name string, greetingFunc func(string) string) {
	fmt.Println(greetingFunc(name))
	fmt.Println("I'm a dialog bot.")
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := espGreeting
dialog("Alice", greeting)
// =>
// ¡Hola Alice, mucho gusto!
// I'm a dialog bot.
```

Значення неініціалізованої змінної типу функції дорівнює `nil`.
Тому виклик функції зі значенням `nil` спричиняє паніку.

```go
var dutchGreeting func(string) string
dutchGreeting("Alice") // panic: call of nil function
```

Значення функцій можна порівнювати з `nil`.
Це може стати в пригоді, щоб уникати зайвих панік у програмі.

```go
var dutchGreeting func(string) string
if dutchGreeting != nil {
	dutchGreeting("Alice") // safe to call dutchGreeting
}
```

## Типи функцій

Користуватися значеннями функцій можна завдяки типам функцій у Go.
Тип функції позначає множину всіх функцій з однаковою послідовністю типів параметрів і однаковою послідовністю типів результатів.
На основі типів функцій можна оголошувати власні типи.
Наприклад, функцію `dialog` з попередніх прикладів можна оновити так:

```go
type greetingFunc func(string) string

func dialog(name string, f greetingFunc) {
	fmt.Println(f(name))
	fmt.Println("I'm a dialog bot.")
}
```

## Анонімні функції

Завдяки підтримці повноправних функцій доступний ще один потужний інструмент - анонімні функції.
Анонімні функції визначаються в місці свого використання, без назви після ключового слова `func`.
Такі функції мають доступ до змінних зовнішньої функції.

Наприклад:

```go
func fib() func() int {
	var n1, n2 int

	return func() int {
		if n1 == 0 && n2 == 0 {
			n1 = 1
		} else {
			n1, n2 = n2, n1 + n2
		}
		return n2
	}
}

next := fib()
for i := range N {
  fmt.Printf("F%d\t= %4d\n", i, next())
}
```

Виклик `fib` оголошує змінні `n1` і `n2` і повертає анонімну функцію, яка, своєю чергою, змінює значення цих змінних щоразу, коли її викликають.
N-й виклик анонімної функції повертає N-те число послідовності Фібоначчі, починаючи з 0. Анонімна внутрішня функція має доступ до локальних змінних (`n1` і `n2`) зовнішньої функції `fib`.
Це чудовий спосіб дати значенням функцій змогу зберігати стан між викликами.
Кажемо, що анонімна функція - це замикання змінних `n1` і `n2`. [Замикання][closure] широко використовують у програмуванні, і їхню підтримку можна побачити і в інших мовах.

[closure]: https://en.wikipedia.org/wiki/Closure_(computer_programming)
