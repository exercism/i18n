# Нормалізації Representer

[Representer для F#][representer] застосовує такі нормалізації:

## Видалення коментарів

Усі коментарі видаляються.

### До

```fsharp
module Fake

(* Block comment
   on multiple lines *)

let message = "Hi" (* Block comment after code *)

// Double-slash comment on single line
let reply = "Yo" // Double-slash comment after code

/// <summary>This function adds two numbers</summary>
/// <param name="x">The first number</param>
/// <param name="y">The second number</param>
/// <returns>The first number added to the second number</param>
let add x y = x + y
```

### Після

```fsharp
module Fake

let message = "Hi"

let reply = "Yo"

let add x y = x + y
```

## Видалення оголошень імпорту

Усі оголошення імпорту видаляються.

### До

```fsharp
module Fake

open System
open System.IO

let message = "Hi"
```

### Після

```fsharp
module Fake

let message = "Hi"
```

## Форматування коду

Код форматується за допомогою [бібліотеки fantomas][fantomas].
Вона форматує код відповідно до настанов зі стилю F#.
Повний список перетворень, які застосовує fantomas, можна знайти [тут][fantomas-formatting].

### До

```fsharp
module Fake

let  add ( birthDate  :  DateTime)  =
    birthDate.Add (    2.0)

type Volume =
| Liter of float
| USPint of float
| ImperialPint of float
```

### Після

```fsharp
module Fake

let add (birthDate: DateTime) =
    birthDate.Add(2.0)

type Volume =
    | Liter of float
    | USPint of float
    | ImperialPint of float
```

## Нормалізація ідентифікаторів

Ідентифікатори нормалізуються до значення-заповнювача.

### До

```fsharp
module Fake

let foo x = x + 1
```

### Після

```fsharp
module PLACEHOLDER_1

let PLACEHOLDER_3 PLACEHOLDER_2 = PLACEHOLDER_2 + 1
```
