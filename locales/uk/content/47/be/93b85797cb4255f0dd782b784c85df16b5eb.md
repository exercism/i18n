# використання заголовка функції

[comment]: # (Ця помилка виникає, коли рішення використовує заголовок функції)

Заголовок функції (визначення функції без тіла) потрібен лише для функцій із типовими аргументами, які мають кілька клозів.

```elixir
# necessary function header
def hello(what \\ "World")
def hello("Alice"), do: "Hello, darling!"
def hello(name), do: "Hello, #{name}!"
```

Якщо функція з типовими аргументами має лише один клоз, типові аргументи можна вказати безпосередньо в цьому клозі.

```elixir
# preferred
def bye(name \\ "World"), do: "See you, #{name}!"

# not preferred - unnecessary function header
def bye(what \\ "World")
def bye(name), do: "See you, #{name}!"
```

Функція `two_fer/1` потребує лише одного клозу, тож заголовок функції їй не потрібен.
