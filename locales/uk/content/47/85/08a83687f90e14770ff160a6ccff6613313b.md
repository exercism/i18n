# Кортежі

Кортежі дають змогу легко згрупувати разом фіксований набір даних довільних типів. Кортеж не має власного імені; щойно ми даємо структурі даних імʼя, вона стає `struct`. Поля кортежу не мають імен; до них звертаються за допомогою деструктуризації або за позицією.

## Синтаксис

Кортеж записують як список полів, узятий у дужки:

- `()` - це `unit type`, [окремий випадок](https://doc.rust-lang.org/std/primitive.unit.html)
- **(** _вираз_ **,)** - це вираз кортежу з одного елемента
- **(** _тип_ **,)** - це тип кортежу з одного елемента
- **(** _вираз_ **,** ... **)** - це загальний вираз кортежу
- **(** _тип_ **,** ... **)** - це загальний тип кортежу

### Створення

Кортежі завжди створюють за допомогою виразу кортежу:

```rust
// pointless but legal
let unit = ();
// single element
let single_element = ("note the comma",);
// two element
let two_element = (123, "elements can be of differing types");
```

Кортеж може містити довільну кількість елементів.

### Доступ за допомогою деструктуризації

До елементів кортежу можна дістатися за допомогою деструктуризації. Це просто означає, що ми даємо імена змінним для окремих елементів кортежу, споживаючи його.

```rust
let (elem1, _elem2) = two_element;
assert_eq!(elem1, 123);
```

### Доступ за позицією

До елементів кортежу можна також дістатися за числовим індексом позиції. Індексація, як і завжди, починається з 0.

```rust
let notation = single_element.0;
assert_eq!(notation, "note the comma");
```

## Кортежні структури

Нам також доведеться працювати з кортежними структурами. Як і звичайні структури, це іменовані типи; на відміну від звичайних структур, їхні поля анонімні. Їхній синтаксис дуже схожий на синтаксис звичайного кортежу. Можна використовувати як деструктуризацію, так і доступ за позицією.

```rust
struct TupleStruct(u8, i32);
let my_tuple_struct = TupleStruct(123, -321);
let borrowed_neg = &my_tuple_struct.1;
let TupleStruct(borrowed_byte, _) = &my_tuple_struct;
assert_eq!(borrowed_neg, &-321);
assert_eq!(borrowed_byte, &123);
```

### Видимість полів

Усі поля анонімних кортежів завжди публічні. Однак поля кортежних структур мають власну видимість, типово приватну, так само як поля звичайних структур. Зробити поля публічними можна за допомогою модифікатора `pub`, так само як у звичайній структурі.

```rust
// fails due to private fields
mod tuple { pub struct TupleStruct(u8, i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```

```rust
// succeeds: fields are public
mod tuple { pub struct TupleStruct(pub u8, pub i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```
