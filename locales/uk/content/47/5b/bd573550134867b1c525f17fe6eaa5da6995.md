# Додаток до інструкцій

## Підказки

Потрібно реалізувати функцію

```haskell
value :: (Color, Color) -> Int
```

яка приймає лише два кольори й повертає числове значення опору резистора.

**Бонус - тестування властивостей:**

Ця вправа - гарна нагода написати [тести властивостей](https://en.wikipedia.org/wiki/Property_testing). Якщо раніше не доводилося їх писати, ось кілька джерел:

1. [School of Haskell](https://www.schoolofhaskell.com/user/pbv/an-introduction-to-quickcheck-testing).
2. [Real world Haskell](http://book.realworldhaskell.org/read/testing-and-quality-assurance.html)

Ми додали один зразок тесту властивостей QuickCheck у файл тестів.

Приклади властивостей, які можна перевірити:

- `value (x, y) >= 10` для всіх `(x, y)`, де `x` не `Black`

- Виклик `show` для `value (x, y)` дає `reverse` рядка тексту (англ. string), який повертає виклик `show` для `value (y, x)`.

- Усі кольори мають унікальні назви. (Для будь-яких двох кольорів: якщо кольори різні, то й назви в них різні.)
