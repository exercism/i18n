# Вступ

## Узагальнення

### Вступ

Узагальнення - це можливість мови, яка дає змогу повторно використовувати код.
Наприклад, для обчислення довжини масиву не повинно мати значення, якого типу елементи він містить.
Саме тому функція `length` використовує узагальнений параметр типу `a` у своїй сигнатурі типу.

```elm
length : List a -> Int
```

### Параметри в типах

Коли тип є узагальненим щодо іншого типу, ми використовуємо для цього іншого типу імʼя з маленької літери й називаємо його параметром типу.
Поширені приклади - це власні типи `List`, `Maybe` і `Result`.

```elm
-- Maybe is generic over the type a
type Maybe a
    = Nothing
    | Just a

someString : Maybe String
someString = Just "hello"

someInt : Maybe Int
someInt = Just 42
```

Одне важливе зауваження щодо назв параметрів типу: вони можуть складатися з кількох символів.
Єдина умова - вони мають бути записані маленькими літерами.
Тож коли це корисно, ми зазвичай даємо їм описові імена.

Тип може бути узагальненим щодо кількох інших типів і, отже, мати кілька параметрів типу.
У такому разі кожен незалежний тип отримує інше імʼя з маленької літери.
Незалежність не заважає їм стати одним і тим самим типом, вона лише дає їм змогу бути різними.

```elm
-- Result is generic over the types error and value
type Result error value
    = Ok value
    | Err error
```

Псевдоніми типів для записів теж можуть мати параметри типу, хоч це трапляється рідше.

```elm
-- Event is generic over the type a
type alias Event a =
    { at : Time
    , data : a 
    }
```

### Параметри типу у функціях

Оскільки типи можуть бути узагальненими, то й функції можуть.
Можна писати функції, що працюють з узагальненими типами, як-от `Maybe.withDefault`.

```elm
withDefault : a -> Maybe a -> a
withDefault default maybe =
    case maybe of
      Just value -> value
      Nothing -> default
```

Функції, які приймають інші функції як параметри, називають функціями вищого порядку, і вони теж можуть бути узагальненими.

```elm
map : (a -> b) -> Maybe a -> Maybe b
map function maybe =
  case maybe of
    Just value ->
      Just (function value)

    Nothing ->
      Nothing
```
