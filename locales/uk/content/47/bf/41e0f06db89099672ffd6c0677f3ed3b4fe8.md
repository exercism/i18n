# Встановлення

Поточна версія elm - 0.19.1.
Інструкції зі встановлення змінюються разом із розвитком мови.
За актуальними інструкціями зі встановлення перейдіть до
[інструкцій зі встановлення з посібника Elm][elm-install].

[elm-install]: https://guide.elm-lang.org/install/elm.html

## Додаткові інструменти

**elm-test**

Інструмент, яким запускають тести з командного рядка, називається elm-test.
Наразі elm-test потребує Node.js і npm, тож якщо їх ще не встановлено,
спершу [встановіть Node.js і npm][npm-install].
Коли npm уже встановлено, elm-test можна встановити так:

```shell
npm install --global elm-test@latest-0.19.1
```

Більше інформації на [сторінці elm-test на npm][elm-test].

[npm-install]: https://www.npmjs.com/get-npm
[elm-test]: https://www.npmjs.com/package/elm-test

**elm-format**

Більшість розробників, які пишуть на elm, використовують elm-format для форматування свого коду.
Це інструмент форматування коду, який не потребує жодного налаштування.
Спочатку це може трохи дратувати, якщо ми не звикли
до інструментів автоматичного форматування, але коли ми до нього звикаємо,
починаємо дивуватися, як раніше писали код без нього.
Його також можна встановити за допомогою npm:

```shell
npm install --global elm-format@latest-0.19.1
```

Більше інформації на [домашній сторінці elm-format на GitHub][elm-format].

[elm-format]: https://github.com/avh4/elm-format

**Текстовий редактор**

Підтримка Elm добре працює принаймні в [IntelliJ][intellij]
та в текстових редакторах, сумісних із [elm language server][els],
як-от VS Code, Sublime Text чи Vim.

[els]: https://github.com/elm-tooling/elm-language-server
[intellij]: https://github.com/klazuka/intellij-elm

## Помилки дозволів у npm

Під час встановлення elm-test або elm-format може виникнути
помилка дозволів EACCESS у npm.
Якщо це так, дотримуйтеся інструкцій на сайті npm.
[Розвʼязання помилок дозволів EACCES під час глобального встановлення пакетів][eaccess].

[eaccess]: https://docs.npmjs.com/resolving-eacces-permissions-errors-when-installing-packages-globally
