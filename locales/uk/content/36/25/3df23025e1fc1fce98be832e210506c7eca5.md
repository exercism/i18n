# Інструкції

У цій вправі ми разом зі своїми найкращими друзями граємо в рольову гру під назвою «Wizard and Warriors».
Наша роль - майстер гри, тобто людина, яка оживляє ігровий світ для гравців.
Ключовий складник цього - описувати гравцям гру: який статус у персонажа, як має вигляд місто, до якого вони прямують, тощо.

На нас чекають пʼять завдань, у яких ми описуємо гравцям окремі частини гри.

## 1. Опишіть персонажа

Кожен персонаж має клас, рівень і кількість очок здоровʼя, і його описують так: `"You're a level <LEVEL> <CLASS> with <HIT_POINTS> hit points."`.
Реалізуйте метод `GameMaster.describe`, який приймає `Character` як свій єдиний параметр і повертає його опис.

```java
Character character = new Character();
character.setCharacterClass("Wizard");
character.setLevel(4);
character.setHitPoints(28);

new GameMaster().describe(character);
// => "You're a level 4 Wizard with 28 hit points."
```

## 2. Опишіть пункт призначення

Кожен пункт призначення має назву та кількість мешканців, і його описують так: `"You've arrived at <NAME>, which has <INHABITANTS> inhabitants."`.
Реалізуйте метод `GameMaster.describe`, який приймає `Destination` як свій єдиний параметр і повертає його опис.

```java
Destination destination = new Destination();
destination.setName("Muros");
destination.setInhabitants(732);

new GameMaster().describe(destination);
// => "You've arrived at Muros, which has 732 inhabitants."
```

## 3. Опишіть спосіб подорожі

Персонажі можуть дістатися пункту призначення одним із двох способів:

- Пішки, описано так: `"You're traveling to your destination by walking."`
- Верхи, описано так: `"You're traveling to your destination on horseback."`

Реалізуйте метод `GameMaster.describe`, який приймає `TravelMethod` як свій єдиний параметр і повертає його опис.

```java
new GameMaster().describe(TravelMethod.HORSEBACK);
// => "You're traveling to your destination on horseback."
```

## 4. Опишіть персонажа, який подорожує до пункту призначення

Коли персонаж подорожує до пункту призначення, це описують як поєднання окремих описів: `"<CHARACTER> <TRAVEL_METHOD> <DESTINATION>"`.
Реалізуйте метод `GameMaster.describe`, який приймає `Character`, `Destination` і `TravelMethod` як свої параметри та повертає його опис.

```java
Character character = new Character();
character.setCharacterClass("Wizard");
character.setLevel(4);
character.setHitPoints(28);

Destination destination = new Destination();
destination.setName("Muros");
destination.setInhabitants(732);

new GameMaster().describe(character, destination, TravelMethod.HORSEBACK);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination on horseback. You've arrived at Muros, which has 732 inhabitants."
```

## 5. Опишіть персонажа, який подорожує до пункту призначення, не вказуючи спосіб подорожі

У більшості випадків персонажі подорожують до пункту призначення пішки.
Для зручності гравцям дозволено не згадувати свій спосіб подорожі, і тоді вважається, що це пішки.
Реалізуйте метод `GameMaster.describe`, який приймає `Character` і `Destination` як свої параметри та повертає його опис.

```java
Character character = new Character();
character.setCharacterClass("Wizard");
character.setLevel(4);
character.setHitPoints(28);

Destination destination = new Destination();
destination.setName("Muros");
destination.setInhabitants(732);

new GameMaster().describe(character, destination);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination by walking. You've arrived at Muros, which has 732 inhabitants."
```
