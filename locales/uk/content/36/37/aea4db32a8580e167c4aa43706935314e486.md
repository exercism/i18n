# Вступ

Якщо типи параметрів можна вивести, Swift також дозволяє пропустити назви параметрів і ключове слово `in` у визначенні замикання. Натомість до параметрів можна звертатися за допомогою спеціального скороченого синтаксису, де `$0` відповідає першому параметру, `$1` відповідає другому, і так далі.

```swift
let mean: (Double, Double) -> Double = { $0 + $1 / 2.0 }

["apple", "ball", "carrot"].sorted(by: { $0.count < $1.count })
```
