# Тести

## Запуск тестів

Щоб запустити тести, виконайте таку команду:

```bash
call {slug}Test.bat
```

## Розвʼязування вправи

Розвʼязати вправу означає зробити так, щоб усі її тести пройшли.
Коли всі тести пройдуть, вправу буде розвʼязано!

Щоб допомогти з початком, кожна вправа містить файл-заготовку з реалізацією.
Цей файл можна використати як відправну точку для побудови свого рішення.
Видаляйте або змінюйте цей файл на свій розсуд.
