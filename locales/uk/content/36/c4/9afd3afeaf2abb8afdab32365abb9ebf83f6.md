# Ітератори

Ітератор - це підпрограма, назва якої закінчується на `!` і яку можна викликати лише всередині `loop`. На кожному проході циклу він видає своє наступне значення; коли він вичерпується, цикл завершується одразу.

```sather
   loop
      total := total + counts.elt!;
   end;
```

У Sather немає інструкції `for`. Саме ітератори її замінюють, і саме цією можливістю ця мова відома.

## Ті, що варто знати від самого початку

| Ітератор | Що дає |
| --- | --- |
| `a.elt!` | кожен елемент `a` по черзі |
| `a.ind!` | кожна позиція `a`: 0, 1, 2 … |
| `n.upto!(m)` | `n`, `n+1` … `m` |
| `n.downto!(m)` | `n`, `n-1` … `m` |
| `n.times!` | виконується `n` разів, нічого не даючи |
| `n.up!` | `n`, `n+1`, … і ніколи не завершується |
| `s.elt!` | кожен символ рядка тексту |

`until!`, `while!` та `break!` теж є ітераторами. Ось чому їхні назви закінчуються на `!` і чому вони працюють лише всередині циклу.

## Де розміщується виклик

Виклик ітератора може стояти будь-де, де може стояти вираз, зокрема в середині умови:

```sather
   loop
      if counts.elt! > 10 then busy := busy + 1; end;
   end;
```

Кожне *місце* в програмі, де написано ітератор, зберігає власну позицію. Якщо написати `counts.elt!` двічі в одному тілі циклу, це створить два незалежні обходи масиву, а це майже ніколи не те, що потрібно:

```sather
   loop
      #OUT + counts.elt! + " and " + counts.elt!;   -- two separate walks
   end;
```

Краще запитати один раз і покласти значення в змінну.

## Завершення циклу

Цикл завершується, щойно вичерпається *будь-який* ітератор у ньому, а не коли вичерпаються всі. З одним ітератором це очевидно. З кількома це те правило, на якому спотикаються всі, і саме про нього йтиметься в наступній вправі.

## Що обирати

Надаваймо перевагу `elt!`, коли потрібні значення, і `ind!`, коли потрібні позиції. До `upto!` по `0 .. a.size - 1` вдаваймося лише тоді, коли потрібні обидва одразу, або коли відповідь - це позиція, а не значення.
