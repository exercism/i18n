# Детальніше

## Оператори порівняння

[Оператори порівняння][comparison-operators] використовують, щоб порівнювати значення й повертати значення `true` або `false`.
Ці оператори вимагають, щоб два значення, які порівнюються, мали один і той самий тип.
Якщо значення мають різні типи, тоді компілятор видасть помилку.
Ось список операторів порівняння та приклад, коли вони дають значення `true`:

| Метод | Опис                  | Приклад |
| ------ | --------------------- | ------- |
| ==     | дорівнює              | 1 == 1  |
| !=     | не дорівнює           | 1 != 2  |
| <      | менше                 | 4 < 5   |
| <=     | менше або дорівнює    | 4 <= 4  |
| >      | більше                | 3 > 1   |
| >=     | більше або дорівнює   | 2 >= 2  |

## Умовні конструкції `if` та `else`

[Умовна конструкція][conditional-statement] дає змогу виконувати код залежно від умови, яка може бути `true` або `false`.
Найпростіша умовна конструкція - це [умовний оператор `if`][if], який виконує код, коли умова має значення `true`.
Щоб оголосити умовний оператор `if`, ми використовуємо ключове слово `if`, після якого йде умова, а далі код для виконання у фігурних дужках.

```swift
let wheelCount = 4
if wheelCount == 4 {
  print("Your vehicle is a car")
}
// Prints "Your vehicle is a car"
```

`if` можна поєднати з `else`, щоб виконати код, коли умова має значення `false`.
Оператор `else` потрібно використовувати разом з умовним оператором `if`, і він не може використовуватися сам по собі.
Щоб оголосити оператор `else`, ми використовуємо ключове слово `else` після фігурних дужок оператора `if`, а далі код для виконання у фігурних дужках.

```swift
let precipitationInMM = 0.5
if precipitationInMM > 0.5 {
  print("You will need an umbrella")
} else {
  print("You will not need an umbrella")
}
// Prints "You will not need an umbrella"
```

Умовні оператори можна також обʼєднувати в ланцюжок за допомогою `else if`, щоб перевірити кілька умов.
Це працює за тим самим принципом, що й оголошення умовного оператора `if`, але ключове слово тут `else if`, а не `if`.
Умовні оператори `if` не потребують `else`, щоб бути чинними, але за потреби можуть його мати.

```swift
let favoriteFruit = "Apple"

if favoriteFruit == "Banana" {
    print("Your favorite fruit is a banana")
} else if favoriteFruit == "Orange" {
    print("Your favorite fruit is an orange")
} else if favoriteFruit == "Apple" {
    print("Your favorite fruit is an apple")
} else {
    print("Your favorite fruit is not a banana, orange or apple")
}
// Prints "Your favorite fruit is an apple"
```

## Вираз `if`

Умовні оператори `if` можна також використовувати як вирази, щоб присвоїти значення змінній.
Остання інструкція в блоці `if` використовується як значення виразу `if`.
Це може стати в пригоді, коли ми хочемо присвоїти змінній значення залежно від умови.

```swift
let CpuBits = 32
let largest = if CpuBits == 64 {
  "x86_64"
} else {
  "x86_32"
}

print(largest)
// Prints "x86_32"
```
