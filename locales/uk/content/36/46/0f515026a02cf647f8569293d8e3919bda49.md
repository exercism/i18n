# Про це

У ABAP є кілька числових типів. У невеликих вступних вправах найчастіше використовують `i` для цілих чисел і `p` для упакованих десяткових чисел.

Використовуймо `i`, коли значення має бути цілим числом, наприклад кількість днів. Використовуймо десятковий тип, коли значення може містити дробові цифри, наприклад погодинну ставку.

```abap
DATA hours_per_day TYPE i VALUE 8.
DATA rate_per_hour TYPE p LENGTH 8 DECIMALS 2 VALUE '89.89'.

DATA day_rate TYPE p LENGTH 8 DECIMALS 2.
day_rate = hours_per_day * rate_per_hour.
```

Упаковані числа часто використовують у бізнес-застосунках, коли потрібна фіксована кількість десяткових знаків. В ABAP також є десяткові числа з плаваючою комою (`decfloat16` і `decfloat34`) та двійкові числа з плаваючою комою (`f`). Двійкові числа з плаваючою комою можуть стати в нагоді для наукових обчислень, але вони не є добрим типовим вибором для прикладів, повʼязаних із грошима, бо багато десяткових дробів неможливо подати точно.
