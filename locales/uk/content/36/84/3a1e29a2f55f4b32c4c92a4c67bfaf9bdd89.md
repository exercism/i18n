# Докладніше

## Часткове застосування

Усі функції в Elm [карровані][currying], тобто якщо викликати функцію, не передавши всі аргументи, вона повертає нову функцію.

Результат цього називають [частковим застосуванням][partial-application] (ми не передаємо функції всі аргументи, а застосовуємо частину з них).

```elm
add: Int -> Int -> Int
add a b = a + b

add2: Int -> Int
add2 = add 2

eight: Int
eight = add2 6
--> 8
```

Часткове застосування завжди застосовує аргументи по порядку.

```elm
contains: String -> String -> Bool
contains first second =
--> This function is in the standard library, and returns True if the second string contains the first one

containsCedd: String -> Bool
containsCedd = contains "Cedd"
--> (partial application always applies the arguments in order, so "Cedd" becomes the first argument to contains
--> This is a function that takes a string, and returns True if that string contains Cedd)

ceddBurgeContainsCedd: Bool
ceddBurgeContainsCedd = containsCedd "Cedd Burge"
--> True
--> ("Cedd Burge" ends up being the second argument to contains, and it does include "Cedd", the first argument)
```

## Оператор конвеєра (`|>`)

Запис `x |> f` робить рівно те саме, що й `f x`. Конкретний приклад: `"5" |> String.toInt` дає те саме, що `String.toInt "5"`.

Спочатку це не звучить надто корисно, але його називають [оператором конвеєра][pipe-operator], бо він дає змогу писати «конвеєрний» код.

Наприклад, припустімо, у нас є функція sanitize, яка перетворює введення користувача на цілі числа:

```elm
sanitize : String -> Maybe Int
sanitize input =
    String.toInt (String.trim input)
```

Можна переписати її так:

```elm
sanitize : String -> Maybe Int
sanitize input =
    input
    |> String.trim
    |> String.toInt
```

Це позбавляє від потреби в дужках і показує функції в тому порядку, у якому вони застосовуються (спочатку `String.trim`, потім `String.toInt`), що допомагає читати код.

Є також [зворотний оператор конвеєра `(<|)`][reverse-pipe-operator].
Запис `x <| f` робить рівно те саме, що й `f x`.
На перший погляд, і це не видається надто корисним, і він точно вживається рідше за оператор конвеєра, але в деяких випадках допомагає обійтися без дужок.

## Композиція функцій / безточковий стиль

Оператор [`(>>)`][forward-composition] має тип `(a -> b) -> (b -> c) -> (a -> c)` і створює функцію типу `a -> c`, компонуючи дві сумісні функції типу `a -> b ` і `b -> c`.
Він робить це так: бере вихідні дані (типу `b`) першої функції й використовує їх як перший аргумент другої функції (яка мусить мати той самий тип `b`).
Створена функція прийматиме ті самі вхідні дані (типу `a`), що й перша функція, і повертатиме те `c`, яке повертає друга функція.

Конкретний приклад: `String.trim >> String.toInt`.
`String.trim` приймає рядок тексту (англ. string) як свій єдиний параметр, тож саме його приймає й створена функція.
`String.toInt` повертає `Maybe Int`, тож саме це повертає й створена функція.
`String.trim` повертає `String`, який `String.toInt` приймає як параметр, тож приклад компілюється.

Тепер ми можемо переписати нашу функцію `sanitize` так:

```elm
sanitize : String -> Maybe Int
sanitize =
    String.trim >> String.toInt
```

Звернімо увагу: ми більше не використовуємо параметр `input`, який був у початковому прикладі, хоча функціональність ідентична.
Такий спосіб створення функцій, які не згадують своїх параметрів, називають «безточковим стилем».
Перевага цього стилю в тому, що код лаконічніший, а недолік у тому, що його буває важче зрозуміти, особливо початківцям.

Варто памʼятати, що всі функції в Elm карровані, тому `String.length >> max` компілюється й дає ось що:

- Функція (1), яка приймає рядок тексту як параметр (вхідні дані для `String.length`)
- `max` має два параметри `Int`, але функція 1 передає їй лише один `Int` (повернене значення `String.length`), тож `max` застосовується частково.
- Повернене значення частково застосованої функції `max` - це інша функція (2), яка приймає `Int` і повертає більше з цього `Int` та частково застосованого `Int` зі `String.length`
- Отже, функція 1 (`String -> Int`) повертає функцію 2 (`Int -> Int`)
- Тож `((String.length >> max) "123") 2` повертає `3`, бо довжина `"123"` дорівнює 3, а це більше за 2 з аргументу `Int`.

## Проєктування функцій

Щоб в Elm було легко писати елегантний код, головну структуру даних варто робити останнім параметром функцій.
Усі поширені функції зі стандартної бібліотеки роблять саме так, наприклад `List.map` (сигнатура типу нижче).

```elm
map : (a -> b) -> List a -> List b
```

Тут видно, що функція `map` приймає останнім параметром `List a` і повертає `List b`, тож головна структура даних (`List`) стоїть останнім параметром.

Завдяки цьому можна писати елегантний конвеєрний код, як ось тут.

```elm
trimAndUpperCase : List String -> List String
trimAndUpperCase names =
    names
    |> List.map String.trim
    |> List.map String.toUpper
```

Це також робить зручним використання композиції функцій і безточкового стилю як альтернативи конвеєрному коду.

```elm
trimAndUpperCase : List String -> List String
trimAndUpperCase =
    List.map String.trim
    >> List.map String.toUpper
```

Композиція функцій також дає змогу звести цей приклад до одного виклику `List.map`.

```elm
trimAndUpperCase : List String -> List String
trimAndUpperCase =
    List.map (String.trim >> String.toUpper)
```
