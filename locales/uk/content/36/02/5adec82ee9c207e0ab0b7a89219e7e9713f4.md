# Додаток до інструкцій

## Формат вихідних даних

Виведіть послідовність дій як рядок тексту (англ. string), що завершується нульовим символом, використовуючи кому та пробіл як розділювачі.

## Регістри

| Регістр | Використання     | Тип     | Опис                                            |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | вхідні дані        | ціле число | число від 1 до 31       |
| `$a1`    | вхідні/вихідні дані | адреса | вихідний рядок тексту, що завершується нульовим символом |
| `$t0-9`  | тимчасовий    | будь-який     | використовується для тимчасового зберігання    |
