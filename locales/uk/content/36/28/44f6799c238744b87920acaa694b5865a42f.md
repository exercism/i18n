# Підказки

## 1. Видалити дублікати треків

- Приклад створення множини з масиву можна побачити в [документації MDN][mdn-relation-to-arrays].
- Переконайтеся, що перед поверненням ви перетворили множину назад на масив.
- Поверніться до [концепції деструктуризації масивів][concept-array-destructuring], щоб пригадати, як використовувати оператор розгортання.

## 2. Перевірити, чи трек уже додано

- Існує [вбудований метод][mdn-set-has] для перевірки, чи є елемент у множині.

## 3. Додати трек

- Існує [вбудований метод][mdn-set-add] для додавання елемента до множини.
- Не викликайте `Set.has()` вручну, щоб перевірити наявність елемента перед додаванням; `Set.add()` подбає про це за вас!

## 4. Видалити трек

- Існує [вбудований метод][mdn-set-delete] для видалення елемента з множини.
- Не викликайте `Set.has()` вручну, щоб перевірити наявність елемента перед видаленням; `Set.delete()` подбає про це за вас!

## 5. Вивести список унікальних виконавців

- Існує [кілька різних способів][mdn-set-iteration] перебрати множину.
- Існує [вбудований метод][mdn-string-split] для поділу рядка тексту (англ. string) на підрядки.
- Поверніться до [концепції деструктуризації масивів][concept-array-destructuring], щоб пригадати, як пропустити елемент під час деструктуризації масиву.
