# Вступ

## Відображення

Відображення - це застосування функції до кожного елемента послідовності, унаслідок чого утворюється нова послідовність.

Це легко зробити з масивом за допомогою функції `mapcar`.
Припустімо, що в нас є функція `double`, яка множить свій аргумент на `2`:

```lisp
(mapcar #'double '(1 2 3 4)) ; => (2 4 6 8)
```

Зауважмо, що перший аргумент - це функція, яку потрібно викликати. `#'` - це спеціальний синтаксис цитування, який указує на функцію.

Спочатку `double` викликали з першим елементом, потім з другим і так далі.
Результати зібрали в масив, який і є значенням цього виразу.

## Фільтрування

Фільтрування - це процес створення послідовності з іншої послідовності шляхом копіювання всіх елементів початкової послідовності, крім деяких.
Вибір того, які елементи включити до нової послідовності, можна зробити за допомогою функції-предиката, тобто функції, яка дає булеве значення (англ. Boolean), або за допомогою перевірки на рівність із конкретним обʼєктом.

### Видалення за предикатом

`remove-if` - це функція, яка приймає функцію-предикат і послідовність як аргументи та повертає послідовність лише з тих елементів, для яких предикат дав неправду.
Інакше кажучи, вона «видаляє» всі елементи послідовності, для яких предикат дав правду. Однак зауважмо, що ця функція не змінює початкову послідовність!
Натомість вона повертає нову послідовність без відповідних елементів. Якщо предикат дав правду для всіх значень, то повертається порожня послідовність.

```lisp
(remove-if #'evenp '(1 2 3 4 5)) ; => (1 3 5)
(remove-if #'oddp '(1 3 5))      ; => ()
```

### Видалення конкретного елемента

Якщо потрібно видалити конкретний елемент із послідовності, можна скористатися функцією `remove`, яка приймає елемент для видалення та послідовність.
Повертаються всі значення з послідовності, які не дорівнюють елементу для видалення.
ПРИМІТКА: рівність типово перевіряється за допомогою `eql` [загального предиката рівності][concept-equality].

```lisp
(remove 1 '(1 2 1 3 1 4)) ; => (2 3 4)
(remove #\l "hello")      ; => "heo"
```
