# Інструкції

Перетворіть трійкове число, подане як рядок тексту (англ. string), наприклад '102012', на його десятковий еквівалент, виходячи з базових принципів.

Програма повинна вважати рядки, що задають некоректне трійкове число, значенням 0.

Трійкові числа містять три символи: 0, 1 і 2.

Останній розряд трійкового числа - розряд одиниць. Передостанній - розряд трійок, третій від кінця - розряд девʼяток, і так далі.

```shell
# "102012"
    1       0       2       0       1       2    # the number
1*3^5 + 0*3^4 + 2*3^3 + 0*3^2 + 1*3^1 + 2*3^0    # the value
  243 +     0 +    54 +     0 +     3 +     2 =  302
```

Якщо мова програмування надає метод зі стандартної бібліотеки для виконання цього перетворення, вдайте, ніби його не існує, і реалізуйте перетворення самостійно.
