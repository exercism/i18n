# Огляд

Тип `Maybe` - це те, як мова Elm працює з необовʼязковими значеннями.
Тому він присутній у сигнатурах типів багатьох основних функцій Elm, і розуміти його вкрай важливо.

## Визначення та змінна типу

Тип `Maybe` визначено так:

```elm
type Maybe a = Nothing | Just a
```

У термінології Elm це називають визначенням «custom type».
Докладніше про custom types ідеться в іншому понятті цього треку, але для розуміння саме `Maybe` вони нам не потрібні.
`a` у `Maybe a` та `Just a` позначає змінну типу, тобто це може бути будь-який тип, наприклад `Int`, `Bool` або `String`.
Отже, `Maybe String` - це змінна, яка необовʼязково містить `String`, а `Maybe Int` необовʼязково містить `Int`.

```elm
name : Maybe String
name = Just "Matthieu"

age : Maybe Int
age = Just 29
```

Вертикальна риска `|` у визначенні типу `Maybe` означає «АБО».
Вона вказує, що значення цього типу може бути або `Nothing`, або `Just` чимось типу `a`.
Тож уявімо, що людина не заповнила імʼя та вік, і ми матимемо таке.

```elm
name : Maybe String
name = Nothing

age : Maybe Int
age = Nothing
```

## Читання вмісту значення `Maybe`

Щоб прочитати вміст значення `Maybe`, використовують «зіставлення зі зразком».
Зіставлення зі зразком також докладніше розглядають в іншому понятті, тож ми зосередимося лише на тому, як воно працює з `Maybe`.

```elm
-- This function returns "Hello, <name>!" if the name was provided.
-- Otherwise, it just says "Hello, World!".
sayHello : Maybe String -> String
sayHello maybeName =
    case maybeName of
        Nothing -> "Hello, World!"
        Just someName -> "Hello, " ++ someName ++ "!"

sayHello (Just "Matthieu")
    --> "Hello, Matthieu!"

sayHello Nothing
    --> "Hello, World!"
```

Щоразу, коли ми використовуємо значення `Maybe`, компілятор Elm перевірятиме, що наш код опрацьовує всі можливості, тож ми ніколи не зможемо зіставити `Maybe` зі зразком і обробити лише випадок `Just someValue`.
Спочатку це може здатися набридливим, але це одна з найбільших переваг мови Elm.
Це запобігатиме сотням багів і робить рефакторинг під керівництвом компілятора безстрашним і приємним досвідом.

## Більше функцій для роботи з `Maybe`

У модулі `Maybe` є також чимало корисних функцій для роботи з типами `Maybe`.

```elm
sayHelloAgain : Maybe String -> String
sayHelloAgain name = "Hello, " ++ Maybe.withDefault "World" name ++ "!"

capitalizeName : Maybe String -> Maybe String
capitalizeName name = Maybe.map String.toUpper name

capitalizeName matthieu
    --> Just "MATTHIEU"

capitalizeName anon
    --> Nothing
```
