# Доповнення до інструкцій

## Реалізація

Функції у цій вправі приймають масив, що містить одне або більше чисел, кожне з яких позначає один «рахунок за гру».

Рахунки гравця за ігри можна прочитати з

| `scores`   |
|---|
| `scores[0]` |
| `scores[1]` |
| ... |
| `scores[scores_len - 1]` |

`personal_top_three()` має записати найкращі рахунки гравця до

| `output`   |
|---|
| `output[0]` |
| ... |
