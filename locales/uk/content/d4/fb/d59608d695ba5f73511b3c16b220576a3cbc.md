# Вступ

Пакет `java.time`, представлений у Java 8, містить кілька класів для роботи з датами й часом.

## `LocalDate`

Клас `java.time.LocalDate` представляє дату без часового поясу в [календарній системі ISO-8601][iso-8601], наприклад `2007-12-03`:

```java
LocalDate date = LocalDate.of(2007, 12, 3);
```

Дати можна порівнювати з іншими датами:

```java
LocalDate date1 = LocalDate.of(2007, 12, 3);
LocalDate date2 = LocalDate.of(2007, 12, 4);

date1.isBefore(date2);
// => true

date1.isAfter(date2);
// => false
```

Екземпляр `LocalDate` має гетери, щоб діставати з нього окремі частини дати:

```java
LocalDate date = LocalDate.of(2007, 12, 3);

date.getDayOfMonth();
// => 3
```

Екземпляр `LocalDate` має методи, щоб додавати до нього одиниці часу:

```exercism/note
Ці методи повертають _новий_ екземпляр `LocalDate` і не змінюють наявний, оскільки клас `LocalDate` незмінний.
```

```java
LocalDate date = LocalDate.of(2007, 12, 3);

date.plusDays(3);
// => 2007-12-06
```

## `LocalDateTime`

Клас `java.time.LocalDateTime` представляє дату й час без часового поясу в [календарній системі ISO-8601][iso-8601], наприклад `2007-12-03T10:15:30`:

```java
LocalDateTime datetime = LocalDateTime.of(2007, 12, 3, 10, 15, 30);
```

Екземпляр `LocalDate` можна перетворити на `LocalDateTime`:

```java
LocalDate date = LocalDate.of(2007, 12, 3);
LocalDateTime datetime = date.atTime(10, 15, 30);
datetime.toString();
// => "2007-12-03T10:15:30"
```

## Форматування дати й часу

І `LocalDate`, і `LocalDateTime` використовують стандартний запис [ISO-8601][iso-8601], коли перетворюють з `String` і на `String`.

```java
LocalDateTime datetime = LocalDateTime.of(2007, 12, 3, 10, 15, 30);
LocalDateTime parsed = LocalDateTime.parse("2007-12-03T10:15:30");

datetime.isEqual(parsed);
// => true
```

Розібрати `LocalDate` чи `LocalDateTime` з такого `String` в іншому форматі неможливо.
Натомість, щоб форматувати дати у власному форматі, варто використати `java.time.format.DateTimeFormatter`:

```java
DateTimeFormatter parser = DateTimeFormatter.ofPattern("dd/MM/yyyy");
LocalDate date = LocalDate.parse("03/12/2007", parser);

DateTimeFormatter printer = DateTimeFormatter.ofPattern("MMMM d, yyyy");
printer.format(date);
// => "December 3, 2007"
```

Під час створення власного формату також можна вказати локаль, щоб форматувати й розбирати для різних регіонів:

```java
DateTimeFormatter.ofPattern("MMMM d, yyyy", Locale.FRENCH).format(date);
// => décembre 3, 2007

DateTimeFormatter.ofPattern("MMMM d, yyyy", Locale.of("pt")).format(date);
// => dezembro 3, 2007
```

[iso-8601]: https://en.wikipedia.org/wiki/ISO_8601
