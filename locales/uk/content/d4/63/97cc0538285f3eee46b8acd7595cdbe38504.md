# Вступ

## Оператори порівняння

Оператори порівняння в Julia схожі на оператори багатьох інших мов, хоча й мають додаткові можливості для любителів математики.

Для рівності є оператори `==` (дорівнює) та `!=` або `≠` (не дорівнює).

```julia
txt = "abc"
txt == "abc"  # true
txt != "abc"  # false
txt ≠ "abc"  # false (synonym for !=)
```

Крім того, є різні оператори «більше» та «менше».

```julia
1 < 3  # true
3 > 3  # false
3 <= 3  # true
3 ≤ 3  # true (synonym for <=)
4 >= 3  # true
4 ≥ 3  # true (synonym for >=)
```

Як часто буває з Julia, відповідний редактор робить використання математичного символа простим.
Наберімо `\ne`, `\le` або `\ge`, а потім `TAB`, щоб отримати `≠`, `≤` або `≥`.

У попередньому прикладі використано лише числа, але в інших частинах силабусу ми побачимо, що різні додаткові типи можна впорядковувати й перевіряти на більше та менше.

Оператори порівняння можна обʼєднувати в ланцюжок, що дає змогу писати чіткий і стислий код:

```julia
n = 3
1 ≤ n ≤ 5  # true (n "between" two limits)
```

Попередній приклад рівнозначний `1 ≤ n && n ≤ 5`.

## Розгалуження з `if`

Це повна форма умовної конструкції `if`:

```julia
if conditional1
    statements...
elseif conditional2
    statements...
else
    statements...
end
```

Дужки `()` або фігурні дужки `{}` не потрібні, а відступи слугують «лише» для покращення читабельності _(але читабельність дуже важлива!)_.

І `elseif`, і `else` необовʼязкові, і блоків `elseif` може бути кілька.
Однак `end` обовʼязковий.

Можна вкладати умовні конструкції `if` одну в одну, хоча для кращої читабельності варто продумано використовувати дужки, відступи та коментарі.

Найкоротша форма умовної конструкції `if` має такий вигляд:

```julia
if n < 0
    n = 0
end
```

Нагадаємо: як умови можна використовувати лише вирази, що обчислюються до `true` або `false`.
Julia свідомо уникає будь-якого поняття «правдивості», тому нульові значення, порожні рядки тексту (англ. string) і порожні масиви _не_ рівнозначні `false`.

## Тернарний оператор

Проста й поширена ситуація: вибрати одне з двох значень залежно від умови.

Julia, як і багато мов, має тернарний оператор, який робить це стислішим.

Синтаксис такий: `conditional ? value_if_true : value_if_false`.

Отже, попередній приклад можна переписати так:

```julia
n = n < 0 ? 0 : n
```

Компілятор не вимагає дужок, але вони можуть покращити читабельність.
