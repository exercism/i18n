# Підказки

## Загальне

- `<min-heap>`, `heap-push`, `heap-peek` та `heap-pop-all` живуть у [`heaps`][heaps]; `values` - в [`assocs`][assocs].
- Купа зберігає кожен елемент як *значення* з *ключем*; ключ - це пріоритет. `heap-push` приймає їх ось так: `( value key heap -- )`.

## 1. Відкрийте чергу

- `<min-heap>` будує порожню мінімальну купу: першим обслуговується найменший ключ.

## 2. Додайте клієнта

- Значенням є імʼя клієнта, а ключем - пріоритет; саме в такому порядку `heap-push` їх і приймає.
- `heap-push` споживає чергу. Скористаймося `[ heap-push ] keep`, щоб додати клієнта і все одно повернути чергу.

## 3. Хто наступний?

- `heap-peek` повертає `value key` для першого елемента й не вилучає його. Нам потрібне лише імʼя, тож відкиньмо ключ за допомогою `drop`.

## 4. Обслужіть усіх

- `heap-pop-all` спорожнює купу в асоціативний список пар `{ key value }`, уже впорядкованих за пріоритетом.
- `values` залишає лише значення, тобто імена.

[heaps]: https://docs.factorcode.org/content/vocab-heaps.html
[assocs]: https://docs.factorcode.org/content/vocab-assocs.html
