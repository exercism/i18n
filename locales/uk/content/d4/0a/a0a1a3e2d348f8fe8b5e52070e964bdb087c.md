# Тести

Щоб перевірити своє рішення, відкрийте термінал і виконайте

```
mason test
```

у теці вправи (тій, що містить файл `Mason.toml` і теки `src/` та `test/`).

Якщо повідомлення про помилку видається недостатньо інформативним, спробуйте наступне, щоб отримати докладніше.

```
mason test --show
```
