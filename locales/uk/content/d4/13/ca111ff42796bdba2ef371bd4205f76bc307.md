# Додаток до вказівок

## Регістри

| Регістр | Використання | Тип          | Призначення                        |
| ------- | ------------ | ------------ | ---------------------------------- |
| `$a0`   | вхідні дані  | ціле число   | задане значення                    |
| `$v0`   | вихідні дані | ціле число   | різниця квадратів                  |
| `$t0-9` | тимчасовий   | будь-який    | використовується для тимчасового зберігання |
