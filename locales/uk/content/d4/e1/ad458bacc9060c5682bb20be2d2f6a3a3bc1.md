# Вступ

У Cairo перевантаження операторів дозволяє визначати власну поведінку для стандартних операторів, як-от `+`, `-`, `==`, `<` тощо, коли ми працюємо з власними типами.

Це робиться шляхом реалізації конкретних трейтів для наших власних типів.

## Основні трейти для операторів

### `Add` та `Sub`

Трейти `Add` та `Sub` дозволяють визначити, як додавання (`+`) і віднімання (`-`) працюють із нашим типом:

```rust
impl MyTypeAdd of Add<MyType> {
    fn add(lhs: MyType, rhs: MyType) -> MyType {
        // Define addition behavior
    }
}
```

### `PartialEq`

Трейт `PartialEq` уможливлює порівняння на рівність (`==` і `!=`) між екземплярами нашого типу.

Часто його можна автоматично вивести за допомогою `#[derive(PartialEq)]`.

### `PartialOrd`

Трейт `PartialOrd` дозволяє виконувати операції порівняння (`<`, `>`, `<=`, `>=`) між екземплярами нашого типу.

Він вимагає реалізувати щонайменше метод `lt` (менше ніж):

```rust
impl MyTypePartialOrd of PartialOrd<MyType> {
    fn lt(lhs: MyType, rhs: MyType) -> bool {
        // Define "less than" behavior
    }
}
```
