# Інструкції

Ласкаво просимо до світу *ChronoRealms*, чарівної землі, де могутні Хранителі часу керують плином часу.

У цьому світі хранителі часу керують «TimeShards», особливими одиницями, які можна додавати, віднімати, порівнювати й навіть перевіряти на рівність.

Наше завдання - допомогти хранителям часу, реалізувавши власні оператори для роботи з цими TimeShards.

Хранителі часу просять нас створити власну структуру `TimeShard`, яка підтримує такі операції:

1. **Додавання і віднімання TimeShards**: хранителям часу потрібно вміти додавати й віднімати TimeShards, щоб керувати плином часу.
2. **Порівняння TimeShards**: іноді TimeShards потрібно порівнювати, щоб зʼясувати, який із них більший або чи вони рівні.
3. **Перевірка рівності**: хранителям часу потрібно перевіряти, чи два TimeShards однакові за значенням.

Наша місія - реалізувати такі трейти для структури `TimeShard`:

1. **Додавання (`Add`)**: дає змогу додавати два екземпляри `TimeShard` один до одного.
2. **Віднімання (`Sub`)**: дає змогу віднімати один `TimeShard` від іншого.
3. **Рівність (`PartialEq`)**: дає змогу хранителям часу перевіряти, чи два екземпляри `TimeShard` однакові.
4. **Порівняння (`PartialOrd`)**: дає змогу порівнювати два екземпляри `TimeShard`, щоб визначити, який із них більший чи менший.

`TimeShard` представлятиме структура, яка зберігає ціле число (`i32`).

Реалізуйте потрібні трейти, щоб полегшити роботу хранителям часу.

```rust
let shard1 = TimeShard { value: 5 };
let shard2 = TimeShard { value: 3 };

// Adding TimeShards
let sum = shard1 + shard2; // TimeShard { value: 8 }

// Subtracting TimeShards
let difference = shard1 - shard2; // TimeShard { value: 2 }

// Checking equality
let are_equal = shard1 == shard2; // false

// Comparing TimeShards
let is_greater = shard1 > shard2; // true
```
