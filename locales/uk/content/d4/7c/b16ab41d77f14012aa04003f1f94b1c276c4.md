# Опис

У цій вправі ми створимо корисну програму, щоб не доводилося запамʼятовувати значення смуг.
Програма прийматиме 1, 4 або 5 кольорів на вхід і видаватиме правильне значення в омах.
Кольорові смуги кодуються так:

| Колір | Значення |
|-------|----------|
| Black | 0 |
| Brown | 1 |
| Red | 2 |
| Orange | 3 |
| Yellow | 4 |
| Green | 5 |
| Blue | 6 |
| Violet | 7 |
| Gray | 8 |
| White | 9 |
|-------------|-------|

У вправі [`Resistor Color Trio`][resistor-color-trio-exercise] ми декодували перші три кольорові смуги.
Наприклад: orange-orange-brown перетворюється на основне значення `330`.
У цій вправі нам потрібно додати до цього ще й _допуск_.
Допуск - це максимальна величина, на яку значення може бути більшим або меншим за основне значення.
Наприклад, якщо остання смуга green, максимальний допуск становитиме `±0.5%`.

Смуга допуску матиме одне з таких значень:

| Колір | Допуск |
|--------|----------:|
| Grey | ±0.05% |
| Violet | ±0.10% |
| Blue | ±0.25% |
| Green | ±0.50% |
| Brown | ±1.00% |
| Red | ±2.00% |
| Gold | ±5.00% |
| Silver | ±10.00% |
|--------|-----------|

Чотирисмуговий резистор влаштований так:

| Смуга_1 | Смуга_2 | Смуга_3 | Смуга_4 |
| ------- | ------- | ---------- | --------- |
| Значення_1 | Значення_2 | Множник | Допуск |

Приклади:

- orange-orange-brown-green дасть `330` омів із допуском `±0.5%`.
- orange-orange-red-grey дасть `3300` омів із допуском `±0.05%`.

Різниця між чотирисмуговим і пʼятисмуговим резистором у тому, що пʼятисмуговий резистор має додаткову смугу, яка вказує точніше значення.

| Смуга_1 | Смуга_2 | Смуга_3 | Смуга_4 | Смуга_5 |
| ------- | ------- | ------- | ---------- | --------- |
| Значення_1 | Значення_2 | Значення_3 | Множник | Допуск |

Приклади:

- orange-orange-orange-black-green дасть `333` омів із допуском `±0.5%`.
- orange-red-orange-blue-violet дасть `323 million` омів із допуском `±0.1%`.

Бувають також односмугові резистори.
Односмугові резистори мають лише колір black зі значенням 0.

Наша програма має перетворювати вхідний `list` кольорів смуг резистора на позначку:

«... ohms ±...%»

Тож на вхідний `list` `["orange", "orange", "black", "green"]` програма має повернути:

«33 ohms ±0.5%»

Коли йдеться про тисячі омів, ми кажемо «kiloohms».
Це як казати «кілометр» для 1000 метрів і «кілограм» для 1000 грамів.

Тож на вхідний `list` `["orange", "orange", "orange", "grey"]` програма має повернути:

«33 kiloohms ±0.05%»

Коли йдеться про мільйони омів, ми кажемо «megaohms».

Тож на вхідний `list` `["orange", "orange", "blue", "red"]` програма має повернути:

«33 megaohms ±2%»
