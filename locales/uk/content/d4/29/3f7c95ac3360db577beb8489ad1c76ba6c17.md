# Інструкції

Ми створюємо невеликий калькулятор зі зворотним польським записом (ЗПЗ).
Стан калькулятора - це *стек значень*, поданий як масив Factor, а *операція* - це quotation, який приймає такий стек і повертає новий.

```factor
{ 3 4 }   ! the calculator's stack: 3 is below 4
[ ... ]   ! an operation that consumes some values and pushes a result
```

## 1. Реалізувати додавання

Визначте `add-op`: він має знімати зі стека два верхні значення, класти на стек їхню суму й повертати новий стек.

```factor
{ 3 4 } add-op .
! => { 7 }

{ 1 2 3 4 } add-op .
! => { 1 2 7 }
```

## 2. Реалізувати множення

Визначте `multiply-op` так само, але для множення.

```factor
{ 3 4 } multiply-op .
! => { 12 }
```

## 3. Застосувати одну операцію

Визначте `apply-op`, який бере зі стека даних стек і операцію (quotation) і повертає новий стек калькулятора.

```factor
{ 3 4 } [ add-op ] apply-op .
! => { 7 }
```

## 4. Обчислити програму

Визначте `evaluate`, який приймає початковий стек і масив операцій, застосовує кожну операцію по черзі й повертає кінцевий стек.

```factor
{ 3 4 5 } { [ add-op ] [ multiply-op ] } evaluate .
! => { 27 }
```

## 5. Обчислити за назвою

Тепер програма - це масив *назв операторів* (рядків тексту (англ. string)), і калькулятор шукає кожну назву в assoc, який зіставляє назви з операціями.

Визначте `evaluate-named`, який приймає початковий стек, assoc іменованих операцій і масив назв, і повертає кінцевий стек.

```factor
{ 3 4 5 } H{ { "+" [ add-op ] } { "*" [ multiply-op ] } } { "+" "*" }
evaluate-named .
! => { 27 }
```

## 6. Ділення з безпекою

Справжній калькулятор не повинен мовчки видавати сміття, коли його просять поділити на нуль. Клас помилки `zero-divisor-error` уже визначено для нас. Реалізуйте `divide-op` за аналогією до `add-op` і `multiply-op`, але він робить `throw` нової `zero-divisor-error`, коли дільник на вершині стека дорівнює `0`.

```factor
{ 12 4 } divide-op .
! => { 3 }

{ 1 5 6 2 } divide-op .
! => { 1 5 3 }

{ 5 0 } divide-op
! throws zero-divisor-error
```
