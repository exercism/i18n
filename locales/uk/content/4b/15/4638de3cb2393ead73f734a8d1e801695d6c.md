# Про перетворення типів

Go вимагає явного перетворення між різними типами.
Наприклад, це спричиняє помилку компілятора:

```go
var x int = 42
var f float64 = x // compiler error x is an int not a float64
```

Перетворення між типами (також відоме як **type casting**) виконується за допомогою функції з назвою типу, на який потрібно перетворити.
Значення `v` перетворюється на тип `T` за допомогою `T(v)`.
Наприклад, щоб перетворити `int` на `float64`, потрібно зробити ось що:

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
```

Те саме стосується будь-яких власних типів:

```go
type Id int
var number int = 121 // number has type int
userId := Id(number) // userId now has type Id
```

## Перетворення між примітивними типами та рядками тексту (англ. string)

Існує пакет `strconv` для перетворення між примітивними типами (як-от `int`) і `string`.

```go
import "strconv"

var intString string = "42"
var i, err = strconv.Atoi(intString)

var number int = 12
var s string = strconv.Itoa(number)
```

УВАГА: використання стандартного методу type casting не дає такої поведінки.
Наприклад:

```go
var num int = 65
str := string(num) // str is now "A" not "65"
```

Ось деякі з інших поширених методів перетворення:

| Method      | Purpose                        |
| ----------- | ------------------------------ |
| ParseBool   | Перетворити `string` на `bool` |
| FormatBool  | Перетворити `bool` на `string` |
| ParseFloat  | Перетворити `string` на `float` |
| FormatFloat | Перетворити `float` на `string` |
| ParseInt    | Перетворити `string` на `int`  |
| FormatInt   | Перетворити `int` на `string`  |
