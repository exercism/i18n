# Тести

Тестові набори для вправ PureScript можна запускати з каталогу вправи за допомогою інструмента spago:

    cd <exercism-workspace>/purescript/<exercise name>
    spago test

де <exercism-workspace> - це робочий каталог CLI.

Наприклад:

    cd ~/exercism/purescript/accumulate
    spago test
