# Детальніше

Структури даних, які можуть містити нуль або більше елементів, називають _колекціями_.
**Масив** у Ruby належить до колекцій, які зберігають порядок, у якому до них додають обʼєкти.
Масиви можуть містити будь-які обʼєкти.
Обʼєкти можна додавати до масиву й діставати з нього за індексом.
Індексація масивів у Ruby починається з нуля, тобто індекс першого елемента завжди дорівнює нулю:

```ruby
# Declare an array containing two values
two_ints = [1,2]

# Assign first and second element by index
two_ints[0] = 7
two_ints[1] = 8

# Retrieve the second element by index
two_ints[1] # => 8

# Check the length of the array
two_ints.size # => 2
```

У Ruby є кілька способів створити масив:

- За допомогою літерального конструктора `[]` _(найпоширеніший)_
- Явно викликавши `Array.new`
- Викликавши метод `Array()` з Kernel

Метод `Array.new` приймає два необовʼязкові аргументи: початковий розмір масиву і типовий обʼєкт.

Якщо вказати розмір і типовий обʼєкт, масив заповнюється `size` копіями цього обʼєкта.

```ruby
a = Array.new(2, Hash.new)
# => [{}, {}]
```

Оскільки всі елементи масиву зберігають той самий хеш, зміна одного з них вплине на всі.

```ruby
a[0]['cat'] = 'feline'
a # => [{"cat"=>"feline"}, {"cat"=>"feline"}]

a[1]['cat'] = 'Felix'
a # => [{"cat"=>"Felix"}, {"cat"=>"Felix"}]
```

Якщо ж потрібні різні копії, варто використати версію з блоком, яка бере результат цього блоку щоразу, коли потрібно ініціалізувати черговий елемент масиву:

```ruby
a = Array.new(2) {Hash.new}
a[0]['cat'] = 'feline'
a # => [{"cat"=>"feline"}, {}]
```

Ще одна особливість масивів у Ruby полягає в тому, що вони включають модуль [Enumerable][enumerable-module], який додає багато зручних методів, щоб перебирати, шукати, сортувати, фільтрувати тощо елементи масиву.

[enumerable-module]: https://docs.ruby-lang.org/en/master/Enumerable.html
[for-loop]: https://launchschool.com/books/ruby/read/loops_iterators#forloops
