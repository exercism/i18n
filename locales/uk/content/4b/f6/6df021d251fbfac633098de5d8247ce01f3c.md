# Варіативні параметри

[_Варіативні параметри_][variadic-parameters] у Swift дають змогу передати нуль або більше значень одного типу в один параметр функції.
Це позначають, дописуючи `...` до анотації типу параметра.

Ці значення автоматично згрупуються в масив, елементи якого мають той самий тип, що й тип варіативного параметра.

```swift
func geometricMean(_ numbers: Double...) -> Double {
  var total = 1.0
  for number in numbers {
      total *= number
  }
  return pow(total, 1.0 / Double(numbers.count))
}

geometricMean(1, 2, 3, 4, 5)
// Returns 2.605171084697352
```

Коли ми використовуємо варіативні параметри, Swift має два обмеження:

1. Swift дозволяє функції мати лише один варіативний параметр. Було вирішено, що це обмеження приберуть у майбутньому випуску Swift, але наразі воно все ще діє.
2. Якщо у визначенні функції після варіативного параметра йдуть інші параметри, то перший параметр після варіативного _обовʼязково_ повинен мати мітку аргументу.

[variadic-parameters]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/functions/#Variadic-Parameters
