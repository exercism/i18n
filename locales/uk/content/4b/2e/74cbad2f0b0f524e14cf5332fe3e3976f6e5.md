# Докладніше

`generator` - це функція або вираз, що повертає особливий тип [ітератора][iterator], який називається [генераторний ітератор][generator-iterator].
`Generator-iterators` є [лінивими][lazy iterator]: вони не зберігають свої `values` у памʼяті, а _генерують_ значення тоді, коли потрібно.

Функція-генератор має такий самий вигляд, як і будь-яка інша функція, але містить один або кілька [виразів `yield`][yield expression].
Кожен `yield` зупиняє виконання коду, зберігаючи поточний стан виконання (_разом з усіма локальними змінними та інструкціями `try`_).
Коли генератор відновлює роботу, він продовжує зі стану, збереженого під час зупинки, на відміну від звичайних функцій, які скидаються з кожним викликом.


## Створення генератора

Генератори створюють майже так само, як інші функції з циклами чи рекурсією, але вони вимагають [виразу `yield`](#the-yield-expression), який ми докладніше розглянемо трохи згодом.

Приклад - функція, яка повертає _квадрати_ із заданого масиву чисел.  
У наведеному вигляді всі вхідні дані потрібно обробити, перш ніж можна буде повернути якісь значення:

```python
>>> def squares(list_of_numbers):
...     squares = []
...     for number in list_of_numbers:
...         squares.append(number ** 2)
...     return squares
```

Перетворити цю функцію на генератор можна так:

```python
>>> def squares_generator(list_of_numbers):
...     for number in list_of_numbers:
...         yield number ** 2
```

Сенс у тому, що генератор використовують тоді, коли всі значення не потрібні _одразу_.

Це заощаджує памʼять і обчислювальні ресурси, адже обчислюється лише те значення, з яким ми _працюємо зараз_.


## Використання генератора

Генератори (_технічно `generator-iterator`ів, див. примітку нижче_) - це різновид `iterator`, і їх можна використовувати будь-де в Python, де очікується `iterator` або `iterable`.
Це стосується _функцій_ або _обʼєктів_, які приймають `iterable`/`iterator` як аргумент.
Щоб зануритися глибше, див. [How to Make an Iterator in Python][how-to-iterator].


~~~~exercism/note

Генераторні ітератори - це особливий підвид [ітераторів][iterator].
`Iterators` - це механізм/протокол, який уможливлює перебирання _ітерабельних обʼєктів_.
Генераторні ітератори та ітератори, які повертають звичайні [`iterables`][iterables] у Python, поводяться дуже схоже, але є кілька важливих відмінностей, які варто зауважити:

- Вони _[обчислюються ліниво][lazy evaluation]_; ітерація _одностороння_, і повернутися до попереднього значення не можна.
- Їх _споживають_, перебираючи повернені значення; скидання чи збереження в памʼяті не існує.
- Їх не можна впорядкувати й не можна розвернути.
- Вони не є послідовностями й _не мають_ `indexes`. 
  Не можна звернутися до попереднього чи наступного значення за допомогою додавання чи віднімання, і не можна використовувати запис у квадратних дужках (`[]`) чи зрізи.
- Їх не можна використовувати з функцією `len()`, бо вони не мають довжини.
- Вони можуть бути _скінченними_ або _нескінченними_: будьмо обережні, збираючи всі значення з _нескінченного_ `generator-iterator`!

[iterator]: https://docs.python.org/3.11/glossary.html#term-iterator
[iterables]: https://wiki.python.org/moin/Iterator
[lazy evaluation]: https://en.wikipedia.org/wiki/Lazy_evaluation
~~~~


Щоб скористатися генератором `squares_generator()`:

```python
>>> squared_numbers = squares_generator([1, 2, 3, 4])

>>> for square in squared_numbers:
...     print(square)
...
1
4
9
16
```

Значення в генераторі також можна створювати й отримувати за допомогою функції `next()`.
`next()` викликає метод `__next__()` обʼєкта-генератора, «просуваючи» або обчислюючи код генератора до його виразу `yield`, який потім «віддає» чи повертає значення.

```python
>>> squared_numbers = squares_generator([1, 2])

>>> next(squared_numbers)
1
>>> next(squared_numbers)
4
```

Коли `generator` повністю вичерпано і він більше не має значень для повернення, він викидає помилку `StopIteration`.

```python
>>> next(squared_numbers)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
StopIteration
```

### Різниця між ітерабельними обʼєктами та генераторами

Генератори - це особливий підвид _ітераторів_.
`Iterators` - це механізм/протокол, який уможливлює перебирання _ітерабельних обʼєктів_.
Генератори й ітератори, які повертають звичайні [`iterables`][iterables] у Python, поводяться дуже схоже, але є кілька важливих відмінностей, які варто зауважити:

- Генератори _односторонні_: повернутися до попереднього значення не можна.

- Перебирання генераторів споживає повернені значення; скидання немає.

- Генератори (_оскільки обчислюються ліниво_) не можна впорядкувати й не можна розвернути.

- Генератори _не_ мають `indexes`, тож не можна звернутися до попереднього чи наступного значення за допомогою додавання чи віднімання.

- Генератори не можна використовувати з функцією `len()`.

- Генератори можуть бути _скінченними_ або _нескінченними_, тож будьмо обережні, збираючи всі значення з _нескінченного_ генератора.

## Вираз `yield`

[Вираз `yield`][yield expression] дуже схожий на вираз `return`.

_На відміну_ від виразу `return`, `yield` віддає значення тому, хто викликав, у _певній точці_, призупиняючи обчислення й повернення подальших значень, доки їх не запросять.

Коли `yield` обчислюється, він зупиняє виконання функції, у якій міститься, і повертає значення функції _на той момент_.

Після цього функція _залишається в області видимості_, і коли викликається `__next__()`, виконання відновлюється, доки знову не трапиться `yield`.

~~~~exercism/note
Використовувати вирази `yield` поза функціями заборонено.
~~~~

```python
>>> def infinite_sequence():
...     current_number = 0
...     while True:
...         yield current_number
...         current_number += 1

>>> lets_try = infinite_sequence()
>>> lets_try.__next__()
0
>>> lets_try.__next__()
1
```

## Навіщо потрібні генератори?

Генератори стають у пригоді в багатьох задачах.

Працюючи з великою колекцією, ми можемо не хотіти тримати всі її значення в `memory`.
Генератор дає змогу опрацьовувати великі дані частина за частиною, заощаджуючи памʼять і підвищуючи швидкодію.

Генератори також дуже допомагають, коли процес чи обчислення _складні_, _дорогі_ або _нескінченні_:

```python
>>> def infinite_sequence():
...     current_number = 0
...     while True:
...         yield current_number
...         current_number += 1
```

Тепер щоразу, коли для обʼєкта `infinite_sequence` викликають `__next__()`, він повертає _попереднє число_ + 1.
