# Встановлення

## Користувачі Windows

Будь ласка, встановіть [Windows Subsystem for Linux][wsl-link] і перейдіть до наступного розділу.

## Користувачі Linux/Mac

### Встановлення за допомогою brew

Це найпростіший спосіб встановити Chapel.
Ви отримаєте базове робоче встановлення, якого достатньо, щоб пройти трек на Exercism.
Досвідченіші користувачі, можливо, захочуть зібрати Chapel з вихідного коду (наступний розділ).

0. Якщо brew ще не встановлено, встановіть менеджер пакетів [brew][brew-link].
1. Спершу переконайтеся, що brew оновлено, виконавши `brew update`
2. Встановіть Chapel, виконавши `brew install chapel`
3. Переконайтеся, що встановлення успішне, виконавши `chpl --version`

Це встановить компілятор Chapel (`chpl`), менеджер пакетів `mason`, який ми будемо використовувати для запуску тестів, і засіб генерації документації `chpldoc`. Для Exercism він не потрібен, але його добре мати, якщо (коли :) ) захочеться розробляти власні бібліотеки на Chapel.

### Збирання Chapel з вихідного коду

Досвідченіші користувачі, можливо, захочуть самостійно зібрати Chapel з вихідного коду. Для цього:

1. Встановіть [передумови][prereqs-link]
2. [Завантажте][download-link] архів останнього випуску Chapel і розпакуйте його.
3. Спершу потрібно підготувати встановлення й налаштувати, куди саме встановлювати Chapel.
Це можна зробити, запустивши наданий скрипт `configure`.
Якщо просто запустити

```
./configure
```

він встановить бінарні файли, бібліотеки та спільні файли в `/usr/local/`; це можна змінити за допомогою опції `--prefix`.
Наприклад, щоб встановити Chapel у `~/.chapel`, можна виконати

```
./configure --prefix=~/.chapel
```

4. Щоб встановити компілятор та інструменти, виконайте

```
make
make mason
make chpldoc
make install
```

5. Переконайтеся, що тека `/dir/for/install/bin` є у змінній `PATH`.

Докладніше про різні способи встановлення Chapel і роботи з вихідним кодом див. на сторінці [Збирання Chapel][building-link] у документації.
