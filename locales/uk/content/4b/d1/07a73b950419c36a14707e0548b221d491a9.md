# Докладніше

PHP надає низку операторів для виконання арифметичних дій. Для своїх арифметичних операторів PHP дотримується стандартного математичного порядку дій. Ось які оператори надає PHP:

* Тотожність (+)
* Заперечення (-)
* Додавання (+)
* Віднімання (-)
* Множення (*)
* Ділення (/)
* Остача від ділення (%)
* Піднесення до степеня (**)

Розгляньмо кожен із них і те, як їх можна застосувати:

## Тотожність (+)

Оператор тотожності (+) працює з одним значенням (унарний оператор). Результатом буде значення змінної типу `float` або `int`.

```php
$value = '42';
$answer = +$value; // 42 (int)
```

## Заперечення (-)

Оператор заперечення працює з одним значенням (унарний оператор) і повертає число, протилежне за знаком.

```php
$forward = 65;
$reverse = -$forward; // -65
```

## Додавання (+) і віднімання (-)

Оператор додавання додає два значення з обох боків від себе, а оператор віднімання віднімає праве значення від лівого.

```php
$apples = 5;
$yourApples = 0;

$apples = $apples - 2; // 3
$yourApples = $yourApples + 2; 2
```

## Ділення (/)

Оператор ділення повертає результат ділення лівого значення на праве. Якщо праве значення дорівнює 0, виникне помилка `DivisionByZeroError`.

```php
$slicesOfPizza = 8;
$people = 4;
$slicesPerPerson = $slicesOfPizza / $people; // 2
```

## Множення (*)

Оператор множення повертає результат множення лівого та правого значень.

```php
$tires = 4;
$priceOfTire = 250;
$totalCost = $tires * $priceOfTire; // 1000
```

## Остача від ділення (%)

Оператор остачі повертає остачу від ділення лівого значення на праве. Цей оператор дуже корисний, коли треба визначити, чи одне число ділиться на інше без остачі, чи є значення парним або непарним, та багато іншого.

```php
$value = 3;
$isOdd = $value % 2;
if ($isOdd === 1) {
    echo 'Yes, it is odd!';
} else {
    echo 'It is even.';
}
```

## Піднесення до степеня (**)

Оператор піднесення до степеня підносить ліве значення до степеня правого. До PHP 5.6 для цього доводилося використовувати функцію `pow`.

```php
$sideLength = 13;
$areaOfSquare = $sideLength ** 2; // 169
```

Оператор піднесення до степеня підтримує цілі числа та числа з плаваючою комою з обох боків, тож із його допомогою можна обчислювати квадратні корені (чи корені інших степенів) або складніші показникові значення.

```php
$squareArea = 144;
$side = $squareArea ** .5; // 12
```

## Порядок дій

PHP дотримується стандартного математичного порядку дій. Це означає, що операції виконуються не просто зліва направо: кожен оператор має свій пріоритет, і операції виконуються відповідно до цього пріоритету. Порядок дій такий:

* дужки
* піднесення до степеня
* множення, ділення
* додавання, віднімання

Множення і ділення мають однаковий пріоритет між собою. Так само однаковий пріоритет мають додавання і віднімання.

Тому наведене нижче значення дорівнюватиме 17, а не 10, бо множення має вищий пріоритет за додавання:

```php
$value = 2 + 3 * 5;
```

PHP також надає низку зручних операторів присвоєння, які поєднують арифметичні оператори з присвоєнням, коли ми виконуємо дію над змінною і записуємо результат назад у неї саму. Про них ітиметься в понятті `Assignment Operators`.
