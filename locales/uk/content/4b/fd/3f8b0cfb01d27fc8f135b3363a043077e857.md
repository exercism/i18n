# Вступ

## Правда і неправда

Логічні стани «правда» і «неправда» позначаються в Ruby за допомогою `true` і `false`.

```ruby
happy = true
sad = false
```

## Рівність і порівняння

У Ruby можна порівнювати обʼєкти між собою за допомогою звичайних символів порівняння:
- Використовуймо `==`, щоб перевірити, чи два обʼєкти рівні
- Використовуймо `>`, щоб перевірити, чи обʼєкт ліворуч **більший за** обʼєкт праворуч
- Використовуймо `<`, щоб перевірити, чи обʼєкт ліворуч **менший за** обʼєкт праворуч.
- Використовуймо `>=` або `<=`, щоб перевірити «більше або дорівнює» та «менше або дорівнює» відповідно.

Також можна застосовувати булеву логіку зі звичайними операторами:
- Використовуймо `&&` (логічне і) або `and`, щоб перевірити, чи `x and y` — це правда
- Використовуймо `||` (логічне або) або `or`, щоб перевірити, чи `x or y` — це правда.
- Використовуймо `!` або `not`, щоб заперечити рівність, наприклад `x != y` (x не дорівнює y)

Ось кілька прикладів:
```ruby
# Is "true equal to false"? 
true == false # false

# Is "true not equal to false"
true != false # true

# Is 5 greater than 4?
5 > 4 # true

# Is 3 less than or equal to 2?
3 <= 2 # false
```
