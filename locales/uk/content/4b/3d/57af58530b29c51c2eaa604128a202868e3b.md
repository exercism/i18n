# Інструкції

Ми ініціалізуємо порожні буфери та виводимо список перших пʼяти чисел, або елементів, послідовності Фібоначчі.

Послідовність Фібоначчі - це набір чисел, де кожен наступний елемент дорівнює сумі двох попередніх. Починаємо послідовність з одиниці. Тож перші два елементи - це 1 і 1.

## 1. Створіть буфер із `count` нулів.

Створіть функцію, яка створює буфер із `count` нулів.

```rust
let my_buffer = create_buffer(5);
// [0, 0, 0, 0, 0]
```

## 2. Виведіть перші пʼять елементів послідовності Фібоначчі

Створіть функцію, яка повертає перші пʼять чисел послідовності Фібоначчі.
Її перші пʼять елементів - це `1, 1, 2, 3, 5`

```rust
let first_five = fibonacci();
// [1, 1, 2, 3, 5]
```
