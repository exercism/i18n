# Вступ

## Булеві значення (англ. Boolean) в Julia

Значення «правда» і «неправда» представлені типом `Bool`.
Він містить лише два значення: `true` та `false`.

```julia-repl
julia> true
true

julia> false
false
```

## Булеві оператори

У Julia є три булеві оператори.

`&&` позначає логічне «і».
Він набуває значення `true`, якщо вирази з *обох* боків `&&` дорівнюють `true`.

```julia-repl
julia> true && true
true

julia> true && false
false
```

`||` позначає логічне «або».
Він набуває значення `true`, якщо вираз з *будь-якого* боку `||` дорівнює `true`.

```julia-repl
julia> true || true
true

julia> false || true
true
```

`!` позначає логічне заперечення.
Він міняє місцями значення `true` і `false`.

```julia-repl
julia> !true
false

julia> !false
true
```

Для довших і складніших виразів краще використовувати дужки, щоб чітко показати, що ми маємо на увазі.

```julia-repl
julia> (true || false) && (false && true)
false
```
