# Докладніше

[Мапи][maps] - це структура даних, яка зберігає пари ключ-значення.

- Ключі можуть бути будь-якого типу, але мають бути унікальними.
- Значення можуть бути будь-якого типу, вони не обовʼязково мають бути унікальними.
- Мапи не гарантують порядок свого вмісту, хоч і справляють таке враження.
  - Це хибне враження створює їхня внутрішня реалізація:
    - За малого розміру (<=32 елементів) вони реалізовані як упорядкований [список ключових слів][keyword-list].
    - За більшого розміру (>32 елементів) вони реалізовані як [hash array mapped trie][hamt] &#91;[1][stackoverflow]&#93;.
- Мапи можна оголосити за допомогою літеральної форми:

  ```elixir
  # An empty map
  %{}

  # A map with the atom key :a associated to the integer value 1
  %{a: 1}

  # A map with the string key "a" associated to the float value 2.0
  %{"a" => 2.0}

  # A map with the map key %{} with the list value [1 ,2, 3]
  %{%{} => [1, 2, 3]}

  # A map with keys of different types
  %{:a => 1, "b" => 2}
  ```

- Мапи також можна створити за допомогою [`Map.new`][map-new] з [модуля Map][map-module]. Це може стати в нагоді, якщо в нас уже є перелічувана колекція, яку потрібно перетворити на список:

  ```elixir
  kw_list = [a: 1, b: 2]
  Map.new(kw_list)
  # => %{a: 1, b: 2}
  ```

- До значень у мапі можна отримати доступ багатьма різними способами:

  ```elixir
  my_map = %{key: "value"}

  # with a dot if the key is an atom
  my_map.key
  # => "value"

  # with [], a syntax provided by the Access behaviour
  my_map[:key]
  # => "value"

  # with pattern matching
  %{key: x} = my_map
  x
  # => "value"

  # with Map.get/2
  Map.get(my_map, :key)
  # => "value"
  ```

- [Модуль Map][map-module], що входить до стандартної бібліотеки, має багато корисних функцій для роботи з мапами.

  ```elixir
  Map.delete(%{a: 2, b: 3}, :a)
  # => %{b: 3}
  ```

- Мапи реалізують протокол [`Enumerable`][enumerable], що дозволяє використовувати функції [модуля Enum][enum].
- [Анонімні функції][anon-fn] або [захоплені посилання на функції][captured-fn] часто потрібні як аргументи для функцій [Map][map-module] та [модуля Enum][enum]

  ```elixir
  # Increment the value by one, if it is not found, update it with 0
  Map.update(%{a: 1}, :a, 0, &(&1 + 1))
  # => %{a: 2}

  # Sorting by a specific sub-value
  list = [{"A", 4}, {"B", 3}, {"C", 2}, {"D", 1}]
  Enum.sort_by(list, &Kernel.elem(&1, 1))
  # => [{"D", 1}, {"C", 2}, {"B", 3}, {"A", 4}]
  ```
