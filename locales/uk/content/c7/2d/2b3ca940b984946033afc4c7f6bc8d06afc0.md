# Додаток до інструкцій

Для треку Python у цій вправі потрібно створити _клас_ `SpaceAge` (_[concept:python/classes]()_), який містить методи для всіх планет Сонячної системи.
Методи мають дотримуватися угоди про найменування `on_<planet name>`.

Кожен метод має повертати (`return`) вік (_«на» цій планеті_) у роках, округлений до двох знаків після коми:

```python
#creating an instance with one billion seconds, and calling .on_earth().
>>> SpaceAge(1000000000).on_earth()

#This is one billion seconds on Earth in years
31.69
```
