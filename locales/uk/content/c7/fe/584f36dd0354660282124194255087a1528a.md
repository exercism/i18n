# Про

У чистій функціональній мові, як-от Elm, функція, викликана з тими самими аргументами, завжди повинна повертати те саме значення.
Тож функцію з сигнатурою типу `rand : Int` можна реалізувати лише як (`rand = 4`)[xkcd-random], що не віщує нічого доброго для генерування випадкових цілих чисел.

То як же нам генерувати випадкові значення в Elm?
Розділімо задачу на дві частини: спершу опишімо значення, яке хочемо згенерувати, за допомогою `Random.Generator a`, а потім згенеруймо значення.

Перший спосіб згенерувати значення - створити `Random.Seed` за допомогою `initialSeed : Int -> Seed`.
`Seed` - це непрозорий тип, який містить ціле число і знає, як перетворити його так, щоб результат мав вигляд випадкового (це називають псевдовипадковістю).
Коли в нас є `Seed`, ми можемо скористатися ним, щоб згенерувати значення за допомогою `Generator a`.
`Generator a` - це непрозорий тип, який знає, як використати ціле число всередині seed, щоб створити псевдовипадкове значення типу `a`, а також новий seed з оновленим цілим числом.

Щоб згенерувати значення, ми можемо скористатися `step : Generator a -> Seed -> ( a, Seed )`, яка повертає значення і новий seed, який ми можемо використати для генерування наступних значень.

Скористаймося цими функціями, щоб добути `n` випадкових значень із генератора:

```elm
generate : Int -> Generator a -> List a
generate n generator = generateValuesFromSeed n generator (Random.initialSeed 42)

generateValuesFromSeed : Int -> Generator a -> Seed -> List a
generateValuesFromSeed n generator seed =
    if n <= 0 then
        []
    else
        let ( value, nextSeed ) = Random.step generator seed
        in value :: generateValuesFromSeed (n - 1) generator nextSeed
```

Зауважмо, що всі ці функції чисті, тож виклик їх двічі з тими самими аргументами дасть ті самі значення.

```elm
generate 10 (Random.int 1 6)
    --> [4, 5, 3, 3, 5, 1, 2, 4, 6, 6]

generate 10 (Random.int 1 6)
    --> [4, 5, 3, 3, 5, 1, 2, 4, 6, 6]
```

Другий спосіб згенерувати значення - скористатися `Random.generate : (a -> msg) -> Generator a -> Cmd msg`, але це можна зробити лише всередині застосунку Elm.
У такому разі середовище виконання Elm може використовувати `step`, а також зовнішні, не чисті ресурси, щоб створювати seed, і виклик тієї самої функції двічі дасть різні результати.

Далі ми зосередимося на генераторах.

Модуль `Random` надає два базові генератори для створення цілих чисел і чисел з плаваючою комою в межах заданого діапазону:

```elm
generate 5 (Random.int -5 5)
    --> [0, 3, -5, 5, 0]

generate 3 (Random.float 0 5)
    --> [1.61803, 3.14159, 2.71828]
```

Ці значення можна поєднати в кортежі або в масиви значень:

```elm
generate 2 (Random.list 3 (Random.int 0 3))
    --> [[0, 3, 3], [1, 3, 2]]

generate 2 (Random.pair (Random.int 0 3) (Random.float 10 10.3))
    --> [(0, 10.23412), (2, 10.17094)]
```

Пакунок (`elm-community/random-extra`)[random-extra] надає набагато більше генераторів для різних структур даних: рядків тексту (англ. string), дат, словників, масивів, множин тощо.

Ми можемо створювати генератори, які повертають лише одне значення, за допомогою `Random.constant`:

```elm
generate 4 (Random.constant "hello")
    --> ["hello", "hello", "hello", "hello"]
```

Ми можемо випадково вибирати з-поміж заданих елементів з однаковою імовірністю за допомогою `Random.uniform`:

```elm
generate 5 (Random.uniform Red [Green, Blue])
    --> [Red, Blue, Blue, Green, Red]
```

`Random.uniform` приймає два аргументи (`Red` і `[Green, Blue]`), щоб гарантувати, що є принаймні одне значення для вибору, адже єдиний масив міг би бути порожнім.

Ми також можемо скоригувати імовірності за допомогою `Random.weighted`:

```elm
generate 5 (Random.weighted (80, Red) [(15, Green), (5, Blue)])
    --> [Red, Red, Green, Red, Red]
```

Значення не обовʼязково мають давати в сумі 100, їх усе одно буде нормалізовано заново.

Ми можемо дістатися до внутрішньої частини генератора за допомогою `Random.map`:

```elm
generate 3 (Random.int 1 6 |> Random.map (\n -> n * 10))
    --> [30, 60, 10]
```

Ми також можемо використовувати `Random.map2` аж до `Random.map5`, щоб поєднати більше генераторів:

```elm
position =
    Random.map3
      (\x y z -> Position x y z)
      (Random.float -100 100)
      (Random.float -100 100)
      (Random.float -100 100)

generate 1 position
    --> [Position 33.788 -98.321 10.0845]
```

Для складніших випадків у нас є `Random.andThen : (a -> Generator b) -> Generator a -> Generator b`, яка може використати значення, згенероване одним генератором, щоб створити інший:

```elm
bool = Random.uniform True [False]

failHalfOfTheTime : Generator a -> Generator (Maybe a)
failHalfOfTheTime generator =
    bool
        |> Random.andThen
            (\boolResult ->
                if boolResult then
                    Random.map Just generator

                else
                    Random.constant Nothing
            )

generate 6 (Random.int 0 1 |> failHalfOfTheTime)
    --> [Nothing, Just 1, Just 0, Nothing, Just 1, Nothing]
```

Іноді корисно визначити генератор рекурсивно щодо самого себе.
У таких випадках може знадобитися `Random.lazy`, щоб не дати компілятору розгортати генератор нескінченно.

```elm
type Peano
    = Zero
    | Next Peano


peano : Generator Peano
peano =
    Random.uniform (Random.constant Zero)
        [ Random.map Next (Random.lazy (\_ -> peano))
        ]
        |> Random.andThen identity

generate 12 peano
    --> [Zero, Next(Next(Zero)), Zero, Next(Zero), Zero, Zero, Next(Zero), Zero, Zero, Next(Zero), Next(Next(Next(Zero)))]
```

Цей приклад трохи складний, тож розберімо його.

`Peano` - це тип, який представляє додатні цілі числа: `Zero` - це 0, `Next(Zero)` - це 1, `Next(Next(Zero))` - це 2, і так далі.
Ми визначаємо `peano`, щоб отримувати випадкове число `Peano`.

Насамперед зауважмо, що `Random.lazy` нічого не додає до логіки, він лише заважає компілятору нескінченно вписувати `peano` в `peano`.

Ми використовуємо `Random.uniform`, щоб вибрати між нулем (з імовірністю 50%) і ще одним числом `Peano` плюс один (з імовірністю 50%).
Однак, на відміну від попереднього прикладу, `Random.uniform` вибирає не зі значень (як-от `Zero`), а з генераторів (як-от `Random.constant Zero`), бо ми хочемо використати сам `peano`.
Це означає, що `Random.uniform` поверне значення типу `Generator (Generator Peano)`, а це не те, що нам потрібно.

Щоб «сплющити» генератор, ми пропускаємо його через `Random.andThen : (a -> Generator b) -> Generator a -> Generator b`, де хочемо, щоб `b` було `Peano`.
Оскільки `Generator a` - це `Generator (Generator Peano)`, `a` має бути `Generator Peano`, а функція `(a -> Generator b)` має бути типу `(Generator Peano -> Generator Peano)`.
Ми не хочемо нічого змінювати, тож `identity` - правильний вибір.

І нарешті, які числа буде генерувати `peano`?
Ми знаємо, що він даватиме 0 у 50% випадків, або ще одну ітерацію себе плюс один у 50% випадків.
Це означає, що числа будуть такими: 0 (у 50% випадків), 1 (у 25% випадків), 2 (у 12% випадків), 3 (у 6% випадків) тощо.
`peano` може видавати як завгодно великі числа, але з імовірністю, що експоненційно спадає.
