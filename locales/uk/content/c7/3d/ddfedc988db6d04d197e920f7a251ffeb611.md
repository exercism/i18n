У Raku блоки коду використовуються дуже широко.
Вони є основою для функцій, але також трапляються в таких інструментах, як `grep` і `map`, як блоки інструкцій `if`, `for`, `while` і `given`, і навіть в індексах масивів.

## Рутини

[`Subs`][type/Sub] і [`Methods`][type/Method] - це різновиди [`Routines`][type/Routine] у Raku.

Рутину можна завершити будь-коли з поверненим значенням за допомогою ключового слова [`return`][control-return], що є корисним інструментом для створення функцій.
Якщо `return` не вказано, остання інструкція рутини буде її неявним поверненим значенням.

Рутина може мати [`Signature`][language/signatures] у дужках перед блоком коду.

[`Routine`][type/Routine] - це підклас [`Block`][type/Block].

```raku
sub add ($x, $y --> Int) { return $x + $y }
say add(1, 2); # 3
```

Методи буде розглянуто в окремій концепції, присвяченій класам і обʼєктам.

## Блоки

[`Block`][type/Block] - це обʼєкт коду, який можна використовувати повторно; зазвичай його застосовують для створення лямбд.

Остання інструкція блоку - це його неявне повернене значення.

Блок може мати [`Signature`][language/signatures] з префіксом `->` перед блоком коду.

[`Block`][type/Block] - це підклас [`Code`][type/Code], який є найвищим базовим класом усіх обʼєктів коду в Raku.

```raku
my $add = -> $x, $y { $x + $y };
say $add(1, 2); # 3
```

## Сигнатури

[`Signature`][language/signatures] складається з нуля або більше [`Parameters`][type/Parameter], розділених комами.

У кінці сигнатури можна вказати тип повернення за допомогою [стрілки типу повернення][signatures-return-type-arrow] `-->`.

Сигнатуру можна використати, щоб указати аргументи, які прийматиме `Block`.

У цій концепції ми тримаємо сигнатури простими: використовуємо лише позиційні параметри зі скалярним сигілом і тип повернення.
Докладніше про них ітиметься в інших концепціях.

## Мультидиспетчеризація

Raku дає змогу писати кілька рутин з однаковою назвою, але різними сигнатурами, використовуючи ключове слово `multi`.
Цю можливість називають [мультидиспетчеризацією][multi-dispatch].
Коли рутину викликають за назвою, середовище виконання визначає відповідного кандидата й викликає його.

Докладніше про це йтиметься в концепції про типи.

```raku
multi foo () { say 'No arguments given'}

multi foo ($bar) { say "One argument given: $bar" }
```

## WhateverCode

Коли зірочка `*` [`Whatever`][type/Whatever] поєднується з більшістю операторів, створюється обʼєкт [`WhateverCode`][type/WhateverCode].
Це дає змогу створювати блоки з простішим синтаксисом.

```raku
# These will all give code blocks that increment a single argument by 1:
-> $x { $x  + 1 }; # Explicit signature
      { $^x + 1 }; # Signature via placeholder variable
      { $_  + 1 }; # Topic variable
          * + 1;   # WhateverCode
```
