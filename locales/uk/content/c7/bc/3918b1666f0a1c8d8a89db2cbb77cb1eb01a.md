# Вступ

У Java перевантаження методів - це можливість, яка дозволяє класу мати більш ніж один метод з однаковою назвою, якщо
їхні списки параметрів різні.
Воно повʼязане з поліморфізмом часу компіляції (або статичним поліморфізмом).
Це поняття має вирішальне значення для
створення методів, які виконують схожі завдання, але з різними вхідними даними.

## Навіщо перевантажувати методи?

Перевантаження методів підвищує читабельність програми.
Різним методам можна дати однакову назву, але з
різними параметрами.
Залежно від кількості параметрів або їхнього типу викликається відповідний метод.

## Як перевантажувати методи?

Ключ до перевантаження методів - сигнатура методу.
Два методи будуть вважатися різними, якщо вони мають різні сигнатури.
Існує два способи перевантажити метод:

1. **Різна кількість параметрів**: методи можуть мати однакову назву, але різну кількість параметрів.

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(int x, int y) {
           System.out.println("Show with two ints: " + x + ", " + y);
       }
   }
   ```

2. **Різні типи параметрів**: методи можуть мати однакову назву й однакову кількість параметрів, але
   різних типів.

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(String s) {
           System.out.println("Show with String: " + s);
       }
   }
   ```

## Що варто запамʼятати

- Перевантажені методи повинні змінювати список аргументів.
- Перевантажені методи можуть також змінювати тип повернення, але сама лише зміна типу повернення не робить метод
  перевантаженим.
- Методи можна перевантажувати в тому самому класі або в підкласі.

У цьому понятті ми розглянемо різні приклади та нюанси перевантаження методів у Java.
