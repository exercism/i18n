## Редактори

### Безкоштовні та з відкритим кодом

- [VS Code](https://code.visualstudio.com)

  VS Code - це редактор коду з відкритим кодом. Про те, як налаштувати TypeScript, можна прочитати [тут](https://code.visualstudio.com/docs/languages/typescript). VS Code - популярний редактор для TypeScript, бо Microsoft підтримує і VS Code, і TypeScript, тож він добре працює з цією мовою; VS Code підтримує TS без жодного додаткового налаштування. До того ж, сам VS Code написано на TypeScript!

  Поширена проблема з VS Code і TS виникає, коли версії редактора і проєкту різняться: тоді VS Code може показати помилку, яка збиває з пантелику. Як діяти в такому разі, описано [тут](https://code.visualstudio.com/docs/typescript/typescript-compiling#_using-newer-typescript-versions)

### Ліцензовані

- [Sublime Text](https://www.sublimetext.com)

  Sublime Text - популярний редактор коду, який підтримує більшість мов за допомогою встановлюваних плагінів. Його можна безкоштовно спробувати, але час від часу зʼявлятиметься нагадування придбати ліцензію, яка зараз коштує \$70 USD.

- [WebStorm](https://www.jetbrains.com/webstorm/)

  WebStorm - це повнофункціональне інтегроване середовище розробки (IDE) для JavaScript і TypeScript. Він підтримує TypeScript без додаткового налаштування, а також має вбудоване тестування, зневадження й аналіз коду. Його можна безкоштовно спробувати протягом 30 днів, а далі річна ліцензія коштує \$129 USD за перший рік.
