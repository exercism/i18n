## Кортеж

[Кортежі][tuple] часто використовують, щоб згрупувати інформацію. Вони відрізняються від масивів тим, що мають фіксований розмір і можуть містити значення різних типів.
Кортежі створюють за допомогою дужок `()`, і часто їх використовують, щоб повернути з функції кілька значень.

```haskell
tuple = (1, "abc", False)
```

Це стає в пригоді, коли ми, наприклад, хочемо зберегти координату на двовимірній площині: тоді ми знаємо, що кортеж завжди матиме два елементи, координати x та y.

```haskell
coordinate = (3, 4)
```

### Доступ до елементів

Досить часто ми працюємо з короткими кортежами, і тоді можна дістатися до елементів за допомогою функцій `fst` і `snd`.

```haskell
x = fst coordinate
-- x = 3
y = snd coordinate
-- y = 4
```

## Зіставлення зі зразком

Пишучи функції на Haskell, ми можемо застосувати [assertive-стиль][assertive-style] із [зіставленням зі зразком][pattern-match-doc]:
Зіставлення зі зразком - це дуже потужна можливість Haskell, яка дозволяє зіставляти конструктори даних і звʼязувати змінні зі значеннями всередині.
Як видно з назви, ми зіставляємо значення зі зразками, і якщо значення відповідає зразку, ми можемо звʼязати змінні зі значеннями всередині зразка.
Зіставлення зі зразком здебільшого складається з таких понять: розпізнавання значень, звʼязування змінних і розкладання значень на частини.

Візьмімо для прикладу таку функцію:

```haskell
lucky :: Int -> String
lucky 7 = "Lucky number seven!"
lucky x = "Sorry, you're out of luck, pal!"
```

Тут ми маємо функцію `lucky`, яка приймає `Int` і повертає `String`.
Ми визначили для функції два зразки: один відповідає числу `7`, а другий - будь-якому іншому числу. Імʼя може бути будь-яким (аби воно відповідало правилам найменування в Haskell), але тут ми використовуємо `x`.
Якщо число дорівнює `7`, функція поверне `"Lucky number seven!"`, інакше вона поверне `"Sorry, you're out of luck, pal!"`.
Важливо зауважити, що зразки перевіряють згори вниз, тож якби ми поміняли порядок зразків, функція завжди повертала б `"Lucky number seven!"`.

### Зразки для масивів

Дуже поширений зразок - це зіставлення з масивами, коли ми беремо голову та хвіст масиву.
Це повʼязано з тим, що масив за своєю природою є звʼязаним списком.
Ось приклад функції, яка повертає голову та хвіст масиву:

```haskell
headAndTail :: [Int] -> (Int, [Int])
headAndTail [] = error "Can't call head on an empty list"
headAndTail (x:xs) = (x, xs)
```

Тут ми маємо два зразки: один відповідає порожньому масиву, а другий - масиву з принаймні одним елементом.
Це тому, що якщо масив порожній, нам потрібен окремий випадок для нього, інакше ми отримаємо помилку під час виконання.
Якщо масив не порожній, ми можемо зіставити голову масиву з `x`, а хвіст масиву з `xs`.
Це робиться за допомогою оператора `:` (cons), який додає елемент на початок масиву.
Але в зіставленні зі зразком він дозволяє розкласти масив на голову та хвіст, тобто, певною мірою, робить протилежне.

`xs` - поширена назва для хвоста масиву, вона підкреслює, що це масив, але якщо ми працюємо з вкладеним масивом, можна взяти `xss`, щоб підкреслити, що це масив масивів.

### Зразки для кортежів

Як і з масивами, ми можемо зіставляти й кортежі.
Ось приклад функції, яка приймає кортеж і повертає перший та другий елементи:

```haskell
sumTuple :: (Int, Int) -> Int
sumTuple (x, y) = x + y
```

Тут ми маємо зразок, що відповідає кортежу з двох елементів: перший елемент звʼязується з `x`, а другий - з `y`.

### Зразки з підстановкою

Інколи значення змінної нам не потрібне, ми просто хочемо зіставити зі зразком.
Саме тут стає в пригоді зразок із підстановкою, який позначають підкресленням `_`.

Ось приклад функції, яка повертає перший елемент масиву:

```haskell
head' :: [Int] -> Int
head' [] = error "Can't call head on an empty list"
head' (x:_) = x
```

Тут ми кажемо, що хвіст масиву нам не потрібен, тож використовуємо зразок із підстановкою, щоб його проігнорувати.

### Зразки для типів

Ми також можемо зіставляти за типами. Для цього використовують конструктор відповідного типу.
Так само ми можемо витягувати значення з типу, як робили це з кортежами.

```haskell
data AccountType = Guest | User String 

greet :: AccountType -> String
greet Guest = "Welcome, guest!"
greet (User name) = "Welcome, " ++ name ++ "!"
```

У першому зразку ми зіставляємо з конструктором `Guest`, а в другому - з конструктором `User`, звʼязуючи значення всередині з `name`.
