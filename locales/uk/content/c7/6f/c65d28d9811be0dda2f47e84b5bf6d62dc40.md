# Вступ

[concept:csharp/resource-cleanup]() використовує інтерфейс `IDispose`, щоб дати знати, що ресурс певного обʼєкта або інший стан програми потрібно було звільнити чи скинути, коли обʼєкт більше не був потрібен (і що покладатися на збирач сміття не дозволило б цього досягти чи забезпечити потрібний рівень контролю), а метод `IDisposable.Dispose()` був природним місцем для таких операцій очищення.

Є ще одна конструкція, блок `using`, яка дає змогу з погляду того, хто викликає, зібрати все керування часом життя ресурсів в одну інструкцію.

```csharp
using (var file = new File("my_secrets"))
{
    file.WriteSecret("xxxxxxx");
}
```

У наведеному вище прикладі ресурси файлової системи, повʼязані з `file`, буде звільнено й повернуто операційній системі, коли ми виходимо з блоку `using`.

Щоб ця схема працювала, змінна в інструкції `using` має бути посилального типу, який реалізує інтерфейс `IDisposable`, і має звільняти ресурси чи скидати стан програми у своєму методі `Dispose()`.

C# 8 пропонує вдосконалення цієї схеми. Інструкцію `using` можна розмістити на початку блоку.

```csharp
using var drawingResource = some_provided_or_new_object;
try
{
    drawingResource.DrawSomething();
}
catch (Exception)
{
    throw;
}
```

Розробники на Java можуть упізнати в цьому аналог механізму _автоматичного керування ресурсами_, запровадженого в Java 7.
