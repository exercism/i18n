# Вступ

`string` у Clojure - це рядок тексту (англ. string) з Java, тобто обʼєкт, який представляє незмінний текст як послідовність символів Unicode (літер, цифр, розділових знаків тощо).

Бібліотека `clojure.string` надає багато стандартних функцій для маніпулювання та обробки рядків тексту. Крім того, усі звичайні методи Java для роботи з рядками тексту доступні через взаємодію з Java.
