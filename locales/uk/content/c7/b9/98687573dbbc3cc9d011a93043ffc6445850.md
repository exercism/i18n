# Підказки

## Загальне

- Для генерації випадкових чисел можна використати [клас Random][random-class].
- Докладніше в статті: [Генератори випадкових чисел у Java 17][random-number-generators].

## Генерація лабіринту

Для генерації ідеального лабіринту можна використати будь-який алгоритм. Хорошим вибором буде [рекурсивний бектрекер][recursive-backtracker].
