# Інструкції

У місті відкрився новий поетичний клуб, і ми думаємо, чи не відвідати його.
Через інциденти в минулому клуб має дуже специфічні правила входу, які потрібно опанувати, перш ніж намагатися потрапити всередину.

У поетичному клубі є двоє дверей, передні та задні, і обидвоє охороняють.
Щоб потрапити всередину, потрібно розгадати пароль дня.

Пароль завжди ґрунтується на вірші, і його можна визначити у два кроки.

1. Охоронець читає вірш, по одному рядку за раз, а ми маємо відповідати відповідною літерою цього рядка.
2. Далі охоронець називає всі літери, якими ми відповідали, одразу, а нам потрібно записати їх на аркуші паперу в певному форматі.

Подробиці процесу залежать від того, до яких дверей ми намагаємося увійти.

~~~~exercism/note
Усі рядки тексту (англ. string) у цій вправі мають кодування ASCII й завершуються символом NUL.
Це означає, що всі символи використовують кодування ASCII, а кожен рядок тексту закінчується там, де трапляється '\0' (символ NUL зі значенням `0`).
~~~~

~~~~exercism/note
Ось рядкові інструкції, згадані в цьому концепті:

| інструкція  | що вона робить                                                                                                    |
|-------------|-------------------------------------------------------------------------------------------------------------------|
| `lods`      | завантажує значення з ділянки памʼяті, на яку вказує `rsi`, у `rax`                                               |
| `stos`      | записує значення з `rax` у ділянку памʼяті, на яку вказує `rdi`                                                   |
| `movs`      | копіює значення з ділянки памʼяті, на яку вказує `rsi`, і записує його в ділянку памʼяті, на яку вказує `rdi`      |

Усі вони повинні мати суфікс, який указує розмір операції:

| суфікс | розмір              |
|--------|---------------------|
| `b`    | байт                |
| `w`    | слово (2 байти)     |
| `d`    | подвійне слово (4 байти) |
| `q`    | чотириразове слово (8 байтів) |

Усі рядкові інструкції також змінюють адреси в `rsi` та/або `rdi` (лише в тих регістрах, які використовує інструкція).
Якщо не вказано іншого, вони збільшують адреси на розмір операції.

Префікс `rep` можна додати до будь-якої з наведених вище рядкових інструкцій, щоб повторити її стільки разів, скільки вказує `rcx`.
~~~~

## 1. Отримати першу літеру речення

Щоб визначити літери для пароля від передніх дверей, потрібно відповідати першою літерою того рядка вірша, який читає охоронець.

Щоб пароль вийшов гарним, члени поетичного клубу люблять використовувати _акровірші_.
Це означає, що перша літера кожного речення утворює слово.
Ось приклад одного з їхніх улюблених авторів, Майкла Локвуда.

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

Тож коли охоронець читає **Stands so high**, ми відповідаємо **S**, а коли охоронець читає **Huge hooves too**, відповідаємо **H**.

Реалізуйте функцію `front_door_response`, яка приймає як аргумент адресу в памʼяті рядка вірша й повертає першу літеру цього рядка.
Цю літеру потрібно повернути як символ у кодуванні ASCII, що займає 1 байт.

```c
front_door_response("Stands so high");
// => 'S'
```

## 2. Написати слово з великої літери

Тепер, коли в нас є всі потрібні літери, щоб отримати пароль від передніх дверей, достатньо лише правильно написати це слово з великої літери.

Реалізуйте функцію `front_door_password`, яка приймає як аргумент адресу в памʼяті рядка тексту, що містить лише обʼєднані літери, знайдені в завданні 1.
Вона повинна змінити вхідний рядок тексту [на місці][in-place], щоб той мав правильний регістр.
Це означає, що правильний рядок тексту потрібно зберегти в тій самій ділянці памʼяті, де й вхідний.

Функція не має поверненого значення.

```c
front_door_password('SHIRE');
// => buffer == "Shire"

front_door_password('shire');
// => buffer == "Shire"
```

## 3. Отримати останню літеру речення

Щоб визначити літери для пароля від задніх дверей, потрібно відповідати останньою літерою того рядка вірша, який читає охоронець.

Члени поетичного клубу справді кмітливі.
Згаданий раніше вірш також належить до _телестихів_, тобто остання літера кожного речення теж утворює слово:

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

Коли охоронець читає **Stands so high**, ми відповідаємо **h**, а коли охоронець читає **Huge hooves too**, відповідаємо **o**.

Зауважмо, що іноді охоронець робить стилістичні паузи (у вигляді розділових знаків або пробілів), коли читає вірш.
Щоб визначити правильну літеру, ці паузи потрібно ігнорувати.

Реалізуйте функцію `back_door_response`, яка приймає як аргумент адресу в памʼяті рядка вірша й повертає останню літеру цього рядка.
Цю літеру потрібно повернути як символ у кодуванні ASCII, що займає 1 байт.

```c
back_door_response('Stands so high');
// => "h"

back_door_response('Stands ... so high   ');
// => "h"
```

## 4. Бути ввічливими

Щоб потрапити до поетичного клубу через задні двері, треба бути особливо ввічливими.
Тож цього разу, щоб визначити пароль, потрібно правильно написати слово з великої літери й додати `", please."` у кінці.

Реалізуйте функцію `back_door_password`, яка приймає аргументи в такому порядку:

1. Адресу в памʼяті буфера, де буде збережено результуючий рядок тексту.
2. Адресу в памʼяті рядка тексту, що містить обʼєднані літери, знайдені в завданні 3.

Функція повинна зберегти ввічливу версію пароля, написаного з великої літери, у [буфері][buffer].
_Буфером_ називають масив, який можна використовувати для зберігання значень у памʼяті, щоб передавати їх між різними функціями.

Ця функція не має поверненого значення.

```c
back_door_password("horse");
// => "Horse, please."
```
