# Підказки

## Загальне

- [Непоправні помилки][unrecoverable]: викликати паніку з повідомленням про помилку.
- [Макрос `panic!`][panic-excl-macro]: викликати паніку з повідомленням про помилку типу `ByteArray`.
- [Макрос `assert!`][assert]: викликати паніку, якщо умова обчислюється як `false`.
- [Перелічення `Result`][result]: як використовувати перелічення `Result`.

## 2. Опрацювання неприпустимих операцій

- Тут потрібно [повернути помилку][result].

- Тут потрібно [викликати паніку][panic-excl-macro] з повідомленням типу `ByteArray`, щоб опрацювати порожні рядки тексту (англ. string) для операцій.

## 4. Опрацювання помилок при діленні на нуль
