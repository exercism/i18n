# Докладніше

Цикл `do-while` - це альтернатива циклу `while`, з тією лише різницею, що він виконується принаймні один раз:

```haxe
var i = 0;

do {
  trace("Hello");
} while (i < 10);
```

Випадки, коли варто використати цикл `do-while`, трапляються дуже рідко, тож натомість використовують звичайний цикл `while`.
