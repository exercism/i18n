# Доповнення до інструкцій

## Регістри

| Регістр  | Використання       | Тип        | Опис                        |
| -------- | ------------------ | ---------- | --------------------------- |
| `$a0`    | вхідні дані        | ціле число | кількість рядків трикутника |
| `$a1`    | вхідні/вихідні дані| адреса     | масив слів                  |
| `$v0`    | вихідні дані       | ціле число | кількість вихідних слів     |
| `$t0-9`  | тимчасовий         | будь-який  | для тимчасового зберігання  |
