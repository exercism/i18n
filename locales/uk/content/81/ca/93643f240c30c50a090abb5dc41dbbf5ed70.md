# Докладніше

Тип `Bool` належить до будівельних блоків мови.
Він покликаний описувати, чи щось є правдою або неправдою, за допомогою відповідних значень `True` і `False`.
Назва `Bool` є скороченням від булевих значень (англ. Boolean), повʼязаних із розділом математики про логічне мислення, названим на честь робіт Джорджа Буля.

## Булеві оператори

Існують дві функції та два оператори для роботи зі значеннями типу `Bool`.

- `not : Bool -> Bool`
  Ця функція перетворює `True` на `False`, а `False` на `True`.
- `(&&) : Bool -> Bool -> Bool`
  Цей оператор, який називають «AND», приймає два булеві значення й повертає `True`, якщо обидва з них `True`.
  Наприклад, `True && True` повертає `True`, а `True && False` повертає `False`.
- `(||) : Bool -> Bool -> Bool`
  Цей оператор, який називають «OR», приймає два булеві значення й повертає `True`, якщо принаймні одне з них `True`.
  Наприклад, `False || False` повертає `False`, а `True || False` повертає `True`.
- `xor : Bool -> Bool -> Bool`
  Ця функція (не оператор), яку називають «XOR», приймає два булеві значення й повертає `True` тоді й лише тоді, коли одне з них `True`, а друге `False`.

Оператори `&&` і `||` не мають однакового пріоритету.
Пріоритет `&&` вищий, ніж у `||`, так само, як із множенням `*` і додаванням `+`.
Як наслідок, вираз `True || False && False` еквівалентний `True || (False && False)`, що відрізняється від `(True || False) && False`.
Перший повертає `True`, а другий повертає `False`.

## Умовне розгалуження

Булеві значення надзвичайно корисні для створення розгалужень у коді, які виконуються лише за виконання певних умов.
У Elm це робиться за допомогою виразу `if-then-else`, який використовують так.

```elm
if someCondition || (someOtherCondition && anotherCondition) then
    doSomething
else
    doSomethingElse
```

Значення `someCondition` може бути будь-яким виразом, що повертає `Bool`.
Якщо це булеве значення `True`, код виконає `doSomething`.
Інакше воно дорівнює `False`, і код виконає `doSomethingElse`.
Гілка `else` обовʼязкова, на відміну від деяких інших мов програмування.

Якщо потрібно поєднати умови, можна просто поєднати вирази `if-then-else`.

```elm
if someCondition then
    doSomething
else if someOtherCondition then
    doAnotherThing
else
    doSomethingElse
```
