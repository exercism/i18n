# Вступ

## Цілі числа

В Elixir є два різних види чисел: цілі числа та числа з плаваючою комою.

Цілі числа - це числа без дробової частини.

```elixir
integer = 3
# => 3
```

## Числа з плаваючою комою

Числа з плаваючою комою - це числа з однією або більше цифрами після десяткового розділювача. Вони використовують 64-бітний формат із плаваючою комою подвійної точності.

```elixir
float = 3.45
# => 3.45
```

### Робота з числами

У модулях [`Integer`][integer-functions] і [`Float`][float-functions] можна знайти корисні функції для роботи з цими типами. Базові арифметичні оператори визначено в модулі [`Kernel`][kernel-arithmetic-operators].

### Перетворення

Цілі числа та числа з плаваючою комою можна поєднувати в одному арифметичному виразі. Якщо у виразі використати число з плаваючою комою, результат теж буде числом з плаваючою комою.

```elixir
2 * 3
# => 6

2 * 3.0
# => 6.0
```

Однак під час ділення результат завжди буде числом з плаваючою комою, навіть якщо використано лише цілі числа.

```elixir
6 / 2
# => 3.0
```

Щоб перетворити число з плаваючою комою на ціле число, можна відкинути дробову частину за допомогою [`trunc/1`][trunc-1].
