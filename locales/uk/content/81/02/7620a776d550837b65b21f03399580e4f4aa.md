# Інструкції

Ми завзято спостерігаємо за птахами і відстежуємо, скільки птахів відвідало наш сад за останні сім днів.

У нас є шість завдань, і всі вони стосуються кількості птахів, що відвідали наш сад.

## 1. Перевірте, якими були підрахунки минулого тижня

Для порівняння ми завжди тримаємо поруч копію підрахунків минулого тижня, а саме: 0, 2, 5, 3, 7, 8 і 4. Реалізуйте (_статичний_) метод `BirdCount.LastWeek()`, який повертає підрахунки минулого тижня:

```csharp
BirdCount.LastWeek();
// => [0, 2, 5, 3, 7, 8, 4]
```

## 2. Перевірте, скільки птахів відвідало наш сад сьогодні

Реалізуйте метод `BirdCount.Today()`, який повертає кількість птахів, що відвідали наш сад сьогодні. Підрахунки птахів упорядковано за днями: перший елемент показує кількість за найдавніший день, а останній - сьогоднішню.

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.Today();
// => 1
```

## 3. Збільште сьогоднішній підрахунок на одиницю

Реалізуйте метод `BirdCount.IncrementTodaysCount()`, який збільшує сьогоднішній підрахунок на одиницю:

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.IncrementTodaysCount();
birdCount.Today();
// => 2
```

## 4. Перевірте, чи був день, коли жоден птах не завітав до саду

Реалізуйте метод `BirdCount.HasDayWithoutBirds()`, який повертає `true`, якщо був день, коли жоден птах не відвідав сад; інакше повертає `false`:

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.HasDayWithoutBirds();
// => true
```

## 5. Обчисліть кількість птахів, що відвідали сад, за перші вказані дні

Реалізуйте метод `BirdCount.CountForFirstDays()`, який повертає кількість птахів, що відвідали наш сад від початку тижня, але обмежує підрахунок указаною кількістю днів від початку тижня.

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.CountForFirstDays(4);
// => 14
```

## 6. Обчисліть кількість завантажених днів

Деякі дні завантаженіші за інші. Завантажений день - це день, коли до нашого саду завітали пʼять або більше птахів.
Реалізуйте метод `BirdCount.BusyDays()`, який повертає кількість завантажених днів:

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.BusyDays();
// => 2
```
