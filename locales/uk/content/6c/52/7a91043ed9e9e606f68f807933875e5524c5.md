# Вступ

## Перелічення

Тип `enum` у C# представляє фіксований набір іменованих констант (перелічення). Його головна мета - забезпечити типобезпечний спосіб роботи з числовими константами, обмежуючи доступні значення заздалегідь визначеним набором. Простий enum можна визначити так:

```csharp
enum Season
{
    Spring,
    Summer,
    Autumn,
    Winter
}
```

Якщо не визначити значення явно, члени enum автоматично отримають цілі значення, що збільшуються на одиницю, а перше з них дорівнюватиме нулю. Також можна присвоїти значення явно:

```csharp
enum Answer
{
    Maybe = 1,
    Yes = 3,
    No = 5
}
```
