# Додаток до інструкцій

## Реалізація

Тести вимагають конструктора, який приймає масив. Внутрішня будова нашої реалізації власної множини може використовувати інші структури даних, але, щоб тести пройшли, можливо, доведеться реалізувати зовнішній конструктор, який приймає рівно один масив.

Деякі методи мають еквівалент у вигляді оператора Юнікод. Наприклад, виклик `intersect(CustomSet([1, 2, 3, 4]), CustomSet([]))` рівнозначний запису `CustomSet([1, 2, 3, 4]) ∩ CustomSet([])`.
