# Інструкції

У цій вправі ми писатимемо код, який друкує бейджі з іменами для працівників фабрики.

## 1. Надрукувати бейдж для працівника

У працівників є ідентифікатор, імʼя та назва відділу. Написи на бейджах працівників мають такий формат: `"[id] - name - DEPARTMENT"`. Реалізуйте (_статичний_) метод `Badge.Print()`, щоб він повертав напис на бейджі працівника:

```csharp
Badge.Print(734, "Ernest Johnny Payne", "Strategic Communication");
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

Зауважимо, що назву відділу в написі слід писати великими літерами.

## 2. Надрукувати бейдж для нового працівника

Через особливість компʼютерної системи нові працівники, починаючи роботу на фабриці, іноді ще не мають ідентифікатора. Оскільки бейджі обовʼязкові, вони отримують тимчасовий бейдж без префікса з ідентифікатором. Змініть (_статичний_) метод `Badge.Print()`, щоб він підтримував нових працівників, які ще не мають ідентифікатора:

```csharp
Badge.Print(id: null, "Jane Johnson", "Procurement");
// => "Jane Johnson - PROCUREMENT"
```

## 3. Надрукувати бейдж для власника

Навіть власник фабрики мусить весь час носити бейдж. Однак у власника немає відділу. У цьому випадку в написі замість назви відділу потрібно надрукувати `"OWNER"`. Змініть (_статичний_) метод `Badge.Print()`, щоб він друкував напис для власника:

```csharp
Badge.Print(254, "Charlotte Hale", department: null);
// => "[254] - Charlotte Hale - OWNER"
```

Зауважимо, що власник може бути також і новим працівником:

```csharp
Badge.Print(id: null, "Charlotte Hale", department: null);
// => "Charlotte Hale - OWNER"
```
