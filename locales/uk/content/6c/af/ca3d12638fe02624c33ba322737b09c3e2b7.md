# Діапазони

[Діапазони][range] позначають інтервал між двома значеннями.
Діапазони найчастіше підтримують типи `Integer` і `String`.
Їх можна використовувати для багатьох речей: швидкого створення колекції, зрізання рядків тексту (англ. string), перевірки, чи міститься значення в діапазоні, та ітерації.
Створюють їх за допомогою оператора діапазону `..` або `...` (включно та невключно відповідно).

```ruby
1..5  # => 1..5
1...5 # => 1...5

(1..5).to_a # => [1, 2, 3, 4, 5]
(1...5).to_a # => [1, 2, 3, 4]
```

Два оператори діапазону існують для того, щоб можна було створювати діапазони, які включають або не включають кінцеве значення. Це буває корисно, наприклад, коли ми працюємо з індексами, що починаються з нуля.

Діапазони також можна створювати за допомогою конструктора `Range`, тобто методу `new`.

```ruby
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
Коли ми створюємо діапазон у Ruby за допомогою операторів діапазону `..` або `...` і хочемо викликати метод у діапазону, потрібно взяти діапазон у дужки.
Інакше метод буде викликано для другого аргументу оператора діапазону.

```ruby
(1..5).sum # => 15
1..5.sum # => Error: undefined method `sum' for 5:Integer (NoMethodError)
```
~~~~

## Отримання підрядків

Коли потрібно зрізати рядок тексту, можна скористатися оператором діапазону, щоб отримати підрядок.
Для цього створюємо діапазон із початковим і кінцевим індексом підрядка.

```ruby
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

Також можна використовувати відʼємні індекси, щоб отримати підрядок із кінця рядка тексту.

```ruby
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## Методи діапазонів

Діапазони мають набір методів, які можна використовувати для роботи з ними.
Наприклад, ці методи дають змогу отримати суму всіх значень у діапазоні або перевірити, чи містить діапазон певне значення.

| Метод                   | Опис                                                                    | Приклад                         |
| ----------------------- | ----------------------------------------------------------------------- | ------------------------------- |
| [`sum`][sum]            | Повертає суму всіх значень у діапазоні                                  | `(1..5).sum # => 15`            |
| [`size`][size]          | Повертає розмір діапазону                                               | `(1..5).size # => 5`            |
| [`include?`][indlude]   | Повертає `true`, якщо діапазон містить задане значення, інакше `false`  | `(1..5).include?(3) # => true` |

## Нескінченні та безпочаткові діапазони

Діапазон може бути нескінченним або безпочатковим.
У нескінченного чи безпочаткового діапазону початкове або кінцеве значення дорівнює `nil`, але під час визначення діапазону `nil` можна опустити.

Використовувати безпочаткові та нескінченні діапазони зручно, коли потрібно, наприклад, зрізати рядок тексту від початку або до кінця.

```ruby
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello "
```

~~~~exercism/caution
Якщо не застосовувати нескінченний діапазон до колекції, він може утворити нескінченну послідовність, тож користуватися ним слід обережно.
~~~~

## Діапазони рядків

Рядки тексту також можна використовувати в діапазонах, що дає змогу отримати інтервал рядків між двома рядками.
Поведінка може бути дещо несподіваною для певних рядків, тож користуймося цим обережно.

```ruby
("aa".."az").to_a # => ["aa", "ab", "ac", ..., "az"]
```
