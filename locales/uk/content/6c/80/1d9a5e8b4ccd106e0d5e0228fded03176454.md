# Про

Clojure використовує базовий тип `java.lang.Character`, який є 16-бітною величиною для представлення найменших адресованих компонентів тексту.
Кілька `char` можуть утворювати рядок тексту (англ. string), як-от `"word"`, або `char` можна обробляти незалежно. Їхні літерали записуються так: `\a \b \c`.

`char` у Clojure підтримують кодування UTF-16 Unicode, тож, крім латинського набору символів, можна представити практично всі системи письма, які використовуються у світі, наприклад грецьку літеру `'β'`.

Існує багато методів бібліотеки, які дають змогу досліджувати й обробляти `char`. До них можна звертатися через interop як до методів класу `Character`. Clojure також містить вбудовану бібліотеку утиліт для роботи з рядками тексту, `clojure.string`, яка пропонує багато потужних функцій для роботи із символами.
