Майбутня фокусниця Еліз має потренувати основи.
У неї є колода карт, з якою вона хоче працювати.

Щоб трохи спростити собі життя, вона використовує лише карти від 1 до 10.

## 1. Дістаньте карту з колоди

Поверніть карту на позиції `idx` із заданої колоди.

```julia-repl
julia> idx = 2;

julia> card([1, 3, 4, 1], idx)
3
```

## 2. Обміняйте карту в колоді

Обміняйте карту на позиції `idx` на надану нову карту та поверніть змінену колоду.
Зауважте, що це мутує (змінює) вхідний вектор, і це нормально.

```julia-repl
julia> idx = 2; new_card = 6;

julia> replace_card!([1, 3, 4, 1], idx => new_card)
[1, 6, 4, 1]
```

## 3. Вставте карту зверху колоди

Вставте нову карту зверху колоди та поверніть колоду.

```julia-repl
julia> new_card = 8;

julia> insert_card_at_top!([1, 3, 4, 1], new_card)
[1, 3, 4, 1, 8]
```

## 4. Видаліть карту з колоди

Видаліть карту на позиції `idx` з колоди та поверніть колоду.

```julia-repl
julia> idx = 2;

julia> remove_card!([1, 3, 4, 1], idx)
[1, 4, 1]
```

## 5. Видаліть верхню карту з колоди

Видаліть верхню карту з колоди та поверніть колоду.

```julia-repl
julia> remove_card_from_top!([1, 3, 4, 1])
[1, 3, 4]
```

## 6. Вставте карту знизу колоди

Вставте нову карту знизу колоди та поверніть колоду.

```julia-repl
julia> new_card = 8;

julia> insert_card_at_bottom!([1, 3, 4, 1], new_card)
[8, 1, 3, 4, 1]
```

## 7. Видаліть карту знизу колоди

Видаліть карту знизу колоди та поверніть колоду.

```julia-repl
julia> remove_card_at_bottom!([1, 3, 4, 1])
[3, 4, 1]
```

## 8. Перевірте розмір колоди

Перевірте, чи дорівнює розмір колоди заданому `deck_size`, чи ні.

```julia-repl
julia> deck_size = 4;

julia> check_deck_size([1, 3, 4, 1], deck_size)
true

julia> check_deck_size([1, 3, 4, 1, 5], deck_size)
false
```
