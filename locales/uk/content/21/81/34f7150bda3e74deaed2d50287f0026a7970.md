# Підказки

## 1. Визначити, скільки часу займає змішування соку

- Створімо [конструкцію `switch`][mdn-switch] для змінної `name`.
- Окремі `case` мають відповідати різним назвам соків.
- Використаймо `default`, щоб охопити всі інші назви.
- Памʼятаймо, що `case` [типово проходять далі один за одним][mdn-fallthrough], тож подбаймо про те, щоб запобігти такій поведінці.

## 2. Поповнити запас часточок лайма

- Використаймо [цикл `while`][mdn-while], щоб нарізати лайми один за одним.
- Повернімося до [концепції масивів][concept-arrays], щоб знайти спосіб вилучати лайми з масиву в правильному порядку.
- Створімо [конструкцію `switch`][mdn-switch], щоб отримати кількість часточок для певного розміру лайма.
- Потрібно стежити за двома речами: скільки лаймів уже нарізано і скільки часточок ще бракує.
- Дві умови для циклу можна поєднати за допомогою [логічних операторів][concept-booleans].

## 3. Завершити зміну

- Використаймо [цикл `do-while`][mdn-do-while], щоб обробити замовлення одне за одним.
- Повернімося до [концепції масивів][concept-arrays], щоб знайти спосіб вилучати напої з масиву в правильному порядку.
- У нас уже є функція, яка визначає час, потрібний для приготування напою. Використаймо її, щоб відповідно зменшити час, який залишився.
- Дві умови для циклу можна поєднати за допомогою [логічних операторів][concept-booleans].
