# Словники

Словники в Cairo це сховища пар ключ-значення, подібні до асоціативних масивів або геш-таблиць в інших мовах.

Однак вони мають деякі унікальні особливості через незмінну модель памʼяті Cairo.

## Основна концепція

Тип `Felt252Dict<T>` забезпечує функціональність словників у Cairo, де ключем є `felt252`, а значенням будь-який підтримуваний тип `T`.

```rust
use core::dict::Felt252Dict;

fn main() {
    let mut balances: Felt252Dict<u64> = Default::default();
    balances.insert('Alice', 100);
    let balance = balances.get('Alice'); // Returns 100
}
```

## Важливі особливості

На відміну від словників в інших мовах, словники Cairo мають низку особливих властивостей:

1. Ключі мають бути значеннями `felt252`.
2. Усі ключі неявно починаються зі значення нуль.
3. Не можна видаляти записи, можна лише оновлювати значення.
4. Значення мають реалізовувати трейт `Felt252DictValue`.

## Примітка щодо продуктивності

Через незмінну модель памʼяті Cairo операції зі словником мають складність $O(n)$, де $n$ це кількість операцій, виконаних над словником.

Кожна операція створює новий запис, який фіксує зміну.

## Робота зі складеними типами

Для типів, які не реалізовують `Felt252DictValue` (як-от масиви чи структури), їх можна обгорнути в `Nullable<T>`:

```rust
let mut dict: Felt252Dict<Nullable<Span<felt252>>> = Default::default();
dict.insert(0, NullableTrait::new(array![1, 2, 3].span()));
```

## Керування памʼяттю

Словники реалізовують трейт `Destruct`, а це означає, що вони автоматично «сплющуються» (перевіряються та оптимізуються), коли виходять з області видимості.

Це частина системи доведень Cairo і відбувається за лаштунками.

Памʼятаймо: хоча словники можуть здаватися менш ефективними, ніж в інших мовах, вони створені саме так, щоб працювати з унікальною моделлю памʼяті Cairo та вимогами системи доведень.
