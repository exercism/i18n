# Додаток до інструкцій

## Слова

`convert ( rows -- str )` приймає сітку як масив рядків тексту (англ. string), по одному рядку тексту на кожен рядок сітки, і повертає розпізнані цифри як один рядок тексту. Кілька рядків комірок зʼєднуються у вихідних даних комами (`,`).

## Помилки

Для некоректних вхідних даних викиньте один із цих рядків тексту (дослівно):

- `"Number of input lines is not a multiple of four"`
- `"Number of input columns is not a multiple of three"`
