# Інструкції

Ми знову на кухні й удосконалюємо рецепт лазаньї з [Смачнюща лазанья Лії][lasagna]. Завдання тут вимагають тримати в голові кілька вхідних даних одночасно, а саме тоді *locals*, іменовані привʼязки Factor, стають у пригоді.

## 1. Визначте стан приготування

Визначте `cooking-status`, щоб вона брала зі стека показник таймера та повертала рядок тексту (англ. string) зі станом.

- `0` → `"Lasagna is done."`
- `f` (таймер не встановлювали) → `"You forgot to set the timer."`
- будь-яке інше число → `"Not done, please wait."`

```factor
12 cooking-status .   ! => "Not done, please wait."
0 cooking-status .    ! => "Lasagna is done."
f cooking-status .    ! => "You forgot to set the timer."
```

## 2. Оцініть час підготовки

Визначте `preparation-time`, щоб вона приймала масив назв шарів і середню кількість хвилин на шар та повертала загальний час підготовки.

```factor
{ "sauce" "noodles" "sauce" "meat" "mozzarella" "noodles" } 3 preparation-time .
! => 18
```

## 3. Обчисліть потрібну кількість локшини й соусу

Визначте `quantities`, щоб вона приймала масив назв шарів і повертала *два* значення: грами потрібної локшини (50 г на шар локшини) та літри потрібного соусу (`1/5` літра на шар соусу).

```factor
{ "sauce" "noodles" "sauce" "meat" "mozzarella" "noodles" } quantities .s
! => 100
! => 2/5
```

## 4. Додайте секретний інгредієнт

Друг надсилає список інгредієнтів; *останній* елемент - це його секрет. Визначте `add-secret-ingredient`, щоб вона приймала його список і наш список та повертала наш список із доданим секретом.

```factor
{ "noodles" "sauce" "mozzarella" "kampot pepper" }
{ "noodles" "meat" "sauce" "mozzarella" }
add-secret-ingredient .
! => { "noodles" "meat" "sauce" "mozzarella" "kampot pepper" }
```

## 5. Масштабуйте рецепт

Рецепт із книги розрахований на дві порції. Визначте `scale-recipe`, щоб вона приймала рецепт (хеш-таблицю від назви інгредієнта до кількості) і цільову кількість порцій та повертала новий рецепт, відповідно масштабований.

```factor
H{ { "noodles" 200 } { "sauce" 1/2 } { "mozzarella" 1 } { "meat" 100 } }
4 scale-recipe .
! => H{ { "noodles" 400 } { "sauce" 1 } { "mozzarella" 2 } { "meat" 200 } }
```
