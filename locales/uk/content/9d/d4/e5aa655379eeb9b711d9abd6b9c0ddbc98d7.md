# Інструкції

У цій вправі ми реалізуємо спосіб відстежувати рекорди для найпопулярнішої гри в нашому місцевому залі ігрових автоматів.

## 1. Додайте гравців до таблиці рекордів

Щоб додати гравця до таблиці рекордів, визначте два методи `add_player!`, які приймають такі аргументи:

- Перший аргумент - словник рахунків.
- Другий аргумент - імʼя гравця як рядок тексту (англ. string).
- Третій аргумент - рахунок як ціле число.
  Цей аргумент необовʼязковий. Якщо значення не вказано, рахунок має дорівнювати 0.

```julia-repl
julia> scores = Dict{String, Int}()
Dict{String, Int64}()

julia> add_player!(scores, "Liselot", 486373)
Dict{String, Int64} with 1 entry:
  "Liselot" => 486373

julia> add_player!(scores, "Éimhín")
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0
```

## 2. Видаліть гравців з таблиці рекордів

Щоб видалити гравця з таблиці рекордів, визначте `remove_player!`, який приймає 2 аргументи:

- Перший аргумент - словник рахунків.
- Другий аргумент - імʼя гравця як рядок тексту.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> remove_player!(scores, "Liselot")
Dict{String, Int64} with 1 entry:
  "Éimhín" => 0
```

## 3. Оновіть рахунок гравця

Щоб оновити рахунок гравця, замінивши попередній рахунок, визначте `update_score!`, який приймає 3 аргументи:

- Перший аргумент - словник рахунків.
- Другий аргумент - імʼя гравця як рядок тексту, рахунок якого ми хочемо оновити.
- Третій аргумент - рахунок, який ми хочемо встановити як збережений рекорд.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> update_score!(scores, "Éimhín", 89479) # TODO: Should this return the dict?
89479

julia> scores

  "Liselot" => 486373
  "Éimhín"  => 89479
```

## 4. Скиньте рахунок гравця

Щоб скинути рахунок гравця, визначте `reset_score!`, який приймає 2 аргументи:

- Перший аргумент - словник рахунків.
- Другий аргумент - імʼя гравця як рядок тексту, рахунок якого ми хочемо скинути.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> reset_score!(scores, "Liselot") # TODO: Should this return the dict?
0

julia> scores
Dict{String, Int64} with 2 entries:
  "Liselot" => 0
  "Éimhín"  => 0
```

## 5. Отримайте масив гравців

Щоб отримати масив гравців, визначте `players`, який приймає 1 аргумент:

- Перший аргумент - словник рахунків.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> players(scores)
2-element Vector{String}:
 "Liselot"
 "Éimhín"
```
