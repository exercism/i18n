# Додаток до інструкцій

## Визначення індуктивного типу

У цій вправі повернене значення має бути [індуктивним типом][inductive] `Classification`, який ми маємо визначити.

Цей тип повинен мати екземпляр [BEq][beq], тобто допускати булеву перевірку на рівність, та екземпляр [Repr][repr], тобто значення цього типу можна відформатувати для відображення.

Можна звернутися до [цієї сторінки][instance] про оголошення екземплярів.
Lean може автоматично [генерувати екземпляри][deriving] для багатьох класів.

## Підтипи

Аргумент функції `classify` - це [підтип][subtype] під назвою `Positive`: 

```
def Positive := { x : Nat // x > 0 }
```

Підтипи представляють елементи певного типу, які задовольняють предикат.
`Positive` представляє елементи `Nat`, які більші за `0`.

Будь-який елемент підтипу можна уявити як пару, що складається зі значення базового типу та доведення, у математичному сенсі, що це значення задовольняє відповідний предикат.

Підтипи забезпечують інваріанти на рівні типу, завдяки чому некоректні значення неможливо створити.
