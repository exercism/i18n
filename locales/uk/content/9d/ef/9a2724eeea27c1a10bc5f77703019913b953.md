# Вступ

## Приведення типів

Приведення та перетворення типів - це різні способи змінити тип виразу з одного на інший.

Вираз можна привести до іншого типу за допомогою оператора приведення `(<type>)`.

```csharp
long l = 1000L;
int i = (int)l;

object o = new Random();
Random r = (Random)o;
```

Якщо типи не сумісні, викидається виняток `InvalidCastException`. У випадку чисел це означає, що тип-одержувач не може представити приведене значення. У випадку класів один із типів має бути похідним від іншого (це так само, хоч і тривіально, стосується структур).

Альтернатива _приведенню_ - _перетворення типів_ за допомогою оператора `is`. Зазвичай це застосовують до посилальних типів і типів, що допускають значення null.

```csharp
object o = new Random();
if (o is Random rand)
{
    int ii = rand.Next();
    // now, do something random
}
```

Якщо потрібно визначити точний тип обʼєкта, то `is` може виявитися трохи надто поблажливим, адже він поверне правду і для класу, і для будь-яких класів й інтерфейсів, від яких він прямо чи опосередковано походить. У цьому випадку варто скористатися `typeof` й `Object.GetType()`.

```csharp
object o = new List<int>();

o is ICollection<int> // true
o.GetType() == typeof(ICollection<int>) // false
o is List<int> // true
o.GetType() == typeof(List<int>) // true
```
