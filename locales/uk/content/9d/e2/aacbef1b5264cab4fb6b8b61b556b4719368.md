# Тести

REPL у ClojureScript дає змогу легко запускати код і одразу отримувати зворотний звʼязок, а також використовувати його для запуску тестів.

## Leiningen
Щоб відкрити REPL за допомогою Clojure CLI, перейдіть у каталог із вправою та виконайте:
``` bash
$ clojure -m cljs.main -re node
```

Зверніть увагу: Node має бути встановлений у системі.

Коли ми готові працювати над вправою й створили файл для рішення (наприклад, `bob.cljs`), тести можна запустити в терміналі командою `$ clojure -A:test`.

Спершу підключімо тестовий простір імен за допомогою `require`:
``` clojure
=> (require 'bob-test)
nil
;; and the test namespace
=> (require 'cljs.test)
```

Перемкнімо `ns` на тестовий простір імен:
```clojure
=> (ns bob-test)
nil
```

Потім викличмо `run-tests` для `bob-test`:
``` clojure
=> (cljs.test/run-tests)

Testing bob-test

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
{:test 14, :pass 14, :fail 0, :error 0, :type :summary}
```

Щоб запустити тести вправи за допомогою Clojure CLI, просто викличмо:
``` bash
$ clojure -M:test

Testing bob-tests

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
```
