# Інструкції

У цій вправі ми напишемо ще трохи коду, повʼязаного з приготуванням і запіканням нашої чудової лазаньї з улюбленої кулінарної книги.

На нас чекає пʼять завдань.
Перше з них стосується самого готування, а решта чотири присвячені ідеальній підготовці.

## 1. Оцініть час підготовки

Для наступної лазаньї, яку ми готуватимемо, хочеться мати достатньо зарезервованого часу, щоб насолоджуватися приготуванням.
Ми вже спланували, з яких шарів складатиметься наша лазанья.
Тепер нам хочеться оцінити, скільки часу займе підготовка, виходячи з цього.

Реалізуйте функцію `preparationTime`, яка приймає вектор шарів як `string` і середній час підготовки одного шару в хвилинах як `int`.
Функція має повернути оцінку загального часу підготовки на основі кількості шарів як `int`.
Якщо середній час підготовки не передано, використовується типове значення `2`.

```cpp
std::vector<std::string> layers{"sauce", "noodles", "sauce", "meat", "mozzarella", "noodles"};
preparationTime(layers, 3)
// => 18
preparationTime(layers)
// => 12
```

## 2. Обчисліть потрібну кількість локшини та соусу

Окрім зарезервованого часу, нам також хочеться переконатися, що соусу й локшини вистачить, щоб приготувати лазанью нашої мрії.
На кожен шар локшини в лазаньї знадобиться 50 грамів локшини.
На кожен шар соусу знадобиться 0,2 літра соусу.

Визначте функцію `quantities`, яка приймає як параметр вектор шарів типу `string`.
Функція визначить потрібну кількість локшини та соусу для нашої страви.
Результат має повертатися як `amount` _struct_, який уже визначено для нас.
`amount` має дві змінні-члени: одна для ваги `noodles` як `int`, а друга для обʼєму `sauce` як `double`.

```cpp
struct amount { int noodles; double sauce; };

amount needed{quantities({"sauce", "noodles", "sauce", "meat", "mozzarella", "noodles"})};
// needed.noodles => 100
// needed.sauce => 0.4
```

## 3. Додайте секретний інгредієнт

Нещодавно ми завітали до друга й скуштували там лазанью.
Вона була неймовірна й мала в собі щось особливе.
Друг надіслав нам список інгредієнтів і сказав, що останній пункт у списку і є тим «секретним інгредієнтом», який зробив страву такою особливою.
Тепер нам хочеться додати цей секретний інгредієнт і до власного рецепта.

Напишіть функцію `addSecretIngredient`, яка приймає два `vector of strings` як параметри.
Перший параметр - це _посилання_ на інгредієнти нашого власного рецепта, а другий _вектор_ рядків містить інгредієнти, які надіслав друг.
Останній елемент у нашому списку інгредієнтів завжди `"?"`.
Функція має замінити його на останній елемент зі списку друга.
**Зверніть увагу:** `addSecretIngredient` нічого не повертає, тож список інгредієнтів треба змінювати безпосередньо.
Список з інгредієнтами друга теж може бути посиланням (для кращої продуктивності), але його **не** можна змінювати.
Подбайте, щоб список не змінювався, скориставшись `const`-посиланням.

```cpp
std::vector<std::string> friendsList{"noodles", "sauce", "mozzarella", "kampot pepper"};
std::vector<std::string> myList{"noodles", "meat", "sauce", "mozzarella", "?"};

addSecretIngredient(myList, friendsList);
// myList => {"noodles", "meat", "sauce", "mozzarella", "kampot pepper"}
```

## 4. Масштабуйте рецепт

Кількості, зазначені в нашій кулінарній книзі, дають лазанью лише на дві порції.
Оскільки наступного разу нам хочеться приготувати для більшої кількості людей, потрібно розрахувати кількості на різну кількість порцій.

Реалізуйте функцію `scaleRecipe`, яка приймає два параметри.

- Вектор кількостей типу `double`, потрібних на 2 порції.
- Кількість порцій, яку ми хочемо приготувати.

Функція має повернути новий вектор кількостей, потрібних для бажаної кількості порцій.
Водночас нам хочеться зберегти початковий рецепт.
Це означає, що аргумент `quantities` у цій функції не можна змінювати.

```cpp
std::vector<double> quantities{1.2, 3.6, 10.5};
scaleRecipe(quantities, 4);
// => { 2.4, 7.2, 21 }
```

## 5. Розкрийте сімейну таємницю

Ми памʼятаємо історії з дитинства, оповіді про нашу прапратітку, охоронницю найглибших кулінарних таємниць родини.
Легенда каже, що саме вона має ключ до смаків, які неможливо уявити, але її методи нетрадиційні.
Вона не має справи зі списками чи мірками; вона говорить пошепки, відкриваючи щоразу лише один інгредієнт.

Зі сумішшю хвилювання й остраху ми вирішуємо звернутися до нашої прапратітки.
Як і очікувалося, вона відповідає своєю загадковою манерою, пропонуючи єдиний секретний інгредієнт, оповитий таємницею.

Внесок нашої прапратітки додає ще один рівень складності, який нам хочеться використати у своєму рецепті.
Реалізуйте ще одну версію функції `addSecretIngredient`, яка приймає два аргументи: посилання на вектор, що представляє наш список інгредієнтів, і один рядок тексту (англ. string), що представляє загадковий дарунок від нашої прапратітки.

```cpp
std::vector<std::string> myList{"noodles", "meat", "sauce", "mozzarella", "?"};
std::string secretIngredient{"spice melange"};
addSecretIngredient(myList, secretIngredient);
// myList => {"noodles", "meat", "sauce", "mozzarella", "spice melange"}
```
