# Про

[Дослівні рядки тексту][verbatim-strings] (англ. string) дозволяють створювати багаторядкові рядки тексту. Вони починаються із символу @. Їх можна використовувати з інтерполяцією рядків тексту. Просто додайте "\$" перед відкриваючою лапкою.

```csharp
string str = @"
See no wretched
quotes everywhere
";
```

[verbatim-strings]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/strings/#regular-and-verbatim-string-literals
