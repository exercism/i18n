# Вказівки

У цій вправі ми писатимемо код для аналізу виробництва на автомобільному заводі.

## 1. Обчислити кількість справних автомобілів, виготовлених за годину

Автомобілі виготовляють на конвеєрі.
Конвеєр має певну швидкість, яку можна змінювати.
Чим вища швидкість конвеєра, тим більше автомобілів виготовляють.
Проте зміна швидкості конвеєра також змінює кількість автомобілів, виготовлених успішно, тобто автомобілів без жодних помилок у виробництві.

Реалізуйте функцію, яка приймає кількість автомобілів, виготовлених за годину, і частку успішних автомобілів, та обчислює кількість справних автомобілів, виготовлених за годину.
Частка успішних автомобілів задається у відсотках, від `0` до `100`:

```go
CalculateWorkingCarsPerHour(1547, 90)
// => 1392.3
```

**Примітка:** повернене значення має бути `float64`.

## 2. Обчислити кількість справних автомобілів, виготовлених за хвилину

Реалізуйте функцію, яка приймає кількість автомобілів, виготовлених за годину, і частку успішних автомобілів, та обчислює, скільки автомобілів успішно виготовляється щохвилини:

```go
CalculateWorkingCarsPerMinute(1105, 90)
// => 16
```

**Примітка:** повернене значення має бути `int`.

## 3. Обчислити вартість виробництва

Зазвичай виготовлення одного автомобіля окремо коштує $10,000, незалежно від того, успішний він чи ні.
Але з трохи планування 10 автомобілів можна виготовити разом за $95,000.

Наприклад, 37 автомобілів можна виготовити так:
37 = 3 × групи по десять + 7 окремих автомобілів

Отже, вартість 37 автомобілів така:
3\*95,000+7\*10,000=355,000

Реалізуйте функцію `CalculateCost`, яка обчислює вартість виробництва певної кількості автомобілів, незалежно від того, успішні вони чи ні:

```go
CalculateCost(37)
// => 355000

CalculateCost(21)
// => 200000
```

**Примітка:** повернене значення має бути `uint`.
