# Встановлення

Для цих задач ми використовуємо популярний симулятор MIPS [MARS](https://dpetersanderson.github.io/Help/MarsHelpIntro.html). Завантажмо jar-архів MARS із [GitHub](https://github.com/dpetersanderson/MARS/releases) і розмістімо його десь у легкодоступному місці. Також встановімо Java SDK, якщо його ще немає.
