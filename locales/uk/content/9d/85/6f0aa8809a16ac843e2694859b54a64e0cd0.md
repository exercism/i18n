# Інструкції

У цій вправі ми будемо писати код, який допоможе компанії з виготовлення вивісок створювати індивідуальні повідомлення для своїх вивісок.

## 1. Створімо набір корисних рядків тексту

Визначмо наведені нижче сталі рядки тексту (англ. string), які будемо використовувати для створення вивісок:

- `birthday`: тут зберігається значення "Birthday"
- `valentine`: тут зберігається значення "Valentine's Day"
- `anniversary`: тут зберігається рядок тексту "Anniversary"

## 2. Створімо набір корисних символів

Визначмо наведені нижче сталі символи, які будемо використовувати для створення вивісок:

- `space`: тут зберігається значення " " (один пробіл)
- `exclamation`: тут зберігається значення "!"

## 3. Поєднаймо фрази, щоб побудувати повідомлення

Реалізуймо функцію `buildSign(for:name:)`, яка приймає аргумент `for` зі значенням одного з трьох рядків тексту, визначених у першому завданні, та аргумент `name` — рядок тексту з іменем людини, для якої призначено вивіску.
Для побудови повідомлення для вивіски скористаймося конкатенацією та памʼятаймо, що вже визначені константи слід використати повторно.
Функція повинна повернути повідомлення для вивіски як рядок тексту.

```swift
buildSign(for: birthday, name: "Otto")
// returns "Happy Birthday Otto!"

buildSign(for: anniversary, name: "Valentina")
// returns "Happy Anniversary Valentina!"
```

## 4. Побудуймо вивіску на випуск

Реалізуймо функцію `graduationFor(name:year:)`, яка приймає аргумент `name` — рядок тексту з іменем людини, для якої призначено вивіску, та аргумент `year` — ціле число із роком, у якому людина випускається.
Для побудови повідомлення для вивіски скористаймося шаблонними рядками.
Функція повинна повернути повідомлення для вивіски як рядок тексту.

```swift
graduationFor(name: "Padma", year: 2023)
// returns "Congratulations Padma!\nClass of 2023"
```

## 5. Обчислімо вартість вивіски

Реалізуймо функцію `costOf(sign:)`, яка приймає аргумент `sign` — рядок тексту з повідомленням для вивіски.
Базова ціна вивіски становить 20 у заданій валюті. Крім того, кожна літера коштує 2 (пробіли також враховуються в розрахунку).
Функція повинна повернути вартість вивіски як ціле число.

```swift
costOf(sign: "Happy Birthday Grandma!")
// returns 66
```
