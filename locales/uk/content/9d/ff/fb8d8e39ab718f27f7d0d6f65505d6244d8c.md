# Додаток до інструкцій

Вихідні дані мають бути впорядковані за [порядком за рядками](https://en.wikipedia.org/wiki/Row-_and_column-major_order): спочатку всі слова з першого рядка, потім слова з другого рядка, і так далі.

## Регістри

| Регістр | Використання    | Тип      | Опис                                |
| ------- | --------------- | -------- | ----------------------------------- |
| `$a0`   | вхідні дані     | ціле число | розмір                            |
| `$a1`   | вхідні/вихідні дані | адреса | матриця слів у порядку за рядками |
| `$v0`   | вихідні дані    | ціле число | кількість слів у матриці          |
| `$t0-9` | тимчасове       | будь-який | для тимчасового зберігання        |
