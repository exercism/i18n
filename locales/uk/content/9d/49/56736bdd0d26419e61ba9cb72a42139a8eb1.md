# Підказки

## 1. Витягнути картку зі стосу

- Індекси `Vector` починаються з `1`.
- Значення з номером `n` у векторі `v` можна отримати так: `v[n]`.

## 2. Замінити картку в стосі

- `Vector` дозволяє будь-коли змінювати свій вміст: достатньо присвоїти нове значення.

## 3. Вставити картку на верх стосу

- У Base є метод [`push!`][push], який додає нове значення в кінець колекції.

## 4. Вилучити картку зі стосу

- У Base є метод [`deleteat!`][deleteat], який вилучає елемент із `Vector` за вказаним індексом.

## 5. Вилучити верхню картку зі стосу

- У Base є метод [`pop!`][pop], який вилучає елемент у кінці колекції.

## 6. Вставити картку в низ стосу

- У Base є метод [`pushfirst!`][pushfirst], який вставляє нове значення на початок колекції.

## 7. Вилучити картку з низу стосу

- У Base є метод [`popfirst!`][popfirst], який вилучає елемент на початку колекції.

## 8. Перевірити розмір стосу

- У Base є метод [`length`][length], який повертає довжину колекції.
