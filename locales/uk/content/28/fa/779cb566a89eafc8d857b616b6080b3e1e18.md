# Вступ

У Ruby **масиви** - це впорядковані колекції будь-яких обʼєктів з цілочисельними індексами.
Індексація масиву починається з `0`.
Вважається, що відʼємний індекс відраховується від кінця масиву, тобто індекс `-1` вказує на останній елемент масиву, `-2` - на передостанній, і так далі.
Масиви Ruby включають [модуль Enumerable][enumerable-module], який додає чимало методів обходу та пошуку, а також можливість сортування.

## Створення масиву

- Масив у Ruby може містити обʼєкти різних типів.

```ruby
array = [1, "two", 3.0] #=> [1, "two", 3.0]
```

## Присвоєння елементів

До елементів можна звертатися та змінювати їх за допомогою індексів.
До підмасивів можна звернутися, вказавши початковий індекс і довжину.

```ruby
a = ["", "", "", "", ""]

a[4] = "hello"  #=> [nil, nil, nil, nil, "hello"]
a[0, 3] = [ 'a', 'b', 'c' ] #=> ["a", "b", "c", nil, "hello"]
```

- Відʼємні індекси відраховуються від кінця масиву.

```ruby
a = ['a', 'b']

a[-1] = "Z"
a #=> ["a", "Z"]
```

## Доступ до елементів

- Елементи масиву можна отримати за допомогою методу #[].
- Він повертає елемент за вказаним індексом або підмасив, що починається з початкового індексу й містить указану кількість елементів.

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[2]    #=> "c"
a[6]    #=> nil
a[1, 2] #=> [ "b", "c" ]
```

- Відʼємні індекси відраховуються від кінця масиву (-1 - це останній елемент)

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[-2]    #=> "d"
a[-3, 3] #=> [ "c", "d", "e" ]
```

## Отримання інформації про масив

Масиви постійно відстежують власну довжину.
Щоб дізнатися, скільки елементів містить масив, можна використати length, count або size.

```ruby
browsers = ['Chrome', 'Firefox', 'Safari', 'Opera', 'IE']
browsers.length #=> 5
browsers.count  #=> 5
browsers.size   #=> 5
```

## Додавання елементів до масиву

Елементи можна додавати в кінець масиву за допомогою `push` або `<<`:

```ruby
arr = [1, 2, 3, 4]
arr.push(5) #=> [1, 2, 3, 4, 5]
arr << 6    #=> [1, 2, 3, 4, 5, 6]
```

## Видалення елементів з масиву

Метод pop видаляє останній елемент масиву й повертає його:

```ruby
arr = [1, 2, 3, 4, 5, 6]
arr.pop #=> 6
arr     #=> [1, 2, 3, 4, 5]
```
