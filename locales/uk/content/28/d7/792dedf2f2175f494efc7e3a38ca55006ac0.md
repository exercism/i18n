# Вступ

Ініціалізатори - це спеціальні методи, які використовуються, щоб задати значення переліку. Їхнє визначення дуже схоже на визначення методу, але без ключового слова `func`, без типу повернення; назва має бути `init`, а ініціалізатор _повинен_ присвоїти `self` значення переліку. Ініціалізатори викликають або через точкову нотацію, або передаючи параметри ініціалізатора назві переліку.

```swift
enum Coin {
  case heads
  case tails

  init(_ i: Int) {
    if i.isMultiple(of: 2) {
      self = .heads
    } else {
      self = .tails
    }
  }

  func flip() -> Self {
    switch self {
    case .heads: return .tails
    case .tails: return .heads
    }
  }
}

let tails = Coin.init(13)
// .tails
let heads = Coin(0)
// .heads
let anotherTails = heads.flip()
// .tails
```
