# Інструкції

У цій вправі ми граємо в рольову гру під назвою «Чарівники і воїни». Щоб грати в цю гру, нам потрібен універсальний метод кидання кубика, який визначатиме різні результати. Це буде традиційний 18-гранний кубик із числами від 1 до 18. Гравцям також потрібно генерувати випадкову силу закляття.

## 1. Дайте змогу гравцеві у _Чарівники і воїни_ кинути кубик

Реалізуйте метод `RollDie()` у класі `Player`.

```csharp
var player = new Player();
player.RollDie();
// => >= 1 <= 18
```

## 2. Гравцям потрібна їхня сила. Надайте спосіб генерувати силу закляття

Реалізуйте метод `GenerateSpellStrength()` у класі гравця.
Сила закляття лежить у межах від 0.0 до 100.0, не включаючи 100.0.

Зауважте, що сила закляття має бути числом з плаваючою комою (не цілим), щоб зменшити ймовірність нічиєї, коли порівнюються сили двох супротивників.

```csharp
var player = new Player();
player.GenerateSpellStrength();
// => >= 0.0 < 100.0
```
