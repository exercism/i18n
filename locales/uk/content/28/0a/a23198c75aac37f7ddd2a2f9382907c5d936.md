# Налагодження

На відміну від багатьох мов, код WebAssembly не має автоматичного доступу до глобальних ресурсів, як-от консоль. Замість цього таку функціональність треба надавати як імпорти.

Щоб забезпечити функціональність, подібну до `console.log`, та кілька інших зручностей, трек WebAssembly на Exercism надає стандартну бібліотеку функцій для всіх вправ.

Ці функції потрібно імпортувати на початку нашого модуля WebAssembly, після чого їх можна викликати зсередини коду WebAssembly.

Функції `log_mem_*` потребують доступу до лінійної памʼяті нашого модуля WebAssembly. За замовчуванням це приватний стан, тож щоб зробити його доступним, потрібно експортувати лінійну памʼять під іменем експорту `mem`. Це робиться так:

```wasm
(memory (export "mem") 1)
```

# Журналювання локальних і глобальних змінних

Ми надаємо функції журналювання для кожного з примітивних типів WebAssembly. Це корисно для журналювання глобальних і локальних змінних.

## log_i32_s - журналювання 32-бітного знакового цілого числа в консоль

```wasm
(module
  (import "console" "log_i32_s" (func $log_i32_s (param i32)))
  (func $main
    ;; logs -1
    (call $log_i32_s (i32.const -1))
  )
)
```

# Журналювання з лінійної памʼяті

Лінійна памʼять WebAssembly - це масив значень з побайтовою адресацією. Вона виконує роль віртуальної памʼяті для програм WebAssembly.

Ми надаємо функції журналювання, які інтерпретують діапазон адрес у лінійній памʼяті як статичні масиви певних типів. Це працює подібно до TypedArrays у JavaScript. Параметри довжини вимірюються не в байтах. Вони вимірюються кількістю послідовних елементів типу, повʼязаного з функцією.

**Щоб ці функції працювали, наш модуль WebAssembly повинен оголосити й експортувати свою лінійну памʼять, використовуючи іменований експорт "mem"**

```wasm
(memory (export "mem") 1)
```

## log_mem_as_utf8 - журналювання послідовності символів UTF8 в консоль

```wasm
(module
  (import "console" "log_mem_as_utf8" (func $log_mem_as_utf8 (param $byteOffset i32) (param $length i32)))
  (memory (export "mem") 1)
  (data (i32.const 64) "Goodbye, Mars!")
  (func $main
    ;; Logs "Goodbye, Mars!" to console
    (call $log_mem_as_utf8 (i32.const 64) (i32.const 14))
  )
)
```

## log_mem_as_i8 - журналювання послідовності знакових 8-бітних цілих чисел в консоль

```wasm

  (func $main
    (memory.fill (i32.const 128) (i32.const -42) (i32.const 10))

  )
)
```
