# Про це

Булеві значення (англ. Boolean) в Kotlin представлені типом `Boolean`, значення якого можуть бути `true` або `false`.

Kotlin підтримує три вбудовані [булеві оператори][reference]: `!` (заперечення, тобто NOT), `&&` (лінива конʼюнкція, тобто логічне і) та `||` (лінива дизʼюнкція, тобто логічне або). Оператори `&&` (і) та `||` (або) використовують _скорочене обчислення_, тобто праву частину оператора обчислюють лише тоді, коли це потрібно.

```kotlin
true || false // => true
true && false // => false
```

Кожен із трьох булевих операторів має різний [_пріоритет операторів_][precedence]. Тому вони обчислюються в такому порядку: спочатку `!`, потім `&&`, і нарешті `||`. Якщо треба «обійти» ці правила, булевий вираз можна взяти в дужки (`()`), бо дужки мають ще вищий пріоритет операторів.

```kotlin
!true && false   // => false
!(true && false) // => true
```

[reference]: https://kotlinlang.org/docs/reference/basic-types.html#booleans
[precedence]: https://kotlinlang.org/docs/reference/grammar.html#expressions
