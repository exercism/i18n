# Інструкції

Навчімося поєднувати дані з двох різних внутрішніх таблиць в одну результуючу внутрішню таблицю. 

Клас отримає дві внутрішні таблиці, які містять два абсолютно різні набори даних: ALPHAS і NUMS.

```abap
TYPES: BEGIN OF alphatab_type,
         cola TYPE string,
         colb TYPE string,
         colc TYPE string,
       END OF alphatab_type.
TYPES: alphas TYPE STANDARD TABLE OF alphatab_type.
TYPES: BEGIN OF numtab_type,
         col1 TYPE string,
         col2 TYPE string,
         col3 TYPE string,
       END OF numtab_type.
TYPES: nums TYPE STANDARD TABLE OF numtab_type.
```

Дані в таблиці ALPHA мають такий вигляд.

| COLA | COLB | COLC |
| --- | --- | --- |
| A | B | C | 
| D | E | F |
| G | H | I |

Дані в таблиці NUMS мають такий вигляд.

| COL1 | COL2 | COL3 |
| --- | --- | --- |
| 1 | 2 | 3 | 
| 4 | 5 | 6 |
| 7 | 8 | 9 |

Наше завдання - повернути внутрішню таблицю із записами, які поєднують значення кожної комірки внутрішньої таблиці ALPHAS і внутрішньої таблиці NUMS. Наприклад, значення першого стовпця першого рядка внутрішньої таблиці COMBINED_DATA має бути «A1».

Очікувана таблиця, яку потрібно повернути, має таке визначення:

```abap
TYPES: BEGIN OF combined_data_type,
         colx TYPE string,
         coly TYPE string,
         colz TYPE string,
       END OF combined_data_type.
TYPES: combined_data TYPE STANDARD TABLE OF combined_data_type WITH EMPTY KEY.
```
