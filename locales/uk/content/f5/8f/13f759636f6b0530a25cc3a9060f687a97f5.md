# Докладніше

Цикли `for` є найскладнішим типом циклів у PHP. Вони поводяться так само, як цикли `for` у `C`, `Java` та `JavaScript`. Їхня базова форма має такий вигляд:

```php
for (expr1; expr2; expr3) {
  // statements
}
```

Перший вираз (_`expr1`_) обчислюється перед початком циклу. Другий вираз (_`expr2`_) обчислюється перед кожною ітерацією, і якщо він дає _правдиве_ значення, інструкції виконуються. Після виконання інструкцій обчислюється третій вираз (_`expr3`_).
