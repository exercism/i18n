# Вступ

У Common Lisp функція може повертати не лише одне значення, а й кілька. Наприклад, `floor`, яка округляє в напрямку до нуля, повертає два значення: перше - округлене значення, а друге - остача.

```lisp
(floor 3.5) ; => 3
            ;    0.5
```
(Кілька повернутих значень будемо показувати на окремих рядках виводу.)

## Повернення кількох значень

Якщо ми хочемо, щоб функція повертала кілька значень, використовуємо аксесор `values`:

```lisp
(defun three-numbers () (values 1 2 3))
(three-numbers) ; => 1
                ;    2
                ;    3
```

## Робота з кількома значеннями

Якщо нам потрібне лише перше значення, нічого особливого робити не треба, мова подбає про це сама:

```lisp
(+ (values 1 2 3) (values 10 20 30)) ; => 11
```

Однак, якщо ми хочемо отримати доступ до тих інших значень, нам знадобиться кілька функцій. Два основні макроси - це `multiple-value-list` і `multiple-value-bind`. Їх використовують, щоб обгорнути щось, що повертає кілька значень, і зібрати всі ці значення. Перший створить масив усіх значень. Другий дасть змогу привʼязати змінні до окремих значень.

```lisp
(multiple-value-list (values 1 2 3))                   ; => (1 2 3)
(multiple-value-bind (a b c) (values 1 2 3) 
   (+ a b c)) ; => 6
```
