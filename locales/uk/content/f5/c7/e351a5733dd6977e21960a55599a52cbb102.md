# Рекомендована література

Оскільки Smalltalk широко використовують, матеріалів для читання є чималий вибір.

## З чого почати

* [Pharo Main Site](https://pharo.org/documentation):
має безліч статей і довідкових матеріалів
* [Pharo Syntax Cheatsheet](https://files.pharo.org/media/pharoCheatSheet.pdf):
уміщується на листівці
* [I Can Read C but not Smalltalk](https://www.eli.sdsu.edu/courses/spring01/cs635/readingSmalltalk.pdf): кілька простих кроків до розуміння Smalltalk
* [Pharo By Example (9.0)](https://books.pharo.org/pharo-by-example9/):
повноцінна книжка у форматі PDF з покроковими прикладами
* [Learning OOP and TDD in Pharo](https://books.pharo.org/learning-oop/):
знайомить із додатковими техніками та концепціями програмування
* [Discord](https://discord.gg/QewZMZa) має
активний онлайн-форум для обговорення Pharo (скористайтеся посиланням-запрошенням угорі сторінки [Community Page](https://pharo.org/community))
* [Pharo Mooc](https://mooc.pharo.org/):
пропонує серію повних курсів програмування та відео

## Для просунутих

* [Deep Into Pharo](https://books.pharo.org/deep-into-pharo/):
проводить через складніші теми, як-от графіка та парсинг
* [Pharo with style](https://github.com/SquareBracketAssociates/Booklet-PharoWithStyle):
це посібник із форматування й проєктування у стилі Pharo
* [Smalltalk with style](http://sdmeta.gforge.inria.fr/FreeBooks/WithStyle/SmalltalkWithStyle.pdf):
ширший посібник із форматування й проєктування мовою Smalltalk
* [Enterprise Pharo - Web Perspective](http://books.pharo.org/enterprise-pharo/):
охоплює вебзастосунки, HTTP і дані
