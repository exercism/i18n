# Доповнення до інструкцій

## Формат сітки

Сітка представлена як рядок тексту (англ. string), що завершується нульовим символом, а в кінці кожного рядка стоїть символ нового рядка.

## Регістри

| Регістр | Використання  | Тип     | Опис                                                                                          |
| ------- | ------------- | ------- | --------------------------------------------------------------------------------------------- |
| `$a0`   | вхідні дані   | адреса  | вхідний рядок тексту, завершений нульовим символом                                            |
| `$a1`   | вхідні/вихідні дані | адреса | рядок тексту з результатом, завершений нульовим символом; порожній, якщо розміри сітки недійсні |
| `$v0`   | вихідні дані  | ціле число | стан сітки (`0` = `ok`, `-1` = `invalid columns`, `-2` = `invalid rows`)                    |
| `$t0-9` | тимчасовий    | будь-який | для тимчасового зберігання                                                                   |
