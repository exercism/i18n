# Написання коду

Напишіть свій код у файлі `<exercise_name>.zig`.
Деякі вправи містять готові сигнатури для конкретних конструкцій Zig, як-от [константи][constants], [функції][functions], [імпорти][imports], [структури][structs] і [потенційно багато іншого][et-cetera]!

Ці готові сигнатури покликані допомогти під час виконання вправ, даючи чітку відправну точку.
Однак починати з цих сигнатур не обовʼязково.
Особливо зважаючи на те, що будь-який написаний код, який проходить їхні тести, є цілком прийнятним рішенням.

## Запуск тестів

Щоб запустити тести, достатньо виконати таку команду:

```bash
zig test test_exercise_name.zig
```

Замініть `exercise_name` на назву вправи.
Цю команду потрібно виконати в кореневій теці вправи, бо її файл тестів має бути в тому самому місці.
Крім того, всі тести для будь-якої вправи увімкнені типово, і жоден тест не можна пропустити.

Оскільки всі тести мають такі умови, щоб пройти кожен тест по черзі, доведеться [закоментувати][comments] тести, які не проходять.
Закоментувати тест так само просто: достатньо почати кожен рядок з `//`.
А коли вже є впевненість, що рішення проходить тести, ці тести можна розкоментувати й перевірити, чи воно справді проходить.
