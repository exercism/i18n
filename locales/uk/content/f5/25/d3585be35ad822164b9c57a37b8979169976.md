# Інструкції

У цій вправі ми напишемо програму, яка визначає стан гри в [хрестики-нулики][tic-tac-toe].
(_Ця гра також відома як «ікси та нулики»._)

Гра відбувається на полі 3×3.
Гравці ходять по черзі, ставлячи `X` та `O` на полі.
Гра завершується, коли один із гравців перемагає, розмістивши три свої позначки в рядку, стовпці або по діагоналі поля, або коли все поле заповнене.

У цій вправі ми будемо вважати, що починає `X`.

Наше завдання - визначити, у якому стані перебуває ця гра.

Існують 3 можливі стани гри:

- Гра ще триває: **ongoing**.
- Гра завершилася нічиєю: **draw**.
- Гра завершилася перемогою: **win**.

Якщо задане поле недійсне, потрібно кинути відповідну помилку.

Поле вважається недійсним, якщо виконуються такі умови:

- Задане поле не можна отримати, якщо ходи робити в правильному порядку (памʼятаймо, що починає `X`).
- Гру продовжили після того, як вона вже завершилася.

## Приклади

### Гра триває

```text
   |   |
 X |   |
___|___|___
   |   |
   | X | O
___|___|___
   |   |
 O | X |
   |   |
```

### Нічия

```text
   |   |
 X | O | X
___|___|___
   |   |
 X | X | O
___|___|___
   |   |
 O | X | O
   |   |
```

### Перемога

```text
   |   |
 X | X | X
___|___|___
   |   |
   | O | O
___|___|___
   |   |
   |   |
   |   |
```

### Недійсне поле

#### Неправильний порядок ходів

```text
   |   |
 O | O | X
___|___|___
   |   |
   |   |
___|___|___
   |   |
   |   |
   |   |
```

#### Гру продовжили після перемоги

```text
   |   |
 X | X | X
___|___|___
   |   |
 O | O | O
___|___|___
   |   |
   |   |
   |   |
```
