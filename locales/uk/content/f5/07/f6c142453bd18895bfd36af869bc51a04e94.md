# Докладніше

*Купа* - це колекція, яка завжди знає свій найменший (або найбільший) елемент і дає змогу швидко його вилучити. Це природна реалізація *пріоритетної черги*. Купи живуть у словнику [`heaps`][heaps].

`<min-heap>` створює порожню купу, з якої першим виходить найменший ключ; `<max-heap>` повертає найбільший першим. Кожен елемент - це *значення*, збережене під *ключем*, а ключ - це пріоритет, за яким Factor упорядковує:

```
<min-heap> ( -- min-heap )
<max-heap> ( -- max-heap )
heap-push  ( value key heap -- )
heap-push-all ( assoc heap -- )
```

```factor
USING: heaps ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
```

Купа *змінювана*: `heap-push` і `heap-pop` змінюють її на місці.

```
heap-peek    ( heap -- value key )
heap-pop     ( heap -- value key )
heap-pop-all ( heap -- alist )
heap-empty?  ( heap -- ? )
heap-size    ( heap -- n )
```

`heap-peek` читає перший елемент, не вилучаючи його; `heap-pop` вилучає його й повертає; `heap-pop-all` спорожнює купу в асоціативний список пар `{ key value }` у порядку пріоритету.

```factor
USING: assocs heaps kernel prettyprint ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
"carol" 9 pick heap-push
dup heap-pop .           ! => 2 "bob"   (removed; value then key)
heap-pop-all values .    ! => { "alice" "carol" }
```

Додавання коштує `O(log n)`, а читання першого елемента - `O(1)`, тож повторюване «взяти найнагальніший елемент, а потім додати ще» залишається швидким навіть для великої черги. Реалізація - це бінарна купа, збережена в масиві, що росте; ключем може бути будь-яке впорядковуване значення (числа, рядки тексту (англ. string), …).

[heaps]: https://docs.factorcode.org/content/vocab-heaps.html
