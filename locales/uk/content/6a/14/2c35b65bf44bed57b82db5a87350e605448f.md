# Основи `match`

Оператор `match` порівнює значення з низкою шаблонів, а потім виконує код залежно від того, який шаблон збігся.

## Зіставлення з літералами

У найпростішому вигляді `match` порівнює значення з кількома можливими варіантами й обирає першу гілку, яка збігається. Завжди обирається лише одна гілка, і керування ніколи не «перетікає» до іншої гілки. `match` - це вираз, який може обчислюватися до значення.

```rust
enum TrollNumber {
    One,
    Two,
    Many,
    Lots,
}

fn estimated_value(troll_number: TrollNumber) -> u32 {
    match troll_number {
        TrollNumber::One => 1,
        TrollNumber::Two => 2,
        TrollNumber::Many => 10,
        TrollNumber::Lots => 100,
    }
}
```

## Вичерпність

Зіставлення завжди вичерпне: Rust не скомпілює програму, якщо якесь значення може вислизнути. На допомогу приходить `_` - символ-замінник, який збігається з чим завгодно.

```rust
fn ordinal(n: u32) -> String {
    let ordinal = match n % 10 {
        1 => "st",
        2 => "nd",
        3 => "rd",
        _ => "th",
    };
    format!("{n}{ordinal}")
}
```

## Зіставлення як керування потоком

Хоча `match` можна використовувати як вираз, щоб отримати значення, його також можна використовувати як інструкцію виключно заради керування потоком виконання.

```rust
// pretend that we've already filtered the key events relevant to the space bar (we don't want a keylogger)
fn space_timer(&mut self, event: Event) {
    match event {
        Event::KeyDown => self.timer = Some(Instant::now()),
        Event::KeyUp => {
            let duration = Instant::now() - self.timer.take().expect("can't have KeyUp without KeyDown");
            self.durations.push(duration);
        }
        // we don't care about any other events; the empty scope is a no-op
        _ => {}
    }
}
```

## Зіставлення з діапазонами

Гілки `match` не обовʼязково задавати як окремі значення; вони також можуть бути діапазонами.

```rust
fn ascii_type(ch: u8) -> &'static str {
    match ch {
        0..=31 => "non-printable control code",
        32..=126 => "printable character",
        127 => "DEL",
        _ => "extended ASCII; region-specific",
    }
}
```

## Шаблони «або»

Гілка `match` може збігатися з одним із кількох можливих варіантів, використовуючи токен `|` як роздільник.

```rust
fn should_retry(error: std::io::Error) -> bool {
    use std::io::ErrorKind;

    match error.kind() {
        ErrorKind::TimedOut | ErrorKind::Interrupted => true,
        _ => false,
    }
}
```

## Структурне зіставлення та звʼязування

Зіставлення може створити звʼязування, чинне в межах конкретної гілки `match`. Це особливо корисно для розпакування енумів, які несуть дані у своїх варіантах.

```rust
/// Consume a result and proceed, logging any errors.
trait OrLog {
    fn or_log(self);
}

impl<E: std::fmt::Display> OrLog for Result<(), E> {
    fn or_log(self) {
        match self {
            // discard Ok results
            Ok(()) => {},
            // log errors
            Err(err) => println!("ERROR: {err}"),
        }
    }
}
```
