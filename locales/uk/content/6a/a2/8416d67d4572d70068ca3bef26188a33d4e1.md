# Додаток до вказівок

## Реалізація

У пакеті twobucket реалізуйте функцію Go Solve з таким підписом:

```go
func Solve(sizeBucketOne,
	sizeBucketTwo, goalAmount int, startBucket string,
) (goalBucket string, numSteps, otherBucketLevel int, e error)
```

Solve повертає чотири значення: отримане цільове відро ("one" або two"), кількість ходів/кроків, потрібних для досягнення цільового обʼєму, літри, що залишилися в іншому відрі, та значення помилки.
Повертайте помилку для будь-якого недійсного параметра або якщо розвʼязок неможливий.
