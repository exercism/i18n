# Інструкції

У цій вправі ми попрацюємо ще трохи з радіокерованими автомобілями.

Розробили експериментальний автомобіль, і тепер випробувальний трек потрібно адаптувати так, щоб він приймав і серійні, й експериментальні моделі. Обидва типи автомобілів уже створено, і нам потрібно знайти спосіб працювати з ними обома на випробувальному треку.

Крім того, серійні автомобілі починають показувати непогані результати. Керівник команди хоче підтримати змагальний дух, опублікувавши рейтинг серійних автомобілів.

## 1. Забезпечте можливість керувати автомобілями на одному випробувальному треку

Додайте метод до інтерфейсу `IRemoteControlCar`, який надає доступ до реалізацій `Drive()` для обох типів автомобілів.

```csharp
TestTrack.Race(new ProductionRemoteControlCar());
TestTrack.Race(new ExperimentalRemoteControlCar());
// this should execute without an exception being thrown
```

## 2. Забезпечте можливість порівнювати відстань, яку проїхали різні моделі на випробувальному треку

Додайте властивість до інтерфейсу `IRemoteControlCar`, яка надає доступ до реалізацій властивості `DistanceTravelled` для обох типів автомобілів.

```csharp
var prod = new ProductionRemoteControlCar();
TestTrack.Race(prod);
var exp = new ExperimentalRemoteControlCar();
TestTrack.Race(exp);
prod.DistanceTravelled
// => 10
exp.DistanceTravelled
// => 20
```

## 3. Забезпечте можливість ранжувати серійні автомобілі

Реалізуйте інтерфейс `IComparable<T>` у класі `ProductionRemoteControlCar`. Типовий порядок сортування автомобілів має бути за зростанням кількості перемог.

Реалізуйте статичний метод `TestTrack.GetRankedCars()`, який повертає передані автомобілі, відсортовані за зростанням кількості перемог.

```csharp
var prc1 = new ProductionRemoteControlCar();
var prc2 = new ProductionRemoteControlCar();
prc1.NumberOfVictories = 3;
prc2.NumberOfVictories = 2;
var rankings = TestTrack.GetRankedCars(prc1, prc2);
// => rankings[1] == prc1
```
