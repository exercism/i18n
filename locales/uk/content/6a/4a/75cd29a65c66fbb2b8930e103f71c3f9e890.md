# Цикли

Цикли в Rust дають змогу багаторазово виконувати блок коду, доки ми не скажемо йому зупинитися або доки не виконається певна умова.

Найпростіший варіант циклу використовує ключове слово `loop`:

```rust
fn main() {
    loop {
        println!("again!");
    }
}
```

Наведений фрагмент коду створює нескінченний цикл. Щоб вийти з циклу, використайте ключове слово `break`:

```rust
fn main() {
    let mut count = 0;
    loop {
        println!("again!");
        count += 1;
        if count > 10 { break; }
    }
}
```

## Цикли з `for` і `while`

Окрім ключового слова `loop`, цикли можна також створювати за допомогою `for` і `while`.

Цикл `for` використовується, щоб перебрати елементи колекції або ітератора.

```rust
fn main() {
    let a = [10, 20, 30, 40, 50];

    for x in a {
        println!("the value is: {x}");
    }
}
```

Діапазони теж є ітераторами, тож перебирати їх циклом `for` дуже зручно:

```rust
fn main() {
    for x in 0..10 {
        println!("the value is: {x}");
    }
}
```

Цикл `while` повторює код, доки не виконається умова. Попередній приклад можна переписати з циклом `while` так:

```rust
fn main() {
    let a = [10, 20, 30, 40, 50];
    let mut index = 0;

    while index < 5 {
        println!("the value is: {}", a[index]);

        index += 1;
    }
}
```

Дивіться [https://doc.rust-lang.org/book/ch03-05-control-flow.html#repetition-with-loops](repetition with loops) у книзі про Rust, щоб дізнатися більше про цикли.
