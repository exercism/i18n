# Використайте `Keyword.get_values`

Списки ключових слів можуть містити більше ніж одне значення для одного ключа, що робить отримання всіх значень ключа незручним.
Модуль `Keyword`, крім `Keyword.get` для отримання одного значення, також надає `Keyword.get_values` для отримання кількох значень.
Використайте `Keyword.get_values`, щоб відфільтрувати вина за кольором.
