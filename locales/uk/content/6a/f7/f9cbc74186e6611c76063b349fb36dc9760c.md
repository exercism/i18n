# Вступ

У JavaScript _шаблонні рядки_ дають змогу вбудовувати вирази в рядки тексту (англ. string); це ще називають інтерполяцією рядків.
Ця можливість розширює функціональність вбудованого глобального обʼєкта [`String`][string-reference].

Шаблонні рядки в JavaScript створюють, беручи текст у зворотні лапки.
Вони дають змогу не лише включати в текст нові рядки та інші спеціальні символи, а й вбудовувати змінні та інші вирази.

```javascript
const num1 = 1;
const num2 = 2;

`Adding ${num1} and ${num2} gives ${num1 + num2}.`;
// => Adding 1 and 2 gives 3.
```

У прикладі вище зворотні лапки (<code>\`\`</code>) позначають шаблонний рядок.
Для підстановки використовують заповнювач `${...}`.
Будь-які типи, що не є рядками тексту, _неявно_ перетворюються на рядки тексту.
Цю тему розглянуто в концепції [перетворення типів][type-conversion-concept].
Із шаблонними рядками можна використовувати всі типи виразів.

```javascript
const track = 'JavaScript';

`This track on exercism.org is ${track.toUpperCase()}.`;
// => This track on exercism.org is JAVASCRIPT.
```

Коли потрібно, щоб рядок тексту було відформатовано на кілька рядків:

```javascript
`This is an example of using template
strings to accomplish multiple
lines`;

/* => This is an example of using template
     strings to accomplish multiple
     lines
*/
```

Якщо потрібно позначити новий рядок усередині звичайного рядка тексту, а не використовувати шаблонний рядок (тобто без зворотних лапок), можна скористатися escape-послідовністю нового рядка `\n`:

```javascript
'This is an example of using the newline escape sequence!\nWithout backticks';

/* => This is an example of using the newline escape sequence!
      Without backticks
*/
```

Завдяки підстановці можна також додати логіку, щоб визначити, яким має бути вихідний рядок тексту.
Один зі способів реалізувати цю логіку - скористатися [тернарним оператором][ternary-operator].
Він дає ту саму умовну функціональність `if/else`, лише в трохи іншому форматі.

Щоб додати логіку в синтаксис шаблонних рядків:

```javascript
const grade = 95;

`You have ${grade > 90 ? 'passed' : 'failed'} the exam.`;
// => You have passed the exam.
```
