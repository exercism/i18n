# Вступ

## Булеві значення (англ. Boolean)

Gleam представляє значення правди та неправди за допомогою типу `Bool`. Існує лише два значення: `True` та `False`. Ці значення можна привʼязати до змінної:

```gleam
let true_variable = True
let false_variable = False
```

Оператори `&&` (логічне і), `||` (логічне або) та `!` можна використовувати для роботи з булевими значеннями:

```gleam
True && True  // -> True
True && False // -> False

False || True  // -> True
False || False // -> False

!False // -> True
!True  // -> False
```

Оператори `&&` (і) та `||` (або) використовують скорочене обчислення, що означає, що вираз праворуч від оператора обчислюється лише за потреби.

Кожен з операторів має різний пріоритет, де `!` обчислюється перед `&&` (і) та `||` (або). Фігурні дужки можна використати, щоб обчислити одну частину виразу перед іншими:

```gleam
!True && False   // -> False
!{True && False} // -> True
```
