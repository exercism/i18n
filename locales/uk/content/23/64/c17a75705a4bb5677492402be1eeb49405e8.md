# Про

`jq` - це інструмент для розбору й перетворення даних JSON.
`jq` схожий на `sed` для даних JSON: з його допомогою можна нарізати, фільтрувати, відображати й перетворювати структуровані дані так само легко, як `sed`, `awk`, `grep` та їхні побратими дозволяють гратися з текстом.

`jq` - це динамічно типізована функціональна мова програмування.
Усі значення незмінні.

Програми `jq` складаються з конвеєрів «фільтрів»: кожен фільтр приймає один елемент як вхідні дані, діє на нього й видає нуль або більше перетворених елементів.
«Фільтр» можна також назвати «виразом».

Вихідні дані виразу можна передати іншому за допомогою оператора `|`.
`expressionA | expressionB` застосовує `expressionA` до якихось вхідних даних, а потім `expressionB` виконується повторно для кожного з виходів `expressionA`.

На вхідні дані виразу можна явно посилатися як на `.`.
Вираз, який додає `1` до своїх вхідних даних, записується так: `. + 1` (або `1 + .`).

## `jq` (програма) проти `jq` (мови)

`jq` - це програма, яку можна встановити як пакунок у різних операційних системах або зібрати з вихідного коду (вона написана мовою C).
Вона має кілька корисних [параметрів командного рядка][cli-options] і досить швидка.

Програма `jq` також реалізує _мову_, яка дозволяє довільно складні маніпуляції з вхідними даними.

Цей трек Exercism зосередиться на мові.
Використання програми `jq` ми побачимо в тестах.

## JSON

З [json.org][json]:

> JSON (JavaScript Object Notation) - це легкий формат обміну даними.
> Людям його легко читати й записувати.
> Машинам його легко розбирати й генерувати.
> Він заснований на підмножині стандарту мови програмування JavaScript ECMA-262, 3-є видання, грудень 1999 року.
> JSON - це текстовий формат, цілком незалежний від мови, але він використовує домовленості, знайомі програмістам мов родини C, зокрема C, C++, C#, Java, JavaScript, Perl, Python та багатьох інших.
> Завдяки цим властивостям JSON - ідеальна мова обміну даними.

Цей трек присвячено `jq`, а не JSON.
Ми вважаємо, що [синтаксис і типи даних JSON][wiki-json] нам уже знайомі.
