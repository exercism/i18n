# Вступ

[Масиви][arrays-concept] мають вбудовані методи для аналізу вмісту масиву.
Більшість із цих методів приймають як аргумент функцію, що повертає правду або неправду.
Таку функцію називають [`predicate`][predicate_in_programming].

Ці вбудовані методи призначені для використання _замість циклу `for`_ або вбудованого методу `forEach`:

Приклад аналізу з використанням циклу `for`:

```javascript
const numbers = [1, 'two', 3, 'four'];
for (var i = 0; i < numbers.length; i++) {
  if (numbers[i] === 'two') {
    return i;
  }
}
// => 1
```

Приклад аналізу з використанням вбудованого методу:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.indexOf('two');
// => 1
```

Нижче наведено ще кілька корисних вбудованих методів, які можна використати для аналізу масиву. Повний перелік методів масиву можна знайти на [MDN][mdn-array-methods].

## `includes`

> Метод includes() визначає, чи містить масив певне значення серед своїх елементів, і повертає відповідно правду або неправду. [^1]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.includes(1);
// => true
numbers.includes('one');
// => false
```

## `every`

> Метод every() перевіряє, чи всі елементи масиву проходять перевірку, реалізовану наданою функцією. Він повертає булеве значення (англ. Boolean). [^2]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.every((num) => num % 2 !== 0);
// => true
```

## `some`

> Метод some() перевіряє, чи принаймні один елемент масиву проходить перевірку, реалізовану наданою функцією. [^3]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.some((num) => num % 2 !== 0);
// => true
```

## `find`

> Метод find() повертає значення першого елемента в наданому масиві, який задовольняє надану тестувальну функцію. Якщо жодне значення не задовольняє тестувальну функцію, повертається undefined. [^4]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.find((num) => num < 5);
// => 1
```

## `findIndex`

> Метод findIndex() повертає індекс першого елемента в масиві, який задовольняє надану тестувальну функцію. Інакше він повертає -1, що означає, що жоден елемент не пройшов перевірку. [^5]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.findIndex((num) => num > 7);
// => 4
numbers.findIndex((num) => num > 9);
// => -1
```
