# Вступ

Успадкування належить до основних концепцій ООП (обʼєктно-орієнтованого програмування).
Воно описує відношення типу «IS-A».
У програмуванні воно означає буквально те саме, що й в англійській мові: успадкування можливостей від батьківського класу (у програмуванні такими можливостями зазвичай є функції та змінні).

Розгляньмо клас `Animal`, як показано нижче.

```java
//Creating an Animal class with bark() as a member function.
public class Animal {

    public void bark() {
        System.out.println("This is an animal");
    }

}
```

Клас `Animal` є батьківським класом, тому що властивості цього класу можна розширити на всіх тварин загалом.

Розгляньмо тварину на імʼя `Lion`, яка має такий клас:

```java
//Lion class is a child class of Animal.
public class Lion extends Animal {

    @Override
    public void bark() {
        System.out.println("Lion here!!");
    }

}
```

~~~~exercism/note
Анотація `Override` вказує на те, що метод у підкласі перевизначає метод його суперкласу.
Вона не є строго обовʼязковою, але її використання вважається найкращою практикою.
~~~~

Тепер, коли ми виконуємо такий код:

```java
Animal animal = new Lion(); //creating instance of Animal, of type Lion
animal.bark();
```

Зауваження: ініціалізуємо клас `Animal` за допомогою `Lion`.
Виведення матиме такий вигляд:

```java
Lion here!!
```

Згідно з ООП, існує багато типів успадкування, але Java підтримує лише деякі з них (багаторівневе та ієрархічне).
Щоб дізнатися більше про це, прочитайте [це][java-inheritance].
