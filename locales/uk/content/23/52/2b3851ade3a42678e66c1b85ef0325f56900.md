# Класи та властивості лише для читання

Класи та властивості лише для читання дають змогу оголошувати публічні властивості для зручного доступу, але забороняють їх змінювати.
Щоб оголосити властивість як таку, що доступна лише для читання, перед зазначенням типу потрібно додати `readonly`.
Властивості дозволено присвоїти значення один раз, але будь-яка спроба повторно присвоїти чи змінити значення призведе до помилки.

```php
<?php

class Block
{
    public function __construct(
        public readonly int $length;
        public readonly int $width;
    ) {
    }
}
```

Класи лише для читання розвивають цю поведінку: якщо клас оголошено як `readonly`, це оголошення застосовується до кожної властивості.
Крім того, це унеможливлює додавання динамічних властивостей.

```php
<?php

readonly class Block
{
    public function __construct(
        public int $length;
        public int $width;
    ) {
    }
}
```
