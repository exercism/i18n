# Про списки

**Списки** - це впорядкована колекція-послідовність у Java.
На відміну від масивів, [`List`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/List.html) може збільшуватися в розмірі, щоб умістити будь-яку кількість елементів.
Одна зі стандартних реалізацій - `ArrayList`, в основі якого лежить масив, що може змінювати свій розмір.
Ще одна стандартна реалізація - клас `LinkedList`, в основі якого лежить двозвʼязний список.

Списки можуть бути порожніми або містити будь-яку кількість елементів (включно з дублікатами).
Списки - це **узагальнений інтерфейс**, типізований так, щоб указувати, які типи обʼєктів він може містити.
Наприклад:

```java
List<String> emptyListOfStrings = List.of();
List<Integer> singleInteger = List.of(1);
List<Boolean> threeBooleans = List.of(true, false, true);
List<Object> listWithMultipleTypes = List.of("hello", 1, true);
```

Списки мають чимало корисних методів, щоб додавати, видаляти, отримувати елементи й перевіряти їхню наявність:

```java
List<Character> vowels = new ArrayList<>(List.of('a', 'e', 'i', 'o', 'i', 'e', 'a'));
int startingSize = vowels.size(); // 7
vowels.add('u'); // vowels is now ['a', 'e', 'i', 'o', 'i', 'e', 'a', 'u']
char a = vowels.get(0); // 'a'
boolean hadI = vowels.remove('i'); // true and vowels is now ['a', 'e', 'o', 'i', 'e', 'a', 'u']
boolean hasI = vowels.contains('i'); // true (still have one more left)
```

Клас [`Collections`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/Collections.html) також має корисні утиліти для роботи з колекціями на кшталт `List`:

```java
List<Integer> numbers = new ArrayList<>(List.of(1, 5, 3, 2, 4));
Collections.sort(numbers); // [1, 2, 3, 4, 5]
Collections.reverse(numbers); // [5, 4, 3, 2, 1]
Collections.fill(numbers, 42); // [42, 42, 42, 42, 42]
List<Integer> fiveNines = Collections.nCopies(5, 9); // [9, 9, 9, 9, 9]
```
