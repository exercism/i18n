# Докладніше

[`Rational numbers`][rational] - це дроби з цілим чисельником і цілим знаменником.

Наприклад, ми можемо зберегти `2//3` як точний дріб замість наближеного значення `Float64` `0.6666...`

Перевага в тому, що (крім крайнього випадку [переповнення цілих чисел][integer-overflow]) раціональне число залишається точним, і ми уникаємо помилок округлення, які часто неминучі для чисел з плаваючою комою.

Деякі додаткові подробиці можна знайти на [сторінці посібника][julia-rational] Julia.

Раціональні числа - це доволі простий числовий тип, і поводяться вони приблизно так, як ми й очікуємо.
Оскільки це стандартний тип у Julia ще з ранніх версій, більшість функцій приймає їх як вхідні дані так само, як цілі числа й числа з плаваючою комою.

## Створення раціональних чисел

Створити їх так само просто, як поставити `//` між двома цілими числами.

```julia-repl
julia> 3//4
3//4

julia> a = 3; b = 4;

julia> a//b
3//4
```

Спільні множники автоматично скорочуються, і дріб набуває [«найпростішого вигляду»][lowest-terms]: це найменші цілі числа, які точно передають дріб, із невідʼємним знаменником.

```julia-repl
julia> 5//15
1//3

julia> 5//-15
-1//3
```

Нескінченні результати приймаються, а от `NaN` - ні.

```julia-repl
julia> 1//0
1//0

julia> float(1//0)
Inf

julia> 0//0
ERROR: ArgumentError: invalid rational: zero(Int64)//zero(Int64)
```

## Арифметика з раціональними числами

Звичайні [`arithmetic operators`][operators] `+ - * / ^ %` працюють із раціональними числами майже так само, як з іншими числовими типами.

Цілі числа та інші `Rational` можна включати у вираз, і результат буде `Rational`.
Якщо у виразі є `float`, результат теж буде `float`, що може призвести до втрати точності.

Якщо потрібен `float`, досить використати функцію `float()`, щоб перетворити раціональне число.
Цілком нормально використовувати раціональні числа, щоб зберегти точність протягом довгого обчислення, а потім перетворити результат на `float`.

```julia-repl
julia> 3//4 + 1//3  # addition
13//12

julia> 3//4 * 1//3  # multiplication
1//4

julia> 3//4 / 1//3  # division
9//4

julia> 3//4 ^ 2  # exponentiation
3//16

julia> 3//4 + 5  # rational and int => rational
23//4

julia> 3//4 + 5.3  # rational and float => float
6.05

julia> float(3//4)  # casting
0.75
```

Раціональні числа можна також поєднувати з [комплексними числами][complex].
Комплексні числа розглядаються в [окремій концепції][complex-concept].

## Інші операції

У Julia раціональні числа - це просто числа.
Компілятор зазвичай сам перетворює типи, коли це потрібно.

Однак варто памʼятати, що порівняння працюють для дробів зі скінченним десятковим представленням:

```julia-repl
julia> 3//4 == 0.75
true

julia> 3//4 < 0.74
false
```

В інших випадках, щоб порівняти, `Rational` треба привести до `Float`:

```julia-repl
julia> 1//3 == 1/3
false

julia> float(1//3) == 1/3
true
```

Математичні функції приймають раціональні числа як вхідні дані, але можуть повернути результат із плаваючою комою:

```julia-repl
julia> sqrt(9//16)
0.75
```
