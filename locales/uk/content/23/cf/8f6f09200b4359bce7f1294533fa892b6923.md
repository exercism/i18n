# Тести

Для кожної вправи є одноразове налаштування, яке може зайняти кілька хвилин:

```
npm install
```

Відкрийте два термінали й у першому запустіть процес збірки.

```
npm start
```

У другому запустіть тести.

```
npm test
```

Коли ми редагуємо код, ці два процеси будуть постійно перебудовувати і перезапускати тести.
