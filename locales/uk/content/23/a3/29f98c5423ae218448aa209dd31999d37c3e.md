# Аудит платежів у базі даних

## Формулювання задачі

ABC Corp доручає нам завантажити всі дані з бази даних SQL у [таблицю Ballerina](https://ballerina.io/learn/by-example/table-syntax/) для подальшого опрацювання. Потім потрібно знайти імена працівників, які мають записи про платежі на суму, більшу за задану (наприклад, 3000.00), зробивши запит до завантаженої таблиці Ballerina.

**Крок 1:**

Створіть таблицю Ballerina з такими стовпцями.

`payment_id` - ціле число

`amount` - десяткове число

`employee_name` - рядок тексту (англ. string)

**Крок 2:**

Заповніть цю таблицю Ballerina, завантаживши відповідний повний набір даних із бази даних H2. Використайте `payment_id` як первинний ключ таблиці.

**Крок 3**

Зробіть запит до таблиці Ballerina за допомогою виразів запитів Ballerina, щоб знайти імена працівників, які мають записи про платежі більші за задану суму. Упорядкуйте результат за іменем працівника за зростанням. Перед поверненням приберіть із результату повторювані імена.

> ПРИМІТКА: для розвʼязання обовʼязково треба використати таблицю Ballerina.

## Деталі бази даних

Для цієї задачі використайте надану базу даних H2.

> Зразок бази даних міститься у файлі `gofigure.mv.db`, а сама база даних має назву `gofigure`. Файл лежить у теці `db`.

У зразку бази даних H2 вже є такі таблиці з деякими зразковими даними. Назви стовпців і типи даних наведено нижче.

**Назва таблиці**: `Employee`

| **Стовпці:**      | тип |
| -----------       | ----------- |
| `employee_id`     | ціле число, автоінкрементований первинний ключ       |
| `name`            | рядок тексту        |
| `city`            | рядок тексту        |
| `department`      | рядок тексту        |
| `age`             | ціле число        |

**Назва таблиці**: `Payment`

| **Стовпці:**      | тип |
| -----------       | ----------- |
| `payment_id`      | ціле число, автоінкрементований первинний ключ       |
| `date`            | дата        |
| `amount`          | десяткове число        |
| `employee_id`     | ціле число        |
| `reason`          | рядок тексту        |

* Файл бази даних називається `gofigure.mv.db`. Використайте JDBC URL `jdbc:h2:file:/path/to/db/file`
* Імʼя користувача: `root`
* Пароль: `root`

## Обмеження

* Використовуйте файл бази даних H2 із теки `db`, щоб перевіряти запити та зразок Ballerina
* Скористайтеся підходом із параметрами залежності Maven, щоб додати драйвер бази даних H2 як платформову залежність у файлі `Ballerina.toml`

## Тестове середовище

* Тести можна запустити командою `bal test`, і вони виконаються проти наданого зразка бази даних.

## Підказки

* Скористайтеся модулем [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc), щоб працювати з базою даних
* Зверніться до розділу [Передумови](https://lib.ballerina.io/ballerinax/java.jdbc/latest), щоб дізнатися, як додати драйвер JDBC як залежність
* Скористайтеся віддаленим методом [query](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-query), щоб отримати дані з бази даних
* Подивіться приклад [Простий запит](https://ballerina.io/learn/by-example/mysql-query-operation)
* Подивіться приклад [Синтаксис таблиці](https://ballerina.io/learn/by-example/table)
* Скористайтеся прикладом [Запити до таблиць](https://ballerina.io/learn/by-example/querying-tables), щоб знайти потрібні дані в таблиці Ballerina
