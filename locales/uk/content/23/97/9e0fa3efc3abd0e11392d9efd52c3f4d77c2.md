# Інструкції

Еліз лише починає свій шлях у магії, тож їй потрібно вміти аналізувати свою колоду багатьма різними способами.
Щоб усе було просто, вона використовує лише картки зі значеннями від 1 до 10.

## 1. Визначити, скільки карток певного типу є в колоді

Еліз хоче знати, скільки карток певного типу є в її колоді.

Напишіть функцію `cardTypeCheck`, яка приймає два параметри: масив карток (колода Еліз) і тип картки, який потрібно порахувати.

<!--prettier-ignore -->
~~~exercism/note
Функція має використовувати `forEach` і повертати кількість карток у колоді вказаного типу.
~~~

```javascript
const cardType = 3;
cardTypeCheck([1, 2, 3, 4], cardType);
// => 1
```

## 2. Визначити, скільки в колоді непарних або парних карток

Для ще одного фокусу Еліз потрібно знати, скільки непарних або парних карток є в її колоді.

Реалізуйте функцію `determineOddEvenCards`, яка приймає два параметри: масив карток (колода Еліз) і булеве значення (англ. Boolean), де `true` означає «парне», а `false` - «непарне».

Ця функція має повернути одне число: кількість непарних або парних карток у колоді (залежно від значення другого аргументу).

<!--prettier-ignore -->
~~~exercism/note
Щоб потренуватися, цього разу використайте цикл `for...of` у реалізації функції.
~~~

```javascript
determineOddEvenCards([1, 2, 3, 1, 5, 6], true);
// => 2

determineOddEvenCards([1, 2, 3, 1, 5, 6], false);
// => 4
```
