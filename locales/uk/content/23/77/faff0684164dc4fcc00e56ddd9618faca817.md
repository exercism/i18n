# Вступ

## Типові значення параметрів

[Типові значення параметрів][default-parameter-values] можна задати для будь-якого параметра функції, присвоївши значення параметру в списку параметрів після анотації типу цього параметра. Коли типове значення параметра вказано, той, хто викликає функцію, може пропустити цей параметр під час виклику, і замість нього буде використано типове значення.

```swift
func greeting(name: String = "guest", duration: Int = 2) -> String {
  "Welcome, \(name). Enjoy your \(duration) night stay."
}

greeting(name: "Bobo", duration: 7)
// Returns "Welcome, Bobo. Enjoy your 7 night stay."
greeting(duration: 3)
// Returns "Welcome, guest. Enjoy your 3 night stay."
greeting(name: "Wynona")
// Returns "Welcome, Wynona. Enjoy your 2 night stay."
greeting()
// Returns "Welcome, guest. Enjoy your 2 night stay."
```

## Варіативні параметри

[_Варіативні параметри_][variadic-parameters] у Swift дозволяють передати нуль або більше значень одного типу в один параметр функції. Це позначають, додавши `...` до анотації типу параметра.

Ці значення автоматично згрупуються в масив, елементи якого мають той самий тип, що й тип варіативного параметра.

```swift
func geometricMean(_ numbers: Double...) -> Double {
  var total = 1.0
  for number in numbers {
      total *= number
  }
  return pow(total, 1.0 / Double(numbers.count))
}

geometricMean(1, 2, 3, 4, 5)
// => 2.605171084697352
```

Зауважмо, що у Swift є обмеження щодо використання варіативних параметрів.
Якщо у визначенні функції після варіативного параметра є ще параметри, то перший параметр після варіативного _обовʼязково_ повинен мати мітку аргументу.

## In-out параметри

У тілі функції параметри вважаються константами, а не змінними; спроба змінити значення параметра призведе до помилки часу компіляції.
Якщо функція хоче змінити значення параметра, вона має використати [_in-out параметр_][in-out-parameters], щоб явно позначити цю змінність.

Щоб скористатися in-out параметрами, програміст має подбати про три речі:

1. У визначенні функції треба явно позначити in-out параметри, написавши ключове слово `inout` між `:` і назвою типу в анотації типу параметра.
2. Значення, яке передають в in-out параметр, має бути оголошене як змінна, а не як константа. Так само воно не може бути літералом.
3. Перед назвою змінної у виклику функції треба поставити `&`, явно позначаючи її як таку, що можна змінювати.

Коли все це зроблено, функція створить внутрішню копію in-out параметра, змінить її відповідно до тіла функції, а потім скопіює змінене значення назад у змінну, яку передали, коли функція поверне результат.

```swift
func updateVersion(_ record: inout (version: Int, title: String)) {
  record.version += 1
}

var dbRecord = (version: 2, title: "Exercism")
updateVersion(&dbRecord)

// dbRecord is now (3, "Exercism")
```

~~~~exercism/warning
Щодо in-out параметрів варто памʼяти про ще кілька додаткових правил.

1.  Усередині функції з in-out параметрами не можна посилатися на змінну, яку передали як in-out параметр.
2.  Ту саму змінну не можна передати як кілька in-out параметрів в одній функції.
    Наприклад, `inoutFunc(&mutVar, &mutVar)` призводить до помилки компілятора.
~~~~

## Вкладені функції

У Swift можна визначати [функції всередині інших функцій][nested-functions].
Такі функції називають **вкладеними функціями**.

Вкладені функції часто використовують як приватні допоміжні функції, які виконують конкретні завдання для функції, що їх містить, і не засмічують зовнішню область видимості:

```swift
func makeNumber(_ number: Int) -> Int {
    func double(_ x: Int) -> Int {
        x * 2
    }

    func increment(_ x: Int) -> Int {
        x + 1
    }

    return number.isMultiple(of: 2) ? increment(double(number)) : double(number)
}

print(makeNumber(3)) // Prints 6
print(makeNumber(4)) // Prints 9
```

Вкладені функції поводяться як звичайні функції, але їхня видимість обмежена тілом функції, що їх містить.
