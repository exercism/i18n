# Інструкції

У нашого друга є стара оптова крамниця під назвою **Gross Store**.
Назва походить від одиниці, у якій крамниця продає товар: усе вимірюється в [гросах][gross-unit].
Друг попросив нас створити для його крамниці систему продажів (POS).
**Спочатку створимо для неї прототип.**
**У прототипі система буде лише записувати кількість.**
Друг дав нам список мір, які допоможуть:

| Одиниця            | Значення |
| ------------------ | ----- |
| quarter_of_a_dozen | 3     |
| half_of_a_dozen    | 6     |
| dozen              | 12    |
| small_gross        | 120   |
| gross              | 144   |
| great_gross        | 1728  |

## 1. Збережіть одиницю вимірювання у своїй програмі

Щоб скористатися мірою, потрібно зберегти її в програмі.

```go
units := Units()
fmt.Println(units)
// Output: map[...] with entries like ("dozen": 12)
```

## 2. Створіть новий рахунок клієнта

Потрібно реалізувати функцію, яка створює новий (порожній) рахунок для клієнта.

```go
bill := NewBill()
fmt.Println(bill)
// Output: map[]
```

## 3. Додайте товар до рахунку клієнта

Щоб це реалізувати, потрібно:

- Повернути `false`, якщо значення `unit` відсутнє в мапі `units`.
- Інакше додати товар до `bill` клієнта за ключем-назвою товару, а потім повернути `true`.
- Якщо товар уже є в рахунку, збільшити його кількість на величину, що відповідає переданому `unit`.

```go
bill := NewBill()
units := Units()
ok := AddItem(bill, units, "carrot", "dozen")
fmt.Println(ok)
// Output: true (since dozen is a valid unit)
```

> Зверніть увагу, що повернене значення має тип `bool`.

## 4. Видаліть товар із рахунку клієнта

Щоб це реалізувати, потрібно:

- Повернути `false`, якщо переданого товару **немає** в рахунку
- Повернути `false`, якщо значення `unit` відсутнє в мапі `units`.
- Повернути `false`, якщо нова кількість була б меншою за 0.
- Якщо нова кількість дорівнює 0, повністю видалити товар із `bill`, а потім повернути `true`.
- Інакше зменшити кількість товару і повернути `true`.

```go
bill := NewBill()
units := Units()
ok := RemoveItem(bill, units, "carrot", "dozen")
fmt.Println(ok)
// Output: false (because there are no carrots in the bill)
```

> Зверніть увагу, що повернене значення має тип `bool`.

## 5. Поверніть кількість конкретного товару з рахунку клієнта

Щоб це реалізувати, потрібно:

- Повернути `0` і `false`, якщо `item` немає в рахунку.
- Інакше повернути кількість товару в `bill` і `true`.

```go
bill := map[string]int{"carrot": 12, "grapes": 3}
qty, ok := GetItem(bill, "carrot")
fmt.Println(qty)
// Output: 12
fmt.Println(ok)
// Output: true
```

> Зверніть увагу, що повернені значення мають типи `int` і `bool`.

[gross-unit]: https://en.wikipedia.org/wiki/Gross_(unit)
