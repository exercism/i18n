# Тести

## Командний рядок

Щоб запустити тести з командного рядка, скористайтеся такою командою:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)'
```

Замініть `<exercise>` на назву вправи, яку розвʼязуєте.

## Інтерактивний режим

Щоб запустити Prolog в інтерактивному режимі, спершу виконайте:

```bash
swipl
```

Коли консоль Prolog запуститься, завантажте свою реалізацію та запустіть тести за допомогою:

```
?- ["<exercise>.pl"].
?- ["<exercise>_tests.plt"].
?- run_tests.
```

Замініть `<exercise>` на назву вправи, яку розвʼязуєте.

### Перезавантаження змін

Коли ці файли завантажено, можна застосувати будь-які внесені зміни, виконавши:

```
?- make.
```

## Пропущені тести

Коли ми тільки починаємо вправу, запускається лише перший тест. Решту пропущено, бо до цілі `test` додано `condition(pending)`. Коли перший тест проходить, увімкніть наступний тест, змінивши `pending` у `condition(pending)` на `true`. Повторіть це для кожного тесту, доки всі вони не почнуть запускатися й проходити.

### Командний рядок

Додайте аргумент `-- --all` у кінець команди, щоб також запустити всі пропущені тести:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)' -- --all
```
