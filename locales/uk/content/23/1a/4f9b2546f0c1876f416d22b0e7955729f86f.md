# Вступ

У C# _ієрархію класів_ можна визначити за допомогою _спадкування_, яке дозволяє похідному класу (`Car`) успадкувати поведінку та дані його батьківського класу (`Vehicle`). Якщо батьківський клас не вказано, клас успадковує від класу `object`.

Батьківські класи можуть надавати функціональність похідним класам трьома способами:

- Визначити звичайний метод.
- Визначити метод `virtual`, який схожий на звичайний метод, але похідні класи _можуть_ його змінювати.
- Визначити метод `abstract`, тобто метод без реалізації, який похідні класи _повинні_ реалізувати. Клас із методами `abstract` також потрібно позначити як `abstract`. Не можна створити екземпляр абстрактного класу.

Модифікатор доступу `protected` дозволяє отримати доступ до члена батьківського класу в похідному класі, але блокує доступ з інших класів.

Похідні класи можуть отримати доступ до членів батьківського класу через ключове слово `base`.

```csharp
// Inherits from the 'object' class
abstract class Vehicle
{
    // Can be overridden
    public virtual void Drive()
    {
    }

    // Must be overridden
    protected abstract int Speed();
}

class Car : Vehicle
{
    public override void Drive()
    {
        // Override virtual method

        // Call parent implementation
        base.Drive();
    }

    protected override int Speed()
    {
        // Implement abstract method
    }
}
```

Конструктор похідного класу автоматично викличе конструктор батьківського класу _перед_ виконанням логіки власного конструктора. Аргументи можна передати в конструктор батьківського класу за допомогою ключового слова `base`:

```csharp
abstract class Vehicle
{
    protected Vehicle(int wheels)
    {
        Console.WriteLine("Called first");
    }
}

class Car : Vehicle
{
    public Car() : base(4)
    {
        Console.WriteLine("Called second");
    }
}
```

Коли від базового класу походять кілька класів, ці два (або більше) класи часто реалізують різні версії методу базового класу. Це дуже важливий принцип під назвою поліморфізм. Наприклад, у варіації наведеного вище прикладу ми показуємо, як код, що використовує `Vehicle`, може змінювати свою поведінку залежно від того, який тип транспортного засобу було створено.

```csharp
abstract class Vehicle
{
   public abstract string GetDescription();
}

class Car : Vehicle
{
   public Car()
   {
   }

   public override string GetDescription()
   {
      return "Runabout";
   }
}

class Rig : Vehicle
{
   public Rig()
   {
   }

   public override string GetDescription()
   {
      return "Big Rig";
   }
}

Vehicle v1 = new Car();
Vehicle v2 = new Rig();

v1.GetDescription();
// => Runabout
v2.GetDescription();
// => Big Rig
```
