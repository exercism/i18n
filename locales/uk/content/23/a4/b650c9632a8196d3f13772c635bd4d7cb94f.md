# Вступ

[Кортежі][tuples] обʼєднують кілька значень в одне складене значення.
На відміну від масивів, значення в кортежі не обовʼязково мають бути одного типу, а розмір кортежу є фіксованим після створення.

Щоб створити кортеж, ми беремо значення в дужки, розділені комами:

```swift
let order = ("biscuits", 2.99, 3)
```

Ми також можемо явно вказати анотації типів:

```swift
let order: (String, Double, Int) = ("biscuits", 2.99, 3)
```

Щоб видобути окремі елементи з неіменованого кортежу, ми можемо використати синтаксис індексів з відліком від нуля (`.0`, `.1` тощо):

```swift
let item = order.0     // "biscuits"
let quantity = order.2 // 3
```

## Іменовані кортежі

Ми можемо дати імена окремим елементам кортежу, коли визначаємо кортеж:

```swift
let order = (item: "biscuits", price: 2.99, quantity: 3)
```

Іменування елементів робить код більш читабельним і дозволяє нам отримувати доступ до елементів за допомогою точкової нотації з їхніми мітками:

```swift
let item = order.item         // "biscuits"
let quantity = order.quantity // 3
```

Ми також можемо включити назви елементів в анотацію типу:

```swift
let order: (item: String, price: Double, quantity: Int) = (item: "biscuits", price: 2.99, quantity: 3)
```

## Зміна кортежів

Якщо кортеж оголошено як змінну (`var`), ми можемо оновити його елементи:

```swift
var order = ("biscuits", 2.99, 3)
order.0 = "cookies"
order.1 = 1.99
order.2 = 5

print(order)
// Prints ("cookies", 1.99, 5)
```

## Кілька повернених значень

Хоча функції в Swift можуть повертати лише одне значення, повернення кортежу дозволяє спакувати кілька значень і [повернути кілька значень з функції][multiple-return-values]:

```swift
func divide(_ dividend: Int, by divisor: Int) -> (quotient: Int, remainder: Int) {
    let quotient = dividend / divisor
    let remainder = dividend % divisor
    return (quotient, remainder)
}

let result = divide(14, by: 4)
print("Quotient: \(result.quotient), Remainder: \(result.remainder)")
// Prints "Quotient: 3, Remainder: 2"
```

## Декомпозиція кортежів

Ми можемо розкласти (розпакувати) значення кортежу на окремі константи або змінні:

```swift
let order = ("biscuits", 2.99, 3)
let (item, price, quantity) = order

print(item) // Prints "biscuits"
```

Декомпозиція кортежів також працює безпосередньо в циклах `for-in`:

```swift
let orders = [("biscuits", 2.99, 3), ("cookies", 1.99, 5)]

for (item, price, quantity) in orders {
    print("Item: \(item), Price: \(price), Quantity: \(quantity)")
}
```
