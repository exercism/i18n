# Інструкції

Джен працює в сортувальному відділі великої фабрики.
Сортувальний відділ має обробляти все, що до нього потрапляє, позначаючи це ярликом.
Джен відповідає за речі, які наперед віднесли до чисел, і їй потрібна програма, яка допоможе з сортуванням.

Більшість примітивних значень має отримувати прості ярлики.
Для чисел вона хоче, щоб рядки тексту (англ. string) мали вигляд `"This is the number 2.0"` (якщо число дорівнювало 2).
Джен хоче однакових вихідних даних і для цілих чисел, і для чисел з плаваючою комою.

Є кілька інтерфейсів `Box`, які потрібно розпакувати, щоб дістатися їхнього вмісту.
Для `NumberBox` вона хоче, щоб рядки тексту мали вигляд `"This is a box containing the number 3.0"` (якщо метод `Number()` повертає 3).
Для `FancyNumberBox` вона хоче, щоб рядки тексту мали вигляд `"This is a fancy box containing the number 4.0"`, але лише якщо тип є `FancyNumber`.

Усе несподіване має видавати `"Return to sender"`, щоб Джен могла відіслати його назад туди, звідки воно прийшло.

## 1. Описати прості числа

Джен хоче, щоб числа повертали рядки тексту на кшталт `"This is the number 2.0"` (з однією цифрою після десяткової коми):

```go
fmt.Println(DescribeNumber(-12.345))
// Output: This is the number -12.3
```

## 2. Описати коробку з числом

Джен хоче, щоб коробки з числами повертали рядки тексту на кшталт `"This is a box containing the number 2.0"` (знову ж таки з однією цифрою після десяткової коми):

```go
fmt.Println(DescribeNumberBox(numberBoxContaining{12}))
// Output: This is a box containing the number 12.0
```

## 3. Реалізувати метод, який вилучає число з вигадливої коробки

Джен потрібна допоміжна функція, щоб вилучити число з `FancyNumberBox`.
Якщо `FancyNumberBox` є `FancyNumber`, вилучіть його значення й перетворіть його з `string` на `int`.
Будь-який інший тип `FancyNumberBox` має повертати 0.

```go
fmt.Println(ExtractFancyNumber(FancyNumber{"10"}))
// Output: 10
fmt.Println(ExtractFancyNumber(AnotherFancyNumber{"4"}))
// Output: 0
```

## 4. Описати вигадливу коробку з числом

Якщо `FancyNumberBox` є `FancyNumber`, Джен хоче, щоб рядки тексту мали вигляд `"This is a fancy box containing the number 4.0"`.
Будь-який інший тип `FancyNumberBox` має видавати `"This is a fancy box containing the number 0.0"`.

```go
fmt.Println(DescribeFancyNumberBox(FancyNumber{"10"}))
// Output: This is a fancy box containing the number 10.0
fmt.Println(DescribeFancyNumberBox(AnotherFancyNumber{"4"}))
// Output: This is a fancy box containing the number 0.0
```

ПРИМІТКА: ми маємо використати функцію `ExtractFancyNumber`!

## 5. Реалізувати `DescribeAnything`, яка використовує їх усі

Це головна функція, яка потрібна Джен і яка приймає будь-які вхідні дані.
`DescribeAnything` має делегувати іншим функціям, залежно від типу переданого значення.
А саме:

- `int` і `float64` мають обидва делегувати `DescribeNumber`
- `NumberBox` має делегувати `DescribeNumberBox`
- `FancyNumberBox` має делегувати `DescribeFancyNumberBox`
- будь-що інше має давати `"Return to sender"`

```go
fmt.Println(DescribeAnything(numberBoxContaining{12.345}))
// Output: This is a box containing the number 12.3
fmt.Println(DescribeAnything("some string"))
// Output: Return to sender
```
