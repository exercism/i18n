# Підказки

## Загальне

- [The Cairo Book: ByteArrays][book-bytearrays]
- [Starknet By Example: Strings & ByteArrays][sbe-strings]

### 1. Відформатуйте магічне заклинання

- Використайте макрос `format!`, щоб поєднати кілька вхідних даних типу `ByteArray` в один рядок тексту (англ. string).
- Розділіть заклинання роздільником, наприклад `"-"`, щоб відповідати очікуваним вихідним даним.
- Переконайтеся, що вихідні дані повертаються як `ByteArray`.

### 2. Реалізуйте трейт `Display` для `EchoStone`

- Трейт `Display` дозволяє нам визначити, як `EchoStone` має мати вигляд, коли його друкують за допомогою `{}`.
- Використайте макрос `write!` усередині функції `fmt`, щоб відформатувати вихідний рядок тексту.
- Додайте обидва поля `power` і `duration` у чіткому й лаконічному форматі, наприклад `EchoStone [power: X, duration: Y]`.

### 3. Реалізуйте трейт `Debug` для `EchoStone`

- Трейт `Debug` використовують для налагодження; він дає змогу отримати докладніші або структурованіші вихідні дані, коли його друкують за допомогою `{:?}`.
- Дотримуйтеся чіткого формату налагодження, наприклад `Debugging EchoStone: { power: X, duration: Y }`.
- Використайте макрос `write!`, щоб створити вихідні дані для налагодження.
