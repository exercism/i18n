# Тести

## Інтерактивне тестування

Запустіть свою реалізацію Common Lisp у каталозі поточної вправи (або змініть поточний каталог уже запущеної реалізації Common Lisp на цей каталог).
Користуючись roswell, зробіть це командою `ros run`.

(У всіх прикладах тут передбачено вправу з назвою `exercise-name`, за потреби змініть.)

Завантажте файл тестів у запущену реалізацію Lisp, наприклад, `(load "exercise-name-test")`. 
(Це також завантажить файл рішення.)
Після завантаження файлу тестів можна запустити тести, виконавши `(exercise-name-test:run-tests)` у REPL.

Під час внесення змін до рішення скористайтеся можливостями редактора, щоб завантажити зміни, або виконайте `(load "exercise-name")`, щоб завантажити файл рішення.

Не забудьте виконати `(exercise-name-test:run-tests)`, щоб перезапустити тести після завантаження оновленого рішення.

## Тестування з командного рядка

Можна запустити тести такою командою (знову ж таки, замініть «exercise» на відповідну назву у двох місцях)

```sh
ros run --load exercise-test.lisp --eval '(uiop:quit (if (exercise-test:run-tests) 0 1))'
```

Ця команда досить громіздка.
Один з учасників написав нотатки про те, [як зробити її виклик простішим](https://glennj.github.io/exercism/cli).
