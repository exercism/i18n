# Тести

Щоб скористатися засобом запуску тестів, нам знадобиться правильно [встановлений Godot][installation].

## Запуск тестів

[Засіб запуску тестів][test runner] використовується для завантаження й перевірки рішень.
Щоб запустити засіб запуску тестів, завантажмо його локально, а потім запустімо через `godot`.
У майбутньому засіб запуску тестів буде завантажуватися автоматично разом із вправами, коли ми використовуємо `exercism download`.

```bash
godot --headless -s /path/to/test_runner.gd -- <solution-slug> <path/to/solution>
```
