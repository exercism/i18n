# Інструкції

Ми працюємо в робототехнічному стартапі, який розробляє простого робота як доказ концепції.
Наше завдання - реалізувати функціональність для керування рухом робота.

## 1. Зорієнтуйте робота

Щоб відстежувати орієнтацію та протяжність робота, він має три маркери, розташовані на відстані 1 одиниці від його центру.
Щоб задати його початкове положення, нам треба взяти три вектори напрямку, нормалізувати їх і записати в матрицю.

Реалізуйте функцію `orientrobot(vectors)`, яка приймає вектор із трьох векторів.
Поверніть матрицю `2x3`, стовпцями якої є нормалізовані вектори.

```julia-repl
julia> orientrobot([[-1,1],[1,0],[-1,-1]])
2×3 Matrix{Float64}:
 -0.707107  1.0  -0.707107
  0.707107  0.0  -0.707107
```

## 2. Оберніть робота

Далі нам потрібна функціональність для зміни напрямку руху.
Для цього треба обернути робота так, щоб він дивився туди, куди хоче рухатися.

Реалізуйте функцію `rotaterobot(orientation, θ)`, яка приймає матрицю орієнтації робота та кут `θ`, на який треба обернути його *проти годинникової стрілки*.
Поверніть нову матрицю орієнтації.

```julia-repl
julia> orientmatrix = initialize([[-1,1],[1,0],[-1,-1]]);

julia> rotaterobot(orientmatrix, π/2)
2×3 Matrix{Float64}:
 -0.707107  6.12323e-17   0.707107
 -0.707107  1.0          -0.707107
```

## 3. Перевірте правильність орієнтації

Щоб перемістити робота з одного місця в інше, спочатку треба перевірити, чи має він правильну орієнтацію.
Другий стовпець матриці орієнтації відповідає напрямку, у який робот дивиться вперед.

Реалізуйте функцію `robotoriented(orientation, direction)`, яка приймає матрицю орієнтації та вектор відносного положення.
Поверніть `true`, якщо робот орієнтований у тому самому напрямку, що й вектор відносного положення (з урахуванням похибки округлення).

```julia-repl
julia> orientmatrix = initialize([[-1,1],[1,0],[-1,-1]]);

julia> robotoriented(orientmatrix, [5, 0])
true

julia> robotoriented(orientmatrix, [0, 5])
false

julia> robotoriented(orientmatrix, [-5, 0])
false
```

## 4. Координати корпусу робота

Оскільки матриця орієнтації також зберігає інформацію про форму робота, нам треба знати, де ці точки розташовані відносно початку координат після переміщення робота.
Це допоможе роботу уникати зіткнень з іншими обʼєктами під час руху.

Реалізуйте функцію `bodylocation(orientation, position)`, яка приймає матрицю орієнтації та поточне положення центру робота.
Поверніть перенесену матрицю орієнтації.

```julia-repl
julia> orientmatrix = initialize([[-1,1],[1,0],[-1,-1]]);

julia> bodylocation(orientmatrix, [5, 3])
2×3 Matrix{Float64}:
 4.29289  6.0  4.29289
 3.70711  3.0  2.29289
```
