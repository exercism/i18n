# Про

[Конструкція switch][switch] порівнює значення з кількома можливими варіантами збігу.
Це чистіша й зрозуміліша альтернатива ланцюжку з кількох конструкцій `if-else`.

Конструкція `switch` починається з ключового слова `switch`, після якого йде значення для перевірки.
Кожен можливий збіг уводиться ключовим словом `case`.
Ключове слово `default` визначає запасний випадок, який виконується, якщо жоден із явних випадків не збігається.
Як і ланцюжки `if-else`, конструкція `switch` виконує лише блок коду, повʼязаний з першим відповідним випадком.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Розгляньмо такий ланцюжок `if-else`:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

Це можна записати зрозуміліше за допомогою конструкції `switch`:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## Привʼязування значень та умови `where`

Випадок `switch` може привʼязати відповідні значення до тимчасових констант або змінних, щоб використати їх у тілі цього випадку.
Випадки також можуть містити умову `where`, яка перед зіставленням перевіряє додаткові умови з булевими значеннями (англ. Boolean):

```swift
let x = 1337
switch sumOfDivisors(of: x) {
case let total where total == x:
    print(total, "is a perfect number")
default:
    print(x, "is not a perfect number")
}
```
