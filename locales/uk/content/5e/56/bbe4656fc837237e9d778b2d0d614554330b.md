# Інструкції

[Число Армстронга][armstrong-number] - це число, яке дорівнює сумі власних цифр, кожна з яких піднесена до степеня, що дорівнює кількості цифр.

Наприклад:

- 9 - число Армстронга, бо `9 = 9^1 = 9`
- 10 - _не_ число Армстронга, бо `10 != 1^2 + 0^2 = 1`
- 153 - число Армстронга, бо: `153 = 1^3 + 5^3 + 3^3 = 1 + 125 + 27 = 153`
- 154 - _не_ число Армстронга, бо: `154 != 1^3 + 5^3 + 4^3 = 1 + 125 + 64 = 190`

Напишіть код, який визначає, чи належить число до чисел Армстронга.
