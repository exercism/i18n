# Інструкції

Уявімо себе завзятими спостерігачами за птахами: ми щодня рахуємо птахів, які прилітають до нашого саду. Щоденні підрахунки зберігаються в масиві, найстаріший день іде першим.

## 1. Підрахунок за сьогодні

Визначте `today`, щоб воно знімало зі стеку масив щоденних підрахунків і повертало сьогоднішній підрахунок.

```factor
{ 2 5 0 7 4 1 } today .
! => 1
```

## 2. Інкремент сьогоднішнього підрахунку

Визначте `increment-todays-count`, щоб воно повертало новий масив, у якому сьогоднішній підрахунок збільшено на одиницю. Початковий масив не повинен змінюватися.

```factor
{ 2 5 0 7 4 1 } increment-todays-count .
! => { 2 5 0 7 4 2 }
```

## 3. Чи був день без птахів?

Визначте `has-day-without-birds?`, щоб воно повертало `t`, якщо принаймні один день мав нуль птахів, а інакше `f`.

```factor
{ 2 5 0 7 4 1 } has-day-without-birds? .
! => t

{ 2 5 1 } has-day-without-birds? .
! => f
```

## 4. Сума перших днів

Визначте `count-for-first-days`, щоб воно брало масив підрахунків і число `n` та повертало суму перших `n` підрахунків.

```factor
{ 2 5 0 7 4 1 } 4 count-for-first-days .
! => 14
```

## 5. Підрахунок насичених днів

Насичений день - це день, коли прилетіло пʼять або більше птахів. Визначте `busy-days`, щоб воно повертало кількість насичених днів у масиві.

```factor
{ 2 5 0 7 4 1 } busy-days .
! => 2
```

## 6. Заповнення пропущених днів

Якщо ми не спостерігали за птахами в якийсь із `n` днів поспіль, заповнімо пропущені дні в кінці значенням `0`. Визначте `pad-missing-days`, щоб воно брало масив підрахунків і цільову довжину `n` та повертало масив довжиною щонайменше `n`, додаткові позиції якого містять `0`. Наявні підрахунки мають залишитися без змін; якщо вхідний масив уже має довжину щонайменше `n`, поверніть його без змін.

```factor
{ 2 5 0 } 7 pad-missing-days .
! => { 2 5 0 0 0 0 0 }

{ 4 1 6 8 } 3 pad-missing-days .
! => { 4 1 6 8 }
```
