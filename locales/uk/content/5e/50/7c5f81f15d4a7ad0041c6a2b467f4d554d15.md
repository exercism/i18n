# Докладніше

[`fold`][fold] - це [споживчий адаптер ітератора][consuming iterator adaptor], який застосовує функцію до кожного елемента ітерації, накопичуючи результат у нове значення.

Кожна ітерація `fold` приймає два аргументи. Перший задає початкове значення акумулятора. Другий - це замикання, яке саме приймає два аргументи: акумулятор і елемент. Повернене значення замикання стає наступним значенням акумулятора. Коли ітератор вичерпується, повертається фінальне значення акумулятора.

`fold` можна застосувати, коли потрібно перетворити колекцію на одне значення. Наприклад, якщо потрібна сума всіх парних чисел

```rust
pub fn main() {
    let even_sum = (1..=10).fold(0, |acc, num| if num % 2 == 0 { acc + num } else { acc });
    println!("{even_sum:?}");
}
```

Друкує `30`.

Те, що можна зробити за допомогою `fold`, часто можна зробити іншою функцією або кількома функціями. Для наведеного вище прикладу [`filter`][filter] по `(1..=10)`, а потім [`sum`][sum] було б менш багатослівним і дало б той самий результат, ось так

```rust
(0..=10).filter(|n| *n % 2 == 0).sum()
```

До інших функцій, які використовують частіше, ніж `fold`, належать [`product`][product] і [`collect`][collect].

Акумулятором може бути не лише число. Наприклад

```rust
pub fn giant_grunts(initial: char) -> String {
    ["Bee", "Fee", "Gee", "Fi", "Hi", "Fo", "Mo", "Fum", "Tum"].iter().fold(
        String::new(),
        |acc, grunt| if grunt.starts_with(initial) { acc + grunt } else { acc },
    )
}

pub fn main() {
    let song = giant_grunts('F');
    println!("{song:?}");
}
```

Друкує `FeeFiFoFum`
