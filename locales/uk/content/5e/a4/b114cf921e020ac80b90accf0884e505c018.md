# Довідник з Rust

## Концепції

Концептуальні вправи з Rust навчають концепцій від основ до досконалого володіння мовою. Їх класифіковано та перелічено нижче.

Концепції Exercism створені, щоб приносити учням практичну користь, тож вони відрізняються від абстрактних понять. Цей документ визначає, що ці концепції означають у Rust. Нижче ми додали візуальні групування, щоб допомогти супровідникам треку створити ефективний довідковий документ. Такі групування _не_ є педагогічними поділами. Тож під час навчання на них не посилаймося.

Прапорці позначають, чи вже викладаються ці концепції у списку зіставлення вправ.

## Зіставлення концептуальних вправ

Хоч ідеально було б мати одну концептуальну вправу для кожної з наведених вище концепцій, яка навчає рівно однієї концепції й потребує лише її передумов, зробити це не цілком практично. Наприклад, було б складно розробити вправу, яка навчала б, що таке функції, не вимагаючи жодних знань про примітивні типи; так само було б складно навчити примітивних типів із набором тестів без жодних знань про функції.

Вправи в цій таблиці мають утворювати орієнтований ациклічний граф (DAG), який зрештою охопить усі перелічені вище концепції.

| вправа                   | передумови                                   | навчає                                                   | наратив                                                                          |
| ------------------------ | -------------------------------------------- | -------------------------------------------------------- | -------------------------------------------------------------------------------- |
| `hello-world`            | -                                            | функції, набори тестів                                   | повернути літерал `&str` `"hello world"`                                        |
| `compiled-calculator`    | `hello-world`                                | цілі числа, присвоєння змінних                            | виконати набір математичних операцій і неявно повернути результат                |
| `conditionals`           | `hello-world`                                | умовні конструкції                                       | слід структурувати як `if` / `else if` / `else` з трьома вітками; неявне повернення          |
| `slices`                 | `hello-world`, `compiled-calculator`         | зрізи                                                   | витягти зріз із параметра, який є зрізом цілих чисел                        |
| `loops`                  | `slices`                                     | базовий перебір зрізу циклом                               | ідеально з достроковим поверненням, щоб було складно виразити це через ітератор           |
| `iterator-use`           | `slices`                                     | використання ітераторів, `collect`                                |
| `integer-sizes`          | `compiled-calculator`                        | цілі числа, не `i32`, приведення типів                              | усе ще всі знакові                                                                 |
| `unsigned-ints`          | `integer-sizes`                              | беззнакові цілі числа                                            |
| `indexing`               | `integer-sizes`, `slices`                    | індексування, `usize`                                        |
| `floats`                 | `compiled-calculator`                        | числа з плаваючою комою                                                   | ймовірно, та сама вправа з калькулятором, але з нецілочисловими результатами             |
| `bools`                  | `compiled-calculator`                        | булеві значення, логічні оператори                                 |
| `char`                   | `compiled-calculator`                        | тип даних `char`                                          | слід включити кілька прикладів широких символів                                           |
| `str-use`                | `char`, `slices`                             | `&str`                                                   | зауваження: незмінний!                                                                 |
| `string-use`             | `str-use`                                    | `String`                                                 | зауваження: володіє даними, змінний                                                             |
| `format-macro`           | `string-use`                                 | макрос `format!`                                          |
| `str-vs-string`          | `str-use`, `string-use`                      | поєднання, перетворення, витрати тощо                        |
| `generics-basics`        | `integer-sizes`, `floats`                    | використання зовнішніх трейтів як обмежень, основи узагальнень          | ймовірно, усе ще калькулятор, лише узагальнений                                 |
| `structs`                | `string-use`, `unsigned-ints`, `floats`      | створення та використання структури для керування даними               | `Person` має імʼя, зріст і кількість взуття, яким володіє                                   |
| `implicit-return`        | `compiled-calculator`                        | області видимості, вирази, неявне повернення                     |
| `explicit-return`        | `implicit-return`, `conditionals`            | явна інструкція `return`                              |
| `methods`                | `structs`, `explicit-return`                 | блоки `impl`, методи                                   |
| `tuples`                 | `structs`                                    | кортежі                                                   | подавати як анонімні структури; пояснювати синтаксис `.0`                                    |
| `tuple-structs`          | `tuples`, `structs`                          | кортежні структури (іменовані кортежі)                             |
| `basic-enums`            | `unsigned-ints`                              | базові переліки (без полів), `match`                         |
| `enums`                  | `basic-enums`, `tuple-structs`               | кортежний синтаксис для варіантів переліку                           |
| `option`                 | `enums`                                      | `Option<T>`                                              |
| `result`                 | `enums`                                      | `Result<T, E>`                                           |
| `mutability`             | `compiled-calculator`                        | незмінність типово; явна змінність             |
| `let-expressions`        | `loops`, `option`, `result`                  | `if let`, `while let`                                    | ймовірно, залежатиме лише від одного з `option` чи `result` залежно від реалізації |
| `vectors`                | `slices`                                     | `Vec<T>`                                                 |
| `hashmaps`               | `vectors`                                    | `Hashmap<K, V>`                                          |
| `entry-api`              | `hashmaps`                                   | Entry API                                                |
| `hashsets`               | `hashmaps`                                   | `HashSet<K>`                                             |
| `btreemaps`              | `hashmaps`                                   | `BTreeMap<K, V>`                                         |
| `deriving-traits`        | `structs`                                    | `PartialEq`, `PartialOrd`, `Debug`, `Display`, `Default` |
| `implementing-traits`    | `deriving-traits`                            | ручна реалізація трейту                            | ймовірно, реалізувати `Iterator`                                                    |
| `collection-conversions` | `vectors`, `hashsets`, `implementing-traits` | `FromIterator`, `IntoIterator`                           |
