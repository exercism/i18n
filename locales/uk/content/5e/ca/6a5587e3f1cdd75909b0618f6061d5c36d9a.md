# Запуск тестів

Виберіть свою операційну систему:

- [Windows](#windows)
- [macOS](#macos)
- [Linux](#linux)

## Windows

1. Відкрийте Command Prompt.
2. Отримайте першу вправу:

   ```batchfile
   C:\Users\JohnDoe>exercism download --exercise hello-world --track java
   ```

3. Перейдіть до каталогу з вправою:

   ```batchfile
   C:\Users\JohnDoe>cd C:\Users\JohnDoe\exercism\java\hello-world
   ```

4. Запустіть тести:

   ```batchfile
   C:\Users\JohnDoe>gradlew.bat test
   ```

   _(Не варто хвилюватися, що тести спочатку не проходять: саме так починається кожна вправа.)_

5. Розвʼяжіть вправу. Знайдіть і опрацюйте посібник `instructions.append.md` ([переглянути на GitHub][hello-world-tutorial]).

Успіхів! Бажаємо гарного настрою!

4. Розвʼяжіть вправу. Знайдіть і опрацюйте посібник `instructions.append.md` ([переглянути на GitHub][hello-world-tutorial]).

Успіхів! Бажаємо гарного настрою!

## Linux

1. У вікні термінала отримайте першу вправу:

   ```sh
   exercism download --exercise hello-world --track java
   ```

2. Перейдіть до каталогу з вправою:

   ```sh
   cd /home/johndoe/exercism/java/hello-world
   ```

3. Запустіть тести:

   ```sh
   ./gradlew test
   ```

   _(Не варто хвилюватися, що тести спочатку не проходять: саме так починається кожна вправа.)_

   Якщо побачимо таку помилку:

   ```sh
   ./gradlew: Permission denied
   ```

   То файлу бракує права на виконання. Щоб це виправити, виконайте:

   ```sh
   chmod +x ./gradlew
   ```

   І тепер ми зможемо виконати попередню команду.

4. Розвʼяжіть вправу. Знайдіть і опрацюйте посібник `instructions.append.md` ([переглянути на GitHub][hello-world-tutorial]).

Успіхів! Бажаємо гарного настрою!
