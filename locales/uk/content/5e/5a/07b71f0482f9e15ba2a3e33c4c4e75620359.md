# Вступ

`when` - ключове слово для фільтрування винятків. Його записують після інструкції `catch`, і воно може приймати булевий вираз (англ. Boolean), що містить будь-які значення, доступні в поточній області видимості. Якщо вираз набуває значення правда, то виконується блок, повʼязаний із цією інструкцією `catch`; інакше перевіряється наступна інструкція `catch`, якщо така є.

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```
