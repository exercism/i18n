# Рекомендовані навчальні ресурси

Вітаємо у вивченні ColdFusion (CFML)! CFML - це динамічна скриптова мова для JVM із нестрогою типізацією. У ній є два різні типи файлів. Файли `.cfm` (розмітка ColdFusion)_ є суто процедурними й використовують синтаксис на основі тегів для шаблонізації HTML. Ці файли використовують для представлень, якщо створюють вебсайт:

**index.cfm**

```xml
<cfoutput>
	<html>
		<h1>Welcome to my site, #FirstName# #LastName#!
	</html>
</cfoutput>
```

Інший тип файлу - це `.cfc` (компонент ColdFusion). Саме так оголошують клас. Компоненти використовують для бізнес-логіки, моделей і контролерів. Зазвичай вони використовують синтаксис скриптів, який нагадує JavaScript.

**Car.cfc**

```js
component accessors=true {
	property name='make' type='string';
	property name='model' type='string';
	property name='year' type='number';

	function init() {
		return this;
	}
 
}
```
