# Докладніше

Регулярні вирази в Gleam відповідають специфікації **PCRE** (**P**erl **C**ompatible **R**egular **E**xpressions), подібно до інших популярних мов, як-от Java, JavaScript чи Ruby.

Модуль `gleam/regex` надає функції для роботи з регулярними виразами.

~~~~exercism/note
Ця вправа припускає, що ми вже знайомі з синтаксисом регулярних виразів, зокрема з класами символів, квантифікаторами, групами та захопленнями.

Якщо потрібно освіжити знання про регулярні вирази, зазирнімо до одного з цих джерел: [Regular-Expressions.info](https://www.regular-expressions.info), [Rex Egg](https://www.rexegg.com/), [RegexOne](https://regexone.com/), [Regular Expressions 101](https://regex101.com/), [RegExr](https://regexr.com/).
~~~~

Найпоширеніший спосіб створити регулярні вирази - скористатися функцією `regex.from_string`.

```gleam
let assert Ok(re) = regex.from_string("test")
```

Функція `regex.from_string` повертає `Error`, якщо синтаксис регулярного виразу неправильний, тому тут використано let-assertion, щоб переконатися, що регулярний вираз правильний.

Функцію `regex.check` можна використати, щоб перевірити, чи регулярний вираз відповідає рядку тексту (англ. string).

```gleam
let assert Ok(re) = regex.from_string("test")

regex.check(re, "this is a test")
// -> True

regex.check(re, "this is too")
// -> False
```


## Захоплення

Якщо ми хочемо захопити підрядки за допомогою регулярного виразу, можна скористатися функцією `regex.scan`, яка повертає масив збігів.

```gleam
let assert Ok(re) = regex.from_string("[oi]n a (\\w+)")
regex.scan(with: re, content: "I am on a boat in a lake.")
// -> [
//   Match(
//     content: "on a boat",
//     submatches: [Some("boat")]
//   ),
//   Match(
//     content: "in a lake",
//     submatches: [Some("lake")]
//   )
// ]
```

## Модифікатори

Поведінку регулярного виразу можна змінити, створивши його за допомогою функції `regex.compile` і передавши опції.

```gleam
let options = regex.Options(case_insensitive: True, multi_line: False)
let assert Ok(re) = regex.compile("[A-Z]", with: options)
regex.check(re, "abc123")
// -> True
```
