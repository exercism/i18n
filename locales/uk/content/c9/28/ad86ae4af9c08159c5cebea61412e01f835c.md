## Імпортування

Модуль зазвичай завантажують за допомогою ключового слова `use`.
Воно і завантажує модуль, і викликає його метод `import`, імпортуючи всі експортовані символи.

Символи з масиву `@EXPORT` пакета імпортуються типово.
Символи з масиву `@EXPORT_OK` пакета потрібно імпортувати явно.

До Perl `v5.37` модуль мав завершуватися істинним значенням (зазвичай `1`), щоб показати, що його успішно завантажено.
Це не потрібно, якщо використовувати можливість [`module_true`][module_true].

## Експортування

Щоб символ можна було імпортувати, його спершу потрібно експортувати.
Модуль [Exporter][Exporter] входить до складу Perl і є одним із найзручніших варіантів для експортування.

Визначення модуля:
```perl
package Foo;

use Exporter ('import');
our @EXPORT_OK = ('bar');

sub bar { ... }
```

Використання модуля:
```perl
use Foo ('bar');

bar();
```

## Прагма

Прагмою називають модуль, який впливає на той чи інший аспект поведінки Perl.

Прагми [`strict`][strict] і [`warnings`][warnings] зазвичай радять використовувати, щоб відповідно обмежити небезпечні конструкції та позначити потенційні проблеми.
Прагма `strict` вмикається разом із `use v5.12` або новішою версією.
Прагма `warnings` вмикається разом із `use v5.35` або новішою версією.

Прагма [`feature`][feature] дає змогу ввімкнути новіші та експериментальні можливості Perl.
Коли ключовому слову `use` задати конкретну версію Perl, воно вмикає набір можливостей для цієї версії.

## Основні модулі

Разом з [Exporter][Exporter] Perl має велику кількість [основних модулів][perl-core-modules], доступних для використання.
До прикладів, корисних для вправ, з якими ми тут можемо зустрітися, належать [List::Util][List::Util], [Time::Piece][Time::Piece] і [Math::BigRat][Math::BigRat].

## CPAN

Крім основних модулів, [CPAN][metacpan] пропонує тисячі додаткових модулів, створених спільнотою Perl, які можна встановити.
Трек Perl використовує [cpanfile][test-runner-cpanfile], щоб установити набір модулів, які можна використовувати із засобом запуску тестів Perl від Exercism.
