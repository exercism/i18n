# Тести

## Запуск тестів

Щоб запустити тести, виконайте таку команду:

```bash
dotnet test
```

Щоб тести запускалися автоматично щоразу, коли змінюється файл із кодом, виконайте таку команду:

```bash
dotnet watch test
```

## Як розвʼязати вправу

Розвʼязати вправу означає зробити так, щоб усі її тести пройшли. Типово, коли ми запускаємо тести, виконується лише один тест (перший). Це зроблено навмисно, щоб ми могли зосередитися лише на тому, щоб цей один тест пройшов. Після того, як він пройде, ми можемо увімкнути наступний тест, прибравши `Skip = "Remove this Skip property to run this test"` з атрибута `[Fact]` або `[Theory]` цього тесту. Коли всі тести буде увімкнено і наша реалізація їх усіх пройде, вправу буде розвʼязано!

Щоб допомогти нам почати, до кожної вправи додається файл-заглушка з реалізацією. Ми можемо використати цей файл як відправну точку для побудови свого рішення. Можна сміливо видаляти або змінювати цей файл, якщо вважаємо, що так буде краще.

## Використання пакетів

Більшість вправ можна розвʼязати без зовнішніх пакетів. Однак у вправах, де ми таки хочемо використати зовнішній пакет, його можна додати до свого проєкту, виконавши таку команду:

```bash
dotnet add package [package-name]
```
