# Додаток до інструкцій

## Регістри

| Регістр | Використання | Тип | Опис |
| -------- | --------- | ------- | ------------------------------------------------ |
| `$a0`    | вхідні дані     | ціле число | рік для перевірки                                    |
| `$v0`    | вихідні дані     | булеве значення (англ. Boolean) | вхідний рік є високосним (`0` = `false`, `1` = `true`) |
| `$t0-9`  | тимчасовий | будь-який     | використовується для тимчасового зберігання                       |
