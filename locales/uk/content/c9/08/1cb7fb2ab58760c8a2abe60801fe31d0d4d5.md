# Вступ

Цикл `for` - одна з найуживаніших інструкцій, які багаторазово виконують певну логіку.
У JavaScript він складається з ключового слова `for`, _заголовка_ в круглих дужках і блоку коду, що містить _тіло_ циклу у фігурних дужках.

```javascript
for (initialization; condition; step) {
  // code that is executed repeatedly as long as the condition is true
}
```

Ініціалізація зазвичай створює змінну-лічильник, умова перевіряє, чи потрібно продовжити цикл чи зупинити його, а крок збільшує лічильник на одиницю наприкінці кожного повторення.
Окремі частини заголовка розділені крапками з комою.

```javascript
const list = ['a', 'b', 'c'];
for (let i = 0; i < list.length; i++) {
  // code that should be executed for each item list[i]
}
```
