# Перетворення даних про пальне у JSON

## Постановка задачі

Кожен працівник ABC Corp отримує необмежений ліміт на пальне. Працівники мають надсилати запис щоразу, коли заправляють свої автомобілі. Ці записи додаються до одного й того самого файлу JSON і обробляються в кінці місяця.

Ми, як члени команди цифрових операцій, маємо прочитати цей файл JSON і записати результати в інший файл JSON. Вихідний файл має містити запис для кожного працівника з такими даними:

- Номер працівника
- Кількість заправок
- Загальна вартість пального
- Загальна кількість галонів
- Загальний пробіг у милях

Ми отримуємо два аргументи `string`.

1. Шлях до вхідного файлу JSON.
1. Шлях до вихідного файлу JSON.

Вхідний файл JSON містить масив обʼєктів JSON. Кожен обʼєкт JSON має такий вигляд.


```json
{
    "type": "array",
    "items": {
        "type": "object",
        "properties": {
            "employeeId": {
                "type": "integer"
            },
            "odometerReading": {
                "type": "integer"
            },
            "gallons": {
                "type": "number"
            },
            "gasPrice": {
                "type": "number"
            }
        },
        "required": [
            "employeeId",
            "odometerReading",
            "gallons",
            "gasPrice"
        ]
    }
}
```

```ballerina
// Ballerina record type definition
type FillUpEntry record {|
    int employeeId;
    int odometerReading;
    decimal gallons;
    decimal gasPrice;
|};
```

Наше завдання - перетворити вхідні дані JSON у наведений нижче формат JSON і записати вміст за вказаним шляхом. Вихідний файл має містити запис для кожного працівника, відсортований за зростанням `employeeId`.

```json
{
    "type": "array",
    "items": {
        "type": "object",
        "properties": {
            "employeeId": {
                "type": "integer"
            },
            "gasFillUpCount": {
                "type": "integer"
            },
            "totalFuelCost": {
                "type": "number"
            },
            "totalGallons": {
                "type": "number"
            },
            "totalMilesAccrued": {
                "type": "integer"
            }
        },
        "required": [
            "employeeId",
            "gasFillUpCount",
            "totalFuelCost",
            "totalGallons",
            "totalMilesAccrued"
        ]
    }
 }
```

```ballerina
// Ballerina record type definition
type EmployeeFillUpSummary record {|
    int employeeId;
    int gasFillUpCount;
    decimal totalFuelCost;
    decimal totalGallons;
    int totalMilesAccrued;
|};
```

## Обмеження

- Кількість записів про заправки `n` у вхідному файлі JSON:  0 <= n <= 1000
- Кількість працівників у компанії: 97
- Ціна пального вказана за галон
- Пропущених записів про заправки немає

## Підказки

- Використайте [модуль `ballerina/io`](https://lib.ballerina.io/ballerina/io/latest), щоб читати й записувати файли JSON.
- Перетворіть значення JSON на типи, визначені для застосунку, щоб працювати з даними типобезпечно. За інформацією зверніться до [прикладу перетворення на визначений користувачем тип](https://ballerina.io/learn/by-example/convert-from-json-to-user-defined-type) у Ballerina By Examples (BBE).

```ballerina
   json jsonPayload = {id: "2", title: "Jeru", artist: "Gerry Mulligan", price: 17.99};

   // Using cloneWithType  
   Album album1 = check jsonPayload.cloneWithType();
   io:println(album1);
 
   // Using fromJsonWithType
   Album album2 = check jsonPayload.fromJsonWithType();
   io:println(album2);
```

- [Деструктуризація записів](https://ballerina.io/learn/by-example/destructure-records-using-query) може допомогти зменшити багатослівність коду.

```ballerina
   Album {id, title, artist, price} = album1;
   io:println(id);
   io:println(title);
```

- Використовуйте функції з тілом-виразом для функцій з єдиним виразом. Наприклад, для функцій, які містять лише інструкцію повернення значення.

```ballerina
   function cfr(int deaths, int cases) returns decimal => <decimal>deaths / <decimal>cases * 100;
```
