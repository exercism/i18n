# Про це

Common Lisp використовує стандартні арифметичні оператори для більшості операцій, але має одну особливість: він послуговується «префіксною нотацією» на противагу звичнішій «інфіксній».

Наочніше:

```lisp
;; Infix-notation (non-lisp languages)
1 + 2 + 3 + 4 + 5 ; => 15
;; Prefix-notation (lisp languages)
(+ 1 2 3 4 5)     ; => 15
```

Хоча префіксна нотація перетворює деякі операції, як-от `2 + 2`, на дещо незвичну форму `(+ 2 2)`, вона значно спрощує роботу з кількома числами одночасно.

## Арифметичні оператори з одним аргументом

Як невелика особливість, оператори `-` і `/` мають спеціальне значення, коли застосовуються лише до одного числа:

```lisp
;; A single number passed to `-` is simply negated
(- 4)   ; => -4
(- -32) ; => 32
;; A single number passed to `/` returns the reciprocal
(/ 8)   ; => 1/8
(/ 0.1) ; => 10.0
```

## Порівняння чисел

Нарешті, порівнювати різні числа буває корисно за допомогою таких функцій, як `=` (дорівнює), `/=` (не дорівнює) і `>=` (більше або дорівнює).
Коли ці порівняння справджуються (як-от `(= 1 1)`), вони повертають `T`, а коли ні (як-от `(> 0 1)`), повертають `NIL`.

## Числові предикати

Мова також має кілька корисних предикатів, як-от `zerop`, `evenp` і `oddp`, які перевіряють очевидні умови.

## Довідка

```lisp
;; Addition
(+ 1 2 3 4 5) ; => 15

;; Subtraction
(- 15 3 2)    ; => 10
(- 42)        ; => -42

;; Multiplication
(* 4 3 2 1)   ; => 24

;; Division
(/ 64 16 2)   ; => 2
(/ 5)         ; => 1/5

;; Exponentiation
(expt 2 8)    ; => 256

;; Square Root
(sqrt 25)     ; => 25

;; Modulo (Similar to remainder)
(mod 10 3)    ; => 1

;; Equality
(= 2 2)       ; => T
(= 3 5)       ; => NIL
```
