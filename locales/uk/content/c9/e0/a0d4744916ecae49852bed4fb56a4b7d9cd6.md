# Числа з плаваючою комою

У PHP числа з плаваючою комою використовуються для представлення підмножини дійсних чисел.
Вони починаються з однієї або кількох цифр, розділених десятковим розділювачем.

```php
<?php

$a = 1.234; 
$b = 1.2e3; 
$c = 7E-10;
$d = 1_234.567; // as of PHP 7.4.0
```

## Поширені пастки

Не всі числа й арифметичні операції можна виконати з числами з плаваючою комою.
Використання чисел з плаваючою комою для представлення доларів і центів може призвести до помилок округлення.

```php
<?php

$result = 0.1 + 0.2; // => 0.30000000000000004
```
