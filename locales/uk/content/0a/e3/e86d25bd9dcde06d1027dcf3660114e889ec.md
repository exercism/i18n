# Інструкції

У цій вправі ми реалізуємо логіку квестів для нової рольової гри (RPG), яку розробляє наш друг. Головна героїня гри - Анналін, смілива дівчина, у якої є грізний і відданий пес. На жаль, трапляється лихо: її найкращого друга викрали, коли він збирав у лісі ягоди. Анналін спробує знайти й визволити свого найкращого друга, за бажанням узявши з собою в цю подорож свого пса.

Йдучи деякий час слідами найкращого друга, вона знаходить табір, у якому його тримають. Виявляється, викрадачів двоє: могутній лицар і хитрий лучник.

Знайшовши викрадачів, Анналін думає, які з наведених нижче дій вона може виконати:

- Швидка атака: швидку атаку можна здійснити, якщо лицар спить, бо йому потрібен час, щоб вдягнути обладунки, тож він буде вразливим.
- Розвідка: за групою можна стежити, якщо хоч один із них не спить. Інакше стеження - марна трата часу.
- Подати сигнал бранцю: бранцю можна подати сигнал пташиними звуками, якщо бранець не спить, а лучник спить, бо лучники вміють подавати пташині сигнали, тож можуть перехопити повідомлення.
- _Визволити бранця_: Анналін може спробувати непомітно пробратися в табір, щоб визволити бранця.
  Це ризиковано, і вдатися це може лише одним із двох способів:
  - Якщо Анналін взяла з собою пса, вона може врятувати бранця, коли лучник спить.
    Лицар боїться пса, і лучник не встигне підготуватися, перш ніж Анналін і бранець утечуть.
  - Якщо Анналін без пса, то їй і бранцю доведеться діяти дуже обережно!
    Анналін може визволити бранця, якщо бранець не спить, а лицар і лучник сплять, але якщо бранець спить, його не врятувати: бранець злякається раптової появи Анналін і розбудить лицаря й лучника.

У нас чотири завдання: реалізувати логіку, яка визначає, чи доступні наведені вище дії, залежно від стану трьох персонажів, знайдених у лісі, і чи взяла Анналін із собою свого пса.

## 1. Перевірте, чи можлива дія «Швидка атака»

Реалізуйте функцію з назвою `canExecuteFastAttack`, яка приймає булеве значення (англ. Boolean), що вказує, чи не спить лицар. Функція повертає `true`, якщо дія «Швидка атака» доступна залежно від стану персонажа. Інакше повертає `false`:

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

canExecuteFastAttack knightIsAwake
-- => false
```

## 2. Перевірте, чи можлива дія «Розвідка»

Реалізуйте функцію з назвою `canSpy`, яка приймає три булеві значення, що вказують відповідно, чи не сплять лицар, лучник і бранець. Функція повертає `true`, якщо дія «Розвідка» доступна залежно від стану персонажів. Інакше повертає `false`:

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

archerIsAwake :: Boolean
archerIsAwake = true

prisonerIsAwake :: Boolean
prisonerIsAwake = true

canSpy knightIsAwake archerIsAwake prisonerIsAwake
-- => true
```

## 3. Перевірте, чи можлива дія «Подати сигнал бранцю»

Реалізуйте функцію з назвою `canSignalPrisoner`, яка приймає два булеві значення, що вказують відповідно, чи не сплять лучник і бранець. Функція повертає `true`, якщо дія «Подати сигнал бранцю» доступна залежно від стану персонажів. Інакше повертає `false`:

```purescript
archerIsAwake :: Boolean
archerIsAwake = false

prisonerIsAwake :: Boolean
prisonerIsAwake = true

canSignalPrisoner archerIsAwake prisonerIsAwake -- => true
```

## 4. Перевірте, чи можлива дія «Визволити бранця»

Реалізуйте функцію з назвою `canFreePrisoner`, яка приймає чотири булеві значення. Перші три параметри вказують відповідно, чи не сплять лицар, лучник і бранець. Останній параметр вказує, чи є з Анналін її пес. Функція повертає `true`, якщо дія «Визволити бранця» доступна залежно від стану персонажів і наявності пса. Інакше вона повертає `false`:

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

archerIsAwake :: Boolean
archerIsAwake = false

prisonerIsAwake :: Boolean
prisonerIsAwake = true

petDogIsPresent :: Boolean
petDogIsPresent = true

canFreePrisoner knightIsAwake archerIsAwake prisonerIsAwake petDogIsPresent
-- => false
```
