# не використовуйте метод `main`

Спробуйте вилучити метод `main` зі свого коду.
Тести вправи не вимагають, щоб у рішенні був метод `main`, а його наявність робить код трохи важчим для читання.

Зазвичай метод `main` додають, щоб було легше налагоджувати код.
Однак кращий підхід - налагоджувати код, запускаючи один або кілька модульних тестів.
Це має додаткову перевагу: можна зосередитися на налагодженні конкретного тестового випадку.

Ось кілька посилань, які пояснюють, як налагоджувати код Java, запускаючи модульні тести в різних інтегрованих середовищах розробки (IDE):

- [Запуск і налагодження тестів Java у Visual Studio Code](https://code.visualstudio.com/docs/java/java-testing#_rundebug-test-cases)
- [Налагодження тестів в IntelliJ IDEA](https://www.jetbrains.com/help/idea/performing-tests.html#RedebugFailedTests)
