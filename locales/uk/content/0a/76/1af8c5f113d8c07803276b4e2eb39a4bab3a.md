# Порядок анотацій функцій

Зазвичай анотації функцій `@doc` мають стояти перед анотаціями функцій `@spec`, а анотації `@spec` - безпосередньо перед самою функцією. Якщо функція має кілька клауз, анотації мають стояти перед першою клаузою.

Приклад:

```elixir
@doc """
This function counts the number elements in a list
"""
@spec count(list(any())) :: integer()
def count([]), do: 0
def count([h | t]), do: 1 + count(t)
```
