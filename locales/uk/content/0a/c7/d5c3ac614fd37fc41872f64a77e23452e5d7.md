# Додаток до інструкцій

## Регістри

| Регістр | Призначення | Тип         | Опис                              |
| ------- | ----------- | ----------- | --------------------------------- |
| `$a0`    | вхідні дані | ціле число  | підкореневе число                 |
| `$v0`    | вихідні дані | ціле число | квадратний корінь                 |
| `$t0-9`  | тимчасовий  | будь-що     | використовується для тимчасового зберігання |
