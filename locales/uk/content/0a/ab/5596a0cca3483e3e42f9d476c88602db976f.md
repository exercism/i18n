# Вступ

Булевий тип у Lua має два традиційні булеві значення (англ. Boolean): `true` і `false`. Ці значення можна присвоїти змінній, поєднати з логічними операторами (`and`, `or`, `not`) і використати в умовних перевірках (наприклад, у структурах керування).

```lua
local is_true = true
local is_false = false

true and true  --> true
true and false --> false
false or true  --> true
false or false --> false
not false      --> true
not true       --> false

-- prints 0
if is_true == true then
  print(0)
else
  print(1)
end
```

Умовні перевірки та логічні оператори вважають неправдою і булеве `false`, і `nil`, а правдою - усе інше.
```lua
1 and 2          --> 2
nil and 2        --> nil
false and 2      --> false
1 or 2           --> 1
false or 'hello' --> "hello"
nil or false     --> false
```

І `and`, і `or` використовують *скорочене обчислення*, тобто обчислюють свій другий операнд лише за потреби. Усі операції обчислюються згідно з [пріоритетом операторів](https://www.lua.org/manual/5.4/manual.html#3.4.8), де `not` обчислюється раніше за `and` та `or`.
