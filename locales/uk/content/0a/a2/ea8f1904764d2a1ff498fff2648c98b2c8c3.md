# Доповнення до інструкцій

Цю вправу слід реалізувати за допомогою граматики з визначеними клаузами (DCG).
Граматики DCG можна використовувати не лише для розбору послідовностей (списків), а й для їх генерації, доповнення та перевірки.

## Бібліотека

Файли із заготовкою рішення містять такий рядок:

```prolog
:- use_module(library(dcg/basics)).
```

Це гарантує, що бібліотеку `dcg/basics` можна використовувати, і цього має бути достатньо для розвʼязання цієї вправи.
