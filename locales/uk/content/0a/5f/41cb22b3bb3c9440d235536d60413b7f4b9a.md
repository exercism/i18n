Мета цієї вправи - удосконалити вправу «Перевірка пароля».
Оскільки заданий пароль, найімовірніше, порушуватиме більш ніж одне правило за раз, корисна перевірка пароля має повідомляти користувачеві про всі порушені правила, а не лише про перше виявлене.
Удосконалена перевірка пароля має вказувати всі правила, які порушує заданий пароль, одразу.

Правила для цієї перевірки пароля такі самі, як у попередній вправі «Перевірка пароля»:

- Має містити 12 або більше символів
- Має містити принаймні одну велику літеру
- Має містити принаймні одну малу літеру
- Має містити принаймні одну цифру
- Має містити принаймні один символ із набору !@#$%^&\*

## 1. Змініть дискриміноване обʼєднання `PasswordError`, щоб окремі значення можна було трактувати як прапорці

Зауважте, що тести не скомпілюються, доки цей обовʼязковий крок не буде виконано.

## 2. Реалізуйте функцію `checkPassword`

Функція `checkPassword` перевіряє заданий пароль на відповідність згаданим правилам.
Функція має повертати значення `Result`, де `Ok` повертається, коли пароль задовольняє всі правила, а `Error` - коли він порушує одне чи більше правил.
Якщо заданий пароль порушує кілька правил, значення `PasswordError` має представляти всі порушені правила.

```fsharp
checkPassword "abcdefghijk5"
// => Error (PasswordError.MissingUppercaseLetter ||| PasswordError.MissingSymbol)
```

## 3. Реалізуйте функцію ``getStatusPhrases`

Функція `getStatusPhrases` повертає набір рядків тексту (англ. string), кожен з яких містить зрозумілу для людини фразу, що відповідає одній з помилок у результаті, поверненому з `checkPassword`.

```fsharp
getStatusPhrases (Error PasswordError.MissingDigit ||| PasswordError.LessThan12Characters)
// => List ["12 characters"; "digit"]
```
