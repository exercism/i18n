# Вступ

Тип називають _узагальненим типом_, коли він може містити значення будь-якого типу за допомогою _параметра типу_.

Наприклад, цей тип `Box` має параметр типу `a` (записаний малими літерами).

```gleam
pub type Box(a) {
  Box(a)
}
```

Параметр типу `a` є замінником для будь-якого типу, тож `Box` можна використовувати з рядками тексту (англ. string), цілими числами чи будь-яким іншим типом.

```gleam
Box("Hello, Joe!") // The type is Box(String)

Box(42) // The type is Box(Int)
```

Тип може мати кілька параметрів типу, якщо розділити їх комами.

```gleam
pub type Pair(a, b) {
  Pair(a, b)
}
```

## Узагальнені функції

Параметри типу можна також використовувати в аргументах функцій.

Ця функція приймає значення типу `a` і двічі викликає функцію, яка приймає `a` та повертає `b`.

```gleam
pub fn twice(value: a, f: fn(a) -> b) -> b {
  f(value)
  f(value)
}
```
```gleam
// The type is fn(String, fn(String) -> Nil) -> Nil
twice("Hello, Joe!", io.println)
```
