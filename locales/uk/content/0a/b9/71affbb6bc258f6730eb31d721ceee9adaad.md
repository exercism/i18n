# Вступ

Значення `null` у JavaScript позначає навмисну відсутність значення обʼєкта. Воно належить до примітивних типів JavaScript.

```javascript
// I do not have an apple.
var apple = null;
apple; // => null

// null is treated as falsy for boolean operations, therefore
!apple; // => true
!!apple; // => false
```
