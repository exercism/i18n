# Інструкції

Еліз, майбутня фокусниця, продовжує тренування. Їй дадуть кілька стосів карт, які їй знадобляться для виконання фокусів.
Щоб трохи спростити собі роботу, вона використовує лише карти від 1 до 10.

У цій вправі скористайтеся вбудованими методами, щоб проаналізувати вміст вектора.

## 1. Визначте, чи присутня карта

Еліз хоче визначити, чи присутня карта в стосі, тобто чи містить стос конкретне число.

```R
card = 3;
does_stack_include_card(c(2, 3, 4, 5), card);
# => TRUE
```

## 2. Знайдіть позицію карти

Еліз хоче знати позицію (індекс) карти в стосі. 
Якщо карти немає в стосі, поверніть `-1`.

```R
card = 2;
get_card_position(c(9, 7, 3, 2), card);
# => 4
```

## 3. Визначте, чи кожна карта парна

Еліз хоче знати, чи кожна карта парна, тобто чи кожне число в стосі є парним числом.

```R
is_each_card_even(c(2, 4, 6, 7));
# => FALSE
```

## 4. Перевірте, чи є в стосі карта з непарним значенням

Еліз хоче знати, чи є в стосі непарне число.

```R
does_stack_include_odd_card(c(3, 2, 6, 4, 8));
# => TRUE
```

## 5. Отримайте першу непарну карту зі стосу

Еліз хоче знати значення першої карти, яка є непарною.  
Якщо в стосі немає непарної карти, поверніть `-1`.

```R
get_first_odd_card(c(4, 2, 8, 7, 9));
# => 7
```

## 6. Визначте позицію першої парної карти

Еліз хоче знати позицію першої карти, яка є парною.
Якщо в стосі немає парної карти, поверніть `-1`.

```R
get_first_even_card_position(c(5, 2, 3, 1));
# => 2
```
