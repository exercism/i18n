# Instructions

Ми завзяті спостерігачі за птахами, які ведуть облік того, скільки птахів відвідало наш сад за останні сім днів.

У нас шість завдань, і всі вони стосуються кількості птахів, що відвідали наш сад.

## 1. Перевірте, скільки птахів відвідало сад сьогодні

Реалізуйте функцію `today()`, яка повертає кількість птахів, що відвідали наш сад сьогодні. Кількість птахів упорядковано за днями: перший елемент містить кількість за найдавніший день, а останній - сьогоднішню кількість.

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
today(birds_per_day)
# => 1
```

## 2. Збільште сьогоднішню кількість на одиницю

Реалізуйте функцію `increment_todays_count()`, яка збільшує сьогоднішню кількість на одиницю:

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
increment_todays_count(birds_per_day)
# => c(2, 5, 0, 7, 4, 2)
```

## 3. Перевірте, чи був день без птахів

Реалізуйте функцію `has_day_without_birds()`, яка повертає `TRUE`, якщо був день, коли жоден птах не відвідав наш сад; інакше повертає `FALSE`:

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
has_day_without_birds(birds_per_day)
# => true
```

## 4. Обчисліть кількість птахів, що відвідали сад, за вказану кількість днів від початку тижня

Реалізуйте функцію `count_for_first_days()`, яка повертає кількість птахів, що відвідали наш сад від початку тижня, але обмежує підрахунок указаною кількістю днів від початку тижня.

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
count_for_first_days(birds_per_day, 4)
# => 14
```

## 5. Обчисліть кількість жвавих днів

Деякі дні жвавіші за інші. Жвавим вважається день, коли наш сад відвідали пʼять або більше птахів.
Реалізуйте функцію `busy_days()`, яка повертає кількість жвавих днів:

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
busy_days(birds_per_day)
# => 2
```

Нам цікаво, скільки всього птахів відвідало сад за цей тиждень.

## 7. Відсортуйте назви днів за жвавістю

Ми підозрюємо, що на відвідування птахів впливають закономірності руху на сусідніх дорогах, а отже вихідні відрізняються від буднів.

Відсортуйте скорочені назви днів у _спадному_ порядку за кількістю птахів, що відвідали сад.

```R
day_names <- c("Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun")
birds_per_day <- c(5, 2, 4, 6, 0, 9, 8)
busy_days_of_week(birds_per_day, day_names)
#> [1] "Sat" "Sun" "Thu" "Mon" "Wed" "Tue" "Fri"
```
