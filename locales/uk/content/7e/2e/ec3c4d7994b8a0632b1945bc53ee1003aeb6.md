# Вступ до циклів for-each

Цикл [for-each](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/for.html) дає змогу виконувати блок коду для кожного елемента колекції.
У деякій документації (наприклад, у документації Oracle) його називають розширеним циклом for.

Ось загальний синтаксис:

```java
for(declaration: collection) {
    body;
}
```

`declaration` оголошує змінну, яка зберігає значення, присвоєні з колекції.

`collection` - це масив або колекція, що містить значення, які буде присвоєно змінній циклу.

`body` містить інструкції, які буде виконано по одному разу для кожного значення в колекції.

Наприклад:

```java
char[] vowels = {'a', 'e', 'i', 'o', 'u'};

for(char vowel: vowels) {
    System.out.println(vowel);
}
```

Це виводить:

```text
a
e
i
o
u
```

Загалом цикл `for-each` кращий за цикл `for` з таких причин:

- Цикл `for-each` гарантовано перебирає _усі_ значення.
- Цикл `for-each` більш _декларативний_: код повідомляє, _що_ він робить, а не _як_ він це робить.
- Цикл `for-each` не дає помилитися, тоді як у циклі `for` легко припуститися помилки на одиницю (згадаймо про використання `<` замість `<=`).
- Цикл `for-each` працює з усіма типами колекцій, зокрема з тими, які не підтримують доступ до елементів за індексом (наприклад, `Set`).
