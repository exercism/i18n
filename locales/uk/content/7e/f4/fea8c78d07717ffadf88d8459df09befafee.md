# Інструкції

Уявімо себе матросом, який заново розставляє вантажні ящики на причалі. Кожне завдання складається з одного слова, тіло якого використовує лише слова перестановки, без арифметики.

## 1. Поміняти місцями два верхні ящики

Визначте слово `swap-crates`. Воно знімає зі стека два ящики й залишає їх у зворотному порядку.

```factor
1 2 swap-crates .s
! 2
! 1
```

## 2. Прибрати розсипаний ящик

Визначте слово `clear-spill`. Воно знімає зі стека три ящики й залишає два нижні, відкидаючи верхній.

```factor
1 2 3 clear-spill .s
! 1
! 2
```

## 3. Зберегти копію ящика, що лежить знизу

Визначте слово `peek-under`. Воно знімає зі стека два ящики й залишає їх, поклавши зверху копію нижнього ящика.

```factor
1 2 peek-under .s
! 1
! 2
! 1
```

## 4. Навести лад на палубі

Визначте слово `tidy-deck`. Воно знімає зі стека три ящики (у порядку `x y z`) і залишає `z z y`: відкидає нижній ящик, а потім кладе дві копії верхнього ящика під середній.

```factor
1 2 3 tidy-deck .s
! 3
! 3
! 2
```
