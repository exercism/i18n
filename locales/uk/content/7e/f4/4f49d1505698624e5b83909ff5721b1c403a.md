# Вступ

Ruby постачається зі стандартною бібліотекою (її часто скорочують до «stdlib»). Це набір класів для роботи з такими речами, як дати, json і мережа. Вона також надає корисні можливості, які роблять наш код зручнішим у роботі.

`OpenStruct` входить до стандартної бібліотеки й дає змогу легко створити обʼєкт із `Hash`. Замість того щоб звертатися до значень за ключами `Hash`, `OpenStruct` дозволяє нам використовувати методи, щоб читати й записувати значення.

Коли ми використовуємо класи зі стандартної бібліотеки або з будь-якої іншої бібліотеки, нам потрібно підключити цей клас за допомогою методу `require`.

```ruby
require 'ostruct'

attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

Ще одна додаткова перевага цього в тому, що в синтаксисі блоків ми можемо скористатися скороченням.
Коли блок викликає лише один метод, його можна замінити на `&:`, після якого йде назва методу.
Наприклад, ці два рядки рівнозначні:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```
