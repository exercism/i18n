# Тернарний оператор

Тернарна умовна конструкція дає коротший спосіб записати прості інструкції `if/else`.
Якщо конструкція `if/else` містить лише дві гілки, одну для випадку, коли умова правдива, і одну для випадку, коли вона неправдива, її можна переписати як тернарну умовну конструкцію.

Тернарні конструкції поєднують символи `?` і `:`, щоб розділити умову на частини:
```ruby
condition ? true_branch : false_branch
```

Код ліворуч від `?` задає умову, а код праворуч містить дві можливі гілки, розділені `:`.
Якщо умова _правдива_, виконується код _ліворуч_ від `:`.
Якщо умова _неправдива_, виконується код _праворуч_ від `:`.

Наприклад:

```ruby
if traffic_light == 'green'
  cross_the_road
else
  wait
end
```

можна переписати так:

```ruby
traffic_light == 'green' ? cross_the_road : wait
```
