# Вступ

## Масиви та вектори

C++ пропонує різні контейнери для зберігання елементів одного типу в певному порядку.
Для контейнерів фіксованого розміру є `std::array`, а `std::vector` уміє динамічно змінювати розмір.

### Створення

Коли ми оголошуємо масив або вектор, потрібно вказати тип елементів, які зберігатиме цей контейнер.
Масивам також потрібен розмір.
Погляньмо на ці приклади, щоб побачити ініціалізацію обох типів контейнерів:

```cpp
#include <array>
#include <string>

// std::array<element_type, size> variable_name {list of elements}
std::array<std::string, 3> indie_rock {"yeah", "yeah", "yeah"};
// indie_rock contains the elements "yeah" three times
```

Вектори зазвичай потребують більше місця, бо виділяють памʼять для подальшого зростання.
Розмір вказувати не потрібно:

```cpp
#include <vector>

// std::vector<element_type> variable_name {list of elements}
std::vector<int> countdown {3, 2, 1};
// countdown contains the elements 3, 2 and 1
```

> Примітка: точний механізм, що стоїть за концепцією шаблонів, знати ще не потрібно, їй присвячено окрему концепцію далі за деревом силабусу.

### Доступ до елементів

Вектори та масиви мають однакові функції для доступу до своїх елементів.
Можна скористатися функціями-членами `front` і `back`, щоб отримати перший і останній елементи контейнера.
Є також `at` й оператор `[]` для доступу до конкретних елементів.

```cpp
countdown[0];
// => 3
countdown.at(2);
// => 1
countdown[1] = 4;
// countdown now contains 3, 4 and 1
indie_rock.back() = "yeahs";
// indie_rock is now "yeah", "yeah", "yeahs"
```

> Примітка: якщо вибрати позицію поза діапазоном контейнера, `[]` може призвести до невизначеної поведінки.
> Функція `at` натомість викличе виняток, що в довгостроковій перспективі може полегшити нам життя.

### Модифікатори вектора

Оскільки `vector` не має фіксованого розміру, до нього можна додавати елементи й вилучати їх.
Для цього зазвичай використовують дві функції: `emplace_back` і `pop_back`.

```cpp
std::vector<std::string> witches {"Holly", "Alyssa", "Shannen"};
witches.pop_back();
// Shannen is no longer with the witches
witches.emplace_back("Rose");
// Rose has joined the team
```

### Місткість

Перевірити контейнер на порожнечу можна за допомогою функції-члена `empty`.
А якщо потрібно дізнатися кількість елементів, можна скористатися `size`.
