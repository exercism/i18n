# Тести

## Запуск тестів

Коли ми в каталозі вправи, поруч мають бути два підкаталоги:

* `src` містить рішення вправи
* `spec` містить тести для цієї вправи

Якщо ми в потрібному каталозі (тобто в тому, що містить `src` і `spec`), можна запустити тести для цієї вправи командою `crystal spec`:

```bash
$ pwd
/Users/johndoe/Code/exercism/crystal/hello-world

$ ls
GETTING_STARTED.md README.md          spec               src

$ crystal spec
```

Це запустить усі файли тестів із каталогу `spec`.

У кожному файлі тестів усі тести, крім першого, пропущені.

Коли тест починає проходити, можна зняти пропуск із наступного тесту, замінивши `pending` на `it`.

## Форматування в Crystal

Перед надсиланням рішення радимо виконати `crystal tool format` для рішення.

Відформатувати все в поточному каталозі можна так:

```bash
$ crystal tool format ./
```

Або вибірково відформатувати файли:

```bash
$ crystal tool format ./<path>/<to>/<file>
```

## Надсилання рішення

Надсилаючи рішення, обовʼязково надішліть вихідний файл із каталогу `src`:

```bash
$ exercism submit src/<exercise>.cr
```
