# Вступ

Common Lisp використовує стандартні арифметичні оператори для більшості операцій, але дещо відрізняється тим, що послуговується «префіксною нотацією» замість звичнішої «інфіксної».

Наочніше:

```lisp
;; Infix-notation (non-lisp languages)
1 + 2 + 3 + 4 + 5 ; => 15
;; Prefix-notation (lisp languages)
(+ 1 2 3 4 5)     ; => 15
```

Хоча префіксна нотація перетворює деякі операції, як-от `2 + 2`, на дещо незвичний запис `(+ 2 2)`, вона значно полегшує роботу одразу з кількома числами.

## Базова математика

У Common Lisp є всі типові функції: `+`, `-`, `*`, `/` для додавання, віднімання, множення й ділення.

Коли йдеться про ділення, може знадобитися дізнатися остачу від ділення. Для цього є функція `mod` (від modulo), яка приймає число і дільник як аргументи:

```lisp
(mod 4 2)  ; => 0
(mod 2 4)  ; => 2
(mod 10 3) ; => 1
```

## Порівняння чисел

І нарешті, може бути корисно порівнювати різні числа за допомогою функцій `=` (дорівнює), `/=` (не дорівнює) і `>=` (більше або дорівнює).
Коли ці порівняння істинні (як-от `(= 1 1)`), вони повертають `T`, а коли ні (як-от `(> 0 1)`), повертають `NIL`.
