## 1. Витягти координати

Реалізуйте функцію `get_coordinate()`, яка приймає пару `(treasure, coordinate)` зі списку Azara й повертає лише витягнуту координату на карті.


```python
>>> get_coordinate(('Scrimshawed Whale Tooth', '2A'))
2A
```

## 2. Відформатувати координати

Реалізуйте функцію `convert_coordinate()`, яка приймає координату у форматі «2A» й повертає кортеж у форматі `("2", "A")`.


```python
>>> convert_coordinate("2A")
("2", "A")
```

## 3. Зіставити координати

Реалізуйте функцію `compare_records()`, яка приймає пару `(treasure, coordinate)` та запис `(location, coordinate, quadrant)` і порівнює координати з кожного.
Поверніть **`True`**, якщо координати «збігаються», і **`False`**, якщо ні.
За потреби переформатуйте координати, щоб порівняння було точним.


```python
>>> compare_records(('Brass Spyglass', '4B'), ('Seaside Cottages', ('1', 'C'), 'blue'))
False

>>> compare_records(('Model Ship in Large Bottle', '8A'), ('Harbor Managers Office', ('8', 'A'), 'purple'))
True
```

## 4. Поєднати зіставлені записи

Реалізуйте функцію `create_record()`, яка приймає пару `(treasure, coordinate)` зі списку Azara та запис `(location, coordinate, quadrant)` зі списку Rui й повертає `(treasure, coordinate, location, coordinate, quadrant)`, **якщо координати збігаються**.
Якщо координати _не_ збігаються, поверніть рядок тексту (англ. string) **«not a match»**.
За потреби переформатуйте координату, щоб порівняння було точним.


```python
>>> create_record(('Brass Spyglass', '4B'), ('Abandoned Lighthouse', ('4', 'B'), 'Blue'))
('Brass Spyglass', '4B', 'Abandoned Lighthouse', ('4', 'B'), 'Blue')

>>> create_record(('Brass Spyglass', '4B'), ('Seaside Cottages', ('1', 'C'), 'blue'))
"not a match"
```
