# Детальніше

Булеве значення (англ. Boolean) показує, чи є умова `true` або `false`.
У Go тип `bool` може набувати лише одного з цих двох значень.

```go
isDoorLocked := true
hasKey := true
knowsCode := false
```

## Логічні оператори

Логічні оператори працюють з одним або двома булевими значеннями й повертають булевий результат.

| Оператор | Назва       | Поведінка                                       |
| -------- | ---- | ---------------------------------------------- |
| `!`      | заперечення | Повертає протилежне до одного булевого значення |
| `&&`     | логічне і   | Повертає `true`, лише коли обидві сторони `true` |
| `\|\|`   | логічне або | Повертає `true`, якщо хоч одна зі сторін `true` |

Використовуймо `!` (заперечення), коли потрібне протилежне до булевого значення:

```go
!isDoorLocked // false
```

Використовуймо `&&` (і), коли обидві умови мають бути `true`:

```go
canUnlockDoor := isDoorLocked && hasKey // true
```

Використовуймо `||` (або), коли принаймні одна умова має бути `true`:

```go
canOpenDoor := canUnlockDoor || knowsCode // true
```

Логічні оператори обчислюються в такому порядку: спочатку `!`, потім `&&`, потім `||`.
Використовуймо дужки, щоб групувати код і керувати тим, які операції виконуються першими:

```go
!true && false   // false because !true is evaluated first
!(true && false) // true because true && false is evaluated first
```
