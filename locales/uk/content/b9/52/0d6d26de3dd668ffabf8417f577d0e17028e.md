## Загальне

Не реалізуйте структуру `SimpleLinkedList` як обгортку навколо `Vec`. Натомість виділяйте вузли в купі.

Це можна реалізувати так:

```
pub struct SimpleLinkedList<T> {
    head: Option<Box<Node<T>>>,
}
```

Поле `head` указує на перший елемент (Node) цього звʼязаного списку.

Ця реалізація також вимагає структури `Node` з такими полями:

```
struct Node<T> {
    data: T,
    next: Option<Box<Node<T>>>,
}
```

`data` містить збережені дані, а `next` указує на наступний вузол (якщо він є) або None.

## Чому `Option<Box<Node<T>>>`, а не просто `Option<Node<T>>`?

Спробуйте самостійно. Отримаємо таку помилку.

```
| struct Node<T>
| ^^^^^^^^^^^^^^ recursive type has infinite size
...
|     next: Option<Node<T>>,
|     --------------------- recursive without indirection
```

Проблема в тому, що під час компіляції розмір next має бути відомий.
Оскільки `next` є рекурсивним («вузол має вузол, який має вузол...»), компілятор не знає, скільки памʼяті потрібно виділити.
На противагу цьому, [Box](https://doc.rust-lang.org/std/boxed/) - це вказівник на купу з визначеним розміром.
