# Вступ

## Тривалості та періоди

Класи, як-от `LocalDate` і `LocalDateTime`, описують _точку_ в часі.
Пакет `java.time` також містить два класи, які описують _проміжок_ часу:

- `java.time.Period` - це проміжок часу в роках, місяцях і днях, наприклад «2 місяці та 5 днів».
- `java.time.Duration` - це проміжок часу в годинах, хвилинах, секундах, мілісекундах і наносекундах, наприклад «1 година та 30 хвилин».

`Period` працює за календарем, тому його використовують із датами та значеннями дати-часу.
`Duration` вимірює точний час, тому його використовують із часом і датою-часом, але не з датами.

```exercism/note
Як і інші класи `java.time`, `Period` і `Duration` є незмінними.
Методи, які на вигляд змінюють їх, натомість повертають _новий_ екземпляр.
```

### `Period`

`Period` створюють одним із його статичних фабричних методів:

```java
Period.ofDays(10);
// => P10D

Period.ofMonths(3);
// => P3M

Period.of(1, 2, 15);
// => P1Y2M15D
```

Результат `toString()` використовує нотацію [ISO-8601][iso-8601-durations]: `P` (від «period»), за яким іде кількість років (`Y`), місяців (`M`) і днів (`D`).

Період можна додати до дати або відняти від неї:

```java
LocalDate date = LocalDate.of(2024, 3, 10);

date.plus(Period.ofMonths(2));
// => 2024-05-10

date.minus(Period.ofDays(10));
// => 2024-02-29
```

Оскільки місяці мають різну довжину, додавання місяців може привести до дня, якого не існує.
У такому разі результат зсувається назад, на останній дійсний день місяця:

```java
LocalDate.of(2025, 1, 31).plus(Period.ofMonths(1));
// => 2025-02-28
```

`Period.between()` повертає період від однієї дати (включно) до іншої (не включно):

```java
LocalDate start = LocalDate.of(2023, 3, 10);
LocalDate end = LocalDate.of(2024, 5, 25);

Period period = Period.between(start, end);
// => P1Y2M15D

period.getYears();
// => 1
period.getMonths();
// => 2
period.getDays();
// => 15
```

### Лічба одиниць за допомогою `ChronoUnit`

`Period` зберігає роки, місяці та дні окремо.
Тому `getDays()` повертає лише _частину_ періоду в днях, а не загальну кількість днів.
Щоб порахувати загальну кількість однієї одиниці між двома датами, скористаймося методом `between()` класу [`java.time.temporal.ChronoUnit`][chronounit-docs]:

```java
LocalDate start = LocalDate.of(2024, 1, 15);
LocalDate end = LocalDate.of(2024, 3, 20);

Period.between(start, end);
// => P2M5D

Period.between(start, end).getDays();
// => 5

ChronoUnit.DAYS.between(start, end);
// => 65
```

Результат буде відʼємним, якщо друга дата передує першій:

```java
ChronoUnit.DAYS.between(end, start);
// => -65
```

### `Duration`

`Duration` також створюють за допомогою статичних фабричних методів:

```java
Duration.ofMinutes(90);
// => PT1H30M

Duration.ofHours(2).plusMinutes(15);
// => PT2H15M
```

У нотації ISO-8601 символ `T` відокремлює частину дати від частини часу, тому тривалості записують як `PT...`.

Тривалість можна додати до дати-часу або відняти від неї:

```java
LocalDateTime start = LocalDateTime.of(2024, 3, 10, 22, 30);

start.plus(Duration.ofMinutes(90));
// => 2024-03-11T00:00
```

`Duration.between()` повертає точний проміжок часу між двома значеннями дати-часу:

```java
LocalDateTime checkIn = LocalDateTime.of(2024, 3, 10, 18, 5);
LocalDateTime checkOut = LocalDateTime.of(2024, 3, 10, 19, 40);

Duration.between(checkIn, checkOut);
// => PT1H35M
```

Тривалість можна перевести в одну одиницю методами, як-от `toHours()`, `toMinutes()` і `toSeconds()`.
Вони повертають _загальну_ кількість у цій одиниці, округлену вниз:

```java
Duration duration = Duration.ofMinutes(95);

duration.toHours();
// => 1
duration.toMinutes();
// => 95
```

Щоб розкласти тривалість на частини, як на годиннику, скористаймося методами `toXxxPart()`:

```java
Duration duration = Duration.ofMinutes(95);

duration.toHoursPart();
// => 1
duration.toMinutesPart();
// => 35
```
