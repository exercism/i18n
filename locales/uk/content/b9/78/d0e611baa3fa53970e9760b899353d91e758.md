# Рядки

`STR` зберігає текст. Рядок тексту (англ. string) записують між подвійними лапками.

```sather
   composer : STR is
      return "Sibelius";
   end;
```

`STR` ніколи не змінюється після створення. Усе подальше повертає *новий*
рядок тексту, а не змінює той, про який його запитали.

## Зʼєднання

```sather
"Jean" + " " + "Sibelius"      -- "Jean Sibelius"
```

`+` також приєднує число до рядка тексту, і саме так число потрапляє
в речення:

```sather
"Opus " + 27           -- "Opus 27"
```

## Довжина

```sather
"Sibelius".size        -- 8
"".size                -- 0
```

`.size` рахує символи, а результатом є `INT`.

## Частини

| Виклик | Відповідь |
| --- | --- |
| `"Sibelius".head(3)` | `"Sib"` |
| `"Sibelius".tail(4)` | `"lius"` |

Якщо попросити більше, ніж є, повертається те, що є, а не помилка.

## Порівняння

`=` перевіряє, чи два рядки тексту однакові, а `/=` - чи вони
різняться.

```sather
"forte" = "forte"      -- true
"forte" = "Forte"      -- false
```

Регістр має значення. `.upper` і `.lower` повертають копію в одному
регістрі, і це звичний спосіб порівнювати, не зважаючи на регістр:

```sather
"Forte".lower                    -- "forte"
"Forte".lower = "forte".lower    -- true
```

## Кілька слів про розмір

`STR` є послідовністю байтів, і `.size` рахує байти. Для англійського
тексту це те саме, що рахувати літери. Для тексту з діакритичними
знаками чи іншими абетками це не так, бо кожна з тих літер займає
більше ніж один байт.
