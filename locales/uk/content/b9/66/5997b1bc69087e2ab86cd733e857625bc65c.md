# Тести

## Налаштування

Пройдіть [інструкції з налаштування WebAssembly][docs-exercism-wasm], щоб встановити потрібні залежності.

## Вимоги

Встановіть залежності вправи:

```shell
# Using npm
npm install

# Alternatively using yarn
yarn
```

## Як пройти набір тестів

Усі вправи містять набір тестів, який допоможе перевірити рішення перед поданням.
Ці тести можна запустити, відкривши командний рядок у каталозі вправи, а потім виконавши:

```bash
# Using npm
npm test

# Alternatively using yarn
yarn test
```

У деяких наборах тестів усі тести, крім першого, пропущено.

Коли тест почне проходити, можна увімкнути наступний, змінивши `xtest` на `test`.

## Написання власних тестів

Якщо потрібно написати додаткові власні тести, створіть новий файл `custom.spec.js` та надішліть його разом із рішенням і новим файлом:

```shell
exercism submit numbers.wat custom.spec.js
```

[docs-exercism-wasm]: https://exercism.org/docs/tracks/wasm/installation
