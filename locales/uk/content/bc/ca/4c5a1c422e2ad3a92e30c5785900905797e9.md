# Дозволи на репозиторій для супроводжувачів

Супроводжувач треку — це учасник команди треку на GitHub.
Стати членом команди треку можна _лише за запрошенням_.

```exercism/note
Щоб стати супроводжувачем треку, відкрийте тему на [форумі](https://forum.exercism.org/c/exercism/building-exercism/125).
```

## Категорія супроводження

Існує пʼять категорій супроводження:

1. `wip-track`
2. `unmaintained`
3. `maintained-solitary`
4. `maintained-autonomous`
5. `maintained`

Категорія супроводження треку визначається трьома чинниками:

1. Чи активний трек (тобто чи можуть студенти приєднатися до треку на сайті)
2. Кількість супроводжувачів треку
3. Кількість супроводжувачів треку, які також входять до команди GitHub `cross-track-maintainers`

Щоб визначити категорію супроводження, знайдіть у цій таблиці першу категорію, що відповідає треку:

| Категорія             | Активний? | Кількість супроводжувачів | Кількість міжтрекових супроводжувачів |
| --------------------- | --------- | ------------------------- | ------------------------------------- |
| wip-track             | Ні        | Будь-яка                  | Будь-яка                              |
| unmaintained          | Так       | 0                         | 0                                     |
| maintained-autonomous | Так       | > 0                       | = Кількість супроводжувачів           |
| maintained-solitary   | Так       | 1                         | 0                                     |
| maintained            | Так       | > 1                       | < Кількість супроводжувачів           |

## Дозволи на репозиторій

Категорія супроводження використовується для встановлення дозволів для репозиторіїв треку в GitHub.

| Категорія             | Потрібен PR | Потрібне схвалення PR | Перевірки команди міжтрекових супроводжувачів |
| --------------------- | ----------- | --------------------- | --------------------------------------------- |
| wip-track             | Ні          | Ні                    | Ні                                            |
| unmaintained          | Так         | Так                   | Так                                           |
| maintained-solitary   | Так         | Так                   | Так                                           |
| maintained-autonomous | Так         | Ні                    | Ні                                            |
| maintained            | Так         | Ні                    | Ні                                            |

```exercism/caution
Лише категорія `wip-track` дозволяє супроводжувачам надсилати зміни в `main`.
```

```exercism/caution
Репозиторії інструментарію _завжди_ потребують схвалення PR, оскільки їхній вміст захищено за допомогою [файлу CODEOWNERS](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-code-owners).
```
