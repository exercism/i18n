# Про поняття

У Swift можна визначати [функції всередині інших функцій][nested-functions].
Такі функції називають **вкладеними функціями**.

Вкладені функції часто використовують як приватні допоміжні функції, які виконують конкретні завдання для функції, що їх містить, і не засмічують зовнішню область видимості:

```swift
func makeNumber(_ number: Int) -> Int {
    func double(_ x: Int) -> Int {
        x * 2
    }

    func increment(_ x: Int) -> Int {
        x + 1
    }

    return number.isMultiple(of: 2) ? increment(double(number)) : double(number)
}

print(makeNumber(3)) // Prints 6
print(makeNumber(4)) // Prints 9
```

Вкладені функції поводяться як звичайні функції, але їхня видимість обмежена тілом функції, що їх містить.

[nested-functions]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/functions/#Nested-Functions
