# Вступ

Вираз switch може зіставити значення з одним випадком із набору шаблонів і повернути повʼязане значення або виконати повʼязану дію. Цей звʼязок позначається символом `=>`. Крім того, кожен шаблон може мати необовʼязкову захисну умову, яку вводить ключове слово `when`. Щоб обралася ця «гілка» switch, вираз захисної умови має обчислюватися до правди. Випадки (також відомі як _гілки switch_) обчислюються в порядку запису, і щойно знайдено збіг, процес переривається, а повʼязане значення повертається.

```csharp
double xx = 42d;

string interesting = xx switch
{
    0 => "I suppose zero is interesting",
    3.14 when DateTime.Now.Day == 14 && DateTime.Now.Month == 3 => "Mmm pie!",
    3.14 => "π",
    42 => "a bit of a cliché",
    1729 => "only if you are a pure mathematician",
    _ => "not interesting"
};

// => interesting == "a bit of a cliché"
```
