# Докладніше

В Elixir є два різні види чисел: цілі числа та числа з плаваючою комою.

Цілі числа не мають дробової частини.

```elixir
integer = 3
# => 3
```

Кілька корисних функцій для роботи з цілими числами можна знайти в модулі [`Integer`][integer].

```elixir
Integer.digits(123)
# => [1, 2, 3]
```

Великі цілі числа (а також числа з плаваючою комою) зазвичай записують, розділяючи кожні три цифри на групи за допомогою підкреслення.

```elixir
1_000_000
# => 1000000
```

Максимальний розмір чисел в Elixir обмежений лише обсягом доступної в системі памʼяті, адже Elixir використовує [арифметику довільної точності][arbitrary-precision-arithmetic].

Elixir також підтримує скорочені позначення для запису [двійкових, вісімкових і шістнадцяткових цілих чисел][integers-in-other-bases].

```elixir
0b0100
# => 4

0o555
# => 365

0xFF
# => 255
```

## Порівняння

Цілі числа та числа з плаваючою комою вважаються рівними ([`==`][kernel-equal]), якщо вони мають однакове значення. Однак, належачи до різних типів, вони ніколи не є строго рівними ([`===`][kernel-strictly-equal]).

```elixir
1 == 1.0
# => true

1 === 1.0
# => false
```
