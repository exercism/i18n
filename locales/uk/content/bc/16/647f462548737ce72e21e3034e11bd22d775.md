# Вступ

Кортеж - це _незмінне_ групування неназваних, але впорядкованих значень.
Кортежі можуть містити значення будь-якого типу (або одразу кількох типів), зокрема й інші кортежі.

Кортежі записують як значення, розділені комами, між символами `(` і `)`: `(<element_1>, ... , <element_n>)`.

```fsharp
("one", 2) // Tuple pair (2 values)
("one", 2, true) // Tuple triplet (3 values)
```

Порівнювати можна лише кортежі однакової довжини з однаковими типами (у тому самому порядку).
Кортежі мають структурну рівність: вони рівні _лише_ тоді, коли рівні всі їхні значення.

```fsharp
(1, 2) = (1, 2) // Same length, same types, same values, same order
// => true

(1, 2) = (2, 1) // Same length, same types, same values, different order
// => false

(1, 2) = (1, "2") // Same length, different types
// compiler error

(1, 2) = (1, 2, 3) // Different length
// compiler error
```

Існує три способи дістати значення з кортежу:

- Функції `fst` і `snd`
- Деконструкція кортежу
- Зіставлення зі зразком

```fsharp
let person = ("Jordan", 170)

// Option 1: fst/snd
let name1 = fst person
let length2 = snd person

// Option 2: deconstruction
let (name2, length2) = person
// => name2 = "Jordan"
// => length2 = 170

// Option 3: pattern matching
match person with
| name3, length3 -> printf "%s: %d" name3 length3
```
