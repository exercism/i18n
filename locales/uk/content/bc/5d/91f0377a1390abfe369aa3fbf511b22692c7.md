# Рядки тексту

**Рядок тексту** (англ. string) - це фрагмент тексту. У Sather для нього є тип `STR`, а рядок тексту записують між подвійними лапками.

```sather
   composer : STR is
      return "Sibelius";
   end;
```

## Зʼєднання рядків тексту

`+` зʼєднує два рядки тексту впритул.

```sather
"Jean" + " " + "Sibelius"      -- "Jean Sibelius"
```

Між ними нічого не ставлять, тому пробіл доводиться додавати окремо. Якщо його пропустити, вийде `"JeanSibelius"`.

## Яка довжина?

`.size` показує, скільки символів містить рядок тексту. Це ціле число, тому воно має тип `INT`.

```sather
"Sibelius".size      -- 8
```

Після `.size` немає дужок, так само як у підпрограми, що не приймає аргументів.

## Витягування частини

`.head(n)` повертає перші `n` символів. `.tail(n)` повертає останні `n` символів.

```sather
"Sibelius".head(3)   -- "Sib"
"Sibelius".tail(4)   -- "lius"
```

`head` рахує від початку, `tail` - від кінця. Обидва не змінюють початковий рядок тексту, а повертають новий рядок тексту.
