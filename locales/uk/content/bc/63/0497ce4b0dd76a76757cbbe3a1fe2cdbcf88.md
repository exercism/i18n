# Доповнення до інструкцій

## Реалізація

Наш список також повинен реалізувати такий інтерфейс:

- `delete` (видаляє перше входження вказаного значення)
- `count` (рахує кількість елементів у списку)

**УВАГА**: _Не_ використовуйте бібліотеку для реалізації цієї вправи. _Не_ використовуйте масив як основу для реалізації цієї вправи.
