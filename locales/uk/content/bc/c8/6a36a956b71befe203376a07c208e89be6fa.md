# Вступ

Unison представляє значення правди й неправди за допомогою типу `Boolean`. Існує лише два значення: `true` і `false`.

```unison
trueVariable = true
falseVariable = false
```

Ми можемо обчислювати булеві вирази (англ. Boolean) за допомогою операторів `&&` (логічне і), `||` (логічне або) та `not`, тобто заперечення (логічне).

```unison
trueVariable = true && true
falseVariable = true && false

trueVariable = false || true
falseVariable = false || false

trueVariable = not false
falseVariable = not true
```

Булеві вирази в Unison підтримують скорочене обчислення: якщо перший аргумент виразу `&&` (і) дорівнює `false`, тоді немає сенсу продовжувати обчислювати другий аргумент.
Так само, якщо перший аргумент виразу `||` (або) дорівнює `true`, вираз одразу поверне `true`.

```unison
> false && (base.bug "oh no")
  ⧩
  false
```

```unison
> true || (base.bug "oh no")
  ⧩
  true
```
