# Вступ

## chars

Примітивний тип `char` у Java представляє один символ у 16 бітах.
Кілька `char` можуть утворювати рядок тексту (англ. string), як-от `"word"`, або ж `char` можна обробляти окремо.
Літерал `char` береться в одинарні лапки (наприклад, `'A'`).

```java
char lowerA = 'a';
char upperB = 'B';
```

## Як отримати `char`-и з `String`

Метод `String.toCharArray` повертає `char`-и рядка тексту як масив.
Як уже згадувалося в розділі про масиви, щоб перебрати масив, можна використати цикл `for`.

```java
String text = "Hello";
char[] asArray = text.toCharArray();

for (char ch: asArray) {
    System.out.println(ch);
}

// Outputs:
// H
// e
// l
// l
// o
```

## Клас Character

Існує багато вбудованих методів бібліотеки, якими можна перевіряти та обробляти `char`-и.
Їх можна знайти як статичні методи класу `java.lang.Character`.
Ось кілька прикладів:

```java
Character.isWhitespace(' ');    // true
Character.isWhitespace('#');    // false

Character.isLetter('a');        // true
Character.isLetter('3');        // false

Character.isDigit('6');         // true
Character.isDigit('?');         // false
```

## Додавання `char` до `String`

Оператор `+` можна використати, щоб додати `char` до рядка тексту.

```java
'a' + " banana"     // => "a banana"
"banana " + 'a'     // => "banana a"
```

~~~~exercism/caution
Будьмо уважні: _не_ використовуймо `+`, щоб зʼєднати два `char`-и в рядок тексту!
Додавання двох `char`-ів у такий спосіб дає `int`, а _не_ `String`!
Наприклад:

```java
'b' + 'c';
// => 197 (not the String "bc")
```

Це тому, що Java підвищує `char` до `int` (див. [4.2 Primitive Types and Values ][jls-primitives] у [Java Language Specification][jls-main]).

[jls-main]: https://docs.oracle.com/javase/specs/jls/se21/html/
[jls-primitives]: https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.2
~~~~

Однак, коли треба додати багато символів, ефективніше використати `StringBuilder`:

```java
StringBuilder builder = new StringBuilder();
builder.append('a');
builder.append('b');
builder.append('c');

String builtString = builder.toString();
// => abc
```
