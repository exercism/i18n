# Доповнення до інструкцій

## Налаштування

Пройдімо інструкції з налаштування TypeScript, щоб установити потрібні залежності:

[https://exercism.org/docs/tracks/typescript/installation](https://exercism.org/docs/tracks/typescript/installation)

## Вимоги

Установіть залежності завдання:

```bash
$ yarn install
```

## Як зробити, щоб набір тестів проходив

Запустіть тести командою:

```bash
$ yarn test
```

У багатьох наборах тестів усі тести, крім першого, пропущено.

Коли тест почне проходити, можна зняти пропуск з наступного, змінивши `xit` на `it`.

## Туторіал

Цей розділ - покроковий посібник із розвʼязання цієї вправи.

Ця вправа містить два файли:

- hello-world.ts
- hello-world.test.ts

У першому файлі ми будемо писати код.
У другому визначено тести.

Тести будуть перевіряти, чи наш код робить те, що потрібно.
Не потрібно вміти писати набір тестів з нуля,
але корисно розуміти, який вигляд має тест і що
він робить.

Відкрийте файл із тестами, hello-world.test.ts.
Усередині є один тест:

```typescript
it('says hello world', () => {
  expect(hello()).toEqual('Hello, World!')
})
```

Запустіть тест такою командою в командному рядку:

```bash
$ yarn test
```

Тест не проходить, і це логічно, адже ми ще не написали жодного коду.

Помилка має такий вигляд:

```
    × says hello world (5ms)

  ● Hello World › says hello world

    expect(received).toEqual(expected) // deep equality

    Expected: "Hello, World!"
    Received: "Goodbye, Mars!"

      4 |
      5 |   it('says hello world', () => {
    > 6 |     expect(hello()).toEqual('Hello, World!')
        |                     ^
      7 |   })
      8 |
      9 | })

      at Object.it (hello-world.test.ts:6:32)
```

А ось ті рядки коду з імовірними дефектами у файлі `hello-world.test.ts`:

6-й рядок:

```typescript
    expect(hello()).toEqual('Hello, World!')
                    ^
```

Отже, проблема у виклику функції `hello()`.
Ми бачимо, що тест очікує на вихідні дані `'Hello, World!'`, а натомість отримує `"Goodbye, Mars!"`.

Тож тепер перевірмо цю функцію у файлі `hello-worlds.ts`:

```typescript
export function hello(): string {
  return 'Goodbye, Mars!'
}
```

Тепер бачимо, що функція повертає неправильний рядок тексту (англ. string), і саме через це тест не проходить. Виправмо це, змінивши повернене значення:

```typescript
export function hello(): string {
  return 'Hello, World!'
}
```

Запустіть тест ще раз:

```bash
 PASS  ./hello-world.test.ts
  Hello World
    √ says hello world (4ms)
```

І тест проходить!
