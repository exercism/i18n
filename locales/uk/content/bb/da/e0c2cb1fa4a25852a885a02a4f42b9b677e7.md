# Інструкції

Ваше завдання - додати кількість квіток до порожніх клітинок завершеного саду «Квіткове поле».
Сам сад - це прямокутна дошка, складена з клітинок, кожна з яких або порожня (`' '`), або містить квітку (`'*'`).

Для кожної порожньої клітинки порахуйте кількість квіток, суміжних із нею (по горизонталі, по вертикалі, по діагоналі).
Якщо порожня клітинка не має суміжних квіток, залиште її порожньою.
Інакше замініть її на кількість суміжних квіток.

Наприклад, ми можемо отримати дошку 5 x 4, що має такий вигляд (порожні місця тут позначено символом '·' для показу на екрані):

```text
·*·*·
··*··
··*··
·····
```

Який наш код має перетворити на такий:

```text
1*3*1
13*31
·2*2·
·111·
```
