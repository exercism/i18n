# Докладніше

Типи C# можна визначати в межах області видимості класу або struct. Зовнішній тип виконує роль чогось на кшталт простору імен. Доступ до такого типу відбувається через зовнішній тип із крапковим синтаксисом.

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

## Рівні доступу

До вкладених типів можна застосовувати рівні доступу. Наприклад, якщо клас оголошено як `private`, його не видно за межами області видимості зовнішнього типу, і, звісно, його екземпляри також не видно й не можна використати поза цією областю.

Приватні члени зовнішнього класу перебувають в області видимості всіх членів вкладеного класу, але для членів зовнішнього класу в області видимості перебувають лише не приватні члени вкладеного класу. Щоб отримати доступ до членів зовнішнього класу, вкладеному класу потрібно передати екземпляр зовнішнього класу.

Це видно в наступному прикладі:

```csharp
class Outer
{
    public class InnerImpl
    {
        private Outer outer;

        public int Interesting = 42;

        public InnerImpl(Outer outer, int interesting)
        {
            this.outer = outer;
            Interesting = interesting;
        }

    }

    public InnerImpl Inner;
    public Outer()
    {
        Inner = new InnerImpl(this, 42);
    }
}

var outer = new Outer();
outer.Inner.Interesting
// => 42
var inner = new Outer.InnerImpl(outer, 1729);
outer.Inner.Interesting
// => 1729
```

## Як запобігти незалежному інстанціюванню

Існує прийом, який забороняє створювати екземпляри типу за межами зовнішнього типу. Ми відкриваємо публічний інтерфейс, але тримаємо клас, що його реалізує, приватним.

```csharp
class Outer
{
    public interface IInner
    {
        void DoSomething();
    }

    private class InnerImpl : IInner
    {
        private Outer outer;
        public InnerImpl(Outer outer)
        {
            this.outer = outer;
        }
        public void DoSomething()
        {
            outer.DoSomethingElse();
        }
    }

    public IInner Inner;

    public Outer()
    {
        Inner = new InnerImpl(this);
    }
    private void DoSomethingElse()
    {
    }
}

var outer = new Outer();
outer.Inner.DoSomething();

// NOT var inner = new Outer.Inner(outer);
```

## Примітка для розробників Java

Вкладені класи C# поєднують у собі риси статичних вкладених класів і внутрішніх класів Java. У C# приватні члени зовнішнього класу перебувають в області видимості для членів вкладеного класу, але спеціального синтаксису для їх інстанціювання й привʼязування до екземпляра зовнішнього класу немає. Доведеться скористатися якимось варіантом прийому, показаного в прикладах вище.

У C# справді є статичні вкладені класи, але це просто вкладені класи зі статичною поведінкою.
