# Вказівки

Ця вправа присвячена розбору файлів журналу.

Після нещодавньої перевірки безпеки постало завдання навести лад в архівних файлах журналів організації.

Усі рядки тексту (англ. string), що передаються методам, гарантовано не є null і не мають пробілів на початку та в кінці.

## 1. Визначити пошкоджені рядки журналу

Потрібно мати хоч якесь уявлення про те, скільки рядків журналу в архіві не відповідають поточним стандартам. Є проста перевірка, яка показує, чи є рядок журналу припустимим. Щоб вважатися припустимим, рядок має починатися з одного з таких рядків:

- [TRC]
- [DBG]
- [INF]
- [WRN]
- [ERR]
- [FTL]

Реалізуйте метод `LogParser.IsValidLine()`, щоб він повертав `false`, якщо рядок неприпустимий, а інакше `true`.

```csharp
var lp = new LogParser();
lp.IsValidLine("[ERR] A good error here");
// => true
lp.IsValidLine("Any old [ERR] text");
// => false
lp.IsValidLine("[BOB] Any old text");
// => false
```

## 2. Розділити рядок журналу

До організації приєдналася нова команда, і виявилося, що в її файлах журналів використовується дивний роздільник для «полів». Замість чогось розумного, як-от двокрапка ":", вони використовують рядок на кшталт "<--->" або "<=>" (бо так красивіше), а насправді будь-який рядок, у якого перший символ "<", останній символ ">", а між ними будь-яка комбінація таких символів: "^", "\*", "=" та "-".

Реалізуйте метод `LogParser.SplitLogLine()`, який приймає рядок і повертає масив рядків, кожен з яких містить одне поле.

```csharp
var lp = new LogParser();
lp.SplitLogLine("Section 1<===>Section 2<^-^>Section 3");
// => {"Section 1", "Section 2", "Section 3"}
```

## 3. Порахувати кількість рядків із паролем у лапках

Команді потрібно знати про паролі, що трапляються в тексті в лапках, щоб їх можна було перевірити вручну.

Реалізуйте метод `LogParser.CountQuotedPasswords()`, щоб отримати уявлення про ймовірний обсяг ручної роботи.

Визначте рядки журналу, у яких літеральний рядок "password", у будь-якій комбінації великих і малих літер, оточений лапками.
Слід враховувати можливість додаткового вмісту в лапках до і після "password".

Рядки, передані методу, можуть бути припустимими, як визначено в завданні 1, а можуть і не бути. Ми обробляємо їх однаково, незалежно від того, припустимі вони чи ні.

```csharp
string lines =
    "[INF] passWord " + Environment.NewLine + // contains 'password' but not surrounded by quotation marks
    "\"passWord\"" + Environment.NewLine + // count this one
    "[INF] User saw error message \"Unexpected Error\" on page load." + Environment.NewLine + //does not contain 'password'
    "[INF] \"The secret password was added by the user\""; // count this one

var lp = new LogParser();
lp.CountQuotedPasswords(lines);
// => 2
```

## 4. Вилучити артефакти з журналу

Виявилося, що деяка попередня обробка журналів розкидала по них текст "end-of-line" із номером рядка (без пробілу між ними).

Реалізуйте метод `LogParser.RemoveEndOfLineText()`, який приймає рядок, вилучає текст end-of-line і повертає «чистий» рядок.

Рядки, що не містять тексту end-of-line, повертаються без змін.

Просто вилучіть текст end-of-line. Не намагайтеся коригувати пробіли.

```csharp
var lp = new LogParser();
lp.RemoveEndOfLineText("[INF] end-of-line23033 Network Failure end-of-line27");
// => "[INF]  Network Failure "
```

## 5. Скласти список рядків із надзвичайно слабкими паролями, щоб покарати винних

Перш ніж вилучити паролі з файлу, нам потрібно скласти список усіх випадків, коли паролі починаються з тексту "password".

Реалізуйте метод `LogParser.ListLinesWithPasswords()`, який виводить неприйнятний пароль, а потім повний рядок.

Рядки з паролями в лапках уже вилучено, і ми обробляємо рядки незалежно від того, чи припустимі вони (згідно із завданням 1).

Рядки, що містять неприйнятний пароль, повертаються з префіксом "<password>: ".

Рядки, що не містять неприйнятного пароля, повертаються з префіксом "--------: ".

```csharp
var lp = new LogParser();
lp.ListLinesWithPasswords(new string[] {"my passwordsecret is great"});
// => "passwordsecret: my passwordsecret is great"
lp.ListLinesWithPasswords(new string[] {"my password secret"});
// => {"--------: my password secret"}

```
