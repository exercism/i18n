# Інструкції

Наша команда дизайнерів частково переходить від CSS-трансформацій до Factor у роботі над макетом. Щоб решта команди була задоволена, ми створимо невеликі багаторазові перетворення у вигляді quotation, які приймають двовимірну точку й повертають двовимірну точку.

Точка - це масив із двох елементів `{ x y }`.

## 1. Перемістити координати

Визначте `translate-2d`, щоб воно брало зі стека два значення `dx` і `dy` та повертало quotation, що переміщує точку на `(dx, dy)`.

```factor
{ 4 8 } 2 0 translate-2d call( p -- p' ) .
! => { 6 8 }
```

## 2. Масштабувати координати

Визначте `scale-2d` так само: воно повертає quotation, що масштабує точку на `(sx, sy)`.

```factor
{ 6 -3 } 2 2 scale-2d call( p -- p' ) .
! => { 12 -6 }
```

## 3. Скомпонувати два перетворення

Визначте `compose-transformations`, щоб воно брало два quotation перетворень `f` і `g` та повертало один quotation, який застосовує спочатку `f`, а потім `g`.

```factor
{ 0 1 } 2 0 translate-2d 2 2 scale-2d compose-transformations
call( p -- p' ) .
! => { 4 2 }
```

## 4. Застосувати перетворення

Визначте `apply-transformation`, щоб воно брало зі стека точку і quotation перетворення та повертало перетворену точку.

```factor
{ 4 8 } 2 0 translate-2d apply-transformation .
! => { 6 8 }
```

## 5. Перетворити багато точок за раз

Визначте `transform-points`, щоб воно брало масив точок і quotation перетворення та повертало масив перетворених точок.

```factor
{ { 0 0 } { 1 1 } { 2 2 } } 1 0 translate-2d transform-points .
! => { { 1 0 } { 2 1 } { 3 2 } }
```
