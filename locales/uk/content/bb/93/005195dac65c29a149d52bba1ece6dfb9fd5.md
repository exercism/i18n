# Класи зі станом

Досі кожен клас був просто набором підпрограм. Кожна з них приймала аргументи,
обчислювала відповідь і забувала все.

Натомість клас може **запамʼятовувати**. Табло просто мусить це вміти: рахунок
тепер залежить від кожного гола з початку гри.

## Атрибути

`attr` дає класу те, що можна запамʼятати.

```sather
class SCOREBOARD is

   attr home_score : INT;
   attr away_score : INT;

end; -- class SCOREBOARD
```

Кожен `attr` стає підпрограмою, яка читає значення, і ще однією, яка його
змінює:

```sather
   board.home_score            -- read it
   board.home_score := 4;      -- change it
```

Атрибути одного типу можуть мати спільне оголошення, як і аргументи:

```sather
   attr home_score, away_score : INT;
```

## Обʼєкти

Клас з атрибутами - це схема для створення **обʼєктів**. Кожен обʼєкт має
власні копії атрибутів, тож два табла ведуть два різні рахунки.

`new` створює обʼєкт. Його викликають усередині підпрограми `create`, яка потім
заповнює обʼєкт і повертає його назад:

```sather
   create(home, away : STR) : SAME is
      board ::= new;
      board.home_team := home;
      board.away_team := away;
      return board;
   end;
```

`SAME` означає «цей клас». Якби ми написали там `SCOREBOARD`, це означало б те
саме, але `SAME` і далі працюватиме, якщо клас перейменувати.

## Як створити обʼєкт

`#` викликає `create`:

```sather
   board ::= #SCOREBOARD("Vixens", "Magpies");
```

`#` ми використовуємо вже з `rehearsal-script`; `#FSTR` працює точно так само.

## Підпрограми, які змінюють обʼєкт

Усередині класу атрибут використовують за назвою, без обʼєкта перед нею. Він
означає той обʼєкт, на якому викликали підпрограму.

```sather
   home_goal is
      home_score := home_score + 1;
   end;
```

`home_goal` не оголошує типу поверненого значення, бо нічого не повертає:
натомість він змінює обʼєкт. Викликаймо його як інструкцію:

```sather
   board.home_goal;
```

## Атрибути починаються порожніми

Атрибут, який ніхто не задавав, містить нуль для `INT`, `false` для `BOOL`,
а для рядка тексту (англ. string) чи обʼєкта — void. Тож нове табло одразу
показує 0:0, хоча ніхто цього не задавав.
