# Вступ

## Масиви

`List` у Elm є незмінною колекцією, що містить нуль або більше значень одного типу.

Масиви можна визначити так:

```elm
empty = []
singleValue = [ 5 ]
threeValues = [ "a", "b", "c" ]
```

Найпоширеніший спосіб додати елемент до масиву полягає у використанні оператора `::` (cons):

```elm
twoToFour = [ 2, 3, 4 ]
oneToFour = 1 :: twoToFour --> [ 1, 2, 3, 4 ]
```

Масивами керують за допомогою функцій та операторів, визначених у [`List` модулі][list-module] або за допомогою [зіставлення зі зразком][list-destructuring]

```elm
describe : List String -> String
describe list =
    case list of
        [] ->
            "Empty list"

        [ "hello" ] ->
            "Singleton list with: hello"

        x :: xs ->
            "Non-empty list with head: " ++ x

describe []                   --> "Empty list"
describe [ "hello" ]          --> "Singleton list with: hello"
describe [ "hello", "world" ] --> "Non-empty list with head: hello"
```
