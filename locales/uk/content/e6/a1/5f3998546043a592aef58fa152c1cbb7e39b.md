# Інструкції

Прослуховування на шкільну виставу завершилося, і режисерові потрібно записати свої рішення.

Усі чотири завдання потрібно розмістити в класі `CASTING_CALL`.

## 1. Вердикт

Кожного виконавця оцінюють за десятибальною шкалою. Виконавця, який набрав вісім балів або більше, беруть до трупи; від пʼяти до семи балів - запрошують на повторний перегляд; менше пʼяти - дякують за участь.

```sather
CASTING_CALL::audition_outcome(8)
-- => "Cast"
CASTING_CALL::audition_outcome(6)
-- => "Recalled"
CASTING_CALL::audition_outcome(2)
-- => "Thank you"
```

## 2. Яка група?

Виконавці, молодші за 13 років, належать до групи «Juniors». Від 13 до 15 років - до групи «Middles». Від 16 років і старші - до групи «Seniors».

```sather
CASTING_CALL::age_group(13)
-- => "Middles"
```

## 3. Коли повертатися

Виконавців із групи «Juniors» запрошують на повторний перегляд о четвертій годині, «Middles» - о пʼятій, а всіх інших - о шостій.

```sather
CASTING_CALL::callback_time("Middles")
-- => "5pm"
```

У цю функцію передають назву групи, записану точно так, як у завданні 2.

## 4. Що писати в бланку

Той, хто набрав вісім балів або більше і вміє співати, отримує `"Lead"`. Вісім і більше без співу - `"Speaking part"`. Усі інші - `"Chorus"`.

```sather
CASTING_CALL::casting_note(9, true)
-- => "Lead"
CASTING_CALL::casting_note(9, false)
-- => "Speaking part"
CASTING_CALL::casting_note(4, true)
-- => "Chorus"
```
