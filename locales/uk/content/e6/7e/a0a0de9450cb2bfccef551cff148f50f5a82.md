# Підказки

Використання комплексних чисел для обертань у 2D може зробити код значно чистішим і чисельно точнішим.

## 1. Створіть комплексне число з декартових координат

- Вбудований метод [`complex(x, y)`][complex] ефективніший, ніж присвоєння `x + im*y`.
- Загляньте до вступу, щоб повторити матеріал.

## 2. Створіть комплексне число з полярних координат

- Є кілька рівноцінних способів це зробити (наприклад, `exp`, `cis`, `cispi`).
- Загляньте до вступу та вказівок, щоб повторити докладніше.

## 3. Виконайте обертання 2D-вектора

- Тут стане в пригоді [формула Ейлера][euler], до того ж можна скористатися власною функцією `euler`.
- Існують методи для отримання [дійсної][real] частини та [уявної][imaginary] частини комплексного числа, або обох одразу!

## 4. Виконайте радіальне зміщення

- Функція `euler` тут може стати в пригоді, а може й ні...
- Вбудований метод [`angle`][angle] дає змогу швидко знайти аргумент комплексного числа.
- Метод [`abs`][abs] дає змогу знайти модуль комплексного числа.

## 5. Знайдіть потрібну пісню

- Це гарна нагода поєднати функції `rotate` та `rdisplace`.
