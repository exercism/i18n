# Інструкції

У цій вправі ми будемо реалізовувати логіку квестів для нової рольової гри, яку розробляє наш друг.

Головна героїня гри - Annalyn, відважна дівчина з лютим і вірним псом. На жаль, трапляється лихо: її найкращого друга викрали, коли він шукав у лісі ягоди.

Annalyn спробує знайти і визволити свого найкращого друга, за бажанням узявши з собою в цей квест і свого пса.

Певний час ідучи слідом за своїм найкращим другом, вона знаходить табір, де його тримають у полоні. Виявляється, викрадачів двоє: могутній лицар і хитрий лучник.

Знайшовши викрадачів, Annalyn обмірковує, які з наведених нижче дій вона може вчинити:

- _Швидка атака_: швидку атаку можна здійснити, якщо лицар спить, адже йому потрібен час, щоб одягнути обладунок, тож він буде вразливим.
- _Стеження_: за групою можна стежити, якщо хоча б один з них не спить. Інакше стежити немає сенсу.
- _Подати сигнал полоненому_: полоненому можна подати сигнал пташиними звуками, якщо він не спить, а лучник спить, адже лучники вміють подавати сигнали пташиними звуками, тож могли б перехопити повідомлення.
- _Визволити полоненого_: Annalyn може спробувати непомітно пробратися в табір, щоб визволити полоненого.
  Це ризикована справа, і вона може вдатися лише в один із двох способів:
  - Якщо Annalyn має з собою свого пса, вона може врятувати полоненого, якщо лучник спить.
    Лицар боїться пса, і лучник не встигне підготуватися, перш ніж Annalyn і полонений утечуть.
  - Якщо ж Annalyn без пса, то їй і полоненому доведеться діяти дуже обережно!
    Annalyn може визволити полоненого, якщо той не спить, а лицар і лучник обоє сплять, але якщо полонений спить, його не врятувати: він злякається раптової появи Annalyn і розбудить лицаря й лучника.

Перед нами чотири завдання: реалізувати логіку, яка визначає, чи доступні наведені вище дії, залежно від стану трьох персонажів, знайдених у лісі, і від того, чи присутній пес Annalyn.

## 1. Перевірити, чи можна здійснити швидку атаку

Реалізуйте метод `can_fast_attack()`, який приймає булеве значення (англ. Boolean), що вказує, чи не спить лицар. Цей метод повертає `TRUE`, якщо швидку атаку можна здійснити залежно від стану лицаря. Інакше повертає `FALSE`:

```R
knight_is_awake <- TRUE
can_fast_attack(knight_is_awake)
# => FALSE
```

## 2. Перевірити, чи можна стежити за групою

Реалізуйте метод `can_spy()`, який приймає три булеві значення, що вказують, чи не сплять лицар, лучник і полонений відповідно. Метод повертає `TRUE`, якщо за групою можна стежити, залежно від стану трьох персонажів. Інакше повертає `FALSE`:

```R
knight_is_awake <- FALSE
archer_is_awake <- TRUE
prisoner_is_awake <- FALSE
can_spy(knight_is_awake, archer_is_awake, prisoner_is_awake)
# => TRUE
```

## 3. Перевірити, чи можна подати сигнал полоненому

Реалізуйте метод `can_signal_prisoner()`, який приймає два булеві значення, що вказують, чи не сплять лучник і полонений відповідно. Метод повертає `TRUE`, якщо полоненому можна подати сигнал, залежно від стану двох персонажів. Інакше повертає `FALSE`:

```R
archer_is_awake <- FALSE
prisoner_is_awake <- TRUE
can_signal_prisoner(archer_is_awake, prisoner_is_awake)
# => TRUE
```

## 4. Перевірити, чи можна визволити полоненого

Реалізуйте метод `can_free_prisoner()`, який приймає чотири булеві значення. Перші три параметри вказують, чи не сплять лицар, лучник і полонений відповідно. Останній параметр вказує, чи присутній пес Annalyn. Метод повертає `TRUE`, якщо полоненого можна визволити, залежно від стану трьох персонажів і присутності пса Annalyn. Інакше повертає `FALSE`:

```R
knight_is_awake <- FALSE
archer_is_awake <- TRUE
prisoner_is_awake <- FALSE
pet_dog_is_present <- FALSE
can_free_prisoner(knight_is_awake, archer_is_awake, prisoner_is_awake, pet_dog_is_present)
# => FALSE
```
