# Масиви

У Cairo масив - це структура даних, яка дозволяє зберігати набір елементів одного типу.
Масиви в Cairo мають обмежені способи змінення.
Додавати елементи можна лише в кінець масиву, а вилучати - лише з початку.
Насправді масиви - це черги, значення яких не можна змінювати.

## Створення масиву

Масиви переважно створюють за допомогою трейту `ArrayTrait`, у будь-який із наведених нижче 4 способів створити масив з елементів `[1, 2]`:

```rust
// 1. Passing the type to the `ArrayTrait`
let mut arr_type_in_trait = ArrayTrait::<felt252>::new();
arr_type_in_trait.append(1);
arr_type_in_trait.append(2);

// 2. Setting the type on the variable itself
let mut arr_explicit_type: Array<felt252> = ArrayTrait::new();
arr_explicit_type.append(1);
arr_explicit_type.append(2);

// 3. Using the `array!` macro
let mut arr_from_macro: Array<felt252> = array![1, 2]; // assign values in-line

// 4. Allowing the compiler to infer the type from the type of values being assigned to it
let mut arr_implicit_type = ArrayTrait::new(); // compiler "knows" this is a `felt252` array
arr_implicit_type.append(1);
arr_implicit_type.append(2);
```

> Кожен виклик `append()` додає нове число в кінець масиву.

## Вилучення елементів масиву

Вилучати елементи з масиву в Cairo можна лише з початку.
Цю операцію виконує метод `pop_front()`, який повертає `Option`, котрий можна розгорнути й отримати вилучений елемент, або `Option::None`, якщо масив порожній.

```rust
fn main() {
    let mut a = array![10, 1, 2];
    let first_value = a.pop_front().unwrap(); // `unwrap()` is used to get the value from `Option`
    println!("The first value is {}", first_value); // prints "The first value is 10"
}
```

## Доступ до значень у масиві

Щоб отримати доступ до елементів масиву, можна використати методи масиву `get()` або `at()`, які повертають різні типи.
Еквівалент `arr.at(index)` - це оператор індексації `arr[index]`.

### Використання методу get()

Метод `get()` схожий на пошук елемента в масиві за його номером.
Ось як він працює:

- `arr.get(index)` дозволяє дістати елемент за конкретною позицією (індексом) у масиві.
- Він повертає `Option::Some(value)`, якщо елемент за вказаним індексом існує, або `Option::None`, якщо індекс поза межами.

Цей метод ідеально підходить, коли треба обробити випадок, у якому індекс може бути недійсним, не допускаючи аварійного завершення програми.

```rust
fn main() {
    let arr: Array<u32> = array![1, 2, 3];

    let index = 1;

    match arr.get(index) {
        Option::Some(value) => { println!("Element at index {}: {}", index, value.unbox()); },
        Option::None => { println!("Index {} is out of bounds!", index); }
    }
}
```

### Використання методу at()

Метод `at()` безпосередньо дає знімок елемента за конкретним індексом, використовуючи операцію `unbox()`, щоб дістати збережене значення з box.
Скорочений запис цього методу - оператор індексації `arr[index]`.
Якщо спробувати звернутися до індексу, якого не існує (поза межами), програма запанікує з помилкою.

```rust
fn main() {
    let a: Array<u32> = array![5, 8];

    println!("First: {}", *a.at(0)); // prints "First: 5"
    println!("Second: {}", a[1]); // prints "Second: 8"
    println!("Third: {}", a[2]); // panics with 'Index out of bounds'
}
```

## Методи, повʼязані з розміром

Щоб визначити кількість елементів у масиві, скористаймося методом `len()`.
Повернене значення має тип `usize`.

Якщо треба перевірити, чи масив порожній, можна скористатися методом `is_empty()`, який повертає `true`, якщо масив порожній, і `false` в іншому разі.

## `Span`

`Span` - це структура, яка являє собою знімок `Array`.
Вона призначена для безпечного й контрольованого доступу до елементів масиву без змінення початкового масиву.
`Span` особливо корисний, коли треба забезпечити цілісність даних і уникнути проблем із запозиченням під час передавання масивів між функціями або виконання операцій лише для читання.

> Усі методи, які надає `Array`, можна використовувати і зі `Span`, крім методу `append()`.

Щоб створити `Span` з `Array`, викличмо метод `span()`:

```rust
let my_array: Array<u32> = array![1, 2, 3];
let my_span: Span<u32> = my_array.span();
```

## Тип `Array` фіксованого розміру

Значення в масиві фіксованого розміру ми записуємо як список, розділений комами, у квадратних дужках.
Тип масиву записують у квадратних дужках: спочатку тип кожного елемента, потім крапка з комою, а далі кількість елементів у масиві.

```rust
let arr: [u64; 5] = [1, 2, 3, 4, 5];
```

> Зауваження: лише масиви фіксованого розміру можна використовувати як константи

До елементів масиву фіксованого розміру можна отримати доступ або через деструктуризацію масиву, або через перетворення його на `Span`, який підтримує індексацію.

```rust
fn main() {
    let arr = [1, 2, 3, 4, 5]; // implicit `felt252` array type

    // Accessing elements of a fixed-size array by deconstruction
    let [a, b, c, _, _] = arr;
    println!("c: {}", c); // c: 3
    
    // Accessing elements of a fixed-size array by index
    let my_span = arr.span();
    println!("my_span[2]: {}", my_span[2]); // my_span[2]: 3
}
```
