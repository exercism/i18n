# Встановлення

## Швидкий старт

``` shellsession
$ bash <(curl -s https://raw.githubusercontent.com/borkdude/babashka/master/install)
```

За промовчанням це встановиться в `/usr/local/bin`. Щоб змінити це, укажіть назву каталогу:

``` shellsession
$ bash <(curl -s https://raw.githubusercontent.com/borkdude/babashka/master/install) /tmp
```

## Brew

Для Linux і macOS бінарні файли надаються через brew.

Встановлення:

    brew install borkdude/brew/babashka

Оновлення:

    brew upgrade babashka

## Arch (Linux)

`babashka` [доступний](https://aur.archlinux.org/packages/babashka-bin/) в [Arch User Repository](https://aur.archlinux.org). Його можна встановити за допомогою улюбленого помічника [AUR](https://aur.archlinux.org), як-от
[yay](https://github.com/Jguer/yay), [yaourt](https://github.com/archlinuxfr/yaourt), [apacman](https://github.com/oshazard/apacman) і [pacaur](https://github.com/rmarquis/pacaur). Ось приклад із використанням `yay`:

    yay -S babashka-bin

## Windows

У Windows можна встановити за допомогою [scoop](https://scoop.sh/) і bucket
[scoop-clojure](https://github.com/littleli/scoop-clojure).

## Завантаження

Також можна завантажити бінарний файл із
[Github](https://github.com/borkdude/babashka/releases). Для Linux доступний
статичний бінарний файл, який можна використати в Alpine.

## Docker

Перегляньте образ на [Docker hub](https://hub.docker.com/r/borkdude/babashka/).
