# Вступ

Коли quotation потрібно *памʼятати* значення зі свого оточення, Factor пропонує два інструменти: `curry`/`compose` з [`kernel`][kernel] і синтаксис fry `'[ … ]` з [`fry`][fry].

`curry` вкладає одне значення на початок quotation:

```
curry ( value quot -- newquot )
```

```factor
3 [ + ] curry .          ! => [ 3 + ]
10 3 [ + ] curry call .  ! => 13
```

`compose` поєднує дві quotation:

```factor
[ 1 + ] [ 2 * ] compose .       ! => [ 1 + 2 * ]
5 [ 1 + ] [ 2 * ] compose call . ! => 12
```

Для більш ніж одного-двох захоплень fry зручніший. Кожен заповнювач `_` заповнюється у порядку значенням, узятим зі стека:

```factor
2 3 '[ _ _ + + ] .    ! => [ 2 3 + + ]
```

Fry також сягає всередину вкладених quotation.

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
[fry]: https://docs.factorcode.org/content/vocab-fry.html
