# Підказки

## Загальне

- `TUPLE:` і `boa` оголошені в словниках, суміжних із `kernel`. Для оголошення класу спеціальний USING не потрібен. Слова-аксесори походять із [`accessors`][accessors].

## 1. Базовий клас

- `TUPLE: dragon name color age ;` оголошує клас із трьома слотами у вказаному порядку. `<dragon>` пишеться одним рядком: `dragon boa`.

## 2. Ті, що дихають вогнем

- Синтаксис `<` для вказівки батьківського класу успадковує його слоти: `TUPLE: fire-dragon < dragon flame-temp ;`. Конструктор `boa` приймає слоти батька першими.

## 3. Ті, що дихають кригою

- Така сама форма, як у завданні 2, лише з іншим додатковим слотом. Сусідні підкласи не взаємодіють між собою: `fire-dragon` та `ice-dragon` обидва є безпосередніми підкласами `dragon`.

## 4. Мешканці вулкана

- Успадковуємо від `fire-dragon` (а не безпосередньо від `dragon`), тож `volcano-dragon` успадковує і слоти `dragon`, і `flame-temp` від `fire-dragon`. Конструктор `boa` приймає пʼять значень: name, color, age, flame-temp, lava-volume.

## 5. Старіння будь-якого дракона

- `change-age` - це мутувальний аксесор. `( tuple quot -- tuple )` застосовує quotation до поточного віку й записує результат назад. `[ 1 + ] change-age drop` збільшує вік на одиницю й відкидає повернутий кортеж. Оскільки кожен нащадок успадковує цей слот, те саме слово працює для кожного з них.
