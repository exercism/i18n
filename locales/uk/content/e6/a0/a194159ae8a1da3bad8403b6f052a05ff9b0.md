# Introduction

Масиви в C# - це колекції примітивних значень або екземплярів структур чи класів. Вони реалізовані в базовій бібліотеці класів як `List<T>`, де `T` - це тип елемента в масиві. API надає багатий набір методів для створення та маніпулювання масивами.

Елементи можна додавати до масивів та видаляти з них. Вони збільшуються та зменшуються за потреби.

```csharp
var listOfStrings = new List<string>();
```
