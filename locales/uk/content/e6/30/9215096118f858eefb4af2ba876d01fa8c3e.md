# Вступ

[Діапазони][range] задають інтервал між двома значеннями.
Діапазони зазвичай використовують із такими типами, як `Int`, `String` і `Character`, щоб перебирати послідовності, зрізати колекції або перевіряти, чи потрапляє значення в межі.

Swift надає два основних оператори діапазону:

- **Оператор закритого діапазону (`...`)**: включає і початкове, і кінцеве значення (`1...5` містить 1, 2, 3, 4 і 5).
- **Оператор напіввідкритого діапазону (`..<`)**: включає початкове значення, але не включає кінцеве (`1..<5` містить 1, 2, 3 і 4).

```swift
let closed = 1...5
let halfOpen = 1..<5
```

~~~~exercism/note
Коли ми викликаємо метод безпосередньо на літералі діапазону, беремо вираз діапазону в дужки, щоб компілятор спершу обчислив діапазон:

```swift
(1...5).contains(3) // Returns true
// 1...5.contains(3) // Error: value of type 'Int' has no member 'contains'
```
~~~~

## Перетворення діапазону на масив

Діапазон чисел можна перетворити на `Array` за допомогою ініціалізатора `Array(_:)`:

```swift
let range = 1...5
let numbers = Array(range)
// numbers is [1, 2, 3, 4, 5]
```

## Зрізання масиву за допомогою діапазонів

Діапазони можна використовувати, щоб зрізати частини масиву:

```swift
let array = [10, 20, 30, 40, 50]
let slice = array[1...3]
// slice contains [20, 30, 40]
```

## Властивості та методи діапазону

Поширені операції з діапазонами:

| Член                    | Опис                                                       | Приклад                              |
| ----------------------- | ---------------------------------------------------------- | ------------------------------------ |
| `count`                 | Повертає кількість елементів у діапазоні                   | `(1...5).count` повертає `5`         |
| [`contains(_:)`][contains] | Повертає `true`, якщо діапазон містить задане значення   | `(1...5).contains(3)` повертає `true` |

## Односторонні діапазони

Swift також підтримує односторонні (часткові) діапазони, у яких ми опускаємо або початкове, або кінцеве значення:

- `array[2...]`: від індексу 2 до кінця колекції.
- `array[...2]`: від початку колекції до індексу 2 включно.
- `array[..<2]`: від початку колекції до індексу 2 (не включаючи його).

## Діапазони рядків тексту та символів

Діапазони також можна створювати між символами або рядками тексту (англ. string), які відповідають протоколу `Comparable`:

```swift
let letters = "a"..."z"
print(letters.contains("m")) // Prints true
print(letters.contains("A")) // Prints false
```
