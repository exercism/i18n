# Доповнення до вказівок

## Про Enum

Конструкція Enum дозволяє створити набір міток із суворою типізацією.
Це перелічення можна використовувати в коді, не розбираючи його та не перевіряючи на помилки в написанні.

Усередині перелічення подаються як цілі числа, починаючи з нуля.
Типово PowerShell присвоює першій мітці в списку значення нуль, а всім наступним міткам дає послідовні цілі числа.

Приклад:
```pwsh
Enum Fruits {
    APPLE       #default internal value 0
    ORANGE      #default internal value 1
    MANGO       #default internal value 2
}

$myFavFruit = [Fruits]::APPLE
Write-host $myFavFruit => APPLE
``````

Щоб дізнатися більше про Enum у PowerShell, перегляньте [модуль Enum.](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.core/about/about_enum)
