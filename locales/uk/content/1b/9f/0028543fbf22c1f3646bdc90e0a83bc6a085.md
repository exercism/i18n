# Вступ

Регулярні вирази в Elixir відповідають специфікації **PCRE** (**P**erl **C**ompatible **R**egular **E**xpressions), як і в інших популярних мовах, таких як Java, JavaScript чи Ruby.

Модуль `Regex` пропонує функції для роботи з регулярними виразами. Деякі функції модуля `String` також приймають регулярні вирази як аргументи.

~~~~exercism/note
Ця вправа розрахована на те, що синтаксис регулярних виразів уже відомий, зокрема класи символів, квантори, групи та захоплення.

Якщо потрібно освіжити знання про регулярні вирази, скористайтеся одним із цих джерел: [Regular-Expressions.info](https://www.regular-expressions.info), [Rex Egg](https://www.rexegg.com/), [RegexOne](https://regexone.com/), [Regular Expressions 101](https://regex101.com/), [RegExr](https://regexr.com/).
~~~~

## Сігіли

Найчастіше регулярні вирази створюють за допомогою сігіла `~r`.

```elixir
~r/test/
```

Зауважмо, що всі сігіли Elixir підтримують [різні види роздільників][sigils], не лише `/`.

## Пошук збігів

Оператор `=~/2` дає змогу виконати зіставлення з регулярним виразом, яке повертає результат `boolean`. Крім того, функції `match?/2` є і в модулі `Regex`, і в модулі `String`.

```elixir
"this is a test" =~ ~r/test/
# => true

String.match?("Alice has 7 apples", ~r/\d{2}/)
# => false
```

## Захоплення

Якщо простої булевої перевірки (англ. Boolean) недостатньо, скористаймося функцією `Regex.run/3`, щоб отримати список усіх захоплень (або `nil`, якщо збігу не було). Перший елемент поверненого списку завжди відповідає всьому регулярному виразу, а наступні елементи - це зіставлені групи.

```elixir
Regex.run(~r/(\d) apples/, "Alice has 7 apples")
# => ["7 apples", "7"]
```

## Модифікатори

Поведінку регулярного виразу можна змінити, додавши спеціальні прапорці. Створюючи регулярний вираз за допомогою сігіла, модифікатори додають після другого роздільника.

Поширені модифікатори:
- `i` - робить зіставлення незалежним від регістру.
- `u` - вмикає специфічні для Unicode шаблони, як-от `\p`, і змушує класи символів, як-от `\w`, `\s` тощо, також зіставлятися з символами Unicode.

```elixir
"this is a TEST" =~ ~r/test/i
# => true
```
