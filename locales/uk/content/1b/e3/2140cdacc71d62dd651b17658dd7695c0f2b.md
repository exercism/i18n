# Умовні конструкції

У Crystal є так звані керуючі вирази. Вони визначають, як виконуватиметься програма, і приймають правдиве або неправдиве значення.
Існують оператори, за допомогою яких можна створювати правдиві або неправдиві значення. Їх називають [операторами рівності та порівняння][equality-and-comparison].

Є два основні керуючі вирази, які визначають, який код виконається, а який ні.
Інакше кажучи, яка саме з гілок спрацює.

Це `if` та `unless`.

## Оператори порівняння

Оператори порівняння порівнюють значення й повертають `true` або `false`.
Ці оператори вимагають, щоб порівнювані значення були одного типу.
Якщо значення різних типів, компілятор видасть помилку.
Ось список операторів порівняння та приклади, коли вони дають `true`:

| Метод | Опис                  | Приклад |
| ------ | --------------------- | ------- |
| <      | менше ніж             | 4 < 5   |
| <=     | менше або дорівнює    | 4 <= 4  |
| >      | більше ніж            | 3 > 1   |
| >=     | більше або дорівнює   | 2 >= 2  |

## Оператори рівності

Оператори рівності схожі на оператори порівняння, але вони перевіряють, чи два значення рівні.

Оператор `==` перевіряє, чи два значення рівні, враховуючи їхній тип.
Якщо значення однакові, він поверне `true`, інакше поверне `false`.
Оператор `==` може порівнювати будь-який тип значень з будь-яким іншим типом.
Оператор `!=` працює так само, але повертає `true`, якщо значення не рівні, і `false`, якщо рівні.

## Оператор «космічний корабель»

Оператор «космічний корабель» - це особливий оператор порівняння, назва якого походить від його вигляду.
Він особливий тим, що повертає не правдиве чи неправдиве значення, а число.
Його записують як `<=>` і використовують для порівняння двох значень.
Він повертає `1`, якщо ліве значення більше за праве, `-1`, якщо ліве значення менше за праве, і `0`, якщо значення рівні.

```crystal
1 <=> 2 # => -1
2 <=> 2 # => 0
3 <=> 2 # => 1
```

## Умовна конструкція if

Умовна конструкція [`if`][if] перевіряє, чи задана умова правдива або неправдива.
Якщо умова правдива, код усередині конструкції if виконається.
Конструкція `if` завершується ключовим словом `end`.

```crystal
if 1 == 1
  puts "1 is equal to 1"
end
# => 1 is equal to 1

if 1 > 2
  puts "1 is greater than 2"
end
# => no output
```

## Умовна конструкція unless

Умовна конструкція [`unless`][unless] працює дуже схоже на конструкцію if, але виконує код усередині себе, якщо умова неправдива.

```crystal
unless 1 == 1
  puts "1 is not equal to 1"
end
# => no output

unless 1 > 2
  puts "1 is not greater than 2"
end
# => 1 is not greater than 2
```

## Конструкція else

Конструкцію `else` можна використовувати разом з конструкціями `if` та `unless`.
Конструкція `else` виконається, якщо гілка `if` або гілка `unless` не виконалася.

~~~~exercism/warning
Хоча гілку `else` можна використовувати разом з `unless,` робити так не рекомендується, бо це погіршує читабельність.
Натомість радимо використовувати `if !condition` з гілкою else.
~~~~

```crystal
if 1 == 1
  puts "1 is equal to 1"
else
  puts "1 is not equal to 1"
end
# => 1 is equal to 1

unless 1 < 2
  puts "1 is not greater than 2"
else
  puts "1 is greater than 2"
end
# => 1 is greater than 2
```

## «Каскадні» конструкції з if

Конструкцію `elsif` можна використовувати разом з конструкцією if.
Конструкція `elsif` виконається, якщо гілка if не виконалася, а умова `elsif` правдива.
Конструкції `elsif` можна обʼєднувати в ланцюжок, і виконається перша правдива умова.
Також у кінці конструкції if може бути конструкція else, яка виконається, якщо жодна з попередніх умов не була правдивою.

```crystal
if 1 != 1
  puts "1 is not equal to 1"
elsif 1 > 2
  puts "1 is greater than 2"
else
  puts "1 is not equal to 1 and 1 is not greater than 2"
end
# => 1 is not equal to 1 and 1 is not greater than 2
```

## Тернарний оператор

У Crystal є тернарний оператор, а саме умовна конструкція if-else в один рядок: `condition ? expression_if_truthy : expression_if_falsey`

```crystal
1 == 1 ? puts("1 is equal to 1") : puts("1 is not equal to 1")
# => 1 is equal to 1
```

## if та unless як суфікс

Конструкції if та unless можна також використовувати як [суфікс][if-as-suffix]. Це зручно, коли потрібно виконати один рядок коду за певної умови.
Для цього if або unless ставлять після коду, який потрібно виконати.

```crystal
puts "1 is equal to 1" if 1 == 1
# => 1 is equal to 1

puts "1 is not equal to 1" unless 1 == 1
# => no output
```

## Типи в умовних конструкціях

Коли в різних гілках змінній присвоюють значення різних типів, вона матиме обидва типи.
Це тому, що компілятор не знає, яка гілка виконається.
Це множинне присвоєння, відоме також як обʼєднання, буде пояснено в наступних концепціях.
Це видно в наступному прикладі:

```crystal
if 1 == 1
  a = 1
else
  a = "1"
end

typeof(a) # => Int32 | String
```
