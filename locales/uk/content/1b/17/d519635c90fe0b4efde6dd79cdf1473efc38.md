# Інструкції

У цій вправі ми напишемо програму, яка допоможе підготуватися до купівлі транспортного засобу.

На нас чекають два завдання: визначити, чи знадобиться посвідчення водія, і оцінити прийнятну ціну вживаного транспортного засобу.

## 1. Визначте, чи потрібне посвідчення водія

Деякі види транспортних засобів вимагають посвідчення водія для керування ними.
Припустімо, що посвідчення потрібне лише для транспортних засобів, які містять `car` або `truck`; усі решта можна використовувати без посвідчення.

Реалізуйте пару `pattern {action}`, яка збігається, коли перше поле має значення `needs_license`.
Вона має взяти вид транспортного засобу з другого поля й надрукувати «true», якщо для цього виду транспортного засобу потрібне посвідчення.
Якщо посвідчення не потрібне, друкувати нічого не треба.

```sh
echo "needs_license,dumptruck" | gawk -f vehicle-purchase.awk
# => true

echo "needs_license,bike" | gawk -f vehicle-purchase.awk
# => (empty output)
```

## 2. Обчисліть оцінку ціни вживаного транспортного засобу

Тепер, коли ми вже визначилися, хочеться бути впевненими, що в автосалоні нам дадуть справедливу ціну.
Оскільки нас цікавить купівля вживаного транспортного засобу, ціна залежить від того, який у нього вік.
Для приблизної оцінки припустімо: якщо транспортному засобу менше ніж 3 роки, він коштує 80% початкової ціни, яку мав новим.
Якщо йому більше ніж 10 років, він коштує 50%.
Якщо транспортному засобу щонайменше 3 роки, але не більше ніж 10 років, він коштує 70% початкової ціни.

Реалізуйте пару `pattern {action}`, яка збігається, коли перше поле має значення `resell_price`.
Вона має взяти початкову ціну транспортного засобу з другого поля, а вік - з третього.
Дія має надрукувати оцінену ціну.

```sh
echo "resell_price,1000,1" | gawk -f vehicle-purchase.awk
# => 800

echo "resell_price,1000,5" | gawk -f vehicle-purchase.awk
# => 700

echo "resell_price,1000,15" | gawk -f vehicle-purchase.awk
# => 500
```
