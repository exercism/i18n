# Інструкції

Згенеруйте ідеальні лабіринти для Мікі та Мінерви, тобто такі, що мають лише один розвʼязок і жодних ізольованих ділянок.
Ось що варто знати:

- Лабіринт має прямокутну форму з отвором на початку та в кінці.
- Лабіринт складається з кімнат і проходів, які перетинаються під прямим кутом.
- Програма повинна приймати два параметри: рядки та стовпці. Розмір лабіринту має бути від 5 до 100 комірок.
- Лабіринт шириною `x` стовпців і висотою `y` рядків має бути `2x + 1` символів завширшки та `2y + 1` символів заввишки.
- Якщо seed не вказано, має генеруватися випадковий лабіринт. Якщо той самий seed вказано кілька разів, лабіринт щоразу має бути однаковим.
- Використовуйте [псевдографічні символи][Box-drawing] для малювання стін, а символ стрілки (⇨) для входу ліворуч і виходу праворуч.

Настав час створити ідеальні лабіринти для цих відважних мишенят!

## Приклади

1. Маленький квадратний лабіринт 5x5 комірок (або 11x11 символів)

    ```text
    ┌───────┬─┐
    │       │ │
    │ ┌─┬── │ │
    │ │ │   │ ⇨
    │ │ │ ──┤ │
    ⇨ │ │   │ │
    ┌─┤ └── │ │
    │ │     │ │
    │ │ ────┘ │
    │         │
    └─────────┘
    ```

2. Прямокутний лабіринт 6x18 комірок

    ```text
    ┌───────────┬─────────┬───────────┬─┐
    │           │         │           │ │
    │ ┌───────┐ │ ┌─┐ ──┐ └───┐ ┌───┐ │ │
    │ │       │ │ │ │   │     │ │   │   ⇨
    │ └─┐ ┌─┐ │ │ │ ├── ├───┐ │ │ ──┼── │
    │   │ │ │   │   │   │   │ │ │   │   │
    └── │ │ ├───┴───┤ ┌─┘ ┌─┘ │ ├── │ ──┤
    ⇨   │   │       │ │   │   │ │   │   │
    ┌─┬─┴─┐ └─┐ ┌─┐ │ └─┐ │ ┌─┘ │ ──┴─┐ │
    │ │   │   │ │ │ │   │   │   │     │ │
    │ │ │ └── │ │ │ └── │ ──┘ ┌─┘ ──┐ │ │
    │   │       │       │     │     │   │
    └───┴───────┴───────┴─────┴─────┴───┘
    ```
