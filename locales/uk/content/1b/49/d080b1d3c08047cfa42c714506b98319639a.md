# Тести

Виберіть свою поточну операційну систему:

* [Windows](##windows)
* [macOS](##macos)
* [Linux](##linux)

# Запуск тестів

## Windows

1. Відкрийте Command Prompt.

2. Отримайте першу вправу:

    ```batchfile
     C:\Users\USERNAME> exercism download --exercise hello-world --track cobol
    ```

3. Перейдіть до теки з вправою:

    ```batchfile
     C:\Users\USERNAME> cd C:\Users\USERNAME\exercism\cobol\hello-world
    ```
   
4. Запустіть тести:

    ```batchfile
     C:\Users\USERNAME\exercism\cobol\hello-world> test.ps1
    ```
    *(Не варто хвилюватися, якщо тести не проходять під час першого запуску: так починається кожна вправа.)*

5. Розвʼяжіть вправу. 
    Прочитайте `instructions.md` і подивіться, як розвʼязати вправу ([переглянути на GitHub](https://github.com/exercism/cobol/blob/main/exercises/practice/hello-world/.docs/instructions.md)).


Успіхів, гарного настрою та вітаємо на треку COBOL!

## macOS

1. Відкрийте вікно Terminal.

2. Отримайте першу вправу:

    ```
     $ exercism download --exercise hello-world --track cobol
    ```

3. Перейдіть до теки з вправою:

    ```
     $ cd /Users/USERNAME/exercism/cobol/hello-world
    ```

4. Запустіть тести:

    ```
     $ bash test.sh
    ```
    *(Не варто хвилюватися, якщо тести не проходять під час першого запуску: так починається кожна вправа.)*

    Підказка: якщо зʼявиться повідомлення про відсутність `basename`, можна скористатися [brew](https://brew.sh/), щоб встановити coreutils. (`brew install coreutils`)

5. Розвʼяжіть вправу. 

    Прочитайте `instructions.md` і подивіться, як розвʼязати вправу ([переглянути на GitHub](https://github.com/exercism/cobol/blob/main/exercises/practice/hello-world/.docs/instructions.md)).


Успіхів, гарного настрою та вітаємо на треку COBOL!
