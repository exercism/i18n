# Докладніше

[Структури][getting-started] - це особливі [словники][maps] з визначеним набором ключів.

- Структури забезпечують перевірки під час компіляції та типові значення.
- Структура отримує назву від модуля, у якому її визначено.
- Щоб визначити структуру, скористаймося конструкцією [`defstruct`][docs-defstruct].
  - Зазвичай ця конструкція йде одразу після визначення модуля.
- `defstruct` приймає або список [атомів][atom] (для типових значень `nil`), або списки ключових слів (для заданих типових значень).
  - Поля без типових значень мають іти перед полями з типовими значеннями.

```elixir
defmodule Plane do
  defstruct [:engine, wings: 2]
end

plane = %Plane{}
# => %Plane{engine: nil, wings: 2}
```

## Доступ до полів і оновлення

- Більшість функцій, які працюють зі [словниками][maps], будуть працювати і зі структурами.
  - [_Access Behaviour_][access-behaviour] є винятком і для структур **не** реалізована.
- Для доступу до полів структури радимо використовувати _оператор статичного доступу_ `.`.

- Отримати значення полів:

  ```elixir
  plane = %Plane{}
  plane.engine
  # => nil
  Map.fetch(plane, :wings)
  # => {:ok, 2}
  ```

- Оновити значення полів

  ```elixir
  plane = %Plane{}
  %{plane | wings: 4}
  # => %Plane{engine: nil, wings: 4}
  ```

## Обовʼязкова ініціалізація значень полів

- [Атрибут модуля `@enforce_keys`][enforcing-keys] створює перевірку під час виконання: указані поля мають бути ініціалізовані значенням, яке **не** дорівнює `nil`, коли створюється структура.
- Після `@enforce_keys` іде список ключів полів (це [атоми][atom]).
- Якщо обовʼязковий ключ не ініціалізовано, виникає помилка.

```elixir
defmodule User do
  @enforce_keys [:username]
  defstruct [:username]
end

%User{}
# => (ArgumentError) the following keys must also be given when building struct User: [:username]
```
