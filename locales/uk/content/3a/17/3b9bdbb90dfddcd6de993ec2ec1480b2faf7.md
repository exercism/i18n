# Вступ

## Термінологія

Ми вже використовували й писали функції C++ у кількох концепціях.
Час зануритися в технічні деталі.
Наведений нижче фрагмент коду показує найуживаніші терміни для зручності.
Оскільки C++ ігнорує пробільні символи, форматування змінено так, щоб кожен елемент опинився в окремому рядку.

```cpp
// Function declaration:
bool                                              // Return type
admin_detected(string user, string password)      // Type signature
;                                                 // Don't forget the ';' for the declaration

// Function definition:
bool                                              // Return type
admin_detected                                    // Function name
(string user, string password)                    // Parameter list
{ return user == "admin" && password == "1234"; } // Function body
```
~~~~exercism/advanced
Оголошення працює як замітка для компілятора про те, що існує функція з такою назвою, типом повернення та списком параметрів.
Код не працюватиме, якщо визначення відсутнє.
Оголошення необовʼязкові; вони потрібні, якщо ми використовуємо функцію до її визначення.
Оголошення можуть розвʼязувати проблеми на кшталт циклічних посилань. Їх також можна використовувати, щоб відокремити інтерфейс від реалізації.
~~~~

## Кваліфікатор `const`

Іноді ми хочемо переконатися, що значення не можна змінити після їх ініціалізації.
C++ використовує ключове слово `const` як кваліфікатор для констант.

```cpp
const int number_of_dragon_balls{7};
number_of_dragon_balls--; // compilation error
```

~~~~exercism/note
Константи часто записують у _UPPER_SNAKE_CASE_.
Якщо немає іншої домовленості, цей регістр краще залишати для макросів.
~~~~

Якщо ми спробуємо змінити константну змінну після того, як її встановлено, код не скомпілюється.
Це допомагає уникнути ненавмисних змін, а також відкриває можливості для оптимізації компілятором.
Нам також легше міркувати про код, коли ми знаємо, що певні частини не зазнають змін.

`const` також може бути кваліфікатором для параметрів функції.

```cpp
string guess_number(const int& secret, const int& guess) {
    if (secret < guess) return "lower.";
    if (secret > guess) return "higher.";
    return "exact!";
}
```

Коли ми передаємо у функцію `const`-посилання, ми можемо бути певні, що воно залишиться незмінним.
`const`-посилання часто використовують для обʼєктів, копіювання яких може бути дорогим, як-от довші рядки тексту (англ. string).
До третього випадку використання кваліфікатора `const` належать функції-члени, які не змінюють екземпляр класу.

```cpp
class Stubborn {
    public:
    Stubborn(string reply) {
        response = reply;
    }
    string answer(const string& question) const {
        if (question.length() == 0) { return ""; }
        return response;
    }
    private:
    string response{};
};
```

Функція-член `answer` класу `Stubborn` використовує `const string&`-посилання як параметр.
Це дозволяє уникнути копіювання вихідного обʼєкта, переданого у функцію.

## Перевантаження функцій

Кілька функцій можуть мати однакову назву, якщо список параметрів різний.
Це називається перевантаженням функцій, і його зазвичай застосовують, коли ці функції виконують дуже схожі завдання.

Заголовок функції без типу повернення визначає її __сигнатуру типу__.
Зміна сигнатури типу дає нову функцію.

Приклад `play_sound` має шість різних перевантажень, щоб охопити різні сценарії:

```cpp
// different argument types:
void play_sound(char note);         // C, D, E, ..., B
void play_sound(string solfege);    // do, re, mi, ..., ti
void play_sound(int jianpu);        // 1, 2, 3, ..., 7

// different number of arguments:
void play_sound(string solfege, double duration);

// different qualifiers:
void play_sound(vector<string>& solfege);
void play_sound(const vector<string>& solfege);
```

~~~~exercism/advanced
Сигнатуру типу визначають назва функції, кількість параметрів, їхні типи та кваліфікатори (але не їхні назви).
Тип повернення навмисно не входить до сигнатури типу, і ми отримаємо помилки компіляції, якщо дві функції відрізняються лише типом повернення.
Компілятор скаржитиметься, бо незрозуміло, яку з двох слід використати.
~~~~

## Типові аргументи

Деякі функції можуть бути дуже довгими, і багато їхніх викликів можуть використовувати ті самі значення для більшості параметрів.
Повторення в таких викликах можна уникнути за допомогою типових аргументів.

```cpp
void record_new_horse_birth(string name, int weight, string color="brown-ish", string dam="Alruccaba", string sire="Poseidon");

record_new_horse_birth("Urban Sea", 130); // color will be brown, dam "Alruccabam", sire "Poseidon"
record_new_horse_birth("Highclere", 175, "off-white", "Fall Aspen");   // sire will be "Poseidon"
```

Оскільки оголошення функції часто читають перед визначенням, саме там краще задавати типові аргументи.
Якщо для одного параметра вказано типове значення в оголошенні, то для всіх параметрів праворуч теж потрібно вказати типове значення.
Іноді складні перевантаження функцій можна переробити на меншу кількість функцій із типовими аргументами, щоб полегшити підтримку.
