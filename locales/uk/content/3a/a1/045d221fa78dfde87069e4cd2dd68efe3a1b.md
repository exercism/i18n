# Вступ

## Порівняння чисел

У `jq` числа можна порівнювати за допомогою наведених нижче операторів відношення та рівності.

| Порівняння             | Оператор |
| ---------------------- | -------- |
| Більше ніж             | `a > b`  |
| Більше або дорівнює    | `a >= b` |
| Менше ніж              | `a < b`  |
| Менше або дорівнює     | `a <= b` |
| Дорівнює               | `a == b` |
| Не дорівнює            | `a != b` |

Результат порівняння завжди є булевим значенням (англ. Boolean), тобто `true` або `false`.

```jq
1 < 3,      # => true
2 != 2,     # => false
1 == 1.0    # => true
            # All numbers are floating-points, so this is different syntax
            # for the exact same value.
```

## Порівняння рядків тексту

Наведені вище оператори порівняння також можна використовувати для порівняння рядків тексту (англ. string). У такому разі застосовується словниковий (лексикографічний) порядок. Впорядкування відбувається _за значенням коду символу Unicode_.

```jq
"Apple" > "Pear",   # => false
"a" < "above",      # => true
"a" == "A"          # => false
```

Треба бути обережними, коли ми порівнюємо дві змінні, які на перший погляд містять числові значення, але мають тип рядка тексту. Через словниковий порядок результат буде не таким, як під час порівняння значень типу числа.

```jq
10 < 2,     # => false
"10" < "2"  # => true (because "1" comes before "2")
```

## «Сувора» рівність

Оператор `==` у `jq` схожий на `===` у JavaScript у тому сенсі, що речі, які «на вигляд» однакові, але мають різні типи, не є рівними.

```jq
"3" == 3    # => false
            # the value on the left has type string,
            # the value on the right has type number.
```

## Порівняння масивів

Два масиви рівні, якщо всі відповідні елементи рівні.

```jq
[1, 2, 3] == [1, 2, 3]      # => true
[1, 2, 3] == [1, 3, 2]      # => false, different order
[1, 2, 3] == [1, 2, "3"]    # => false, different types
```

## Порівняння обʼєктів

Два обʼєкти рівні, якщо вони мають однакові пари ключ-значення.

```jq
{name: "Joe", age: 42} == {age: 42, name: "Joe"}                # => true
{name: "Joe", age: 42} == {age: 42, name: "Jane"}               # => false
{name: "Joe", age: 42} == {age: "42", name: "Joe"}              # => false
{name: "Joe", age: 42} == {age: 42, name: "Joe", height: 175}   # => false

# comparisons will drill down as deeply as required
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2]}}}                  # => true
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2, 3]}}}               # => false
```
