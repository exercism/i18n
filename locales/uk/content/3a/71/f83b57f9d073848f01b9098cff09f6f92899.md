# Вступ

Насоси, клапани, шланги: усе, що утримує ресурс операційної системи (відкритий файл, мережеве зʼєднання), потрібно *звільнити*, коли ми закінчили з ним працювати. Словник [`destructors`][destructors] у Factor обгортає їх у фреймворк, який гарантує прибирання, навіть коли помилка перериває наш код десь посередині.

## Клас і дженерик

Клас долучається до фреймворку, успадковуючи `disposable` і реалізуючи дженерик `dispose*`:

```factor
USING: accessors destructors kernel ;

TUPLE: pump < disposable opened ;

: <pump> ( -- pump )
    pump new-disposable t >>opened ;

M: pump dispose* f >>opened drop ;
```

`new-disposable ( class -- obj )` виділяє кортеж *і* реєструє його у фреймворку: виняток між виділенням і наступною безпечною точкою не може призвести до витоку ресурсу. Фреймворк гарантує, що `dispose*` виконується **не більше одного разу** для кожного обʼєкта: повторні виклики `dispose` нічого не роблять.

## Зовнішні виклики використовують `dispose`

```
dispose          ( obj -- )                ! release; safe to call twice
with-disposal    ( disposable quot -- )    ! scope one resource
with-destructors ( quot -- )               ! open a registry scope
&dispose         ( obj -- obj )            ! dispose on normal *or* failure exit
|dispose         ( obj -- obj )            ! dispose only if the scope unwinds
```

`with-disposal` - форма для одного ресурсу: він додає до стека обʼєкт, який слід звільнити, для внутрішньої quotation і звільняє його на виході.

```factor
USING: destructors io ;

<pump> [
    "pumping" print
] with-disposal
! pump released on the way out — even if `print` had thrown
```

Якщо ресурсів більше ніж один, відкриваємо область `with-destructors` і реєструємо кожен отриманий ресурс. `&dispose` (амперсанд) означає «завжди звільняти на виході, незалежно від того, успіх це чи невдача». `|dispose` (вертикальна риска) означає «звільняти **лише** в разі помилки»: це корисно, коли шлях успіху передає ресурс викликачу, який візьме на нього право власності.

```factor
[
    <pump> &dispose
    <pump> &dispose
    ! ... use the pumps ...
] with-destructors
! both pumps released
```

Для звичайного try/finally без реєстру нижчорівневим примітивом є [`cleanup`][cleanup] (у `continuations`), але `with-destructors` - це ідіоматичний сучасний Factor.
