# Вступ

## Тернарний оператор

Тернарний оператор - це коротший спосіб записати прості конструкції `if/else`.
Якщо конструкція `if/else` містить лише дві гілки, одну для випадку, коли умова є правдою, і одну для випадку, коли вона є неправдою, її можна переписати як тернарний оператор.

Тернарні оператори використовують комбінацію символів `?` і `:`, щоб розділити умову:

```ruby
condition ? true_branch : false_branch
```

Код ліворуч від `?` - це умова, а код праворуч містить дві можливі гілки, розділені символом `:`.
Якщо умова - _правда_, виконується код _ліворуч_ від `:`.
Якщо умова - _неправда_, тоді виконується код _праворуч_ від `:`.

Наприклад:

```ruby
if traffic_light == 'green'
  cross_the_road
else
  wait
end
```

можна переписати так:

```ruby
traffic_light == 'green' ? cross_the_road : wait
```
