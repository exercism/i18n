# Доповнення до інструкцій

## Регістри

| Регістр | Використання     | Тип    | Опис                     |
| -------- | --------- | ------- | ------------------------------- |
| `$a0`    | вхідні дані     | адреса | колір як рядок тексту (англ. string), завершений нульовим символом |
| `$v0`    | вихідні дані     | ціле число | значення резистора                  |
| `$t0-9`  | тимчасовий | будь-який     | для тимчасового зберігання           |
