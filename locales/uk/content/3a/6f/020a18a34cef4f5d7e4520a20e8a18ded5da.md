# Вступ

У C++ булеві значення (англ. Boolean) представлені типом `bool`.
`bool` може бути або `true`, або `false`.

## Логічні оператори

C++ підтримує три булеві оператори: `!` (логічне заперечення), `&&` (логічне і) та `||` (логічне або).
Також можна використовувати альтернативні версії `not`, `and` і `or`.

```cpp
true || false // => true
true && false // => false
!true // => false
not false // => true
```

## Пріоритет

Кожен із трьох булевих операторів має свій _пріоритет_.
Як наслідок, вони обчислюються в такому порядку: спочатку `!`, потім `&&`, і врешті `||`.
Якщо потрібно змусити їх обчислюватися в іншому порядку, можна взяти булевий вираз у дужки (тобто `()`), адже дужки мають ще вищий пріоритет.

```cpp
!true && false   // => false
!(true and false) // => true
```

## Перетворення

Якщо використати `true` або `false` там, де очікується число, їх буде перетворено відповідно на `1` та `0`.
Якщо використати число в булевій операції, усе, крім `0`, вважається за `true`, навіть відʼємні значення.

```cpp
!true && 0.0   // => false
true + true + false // => 2
```
