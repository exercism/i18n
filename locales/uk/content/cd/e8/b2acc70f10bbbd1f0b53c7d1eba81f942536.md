# Інструкції

У цій вправі потрібно реалізувати кілька правил із [Pac-Man][Pac-Man], класичної аркадної гри 1980-х років.

Усього тут шість завдань, і чотири з них описують правила, повʼязані зі станами гри.

> _Не переймайтеся тим, як утворюються аргументи функцій, просто зосередьтеся на поєднанні аргументів, щоб повернути потрібний результат._


## 0. Визначити стан енергії

Визначте змінну з назвою `PowerOn` зі значенням, яке позначає, що енергію справді ввімкнено.

```powershell
> $PowerOn
True
```

## 1. Визначити, чи Pac-Man зʼїдає привида

Визначте функцію `EatGhost`, яка приймає два параметри (_чи активна в Pac-Man енергетична піґулка_ і _чи торкається Pac-Man привида_) і повертає булеве значення (англ. Boolean), якщо Pac-Man може зʼїсти привида.
Функція повинна повертати `True` лише тоді, коли в Pac-Man активна енергетична піґулка і він торкається привида.

```powershell
> EatGhost -ActivePower $false -TouchingGhost $true
False
```

## 2. Визначити, чи Pac-Man набирає очки

Визначте функцію `Score`, яка приймає два параметри (_чи торкається Pac-Man енергетичної піґулки_ і _чи торкається Pac-Man точки_) і повертає булеве значення, якщо Pac-Man набрав очки.
Функція повинна повертати `True`, якщо Pac-Man торкається енергетичної піґулки або точки.

```powershell
> Score -TouchDot $true -TouchPowerPellet $true
4
```

## 3. Визначити, чи Pac-Man програє

Визначте функцію `Lose`, яка приймає два параметри (_чи активна в Pac-Man енергетична піґулка_ і _чи торкається Pac-Man привида_) і повертає булеве значення, якщо Pac-Man програє.
Функція повинна повертати `True`, якщо Pac-Man торкається привида і в нього немає активної енергетичної піґулки.

```powershell
> Lose -ActivePower $false -TouchingGhost $true
True
```

## 4. Визначити, чи Pac-Man виграє

Визначте функцію `Win`, яка приймає три параметри (_чи зʼїв Pac-Man усі точки_, _чи активна в Pac-Man енергетична піґулка_ і _чи торкається Pac-Man привида_) і повертає булеве значення, якщо Pac-Man виграє.
Функція повинна повертати `True`, якщо Pac-Man зʼїв усі точки і не програв за параметрами, визначеними в завданні 3.

```powershell
> Win -EatenAllDots $false -ActivePower $true -TouchingGhost $false
False
```

## 5. Написати `Synopsis` для умови перемоги

Поверніться до останньої функції й додайте до блоку коментаря розділ `Synopsis` з коротким описом того, як виграти гру.
Опис має містити щонайменше десять символів.

```powershell
function MyFunc($Arg) {
    <#
    .DESCRIPTION
    This is a demonstration of the comment-based help with the description keyword.
    #>
}
```
