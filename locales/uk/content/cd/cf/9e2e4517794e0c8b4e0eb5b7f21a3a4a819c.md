# Вступ

Регулярні вирази в Gleam відповідають специфікації **PCRE** (**P**erl **C**ompatible **R**egular **E**xpressions), як і в інших популярних мовах, зокрема Java, JavaScript чи Ruby.

Модуль `gleam/regex` пропонує функції для роботи з регулярними виразами.

~~~~exercism/note
Ця вправа розрахована на те, що синтаксис регулярних виразів уже відомий, зокрема класи символів, квантифікатори, групи та захоплення.

якщо потрібно освіжити знання про регулярні вирази, перегляньте одне з цих джерел: [Regular-Expressions.info](https://www.regular-expressions.info), [Rex Egg](https://www.rexegg.com/), [RegexOne](https://regexone.com/), [Regular Expressions 101](https://regex101.com/), [RegExr](https://regexr.com/).
~~~~

Найпоширеніший спосіб створити регулярний вираз - скористатися функцією `regex.from_string`.

```gleam
let assert Ok(re) = regex.from_string("test")
```

Функція `regex.from_string` повертає `Error`, якщо синтаксис регулярного виразу неправильний, тому тут застосовано перевірку let assert, щоб переконатися, що регулярний вираз дійсний.

Функцію `regex.check` можна використати, щоб перевірити, чи регулярний вираз збігається з рядком тексту (англ. string).

```gleam
let assert Ok(re) = regex.from_string("test")

regex.check(re, "this is a test")
// -> True

regex.check(re, "this is too")
// -> False
```


## Захоплення

Якщо потрібно захопити підрядки за допомогою регулярного виразу, можна скористатися функцією `regex.scan`, яка повертає масив збігів.

```gleam
let assert Ok(re) = regex.from_string("[oi]n a (\\w+)")
regex.scan(with: re, content: "I am on a boat in a lake.")
// -> [
//   Match(
//     content: "on a boat",
//     submatches: [Some("boat")]
//   ),
//   Match(
//     content: "in a lake",
//     submatches: [Some("lake")]
//   )
// ]
```

## Модифікатори

Поведінку регулярного виразу можна змінити, створивши його функцією `regex.compile` і передавши опції.

```gleam
let options = regex.Options(case_insensitive: True, multi_line: False)
let assert Ok(re) = regex.compile("[A-Z]", with: options)
regex.check(re, "abc123")
// -> True
```
