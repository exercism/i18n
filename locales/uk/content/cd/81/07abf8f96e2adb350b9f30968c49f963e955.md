# Вступ

Переліки в Swift - це механізм створення нових типів, які складаються зі скінченної кількості іменованих значень. Ці значення можуть нести додаткову супутню інформацію, а до переліків можна прикріпити властивості й методи.

## Визначення переліків

Найпростіші переліки визначаються так, як показано нижче.

```swift
enum NESButton {
  case up
  case down
  case left
  case right
  case a
  case b
  case select
  case start
}
```

Для стислості кілька варіантів можна записати і в один рядок, розділивши їх комами, з одним ключовим словом `case`.

```swift
enum NESButton {
  case up, down, left, right, a, b, select, start
}
```

Так визначається новий тип із назвою `NESButton` з можливими значеннями `up`, `down`, `left`, `right`, `a`, `b`, `select` і `start`. На ці значення можна посилатися, поставивши після назви типу крапку (`.`) і значення. Якщо назву типу можна вивести, достатньо лише крапки та значення.

## Методи

Як і інші типи в Swift, переліки можуть містити методи, які дають переліку змогу надавати функціональність залежно від його поточного значення.

Методи аналогічні функціям, але визначаються всередині тіла переліку й привʼязані до поточного значення переліку. Звертаються до них через _точкову нотацію_: за назвою значення переліку йде крапка (`.`), а далі назва методу та його параметри.

Усередині методу значення переліку можна позначити як `self`, а в сигнатурі типу, якщо метод приймає як параметр або повертає значення цього переліку, тип можна позначити як `Self`.

### Ініціалізатори

Ініціалізатори - це особливі методи, які використовують, щоб створити значення переліку. Їхнє визначення дуже схоже на визначення методу, тільки без ключового слова `func` і без типу повернення; назва має бути `init`, а ініціалізатор _мусить_ присвоїти `self` значення переліку. Ініціалізатори викликають або через точкову нотацію, або передавши параметри ініціалізатора назві переліку.

```swift
enum Coin {
  case heads
  case tails

  init(_ i: Int) {
    if i.isMultiple(of: 2) {
      self = .heads
    } else {
      self = .tails
    }
  }

  func flip() -> Self {
    switch self {
    case .heads: return .tails
    case .tails: return .heads
    }
  }
}

let tails = Coin.init(13)
// .tails
let heads = Coin(0)
// .heads
let anotherTails = heads.flip()
// .tails
```

### Сирі значення

Переліки також можуть нести із собою внутрішнє значення, відоме як _сире значення_. Усі сирі значення мають бути одного типу, який оголошують у визначенні переліку. Тож ми могли б, наприклад, присвоїти нашому переліку `NESButton` значення типу `Character`, змінивши визначення:

```swift
enum NESButton: Character {
  case up = "⬆️"
  case down = "⬇️"
  case left = "⬅️"
  case right = "➡️"
  case a = "🅰️"
  case b = "🅱️"
  case select = "✅"
  case start = "🚦"
}
```

Тут `: Character` указує компілятору, що сирі значення матимуть тип `Character`, а присвоєння сирого значення йде після кожного варіанта.

До сирих значень можна звертатися через автоматично згенеровану властивість `rawValue` кожного варіанта.

```swift
NESButton.left.rawValue
// => "⬅️"
NESButton.b.rawValue
// => "🅱️"
```

Swift може неявно присвоювати сирі значення для типів `String` та `Int`. Якщо вказано тип сирого значення `String`, то сире значення неявно присвоюється назві варіанта як рядок тексту, якщо тільки це неявне значення не перекрито явним присвоєнням.

Якщо вказано тип сирого значення `Int`, сире значення неявно присвоюється як ціле число, на 1 більше за сире значення попереднього варіанта, якщо його не перекрито явним присвоєнням. Типове сире значення для першого варіанта - 0, якщо не вказано іншого.

```swift
enum Coin: String {
  case heads
  case tails = "eagle"
}

Coin.heads.rawValue
// => "heads"
Coin.tails.rawValue
// => "eagle"

enum Dwarf: Int {
  case grumpy, sleepy, sneezy, happy = 8, bashful, dopey, doc
}

Dwarf.grumpy.rawValue
// => 0
Dwarf.sneezy.rawValue
// => 2
Dwarf.happy.rawValue
// => 8
Dwarf.bashful.rawValue
// => 9
```
