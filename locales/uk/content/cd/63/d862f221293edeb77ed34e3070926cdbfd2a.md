# Краще винести константу на верхній рівень

Замість того, щоб визначати константу _всередині_ функції, спробуйте винести її на верхній рівень. Константи, функції та класи, які не позначені `export`, недоступні ззовні файлу.

```javascript
const %{name} = %{value}

export const gigasecond = (...)
```
