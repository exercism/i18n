# Заповнювач

## Загальне

- [Числова функція][rand-func] `rand` може генерувати випадкові числа.
- [Числова функція][srand-func] `srand` стане в пригоді, щоб задати початкове значення для `rand`.

## Генерування лабіринту

Можна використати будь-який алгоритм, щоб згенерувати ідеальний лабіринт. Гарним вибором буде [рекурсивний алгоритм із поверненням][recursive-backtracker].

## Символи для малювання рамок

| Символ | Назва                                  | Unicode |
|:---------:|:--------------------------------------|:--------:|
|     ┌     | рамкові лінії: тонка вниз і праворуч   |  U+250C |
|     ─     | рамкові лінії: тонка горизонтальна     |  U+2500 |
|     ┬     | рамкові лінії: тонка вниз і горизонтальна|  U+252C |
|     ┐     | рамкові лінії: тонка вниз і ліворуч    |  U+2510 |
|     │     | рамкові лінії: тонка вертикальна       |  U+2502 |
|     └     | рамкові лінії: тонка вгору і праворуч  |  U+2514 |
|     ┴     | рамкові лінії: тонка вгору і горизонтальна|  U+2534 |
|     ┘     | рамкові лінії: тонка вгору і ліворуч   |  U+2518 |
|     ├     | рамкові лінії: тонка вертикальна і праворуч |  U+2520 |
|     ⇨     | біла стрілка праворуч                  |  U+21E8 |
