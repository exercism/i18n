# Налагодження

Коли тест не проходить, показується повідомлення з описом того, що пішло не так і для яких вхідних даних.
Ми також можемо скористатися тим, що все, надруковане у «стандартний вивід», теж буде показано.
Записувати у стандартний вивід можна за допомогою `println!`:

```rust
println!("Debug message");
```

Щоб надрукувати значення змінної або виразу, скористаймося фігурними дужками `{}`:

```rust
let secret_number = 4321;
println!("My banking password is {}, which is better than {}.", secret_number, 1200 + 34);
```

Зауважмо, що в такий спосіб можна надрукувати не всі типи, а лише ті, які можна однозначно показати користувачам.
Наприклад, вектори (масиви) так надрукувати не можна, бо незрозуміло, як вектор слід показувати користувачам!
Для цих інших типів можна вказати макросу `println!` використовувати _debug-formatting_ за допомогою `{:?}`.
Це представлення призначене лише для розробників.
Ось приклад:

```rust
let words = vec!["hello", "world"];
println!("words that are often combined: {:?}", words);
```

Є навіть зручний макрос `dbg!`, який дозволяє налагоджувати великі вирази прямо на місці, без потреби розбирати їх на окремі оголошення змінних.

Припустімо, у нас є такий вираз:

```rust
"hello world".split(' ').collect::<Vec<_>>().join("-")
```

Тепер нам хотілося б побачити, що повертає виклик `collect`.
Ми могли б зробити так:

```rust
let my_temporary_debug_variable = "hello world".split(' ').collect::<Vec<_>>();
println!("{:?}", my_temporary_debug_variable);
my_temporary_debug_variable.join("-")
```

Але це марудно!
Нам не хочеться переписувати наші гарні вирази лише для того, щоб їх налагодити.
Вітаємо на сцені: `dbg!`

```rust
dbg!(
    "hello world".split(' ').collect::<Vec<_>>()
).join("-")
```

Пробіли тут лише для наочності.
Можна обгорнути будь-який вираз у `dbg!()`, і він надрукує це значення (з _debug-formatting_).
Після цього можна й далі використовувати це значення у більшому виразі, наче `dbg!` там і не було.

Щасливого налагодження!
