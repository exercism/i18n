## 1. Захопіть інформацію, потрібну для генерації карток, за допомогою регулярних виразів

- `\p{L}` відповідає будь-якій літері з будь-якої мови.
- Можемо використати такий вираз, щоб захопити інформацію:
  ```julia
  re = r"""»(.*)«                     # title
           \ –\ (.*?)                 # name
           (?:\ \((.*?)\)|)           # optional pronouns
           (?:,\ from\ (.*?)|).       # optional organisation
           \ Start:\ (.*?),\          # start time
           (?:Q&A:\ (.*?),\ |)        # optional Q&A time
           End:\ (.*)                 # end time
        """x
  ```
