# Докладніше

Булевий тип у Lua має два традиційні булеві значення (англ. Boolean): `true` і `false`. Ці значення можна присвоїти змінній, поєднувати з логічними операторами (`and`, `or`, `not`) і використовувати в умовних перевірках (наприклад, у керувальних конструкціях).

```lua
local is_true = true
local is_false = false

true and true  --> true
true and false --> false
false or true  --> true
false or false --> false
not false      --> true
not true       --> false

-- prints 0
if is_true == true then
  print(0)
else
  print(1)
end
```

Умовні перевірки та логічні оператори вважають неправдою як булеве `false`, так і `nil`, а будь-що інше - правдою.
```lua
1 and 2          --> 2
nil and 2        --> nil
false and 2      --> false
1 or 2           --> 1
false or 'hello' --> "hello"
nil or false     --> false
```

І `and`, і `or` використовують *скорочене обчислення*: це означає, що вони обчислюють другий операнд лише тоді, коли це потрібно. Усі операції обчислюються згідно з [пріоритетом операторів](https://www.lua.org/manual/5.4/manual.html#3.4.8), де `not` обчислюється раніше за `and` та `or`.

Зважаючи на те, що неправдою вважаються лише `false` і `nil`, а все інше - правдою, поширеною ідіомою в Lua є:
```lua
x = x or y
```

Це рівнозначно запису:
```lua
if not x then
  x = y
end
```

Досить часто це використовують у функціях, щоб присвоїти типове значення, якщо параметр не має значення (дорівнює `nil`):
```lua
local function hello(name)
  name = name or "World"
  print("Hello " .. name)
end

hello()       --> "Hello World"
hello('Mars') --> "Hello Mars"
```
