# Про ColdFusion

ColdFusion (CFML) - це скриптова мова для віртуальної машини Java (JVM), синтаксис якої схожий на C або JavaScript.
Вона проходить JIT-компіляцію в байт-код, який виконується на JVM, але при цьому динамічна та слабко типізована, завдяки чому розробляти нею швидко й просто.
CF - мультипарадигменна мова, яка підтримує класичне обʼєктно-орієнтоване та функціональне програмування.

CFML також має вбудовану мову шаблонів на основі тегів, що робить її ідеальною для вебзастосунків.
Вона працює в контейнері J2EE з багатьма вбудованими бібліотеками, завдяки яким розробка стає дуже продуктивною і не потребує встановлення безлічі пакетів.
CFML має вбудовану підтримку zip-файлів, генерації PDF та Excel, електронних листів, FTP, HTTP, файлових систем S3, бібліотек безпеки ESAPI, драйверів JDBC, JSON і REST API.

CFML також може скористатися будь-яким Java-проєктом: достатньо покласти jar-файли до проєкту й безпосередньо створювати обʼєкти Java у своєму коді.
Більше про базовий синтаксис і вбудовані типи даних можна дізнатися з цього посібника: [Modern ColdFusion (CFML) in 100 Minutes](https://modern-cfml.ortusbooks.com/)
