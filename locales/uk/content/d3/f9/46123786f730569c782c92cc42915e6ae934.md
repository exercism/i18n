# Вказівки

Готуючись спекти печиво для друзів, ми виявили, що доведеться перевести деякі міри, використані в рецепті. Оскільки ми знайомі лише з метричною системою, потрібно придумати спосіб переводити поширені американські кулінарні міри в мілілітри (mL) для власної зручності.

Скористайтеся цією таблицею переведення у своєму рішенні:

| Unit to convert | volume | in milliliters (mL) |
| --------------- | ------ | ------------------- |
| mL              | 1      | 1                   |
| US cup          | 1      | 240                 |
| US fluid ounce  | 1      | 30                  |
| US teaspoon     | 1      | 5                   |
| US tablespoon   | 1      | 15                  |

Як талановиті програмісти-початківці, ми вирішуємо використати мілілітри як проміжну одиницю, щоб спростити переведення з будь-якої наведеної одиниці в будь-яку іншу (навіть у ту саму).

## 1. Отримати числовий компонент із пари обʼєму

Реалізуйте функцію `KitchenCalculator.get_volume/1`. Отримавши кортеж із парою обʼєму, вона повинна повернути лише числовий компонент.

```elixir
KitchenCalculator.get_volume({:cup, 2.0})
# => 2.0
```

## 2. Перевести пару обʼєму в мілілітри

Реалізуйте функцію `KitchenCalculator.to_milliliter/1`. Отримавши кортеж із парою обʼєму, вона повинна перевести обʼєм у мілілітри за допомогою таблиці переведення.

Використайте кілька визначень функції та зіставлення зі зразком, щоб створити функції для кожної одиниці. Атоми, якими позначається кожна одиниця: `:cup`, `:fluid_ounce`, `:teaspoon`, `:tablespoon`, `:milliliter`. Поверніть результат переведення, загорнутий у кортеж.

```elixir
KitchenCalculator.to_milliliter({:cup, 2.5})
# => {:milliliter, 600.0}
```

## 3. Перевести пару обʼєму в мілілітрах в іншу одиницю

Реалізуйте функцію `KitchenCalculator.from_milliliter/2`. Отримавши кортеж із парою обʼєму та потрібну одиницю, вона повинна перевести обʼєм у потрібну одиницю за допомогою таблиці переведення.

Використайте кілька визначень функції та зіставлення зі зразком, щоб створити функції для кожної одиниці. Атоми, якими позначається кожна одиниця: `:cup`, `:fluid_ounce`, `:teaspoon`, `:tablespoon`, `:milliliter`

```elixir
KitchenCalculator.from_milliliter({:milliliter, 1320.0}, :cup)
# => {:cup, 5.5}
```

## 4. Перевести з будь-якої одиниці в будь-яку іншу

Реалізуйте функцію `KitchenCalculator.convert/2`. Отримавши кортеж із парою обʼєму та потрібну одиницю, вона повинна перевести заданий обʼєм у потрібну одиницю.

```elixir
KitchenCalculator.convert({:teaspoon, 9.0}, :tablespoon)
# => {:tablespoon, 3.0}
```
