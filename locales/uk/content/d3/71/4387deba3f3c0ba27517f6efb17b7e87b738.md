# Вступ

Pyret має два окремі булеві примітиви (англ. Boolean): `true` та `false`.
Ці два значення вказують, чи є твердження або умова правильною.

```pyret
"a" == "a" # true
"a" == "b" # false
```

Pyret надає оператори `and` та `or`, які можуть поєднувати булеві значення.

Оператор `and` повертає правду, якщо обидві сторони правдиві, і неправду для всіх інших комбінацій.

```pyret
true and true # true
true and false # true
false and true # false
false and false # false
```

Оператор `or` повертає правду, якщо принаймні одна сторона правдива, і неправду, якщо обидві сторони неправдиві.

```pyret
true or true # true
true or false # true
false or true # true
false or false # false
```

`not()` - це вбудована функція, яка змінює правду на неправду або неправду на правду.

```pyret
not(true) # false
not(false) # true
```
