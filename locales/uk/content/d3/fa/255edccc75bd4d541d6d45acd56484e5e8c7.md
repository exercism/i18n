# Встановлення

## Windows (рекомендовано)

Чи йдеться про операційну систему Windows?

Натисніть `Windows Key`, введіть `cmd` і натисніть `enter`.

> Batch уже встановлено в системі, якщо операційна система - Windows.

Якщо ми використовуємо іншу операційну систему, Batch можна встановити, виконавши наведені нижче інструкції.

## Mac OS

1. Gatekeeper не має блокувати непідписані пакети.
2. Відкрийте програму Terminal.
3. Виконайте таку команду, щоб установити Batch:

```bash
brew install --cask --no-quarantine wine-stable
```

## Ubuntu

1. Якщо система 64-бітна, увімкніть 32-бітну архітектуру (якщо ще не ввімкнули):

```bash
sudo dpkg --add-architecture i386
```

2. Додайте репозиторій WineHQ:

```bash
sudo mkdir -pm755 /etc/apt/keyrings
sudo wget -O /etc/apt/keyrings/winehq-archive.key https://dl.winehq.org/wine-builds/winehq.key
sudo apt update
```

3. Установіть WineHQ:

```bash
sudo apt install --install-recommends winehq-stable
```

## Fedora

1. Увімкніть репозиторій Wine:

```bash
# Fedore 39
dnf config-manager --add-repo https://dl.winehq.org/wine-builds/fedora/39/winehq.repo

# Fedora 40
dnf config-manager --add-repo https://dl.winehq.org/wine-builds/fedora/40/winehq.repo
```

2. Установіть WineHQ:

```bash
dnf install winehq-stable
```
