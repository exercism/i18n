# Інструкції

Ваш струнний ансамбль дає концерт, і комусь треба написати програму.

Усі пʼять завдань потрібно виконати в класі `PROGRAMME_NOTES`.

## 1. Назвіть твір і його автора

Спочатку назва твору, потім ` by `, а потім імʼя композитора.

```sather
PROGRAMME_NOTES::full_title("Nocturne", "Chopin")
-- => "Nocturne by Chopin"
```

## 2. Виміряйте рядок

Друкареві треба знати довжину рядка.

```sather
PROGRAMME_NOTES::title_length("Nocturne")
-- => 8
```

## 3. Перші кілька літер

Отримавши назву та число, поверніть стільки літер від початку.

```sather
PROGRAMME_NOTES::opening_letters("Nocturne", 3)
-- => "Noc"
```

## 4. Останні кілька літер

Те саме, але рахунок від кінця.

```sather
PROGRAMME_NOTES::closing_letters("Nocturne", 4)
-- => "urne"
```

## 5. Скоротіть довгу назву

Назви, які не вміщуються, обрізають до перших шести літер, а після них ставлять три крапки.

```sather
PROGRAMME_NOTES::short_title("Nocturne in E flat")
-- => "Noctur..."
```
