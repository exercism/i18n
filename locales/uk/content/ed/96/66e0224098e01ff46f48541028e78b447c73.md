# Про мову

[Clojure](http://clojure.org) - динамічна мова програмування, що виконується на Java Virtual Machine (JVM).
Задумана як мова загального призначення, Clojure поєднує доступність скриптової мови з надійною інфраструктурою для багатопотокового програмування.

Clojure - переважно функціональна мова програмування, і вона має багатий набір незмінних персистентних [структур даних](http://clojure.org/data_structures).

Clojure має відкритий код, а інформацію про те, як долучитися до мови, [можна знайти тут](http://clojure.org/contributing).

Річ Гікі, творець Clojure, хотів створити сучасний Lisp для функціонального програмування, симбіотичний з усталеною платформою Java і призначений для конкурентного програмування. Ось так і народилася Clojure.

Ось кілька цитат, які ілюструють цілі Clojure:

* _Гарний дизайн - це не про грандіозні плани, а про те, щоб розбирати речі на частини._
* _Програмування - це не про набирання тексту... а про мислення._
