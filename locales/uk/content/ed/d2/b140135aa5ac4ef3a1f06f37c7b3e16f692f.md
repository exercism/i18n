# Про конструкцію `switch`

[Конструкція `switch`][switch] дає змогу порівняти значення з кількома можливими відповідними значеннями. Вона дає змогу писати більш лаконічний код, ніж використовувати кілька конструкцій `else-if`. Конструкція `switch` починається з ключового слова `switch`, після якого йде значення, яке потрібно порівняти. Потім можна визначити випадки за допомогою ключового слова `case`, після якого вказується значення, з яким виконується порівняння. Ключове слово `default` використовується для визначення випадку `default`, коли жоден із випадків не збігається. Як і конструкції `else-if`, конструкції `switch` виконують лише блок коду, повʼязаний із першим відповідним випадком.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Розгляньмо такий приклад:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

Це можна натомість записати так:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

[switch]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#Switch
