# Вступ

Увесь код на Common Lisp складається з S-виразів (символічних виразів). Для стислості їх називають sexpr. Кожен sexpr - це або атом, або cons. Коли S-вирази обчислюються, вони автоматично повертають певне значення, яке займає місце виразу. Коли ми пишемо власні функції (за допомогою `defun`), останнє значення в тілі `defun` автоматично повертається:

```lisp
;; Defining a new function
(defun gimme-foo () 'foo)
;; Calling the function as an S-Expression
(gimme-foo) ; => FOO
```
