# Інструкції

Ми розмічаємо пішохідну стежку в чагарнику. Відстані та спостереження надходять як послідовності, тож і те, і те є ітераторами.

Усі чотири належать класу `BUSH_WALK`. Кожен із них є ітератором, тому кожна назва закінчується знаком `!`.

## 1. Маркери

`markers!` приймає відстань між маркерами в метрах і кількість, а повертає відстань кожного маркера від початку.

```sather
loop
   #OUT + BUSH_WALK::markers!(100, 3) + " ";
end;
-- 100 200 300
```

Кількість нуль не повертає нічого взагалі.

## 2. Поки стежка не закінчиться

`until_end!` приймає спостереження вздовж стежки й повертає їх по одному, зупиняючись, коли натрапляє на `"end"`. Сам `"end"` не повертається.

```sather
loop
   #OUT + BUSH_WALK::until_end!(|"gum", "wattle", "end", "banksia"|) + " ";
end;
-- gum wattle
```

Якщо `"end"` немає, він повертає все.

## 3. Лише птахи

`birds!` приймає спостереження й повертає лише ті, що починаються з великої літери, адже саме так у цьому обліку записують птахів.

```sather
loop
   #OUT + BUSH_WALK::birds!(|"gum", "Emu", "wattle", "Galah"|) + " ";
end;
-- Emu Galah
```

## 4. З номерами

`numbered!` приймає спостереження й повертає кожне з його позицією попереду, рахуючи від одиниці.

```sather
loop
   #OUT + BUSH_WALK::numbered!(|"gum", "Emu"|) + " ";
end;
-- 1. gum 2. Emu
```
