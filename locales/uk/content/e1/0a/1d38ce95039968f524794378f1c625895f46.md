# Інструкції

У цій вправі ми будемо писати код, щоб допомогти компанії з виготовлення вивісок створювати індивідуальні повідомлення для їхніх вивісок.

## 1. Створіть вивіску для урочистості

Реалізуйте метод `build_sign( )`, який приймає рядок тексту (англ. string) як параметр `occasion` і рядок тексту, що містить чиєсь імʼя, як параметр `name`. Ці два параметри буде вбудовано в шаблонний рядок, щоб вивести повідомлення на вивісці.

```abap
build_sign( occasion = 'Birthday' 
            name     = 'Rob').
" => "Happy Birthday Rob!"
```

## 2. Створіть вивіску на день народження

Реалізуйте метод `build_birthday_sign( )`, який приймає вік і на основі віку визначає частину повідомлення на вивісці. Якщо вік 50 або більше, вивіска міститиме слово _mature_, інакше вивіска міститиме слово _young_.

```abap
build_birthday_sign( 45 ).
" => "Happy Birthday! What a young fellow you are."
```

## 3. Створіть вивіску для випускного

Реалізуйте метод `graduation_for( )`, який приймає імʼя як параметр типу рядок тексту та рік як числовий параметр і використовує шаблонні рядки, щоб створити фразу для вивіски, яка використовує символ нового рядка для розділення двох рядків повідомлення.

```abap
graduation_for( name = 'Hannah' 
                year = 2022 ).
" => "Congratulations Hannah!\nClass of 2022"
```

## 4. Обчисліть вартість вивіски

Реалізуйте функцію `cost_of( sign currency )`, яка приймає рядок тексту, що містить вміст вивіски, і рядок тексту, що представляє валюту.
Вивіска має базову ціну 20 у заданій валюті. Крім того, кожна літера коштує 2. (Пробіли враховуються в розрахунку.)
Повернута фраза містить вартість створення вивіски, записану з двома цифрами після десяткової крапки, після чого йде рядок тексту валюти.

```abap
costOf( sign     = 'Happy Birthday Rob!'
        currency = 'euros');
// => "Your sign costs 58.00 euros."
```
