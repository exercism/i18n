# Детальніше

[Цикл `while`][while-loops] — це інструкція керування потоком виконання, яка дозволяє виконувати код, поки певна умова правдива.
Swift надає два види циклів `while`: цикл `while` і цикл `repeat-while`.
Умова циклу `while` обчислюється перед виконанням тіла циклу; якщо умова неправдива, тіло циклу не виконається взагалі.
Цикли `while` у Swift мають таку структуру:

```swift
while <#condition#> {
  <#code#>
}
```

Тут цикл буде виконуватися, поки `count` більше за 0, і таким чином виведе числа 2, 1 і «Liftoff!».

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

[Цикл `repeat-while`][while-loops] схожий на цикл `while`, але умова обчислюється після виконання тіла циклу.
Це означає, що тіло циклу завжди виконається принаймні один раз, навіть якщо умова неправдива.
Цикли `repeat-while` у Swift мають таку структуру:

```swift
repeat {
  <#code#>
} while <#condition#>
```

Тут цикл виконається лише один раз, оскільки умова неправдива.
Оскільки це цикл `repeat-while`, тіло циклу виконається один раз перед тим, як умову буде обчислено.

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```
