# Тести

Перейдіть до каталогу, що містить потрібний файл `${slug}_test.sql`, де `${slug}` позначає назву вправи, записану малими літерами, у якій замість пробілів стоять дефіси (наприклад, `hello-world_test.sql` для вправи `Hello World`).

```bash
sqlite3 -bail < ${slug}_test.sql
```

Для налагодження можна використовувати інструкції `SELECT`.
Вихідні дані буде передано до `user_output.md` і показано у вебредакторі, якщо тести не пройдуть.

Більше інформації можна знайти в [документації треку sqlite про тестування](https://exercism.org/docs/tracks/sqlite/tests).
