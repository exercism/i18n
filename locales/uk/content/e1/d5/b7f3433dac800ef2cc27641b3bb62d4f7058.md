# Вступ

Простори імен - важливий засіб організації коду.
У двох функцій може виникнути конфлікт імен, який можна розвʼязати, розмістивши їх у різних просторах імен.
Простори імен можуть бути вкладеними, і це допомагає структурувати великі кодові бази.
Доступ до просторів імен здійснюється через оператор розвʼязання області видимості `::`.

У прикладі нижче показано використання двох різних функцій `foo`.
Щоб використати їх разом, перед назвою кожної дописують відповідний простір імен.

```cpp
namespace my_ns {
    int foo() {
        return 44;
    }
    namespace my_inner_ns {
        int baz() {
            return 90;
        }
    }
}
namespace my_other_ns {
    int foo() {
        return -2;
    }
}

int myresult{my_ns::foo() + my_other_ns::foo() * my_ns::my_inner_ns::baz()};
```
