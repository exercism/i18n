# Докладніше

## Загальний синтаксис

Цикл `for` належить до найпоширеніших інструкцій для багаторазового виконання певної логіки.
У Go він складається з ключового слова `for`, заголовка та блоку коду, який містить тіло циклу, узяте у фігурні дужки.
Заголовок складається з трьох компонентів, розділених крапками з комою `;`: init, condition і post.

```go
for init; condition; post {
  // loop body - code that is executed repeatedly as long as the condition is true
}
```

- Компонент **init** містить код, який виконується лише один раз перед початком циклу.
- Компонент **condition** має бути виразом, який обчислюється у булеве значення (англ. Boolean) і визначає, коли цикл повинен зупинитися.
  Код усередині циклу виконуватиметься, доки ця умова має значення правда.
  Щойно цей вираз набуде значення неправда, цикл більше не виконає жодної ітерації.
- Компонент **post** містить код, який виконується в кінці кожної ітерації.

**Примітка:** На відміну від інших мов, три компоненти заголовка не оточуються круглими дужками (`()`).
Насправді, якщо поставити такі дужки, це спричинить помилку компіляції.
Однак фігурні дужки (`{ }`), які оточують тіло циклу, обовʼязкові завжди.

## Приклад циклу `for`

Компонент **init** зазвичай створює змінну-лічильник, компонент **condition** перевіряє, чи продовжувати цикл, чи зупиняти, а компонент **post** зазвичай інкрементує лічильник наприкінці кожного повторення.

```go
for i := 1; i < 10; i++ {
  fmt.Println(i)
}
```

Цей цикл виведе числа від `1` до `9` (включно з `9`).
Крок часто задають інструкціями інкременту або декременту, як показано в прикладі вище.

## Необовʼязкові компоненти заголовка

Компоненти **init** і **post** у заголовку необовʼязкові:

```go
var sum = 1
for sum < 1000 {
	sum += sum
}
fmt.Println(sum)
// Output: 1024
```

Якщо в циклі `for`, як показано вище, опустити компоненти **init** і **post**, ми створимо цикл `while` у Go.
Ключового слова `while` тут немає.
Це приклад принципу Go про те, що концепції мають бути ортогональними.
Оскільки вже є концепція, яка дає змогу досягти поведінки циклу `while`, а саме цикл `for`, то `while` не стали додавати як окрему концепцію.

## `break` і `continue`

Усередині тіла циклу можна використати ключове слово `break`, щоб повністю зупинити виконання циклу:

```go
for n := 0; n <= 5; n++ {
  if n == 3 {
    break
  }
  fmt.Println(n)
}
// Output:
// 0
// 1
// 2
```

Натомість ключове слово `continue` зупиняє лише виконання поточної ітерації та переходить до наступної:

```go
for n := 0; n <= 5; n++ {
  if n%2 == 0 {
    continue
  }
  fmt.Println(n)
}
// Output:
// 1
// 3
// 5
```

## Нескінченний цикл `for`

Частина заголовка циклу з умовою теж необовʼязкова.
Більше того, цикл можна записати й зовсім без заголовка:

```go
for {
  // Endless loop...
}
```

Такий цикл завершиться лише тоді, коли програма вийде або коли в його тілі є `break`.

## Мітки та `goto`

Коли ми використовуємо `break`, Go зупиняє найвнутрішніший цикл.
Так само, коли ми використовуємо `continue`, Go переходить до наступної ітерації найвнутрішнішого циклу.

Однак така поведінка підходить не завжди.
Ми можемо використовувати мітки разом із `break` та `continue`, щоб точно вказати, з якого циклу ми хочемо вийти або в якому продовжити.

У цьому прикладі ми створюємо мітку `OuterLoop`, яка вказує на найзовнішіший цикл.
У найвнутрішнішому циклі, щоб сказати, що ми хочемо вийти із найзовнішішого циклу, ми використовуємо `break`, а після нього назву мітки найзовнішішого циклу:

```go
OuterLoop:
    for i := 0; i < 10; i++ {
        for j := 0; j < 10; j++ {
            // ...
            break OuterLoop
        }
    }
```

Мітки працюють і з `continue`: у цьому разі Go перейде до наступної ітерації циклу, на який вказує мітка.

У Go також є ключове слово `goto`, яке працює подібно та дозволяє перестрибнути з одного фрагмента коду до іншого, позначеного міткою.

**Застереження:** Хоча Go дозволяє перестрибнути до фрагмента коду, позначеного міткою, використання цієї можливості мови може легко зробити код дуже важким для читання.
Тому мітки часто не рекомендують використовувати.
