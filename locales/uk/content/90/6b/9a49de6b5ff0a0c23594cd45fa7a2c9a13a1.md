# Інструкції

ESA (Космічне агентство Exercism) на повній швидкості планує нову місію до [Фобоса][phobos], супутника Марса.
Мета місії - посадити зонд на поверхню Фобоса й надіслати назад дані про цю поверхню.
ESA попросила нас допомогти створити навігаційний компʼютер для зонда.
Навігаційний компʼютер має обмежену памʼять, тож нам потрібно якомога зменшити використання памʼяті.
Тому нам потрібно використовувати відповідні типи даних.

## 1. Константи навігації

Навігаційному компʼютеру потрібно знати відстань між деякими обʼєктами в космосі, щоб виконувати правильні обчислення; відстань вимірюється в кілометрах.

Визначте такі константи:

- `NEPTUNE_DISTANCE` зі значенням `4_400_000_000`, яке потрібно зберігати як `Int64`
- `MARS_DISTANCE` зі значенням `227_940_000`, яке потрібно зберігати як `Int32`
- `ATMOSPHERE_DISTANCE` зі значенням `10_000`, яке потрібно зберігати як `Int16`

## 2. Правильний аналіз площі

Навігаційному компʼютеру потрібно знати площу деяких обʼєктів у космосі, щоб виконувати правильні обчислення.
Площа **НЕ** може бути відʼємною.
Інженери планували, що програма генеруватиме помилку переповнення, коли площа відʼємна.
Однак інженери забули змінити ціле число зі знаком на беззнакове ціле число.

Тому інженери хочуть програму, яка перетворює ціле число зі знаком на беззнакове ціле число.

Реалізуйте метод `Navigation#correct_area_analysis`, який приймає `measurement` як аргумент і повертає площу як беззнакове ціле число з 32 бітами.

~~~~exercism/note
Надана площа завжди поміститься в беззнакове ціле число з 32 бітами.
~~~~

```crystal
measurement = 52554
measurement.class
# => Int32

Navigation.new.correct_area_analysis(measurement)
# => 52554

Navigation.new.correct_area_analysis(measurement).class
# => UInt32
```

## 3. Обчислення швидкості

Навігаційному компʼютеру потрібно знати швидкість зонда.
Швидкість вимірюється в м/с.

Щоб обчислити швидкість, нам потрібно знати пройдену відстань і час, за який її пройдено.
Далі беремо відстань і ділимо її на час.

Швидкість може бути не зовсім точною й ніколи не буде надто великим числом.
Тому ми можемо використати `Float32`.

Реалізуйте метод `Navigation#calculate_velocity`, який приймає `distance` і `time` як аргументи й повертає швидкість як `Float` з 32 бітами.

```crystal
distance = 52554
time = 2.5

Navigation.new.calculate_velocity(distance, time)
# => 21021.6

Navigation.new.calculate_velocity(distance, time).class
# => Float32
```
