# Інструкції

Реалізуйте обчислювач для дуже простої підмножини Forth.

[Forth][forth] - це стекова мова програмування.
Реалізуйте дуже базовий обчислювач для невеликої підмножини Forth.

Обчислювач має підтримувати такі слова:

- `+`, `-`, `*`, `/` (арифметика з цілими числами)
- `DUP`, `DROP`, `SWAP`, `OVER` (маніпуляції зі стеком)

Використайте кортеж як стек, щоб уникнути кодів операцій, повʼязаних зі стеком fift та asm.

Щоб спростити, єдиний тип даних, який потрібно підтримувати, - знакові цілі числа розміром щонайменше 16 бітів.

Для синтаксису слід використовувати такі правила: число - це послідовність однієї або більше (ASCII) цифр, слово - це послідовність однієї або більше літер, цифр, символів або розділових знаків, яка не є числом.
(Forth, імовірно, використовує трохи інші правила, але це досить близько.)
