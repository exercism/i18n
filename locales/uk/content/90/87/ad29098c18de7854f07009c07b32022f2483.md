## Тернарні оператори

_Тернарний оператор_ дає легку, компактну альтернативу простим умовним конструкціям _if/else_. Зазвичай його використовують в інструкціях повернення (але не тільки в них); йому потрібен лише один рядок, щоб зробити вибір: повернути ліве значення, якщо вираз дорівнює `true`, і праве, якщо `false`, ось так:

```java
boolean expr = 0 != 200;

// Ternary statement
int value = expr ? 22 : 33;
// => 22
```

Багато простих виразів _if/else_ можна спростити за допомогою _тернарних операторів_.
