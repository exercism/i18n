# Докладніше

[Запис][records] - це сукупність полів (які можуть мати різні типи), що логічно поєднані між собою. Щоб [визначити запис][define], використовується ключове слово `type`. Поля запису визначаються між символами `{` і `}`, і кожне поле має імʼя _і_ тип.

```fsharp
type Address =
    { Street: string
      HouseNumber: int }
```

Щоб [створити запис][create], потрібно вказати назви полів і присвоїти їм значення між символами `{` і `}`. Під час створення запису всім полям потрібно присвоїти значення. Поля можна вказати в будь-якому порядку, вони не мусять збігатися з порядком у визначенні типу запису. Щоб отримати доступ до значень полів примірника запису, використовується точкова нотація.

```fsharp
let oldAddress: Address =
    { Street = "Main Street"
      HouseNumber = 17 }

oldAddress.Street      // => "Main Street"
oldAddress.HouseNumber // 17
```

Коли ми визначаємо або створюємо запис, кожне поле має бути або в окремому рядку, або відокремлене крапками з комою (`;`), якщо все в одному рядку:

```fsharp
type Address = { Street: string; HouseNumber: int }

let oldAddress: Address = { Street = "Main Street"; HouseNumber = 17 }
```

Якщо назви полів запису унікальні, анотації типів необовʼязкові, бо компілятор зможе автоматично вивести тип. Якщо комбінація назв полів _не_ унікальна, можна допомогти компілятору вибрати правильний запис: або вказати явний тип для привʼязки запису, або додати перед одним чи кількома полями назву типу запису:

```fsharp
type Boat = { Weight: int; Length: int }
type Car = { Weight: int; Length: int }

// Let compiler infer type. As there are multiple matching record types,
// the last matching type is used (Car)
let typeEqualsLastMatch = { Weight = 5000; Length = 15 }

// Use type annotation on binding to force type to Boat
let typeAnnotation: Boat = { Weight = 5000; Length = 15 }

// Use fully qualified name for field to force type to Boat
let fullyQualifiedField = { Boat.Weight = 5000; Length = 15}
```

Записи незмінні, тому після створення запису його значення полів уже ніколи не зміняться. Якщо треба змінити значення запису, ключове слово `with` дає змогу [створити копію наявного запису, але з новими значеннями для одного чи кількох полів][create].

```fsharp
// Copy the old address but change the house number
let newAddress = { oldAddress with HouseNumber = 86 }
newAddress.Street      // => "Main Street"
newAddress.HouseNumber // => 86
```

Записи мають [_структурну рівність_][equality], тобто два примірники одного запису з однаковими значеннями рівнозначні:

```fsharp
let address1 = { Street = "Main Street"; HouseNumber = 17 }
let address2 = { Street = "Main Street"; HouseNumber = 17 }
let address3 = { Street = "Broadway"; HouseNumber = 17 }

address1 = address2 // => true
address1 = address3 // => false
```

Крім доступу до полів запису через точкову нотацію, записи можна також _деконструювати_ в привʼязках і під час зіставлення зі зразком за допомогою [зразка запису][record-patterns]:

```fsharp
let myAddress = { Street = "Broadway"; HouseNumber = 123 }
let { Street = myStreet; HouseNumber = myHouseNumber } = myAddress

match myAddress with
| { HouseNumber = 1 } -> printfn "First house"
| { HouseNumber = houseNumber; Street = street } -> printfn "House number %d on %s" houseNumber street
// => "House number 123 on Broadway
```
