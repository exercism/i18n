# Про класи

Основною обʼєктно-орієнтованою конструкцією в Java є _клас_, що поєднує дані ([_поля_][fields]), які також називають змінними екземпляра, і поведінку ([_методи_][methods]).
Поля та методи класу називають його _членами_.

Доступом до членів можна керувати за допомогою модифікаторів доступу. Два найпоширеніші з них:

- [`public`][public]: член доступний будь-якому коду (жодних обмежень).
- [`private`][private]: член доступний лише коду в тому самому класі.

У Java, якщо модифікатор доступу не вказано, типовою є _видимість у межах пакета_.
У цьому разі член видимий для всіх класів, визначених у тому самому пакеті.

Описане вище обʼєднання повʼязаних даних і поведінки разом з обмеженням доступу до членів називають [_інкапсуляцією_][encapsulation], яка є одним із основних понять обʼєктно-орієнтованого програмування.

Клас можна уявити як шаблон для створення екземплярів цього класу.
Щоб [створити екземпляр класу][creating-objects] (його ще називають _обʼєктом_), використовують [ключове слово `new`][new]:

```java
class Car {
}

// Create two car instances
Car myCar = new Car();
Car yourCar = new Car();
```

[Поля][fields] мають тип та імʼя (їх записують у [camelCase][camel-case]) і можуть бути визначені будь-де в класі (записують у [PascalCase][pascal-case]).

```java
class Car {
    // Accessible by anyone
    public int weight;

    // Only accessible by code in this class
    private String color;
}
```

Полю можна за бажанням присвоїти початкове значення.
Якщо поле _не_ вказує початкового значення, йому буде встановлено [типове значення][default-values] його типу.
Значення полів екземпляра можна читати й оновлювати за допомогою точкової нотації.

```java
class Car {
    // Will be set to specified value
    public int weight = 2500;

    // Will be set to default value (0)
    public int year;
}

Car newCar = new Car();
newCar.weight; // => 2500
newCar.year;   // => 0

// Update value of the field
newCar.year = 2018;
```

Приватні поля зазвичай оновлюються як побічний ефект виклику методу.
Такі методи зазвичай не повертають жодного значення, і тоді тип поверненого значення має бути [`void`][void]:

```java
class CarImporter {
    private int carsImported;

    public void importCars(int numberOfCars)
    {
        // Update private field
        carsImported = carsImported + numberOfCars;
    }
}
```

Зауважмо, що в класах Java не прийнято використовувати поля `public`.
Зазвичай використовують приватні поля, доступ до яких отримують через [_гетери_ та _сетери_][so-getters-setters].

Усередині класу [ключове слово `this`][this] вказує на поточний клас.
Це особливо зручно, коли параметр має те саме імʼя, що й поле:

```java
class CarImporter {
    private int carsImported;

    public void setImportedCars(int carsImported)
    {
        // Update private field from public method
        this.carsImported = carsImported;
    }
}
```
