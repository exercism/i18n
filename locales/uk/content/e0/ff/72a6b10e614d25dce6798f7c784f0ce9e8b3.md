# Вступ

Цикл `for` дозволяє багаторазово виконувати код, доки не виконається умова.

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

Цикл `for` складається з чотирьох частин:

1. Ініціалізатор: виконується один раз перед входом у цикл. Зазвичай використовується для визначення змінних, які використовуються всередині циклу.
2. Умова: виконується перед кожною ітерацією циклу. Цикл продовжує виконуватися, доки умова дорівнює `true`.
3. Ітератор: виконується після кожної ітерації циклу. Зазвичай використовується для зміни (часто: інкременту чи декременту) змінної (змінних) циклу.
4. Тіло циклу: код, який виконується на кожній ітерації циклу.
