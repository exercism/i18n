## Загальне

- Документація Python про [засоби керування потоком][control flow tools] і туторіал Real Python про [умовні конструкції][real python conditionals] - чудові місця, з яких варто почати.
- Документація Python про [булеві операції (англ. Boolean)][boolean operations] може стати чудовим нагадуванням про `bools`, як і туторіал Real Python про [булеві значення][python booleans].
- Документація Python про [порівняння][comparisons] і [приклади порівнянь][python comparisons examples] можуть стати чудовим нагадуванням про порівняння.

## 1. Перевірте критичність

- Оператори порівняння ([порівняння][comparisons review]) і булеві операції ([concept:python/bools]()) можна поєднувати та використовувати разом з умовами.
- Умовні вирази повинні обчислюватися до `True` або `False`.
- `else` можна використати для блоку коду, який виконається, коли всі умовні перевірки повернуть `False`.

  ```python
     >>> item = 'blue'
     >>> item_2 = 'green'
     
     >>>  if len(item) >= 3 and len(item_2) < 5:
            print('Both pass the test!')
          elif len(item) >= 3 or len(item_2) < 5:
            print('One passes the test!')
          else:
            print('None pass the test!')
    ...
    One passes the test!
  ```

## 2. Визначте діапазон вихідної потужності

- Оператори порівняння можна поєднувати й використовувати разом з умовами.
- Будь-яку кількість інструкцій `elif` можна використати як «гілки» рішень.
- Кожна «гілка» може мати окремий `return`, хоча інструменти лінтингу можуть вважати це поганим стилем.
- Якщо лінтер скаржиться, спробуйте присвоїти вихідні дані гілки спільній змінній, а потім повернути цю змінну через `return`.

## 3. Запобіжний механізм

- Оператори порівняння можна поєднувати й використовувати разом з умовами.
- Будь-яку кількість інструкцій `elif` можна використати як «гілки» рішень.
- Кожна «гілка» може мати окремий `return`, хоча інструменти лінтингу можуть вважати це поганим стилем.
