# Підказки

## Загальне

- Перші шість цілочисельних аргументів передаються функції в `rdi`, `rsi`, `rdx`, `rcx`, `r8` та `r9`.
- Адреси в памʼяті мають розмір 64 біти (8 байтів).

## 1. Створити запис для кожної речі

- Перші шість цілочисельних аргументів передаються функції в `rdi`, `rsi`, `rdx`, `rcx`, `r8` та `r9`.
- Адреси в памʼяті мають розмір 64 біти (8 байтів).
- Усі цілочисельні аргументи після шостого передаються через стек, і перший із них можна знайти в `rsp + 8`.
- Кількість додаткових аргументів дорівнює кількості категорій, яку передано в `r9`.
- Можемо пройтися циклом і додати додаткові аргументи по одному, або скористатися [movsq][movs] у поєднанні з [rep][rep].

## 2. Зарезервувати місце для щомісячного списку речей

- Перші шість цілочисельних аргументів передаються функції в `rdi`, `rsi`, `rdx`, `rcx`, `r8` та `r9`.
- Адреси в памʼяті мають розмір 64 біти (8 байтів).
- Нам потрібно знати розмір масиву, щоб очистити його байти після виклику функції виділення памʼяті.
- Коли ми викликаємо зовнішню функцію, вона може змінити значення в будь-якому _регістрі, який зберігає викликач_.
- Можемо зберегти значення регістра в стеку за допомогою [push][push] або безпосередньо змінивши `rsp`.
- Будь-яку зміну `rsp`, зокрема зроблену через `push`, потрібно скасувати перед поверненням із функції: або за допомогою [pop][pop], або безпосередньо змінивши `rsp`.

## 3. Вставити річ у щомісячний список

- Перші шість цілочисельних аргументів передаються функції в `rdi`, `rsi`, `rdx`, `rcx`, `r8` та `r9`.
- Адреси в памʼяті мають розмір 64 біти (8 байтів).
- Значення, яке не вміщується в регістр, передається функції через стек.
- Кожен запис для речі займає 120 байтів, що значно більше за максимальний розмір регістра (8 байтів).
- Аргументи, передані через стек, можна знайти за адресами, починаючи з `rsp + 8`.
- Можемо пройтися циклом і додати значення до місця призначення в памʼяті, або скористатися [movsb][movs] у поєднанні з [rep][rep].

## 4. Надрукувати річ

- Перші шість цілочисельних аргументів передаються функції в `rdi`, `rsi`, `rdx`, `rcx`, `r8` та `r9`.
- Адреси в памʼяті мають розмір 64 біти (8 байтів).
- Вступний рядок тексту (англ. string) необовʼязковий: замість нього функції друку можна передати `0`.
- Якщо вступний рядок тексту передано функції друку, він має містити щонайбільше 50 ASCII-символів, уже враховуючи нульовий термінатор (значення `0`).
- Щоразу, коли ми викликаємо функцію, ми маємо зарезервувати місце в стеку для кожного аргументу після шостого.
- System V ABI вимагає, щоб стек був вирівняний на 16 байтів перед викликом функції, що особливо важливо для зовнішніх функцій.
- Кожен запис для речі в списку займає 120 байтів.
