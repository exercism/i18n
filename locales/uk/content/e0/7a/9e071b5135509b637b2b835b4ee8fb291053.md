# Інструкції

У цій вправі ми перевірятимемо дозволи облікових записів користувачів на інтернет-форумі. Форум підтримує три різні дозволи:

- Read
- Write
- Delete

Є три типи облікових записів, кожен із різними типовими дозволами:

- Гості: можуть читати дописи.
- Користувачі: можуть читати й писати дописи.
- Модератори: можуть читати, писати й видаляти дописи, вони мають усі дозволи.

Іноді окремі дозволи можна змінювати. Наприклад, можна надати гостьовому обліковому запису дозвіл також писати дописи, або ж відкликати всі дозволи в облікового запису, і тоді в нього не залишиться жодного дозволу.

## 1. Отримати типові дозволи для типу облікового запису

Спочатку визначте перелік `AccountType`, щоб представити три типи облікових записів: `Guest`, `User` і `Moderator`.

Далі визначте перелік `Permission`, щоб представити три типи дозволів: `Read`, `Write`, `Delete`, і два додаткові: `All` для наявності всіх дозволів і `None` для відсутності жодного дозволу.

Потім реалізуйте (_static_) метод `Permissions.Default()`, який повертає типові дозволи для конкретного типу облікового запису:

```csharp
Permissions.Default(AccountType.Guest)
// => Permission.Read
```

## 2. Надати дозвіл

Реалізуйте (_static_) метод `Permissions.Grant()`, який надає (додає) дозвіл:

```csharp
Permissions.Grant(current: Permission.None, grant: Permission.Read)
// => Permission.Read
```

## 3. Відкликати дозвіл

Реалізуйте (_static_) метод `Permissions.Revoke()`, який відкликає (видаляє) дозвіл:

```csharp
Permissions.Revoke(current: Permission.Read, revoke: Permission.Read)
// => Permission.None
```

## 4. Перевірити наявність дозволу

Реалізуйте (_static_) метод `Permissions.Check()`, який бере поточні дозволи облікового запису й перевіряє, чи авторизований обліковий запис для заданого дозволу:

```csharp
Permissions.Check(current: Permission.Write, check: Permission.Read)
// => false
```
