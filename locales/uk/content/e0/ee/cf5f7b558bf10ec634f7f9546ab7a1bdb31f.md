# Вступ

## Інтерфейс як набір методів

У найпростішому вигляді **інтерфейсний тип** - це набір сигнатур методів.
Ось приклад визначення інтерфейсу, який містить два методи `Add` і `Value`:

```go
type Counter interface {
    Add(increment int)
    Value() int
}
```

Назви параметрів, як-от `increment`, можна опустити у визначенні інтерфейсу, але вони часто підвищують читабельність.

Назви інтерфейсів у Go не містять слова `Interface` чи `I`.
Натомість вони часто закінчуються на `er`, наприклад `Reader`, `Stringer`.

## Реалізація інтерфейсу

Будь-який тип, який визначає методи інтерфейсу, автоматично й неявно «реалізує» цей інтерфейс.
У Go немає ключового слова `implements`.

Наступний тип реалізує інтерфейс `Counter`, який ми бачили вище.

```go
type Stats struct {
    value int
    // ...
}

func (s Stats) Add(v int) {
    s.value += v
}

func (s Stats) Value() int {
    return s.value
}

func (s Stats) SomeOtherMethod() {
    // The type can have additional methods not mentioned in the interface.
}
```

Для реалізації інтерфейсу не має значення, чи має метод ресивер за значенням, чи за вказівником.
(Повернімося до [концепцій методів][concept-methods], якщо тут виникають сумніви.)

> Значення інтерфейсного типу може містити будь-яке значення, яке реалізує ці методи. [^1]

Це означає, що `Stats` тепер можна використовувати в усіх місцях, де приймають інтерфейс `Counter`.

```go
func SetUpAnalytics(counter Counter) {
    // ...
}

stats := Stats{}
SetUpAnalytics(stats)
// works because Stats implements Counter
```

Оскільки інтерфейси реалізуються неявно, тип може легко реалізувати кілька інтерфейсів.
Для цього йому достатньо мати всі потрібні методи.

## Порожній інтерфейс

У Go є один дуже особливий інтерфейсний тип: **порожній інтерфейс**, який не містить жодного методу.
Порожній інтерфейс записують так: `interface{}`.
`any` - це псевдонім для `interface{}`, і його використовують частіше.

Оскільки порожній інтерфейс не має методів, кожен тип реалізує його неявно.
Це допомагає визначати функції, які можуть узагальнено приймати будь-яке значення.
У такому разі параметр функції має порожній інтерфейсний тип.
