# Нотатки про дужки

Tcl - [дуже проста мова](https://tcl.tk/man/tcl8.6/TclCmd/Tcl.htm), але те, як інтерпретатор розбирає код, має кілька підступних крайніх випадків.

## Фігурні дужки

Фігурні дужки в Tcl - це просто спосіб зацитувати блок тексту: цей текст можна інтерпретувати як код або як дані. Усередині фігурних дужок можуть бути вкладені фігурні дужки, але вони мають бути збалансовані. Ось що сказано на сторінці довідки Tcl (man page):

> Фігурні дужки вкладаються всередині слова: на кожну додаткову відкриту фігурну дужку має припадати додаткова закрита фігурна дужка (однак якщо відкрита або закрита фігурна дужка всередині слова _взята в лапки за допомогою зворотного слеша_, то вона не враховується під час пошуку відповідної закритої дужки).

Формулювання там досить конкретне: якщо нам потрібен непарний символ відкритої або закритої фігурної дужки, його треба взяти в лапки за допомогою зворотного слеша. Тож не робіть так:
```tcl
proc isOpenBrace {char} {
    return [expr {$char eq "{"}]
    # ......................^ will not work
}
```
А треба так:
```tcl
proc isOpenBrace {char} {
    return [expr {$char eq "\{"}]
    # ......................^^ will work
}
```

Це може створювати проблеми через те, як Tcl розбирає коментарі, а це відрізняється від більшості мов. Більше про це є на [вікі Tcl](https://wiki.tcl-lang.org/page/Why+can+I+not+place+unmatched+braces+in+Tcl+comments).

## Квадратні дужки

Так само, оскільки Tcl використовує дужки для [підстановки команд.](https://tcl.tk/man/tcl8.6/TclCmd/Tcl.htm#M11), навіть усередині рядків тексту (англ. string) у подвійних лапках треба бути обережними з екрануванням відкритих дужок.

## Круглі дужки

За винятком [змінних асоціативних масивів](https://tcl.tk/man/tcl8.6/TclCmd/Tcl.htm#M12), круглі дужки - це просто звичайні символи.
