# Додаток до інструкцій

## Структура проєкту

* `src` містить рішення вправи
* `spec` містить тести, які запускаються для вправи

## Запуск тестів

Якщо ми в потрібному каталозі (тобто в тому, що містить `src` і `spec`), тести для цієї вправи можна запустити командою `crystal spec`:

```bash
$ pwd
/Users/johndoe/Code/exercism/crystal/hello-world

$ ls
GETTING_STARTED.md README.md          spec               src

$ crystal spec
```

Це запустить усі тестові файли в каталозі `spec`.

У кожному тестовому файлі всі тести, крім першого, пропущено.

Коли тест починає проходити, можна зняти пропуск із наступного, змінивши `pending` на `it`.

## Надсилання рішення

Обовʼязково надішліть вихідний файл із каталогу `src`, коли надсилаєте рішення:

```bash
$ exercism submit src/hello_world.cr
```
