# Приклад

```riscvasm
.equ FRAME_SIZE, 16

.text
.global is_triple
```

Рядки, що починаються з крапки, - це _директиви_: вказівки для асемблера, а не для процесора.
`.equ` дає імʼя `FRAME_SIZE` числу 16.
`.text` указує, що далі йде код.
`.global` робить мітку `is_triple` видимою за межами цього файлу, тож інший код може її викликати.
Можна також побачити `.globl`, який означає те саме.

```riscvasm
/* bool is_triple(unsigned a, unsigned b, unsigned c); */
is_triple:
```

`is_triple` перевіряє, чи `a² + b² = c²`, повертаючи 1, якщо так, і 0 в іншому разі.
Наприклад, `(6, 8, 10)` дає 1, бо `36 + 64 = 100`.
Мітка `is_triple` позначає місце, де починається функція.
Її викликають зі значеннями `a`, `b` і `c` у регістрах `a0`, `a1` і `a2`.

```riscvasm
        addi    sp, sp, -FRAME_SIZE
        sw      ra, 12(sp)      /* save the return address */
        sw      a1, 8(sp)       /* save b */
        sw      a2, 4(sp)       /* save c */
```

Регістр `ra` зберігає _адресу повернення_ - місце у функції, яка нас викликала, куди треба повернутися, коли ми закінчимо.
Кожен `call` перезаписує `ra`, тож спершу ми зберігаємо її в _стеку_.
Стек росте вниз, у бік менших адрес, тож віднімання 16 від покажчика стека `sp` резервує для нас 16 байтів.
(`sp` завжди має бути кратним 16.)
Ми також зберігаємо `b` і `c`, бо функція, яку ми викликаємо, має право змінювати регістри `a`.

```riscvasm
        call    square          /* a0 = a * a */
        sw      a0, 0(sp)       /* save a * a */
```

`a` уже лежить у `a0`, де `square` приймає свої вхідні дані.
`call` записує в `ra` адресу наступної інструкції та переходить до `square`, яка повертає свій результат у `a0`.

```riscvasm
        lw      a0, 8(sp)       /* a0 = b */
        call    square          /* a0 = b * b */
        lw      t0, 0(sp)       /* t0 = a * a */
        add     t0, t0, a0      /* t0 = a * a + b * b */
        sw      t0, 0(sp)       /* save a * a + b * b */
```

Ми завантажуємо `b` назад зі стека, підносимо до квадрата й додаємо до `a * a`.

```riscvasm
        lw      a0, 4(sp)       /* a0 = c */
        call    square          /* a0 = c * c */
        lw      t0, 0(sp)       /* t0 = a * a + b * b */
        sub     a0, t0, a0      /* a0 = a * a + b * b - c * c */
        seqz    a0, a0          /* a0 = 1 if that is zero, otherwise 0 */
```

Різниця дорівнює нулю саме тоді, коли `a² + b² = c²`.
`seqz` («set if equal to zero») перетворює це на 1 або 0.

```riscvasm
        lw      ra, 12(sp)      /* restore the return address */
        addi    sp, sp, FRAME_SIZE
        ret
```

Ми відновлюємо `ra` і повертаємо 16 байтів стека.
Потім `ret` переходить за адресою в `ra`, назад до того, хто викликав.

```riscvasm
/* unsigned square(unsigned n); */
square:
        mul     a0, a0, a0      /* n * n */
        ret
```

`square` не викликає жодної іншої функції, тож `ra` залишається незмінною і зберігати нічого.
Її не позначено як `.global`, бо її використовує лише `is_triple`.
