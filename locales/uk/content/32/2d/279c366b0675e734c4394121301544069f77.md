# Вступ

Іноді не потрібні накладні витрати на створення обʼєкта зі станом.
У таких випадках можна використати `module`.

Модуль дуже схожий на клас (насправді, `Module` є предком `Class` в ієрархії обʼєктів). Головна відмінність полягає в тому, що замість використання методів екземпляра ми використовуємо методи класу.
Методи класу починаються з `self.` і викликаються безпосередньо на модулі.

Наприклад:

```ruby
module Speaker
  def self.echo(something)
    "#{something} ... #{something}"
  end
end

Speaker.echo("Hello")   #=> "Hello ... Hello"
```
