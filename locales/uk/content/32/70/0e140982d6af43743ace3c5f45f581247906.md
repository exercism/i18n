# Докладніше

Пишучи функції в Haskell, ми можемо скористатися [зіставленням зі взірцями][pattern-matching].
Зіставлення зі взірцями - дуже потужна можливість Haskell, яка дає змогу зіставляти значення з конструкторами даних і звʼязувати змінні зі значеннями всередині.
Як підказує назва, ми зіставляємо значення зі взірцями, і якщо значення відповідає взірцю, ми можемо звʼязати змінні зі значеннями всередині цього взірця.
Зіставлення зі взірцями здебільшого складається з таких понять: розпізнавання значень, звʼязування змінних і розкладання значень на частини.

~~~~exercism/note
Зіставлення зі взірцями в таких мовах, як Elixir, дещо відрізняється від зіставлення зі взірцями в Haskell.
Elixir, наприклад, дозволяє використовувати в одному взірці кілька однакових імен звʼязування, а Haskell - ні.
~~~~


Візьмімо для прикладу таку функцію:

```haskell
lucky :: Int -> String
lucky 7 = "Lucky number seven!"
lucky x = "Sorry, you're out of luck, pal!"
```

Тут ми маємо функцію `lucky`, яка приймає `Int` і повертає `String`.
Ми визначили для цієї функції два взірці: один зіставляється з числом `7`, а другий - з будь-яким іншим числом. Імʼя може бути будь-яким (аби воно відповідало угоді про найменування в Haskell), але тут ми використовуємо `x`.
Якщо число дорівнює `7`, функція поверне `"Lucky number seven!"`, інакше вона поверне `"Sorry, you're out of luck, pal!"`.
Важливо зауважити, що взірці перевіряються згори вниз, тож якби ми поміняли їхній порядок, функція завжди повертала б `"Lucky number seven!"`.

## Взірці для списків

Дуже поширений взірець - зіставлення зі списками, а саме взяття голови й хвоста списку.
Це випливає з того, що списки за своєю природою є звʼязаними списками.
Ось приклад функції, яка повертає голову й хвіст списку:

```haskell
headAndTail :: [Int] -> (Int, [Int])
headAndTail [] = error "Can't call head on an empty list"
headAndTail (x:xs) = (x, xs)
```

Тут ми маємо два взірці: один зіставляється з порожнім списком, а другий - зі списком, у якому є принаймні один елемент.
Це тому, що коли список порожній, нам потрібен окремий випадок для нього, інакше ми отримали б помилку під час виконання.
Якщо список не порожній, ми можемо зіставити голову списку з `x`, а хвіст списку - з `xs`.
Для цього використовується оператор `:` (cons), який долучає елемент на початок списку.
Але у зіставленні зі взірцями він дає змогу розкласти список на голову й хвіст, тобто певною мірою зробити протилежне.

Імʼя `xs` - поширена назва для хвоста списку, воно підкреслює, що це список. А якщо ми працюємо з вкладеним списком, можна взяти `xss`, щоб підкреслити, що це список списків.

## Взірці для кортежів

Як і зі списками, ми можемо зіставляти й кортежі.
Ось приклад функції, яка приймає кортеж і повертає його перший і другий елементи:

```haskell
sumTuple :: (Int, Int) -> Int
sumTuple (x, y) = x + y
```

Тут ми маємо взірець, що зіставляється з кортежем із двох елементів: перший елемент звʼязується з `x`, а другий - з `y`.

## Взірці з підстановкою

Іноді значення змінної нам не важливе, і ми просто хочемо зіставити взірець.
Саме тут стає в пригоді взірець із підстановкою, який позначається знаком підкреслення `_`.

Ось приклад функції, яка повертає перший елемент списку:

```haskell
head' :: [Int] -> Int
head' [] = error "Can't call head on an empty list"
head' (x:_) = x
```

Тут ми кажемо, що хвіст списку нам не потрібен, тож використовуємо взірець із підстановкою, щоб його проігнорувати.

## Взірці за типами

Ми також можемо зіставляти за типами, для цього використовується конструктор відповідного типу.
А ще ми можемо вилучати значення з типу, як це робили з кортежами.

```haskell
data AccountType = Guest | User String 

greet :: AccountType -> String
greet Guest = "Welcome, guest!"
greet (User name) = "Welcome, " ++ name ++ "!"
```

У першому взірці ми зіставляємо з конструктором `Guest`, а в другому - з конструктором `User`, звʼязуючи значення всередині з `name`.
