# Вступ

Крім конструкції if, у JavaScript є також конструкція switch, яка дає змогу умовно виконувати логіку.
Її використовують, коли одну змінну треба порівняти з кількома варіантами.
Порівняння відбувається через перевірку строгої рівності (`===`), див. [Порівняння][concept-comparison].
Для деякої змінної `x` конструкція switch у JavaScript має такий синтаксис.

<!-- prettier-ignore-start -->
```javascript
switch (x) {
  case option1:
    // code that is executed when "x === option1" is true
    break;
  case option2:
    // code that is executed when "x === option2" is true
    break;
  default:
    // code that is executed when x does not equal any of the options
}
```
<!-- prettier-ignore-end -->

Гілка `default` необовʼязкова, і її використовують, коли треба виконати якийсь код, якщо жоден з інших варіантів не збігається зі змінною.

Інструкції `break` вище потрібні, бо типово всі гілки `case` у JavaScript «провалюються» далі.
Це означає, що без жодної інструкції `break` виконався б увесь код у тих гілках, які йдуть після першого збігу, навіть якби `x` не збігався з ними.
Така типова поведінка «провалювання» часто стає пасткою, коли ми використовуємо `switch` у JavaScript.
Усередині функції замість `break` можна також використати `return`, щоб уникнути цієї проблеми.
