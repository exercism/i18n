# Вступ

`list` у R - це впорядкована колекція елементів, яка відрізняється від `vectors` кількома особливостями:

- Елементи можуть мати різні типи (наприклад, поєднання `numeric` з `character`).
- Елементами можуть бути складені структури (наприклад, вектори, інші списки тощо).
- Для доступу до елементів є дещо інший синтаксис.

Аналогії з іншими мовами неточні.
`list` у R дещо нагадує словник у Python, але він упорядкований, і звертатися до його елементів можна за числовим індексом.
Він дещо нагадує `struct` у C, хоч `list` можна легко розширити під час виконання.

## Створення списків

Надавати елементам назви (які часто називають «теги») частіше доводиться у списках, ніж у векторах:

```R
list(x = 5.3, y = 4.2, color = "blue")
$x
#> [1] 5.3

$y
#> [1] 4.2

$color
#> [1] "blue"
```

Однак теги необовʼязкові, і тоді R просто використає номери індексів:

```R
list(5.3, 4.2, "blue")
#> [[1]]
#> [1] 5.3

#> [[2]]
#> [1] 4.2

#> [[3]]
#> [1] "blue"
```

## Доступ до елементів списку

Є три способи зробити це, і кожен із них стане в пригоді в тій чи іншій ситуації.

### 1. Нотація `$tag`

Дуже поширений, якщо назви тегів відомі заздалегідь.

```R
point <- list(x = 5.3, y = 4.2, color = "blue")
point$x
#> [1] 5.3
point$color
#> [1] "blue"
```

### 2. Нотація `[[tag]]`

Перевага в тому, що назву тега можна вибрати під час виконання.
Звернімо увагу на подвійні дужки.

```R
want <- "y"
point[[want]] # same as point$y
#> [1] 4.2
```

### 3. За індексом позиції

Це працює незалежно від того, чи має список теги.
Тут також подвійні дужки.

```R
point[[3]] # same as point$color
#> [1] "blue"
```

## Додавання та видалення елементів

Усе просто: присвоєння елементу змінить його, якщо він уже є, або додасть, якщо він новий.

```R
point$color <- "red"
point$trust <- TRUE
str(point)
#> List of 4
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
#>  $ trust: logi TRUE
```

Щоб видалити, присвоймо `NULL` непотрібному елементу.

```R
point$trust <- NULL
str(point)
#> List of 3
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
```
