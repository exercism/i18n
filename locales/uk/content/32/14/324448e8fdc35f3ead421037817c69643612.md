# Інструкції

Плануючи вечір ігор із друзями, компанія вирішує згадати улюблені забави з дитинства. Наш німецький друг пропонує _Mensch ärgere Dich nicht_ (_Людино, не гнівайся_) — класику в багатьох європейських країнах (схожу на англійську _Ludo_ або північноамериканську _Parcheesi_).

Щоб підготуватися до гри, ми вирішуємо реалізувати функцію кидання кубика мовою Elixir.

У _Mensch ärgere Dich nicht_ гравці кидають один шестигранний кубик, щоб визначити свій наступний хід. Якщо пощастить і випаде 6, можна кинути ще раз і знову зробити хід.

## 1. Зробіть один кидок шестигранного кубика

Реалізуйте функцію `d6/0`, яка під час кожного виклику випадково вибиратиме одне ціле число від 1 до 6.

```elixir
MenschAergereDichNicht.d6()
# => 1
MenschAergereDichNicht.d6()
# => 5
```

## 2. Продовжуйте кидати, доки випадає шістка

Реалізуйте функцію `roll/0`. Вона повинна повертати потік кидків кубика. Кидки мають відповідати правилам гри. Якщо випадає шістка, можна кинути ще раз. Інакше припиняємо кидати. Використайте функцію `d6/0`, визначену на попередньому кроці.

```elixir
MenschAergereDichNicht.roll() |> Enum.to_list()
# => [5]
MenschAergereDichNicht.roll() |> Enum.to_list()
# => [6, 3]
```

## 3. Дозвольте використовувати підлаштований кубик

Щоб було легше тестувати свій код, дозвольте використовувати підлаштований кубик.

Розширте функцію `roll/0`. Вона повинна приймати необовʼязковий аргумент, а саме функцію. Якщо аргумент передано, використайте його для кидка. Інакше скористайтеся `MenschAergereDichNicht.d6/0`.

```elixir
MenschAergereDichNicht.roll(fn -> 3 end) |> Enum.to_list()
# => [3]
```
