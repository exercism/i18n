# Вступ

Так само як можна створити покажчик на `int` чи інший базовий тип даних, можна створити покажчик і на функцію.
Покажчик на функцію дозволяє передати функцію в іншу функцію.
Функцію, яку передають як значення параметра в іншу функцію, називають функцією першого класу.
Функцію, яка приймає одну або більше функцій як параметр чи повертає функцію, називають функцією вищого порядку.

У наступному прикладі `is_even` і `is_odd` - функції першого класу.
Функція вищого порядку - це `test_number`.

```c
#include <stdio.h>
#include <stdbool.h>

bool is_even (int number) {
    return number & 1 != 1;
}

bool is_odd (int number) {
    return number & 1 == 1;
}

// this function takes any other function which takes a number and returns a bool
void test_number(bool (*func) (int), int number, char *text){
    printf(text, number, func(number)? "true": "false");
}

int main() {
    // prints Testing odd for 3 is true
    test_number(is_odd, 3,"Testing odd for %d is %s\n");
    // prints Testing even for 3 is false
    test_number(is_even, 3,"Testing even for %d is %s\n");
}
```
Сигнатура функції `bool (*func) (int)` для першого аргументу `test_number` збігається з сигнатурою переданих функцій.
І `is_even`, і `is_odd` приймають параметр `int` і повертають `bool`.
У `(*func)` `func` позначає назву функції, яку буде використано.
Якби використали `(*fn)`, то виклик мав би такий вигляд: `printf(text, number, fn(number)? "true": "false");`.
Щоб задовольнити параметр-покажчик на функцію, під час виклику `test_number` ми передаємо назву функції з очікуваною сигнатурою.
Отже, ми бачимо, що назва функції вказує на адресу цієї названої функції.
