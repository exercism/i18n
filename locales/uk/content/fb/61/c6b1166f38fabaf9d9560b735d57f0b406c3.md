# Основи синтаксису Elm 1

## Константи та функції

Програми Elm складаються з визначень і виразів.
Усе в Elm - це або визначення, або вираз.

Константне значення визначають так: `name = expression`.

```elm
five = 5

six = 3 + 3
```

Функції визначають так: `name parameters... = expression`,
причому параметри розділяються лише пробілами.

```elm
add number1 number2 = number1 + number2
```

Виклик функції також є виразом і виконується так:
вказують її назву й передають аргументи для кожного з параметрів функції,
розділяючи їх пробілами, так само як і у визначенні функції.

```elm
five = add 2 3
```

Дужки можна використовувати, щоб задати порядок обчислення виразу.

```elm
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## Відступи / значущі пробіли

Elm не використовує синтаксичних маркерів, як-от фігурні дужки, круглі дужки чи крапки з комою, щоб позначати межі коду. Замість цього він використовує пробіли та відступи.

- Визначення модулів, імпортів і функцій верхнього рівня повинні починатися з найлівішого стовпця.
- Якщо вираз розбито на кілька рядків, код, що є частиною цього виразу, потрібно відступити під цим виразом щонайменше на один пробіл.
- Частини виразу, згруповані разом, слід відступити на однакову кількість пробілів.

```elm
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://elmprogramming.com/indentation.html

## Модулі

Кожен файл в Elm - це модуль, і він повинен містити інструкцію `module` перед усім іншим кодом.
Назви модулів мають збігатися з назвою їхнього файлу, тож модуль `Calculator` має бути у файлі Calculator.elm.
Усе, визначене в модулі, має приватну область видимості в ньому
й не доступне ззовні цього модуля, якщо його не перелічено в `exposing`.

```elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## Коментарі

Коментар - це текст у файлі Elm, який не інтерпретується як код.
Його переважно читаємо ми самі та інші програмісти.
Для однорядкових коментарів є простий синтаксис на основі двох дефісів.
Багаторядкові коментарі також можливі за допомогою пари
відкривального і закривального роздільників `{-` та `-}`.

```elm
-- a single line comment
-- another single line comment

{- a multiline comment
   spawning multiple lines
-}
```
