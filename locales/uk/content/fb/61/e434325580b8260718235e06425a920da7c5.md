# непотрібні умовні конструкції

У цьому рішенні [умовні конструкції][conditionals] використано без потреби.
Використання [типового аргументу][default argument] разом із [str.format][str.format] або [f-strings][f-strings] (_також відомих як «форматовані рядкові літерали» або «інтерпольовані рядки»_) може зробити код зрозумілішим і менш багатослівним.

Більше подробиць можна знайти в цій публікації про [типові аргументи в Python][python default arguments].
Гарною відправною точкою для знайомства з форматуванням рядків тексту (англ. string) у Python може стати і допис у блозі [форматування рядків тексту в Python][string formatting in python].
