# Про мову

Kotlin розробила компанія JetBrains, яка створила IntelliJ.
Це мова, що працює на JVM і може орієнтуватися на версії 6+ (зокрема на [платформу Android](https://blog.jetbrains.com/kotlin/2017/05/kotlin-on-android-now-official/)).
JetBrains хотіла використовувати статично типізовану мову, яка позбавляє від повторюваного коду Java, надає сучасні функціональні парадигми та має безперешкодну двосторонню сумісність із Java для наявної кодової бази.
Для JVM уже існували інші мови, як-от Groovy і Scala, але жодна з них не відповідала їхнім вимогам, тож вони створили Kotlin.

Синтаксис Kotlin подібний до Scala і Swift, але вбирає найкращі риси інших мов, як-от C# і Groovy.
Kotlin обрала прагматичний підхід до можливостей мови й додала лише ту функціональність, користь якої для розробників доведена.
Ухваливши таке рішення, вони реалізували підмножину можливостей Scala, сподіваючись, що це дасть код, який легше підтримувати, і простішу криву навчання для розробників, які шукають «кращий Java».

У JetBrains є окрема команда розробників, які працюють над Kotlin, а кодова база доступна на [Github](https://github.com/JetBrains/kotlin).
