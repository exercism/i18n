# Докладніше

Фільтрування - це процес створення однієї послідовності з іншої шляхом копіювання всіх елементів початкової послідовності, крім деяких.
Вибір того, які елементи включити до нової послідовності, можна зробити за допомогою функції-предиката (функції, яка обчислюється як булеве значення (англ. Boolean)) або за допомогою перевірки на рівність із конкретним обʼєктом.

## Видалення за допомогою предиката

`remove-if` - це функція, яка приймає функцію-предикат і послідовність як аргументи та повертає послідовність лише тих елементів, для яких предикат обчислюється як неправда.
Інакше кажучи, вона «видаляє» всі елементи послідовності, для яких предикат обчислюється як правда. Однак зауважмо: ця функція не змінює початкову послідовність!
Натомість вона повертає нову послідовність без відповідних елементів. Якщо предикат був правдою для всіх значень, повертається порожня послідовність.

```lisp
(remove-if #'evenp '(1 2 3 4 5)) ; => (1 3 5)
(remove-if #'oddp '(1 3 5))      ; => ()
```

## Збереження елементів за допомогою предиката

Існує функція `remove-if-not`, яка працює так само, як `remove-if`, але *залишає* елементи, для яких предикат обчислюється як правда.

Як альтернативу можна використати `complement`, щоб змінити предикат на його «протилежність».

```lisp
(remove-if #'evenp '(1 2 3 4 5 6))             ; => (1 3 5)
(remove-if-not #'oddp '(1 2 3 4 5 6))          ; => (1 3 5)
(remove-if (complement #'oddp) '(1 2 3 4 5 6)) ; => (1 3 5)
```

## Видалення конкретного елемента

Якщо потрібно видалити конкретний елемент із послідовності, можна скористатися `remove`, яка приймає елемент для видалення та послідовність.
Повертаються всі значення послідовності, які не дорівнюють елементу для видалення.

```lisp
(remove 1 '(1 2 1 3 1 4)) ; => (2 3 4)
(remove #\l "hello")      ; => "heo"
```

Функцію, яку використовувати для перевірки рівності, можна вказати за допомогою [ключового параметра][concept-keyword-parameters] `:test`.

Зауважмо, що `remove` можна реалізувати через `remove-if`, написавши предикат, який перевіряє обʼєкт на рівність із конкретним елементом.

## Багато варіантів

Кожна з цих функцій також приймає багато інших [ключових параметрів][concept-keyword-parameters], які дають змогу працювати лише з підпослідовностями, застосовуватися лише певну кількість разів тощо. За повними подробицями звернімося до [документації Hyperspec][hyperspec-remove]


## Деструктивні варіанти

Крім `remove`, `remove-if` і `remove-if-not`, існують `delete`, `delete-if` і `delete-if-not`, які дають еквівалентний результат, але можуть змінювати передану їм послідовність.
