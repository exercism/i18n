# Інструкції

Нам раптом захотілося млинців.
Як сучасна технічно орієнтована людина, ми пишемо список покупок для інгредієнтів млинців у форматі JSON.
Структура списку така:

```json
{
  "name": "name of shopping list",
  "ingredients": [ ...list of ingredients... ],
  "optional ingredients": [ ...list of ingredients... ]
}
```

Інгредієнт представлено як обʼєкт JSON, наприклад:

```json
{
  "item": "flour",
  "amount": {
    "quantity": 2,
    "unit": "cup"
  }
}
```

Інгредієнт має необовʼязкову властивість з назвою `"substitute"`, яка містить рядок тексту (англ. string) з назвою іншого продукту, який можна використати замість нього.

Погляньмо, як можна дослідити список покупок за допомогою `jq`.

## 1. Витягти назву списку покупок

Напишіть вираз, який виводить елемент «name» зі списку покупок.

## 2. Порахувати, скільки інгредієнтів потрібно

Рахуйте лише «обовʼязкові» інгредієнти. Не включайте необовʼязкові інгредієнти.

## 3. Скільки цукру?

Напишіть вираз, який виводить кількість цукру.
Потрібна лише числова частина.

## 4. Зіставити інгредієнти, які можна замінити

Деякі інгредієнти можна замінити (якщо немає інгредієнта X, можна використати Y).
Виведіть обʼєкт JSON, який зіставляє рекомендований інгредієнт із його заміною.
Включіть необовʼязкові інгредієнти до цього зіставлення.
