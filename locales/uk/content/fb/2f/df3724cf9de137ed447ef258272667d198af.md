# приватні допоміжні функції

[comment]: # (потрібно 2 параметри:)
[comment]: # (- expected: виправлене визначення функції)
[comment]: # (- actual: неправильне визначення функції, яке використав студент)

Публічний інтерфейс кодової бази варто ретельно продумати, адже кожна публічна функція збільшує витрати на довгострокову підтримку та ускладнює рефакторинг.

У кожній вправі Exercism публічний інтерфейс визначає набір тестів.
Якщо функцію тестують, вона має бути публічною.
Усі інші функції мають бути приватними, зокрема функції з тією самою назвою, але іншою арністю.

```elixir
# you defined the following public function

%{actual}

# make it private like this

%{expected}
```
Зауважмо, що типові аргументи змінюють арність функції.

Коли ми пишемо бібліотеку, часто потрібно зробити функції публічними, щоб їх можна було використовувати з інших модулів.
Щоб приховати такі функції від документації, автори бібліотек додають `@doc false` перед визначенням функцій або `@moduledoc false`, щоб приховати весь модуль.
