# Вступ

У Swift не можна індексувати рядок тексту (англ. string) за допомогою цілого числа (наприклад, `string[3]`).
Оскільки рядки тексту в Swift складаються з символів Unicode змінної довжини, щоб знайти символ, потрібно пройти крізь усі попередні символи.

Щоб отримати символ у певній позиції, треба обчислити індекс типу `String.Index`.
Такі індекси називають *непрозорими індексами*, бо їхньою внутрішньою структурою керує Swift, а не ми безпосередньо працюємо з нею як з необробленими цілими числами:

```swift
let csv = "apple,pear,peach,orange,cherry,lime,gooseberry"
let index = csv.index(csv.startIndex, offsetBy: 21)
print(csv[index])
// Prints "g"

print(index)
// Prints internal representation: Index(_rawBits: ...)
```
