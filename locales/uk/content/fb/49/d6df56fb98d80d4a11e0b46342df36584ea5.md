# Докладніше

Інструкція `guard` у Swift призначена для дострокового повернення з функцій Swift, коли не виконано потрібну умову, яку необхідно задовольнити, щоб подальша обробка могла продовжитися, наприклад:

```swift
guard myValue = 0 else { return 0 }
let root = myValue.squareRoot()
```

Тут `guard` перевіряє, чи набуває булевий вираз після ключового слова `guard` значення правда. Якщо так, обробка продовжується кодом, що йде після інструкції `guard` (тут `let root = myValue.squareRoot()`. Інакше буде виконано код у гілці `else`. На відміну від інструкції `if`, інструкція `guard` _мусить_ мати гілку `else`, а на відміну від гілки `else` конструкції if-else, гілка `else` інструкції `guard` _мусить_ вийти за межі області видимості цієї інструкції `guard`. Тобто вона повинна використати інструкцію передачі керування, як-от `return`, `continue`, `break`, або викинути помилку чи завершити програму.

Прикладом такого використання є функція sinc, яка дорівнює sin(x)/x, причому sinc(0) визначено як 1, що дає змогу уникнути проблем із діленням на 0. Цю функцію можна записати мовою Swift, застосувавши `guard` так:

```swift
func sinc(_ x: Double) -> Double {
    guard x != 0 else { return 1 }
    return sin(x) / x
}

sinc(0)              // returns 1
sinc(Double.pi / 2)  // returns 0.6366197723675814
```
