# Вказівки

У цій вправі ми будемо обробляти рядки журналу.

Кожен рядок журналу записано як рядок тексту (англ. string) такого формату: `"[<LVL>]: <MESSAGE>"`.

Ось які бувають рівні журналу:

- `TRC` (trace)
- `DBG` (debug)
- `INF` (info)
- `WRN` (warning)
- `ERR` (error)
- `FTL` (fatal)

На нас чекають три завдання.

## 1. Розбір рівня журналу

Визначте перелік `LogLevel` із шістьма елементами, що відповідають наведеним вище рівням журналу.

- `TRACE`
- `DEBUG`
- `INFO`
- `WARNING`
- `ERROR`
- `FATAL`

Далі реалізуйте метод `LogLine.getLogLevel()`, який повертає розібраний рівень переданого рядка журналу:

```java
var logLine = new LogLine("[INF]: File deleted");
logLine.getLogLevel();
// => LogLevel.INFO
```

## 2. Підтримка невідомого рівня журналу

На жаль, подекуди рядки журналу мають невідомий рівень.
Щоб коректно обробляти такі рядки журналу, додайте елемент `UNKNOWN` до переліку `LogLevel`; його слід повертати під час розбору невідомого рівня журналу:

```java
var logLine = new LogLine("[XYZ]: Overly specific, out of context message");
logLine.getLogLevel();
// => LogLevel.UNKNOWN
```

## 3. Перетворення рядка журналу на короткий формат

Рівень журналу в рядку записано досить громіздко.
Щоб зменшити місце на диску, потрібне для зберігання рядків журналу, було розроблено короткий формат: `"[<ENCODED_LEVEL>]:<MESSAGE>"`.

Закодований рівень журналу отримуємо простим зіставленням рівня журналу з числом:

- `UNKNOWN` - `0`
- `TRACE` - `1`
- `DEBUG` - `2`
- `INFO` - `4`
- `WARNING` - `5`
- `ERROR` - `6`
- `FATAL` - `42`

Реалізуйте метод `LogLine.getOutputForShortLog()`, який виводить рядок журналу в скороченому форматі:

```java
var logLine = new LogLine("[ERR]: Stack Overflow");
logLine.getOutputForShortLog();
// => "6:Stack Overflow"
```
