# Додаток до інструкцій

## Формат вхідних даних

Кожен список вхідних даних подано як рядок тексту (англ. string), завершений нульовим символом, із символом нового рядка в кінці кожного входу.

Наприклад: `"nail\nshoe\nhorse\nrider\nmessage\nbattle\nkingdom\n"`

## Регістри

| Регістр | Використання      | Тип     | Опис                                                              |
| ------- | ----------------- | ------- | ----------------------------------------------------------------- |
| `$a0`   | вхідні дані       | адреса  | вхідний рядок, завершений нульовим символом, з новим рядком після кожного входу |
| `$a1`   | вхідні/вихідні дані | адреса | вихідний рядок, завершений нульовим символом                     |
| `$t0-9` | тимчасові         | будь-який | для тимчасового зберігання                                      |
