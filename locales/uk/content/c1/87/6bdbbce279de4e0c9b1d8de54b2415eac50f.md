# Вступ

Рядки тексту (англ. string) в Elixir обмежуються подвійними лапками і кодуються в UTF-8:

```elixir
"Hi!"
```

Рядки тексту можна зʼєднати за допомогою оператора `<>/2`:

```elixir
"Welcome to" <> " " <> "New York"
# => "Welcome to New York"
```

Рядки тексту в Elixir підтримують інтерполяцію за допомогою синтаксису `#{}`:

```elixir
"6 * 7 = #{6 * 7}"
# => "6 * 7 = 42"
```

Щоб додати символ нового рядка в рядок тексту, використаймо керуючу послідовність `\n`:

```elixir
"1\n2\n3\n"
```

Щоб зручно працювати з текстами, що містять багато символів нового рядка, використаймо натомість синтаксис heredoc із потрійними подвійними лапками:

```elixir
"""
1
2
3
"""
```

Elixir надає багато функцій для роботи з рядками тексту в модулі `String`.
