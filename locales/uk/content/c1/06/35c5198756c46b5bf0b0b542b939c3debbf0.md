# Додаток до інструкцій

## Пакет для сортування

У цій вправі потрібно відсортувати масив, але в стандартній бібліотеці цього немає. Можна написати власну бібліотеку сортування, але кращий варіант - скористатися [пакетом sorts](https://github.com/diku-dk/sorts).

Ми можемо використати цей пакет у своєму рішенні, запустивши таку команду в каталозі рішення:

```shell
futhark pkg add github.com/diku-dk/sorts
futhark pkg sync
```

Потім імпортуємо потрібні [алгоритми сортування](https://github.com/diku-dk/sorts/tree/master/lib/github.com/diku-dk/sorts) так:

```futhark
import "lib/github.com/diku-dk/sorts/<sorting algorithm>"
```
