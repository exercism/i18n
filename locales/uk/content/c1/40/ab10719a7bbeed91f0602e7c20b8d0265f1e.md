# Вступ

## Зіставлення зі зразком

Вираз `if/elif/else` дає змогу умовно виконувати логіку. У F# є й інший, потужніший спосіб умовно виконувати логіку: зіставлення зі зразком. За допомогою зіставлення зі зразком значення можна перевірити на відповідність одному або кільком _зразкам_. Приклад такого зразка - _константний зразок_, який зіставляє значення з константою (наприклад, `1` або `"hello"`).

У F# зіставлення зі зразком виконують за допомогою ключового слова `match`:

```fsharp
let describe number =
    match number with
    | 0 -> "Zero"
    | 1 -> "One"
```

Хоча це може скидатися на інструкції `switch` в інших мовах, зіставлення зі зразком по-справжньому розкривається тоді, коли використовувати й інші зразки. Один із таких зразків - _зразок-змінна_, який дає змогу захопити значення:

```fsharp
match number with
| 0 -> "Zero"
| i -> sprintf "Non zero: %d" i
```

У деяких випадках до зразка може знадобитися додати ще одну умову. Це називають _охоронною умовою_ (конструкцією), яку можна додати за допомогою ключового слова `when`:

```fsharp
match number with
| 0 -> "Zero"
| i when i < 0 -> "Negative number"
```

У наведеному вище прикладі не кожні можливі вхідні дані матимуть відповідний зразок. Компілятор це виявить і видасть попередження. Це називають _перевіркою на вичерпність_. Щоб позбутися цього попередження, потрібно опрацювати всі випадки. Для цього можна використати _зразок-підстановку_, який зіставляється з будь-яким значенням:

```fsharp
match number with
| i when i < 0 -> "Negative number"
| _ -> "Positive number"

// No compiler warning
```

Зіставлення зі зразком перевіряє значення на відповідність кожному зразку згори донизу, доки не знайде відповідний зразок і не виконає логіку, повʼязану з цим зразком. Порядок зразків має значення!
