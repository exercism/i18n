# Про цей розділ

## Типи функцій

Ми вже бачили, як визначаються сигнатури функцій: спочатку йде назва функції, потім список міток параметрів, розділених комами, разом з їхніми типами, а далі `->` і тип значень, які повертає функція.

Якщо прибрати з цієї сигнатури всі назви та мітки, залишиться [тип функції][function-types].

```swift
func shoppingList(item: String, quantity: Int) -> String {
  "You need to buy \(quantity) \(item)."
}
// shoppingList: (String, Int) -> String

func repeater(_ phrase: String, times: Int) -> String {
  var result = ""
  for _ in 1...times {
    result += phrase
  }
  return result
}
// repeater: (String, Int) -> String

func printString(line: String) {
  print(line)
}
// printString: (String) -> ()
```

Звернімо увагу, що типи перших двох функцій однакові, `(String, Int) -> String`, хоча ці дві функції працюють зовсім по-різному. Обидві вони приймають `String` і `Int` як вхідні дані та повертають `String`. А як видно з типу третьої функції, хоча вона, здавалося б, нічого не повертає, насправді вона повертає `()`, єдине значення типу `Void`. Зауважмо, що `()` і `Void` взаємозамінні як назви типів, тож тип `printString` можна записати і як `String) -> Void`.

Ці типи можна використовувати так само, як і будь-який інший тип у Swift, наприклад, в оголошенні змінних чи констант. А оскільки функції у Swift є значеннями, уже наявні функції можна присвоїти цим константам чи змінним:

```swift
var stringAndIntToString: (String, Int) -> String

stringAndIntToString = shoppingList
stringAndIntToString("carrots", 3)
// => "You need to buy 3 carrots."

stringAndIntToString = repeater
stringAndIntToString("carrots", 3)
// => "carrotscarrotscarrots"
```

Як і з іншими змінними чи константами, значення, яке ми присвоюємо, має бути правильного типу:

```swift
stringAndIntToString = printShoppingList
// Error: Cannot assign value of type '(String) -> ()' to type '(String, Int) -> String'
```

## Типи функцій як типи параметрів

Оскільки типи функцій можна використовувати будь-де, де й інші типи, звідси випливає, що [їх можна використовувати як типи параметрів][functions-as-parameters] і передавати в інші функції та викликати зсередини цих функцій.

```swift
func apply3(to str: String, function f: (String, Int) -> String) -> String {
  f(str,3)
}
// apply3: ([String], (String, Int) -> String) -> [String]

apply3(to: "eggs", function: shoppingList)
// => "You need to buy 3 eggs."

apply3(to: "eggs", function: repeater)
// => "eggseggseggs"

func apply(functions fs: [(String, Int) -> String],
           to string: String,
          ) -> [String] {
  var result = [String]()
  for f in fs {
    result.append(f(string, 3))
  }
  return result

}
// apply: ([(String, Int) -> String], String) -> [String]


apply(functions: [shoppingList, repeater], to: "carrots")
// => ["You need to buy 3 carrots.", "carrotscarrotscarrots"]
```

## Типи функцій як типи повернених значень

Так само [типи функцій можна використовувати як типи повернених значень][functions-as-returns] функцій. Інакше кажучи, можна писати функції, які створюють і повертають інші функції. Під час створення таких функцій функція, яку повертають, може використовувати інші параметри, передані в функцію, або локальні змінні, створені всередині батьківської функції.

```swift
func makeAdder(base: Int) -> (Int) -> Int {
  func adder(_ i: Int) -> Int {
    base + i
  }
  return adder
}
// makeAdder: (Int) -> (Int) -> Int

let add10 = makeAdder(base: 10)
// add10: (Int) -> Int

let subtract20 = makeAdder(base: -20)
// subtract10: (Int) -> Int

add10(5)
// => 15

subtract20(5)
// => -15
```

## Захоплення значень

Як ми бачили на прикладі функції `makeAdder(base:)` вище, вкладені функції можуть отримувати доступ до параметрів і змінних функцій, що їх оточують. Крім того, вони зберігають доступ до цих значень і після завершення зовнішньої функції. Ця дія отримання й збереження доступу відома як [_захоплення_][capturing-values].

## Функції вищого порядку

Функції, які приймають функції як параметри та/або повертають функції, називають функціями вищого порядку. У Swift є багато функцій вищого порядку в різних його бібліотеках. Наприклад, метод `sorted(by:)`, доступний у колекціях Swift, як-от `Array`, який для масиву з елементами типу `T` приймає функцію типу `(T, T) -> Bool`, що визначає, яке з двох значень має йти перед іншим у відсортованому масиві, повертаючи `true`, якщо ліве значення має стояти першим, і `false`, якщо першим має стояти праве значення.

Іншим прикладом є метод `contains(where:)` у колекціях, який для колекції з елементами типу `T` приймає функцію типу `(T) -> Bool`, що повертає `true`, якщо елемент задовольняє деяку властивість, і `false` в іншому разі. Тоді `contains(where:)` повертає `true`, якщо якийсь елемент колекції задовольняє цю властивість.

```swift
func longer(_ strA: String, _ strB: String) -> Bool {
  strA.count > strB.count
}
// longer: (String, String) -> Bool

["apple", "ball", "carrot"].sorted(by: longer)
// => ["carrot", "apple", "ball"]

["apple", "ball", "carrot"].sorted(by: >)
// => ["carrot", "ball", "apple"]


func isBig(_ i: Int) -> Bool {
  i > 100
}
// isBig: (Int) -> Bool

func isVowel(_ char: Character) -> Bool {
  switch char.lowercased() {
  case "a", "e", "i", "o", "u": return true
  default: return false
  }
}
// isVowel: (Character) -> Bool

[1, 75, 3, 99].contains(where: isBig)
// => false

"Owl".contains(where: isVowel)
// => true

```
