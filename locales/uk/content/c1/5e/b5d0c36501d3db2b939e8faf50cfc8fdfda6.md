# Вступ

У Common Lisp час подають чотирма способами, два з яких ми розглянемо тут.

- Універсальний час - це абсолютний час, ціле число, що задає кількість секунд від `1900-01-01T00:00:00Z` (тобто від опівночі 1 січня 1900 року за UTC).
- Декодований час - це кортеж із 9 значень, які разом представляють конкретний календарний час: секунди, хвилини, година, день місяця, місяць, рік, день тижня, прапорець літнього часу, часовий пояс.
(Детально розглянуто нижче.)

## Універсальний час

Щоб отримати поточний універсальний час, використовують `get-universal-time` або `get-decoded-time`.
Перша повертає поточну кількість секунд від `1900-01-01T00:00Z`, а друга повертає ті самі дані в декодованому форматі.

## Декодований час

Для роботи з часом призначені дві основні функції: `decode-universal-time` і `encode-universal-time`.
Перша приймає універсальний час і повертає декодоване значення часу як [multiple-values][concept-multiple-values], а друга приймає декодовані значення часу як аргументи й повертає універсальний час.

Обидві приймають необовʼязковий аргумент часового поясу.
Формат часового поясу описано нижче.

Декодований час складається з набору значень:

- *секунди*: ціле число від 0 до 59
- *хвилини*: ціле число від 0 до 59
- *година*: ціле число від 0 до 23
- *день місяця*: ціле число від 1 до 31 (верхня межа, очевидно, залежить від місяця й року)
- *місяць*: ціле число від 1 до 12
- *рік*: ціле число, що вказує на рік.
- *день тижня*: ціле число від 0 до 6. 0 означає понеділок, 1 означає вівторок і так далі... 6 означає неділю.
- *прапорець літнього часу*: значення правда означає, що діє літній час.
- *часовий пояс*: кількість годин від -24 до 24, що позначає зміщення від UTC.
Це раціональне число, і воно має бути кратним `1/3600`

```lisp
(encode-universal-time 1 2 3 4 5 2000 0) ; => 3166398121
(decode-universal-time 3166398121)       ; => 1
                                         ;    2
                                         ;    3
                                         ;    4
                                         ;    5
                                         ;    2000
                                         ;    3 (Thursday)
                                         ;    NIL
                                         ;    0
(decode-universal-time 2208988800) ; => 0
                                   ;    0
                                   ;    0
                                   ;    1
                                   ;    1
                                   ;    1970
                                   ;    3
                                   ;    NIL
                                   ;    0
```
