# Про

[Функція вищого порядку](https://docs.microsoft.com/en-us/dotnet/fsharp/introduction-to-functional-programming/first-class-functions) - це функція, яка або:

- приймає функцію як аргумент
- повертає функцію

Аргумент функції - це просто звичайний аргумент, але такий, який можна викликати.

```fsharp
let double = fun x -> x * 2

let apply f x = f x

apply double 3
// => 6
```
