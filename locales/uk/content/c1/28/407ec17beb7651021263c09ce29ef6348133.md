# Вступ

Тип «розрізнюване обʼєднання» представляє фіксовану кількість іменованих випадків. Кожне значення розрізнюваного обʼєднання відповідає рівно одному з іменованих випадків.

Розрізнюване обʼєднання визначають за допомогою ключового слова `type`, а випадки розділяють символами вертикальної риски (`|`):

```fsharp
type Season =
    | Spring
    | Summer
    | Autumn
    | Winter
```

З кожним випадком розрізнюваного обʼєднання за потреби можна повʼязати дані, і різні випадки можуть мати дані різних типів. Якщо з жодним із випадків не повʼязано даних, таке розрізнюване обʼєднання схоже на те, що в інших мовах зазвичай називають _enumeration_ (або _enum_).

```fsharp
type Number =
    | Integer of int
    | Float of float
    | Invalid
```

Щоб створити значення для конкретного випадку, достатньо звернутися до його назви (наприклад, `Success`). Оскільки назви випадків - це просто функції-конструктори, повʼязані дані можна передати як звичайний аргумент функції. Якщо в іншому розрізнюваному обʼєднанні вже визначено випадок із такою самою назвою, потрібно буде використати його повну назву (наприклад, `Result.Success`).

```fsharp
let byName = Integer 2
let byFullName = Number.Invalid
```

Розрізнювані обʼєднання мають _структурну рівність_: це означає, що два значення одного й того самого випадку з однаковими (необовʼязковими) даними рівнозначні.

Хоча для роботи з розрізнюваними обʼєднаннями можна використовувати вирази `if/elif/else`, рекомендований спосіб - зіставлення з шаблонами за допомогою _шаблону ідентифікатора_:

```fsharp
let describe number =
    match number with
    | Integer i -> sprintf "Integer: %d" i
    | Float d  -> sprintf "Float: %f" d
    | Invalid   -> "Invalid"
```
