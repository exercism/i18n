# Доповнення до інструкцій

## Реалізація

У цій вправі ми реалізуємо процедуру, яка має виділяти памʼять під рядок тексту (англ. string), що його вона повертає. Звільнити цей рядок тексту має той, хто викликає процедуру.

```odin
// The procedure will be called like that:
converted := convert(3)
// ...
// and eventually the caller will delete the string
delete(converted)
```
