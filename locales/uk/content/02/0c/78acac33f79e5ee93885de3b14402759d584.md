# Побітові операції

У Crystal є побітові оператори для роботи з [`Int`][ints] на рівні бітів.

## Оператори зсуву

У Crystal є [оператори зсуву][shift] для зсуву бітів ліворуч (`<<`) або праворуч (`>>`).

### Зсув ліворуч(`<<`)

Оператор зсуву ліворуч (`<<`) зсуває біти ліворуч.
Значення для зсуву вказується ліворуч, а кількість позицій для зсуву - праворуч.

```crystal
0b0010 << 1
# => 0b0100

0b0010 << 2
# => 0b1000
```

Якщо число відʼємне, зсув відбудеться праворуч.

```crystal
0b0010 << -1
# => 0b0001
```

### Зсув праворуч(`>>`)

Оператор зсуву праворуч (`>>`) зсуває біти праворуч.
Як і оператор зсуву ліворуч, він бере значення для зсуву ліворуч, а кількість позицій для зсуву - праворуч.

```crystal
0b0100 >> 1
# => 0b0010

0b0100 >> 2
# => 0b0001
```

І так само, якщо число відʼємне, оператор зсуне біти ліворуч.

```crystal
0b0100 >> -1
# => 0b1000
```

## Бінарні оператори

У Crystal є 3 [бінарні оператори][binary] (`&`, `|`, `^`) і оператор `~` для виконання побітових операцій.

### Побітове AND(`&`)

Бінарний оператор AND (`&`) виконує побітове AND над двома значеннями.
Він порівнює кожен біт першого значення з бітом у тій самій позиції другого значення.
Результуючий біт встановлюється в 1, якщо обидва біти дорівнюють 1.
Інакше він встановлюється в 0.

```crystal
0b0011 & 0b1010
# => 0b0010
```

### Побітове OR(`|`)

Бінарний оператор OR (`|`) виконує побітове OR над двома значеннями.
Він так само порівнює кожен біт першого значення з бітом у тій самій позиції другого значення.
Якщо принаймні один із бітів дорівнює 1, результуючий біт встановлюється в 1.
Інакше він встановлюється в 0.

```crystal
0b0011 | 0b1010
# => 0b1011
```

### Побітове XOR(`^`)

Бінарний оператор XOR (`^`) виконує побітове XOR.
Як і побітові оператори AND та OR, він порівнює кожен біт першого значення з бітом у тій самій позиції другого значення.
Якщо _лише один_ із них дорівнює 1, результуючий біт дорівнює 1.
Інакше він дорівнює 0.

```crystal
0b0011 ^ 0b1010
# => 0b1001
```

### Побітове NOT(`~`)

І нарешті, побітовий оператор NOT (`~`) інвертує кожен біт значення.
На відміну від інших бінарних операторів, це унарний оператор, який працює лише зі значенням праворуч.

```crystal
~0b1110_0010
# => 0b0001_1101
```
