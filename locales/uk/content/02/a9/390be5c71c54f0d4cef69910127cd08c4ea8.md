# Про Python

[Python][python docs] - це [динамічна та строго][dynamic typing in python] типізована [обʼєктно-орієнтована][object oriented programming] мова програмування.
Вона поєднує [качину типізацію][duck typing] та [поступову типізацію][gradual typing] (через [підказки типів][type hints]).
Вона підтримує кілька парадигм програмування, зокрема імперативний (_обʼєктно-орієнтований, процедурний_) і декларативний (_функціональний, конкурентний_) стилі.
Але не даймо себе обдурити: хоча програмування в різних парадигмах повністю підтримується, [усе в Python є обʼєктом][everythings an object].


Python створив Гвідо ван Россум, і його вперше випустили 1991 року.
[Python Software Foundation][psf] керує та спрямовує ресурси для розробки Python і CPython, а також приймає пропозиції щодо змін до мови від [членів][psf membership] спільноти через [Python Enhancement Proposals (PEPs)][peps].
Її вважають сильною мовою для програмістів, які [розпочинають свою подорож][python for beginners], адже її спільнота привітна, а для учнів будь-якого рівня та зацікавлень доступно багато ресурсів.


Python надає великого значення читабельності коду і (_подібно до Haskell_) використовує [значущі відступи][significant indentation], щоб позначати визначення функцій, методів і класів.
Код можна писати й виконувати з командного рядка, в інтерактивній сесії інтерпретатора, у [JupyterLab][jupyter] (Jupyter Notebooks) або в найрізноманітніших [редакторах коду та IDE][editors for python].

[Python широко використовують][python is used extensively] у наукових обчисленнях, фінансах, іграх, мережах, розробці для інтернету та для збирання конвеєрів з інших програм.


Більше філософії та поглядів на мову можна знайти в [zen of Python (PEP 20)][the zen of python] і в [What is Pythonic?][what is pythonic].


Тести й інструментарій для цього треку наразі підтримують `Python 3.10 - 3.13.7` (_тести_) та [`Python 3.13.7`][313-new-features] (_інструментарій_).
Наполегливо радимо учням оновитися принаймні до `Python 3.10`, адже деякі можливості, які використовує цей трек, можуть не підтримуватися в давніших версіях.
Водночас більшість вправ працюватиме з `Python 3.6+` і навіть із давнішими версіями.
Але ми не гарантуємо підтримку версій, не зазначених у [списку активних випусків Python][active-python-releases].
Ми будемо намагатися зазначати, коли певна можливість доступна лише в конкретній версії.
