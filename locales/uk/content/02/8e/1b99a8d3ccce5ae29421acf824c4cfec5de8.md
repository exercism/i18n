# Вступ

`case` (у [`combinators`][combinators]) виконує розгалуження за значенням,
перебираючи асоціативний список пунктів і виконуючи тіло першого
відповідного пункту.

```
case ( obj assoc -- )
```

```factor
USING: combinators ;

: name-of ( n -- s )
    {
        { 1 [ "one" ] }
        { 2 [ "two" ] }
        [ drop "many" ]
    } case ;
```

Кожен пункт має вигляд `{ value [ body ] }`. Рівність перевіряється
за допомогою `=`. Відповідні пункти виконуються, коли вхідне значення
*вже спожито*. Завершальний `[ body ]` (без значення) використовується
як типовий пункт: він виконується, коли вхідне значення *все ще* на
стеку, тож тіло зазвичай починається з `drop`.

[combinators]: https://docs.factorcode.org/content/vocab-combinators.html
