# Вступ

У Gleam функції належать до обʼєктів першого класу, тобто функції є звичайними значеннями, які можна присвоювати змінним, передавати як аргументи та повертати з інших функцій.

На іменовану функцію, визначену в модулі, можна посилатися за її назвою.

```gleam
pub fn main() {
  // Assign the function to a variable
  let f = add_one
  
  // Invoke the function
  f(1) // -> 2
  f(2) // -> 3
}

fn add_one(x) {
  x + 1
}
```

У Gleam також є анонімні функції, які визначають усередині інших функцій.

```gleam
// Define the function
let f = fn(x) { x + 1 }

// Invoke the function
f(1) // -> 2
f(2) // -> 3
```

Тип функції записують за допомогою синтаксису, схожого на синтаксис анонімних функцій. Тип функції, яка приймає `Int` і `Float` та повертає `Int`, записують так:

```gleam
fn(Int, Float) -> Int
```

Анонімні функції можуть посилатися на змінні, які були в області видимості на момент їхнього визначення, що робить їх _замиканнями_.

```gleam
let secret_number = 42

// This function always returns 42
fn() { secret_number }
```

Синтаксис _захоплення функції_ дає зручний скорочений запис для створення анонімних функцій, які передають один аргумент у функцію. Ці два вирази рівнозначні:

```gleam
// Anonymous function syntax
let f = fn(x) { my_function(1, 2, x) }

// Function capture syntax
let f = my_function(1, 2, _)
```
