# Вступ

За допомогою циклу `while` можна повторно виконувати код, доки виконується певна умова.
Його записують так: спочатку ключове слово `while`, потім умова в круглих дужках і блок коду, що містить _тіло_ циклу, у фігурних дужках.

```javascript
while (condition) {
  // code that is executed repeatedly as long as the condition is true
}
```

У JavaScript також є цикл `do-while`.
Тут умова перевіряється після виконання тіла циклу.
Це корисно, коли умова залежить від результату роботи коду в тілі.

```javascript
do {
  // The code here will always be executed once and then
  // repeatedly while the condition is true.
} while (condition);
```

Усередині тіла циклу можна використати ключове слово `break`, щоб повністю зупинити виконання циклу.
Натомість ключове слово `continue` зупиняє виконання лише поточної ітерації та переходить до наступної.
За допомогою `continue` часто вдається уникнути того, щоб брати великі частини тіла циклу в умовну конструкцію.

```javascript
let i = 0;

while (i < 100) {
  i = i + 2;

  if (i % 3 === 0) {
    continue;
  }

  // The code here will only be executed when i was not divisible
  // by 3 in the check above.
}
```
