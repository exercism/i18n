# Вступ

Масиви та списки містять упорядковану колекцію скалярів.
Якщо не використовувати посилання (про них ітиметься в окремій темі), це означає, що масиви та списки завжди пласкі, тобто вони не можуть містити інших масивів чи списків.

У більшості випадків списки оточені круглими дужками `()`, а їхні елементи розділені комами `,`.

Змінну-масив зазвичай наповнюють, присвоївши їй список, наприклад `my @names = ('Alice', 'Bob', 'Charlie');`.

До елементів масиву чи списку можна звертатися, вказавши індекс, наприклад `('Alice', 'Bob', 'Charlie')[1] # 'Bob'`.

Індекси в Perl починаються з `0`.
Відʼємні індекси відраховуються від кінця масиву чи списку, наприклад `('Alice', 'Bob', 'Charlie')[-1] # 'Charlie'`.

## Функції

Існує багато функцій для роботи з масивами та списками, серед найкорисніших: [grep][grep] для нового списку відфільтрованих елементів, які відповідають умові, [map][map] для перетворення елементів на новий список значень і [sort][sort] для нового списку перевпорядкованих елементів.

Функції для роботи з масивами включають [push][push] для додавання елементів у кінець, [pop][pop] для вилучення останнього елемента, [shift][shift] для вилучення першого елемента, [unshift][unshift] для додавання елементів на початок і [splice][splice] для складніших змін.

Також ми часто будемо натрапляти на ітерацію по масивах і списках за допомогою інструкції [for(each)][perlsynforeach].

## Різниця сигілів

Коли ми звертаємося до елементів масиву, результат визначає відповідний сигіл.
Саме індекс `[]` у кінці назви змінної вказує Perl, що ми звертаємося до масиву з цією назвою.

```perl
my @names = ('Alice', 'Bob', 'Charlie');

$names[0]; # 'Alice'      <- A scalar
@names[0]; # ('Alice')    <- A slice (with only one index, this probably isn't what you want. There will be a warning.)
%names[0]; # (0, 'Alice') <- A key/index + value slice

$names[1, 2]; # 'Charlie'                <- A scalar (via unsupported syntax for an ancient feature. Probably not what you want. There will be a warning.)
@names[1, 2]; # ('Bob', 'Charlie')       <- A slice
%names[1, 2]; # (1, 'Bob', 2, 'Charlie') <- A key/index + value slice
```

Хоча це й дозволено, заради читабельності краще не давати різним типам змінних однакову назву.

## Масиви проти списків

Масиви та списки мають багато спільного і в багатьох місцях їх можна використовувати взаємозамінно, але це не одне й те саме.
Список - це фіксована й незмінна колекція скалярів.
Масив - це змінна колекція скалярів, вміст і розмір якої можна змінювати.

У деяких контекстах вони поводяться по-різному.
Масив у скалярному контексті дає розмір масиву.
Список у скалярному контексті дає останній елемент списку і, можливо, кілька попереджень про те, що решту його вмісту використано в порожньому контексті.

```perl
my @names = ('Alice', 'Bob', 'Charlie');

scalar @names; # 3
scalar ('Alice', 'Bob', 'Charlie'); # 'Charlie' (and some warnings).
```
