# Про

[Конструкція switch][switch] дає змогу порівняти значення з кількома можливими відповідними значеннями.
Вона дає змогу писати лаконічніший код, ніж використовувати кілька `else-if`.
Конструкція switch починається з ключового слова `switch`, після якого йде значення для порівняння.
Потім можна визначити випадки за допомогою ключового слова `case`, після якого йде значення, з яким порівнювати.
Ключове слово `default` використовується для визначення випадку за замовчуванням, коли жоден з випадків не збігається.
Як і `else-if`, конструкції `switch` виконують лише блок коду, повʼязаний з першим відповідним випадком.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Розгляньмо такий приклад:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

Це можна натомість записати так:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## Привʼязування та `where`

Значення, які зіставляються в конструкціях `switch`, також можна привʼязати до імен, які можна використовувати в тілі випадку.
Їх також можна використовувати в умовах `where`, які є додатковими булевими виразами, що мають обчислюватися як `true`, щоб випадок збігся.

```swift
let x = 1337
switch sumOfDivisors(of: x) {
case let total where total == x:
  print(total, "is a perfect number")
default:
  print(x, "is not a perfect number")
}
```
