# Підказки

## 1. Створіть вектор з усіх вагонів

- Класичний цикл `for`/`while` із `push!` до `Vector` спрацює.
- Інакше функція [`collect()`][collect] може виявитися лаконічнішою.
- Або ж усередині конструктора вектора можна застосувати розпакування:

```julia-repl
julia> input = (1, 5, 9)
(1, 5, 9)

julia> [input...]
3-element Vector{Int64}:
 1
 5
 9
```

## 2. Виправте вектор вагонів

- Корисно відокремити передні вагони й локомотив від решти, щоб потім зібрати їх у правильному порядку.
- Може стати в пригоді множинне присвоєння з розпакуванням (див. вступ).

## 3. Додайте пропущені зупинки

- Памʼятайте, ця функція не змінює вхідні дані! Створіть новий `Dict`.
- Потрібна лише назва зупинки, а не її номер, тож кожну пару треба розділити.
- Є кілька способів зібрати вектор назв:
  -  Цикл `for`/`while` із `push!()` до `Vector`.
  -  Генератор масиву, або Array [comprehension][comprehensions]
  -  [`map()`][map] функції до вектора.
  -  Також можливий [Broadcasting][broadcasting] [анонімної][anonymous] функції:

 ```julia-repl
julia> (x -> x^4).([1, 2, 3]) == [1, 16, 81]
true
 ```

## 4. Розширте інформацію про маршрут

- Після застосування оператора `...` `more_route_information` є колекцією `Pairs()`.
- Функція [`merge()`][merge] поєднає два або більше `Dict`, але також приймає колекцію `Pairs()`.
  Явне перетворення колекції `Pairs()` на `Dict` можливе, але не потрібне.
