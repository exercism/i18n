# Інструкції

У **Chrono Realms** Хранителі часу часто мають справу не лише з деревами часових ліній, а й із **Chrono Chains** - послідовностей звʼязаних **TimeNodes**, кожен із яких представляє конкретний момент часу.
**Chrono Chain** - це прямий шлях із послідовних моментів, де кожен **TimeNode** зʼєднується з наступним.
Ці **Chrono Chains** стають у пригоді під час подорожі крізь низку конкретних подій, адже вони дають Хранителям часу змогу рухатися однією часовою лінією.

Однак, щоб упоратися з цими потенційно довгими **Chrono Chains**, Хранителі часу використовують **розумні вказівники (Box<T>)**, щоб безпечно керувати цими списками моментів і перебирати їх, не спричиняючи зайвого дублювання чи переповнення памʼяті.
Кожен **TimeNode** зберігає посилання на наступний вузол, утворюючи рекурсивну структуру.

Наше завдання як учнів - реалізувати **Chrono Chain** як рекурсивну структуру списку за допомогою розумних вказівників.

У цій вправі ми зробимо таке:

1. Створити рекурсивний enum `ChronoChain`, що представляє список моментів.
2. Використати розумний вказівник `Box<T>` для зберігання рекурсивних вузлів.
3. Реалізувати функцію, яка створює `ChronoChain` з масиву значень `u32`.
4. Реалізувати функцію, яка перебирає `ChronoChain` й обчислює суму значень, збережених у списку.

## 1. Визначте рекурсивний enum `ChronoChain`

Створіть рекурсивний enum `ChronoChain` із двома варіантами:

- `End`: позначає кінець списку.
- `Link`: містить значення `u32` і посилання на наступний вузол ланцюга, загорнуте в Box.

## 2. Створіть функцію для побудови ChronoChain

Напишіть функцію `ChronoChain::build`, яка приймає масив значень `u32` і повертає `ChronoChain`, зʼєднуючи значення послідовно за допомогою розумних вказівників.

## 3. Реалізуйте функцію підсумовування

Напишіть функцію `ChronoChain::sum`, яка рекурсивно перебирає `ChronoChain` й обчислює суму значень усіх вузлів.

## Приклад використання

```rust
fn main() {
    // Create a ChronoChain from an array of values
    let chrono_chain = ChronoChain::build(array![10, 20, 30]);

    // Sum the values in the ChronoChain
    let total_sum = chrono_chain.sum();

    println!("Total Time Power: {}", total_sum);
}
```
