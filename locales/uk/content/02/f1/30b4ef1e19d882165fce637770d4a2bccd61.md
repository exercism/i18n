# Вступ

## Числа

Lua використовує два представлення чисел: 64-бітні цілі числа та числа з плаваючою комою подвійної точності. Вона підтримує звичайний набір арифметичних операторів: додавання, віднімання, множення, ділення та заперечення. Крім того, вона підтримує ділення націло, остачу від ділення та піднесення до степеня.

| Оператор | Приклад             |
| -------- | ------------------- |
| `+`      | `1 + 2 --> 3`       |
| `-`      | `2 - 1 --> 1`       |
| `*`      | `2 * 2 --> 4`       |
| `/`      | `4 / 2 --> 2.0`     |
| `//`     | `11 // 3 --> 3`     |
| `%`      | `11 % 3 --> 2`      |
| `^`      | `10 ^ 2 --> 100.0`  |
| `-`      | `-(2 * 2) --> -4`   |
