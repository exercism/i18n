# Концепції вправи «Високосний рік»

Я віддаю перевагу першому прикладу рішення, бо його лаконічність відповідає тому, що я бачив в ідіоматичному Rust. Воно також уникає додавання концепції замикання в канонічному рішенні.

## Виокремлені концепції

### Загальне

- Булева логіка
  - булеве значення (англ. Boolean)
- Вирази
  - функції Rust неявно повертають вирази
- Арифметика
  - остача (від ділення)

### Типи

- беззнакові цілі числа - `u64`
- булеві значення - `bool`

## Приклад вправи 1

Рішення [«desi-belokonska»](https://exercism.org/tracks/rust/exercises/leap/solutions/01d024321b6a491690321844aedf8b09)

```rust
pub fn is_leap_year(year: u64) -> bool {
  year % 400 == 0 || year % 4 == 0 && year % 100 != 0
}
```

## Приклад вправи 2

[Канонічне рішення](https://github.com/exercism/rust/blob/master/exercises/leap/example.rs)

```rust
pub fn is_leap_year(year: u64) -> bool {
    let has_factor = |n| year % n == 0;
    has_factor(4) && (!has_factor(100) || has_factor(400))
}
```
