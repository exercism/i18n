# Пакети платежів у базі даних

## Постановка задачі

Потрібно вставити пакет платіжних даних у таблицю `Payment`. Завдання - прочитати платіжні дані із заданого вхідного JSON-файлу та скористатися операцією `batchExecute` клієнта JDBC, щоб вставити платіжні дані в таблицю `Payment`. Приклад вхідного файлу наведено як `payments.json`.

Вміст вхідного JSON-файлу відповідає такій схемі JSON.

```json
{
  "type": "array",
  "items": [
    {
      "type": "object",
      "properties": {
        "employee_id": {
          "type": "integer"
        },
        "amount": {
          "type": "number"
        },
        "reason": {
          "type": "string"
        },
        "date": {
          "type": "string"
        }
      },
      "required": [
        "employee_id",
        "amount",
        "reason",
        "date"
      ]
    }
  ]
}

```

Потрібно повернути автоматично згенеровані ідентифікатори платежів для вставлених у пакеті платіжних даних як вихідні дані, не виконуючи додаткового запиту до бази даних.

Можна припустити, що значення `employee_id`, наведені у файлі `payments.json`, коректні й уже містяться в таблиці `Employee`.

## Відомості про базу даних

Скористайтеся наданою базою даних H2 для цієї задачі.

> Файл прикладу бази даних - `gofigure.mv.db`, а імʼя бази даних - `gofigure`. Його наведено в папці `db`.

У прикладі бази даних H2 уже є такі таблиці з деякими зразковими даними. Назви стовпців і типи даних наведено нижче.

**Назва таблиці**: `Employee`

| **Стовпці:**      | тип |
| -----------       | ----------- |
| `employee_id`     | ціле число, первинний ключ з автоінкрементом       |
| `name`            | рядок тексту (англ. string)        |
| `city`            | рядок тексту        |
| `department`      | рядок тексту        |
| `age`             | ціле число        |

**Назва таблиці**: `Payment`

| **Стовпці:**      | тип |
| -----------       | ----------- |
| `payment_id`      | ціле число, первинний ключ з автоінкрементом       |
| `date`            | дата        |
| `amount`          | десяткове число        |
| `employee_id`     | ціле число        |
| `reason`          | рядок тексту        |

* Файл бази даних - `gofigure.mv.db`. Використовуйте JDBC URL такого вигляду: `jdbc:h2:file:/path/to/db/file`
* Імʼя користувача: `root`
* Пароль: `root`

## Обмеження

* Використовуйте наданий у папці `db` файл бази даних H2 для перевірки запитів і зразка Ballerina
* Використовуйте підхід із параметрами залежності Maven, щоб додати драйвер бази даних H2 як платформну залежність у файлі Ballerina.toml
* Потрібно знайти автоматично згенеровані ідентифікатори платежів, не виконуючи додаткового запиту до бази даних.

## Середовище тестування

## Приклади

### Приклад 1

**Вхідні дані:** dbFilePath: `"/path/to/file/gofigure"`, paymentFilePath: `"/path/to/file/payments.json"`

Дані прикладу файлу `payments.json`:

```json
[{
        "employee_id": 4,
        "amount": 12500.50,
        "reason": "Fuel for the month January",
        "date": "2022-02-03"
    },
    {
        "employee_id": 1,
        "amount": 10500.50,
        "reason": "Medical Expenses for the month January",
        "date": "2022-02-04"
    },
    {
        "employee_id": 4,
        "amount": 500.50,
        "reason": "Fuel for the month February",
        "date": "2022-03-03"
    }
]

```

**Вихідні дані:** `[1,2,3]`

## Підказки

* Використовуйте модуль [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc) для роботи з базою даних
* Дивіться розділ [Передумови](https://lib.ballerina.io/ballerinax/java.jdbc/latest), щоб дізнатися, як додати драйвер JDBC як залежність
* Використовуйте [io:fileReadJson](https://lib.ballerina.io/ballerina/io/latest/functions#fileReadJson) для читання вхідного JSON-файлу
* Перетворіть значення JSON на типи, специфічні для застосунку, щоб працювати з даними типобезпечно. Дивіться приклад [Перетворення на тип, визначений користувачем](https://ballerina.io/learn/by-example/convert-from-json-to-user-defined-type/)
* Використовуйте [sql:ParameterizedQuery](https://lib.ballerina.io/ballerina/sql/latest#ParameterizedQuery) і віддалений метод [batchExecute](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-batchExecute) для роботи з базою даних
* Дивіться приклад [пакетного виконання](https://ballerina.io/learn/by-example/mysql-batch-execute-operation/)
