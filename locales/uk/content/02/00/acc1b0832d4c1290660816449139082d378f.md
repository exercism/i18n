# Вступ

У Elixir кортеж - це структура даних, яка впорядковує дані, містить фіксовану кількість елементів будь-якого типу, але без явних назв для кожного елемента. Кортежі часто використовують в Elixir для операцій з інтенсивним читанням памʼяті, оскільки доступ до елемента на читання виконується за сталий час. Їх зазвичай не використовують, коли елементи потрібно додавати або вилучати динамічно, бо замість зміни наявного кортежу створюється новий кортеж, під який потрібно заздалегідь виділити памʼять.

На практиці кортежі в Elixir створюють за допомогою фігурних дужок. До елементів кортежу можна окремо звертатися за допомогою функції `elem/2`, використовуючи індексацію з нуля:

```elixir
empty_tuple = {}
one_element_tuple = {1}
multiple_element_tuple = {1, :a, "hello"}

elem(multiple_element_tuple, 2)
# => "hello"
```

## Кортежі як згрупована інформація

На практиці кортежі часто використовують, щоб представити згруповану інформацію.

```elixir
Float.ratio(0.25)
# => {1, 4} indicating the numerator and denominator of the fraction ¼
```
