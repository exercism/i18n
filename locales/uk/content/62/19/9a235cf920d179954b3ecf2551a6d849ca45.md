# Вступ

Основні арифметичні оператори та оператори порівняння можна пристосувати для використання у власному **abstract**. Це називається перевантаженням операторів.

Щоб перевантажити оператор, скористаймося полем класу з метаданими `@:op()`:

```haxe
abstract MyAbstract(String) {
  public inline function new(s:String) {
    this = s;
  }

  @:op(A * B)
  public function repeat(rhs:Int):MyAbstract {
    var s:StringBuf = new StringBuf();
    for (i in 0...rhs)
      s.add(this);
    return new MyAbstract(s.toString());
  }
}

class Main {
  static public function main() {
    var a = new MyAbstract("foo");
    trace(a * 3); // foofoofoo
  }
}
```
