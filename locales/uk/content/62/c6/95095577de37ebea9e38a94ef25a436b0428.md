# Вступ

## Коригувальники TemporalAdjusters

Коли ми працюємо з обʼєктами `java.time` на кшталт `LocalDate`, часто виникає потреба у складних коригуваннях дати, як-от пошук «другого вівторка місяця».
Замість того щоб обчислювати це вручну, можна скористатися **`TemporalAdjusters`**.

Утилітний клас `java.time.temporal.TemporalAdjusters` (звернімо увагу на «s» в кінці) надає статичні методи для багатьох типових коригувань дати.
Ці коригування застосовують через метод `.with()` на часовому обʼєкті (наприклад, `LocalDate`).

```exercism/note
Використання `with(TemporalAdjuster)` повертає _новий_ екземпляр і не оновлює наявний, оскільки обʼєкти `java.time` є незмінними.
```

```java
import java.time.LocalDate;
import java.time.Month;
import java.time.DayOfWeek;
import java.time.temporal.TemporalAdjusters;

LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15 (a Thursday)

// Use a predefined adjuster: find the last day of the month
LocalDate lastDay = date.with(TemporalAdjusters.lastDayOfMonth());
// => 2024-08-31
```

Ось кілька ключових коригувальників, корисних для обчислень у розкладі:

### Пошук порядкового дня тижня в місяці

Скористаймося `dayOfWeekInMonth(int ordinal, DayOfWeek dayOfWeek)`, щоб знайти n-те входження дня тижня.

```java
// Find the second Tuesday of August 2024
LocalDate secondTuesday = date.with(TemporalAdjusters.dayOfWeekInMonth(2, DayOfWeek.TUESDAY));
// => 2024-08-13
```

### Пошук першого та останнього дня тижня в місяці

Скористаймося `firstInMonth(DayOfWeek dayOfWeek)` або `lastInMonth(DayOfWeek dayOfWeek)`.

```java
// Find the last Monday of August 2024
LocalDate lastMonday = date.with(TemporalAdjusters.lastInMonth(DayOfWeek.MONDAY));
// => 2024-08-26
```

### Відносні коригування (наступний і попередній)

Коригувальники на кшталт `next()`, `previous()`, `nextOrSame()` і `previousOrSame()` знаходять наступне або попереднє входження заданого дня тижня відносно поточної дати.

- `next()`/`previous()`: не враховують поточну дату, навіть якщо вона збігається.
- `nextOrSame()`/`previousOrSame()`: враховують поточну дату, якщо вона збігається.

```java
LocalDate thursday = LocalDate.of(2024, Month.AUGUST, 15); // A Thursday

// Find the next Thursday (exclusive)
LocalDate nextThursday = thursday.with(TemporalAdjusters.next(DayOfWeek.THURSDAY));
// => 2024-08-22

// Find the next Thursday (inclusive) - returns the same date
LocalDate nextOrSameThursday = thursday.with(TemporalAdjusters.nextOrSame(DayOfWeek.THURSDAY));
// => 2024-08-15

// Find the previous Monday (exclusive)
LocalDate previousMonday = thursday.with(TemporalAdjusters.previous(DayOfWeek.MONDAY));
// => 2024-08-12
```

### Власні коригувальники

`TemporalAdjuster` - це функціональний інтерфейс, тому власний коригувальник можна написати як лямбду, що приймає часове значення для коригування і повертає скориговане.
Його застосовують через `.with()` так само, як і визначені наперед коригувальники, і всередині він може використовувати їх.

```java
import java.time.temporal.TemporalAdjuster;

// An adjuster that moves a weekend date to the following Monday
TemporalAdjuster skipWeekend = temporal -> {
    DayOfWeek day = DayOfWeek.from(temporal);
    if (day == DayOfWeek.SATURDAY || day == DayOfWeek.SUNDAY) {
        return temporal.with(TemporalAdjusters.next(DayOfWeek.MONDAY));
    }
    return temporal;
};

LocalDate saturday = LocalDate.of(2024, Month.AUGUST, 17);
LocalDate monday = saturday.with(skipWeekend);
// => 2024-08-19
```

Використання цих коригувальників із класу `TemporalAdjusters` може значно спростити роботу з датами.
