# Вступ

## With

[Спеціальна форма with][with] дає змогу зосередитися на «щасливому шляху» серії кроків, які можуть зазнати невдачі, а з невдачами розібратися пізніше.

```elixir
with {:ok, id} <- get_id(username),
     {:ok, avatar} <- fetch_avatar(id),
     {:ok, image_type} <- check_valid_image_type(avatar) do
  {:ok, image_type, avatar}
else
  :not_found ->
    {:error, "invalid username"}

  {:error, "not an image"} ->
    {:error, "avatar associated to #{username} is not an image"}

  err ->
    err
end
```

На кожному кроці, якщо збігається вираз, ланцюжок продовжиться, доки не виконається блок `do`. Якщо один збіг не вдається, ланцюжок зупиняється, і повертається вираз, який не збігся. Ми маємо можливість використати блок `else`, щоб перехопити невдалі збіги та змінити повернене значення.

[with]: https://hexdocs.pm/elixir/Kernel.SpecialForms.html#with/1
