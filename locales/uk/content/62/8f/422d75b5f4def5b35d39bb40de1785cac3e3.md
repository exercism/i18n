# Інструкції

У цій вправі ми реалізуємо частину набору допоміжних процедур, які допомагають розробнику чистити назви ідентифікаторів.
У 5 завданнях ми поступово побудуємо процедуру `Clean`.
Правильний ідентифікатор складається з нуля або більше літер і символів підкреслення.
У всіх випадках вхідний рядок тексту (англ. string) гарантовано не є `null`.
Якщо у функцію `Clean` передати порожній рядок тексту, вона має повернути порожній рядок тексту.
Зауважмо, що не варто викликати процедуру `Clean` з порожнім ідентифікатором, бо такі ідентифікатори нічого не дають.

## 1. Замініть усі пробіли на символи підкреслення

Реалізуйте (_статичний_) метод `Identifier.Clean()`, щоб замінити всі пробіли на символи підкреслення.
Це стосується також пробілів на початку й у кінці рядка.

```csharp
Identifier.Clean("my   Id");
// => "my___Id"
```

## 2. Замініть керуючі символи на рядок тексту «CTRL» у верхньому регістрі

Змініть (_статичний_) метод `Identifier.Clean()`, щоб замінити керуючі символи на рядок тексту `"CTRL"` у верхньому регістрі.

```csharp
Identifier.Clean("my\0Id");
// => "myCTRLId",
```

## 3. Перетворіть kebab-case на camelCase

Змініть (_статичний_) метод `Identifier.Clean()`, щоб перетворювати kebab-case на camelCase.

```csharp
Identifier.Clean("à-ḃç");
// => "àḂç"
```

## 4. Пропустіть символи, які не є літерами

Змініть (_статичний_) метод `Identifier.Clean()`, щоб він пропускав будь-які символи, які не є літерами.

```csharp
Identifier.Clean("1😀2😀3😀");
// => ""
```

## 5. Пропустіть грецькі літери в нижньому регістрі

Змініть (_статичний_) метод `Identifier.Clean()`, щоб пропускати грецькі літери в діапазоні від 'α' до 'ω'.

```csharp
Identifier.Clean("MyΟβιεγτFinder");
// => "MyΟFinder"
```
