# Тести

## Файли вправи

Завантажена вправа містить такі файли для збірки та тестування рішення:

```text
hello-world/
├── HelloWorld.vb       # Your solution
├── HelloWorldTests.vb  # The test suite
├── HelloWorld.vbproj   # Project and build configuration
└── packages.lock.json  # Resolved project dependencies
```

Назви файлів різняться залежно від вправи.
Напишіть своє рішення у файлі `.vb`, назва якого не закінчується на `Tests`.
Файл, назва якого закінчується на `Tests.vb`, - це набір тестів xUnit; зазвичай редагуйте його лише для того, щоб прибрати аргументи `Skip`.
Редагувати файл проєкту чи файл блокування зазвичай не потрібно.

## Запуск тестів

Відкрийте термінал у каталозі вправи та виконайте:

```bash
dotnet test
```

Ця команда відновлює залежності проєкту, збирає проєкт і запускає його тести.
Також можна використати `dotnet watch test`, щоб перезапускати тести щоразу, коли змінюється вихідний файл.

## Пропущені тести

Спочатку у вправах увімкнено лише перший тест, тож решту можна розвʼязувати крок за кроком.
Відкрийте файл, назва якого закінчується на `Tests.vb`, щоб побачити тести.
Кожен тест - це підпрограма `Sub`, позначена атрибутом `<Fact>` з xUnit.
Тест залишається пропущеним, доки в його атрибуті `<Fact>` вказано аргумент `Skip`:

```vb
<Fact(Skip:="Remove this Skip property to run this test")>
Public Sub Lowercase_words()
    Assert.Equal("ROR", Abbreviate("Ruby on Rails"))
End Sub
```

Щоб увімкнути тест, просто приберіть аргумент `Skip`:

```vb
<Fact>
Public Sub Lowercase_words()
    Assert.Equal("ROR", Abbreviate("Ruby on Rails"))
End Sub
```

Після того як щойно увімкнений тест пройде, повторіть цей процес із наступним пропущеним тестом.
Коли всі тести увімкнено та вони проходять, усе готово.
