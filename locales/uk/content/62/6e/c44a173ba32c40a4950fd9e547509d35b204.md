# Вказівки

У цій вправі ми граємо з другом у гру, де треба вгадати число. Правила прості: ми таємно обираємо число від `1` до `100`, а наш друг намагається вгадати, яке число ми обрали. Щоб допомогти другові, ми відповідаємо по-різному залежно від того, наскільки близькою була здогадка до обраного числа (`42`). Ось правила для різних відповідей:

- Якщо здогадка `42`: «Correct»
- Якщо здогадка `41` або `43`: «So close»
- Якщо здогадка менша за `41`: «Too low»
- Якщо здогадка більша за `43`: «Too high»

На нас чекають чотири завдання: потрібно закодувати відповіді на здогадки.

## 1. Дайте відповідь на правильну здогадку

Реалізуйте функцію `reply`, щоб вона відповідала на правильну здогадку:

```fsharp
reply 42
// => "Correct"
```

## 2. Дайте відповідь на близьку здогадку

Змініть функцію `reply`, щоб вона відповідала на близькі здогадки:

```fsharp
reply 41
// => "So close"
```

## 3. Дайте відповідь на надто малі здогадки

Змініть функцію `reply`, щоб вона відповідала на надто малі здогадки:

```fsharp
reply 25
// => "Too low"
```

## 4. Дайте відповідь на надто великі здогадки

Змініть функцію `reply`, щоб вона відповідала на надто великі здогадки:

```fsharp
reply 88
// => "Too high"
```
