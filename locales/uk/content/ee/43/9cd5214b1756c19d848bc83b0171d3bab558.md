# Типи чисел

У Crystal є різноманітні типи чисел для різних потреб.
Наприклад, одні типи працюють швидше, але мають менший діапазон можливих значень, ніж інші.
Інші мають ширший діапазон можливих значень, але працюють повільніше.

У Crystal існують як цілі числа зі знаком, так і беззнакові цілі числа.
Цілі числа зі знаком можуть бути додатними або відʼємними.
Беззнакові цілі числа можуть бути лише додатними.

## Типи цілих чисел зі знаком

Ось [типи цілих чисел зі знаком][int] у Crystal:

| Тип      | Розмір (біти) | Діапазон                                                                                                    |
| -------- | ------------- | ----------------------------------------------------------------------------------------------------------- |
| `Int8`   | 8             | від -128 до 127                                                                                             |
| `Int16`  | 16            | від -32_768 до 32_767                                                                                       |
| `Int32`  | 32            | від -2_147_483_648 до 2_147_483_647                                                                         |
| `Int64`  | 64            | від -9_223_372_036_854_775_808 до 9_223_372_036_854_775_807                                                 |
| `Int128` | 128           | від -170_141_183_460_469_231_731_687_303_715_884_105_728 до 170_141_183_460_469_231_731_687_303_715_884_105_727 |

Менші типи використовують менше памʼяті й працюють швидше за більші, але мають менший діапазон можливих значень.

Коли ми знаємо, що значення перебуватимуть у певному діапазоні, найкраще використати якомога менший тип, щоб заощадити памʼять і підвищити швидкодію.

Типовим типом цілих чисел є `Int32`.
Щоб оголосити ціле число з конкретним типом, можна додати назву типу як суфікс, дописавши `<number>_I <bit>`.

```crystal
1_i8.class
# => Int8
```

Щоб перетворювати різні типи цілих чисел, можна використати метод `to_i<bit>`.
Метод `to_i` перетворює значення на типовий тип цілих чисел, `Int32`.

```crystal
1_i8.to_i16.class
# => Int16

2_i16.to_i.class
# => Int32
```

## Типи беззнакових цілих чисел

Ось [беззнакові цілі числа][uint] у Crystal:

`UInt8`, `UInt16`, `UInt32`, `UInt64`, `UInt128`

Єдина відмінність між цілими числами зі знаком і беззнаковими цілими числами полягає в тому, що беззнакові можуть бути лише додатними.
Щоб оголосити беззнакове ціле число з конкретним типом, можна додати назву типу як суфікс, дописавши `<number>_u<bit>`.
Щоб перетворювати різні типи беззнакових цілих чисел, можна використати метод `to_u<bit>`.
Метод `to_u` перетворює значення на типовий тип беззнакових цілих чисел, `UInt32`.

```crystal
1_u8.to_u16.class
# => UInt16
```

## Типи чисел з плаваючою комою

Ось типи чисел з плаваючою комою в Crystal:

| Тип       | Розмір (біти) | Діапазон             |
| --------- | ------------- | -------------------- |
| `Float32` | 32            | від 1.2E-38 до 3.4E+38 |
| `Float64` | 64            | від 2.3E-308 до 1.7E+308 |

Існують два різні [типи чисел з плаваючою комою][float], один із них точніший за інший.

Типовим типом чисел з плаваючою комою є `Float64`.

Щоб перетворювати різні типи чисел з плаваючою комою, можна використати метод `to_f<bit>`.
Метод `to_f` перетворює значення на типовий тип чисел з плаваючою комою, `Float64`.

[float]: https://crystal-lang.org/api/latest/Float.html
[int]: https://crystal-lang.org/api/latest/Int.html
[uint]: https://crystal-lang.org/api/latest/UInt32.html
