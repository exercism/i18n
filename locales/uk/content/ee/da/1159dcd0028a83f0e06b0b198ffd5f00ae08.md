# Навчання

Якщо ми тільки починаємо працювати з SQLite і хочемо вивчити основи синтаксису SQL та керування базами даних, ось кілька чудових ресурсів, розрахованих на початківців:

- **Вступ до SQL на YouTube**: Погляньмо на [What is SQL?][sql-youtube], чотирихвилинне відео для початківців від Danielle Thé.

- **SQLite Tutorials**: [SQLite Tutorials][sqlite-tutorial] пропонує дружній для початківців вступ до SQLite, охоплюючи фундаментальні поняття, як-от створення бази даних, виконання запитів і роботу з даними.

- **SQLZoo**: Попрактикуймо навички роботи з SQL за допомогою інтерактивних вправ і туторіалів на [SQLZoo][sqlzoo], зокрема матеріалів, присвячених саме SQLite, придатних для початківців.

Ці ресурси дають базову основу для вивчення SQLite і синтаксису SQL, допомагаючи початківцям зрозуміти поняття баз даних і набути практичного досвіду роботи з базами даних SQLite.

[sqlite-tutorial]: https://www.sqlitetutorial.net/
[sql-youtube]: https://www.youtube.com/watch?v=27axs9dO7AE
[sqlzoo]: https://sqlzoo.net/
