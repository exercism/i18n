# Вступ

У концепті [`Vectors`][vectors] ми казали, що «масиви лежать в основі мови Julia», а вектор - це одновимірний масив.

З огляду на це, цілком можна сподіватися, що мова надає багато універсальних і потужних способів _робити щось_ з векторами, хоч би що це означало.

## Функції, що приймають вектор

Деякі дуже прості функції приймають вектор на вході й повертають скалярний результат.

```julia
v = [2, 3, 4]
length(v)  # => 3
sum(v)  # => 9
```

## Арифметика

Припустімо, у нас є числовий вектор і ми хочемо відняти 0.5 від кожного значення.

```julia-repl
julia> v = [1.2, 1.5, 1.7]
3-element Vector{Float64}:
 1.2
 1.5
 1.7

julia> v - 0.5
ERROR: MethodError: no method matching -(::Vector{Float64}, ::Float64)
```

Це не спрацьовує, то як щодо віднімання іншого вектора?

```julia-repl
julia> v - [0.5, 0.5, 0.5]
3-element Vector{Float64}:
 0.7
 1.0
 1.2
```

Успішно, але досить марудно й марнотратно щодо памʼяті, коли вектори стають довшими.

На щастя, у Julia є «чарівна» крапка, яка розвʼязує цю проблему дуже просто: достатньо написати `v .- 0.5`.

Наступний розділ пояснить чому.

## Broadcasting

Отже, `v - 0.5` не спрацьовує, а `v .- 0.5` спрацьовує, і нам треба зрозуміти, що робить крапка.

Дві речі, які разом дають потрібний результат.

### 1. Поелементне застосування

По-перше, крапка _перед_ будь-яким інфіксним оператором означає «застосувати цю операцію до кожного елемента окремо».

Так само крапка _після_ назви функції «векторизує» її, навіть якщо функцію написано для скалярних вхідних даних.

```julia-repl
julia> sqrt.([1, 4, 9])
3-element Vector{Float64}:
 1.0
 2.0
 3.0
```

### 2. Розширення одиничних вимірів

Ми бачили в попередньому прикладі, що можемо віднімати вектори однакової довжини, але звернімо увагу: `.-` працює _безпечніше_, ніж `-`, бо ясно показує поелементний намір.

```julia-repl
julia> v .- [0.5, 0.5, 0.5]
3-element Vector{Float64}:
 0.7
 1.0
 1.2
```

А що з векторами різної довжини?

```julia-repl
julia> v .- [0.5, 0.5]
ERROR: DimensionMismatch: arrays could not be broadcast to a common size

julia> v .- [0.5,]
3-element Vector{Float64}:
 0.7
 1.0
 1.2
```

Загалом різна довжина спричиняє помилку, _крім_ випадку, коли один із векторів має довжину 1 (технічно кажучи, це «одиничний» вимір).

Одиничні значення, як-от `[0.5,]` або просто `0.5`, автоматично розширюються до потрібної довжини повторенням.
Саме це лежить в основі `broadcasting`.

### Broadcasting на місці

Якщо витрати памʼяті мають значення, то операції на місці часто допомагають зменшити виділення памʼяті.

Однак операції broadcasting у наведених вище прикладах створюють новий `Vector`, а не змінюють початковий.

Щоб змінити початковий `Vector` на місці, потрібно застосувати broadcasting.

```julia-repl
julia> v .= v .+ 1
3-element Vector{Int64}:
 2
 3
 4

julia> v .+= 1  # equivalent operation to above
3-element Vector{Int64}:
 3
 4
 5

julia> v
3-element Vector{Int64}:
 3
 4
 5
```

## Індексація

Вибір елементів вектора за номером індексу ми вже розглядали в попередніх концептах.

```julia
a = collect('A':'Z')  # => 26-element Vector{Char}

# index with an integer
a[2]  # => 'B'

# index with a range
 a[12:2:18]  # => ['L', 'N', 'P, 'R']
 
 # index with another vector
 a[ [1, 3, 5] ]  # => ['A', 'C', 'E']
```

### Логічна індексація

Також можна вибирати елементи, які задовольняють деякий логічний вираз (технічно кажучи, «предикат»).
Зазвичай для цього потрібен broadcasting.

```julia-repl
julia> a[a .< 'D']
3-element Vector{Char}:
 'A': ASCII/Unicode U+0041 (category Lu: Letter, uppercase)
 'B': ASCII/Unicode U+0042 (category Lu: Letter, uppercase)
 'C': ASCII/Unicode U+0043 (category Lu: Letter, uppercase)
```

У складніших виразах крапок стає дедалі більше (але вони маленькі та легко набираються).

```julia-repl
julia> a[a .< 'D' .|| a .> 'W']
6-element Vector{Char}:
 'A': ASCII/Unicode U+0041 (category Lu: Letter, uppercase)
 'B': ASCII/Unicode U+0042 (category Lu: Letter, uppercase)
 'C': ASCII/Unicode U+0043 (category Lu: Letter, uppercase)
 'X': ASCII/Unicode U+0058 (category Lu: Letter, uppercase)
 'Y': ASCII/Unicode U+0059 (category Lu: Letter, uppercase)
 'Z': ASCII/Unicode U+005A (category Lu: Letter, uppercase)
```

Нагадаємо, що «вектор» насправді може бути будь-яким відповідним упорядкованим обʼєктом, який можна перебирати, наприклад діапазоном:

```julia-repl
julia> n = 3:10
3:10

julia> n[isodd.(n)]
4-element Vector{Int64}:
 3
 5
 7
 9
```
