# Вступ

У Elixir механізм _Behaviour_ дає змогу описати спільні узагальнені інтерфейси, а кожен модуль, який його реалізує, може мати власну реалізацію. Один із найпоширеніших прикладів такого механізму - _Access Behaviour_.

_Access Behaviour_ надає спільний інтерфейс для отримання даних зі структури даних за ключем. Його реалізовано для словників і списків ключових слів, але розгляньмо, як він працює зі словниками, щоб відчути його краще. _Access Behaviour_ визначає, що коли в нас є словник, після нього можна поставити _квадратні дужки_ й узяти з них ключ, щоб отримати значення, повʼязане з цим ключем.

```elixir
# Suppose we have these two maps defined (note the difference in the key type)
my_map = %{key: "my value"}
your_map = %{"key" => "your value"}

# Obtain the value using the Access Behaviour
my_map[:key] == "my value"
your_map[:key] == nil
your_map["key"] == "your value"
```

Якщо ключа немає в структурі даних, повертається `nil`. Це може призвести до несподіваної поведінки, бо помилки не виникає. Зауважмо, що сам `nil` реалізує Access Behaviour і завжди повертає `nil` для будь-якого ключа.
