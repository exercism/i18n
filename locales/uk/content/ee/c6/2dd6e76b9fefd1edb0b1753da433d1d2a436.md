# Цикли `for-in`

Циклічне виконання - фундаментальна концепція програмування, яка дає змогу виконувати блок коду багаторазово.
У Swift є два типи циклів: [цикли `for-in`][for-loops] і цикли `while`.
У цьому розділі ми дізнаємося про цикли `for-in`.

Цикли `for-in` дають змогу перебирати послідовність значень, беручи по черзі кожен елемент і привʼязуючи його до змінної, яку ми обираємо.
Swift дає змогу перебирати різноманітні послідовності, як-от діапазони, масиви та рядки тексту (англ. string), а також інші типи, які ми розглянемо далі.
Коли перебрано кожен елемент послідовності, цикл завершується.

Цикли `for-in` оголошують за допомогою ключового слова `for`, після якого йде імʼя змінної, ключове слово `in` і послідовність значень для перебирання.
Змінна, задана в циклі `for-in`, незмінна, тож її значення не можна змінити всередині циклу.
Ось приклад циклу `for-in`, який перебирає масив чисел:

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
  print(number)
}
print("Done with numbers")

// prints:
// 3
// 10
// 7
// 11
// Done with numbers
```

~~~~exercism/note
Змінна `number` оголошується в циклі `for-in` і доступна лише в межах області видимості цього циклу.

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
    number + 1
}
number + 1
// Error: Use of unresolved identifier 'number'
```
~~~~

## Перебирання діапазону

Також можна перебирати діапазон чисел за допомогою циклу `for-in`.
Це дає змогу виконати блок коду певну кількість разів: наприклад, діапазон `1...5` охоплює числа 1, 2, 3, 4 і 5, тож цикл виконається 5 разів.
Іноді може знадобитися перебрати індекси в такій структурі даних, як масив; тоді можна використати діапазон `0..<array.count`.

```swift
let numbers = [3, 10, 7, 11]

for i in 0..<numbers.count {
  print(numbers[i])
}

// prints:
// 3
// 10
// 7
// 11
```

## Перебирання рядка тексту

Також можна перебирати рядок тексту за допомогою циклу `for-in`.
Це дає змогу перебрати кожен символ у рядку тексту. Звернімо увагу, що тип, який отримує змінна в циклі, - це `Character`.

```swift
let message = "Hello!"

for character in message {
  print(character)
}

// prints:
// H
// e
// l
// l
// o
// !
```

## Невикористані змінні

Якщо значення змінної в циклі нам не потрібне, можна використати підкреслення `_`, щоб його проігнорувати.

```swift
let numbers = [3, 10, 7, 11]

for _ in numbers {
  print("Hello!")
}
```

## stride

Swift також надає функцію `stride`, яка дає змогу створити послідовність у межах діапазону із заданим кроком.
Її потім можна перебрати за допомогою циклу `for-in`.
`stride` має дві форми: [`stride(from:to:by:)`][stride-to] і [`stride(from:through:by:)`][stride-through]. Перша не включає кінцеве значення, а друга включає його.

```swift
for i in stride(from: 0, to: 10, by: 2) {
  print(i)
}

// prints:
// 0
// 2
// 4
// 6
// 8
```

Зауважмо, що параметр `to` не включає кінцеве значення, тож цикл перебиратиме аж до числа, що передує значенню `to`, а параметр `through` включає його, тож у цьому випадку буде включено і `10`.

[stride-to]: https://developer.apple.com/documentation/swift/stride(from:to:by:)
[stride-through]: https://developer.apple.com/documentation/swift/stride(from:through:by:)
[for-loops]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
