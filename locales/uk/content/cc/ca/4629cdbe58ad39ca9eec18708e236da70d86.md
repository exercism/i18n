# Детальніше

[Гарди][guards] використовують як доповнення до [зіставлення зі зразком][exercism-pattern-matching]. Вони дають змогу робити складніші перевірки. Їх можна використовувати в деяких, але не в усіх ситуаціях, де застосовне зіставлення зі зразком, наприклад у визначеннях функцій або в гілках `case`.

```elixir
def empty?(list) when is_list(list) and length(list) == 0 do
  true
end
```

- Гарди починаються з ключового слова `when`, після якого йде булевий вираз (англ. Boolean).
- Вирази гардів є спеціальними функціями, які:
  - Мають бути [чистими][pure-function] і не змінювати жодних глобальних станів.
  - Мають повертати строго `true` або `false`.
- Перелік поширених гардів можна знайти в [документації Elixir][kernel-guards]. До нього входять:
  - Перевірки типів: [`is_integer/1`][guard-is-integer], [`is_list/1`][guard-is-list], [`is_nil/1`][guard-is-nil] тощо.
  - Арифметичні оператори: [`+/2`][guard-plus], [`-/2`][guard-minus] тощо.
  - Порівняння: [`==/2`][guard-equals], [`>/2`][guard-greater], [`</2`][guard-less] тощо.
  - Булеві оператори: [`and/2`][guard-and], [`or/2`][guard-or], [`not/1`][guard-not]
  - Оператор належності: [`in/2`][guard-in]
- Власний гард можна визначити за допомогою [`defguard`][defguard].

  - Згідно з [правилами найменування][naming] в Elixir, назви гардів мають починатися з `is_`.

    ```elixir
    defmodule HTTP do
      defguard is_success(code) when code >= 200 and code < 300

      def handle_response(code) when is_success(code) do
        :ok
      end
    end
    ```
