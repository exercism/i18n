# Вступ

## Масиви

`array` у F# це колекція з нуля або більше значень фіксованої довжини, яку можна змінювати. Це означає, що після створення масиву його розмір уже не зміниться, але значення в ньому змінювати можна. Усі значення в масиві повинні мати однаковий тип. Масиви можна визначити так:

```fsharp
let empty = [| |]
let emptyAlternative = Array.empty

let singleValue = [| 5 |]
let singleValueAlternative = Array.singleton 5

let threeValues = [| "a"; "b"; "c" |]
```

Елементи можна присвоювати масиву або отримувати з нього за індексом. Масиви F# мають нульову індексацію: індекс першого елемента завжди дорівнює нулю:

```fsharp
let numbers = [| 2; 3; 5 |]

// Update value in array
numbers[2] <- 9

// Read value from array
numbers[2]
// => 9
```

З масивами працюють або через функції та оператори, визначені в модулі `Array`, або вручну, за допомогою зіставлення зі зразком, використовуючи _зразок масиву_:

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty"
    | [| 1; 2; three |] -> sprintf "1, 2, %d" three
    | _ -> "Other"

describe [| |]         // => "Empty"
describe [| 1; 2; 4 |] // => "1, 2, 4"
describe [| 5; 7; 9 |] // => "Other"
```

Під час зіставлення зі зразком значення можна також _відкинути_: якщо в конкретному випадку значення нас _не_ цікавить (тобто ми не збираємося його _використовувати_), для цього можна використати знак підкреслення (`'_'`):

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty array"
    | [| x |] -> "Array with one item"
    | [| _; y |] -> "Array with two items (first item ignored)"
    | _ -> "Array with many items (all items ignored)"

describe [| |]          // => "Empty array"
describe [| 1 |]        // => "Array with one item"
describe [| 5; 7 |]     // => "Array with two items (first item ignored)"
describe [| 5; 7; 9 |]  // => "Array with many items (all items ignored)"
```

Одиничний `'_'` завжди має стояти _останнім_ у зіставленні зі зразком: будь-яке значення, яке _не_ збігається з жодним іншим випадком, обробить саме він.
