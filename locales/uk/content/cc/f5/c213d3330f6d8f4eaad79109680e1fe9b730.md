# Довідка

[Списки][list] - це базовий тип даних в Elixir для зберігання колекції значень. Списки _незмінні_, тобто їх не можна змінити. Будь-яка операція, що змінює список, повертає новий список. Списки реалізують [протокол Enumerable][enum-protocol], який дає змогу використовувати функції модулів [Enum][enum] і [Stream][stream].

Списки в Elixir реалізовано як [звʼязані списки][linked-list-wiki], а не як масиви суміжних ділянок памʼяті. Тому доступ до елемента в списку займає лінійний час, що залежить від довжини списку.

Списки можна записувати в літеральній формі, у нотації «голова-хвіст» (яка використовує оператор `cons` `|`) або як комбінацію обох:

```elixir
# Literal Form
[]
[1]
[1, 2, 3]

# Head-tail Notation
[]
# same as [1]
[1 | []]
# same as [1, 2, 3]
[1 | [2 | [3 | []]]]

# Mixed
# same as [1, 2, 3]
[1 | [2, 3]]
```

Перед оператором _cons_ (`|`) також може стояти більше ніж один елемент.

```elixir
# Multiple prepends
[1, 2, 3 | [4, 5]]
```

Нотацію «голова-хвіст» можна використовувати, щоб додавати елементи в кінець списку.

```elixir
list = [2, 1]

[3, 2, 1] == [3 | list]
# => true
```

Додавання елементів у кінець списку під час ітерації вважається антипатерном. Щоб додати елемент у кінець, потрібно пройти весь список і додати елемент у самому кінці, тому додавання нового елемента на кожній ітерації вимагало б проходження всього списку на кожній ітерації.

Того самого результату можна досягти, додавши елемент на початок перевернутого списку, а потім перевернувши результат. Додавання на початок виконується швидко й потребує сталого часу.

```elixir
# Appending to the end of a list (potentially slow)
[1, 2, 3] ++ [4] ++ [5] ++ [6]

# Prepend to the start of a list (faster, due to the nature of linked lists)
[6 | [5 | [4 | [3, 2, 1]]]]
# then reverse!
```

Є кілька поширених функцій `Kernel` для роботи зі списками:

- [`hd/1`][hd] повертає _голову_ списку, тобто _перший_ елемент списку.
- [`tl/1`][tl] повертає _хвіст_ списку, тобто список _без_ _першого_ елемента.
- [`length/1`][length] повертає кількість елементів у списку.
- [`in/2`][in] повертає булеве значення (англ. Boolean), яке вказує, чи є елемент у списку.

Є також [модуль `List`][list].

Списки можуть містити будь-який тип даних і суміш різних типів даних.

```elixir
list = [1, :a, 2.0, "string"]
```
