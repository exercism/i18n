# Вступ

Працювати з бінарними даними буває непросто, тож Gleam надає тип `BitArray` і відповідний синтаксис, щоб створювати бінарні дані та зіставляти їх зі зразком.

Літерали бітових масивів записуються за допомогою синтаксису `<<>>`. Літерал бітового масиву складається із сегментів. Кожен сегмент має значення й анотацію, розділені символом `:`. Анотація визначає, скільки бітів буде використано для кодування значення, і її можна взагалі пропустити, тоді типовим значенням буде 8-бітне ціле число.

```gleam
// This defines a bit array with three segments of a single bit each
<<0:1, 1:1, 0:1>>

// This defines a bit array with three segments of 8 bits each
<<0, 1, 0>>
```

Записати тип як `:1` - це скорочення для `:size(1)`. Якщо розмір у бітах походить із змінної, треба скористатися довшим синтаксисом.

```gleam
let segment_size = 1
<<0:size(segment_size), 1:size(segment_size), 0:size(segment_size)>>
```

## Двійковий запис

Коли ми записуємо двійкові літерали цілих чисел, їх можна записати безпосередньо в двійковій системі числення, додавши перед літералом префікс `0b`. Зауважмо, що під час виведення в тестах чи в нашій програмі вони будуть відображатися як десяткові числа.

```gleam
<<0b1011:4>> == <<11:4>>
// -> True
```

## Усікання

Якщо значення сегмента перевищує місткість типу сегмента, його буде усічено зліва.

```gleam
<<0b1011:3>> == <<0b0011:3>>
// -> True
```

## Додавання на початок і в кінець

За допомогою синтаксису бітових масивів до наявного бітового масиву можна додавати як на початок, так і в кінець. Для наявного бітового масиву потрібно використати анотацію `:bits`.

```gleam
let value = <<0b110:3, 0b001:3>>
let new_value = <<0b011:3, value:bits, 0b000:3>>
// -> <<120, 8:size(4)>>
```

## Конкатенація

Бітові масиви, збережені у змінних, можна зʼєднувати за допомогою цього синтаксису. Анотацію `:bits` потрібно використати, коли ми зʼєднуємо два бітові масиви змінних розмірів.

```gleam
let first = <<0b110:3>>
let second = <<0b001:3>>
let concatenated = <<first:bits, second:bits>>
// -> <<49:size(6)>>
```

## Зіставлення зі зразком

Зіставлення зі зразком також дає змогу дістати значення з бітового масиву. Для кожного фрагмента, який ми хочемо захопити, треба знати кількість бітів, і тут є один виняток: анотацію `:bits` можна використати, щоб зіставити зі зразком бітовий масив невідомого розміру, але лише для останнього фрагмента.

```gleam
let assert <<value:4, rest:bits>> = <<0b01101001:8>>
value == 0b0110
// -> true
```

## Огляд бітових масивів

~~~~exercism/note
Бітові масиви можуть виводитися в іншому форматі, ніж той, у якому їх було створено. Під час вивчення бітових масивів це часто спантеличує.
~~~~

Типово бітові масиви відображаються фрагментами по 8 бітів (один байт), навіть якщо ми створили їх із фрагментів іншого розміру.

```gleam
<<2011:11>>
// -> <<251, 3:size(3)>>
```

Якщо ми створюємо бітовий масив, який представляє придатний для друку рядок тексту (англ. string) у кодуванні UTF-8, функції на кшталт `io.debug` можуть відобразити його як рядок тексту. Це повʼязано з особливістю реалізації того, як Gleam представляє рядки тексту всередині.

```gleam
<<>>
// -> ""

<<65, 66, 67>>
// -> "ABC"
```
