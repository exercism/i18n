# Інструкції

У цій вправі ми будемо працювати з ощадними рахунками.
Щороку баланс нашого ощадного рахунку оновлюється відповідно до його відсоткової ставки.
Відсоткова ставка, яку дає нам банк, залежить від суми грошей на рахунку (його балансу):

- 3.213% за відʼємного балансу (баланс стає ще відʼємнішим).
- 0.5% за додатного балансу, меншого за `1000` доларів.
- 1.621% за додатного балансу від `1000` доларів і меншого за `5000` доларів.
- 2.475% за додатного балансу від `5000` доларів.

На нас чекають чотири завдання, і в кожному з них ітиметься про баланс та його відсоткову ставку.

## 1. Обчислити відсоткову ставку

Реалізуйте метод `SavingsAccount.interest_rate()`, який приймає баланс як аргумент.
Метод повинен повернути відсоткову ставку для заданого балансу.

```Crystal
SavingsAccount.interest_rate(200.75)
# => 0.5
```

## 2. Обчислити відсотки

Реалізуйте метод `SavingsAccount.interest()`, який приймає баланс як аргумент.
Метод повинен повернути відсотки для заданого балансу.

```Crystal
SavingsAccount.interest(200.75)
# => 1.00375
```

## 3. Обчислити річне оновлення балансу

Реалізуйте метод `SavingsAccount.annual_balance_update()`, який приймає баланс як аргумент.
Метод повинен повернути баланс через один рік.

```Crystal
SavingsAccount.annual_balance_update(200.75)
# => 201.75375
```

## 4. Обчислити кількість років до досягнення бажаного балансу

Реалізуйте метод `SavingsAccount.years_before_desired_balance()`, який приймає баланс і цільовий баланс як аргументи.
Метод повинен повернути кількість років, потрібних для досягнення цільового балансу.

```Crystal
balance = 200.75
target_balance = 214.88
SavingsAccount.years_before_desired_balance(balance, target_balance)
# => 14
```

~~~~exercism/note
Коли до початкового балансу застосовують прості відсотки, баланс множать на відсоткову ставку, і добуток цих двох величин і є сумою відсотків.

Складні відсотки, зі свого боку, нараховують, застосовуючи відсотки регулярно.
За кожного нарахування суму відсотків обчислюють і додають до початкового балансу, тож наступні розрахунки відсотків виконуються вже від більшого балансу.
~~~~
