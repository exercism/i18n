# Інструкції

У цій вправі ми попрацюємо над кількома функціями, щоб керувати зустрічами.
Система зберігає все в рядках тексту (англ. string) у форматі ISO 8601, але люди користуються календарем не так.
Щоб перетворювати один формат на інший, потрібні різні функції.

## 1. Створіть зустріч

Створіть зустріч через `n` днів від поточного моменту на поточний час.
Функція приймає `n` днів і повертає час зустрічі через `n` днів від поточного моменту.

```javascript
createAppointment(4, now);
// Given now is Sun Oct 05 2022 23:28:43 GMT+0600 (Bangladesh Standard Time)
// => Sun Oct 09 2022 23:28:43 GMT+0600 (Bangladesh Standard Time)
```

Якщо другий параметр `now` не використано, слід використати поточний час.

## 2. Перетворіть дату на мітку часу

Багато інструментів працюють лише з міжнародним стандартизованим форматом ISO 8601.
Напишіть функцію `getAppointmentTimestamp`, яка приймає дату й повертає рядок тексту в цьому форматі.

```javascript
const appointment = new Date(Date.UTC(2010, 6, 16, 12, 42, 0, 0));

getAppointmentTimestamp(appointment);
// => '2010-07-16T12:42:00.000Z'
```

## 3. Отримайте подробиці зустрічі

Мітки часу важко читати, і функція для отримання подробиць зустрічі має з цим допомогти.
Функція `getAppointmentDetails` приймає мітку часу у форматі ISO 8601 і повертає рік, місяць, число, годину і хвилину.

```javascript
getAppointmentDetails('2022-04-24T08:15:00.000');
// => { year: 2022, month: 3, date: 24, hour: 8, minute: 15 }
```

## 4. Оновіть зустріч із заданими опціями

Функція отримає першим аргументом час зустрічі, а другим - обʼєкт із деякими опціями.
Потрібно оновити зустріч відповідно до опцій в обʼєкті й повернути нову дату зустрічі.
Обʼєкт опцій може містити кілька опцій.

```javascript
updateAppointment('2022-02-09T09:20:00.000', { month: 6 });
// => { year: 2022, month: 6, date: 9, hour: 10, minute: 20 }
```

## 5. Отримайте час між двома зустрічами

Функція отримає два аргументи - дві зустрічі (мітки часу).
Потрібно повернути різницю між цими моментами в секундах.

Оскільки пів секунди майже нічого не значить, округліть число перед тим, як його повернути.

```javascript
timeBetween('2022-12-12T09:20:00.000', '2022-12-18T08:30:00.000');
// => 515400
```

## 6. Перевірте, чи зустріч на цей момент дійсна

Нарешті, коли зустріч призначено, система має перевірити, чи вона дійсна.
Іншими словами, зустріч має бути в майбутньому, а не в минулому.

Напишіть функцію `isValid`, яка приймає два аргументи: мітку часу зустрічі (рядок тексту) і поточний час як мітку часу (рядок тексту), і повертає `true`, якщо зустріч відбувається в майбутньому відносно поточного часу.

```javascript
isValid('2022-02-11T23:00:00.000', '2022-02-08T23:00:00.000');
// => true
```
