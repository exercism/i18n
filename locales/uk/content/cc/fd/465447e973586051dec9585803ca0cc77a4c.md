# Доповнення до інструкцій

## Слова

Визначте кортеж `game` і конструктор `<game> ( -- game )`, який повертає нову гру без кидків.

Надайте такі слова, які працюють із грою:

- `roll ( pins game -- )`: зафіксуйте, що збито `pins` кеглів. Киньте помилку, коли кидок недійсний:
  - `"Negative roll is invalid"` для відʼємної кількості кеглів.
  - `"Cannot roll after game is over"`, коли вже зроблено всі десять фреймів (і будь-які додаткові кидки).
  - `"Pin count exceeds pins on the lane"`, коли збито більше кеглів, ніж стоїть.
- `score ( game -- n )`: загальний рахунок за гру. Киньте `"Score cannot be taken until the end of the game"`, коли гра ще не завершена.

Зверніть увагу, що `roll` затінює слово `roll` для перемішування зі словника `kernel`. Набір тестів усуває неоднозначність за допомогою `FROM: bowling => roll ;`.
