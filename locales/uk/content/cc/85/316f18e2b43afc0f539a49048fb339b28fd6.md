# Про це

Булеві значення (англ. Boolean) у C++ представлені типом `bool`.
Значення типу `bool` буває або `true`, або `false`.

## Логічні оператори

C++ підтримує три булеві оператори: `!` (заперечення), `&&` (логічне і) та `||` (логічне або).
Можна також використовувати альтернативні версії `not`, `and` та `or`.

```cpp
true || false // => true
true && false // => false
!true // => false
not false // => true
```

## Пріоритет

Усі три булеві оператори мають різний _пріоритет операторів_.
Як наслідок, вони обчислюються в такому порядку: спочатку `!`, потім `&&`, і нарешті `||`.
Якщо треба змінити цей порядок, можна взяти булевий вираз у дужки (тобто `()`), адже дужки мають ще вищий пріоритет.

```cpp
!true && false   // => false
!(true and false) // => true
```

## Перетворення

Якщо використати `true` або `false` там, де має бути число, вони перетворяться на `1` і `0` відповідно.
Якщо використати число в булевій операції, то все, крім `0`, вважається `true`, навіть відʼємні значення.

```cpp
!true && 0.0   // => false
true + true + false // => 2
```
