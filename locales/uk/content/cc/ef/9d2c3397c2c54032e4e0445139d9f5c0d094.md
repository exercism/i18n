# Вступ

PowerShell - це мова сценаріїв від Microsoft із динамічною неявною типізацією (яка також підтримує строго типізовані змінні), зосереджена переважно на автоматизації завдань та управлінні конфігурацією.

PowerShell підтримує імперативне, функціональне, обʼєктно-орієнтоване програмування і навіть стиль конвеєрів.

PowerShell створено на платформі .NET, і вперше його випустили у 2006 році.
Його включено за замовчуванням до всіх сучасних версій Windows, а також його можна встановити на Mac і Linux.


## Змінні

Існує два поширені способи визначити змінну в PowerShell.

Назва змінної в PowerShell має починатися з `$`, а щоб привʼязати назву змінної до значення, використовують оператор присвоєння `=`.

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

Також можна явно вказати тип змінної, якщо потрібно закріпити конкретний [тип][strong typed].
PowerShell намагатиметься якнайкраще перетворити значення з одного типу в інший, якщо це можливо.

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```


### Константи

Константи в PowerShell - це змінні, доступні лише для читання, які після визначення не можна **видалити**.
Це підводить нас до другого способу визначити змінні за допомогою командлета `New-Variable`.

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
```

Докладніше про створення нової змінної з різними параметрами дивіться в командлеті [New-Variable][New-Variable].


## Функції

[Функції][functions] у PowerShell визначають за допомогою ключового слова `function`.
Кожна функція може мати нуль або більше формальних [параметрів][parameters] у дужках `()`, після чого починається її власна [область видимості][scope], що відкривається `{` і закривається `}`.

```powershell
function Greeting {
    return "Hello!"
}
```

У PowerShell функції можуть явно повертати значення за допомогою ключового слова `return`, після виклику за синтаксисом `FuncName $Arg`.

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

Докладніший огляд того, як писати детальне визначення функції та як функції повертають значення неявно, буде в модулі концепції `Functions`.


## Коментарі

Однорядковий коментар у PowerShell починається з `#` і закінчується в кінці рядка.
Блоковий коментар у PowerShell починається з `<#` і закінчується `#>`.
Докладніший приклад використання блокового коментаря для створення довідки на основі коментарів буде розглянуто в модулі концепції `Functions`.

```powershell
function Main() {
    #This is a comment
}
```
