# Поняття числа Армстронга

> [Число Армстронга](https://en.wikipedia.org/wiki/Narcissistic_number) - це число, яке дорівнює сумі власних цифр, кожну з яких піднесено до степеня, що дорівнює кількості цифр.

## Приклад рішення

```rust
pub fn is_armstrong_number(num: u32) -> bool {
    let digits = format!("{}", num);
    digits
        .chars()
        .map(|c| c.to_digit(10).unwrap().pow(digits.len() as u32))
        .sum::<u32>()
    == num
}
```
