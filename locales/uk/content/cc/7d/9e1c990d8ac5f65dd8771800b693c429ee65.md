# Додаток до інструкцій

## Регістри

| Регістр | Використання       | Тип     | Опис                                    |
| -------- | ------------ | ------- | --------------------------------------- |
| `$a0`    | вхідні дані        | адреса | вхідний рядок тексту (англ. string) із завершальним нульовим байтом |
| `$a1`    | вхідні/вихідні дані | адреса | масив слів з остаточними кількостями нуклеотидів |
| `$t0-9`  | тимчасовий    | будь-який     | для тимчасового зберігання              |
