# Тести

Щоб запустити тести, виконайте таку команду:

```bash
make
```

## Пропущені тести

Розвʼязати вправу означає зробити так, щоб усі її тести пройшли.
Коли ми запускаємо тести, типово виконується лише один тест (перший).
Це зроблено навмисно, щоб ми могли зосередитися лише на тому, щоб цей один тест пройшов.
Як тільки він пройде, ми можемо увімкнути наступний тест, прибравши рядок `TEST_IGNORE()`.
Коли всі тести буде увімкнено і наша реалізація змусить їх усі пройти, вправу буде розвʼязано!
