# Вирази match

Вираз match обчислює значення й умову, щоб повернути вираз, який буде обчислено.
Як і в тернарному операторі, якщо умова не збігається, повернений вираз не обчислюється.
Щоб перевірити відповідність умові, виконується перевірка ідентичності [строга рівність або `===`].

```php
<?php
$some_value = 42;

$return_value = match($some_value) {
    0 => 'number is 0',
    1 => 'number is 1',
    default => 'number is something else'
}
```

Щоб виконати перевірку на рівність [`==`], можна перебудувати умову:

```php
<?php
$some_value = 42;

$return_value = match(true) {
    $some_value < 100 => 'number is less than 100',
    $some_value > 100 => 'number is greater than 100',
    $some_value == 100 => 'number is 100',
}
```

У виразі match, якщо жодна умова не збігається, буде викинуто `UnhandledMatchError`.
