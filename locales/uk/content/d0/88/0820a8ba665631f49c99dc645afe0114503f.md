# Інструкції

У цій вправі ми писатимемо код, який допоможе фрилансеру спілкуватися з менеджером проєкту: кілька утиліт для швидкого обчислення денної та місячної ставки, за потреби з урахуванням знижки.

Спершу встановімо кілька правил між фрилансером і менеджером проєкту:

Денна ставка у 8 разів більша за погодинну.
У місяці 22 оплачувані дні.
Фрилансер пропонує застосувати знижку, якщо менеджер проєкту вирішить дозволити фрилансеру виставляти рахунок помісячно, що стане в пригоді, коли менеджер проєкту має працювати з певним бюджетом.

Знижки подано як дробові числа, що виражають відсотки, наприклад 25.0 (25%).

## 1. Обчислення денної ставки за погодинною ставкою

Реалізуйте функцію, яка обчислює денну ставку за погодинною ставкою:

```gleam
freelancer_rates.daily_rate(60)
# => 480.0
```

Повернена денна ставка має бути числом з плаваючою комою.

## 2. Обчислення ціни зі знижкою

Реалізуйте функцію, яка обчислює ціну після застосування знижки.

```gleam
freelancer_rates.apply_discount(150, 10)
# => 135.0
```

Повернене значення завжди має бути числом з плаваючою комою, без жодного округлення.

## 3. Обчислення місячної ставки за погодинною ставкою та знижкою

Реалізуйте функцію, яка обчислює місячну ставку та застосовує знижку:

```gleam
freelancer_rates.monthly_rate(77, 10.5)
# => 12130
```

Повернену місячну ставку слід округлити вгору (взяти верхню межу) до найближчого цілого числа.

## 4. Обчислення кількості робочих днів за бюджетом, погодинною ставкою та знижкою

Реалізуйте функцію, яка приймає бюджет, погодинну ставку та знижку й обчислює, скільки робочих днів вони покривають.

```gleam
freelancer_rates.days_in_budget(20000, 80, 11.0)
# => 35
```

Повернену кількість днів слід округлити вниз (взяти нижню межу) до одного десяткового знака.
