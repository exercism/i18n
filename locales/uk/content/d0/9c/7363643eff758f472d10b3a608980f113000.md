# Інструкції

Наша знайома Ерін має надрукувати тисячі листівок для багатьох подій, і їй потрібна наша допомога! Вона попросила нас створити макет листівки, який містить заголовок, необовʼязкову дату та масив виконавців, кожен з яких повʼязаний з _картинкою Unicode_. Мета полягає в тому, щоб за допомогою `print` вивести й розповсюдити наш крутий новий дизайн листівки, а для цього знадобляться всі наші навички форматування рядків тексту (англ. string) у Python.

## 1. Створіть клас із заголовком, написаним з великої літери

Функція `capitalize_header` має приймати назву події й повертати назву події, написану з великої літери.

```python
>>> capitalize_header("fan meetup")
"Fan meetup"
```

## 2. Відформатуйте дату

Створіть новий метод `format_date`, який приймає масив, що містить число, місяць і рік. Він показує відформатовану дату у форматі `<month_name> <date>, <year>`

```python
>>> convert_date([9, 4, 2020])
>>> leaflet.date
"April 9, 2020"
>>> leaflet.set_date([13, 5, 2030])
>>> leaflet.date
"May 13, 2030"
```

## 3. Відобразіть кодові точки Unicode як картинки

Коли викликають метод `display_icons`, переданий масив кодових точок Unicode потрібно відобразити й повернути як `list` з _картинок_.

```python
>>> leaflet.display_icons(['\U00000040', '\U0001D70B'])
['@', '𝜋']
```

## 4. Покажіть готову листівку

Тепер ми використаємо всі функції вище й поєднаємо їх у функції `print_leaflet`.
Вона має приймати `event_name`, масив `icons`, масив `authors` і масив `event_date`.

Плакат має відповідати макету нижче.

Листівка має певний макет у формі прямокутника:

- Перший і останній рядки містять 20 зірочок. `"*"`
- Кожен розділ відокремлений порожнім рядком зверху та знизу.
- Порожній рядок містить лише одну зірочку на початку й одну в кінці.
- Перший розділ - заголовок листівки, і цей заголовок написано з великої літери.
- Другий розділ - необовʼязкова дата; якщо дату не передано, цей розділ має бути порожнім рядком.
- Третій і останній розділ - масив виконавців, кожен виконавець повʼязаний з відповідною картинкою.

```python
********************
*                  *
*    'Concert'     *
*                  *
*  June 22, 2020   *
*                  *
* John         🎸  *
* Benjamin     🎤  *
* Max          🎹  *
*                  *
********************
```
