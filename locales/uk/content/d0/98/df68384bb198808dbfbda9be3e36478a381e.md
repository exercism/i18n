# Підказки

## Загальне

- [The Cairo Book: перетворення типів][tcb-conversions]

## 1. Перетворення знакового числа на беззнакове

- Перевірте, чи знакове значення відʼємне. Якщо так, поверніть `Option::None`
- Перевірте, чи не перевищує знакове значення `u16::MAX` (65535). Якщо перевищує, поверніть `Option::None`
- Для припустимих значень виконайте перетворення за допомогою `.try_into()` або прямого приведення
- Памʼятайте, що `u16` може вміщати значення від 0 до 65535

## 2. Перетворення беззнакового на знакове

- Оскільки `u16::MAX` (65535) вільно вміщається в `i32`, це перетворення завжди вдається
- Використайте `.into()` для безпечного перетворення з `u16` у `i32`

## 3. Перетворення власних типів

- Реалізуйте трейт `Into` із таким синтаксисом: `impl IntoImplName of Into<SourceType, TargetType>`
- У методі `into` створіть новий екземпляр цільового типу
- Перенесіть значення поля `potency` з `Essence` у поле `strength` структури `Elixir`
- Коли трейт реалізовано, можна використовувати `.into()` для екземплярів `Essence`

## 4. Використання трейту `Into`

- Після реалізації трейту `Into` викличте `.into()` для параметра `Essence`
- Компілятор автоматично скористається цією реалізацією трейту
- Анотація типу поверненого значення допомагає Cairo визначити, яке перетворення застосувати
