# Інструкції для SQLite

У цій вправі потрібно присвоїти стовпцю `result` таблиці `etl` правильне значення на основі обʼєкта JSON, що міститься у стовпці `input`. Ключі в обʼєкті результату мають бути відсортовані за алфавітом.

## Схема таблиці

```sql
CREATE TABLE "etl" ("input" TEXT, "result" TEXT);
```
