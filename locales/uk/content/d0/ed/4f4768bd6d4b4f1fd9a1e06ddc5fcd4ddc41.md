# Вступ

[`Time`][time] у Go - це тип, який описує момент часу. Інформацію про дату й час можна читати, порівнювати та змінювати через його методи, але є також функції, які викликають на самому пакеті `time`. Поточну дату й час можна отримати за допомогою функції [`time.Now`][now].

Функція [`time.Parse`][parse] розбирає рядки тексту (англ. string) на значення типу `Time`. У Go є особливий спосіб задавати макет, який ми очікуємо під час розбору. Потрібно написати приклад макета, використовуючи значення зі спеціальної позначки часу:
`Mon Jan 2 15:04:05 -0700 MST 2006`.

Наприклад:

```go
import "time"

func parseTime() time.Time {
    date := "Tue, 09/22/1995, 13:00"
    layout := "Mon, 01/02/2006, 15:04"

    t, err := time.Parse(layout,date) // time.Time, error
}

// => 1995-09-22 13:00:00 +0000 UTC
```

Метод [`Time.Format()`][format] повертає рядок тексту, який представляє час. Як і у випадку з функцією `Parse`, потрібний макет знову задають через приклад, який використовує значення зі спеціальної позначки часу.

Наприклад:

```go
import (
    "fmt"
    "time"
)

func main() {
    t := time.Date(1995,time.September,22,13,0,0,0,time.UTC)
    formattedTime := t.Format("Mon, 01/02/2006, 15:04") // string
    fmt.Println(formattedTime)
}

// => Fri, 09/22/1995, 13:00
```

## Параметри макета

Для власного макета можна скористатися комбінацією цих параметрів.
У Go також є наперед визначені [константи форматування][const] дати й позначки часу.

| Час         | Параметри                                      |
| ----------- | ---------------------------------------------- |
| Рік         | 2006 ; 06                                      |
| Місяць      | Jan ; January ; 01 ; 1                         |
| День        | 02 ; 2 ; \_2 (для провідного 0)                |
| День тижня  | Mon ; Monday                                   |
| Година      | 15 ( 24-годинний формат часу ) ; 3 ; 03 (AM або PM) |
| Хвилина     | 04 ; 4                                         |
| Секунда     | 05 ; 5                                         |
| Позначка AM/PM | PM                                          |
| День року   | 002 ; \_\_2                                    |

Тип `time.Time` має чимало методів для доступу до окремих складових часу. Наприклад, година: [`Time.Hour()`][hour], місяць: [`Time.Month()`][month].
Докладніше про те, як це працює, можна прочитати в [офіційній документації][time].

Пакет [`time`][time] містить ще один тип, [`Duration`][duration], який представляє тривалість часу, а також підтримку локацій і часових зон, таймерів та іншої повʼязаної функціональності, яку розглянемо в іншому концепті.
