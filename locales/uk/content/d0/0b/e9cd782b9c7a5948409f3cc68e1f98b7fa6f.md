# Встановлення

## Mac

Установіть через homebrew командою `brew install swi-prolog`.
Або завантажте вихідний код для своєї системи з [SWI Prolog Website](http://www.swi-prolog.org/download/devel).

## Windows

Завантажте вихідний код для своєї системи з [SWI Prolog Website](http://www.swi-prolog.org/download/devel).

## Linux

Дотримуйтеся інструкцій для свого дистрибутива [тут](http://www.swi-prolog.org/build/unix.html).
