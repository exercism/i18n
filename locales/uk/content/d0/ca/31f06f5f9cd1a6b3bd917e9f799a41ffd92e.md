# Додаток до інструкцій

## Регістри

| Регістр | Використання | Тип | Опис |
| -------- | --------- | ------- | -------------------------------- |
| `$a0`    | вхідні дані     | ціле число | номер клітинки в діапазоні 1..64 |
| `$v0`    | вихідні дані     | ціле число | молодші 32 біти вихідних даних            |
| `$v1`    | вихідні дані     | ціле число | старші 32 біти вихідних даних           |
| `$t0-9`  | тимчасовий | будь-який     | для тимчасового зберігання            |
