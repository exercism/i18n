# Заповнювач

## Як розвʼязати за допомогою bash

`bash` не має вбудованих способів **розібрати** рядки з датою й часом.
У цій вправі потрібно звернутися до зовнішньої утиліти.

* Опція `-d` команди GNU `date` може розібрати [широкий спектр форматів][gnu-date].
* Для користувачів Mac варто звернути увагу на [команду BSD `date`][bsd-date] та її опцію `-f`.
* Perl широко доступний, і його [модуль `Time::Piece`][time-piece] можна використати для розбору міток часу.

bash може **форматувати** дати без будь-яких зовнішніх інструментів.
Якщо задано цілочисельне значення часу (секунди від початку епохи), [форматувальник `printf` `%()T`][bash-printf] може застосувати форматування у стилі «strftime».

```bash
epoch=1234567890

printf '%(%Y-%m-%d %H:%M:%S)T\n' "$epoch"
# ==> 2009-02-13 18:31:30

# bash uses the `TZ` environment variable for the timezone.

TZ=Asia/Kolkata printf '%(%Y-%m-%d %H:%M:%S)T\n' "$epoch"
# ==> 2009-02-14 05:01:30
```

[bsd-date]: https://manpage.me/index.cgi?apropos=0&q=date&sektion=0&manpath=FreeBSD+12-CURRENT+and+Ports&arch=default&format=html
