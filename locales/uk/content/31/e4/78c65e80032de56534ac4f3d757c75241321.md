# Вступ

У Go застосунок організовано в пакети.
Пакет обʼєднує вихідні файли, які лежать в одній теці.
Усі вихідні файли в одній теці повинні мати однакову назву пакета на початку файлу.
За домовленістю пакети називають так само, як теку, у якій вони лежать.

```go
package greeting
```

Go надає велику стандартну бібліотеку пакетів, які можна використовувати у своїй програмі за допомогою ключового слова `import`.
Пакети зі стандартної бібліотеки імпортують за їхньою назвою.

```go
package greeting

import "fmt"
```

До імпортованого пакета далі звертаються за назвою пакета:

```go
world := "World"
fmt.Sprintf("Hello %s", world)
```

Go визначає, чи можна викликати щось із коду в інших пакетах, за тим, як його оголошено.
Щоб функція, тип, змінна, константа або поле структури були видимими ззовні (тобто _експортованими_), їхня назва повинна починатися з великої літери.
Це схоже на те, як працюють інші мови програмування, наприклад Java, де використовують модифікатори доступу, як-от `public` і `private`.

```go
package greeting

// Hello is a public function (callable from other packages).
func Hello(name string) string {
    return "Hello " + name
}

// hello is a private function (not callable from other packages).
func hello(name string) string {
    return "Hello " + name
}
```
