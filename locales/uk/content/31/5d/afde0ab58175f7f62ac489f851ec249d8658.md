# Докладніше

[Класи](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/classes) - це основна конструкція для обʼєктно-орієнтованого програмування у F#.

Клас у F# складається зі своїх полів і методів. Поля та методи класу називають його _членами_.

Класи у F# визначають за допомогою ключового слова `type`. Методи визначають за допомогою ключового слова `member`, і вони завжди публічні. Щоб визначити (приватні) поля, можна використовувати привʼязки `let`.

```fsharp
type Shoe() =
    let size = 8

    member this.Describe() = $"This is a size {size} shoe"
```

Класи слугують шаблонами для створення обʼєктів. Щоб створити екземпляр класу, назву класу викликають як функцію. Екземпляр класу також називають _обʼєктом_.

До членів обʼєкта можна звертатися за допомогою точкової нотації.

```fsharp
let myShoe = Shoe()
myShoe.Describe()
// => "This is a size 8 shoe"
```
