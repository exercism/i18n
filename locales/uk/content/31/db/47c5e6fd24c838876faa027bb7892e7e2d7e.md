# Інструкції

Елейн працює над новою дитячою грою, у якій є тварини та чарівні палички.
Настав час написати функції для кидання грального кубика, генерування випадкової енергії палички та перемішування зрізу.

## 1. Кидання грального кубика

Реалізуйте функцію `RollADie`.

Це буде традиційний двадцятигранний кубик із числами від 1 до 20.

```go
d := RollADie() // d will be assigned a random int, 1 <= d <= 20
```

## 2. Генерування енергії палички

Реалізуйте функцію `GenerateWandEnergy`.
Енергія палички має бути випадковим числом з плаваючою комою, більшим або рівним 0.0 і меншим за 12.0.

```go
f := GenerateWandEnergy()  // f will be assigned a random float64, 0.0 <= f < 12.0
```

## 3. Перемішування зрізу

У грі є вісім різних тварин:

- ant
- beaver
- cat
- dog
- elephant
- fox
- giraffe
- hedgehog

Напишіть функцію `ShuffleAnimals`, яка повертає зріз із цими вісьмома тваринами у випадковому порядку.
