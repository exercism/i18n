# Інструкції

Ми великі поціновувачі моделей потягів і вирішили поділитися своїм захопленням зі світом, започаткувавши розсилку новин. Почнімо з того, що надішлемо перший випуск нашої розсилки друзям і знайомим, які поділяють наше захоплення. У нас є текстовий файл зі списком їхніх адрес електронної пошти.

## 1. Прочитати адреси електронної пошти з файлу

Реалізуйте функцію `Newsletter.read_emails/1`. Вона має приймати шлях до файлу. Це текстовий файл, що містить адреси електронної пошти, розділені символами нового рядка. Функція має повернути масив адрес електронної пошти з файлу.

```elixir
Newsletter.read_emails("/home/my_user/documents/model_train_friends_emails.txt")
# => ["rick@example.com", "choochoo42@example.com", "anna@example.com"]
```

## 2. Відкрити файл журналу для запису

Надсилання електронного листа може не вдатися з багатьох непередбачуваних причин, як-от одруківка в адресі електронної пошти чи тимчасові проблеми з мережею. Щоб мати змогу повторити надсилання листів усім друзям і не надіслати дублікатів, потрібно записувати в журнал адреси, які вже отримали лист. Для цього знадобиться файл журналу.

Реалізуйте функцію `Newsletter.open_log/1`. Вона має приймати шлях до файлу, відкривати файл для запису й повертати PID процесу, який обслуговує цей файл.

```elixir
Newsletter.open_log("/home/my_user/documents/newsletter_issue1_log.txt")
# => #PID<0.145.0>
```

## 3. Записати надісланий лист у журнал

Реалізуйте функцію `Newsletter.log_sent_email/2`. Вона має приймати PID процесу, який обслуговує файл, і рядок тексту (англ. string) з адресою електронної пошти. Вона має записати адресу електронної пошти у файл, додавши після неї символ нового рядка.

```elixir
Newsletter.log_sent_email(pid, "joe@example.com")
# => :ok
```

## 4. Закрити файл журналу

Реалізуйте функцію `Newsletter.close_log/1`. Вона має приймати PID процесу, який обслуговує файл, і закривати файл.

```elixir
Newsletter.close_log(pid)
# => :ok
```

## 5. Надіслати розсилку новин

Тепер, коли в нас є всі складники процедури надсилання листів, потрібно поєднати їх в одній функції.

Реалізуйте функцію `Newsletter.send_newsletter/3`. Вона має приймати шлях до файлу з адресами електронної пошти, шлях до файлу журналу й анонімну функцію, яка надсилає лист на вказану адресу електронної пошти. Вона має прочитати всі адреси електронної пошти з указаного файлу й спробувати надіслати лист на кожну з них. Якщо анонімна функція, яка надсилає лист, повертає `:ok`, запишіть адресу електронної пошти у файл журналу, додавши після неї символ нового рядка. Обовʼязково зробіть це одразу після надсилання листа. Коли всі листи надіслано, закрийте файл журналу.

```elixir
Newsletter.send_newsletter(
  "model_train_friends_emails.txt",
  "newsletter_issue1_log.txt",
  fn email -> :ok end
)

# => :ok
```
