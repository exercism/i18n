# Вступ

## Основи

Вирушаючи в подорож C++, ми почнемо зі змінних, викликів функцій і коментарів.

### Коментарі

Коментарі бувають двох видів: однорядкові та багаторядкові.
Усе, що йде після `//` у тому ж рядку, компілятор ігнорує.
Багаторядкові коментарі також називають коментарями в стилі C.
Їх обрамляють символами `/*` і `*/`.
Усе, що стоїть між ними, також буде проігноровано.

### Змінні

C++ належить до типізованих мов.
Усі типи мають бути відомі під час компіляції, і зазвичай їх потрібно вказувати явно.
Тип змінної не може змінюватися.
Змінну цілого типу з назвою `years` можна оголосити так:

```cpp
int years;
```

Гарною практикою є ініціалізація змінних під час оголошення.
C++ пропонує для цього різні механізми.
Варіант із фігурними дужками більше відповідає сучасному C++, але варіант зі знаком рівності теж дуже поширений.

```cpp
int tomatoes{80};
int potatoes = 40;
```

~~~~exercism/caution
C++ справді дозволяє використовувати неініціалізовані змінні.
Доки змінній навмисно не надано значення, вона невизначена й може містити будь-що.
Щоб уникнути помилок використання до присвоєння та невизначеної поведінки, радимо **завжди ініціалізувати змінні**.
Невизначена поведінка може спричинити збій програми в найгірший момент, хоча раніше вона працювала бездоганно.
Це варто підкреслити ще раз: уникаймо невизначеної поведінки за будь-яку ціну.
~~~~

### Арифметичні операції

Арифметичні оператори, як-от `*`, `+` чи `-`, можуть бути частиною виразу, наприклад `3 * 2` або `tomatoes + potatoes`.

### Оновлення змінних

Змінним можна присвоювати нові значення, якщо вони зберігають свій тип:

```cpp
tomatoes = tomatoes - 5; // tomatoes is now 75
potatoes = (32 * 2) + 11; // potatoes is now 75 as well
```

### Функції

Функція має назву, тип поверненого значення та (можливо, порожній) список параметрів.
Ось приклад функції з назвою `always_fortyseven`, яка завжди повертає 47:

```cpp
int always_fortyseven() {
    return 47;
}
```

А ось `vip_fee` з одним параметром:

```cpp
int vip_fee(int standard_fee) {
    /*
    vip_fee calculates the vip fee based on the standard_fee.
    */
    int vip_multi{3};
    return standard_fee * vip_multi;
}
```

Або `total_fee`, функція з трьома параметрами, що викликає іншу функцію.

```cpp
int total_fee(int vips, int adults, int kids) {
    /*
    total_fee calculates the total price for a group of VIP and adult guests with kids.
    Kids get a flat discount on the standard fee.
    VIP guest fees are calculated by calling vip_fee.
    */
    int standard_fee{30};
    int kids_discount{15};

    int kids_total_fee = kids * (standard_fee - kids_discount);
    int vips_total_fee = vips * vip_fee(standard_fee);
    int adult_total_fee = adults * standard_fee;

    return vips_total_fee + adult_total_fee + kids_total_fee;
}
```

У C++ функції не повертають значення останньої інструкції, як у деяких інших мовах.
Щоб код скомпілювався, потрібне ключове слово `return`.

### Пробільні символи

Пробільні символи використовують для форматування вихідного коду; до них належать пробіли, табуляції та переходи на новий рядок.
Оскільки компілятор ігнорує зайві пробільні символи, їх можна використовувати, щоб структурувати код.
Розумне використання пробільних символів може поліпшити читабельність коду.
Існують різні стандарти форматування, але всі вони умовні, і компілятор їх не вимагає.

```cpp
// Formatting makes it easier to find bugs

int eggs_yolks =  3;
int      yeast = 15;

int flour=500;int sugar=200;// compact, but difficult to read
```
