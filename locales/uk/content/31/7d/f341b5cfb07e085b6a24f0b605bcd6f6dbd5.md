# Встановлення

## Встановлення Node.js

**Користувачі Windows та OS X**: встановіть [Node.js][node] [через менеджер пакетів][node-download].

**Користувачі Linux**: встановіть [Node.js][node] за інструкціями, знайденими для свого дистрибутива на сторінці [менеджера пакетів Node.js][linstall].

## Встановлення `jasmine-node` і `coffeescript`

Для більшості користувачів усе зведеться до виконання такої команди:

```bash
$ npm install -g jasmine-node coffeescript
```

Залежно від налаштувань, для глобального встановлення модуля `npm` можуть знадобитися права суперкористувача.
Це стосується випадків, коли використано офіційний інсталятор, посилання на який наведено вище.
Якщо NPM видає помилку про відсутність доступу, додайте `sudo` до наведеної вище команди:

```bash
$ sudo npm install -g jasmine-node coffeescript
```

Якщо використано офіційний інсталятор, `PATH` мав налаштуватися автоматично. Але якщо оболонка не може знайти глобально встановлені модулі, або якщо Node.js зібрано з вихідного коду, тоді оновіть `PATH`, щоб він містив бінарні файли `npm`, додавши наведене нижче до `~/.bash_profile` або `~/.zshrc`:

```bash
$ export PATH=/usr/local/share/npm/bin:$PATH
```
