# Вступ

## Фільтрування винятків

`when` - це ключове слово для фільтрування винятків. Його розміщують після інструкції `catch`, і воно може приймати булевий вираз (англ. Boolean), що містить будь-які значення, доступні в області видимості на той момент. Якщо вираз обчислюється як правда, то виконується блок, повʼязаний із цією інструкцією `catch`, інакше перевіряється наступна інструкція `catch`, якщо вона є.

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```

## Визначені користувачем винятки

Визначений користувачем виняток - це будь-який клас, визначений у нашому коді, який походить від `System.Exception`. Він підлягає всім правилам успадкування класів, але, крім того, компілятор і середовище виконання мови ставляться до таких класів особливим чином, дозволяючи генерувати та перехоплювати їхні екземпляри поза звичайним потоком керування, як розглядається у вправі `exceptions`.

Визначені користувачем винятки часто використовують, щоб передавати додаткову інформацію: повідомлення та інші доречні дані, які мають бути доступні коду, що перехоплює виняток.
