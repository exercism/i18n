# Оператори порівняння

У PHP є десять вбудованих операторів порівняння:

| Назва  | Приклад    | Результат                                             |
| ----- | ---------- | -------------------------------------------------- |
| Рівність | `$a == $b` | правда, якщо `$a` дорівнює `$b` після перетворення типів. |
| Ідентичність | `$a === $b` | правда, якщо `$a` дорівнює `$b` і має той самий тип. |
| Нерівність | `$a != $b` | правда, якщо `$a` не дорівнює `$b` після перетворення типів. |
| Нерівність | `$a <> $b` | правда, якщо `$a` не дорівнює `$b` після перетворення типів. |
| Неідентичність | `$a !== $b` | правда, якщо `$a` не дорівнює `$b` або має інший тип. |
| Менше | `$a < $b` | правда, якщо `$a` строго менше за `$b`. |
| Більше | `$a > $b` | правда, якщо `$a` строго більше за `$b`. |
| Менше або дорівнює | `$a <= $b` | правда, якщо `$a` менше або дорівнює `$b`. |
| Більше або дорівнює | `$a >= $b` | правда, якщо `$a` більше або дорівнює `$b`. |
| Космічний корабель | `$a <=> $b` | повертає ціле число, менше, рівне або більше за `0`, коли `$a`. |

У PHP є окремі визначення, які розрізняють `equal` та `identical`.
Іноді `identical` також називають `strictly equal`.

```php
<?php

// Comparisons between integer and numeric string values
1 == "1"; // => true, equal
1 === "1"; // => false, not identical

// Comparisons between integers and floating point values
1 == 1.0; // => true
1 === 1.0; // => false

// Comparisons between object instances
new stdClass() == new stdClass(); // => true, properties are equal
new stdClass() === new stdClass(); // => false, references are not identical
```
