# Перетворення коду символу на рядок тексту напряму

Найпростіший спосіб перетворити код символу на рядок тексту (англ. string) із цим символом - скористатися спеціальною формою `<<>>`. Проміжний крок у вигляді charlist тут не потрібен.

```elixir
# instead of:
to_string([?A])
# => "A"

# use:
<<?A>>
# => "A"
```
