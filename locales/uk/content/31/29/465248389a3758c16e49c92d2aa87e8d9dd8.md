# Уникайте операторів виведення

Спробуйте прибрати зі свого коду такі інструкції, як `System.out.println()`.
Тести вправи вимагають, щоб рішення _повертало_ значення з методів, а не друкувало їх.

Зазвичай такі інструкції додають, щоб допомогти з налагодженням коду.
Проте кращий підхід - налагоджувати код під час запуску одного або кількох модульних тестів.
Це має додаткову перевагу: можна зосередитися на налагодженні конкретного тесту.

Ось кілька посилань, які пояснюють, як налагоджувати код Java під час запуску модульних тестів у різних IDE:

- [Запуск і налагодження тестів Java у Visual Studio Code](https://code.visualstudio.com/docs/java/java-testing#_rundebug-test-cases)
- [Налагодження тестів в IntelliJ IDEA](https://www.jetbrains.com/help/idea/performing-tests.html#RedebugFailedTests)
