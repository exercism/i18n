# Числа

У Crystal є тип `Number`, базовий для всіх числових типів.
Усередині типу Number є два основні підтипи: [`Int`][int] і [`Float`][float].

`Int` - скорочення від англійського integer, він позначає цілі числа.
`Int` може бути як відʼємним, так і додатним, без десяткової коми.

```crystal
1.class
# => Int32

-1.class
# => Int32
```

`Float` позначає числа з десятковою комою.
`Float` може бути як відʼємним, так і додатним.

```crystal
10.5.class
# => Float64
```

## Перетворення між `Int` і `Float`

За допомогою методів 'to_i' і 'to_f' можна перетворювати значення між `Int` і `Float`.
Під час перетворення з `Float` у `Int` число округлюється вниз.

```crystal
1.to_f
# => 1.0

1.0.to_i
# => 1

1.9.to_i
# => 1
```

## Арифметичні оператори

До `Int` і `Float` можна застосовувати [основні арифметичні оператори][math].
Це оператори `+`, `-`, `*`, `/` та `%`.
Використовуючи ці оператори, можна поєднувати `Int` і `Float`.

### Додавання, віднімання та множення

Оператор `+` використовується для додавання, оператор `-` - для віднімання, а оператор `*` - для множення.

| Оператор | Приклад        |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### Ділення

Ділення використовується, щоб ділити числа.
Оператор `/` використовується для ділення.
Результат завжди буде типу Float.

```crystal
4 / 2
# => 2.0

4.0 / 2
# => 2.0
```

~~~~exercism/caution
У деяких мовах програмування ділення на нуль призводить до помилки.

У Crystal ділення на нуль дає `Infinity` або `-Infinity`.
Єдиний виняток - ділення нуля на нуль, результатом якого є `NaN` (Not a Number).
`Infinity` і `NaN` - особливі значення типу `Float`.

```crystal
1 / 0
# => Infinity

-1 / 0
# => -Infinity

0 / 0
# => NaN
```
~~~~

## Цілочисельне ділення

Цілочисельне ділення використовується, щоб поділити числа й отримати цілу частину результату.
Результат завжди округлюється вниз до типу Int.

```crystal
4.0 // 2
# => 2

4.5 // 2
# => 2
```

~~~~exercism/caution
Ділення на нуль під час цілочисельного ділення призводить до помилки `DivisionByZeroError`.
Це відрізняється від звичайного ділення.
~~~~

### Остача

Остача використовується, щоб отримати остачу від ділення.
Оператор `%` використовується для взяття остачі.

```crystal
5 % 2
# => 1

5.0 % 2
# => 1.0

5 % 3
# => 2
```

~~~~exercism/caution
Ділення на нуль під час взяття остачі призводить до помилки DivisionByZeroError.
Це відрізняється від звичайного ділення.

```crystal
1 % 0
# Error: Unhandled exception: Division by 0 (DivisionByZeroError)
```
~~~~

## Піднесення до степеня

Піднесення до степеня використовується, щоб піднести число до степеня.
Оператор `**` використовується для піднесення до степеня.
Результат операції з `Float` і `Int` буде `Float`.

```crystal
2 ** 2
# => 4

2.0 ** 2
# => 4.0
```

## Округлення

Метод `round` приймає необовʼязковий аргумент: кількість десяткових знаків для округлення.
Типова кількість десяткових знаків дорівнює 0.

```crystal
1.0.round
# => 1

1.5.round
# => 2

1.234.round(2)
# => 1.23
```

### Округлення вгору та вниз

Також можна округлювати вгору або вниз до `Int` за допомогою методів `ceil` і `floor`.
Метод `ceil` округлює вгору, а метод `floor` - вниз.

```crystal
1.0.ceil
# => 1

1.2.ceil
# => 2

1.7.floor
# => 1
```

## Пріоритет і дужки

Crystal дозволяє використовувати дужки (`()`), якими можна групувати вирази.
Це корисно, коли потрібно змінити порядок виконання операцій.

Коли ми використовуємо кілька арифметичних операторів, порядок виконання операцій такий самий, як у математиці, також відомий як [PEMDAS][pemdas].
Він дотримується такого порядку: дужки (`()`), степені (`**`), множення (`*`) і ділення (`/`), додавання (`+`) і віднімання (`-`).

```crystal
2 + 3 - 4 * 4
# => -11

(2 + 3 - 4) * 4
# => 4
```
