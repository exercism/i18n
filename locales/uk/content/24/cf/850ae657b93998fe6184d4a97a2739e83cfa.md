# Вступ

Динамічну памʼять реалізують функції бібліотеки, які програміст використовує, щоб виділяти та звільняти памʼять під час виконання програми.
Оскільки програміст керує виділенням і звільненням памʼяті, динамічна памʼять настільки безпечна, наскільки програміст вільний від людських помилок.
Із цієї причини динамічна памʼять - одне з головних джерел багів і одна з головних цілей хакерських атак.

## malloc

`malloc` - це функція, оголошена в `stdlib.h`, яку використовують для виділення динамічної памʼяті.
Якщо виділення успішне, повертається вказівник, який указує на адресу першого байта виділеної памʼяті.
Якщо виділення не вдалося, повертається `NULL`.
Буде розсудливо перевірити результат `malloc` на `NULL` і коректно обробити невдачу.
Повернений вказівник має тип `pointer-to-void`, який приблизно можна вважати «узагальненим» вказівником, що його можна перетворити на конкретний тип, який використовує памʼять.
`malloc` має один параметр: розмір потрібної памʼяті в байтах.
Загальний розмір для виділення масиву дорівнює розміру типу даних кожного елемента, помноженому на кількість елементів.
Оператор `sizeof` зазвичай використовують, щоб отримати розмір типу даних кожного елемента.
Це демонструє наступний приклад

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // pointer-to-void from malloc is converted to a pointer-to-int
    int * numbers = malloc(sizeof(int) * count);
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    // printed The size of numbers is 8 bytes (can vary by system)
    printf("The size of numbers is %zu bytes\n", sizeof(numbers));
    numbers[0] = 1;
    numbers[1] = 2;
    numbers[2] = 3;
    // prints The first element of the array is 1
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The second element of the array is 2
    printf("The second element of the array is %d\n", numbers[1]);
    // prints The third element of the array is 3
    printf("The third element of the array is %d\n", numbers[2]);
    free(numbers);
    numbers = NULL;
}
```

Важливо памʼятати, що памʼять, яку щойно виділив `malloc`, не ініціалізована, але може містити сміттєві значення.
Зауважмо, що `sizeof` вказівника `numbers` не є ні кількістю елементів масиву, ні загальним обсягом виділеної памʼяті.
Розмір вказівника, який повертає `malloc`, дорівнює розміру будь-якого вказівника в цій конкретній системі.
Код із прикладу виконували в 64-бітній системі, тож розмір вказівника становив 8 байтів (помножено на 8 бітів у байті = 64 біти).
Тип вказівника неявно перетворили з вказівника на void на вказівник на int.
Його можна було б також перетворити явно: `int * numbers = (int *) malloc(sizeof(int) * count);`.
Якщо значення точно запишуть до того, як його прочитають, то `malloc` може бути ефективним способом виділити памʼять.
Але якщо є ймовірність, що значення прочитають до ініціалізації, то використовувати `malloc` ризиковано.
Безпечніший спосіб виділити памʼять - скористатися `calloc`, який ініціалізує щойно виділену памʼять нулями.

Зауважмо, що в прикладах вище використано `free(numbers)`.

## free

`free` - це функція, оголошена в `stdlib.h`, яку використовують, щоб звільняти памʼять, виділену динамічно.
Динамічно виділена памʼять залишається зайнятою, доки її не звільнить `free`.
Деякі операційні системи можуть автоматично звільняти динамічно виділену памʼять, коли програма завершується, але найкраща практика - не покладатися на це.
`free` має один параметр: вказівник на памʼять, яку виділили динамічно.
Вказівник, який не встановили на `NULL` після звільнення, називають висячим вказівником.
Висячий вказівник може вказувати на іншу памʼять, ніж та, для якої його призначали.
Отже, висячий вказівник може призвести до пошкодження даних і довільної підміни та виконання коду.
Вказівник на виділену памʼять, який не обнулили, встановивши на `NULL`, можна використати, щоб зламати програму.
Найкраща практика - встановлювати вказівник на `NULL` після того, як його передали `free`.

## calloc

`calloc` - це функція, оголошена в `stdlib.h`, яку використовують і для виділення динамічної памʼяті, і для ініціалізації щойно виділеної памʼяті нулями.
Якщо виділення успішне, повертається вказівник, який указує на адресу першого байта виділеної памʼяті.
Якщо виділення не вдалося, повертається `NULL`.
Буде розсудливо перевірити результат `calloc` на `NULL` і коректно обробити невдачу.
Повернений вказівник має тип `pointer-to-void`, який приблизно можна вважати «узагальненим» вказівником, що його можна перетворити на конкретний тип, який використовує памʼять.
`calloc` має два параметри.
Перший параметр указує, скільки елементів указаного типу даних треба виділити.
Другий параметр указує розмір указаного типу даних, який треба виділити.

У наступному прикладі всі інструкції `printf` завжди повинні показувати `0`, бо `calloc` гарантовано обнуляє щойно виділені значення.

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // allocates the amount of bytes in an int, multiplied by count
    int * numbers = calloc(count, sizeof(int));
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    // prints The first element of the array is 0
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The second element of the array is 0
    printf("The second element of the array is %d\n", numbers[1]);
    // prints The third element of the array is 0
    printf("The third element of the array is %d\n", numbers[2]);
    free(numbers);
    numbers = NULL;
}
```

## realloc

`realloc` - це функція, оголошена в `stdlib.h`, яку використовують, щоб розширювати або звужувати вже виділену памʼять.
Якщо перевиділення успішне, повертається вказівник, який указує на адресу першого байта перевиділеної памʼяті.
Якщо перевиділення не вдалося, повертається `NULL`.
Буде розсудливо перевірити результат `realloc` на `NULL` і коректно обробити невдачу.
`realloc` має два параметри.
Перший параметр - це вказівник на наявну памʼять, яку треба перевиділити.
Другий параметр указує розмір у байтах перевиділеної памʼяті.
Значення, установлені до розширення памʼяті, зберігаються.
Важливо памʼятати, що памʼять, додану під час розширення, не ініціалізують нулями, і її значення може бути будь-яким.
Крім того, памʼять, яку прибирають під час звуження, також не ініціалізують, і вона може зберігати старі значення.
Наступний приклад демонструє розширення та звуження масиву

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // allocates the amount of bytes in an int, multiplied by count
    int * numbers = calloc(count, sizeof(int));
    return numbers;
}

int * my_function_2 (int * ptr , int count) {
    // reallocates the memory to the size of an int multiplied by count
    int * numbers = realloc(ptr, sizeof(int) * count);
    // if realloc fails, exit the program
    if (!numbers) exit(-1);
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    numbers[0] = 1;
    numbers[1] = 2;
    numbers[2] = 3;
    // expand the size of the array
    numbers = my_function_2(numbers, 6);
    // prints The first element of the array is 1
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The sixth element of the array is [whatever is there]
    // the additional memory is not initialized, so it could be
    // 0 or it could be 18728 or anything else
    printf("The sixth element of the array is %d\n", numbers[5]);
    numbers[5] = 6;
    // shrink the size of the array
    numbers = my_function_2(numbers, 3);
    // prints The sixth element of the array is [whatever is there]
    // the removed memory is not initialized, so it could be
    // 6 or it could be 43164 or anything else
    printf("The sixth element of the array is %d\n", numbers[5]);
}
```
