# Вступ

На цілі числа можна дивитися не лише як на числові значення, а як на послідовності бітів. Словник [`math`][math] у Factor містить стандартні низькорівневі операції над цими послідовностями бітів, а словник [`math.bitwise`][bitwise] додає кілька допоміжних засобів для роботи зі значеннями фіксованої ширини.

## Побітові зсуви

`shift ( m n -- m' )` зсуває біти `m`. *Додатне* `n` зсуває вліво (множачи на 2 на кожному кроці); *відʼємне* `n` зсуває вправо (ділячи на 2 на кожному кроці):

```factor
3 2 shift .     ! => 12   (3 << 2)
24 -3 shift .   ! => 3    (24 >> 3)
```

Для додатних цілих чисел зсув вправо відкидає біти знизу й заповнює нулями. Для *відʼємних* цілих чисел `shift` у Factor працює арифметично, зберігаючи знаковий біт і концептуально заповнюючи зліва копіями знакового біта. (Цілі числа у Factor мають довільну точність, тож «ліворуч» сягає так далеко, як потрібно.)

## Побітова логіка

Чотири базові логічні операції:

```
bitor  ( x y -- z )   ! 1 in either operand
bitand ( x y -- z )   ! 1 in both operands
bitxor ( x y -- z )   ! 1 in exactly one operand
bitnot ( x   -- z )   ! flip every bit
bit?   ( x n -- ? )   ! true when bit at position n is set
```

```factor
0b1011 0b0010 bitor .    ! => 11  (0b1011)
0b1011 0b0010 bitand .   ! => 2   (0b0010)
0b1011 0b0010 bitxor .   ! => 9   (0b1001)
0b1011 bitnot .          ! => -12
0b1011 0 bit? .          ! => t   (low bit is set)
0b1011 2 bit? .          ! => f   (bit 2 is clear)
```

`bitnot` від `0b1011` дорівнює `-12`, бо цілі числа у Factor мають довільну точність: перевертання бітів `0b1011` концептуально дає «усі одиниці, а молодші чотири біти перевернуто на `0100`», що при читанні як знакове число довільної точності дає `-12`.

## Розгляд значення як N бітів

`bits ( x n -- y )` зі словника `math.bitwise` маскує `x` до його молодших `n` бітів. Це спосіб у Factor «переінтерпретувати значення як N-бітове беззнакове ціле число»:

```factor
-1 8 bits .              ! => 255   (lowest 8 bits of -1 are all 1)
-2144333657 32 bits .    ! => 2150633639
```

Другий приклад важливий для цієї вправи. Якщо ми починаємо з відʼємного значення Int32 у доповняльному коді й хочемо «логічно» зсунути його вправо (із заповненням нулями зліва) на `amount`, то ідіома Factor така:

```
( value -- shifted )
32 bits  amount neg  shift
```

Спочатку маскуємо до 32 бітів, щоб перейти до беззнакової інтерпретації, а потім зсуваємо. Оскільки замасковане значення невідʼємне, `shift` просто відкидає біти знизу й доповнює нулями.
