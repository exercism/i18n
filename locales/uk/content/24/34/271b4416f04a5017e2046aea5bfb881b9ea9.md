# Інструкції

Ларрі, Lisp-прибулець, любить писати код, щоб грати в ігри.
Сьогодні йому потрібно написати кілька функцій, які допоможуть у грі, дуже схожій на хрестики-нулики.

Як і в хрестики-нулики, у цю гру грають на дошці, яка має вигляд сітки 3x3.

## 1. Починаємо з нуля

Спочатку Ларрі потрібна функція, яка створює порожню дошку `make-empty-board`.
Усі комірки дошки повинні мати значення `NIL`.

```lisp
(make-empty-board) ; => #2A((NIL NIL NIL) (NIL NIL NIL) (NIL NIL NIL))
```

## 2. Починаємо з наявної дошки

Далі Ларрі потрібна функція, яка створює дошку зі списку рядків.
Наприклад:

```lisp
(make-board-from-list '((A B C) (D E F) (G H I))) ; => #2A((A B C) (D E F) (G H I))
```

## 3. Умова перемоги

Якщо три однакові символи стоять в один ряд, то цей гравець переміг.
Ларрі знадобиться функція `all-the-same-p`, яка для масиву з 3 елементів повертає `T`, якщо всі елементи однакові.
(для перевірки, чи два символи однакові, можна використати `eq`.)

```lisp
(all-the-same-p #(A A A)) ; => T
(all-the-same-p #(A B C)) ; => NIL
```

## 4. У рядку

Тепер Ларрі потрібен спосіб отримати елементи рядка.
Функція `row` приймає дошку та номер рядка і повертає масив елементів цього рядка.

```lisp
(row #2A((1 2 3) (4 5 6) (7 8 9)) 1) ; => #(4 5 6)
```

## 5. У стовпці

Наостанок Ларрі потрібен спосіб отримати елементи стовпця.
Функція `column` приймає дошку та номер стовпця і повертає масив елементів цього стовпця.

```lisp
(column #2A((1 2 3) (4 5 6) (7 8 9)) 1) ; => #(2 5 8)
```
