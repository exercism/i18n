# Вступ

## Деструктуризація масивів

Синтаксис деструктуризації масивів у JavaScript дає змогу стисло витягти значення з масиву та присвоїти їх окремим змінним.

У цьому прикладі кожне значення з масиву `numberOfMoons` присвоюється відповідній планеті:

```javascript
const numberOfMoons = [0, 2, 14];
const [venus, mars, neptune] = numberOfMoons;

neptune;
// => 14
```

Стисло:

- Синтаксис дозволяє давати назви _позиційним_ елементам масиву, а також міняти змінні місцями за допомогою повторного присвоєння.
- Синтаксис деструктуризації можна використовувати всередині параметрів функції, і він працює з будь-яким обʼєктом, який можна перебрати.
- Якщо залишити позицію без назви (не написавши _жодної_ назви змінної), ця позиція просто ігнорується.

## Деструктуризація обʼєктів

У JavaScript також є синтаксис деструктуризації, який дозволяє витягти властивості з обʼєкта та присвоїти їх окремим змінним.

У цьому прикладі з обʼєкта `weather` витягуються символи погоди:

```javascript
const weather = {
  sun: '☀️',
  sun_behind_small_cloud: '🌤️',
  sun_behind_cloud: '⛅',
  sun_behind_large_cloud: '🌥️',
  sun_behind_rain_cloud: '🌦️',
  cloud: '☁️',
  cloud_with_rain: '🌧️',
  cloud_with_snow: '🌨️',
  cloud_with_lightning: '🌩️',
  cloud_with_lightning_and_rain: '⛈️',
};

const { sun, cloud, cloud_with_lightning: thunder } = weather;

sun;
// => '☀️'

cloud;
// => '☁️'

thunder;
// => '🌩️'
```

Стисло:

- Синтаксис дозволяє і просто витягувати властивості, і витягувати їх із перейменуванням.
- Синтаксис деструктуризації можна використовувати всередині параметрів функції.
