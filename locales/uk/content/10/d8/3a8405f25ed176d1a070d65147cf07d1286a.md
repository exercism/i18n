# Про масив

У Elm [`Array`][array] - це швидка незмінна колекція, що містить нуль або більше значень одного типу.

На відміну від `List`, який є [типовим імпортом][default-imports], модуль `Array` потрібно імпортувати явно, за допомогою `import Array` або подібного.

Масиви можна визначити так:

```elm
import Array exposing (Array)

empty : Array Char
empty = Array.empty

singleValue = Array.fromList [ 5 ] --> Array Int

repeatSingleValue = Array.repeat 2 5 --> Array.fromList [ 5, 5 ]

initialiseFromIndex = Array.initialise 3 (\index -> index * 2) --> Array.fromList [ 0, 2, 4 ]

initialisefromList = Array.fromList [ "a", "b", "c" ] --> Array.fromList [ "a", "b", "c" ]
```

Елементи додаються до масиву за допомогою `Array.push`:

```elm
twoToFour = Array.fromList [ 2, 3, 4 ]
oneToFour = Array.push 1 twoToFour --> Array.fromList [ 1, 2, 3, 4 ]
```

Елемент у масиві отримують за допомогою `Array.get`:

```elm
sixSeven = Array.fromList [ 6, 7 ]
Array.get 0 sixSeven --> Just 6
```

Елемент у масиві встановлюють за допомогою `Array.set`:

```elm
sixSeven = Array.fromList [ 6, 7 ]
Array.set 1 8 sixSeven --> Array.fromList [ 6, 8 ]
```

З масивами працюють за допомогою функцій, визначених у [модулі `Array`][array-module].

```elm
oneTwo = Array.fromList [ 1, 2 ]
Array.length oneTwo --> 2
```
