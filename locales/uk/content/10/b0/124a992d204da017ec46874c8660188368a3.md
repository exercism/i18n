# Вступ

У Go рядки тексту (англ. string) є незмінними.
Конкатенація рядків тексту за допомогою `+` у циклі спричиняє часті виділення памʼяті та багаторазове копіювання даних.
Пакет [`strings`](https://pkg.go.dev/strings) надає [`Builder`](https://pkg.go.dev/strings#Builder), щоб мінімізувати накладні витрати памʼяті завдяки ефективному збиранню рядків тексту.

## Побудова рядків тексту

Нульове значення `strings.Builder` готове до використання одразу, без жодної явної ініціалізації чи виділення памʼяті.
Ми можемо додавати нові дані до білдера за допомогою спеціальних методів запису.
Кожен метод запису повертає значення помилки, щоб відповідати стандартним інтерфейсам Go, але гарантовано, що це завжди `nil`, тож у повсякденному коді його зазвичай ігнорують.

Найчастіше використовувані методи:

- `WriteString(s string) (int, error)`: додає рядок тексту до буфера.
- `WriteRune(r rune) (int, error)`: додає UTF-8 кодування руни.
- `WriteByte(c byte) error`: додає один байт.

```go
var sb strings.Builder

sb.WriteString("Hello")
var r rune = ' '
sb.WriteRune(r)
var b byte = '.'
sb.WriteByte(b)
```

## Отримання вмісту та скидання

Коли ми завершили збирання тексту, накопичений вміст можна отримати як звичайний рядок тексту Go, викликавши метод `String()`.
Виклик `String()` є дуже дешевою операцією, бо він повертає базовий зріз байтів як рядок тексту безпосередньо, без копіювання накопичених даних.

Якщо потрібно повторно використати той самий екземпляр білдера, щоб зібрати новий рядок тексту (наприклад, у циклі), можна викликати метод `Reset()`.
Він спорожнює внутрішній буфер, дозволяючи почати з нуля й зібрати наступний рядок тексту, зберігаючи при цьому вже виділену ємність памʼяті усередині.

```go
var sb strings.Builder

sb.WriteString("Task One")
fmt.Println(sb.String()) // Output: Task One

// Clear the buffer for resource reuse
sb.Reset()

sb.WriteString("Task Two")
fmt.Println(sb.String()) // Output: Task Two
```
