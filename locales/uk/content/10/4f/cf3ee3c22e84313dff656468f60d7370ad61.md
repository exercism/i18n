# Case

[Конструкція case][case] (часто її називають switch в інших мовах) належить до керуючих виразів, як if-else.
Конструкція case дозволяє обʼєднувати кілька інструкцій if-else-if у ланцюжок і може бути зрозумілішою, водночас забезпечуючи керування потоком.

Конструкція case визначається ключовим словом `case`, після якого йде необовʼязковий вираз.
Далі для кожного case використовується ключове слово `when`, після якого йде вираз, що порівнюється з виразом case.
Ключове слово `when` не повинно мати відступу відносно ключового слова `case`.
Після ключового слова `when` розміщується код, який потрібно виконати, якщо вираз case збігається з виразом when.
Конструкція case дозволяє використовувати необовʼязкову інструкцію `else`, яка виконується, якщо жоден інший case не збігається.

Вираз case обчислюється, а потім порівнюється з кожним виразом `when`.
Порівняння виконується за допомогою оператора рівності case (`===`).

```ruby
value = 1
case value
when 1
  "One"
when 2
  "Two"
else
  "Other"
end

# This is the same as:
value = 1
if 1 === value
  "One"
elsif 2 === value
  "Two"
else
  "Other"
end
```

## Оператор рівності case (`===`)

Оператор рівності case (`===`) трохи відрізняється від оператора рівності (`==`).
Цей оператор перевіряє, чи належить права частина множині, яку описує ліва частина.
Це означає, що важливо, з якого боку розміщено кожен операнд.
Те, як це працює, залежить від типу лівої частини. Наприклад, `Range` перевіряє, чи належить права частина діапазону, а `Object` перевіряє, чи є права частина екземпляром `Object`.

```ruby
(1..3) == 1  # => false
(1..3) === 1 # => true

String == "foo"  # => false
String === "foo" # => true
```

## Конструкція case з кількома виразами

Конструкція case дозволяє зіставляти кілька виразів в одному case, де кожне можливе значення відокремлюється комою.
Вона виконає код, якщо збігається хоча б один із виразів.
Це може бути корисно, коли потрібно, щоб один case мав кілька можливих значень.

```ruby
case var
when 1, 2
  "One or two"
else
  "Other"
end
```

## Конструкція case з діапазонами

Конструкція case також може перевіряти, чи значення належить діапазону.
Для цього використовують діапазон як вираз when.

```ruby
case var
when 1..3
  puts "One to three"
else
  puts "Other"
end
```

## Конструкція case без виразу case

Якщо вираз case не потрібен, його можна пропустити.
Тоді кожен вираз case перевіряється на істинність.
І вони поводяться як інструкції if-else-if.

```ruby
case
when 1 == 1
  "One is equal to one"
when 1 > 2
  "One is greater than two"
else
  "Other"
end
```

## Однорядковий when

Ruby дозволяє однорядкові інструкції case.
Це можна застосувати, коли потрібна проста однорядкова інструкція.
Однорядкова інструкція when записується як `when <expression> then <statement>`.
А в інструкції else вона записується як `else <statement>`.

```ruby
case var
when 1 then "One"
when 2 then "Two"
else "Other"
end
```

## Конструкція case з типами

Конструкція case дозволяє зіставляти значення за типами.
Це корисно, коли потрібна різна поведінка залежно від типу змінної.

```ruby
case var
when Integer
  "Integer"
when String
  "String"
else
  "Other"
end
```
