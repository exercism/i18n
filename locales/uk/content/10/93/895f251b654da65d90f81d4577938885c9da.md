# Інструкції

Еллен створює гру, у якій гравець має битися з прибульцями.
Вона щойно дізналася про обʼєктно-орієнтоване програмування (ООП) і прагне скористатися тим, що може дати її програмі використання `classes`.

На радість Еллен, ми запропонували їй допомогу, і вона доручила нам запрограмувати прибульців, з якими має битися гравець.


## 1. Створення класу Alien

Визначте клас Alien з конструктором, який приймає два параметри `<x_coordinate>` і `<y_coordinate>` та записує їх у змінні екземпляра `x_coordinate` і `y_coordinate`.
Кожен прибулець також починає з рівнем здоровʼя 3, тож змінну `health` теж потрібно ініціалізувати.

```python
>>> alien = Alien(2, 0)
>>> alien.x_coordinate
2
>>> alien.y_coordinate
0
>>> alien.health
3
```

Тепер кожен прибулець має самостійно відстежувати власну позицію та здоровʼя.

## 2. Метод `hit`

Еллен хотіла б, щоб `class` Alien мав метод `hit`, який під час виклику зменшує здоровʼя обʼєкта прибульця на 1.
Так вона зможе просто викликати `<alien>.hit()`, замість того щоб щоразу змінювати здоровʼя прибульця вручну.
Вирішуйте самі, чи `hit()` знижує здоровʼя _до_ нуля, чи _нижче_ за нуль.

```python
>>> alien = Alien(0, 0)

# Initialized health value.
>>> alien.health
3

# Decrements health by 1 point.
>>> alien.hit()
>>> alien.health
2
```

## 3. Метод `is_alive`

Зауважмо, що якщо здоровʼя й далі зменшуватиметься, то в якийсь момент воно, найімовірніше, досягне 0 (а то й менше!).
Було б добре додати метод `is_alive`, який Еллен зможе швидко викликати, щоб перевірити, чи прибулець... ну... живий. 😉
`<alien>.is_alive()` має повертати булеве значення (англ. Boolean).

```python
>>> alien.health
1
>>> alien.is_alive()
True
>>> alien.hit()
>>> alien.health
0
>>> alien.is_alive()
False
```

## 4. Метод `teleport`

У грі Еллен прибульці вміють телепортуватися!
Потрібно написати метод `teleport`, який приймає нові значення `x_coordinate` і `y_coordinate` та відповідно змінює координати прибульця.

```python
>>> alien.teleport(5, -4)
>>> alien.x_coordinate
5
>>> alien.y_coordinate
-4
```

## 5. Метод `collision_detection`

Очевидно, що якщо прибульців можна у щось влучити, то вони мають уміти визначати, коли таке зіткнення сталося.
Однак алгоритми виявлення зіткнень бувають непростими, і ми ще не знаємо, як реалізувати такий.
Еллен сказала, що зробить це пізніше, але все одно хотіла б, щоб метод `collision_detection` був у класі як нагадування про те, що цю функціональність треба допрацювати.
Він має приймати якусь змінну (ймовірно, інший обʼєкт), але це все, що ми поки що знаємо.
Потрібно подбати про те, щоб додавання визначення методу до класу не спричиняло помилок під час виклику:

```python
>>> alien.collision_detection(other_object)
>>>
```

## 6. Лічильник прибульців

Еллен повернулася з новим проханням.
Вона хоче відстежувати, скільки прибульців було створено за весь час існування гри.
Каже, що це якось повʼязано із системою нарахування очок.

Наприклад:

```python
>>> alien_one = Alien(5, 1)
>>> alien_one.total_aliens_created
1
>>> alien_two = Alien(3, 0)
>>> alien_two.total_aliens_created
2
>>> alien_one.total_aliens_created
2
# Accessing the variable from the class directly
>>> Alien.total_aliens_created
2
```

## 7. Створення масиву прибульців

Еллен захоплена тим, що ми вже зробили, але має ще одне прохання.
Вона хотіла б окрему функцію (_поза класом `Alien()`_), яка створює `list` з обʼєктів `Alien()`, отримуючи масив позицій (як `tuples`).

Наприклад:

```python
>>> alien_start_positions = [(4, 7), (-1, 0)]
>>> aliens = new_aliens_collection(alien_start_positions)
...
>>> for alien in aliens:
...     print(alien.x_coordinate, alien.y_coordinate)
(4, 7)
(-1, 0)
```
