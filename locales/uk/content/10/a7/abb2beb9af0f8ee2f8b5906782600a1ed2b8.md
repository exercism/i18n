# Вступ

C# є статично типізованою мовою, що означає, що все має тип під час компіляції. Присвоєння значення імені називається визначенням змінної. Змінну можна визначити або явно вказавши її тип, або дозволивши компілятору C# вивести її тип на основі присвоєного значення (що відомо як _виведення типу_). Отже, наступні два визначення змінних еквівалентні:

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

Оновлення значення змінної виконується за допомогою оператора `=`. Після визначення тип змінної ніколи не може змінитися.

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

C# є [обʼєктно-орієнтованою мовою][object-oriented-programming] і вимагає, щоб усі функції були визначені в _класі_. Ключове слово `class` використовується для визначення класу. Обʼєкти (або _екземпляри_) створюються за допомогою ключового слова `new`.

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

Функція в класі називається _методом_. Кожен метод може мати нуль або більше параметрів. Усі параметри повинні бути явно типізовані, для параметрів не існує виведення типу. Подібним чином, тип повернення також має бути явно вказаний. Значення повертаються з методів за допомогою ключового слова `return`. Щоб метод можна було викликати з коду в інших файлах, потрібно додати модифікатор доступу `public`.

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

Методи викликаються за допомогою синтаксису з крапкою (`.`) на екземплярі, вказуючи назву методу для виклику та передаючи аргументи для кожного параметра методу. Аргументи можуть додатково вказувати назву відповідного параметра.

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

Область видимості в C# визначається між символами `{` та `}`.

C# підтримує два типи коментарів. Однорядкові коментарі починаються з `//`, а багаторядкові коментарі вставляються між `/*` та `*/`.

[object-oriented-programming]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/object-oriented-programming
