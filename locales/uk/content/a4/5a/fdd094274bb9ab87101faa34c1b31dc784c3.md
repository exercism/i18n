# Null

`null` - примітивний тип даних з єдиним значенням `null`.
Часто `null` використовують для позначення відсутності значення.
Його вважають «неправдивим», але воно відрізняється від `false` та інших неправдивих значень.

```php
<?php

is_null(null); // => true
isset(null); // => false

null == true; // => false
null === true; // => false

null == false; // => true
null === false; // => false
```

## Робота зі значеннями `null`

У PHP значення `null` можуть бути частими причинами помилок, оскільки їх часто повертають замість стану помилки або щоб позначити відсутність значення.
Щоб запобігти виникненню помилок, часто потрібно робити «перевірку на `null`», аби переконатися, що значення не є `null`, перш ніж працювати з ним.

```php
<?php

$value = null;

$value->doSomething(); // throws an error as a null value is not an object instance.

if (!is_null($value)) {
    $value->doSomething(); // succeeds
}
```

Повторювана перевірка на `null` може призводити до помилок, тому PHP надає два оператори для роботи зі значеннями `null`: оператор безпечного доступу `?->` й оператор обʼєднання `??`.

```php
<?php

$value = null;
$result = $value?->doSomething(); // => return null rather than error
$result = $result ?? "default"; // => "default" is assigned to $result
```
