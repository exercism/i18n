# Про це

## Псевдоніми типів

У Gleam псевдонім типу дає змогу дати зручну назву наявному типу, який інакше було б громіздко записувати.

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

Якщо записати його з `pub type`, псевдонім можна використовувати поза модулем, у якому його визначено. Якщо `pub` опущено, псевдонім залишається приватним, і на нього не можна посилатися з інших модулів.
