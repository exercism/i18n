# Enum

Enum - це тип даних у Cairo, який використовують, щоб визначити набір наперед заданих варіантів для читабельності й безпеки коду.
У Cairo варіанти `enum` можна оголошувати так, щоб вони містили різні типи даних (цілі числа, `struct`, кортежі, інші `enum` тощо).

Наведений нижче фрагмент коду показує, як можна визначити enum:

```rust
#[derive(Drop)]
enum Direction {
    North,
    East,
    South,
    West,
}
```

Оголошений вище enum `Direction` - це простий enum із чотирма варіантами: `North`, `East`, `South` і `West`.
За домовленістю назви варіантів enum записують у PascalCase.
Кожен варіант - це окреме значення типу `Direction`.
У цьому прикладі жоден із варіантів enum не має повʼязаного значення, і його можна створити за таким синтаксисом:

```rust
let direction = Direction::North;
```

Нижче наведено той самий enum `Direction`, але з варіантами, що мають повʼязані значення, які зберігають точний градус напрямку:

```rust
#[derive(Drop)]
enum Direction {
    North: u128,
    East: u128,
    South: u128,
    West: u128,
}
```

Із цього прикладу видно, що кожен варіант enum `Direction` має повʼязане значення типу `u128`.
Такий enum можна створити так:

```rust
let direction = Direction::North(10);
```

## Приклад складного enum із власними типами

Enum можна оголосити так, щоб його варіанти поєднували різні типи даних.
У наведеному нижче прикладі `Action` - це складний enum, який має набір варіантів: `Quit`, `Direction`, `SendMessage`, `ChangeAvatar` і `ProfileState`.

```rust
#[derive(Drop)]
struct Move {
    up: u32,
    down: u32,
    right: u32,
    left: u32,
}

#[derive(Drop)]
enum UserCommand {
    Login,
    UpdateProfile,
    Logout,
}

#[derive(Drop)]
enum Action {
    Quit, //  variant with no associated value
    Direction: Move, // variant with the `Move` struct associated value
    SendMessage: felt252, // a single felt252 variant
    ChangeAvatarColor: (u8, u8, u8), // variant with the tuple of three associated values
    ProfileState: UserCommand // variant with an enum associated value
}
```

## Реалізація trait для enum

У Cairo можна визначати й реалізовувати trait для власних enum.
Це дає змогу визначати методи й атрибути, повʼязані з enum.
Нижче наведено приклад: ми визначаємо enum `Message` і реалізовуємо для нього trait `Processing`:

```rust
#[derive(Drop)]
enum Message {
    Quit,
    Echo: felt252,
    Move: (u128, u128),
}

trait Processing {
    fn process(self: Message);
}

impl ProcessingImpl of Processing {
    fn process(self: Message) {
        match self {
            Message::Quit => { println!("quitting") },
            Message::Echo(value) => { println!("echoing {}", value) },
            Message::Move((x, y)) => { println!("moving from {} to {}", x, y) },
        }
    }
}
```

Ось як можна використати цей trait, щоб обробити повідомлення `Quit`:

```rust
let msg: Message = Message::Quit;
msg.process(); // prints "quitting"
```

У багатьох ситуаціях enum стають у пригоді, особливо разом із конструкцією `match`, як у наведеній вище реалізації trait.
Докладніше про конструкцію `match` можна прочитати в [The Cairo Book][match].
