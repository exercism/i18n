# Вступ

У Clojure привʼязування значення до імені називають _змінною_. Змінні верхнього рівня (глобальні) схожі на константи в інших мовах, але їх часто перевизначають, щоб полегшити динамічну розробку.

Змінні верхнього рівня визначають за допомогою `def`:

```clojure
(def fingers 10)
```

Макрос `defn` можна використати, щоб визначити функцію, яка приймає нуль або більше аргументів. Функція завжди повертає результат останнього виразу у своєму тілі.

```clojure
(defn add [x y]
  (+ x y))
```

Щоб викликати функцію, треба вказати її назву й передати аргументи для кожного з її параметрів.

```clojure
(def five (add 2 3))
```

Функції та значення в Clojure можна використовувати лише _після_ того, як їх визначили. Якщо використати їх до визначення, виникне помилка компіляції.

```clojure
;; Compile error as `add` has not yet been defined
(def seven (add 3 4))

(defn add [x y]
  (+ x y))
```

У Clojure пробільні символи не мають жодного значення, крім форматування.

Функції та змінні в Clojure організовано в простори імен. Простір імен обʼєднує споріднену функціональність і визначається за допомогою макросу `ns`:

```clojure
(ns calculator)

(def pi 3.14)

(defn add [x y]
  (+ x y))
```

Clojure підтримує два типи коментарів. Однорядкові коментарі починаються з `;`, а форму `comment` використовують, щоб запобігти обчисленню всього між `(comment` і `)`.
