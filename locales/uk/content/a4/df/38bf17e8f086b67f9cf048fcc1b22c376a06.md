# Вступ

Спеціальна форма `import` дозволяє використовувати функції із зовнішнього модуля, не згадуючи назву цього модуля.

Імпорт усього зовнішнього модуля може створити конфлікти з наявними локальними функціями. Щоб цього уникнути, є два варіанти: `:except` і `:only`. Обидва приймають список ключових слів, у якому ключем є назва функції, а значенням - арність функції.

Зазвичай імпорти додають на початку визначення модуля.

```elixir
defmodule Square do
  import Integer, only: [pow: 2]

  def area(a), do: pow(a, 2)
end
```
