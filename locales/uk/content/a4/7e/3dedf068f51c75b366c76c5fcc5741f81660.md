# Докладніше

[Перевантаження методів][method-overloading] - ключова концепція в Java, яка дозволяє класу мати більше ніж один метод з однаковою назвою, за умови, що кожен метод має різний список параметрів.
Ця можливість лежить в основі обʼєктно-орієнтованого програмування в Java і дає змогу виконувати схожі операції з різними типами чи кількістю вхідних даних.
Перевантаження методів підвищує читабельність і впорядкованість коду, дозволяючи методам, які виконують схожі завдання, мати однакову назву.
Важливо зауважити, що перевантаження визначається сигнатурою методу, яка охоплює назву методу та список параметрів.

## Ключові моменти

- **Сигнатура має значення**: тип повернення не входить до сигнатури методу, тож сама лише зміна типу повернення методу не є перевантаженням.
- **Відмінності в параметрах**: перевантажені методи мають відрізнятися кількістю або типами параметрів.
- **Використання**: перевантаження часто застосовують, щоб зробити роботу з методом інтуїтивнішою для різних типів вхідних даних.

## Приклади перевантаження методів

Розгляньмо клас `Calculator`, який уміє додавати числа.
Перевантаження дозволяє різні варіанти додавання:

```java
public class Calculator {

    public int add(int a, int b) {
        return a + b;
    }

    public double add(double a, double b) {
        return a + b;
    }

    public int add(int a, int b, int c) {
        return a + b + c;
    }
}
```

## Найкращі практики

- **Зрозумілість**: перевантажені методи варто використовувати так, щоб код ставав інтуїтивнішим.
  - Поведінка перевантажених методів має бути спорідненою та узгодженою.
- **Уникаймо неоднозначності**: простежмо, щоб кожен перевантажений метод мав чітке призначення, а відмінності в списках параметрів були достатньо суттєвими, щоб не виникало плутанини.
- **Документація**: належно документуймо кожен варіант перевантажених методів.
  - Чітка документація допомагає іншим розробникам зрозуміти призначення та використання кожного варіанта методу.
- **Узгоджені типи повернення**: хоч типи повернення в перевантажених методах можуть відрізнятися, зазвичай краще, де це можливо, тримати їх узгодженими, щоб не виникало плутанини.
- **Обмежуймо перевантаження**: не варто зловживати перевантаженням методів.
  - Надмірне перевантаження ускладнює читання коду та його супровід.

## Висновок

Перевантаження методів - потужна можливість Java, яка за правильного використання може значно підвищити читабельність і гнучкість нашого коду.
Воно дозволяє методам бути універсальнішими та краще пристосовуватися до різних контекстів, а наші програми на Java стають модульнішими й зручнішими в супроводі.
