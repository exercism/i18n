# Про

Elm - чарівна мова для створення надійних вебзастосунків.
Вона має дружні повідомлення про помилки, високу продуктивність, компактні збірки й жодних винятків під час виконання.

Мабуть, найвідоміша й найбільш наслідувана частина Elm - The Elm Architecture, простий патерн для структурування вебзастосунків, за яким написано всі вебзастосунки на Elm.

Основна ідея в тому, що код будується навколо `Model` - стану застосунку, способу оновити його через `update` і способу показати його через `view`.

`Model` містить стан застосунку: усі дані, які йому потрібні.
Це може бути будь-який тип, але в будь-якому корисному застосунку це зазвичай [запис][record].
Уявімо простий застосунок із текстовим полем і текстом, що показує його у зворотному порядку. Тоді модель матиме такий вигляд.
Цей приклад також можна побачити в [посібнику Elm][elm-guide-text-fields].

```elm
type alias Model =
  { text : String
  }
```

`update` - це функція, яку викликають із `Msg`, коли відбувається зміна (наприклад, користувач натискає кнопку).
Вона приймає `Msg` і поточний `Model` та повертає новий `Model`.
`Msg` може бути будь-якого типу, але зазвичай це [власний тип][custom-type].

```elm
type Msg
  = TextChanged String

update : Msg -> Model -> Model
update msg model =
  case msg of
    TextChanged newText ->
      { model | text = newText }
```

Як і в усіх власних типах, варіанти `Msg` можуть містити стільки довільної інформації, скільки потрібно.
У наведеному прикладі варіант `TextChanged` містить `String`.

`view` - це функція, яка повертає HTML для показу користувачу в браузері.
Вона приймає поточний `Model` і повертає `Html Msg` (тип, який Elm використовує для подання HTML).
Кожен HTML-елемент (наприклад, `<div>`) має відповідну функцію Elm (`Html.div`) із пакета `Html`.
Кожна з цих функцій приймає два параметри: перший - список атрибутів (із пакетів `Html.Attributes` і `Html.Events`), а другий - список дочірніх елементів (функцій із пакета `Html`).
Також є функція `text`, що представляє вміст HTML як рядок тексту (англ. string); вона приймає лише параметр-рядок, але в усьому іншому використовується так само, як і решта функцій та елементів пакета `Html`.

Функція `view` може вказати, що певні події, як-от натискання кнопки чи редагування тексту в текстовому полі, створюють `Msg`. Середовище виконання Elm використає його, щоб викликати функцію `update`, змінити `Model` і згенерувати оновлений HTML.
У коді нижче це відбувається за допомогою `Html.Events.onInput TextChanged`.

```elm
view : Model -> Html Msg
view model =
  Html.div []
    [ Html.input
      [ Html.Attributes.placeholder "Text to reverse"
      , Html.Attributes.value model.text
      , Html.Events.onInput TextChanged
      ]
      []
    , Html.div [] [ Html.text (String.reverse model.text) ]
    ]
```

`Html.Events.onInput` приймає функцію (`String -> Msg`), яку використає, щоб створити `Msg`.
Різні події приймають різні функції залежно від того, яку інформацію вони можуть надати: наприклад, `Html.Events.onCheck` (для прапорців) приймає `Bool -> Msg`, а `Html.Events.onClick` - просто `Msg`.

Мова Elm - чиста й функціональна, і змінювати нічого не можна, тож усі зміни обробляє середовище виконання Elm.
Усі різні [HTML-елементи][html-elements], [атрибути елементів][element-attributes] та [HTML-події][html-events] можна побачити в реєстрі пакетів Elm.

Можна писати вебзастосунки 4 «рівнів», які стають дедалі потужнішими й складнішими (хоча Elm залишається напрочуд простою мовою та екосистемою).
Усі вони визначені в [пакеті Browser][browser-package]:

- [sandbox][browser-sandbox] - реагувати на ввід користувача, наприклад кнопки та прапорці
- [element][browser-element] - спілкуватися із зовнішнім світом через HTTP і взаємодію з JavaScript
- [document][browser-document] - керувати `<title>` і `<body>` вебсторінки
- [application][browser-application] - створювати повноцінні односторінкові застосунки, які обробляють маршрутизацію та зміни URL

У цьому концепті використовується [sandbox][browser-sandbox], бо він найпростіший (а ще, оскільки це пісочниця, з ним відносно легко працювати в онлайн-редакторі Exercism).
Вхідний модуль програми Elm має називатися `Main`, а функція, яка створює застосунок, - `main`, як показано нижче.

```elm
import Browser
import Html exposing (Html, Attribute, div, input, text)
import Html.Attributes exposing (placeholder, value)
import Html.Events exposing (onInput)

main =
  Browser.sandbox { init = init, update = update, view = view }

init : Model
init =
  { text = "" }

-- Add Model, Msg, update and view here
```

Ми вже бачили функції `update` і `view`, а [sandbox][browser-sandbox] додатково потребує функції `init`, яка повертає початковий стан `Model`.
