# Докладніше

Булеві значення (англ. Boolean) у Java представлені типом `boolean`, який може набувати значень `true` або `false`.

Java підтримує три оператори булевих значень, [оператори][operators]:

- `!` (заперечення): заперечує булеве значення
- `&&` (логічне і): приймає два булеві значення і дає правду, якщо обидва є правдою
- `||` (логічне або): дає правду, якщо хоча б одне з двох булевих значень є правдою

Оператори `&&` (і) та `||` (або) використовують _скорочене обчислення_, тобто праву частину оператора обчислюють лише тоді, коли це потрібно.

Їх також називають умовними або логічними операторами.
`!` у документації іноді класифікують як побітову операцію, але він має звичну семантику заперечення.

```java
true || false // => true
false || false // => false
false || true // => true
true && false // => false
true && true // => true
!true // => false
!false // => true
```

Кожен із трьох операторів булевих значень має свій [_пріоритет операторів_][precedence].
Як наслідок, вони обчислюються в такому порядку: спочатку `not`, потім `&&`, і нарешті `||`.
Якщо ми хочемо «обійти» ці правила, можна взяти булевий вираз у дужки (`()`), адже дужки мають ще вищий пріоритет операторів.

```java
!true && false   // => false
!(true && false) // => true
```
