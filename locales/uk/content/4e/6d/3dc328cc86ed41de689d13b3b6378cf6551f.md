# Вступ

## Інструкція _if-then_

Найпростіша інструкція керування потоком виконання в Java - інструкція _if-then_.
Цю інструкцію використовують, щоб виконати частину коду лише тоді, коли певна умова набуває значення `true`.
Інструкцію _if-then_ визначають за допомогою конструкції `if`:

```java
class Car {
    void drive() {
        // the "if" clause: the car needs to have fuel left to drive
        if (fuel > 0) {
            // the "then" clause: the car drives, consuming fuel
            fuel--;
        }
    }
}
```

У наведеному вище прикладі, якщо в машині закінчилося пальне, виклик методу `Car.drive` нічого не зробить.

## Інструкція _if-then-else_

Інструкція _if-then-else_ дає альтернативний шлях виконання на випадок, коли умова в конструкції `if` набуває значення `false`.
Цей альтернативний шлях виконання йде після конструкції `if` і визначається за допомогою конструкції `else`:

```java
class Car {
    void drive() {
        if (fuel > 0) {
            fuel--;
        } else {
            stop();
        }
    }
}
```

У наведеному вище прикладі, якщо в машині закінчилося пальне, виклик методу `Car.drive` викличе інший метод, щоб зупинити машину.

Інструкція _if-then-else_ також підтримує кілька умов за допомогою конструкції `else if`:

```java
class Car {
    void drive() {
        if (fuel > 5) {
            fuel--;
        } else if (fuel > 0) {
            turnOnFuelLight();
            fuel--;
        } else {
            stop();
        }
    }
}
```

У наведеному вище прикладі, якщо їхати, коли пального менше або дорівнює `5`, машина поїде, але загориться індикатор пального.
Коли пальне сягне `0`, машина зупиниться.
