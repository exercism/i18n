# Доповнення до інструкцій

## Інструкції для цього треку

### Формат вхідних даних

Вхідні дані буде подано у вигляді рядка тексту (англ. string).
Щоб ця вправа була зрозумілою для початківців, не доведеться мати справу з багатоцифровими числами.

Байти 64-191 лінійної памʼяті зарезервовано для вхідного рядка тексту.

### Формат вихідних даних

Вихідні дані мають складатися з пар «рядок і стовпець» як значень u8, безпосередньо зʼєднаних.

Наприклад, якщо є три сідлові точки

рядок: 2, стовпець: 1
рядок: 2, стовпець: 2
рядок: 2, стовпець: 3

то очікувані вихідні дані матимуть вигляд значень u8 `2, 1, 2, 2, 2, 3`
