# Про поняття

Swift - компільована мова з кількома парадигмами.
Вона має такі цілі:

- Мати засоби безпеки, які запобігають помилкам у продакшені

- Мати швидкодію, порівнянну з мовами на базі C

- Мати синтаксис, який приємно читати й писати

Swift розробили як заміну Objective-C, яка була основною мовою для створення застосунків для iOS і macOS.
Swift розробила компанія Apple Inc.
Перший випуск мови відбувся у 2014 році.
Тепер вона з відкритим кодом і доступна на всіх пристроях Apple, а також у Linux і Windows.

## З чого почати

### Змінні

Значення можна повʼязати з іменами, визначивши [змінну][constants-variables] і присвоївши їй значення.
Тоді це імʼя можна використовувати для посилання на це значення в усій програмі.
Змінні _змінювані_, тобто їхнє значення можна змінити будь-коли.

Змінні визначають за допомогою ключового слова `var`.

```swift
var variableName = 10
```

Swift - статично типізована мова з перевіркою типів, а це означає, що кожне значення має тип уже під час компіляції.
Можна або явно вказати тип змінної за допомогою [анотацій типів][type annotations], або дозволити компілятору [вивести тип][type-inferring].
```swift
var explicitVar: Int = 10 // Explicitly typed
var implicitVar = 10      // Implicitly typed
```

Щоб оновити значення змінної, використовують оператор `=`.

~~~~exercism/note
Тип змінної фіксується, щойно її визначено.

```swift
variableName = 13 // update to new value

// compiler error when assigning a different type
variableName = "Hello, world!" // Cannot assign value of type 'String' to type 'Int'
```
~~~~

Змінну можна оголосити без присвоєння значення, вказавши імʼя та тип, але використовувати її не можна, доки значення не присвоєно.

```swift
var someInt: Int

// This would trigger a compiler error
// print(someInt) // Variable 'someInt' used before being initialized

// Assign a value to the names
someInt = 169

print(someInt) // Prints '169'
```

### Константи

[Константи][constants-variables] схожі на змінні тим, що теж повʼязані з іменем і значенням, але значення константи не можна змінити після першого присвоєння, тому вона _незмінна_.
Константи визначають за допомогою ключового слова `let`.

```swift
let constantName = 10          // constant
let explicitConstant: Int = 10 // Explicitly typed constant
```

### Додавання, віднімання та множення

У Swift є [оператори][arithmetical-operators] для додавання, віднімання та множення.
Це відповідно `+`, `-` і `*`.

```swift
print(1 + 1) // Prints 2
print(2 - 1) // Prints 1
print(2 * 2) // Prints 4
```

### Функції

У Swift [функції][functions] - це фрагмент коду, який виконує певне завдання.
Функція має тип поверненого значення, завдяки чому її саму можна використовувати як значення й передавати як аргумент іншим функціям.
У Swift функції визначають за допомогою ключового слова `func`, після якого йде назва функції, аргументи, розділені комами, і тип поверненого значення.

Аргументи задаються міткою аргументу, назвою параметра, після якої стоїть двокрапка, а далі тип.
Тип поверненого значення задають за допомогою `->`, після якого вказують тип значення, яке повертається.

```swift
func functionName(argumentName parameterName: ArgumentType) -> ReturnType {
  // function body
}
```

Аргументи у Swift трохи особливі порівняно з іншими мовами: вони використовують [мітки аргументів][argument-labels].
Мітку аргументу вказують під час виклику функції.
Назву параметра використовують усередині тіла функції, щоб звертатися до значення аргументу.
Якщо вказати лише одне імʼя для аргументу, воно слугуватиме і міткою аргументу, і назвою параметра.
Якщо вказати мітку аргументу як `_`, під час виклику функції аргумент не матиме мітки, наприклад: `functionName(argumentValue)`

Щоб викликати функцію, потрібно вказати назву функції, а потім мітку аргументу та значення аргументу, ось так:

```swift
func functionName(argumentLabel parameterName: ArgumentType) -> ReturnType {
  // function body
}

// calling the function
functionName(argumentLabel: argumentValue)
```

Усі аргументи типово незмінні, і їх не можна змінити всередині функції.
Якщо функція має тип поверненого значення, потрібно обовʼязково повернути значення цього типу.
Це роблять за допомогою ключового слова `return`, після якого вказують значення, яке потрібно повернути.

```swift
func addTen(number value: Int) -> Int {
  return value + 10
}

// calling the function
addTen(number: 10) // Returns 20
```

Якщо функція не повертає значення, її тип поверненого значення - `Void`, те саме, що й `()`, але в таких випадках тип можна й опустити.

### Коментарі

У Swift є два типи [коментарів][comments].
Однорядковий коментар починається з `//`, а багаторядковий вставляють між `/*` та `*/`.
