# Instructions

Ваше завдання: розібрати рядок у форматі Smart Game Format (SGF) і повернути структуру даних у вигляді дерева, що представляє гру.

Рядок SGF представляє дерево вузлів. Усе дерево взято в дужки `()`.
Кожен вузол дерева позначено крапкою з комою `;`, після якої йде послідовність властивостей.
Властивість складається з ідентифікатора у верхньому регістрі (наприклад, `AB`), після якого йде одне або кілька значень у квадратних дужках `[]`.

Наприклад, рядок `(;FF[4]C[root])` представляє дерево з єдиним кореневим вузлом. Цей вузол має дві властивості:
- Властивість `FF` зі значенням `4`
- Властивість `C` зі значенням `root`

**Варіації (дерева та гілки)**
SGF підтримує варіації гри за допомогою вкладених дерев. Дерево може мати кілька дочірніх дерев, які також беруться в дужки.
Наприклад, `(;A[B](;C[D])(;E[F]))` представляє кореневий вузол із властивістю `A`, який має дві дочірні гілки:
1. Вузол із властивістю `C` і значенням `D`
2. Вузол із властивістю `E` і значенням `F`

**Форматування та екранування**
Значення в дужках можуть містити екрановані символи. Зворотна скісна риска `\`, за якою йде будь-який символ, означає цей самий символ буквально (наприклад, `\]` слід розбирати як буквальний `]`). Крім того, якщо перед символом нового рядка стоїть зворотна скісна риска, він працює як продовження рядка і його слід прибрати зі значення. Усі інші символи нового рядка всередині значення потрібно зберігати.

**Обробка помилок**
Для некоректних рядків SGF потрібно генерувати помилку. Ось приклади некоректних рядків SGF:
- Дерево, яке не починається з дужок `()`.
- Вузол, який не починається з крапки з комою `;`.
- Ідентифікатори властивостей, які складаються не лише з великих літер.
- Пропущені квадратні дужки або непарні круглі дужки.

### Структура даних

Функція розбору повинна повертати представлення дерева. Поширений підхід - представляти кожне дерево як обʼєкт із двома полями:
- `properties`: обʼєкт (або Map), у якому ключами є ідентифікатори властивостей, тобто рядки тексту (англ. string), а значеннями - масиви таких рядків, адже властивість може мати кілька значень.
- `children`: масив, що містить дочірні дерева.


Приклад:

Вхідні дані: `(;FF[4]C[root])`
Вихідні дані: `{
  properties: {
    FF: ['4'],
    C: ['root']
  },
  children: []
}`

Вхідні дані: `(;A[B](;C[D])(;E[F]))`
Вихідні дані: `{
  properties: {
    A: ['B']
  },
  children: [
    {
      properties: {
        C: ['D']
      },
      children: []
    },
    {
      properties: {
        E: ['F']
      },
      children: []
    }
  ]
}`
