# Вступ

[Zen of Python][zen-of-python] стверджує, що має бути «один _очевидний_ спосіб зробити щось у Python».
Для Python 3.6+ [**літеральна інтерполяція рядків**][string-interpolation] ([**`f-string`s**][f-string]) часто є очевидним і бажаним способом форматування рядків тексту (англ. _string_):

```python
>>> adjective = "easy"
>>> f"This is an {adjective} way to format strings!"
'This is an easy way to format strings!'
```

Однак, з огляду на довгу історію Python і різні сценарії використання, не дивно, що в Python є **три** інші поширені способи форматування рядків:

1. [`str.format()`][str-format] універсальний, дуже потужний і сумісний як із [`gnu gettext`][gettext], так і з більшістю версій Python.
2. Якщо потрібні простота, безпека та/або масштабна інтернаціоналізація, [`string.Template()`][string-template] можна використати, щоб зменшити ризики, коли треба обробляти вхідні дані, і для обгортання рядків перекладу.
3. Оператор `%` зазвичай вважають застарілим для нового коду, хоча в сучасному Python він досі працює.
  Його варто переважно використовувати для сумісності зі старішими кодовими базами.
  Форматування через `%` може спричиняти проблеми з відображенням символів, що не входять до ASCII, та символів Unicode, а також має більше помилок і менше можливостей, ніж інші способи.
  Якщо плануємо його використовувати, варто перевірити подробиці підтримки у своєму дистрибутиві Python.
