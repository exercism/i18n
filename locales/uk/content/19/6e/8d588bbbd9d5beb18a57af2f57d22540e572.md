# Додаток до інструкцій

## Регістри

| Регістр | Використання | Тип          | Опис                                               |
| ------- | ------------ | ------------ | -------------------------------------------------- |
| `$a0`   | вхідні дані  | адреса       | перший рядок тексту (англ. string), завершений нульовим символом  |
| `$a1`   | вхідні дані  | адреса       | другий рядок тексту, завершений нульовим символом  |
| `$v0`   | вихідні дані | ціле число   | відстань Геммінга                                  |
| `$t0-9` | тимчасовий   | будь-який    | для тимчасового зберігання                         |
