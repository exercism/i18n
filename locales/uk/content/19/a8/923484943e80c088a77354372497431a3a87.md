# Вступ

## Бітові масиви

Робота з двійковими даними може бути непростою, тому Gleam надає тип `BitArray` і відповідний синтаксис, щоб створювати двійкові дані та виконувати зіставлення з шаблоном.

Літерали бітових масивів задаються за допомогою синтаксису `<<>>`. Літерал бітового масиву складається з сегментів. Кожен сегмент має значення та анотацію, розділені `:`. Анотація визначає, скільки бітів буде використано для кодування значення, і її можна взагалі пропустити, тоді типовим буде 8-бітове ціле число.

```gleam
// This defines a bit array with three segments of a single bit each
<<0:1, 1:1, 0:1>>

// This defines a bit array with three segments of 8 bits each
<<0, 1, 0>>
```

Запис `:1` - це скорочений варіант запису `:size(1)`. Довший синтаксис потрібен, якщо розмір бітів задає змінна.

```gleam
let segment_size = 1
<<0:size(segment_size), 1:size(segment_size), 0:size(segment_size)>>
```

### Двійковий запис

Записуючи двійкові цілочислові літерали, ми можемо писати їх одразу в двійковій системі числення, додавши перед літералом префікс `0b`. Зауважмо, що під час виведення в тестах чи в програмі вони показуватимуться як десяткові числа.

```gleam
<<0b1011:4>> == <<11:4>>
// -> True
```

### Усікання

Якщо значення сегмента перевищує місткість типу цього сегмента, його буде усічено зліва.

```gleam
<<0b1011:3>> == <<0b0011:3>>
// -> True
```

### Додавання на початок і в кінець

Ми можемо додавати як на початок, так і в кінець наявного бітового масиву, використовуючи синтаксис бітових масивів. Для наявного бітового масиву потрібно використати анотацію `:bits`.

```gleam
let value = <<0b110:3, 0b001:3>>
let new_value = <<0b011:3, value:bits, 0b000:3>>
// -> <<120, 8:size(4)>>
```

### Конкатенація

Ми можемо зʼєднати бітові масиви, збережені у змінних, використовуючи синтаксис бітових масивів. Анотацію `:bits` потрібно використовувати, коли зʼєднуємо два бітові масиви різного розміру.

```gleam
let first = <<0b110:3>>
let second = <<0b001:3>>
let concatenated = <<first:bits, second:bits>>
// -> <<49:size(6)>>
```

### Зіставлення з шаблоном

Зіставлення з шаблоном також можна застосувати, щоб дістати значення з бітового масиву. Потрібно знати кількість бітів для кожного сегмента, який ми хочемо захопити, за одним винятком: анотацію `:bits` можна використати для зіставлення з шаблоном бітового масиву невідомого розміру, але лише для останнього сегмента.

```gleam
let assert <<value:4, rest:bits>> = <<0b01101001:8>>
value == 0b0110
// -> True
```

### Огляд бітових масивів

~~~~exercism/note
Бітові масиви можуть виводитися в іншому форматі, ніж той, у якому їх було створено. Це часто спантеличує тих, хто вивчає бітові масиви.
~~~~

Типово бітові масиви показуються сегментами по 8 бітів (байт), навіть якщо ми створили їх із сегментів іншого розміру.

```gleam
<<2011:11>>
// -> <<251, 3:size(3)>>
```

Якщо ми створимо бітовий масив, що представляє придатний для друку рядок тексту (англ. string) у кодуванні UTF-8, його може бути показано як рядок тексту функціями на кшталт `io.debug`. Це повʼязано з деталлю реалізації того, як Gleam представляє рядки тексту всередині.

```gleam
<<>>
// -> ""

<<65, 66, 67>>
// -> "ABC"
```
