# Вступ

Модифікатор `const` можна (і зазвичай слід) застосовувати до будь-якого поля, значення якого відоме під час компіляції й не зміниться протягом часу життя програми.

```csharp
private const int num = 1729;
public const string title = "Grand" + " Master";
```

Модифікатор `readonly` можна (і зазвичай слід) застосовувати до будь-якого поля, яке не можна зробити `const`, якщо його значення не зміниться протягом часу життя програми і встановлюється або вбудованим ініціалізатором, або під час створення екземпляра (конструктором або методом, який викликається конструктором).

```csharp
private readonly int num;
private readonly System.Random rand = new System.Random();

public MyClass(int num)
{
    this.num = num;
}
```
