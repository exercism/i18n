# Вступ

Рекурсивні функції - це функції, які викликають самі себе.

Рекурсивна функція повинна мати принаймні один _базовий випадок_ і принаймні один _рекурсивний випадок_.

_Базовий випадок_ повертає значення, не викликаючи функцію знову. _Рекурсивний випадок_ викликає функцію знову, змінюючи вхідні дані так, щоб вони зрештою збіглися з базовим випадком.

Дуже часто кожен випадок записують в окремій клаузі функції.

```elixir
# base case
def count([]), do: 0

# recursive case
def count([_head | tail]), do: 1 + count(tail)
```
