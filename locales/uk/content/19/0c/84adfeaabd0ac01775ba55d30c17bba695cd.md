# Доповнення до інструкцій

## Регістри

| Регістр | Використання | Тип         | Опис                                                          |
| -------- | --------- | ------- | ---------------------------------------------------------- |
| `$a0`    | вхідні дані     | адреса | елементи першого масиву                                    |
| `$a1`    | вхідні дані     | ціле число | розмір першого масиву в словах                             |
| `$a2`    | вхідні дані     | адреса | елементи другого масиву                                    |
| `$a3`    | вхідні дані     | ціле число | розмір другого масиву в словах                             |
| `$v0`    | вихідні дані    | ціле число | `0` = equal, `1` = unequal, `2` = sublist, `3` = superlist |
| `$t0-9`  | тимчасовий | будь-який     | використовується для тимчасового зберігання                |
