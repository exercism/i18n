# Інструкції

У цій вправі ми працюватимемо з рядками журналу.

Кожен рядок журналу - це рядок тексту (англ. string) такого формату: `"[<LEVEL>]: <MESSAGE>"`.

Існує три різні рівні журналу:

- `INFO`
- `WARNING`
- `ERROR`

На нас чекають три завдання, і кожне з них отримує рядок журналу, з яким потрібно щось зробити. Існує безліч способів розвʼязати ці завдання. Виберімо улюблені методи з наведених вище прикладів і подивімося, що з цього вийде.

## 1. Отримати повідомлення з рядка журналу

Реалізуйте метод `LogLineParser#message`, щоб він повертав повідомлення з рядка журналу:

```ruby
LogLineParser.new('[ERROR]: Invalid operation').message
# => "Invalid operation"
```

Будь-які пробільні символи на початку й у кінці потрібно прибрати:

```ruby
LogLineParser.new("[WARNING]:  Disk almost full\r\n").message
# => "Disk almost full"
```

## 2. Отримати рівень журналу з рядка журналу

Реалізуйте метод `LogLineParser#log_level`, щоб він повертав рівень журналу з рядка журналу. Рівень потрібно повертати в нижньому регістрі:

```ruby
LogLineParser.new('[ERROR]: Invalid operation').log_level
# => "error"
```

## 3. Переформатувати рядок журналу

Реалізуйте метод `LogLineParser#reformat`, який переформатовує рядок журналу: спочатку йде повідомлення, а потім у дужках рівень журналу:

```ruby
LogLineParser.new('[INFO]: Operation completed').reformat
# => "Operation completed (info)"
```
