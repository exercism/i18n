# Вступ

Haxe має два типи чисел - цілі числа та числа з плаваючою комою:

- `Int`: представляє ціле число.
- `Float`: представляє 64-бітне число з плаваючою комою подвійної точності.

```haxe
var integer:Int = 10;
var floating:Float = 5.4;
```

Хоча будь-яке `Int` можна використати там, де потрібен `Float` (тобто `Int` **можна присвоїти** `Float` або **уніфікувати з** `Float`), проте навпаки це не так: присвоєння `Float` змінній типу `Int` може спричинити втрату точності, тому не дозволяється неявно.
