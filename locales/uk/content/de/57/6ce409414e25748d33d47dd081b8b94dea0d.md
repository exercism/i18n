# Вступ

Узагальнення дають змогу писати код, який працює з багатьма типами без дублювання. Визначати узагальнені типи можна за допомогою кутових дужок `<T>`, де `T` є заповнювачем для будь-якого типу.

```rust
fn largest_list<T>(l1: Array<T>, l2: Array<T>) -> Array<T> {
    if l1.len() > l2.len() {
        l1
    } else {
        l2
    }
}
```

Cairo вимагає обмежень трейтів, щоб указати, які операції повинен підтримувати узагальнений тип.
Додати обмеження можна за допомогою синтаксису `+`:

```rust
fn process_data<T, +Drop<T>, +Copy<T>>(value: T) -> T {
    // Function body
}
```

Структури також можуть бути узагальненими:

```rust
#[derive(Drop)]
struct Container<T> {
    value: T,
}
```

Трейти теж можуть бути узагальненими, що дає їм змогу працювати з різними типами:

```rust
trait Processor<T> {
    fn process(self: @T) -> ByteArray;
}

impl MyProcessor<T, +Drop<T>> of Processor<T> {
    fn process(self: @T) -> ByteArray {
        "processed"
    }
}
```

Функції можуть приймати узагальнені параметри з обмеженнями трейтів, завдяки чому вони працюють з будь-яким типом, який реалізує потрібний трейт:

```rust
fn use_processor<T, +Processor<T>, +Drop<T>>(item: T) -> ByteArray {
    item.process()
}
```
