# Вступ

Функції для роботи з введенням і виведенням надає модуль `IO`.

## Виведення

Щоб записати рядок тексту (англ. string) у стандартне виведення, використаймо `IO.puts`. `IO.puts` завжди додає в кінці новий рядок. Якщо така поведінка нам не потрібна, використаймо натомість `IO.write`. Обидві функції повертають атом `:ok`, якщо виклик успішний.

```elixir
IO.puts("Hi!")
# > Hi!
# => :ok
```

`IO.puts` добре підходить для запису рядків тексту, але майже ні для чого іншого. Якщо нам потрібен інструмент для налагодження, який дозволить записати в стандартне виведення будь-яке значення, використаймо натомість `IO.inspect`. `IO.inspect` повертає передане їй значення без змін, тож її можна вставити в будь-якому місці коду. Вона також приймає багато опцій, наприклад `:label`, які дозволять відрізнити її від інших викликів `IO.inspect`.

## Введення

Щоб прочитати рядок зі стандартного введення, використаймо `IO.gets`. `IO.gets` приймає один аргумент: рядок тексту, який вона надрукує як запрошення до введення. `IO.gets` не додає нового рядка після запрошення, тож додаймо його самі, якщо це потрібно.

```elixir
IO.gets("What's your name?\n")
# > What's your name?
# < Mary
# => "Mary\n"
```
