# Вступ

Друк у Cairo дає змогу виводити повідомлення або інформацію для налагодження під час виконання програми.

## Основи

Cairo надає два макроси для друку:

- `println!`: виводить повідомлення і додає символ нового рядка.
- `print!`: виводить повідомлення без символу нового рядка.

```rust
println!("Hello, Cairo!"); 
println!("x = {}, y = {}", 10, 20); 
```

Замісники `{}` замінюються на передані значення.

## Форматування рядків тексту (англ. string)

Використаймо `format!`, щоб створити `ByteArray`, не друкуючи його одразу:

```rust
let result = format!("{}-{}-{}", "tic", "tac", "toe");
println!("{}", result); // Output: tic-tac-toe
```

## Власні типи даних

Для власних типів, щоб мати змогу їх надрукувати, потрібно реалізувати `Display` або вивести `Debug`:

```rust
#[derive(Debug)]
struct Point { x: u8, y: u8 }

let p = Point { x: 3, y: 4 };
println!("{:?}", p); // Debug output: Point { x: 3, y: 4 }
```

## Друк у шістнадцятковому форматі

Щоб надрукувати цілі числа у шістнадцятковому форматі, використаймо `{:x}`:

```rust
println!("{:x}", 255); // Output: ff
```
