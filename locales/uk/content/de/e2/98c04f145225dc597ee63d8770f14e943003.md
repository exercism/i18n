# Докладніше

`bit` - найдрібніше значення в обчислювальній техніці.
Слово `bit` походить від англійського «binary digit», тобто «двійкова цифра».
Це одиниця зберігання даних у середовищі виконання, достатньо велика, щоб умістити обʼєкт, який може набувати одного з двох значень.
Отже, він має двійкове значення `1` або `0`.
Усі інші типи даних складаються з кількох `bits`.
Наприклад, `byte` зазвичай складається з восьми `bits`.

## Як записувати значення бітів

`Bits` утворюють двійкову систему числення.
Кожне кратне `2` опиняється там, де ми звикли бачити розряди десятків, сотень, тисяч тощо, тільки замість «десятків» маємо «двійки», замість «сотень» - «четвірки», замість «тисяч» - «вісімки» і так далі.
Отже, десяткове значення `2` - це двійкове `10`, `4` - `100`, а `8` - `1000`.
Як і в десяткових числах, значення зростають, коли рухатися справа наліво.
Десяткове значення `5` можна уявити як `101` у двійковій системі: `1` у розряді одиниць і `1` у розряді четвірок.
Однак двійкові літерали не входять до стандарту мови C.
Єдині двійкові значення, які підтримує стандарт мови C, - це окремі `1` або `0`.
Деякі нестандартні розширення компіляторів, як-от компілятор GNU, _усе ж_ підтримують двійкові літерали, якщо поставити перед літералом `0b`.

```c
#include <stdio.h>

int main() {
    int binary_five = 0b101;
    printf("%d", binary_five);
    return 0;
}
```

Важливо памʼятати, що такий запис підтримують не всі компілятори, і він може стати на заваді переносності коду між різними компіляторами.

Поширений спосіб записувати двійкові значення - використовувати шістнадцяткову нотацію, тобто систему числення з основою 16.
У мові C шістнадцятковий літерал починається з `0x` або `0X`.
Оскільки десяткове значення `16` у розряді десятків записується як `1`, десяткове значення `10` у шістнадцятковій системі записується як `0xA`, `11` - як `0xB`, `12` - як `0xC`, `13` - як `0xD`, `14` - як `0xE`, а `15` - як `0xF`.
Наприклад, десяткове значення `42` записується як `0x2A`: `2` помножити на `16` (= `32`) плюс `10` (= `42`).

У двійковій системі `42` можна уявити як `00101010`: `32` плюс `8` плюс `2`.
Кажуть, що другий, четвертий і шостий біти справа «встановлені», тобто дорівнюють `1`, а не `0`.
Другий біт - це `2`, четвертий - `8`, а шостий - `32`.
Встановлення цих трьох бітів дає значення `42`.

## Бітові маски

Бітовою маскою може бути будь-яке значення, яке використовують для встановлення окремих бітів.
Наприклад, в англійському алфавіті двадцять шість літер.
Значення завдовжки щонайменше двадцять шість бітів, як-от беззнакове 32-бітове ціле число, можна використати як бітову маску, щоб задати умову `true` або `false` для кожної літери англійського алфавіту.
Будь-яке значення, у якому достатньо бітів для потрібного набору умов `true` або `false`, може правити за бітову маску.
Встановлюють і читають окремі біти за допомогою побітових операторів.

## Побітові оператори

Уявімо, що нам потрібно відстежувати, які літери трапляються в `string`.
У нашому прикладі використаймо лише двадцять шість літер англійського алфавіту.
Нашою бітовою маскою буде беззнакове 32-бітове ціле число.
`0` означатиме, що літера не трапляється.
`1` означатиме, що літера трапляється один або більше разів.
Спочатку бітове представлення нашої бітової маски складається з 32 `0s` підряд: `00000000000000000000000000000000`.
Найправіша позиція відповідатиме `A`.
Друга позиція зліва відповідатиме `B`, і так далі.
Припустімо, що ми обробляємо всі літери рядка тексту (англ. string) у циклі, тож нам потрібен один рядок коду, який спрацює для встановлення будь-якої літери.

### Побітовий оператор зсуву вліво: як розмістити біт

`<<` - це побітовий оператор зсуву вліво.

Якщо наша літера - `A`, зсувати вліво не потрібно; якщо літера - `B`, потрібно зсунути на одну позицію вліво; якщо `C` - на дві позиції, і так далі.
Хоча ми сприймаємо `chars` як літери на кшталт `A` чи `B`, у памʼяті `char` реалізовано як цілочисельний тип, тож із `char` можна робити прості обчислення.
Маючи змінну з назвою `letter`, яка представляє оброблюваний `char`, ми можемо зсунути `1` вліво на різницю між `letter` і символом `'A'` - і так отримати потрібну кількість позицій: `1 << letter - 'A'`.
`A` мінус `A` дорівнює `0`, тож якщо `letter` - це `A`, зсув буде на `0` позицій.
`B` мінус `A` дорівнює `1`, тож якщо `letter` - це `B`, зсув буде на одну позицію, і так далі.

### Побітовий оператор включального АБО: як встановити біт

Коли ми знаємо, _де_ саме хочемо встановити біт, ми можемо зробити це за допомогою побітового оператора включального АБО, тобто `|`.
Результат оператора `|` дорівнюватиме `1` у кожній позиції, де встановлений біт є або в лівому, або в правому операнді.
Отже, результат `0010 | 0001` - `0011`.
(Важливо памʼятати, що це значення `11` у двійковій системі, але `3` у десятковій.)
Щоб присвоїти результат, оператор `|` можна поєднати з оператором присвоєння і встановлювати біти ось так: `|=`.
Щоб не ускладнювати, у наступному прикладі немає циклу, але він показує, як ми могли б обробити літери `ABA` в бітовій масці.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    // it's important to initialize the mask to 0 so we don't get garbage values
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    mask |= 1 << letter_A_again - 'A';
    // prints 3
    printf("%d", mask);
}
```

Для `A` ми встановлюємо найправішу частину маски в `0001`, а потім для `B` маска стає `0011`.
Повторне встановлення `A` нічого не змінює в наявній масці.
Можна було б уникнути повторного встановлення біта, перевіривши, чи `A` вже встановлено.

### Побітовий оператор І: як прочитати біт

`&` - це побітовий оператор І.
Результат оператора `&` дорівнюватиме `1` у кожній позиції, де встановлений біт є і в лівому, і в правому операнді.
Отже, результат `0011 & 0001` - `0001`.
Побачити це в дії можна в наступному прикладі.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    // prints A already set
    if (mask & 1 << letter_A_again - 'A')
        printf("A already set\n");
    else
        mask |= 1 << letter_A_again - 'A';
    printf("%d", mask);
}
```

### Побітовий оператор виключного АБО: як перемкнути біт

`^` - це побітовий оператор виключного АБО.
Наявність оператора _включального_ АБО означає, що існує й оператор _виключного_ АБО з іншою поведінкою.
Результат оператора `^` дорівнюватиме `1` у кожній позиції, де встановлений біт має _лише один_ з операндів, лівий або правий.
Отже, результат `0001 ^ 0011` - `0010`.
Найправіший біт не буде встановлено, бо _обидва_ операнди мають `1` у найправішій позиції.
Операцію виключного АБО іноді позначають як XOR.
Якщо результат операції XOR ще раз піддати операції XOR, повернеться початкове значення.
Це можна використати для дуже простого шифрування, де той самий ключ використовують і для шифрування, і для розшифрування даних.
Наприклад

```c
#include <stdio.h>

int main() {
    char a = 'a';
    char b = 'b';
    char c = 'c';
    // we will use "a" for the "key"
    char first = a ^ 'a';
    char second = b ^ 'a';
    char third = c ^ 'a';
    // prints three "dots" for unprintable characters
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 0 3 2
    printf("%d %d %d\n", first, second, third);
    first = first ^ 'a';
    second = second ^ 'a';
    third = third ^ 'a';
    // prints a b c
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 97 98 99
    printf("%d %d %d\n", first, second, third);
}
```

### Побітовий оператор зсуву вправо: як поділити значення навпіл

`>>` - це побітовий оператор зсуву вправо.
Зазвичай кожен зсув бітів значення вправо на одну позицію ділить це значення на два.
Наприклад

```c
#include <stdio.h>

int main() {
    int number = 16;
    number >>= 2;
    // prints 4, or 16 / 2 = 8 / 2 = 4
    printf("%d\n", number);
}
```

Якщо значення правого операнда відʼємне або більше чи дорівнює ширині розширеного лівого операнда, поведінка невизначена.
Це стосується й оператора зсуву вліво.
Коли замість беззнакового цілого числа використовують знакове, свою роль може відіграти і знаковість.
Наступний приклад показує, як поводиться система, коли знакове ціле число зсунути занадто далеко вліво або вправо.

```c
#include <stdio.h>

int main() {
    int number = 16;
    number <<= 250;
    // prints 1073741824
    printf("%d\n", number);
    number <<= 1;
    // prints -2147483648
    printf("%d\n", number);
    number <<= 1;
    // prints 0
    printf("%d\n", number);
    // total shifts are now 256, done incrementally
    number <<= 4;
    // prints 0
    printf("%d\n", number);
    number = 16;
    // prints 16 when 256 total shifts done at once
    printf("%d\n", number << 256);
    // prints 0 when bits shifted right far enough
    printf("%d\n", number >> 5);    
    // still prints 0
    printf("%d\n", number >> 255);
    // prints 16 when shifted right far enough to "wrap around"
    printf("%d\n", number >> 256);
}
```

Оскільки поведінка невизначена, інша система може дати інші результати.
Зсуваючи біти, важливо розуміти межі типу даних, з яким ми працюємо.

## Бітові поля

Ми вже бачили, як біти, упаковані в простий тип даних, можна адресувати за їхньою позицією.
Біти, упаковані в `struct`, можна адресувати за назвою.
Такий тип даних називають `bit field`.
`bit fields` можуть знадобитися, коли потрібен набір прапорців ON/OFF, а використання памʼяті хочеться звести до мінімуму.

```c
#include <stdio.h>

int main() {

    struct lights {
        unsigned int number_of_lights;
        unsigned int red   : 1;
        unsigned int green : 1;
        unsigned int blue  : 1;
    };
    struct lights lightboard = {3, 0, 0, 0};
     
    //  prints 000
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    lightboard.green = 1;

    //  prints 010
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    // prints 3
    printf("%d\n", lightboard.number_of_lights);
}
```

Синтаксис `unsigned int variable_name : 1;` створює поле завширшки `1` біт усередині `unsigned int`, розміщеного в структурі.
Замість `unsigned int` можна взяти `signed int`, а починаючи з C99 - тип `bool`.
Структура з бітовими полями може містити й поля інших типів даних, як-от `number_of_lights` у прикладі вище.
