# Інструкції

У цій вправі ми будемо писати код, який допоможе приготувати чудову лазанью з улюбленої кулінарної книги.

На нас чекають чотири завдання, усі повʼязані з часом, який витрачається на приготування лазаньї.

## 1. Визначте очікуваний час у духовці в хвилинах

Визначте метод `Lasagna.expectedMinutesInOven()`, який не приймає жодних параметрів і повертає, скільки хвилин лазанья має пробути в духовці. Згідно з кулінарною книгою, очікуваний час у духовці становить 40 хвилин:

```scala
val lasagna = new Lasagna()
lasagna.expectedMinutesInOven()
// => 40
```

## 2. Обчисліть решту часу в духовці у хвилинах

Визначте метод `Lasagna.remainingMinutesInOven()`, який приймає як параметр фактичну кількість хвилин, які лазанья вже провела в духовці, і повертає, скільки хвилин їй ще залишилося пробути в духовці, виходячи з очікуваного часу в духовці з попереднього завдання.

```scala
val lasagna = new Lasagna()
lasagna.remainingMinutesInOven(30)
// => 10
```

## 3. Обчисліть час підготовки в хвилинах

Визначте метод `Lasagna.preparationTimeInMinutes()`, який приймає як параметр кількість шарів, які ми додали до лазаньї, і повертає, скільки хвилин ми витратили на підготовку лазаньї, за умови, що на підготовку кожного шару йде 2 хвилини.

```scala
val lasagna = new Lasagna()
lasagna.preparationTimeInMinutes(2)
// => 4
```

## 4. Обчисліть витрачений час у хвилинах

Визначте метод `Lasagna.elapsedTimeInMinutes()`, який приймає два параметри: перший параметр - це кількість шарів, які ми додали до лазаньї, а другий - кількість хвилин, які лазанья провела в духовці. Функція має повертати, скільки хвилин ми витратили на приготування лазаньї, тобто суму часу підготовки у хвилинах і часу в хвилинах, який лазанья на цей момент провела в духовці.

```scala
var lasagna = new Lasagna()
lasagna.elapsedTimeInMinutes(3, 20)
// => 26
```
