# Вступ

## Структури та класи

Структури та класи - це два з основних будівельних блоків програмування мовою Swift. Обидва вони дають змогу обʼєднувати повʼязані дані та функції в самодостатні одиниці функціональності. І коли ми визначаємо структуру чи клас, ми визначаємо новий тип, який можна використовувати у Swift, так само як ми користувалися типами, з якими вже працювали, наприклад `Int` і `String`.

У структур і класів у Swift багато спільного. Серед іншого, і ті, й інші вміють зберігати значення у _властивостях_ і надавати функціональність через _методи_.

Кожен із них надає ще й додаткову функціональність, яка виходить за межі цієї вправи.

### Визначення структур і класів

І структури, і класи визначають приблизно однаково. Спершу йде відповідне ключове слово, потім назва типу, який ми визначаємо, а далі тіло структури чи класу, вміщене у фігурні дужки.

Тіло може складатися зі збережених властивостей, які визначають і які поводяться точно так само, як звичайні константи чи змінні.

```swift
struct CharacterStats {
  var health = 0.0
  var speed = 0
  var strength = 0
}

class GameCharacter {
  var stats = CharacterStats()
  var characterClass: String?
  var name: String?
  var active = false
  let id = makeRandomID()
}
```

### Екземпляри

Як зазначено вище, визначення структури чи класу - це лише визначення нового _типу_. Це лише креслення того, який вигляд матимуть значення цього типу, але воно не створює жодних значень цього типу, з якими можна було б працювати.

Щоб створити _екземпляр_ цього типу, треба написати назву типу, а потім пару дужок.

```swift
let someStats = CharacterStats()
let someCharacter = GameCharacter()
```

Так ми створимо значення цих типів, де властивості заповнені типовими значеннями, заданими у визначенні. Зауважмо, що в опціональних випадках, як-от властивість `name` у GameCharacter, властивість типово матиме значення nil, якщо їй не надати значення, точнісінько як зі звичайними опціональними типами, де значення не задають одразу.

Для структур Swift автоматично надає те, що називають _почленним ініціалізатором_: значення для властивостей структури можна передати в дужках, і вони перекриють типові значення з визначення.

```swift
let differentStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

### Доступ до властивостей

До властивостей структур і класів можна звертатися через _точкову нотацію_, де після назви значення йде крапка (`.`) і назва властивості. Якщо у властивості структури чи класу є власні властивості, цією самою точковою нотацією можна дістатися і до вкладених властивостей.

Цю нотацію можна використовувати і щоб отримати значення властивості, і, де це дозволено, щоб його змінити.

```swift
someStats.health
// => 0
someCharacter.name
// => nil

someStats.health = 87.3
someStats.health
// => 87.3
someCharacter.name = "Luther"
someCharacter.name
// => "Luther"

someCharacter.id  = "new id"
// Error: Cannot assign to property: 'id' is a 'let' constant
```

### Методи

Окрім властивостей, які зберігають дані в структурах і класах, можна також визначати _методи_, які зберігають функції в структурі чи класі.

Методи визначають так само, як звичайні функції, тільки всередині тіла структури чи класу. Зауважмо: якщо функція змінює значення властивості в структурі, перед нею обовʼязково має стояти ключове слово `mutating`. Крім того, якщо властивість може змінювати метод, цю властивість треба визначати через `var`, а не `let`, так само як звичайні змінні.

```swift
struct CharacterStats {
  var health = 0.0
  var speed = 0
  var strength = 0

  mutating func takeHit(_ damage: Double) {
    health = max(0.0, health - damage)
  }
  func canLift(_ weight: Int) -> Bool {
    weight < strength * 100
  }
}

class GameCharacter {
  var stats = CharacterStats()
  var characterClass: String?
  var name: String?
  var active = false
  let id: String = makeRandomID()

  func takesDamage(_ damage: Double) {
    stats.takeHit(damage)
    if stats.health <= 0 {
      active = false
    }
  }
  func sayName() -> String {
    return "My name is \(name ?? "no one"), my class is \(characterClass ?? "undetermined")"
  }
  func lift(_ weight: Int) -> String {
    if stats.canLift(weight) {
      return "No problem!"
    } else {
      return "Ooof! No way."
    }
  }
}
```

Ці методи можна викликати точковою нотацією, так само як властивості.

```swift
var myChar = GameCharacter()
myChar.stats = CharacterStats(health: 72.8, speed: 19, strength: 6)
myChar.active = true

myChar.lift(750)
// => "Ooof! No way."
myChar.takesDamage(80)
myChar.active
// => false
```

### Self

Кожен екземпляр структури чи класу має неявне значення з назвою `self`, яке вказує на сам цей екземпляр. У `self` є багато застосувань, але найчастіше його використовують, щоб розрізнити назви властивостей і методів структури чи класу, коли може виникнути плутанина.

```swift
struct MySelf {
  var x = 0

  mutating func move(x: Int) {
    // here if we just say x = x it is unclear if we mean
    // the property x or the method parameter x, so we use
    // self for clarity
    self.x = x
  }
}
```
