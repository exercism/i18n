# Доповнення до інструкцій

## Регістри

| Регістр | Використання       | Тип          | Опис                                              |
| ------- | ------------------ | ------------ | ------------------------------------------------- |
| `$a0`   | вхідні дані        | ціле число   | кількість вхідних монет                           |
| `$a1`   | вхідні дані        | ціле число   | цільова сума                                      |
| `$a2`   | вхідні/вихідні дані | адреса       | перезаписуваний масив слів із монетами            |
| `$v0`   | вихідні дані       | ціле число   | кількість вихідних монет, -1, якщо вхідні дані некоректні |
| `$t0-9` | тимчасовий         | будь-який    | використовується для тимчасового зберігання       |
