# Вступ

Gleam представляє значення правда та неправда за допомогою типу `Bool`. Є лише два значення: `True` та `False`. Ці значення можна привʼязати до змінної:

```gleam
let true_variable = True
let false_variable = False
```

Оператори `&&`, `||` та `!` можна використовувати для маніпулювання булевими значеннями (англ. Boolean):

```gleam
True && True  // -> True
True && False // -> False

False || True  // -> True
False || False // -> False

!False // -> True
!True  // -> False
```

Оператори `&&` та `||` використовують скорочене обчислення, що означає, що вираз праворуч від оператора обчислюється лише за потреби.

Кожен з операторів має різний пріоритет, причому `!` обчислюється перед `&&` та `||`. Фігурні дужки можна використовувати, щоб обчислити одну частину виразу перед іншими:

```gleam
!True && False   // -> False
!{True && False} // -> True
```
