# Додаток до інструкцій

## Регістри

| Регістр | Використання | Тип | Опис |
| -------- | ------------ | ------- | -------------------------------------------- |
| `$a0`    | вхід        | адреса | рядок імені із завершальним нульовим символом, або нульовий вказівник |
| `$a1`    | вхід/вихід | адреса | рядок результату із завершальним нульовим символом |
| `$t0-9`  | тимчасовий    | будь-який | для тимчасового зберігання |
