# Про

Здебільшого ітерація у Factor виражається комбінаторами (`each`, `map`, `reduce`), але явна рекурсія все ще має своє місце: коли рекурсія не має форми списку, коли базовий випадок нетривіальний або коли ми самі реалізуємо комбінатор.

```factor
: total ( seq -- sum )
    [ 0 ] [ unclip swap total + ] if-empty ;

: gcd ( a b -- g )
    dup zero? [ drop ] [ tuck mod gcd ] if ;
```

Ось кілька речей, які варто знати:

- Звичайні визначення з `:` можуть викликати самі себе без спеціального синтаксису. Компілятор виводить стекові ефекти під час рекурсивного виклику.
- `loop ( quot -- )` дає змогу перебирати блок коду, що повертає булеве значення (англ. Boolean), і продовжувати, поки воно правдиве.
- Хвостові виклики компілюються в переходи, тому глибоко рекурсивні слова не переповнюють стек.

Пара `unclip` / `if-empty` є стандартною формою рекурсії для послідовностей, а `cond` - стандартною формою багатоваріантного розгалуження.
