# Докладніше

Пакет `java.time`, представлений у Java 8, містить кілька класів для роботи з датами й часом.

## `LocalDate`

Клас [`java.time.LocalDate`][localdate-docs] представляє дату без часового поясу в [календарній системі ISO-8601][iso-8601], наприклад `2007-12-03`:

```java
LocalDate date = LocalDate.of(2007, 12, 3);
```

Дати можна порівнювати з іншими датами:

```java
LocalDate date1 = LocalDate.of(2007, 12, 3);
LocalDate date2 = LocalDate.of(2007, 12, 4);

date1.isBefore(date2);
// => true

date1.isAfter(date2);
// => false
```

Примірник `LocalDate` має методи-гетери, які повертають окремі частини дати:

```java
LocalDate date = LocalDate.of(2007, 12, 3);

date.getYear();
// => 2007

date.getMonthValue();
// => 12

date.getDayOfMonth();
// => 3
```

Примірник `LocalDate` має методи, щоб додати до нього одиниці часу.

```exercism/note
Ці методи повертають _новий_ примірник `LocalDate` і не змінюють наявний примірник, оскільки клас `LocalDate` незмінний.
```

```java
LocalDate date = LocalDate.of(2007, 12, 3);

date.plusDays(3);
// => 2007-12-06

date.plusMonths(1);
// => 2008-01-03

date.plusYears(1);
// => 2008-12-03
```

## `LocalDateTime`

Клас [`java.time.LocalDateTime`][localdatetime-docs] представляє дату й час без часового поясу в [календарній системі ISO-8601][iso-8601], наприклад `2007-12-03T10:15:30`:

```java
LocalDateTime datetime = LocalDateTime.of(2007, 12, 3, 10, 15, 30);

datetime.getYear();
// => 2007

datetime.getMonthValue();
// => 12

datetime.getDayOfMonth();
// => 3

datetime.getHours();
// => 10

datetime.getMinutes();
// => 15

datetime.getSeconds();
// => 30
```

Як і клас `LocalDate`, примірник `LocalDateTime` має ті самі методи, щоб порівнювати його з іншими `LocalDateTime` і додавати до нього одиниці часу.

Також можна перетворити примірник `LocalDate` на `LocalDateTime`:

```java
LocalDate date = LocalDate.of(2007, 12, 3);
LocalDateTime datetime = date.atTime(10, 15, 30);
datetime.toString();
// => "2007-12-03T10:15:30"
```

## Форматування дат і часу

І `LocalDate`, і `LocalDateTime` використовують стандартний запис [ISO-8601][iso-8601], коли перетворюють на `String` і з `String`.

```java
LocalDateTime datetime = LocalDateTime.of(2007, 12, 3, 10, 15, 30);
LocalDateTime parsed = LocalDateTime.parse("2007-12-03T10:15:30");

datetime.isEqual(parsed);
// => true
```

Розібрати `LocalDate` чи `LocalDateTime` з `String` у такий самий спосіб, але в іншому форматі, не вийде.
Натомість, щоб форматувати дати за власним форматом, скористаймося [`java.time.format.DateTimeFormatter`][datetimeformatter-docs]:

```java
DateTimeFormatter parser = DateTimeFormatter.ofPattern("dd/MM/yyyy");
LocalDate date = LocalDate.parse("03/12/2007", formatter);

DateTimeFormatter printer = DateTimeFormatter.ofPattern("MMMM d, yyyy");
printer.format(date);
// => "December 3, 2007"
```

Під час створення власного формату також можна вказати [локаль][locale], щоб форматувати й розбирати дати для різних регіонів:

```java
DateTimeFormatter.ofPattern("MMMM d, yyyy", Locale.FRENCH).format(date);
// => décembre 3, 2007

DateTimeFormatter.ofPattern("MMMM d, yyyy", Locale.of("pt")).format(date);
// => dezembro 3, 2007
```
