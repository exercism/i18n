# Докладніше

[Тернарний оператор][ternary-operator] є короткою формою умовної конструкції if-else.
Він приймає булевий вираз і два вирази, розділені двокрапкою.
Якщо булевий вираз має значення правда, обчислюється перший вираз, інакше обчислюється другий вираз.
Він має такий вигляд: `Boolean-expression ? expression1 : expression2`.

Тернарний оператор чудово підходить тоді, коли потрібна коротка форма умовної конструкції if-else, а вирази короткі:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = showFahrenheit ? temperatureInCelsius * 9 / 5 + 32 : temperatureInCelsius
print(temperature)
// Prints 86
```

Наведений вище приклад є скороченим записом такого коду:
    
```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = if showFahrenheit {
    temperatureInCelsius * 9 / 5 + 32
} else {
    temperatureInCelsius
}
```

[ternary-operator]: https://docs.swift.org/swift-book/LanguageGuide/BasicOperators.html#ID71
