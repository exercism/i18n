# Використання індексу rune з bytes

Перебирати `runes` і використовувати індекс, щоб отримати окремі `bytes`, у цьому випадку безпечно, тому що вхідні дані складаються лише з ASCII-символів. 
Щоб побачити, що станеться із символами поза ASCII, додайте цей тестовий випадок:

```go
{
	s1:          "aüa",
	s2:          "aÃa",
	want:        1,
	expectError: false,
}
```
