# Вступ

Коли Elixir визначає, яку функцію слід викликати, він використовує назву модуля, щоб виконати пошук. Пошук можна виконати динамічно, якщо назву модуля привʼязано до змінної.

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```

Усередині назва модуля зберігається як атом. Усі атоми модулів Elixir автоматично отримують префікс `Elixir.`

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```
