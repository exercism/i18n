# Вступ

## Словники

Словник - це колекція елементів, де кожен елемент складається з ключа та значення, так що якщо ключ передати методу словника, повертається повʼязане з ним значення. Він відіграє ту саму роль, що й мапи чи асоціативні масиви в інших мовах.

Словник можна створити так:

```csharp
new Dictionary<int, string>();
// Empty dictionary
```

Або

```csharp
new Dictionary<int, string>
{
    [1] = "One",
    [2] = "Two"
};

// Or

new Dictionary<int, string>
{
    {1, "One"},
    {2, "Two"}
};
// 1 => "One", 2 => "Two"
```

Зауважмо, що типи ключа та значення є частиною визначення словника.

Після створення записи можна додавати чи вилучати зі словника за допомогою його вбудованих методів `Add` і `Remove`.

Щоб отримати чи оновити значення у словнику, ми звертаємося до словника за індексом, використовуючи ключ:

```csharp
var numbers = new Dictionary<int, string>
{
   {1, "One"},
   {2, "Two"}
};

// Set the value of the element with key 2 to "Deux"
numbers[2] = "Deux";

// Get the value of the element with key 2
numbers[2];
// => "Deux"
```

Перевірити, чи існує значення у словнику, можна так:

```csharp
var dict = new Dictionary<string, string>{/*...*/};
dict.ContainsKey("some key that exists");
// => true
```

Перебирання словника перебирає його пари ключ-значення. Словники також мають властивості, які дозволяють перебирати їхні ключі чи значення.
