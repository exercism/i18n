# Відсоткове форматування або «старий стиль»

Це рішення використовує `%%-formatting` або [старе форматування][old-style formatting] для рядків тексту (англ. string).

Хоча підхід `%%-formatting` цілком слушний, він може створювати проблеми з відображенням або читабельністю. Використання методу [str.format()][str.format()] або [f-strings][f-strings] (_їх також називають «форматованими рядковими літералами» або «інтерпольованими рядками»_) може запропонувати варіанти, які покращують читабельність і роблять заміну змінних усередині рядків тексту зрозумілішою.

Допис у блозі [String Formatting in Python][string formatting in python] - гарна відправна точка для розуміння всіх варіантів форматування рядків тексту в Python, а [Newer Python String Format Techniques][newer python string format techniques] також дає слушні поради та прийоми для використання `str.format()` і `f-strings`.
