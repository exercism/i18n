# Вступ

У Python `None` часто використовують, щоб позначити відсутність значення: це заповнювач для оголошення `null` (порожньої) змінної, обʼєкта або аргументу.

Якщо ми чули про тип `NULL` чи `nil` в іншій мові програмування або користувалися ним, то це використання `None` у Python буде нам знайомим.
`None` допомагає нам оголошувати змінні або аргументи функцій, для яких у нас ще немає значень.
Потім їм можна присвоїти конкретні значення, коли це потрібно:


```python
a = None
print(a)
#=> None

type(a)
#=> <class 'NoneType'>

# Adding a default argument with `None`
def add_to_todos(new_task, todo_list=None):
    if todo_list is None:
        todo_list = []  
    todo_list.append(new_task)
     
  return todo_list
```

`None` обчислюється як `False` в умовній перевірці, тож він стає в пригоді, коли треба перевірити наявність або відсутність значення (*будь-якого* значення). Цей прийом часто використовують, коли функція чи процес можуть повернути `error`, `object` або повідомлення.

```python
a = None
if a: #<-- a will be evaluated to False when it is used in a conditional check.
    print("This will not be printed")
```
