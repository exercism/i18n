# Інструкції

Бібліотека Лутона - велика бібліотека з великою колекцією літератури, від книжок до мистецтва.
У бібліотеці є відділ, де вивчають літературу та додають книжки до компʼютерної системи.

Деякі частини мають бути автоматизовані, і нас просять допомогти.
Це охоплює допомогу в усьому: від автоматизації форм процесу вписування до розшифрування текстів.

## 1. Отримати першу літеру назви

Книжки в бібліотеці мають бути легко знаходити, тому їх сортують за першою літерою назви.

Реалізуйте метод `Library.first_letter`, який приймає аргумент `title`, що містить назву книги.
Метод має повертати першу літеру назви.

```Crystal
Library.first_letter("Mystery of the Crystal Skull")
# => 'M'
```

## 2. Отримати ініціали авторів

У бібліотеці багато книжок, написаних різними авторами.
Авторів часто називають за ініціалами, тож бібліотека попросила систему, яка за введеними імʼям та прізвищем видає ініціали автора.
Ініціали мають бути відформатовані так: `{first_letter_of_first_name}.{first_letter_of_last_name}`

Реалізуйте метод `Library.initials`, який приймає два аргументи `first_name` і `last_name`, що містять імʼя та прізвище автора.
Метод має повертати ініціали автора.

```Crystal
Library.initials("William", "Shakespeare")
# => "W.S"
```

## 3. Розшифрувати літеру

Деяка література зашифрована, і в бібліотеці багато зашифрованих текстів.
Бібліотека хотіла б отримати нову систему розшифрування для особливого шифрування.

Шифрування працює так: беруть літеру й замінюють її на літеру, що стоїть перед нею в алфавіті.
Наприклад, `a` стає `z`, `b` стає `a`, `c` стає `b` і так далі.

Бібліотека хотіла б, щоб система могла розшифровувати як великі, так і малі літери й зберігати той самий регістр, що й у вихідної літери.

Реалізуйте метод `Library.decrypt_character`, який приймає аргумент `character`, що містить літеру для розшифрування.
Метод має повертати розшифровану літеру.

```Crystal
Library.decrypt_character('a')
# => 'z'
```

## 4. Розшифрувати текст

Бібліотека також хотіла б розшифровувати цілий текст за допомогою шифрування, яке бере попередню літеру в алфавіті.

Розшифрувальник має розшифровувати лише літери, а всі інші символи залишати без змін.

Реалізуйте метод `Library.decrypt_text`, який приймає аргумент `text`, що містить текст для розшифрування.
Метод має повертати розшифрований текст.

```Crystal
Library.decrypt_text("Ifmmp Xpsme!")
# => "Hello World!"
```
