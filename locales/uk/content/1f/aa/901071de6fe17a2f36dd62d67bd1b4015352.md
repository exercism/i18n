# Інструкції

Aazra та Rui розробляють піратський квест з пошуку скарбів. Є список скарбів із зазначенням їхніх розташувань на карті, а також список назв місць із зазначенням їхніх розташувань.

| --------------------------- | ------------ |
| Amethyst Octopus            | (1, F)       |
| Angry Monkey Figurine       | (5, B)       |
| Antique Glass Fishnet Float | (3, D)       |
| Brass Spyglass              | (4, B)       |
| Carved Wooden Elephant      | (8, C)       |
| Crystal Crab                | (6, A)       |

| Vintage Pirate Hat          | (7, E)       |

| Назва місця                           | Розташування | Квадрант |
| ------------------------------------- | ------------ | -------- |
| Seaside Cottages                      | (C, 1) | Blue      |
| Aqua Lagoon (Island of Mystery)       | (F, 1) | Yellow    |

| Windswept Hilltop (Island of Mystery) | (F, 7) | Orange    |
| Harbor Managers Office                | (A, 8) | Purple    |
| Foggy Seacave                         | (C, 8) | Purple    |

Гравці подорожують картою і дорогою збирають скарби.
Розташування скарбів і місць записано по-різному, щоб додати додаткову складність.
Є також особливі місця, де одні скарби можна обміняти на інші, щоб додати грі ще одну цікавинку.
Наше завдання - написати функції, які допоможуть їм у цій грі.

## 1. Перетворення розташувань

Реалізуйте функцію `placeLocationToTreasureLocation`, яка приймає розташування місця (наприклад, `('C', 1)`) і перетворює його на розташування скарбу (наприклад, `(1, 'C')`).

```elm
placeLocationToTreasureLocation ('C', 1)
--> (1,'C')
```

## 2. Порівняння розташувань скарбів і місць

Реалізуйте функцію `treasureLocationMatchesPlaceLocation`, яка приймає `PlaceLocation` (наприклад, `('C', 1)`) і повертає правду, якщо воно збігається з `TreasureLocation` (наприклад, `(1, 'C')`).

```elm
treasureLocationMatchesPlaceLocation ('C', 1) (1, 'C')
--> true

treasureLocationMatchesPlaceLocation ('C', 1) (2, 'C')
--> false
```

## 3. Підрахунок розташувань скарбів

Реалізуйте функцію `countPlaceTreasures`, яка приймає місце (наприклад, `("Aqua Lagoon (Island of Mystery)", ('F', 1))`) і список скарбів, та повертає кількість скарбів, які можна там знайти.

```elm
place = ("Aqua Lagoon (Island of Mystery)", ('F', 1))

countPlaceTreasures place treasures =
--> 2
```

## 4. Особливі місця

Реалізуйте функцію `specialCaseSwapPossible`, яка приймає скарб (наприклад, `("Amethyst Octopus", (1, 'F'))`) і місце (наприклад, `("Seaside Cottages ", ('C', 1))`), та повертає правду для таких комбінацій:

- Brass Spyglass можна обміняти на будь-який інший скарб у Abandoned Lighthouse
- Amethyst Octopus можна обміняти на Crystal Crab або Glass Starfish у Stormy Breakwater
- Vintage Pirate Hat можна обміняти на Model Ship in Large Bottle або Antique Glass Fishnet Float у Harbor Managers Office

Спробуйте реалізувати цю функцію як конструкцію case зі спеціально створеним кортежем, а не через умовні конструкції if (це поширена ідіома в Elm).
