# Вступ

У SQL інструкція `SELECT` дає змогу отримувати дані з бази даних.
Результатом інструкції `SELECT` є набір результатів.
Набір результатів містить значення, упорядковані в рядки та стовпці.
Кожен стовпець описує окремий атрибут даних.
Кожен рядок містить значення для кожного стовпця.

Один зі способів уявити це такий: набір стовпців утворює структуру даних, де кожен стовпець відповідає полю структури даних, а кожен рядок - екземпляру структури даних.

За допомогою інструкції `SELECT` ми вказуємо, які дані хочемо отримати.
Крім того, ми можемо за бажанням перетворювати, фільтрувати та/або змінювати форму вихідних даних.

## Основи

Будова базової інструкції `SELECT` така:

```sql
SELECT <columns>
FROM <source>
WHERE <criteria>;
```

~~~~exercism/note
Конструкції `FROM` і `WHERE` необовʼязкові.
Наприклад, інструкція на кшталт `SELECT "Hello, world.";` цілком допустима.

Зауважмо також, що розриви рядків не обовʼязкові: щоб розділити різні конструкції (тобто частини) інструкції `SELECT`, достатньо будь-яких проміжків.
~~~~

Одразу після ключового слова `SELECT` іде список стовпців, які ми хочемо бачити в результаті.
Конструкція `FROM` указує джерело даних, яким зазвичай є таблиця в базі даних.
Конструкція `WHERE` фільтрує вихідні дані за однією або кількома умовами.

## Фільтрування даних за допомогою конструкції WHERE

Конструкція `WHERE` дає змогу фільтрувати дані, отримані інструкцією `SELECT`.
Наприклад, якщо нам потрібні лише Appliances, можемо зробити так:

```sql
SELECT * FROM inventory
WHERE category = "Appliances";
```

Результат:
```
upc           category    supplier        brand      product_name                 weight  stock
------------  ----------  --------------  ---------  ---------------------------  ------  -----
899001234556  Appliances  Culinary Depot  QuickBrew  Single-Serve Coffee Maker    4.2     18   
880012349876  Appliances  Culinary Depot  HeatWave   Compact Toaster Oven         7.5     14   
844110220987  Appliances  Culinary Depot  BlendPro   High-Speed Personal Blender  3.1     16   
```

Або, можливо, нам потрібні лише дані, де weight лежить між 2.0 і 6.0:

```sql
SELECT * FROM inventory
WHERE weight BETWEEN 2.0 AND 6.0;
```

Результат:
```
upc           category    supplier        brand      product_name                  weight  stock
------------  ----------  --------------  ---------  ----------------------------  ------  -----
899001234556  Appliances  Culinary Depot  QuickBrew  Single-Serve Coffee Maker     4.2     18   
823450987112  Cookware    KitchenCo       FreshKeep  12-Piece Glass Container Set  6       33   
899998877665  Cookware    KitchenCo       IronCraft  Cast-Iron Grill Pan           5.3     21   
844110220987  Appliances  Culinary Depot  BlendPro   High-Speed Personal Blender   3.1     16   
```

Окрім `=` і `BETWEEN...AND`, конструкція `WHERE` підтримує широкий набір виразів, зокрема порівняння (`<`, `<=`, `>`, `>=`), пошук за зразком (`LIKE`, `GLOB`, `REGEXP`, `MATCH`) і перевірку на належність до списку (`IN`, `NOT IN`).
Повну документацію можна знайти на сторінці [SQL Language Expressions](sql-expr).
