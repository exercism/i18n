# Докладніше

`while` та `until` (у [`kernel`][kernel]) - комбінатори циклів на основі quotation для випадку, коли кількість ітерацій заздалегідь невідома:

```
while ( pred: ( -- ? ) body: ( -- ) -- )
until ( pred: ( -- ? ) body: ( -- ) -- )
```

`while` продовжує роботу, доки `pred` залишає істинне значення; `until` продовжує роботу, доки `pred` залишає `f`. Обидва зупиняються й повертають керування, коли їхній предикат змінює значення на протилежне.

```factor
USING: kernel math ;

! Halve down to 1
16 [ dup 1 > ] [ 2 / ] while .   ! => 1

! Double up to 100
1 [ dup 100 >= ] [ 2 * ] until .   ! => 128
```

Коли одного значення, що проходить по стеку, не вистачає для стану (скажімо, потрібні водночас і залишок списку, і накопичувальна сума, і лічильник), найчистіший підхід - скористатися для ясності іменованими *локальними змінними*. Локальні змінні докладніше розглядаються далі в навчальній програмі, тож тут достатньо знати, що `:: word ( a b -- c )` оголошує вхідні дані як іменовані локальні змінні, а `:> name!` додає змінювану локальну змінну, яку тіло циклу може оновити за допомогою `value name!`.

```factor
USING: kernel locals math sequences ;

! Sum a sequence by hand
:: sum-by-hand ( seq -- total )
    seq :> rest!
    0 :> running!
    [ rest length 0 > ] [
        rest unclip [ rest! ] dip
        running + running!
    ] while
    running ;
```

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
