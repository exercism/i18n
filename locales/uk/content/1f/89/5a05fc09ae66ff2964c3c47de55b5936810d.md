# Ресурси

## Створення першого модуля CoffeeScript

Щоб створити модуль, який можна завантажити за допомогою `Bob = require './bob'`, помістіть цей код у файл `bob.coffee`:

```coffeescript
class Bob

module.exports = Bob
```

Більше інформації про модулі можна знайти в [документації Node](http://nodejs.org/api/modules.html#modules_module_exports).

## Visual Studio у Windows

За наявності платної версії Visual Studio можна завантажити готовий проєкт Visual Studio, уже налаштований для роботи з CoffeeScript та іншими мовами, які підтримує Visual Studio.

![Solution Explorer](https://raw.githubusercontent.com/exercism/coffeescript/main/docs/img/SolutionExplorer.png)

1. Завантажте [шаблон Exercism.io для Visual Studio](https://github.com/rprouse/Exercism.VisualStudio) з GitHub, натиснувши на цій сторінці кнопку Download Zip.
2. Розпакуйте шаблон у каталог вправ, наприклад `C:\src\exercises`
2. Встановіть [Exercism CLI](http://exercism.io/cli)
3. Відкрийте командний рядок у каталозі вправ
4. Додайте свій ключ API до exercism: `exercism configure --key=YOUR_API_KEY`
5. Налаштуйте каталог вихідних файлів в exercism: `exercism configure --dir=C:\src\exercises`
6. [Завантажте свою першу вправу](http://exercism.io/languages/coffeescript): `exercism fetch coffeescript`
7. Відкрийте рішення Exercism у Visual Studio
8. Розгорніть проєкт Exercism.coffeescript
9. Натисніть **Show All Files** в Solution Explorer (див. нижче)
10. Щойно завантажена вправа зʼявиться сірою. Клацніть правою кнопкою миші на теці та виберіть **Include In Project**
11. Беріться до коду...

![Додавання файлів](https://raw.githubusercontent.com/exercism/coffeescript/main/docs/img/AddFiles.png)

Щоб працювати з CoffeeScript у Visual Studio, варто встановити розширення [Web Essentials](http://vswebessentials.com/). Воно також значно полегшить роботу з JavaScript.

Модульні тести можна запустити з командного рядка node.js за допомогою пакетного файлу в проєкті.

```bash
C:\Src\exercises\coffeescript> test example\bob_test.spec.coffee
.................

Finished in 0.02 seconds
17 tests, 17 assertions, 0 failures, 0 skipped
```

Якщо під час запуску тестів не видно жодного виводу, найімовірніше, це не командний рядок Node.js.
