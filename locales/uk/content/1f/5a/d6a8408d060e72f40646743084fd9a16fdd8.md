# Null

Null — це примітивний тип даних з єдиним значенням: `null`.
Часто null використовують для позначення відсутності значення.
Його вважають хибним, але він відрізняється від `false` та інших хибних значень.

```php
<?php

is_null(null); // => true
isset(null); // => false

null == true; // => false
null === true; // => false

null == false; // => true
null === false; // => false
```

## Робота зі значеннями null

У PHP значення null часто стають причиною помилок, адже їх нерідко повертають замість стану помилки або для позначення відсутності значення.
Щоб помилки не виникали, часто доводиться робити «перевірку на null»: переконатися, що значення не null, перш ніж працювати з ним.

Повторювані перевірки на null можуть призводити до помилок, тому PHP надає два оператори для роботи зі значеннями null: оператор безпечного доступу `?->` й оператор обʼєднання з null `??`.
