# Основи синтаксису Haskell

## Константи та функції

Програми на Haskell складаються з визначень і виразів.

Стале значення визначають як `name = expression`.

```haskell
five = 5

six = 3 + 3
```

Функції визначають як `name parameters... = expression`, де параметри розділяються лише пробілом.

```haskell
add number1 number2 = number1 + number2
```

Виклик функції також є виразом і виконується так: ми вказуємо її назву й передаємо аргументи для кожного з параметрів функції, розділяючи їх пробілами, так само як і у визначеннях функцій.

```haskell
five = add 2 3
```

Дужки можна використовувати, щоб задати порядок обчислення виразу.

```haskell
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## Відступи / значущі пробіли

Haskell використовує пробіли й відступи, щоб визначати межі коду.
***Код, який є частиною якогось виразу, має бути відступлений далі, ніж початок цього виразу.***

- Визначення модулів, імпортів і функцій верхнього рівня мають починатися з найлівішої колонки.
- Якщо вираз розбито на кілька рядків, код, який є частиною цього виразу, має бути відступлений під ним щонайменше на один пробіл.
- Частини виразу, згруповані разом, мають бути відступлені на однакову кількість пробілів.

```haskell
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://en.wikibooks.org/wiki/Haskell/Indentation

## Модулі

Модулі експортують функції.
Це означає, що ми можемо використовувати функції, які модуль робить доступними у своєму списку експорту.
Модуль також може визначати функції лише для внутрішнього використання.
Якщо не вказано іншого, функції, які явно не експортовано, не можна використовувати ззовні модуля.

На початку модуля ми вказуємо назву модуля.
Якщо у нас є файл із назвою Calculator.hs, то модуль має називатися Calculator.
Далі ми вказуємо функції, які він експортує, а після цього можемо почати писати функції.
Отже, почнімо з цього.

```haskell
module Calculator ( add ) where
```

https://learnyouahaskell.github.io/modules#making-our-own-modules

## Коментарі

Коментар - це текст у файлі Haskell, який не інтерпретується як код.
Його пишуть переважно для себе та інших програмістів.
Для однорядкових коментарів є простий синтаксис на основі двох дефісів.
Багаторядкові коментарі також можливі за допомогою пари відкриваючого та закриваючого роздільника `{-` і `-}`.

```haskell
-- a single line comment
-- another single line comment

{- a multiline comment
   spanning multiple lines
-}
```
