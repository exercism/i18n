# Вступ

Go містить базові числові типи, які можуть представляти набори цілих чисел або чисел з плаваючою комою.

У цій концепції ми зосередимося на двох типах чисел:

- `int`: наприклад, `0`, `255`, `2147483647`.
   Ціле число зі знаком, розмір якого становить щонайменше 32 біти (діапазон значень: від -2147483648 до 2147483647).
   Але це залежить від архітектури системи.
   Більшість сучасних компʼютерів 64-бітні, тому `int` матиме розмір 64 біти (діапазон значень: від -9223372036854775808 до 9223372036854775807).

- `float64`: наприклад, `0.0`, `3.14`.
   Містить набір усіх 64-бітних чисел з плаваючою комою.

Go підтримує стандартний набір арифметичних операторів: `+`, `-`, `*`, `/` і `%` (остача від ділення, а не модуль).

У Go присвоєння значення між різними типами вимагає явного перетворення.
Наприклад, щоб перетворити `int` на `float64`, потрібно зробити таке:

```go
var x int = 42
f := float64(x)

fmt.Printf("x is of type: %s\n", reflect.TypeOf(x))
// Output: x is of type: int

fmt.Printf("f is of type: %s\n", reflect.TypeOf(f))
// Output: f is of type: float64
```
