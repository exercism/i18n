# Вступ

Типи C# можна визначати в межах області видимості класу або struct. Зовнішній тип забезпечує щось на кшталт простору імен. Доступ до типу здійснюється через зовнішній тип за допомогою синтаксису з крапкою.

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

Для вкладених типів можна встановлювати рівні доступу.

Приватні члени зовнішнього типу перебувають в області видимості для членів вкладеного типу, але не навпаки.
