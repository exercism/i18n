# Детальніше

## Арифметичні оператори

JavaScript надає 6 різних операторів для виконання базових арифметичних дій над числами.

- `+`: оператор додавання використовується, щоб знайти суму чисел.

  ```javascript
  1 + 2; // => 3
  2.5 + 3.9; // => 6.5
  ```

- `-`: оператор віднімання використовується, щоб знайти різницю між двома числами

  ```javascript
  19 - 2; // => 17
  7.4 - 1.2; // => 6.2
  ```

- `*`: оператор множення використовується, щоб знайти добуток двох чисел

  ```javascript
  7 * 5; // => 35
  9.2 * 6.3; // => 57.959999999999994
  ```

- `/`: оператор ділення використовується, щоб поділити одне число на інше.
  Оскільки числа в JavaScript завжди є числами з плаваючою комою, ділення націло не існує.

  ```javascript
  8 / 2; // => 4
  25 / 3; // => 8.333333333333334
  ```

- `%`: оператор остачі використовується, щоб знайти остачу від виконаного ділення.

  ```javascript
  40 % 4; // => 0
  11 % 4; // => 3
  -11 % 4; // => -3
  ```

- `**`: оператор піднесення до степеня використовується, щоб піднести число до степеня.
  Він рівнозначний використанню [`Math.pow()`][mdn-math-pow]

  ```javascript
  4 ** 3; // => 64
  4 ** 1 / 2; // => 2
  ```

## Порядок виконання операцій

Коли в одному рядку використовується кілька операторів, JavaScript дотримується порядку пріоритету, показаного в [цій таблиці пріоритетів][mdn-operator-precedence].
Якщо спростити це для нашого контексту, JavaScript використовує правило PEDMAS (дужки, степені, ділення/множення, додавання/віднімання), яке ми вивчали на уроках елементарної математики.

<!-- prettier-ignore-start -->
```javascript
const result = 3 ** 3 + 9 * 4 / (3 - 1);
// => 3 ** 3 + 9 * 4/2
// => 27 + 9 * 4/2
// => 27 + 18
// => 45
```
<!-- prettier-ignore-end -->

## Скорочені оператори присвоєння

Скорочені оператори присвоєння - це коротший спосіб записати код, який виконує арифметичні дії над змінною та присвоює нове значення тій самій змінній.
Наприклад, візьмімо дві змінні `x` і `y`.
Тоді `x += y` означає те саме, що `x = x + y`.
Часто замість змінної `y` використовують просто число.
Решту 5 операцій можна записати так само.

```javascript
let x = 5;
x += 25; // x is now 30

let y = 31;
y %= 3; // y is now 1
```
