## MacOS

Спершу встановімо Lua та [Luarocks][2] за допомогою [Homebrew][1]:

```shell
$ brew install lua luarocks
```

Потім встановімо фреймворк для тестування [Busted][3] для Lua:

```shell
$ luarocks install --local busted
```

Додамо `~/.luarocks/bin` до системного `$PATH`

```shell
export PATH="$HOME/.luarocks/bin:$PATH"
```

Зауважмо, що це лише тимчасово.
Щоб додати назавжди до свого `$PATH`, доведеться додати це до `.bashrc`, `.zshrc` або `config.fish` залежно від того, яку оболонку ми використовуємо.

Потім запустімо тести:

```shell
$ busted
```

## Windows 10: WSL

Спершу треба увімкнути [WSL (Windows Subsystem for Linux)][7] за допомогою [PowerShell][8] (від імені адміністратора):

```shell
PS> Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Windows-Subsystem-Linux
```

Це потребує перезавантаження.

Далі встановімо Ubuntu з [Microsoft Store][9] **або** завантажмо й встановімо його за допомогою PowerShell:

```shell
PS> curl.exe -L -o ubuntu1804.appx https://aka.ms/wsl-ubuntu-1804
PS> Add-AppxPackage .\ubuntu1804.appx; rm .\ubuntu1804.appx
PS> ubuntu1804
```

Потім оновімо список пакетів:

```shell
PS> wsl
$ sudo apt-get update
```

Тепер ми готові встановити [LuaRocks][2] і [Busted][3], скориставшись [інструкціями для Ubuntu](#ubuntu) вище.

Коли все готово, ми можемо запускати тести безпосередньо з будь-якого командного рядка Windows:

```cmd
C:\> wsl busted
```

Завантажити можна [тут][10].
Інструкції зі встановлення [тут][11].

### Встановлення Docker

Дотримуймося інструкцій, щоб встановити [Docker for Windows][12].
Коли встановлення завершиться, ми можемо виконати наступну команду, щоб переконатися, що все встановлено правильно.

```shell
$ docker --version
```

_Можливо, під час першого запуску Docker виникне помилка._

`cannot enable hyper-v service`

_Якщо це сталося, скористаймося цими інструкціями, щоб [увімкнути Hyper V][13]. Можливо, доведеться вимкнути параметр, перезавантажити компʼютер і знову ввімкнути його після завантаження._

### Встановлення busted

Коли Gitbash і Docker встановлено, ми зможемо встановити «контейнер» busted.

У Gitbash виконаймо наступне:

Завантажмо цей широко використовуваний Docker-контейнер, виконавши наступне:

```shell
$ docker pull imega/busted
```

Створімо функцію, щоб не доводилося щоразу вводити всю команду.
Додамо це до `.bashrc`:

```shell
dbusted() { docker run --rm -t -v "/$@":/data imega/busted; }
```

Тепер в інтерфейсі командного рядка ми можемо перейти до каталогу, у якому хочемо запускати тести. Виконаймо наступне:

```shell
$ dbusted $PWD
```

Ми повинні побачити вихідні дані від наших тестів busted.
