# Інструкції

Місцевий поетичний клуб відкриває новий сезон. Поети приєднуються до клубу, і коли двоє з них пишуть вірш разом, вони стають частиною одного *письменницького кола*. Клуб хоче знати, хто з ким ділить коло, і нас попросили написати слова, які всім цим керують.

Система неперетинних множин підходить якнайкраще: кожен поет - окремий елемент, а письменницьке коло - група.

## 1. Відкрити клуб

Визначте `new-club`, який приймає послідовність поетів і повертає нову систему неперетинних множин, де зареєстровано кожного поета. Кожен поет починає у власному письменницькому колі.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
! => a disjoint set holding the three poets
```

## 2. Записати співпрацю

Визначте `collaborate`, який приймає двох поетів і клуб. Він обʼєднує письменницькі кола цих двох поетів і повертає клуб, тож співпрацю можна записувати одну за одною.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Keats" "Byron" rot collaborate
! => the club, with Keats and Byron now in one circle
```

## 3. Знайти коло поета

Визначте `circle-of`, який приймає поета і клуб та повертає представника письменницького кола цього поета. Двоє поетів, які ділять одне коло, завжди мають того самого представника.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Dickinson" swap circle-of
! => "Dickinson"   (still in a circle of their own)
```

## 4. Чи ділять вони коло?

Визначте `same-circle?`, який приймає двох поетів і клуб та повертає `t`, коли обидва поети належать до одного письменницького кола, і `f` в іншому разі. Порівняйте представників поетів, а не використовуйте вбудований тест на еквівалентність.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Keats" "Byron" rot collaborate
dup [ "Keats" "Byron" ] dip same-circle? .      ! => t
    [ "Keats" "Dickinson" ] dip same-circle? .  ! => f
```
