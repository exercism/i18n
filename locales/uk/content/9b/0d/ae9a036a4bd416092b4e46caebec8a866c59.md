# Інструкції

Шкільний офіс забутих речей зберігає все в коробках, а в коробці може опинитися будь-що: светр, кілька речей, імʼя.

Напишіть клас `LOST_BOX{T}`. Заголовок класу вже надано в заготовці.

## 1. Прийняти річ

`create` приймає річ і імʼя того, хто її здав, і повертає коробку. Спочатку коробку не затребувано.

```sather
box ::= #LOST_BOX{STR}("blue jumper", "Mia");
box.item
-- => "blue jumper"
box.handed_in_by
-- => "Mia"
box.claimed
-- => false
```

## 2. Затребувати її

`claim` позначає коробку як затребувану. Вона нічого не повертає.

```sather
box.claim;
box.claimed
-- => true
```

## 3. Чи вона ще чекає?

`waiting` повертає, чи коробку ще не затребувано.

```sather
box.waiting
-- => false
```

## 4. Замінити вміст

`replace` приймає нову річ, кладе її в коробку й повертає те, що було там раніше. І річ, що входить, і річ, що виходить, мають тип `T`.

```sather
old ::= box.replace("red jumper");
old
-- => "blue jumper"
box.item
-- => "red jumper"
```

## 5. Скласти опис

`describe` повертає рядок тексту про коробку, як-от
`"blue jumper, handed in by Mia"`.

Щоб умістити річ у рядок тексту, клас має знати, що `T` можна перетворити на рядок. Обмежте параметр: запишіть заголовок класу як
`class LOST_BOX{T < $STR}`, і тоді `item.str` стане дозволеним.

```sather
box.describe
-- => "blue jumper, handed in by Mia"
```
