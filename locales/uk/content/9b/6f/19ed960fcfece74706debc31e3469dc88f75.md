# Про

У PHP змінну можна викликати як функцію, застосувавши до неї дужки [`()`]. Коли PHP намагається викликати функцію, відбувається пошук функції з тією самою назвою, що й значення змінної.

```php
function foo(): string
{
    return "foo() invoked";
}

$func = 'foo';
$func(); // This calls foo()
```

## Виклик статичних функцій класу

Статичні функції класу можна викликати так само:

```php
class Rocket
{
    public static function launch()
    {
        return '3, 2, 1, Liftoff!';
    }
}

$func = 'Rocket::launch';
$func(); // This calls Rocket::launch()
```

## Виклик функцій екземпляра класу

Також можна викликати функцію екземпляра класу:

```php
class Rocket
{
    public function openDoor()
    {
        return 'Door open.';
    }
}

$rocket = new Rocket();
$func = [$rocket, 'openDoor'];
$func(); // This calls Rocket::openDoor()
```
