# Інструкції

Ваша Величність влаштовує званий обід у столиці [Кальмарської унії][kalmar_union], Копенгагені.
Це найбільше свято року, і всю знать запрошено.
Але країною ширяться чутки про змову, щоб отруїти Вашу Величність.

Її Величність попросила нас, королівського шукача отрути, зʼясувати, чи не отруєна якась страва чи напій.
Її Величність планує подати з їжі лише **Mushroom pasties**, а от напої будуть найрізноманітніші.

## 1. Перевірте, чи страва правильна

Якщо страва не та, яку замовила Її Величність, є велика ймовірність, що її отруєно.
А якщо страва не та, яку замовила Її Величність, її слід викинути.

Реалізуйте метод `check_food?`, який приймає аргумент `food`, що містить назву страви як `String`.
Метод має повернути страву, якщо це `Mushroom pasties`; інакше він має повернути `nil`.

```crystal
CastleDinner.check_food?("Mushroom pasties")
# => "Mushroom pasties"

CastleDinner.check_food?("Bread")
# => nil
```

## 2. Перевірте, чи напій отруєний

Можливо, напій отруєний, але визначити це трохи складніше.
Напій отруєний, якщо в його назві **немає** літери `i`; регістр не має значення.
Отруєний напій слід викинути.

Реалізуйте метод `check_drink?`, який приймає аргумент `drink`, що містить назву напою як `String`.
Метод має повернути напій, якщо він не отруєний; інакше він має повернути `nil`.

```crystal
CastleDinner.check_drink?("Apple juice")
# => "Apple juice"

CastleDinner.check_drink?("Tea")
# => nil
```

## 3. Замініть напій

Ваша Величність не хотіла б, щоб гості непокоїлися через можливу отруту в їжі.
Тож якщо напій отруєний, його слід замінити новим, а саме **Apple juice**.

Реалізуйте метод `replace_drink`, який приймає аргумент `drink`, що містить назву напою як `String`.
Метод має повернути напій, якщо він не отруєний; інакше він має повернути `"Apple juice"`.

```crystal
CastleDinner.replace_drink("Orange juice")
# => "Orange juice"

CastleDinner.replace_drink("Tea")
# => "Apple juice"
```
