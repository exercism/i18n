# Доповнення до інструкцій

## Підказки

Потрібно реалізувати функцію `recite`, яка виводить текст пісні «The Twelve Days of Christmas». Можна скористатися наданою сигнатурою, якщо є сумніви щодо типів, але не варто дозволяти їй обмежувати творчість.

Ця вправа працює з текстовими даними. З історичних причин тип `String` у Haskell позначає те саме, що `[Char]`, тобто масив символів. Для ефективнішої роботи з текстовими даними можна використовувати тип `Text`.

Як необовʼязкове доповнення до цієї вправи, можна

- прочитати про [типи рядків тексту (англ. string)](https://haskell-lang.org/tutorial/string-types) у Haskell.
- додати `- text` до переліку залежностей у package.yaml.
- імпортувати `Data.Text` [у такий спосіб](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- написати, наприклад, `recite :: Int -> Int -> [Text]` і звертатися до комбінаторів `Data.Text` як, наприклад, `T.pack`.
- пошукати документацію для
  [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html).
- замінити всі входження `String` на `Text` у TwelveDays.hs, тобто:

```haskell
recite :: Int -> Int -> [Text]
```

Ця частина цілком необовʼязкова.
