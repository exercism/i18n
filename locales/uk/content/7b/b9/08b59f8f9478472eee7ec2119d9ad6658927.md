В Elixir є особливі домовленості щодо назв, зокрема щодо того, як називати [функції, що повертають булеві значення (англ. Boolean)](https://hexdocs.pm/elixir/naming-conventions.html#trailing-question-mark-foo):

> Функції, що повертають булеве значення, називають зі знаком питання в кінці.

```elixir
# this is the expected name of functions that return a boolean

%{expected}

# this is the current name

%{actual}
```

Зауважмо, що охоронні вирази, а також деякі вбудовані функції та макроси, які повертають булеві значення і які можна використовувати в охоронних виразах, дотримуються іншої домовленості й називаються з префіксом `is_` (`def is_integer`, `defguard is_foo`, `defmacro is_foo`). Ці дві домовленості не можна змішувати.
