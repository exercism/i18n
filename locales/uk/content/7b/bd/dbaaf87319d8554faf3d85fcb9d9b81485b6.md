# Вступ

У Cairo немає вбудованого типу для рядків тексту (англ. string), але є два способи працювати з ними: короткі рядки в одинарних лапках і `ByteArray` у подвійних.

Короткий рядок - це ASCII-рядок, у якому кожен символ закодовано одним байтом.

Тип, який Cairo типово використовує для коротких рядків, - це `felt252`, тож їхня максимальна довжина становить лише 31 символ.

```rust
// below are different ways to write the same value
let name: felt252 = 'Jane';     // short string format
let name: felt252 = 0x4a616e65; // byte format
let name: felt252 = 1247899237; // decimal format
```

Формально кажучи, будь-який цілий тип, менший за `felt252`, можна подати у форматі короткого рядка.

```rust
// all of the below are equal u8 values, they are just written using different formats!
let lowercase_a_in_ascii: u8 = 'a';  // short string format
let lowercase_a_in_ascii: u8 = 0x61; // byte format
let lowercase_a_in_ascii: u8 = 97;   // decimal format
```

Для рядків, довших за 31 символ, Cairo надає `ByteArray`, довжина якого необмежена.

```rust
let long_string: ByteArray = "this is a string which has more than 31 characters";
```

`ByteArray` можна зʼєднувати за допомогою оператора `+`:

```rust
"Jane" + " " + "Austen"
// => "Jane Austen"
```

Деякі спеціальні символи потрібно екранувати за допомогою зворотної скісної риски, наприклад `\t` для символу табуляції та `\n` для переходу на новий рядок.

```rust
"How is the weather today?\nIt's sunny"  
// =>
// How is the weather today?
// It's sunny
```

Можна навіть отримати доступ до окремих байтів усередині `ByteArray` за його індексом.

Але будьмо уважні: тип поверненого байта - це `u8`, а не `ByteArray`!

```rust
let hello: ByteArray = "Hello World!";
let exclamation_mark: u8 = hello[11];
// => 33
```

Основна бібліотека надає багато корисних методів і операторів для роботи з `ByteArray`.

Щоб дізнатися більше про методи `ByteArray`, перегляньте [документацію `ByteArrayTrait`][docs].

Ось кілька прикладів:

```rust
let name: felt252 = 'Jane';
let mut greeting: ByteArray = "Welcome ";

// append_word appends a single word of a given number of bytes to the end of the ByteArray 
greeting.append_word(name, 4);
// => "Welcome Jane"

// rev returns a ByteArray with the all characters reversed
let rev_greeting = greeting.rev();
// => "enaJ emocleW"
```

[docs]: https://docs.swmansion.com/scarb/corelib/core-byte_array-ByteArrayTrait.html
