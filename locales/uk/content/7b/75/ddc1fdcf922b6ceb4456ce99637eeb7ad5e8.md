# Кортежі

[Кортеж][tuple] - це скінченна впорядкована послідовність елементів, яку не можна змінювати.
Кортежі вимагають, щоб кожна позиція мала фіксований тип.
Це, своєю чергою, означає, що компілятор знає, який тип міститься в кожній позиції.
Типи, які використовуються в кортежі, можуть відрізнятися в кожній позиції, але мають бути відомі під час компіляції.

## Створення кортежу

Залежно від того, чи можна визначити типи значень кортежу під час компіляції, кортеж можна створити різними способами.
Якщо значення відомі під час компіляції, кортеж можна створити за допомогою синтаксису літерала кортежу, інакше їх потрібно явно оголосити.
Також важливо, щоб типи значень збігалися з типами, зазначеними в кортежі, а кількість значень відповідала кількості зазначених типів.
Ось приклад визначення через синтаксис літерала кортежу:

```crystal
tuple = {1, "foo", 'c'} # Tuple(Int32, String, Char)
```

Також є можливість створити кортеж за допомогою класу `Tuple`.

```crystal
tuple = Tuple(Int32, String, Char).new(1, "foo", 'c')
```

Або ж можна явно вказати тип змінної, якій присвоюється кортеж.

```crystal
tuple : Tuple(Int32, String, Char) = {1, "foo", 'c'}
```

Явне зазначення типу кортежу може бути корисним, оскільки це дозволяє вказати, що позиція має містити обʼєднаний тип.
Це означає, що позиція може містити кілька типів.

```crystal
tuple : Tuple(Int32 | String, String, Char) = {1, "foo", 'c'}
```

## Перетворення

### Створення кортежу з масиву

Кортеж можна створити з масиву за допомогою методу `from` класу `Tuple`.
Для цього потрібно зазначити тип кортежу.

```crystal
array = [1, "foo", 'c']
tuple = Tuple(Int32, String, Char).from(array)
```

### Перетворення на масив

Кортеж можна перетворити на масив за допомогою методу `to_a`.
Тип елементів отриманого масиву є обʼєднанням типів усіх полів кортежу.

```crystal
tuple = {1, "foo", 'c'}
array = tuple.to_a
array # => [1, "foo", 'c']
```

## Доступ до елементів

Як і масиви, кортежі індексуються з нуля, тобто перший елемент має індекс 0.
Однак, на відміну від масивів, тип кожного елемента фіксований і відомий під час компіляції, тому під час індексування кортежу тип елемента визначається його позицією.
Щоб отримати доступ до елемента кортежу, можна скористатися оператором `[]`.

```crystal
array = [1, "foo", 'c']
array[0]         # => 1
typeof(array[0]) # => Int32 | String | Char

tuple = {1, "foo", 'c'}
tuple[0]         # => 1
typeof(tuple[0]) # => Int32
```

Ще одна відмінність у доступі до елементів масивів: якщо індекс задано напряму, компілятор перевірить, чи перебуває індекс у межах кортежу.
Це означає, що ми отримаємо помилку часу компіляції, а не помилку під час виконання.

```crystal
tuple = {1, "foo", 'c'}
tuple[3]
# => Error: index out of bounds for Tuple(Int32, String, Char) (3 not in -3..2)
```

Однак, якщо індекс збережено в змінній, компілятор не зможе перевірити під час компіляції, чи перебуває індекс у межах кортежу, і натомість видасть помилку під час виконання.

## Підкортеж

Отримати підкортеж кортежу можна за допомогою оператора `[]` із діапазоном.
Повертається новий кортеж з елементами із зазначеного діапазону.
Діапазон потрібно задати під час компіляції, інакше компілятор не зможе визначити типи елементів підкортежу.
Це означає, що діапазон має бути літералом діапазону, а не присвоєним змінній.

```crystal
tuple = {1, "foo", 'c'}
subtuple = tuple[0..1] # Tuple(Int32, String)

i = 0..1
tuple[i]
# Error: Tuple#[](Range) can only be called with range literals known at compile-time
```

## Коли використовувати кортеж

Кортежі стають у пригоді, коли потрібно згрупувати фіксовану кількість значень, типи яких відомі під час компіляції.
Це тому, що кортежі займають менше памʼяті та працюють швидше за масиви завдяки своїй незмінності.
Ще один випадок використання - повернення кількох значень із методу.
Це особливо зручно, якщо значення мають різні типи, адже кожна позиція в кортежі може мати свій тип.

Кортежі не варто використовувати, коли потрібна структура даних, яка може збільшуватися чи зменшуватися в розмірі або яку часто потрібно змінювати.
