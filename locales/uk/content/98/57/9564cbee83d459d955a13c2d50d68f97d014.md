# Підказки

## 1. Визначте схвалення

- Власні типи можна визначити за допомогою синтаксису `pub type Name { Variant1 }`.

## 4. Визначте активність

- Власні типи, що містять дані, можна визначити за допомогою синтаксису `pub type Name { Variant1(SomeType) }`.

## 5. Оцініть активність

- Варіанти власних типів можна зіставляти зі зразками за допомогою виразів case.
- Якщо до зразка потрібно додати додаткову умову, можна скористатися сторожовою умовою та ключовим словом `if`.
