# Вказівки

У цій вправі ми напишемо трохи коду, який допоможе підготуватися до купівлі транспортного засобу.

На нас чекають три завдання: визначити, чи потрібне посвідчення водія, обрати один із двох транспортних засобів та оцінити прийнятну ціну вживаного транспортного засобу.

## 1. Визначте, чи знадобиться посвідчення водія

Деякі типи транспортних засобів потребують посвідчення водія для керування ними.
Припустімо, що посвідчення потребують лише типи `"car"` і `"truck"`, а всі решта можна керувати без посвідчення.

Реалізуйте функцію `needsLicense(kind)`, яка приймає тип транспортного засобу й повертає булеве значення (англ. Boolean), що вказує, чи потрібне посвідчення для цього типу транспортного засобу.

```kotlin
needsLicense("car")
// => true

needsLicense("bike")
// => false

needsLicense("truck")
// => true
```

## 2. Оберіть один із двох транспортних засобів для купівлі

Ми оцінюємо доступні варіанти транспортних засобів.
Нам вдалося звузити вибір до двох варіантів, але потрібна допомога, щоб ухвалити остаточне рішення.
Для цього реалізуйте функцію `chooseVehicle(option1, option2)`, яка приймає два транспортні засоби як аргументи й повертає рішення із варіантом, що стоїть першим у [лексикографічному порядку][lexicographical-order].

```kotlin
chooseVehicle("Wuling Hongguang", "Toyota Corolla")
// => "Toyota Corolla is clearly the better choice."

chooseVehicle("Volkswagen Beetle", "Volkswagen Golf")
// => "Volkswagen Beetle is clearly the better choice."
```

## 3. Обчисліть приблизну ціну вживаного транспортного засобу

Тепер, коли рішення ухвалено, ми хочемо переконатися, що в автосалоні нам запропонують справедливу ціну.
Оскільки нас цікавить купівля вживаного транспортного засобу, ціна залежить від його віку.
Для приблизної оцінки припустімо, що якщо транспортному засобу менше 3 років, він коштує 80% від початкової ціни, яку мав, коли був новим.
Якщо йому щонайменше 10 років, він коштує 50%.
Якщо транспортному засобу від 3 до 10 років, він коштує 70% від початкової ціни.

Реалізуйте функцію `calculateResellPrice(originalPrice, age)`, яка застосовує цю логіку за допомогою `if`, `else if` та `else` (існують й інші способи, якщо захочеться потренуватися).
Вона приймає початкову ціну й вік транспортного засобу як аргументи та повертає орієнтовну ціну в автосалоні.

```kotlin
calculateResellPrice(1000, 1)
// => 800

calculateResellPrice(1000, 5)
// => 700

calculateResellPrice(1000, 15)
// => 500
```

[lexicographical-order]: https://en.wikipedia.org/wiki/Lexicographic_order
