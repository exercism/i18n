## 1. Перевірка зʼєднання сенсора (`connection_check`)

Наше перше завдання - переконатися, що сенсор Людей-стовпів підключено правильно.
Ми не можемо допустити хибних тривог через відʼєднані сенсори.
Ми напишемо функцію `connection_check`, яка перевіряє, чи дійсний вказівник сенсора, порівнюючи його з `nullptr`.

- Визначте функцію, яка приймає вказівник на _struct_ `pillar_men_sensor`.
- Функція має повертати `true`, якщо вказівник сенсора не є null, і `false` в іншому разі.

```cpp
pillar_men_sensor* sensor{nullptr};
bool isConnected = connection_check(sensor);
// isConnected => false
```

## 2. Підрахунок активності сенсорів (`activity_counter`)

Люди-стовпи чатують у тінях, і нам потрібно знати, чи зафіксували сенсори якусь активність.
Ми напишемо функцію `activity_counter`, яка приймає масив сенсорів і місткість, що вказує на кількість сенсорів у масиві.

- Визначте функцію, яка приймає вказівник на перший елемент масиву та місткість масиву.
- Використайте арифметику вказівників, щоб пройти циклом по масиву сенсорів і накопичити показання активності.
- Поверніть накопичену активність.

```cpp
pillar_men_sensor sensor_array[3] = {{0}, {101}, {22}};
int totalActivity = activity_counter(sensor_array, 3);
// totalActivity => 123
```

## 3. Керування тривогою (`alarm_control`)

Не кожен сенсор має спричиняти тривогу: це повинно відбуватися лише за справжньої небезпеки.
Функція `alarm_control` гарантує, що сенсор спричиняє тривогу, лише якщо рівень його активності більший за 0.
Ця функція також має перевіряти сенсори на null, щоб запобігти збоям системи.

- Визначте функцію, яка приймає вказівник на `pillar_men_sensor`.
- Спочатку функція має перевірити, чи не є сенсор `nullptr`. Якщо сенсор дорівнює `nullptr`, поверніть `false`.
- Якщо сенсор дійсний і його активність більша за 0, поверніть `true`; інакше поверніть `false`.

```cpp
pillar_men_sensor db{9008, "songokunoie", {7, 7, 7}};
bool alarm = alarm_control(&db);
// alarm => true
```

## 4. Перевірка даних на аномалії за допомогою функції `uv_alarm`

У цьому завданні ми реалізуємо функцію `uv_alarm`, щоб визначити, чи потрібно запускати тривогу, виходячи з рівнів ультрафіолетового опромінення та активності сенсора.
Функція `uv_alarm` має використовувати надану функцію `uv_light_heuristic`, яка працює з вектором даних і повертає значення на основі певних порогів.
Це макетна версія складного коду, який працюватиме у виробництві, тож не змінюйте інтерфейс.

Визначте функцію `uv_alarm` у просторі імен `speedywagon`. Вона має:

- Приймати вказівник на _struct_ `pillar_men_sensor` як свій параметр.
- Повертати `false`, якщо вказівник сенсора є null.
- Викликати функцію `uv_light_heuristic`, передаючи адресу масиву `data` сенсора.
- Повертати `true`, якщо значення, повернуте `uv_light_heuristic`, більше за рівень `sensor->activity`, інакше повертати `false`.
