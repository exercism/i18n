# Додаток до інструкцій

## Слова

Визначте кортеж `custom-set` та оголосіть його екземпляром міксину `set` за допомогою `INSTANCE: custom-set set`.

- `<custom-set> ( -- set )` - створює порожню множину.
- `>custom-set ( seq -- set )` - будує множину з послідовності, мовчки відкидаючи дублікати.

Потім надайте методи `M:` (з `sets`) для `members`, `in?`, `adjoin` та `set-like` у `custom-set`. Коли оголошення `INSTANCE:` і ці чотири методи на місці, `null?`, `union`, `intersect`, `diff`, `subset?`, `set=` та `intersects?` зі словника `sets` працюють із нашою множиною через типові реалізації протоколу - тести викликають ці слова напряму.

`adjoin ( elt set -- )` змінює свій аргумент: він додає `elt` до `set` на місці, якщо його там ще немає.
