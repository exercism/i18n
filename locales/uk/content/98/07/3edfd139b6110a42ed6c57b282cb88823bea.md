# Вступ

Хеші - це тип даних у Perl, які містять невпорядковану колекцію ключів-рядків тексту (англ. string), спарених зі скалярними значеннями.

Хеш-змінну зазвичай заповнюємо, присвоюючи їй масив, наприклад: `my %scores = (Alice => 10, Bob => 15, Charlie => 20);`.

Елементи масивів зазвичай розділяють комами, але ми часто бачимо так звану «жирну кому» `=>` для розділення ключів і значень у масиві.
Її поведінка майже ідентична до коми, але вона має додаткову перевагу: інтерпретує елемент з лівого боку як рядок тексту.

Хеші можна заповнювати, присвоюючи значення окремим ключам, наприклад: `$scores{Alice} = 10;`.

До значень хеша можна отримати доступ, вказавши ключі через індекс, наприклад: `$scores{Bob} # 15`.

Ключі в хеші унікальні.
Якщо ключ вказано кілька разів, буде збережено лише останнє вказане значення.

## Функції

Функції для роботи з хешами включають [keys][keys] та [values][values] для отримання відповідних частин хеша у вигляді масиву.
Масиви, які повертають функції [keys][keys] та [values][values], можуть бути корисними для функцій роботи з масивами, таких як [grep][grep], [map][map] і [sort][sort], а також для циклів [for][for].

Інші функції для роботи з хешами включають [exists][exists] для перевірки, чи існує ключ у хеші (навіть якщо його значення `undef`), та [delete][delete] для видалення ключа з хеша.

## Варіативність сигілів

Коли ми отримуємо значення хеша, заданий сигіл визначає результат.
Індекс `{}` у кінці імені змінної повідомляє Perl, що ми звертаємося до хеша з таким іменем.

```perl
my %names = (Alice => 10, Bob => 15, Charlie => 20);

$names{Alice}; # 10            <- A scalar
@names{Alice}; # (10)          <- A slice (with only one key, this probably isn't what you want. There will be a warning.)
%names{Alice}; # ('Alice', 10) <- A key/index + value slice

$names{'Bob', 'Charlie'}; #                            <- An error (disabled syntax for an ancient feature.)
@names{'Bob', 'Charlie'}; # (15, 20)                   <- A slice
%names{'Bob', 'Charlie'}; # ('Bob', 15, 'Charlie', 20) <- A key/index + value slice
```

Хоча це дозволено, заради читабельності рекомендується не давати різним типам змінних однакові імена.
