# Додаток до інструкцій

## Слова

`classify ( n -- str )` повертає один із рядків тексту (англ. string) `"perfect"`,
`"abundant"` або `"deficient"`.

## Помилки

Коли вхідні дані дорівнюють нулю або є відʼємними, киньте рядок

```
"Classification is only possible for positive integers."
```

(дослівно, разом із крапкою в кінці).
