# Конструктори рядків

`STR` ніколи не змінюється. Тож `+` не може нічого до нього додати: йому доводиться створювати цілком новий рядок тексту (англ. string) з вмістом обох.

Один раз це прийнятно. А в циклі - ні:

```sather
   -- don't
   script ::= "";
   loop
      script := script + lines.elt!;
   end;
```

Кожен оберт копіює все, що вже накопичено, у новий рядок тексту і викидає старий. Десять рядків - це десять копій, кожна довша за попередню. Сотня рядків - це сотня копій. Обсяг роботи зростає як *квадрат* кількості рядків, і цикл, який має нешкідливий вигляд, стає повільною частиною програми.

## FSTR

`FSTR` - це рядок тексту, який *може* змінюватися, тобто **конструктор рядків**. Додавання до нього зазвичай просто пише в уже наявне місце, тож цикл на сотню рядків виконує приблизно стільки роботи, скільки потрібно на сотню рядків, а не сотню копіювань.

```sather
   script ::= #FSTR;
   loop
      script := script + lines.elt!;
   end;
   return script.str;
```

Три моменти, на які варто звернути увагу.

**`#FSTR` створює порожній конструктор.** `#FSTR(100)` створює такий конструктор, де вже виділено місце на сотню символів; це варто робити, коли розмір відомий.

**Результат потрібно присвоїти назад.** `script := script + ...`, а не просто `script + ...`. Зазвичай результатом є той самий конструктор, який ми взяли, але коли в ньому закінчується місце, це вже більший, новий конструктор. Якщо ж відкинути результат, ми писатимемо в старий.

**`.str` у кінці.** Функція, яка обіцяє `: STR`, має повернути `STR`, а `.str` створює його з конструктора.

## Що можна додавати

`+` для `FSTR` приймає рядок тексту, символ, ціле число або булеве значення (англ. Boolean), тож зазвичай не потрібно нічого перетворювати заздалегідь:

```sather
   line ::= #FSTR;
   line := line + 1 + ". " + "Enter" + '!';   -- "1. Enter!"
```

## Нові рядки

`"\n"` усередині рядка тексту - це новий рядок: один символ, записаний двома.

```sather
   script := script + "Enter" + "\n" + "Exit";
```
