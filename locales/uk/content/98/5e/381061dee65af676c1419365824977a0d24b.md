# Вказівки

У цій вправі ми будемо працювати над планувальником прийомів для салону краси в Нью-Йорку, який відкрився 15 вересня 2012 року.

## 1. Розібрати дату прийому

Реалізуйте метод `AppointmentScheduler.schedule()`, щоб розібрати текстове представлення дати прийому у відповідний `LocalDateTime`:

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.schedule("7/25/2019 13:45:00");
// => LocalDateTime.of(2019, 7, 25, 13, 45, 0)
```

## 2. Перевірити, чи прийом уже минув

Реалізуйте метод `AppointmentScheduler.hasPassed()`, який приймає дату прийому й перевіряє, чи прийом відбувся колись у минулому:

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.hasPassed(LocalDateTime.of(1999, 12, 31, 9, 0, 0));
// => true
```

## 3. Перевірити, чи прийом після обіду

Реалізуйте метод `AppointmentScheduler.isAfternoonAppointment()`, який приймає дату прийому й перевіряє, чи прийом після обіду (`>= 12:00 and < 18:00`):

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.isAfternoonAppointment(LocalDateTime.of(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. Описати час і дату прийому

Реалізуйте метод `AppointmentScheduler.getDescription()`, який приймає дату прийому й повертає опис цієї дати й часу:

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.getDescription(LocalDateTime.of(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on Friday, March 29, 2019, at 3:00 PM."
```

## 5. Повернути дату річниці

Реалізуйте метод `AppointmentScheduler.getAnniversaryDate()`, який повертає дату річниці цього року, тобто 15 вересня:

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.getAnniversaryDate()
// => LocalDate.of(<current year>, 9, 15)
```
