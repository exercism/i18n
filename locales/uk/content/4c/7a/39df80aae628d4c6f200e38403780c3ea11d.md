# Інструкції

Ми щойно почали працювати на рецепції скеледрому.
Відвідувачі купують абонементи на певну кількість місяців і щоразу відмічаються на вході та виході.
Керівник попросив нас написати допоміжний метод, який відповідає на найчастіші запитання відвідувачів.

## 1. Визначте, коли завершується абонемент

Абонемент, що починається з певної дати, завершується того самого числа через указану кількість місяців.
Якщо такого числа в кінцевому місяці немає, абонемент завершується в останній день цього місяця.

Реалізуйте метод `FrontDesk.membershipEnd()`, який приймає дату початку абонемента та кількість місяців і повертає дату, коли абонемент завершується:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.membershipEnd(LocalDate.of(2024, 3, 10), 1);
// => LocalDate.of(2024, 4, 10)
frontDesk.membershipEnd(LocalDate.of(2025, 1, 31), 1);
// => LocalDate.of(2025, 2, 28)
```

## 2. Покажіть, скільки триває абонемент

На картці абонемента спортзал зазначає, скільки триває абонемент, у роках, місяцях і днях.

Реалізуйте метод `FrontDesk.membershipLength()`, який приймає дату початку та дату завершення абонемента і повертає тривалість абонемента як `Period`:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.membershipLength(LocalDate.of(2023, 3, 10), LocalDate.of(2024, 5, 25));
// => Period.of(1, 2, 15)
```

## 3. Порахуйте, скільки днів залишилося до кінця абонемента

Відвідувачі часто питають, скільки днів у них залишилося до завершення абонемента.

Реалізуйте метод `FrontDesk.daysLeft()`, який приймає сьогоднішню дату та дату завершення абонемента і повертає загальну кількість днів від сьогодні до дати завершення.
Якщо дата завершення збігається з сьогоднішньою або вже минула, днів не залишилося, тож метод повертає `0`:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.daysLeft(LocalDate.of(2024, 1, 15), LocalDate.of(2024, 3, 20));
// => 65
frontDesk.daysLeft(LocalDate.of(2024, 4, 2), LocalDate.of(2024, 3, 20));
// => 0
```

## 4. Виміряйте тривалість відвідування

Спортзал працює цілодобово, а турнікет записує дату і час, коли відвідувач відмічається на вході та виході.

Реалізуйте метод `FrontDesk.visitDuration()`, який приймає дату і час відмітки на вході та виході під час відвідування і повертає, скільки тривало відвідування, як `Duration`:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.visitDuration(LocalDateTime.of(2024, 3, 10, 23, 30), LocalDateTime.of(2024, 3, 11, 1, 15));
// => Duration.ofMinutes(105)
```

## 5. Надрукуйте тривалість відвідування в чеку

У чеку тривалість відвідування показано в годинах і хвилинах, наприклад `1h 35m`.
Хвилини завжди записують двома цифрами, секунди відкидають, а кількість годин не обмежена однією добою.

Реалізуйте метод `FrontDesk.formatVisit()`, який приймає тривалість відвідування і повертає її в такому форматі:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.formatVisit(Duration.ofMinutes(95));
// => "1h 35m"
frontDesk.formatVisit(Duration.ofHours(2).plusMinutes(5));
// => "2h 05m"
frontDesk.formatVisit(Duration.ofHours(26).plusMinutes(10));
// => "26h 10m"
```
