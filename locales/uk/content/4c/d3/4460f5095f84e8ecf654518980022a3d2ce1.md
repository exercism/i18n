# Вступ

Багатьом програмам потрібні (псевдо)випадкові значення, щоб імітувати події реального світу.

Ось кілька поширених і знайомих прикладів:

- Підкидання монети: випадкове значення з ('H', 'T').
- Кидок кубика: випадкове ціле число від 1 до 6.
- Перемішування колоди карт: випадковий порядок масиву карт.
- Створення дерев і кущів у тривимірній графічній симуляції.

Згенерувати справді випадкові значення за допомогою компʼютера - напрочуд складна технічна задача, тому й існують також «псевдовипадкові» генератори.

## Генерування випадкових чисел

У JavaScript ми можемо генерувати псевдовипадкові числа за допомогою функції [`Math.random()`][Math.random].
Вона поверне псевдовипадкове число з плаваючою комою від 0 (включно) до 1 (не включно).

Щоб отримати випадкове число від _min_ (включно) до _max_ (не включно), можна використати функцію приблизно такого вигляду:

```javascript
function getRandomInRange(min, max) {
  return min + Math.random() * (max - min);
}
getRandomInRange(4, 10);
// => 5.72
```

## Генерування випадкових цілих чисел

Щоб згенерувати випадкове ціле число, можна скористатися `Math.floor()` або `Math.ceil()`, щоб перетворити згенероване випадкове число на ціле.
