# Не використовуйте вкладені умовні конструкції

Спробуйте переписати умовні конструкції, щоб уникнути глибокої вкладеності, адже вона може призвести до коду, який важче читати. Розгляньмо такі два фрагменти коду:

```csharp
void PrintName(Person p)
{
    if (p != null)
    {
        if (p.Name != null)
        {
            if (p.Age >= 21)
            {
                Console.WriteLine(p.Name);
            }
        }
    }
}
```

Порівняйте це з наступним кодом:

```csharp
void PrintName(Person p)
{
  if (p == null || p.Name == null || p.Age < 21)
  {
      return;
  }

  Console.WriteLine(p.Name);
}
```

Другий приклад має цілком конкретну структуру: усі шляхи, що працюють з помилками, обробляються у блоках з відступом, тоді як «щасливий шлях» завжди вирівняно найлівіше. Завдяки цьому код дуже легко читати, адже одразу видно, який шлях у коді є найпоширенішим і безпомилковим.
