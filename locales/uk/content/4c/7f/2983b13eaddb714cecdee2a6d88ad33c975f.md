# Використати один return

Це рішення використовує кілька інструкцій return, але його можна записати так, щоб був лише один return.
Розгляньте використання [тернарного оператора](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/op2.html), щоб обробити випадок, коли на вхід надходить `null`.
