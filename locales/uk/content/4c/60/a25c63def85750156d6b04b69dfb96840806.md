# Інструкції для SQLite

- Стовпець **matrix** містить вхідні дані: закодований у JSON масив масивів цілих чисел.
- Стовпці **result** повинні містити вихідні дані: масив сідлових точок.
  Вихідні дані мають бути закодованим у JSON масивом обʼєктів, кожен обʼєкт має два ключі: row і column.
  Наприклад, `[{"row": 2, "column": 1}]`.
