# Докладніше

[Cons][hyper-conses] - базовий тип даних у Common Lisp. Вони складаються з голови та хвоста (які з [історичних причин][history] називають `car` і `cdr`).
Немає жодних обмежень на типи даних голови та хвоста cons.

Cons створюють за допомогою функції [`cons`][hyper-cons], яка приймає два обʼєкти й обчислюється в cons (який іноді також називають «cons cell»).

До частин cons можна дістатися за допомогою функцій [`car`][hyper-car] і [`cdr`][hyper-cdr].

## Довідка

```lisp
;; Testing for atoms
(atom 'foo)              ; => T
(atom '(bar baz))        ; => NIL

;; Testing for cons
(consp 'foo)             ; => NIL
(consp '(bar baz))       ; => T

;; First item of a cons
(car '(one two three))   ; => ONE
(first '(one two three)) ; => ONE

;; Rest of a cons
(cdr '(one two three))   ; => (TWO THREE)
(rest '(one two three))  ; => (TWO THREE)
```
