# Встановлення

Дистрибутив Racket можна завантажити з https://download.racket-lang.org

Інсталятори доступні для

* Windows
* Linux
* macOS

Радимо звернутися до сторінки Racket [Getting Started](http://docs.racket-lang.org/getting-started/) по навчальні матеріали.

Посібник [Racket Guide](https://docs.racket-lang.org/guide/intro.html) знайомить із тим, як взаємодіяти з Racket.

Про роботу в середовищі розробки DrRacket розповідає сторінка [DrRacket: The Racket Programming Environment](https://docs.racket-lang.org/drracket/index.html).

Про інструменти командного рядка Racket і про використання інших редакторів розповідає сторінка [Command-Line Tools and Your Editor of Choice](https://docs.racket-lang.org/guide/other-editors.html).


## Про інсталятор для Linux

Збірка для Linux досить універсальна, тож має працювати в більшості дистрибутивів, зокрема й у доволі старих.

Після завантаження файлу інсталятора запустіть його командою
```
sh racket-8.10-x86_64-linux-cs.sh
```

Може знадобитися додати `sudo` на початок команди, щоб встановити в місце, яке потребує прав адміністратора.

**Застереження: Racket також може бути доступний у менеджері пакетів дистрибутива, хоча він може бути старішим за найновішу версію Racket.**
Хоча це можна зробити й пізніше, для того, хто вчиться, досвід буде значно кращим, якщо триматися поточної версії, доступної на https://download.racket-lang.org


## Про інсталятор для macOS

Якщо компʼютер має процесори серії M1 або M2, перед завантаженням виберіть **Apple Silicon** у випадному меню вибору платформи.
