# Вступ

*Quotation* (код у квадратних дужках `[ ]`) сам по собі є значенням у мові Factor, так само як число чи рядок тексту (англ. string). Його можна зберегти у змінній, покласти в масив, передати іншому слову і *викликати* пізніше.

## `call`

`call` (у [`kernel`][kernel]) виконує quotation:

```factor
3 4 [ + ] call .
! => 7
```

Коли ми викликаємо quotation у контексті, де Factor не може вивести його стековий ефект, потрібно явно оголосити цей ефект:

```
call( stack-effect ) ! e.g. call( a b -- c )
```

```factor
: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .
! => 2
```

Це компілює перевірку під час виконання, яка засвідчує, що quotation справді має оголошений ефект.

## Quotation у послідовностях

Оскільки quotation - це значення, масив може вміщати як числа, так і quotation:

```factor
{ 3 4 [ + ] }
```

Завдяки цьому «програма» стає звичайною послідовністю, а `each` - природним способом її виконати:

```
each ( seq quot -- )
```

```factor
{ [ 1 + ] [ 2 * ] } 5 swap [ call( x -- y ) ] each .
! 5 -> 6 -> 12
```

## Зрізання кінця послідовності

`head*` повертає все, крім останніх `n` елементів; `last2` повертає останні два:

```
head* ( seq n -- headseq )
last2 ( seq -- penultimate last )
```

```factor
{ 1 2 3 4 5 } 2 head* .    ! => { 1 2 3 }
{ 1 2 3 4 5 } last2 .s
! => 4
! => 5
```

Разом із `suffix` це все, що потрібно, щоб написати стекову операцію «взяти два верхні елементи, покласти один результат».
