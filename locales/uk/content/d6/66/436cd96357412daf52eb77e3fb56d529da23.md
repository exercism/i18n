# Вступ

Модуль `Time` використовують, щоб показувати дати й час у зручному для людини вигляді.
Хоча технічно час можна обробляти й самим `Time`, існують пакунки спільноти Elm, які значно краще підходять для цього, як-от [`justinmimbs/date`][date] чи [`CoderDennis/elm-time-format`][elm-time-format].

## Posix

Час подають за допомогою непрозорого типу `Posix`, який обгортає час Unix-епохи, тобто кількість мілісекунд, що минули від півночі UTC 1 січня 1970 року.
`Posix` задає однозначне значення, яке не змінюється залежно від часового поясу, тож це вдалий вибір для зберігання часу.
У застосунку Elm значення `Posix` зазвичай надходять із зовнішніх джерел, як-от браузер.

Перетворити `Posix` на число мілісекунд і навпаки можна такими функціями:

```elm
posixToMillis : Posix -> Int
millisToPosix : Int -> Posix
```

## Часові пояси

У повсякденному житті ми зазвичай не читаємо `Posix`, а надаємо перевагу місцевому часу, який залежить від нашого розташування на Землі та місцевих правил переходу на літній час.
В Elm цю інформацію закодовано в непрозорому типі `Zone`, який зазвичай надає браузер.

Є особливий `Zone`, доступний завжди:

```elm
utc : Zone
```

## Час у зручному для людини вигляді

Маючи `Posix` і `Zone`, ми маємо достатньо інформації, щоб показати місцевий час із будь-яким рівнем деталізації.
Ось список функцій, які для цього можна використати:

```elm
toYear : Zone -> Posix -> Int
toMonth : Zone -> Posix -> Month
toDay : Zone -> Posix -> Int
toWeekday : Zone -> Posix -> Weekday
toHour : Zone -> Posix -> Int
toMinute : Zone -> Posix -> Int
toSecond : Zone -> Posix -> Int
toMillis : Zone -> Posix -> Int
```

Ми, напевно, вже помітили ще два власні типи з `Time`:

```elm
type Month = Jan | Feb | Mar | Apr | May | Jun | Jul | Aug | Sep | Oct | Nov | Dec
type Weekday = Mon | Tue | Wed | Thu | Fri | Sat | Sun
```

Перетворити ці власні типи на зрозумілі людині значення вже має сам користувач.
