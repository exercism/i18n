# Про анонімні функції та замикання

PHP дозволяє оголошувати функції всередині інших функцій. Такі функції не обовʼязково називати: їх можна присвоїти змінним або навіть одразу передати в іншу функцію, яка потребує параметра-функції.

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, function($num) {
        return $num % 2 === 1;
    });
}
```

Функція, оголошена й передана в `array_filter` вище, є анонімною функцією. `array_filter` використовує її, щоб вирішити, чи потрапить задане значення з масиву до результату `array_filter`. Якщо функція повертає для значення `true`, то це значення потрапить до результівного масиву.

Анонімні функції також дають змогу зсередини функції звертатися до змінних, які перебувають поза нею в області видимості. Кажуть, що область видимості функції «замикається» над змінною, яку використовує функція, звідси й назва «замикання». У деяких мовах усі змінні з області видимості автоматично доступні всередині замикання. У PHP `$this`, який указує на поточний обʼєкт, автоматично доступний усередині замикання. Усі інші змінні потрібно явно вказати за допомогою ключового слова `use`.

```php
function makeAdderFunction(int $number) {
    return function(int $x) use($number) {
        return $x + $number;
    }
}

$add5 = makeAdderFunction(5);
echo $add5(4); // echos 9
```

У функції `makeAdderFunction` вище передане значення `$number` «замикається» всередині оголошеної в ній анонімної функції, яку потім повертають. І коли цю функцію виконують, вона знає значення `$number`, яке було передано. Якщо викликати цю функцію ще раз з іншим числом, повернеться зовсім інша функція. Це не змінить ні значень, ні функціональності, які повертає перший виклик функції.
Якщо потрібно замкнути більш ніж одну змінну, їх можна перелічити в ключовому слові `use`, розділивши комами.

У PHP також є коротший синтаксис функцій, який називають `arrow functions`. Вони мають бути досить простими. Основна їхня форма така:

```php
fn(arguments) => expression
```

У цьому стилі функцій не потрібно використовувати `use`. Вона автоматично замикається над значеннями з батьківської області видимості й захоплює їх. Вираз у таких стрілкових функціях повертається автоматично, без потреби використовувати ключове слово `return`. Завдяки цьому функцію `onlyOdds` вище можна переписати так:

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, fn($n) => $n % 2 == 1);
}
```

Функцію `makeAdderFunction` вище можна переписати так:

```php
function makeAdderFunction(int $number) {
    return fn(int $x) => $x + $number;
}
```

**Примітка:** Якщо функцію не можна записати як вираз, то коротший синтаксис стрілкових функцій використати не вдасться.

Змінні передаються в анонімні функції та замикання і використовуються в них за значенням. Це означає, що зміна значення змінної всередині функції не вплине на значення цієї змінної поза функцією. Якщо потрібно, щоб значення змінилося, його можна передати за посиланням.

```php
function positiveAverage(array $numbers): float
{
    $total = 0;
    $count = 0;
    return array_walk(
      $numbers,
      function($num) use (&$count, &$total) {
          $total += abs($num);
          $count++;
      }
    );
    return $total / $count;
}
```

У прикладі вище `array_walk` перебирає кожен елемент масиву, передаючи кожне значення у функцію, оголошену у виклику. Вона накопичує суму в `$total`, де кожне додане значення - абсолютна величина числа. Вона також рахує, скільки було чисел. Обидві змінні використовуються в замиканні за посиланням, на що вказує `&` перед кожною змінною в частині `use`. Це означає, що зміни, які відбуваються зі змінними, збережуться й після завершення `array_walk`, тож функція може повернути середнє арифметичне абсолютних значень чисел у масиві.

Анонімні функції та замикання дають зручний спосіб оголосити функцію, яка може знадобитися лише в одному контексті, або функцію, що повертає динамічну функцію на основі набору параметрів, відомих в інший момент, ніж той, коли функцію справді використовують.
