# Вступ

[`function`][function] - це спосіб відокремити код в окрему частину, щоб його можна було викликати за назвою з одного або кількох місць програми.
Функції використовують для виконання конкретних і повторюваних завдань.

Формальніше: функція - це будь-який обʼєкт Python, до якого можна застосувати операцію [`function call`][calls].
Функція може [`return`][return] одне або кілька значень у результаті певних операцій або ж використовуватися для одного чи кількох [`side effects`][side effects].
Якщо функція не вказує повернене значення, вона все одно поверне `None`.

Ось приклад функції з побічним ефектом:

```python
>>> def hello():
...     print("Hello")
...
>>> hello()
Hello

```

У прикладі вище ключове слово [`def`][def] позначає початок визначення функції.
`hello` - назва функції.
Порожні дужки означають, що до функції не передають жодних значень.
Тіло функції складається з єдиної інструкції `print("Hello")`.
`print` - також функція.
`"Hello"` у дужках функції `print` називають [`argument`][arguments].
Функція `print` використовує цей аргумент, щоб знати, що друкувати.
Звернімо увагу, що тіло функції записано з відступом.
Відступ важливий, бо Python покладається на нього, щоб визначити, де закінчується цей блок коду.
Тіло функції закінчується або в кінці програми, або безпосередньо перед наступним рядком коду, який _не_ має відступу.
Оскільки `hello()` не вказує значення `return`, вона виконує свій побічний ефект, тобто викликає `print()`, а потім повертає `None`.
І нарешті, ми викликаємо функцію за її назвою та дужками, а це сигналізує інтерпретатору Python, що цю назву можна _викликати_.

Ось приклад функції з поверненим значенням:

```python
>>> def hello():
...     return "Hello"
... 
print(hello())
Hello

```

Тіло цієї функції змінили: замість _виклику_ `print` воно тепер _повертає_ `string` «Hello».
Зрештою, код усе одно друкує `"Hello"`, але побічний ефект відбувається у _коді, що викликає_, а не у функції `hello`.
Якщо забути дужки під час виклику функції `hello` (наприклад, `print(hello)`), то `print` виведе щось на кшталт

```
<function hello at 0x0000026E18E93E20>
```

Важливо, що навіть якщо функція не приймає жодного аргументу (_тобто не має параметрів_), щоб правильно її _викликати_, потрібно використати порожні дужки.
Це відрізняється від такої мови, як Ruby, у якій для виклику функції без аргументів порожні дужки не потрібні.

Функція може визначати нуль або більше [`parameters`][parameters]. Параметр визначає, які аргументи приймає функція.

Ось приклад функції, яка приймає аргумент:

```python
>>> def hello(name):
...     return f"Hello, {name}"
... 
>>> print(hello("Bob"))
Hello, Bob

```

Параметр визначено як `name`.
`"Bob"` - це аргумент, який програма передає функції `hello`.
Функція _повертає_ `string` «Hello, Bob».

А що, якщо викликати `hello`, не передавши аргумент?
Програма видає помилку:

```python
print(hello())
Traceback (most recent call last):

  Input In in <line: 1>
    print(hello())

TypeError: hello() missing 1 required positional argument: 'name'
```

Якщо ми не хочемо, щоб програма видавала помилку без аргументу (_але хочемо дозволити коду, що викликає, його не надавати_), ми можемо визначити [типовий аргумент][default arguments].
Типовий аргумент визначає, яке значення використати, якщо аргумент відсутній під час виклику функції.

Ось приклад функції з типовим аргументом:

```python
>>> def hello(name="you"):
...     return f"Hello, {name}"
... 
>>> print(hello())
Hello, you

```

Параметру `name` задано типовий аргумент `"you"`, тож якщо не передати аргумент `name`, програма виведе `Hello, you`.

Докладніше про аргументи функцій читайте в концепції [аргументи функцій][function arguments].
