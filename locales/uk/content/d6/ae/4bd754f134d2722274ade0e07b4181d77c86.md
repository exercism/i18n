# Докладніше

Примітивний тип `char` у Java це 16-бітове представлення одного символу Unicode.

~~~~exercism/note
Тип `char` ґрунтується на [початковій специфікації Unicode][unicode-specification], яка використовувала 16 бітів для представлення символів.
Цього достатньо, щоб охопити більшість поширених літер і символи в діапазоні від 0x0000 до 0xFFFF.
Відтоді специфікація розширила діапазон можливих символів до 0x01FFFF.

[unicode-specification]: https://www.unicode.org/versions/Unicode1.0.0/
~~~~

З кількох `char` може скластися рядок тексту (англ. string), як-от `"word"`, або ж кожен `char` можна обробити окремо.
Літерал `char` беруть в одинарні лапки (наприклад, `'A'`).

```java
char lowerA = 'a';
char upperB = 'B';
```

## Як отримати `char` з `String`

Метод `String.toCharArray` повертає символи рядка тексту як масив.
Як згадувалося в [масивах][concept-arrays], для перебору масиву можна використати цикл `for`.

```java
String text = "Hello";
char[] asArray = text.toCharArray();

for (char ch: asArray) {
    System.out.println(ch);
}

// Outputs:
// H
// e
// l
// l
// o
```

## Клас [Character][docs-character]

У стандартній бібліотеці є багато вбудованих методів для перевірки й обробки `char`.
Це статичні методи класу [`java.lang.Character`][docs-character].
Ось кілька прикладів:

```java
Character.isWhitespace(' ');    // true
Character.isWhitespace('#');    // false

Character.isLetter('a');        // true
Character.isLetter('3');        // false

Character.isDigit('6');         // true
Character.isDigit('?');         // false
```

~~~~exercism/note
Деякі методи класу Character мають перевантаження, тож можуть приймати або `char`, або `int`.
Наприклад, у `isDigit` є перевантаження, яке приймає [`char`][is-digit-char], та інше, яке приймає [`int`][is-digit-int].
Як зазначалося раніше, тип `char` може представляти лише символи в діапазоні від 0x0000 до 0xFFFF.
Натомість `int` може представляти всі символи, звідси й перевантаження для `int`.

[is-digit-char]: https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/Character.html#isDigit(char)
[is-digit-int]: https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/Character.html#isDigit(int)
~~~~

## Додавання `char` до `String`

Оператор `+` можна використати, щоб додати `char` до `String`.

```java
'a' + " banana"     // => "a banana"
"banana " + 'a'     // => "banana a"
```

~~~~exercism/caution
Звернімо увагу: _не_ використовуймо `+`, щоб зʼєднати два `char` в один `String`!
Додавання двох `char` у такий спосіб дає `int`, а _не_ `String`!
Наприклад:

```java
'b' + 'c';
// => 197 (not the String "bc")
```

Це тому, що Java розширює `char` до `int` (див. [4.2 Primitive Types and Values ][jls-primitives] у [Java Language Specification][jls-main]).

[jls-main]: https://docs.oracle.com/javase/specs/jls/se21/html/
[jls-primitives]: https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.2
~~~~

Однак, коли символів треба додати багато, ефективніше скористатися [`StringBuilder`][docs-stringBuilder]:

```java
StringBuilder builder = new StringBuilder();
builder.append('a');
builder.append('b');
builder.append('c');

String builtString = builder.toString();
// => abc
```
