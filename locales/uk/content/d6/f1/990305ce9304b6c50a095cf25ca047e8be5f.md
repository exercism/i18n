# Доповнення до інструкцій

## Додаткові інструкції

Нам нададуть таблицю з назвою «isogram».
Перший стовпець, «phrase», містить текст.
Визначте, чи є фраза ізограмою.
Оновіть другий стовпець, «is_isogram», цілим числом:

* 1, якщо фраза є ізограмою,
* 0, якщо ні.

~~~~exercism/note
Операції порівняння SQLite повертають булеві значення (англ. Boolean) як числа 0/1

```sh
$ sqlite3
sqlite> .mode table
sqlite> SELECT 1 < 2 AS "true", 1 > 2 AS "false";
+------+-------+
| true | false |
+------+-------+
| 1    | 0     |
+------+-------+
```
