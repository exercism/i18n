# Додаток до інструкцій

## Слова

Визначте кортеж `linked-list-node`.

Визначте кортеж `linked-list` і надайте метод `M: linked-list length`
(з `sequences`), щоб тести могли викликати `length` безпосередньо
для вашого списку.

- `<linked-list> ( -- linked-list )` - створити порожній список.
- `>linked-list ( seq -- linked-list )` - додати кожен елемент із
  `seq` до нового списку, зберігаючи їхній порядок.
- `linked-list>array ( linked-list -- array )` - повернути
  значення, починаючи з верхівки списку.
- `list-push ( linked-list value -- linked-list )` - покласти значення
  на верхівку.
- `list-pop ( linked-list -- linked-list value )` - вилучити й
  повернути верхнє значення.
- `list-peek ( linked-list -- value )` - повернути верхнє значення,
  не вилучаючи його.
- `list-reverse ( linked-list -- linked-list )` - повернути список
  з елементами у зворотному порядку.

Викиньте клас помилки `list-empty` з `list-pop` і `list-peek`,
коли список порожній.
