# Тести

Перш ніж запускати тести, переконаймося, що папку із завданням налаштовано правильно, виконавши кроки встановлення, а саме `corepack yarn install` і налаштування Editor SDK.

Запустімо тести так:

```bash
$ corepack yarn test
```

Переконаймося, що наш код відповідає найкращим практикам, як і код інших користувачів, за допомогою eslint, інструмента для статичного аналізу нашого коду. Такі інструменти економлять час на виявленні одруківок чи дурних помилок у коді:

```bash
$ corepack yarn lint
```

Або виконаймо обидві дії одразу:

```bash
$ corepack yarn test && corepack yarn lint
```

Трек TypeScript на Exercism не вимагає дотримання _стилю_ коду, тож ми вільні обирати між крапками з комою, табами чи пробілами та будь-чим посередині.

## Створення першого модуля

Зазвичай тести в цьому треку завантажують нашу реалізацію, імпортуючи її як модуль: `import Bob from './bob';`.
Щоб це працювало, потрібно експортувати нашу реалізацію з файлу, у якому тести шукають наш модуль, `bob.ts`:

```typescript
export class Bob {
  public hey(message: string) {
    // Your solution here
  }
}
```

Ми підготували заготовки для кожної вправи й уже додали туди цей `export`.
