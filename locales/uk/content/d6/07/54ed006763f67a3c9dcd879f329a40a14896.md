# Булеві значення

Crystal має тип, відомий як [`Bool`][bools].
Він представляє значення `true` і `false`.

## Логічні оператори

У Crystal є три логічні оператори: `!` (логічне заперечення), `||` (логічне або) і `&&` (логічне і). Вони поєднують булеві значення (англ. Boolean) і створюють вирази, що дають різні значення.

### І(`&&`)

Оператор [_і_][and] у Crystal позначається `&&` (і) і повертає `true`, якщо обидва значення `true`; інакше він повертає `false`.
Коли ми використовуємо оператор _і_, одне булеве значення ставиться праворуч від `&&` (і), а інше - ліворуч.

```crystal
true && true
# => true

true && false
# => false
```

### Або(`||`)

Оператор [_або_][or] у Crystal позначається `||` (або) і повертає `true`, якщо **принаймні одне** з наданих значень `true`.
Якщо обидва значення `false`, то він повертає `false`.
Коли ми використовуємо оператор _або_, одне булеве значення слід поставити праворуч від `||` (або), а інше - ліворуч.

```crystal
true || true
# => true

true || false
# => true

false || false
# => false
```

### Заперечення(`!`)

Логічне заперечення у Crystal позначається `!` і повертає `true`, якщо надане булеве значення `false`, і повертає `false`, якщо надано `true`.
Коли ми використовуємо логічне заперечення, одне булеве значення слід поставити після оператора (`!`).

```crystal
!true
# => false

!false
# => true
```

## Використання дужок(`()`)

Коли ми працюємо з булевими значеннями, дужки дають змогу вирішити, які булеві значення обчислювати першими.
Результат може відрізнятися залежно від того, як використано дужки.
У Crystal те, що стоїть у дужках, обчислюється першим.

```crystal
true && false && false || true
# => true

true && false && (false || true)
# => false
```

Оскільки те, що стоїть у дужках, обчислюється першим, у наведеному далі прикладі логічне заперечення застосується до виразу всередині дужок.

```crystal
!true && false
# => false

!(true && false)
# => true
```

~~~~exercism/note
Використовуйте дужки лише тоді, коли вони впливають на результат; інакше їх слід опускати.
~~~~
