# Інструкції

У цій вправі ми будемо писати код, який допоможе фрілансеру спілкуватися з менеджером проєкту.
Наше завдання - надати кілька інструментів, щоб швидко обчислювати денні та місячні ставки, за потреби з урахуванням заданої знижки.

Спершу встановімо кілька правил між фрілансером і менеджером проєкту:

- Денна ставка у 8 разів більша за годинну ставку.
- У місяці 22 оплачувані дні.

Іноді фрілансер пропонує застосувати знижку на свою денну ставку (наприклад, для найвідданіших клієнтів або неприбуткових організацій).

Знижки подаються як дробові числа, що позначають відсотки, наприклад `25.0` (25%).

## 1. Обчислити денну ставку за годинною ставкою

Реалізуйте функцію `daily_rate`, яка обчислює денну ставку, беручи годинну ставку як параметр.
Договір визначає, що в дні 8 оплачуваних годин.

```cpp
daily_rate(60)
// => 480.0
```

Повернена денна ставка має бути типу `double`.

## 2. Обчислити ціну зі знижкою

Реалізуйте функцію `apply_discount`, яка обчислює ціну після застосування знижки.
Вона повинна приймати два параметри: початкову ціну та відсоток знижки.

```cpp
apply_discount(150, 10)
// => 135.0
```

Повернене значення завжди має бути типу `double`, без будь-якого округлення.

## 3. Обчислити місячну ставку за годинною ставкою та знижкою

Реалізуйте функцію `monthly_rate`, яка обчислює місячну ставку зі знижкою.
Вона повинна мати два параметри: годинну ставку та відсоток знижки.

```cpp
monthly_rate(77, 10.5)
// => 12130
```

Повернену місячну ставку слід округлити вгору (узяти верхню межу) до найближчого цілого числа.

## 4. Обчислити кількість повних робочих днів за бюджетом, годинною ставкою та знижкою

Реалізуйте функцію `days_in_budget`, яка приймає бюджет, годинну ставку та знижку й обчислює, на скільки повних робочих днів цього вистачить.

```cpp
days_in_budget(20'000, 80, 11.0)
// => 35
```

Повернену кількість днів слід округлити вниз (узяти нижню межу) до наступного цілого числа.
