# Докладніше

Зіставлення з шаблоном - це процес розгалуження залежно від того, чи відповідає значення заданим, можливо, глибоким шаблонам. У Haxe **зіставлення з шаблоном** виконується за допомогою виразу `switch` та окремих виразів `case`.

Розгляньмо таку структуру даних:

```haxe
enum Tree<T> {
  Leaf(v:T);
  Node(l:Tree<T>, r:Tree<T>);
}
```

- Шаблони завжди зіставляються згори вниз.
- Для найпершого шаблону, що зіставляється з вхідним значенням, виконується його вираз.
- Шаблон `_` зіставляється з будь-чим, тому `case _:` дорівнює `default:`

## Зіставлення переліків

Переліки можна зіставляти за їхніми конструкторами природним чином:

```haxe
var myTree = Node(Leaf("foo"), Node(Leaf("bar"), Leaf("foobar")));

var match = switch (myTree) {
  // Matches any Leaf
  case Leaf(_):
    "0";

  // Matches any Node that has r = Leaf
  case Node(_, Leaf(_)):
    "1";

  // Matches any Node that has
  // r = another Node which has
  // l = Leaf("bar")
  case Node(_, Node(Leaf("bar", _))):
    "2";

  // Matches anything
  case _:
    "3";
}

trace(match); // 2
```
