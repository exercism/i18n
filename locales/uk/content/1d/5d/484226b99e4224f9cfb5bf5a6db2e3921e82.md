# Докладніше

`string` (рядок тексту) у C++ - це змінюваний обʼєкт, який представляє текст як послідовність символів (літер, цифр, розділових знаків тощо).
Щоб працювати з рядками, викликають методи рядка.

## Бібліотека рядків

У C++ тип рядка тексту та повʼязані з ним функції потрібно підключити з бібліотеки рядків перед використанням.
Це можна зробити, додавши `#include <string>` на початок файлу.
Тоді вони наповнять простір імен `std`.
Рядковий літерал використовує символ подвійних лапок: `"`.

```cpp
#include <string>
std::string w_berry_quote{"A well-made sentence, I think, is a thing of beauty."};
```

## Поширені операції з рядками

Для зʼєднання рядків можна використати оператор `+`:

```cpp
std::string original_title{"The School of Rock"};
std::string sequel_indicator{"Electric Boogaloo"};
std::string next_movie_title = original_title + " 2: " + sequel_indicator;
```

Щоб скористатися бібліотекою рядків, потрібно знати, що функцію, яка належить обʼєкту, можна викликати.
Такі функції називають функціями-членами.
Пізніше в силабусі ми дізнаємося більше про функції-члени та повʼязане з ними поняття класу.

```cpp
std::string qualification{"awesome"};
// 1st argument: from the index to the end of the string:
std::string who_is_awesome = qualification.substr(5);
// => "me"

// 2nd optional argument for the length:
std::string material{"haunted books"};
std::string ghost = material.substr(8, 3);
// => "boo"
```


Функція `find` теж дуже корисна.
Її викликають як функцію-член у рядка, і вона приймає рядок як аргумент.
`find` повертає позицію з відліком від нуля для першого входження в рядку.

```cpp
std::string new_release{"apple released a new app!"};
new_release.find("app");
// => 0
new_release.find("!");
// => 24
```

Є також функція `to_string`, яку можна використати, щоб перетворити цілі числа та значення з плаваючою комою у рядок тексту.
`to_string` повертає рядок тексту.

```cpp
int num{92};
double exponent{0.92e2};
std::string msg{ std::to_string(num) + " can also be written as " + std::to_string(exponent)};
// => 92 can also be written as 92.0000000
```
