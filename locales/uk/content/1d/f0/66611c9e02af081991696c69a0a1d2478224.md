# Додаток до інструкцій

## Вихідні дані

У цій вправі ми реалізуємо дієслово, яке генерує трикутник Паскаля до заданої кількості рядків. Вихідні дані нашого дієслова можна форматувати одним із двох способів:

  1. Як масив упакованих масивів, де кожен масив представляє рядок трикутника Паскаля.
  1. Як таблиця, де числа вирівняні праворуч, а нулі використовуються для заповнення порожніх місць ліворуч.

### Приклад вихідних даних

Ось два допустимі вихідні дані для `pascal 3`:

  - Як масив упакованих масивів:
```j
  (1 ; 1 1 ; 1 2 1) -: pascal 3          NB. This test will pass
```
  - Як таблиця з доповненням:
```j
  (3 3$1 0 0 1 1 0 1 2 1) -: pascal 3   NB. This test also passes
```
