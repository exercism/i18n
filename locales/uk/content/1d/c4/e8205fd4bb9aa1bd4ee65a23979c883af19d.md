# Докладніше

Найважливіше, що варто памʼятати про рядки тексту (англ. string) у Java: це незмінні обʼєкти, які подають текст як послідовність символів Unicode (літер, цифр, розділових знаків тощо).
Щоб визначити екземпляр `String`, використовують подвійні лапки:

```java
String fruit = "Apple";
```

Опрацювати рядок тексту можна за допомогою методів класу [`String`][string-class].
Оскільки значення рядка тексту ніколи не змінюються після визначення, усі методи опрацювання рядків повертають новий рядок тексту.

Рядок тексту обмежують подвійні лапки (`"`).
Деякі спеціальні символи потрібно екранувати за допомогою символу зворотної скісної риски (`\`).
Символи, які потрібно екранувати в Java:

- `"`
- `\`

```java
String escaped = "c:\\test.txt";
// => c:\test.txt
```

Нарешті, є багато способів зʼєднати рядок тексту.
Найпростіший із них - оператор `+`:

```java
String name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

Для будь-якого форматування рядків, складнішого за просте зʼєднання, краще використовувати метод `String.format`.

```java
String name = "Jane";
String.format("Hello %s!",name);
// => "Hello Jane!"
```

Інші можливості:

- використати [клас `StringBuilder`][string-builder]
- використати [метод `String.concat`][string-concat]
