# Встановлення Emacs

Оскільки Emacs Lisp (elisp) є мовою розширень для Emacs, спершу потрібно встановити [GNU Emacs](http://www.gnu.org/software/emacs/).

Радимо взяти найновішу версію Emacs, але цільовою реалізацією для вправ слід вважати 28.1 або новішу.
Якщо Emacs уже встановлено, версію можна перевірити за допомогою `M-x emacs-version RET`.

## В OS X
Найпростіший спосіб - завітати на [Emacs For Mac OS X](http://emacsformacosx.com/) і завантажити dmg, який
встановить GNU Emacs як запакований застосунок для OS X.

Є й альтернативи, як-от Aquamacs (не радимо) або встановлення через
[Homebrew](https://formulae.brew.sh/formula/emacs), якщо так зручніше.

## У Linux
У деяких дистрибутивах Emacs уже встановлено, адже він є частиною GNU.

### Ubuntu
Наразі найновіший Emacs радимо встановлювати через [snap](https://snapcraft.io/emacs):

```
sudo snap install emacs --classic
```

Якщо не хочете використовувати snap, можна встановити Emacs і через snap, але версія, доступна в репозиторіях Ubuntu, часто застаріла.
Якщо потрібна новіша версія Emacs через apt, доведеться скористатися [PPA](https://launchpad.net/ubuntu/+ppas?name_filter=emacs) або [зібрати з початкового коду](https://www.emacswiki.org/emacs/BuildingEmacs).

Якщо найновіша версія не принципова, усе зводиться до такого:

```
sudo apt-get install emacs
```

### Arch
В Arch зазвичай уже є найновіша версія Emacs, тож виконайте:

```
sudo pacman -S emacs
```

і все готово.

### Інші дистрибутиви
Перевірте у своєму дистрибутиві, яка версія актуальна, і скористайтеся менеджером
пакунків або зберіть із початкового коду.

### Windows
Щоб встановити Emacs у Windows, перейдіть на найближче
[дзеркало FTP-архіву](https://ftpmirror.gnu.org/emacs/windows), візьміть інсталятор (=emacs-XX.X-installer.exe=) і запустіть його.
Якщо хочете користуватися Emacs без встановлення, візьміть файл із шаблоном =emacs-XX.x.zip=, розпакуйте його та запустіть `bin\runemacs.exe`.

Якщо використовуєте [MSYS2](https://www.msys2.org/), 64-бітну збірку Emacs можна встановити так:

```
pacman -S mingw-w64-x86_64-emacs
```

або 32-бітну збірку так:

```
pacman -S mingw-w64-i686-emacs
```
