# Підказки

## Загальне

- Прочитайте про композицію функцій у [керівництві][function-composition-manual].
- Перегляньте [методи, доступні для рядків тексту (англ. _string_)][string-methods].

## 1. Очистимо імʼя

- Існує [вбудований метод][string-replace], який замінює всі входження підрядка в рядку тексту.
- Існує [вбудований метод][string-strip], який видаляє пробільні символи на початку й у кінці рядка тексту.

## 2. Отримаймо першу літеру імені

- Щоб отримати конкретний символ із рядка тексту, можна скористатися [індексацією][string-indexing].
- Найпростіший спосіб записати це - скористатися оператором композиції `∘`.

## 3. Оформимо першу літеру як ініціал

- Існує [вбудований метод][string-uppercase], який перетворює всі символи рядка тексту на їхній варіант у верхньому регістрі.

## 4. Помістимо ініціали всередину серця

- Символи Unicode у рядках тексту можна записати так: `'\u<id>'`, де для емодзі серця ідентифікатор дорівнює `2764`.
- Це можна зробити за допомогою [конкатенації][string-concatenation] або [інтерполяції][string-interpolation].
