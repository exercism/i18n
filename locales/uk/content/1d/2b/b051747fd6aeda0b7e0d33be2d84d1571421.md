# Додаток до інструкцій

## Формат вихідних даних

Виведіть текст пісні як рядок тексту (англ. string), що завершується нульовим символом.

## Регістри

| Регістр  | Використання        | Тип       | Опис                          |
| -------- | ------------------- | --------- | ----------------------------- |
| `$a0`    | вхідні дані         | ціле число | початкова кількість пляшок    |
| `$a1`    | вхідні дані         | ціле число | кількість, яку знімають       |
| `$a2`    | вхідні/вихідні дані | адреса    | рядок тексту вихідних даних, що завершується нульовим символом |
| `$t0-9`  | тимчасовий          | будь-який | для тимчасового зберігання    |
