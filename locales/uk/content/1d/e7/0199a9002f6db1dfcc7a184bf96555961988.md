# Про

## Умовні конструкції

Умовні конструкції ухвалюють рішення: вони або виконують побічні ефекти, або керують потоком виконання програми.
До умовних конструкцій належать `if`, `if/else`, `switch` і `ternary`.

Умовні конструкції використовують, щоб поставити запитання про значення або про відношення між значеннями.
Запитання дає булеве значення (англ. Boolean), але сама конструкція `if` може повернути будь-яке значення або просто виконати побічний ефект.

## Конструкції `if`

Найпростіша конструкція `if` обчислює вираз і виконує один рядок.
Вираз, який перевіряють, завжди беруть у дужки.

Вона може виконати побічний ефект

```c
if (count > 10)
    printf("count is greater than 10");
```

або змінити потік виконання


```c
if (count > 10)
    return sum;
```

Якщо конструкція `if` виконує більше ніж один рядок, ці рядки потрібно взяти у фігурні дужки

```c
if (count > 10) {
    printf("count is greater than 10");
    return sum;
}
```

Деякі команди розробників можуть ухвалити стандарт, що конструкції `if` завжди використовують фігурні дужки, навіть для одного рядка.


## `if` та `else`

Конструкцію `if` можна поєднати з `else`

```c
if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## `if`, `else if`


`else` можна поєднати з ще одним `if`, і тоді утворюється так звана драбина `if-else-if`.

```c
if (number == 0)
    return "zero";
else if (number < 0)
    return "negative";
else if (number < 10)
    return "single digit";   
else if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## `switch`


Іноді конструкцію `if-else-if ladder` краще подати через `switch`.
Як і в `if`, вираз, який перевіряють, завжди беруть у дужки.

```c
switch (number) {
    case -1:
        return "negative one";
    case 0:
        return "zero";
    case 1:
        return "positive one";
    case 10:
        return "positive ten";
    case -10:
        return "negative ten";
    default:
        return "don't care";
}
```

Варіант `default` виконується, якщо значення, яке перевіряють, не збігається з жодним із попередніх варіантів.

Якщо варіант `switch` не повертає значення, то зазвичай додають `break`, щоб завершити кожен варіант, інакше керування «провалюється» до наступного варіанта.
Іноді провалювання використовують навмисно

```c
switch (number) {
    case 0:
        msg = "zero"; break;
    case 1:
        msg = "one"; break;
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

Коли провалювання відбувається ненавмисно, це помилка.

```c
switch (number) {
    case 0:
        msg = "zero"; // bug! fallthrough of 0 will set msg to "one"
    case 1:
        msg = "one"; break; 
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

`switch` буває корисним, коли перевіряють конкретні значення, а не діапазон значень.
Він може бути швидшим за `if-else-if ladder`, бо компілятор здатен оптимізувати конструкцію `switch` так, як не може оптимізувати драбину.
А часом `switch` читається краще, ніж драбина.

## Тернарний оператор (він же умовний)

Тернарний оператор - це умовна конструкція з трьох частин, яку часто використовують, щоб задати значення.
Вираз, який перевіряють, стоїть перед знаком питання, і його не обовʼязково брати в дужки.
Значення, яке повертається, коли умова виконується, стоїть перед двокрапкою, а значення, яке повертається, коли умова не виконується, - після двокрапки.
Повернути можна як літерал значення, так і змінну.

```c
int i = j > 5 ? 5: j;
```

Тернарні оператори можна вкладати один в один, щоб зменшити синтаксичний безлад.

```c
// the below could also be 
i = j > 5 ? j :k > 5 ? k: 10;
// but that may not be quite as readable

i = j > 5 ? j
    :k > 5 ? k
    :10;

// which is the same as
if (j > 5) i = j;
else if (k > 5) i = k;
else i = 10;
```

## Порівняння чисел з плаваючою комою

Через те, як реалізовано числа з плаваючою комою, навіть проста математична операція може дати похибку округлення, і тоді перевірка на рівність може не повернути очікуваний результат.

```c
    a = 1.345f;
    b = 1.123f;
    c = a + b;
    // c may equal something like 2.4679999352
    if (c == 2.468)
        return "I won the lottery!";
```

Можна використати значення допуску, яке називають `epsilon`: воно задає діапазон, у межах якого значення все ще вважається рівним під час порівняння з іншим значенням.
Деякі платформи мають вбудовані константи епсилона для `float` і `double`.
Щоб дізнатися більше, звернімося до документації свого компілятора.
Обчислення `epsilon` буває непростим і може відрізнятися на різних платформах, навіть між окремими машинами.
Ось приклад програми з простим порівнянням.

```c
#include <stdio.h>
#include <math.h>
#include <stdbool.h>

const double MY_EPSILON = .002;

bool same(double x, double y)
{
    return fabs(x - y) < MY_EPSILON;
}

int main()
{
    // Same should return true if the difference is less than MY_EPSILON
    printf("%s\n", same(1.1, 1.099) ? "true" : "false"); // prints true
    printf("%s\n", same(1.1, 1.098) ? "true" : "false"); // prints false
    return 0;
}
```

*Будьмо пильними, коли порівнюємо `float` і `double` на рівність!*
