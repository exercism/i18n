# Import

[спеціальна форма `import`][import] дає змогу використовувати функції та макроси із зовнішнього модуля, не вказуючи назву цього модуля.

Імпорт цілого зовнішнього модуля може створити конфлікти з наявними локальними функціями. Щоб цього уникнути, є два варіанти: `:except` і `:only`. Обидва приймають список ключових слів, де ключем є назва функції, а значенням - арність функції.

```elixir
defmodule Square do
  import Integer, only: [pow: 2]

  def area(a), do: pow(a, 2)
end
```

Зазвичай імпорти додають на початку визначення модуля, але можна додати їх будь-де. Вони мають лексичну область видимості, тобто імпорт, доданий усередині визначення функції, не буде доступним в іншій функції.

Невикористані імпорти спричиняють попередження компілятора.

[import]: https://hexdocs.pm/elixir/Kernel.SpecialForms.html#import/2
