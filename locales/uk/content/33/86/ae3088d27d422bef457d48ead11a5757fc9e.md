# Вступ

Буває, що функція вищого порядку приймає іншу функцію як параметр і використовує її так, що передана функція викликається _після_ того, як функція вищого порядку завершується. Це називають виходом за межі функції вищого порядку, а передану функцію називають _функцією, що виходить за межі_.

Це трапляється найчастіше в асинхронному коді, але може статися й у функціях вищого порядку, де передана функція (або функція, яка її викликає) повертається з функції вищого порядку. Наприклад:

```swift
func emptyKitchen(_ order: String) -> String {
  "Sorry, we're all out of \(order)."
}

func prepare(order: String, kitchen: (String) -> String) -> (String) -> String {
  func newKitchen(_ newOrder: String) -> String {
    if newOrder == order {
      return "One \(order) coming up!"
    } else {
      return kitchen(newOrder)
    }
  }
  return newKitchen
}
```

Тут функція `prepare` приймає функцію для свого параметра `kitchen`, а потім створює нову функцію `newKitchen`, яка може викликати `kitchen`. Цю функцію `newKitchen` потім повертають тому, хто її викликав. Спроба написати цю функцію в Swift призводить до помилки: _Escaping local function captures non-escaping parameter 'kitchen'_

Swift видає помилку в цьому випадку, тому що є ситуації, коли вкладена або передана функція може захопити значення, що може призвести до витоків памʼяті. Те, як це відбувається й як запобігти цим витокам, виходить за межі цієї вправи. Однак цю помилку можна усунути, поставивши атрибут `@escaping` перед сигнатурою типу переданої функції.

```swift
func prepare(order: String, kitchen: @escaping (String) -> String) -> (String) -> String {
  func newKitchen(_ newOrder: String) -> String {
    if newOrder == order {
      return "One \(order) coming up!"
    } else {
      return kitchen(newOrder)
    }
  }
  return newKitchen
}

let restaurant =
  prepare(order: "sandwich",
          kitchen: prepare(order: "chicken",
                           kitchen: prepare(order: "steak",
                                            kitchen: emptyKitchen)))

restaurant("pork chop")
// => "Sorry, we're all out of pork chop."
restaurant("chicken")
// => "One chicken coming up!"
```

Цей атрибут повідомляє компілятору Swift, що автор усвідомлює можливість виникнення витоків памʼяті, дозволяючи цій функції виходити за межі.
