# Інструкції

У цій вправі ми писатимемо код, щоб відстежувати масив мов програмування, які хочемо вивчити на Exercism.

На нас чекає девʼять завдань, і всі вони повʼязані з масивами.

## 1. Створити новий масив

Щоб відстежувати мови, які ми хочемо вивчити, потрібно створити новий масив.

Реалізуйте статичний метод `Languages.NewList()`, який повертає новий порожній масив.

```csharp
Languages.NewList()
// => empty list
```

## 2. Визначити наявний масив

Наразі в нас є аркуш паперу зі списком мов, які ми хочемо вивчити: C#, Clojure та Elm.

Будь ласка, реалізуйте статичний метод `Languages.GetExistingLanguages()`, який повертає цей масив.

```csharp
Languages.GetExistingLanguages();
// => {"C#", "Clojure", "Elm"}
```

## 3. Додати нову мову до масиву

Досліджуючи Exercism і знаходячи цікавіші мови, ми хочемо додати їх до свого масиву.

Реалізуйте статичну функцію `Languages.AddLanguage()`, щоб додавати нову мову в кінець масиву.

```csharp
Languages.AddLanguage(Languages.GetExistingLanguages(), "VBA");
// => {"C#", "Clojure", "Elm", "VBA"}
```

## 4. Порахувати мови в масиві

Лічити мови по одній незручно.

Реалізуйте статичний метод `Languages.CountLanguages()`, щоб порахувати кількість мов у масиві.

```csharp
Languages.CountLanguages(Languages.GetExistingLanguages())
// => 3
```

## 5. Перевірити, чи є мова в масиві

Реалізуйте статичний метод `Languages.HasLanguage()`, щоб перевірити, чи присутня мова.

```csharp
Languages.HasLanguage(Languages.GetExistingLanguages(), "Elm")
// => true
```

## 6. Перевернути масив

Згодом ми розуміємо, що наш масив насправді впорядковано задом наперед!

Реалізуйте статичний метод `Languages.ReverseList()`, щоб перевернути масив.

```csharp
Languages.ReverseList(Languages.GetExistingLanguages())
// => {"Elm", "Clojure", "C#"}
```

## 7. Перевірити, чи масив захопливий

Хоча ми любимо всі мови, C# займає особливе місце в нашому серці. Тому ми дуже радіємо масиву мов, якщо виконується одна з таких умов:

- Перша мова в масиві - C#.
- Другий елемент масиву - C#, а масив містить або дві, або три мови.

Реалізуйте статичний метод `Languages.IsExciting()`, щоб перевірити, чи масив мов захопливий:

```csharp
Languages.IsExciting(Languages.GetExistingLanguages())
// => true
```

## 8.Видалити мову

Будь ласка, реалізуйте статичний метод `Languages.RemoveLanguage()`, щоб видалити вказану мову з масиву.

```csharp
Languages.RemoveLanguage(Languages.GetExistingLanguages(), "Clojure")
// => { "C#", "Elm" }
```

## 9. Перевірити, чи всі мови в масиві унікальні

Будь ласка, реалізуйте статичний метод `Languages.IsUnique()`, щоб перевірити, чи не повторюється якась із мов у масиві.

Гарантовано, що масив мов (тобто параметр) не буде порожнім, коли викликають цей метод, і не має значення, чи буде масив змінено.

```csharp
Languages.IsUnique(Languages.GetExistingLanguages())
// => true
```
