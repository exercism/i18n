# Інструкції

У місцевому клубі фінал сезону. Ми ведемо таблицю лідерів на фінішній лінії: гонщики перетинають фініш по черзі, доріжкам потрібні позначки, а в офіційному журналі треба зробити позначки до наступного заїзду.

Імена гонщиків надходять як масив у порядку фінішу: нульове імʼя - переможець, перше - друге місце, і так далі.

## 1. Призначте нагрудні номери

Визначте `assign-bibs`, яка приймає масив імен гонщиків і повертає масив пар `{ position name }`, де позиція стоїть першою.

```factor
{ "Bolt" "Comet" "Spirit" } assign-bibs .
! => { { 0 "Bolt" } { 1 "Comet" } { 2 "Spirit" } }
```

## 2. Позначки доріжок

Визначте `lane-labels`, яка приймає масив імен гонщиків і повертає рядки тексту (англ. string) на кшталт `"Lane 0: Bolt"`.

```factor
{ "Bolt" "Comet" } lane-labels .
! => { "Lane 0: Bolt" "Lane 1: Comet" }
```

## 3. Позначте гонщиків

Визначте `tag-racers`, яка приймає масив імен гонщиків *і* рядок тексту тега та повертає позначки виду `"<tag>/<index>: <name>"`. Той самий тег закладено в кожну позначку.

```factor
{ "Bolt" "Comet" } "Green" tag-racers .
! => { "Green/0: Bolt" "Green/1: Comet" }
```

## 4. Запишіть фініші

Визначте `record-finishes`, яка приймає масив імен гонщиків і журнал (вектор). Для кожного гонщика допишіть рядок тексту виду `"<index>: <name>"` до журналу на місці. Нічого не повертає.

```factor
V{ } clone   ! a fresh empty ledger
{ "Bolt" "Comet" } over record-finishes
.
! => V{ "0: Bolt" "1: Comet" }
```

## 5. Дзвіночки за коло

Визначте `lap-bells`, яка приймає число `laps` і повертає рядок тексту, складений із `"ding "`, повтореного `laps` разів.

```factor
0 lap-bells .   ! => ""
3 lap-bells .   ! => "ding ding ding "
```
