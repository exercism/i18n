# Довідка

[`list`][lists] у F# - це незмінна колекція з нуля або більше значень. Усі значення в масиві мають бути одного типу. Оскільки масиви незмінні, після створення масиву його значення вже ніколи не зміниться. Масив F# має _голову_ (перший елемент) і _хвіст_ (усе після першого елемента). Хвіст масиву - це теж масив.

Масиви можна визначити так:

```fsharp
let empty = []
let emptyAlternative = List.empty

let singleValue = [5]
let singleValueAlternative = List.singleton 5

let threeValues = ["a"; "b"; "c"]
```

Найпоширеніший спосіб додати елемент до масиву - скористатися оператором `::` (cons):

```fsharp
let twoToFour = [2; 3; 4]
let oneToFour = 1 :: twoToFour
// => [1; 2; 3; 4]
```

Масиви можна приєднати за допомогою оператора `@` або `List.append`:

```fsharp
[6; 7] @ [8; 9]           // => [6; 7; 8; 9]
List.append [6; 7] [8; 9] // => [6; 7; 8; 9]
```

Масивами можна керувати за допомогою функцій та операторів, визначених у [модулі `List`][list-module]. Деякі з цих функцій також доступні як [властивості][list-properties] примірника `list`:

```fsharp
List.length [7; 8] // => 2
[7; 8].Length      // => 2
```

Тут немає правильного чи неправильного вибору. Загалом функції з модуля `List` краще працюють з виведенням типів, а властивості дають змогу писати лаконічніший код.

Будь-які функції чи оператори, які нібито змінюють масив (наприклад, додають елемент), насправді повертають новий масив. Продуктивність зазвичай не страждає, оскільки реалізація масивів запобігає зайвим виділенням памʼяті та копіюванням.

Оскільки масиви реалізовано як однозвʼязні списки, додавання елемента на початок (за допомогою оператора `::`) відбувається дуже швидко, тоді як доступ до елемента за індексом може бути відносно повільним.

Масиви також можна обробляти за допомогою зіставлення зі шаблоном через шаблони [_list_][list-pattern] та [_cons_][cons-pattern]:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [ 1 ] -> "Singleton list with 1"
    | head::tail -> sprintf "Non-empty list with head: %d" head

describe []        // => "Empty list"
describe [1]       // => "Singleton list with 1"
describe [5; 7; 9] // => "Non-empty with head: 5"
```

Також можна _відкидати_ значення під час зіставлення зі шаблоном; коли в конкретному випадку значення _не_ цікавить (тобто ми не збираємося його _використовувати_), можна позначити це підкресленням (`'_'`):

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [x] -> "List with one item"
    | [_; y] -> "List with two items (first item ignored)"
    | _ -> "List with many items (all items ignored)"

describe []        // => "Empty list"
describe [1]       // => "List with one item"
describe [5; 7]     // => "List with two items (first item ignored)"
describe [5; 7; 9] // => "List with many items (all items ignored)"
```

Єдиний `'_'` має завжди стояти _останнім_ під час зіставлення зі шаблоном; кожне значення, яке _не_ збігається з жодним з інших випадків, обробить цей випадок.
