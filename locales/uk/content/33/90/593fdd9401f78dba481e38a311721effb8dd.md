# Додаток до інструкцій

## Реалізація

У цій вправі ми реалізуємо процедуру, яка має виділяти памʼять під рядок тексту (англ. string), який вона повертає. А звільняти цей рядок тексту має той, хто викликає процедуру.

```odin
// The procedure will be called like that:
formatted := format("Gianna", 4)
// ...
// and eventually the caller will delete the string
delete(formatted)
```
