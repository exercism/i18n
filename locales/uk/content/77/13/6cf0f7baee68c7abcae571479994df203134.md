# Інструкції

Перетворіть число від 1 до 31 на послідовність дій у таємному рукостисканні.

Послідовність дій ми визначаємо, дивлячись на п'ять найправіших цифр числа після перетворення його в двійкову форму.
Почнімо з найправішої цифри й рухаймося ліворуч.

Дії для кожного розряду числа такі:

```plaintext
00001 = wink
00010 = double blink
00100 = close your eyes
01000 = jump
10000 = Reverse the order of the operations in the secret handshake.
```

Розгляньмо число `9` як приклад:

- Число 9 у двійковій системі - це `1001`.
- Цифра, що найдалі праворуч, - 1, тому перша дія - `wink`.
- Рухаючись ліворуч, наступна цифра - 0, тому double-blink немає.
- Знову рухаючись ліворуч, наступна цифра - 0, тому очі залишаються розплющеними.
- Знову рухаючись ліворуч, наступна цифра - 1, тому ми робимо jump.

Це була остання цифра, тому кінцевий код такий:

```plaintext
wink, jump
```

Для числа 26, яке в двійковій системі дорівнює `11010`, ми отримуємо такі дії:

- double blink
- jump
- зворотний порядок дій

Отже, таємне рукостискання для 26 таке:

```plaintext
jump, double blink
```
