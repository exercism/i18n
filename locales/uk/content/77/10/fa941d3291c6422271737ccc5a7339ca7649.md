# Додаток до інструкцій

## Процес IO

На відміну від інших вправ, `grep` потребує взаємодії із «зовнішнім світом»: читання файлів, обробки системних помилок і виведення в `stdout`.

У Lean взаємодія із системою зазвичай відбувається в монаді [IO][io], яка дозволяє побічним ефектам виникати в ізольованому середовищі, не впливаючи на чистий стан більшості інших функцій.

## Читання аргументів

Lean дозволяє викликати файл як скрипт: або безпосередньо як окремий скрипт через `lean --run`, або з використанням `lake`.

Проєкт Lean має одну точку входу, функцію з назвою `main`, яка приймає `List String` з усіма переданими їй аргументами.
Щоб змоделювати запуск `Grep.lean` як виконуваного файлу, у цій вправі аргументи передаються так само.

## Читання файлів

Lean пропонує [функції][files] для роботи з файлами в монаді `IO.FS`.
Наприклад, `IO.FS.readFile` можна використати, щоб прочитати вміст файлу за заданим шляхом як `String`.

## Запис вихідних даних

Замість повернення значення ця вправа вимагає, щоб результати записувалися до стандартного виводу або стандартного потоку помилок.
Для цього в Lean є [функції][console].

## Обробка системних помилок

На відміну від помилок у `Except`, винятки `IO` насправді є винятками часу виконання.
Щоб їх обробити, можна використати `try`/`catch`:

```
try
    /- 
        code that may possibly raise an exception 
    -/
catch msg =>
    /-
        code that is executed only if an exception was thrown
    -/
```
