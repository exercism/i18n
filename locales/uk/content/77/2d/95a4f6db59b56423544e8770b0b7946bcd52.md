# Вступ

## Функції

У Gleam функції визначаються за допомогою синтаксису `pub fn`.

```gleam
pub fn add(x: Int, y: Int) -> Int {
  x + y
}
```

Ця функція приймає два аргументи, обидва типу `Int`, і повертає значення типу `Int`. У Gleam немає ключового слова `return`, значення останнього виразу у функції завжди _неявно повертається_.

Анотації типів для аргументів і тип повернення є необовʼязковими, і Gleam завжди повністю перевіряє типи в нашому коді. Зазвичай програмісти Gleam додають анотації типів до своїх функцій для ясності, але ми можемо їх опустити, якщо хочемо.

```gleam
pub fn add(x, y) {
  x + y
}
```

Функцію можна викликати за допомогою синтаксису `function_name(argument1, argument2)`.

```gleam
pub fn double(x: Int) -> Int {
  // Call the add function defined above
  add(x, x)
}
```

## Змінні

У Gleam змінні визначаються за допомогою синтаксису `let name = expression`.

```gleam
pub fn main() {
  let count = 1
}
```

Змінні можна оголошувати з анотаціями типів. Як і аргументи функцій, вони необовʼязкові, хоча більшість програмістів Gleam опускають анотації типів для змінних заради стислості.

```gleam
pub fn main() {
  let count: Int = 1
}
```

## Літерали рядків тексту

У Gleam рядки тексту (англ. string) записуються за допомогою подвійних лапок.

```gleam
pub fn greeting() {
  "Hello, world!"
}
```

## Коментарі в коді

Коментарі можна використовувати, щоб залишати нотатки для інших розробників, які читають вихідний код. У Gleam коментар складається з одного рядка, перед яким стоїть `//`.

```gleam
pub fn main() {
  // This is a comment
  let x = 1
}
```
