# Інструкції

У цій вправі ми допомагаємо молодшій сестрі відредагувати її роботу для школи. Учитель звертає увагу на правильну пунктуацію, граматику та вдалий добір слів.

Попереду чотири завдання, у яких ми прибираємо зайве й змінюємо рядки тексту (англ. string).

## 1. Зробіть перші літери слів у заголовку роботи великими

Будь-яка гарна робота потребує правильно оформленого заголовка.
Реалізуйте функцію `capitalize_title(<title>)`, яка приймає заголовок `str` як параметр і робить першу літеру кожного слова великою.
Ця функція має повернути `str`, у якому кожне слово починається з великої літери.


```python
>>> capitalize_title("my hobbies")
"My Hobbies"
```

## 2. Перевірте, чи кожне речення закінчується крапкою

Ми хочемо переконатися, що пунктуація в роботі бездоганна.
Реалізуйте функцію `check_sentence_ending()`, яка приймає `sentence` як параметр. Ця функція має повернути `bool`.


```python
>>> check_sentence_ending("I like to hike, bake, and read.")
True
```

## 3. Приберіть зайві пробіли

Щоб робота мала професійний вигляд, потрібно прибрати зайві пробіли.
Реалізуйте функцію `clean_up_spacing()`, яка приймає `sentence` як параметр.
Функція має прибрати зайві пробіли на початку й у кінці речення та повернути новий, оновлений `str` із цим реченням.


```python
>>> clean_up_spacing(" I like to go on hikes with my dog.  ")
"I like to go on hikes with my dog."
```

## 4. Замініть слова синонімами

Щоб зробити роботу _ще кращою_, можна замінити деякі прикметники їхніми синонімами.
Напишіть функцію `replace_word_choice()`, яка приймає `sentence`, `old_word` і `new_word` як параметри.
Ця функція має замінити всі входження `old_word` на `new_word` і повернути новий `str` з оновленим реченням.


```python
>>> replace_word_choice("I bake good cakes.", "good", "amazing")
"I bake amazing cakes."
```
