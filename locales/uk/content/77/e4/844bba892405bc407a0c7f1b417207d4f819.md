# Вступ

У Gleam константи дають змогу дати імена значенням. Їх визначають за допомогою ключового слова `const`.

```gleam
pub const pi: Float = 3.14159

pub fn circle_area(radius: Float) -> Float {
  radius *. radius *. pi
}
```

Коли модульні константи визначено з ключовим словом `pub`, до них можна отримати доступ з інших модулів, інакше вони доступні лише зсередини модуля, у якому їх визначено.
