# Як працює рекурсія в JavaScript

Рекурсія - це потужна концепція в програмуванні, яка полягає в тому, що функція викликає саму себе.
Спочатку її буває трохи складно зрозуміти, але коли ми розберемося в основах, вона стає цінним інструментом у розвʼязанні складних задач.
Розглянемо рекурсію в JavaScript на простих прикладах.

## Що таке рекурсія?

Рекурсія виникає тоді, коли функція викликає саму себе безпосередньо або опосередковано.
Вона схожа на цикл, але передбачає розбиття задачі на менші, зручніші підзадачі.

### Приклад 1: відлік

Почнімо з простого прикладу: функція відліку.

```javascript
function countdown(num) {
  // Base case
  if (num <= 0) {
    console.log('Blastoff!');
    return;
  }

  // Recursive case
  console.log(num);
  countdown(num - 1);
}

// Call the function
countdown(5);
```

У цьому прикладі:

- **Базовий випадок**: коли `num` стає меншим або дорівнює 0, функція виводить «Blastoff!» і припиняє викликати себе.
- **Рекурсивний випадок**: функція виводить поточне значення `num` і викликає себе з `num - 1`.

### Приклад 2: факторіал

А тепер розглянемо класичний приклад рекурсії: обчислення факторіала числа.

```javascript
function factorial(n) {
  // Base case
  if (n === 0 || n === 1) {
    return 1;
  }

  // Recursive case
  return n * factorial(n - 1);
}

// Test the function
console.log(factorial(5)); // Output: 120
```

У цьому прикладі:

- **Базовий випадок**: коли `n` дорівнює 0 або 1, функція повертає 1.
- **Рекурсивний випадок**: функція множить `n` на факторіал `n - 1`.

## Ключові поняття

### Базовий випадок

Кожна рекурсивна функція повинна мати принаймні один базовий випадок, тобто умову, за якої функція припиняє викликати себе.
Без базового випадку рекурсія тривала б нескінченно, що призводить до переповнення стека.

### Рекурсивний випадок

Рекурсивний випадок визначає, як функція викликає себе з меншою або простішою версією задачі.

## Переваги та недоліки рекурсії

**Переваги:**

- Витончене рішення для деяких задач.
- Наслідує концепцію математичної індукції.

**Недоліки:**

- Може бути менш ефективною, ніж ітеративні рішення.
- Може призвести до переповнення стека за глибокої рекурсії.

## Висновок

Рекурсія - цінний прийом, який спрощує складні задачі, розбиваючи їх на менші, зручніші підзадачі.
Розуміння базових і рекурсивних випадків є ключовим для ефективних рекурсивних рішень у JavaScript.
