# Інструкції

У цій вправі ми застосуємо [правила гри в ґо](https://matmoore.github.io/learngo/). Самі правила вже написані, потрібно лише застосувати їх, щоб оновити Game і обробити будь-які помилки чи порушення правил.

Гру представлено так:

```elm
type Player
    = Black
    | White


type alias Game =
    { whiteCapturedStones : Int
    , blackCapturedStones : Int
    , player : Player
    , error : String
    }
```

У грі є 4 правила:

- Кожна точка може мати лише один камінь (`oneStonePerPointRule`)
- Камені суперника можна захопити! (`captureRule`)
- Не можна ставити камінь там, де він захопив би сам себе (`libertyRule`)
- Не можна використати ту саму точку двічі (`koRule`)

## 1. Застосуйте правила

Напишіть вміст функції `applyRules`, яка приймає початковий `Game` і набір правил та повертає новий `Game` після застосування правил.

`oneStonePerPointRule`, `libertyRule` і `koRule` перевіряють, чи не порушено правила, і можуть повернути помилку, тому мають тип повернення `Result String Game`. Якщо якесь із цих правил не проходить, потрібно повернути початкову гру, але з оновленим полем `error`, у якому записано відповідну помилку.

`captureRule` не перевіряє порушень, тому не може зазнати невдачі (хоча може повернути змінений `Game`), тож має тип повернення `Game`.

Якщо всі правила проходять, то всі зміни `Game`, внесені правилами, потрібно зберегти, а гравця змінити. Для цього надано функцію `changePlayer`.

```elm
applyRules : Game -> Rule -> NonValidatingRule -> Rule -> Rule -> Game
applyRules game oneStonePerPointRule captureRule libertyRule koRule =
--> If all rules pass, return a `Game` with all changes from the rules applied, and changePlayer
--> If any rule fails, return the original Game, but with the error field set
```
