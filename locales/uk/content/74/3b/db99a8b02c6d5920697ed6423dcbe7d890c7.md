# PaySwitch - конвертер зарплати

## Постановка задачі

Компанія **Insure Everyone** платить своїм працівникам в іноземних валютах. Але через вимоги законодавства зарплату потрібно конвертувати в місцеву валюту. Її працівники розкидані по всьому світу.
Відділ кадрів Insure Everyone шукає талановитого розробника, який допоможе створити програму для конвертації зарплати кожного працівника у відповідну місцеву валюту. Insure Everyone покладається на курси обміну, які надає зовнішній API.

Маючи зовнішній API курсів обміну, нам потрібно написати функцію, яка приймає `source currency`, `salary` (у вихідній валюті) та `local currency` працівника і повертає зарплату в місцевій валюті.

## Обмеження

* 500 <= `salary` <= 10000
* `sourceCurrency` і `targetCurrency` - це [коди валют ISO (алфавітні)](https://en.wikipedia.org/wiki/ISO_4217#Active_codes). Тестові вхідні дані можуть містити недійсні коди валют.
* Точність поверненого курсу вимірюється до `5` знаків після коми.

## Приклад

### Приклад 1

#### Вхідні дані:
* Зарплата: 1000
* Вихідна валюта: USD
* Цільова валюта: GBP

#### Вихідні дані:

Припустімо, що зовнішній обмін валют повернув таку відповідь із курсами конвертації (скорочено):

```json
{
    "base": "USD",
    "rates": {
        // omitted
        "GBP": 0.73584,
        // omitted
    }
}
```

Функція має повернути `735.84000`
