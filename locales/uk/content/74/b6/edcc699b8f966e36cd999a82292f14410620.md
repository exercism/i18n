# Вказівки

Ми завзяті спостерігачі за птахами й ведемо облік того, скільки птахів завітало до нашого саду.
Зазвичай ми ведемо лічбу птахів у записнику, але, щоб зручніше працювати з даними, ми оцифрували підрахунки птахів за останні тижні.

## 1. Визначте загальну кількість птахів, яких ми нарахували на цей момент

Почнімо аналізувати дані із загального огляду.
Зʼясуймо, скільки птахів ми нарахували загалом відтоді, як почали вести свої записи.

Реалізуйте функцію `TotalBirdCount`, яка приймає зріз `int`, що містить кількість птахів за кожен день.
Вона повинна повернути загальну кількість птахів, яких ми нарахували.

```go
birdsPerDay := []int{2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1}
TotalBirdCount(birdsPerDay)
// => 34
```

## 2. Обчисліть кількість птахів, що завітали, за конкретний тиждень

Тепер, коли в нас є загальне уявлення про підрахунки птахів, хочеться зробити докладніший аналіз.

Реалізуйте функцію `BirdsInWeek`, яка приймає зріз підрахунків птахів за днями та номер тижня.

Вона повертає загальну кількість птахів, яких ми нарахували за цей конкретний тиждень.
Можна припускати, що тижні завжди обліковані повністю.

```go
birdsPerDay := []int{2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1}
BirdsInWeek(birdsPerDay, 2)
// => 12
```

## 3. Виправте помилку в підрахунку

Ми зрозуміли, що весь час, поки ми намагалися вести облік птахів, один птах ховався в далекому куточку саду.

Ми зʼясували, що цей птах завжди проводив у нашому саду кожен другий день.

Ми не знаємо точно, де він був у проміжках між цими днями, але точно не в нашому саду.

Інтуїція спостерігача за птахами також підказує, що цей птах був у нашому саду першого дня, який ми записали.

З огляду на цю нову інформацію напишіть функцію `FixBirdCountLog`, яка приймає як аргумент зріз підрахунків птахів за днями та повертає цей зріз після виправлення помилки в підрахунку.

```go
birdsPerDay := []int{2, 5, 0, 7, 4, 1}
FixBirdCountLog(birdsPerDay)
// => [3 5 1 7 5 1]
```
