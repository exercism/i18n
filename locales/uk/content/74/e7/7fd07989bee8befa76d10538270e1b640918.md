## Обмеження

* 1 <= N <= 5
* 1 <= x <= 10

Вхідні дані

```

```

```

```

## Підказки

* Щоб викликати API отримання мільярдерів за країною, можна скористатися [клієнтом](https://lib.ballerina.io/ims/billionairehub/1.0.0/clients/Client) пакета `ims/billionairehub`. Зокрема, для цього призначений віддалений метод `getBillionaires("<country>")`.

* Для фільтрування та сортування стануть у пригоді [вирази запитів](https://ballerina.io/learn/by-example/query-expressions/)
