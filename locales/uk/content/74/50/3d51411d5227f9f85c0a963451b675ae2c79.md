# Докладніше

Структури даних, які можуть вміщати нуль або більше елементів, називаються _колекціями_. **Масив** - це колекція, яка має фіксований розмір (довжину), і всі її елементи повинні бути одного типу. Елементи можна присвоїти масиву або отримати з нього за допомогою індексу. Масиви в C# індексуються з нуля, тобто індекс першого елемента завжди дорівнює нулю:

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true

// Check the length of the array
twoInts.Length == 2; // => true
```

Масиви також можна визначати за допомогою скороченого запису, який дозволяє одночасно створити масив і задати його значення. Оскільки компілятор тепер може визначити, скільки елементів буде в масиві, довжину можна опустити:

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

Масивами можна керувати, викликаючи [методи][array-methods] чи [властивості][array-properties] екземпляра масиву, або використовуючи статичні методи, визначені в [класі `Array`][array-class].

## Ітерація

Масив також є _колекцією_, а це означає, що ми можемо перебрати _всі_ його значення за допомогою [циклу `foreach`][foreach-statement]:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```

Для перебирання масиву можна використати [цикл `for`][for-statement]:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

for (int i = 0; i < vowels.Length; i++)
{
    // Output the vowel
    System.Console.Write(vowels[i]);
}

// => aeiou
```

Однак зазвичай цикл `foreach` кращий за цикл `for` з таких причин:

- Цикл `foreach` гарантовано перебирає _всі_ значення. У циклі `for` легко пропустити елементи, наприклад через помилку на одиницю.
- Цикл `foreach` більш _декларативний_: наш код повідомляє, _що_ ми хочемо зробити, тоді як цикл `for` повідомляє, _як_ ми хочемо це зробити.
- Цикл `foreach` захищений від помилок, тоді як у циклах `for` легко припуститися помилки на одиницю.
- Цикл `foreach` працює з усіма типами колекцій, зокрема з тими, які не підтримують доступ до елементів через індексатор.

Щоб гарантувати, що цикл `foreach` перебере _всі_ значення, компілятор не дозволяє змінювати колекцію всередині циклу `foreach`:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

Цикл `for` має деякі переваги над циклом `foreach`:

- Можна почати або зупинитися на потрібному індексі.
- Можна використати будь-яку булеву (англ. Boolean) умову завершення.
- Можна пропускати елементи, налаштувавши інкремент змінної циклу.
- Можна обробляти колекції від кінця до початку, ведучи відлік у зворотному напрямку.
- Можна використовувати цикли `for` у ситуаціях, які не повʼязані з колекціями.

Повʼязані теми:

- Варто знати, що C# підтримує [багатовимірні масиви][multi-dimensional-arrays], як-от `int[,] arr = new int[10, 5]`, які можуть бути дуже корисними.
- Також варто знати, що можна створити обʼєкти типу [`System.Array`][system-array-object] за допомогою `Array.CreateInstance`. Такі обʼєкти майже не мають застосування, головно для взаємодії з кодом VB.NET. Вони не взаємозамінні зі стандартними масивами (`T[]`). Їхня нижня межа може бути не нульовою.
