# Інструкції

У цій вправі нам потрібно перекласти кілька правил із класичної гри Pac-Man у функції C++.

Перед нами чотири правила, усі повʼязані зі станами гри.

> Не переймаймося тим, як отримуються аргументи, а зосередьмося на тому, щоб поєднати аргументи й повернути потрібний результат.

## 1. Визначте, чи зʼїдає Pac-Man привида

Визначте функцію `can_eat_ghost`, яка приймає два аргументи (_чи в Pac-Man активна енергетична піґуля_ та _чи торкається Pac-Man привида_) і повертає булеве значення (англ. Boolean), яке показує, чи здатен Pac-Man зʼїсти привида. Функція повинна повертати правду лише тоді, коли в Pac-Man активна енергетична піґуля і він торкається привида.

```cpp
can_eat_ghost(false, true);
// => false
```

## 2. Визначте, чи набирає Pac-Man очки

Визначте функцію `scored`, яка приймає два аргументи (_чи торкається Pac-Man енергетичної піґулі_ та _чи торкається Pac-Man крапки_) і повертає булеве значення, яке показує, чи набрав Pac-Man очки. Функція повинна повертати правду, якщо Pac-Man торкається енергетичної піґулі або крапки.

```cpp
scored(true, true);
// => true
```

## 3. Визначте, чи програє Pac-Man

Визначте функцію `lost`, яка приймає два аргументи (_чи в Pac-Man активна енергетична піґуля_ та _чи торкається Pac-Man привида_) і повертає булеве значення, яке показує, чи програє Pac-Man. Функція повинна повертати правду, якщо Pac-Man торкається привида і в нього не активна енергетична піґуля.

```cpp
lost(false, true);
// => true
```

## 4. Визначте, чи перемагає Pac-Man

Визначте функцію `won`, яка приймає три аргументи (_чи зʼїв Pac-Man усі крапки_, _чи в Pac-Man активна енергетична піґуля_ та _чи торкається Pac-Man привида_) і повертає булеве значення, яке показує, чи перемагає Pac-Man. Функція повинна повертати правду, якщо Pac-Man зʼїв усі крапки і не програв за аргументами, визначеними в частині 3.

```cpp
won(false, true, false);
// => false
```
