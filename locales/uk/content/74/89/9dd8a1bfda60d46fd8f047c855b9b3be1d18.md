# Вступ

У програмуванні часто доводиться працювати з текстом.
Swift разом із фреймворком Foundation надає чимало зручних методів і властивостей, щоб переглядати, перетворювати та опрацьовувати рядки тексту (англ. string).

## Розбиття рядків тексту за допомогою `components(separatedBy:)`

Щоб розбити рядок тексту на масив підрядків за роздільником, можна скористатися методом `components(separatedBy:)` (потрібен імпорт Foundation):

```swift
import Foundation

let sentence = "Hello, world!"
let words = sentence.components(separatedBy: " ")
print(words) // Prints ["Hello,", "world!"]
```

## Перевірка префіксів і суфіксів за допомогою `hasPrefix(_:)` і `hasSuffix(_:)`

Щоб перевірити, чи починається або закінчується рядок тексту певною послідовністю символів, можна скористатися методами `hasPrefix(_:)` і `hasSuffix(_:)`:

```swift
let greeting = "Hello, world!"
print(greeting.hasPrefix("Hello"))  // Prints true
print(greeting.hasSuffix("world!")) // Prints true
```

## Зміна регістру

Регістр рядка тексту можна змінити за допомогою таких стандартних методів і властивостей:

- `lowercased()`: повертає копію рядка тексту в нижньому регістрі.
- `uppercased()`: повертає копію рядка тексту у верхньому регістрі.
- `capitalized`: повертає копію, у якій перша літера кожного слова велика (з Foundation).

```swift
let greeting = "hello, world!"
print(greeting.lowercased())  // Prints "hello, world!"
print(greeting.uppercased())  // Prints "HELLO, WORLD!"
print(greeting.capitalized)   // Prints "Hello, World!"
```

## Заміна підрядків за допомогою `replacingOccurrences(of:with:)`

Щоб замінити всі входження цільового підрядка іншим рядком тексту, можна скористатися методом `replacingOccurrences(of:with:)` (з Foundation):

```swift
let greeting = "Hello, world!"
let updated = greeting.replacingOccurrences(of: "world", with: "Swift")
print(updated) // Prints "Hello, Swift!"
```

## Зʼєднання рядків тексту за допомогою `joined(separator:)`

Метод `joined(separator:)` належить колекціям рядків тексту, як-от `[String]`.
Він зʼєднує елементи в один рядок тексту за допомогою роздільника:

```swift
let words = ["Hello", "world"]
let sentence = words.joined(separator: ", ")
print(sentence) // Prints "Hello, world"
```
