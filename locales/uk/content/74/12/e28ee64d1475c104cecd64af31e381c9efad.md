# Вступ до циклів `for`

[Цикл `for`](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/for.html) дає механізм виконувати групу інструкцій повторно, доки не виконається певна умова.
Цикл складається з чотирьох частин:

```java
for (initialization; test; update) {
    body;
}
```

`initialization` задає початковий стан циклу і виконується рівно один раз на його початку.
Зазвичай тут оголошують і присвоюють змінну, яку використовують у виразі `test` та виразі `update`.
Наприклад:

```java
int i = 1
```

Вираз `test` перевіряє, чи має цикл завершитися.
Якщо він набуває значення `true`, виконуються тіло циклу, а потім вираз `update`.
Якщо він набуває значення `false`, не виконується ні тіло циклу, ні вираз `update`, і виконання продовжується після закривної фігурної дужки циклу.
Зазвичай він перевіряє змінну, присвоєну в блоці `initialization`.
Наприклад:

```java
i <= 10
```

Після виконання тіла циклу виконується вираз `update`.
Зазвичай він збільшує або зменшує змінну циклу на певне значення.
Наприклад:

```java
i++
```

Цикл `for`, який виводить перші чотири квадрати, матиме такий вигляд:

```java
for (int i = 1; i <= 4; i++) {
    System.out.println("square of " + i + " is " + i * i);
}
```

Вихідні дані будуть такими:

```text
square of 1 is 1
square of 2 is 4
square of 3 is 9
square of 4 is 16
```

Якщо потрібно перебрати кожен елемент колекції, краще використати цикл `for-each`, але це можна зробити й циклом `for` ось так:

```java
for (int i = 0; i < array.length; i++) {
    System.out.print(array[i]);
}
```

Цикл `for` має деякі переваги над циклом `for-each`:

- Можна почати або зупинитися на потрібному індексі.
- Можна використати будь-яку (булеву) умову завершення, яку потрібно.
- Можна пропускати елементи, налаштувавши збільшення змінної циклу.
- Можна обробляти колекції від кінця до початку, рахуючи у зворотному порядку.
- Можна використовувати цикли `for` у ситуаціях, не повʼязаних із колекціями.
