# Інструкції

У цій вправі ми працюватимемо над планувальником записів на прийом для салону краси в Нью-Йорку, який відкрився 15 вересня 2012 року.

На нас чекає пʼять завдань, і всі вони повʼязані з датами прийомів.
Час подано у 24-годинному форматі (без AM/PM).
Щоб якомога спростити питання часових поясів, вважатимемо, що всюди використовується UTC.

## 1. Розібрати дату прийому, записану лише цифрами

Реалізуйте функцію `schedule_appointment()`, щоб розібрати текстове подання дати прийому та перетворити його на відповідний формат `DateTime`.

Зауважте, що вхідні дані подано в американському порядку місяць/день/рік.

```julia-repl
julia> schedule_appointment("07/25/2023 13:45:00")
2023-07-25T13:45:00
```

## 2. Перевірити, чи прийом уже минув

Реалізуйте функцію `has_passed()`, яка приймає дату прийому й перевіряє, чи був прийом колись у минулому:

```julia-repl
julia> has_passed(DateTime(1999, 12, 31, 9, 0, 0))
true
```

## 3. Перевірити, чи припадає прийом на післяобідній час

Реалізуйте функцію `is_afternoon_appointment()`, яка приймає дату прийому й перевіряє, чи припадає прийом на післяобідній час (>= 12:00 і < 18:00):

```julia-repl
julia> is_afternoon_appointment(DateTime(2023, 3, 29, 15, 0, 0))
true
```

## 4. Перевірити день тижня для прийому

Реалізуйте функцію `day_of_week()`, яка повертає _числовий_ день тижня.
Салон не працює в неділю, тож понеділок має номер 1, а субота - 6.

```R
# a Friday
day_of_week(make_datetime(2026, 06, 05, 12, 30, 00))
#> [1] 5
```

## 5. Перенести прийом

Коли клієнту потрібно перенести прийом, його автоматично призначають на наступну пʼятницю на ту саму годину (адже це найменш завантажений день тижня).

Реалізуйте функцію `reschedule()`, яка приймає початковий прийом (як рядок тексту (англ. string) у порядку місяць/день/рік) і повертає перенесений прийом.

```R
# a Saturday
reschedule("06/13/2026 12:30:00")
#> [1] "2026-06-19 12:30:00 UTC"
```

Якщо початковий прийом припадав на понеділок-четвер, перенесіть його на пʼятницю _цього_ тижня.
Для прийомів у пʼятницю або суботу перенесіть на пʼятницю _наступного_ тижня.
