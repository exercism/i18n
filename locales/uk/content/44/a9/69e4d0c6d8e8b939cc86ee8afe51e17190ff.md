# Про

Класи - це основний будівельний блок програмування на Swift. Вони дають змогу обʼєднувати повʼязані дані та функції в самодостатні одиниці функціональності.

### Визначення класів

Щоб визначити клас, почнімо з ключового слова `class`, після якого йде назва типу, який ми визначаємо, а далі тіло класу, розміщене між фігурними дужками.

Тіло може складатися зі збережених властивостей, які визначаються та поводяться так само, як звичайні константи чи змінні.

```swift
class GameCharacter {
  var characterClass: String?
  var name: String?
  var active = false
  let id = makeRandomID()
}
```

### Екземпляри

Як зазначено вище, визначення класу - це лише визначення нового _типу_. Це лише креслення того, як матимуть вигляд значення цього типу, але воно насправді не створює жодних значень цього типу, з якими ми могли б працювати.

Щоб створити _екземпляр_ цього типу, потрібно написати назву типу, а потім пару дужок.

```swift
let someCharacter = GameCharacter()
```

Це створить значення цих типів, у яких властивості заповнюються типовими значеннями, наданими у визначенні. Зауважмо, що в опціональних випадках, як-от властивість `name` у GameCharacter, якщо значення не надано, властивість типово дорівнюватиме nil, так само як і під час визначення звичайних опціональних типів, де значення не надається одразу.

### Доступ до властивостей

До властивостей класу можна отримати доступ за допомогою _крапкової нотації_, де після назви значення йде крапка (`.`) та назва властивості. Якщо властивість класу має власні властивості, цю крапкову нотацію можна використати й для доступу до таких вкладених властивостей.

Цю нотацію можна використовувати як для отримання значення властивості, так і, де це дозволено, для його зміни.

```swift
someCharacter.name
// => nil
someCharacter.name = "Luther"
someCharacter.name
// => "Luther"

someCharacter.id  = "new id"
// Error: Cannot assign to property: 'id' is a 'let' constant
```

### Методи

Як і властивості, які зберігають дані у класах, ми також можемо визначати _методи_, які зберігають функції у класі.

Методи визначаються так само, як звичайна функція, лише всередині тіла класу. Крім того, якщо властивість може бути змінена методом, її потрібно визначити за допомогою `var`, а не `let`, так само як і звичайні змінні.

```swift

class GameCharacter {
  var characterClass: String?
  var name: String?
  var active = false
  let id: String = makeRandomID()

  func takesDamage(_ damage: Double) {
    if damage > 100 {
      active = false
    }
  }
  func sayName() -> String {
    return "My name is \(name ?? "no one"), my class is \(characterClass ?? "undetermined")"
  }
}
```

Ці методи можна викликати за допомогою крапкової нотації, так само як і властивості.

```swift
var myChar = GameCharacter()
myChar.active = true
myChar.takesDamage(200)
myChar.active
// => false
```

### Self

Кожен екземпляр класу має неявне значення з назвою `self`, яке вказує на сам екземпляр. Є кілька способів використання `self`, але найчастіше його застосовують, щоб усунути неоднозначність назв властивостей і методів структури чи класу, коли може виникнути плутанина.
