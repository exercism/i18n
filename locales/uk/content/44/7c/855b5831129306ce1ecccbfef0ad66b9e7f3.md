# Докладніше

У Clojure `string` (рядок тексту (англ. string)) - це Java-рядок, тобто обʼєкт, який представляє незмінний текст як послідовність символів Unicode (літер, цифр, розділових знаків тощо) і визначається так:

```clojure
(def fruit "Apple")
```

Бібліотека `clojure.string` надає багато стандартних функцій для маніпулювання рядками тексту та їх обробки. Крім того, усі звичайні методи Java для роботи з рядками тексту доступні через взаємодію.
