# Встановлення

Інструкції з налаштування системи наведено в [System/Installation][install-link].

~~~exercism/caution
Якщо в системі встановлено Java Development Kit (JDK), виконуваний файл `jconsole` може потенційно конфліктувати з Java Console, яка має таку саму назву.

Серед можливих рішень:

- Перейменувати виконуваний файл `jconsole` мови програмування J на щось унікальне (наприклад, `jconsole-jlang`).

- Змінити змінні середовища системи або PATH так, щоб `jconsole` мови програмування J мав вищий пріоритет.

- **Для користувачів Linux** існує bash-скрипт у `bin/install.sh`, який створить **символічне посилання** з назвою `ijconsole` у каталозі `/usr/`. Скористатися цим посиланням можна, набравши `ijconsole` у терміналі.
~~~

Після встановлення J відкрийте консоль J у терміналі та введіть наведені нижче команди, щоб встановити фреймворк модульних тестів:

```j
  load 'pacman'
  'update' jpkg ''
  'install' jpkg 'general/unittest'
  exit 0
```
