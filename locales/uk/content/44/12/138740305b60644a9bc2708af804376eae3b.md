# Вступ

Створити екземпляр класу можна, викликавши його [_конструктор_][constructor] через оператор `new`. Конструктор - це особливий метод у класі, мета якого - ініціалізувати клас. У Haxe метод-конструктор має назву `new()`.

```haxe
class Library {
  private var books:Int;

  public function new() {
    this.books = 10; // Initialize the books field
  }
}

var library = new Library(); // This calls the constructor
```

Як і звичайні методи, конструктори можуть приймати параметри. Ці параметри (зазвичай) зберігаються в приватних полях, а звертаються до них пізніше.

```haxe
class Building {
  private var numberOfStories:Int;
  private var totalHeight: Float;

  public function new(numberOfStories:Int, storyHeight:Float) {
    this.numberOfStories = numberOfStories;
    this.totalHeight = storyHeight * numberOfStories;
  }
}

var largeBuilding = new Building(55, 6.2);
```

Ми **не можемо** створити новий екземпляр класу, якщо в нього немає конструктора. Отже, єдиний вихід - використати порожній конструктор.

```haxe
class Car {
  public var weight:Int = 1000;

  public function new() {}
}

var myCar = new Car();
```
