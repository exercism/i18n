# Вступ

Булеві значення (англ. Boolean) у Go представлені попередньо оголошеним булевим типом `bool`, значеннями якого можуть бути `true` або `false`.
Це визначений тип.

```go
var closed bool    // boolean variable 'closed' implicitly initialized with 'false'
speeding := true   // boolean variable 'speeding' initialized with 'true'
hasError := false  // boolean variable 'hasError' initialized with 'false' 
```

Go підтримує три логічні оператори, які зводять вирази до булевих значень, повертаючи `true` або `false`.

| Оператор    | Що це означає                                 |
| ----------- | --------------------------------------------- |
| `&&` (логічне і)  | Дає правду, якщо обидва твердження правдиві.       |
| `\|\|` (логічне або) | Дає правду, якщо правдиве принаймні одне твердження. |
| `!` (логічне заперечення)   | Дає правду лише тоді, коли твердження неправдиве.    |
