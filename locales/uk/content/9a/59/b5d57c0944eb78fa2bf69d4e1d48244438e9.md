# Вказівки

Ми завзяті спостерігачі за птахами й ведемо облік того, скільки птахів завітало до нашого саду за останні сім днів.

На нас чекає шість завдань, і всі вони стосуються кількості птахів, які відвідали наш сад.

## 1. Перевірте, якими були підрахунки минулого тижня

Для порівняння ми завжди тримаємо поруч копію підрахунків за минулий тиждень, а саме: 0, 2, 5, 3, 7, 8 і 4. Визначте привʼязку `lastWeek`, яка містить підрахунки за минулий тиждень:

```fsharp
lastWeek
// => [| 0; 2; 5; 3; 7; 8; 4 |]
```

## 2. Перевірте, скільки птахів прилетіло учора

Реалізуйте функцію `yesterday`, яка повертає кількість птахів, що відвідали наш сад учора. Підрахунки птахів упорядковано за днями: перший елемент масиву - це підрахунок за найдавніший день, а останній - за сьогодні.

```fsharp
yesterday [| 3; 5; 0; 7; 4; 1 |]
// => 4
```

## 3. Обчисліть загальну кількість птахів, що прилітали

Реалізуйте функцію `total`, яка повертає загальну кількість птахів, що відвідали наш сад:

```fsharp
total [| 3; 5; 0; 7; 4; 1 |]
// => 20
```

## 4. Перевірте, чи був день, коли не прилетів жоден птах

Реалізуйте функцію `dayWithoutBirds`, яка повертає `true`, якщо був день, коли до саду не прилетів жоден птах; інакше повертає `false`:

```fsharp
dayWithoutBirds [| 3; 5; 0; 7; 4; 1 |]
// => true
```

## 5. Збільште підрахунок за сьогодні

Реалізуйте функцію `incrementTodaysCount`, яка збільшує сьогоднішній підрахунок і повертає оновлені підрахунки:

```fsharp
let birdCount = [| 3; 5; 0; 7; 4; 1 |]
incrementTodaysCount birdCount
// => [| 3; 5; 0; 7; 4; 2 |]
```

## 6. Перевірте, чи незвичайний цей тиждень

За останній рік ми виявили, що деякі тижні мають однакові незвичайні закономірності:
- У кожен парний день тижня не було жодного птаха
- У кожен парний день тижня помічали рівно 10 птахів
- У кожен непарний день тижня помічали рівно 5 птахів

Реалізуйте функцію `unusualWeek`, яка повертає `true`, якщо закономірність підрахунків птахів цього тижня збігається з однією з незвичайних закономірностей:

```fsharp
unusualWeek [| 1; 0; 5; 0; 12; 0; 2 |]
// => true

unusualWeek [| 5; 0; 5; 12; 5; 3; 5|]
// => true
```

(Зауважте, що парність днів нумерується з 1, а не з 0: перший елемент масиву відповідає непарному дню)
