# Вступ

Двійкові цифри зрештою прямо відповідають транзисторам у нашому процесорі чи оперативній памʼяті та їхньому стану: увімкнений чи вимкнений.

Низькорівнева робота з бітами, яку неформально називають «bit-twiddling», особливо важлива в системних мовах.

Мови вищого рівня, як-от Kotlin, зазвичай приховують більшість цих деталей. Утім, базовий набір порозрядних операцій [доступний][ref-bitwise].

## Операції зсуву бітів

Типи `Int` і `Long`, зі знаком чи без, можна подати як рядок із 1 та 0 і працювати з ними як із послідовністю бітів.

Як не дивно, типи `Byte` і `Short` несумісні з більшістю порозрядних операцій у Kotlin. У всіх наведених нижче прикладах використовуються 32-бітні цілі числа (`Int` або `UInt`).

```kotlin
val ns = 0b111  // 7 decimal
Integer.toBinaryString(ns)  // => "111"
```

Зсуви бітів просто пересувають усе ліворуч або праворуч на вказану кількість позицій. Деякі біти зникають з одного краю, а інший край доповнюється нулями чи одиницями.

- Зсув ліворуч за допомогою `shl`: доповнення нулями.
- Зсув праворуч за допомогою `shr` або `ushr`: доповнення нулями для додатних чисел (про відʼємні числа йтиметься далі).

```kotlin
val ns = 0b111  // 7 decimal
ns shl 1  // => 0b1110, decimal 14
ns shr 1  // => 0b11, decimal 3
ns ushr 1  // => 0b11

val nu: UInt = 0b111u  // 7 unsigned
nu shr 1  //  => 0b11
```

Кожен зсув ліворуч подвоює значення, а кожен зсув праворуч ділить його навпіл (з урахуванням усічення). Це помітніше в десятковому поданні:

```kotlin
3 shl 2  // => 12
24 shr 3 // => 3
```

Такий зсув бітів значно швидший за «справжню» арифметику, тож цей прийом дуже популярний у низькорівневому програмуванні.

Із _відʼємними цілими числами_ треба бути трохи обережнішими.

Відʼємні значення зберігаються у формі [доповняльного коду][wiki-2complement], а це означає, що найлівіший біт дорівнює 1. Зі зсувом ліворуч проблем немає, але як під час зсуву праворуч доповнити найлівіші біти?

```kotlin
val ns = -0b111  // => 0b11111111111111111111111111111001

// shift left: simple
ns shl 1  // => 0b11111111111111111111111111110010, decimal -14

// shift right: preserves sign bit
ns shr 1  // => 0b11111111111111111111111111111100, decimal -4

// unsigned shift right: left-pads with zeros
ns ushr 1 // => 0b01111111111111111111111111111100, decimal 2147483644
```

Оператор `shr` виконує [арифметичний зсув][wiki-arithmetic], зберігаючи знаковий біт.

Оператор `ushr` виконує [логічний зсув][wiki-logical], доповнюючи нулями так, ніби число беззнакове.

## Порозрядна логіка

Ми бачили в [концепції булевих значень][concept-booleans], що оператори `&&` (логічне і), `||` (логічне або) та `!` (логічне заперечення) застосовують до булевих значень (англ. Boolean).

Є рівнозначні оператори `and`, `or`, `xor` ([виключне або][wiki-xor]) для порівняння бітів у двох цілих числах, а також функція `inv` (інверсія), яка інвертує всі біти.

```kotlin
0b1011 and 0b0010 //  bit is 1 in both numbers
// => 0b0010

0b1011 or 0b0010 // bit is 1 in at least one number
// => 0b1011

0b1011 xor 0b0010 // bit is 1 in exactly one number, not both
// => 0b1001

0b1011.inv() // flip all bits (in a 32-bit signed Int)
// => 0b11111111111111111111111111110100
```
