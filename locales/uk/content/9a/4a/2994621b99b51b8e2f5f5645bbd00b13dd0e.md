# Інструкції

У місцевій школі неподалік дуже активна учнівська асоціація. Асоціацію учнів очолює президент, і раз на 2 роки проводять вибори, щоб обрати нового президента.

Цього року було вирішено, що для підрахунку голосів потрібна нова цифрова система. Школі потрібна наша допомога в її створенні.

## 1. Отримайте кількість голосів з `ElectionResult`

Новій системі знадобиться спосіб отримувати кількість голосів від лічильника.

Структуру результату виборів уже створено, і вона має такий вигляд:

```cpp
struct ElectionResult {
    // Name of the candidate
    std::string name{};
    // Number of votes the candidate has
    int votes{};
};
```

Оскільки всі члени `struct` є відкритими, не потрібно писати `constructor`, щоб ініціалізувати обʼєкт `ElectionResult`. Натомість можна скористатися `initializer list`:

```cpp
ElectionResult hamilton{"Alex", 1804};
// => the hamilton object was initialized with the name "Alex" and 1804 votes.
```

Створіть функцію `vote_count`, яка прийматиме посилання на `ElectionResult` як аргумент і повертатиме кількість голосів у `ElectionResult`.

```cpp
vote_count(hamilton);
// => 1804
```

## 2. Збільште кількість голосів `ElectionResult`

Нарешті час обробити голоси! Тепер потрібен спосіб збільшувати кількість голосів в `ElectionResult`.

Створіть функцію `increment_vote_count` типу `void`, яка прийматиме посилання на `ElectionResult` як аргумент і число голосів, та збільшить `ElectionResult` на це число голосів.

```cpp
ElectionResult burr{"Aaron " 1801};

increment_vote_count(burr, 3);

vote_count(burr);
// => 1804
```

## 3. Підрахунок голосів і президентство

Школа здала свої голоси, і тепер час перевірити результати, щоб визначити переможця.

Створіть функцію `determine_result`, яка приймає посилання на остаточний підрахунок і повертає посилання на `ElectionResult` нового президента. Вона також має змінити імʼя переможця, додавши на початку «President». Остаточний підрахунок подано у вигляді `reference` на `std::vector<ElectionResult>`, вектор із `ElectionResults` усіх кандидатів, які брали участь.

```cpp
ElectionResult sanchez{"Pedro", 471};
ElectionResult wheatley{"Summer", 340};
std::vector<ElectionResult> final_count{sanchez, wheatley};

ElectionResult& winner = determine_result(final_count);

winner.name;
// => "President Pedro"
```

Щоб спростити, можна припустити таке:
- `vector` має щонайменше один елемент.
- Нічиєї за перше місце не буде.
