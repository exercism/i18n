# Додаток до інструкцій

## Зарезервована памʼять

Буфер для вхідного рядка тексту (англ. string) використовує байти 64-191 лінійної памʼяті.


## Формат вихідних даних

Серія чисел подається як один неперервний масив чисел u8; під час десеріалізації його буде розбито за довжиною:

```js
slice("123456", 3) => UInt8Array[1, 2, 3,   2, 3, 4,   3, 4, 5,   4, 5, 6]
// will be split into          [[1, 2, 3], [2, 3, 4], [3, 4, 5], [4, 5, 6]]
```
