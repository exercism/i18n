# Вступ

Тип `Option` є механізмом мови F# для роботи зі значеннями, які можуть існувати або не існувати.
Він надає типобезпечну альтернативу використанню `null`, який часто застосовується в інших мовах для роботи з такими значеннями.
Він використовується в багатьох стандартних функціях бібліотеки F#, тому його розуміння є важливим для ефективного використання стандартної бібліотеки F#.

## Використання

Тип `Option` є узагальненим типом (який має базовий тип).  
Значення `Option` бувають або `Some value`, що представляє якесь конкретне значення, або `None`, що представляє відсутність значення.

Наступна функція демонструє, як створити значення `Option`:

```fsharp
let keepIfPositive (a: int) : int option = if a > 0 then Some a else None
```

~~~~exercism/note
`T option` є постфіксним синтаксисом, еквівалентним `Option<T>`; обидві синтаксичні форми можна використовувати взаємозамінно.
Однак, згідно з Керівництвом зі стилю F#, для типів Option перевага надається постфіксній нотації (див. [розділ Керівництва зі стилю F# про форматування типів і анотацій типів](https://learn.microsoft.com/en-us/dotnet/fsharp/style-guide/formatting#for-types-prefer-prefix-syntax-for-generics-foot-with-some-specific-exceptions)). 
~~~~

## Читання вмісту значення Option

Ідіоматичний спосіб прочитати значення `Option` полягає в зіставленні зі зразком, як показано в наступному прикладі:

```fsharp
// Returns "Hello, <name>!" if the name is provided; otherwise returns "Hello, you!"
let sayHello (optionalName: string option): string = 
    match optionalName with
    | Some name -> "Hello, " + name + "!"
    | None -> "Hello, you!"

sayHello (Some "Matthieu")
// --> "Hello, Matthieu!"

sayHello None
// --> "Hello, you!"
```

## Розгортання Option із типовими значеннями

Значення `Option` можна «розгорнути» (перетворити на їхній вміщений тип), надавши типові значення за допомогою функції `Option.defaultValue`.
Це особливо корисно, коли потрібно переконатися, що значення не є `None`.
Наприклад:

```fsharp
Option.defaultValue "" (Some "F#")
// --> "F#"

Option.defaultValue 0 None
// --> 0
```
