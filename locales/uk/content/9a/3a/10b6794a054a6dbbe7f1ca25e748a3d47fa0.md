# Про

Типово змінні обмежені тією областю видимості, у якій їх визначено. Якщо їх визначено у файлі поза функцією чи класом, вони обмежені областю видимості файлу. Якщо їх визначено у функції чи класі, вони обмежені областю видимості цієї функції чи класу.

```php
<?php

$file_scoped = "I am file scoped";

function example(): void
{
  $function_scoped = "I am function scoped!";
}
```

## Глобальна область видимості

Використання ключового слова `global` перед присвоєнням змінній створює змінну з глобальною областю видимості. Цей підхід часто не радять застосовувати, оскільки він створює [тісно звʼязаний код](<https://en.wikipedia.org/wiki/Coupling_(computer_programming)#Disadvantages_of_tight_coupling>).

```php
function example(): void
{
  global $hello = "World!";
}

echo $hello; // #=> "World!"
```

## Статична область видимості

Використання ключового слова `static` перед присвоєнням або оголошенням змінної зберігає область видимості змінної, але її значення зберігається між областями виконання.

```php
function counter(): int
{
  static $count = 0;
  $count += 1;
  return $count;
}
```

У цьому прикладі змінну `$count` ініціалізовано значенням 0 _лише під час першого виклику функції_. За кожного наступного виклику значення переноситься в наступний виклик. Тож кожен виклик функції повертає дедалі більше ціле число.
