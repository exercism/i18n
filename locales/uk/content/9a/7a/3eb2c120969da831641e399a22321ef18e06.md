# Докладніше

## Цикли `for`

Інструкція `for` повторює блок коду.
Її перший рядок визначає, скільки разів цей блок повторюється:

```go
for init; condition; post {
    // loop body
}
```

- Інструкція **init** виконується один раз перед першою ітерацією. Зазвичай тут оголошують та ініціалізують змінну-лічильник, яку використовує цикл.
- **condition** — це булевий вираз (англ. Boolean), який обчислюється перед кожною ітерацією. Цикл зупиняється, коли цей вираз набуває значення `false`.
- Інструкція **post** виконується після кожної завершеної ітерації. Її можна використати, щоб оновити лічильник.

Не оточуймо `init; condition; post` круглими дужками.
Однак фігурні дужки (`{ }`), які оточують тіло циклу, обовʼязкові завжди.

Цей цикл починає `i` з `1`, виводить поточне значення `i`, збільшує його для наступної ітерації та зупиняється, коли `i` сягає `10`:

```go
for i := 1; i < 10; i++ {
    fmt.Println(i)
}
```

## Інші форми циклу

### Цикл лише з умовою

Інструкції init і post можна опустити.
Інструкція `for` лише з умовою виконує ту саму роль, що й цикл `while` в інших мовах.
У Go немає ключового слова `while`.

```go
sum := 1
for sum < 1000 {
    sum += sum
}
fmt.Println(sum)
// Output: 1024
```

### Нескінченний цикл

Інструкцію `for` можна записати й без умови:

```go
for {
    // loop body
}
```

Такий цикл не завершується сам.
Виконання має вийти з циклу явно, наприклад за допомогою `break` або `return`.

## Керування циклами

### `break` і `continue`

У цьому циклі `break` перериває цикл:

```go
for n := 0; n <= 5; n++ {
    if n == 3 {
        break
    }
    fmt.Println(n)
}
// Output:
// 0
// 1
// 2
```

`continue` пропускає решту тіла поточної ітерації та починає наступну:

```go
for n := 0; n <= 5; n++ {
    if n % 2 == 0 {
        continue
    }
    fmt.Println(n)
}
// Output:
// 1
// 3
// 5
```

### `break` і `continue` з мітками

У вкладених циклах `break` або `continue` без мітки діє на найвнутрішніший цикл.
Щоб позначити зовнішній цикл, поставмо ідентифікатор із двокрапкою в рядку безпосередньо над ним.
Потім напишімо мітку циклу після `break` або `continue`, щоб спрямувати дію на нього:

```go
OuterLoop:
for i := 0; i < 10; i++ {
    for j := 0; j < 10; j++ {
        if i + j == 10 {
            break OuterLoop
        }
    }
}
```
