# Про арифметику в оболонці Bash

Bash уміє виконувати арифметичні дії, але _лише з цілими числами_.
Якщо потрібні обчислення з плаваючою комою, нам доведеться звернутися до якоїсь зовнішньої програми (наприклад, [awk][awk] або [bc][bc]).

Арифметичні оператори перелічено (у порядку пріоритету) в посібнику: [Арифметика оболонки][arithmetic].

Крім того, Bash виконує арифметичні дії лише в певних місцях (які називають арифметичними «контекстами»).

## Арифметичне розгортання

Арифметичне розгортання має такий самий вигляд, як [підстановка команд][cmd-sub], але з подвійними дужками.

```bash
$(( expression ))
```

Цей синтаксис розгортається в результат обчислення виразу.
Його часто використовують, щоб зберегти результат у змінній:

```bash
x=$(( 3 + 4 ))
```

~~~~exercism/note
Скільки пробілів ставити всередині дужок - справа смаку.
Це питання стилю та читабельності.

```bash
x=$(( 3 + 4 ))
y=$((5+6))
```

Автор, прихильний до читача, любить додавати пробіли, щоб арифметичний вираз було краще видно в дужках.
~~~~

## Арифметична умовна конструкція

Арифметичну умовну конструкцію виконують у подвійних дужках _без_ провідного `$`:

```bash
(( expression ))
```

Вона не розгортається в результат.
Натомість вона формує _статус виходу_.

* Статус виходу дорівнює 0 (успіх), якщо результат виразу **ненульовий**.
* Статус виходу дорівнює 1 (невдача), якщо результат виразу **нуль**.

~~~~exercism/note
Усередині `((` Bash використовує те саме розуміння правди та неправди, що й мова C: нуль означає неправду, а ненульове значення - правду.
**Це протилежність до того, як Bash оцінює статуси виходу!**
~~~~

Цей синтаксис зазвичай використовують у двох місцях:

1. як частину COMMAND в [умовній конструкції `if`][conditional-if] або в [циклі `while`][looping-while].

   ```bash
   if (( x == y - 1 )); then ...
   while (( y > 0 )); do ...
   ```

1. як окрему команду, щоб змінити значення змінної.

   ```bash
   (( x = x + 1 ))
   echo "new value for x is $x"
   ```

   ~~~~exercism/caution
   Будьмо обережні, поєднуючи арифметику в такий спосіб із `set -e`.
   Якщо вираз обчислюється в нуль, статус виходу буде ненульовим, і Bash завершить роботу.

   ```bash
   x=0
   (( x++ ))
   echo "you will see this"

   set -e
   x=0
   (( x++ ))
   echo "shell exits on the previous line; you won't see this"
   ```

   Докладніше про оператор `++` розповідає стаття [Postincrement vs Preincrement][incr]

   [incr]: https://thisvsthat.io/postincrement-vs-preincrement
   ~~~~


## Інші місця з арифметичним контекстом

Є ще кілька місць, де діє арифметичний контекст:

* [Арифметичний цикл `for`][looping-for].

  ```bash
  for (( i = 0; i < 10; i++ )); do
      echo "$i"
  done
  ```

* Частина з індексом у масиві з числовими індексами.

  ```bash
  echo "The next element is ${array[x + 1]}"
  # ................................^^^^^
  ```

  Докладніше про масиви читайте в документі концепції [Масиви][arrays].

* Частини зі зсувом і довжиною в розширенні `${var:offset:length}`.
* [Вбудована команда `let`][let].
  * Зауважимо, що `(( expression ))` має перевагу над `let "expresson"`.
    На відміну від арифметичної умовної конструкції, вираз `let` підлягає розгортанню імен файлів і розбиттю на слова, тож його потрібно брати в лапки.
* Присвоєння змінній, коли змінна має «атрибут цілого числа».

  ```bash
  # variable x does not have the integer attribute
  x="3 + 4"
  declare -p x      # => declare -- x="3 + 4"

  # variable y has the integer attribute
  declare -i y
  y="4 + 5"
  declare -p y      # => declare -i y="9"
  ```

  ~~~~exercism/note
  На думку автора, `declare -i` має обмежене застосування.
  Його основна перевага в тому, що він дозволяє «голу» арифметику (без синтаксису арифметичного виразу).
  Це може заплутати тих, хто читає код, адже арифметичні вирази обчислюються в несподіваних місцях.
  ~~~~

## Використання змінних в арифметичних виразах

Ось одна особливість арифметичних контекстів, яка покращує читабельність.

```bash
height=10
width=20
area=$(( height * width ))
```

Звернімо увагу: у змінних в арифметичному виразі немає знаків долара `$`.
Bash це дозволяє.
Завдяки цьому вирази читаються набагато легше.

У посібнику сказано:

> Усередині виразу на змінні оболонки можна також посилатися за іменем, не використовуючи синтаксис підстановки параметрів.

Це працює навіть для елементів масиву:

```bash
point1=(10 15)  # these are (x, y) coordinates
point2=(20 7)
distance_squared=$(( (point1[0] - point2[0])**2 + (point1[1] - point2[1])**2 ))
```

Але інші вирази з параметрами потребують свого спеціального синтаксису.
Наприклад, подвоєння довжини рядка тексту (англ. string):

```bash
s="hello world"
len=$(( ${#s} * 2 ))
```

Те саме стосується й позиційних параметрів.
Якщо перші два позиційні параметри задають ширину і висоту:

```bash
area=$(( $1 * $2 ))
```
