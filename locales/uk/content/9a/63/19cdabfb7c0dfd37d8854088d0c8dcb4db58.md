# Докладніше

Параметр методу можна зробити необовʼязковим, присвоївши йому типове значення. Коли параметр необовʼязковий, той, хто викликає метод, не зобовʼязаний передавати аргумент для цього параметра, і тоді буде використано типове значення. [Необовʼязкові параметри][optional-arguments] _мусять_ стояти в кінці списку параметрів; після них не можуть іти обовʼязкові параметри. Якщо метод має кілька необовʼязкових параметрів, можна вказати лише частину з них за допомогою [іменованих аргументів][named-arguments].

```csharp
class Card
{
    static string NewYear(int year = 2020, string sender = "me")
    {
        return $"Happy {year} from {sender}!";
    }
}

Card.NewYear();     // => "Happy 2020 from me!"
Card.NewYear(1999); // => "Happy 1999 from me!"
Card.NewYear(sender: "mom"); // => "Happy 2020 from mom!"
```

Значення необовʼязкового параметра має бути одним із такого:

- Константний вираз (наприклад, `"hi"`, `2`, `DayOfWeek.Friday`, `null` тощо)
- Вираз `new` типу-значення
- Вираз `default` типу-значення
