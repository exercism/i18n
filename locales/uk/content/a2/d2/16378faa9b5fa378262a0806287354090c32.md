# Про `Enum`

`Enum` - це дуже корисний модуль, який надає набір алгоритмів для роботи з перелічуваними даними. Він пропонує:

- сортування ([`sort/2`][enum-sort/2], [`sort_by/2`][enum-sort_by/2]),
- фільтрування ([`filter/2`][enum-filter/2]),
- групування ([`group_by/3`][enum-group_by/3]),
- підрахунок ([`count/2`][enum-count/2])
- пошук ([`find/3`][enum-find/3]),
- пошук мінімальних і максимальних значень ([`min/3`][enum-min/3], [`max/3`][enum-max/3]),
- згортання ([`reduce/3`][enum-reduce/3], [`reduce_while/3`][enum-reduce_while/3]),

І це ще не все! Повний перелік шукайте в [документації модуля `Enum`][enum-functions].

## Перелічуване

Загалом _перелічуване_ - це будь-які дані, які можна перебрати, тобто колекція. В Elixir перелічуване - це будь-який тип даних, який реалізує [протокол][exercism-protocols] `Enumerable`. Це:

- [`List`][list]
- [`Map`][map]
- [`Range`][range]
- [`Stream`][stream]
- [`MapSet`][mapset]
- [`Function`][function]
- [`Date.Range`][date-range]
- [`IO.Stream`][io-stream]
- [`File.Stream`][file-stream]

Не варто хвилюватися, якщо ми ще не знаємо їх усіх.

Будь-хто може реалізувати протокол `Enumerable` для власної структури даних.

## Згортання

`Enum.reduce/2` дає змогу _згорнути_ все перелічуване до одного значення. Для цього використовується спеціальна змінна, яку називають _акумулятором_. Акумулятор зберігає проміжний стан згортання між ітераціями. Саме тому це одна з найпотужніших функцій для перелічуваних даних. Багато інших спеціалізованих функцій можна замінити загальнішою `reduce`. Наприклад...

Пошук максимального значення:

```elixir
Enum.max([4, 20, 31, 9, 2])
# => 31

Enum.reduce([4, 20, 31, 9, 2], nil, fn x, acc ->
  cond do
    acc == nil -> x
    x > acc -> x
    x <= acc -> acc
  end
end)

# => 31
```

І навіть перетворення (але після цього результат доведеться перевернути):

```elixir
Enum.map([1, 2, 3, 4, 5], fn x -> x + 10 end)
# => [11, 12, 13, 14, 15]

Enum.reduce([1, 2, 3, 4, 5], [], fn x, acc -> [x + 10 | acc] end)
# => [15, 14, 13, 12, 11]
```

## Перетворення словників

- За допомогою [`Map.new/2`][map-new]:
  ```elixir
  %{a: 1, b: 2}
  |> Map.new(fn {key, value} -> {key, value * 10} end)
  ```

- За допомогою [`Enum.into/3`][enum-into]:
  ```elixir
  %{a: 1, b: 2}
  |> Enum.into(%{}, fn {key, value} -> {key, value * 10} end)
  ```

- За допомогою [`Enum.map/2`][enum-map]:
  ```elixir
  %{a: 1, b: 2}
  |> Enum.map(fn {key, value} -> {key, value * 10} end)
  |> Enum.into(%{})
  ```
