# Докладніше

[Структури та класи][structs-and-classes] - це два з основних будівельних блоків програмування мовою Swift. Обидва вони дають змогу обʼєднати повʼязані дані та функції в самодостатні одиниці функціональності. Усі базові типи, з якими ми працювали досі, як-от `Int`, `Double` і `Character`, а також колекційні типи на кшталт `Array`, `String` і `Dictionary`, насправді є структурами. А коли ми визначаємо структуру чи клас, ми визначаємо новий тип, який можна використовувати в Swift, так само як ми використовували ті типи.

Між структурами та класами в Swift є багато спільного. Крім іншого, обидва вони вміють зберігати значення у _властивостях_ і надавати функціональність за допомогою _методів_.

Кожен із них надає ще й додаткову функціональність, яка виходить за межі цієї вправи.

## Визначення структур

Структура визначається за допомогою ключового слова `struct`, після якого йде назва типу, що визначається, а потім тіло, вміщене у фігурні дужки.

Тіло може складатися зі збережених властивостей, які визначаються й поводяться так само, як звичайні константи чи змінні.

```swift
struct CharacterStats {
  var health = 0.0
  var speed = 0
  var strength = 0
}
```

## Примірники

Як зазначено вище, визначити структуру - це лише визначити новий _тип_. Це всього лише креслення того, який вигляд матимуть значення цього типу, але воно не створює жодних значень цього типу, з якими можна працювати.

Щоб створити _примірник_ цього типу, треба написати назву типу, а потім пару дужок.

```swift
let someStats = CharacterStats()
```

Це створить значення цих типів, де властивості заповнюються типовими значеннями, указаними у визначенні.

Для структур Swift автоматично надає так званий _ініціалізатор за членами_, у якому значення для властивостей структури можна передати всередині дужок, і вони перекриють типові значення з визначення.

```swift
let differentStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

## Доступ до властивостей

До властивостей структури можна звертатися за допомогою _точкової нотації_: після назви значення ставиться крапка (`.`) і назва властивості. Якщо властивість структури має власні властивості, цю точкову нотацію можна використати й для доступу до таких вкладених властивостей.

Цю нотацію можна використовувати і для читання значення властивості, і, де це дозволено, для його зміни.

```swift
someStats.health
// => 0
someStats.health = 87.3
someStats.health
// => 87.3
```
