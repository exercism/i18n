# Докладніше

Оскільки Clojure є функціональною мовою, функції в ній мають статус повноправних обʼєктів. Це означає, що їх можна передавати іншим функціям і створювати за допомогою інших функцій так само, як і дані. Зокрема, Clojure має багатий набір функцій вищого порядку, які утворюють нові функції на основі наявних. Тут ми розглянемо чотири важливі випадки: `partial`, `comp`, `memoize` і `juxt`. Ці функції, що породжують функції, належать до ширшої категорії функцій вищого порядку, як-от `map`, `reduce`, `apply`, `complement`, та багато інших, які працюють з наявними функціями.

## partial

Загалом, маючи наявну функцію `my-function` з параметрами `p1, p2, ..., pN`, ми можемо зафіксувати частину її параметрів `p1, p2, ..., pM`, надавши їм сталі значення `v1, v2, ..., vM`. Для цього ми застосовуємо `partial` так: `(partial my-function v1 v2 ... vM)`. 

Результат - нова функція, яка застосовує початкову функцію `my-function`, зафіксувавши `p1=v1, p2=v2, ..., pM=vM`. Наша нова функція приймає на вхід решту параметрів `pM+1, pM+2, ..., pN`, значення яких не було вказано під час застосування `partial`:

```clojure
(def my-new-function 
  (partial my-function v1 v2 ... vM))
(my-new-function xM+1 xM+2 ... xN)
; => equivalent to (my-function v1 v2 ... vM xM+1 xM+2 ... xN)
```

Як простий приклад, визначмо функцію `inc-by-9`, яка збільшує на фіксовану величину 9 будь-яке передане їй значення. Ми могли б реалізувати таку функцію так:

```clojure
(def inc-by-9 (partial + 9))
(inc-by-9 5)
; => 14
```

Як другий приклад візьмімо функцію `generic-greetings`, яка використовує імʼя людини, яку ми хочемо привітати, разом із початковим і кінцевим повідомленнями:

```clojure
(defn generic-greetings
  [initial-text final-text name]
  (println (str initial-text name final-text)))
```

І застосуймо `partial`, щоб завжди використовувати конкретне вітальне повідомлення:

```clojure
(def say-hello-and-how-are-you-doing 
  (partial generic-greetings "Hello " ", how are you doing?"))
(say-hello-and-how-are-you-doing "Mary")
; => Hello Mary, how are you doing?
```

## comp

`comp` можна використати, щоб створити композицію з будь-якої кількості функцій, які ми хочемо скомпонувати. Загалом, композиція `N` функцій `f1, f2, ..., fN` означає застосування цих функцій у послідовному порядку, коли вихідні дані попередньої функції передаються наступній. У математичному записі це має такий вигляд:

```
f1 (f2 (... fN(x)))
```

У Clojure це рівнозначно такому запису:
```clojure
(f1 (f2 (... (fN x))))
```

Застосувавши comp, ми можемо створити нову функцію, яка виконує цю композицію за нас:

```clojure
(def my-function-composition 
  (comp f1 f2 ... fN))
(my-function-composition x)
; equivalent to
(f1 (f2 (... (fN x))))
```

Наприклад, припустімо, ми хочемо додати кілька чисел, а потім помножити результат на 6. Ми можемо зробити це так:


```clojure
(def six-times-result-sum 
  (comp (partial * 6) +))
(six-times-result-sum 3 2)
; = ((partial * 6) (+ 3 2))
; = (* 6 (+ 3 2))
; = 30
```

## memoize

`memoize` дає змогу повторно використовувати раніше обчислені результати, повʼязані з певним вхідним значенням. За того самого вхідного значення *мемоізована* функція повертає той самий результат без потреби обчислювати його знову. Вона використовує той факт, що функції `clojure` за замовчуванням *референційно прозорі*: за того самого вхідного значення вони завжди дають той самий результат, що дає змогу легко повторно використовувати попередні обчислення. 

Щоб побачити, як це працює, скористаймося штучним прикладом, де функція засинає на дві секунди перед тим, як видати результат, щоб ми могли легко порівняти *час обчислення* до і після застосування `memoize`.

```clojure
(defn my-time-consuming-fn
    "Original, time-consuming function"
    [x]
    (Thread/sleep 2000)
    (* x 2)
)

; We measure the time it takes for the original function
(time (my-time-consuming-fn 3))
; => "Elapsed time: 2007.785622 msecs"
; => 6

; We define a memoized function
(def my-memoized-fn 
  (memoize my-time-consuming-fn) )

; We call the memoized function and measure its execution time. 
; The first execution actually runs the function, taking
; similar time as the original.
(time (my-memoized-fn 3))
; => "Elapsed time: 2001.364052 msecs"
; => 6

; Subsequent calls reuse the previous computation, taking less
; time. Time is further reduced in additional calls.
(time (my-memoized-fn 3))
; => "Elapsed time: 1.190291 msecs"
; => 6

(time (my-memoized-fn 3))
; => "Elapsed time: 0.043701 msecs"
; => 6

; Changing the input makes the function be executed, so that
; we observe a similar computation time as the original 
(time (my-memoized-fn 4))
; => "Elapsed time: 2000.29306 msecs"
; => 8

; Again, repeating the same input will make the 
; execution be skipped, and the associated output returned
(time (my-memoized-fn 4))
; => "Elapsed time: 0.043701 msecs"
; => 8
```

## juxt

`juxt` породжує функцію, яка застосовує передані їй функції в порядку зліва направо. Результат - вектор, компонентами якого є окремі результати кожної функції: 

```clojure
((juxt f g h) x) ; => [(f x) (g x) (h x)]
```

Як простий приклад, створімо функцію, яка обчислює добуток x на послідовні множники від 2 до 5:
```clojure
((juxt (partial * 2) (partial * 3) (partial * 4) (partial * 5)) 10) ; => [20 30 40 50]
```
