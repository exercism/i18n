# Докладніше

PowerShell - це динамічна мова сценаріїв із неявною типізацією (_яка також підтримує [строго типізовані][strong typed] змінні_) від Microsoft, зосереджена переважно на автоматизації завдань і керуванні конфігурацією.

PowerShell підтримує імперативний, функціональний, обʼєктно-орієнтований і навіть конвеєрний стиль програмування.

PowerShell створено на платформі .NET і вперше випущено 2006 року.
Його типово включено до всіх сучасних операційних систем Windows, а також можна встановити на Mac і Linux.


## Змінні

У PowerShell є два поширені способи визначити змінну.

Назви змінних у PowerShell мають починатися з `$`, а оператор присвоєння `=` привʼязує назву змінної до значення.

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

Ми можемо також явно вказати тип змінної, якщо хочемо, щоб значення мало певний тип.
PowerShell намагатиметься якнайкраще перетворити значення з одного типу на інший, якщо це можливо.

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```

### Константи

Константи в PowerShell - це змінні, які не можна **змінити** чи **видалити** після визначення.
Це приводить нас до другого способу визначення змінних: використання командлета `New-Variable`.

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
100
```


## Функції

Функції в PowerShell визначають за допомогою ключового слова `function`.
Кожна функція може мати нуль або більше формальних параметрів у дужках `()`, після чого йде область видимості функції, яка починається з `{` і закінчується `}`.

```powershell
function Greeting {
    return "Hello!"
}
```

Функції в PowerShell можуть явно повертати значення через ключове слово `return`; викликають їх із синтаксисом `FuncName $Arg`.

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

## Коментарі

Однорядкові коментарі в PowerShell починаються з `#` і закінчуються в кінці рядка.
Блоки коментарів у PowerShell починаються з `<#` і закінчуються `#>`.

```powershell
function Main() {
    #This is a comment
    <#
    And this is a comment block
    that can span multiple lines
    #>
}
```
