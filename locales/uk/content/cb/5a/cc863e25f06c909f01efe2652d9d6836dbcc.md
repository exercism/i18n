# Інструкції

Якщо ми захоплюємося шахами, то нам захочеться написати власну версію цієї гри.
Так, в інтернеті вже є чимало готових реалізацій шахів, але наша буде неповторною!

Почнімо з реалізації шахівниці.

Гра відбуватиметься на дошці, що має вісім клітинок завширшки і вісім клітинок завдовжки.
Кожну клітинку позначають літерою та числом.

## 1. Визначте діапазон горизонталей і вертикалей

Гра має зберігати горизонталі дошки.
Горизонталями називають ряди дошки, пронумеровані від 1 до 8.

Гра також має зберігати вертикалі дошки.
Вертикалями називають стовпці дошки, позначені літерами від A до H.

Визначте константи `ranks` і `files`, які зберігають діапазони горизонталей і вертикалей відповідно.

```swift
ranks
// Returns 1..8

files
// Returns "A".."H"
```

## 2. Перевірте, чи клітинка коректна

Гра має перевіряти, чи клітинка коректна.
Клітинка коректна, якщо її горизонталь і вертикаль належать діапазонам горизонталей і вертикалей.

Визначте метод `isValidSquare(rank:file:)`, який приймає аргументи `rank` типу `Int` із номером горизонталі та `file` типу `String` із літерою вертикалі.
Метод має повернути `true`, якщо горизонталь і вертикаль належать діапазонам горизонталей і вертикалей, і `false` в іншому разі.

```swift
isValidSquare(rank: 1, file: "A")
// Returns true
```

## 3. Отримайте ряд

Гра зберігатиме всі клітинки дошки в одновимірному масиві.
Кожна клітинка утворюється як рядок тексту (англ. string) з горизонталі та вертикалі, наприклад "1A", "8B", "4G" тощо.
Щоб отримати ряд, у якому розташована клітинка, гра має обчислити індекс першої клітинки цього ряду.

Визначте метод `getRow(rank:)`, який приймає аргумент `rank` типу `Int` із номером горизонталі.
Метод має повернути масив рядків тексту, які представляють клітинки цього ряду.

```swift
let board = ["1A", "1B", "1C", "1D", "1E", "1F", "1G", "1H", "2A", ..., "8H"]
getRow(board, rank: 1)
// Returns ["1A", "1B", "1C", "1D", "1E", "1F", "1G", "1H"]
```
