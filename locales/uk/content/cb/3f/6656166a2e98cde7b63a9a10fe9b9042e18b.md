# Інструкції

У цій вправі ми будемо гратися з радіокерованою машинкою, на яку ми нарешті назбирали грошей, щоб купити.

Машинки починають із повним (100%) зарядом батареї. Щоразу, коли ми керуємо машинкою з пульта, вона проїжджає 20 метрів і витрачає один відсоток заряду батареї.

Радіокерована машинка має вишуканий світлодіодний дисплей, який показує дві частини інформації:

- Загальну відстань, яку вона проїхала, у такому вигляді: `"Driven <METERS> meters"`.
- Залишок заряду батареї у такому вигляді: `"Battery at <PERCENTAGE>%"`.

Якщо заряд батареї сягає 0%, ми більше не можемо керувати машинкою, і дисплей батареї покаже `"Battery empty"`.

На нас чекає шість завдань, кожне з яких працюватиме з екземплярами радіокерованої машинки.

## 1. Купити новісіньку радіокеровану машинку

Реалізуйте (_стат_) `JedliksToyCar.buy()` метод, який повертає новісінький екземпляр радіокерованої машинки:

```java
JedliksToyCar car = JedliksToyCar.buy();
```

## 2. Показати пройдену відстань

Реалізуйте метод `JedliksToyCar.distanceDisplay()`, який повертає відстань у тому вигляді, як її показано на світлодіодному дисплеї:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.distanceDisplay();
// => "Driven 0 meters"
```

## 3. Показати відсоток заряду батареї

Реалізуйте метод `JedliksToyCar.batteryDisplay()`, який повертає відсоток заряду батареї у тому вигляді, як його показано на світлодіодному дисплеї:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.batteryDisplay();
// => "Battery at 100%"
```

## 4. Оновлювати кількість пройдених метрів під час руху

Реалізуйте метод `JedliksToyCar.drive()`, який оновлює кількість пройдених метрів:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.drive();
car.drive();
car.distanceDisplay();
// => "Driven 40 meters"
```

## 5. Оновлювати відсоток заряду батареї під час руху

Оновіть метод `JedliksToyCar.drive()` так, щоб він оновлював відсоток заряду батареї:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.drive();
car.drive();
car.batteryDisplay();
// => "Battery at 98%"
```

## 6. Заборонити рух, коли батарея розряджена

Оновіть метод `JedliksToyCar.drive()` так, щоб він не збільшував пройдену відстань і не зменшував відсоток заряду батареї, коли батарея розряджена (0%):

```java
JedliksToyCar car = JedliksToyCar.buy();

// Drain the battery
// ...

car.distanceDisplay();
// => "Driven 2000 meters"

car.batteryDisplay();
// => "Battery empty"
```
