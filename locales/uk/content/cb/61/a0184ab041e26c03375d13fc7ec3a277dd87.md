# Вступ

Python - це [динамічна й строго типізована][dynamic typing in python] мова програмування. Вона поєднує [качину типізацію][duck typing] і [поступову типізацію][gradual typing] за допомогою [підказок типів][type hints]. Python приділяє велику увагу читабельності коду та (_подібно до Haskell_) використовує [значущі відступи][significant indentation], щоб позначати визначення функцій, методів і класів.

Python створив Гвідо ван Россум, а вперше мову випустили 1991 року.

Підтримуються всі _стилі_ програмування: імперативний, декларативний (наприклад, функціональний) та обʼєктно-орієнтований, але внутрішньо **[усе в Python є обʼєктом][everythings an object]**.

Ми ще докладніше розберемо, що все це означає, коли рухатимемося далі концепціями треку Python.

Ця перша концепція (`basics`) знайомить із 4 основними можливостями мови Python:
1.  Присвоєння імен (_змінні та константи_),
2.  Функції (ключове слово `def` і ключове слово `return`),
3.  Коментарі, і
4.  Рядки документації.

<br>

## Присвоєння імен (змінні та константи)

Програмісти можуть привʼязувати [_імена_][facts-and-myths-about-python-names] (їх також називають _змінними_) до обʼєктів будь-якого типу за допомогою оператора присвоєння `=`: `<name> = <value>`. Протягом свого життя імʼя можна присвоїти повторно (або привʼязати заново) до інших значень (інших типів обʼєктів):


```python
>>> my_first_variable = 1  # <--my_first_variable bound to an integer object of value one.
>>> my_first_variable = 2  # <--my_first_variable re-assigned to integer value 2.

>>> print(type(my_first_variable))
<class 'int'>

>>> print(my_first_variable)
2

>>> my_first_variable = "Now, I'm a string." # <--You may re-bind a name to a different object type and value.
>>> print(type(my_first_variable))
<class 'str'>

>>> my_first_variable = 'You can call me "str".' # <--Strings can be declared using single or double quote marks.
>>> print(my_first_variable)
You can call me "str".
```


### Константи

Константи - це імена, які мають бути присвоєні в програмі лише один раз, хоч Python і не забороняє повторного присвоєння.
Запис `SCREAMING_SNAKE_CASE` підказує кожному, хто читає код, що імʼя **не** варто присвоювати повторно і що його значення не можна змінювати.
Константи варто визначати на рівні [модуля][module] (файлу), і зазвичай вони видимі для всіх функцій і класів у програмі.



## Функції

[Визначення функції][function definition] починає ключове слово `def`.
Кожна функція може мати нуль або більше формальних [параметрів][parameters] у дужках `()`, після яких іде двокрапка `:`.
Інструкції _тіла_ функції починаються з наступного після `def` рядка і мають бути _відступлені як блок_.


```python
# The body of this function is indented by 2 spaces & prints the sum of the numbers.
def add_two_numbers(number_one, number_two):
  total = number_one + number_two
  print(total)  

>>> add_two_numbers(3, 4)
7


# Inconsistent indentation in your code blocks will raise an error.
>>> def add_three_numbers_misformatted(number_one, number_two, number_three):
...     result = number_one + number_two + number_three   # This was indented by 4 spaces.
...    print(result)     # <--This was only indented by 3 spaces.
...
...
  File "<stdin>", line 3
    print(result)
    ^
IndentationError: unindent does not match any outer indentation level
```


Функції _явно_ повертають значення або обʼєкт за допомогою ключового слова [`return`][return]:


```python
# Function definition on first line, explicit return used on final line.
def add_two_numbers(number_one, number_two):
  return number_one + number_two   


# Calling the function in the Python shell returns the sum of the numbers.
>>> add_two_numbers(3, 4)
7

# Assigning the function call to a variable and printing 
# the variable will also return the value.
>>> sum_with_return = add_two_numbers(5, 6)
>>> print(sum_with_return)
11
```


Функції, у яких після `return` немає _явного_ виразу, _неявно_ повертають обʼєкт [`None`][none].
Подробиці про `None` ми розглянемо в наступній концепції.
У межах цієї вправи та цього пояснення `None` - це заповнювач, який позначає ніщо, або null:


```python
# This function will return `None`
def square_a_number(number):
    square = number * number
    return # <-- note that this return is not followed by an expression

# Calling the function in the Python shell appears 
# to not return anything at all.
>>> square_a_number(2)
>>>


# Using print() with the function call shows that 
# the function is actually returning the **None** object.
>>> print(square_a_number(2))
None
```

Функції, у яких `return` узагалі відсутній, теж _неявно_ повертають обʼєкт [`None`][none].
Це означає, що якщо ми не використовуємо `return` у функції, Python поверне обʼєкт `None` за нас.

```python
# This function omits a return keyword altogether.
def add_two_numbers(number_one, number_two):
  result = number_one + number_two

>>> add_two_numbers(5, 7)
>>> print(add_two_numbers(5, 7))
None

# Assigning the function call to a variable and printing 
# the variable will also show None.
>>> sum_without_return = add_two_numbers(5, 6)
>>> print(sum_without_return)
None
```


## Коментарі

[Коментарі][comments] в Python починаються з `#`, який не є частиною рядка тексту (англ. string), і закінчуються в кінці рядка.
На відміну від багатьох інших мов програмування, Python **не підтримує** позначок для багаторядкових коментарів.
Кожен рядок блоку коментарів має починатися із символу `#`.


## Рядки документації

Першою інструкцією тіла функції може бути [_рядок документації_][docstring], який стисло описує призначення функції чи обʼєкта.
Рядки документації читають автоматичні інструменти документації, як-от [Sphinx][sphinx], і їх отримують, викликавши спеціальний атрибут `.__doc__` у назви функції, методу чи класу.
Загальні домовленості щодо рядків документації викладено в [PEP257][pep257], але точний формат залежить від проєкту та команди.
Рядки документації оголошують за допомогою потрійних подвійних лапок (""") з відступом на тому самому рівні, що й блок коду:
