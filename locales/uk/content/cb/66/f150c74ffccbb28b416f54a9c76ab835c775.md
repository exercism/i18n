# Інструкції

У цій вправі ми створимо кілька констант, які використовуються в роботі банку.

Маємо пʼять завдань:

## 1. Позначте фіксовану відсоткову ставку за кредитом

Створіть нетипізовану числову константу `FixedInterestRate` для зберігання значення 5% (5/100), а потім реалізуйте функцію `GetFixedInterestRate`, яка його повертає:

```go
GetFixedInterestRate()
// => 0.05
```

## 2. Позначте кількість днів у році

Створіть константу `DaysPerYear` типу `int` для зберігання значення 365, а потім реалізуйте функцію `GetDaysPerYear`, яка його повертає:

```go
GetDaysPerYear()
// => 365
```

## 3. Позначте місяці року

У блоці скористайтеся перелічувачем Go, щоб створити дванадцять нетипізованих числових констант зі значеннями від 1 до 12 для місяців року.
Назвіть їх `Jan`, `Feb`, `Mar` тощо, а потім реалізуйте функцію `GetMonth`, яка повертає значення для заданого місяця:

```go
GetMonth(Jan)
// => 1
```

## 4. Позначте номер рахунку

Створіть нетипізовану константу `AccountNo` типу рядок тексту (англ. string) для зберігання значення XF348IJ, а потім реалізуйте функцію `GetAccountNumber`, яка його повертає:

```go
GetAccountNumber()
// => "XF348IJ"
```
