# Інструкції

Ми — телеграфісти бездротового звʼязку на вантажному судні. Сигнал надходить зашумленою лінією (корабельні механізми, атмосферні завади, уривки чужої мови), переплітаючись із тим кодом Морзе, який ми шукаємо. Щоб упіймати повідомлення, ми пропускаємо дріт крізь пристрій-*стрічку*, який відкидає все, крім дійсних символів коду Морзе (`.`, `-` і пробіл, що розділяє літери).

Наше завдання — збудувати стрічку як власний вхідний потік Factor.

## 1. Визначте стрічку

Визначте кортеж `tape`, який успадковує `disposable` і містить один слот `wire` для базового вхідного потоку.

```factor
TUPLE: tape < disposable wire ;
```

Потім напишіть конструктор `<tape> ( wire -- tape )`. Використайте `new-disposable` (а не `new`), щоб framework деструкторів зареєстрував стрічку, і збережіть базовий потік у слоті `wire`.

## 2. Долучіть міксин input-stream

Оголосіть `tape` як `input-stream`:

```factor
INSTANCE: tape input-stream
```

Завдяки цьому типові комбінатори протоколу звертаються до нашого класу.

## 3. Прочитайте один символ коду Морзе

Реалізуйте `M: tape stream-read1 ( tape -- elt/f )`. Читайте байти з базового дроту, доки не натрапите на один із символів `CHAR: .`, `CHAR: -` або `CHAR: \s` (пробіл). Поверніть цей байт. Якщо дріт повертає `f` (кінець потоку), поверніть і `f`: стрічка закінчилася.

```factor
"x.y -ab cz" <string-reader> <tape>
[ stream-read1 ] [ stream-read1 ] [ stream-read1 ] tri
! => CHAR: . CHAR: - CHAR: \s
```

## 4. Делегуйте тип елемента

Реалізуйте `M: tape stream-element-type ( tape -- type )`, делегувавши роботу дроту: стрічка не змінює тип елементів, які читаються.

## 5. Приберіть за собою

Реалізуйте `M: tape dispose* ( tape -- )`. Framework викликає наш метод рівно один раз на кожен `dispose`; просто звільніть базовий дріт.

Коли ці пʼять частин на місці, стрічка працює як звичайний вхідний потік: `with-input-stream`, `stream-read` та інші слова протоколу автоматично звертаються до наших методів.
