# Вступ

Щоб ознайомитися з основами аргументів функцій, звернімося до [концепції функцій][function concept].

## Назви параметрів

[Назви параметрів][parameters], як і назви змінних, мають починатися з літери або знака підкреслення і можуть містити літери, знаки підкреслення або цифри.
Назви параметрів не повинні містити пробілів або розділових знаків.


## Позиційні аргументи

Позиційними аргументами називають значення, які передаються у функцію в тому самому порядку, у якому йдуть параметри, що їм відповідають.
Їх також можна передавати, вказуючи назву відповідного параметра:


```python
def concat(greeting, name):
    return f"{greeting}{name}"
 
# Passing data to the function by position.
print(concat("Hello, ", "Judy"))
#->  Hello, Judy

# Passing data to the function using the parameter name.
print(concat(name="Sally", greeting="Hello, "))
#-> Hello, Sally
```

Перший виклик concat передає аргументи за позицією.
Другий виклик concat передає аргументи за _назвою_, що дозволяє змінювати їхній порядок.

Зауважмо, що позиційні аргументи не можуть іти після аргументів, переданих за назвою (_їх також називають [іменованими аргументами][keyword-arguments]. **Не** варто плутати їх з варіативними позиційними параметрами або [**kwargs][kwargs]**).

Такий набір аргументів:

```python
>>> print(concat(greeting="Hello, ", "Zed"))
```

призведе до такої помилки:

```
SyntaxError: positional argument follows keyword argument
```

## Типові значення аргументів

[Типові значення][default arguments] для одного чи кількох аргументів можна вказати у списку параметрів.
Це дозволяє викликати функцію з _меншою_ кількістю аргументів, якщо потрібно.
Типові значення можна перевизначити, викликавши функцію з новими аргументами замість типових:


```python
# Note the default arguments for both greeting and name.
def concat(greeting="Hello, ", name="you"):
    return f"{greeting}{name}"
 
# Function call overriding the defaults
print(concat(name="Jerry", greeting="Hello, "))
#-> Hello, Jerry

# Function call without arguments resulting in the defaults being used.
print(concat())
#-> Hello, you
```

## Іменовані аргументи

Іменовані аргументи використовують назву параметра, коли ми передаємо аргументи у функцію.
Їх також можна вказувати за позицією:


```python
# Note the default arguments for both greeting and name.
def concat(greeting="Hello, ", name="you"):
    return f"{greeting}{name}"

# Function call using parameter names as argument keywords.
print(concat(name="Jerry", greeting="Hello, "))
#-> Hello, Jerry

# Function call with positional data as arguments.
print(concat("Hello, ", "Isaac"))
#-> Hello, Isaac
```
