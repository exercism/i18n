# Вступ

## Арифметичні оператори

JavaScript надає 6 різних операторів для виконання базових арифметичних дій над числами.

- `+`: Оператор додавання знаходить суму чисел.
- `-`: Оператор віднімання знаходить різницю між двома числами
- `*`: Оператор множення знаходить добуток двох чисел.
- `/`: Оператор ділення ділить два числа.

```javascript
2 - 1.5; //=> 0.5
19 / 2; //=> 9.5
```

- `%`: Оператор остачі від ділення показує, скільки залишається після ділення.

  ```javascript
  40 % 4; // => 0
  -11 % 4; // => -3
  ```

- `**`: Оператор піднесення до степеня обчислює степінь числа.

  ```javascript
  4 ** 3; // => 64
  4 ** 1 / 2; // => 2
  ```

## Порядок виконання операцій

Коли в одному рядку використовується кілька операторів, JavaScript дотримується порядку пріоритету, як показано в [цій таблиці пріоритетів][mdn-operator-precedence].
Якщо спростити це до нашого контексту, JavaScript використовує правило PEDMAS (дужки, степені, ділення/множення, додавання/віднімання), яке ми вивчали на уроках математики в молодших класах.

<!-- prettier-ignore-start -->
```javascript
const result = 3 ** 3 + 9 * 4 / (3 - 1);
// => 3 ** 3 + 9 * 4/2
// => 27 + 9 * 4/2
// => 27 + 18
// => 45
```
<!-- prettier-ignore-end -->

## Скорочені оператори присвоєння

Скорочені оператори присвоєння - це коротший спосіб записати код, який виконує арифметичні дії над змінною й присвоює нове значення тій самій змінній.
Наприклад, візьмімо дві змінні `x` та `y`.
Тоді `x += y` - це те саме, що `x = x + y`.
Часто це використовують із числом замість змінної `y`.
Інші 5 операцій можна виконувати так само.

```javascript
let x = 5;
x += 25; // x is now 30

let y = 31;
y %= 3; // y is now 1
```
