# Доповнення до інструкцій

## Регістри

| Регістр | Використання | Тип           | Опис                             |
| ------- | ------------ | ------------- | -------------------------------- |
| `$a0`   | вхідні дані  | ціле число    | індекс простого числа            |
| `$v0`   | вихідні дані | ціле число    | значення n-го простого числа     |
| `$t0-9` | тимчасовий   | будь-який     | для тимчасового зберігання       |
