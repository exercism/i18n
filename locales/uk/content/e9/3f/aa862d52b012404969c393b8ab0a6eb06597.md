# Вступ

Концепція [`Basics`][basics] представила два способи визначення функції.

Найчастіше використовують багаторядкову форму:

```julia
function muladd(x, y, z)
    x * y + z
end
```

Форма «присвоєння», або «однорядкова», для коротких визначень:
```julia
muladd(x, y, z) = x * y + z
```

У третій, ще коротшій формі коротку функцію для одноразового використання можна створити без назви:

```julia-repl
julia> map(x -> 2x, 1:3)
4-element Vector{Int64}:
 2
 4
 6

julia> map((x, y) -> x * y, 1:3, 4:6)
3-element Vector{Int64}:
  4
 10
 18
```

У цьому випадку `x -> 2x` називають «анонімною функцією».
Це відповідає тому, що в деяких інших мовах називають «лямбда-функцією».

Зауважмо, що кілька аргументів потребують дужок, як у `(x, y) -> x * y`.

Анонімні функції часто трапляються в коді Julia, особливо в поєднанні з функціями вищого порядку, такими як `map()` і `filter()`.

## Аргументи функції

Досі в силабусі ми розглядали лише функції з точною кількістю аргументів, які вимагають, щоб виклики функції надавали всі з них у правильному порядку.
Це було б надто обмежувально й незручно, тож є кілька інших можливостей.

### Необовʼязкові аргументи

Як і багато мов, Julia дозволяє у визначенні функції задавати типові значення для окремих аргументів.

Тоді виклик функції може або надати значення для цього аргументу, або пропустити його й покластися на типове значення.

```julia-repl
julia> f(x, y=10) = x * y
f (generic function with 2 methods)

julia> f(2, 3)
6

julia> f(2)
20
```

Усі аргументи _без_ типових значень мають іти перед будь-якими аргументами _з_ типовими значеннями, тож `f(x=2, y)` було б некоректним.

### Іменовані аргументи

У всіх прикладах досі використовувалися `positional arguments`, де значення, надані у виклику функції, мають збігатися з порядком відповідних аргументів у визначенні функції.

Як і багато мов, Julia також дозволяє `keyword arguments`.
У виклику функції потрібно вказати назву аргументу, але кілька іменованих аргументів тоді можна вказати в будь-якому порядку.

Характерна особливість Julia полягає в тому, що іменованим аргументам (якщо вони є) у визначенні функції має передувати крапка з комою `;`, яка відокремлює їх від будь-яких позиційних аргументів.
У виклику функції можна використати `;` або `,` між останнім позиційним аргументом і першим іменованим аргументом.

```julia-repl
julia> b(x; y) = x + y
b (generic function with 1 method)

julia> b(2, y=3)
5

# keyword is required when calling
julia> b(2, 3)
ERROR: MethodError: no method matching b(::Int64, ::Int64)
The function `b` exists, but no method is defined for this combination of argument types.
```

Типові значення можна за бажанням вказати, точно як для позиційних аргументів.

Часто у виклику функції доводиться писати синтаксис на кшталт `myarg=myarg`, коли змінну з тією самою назвою, що й параметр, було обчислено заздалегідь.
У цій ситуації дозволено скорочений синтаксис:

```julia-repl
julia> width = 4.0
4.0

julia> height = √ width
2.0

julia> area(; width, height) = width * height
area (generic function with 1 method)

# repetition
julia> area(; width=width, height=height)
8.0

# shorthand form
julia> area(; width, height)
8.0
```

### Splat і slurp

Це стандартні назви для корисної особливості синтаксису Julia, якщо раптом цікаво.
Обидві стосуються оператора `...`.

#### Splat

Splat застосовують у _викликах_ функцій, щоб розгорнути колекції в окремі значення, потрібні функції.

Це, мабуть, легше показати, ніж пояснити:

```julia-repl
julia> fxyz(x, y, z) = x * y * z
fxyz (generic function with 1 method)

julia> xyz = [2, 3, 4]
3-element Vector{Int64}:
 2
 3
 4

# Using the vector directly in a function call is invalid
julia> fxyz(xyz)
ERROR: MethodError: no method matching fxyz(::Vector{Int64})
The function `fxyz` exists, but no method is defined for this combination of argument types.

# splatting converts the vector to 3 numbers, used as positional arguments
julia> fxyz(xyz...)
24
```

Деякі «виклики функцій» приховані синтаксичним цукром, тож splat можна застосувати й у менш очевидних місцях.

Наприклад, множинне присвоєння всередині використовує функцію-конструктор кортежу:

```julia-repl
julia> first, rest... = [1, 2, 3, 4]
4-element Vector{Int64}:
 1
 2
 3
 4

julia> first
1

julia> rest
3-element Vector{Int64}:
 2
 3
 4
```

Іменовані аргументи також можна надати через splat, зазвичай за допомогою `named tuple`. 
`Dict` також підійде, але ключі мають бути типу `Symbol`; рядки тексту (англ. string) не підійдуть.

```julia-repl
# function with 3 keyword arguments
julia> fabc(; a, b, c) = a + b + c
fabc (generic function with 1 method)

# named tuple
julia> abc_nt = (a=2, b=3, c=4)
(a = 2, b = 3, c = 4)

# there are no positional arguments, so need to use ; before kw argument
julia> fabc(;abc_nt...)
9

# Dict
julia> abc_dict = Dict(:a=>2, :b=>3, :c=>4)
Dict{Symbol, Int64} with 3 entries:
  :a => 2
  :b => 3
  :c => 4

julia> fabc(;abc_dict...)
9
```

#### Slurp

Slurp використовують у _визначенні_ функції, щоб запакувати довільну кількість окремих значень у колекцію.

```julia-repl
julia> f_more(i, j, more...) = i + j + sum(more)
f_more (generic function with 1 method)

julia> f_more(1, 3, 5, 7, 9, 11)
36
```

Назва аргументу зі slurp (у цьому випадку `more`) не має значення.
Тип цієї змінної вибирає компілятор, але для позиційних аргументів він, найімовірніше, буде `tuple` або чимось подібним.

Іменовані аргументи також можна зібрати через slurp, отримавши `Dict` (або подібне).

```julia-repl
julia> f_kwslurp(x, y; switches...) = :mult in keys(switches) ? x * y : x + y
f_kwslurp (generic function with 1 method)

julia> f_kwslurp(5, 6; mult=true)
30

julia> f_kwslurp(5, 6)
11
```

У виклику можна використати будь-які іменовані аргументи.
Саме визначення функції вирішує, на які ключові слова реагувати, а які ігнорувати.
