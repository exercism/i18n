# Доповнення до інструкцій

## Використовувати `random` чи `secrets`?

Починаючи з Python 3.6, існує два різні модулі для отримання «випадкових» чисел:

Модуль [`random`][random] є [_псевдовипадковим_][pseudo-random]: він **не** генерує справжньої випадковості, а працює за алгоритмом, який _імітує_ випадковість.
Оскільки ці «випадкові числа» утворюються за відомим алгоритмом, вони не є по-справжньому випадковими.
Як наслідок, модуль `random` не годиться для криптографії і його не варто використовувати, саме тому, що він псевдовипадковий.


Модуль [`secrets`][secrets] генерує [криптографічно стійкі][crypto-strong] «випадкові» числа, які забезпечують вищий рівень безпеки, потрібний для криптографії.
У найстрогішому сенсі вони теж псевдовипадкові, але вони гарантують, що утворені ними числа абсолютно непередбачувані.


Оскільки це лише практична вправа, використовувати модуль `random` цілком прийнятно, але зауважмо, що **для справжньої криптографії він був би
дуже незахищеним.**

[crypto-strong]: https://cryptobook.nakov.com/secure-random-generators/secure-random-generators-csprng
[pseudo-random]: https://en.wikipedia.org/wiki/Pseudorandomness
[random]: https://docs.python.org/3/library/random.html
[secrets]: https://docs.python.org/3/library/secrets.html
