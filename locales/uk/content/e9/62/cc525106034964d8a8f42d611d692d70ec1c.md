# Запуск тестів Ceylon

Перш ніж запускати тести, код потрібно скомпілювати за допомогою [`ceylon compile`](https://ceylon-lang.org/documentation/current/reference/tool/ceylon/subcommands/ceylon-compile.html).

Тести ми запускаємо командою [`ceylon test`](https://ceylon-lang.org/documentation/reference/tool/ceylon/subcommands/ceylon-test.html).

Команда `ceylon test` приймає назву модуля, для якого слід запустити тести.
У треку Ceylon кожна вправа має лише один модуль.

Тож запустити тести можна так:

```bash
ceylon compile && ceylon test $(basename source/*)
```
