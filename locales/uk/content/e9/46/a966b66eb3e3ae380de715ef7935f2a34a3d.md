# Про

Базову концепцію `try .. rescue` можна розширити, щоб підтримувати додаткові конструкції `else` та `after`:

- Блок `else`:
  - Тут успішний результат із блоку `try` зіставляється зі зразком.
- Блок `after`:
  - Тут функції викликаються незалежно від того, чи блок `try` завершується успішно, чи його перехоплено, поки програма виконується.
  - Результат блоку `after` не повертається до області видимості, з якої викликали `try`.

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```
