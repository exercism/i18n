# Докладніше

- Тип [бінарні дані][binary] є спеціалізацією типу [бітовий рядок][bitstring].
- Бінарні дані складаються з [байтів][wiki-byte].
  - Байти складаються з 8 [бітів][wiki-bit].
  - Байти можуть представляти числа від `0` до `255`
  - Працюючи з байтами, часто використовують [шістнадцяткові][wiki-hexadecimal] цілі числа: від `0x00` до `0xFF`.
- Бінарні літерали визначають за допомогою [спеціальної форми `<<>>`][special-form].
  - Якщо для байта використати ціле число, більше за `255`, використовуються лише останні 8 бітів, якщо тільки не вказати [одиницю та/або розмір][bin-size] за допомогою оператора [`::`][type-operator].
- За допомогою [`<>/2`][bin-concat] можна зʼєднувати бітові рядки, бінарні дані та рядки тексту (англ. string).

```elixir
<<255>> == <<0xFF>>
# Overflowing bits are truncated
<<256>> == <<0>>
<<256::size(16)>> == <<1, 0>>

<<"Hello">> == <<72, 101, 108, 108, 111>>
```

_Нульовий байт_ - це інша назва для `<<0>>`.

## Рядки тексту - це закодовані бінарні дані

- Рядки тексту - це закодовані бінарні дані у форматі [UTF-8][wiki-utf8].
  - Вони закодовані 8-бітними (однобайтовими) частинами, і для представлення понад 255 символів використовується до 4 байтів.
  - [Довжина рядка тексту][string-length] може не збігатися з його [розміром у байтах][byte-size].

```elixir
# This string has a string length of 5, but is made up of 7 bytes
string = "cześć"
String.length(string) != byte_size(string)

# Even emoji strings are encoded binaries
"👍" == <<240, 159, 145, 141>>
```

## Зіставлення зі зразком для бінарних даних

- Бінарні дані можна [зіставити зі зразком як одне ціле або за допомогою спеціальної форми][special-form], щоб зіставити лише одну частину.
  - Лише остання частина у зразку може мати змінний розмір.

```elixir
# Ignore the first 8 bytes, bind the remaining variable sized binary to `body`
<<_::binary-size(8), body::binary>>
```

Так само можна робити і з рядками тексту:

```elixir
# bind the first 5 bytes to `name`,
# match the string literal " the ",
# bind remaining bytes to `species`
<<name::binary-size(5), " the ", species::binary>> = <<"Frank the Walrus">>
{name, species}
# => {"Frank", "Walrus"}
```
