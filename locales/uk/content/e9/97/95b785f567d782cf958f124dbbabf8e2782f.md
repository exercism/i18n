# Тести

Щоб запустити надані тести, нам знадобиться гем Minitest. Відкриємо вікно термінала й виконаємо таку команду, щоб встановити minitest:

```
gem install minitest
```


Запустимо тести з каталогу вправи за допомогою такої команди:

```
ruby <snake-case-exercise>_test.rb
```

Замініть `<snake-case-exercise>` на назву своєї вправи у зміїному регістрі.

## Кольоровий вивід

Можна виконати `require 'minitest/pride'` або запустити таку команду, щоб отримати кольоровий вивід:

```
ruby -r minitest/pride <snake-case-exercise>_test.rb
```
