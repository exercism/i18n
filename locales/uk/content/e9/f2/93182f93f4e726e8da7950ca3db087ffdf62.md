# Обʼєднані типи

Crystal дозволяє, щоб змінна складалася з кількох типів.
Це називають [обʼєднаним типом][union-type].
У Crystal обʼєднаний тип часто виводить компілятор.

~~~~exercism/note
Під час виконання обʼєднаний тип усе одно залишається одним типом, навіть якщо складається з кількох типів.
Це означає, що якщо обʼєднаний тип складено з `String` й `Int32`, він не буде обома водночас.
Натомість він буде або `String`, або `Int32`.
~~~~

Обʼєднаний тип оголошують, розділяючи типи вертикальною рискою (`|`).
Їх часто беруть у дужки, але це не обовʼязково.
Найпоширеніший обʼєднаний тип: `(T | Nil)`, де замість `T` стоїть якийсь тип. Він трапляється в методах, які можуть повернути `Nil`.
Також кажуть, що така змінна **допускає `Nil`**.

```crystal
foo : String = "Hello"
foo = nil # Error: type must be String, not (String | Nil)

foo : (String | Nil) = "Hello"
foo = nil
```

Це не обмежується лише двома типами: їх може бути скільки завгодно.

```crystal
foo : (String | Int32 | Nil | Float64) = "Hello"
foo = 1
foo = nil
foo = 1.0
```

## `typeof` проти `Object#class`

Є два способи дізнатися тип змінної.
Або скористатися [`typeof`][typeof], або [`Object#class`][Object#class].
Різниця в тому, що `typeof` повертає тип змінної на етапі компіляції, а `Object#class` повертає тип під час виконання.
Тож якщо ми хочемо, наприклад, перевірити, чи має змінна обʼєднаний тип, то `Object#class` цього не покаже, бо повертає тип лише під час виконання, а там тип один.

```crystal
foo = 0 == 0 ? "a" : 1
typeof(foo) # => (String | Int32)
foo.class # => String
```

## Операції з обʼєднаними типами

Оскільки під час виконання обʼєднаний тип є одним типом, з ним працюють усі звичайні операції.
Але під час компіляції компілятору потрібно знати, який саме це тип.
Тому код потрібно побудувати так, щоб перед використанням операцій, специфічних для певного типу, він гарантовано був лише одного типу.

```crystal
foo : (String | Int32) = "Hello"
foo.downcase # Error: undefined method 'downcase' for (String | Int32)
```

У Crystal для обʼєднаних типів є особливий метод: метод `is_a?`, який приймає тип як аргумент і повертає булеве значення (англ. Boolean).
Метод `nil?` працює як скорочення для `is_a?(Nil)`.
Якщо помістити метод `is_a?` у керуючий вираз, він підкаже компілятору, який це тип, і тим самим гарантує, що тип саме такий.
А в гілці `else` буде гарантовано, що це не той тип.

```crystal
foo : (String | Int32) = "Hello"
if foo.is_a?(String)
  typeof(foo)  # => String
  foo.downcase # => "hello"
end
```

Метод `is_a?` приймає не лише один тип: аргументом може бути й обʼєднаний тип.
Його також можна поєднувати з `&&` (логічне і) для кількох типів.

~~~~exercism/note
Метод `is_a?` у керуючому виразі не може застосовуватися до змінної екземпляра або змінної класу.
Натомість такі змінні спочатку потрібно присвоїти локальній змінній.
~~~~

## as

Один зі способів звести обʼєднаний тип до одного типу полягає в тому, щоб зробити вхід у гілку можливим лише для конкретного типу.
Інший підхід: скористатися методом [`as`][as].
Він зводить обʼєднаний тип до одного типу за допомогою перевірки під час виконання.
Якщо тип не той, що очікується, буде викликано виняток.

```crystal
foo : String | Int32 = "Hello"
foo.as(String).downcase # => "hello"

foo.as(Int32) # Error: can't cast String to Int32
```

~~~~exercism/caution
Цей підхід призначено лише для випадків, коли ми впевнені, що тип саме той, який очікується, або коли ми хочемо, щоб у протилежному випадку було викликано виняток.

Використання цього підходу за неправильної побудови коду може призвести до несподіваної поведінки.
~~~~

## as?

[`as?`][as?] працює майже так само, як `as`, але повертає `nil` замість того, щоб викликати виняток, якщо тип не той, що очікується.
Тобто він повертає обʼєднаний тип з очікуваного типу та `Nil`.

```crystal
foo : (String | Int32) = "Hello"
foo.as?(String).downcase # => "hello"

foo.as?(Int32) # => nil
```

## Скорочений запис для типів, що допускають Nil

«Допускає `Nil`» означає, що змінна може бути або якогось типу, або `Nil`.
Це можна записати як `(T | Nil)`.
Але оскільки типи, що допускають `Nil`, досить поширені, для них є скорочений запис: `T?`.

```crystal
# This:
foo : (String | Nil) = "Hello"
foo = nil

# Is the same as:
foo : String? = "Hello"
foo = nil
```
