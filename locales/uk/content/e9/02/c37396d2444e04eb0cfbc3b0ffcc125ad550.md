# Підказки

## 1. Визначте типи `Usd`, `Eur` і `Jpy`

- Типи `Usd`, `Eur` і `Jpy` можна визначити без конструкторів, скориставшись синтаксисом `pub type TypeName`.

## 2. Визначте тип `Money`.

- Тип `Money` повинен мати фантомний параметр типу для валюти.

## 3. Визначте функції `dollar`, `euro` і `yen`

- Анотація повернення функцій `dollar`, `euro` і `yen` має бути `Money(currency)`, де `currency` - відповідний параметр типу `Money`.

## 4. Визначте функцію `total`

- Анотація повернення функції `total` має використовувати той самий параметр типу, що й аргумент.
