# Потоки

Ця вправа знайомить нас із потоками, щоб перевірити, наскільки надійно наш банківський рахунок витримує паралельні операції. Деякі матеріали для читання про потоки в Tcl:

* [Tcl Threading Model](https://www.tcl.tk/doc/howto/thread_model.html)
* [Threads Done Right… with Tcl](https://www.activestate.com/blog/threads-done-right-tcl/)
* [Multi-Threaded Tcl Scripts](http://www.beedub.com/book/4th/Threads.pdf),
  розділ із _Practical Programming in Tcl and Tk, 4th Ed._,
copyright 2003 © Brent Welch, Ken Jones
[http://www.beedub.com/book/](http://www.beedub.com/book/)
    * У цьому розділі зазначено: «Більшість бінарних дистрибутивів Tcl не мають підтримки потоків». Зараз це вже не так: дистрибутиви Tcl тепер збираються з підтримкою потоків (див. [TIP 364](https://core.tcl-lang.org/tips/doc/trunk/tip/364.md))
* [Thread Package Commands](https://tcl.tk/man/tcl8.6/ThreadCmd/contents.htm) з документації Tcl.

## Встановлення

Деякі дистрибутиви Tcl не містять пакета Thread у стандартній поставці: його може знадобитися встановити окремо.
Перевірте так:
```bash
$ echo 'package require Thread' | tclsh
```
Якщо команда _нічого не виведе_, то пакет Thread уже встановлено.

За потреби виконайте `apt install tcl-thread` (або `dnf install tcl-thread`).
