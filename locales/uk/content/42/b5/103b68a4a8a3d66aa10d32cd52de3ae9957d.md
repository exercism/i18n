# Вступ

Структури - базовий будівельний блок програмування мовою Swift. Вони обʼєднують повʼязані дані та функції в самодостатні одиниці функціональності. Усі базові типи, з якими ми працювали досі, як-от `Int`, `Double` і `Character`, а також колекційні типи, як-от `Array`, `String` і `Dictionary`, насправді є структурами.

## Визначення структур

Структуру визначають за допомогою ключового слова `struct`, після якого йде назва типу, що визначається, а потім тіло, розміщене у фігурних дужках.

Тіло може складатися зі збережених властивостей, які визначаються й поводяться так само, як звичайні константи чи змінні.

```swift
struct CharacterStats {
  var health = 0.0
  var speed = 0
  var strength = 0
}
```

## Екземпляри

Як зазначено вище, визначення структури - це лише визначення нового _типу_. Це лише креслення того, який вигляд матимуть значення цього типу, але воно насправді не створює жодного значення цього типу, з яким ми могли б працювати.

Щоб створити _екземпляр_ цього типу, потрібно написати назву типу, а потім пару дужок.

```swift
let someStats = CharacterStats()
```

Так ми створимо значення цих типів, у яких властивості заповнені типовими значеннями, заданими у визначенні.

Для структур Swift автоматично надає так званий _ініціалізатор за членами_, у якому значення для властивостей структури можна передати в дужках, і вони перекриють типові значення з визначення.

```swift
let differentStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

## Доступ до властивостей

До властивостей структури можна звертатися за допомогою _точкової нотації_, де після назви значення йде крапка (`.`), а потім назва властивості.

```swift
someStats.health
// => 0
someStats.health = 87.3
```
