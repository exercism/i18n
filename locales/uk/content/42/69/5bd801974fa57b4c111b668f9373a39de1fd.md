# Тести

Кожна вправа надає модульні тести й рецепт збірки за допомогою Make.
Реалізацію надаємо ми.

Кожен тестовий файл має компонуватися з нашою реалізацією, щоб отримати консольний виконуваний файл, який запускає тести.
Запуск виконуваного файлу тестів виводить повідомлення для кожного невдалого тесту й повідомляє про ненульовий статус виходу, коли тести не проходять.

Щоб пропрацювати вправу:
* Створіть початкову збірку за допомогою Make
* Для кожного модульного тесту:
  * Приберіть рядок `TEST_IGNORE()`.
  * Усуньте всі помилки компіляції, щоб тест запустився й не пройшов.
  * Реалізуйте рівно стільки, щоб тест пройшов.
  * Проведіть рефакторинг реалізації, щоб підвищити читабельність, зменшити дублювання тощо.
