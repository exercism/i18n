# Ітератори

Прохід масивом із лічильником потребує чотирьох рядків допоміжного коду, перш ніж почнеться будь-яка робота:

```sather
   i ::= 0;
   loop
      until!(i >= counts.size);
      total := total + counts[i];
      i := i + 1;
   end;
```

Лічильник, перевірка завершення і крок не мають жодного стосунку до додавання чисел. Усі три дії виконує **ітератор**.

```sather
   loop
      total := total + counts.elt!;
   end;
```

`elt!` щоразу віддає один елемент і завершує цикл, коли елементів більше немає. Ніякого лічильника, нічого, що можна зробити неправильно, і жодного способу вийти за межі масиву.

## Знак оклику

`!` позначає ітератор. Ми вже зустрічали три з них: `until!`, `while!` і `break!`, і всі вони дотримуються того самого правила: **ітератор можна викликати лише всередині циклу.** Якщо написати `counts.elt!` поза циклом, це помилка.

Коли ітератор викликають усередині циклу, у нього щоразу запитують значення. Коли в нього нічого не залишається, цикл завершується негайно, де б у тілі циклу не стався виклик.

## Почнімо з двох

`elt!` дає елементи масиву або рядка тексту (англ. string) у порядку.

```sather
   loop
      #OUT + names.elt! + "\n";
   end;
```

`upto!` рахує. `1.upto!(5)` дає 1, 2, 3, 4, 5, а потім завершує цикл.

```sather
   loop
      total := total + 1.upto!(5);
   end;
```

Обидві є звичайними підпрограмами, які просто закінчуються на `!`, тому обидві викликаються через крапку, на масиві або на числі.

## Зберігаємо відповідь

Цикл завершується сам, тому все, що обчислено всередині нього, потрібно зберігати у змінній, оголошеній **зовні**, інакше воно зникне, коли завершиться цикл.

```sather
   total ::= 0;             -- outside
   loop
      total := total + counts.elt!;
   end;
   return total;
```
