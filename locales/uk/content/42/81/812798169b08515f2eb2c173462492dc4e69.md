# Докладніше

jq працює так: вхідні дані JSON проходять через _один вираз_ (записаний як _конвеєр фільтрів_), і на виході ми отримуємо потрібні перетворені дані.

## Швидкий вступ до параметрів командного рядка `jq`

Мову `jq` реалізує _програма_ `jq`.
Ця програма має кілька зручних параметрів командного рядка, які керують тим, як споживаються вхідні дані та як подаються вихідні.

Нижче в прикладах ми побачимо:

- `-n` або `--null-input`

  Зазвичай програмі `jq` передають файл для читання або надсилають дані на її вхід.
  Параметр `--null-input` дає змогу згенерувати дані JSON без жодних вхідних даних.

- `-c` або `--compact-output`

  `jq` типово гарно форматує свої вихідні дані.
  Людям надзвичайно зручно дивитися на дані, коли вони гарно відформатовані.
  Однак машинам це не потрібно: параметр `--compact-output` прибирає пробільні символи форматування, щоб зменшити розмір отриманого JSON.

- `-f filename` або `--from-file filename`

  Читає програму `jq` з файлу `filename` замість того, щоб задавати її в командному рядку.
  І `sed`, і `awk` використовують параметр `-f` для тієї самої мети.
  Цей параметр використовується в тестових скриптах практичних вправ.

Докладніше про всі параметри можна прочитати в [посібнику][man-cli].

## Фільтри та конвеєри

**Фільтри** також називають **виразами**.

_Фільтр_ приймає вхідні дані й видає вихідні.
Як і в оболонці Unix, _фільтри_ можна зʼєднувати конвеєром `|`, щоб передавати вихідні дані одного _фільтра_ на вхід іншого.

## Фільтр тотожності: `.`

Це найпростіший _фільтр_.
Він просто передає свої вхідні дані на вихід.
Наприклад, `jq` типово форматує вихідні дані, тож якщо пропустити JSON через фільтр `.`, ми безкоштовно отримаємо гарно відформатовані вихідні дані!

```sh
$ echo '[1, 2, 3]' | jq '.'
[
  1,
  2,
  3
]
```

## Масиви

Це буде короткий вступ до роботи з **масивами**.
Докладніше ми розглянемо цю тему пізніше.

До елементів _масиву_ звертаються через дужки, а індексація починається з нуля.

```sh
$ echo '[10, 20, 30]' | jq '.[1]'
20
```

_Фільтр_ може побудувати _масив_, узявши вираз у `[` та `]`

- зі сталим переліком елементів:

  ```sh
  jq -n '[1, 2, 3]'
  ```

- щоб зібрати потік елементів: наприклад,
  [`range`][man-range] - це функція, яка видає потік чисел

  ```sh
  $ jq -n 'range(10; 70; 15)'
  10
  25
  40
  55
  ```

  Використання `[]` збирає результати виразу в масив

  ```sh
  $ jq -c -n '[range(10; 70; 15)]'
  [10,25,40,55]
  ```

## Кома - це оператор

_Кома_ - це не просто синтаксис, що розділяє елементи _масиву_.
**Кома** - це **оператор**, який обʼєднує потоки.

Наприклад, `[1, 2, 3]` - це _фільтр_, який використовує конструктор _масиву_ `[]`, щоб зібрати результат обʼєднання трьох виразів `1`, `2` і `3`.

Звернімо увагу на крапки з комою в `range(10; 70; 15)` вище?
Оскільки _коми_ в мові `jq` мають особливе призначення, функції, які приймають кілька аргументів, розділяють аргументи крапками з комою.

## Обʼєкти

Короткий вступ до **обʼєктів**.

Як і в багатьох мовах програмування, до властивостей _обʼєкта_ звертаються через крапку

```sh
$ echo '{"foo": {"bar": "qux"}}' | jq '.foo.bar'
"qux"
```

Для _обʼєктів_ можна використовувати й дужки, але тоді рядкові літерали (англ. string) потребують лапок.
Це один зі способів працювати з ключами, що містять пробіли.

```sh
$ echo '{"foo bar": "qux"}' | jq '.["foo bar"]'
"qux"
```

_Обʼєкт_ можна побудувати з `{}` та пар `key: value`.
Лапки не потрібні навколо _ключів_, які є «простими» рядками тексту.

```sh
jq -n '{question: (6 * 9), answer: 42}'
```

видає

```none
{
  "question": 54,
  "answer": 42
}
```

Щоб _ключ_ було оброблено як _вираз_, його треба взяти в круглі дужки (наступний приклад видає те саме, що й попередній).

```sh
echo '[["question", "answer"], [54, 42]]' \
| jq '{(.[0][0]): .[1][0], (.[0][1]): .[1][1]}'
```

## Конвеєри

Наприклад, якщо файл `file.json` містить

```json
{
  "key1": "value1",
  "key2": [5, 15, 25]
}
```

Обчислімо довжину _масиву_ key2:

```sh
$ jq '.key2 | length' file.json
3
```

Ми спрямовуємо вихідні дані виразу `.key2` на вхід [`length`][man-length], яка, що не дивно, видає кількість елементів у масиві.

<!-- prettier-ignore -->
~~~~exercism/caution
Це та особливість `jq`, до якої треба звикнути:
більшість (але не всі) функцій поводяться як _фільтри_, тобто дані передають на вхід фільтра, а не як аргумент.
~~~~

## Фільтри можуть ігнорувати свої вхідні дані

У цьому прикладі вхідні дані JSON ігноруються й не впливають на вихідні дані:

```sh
$ echo '{"answer": 42}' | jq '6 * 9'
54
```

## Фільтри можуть видавати потоки даних

_Фільтр_ може видати більше ніж одне значення.
Наприклад, _фільтр_ `.[]` видає кожен елемент _масиву_ як окреме значення:

```sh
$ jq -n -c '[1, 2, 3]'
[1,2,3]

$ jq -n -c '[1, 2, 3] | .[]'
1
2
3
```

Якщо спрямувати такий _фільтр_ в інший, то другий _фільтр_ буде виконуватися **_для кожного значення_**:

```sh
$ jq -n -c '[1, 2, 3] | .[] | . * 2'
2
4
6
```

Це схоже на неявну ітерацію.
Коли ми зрозуміємо цю техніку, то побачимо, що дуже потужні _фільтри_ `jq` можуть бути зовсім короткими.

## Круглі дужки

**Круглі дужки** обʼєднують підвирази в групи, щоб задати порядок обчислень, як і в інших мовах.
У `jq` потреба в них може видатися дещо несподіваною.

Наприклад, припустімо, ми хочемо побудувати _масив_ з 2 елементів: квадратний корінь з 9 та _e_ у степені 1.
Окремі вирази такі: `9 | sqrt` та `1 | exp`.
Ми сподіваємося побачити на виході _масив_ `[3, 2.7...]`

```jq
$ jq -n '[ 9|sqrt, 1|exp ]'
[
  20.085536923187668,
  2.718281828459045
]
```

Чому ми не отримали те, що сподівалися? `jq` розуміє це так:

```jq
[ ((9|sqrt), 1) | exp ]
```

`jq` будує потік із двох елементів (`3` і `1`), і кожен з них потрапляє до `exp`.

Треба подбати, щоб `exp` приймав лише одне число як вхідні дані.
Інакше кажучи, треба зробити так, щоб конвеєр обчислювався раніше за кому.

```jq
$ jq -n '[ 9|sqrt, (1|exp) ]'
[
  3,
  2.718281828459045
]
```

## Типи

З [посібника][man-types]

> jq підтримує той самий набір типів даних, що й JSON: числа, рядки тексту, булеві значення (англ. Boolean), масиви, обʼєкти (які мовою JSON є хешами, де ключами можуть бути лише рядки тексту), та «null».

Більше про них ми дізнаємося в наступних вправах.

## Пробільні символи

Пробільні символи в `jq` не мають значення.
Ми можемо використовувати пробіли, табуляції та перенесення рядків так, як нам зручно форматувати код.
Нам невідомі жодні наявні посібники зі стилю для `jq`.

## Незмінні значення

Значення в `jq` _незмінні_.
Фільтри, які змінюють значення, видадуть нове значення.
Це означає, що в `jq` немає глобальних змінних, тож нам доведеться звикнути передавати стан від одного фільтра до іншого.

## «Правдивість»

Значення `false` і `null` вважаються неправдою. Будь-яке інше значення
(зокрема число нуль і порожній рядок тексту, масив чи обʼєкт) вважається правдою.

## Функції та оператори

Не заглиблюючись надто (функції будуть темою іншої вправи), ось кілька корисних вбудованих функцій:

- [`length`][man-length]

  Отримуючи масив як вхідні дані, видає кількість елементів у масиві.

  ```sh
  $ jq -n '[10, 20, 30, 40] | length'
  4
  ```

- [`+`][man-plus]

  Цей оператор робить різні речі залежно від типу своїх операндів:
  додає числа,
  зʼєднує рядки тексту,
  приєднує масиви,
  обʼєднує обʼєкти.

  ```sh
  $ jq -c -n '
      3 + 4,
      "foo" + "bar",
      ["a", "b"] + ["c"],
      {"m": 10} + {"n": 20}
  '
  7
  "foobar"
  ["a","b","c"]
  {"m":10,"n":20}
  ```

  [`add`][man-add] - це функція, яка приймає масив і повертає елемент, у якому всі елементи додано разом за правилами `+`.
  `[1, 2, 3] | add` видає `6`.

- [`map`][man-map]

  Отримуючи масив як вхідні дані та фільтр як аргумент, видає масив, у якому фільтр застосовано до кожного елемента

  ```sh
  $ jq -c -n '[10, 20, 30, 40] | map(. / 5)'
  [2,4,6,8]
  ```

- [`select`][man-select]

  Отримуючи _якісь_ вхідні дані та фільтр як аргумент:
  - якщо фільтр, застосований до аргументу, дає значення _правда_, видає вхідні дані без змін
  - інакше не видає _нічого_ (не значення `null`, а справді жодних вихідних даних)

  Наприклад, маючи деякі числа, виберімо ті, що діляться на 3

  ```sh
  $ jq -n 'range(10) | select(. % 3 == 0)'
  0
  3
  6
  9
  ```

  Пригадаймо, що `range` видає _потік_ чисел.
  `select` викликатиметься один раз для кожного числа.
  Виводяться лише ті числа, які «проходять» вираз.

  Часто потрібно вибрати елементи масиву.
  Є кілька способів це зробити.

  Маючи вхідні дані `["Anne", "Bob", "Cathy", "Dave"]`, виберімо імена довжиною 4.
  - використаймо `map` і `select` разом

    ```jq
    map(select(length == 4))
    ```

  - розкладімо масив на елементи, застосуймо `select` до цього потоку й зберімо результати

    ```jq
    [ .[] | select(length == 4) ]
    ```
