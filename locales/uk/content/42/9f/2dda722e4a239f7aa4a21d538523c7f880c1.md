# Додаток до інструкцій

## Регістри

| Register | Використання | Тип    | Опис                                       |
| -------- | --------- | ------- | ------------------------------------------------- |
| `$a0`    | вхідні дані     | ціле число | число                                            |
| `$v0`    | вихідні дані     | булеве значення | чи є число числом Армстронга (`0` = `false`, `1` = `true`) |
| `$t0-9`  | тимчасовий | будь-який     | використовується для тимчасового зберігання                        |
