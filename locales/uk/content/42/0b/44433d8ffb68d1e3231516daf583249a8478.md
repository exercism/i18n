# Докладніше

Літерали - це фіксовані значення, які використовують безпосередньо в коді.
Їх не потрібно обчислювати під час виконання.
Вони бувають різних форм, щоб ефективно подавати різні типи даних.
Найчастіше трапляються числові літерали, але є також літеральні оператори для типів дати, часу та рядків.
Пізніший концепт покаже, як використовувати користувацькі літеральні оператори.

## Числові літерали

Числові літерали охоплюють десяткові, вісімкові, шістнадцяткові та двійкові подання.
Ці основи вже розглянуто в [концепті чисел][numbers-concept].

Усі подання, як-от `23`, `0x50f7ba11` і `0xba5eba11`, компілятор сприймає як `int`.
Загальний тип `int` є знаковим і ([залежно від компілятора та системи][in-depth-integers]) часто має діапазон від `-2'147'483'648` до `2'147'483'647`.
Здебільшого цього достатньо, і нам не варто перейматися конкретним типом.

Деякі випадки вимагають більших діапазонів або дуже малого обсягу памʼяті програм.
Щоб указати це явно, можна прямо вказати конкретний цілочисельний тип самим числовим літералом.

Коли відʼємні числа не потрібні, але потрібен додатковий діапазон, для _беззнакових_ цілих чисел використовують суфікс `u` або `U`.
Для більших діапазонів можна використати `L` або навіть `LL` для типів `long` і `long long`.

~~~~exercism/caution
Використовувати малу літеру `l` дозволено, але її легко сплутати з числом `1`, тому так робити не радимо.
~~~~

```cpp
auto net_worth_christian_grey{2'500'000'000U}; // out of range for 32-bit integers
auto net_worth_carlisle_cullen{46'000'000'000LL}; // int and uint are not enough
```

Числа з плаваючою комою під час компіляції зазвичай зводяться до `double`.
Це вдалий типовий випадок, а випадки з вужчим типом `float` трапляються рідше, ніж приклад із беззнаковим типом вище.

```cpp
auto light_year_in_m{9.46073e+15f}; // well in the range of float
auto earth_to_edge_comoving_distance_in_nm{4.32355e+32}; // needs double type for magnitude
auto eulers_number{2.718281828459045}; // needs double type for precision
```

## Символьні та рядкові літерали

В інших концептах уже використовували символьні літерали в одинарних лапках, як-от `'}'` чи `'@'`.

У C++ `char` обмежений першими 128 [кодами символів ASCII][ascii-code].
Щоб використати кілька символів ASCII, розширені символи ASCII, як-от `‰`, або навіть символи Unicode, як-от `麗` і `ẞ`, потрібні інші типи.
У попередньому концепті рядкові літерали було введено в _подвійних лапках_: `"一体どういう意味ですか。C++です"`.
Ця японська фраза насправді має тип `const char (&)[46]`, тобто рядок у стилі C.

Типово використання рядкових літералів не активовано.
Щоб скористатися літералом _string_ `""s` або літералом _string-view_ `""sv`, потрібно явно вказати це через відповідний простір імен:

```cpp
#include <string>
#include <string_view>

using namespace std::literals;

auto green_light{"무궁화 꽃 이 피었 습니다"};
// green_light type is const char (&)[36]
auto umbrella{"달고나"s};
// umbrella type is std::basic_string<char>, the same as std::string
auto il_nam{"보는 것이 하는 것보다 더 재미있을 수가 없지"sv};
// il_nam type is std::basic_string_view<char>
```

_String_view_ можна розуміти як посилання на константний рядок.
