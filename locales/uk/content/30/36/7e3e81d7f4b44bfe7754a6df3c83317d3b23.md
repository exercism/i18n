# Додаток до інструкцій

## Формат мінного поля

Мінне поле подано як рядок тексту (англ. string), що завершується нульовим символом, а в кінці кожного рядка стоїть символ нового рядка.

Прикладом може бути `"   \n * \n   \n"`

## Регістри

| Регістр | Використання | Тип     | Опис                                          |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | вхідні дані        | адреса | вхідний рядок тексту, що завершується нульовим символом  |
| `$a1`    | вхідні/вихідні дані | адреса | вихідний рядок тексту, що завершується нульовим символом |
| `$t0-9`  | тимчасові    | будь-який     | для тимчасового зберігання         |
