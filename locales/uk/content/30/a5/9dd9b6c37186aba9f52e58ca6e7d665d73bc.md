# Вступ

Julia - мова загального призначення, яку можна використовувати для більшості програмних завдань.
Однак на практиці основні випадки використання зазвичай повʼязані з інженерією та наукою.
В основі дизайну мови лежать швидкі, універсальні й витончені числові обчислення.

## Цілі числа

Ціле число - це «кругле» число без десяткової коми.

У концепті [Основи][basics] ми бачили, що ціле значення можна присвоїти змінній, не вказуючи тип.

Для читабельності як розділювач розрядів можна використовувати символи підкреслення.
Компілятор їх ігнорує.

```julia-repl
julia> x = 3
3

julia> typeof(x)
Int64

julia> large_number = 1_234_567_890
1234567890
```


## Числа з плаваючою комою

Не дивно, що числа з плаваючою комою мають десяткову кому та дробову частину після неї.

```julia-repl
julia> f = 3.45
3.45

julia> typeof(f)
Float64
```

Звісно, підтримується наукова нотація.

```julia-repl
julia> avogadro = 6.02e23
6.02e23
```

Максимальне й мінімальне значення можуть здивувати:

```julia-repl
julia> typemax(Float64)
Inf

julia> typemin(Float64)
-Inf
```

Нескінченність - допустиме значення!

## Арифметичні оператори

Як ми обговорювали в концепті Основи, арифметичні оператори здебільшого працюють так само, як звичайна арифметика, яку вивчають діти.
Звернімо увагу: піднесення до степеня використовує `^`, а _не_ `**` (обидва поширені в інших мовах).

```julia
2 + 3  # 5 (addition)
2 - 3  # -1 (subtraction)
2 * 3  # 6 (multiplication)
8 / 2  # 4.0 (division)
8 % 3  # 2 (remainder)
2 ^ 3  # 8 (exponentiation)
```

Проте кілька деталей, специфічних для Julia, варті обговорення.

### Множення

```julia-repl
julia> x = 4.2
4.2

julia> 2 * x
8.4

julia> 2x
8.4

julia> 2.4x
10.08
```

Це може здивувати.

Завжди можна використати `*` як інфіксний оператор, як і в більшості інших мов програмування.

Однак Julia створювали люди, які вважають, що код має якомога більше нагадувати математичні рівняння.

Оскільки назви змінних мають починатися з літери, число (ціле або з плаваючою комою) перед назвою сприймається як неявне множення.

Наприклад, якщо нам потрібна площа поверхні сфери, замість `4 * pi * r * r` ми могли б зробити так:

```julia-repl
julia> surface(r) = 4π * r^2
surface (generic function with 1 method)

julia> surface(3)
113.09733552923255
```

Хоча π - вбудована константа, це також (грецька) літера.
Тому парсеру все одно потрібен один явний `*`, щоб відокремити `π` від `r`.

### Ділення

Використання `/` як інфіксного оператора завжди дає результат з плаваючою комою, навіть для цілих вхідних даних.

Для цілочисельного ділення є більше варіантів.

```julia-repl
julia> 10 / 3  # floating-point division
3.3333333333333335

julia> div(10, 3)  # integer division
3

julia> 10 ÷ 3  # synonym for div()
3

julia> 10 // 3  # rational number (fraction)
10//3
```

Функція `div()` призначена для цілочисельного ділення, і результат відкидається в напрямку нуля: вниз для додатних чисел, вгору для відʼємних.

Як синонім можна використати інфіксний оператор `÷`, знову ж таки прагнучи зробити запис математичнішим.
Якщо ми користуємося редактором, який розуміє Julia, введімо `\div`, а потім натиснімо клавішу `<Tab>`.

Оператор `//` виходить за межі цього концепту.
Поки що скажімо лише, що результат `//` - це «раціональне» число, яке більшість людей називає _дробом_.

## Перетворення числових типів

Часто це відбувається автоматично:

```julia-repl
julia> x = 2 + 3.5
5.5

julia> typeof(x)
Float64
```

Ми додали `Int64` до `Float64` й отримали результат `Float64`.

Насправді ціле число непомітно перетворилося на `Float64` ще до самого додавання.

**Перетворення з плаваючою комою на ціле число** неминуче складніші.
Що робити з тим, що стоїть після десяткової коми?

- Функція `round()` перетворює число на найближче ціле, а за рівної відстані, як-от 4.5, округлює до найближчого _парного_ цілого.
- `floor()` округлює вниз, `ceil()` округлює вгору, `trunc()` округлює в напрямку нуля.
- Спроба прямого приведення типу, наприклад за допомогою `Int32()`, завершиться помилкою `InexactError`.

Однак типово ці функції повертають не той цілий тип, який міг бути потрібен.
Бажаний тип вихідних даних можна вказати.

```julia-repl
julia> round(4.5)
4.0

julia> ceil(Int, 4.3)
5
```

Округлення до заданої кількості цифр після десяткової коми також можливе за допомогою ключового слова `digits`.

```julia-repl
julia> round(π, digits=10)
3.1415926536
```

## Ділення на нуль

Невже тут просто виникає помилка?
Насправді все не так просто.

Цілочисельне ділення з `÷` або `//` спричинить помилку, як і можна очікувати.

Ділення з плаваючою комою за допомогою `/` дотримується радше інженерного підходу, ніж стандартного підходу інформатики:

```julia-repl
julia> 2 / 0
Inf

julia> 0 / 0
NaN
```

Як ми обговорювали в попередньому розділі, нескінченність - це допустиме число з плаваючою комою в Julia, яке позначається `Inf`.

Коли чисельник також дорівнює нулю, результат математично не визначений.
Тоді Julia трактує його як «не число», позначене `NaN`.
