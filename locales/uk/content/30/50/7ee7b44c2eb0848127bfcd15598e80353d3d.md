# Додаток до інструкцій

## Підказки

Щоб виконати цю вправу, потрібно реалізувати функцію `score`,
яка приймає послідовність *кидків* у боулінгу і повертає фінальний рахунок
або відповідну помилку:

```haskell
score :: [Int] -> Either BowlingError Int

data BowlingError = IncompleteGame
                  | InvalidRoll { rollIndex :: Int, rollValue :: Int }
                  deriving (Eq, Show)
```

Ці визначення вже на місці, але саму функцію потрібно визначити самостійно.

Зверніть увагу, що набір тестів припускає, що нумерація кидків починається з нуля.
