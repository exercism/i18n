# Інструкції

У цій вправі ми працюватимемо над планувальником зустрічей для салону краси в Нью-Йорку, який відкрився 15 вересня 2012 року.

На нас чекає пʼять завдань, і всі вони стосуються дат зустрічей.
Час подано у 24-годинному форматі (без позначок AM/PM).

## 1. Розібрати дату зустрічі, що містить лише числа

Реалізуйте функцію `schedule_appointment()`, яка перетворює текстове подання дати зустрічі у відповідний формат `DateTime`.

Зауважте, що вхідні дані подано в американському порядку місяць/день/рік.

```julia-repl
julia> schedule_appointment("07/25/2023 13:45:00")
2023-07-25T13:45:00
```

## 2. Перевірити, чи зустріч уже минула

Реалізуйте функцію `has_passed()`, яка приймає дату зустрічі й перевіряє, чи зустріч була десь у минулому:

```julia-repl
julia> has_passed(DateTime(1999, 12, 31, 9, 0, 0))
true
```

## 3. Перевірити, чи зустріч відбудеться після обіду

Реалізуйте функцію `is_afternoon_appointment()`, яка приймає дату зустрічі й перевіряє, чи призначено зустріч на післяобідній час (>= 12:00 та < 18:00):

```julia-repl
julia> is_afternoon_appointment(DateTime(2023, 3, 29, 15, 0, 0))
true
```

## 4. Описати час і дату зустрічі

Реалізуйте функцію `description()`, яка приймає дату зустрічі й повертає опис цієї дати й часу:

```julia-repl
julia> describe(DateTime(2023, 3, 29, 15, 0, 0))
"You have an appointment on Wednesday, March 29, 2023 at 15:00"
```

## 5. Повернути дату річниці

Реалізуйте функцію `anniversary_date()`, яка повертає дату річниці цього року, а саме 15 вересня:

```julia-repl
julia> anniversary_date()  # run during 2025
2025-09-15
```
