# Довідка

Ініціалізатори обʼєктів - це альтернатива конструкторам. Синтаксис - це розділений комами список пар «імʼя поля=значення», як показано нижче:

```csharp
public class Person
{
    public string Name;
    public string Address;
}

var person = new Person{Name="The President", Address = "Élysée Palace"};
```

Колекції теж можна ініціалізувати в такий спосіб. Зазвичай це робиться за допомогою списків, розділених комами, як показано тут:

```csharp
IList<Person> people = new List<Person>{ new Person(), new Person{Name="Joe Shmo"}};
```

Цей підхід (і синтаксис) можна застосувати з будь-яким класом, який реалізує `IEnumerable` і має метод `Add()`.

Поля можна вказувати в будь-якому порядку або зовсім не вказувати.

Словники використовують такий синтаксис:

```csharp
IDictionary<int, string> numbers = new Dictionary<int, string>{ [0] = "zero", [1] = "one"...};

// or

IDictionary<int, string> numbers = new Dictionary<int, string>{ {0, "zero" }, {1,  "one"}...};
```

Ініціалізовані поля мають бути доступними для того, хто викликає код. Зазвичай це означає, що вони мають бути `public` або `internal`.

Серед розробників мови та провідних практиків є стійка тенденція до незмінності, тому змінність обʼєктів, ініціалізованих у такий спосіб, вважають недоліком. Є пропозиції додати конструкцію `init` у майбутній версії мови, C# 9, що може вирішити цю проблему.

- Документація [ініціалізаторів обʼєктів][object-initializers] описує, як користуватися ініціалізаторами.
- Документація [ініціалізаторів колекцій][collection-initializers] показує, як ініціалізатори можна застосовувати з колекціями, як-от словниками та масивами.
