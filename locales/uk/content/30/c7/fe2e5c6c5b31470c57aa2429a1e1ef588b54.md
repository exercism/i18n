# Вступ
Вбудовані числові типи в C++ можна поділити на цілі числа та числа з плаваючою комою.
Цілі числа не мають дробової частини, наприклад `0`, `691` чи `-2`.
Числа з плаваючою комою мають десяткову точку, наприклад `6.02214076`, `0.1` чи `-1.616`.

## Цілі числа
У наступному прикладі показано оголошення та ініціалізацію чотирьох різних змінних

```cpp
int m_morales{9241};              // base 10: 0-9
int a_apaec{0x24CD};              // base 16: 0-9 and A-F
int m_gargan{0b10010000011001};   // base  2: 0-1
int b_reilly{022031};             // base  8: 0-7
                                  // Leading with a 0 not the letter o.
```

Коли ми присвоюємо значення змінній `int`, можна зробити це безпосередньо літералом.
Літералом називають жорстко закодоване число, як-от `9241`.
Існують різні цілочисельні літерали для кількох основ представлення.
Десяткові цілочисельні літерали найпоширеніші та використовують цифри від `0` до `9`.
Додавши спеціальний префікс, як-от `0x`, можна використовувати інші основи.
У наведеному вище прикладі число `9421` показано в чотирьох представленнях із відповідними префіксами.
Усі змінні ініціалізовано одним і тим самим значенням.

Щоб дізнатися більше про різні системи представлення, погляньмо на [невеликий посібник][cpp_numerical_bases].

Для кращої читабельності можна розділяти цифри апострофом.
`9'241` те саме, що `0b0100'100'0001'1001` або `92'4'1`.

## Числа з плаваючою комою

Літерали з плаваючою комою бувають двох видів.
Окрім звичного `0.0024`, можна використовувати його наукову нотацію `2.4e-3`.
Найпоширенішим типом із плаваючою комою є `double`.

## Арифметика

C++ підтримує `+`, `-`, `*`, `/`, `(` та `)` і `%` для формування виразів.
Результат операції між двома цілими числами також є цілим числом.
`5 / 2` поверне `2`.
Коли один із задіяних типів є типом із плаваючою комою, результат також буде числом із плаваючою комою.
`5.0 / 2` і `5 / 2.0` повернуть `2.5`.
`%` є оператором остачі (від ділення) і повертає остачу від ділення цілих чисел: `5%3` дорівнює `2`.

## Оператор присвоєння

Оператор присвоєння присвоює змінній літерал.
Присвоєння завжди відбувається справа наліво, і ніколи навпаки.

```cpp
int length = 5;
int width = 2;
length = width;
```

Тут ціле значення `5` присвоюється змінній `length`.
Потім ціле значення `2` присвоюється змінній `width`.
Нарешті, значення `width` копіюється у змінну `length`, а попереднє значення `5` буде втрачено.
Звернімо увагу також на те, що ми лише присвоюємо значення `width` змінній `length` у момент операції присвоєння.
Тому, якщо значення `width` зміниться пізніше, це не вплине на значення, яке набуде `length`.

Оператор присвоєння можна поєднувати з іншими операторами (арифметичними та побітовими), відомими як оператори `compound assignment`: `+=`, `-=`, `*=`, `/=`, `%=`.
Ці оператори змінюють поточне значення змінної, виконуючи над ним операцію.

```cpp
// we start with 0 people
int people{};
// we need 0 eggs
int eggs{};
// two people joined:
people += 2;
// people is now 2
// let's add 3 eggs per person
eggs += 3 * people;
// eggs is now 6
```

Змінні `people` та `eggs` ініціалізовано значенням `0`.
Потім ми додаємо ціле значення `2` до наявного значення `0` змінної `people` і присвоюємо результат назад змінній `people`.
Тепер `people` дорівнює `2`.
Пізніше ми додаємо `3` яйця на кожну людину, що дає `6` яєць загалом.
Тепер додамо ці `6` до наявного значення `0` змінної `eggs` і присвоїмо результат назад змінній `eggs`.
Тепер `eggs` дорівнюватиме `6`.
Еквівалентними виразами будуть `people = people + 2` та `eggs = eggs + (3 * people)`.
