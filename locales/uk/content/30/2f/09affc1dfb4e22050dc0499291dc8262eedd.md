# Докладніше

`assocs` - це [протокол][assoc-protocol], а не окремий тип даних. Його реалізують хеш-таблиці (`H{ }`), списки асоціацій (послідовності пар `{ key value }`) і tree maps, а більшість слів для асоціацій взаємозамінні між ними.

```factor
USING: assocs ;

H{ } clone "coal" over inc-at
"coal" over inc-at
"wood" over inc-at      ! => H{ { "coal" 2 } { "wood" 1 } }
```

Повний набір операцій широкий (впорядкована ітерація, відображення, фільтрування), але більшість роботи на рівні вправ зачіпає лише невеликий набір:

| слово       | ефект                                         |
|-------------|-----------------------------------------------|
| `at`        | `( key assoc -- value/f )`                    |
| `at*`       | `( key assoc -- value ? )` відрізняє f як значення від відсутнього ключа |
| `key?`      | `( key assoc -- ? )`                          |
| `set-at`    | `( value key assoc -- )`, змінює асоціацію    |
| `change-at` | `( key assoc quot -- )`, `quot` має вигляд `( old -- new )` |
| `inc-at`    | `( key assoc -- )`, `+1`, а якщо ключа немає, вставляє `1` |
| `delete-at` | `( key assoc -- )`, змінює асоціацію          |
| `>alist`    | `( assoc -- pairs )`                          |

`sort-keys` і `sort-values` (з `sorting`) сортують список асоціацій за вибраним полем.

[assoc-protocol]: https://docs.factorcode.org/content/article-assocs-protocol.html
