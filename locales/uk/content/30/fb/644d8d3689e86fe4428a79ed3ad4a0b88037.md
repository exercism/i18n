# Тести

Надані тести можна запускати через DrRacket або з командного рядка.

Щоб запустити тест через DrRacket, просто відкрийте файл тестів і натисніть кнопку «Run» у правому верхньому куті.

Щоб запустити тест із командного рядка, просто запустіть його з каталогу вправи. Наприклад, якщо набір тестів називається `hello-world-test.rkt`, можна виконати таку команду:

```
raco test hello-world-test.rkt
```

яка виведе таке:

```
raco test: (submod "hello-world-test.rkt" test)
2 success(es) 0 failure(s) 0 error(s) 2 test(s) run
0
2 tests passed
```
