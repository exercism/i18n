# Вступ

Клас `str` пропонує [багато корисних методів][str methods] для роботи з рядками тексту (англ. string) та їх поєднання. Серед них пошук, очищення, розбиття, перетворення, переклад та багато інших прийомів.

Рядки тексту - це [послідовності][text sequence] [кодових точок Unicode][unicode code points]: до окремих «символів» або кодових точок (_рядків тексту довжиною 1_) можна звертатися за номером `0-based index` зліва або `-1-based index` справа.
Рядки тексту підтримують усі [звичайні операції з послідовностями][common sequence operations].

Їх можна перебирати за допомогою синтаксису `for item in <str>` або `for index, item in enumerate(<str>)`.
Їх також можна конкатенувати за допомогою `<str> + <other str>` або `<str>.join(<iterable>)`.

Рядки тексту є _незмінними_: значення обʼєкта `str` у памʼяті не може змінитися.
Функції чи методи, що працюють із `str` (_як-от ті, про які ми тут дізнаємося_), повертають новий `instance` цього обʼєкта `str`, а не змінюють початковий `str`.

Далі наведено невелику добірку методів для рядків тексту в Python.
Повний список дивіться у [класі str][str methods] у документації Python.


[`<str>.title()`][str-title] розбирає рядок тексту та переводить у верхній регістр перший «символ» кожного знайденого «слова».
У Python це сильно залежить від [кодеку мови][codecs], який використовується, і від того, як конкретна мова подає слова та символи.
Також можуть діяти [правила локалі][locale] для мови або набору символів.


```python
man_in_hat_th = 'ผู้ชายใส่หมวก'
man_in_hat_ru = 'мужчина в шляпе'
man_in_hat_ko = '모자를 쓴 남자'
man_in_hat_en = 'the man in the hat.'

>>> man_in_hat_th.title()
'ผู้ชายใส่หมวก'

>>> man_in_hat_ru.title()
'Мужчина В Шляпе'

>>> man_in_hat_ko.title()
'모자를 쓴 남자'

>> man_in_hat_en.title()
'The Man In The Hat.'
```

[`<str>.endswith(<suffix>)`][str-endswith] повертає `True`, якщо рядок тексту закінчується на `<suffix>`, і `False` в іншому разі.


```python
>>> 'My heart breaks. 💔'.endswith('💔')
True

>>> 'cheerfulness'.endswith('ness')
True

# Punctuation is part of the string, so needs to be included in any endswith match.
>>> 'Do you want to 💃?'.endswith('💃')
False

>> 'The quick brown fox jumped over the lazy dog.'.endswith('dog')
False
```

[`<str>.strip(<chars>)`][str-strip] повертає копію `str`, з якої прибрано провідні та кінцеві `<chars>`.
Кодові точки, указані в `<chars>`, не є ані префіксом, ані суфіксом: **усі комбінації** цих кодових точок буде прибрано, починаючи з **обох кінців** рядка тексту.
Якщо для `<chars>` нічого не вказано, буде прибрано всі комбінації кодових точок пробілів.


 ```python
# This will remove "https://", because it can be formed from "/stph:". 
>>> 'https://unicode.org/emoji/'.strip('/stph:')
'unicode.org/emoji'

# Removal of all whitespace from both ends of the str.
>>> '   🐪🐪🐪🌟🐪🐪🐪   '.strip()
'🐪🐪🐪🌟🐪🐪🐪'

>>> justification = 'оправдание'
>>> justification.strip('еина')
'оправд'

# Prefix and suffix in one step.
>>> 'unaddressed'.strip('dnue')
'address'

>>> '  unaddressed  '.strip('dnue ')
'address'
```


[`<str>.replace(<substring>, <replacement substring>)`][str-replace] повертає копію рядка тексту, у якій усі входження `<substring>` замінено на `<replacement substring>`.

Цитата нижче взята з твору [The Hunting of the Snark][The Hunting of the Snark] [Льюїса Керролла][Lewis Carroll]

```python
# The Hunting of the Snark, by Lewis Carroll
>>> quote = '''
"Just the place for a Snark!" the Bellman cried,
   As he landed his crew with care;
Supporting each man on the top of the tide
   By a finger entwined in his hair.

"Just the place for a Snark! I have said it twice:
   That alone should encourage the crew.
Just the place for a Snark! I have said it thrice:
   What I tell you three times is true."
'''

>>> quote.replace('Snark', '🐲')
...
'\n"Just the place for a 🐲!" the Bellman cried,\n   As he landed his crew with care;\nSupporting each man on the top of the tide\n   By a finger entwined in his hair.\n\n"Just the place for a 🐲! I have said it twice:\n   That alone should encourage the crew.\nJust the place for a 🐲! I have said it thrice:\n   What I tell you three times is true."\n'

>>> 'bookkeeper'.replace('kk', 'k k')
'book keeper'
```
