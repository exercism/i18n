# Вступ

Властивість у C# - це член класу, який надає доступ до даних усередині цього класу.
Той, хто викликає, може встановлювати або отримувати (get) ці дані. Властивості бувають
автоматично реалізованими або мають резервне поле. Вони складаються з аксесора set та/або
аксесора get.
У деяких інших мовах «mutator» приблизно відповідає аксесору set, а «accessor» - аксесору
get, хоча будова синтаксису зовсім інша.

Коли ми встановлюємо властивість, вхідне значення можна перевірити, відформатувати
чи якось інакше обробити, і взагалі можна виконати будь-яку програмну операцію, доступну
коду в класі.

Так само, коли ми отримуємо значення властивості, дані можна обчислити або відформатувати, і
знову ж таки можна виконати будь-яку програмну операцію, доступну класу.

Властивості мають модифікатори доступу (`public`, `private` тощо) так само, як і інші
члени класу, але аксесор set може мати рівень доступу, незалежний від аксесора get
(отримання), і навпаки. Властивість не обовʼязково повинна мати обидва аксесори, вона може мати лише один (або get, або set).

Базовий синтаксис для опису властивостей може набувати двох форм:

## Властивості на основі поля або виразу:

```csharp
private int myField;
public int MyProperty
{
    get { return myField; }
    set { myField = value; }
}
```

## Автоматично реалізовані властивості

```
public int MyProperty { get; private set; } = 42;
```

Ініціалізація необовʼязкова.
