# Вступ

*Кортеж* поєднує кілька іменованих значень в один обʼєкт, те, що в інших мовах називають записом, структурою або класом. Кожен клас кортежу має фіксований набір іменованих слотів, і Factor автоматично генерує для них гетери й сетери.

## Визначення кортежу

```factor
TUPLE: point
    { x initial: 0 }
    { y initial: 0 } ;
```

Кожен слот оголошується як `{ name initial: default-value }`. Без частини `initial:` типовим значенням є `f`.

## Створення кортежу

Найпростіший конструктор - `new`:

```factor
point new .
! => T{ point }
```

`boa` (за порядком аргументів) заповнює слоти в порядку оголошення зі стека даних:

```factor
3 4 point boa .
! => T{ point { x 3 } { y 4 } }
```

Синтаксис літерала `T{ class { slot value } … }` дає змогу створити кортеж із частиною встановлених слотів, і друкується він так само:

```factor
T{ point { x 3 } } .
! => T{ point { x 3 } }
```

Коли значення слота збігається з типовим, принтер його пропускає.

## Читання слота

Factor генерує гетер `slot>>` для кожного слота. Гетери містяться в [`accessors`][accessors]:

```factor
T{ point { x 3 } { y 4 } } x>> .
! => 3
```

## Оновлення слота

Сетери записуються як `>>slot` і *змінюють* кортеж на місці:

```factor
T{ point { x 3 } { y 4 } } 10 >>x .
! => T{ point { x 10 } { y 4 } }
```

Щоб залишити оригінал без змін, спершу викликаємо `clone`:

```factor
: shifted ( pt -- pt' )
    clone 10 >>x ;
```

`change-slot` приймає квотейшн, який перетворює поточне значення на нове:

```factor
: shift-x ( pt dx -- pt )
    [ + ] curry change-x ;
```

`change-x` так само змінює кортеж на місці, тож якщо ми хочемо зберегти оригінал, треба викликати `clone` перед його викликом.
