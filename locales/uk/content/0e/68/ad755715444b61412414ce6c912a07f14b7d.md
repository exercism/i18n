# Вступ

Тернарні оператори дозволяють визначати умови if у виразах, а не в блоках інструкцій. Це перегукується з підходами функціонального програмування і часто робить код виразнішим та менш схильним до помилок.

Тернарний оператор поєднує 3 вирази: умову, після якої йде вираз, який потрібно обчислити й повернути, якщо умова правдива (частина `if`, яку вводить `?`), і вираз, який потрібно обчислити й повернути, якщо умова неправдива (частина `else`, яку вводить `:`).

```csharp
int a = 3, b = 4;
int max = a > b ? a : b;
// => 4
```
