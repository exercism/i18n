# Докладніше

Числом з плаваючою комою називають число, у якому після десяткового розділювача стоїть нуль або більше цифр.
Приклади: `4.0`, `0.1`, `3.14`, `-6.4`, `16.984025` та `1024.0`.
У Ruby числа з плаваючою комою реалізовано через клас [Float][Float].

Короткий вступ до чисел з плаваючою комою можна знайти на [0.30000000000000004.com][0.30000000000000004.com].

На [сторінці Float Toy][evanw.github.io-float-toy] є гарне графічне пояснення того, як біти числа з плаваючою комою перетворюються на його фактичне значення.

Щоб виконувати якусь логіку багаторазово, можна скористатися циклами.
У цьому прикладі цикл `while` стає в пригоді, бо він продовжує повторюватися, _поки_ умова дає правдиве значення (тобто не `false` і не `nil`).
Ruby має цикл, схожий на цикл `while`.
Він називається циклом `until`, і ми, мабуть, уже здогадуємося, що він робить.
Він продовжує повторюватися, _доки_ умова не дасть булевого значення (англ. Boolean) `true`.
У деяких мовах, щоб змусити фрагмент коду виконуватися необмежену кількість разів, використовують конструкції на кшталт `while true`.
У Ruby для цього є цикл `loop`.
Хоча цикл `loop` не залежить від якоїсь однієї умови, його можна перервати за допомогою ключового слова `return` або `break`.

Метод `#years_before_desired_balance` із попередньої вправи можна було написати, використовуючи будь-який із трьох згаданих циклів:

## `while`

```ruby
def self.years_before_desired_balance(current_balance, desired_balance)
  years = 0
  while current_balance < desired_balance
    current_balance = annual_balance_update(current_balance)
    years += 1
  end
  years
end
```

## `until`

```ruby
def self.years_before_desired_balance(current_balance, desired_balance)
  years = 0
  until current_balance >= desired_balance
    current_balance = annual_balance_update(current_balance)
    years += 1
  end
  years
end
```

## `loop`

```ruby
def self.years_before_desired_balance(current_balance, desired_balance)
  years = 0
  loop do
    current_balance = annual_balance_update(current_balance)
    years += 1
    return years if current_balance >= desired_balance
  end
end
```

Як ми, мабуть, уже помітили, у Ruby немає оператора інкременту (`i++`), як у деяких інших мовах.
Натомість можна використовувати конструкції на кшталт `i += 1` (що дорівнює `i = i + 1`).
