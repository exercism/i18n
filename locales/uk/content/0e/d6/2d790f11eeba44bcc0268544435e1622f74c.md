# Вступ

`Map` використовують для зберігання пар **ключ** і **значення**. `Maps` ініціалізуються так само, як масив, але з використанням оператора літерала мапи `=>`. Також можна явно вказати типи ключів і значень, або ж ці типи виводяться автоматично. Ключі мають бути унікальними, інакше виникне помилка.

```haxe
var map1:Map<Int, String> = [1 => "one", 2 => "two", 3 => "three"];

var map2 = ["one" => 1, "two" => 2, "three" => 3];

var map3 = [1 => "cat", 1 => "dog"]; // Error: Duplicate Key

var map4 = ["h" => "Hello", "b" => "Bye"];
trace(map4["h"]); // Hello
```

`Map` можна перебрати за допомогою циклу `for`. Перебирати можна як значення, так і ключі:

```haxe
for (value in map) {
  // ...
}

for (key in map.keys()) {
  // ...
}
```
