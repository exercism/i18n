# Вступ

До окремих символів у `String` можна звертатися за допомогою того самого індексування, яке застосовується до масивів.
Однак [індекси][string-indices], які використовуються для рядків тексту (англ. string), _не_ є цілими числами, і працювати з ними напряму не можна.
Натомість їх потрібно обчислювати на основі якогось іншого відомого індексу, наприклад `startIndex`, який указує на позицію першого символу в непорожньому рядку тексту, використовуючи методи, доступні в бібліотеках [`String`][string-docs] і [`NSString`][nsstring-docs] (коли імпортовано модуль `Foundation`, рядки тексту у Swift мають доступ до всіх властивостей і методів NSString).

Наприклад, маємо такий рядок тексту:

```swift
let csv = "apple,pear,peach,orange,cherry,lime,goosberry"
```

Не можна написати `csv[21]`, щоб отримати «g» з «orange»; натомість треба обчислити значення типу `String.Index` і передати саме його.
Зауважмо, що ці індекси не призначені для того, щоб людина могла читати їх сама по собі.
Їх називають _непрозорими індексами_, бо людині не потрібно знати, що всередині них.

```swift
let index = csv.index(csv.startIndex, offsetBy: 21)
csv[index]
// "g"
print(index)
// prints Index(_rawBits: 1376513)
```

Однак зауважмо: якщо зсув не є допустимим індексом, тобто якщо він указував би на індекс перед `startIndex` або після `endIndex`, операція викличе помилку й аварійно завершить програму.
Щоб запобігти цій проблемі, можна вказати обмежувальний індекс.
Тоді метод повертає опціональний індекс, а для індексів, які інакше були б недопустимими, повертає nil.

```swift
let tooFar = csv.index(csv.startIndex, offsetBy: 200)
// error: Execution was interrupted, reason: EXC_BAD_INSTRUCTION (code=EXC_I386_INVOP, subcode=0x0).
let tooFarButSafe = csv.index(csv.startIndex, offsetBy: 200, limitedBy: csv.endIndex)
// nil
```

Крім того, індекси не можна використовувати для різних рядків тексту.
Наприклад, якщо взяти `index` для «g» з «orange», обчислений вище, і спробувати проіндексувати ним рядок `fam = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶, this is our cat: 🐱!"`, тобто `fam[index]`, програма аварійно завершиться.

У всього цього багато причин, але по суті всі вони зводяться до того, що з Unicode усе непросто.

Загалом, якщо потрібен довільний доступ до окремих символів, імовірно, варто використати іншу структуру даних, наприклад `Array<Character>`.

## Кілька корисних методів

У Swift є методи `first` і `last`, щоб отримати перший і останній символ рядка тексту.
Ці методи повертають опціональний символ, тож якщо рядок тексту порожній, вони повернуть nil.

```swift
let str = "Hello, world!"
print(str.first) // Prints Optional("H")
print(str.last)  // Prints Optional("!")
```

Можна також скористатися методами `prefix` і `suffix`, щоб отримати частину рядка тексту.
Ці методи приймають ціле число як аргумент і повертають частину рядка, що містить перші або останні n символів.

```swift
let str = "Hello, world!"
print(str.prefix(5)) // Prints "Hello"
print(str.suffix(6)) // Prints "world!"
```
