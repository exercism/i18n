# Докладніше

Rust реалізує тип [char][char type] для представлення одного символу. Літерал `char` записують в одинарних лапках, наприклад `'a'`.
Кожен `char` займає чотири байти й представляє одне [скалярне значення Unicode][unicode scalar].

Однак [`char`][character type] не завжди є тим, що ми звикли вважати літерою. Є мови, наприклад гінді, які використовують [діакритичні знаки][diacritics].
Це особливі символи, які змінюють символ, до якого приєднані. Хоча в Rust діакритичний знак є окремим `char`, саме діакритичний знак
разом із символом, який він змінює, ми зазвичай вважаємо літерою.

Символ разом із його діакритичним знаком називають [графемним кластером][grapheme cluster]. Існують зовнішні крейти, які можна використати для обробки графемних кластерів,
наприклад [unicode-segmentation][unicode-segmentation].

Приклад

```rust
pub fn main() {
    let text = "ü"; // a "u" with a diacritic
    let text_vec: Vec<char> = text.chars().collect(); // this gets the chars in "ü"
    println!("{:?}", text_vec.len()); // this prints the number of chars in "ü"
    println!("{:?}", text_vec[0]); // this prints the first char in "ü"
    println!("{:?}", text_vec[1]); // this prints the second char in "ü"
}
```

виводить

```rust
2
'u'
'\u{308}'
```

`'\u{308}'` - ще один спосіб записати літерал `char`. `\u` показує, що це символ `char` у Unicode, а `{308}` - унікальний номер Unicode для цього символу
або діакритичного знака.
