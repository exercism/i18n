# Вказівки

У цій вправі ми створюватимемо обробку помилок для простого калькулятора цілих чисел.
Калькулятор повинен підтримувати операції додавання, множення і ділення, повертаючи результат як рядок тексту (англ. string).
Також ми реалізуємо обробку помилок для неприпустимих операцій і ділення на нуль.

Мета - мати робочий калькулятор, який повертає рядок тексту в такому форматі:

```rust
SimpleCalculator::calculate(16, 51, "+"); // => returns "16 + 51 = 67"

SimpleCalculator::calculate(32, 6, "*"); // => returns "32 * 6 = 192"

SimpleCalculator::calculate(512, 4, "/"); // => returns "512 / 4 = 128"
```

## 1. Реалізуйте операції калькулятора

Головною функцією для цього завдання буде `SimpleCalculator::calculate`, яка приймає три аргументи: два цілі числа і `ByteArray`, що представляє операцію.
Реалізуйте такі операції:

- **Додавання** із символом `+`
- **Множення** із символом `*`
- **Ділення** із символом `/`

## 2. Обробіть неприпустимі операції

Якщо символ операції відрізняється від `+`, `*` або `/`, калькулятор має або панікувати, або повернути помилку:

- Якщо операція - порожній рядок тексту, панікуйте з повідомленням про помилку `ByteArray` `"Operation cannot be an empty string"`.
- Для будь-якої іншої неприпустимої операції поверніть `Result::Err("Operation is out of range")`.

```rust
SimpleCalculator::calculate(100, 10, "-"); // => returns Result::Err("Operation is out of range")

SimpleCalculator::calculate(8, 2, ""); // => panics with "Operation cannot be an empty string"
```

## 3. Обробіть помилки під час ділення на нуль

Коли ми намагаємося поділити на `0`, калькулятор має панікувати з повідомленням про помилку, яке вказує, що ділення на нуль неприпустиме.
Повернене значення має бути `felt252` зі значенням `'Division by zero is not allowed'`.

```rust
SimpleCalculator::calculate(512, 0, "/"); // => panics with 'Division by zero is not allowed'
```
