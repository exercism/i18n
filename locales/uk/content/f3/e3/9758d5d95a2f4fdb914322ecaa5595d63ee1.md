# Ключові слова static і self у класі

Клас - це одиниця організації коду в PHP, яка часто представляє екземпляр якоїсь речі, сервісу чи процедури.
За допомогою ключових слів `static` і `self` властивості та методи можуть існувати у привʼязці до класу для всіх екземплярів (або ж для жодного).

```php
<?php

class Book
{
    static $genre = 'Adventure';

    static function getGenre()
    {
        return self::$genre;
    }
}

// Usage
$genre = Book::$genre;
$genre = Book::getGenre();
```

## Обмеження

Статичні методи класу можуть викликати лише інші статичні властивості або методи власного класу.
