# Вказівки

У цій вправі нам доручено написати програмне забезпечення для пристрою шифрування, який працює, виконуючи перетворення даних. Нам потрібен спосіб гнучко створювати складні функції, поєднуючи простіші функції.

Для кожного завдання поверніть анонімну функцію, яку можна викликати з області видимості виклику.

## 1. Створіть функцію додавання

Реалізуйте `secret_add`. Вона повинна повертати функцію, яка приймає один аргумент і додає до нього аргумент, переданий у `secret_add`.

```gleam
let adder = secret_add(2)
adder(2)
// -> 4
```

## 2. Створіть функцію віднімання

Реалізуйте `secret_subtract`. Вона повинна повертати функцію, яка приймає один аргумент і віднімає від нього секрет, переданий у `secret_subtract`.

```gleam
let subtractor = secret_subtract(2)
subtractor(3)
// -> 1
```

## 3. Створіть функцію множення

Реалізуйте `secret_multiply`. Вона повинна повертати функцію, яка приймає один аргумент і множить його на секрет, переданий у `secret_multiply`.

```gleam
let multiplier = secret_multiply(7)
multiplier(3)
// -> 21
```

## 4. Створіть функцію ділення

Реалізуйте `secret_divide`. Вона повинна повертати функцію, яка приймає один аргумент і ділить його на секрет, переданий у `secret_divide`.

```gleam
let divider = secret_divide(3)
divider(32)
// -> 10
```

## 5. Створіть комбінатор функцій

Реалізуйте `secret_combine`. Вона повинна повертати функцію, яка приймає один аргумент і послідовно застосовує до нього дві функції, передані в `secret_combine`.

```gleam
let multiply = secret_multiply(7)
let divide = secret_divide(3)
let combined = secret_combine(multiply, divide)

combined(6)
// -> 14
```
