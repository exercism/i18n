# Вступ

## Бінарні дані

Elixir надає елегантний синтаксис для роботи з бінарними даними, як ми вже бачили на прикладі спеціальної форми `<<>>`, призначеної для роботи з [бітовими рядками][exercism-bitstrings].

Тип «бінарні дані» є спеціалізацією типу «бітовий рядок». Бітові рядки можуть мати будь-яку довжину (будь-яку кількість [бітів][wiki-bit]), а в бінарних даних кількість бітів ділиться на 8 без остачі. Тобто, працюючи з бінарними даними, ми часто думаємо про них у термінах [байтів][wiki-byte] (8 бітів). Байт може представляти цілі числа від `0` до `255`. Зазвичай значення байтів записують у [шістнадцятковій системі][wiki-hexadecimal], `0x00 - 0xFF`.

Бінарні літерали визначають за допомогою спеціальної форми `<<>>`. Коли ми визначаємо бінарний літерал, можна використовувати цілі числа та рядки тексту (англ. string). Цілі числа, більші за 255, переповнюються, і використовуються лише останні 8 бітів числа. Типово до значення застосовується модифікатор `::binary`. Ми можемо зʼєднувати бінарні дані оператором `<>/2`.

```elixir
<<255>> == <<0xFF>>
# Overflowing bits are truncated
<<256>> == <<0>>
<<2, 4, 6, 8, 10, 12, 14, 16>> == <<0x02, 0x04, 0x06, 0x08, 0x0A, 0x0C, 0x0E, 0x10>>
```

_Нульовий байт_ - це інша назва для `<<0>>`.

### Зіставлення зі зразком для бінарних даних

[Зіставлення зі зразком][exercism-pattern-matching] поширюється навіть на бінарні дані, і ми можемо зіставляти частину бінарних даних зі зразком так само, як робили б це з масивом.

```elixir
# Ignore the first 8 bytes, match and bind the remaining to `body`
<<_::binary-size(8), body::binary>>
```

Як і з іншими видами зіставлення зі зразком, ми можемо застосовувати це в сигнатурах функцій, щоб обирати потрібне визначення серед кількох.
