# Інструкції

Друг щойно надіслав нам повідомлення з важливою таємницею.
Щоб іншим було нелегко його прочитати, повідомлення зашифрували, виконавши низку операцій над бітами.
Нам потрібно буде написати методи, які допоможуть розшифрувати повідомлення.

## 1. Зсунути біти назад

Перший крок у розшифруванні повідомлення - скасувати зсув із процесу шифрування, зсунувши біти назад праворуч.
У процесі розшифрування будуть подальші кроки, які припускають, що нулі вставляються з лівого боку.

Реалізуйте метод `Secrets.shiftBack`, який приймає значення й кількість позицій для зсуву та виконує зсув.

```java
Secrets.shiftBack(0b1001, 2);
# => 0b0010
```

## 2. Встановити деякі біти

Далі є кілька бітів, які потрібно встановити в 1.

Реалізуйте метод `Secrets.setBits`, який приймає значення й маску та повертає результат встановлення бітів у значенні в 1.
Біт зі значення потрібно встановити в 1 там, де біт у масці також дорівнює 1.
Усі інші біти залишаються без змін.

```java
Secrets.setBits(0b0110, 0b0101);
# => 0b0111
```

## 3. Перевернути конкретні біти

Деякі біти перевертаються під час шифрування.
Їх потрібно буде перевернути назад, щоб розшифрувати повідомлення.

Реалізуйте метод `Secrets.flipBits`, який приймає значення й маску.
Маска вказує, які біти у значенні перевернути.
Якщо біт у масці дорівнює 1, цей біт перевертається у значенні.
Усі інші біти залишаються без змін.

```java
Secrets.flipBits(0b1100, 0b0101);
# => 0b1001
```

## 4. Очистити конкретні біти

Нарешті, є також певні біти, які завжди розшифровуються в 0.

Реалізуйте метод `Secrets.clearBits`, який приймає значення й маску.
Біти у `value` потрібно встановити в 0 там, де біт у масці дорівнює 1.
Усі інші біти залишаються без змін.

```java
Secrets.clearBits(0b0110, 0b0101);
# => 0b0010
```
