# Інструкції

Карл хоче вести список мов, які збирається вивчати на сайті Exercism.
Карлові потрібно вміти додавати нові мови, видаляти старі та перевіряти, чи є певні мови у списку.
Було б дуже захопливо, якби Карл захотів вивчати Java або Kotlin!

## 1. Визначте функцію, щоб перевірити, чи список мов порожній

Карлові потрібно знати, чи його список мов колись стане порожнім, щоб він міг знайти ще щось для вивчення!
Визначте метод під назвою `isEmpty`, який повертає `true`, якщо у списку немає жодної мови.

```java
if (languageList.isEmpty()) {
    findMoreLanguagesToLearn();
}
```

## 2. Визначте функцію, щоб додати мову до списку

Карл з нетерпінням чекає на вивчення Kotlin і Python!
Допоможіть Карлові почати: визначте метод під назвою `addLanguage`, який приймає мову, яку він хоче вивчати, і додає її до списку.

```java
languageList.addLanguage("Kotlin");
languageList.addLanguage("Python");
```

## 3. Визначте функцію, щоб видалити мову зі списку

Карл вирішив, що зараз не хоче вивчати Scala.
Допоможіть Карлові видалити її зі списку: визначте метод під назвою `removeLanguage`, який приймає мову, яку він видаляє, і видаляє її зі списку.

```java
languageList.removeLanguage("Scala");
```

## 4. Визначте функцію, яка повертає перший елемент списку

Карл хоче пригадати першу мову, яку він додав до списку (і яка досі в списку).
Визначте метод під назвою `firstLanguage`, який повертає першу мову в списку.

```java
String kotlin = languageList.firstLanguage(); // "Kotlin"
```

## 5. Визначте функцію, яка повертає кількість мов у списку

Карлові потрібно знати, скільки мов він намагається вивчити.
Допоможіть Карлові знайти відповідь: визначте метод під назвою `count`, який повертає кількість мов у списку.

```java
int two = languageList.count(); // 2
```

## 6. Визначте функцію, щоб визначити, чи мова є у списку

Карл намагається пригадати, чи хотів він вивчати Python або Ruby.
Визначте метод під назвою `containsLanguage`, який приймає мову, про яку він питає, щоб Карл міг це зʼясувати!

```java
boolean learningPython = languageList.containsLanguage("Python"); // true
boolean learningRuby = languageList.containsLanguage("Ruby"); // false
```

## 7. Визначте функцію, щоб визначити, чи список захопливий

Якщо Карл хоче вивчати Java або Kotlin, це дуже захопливо!
Визначте метод під назвою `isExciting`, який повертає true, якщо Карл хоче вивчати Java або Kotlin.

```java
javaLanguageList.isExciting() // true
neitherKotlinNorJavaLanguageList.isExciting() // false
```
