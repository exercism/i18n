# Про Dart

Dart поєднує обʼєктно-орієнтоване програмування і статичну типізацію з гнучкістю динамічних мов, як-от JavaScript.
Створений, щоб спростити типові завдання програмування, Dart швидко здобув популярність у спільноті розробників, зокрема завдяки тісній інтеграції з [Flutter](https://flutter.dev), популярним фреймворком для кросплатформної розробки.

## Ключові концепції Dart

- **Простий і знайомий:** Dart легко вивчити розробникам, знайомим із мовами, як-от Java, JavaScript або C#.
  У нього чистий і послідовний синтаксис, тож він зрозумілий новачкам.
- **Сучасна обʼєктно-орієнтована мова:** Dart втілює сучасні обʼєктно-орієнтовані принципи й дає надійну підтримку класів, успадкування та інтерфейсів.
- **Строга типізація з гнучкістю:** Dart належить до статично типізованих мов, але пропонує гнучке виведення типів і динамічні можливості, тож розробники отримують найкраще з обох світів.
- **Асинхронне програмування стало простим:** Ключові слова `async` і `await` у Dart спрощують конкурентність.
  Модель, керована подіями, побудована навколо **isolates** (легких структур, схожих на потоки), забезпечує ефективне асинхронне виконання без складної роботи з потоками.
- **Повний набір інструментів і бібліотек:** Dart має великий набір вбудованих бібліотек, а його екосистему підсилює [Pub.dev](https://pub.dev), менеджер пакетів із широким вибором бібліотек із відкритим кодом та інструментів.
- **Кросплатформна розробка:** Dart лежить в основі [Flutter](https://flutter.dev), одного з найпопулярніших фреймворків для створення швидких кросплатформних застосунків для мобільних пристроїв, вебу й настільних систем з єдиної кодової бази.
- **Підтримка вебу:** Код Dart можна транспілювати в JavaScript, тож він підходить і для клієнтської, і для серверної веброзробки.
  Фреймворки, як-от [AngularDart](https://angulardart.dev/), створені спеціально для вебзастосунків на Dart.
- **Можливості для серверної частини:** Dart призначений не лише для фронтенду: з його допомогою можна створювати масштабовані серверні застосунки з фреймворками, як-от [Shelf](https://pub.dev/packages/shelf).
- **Висока продуктивність:** Код Dart компілюється в нативний машинний код для мобільних і настільних застосунків та в оптимізований JavaScript для вебу, що забезпечує високу продуктивність на всіх платформах.

## Універсальність Dart

- **Мобільні застосунки:** Найпомітніше Dart використовують у розробці мобільних застосунків через Flutter, що дає змогу мати єдиний інтерфейс і бізнес-логіку на iOS та Android.
- **Веброзробка:** Dart можна компілювати в JavaScript для створення сучасних вебзастосунків, або через рідні фреймворки Dart, або через Flutter для вебу.
- **Розробка для настільних систем:** Разом із Flutter Dart тепер підтримує створення нативних застосунків для Windows, macOS і Linux, даючи справжню кросплатформність.
- **Серверні сервіси:** Dart дедалі частіше використовують у серверних сервісах завдяки лаконічному синтаксису й оптимізації продуктивності.
  Він здатен працювати з RESTful API, мікросервісами та багато іншим.
- **Інтеграція з Firebase і хмарою:** Dart має надійну підтримку інтеграції з Firebase та іншими хмарними сервісами через офіційні бібліотеки, що робить його привабливим вибором для застосунків, підʼєднаних до хмари.

## Останні вдосконалення

- **Безпека щодо null:** Dart запровадив **надійну безпеку щодо null**, яка допомагає позбутися помилок, повʼязаних із null-посиланнями, гарантуючи, що під час розробки типи без null використовують правильно.
- **Швидша компіляція:** Dart суттєво вдосконалив процес компіляції, пропонуючи і **випереджувальну компіляцію (AOT)**, і **компіляцію під час виконання (JIT)**, що забезпечує швидкий цикл розробки й оптимізовані релізні збірки.
- **Настільні та вбудовані пристрої:** Розширення Flutter на настільні та вбудовані платформи зробило Dart універсальнішим, ніж будь-коли, і дало розробникам змогу створювати застосунки для безлічі пристроїв поза мобільними й вебом.

Екосистема Dart, що зростає, потужна підтримка розробників і кросплатформні можливості роблять його привабливим вибором для сучасної розробки застосунків.
