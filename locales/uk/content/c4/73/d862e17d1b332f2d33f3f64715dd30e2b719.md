# Детальніше

Там, де типи не можна привести неявно, потрібно скористатися [оператором][cast-operator] явного приведення. Оператор приведення - це не що інше, як цільовий тип у дужках перед значенням, яке потрібно привести:

```csharp

int i = 7;
byte b = (byte)i; // Explicit cast from int to byte
```

Використання явного приведення потенційно небезпечним. Дві найпоширеніші помилки:

- Приведення до несумісного типу. Під час виконання програми буде викинуто виняток.
- Приведення до числового значення, яке є недостатньо «широким». У випадку цілих чисел це може призвести до конфлікту знаків або до викидання винятку переповнення

Зауваження: вираз типу `int` можна явно привести до `char`. Це може призвести до некоректного `char`.

[cast-operator]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/operators/type-testing-and-cast#cast-expression
