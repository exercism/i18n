# Вступ

## Числа

У ABAP є кілька числових типів. У цій вправі ми використаємо два з них:

- `i` для цілих значень, як-от кількість днів.
- `p` для упакованих десяткових значень, як-от погодинна ставка або знижка.

```abap
DATA billable_days TYPE i VALUE 22.
DATA rate_per_hour TYPE p LENGTH 8 DECIMALS 2 VALUE '89.89'.
```

Упаковані числа задають свою максимальну довжину та кількість десяткових знаків.
Десяткові літерали зазвичай записують як текстові значення, і компілятор або `CONV` перетворює їх на потрібний десятковий тип.

```abap
TYPES discount_rate TYPE p LENGTH 8 DECIMALS 6.

DATA discount TYPE discount_rate.
discount = CONV discount_rate( '0.15' ).
```

### Округлення

ABAP надає вбудовані числові функції для округлення.
Функція `floor` округлює вниз до найближчого цілого числа, а `ceil` округлює вгору до найближчого цілого числа.

```abap
DATA full_months TYPE i.
full_months = floor( 70 / 22 ).

DATA rounded_cost TYPE i.
rounded_cost = ceil( '14527.2' ).
```

## Арифметичні оператори

ABAP підтримує арифметичні оператори для обчислень із числовими значеннями.

```abap
DATA day_rate TYPE p LENGTH 8 DECIMALS 2.
day_rate = rate_per_hour * 8.
```

Основні оператори:

- `+` для додавання.
- `-` для віднімання.
- `*` для множення.
- `/` для ділення.
- `MOD` для остачі від ділення цілих чисел.

```abap
DATA remaining_days TYPE i.
remaining_days = num_days MOD 22.
```

ABAP обчислює множення та ділення перед додаванням і відніманням.
Дужки можна використати, щоб явно задати потрібний порядок обчислень.

```abap
DATA discounted_rate TYPE p LENGTH 8 DECIMALS 2.
discounted_rate = monthly_rate * ( 1 - discount ).
```
