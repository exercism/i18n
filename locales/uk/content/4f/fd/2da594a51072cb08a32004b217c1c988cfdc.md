# Вступ

Високосний рік (у григоріанському календарі) настає:

- У кожному році, який ділиться без остачі на 4.
- Окрім випадку, коли рік ділиться без остачі на 100, і тоді він високосний лише за умови, що також ділиться без остачі на 400.

Кілька прикладів:

- 1997 рік не був високосним, бо не ділиться на 4.
- 1900 рік не був високосним, бо не ділиться на 400.
- 2000 рік був високосним!
