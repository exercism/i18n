# Підказки

## 1. Три номери

- У заголовку класу назву абстрактного класу вказано після `<`:
  `class JUGGLING < $ACT is`.
- Кожен із них має визначати і `name`, і `minutes`, саме так, як їх
  оголошує абстрактний клас. Якщо пропустити одне з них, компілятор видасть
  помилку із назвою цієї підпрограми.
- Кожному також потрібен `create`, інакше `#JUGGLING` не матиме що викликати.
  Для двох із них усе зводиться до `create : SAME is return new; end;`.
- `TRAPEZE` потребує атрибута для висоти та `create`, який його приймає.
- `+` зʼєднує число з рядком тексту (англ. string), тож `"Trapeze at " + height + "m"`
  не потребує перетворення.

## 2. Вистава

- Тип аргументу має бути `ARRAY{$ACT}`. Саме завдяки цьому один масив може
  містити всі три різновиди.
- `acts.elt!` дає `$ACT`. Виклик `.minutes` на ньому сам запускає потрібний
  номер - це динамічне звʼязування, і саме в цьому суть вправи. Тут нічого
  перевіряти і не потрібно писати жодного `typecase`.
- `billing` будує рядок тексту в циклі, тому `FSTR`, і `", "` ставиться перед
  кожним іменем, крім першого.
- `longest` зберігає найкращий номер, знайдений досі. Якщо почати найкращі
  хвилини з `-1`, перший номер завжди його перевершить, і це дає змогу
  обробити порожню виставу без окремого випадку: імʼя залишається `""`.
