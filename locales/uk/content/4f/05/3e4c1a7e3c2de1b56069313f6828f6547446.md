Хоча в Haxe можна зʼєднувати рядки тексту (англ. string) і вручну, він підтримує [інтерполяцію рядків][string-interpolation], яка дає коротший і зручніший синтаксис:

```haxe
var x = 42;
//The following two statements are equivalent:

// manual concatenation
trace("the number is " + x);

// using interpolation
trace('the number is $x');
```

Як показано вище, інтерпольовані рядки тексту беруться в одинарні лапки (`'`), на відміну від звичайних [рядків тексту][strings], і можуть містити спеціальні ідентифікатори, позначені знаком долара (`$`), які вмикають інтерполяцію.

Можна також включати цілі вирази за допомогою `${expr}`, де `expr` може бути будь-яким коректним виразом Haxe:

```haxe
trace('the next number is ${x + 1}');
```

Щоб вимкнути інтерполяцію, коли потрібен справжній знак долара, можна використати `$$`:

```haxe
trace('the price is $$42'); // outputs: the price is $42
```

Насамкінець зауважимо, що інтерполяція рядків є можливістю, яка працює на етапі компіляції, і жодним чином не впливає на швидкодію під час виконання. Внутрішньо компілятор Haxe генерує код, еквівалентний ручному зʼєднанню рядків.

[string-interpolation]: https://haxe.org/manual/lf-string-interpolation.html
[strings]: https://haxe.org/manual/std-String.html
