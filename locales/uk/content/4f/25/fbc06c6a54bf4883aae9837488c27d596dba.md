# Запуск тестів

У терміналі перейдіть у базову теку вправи, а потім запустіть тести такою командою:

```bash
$ gleam test
```

Це запустить файл тестів із підтеки `test`, тобто файл, назва якого закінчується на `_test.gleam`

## Функції тестів

Тести використовують [власний фреймворк для тестів](https://github.com/exercism/gleam-test-runner/tree/main/runner).
Фреймворк вважатиме тестом будь-яку публічну функцію в теці `test`, назва якої закінчується на `_test`.

Наприклад:

```gleam
import bob
import exercism/should

pub fn shouting_test {
  bob.hey("WATCH OUT!")
  |> should.equal("Whoa, chill out!")
}
```
