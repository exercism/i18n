# Вступ

## Результати

Gleam не використовує винятки для обробки помилок. Замість цього функції, які можуть завершитися успішно або невдачею, повертають узагальнений тип `Result`.

Тип `Result` вбудований у мову, тому нам не потрібно визначати чи імпортувати його. Але якби ми визначили його самостійно, він мав би такий вигляд:

```gleam
pub type Result(value, error) {
  Ok(value)
  Error(error)
}
```

Варіант `Ok` повертається, коли функція завершується успішно, а варіант `Error` - коли функція зазнає невдачі.

Результати дуже поширені в Gleam, і програмісти Gleam зазвичай використовують [модуль `gleam/result`](https://hexdocs.pm/gleam_stdlib/gleam/result.html), щоб полегшити роботу з ними.

Функцію `result.map` можна використати, щоб викликати функцію для значення всередині результату, якщо це `Ok`, або щоб передати `Error` без змін.

```gleam
Ok(1)
|> result.map(fn(x) { x + 1 })
// -> Ok(2)

Error("Oh no!")
|> result.map(fn(x) { x + 1 })
// -> Error("Oh no!")
```

Функція `result.try` схожа, але функція зворотного виклику має повертати результат. Це корисно для обʼєднання кількох функцій, які повертають результати.

```gleam
Ok(1)
|> result.try(fn(x) { Ok(x + 1) })
// -> Ok(2)

Ok(1)
|> result.try(fn(x) { Error("Nope!") })
// -> Error("Nope!")
```
