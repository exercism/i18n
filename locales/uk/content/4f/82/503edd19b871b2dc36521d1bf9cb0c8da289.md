# Вступ

У Python є дві конструкції для циклів.
Цикли `while` призначені для _невизначеної_ (непорахованої) ітерації, а цикли `for` - для _визначеної_ (порахованої) ітерації.
Ключові слова `break`, `continue` та `else` допомагають налаштовувати поведінку циклу.
Функції `range(<length of sequence>)` та `enumerate(<iterable>)` допомагають із підрахунком ітерацій та індексацією.


У циклів `while` кількість повторень не задається заздалегідь, і вони будуть тривати доти, доки вираз `loop` або «тест» буде обчислюватися як `True`.
Цикл завершиться, коли вираз циклу буде обчислюватися як `False`.

```python
while expression:
    set_of_statements
```

Цикли `for` перебирають значення будь-якої послідовності й завершуються, коли значень більше не повертається.
Функція `range(<length of sequence>)` дає лічильник `loop` або послідовність, коли немає структури даних чи іншого обʼєкта, який можна перебрати.

```python
# Python will keep track of the loop count internally.
for item in sequence:
    set_of_statements
    
# `range()` is used as an explicit loop counter.  
# This will loop 12 times, from index 0 to index 11.
for item in range(12):
    set_of_statements
```
