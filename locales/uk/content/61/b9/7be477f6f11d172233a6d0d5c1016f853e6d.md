# Вбудовані числові типи в Haskell

## Числа

Стандартна бібліотека Haskell, відома як ***Prelude***, визначає більшість базових числових типів: цілі числа фіксованого розміру (`Int`), цілі числа довільної точності (`Integer`), числа з плаваючою комою одинарної точності (`Float`) і числа з плаваючою комою подвійної точності (`Double`).
Інші числові типи, як-от раціональні та комплексні числа, визначені в додаткових бібліотеках.

`Integer` вміщує будь-яке число, яким би великим воно не було, аж до межі памʼяті машини, тоді як `Int` відповідає множині додатних і відʼємних цілих чисел, які можна виразити в 32 або 64 бітах (гарантовано щонайменше від -2^29 до 2^29).

`Float` відповідає множині дійсних чисел, обмеженій точністю компʼютера.
Операції, визначені для чисел, зазвичай працюють або з одним типом, або з іншим, але не з обома одночасно.

Функції для перетворення між `Float` та `Integer` включають, серед інших, `toFloat`, яка перетворює `Int`/`Integer` на `Float`, і `ceiling`, яка перетворює `Float` на `Int`.

## Арифметичні оператори

У Haskell є три оператори «піднесення до степеня», які працюють по-різному та приймають різні типи аргументів.

- `**` приймає два **числа з плаваючою комою** і використовує логарифми, щоб обчислити степінь.
- `^^` приймає **число з плаваючою комою** і підносить його до додатного або відʼємного **цілого** степеня.
- `^` приймає **будь-який числовий тип** і підносить його до **додатного цілого** степеня.

Перетворення з цілочисельного типу (`Int` або `Integer`) на будь-який інший числовий тип виконується за допомогою функції `fromIntegral`.
Цільовий тип виводиться автоматично.
Наприклад:

```haskell
n :: Integer
n = 6
x :: Float
x = fromIntegral n      --> x = 6.0

m :: Int
m = 7
y :: Double
y = fromIntegral m      --> y = 7.0
```

Ділення цілих чисел трохи складніше.
Якщо застосувати звичайний оператор `/` до цілих чисел, то отримаємо повідомлення про помилку (хоча вираз `4/3` усе ж працює, бо Haskell любʼязно підвищує цілочисельні літерали до чисел з плаваючою комою, коли це потрібно).
Натомість ділення цілих чисел виконується за допомогою набору іменованих операторів.

У Haskell є одна витончена хитрість з операторами: будь-яку функцію, що приймає два аргументи, можна використати як оператор, узявши її назву у зворотні лапки.
Отже, наступні два рядки означають абсолютно те саме:

```haskell
 d = 7 `div` 3
 d = div 7 3
```

Зважаючи на це, ось оператори ділення цілих чисел:

- `quot`: повертає частку двох чисел.
  Це результат ділення, який потім відкидає дробову частину в бік нуля.
- `rem`: повертає остачу від частки.
- `div`: схожий на `quot`, але округлюється вниз до мінус нескінченності.
- `mod`: повертає остачу від ділення за модулем двох чисел.
  Це схоже на `rem`, але має інші правила, коли `div` повертає відʼємне число.

Так само, як функцію з двома аргументами можна перетворити на оператор, можна перетворити оператор на функцію з двома аргументами, узявши його в круглі дужки.
Отже, наступні два рядки означають те саме:

```haskell
(+) 3 4
3 + 4
```
