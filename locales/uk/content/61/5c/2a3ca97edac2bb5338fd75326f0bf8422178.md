# Інструкції

У цій вправі ми змоделюємо перший хід гри в [блекджек][blackjack].

## 1. Обчислимо значення будь-якої карти.

Ми отримаємо дві карти й побачимо відкриту карту дилера.
Усі карти подано як рядок тексту (англ. string), наприклад "ace", "king", "three", "two" тощо.
Значення кожної карти такі:

| card  | value |  card   | value |
| :---: | :---: | :-----: | :---: |
|  ace  |  11   |  eight  |   8   |
|  two  |   2   |  nine   |   9   |
| three |   3   |   ten   |  10   |
| four  |   4   |  jack   |  10   |
| five  |   5   |  queen  |  10   |
|  six  |   6   |  king   |  10   |
| seven |   7   | _інші_  |   0   |

~~~~exercism/note
Зазвичай тузи можуть мати значення 1 або 11, але для простоти припустімо, що вони можуть мати лише значення 11.
~~~~

Реалізуйте метод `Blackjack.parse_card`, який приймає карту як рядок тексту в аргументі.
Метод має повернути значення карти як ціле число.

```Crystal
Blackjack.parse_card("ace")
# => 11
```

## 2. Назвімо діапазони значень.

Рахунок гравця треба розподілити за діапазонами значень.
Рахунок гравця обчислюється додаванням значень двох карт гравця.
Використовуються такі діапазони:

|   range   |  value   |
| :-------: | :------: |
|    low    | [4, 11]  |
|    mid    | [12, 16] |
|   high    | [17, 20] |
| blackjack |   [21]   |

Реалізуйте метод `Blackjack.card_range`, який приймає дві карти як рядки тексту в аргументах.
Метод має повернути назву діапазону значень, до якого належать ці дві карти.

```Crystal
Blackjack.card_range("ten", "king")
# => "high"
```

## 3. Реалізуємо логіку ухвалення рішень для першого ходу.

Залежно від наших двох карт і карти дилера для першого ходу в грі є стратегія, яка передбачає такі варіанти:

- Зупинитися (S)
- Взяти карту (H)
- Розділити (P)
- Автоматична перемога (W)

Хоча вона ще не оптимальна, ми будемо дотримуватися стратегії, яку розробляє наш друг Алекс. Ось вона:

- Якщо в нас пара тузів, їх треба завжди розділяти.
- Якщо в нас блекджек (дві карти, які в сумі дають 21), і в дилера немає туза, фігурної карти чи десятки, ми автоматично перемагаємо.
  Якщо ж у дилера є одна з цих карт, доведеться зупинитися й чекати, поки відкриють другу карту.
- Якщо сума наших карт потрапляє в діапазон [17, 20], треба завжди зупинятися.
- Якщо сума наших карт потрапляє в діапазон [12, 16], треба завжди зупинятися, крім випадку, коли в дилера 7 або більше: тоді треба завжди брати карту.
- Якщо сума наших карт 11 або менше, треба завжди брати карту.

Реалізуйте метод `Blackjack.first_turn`, який приймає три карти як рядки тексту в аргументах.
Метод має повернути рішення, яке треба ухвалити, як рядок тексту.

```Crystal
Blackjack.first_turn("ace", "ace", "two")
# => "P"
```
