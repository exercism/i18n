# Встановлення

Найпростіший спосіб встановити Ceylon - просто **не** встановлювати його.
Більшість вправ можна розвʼязати за допомогою нашого [веб-IDE](http://try.ceylon-lang.org/).

Однак за бажанням можна встановити дистрибутив для командного рядка; найпростіше зробити це через [SDKMAN](http://sdkman.io/), тож спершу потрібно встановити його, якщо його ще немає, а потім просто набрати `sdk install ceylon` у терміналі.

Користувачі OSX також можуть встановити його через [менеджер пакетів Homebrew](http://mxcl.github.com/homebrew/).

Інструкції зі встановлення для інших платформ, а також для Ceylon IDE, плагіна для Eclipse, можна знайти на [офіційному сайті](http://ceylon-lang.org/download/).
