# Вступ

[Nil][nil-dictionary] - англійське слово, що означає «ніщо» або «нуль».
У Ruby `nil` використовується, щоб виразити _відсутність_ обʼєкта.
В інших мовах програмування подібну роль можуть відігравати значення `null` або `none`.

```ruby
# I do not have a favorite color
favorite_color = nil
```

Коли Ruby вперше натрапляє на змінну екземпляра, вона отримує типове значення `nil`, аж доки їй не присвоять інше.

[nil-dictionary]: https://www.merriam-webster.com/dictionary/nil
