# Вступ

_Тип переліку_ - це особливий тип даних, який дає змогу змінній набувати одне зі значень наперед визначеного набору констант.
Значення змінної має дорівнювати одному з наперед визначених для неї значень.
Поширені приклади: сторони світу (значення `NORTH`, `SOUTH`, `EAST` і `WEST`) та дні тижня.

Оскільки це константи, назви полів типу переліку записують великими літерами.

## Визначення типу переліку

У мові програмування Java тип переліку визначають за допомогою ключового слова `enum`.
Наприклад, тип переліку для днів тижня ми задамо так:

```java
public enum DayOfWeek {
    SUNDAY,
    MONDAY,
    TUESDAY,
    WEDNESDAY,
    THURSDAY,
    FRIDAY,
    SATURDAY
}
```

Типи переліку варто використовувати щоразу, коли потрібно подати фіксований набір констант.
Це стосується й природних переліків, як-от планети Сонячної системи, а також наборів даних, усі можливі значення яких відомі ще на етапі компіляції: наприклад, пункти меню, прапорці командного рядка тощо.

## Використання типу переліку

Ось код, який показує, як використати перелік `DayOfWeek`, визначений вище:

```java
public class Shop {
    public String getOpeningHours(DayOfWeek dayOfWeek) {
        switch (dayOfWeek) {
            case MONDAY:
            case TUESDAY:
            case WEDNESDAY:
            case THURSDAY:
            case FRIDAY:
                return "9am - 5pm";
            case SATURDAY:
                return "10am - 4pm"
            case SUNDAY:
                return "Closed.";
        }
    }
}
```

```java
var shop = new Shop();
shop.getOpeningHours(DayOfWeek.WEDNESDAY);
// => "9am - 5pm"
```

## Додавання методів і полів

Типи переліку в мові програмування Java значно потужніші, ніж їхні аналоги в інших мовах.
Оголошення `enum` визначає _клас_ (який називають _типом переліку_).
Тіло класу переліку може містити методи та інші поля:

```java
public enum Rating {
    GREAT(5),
    GOOD(4),
    OK(3),
    BAD(2),
    TERRIBLE(1);

    private final int numberOfStars;

    Rating(int numberOfStars) {
        this.numberOfStars = numberOfStars;
    }

    public int getNumberOfStars() {
        return this.numberOfStars;
    }
}
```

Виклик методу `getNumberOfStars` в елемента типу переліку `Rating`:

```java
Rating.GOOD.getNumberOfStars();
// => 4
```
