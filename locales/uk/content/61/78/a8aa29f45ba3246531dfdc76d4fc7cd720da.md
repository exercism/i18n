# Булеві значення (англ. Boolean)

`BOOL` має одне з двох значень: `true` або `false`.

```sather
   ready : BOOL is
      return true;
   end;
```

## Порівняння

| Оператор | Запитує | Приклад |
| --- | --- | --- |
| `=` | однакові? | `age = 13` |
| `/=` | різні? | `age /= 13` |
| `<` | менше ніж | `age < 13` |
| `<=` | менше або дорівнює | `age <= 13` |
| `>` | більше ніж | `age > 13` |
| `>=` | більше або дорівнює | `age >= 13` |

Вони працюють із числами, а `=` і `/=` також працюють із рядками тексту (англ. string).

## Три оператори

| Оператор | Запис | Коли правда |
| --- | --- | --- |
| and | `a and b` | обидва - правда |
| or | `a or b` | принаймні один - правда |
| not | `~a` | `a` - неправда |

`and` і `or` використовують **обчислення за коротким замиканням**: `a and b` не витрачає час на `b`, щойно зʼясується, що `a` неправда, бо відповідь уже відома. Так само `a or b` припиняє обчислення, щойно `a` виявиться правдою. Це має значення, коли права частина виразу затратна в обчисленні або спричинить помилку, якби її виконали.

## Повернення порівняння напряму

Процедура, чия робота - поставити питання, має повертати саме питання, а не добирати відповідь через умовну конструкцію:

```sather
   -- say this
   old_enough(age : INT) : BOOL is
      return age >= 13;
   end;
```

Запис `if age >= 13 then return true else return false end` займає три рядки, щоб сказати те, що вже сказало порівняння, і кожен досвідчений читач це помітить.

## Пріоритет

Найміцніше звʼязує `~`, потім `and`, потім `or`. Отже,

```sather
~a and b or c
```

означає `((~a) and b) or c`. Дужки нічого не коштують, і вони того варті щоразу, коли читачеві інакше довелося б пригадувати цей порядок, щоб простежити за рядком.
