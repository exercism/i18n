# Інструкції

Мері - велика шанувальниця серіалу «Зоряний шлях: Наступне покоління».
Вона часто грає в настільні рольові ігри, де вони з друзями уявляють себе екіпажем зорельота «Ентерпрайз».
Персонаж Мері - капітан Пікар, тож їй доводиться вести журнал капітана.
Їй подобається творча частина гри, але не подобається генерувати випадкові дані на ходу.

Допоможімо Мері, створивши генератори випадкових даних, які часто трапляються в журналі капітана.

~~~~exercism/note
Початкова реалізація цієї вправи приймає екземпляр `java.util.Random` як аргумент конструктора.
Це дозволяє тестам вправи передати екземпляр із наперед заданим зерном, завдяки чому результати тестів стають передбачуваними.

Тому у своїй реалізації ми маємо використати наданий екземпляр `java.util.Random`.
~~~~

## 1. Згенеруйте випадкову планету

Під час своїх подорожей «Ентерпрайз» натрапляє на безліч планет.
У всесвіті «Зоряного шляху» планети поділяють на категорії за їхніми властивостями.
Наприклад, Земля належить до планет класу `M`.
Усі можливі класи планет: `D`, `H`, `J`, `K`, `L`, `M`, `N`, `R`, `T` і `Y`.

Реалізуйте метод `randomPlanetClass()`.
Він має повертати один із класів планет випадковим чином.

```java
captainsLog.randomPlanetClass();
// => "K"
```

## 2. Згенеруйте випадковий реєстраційний номер зорельота

«Ентерпрайз» (реєстраційний номер `NCC-1701`) не єдиний зореліт у космосі!
Коли він зустрічається з іншим зорельотом, Мері потрібно занести його реєстраційний номер до журналу.

Реєстраційні номери починаються з префікса «NCC-», після чого йде число від `1000` до `9999` (включно).

Реалізуйте метод `randomShipRegistryNumber()`, який повертає випадковий реєстраційний номер зорельота.

```java
captainsLog.randomShipRegistryNumber();
// => "NCC-1947"
```

## 3. Згенеруйте випадкову зоряну дату

Який сенс у журналі, якщо в ньому немає дат?

Зоряна дата - це число з плаваючою комою.
Пригоди «Ентерпрайза» з першого сезону «Наступного покоління» відбуваються між зоряними датами `41000.0` і `42000.0`.
«4» означає 24 століття, а «1» - перший сезон.

Реалізуйте метод `randomStardate()`, який повертає число з плаваючою комою у проміжку від `41000.0` (включно) до `42000.0` (не включно).

```java
captainsLog.randomStardate();
// => 41458.15721310934
```
