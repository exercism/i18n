# Інструкції

У цій вправі ми з другом граємо в гру на вгадування числа.
Правила прості: ми таємно загадуємо число від `1` до `100`, а друг намагається вгадати, яке число ми загадали.
Щоб допомогти другові, ми відповідаємо по-різному залежно від того, наскільки близьким було припущення до загаданого числа (`42`).
Ось правила для різних можливих вхідних даних:

- Якщо припущення дорівнює `42`: "Correct"
- Якщо припущення дорівнює `41` або `43`: "So close"
- Якщо припущення менше за `41`: "Too low"
- Якщо припущення більше за `43`: "Too high"

На нас чекають чотири завдання: закодувати відповіді на припущення.

## 1. Відповідь на правильне припущення

Реалізуйте функцію `reply`, щоб відповідати на правильне припущення:

```haskell
reply 42
-- -> "Correct"
```

## 2. Відповідь на близьке припущення

Змініть функцію `reply`, щоб вона відповідала на близькі припущення:

```haskell
reply 41
-- -> "So close"
```

## 3. Відповідь на занадто низькі припущення

Змініть функцію `reply`, щоб вона відповідала на занадто низькі припущення:

```haskell
reply 25
-- -> "Too low"
```

## 4. Відповідь на занадто високі припущення

Змініть функцію `reply`, щоб вона відповідала на занадто високі припущення:

```haskell
reply 88
-- -> "Too high"
```
