# Alias

[Спеціальна форма `alias`][alias] дає змогу скоротити або змінити назву, під якою ми посилаємося на зовнішній модуль. Власну назву можна задати за допомогою опції `:as`.

```elixir
defmodule Square do
  alias Integer, as: I

  def area(a), do: I.pow(a, 2)
end
```

Якщо використати її без аргументів, вона скорочує назву модуля до останньої частини, наприклад

```elixir
alias MyApp.Account.User
# is the same as
alias MyApp.Account.User, as: User
```

Кілька таких `alias` можна згрупувати за допомогою `{}`:

```elixir
alias MyApp.Account.{User, EmailValidation}
# is the same as
alias MyApp.Account.User
alias MyApp.Account.EmailValidation
```

Зазвичай `alias` додають на початку визначення модуля, але його можна додати будь-де. Вони мають лексичну область видимості, а це означає, що `alias`, доданий усередині визначення функції, не буде доступним в іншій функції.

Невикористані `alias` спричиняють попередження компілятора.

[alias]: https://hexdocs.pm/elixir/Kernel.SpecialForms.html#alias/2
