# Докладніше

[Словники][dictionaries] належать до трьох основних типів колекцій у Swift.
Словники зберігають відповідності між _ключами_, які є елементами одного типу, і _значеннями_, які є елементами іншого типу (можливо, того самого, що й ключі).

Літерали словників записують як послідовність пар `key: value`, розділених комами й узятих у квадратні дужки.
Порожній словник можна записати, поставивши після назви типу словника пару дужок, наприклад `[Int: String]()`, або, якщо тип можна визначити з контексту, просто як пару квадратних дужок із двокрапкою всередині: `[:]`.
Назви типів словників записують одним із двох способів: `Dictionary<K, V>` або `[K: V]`, де `K` - тип ключів у словнику, а `V` - тип значень.
Під час створення порожнього словника тип потрібно вказати.

```swift
var addresses: Dictionary<String, String> = ["The Munsters": "1313 Mockingbird Lane", "The Simpsons": "742 Evergreen Terrace", "Buffy Summers": "1630 Revello Drive"]
var sequences: [String: [Int]] = ["Euler's totient": [1, 1, 2, 2, 4, 2, 6, 4], "Lazy caterer": [1, 2, 4, 7, 11, 16, 22, 29, 37], "Carmichael": [561, 1105, 1729, 2465, 2821, 6601, 8911, 10585, 15841]]
let constants = ["pi": 3.14159, "e": 2.71828, "phi": 1.618033, "avogadro": 6.02214076e23]
var emptyDict1: [Int: Int] = [:]
var emptyDict2 = [Character: String]()
var emptyDict3 = Dictionary<Int, Double>()
```

До елементів словника можна звертатися за допомогою індексної нотації: після назви словника ставлять квадратні дужки, у яких записано ключ, для якого ми хочемо отримати відповідне значення.

Звернімо увагу, однак, що повернене значення має не тип _Value_, а опціональний тип _Value?_.
Це тому, що можна передати ключ, якого в словнику немає.
У таких випадках Swift повертає `nil`, а не викидає помилку.

```swift
let munster: String? = addresses["The Munsters"]
// Returns "1313 Mockingbird Lane"
let carmichael = sequences["Carmichael"]
// Returns [561, 1105, 1729, 2465, 2821, 6601, 8911, 10585, 15841]
let planck = constants["planck"]
// Returns nil
```

Щоб уникнути опціонального типу поверненого значення, можна вказати типове значення, яке повертається, якщо ключа в словнику немає.

```swift
let e: Double = constants["e", default: 0]
// Returns 2.71828
let hoagie: [Int] = sequences["Hoagie", default: []]
// Returns []
let betty = addresses["Betty Cooper", default: "Address unknown"]
// Returns "Address unknown"
```

Цю індексну нотацію можна використовувати і для отримання значення, повʼязаного з ключем, і для його встановлення, за умови, що словник визначено як змінну (тобто за допомогою `var`).
Так можна оновити значення, повʼязане з ключем, або додати до словника нову пару _key: value_.

```swift
sequence["Euler's totient"]?.append(contentsOf: [6,4])
sequence["Euler's totient"]
// Returns [1, 1, 2, 2, 4, 2, 6, 4, 6, 4]
addresses["Betty Cooper"] = "111 Queens Ave."
addresses["Betty Cooper", default: "Address unknown"]
// Returns "111 Queens Ave."
constants["Gelfond's"] = 23.140692
// compiler error: "Cannot assign through subscript: 'constants' is a 'let' constant"
```

Як і масиви, пари _key: value_ у словнику можна перебирати по одній за допомогою циклу `for-in`.
Такий цикл бере кожну пару _key: value_ зі словника й привʼязує її до вказаного імені, щоб далі працювати з нею всередині тіла циклу.
Пару подано як кортеж, і його можна розкласти, як і будь-який інший кортеж, щоб присвоїти кожен елемент окремому імені. Наприклад, щоб надрукувати адресну книгу, можна написати так:

```swift
for (name, address) in addresses {
  print("\(name) lives at \(address)")
}

// prints out:
// Betty Cooper lives at 111 Queens Ave.
// The Munsters lives at 1313 Mockingbird Lane
// The Simpsons lives at 742 Evergreen Terrace
// Buffy Summers lives at 1630 Revello Drive
```

Як і інші типи колекцій, словники можна сортувати за довільними функціями сортування.
Для цього спершу треба визначити функцію, яка приймає дві пари _key: value_, подані як кортежі, і повертає `Bool`: повернене значення має бути `true`, якщо перша пара _key: value_ має стояти у відсортованому результаті _перед_ другою парою _key: value_.

Далі цю функцію можна передати в метод `sorted(by:)` словника, який поверне відсортований масив пар _key: value_.
Наприклад, щоб відсортувати словник `constants` за значенням константи плюс кількістю символів у її назві, можна написати так:

```swift
func weirdSort(_ lhs: (String, Double), _ rhs: (String, Double)) -> Bool {
  let left = lhs.1 + Double(lhs.0.count)
  let right = rhs.1 + Double(rhs.0.count)
  return left < right
}

let sortedConstants = constants.sorted(by: weirdSort)
// returns [(key "e", value 2.71828), (key "phi", value 1.618033), (key "pi", value 3.14159), (key "avogadro", value 6.02214076e+22)]
```
