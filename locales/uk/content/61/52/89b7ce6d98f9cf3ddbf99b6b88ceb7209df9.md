# Вступ

## Атрибути

[C# `Attribute`](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/) дає змогу оздобити оголошення, щоб повʼязати з ним метадані: з класом, методом, переліком, полем, властивістю чи будь-яким [іншим підтримуваним](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/#attribute-targets) оголошенням.

Застосувати атрибут можна, додавши його рядком перед оголошенням за допомогою `ClassAttribute` та `FieldAttribute`:

```csharp
[Class]
class MyClass
{
    [Field]
    int myField;
}
```

Ці декларативні метадані лише додають до коду додаткову структуровану інформацію й не змінюють його поведінки, але інші частини коду використовують ці метадані, щоб змінити те, як поводиться ціль атрибута, або додати, змінити, прибрати чи обмежити деякі її можливості.

Існує багато [наперед визначених і зарезервованих атрибутів](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/attributes/general#conditional-attribute), наприклад: `Flags`, `Obsolete`, `Conditional` і `Experimental`. Кожен із них має конкретне семантичне значення, яке можна знайти в документації C#. Зауважмо, що повна назва атрибута, як-от [`Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute), має вигляд `<Name>Attribute` (наприклад, `FlagsAttribute`).

## Переліки з прапорцями

C# [`enum`](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/builtin-types/enum) представляє фіксований набір іменованих констант (перелік).

Зазвичай член `enum` може вказувати лише на одну з цих іменованих констант. Однак іноді корисно вказати більше ніж одну константу. Для цього можна позначити `enum` за допомогою [атрибута `Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute).

Перелік із прапорцями можна оголосити так (використовуючи двійкову нотацію цілих чисел `0b`):

```csharp
[Flags]
enum PhoneFeatures
{
    Call = 0b00000001,
    Text = 0b00000010
}
```

У примірника `PhoneFeatures` зі значенням `0b00000011` встановлено обидва прапорці, `Call` _і_ `Text`.

Типово для значень членів `enum` використовується тип `int`. Можна використати інший цілий тип, вказавши його в оголошенні переліку:

```csharp
[Flags]
enum PhoneFeatures : byte
{
    Call = 0b00000001,
    Text = 0b00000010
}
```
