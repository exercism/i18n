# Інструкції

Танцювальний колектив планує свій підсумковий концерт року: скільки є способів розставити танцівників і як розподіляється між актами тривалість вистави.

Усі пʼять завдань містяться в класі `FORMATION_COUNT`.

## 1. Скільки є шикувань?

Якщо танцівників `n`, то кількість способів вишикувати їх у лінію дорівнює `n` факторіал: `n` варіантів для першого місця, далі `n-1` для наступного, і так далі. Поверніть це як `INTI`. Нуль танцівників дає рівно одне шикування, а саме порожнє.

```sather
FORMATION_COUNT::line_ups(5)
-- => 120
FORMATION_COUNT::line_ups(20)
-- => 2432902008176640000
```

## 2. Записати його повністю

Те саме число як рядок тексту (англ. string), з усіма його цифрами.

```sather
FORMATION_COUNT::line_ups_text(25)
-- => "15511210043330985984000000"
```

Тип `INT` не може вмістити таке число, і в цьому саме суть завдання.

## 3. Частка одного акту

Вистава з `acts` однакових актів дає кожному акту `1/acts` тривалості вистави. Поверніть це як `RAT`.

```sather
FORMATION_COUNT::share(3)
-- => 1/3
```

## 4. Два акти разом

Додайте дві частки та поверніть точну суму.

```sather
FORMATION_COUNT::combined(FORMATION_COUNT::share(2), FORMATION_COUNT::share(3))
-- => 5/6
```

## 5. Чи заповнює вона всю виставу?

Дайте відповідь, чи дорівнює частка цілій виставі, тобто рівно одиниці.

```sather
FORMATION_COUNT::covers_whole_show(#RAT(3, 3))
-- => true
FORMATION_COUNT::covers_whole_show(#RAT(2, 3))
-- => false
```
