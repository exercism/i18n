# Про

Значення `null` використовується для позначення _відсутності_ значення. **Тип, що допускає `null`** - це такий тип, який дозволяє змінній набувати значення `null`. Щоб зробити будь-який тип таким, що допускає `null`, ми обгортаємо його в `Null<T>`:

```haxe
var a:Int = null; // Error
var b:Null<Int> = null; // Allowed
```

Щоб перевірити, чи значення зараз `null`, просто використаймо вираз `if`:

```haxe
var a:Null<Int> = 10;

if (a != null) {
  trace("a is not null"); // a is not null
}
```
