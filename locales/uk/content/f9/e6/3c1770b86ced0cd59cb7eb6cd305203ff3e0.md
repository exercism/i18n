# Інструкції

Нарешті настав день, на який ми так довго чекали, і тепер ми - щасливі власники прекрасної ферми в Альпах.

Ми й досі не любимо прокидатися надто рано вранці, щоб погодувати своїх корів.
Оскільки ми - чудові інженери, ми створюємо дозатор корму `FEED-M-ALL`.

Останнє, що потрібно, аби завершити наш проєкт, - це фрагмент коду, який обчислює кількість корму, яку має отримати кожна корова.
Важливо, щоб кожна корова отримала однакову кількість. Потрібно уникати конфліктів.
Корови дуже вразливі.

На щастя, нам не потрібно самостійно виводити всі формули для обчислення кількості корму.
Ми використовуємо якусь загадкову зовнішню бібліотеку, яку знайшли в інтернеті.
За задумом, вона має зробити корів найщасливішими.
Бібліотека надає тип, що реалізує такий інтерфейс.
На це ми будемо покладатися у коді, який пишемо самі.

```go
type FodderCalculator interface {
	FodderAmount(int) (float64, error)
	FatteningFactor() (float64, error)
}
```

Працюючи над своїм кодом, ми будемо вдосконалювати обробку помилок, щоб зробити її надійнішою та легшою для налагодження згодом, коли будемо користуватися нею в щоденному житті на фермі.

## 1. Розділіть корм порівну

Перш за все, ми зосереджуємося на написанні коду, потрібного для обчислення кількості корму на одну корову.

Реалізуйте функцію `DivideFood`, яка приймає як аргументи `FodderCalculator` і кількість корів (ціле число).
*Для цього завдання ми припускаємо, що передана кількість корів завжди більша за нуль.*
Функція має повернути кількість корму на одну корову як `float64` або помилку, якщо вона сталася.

Щоб виконати обчислення, спершу потрібно отримати загальну кількість корму для всіх корів.
Це робиться викликом методу `FodderAmount`, якому передають кількість корів.
Крім того, потрібен множник, на який цю кількість треба помножити.
Цей множник ми отримуємо, викликавши метод `FatteningFactor`.
Маючи ці два значення та кількість корів, ми тепер можемо обчислити кількість корму на одну корову (як `float64`).
Саме це й має повертати функція `DivideFood`.

Якщо один із викликаних методів повертає помилку, виконання має зупинитися, і цю помилку слід повернути (як є) з функції `DivideFood`.

```go
// For this example, we assume FodderAmount returns 50
// and FatteningFactor returns 1.5.
DivideFood(fodderCalculator, 5)
// => 15 <nil>

// Now assuming FodderAmount returns an error with message "something went wrong".
DivideFood(fodderCalculator, 5)
// => 0 "something went wrong"
```

## 2. Перевірте кількість корів

Працюючи над першим завданням вище, ми зрозуміли, що зовнішня бібліотека, яку ми використовуємо, не така якісна, як здавалося.
Наприклад, вона не вміє належно обробляти некоректні вхідні дані.
Ми хочемо обійти це обмеження, додавши перевірку вхідного значення у власному коді.

Напишіть функцію `ValidateInputAndDivideFood` з тією ж сигнатурою, що й `DivideFood` вище.

- Якщо передана кількість корів більша за 0, функція має викликати `DivideFood` і повернути результати цього виклику.
- Якщо кількість корів дорівнює 0 або менша, функція має повернути помилку з повідомленням `"invalid number of cows"`.

```go
ValidateInputAndDivideFood(fodderCalculator, 5)
// => 15 <nil>

ValidateInputAndDivideFood(fodderCalculator, -2)
// => 0 "invalid number of cows"
```

## 3. Покращте обробку помилок

Перевірка кількості корів перед передаванням була вдалим кроком, але нас не зовсім влаштовує неконкретне повідомлення про помилку.
Ми вирішуємо зробити краще й створити власний тип помилки під назвою `InvalidCowsError`.

Власна помилка має містити кількість корів (`int`) і власне повідомлення (`string`), а метод `Error` має серіалізувати дані в такому форматі:

```txt
{number of cows} cows are invalid: {custom message}
```

Озброївшись власною помилкою, реалізуйте функцію `ValidateNumberOfCows`, яка приймає кількість корів як ціле число й повертає помилку (або nil).

- Якщо кількість корів менша за 0, функція повертає `InvalidCowsError` з власним повідомленням `"there are no negative cows"`.
- Якщо кількість корів дорівнює 0, функція повертає `InvalidCowsError` з власним повідомленням `"no cows don't need food"`.
- В іншому разі функція повертає `nil`, що означає, що перевірка була успішною.

```go
err := ValidateNumberOfCows(-5)
err.Error()
// => "-5 cows are invalid: there are no negative cows"
```

Після нелегкої роботи з налаштування цієї функції перевірки ми помічаємо, що вже вечір, і залишаємо робоче місце, щоб помилуватися заходом сонця над горами.
Ми відкладаємо додавання нової функції перевірки до нашого коду на інший день.
