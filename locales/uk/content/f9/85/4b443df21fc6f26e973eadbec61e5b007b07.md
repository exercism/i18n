# Вступ

## Оператори порівняння

У R є набір операторів, такий самий, як у багатьох інших мовах:

```R
1 == 2 # FALSE
1 != 2 # TRUE
1 < 2 # TRUE
1 > 2 # FALSE
1 <= 2 # TRUE
1 >= 2 # FALSE
```

## Розгалуження

Основна форма конструкції if-else така:

```R
if (x > 10) {
    y <- "big"
} else if (x > 2) {
    y <- "medium"
} else {
    y <- "tiny"
}
```

У цьому випадку обовʼязковими є і круглі дужки `()` навколо булевого значення (англ. Boolean), і фігурні дужки `{}` навколо інструкції.
Просту умовну конструкцію `if` можна скоротити:

```R
if (x == 0) return("success")
```
