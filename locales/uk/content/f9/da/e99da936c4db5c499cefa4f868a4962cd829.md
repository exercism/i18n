# Вступ

Ця вправа спирається на стек даних і нотацію стекових ефектів, з якими ми познайомилися у [Cargo Shuffle][cargo-shuffle]. Тут ми будемо писати слова, які поєднують булеві значення (англ. Boolean).

## Слова перемішування

Найпоширеніші слова перемішування містяться у [`kernel`][kernel]:

```
dup    ( x -- x x )
dupd   ( x y -- x x y )
drop   ( x -- )
swap   ( x y -- y x )
swapd  ( x y z -- y x z )
over   ( x y -- x y x )
pick   ( x y z -- x y z x )
rot    ( x y z -- y z x )
-rot   ( x y z -- z x y )
rotd   ( w x y z -- w y z x )
spin   ( x y z -- z y x )
nip    ( x y -- y )
tuck   ( x y -- y x y )

2dup   ( x y -- x y x y )
3dup   ( x y z -- x y z x y z )
4dup   ( w x y z -- w x y z w x y z )
2drop  ( x y -- )
3drop  ( x y z -- )
4drop  ( w x y z -- )
2nip   ( x y z -- z )
2swap  ( x y z w -- z w x y )
```

## Булеві значення

Два булеві літерали - `t` і `f`. `f` - єдине хибне значення у Factor: усе інше, зокрема `0` і порожні колекції, вважається істинним.

```factor
t .    ! => t
f .    ! => f
```

## Булеві слова

Ось три булеві слова зі словника `kernel`:

```
and ( x y -- ? )    ! true when both inputs are truthy
or  ( x y -- ? )    ! true when either input is truthy
not ( x   -- ? )    ! inverts its argument
```

```factor
t t and .    ! => t
t f and .    ! => f
f t or .     ! => t
t not .      ! => f
```

Знак `?` у кожному записі стекового ефекту - це позначення булевого значення.

Для одного із завдань нижче нам знадобиться `swap`.
