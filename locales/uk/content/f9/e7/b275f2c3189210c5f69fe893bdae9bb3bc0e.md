# Вступ

Як і умовна конструкція _if/else_, конструкція `switch` дозволяє змінювати хід виконання програми, умовно виконуючи код.
Різниця в тому, що конструкція `switch` може порівнювати значення примітивного виразу або рядка тексту (англ. string) лише із заздалегідь визначеними сталими значеннями.

Коли ми використовуємо конструкцію `switch`, у пригоді стають деякі ключові слова.

- `switch`: це ключове слово дозволяє оголосити структуру конструкції `switch`.
  Після нього йде вираз або змінна, яка змінюватиме результат.
- `case`: цим ключовим словом ми оголошуємо різні можливі результати.
- `break`: ключове слово `break` дуже корисне, щоб зупинити виконання конструкції `switch` наприкінці потрібного потоку.
  Якщо його забути, програма продовжить роботу й може дати несподівані результати.
- `default`: як видно з назви, його використовують як типовий результат, коли з результатом виразу не збігається жоден інший варіант.

У найпростішому вигляді вони перевіряють примітивний вираз або рядок тексту й ухвалюють рішення на основі його значення.
Наприклад:

```java
String direction = getDirection();
switch (direction) {
    case "left":
        goLeft();
        break;
    case "right":
        goRight();
        break;
    default:
        // otherwise
        markTime();
        break;
}
```
