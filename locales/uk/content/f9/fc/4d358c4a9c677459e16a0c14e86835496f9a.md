# Інструкції

У цій вправі ми напишемо трохи коду, який допоможе приготувати чудову лазанью з улюбленої кулінарної книги.

На нас чекають пʼять завдань, і всі вони повʼязані з часом приготування лазаньї.

## 1. Визначте очікуваний час приготування в духовці у хвилинах

Реалізуйте функцію `expectedCookTime` у класі `Lasagna`, яка не приймає аргументів і повертає, скільки хвилин лазанья має провести в духовці.
Згідно з кулінарною книгою, очікуваний час приготування в духовці становить 40 хвилин:

```php
<?php
$timer = new Lasagna();
$timer->expectedCookTime()
// => 40
```

## 2. Обчисліть залишок часу приготування в духовці у хвилинах

Реалізуйте функцію `remainingCookTime` у класі `Lasagna`, яка приймає як аргумент фактичну кількість хвилин, які лазанья вже провела в духовці, і повертає, скільки хвилин їй ще залишилося там бути, виходячи з очікуваного часу приготування в духовці з попереднього завдання.

```php
<?php
$timer = new Lasagna();
$timer->remainingCookTime(30)
// => 10
```

## 3. Обчисліть час підготовки у хвилинах

Реалізуйте функцію `totalPreparationTime` у класі `Lasagna`, яка приймає як аргумент кількість шарів, які ми додали до лазаньї, і повертає, скільки хвилин ми витратили на її підготовку, якщо на кожен шар іде 2 хвилини.

```php
<?php
$timer = new Lasagna();
$timer->totalPreparationTime(3)
// => 6
```

## 4. Обчисліть загальний час роботи у хвилинах

Реалізуйте функцію `totalElapsedTime` у класі `Lasagna`, яка приймає два аргументи: перший це кількість шарів, які ми додали до лазаньї, а другий це кількість хвилин, які лазанья вже провела в духовці.
Функція має повернути загальну кількість хвилин, витрачених на приготування лазаньї, тобто суму часу підготовки у хвилинах і часу в хвилинах, який лазанья на цей момент провела в духовці.

```php
<?php
$timer = new Lasagna();
$timer->totalElapsedTime(3, 20)
// => 26
```

## 5. Створіть сповіщення про те, що лазанья готова

Реалізуйте функцію `alarm` у класі `Lasagna`, яка не приймає аргументів і повертає повідомлення про те, що лазанью вже можна їсти.

```php
<?php
$timer = new Lasagna();
$timer->alarm()
// => "Ding!"
```
