# Вступ

*Quotation* - це фрагмент коду в дужках `[ ]`. Це значення: ми можемо покласти його на стек, передати іншому слову або зберегти в масиві.

```factor
[ 1 + ] .          ! => [ 1 + ]
5 [ 1 + ] call .   ! => 6
```

Більшість слів вищого порядку приймають quotation як другий аргумент:

```factor
{ 1 2 3 } [ sq ] map .    ! => { 1 4 9 }
{ 1 2 3 } [ even? ] filter .  ! => { 2 }
```

Тіло quotation - це просто звичайний код Factor, ті самі оператори та стекові ефекти, які ми використовуємо всюди.

Коли ми будуємо код з даних, поєднуючи фрагменти та зіставляючи токени з операціями, результат - це послідовність; пропустімо його через `>quotation`, щоб зробити його викликаним:

```factor
{ [ 1 ] [ 2 + ] [ 3 * ] } concat >quotation call .   ! => 9
```
