# Докладніше

Булевий вираз (англ. Boolean) - це питання, поставлене до одного чи кількох значень, на яке можна відповісти `true` або `false`.
Істинний вираз повертає `1`; хибний вираз повертає `0`.
Також числа мають значення `true` і `false`: нуль - це `false`, а ненульове число - це `true`.

У старому коді на C або безпосередньо використовували тип `int` для булевих значень, або програміст визначав константи на кшталт `TRUE` і `FALSE`, щоб зіставити `1` і `0` з булевим поданням.

У версії C99 додали тип `_Bool`.
Заголовний файл `stdbool.h` визначає три нові булеві позначення: `bool`, `true` і `false`.
`true` відповідає `1`, `false` відповідає `0`, а `bool` відповідає `_Bool`.
Тож тепер замість того, щоб безпосередньо використовувати `int` чи вигадувати власні булеві зіставлення, програмісти можуть підключити `stdbool.h` й автоматично отримати булеві позначення у своєму коді.

## Оператори порівняння

C підтримує шість операторів порівняння: `==` (дорівнює), `!=` (не дорівнює), `>` (більше), `<` (менше), `>=`(більше або дорівнює), `<=` (менше або дорівнює).
Ці оператори порівнюють співвідношення між значеннями й перетворюють їх на булеві значення.

```c
0 == 0 // true. Although 0 is false, 0 equals 0 is true.
0 != 0 // false
1 > 0 // true
1 < 0 // false
1 >= 0 // true
1 <= 0 // false
```

## Булеві оператори

C підтримує три булеві оператори: `||` (логічне або), `&&` (логічне і) та `!` (логічне заперечення).

`!` використовують з одним операндом.
Він обертає булеве значення операнда.
Наприклад, `0` - це `false`, але `!0` - це `true`.

`||` (або) і `&&` (і) використовують з двома операндами.
Правий операнд обчислюється лише тоді, коли лівий операнд ще не визначає результат виразу.
Тобто `||` (або) обчислює свій правий операнд лише тоді, коли його лівий операнд дає `false`.
`&&` (і) обчислює свій правий операнд лише тоді, коли його лівий операнд дає `true`.


## Скорочене обчислення

Обчислення не всіх операндів називають «скороченим обчисленням».
Скорочене обчислення - це стислий і потужний спосіб впоратися з певними ситуаціями.
Наприклад, поширений прийом - перевірити, чи покажчик не дорівнює `NULL`, і (&&), якщо він не `NULL`, розіменувати його, уникнувши таким чином розіменування `NULL`-покажчика.
Але скорочене обчислення може також призводити до помилок.
Іноді програміст забуває, що правий операнд `||` (або) чи `&&` (і) може обчислюватися не завжди.
Якщо правий операнд - це вираз із побічним ефектом, який має відбуватися завжди, то це буде помилка, що залежить від булевого значення лівого операнда.


## Повернення булевого виразу

Результат булевого виразу можна повернути безпосередньо.
Наприклад, таку умовну конструкцію `if`

```c
if (count > 0)
    return true;
else
    return false;
end
```

можна замінити на

```c
return count > 0;
```
