# Підказки

## Загальні

- Прочитайте документацію про [оператори порівняння][comparison-operators]
- Прочитайте документацію про [сортування масивів][list-sort]
- Пригадайте, як можна [отримувати доступ до записів або зіставляти їх зі зразком][records]

## 1. Порівняйте рівні сили

- Використайте [оператор `(>)`][greater]

## 2. Знайдіть найвищу силу

- Використайте [функцію `max`][max]

## 3. Посортуйте картки

- Використайте [функцію `List.sortBy`][sort-by]

## 4. Спочатку найкрутіші картки

- Використайте функції [`List.sortBy`][sort-by] або [`List.sortWith`][sort-with]
- Можна використати кортежі для ієрархічного сортування

## 5. Блискуча сила

- Можна явно визначити порядок або використати [функцію `compare`][compare] з конкретним значенням
- Можна використати кортежі для ієрархічного сортування

## 6. Робіть ставки

- Використайте `compareShinyPower` в `expectedWinner`
- Використайте `case`, щоб [зіставити порядок зі зразком][pattern-match]
