# Встановлення

## Який у нас awk?

Трек AWK на Exercism використовує `gawk`, AWK від GNU.
Можливо, він уже встановлений; щоб перевірити, виконайте цю команду
```sh
awk --version
```

Якщо вона повертає:

* щось на кшталт `GNU Awk 5.1.0 ...`
    - GNU awk уже встановлено, тож можна переходити до вправ.

* щось на кшталт `awk version 20200816`
    - Це `nawk`, також відомий як BWK awk (на честь Браяна Кернігана) або «one true awk».
    - Саме він постачається з MacOS і системами BSD.
    - Нижче наведено інструкції зі встановлення.

* помилка `awk: not an option: --version`
    - Імовірно, це `mawk`.
    - Щоб переконатися, виконайте `awk -W version`; вона може повернути `mawk 1.3.4 20200120`.
    - mawk - дуже хороша й швидка реалізація awk, але в ній немає деяких можливостей, специфічних для gawk, які ми будемо використовувати в треку.
    - Нижче наведено інструкції зі встановлення.

* помилка `awk: unrecognized option: version`, за якою йде `BusyBox v1.35.0 ...`
    - Можливо, це Alpine Linux.
    - Нижче наведено інструкції зі встановлення.

* помилка «command not found»
    - Тоді або з PATH щось негаразд, або awk просто не встановлено.
    - Нижче наведено інструкції зі встановлення.

### Linux

Залежить від пакетного менеджера дистрибутива. Зазвичай це виглядає так:
```sh
apt install gawk
yum install gawk
apk add gawk
# and so on
```
Щоб виконати відповідну команду, може знадобитися `sudo`.

### MacOS

[Homebrew][brew] стане в пригоді. Перейдіть за посиланням, щоб установити його, а потім виконайте:
```sh
brew install gawk
```

### Windows

Для [WSL][wsl] скористайтеся інструкціями для Linux вище.
Для cygwin установіть пакет `gawk`.

### Збирання з вихідного коду

Для сміливців: інструкції [доступні в посібнику з `gawk`][build].
