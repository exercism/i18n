# Вступ

У Java є два різні типи чисел:

- Цілі числа: числа без цифр після десяткового розділювача (цілі числа).
  Наприклад: `-6`, `0`, `1`, `25`, `976` і `-500000`.
- Числа з плаваючою комою: числа, які мають нуль або більше цифр після десяткового розділювача.
  Наприклад: `-20.4`, `0.1`, `2.72`, `16.984025` і `1024.0`.

Два найпоширеніші числові типи в Java - це `int` і `double`.
`int` - це 32-бітне ціле число, а `double` - це 64-бітне число з плаваючою комою.

Арифметичні дії виконуються за допомогою стандартних арифметичних операторів.
Числа можна порівнювати за допомогою стандартних операторів порівняння (наприклад, `5 > 4` і `4 <= 5`), а також операторів рівності (`==`) і нерівності (`!=`).

У Java є два типи перетворень чисел:

1. Неявні перетворення: дані не втрачаються і додатковий синтаксис не потрібен.
2. Явні перетворення: дані можуть втратитися, і потрібен додатковий синтаксис у вигляді _приведення типу_.

Оскільки `int` має меншу точність, ніж `double`, перетворення з `int` на `double` є безпечним, а отже, належить до неявних перетворень.
Однак перетворення з `double` на `int` може призвести до втрати даних, тому воно потребує явного перетворення.
