# Вступ

Пригадаймо, що програма `jq` - це _конвеєр виразів_.
**Присвоєння змінної** підкоряється такому правилу: _присвоєння змінної_ - це вираз такого вигляду:

```jq
... | expr as $varname | ...
```

## Вихідні дані фільтра збігаються з вхідними

Як і _вираз тотожності_ `.`, _присвоєння змінної_ видає на вихід ті самі дані, що отримує на вхід.
Встановлення значення змінної - це побічний ефект.

Приклад, який показує, що `.` після присвоєння збігається з початковими вхідними даними:

```sh
$ jq -c -n '42 | (. * 2) as $double | [., $double]'
[42,84]
```

## Область видимості змінної

Область видимості змінної «лексична»: змінна залишається в області видимості до кінця конвеєра.
Змінні, визначені у функціях (до функцій ми дійдемо пізніше), є «локальними» для цієї функції.

## Назви змінних

Назва змінної має починатися з `$`.
Решта назви змінної - це **ідентифікатор**: він починається з літери або символу підкреслення, за якими йдуть літери, цифри або символи підкреслення.

## Деструктуризаційне присвоєння

З документації:

> За допомогою одного виразу `as` можна оголосити кілька змінних, надавши шаблон, який _відповідає структурі вхідних даних_ (це називається «деструктуризацією»).

Приклади:

```jq
[1, 2, 3] as [$a, $b, $c]
| [$a, $b, $c]     # => [1, 2, 3]
```

```jq
{"foo": "bar", "len": [10, 20]} as {foo: $f, len: [$h, $w]}
| [$f, $h, $w]     # => ["bar", 10, 20]
```

Якщо назва змінної збігається з _ключем обʼєкта_, можна скористатися скороченням:

```jq
{"x": 4, "y": 7} as {$x, $y}
| [$x, $y]         # => [4, 7]
```

```jq
{"foo": "bar", "len": [10, 20]} as {$foo, $len}
| [$foo, $len]     # => ["bar", [10, 20]]
```

## Константи

Як видно з наведеного вище прикладу, змінні зручні для зберігання констант.
Краще дати константам назву, ніж залишати «магічні числа» в коді.

## Часто змінні не потрібні

Часто код читається краще без змінних.

Погляньмо на обчислення середнього масиву чисел

```jq
[2, 4, 8, 7]
| add as $sum
| length as $len
| $sum / $len
```

порівняно з

```jq
[2, 4, 8, 7] | add / length
```

Це підкреслює одну з найпотужніших особливостей `jq`: вхідні дані фільтра передаються _кожному_ підвиразу:

- вхідний масив `[2,4,8,7]` передається у `add` (який додає числа, застосовуючи оператор `+` до всіх елементів)
- _паралельно_ `[2,4,8,7]` також передається у `length`
- коли ці підвирази завершуються, їхні результати діляться між собою, і ми отримуємо середнє значення чисел у вхідному масиві.
