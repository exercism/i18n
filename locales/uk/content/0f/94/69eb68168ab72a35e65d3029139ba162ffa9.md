# Вступ

Функція - це блок організованого коду, який можна використовувати повторно і який виконує певну дію.
У JavaScript функції можна визначати кількома способами.
Тут ми розглянемо _оголошення функцій_ та _функціональні вирази_.
Інші можливості, як-от [стрілкові функції][concept-arrow-functions], розглянемо в інших концепціях.

## Оголошення функції

Стандартний спосіб визначення функції в JavaScript - це _оголошення функції_, яке також називають _визначенням функції_ або _інструкцією функції_.

Воно складається з ключового слова `function`, назви функції та списку параметрів, розділених комами, у круглих дужках.
Далі йде тіло функції (набір інструкцій, які визначають, що робить функція), узяте у фігурні дужки.

```javascript
function someName(param1, param2, param3) {
  // ...
}
```

У JavaScript функцію викликають, записавши назву функції, а потім дужки з аргументами.

```javascript
someName(arg1, arg2, arg3);
```

## Параметри

Працюючи з параметрами всередині тіла функції, варто памʼятати про можливі побічні ефекти.

- Значення [примітивних типів даних][mdn-primitives] є _незмінними_.
  На початкове значення аж ніяк не впливає те, що відбувається з аргументом у тілі функції.
- Для всіх інших значень (обʼєктів, масивів, функцій) повторне присвоєння не вплине на початкове значення.
  Однак якщо ми змінюємо такий аргумент (наприклад, додаємо ключ до обʼєкта), то змінюється і початкове значення, яке передали у функцію.

Типово всі параметри, визначені в оголошенні функції, у JavaScript необовʼязкові.
Якщо ми передаємо менше аргументів, ніж є параметрів, пропущені аргументи всередині функції матимуть значення `undefined`, див. [Null та Undefined][concept-null-undefined].
У багатьох випадках краще присвоїти доречніше типове значення, ніж `undefined`.
Це можна зробити, указавши типові параметри безпосередньо у визначенні функції.

```javascript
function someName(param1 = defaultValue1, param2 = defaultValue2) {
  // ...
}
```

## Інструкція `return`

Інструкція `return` завершує виконання функції та вказує значення, яке треба повернути тому, хто викликав функцію. У функції може бути кілька інструкцій `return`.

```javascript
function checkNumber(num) {
  if (num === 0) {
    return 'You passed 0, please provide another number.';
  }

  return 'Thanks for passing such a nice number.';
}
```

Повернене значення функції можна зберегти у змінній.

```javascript
function sum(x, y) {
  return x + y;
}

const total = sum(5, 10);
// => 15
```

Якщо функція виконує `return` без значення або взагалі не має інструкції `return`, її результат дорівнює `undefined`.
У JavaScript немає неявного `return`.

```javascript
function nakedReturn(a) {
  a * 2;
  return;
}

nakedReturn(1);
// => undefined

function noReturn(a) {
  a * 2;
}

noReturn(1);
// => undefined
```

У JavaScript можна повернути лише одне значення.
Якщо потрібно передати більше інформації, її спершу треба поєднати в одну сутність, зазвичай в [обʼєкт][concept-objects] або в [масив][concept-arrays].

```javascript
function divide(a, b) {
  return {
    quotient: Math.floor(a / b),
    remainder: a % b,
  };
}
```

## Функціональний вираз

Оголошення функції є самостійною інструкцією.
Але іноді зручно визначити функцію як частину іншого виразу: наприклад, у присвоєнні, як параметр функції ([колбек][concept-callbacks]) або як значення в [обʼєкті][concept-objects].
Це можна зробити за допомогою функціонального виразу.
Він має той самий синтаксис, що й оголошення функції, тільки назву функції можна опустити, щоб створити _анонімну функцію_.

```javascript
const someFunction = function (param) {
  // ...
};

someOtherFunction(function (param) {
  // ...
});

const obj = {
  someFunction: function (param) {
    // ...
  },
};
```
