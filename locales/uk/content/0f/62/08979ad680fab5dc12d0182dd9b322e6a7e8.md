# Додаток до інструкцій

## Формат вхідних даних

Параметр `board`, який представляє ігрове поле, має формат масиву рядків тексту (англ. string).

```javascript
['  B  ', ' B B ', 'B W B', ' W W ', '  W  '];
```

Кожен символ рядка тексту представляє комірку.
Припустимі значення для комірки:

- ` ` пробіл, що відповідає порожній комірці
- `B` комірка, що належить чорному гравцю
- `W` комірка, що належить білому гравцю

## Формати вихідних даних

Функція `getTerritory` має повертати обʼєкт із двома властивостями:

- `owner` Власник території (`NONE`, `BLACK` або `WHITE`)
- `territory` Масив координат, що представляє кожну комірку території.

```javascript
{
    owner: 'BLACK',
    territory: [
        [0, 0],
        [0, 1],
        [1, 0],
    ],
}
```

Функція `getTerritories` має повертати обʼєкт із трьома властивостями:

- `territoryBlack` Масив координат, що представляє території, які належать гравцю `BLACK`
- `territoryWhite` Масив координат, що представляє території, які належать гравцю `WHITE`
- `territoryNone` Масив координат, що представляє території, які не належать жодному з двох гравців

```javascript
{
    territoryBlack: [
        [0, 0],
        [0, 1],
    ],
    territoryWhite: [
        [3, 0],
        [3, 1],
    ],
    territoryNone: [],
}
```
