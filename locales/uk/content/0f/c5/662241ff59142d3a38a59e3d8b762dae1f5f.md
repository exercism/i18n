# Підказки

## Загальне

- [Властивості][docs.microsoft.com-properties]
- [Використання властивостей][docs.microsoft.com-using-properties]

## 1. Дозвольте вагам мати точність

- Потрібно додати [властивість лише для читання][stackoverflow.com-get-only-properties], у якій зберігатиметься точність.
- Властивість лише для читання (`get`) можна ініціалізувати з конструктора (і лише з конструктора).

## 2. Дозвольте встановлювати вагу на вагах

- Додайте властивість із приватним [резервним полем][docs.microsoft.com-properties-with-backing-fields].

## 3. Забезпечте, щоб відʼємна вхідна вага відхилялася

- Ключове слово `value` використовується для посилання на значення, яке той, хто викликає, хоче надати властивості.
- Додайте [перевірку][stackoverflow.com-validating-properties] до аксесора `set` властивості `Weight`, щоб кидати виняток, коли значення неприпустиме.

## 4. Дозвольте застосовувати регулювання тари до ваг

- Додайте [автоматично реалізовану властивість][docs.microsoft.com-auto-implemented-properties] для регулювання тари.

## 5. Забезпечте, щоб ваги мали типове регулювання тари

- Автоматично реалізовану властивість можна ініціалізувати так само, як поле.

## 6. Дозвольте отримувати вагу

- Додайте властивість лише для читання (`get`), у якій обчислюється правильна відображувана вага.

## 7. Покажіть рядок тексту (англ. string) відображуваної ваги належним чином

- [Відформатуйте рядок тексту][stackoverflow.com-format-string] належним чином.
