# Синтаксис методів

Методи в Cairo схожі на функції, але привʼязані до конкретного типу через трейти.

Їхній перший параметр завжди `self`: він позначає екземпляр, на якому викликають метод.

Хоча Cairo не дозволяє визначати методи безпосередньо на типі, того самого можна досягти, визначивши трейт і реалізувавши його для цього типу.

Ось приклад визначення методу для типу `Rectangle` за допомогою трейту:

```rust
#[derive(Copy, Drop)]
struct Rectangle {
    width: u64,
    height: u64,
}

#[generate_trait]
impl RectangleImpl of RectangleTrait {
    fn area(self: @Rectangle) -> u64 {
        (*self.width) * (*self.height)
    }
}

fn main() {
    let rect = Rectangle { width: 30, height: 50 };
    println!("Area is {}", rect.area());
}
```

У наведеному прикладі метод `area` обчислює площу прямокутника.

Використання атрибута `#[generate_trait]` спрощує процес: він автоматично створює потрібний трейт.

Завдяки цьому код стає чистішим, а методи все одно можна повʼязувати з конкретними типами.

## Асоційовані функції

Асоційовані функції схожі на методи, але не працюють з екземпляром типу й не приймають `self` як параметр.

Ці функції часто використовують як конструктори або допоміжні функції, повʼязані з типом.

```rust
#[generate_trait]
impl RectangleImpl of RectangleTrait {
    fn square(size: u64) -> Rectangle {
        Rectangle { width: size, height: size }
    }
}

fn main() {
    let square = RectangleTrait::square(10);
    println!("Square dimensions: {}x{}", square.width, square.height);
}
```

Асоційовані функції, як-от `Rectangle::square`, використовують синтаксис `::` і належать простору імен цього типу.

Вони дають змогу легко створювати екземпляри й працювати з ними, не маючи вже наявного обʼєкта.

Організовуючи споріднений функціонал у трейти та реалізації, Cairo дає змогу будувати чисті, модульні й розширювані структури коду.
