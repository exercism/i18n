# Докладніше

У Factor quotation записують у `[ ]`; це аналог анонімної функції або блоку коду. Це повноцінне значення: його можна покласти на стек, зберегти чи передати далі, і він виконується лише тоді, коли щось його *викликає*.

```factor
[ 1 + ]              ! a quotation, sitting on the stack
5 [ 1 + ] call .     ! => 6
```

quotation - це послідовність слів, і Factor застосовує їх усюди, де треба відкласти чи параметризувати певну поведінку:

- гілки `if` / `when` / `unless` / `cond`
- предикат `filter`, `count`, `any?`, `all?`
- перетворення для `map`, `each`, `reduce`
- тіло `times`, `while`, `loop`

Стек-ефект quotation зазвичай можна вивести. Коли ні (зазвичай, коли його зберігають і пізніше викликають через `call`), оголосимо ефект явно: `call( a b -- c )`.

## Поєднання quotation

```
compose ( quot1 quot2 -- compound )
curry   ( value quot  -- curried )
```

`compose` зʼєднує два quotation один за одним у новий quotation, що виконує спочатку перший, а потім другий. `curry` додає фіксоване значення спереду й повертає quotation, що покладе його на стек перед викликом початкового. Обидва дають звичайні quotation, які можна викликати через `call`, зберегти чи передати комбінаторам.

```factor
USING: kernel math ;

3 [ 2 * ] [ 1 + ] compose call .   ! 3 2 * 1 + => 7
5 [ 1 + ] curry call .             ! 5 1 +     => 6
```
