# Вступ

Типово змінні обмежені областю видимості, у якій їх визначено. Якщо їх визначено у файлі поза функцією чи класом, вони обмежені областю видимості файлу. Якщо їх визначено у функції чи класі, вони обмежені областю видимості функції чи класу.

```php
<?php

$file_scoped = "I am file scoped";

function example(): void
{
  $function_scoped = "I am function scoped!";
}
```

Змінні також можна спеціально оголосити з областю видимості `global` або `static`.
