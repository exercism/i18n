# Інструкції

Транслюйте послідовності РНК у білки.

РНК можна розбити на послідовності з трьох нуклеотидів, які називаються кодонами, а потім транслювати в поліпептид ось так:

РНК: `"AUGUUUUCU"` => транслюється в

Кодони: `"AUG", "UUU", "UCU"`
=> які утворюють поліпептид із такою послідовністю =>

Білок: `"Methionine", "Phenylalanine", "Serine"`

Існує 64 кодони, які, своєю чергою, відповідають 20 амінокислотам; однак у цій вправі важливі не всі послідовності кодонів і відповідні амінокислоти.
Якщо програма працює для одного кодона, вона має працювати для всіх.
Втім, список у наборі тестів можна вільно розширити, щоб охопити їх усі.

Також є три термінуючі кодони (також відомі як «STOP»-кодони); якщо рибосома натрапляє на будь-який із цих кодонів, трансляція завершується, і синтез білка припиняється.

Усі наступні кодони після цього ігноруються, ось так:

РНК: `"AUGUUUUCUUAAAUG"` =>

Кодони: `"AUG", "UUU", "UCU", "UAA", "AUG"` =>

Білок: `"Methionine", "Phenylalanine", "Serine"`

Зверніть увагу: стоп-кодон `"UAA"` завершує трансляцію, і останній метіонін не транслюється в послідовність білка.

Нижче наведено кодони та відповідні амінокислоти, потрібні для цієї вправи.

| Кодон              | Білок       |
| :----------------- | :------------ |
| AUG                | Methionine    |
| UUU, UUC           | Phenylalanine |
| UUA, UUG           | Leucine       |
| UCU, UCC, UCA, UCG | Serine        |
| UAU, UAC           | Tyrosine      |
| UGU, UGC           | Cysteine      |
| UGG                | Tryptophan    |
| UAA, UAG, UGA      | STOP          |
