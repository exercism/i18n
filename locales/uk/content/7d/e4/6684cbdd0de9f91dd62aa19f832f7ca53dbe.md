# Вступ

## Числа

З [керівництва][man-types]

> jq підтримує той самий набір типів даних, що й JSON: числа, рядки тексту (англ. string), булеві значення (англ. Boolean), масиви, обʼєкти (які в термінах JSON є хешами лише з рядковими ключами) та "null".

Зосередьмося на **числах**.

### Числа та числові оператори

Усі числа, цілі чи ні, належать до чисел з плаваючою комою подвійної точності IEEE754.
Це обмежує точність до 53 бітів.

З числами можна використовувати звичайні оператори:

- арифметичні: `+`, `-`, `*`, `/`, `%`
- порівняння: `==`, `!=`, `<`, `<=`, `>=`, `>`
- стандартні [математичні функції][man-math]

  Для функцій з одним вхідним значенням передайте значення у функцію через конвеєр

  ```sh
  $ jq -n '(1 | atan) * 4'
  3.141592653589793
  ```

  Для функцій із двома вхідними значеннями вхід ігнорується, а самі значення передаються
  як параметри (нагадаємо, параметри розділяються крапками з комою)

  ```sh
  $ jq -n 'pow(2; 10)'
  1024
  ```

  Розділювач аргументів функції - крапка з комою, а не кома.

### Інші вирази `jq`

Щоб розвʼязати цю вправу, потрібно знати про умовні вирази.

#### Умовні вирази

`jq` використовує [вираз `if-then-else`][if-then-else] для **умовних виразів**.
Як _вираз_, його розміщують у конвеєрі.

Синтаксис такий: `if CONDITION then TRUE_EXPR else FALSE_EXPR end`.

Гілка `else` необовʼязкова.

```jq
42 | if . < 33 then "small" else "larger" end
# => "larger"
```

Для додаткових умов використовують `elif`

```jq
42 | if . < 33 then "small"
     elif . < 67 then "medium"
     else "large"
     end
# => "medium"
```
