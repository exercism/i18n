# Додаток до інструкцій

## Формат саду

Сад подано як рядок тексту (англ. string), завершений нульовим символом, із символом нового рядка в кінці кожного рядка.

Приклад: `"   \n * \n   \n"`

## Регістри

| Регістр | Використання       | Тип     | Опис                                       |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | вхідні дані        | адреса | вхідний рядок тексту, завершений нульовим символом  |
| `$a1`    | вхідні/вихідні дані | адреса | вихідний рядок тексту, завершений нульовим символом |
| `$t0-9`  | тимчасовий    | будь-який     | для тимчасового зберігання         |
