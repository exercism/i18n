# Статті

До кожної вправи можна додати статті, які досліджують якийсь цікавий аспект цієї вправи.

## Теми

Можливі теми, які могла б дослідити стаття:

- Порівняння продуктивності різних підходів
- Будь-що цікаве, що спаде на думку!

## Загальні міркування

- Якщо стаття ґрунтується на коді, який ми написали, варто закомітити цей код (у каталозі статті)
  - Наприклад, стаття про продуктивність, для якої написано код для бенчмарків

## Для яких вправ писати статті?

Для будь-якої вправи, аби було що цікаве дослідити.

## Файли

Кожна стаття має додати такі два файли:

- `.articles/<article-slug>/content.md`: опис статті (див. [документацію](/docs/building/tracks/practice-exercises#file-articles-article-slug-content-md))
- `.articles/<article-slug>/snippet.md`: фрагмент, який демонструє статтю (див. [документацію](/docs/building/tracks/practice-exercises#file-articles-article-slug-snippet-txt))

Потім треба додати або оновити:

- `.articles/config.json`: метадані статей (див. [документацію](/docs/building/tracks/practice-exercises#file-article-config-json))
