# Інструкції

У цій вправі нам потрібно реалізувати кілька методів для роботи з масивом мов програмування.

## 1. Визначте метод, який повертає порожній масив мов

Визначте метод `LanguageList.list`, який не приймає аргументів і повертає порожній масив типу `Array(String)`.

```crystal
LanguageList.list()
# => []
```

## 2. Визначте метод, який додає мову до масиву

Визначте метод `LanguageList.add`, який приймає 2 аргументи (_масив мов_ і літерал рядка тексту (англ. string) з назвою _мови_).
Метод має повернути масив із новою мовою, доданою в кінець масиву.

```crystal
language_list = LanguageList.list()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
```

## 3. Визначте метод, який видаляє мову з масиву

Визначте метод `LanguageList.remove`, який приймає 1 аргумент (_масив мов_).
Метод має повернути масив без останнього елемента.
Вважайте, що в масиві завжди буде принаймні один елемент.

```crystal
language_list = LanguageList.list()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
language_list = LanguageList.remove(language_list)
# => ["Crystal"]
```

## 4. Визначте метод, який повертає n-й елемент масиву

Визначте функцію `LanguageList.at`, яка приймає 2 аргументи (_масив мов_ і індекс).
Метод має повернути мову за індексом n у масиві.
Вважайте, що за цим індексом завжди буде мова.

```crystal
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
LanguageList.at(language_list, 1)
# => "Ruby"
```

## 5. Визначте метод, який розбирає рядок тексту з мовами

Визначте метод `LanguageList.parse`, який приймає 1 аргумент (літерал рядка тексту з мовами, розділеними комою).
Метод має повернути масив мов.

```crystal
LanguageList.parse("Crystal, Ruby")
# => ["Crystal", "Ruby"]
```
