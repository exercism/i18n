# Вказівки

У цій вправі ми маємо перекласти кілька правил із класичної гри Pac-Man у функції Elixir.

Нам потрібно перекласти чотири правила, усі повʼязані зі станами гри.

> Не хвилюйтеся про те, як виводяться аргументи, просто зосередьтеся на поєднанні аргументів, щоб повернути потрібний результат.

## 1. Визначте, чи зʼїдає Pac-Man привида

Визначте функцію `Rules.eat_ghost?/2`, яка приймає два аргументи (_чи є в Pac-Man активна енергетична пігулка_ та _чи торкається Pac-Man привида_) і повертає булеве значення (англ. Boolean), якщо Pac-Man здатен зʼїсти привида. Функція повинна повертати правду, лише якщо в Pac-Man є активна енергетична пігулка і він торкається привида.

```elixir
Rules.eat_ghost?(false, true)
# => false
```

## 2. Визначте, чи набирає Pac-Man очки

Визначте функцію `Rules.score?/2`, яка приймає два аргументи (_чи торкається Pac-Man енергетичної пігулки_ та _чи торкається Pac-Man крапки_) і повертає булеве значення, якщо Pac-Man набрав очки. Функція повинна повертати правду, якщо Pac-Man торкається енергетичної пігулки або крапки.

```elixir
Rules.score?(true, true)
# => true
```

## 3. Визначте, чи програє Pac-Man

Визначте функцію `Rules.lose?/2`, яка приймає два аргументи (_чи є в Pac-Man активна енергетична пігулка_ та _чи торкається Pac-Man привида_) і повертає булеве значення, якщо Pac-Man програє. Функція повинна повертати правду, якщо Pac-Man торкається привида і в нього немає активної енергетичної пігулки.

```elixir
Rules.lose?(false, true)
# => true
```

## 4. Визначте, чи перемагає Pac-Man

Визначте функцію `Rules.win?/3`, яка приймає три аргументи (_чи зʼїв Pac-Man усі крапки_, _чи є в Pac-Man активна енергетична пігулка_ та _чи торкається Pac-Man привида_) і повертає булеве значення, якщо Pac-Man перемагає. Функція повинна повертати правду, якщо Pac-Man зʼїв усі крапки і не програв за аргументами, визначеними в частині 3.

```elixir
Rules.win?(false, true, false)
# => false
```
