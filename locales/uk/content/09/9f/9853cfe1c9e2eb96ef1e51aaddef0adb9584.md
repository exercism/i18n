# Підказки

## Загальне

- `include` ставимо всередині класу, зазвичай першим рядком.
- Змінюється лише те, що ми перейменовуємо або пропускаємо. Усе інше
  приходить без змін.

## 1. Джазовий номер

- Один рядок усередині класу: `include WARM_UP;`
- Більше нічого. Тіло класу - це той рядок, і не більше.

## 2. Чечітковий номер

- `include WARM_UP describe -> ;`
- `-> ;` без нічого після стрілки пропускає `describe`, і саме тому
  звільняється місце для власної версії.
- Без нього компілятор скаржиться, що `describe` визначено двічі. Ця
  помилка - це і є задумана поведінка: Sather не вибере один із варіантів
  мовчки.

## 3. Фінал

- Два записи в одному `include`, розділені комою:
  `include WARM_UP counts -> warm_up_counts, describe -> ;`
- Потім пишемо `counts`, що повертає `warm_up_counts * 2`, і `describe`.
- `describe` має викликати `counts`, а не обчислювати число знову.
- Памʼятаймо, що до числа не можна додати рядок тексту (англ. string),
  тому опис, який починається зі слів, цілком годиться:
  `"Finale: " + counts + " counts"`.
