# Вступ

Набір слів [`random`][random] у Factor надає одне загальне слово `random`, яке підлаштовується під свій аргумент, а також допоміжні слова для перемішування та вибирання елементів послідовностей.

```factor
USING: random ;

6 random .                       ! a value from 0..5
{ "rock" "paper" "scissors" } random .   ! a random element
{ 1 2 3 4 5 } randomize .        ! the same cards, reordered
{ 1 2 3 4 5 } 2 sample .         ! two distinct elements
```

`random` для цілого числа `n` повертає значення з проміжку `[0, n)`; для послідовності він повертає випадковий елемент. `randomize` перемішує послідовність на місці, а `sample` вибирає різні елементи.

Типово ці слова беруть значення з глобального генератора, початкове значення якого надходить із системного годинника. Щоб результати можна було відтворити, встановімо генератор із заданим початковим значенням за допомогою `<mersenne-twister>` (із [`random.mersenne-twister`][mt]) та `with-random`:

```factor
USING: random random.mersenne-twister ;

42 <mersenne-twister> [ 6 random ] with-random .   ! same value every run
```

[mt]: https://docs.factorcode.org/content/vocab-random.mersenne-twister.html
