# Підказки

## Загальне

- Кортеж `plot`, символи `registrations` і `next-id`, а також символ `not-found` уже оголошені у файлі вправи.
- Для стану на рівні модуля використовуйте `set-global`, `get-global` і `change-global`.

## 1. Відкрийте сад і виведіть список його реєстрацій

- Як початкове значення для `registrations` візьміть `V{ } clone` (завжди саме `clone`, щоб літерал не був спільним для різних викликів).
- `1 next-id set-global` встановлює лічильник.
- Для `list-registrations` достатньо одного `registrations get-global`.

## 2. Зареєструйте ділянку

- Спершу прочитайте `next-id`, а потім викличте `plot boa`, щоб побудувати ділянку з `id` і `name`.
- Збільште лічильник за допомогою `next-id [ 1 + ] change-global`.
- `push` (з [`sequences`][sequences]) дописує елемент у вектор на місці, і це ідеально підходить для `registrations get-global`.

## 3. Звільніть ділянку

- `:: release ( id -- )` робить `id` доступним усередині предиката фільтрації.
- `[ id>> id = ] reject` залишає кожну ділянку, чий слот `id` *не* збігається з локальним `id`. Використайте це як тіло `change-global`.

## 4. Отримайте зареєстровану ділянку

- `find` повертає `( index elt/f )`. `nip` відкидає індекс.
- `[ not-found ] unless*` підставляє цей символ, коли нічого не знайдено.

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
