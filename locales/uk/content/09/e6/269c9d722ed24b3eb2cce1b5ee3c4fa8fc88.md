# Вступ

## Пакети й модулі

### Імпортування

Модуль зазвичай завантажують за допомогою ключового слова `use`.
Це одночасно завантажує модуль і викликає його метод `import`, імпортуючи всі експортовані символи.

Символи в масиві `@EXPORT` пакета імпортуються типово.
Символи в масиві `@EXPORT_OK` пакета потрібно імпортувати явно.

### Експортування

Щоб символ можна було імпортувати, його спершу потрібно експортувати.
Модуль [Exporter][Exporter] входить до складу Perl і є одним із найзручніших варіантів для експорту.

Визначення модуля:
```perl
package Foo;

use Exporter ('import');
our @EXPORT_OK = ('bar');

sub bar { ... }
```

Використання модуля:
```perl
use Foo ('bar');

bar();
```

### Основні модулі

Крім [Exporter][Exporter], Perl має велику кількість [основних модулів][perl-core-modules], доступних для використання.
До прикладів, корисних для вправ, які тут можуть трапитися, належать [List::Util][List::Util], [Time::Piece][Time::Piece] і [Math::BigRat][Math::BigRat].

### CPAN

Крім основних модулів, [CPAN][metacpan] має тисячі додаткових модулів, створених спільнотою Perl, доступних для встановлення.
Трек Perl використовує [cpanfile][test-runner-cpanfile], щоб установити набір модулів, які можна використовувати з тестовим раннером Perl на Exercism.
