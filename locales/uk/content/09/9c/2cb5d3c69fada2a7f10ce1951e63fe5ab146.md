Але все трохи заплутано: координати Aazra, схоже, відформатовані й відсортовані інакше, ніж у Rui, тож їм доводиться раз у раз зазирати з одного масиву до іншого, щоб зрозуміти, які скарби відповідають яким розташуванням. Як Gleamlins-початківці, вони звернулися до нас по допомогу з написанням невеличкої програми (насправді набору функцій), щоб краще впорядкувати інформацію про пошук скарбів.

## 1. Перетворіть розташування

Реалізуйте функцію `place_location_to_treasure_location`, яка приймає розташування місця (наприклад, `#("C", 1)`) і перетворює його на розташування скарбу (наприклад, `#(1, "C")`).

```gleam
place_location_to_treasure_location(#("C", 1))
// -> #(1, "C")
```

## 2. Порівняйте розташування скарбу й місця

Реалізуйте функцію `treasure_location_matches_place_location`, яка приймає розташування місця (наприклад, `#("C", 1)`) і повертає `True`, якщо воно збігається з розташуванням скарбу (наприклад, `#(1, "C")`).

```gleam
treasure_location_matches_place_location(#("C", 1), #(1, "C"))
// -> True

treasure_location_matches_place_location(#("C", 1), #(2, "C"))
// -> False
```

## 3. Порахуйте скарби за розташуванням

Реалізуйте функцію `count_place_treasures`, яка приймає місце (наприклад, `#("Aqua Lagoon (Island of Mystery)", #("F", 1))`) і масив скарбів, а повертає кількість скарбів, які там можна знайти.

```gleam
let place = #("Aqua Lagoon (Island of Mystery)", #("F", 1))

count_place_treasures(place, treasures)
// -> 2
```

## 4. Особливі місця

Реалізуйте функцію `special_case_swap_possible`, яка приймає скарб (наприклад, `#("Amethyst Octopus", #(1, "F"))`), місце (наприклад, `#("Seaside Cottages", #("C", 1))`) і бажаний скарб (наприклад, `#("Crystal Crab", #(6, "A"))`), а повертає `True` для таких комбінацій:

- Brass Spyglass можна обміняти на будь-який інший скарб в Abandoned Lighthouse.
- Amethyst Octopus можна обміняти на Crystal Crab або Glass Starfish у Stormy Breakwater.
- Vintage Pirate Hat можна обміняти на Model Ship in Large Bottle або Antique Glass Fishnet Float у Harbor Managers Office.
