# Підказки

## Загальне

- У незмінному класі немає `new`. `create` починається зі змінної класу, яка вже існує:

  ```sather
     create(d : INT) : SAME is
        b : SAME;
        return b.degrees(...);
     end;
  ```

- `b.degrees(x)` не змінює `b`. Він дає новий азимут, і саме тому його повертають.

## 1. Взяти азимут

- `%` приводить число до діапазону, але `-10 % 360` дає `350` лише тому, що `%` у Sather ніколи не повертає відʼємного значення за додатної правої частини. Тож самого `d % 360` цілком достатньо.

## 2. Повернути

- Додаймо поворот до градусів і створімо новий азимут із суми: `#BEARING(degrees + by)`.
- `create` уже сам приводить відповідь до потрібного діапазону, тож поворот через північ не потребує жодних додаткових дій.

## 3. Порівняти

- Усе в один рядок: порівнюємо два `degrees`.
- Тип аргументу - `SAME`, а його атрибут читаємо звичним способом: `other.degrees`.

## 4. Назвати точку

- Річ у тім, що перед діленням треба зсунути на половину сегмента, щоб відлік для кожної точки йшов від її *центру*: `((degrees + 22) / 45) % 8` дає 0 для півночі, 1 для північного сходу і так далі.
- Далі `case` за цим числом із вісьмома назвами, а також `else`, який `case` потребує завжди, навіть коли вісім гілок покривають усі можливі значення.

## 5. Записати

- `+` зʼєднує частини, але додавати щось можна лише до рядка тексту (англ. string). Тут число стоїть першим, тож потрібен `degrees.str`, щоб почати зʼєднання. `"a" + 1` працює, а `1 + "a"` не компілюється.
- Викличмо `point` замість того, щоб знову обчислювати назву.
