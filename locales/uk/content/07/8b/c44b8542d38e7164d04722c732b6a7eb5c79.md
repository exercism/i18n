# Тестування вправ

Виконайте наведені нижче кроки, щоб розробити рішення вправи та перевірити його локально.

## Завантаження вправи

Відкрийте Command Prompt і виконайте наведену нижче команду, вказавши назву потрібної вправи, щоб завантажити її.

```sh
exercism download --track ballerina --exercise <exercise-name>
```

## Розробка рішення

1. Виконайте наведену нижче команду, щоб перейти до каталогу щойно завантаженої вправи.

     >**Порада:** Розташування каталогу в наведеній нижче команді залежить від операційної системи та налаштованого робочого простору Exercism. Дізнатися розташування робочого простору можна, виконавши команду `exercism configure`.

     ```sh
     cd ~/exercism/ballerina/hello-world/
     ```

2. Дотримуйтеся наданих вказівок і розробіть рішення вправи.

## Перевірка рішення

Деякі вправи з Ballerina мають один тест, а деякі - кілька тестів. Тести можна знайти у відповідному файлі тестів у каталозі `/tests` у кореневому каталозі вправи.

### Перевірка вправи з одним тестом

Виконайте наведену нижче команду, щоб запустити тест вправи.

За типовим налаштуванням увімкнено лише перший тест. Це зроблено навмисно, щоб можна було зосередитися на тому, щоб цей тест пройшов.

```sh
bal test
```

### Перевірка вправи з кількома тестами

Виконайте наведені нижче кроки, щоб перевірити вправу з кількома тестами.

1. Коли перший тест пройде, увімкніть наступний тест, прибравши властивість `enable: false` з анотації `@test:Config`.

     ```ballerina
     @test:Config {
       enable: false
     }
     function nextTestCase() {
     }
     ``` 

2.  Виконайте наведену нижче команду, щоб запустити увімкнений тест.

   ```sh
     bal test
   ```

3. Повторіть два попередні кроки, щоб увімкнути решту тестів.

Вправу успішно завершено, коли всі тести увімкнено й кожен із них проходить.
