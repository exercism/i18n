# Докладніше

Існують, по суті, два типи циклів:

1. Цикл, що повторюється, доки не виконається умова.
2. Цикл, що перебирає елементи колекції.

Обидва [можливі в R][web-loops], хоча перший може траплятися частіше.

## `while` і `repeat`

Для задач, де кількість проходів циклом заздалегідь невідома, у R є цикл [`while`][ref-control] з умовою та цикл [`repeat`][ref-control] без умови (еквівалентний `while (TRUE)`).

Базова форма досить проста:

```R
while (condition) {
  do_something()
}
```

У цьому випадку програма продовжуватиме проходи циклом, доки `condition` не перестане дорівнювати `TRUE`.

Є два способи достроково вийти з циклу:

- `break` перериває цикл, і виконання продовжується з наступного рядка після закривної фігурної дужки циклу `}`.
- `return(x)` зупиняє виконання поточної функції та повертає значення `x` тому, хто її викликав.

Маючи ці можливості, іноді зручно створити «нескінченний» цикл за допомогою `repeat { ... }`, а потім покладатися на те, що умову зупинки буде знайдено всередині тіла циклу, щоб викликати `break` чи `return`.

Ці три варіанти еквівалентні, і всі вони завершуються з `x == 0.4444...`

```R
x <- 12
while (x > 1) {
  x <- x / 3
}

x <- 12
while (TRUE) {
  x <- x/3
  if (x <= 1) break
}

x <- 12
# no boolean clause 
repeat { 
  x <- x/3
  if (x <= 1) break
}
```

## Перебирання вектора (або іншої колекції)

У R це часто не потрібно.
Як зазначалося в інших концепціях, багато функцій працюють із цілими векторами.

Однак явних циклів іноді не уникнути.
Особливо це стосується випадків, коли:

- Тіло циклу має побічні ефекти, як-от виведення на екран або робота з файлами.
- Цикл триває, доки не буде досягнуто певного критерію, після непередбачуваної кількості ітерацій.

Умова циклу має бути в круглих дужках.
Як і для тіл функцій, фігурні дужки для однорядкових тіл циклу необовʼязкові (але їх часто додають).

```R
words <- c("This", "is", "a", "loop")
for (w in words) { print(w) } # the braces are optional here
#> [1] "This"
#> [1] "is"
#> [1] "a"
#> [1] "loop"
```

Якщо поточна ітерація не задовольняє певну умову, можна одразу перейти до наступної ітерації за допомогою `next`:

```R
for (n in 1:5) {
  if (n %% 2 == 0) next
  print(n)
}
#> [1] 1
#> [1] 3
#> [1] 5
```

Якщо потрібен числовий індекс, скористаймося [`seq_along()`][ref-seq_along].

```R
v <- LETTERS[1:3]
v
#> [1] "A" "B" "C"

for (i in seq_along(v)) { print(sprintf("%s%i", v[i], i)) }
#> [1] "A1"
#> [1] "B2"
#> [1] "C3"
```

Використовувати `i in 1:length(v)` _не_ рекомендується, оскільки це може спричинити проблеми, коли `length(v)` дорівнює нулю.
Діапазон `1:0` еквівалентний `c(1, 0)`, тож тіло циклу виконається й, імовірно, зазнає помилки.
Функція `seq_along()` призначена правильно обробляти цей випадок.
