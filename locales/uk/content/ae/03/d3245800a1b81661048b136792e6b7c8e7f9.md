Булеві значення (англ. Boolean) у Haxe представлені типом `Bool`, значення якого можуть бути або `true`, або `false`.

Haxe підтримує три [булеві оператори][operators]: `!` (унарне заперечення), `&&` (логічне і) та `||` (логічне або).

Складені булеві вирази (`&&` та `||`) використовують _скорочене обчислення_: вирази обчислюються зліва направо, але лише настільки, наскільки це потрібно. Це важливо в таких випадках:

```haxe
object != null && object.field == x
```

Перша булева перевірка гарантує, що до `object.field` ми звернемося лише тоді, коли `object` не `null`, і це захищає від помилки під час виконання.

Три булеві оператори мають різний [пріоритет][precedence] і обчислюються в такому порядку: `!` -> `&&` -> `||`.

Якщо взяти вираз у дужки `()`, можна змінити ці правила пріоритету, бо дужки мають вищий пріоритет.

```haxe
!true && false   // => false
!(true && false) // => true
```

[operators]: https://haxe.org/manual/expression-operators-binops.html
[precedence]: https://haxe.org/manual/expression-operators-precedence.html
