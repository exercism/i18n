# Вступ

Ітератори в Haxe використовуються для перебирання значень за допомогою циклу `for`. Існує два типи ітераторів:

- `Iterator`, який перебирає значення.
- Дані `Iterable`, які дають змогу перебирати тип даних.

Обидва ці поняття представлені `Iterator<T>` та `Iterable<T>`:

```haxe
typedef Iterator<T> = {
  function hasNext():Bool;
  function next():T;
}

typedef Iterable<T> = {
  function iterator():Iterator<T>;
}
```

Будь-який клас, який уніфікується з одним із цих типів, можна перебирати за допомогою циклу `for`. Якщо клас визначає методи `hasNext` і `next`, він вважається ітератором; інакше, якщо він визначає метод `iterator`, він вважається ітерованим типом.
