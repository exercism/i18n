# Встановлення

## Передумови

Трек мови C++ вимагає, щоб у системі було встановлено таке програмне забезпечення:
* сучасний компілятор C++14
* кросплатформну систему збірки CMake

Для тестування ми використовуємо [Catch2](https://github.com/catchorg/Catch2), яка складається лише із заголовкових файлів і постачається разом із вправами.

Такий набір залежностей дуже поширений у проєктах C++, тож якщо виникнуть проблеми з налаштуванням, в інтернеті можна знайти багато корисних матеріалів.

Багато інтегрованих середовищ розробки (IDE), зокрема Visual Studio від Microsoft, Xcode від Apple і CLion від JetBrains, містять компілятор і CMake разом, тож достатньо встановити лише саме середовище розробки.

### Сучасний компілятор C++14

Цей трек мови потребує компілятора з підтримкою [C++14](http://en.wikipedia.org/wiki/C%2B%2B14), який вийшов у 2014 році. Усі основні компілятори, випущені за останні кілька років, мають бути сумісними, тож достатньо мати досить свіжу версію. Конкретніше: GCC версії 7 або новішої, Clang версії 6 або новішої чи Visual Studio 2017 або новішої.

### CMake

CMake - це кросплатформна система збірки з відкритим кодом, яка створює скрипти збірки для нативної системи збірки (`make`, Visual Studio, Xcode тощо). Трек C++ на Exercism використовує CMake, щоб дати готову збірку, яка:

* компілює тести
* компілює рішення
* компонує виконуваний файл тестів
* автоматично запускає тести під час кожної збірки
* завершує збірку невдачею, якщо якийсь тест не проходить

Завдяки CMake Exercism може надавати кросплатформний скрипт збірки, який створює файли проєктів для інтегрованих середовищ розробки, як-от Visual Studio та Xcode. Це дає змогу зосередитися на задачі й не перейматися налаштуванням збірки для кожної вправи.

Створити переносну збірку непросто, і для цього потрібен доступ до багатьох різних систем. Якщо виникнуть проблеми з наданим рецептом CMake, [повідомте про проблему](https://github.com/exercism/cpp/issues), щоб ми могли покращити підтримку CMake.

Для використання наданого рецепта збірки потрібен [CMake 3.5.1 або новіший](http://www.cmake.org/).

## Windows

Користувачі Windows можуть отримати [Visual Studio Community](https://www.visualstudio.com/vs/community/), безкоштовне завантаження, яке надає середовище розробки Visual Studio і найновішу версію компілятора Microsoft Visual C++.

1. Дотримуйтеся [наведених тут вказівок](https://docs.microsoft.com/en-us/cpp/build/cmake-projects-in-visual-studio), щоб налаштувати CMake.
1. Завантажте вправу за допомогою інструмента [Exercism CLI](https://exercism.io/cli-walkthrough).
1. Відкрийте Visual Studio 2017 або новішу версію (з інструментами Visual C++ для CMake, встановленими, як описано за посиланням вище).
1. Відкрийте теку з вправою у VS.
1. Виконайте «Build->Build the solution». Тести виконуватимуться під час збірки, а їхні результати виводитимуться у вікно збірки. Оскільки тести запускаються під час збірки, VS повідомить про помилку збірки, якщо якийсь тест не пройде, а повідомлення про невдалі тести будуть у вікні виведення збірки.

Інші інтегровані середовища розробки, як-от CLion від JetBrains, можна використовувати подібним чином.

### Встановлення Boost у Windows

Вправи `meetup` і `gigasecond` залежать від бібліотек [Boost][boost-website]. Описані нижче кроки показують, як це налаштувати.

1. Завантажте [готові бібліотеки для Windows][sourceforge-boost-binaries] для Boost.
   - Вправи потребують щонайменше Boost версії 1.58.
   - Версію MSVC можна знайти, натиснувши «Modify» у Visual Studio Installer.
1. Розпакуйте бібліотеки до локальної теки.
1. Встановіть змінну середовища `BOOST_ROOT` на теку, де встановлено бібліотеки Boost.
1. Якщо Visual Studio було відкрито під час цих дій, закрийте його, щоб значення `BOOST_ROOT` точно підхопилося.
1. Запустіть Visual Studio і відкрийте теку, що містить вправу `gigasecond` або `meetup`.
1. «Startup Item» має бути `gigasecond.exe` або `meetup.exe`, і у файлах `gigasecond_test.cpp` або `meetup_test.cpp` будуть помилки збірки, які підказують реалізувати відсутні елементи, як і в інших вправах.

## Linux

Усі нещодавні випуски дистрибутивів Linux мають сумісні компілятори C++14, тож його можна встановити за допомогою менеджера пакетів. Версії, які ми підтримуємо, - це типові встановлені версії в Ubuntu LTS 18.04.

Наприклад, в Ubuntu для встановлення gcc використовують таку команду.

```bash
$ sudo apt-get install gcc
$ gcc --version
```

Якщо дистрибутив старіший, компілятор може не підтримувати C++14. У такому разі доведеться звернутися по допомогу до спільноти дистрибутива, щоб зʼясувати, як встановити мінімально потрібну версію компілятора.

## MacOS

Користувачі MacOS можуть встановити GCC за допомогою [Homebrew](http://brew.sh/) командою `brew install gcc`.
