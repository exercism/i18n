# Інструкції

У цій вправі ми будемо керувати системою інвентарю.

Інвентар має бути впорядкований за назвою предмета і зберігати кількість наявних предметів.

Нам доведеться додавати предмети до інвентарю.
Щоразу, коли предмет трапляється в наданому векторі, його кількість в інвентарі має збільшуватися на `1`.
Також нам доведеться видаляти предмети з інвентарю, зменшуючи кількість на `1`, коли надходить відповідний запит.

Нарешті, нам потрібно буде реалізувати функцію, яка повертатиме всі пари ключ-значення з наданого інвентарю як `vector` із `pair`.

~~~~exercism/note
Тести в цій вправі не залежать від мутацій, але назви функцій указують на те, що вони не повинні мутувати вхідні дані.
Якщо ми хочемо скористатися функціями зі вступу й при цьому не мутувати вхідні дані, нам стане в пригоді функція `copy()`.
~~~~

## 1. Створіть інвентар на основі вектора

Реалізуйте функцію `create_inventory(<input vector>)`, яка створює «інвентар» з вхідного вектора предметів.
Вона має повертати `dict`, у якому кожна назва предмета поєднана з відповідною кількістю.

```julia-repl
julia> create_inventory(["coal", "wood", "wood", "diamond", "diamond", "diamond"])
Dict("coal" => 1, "wood" => 2, "diamond" => 3)
```

## 2. Додайте предмети з вектора до наявного словника

Реалізуйте функцію `add_items(<inventory dict>, <item vector>)`, яка додає вектор предметів до переданого інвентарю:

```julia-repl
julia> add_items(Dict("coal" => 1), ["wood", "iron", "coal", "wood"])
Dict("coal" => 2, "wood" => 2, "iron" => 1)
```

## 3. Зменште кількість предметів в інвентарі

Реалізуйте функцію `decrement_items(<inventory dict>, <items vector>)`, яка приймає `vector` предметів.
Функція має віднімати `1` від кількості предмета щоразу, коли цей предмет трапляється у `vector`:

```julia-repl
julia> decrement_items(Dict("coal" => 3, "diamond" => 1, "iron" => 5), ["diamond", "coal", "iron", "iron"])
Dict("coal" => 2, "diamond" => 0, "iron" => 3)
```

Кількість предметів в інвентарі не повинна опускатися нижче 0.
Якщо предмет трапляється у вхідному `vector` більше разів, ніж є в наявності, указана кількість цього предмета має залишатися на 0.
Додаткові спроби зменшити кількість слід ігнорувати, щойно вона сягне нуля.

```julia-repl
julia> decrement_items(Dict("coal" => 2, "wood" => 1, "diamond" => 2), ["coal", "coal", "wood", "wood", "diamond"])
Dict("coal" => 0, "wood" => 0, "diamond" => 1)
```

## 4. Повністю видаліть запис з інвентарю

Реалізуйте функцію `remove_item(<inventory dict>, <item>)`, яка повністю видаляє предмет і його кількість з інвентарю:

```julia-repl
julia> remove_item!(Dict("coal" => 2, "wood" => 1, "diamond" => 2), "coal")
Dict("wood" => 1, "diamond" => 2)
```

Якщо предмета немає в інвентарі, функція має повернути початковий інвентар без змін.

```julia-repl
julia> remove_item(Dict("coal" => 2, "wood" => 1, "diamond" => 2), "gold")
Dict("coal" => 2, "wood" => 1, "diamond" => 2)
```

## 5. Поверніть весь вміст інвентарю

Реалізуйте функцію `list_inventory(<inventory dict>)`, яка приймає інвентар і повертає вектор пар `(item, quantity)`.

Вектор має містити лише _наявні_ предмети (_з кількістю більшою за нуль_) і бути відсортованим в алфавітному порядку назв предметів:

```julia-repl
julia> list_inventory(Dict("coal" => 7, "wood" => 11, "diamond" => 2, "iron" => 7, "silver" => 0))
["coal" => 7, "diamond" => 2, "iron" => 7, "wood" => 11]
```
