# Вступ

Умовні конструкції в C++ схожі на умовні конструкції в інших мовах.
Будь-яка умовна операція має базовий тип `bool`, який може набувати значення `true` або `false`.
Умовні конструкції часто використовують як механізм керування потоком виконання, щоб перевіряти різні умови.

Можна використати інструкцію `if`: вона виконує свій код, якщо умова має значення `true`, ось так:

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

Коли випадків більше ніж один, багато інструкцій `if` можна обʼєднати в ланцюжок за допомогою інструкцій `else if` та `else`.

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

Починаючи з C++17, інструкції `if` можуть також містити коротку інструкцію ініціалізації, яку можна використати, щоб ініціалізувати одну або кілька змінних для цієї інструкції `if`.
Наприклад:

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> Зверніть увагу: змінні, створені в ініціалізації, недоступні після завершення інструкції `if`.
