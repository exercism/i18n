# Вступ до циклів

У Bash є дві форми циклів:

* Повторювати деякі команди _для кожного елемента зі списку елементів_,
* Повторювати деякі команди _поки деяка умова є правдою (або неправдою)_.

## Цикли `for`

Щоб перебрати елементи списку, ми використовуємо цикл `for`.

```bash
for varname in words; do COMMANDS; done
```

`words` розкривається за допомогою розбиття на слова та розгортання імен файлів (про які ми дізналися в [концепції лапок][quoting]).
Кожне слово по черзі присвоюється змінній `varname`, після чого виконуються COMMANDS.

Ось кілька прикладів, які показують, коли цикл `for` може бути корисним

* Виконати деякі команди над групою файлів.

    ```bash
    # source all the bash library files in the current directory
    for file in ./*.bash; do
        source "$file"
    done
    ```

* Виконати деяку команду для кожного з параметрів скрипту або функції.

    ```bash
    for arg in "$@"; do
        echo "argument: ${arg}"
    done
    ```

* Виконати деяку команду для кожного слова, відокремленого пробілами, у виводі команди.

    ```bash
    for i in $(seq 10); do
        echo "${i} squared is $((i * i))"
    done
    ```

    Пізніше ми побачимо застереження щодо цього стилю.

### Арифметичний цикл `for`

У Bash справді є арифметичний цикл.
Тим, хто писав код іншими мовами програмування, він буде дещо знайомим.

```bash
for ((INITIALIZATION; CONDITION; INCREMENT)); do COMMANDS; done
```

Подвійні дужки в Bash задають арифметичний контекст (докладніше про арифметику в Bash ми поговоримо в одній із наступних концепцій).
Наведений вище приклад із `seq` можна записати так

```bash
for ((i = 1; i <= 10; i++)); do
    echo "${i} squared is $((i * i))"
done
```

### Коли не варто використовувати `for`

[Не читайте рядки за допомогою `for`][bashfaq1].

Ось антипатерн, який трапляється часто: перебирання виводу `cat`.

```bash
for line in $(cat some.file); do 
    do_something_with "$line"
done
```

Це неправильно з двох причин.

1. Підстановка команди не взята в лапки, тому до неї застосовується розбиття на слова.
   Розбиття на слова типово виконується за _пробільними символами_, а не лише за символами нового рядка.
   Цей цикл `for` перебирає **слова** у файлі, а не рядки.
2. Підстановка команди не взята в лапки, тому до неї застосовується розгортання імен файлів.
   Кожне слово у файлі буде зіставлено зі шаблоном.

Як ми дізналися з [концепції лапок][quoting], розбиттям на слова можна керувати за допомогою змінної `IFS`, а розгортання імен файлів можна вимкнути.
Але таке рішення зазвичай виходить крихким.
`for` не годиться для перебирання рядків файлу.
Ідіоматичний спосіб читати файл - це цикл `while`.

## Цикли `while`

Щоб повторювати послідовність команд, _поки_ деяка умова є правдою, використаймо `while`.

```bash
while CONDITION_COMMANDS; do COMMANDS; done
```

Як і з `if` (як ми дізналися з [концепції умовних конструкцій][conditionals]), для CONDITION_COMMANDS немає спеціального синтаксису.
Код завершення списку команд визначить «правду» чи «неправду».

## Керування циклами

Команда `break` перериває цикл.
Керування продовжується з команди, що йде після завершувального `done` циклу.

Команда `continue` переходить до наступної ітерації циклу.

## Читання рядків файлу

Як уже згадувалося, цикл `while` - це ідіоматичний спосіб читати файл. 

```bash
while IFS= read -r line; do
    do_something_with "$line"
done < some.file
```

* Вміст файлу подається циклу як вхідні дані за допомогою перенаправлення `<`.
* Команда `read` повертає «правду», якщо може прочитати повний рядок зі своїх вхідних даних.
  Коли вхідні дані вичерпано, або якщо останній рядок не завершується символом нового рядка, `read` повертає «неправду».
  * _По-справжньому_ ідіоматичний спосіб читати рядки файлу, навіть якщо останній рядок не завершується символом нового рядка, такий:

    ```bash
    while IFS= read -r line || [[ -n "$line" ]]; do ...
    ```

* Опція `-r` вказує `read` не підставляти послідовності зі зворотним слешем: зворотний слеш - це просто звичайний символ.
* `IFS=` присвоює порожній рядок тексту змінній IFS лише на час виконання команди `read`.
  Це тимчасово вимикає розбиття на слова, завдяки чому будь-які пробільні символи на початку чи в кінці вхідного рядка зберігаються.

## `until`

Конструкція `until` повторює послідовність команд, поки деяка умова є **неправдою**.
Цикл повторюється, _доки_ умова не стане правдою.

```bash
until CONDITION_COMMANDS; do COMMANDS; done
```

`until` використовують рідко.
Частіше застосовують цикл «while not».

```bash
while ! CONDITION_COMANDS; do ...
```

## Нескінченні цикли

Іноді потрібно повторювати цикл нескінченно.
Ось два способи це зробити.

1. цикл `while` з умовою, яка завжди має успішний код завершення

    ```bash
    while true; do ...
    ```

2.  арифметичний цикл `for` з порожніми виразами

    ```bash
    for ((;;)); do ...
    ```

## Do-While

Явної конструкції do-while не існує, але того самого ефекту можна досягти так:

```bash
while true; do
    COMMANDS

    if END_CONDITION; then
        break
    fi
done
```
