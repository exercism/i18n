# Вступ

У Common Lisp рядки тексту (англ. string) - це вектори символів. Вони записуються як символи, узяті в подвійні лапки (наприклад, "Hello World!").

Предикат `stringp` поверне правду лише тоді, коли задане значення - це рядок тексту.

Рядки тексту можна розбивати на підрядки за допомогою функції `subseq`, яка приймає рядок, початковий індекс і, за бажанням, кінцевий індекс. Індексація починається з нуля.

```lisp
(subseq "Hello World" 1 5)   ; => "ello"
(subseq "skip to the end" 5) ; => "to the end"
```

Рядки тексту можна порівнювати на рівність за допомогою `string=`. Якщо регістр символів потрібно ігнорувати, тоді можна використати `string-equal`.

```lisp
(string= "macaroni" "macaroni")      ; => T
(string= "macaroni" "MACARONI")      ; => NIL
(string-equal "macaroni" "MACARONI") ; => T
```

Такі операції, як переведення рядків тексту у верхній регістр, у нижній регістр і написання з великої літери, можна виконати за допомогою `string-upcase`, `string-downcase` і `string-capitalize`.

```lisp
(string-upcase "not too loud")                ; => "NOT TOO LOUD"
(string-downcase "YELL IT FROM THE ROOFTOPS") ; => "yell it from the rooftops"
(string-capitalize "practical COMMON LiSP")   ; => "Practical Common Lisp"
```
