# Вступ

JavaScript - динамічна мова, яка підтримує різні стилі програмування: обʼєктно-орієнтований, імперативний і декларативний (наприклад, функціональний).

## (Пере)присвоєння

У JavaScript є кілька основних способів присвоїти значення іменам: за допомогою змінних або констант. На Exercism змінні завжди записують у стилі [camelCase][wiki-camel-case], а константи - у [SCREAMING_SNAKE_CASE][wiki-snake-case]. Немає офіційного посібника, якого слід дотримуватися, і різні компанії та організації мають різні настанови щодо стилю. _Можна писати змінні так, як заманеться_. Перевага написання їх так, як це зроблено у вправах, полягає в тому, що вебінтерфейс і більшість IDE підсвічуватимуть їх інакше.

Змінні в JavaScript можна визначати за допомогою ключового слова [`const`][mdn-const], [`let`][mdn-let] або [`var`][mdn-var].

Змінна, визначена через `let` або `var`, може протягом свого існування посилатися на різні значення. Наприклад, `myFirstVariable` можна визначати і перевизначати багато разів за допомогою оператора присвоєння `=`:

```javascript
let myFirstVariable = 1
myFirstVariable = 'Some string'
myFirstVariable = new SomeComplexClass()
```

На відміну від `let` і `var`, змінній, визначеній через `const`, можна присвоїти значення лише один раз. Саме так у JavaScript визначають константи.

```javascript
const MY_FIRST_CONSTANT = 10

// Can not be re-assigned.
MY_FIRST_CONSTANT = 20
// => TypeError: Assignment to constant variable.
```

> 💡 У пізнішій концептуальній вправі ми розглянемо і пояснимо різницю між _присвоєнням_ (звʼязуванням) константи та її _значенням_.

## Оголошення функцій

У JavaScript одиниці функціональності втілюються у _функціях_; функції, які належать одна одній, зазвичай групують в одному файлі. Ці функції можуть приймати параметри (аргументи) і _повертати_ значення за допомогою ключового слова `return`. Функції викликають за допомогою синтаксису `()`.

```javascript
function add(num1, num2) {
  return num1 + num2
}

add(1, 3)
// => 4
```

> 💡 У JavaScript існує _багато_ різних способів оголосити функцію. Ці інші способи мають інший вигляд, ніж використання ключового слова `function`. Трек намагається вводити їх поступово, але якщо ми вже знайомі з ними, то можемо сміливо використовувати будь-який із них. Здебільшого використання одного чи іншого не краще й не гірше.

## Надання доступу іншим файлам

Щоб зробити `function`, константу чи змінну доступними в _інших файлах_, їх потрібно [експортувати][mdn-export] за допомогою ключового слова `export`. Інший файл потім може [імпортувати][mdn-import] їх за допомогою ключового слова `import`. Це також називають системою модулів. Дуже добре це видно на прикладі того, як працюють усі тести. Кожна вправа має принаймні один файл, наприклад `lasagna.js`, який містить _реалізацію_. Крім того, є принаймні ще один файл, наприклад `lasagna.spec.js`, який містить _тести_. Цей файл _імпортує_ публічні (тобто експортовані) сутності, щоб протестувати реалізацію:

```javascript
// file.js
export const MY_VALUE = 10

export function add(num1, num2) {
  return num1 + num2
}

// file.spec.js
import { MY_VALUE, add } from './file'

add(MY_VALUE, 5)
// => 15
```
