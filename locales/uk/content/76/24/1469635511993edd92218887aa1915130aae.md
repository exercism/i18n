# Детальніше

[Спеціальна форма `with`][with] дає змогу зосередитися на «щасливому шляху» послідовності кроків, кожен із яких може зазнати невдачі, а з невдачами розібратися пізніше.

Уявімо, що ми хочемо перевірити імʼя користувача кількома перевірками. Імовірно, ми звернемося до `case`:

```elixir
case check_ascii(username) do
  {:ok, username} ->
    case check_starts_with_letter(username) do
      {:ok, username} ->
        {:ok, username}

      {:error, "usernames may only start with a letter"} = err ->
        err
    end

  {:error, "usernames may only contain ascii letters"} = err ->
    err
end
```

Поки що це може бути читабельним, але якщо ми додамо більше вкладених перевірок, стане значно заплутаніше. У такій ситуації скористаймося `with`:


```elixir
with {:ok, username} <- check_ascii(username),
     {:ok, username} <- check_starts_with_letter(username),
     {:ok, username} <- check_not_a_joke_name(username),
     {:ok, username} <- check_if_available(username) do
  {:ok, "#{username} is a fine username and you deserve it!"}
end
```

На кожному кроці, якщо гілка збігається, ланцюжок продовжується, доки не виконається блок `do`. Якщо якийсь крок не збігається, ланцюжок зупиняється й повертається гілка, що не збіглася.

У ланцюжку можна використовувати сторожові вирази, а також оператор `=` для звичайних збігів.

```elixir
with {:ok, id} <- get_id(username),
     {:ok, avatar} when is_bitstring(avatar) <- fetch_avatar(id),
     avatar_size = bit_size(avatar),
     {:ok, image_type} <- check_valid_image_type(avatar) do
  {:ok, image_type, avatar_size, avatar}
end
```

Нарешті, можна скористатися блоком `else`, щоб перехопити невдалі збіги й змінити повернене значення.

```elixir
with {:ok, id} <- get_id(username),
     {:ok, avatar} when is_bitstring(avatar) <- fetch_avatar(id),
     avatar_size = bit_size(avatar),
     {:ok, image_type} <- check_valid_image_type(avatar) do
  {:ok, image_type, avatar_size, avatar}
else
  :not_found ->
    {:error, "invalid username"}

  {:error, "not an image"} ->
    {:error, "avatar associated to #{username} is not an image"}

  err ->
    err
end
```

Блок `else` схожий на інструкцію `case` для будь-якого значення, що не збіглося в конструкції `with`. Буде використано перше значення, яке збігається.

[with]: https://hexdocs.pm/elixir/Kernel.SpecialForms.html#with/1
