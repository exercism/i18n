# Про це

`reduce` виконує у Factor роль загальної згортки: він перебирає послідовність, проносячи акумулятор через бінарну quotation, яка приймає поточний акумулятор і наступний елемент та видає новий акумулятор.

```
reduce ( seq init quot: ( prev elt -- next ) -- result )
```

```factor
USING: math sequences ;

{ 1 2 3 4 } 0 [ + ] reduce .         ! => 10
{ 1 2 3 4 } 1 [ * ] reduce .         ! => 24
```

Власне початкове значення дає `reduce` змогу виражати згортки, яких не виразити через `sum` чи `product`. Наприклад, найбільше значення в послідовності з типовим значенням на випадок, коли всі елементи менші:

```factor
USING: math.order ;

{ 3 1 -4 5 -2 } 0 [ max ] reduce .   ! => 5
{ -3 -1 -4 }    0 [ max ] reduce .   ! => 0
```

Початкове значення `0` бере участь у порівнянні, тож послідовність із самих відʼємних чисел усе одно видає `0`, а не своє найменше значення.

## `produce` - розгортка

Двоїсту до `reduce` операцію виконує `produce` (у [`sequences`][sequences]): там, де `reduce` *споживає* послідовність, `produce` *породжує* її. Предикатна quotation перевіряє поточний стан; доки вона повертає правдиве значення, тіло quotation породжує наступний елемент.

```
produce ( pred quot -- seq )
```

Разом `reduce` і `produce` утворюють пару «згортка/розгортка» у Factor.

## Накопичувальні згортки

Родина накопичувальних слів у [`math.statistics`][math.statistics] повертає послідовність тієї самої довжини, що й вхідні дані, де кожен елемент - це згортка за префіксом аж до цієї позиції включно:

| слово         | поточна операція |
|---------------|-------------------|
| `cum-sum`     | поточна сума      |
| `cum-product` | поточний добуток  |
| `cum-min`     | поточний мінімум  |
| `cum-max`     | поточний максимум |

```factor
USING: math.statistics ;

{ 3 1 4 1 5 9 2 6 } cum-sum .         ! => { 3 4 8 9 14 23 25 31 }
{ 3 1 4 1 5 9 2 6 } cum-min .         ! => { 3 1 1 1 1 1 1 1 }
{ 3 1 4 1 5 9 2 6 } cum-max .         ! => { 3 3 4 4 5 9 9 9 }
```

Накопичувальні згортки стають у пригоді, коли треба побачити, *як* величина змінювалася вздовж послідовності, а не лише її підсумкове значення. Корисно також зчіплювати їх: вихідні дані однієї накопичувальної згортки самі є послідовністю, готовою для наступної.
