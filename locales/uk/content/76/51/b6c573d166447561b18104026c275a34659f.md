# Загальне

- Не забуваймо експортувати всі функції, які вимагають тести

## 1. Визначмо тип `Password` як непрозорий тип, використовуючи підхід «Parse, don't validate»

- У посібнику з Elm є розділ про [власні типи][custom-types].
- Власний тип `Password` має лише один варіант.
- У Elm прийнято, що коли власний тип має єдиний варіант, то варіант і тип мають однакову назву (у цьому випадку обидва називалися б `Password`).
- У посібнику з Elm є розділ про [Maybe][maybe], якщо треба пригадати.

## 2. Експортуймо `SecureTreasureChest`, але не його варіант

- У посібнику з Elm є розділ про [власні типи][custom-types].
- Власний тип `SecureTreasureChest` має лише один варіант.
- У Elm прийнято, що коли власний тип має єдиний варіант, то варіант і тип мають однакову назву (у цьому випадку обидва називалися б `SecureTreasureChest`).
