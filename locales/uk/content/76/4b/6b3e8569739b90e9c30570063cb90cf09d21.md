# Про

Щоб розпочати подорож C++, почнімо зі змінних, викликів функцій і коментарів.

## Коментарі

Коментарі бувають двох видів: однорядкові та багаторядкові.
Усе, що стоїть після `//` у тому самому рядку, компілятор ігнорує.
Багаторядкові коментарі також називають коментарями у стилі C.
Вони оточені `/*` та `*/`.
Усе, що стоїть між ними, теж буде проігноровано.

## Змінні

C++ належить до типізованих мов.
Усі типи мають бути відомі під час компіляції, і зазвичай їх потрібно вказувати явно.
Тип змінної не може змінюватися.
Змінну цілого типу з назвою `years` можна оголосити так:

```cpp
int years;
```

Добра практика - ініціалізувати змінні під час оголошення.
C++ пропонує для цього різні механізми.
Версія з фігурними дужками більше відповідає сучасному C++, але версія зі знаком рівності теж дуже поширена.

```cpp
int tomatoes{80};
int potatoes = 40;
```

~~~~exercism/caution
C++ справді дозволяє використовувати неініціалізовані змінні.
Поки змінній навмисно не надано значення, вона невизначена й може містити будь-що.
Щоб уникнути помилок використання до надання значення та невизначеної поведінки, радимо **завжди ініціалізувати** змінні.
Невизначена поведінка може обвалити програму в найгірший можливий момент, хоча раніше вона працювала бездоганно.
Це неможливо переоцінити: невизначеної поведінки слід уникати за всяку ціну.
~~~~

## Арифметичні операції

Арифметичні оператори, як-от `*`, `+` чи `-`, можуть бути частиною виразу, наприклад `3 * 2` або `tomatoes + potatoes`.

## Оновлення змінних

Змінним можна повторно присвоювати значення, доки вони зберігають свій тип:

```cpp
tomatoes = tomatoes - 5; // tomatoes is now 75
potatoes = (32 * 2) + 11; // potatoes is now 75 as well
```

## Функції

Функції мають назву, тип поверненого значення та (можливо, порожній) список параметрів.
Ось приклад функції з назвою `always_fortyseven`, яка завжди повертала б 47:

```cpp
int always_fortyseven() {
    return 47;
}
```

Ось `vip_fee`, яка має один параметр:
```cpp
int vip_fee(int standard_fee) {
    /*
    vip_fee calculates the vip fee based on the standard_fee.
    */
    int vip_multi{3};
    return standard_fee * vip_multi;
}
```

Або `total_fee` - функція з трьома параметрами та викликом іншої функції.

```cpp
int total_fee(int vips, int adults, int kids) {
    /*
    total_fee calculates the total price for a group of VIP and adult guests with kids.
    Kids get a flat discount on the standard fee.
    VIP guest fees are calculated by calling vip_fee.
    */
    int standard_fee{30};
    int kids_discount{15};

    int kids_total_fee = kids  * (standard_fee - kids_discount);
    int vips_total_fee = vips * vip_fee(standard_fee);
    int adult_total_fee = adults * standard_fee;

    return vips_total_fee + adult_total_fee + kids_total_fee;
}
```

Функції в C++ не повертають значення останньої інструкції, як у деяких інших мовах.
Щоб код скомпілювався, потрібне ключове слово `return`.

### Пробільні символи

Пробільні символи використовуються для форматування вихідного коду й охоплюють пробіли, табуляції та символи нового рядка.
Оскільки компілятор ігнорує зайві пробільні символи, їх можна використовувати, щоб структурувати код.
Розумне використання пробільних символів може покращити читабельність коду.
Існують різні стандарти форматування, але всі вони є лише домовленостями, і компілятор їх не навʼязує.

```cpp
// Formatting makes it easier to find bugs

int eggs_yolks =  3;
int      yeast = 15;

int flour=500;int sugar=200;// compact, but difficult to read
```
