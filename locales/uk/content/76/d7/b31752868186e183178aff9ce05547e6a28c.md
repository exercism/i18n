# Вступ

## Термінологія

Ми вже використовували і писали функції C++ у кількох концепціях.
Час перейти до технічних деталей.
Наведений нижче фрагмент коду показує найпоширеніші терміни для довідки.
Оскільки C++ ігнорує пробільні символи, форматування змінили так, щоб кожен елемент був на окремому рядку.

```cpp
// Function declaration:
bool                                              // Return type
admin_detected(string user, string password)      // Type signature
;                                                 // Don't forget the ';' for the declaration

// Function definition:
bool                                              // Return type
admin_detected                                    // Function name
(string user, string password)                    // Parameter list
{ return user == "admin" && password == "1234"; } // Function body
```
~~~~exercism/advanced
Оголошення працює як зауваження для компілятора про те, що існує функція з такою назвою, типом повернення та списком параметрів.
Код не працюватиме, якщо визначення відсутнє.
Оголошення необовʼязкові, вони потрібні, якщо ми використовуємо функцію до її визначення.
Оголошення можуть розвʼязувати проблеми на кшталт циклічних посилань, і їх можна використовувати, щоб відокремити інтерфейс від реалізації.
~~~~

## Кваліфікатор `const`

Іноді ми хочемо переконатися, що значення не можна змінити після ініціалізації.
C++ використовує ключове слово `const` як кваліфікатор для констант.

```cpp
const int number_of_dragon_balls{7};
number_of_dragon_balls--; // compilation error
```

~~~~exercism/note
Константи часто записують у _UPPER_SNAKE_CASE_.
Якщо немає іншої конвенції, цей регістр рекомендується залишати для макросів.
~~~~

Якщо спробувати змінити константну змінну після того, як її задано, код не скомпілюється.
Це допомагає уникати ненавмисних змін, а також відкриває можливості для оптимізації з боку компілятора.
Людині також легше міркувати про код, якщо вона знає, що певні частини залишаться незмінними.

`const` також може бути кваліфікатором для параметрів функції.

```cpp
string guess_number(const int& secret, const int& guess) {
    if (secret < guess) return "lower.";
    if (secret > guess) return "higher.";
    return "exact!";
}
```

Коли ми передаємо у функцію посилання `const`, можемо бути впевнені, що його не змінять.
Ми часто бачитимемо посилання `const` для обʼєктів, які може бути дорого копіювати, як-от довші рядки тексту (англ. string).
Третім випадком використання кваліфікатора `const` є функції-члени, які не змінюють екземпляр класу.

```cpp
class Stubborn {
    public:
    Stubborn(string reply) {
        response = reply;
    }
    string answer(const string& question) const {
        if (question.length() == 0) { return ""; }
        return response;
    }
    private:
    string response{};
};
```

Функція-член `answer` класу `Stubborn` використовує посилання `const string&` як параметр.
Це дозволяє уникнути копіювання вихідного обʼєкта, переданого у функцію.

## Перевантаження функцій

Кілька функцій можуть мати однакову назву, якщо їхні списки параметрів різняться.
Це називається перевантаженням функцій, і його зазвичай застосовують, коли ці функції виконують дуже схожі завдання.

Заголовок функції без типу повернення називають __сигнатурою типу__ функції.
Зміна сигнатури типу призводить до появи нової функції.

Приклад із `play_sound` має шість різних перевантажень, щоб охопити різні сценарії:

```cpp
// different argument types:
void play_sound(char note);         // C, D, E, ..., B
void play_sound(string solfege);    // do, re, mi, ..., ti
void play_sound(int jianpu);        // 1, 2, 3, ..., 7

// different number of arguments:
void play_sound(string solfege, double duration);

// different qualifiers:
void play_sound(vector<string>& solfege);
void play_sound(const vector<string>& solfege);
```

~~~~exercism/advanced
Сигнатуру типу визначають назва функції, кількість параметрів, їхні типи та кваліфікатори (але не їхні назви).
Тип повернення явно не входить до сигнатури типу, і ми отримаємо помилки компіляції, якщо дві функції різняться лише типом повернення.
Компілятор скаржитиметься, бо незрозуміло, яку з двох слід використати.
~~~~

## Типові аргументи

Деякі функції можуть бути дуже довгими, і в багатьох їхніх викликах для більшості параметрів використовуються ті самі значення.
Повторення в таких викликах можна уникнути за допомогою типових аргументів.

```cpp
void record_new_horse_birth(string name, int weight, string color="brown-ish", string dam="Alruccaba", string sire="Poseidon");

record_new_horse_birth("Urban Sea", 130); // color will be brown, dam "Alruccabam", sire "Poseidon"
record_new_horse_birth("Highclere", 175, "off-white", "Fall Aspen");   // sire will be "Poseidon"
```

Оскільки оголошення функції зазвичай іде перед визначенням, типові аргументи краще задавати саме в ньому.
Якщо для одного параметра задано типове значення, то для всіх параметрів праворуч від нього теж потрібно задати типове значення.
Іноді складні перевантаження функцій можна переробити на меншу кількість функцій із типовими аргументами, щоб полегшити супровід коду.
