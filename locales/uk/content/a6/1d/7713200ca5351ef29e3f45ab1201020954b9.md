# Ітерація

У програмуванні під [ітерацією][iteration] розуміють процес повторення блоку коду кілька разів.
Цього можна досягти за допомогою таких конструкцій, як цикли `while` та `until`.
Це також можна зробити за допомогою рекурсії, тобто функції, яка викликає саму себе.

Однак найчастіше нам потрібно перебрати колекцію елементів, як-от `Array`, `Range` чи `String`.
І клас `Array`, і клас `Range` у Crystal включають модуль [`Enumerable`][enumerable], який надає низку методів для перебирання елементів.
Водночас клас `String` має власний набір методів для перебирання символів.

Крім того, у Crystal немає жодної інструкції `for`, як в інших мовах.
Натомість є кілька методів, які можна використати для перебирання.

## Перебирання

Найпоширеніший спосіб перебрати колекцію - скористатися методом [`each`][each], який передає кожен елемент колекції в блок.
Це легко зробити з `Range`.
Скажімо, треба пройтися циклом від 1 до 3: можна скористатися методом `each`, щоб перебрати діапазон.

```crystal
(1..3).each do |n|
  puts n
end

# Output:
# 1
# 2
# 3
```

Ще простіше: якщо треба просто повторити щось певну кількість разів, можна скористатися методом [`times`][times], який є в класі `Int`.

```crystal
3.times do |n|
  puts n
end

# Output:
# 0
# 1
# 2
```

## Перебирання `String`

`String` - це послідовність символів, і він не належить до модуля `Enumerable`, а отже, має власний набір методів для перебирання символів.
Найпоширеніший спосіб перебрати `String` - скористатися методом [`each_char`][each_char], який передає кожен символ `String` у блок.

~~~~exercism/note
Метод `each_char` передає в блок обʼєкт `Char`, а не обʼєкт `String`.
~~~~

```crystal
str = "hello"
str.each_char { |char| puts char }

# Output:
# h
# e
# l
# l
# o
```

Ще один спосіб перебрати `String` - скористатися методом [`each_line`][each_line].
Цей метод здебільшого використовують, коли читають файл рядок за рядком.

```crystal
str = "hello\nworld"
str.each_line do |line|
  puts line
end

# Output:
# hello
# world
```

## Перебирання обʼєкта, який включає модуль `Enumerable`

Модуль [`Enumerable`][enumerable] надає низку методів для перебирання елементів колекції.
Колекції, які включають модуль `Enumerable`, - це `Array`, `Range`, `Hash`, `Set` та інші; про решту йтиметься в наступних концепціях.

Найпоширеніший спосіб перебрати `Array` - скористатися методом [`each`][each], який передає кожен елемент `Array` у блок.

```crystal
arr = [5, 2, 3]
arr.each do |element|
  puts element
end

# Output:
# 5
# 2
# 3
```

### `map`

Метод [`map`][map] - ще один спосіб перебрати `Array`: він повертає новий `Array` з результатами застосування блоку до кожного елемента.
Він схожий на метод `each`, але повертає новий `Array` з перетвореними елементами.
Перетворення дуже корисне, коли потрібно застосувати функцію до кожного елемента колекції, а це часта операція.

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  element * 2
end

new_arr
# => [2, 4, 6]
```

За допомогою конструкції керування потоком, як-от `if`, можна також відфільтрувати, які елементи перетворювати.

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  if element.odd?
    element * 2
  else
    element
  end
end

new_arr
# => [2, 2, 6]
```

## Скорочений синтаксис

У Crystal є скорочений синтаксис для перебирання та застосування методу до кожного елемента колекції.
Це зручно, коли логіка проста і для перетворення потрібен лише один метод.
Для цього використовують синтаксис `&.`, після якого йде назва методу.

```crystal
arr = [1, 2, 3]
arr.map(&.to_s)
# => ["1", "2", "3"]
```

### З індексом

Іноді потрібно знати індекс елемента, який ми перебираємо; для цього можна скористатися методом [`each_with_index`][each_with_index] або [`map_with_index`][map_with_index].
Він передає в блок кожен елемент та його індекс; метод також приймає необовʼязковий аргумент, який задає початковий індекс.

```crystal
arr = [1, 2, 3]
arr.each_with_index(4) do |element, index|
  puts "Element: #{element}, Index: #{index}"
end

# Output:
# Element: 1, Index: 4
# Element: 2, Index: 5
# Element: 3, Index: 6
```

Зауважмо, що метод [`each_char_with_index`][each_char_with_index] також доступний для обʼєктів `String`.

### `sum`

Метод [`sum`][sum] повертає суму всіх елементів колекції; він також приймає необовʼязковий блок, щоб перетворити елементи перед додаванням.
Крім того, він приймає необовʼязковий аргумент, який задає початкове значення суми.

```crystal
arr = [1, 2, 3]
arr.sum
# => 6

arr.sum(2) { |n| n * 2 }
# => 14
```

### `reduce`

[`reduce`][reduce], або згортка (fold), як його називають в інших мовах, - це метод, який за допомогою способу обʼєднання та початкового значення обʼєднує всі елементи колекції.
Метод `reduce` має акумулятор, який передається в блок; акумулятор - це результат попередньої ітерації.
Так виходить рекурсивний процес, який обʼєднує всі елементи колекції.

```crystal
arr = [1, 2, 3]
arr.reduce(0) do |acc, n|
  acc + n
end
# => 6
```

`reduce` може здатися схожим на `sum`, але `reduce` гнучкіший, бо дозволяє задати початкове значення акумулятора та спосіб обʼєднання.
За допомогою `reduce` можна реалізувати `sum`, `count` та інші методи.
