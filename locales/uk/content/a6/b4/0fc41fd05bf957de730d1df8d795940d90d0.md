# Тестування з командного рядка

Roc постачається з власними вбудованими інструментами для тестування, тож нічого іншого встановлювати не потрібно.

Щоб перевірити своє рішення вправи, відкрийте термінал, перейдіть до каталогу вправи, виконайте `roc test <exercise-name>-test.roc`, наприклад `roc test hello-world-test.roc`, і переконайтеся, що всі тести проходять. *Не* редагуйте сам файл `*-test.roc`, лише інші файли `*.roc`.
