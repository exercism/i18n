# Підказки

## Загальні

- Прочитайте офіційну документацію про [typespecs][typespecs].
- Прочитайте офіційну документацію про [написання документації][writing-documentation].
- Прочитайте про використання атрибутів модуля як анотацій в [офіційному посібнику Getting Started][getting-started-module-attributes].
- Прочитайте про використання typespecs в [офіційному посібнику Getting Started][getting-started-typespecs].

## 1. Задокументуйте призначення інструментів форми

- Атрибут модуля `@moduledoc` можна використати, щоб написати документацію для модуля.

## 2. Задокументуйте заповнення полів порожніми значеннями

- Атрибут модуля `@doc` можна використати, щоб написати документацію для функції.
- Атрибут модуля `@spec` можна використати, щоб написати typespec для функції.
- Розмістіть атрибути `@doc` і `@spec` безпосередньо перед першою клаузою функції, яку описують ці атрибути.
- Зверніться до [документації typespecs][typespecs-types], щоб побачити список усіх доступних типів.
- Правильний тип для рядків тексту (англ. string) [визначено в модулі `String`][string-t].

## 3. Задокументуйте розбиття значень на масиви великих літер

- Атрибут модуля `@doc` можна використати, щоб написати документацію для функції.
- Атрибут модуля `@spec` можна використати, щоб написати typespec для функції.
- Розмістіть атрибути `@doc` і `@spec` безпосередньо перед першою клаузою функції, яку описують ці атрибути.
- Зверніться до [документації typespecs][typespecs-types], щоб побачити список усіх доступних типів.
- Правильний тип для рядків тексту [визначено в модулі `String`][string-t].
- Масив - це параметризований тип.

## 4. Задокументуйте перевірку, чи вміщується значення в поле з максимальною довжиною

- Атрибут модуля `@doc` можна використати, щоб написати документацію для функції.
- Атрибут модуля `@spec` можна використати, щоб написати typespec для функції.
- Розмістіть атрибути `@doc` і `@spec` безпосередньо перед першою клаузою функції, яку описують ці атрибути.
- Зверніться до [документації typespecs][typespecs-types], щоб побачити список усіх доступних типів.
- Правильний тип для рядків тексту [визначено в модулі `String`][string-t].
- У typespec можна використовувати літеральні значення.
- Вертикальну риску `|` можна використати, щоб позначити обʼєднання типів.

## 5. Задокументуйте різні формати адрес

- Атрибут модуля `@type` можна використати, щоб визначити власний публічний тип.
- Типи можуть бути складеними: наприклад, коли ми задаємо тип, який є словником, ми також можемо вказати типи значень за конкретними ключами.
- [Оператор типу `::`][type-operator] також можна використати, щоб додати імʼя змінної перед типом.
- Власні типи можна використовувати, щоб визначати інші власні типи.

## 6. Задокументуйте форматування адреси

- Атрибут модуля `@doc` можна використати, щоб написати документацію для функції.
- Атрибут модуля `@spec` можна використати, щоб написати typespec для функції.
- Розмістіть атрибути `@doc` і `@spec` безпосередньо перед першою клаузою функції, яку описують ці атрибути.
- Зверніться до [документації typespecs][typespecs-types], щоб побачити список усіх доступних типів.
- Правильний тип для рядків тексту [визначено в модулі `String`][string-t].
- Власні типи можна використовувати в typespec.
