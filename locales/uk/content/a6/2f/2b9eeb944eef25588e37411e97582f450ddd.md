# Про це

Gleam може працювати на віртуальній машині Erlang (BEAM) або в середовищах виконання JavaScript. Існує багато інших мов, які використовують ці середовища виконання, і часто буває корисно мати змогу викликати код, написаний цими мовами, із Gleam.

Можливість _зовнішніх функцій_ у Gleam дозволяє імпортувати функції з інших мов у Gleam і викликати їх без накладних витрат під час виконання.

Якщо наш проєкт на Gleam працює на віртуальній машині Erlang і ми хочемо викликати функцію `reverse` з модуля `lists` Erlang, це можна зробити, додавши атрибут `@external` до заголовка функції Gleam ось так:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

Тоді її можна викликати як звичайну функцію Gleam:

```gleam
let reversed = reverse_list([1, 2, 3])
// -> [3, 2, 1]
```

Якщо спробувати скомпілювати цей код для середовищ виконання JavaScript, це завершиться помилкою, бо для JavaScript немає реалізації. Для середовищ виконання JavaScript можна вказати іншу реалізацію ось так:

```gleam
@external(erlang, "lists", "reverse")
@external(javascript, "./my_module.mjs", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

Також можна написати реалізацію на Gleam, яка буде використовуватися, коли для поточної цілі компіляції немає зовнішньої реалізації:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a) {
  tail_recursive_reverse(x, [])
}

fn tail_recursive_reverse(list, reversed) {
  case list {
    [] -> reversed
    [x, ..xs] -> tail_recursive_reverse(xs, [x, ..reversed])
  }
}
```
