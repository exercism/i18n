# Докладніше

Go має статичну типізацію, тож кожна змінна має тип, відомий на етапі компіляції.
Щойно змінну оголошено, її тип змінити вже не можна.

## Створення змінної

Інструкція `var` може оголосити тип нової змінної, задати її значення або зробити і те, й інше одразу:

```go
var total int     // Type explicitly declared, value implicitly set (see note on zero values below)
var count int = 1 // Type explicitly declared, value explicitly set
var sum = 100     // Type implictly declared, value explicitly set
```

Усередині функції також можна використати коротку інструкцію присвоєння `:=`.

```go
count := 1 // Type implictly declared, value explicitly set
```

Змінна в Go завжди має значення.
Якщо його не задано під час оголошення, Go надає [нульове значення][zero-values] відповідно до типу змінної.

```go
var total int     // 0
var name string   // ""
var ready bool    // false
```

## Оновлення змінної

Усередині функції оператор присвоєння `=` може задати нове значення вже наявній змінній:

```go
count := 1
count = 2
```

Нове значення має бути того самого типу, що й змінна:

```go
count := 1
count = false // compile error: a Boolean is not an int
```

[zero-values]: https://exercism.org/tracks/go/concepts/zero-values
