# Вступ

## Правдиві та неправдиві значення

У Common Lisp усі значення є правдою, крім `()`, яке є неправдою.
Також є два особливі символи-константи `t` і `nil`, значеннями яких є відповідно правда та неправда.

## Умовні конструкції

Common Lisp надає кілька різних умовних виразів; головна відмінність між ними - кількість гілок, які вони підтримують.

- `when` і `unless` дають змогу мати лише одну гілку:

```lisp
(when (= 2 2) "All is well")      ; => "All is well"
(unless (= 2 2) "Time to panic!") ; => NIL
```

Після виразу умови може стояти більше ніж один вираз.

- `if` реалізує класичну конструкцію «якщо, то, інакше»:

```lisp
(if (= 2 2) 'how-honest 'you-liar) ; => HOW-HONEST
```

Зауважте, що і гілка «то», і гілка «інакше» можуть містити лише один вираз.

- `cond` дає змогу мати кілька гілок без вкладення виразів `if`:

```lisp
(cond ((= 0 2) 'nope)
      ((= 1 2) 'try-again)
      ((= 2 2) 'quite-true)
      ((= 3 2) 'too-far)
      (t 'something-else))
; => QUITE-TRUE
```

Зауважте, що кількість виразів після виразу умови не обмежена. 

- `case` реалізує класичну конструкцію у стилі «switch»: вона перевіряє одне значення на відповідність кільком гілкам:

```lisp
(case 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark")
  (otherwise "???"))
; => "???"
```

Зауважте, що, як і в `cond`, кількість виразів після виразу умови не обмежена.
