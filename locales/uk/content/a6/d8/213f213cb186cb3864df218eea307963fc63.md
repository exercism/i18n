# Вступ

У Haxe властивість - це член класу, який надає доступ до даних у цьому класі. Ті, хто викликає, можуть встановлювати або отримувати (get) ці дані. Вони складаються з сетера та/або гетера.

Властивості мають модифікатори доступу (public, private тощо) так само, як інші члени класу, але сетер може мати рівень доступу, незалежний від гетера, і навпаки. Властивість не обов'язково повинна мати обидва аксесори, вона може мати лише один (або get, або set).

Доступ на читання та доступ на запис безпосередньо відображаються в синтаксисі, як показує наступний приклад:

```haxe
class Main {
  public var x(default, null):Int;
}
```

І `default`, і `null` є спеціальними **ідентифікаторами доступу**. Ідентифікатори доступу визначають поведінку, коли поле читається (перший ідентифікатор), і коли поле записується (другий ідентифікатор). Прийнятні значення:

- `default`: дозволяє звичайний доступ до поля, якщо поле public.
- `null`: дозволяє доступ лише з класу, у якому його визначено.
- `get/set`: доступ генерується як виклик методу-аксесора (`get_x()`).
- `dynamic`: те саме, що `get/set`, але наявність методу-аксесора неможливо перевірити.
- `never`: не дозволяє жодного доступу.

Ось повний приклад:

```haxe
class Main {
  public var x(default, set):Int;

  public function set_x(x:Int):Int {
    return this.x = x + 2;
  }

  public function main() {
    trace(x); // null
    x = 2;
    trace(x); // 4
  }
}
```
