# Вступ

Символи в Common Lisp - це особливі значення, які можуть вказувати на інші значення або, у випадку _ключових слів_, на самих себе.
Коли Lisp обчислює символи, він замінює їх на значення, на які вони вказують:

```lisp
foo  ; => <whatever-foo-points-to>
:foo ; => :FOO
```

Зауважмо, що ключові слова позначаються двокрапкою на початку (`:`).

Цитування, тобто додавання `'` перед S-виразом, вказує Lisp не обчислювати цей вираз.
Цитуючи `'foo` у нашому прикладі з `defun`, ми уникли того, щоб Lisp намагався знайти (і не знайти) те, на що мав указувати `FOO`; натомість повернулося саме значення `FOO`.
Якщо `FOO` ніде не визначено в нашій програмі:

```lisp
foo  ; => <ERROR! Lisp doesn't know what foo points to!>
'foo ; => FOO
```

Поки що це можна розглядати просто як спосіб повертати символи з функції, але ми ще повернемося до цитування і докладніше розглянемо його наслідки в майбутніх вправах на концепції.
