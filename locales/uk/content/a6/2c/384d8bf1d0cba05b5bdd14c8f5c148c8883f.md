# Підказки

Для всіх цих завдань нам знадобиться команда `print`:
```awk
{print "something", "something else"}
```

## 1. Вивести список імен користувачів

* Скористайтеся [змінною `FS`][var-fs], щоб задати роздільник полів.

## 2. Вивести номери рядків

* Скористайтеся [вбудованою змінною `NR`][var-nr], щоб отримати номер рядка.

## 3. Вивести записи з некоректними домашніми каталогами.

* Домашній каталог міститься в шостому полі.
* Скористайтеся наданою функцією `startsWith`.
* Скористайтеся [булевими операторами][boolean-ops] (англ. Boolean): `&&` (логічне і), `||` (логічне або), `!`.

## 4. Вивести кількість коректних користувачів, які використовують bash

* Командна оболонка входу міститься в останньому полі; можна скористатися [змінною `NF`][var-nf].
