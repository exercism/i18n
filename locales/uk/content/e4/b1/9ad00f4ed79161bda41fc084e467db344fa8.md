# Ресурси

## Модулі

Perl постачається з набором основних модулів, перелік яких наведено на [perldoc](https://perldoc.perl.org/modules). Зазвичай будь-який із цих модулів можна використати одразу. (У деяких дистрибутивах основні модулі, можливо, доведеться встановлювати окремо).

[Awesome Perl](https://github.com/hachiojipm/awesome-perl) — це дібраний список корисних модулів, який до того ж посилається на низку інших списків із рекомендаціями.

Для Perl існує кілька засобів встановлення модулів, які дають змогу встановити безліч найрізноманітніших модулів із [CPAN](https://metacpan.org/).

### App::cpm
Дуже швидкий і простий засіб встановлення модулів.
Посібник із ним доступний на [CPAN](https://metacpan.org/pod/App::cpm::Tutorial).

Якщо скористатися інструкціями щодо `local::lib` із [документації зі встановлення](https://exercism.org/tracks/perl5/installation), цей засіб уже буде встановлено.

Щоб установити потрібні модулі з `cpanfile`, достатньо виконати `cpm install`, а для встановлення рекомендованих чи бажаних модулів скористатися `--with-recommends` або `--with-suggested` відповідно.

Виконайте `cpm install Module::Name`, щоб установити конкретний модуль локально, або `cpm install -g Module::Name`, щоб установити його глобально.

### App::cpanminus
Найвідоміший і найпоширеніший засіб встановлення модулів.
Інструкції зі встановлення можна знайти на [CPAN](https://metacpan.org/pod/App::cpanminus).

Щоб установити потрібні модулі з `cpanfile`, виконайте `cpanm -L local --installdeps .`.
Щоб установити конкретний модуль локально, виконайте `cpanm -L local Module::Name`, а щоб установити його глобально, виконайте `cpanm Module::Name`.

## Стиль коду та лінтування

Якщо потрібна слушна загальна порада щодо написання коду на Perl, гарним довідником буде [Perl Best Practices][PBP] Деміана Конвея.

Щоб причепурити код, можна скористатися модулем
[Perl::Tidy][PerlTidy].

Потім можна скористатися наданою утилітою `perltidy`,
щоб переформатувати код.

    # modify file in-place and save old version as some_script.pl.bak
    $ perltidy -b some_script.pl

У `perltidy` є *безліч* параметрів налаштування на будь-який смак. Вони
задокументовані [тут][perltidyDocs].

Є також [tidyview], візуальний інтерфейс, який дає змогу
змінювати різні параметри й одразу бачити результат.

Якщо потрібно дотримуватися певних правил написання коду, є також
[Perl::Critic][perlcritic]. Він містить правила, описані в уже згаданій
книжці *Perl Best Practices*, але існує безліч
плагінів, і його можна налаштувати під будь-які внутрішні правила
написання коду.

Щоб скористатися:

    $ perlcritic some_script.pl

Інструмент має безліч найрізноманітніших налаштувань; повний їхній
огляд наведено в його [документації][perlcriticdocs].
