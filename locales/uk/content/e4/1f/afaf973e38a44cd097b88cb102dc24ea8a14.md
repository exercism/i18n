# Цикли `for`

Циклічне виконання - фундаментальна концепція програмування, яка дозволяє виконувати блок коду кілька разів.
У Swift є два типи циклів: цикли [`for-in`][for-loops] і цикли `while`.
У цьому розділі ми розглянемо цикли `for-in`.

Цикли `for` дозволяють перебирати послідовність значень, беручи кожен елемент по черзі та привʼязуючи його до змінної, яку ми обираємо самі.
Swift дозволяє перебирати різноманітні послідовності, як-от діапазони, масиви та рядки тексту (англ. string), а також інші типи, які ми розглянемо пізніше.
Коли всі елементи послідовності перебрано, цикл завершується.

Цикли `for` оголошуються за допомогою ключового слова `for`, після якого йде імʼя змінної, ключове слово `in` і послідовність значень для перебору.
Змінна, задана в циклі `for-in`, незмінна, тобто ми не можемо змінити її значення всередині циклу.
Ось приклад циклу `for-in`, який перебирає масив чисел:

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
  print(number)
}
print("Done with numbers")

// prints:
// 3
// 10
// 7
// 11
// Done with numbers
```

~~~~exercism/note
Змінна `number` оголошується в циклі `for-in` і доступна лише в межах області видимості циклу.

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
    number + 1
}
number + 1
// Error: Use of unresolved identifier 'number'
```
~~~~

## Перебирання діапазону

Діапазон чисел також можна перебрати за допомогою циклу `for-in`.
Це дозволяє виконати блок коду певну кількість разів. Наприклад, діапазон `1...5` охоплює числа 1, 2, 3, 4 і 5, тож цикл виконається 5 разів.
Іноді може знадобитися перебрати індекси в такій структурі даних, як масив; для цього можна використати діапазон `0..<array.count`.

```swift
let numbers = [3, 10, 7, 11]

for i in 0..<numbers.count {
  print(numbers[i])
}

// prints:
// 3
// 10
// 7
// 11
```

## Перебирання рядка тексту

Рядок тексту також можна перебрати за допомогою циклу `for-in`.
Це дозволяє перебрати кожен символ у рядку тексту. Зауважмо, що тип, заданий у циклі, - це `Character`.

```swift
let message = "Hello!"

for character in message {
  print(character)
}

// prints:
// H
// e
// l
// l
// o
// !
```

## stride

Swift також надає функцію `stride`, яка дозволяє створити послідовність у межах діапазону із заданим кроком.
Яку потім можна перебрати за допомогою циклу `for-in`.
`stride` визначається як [`stride(from:to:by:)`][stride-to] або [`stride(from:through:by:)`][stride-through]: перший варіант не включає кінцеву межу, а другий включає її.

```swift
for i in stride(from: 0, to: 10, by: 2) {
  print(i)
}

// prints:
// 0
// 2
// 4
// 6
// 8
```

Зауважмо, що параметр `to` не включає кінцеву межу, тож цикл перебиратиме числа до числа перед параметром `to`, а параметр `through` включає кінцеву межу, тож у цьому випадку він також охопить `10`.

[stride-to]: https://developer.apple.com/documentation/swift/stride(from:to:by:)
[stride-through]: https://developer.apple.com/documentation/swift/stride(from:through:by:)
[for-loops]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
