# Докладніше

За допомогою власних типів у Gleam визначають нові типи даних. Вони можуть мати кілька _варіантів_, і кожен має власну назву.

```gleam
pub type Season {
  Spring
  Summer
  Autumn
  Winter
}
```

Кожен варіант власного типу може додатково містити певні дані, і різні варіанти можуть містити дані різних типів. Коли варіант містить дані, його називають _записом_.

```gleam
pub type Number {
  SomeInt(Int)
  SomeFloat(Float)
  Invalid
}
```

Щоб створити значення для конкретного варіанта, достатньо згадати його назву, якщо він не містить додаткових даних (`Spring`), або викликати його як функцію, якщо містить (`SomeInt(2)`).

```gleam
let spring = Spring
let integer_two = SomeInt(2)
```

Власні типи, як і все в Gleam, мають _структурну рівність_. Це означає, що два значення одного варіанта з однаковими даними рівнозначні.

```gleam
Spring == Spring // -> True
Spring == Autumn // -> False
SomeInt(2) == SomeInt(2) // -> True
SomeInt(2) == SomeFloat(2.0) // -> False
```

Варіанти власних типів можна зіставляти зі зразком за допомогою виразів `case`.

```gleam
import gleam/int
import gleam/float

pub fn describe(flexible_number: Number) -> String {
  case flexible_number {
    SomeFloat(f) -> "Float: " <> float.to_string(f)
    SomeInt(i) -> "Int: " <> int.to_string(i)
    Invalid -> "Neither a float nor an int"
  }
}
```
