# Докладніше

`case` - це багатошляховий перемикач у Factor, що працює на основі рівності. Це саме той інструмент, коли вибір залежить від того, чи *одне* значення дорівнює одному з кількох варіантів, а не коли кожній гілці потрібна окрема перевірка (для цього використовуйте `cond`).

```factor
USING: combinators ;

SYMBOLS: yes no maybe ;

: invert ( ?/maybe -- ?'/maybe )
    {
        { yes [ no ] }
        { no  [ yes ] }
        [ ]            ! default: leave value alone
    } case ;
```

Кілька моментів, які варто тримати в голові:

- Рівність записують як `=`. Ключем може стати будь-що, для чого працює `=`: числа, рядки тексту (англ. string), символи, symbol, навіть кортежі.
- *Зіставлені* гілки бачать стек *без* вхідного значення. *Типові* гілки бачать його все ще на вершині стека.
- Якщо в `case` немає типової гілки й жодна гілка не збігається, він кидає помилку.

Де це можливо, `case` компілюється в таблицю переходів, тож він не просто синтаксичний цукор для ланцюжка `if`, а ще й швидкий.
