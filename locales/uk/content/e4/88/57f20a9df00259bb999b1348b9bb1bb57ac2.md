# Вступ

У Python [кортеж][tuple] - це _незмінна_ колекція елементів, розташованих у _послідовності_.
Як і більшість колекцій, `tuples` можуть містити будь-які (або кілька) типи даних, зокрема інші `tuples`.
Кортежі підтримують усі [звичайні операції над послідовностями][common sequence operations], але **не** підтримують [операції над змінними послідовностями][mutable sequence operations].

Елементи кортежу можна перебирати за допомогою конструкції `for item in <tuple>`.
Якщо потрібні й індекс, і значення елемента, можна скористатися `for index, item in enumerate(<tuple>)`.
Як і в будь-якій послідовності, до елементів усередині `tuples` можна звертатися через _запис у дужках_ з використанням `0-based index` зліва або `-1-based index` справа.
Кортежі також можна копіювати повністю або частково за допомогою зрізів (_`<tuple>[<start>:<stop>:<step>]`_).


## Створення кортежу

Кортежі можна створювати кількома способами: за допомогою конструктора класу `tuple(<iterable>)` або оголошення літерала `tuple`.

### Використання конструктора `tuple()` порожнім або з _ітерованим обʼєктом_:

```python
>>> no_elements = tuple()
()

# The constructor *requires* an iterable, so single elements must be passed in a list or another tuple.
>>> one_element = tuple([16])
(16,)
```

Рядки тексту (англ. string) можна перебирати, тож використання одного `str` як аргументу конструктора `tuple()` може дати несподіваний результат:

```python
# String elements (characters) are iterated through and added to the tuple
>>> multiple_elements_string = tuple("Timbuktu")
('T', 'i', 'm', 'b', 'u', 'k', 't', 'u')
```

Елементи одного ітерованого обʼєкта додаються по одному:

```python
>>> multiple_elements_list = tuple(["Parrot", "Bird", 334782])
("Parrot", "Bird", 334782)

>>> multiple_elements_set = tuple({2, 3, 5, 7, 11})
(2,3,5,7,11)
```

#### Оголошення кортежу як _літерала_:

Оскільки конструктор `tuple(<iterable>)` приймає як аргументи лише _ітеровані обʼєкти_ (або нічого), створити кортеж з одного елемента набагато простіше літеральним способом.

```python
>>> no_elements = ()
()

>>> one_element = ("Guava",)
("Guava",)
```

Вкладені структури даних можна включати як елементи `tuple`, зокрема інші `tuples`:

```python
>>> nested_data_structures = ({"fish": "gold", "monkey": "brown", "parrot" : "grey"}, ("fish", "mammal", "bird"))
({"fish": "gold", "monkey": "brown", "parrot" : "grey"}, ("fish", "mammal", "bird"))

>>> nested_data_structures_1 = (["fish", "gold", "monkey", "brown", "parrot", "grey"], ("fish", "mammal", "bird"))
(["fish", "gold", "monkey", "brown", "parrot", "grey"], ("fish", "mammal", "bird"))
```

## Конкатенація кортежів

Кортежі можна зʼєднати за допомогою оператора плюс `+`, який розпаковує кожен `tuple` і створює новий обʼєднаний `tuple`.

```python
>>> new_via_concatenate = ("George", 5) + ("cat", "Tabby")
("George", 5, "cat", "Tabby")

#likewise, using the multiplication operator * is the equivalent of using + n times
>>> first_group = ("cat", "dog", "elephant")

>>> multiplied_group = first_group * 3
('cat', 'dog', 'elephant', 'cat', 'dog', 'elephant', 'cat', 'dog', 'elephant')
```

## Доступ до елементів усередині кортежу

До елементів усередині `tuple` можна звертатися через _запис у дужках_ з використанням `0-based index` зліва або `-1-based index` справа.

```python
student_info = ("Alyssa", "grade 3", "female", 8 )

#gender is at index 2 or index -2
>>> student_gender = student_info[2]
'female'

>>> student_gender = student_info[-2]
'female'

#name is at index 0 or index -4
>>> student_name = student_info[0]
Alyssa

>>> student_name = student_info[-4]
Alyssa
```

## Перебирання елементів кортежу

Елементи всередині `tuple` можна _перебирати_ в циклі, використовуючи синтаксис `for item in <tuple>`.
Якщо потрібні й індекси, і значення, можна скористатися `for index, item in enumerate(<tuple>)`.

```python
>>> student_info = ("Alyssa", "grade 3", "female", 8 )
>>> for item in student_info:
...   print(item)

...
Alyssa
grade 3
female
8

>>> for index, item in enumerate(student_info):
...  print("Index is: " + str(index) + ", value is: " + str(item) +".")

...
Index is: 0, value is: Alyssa.
Index is: 1, value is: grade 3.
Index is: 2, value is: female.
Index is: 3, value is: 8.
```

## Перевірка належності до кортежу

Оператор `in` можна використовувати для перевірки належності елемента до `tuple`.

```python
>>> multiple_elements_list = tuple(["Parrot", "Bird", 334782])
("Parrot", "Bird", 334782)

>>> "Parrot" in multiple_elements_list
True
```
