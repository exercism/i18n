# Вступ

## Порівняння

У JavaScript числа можна порівнювати за допомогою наведених нижче операторів відношення та рівності.

| Порівняння               | Оператор  |
| ------------------------ | --------- |
| Більше ніж               | `a > b`   |
| Більше або дорівнює      | `a >= b`  |
| Менше ніж                | `a < b`   |
| Менше або дорівнює       | `a <= b`  |
| (Строга) рівність        | `a === b` |
| Не (строга) рівність     | `a !== b` |

Результат порівняння завжди є булевим значенням (англ. Boolean): `true` або `false`.

```javascript
1 < 3;
// => true

2 !== 2;
// => false

1 === 1.0;
// => true
// All numbers are floating-points, so this is different syntax for
// the exact same value.
```

У JavaScript наведені вище оператори порівняння можна також використовувати для порівняння рядків тексту (англ. string).
У такому разі застосовується словниковий (лексикографічний) порядок.
Список точного порядку всіх символів можна знайти [тут][utf-16-list].

```javascript
'Apple' > 'Pear';
// => false

'a' < 'above';
// => true

'a' === 'A';
// => false
```

## Умовні конструкції

Щоб виконати код за певної умови, у JavaScript часто використовують умовну конструкцію `if`.
Вона складається з ключового слова `if`, умови в круглих дужках і блоку коду у фігурних дужках.
Блок коду виконається, лише якщо умова дорівнює `true`.

```javascript
if (condition) {
  // code that is executed if "condition" is true
}
```

Її можна використовувати окремо або разом із ключовим словом `else`.

```javascript
if (condition) {
  // code that is executed if "condition" is true
} else {
  // code that is executed otherwise
}
```

Щоб додати ще одну умову до `else`, можна використати `else if`.

```javascript
if (condition1) {
  // code that is executed if "condition1" is true
} else if (condition2) {
  // code that is executed if "condition2" is true
  // but "condition1" was false
} else {
  // code that is executed otherwise
}
```
