# Докладніше

Haxe має два типи чисел: цілі числа та числа з плаваючою комою:

- `Int`: позначає ціле число.
- `Float`: позначає 64-бітне число з плаваючою комою подвійної точності.

```haxe
var integer:Int = 10;
var floating:Float = 5.4;
```

Хоча кожне `Int` можна використати там, де потрібне `Float` (тобто `Int` **можна присвоїти** змінній типу `Float`, і він **уніфікується** з `Float`), зворотне не так: присвоєння `Float` змінній типу `Int` може спричинити втрату точності, тому не дозволяється неявно.

## Порівняння

Числа рівні, якщо вони мають однакове значення.

```haxe
1 == 1; // true

1.2 == 1.2; // true

1 == 1.0; // true

0.2 + 0.1 == 0.3 // false
```
