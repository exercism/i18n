# Вказівки

У цій вправі ми будемо писати код, який допоможе компанії з виготовлення вивісок створювати написи на замовлення для своїх вивісок.

## 1. Створити вивіску для події

Реалізуйте функцію `buildSign(occasion, name)`, яка приймає рядок тексту (англ. string) як параметр `occasion` і рядок тексту з чиїмось іменем як параметр `name`.
Обидва параметри буде вбудовано в шаблонний рядок, щоб вивести напис на вивісці.

```javascript
buildSign('Birthday', 'Rob');
// => "Happy Birthday Rob!"
```

## 2. Створити вивіску до дня народження

Реалізуйте функцію `buildBirthdaySign(age)`, яка приймає вік і залежно від нього визначає частину напису на вивісці.
Якщо вік 50 або більше, користувача на вивісці буде названо _mature_, інакше його буде названо _young_.
Точний очікуваний вивід показано нижче:

```javascript
buildBirthdaySign(50);
// => "Happy Birthday! What a mature fellow you are."

buildBirthdaySign(45);
// => "Happy Birthday! What a young fellow you are."
```

## 3. Створити вивіску до випуску

Реалізуйте функцію `graduationFor(name, year)`, яка приймає імʼя як рядок тексту, а рік як число, і за допомогою інтерполяції рядків створює фразу для вивіски, у якій символ нового рядка розділяє два рядки повідомлення.

```javascript
graduationFor('Hannah', 2022);
/* => "Congratulations Hannah!
       Class of 2022"
*/
```

## 4. Обчислити вартість вивіски

Реалізуйте функцію `costOf(sign, currency)`, яка приймає рядок тексту з вмістом вивіски та рядок тексту, що позначає валюту.
Базова ціна вивіски становить 20 у заданій валюті. Крім того, кожна літера коштує 2. (Пробіли теж враховуються в розрахунку.)
Повернута фраза містить вартість створення вивіски, записану з двома цифрами після десяткової коми, а далі йде рядок тексту з валютою.

```javascript
costOf('Happy Birthday Rob!', 'dollars');
// => "Your sign costs 58.00 dollars."
```
