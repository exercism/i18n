# Вступ

Масиви у Factor - це послідовності фіксованої довжини: ми можемо змінювати елементи, але не довжину. Ми вже знаємо, як записати літерал масиву (`{ … }`), а також як брати зрізи та агрегувати його. Ця вправа охоплює невеликий набір інструментів, який стає в нагоді, коли ми будуємо масиви зі значень у стеку, а потім шукаємо в них або перевпорядковуємо їхній вміст.

## Побудова зі стека

`1array`, `2array`, `3array` і `4array` (у [`arrays`][arrays]) знімають 1, 2, 3 або 4 значення з вершини стека й збирають їх у масив:

```
1array ( a       -- { a }       )
2array ( a b     -- { a b }     )
3array ( a b c   -- { a b c }   )
4array ( a b c d -- { a b c d } )
```

```factor
42 1array .                ! => { 42 }
3 4 2array .               ! => { 3 4 }
"x" "y" "z" 3array .       ! => { "x" "y" "z" }
1 2 3 4 4array .           ! => { 1 2 3 4 }
```

## Обʼєднання

`concat` (із [`sequences`][sequences]) приймає послідовність, елементи якої самі є послідовностями, і вирівнює їх на один рівень. `join` робить те саме, але вставляє роздільник між кожною парою:

```
concat ( seqs     -- seq )
join   ( seqs sep -- seq )
```

```factor
{ { 1 2 } { 3 4 } { 5 } } concat .
! => { 1 2 3 4 5 }

{ "alpha" "beta" "gamma" } ", " join .
! => "alpha, beta, gamma"
```

## Обернення

`reverse` повертає нову послідовність з елементами у зворотному порядку:

```
reverse ( seq -- newseq )
```

```factor
{ 1 2 3 4 } reverse .   ! => { 4 3 2 1 }
```

## Чи це масив?

`array?` (у [`arrays`][arrays]) - це предикат типу. Він повертає правду для будь-якого значення, створеного за допомогою `<array>`, `1array`/`2array`/..., чи літерала масиву `{ … }`, і неправду для всього іншого: векторів, рядків тексту (англ. string) та інших послідовностей.

```
array? ( obj -- ? )
```

```factor
{ 1 2 3 } array? .         ! => t
"hello" array? .           ! => f
V{ 1 2 3 } array? .        ! => f
```

## Пошук

`index` повертає позицію першого елемента, що дорівнює вхідному значенню, або `f`, якщо такого немає. `member?` повертає лише булеве значення (англ. Boolean). Обидва приймають **спершу елемент**, а **послідовність — другою**. `members` (у [`sets`][sets]) повертає *унікальні* елементи послідовності, тобто усуває дублікати, а `all-unique?` (теж із `sets`) перевіряє, чи в послідовності вже немає дублікатів:

```
index       ( elt seq -- i/f )
member?     ( elt seq -- ? )
members     ( seq     -- uniques )
all-unique? ( seq     -- ? )
```

```factor
"b" { "a" "b" "c" } index .       ! => 1
"z" { "a" "b" "c" } index .       ! => f
"b" { "a" "b" "c" } member? .     ! => t
"z" { "a" "b" "c" } member? .     ! => f
{ 1 2 3 2 1 } members .           ! => { 1 2 3 }
{ 1 2 3 } all-unique? .           ! => t
{ 1 2 1 } all-unique? .           ! => f
```
