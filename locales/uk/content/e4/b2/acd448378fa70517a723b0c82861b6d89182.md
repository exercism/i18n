# Вступ

Kotlin - це **статично типізована** мова програмування, яку розробила компанія JetBrains. Це означає, що тип змінних визначається під час компіляції.

## Змінні

Як і в інших статично типізованих мовах програмування, тип кожної змінної потрібно визначати під час компіляції. Можна не вказувати тип явно там, де компілятор здатен вивести його з контексту.

У Kotlin є незмінні (`val`) та змінювані (`var`) змінні. Значення незмінної змінної не можна змінити після присвоєння їй початкового значення. Здебільшого ми користуємося саме такими змінними.

```kotlin
val robotName = "HAL-9000"
userId = "T-1000"  // This will not compile
```

Значення змінюваної змінної можна змінювати один або кілька разів:

```kotlin
var index = 12
print(index)  // 12

index = 100
print(index)  // 100
```

Крапка з комою в Kotlin необовʼязкова, крім кількох особливих випадків, про які йтиметься далі.

## Функції

Функції в Kotlin визначають за допомогою ключового слова `fun`, і вони є _обʼєктами першого класу_ (це не повʼязано з ООП). Це означає, що їх можна оголошувати прямо у файлах (так звані `top-level functions`; наприклад, у Java методи можна визначати лише в класах, а не у файлах):

```kotlin
// This is content of the Hello.kt file

fun hello() {}
```

Функції можуть приймати аргументи. Кожен аргумент має імʼя та тип. На відміну від змінних, тип аргументів не можна вивести. Функція може мати нуль або більше аргументів:

```kotlin
fun hello() {}

fun hello(name: String) {}

fun hello(name: String, age: Int) {}
```

Функції Kotlin можуть повертати значення, а можуть і не повертати:

```kotlin
fun min(a: Int, b: Int): Int

fun countBonuses(user: User): Bonuses

fun run() {}
```

Щоб повернути значення з функції, використовують ключове слово `return`:

```kotlin
fun getName(): String {
    return "Alice"
}
```

Функції можуть мати параметри з типовими значеннями. Ці значення використовуються, якщо їх не вказати під час виклику функції:

```kotlin
fun ping(host: String = "localhost") {
    println("PING --> $host")
}

ping("exercism.io")  // PING --> exercism.io
ping()               // PING --> localhost
```

## Коментарі

Щоб написати однорядковий коментар, використовують `//`:

```kotlin
foo() // Everything after `//` will be ignored by compiler

// I will be ignored too
```

а за допомогою `/*` і `*/` пишуть багаторядкові коментарі:

```kotlin
/*
   This this an example
   for a multiline comment
*/
```
