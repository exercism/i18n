# Вказівки

У цій вправі ми напишемо трохи коду, який допоможе нам підготуватися до купівлі транспортного засобу.

На нас чекають три завдання: визначити, чи потрібне посвідчення водія, допомогти вибрати між двома транспортними засобами та оцінити прийнятну ціну вживаного транспортного засобу.

## 1. Визначити, чи потрібне посвідчення водія

Деякі види транспортних засобів вимагають посвідчення водія для керування ними.
Припустімо, що посвідчення потребують лише види `"car"` і `"truck"`, а всім іншим можна керувати й без посвідчення.

Реалізуйте функцію `needs_license(kind)`, яка приймає вид транспортного засобу як рядок тексту (англ. string) і повертає булеве значення (англ. Boolean), яке вказує, чи потрібне посвідчення водія для цього виду транспортного засобу.

```cpp
needs_license("car")
// => true

needs_license("bike")
// => false

needs_license("truck")
// => true
```

## 2. Вибір між двома потенційними транспортними засобами для купівлі

Оцінімо доступні нам варіанти транспортних засобів.
Нам вдалося звузити вибір до двох варіантів, але потрібна допомога, щоб ухвалити остаточне рішення.
Для цього реалізуйте функцію `choose_vehicle(option1, option2)`, яка приймає два транспортні засоби як аргументи й повертає рішення, що містить варіант, який іде першим у лексикографічному порядку.

```cpp
choose_vehicle("Wuling Hongguang", "Toyota Corolla")
// => "Toyota Corolla is clearly the better choice."

choose_vehicle("Volkswagen Beetle", "Volkswagen Golf")
// => "Volkswagen Beetle is clearly the better choice."
```

Повернутий рядок тексту має відповідати шаблону `"<CHOSEN_VEHICLE> is clearly the better choice."`, де `<CHOSEN_VEHICLE>` - це обраний варіант із переданих аргументів.

## 3. Розрахунок орієнтовної ціни вживаного транспортного засобу

Тепер, коли ми ухвалили рішення, хочеться переконатися, що в автосалоні нам дадуть справедливу ціну.
Оскільки ми збираємося купити вживаний транспортний засіб, ціна залежить від того, який він старий.
Для приблизної оцінки припустімо: якщо транспортному засобу менше ніж 3 роки, він коштує 80% від початкової ціни, яку мав, коли був новим.
Якщо йому щонайменше 10 років, він коштує 50%.
Якщо транспортному засобу щонайменше 3 роки, але менше ніж 10 років, він коштує 70% від початкової ціни.

Реалізуйте функцію `calculate_resell_price(original_price, age)`, яка застосовує цю логіку за допомогою `if`, `else if` і `else` (є й інші способи, якщо є бажання потренуватися).
Вона приймає початкову ціну й вік транспортного засобу як аргументи та повертає орієнтовну ціну в автосалоні.

```cpp
calculate_resell_price(1000, 1)
// => 800

calculate_resell_price(1000, 5)
// => 700

calculate_resell_price(1000.0, 15)
// => 500
```

> Зауваження: повернене значення має тип `double`.
