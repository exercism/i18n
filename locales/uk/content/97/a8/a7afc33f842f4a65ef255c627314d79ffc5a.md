# Додаток до інструкцій

## Особливості Arturo

У цій вправі потрібно повертати вік за допомогою [фізичної величини][physical-quantities] з власною одиницею вимірювання, яка позначає тривалість одного року на цій планеті.
В Arturo величина складається з числового значення та повʼязаної з нею [одиниці вимірювання][unit-of-measurement].

```arturo
length: 10`m
units length ; `m
scalar length ; 10

10`m * 10`m ; 100 m²
```

~~~~exercism/caution
Вбудована в Arturo одиниця `yr дорівнює 31556952 секундам.
Тому потрібно визначити й використати власну одиницю року через кількість секунд, згадану раніше в інструкціях.
~~~~

Величини можна [перетворювати][convert] на іншу сумісну одиницю.
```arturo
convert 1`m `ft ; 1250/381 ft
convert 100`m2 `ft2 ; 156250000/145161 ft²

property `m  ; length
property `m2 ; area

convert 1`m `m2 ; conversion error results
```

~~~~exercism/note
Через обмеження точності чисел з плаваючою комою Arturo іноді зберігає скаляр як раціональне число.
Функція [`to`][to] дозволяє натомість отримати значення як наближене число з плаваючою комою.

```arturo
length: convert 1`m `ft ; 1250/381 ft
to :floating length ; 3.280839895013123
```

[to]: https://arturo-lang.io/documentation/library/types/to/
~~~~

Arturo також дозволяє [задавати][specify] власні одиниці для величин.

```arturo
specify 'nauMile 1.151`mi
property `nauMile length
specify 'lea 3.00579`nauMile
property `lea ; length
depth: 20000`lea
convert depth `km ; 111355.7993425152 km
```
