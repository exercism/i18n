# Про

Кожна програма, яку ми будь-коли запускали, чи то гра, веббраузер або застосунок на телефоні, зрештою стає довгим списком крихітних інструкцій, які процесор виконує одну за одною.
Мова асемблера дає змогу писати ці інструкції самостійно.
Замість змінних, масивів і циклів `for` ми працюємо з власними будівельними блоками процесора: невеликим набором регістрів, адресами памʼяті та переходами від однієї інструкції до іншої.

RISC-V (вимовляється «risk five») - це архітектура процесорів, яку започаткували в Каліфорнійському університеті в Берклі 2010 року.
На відміну від більшості процесорних архітектур, вона є відкритим стандартом: нікому не потрібно платити чи просити дозволу, щоб виготовляти чип RISC-V, а специфікацію може безкоштовно прочитати будь-хто.
Чипи RISC-V трапляються в мікроконтролерах, одноплатних компʼютерах, пристроях зберігання даних тощо.

RISC-V добре підходить на роль першої мови асемблера, адже її задумали простою.
Її інструкції підкоряються невеликій кількості регулярних закономірностей, а 32 регістри мають чіткі й послідовні ролі, тож запамʼятовувати треба значно менше, ніж для процесорів у більшості ноутбуків.
Саме через цю простоту багато університетів тепер використовують RISC-V, щоб пояснювати, як працюють компʼютери.

Ось невеликий приклад: функція, яка додає два числа:

```riscvasm
add_numbers:
        add     a0, a0, a1      /* a0 = a0 + a1 */
        ret                     /* return to the caller, with the answer in a0 */
```

У цьому треку ми пишемо код 32-бітною мовою асемблера RISC-V.
Нам не потрібне жодне апаратне забезпечення RISC-V: наші програми тестуються на емуляторі, який вдає, що він процесор RISC-V.
Вправи можна розвʼязувати в онлайн-редакторі або на власному компʼютері за допомогою безкоштовних інструментів.

Вивчення асемблера потребує терпіння, але воно того варте.
Коли ми побачимо, який вигляд має цикл або виклик функції для процесора, кожна інша мова програмування стане трохи зрозумілішою.
