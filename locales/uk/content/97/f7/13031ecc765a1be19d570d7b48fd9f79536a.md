# Тести

Щоб запустити тест через DrRacket, просто відкрийте файл тесту й натисніть кнопку «Run» у верхньому правому куті.

Щоб запустити тест із командного рядка, запустіть тест із каталогу вправи такою командою:

```
raco test <exercise>-test.rkt
```

де `<exercise>` слід замінити на ідентифікатор вправи.
