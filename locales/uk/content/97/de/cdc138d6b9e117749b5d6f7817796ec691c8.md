# Вступ

Окрім класів символів і квантифікаторів, регулярні вирази можуть описувати *структуру* та *контекст*. Ці можливості належать до того самого словника [`regexp`][regexp] і того самого літерала `R/ /`.

Круглі дужки `( )` групують частину шаблону, щоб квантифікатор або `|` («це або те») застосовувався до всієї групи; `?` після групи робить її необовʼязковою:

```factor
USING: regexp ;

"abab"    R/ (ab)+/ matches? .             ! => t
"$100"    R/ \$\d+(\.\d{2})?/ matches? .   ! => t   (optional group)
```

Якорі привʼязують шаблон до позиції: `^` (початок), `$` (кінець) і `\b` (межа слова).

*Перегляд навколо* зіставляє за тим, що оточує позицію, і не споживає її:

```
(?=...)    ! lookahead — ... must follow
(?!...)    ! negative lookahead — ... must not follow
(?<=...)   ! lookbehind — ... must come before
```

```factor
USING: regexp ;

"spent $100 and $25" R/ (?<=\$)\d+/ all-matching-subseqs .
! => { "100" "25" }

"up 5% then 12%" R/ \d+(?=%)/ all-matching-subseqs .
! => { "5" "12" }
```

Літера-опція після закривного `/` змінює весь шаблон; `i` робить його нечутливим до регістру:

```factor
USING: regexp ;

"REFUND" R/ refund/i matches? .   ! => t
```

Factor використовує перегляд навколо замість груп захоплення: у ньому немає видобування груп захоплення, зворотних посилань або лінивих квантифікаторів.

[regexp]: https://docs.factorcode.org/content/vocab-regexp.html
