# Вступ

## Числа з плаваючою комою

Число з плаваючою комою містить нуль або більше цифр після десяткового розділювача. Наприклад: `-2.4`, `0.1`, `3.14`, `16.984025` і `1024.0`.

Різні типи з плаваючою комою можуть зберігати різну кількість цифр після десяткового розділювача; це називається точністю.

У C# є три типи з плаваючою комою:

- `float`: 4 байти (точність ~6-9 цифр). Записується як `2.45f`.
- `double`: 8 байтів (точність ~15-17 цифр). Це найпоширеніший тип. Записується як `2.45` або `2.45d`.
- `decimal`: 16 байтів (точність 28-29 цифр). Зазвичай використовується під час роботи з грошовими даними, оскільки його точність зменшує ймовірність помилок округлення. Записується як `2.45m`.

Як бачимо, кожен тип може зберігати різну кількість цифр. Наприклад, якщо спробувати зберегти число π у `float`, збережуться лише перші 6 знаків після коми (остання збережена цифра буде округлена).

## Цикли `while`

У цій вправі нам може знадобитися цикл. У C# є кілька способів записати цикл, але тут найдоречнішим буде цикл `while`:

```csharp
int x = 23;

while (x > 10)
{
    // Execute logic if x > 10
    x = x - 2;
}
```

## Цикли `do`/`while`

Якщо код у циклі має виконуватися принаймні один раз, можна використати цикл `do`/`while`:

```csharp
int x = 23;

do
{
    // Execute body, repeating only if x > 10
    x = x - 2;
} while (x > 10);
```
