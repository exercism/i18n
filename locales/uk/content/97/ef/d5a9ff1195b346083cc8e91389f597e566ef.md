## Інтерактивні інструменти jq

Введіть якісь дані та поекспериментуйте з різними фільтрами jq, щоб побачити, що з цього вийде.

- [jq playground][jqplay] — це «спробувати онлайн».
- [ijq][ijq], інтерактивний інструмент jq, як jqplay для командного рядка.
- [jqp][jqp] — це ще один інструмент командного рядка: він використовує gojq як backend, який не на 100% сумісний з оригінальним jq.

## Інші інструменти для обробки JSON

- [gron][gron]: «розгортає» JSON у послідовність окремих присвоєнь, що дає змогу обробляти його інструментами, орієнтованими на рядки (grep тощо).
- [jo][jo]: невелика утиліта для створення обʼєктів JSON зі змінних оболонки.
- [jello][jello]: jello схожий на jq, але використовує стандартний синтаксис словників і масивів Python.
