# Інструкції

У цій вправі ми будемо організовувати гонки між різними типами машин з дистанційним керуванням.
Кожна машина має власні характеристики швидкості та розряду батареї.

Машини стартують із повністю зарядженими батареями (100%). Щоразу, коли ми керуємо машиною за допомогою
пульта дистанційного керування, вона проїжджає відстань, що дорівнює швидкості машини в метрах, а відсоток
заряду батареї, що залишився, зменшується на розмір її розряду.

Якщо заряд батареї машини менший за відсоток її розряду, ми більше не можемо керувати машиною.

Кожна гоночна траса має власну довжину. Машини перевіряють, дивлячись, чи зможуть вони завершити трасу,
не розрядивши батарею.

## 1. Створімо машину з дистанційним керуванням

Визначмо масив `car` з такими елементами:

- speed
- battery_drain
- battery
- distance_traveled

Дозвольмо створювати машину з дистанційним керуванням, визначивши функцію `new_car`, яка приймає швидкість машини в метрах,
і відсоток розряду батареї як свої два параметри та повертає масив `car`.

У нової машини заряд батареї становить 100%, а пройдена відстань дорівнює нулю.

```R
speed <- 5
battery_drain <- 2
car <- new_car(speed, battery_drain)
str(car)
#> List of 4
#>  $ speed             : num 5
#>  $ battery_drain     : num 2
#>  $ battery           : num 100
#>  $ distance_traveled : num 0
```

## 2. Створімо гоночну трасу

Визначмо інший масив під назвою `track` з єдиним елементом `track_length`.
Дозвольмо створювати гоночну трасу, визначивши функцію `new_track`, яка приймає довжину траси в метрах:

```R
track_length <- 800
track <- new_track(track_length)
str(track)
#> List of 1
#>  $ track_length: num 800
```

## 3. Перевірмо, чи розряджена батарея

Реалізуймо функцію `battery_drained()`, яка показує, чи розряджена батарея.
Батарея вважається розрядженою, якщо її заряду не вистачає, щоб проїхати ще раз.

```R
speed <- 5;
battery_drain <- 2;
car <- new_car(speed, battery_drain);
car <- drive(car);

battery_drained(car);
#> [1] FALSE
```

## 4. Керуймо машиною

Реалізуймо функцію `drive`, яка оновлює кількість пройдених метрів відповідно до швидкості машини та зменшує заряд батареї відповідно до її розряду.
Якщо заряду батареї не вистачає, щоб проїхати ще раз, машина не рухатиметься.

```R
speed <- 5
battery_drain <- 2
car <- new_car(speed, battery_drain)
car <- drive(car)
str(car)
#> List of 4
#>  $ speed             : num 5
#>  $ battery_drain     : num 2
#>  $ battery           : num 98
#>  $ distance_traveled : num 5
```

## 5. Перевірмо, чи може машина з дистанційним керуванням завершити гонку

Щоб завершити гонку, машина повинна мати змогу проїхати всю довжину траси. Це означає не розрядити батарею до того,
як перетнути фінішну лінію.

Реалізуймо функцію `can_finish`, яка приймає `car` і `track` як свої параметри та повертає `TRUE`, якщо машина може завершити гонку; інакше повертає `FALSE`.

Припустімо, що ми зараз на стартовій лінії гонки й запускаємо двигун машини для перегонів. Зважмо на те, що батарея машини на старті гонки не обовʼязково може бути повністю зарядженою.

```R
speed <- 5
battery_drain <- 5
car <- new_car(speed, battery_drain)

name <- "track1"
track_length <- 100
track <- new_track(track_length)

can_finish(car, track)
#> [1] TRUE

# partial battery charge
car$battery <- 50
can_finish(car, track)
#> [1] FALSE
```

## 6. Збережімо, чи може машина з повною батареєю завершити трасу

Ми створили кілька трас різної довжини й маємо зберегти, чи зможе наша машина подолати їх із повністю зарядженою батареєю.

Реалізуймо функцію `store_track`, яка приймає машину, трасу й назву траси та повертає оновлену машину з додатковим елементом.
Імʼям цього елемента має бути `name` траси, а значенням має бути вкладений масив із `track_length` та ознакою того, чи може машина її `complete`.

Машина, передана в аргументі, може бути не повністю зарядженою, тож не забудьмо скинути заряд батареї та пройдену відстань, перш ніж її використовувати.

```R
speed <- 5
battery_drain <- 5
car <- new_car(speed, battery_drain)
car$battery <- 50

name <- "track1"
track_length <- 100
track <- new_track(track_length)

track1 <- store_track(car, track, "Imola")
str(track1)
#> List of 5
#>  $ speed             : num 5
#>  $ battery_drain     : num 5
#>  $ battery           : num 100
#>  $ distance_traveled : num 0
#>  $ Imola             :List of 2
#>   ..$ track_length: num 100
#>   ..$ complete    : logi TRUE
```
