# Докладніше

Щоб виконувати логіку повторно, можна використовувати цикли. Один із найпоширеніших типів циклів у C# - цикл `while`, який продовжує повторюватися, доки булева умова (англ. Boolean) не набуде значення `false`.

```csharp
int x = 23;

while (x > 10)
{
    // Execute logic if x > 10
    x = x - 1;
}
```
