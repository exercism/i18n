# Οδηγίες

Δουλεύεις πάνω στην υλοποίηση ενός παιχνιδιού ρόλων. Ο χαρακτήρας του παίκτη αναπαρίσταται από το εξής:

```rust
pub struct Player {
    health: u32,
    mana: Option<u32>,
    level: u32,
}
```

Οι παίκτες σε αυτό το παιχνίδι πρέπει να φτάσουν στο level 10 για να ξεκλειδώσουν ένα mana pool και να αρχίσουν να ρίχνουν ξόρκια. Πριν από αυτό το σημείο, το mana του Player είναι `None`.

Δουλεύεις πάνω σε δύο λειτουργίες σε αυτό το παιχνίδι: τη μηχανική revive και τη μηχανική ρίψης ξόρκιων.

Η μέθοδος `revive` πρέπει να ελέγχει αν ο Player είναι πράγματι νεκρός (το health του έχει φτάσει στο 0) και, αν είναι, η μέθοδος πρέπει να επιστρέφει ένα νέο στιγμιότυπο Player με 100 health.
Αν το level του Player είναι 10 ή παραπάνω, πρέπει επίσης να αναβιώνει με 100 mana.
Αν το level του Player είναι κάτω από 10, το mana του πρέπει να είναι `None`. Η μέθοδος `revive` πρέπει να διατηρεί το level του Player.

```rust
let dead_player = Player { health: 0, mana: None, level: 2 };
dead_player.revive()
// Returns Player { health: 100, mana: None, level: 2 }
```

Αν η μέθοδος `revive` κληθεί σε έναν Player του οποίου το health είναι 1 ή παραπάνω, τότε η μέθοδος πρέπει να επιστρέφει `None`.

```rust
let alive_player = Player { health: 1, mana: Some(15), level: 11 };
alive_player.revive()
// Returns None
```

Η μέθοδος `cast_spell` παίρνει μια μεταβλητή αναφορά σε έναν Player καθώς και μια παράμετρο `mana_cost` που δείχνει πόσο mana κοστίζει το ξόρκι. Επιστρέφει την ποσότητα ζημιάς που προκαλεί το ξόρκι, η οποία θα είναι πάντα το διπλάσιο του κόστους mana του ξόρκι, αν το ξόρκι εκτελεστεί με επιτυχία.

- Αν ο παίκτης δεν έχει πρόσβαση σε mana pool, η προσπάθεια να ρίξει το ξόρκι πρέπει να μειώσει το health του κατά το κόστος mana του ξόρκι. Η ζημιά που επιστρέφεται πρέπει να είναι 0.

  ```rust
  let not_a_wizard_yet = Player { health: 79, mana: None, level: 9 };
  assert_eq!(not_a_wizard_yet.cast_spell(5), 0)
  assert_eq!(not_a_wizard_yet.health, 74);
  assert_eq!(not_a_wizard_yet.mana, None);
  ```

- Αν ο παίκτης έχει mana pool αλλά ανεπαρκές mana, η μέθοδος δεν πρέπει να επηρεάζει το pool, αλλά να επιστρέφει 0

  ```rust
  let low_mana_wizard = Player { health: 93, mana: Some(3), level: 12 };
  assert_eq!(low_mana_wizard.cast_spell(10), 0);
  assert_eq!(low_mana_wizard.health, 93);
  assert_eq!(low_mana_wizard.mana, Some(3));
  ```

- Διαφορετικά, το `mana_cost` πρέπει να αφαιρείται από το mana pool του Player και να επιστρέφεται η κατάλληλη ποσότητα ζημιάς.

  ```rust
  let wizard = Player { health: 123, mana: Some(30), level: 18 };
  assert_eq!(wizard.cast_spell(10), 20);
  assert_eq!(wizard.health, 123);
  assert_eq!(wizard.mana, Some(20));
  ```

Καλή διασκέδαση!
