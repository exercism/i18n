# Σχετικά

Οι δομές δεδομένων που μπορούν να περιέχουν μηδέν ή περισσότερα στοιχεία είναι γνωστές ως _συλλογές_.
Ένας **πίνακας** στη Ruby είναι μια συλλογή που διατηρεί τη σειρά με την οποία προστίθενται τα αντικείμενά του.
Οι πίνακες μπορούν να περιέχουν οποιοδήποτε αντικείμενο.
Τα αντικείμενα μπορούν να προστεθούν σε έναν πίνακα ή να ανακτηθούν από αυτόν χρησιμοποιώντας μια θέση.
Στη Ruby, οι θέσεις στους πίνακες ξεκινούν από το μηδέν, που σημαίνει ότι η θέση του πρώτου στοιχείου είναι πάντα μηδέν:

```ruby
# Declare an array containing two values
two_ints = [1,2]

# Assign first and second element by index
two_ints[0] = 7
two_ints[1] = 8

# Retrieve the second element by index
two_ints[1] # => 8

# Check the length of the array
two_ints.size # => 2
```

Στη Ruby υπάρχουν πολλοί τρόποι για να δημιουργήσεις έναν πίνακα:

- Χρησιμοποιώντας τον κυριολεκτικό κατασκευαστή `[]` _(πιο συνηθισμένος)_
- Καλώντας ρητά το `Array.new`
- Καλώντας τη μέθοδο `Array()` του Kernel

Η μέθοδος `Array.new` υποστηρίζει δύο προαιρετικά ορίσματα: το αρχικό μέγεθος του πίνακα και ένα προεπιλεγμένο αντικείμενο.

Όταν δίνονται ένα μέγεθος και ένα προεπιλεγμένο αντικείμενο, ο πίνακας γεμίζει με `size` αντίγραφα του προεπιλεγμένου αντικειμένου.

```ruby
a = Array.new(2, Hash.new)
# => [{}, {}]
```

Επειδή όλα τα στοιχεία του πίνακα αποθηκεύουν το ίδιο hash, οι αλλαγές σε ένα από αυτά θα επηρεάσουν όλα τα υπόλοιπα.

```ruby
a[0]['cat'] = 'feline'
a # => [{"cat"=>"feline"}, {"cat"=>"feline"}]

a[1]['cat'] = 'Felix'
a # => [{"cat"=>"Felix"}, {"cat"=>"Felix"}]
```

Αν θέλεις πολλαπλά αντίγραφα, θα πρέπει να χρησιμοποιήσεις την έκδοση με μπλοκ, η οποία χρησιμοποιεί το αποτέλεσμα αυτού του μπλοκ κάθε φορά που ένα στοιχείο του πίνακα χρειάζεται αρχικοποίηση:

```ruby
a = Array.new(2) {Hash.new}
a[0]['cat'] = 'feline'
a # => [{"cat"=>"feline"}, {}]
```

Ένα άλλο χαρακτηριστικό των πινάκων της Ruby είναι ότι ενσωματώνουν το άρθρωμα [Enumerable][enumerable-module], το οποίο προσθέτει πολλές βολικές μεθόδους για να επαναλαμβάνεις, να αναζητάς, να ταξινομείς, να φιλτράρεις κ.λπ. στοιχεία ενός πίνακα.
