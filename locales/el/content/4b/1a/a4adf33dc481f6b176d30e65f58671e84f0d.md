# Παράρτημα οδηγιών

## Προσθήκη μεθόδου στη δομή `Int`

Αυτή η άσκηση επικεντρώνεται στην προσθήκη μεθόδων στη δομή `Int` στην Crystal.
Για να το κάνεις αυτό, θα χρειαστεί να ορίσεις μια δομή με το όνομα `Int`.
Και να βάλεις τη μέθοδο μέσα σε αυτή τη δομή.

```crystal
struct Int
  # your solution here
end
```

Ο πηγαίος κώδικας για την κλάση `Int` μπορεί να βρεθεί [εδώ][int].
