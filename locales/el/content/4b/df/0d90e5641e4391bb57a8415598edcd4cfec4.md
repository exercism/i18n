# Οδηγίες

Η Elyse ανυπομονεί πραγματικά να παίξει λίγο πόκερ (και άλλα παιχνίδια με κάρτες) στο επερχόμενο ταξίδι της στο Λας Βέγκας.
 Ως μεγάλη λάτρης της "αυτοπαρακολούθησης" θέλει να φτιάξει μερικές μικρές συναρτήσεις που θα τη βοηθήσουν με εργασίες παρακολούθησης και ζήτησε τη βοήθειά σου για να τις σκεφτείτε μαζί.

## 1. Παρακολούθηση γύρων πόκερ

Η Elyse λατρεύει ιδιαίτερα το πόκερ και θέλει να παρακολουθεί πόσους γύρους παίζει, αλλά και _ποιοι_ είναι αυτοί οι γύροι.
 Κάθε γύρος έχει τον δικό του αριθμό και κάθε τραπέζι δείχνει τον αριθμό του γύρου που παίζεται αυτή τη στιγμή.
 Η Elyse διαλέγει ένα τραπέζι και κάθεται να παίξει τον πρώτο της γύρο. Σκοπεύει να παίξει τρεις γύρους.

Υλοποίησε μια συνάρτηση `rounds` που παίρνει τον αριθμό του τρέχοντος γύρου και επιστρέφει μία `list` με αυτόν τον γύρο και τους _επόμενους δύο_ που έρχονται:

```clojure
(rounds 27)
;;=> (27 28 29)
```

## 2. Κρατώντας όλους τους γύρους στο ίδιο σημείο

Η Elyse έπαιξε μερικούς γύρους στο πρώτο τραπέζι, μετά έκανε διάλειμμα και έπαιξε κι άλλους γύρους σε ένα δεύτερο τραπέζι ... αλλά κατέληξε με διαφορετική λίστα για κάθε τραπέζι!
 Θέλει να βάλει τις δύο λίστες μαζί, ώστε να μπορεί να παρακολουθεί όλους τους γύρους πόκερ στο ίδιο σημείο.

Υλοποίησε μια συνάρτηση `concat-rounds` που παίρνει δύο λίστες και επιστρέφει μία `list` που αποτελείται από όλους τους γύρους της πρώτης `list`, ακολουθούμενους από όλους τους γύρους της δεύτερης `list`:

```clojure
(concat-rounds '(27 28 29) '(35 36))
;;=> (27 28 29 35 36)
```

## 3. Βρίσκοντας προηγούμενους γύρους

Μιλώντας για μερικούς από τους προηγούμενους γύρους πόκερ, ένας άλλος παίκτης σχολιάζει πόσο παρόμοια εξελίχθηκαν δύο από αυτούς.
 Η Elyse δεν είναι σίγουρη αν έπαιξε αυτούς τους γύρους ή όχι.

Υλοποίησε μια συνάρτηση `contains-round?` που παίρνει δύο ορίσματα, μια λίστα με τους γύρους που παίχτηκαν και έναν αριθμό γύρου.
 Η συνάρτηση θα επιστρέψει `true` αν ο γύρος υπάρχει στη λίστα με τους γύρους που παίχτηκαν, `false` αν όχι:

```clojure
(contains-round? '(27 28 29 35 36) 29)
;;=> true

(contains-round? '(27 28 29 35 36) 30)
;;=> false
```

## 4. Μέσος όρος τιμών καρτών

Η Elyse θέλει να δοκιμάσει ένα νέο παιχνίδι που λέγεται Black Joe.
 Είναι παρόμοιο με το Black Jack, όπου ο στόχος σου είναι οι κάρτες στο χέρι σου να αθροίζουν σε μια τιμή-στόχο, αλλά στο Black Joe ο στόχος είναι ο _μέσος όρος_ των τιμών των καρτών να είναι 7.
 Τον μέσο όρο μπορείς να τον βρεις αθροίζοντας όλες τις τιμές των καρτών και μετά διαιρώντας αυτό το άθροισμα με τον αριθμό των καρτών στο χέρι.

Υλοποίησε μια συνάρτηση `card-average` που θα επιστρέφει τη μέση τιμή ενός χεριού στο Black Joe.

```clojure
(card-average '(5 6 7))
;;=> 6.0
```

## 5. Εναλλακτικοί μέσοι όροι

Στο Black Joe, η ταχύτητα είναι σημαντική. Η Elyse θα προσπαθήσει να βρει έναν πιο γρήγορο τρόπο να υπολογίζει τον μέσο όρο.

Έχει σκεφτεί δύο τρόπους για να βρει έναν αριθμό _σαν μέσο όρο_:

- Πάρε τον μέσο όρο του _πρώτου_ και του _τελευταίου_ αριθμού στο χέρι.
- Χρησιμοποιώντας τη διάμεσο (τη μεσαία κάρτα) του χεριού.

Υλοποίησε τη συνάρτηση `approx-average?`, δεδομένης της `hand`, μιας λίστας που περιέχει τις τιμές των καρτών στο χέρι σου.

Επίστρεψε `true` αν _μία_ `or` _και οι δύο_ από τις παραπάνω στρατηγικές δίνουν έναν αριθμό _ίσο_ με τον _πραγματικό μέσο όρο_.

Σημείωση: _Το μήκος όλων των χεριών είναι περιττό, για να είναι πιο εύκολη η εύρεση της διαμέσου._

```clojure
(approx-average? '(1 2 3))
;;=> true

(approx-average? '(2 3 4 8 8))
;;=> true

(approx-average? '(1 2 3 5 9))
;;=> false
```

## 6. Περισσότερες τεχνικές υπολογισμού μέσου όρου

Η Elyse, έχοντας κεντριστεί από τα αποτελέσματα του πειράματός της με τους μέσους όρους, αναρωτιέται αν ο μέσος όρος των καρτών στις _ζυγές_ θέσεις εναντίον του μέσου όρου των καρτών στις _περιττές_ θέσεις θα έδινε τα ίδια αποτελέσματα.
 Ώρα για άλλη μια συνάρτηση δοκιμής!

Υλοποίησε μια συνάρτηση `average-even-odd?` που επιστρέφει ένα Boolean (λογική τιμή) που δείχνει αν ο μέσος όρος των καρτών στις ζυγές θέσεις είναι ίδιος με τον μέσο όρο των καρτών στις περιττές θέσεις.

```clojure
(average-even-odd? '(1 2 3))
;;=> true

(average-even-odd? '(1 2 3 4))
;;=> false
```

## 7. Κανόνες του γύρου μπόνους

Κάθε 11ο χέρι στο Black Joe είναι ένα χέρι μπόνους με κανόνα μπόνους: αν η τελευταία κάρτα που τραβάς είναι Βαλές, διπλασιάζεις την αξία της.

Υλοποίησε μια συνάρτηση `maybe-double-last` που παίρνει ένα χέρι και ελέγχει αν η τελευταία κάρτα είναι Βαλές (11).
 Αν η τελευταία κάρτα **είναι** Βαλές (11), διπλασίασε την αξία της πριν επιστρέψεις το χέρι.

```clojure
(maybe-double-last '(5 9 11))
;;=> '(5 9 22)

(maybe-double-last '(5 9 10))
;;=> '(5 9 10)
```
