# Παράμετροι μεταβλητού αριθμού

Οι [_παράμετροι μεταβλητού αριθμού_][variadic-parameters] στη Swift επιτρέπουν να περαστούν μηδέν ή περισσότερες τιμές ίδιου τύπου σε μία μόνο παράμετρο μιας συνάρτησης.
Αυτό υποδεικνύεται με την προσθήκη `...` στην επισημείωση τύπου της παραμέτρου.

Αυτές οι τιμές θα ομαδοποιηθούν αυτόματα σε έναν πίνακα με στοιχεία ίδιου τύπου με τον τύπο της παραμέτρου μεταβλητού αριθμού.

```swift
func geometricMean(_ numbers: Double...) -> Double {
  var total = 1.0
  for number in numbers {
      total *= number
  }
  return pow(total, 1.0 / Double(numbers.count))
}

geometricMean(1, 2, 3, 4, 5)
// Returns 2.605171084697352
```

Όταν χρησιμοποιείς παραμέτρους μεταβλητού αριθμού, η Swift έχει δύο περιορισμούς:

1. Η Swift επιτρέπει στις συναρτήσεις να έχουν μόνο μία παράμετρο μεταβλητού αριθμού. Έχει αποφασιστεί ότι αυτός ο περιορισμός θα αρθεί σε μια μελλοντική έκδοση της Swift, αλλά προς το παρόν εξακολουθεί να ισχύει.
2. Αν μια συνάρτηση έχει παραμέτρους που ακολουθούν την παράμετρο μεταβλητού αριθμού στον ορισμό, η πρώτη παράμετρος που ακολουθεί την παράμετρο μεταβλητού αριθμού _απαιτείται_ να έχει ετικέτα ορίσματος.

[variadic-parameters]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/functions/#Variadic-Parameters
