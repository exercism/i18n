# Σχετικά

Η PHP παρέχει έναν αριθμό τελεστών για την εκτέλεση αριθμητικών πράξεων. Η PHP ακολουθεί την καθιερωμένη μαθηματική σειρά εκτέλεσης των πράξεων για τους αριθμητικούς τελεστές της. Οι τελεστές που παρέχει η PHP είναι:

* Ταυτότητα (+)
* Άρνηση (-)
* Πρόσθεση (+)
* Αφαίρεση (-)
* Πολλαπλασιασμός (*)
* Διαίρεση (/)
* Υπόλοιπο (%)
* Ύψωση σε δύναμη (**)

Ας δούμε τον καθένα ξεχωριστά και πώς μπορούν να χρησιμοποιηθούν:

## Ταυτότητα (+)

Ο τελεστής ταυτότητας (+) δρα σε μία μόνο τιμή (μοναδιαίος τελεστής). Θα έχει ως αποτέλεσμα την τιμή `float` ή `int` της μεταβλητής.

```php
$value = '42';
$answer = +$value; // 42 (int)
```

## Άρνηση (-)

Ο τελεστής άρνησης δρα σε μία μόνο τιμή (μοναδιαίος τελεστής) και επιστρέφει το αντίθετο της αριθμητικής τιμής.

```php
$forward = 65;
$reverse = -$forward; // -65
```

## Πρόσθεση (+) και Αφαίρεση (-)

Ο τελεστής πρόσθεσης προσθέτει τις δύο τιμές στις δύο πλευρές του, ενώ ο τελεστής αφαίρεσης αφαιρεί τη δεξιά τιμή από την αριστερή.

```php
$apples = 5;
$yourApples = 0;

$apples = $apples - 2; // 3
$yourApples = $yourApples + 2; 2
```

## Διαίρεση (/)

Ο τελεστής διαίρεσης δίνει το αποτέλεσμα της διαίρεσης της αριστερής τιμής με τη δεξιά τιμή. Αν η δεξιά τιμή είναι 0, θα προκαλέσει σφάλμα `DivisionByZeroError`.

```php
$slicesOfPizza = 8;
$people = 4;
$slicesPerPerson = $slicesOfPizza / $people; // 2
```

## Πολλαπλασιασμός (*)

Ο τελεστής πολλαπλασιασμού επιστρέφει το αποτέλεσμα του πολλαπλασιασμού της αριστερής και της δεξιάς τιμής μεταξύ τους.

```php
$tires = 4;
$priceOfTire = 250;
$totalCost = $tires * $priceOfTire; // 1000
```

## Υπόλοιπο (%)

Ο τελεστής υπολοίπου επιστρέφει το υπόλοιπο της διαίρεσης της αριστερής τιμής με τη δεξιά τιμή. Αυτός ο τελεστής είναι πολύ χρήσιμος για να διαπιστώσεις αν ένας αριθμός διαιρείται ακριβώς με έναν άλλο, αν μια τιμή είναι άρτια ή περιττή και για πολλά ακόμη.

```php
$value = 3;
$isOdd = $value % 2;
if ($isOdd === 1) {
    echo 'Yes, it is odd!';
} else {
    echo 'It is even.';
}
```

## Ύψωση σε δύναμη (**)

Ο τελεστής ύψωσης σε δύναμη χρησιμοποιείται για να υψώσει την αριστερή τιμή στη δύναμη της δεξιάς τιμής. Πριν από την PHP 5.6, θα έπρεπε να χρησιμοποιήσεις τη συνάρτηση `pow` για να κάνεις το ίδιο πράγμα.

```php
$sideLength = 13;
$areaOfSquare = $sideLength ** 2; // 169
```

Ο τελεστής ύψωσης σε δύναμη υποστηρίζει ακέραιους και δεκαδικούς και στις δύο πλευρές, οπότε μπορείς να τον χρησιμοποιήσεις για να υπολογίσεις τετραγωνικές ρίζες (ή άλλες ρίζες) ή πιο σύνθετες εκθετικές τιμές.

```php
$squareArea = 144;
$side = $squareArea ** .5; // 12
```

## Σειρά εκτέλεσης των πράξεων

Η PHP ακολουθεί την καθιερωμένη σειρά εκτέλεσης των πράξεων στα μαθηματικά. Αυτό σημαίνει ότι αντί να εκτελούνται οι πράξεις από αριστερά προς τα δεξιά, κάθε τελεστής έχει προτεραιότητα και οι πράξεις εκτελούνται σύμφωνα με την προτεραιότητά τους. Η σειρά εκτέλεσης των πράξεων είναι:

* παρενθέσεις
* ύψωση σε δύναμη
* πολλαπλασιασμός, διαίρεση
* πρόσθεση, αφαίρεση

Ο πολλαπλασιασμός και η διαίρεση έχουν την ίδια προτεραιότητα μεταξύ τους. Παρομοίως, η πρόσθεση και η αφαίρεση έχουν την ίδια προτεραιότητα.

Αυτό σημαίνει ότι η παρακάτω τιμή θα ήταν 17 και όχι 10, αφού ο πολλαπλασιασμός έχει μεγαλύτερη προτεραιότητα από την πρόσθεση:

```php
$value = 2 + 3 * 5;
```

Η PHP παρέχει επίσης έναν αριθμό χρήσιμων τελεστών ανάθεσης που συνδυάζουν αριθμητικούς τελεστές με ανάθεση, όταν εκτελείς μια πράξη σε μια μεταβλητή και αναθέτεις το αποτέλεσμα πίσω στην ίδια. Αυτοί θα καλυφθούν στην έννοια `Assignment Operators`.
