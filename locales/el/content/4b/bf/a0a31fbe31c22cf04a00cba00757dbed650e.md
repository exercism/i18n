# Προσθήκη στις οδηγίες

## Υλοποίηση

Υλοποίησε τις μεθόδους `waterDrinker` και `zebraOwner` της κλάσης `ZebraPuzzle`.
Κάθε μία από αυτές πρέπει να επιστρέφει μια συμβολοσειρά, της οποίας η τιμή είναι η απάντηση στις ερωτήσεις του γρίφου της ζέβρας "Ποιος πίνει νερό;" και "Ποιος έχει τη ζέβρα;".
Κάθε απάντηση θα είναι μία από τις εθνικότητες των κατοίκων: Englishman, Spaniard, Ukrainian, Norwegian ή Japanese.

Προφανώς, θα μπορούσες απλώς να γράψεις δύο συναρτήσεις με μία μόνο εντολή, αν ρίξεις μια ματιά στα tests για να δεις την αναμενόμενη λύση.
Όμως ο στόχος είναι να αναπτύξεις έναν αλγόριθμο που χρησιμοποιεί τα δεδομένα και τους περιορισμούς που δίνονται για τον γρίφο και προσδιορίζει τις δύο σωστές απαντήσεις.
