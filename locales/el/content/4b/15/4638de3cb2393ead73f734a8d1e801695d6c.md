# Σχετικά με τη μετατροπή τύπων

Η Go απαιτεί ρητή μετατροπή ανάμεσα σε διαφορετικούς τύπους.
Για παράδειγμα, αυτό προκαλεί σφάλμα μεταγλωττιστή:

```go
var x int = 42
var f float64 = x // compiler error x is an int not a float64
```

Η μετατροπή μεταξύ τύπων (γνωστή και ως **type casting**) γίνεται μέσω μιας συνάρτησης με το όνομα του τύπου στον οποίο θέλεις να μετατρέψεις.
Μια τιμή `v` μετατρέπεται στον τύπο `T` χρησιμοποιώντας το `T(v)`.
Για παράδειγμα, για να μετατρέψεις ένα `int` σε `float64` θα χρειαστεί να κάνεις το εξής:

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
```

Το ίδιο ισχύει για κάθε προσαρμοσμένο τύπο:

```go
type Id int
var number int = 121 // number has type int
userId := Id(number) // userId now has type Id
```

## Μετατροπή μεταξύ πρωτόγονων τύπων και συμβολοσειρών

Υπάρχει το πακέτο `strconv` για τη μετατροπή ανάμεσα σε πρωτόγονους τύπους (όπως ο `int`) και σε `string`.

```go
import "strconv"

var intString string = "42"
var i, err = strconv.Atoi(intString)

var number int = 12
var s string = strconv.Itoa(number)
```

ΠΡΟΣΟΧΗ: η χρήση της τυπικής μεθόδου μετατροπής δεν συμπεριφέρεται έτσι.
Για παράδειγμα:

```go
var num int = 65
str := string(num) // str is now "A" not "65"
```

Ορίστε μερικές από τις άλλες συνηθισμένες μεθόδους μετατροπής:

| Μέθοδος    | Σκοπός                      |
| ----------- | --------------------------- |
| ParseBool   | Μετατροπή `string` σε `bool`  |
| FormatBool  | Μετατροπή `bool` σε `string`  |
| ParseFloat  | Μετατροπή `string` σε `float` |
| FormatFloat | Μετατροπή `float` σε `string` |
| ParseInt    | Μετατροπή `string` σε `int`   |
| FormatInt   | Μετατροπή `int` σε `string`   |
