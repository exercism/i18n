# Σχετικά

Ένας `generator` είναι μια συνάρτηση ή έκφραση που επιστρέφει έναν ειδικό τύπο [iterator][iterator] που ονομάζεται [generator iterator][generator-iterator].
Οι `Generator-iterators` είναι [οκνηροί][lazy iterator]: δεν αποθηκεύουν τις `values` τους στη μνήμη, αλλά _παράγουν_ τις τιμές τους όταν χρειάζεται.

Μια συνάρτηση generator μοιάζει με οποιαδήποτε άλλη συνάρτηση, αλλά περιέχει μία ή περισσότερες [εκφράσεις yield][yield expression].
Κάθε `yield` αναστέλλει την εκτέλεση του κώδικα, αποθηκεύοντας την τρέχουσα κατάσταση εκτέλεσης (_συμπεριλαμβανομένων όλων των τοπικών μεταβλητών και των εντολών try_).
Όταν ο generator συνεχίσει, ανακτά την κατάσταση από το σημείο της αναστολής, σε αντίθεση με τις κανονικές συναρτήσεις που επαναφέρονται σε κάθε κλήση.


## Κατασκευή ενός generator

Οι generators κατασκευάζονται σχεδόν όπως άλλες συναρτήσεις με βρόχους ή αναδρομικές συναρτήσεις, αλλά απαιτούν μια [έκφραση `yield`](#the-yield-expression), την οποία θα εξετάσουμε σε βάθος λίγο αργότερα.

Ένα παράδειγμα είναι μια συνάρτηση που επιστρέφει τα _τετράγωνα_ των αριθμών από μια δοσμένη λίστα.  
Όπως είναι γραμμένη τώρα, όλα τα δεδομένα εισόδου πρέπει να υποστούν επεξεργασία πριν επιστραφεί οποιαδήποτε τιμή:

```python
>>> def squares(list_of_numbers):
...     squares = []
...     for number in list_of_numbers:
...         squares.append(number ** 2)
...     return squares
```

Μπορείς να μετατρέψεις αυτή τη συνάρτηση σε generator ως εξής:

```python
>>> def squares_generator(list_of_numbers):
...     for number in list_of_numbers:
...         yield number ** 2
```

Το σκεπτικό πίσω από αυτό είναι ότι χρησιμοποιείς έναν generator όταν δεν χρειάζεσαι όλες τις τιμές _ταυτόχρονα_.

Αυτό εξοικονομεί μνήμη και υπολογιστική ισχύ, αφού υπολογίζεται μόνο η τιμή με την οποία _δουλεύεις αυτή τη στιγμή_.


## Χρήση ενός generator

Οι generators (_τεχνικά [`generator-iterator`s][generator-iterator], δες το σημείωμα παρακάτω._) είναι ένα είδος `iterator` και μπορούν να χρησιμοποιηθούν οπουδήποτε στην Python περιμένει κάποιος έναν `iterator` ή ένα `iterable`.
Αυτό περιλαμβάνει _συναρτήσεις_ ή _αντικείμενα_ που απαιτούν ένα `iterable`/`iterator` ως όρισμα.
Για μια πιο βαθιά ματιά, δες το [How to Make an Iterator in Python][how-to-iterator].


~~~~exercism/note

Οι generator-iterators είναι ένα ειδικό υποσύνολο των [iterators][iterator].
Οι `Iterators` είναι ο μηχανισμός/πρωτόκολλο που επιτρέπει την επανάληψη πάνω σε _iterables_.
Οι generator-iterators και οι iterators που επιστρέφουν τα συνηθισμένα [`iterables`][iterables] της Python συμπεριφέρονται πολύ παρόμοια, αλλά υπάρχουν μερικές σημαντικές διαφορές που αξίζει να σημειώσεις:

- Είναι _[οκνηρά αξιολογημένοι][lazy evaluation]_: η επανάληψη είναι _μονόδρομη_ και δεν υπάρχει "επιστροφή" σε μια προηγούμενη τιμή.
- _Καταναλώνονται_ με την επανάληψη πάνω στις τιμές που επιστρέφονται: δεν γίνεται επαναφορά ούτε αποθήκευση στη μνήμη.
- Δεν ταξινομούνται και δεν μπορούν να αντιστραφούν.
- Δεν είναι τύποι ακολουθίας και _δεν_ έχουν `indexes`. 
  Δεν μπορείς να αναφερθείς σε μια προηγούμενη ή μελλοντική τιμή με πρόσθεση ή αφαίρεση και δεν μπορείς να χρησιμοποιήσεις συμβολισμό με αγκύλη (`[]`) ή τεμαχισμό.
- Δεν μπορούν να χρησιμοποιηθούν με τη συνάρτηση `len()`, αφού δεν έχουν μήκος.
- Μπορούν να είναι _πεπερασμένοι_ ή _άπειροι_. Πρόσεχε όταν συλλέγεις όλες τις τιμές από έναν _άπειρο_ `generator-iterator`!

[iterator]: https://docs.python.org/3.11/glossary.html#term-iterator
[iterables]: https://wiki.python.org/moin/Iterator
[lazy evaluation]: https://en.wikipedia.org/wiki/Lazy_evaluation
~~~~


Για να χρησιμοποιήσεις τον generator `squares_generator()`:

```python
>>> squared_numbers = squares_generator([1, 2, 3, 4])

>>> for square in squared_numbers:
...     print(square)
...
1
4
9
16
```

Οι τιμές μέσα σε έναν generator μπορούν επίσης να παραχθούν/προσπελαστούν μέσω της συνάρτησης `next()`.
Η `next()` καλεί τη μέθοδο `__next__()` ενός αντικειμένου generator, "προωθώντας" ή αξιολογώντας τον κώδικα του generator μέχρι την έκφραση `yield`, η οποία τότε "δίνει" ή επιστρέφει την τιμή.

```python
>>> squared_numbers = squares_generator([1, 2])

>>> next(squared_numbers)
1
>>> next(squared_numbers)
4
```

Όταν ένας `generator` καταναλωθεί πλήρως και δεν έχει άλλες τιμές να επιστρέψει, πετάει ένα σφάλμα `StopIteration`.

```python
>>> next(squared_numbers)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
StopIteration
```

### Διαφορά μεταξύ iterables και generators

Οι generators είναι ένα ειδικό υποσύνολο των _iterators_.
Οι `Iterators` είναι ο μηχανισμός/πρωτόκολλο που επιτρέπει την επανάληψη πάνω σε _iterables_.
Οι generators και οι iterators που επιστρέφουν τα συνηθισμένα [`iterables`][iterables] της Python συμπεριφέρονται πολύ παρόμοια, αλλά υπάρχουν μερικές σημαντικές διαφορές που αξίζει να σημειώσεις:

- Οι generators είναι _μονόδρομοι_: δεν υπάρχει "επιστροφή" σε μια προηγούμενη τιμή.

- Η επανάληψη πάνω σε generators καταναλώνει τις τιμές που επιστρέφονται: δεν γίνεται επαναφορά.

- Οι generators (_καθώς αξιολογούνται οκνηρά_) δεν ταξινομούνται και δεν μπορούν να αντιστραφούν.

- Οι generators _δεν_ έχουν `indexes`, οπότε δεν μπορείς να αναφερθείς σε μια προηγούμενη ή μελλοντική τιμή με πρόσθεση ή αφαίρεση.

- Οι generators δεν μπορούν να χρησιμοποιηθούν με τη συνάρτηση `len()`.

- Οι generators μπορούν να είναι _πεπερασμένοι_ ή _άπειροι_. Πρόσεχε όταν συλλέγεις όλες τις τιμές από έναν _άπειρο_ generator.

## Η έκφραση `yield`

Η [έκφραση yield][yield expression] μοιάζει πολύ με την έκφραση `return`.

_Σε αντίθεση_ με την έκφραση `return`, το `yield` παραδίδει τιμές σε αυτόν που το καλεί σε ένα _συγκεκριμένο σημείο_, αναστέλλοντας την αξιολόγηση/επιστροφή οποιωνδήποτε επιπλέον τιμών μέχρι να ζητηθούν.

Όταν αξιολογείται το `yield`, παύει η εκτέλεση της συνάρτησης που το περικλείει και επιστρέφονται οι τιμές της συνάρτησης _εκείνη τη στιγμή_.

Η συνάρτηση τότε _παραμένει σε εμβέλεια_ και, όταν κληθεί η `__next__()`, η εκτέλεση συνεχίζεται μέχρι να συναντήσει ξανά το `yield`.

~~~~exercism/note
Η χρήση εκφράσεων `yield` απαγορεύεται έξω από συναρτήσεις.
~~~~

```python
>>> def infinite_sequence():
...     current_number = 0
...     while True:
...         yield current_number
...         current_number += 1

>>> lets_try = infinite_sequence()
>>> lets_try.__next__()
0
>>> lets_try.__next__()
1
```

## Γιατί generators;

Οι generators είναι χρήσιμοι σε πολλές εφαρμογές.

Όταν δουλεύεις με μια μεγάλη συλλογή, μπορεί να μη θέλεις να βάλεις όλες τις τιμές της στη `memory`.
Ένας generator μπορεί να χρησιμοποιηθεί για να δουλέψεις με μεγαλύτερα δεδομένα κομμάτι-κομμάτι, εξοικονομώντας μνήμη και βελτιώνοντας την απόδοση.

Οι generators είναι επίσης πολύ χρήσιμοι όταν μια διαδικασία ή ένας υπολογισμός είναι _πολύπλοκος_, _δαπανηρός_ ή _άπειρος_:

```python
>>> def infinite_sequence():
...     current_number = 0
...     while True:
...         yield current_number
...         current_number += 1
```

Τώρα, κάθε φορά που καλείται η `__next__()` στο αντικείμενο `infinite_sequence`, θα επιστρέφει τον _προηγούμενο αριθμό_ + 1.
