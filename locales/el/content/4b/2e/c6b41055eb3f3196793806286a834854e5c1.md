# Παύση των συνεισφορών της κοινότητας

Μερικά αποθετήρια δεν έχουν τους πόρους να διαχειρίζονται ή να εξετάζουν issues ή pull requests από χρήστες που δεν είναι maintainers.
Η παύση των λύσεων της κοινότητας
Αν ένα αποθετήριο έχει ενεργοποιήσει αυτό το workflow, θα σχολιάζει αυτόματα σε ένα νέο issue ή pull request αν ο συντάκτης _δεν_ είναι μέλος του οργανισμού του Exercism στο GitHub.
Το σχόλιο θα προτείνει στον χρήστη να ανοίξει πρώτα ένα θέμα στο φόρουμ του Exercism.

## Ενεργοποίηση του workflow

Πρόσθεσε το [αρχείο .github/workflows/pause-community-contributions.yml](https://github.com/exercism/github-actions/blob/b5424c17f661f5529493258a1ad480013351aa9e/.github/workflows/pause-community-contributions.yml) στο αποθετήριό σου.

## Απενεργοποίηση του workflow

Αφαίρεσε το αρχείο workflow από το αποθετήριό σου.

## Πηγή

Το workflow ορίζεται στο αρχείο `.github/workflows/pause-community-contributions.yml`.
