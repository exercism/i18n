# Οδηγίες

Θα αρχικοποιήσεις κενούς buffer και θα απαριθμήσεις τα πρώτα πέντε νούμερα, ή στοιχεία, της ακολουθίας Fibonacci.

Η ακολουθία Fibonacci είναι ένα σύνολο αριθμών όπου το επόμενο στοιχείο είναι το άθροισμα των δύο προηγούμενων. Ξεκινάμε την ακολουθία από το ένα. Έτσι, τα δύο πρώτα στοιχεία είναι το 1 και το 1.

## 1. Δημιούργησε έναν buffer από `count` μηδενικά.

Δημιούργησε μια συνάρτηση που δημιουργεί έναν buffer από `count` μηδενικά.

```rust
let my_buffer = create_buffer(5);
// [0, 0, 0, 0, 0]
```

## 2. Απαρίθμησε τα πρώτα πέντε στοιχεία της ακολουθίας Fibonacci

Δημιούργησε μια συνάρτηση που επιστρέφει τα πρώτα πέντε νούμερα της ακολουθίας Fibonacci.
Τα πρώτα πέντε στοιχεία της είναι `1, 1, 2, 3, 5`

```rust
let first_five = fibonacci();
// [1, 1, 2, 3, 5]
```
