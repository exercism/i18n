# Εισαγωγή

## Αληθής και ψευδής

Οι λογικές καταστάσεις αληθής και ψευδής αναπαρίστανται με `true` και `false` στη Ruby.

```ruby
happy = true
sad = false
```

## Ισότητα και σύγκριση

Η Ruby σου επιτρέπει να συγκρίνεις αντικείμενα μεταξύ τους με τα συνηθισμένα σύμβολα ισότητας:
- Χρησιμοποίησε το `==` για να δεις αν δύο αντικείμενα είναι ίσα
- Χρησιμοποίησε το `>` για να δεις αν το αντικείμενο στα αριστερά είναι **μεγαλύτερο από** το αντικείμενο στα δεξιά
- Χρησιμοποίησε το `<` για να δεις αν το αντικείμενο στα αριστερά είναι **μικρότερο από** το αντικείμενο στα δεξιά.
- Χρησιμοποίησε το `>=` ή το `<=` για να ελέγξεις το "μεγαλύτερο ή ίσο με" και το "μικρότερο ή ίσο με" αντίστοιχα.

Μπορείς επίσης να χρησιμοποιήσεις λογική Boolean με τους συνηθισμένους τελεστές:
- Χρησιμοποίησε το `&&` ή το `and` για να ελέγξεις αν το `x and y` είναι αληθές
- Χρησιμοποίησε το `||` ή το `or` για να ελέγξεις αν το `x or y` είναι αληθές.
- Χρησιμοποίησε το `!` ή το `not` για να αντιστρέψεις την ισότητα, π.χ. `x != y` (το x δεν είναι ίσο με το y)

Ορίστε μερικά παραδείγματα:
```ruby
# Is "true equal to false"? 
true == false # false

# Is "true not equal to false"
true != false # true

# Is 5 greater than 4?
5 > 4 # true

# Is 3 less than or equal to 2?
3 <= 2 # false
```
