# Δοκιμές

Μπορείς να εκτελέσεις τις σουίτες δοκιμών των ασκήσεων PureScript από τον κατάλογο της άσκησης χρησιμοποιώντας το εργαλείο spago:

    cd <exercism-workspace>/purescript/<exercise name>
    spago test

όπου το <exercism-workspace> είναι ο κατάλογος χώρου εργασίας της γραμμής εντολών.

Για παράδειγμα:

    cd ~/exercism/purescript/accumulate
    spago test
