# Τεστ

Κάθε άσκηση παρέχει τα τεστ μονάδας και μια συνταγή build για το Make.
Την υλοποίηση την παρέχεις εσύ.

Κάθε αρχείο τεστ προορίζεται να συνδεθεί με την υλοποίησή σου, ώστε να προκύψει ένα εκτελέσιμο κονσόλας που τρέχει τα τεστ.
Όταν τρέχεις το εκτελέσιμο των τεστ, εκτυπώνονται μηνύματα για κάθε αποτυχημένο τεστ και, όταν τα τεστ αποτυγχάνουν, αναφέρεται μη μηδενική κατάσταση εξόδου.

Για να δουλέψεις πάνω σε μια άσκηση:
* Δημιούργησε το αρχικό build με το Make
* Για κάθε τεστ μονάδας:
  * Αφαίρεσε τη γραμμή `TEST_IGNORE()`.
  * Διόρθωσε τυχόν σφάλματα μεταγλώττισης ώστε να αποτύχει το τεστ.
  * Υλοποίησε τόσο μόνο όσο χρειάζεται για να περάσει το τεστ.
  * Αναδιαμόρφωσε την υλοποίησή σου για να βελτιώσεις την αναγνωσιμότητα, να μειώσεις τον διπλότυπο κώδικα κ.λπ.
