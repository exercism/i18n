# Επαναλήπτες

Το να διατρέξεις έναν πίνακα με έναν μετρητή απαιτεί τέσσερις γραμμές βοηθητικών χειρισμών πριν γίνει οποιαδήποτε δουλειά:

```sather
   i ::= 0;
   loop
      until!(i >= counts.size);
      total := total + counts[i];
      i := i + 1;
   end;
```

Ο μετρητής, ο έλεγχος τερματισμού και το βήμα δεν έχουν καμία σχέση με την πρόσθεση αριθμών. Ένας **επαναλήπτης** κάνει και τα τρία.

```sather
   loop
      total := total + counts.elt!;
   end;
```

Το `elt!` δίνει από ένα στοιχείο σε κάθε γύρο και τερματίζει τον βρόχο όταν δεν υπάρχουν άλλα. Χωρίς μετρητή, χωρίς τίποτα που μπορεί να πάει στραβά και χωρίς τρόπο να ξεπεράσεις τα όρια του πίνακα.

## Το θαυμαστικό

Το `!` σηματοδοτεί έναν επαναλήπτη. Έχεις συναντήσει ήδη τρεις, τους `until!`, `while!` και `break!`, και ακολουθούν τον ίδιο κανόνα: **ένας επαναλήπτης μπορεί να κληθεί μόνο μέσα σε έναν βρόχο.** Το να γράψεις `counts.elt!` έξω από έναν βρόχο είναι σφάλμα.

Κάθε φορά που ένας επαναλήπτης καλείται μέσα σε έναν βρόχο, του ζητείται μια τιμή. Όταν δεν του έχει απομείνει καμία, ο βρόχος τερματίζεται αμέσως, όπου κι αν τυχαίνει να βρίσκεται η κλήση μέσα στο σώμα του.

## Δύο για αρχή

Το `elt!` δίνει τα στοιχεία ενός πίνακα ή μιας συμβολοσειράς, με τη σειρά.

```sather
   loop
      #OUT + names.elt! + "\n";
   end;
```

Το `upto!` μετράει. Το `1.upto!(5)` δίνει 1, 2, 3, 4, 5 και μετά τερματίζει τον βρόχο.

```sather
   loop
      total := total + 1.upto!(5);
   end;
```

Και τα δύο είναι συνηθισμένες ρουτίνες που τυχαίνει να τελειώνουν σε `!`, οπότε καλούνται και τα δύο με τελεία, πάνω σε έναν πίνακα ή σε έναν αριθμό.

## Κρατώντας το αποτέλεσμα

Ο βρόχος τερματίζεται μόνος του, οπότε ό,τι υπολογίζεται μέσα του πρέπει να φυλάσσεται σε μια μεταβλητή που δηλώνεται **έξω** από αυτόν, αλλιώς χάνεται μαζί με τον βρόχο.

```sather
   total ::= 0;             -- outside
   loop
      total := total + counts.elt!;
   end;
   return total;
```
