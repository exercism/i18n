# Debug

Όταν ένα test αποτύχει, εμφανίζεται ένα μήνυμα που περιγράφει τι πήγε στραβά.
Αν θέλεις επιπλέον έξοδο, μπορείς να χρησιμοποιήσεις την υπορουτίνα `::YYY()` γύρω από τον κώδικα που θέλεις να εξετάσεις.
(Το `::` είναι συντόμευση για το `main::`).
Αυτή η υπορουτίνα είναι μέρος της ενότητας [XXX][XXX].

Μπορείς επίσης να εκτυπώσεις απλώς ένα μήνυμα χρησιμοποιώντας τη συνάρτηση `say`, π.χ. `say 'Hello, World!';`.

Ο διαδικτυακός test runner χρησιμοποιεί το [Test Anything Protocol][TAP].
Λόγω της φύσης του TAP, η χρήση του `print` στον διαδικτυακό test runner αποθαρρύνεται έντονα.
