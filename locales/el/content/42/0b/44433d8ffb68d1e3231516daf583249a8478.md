# Σχετικά

Τα literals είναι σταθερές τιμές που χρησιμοποιούνται απευθείας στον κώδικα.
Δεν χρειάζονται κανέναν υπολογισμό κατά τον χρόνο εκτέλεσης.
Υπάρχουν σε διάφορες μορφές, ώστε να αναπαριστούν αποτελεσματικά διαφορετικούς τύπους δεδομένων.
Τα πιο συχνά literals είναι αριθμητικά, αλλά υπάρχουν και τελεστές literals για τύπους ημερομηνίας, ώρας και συμβολοσειράς.
Μια επόμενη έννοια θα δείξει πώς μπορούν να χρησιμοποιηθούν τελεστές literals που ορίζει ο χρήστης.

## Αριθμητικά literals

Τα αριθμητικά literals περιλαμβάνουν δεκαδικές, οκταδικές, δεκαεξαδικές και δυαδικές αναπαραστάσεις.
Αυτά τα βασικά έχουν ήδη καλυφθεί στην [έννοια numbers][numbers-concept].

Όλες οι αναπαραστάσεις όπως `23`, `0x50f7ba11` και `0xba5eba11` γίνονται κατανοητές ως `int` από τον μεταγλωττιστή.
Ο γενικός τύπος `int` είναι προσημασμένος και ([ανάλογα με τον μεταγλωττιστή και το σύστημα][in-depth-integers]) έχει συχνά εύρος από `-2'147'483'648` έως `2'147'483'647`.
Αυτό επαρκεί τις περισσότερες φορές και δεν χρειάζεται να ανησυχείς για τον συγκεκριμένο τύπο.

Κάποιες περιπτώσεις χρήσης απαιτούν μεγαλύτερα εύρη ή πολύ μικρό αποτύπωμα μνήμης για τα προγράμματα.
Για να είσαι σαφής, μπορείς να δηλώσεις απευθείας συγκεκριμένους ακέραιους τύπους με το αριθμητικό literal.

Όταν δεν χρειάζεσαι αρνητικούς αριθμούς, αλλά θέλεις το επιπλέον εύρος, χρησιμοποιείς το επίθημα `u` ή `U` για ακεραίους _χωρίς πρόσημο_.
Για ακόμη μεγαλύτερα εύρη, μπορείς να χρησιμοποιήσεις το `L` ή ακόμα και το `LL` για τύπους long και long long.

~~~~exercism/caution
Η χρήση του πεζού `l` επιτρέπεται, αλλά συγχέεται εύκολα με τον αριθμό `1` και γι’ αυτό αποθαρρύνεται.
~~~~

```cpp
auto net_worth_christian_grey{2'500'000'000U}; // out of range for 32-bit integers
auto net_worth_carlisle_cullen{46'000'000'000LL}; // int and uint are not enough
```

Οι αριθμοί κινητής υποδιαστολής συνήθως καταλήγουν σε `double` κατά τη μεταγλώττιση.
Αυτή είναι μια καλή προεπιλεγμένη περίπτωση και οι περιπτώσεις χρήσης με τον στενότερο τύπο `float` είναι πιο σπάνιες από το παραπάνω παράδειγμα χωρίς πρόσημο.

```cpp
auto light_year_in_m{9.46073e+15f}; // well in the range of float
auto earth_to_edge_comoving_distance_in_nm{4.32355e+32}; // needs double type for magnitude
auto eulers_number{2.718281828459045}; // needs double type for precision
```

## Literals χαρακτήρων και συμβολοσειρών

Άλλες έννοιες έχουν ήδη χρησιμοποιήσει literals χαρακτήρων με μονά εισαγωγικά, όπως `'}'` ή `'@'`.

Στη C++ ο `char` περιορίζεται στους πρώτους 128 [κωδικούς χαρακτήρων ascii][ascii-code].
Για να χρησιμοποιήσεις πολλούς χαρακτήρες ascii ή εκτεταμένους χαρακτήρες ascii, όπως `‰`, ή ακόμα και χαρακτήρες unicode, όπως `麗` και `ẞ`, χρειάζεσαι άλλους τύπους.
Σε προηγούμενη έννοια, τα literals συμβολοσειράς παρουσιάστηκαν με _διπλά εισαγωγικά_: `"一体どういう意味ですか。C++です"`.
Ο πραγματικός τύπος αυτής της ιαπωνικής φράσης είναι `const char (&)[46]`, μια συμβολοσειρά τύπου C.

Η χρήση των literals συμβολοσειράς δεν ενεργοποιείται από προεπιλογή.
Για να χρησιμοποιήσεις το literal _συμβολοσειράς_ `""s` ή το literal _string-view_ `""sv`, πρέπει να δηλώσεις τη χρήση τους με τον σχετικό χώρο ονομάτων:

```cpp
#include <string>
#include <string_view>

using namespace std::literals;

auto green_light{"무궁화 꽃 이 피었 습니다"};
// green_light type is const char (&)[36]
auto umbrella{"달고나"s};
// umbrella type is std::basic_string<char>, the same as std::string
auto il_nam{"보는 것이 하는 것보다 더 재미있을 수가 없지"sv};
// il_nam type is std::basic_string_view<char>
```

Ένα _string_view_ μπορεί να θεωρηθεί ως αναφορά σε μια const συμβολοσειρά.
