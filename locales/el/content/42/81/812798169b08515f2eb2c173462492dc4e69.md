# Σχετικά

Το jq λειτουργεί περνώντας τα εισερχόμενα δεδομένα JSON μέσα από μία _ενιαία έκφραση_ (γραμμένη ως _σωλήνωση φίλτρων_) για να πετύχεις τα επιθυμητά μετασχηματισμένα δεδομένα.

## Μια γρήγορη εισαγωγή στις επιλογές γραμμής εντολών του `jq`

Η γλώσσα `jq` υλοποιείται από το _πρόγραμμα_ `jq`.
Αυτό το πρόγραμμα παρέχει αρκετές βολικές επιλογές γραμμής εντολών για να ελέγχεις πώς καταναλώνεται η είσοδος και πώς παρουσιάζεται η έξοδος.

Στα παρακάτω παραδείγματα θα συναντήσεις:

- `-n` ή `--null-input`

  Κανονικά στο πρόγραμμα `jq` δίνεται ένα αρχείο για ανάγνωση, ή στέλνεις δεδομένα στην είσοδό του.
  Η επιλογή `--null-input` σου επιτρέπει να παράγεις δεδομένα JSON χωρίς καμία είσοδο.

- `-c` ή `--compact-output`

  Το `jq` μορφοποιεί όμορφα την έξοδό του από προεπιλογή.
  Είναι εξαιρετικά χρήσιμο για τους ανθρώπους να βλέπουν τα δεδομένα όταν είναι όμορφα μορφοποιημένα.
  Ωστόσο, αυτό δεν είναι απαραίτητο για τις μηχανές: η επιλογή `--compact-output` αφαιρεί τα κενά μορφοποίησης για να ελαχιστοποιήσει το μέγεθος του JSON που προκύπτει.

- `-f filename` ή `--from-file filename`

  Διάβασε το πρόγραμμα `jq` από το `filename` αντί να το δίνεις στη γραμμή εντολών.
  Τόσο το `sed` όσο και το `awk` χρησιμοποιούν την επιλογή `-f` για τον ίδιο σκοπό.
  Θα το δεις αυτό να χρησιμοποιείται στα σενάρια δοκιμών για τις ασκήσεις πρακτικής.

Δες [το εγχειρίδιο][man-cli] για λεπτομέρειες σχετικά με όλες τις επιλογές.

## Φίλτρα και σωλήνες

Τα **φίλτρα** είναι επίσης γνωστά ως **εκφράσεις**.

Ένα _φίλτρο_ δέχεται μια είσοδο και παράγει μια έξοδο.
Όπως ακριβώς δουλεύεις σε ένα κέλυφος unix, μπορείς να ενώσεις _φίλτρα_ με έναν σωλήνα `|` για να συνδέσεις την έξοδο του ενός _φίλτρου_ με την είσοδο του άλλου.

## Το φίλτρο ταυτότητας: `.`

Αυτό είναι το πιο απλό _φίλτρο_.
Περνά απλώς την είσοδό του στην έξοδό του.
Για παράδειγμα, το `jq` μορφοποιεί όμορφα από προεπιλογή, οπότε περνώντας JSON στο φίλτρο `.` παίρνεις δωρεάν όμορφα μορφοποιημένη έξοδο!

```sh
$ echo '[1, 2, 3]' | jq '.'
[
  1,
  2,
  3
]
```

## Πίνακες

Αυτή θα είναι μια γρήγορη εισαγωγή στην εργασία με **πίνακες**.
Θα καλύψουμε αυτό το θέμα με περισσότερες λεπτομέρειες αργότερα.

Τα στοιχεία ενός _πίνακα_ προσπελαύνονται με αγκύλες και η αρίθμησή τους ξεκινά από το μηδέν.

```sh
$ echo '[10, 20, 30]' | jq '.[1]'
20
```

Ένα _φίλτρο_ μπορεί να φτιάξει έναν _πίνακα_ τυλίγοντας μια έκφραση σε `[` και `]`

- με μια γνωστή λίστα στοιχείων:

  ```sh
  jq -n '[1, 2, 3]'
  ```

- για να συλλέξεις μια ροή στοιχείων: για παράδειγμα,
  η [`range`][man-range] είναι μια συνάρτηση που παράγει μια ροή αριθμών

  ```sh
  $ jq -n 'range(10; 70; 15)'
  10
  25
  40
  55
  ```

  Η χρήση του `[]` συλλέγει τα αποτελέσματα της έκφρασης σε έναν πίνακα

  ```sh
  $ jq -c -n '[range(10; 70; 15)]'
  [10,25,40,55]
  ```

## Το κόμμα είναι τελεστής

Το _κόμμα_ δεν είναι απλώς σύνταξη που χωρίζει τα στοιχεία ενός _πίνακα_.
Το **κόμμα** είναι ένας **τελεστής** που ενώνει ροές.

Για παράδειγμα, το `[1, 2, 3]` είναι ένα _φίλτρο_ που χρησιμοποιεί τον κατασκευαστή _πίνακα_ `[]` για να συλλέξει το αποτέλεσμα της ένωσης των τριών εκφράσεων `1`, `2` και `3`.

Πρόσεξες τις άνω τελείες στο `range(10; 70; 15)` παραπάνω;
Επειδή τα _κόμματα_ έχουν συγκεκριμένο σκοπό στη γλώσσα `jq`, οι συναρτήσεις που δέχονται πολλαπλά ορίσματα χρησιμοποιούν άνω τελείες για να χωρίσουν τα ορίσματα.

## Αντικείμενα

Μια γρήγορη εισαγωγή στα **αντικείμενα**.

Όπως σε πολλές γλώσσες προγραμματισμού, χρησιμοποίησε τελείες για να προσπελάσεις τις ιδιότητες ενός _αντικειμένου_

```sh
$ echo '{"foo": {"bar": "qux"}}' | jq '.foo.bar'
"qux"
```

Οι αγκύλες μπορούν να χρησιμοποιηθούν και για _αντικείμενα_, αλλά τότε χρειάζονται εισαγωγικά για τα κυριολεκτικά συμβολοσειρών.
Αυτός είναι ένας τρόπος να δουλέψεις με κλειδιά που περιέχουν κενά.

```sh
$ echo '{"foo bar": "qux"}' | jq '.["foo bar"]'
"qux"
```

Μπορείς να κατασκευάσεις ένα _αντικείμενο_ με `{}` και ζεύγη `key: value`.
Τα εισαγωγικά δεν είναι απαραίτητα γύρω από _κλειδιά_ που είναι "απλές" συμβολοσειρές.

```sh
jq -n '{question: (6 * 9), answer: 42}'
```

παράγει

```none
{
  "question": 54,
  "answer": 42
}
```

Για να αντιμετωπίσεις το _κλειδί_ ως _έκφραση_, πρέπει να το τυλίξεις σε παρενθέσεις (το παρακάτω δίνει επίσης το ίδιο αποτέλεσμα όπως παραπάνω).

```sh
echo '[["question", "answer"], [54, 42]]' \
| jq '{(.[0][0]): .[1][0], (.[0][1]): .[1][1]}'
```

## Σωληνώσεις

Για παράδειγμα, δεδομένου του `file.json` που περιέχει

```json
{
  "key1": "value1",
  "key2": [5, 15, 25]
}
```

Ας υπολογίσουμε το μήκος του _πίνακα_ key2:

```sh
$ jq '.key2 | length' file.json
3
```

_Διοχετεύουμε_ την έξοδο της έκφρασης `.key2` ως είσοδο στη [`length`][man-length], η οποία, όπως είναι αναμενόμενο, παράγει τον αριθμό των στοιχείων του πίνακα.

<!-- prettier-ignore -->
~~~~exercism/caution
Αυτή είναι μια πτυχή του `jq` που θέλει λίγο χρόνο για να τη συνηθίσεις. Οι περισσότερες (αλλά όχι όλες) οι συναρτήσεις συμπεριφέρονται σαν _φίλτρα_, όπου περνάς δεδομένα στην είσοδο του φίλτρου, όχι ως όρισμα.
~~~~

<!-- prettier-ignore-end -->

## Τα φίλτρα μπορούν να αγνοήσουν την είσοδό τους

Σε αυτό το παράδειγμα, τα δεδομένα JSON εισόδου αγνοούνται και δεν έχουν καμία επίδραση στην έξοδο:

```sh
$ echo '{"answer": 42}' | jq '6 * 9'
54
```

## Τα φίλτρα μπορούν να παράγουν ροές δεδομένων

Ένα _φίλτρο_ μπορεί να παράγει περισσότερες από μία τιμές.
Για παράδειγμα, το _φίλτρο_ `.[]` παράγει κάθε στοιχείο ενός _πίνακα_ ως ξεχωριστή τιμή:

```sh
$ jq -n -c '[1, 2, 3]'
[1,2,3]

$ jq -n -c '[1, 2, 3] | .[]'
1
2
3
```

Διοχετεύοντας ένα τέτοιο _φίλτρο_ σε ένα άλλο, θα εκτελεστεί το 2ο _φίλτρο_ **_για κάθε τιμή_**:

```sh
$ jq -n -c '[1, 2, 3] | .[] | . * 2'
2
4
6
```

Αυτό μοιάζει με έμμεση επανάληψη.
Μόλις καταλάβεις αυτήν την τεχνική, θα συνειδητοποιήσεις ότι ισχυρότατα _φίλτρα_ `jq` μπορούν να είναι πολύ σύντομα.

## Παρενθέσεις

Οι **παρενθέσεις** χρησιμοποιούνται για να ομαδοποιήσουν υποεκφράσεις μαζί, ώστε να επιβληθεί η σειρά των πράξεων, όπως ακριβώς και σε άλλες γλώσσες.
Στη `jq`, η ανάγκη γι' αυτές μπορεί να φαίνεται κάπως αναπάντεχη.

Για παράδειγμα, ας πούμε ότι θέλουμε να κατασκευάσουμε έναν _πίνακα_ με 2 στοιχεία: την τετραγωνική ρίζα του 9 και το _e_ υψωμένο στη δύναμη 1.
Οι δύο μεμονωμένες εκφράσεις είναι `9 | sqrt` και `1 | exp`.
Περιμένουμε η έξοδος να είναι ο _πίνακας_ `[3, 2.7...]`

```jq
$ jq -n '[ 9|sqrt, 1|exp ]'
[
  20.085536923187668,
  2.718281828459045
]
```

Γιατί δεν πήραμε αυτό που περιμέναμε; Το `jq` το ερμηνεύει ως εξής:

```jq
[ ((9|sqrt), 1) | exp ]
```

Το `jq` φτιάχνει μια ροή δύο στοιχείων (`3` και `1`), τα οποία δίνονται το καθένα στο `exp`.

Πρέπει να διασφαλίσουμε ότι το `exp` παίρνει μόνο έναν αριθμό ως είσοδο.
Με άλλα λόγια, πρέπει να επιβάλουμε ο σωλήνας να αξιολογείται πριν από το κόμμα.

```jq
$ jq -n '[ 9|sqrt, (1|exp) ]'
[
  3,
  2.718281828459045
]
```

## Τύποι

Από [το εγχειρίδιο][man-types]

> Το jq υποστηρίζει το ίδιο σύνολο τύπων δεδομένων με το JSON: αριθμούς, συμβολοσειρές, Boolean (λογική τιμή), πίνακες, αντικείμενα (τα οποία στην ορολογία του JSON είναι hashes με κλειδιά μόνο συμβολοσειρών) και "null".

Θα μάθεις περισσότερα γι' αυτά σε επόμενες ασκήσεις.

## Κενά διαστήματα

Τα κενά διαστήματα δεν είναι σημαντικά στη `jq`.
Χρησιμοποίησε κενά, στηλοθέτες και αλλαγές γραμμής όπως θέλεις για να μορφοποιήσεις τον κώδικά σου.
Δεν γνωρίζουμε να υπάρχει κανένας οδηγός στυλ για τη `jq`.

## Αμετάβλητες τιμές

Οι τιμές στη `jq` είναι _αμετάβλητες_.
Τα φίλτρα που τροποποιούν μια τιμή θα παράγουν μια νέα τιμή.
Αυτό σημαίνει ότι η `jq` δεν έχει καθολικές μεταβλητές. Θα πρέπει να συνηθίσεις να περνάς κατάσταση από το ένα φίλτρο στο άλλο.

## "Αληθότητα"

Οι τιμές `false` και `null` θεωρούνται ψευδείς. Οποιαδήποτε άλλη τιμή
(συμπεριλαμβανομένου του αριθμού μηδέν και της κενής συμβολοσειράς/πίνακα/αντικειμένου) είναι αληθής.

## Συναρτήσεις και τελεστές

Χωρίς να μπούμε σε μεγάλο βάθος (οι συναρτήσεις θα είναι θέμα άλλης άσκησης), ορίστε μερικές χρήσιμες ενσωματωμένες συναρτήσεις:

- [`length`][man-length]

  Δεδομένου ενός πίνακα ως είσοδο, παράγει τον αριθμό των στοιχείων του πίνακα.

  ```sh
  $ jq -n '[10, 20, 30, 40] | length'
  4
  ```

- [`+`][man-plus]

  Αυτός ο τελεστής κάνει διαφορετικά πράγματα ανάλογα με τον τύπο των τελεστέων του:
  προσθέτει αριθμούς,
  συνενώνει συμβολοσειρές,
  προσθέτει στοιχεία σε πίνακες,
  συγχωνεύει αντικείμενα.

  ```sh
  $ jq -c -n '
      3 + 4,
      "foo" + "bar",
      ["a", "b"] + ["c"],
      {"m": 10} + {"n": 20}
  '
  7
  "foobar"
  ["a","b","c"]
  {"m":10,"n":20}
  ```

  Η [`add`][man-add] είναι μια συνάρτηση που παίρνει έναν πίνακα και επιστρέφει ένα στοιχείο με όλα τα στοιχεία αθροισμένα μεταξύ τους με τους κανόνες του `+`.
  Το `[1, 2, 3] | add` παράγει `6`.

- [`map`][man-map]

  Δεδομένου ενός πίνακα ως είσοδο και ενός φίλτρου ως όρισμα, παράγει έναν πίνακα όπου το φίλτρο εφαρμόζεται σε κάθε στοιχείο

  ```sh
  $ jq -c -n '[10, 20, 30, 40] | map(. / 5)'
  [2,4,6,8]
  ```

- [`select`][man-select]

  Δεδομένης _κάποιας_ εισόδου και ενός φίλτρου ως όρισμα:
  - αν το φίλτρο που εφαρμόζεται στο όρισμα έχει ως αποτέλεσμα μια _αληθή_ τιμή, παράγει την είσοδο αμετάβλητη
  - διαφορετικά, δεν παράγει _τίποτα_ (όχι την τιμή `null`, αλλά πραγματικά καμία έξοδο)

  Για παράδειγμα, δεδομένων κάποιων αριθμών, επίλεξε αυτούς που διαιρούνται με το 3

  ```sh
  $ jq -n 'range(10) | select(. % 3 == 0)'
  0
  3
  6
  9
  ```

  Θυμήσου ότι η `range` παράγει μια _ροή_ αριθμών.
  Η `select` θα καλείται μία φορά για κάθε αριθμό.
  Μόνο οι αριθμοί που "περνούν" την έκφραση παράγονται.

  Συχνά χρειάζεται να επιλέξεις στοιχεία ενός πίνακα.
  Υπάρχουν μερικοί τρόποι να το κάνεις αυτό.

  Με είσοδο `["Anne", "Bob", "Cathy", "Dave"]`, επίλεξε τα ονόματα που έχουν μήκος 4.
  - χρησιμοποίησε τις `map` και `select` μαζί

    ```jq
    map(select(length == 4))
    ```

  - σπάσε τον πίνακα στα στοιχεία του, εφάρμοσε `select` σε αυτή τη ροή και συγκέντρωσε τα αποτελέσματα

    ```jq
    [ .[] | select(length == 4) ]
    ```
