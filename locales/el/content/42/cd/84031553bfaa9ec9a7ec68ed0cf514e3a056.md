# Προσθήκη στις οδηγίες

## Υλοποίηση

Οι βασίλισσες που φαίνονται παρακάτω βρίσκονται στις [προεπιλεγμένες αρχικές θέσεις](https://en.wikipedia.org/wiki/Rules_of_chess#Initial_setup) τους.
Δηλαδή στην 1η γραμμή (σειρά 7) για τη λευκή βασίλισσα και στην 8η γραμμή (σειρά 0) για τη μαύρη βασίλισσα.
Και οι δύο βασίλισσες ξεκινούν στη στήλη d (στήλη 3).
