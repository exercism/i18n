# Οδηγίες

Η Chaitana έχει ένα πολύ δημοφιλές λούνα παρκ.
Έχει μόνο ένα παιχνίδι, ακριβώς στο κέντρο ενός πανέμορφα διαμορφωμένου τοπίου: το Μεγαλύτερο Τρενάκι του Λούνα Παρκ στον Κόσμο(TM).
Αν και υπάρχει μόνο αυτό το ένα αξιοθέατο, άνθρωποι ταξιδεύουν από όλο τον κόσμο και στέκονται στην ουρά για ώρες, μόνο και μόνο για την ευκαιρία να κάνουν βόλτα με το hypercoaster της Chaitana.

Υπάρχουν δύο ουρές για αυτό το παιχνίδι, και καθεμία αναπαρίσταται ως `array`:

1. Κανονική ουρά
2. Ουρά Express (_γνωστή και ως Fast-track_) - όπου οι άνθρωποι πληρώνουν επιπλέον για πρόσβαση κατά προτεραιότητα.

Σου ζητήθηκε να γράψεις κώδικα για να διαχειρίζεσαι καλύτερα τους επισκέπτες του πάρκου.
Πρέπει να υλοποιήσεις τις παρακάτω συναρτήσεις το συντομότερο δυνατό, πριν οι επισκέπτες (και το αφεντικό σου, η Chaitana!) αρχίσουν να γκρινιάζουν.

## 1. Πρόσθεσε ένα άτομο στην ουρά

Όρισε τη μέθοδο `ColossalCoaster.add_to_queue` που δέχεται 4 ορίσματα `<express_queue>, <normal_queue>, <ticket_type>, <person_name>` και επιστρέφει την κατάλληλη ουρά, ενημερωμένη με το όνομα του ατόμου.

1. Το όρισμα `<ticket_type>` είναι `Int32`, όπου 1 == express_queue και 0 == normal_queue.
2. Το όρισμα `<person_name>` είναι το όνομα (ως `String`) του ατόμου που θα προστεθεί στην αντίστοιχη ουρά.

```crystal
express_queue = ["Tony", "Bruce"]
normal_queue = ["RobotGuy", "WW"]
ColossalCoaster.add_to_queue(express_queue, normal_queue, 1, "RichieRich")
# => ["Tony", "Bruce", "RichieRich"]
```

## 2. Πού είναι οι φίλοι μου;

Ένα άτομο έφτασε αργά στο πάρκο, αλλά θέλει να μπει στην ουρά όπου περιμένουν οι φίλοι του.
Ωστόσο, δεν έχει ιδέα πού στέκονται οι φίλοι του και δεν υπάρχει σήμα τηλεφώνου για να τους καλέσει.

Όρισε τη μέθοδο `ColossalCoaster.find_my_friend` που δέχεται 2 ορίσματα, τα `queue` και `friend_name`, και επιστρέφει τη θέση στην ουρά του ατόμου με αυτό το όνομα.

1. Το όρισμα `<queue>` είναι ένα `array` με τα άτομα που στέκονται στην ουρά.
2. Το όρισμα `<friend_name>` είναι το όνομα του φίλου του οποίου τη θέση (πού βρίσκεται στην ουρά) πρέπει να βρεις.

```crystal
ColossalCoaster.find_my_friend(["Natasha", "Steve", "T'challa", "Wanda", "Rocket"], "Steve")
# => 1
```

## 3. Μπορώ να μπω και εγώ μαζί τους;

Τώρα που βρέθηκαν οι φίλοι τους (στην εργασία #2 παραπάνω), ο καθυστερημένος θα ήθελε να μπει μαζί τους, στη θέση τους στην ουρά.
Όρισε τη μέθοδο `ColossalCoaster.add_with_friends` που δέχεται 3 ορίσματα, τα `queue`, `friend_name` και `person_name`.

1. Το όρισμα `<queue>` είναι ένα `array` με τα άτομα που στέκονται στην ουρά.
2. Το όρισμα `<friend_name>` είναι το όνομα του φίλου στη θέση του οποίου πρέπει να προστεθεί το άτομο.
2. Το όρισμα `<person_name>` είναι το όνομα του ατόμου που θα προστεθεί στη θέση.

Επίστρεψε την ουρά ενημερωμένη με το όνομα του καθυστερημένου.

```crystal
ColossalCoaster.add_with_friends(["Natasha", "Steve", "T'challa", "Wanda", "Rocket"], "Steve", "Bucky")
# => ["Natasha", "Bucky", "Steve", "T'challa", "Wanda", "Rocket"]
```

## 4. Κακόβουλο άτομο στην ουρά

Μόλις έμαθες από την ουρά ότι υπάρχει ένας πολύ κακός άνθρωπος που σπρώχνει, φωνάζει και προκαλεί φασαρία.
Πρέπει να πετάξεις έξω αυτόν τον ταραξία για την κακή του συμπεριφορά!

Όρισε τη μέθοδο `ColossalCoaster.remove_from_queue` που δέχεται 2 ορίσματα, τα `queue` και `person_name`.

1. Το όρισμα `<queue>` είναι ένα `array` με τα άτομα που στέκονται στην ουρά.
2. Το όρισμα `<person_name>` είναι το όνομα του ατόμου που πρέπει να πεταχτεί έξω.

Επίστρεψε την ουρά ενημερωμένη, χωρίς το όνομα του κακόβουλου ατόμου.

```crystal
ColossalCoaster.remove_from_queue(["Natasha", "Steve", "Eltran", "Wanda", "Rocket"], "Eltran")
# => ["Natasha", "Steve", "Wanda", "Rocket"]
```

## 5. Ταξινόμησε τη λίστα της ουράς

Για διοικητικούς λόγους, πρέπει να βάλεις όλα τα ονόματα μιας δεδομένης ουράς σε αλφαβητική σειρά.

Όρισε τη μέθοδο `ColossalCoaster.sorted_queue` που δέχεται 1 όρισμα, το `queue` (το `array` με τα άτομα που στέκονται στην ουρά).
Η μέθοδος πρέπει να επιστρέφει ένα ταξινομημένο αντίγραφο του `array`.

```crystal
ColossalCoaster.sorted_queue(["Natasha", "Steve", "Eltran", "Natasha", "Rocket"])
# => ['Eltran', 'Natasha', 'Natasha', 'Rocket', 'Steve']
```
