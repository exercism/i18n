# Εισαγωγή

## Αναφορές null

Αν έχεις χρησιμοποιήσει ποτέ κάποια άλλη γλώσσα προγραμματισμού (C/C++, Python, Java, Ruby, Lisp κ.λπ.), είναι πιθανό να έχεις συναντήσει το `null` ή το `nil`.
Η χρήση του `null` ή του `nil` είναι ο τρόπος με τον οποίο αυτές οι γλώσσες δηλώνουν ότι μια συγκεκριμένη μεταβλητή δεν έχει τιμή.
Ωστόσο, αυτό κάνει το να χρησιμοποιήσεις κατά λάθος μια μεταβλητή που δείχνει στο `null` ένα εύκολο (και συχνό) λάθος.
Όπως μπορείς να φανταστείς, το να προσπαθείς να καλέσεις μια συνάρτηση που δεν υπάρχει ή να προσπελάσεις μια τιμή που δεν υπάρχει μπορεί να οδηγήσει σε κάθε λογής bugs και καταρρεύσεις.
Ο δημιουργός του `null` έφτασε στο σημείο να το αποκαλέσει ['το λάθος του ενός δισεκατομμυρίου δολαρίων'.](https://www.infoq.com/presentations/Null-References-The-Billion-Dollar-Mistake-Tony-Hoare/)

## Ο τύπος `Option`

Για να αποφύγει αυτά τα προβλήματα, η Rust δεν χρησιμοποιεί αναφορές null.
Ωστόσο, χρειάζεται ακόμα έναν ασφαλή τρόπο να δηλώνει ότι μια συγκεκριμένη μεταβλητή δεν έχει τιμή.
Εδώ έρχεται το `Option`.
Αντί να έχει μια μεταβλητή που στερείται τιμής, οι μεταβλητές της Rust μπορούν να χρησιμοποιούν το enum `Option`.
Αυτό το enum έχει δύο παραλλαγές: το `None`, το αντίστοιχο του null στη Rust, και το `Some(T)`, όπου το T είναι μια τιμή οποιουδήποτε τύπου.

Μοιάζει κάπως έτσι:

```rust
enum Option<T> {
    None,
    Some(T),
}
```

Μπορείς να σκεφτείς το `Option` ως ένα στρώμα ασφάλειας ανάμεσα σε εσένα και στα προβλήματα που μπορούν να προκαλέσουν οι αναφορές null, διατηρώντας παράλληλα τη χρησιμότητά τους σε εννοιολογικό επίπεδο.

## Χρήση του `Option`

Το να θέσεις μια μεταβλητή σε `None` είναι αρκετά απλό:

```rust
let nothing: Option<u32> = None;  // Variable nothing is set to None
```

Ωστόσο, αν θέλεις ο τύπος `Option` να μεταφέρει μια τιμή, δεν μπορείς να αναθέσεις αυτή την τιμή απευθείας.
Μια μεταβλητή τύπου `Option` και, ας πούμε, μια μεταβλητή τύπου `i32` δεν είναι ισοδύναμες.
Θα χρειαστεί να χρησιμοποιήσεις το `Some`:

```rust
let wrong_way: Option<i32> = -4; // This will not work

let right_way: Option<i32> = Some(-4); // This will work
let another_right_way = Some(-4); // Compiler infers that this is Option<i32>
```

Για τον ίδιο λόγο, το παρακάτω δεν θα δουλέψει:

```rust
let number = 47;
let option_number = Some(15);

let compile_error = number + option_number; // Cannot add an i32 and an Option<i32> - they are of different types
```

Αν θέλεις να πάρεις την τιμή που περιέχει το Some, θα πρέπει πρώτα να ελέγξεις ότι υπάρχει:

```rust
let mut some_words = Some("choose something to say"); // some_words set to something

match some_words {
    Some(str) => println!("Here, we will {}", str),
    None => println!("I've got nothing to say"),
} // Prints "Here, we will choose something to say"

some_words = None; // some_words now set to None

// exactly the same match block as above
match some_words {
    Some(str) => println!("Here, we will {}", str),
    None => println!("I've got nothing to say"),
} // Prints "I've got nothing to say"
```

Εκτός από το `match`, η Rust έχει κι άλλα εργαλεία για τον έλεγχο και την πρόσβαση σε τιμές που περιέχονται σε ένα `Option`, αλλά το `match` θα πρέπει να σου είναι πλέον οικείο.

Επιπλέον, δες το ως μια επίδειξη του γιατί η Rust χρησιμοποιεί το `Option` αντί για αναφορά null.
Το θέμα είναι ότι **πρέπει _οπωσδήποτε_ να ελέγξεις** αν η μεταβλητή `Option` είναι `Some` (οπότε μπορείς να προχωρήσεις και να εξαγάγεις και να χρησιμοποιήσεις την τιμή που περιέχει) ή `None`.
Οτιδήποτε άλλο και το πρόγραμμά σου δεν θα μεταγλωττιστεί. Ο μεταγλωττιστής σε προστατεύει από το `null`.
