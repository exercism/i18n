# Tests

Για να τρέξεις τα tests, τρέξε την εντολή `sbt test` στον φάκελο της άσκησης.
Δες τη [σελίδα tests](https://exercism.org/docs/tracks/scala/tests) για περισσότερες πληροφορίες.

## Παραλειμμένα tests

Στην αρχή, θα είναι ενεργό μόνο το πρώτο test.
Έτσι σε ενθαρρύνουμε να λύσεις την άσκηση βήμα βήμα.
Μόλις περάσει το πρώτο test, αφαίρεσε τη λέξη-κλειδί `pending` από την αρχή του επόμενου test και δούλεψε πάνω σε αυτό μέχρι να περάσει.
