# Προσθήκη οδηγιών

## Υποδείξεις

Αυτή η άσκηση απαιτεί να επεξεργαστείς μια συλλογή δεδομένων. Μπορείς να απλοποιήσεις τον κώδικά σου χρησιμοποιώντας οκνηρές ακολουθίες για να βελτιώσεις την απόδοση.
Για περισσότερες πληροφορίες, δες την [οκνηρή αποτίμηση][lazy evaluation].
