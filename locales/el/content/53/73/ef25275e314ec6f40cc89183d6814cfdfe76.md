# Σχετικά

Όταν διατρέχεις μια ακολουθία, μερικές φορές το στοιχείο μόνο του δεν αρκεί: χρειάζεσαι και τη θέση. Οι λέξεις της Factor για *επανάληψη με θέση* δίνουν στο quotation ανά στοιχείο και τα δύο, με τη θέση στην κορυφή της στοίβας. Το `times` είναι η σχετική λέξη για επανάληψη με μέτρημα, χωρίς υποκείμενη ακολουθία.

```factor
USING: io kernel math.parser sequences ;

! map-index: build a new sequence; quot sees ( elt index )
{ "alice" "bob" "carol" }
[ number>string ": " glue ] map-index .
! => { "alice: 0" "bob: 1" "carol: 2" }

! each-index: for side effect; quot sees ( elt index )
{ "alice" "bob" } [
    number>string ": " glue print
] each-index
! prints alice: 0
! prints bob: 1

! times: run a quotation N times
3 [ "tick " print ] times
```

| λέξη         | αποτέλεσμα                                                           |
|--------------|----------------------------------------------------------------------|
| `each-index` | `( seq quot: ( elt index -- ) -- )`                                  |
| `map-index`  | `( seq quot: ( elt index -- newelt ) -- newseq )`                    |
| `times`      | `( n quot: ( -- ) -- )`, αλλά δες παρακάτω                           |

Μια λεπτομέρεια για το `times`: αν και το quotation του τεκμηριώνεται ως `( -- )`, η λέξη είναι `inline`, οπότε ένα quotation με ισορροπημένο αποτέλεσμα όπως το `( str -- str )` δουλεύει μια χαρά και περνά τη στοίβα από τη μια επανάληψη στην άλλη. Έτσι έχεις έναν συσσωρευτή με μέτρημα, χωρίς καμία μεταβλητή κατάσταση:

```factor
USING: kernel sequences ;

"" 3 [ "clop " append ] times .    ! => "clop clop clop "
```

Το ίδιο τρικ δουλεύει και για τα `each-index` και `map-index`: το δηλωμένο αποτέλεσμα ανά στοιχείο είναι *ελάχιστο*, όχι μέγιστο.
