# Υπόλοιπο

Οι συγκρίσεις με το υπόλοιπο είναι απόλυτα έγκυρες στην Crystal, αλλά ένας πιο ευανάγνωστος τρόπος να συγκρίνεις το υπόλοιπο μιας διαίρεσης είναι η μέθοδος [`divisible_by?`][divisible_by].
Ή, ακόμα καλύτερα, αν θέλεις να ελέγξεις αν ένας αριθμός είναι μονός ή ζυγός, χρησιμοποίησε τις μεθόδους [`odd?`][odd?] και [`even?`][even?].

Για παράδειγμα:

```crystal
# Rather than:
number %% 2 == 0

# Consider:
number.even?
```

[odd?]: https://crystal-lang.org/api/Int.html#odd%%3F%%3ABool-instance-method
[even]: https://crystal-lang.org/api/Int.html#odd%%3F%%3ABool-instance-method
