# Συμβολοσειρές

Οι συμβολοσειρές είναι μια σειρά από χαρακτήρες, μέσα σε εισαγωγικά.
Υποστηρίζονται και τα μονά και τα διπλά εισαγωγικά.

```php
<?php

$where = "Spain";
$what = 'rain';
```

## Επέκταση μεταβλητών μέσα σε συμβολοσειρές

Στις συμβολοσειρές με διπλά εισαγωγικά, αν γίνει αναφορά σε μια μεταβλητή που βρίσκεται εντός εμβέλειας, η τιμή της ενσωματώνεται μέσα στη συμβολοσειρά.

```php
<?php

$answer = 42;
$expanded = "The answer to life, the universe, and everything is $answer"; 
```

## Υποστήριξη κωδικοποίησης χαρακτήρων

Ιστορικά, οι συναρτήσεις συμβολοσειρών στην PHP υποστήριζαν μόνο χαρακτήρες ASCII και δεν υποστήριζαν σύγχρονες κωδικοποιήσεις Unicode.
Οι χαρακτήρες ASCII καταλαμβάνουν 1 byte ο καθένας, ενώ οι χαρακτήρες Unicode μπορεί να έχουν μήκος 1-4 byte.
Αν χρειάζεται να χειριστείς συμβολοσειρές Unicode με ασφάλεια, ανατρέξε στις [εκδόσεις πολλαπλών byte][multi-byte-fns] των παλιών συναρτήσεων.

```php
<?php

$byte_length = strlen('😃'); // => 4
$string_length = mb_strlen('😃'); // => 1
```

[multi-byte-fns]: https://www.php.net/manual/en/ref.mbstring.php
