# Εγκατάσταση

## Εγκατάσταση .NET 10

Η διαδρομή Visual Basic χρησιμοποιεί .NET 10.
Για να μεταγλωττίσεις και να δοκιμάσεις τις ασκήσεις τοπικά, εγκατέστησε [το .NET 10 SDK για το λειτουργικό σου σύστημα][install-sdk]:
Εγκατέστησε το SDK, όχι μόνο το runtime.

## Έλεγξε την εγκατάστασή σου

Άνοιξε ένα νέο τερματικό και τρέξε:

```bash
dotnet --version
```

Η εντολή θα πρέπει να εμφανίζει `10.0.0` ή νεότερη.

## Υποστήριξη επεξεργαστών

Το .NET SDK και ένας απλός επεξεργαστής κειμένου είναι το μόνο που χρειάζεσαι για να ολοκληρώσεις τις ασκήσεις.
Για πιο προηγμένες λειτουργίες, όπως η αυτόματη συμπλήρωση κώδικα και η αποσφαλμάτωση, σκέψου έναν από αυτούς τους επεξεργαστές:

- [Visual Studio 2026][visual-studio] σε Windows
- [Visual Studio Code][visual-studio-code] σε Windows, Linux ή macOS
- [JetBrains Rider][rider] σε Windows, Linux ή macOS

[rider]: https://www.jetbrains.com/rider/
