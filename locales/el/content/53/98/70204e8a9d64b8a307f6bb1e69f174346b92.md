# Σχετικά

Μπορείς να χρησιμοποιήσεις [τύπους απαρίθμησης][enumeration types] όποτε έχεις ένα καθορισμένο σύνολο σταθερών τιμών. Η χρήση ενός `enum` σου δίνει έναν τρόπο να χειρίζεσαι σταθερές τιμές με ασφάλεια τύπων. Ο ορισμός ενός enum γίνεται με τη λέξη-κλειδί `enum`. Για να αναφερθείς σε ένα μέλος enum, βάζεις μπροστά του το όνομα του enum και μια τελεία (π.χ. `Status.Active`).

Κάθε μέλος enum είναι ένας συνδυασμός ενός ονόματος και μιας τιμής `int`. Αν το πρώτο μέλος δεν έχει ρητή τιμή, η τιμή του ορίζεται σε `0`. Αν δεν οριστεί ρητά κάποια τιμή για ένα μέλος enum, η τιμή του παίρνει αυτόματα την τιμή του προηγούμενου μέλους συν `1`.

```csharp
enum Season
{
    Spring,     // Auto set 0
    Summer = 2, // Set the value 2
    Autumn,     // Auto set 3
    Winter = 7  // Set the value 7
}
```

Τα enum είναι πολύ δηλωτικά. Σύγκρινε τις παρακάτω δύο κλήσεις μεθόδων:

```csharp
Users.WithStatus(1)
Users.WithStatus(Status.Active)
```

Για κάποιον που διαβάζει τον κώδικα, η δεύτερη έκδοση (με enum) είναι πιο κατανοητή.

## Enums αριθμητικού τύπου

Αν και ο προεπιλεγμένος αριθμητικός τύπος των τιμών είναι `int`, μπορείς να τον αλλάξεις ορίζοντας ρητά οποιονδήποτε άλλο [ακέραιο αριθμητικό][integral numeric] τύπο.

Το παρακάτω enum χρησιμοποιεί τον αριθμητικό τύπο `byte` για τις τιμές του:

```csharp
enum Priority : byte
{
    Low = 0,
    Medium = 127,
    High = 255
}
```

## Μετατροπή σε μέλος enum

Όποτε θέλεις να μοντελοποιήσεις κάτι σαν Boolean, καλό είναι να σκεφτείς να χρησιμοποιήσεις ένα enum. Εκτός από τα προαναφερθέντα οφέλη στην αναγνωσιμότητα, τα enum έχουν ένα ακόμη πλεονέκτημα σε σχέση με τα Boolean: μπορείς πάντα να προσθέσεις νέες τιμές σε ένα enum, ενώ μια τιμή Boolean θα είναι πάντα μόνο `true` ή `false`. Έτσι, η χρήση ενός enum είναι πιο ανθεκτική στο μέλλον.

```csharp
enum Status
{
    Inactive = 0,
    Active = 1
}

Status active = (Status) 1;
active == Status.Active; // True
```

Σημείωσε ότι, ενώ _μπορείς_ να μετατρέψεις ακέραιες τιμές σε enum, αυτό μπορεί να οδηγήσει σε απρόσμενα αποτελέσματα όταν η ακέραια τιμή δεν αντιστοιχεί σε κάποια τιμή του enum:

```csharp
Status status = (Status) 2;
status == Status.Inactive; // False
status == Status.Active;   // False
```

## Ανάλυση ενός enum

Μερικές φορές είναι χρήσιμο να μετατρέψεις μια συμβολοσειρά σε μέλος enum με βάση το όνομά της, χρησιμοποιώντας το [`Enum.Parse`][enum parse]:

```csharp
var input = "Inactive";
Status status = (Status)Enum.Parse(typeof(Status), input);
// Inactive
```

Για να ελέγξεις αν υπάρχει ένα όνομα ή μια τιμή στο enum, μπορείς να χρησιμοποιήσεις το [`Enum.TryParse`][enum tryparse] ή το [`Enum.IsDefined`][enum isdefined]· και τα δύο επιστρέφουν ένα Boolean που δείχνει αν υπάρχει το μέλος enum:

```csharp
bool doesExist = Enum.IsDefined(typeof(Status), "Inexistent");
// False
```
