# Εισαγωγή

## Μεταβλητές και εκχώρηση

Η R είναι μια γλώσσα με δυναμικούς τύπους, οπότε γενικά δεν χρειάζεται να προσδιορίσεις τον τύπο μιας μεταβλητής. Ο προτιμώμενος τελεστής εκχώρησης είναι ο `<-`

```R
x <- 42
avogadro <- 6.02e23
mystr <- "Hello, World!"
```

Η χρήση του `=` αντί για το `<-` συχνά δουλεύει, αλλά όχι πάντα, και αποθαρρύνεται ως κακό στυλ.
Αν δουλεύεις στο RStudio, μπορείς να το εισάγεις με τη συντόμευση πληκτρολογίου `Alt-minus`.

Οι τελεστές είναι ως επί το πλείστον συμβατικοί, αλλά πρόσεξε τους `%/%` και `%%`:

```R
2 + 3   # 5
2 - 3   # -1
2 * 3   # 6
2 / 3   # 0.6666667
8 %/% 3 # 2 (integer division)
8 %% 3  # 2 (remainder)
2 ^ 3   # 8 (exponential)
```

Στη R, το `#` ξεκινά ένα σχόλιο μίας γραμμής.
Δεν υπάρχει ξεχωριστή σύνταξη για σχόλια πολλών γραμμών.

## Συναρτήσεις

Για να ορίσεις μια συνάρτηση:

```R
squareit <- function(x) {
    x * x
}
```

Οι συναρτήσεις μπορούν να έχουν μηδέν ή περισσότερα ορίσματα, χωρισμένα με κόμμα.
Οι παρενθέσεις `()` χρειάζονται με το `function()`, ακόμα κι αν δεν υπάρχουν παράμετροι.

Μπορείς να ορίσεις προεπιλεγμένες τιμές για τα ορίσματα μιας συνάρτησης, αν και αυτές πρέπει να έρχονται μετά από οποιαδήποτε ορίσματα χωρίς προεπιλογή, και χρησιμοποιείς `=` και όχι `<-` για να αναθέσεις την προεπιλεγμένη τιμή.
Ως ένα μάλλον άσκοπο παράδειγμα:

```R
squareit <- function(x = 42) {
    x * x
}

squareit()
#> [1] 1764
```

Τα άγκιστρα `{ }` δεν είναι αυστηρά απαραίτητα για σώματα συνάρτησης μίας γραμμής, αλλά το να τα συμπεριλάβεις θεωρείται καλό στυλ.

Η R επιστρέφει αυτόματα την τελική τιμή μιας συνάρτησης, όπως στα παραπάνω παραδείγματα.

Το `return()` μπορεί να χρησιμοποιηθεί οπουδήποτε μέσα στο σώμα της συνάρτησης για να κάνει ρητή την τιμή επιστροφής.

Η κλήση μιας συνάρτησης είναι ίδια όπως σε πολλές άλλες γλώσσες:

```R
squareit(3)
#> [1] 9
```
