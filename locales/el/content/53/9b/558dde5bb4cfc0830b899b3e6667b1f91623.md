# Υποδείξεις

## 1. Δημιούργησε ερωτήματα SELECT

- Θυμήσου ότι δεν χρειάζεται να αρχικοποιήσεις τον builder με κάποιον constructor ή literal.
  Ένα απλό `var sb strings.Builder` είναι αμέσως έτοιμο για χρήση.
- Φρόντισε να χειριστείς την περίπτωση όπου το slice `columns` είναι κενό ή `nil`, προσθέτοντας το σύμβολο μπαλαντέρ `*`.
- Σημείωσε ότι εδώ δεν απαιτείται ούτε αναμένεται να χειριστείς μεταχαρακτήρες ή να κάνεις καθαρισμό SQL. Μπορείς να προσθέτεις τα ονόματα των στηλών απευθείας με `sb.WriteString(col)` χωρίς κίνδυνο.

## 2. Δημιούργησε μαζικές εντολές INSERT

- Το να δεσμεύσεις ένα ολοκαίνουργιο `strings.Builder` μέσα σε έναν βρόχο `for` ακυρώνει τα οφέλη στην απόδοση.
  Αντίθετα, δήλωσε έναν μόνο builder *πριν* ξεκινήσει ο βρόχος.
- Στην αρχή κάθε επανάληψης του βρόχου, κάλεσε τη μέθοδο `Reset()` στο στιγμιότυπο του builder σου.
  Έτσι αδειάζει το buffer, ώστε να ξεκινήσεις ένα νέο ερώτημα κρατώντας παράλληλα τη χωρητικότητα μνήμης που έχει ήδη δεσμευτεί.
- Μην ξεχάσεις ότι οι τιμές συμβολοσειρών στη ρήτρα `VALUES` της SQL πρέπει να περικλείονται ρητά σε απλά εισαγωγικά `'`.
  Μπορείς να χρησιμοποιήσεις το `WriteByte('\'')` για να τις προσθέσεις καθαρά.
- Όπως και με τα ερωτήματα SELECT, μην ανησυχείς για τη διαφυγή ειδικών χαρακτήρων ή την αποτροπή εισβολών SQL μέσα στις τιμές των στηλών. Θεώρησε τις συμβολοσειρές εισόδου ασφαλείς για άμεση χρήση.
