# Προσθήκη στις οδηγίες

## Καταχωρητές

| Καταχωρητής | Χρήση        | Τύπος    | Περιγραφή                         |
| -------- | ------------ | ------- | ----------------------------------- |
| `$a0`    | είσοδος        | ακέραιος | φυσικός αριθμός προς παραγοντοποίηση     |
| `$a1`    | είσοδος/έξοδος | διεύθυνση | πίνακας προορισμού για τους πρώτους παράγοντες |
| `$v0`    | έξοδος       | ακέραιος | πλήθος παραγόντων                   |
| `$t0-9`  | προσωρινός    | οτιδήποτε     | χρησιμοποιείται για προσωρινή αποθήκευση          |
