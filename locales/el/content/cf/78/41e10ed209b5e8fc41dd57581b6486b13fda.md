# Εισαγωγή

## Εντολές `switch`

Η Wikipedia περιγράφει την εντολή `switch` ως "έναν τύπο μηχανισμού ελέγχου επιλογής που επιτρέπει στην τιμή μιας μεταβλητής ή μιας έκφρασης να αλλάξει τη ροή ελέγχου του προγράμματος".

Ο μηχανισμός περιλαμβάνει τις εξής λέξεις-κλειδιά: `switch`, `case`, `break` και `default`.

Στην πιο απλή τους μορφή, ελέγχουν μια έκφραση πρωτογενούς τύπου ή συμβολοσειράς και παίρνουν μια απόφαση με βάση την τιμή της. Για παράδειγμα:

```csharp
string direction = GetDirection();
switch (direction)
{
    case "left":
        GoLeft();
        break;
    case "right":
        GoRight();
        break;
    default:
        MarkTime();
        break;
}
```

Στην πιο εξελιγμένη τους μορφή, εισάγουν το downcasting `case <Type> <variable>:` και τους φρουρούς (`when`).

```csharp
Animal animal = GetAnimal();

switch (animal)
{
    case Dog canine:
    case Coyote canine:
        canine.Bark();
        break;
    case Cat cat when cat.HasOnly8Lives():
        cat.IsCareful();
        cat.Meow();
        break;
    case Cat cat:
        cat.Meow();
        break;
}
```
