# Εγκατάσταση

## Απαιτήσεις της διαδρομής γλώσσας PowerShell

Η διαδρομή γλώσσας PowerShell του Exercism απαιτεί να είναι εγκατεστημένα στο σύστημά σου:

- PowerShell ή Windows PowerShell Core
- Εγκατεστημένο module του framework δοκιμών και mock Pester

(Υ.Γ.: Η υποστήριξη του PowerShell περιορίζεται σε κρίσιμες διορθώσεις. Το PowerShell Core συντηρείται σταθερά και έχει μεγαλύτερη υποστήριξη σε πολλαπλές πλατφόρμες)

### Εγκατάσταση του PowerShell

Το PowerShell έρχεται προεγκατεστημένο σε όλα τα λειτουργικά συστήματα Windows από τα Windows 7 SP1 και μετά.

Μπορείς να βρεις την τελευταία έκδοση του PowerShell και οδηγίες εγκατάστασης για όλες τις πλατφόρμες (Linux, macOS και Windows) [εδώ][installation].

Ο πηγαίος κώδικας και η χειροκίνητη εγκατάσταση για το [PowerShell][source-code] είναι επίσης διαθέσιμα.

### Εγκατάσταση και ενημέρωση του framework Pester

Το [Pester][pester] είναι το framework δοκιμών του PowerShell.
Από την έκδοση 4.0.9 είναι συμβατό με το PowerShell Core σε Windows, Linux και MacOS (με ορισμένους περιορισμούς)

Είναι προεγκατεστημένο στα Windows 10, ωστόσο συνιστάται να το ενημερώσεις εκτελώντας την ακόλουθη εντολή PowerShell:

```PowerShell
Install-Module -Name Pester -Force -SkipPublisherCheck
```

Για μετέπειτα ενημερώσεις, εκτέλεσε:

```PowerShell
Update-Module -Name Pester
```

Αν χρειάζεται, περισσότερες οδηγίες για την εγκατάσταση είναι διαθέσιμες στη διεύθυνση: [https://github.com/pester/Pester/wiki/Installation-and-Update]()

## Χρήση IDE

Αν θέλεις μια πιο πλήρη εμπειρία επεξεργασίας, πιθανότατα θέλεις να χρησιμοποιήσεις ένα IDE.
Αυτά είναι τα πιο δημοφιλή IDE που υποστηρίζουν τη δημιουργία έργων PowerShell:

### Όλες οι πλατφόρμες

- [PowerShell ISE (Ολοκληρωμένο Περιβάλλον Δημιουργίας Σεναρίων)][ise], ενσωματωμένο γραφικό IDE που έρχεται με το PowerShell (μόνο για Windows).
  Για να ξεκινήσεις το PowerShell ISE, πληκτρολόγησε `powershell_ise.exe` σε μια κονσόλα PowerShell.
- [Visual Studio Code][vsc] με την [επέκταση PowerShell][vsc-extension].
  Το Visual Studio Code θα σου επιτρέψει επίσης να τρέξεις τα tests και να κάνεις debug τον κώδικα σου.
- [Sublime Text 3][sublime] με το [πακέτο PowerShell][sublime-package].
