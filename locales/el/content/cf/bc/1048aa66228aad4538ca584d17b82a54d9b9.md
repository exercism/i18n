# Οδηγίες

Δημιουργείς ένα απλό διαδικτυακό παιχνίδι όπου ένας φίλος μπορεί να μαντέψει έναν μυστικό αριθμό. Θέλεις να δώσεις κάποια ανατροφοδότηση, αλλά χωρίς να αποκαλύψεις την απάντηση με μια μαντεψιά. Πρέπει να σχεδιάσεις μια συνάρτηση που να δίνει διαφορετικές απαντήσεις ανάλογα με το πώς σχετίζεται η μαντεψιά με τον μυστικό αριθμό.

| Συνθήκη                                                              | Απάντηση       |
| -------------------------------------------------------------------- | -------------- |
| Όταν η μαντεψιά ταιριάζει με τον μυστικό αριθμό                       | "Correct"      |
| Όταν η μαντεψιά είναι κατά ένα μεγαλύτερη ή κατά ένα μικρότερη από τον μυστικό αριθμό | "So close"     |
| Όταν η μαντεψιά είναι μεγαλύτερη από τον μυστικό αριθμό               | "Too high"     |
| Όταν η μαντεψιά είναι μικρότερη από τον μυστικό αριθμό                | "Too low"      |
| Όταν δεν γίνεται καμία μαντεψιά                                       | "Make a guess" |

Όλες οι μαντεψιές και οι μυστικοί αριθμοί είναι ακέραιοι αριθμοί.

## 1. Φτιάξε την απάντηση όταν η μαντεψιά ταιριάζει με τον μυστικό αριθμό

Υλοποίησε τη συνάρτηση `compare/2`, η οποία δέχεται δύο ορίσματα, τα `secret_number` και `guess`, που είναι και τα δύο ακέραιοι.

```elixir
GuessingGame.compare(5, 5)
# => "Correct"
```

## 2. Φτιάξε την απάντηση όταν η μαντεψιά είναι μεγαλύτερη από τον μυστικό αριθμό

Τροποποίησε τη συνάρτηση `compare` ώστε να ανταποκρίνεται σε μαντεψιές που είναι μεγαλύτερες από τον μυστικό αριθμό.

```elixir
GuessingGame.compare(5, 8)
# => "Too high"
```

## 3. Φτιάξε την απάντηση όταν η μαντεψιά είναι μικρότερη από τον μυστικό αριθμό

Τροποποίησε τη συνάρτηση `compare` ώστε να ανταποκρίνεται σε μαντεψιές που είναι μικρότερες από τον μυστικό αριθμό.

```elixir
GuessingGame.compare(5, 2)
# => "Too low"
```

## 4. Φτιάξε τις απαντήσεις όταν η μαντεψιά είναι κατά ένα μεγαλύτερη ή κατά ένα μικρότερη από τον μυστικό αριθμό

Τροποποίησε τη συνάρτηση `compare` ώστε να ανταποκρίνεται σε μαντεψιές που είναι κοντά στον μυστικό αριθμό.

```elixir
GuessingGame.compare(5, 6)
# => "So close"
GuessingGame.compare(5, 4)
# => "So close"
```

## 5. Φτιάξε την απάντηση όταν δεν υπάρχει μαντεψιά

Τροποποίησε τη συνάρτηση `compare` ώστε να ανταποκρίνεται στην απουσία μαντεψιάς.

```elixir
GuessingGame.compare(5)
# => "Make a guess"

GuessingGame.compare(5, :no_guess)
# => "Make a guess"
```
