# Οδηγίες

Η νοσταλγία σου για τις κάρτες Blorkemon™️ δε δείχνει σημάδια κόπωσης, ξεκίνησες μάλιστα να τις συλλέγεις ξανά και βάζεις και τους φίλους σου να σε ακολουθήσουν.

Σε αυτή την άσκηση, μια συλλογή καρτών αναπαρίσταται από ένα `MapSet`, αφού οι διπλότυπες κάρτες δεν έχουν σημασία όταν ο στόχος σου είναι να αποκτήσεις όλες τις υπάρχουσες κάρτες.

## 1. Ξεκίνα μια συλλογή

Θέλεις πραγματικά να μπουν και οι φίλοι σου στην τρέλα με τα Blorkemon™️, και ο καλύτερος τρόπος είναι να ξεκινήσεις τη συλλογή τους δίνοντάς τους μία κάρτα.

Υλοποίησε τη `GottaSnatchEmAll.new_collection`, που μετατρέπει μια κάρτα σε συλλογή.

```elixir
GottaSnatchEmAll.new_collection("Newthree")
# => MapSet.new(["Newthree"])
```

## 2. Μεγάλωσε τη συλλογή

Μόλις αποκτήσεις μια συλλογή, αυτή αποκτά ζωή δική της και πρέπει να μεγαλώσει.

Υλοποίησε τη `GottaSnatchEmAll.add_card`, που παίρνει μια κάρτα και μια συλλογή και επιστρέφει μια πλειάδα με δύο τιμές: μία Boolean (λογική τιμή) που δείχνει αν η κάρτα ήταν ήδη στη συλλογή, και τη συλλογή με την κάρτα προσθεμένη.

```elixir
GottaSnatchEmAll.add_card("Scientuna", MapSet.new(["Newthree"]))
# => {false, MapSet.new(["Newthree", "Scientuna"])}
```

## 3. Ξεκίνα τις ανταλλαγές

Τώρα που οι φίλοι σου έχουν ξανατρελαθεί με τα Blorkemon™️, μπορείς να το εκμεταλλευτείς για να μεγαλώσεις τη δική σου συλλογή ανταλλάσσοντας κάρτες.

Δεν αξίζει να κάνεις κάθε ανταλλαγή, ενώ κάποιες δε γίνονται καθόλου.
Δε μπορείς να ανταλλάξεις μια κάρτα που δεν έχεις, και δεν πρέπει να ανταλλάξεις μια κάρτα με κάποια που έχεις ήδη.

Υλοποίησε τη `GottaSnatchEmAll.trade_card`, που παίρνει δύο κάρτες προς ανταλλαγή (τη δική σου και τη δική τους) και την τρέχουσα συλλογή σου.
Η τιμή επιστροφής είναι μια πλειάδα με δύο τιμές: ένα boolean που δηλώνει αν η ανταλλαγή είναι εφικτή και αξίζει να γίνει, και τη συλλογή με την οποία θα κατέληγες αν έκανες την ανταλλαγή (ακόμα κι αν δεν είναι στην πραγματικότητα εφικτή).

```elixir
GottaSnatchEmAll.trade_card("Scientuna", "Newthree", MapSet.new(["Scientuna"]))
# => {true, MapSet.new(["Newthree"])}
```

## 4. Μόνο ένα από το καθένα

Βρίσκεις έναν παλιό σωρό κάρτες σε ένα παζάρι.
Πρέπει να ταξινομήσεις τις κάρτες και να αφαιρέσεις τα διπλότυπα για να συγκρίνεις τη λίστα με τη συλλογή σου.

Υλοποίησε τη `GottaSnatchEmAll.remove_duplicates`, που θα ταξινομήσει μια λίστα καρτών και θα επιστρέψει μια λίστα με ταξινομημένες, μοναδικές κάρτες.

```elixir
GottaSnatchEmAll.remove_duplicates(["Newthree", "Newthree", "Newthree", "Scientuna"])
# => ["Newthree", "Scientuna"]
```

## 5. Κάρτες που τους λείπουν

Ώρα να νιώσεις καλά με τη συλλογή σου.

Υλοποίησε τη `GottaSnatchEmAll.extra_cards`, που παίρνει τη συλλογή σου και κάποια άλλη συλλογή, και επιστρέφει τον αριθμό των καρτών που δεν έχει η άλλη συλλογή.

```elixir
GottaSnatchEmAll.extra_cards(MapSet.new(["Scientuna"]), MapSet.new(["Newthree", "Scientuna"]))
# => 0
```

## 6. Κάρτες που τις έχουν όλοι

Μαζεύεστε εσύ και οι φίλοι σου οι φανατικοί των Blorkemon™️ και αναρωτιέστε ποιες κάρτες είναι οι πιο κοινές.

Υλοποίησε τη `GottaSnatchEmAll.boring_cards`, που παίρνει μια λίστα από συλλογές και επιστρέφει μια λίστα με ταξινομημένες κάρτες που τις έχουν όλες οι συλλογές.

```elixir
GottaSnatchEmAll.boring_cards([MapSet.new(["Scientuna"]), MapSet.new(["Newthree", "Scientuna"])])
# => ["Scientuna"]
```

## 7. Όλες οι κάρτες

Έχετε συλλογικά εσύ και οι φίλοι σου όλες τις κάρτες Blorkemon™️;

Υλοποίησε τη `GottaSnatchEmAll.total_cards`, που παίρνει μια λίστα από συλλογές και επιστρέφει τον συνολικό αριθμό των διαφορετικών καρτών σε όλες τις συλλογές.

```elixir
GottaSnatchEmAll.total_cards([MapSet.new(["Scientuna"]), MapSet.new(["Newthree", "Scientuna"])])
# => 2
```

## 8. Γυαλιστερές για τη νίκη

Ο ανιψιός σου θα έρθει σύντομα να σε επισκεφτεί και θέλεις να τον εντυπωσιάσεις.
Στα παιδιά αρέσουν τα γυαλιστερά πράγματα, έτσι δεν είναι;
Οι κάρτες Blorkemon™️ μπορούν να είναι γυαλιστερές!

Υλοποίησε τη `GottaSnatchEmAll.split_shiny_cards`, που παίρνει μια συλλογή και επιστρέφει μια πλειάδα με δύο λίστες ταξινομημένων καρτών: μία με όλες τις κάρτες που ξεκινούν με `"Shiny"` και μία με τις υπόλοιπες κάρτες.

```elixir
GottaSnatchEmAll.split_shiny_cards(MapSet.new(["Newthree", "Scientuna", "Shiny Scientuna"]))
# => {["Shiny Scientuna"], ["Newthree", "Scientuna"]}
```
