# Εισαγωγή

Σε αυτή την άσκηση πρέπει να εκτελέσεις λογική υπό συνθήκη. Ο πιο συνηθισμένος τρόπος για να το κάνεις αυτό στη C# είναι να χρησιμοποιήσεις μια εντολή `if/else`:

```csharp
int x = 6;

if (x == 5)
{
    // Execute logic if x equals 5
}
else if (x > 7)
{
    // Execute logic if x greater than 7
}
else
{
    // Execute logic in all other cases
}
```

Η συνθήκη μιας εντολής `if` πρέπει να είναι τύπου `bool`. Η C# δεν έχει την έννοια των _truthy_ τιμών.
