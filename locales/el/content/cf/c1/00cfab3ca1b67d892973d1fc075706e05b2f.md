# Εισαγωγή

## Συναρτήσεις με πολλαπλές ρήτρες

Η Elixir διευκολύνει την εφαρμογή της **Αρχής Ανοικτού-Κλειστού**, επιτρέποντας στις συναρτήσεις να έχουν πολλαπλές ρήτρες: έτσι, αντί για εκτεταμένη και καρφωτή λογική ελέγχου, μπορείς να γράψεις στοχευμένες συναρτήσεις που προσθέτουν ή αφαιρούν συμπεριφορά εύκολα.

Η Elixir προσφέρει _πολλαπλές ρήτρες συνάρτησης_ και _φρουρούς_ για να γράψεις:

```elixir
def number(n) when n == 7 do
  "Awesome, that's my favorite"
end

def number(_n) do
  "That's not my favorite"
end
```

Κατά την εκτέλεση, η Elixir ελέγχει, από την αρχή προς το τέλος του αρχείου πηγαίου κώδικα, ποια ρήτρα συνάρτησης θα καλέσει.

Οι μεταβλητές που δεν χρησιμοποιούνται πρέπει να ξεκινούν με κάτω παύλα.

## Φρουροί

Οι φρουροί χρησιμοποιούνται για να αποτρέψουν την Elixir από το να καλέσει συναρτήσεις, με βάση την αξιολόγηση των ορισμάτων από συναρτήσεις-φρουρούς. Οι φρουροί ξεκινούν με τη λέξη-κλειδί `when`, την οποία ακολουθεί μια έκφραση boolean. Οι συναρτήσεις-φρουροί είναι ειδικές συναρτήσεις που:

- Πρέπει να είναι καθαρές και να μην μεταβάλλουν καμία καθολική κατάσταση.
- Πρέπει να επιστρέφουν αυστηρά τιμές `true` ή `false`.

Μια λίστα με τους συνηθισμένους φρουρούς θα βρεις στην [τεκμηρίωση της Elixir][kernel-guards]. Περιλαμβάνει ελέγχους τύπων, βασική αριθμητική, συγκρίσεις και τελεστές που είναι αυστηρά boolean.

## Προεπιλεγμένα ορίσματα

Οι συναρτήσεις μπορούν να δηλώνουν προεπιλεγμένες τιμές για ένα ή περισσότερα ορίσματα. Ας δούμε αυτή τη συνάρτηση:

```elixir
def number(n \\ 13), do: "That's not my favorite"
```

Όταν γίνεται μεταγλώττιση, η Elixir δημιουργεί έναν ορισμό συνάρτησης για το `number/0` (χωρίς ορίσματα) και για το `number/1` (ένα όρισμα).

Αν περισσότερα από ένα ορίσματα έχουν προεπιλεγμένες τιμές, οι προεπιλεγμένες τιμές εφαρμόζονται στη συνάρτηση από αριστερά προς τα δεξιά, για να καλύψουν τα ορίσματα που λείπουν.

Αν η συνάρτηση έχει περισσότερες από μία ρήτρες, τα προεπιλεγμένα ορίσματα πρέπει να ορίζονται σε μια κεφαλίδα συνάρτησης (μια συνάρτηση χωρίς σώμα), πριν από τις ρήτρες της συνάρτησης:

```elixir
def number(n \\ 13)
def number(n) when n < 10, do: "Dream bigger!"
def number(n) when n > 100, do: "Not that big..."
```
