**Ψάχνουμε νέους συντηρητές διαδρομών. Ενδιαφέρεσαι; Διάβασε παρακάτω!**

Το Exercism τροφοδοτείται από την ενέργεια πολλών εθελοντών, ειδικά των [συντηρητών διαδρομών](https://exercism.io/team/maintainers) που είναι υπεύθυνοι για τη δημιουργία και τη διαχείριση των γλωσσικών διαδρομών μας.

Είμαστε έτοιμοι να ξεκινήσουμε μια μεγάλη προσπάθεια για την έκδοση 3 (v3) του Exercism. Το να ετοιμάσουμε όλες τις διαδρομές για τη v3 θα είναι μια μεγάλη κοινοτική προσπάθεια, και θέλουμε να προσθέσουμε περισσότερους συντηρητές για να επιβλέπουν και να διαχειρίζονται αυτό το έργο.

Στην προσπάθεια για τη v3, οι συντηρητές μας θα είναι υπεύθυνοι για:
- **Σχεδιασμό της διαδρομής:** Να καθορίζεις τι χρειάζεται να μάθει κάποιος για να αποκτήσει άνεση σε μια γλώσσα και να το αποτυπώνεις ως μονοπάτι.
- **Λήψη αποφάσεων:** Να λαμβάνεις αποφάσεις σχεδιασμού για τα εργαλεία που χρησιμοποιεί η διαδρομή, τα πρότυπα με τα οποία συμμορφώνεται, τις προεπιλογές που χρησιμοποιεί κ.λπ.
- **Ενθάρρυνση και υποστήριξη συνεισφορών:** Να δημιουργείς ένα φιλόξενο περιβάλλον για ανθρώπους που θέλουν να βοηθήσουν, να απαντάς στις ερωτήσεις τους κ.λπ.
- **Έλεγχο PR:** Μεγάλο μέρος της πραγματικής δουλειάς για την ανάπτυξη των διαδρομών v3 θα γίνει από την κοινότητα. Οι συντηρητές λειτουργούν ως φύλακες, ελέγχοντας τη δουλειά που κάνει η κοινότητα και διασφαλίζοντας ότι τηρούνται τα πρότυπα της διαδρομής.

Όλα αυτά μπορεί να ακούγονται λίγο τρομακτικά, αλλά με τη δουλειά μοιρασμένη σε μια ομάδα συντηρητών, ο καθένας μπορεί να κάνει τα κομμάτια για τα οποία νιώθει καλύτερα προετοιμασμένος. Οι πιο έμπειροι συντηρητές μας θα σε βοηθήσουν επίσης να ξεκινήσεις και θα σε πάρουν από το χέρι όσο μαθαίνεις τα κατατόπια.

Για να μπορείς να ανταποκριθείς στον ρόλο, θα πρέπει:
- Να μπορείς να αφιερώνεις κατά μέσο όρο 3 ώρες την εβδομάδα (κατά προτίμηση μοιρασμένες μέσα στην εβδομάδα) για περίπου 6 μήνες. Ξέρουμε όμως ότι η ζωή έχει σκαμπανεβάσματα, οπότε καταλαβαίνουμε απόλυτα ότι κάποιες εβδομάδες μπορεί να είναι καλύτερες από άλλες για να συνεισφέρεις.
- Να έχεις χρησιμοποιήσει το Exercism.
- Κατά προτίμηση να έχεις συνεισφέρει στο Exercism, είτε ως μέντορας είτε συνεισφέροντας στη βάση κώδικα. Αν και δεν είναι απολύτως απαραίτητο, βλέπουμε ότι οι συντηρητές μας απολαμβάνουν περισσότερο τη διαδικασία αν έχουν ήδη κάποια εμπειρία με το Exercism.

Οι συντηρητές είναι εθελοντές, άρα δεν πληρώνονται. Το βασικό κίνητρο ιδανικά θα είναι να θέλεις να βοηθήσεις ανθρώπους να αναπτύξουν τις προγραμματιστικές τους δεξιότητες και να βοηθήσεις έναν μη κερδοσκοπικό οργανισμό. Το να είσαι συντηρητής στο Exercism είναι επίσης μια εξαιρετική ευκαιρία να δουλέψεις με άλλους έξυπνους ανθρώπους, να μάθεις περισσότερα για τη γλώσσα της επιλογής σου και να αποκτήσεις δεξιότητες και εμπειρία που είναι χρήσιμες για να εξελίξεις την καριέρα σου προς την τεχνική ηγεσία. Επίσης, φαίνεται αρκετά καλό στο βιογραφικό.

Αν ενδιαφέρεσαι να γίνεις συντηρητής, θα χαρούμε πολύ να επικοινωνήσεις μαζί μας. Υπάρχει ένα issue στο GitHub για κάθε ενεργή διαδρομή, όπου μπορείς να αφήσεις ένα σχόλιο για να συστηθείς. Μπορείς να βρεις μια [λίστα με τα issues εδώ](https://github.com/exercism/exercism/issues/5161).
