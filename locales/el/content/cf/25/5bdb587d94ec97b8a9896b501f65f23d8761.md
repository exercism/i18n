# Μέθοδοι συμβολοσειρών

Η `String` έχει αρκετές μεθόδους που μπορούν να χρησιμοποιηθούν για τον χειρισμό συμβολοσειρών.
Αυτές οι μέθοδοι καλούνται πάνω στην ίδια τη συμβολοσειρά και συχνά αλυσιδώνονται μεταξύ τους για να εκτελέσουν πολλαπλές πράξεις σε μια συμβολοσειρά.

Ακολουθεί μια λίστα με μερικές από τις πιο συνηθισμένες μεθόδους.
Δες την [τεκμηρίωση του API της `String`][string-api] για μια πλήρη λίστα μεθόδων.

## String#upcase & String#downcase

Η μέθοδος [`upcase`][upcase] επιστρέφει μια νέα συμβολοσειρά με όλους τους χαρακτήρες μετατρεπόμενους σε κεφαλαία.

```crystal
"hello".upcase
# => "HELLO"
```

Η μέθοδος [`downcase`][downcase] επιστρέφει μια νέα συμβολοσειρά με όλους τους χαρακτήρες μετατρεπόμενους σε πεζά.

```crystal
"HELLO".downcase
# => "hello"
```

## String#capitalize & String#camelcase & String#underscore & String#titleize

Αρκετές μέθοδοι μπορούν να κάνουν πιο συγκεκριμένες μετατροπές πεζών/κεφαλαίων.
Αυτό μπορεί να είναι χρήσιμο όταν μετατρέπεις μια συμβολοσειρά σε ένα συγκεκριμένο μορφότυπο.
Ακολουθεί μια λίστα με μερικές από τις πιο συνηθισμένες μεθόδους:

| Μέθοδος                          | Περιγραφή                                                                                                          | Παράδειγμα                                           |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------- |
| [`String#capitalize`][capitalize] | Μετατρέπει το πρώτο γράμμα σε κεφαλαίο και τα υπόλοιπα σε πεζά                                                     | `"hEllO" # => "Hello"`                               |
| [`String#camelcase`][camel-case]  | Μετατρέπει την κάτω παύλα σε μορφή camelCase                                                                       | `"eiffel_tower" # => "EiffelTower"`                  |
| `String#camelcase(lower: true)`   | Ίδιο με το String#camelcase, αλλά αφήνει τον πρώτο χαρακτήρα πεζό                                                  | `"empire_state_building" # => "empireStateBuilding"` |
| [`String#underscore`][underscore] | Μετατρέπει όλους τους χαρακτήρες σε πεζούς και τοποθετεί μια κάτω παύλα ανάμεσα σε ένα πεζό και ένα κεφαλαίο γράμμα | `"PartyInTheUSA" # => "party_in_the_usa"`            |
| [`String#titleize`][titleize]     | Κεφαλαιοποιεί το πρώτο γράμμα κάθε λέξης και μετατρέπει τα υπόλοιπα σε πεζά                                         | `"the great gatsBY" # => "The Great Gatsby"`         |

## String#sub & String#gsub

Η Crystal έχει μεθόδους για την αντικατάσταση τμημάτων μιας συμβολοσειράς.
Αυτές είναι οι [`sub`][sub] (_αντικατάσταση_) και [`gsub`][gsub] (_καθολική αντικατάσταση_).

Αυτές οι μέθοδοι μπορούν να πάρουν ως πρώτο όρισμα μια συμβολοσειρά, έναν χαρακτήρα ή μια κανονική έκφραση, και ως δεύτερο όρισμα μια συμβολοσειρά ή έναν χαρακτήρα.
Το πρώτο όρισμα είναι το τμήμα της συμβολοσειράς που θα αντικατασταθεί, και το δεύτερο όρισμα είναι η αντικατάσταση.
Ο `Char` και οι κανονικές εκφράσεις θα εξηγηθούν σε επόμενες έννοιες.

Η μέθοδος `sub` αντικαθιστά την πρώτη εμφάνιση του πρώτου ορίσματος με το δεύτερο όρισμα.

```crystal
"hello".sub("l", "r")
# => "herlo"
```

Η μέθοδος `gsub` λειτουργεί όπως η `sub`, αλλά αντικαθιστά όλες τις εμφανίσεις του πρώτου ορίσματος με το δεύτερο όρισμα.

```crystal
"hello".gsub("l", "r")
# => "herro"
```

## String#chomp & String#strip

Οι chomp και strip μπορούν να χρησιμοποιηθούν για να αφαιρέσεις ανεπιθύμητους χαρακτήρες από μια συμβολοσειρά.

Η μέθοδος [`chomp`][chomp] αφαιρεί από προεπιλογή τους τελευταίους χαρακτήρες `\r`, `\n` ή `\r\n` από μια συμβολοσειρά.
Αν η μέθοδος κληθεί με ένα όρισμα, θα αφαιρέσει τη δεδομένη τιμή από το τέλος της συμβολοσειράς.
Αν αυτή υπάρχει στο τέλος της συμβολοσειράς.

```crystal
"hello\n".chomp
# => "hello"

"hello".chomp("llo")
# => "he"
```

Από προεπιλογή, η μέθοδος [`strip`][strip] αφαιρεί όλα τα κενά από την αρχή και το τέλος μιας συμβολοσειράς.
Αν η μέθοδος κληθεί με ένα όρισμα, θα αφαιρέσει αυτό το όρισμα από την αρχή και το τέλος της συμβολοσειράς.
Αν αυτό υπάρχει στην αρχή ή στο τέλος της συμβολοσειράς.

```crystal
" hello ".strip
# => "hello"
```

## String#reverse

Μπορείς να χρησιμοποιήσεις τη μέθοδο [`reverse`][reverse] για να αντιστρέψεις μια συμβολοσειρά.
Αυτή η μέθοδος επιστρέφει μια νέα συμβολοσειρά με τους χαρακτήρες σε αντίστροφη σειρά.

```crystal
"hello".reverse
# => "olleh"
```

## String#index

Η μέθοδος [`index`][index] μπορεί να χρησιμοποιηθεί για να βρεις τη θέση ενός χαρακτήρα σε μια συμβολοσειρά.
Η μέθοδος `index` δέχεται ως όρισμα μια `String`, ένα `Char` ή μια κανονική έκφραση.
Μπορεί να δεχτεί και ένα προαιρετικό δεύτερο όρισμα που καθορίζει τη θέση από την οποία θα γίνει η αναζήτηση.
Η μέθοδος `index` επιστρέφει τη θέση της πρώτης εμφάνισης του ορίσματος.

```crystal
"hello".index("l")
# => 2

"hello".index("l", 3)
# => 3
```

## String#delete_at

Μπορείς να χρησιμοποιήσεις τη μέθοδο [`delete_at`][delete_at] για να αφαιρέσεις έναν χαρακτήρα από μια συμβολοσειρά.
Η μέθοδος `delete_at` δέχεται ως όρισμα μια θέση και αφαιρεί τον χαρακτήρα σε αυτή τη θέση.

```crystal
"hello".delete_at(0)
# => "ello"

"hello".delete_at(3)
# => "helo"
```

## String#insert

Η μέθοδος [`insert`][insert] μπορεί να χρησιμοποιηθεί για να εισαγάγεις μια συμβολοσειρά σε μια συγκεκριμένη θέση.
Η μέθοδος `insert` δέχεται ως πρώτο όρισμα μια θέση και ως δεύτερο όρισμα μια συμβολοσειρά.
Η μέθοδος `insert` επιστρέφει μια νέα συμβολοσειρά με το δεύτερο όρισμα εισαγμένο σε αυτή τη θέση.

```crystal
"hello".insert(0, "h")
# => "hhello"

"hello".insert(3, "l")
# => "helllo"
```
