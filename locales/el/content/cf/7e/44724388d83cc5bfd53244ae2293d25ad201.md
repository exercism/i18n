# Εισαγωγή

Μια συνάρτηση σου επιτρέπει να ομαδοποιήσεις κώδικα σε μια επαναχρησιμοποιήσιμη μονάδα.
Αποτελείται από τη λέξη-κλειδί `func`, το όνομα της συνάρτησης και μια λίστα από μηδέν ή περισσότερες παραμέτρους και τύπους, χωρισμένες με κόμμα, μέσα σε παρενθέσεις.

## Παράμετροι συνάρτησης

Όλες οι παράμετροι πρέπει να έχουν ρητά τον τύπο τους· δεν υπάρχει εξαγωγή τύπου για τις παραμέτρους.
Δεν υπάρχουν προεπιλεγμένες τιμές για τις παραμέτρους, οπότε όλες οι παράμετροι μιας συνάρτησης είναι υποχρεωτικές.

```go
import "fmt"

// No parameters
func PrintHello() {
    fmt.Println("Hello")
}

// One parameter
func PrintHelloName(name string) {
  fmt.Println("Hello " + name)
}
```

Παράμετροι του ίδιου τύπου μπορούν να δηλωθούν μαζί, ακολουθούμενες από μία μόνο δήλωση τύπου.

```go
import "fmt"

func PrintGreetingName(greeting, name string) {
  fmt.Println(greeting + " " + name)
}
```

## Παράμετροι εναντίον ορισμάτων

Ας καλύψουμε γρήγορα δύο όρους που συχνά μπερδεύονται μεταξύ τους: `parameters` και `arguments`.
Οι παράμετροι μιας συνάρτησης είναι τα ονόματα που ορίζονται στην υπογραφή της συνάρτησης, όπως τα `greeting` και `name` στη συνάρτηση `PrintGreetingName` παραπάνω.
Τα ορίσματα μιας συνάρτησης είναι οι συγκεκριμένες τιμές που περνιούνται στις παραμέτρους της συνάρτησης όταν καλούμε τη συνάρτηση.
Για παράδειγμα, στο παρακάτω παράδειγμα, τα `"Hello"` και `"Katrina"` είναι τα ορίσματα που περνιούνται στις παραμέτρους `greeting` και `name`:

```go
PrintGreetingName("Hello", "Katrina")
```

## Τιμές επιστροφής

Οι παράμετροι της συνάρτησης ακολουθούνται από μηδέν ή περισσότερες τιμές επιστροφής, οι οποίες πρέπει επίσης να έχουν ρητά τον τύπο τους.
Οι μεμονωμένες τιμές επιστροφής γράφονται σκέτες, ενώ οι πολλαπλές τιμές επιστροφής περικλείονται σε παρενθέσεις.
Οι τιμές επιστρέφονται στον κώδικα που κάλεσε τη συνάρτηση με τη λέξη-κλειδί `return`.
Μπορεί να υπάρχουν πολλαπλές εντολές `return` μέσα σε μια συνάρτηση.
Η εκτέλεση της συνάρτησης τελειώνει μόλις συναντήσει μία από αυτές τις εντολές `return`.
Αν μια συνάρτηση πρόκειται να επιστρέψει πολλαπλές τιμές, αυτές χωρίζονται με κόμμα.

```go
func Hello(name string) string {
  return "Hello " + name
}

func HelloAndGoodbye(name string) (string, string) {
  return "Hello " + name, "Goodbye " + name
}
```

## Κλήση συναρτήσεων

Η κλήση μιας συνάρτησης γίνεται γράφοντας το όνομα της συνάρτησης και περνώντας ορίσματα για κάθε παράμετρο της συνάρτησης μέσα σε παρενθέσεις.

```go
import "fmt"

// No parameters, no return value
func PrintHello() {
    fmt.Println("Hello")
}
// Called like this:
PrintHello()

// One parameter, one return value
func Hello(name string) string {
  return "Hello " + name
}
// Called like this:
greeting := Hello("Dave")

// Multiple parameters, multiple return values
func SumAndMultiply(a, b int) (int, int) {
    return a+b, a*b
}
// Called like this:
aplusb, atimesb := SumAndMultiply(a, b)
```

## Ονομαστικές τιμές επιστροφής και γυμνή επιστροφή

Όπως και οι παράμετροι, έτσι και οι τιμές επιστροφής μπορούν προαιρετικά να έχουν όνομα.
Αν χρησιμοποιηθούν ονομαστικές τιμές επιστροφής, μια εντολή `return` χωρίς ορίσματα θα επιστρέψει αυτές τις τιμές.
Αυτό είναι γνωστό ως "γυμνή" επιστροφή.

```go
func SumAndMultiplyThenMinus(a, b, c int) (sum, mult int) {
    sum, mult = a+b, a*b
    sum -= c
    mult -= c
    return
}
```
