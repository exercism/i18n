# Εισαγωγή

Μερικές φορές ένα κομμάτι κατάστασης πρέπει να μοιράζεται ανάμεσα σε πολλές λέξεις, χωρίς να το περνάς κάθε φορά μέσα από τα stack effects τους. Οι *δυναμικές μεταβλητές* της Factor, που δηλώνονται με `SYMBOL:`, δίνουν σε κάθε λέξη πρόσβαση σε μια τιμή που είναι αποθηκευμένη σε έναν χώρο ονομάτων.

## `SYMBOL:` και `SYMBOLS:`

Το `SYMBOL: name` δηλώνει μία μεταβλητή. Το `SYMBOLS: a b c ;` δηλώνει πολλές μαζί:

```factor
USING: namespaces ;

SYMBOLS: counter total ;
```

## Ορισμός και ανάγνωση

Τα `set-global` και `get-global` (στο [`namespaces`][namespaces]) λειτουργούν στον καθολικό χώρο ονομάτων:

```
set-global    ( value variable -- )
get-global    ( variable -- value )
change-global ( variable quot: ( old -- new ) -- )
```

```factor
0 counter set-global
counter get-global .         ! => 0
counter [ 10 + ] change-global
counter get-global .         ! => 10
```

Για κατάσταση σε επίπεδο module, οι εκδοχές `-global` είναι αυτές που χρειάζεσαι.

## Δεσμεύσεις με εμβέλεια με το `with-variable`

Μια δυναμική μεταβλητή υποστηρίζει επίσης μια δεύτερη εκδοχή, *με εμβέλεια*. Τα `set` / `get` / `change` (χωρίς την κατάληξη `-global`) διαβάζουν και γράφουν την *τρέχουσα* δυναμική εμβέλεια, και το `with-variable` (στο [`namespaces`][namespaces]) δημιουργεί μια νέα εμβέλεια όσο διαρκεί μια παράθεση:

```
with-variable ( value variable quot -- )
set           ( value variable -- )
get           ( variable -- value )
change        ( variable quot: ( old -- new ) -- )
```

Η μεταβλητή είναι δεσμευμένη στην `value` όσο εκτελείται η `quot`; μόλις αυτή επιστρέψει, η δέσμευση εξαφανίζεται. Αυτό επιτρέπει σε έναν εξωτερικό καλούντα να "εισάγει" μια τιμή που ο εσωτερικός κώδικας μπορεί να διαβάσει, χωρίς να την περνά μέσα από κάθε stack signature.

```factor
SYMBOL: greeting

"Hello" greeting [
    greeting get .                ! => "Hello"
    "Howdy" greeting set
    greeting get .                ! => "Howdy"
    greeting [ "!" append ] change
    greeting get .                ! => "Howdy!"
] with-variable

greeting get-global .    ! => f   (the scoped binding is gone)
```

Αυτή η άσκηση χρησιμοποιεί την καθολική εκδοχή σε όλη τη διάρκεια, αλλά το να αναγνωρίζεις την παράλληλη οικογένεια `set`/`get`/`change` είναι χρήσιμο όταν διαβάζεις κώδικα άλλων.

## Μεταβλητά διανύσματα

Επειδή οι δυναμικές μεταβλητές κρατούν μια αναφορά, μπορείς να κρατάς μια *μεταβλητή* συλλογή μέσα σε μία από αυτές και να την ενημερώνεις επιτόπου:

```factor
SYMBOL: history

V{ } clone history set-global
"first event" history get-global push
"second event" history get-global push
history get-global .
! => V{ "first event" "second event" }
```

Το `V{ … }` είναι ένα literal διάνυσμα. Πάντα να κάνεις `clone` σε ένα literal `V{ }` πριν το αποθηκεύσεις: τα literals μοιράζονται μεταξύ των κλήσεων.

## `find`, το πρώτο ταίριασμα

Το `find` (στο [`sequences`][sequences]) επιστρέφει το πρώτο στοιχείο για το οποίο ένα κατηγόρημα είναι αληθές, μαζί με τη θέση του:

```
find ( seq quot -- index elt/f )
```

Αν δεν ταιριάζει τίποτα, και οι δύο τιμές είναι `f`. Το να πετάξεις τη θέση με το `nip` και να χρησιμοποιήσεις το `unless*` είναι ο καθιερωμένος συνδυασμός για "προεπιλογή αν λείπει".

## `reject`, πέταξε τα ταιριάσματα

Το `reject` (επίσης στο [`sequences`][sequences]) είναι το αντίθετο του `filter`: επιστρέφει τα στοιχεία που *αποτυγχάνουν* στο κατηγόρημα.
