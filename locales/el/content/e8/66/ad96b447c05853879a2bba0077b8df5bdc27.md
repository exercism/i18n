# Εισαγωγή

## Try/Rescue/Else/After

Η χρήση του `try..rescue` είναι ένα ισχυρό κατασκεύασμα για τη σύλληψη σφαλμάτων όταν προκύπτουν. Η σύλληψη σφαλμάτων επιτρέπει στις συναρτήσεις να επιστρέφουν καθορισμένες τιμές όταν είναι απαραίτητο. Το κατασκεύασμα `try..rescue` μας προσφέρει επίσης δύο επιπλέον δυνατότητες που μπορούμε να αξιοποιήσουμε:

- το μπλοκ `else`
  - Όταν το μπλοκ try πετύχει, το αποτέλεσμα αντιστοιχίζεται σε αυτό το μπλοκ.
- το μπλοκ `after`
  - Είτε το μπλοκ try πετύχει είτε πετάξει σφάλμα, ο κώδικας στο μπλοκ `after` εκτελείται πάντα, εφόσον το πρόγραμμα εκτελείται ακόμη εκείνη τη στιγμή.
  - Το αποτέλεσμα του μπλοκ `after` δεν επιστρέφεται στην εμβέλεια κλήσης.

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```

## Δυναμική αποστολή

Όταν η Elixir προσδιορίζει ποια συνάρτηση θα κληθεί, χρησιμοποιεί το όνομα του Module για να κάνει μια αναζήτηση. Η αναζήτηση μπορεί να γίνει δυναμικά αν το όνομα του Module είναι δεσμευμένο σε μια μεταβλητή.

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```

Εσωτερικά, το όνομα ενός Module είναι ένα atom. Όλα τα atom των Module της Elixir παίρνουν αυτόματα πρόθεμα `Elixir.`

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```
