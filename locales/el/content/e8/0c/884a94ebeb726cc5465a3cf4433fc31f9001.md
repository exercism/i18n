# Εισαγωγή

## Εντολές υπό συνθήκη If

### Λογικοί τελεστές

Η Java υποστηρίζει τους τρεις λογικούς τελεστές `&&` (AND), `||` (OR) και `!` (NOT).

### Εντολή `if`

Ο υποκείμενος τύπος κάθε πράξης υπό συνθήκη είναι ο τύπος `boolean`, ο οποίος μπορεί να έχει την τιμή `true` ή `false`. Οι συνθήκες χρησιμοποιούνται συχνά ως μηχανισμοί ελέγχου ροής για τον έλεγχο διάφορων περιπτώσεων. Για τον έλεγχο μιας συγκεκριμένης περίπτωσης μπορεί να χρησιμοποιηθεί μια εντολή `if`, η οποία εκτελεί τον κώδικά της αν η υποκείμενη συνθήκη είναι `true`, όπως εδώ:

```java
int val;

if(val == 9) {
    // conditional code
}
```

Σε σενάρια με περισσότερες από μία περιπτώσεις, πολλές εντολές `if` μπορούν να συνδυαστούν σε αλυσίδα χρησιμοποιώντας τις εντολές `else if` και `else`.

```java
if(val == 10) {
    // conditional code
} else if(val == 17) {
    // conditional code
} else {
    // executes when val is different from 10 and 17
}
```

### Εντολή `switch`

Η Java παρέχει επίσης μια εντολή `switch` για σενάρια με πολλαπλές επιλογές.

```java
int val;

// switch statement on variable content
switch(val) {
    case 1:
        // conditional code
        break;
    case 2: case 3: case 4:
        // conditional code
        break;
    default:
        // if all cases fail
        break;
}
```
