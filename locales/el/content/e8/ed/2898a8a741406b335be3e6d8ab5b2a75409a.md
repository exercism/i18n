# Εισαγωγή

Οι εντολές υπό συνθήκη της Factor επιλέγουν ανάμεσα σε **quotations**: αποσπάσματα κώδικα γραμμένα σε αγκύλες, `[ ... ]`. Γράφοντας `[ ... ]` σπρώχνεις τον κώδικα στη στοίβα ως τιμή αντί να τον τρέξεις· η εντολή υπό συνθήκη αποφασίζει μετά ποιο quotation θα τρέξει. (Τα quotations καλύπτονται πλήρως σε μια επόμενη άσκηση.)

Το `if` (στο [`kernel`][kernel]) είναι η βασική εντολή υπό συνθήκη της Factor. Παίρνει ένα boolean και δύο quotations, τρέχοντας το πρώτο αν το boolean είναι αληθές και το δεύτερο σε αντίθετη περίπτωση.

```
if ( ? then-quot else-quot -- )
```

```factor
: abs ( x -- y ) dup 0 < [ neg ] [ ] if ;
```

Το `when` τρέχει το quotation του μόνο όταν το boolean είναι αληθές, και το `unless` μόνο όταν είναι ψευδές. Για διακλαδώσεις με πολλές περιπτώσεις υπάρχει το `cond` (στο [`combinators`][combinators]):

```factor
USING: combinators ;

: classify ( n -- s )
    {
        { [ dup 0 <  ] [ drop "negative" ] }
        { [ dup 0 =  ] [ drop "zero"     ] }
        [ drop "positive" ]
    } cond ;
```
