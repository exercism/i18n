# Σχετικά

Τα Boolean στο Rust αναπαρίστανται από τον τύπο `bool`, του οποίου οι τιμές μπορούν να είναι είτε `true` είτε `false`.

Η Rust υποστηρίζει έναν [τελεστή άρνησης Boolean][negation operators]: `!` (Όχι).

Η Rust υποστηρίζει έξι [τελεστές σύγκρισης][comparison operators]: `==` (Ίσο), `!=` (Άνισο), `>` (Μεγαλύτερο από), `<` (Μικρότερο από), `>=` (Μεγαλύτερο ή ίσο με), `<=` (Μικρότερο ή ίσο με). Μπορούν να χρησιμοποιηθούν για να αξιολογήσουν τη σχέση μη Boolean τιμών σε μια Boolean τιμή.

```rust
1 > 0 // true
1 < 0 // false
1 == 0 // false
1 != 0 // true
1 >= 0 // true
1 <= 0 // false
```

Σε αντίθεση με κάποιες άλλες γλώσσες, το `0` δεν είναι `false` και μια μη μηδενική τιμή δεν είναι `true`.

Η Rust υποστηρίζει τρεις [λογικούς δυαδικούς τελεστές][logical binary operators]: `&` (Λογικό ΚΑΙ), `|` (Λογικό Ή), `^` (Λογικό αποκλειστικό Ή).

Η Rust υποστηρίζει δύο [τελεστές Boolean][lazy boolean operators]: `||` (Ή), `&&` (ΚΑΙ). Διαφέρουν από τους `|` και `&` στο ότι ο δεξιά τελεστέος αξιολογείται μόνο όταν ο αριστερός τελεστέος δεν καθορίζει ήδη το αποτέλεσμα της έκφρασης. Δηλαδή, ο `||` αξιολογεί τον δεξιό τελεστέο του μόνο όταν ο αριστερός τελεστέος αξιολογείται σε `false`, και ο `&&` μόνο όταν αξιολογείται σε `true`.

```rust
true || false // == true; the right-hand side was not evaluated
true && false // == false
```
