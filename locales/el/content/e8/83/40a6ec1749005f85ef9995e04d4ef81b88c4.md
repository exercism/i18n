# Προσθήκη στις οδηγίες

## Καταχωρητές

| Καταχωρητής | Χρήση     | Τύπος   | Περιγραφή                             |
| -------- | --------- | ------- | ------------------------------------- |
| `$a0`    | είσοδος   | address | συμβολοσειρά οκταδικών χαρακτήρων που τερματίζεται με null |
| `$v0`    | έξοδος    | integer | δεκαδική τιμή της συμβολοσειράς εισόδου |
| `$t0-9`  | προσωρινός | any     | χρησιμοποιείται για προσωρινή αποθήκευση |
