# Οδηγίες

Σε αυτή την άσκηση πρέπει να υλοποιήσεις μερικές συναρτήσεις για να χειρίζεσαι μια λίστα με γλώσσες προγραμματισμού.

## 1. Όρισε μια συνάρτηση που επιστρέφει μια κενή λίστα γλωσσών

Όρισε τη συνάρτηση `new/0` που δεν παίρνει ορίσματα και επιστρέφει μια κενή λίστα.

```elixir
LanguageList.new()
# => []
```

## 2. Όρισε μια συνάρτηση που προσθέτει μια γλώσσα στη λίστα

Όρισε τη συνάρτηση `add/2` που παίρνει 2 ορίσματα (μια _λίστα γλωσσών_ και μια συμβολοσειρά που αντιπροσωπεύει μια _γλώσσα_). Θα πρέπει να επιστρέφει τη λίστα που προκύπτει, με τη νέα γλώσσα να προστίθεται στην αρχή της δεδομένης λίστας.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Clojure")
# => ["Clojure"]
language_list = LanguageList.add(language_list, "Haskell")
# => ["Haskell", "Clojure"]
```

## 3. Όρισε μια συνάρτηση που αφαιρεί μια γλώσσα από τη λίστα

Όρισε τη συνάρτηση `remove/1` που παίρνει 1 όρισμα (μια _λίστα γλωσσών_). Θα πρέπει να επιστρέφει τη λίστα χωρίς το πρώτο στοιχείο. Υπόθεσε ότι η λίστα θα έχει πάντα τουλάχιστον ένα στοιχείο.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Clojure")
# => ["Clojure"]
language_list = LanguageList.add(language_list, "Haskell")
# => ["Haskell", "Clojure"]
language_list = LanguageList.remove(language_list)
# => ["Clojure"]
```

## 4. Όρισε μια συνάρτηση που επιστρέφει το πρώτο στοιχείο της λίστας

Όρισε τη συνάρτηση `first/1` που παίρνει 1 όρισμα (μια _λίστα γλωσσών_). Θα πρέπει να επιστρέφει την πρώτη γλώσσα στη λίστα. Υπόθεσε ότι η λίστα θα έχει πάντα τουλάχιστον ένα στοιχείο.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elm")
# => ["Elm"]
language_list = LanguageList.add(language_list, "Prolog")
# => ["Prolog", "Elm"]
LanguageList.first(language_list)
# => "Prolog"
```

## 5. Όρισε μια συνάρτηση που επιστρέφει πόσες γλώσσες υπάρχουν στη λίστα

Όρισε τη συνάρτηση `count/1` που παίρνει 1 όρισμα (μια _λίστα γλωσσών_). Θα πρέπει να επιστρέφει τον αριθμό των γλωσσών στη λίστα.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elm")
# => ["Elm"]
language_list = LanguageList.add(language_list, "Prolog")
# => ["Prolog", "Elm"]
LanguageList.count(language_list)
# => 2
```

## 6. Όρισε μια συνάρτηση που προσδιορίζει αν η λίστα περιλαμβάνει μια συναρτησιακή γλώσσα

Όρισε τη συνάρτηση `functional_list?/1` που παίρνει 1 όρισμα (μια _λίστα γλωσσών_). Θα πρέπει να επιστρέφει μια τιμή Boolean. Θα πρέπει να επιστρέφει την τιμή αληθής αν η _"Elixir"_ είναι μία από τις γλώσσες στη λίστα.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elixir")
# => ["Elixir"]
LanguageList.functional_list?(language_list)
# => true
```
