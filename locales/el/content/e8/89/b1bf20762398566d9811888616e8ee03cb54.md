# Οδηγίες

Υλοποίησε ένα RESTful API για την παρακολούθηση οφειλών.

Τέσσερις συγκάτοικοι έχουν τη συνήθεια να δανείζονται συχνά χρήματα ο ένας από τον άλλον και δυσκολεύονται να θυμούνται ποιος χρωστάει σε ποιον και πόσα.

Η αποστολή σου είναι να υλοποιήσεις ένα απλό [RESTful API][restful-wikipedia] που δέχεται [οφειλές][iou] ως αιτήματα POST και μπορεί να παρέχει συγκεκριμένες συνοπτικές πληροφορίες μέσω αιτημάτων GET.

## Προδιαγραφή API

### Αντικείμενο χρήστη

```json
{
  "name": "Adam",
  "owes": {
    "Bob": 12.0,
    "Chuck": 4.0,
    "Dan": 9.5
  },
  "owed_by": {
    "Bob": 6.5,
    "Dan": 2.75
  },
  "balance": "<(total owed by other users) - (total owed to other users)>"
}
```

### Μέθοδοι

| Περιγραφή                 | Μέθοδος HTTP | URL    | Μορφή payload                                                             | Απόκριση χωρίς payload                 | Απόκριση με payload                                                             |
| ------------------------- | ------------ | ------ | ------------------------------------------------------------------------- | -------------------------------------- | ------------------------------------------------------------------------------- |
| Λίστα πληροφοριών χρηστών | GET          | /users | `{"users":["Adam","Bob"]}`                                                | `{"users":<List of all User objects>}` | `{"users":<List of User objects for <users> (sorted by name)}`                  |
| Δημιουργία χρήστη         | POST         | /add   | `{"user":<name of new user (unique)>}`                                    | N/A                                    | `<User object for new user>`                                                    |
| Δημιουργία οφειλής        | POST         | /iou   | `{"lender":<name of lender>,"borrower":<name of borrower>,"amount":5.25}` | N/A                                    | `{"users":<updated User objects for <lender> and <borrower> (sorted by name)>}` |
