# έχει σφάλματα μεταγλώττισης

Ο κώδικας έχει ένα ή περισσότερα σφάλματα μεταγλώττισης, που εμποδίζουν την εκτέλεση της σουίτας δοκιμών. Ένα καλό πρώτο βήμα για να βρεις πώς να διορθώσεις το σφάλμα (ή τα σφάλματα) είναι να εξετάσεις τα μηνύματα σφάλματος που εμφανίζονται όταν προσπαθείς να μεταγλωττίσεις τον κώδικα. Αυτά τα μηνύματα σφάλματος περιέχουν έναν αριθμό σφάλματος και μια περιγραφή, που σε βοηθούν να εντοπίσεις ποιο είναι το ακριβές πρόβλημα.
