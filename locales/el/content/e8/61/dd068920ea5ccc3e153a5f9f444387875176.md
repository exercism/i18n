# Σχετικά

Ένας [`while` βρόχος][while-loops] είναι μια εντολή ροής ελέγχου που επιτρέπει την εκτέλεση κώδικα όσο μια συγκεκριμένη συνθήκη είναι αληθής.
Η Swift παρέχει δύο είδη βρόχων `while`: τους βρόχους `while` και `repeat-while`.
Η συνθήκη του βρόχου `while` αξιολογείται πριν εκτελεστεί το σώμα του βρόχου· αν η συνθήκη είναι ψευδής, το σώμα του βρόχου δεν θα εκτελεστεί καθόλου.
Οι βρόχοι `while` στη Swift έχουν την εξής δομή:

```swift
while <#condition#> {
  <#code#>
}
```

Εδώ ο βρόχος θα εκτελεστεί όσο το count είναι μεγαλύτερο από το 0 και έτσι θα εκτυπώσει τους αριθμούς 2, 1 και "Liftoff!".

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

Ένας [`repeat-while` βρόχος][while-loops] είναι παρόμοιος με έναν βρόχο `while`, αλλά η συνθήκη αξιολογείται αφού εκτελεστεί το σώμα του βρόχου.
Αυτό σημαίνει ότι το σώμα του βρόχου θα εκτελεστεί πάντα τουλάχιστον μία φορά, ακόμη και αν η συνθήκη είναι ψευδής.
Οι βρόχοι `repeat-while` στη Swift έχουν την εξής δομή:

```swift
repeat {
  <#code#>
} while <#condition#>
```

Εδώ ο βρόχος θα εκτελεστεί μόνο μία φορά, αφού η συνθήκη είναι ψευδής.
Επειδή πρόκειται για βρόχο `repeat-while`, το σώμα του βρόχου θα εκτελεστεί μία φορά πριν αξιολογηθεί η συνθήκη.

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```

## Βρόχοι προαιρετικής δέσμευσης

Μια συνηθισμένη παραλλαγή των βρόχων `while` στη Swift είναι ο βρόχος `while` με προαιρετική δέσμευση.
Αυτοί οι βρόχοι επαναλαμβάνονται όσο η κλήση σε κάποια συνάρτηση που παράγει μια προαιρετική τιμή επιστρέφει μια τιμή που δεν είναι `nil`.
Αυτή η τιμή (η οποία δεν είναι προαιρετική) δεσμεύεται τότε σε ένα όνομα της επιλογής σου και μπορεί να χρησιμοποιηθεί στο σώμα του βρόχου.

```swift
var arr = [1,2]
while let count = arr.popLast() {
  print("\(count)…")
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```
