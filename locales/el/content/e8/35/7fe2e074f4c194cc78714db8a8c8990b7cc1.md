# Υποδείξεις

## Γενικά

- Μια [ακέραια τιμή (`Int`)][numbers] μπορεί να οριστεί ως ένα ή περισσότερα συνεχόμενα ψηφία.
- Χρησιμοποίησε μεταβλητές για να δώσεις ωραία και ευανάγνωστα ονόματα στις τιμές σου. Θυμήσου ότι η αναγνωσιμότητα του κώδικα είναι πολύ πιο σημαντική από τον αριθμό των γραμμών κώδικα.

## 1. Υπολόγισε τον χρόνο ψησίματος που απομένει σε λεπτά

- Πρέπει να ορίσεις μια [συνάρτηση][functions] με μία μόνο παράμετρο.
- Πρέπει να εκχωρήσεις μια [προεπιλεγμένη τιμή][function-defaults] στην παράμετρο.
- Πρέπει να επιστρέψεις ρητά μια ακέραια τιμή από μια μέθοδο.
- Η παράμετρος της μεθόδου είναι [ακέραιος][numbers].
- Πρέπει να χρησιμοποιήσεις τον μαθηματικό τελεστή της αφαίρεσης (`-`) για να αφαιρέσεις τιμές.

## 2. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

- Πρέπει να ορίσεις μια [συνάρτηση][functions] με μία μόνο παράμετρο.
- Πρέπει να επιστρέψεις ρητά μια ακέραια τιμή από μια μέθοδο.
- Η παράμετρος της μεθόδου είναι [ακέραιος][numbers].
- Πρέπει να χρησιμοποιήσεις τον μαθηματικό τελεστή της πρόσθεσης (`+`) για να προσθέσεις τιμές.

## 3. Υπολόγισε τον χρόνο που πέρασε σε λεπτά

- Πρέπει να ορίσεις μια [συνάρτηση][functions] με δύο παραμέτρους.
- Πρέπει να εκχωρήσεις μια [προεπιλεγμένη τιμή][function-defaults] στη δεύτερη παράμετρο.
- Πρέπει να επιστρέψεις ρητά μια ακέραια τιμή από μια μέθοδο.
- Η παράμετρος της μεθόδου είναι [ακέραιος][numbers].
- Πρέπει να χρησιμοποιήσεις τον μαθηματικό τελεστή της πρόσθεσης (`+`) για να προσθέσεις τιμές.
- Πρέπει να καλέσεις συναρτήσεις που έχουν ήδη υλοποιηθεί.

[numbers]: https://kotlinlang.org/docs/reference/basic-types.html#numbers
[functions]: https://kotlinlang.org/docs/reference/functions.html#function-declarations
[function-defaults]: https://kotlinlang.org/docs/reference/functions.html#default-arguments
