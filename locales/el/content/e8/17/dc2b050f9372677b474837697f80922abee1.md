# Παράρτημα οδηγιών

## Υλοποίηση

Αν το τελευταίο στοιχείο της λίστας είναι ένα `object` αντί για ένα `string`, θα περιέχει έναν προσδιορισμό που τροποποιεί την τελευταία γραμμή της παροιμίας.

```javascript
proverb('nail', 'shoe', { qualifier: 'horseshoe' });
// => For want of a nail the shoe was lost.
//    And all for the want of a horseshoe nail.
```
