# Υπόλοιπο

Στα μαθηματικά, το **υπόλοιπο** είναι το ποσό που "περισσεύει" μετά από κάποιον υπολογισμό.
Για παράδειγμα, το υπόλοιπο του `5 / 3` είναι `2`.

Πολλές γλώσσες προγραμματισμού χρησιμοποιούν το σύμβολο του ποσοστού (`%`) ως τελεστή για να υπολογίσουν το υπόλοιπο.
Για παράδειγμα:
```javascript
5 % 3 == 2
```

Τα υπόλοιπα μπορούν συχνά να υπολογιστούν τόσο σε ακέραιους όσο και σε αριθμούς κινητής υποδιαστολής.
Για παράδειγμα,
```javascript
5.3 % 3 == 2.3
```

Όταν δουλεύεις με αρνητικούς αριθμούς, το αποτέλεσμα έχει πάντα το ίδιο πρόσημο με τον διαιρετέο (τον αριθμό στα αριστερά που διαιρείται).
Για παράδειγμα:
```javascript
-5 % 3 == -2
5 % -3 == 2
-5 % -3 == -2
```

Κάποιες γλώσσες (όπως η Python) χρησιμοποιούν τον τελεστή `%` για τον υπολογισμό του μέτρου, όχι του υπολοίπου.
Αυτό χειρίζεται τους αρνητικούς αριθμούς διαφορετικά.
Μπορείς να μάθεις περισσότερα γι' αυτό [στη Wikipedia](https://en.wikipedia.org/wiki/Modulo).
