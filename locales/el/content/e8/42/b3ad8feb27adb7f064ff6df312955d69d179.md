- Μπορείς να χρησιμοποιήσεις [μεθόδους συμβολοσειρών][title-method-docs] για να βάλεις σωστά τα κεφαλαία στον τίτλο.

## 2. Έλεγξε αν κάθε πρόταση τελειώνει με τελεία

- Μπορείς να χρησιμοποιήσεις [μεθόδους συμβολοσειρών][endswith-method-docs] για να ελέγξεις το τέλος μιας συμβολοσειράς.

## 3. Καθάρισε τα κενά

- Μπορείς να χρησιμοποιήσεις [μεθόδους συμβολοσειρών][strip-method-docs] για να αφαιρέσεις τα κενά διαστήματα.

## 4. Αντικατέστησε λέξεις με συνώνυμες

- Μπορείς να χρησιμοποιήσεις [μεθόδους συμβολοσειρών][replace-method-docs] για να αντικαταστήσεις λέξεις.
