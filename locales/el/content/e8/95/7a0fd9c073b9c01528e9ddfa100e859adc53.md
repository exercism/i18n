# Εισαγωγή

## Agent

Η μονάδα `Agent` παρέχει μια αφαίρεση για τη δημιουργία [διεργασιών και για τον _βρόχο λήψης-αποστολής_][exercism-processes]. Από εδώ και πέρα, θα ονομάζουμε τις διεργασίες που ξεκινούν χρησιμοποιώντας τη μονάδα `Agent` _'διεργασίες Agent'_. Μπορεί να επιλέξεις μια _διεργασία Agent_ για να αναπαραστήσει μια κεντρική κοινόχρηστη κατάσταση.

Για να ξεκινήσεις μια _διεργασία Agent_, η μονάδα `Agent` παρέχει τη συνάρτηση `start/2`. Η συνάρτηση που παρέχεται όταν _ξεκινάς_ τη _διεργασία Agent_ μέσω της `start` επιστρέφει την αρχική κατάσταση της διεργασίας:

```elixir
# Start an agent process with an initial value of an empty list
{:ok, agent_pid} = Agent.start(fn -> [] end)
```

Όπως ακριβώς το `Map` ή το `List`, η μονάδα `Agent` παρέχει πολλές συναρτήσεις για να δουλεύεις με _διεργασίες Agent_.

Συνηθίζεται να οργανώνεις και να ενθυλακώνεις όλη τη λειτουργικότητα που σχετίζεται με το `Agent` σε μια μονάδα για τον τομέα που μοντελοποιείς.

[exercism-processes]: https://exercism.org/tracks/elixir/concepts/processes
