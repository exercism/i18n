# Οδηγίες

Δουλεύεις σε ένα έργο που επιτρέπει στους χρήστες να ανεβάζουν αρχεία στον διακομιστή για να τα μοιράζονται με άλλους χρήστες. Σου έχει ανατεθεί να γράψεις μια συνάρτηση που επαληθεύει ότι ένα ανεβασμένο αρχείο ταιριάζει με τον [τύπο μέσου][mimetype] του. Κάνεις λίγη έρευνα και ανακαλύπτεις ότι τα πρώτα λίγα bytes ενός αρχείου είναι συνήθως μοναδικά για αυτόν τον τύπο αρχείου, κάτι που του δίνει ένα είδος υπογραφής.

Χρησιμοποίησε τον παρακάτω πίνακα ως αναφορά:

| Τύπος αρχείου | Συνήθης επέκταση | Τύπος μέσου                 | δυαδική 'υπογραφή'                               |
| --------- | ---------------- | ---------------------------- | ------------------------------------------------ |
| ELF       | `"exe"`          | `"application/octet-stream"` | `0x7F, 0x45, 0x4C, 0x46`                         |
| BMP       | `"bmp"`          | `"image/bmp"`                | `0x42, 0x4D`                                     |
| PNG       | `"png"`          | `"image/png"`                | `0x89, 0x50, 0x4E, 0x47, 0x0D, 0x0A, 0x1A, 0x0A` |
| JPG       | `"jpg"`          | `"image/jpg"`                | `0xFF, 0xD8, 0xFF`                               |
| GIF       | `"gif"`          | `"image/gif"`                | `0x47, 0x49, 0x46`                               |

## 1. Δεδομένης μιας επέκτασης, επέστρεψε τον αναμενόμενο τύπο μέσου

Υλοποίησε τη συνάρτηση `type_from_extension/1`. Πρέπει να δέχεται μια επέκταση αρχείου (συμβολοσειρά) και να επιστρέφει τον τύπο μέσου (συμβολοσειρά) ή nil αν η επέκταση δεν ταιριάζει με τις αναμενόμενες.

```elixir
FileSniffer.type_from_extension("exe")
# => "application/octet-stream"

FileSniffer.type_from_extension("txt")
# => nil
```

## 2. Δεδομένου ενός δυαδικού αρχείου, επέστρεψε τον αναμενόμενο τύπο μέσου

Υλοποίησε τη συνάρτηση `type_from_binary/1`. Πρέπει να δέχεται ένα αρχείο (δυαδικό) και να επιστρέφει τον τύπο μέσου (συμβολοσειρά) ή nil αν η υπογραφή του αρχείου δεν ταιριάζει με τις αναμενόμενες.

```elixir
file = File.read!("application.exe")
FileSniffer.type_from_binary(file)
# => "application/octet-stream"

file = File.read!("example.txt")
FileSniffer.type_from_binary(file)
# => nil
```

Μην ανησυχείς για την ανάγνωση του αρχείου ως δυαδικού. Υπέθεσε ότι έχει γίνει για σένα και ότι παρέχεται από τα tests ως όρισμα.

## 3. Δεδομένης μιας επέκτασης και ενός δυαδικού αρχείου, επαλήθευσε ότι το αρχείο ταιριάζει με τον αναμενόμενο τύπο

Υλοποίησε τη συνάρτηση `verify/2`. Πρέπει να δέχεται ένα αρχείο (δυαδικό) και μια επέκταση (συμβολοσειρά) και να επιστρέφει μια πλειάδα `:ok` ή `:error`.

```elixir
file = File.read!("application.exe")

FileSniffer.verify(file, "exe")
# => {:ok, "application/octet-stream"}

FileSniffer.verify(file, "png")
# => {:error, "Warning, file format and file extension do not match."}
```

[mimetype]: https://en.wikipedia.org/wiki/Media_type
