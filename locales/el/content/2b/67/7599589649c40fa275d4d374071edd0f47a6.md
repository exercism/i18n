# Οδηγίες

Η Έλενα, η νέα υπεύθυνη ποιότητας σε ένα εργοστάσιο εφημερίδων, σου ζητά να γράψεις ένα μικρό πρόγραμμα που θα παρακολουθεί τον χώρο παραγωγής.

## 1. Όρισε ένα προσαρμοσμένο σφάλμα

Όρισε μια κλάση tuple σφάλματος `machine-error` χρησιμοποιώντας τη λέξη ανάλυσης `ERROR:`. Δεν χρειάζεται πεδία.

```factor
machine-error   ! throws a fresh machine-error
```

## 2. Έλεγξε την υγρασία

Όρισε τη `check-humidity`. Παίρνει μια μέτρηση υγρασίας από τη στοίβα και κάνει `throw` τη συμβολοσειρά `"humidity too high"` όταν η μέτρηση είναι αυστηρά μεγαλύτερη από `70`. Διαφορετικά, δεν επιστρέφει τίποτα.

```factor
50 check-humidity   ! returns nothing
80 check-humidity   ! throws "humidity too high"
```

## 3. Έλεγξε τη θερμοκρασία

Όρισε τη `check-temperature`. Παίρνει μια μέτρηση θερμοκρασίας και κάνει `throw` τη συμβολοσειρά `"temperature too high"` όταν η μέτρηση είναι αυστηρά μεγαλύτερη από `500`. Διαφορετικά, δεν επιστρέφει τίποτα.

```factor
400 check-temperature   ! returns nothing
600 check-temperature   ! throws "temperature too high"
```

## 4. Παρακολούθησε το μηχάνημα

Όρισε τη `monitor` ώστε να παίρνει μια υγρασία και μια θερμοκρασία από τη στοίβα και να εκτελεί και τους δύο ελέγχους. Αν κάποιος από τους ελέγχους πετάξει, το `monitor` πρέπει να πετάξει ένα νέο `machine-error` αντ' αυτού. Αν και οι δύο περάσουν, το `monitor` δεν επιστρέφει τίποτα.

```factor
50 400 monitor   ! returns nothing
80 400 monitor   ! throws a machine-error
50 600 monitor   ! throws a machine-error
```

## 5. Παρακολούθησε μια παρτίδα μετρήσεων

Όρισε τη `monitor-batch` ώστε να παίρνει έναν πίνακα από μετρήσεις `{ humidity temperature }` και να επιστρέφει πόσες από αυτές θα αποτύχουν (δηλαδή, πόσες θα έκαναν το `monitor` να πετάξει).

```factor
{ { 50 400 } { 80 400 } { 50 600 } { 60 200 } } monitor-batch .
! => 2
```
