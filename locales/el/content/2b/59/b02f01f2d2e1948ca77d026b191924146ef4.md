# Οδηγίες

Σε αυτή την άσκηση, θα βοηθήσεις ζευγάρια του λυκείου να δηλώσουν τον έρωτά τους στα μέσα κοινωνικής δικτύωσης, δημιουργώντας μια καρδιά ASCII με τα αρχικά τους:

```
     ******       ******
   **      **   **      **
 **         ** **         **
**            *            **
**                         **
**     J. K.  +  M. B.     **
 **                       **
   **                   **
     **               **
       **           **
         **       **
           **   **
             ***
              *
```

## 1. Πάρε το πρώτο γράμμα του ονόματος

Υλοποίησε τη συνάρτηση `HighSchoolSweetheart::firstLetter`.
Πρέπει να παίρνει ένα όνομα και να επιστρέφει το πρώτο του γράμμα.
Πρέπει να καθαρίζει τυχόν περιττά κενά από το όνομα.

```php
<?php

$sweetheart = new HighSchoolSweetheart();
$sweetheart->firstLetter("Jane");
# => "J"
```

## 2. Μορφοποίησε το πρώτο γράμμα ως αρχικό

Υλοποίησε τη συνάρτηση `HighSchoolSweetheart::initial`.
Πρέπει να παίρνει ένα όνομα και να επιστρέφει το πρώτο του γράμμα, κεφαλαίο, ακολουθούμενο από τελεία.
Φρόντισε να ξαναχρησιμοποιήσεις τη `HighSchoolSweetheart::first_letter` που όρισες στο προηγούμενο βήμα.

```php
<?php

$sweetheart = new HighSchoolSweetheart();
$sweetheart->initial("jane");
# => "J."
```

## 3. Χώρισε το πλήρες όνομα σε όνομα και επώνυμο

Υλοποίησε τη συνάρτηση `HighSchoolSweetheart::initials`.
Πρέπει να παίρνει ένα πλήρες όνομα, που αποτελείται από ένα όνομα και ένα επώνυμο χωρισμένα με ένα κενό, και να επιστρέφει τα αρχικά.
Φρόντισε να ξαναχρησιμοποιήσεις τη `HighSchoolSweetheart::initial` που όρισες στο προηγούμενο βήμα.

```php
<?php

$sweetheart = new HighSchoolSweetheart();
$sweetheart->initials("Jane Doe");
# => "J. D."
```

## 4. Βάλε τα αρχικά μέσα στην καρδιά

Υλοποίησε τη συνάρτηση `HighSchoolSweetheart::pair`.
Πρέπει να παίρνει δύο πλήρη ονόματα και να επιστρέφει τα αρχικά μέσα σε μια καρδιά ASCII.
Φρόντισε να ξαναχρησιμοποιήσεις τη `HighSchoolSweetheart::initials` που όρισες στο προηγούμενο βήμα.

```php
<?php

$sweetheart = new HighSchoolSweetheart();
$sweetheart->pair("Blake Miller", "Riley Lewis")
# => """
#      ******       ******
#    **      **   **      **
#  **         ** **         **
# **            *            **
# **                         **
# **     B. M.  +  R. L.     **
#  **                       **
#    **                   **
#      **               **
#        **           **
#          **       **
#            **   **
#              ***
#               *
# """
```
