# Προσθήκη στις οδηγίες

Μια πιθανή λύση γι' αυτή την άσκηση είναι να υλοποιήσεις τη δική σου συνάρτηση ύψωσης σε δύναμη με μέτρο.
Για να μάθεις περισσότερα γι' αυτό, ανατρέξε στην [παρακάτω σελίδα](https://en.wikipedia.org/wiki/Modular_exponentiation).

## Για πόντους μπόνους

Πολλές υλοποιήσεις δεν λειτουργούν για όλες τις δυνατές εισόδους.
Έχουν οριστεί επιπλέον προαιρετικά tests που βοηθούν να διασφαλιστεί ότι όλες οι έγκυρες είσοδοι παράγουν έγκυρα αποτελέσματα.

Για να τρέξεις τα tests μπόνους, αφαίρεσε τη σημαία `#[ignore]` και εκτέλεσε τα tests με το feature `big-primes`, ως εξής:

```bash
$ cargo test --features big-primes
```
