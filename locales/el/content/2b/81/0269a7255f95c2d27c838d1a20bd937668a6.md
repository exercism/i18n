# Σχετικά

Η Lua χρησιμοποιεί δύο αναπαραστάσεις για τους αριθμούς: ακέραιους αριθμούς 64 bit και αριθμούς κινητής υποδιαστολής διπλής ακρίβειας.

~~~exercism/note
Πριν από την έκδοση 5.3, η Lua αναπαριστούσε όλους τους αριθμούς χρησιμοποιώντας τη μορφή κινητής υποδιαστολής διπλής ακρίβειας.
~~~

Οι αριθμοί μπορούν να γραφτούν με ένα προαιρετικό δεκαδικό μέρος, συν έναν προαιρετικό δεκαδικό εκθέτη.
```lua
1               --> 1
0.2             --> 0.2
0.3e4           --> 3000.0
4.0e-3          --> 0.004
5.0e+20         --> 5e+20
```

Ένας αριθμός με υποδιαστολή ή εκθέτη θεωρείται αριθμός κινητής υποδιαστολής, ενώ χωρίς θεωρείται ακέραιος, αλλά και οι δύο έχουν τον τύπο 'number'.
```lua
type(1)         --> number
type(2.0)       --> number
```

Αν θέλουμε να ξεχωρίσουμε τους αριθμούς κινητής υποδιαστολής από τους ακέραιους, μπορούμε να χρησιμοποιήσουμε τη συνάρτηση `type` του αρθρώματος `math`.
```lua
math.type(1)    --> integer
math.type(2.0)  --> float
```

## Σύγκριση

Ακέραιοι και αριθμοί κινητής υποδιαστολής με την ίδια τιμή συγκρίνονται ως ίσοι:
```lua
1 == 1.0        --> true
-2 == -2.0      --> true
0.3e3 == 300    --> true
```

## Αριθμητικές πράξεις

Η Lua υποστηρίζει το σύνηθες σύνολο αριθμητικών τελεστών: την πρόσθεση, την αφαίρεση, τον πολλαπλασιασμό, τη διαίρεση και την άρνηση. Επιπλέον υποστηρίζει την ακέραια διαίρεση, το modulo και την ύψωση σε δύναμη.

### Πρόσθεση, αφαίρεση, πολλαπλασιασμός και άρνηση

Αν και οι δύο τελεστέοι είναι ακέραιοι, το αποτέλεσμα της πράξης είναι ακέραιος. Το ίδιο ισχύει και για τους αριθμούς κινητής υποδιαστολής.
```lua
1 + 2     --> 3
1.0 + 2.0 --> 3.0
```

Αν ένας τελεστέος είναι αριθμός κινητής υποδιαστολής, οι υπόλοιποι ακέραιοι θα μετατραπούν επίσης σε αριθμούς κινητής υποδιαστολής και η πράξη θα δώσει αριθμό κινητής υποδιαστολής.
```lua
1.0 + 2   --> 3.0
```

### Διαίρεση

Η διαίρεση λειτουργεί πάντα με αριθμούς κινητής υποδιαστολής και δίνει αριθμό κινητής υποδιαστολής ως αποτέλεσμα.
```lua
1.0 / 2.0 --> 0.5
2 / 1     --> 2.0
```

Η διαίρεση με το μηδέν θα δώσει `inf` ή `-inf`. Η διαίρεση του μηδέν με το μηδέν θα δώσει `-nan`.
```lua
1 / 0     --> inf
-1 / 0    --> -inf
0 / 0     --> -nan
```

### Ακέραια διαίρεση

Αν χρειάζεται ακέραιο αποτέλεσμα, μπορούμε να χρησιμοποιήσουμε την ακέραια διαίρεση. Η ακέραια διαίρεση στρογγυλοποιεί πάντα το πηλίκο προς το αρνητικό άπειρο, εξασφαλίζοντας ακέραιο αποτέλεσμα για όλους τους τελεστέους.

~~~exercism/note
Πριν από την έκδοση 5.3, η Lua δεν είχε αριθμητικό τελεστή για ακέραια διαίρεση.
~~~

```lua
3 // 2    --> 1
6 // 2    --> 3
```

Η ακέραια διαίρεση ακολουθεί τους ίδιους κανόνες με τους τελεστές της πρόσθεσης, της αφαίρεσης, του πολλαπλασιασμού και της άρνησης: αν και οι δύο τελεστέοι είναι ακέραιοι, το αποτέλεσμα της πράξης είναι ακέραιος, αλλιώς το αποτέλεσμα είναι αριθμός κινητής υποδιαστολής.

```lua
3.0 // 2   --> 1.0
6.0 // 2.0 --> 3.0
```

Όταν διαιρούμε με το μηδέν χρησιμοποιώντας ακέραια διαίρεση, η Lua θα πετάξει ένα σφάλμα.
```lua
3 // 0     --> stdin:1: attempt to divide by zero
```

### Modulo

Το modulo χρησιμοποιείται για να πάρουμε το υπόλοιπο της διαίρεσης δύο τελεστέων.
```lua
8 % 2      --> 0
13 % 9     --> 4
-13 % -9   --> -4
-13 % 9    --> 5
13 % -9    --> -5
0.3 % 0.2  --> 0.1
```

### Ύψωση σε δύναμη

Όπως και η διαίρεση, η ύψωση σε δύναμη λειτουργεί με αριθμούς κινητής υποδιαστολής και δίνει αριθμούς κινητής υποδιαστολής ως αποτέλεσμα.
```lua
10 ^ 2    --> 100.0
```

## Προτεραιότητα

Όλες οι πράξεις αξιολογούνται σύμφωνα με την [προτεραιότητα τελεστών](https://www.lua.org/manual/5.4/manual.html#3.4.8). Μπορούμε να χρησιμοποιήσουμε παρενθέσεις για να αλλάξουμε την προτεραιότητα μιας παράστασης.

```lua
1 + 2 * 3   --> 7
(1 + 2) * 3 --> 9
```

## Στρογγυλοποίηση

Το άρθρωμα `math` παρέχει τρεις συναρτήσεις στρογγυλοποίησης: η `floor` στρογγυλοποιεί "προς τα κάτω" (προς το αρνητικό άπειρο), η `ceil` στρογγυλοποιεί "προς τα πάνω" (προς το θετικό άπειρο) και η `modf` στρογγυλοποιεί προς το μηδέν.

### `math.floor`

Η `floor` στρογγυλοποιεί προς το αρνητικό άπειρο.
```lua
math.floor(1.3)    --> 1
math.floor(-1.3)   --> -2
```

### `math.ceil`

Η `ceil` στρογγυλοποιεί προς το θετικό άπειρο.
```lua
math.ceil(1.3)    --> 2
math.ceil(-1.3)   --> -1
```

### `math.modf`

Η `modf` στρογγυλοποιεί προς το μηδέν. Η συνάρτηση επιστρέφει τη στρογγυλοποιημένη τιμή καθώς και το κλασματικό μέρος του αριθμού, το οποίο είναι πάντα αριθμός κινητής υποδιαστολής.
```lua
math.modf(1.3)    --> 1    0.3
math.modf(-1.3)   --> -1   -0.3
```

## Μετατροπή

Αν θέλουμε να μετατρέψουμε έναν ακέραιο σε αριθμό κινητής υποδιαστολής, μπορούμε να προσθέσουμε `0.0` σε αυτόν.
```lua
1 + 0.0         --> 1.0
```

Αν θέλουμε να μετατρέψουμε έναν αριθμό κινητής υποδιαστολής σε ακέραιο, μπορούμε να του κάνουμε bitwise OR με το μηδέν ή να χρησιμοποιήσουμε τη συνάρτηση `tointeger` του αρθρώματος `math`.
```lua
1.0 | 0              --> 1
math.tointeger(1.0)  --> 1
```

Αν ο αριθμός δεν μπορεί να μετατραπεί σε ακέραιο, ο τελεστής OR θα πετάξει ένα σφάλμα και η συνάρτηση `tointeger` θα επιστρέψει `nil`.
```lua
1.1 | 0              --> stdin:1: number has no integer representation
math.tointeger(1.1)  --> nil
```

## Δεκαεξαδικοί αριθμοί

Όπως πολλές άλλες γλώσσες προγραμματισμού, η Lua υποστηρίζει δεκαεξαδικούς αριθμούς προτάσσοντάς τους `0x`, αλλά σε αντίθεση με πολλές άλλες γλώσσες προγραμματισμού, η Lua υποστηρίζει επίσης δεκαεξαδικούς αριθμούς κινητής υποδιαστολής. Μπορούν να έχουν κλασματικό μέρος και δυαδικό εκθέτη, με πρόθεμα 'p' ή 'P'.
```lua
0xff            --> 255
0x0.2           --> 0.125
0x3p-1          --> 1.5
0xa.bp2         --> 42.75
```
