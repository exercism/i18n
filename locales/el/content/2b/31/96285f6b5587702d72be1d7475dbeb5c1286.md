# Οδηγίες

Σε αυτή την άσκηση θα γράψεις ένα γενικό (και μαγικό!) TreasureChest, για να αποθηκεύσεις κάποιον θησαυρό.

## 1. Όρισε τον γενικό προσαρμοσμένο τύπο TreasureChest

Όρισε έναν προσαρμοσμένο τύπο `TreasureChest` με μία μόνο παραλλαγή.

Η παραλλαγή θα πρέπει να έχει μια συσχετισμένη τιμή `String`, η οποία θα χρησιμοποιηθεί για την αποθήκευση του κωδικού πρόσβασης του σεντουκιού του θησαυρού.

Η παραλλαγή θα πρέπει επίσης να έχει μια συσχετισμένη γενική τιμή, η οποία θα χρησιμοποιηθεί για την αποθήκευση του θησαυρού.
Αυτή η τιμή είναι γενική, ώστε ο θησαυρός να μπορεί να είναι οτιδήποτε.

## 2. Όρισε τον τύπο UnlockResult

Όρισε έναν προσαρμοσμένο τύπο `UnlockResult` με δύο παραλλαγές.

Η πρώτη παραλλαγή θα πρέπει να είναι `Unlocked` και να περιέχει μια γενική τιμή, η οποία θα χρησιμοποιηθεί για την αποθήκευση του θησαυρού.

Η δεύτερη παραλλαγή θα πρέπει να είναι `WrongPassword`, η οποία δεν περιέχει καμία τιμή.

## 3. Όρισε τη συνάρτηση get_treasure

Αυτή η συνάρτηση θα πρέπει να δέχεται δύο παραμέτρους

- έναν γενικό προσαρμοσμένο τύπο `TreasureChest`
- ένα `String` (για να δοκιμάσεις έναν κωδικό πρόσβασης)

Αυτή η συνάρτηση θα πρέπει να ελέγχει τον κωδικό πρόσβασης που δίνεται ως προσπάθεια με το `String` μέσα στο `TreasureChest`.

Η συνάρτηση θα πρέπει να επιστρέφει ένα `UnlockResult`.

Αν οι κωδικοί πρόσβασης ταιριάζουν, τότε επέστρεψε `Unlocked` με τη γενική τιμή από το `TreasureChest` (τον θησαυρό!)

Αν οι κωδικοί πρόσβασης δεν ταιριάζουν, τότε επέστρεψε `WrongPassword`.
