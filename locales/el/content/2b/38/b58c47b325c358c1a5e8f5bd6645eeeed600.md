# Υποδείξεις

## Γενικά

- Ρίξε μια ματιά στις συναρτήσεις που είναι διαθέσιμες στο [module `NaiveDateTime`][naive-date-time], στο [module `Date`][date] και στο [module `Time`][time].

## 1. Ανάλυσε τις αποθηκευμένες ημερομηνίες και ώρες

- Υπάρχει μια [ενσωματωμένη συνάρτηση][naive-date-time-from-iso8601] που αναλύει μια συμβολοσειρά ημερομηνίας και ώρας ISO8601 και επιστρέφει ένα struct `NaiveDateTime`.

## 2. Προσδιόρισε αν ένα βιβλίο δανείστηκε πριν το μεσημέρι

- Μπορείς να ορίσεις ένα literal `Time` χρησιμοποιώντας το [sigil `~T`][time-sigil].
- Υπάρχει μια [ενσωματωμένη συνάρτηση][naive-date-time-to-time] που μετατρέπει ένα struct `NaiveDateTime` σε struct `Time`.
- Υπάρχει μια [ενσωματωμένη συνάρτηση][time-compare] που ελέγχει ποιο από δύο struct `Time` είναι μεγαλύτερο.

## 3. Υπολόγισε την ημερομηνία επιστροφής

- Μια μέρα έχει `24 * 60 * 60` δευτερόλεπτα.
- Υπάρχει μια [ενσωματωμένη συνάρτηση][naive-date-time-add] που προσθέτει έναν δεδομένο αριθμό δευτερολέπτων σε ένα struct `NaiveDateTime`.
- Υπάρχει μια [ενσωματωμένη συνάρτηση][naive-date-time-to-date] που μετατρέπει ένα struct `NaiveDateTime` σε struct `Date`.

## 4. Προσδιόρισε πόσο καθυστέρησε η επιστροφή του βιβλίου

- Υπάρχει μια [ενσωματωμένη συνάρτηση][naive-date-time-to-date] που μετατρέπει ένα struct `NaiveDateTime` σε struct `Date`.
- Υπάρχει μια [ενσωματωμένη συνάρτηση][date-diff] που υπολογίζει τη διαφορά σε ημέρες μεταξύ δύο struct `Date`.

## 5. Προσδιόρισε αν το βιβλίο επιστράφηκε Δευτέρα

- Υπάρχει μια [ενσωματωμένη συνάρτηση][naive-date-time-to-date] που μετατρέπει ένα struct `NaiveDateTime` σε struct `Date`.
- Υπάρχει μια [ενσωματωμένη συνάρτηση][date-day-of-week] που επιστρέφει την ημέρα της εβδομάδας για ένα δεδομένο struct `Date`.

## 6. Υπολόγισε το πρόστιμο καθυστέρησης

- Συνδύασε όλες τις συναρτήσεις που όρισες στα προηγούμενα βήματα.
