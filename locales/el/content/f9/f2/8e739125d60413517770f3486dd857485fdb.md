# Σχετικά

Οι αρχικοποιητές είναι ειδικές μέθοδοι που χρησιμοποιούνται για να ορίσουν μια τιμή του enum. Ο ορισμός τους μοιάζει πολύ με αυτόν μιας μεθόδου, μόνο που δεν υπάρχει η λέξη-κλειδί `func`, ούτε τύπος επιστροφής, και το όνομα πρέπει να είναι `init` και ο αρχικοποιητής _πρέπει_ να εκχωρήσει μια τιμή του enum στο `self`. Οι αρχικοποιητές καλούνται είτε μέσω σημειογραφίας με τελεία είτε περνώντας τις παραμέτρους του αρχικοποιητή στο όνομα του enum.

```swift
enum Coin {
  case heads
  case tails

  init(_ i: Int) {
    if i.isMultiple(of: 2) {
      self = .heads
    } else {
      self = .tails
    }
  }

  func flip() -> Self {
    switch self {
    case .heads: return .tails
    case .tails: return .heads
    }
  }
}

let tails = Coin.init(13)
// .tails
let heads = Coin(0)
// .heads
let anotherTails = heads.flip()
// .tails
```
