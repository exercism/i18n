Το Elixir έχει συγκεκριμένες συμβάσεις ονοματοδοσίας, που περιλαμβάνουν το πώς ονομάζονται οι [έλεγχοι που επιστρέφουν Boolean και είναι έγκυροι σε guard clauses](https://hexdocs.pm/elixir/naming-conventions.html#is_-prefix-is_foo):

> Οι έλεγχοι τύπων και οι άλλοι έλεγχοι Boolean που επιτρέπονται σε guard clauses ονομάζονται με πρόθεμα `is_`.

Σε αυτούς τους ελέγχους περιλαμβάνονται μερικές ενσωματωμένες συναρτήσεις, μερικά μάκρο και guards.

```elixir
# this is the expected name for checks that return booleans and are valid in guard clauses

%{expected}

# this is the current name

%{actual}
```
Σημείωσε ότι οι συναρτήσεις και τα μάκρο που επιστρέφουν Boolean και δεν είναι έγκυρα σε guard clauses ακολουθούν άλλη σύμβαση και ονομάζονται με κατάληξη `?` (`def foo?`, `defmacro foo?`). Οι δύο συμβάσεις δεν πρέπει να αναμειγνύονται.
