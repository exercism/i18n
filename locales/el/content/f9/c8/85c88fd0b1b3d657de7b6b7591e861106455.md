Ένα από τα μεγαλύτερα προβλήματα που αντιμετωπίζουμε είναι ότι τα tracks γίνονται υπερβολικά δημοφιλή και οι μέντορές μας δεν μπορούν να αντεπεξέλθουν στον όγκο των υποβολών. Ο χρόνος αναμονής για τους μαθητές αυξάνεται, και οι μέντορες βιώνουν τη βαθιά απογοητευτική εμπειρία να βλέπουν τις ουρές να μεγαλώνουν συνεχώς, παρόλο που καταβάλλουν τεράστια προσπάθεια για να προλάβουν τα πάντα.

Η επίλυση αυτού του προβλήματος δεν είναι καθόλου απλή, αλλά πιστεύουμε ότι έχουμε κάποιες καλές λύσεις που θα βελτιώσουν την κατάσταση (δες το [πρόσφατο άρθρο μας στο blog](https://exercism.io/blog/whats-next-for-exercism-aug-2019) για λεπτομέρειες). Ωστόσο, όλες τους χρειάζονται χρόνο για να υλοποιηθούν, και το πρόβλημα είναι πολύ υπαρκτό σήμερα.

Αποφασίσαμε λοιπόν να προσθέσουμε στα tracks μια κατάσταση "Oversubscribed", όπου, όταν ο διάμεσος χρόνος αναμονής για τις βασικές ασκήσεις γίνεται υπερβολικά μεγάλος, κάνουμε τα εξής:
- Επιτρέπουμε σε όσους μαθητές συμμετέχουν σε ένα track να χρησιμοποιούν μόνο τη Λειτουργία Εξάσκησης και όχι τη Λειτουργία Καθοδήγησης
- Εμποδίζουμε τους μαθητές στη Λειτουργία Εξάσκησης να ζητούν καθοδήγηση για τις λύσεις τους (μπορούν να συνεχίσουν να χρησιμοποιούν τη Λειτουργία Εξάσκησης ανεξάρτητα)

Μόλις ο διάμεσος χρόνος αναμονής ενός track επανέλθει υπό έλεγχο, το σύστημα θα επιτρέπει αυτόματα σε νέους μαθητές να συμμετέχουν στη Λειτουργία Καθοδήγησης, και σε μαθητές της Λειτουργίας Εξάσκησης να υποβάλλουν λύσεις για καθοδήγηση.

Αυτές οι αλλαγές δεν επηρεάζουν τους μαθητές που εργάζονται ήδη στη Λειτουργία Καθοδήγησης.

Υπάρχουν πολλά επιπλέον χαρακτηριστικά που θα μπορούσαμε να προσθέσουμε σε αυτό (π.χ. ουρές για συμμετοχή, ειδοποιήσεις όταν ξεκλειδώνουν τα tracks), αλλά για την ώρα απλώς εφαρμόζουμε μια κάπως brute-force προσέγγιση για να διορθώσουμε το βασικό πρόβλημα.

Ελπίζουμε ότι έτσι οι μαθητές θα έχουν καλύτερη εμπειρία και πιο ρεαλιστικές προσδοκίες, ότι οι μέντορες θα απαλλαγούν από την ταλαιπωρία των ουρών που μεγαλώνουν διαρκώς, και ότι εμείς θα μπορέσουμε να επικεντρωθούμε στην υλοποίηση των μεγαλύτερων αλλαγών που θα έχουν πιο μακροπρόθεσμο αντίκτυπο.
