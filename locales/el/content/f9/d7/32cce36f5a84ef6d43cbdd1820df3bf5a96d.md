# Υποδείξεις

## 1. Όρισε το εύρος των γραμμών και των στηλών

- Πρέπει να ορίσεις δύο [σταθερές][constants] που θα περιέχουν ένα [εύρος][range] γραμμών και στηλών.
- Οι γραμμές πρέπει να είναι ένα [εύρος][range] [ακεραίων][integers] από το 1 έως το 8.
- Οι στήλες πρέπει να είναι ένα [εύρος][range] [χαρακτήρων][characters] από το 'A' έως το 'H'.
- Η σταθερά πρέπει να οριστεί στο [module][module] `Chess`.

## 2. Έλεγξε αν το τετράγωνο είναι έγκυρο

- Πρέπει να ελέγξεις αν μια τιμή βρίσκεται μέσα σε ένα εύρος.
- Υπάρχει [μια μέθοδος][include] που μπορεί να χρησιμοποιηθεί για να ελέγξεις αν μια τιμή βρίσκεται μέσα σε ένα εύρος.

## 3. Πάρε το ψευδώνυμο του παίκτη

- Μπορείς να πάρεις μια υποσυμβολοσειρά χρησιμοποιώντας τον [τελεστή εύρους][range-operator] ως θέση.
- Υπάρχει [μια μέθοδος][upcase] που μπορεί να χρησιμοποιηθεί για να μετατρέψεις μια συμβολοσειρά σε κεφαλαία.

## 4. Δημιούργησε το μήνυμα κίνησης

- Μπορείς να χρησιμοποιήσεις τη θέση στη συμβολοσειρά του τετραγώνου για να πάρεις τη γραμμή και τη στήλη.
- Μπορείς να χρησιμοποιήσεις μεθόδους που έχουν ήδη οριστεί για να πάρεις το ψευδώνυμο του παίκτη και να ελέγξεις αν η κίνηση είναι έγκυρη.
