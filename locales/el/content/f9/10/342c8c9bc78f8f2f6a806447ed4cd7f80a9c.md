# Εισαγωγή

Μια *παράθεση* είναι ένα κομμάτι κώδικα μέσα σε αγκύλες `[ ]`. Είναι μια τιμή:
μπορείς να τη βάλεις στη στοίβα, να τη δώσεις σε μια άλλη λέξη ή να την
αποθηκεύσεις σε έναν πίνακα.

```factor
[ 1 + ] .          ! => [ 1 + ]
5 [ 1 + ] call .   ! => 6
```

Οι περισσότερες λέξεις υψηλότερης τάξης παίρνουν μια παράθεση ως δεύτερο
όρισμά τους:

```factor
{ 1 2 3 } [ sq ] map .    ! => { 1 4 9 }
{ 1 2 3 } [ even? ] filter .  ! => { 2 }
```

Το σώμα μιας παράθεσης είναι απλώς συνηθισμένος κώδικας Factor: οι ίδιοι
τελεστές και οι ίδιες επιδράσεις στη στοίβα που χρησιμοποιείς παντού αλλού.

Όταν φτιάχνεις κώδικα από δεδομένα (συνενώνοντας κομμάτια, αντιστοιχίζοντας
tokens σε πράξεις), το αποτέλεσμα είναι μια ακολουθία. Πέρασέ τη από το
`>quotation` για να μπορεί να κληθεί:

```factor
{ [ 1 ] [ 2 + ] [ 3 * ] } concat >quotation call .   ! => 9
```
