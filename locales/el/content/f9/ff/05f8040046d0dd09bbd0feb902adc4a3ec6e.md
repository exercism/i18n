# Σχετικά

Μια Boolean έκφραση είναι μια ερώτηση που θέτουμε σε μία ή περισσότερες τιμές και στην οποία μπορούμε να απαντήσουμε με `true` ή `false`.
Μια αληθής έκφραση επιστρέφει `1`; μια ψευδής έκφραση επιστρέφει `0`.
Επίσης, οι αριθμοί έχουν τιμές αληθούς/ψευδούς. Το μηδέν είναι `false`; το μη μηδέν είναι `true`.

Ο παλιός κώδικας σε C είτε θα χρησιμοποιεί απευθείας τον τύπο `int` για Boolean τιμές, είτε ο προγραμματιστής μπορεί να έχει ορίσει σταθερές όπως `TRUE` και `FALSE` για να αντιστοιχίσει το `1` και το `0` σε μια Boolean αναπαράσταση.

Με την έκδοση C99 προστέθηκε ο τύπος `_Bool`.
Το αρχείο κεφαλίδας `stdbool.h` ορίζει τρία νέα Boolean σύμβολα: `bool`; `true` και `false`.
Το `true` αντιστοιχεί στο `1`; το `false` αντιστοιχεί στο `0`; και το `bool` αντιστοιχεί στο `_Bool`.
Έτσι τώρα, αντί να χρησιμοποιούν απευθείας `int` ή να φτιάχνουν τις δικές τους Boolean αντιστοιχίσεις, οι προγραμματιστές μπορούν να συμπεριλάβουν το `stdbool.h` και να έχουν αυτόματα Boolean σύμβολα στον κώδικά τους.

## Τελεστές σύγκρισης

Η C υποστηρίζει έξι τελεστές σύγκρισης: `==` (Ίσο), `!=` (Διάφορο), `>` (Μεγαλύτερο από), `<` (Μικρότερο από), `>=`(Μεγαλύτερο ή ίσο με), `<=` (Μικρότερο ή ίσο με).
Αυτοί οι τελεστές συγκρίνουν τις σχέσεις μεταξύ τιμών και τις μετατρέπουν σε Boolean τιμές.

```c
0 == 0 // true. Although 0 is false, 0 equals 0 is true.
0 != 0 // false
1 > 0 // true
1 < 0 // false
1 >= 0 // true
1 <= 0 // false
```

## Boolean τελεστές

Η C υποστηρίζει τρεις Boolean τελεστές: `||` (Ή), `&&` (Και) και `!` (Όχι).

Το `!` χρησιμοποιείται με έναν τελεστέο.
Αντιστρέφει τη Boolean τιμή του τελεστέου.
Για παράδειγμα, το `0` είναι `false`, αλλά το `!0` είναι `true`.

Τα `||` και `&&` χρησιμοποιούνται με δύο τελεστέους.
Ο δεξιός τελεστέος αξιολογείται μόνο όταν ο αριστερός τελεστέος δεν καθορίζει ήδη το αποτέλεσμα της έκφρασης.
Δηλαδή, το `||` αξιολογεί τον δεξιό τελεστέο του μόνο όταν ο αριστερός τελεστέος του αξιολογείται σε `false`.
Το `&&` αξιολογεί τον δεξιό τελεστέο του μόνο όταν ο αριστερός τελεστέος του αξιολογείται σε `true`.


## Βραχυκύκλωμα

Το να μην αξιολογούνται όλοι οι τελεστέοι είναι γνωστό ως "βραχυκύκλωμα".
Το βραχυκύκλωμα είναι ένας σύντομος και ισχυρός τρόπος να χειριστείς ορισμένες καταστάσεις.
Για παράδειγμα, μια συνηθισμένη πρακτική είναι να ελέγξεις αν ένας δείκτης δεν είναι `NULL` και (&&), αν δεν είναι `NULL`, τότε να τον αποαναφέρεις, αποφεύγοντας έτσι την αποαναφορά ενός δείκτη `NULL`.
Αλλά το βραχυκύκλωμα μπορεί επίσης να οδηγήσει σε bugs.
Μερικές φορές ένας προγραμματιστής ξεχνά ότι ο δεξιός τελεστέος του `||` ή του `&&` μπορεί να μην αξιολογηθεί πάντα.
Αν ο δεξιός τελεστέος είναι μια έκφραση με παρενέργεια που περιμένουμε να συμβεί πάντα, τότε θα προκύψει bug ανάλογα με τη Boolean τιμή του αριστερού τελεστέου.


## Επιστροφή Boolean έκφρασης

Το αποτέλεσμα μιας Boolean έκφρασης μπορεί να επιστραφεί απευθείας.
Για παράδειγμα, αυτή η εντολή `if`

```c
if (count > 0)
    return true;
else
    return false;
end
```

θα μπορούσε να αντικατασταθεί από

```c
return count > 0;
```
