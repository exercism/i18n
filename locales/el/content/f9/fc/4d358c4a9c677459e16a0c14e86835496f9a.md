# Οδηγίες

Σε αυτή την άσκηση θα γράψεις λίγο κώδικα για να σε βοηθήσει να μαγειρέψεις υπέροχα λαζάνια από το αγαπημένο σου βιβλίο μαγειρικής.

Έχεις πέντε εργασίες, όλες σχετικές με τον χρόνο που ξοδεύεται για το μαγείρεμα των λαζανιών.

## 1. Όρισε τον αναμενόμενο χρόνο στον φούρνο σε λεπτά

Υλοποίησε τη συνάρτηση `expectedCookTime` της κλάσης `Lasagna`, η οποία δεν παίρνει κανένα όρισμα και επιστρέφει πόσα λεπτά πρέπει να μείνουν τα λαζάνια στον φούρνο.
Σύμφωνα με το βιβλίο μαγειρικής, ο αναμενόμενος χρόνος στον φούρνο σε λεπτά είναι 40:

```php
<?php
$timer = new Lasagna();
$timer->expectedCookTime()
// => 40
```

## 2. Υπολόγισε τον υπόλοιπο χρόνο στον φούρνο σε λεπτά

Υλοποίησε τη συνάρτηση `remainingCookTime` της κλάσης `Lasagna`, η οποία παίρνει ως όρισμα τα πραγματικά λεπτά που βρίσκονται τα λαζάνια στον φούρνο και επιστρέφει πόσα λεπτά πρέπει ακόμη να μείνουν τα λαζάνια στον φούρνο, με βάση τον αναμενόμενο χρόνο σε λεπτά από την προηγούμενη εργασία.

```php
<?php
$timer = new Lasagna();
$timer->remainingCookTime(30)
// => 10
```

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

Υλοποίησε τη συνάρτηση `totalPreparationTime` της κλάσης `Lasagna`, η οποία παίρνει ως όρισμα τον αριθμό των στρώσεων που πρόσθεσες στα λαζάνια και επιστρέφει πόσα λεπτά χρειάστηκες για να προετοιμάσεις τα λαζάνια, υποθέτοντας ότι κάθε στρώση χρειάζεται 2 λεπτά για να ετοιμαστεί.

```php
<?php
$timer = new Lasagna();
$timer->totalPreparationTime(3)
// => 6
```

## 4. Υπολόγισε τον συνολικό χρόνο εργασίας σε λεπτά

Υλοποίησε τη συνάρτηση `totalElapsedTime` της κλάσης `Lasagna`, η οποία παίρνει δύο ορίσματα: το πρώτο όρισμα είναι ο αριθμός των στρώσεων που πρόσθεσες στα λαζάνια και το δεύτερο όρισμα είναι τα λεπτά που βρίσκονται τα λαζάνια στον φούρνο.
Η συνάρτηση πρέπει να επιστρέφει πόσα λεπτά συνολικά έχεις δουλέψει για το μαγείρεμα των λαζανιών, δηλαδή το άθροισμα του χρόνου προετοιμασίας σε λεπτά και του χρόνου σε λεπτά που έχουν περάσει τα λαζάνια στον φούρνο αυτή τη στιγμή.

```php
<?php
$timer = new Lasagna();
$timer->totalElapsedTime(3, 20)
// => 26
```

## 5. Δημιούργησε μια ειδοποίηση ότι τα λαζάνια είναι έτοιμα

Υλοποίησε τη συνάρτηση `alarm` της κλάσης `Lasagna`, η οποία δεν παίρνει κανένα όρισμα και επιστρέφει ένα μήνυμα που δηλώνει ότι τα λαζάνια είναι έτοιμα για φαγητό.

```php
<?php
$timer = new Lasagna();
$timer->alarm()
// => "Ding!"
```
