# Σχετικά

Στη Go, οι συμβολοσειρές είναι αμετάβλητες.
Η συνένωση συμβολοσειρών με `+` μέσα σε έναν βρόχο προκαλεί συχνές δεσμεύσεις μνήμης και αντιγράφει τα δεδομένα πολλές φορές.
Το [πακέτο `strings`](https://pkg.go.dev/strings) παρέχει το [`Builder`](https://pkg.go.dev/strings#Builder) για να ελαχιστοποιήσεις το κόστος μνήμης, συναρμολογώντας τις συμβολοσειρές αποτελεσματικά.

## Κατασκευή συμβολοσειρών

Η μηδενική τιμή ενός `strings.Builder` είναι έτοιμη για χρήση αμέσως, χωρίς καμία ρητή αρχικοποίηση ή δέσμευση μνήμης.
Μπορείς να προσθέτεις νέα δεδομένα στον builder χρησιμοποιώντας συγκεκριμένες μεθόδους εγγραφής.
Κάθε μέθοδος εγγραφής επιστρέφει μια τιμή σφάλματος για να ικανοποιεί τις τυπικές διεπαφές της Go, αλλά είναι εγγυημένο ότι αυτή θα είναι πάντα `nil` και συνήθως αγνοείται στον καθημερινό κώδικα.

Οι πιο συχνά χρησιμοποιούμενες μέθοδοι είναι:

- `WriteString(s string) (int, error)`: Προσθέτει μια συμβολοσειρά στον buffer.
- `WriteRune(r rune) (int, error)`: Προσθέτει την κωδικοποίηση UTF-8 ενός rune.
- `WriteByte(c byte) error`: Προσθέτει ένα μόνο byte.

```go
var sb strings.Builder

sb.WriteString("Hello")
var r rune = ' '
sb.WriteRune(r)
var b byte = '.'
sb.WriteByte(b)
```

## Ανάκτηση και επαναφορά

Όταν τελειώσεις τη συναρμολόγηση του κειμένου σου, μπορείς να εξαγάγεις το συσσωρευμένο περιεχόμενο ως μια τυπική συμβολοσειρά Go, καλώντας τη μέθοδο `String()`.
Η κλήση της `String()` είναι μια πολύ φθηνή λειτουργία, γιατί επιστρέφει το υποκείμενο slice από bytes ως συμβολοσειρά απευθείας, χωρίς να αντιγράφει τα συσσωρευμένα δεδομένα.

Αν χρειάζεται να ξαναχρησιμοποιήσεις το ίδιο στιγμιότυπο builder για να συναρμολογήσεις μια νέα συμβολοσειρά (για παράδειγμα, μέσα σε έναν βρόχο), μπορείς να καλέσεις τη μέθοδο `Reset()`.
Αυτή αδειάζει τον εσωτερικό buffer, επιτρέποντάς σου να ξεκινήσεις από την αρχή και να χτίσεις την επόμενη συμβολοσειρά, διατηρώντας στο παρασκήνιο την ήδη δεσμευμένη χωρητικότητα μνήμης.

```go
var sb strings.Builder

sb.WriteString("Task One")
fmt.Println(sb.String()) // Output: Task One

// Clear the buffer for resource reuse
sb.Reset()

sb.WriteString("Task Two")
fmt.Println(sb.String()) // Output: Task Two
```
