# Εισαγωγή

## Τελεστές σύγκρισης

Η R έχει ένα σύνολο τελεστών που είναι ίδιο με πολλές άλλες γλώσσες:

```R
1 == 2 # FALSE
1 != 2 # TRUE
1 < 2 # TRUE
1 > 2 # FALSE
1 <= 2 # TRUE
1 >= 2 # FALSE
```

## Διακλάδωση

Η βασική μορφή μιας εντολής if-else είναι

```R
if (x > 10) {
    y <- "big"
} else if (x > 2) {
    y <- "medium"
} else {
    y <- "tiny"
}
```

Σε αυτή την περίπτωση, απαιτούνται και οι παρενθέσεις `()` γύρω από τη Boolean (λογική τιμή) και τα άγκιστρα `{}` γύρω από την εντολή.
Μια απλή εντολή `if` μπορεί να συντομευτεί:

```R
if (x == 0) return("success")
```
