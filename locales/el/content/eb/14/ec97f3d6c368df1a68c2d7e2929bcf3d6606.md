# Οδηγίες

Σε αυτή την άσκηση θα γράψεις λίγο κώδικα για να σε βοηθήσει να μαγειρέψεις μια υπέροχη λαζάνια από το αγαπημένο σου βιβλίο μαγειρικής.

Έχεις τέσσερις εργασίες, όλες σχετικές με τον χρόνο που περνάς μαγειρεύοντας τη λαζάνια.

## 1. Όρισε τον αναμενόμενο χρόνο ψησίματος σε λεπτά

Όρισε τη μέθοδο `Lasagna.expectedMinutesInOven()` που δεν παίρνει καμία παράμετρο και επιστρέφει πόσα λεπτά πρέπει να μείνει η λαζάνια στον φούρνο. Σύμφωνα με το βιβλίο μαγειρικής, ο αναμενόμενος χρόνος ψησίματος σε λεπτά είναι 40:

```scala
val lasagna = new Lasagna()
lasagna.expectedMinutesInOven()
// => 40
```

## 2. Υπολόγισε τον χρόνο ψησίματος που απομένει σε λεπτά

Όρισε τη μέθοδο `Lasagna.remainingMinutesInOven()` που παίρνει ως παράμετρο τα πραγματικά λεπτά που η λαζάνια βρίσκεται στον φούρνο και επιστρέφει πόσα λεπτά πρέπει ακόμα να μείνει η λαζάνια στον φούρνο, με βάση τον αναμενόμενο χρόνο ψησίματος σε λεπτά από την προηγούμενη εργασία.

```scala
val lasagna = new Lasagna()
lasagna.remainingMinutesInOven(30)
// => 10
```

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

Όρισε τη μέθοδο `Lasagna.preparationTimeInMinutes()` που παίρνει ως παράμετρο τον αριθμό των στρώσεων που πρόσθεσες στη λαζάνια και επιστρέφει πόσα λεπτά σου πήρε η προετοιμασία της λαζάνιας, υποθέτοντας ότι κάθε στρώση σου παίρνει 2 λεπτά.

```scala
val lasagna = new Lasagna()
lasagna.preparationTimeInMinutes(2)
// => 4
```

## 4. Υπολόγισε τον χρόνο που έχει περάσει σε λεπτά

Όρισε τη μέθοδο `Lasagna.elapsedTimeInMinutes()` που παίρνει δύο παραμέτρους: η πρώτη παράμετρος είναι ο αριθμός των στρώσεων που πρόσθεσες στη λαζάνια και η δεύτερη παράμετρος είναι ο αριθμός των λεπτών που η λαζάνια βρίσκεται στον φούρνο. Η συνάρτηση πρέπει να επιστρέφει πόσα λεπτά έχεις δουλέψει για το μαγείρεμα της λαζάνιας, που είναι το άθροισμα του χρόνου προετοιμασίας σε λεπτά και του χρόνου σε λεπτά που η λαζάνια έχει περάσει στον φούρνο αυτή τη στιγμή.

```scala
var lasagna = new Lasagna()
lasagna.elapsedTimeInMinutes(3, 20)
// => 26
```
