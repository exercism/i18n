# Σχετικά

Η περισσότερη επανάληψη στη Factor εκφράζεται με συνδυαστές (`each`,
`map`, `reduce`), αλλά η ρητή αναδρομή έχει ακόμα τη θέση της: όταν
η αναδρομή δεν έχει μορφή λίστας, όταν η βασική περίπτωση δεν είναι
τετριμμένη ή όταν υλοποιείς ο ίδιος έναν συνδυαστή.

```factor
: total ( seq -- sum )
    [ 0 ] [ unclip swap total + ] if-empty ;

: gcd ( a b -- g )
    dup zero? [ drop ] [ tuck mod gcd ] if ;
```

Μερικά πράγματα που αξίζει να ξέρεις:

- Οι απλοί ορισμοί με `:` μπορούν να κάνουν αναδρομή χωρίς ειδική
  σύνταξη. Ο μεταγλωττιστής συμπεραίνει τις επιδράσεις στη στοίβα
  μέσω της αναδρομικής κλήσης.
- Το `loop ( quot -- )` σου επιτρέπει να επαναλαμβάνεις ένα quotation
  που επιστρέφει boolean: συνέχισε όσο αυτό είναι αληθές.
- Οι κλήσεις ουράς μεταγλωττίζονται σε άλματα, οπότε οι βαθιά
  αναδρομικές λέξεις δεν τινάζουν τη στοίβα.

Το ζεύγος `unclip` / `if-empty` είναι η συνήθης μορφή αναδρομής πάνω
σε ακολουθίες, ενώ το `cond` είναι η συνήθης μορφή διακλάδωσης για
πολλές περιπτώσεις.
