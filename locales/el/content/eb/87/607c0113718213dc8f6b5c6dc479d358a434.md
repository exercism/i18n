# Προσθήκη στις οδηγίες

## Καταχωρητές

| Καταχωρητής | Χρήση          | Τύπος     | Περιγραφή                                                    |
| ----------- | -------------- | --------- | ------------------------------------------------------------ |
| `$a0`       | είσοδος        | διεύθυνση | συμβολοσειρά ονόματος τερματισμένη με null, ή δείκτης null    |
| `$a1`       | είσοδος/έξοδος | διεύθυνση | συμβολοσειρά αποτελέσματος τερματισμένη με null               |
| `$t0-9`     | προσωρινός     | οτιδήποτε | για προσωρινή αποθήκευση                                      |
