# Εισαγωγή

Όταν η Elixir προσδιορίζει τη συνάρτηση που θα κληθεί, χρησιμοποιεί το όνομα του module για να κάνει μια αναζήτηση. Η αναζήτηση μπορεί να γίνει δυναμικά αν το όνομα του module είναι δεσμευμένο σε μια μεταβλητή.

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```

Εσωτερικά, το όνομα ενός module είναι ένα άτομο. Όλα τα άτομα των module της Elixir έχουν αυτόματα πρόθεμα `Elixir.`

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```
