# Χρήση θέσης rune με bytes

Η επανάληψη πάνω σε `runes` και η χρήση της θέσης για τη λήψη μεμονωμένων `bytes` είναι ασφαλής σε αυτή την περίπτωση, γιατί η είσοδος αποτελείται μόνο από χαρακτήρες ASCII. Για να δεις τι συμβαίνει όταν χρησιμοποιούνται χαρακτήρες που δεν είναι ASCII, πρόσθεσε αυτή την περίπτωση δοκιμής:

```go
{
	s1:          "aüa",
	s2:          "aÃa",
	want:        1,
	expectError: false,
}
```
