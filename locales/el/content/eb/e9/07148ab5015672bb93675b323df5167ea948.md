# Δοκιμές

Για να δοκιμάσεις τη λύση, απλώς **τρέξε το script δοκιμών**. Μπορείς να το κάνεις αυτό από τη Red Console χρησιμοποιώντας τη συνάρτηση `do` μαζί με τη διαδρομή του script δοκιμών, έτσι:

```red
do %exercism/red/hello-world/hello-world-test.red
```

Ή απλώς περνώντας το ως όρισμα στο εκτελέσιμο του Red στο τερματικό του συστήματός σου:

```shell
red exercism/red/hello-world/hello-world-test.red
```

Αρχικά, μόνο η πρώτη δοκιμή από το αρχείο δοκιμών θα είναι ενεργοποιημένη. Αυτό γίνεται για να σε ενθαρρύνει να λύνεις τις ασκήσεις μία κάθε φορά. Μόλις περάσει η πρώτη δοκιμή, άλλαξε το δεύτερο *όρισμα* της συνάρτησης `test-init` στην αρχή του αρχείου δοκιμών και τρέξε το ξανά. Αυτή η τιμή είναι το πλήθος των ενεργοποιημένων δοκιμών, οπότε αλλάζοντάς την από `1` σε `2` θα ενεργοποιήσεις τη δεύτερη δοκιμή. Μπορείς επίσης να αφαιρέσεις το refinement `\limit` της συνάρτησης `test-init` και το δεύτερο όρισμα, για να τρέξεις όλες τις δοκιμές χωρίς να παραλείπεται καμία.
