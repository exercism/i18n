# Σχετικά

Ο [τριμερής τελεστής][ternary-operator] είναι μια συντομογραφία της εντολής if-else.
Παίρνει μια έκφραση Boolean και δύο εκφράσεις χωρισμένες με άνω κάτω τελεία.
Η πρώτη έκφραση αξιολογείται αν η έκφραση Boolean είναι αληθής, διαφορετικά αξιολογείται η δεύτερη έκφραση.
Έχει την εξής μορφή: `Boolean-expression ? expression1 : expression2`.

Ο τριμερής τελεστής είναι εξαιρετικός όταν θέλεις μια σύντομη μορφή μιας εντολής if-else και οι εκφράσεις είναι σύντομες:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = showFahrenheit ? temperatureInCelsius * 9 / 5 + 32 : temperatureInCelsius
print(temperature)
// Prints 86
```

Το παραπάνω παράδειγμα είναι συντομογραφία του παρακάτω κώδικα:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = if showFahrenheit {
    temperatureInCelsius * 9 / 5 + 32
} else {
    temperatureInCelsius
}
```

[ternary-operator]: https://docs.swift.org/swift-book/LanguageGuide/BasicOperators.html#ID71
