# Προσθήκη στις οδηγίες

## Καταχωρητές

| Καταχωρητής | Χρήση          | Τύπος    | Περιγραφή                                              |
| -------- | ------------ | ------- | ------------------------------------------- |
| `$a0`    | είσοδος        | ακέραιος | πλήθος κερμάτων εισόδου                       |
| `$a1`    | είσοδος        | ακέραιος | στόχος                                      |
| `$a2`    | είσοδος/έξοδος | διεύθυνση | πίνακας από λέξεις κερμάτων που μπορεί να αντικατασταθεί |
| `$v0`    | έξοδος       | ακέραιος | πλήθος κερμάτων εξόδου, -1 αν η είσοδος δεν είναι έγκυρη |
| `$t0-9`  | προσωρινός    | οποιοσδήποτε     | χρησιμοποιείται για προσωρινή αποθήκευση                  |
