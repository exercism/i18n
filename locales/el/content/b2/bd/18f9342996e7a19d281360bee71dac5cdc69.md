# Προσθήκη στις οδηγίες

## Σημείωση

Οι θέσεις x,y συχνά αναπαρίστανται ως Point, κάτι που οδηγεί σε μερικές χρήσιμες συναρτήσεις σημείων οι οποίες μπορούν να βοηθήσουν σε αυτό.
Εναλλακτικά, η αναπαράστασή τους ως δισδιάστατου πίνακα μπορεί επίσης να φανεί χρήσιμη.
Όπως και να 'χει, ο ορισμός μερικών περιγραφικών μεθόδων επέκτασης μπορεί να κάνει τη λύση σου πολύ πιο ευανάγνωστη και κομψή.
