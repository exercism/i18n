# Εισαγωγή

Η έννοια "Ζεύγη και Λεξικά" συζήτησε τα βασικά του τύπου λεξικού της Julia.

Επειδή τα `Dict` αποτελούν έναν σημαντικό και συχνά χρησιμοποιούμενο τύπο συλλογής, υπάρχουν επίσης πολλές συναρτήσεις για τον χειρισμό τους.

## Ανάκτηση καταχωρίσεων

Ο απλούστερος τρόπος για να ανακτήσεις μια καταχώριση είναι μέσω του κλειδιού (όπως σε πολλές γλώσσες).
Ωστόσο, το να ζητήσεις ένα κλειδί που δεν υπάρχει προκαλεί `KeyError`.

```julia-repl
julia> d = Dict(i => ('a':'c')[i] for i in 1:3)
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'
julia> d[2]
'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
# missing key
julia> d[4]
ERROR: KeyError: key 4 not found
```

Θα μπορούσαμε να ελέγξουμε αν υπάρχει το κλειδί πριν προσπαθήσουμε να το ανακτήσουμε (με κάτι σαν `haskey(d, 4)`), αλλά μπορεί να είναι χρήσιμο να πάρεις απλώς μια προεπιλεγμένη τιμή για κλειδιά που λείπουν.

Γι' αυτό, έχουμε τη συνάρτηση `get()` και τη μεταλλακτική παραλλαγή `get!()`.
Αυτές διαφέρουν ως προς το αν ένα κλειδί που "λείπει" προστίθεται στο `Dict`.

```julia-repl
julia> get(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
# get() leaves Dict unchanged
julia> d
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'
julia> get!(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
# get!() adds new key to Dict
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'
```

Είδαμε στην προηγούμενη έννοια ότι η `delete!()` αφαιρεί μια καταχώριση με βάση το κλειδί.
Αυτό μπορεί να συνδυαστεί με την ανάκτηση της τιμής, χρησιμοποιώντας τη συνάρτηση `pop!()`.

```julia-repl
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'
# popped value is returned
julia> pop!(d, 3)
'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)
# Dict is shrunk
julia> d
Dict{Int64, Char} with 3 entries:
  4 => '!'
  2 => 'b'
  1 => 'a'
```

## Επανάληψη

Η επανάληψη πάνω σε ένα `Dict` από προεπιλογή αποδίδει ζεύγη `key => value`.
Τα συστατικά είναι προσβάσιμα με τη συνήθη ονοματολογία `.first` και `.second`.

```julia-repl
# d is from the previous example
julia> [(kv.first, kv.second) for kv in d]
3-element Vector{Tuple{Int64, Char}}:
 (4, '!')
 (2, 'b')
 (1, 'a')
```

Συχνά, θέλουμε να χρησιμοποιήσουμε μόνο τα κλειδιά ή μόνο τις τιμές, κάτι που είναι εύκολο.

```juliajulia> [k for k in keys(d)]
julia> [k for k in keys(d)]
3-element Vector{Int64}:
 4
 2
 1
julia> [v for v in values(d)]
3-element Vector{Char}:
 '!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
```

## Συγχώνευση

Ο συνδυασμός δύο `Dict` μπορεί να είναι χρήσιμος, αλλά πρέπει να είμαστε σαφείς για το τι σκοπεύουμε να κάνουμε με κλειδιά που υπάρχουν σε περισσότερες από μία εισόδους.

Οι συναρτήσεις `merge()` και `merge!()` συνδυάζουν έναν αυθαίρετο αριθμό από `Dict` που δίνονται, με σειρά από αριστερά προς τα δεξιά.

Οι τιμές των υπαρχόντων κλειδιών απλώς αντικαθίστανται, οπότε το δεξιότερο `Dict` "κερδίζει".

```julia-repl
julia> d3 = Dict("color" => "red", "shape" => "circle")
Dict{String, String} with 2 entries:
  "shape" => "circle"
  "color" => "red"
julia> d4 = Dict("color" => "blue", "coords" => (3, 2))
Dict{String, Any} with 2 entries:
  "color"  => "blue"
  "coords" => (3, 2)
# color from d3 is lost
julia> merge(d3, d4)
Dict{String, Any} with 3 entries:
  "shape"  => "circle"
  "color"  => "blue"
  "coords" => (3, 2)
```

Οι συναρτήσεις `mergewith()` και `mergewith!()` μάς επιτρέπουν να δώσουμε μια συνάρτηση ως πρώτο όρισμα, για να ορίσουμε πώς θα συγχωνεύονται τα κλειδιά που επαναλαμβάνονται.
Η πρόσθεση είναι ένα απλό παράδειγμα.

```julia-repl
julia> d5 = Dict("color" => "red", "area" => 3)
Dict{String, Any} with 2 entries:
  "area"  => 3
  "color" => "red"
julia> d6 = Dict("shape" => "circle", "area" => 5)
Dict{String, Any} with 2 entries:
  "shape" => "circle"
  "area"  => 5
# area values are added, not overwritten
julia> mergewith(+, d5, d6)
Dict{String, Any} with 3 entries:
  "shape" => "circle"
  "area"  => 8
  "color" => "red"
```

Σημείωσε ότι οι συναρτήσεις `mergewith` αποτελούν ένα καλό παράδειγμα συναρτήσεων υψηλότερης τάξης σε δράση.
