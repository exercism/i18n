# Σχετικά

Στη Java, το literal [`null`][null-keyword] χρησιμοποιείται για να δηλώσει την απουσία μιας τιμής.

[Οι πρωτόγονοι τύποι δεδομένων][primitive-data-types] στη Java έχουν όλοι μια προεπιλεγμένη τιμή και επομένως δεν μπορούν ποτέ να είναι `null`.
Κατά σύμβαση, ξεκινούν με πεζό γράμμα, π.χ. `int`.

[Οι τύποι αναφοράς][reference-data-types] περιέχουν τη διεύθυνση μνήμης ενός αντικειμένου και μπορούν να έχουν τιμή `null`.
Γενικά ξεκινούν με κεφαλαίο γράμμα, π.χ. `String`.

Αν προσπαθήσεις να αναθέσεις σε μια πρωτόγονη μεταβλητή την τιμή `null`, θα προκύψει σφάλμα κατά τη μεταγλώττιση, καθώς η μεταβλητή κρατά πάντα μια προεπιλεγμένη τιμή του τύπου που της έχει ανατεθεί.

```java
// Throws compile time error stating the required type is int, but null was provided
int number = null;
```

Αν αναθέσεις σε μια μεταβλητή αναφοράς την τιμή `null`, δεν θα προκύψει σφάλμα κατά τη μεταγλώττιση, καθώς οι μεταβλητές αναφοράς μπορούν να είναι `null`.

```java
//No error will occur as the String variable str is nullable
String str = null;
```

Ενώ η πρόσβαση σε μια μεταβλητή αναφοράς που έχει τιμή `null` μεταγλωττίζεται κανονικά, έχει ως αποτέλεσμα να πεταχτεί μια `NullPointerException` κατά την εκτέλεση.

```java
int[] arr = null;

// Throws NullPointerException at runtime
arr.length;
```

Μια [`NullPointerException` πετιέται][null-pointer-exception] όταν προσπαθείς να προσπελάσεις μια μεταβλητή αναφοράς που είναι null αλλά απαιτεί ένα αντικείμενο.

Για να δουλέψεις με ασφάλεια με τιμές που μπορούν να είναι `null`, καλό είναι να ελέγχεις αν είναι `null` πριν δουλέψεις μαζί τους, κάτι που μπορείς να κάνεις χρησιμοποιώντας [τελεστές ισότητας][equality-operators] όπως `==` ή `!=`:

```java
int[] arr = null;

if(arr != null) {
    System.out.println(arr.length);
} else {
    //Perform an alternate action when arr is null
}
```
