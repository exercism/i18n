# Οδηγίες


Είσαι ο maître d' ενός ξενοδοχειακού εστιατορίου.
Το καθήκον σου είναι να διαχειρίζεσαι τη διάταξη των θέσεων στην αίθουσα ανάλογα με τον αριθμό των διαθέσιμων θέσεων σήμερα, τον αριθμό των κρατήσεων και τους πελάτες που έρχονται χωρίς κράτηση και περιμένουν αυτή τη στιγμή να καθίσουν.
Για τις ανάγκες αυτής της άσκησης, η θέση δίνεται με βάση την πρώτη διαθέσιμη κενή θέση.


Για αυτή την άσκηση, έχεις 6 διαφορετικές προκλήσεις οργάνωσης της αίθουσας να ολοκληρώσεις.


## 1. Φτιάξε τον σημερινό χάρτη θέσεων

Όρισε τη συνάρτηση `new_seating_chart(<size=22>)` που παίρνει ένα όρισμα size, το οποίο αντιπροσωπεύει τον αριθμό των θέσεων που θα στηθούν σήμερα στην αίθουσα.
Αν δεν δοθεί `size`, η συνάρτηση πρέπει να επιστρέφει έναν χάρτη θέσεων με 22 θέσεις.
Οι τιμές των θέσεων πρέπει να έχουν `None` ως προσωρινή τιμή, ώστε να φαίνεται ότι είναι διαθέσιμες για ανάθεση σε πελάτη.


## 2. Τακτοποίησε τις κρατήσεις

Όρισε τη συνάρτηση `arrange_reservations(<guest_names>)` με 1 παράμετρο για μια λίστα με ονόματα πελατών.
Αυτό αντιπροσωπεύει τον αριθμό των ατόμων που έχουν κρατήσει θέση σήμερα στην αίθουσα.


Η συνάρτηση πρέπει να επιστρέφει έναν χάρτη θέσεων `dict` προεπιλεγμένου μεγέθους (22 θέσεις), με τους πελάτες τοποθετημένους στις θέσεις με τη σειρά που εμφανίζονται στη λίστα κρατήσεων.
Όλες οι μη ανατεθειμένες θέσεις πρέπει να οριστούν σε `None`.
Αν δεν υπάρχουν πελάτες, πρέπει να επιστραφεί ένας "άδειος" χάρτης θέσεων με όλες τις προσωρινές τιμές σε `None`.


```python
>>> arrange_reservations(guests=["Walter", "Frank", "Jenny", "Carol", "Alice", "George"])
...
{1: 'Walter', 2: 'Frank', 3: 'Jenny', 4: 'Carol', 5: 'Alice', 6: 'George', 7: None, 8: None, 9: None, 10: None, 11: None, 12: None, 13: None, 14: None, 15: None, 16: None, 17: None, 18: None, 19: None, 20: None, 21: None, 22: None}
```


## 3. Βρες όλες τις "κενές" θέσεις

Όρισε τη συνάρτηση `find_all_available_seats(<seats>)` που παίρνει 1 παράμετρο (_ένα λεξικό χάρτη θέσεων_) και επιστρέφει μια `list` με αριθμούς θέσεων που είναι διαθέσιμες για τους πελάτες που περιμένουν αυτή τη στιγμή.
Αν μια θέση είναι κενή, θα έχει τιμή `None` στο λεξικό. Οι κατειλημμένες θέσεις θα έχουν το όνομα του πελάτη.


```python
>>> seats = {1: None, 2: 'Frank', 3: 'Jenny', 4: None, 5: 'Alice', 6: 'George', 7: None, 8: 'Carol', 9: None, 10: None, 11: None, 12: 'Walter'}

>>> find_all_available_seats(seats)
[1,4,7,9,10,11]
```

## 4. Τρέχουσα χωρητικότητα κενών θέσεων

Όρισε τη συνάρτηση `current_empty_seat_capacity(<seats>)` που παίρνει 1 παράμετρο, το `dict` με τις υπάρχουσες κρατήσεις θέσεων.
Η συνάρτηση πρέπει να επιστρέφει τον συνολικό αριθμό των θέσεων που είναι κενές.

```python
>>> curr_empty_seat_capacity({1: "Occupied", 2: None, 3: "Occupied"})
1

>>> curr_empty_seat_capacity({1: "Occupied", 2: None, 3: None})
2
```


## 5. Να περιμένουμε;

Όρισε τη συνάρτηση `accommodate_waiting_guests(<seats>, <guests>)` που παίρνει δύο παραμέτρους.
Η πρώτη παράμετρος θα είναι ένας χάρτης θέσεων `dict`.
Η δεύτερη παράμετρος θα είναι μια `list` με πελάτες που εμφανίστηκαν ξαφνικά χωρίς κράτηση.
Πρώτα θα χρειαστεί να βρεις πόσες θέσεις είναι διαθέσιμες και αν μπορείς καθόλου να δώσεις θέσεις στους πελάτες που εμφανίστηκαν απροειδοποίητα αυτή τη στιγμή.

Αν δεν έχεις αρκετές θέσεις, επέστρεψε τον χάρτη θέσεων `dict` αμετάβλητο.

Αν υπάρχουν διαθέσιμες θέσεις, τοποθέτησε τους πελάτες στον χάρτη θέσεων και επέστρεψέ τον ενημερωμένο.
**Συμβουλή:** Μπορείς να χρησιμοποιήσεις συναρτήσεις που όρισες προηγουμένως για να κάνεις τους υπολογισμούς.


```python
# Guests cannot be accommodated.
>>> starting_reservations = {1: 'Carol', 2: 'Alice', 3: 'George', 4: None, 5: None, 6: None, 7: 'Frank', 8: 'Walter'}
>>> accommodate_guests(starting_reservations, ["Mort", "Suze", "Phillip", "Tony"])
...
{1: 'Carol', 2: 'Alice', 3: 'George', 4: None, 5: None, 6: None, 7: 'Frank', 8: 'Walter'}


# Guests can be accommodated.
>>> starting_reservations = {1: None, 2: None, 3: None, 4: 'Carol', 5: 'Alice', 6: 'George', 7: None, 8: None, 9: None, 10: None, 11: None, 12: None, 13: None, 14: None, 15: None, 16: None, 17: None, 18: 'Frank', 19:  'Jenny', 20: None, 21: None, 22: 'Walter'}
>>> accommodate_guests(starting_reservations, ["Mort", "Suze", "Phillip", "Tony"])
...
{1: 'Mort', 2: 'Suze', 3: 'Phillip', 4: 'Carol', 5: 'Alice', 6: 'George', 7: 'Tony', 8: None, 9: None, 10: None, 11: None, 12: None, 13: None, 14: None, 15: None, 16: None, 17: None, 18: 'Frank', 19: 'Jenny', 20: None, 21: None, 22: 'Walter'}
```

## 6. Κενές θέσεις

Όρισε τη συνάρτηση `empty_seats(<seats>, <seat_numbers>)` που παίρνει δύο παραμέτρους.
Η πρώτη παράμετρος θα είναι ένα λεξικό χάρτη θέσεων.
Η δεύτερη παράμετρος είναι μια λίστα με αριθμούς θέσεων που πρέπει να "ελευθερώσεις" ή να αδειάσεις, δηλαδή να ορίσεις την τιμή του αριθμού της θέσης σε `None`.

Επέστρεψε το `dict` με τις θέσεις αφού ενημερώσεις τις τιμές των θέσεων που πρέπει να αδειάσουν.

```python
>>> empty_seats(seats={1: "Alice", 2: None, 3: "Bob", 4: "George", 5: "Gloria"}, seat_numbers=[5,3,1])
{1: None, 2: None, 3: None, 4: "George", 5: None}
```
