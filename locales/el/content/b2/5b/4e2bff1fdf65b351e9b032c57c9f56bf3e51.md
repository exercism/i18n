# Υποδείξεις

## 1. Δημιούργησε έναν νέο επισκέπτη

- Δες ξανά την [έννοια "Αντικείμενα"][concept-objects] για να μάθεις πώς να δημιουργήσεις ένα αντικείμενο με συγκεκριμένα κλειδιά και τιμές.

## 2. Ακύρωσε το εισιτήριο

- Χρησιμοποίησε τον τελεστή ανάθεσης `=` για να θέσεις την ιδιότητα `ticketId` του αντικειμένου του επισκέπτη σε `null`.
- Στη συνέχεια, επίστρεψε το αντικείμενο του επισκέπτη.

## 3. Προσδιόρισε την κατάσταση του εισιτηρίου

- Δες ξανά την [έννοια "Συνθήκες"][concept-conditionals] για να μάθεις πώς να επιστρέφεις υπό συνθήκη διαφορετικές τιμές από τη συνάρτηση.
- Χρησιμοποίησε τη σημειογραφία αγκύλης για να προσπελάσεις την τιμή του δοσμένου `ticketId` στο αντικείμενο.
- Χρησιμοποίησε τον τελεστή αυστηρής ισότητας `===` για να ελέγξεις για `null` ή `undefined`.

## 4. Βελτίωσε την απόκριση της κατάστασης του εισιτηρίου

- Ανάκτησε την τιμή για ένα δοσμένο `ticketId` με σημειογραφία αγκύλης, όπως στην προηγούμενη εργασία.
- Δεν χρειάζεται εντολή `if` για να λύσεις αυτή την εργασία.
- Χρησιμοποίησε αντ' αυτού τον [τελεστή nullish coalescing][mdn-nullish-coalescing] `??`.

## 5. Προσδιόρισε την έκδοση των όρων και προϋποθέσεων

- Δες ξανά την [έννοια "Αντικείμενα"][concept-objects] για το πώς να προσπελαύνεις εμφωλευμένες τιμές και ξεκίνα γράφοντας την έκφραση για την ανάκτηση της έκδοσης.
- Στη συνέχεια, χρησιμοποίησε τον τελεστή [optional chaining][mdn-optional-chaining] για να χειριστείς την περίπτωση όπου λείπει το αντικείμενο gtc.
- Δεν χρειάζεται εντολή `if` για να λύσεις αυτή την εργασία.
