# Προσάρτημα οδηγιών

Κάθε γραμμή του πλέγματος αναπαρίσταται ως λέξη.

Για παράδειγμα,

```
    0 1 0
    1 0 0
    1 1 0
```

αναπαρίσταται ως

```
0x2
0x4
0x6
```

Το πλέγμα έχει το πολύ 32 στήλες.

## Καταχωρητές

| Καταχωρητής | Χρήση        | Τύπος    | Περιγραφή                 |
| -------- | ------------ | ------- | --------------------------- |
| `$a0`    | είσοδος        | ακέραιος | αριθμός γραμμών              |
| `$a1`    | είσοδος        | ακέραιος | αριθμός στηλών           |
| `$a2`    | είσοδος        | διεύθυνση | πλέγμα για την τρέχουσα γενιά |
| `$a3`    | είσοδος/έξοδος | διεύθυνση | πλέγμα για την επόμενη γενιά    |
| `$t0-9`  | προσωρινός    | οποιοσδήποτε     | χρησιμοποιείται για προσωρινή αποθήκευση  |
