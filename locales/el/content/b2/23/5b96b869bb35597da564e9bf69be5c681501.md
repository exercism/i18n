# Προσθήκη οδηγιών

## Οδηγίες ειδικές για το track

Αυτή η άσκηση επικεντρώνεται στην προσθήκη μεθόδων στη δομή `Array` της Swift.
Ο ευκολότερος τρόπος για να το κάνεις αυτό είναι μέσω των [extensions][extensions].

```swift
extension Array {
  // Write your code for the 'Strain' exercise in this file.
}
```

Η τεκμηρίωση του `Array` βρίσκεται [εδώ][array].

[array]: https://developer.apple.com/documentation/swift/array
[extensions]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/extensions/
