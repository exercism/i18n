# Προσθήκη οδηγιών
## Ειδικές οδηγίες για την Arturo

Σε αντίθεση με τις περισσότερες ασκήσεις της Arturo, το `src/grep.art` δεν θα εισαχθεί άμεσα από τη σουίτα δοκιμών.
Αντίθετα, η λύση σου θα εκτελεστεί ως αυτόνομο script Arturo, λαμβάνοντας μια σειρά από ορίσματα γραμμής εντολών.
Μπορείς να χρησιμοποιήσεις το `arg`[arg] ή το `args`[args] για να έχεις πρόσβαση σε αυτά τα ορίσματα γραμμής εντολών, τα οποία περιέχουν μηδέν ή περισσότερες σημαίες, ένα μοτίβο αναζήτησης και ένα ή περισσότερα ονόματα αρχείων.
Αυτά τα αρχεία δημιουργούνται και συμπληρώνονται από τη σουίτα δοκιμών κατά την εκτέλεση.
Η λύση σου θα πρέπει να διαβάσει το ζητούμενο αρχείο και να γράψει την αναμενόμενη έξοδο στην τυπική έξοδο.

[arg]: https://arturo-lang.io/documentation/library/system/arg
[args]: https://arturo-lang.io/documentation/library/system/args
