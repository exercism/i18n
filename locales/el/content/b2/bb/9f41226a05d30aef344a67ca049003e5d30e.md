# Βοήθεια

Για να λάβεις βοήθεια αν αντιμετωπίζεις κάποιο πρόβλημα, μπορείς να χρησιμοποιήσεις έναν από τους παρακάτω πόρους:

- Το [/r/javascript](https://www.reddit.com/r/javascript) είναι το subreddit για τη JavaScript.
- Το [StackOverflow](https://stackoverflow.com/questions/tagged/javascript+exercism) μπορεί να χρησιμοποιηθεί για να αναζητήσεις το πρόβλημά σου και να δεις αν έχει ήδη απαντηθεί. Μπορείς επίσης να ρωτάς και να απαντάς.
- Ο [καταγραφέας ζητημάτων στο GitHub](https://github.com/exercism/javascript/issues) είναι το μέρος όπου παρακολουθούμε την ανάπτυξη και τη συντήρηση των ασκήσεων JavaScript στο Exercism. Αλλά αν κανένας από τους παραπάνω συνδέσμους δεν σε βοηθήσει, μη διστάσεις να δημοσιεύσεις ένα ζήτημα εδώ.
