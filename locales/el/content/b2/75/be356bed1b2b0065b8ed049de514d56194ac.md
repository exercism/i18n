# Προσθήκη στις οδηγίες

## Μορφή εξόδου

Να εμφανίζεις τα φυτά του μαθητή ως συμβολοσειρά τερματιζόμενη με null, χρησιμοποιώντας ως διαχωριστικά ένα κόμμα και ένα κενό.

## Καταχωρητές

| Καταχωρητής | Χρήση        | Τύπος    | Περιγραφή                   |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | είσοδος        | διεύθυνση | διάγραμμα κήπου                |
| `$a1`    | είσοδος        | διεύθυνση | όνομα μαθητή                |
| `$a2`    | είσοδος/έξοδος | διεύθυνση | συμβολοσειρά εξόδου τερματιζόμενη με null |
| `$t0-9`  | προσωρινός    | οτιδήποτε     | χρησιμοποιείται για προσωρινή αποθήκευση    |
