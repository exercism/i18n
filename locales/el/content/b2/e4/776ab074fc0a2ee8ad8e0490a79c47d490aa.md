# Εισαγωγή

Ο _τριμερής τελεστής_ είναι μια ελαφριά, συμπαγής εναλλακτική για απλές εντολές _if/else_. Συνήθως χρησιμοποιείται σε εντολές επιστροφής (αλλά όχι μόνο), και χρειάζεται μόνο μία γραμμή για να πάρει την απόφαση, επιστρέφοντας την αριστερή τιμή αν η έκφραση είναι `true` και τη δεξιά τιμή αν είναι `false`, ως εξής:

```java
boolean expr = 0 != 200;

// Ternary statement
int value = expr ? 22 : 33;
// => 22
```

Πολλές απλές εκφράσεις _if/else_ μπορούν να απλοποιηθούν με τη χρήση _τριμερών τελεστών_.
