# Σχετικά

Στη Swift, δεν μπορείς να κάνεις ευρετηρίαση σε μια συμβολοσειρά χρησιμοποιώντας έναν ακέραιο (όπως `string[3]`).
Επειδή οι συμβολοσειρές της Swift αποτελούνται από χαρακτήρες Unicode μεταβλητού μήκους, για να βρεις έναν χαρακτήρα πρέπει να διατρέξεις τους προηγούμενους χαρακτήρες.

Για να προσπελάσεις έναν χαρακτήρα σε μια συγκεκριμένη θέση, πρέπει να υπολογίσεις μια θέση τύπου `String.Index`.
Αυτές οι θέσεις ονομάζονται *αδιαφανείς θέσεις*, επειδή η εσωτερική τους δομή διαχειρίζεται από τη Swift και δεν χειρίζεται άμεσα ως ακατέργαστοι ακέραιοι:

```swift
let csv = "apple,pear,peach,orange,cherry,lime,gooseberry"
let index = csv.index(csv.startIndex, offsetBy: 21)
print(csv[index])
// Prints "g"

print(index)
// Prints internal representation: Index(_rawBits: ...)
```
