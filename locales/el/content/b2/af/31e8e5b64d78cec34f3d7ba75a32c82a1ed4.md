# Οδηγίες

Σε αυτή την άσκηση θα αναλύσεις αριθμούς τηλεφώνου.

Θα χρειαστεί να υλοποιήσεις 2 δυνατότητες.

Οι αριθμοί τηλεφώνου που περνούν στις ρουτίνες είναι εγγυημένο ότι έχουν τη μορφή
NNN-NNN-NNNN, π.χ. 212-515-9876, και δεν είναι null.

## 1. Ανάλυσε έναν αριθμό τηλεφώνου

Η ανάλυσή σου θα πρέπει να επιστρέφει 3 στοιχεία δεδομένων

1. Μια ένδειξη για το αν ο αριθμός έχει κωδικό κλήσης Νέας Υόρκης, δηλ. 212 ως τα πρώτα 3 ψηφία
2. Μια ένδειξη για το αν ο αριθμός είναι ψεύτικος, έχοντας 555 ως κωδικό προθέματος στις θέσεις 5 έως 7 (με αρίθμηση από το 1)
3. Τα τελευταία 4 ψηφία του αριθμού.

Υλοποίησε τη (στατική) μέθοδο `PhoneNumber.Analyze()` για να παράγεις τις πληροφορίες του αριθμού τηλεφώνου.

```csharp
PhoneNumber.Analyze("631-555-1234");
// => (false, true, "1234")
```

## 2. Εντόπισε αν ένας αριθμός τηλεφώνου έχει ψεύτικο κωδικό προθέματος (555)

Υλοποίησε τη (στατική) μέθοδο `PhoneNumber.IsFake()` για να εντοπίσεις αν ο αριθμός τηλεφώνου είναι ψεύτικος, χρησιμοποιώντας τις πληροφορίες του αριθμού τηλεφώνου που παράγονται στην εργασία 1.

```csharp
PhoneNumber.IsFake(PhoneNumbers.Analyze("631-555-1234"));
// => true
```
