# έχει συνάρτηση main

Αφαίρεσε τη συνάρτηση `Main`, καθώς τα tests δεν τη χρειάζονται και κάνουν τον κώδικα λίγο πιο δύσκολο στην ανάγνωση.

Συνήθως, η συνάρτηση `Main` προστίθεται για να βοηθάει στο debug του κώδικα. Ωστόσο, καλύτερη προσέγγιση είναι να κάνεις debug στον κώδικα τρέχοντας ένα ή περισσότερα unit tests. Αυτό έχει το πρόσθετο πλεονέκτημα ότι μπορείς να επικεντρωθείς στο debug ενός συγκεκριμένου test case. Ορίστε μερικοί σύνδεσμοι που εξηγούν πώς να κάνεις debug σε κώδικα Scala ενώ τρέχεις unit tests σε διάφορα IDE:

- [IntelliJ](https://www.jetbrains.com/help/idea/run-debug-and-test-scala.html)
- [Eclipse](http://scala-ide.org/docs/current-user-doc/features/scaladebugger/index.html)
