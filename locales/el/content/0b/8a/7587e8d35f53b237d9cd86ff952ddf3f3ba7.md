# Υποδείξεις

## Γενικά

- Ρίξε ίσως μια ματιά στις [Interfaces στο Tour of Go][interfaces-tour-of-go] για να δεις περισσότερα παραδείγματα, αν δυσκολεύεσαι με την άσκηση.

## 1. Δημιούργησε την αφηρημένη λειτουργικότητα χαιρετισμού

- Κοίτα ξανά το παράδειγμα `Counter` στην εισαγωγή για να μάθεις πώς να ορίσεις μια διεπαφή.
- Ξαναδές τις [έννοιες των συναρτήσεων][concept-functions] για να θυμηθείς πώς γράφονται οι υπογραφές συναρτήσεων στη Go.
- Ο αφηρημένος τύπος `Greeter` μπορεί να χρησιμοποιηθεί σε μια υπογραφή συνάρτησης με τον ίδιο τρόπο όπως ένας συνηθισμένος συγκεκριμένος τύπος, όπως η `string`.
- Για να υλοποιήσεις τη μέθοδο `SayHello`, κάλεσε τις μεθόδους στο όρισμα του τύπου `Greeter`.
  Έπειτα χρησιμοποίησε μορφοποίηση συμβολοσειρών ή συνένωση συμβολοσειρών για να φτιάξεις το τελικό αποτέλεσμα.

## 2. Υλοποίησε τα ιταλικά

- Ξαναδές την [έννοια των δομών][concept-structs] για να δεις πώς ορίζεται ένας τύπος δομής.
- Για να λύσεις την εργασία, η δομή δεν χρειάζεται καθόλου πεδία.
- Μόλις ορίσεις τη δομή, θέλεις να προσθέσεις τις μεθόδους `LanguageName` και `Greet` σε αυτή.
  Ξαναδές την [έννοια των μεθόδων][concept-methods] για να μάθεις πώς προσθέτεις μια μέθοδο σε έναν τύπο.

## 3. Υλοποίησε τα πορτογαλικά

- Δες τις υποδείξεις για την εργασία 2.
