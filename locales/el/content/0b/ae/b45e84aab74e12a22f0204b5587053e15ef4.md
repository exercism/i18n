# Σχετικά

Το `Nil` στη Gleam είναι ένας τύπος με μία μόνο τιμή, που ονομάζεται επίσης `Nil`. Μοιάζει με το `void` σε άλλες γλώσσες, καθώς χρησιμοποιείται όταν μια συνάρτηση δεν έχει κάποια πιο κατάλληλη τιμή να επιστρέψει.

```gleam
io.println("Hello, Joe!")
// -> Nil
```

Οι τιμές στη Gleam δεν είναι "nil-able" ή "nullable" όπως σε κάποιες άλλες γλώσσες. Μια τιμή μπορεί να είναι `Nil` μόνο αν ο τύπος της είναι `Nil`, και μια τιμή οποιουδήποτε άλλου τύπου δεν μπορεί ποτέ να είναι `Nil`.
