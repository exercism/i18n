# Σχετικά

Μια συνάρτηση είναι [αναδρομή ουράς][recursion-tc] αν το _τελευταίο_ πράγμα που εκτελεί η συνάρτηση είναι μια κλήση στον εαυτό της.

Κάθε φορά που καλείται μια συνάρτηση, ένα _πλαίσιο στοίβας_ με τις τοπικές μεταβλητές, τα ορίσματα κ.λπ. της τοποθετείται στην κορυφή της [στοίβας κλήσεων συναρτήσεων][call-stack]. Όταν μια συνάρτηση επιστρέφει, το πλαίσιο στοίβας αφαιρείται από τη στοίβα.

Οι αναδρομικές συναρτήσεις ουράς επιτρέπουν τη [βελτιστοποίηση κλήσης ουράς][tail-call-optimization]. Είναι μια βελτιστοποίηση που επιτρέπει την επαναχρησιμοποίηση του τελευταίου πλαισίου στοίβας από την επόμενη κλήση συνάρτησης, επειδή είναι βέβαιο ότι η προηγούμενη συνάρτηση δεν το χρειάζεται πια. Αυτό μειώνει τον κίνδυνο υπερχείλισης της στοίβας κλήσεων συναρτήσεων, μια κατάσταση όπου υπάρχουν τόσα πολλά πλαίσια στη στοίβα κλήσεων συναρτήσεων που δεν έχει απομείνει αρκετή μνήμη για να δημιουργηθεί άλλο.

- Για να επιτευχθεί αναδρομή ουράς στην Elixir, συχνά απαιτείται ένας συσσωρευτής, εξαιτίας των κανόνων αμεταβλητότητας των δεδομένων.

  - Ένας συσσωρευτής είναι μια μεταβλητή που μεταφέρεται μαζί με την αναδρομική κλήση και κρατά την τρέχουσα κατάσταση της αναδρομικής συνάρτησης _μέχρι στιγμής_, έως ότου επιστραφεί το τελικό αποτέλεσμα στη βασική περίπτωση.

    ```elixir
    # Count the length of a list without an accumulator
    def count([]), do: 0
    def count([_head | tail]), do: 1 + count(tail)

    # Count the length of a list with an accumulator
    def count(list), do: do_count(list, 0)

    defp do_count([], count), do: count
    defp do_count([_head | tail], count), do: do_count(tail, count + 1)
    ```

- Όταν δουλεύεις με λίστες, θυμήσου ότι υλοποιούνται ως απλά συνδεδεμένες λίστες: οι πράξεις προσθήκης στην αρχή είναι πολύ γρήγορες, αλλά οι πράξεις προσθήκης στο τέλος είναι πολύ αργές.

  ```elixir
  # Reverse a list with an accumulator
  def reverse(list), do: do_reverse(list, [])

  defp do_reverse([], acc), do: acc

  defp do_reverse([head | tail], acc) do
    do_reverse(tail, [head | acc])
  end
  ```
