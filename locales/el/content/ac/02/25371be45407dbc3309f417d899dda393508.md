# Υποδείξεις

## Γενικά

- Διάβασε για τα [structs][getting-started-structs] στον οδηγό Getting Started.
- Διάβασε για τη [`defstruct`][docs-defstruct] στην τεκμηρίωση.
- Δες το [Elixir Casts - #106: Intro to Structs][elixir-casts].

## 1. Δημιούργησε ένα ολοκαίνουργιο τηλεχειριζόμενο αυτοκίνητο

- Το module attribute `@enforce_keys` μπορεί να χρησιμοποιηθεί για να ορίσεις τις απαιτούμενες τιμές. Πρέπει να οριστεί πριν καλέσεις τη `defstruct`.
- Το πεδίο `nickname` δεν πρέπει να έχει καθορισμένη προεπιλεγμένη τιμή.
- Η συνάρτηση `new/0` πρέπει να αρχικοποιεί το `nickname` με την τιμή `"none"`.

## 2. Δημιούργησε ένα ολοκαίνουργιο τηλεχειριζόμενο αυτοκίνητο με ψευδώνυμο

- Χρησιμοποίησε [`multiple-function-clauses`][multiple-fn-clauses] για να ξαναχρησιμοποιήσεις το όνομα της συνάρτησης αλλά να δέχεσαι διαφορετικά ορίσματα.
- Εξέτασε το ενδεχόμενο ενός [`default-argument`][default-arg] για τη συνάρτηση.

## 3. Εμφάνισε την απόσταση

- Για συναρτήσεις που δέχονται μόνο έναν συγκεκριμένο τύπο struct, βεβαιώσου ότι κάνεις αντιστοίχιση προτύπων για να ελέγξεις το όρισμα.
- Χρησιμοποίησε τον _τελεστή στατικής πρόσβασης_ για να πάρεις τις τιμές των πεδίων.

## 4. Εμφάνισε το ποσοστό της μπαταρίας

- Για συναρτήσεις που δέχονται μόνο έναν συγκεκριμένο τύπο struct, βεβαιώσου ότι κάνεις αντιστοίχιση προτύπων για να ελέγξεις το όρισμα.
- Χρησιμοποίησε τον _τελεστή στατικής πρόσβασης_ για να πάρεις τις τιμές των πεδίων.

## 5. Η οδήγηση αλλάζει την μπαταρία και την απόσταση που διανύθηκε

- Για συναρτήσεις που δέχονται μόνο έναν συγκεκριμένο τύπο struct, βεβαιώσου ότι κάνεις αντιστοίχιση προτύπων για να ελέγξεις το όρισμα.
- Χρησιμοποίησε τον _τελεστή στατικής πρόσβασης_ για να πάρεις τις τιμές των πεδίων.
- Ξαναδές την εισαγωγή για την ενημέρωση των structs.

## 6. Λάβε υπόψη την οδήγηση με άδεια μπαταρία

- Αν η μπαταρία είναι άδεια, θα πρέπει να επιστρέφει το struct αμετάβλητο.
