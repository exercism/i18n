# Σχετικά

## Αριθμοί

Η Swift έχει δύο βασικούς τύπους αριθμών: τους ακέραιους και τους αριθμούς κινητής υποδιαστολής.
Οι [ακέραιοι][integers] είναι αριθμοί χωρίς κλασματικό μέρος, π.χ. `0`, `1`, `-1`, `42` και `-273`.
Οι [αριθμοί κινητής υποδιαστολής][floatingpoint] είναι αριθμοί με κλασματικό μέρος, π.χ. `0.0`, `3.14` και `-1.36969e-10`.
Η Swift επιτρέπει επίσης τη χρήση κάτω παύλας για να γίνονται οι αριθμοί πιο ευανάγνωστοι, π.χ. το `1_000_000` είναι το ίδιο με το `1000000`.
Οι αριθμοί κινητής υποδιαστολής μπορούν να γραφτούν είτε σε δεκαδική είτε σε εκθετική μορφή.

Στις περισσότερες περιπτώσεις, θα ορίσεις τον τύπο για τους ακέραιους ως [`Int`][int] και για τους αριθμούς κινητής υποδιαστολής ως [`Double`][double].

Για να δηλώσεις ότι μια μεταβλητή ή μια σταθερά είναι τύπου `Int` ή `Double`, μπορείς να χρησιμοποιήσεις μια επισημείωση τύπου:

```swift
let speed: Int = 42                           // speed is an Int
let pi: Double = 3.14                         // pi is a Double
let giga: Double = 1_000_000_000              // giga is a Double
let plancksConstant : Double = 6.62607015e-34 // plancksConstant is a Double
```

## Αριθμητικοί τελεστές

~~~~exercism/caution
Στη Swift δεν μπορείς να αναμίξεις τύπους σε αριθμητικές πράξεις, οπότε δεν μπορείς να χρησιμοποιήσεις κάποιον αριθμητικό τελεστή ανάμεσα σε ένα `Int` και ένα `Double` ή το αντίστροφο.
Επομένως, πρέπει πρώτα να κάνεις μια μετατροπή τύπου.
~~~~

Η Swift διαθέτει ένα σύνολο [αριθμητικών τελεστών][arithmetic-operators] που μπορούν να χρησιμοποιηθούν για βασικές μαθηματικές πράξεις.
Ο τελεστής `+` χρησιμοποιείται για την πρόσθεση, ο τελεστής `-` για την αφαίρεση και ο τελεστής `*` για τον πολλαπλασιασμό.

| Τελεστής | Παράδειγμα              |
| -------- | ----------------------- |
| `+`      | `4 + 6   // equals  10` |
| `-`      | `15 - 10 // equals  5`  |
| `*`      | `2 * 3   // equals  6`  |

### Διαίρεση

Ο τελεστής `/` χρησιμοποιείται για τη διαίρεση.
Όταν χρησιμοποιείς αριθμό κινητής υποδιαστολής, το αποτέλεσμα θα είναι αριθμός κινητής υποδιαστολής.
Όταν χρησιμοποιείς ακέραιους, το αποτέλεσμα θα είναι ακέραιος.

```swift
5 / 2.0 // equals 2.5
5 / 2   // equals 2
```

Αν διαιρέσεις έναν αριθμό κινητής υποδιαστολής με το μηδέν, το αποτέλεσμα θα είναι `inf`, ή `-inf`, με πρόσημο ίδιο με αυτό του αριθμού.
Αν διαιρέσεις το μηδέν με το μηδέν και ένας από τους δύο είναι αριθμός κινητής υποδιαστολής, το αποτέλεσμα θα είναι `nan`.
Αν διαιρέσεις έναν ακέραιο με το μηδέν, θα πάρεις σφάλμα μεταγλώττισης.

```swift
print(5.0 / 0.0)  // Prints inf
print(-5.0 / 0.0) // Prints -inf
print(0.0 / 0.0)  // Prints nan

// The following code will not compile
print(5 / 0) // error: division by zero
```

### Υπόλοιπο

Ο [τελεστής `%`][remainder-operator] δίνει το υπόλοιπο της διαίρεσης του πρώτου ορίσματος με το δεύτερο όρισμα.
Ο τελεστής υπολοίπου λειτουργεί μόνο με ακέραιους.
Όπως στη διαίρεση, αν το δεύτερο όρισμα είναι μηδέν, το αποτέλεσμα είναι σφάλμα μεταγλώττισης.

```swift
5 % 2  // equals 1
-5 % 2 // equals -1

// The following code will not compile
5 % 0 // error: division by zero
```

~~~~exercism/note
Το `%` στη Swift είναι ο τελεστής υπολοίπου, σε αντίθεση με πολλές άλλες γλώσσες που τον χρησιμοποιούν ως τελεστή modulo.
Ο τελεστής υπολοίπου (`REM`) και ο τελεστής modulo (`MOD`) συμπεριφέρονται διαφορετικά όταν χρησιμοποιούνται με αρνητικούς αριθμούς.
Με τον τελεστή _υπολοίπου_, το αποτέλεσμα έχει το ίδιο πρόσημο με το πρώτο όρισμα. Το πρόσημο του δεύτερου ορίσματος δεν επηρεάζει το αποτέλεσμα.
Με τους τελεστές _modulo_ σε άλλες γλώσσες, το αποτέλεσμα έχει το ίδιο πρόσημο με το δεύτερο όρισμα.

```swift
+5 % -2 // equals 1
```
~~~~

## Στρογγυλοποίηση αριθμών

Η στρογγυλοποίηση αριθμών γίνεται με τη μέθοδο `rounded()` σε έναν αριθμό κινητής υποδιαστολής.
Για να στρογγυλοποιήσεις στον πλησιέστερο ακέραιο, μπορείς να χρησιμοποιήσεις τη μέθοδο `rounded()` χωρίς ορίσματα.
Για να στρογγυλοποιήσεις προς τα πάνω ή προς τα κάτω, μπορείς να ορίσεις έναν [κανόνα στρογγυλοποίησης][rounding-rule]: `rounded(.up)` ή `rounded(.down)`.

```swift
let x = 3.14
let y = x.rounded()      // y equals 3.0
let w = x.rounded(.down) // w equals 3.0
let z = x.rounded(.up)   // z equals 4.0
```

## Εξαγωγή τύπου

Η Swift μπορεί να [συμπεράνει τον τύπο][typeinference] ενός αριθμού με βάση το πλαίσιο. Χωρίς επιπλέον πλαίσιο, ο μεταγλωττιστής θα υποθέσει ότι ο αριθμός είναι `Int`.
Αν θέλεις να πεις στον μεταγλωττιστή ότι θέλεις έναν ακέραιο να είναι `Double`, πρέπει είτε να χρησιμοποιήσεις μια επισημείωση τύπου είτε να προσθέσεις ένα `.0` στο τέλος του αριθμητικού λεκτικού, π.χ.:

```swift
let x = 42         // x is an Int
let y = 42.0       // y is a Double
let z: Double = 42 // z is a Double
```

## Μετατροπή τύπου

Στη Swift, για να μετατρέψεις μια τιμή από έναν τύπο σε έναν άλλο, πρέπει να κάνεις μια [μετατροπή τύπου][type-conversion].
Για παράδειγμα, για να μετατρέψεις ένα `Int` σε `Double` και αντίστροφα, θα έκανες το εξής:

```swift
let x = 42
let d = Double(x)
print(d)           // Prints 42.0
print(type(of: d)) // Prints Double

let pi = 3.14
let iPi = Int(pi)
print(iPi)           // Prints 3
print(type(of: iPi)) // Prints Int
```
