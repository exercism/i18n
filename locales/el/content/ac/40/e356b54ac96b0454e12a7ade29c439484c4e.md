# Οδηγίες

Ο φίλος σου μόλις σου έστειλε ένα μήνυμα με ένα σημαντικό μυστικό.
Επειδή δεν ήθελε να το διαβάζουν εύκολα οι άλλοι, το μήνυμα έχει κρυπτογραφηθεί με μια σειρά από χειρισμούς bit.
Θα χρειαστεί να γράψεις ένα πρόγραμμα που θα βοηθήσει στην αποκρυπτογράφηση του μηνύματος.

## 1. Κάνε ολίσθηση των bit πίσω

Το πρώτο βήμα για την αποκρυπτογράφηση του μηνύματος είναι να αναιρέσεις την ολίσθηση της κρυπτογράφησης, κάνοντας ολίσθηση των bit πίσω προς τα αριστερά.
Ο αριθμός των θέσεων ολίσθησης μπορεί να διαφέρει από μήνυμα σε μήνυμα.

Υλοποίησε τη μέθοδο `Secrets.shift_back` που παίρνει μια τιμή και τον αριθμό των θέσεων για ολίσθηση προς τα αριστερά.

```crystal
Secrets.shift_back(0b0001, 2)
# => 0b0100
```

## 2. Εφάρμοσε μια μάσκα bit

Το επόμενο βήμα είναι να εφαρμόσεις μια μάσκα bit για να εξαγάγεις την τιμή ορισμένων bit.
Η μάσκα εφαρμόζεται εκτελώντας ένα bitwise AND ανάμεσα στην τιμή και τη μάσκα.

Υλοποίησε τη μέθοδο `Secrets.apply_mask` που παίρνει μια τιμή και εφαρμόζει μια μάσκα.

```crystal
Secrets.apply_mask(0b0110, 0b0101)
# => 0b0100
```

## 3. Θέσε κάποια bit

Η ολίσθηση των bit προς τα αριστερά πρόσθεσε κάποια νέα 0.
Κάποια από αυτά τα νέα bit πρέπει να τεθούν σε 1.
Το bitwise OR είναι χρήσιμο για να θέτεις συγκεκριμένα bit σε 1 διατηρώντας τα υπόλοιπα.

Υλοποίησε τη μέθοδο `Secrets.set_bits` που παίρνει δύο τιμές και εκτελεί ένα bitwise OR.

```crystal
Secrets.set_bits(0b0110, 0b0101)
# => 0b111
```

## 4. Αντίστροφο XOR

Μέρος της διαδικασίας κρυπτογράφησης εφαρμόζει ένα XOR με μια συμφωνημένη τιμή.
Για να επιστρέψεις στην αρχική τιμή, αρκεί να κάνεις ξανά XOR της κρυπτογραφημένης τιμής με τη συμφωνημένη τιμή.
Ωστόσο, λόγω μιας παρεξήγησης, ο φίλος σου ανέστρεψε τα bit της συμφωνημένης τιμής (δηλαδή εφάρμοσε ένα bitwise NOT στη συμφωνημένη τιμή) πριν εφαρμόσει το XOR.

Υλοποίησε τη μέθοδο `Secrets.reverse_xor` που παίρνει την κρυπτογραφημένη και τη συμφωνημένη τιμή και υπολογίζει την αρχική τιμή.

```crystal
Secrets.reverse_xor(0b1100, 0b0101)
# => 0b(0110)
```
