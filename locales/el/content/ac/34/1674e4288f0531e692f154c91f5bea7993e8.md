# Υποδείξεις

## Γενικά

- Μπορείς να αποθηκεύσεις συναρτήσεις σε καταγραφές, μαζί με τα αναγνωριστικά του κελιού ή του callback τους.

- Για να καλέσεις μια συνάρτηση που είναι αποθηκευμένη σε ένα πεδίο καταγραφής, χρησιμοποίησε παρενθέσεις, όπως `(cell.compute)(values)` ή `(registration.callback)(value, log)`.
  Χωρίς αυτές τις παρενθέσεις, η Roc αντιμετωπίζει την κλήση ως μέθοδο στον τύπο της καταγραφής.

- Οι `List.map_try` και `List.fold_try` μπορούν να σε βοηθήσουν να εκτελέσεις στη σειρά υπολογισμούς που μπορεί να αποτύχουν.
