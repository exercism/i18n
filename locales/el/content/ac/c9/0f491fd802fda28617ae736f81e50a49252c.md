# Εισαγωγή

Μια συνάρτηση σου επιτρέπει να ομαδοποιήσεις κώδικα σε μια επαναχρησιμοποιήσιμη μονάδα.
Αποτελείται από τη λέξη-κλειδί `func`, το όνομα της συνάρτησης και μια λίστα από μηδέν ή περισσότερες παραμέτρους και τύπους, χωρισμένες με κόμμα μέσα σε παρενθέσεις.

## Παράμετροι συνάρτησης

Όλες οι παράμετροι πρέπει να έχουν ρητά δηλωμένο τύπο. Δεν γίνεται εξαγωγή τύπου για τις παραμέτρους.
Δεν υπάρχουν προεπιλεγμένες τιμές για τις παραμέτρους, οπότε όλες οι παράμετροι μιας συνάρτησης είναι υποχρεωτικές.

```go
import "fmt"

// No parameters
func PrintHello() {
    fmt.Println("Hello")
}

// Two parameters
func PrintGreetingName(greeting string, name string) {
  fmt.Println(greeting + " " + name)
}
```

Παράμετροι του ίδιου τύπου μπορούν να δηλωθούν μαζί, ακολουθούμενες από μία μόνο δήλωση τύπου.

```go
import "fmt"

func PrintGreetingName(greeting, name string) {
  fmt.Println(greeting + " " + name)
}
```

## Παράμετροι εναντίον ορισμάτων

Ας δούμε γρήγορα δύο όρους που συχνά συγχέονται μεταξύ τους: `parameters` και `arguments`.
Οι παράμετροι συνάρτησης είναι τα ονόματα που ορίζονται στην υπογραφή της συνάρτησης, όπως τα `greeting` και `name` στη συνάρτηση `PrintGreetingName` παραπάνω.
Τα ορίσματα συνάρτησης είναι οι συγκεκριμένες τιμές που περνάμε στις παραμέτρους της συνάρτησης όταν καλούμε τη συνάρτηση.
Για παράδειγμα, στο παρακάτω παράδειγμα, τα `"Hello"` και `"Katrina"` είναι τα ορίσματα που περνάμε στις παραμέτρους `greeting` και `name`:

```go
PrintGreetingName("Hello", "Katrina")
```

## Τιμές επιστροφής

Μετά τις παραμέτρους της συνάρτησης ακολουθούν μηδέν ή περισσότερες τιμές επιστροφής, οι οποίες πρέπει επίσης να έχουν ρητά δηλωμένο τύπο.
Οι μεμονωμένες τιμές επιστροφής γράφονται χωρίς παρενθέσεις, ενώ οι πολλαπλές τιμές επιστροφής περικλείονται σε παρενθέσεις.
Οι τιμές επιστρέφονται στον κώδικα που κάλεσε τη συνάρτηση με τη λέξη-κλειδί `return`.
Μπορούν να υπάρχουν πολλαπλές εντολές `return` μέσα σε μια συνάρτηση.
Η εκτέλεση της συνάρτησης τελειώνει μόλις συναντήσει μία από αυτές τις εντολές `return`.
Αν μια συνάρτηση πρέπει να επιστρέψει πολλαπλές τιμές, αυτές χωρίζονται με κόμμα.

```go
func Hello(name string) string {
  return "Hello " + name
}

func HelloAndGoodbye(name string) (string, string) {
  return "Hello " + name, "Goodbye " + name
}
```

## Κλήση συναρτήσεων

Η κλήση μιας συνάρτησης γίνεται γράφοντας το όνομα της συνάρτησης και περνώντας ορίσματα για κάθε παράμετρο της συνάρτησης μέσα σε παρενθέσεις.

```go
import "fmt"

// No parameters, no return value
func PrintHello() {
    fmt.Println("Hello")
}
// Called like this:
PrintHello()

// One parameter, one return value
func Hello(name string) string {
  return "Hello " + name
}
// Called like this:
greeting := Hello("Dave")

// Multiple parameters, multiple return values
func SumAndMultiply(a, b int) (int, int) {
    return a+b, a*b
}
// Called like this:
aplusb, atimesb := SumAndMultiply(a, b)
```

## Ονομαστικές τιμές επιστροφής και "γυμνή" επιστροφή

Όπως και οι παράμετροι, έτσι και οι τιμές επιστροφής μπορούν προαιρετικά να έχουν όνομα.
Αν χρησιμοποιήσεις ονομαστικές τιμές επιστροφής, μια εντολή `return` χωρίς ορίσματα θα επιστρέψει αυτές τις τιμές.
Αυτό είναι γνωστό ως "γυμνή" επιστροφή.

```go
func SumAndMultiplyThenMinus(a, b, c int) (sum, mult int) {
    sum, mult = a+b, a*b
    sum -= c
    mult -= c
    return
}
```

## Πέρασμα με τιμή εναντίον περάσματος με αναφορά

Είναι επίσης σημαντικό να ξεκαθαρίσουμε την έννοια του περάσματος με τιμή και του περάσματος με αναφορά.

Πρώτα, ας ξεκαθαρίσουμε το πέρασμα με τιμή.
Στο παρακάτω παράδειγμα, όταν περνάμε τη μεταβλητή `val` στη συνάρτηση `MultiplyByTwo`, περνάμε ένα αντίγραφο του `val`.
Εξαιτίας αυτού, το `newVal` έχει την ενημερωμένη τιμή `4`, αλλά η αρχική μεταβλητή `val` παραμένει `2`.
Στο παρασκήνιο, η Go ουσιαστικά φτιάχνει ένα αντίγραφο της αρχικής τιμής, ώστε μόνο αυτό το αντίγραφο, δηλαδή το `v`, να τροποποιείται από τη συνάρτηση.

```go
val := 2
func MultiplyByTwo(v int) int {
    v = v * 2
    return v
}
newVal := MultiplyByTwo(val)
// newval is 4, val is still 2 because only a copy of its value was passed into the function
```

Αυστηρά μιλώντας, στη Go όλα τα ορίσματα περνούν με τιμή, δηλαδή γίνεται ένα αντίγραφο της τιμής ή των δεδομένων που δίνονται στη συνάρτηση.
Αν όμως δεν θέλεις να φτιάχνεις αντίγραφο των δεδομένων που περνάς σε μια συνάρτηση και θέλεις να αλλάζεις τα δεδομένα μέσα στη συνάρτηση,
τότε θα πρέπει να χρησιμοποιήσεις `pointers` ως ορίσματα, δηλαδή πέρασμα με αναφορά.

## Δείκτες

Χρησιμοποιούμε έναν `pointer` για να πετύχουμε το πέρασμα με αναφορά.
Περνώντας `pointer` ορίσματα σε μια συνάρτηση,
μπορούμε να τροποποιήσουμε τα δεδομένα που περνιούνται στη συνάρτηση αντί να δουλεύουμε μόνο με ένα αντίγραφό τους.

Για την ώρα, αρκεί να ξέρεις ότι οι τύποι δεικτών αναγνωρίζονται από το `*` μπροστά από τον τύπο στην υπογραφή της συνάρτησης.

```go
func HandlePointers(x, y *int) {
    // Some logic to handle integer values referenced by pointers x and y
}
```

Αν η έννοια του `pointer` σε μπερδεύει, μην ανησυχείς.
Έχουμε ένα ξεχωριστό τμήμα πιο κάτω στο πρόγραμμα σπουδών που θα σε βοηθήσει να μάθεις καλά τους δείκτες.

## Εξαιρέσεις

Σημείωσε ότι τα `slices` και τα `maps` αποτελούν εξαιρέσεις στον παραπάνω κανόνα.
Όταν περνάμε ένα `slice` ή ένα `map` ως ορίσματα σε μια συνάρτηση, αντιμετωπίζονται ως τύποι δεικτών, ακόμα κι αν δεν υπάρχει ρητό `*` στον τύπο.
Αυτό σημαίνει ότι αν περάσουμε ένα slice ή ένα map σε μια συνάρτηση και τροποποιήσουμε τα δεδομένα του,
οι αλλαγές θα φανούν στο αρχικό slice ή map.
