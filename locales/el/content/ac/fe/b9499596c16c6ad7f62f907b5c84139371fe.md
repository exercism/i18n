# Οδηγίες

Δουλεύεις πάνω στην υλοποίηση ενός συστήματος παρακολούθησης υγείας.
Ως μέρος αυτού, πρέπει να παρακολουθείς τα στατιστικά υγείας των χρηστών.

Θα ξεκινήσεις με κάποιες κενές συναρτήσεις σε ένα μπλοκ `impl`, καθώς και με τον ακόλουθο ορισμό struct:

```rust
pub struct User {
    name: String,
    age: u32,
    weight: u32,
}
```

Ο στόχος σου είναι να υλοποιήσεις τις κενές μεθόδους στη `struct` `User` που ορίζεται στο μπλοκ `impl`.

Για παράδειγμα, η μέθοδος `new` πρέπει να επιστρέφει ένα στιγμιότυπο της `struct` `User` με τις καθορισμένες τιμές για name, age και weight.

```rust
let mut bob = User::new("Bob", 32, 72);
// Returns: a User with name "Bob", age 32, and weight 72
```

Η μέθοδος `weight` πρέπει να επιστρέφει το βάρος του `User`.

```rust
bob.weight();
// Returns: 72
```

Η μέθοδος `set_age` πρέπει να ορίζει την ηλικία του `User`.

```rust
bob.set_age(33);
// Updates Bob's age to 33; happy birthday Bob!
```

Καλή διασκέδαση!
