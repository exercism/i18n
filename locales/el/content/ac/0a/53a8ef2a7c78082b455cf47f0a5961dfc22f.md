# Γεννήτριες

Ένας `generator` είναι μια συνάρτηση ή έκφραση που επιστρέφει έναν ειδικό τύπο [επαναλήπτη][iterator] που ονομάζεται [`generator iterator`][generator-iterator].
Οι `Generator-iterator`s είναι [τεμπέληδες][lazy iterator]: δεν αποθηκεύουν τις `values` τους στη μνήμη, αλλά _παράγουν_ τις τιμές τους όταν χρειάζεται.

Μια συνάρτηση γεννήτριας μοιάζει με οποιαδήποτε άλλη συνάρτηση, αλλά περιέχει μία ή περισσότερες [εκφράσεις yield][yield expression].
Κάθε `yield` αναστέλλει την εκτέλεση του κώδικα, αποθηκεύοντας την τρέχουσα κατάσταση εκτέλεσης (_συμπεριλαμβανομένων όλων των τοπικών μεταβλητών και των εντολών try_).
Όταν η γεννήτρια συνεχίσει, ξεκινά από την κατάσταση όπου είχε ανασταλεί, σε αντίθεση με τις κανονικές συναρτήσεις, που μηδενίζονται σε κάθε κλήση.


## Δημιουργία μιας γεννήτριας

Οι γεννήτριες κατασκευάζονται περίπου όπως οι άλλες συναρτήσεις με βρόχους ή οι αναδρομικές συναρτήσεις, αλλά απαιτούν μια [έκφραση `yield`](#the-yield-expression), την οποία θα εξετάσουμε σε βάθος λίγο αργότερα.

Ένα παράδειγμα είναι μια συνάρτηση που επιστρέφει τα _τετράγωνα_ μιας δεδομένης λίστας αριθμών.
Όπως είναι γραμμένη αυτή τη στιγμή, όλη η είσοδος πρέπει να υποστεί επεξεργασία πριν μπορέσει να επιστραφεί οποιαδήποτε τιμή:

```python
>>> def squares(list_of_numbers):
...     squares = []
...     for number in list_of_numbers:
...         squares.append(number ** 2)
...     return squares
```

Μπορείς να μετατρέψεις αυτή τη συνάρτηση σε γεννήτρια ως εξής:

```python
>>> def squares_generator(list_of_numbers):
...     for number in list_of_numbers:
...         yield number ** 2
```

Το σκεπτικό πίσω από αυτό είναι ότι χρησιμοποιείς μια γεννήτρια όταν δεν χρειάζεται να παραγάγεις όλες τις τιμές _με τη μία_.
Αυτό εξοικονομεί μνήμη και υπολογιστική ισχύ, αφού υπολογίζεται μόνο η τιμή με την οποία _εργάζεσαι αυτή τη στιγμή_.


## Χρήση μιας γεννήτριας

Οι γεννήτριες μπορούν να χρησιμοποιηθούν στη θέση των περισσότερων `iterables` στην Python.
Αυτό περιλαμβάνει _συναρτήσεις_ ή _αντικείμενα_ που απαιτούν ένα `iterable`/`iterator` ως όρισμα.

Για να χρησιμοποιήσεις τη γεννήτρια `squares_generator()`:

```python
>>> squared_numbers = squares_generator([1, 2, 3, 4])

>>> for square in squared_numbers:
...     print(square)
...
1
4
9
16
```

Οι τιμές μέσα σε έναν `generator` μπορούν επίσης να παραχθούν ή να προσπελαστούν μέσω της συνάρτησης `next()`.
Η `next()` καλεί τη μέθοδο `__next__()` ενός αντικειμένου επαναλήπτη γεννήτριας, "προχωρώντας" ή αξιολογώντας τον κώδικα μέχρι την έκφραση `yield` του, η οποία τότε "αποδίδει" ή επιστρέφει μια τιμή:

```python
>>> squared_numbers = squares_generator([1, 2])

>>> next(squared_numbers)
1
>>> next(squared_numbers)
4
```

Όταν ένας `generator-iterator` καταναλωθεί πλήρως και δεν έχει άλλες τιμές να επιστρέψει, πετάει ένα σφάλμα `StopIteration`.

```python
>>> next(squared_numbers)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
StopIteration
```


~~~~exercism/note

Οι επαναλήπτες γεννήτριας είναι ένα ειδικό υποσύνολο των [επαναληπτών][iterator].
Οι `Iterators` είναι ο μηχανισμός/το πρωτόκολλο που επιτρέπει την επανάληψη πάνω από _επαναλήψιμα_ αντικείμενα.
Οι επαναλήπτες γεννήτριας και οι επαναλήπτες που επιστρέφουν τα κοινά [`iterables`][iterables] της Python συμπεριφέρονται με πολύ παρόμοιο τρόπο, αλλά υπάρχουν μερικές σημαντικές διαφορές που πρέπει να προσέξεις:

- Αξιολογούνται _[τεμπέλικα][lazy evaluation]_· η επανάληψη είναι _μονής κατεύθυνσης_ και δεν υπάρχει τρόπος να "γυρίσεις πίσω" σε μια προηγούμενη τιμή.
- _Καταναλώνονται_ καθώς επαναλαμβάνεις πάνω στις τιμές που επιστρέφονται· δεν υπάρχει επαναφορά ούτε αποθήκευση στη μνήμη.
- Δεν μπορούν να ταξινομηθούν ούτε να αντιστραφούν.
- Δεν είναι τύποι ακολουθίας και _δεν_ έχουν `indexes`. 
  Δεν μπορείς να αναφερθείς σε προηγούμενη ή μελλοντική τιμή χρησιμοποιώντας πρόσθεση ή αφαίρεση και δεν μπορείς να χρησιμοποιήσεις σημειογραφία αγκύλης (`[]`) ούτε τεμαχισμό.
- Δεν μπορούν να χρησιμοποιηθούν με τη συνάρτηση `len()`, αφού δεν έχουν μήκος.
- Μπορούν να είναι _πεπερασμένοι_ ή _άπειροι_. Πρόσεχε όταν συλλέγεις όλες τις τιμές από έναν _άπειρο_ `generator-iterator`!

## Η έκφραση yield

Η [έκφραση yield][yield expression] μοιάζει πολύ με την έκφραση `return`.
_Σε αντίθεση_ με την έκφραση `return`, το `yield` παραχωρεί τιμές στον καλούντα σε ένα _συγκεκριμένο σημείο_, αναστέλλοντας την αξιολόγηση ή την επιστροφή τυχόν πρόσθετων τιμών μέχρι να ζητηθούν.
Όταν αξιολογείται το `yield`, παύει την εκτέλεση της συνάρτησης που το περιέχει και επιστρέφει τις τιμές της συνάρτησης _εκείνη τη στιγμή_.
Η συνάρτηση τότε _παραμένει ενεργή_ και, όταν κληθεί η `__next__()`, η εκτέλεση συνεχίζεται μέχρι να συναντήσει ξανά το `yield`.


~~~~exercism/note
Η χρήση εκφράσεων `yield` απαγορεύεται εκτός συναρτήσεων.
~~~~

```python
>>> def infinite_sequence():
...     current_number = 0
...     while True:
...         yield current_number
...         current_number += 1

>>> lets_try = infinite_sequence()
>>> lets_try.__next__()
0
>>> lets_try.__next__()
1
```


## Γιατί να δημιουργήσεις μια γεννήτρια;

Οι γεννήτριες είναι χρήσιμες σε πολλές εφαρμογές.

Όταν δουλεύεις με μια δυνητικά μεγάλη συλλογή τιμών, μπορεί να μη θέλεις να τις βάλεις όλες στη μνήμη.
Μια γεννήτρια μπορεί να χρησιμοποιηθεί για να δουλέψεις με μεγαλύτερα δεδομένα κομμάτι-κομμάτι, εξοικονομώντας μνήμη και βελτιώνοντας την απόδοση.

Οι γεννήτριες είναι επίσης πολύ χρήσιμες όταν μια διαδικασία ή ένας υπολογισμός είναι _πολύπλοκος_, _δαπανηρός_ ή _άπειρος_:

```python
>>> def infinite_sequence():
...     current_number = 0
...     while True:
...         yield current_number
...         current_number += 1
```

Τώρα, όποτε καλείται η `__next__()` στο αντικείμενο `infinite_sequence`, θα επιστρέφει τον _προηγούμενο αριθμό_ + 1.
