# Υποδείξεις

## Γενικά

- Ξαναδές τα μοτίβα κανονικών εκφράσεων από την εισαγωγή. Θυμήσου ότι όταν δημιουργείς το μοτίβο ως συμβολοσειρά, πρέπει να κάνεις escape σε ορισμένους χαρακτήρες.
- Διάβασε για τη [μονάδα `Regex`][regex-docs] στην τεκμηρίωση.
- Διάβασε για το [sigil κανονικών εκφράσεων][sigils-regex] στον οδηγό Getting Started.
- Ρίξε μια ματιά σε αυτή την ιστοσελίδα για κανονικές εκφράσεις: [Regular-Expressions.info][website-regex-info].
- Ρίξε μια ματιά σε αυτή την ιστοσελίδα για κανονικές εκφράσεις: [Rex Egg - Ο πιο τυραννοσαυρικός οδηγός κανονικών εκφράσεων στον κόσμο][website-rexegg].
- Ρίξε μια ματιά σε αυτή την ιστοσελίδα για κανονικές εκφράσεις: [RegexOne - Μάθε κανονικές εκφράσεις με απλές, διαδραστικές ασκήσεις.][website-regexone].
- Ρίξε μια ματιά σε αυτή την ιστοσελίδα για κανονικές εκφράσεις: [Regular Expressions 101 - ένα διαδικτυακό περιβάλλον δοκιμών για κανονικές εκφράσεις][website-regex-101].
- Ρίξε μια ματιά σε αυτή την ιστοσελίδα για κανονικές εκφράσεις: [RegExr - ένα διαδικτυακό περιβάλλον δοκιμών για κανονικές εκφράσεις][website-regexr].

## 1. Αντιστοίχισε την ημέρα, τον μήνα και το έτος από μια ημερομηνία

- Θυμήσου να επιστρέψεις μια συμβολοσειρά που αναπαριστά το μοτίβο της κανονικής έκφρασης.
- Ξαναδές πώς δημιουργείς _κλάσεις χαρακτήρων_ ή πώς χρησιμοποιείς _συντομευμένες κλάσεις χαρακτήρων_.
- Ξαναδές τους _ποσοδείκτες_.
- Η ημέρα είναι ένα ή δύο ψηφία.
- Ο μήνας είναι ένα ή δύο ψηφία.
- Το έτος είναι τέσσερα ψηφία.

## 2. Αντιστοίχισε την ημέρα της εβδομάδας και τον μήνα του έτους

- Ξαναδές πώς γράφεις ένα μοτίβο που να αντιστοιχίζει _κυριολεκτικές συμβολοσειρές_.
- Ξαναδές τις _εναλλαγές_.
- Τύλιξε ολόκληρη την έκφραση σε μια _ομάδα_.

## 3. Σύλλαβε την ημέρα, τον μήνα και το έτος

- Ξαναδές πώς γράφεις μοτίβα για συλλήψεις και ονομασμένες συλλήψεις.
- Χρησιμοποίησε ξανά τις συναρτήσεις `day/0`, `month/0`, `year/0`, `day_names/0` και `month_names/0` που έχεις ήδη υλοποιήσει.

## 4. Συνδύασε τις συλλήψεις για να συλλάβεις ολόκληρη την ημερομηνία

- Θυμήσου ότι μπορείς να χρησιμοποιήσεις παρεμβολή συμβολοσειρών για να ενώσεις συμβολοσειρές.
- Χρησιμοποίησε ξανά τις συναρτήσεις `capture_day/0`, `capture_month/0`, `capture_year/0`, `capture_day_name/0` και `capture_month_name/0` που έχεις ήδη υλοποιήσει.

## 5. Περιόρισε τη σύλληψη ώστε να αντιστοιχίζει μόνο στην ημερομηνία

- Θυμήσου, οι _άγκυρες_ βοηθούν το μοτίβο να αντιστοιχίσει σε **ολόκληρη τη γραμμή**.
- Μπορείς να χρησιμοποιήσεις παρεμβολή συμβολοσειρών στη σύνταξη του sigil κανονικών εκφράσεων.
- Χρησιμοποίησε ξανά τις συναρτήσεις `capture_numeric_date/0`, `capture_month_name_date/0` και `capture_day_month_name_date/0` που έχεις ήδη υλοποιήσει.
