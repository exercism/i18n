# Προσάρτημα οδηγιών

## Καταχωρητές

| Καταχωρητής | Χρήση         | Τύπος    | Περιγραφή                   |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | είσοδος        | ακέραιος | ο αριθμός που δίνεται                  |
| `$a1`    | είσοδος/έξοδος | διεύθυνση | συμβολοσειρά αποτελέσματος με τερματισμό null |
| `$t0-9`  | προσωρινός    | οτιδήποτε     | για προσωρινή αποθήκευση         |
