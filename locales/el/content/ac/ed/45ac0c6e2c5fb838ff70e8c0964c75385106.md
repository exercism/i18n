# Επίλυση ασκήσεων

Ο κύριος τρόπος με τον οποίο το Exercism σε βοηθά να μάθεις είναι η επίλυση ασκήσεων.

Υπάρχουν δύο τρόποι για να λύσεις ασκήσεις στο Exercism:

1. [Διαδικτυακά, μέσω του επεξεργαστή του ιστότοπου στον περιηγητή](/docs/using/solving-exercises/using-the-online-editor)
2. [Στον τοπικό σου υπολογιστή, μέσω της γραμμής εντολών](/docs/using/solving-exercises/working-locally)

## Ποια επιλογή να διαλέξω;

Η χρήση του διαδικτυακού επεξεργαστή και η χρήση της γραμμής εντολών έχουν διαφορετικά πλεονεκτήματα και μειονεκτήματα:

|            | Διαδικτυακός επεξεργαστής              | Γραμμή εντολών                               |
| ---------- | -------------------------------------- | -------------------------------------------- |
| Εγκατάσταση | Όχι                                   | Ναι (π.χ. SDK)                               |
| Επεξεργασία | Πρόγραμμα περιήγησης                  | Ο επεξεργαστής που προτιμάς                  |
| Δοκιμές    | Εκτέλεση των δοκιμών στον ιστότοπο     | Εκτέλεση των δοκιμών τοπικά                  |
| Αποσφαλμάτωση | Περιορισμένη υποστήριξη (μόνο για ορισμένες διαδρομές) | Πλήρης υποστήριξη (ανάλογα με το περιβάλλον σου) |

Γενικά, ο διαδικτυακός επεξεργαστής είναι ιδανικός για να ξεκινήσεις νέες διαδρομές, ενώ η προσέγγιση μέσω της γραμμής εντολών είναι εξαιρετική αν θέλεις να χρησιμοποιήσεις το δικό σου, εξατομικευμένο περιβάλλον προγραμματισμού.
