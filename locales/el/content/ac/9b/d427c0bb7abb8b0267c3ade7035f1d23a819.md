# defmacro με `_is` και ερωτηματικό

[comment]: # (απαιτεί 3 παραμέτρους:)
[comment]: # (- actual: το λανθασμένο όνομα που χρησιμοποίησε ο μαθητής)
[comment]: # (- option1: το σωστό όνομα για τις συναρτήσεις)
[comment]: # (- option2: το σωστό όνομα για τα guard clauses)

Το Elixir έχει συγκεκριμένες συμβάσεις ονομασίας, οι οποίες περιλαμβάνουν το πώς ονομάζονται οι [συναρτήσεις που επιστρέφουν boolean](https://hexdocs.pm/elixir/naming-conventions.html#trailing-question-mark-foo) και οι [έλεγχοι που επιστρέφουν boolean και είναι έγκυροι σε guard clauses](https://hexdocs.pm/elixir/naming-conventions.html#is_-prefix-is_foo):

> Οι συναρτήσεις που επιστρέφουν boolean ονομάζονται με τελικό ερωτηματικό.

> Οι έλεγχοι τύπων και οι άλλοι έλεγχοι boolean που επιτρέπονται σε guard clauses ονομάζονται με πρόθεμα `is_`.

Οι μακροεντολές μπορούν να χρησιμοποιηθούν και στα δύο πλαίσια, οπότε η ονομασία εξαρτάται από την περίπτωση, αλλά οι δύο συμβάσεις ονομασίας δεν πρέπει να ανακατεύονται μεταξύ τους.

```elixir
# this is the expected name of macros that return booleans

%{option1}

# this is the expected name of macros that return booleans and are valid in guard clauses

%{option2}

# this is the current name

%{actual}
```
