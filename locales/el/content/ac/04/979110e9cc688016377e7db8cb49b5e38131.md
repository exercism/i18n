# Ιδιοκτησία

Στο Cairo, η έννοια της ιδιοκτησίας συνδέεται με τις _μεταβλητές_ και όχι με τις _τιμές_ που κρατούν.

Οι τιμές στο Cairo είναι αμετάβλητες. Αυτή η αμεταβλητότητα διασφαλίζει ότι ακόμα κι αν πολλές μεταβλητές αναφέρονται στην ίδια τιμή, η ίδια η τιμή παραμένει σταθερή και αναλλοίωτη.
Έτσι, ο μεταγλωττιστής πρέπει να διασφαλίζει τη σωστή χρήση τους από τον προγραμματιστή.
Αυτή είναι η έννοια της _ιδιοκτησίας_ μεταβλητής: ο ιδιοκτήτης είναι ο κώδικας που μπορεί να διαβάσει (και να γράψει, αν επιτρέπεται η μεταβολή) τη μεταβλητή.

## Κανόνες ιδιοκτησίας μεταβλητών

```console
1. Each variable in Cairo has an owner.
2. There can only be one owner at a time.
3. When the owner goes out of scope, the variable is destroyed.
```

## Εμβέλεια μεταβλητής

Η εμβέλεια είναι το εύρος μέσα σε ένα πρόγραμμα στο οποίο μια μεταβλητή είναι έγκυρη.
Ας δούμε το παρακάτω παράδειγμα που δηλώνει μια μεταβλητή `x` ανυπόγραφου ακέραιου τύπου, με σχόλια που σημειώνουν πού είναι έγκυρη η μεταβλητή:

```rust
fn main() {
                      // `x` is not valid here, it has not been declared yet
    let x: u32 = 3;   // `x` is declared, it is valid from this point forward
                      // do stuff with `x`

} // this scope ended here, `x` goes out of scope and is no longer valid
```

Σημειώσεις:

- Όταν το `x` μπαίνει στην εμβέλεια, είναι έγκυρο.
- Παραμένει έγκυρο μέχρι να βγει από την εμβέλεια, στην περίπτωση αυτή μέχρι το τέλος της συνάρτησης `main()`.

## Μετακίνηση τιμών

Μια μετακίνηση συμβαίνει όταν μια τιμή περνά σε μια άλλη συνάρτηση, καταστρέφοντας την αρχική μεταβλητή που αναφερόταν στην τιμή (καθιστώντας έτσι τη μεταβλητή άχρηστη) και δημιουργώντας μια νέα μεταβλητή που θα κρατήσει την ίδια τιμή.

Οι πίνακες είναι ένα παράδειγμα σύνθετου τύπου που μετακινείται όταν περαστεί σε άλλη συνάρτηση.
Ακολουθεί μια σύντομη υπενθύμιση του πώς μοιάζει ένας πίνακας:

```rust
    let mut arr: Array<u128> = array![];
    arr.append(1);
    arr.append(2);
```

Πώς διασφαλίζει το σύστημα τύπων ότι το πρόγραμμα Cairo δεν θα προσπαθήσει ποτέ να γράψει δύο φορές στο ίδιο κύτταρο μνήμης;
Θεώρησε τον παρακάτω κώδικα, όπου προσπαθούμε να αφαιρέσουμε το πρώτο στοιχείο του πίνακα δύο φορές:

```rust
fn foo(mut arr: Array<u128>) {
    arr.pop_front();
}

fn main() {
    let arr: Array<u128> = array![1];
    foo(arr);
    foo(arr); // -> compiler error: Variable was previously moved.
}
```

Σε αυτή την περίπτωση, προσπαθούμε να περάσουμε την ίδια τιμή (τον πίνακα στη μεταβλητή `arr`) και στις δύο κλήσεις συναρτήσεων.
Αυτό σημαίνει ότι ο κώδικάς μας προσπαθεί να αφαιρέσει το πρώτο στοιχείο δύο φορές, κάτι που θα προσπαθούσε να γράψει δύο φορές στο ίδιο κύτταρο μνήμης, κάτι που απαγορεύεται από την εικονική μηχανή του Cairo, οδηγώντας σε σφάλμα χρόνου εκτέλεσης.
Ευτυχώς, αυτός ο κώδικας στην πραγματικότητα δεν μεταγλωττίζεται.
Μόλις περάσουμε τον πίνακα στη συνάρτηση `foo`, η μεταβλητή `arr` δεν είναι πλέον χρησιμοποιήσιμη.
Παίρνουμε αυτό το σφάλμα χρόνου μεταγλώττισης, που μας λέει ότι θα χρειαζόμασταν ο `Array` να υλοποιεί το trait `Copy`:

## Το trait `Copy`

Αν ένας τύπος υλοποιεί το trait `Copy`, το πέρασμά του σε μια συνάρτηση δεν μετακινεί την τιμή αλλά δημιουργεί μια νέα μεταβλητή που αναφέρεται στην ίδια τιμή.
Αυτή είναι μια λειτουργία μηδενικού κόστους επειδή οι μεταβλητές είναι μια αφαίρεση του Cairo και οι τιμές είναι πάντα αμετάβλητες.

Για να υλοποιήσεις το trait `Copy` στον τύπο σου, πρόσθεσε τη σημείωση `#[derive(Copy)]` στον ορισμό του τύπου.
Ωστόσο, το Cairo δεν θα το επιτρέψει αυτό αν ο τύπος ή οποιοδήποτε από τα συστατικά του δεν υλοποιεί το trait `Copy`.

```rust
#[derive(Copy, Drop)]
struct Point {
    x: u128,
    y: u128,
}

fn main() {
    let p1 = Point { x: 5, y: 10 };
    foo(p1);
    foo(p1);
}

fn foo(p: Point) { // do something with p
}
```

## Καταστροφή τιμών

Οι γραμμικοί τύποι μπορούν επίσης να αξιοποιηθούν με το να καταστραφούν, κάτι που διασφαλίζει ότι ο σχετιζόμενος πόρος απελευθερώνεται σωστά.
Αυτό επιτυγχάνεται υλοποιώντας ή παράγοντας το trait `Drop`, το οποίο σηματοδοτεί στον μεταγλωττιστή ότι ο τύπος μπορεί να καταστραφεί με ασφάλεια μόλις πάψει να είναι χρήσιμος.

```rust
#[derive(Drop)]
struct A {}

fn main() {
    A {}; // this value can be destroyed after going out of scope
}
```

Προς το παρόν, η υλοποίηση του `Drop` μπορεί να παραχθεί για όλους τους τύπους, εκτός από τα λεξικά (`Felt252Dict`) και τους τύπους που περιέχουν λεξικά.
Αυτό συμβαίνει επειδή τα λεξικά πρέπει να "συμπιεστούν" όταν καταστρέφονται.
Για αυτό, παράγουμε το trait `Destruct`:

```rust
#[derive(Destruct)]
struct A {
    dict: Felt252Dict<u128>
}

fn main() {
    A { dict: Default::default() };
}
```

## Τιμές επιστροφής και εμβέλεια

Η επιστροφή τιμών είναι ισοδύναμη με τη μετακίνησή τους.
Το παρακάτω παράδειγμα δείχνει μια συνάρτηση που επιστρέφει κάποια τιμή:

```rust
#[derive(Drop)]
struct A {}

fn main() {
    let a1 = gives_ownership();           // gives_ownership moves its return
                                          // value into a1

    let a2 = A {};                        // a2 comes into scope

    let a3 = takes_and_gives_back(a2);    // a2 is moved into
                                          // takes_and_gives_back, which also
                                          // moves its return value into a3

} // Here, a3 goes out of scope and is dropped. a2 was moved, so nothing
  // happens. a1 goes out of scope and is dropped.

fn gives_ownership() -> A {               // gives_ownership will move its
                                          // return value into the function
                                          // that calls it

    let some_a = A {};                    // some_a comes into scope

    some_a                                // some_a is returned and
                                          // moves ownership to the calling
                                          // function
}

// This function takes an instance some_a of A and returns it
fn takes_and_gives_back(some_a: A) -> A { // some_a comes into scope

    some_a                                // some_a is returned and
                                          // moves ownership to the calling
                                          // function
}
```
