# Εισαγωγή

Η κατανόηση των αναφορών είναι θεμελιώδες στοιχείο για να χρησιμοποιείς την Perl αποτελεσματικά.
Επειδή οι αναφορές είναι scalars, και οι πίνακες και τα hash μπορούν να περιέχουν μόνο scalars, οι αναφορές είναι το κλειδί για την εμφώλευση αυτών των δομών δεδομένων.

Μπορείς να δημιουργήσεις αναφορές για υπάρχουσες μεταβλητές και υπορουτίνες χρησιμοποιώντας τον τελεστή ανάποδης καθέτου `\`:

* `\$scalar` για να δημιουργήσεις μια αναφορά σε scalar (μπορεί να είναι οποιοδήποτε scalar, π.χ. `\1`, όχι μόνο μια μεταβλητή).
* `\@array` για να δημιουργήσεις μια αναφορά σε πίνακα.
* `\%hash` για να δημιουργήσεις μια αναφορά σε hash.
* `\&sub` για να δημιουργήσεις μια αναφορά σε κώδικα.

Μπορείς επίσης να δημιουργήσεις αυτό που είναι γνωστό ως ανώνυμη αναφορά για πίνακες, hash και υπορουτίνες:

* `['Alice', 'Bob', 'Charlie']` για να δημιουργήσεις μια ανώνυμη αναφορά σε πίνακα.
* `{foo => 'a', bar => 'b', baz => 'c'}` για να δημιουργήσεις μια ανώνυμη αναφορά σε hash.
* `sub { return 1 }` για να δημιουργήσεις μια ανώνυμη αναφορά σε κώδικα.

ΠΡΟΕΙΔΟΠΟΙΗΣΗ: Τα άγκιστρα στην Perl μπορεί να είναι διφορούμενα σε ορισμένα συμφραζόμενα. Αν δεν παίρνεις την αναφορά σε hash που περιμένεις, πρόσθεσε ένα συν μπροστά για να το ξεκαθαρίσεις, π.χ. `+{}`. Δες τα [Άγκιστρα][perlrefcurlybrackets] για περισσότερες πληροφορίες.

Μπορείς να έχεις πρόσβαση στις αναφορές χρησιμοποιώντας τον τελεστή βέλους `->`:

* `$ref->[0]` για να έχεις πρόσβαση σε ένα στοιχείο μέσα σε μια αναφορά σε πίνακα.
* `$ref->{foo}` για να έχεις πρόσβαση σε μια τιμή μέσα σε μια αναφορά σε hash.
* `$ref->($arg)` για να καλέσεις μια υπορουτίνα μέσω μιας αναφοράς σε κώδικα.

Μπορείς να έχεις πρόσβαση σε δεδομένα μέσα σε πολύπλοκες δομές δεδομένων, όπως πολυδιάστατους πίνακες και εμφωλευμένα hash, αλυσιδώνοντας θέσεις, π.χ. `$ref->{foo}[0]{bar}` (ίδιο με `$ref->{foo}->[0]->{bar}`).

Αν θέλεις να προσπελάσεις ολόκληρο τον πίνακα ή το hash μέσω της αναφοράς, μπορείς να χρησιμοποιήσεις τον τελεστή βέλους ακολουθούμενο από `@*` ή `%*` αντίστοιχα, π.χ. `$ref->@*` ή `$ref->%*`.
Μπορείς επίσης να πάρεις slices από μια αναφορά σε πίνακα ή hash, αντικαθιστώντας το `*` με μια θέση, π.χ. `$ref->@[0..2]` ή `$ref->@{'Foo', 'Bar'}`.
Στα slices, η εναλλαγή του sigil ισχύει εδώ με τον ίδιο τρόπο όπως και στις μεταβλητές πίνακα και hash.

[perlrefcurlybrackets]: https://perldoc.perl.org/perlref#Curly-Brackets
