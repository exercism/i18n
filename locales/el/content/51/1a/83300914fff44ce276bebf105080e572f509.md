# Βασικά στοιχεία του `match`

Η έκφραση `match` επιτρέπει την εύκολη σύγκριση μιας τιμής με μια σειρά μοτίβων και στη συνέχεια την εκτέλεση του κώδικα με βάση το μοτίβο που ταιριάζει.
Ένα μοτίβο αποτελείται από κυριολεκτικές τιμές, ονόματα μεταβλητών, μπαλαντέρ και πολλά άλλα πράγματα.

```rust
#[derive(Drop)]
enum Color {
    Red,
    Yellow,
    Green,
}

fn print_color_type(color: Color) {
    match color {
        Color::Red => println!("The color is Red"),
        Color::Yellow => println!("The color is Yellow"),
        Color::Green => println!("The color is Green"),
    }
}

fn main() {
    let color = Color::Yellow;
    print_color_type(color); // prints "The color is Yellow"
}
```

Για να χειριστείς πολλές γραμμές κώδικα, ο κλάδος του `match` πρέπει να περικλείεται σε άγκιστρα `{}`:

```rust
fn specified_color(color: Color) -> felt252 {
    let mut response: felt252 = '';

    match color {
        Color::Red => {
            response = 'You passed in Red';
        },
        Color::Yellow => {
            response = 'You passed in Yellow';
        },
        Color::Green => {
            response = 'You passed in Green';
        },
    }

    response
}
```

Η έκφραση `match` έχει επίσης τη δυνατότητα δέσμευσης σε τιμές που ταιριάζουν με το μοτίβο.
Αυτό καθιστά δυνατή την εξαγωγή της συσχετισμένης τιμής μιας παραλλαγής enum.

```rust
#[derive(Drop, Debug)]
enum ColorType {
    Light,
    Dark,
}

#[derive(Drop)]
enum Color {
    Red: ColorType,
    Yellow,
    Green,
}

fn print_color_type(color: Color) {
    match color {
        Color::Red(state) => {
            println!("The color is Red");
            println!("The Color Type is {:?}", state);
        },
        Color::Yellow => println!("The color is Yellow"),
        Color::Green => println!("The color is Green"),
    }
}

fn main() {
    let color = Color::Red(ColorType::Dark);
    print_color_type(color);
}
```

Επεκτείνοντας την παραλλαγή `Red` του enum `Color` ώστε να έχει ένα συσχετισμένο enum.
Με τη βοήθεια της έκφρασης `match`, μπορούμε να εξαγάγουμε τη συσχετισμένη τιμή, το `state`.
Αυτό είναι απλώς ένα όνομα μεταβλητής που μπορεί να χρησιμοποιηθεί στη συνέχεια μέσα στον κλάδο κώδικα.

## Αντιστοίχιση του τύπου enum `Option`

Το ενσωματωμένο enum `Option` μπορεί επίσης να χειριστεί με την έκφραση `match`.

Ας σχεδιάσουμε μια συνάρτηση που δέχεται μια παράμετρο `Option<u8>`.
Αν υπάρχει κάποια τιμή στην παράμετρο που δίνεται, πρόσθεσε ένα σε αυτή την τιμή, αλλιώς η συνάρτηση πρέπει να επιστρέψει την τιμή `None` χωρίς να κάνει κάποια ενέργεια.

```rust
fn add_one(x: Option<u8>) -> Option<u8> {
    match x {
        Option::Some(val) => Option::Some(val + 1),
        Option::None => Option::None,
    }
}

fn main() {
    let three: Option<u8> = Option::Some(3);
    let four: Option<u8> = add_one(three);
    let none = add_one(Option::None);

    println!("{three:?}"); // prints "Option::Some(3)"
    println!("{four:?}"); // prints "Option::Some(4)"
    println!("{none:?}"); // prints "Option::None(())"
}
```

> Σημείωση: Το `{:?}` είναι μια ειδική σύνταξη μορφοποίησης που επιτρέπει την εκτύπωση μιας μορφής debug της παραμέτρου που περνά στη μακροεντολή `println!`.
> Μπορείς να βρεις περισσότερες πληροφορίες γι' αυτό στο [The Cairo Book][debugging].

Ένα πλεονέκτημα της χρήσης της ροής ελέγχου `match` είναι η εξαντλητική της φύση: τα μοτίβα των κλάδων πρέπει να καλύπτουν _όλες_ τις δυνατότητες.
Δες την εκδοχή του προηγούμενου παραδείγματος που δεν χειρίζεται την περίπτωση `None`:

```rust
fn add_one(x: Option<u8>) -> Option<u8> {
    match x {
        Option::Some(val) => Option::Some(val + 1),
    }
     // this code does not compile, as we forgot to handle the `None` case
}
```

## Μοτίβο που καλύπτει τα πάντα με τον μπαλαντέρ `_`

Χρησιμοποιώντας enum, μπορούμε επίσης να κάνουμε ειδικές ενέργειες για μερικές συγκεκριμένες τιμές, αλλά για όλες τις άλλες τιμές να εκτελούμε μία προεπιλεγμένη ενέργεια, προσθέτοντας έναν νέο κλάδο με `_` ως μοτίβο για τον τελευταίο κλάδο της έκφρασης `match`.
Το μοτίβο `_` είναι ένα ειδικό μοτίβο που ταιριάζει με οποιαδήποτε τιμή και δεν δεσμεύεται σε αυτή την τιμή.

Η συνάρτηση `is_red` δέχεται μια παράμετρο και επιστρέφει `true` αν το χρώμα είναι `Red` και `false` για οποιοδήποτε άλλο χρώμα:

```rust
fn is_red(color: Color) -> bool {
    match color {
        Color::Red => true,
        _ => false,
    }
}
```

## Αντιστοίχιση μοτίβων με τον τελεστή `|`

Η δομή ροής ελέγχου `match` της Cairo επιτρέπει την αντιστοίχιση μιας τιμής με πολλά μοτίβα χρησιμοποιώντας τον τελεστή `|` (_ή_).
Αυτό βοηθά στην απλοποίηση του κώδικα.

Για παράδειγμα, χρησιμοποιώντας το enum `Color`, θέλουμε να γράψουμε μια συνάρτηση που επιστρέφει `true` για τα χρώματα `Red` ή `Green` και `false` για τα άλλα χρώματα:

```rust
fn is_red_or_green(color: Color) -> bool {
    match color {
        Color::Red | Color::Green => true,
        _ => false,
    }
}
```

## Αντιστοίχιση μοτίβων με `felt252` και ακέραιες μεταβλητές

Είναι δυνατή η αντιστοίχιση μεταβλητών `felt252` και ακέραιων μεταβλητών με ένα σύνολο τιμών.
Ωστόσο, υπάρχουν κάποιοι περιορισμοί:

- Υποστηρίζονται μόνο ακέραιοι που χωρούν σε ένα μόνο `felt252` (δηλαδή το `u256` δεν υποστηρίζεται).
- Το 0 πρέπει να είναι ο πρώτος κλάδος.
- Κάθε κλάδος πρέπει να ακολουθεί ένα διαδοχικό τμήμα, συνεχόμενα με τους άλλους κλάδους.

Ας υλοποιήσουμε ένα παιχνίδι ρίψης ζαριού με έξι πλευρές.
Όταν ρίχνουμε αυτό το ζάρι, παίρνουμε έναν αριθμό μεταξύ 0 και 5.
Για μια ρίψη που φέρνει 0, 1 ή 2, κερδίζεις.
Ρίχνεις ξανά αν φέρεις 3.
Χάνεις για τις άλλες τιμές:

```rust
fn toss(value: u8) {
    match value {
        0 | 1 | 2 => println!("you won!"),
        3 => println!("you can roll again!"),
        _ => println!("you lost...")
    }
}

fn main() {
    toss(2); // prints "you won!".
    toss(3); // prints "you can roll again!".
    toss(5); // prints "you lost...".
}
```

## Αντιστοίχιση πλειάδων

Οι πλειάδες μπορούν επίσης να αντιστοιχιστούν με ένα σύνολο μοτίβων.
Αυτά τα μοτίβα σχεδιάζονται με παρόμοιο τρόπο όπως μια πλειάδα.

```rust
#[derive(Drop)]
enum DayType {
    Week,
    Weekend,
    Holiday
}

enum Coin {
    Penny,
    Nickel,
    Dime,
    Quarter,
}

fn vending_machine_accept(c: (DayType, Coin)) -> bool {
    match c {
        (DayType::Week, _) => true, // accepts all coins during week day
        (_, Coin::Dime) | (_, Coin::Quarter) => true, // accepts only Dime or Quarter coin for all specified days
        (_, _) => false, // returns false for other instances
    }
}
```

Στον τελευταίο κλάδο του `match`, δεν έχει σημασία αν χρησιμοποιούμε `(_, _)` ή απλώς τον μπαλαντέρ `_` για να αντιστοιχίσουμε οποιονδήποτε συνδυασμό ημέρας και χρώματος, γιατί λειτουργικά είναι το ίδιο.
