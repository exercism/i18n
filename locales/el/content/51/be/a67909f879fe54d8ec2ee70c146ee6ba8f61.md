# Οδηγίες

Πάρε μια εμφωλευμένη λίστα και επέστρεψε μία ενιαία επίπεδη λίστα με όλες τις τιμές, εκτός από τις τιμές nil/null.

Η πρόκληση είναι να γράψεις μια συνάρτηση που δέχεται μια δομή σαν λίστα, εμφωλευμένη σε αυθαίρετο βάθος, και επιστρέφει μια επίπεδη δομή χωρίς καμία τιμή nil/null.

Για παράδειγμα:

είσοδος: [1,[2,3,null,4],[null],5]

έξοδος: [1,2,3,4,5]
