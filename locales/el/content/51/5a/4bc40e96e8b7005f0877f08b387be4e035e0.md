# Οδηγίες

Σε αυτήν την άσκηση θα γράφεις κώδικα για να εκτυπώνεις σήματα με ονόματα για τους υπαλλήλους του εργοστασίου.

## 1. Εκτύπωσε ένα σήμα για έναν υπάλληλο

Οι υπάλληλοι έχουν ένα ID, ένα όνομα και ένα όνομα τμήματος.
Οι ετικέτες των σημάτων των υπαλλήλων έχουν την εξής μορφή: `"[id] - name - DEPARTMENT"`.
Υλοποίησε τη μέθοδο `printBadge()` ώστε να επιστρέφει την ετικέτα του σήματος ενός υπαλλήλου:

```kotlin
printBadge(734, "Ernest Johnny Payne", "Strategic Communication")
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

~~~~exercism/note
Πρόσεξε ότι το τμήμα πρέπει να γράφεται με κεφαλαία γράμματα στην ετικέτα.
~~~~

## 2. Εκτύπωσε ένα σήμα για έναν νέο υπάλληλο

Λόγω μιας ιδιορρυθμίας στο σύστημα του υπολογιστή, οι νέοι υπάλληλοι μερικές φορές δεν έχουν ακόμη ID όταν ξεκινούν να δουλεύουν στο εργοστάσιο.
Καθώς τα σήματα είναι υποχρεωτικά, θα λάβουν ένα προσωρινό σήμα χωρίς το πρόθεμα ID.
Τροποποίησε τη μέθοδο `printBadge()` ώστε να υποστηρίζει νέους υπαλλήλους που δεν έχουν ακόμη ID:

```kotlin
printBadge(null, "Jane Johnson", "Procurement")
// => "Jane Johnson - PROCUREMENT"
```

## 3. Εκτύπωσε ένα σήμα για τον ιδιοκτήτη

Ακόμη και ο ιδιοκτήτης του εργοστασίου πρέπει να φοράει σήμα ανά πάσα στιγμή.
Ωστόσο, ο ιδιοκτήτης δεν έχει τμήμα.
Σε αυτήν την περίπτωση, η ετικέτα πρέπει να εκτυπώνει `"OWNER"` αντί για το όνομα του τμήματος.
Τροποποίησε τη μέθοδο `printBadge()` ώστε να εκτυπώνει μια ετικέτα για τον ιδιοκτήτη:

```kotlin
printBadge(254, "Charlotte Hale", null)
// => "[254] - Charlotte Hale - OWNER"
```

~~~~exercism/note
Πρόσεξε ότι ο ιδιοκτήτης μπορεί να είναι ταυτόχρονα και νέος υπάλληλος:

```kotlin
printBadge(null, "Charlotte Hale", null)
// => "Charlotte Hale - OWNER"
```
~~~~
