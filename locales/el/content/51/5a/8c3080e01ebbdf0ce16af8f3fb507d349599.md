# Εισαγωγή

Η μονάδα `Agent` παρέχει μια αφαίρεση για τη δημιουργία [διεργασιών και του βρόχου _receive-send_][exercism-processes]. Από εδώ και πέρα, τις διεργασίες που ξεκινούν με τη χρήση της μονάδας `Agent` θα τις αποκαλούμε _"διεργασίες agent"_. Μια _διεργασία agent_ μπορεί να επιλεγεί για να αναπαραστήσει μια κεντρική κοινόχρηστη κατάσταση.

Για να ξεκινήσεις μια _διεργασία agent_, το `Agent` παρέχει τη συνάρτηση `start/2`. Η συνάρτηση που δίνεις όταν ξεκινάς τη _διεργασία agent_ με τη `start` επιστρέφει την αρχική κατάσταση της διεργασίας:

```elixir
# Start an agent process with an initial value of an empty list
{:ok, agent_pid} = Agent.start(fn -> [] end)
```

Όπως το `Map` ή το `List`, το `Agent` παρέχει πολλές συναρτήσεις για να δουλεύεις με _διεργασίες agent_.

Συνηθίζεται να οργανώνεις και να ενθυλακώνεις όλη τη λειτουργικότητα που σχετίζεται με το `Agent` σε μια μονάδα για το πεδίο που μοντελοποιείς.

[exercism-processes]: https://exercism.org/tracks/elixir/concepts/processes
