# Οδηγίες

Η αποστολή σου είναι να λύσεις ένα δυαδικό παζλ.
Κάθε δυαδικό παζλ έχει ακριβώς _μία_ λύση, η οποία μπορεί να βρεθεί εφαρμόζοντας αυτούς τους κανόνες:

1. Κάθε κελί πρέπει να περιέχει είτε μηδέν είτε άσσο.
2. Περισσότερα από δύο ίδια ψηφία δεν μπορούν να είναι γειτονικά. Έτσι, αν δύο γειτονικά κελιά περιέχουν το ίδιο ψηφίο, τα κελιά δίπλα τους πρέπει να περιέχουν το άλλο ψηφίο.
3. Κάθε γραμμή και κάθε στήλη πρέπει να περιέχει ίσο αριθμό μηδενικών και άσσων.
4. Κάθε γραμμή και κάθε στήλη είναι μοναδική.

Θα σου δοθεί ένα ημιτελές παζλ ως γραμμές από μηδενικά και άσσους, με σύμβολα αντικατάστασης (`_`) για τις άγνωστες τιμές.
Ο στόχος είναι να ορίσεις τους κανόνες του δυαδικού παζλ, ώστε τα tests να μπορούν να βρουν τις τιμές για τα σύμβολα αντικατάστασης (δεν το κάνεις αυτό μόνος σου).
Η υλοποίησή σου πρέπει να χρησιμοποιεί το [Constraint Logic Programming over Finite Domains (CLP(FD))](https://www.swi-prolog.org/man/clpfd.html) της Prolog, που είναι ιδανικό για τέτοιου είδους εργασίες.

````exercism/note
Για να ξεκινήσεις, το αρχείο stub περιλαμβάνει ήδη τη [βιβλιοθήκη `clpfd`](https://www.swi-prolog.org/man/clpfd.html) μέσω:

```prolog
:- use_module(library(clpfd)).
```
````
