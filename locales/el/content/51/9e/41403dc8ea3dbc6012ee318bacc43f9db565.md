# Εισαγωγή

Η Julia ενθαρρύνει τους προγραμματιστές να βάζουν όσο περισσότερο κώδικα γίνεται μέσα σε συναρτήσεις που μπορούν να μεταγλωττιστούν με JIT, και η δημιουργία πολλών μικρών συναρτήσεων είναι, εκ σχεδιασμού, αποδοτική.

Αυτό έχει την τάση να αφήνει πολλές μικρές, απλές συναρτήσεις, οι οποίες πρέπει να συνδυαστούν για να φέρουν εις πέρας μη τετριμμένες εργασίες.

Μια προφανής προσέγγιση είναι η εμφώλευση κλήσεων συναρτήσεων.
Το παρακάτω παράδειγμα είναι πολύ επιτηδευμένο, αλλά δείχνει το σημείο.

```julia-repl
julia> first.(titlecase.(reverse.(["my", "test", "strings"])))
3-element Vector{Char}:
 'Y': ASCII/Unicode U+0059 (category Lu: Letter, uppercase)
 'T': ASCII/Unicode U+0054 (category Lu: Letter, uppercase)
 'S': ASCII/Unicode U+0053 (category Lu: Letter, uppercase)
```

Το μειονέκτημα αυτής της προσέγγισης είναι ότι η αναγνωσιμότητα πέφτει γρήγορα όσο βαθαίνει η εμφώλευση.

Χρειαζόμαστε μια απλούστερη και πιο ευέλικτη προσέγγιση.

## Σύνθεση

Αυτή είναι η τεχνική που αγαπούν οι μαθηματικοί, και η Julia αντιγράφει τη μαθηματική σύνταξη.

Οποιοσδήποτε αριθμός συναρτήσεων μπορεί να [`composed`][comp] μαζί με τελεστές `∘` (τους πληκτρολογείς ως `\circ` και μετά tab).
Το αποτέλεσμα μπορεί να χρησιμοποιηθεί ως μία μόνο συνάρτηση.

```julia-repl
julia> compfunc = first ∘ titlecase ∘ reverse
first ∘ titlecase ∘ reverse
julia> compfunc.(["my", "test", "strings"])
3-element Vector{Char}:
 'Y': ASCII/Unicode U+0059 (category Lu: Letter, uppercase)
 'T': ASCII/Unicode U+0054 (category Lu: Letter, uppercase)
 'S': ASCII/Unicode U+0053 (category Lu: Letter, uppercase)
# alternative syntax, giving the same result
julia> (first ∘ titlecase ∘ reverse).(["my", "test", "strings"])
```

Δύο σημεία που αξίζει να προσέξεις:

- Οι αρχικές συναρτήσεις εμφανίζονται με την ίδια σειρά όπως στην εμφώλευση και εκτελούνται με σειρά από τα δεξιά προς τα αριστερά.
- Το broadcasting δεν είναι απλό στη χρήση κατά τη σύνθεση, αλλά μπορεί να εφαρμοστεί κατά την κλήση της συντεθειμένης συνάρτησης.

## Διοχέτευση

Μια εναλλακτική θα μπορούσε να θεωρηθεί η προσέγγιση των _προγραμματιστών_ και όχι των _μαθηματικών_.

Οι [`Pipelines`][comp] χρησιμοποιούνται εδώ και καιρό σε σενάρια κελύφους του Unix και πιο πρόσφατα έγιναν δημοφιλείς σε mainstream γλώσσες προγραμματισμού (στη F# αποδίδεται μερικές φορές η πρωτοπορία της υιοθέτησής τους).

Η βασική ιδέα είναι να ξεκινήσεις με κάποια δεδομένα και μετά να τα διοχετεύσεις μέσω μιας σειράς συναρτήσεων για να πάρεις το αποτέλεσμα.

Ο τελεστής διοχέτευσης είναι ο `|>` (όπως στη F# και σε πρόσφατες εκδόσεις της R), αν και η Julia έχει και μια έκδοση για broadcasting, τον `.|>`.

```julia-repl
julia> ["my", "test", "strings"] .|> reverse .|> titlecase .|> first
3-element Vector{Char}:
 'Y': ASCII/Unicode U+0059 (category Lu: Letter, uppercase)
 'T': ASCII/Unicode U+0054 (category Lu: Letter, uppercase)
 'S': ASCII/Unicode U+0053 (category Lu: Letter, uppercase)
```

Η εκτέλεση τώρα γίνεται αυστηρά από τα αριστερά προς τα δεξιά, με την έξοδο κάθε συνάρτησης να ρέει προς την κατεύθυνση του βέλους και να γίνεται η είσοδος για την επόμενη συνάρτηση.

## Περιορισμοί, παρακάμψεις και άλλες επιλογές

Δεν είναι τυχαίο ότι οι συναρτήσεις που χρησιμοποιούνται για να δείξουν τη σύνθεση και τη διοχέτευση παίρνουν όλες ένα _μόνο_ όρισμα.

Κάποιες καθαρά συναρτησιακές γλώσσες διοχετεύουν το _πρώτο_ όρισμα σε μια συνάρτηση αλλά επιτρέπουν να συμπεριληφθούν και άλλα.

Αντίθετα, η Julia περιμένει μόνο _ονόματα_ συναρτήσεων (ή κάτι ισοδύναμο) σε μια διοχέτευση, χωρίς πρόσθετα ορίσματα.

Υπάρχουν σημαντικοί τεχνικοί λόγοι γι' αυτό (που σχετίζονται με το γεγονός ότι το [`currying`][currying] δεν αποτελεί στάνταρ μέρος του σχεδιασμού της γλώσσας).
Οι _πολλοί_ άνθρωποι που δεν καταλαβαίνουν το currying θα πρέπει απλώς να δεχτούν ότι αυτός ο περιορισμός δεν είναι μια απρόσεκτη παράλειψη και δεν είναι πιθανό να αλλάξει σε μελλοντικές εκδόσεις της Julia.

### Παρακάμψεις

Χρειαζόμαστε συναρτήσεις με ένα μόνο όρισμα που κάνουν ό,τι χρειάζεται.
Ευτυχώς, ο ορισμός νέων συναρτήσεων στη Julia είναι εύκολος.

Πιο απλά, θα μπορούσαμε να χρησιμοποιήσουμε μια [`anonymous function`][anonymous-function].
Για παράδειγμα, αν έχουμε μία συμβολοσειρά εισόδου και θέλουμε να τη χωρίσουμε με βάση τις κάτω παύλες:

```julia-repl
julia> "my_test_strings" |> (s -> split(s, '_'))
3-element Vector{SubString{String}}:
 "my"
 "test"
 "strings"
```

Αυτό το διάνυσμα θα μπορούσε τότε να διοχετευτεί σε άλλες συναρτήσεις, όπως και πριν.

Η περικύκλωση της ανώνυμης συνάρτησης σε παρενθέσεις είναι προαιρετική σε αυτή την περίπτωση, αλλά γενικότερα αποτελεί έναν χρήσιμο τρόπο για να μειώσεις την ασάφεια.

Παρομοίως, θα μπορούσαμε να δημιουργήσουμε μια ονομασμένη συνάρτηση, νωρίτερα στο πρόγραμμα, και να την επαναχρησιμοποιήσουμε όποτε χρειάζεται.
