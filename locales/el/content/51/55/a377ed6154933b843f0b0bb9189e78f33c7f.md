# Εισαγωγή

Ένας βρόχος είναι ένας τρόπος να καλείς επανειλημμένα μία ή περισσότερες εντολές μαζί, σε μια ομάδα.
Κάθε εκτέλεση μιας ομάδας εντολών ονομάζεται επανάληψη.

## Ο βρόχος `while`

Ο βρόχος `while` εκτελεί μια ομάδα εντολών όσο μια έκφραση Boolean στην αρχή του βρόχου είναι αληθής.
Όταν η έκφραση Boolean είναι ψευδής, ο βρόχος σταματά να εκτελείται και η εκτέλεση προχωρά στην επόμενη γραμμή κώδικα μετά τον βρόχο.

Αν η έκφραση Boolean αξιολογείται ως ψευδής από την αρχή, ο βρόχος `while` δεν θα εκτελεστεί καθόλου και η εκτέλεση θα προχωρήσει στην επόμενη γραμμή κώδικα μετά τον βρόχο.

```c
int main() {
    int i = 0;
    while (i < 5) {
        printf("Number is %i\n", i++);
    }    
    return 0;
}
```

Είναι σημαντικό να υπάρχει μια συνθήκη που τερματίζει τον βρόχο. Διαφορετικά, πρόκειται για έναν άπειρο βρόχο που θα μπλοκάρει κάθε πρόοδο του κώδικα.
Αν από τον παραπάνω κώδικα αφαιρούσαμε το `++` από το `i`, θα ήταν ένας άπειρος βρόχος.

## Ο βρόχος `do`

Ο βρόχος `do` ελέγχει την έκφραση Boolean στο τέλος του βρόχου.
Ο βρόχος `do` εκτελείται πάντα τουλάχιστον μία φορά, όπως στο παρακάτω παράδειγμα

```c
do {
    printf("Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
} while (answer != 42); 
// Note that a semicolon is needed after the Boolean expression.
```

Με έναν βρόχο `while` αυτό θα ήταν πιο φλύαρο

```c
printf(""Enter the Answer to the Ultimate Question of Life: ");
scanf("%d", &answer);
while (answer != 42) {
    printf(""Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
}
```

## Ο βρόχος `for`

Συχνά ένας βρόχος ενημερώνει μια μεταβλητή και τερματίζεται όταν η μεταβλητή φτάσει σε μια συγκεκριμένη τιμή.
Ο βρόχος `for` είναι ένας τρόπος να αρχικοποιείς, να ενημερώνεις και να ελέγχεις μία ή περισσότερες μεταβλητές σε μία γραμμή, μέσα σε παρενθέσεις.
Το πρώτο τμήμα είναι για την αρχικοποίηση της μεταβλητής, το δεύτερο για τον έλεγχό της και το τρίτο για την ενημέρωση της τιμής της μεταβλητής.

```c
for (int i = 0; i < 5; i++) {
    printf("Number is %i\n", i);
}
```

Αυτό είναι λιγότερο φλύαρο από τον αντίστοιχο βρόχο `while` και παραμένει ευανάγνωστο.
