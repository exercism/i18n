# Οδηγίες

Σε αυτή την άσκηση θα παίξεις με ένα τηλεχειριζόμενο αυτοκίνητο, για το οποίο τελικά μάζεψες αρκετά χρήματα ώστε να το αγοράσεις.

Τα αυτοκίνητα ξεκινούν με πλήρη μπαταρία (100%). Κάθε φορά που οδηγείς το αυτοκίνητο με το τηλεχειριστήριο, διανύει 20 μέτρα και καταναλώνει ένα τοις εκατό της μπαταρίας.

Το τηλεχειριζόμενο αυτοκίνητο έχει μια εντυπωσιακή οθόνη LED που δείχνει δύο πληροφορίες:

- Τη συνολική απόσταση που έχει διανύσει, σε μορφή: `"Driven <METERS> meters"`.
- Την υπολειπόμενη φόρτιση της μπαταρίας, σε μορφή: `"Battery at <PERCENTAGE>%"`.

Αν η μπαταρία είναι στο 0%, δεν μπορείς να οδηγήσεις άλλο το αυτοκίνητο και η ένδειξη της μπαταρίας θα δείχνει `"Battery empty"`.

Έχεις έξι εργασίες, καθεμία από τις οποίες θα δουλέψει με στιγμιότυπα τηλεχειριζόμενου αυτοκινήτου.

## 1. Αγόρασε ένα ολοκαίνουριο τηλεχειριζόμενο αυτοκίνητο

Υλοποίησε τη (_static_) μέθοδο `RemoteControlCar.Buy()` ώστε να επιστρέφει ένα ολοκαίνουριο στιγμιότυπο τηλεχειριζόμενου αυτοκινήτου:

```csharp
RemoteControlCar car = RemoteControlCar.Buy();
```

## 2. Εμφάνισε την απόσταση που διανύθηκε

Υλοποίησε τη μέθοδο `RemoteControlCar.DistanceDisplay()` ώστε να επιστρέφει την απόσταση όπως εμφανίζεται στην οθόνη LED:

```csharp
var car = RemoteControlCar.Buy();
car.DistanceDisplay();
// => "Driven 0 meters"
```

## 3. Εμφάνισε το ποσοστό της μπαταρίας

Υλοποίησε τη μέθοδο `RemoteControlCar.BatteryDisplay()` ώστε να επιστρέφει το ποσοστό της μπαταρίας όπως εμφανίζεται στην οθόνη LED:

```csharp
var car = RemoteControlCar.Buy();
car.BatteryDisplay();
// => "Battery at 100%"
```

## 4. Ενημέρωσε τον αριθμό των μέτρων που διανύθηκαν κατά την οδήγηση

Υλοποίησε τη μέθοδο `RemoteControlCar.Drive()` που ενημερώνει τον αριθμό των μέτρων που διανύθηκαν:

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
car.DistanceDisplay();
// => "Driven 40 meters"
```

## 5. Ενημέρωσε το ποσοστό της μπαταρίας κατά την οδήγηση

Ενημέρωσε τη μέθοδο `RemoteControlCar.Drive()` ώστε να ενημερώνει το ποσοστό της μπαταρίας:

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
car.BatteryDisplay();
// => "Battery at 98%"
```

## 6. Απότρεψε την οδήγηση όταν η μπαταρία έχει αδειάσει

Ενημέρωσε τη μέθοδο `RemoteControlCar.Drive()` ώστε να μην αυξάνει την απόσταση που διανύθηκε ούτε να μειώνει το ποσοστό της μπαταρίας όταν η μπαταρία έχει αδειάσει (στο 0%):

```csharp
var car = RemoteControlCar.Buy();

// Drain the battery
// ...

car.DistanceDisplay();
// => "Driven 2000 meters"

car.BatteryDisplay();
// => "Battery empty"
```
