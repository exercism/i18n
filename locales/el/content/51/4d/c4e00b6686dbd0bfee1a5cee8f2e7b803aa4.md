# Εισαγωγή

Στη Factor, οι πίνακες κατακερματισμού είναι *συσχετιστικοί πίνακες*: συλλογές από ζεύγη `key/value` με αναζήτηση σε χρόνο O(1). Αποτελούν μέρος της ευρύτερης οικογένειας του [`assocs`][assocs].

## Άμεση κατασκευή πίνακα κατακερματισμού

```factor
H{ { "coal" 1 } { "wood" 2 } } .
```

Το `H{ }` είναι ένας κενός πίνακας κατακερματισμού. Οι πίνακες κατακερματισμού είναι *μεταβλητοί*: μεγαλώνουν και μικραίνουν καθώς προσθέτεις και αφαιρείς κλειδιά. Κάνε πρώτα `clone` αν θέλεις να μείνει ο αρχικός άθικτος. Η εκτύπωση ενός πίνακα κατακερματισμού δείχνει τις καταχωρήσεις του, αλλά η σειρά δεν ακολουθεί τη σειρά εισαγωγής: οι πίνακες κατακερματισμού δεν έχουν σειρά.

## Ανάγνωση

Το `at` (στο [`assocs`][assocs]) διαβάζει μια τιμή και επιστρέφει `f` αν λείπει το κλειδί:

```
at      ( key assoc -- value/f )
key?    ( key assoc -- ? )
```

```factor
"coal" H{ { "coal" 1 } { "wood" 2 } } at .   ! => 1
"gold" H{ { "coal" 1 } { "wood" 2 } } at .   ! => f
```

## Εγγραφή

Το `set-at` προσθέτει ή αντικαθιστά· το `delete-at` αφαιρεί· το `change-at` εκτελεί ένα quotation πάνω στην τρέχουσα τιμή. Και τα τρία *μεταβάλλουν* τον πίνακα:

```
set-at     ( value key assoc -- )
delete-at  ( key assoc -- )
change-at  ( key assoc quot: ( old -- new ) -- )
```

```factor
H{ } clone 5 "coal" pick set-at .
! => H{ { "coal" 5 } }
```

## `inc-at`: η συντόμευση για καταμέτρηση

Το `inc-at` (επίσης στο [`assocs`][assocs]) προσθέτει 1 στην υπάρχουσα τιμή για ένα κλειδί και, αν το κλειδί λείπει, το εισάγει με τιμή 1. Ιδανικό για καταμέτρηση:

```
inc-at ( key assoc -- )
```

```factor
H{ } clone "coal" over inc-at .
! => H{ { "coal" 1 } }
```

## Επανάληψη και οκνηρή εισαγωγή

Το `assoc-each` διατρέχει κάθε ζεύγος `( key value -- )`· το `cache` επιστρέφει την τιμή για ένα κλειδί και, αν το κλειδί λείπει, την υπολογίζει μία φορά με το quotation που του δίνεις.

```
assoc-each ( assoc quot: ( key value -- ) -- )
cache      ( key assoc quot: ( key -- value ) -- value )
```

Το `cache` είναι το μοτίβο "αναζήτησε ή δημιούργησε" σε μία μόνο λέξη: βολικό όταν φτιάχνεις έναν πίνακα κατακερματισμού από μια ροή κλειδιών και δεν θέλεις να χειρίζεσαι την περίπτωση του κλειδιού που λείπει σε κάθε σημείο κλήσης.

## Εφαρμογή ενημέρωσης του πίνακα κατακερματισμού σε μια ακολουθία κλειδιών

Όταν η είσοδος είναι μια ακολουθία κλειδιών και θέλεις να ενημερώσεις τον πίνακα κατακερματισμού μία φορά για κάθε κλειδί, διάτρεξε την *ακολουθία* με το `each` και χρησιμοποίησε ένα τηγανητό quotation `'[ _ … ]` (από το [`fry`][fry]) για να ενσωματώσεις τον πίνακα κατακερματισμού στο σώμα του βρόχου. Για παράδειγμα, για να αφαιρέσεις μια λίστα κλειδιών:

```factor
{ "wood" "iron" } H{ { "coal" 5 } { "wood" 3 } { "iron" 2 } } clone
[ '[ _ delete-at ] each ] keep .
! => H{ { "coal" 5 } }
```

Το `'[ _ delete-at ]` συλλαμβάνει τον πίνακα κατακερματισμού που βρίσκεται πάνω από αυτό στη στοίβα, ώστε σε κάθε επανάληψη το `each` να χρειάζεται να δώσει μόνο το κλειδί. Το `keep` εκτελεί το quotation κρατώντας ταυτόχρονα τον πίνακα κατακερματισμού για την τελική `.`.

## Κατασκευή πίνακα κατακερματισμού από μια ακολουθία

Το `map>assoc` (στο [`assocs`][assocs]) εφαρμόζει ένα quotation πάνω σε μια ακολουθία και συλλέγει τα αποτελέσματα `( elt -- key value )` σε ένα assoc του τύπου του exemplar:

```
map>assoc ( seq quot: ( elt -- key value ) exemplar -- assoc )
```

```factor
{ "wood" } [ dup length ] H{ } map>assoc .
! => H{ { "wood" 4 } }
```

## Κλειδιά, τιμές και ζεύγη

Τα `keys` και `values` (στο [`assocs`][assocs]) επιστρέφουν μόνο τα κλειδιά ή μόνο τις τιμές· το `>alist` επιστρέφει τα ζεύγη `{ key value }`.

```
keys   ( assoc -- keys )
values ( assoc -- values )
>alist ( assoc -- alist )
```

```factor
H{ { "wood" 11 } { "coal" 7 } } keys .     ! the keys (order not guaranteed)
H{ { "wood" 11 } { "coal" 7 } } values .   ! the matching values
```

Τα `keys` και `values` αντιστοιχίζονται μεταξύ τους: η τιμή σε μια θέση ανήκει στο κλειδί της ίδιας θέσης.

Το `sort-keys` (στο [`sorting`][sorting]) επιστρέφει τα ζεύγη `{ key value }` ταξινομημένα κατά κλειδί:

```factor
H{ { "wood" 11 } { "coal" 7 } } sort-keys .
! => { { "coal" 7 } { "wood" 11 } }
```

## Από τα ζεύγη πίσω στον πίνακα κατακερματισμού

Το `>hashtable` (στο [`hashtables`][hashtables]) είναι το αντίστροφο του `>alist`: μετατρέπει οποιοδήποτε assoc, συνήθως μια alist από ζεύγη `{ key value }`, σε πίνακα κατακερματισμού με αναζήτηση σε χρόνο O(1).

```
>hashtable ( assoc -- hashtable )
```

```factor
{ { "coal" 7 } { "wood" 11 } } >hashtable .
! => H{ { "wood" 11 } { "coal" 7 } }   (entry order not guaranteed)
```

Βολικό όταν έχεις συναρμολογήσει ή μετασχηματίσει μια λίστα από ζεύγη και θέλεις να τη διπλώσεις ξανά σε έναν πίνακα κατακερματισμού, για να αναζητάς καταχωρήσεις με βάση το κλειδί.
