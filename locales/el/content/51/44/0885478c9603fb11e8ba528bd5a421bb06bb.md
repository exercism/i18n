# Σχετικά

Στη Clojure, η δέσμευση μιας τιμής σε ένα όνομα ονομάζεται [_var_][vars]. Τα var ανώτατου επιπέδου (καθολικά) μοιάζουν με τις σταθερές σε άλλες γλώσσες, αλλά συνήθως επαναπροσδιορίζονται για να διευκολύνουν τη δυναμική ανάπτυξη.

Τα var ανώτατου επιπέδου ορίζονται με το [`def`][def]:

```clojure
(def fingers 10)
```

Μπορείς να χρησιμοποιήσεις τις βασικές συναρτήσεις για [πράξεις με αριθμούς][operators] ώστε να κάνεις υπολογισμούς με τιμές.

Με το macro `defn` μπορείς να ορίσεις μια [συνάρτηση][functions] που δέχεται μηδέν ή περισσότερα ορίσματα. Μια συνάρτηση επιστρέφει πάντα το αποτέλεσμα της τελευταίας έκφρασης στο σώμα της.

```clojure
(defn add [x y]
  (+ x y))
```

Καλείς μια συνάρτηση γράφοντας το όνομά της και περνώντας ορίσματα για κάθε παράμετρο της συνάρτησης.

```clojure
(def five (add 2 3))
```

Οι συναρτήσεις και οι τιμές στη Clojure μπορούν να χρησιμοποιηθούν μόνο _αφού_ οριστούν. Αν χρησιμοποιήσεις κάτι πριν οριστεί, προκύπτει σφάλμα μεταγλώττισης.

```clojure
;; Compile error as `add` has not yet been defined
(def seven (add 3 4))

(defn add [x y]
  (+ x y))
```

Στη Clojure, τα κενά δεν έχουν σημασία πέρα από τη μορφοποίηση.

Οι συναρτήσεις και τα var της Clojure οργανώνονται σε namespaces. Ένα namespace ομαδοποιεί σχετική λειτουργικότητα και ορίζεται με το macro `ns`:

```clojure
(ns calculator)

(def pi 3.14)

(defn add [x y]
  (+ x y))
```

Η Clojure υποστηρίζει δύο τύπους σχολίων. Τα σχόλια μιας γραμμής ξεκινούν με `;` και η μορφή `comment` χρησιμοποιείται για να αποτρέψει την αξιολόγηση όλων όσων βρίσκονται ανάμεσα στο `(comment` και στο `)`.
