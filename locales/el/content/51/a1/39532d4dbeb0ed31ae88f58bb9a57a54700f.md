# Οδηγίες

Ο Ozan ετοιμάζει μια λίστα αναπαραγωγής για ένα οδικό ταξίδι που πλησιάζει. Δεν θέλει να ακούσει το ίδιο κομμάτι δύο φορές, αλλά η λίστα αναπαραγωγής έχει γίνει τόσο μεγάλη που δυσκολεύεται να θυμηθεί ποια κομμάτια έχουν ήδη προστεθεί.

Το API της εφαρμογής μουσικής του Ozan ξέρει να δουλεύει μόνο με διανύσματα. Δεν είναι δυνατοί ρητοί βρόχοι ή λογική if/else. Χρειάζεται τη βοήθειά σου!

## 1. Αφαίρεσε τα διπλότυπα κομμάτια

Υλοποίησε τη συνάρτηση `remove_duplicates`, η οποία παίρνει μια λίστα αναπαραγωγής ως _παράμετρο_ και _επιστρέφει_ μια νέα λίστα αναπαραγωγής όπου όλα τα κομμάτια είναι μοναδικά.

```R
> playlist <- c(
  "Court and Spark - Joni Mitchell",
  "Big Yellow Taxi - Joni Mitchell",
  "Court and Spark - Joni Mitchell"
)

> remove_duplicates(playlist)
[1] "Court and Spark - Joni Mitchell" "Big Yellow Taxi - Joni Mitchell"
```

## 2. Έλεγξε αν ένα κομμάτι έχει ήδη προστεθεί

Υλοποίησε τη συνάρτηση `has_track`, η οποία παίρνει μια λίστα αναπαραγωγής και ένα κομμάτι ως _παραμέτρους_ και _επιστρέφει_ ένα Boolean που δείχνει αν η λίστα αναπαραγωγής περιέχει το κομμάτι.

```R
> playlist <- c(
  "The Fashion Show - Grace Jones",
  "Dr. Funkenstein - Parliament"
)

> has_track(playlist, "Dr. Funkenstein - Parliament")
[1] TRUE

> has_track(playlist, "Walking in the Rain - Grace Jones")
[1] FALSE
```

## 3. Πρόσθεσε κομμάτια

Υλοποίησε τη συνάρτηση `add_tracks`, η οποία παίρνει μια λίστα αναπαραγωγής και ένα διάνυσμα με ένα ή περισσότερα κομμάτια ως _παραμέτρους_ και _επιστρέφει_ μια νέα λίστα αναπαραγωγής που περιλαμβάνει τα κομμάτια.

```R
> playlist <- c("Selma - Bijelo Dugme")

> playlist <- add_tracks(playlist, "Atomic Dog - George Clinton")
> playlist
[1] "Selma - Bijelo Dugme"   "Atomic Dog - George Clinton"

> add_tracks(playlist, "Selma - Bijelo Dugme")
[1] "Selma - Bijelo Dugme"   "Atomic Dog - George Clinton"

> add_tracks(playlist, c("The Chain - Fleetwood Mac", "Selma - Bijelo Dugme"))
[1] "Selma - Bijelo Dugme"   "Atomic Dog - George Clinton" "The Chain - Fleetwood Mac"  

```

## 4. Διάγραψε κομμάτια

Υλοποίησε τη συνάρτηση `delete_tracks`, η οποία παίρνει μια λίστα αναπαραγωγής και ένα ή περισσότερα κομμάτια ως _παραμέτρους_ και _επιστρέφει_ μια νέα λίστα αναπαραγωγής που δεν περιλαμβάνει τα κομμάτια.

```R
> playlist <- c(
  "The Treasure - Fra Lippo Lippi",
  "After the Fall - Klaus Nomi"
)

> playlist <- delete_tracks(playlist, "The Treasure - Fra Lippo Lippi")
> playlist
[1] "After the Fall - Klaus Nomi"

> delete_tracks(playlist, "I Feel the Magic - Belinda Carlisle")
[1] "After the Fall - Klaus Nomi"
```

## 5. Σύγκρινε λίστες αναπαραγωγής

Ο Ozan γνωρίζει έναν νέο φίλο και αναρωτιέται πόσο μοιάζουν τα γούστα τους. 
Υλοποίησε τη συνάρτηση `find_common_tracks`, η οποία παίρνει δύο λίστες αναπαραγωγής και επιστρέφει μια νέα λίστα αναπαραγωγής που περιέχει μόνο τα κομμάτια που υπάρχουν και στις δύο.

```R
> playlist_1 <- c("Karma - Taylor Swift", "Tired - Adele")
> playlist_2 <- c("Andromeda - Weyes Blood", "Karma - Taylor Swift")
> find_common_tracks(playlist_1, playlist_2)
[1] "Karma - Taylor Swift"
````
