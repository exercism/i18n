# Υποδείξεις

## 1. Οδήγησε ένα αυτοκίνητο

- Πρόσθεσε ένα πεδίο στο struct `Car` που παρακολουθεί την απόσταση που έχει διανυθεί
- Δημιούργησε μια [μέθοδο][method] που έχει δέκτη τύπου `Car` και ενημερώνει την απόσταση που έχει διανυθεί

## 2. Εμφάνισε την απόσταση που διανύθηκε

- Δημιούργησε μια [μέθοδο][method] που έχει δέκτη τύπου `Car`
- Δείξε την τιμή του πεδίου _distance_

## 3. Εμφάνισε το ποσοστό της μπαταρίας

- Δημιούργησε μια [μέθοδο][method] που έχει δέκτη τύπου `Car`
- Δείξε την τιμή του πεδίου _battery_

## 4. Έλεγξε αν ένα τηλεχειριζόμενο αυτοκίνητο μπορεί να τερματίσει έναν αγώνα

- Θυμήσου ότι το αυτοκίνητο έχει μια [μέθοδο][method] για να ανακτήσεις την απόσταση που έχει διανύσει
- Σκέψου τι να κάνεις όταν η μπαταρία έχει εξαντληθεί πριν φτάσεις στη γραμμή τερματισμού

[method]: https://tour.golang.org/methods/1
