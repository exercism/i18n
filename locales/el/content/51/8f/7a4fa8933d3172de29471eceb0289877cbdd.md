# Υποδείξεις

## Γενικά

- Ο τύπος που σου δίνεται είναι αναδρομικός: το `Nil` αναπαριστά μια κενή λίστα και το `Cons(value, rest)` περιέχει ένα στοιχείο και μια άλλη λίστα.
  Χρησιμοποίησε τις ίδιες μορφές μέσα σε ένα `match` για να εξετάσεις μια λίστα ή μέσα σε μια έκφραση για να κατασκευάσεις μία.

- Οι πράξεις επιστρέφουν ενημερωμένες λίστες αντί να τροποποιούν τα ορίσματά τους.
